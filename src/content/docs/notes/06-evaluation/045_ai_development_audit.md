## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **인공지능 개발 감리(AI Development Audit)**: 데이터 수집·정제부터 모델 학습, 평가, 배포, 운영에 이르는 AI 전 주기에서 품질, 신뢰성, 공정성을 독립 검증하는 전문 감리.
- **AI 모델 품질(AI Model Quality)**: 정확도(Accuracy), 정밀도(Precision), 재현율(Recall), 일반화(Generalization) 능력을 정량적으로 평가하는 척도.
- **AI 신뢰성 및 윤리(AI Trustworthiness & Ethics)**: 편향성(Bias), 설명가능성(XAI), 개인정보 보호, 적대적 공격 방어 능력을 종합 보증하는 체계.

</details>

- 정의/개념: 데이터·모델·운영 증거를 검증하는 **AI 개발 감리**
- 배경/필요성: 코드 감리만으로는 **편향·드리프트·확률 오류 통제 불가**

#### 한줄 요약

- 데이터 출처부터 **배포 후 감독·롤백**까지 검증

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **데이터셋 품질 검증(Dataset Quality)**: 학습/검증/테스트 데이터셋의 라벨링 정확도, 클래스 불균형, 결측치, 편향성 검증.
- **모델 학습 및 검증(Model Training & Validation)**: 과적합(Overfitting) 방지 기법, 하이퍼파라미터 튜닝 이력, 교차 검증 절차의 적정성 확인.
- **설명가능성 및 투명성(Explainability & Transparency)**: SHAP, LIME, Attention Map 등을 통해 AI 의사결정 과정의 해석 가능성을 확보.
- **보안 및 적대적 공격 방어(AI Security)**: 적대적 섭동(Adversarial Perturbation), 데이터 포이즈닝(Data Poisoning), 모델 추출 공격에 대한 방어력 점검.

</details>

- **데이터 계보·재현성** 기반 평가 증거
- 집단별 **공정성·적대적 강건성** 검증
- **모델 드리프트·인간 감독** 운영 통제

#### 한줄 요약

- 계보·재현·드리프트·**인간 감독**의 증거 검증

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **데이터 계층(Data Layer)**: 데이터 수집 출처의 적법성, 라벨링 검수 프로세스, 개인정보 가명/익명화 조치.
- **알고리즘 및 모델 계층(Model Layer)**: 모델 아키텍처 선정 타당성, 손실함수 최적화, 성능 벤치마크 지표.
- **서빙 및 MLOps 계층(MLOps Layer)**: 지속적 학습(CT), 모델 레지스트리 버전 관리, 추론 지연시간(Latency), 드리프트 모니터링.

</details>

```text
                         [목적•위험]
                         /         \
                    [데이터]     [모델]
                         \         /
                         [버전•증거]
                              |
                         [운영•책임]
```

선의 의미: 목적·위험 아래 데이터·모델·버전·운영 연결

| 구성요소 | 책임 및 검증 초점 |
|:---|:---|
| 목적•위험 | 오류 비용·피해 집단과 합격선 정의 |
| 데이터 | 출처·권리·대표성·**계보** 검증 |
| 모델 | **공정성·강건성·모델 카드** 검증 |
| 버전•증거 | **불변 식별자·재현성** 확보 |
| 운영•책임 | 드리프트 감시·중단 권한 명확화 |

#### 한줄 요약

- 위험별 **데이터·모델·버전·운영 책임** 검증

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **데이터 수집 및 구축 점검(Data Audit)**: 데이터셋 명세서, 저작권 적법성, 데이터 다양성 및 품질 지표를 검증하는 단계.
- **모델 설계 및 학습 점검(Model Training Audit)**: 학습 파이프라인 코드, 과적합 방지 조치, 재현성(Seed 고정)을 확인하는 단계.
- **성능 및 편향 평가(Validation & Fairness Audit)**: 독립된 테스트 데이터셋을 통해 성능 지표와 특정 집단에 대한 편향성 여부를 실측하는 단계.
- **배포 및 모니터링 체계 점검(MLOps Audit)**: 데이터 드리프트 탐지 알림, 모델 롤백 전략, API 서빙 안정성을 검증하는 단계.

</details>

```text
              [발주자]
                  │ AI 감리 요청
                  ▼
              [감리인]
                  │ 1. 용도•위험 정의
                  │   수명주기 증거 요청
                  ▼
              [사업자]
                  │ 데이터•학습•운영 증거
                  ▼
              [감리인]
                  │ 2. 데이터 증거 검증
                  │ 3. 모델 재현 시험
                  │ 4. 배포•감시 통제 검증
                  │   잔여 위험•승인 조건 반환
                  ▼
              [발주자]
```

### 동작 원리

1. **용도•위험 정의**: 오류 비용·피해별 승인 조건 설정
2. **데이터 증거 검증**: 출처·계보·대표성·누수 검증
3. **모델 재현 시험**: 성능·공정성·강건성 재현
4. **배포•감시 통제 검증**: 드리프트·감독·롤백 확인

#### 한줄 요약

- 오류 비용별 증거와 **감독·롤백 통제** 충족 후 배포

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **기존 SW 감리(Traditional Software Audit)**: 결정론적(Deterministic) 로직과 코드 구문, 관계형 DB 정규화를 검증하는 방식.
- **AI 특화 감리(AI-Specific Audit)**: 확률론적(Probabilistic) 모델 동작, 데이터 분포 변화, 모델 신뢰성과 윤리성을 검증하는 방식.

</details>

| AI 감리 점검 영역 | 데이터 감리 (Data Audit) | 모델 감리 (Model Audit) | 운영 감리 (Operation Audit) |
|:---|:---|:---|:---|
| 적용 기준 | 출처·권리·대표성·누수 | 성능·공정성·강건성 | 드리프트·감독·롤백 |
| 핵심 특징 | **데이터 계보·누수** | **재현성·집단별 성능** | **운영 감시·중단 권한** |
| 한계 | 비정형 데이터 정제 및 저작권 확인 한계 | 블랙박스 모델의 설명 가능성 한계 | 런타임 데이터 드리프트 및 환각 통제 한계 |

#### 한줄 요약

- 데이터·모델·운영별 **승인 책임** 분리

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **데이터 편향 및 공정성(Data Bias & Fairness)**: 성별, 연령, 지역 등에 대한 통계적 패리티(Demographic Parity) 지표를 측정하여 알고리즘 차별 방지.
- **데이터 및 개념 드리프트(Data & Concept Drift)**: 운영 환경 데이터 분포 변화를 주기적으로 감지하고 자동 재학습(Retraining) 트리거 구축 여부 확인.
- **AI 재현성 확보(AI Traceability)**: 데이터 버전(DVC), 코드(Git), 모델 가중치(MLflow)를 완전히 연계하여 동일 결과 재현성 보장.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 집단별 **미탐·오탐** 편중 | 집단별 지표·인간 검토 | 차별·윤리 위험 억제 |
| 데이터·모델 버전 단절 | MLOps **불변 식별자** 결속 | 승인 근거 재현·추적 |
| 배포 후 **드리프트** | 임계치 알림·롤백 책임자 | 성능 붕괴 조기 회복 |
| **프롬프트 주입·환각** | 격리·RAG 근거 검증 | 생성형 AI 오용·오류 감축 |
| 지사별 위험 기준 불일치 | **ISO 42001·NIST AI RMF** 정렬 | 거버넌스 일관성 확보 |

#### 한줄 요약

- 고위험 AI는 집단별 **미탐과 인간 검토** 검증

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **신뢰할 수 있는 인공지능 거버넌스 체계(Trustworthy AI Governance)**: 데이터 품질과 모델 투명성을 체계적으로 감리하여 공공 및 산업 전반에 안전하고 신뢰할 수 있는 AI 서비스를 정착시키는 체계.

</details>

- 오류 비용별 기준과 재현·감독·롤백을 충족한 모델만 배포

#### 한줄 요약

- **재현 시험·드리프트 감시·인간 감독** 충족 후 배포
