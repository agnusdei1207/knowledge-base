## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **대기행렬 이론(Queuing Theory)**: 요청 유입과 서버 처리 능력을 확률 모델화하여 혼잡도와 대기시간을 수학적으로 분석하는 이론.
- **도착률(Arrival Rate, λ)**: 단위 시간당 시스템에 유입되는 평균 요청 건수.
- **서비스율(Service Rate, μ)**: 단위 시간당 단일 서버가 처리 완료하는 평균 건수.
- **대기 급증(Non-linear Queue Growth)**: 유입 부하가 처리 한계에 근접할 때 대기열이 비선형적으로 폭증하는 현상.

</details>

- 정의/개념: 요청 유입률과 처리율의 확률 분포를 기반으로 대기열 길이와 체류시간을 산출하는 수리 분석 기법
- 배경/필요성: 평균값만으로는 **비선형 대기 급증** 예측 불가

#### 한줄 요약

- 유입·처리 속도로 **대기 지연·서버 용량 산출** ## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **이용률(Utilization, ρ)**: 전체 서비스 처리 능력 대비 유입 부하가 차지하는 비율.
- **안정 조건(Stability Condition)**: 총 처리 역량 미만으로 유입 부하가 유지되어 대기열이 발산하지 않는 전제 조건.
- **가정 민감도(Assumption Sensitivity)**: 도착 및 처리시간 분포 가정에 따라 예측값이 크게 변화하는 특성.
- **얼랑 C(Erlang C)**: 다중 서버 환경에서 새 요청이 대기열로 진입할 확률을 계산하는 수식.

</details>

- **이용률** 1에 근접할수록 대기시간 비선형 증가
- **안정 조건** 안에서만 서버 용량 산정 가능
- 분포·큐 용량·규율에 따른 **가정 민감도** 관리
- 병렬 서버의 대기 확률은 **얼랑 C** 기반 산출

#### 한줄 요약

- 이용률 1 접근 전 **비선형 대기 급증 방지** ## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **켄달 표기법(Kendall's Notation)**: 도착 분포, 서비스 분포, 서버 수 등을 축약해 대기행렬을 표현하는 표준 기호 체계.
- **M/M/1 모형(Single-Server Queue)**: 포아송 도착과 지수 서비스 분포를 갖는 단일 서버 큐잉 모델.
- **M/M/c 모형(Multi-Server Queue)**: 포아송 도착과 지수 서비스 분포를 갖는 다중 병렬 서버 큐잉 모델.
- **선입선출(First In First Out, FIFO)**: 먼저 도착한 요청을 먼저 처리하는 기본 대기 규율.

</details>

```text
대기행렬 모형
├─ 도착 과정 (Arrival Process)
├─ 대기열 (Queue)
├─ 서비스 과정 (Service Mechanism)
├─ 대기 규칙 (Queue Discipline)
└─ 켄달 표기 (A/S/c/K/N/D)
```

선의 의미: 유입(도착), 저장(대기), 방출(서비스) 메커니즘을 켄달 표기법으로 모델링하는 분석 구조.

| 구성요소 | 책임 |
|:---|:---|
| 도착 과정 | **도착률** $\lambda$와 분포 정의 |
| 대기열 | 용량·요청 차단 정책 설정 |
| 서비스 과정 | **서비스율** $\mu$와 서버 수 $c$ 정의 |
| 대기 규칙 | **FIFO**·우선순위·포기 규칙 설정 |
| 켄달 표기 | **Kendall 표기** 기반 수식 조건 명시 |

#### 한줄 요약

- 도착률·서비스율·서버 수 기반 **체류시간 산출** ## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **대기열(Queue)**: 서버 가용 용량이 부족할 때 작업이 순번을 대기하는 완충 공간.
- **실측 보정(Empirical Calibration)**: 이론 모델의 계산치를 실제 부하 테스트 측정값과 대조해 튜닝하는 과정.

</details>

```text
측정 담당자
   │ 1. λ, μ, 분포 측정
   ▼
모형 선정자
   │ 2. 켄달 A/S/c/K/N/D 확정
   ▼
안정성 검증자
   │ 3. ρ = λ/(cμ) < 1 확인
   ▼
지표 산출자
   │ 4. L_q·W_q·W 계산
   ▼
보정 담당자
   │ 5. 실측 오차 반영
   ▼
용량 산정 결과
```

**동작 원리** 1. **λ, μ, 분포 측정**: 유입·처리 표본 수집
2. **켄달 A/S/c/K/N/D 확정**: 모형 조건 명시
3. **ρ = λ/(cμ) < 1 확인**: 안정 조건 검증
4. **L_q·W_q·W 계산**: 대기·체류 지표 산출
5. **실측 오차 반영**: 부하 시험으로 예측값 보정

#### 한줄 요약

- 실측 보정 기반 **최적 서버 수 확정** ## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **분배 불균형(Load Imbalance)**: 다중 노드 환경에서 트래픽이 특정 서버에 편중되는 상태.

</details>

| 큐잉 모델 | M/M/1 단일 모형 | M/M/c 다중 병렬 모형 |
|:---|:---|:---|
| 적용 기준 | 락 경합 **DB**·단일 파티션 | 클러스터 **WAS**·상담원 풀 |
| 핵심 특징 | **M/M/1** 기반 순차 처리 | **M/M/c** 기반 병렬 분산 |
| 한계 | 단일 포화·SPOF 위험 | **분배 불균형**·공유 자원 병목 |

> 요약: 시스템 아키텍처 토폴로지에 따라 단일 병목점 모델인 M/M/1과 수평 확장 모델인 M/M/c를 구분 적용.

#### 한줄 요약

- 순차 **M/M/1** 및 병렬 **M/M/c** 구분 적용

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **도착분포(Arrival Distribution)**: 단위 시간당 유입 요청 간격의 확률 분포.
- **서비스분포(Service Distribution)**: 개별 트랜잭션 처리시간의 확률 분포.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 모형 가정과 실제 지표 괴리 | **도착분포**•**서비스분포** 명시 | 지표 재현성 확보 |
| 발산 큐로 분석 무의미 | $\rho < 1$ **안정 조건** 선검증 | 불안정 설계 배제 |
| 통계 가정과 실측 편차 | 부하 시험·시뮬레이션 병행 | 예측 오차 감소 |

#### 한줄 요약

- 모형 가정 검증 후 **실측 기반 용량 보정** ## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **안정 여유(Safety Headroom)**: 트래픽 급증 시 대기열 폭발을 방어하기 위해 확보하는 예비 용량.

</details>

- 순차는 M/M/1, 병렬은 M/M/c로 **안정 여유 산정** #### 한줄 요약

- 목표 지연을 만족하는 **서버 수·안정 여유 결정**
