## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **PUE**: 총 시설 전력을 IT 장비 전력으로 나눈 전력 효율 지표.
- **WUE**: IT 에너지당 데이터센터의 물 사용량을 나타내는 지표.
- **CUE**: IT 에너지당 온실가스 배출량을 나타내는 지표.
- **REF**: 총 에너지 중 재생에너지 비율을 나타내는 지표.

</details>

- 정의/개념: 전력·물·탄소·재생에너지를 통합 최적화하는 **친환경 데이터센터**
- 배경/필요성: AI 랙의 전력 밀도 증가로 기존 공랭식의 **열 제거 한계**

#### 한줄 요약
- 그린 데이터센터는 가용성을 유지하며 에너지와 환경 영향을 최소화한다.

## Ⅱ. 특징

- 전력 효율을 평가하는 **PUE** 통합 관리
- 수자원 소비를 평가하는 **WUE** 통합 관리
- 탄소 배출을 평가하는 **CUE** 통합 관리
- 재생에너지 비율을 평가하는 **REF** 통합 관리
- IT 부하·시설·조달을 아우르는 **3계층 최적화**
- 고밀도 AI 랙의 **D2C·액침 냉각** 적용
- 지역 에너지로 전환하는 **폐열 회수**

#### 한줄 요약
- 4대 지표, 3계층 최적화, 액체 냉각, 폐열 회수가 핵심이다.

## Ⅲ. 구조 및 구성요소

```text
┌────────────── 그린 데이터센터 ──────────────┐
│                                             │
├── [IT 자원 계층]                            │
│   └── 가상화 · DVFS · 고효율 서버           │
├── [시설 인프라 계층]                        │
│   └── D2C · 액침 냉각 · 고효율 UPS · 폐열   │
├── [에너지·수자원 조달 계층]                 │
│   └── PPA · 재생에너지 · 중수도             │
└── [지표 관리]                               │
    └── PUE · WUE · CUE · REF                 │
```

| 구성요소 | 책임 |
|:---|:---|
| **IT 자원 계층** | 연산량과 유휴 전력의 원인 통제 |
| **시설 인프라 계층** | 냉각·전력 변환 손실 최소화 |
| **에너지·수자원 조달** | 저탄소 전력과 재이용수 확보 |
| **지표 관리** | PUE·WUE·CUE·REF 동시 감시 |

#### 한줄 요약
- IT 원인 통제, 시설 효율화, 청정 조달, 지표 관리로 구성된다.

## Ⅳ. 흐름도

```text
[사업·입지 조건]
     │
     │ 1. 부하·환경 기준선 산정
     ▼
[설계 조직]
     │ 2. IT·냉각·전력·용수 통합 설계
     │ 3. LCA·LCC 타당성 평가
     │ 4. 부하 시운전과 지표 실측
     │ 5. 가용성·환경 목표 판정
     ▼
[운영·인증 조직]
     │
     └──────── 인증·운영 결과 반환
```

**동작 원리**

1. **부하·환경 기준선 산정**: 랙 밀도와 기후·전력·용수 조건 분석
2. **IT·냉각·전력·용수 통합 설계**: 계층별 효율 대안과 이중화 결정
3. **LCA·LCC 타당성 평가**: 전 과정 환경 영향과 총비용 검증
4. **부하 시운전과 지표 실측**: 최대 부하에서 4대 지표 측정
5. **가용성·환경 목표 판정**: 가용성 하한과 환경 목표 동시 확인

#### 한줄 요약
- 기준선, 통합 설계, LCA·LCC, 실측, 목표 판정 순으로 구축한다.

## Ⅴ. 종류 및 비교

| 비교 항목 | 공랭식 | D2C 액체 냉각 | 액침 냉각 |
|:---|:---|:---|:---|
| 열 전달 매체 | 공기 | 냉각판의 액체 | 절연액 |
| 랙 전력 밀도 | **저밀도 랙** | **고밀도 AI 랙** | **초고밀도 랙** |
| 에너지 효율 | 팬·칠러 손실 큼 | 칩 열 직접 제거 | 팬 제거와 열 회수 유리 |
| 구축 난도 | 기존 표준 활용 | 매니폴드·누수 관리 | 전용 탱크·유체 관리 |
| 적용 판단 | 일반 워크로드 | 고발열 GPU 중심 | 최고 밀도와 효율 우선 |

#### 한줄 요약
- 랙 밀도와 운영 역량에 따라 공랭식, D2C, 액침 냉각을 선택한다.

## Ⅵ. 실무 고려사항 및 대책

| 문제 | 대책 |
|:---|:---|
| 고밀도 GPU의 핫스팟과 스로틀링 | 열 밀도에 맞춘 **D2C·액침 냉각** |
| PUE 개선 과정의 물 소비 증가 | PUE·WUE의 **동시 최적화** |
| 효율 개선을 위한 이중화 축소 | 가용성의 **최소 설계 기준** 유지 |
| 재생에너지의 간헐성과 출력 변동 | PPA·ESS 기반 **전력 조달 다변화** |
| 운영 탄소만 평가하는 그린워싱 | 내재 탄소를 포함한 **LCA** 적용 |

#### 한줄 요약
- 열, 물, 가용성, 전력 변동, 전 과정 탄소를 함께 통제한다.

## Ⅶ. 결론

- 가용성 하한을 지키며 랙 밀도에 맞춰 **냉각·청정 조달** 동시 최적화

#### 한줄 요약
- 가용성을 전제로 4대 지표가 개선되는 냉각과 조달 조합을 선택한다.
