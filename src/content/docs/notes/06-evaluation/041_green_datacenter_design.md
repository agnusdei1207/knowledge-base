## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **그린 데이터센터(Green Data Center)**: IT 가용성을 유지하면서 전력, 수자원, 탄소 배출량 및 전자 폐기물 영향을 최소화하도록 설계·운영되는 친환경 데이터센터 인프라.
- **전력 사용 효율(Power Usage Effectiveness, PUE)**: 총 시설 에너지 소비량을 순수 IT 장비 에너지 소비량으로 나눈 전력 효율 지표.
- **환경 부담 전가(Environmental Burden Shifting)**: 특정 환경 지표(PUE)를 개선하는 과정에서 수자원 소비나 탄소 배출 등 다른 환경 영역의 부담이 증가하는 현상.
- **생애주기 최적화(Life Cycle Optimization)**: 부지 선정, 건축, 운영, 장비 폐기까지 전 과정에 걸쳐 총소유비용(TCO)과 환경 영향을 종합 관리하는 설계 방식.

</details>

- 정의: 가용성 보장 하에 전력·수자원·탄소를 감축하는 **그린 데이터센터**이다.
- 배경/필요성: PUE 단독 최적화 시 **환경 부담 전가 통제 불가**

#### 한줄 요약

- 전 생애주기의 **전력·수자원·탄소 영향** 동시 통제

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **물 사용 효율(Water Usage Effectiveness, WUE)**: 냉각을 위한 직접 물 소비량을 IT 장비 전력 소비량으로 나눈 수자원 효율 지표.
- **탄소 사용 효율(Carbon Usage Effectiveness, CUE)**: 데이터센터 운영으로 발생한 탄소 배출량을 IT 장비 전력 소비량으로 나눈 탄소 집약도 지표.
- **재생에너지 계수(Renewable Energy Factor, REF)**: 총 에너지 소비량 중 재생에너지가 차지하는 비율.

</details>

- **PUE·WUE·CUE·REF**의 다지표 평가
- 입지·건설·운영·폐기의 **생애주기 최적화**
- 부하 시운전으로 환경 효율과 **가용성 상충** 검증

#### 한줄 요약

- 다지표 검증으로 **환경 부담 전가** 방지

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **고밀도 랙(High-Density Rack)**: 단위 랙당 30kW 이상의 고전력·고발열 IT 장비를 집적한 랙 구성.
- **액체 냉각(Liquid Cooling)**: 냉각액을 프로세서 발열체에 직접 순환시켜 열을 흡수하는 고효율 냉각 방식.
- **침지 냉각(Immersion Cooling)**: 비전도성 절연 액체 수조에 서버를 직접 침강시켜 냉각하는 고효율 냉각 기술.
- **정보기술 자원 최적화(IT Resource Optimization)**: 서버 가상화, 저전력 프로세서 적용으로 IT 자체의 전력 소모를 절감하는 활동.

</details>

```text
[입지]---[에너지•수자원]---[IT 자원]
  |                            |
[시설 인프라]---[전력•물 계측]---[탄소•재생에너지 계측]
```

선의 의미: 입지·조달·IT·시설을 4대 지표로 감시

| 구성요소 | 책임 |
|:---|:---|
| 입지 | 기후·전력망·재해·물 부족도 검토 |
| 에너지•수자원 | **REF**•**재이용수**로 조달 부담 완화 |
| IT 자원 | 이용률 개선과 **고밀도 랙** 배치 통제 |
| 시설 인프라 | 고효율 배전·**액체·침지 냉각** 적용 |
| 전력•물 계측 | 동일 부하의 **PUE**•**WUE** 추적 |
| 탄소•재생에너지 계측 | **CUE**•**REF** 장기 추세 입증 |

#### 한줄 요약

- 입지·냉각·조달 효과를 **4대 지표**로 검증

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **생애주기 평가(Life Cycle Assessment, LCA)**: 원자재 채굴부터 건설, 운영, 폐기까지 전 과정의 환경 영향을 평가하는 기법.
- **생애주기 비용(Life Cycle Cost, LCC)**: 초기 구축 비용(Capex)과 운영 비용(Opex) 및 폐기 비용을 합산하여 총비용을 평가하는 재무 척도.

</details>

```text
              [기획자]
                  │ 설계 검토 요청
                  ▼
              [설계자]
                  │ 1. 입지•지표 설정
                  │ 2. 통합 설계
                  │   시운전 요청
                  ▼
              [검증원]
                  │ 3. 부하별 시운전
                  │ 4. LCA•LCC 검증
                  │
                  ▼
              [기획자]
```

### 동작 원리

1. 입지•지표 설정: 기후·전력망과 4대 목표 확정
2. 통합 설계: 전력·물·탄소·가용성 상충 조정
3. 부하별 시운전: 부하별 지표와 무중단성 검증
4. LCA•LCC 검증: 생애주기 환경·비용으로 설계 확정

#### 한줄 요약

- 부하 시운전과 **LCA**•**LCC**로 통합 설계 확정

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **시설 인프라 최적화(Facility Optimization)**: 공조, 배전, 냉각 인프라의 효율을 개선하여 지원 설비 전력 소비를 줄이는 전략.
- **조달 청정화(Clean Procurement)**: 신재생에너지 전력 수급(PPA)과 재이용수 활용으로 탄소와 수자원 영향을 억제하는 전략.

</details>

| 그린 설계 타기팅 영역 | IT 자원 (원인 통제) | 시설 인프라 (효율 통제) | 에너지•수자원 (조달 혁신) |
|:---|:---|:---|:---|
| 적용 기준 | IT 장비 노후화 및 저이용률 환경 | 고밀도 랙 및 냉각 병목 환경 | 신재생에너지 인입 가능 환경 |
| 핵심 특징 | 가상화·저전력 칩으로 **발열 원천 감축** | 액체 냉각·고효율 UPS로 **PUE 개선** | 재생에너지·재이용수로 **CUE·WUE 개선** |
| 한계 | 초기 서버 교체 투자 비용 수반 | 고집적 액체 배관 유지보수 복잡도 | 지역별 재생에너지 수급 인프라 의존 |

#### 한줄 요약

- IT 원인·시설 효율·**청정 조달**의 3축 최적화

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **가용성-효율 상충(Availability-Efficiency Trade-off)**: 에너지 절감을 위한 이중화 축소가 시스템 무중단 가용성을 저해하는 위험 관계.
- **전력-물 상충(Power-Water Trade-off)**: 증발식 냉각으로 PUE를 개선할 때 수자원 소비(WUE)가 증가하는 상충 관계.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **고밀도 랙**의 공랭 한계 | 액체·침지 냉각과 누수 방지 시험 | 고밀도 열 폭주 방지 |
| PUE 개선의 물 부담 전가 | **PUE·WUE·CUE** 동시 관리 | 환경 부담 전가 억제 |
| 효율 개선의 예비력 축소 | N+1 다중화와 장애 전환 시험 | **가용성 하한** 유지 |

#### 한줄 요약

- 고밀도 랙은 액체 냉각, 효율 조정은 **가용성 우선**

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **다지표 최적화(Multi-Metric Optimization)**: 단일 지표에 편중되지 않고 PUE, WUE, CUE, REF와 가용성, LCC를 종합 고려하여 설계 대안을 선정하는 방법.

</details>

- 가용성 하한을 지키며 4대 지표와 LCA·LCC가 우수한 설계 선택

#### 한줄 요약

- **가용성 충족 대안 중** 생애주기 환경·비용 최소화
