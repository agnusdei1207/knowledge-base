## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **스플릿 브레인**: 네트워크 분리 뒤 복수 노드가 자신을 활성 주체로 판단하여 동일 데이터에 동시에 쓰는 일관성 장애이다.
- **네트워크 분할**: 노드는 동작하지만 통신 경로가 끊겨 서로의 상태를 확인할 수 없는 장애이다.
- **단일 쓰기 보장**: 네트워크 분할 중에도 한 세대의 승인된 리더만 데이터를 변경하게 하는 안전성 조건이다.

</details>

- 정의/개념: 네트워크 분할로 다중 리더가 생기는 **일관성 장애**
- 배경/필요성: 생존 확인만으로는 **단일 쓰기 보장 불가**

#### 한줄 요약

- 네트워크 분할 때 과반수 쪽만 쓰고 반대쪽은 중단하는 단일 쓰기 통제

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **쿼럼**: 클러스터가 결정권과 쓰기 권한을 유지하기 위해 확보해야 하는 최소 투표 수이다.
- **과반수**: 전체 투표 수의 절반을 초과한 수로, 서로 다른 두 과반수 집합이 적어도 한 표를 공유하게 한다.
- **하트비트**: 노드가 자신의 생존 상태를 주기적으로 다른 노드에 알리는 신호이다.
- **펜싱**: 쿼럼에서 탈락하거나 이전 세대인 노드가 공유 데이터에 쓰지 못하도록 실제 접근을 차단하는 통제이다.

</details>

- 과반수 쿼럼 기반 **단일 리더 선출**
- 펜싱•세대 번호 기반 **이전 쓰기 차단**
- 증인 노드 기반 **2노드 동률 해소**

#### 한줄 요약

- 과반수 판정과 고립 노드 펜싱을 결합한 단일 쓰기 보장

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **증인•중재 노드**: 데이터를 복제하지 않고 제3의 투표를 제공하여 2노드 동률을 해소하는 구성요소이다.
- **임대권**: 정해진 시간과 세대 동안 하나의 노드에만 유효한 쓰기 권한이다.
- **세대 번호**: 이전 리더의 오래된 요청과 새 리더의 요청을 구분하는 단조 증가 식별값이다.
- **2노드 동률 해소**: 독립된 제3의 증인 투표를 더해 어느 한 파티션만 과반수를 구성하게 하는 방식이다.

</details>

```text
[복제 노드•투표권]---[다중 하트비트•분할 감지]---[증인•중재 노드•쿼럼]
                              |                              |
                    [임대권•임기•세대]----------[펜싱•재동기화]
```

선의 의미: 복제 노드와 장애 감지 체계에 쿼럼, 임대권•세대, 펜싱•재동기화 통제가 결합되는 단일 쓰기 클러스터 구조를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 복제 노드•투표권 | 리더 선출•**로그 복제 참여** |
| 다중 하트비트•분할 감지 | 독립 경로•**시간초과 판정** |
| 증인•중재 노드•쿼럼 | 동률 해소•**과반수 교차집합** 형성 |
| 임대권•임기•세대 | 단일 권한•**오래된 쓰기 거부** |
| 펜싱•재동기화 | 고립 차단•**승인 상태 복구** |

#### 한줄 요약

- 투표•임대권•펜싱을 연결한 단일 쓰기 주체 확정

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **펜싱**: 고립되거나 이전 세대인 노드의 전원•스토리지•쓰기 권한을 강제로 차단하는 통제이다.
- **재동기화**: 분리됐던 노드가 재합류할 때 승인된 리더의 데이터 상태로 맞추는 처리이다.

</details>

```text
       후보 노드
              │ 1. 분할 감지•새 임기 시작
              ▼
       쿼럼 관리자
              │ 2. 과반수 투표•로그 확인
              ▼
       펜싱 장치
              │ 3. 고립 노드 펜싱 실행
              ▼
       새 리더
              ├─ 4. 단일 임대권•리더 활성화
              └─ 5. 로그 재동기화•쓰기 재개
                          │
                          ▼
                합류 상태 복구
```

**동작 원리**

1. **분할 감지•새 임기 시작**: 통신 단절•세대 증가
2. **과반수 투표•로그 확인**: 권한 파티션•최신성 결정
3. **고립 노드 펜싱 실행**: 전원•스토리지•쓰기 차단
4. **단일 임대권•리더 활성화**: 한 파티션만 쓰기 허용
5. **로그 재동기화•쓰기 재개**: 분기 방지•합류 상태 복구

#### 한줄 요약

- 패배 파티션의 저장 권한 차단 후 새 리더 쓰기 권한 부여

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **Raft**: 다수결과 임기 번호를 이용하여 단일 리더와 로그 복제를 유지하는 분산 합의 알고리즘이다.
- **Paxos**: 과반수 수락자 집합의 교차 성질을 이용하여 하나의 합의값을 보장하는 알고리즘이다.
- **스플릿 브레인 영향**: 중복 쓰기와 데이터 분기를 발생시킨다.
- **쿼럼 통제 효과**: 한 파티션에만 결정권을 부여한다.

</details>

**스플릿 브레인** 과 **쿼럼** 은 대안 관계가 아니라 네트워크 분할에서 발생하는 장애와 이를 통제하는 판정 규칙의 관계이다.

| 요소 | 역할 | 결과•운영 대가 |
|:---|:---|:---|
| 스플릿 브레인 | 분할 뒤 여러 노드가 동시에 활성화되는 **장애 상태** | 중복 쓰기•데이터 분기와 복구 비용 발생 |
| 쿼럼 | 한 파티션에만 결정권을 주는 **통제 규칙** | 단일 쓰기를 보장하되 과반수 미달 시 서비스 중단 |

**Raft** 와 **Paxos** 는 과반수 집합이 교차한다는 성질을 이용해 쿼럼 기반 단일 합의를 구현한다.

#### 한줄 요약

- 동시 쓰기 장애인 스플릿 브레인과 단일 권한 판정 규칙인 쿼럼의 관계

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **거짓 장애 탐지**: 지연•일시적 패킷 손실을 노드 고장으로 오판하여 불필요한 리더 전환을 일으키는 문제이다.
- **쿼럼 손실**: 살아 있는 노드가 있어도 과반수 표를 확보하지 못하여 안전한 쓰기를 중단하는 상태이다.
- **오래된 리더 쓰기**: 새 리더가 선출된 뒤 이전 리더의 지연 요청이 저장소에 반영되는 위험이다.
- **AZ(Availability Zone)**: 전원•망•시설을 독립 분리한 가용 영역이다.
- **AZ 증인**: 다른 장애 영역에서 제3의 투표를 제공하는 구성이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 지연을 고장으로 오판한 **거짓 장애 탐지** | **다중 경로•적응 시간초과** | 불필요한 **리더 전환 감소** |
| 과반수 상실로 쓰기가 멈추는 **쿼럼 손실** | **홀수 노드•독립 AZ 증인** | 안전한 **쓰기 가용성** 확보 |
| 새 임기 뒤 남는 **오래된 리더 쓰기** | **펜싱•세대 번호** 검증 | **데이터 분기** 방지 |

#### 한줄 요약

- 2노드 동률을 독립 장애 영역의 증인으로 해소하는 구성

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **단일 쓰기 보장**: 네트워크 분할 중에도 한 세대의 승인된 리더만 상태를 변경하게 하는 안전성 조건이다.
- **가용성-일관성 절충**: 분할 상황에서 쓰기 중단을 택해 일관성을 지키거나 양쪽 쓰기를 허용해 가용성을 높이는 선택 관계이다.
- **리더 승인 조건**: 과반수와 최신 로그를 확보하고 이전 노드의 펜싱이 성공한 경우에만 새 쓰기 권한을 부여하는 기준이다.

</details>

- 과반수•최신 로그 확보 후 펜싱 성공 시만 **단일 리더 승인**

#### 한줄 요약

- 과반수 없는 파티션을 중단하고 한쪽에만 새 쓰기 권한을 주는 통제
