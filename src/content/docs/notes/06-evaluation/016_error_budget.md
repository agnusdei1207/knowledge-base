## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **SLO(Service Level Objective, 서비스 품질 쉴드 목표 마지노선 타겟)**: "이번 달 결제 성공률은 최소 99.9% 컷오프를 기어코 무조건 방어 사수한다"처럼, 일정 달력 캘린더 기간 내에 데브옵스 엔지니어 기동조가 뚫리지 않고 지켜내야 할 사내 내부 품질 방어 쉴드 타겟 컷오프 목표 잣대.
- **오류 예산(Error Budget, 뻗음 허용 실패 쉴드 캡 마일리지 잔고 쿼터 한도 통장)**: 서비스 수준 목표(SLO)가 100% 무결점을 포기하고 합법적으로 "이만큼은 에러 나고 뻗어도 위약금 안 내고 용서해 준다"고 허용 쉴드 쳐준 최대 실패 마지노선 캡 쿼터 용량에서, 센서가 실제 적발한 리얼타임 에러 뻗음 실패 팩트 발생량 덤프를 빼고 간신히 까먹고 남은, 맘 놓고 신규 기능 땜질 배포 액셀 킥을 지를 수 있는 잉여 쉴드 쿠션 마일리지 여유 잔고 통장 팩트 분량.

</details>

- 정의/개념: SLO 허용 실패량에서 실제 실패를 뺀 **오류 예산**
- 배경/필요성: 팀별 감만으로는 **배포·안정화 우선순위 합의 불가**

#### 한줄 요약

- 허용 실패량과 실제 실패량의 **잔여 예산 산출**

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **예산 소진율(Burn Rate, 쿼터 잔고 통장 파산 까먹기 소비 스파이크 스퀴즈 속도 궤적)**: 오류 면책 쉴드 예산 마일리지 잔고 캡이, 전체 캘린더 측정 창 바운더리 기간에 균등 스무스하게 배분 까먹는 정상적 기준 속도보다 도대체 몇 배나 미친 듯이 더 급격하고 빠르게 소비 증발 스퀴즈 되어버리는지 팩트 적발해 내는 엑셀 스파이크 계산 궤적 수치.
- **이동 측정 창(Rolling Time Window, 뱀 꼬리 갱신 누적 캘린더 박스 스코프 팩트 감시 창)**: "1일부터 30일까지" 같은 고정된 야매 엑셀 핑계를 버리고, 어제 팩트는 버리고 오늘 팩트를 새로 밀어 넣으며 항상 오늘 기준 "과거 30일 누적 합산"을 뱀처럼 징그럽게 스르륵 따라다니며 갱신 스크롤 스캔 감시하는 무결 팩트 측정 구역 박스 바운더리 존.
- **배포•안정화 판단(Rollout vs Stabilization Decision-Making, 팩트 기반 킥 배포 릴리즈 액셀과 수술 땜질 롤백 브레이크 스위칭 저울질 통제 의사결정 전략)**: 마일리지 캡 잔여 예산 통장 빵꾸 여부와 빛의 속도 팩트 파산 까먹기 소진율 번레이트 속도 궤적 적발 결과에 락(Lock) 기계 의존하여, 당장 신규 기능 변경 배포 킥을 액셀 밟아 진행 패스할지 아니면 올스톱 중지 때리고 롤백 시스템 수술 신뢰성 땜질 쉴드 안정화 개선 긴급 턴 스위칭 복구를 최우선 순위로 칼같이 엑셀 정렬 변경 전환할지 정하는 피도 눈물도 없는 기계적 통제 결단 판정.

</details>

![가용성 SLO가 높아질수록 감소하는 월간 오류 예산](/study/diagrams/slo-error-budget.svg)

> 30일 기준 99.9% SLO는 약 43.2분 중단을 허용한다.

- **SLO**의 $1-SLO$로 허용 실패량 산출
- 잔여 예산으로 **배포·안정화 판단**
- 단기·장기 창에서 **예산 소진율** 감시
- **이동 측정 창** 결과로 배포 관문 통제

#### 한줄 요약

- 예산 여유 시 배포, 소진 시 **안정화 전환**

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **SLI(Service Level Indicator, 유저 돈벌이 관문 프론트 체감 품질 렌더링 503 생존 팩트 투명 측정값 센서 마커)**: 시스템 내부 CPU 핑계가 아니라, 실제 퓨어 발주사 리얼 유저 화면 클릭 관문 요청 궤적의 성공 합격 방어 생존 퀄리티를 1초 단위 투명 덤프 적발해 낸 팩트 측정값 데이터 지표.
- **허용 실패량(Error Budget Cap, 합법 면책 방어 쉴드 최대 예산 쿼터 마일리지 캡 리미트 수량)**: 캘린더 모수 전체 유효 트래픽 이벤트 덤프 덩어리 중, 사내 타겟 마지노선 SLO 목표가 뻗어도 위약금 안 내고 용서 쉴드 쳐준다고 엑셀로 정해둔 합법적 최대 에러 마비 타임아웃 이벤트 패킷 개수 혹은 블랙아웃 타임 캡 한도 마지노선.
- **실제 실패량(Empirical Failure Telemetry, 센서 적발 퓨어 팩트 503 에러 뻗음 마비 붕괴 마이너스 덤프 카운트 누적량)**: 스코프 측정 캘린더 창에서 SLI 팩트 투명 센서가 합격 잣대 200 OK 렌더링 성공 조건을 뚫지 충족 방어해 내지 못하고 기어코 500 에러를 뿜으며 뻗어버렸다고 실시간 적발 사살 카운트 덤프 뜬 실패 펑크 타임아웃 이벤트 패킷 팩트 발생 누적 총합 개수.

</details>

```text
오류 예산 관리 체계
├─ SLI•좋은 사건
├─ SLO•측정 창
├─ 허용•실제•잔여 예산
├─ 단기•장기 소진율
└─ 배포•안정화 관문
```

선의 의미: SLI 측정에서 배포 관문까지의 정적 관계이다.

| 구성요소 | 책임 |
|:---|:---|
| SLI•좋은 사건 | **SLI** 분자·분모 정의 |
| SLO•측정 창 | **SLO** 목표·평가 기간 설정 |
| 허용•실제•잔여 예산 | **허용 실패량**에서 **실제 실패량** 차감 |
| 단기•장기 소진율 | 급성 폭증·만성 누수 탐지 |
| 배포•안정화 관문 | 예산 기준 변경 승인·제한 |

#### 한줄 요약

- SLI·SLO에서 **예산·배포 관문까지 연결**

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>
- **다중 창 경보(Multi-Window Alerting, 단기 급성 장애 폭발과 장기 만성 누수 붕괴 투트랙 듀얼 스캔 스위칭 감시 경보망 방식)**: 5분, 1시간짜리 타임라인 짧은 단기 스코프 캘린더 창의 파산 까먹기 소진율과 30일짜리 타임라인 롱 텀 긴 캘린더 스코프 창의 찔끔찔끔 느린 소진율 팩트 스파이크 덤프를 듀얼 투트랙으로 동시에 대조 비교 스캔 렌더링 째려보아, 새벽에 갑자기 미친 듯 터지는 503 에러 급성 대형 뻗음 장애 폭발 참사와 며칠 내내 서서히 피 말리게 뻗어 누수 되는 만성 장애 붕괴 리스크를 칼같이 분리 식별 구분 탐지해 내는 입체적 듀얼 경보망 체계 방식.
- **배포 관문(Release Rollout Gate, 팩트 통장 점수 기반 액셀 통과 승인 및 브레이크 컷오프 제한 올스톱 락 스위치 관문 통제소)**: 센서가 적발한 오류 면책 쉴드 캡 잔여 통장 예산 빵꾸 여부와 파산 까먹기 번레이트 소진율 궤적 스파이크 조건 팩트 덤프 점수에 기계적으로 종속 락(Lock) 의존하여, 신규 펌핑 코드 패치 배포 킥 릴리즈를 무사통과 승인 엑셀 패스할지, 혹은 스위칭 락 걸고 브레이크 제한 중지 올스톱 스톱 컷오프 때릴지 피도 눈물도 없이 기계 심판 통제하는 최종 배포 스위치 장벽 통제 롤 컷오프소.
- **SLI•SLO•측정 창 정의(Telemetry Sentinel & Target Baseline Scope Setup Phase, 센서 품질 타임라인 캘린더 계산 분자•분모•타겟 목표•평가 룰 기간 컷오프 사전 정립 픽스 1단계)**: 야매 계산 꼼수를 짓밟기 위해 무결점 품질 계산 엑셀 나눗셈 식의 분자 챔피언 덤프•분모 유효 모수•내부 방어 타겟 마지노선 컷오프 목표 잣대•뱀 꼬리 갱신 누적 평가 스코프 캘린더 룰 기간 컷오프를 칼같이 사전 정립 밀봉 동결 픽스 세팅하는 마일스톤 설계 체계화 1단계.
- **허용•실제 실패량 계산(Error Budget Cap vs Real Failure Fact Computation Phase, 목표 합법 쉴드 허용 캡 에러 수량과 센서 적발 실제 뻗음 발생 마비 수량 팩트 수학 집계 동기화 연산 2단계)**: 사내 SLO 타겟 목표가 합법적으로 면책 허용한 캡 실패 쿼터량과 센서가 팩트 덤프 적발한 503 에러 실제 뻗음 붕괴 실패 발생 카운트량을 완벽히 같은 수학 단위로 치환 집계 합산 덤프 렌더링하는 기계적 팩트 도출 집계 연산 2단계.
- **잔여 예산•소진율 산출(Remaining Budget Balance & Burn Rate Squeeze Math Execution Phase, 통장 빵꾸 남은 실패 마일리지 여유분과 타임라인 대비 소비 파산 스파이크 번레이트 속도 팩트 엑셀 수학 펌핑 계산 산출 3단계)**: 마일리지 캡 오류 예산 통장 빵꾸 여부와 타임라인 캘린더 구간 대비 미친 듯 까먹는 파산 소비 번레이트 스파이크 스퀴즈 속도 궤적을 팩트 데이터로 무자비 수학 계산 스텝 연산 타격 3단계.
- **다중 창 경보•정책 판정(Dual Multi-Window Alerting & Policy Adjudication Phase, 짧은 창 단기 폭발 덤프와 긴 창 장기 만성 붕괴 경보 팩트를 투트랙 믹스 결합해 냉혹 운영 정책 룰 스위칭 선택 적발 심판 판독 4단계)**: 단기•장기 듀얼 스캐너 경보를 투트랙 병합 크로스체크 결합해 예산 통장 빵꾸 속도를 적발 사살하고, 이에 맞는 신규 배포 킥 스위치 롤아웃 운영 액션 룰 정책을 칼같이 선택 판정 스위칭 픽스하는 판독 결단 4단계.
- **배포•안정화•예외 결정(Rollout Release, Stabilization & Bypass Exception Decision Phase, 예산 빵꾸 통장 상태 팩트 스코어에 종속 락 의존한 변경 릴리즈 엑셀 진행 통과•롤백 수술 스톱 안정화 스위치 턴•C 레벨 책임자 서명 예외 배포 킥 스위칭 승인 최종 결단 스텝 5단계)**: 적발된 예산 통장 빵꾸 상태 팩트 점수에 따라 즉각적인 신규 패치 변경 진행 엑셀 스피드 킥, 롤백 긴급 수술 땜질 스톱 안정화 방어 모드 턴 스위칭, 혹은 천재지변 시 CEO 책임자 피 서명 예외 킥 강제 진행을 피 튀기게 결정 선택 스위칭하는 최종 SRE 5단계.

</details>


### 동작 원리

1. **SLI·SLO·측정 창 정의**: 산식·목표·기간 설정
2. **허용·실제 실패량 계산**: 동일 단위로 집계
3. **잔여 예산·소진율 산출**: 잔량·번레이트 계산
4. **다중 창 경보·정책 판정**: 급성·만성 위험 구분
5. **배포·안정화·예외 결정**: 변경 정책 선택

#### 한줄 요약

- 예산 소진 시 **배포 제한·안정화 우선**

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **잔여 예산 충분(Budget Green Status, 쉴드 면책 쿼터 통장 마일리지 빵빵 넉넉 안심 상태)**: 센서가 적발한 실제 뻗음 에러 실패 덤프 카운트가 사내 타겟 SLO 허용 캡 쿼터량 마지노선보다 아주 널널하게 충분히 적어 빵꾸 나지 않고, 맘 놓고 엑셀 신규 펌핑 패치 기능 변경 개발 배포와 엉뚱한 기술 모험 실험 킥을 맘 놓고 질러 계속 진행 가동할 수 있는 가장 평화로운 천국 그린 라이트 빵빵 여유 상태.
- **예산 소진 가속(Budget Yellow Burn Rate Accelerated Spike, 마일리지 까먹기 파산 스파이크 급발진 폭주 번레이트 옐로우 카드 타임아웃 임박 경고 상태)**: 503 에러 뻗음 실패 팩트 카운트 발생률이 정상적인 균등 소진 기준 캘린더 궤적 속도 스텝보다 미친 듯이 스파이크 폭주하며 더 빨리 스퀴즈 증발 늘어나, 이대로 방치하면 며칠 내로 SLO 쉴드 방어 마지노선 타겟 위반 빵꾸 미달 미끄러짐 붕괴 파산이 눈앞에 턱밑까지 임박해버린 아슬아슬 위험한 옐로우 카드 가속 경보 경고 상태.
- **예산 전량 소진(Budget Red Bankruptcy Depleted, 쉴드 캡 통장 완전 깡통 파산 소진 적자 붕괴 레드 카드 사살 올스톱 상태)**: 미친 뻗음 대형 셧다운 마비 장애 발생 탓에 센서가 적발한 실제 에러 덤프 실패량이 SLO 타겟이 허용한 1년 치 합법 쉴드 캡 허용 실패량 쿼터 마일리지를 이미 다 까먹어 소진 깡그리 모두 사용하여 바닥 파산 적자 빵꾸 난 사태로, 배포는 당장 즉시 전면 락 올스톱 스톱이고 땜질 인프라 복원 긴급 안정화 수술 개선이 무조건 최우선 생명줄로 강제 스위치 턴 되는 최악의 파산 붕괴 레드 카드 사살 고갈 상태.

</details>

| 구분 | 여유(Green) | 경고(Yellow) | 고갈(Red) |
|:---|:---|:---|:---|
| 기준 | **잔여 예산 충분** | **예산 소진 가속** | **예산 전량 소진** |
| 운영 | 변경 배포 진행 | 배포 속도 제한 | 배포 중단·안정화 |
| 위험 | 과도한 변경 증가 | 안정화 전환 지연 | 신규 기능 장기 지연 |

#### 한줄 요약

- Green 배포, Yellow 제한, **Red 안정화 전환**

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **CI/CD(Continuous Integration/Continuous Delivery, 개발자 코드 통짜 릴리즈 무결점 자동 융합 통합•시험 테스트 덤프•배포 패치 킥 파이프라인 자동화 체계 스위치 머신망)**: 개발자가 짠 더러운 코드를 깃허브에 밀어 넣자마자, 서버에 뻗음 붕괴 버그가 없는지 무결점 팩트 테스트 센서 덤프를 자동으로 융합 시험 검증하고 이상 없으면 실시간 라이브 서버 릴리즈에 자동 스퀴즈 배포 패치 킥을 때려 박는 인간 배제 오토메이션 무적 통제 체계 파이프라인 스위치망.
- **오류 예산 정책(Error Budget Burn Rate Strategy Policy, 마일리지 캡 예산 잔고 통장 빵꾸 파산 번레이트 궤적 팩트 적발 기반 액셀 브레이크 신규 배포 릴리즈 킥•실험 모험•땜질 롤백 안정화 우선순위 스위치 정렬 룰 픽스 운영 규칙 가이드 통제 바이블)**: 아슬아슬 남아있는 합법 면책 잔여 캡 예산 잔고 통장량과 파산 까먹기 궤적 스퀴즈 소진율 스파이크 팩트에 피도 눈물 없이 락(Lock) 기계 의존하여, 당장 신규 기능 개발 킥 릴리즈 배포를 뚫을지 엉뚱한 테스트 실험 모험을 지를지 아니면 올스톱 락 스위칭 땜질 방어 안정화 롤백 복구를 최우선 순위로 칼같이 엑셀 스위치 정렬 턴 변경할지 강제 픽스 정해둔 피투성이 살벌한 기계적 스탠스 운영 통제 규칙 가이드 바이블 룰.
- **잘못된 SLI(Corrupted Telemetry SLI Sentinel, 야매 핑계 조작 꼼수 왜곡 편향 측정 지표 덤프 센서 마커)**: 진짜 발주사 유저 돈벌이 결제 클릭 화면 체감 피해 타임아웃 뻗음 마비와는 1도 상관없는, 지들 편한 백엔드 서버 깡통 CPU 널널한 사용률 같은 엉뚱한 쓰레기 허수 신호만 야매로 계측 측정하여 엑셀 오류 예산 마일리지 쉴드 잔고 캡 파산 통장 까먹기 빵꾸 소진 판독 심판을 새빨간 거짓 사기로 왜곡 조작 농단 기만해버리는 최악의 편향 결함 어처구니없는 쓰레기 지표 센서 마커.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **잘못된 SLI**로 예산 왜곡 | 여정별 **SLI** 적용 | 판정 정확도 향상 |
| 단일 창의 경보 지연 | 단기·장기 창 병행 | 급성·만성 장애 조기 탐지 |
| 예산 고갈 시 사업 경직 | **오류 예산 정책**·예외 승인 | **CI/CD** 유연성 확보 |

#### 한줄 요약

- 단기·장기 창으로 **급성·만성 장애 조기 탐지**

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **신뢰성 투자(Reliability Investment Effort, 땜질 수술 안정화 인프라 방어 펌핑 복구 스위칭 스탠스 올인 전면 턴 투입 타격 액션 작업)**: 쉴드 캡 통장 쿼터 오류 마일리지 예산이 바닥 파산 나 빵꾸 적자가 나 턱밑까지 부족할 위기 때, 신규 달러 돈벌이 비즈니스 기능 코드 배포 킥 개발 스피드를 전면 락 스톱 컷오프 때리고 잠정 중단 멈춘 뒤, 모든 데브옵스 엔지니어 기동조 병력을 뻗음 마비 503 에러 장애 원인 근본 메스 제거 수술 땜질•오토 스케일링 복구 자동 롤백 스크립트 복원 장착 튜닝 방어 펌핑•투명 센서 계측 옵저버빌리티(관측성) 감시망 렌더링 개선 픽스 수술에 최우선적으로 몰빵 올인 스위치 턴 집중 투입하는 긴급 쉴드 방어 살리기 구조 작업 턴 액션.
- **운영 정책 선택(Rollout Release vs Reliability Rollback Switching Policy Decision-Making, 예산 잔고 통장 팩트 기반 액셀 브레이크 킥 스위칭 결단 타결 결정 통제 엑셀 의사결정 전략 액션)**: 쉴드 면책 쿼터 통장 예산 마일리지 잔고 캡 여유가 빵빵히 넉넉히 그린 라이트로 남아 돌 때는 안심하고 CI/CD 파이프라인 머신을 돌려 엑셀 밟아 신규 코드 릴리즈 킥 자동 통과 배포를 무사 패스 진행하고, 급성 스파이크 파산 번레이트 소진 빵꾸로 레드 카드 적자 고갈이 터지면 즉각 피도 눈물 없이 변경 릴리즈 배포 액셀을 기계 락 스톱 컷오프 중지시켜 땜질 긴급 롤백 수술 방어 안정화 스탠스 턴으로 스위칭 턴하며, 천재지변 같은 비상상황 예외 킥은 CEO C 레벨 책임자 서명으로만 패스 예외 승인 뚫어주도록 룰 정책 밸브를 설계 타결 결정하는 피도 눈물도 없는 기계적 팩트 기반 양극단 스위치 밸런싱 최후 결단 의사결정 전략 통제 룰.

</details>

- 예산 여유 시 배포, 고갈 시 **신뢰성 투자 전환**
