## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **결함 허용 시스템(Fault-Tolerant System, FTS)**: 일부 구성요소가 고장 나도 올바른 서비스를 계속 제공하는 시스템.
- **결함 마스킹(Fault Masking)**: 결함 출력을 외부에 드러내지 않고 정상 결과를 제공하는 기법.

</details>

- 정의/개념: 중복 실행과 표결로 구성요소 결함을 가리는 **연속 가용성 시스템**
- 배경/필요성: 장애 후 전환 방식으로는 안전 제어의 **연속 출력** 보장 불가

#### 한줄 요약
- 여러 구성요소가 같은 일을 수행해 하나가 고장 나도 정상 결과를 계속 제공한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **락스텝(Lockstep)**: 복수 처리기가 같은 클록과 입력으로 동일 연산을 수행하는 실행 방식.
- **삼중 모듈 중복(Triple Modular Redundancy, TMR)**: 세 모듈의 출력 중 다수 값을 채택하는 중복 구조.
- **핫스왑(Hot Swap)**: 시스템 전원을 유지한 채 고장 모듈을 교체하는 방식.

</details>

- 동일 입력을 동시 실행하는 **락스텝** 기반 오류 검출
- 단일 모듈 오출력을 숨기는 **TMR** 다수결
- 서비스 중단 없이 중복성을 복원하는 **핫스왑**

#### 한줄 요약
- 같은 연산을 여러 모듈이 수행하고 다수 결과를 채택해 단일 고장을 숨긴다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **다수결 표결기(Majority Voter)**: TMR 출력 중 둘 이상이 일치하는 값을 선택하는 회로.
- **결함 격리(Fault Containment)**: 고장 모듈의 오류가 다른 영역으로 퍼지지 않게 분리하는 조치.

</details>

```text
[결함 허용 시스템]
|
+-- [입력 분배기]
|
+-- [TMR 실행 계층]
|   +-- [모듈 A]
|   +-- [모듈 B]
|   `-- [모듈 C]
|
+-- [다수결 표결기]
|
`-- [진단·복구 제어기]
    `-- [핫스왑 슬롯]
```

선의 의미: 가지는 시스템 내부의 포함·소유 관계

| 구성요소 | 책임 |
|:---|:---|
| 입력 분배기 | 동일 입력의 **동기 분배** |
| TMR 실행 계층 | 독립 모듈의 **중복 연산** |
| 다수결 표결기 | 일치 출력 기반 **결함 마스킹** |
| 진단·복구 제어기 | 고장 모듈 **격리·재통합** |

#### 한줄 요약
- 입력 분배기와 세 실행 모듈, 표결기, 복구 제어기가 중복 연산과 교체를 분담한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **공통 원인 고장(Common Cause Failure, CCF)**: 공유 전원·설계 결함이 중복 모듈을 함께 고장 내는 현상.

</details>

```text
입력 분배기          TMR 모듈          표결·복구 제어기
    |                   |                    |
    |------------------>| 입력               |
    |                   | 1. 락스텝 실행     |
    |                   |------------------->|
    |                   | 2. 출력 표결       |
    |<---------------------------------------| 정상 결과
    |                   |<-------------------|
    |                   | 3. 결함 모듈 격리  |
    |                   |<-------------------|
    |                   | 4. 중복성 복원     |
```

**동작 원리**

1. **락스텝 실행**: 세 모듈이 같은 입력을 동시 처리
2. **출력 표결**: 둘 이상 일치하는 값을 정상 출력으로 선택
3. **결함 모듈 격리**: 불일치 모듈의 버스 접근 차단
4. **중복성 복원**: 교체 모듈에 정상 상태를 동기화

#### 한줄 요약
- 세 결과를 비교해 다수 값을 출력하고, 다른 결과를 낸 모듈은 격리·교체한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **고가용성(High Availability, HA)**: 장애 노드를 대기 노드로 전환해 중단 시간을 줄이는 구조.
- **복구 시간 목표(Recovery Time Objective, RTO)**: 장애 후 서비스 복구까지 허용하는 최대 시간.

</details>

| 가용성 구조 | FTS | HA |
|:---|:---|:---|
| 적용 기준 | 제어 출력의 연속성이 필수일 때 | 짧은 전환 중단을 허용할 때 |
| 핵심 특징 | **TMR** 기반 실시간 결함 마스킹 | **페일오버** 기반 서비스 복구 |
| 한계 | 전용 중복 하드웨어 비용 | **RTO** 동안 세션·처리 중단 |

#### 한줄 요약
- 출력 단절을 허용하지 않으면 FTS, 짧은 복구 시간을 허용하면 HA를 선택한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **N-버전 프로그래밍(N-Version Programming)**: 독립 구현한 여러 프로그램의 결과를 비교하는 소프트웨어 결함 허용 기법.
- **안전 무결성 수준(Safety Integrity Level, SIL)**: 안전 기능의 위험 저감 성능을 네 단계로 구분한 등급.
- **단일 장애점(Single Point of Failure, SPOF)**: 한 요소의 고장이 전체 서비스 중단으로 이어지는 지점.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 단일 표결기 고장으로 **SPOF** 발생 | 독립 **표결기 다중화** | 표결 경로의 단일 장애점 제거 |
| 동일 설계 결함으로 **CCF** 발생 | 이종 구현 기반 **N-버전 프로그래밍** | 공통 소프트웨어 결함 영향 축소 |
| 일반 서비스에 전용 중복 비용 과다 | 위험 분석과 **SIL** 기반 적용 범위 결정 | 안전 요구에 맞는 투자 집중 |

#### 한줄 요약
- 표결기와 구현 원인을 함께 분산하고 안전 위험이 큰 영역에만 비용을 집중한다.

## Ⅶ. 결론

- 출력 단절이 허용되지 않으면 **TMR 기반 FTS**, 전환 지연을 허용하면 **HA** 선택

#### 한줄 요약
- 연속 출력이 안전을 좌우하면 결함을 즉시 숨기고, 짧은 중단이 가능하면 대기 노드로 복구한다.
