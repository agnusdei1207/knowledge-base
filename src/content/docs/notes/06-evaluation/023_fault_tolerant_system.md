## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **고장 감내 시스템(Fault-Tolerant System, FTS)**: 부품 결함 발생 시에도 서비스 중단이나 성능 저하 없이 기능을 지속하는 시스템.
- **고장 감내(Fault Tolerance)**: 결함이 오류 및 시스템 실패로 전파되지 않도록 다중화하고 격리하는 설계 기법.
- **연속 가용성(Continuous Availability)**: 페일오버 지연 없이 다운타임 0을 목표로 하는 고신뢰성 아키텍처.

</details>

- 정의/개념: 시스템 내부 일부 부품에 결함이 발생하더라도 중단이나 성능 저하 없이 정상 서비스를 지속하는 결함 허용(Fault Tolerance) 시스템
- 배경/필요성: 미션 크리티컬 환경에서 단일 부품 장애가 **전체 시스템 실패 및 치명적 비즈니스 손실로 전파 방지**

#### 한줄 요약

- 중복 실행과 다수결로 **결함을 투명하게 마스킹**

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **무중단 복구(Zero Downtime)**: 장애 발생 시 세션 단절 없이 대기 부품이 연산을 즉각 인계하는 특성.
- **락스텝 프로세서(Lockstep Processor)**: 동일 명령어를 다수 CPU에서 동시 실행하고 출력을 비트 단위로 비교하는 구조.
- **공통 원인 고장(Common Cause Failure, CCF)**: 단일 원인으로 다수 부품이 동시 고장 나는 현상.

</details>

- 병렬 중복과 다수결 기반 **결함 마스킹**
- 진단·격리·재통합으로 중복성 회복
- 물리 독립성과 설계 다양성으로 **공통 원인 억제**

#### 한줄 요약

- 독립성·다양성·재통합을 갖춘 **중복 설계**

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **삼중 모듈 중복(Triple Modular Redundancy, TMR)**: 동일 연산 모듈 3개를 병렬 배치하고 표결기로 결과를 결정하는 구조.
- **다수결 표결기(Majority Voter)**: 3개 모듈의 출력 중 2개 이상의 일치 값을 정상 출력으로 선택하는 장치.
- **오류 정정 부호(ECC, Error-Correcting Code)**: 메모리 및 전송 과정의 단일 비트 오류를 실시간 수정하는 메커니즘.

</details>

```text
결함 허용 시스템 (TMR 기반 FTS 아키텍처)
├─ 입력 분배기: 동일 입력 신호를 3개 모듈로 병렬 분기
├─ 독립 실행 모듈: 모듈 A / 모듈 B / 모듈 C (락스텝 병렬 연산)
├─ 다수결 표결기(Voter): 2:1 다수결 판정 및 정상 결과 단일 출력
├─ 결함 진단·격리기: 오차 발생 모듈 식별 및 버스 신호 즉각 차단
└─ 온라인 복구·재통합: 핫스왑 부품 교체 후 상태 동기화 및 중복성 복원
```

선의 의미: 입력 분배부터 독립 실행, 다수결 표결, 결함 격리 및 온라인 재통합으로 이어지는 결함 허용 시스템 구조.

| 구성요소 | 책임 |
|:---|:---|
| 독립 중복 실행 모듈 | **삼중 모듈 중복** 병렬 실행 |
| 표결기·비교기 | **2:1 다수결** 기반 정상 출력 선택 |
| 진단·오류 검출 | **오류 정정 부호** 기반 비트 오류 보정 |
| 결함 격리 | 고장 모듈의 출력·상태 오염 차단 |
| 복구·재통합 | 수리 후 **중복성 수준 회복** |

#### 한줄 요약

- TMR 표결·격리·재통합으로 **무중단 출력 유지**

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **결함 감지(Fault Detection)**: 락스텝 비교기 및 패리티 검사로 부품 이상을 마이크로초 단위로 탐지하는 단계.
- **결함 격리(Fault Containment)**: 결함 부품을 즉각 비활성화하고 정상 모듈로 출력을 지속하는 단계.

</details>

```text
       입력 제어기
              │ 1. 동일 입력 복제•배포
              ▼
       중복 실행 모듈
              │ 2. 중복 모듈 독립 실행
              ▼
       표결기
              │ 3. 결과 비교•다수값 선택
              ▼
       진단기
              │ 4. 결함 위치 진단•격리
              ▼
       재통합 제어기
              │ 5. 복구•동기화•재통합
              ▼
                 중복성 회복
```

**동작 원리**

1. **동일 입력 복제·배포**: 모든 중복 모듈에 동일한 입력 데이터 전달
2. **중복 모듈 독립 실행**: 독립된 연산 유닛에서 동일 명령어를 락스텝 실행
3. **결과 비교·다수값 선택**: 표결기에서 2:1 다수결로 정상 출력 단일 결정
4. **결함 위치 진단·격리**: 이상 출력 모듈을 실시간 식별하여 시스템 버스에서 분리
5. **복구·동기화·재통합**: 부품 온라인 교체 및 메모리 동기화 후 중복성 정상 복원

#### 한줄 요약

- 다수값 출력 후 고장 모듈을 격리·**재통합**

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **결함 허용 시스템(FTS)**: 하드웨어 락스텝 동기화로 중단시간 0초를 달성하는 무중단 신뢰성 모델.
- **고가용성 시스템(HA)**: 클러스터링과 Failover로 수 초~수 분 내 복구하는 비용 효율적 가용성 모델.

</details>

| 구분 | 결함 허용 시스템 (Fault Tolerant) | 고가용성 시스템 (High Availability) |
|:---|:---|:---|
| 적용 기준 | 무중단이 필수적인 미션 크리티컬 업무 (금융, 항공) | 수 초~수 분의 짧은 전환 지연을 허용하는 업무 |
| 핵심 특징 | 하드웨어 락스텝 및 다수결 표결 기반 결함 마스킹 | 헬스체크 및 장애 감지 기반 Active-Standby Failover |
| 한계 | 고가의 전용 하드웨어 비용 및 설계 복잡도 | 장애 감지 및 전환 시 순간적인 세션 단절 발생 |

> 요약: 무중단 필수 환경에는 FTS를, 비용 효율적 서비스 지속성에는 HA를 선정.

#### 한줄 요약

- FT는 결함 마스킹, HA는 **감지 후 승계**

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **IEC 61508 / SIL**: 기능 안전 표준 및 안전 무결성 수준(Safety Integrity Level) 등급 체계.
- **진단 커버리지(Diagnostic Coverage)**: 전체 잠재 결함 중 시스템이 자체 감지할 수 있는 결함의 백분율.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 위험도와 무관한 중복 수준 | **IEC 61508·SIL** 기반 설계 | 위험도와 무결성 요구 정렬 |
| 낮은 결함 검출 범위 | 진단 커버리지 측정·개선 | 잠복 결함 탐지율 향상 |
| 표결기 SPOF | 표결기 N+1·독립 전원 | 단일 장애점 제거 |
| 공통 원인 고장 | 설계 다양성·물리적 격리 | 동시 실패 가능성 감소 |

#### 한줄 요약

- 진단 커버리지와 독립성으로 **안전 출력 보장**

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **신뢰성 설계 최적화**: 업무 중단 비용과 인프라 구축 비용을 고려하여 최적의 결함 감내 수준을 결정하는 전략.

</details>

- 업무 위험도 및 다운타임 허용치에 따른 **FTS와 HA의 차등 적용 및 검증**

#### 한줄 요약

- 안전·중단 허용도에 따라 **FT와 HA 차등 적용**
