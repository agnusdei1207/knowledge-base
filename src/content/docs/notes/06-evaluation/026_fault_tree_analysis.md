## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **결함 나무 분석(Fault Tree Analysis, FTA)**: 정상 사상에서 원인 조합을 하향 전개하는 연역적 위험 분석 기법.
- **정상 사상(Top Event)**: 분석 대상으로 정한 시스템 수준의 바람직하지 않은 최종 사건.

</details>

- 정의/개념: 정상 사상의 원인 조합을 논리 트리로 역추적하는 **연역 분석 기법**
- 배경/필요성: 부품별 점검만으로는 복합 결함의 **정상 사상 경로** 식별 불가

#### 한줄 요약
- 먼저 피하고 싶은 사고를 정하고 그 사고를 만드는 원인 조합을 거꾸로 찾는다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **최소 컷셋(Minimal Cut Set, MCS)**: 정상 사상을 일으키는 데 필요한 최소 기본 사상 조합.
- **최소 패스셋(Minimal Path Set, MPS)**: 모두 정상일 때 시스템 성공을 보장하는 최소 사상 조합.

</details>

- 결과에서 원인으로 분해하는 **하향식 연역 분석**
- 복합 고장 경로를 압축하는 **최소 컷셋** 도출
- 컷셋과 기본 사상 확률을 결합한 **정량 위험 분석**

#### 한줄 요약
- 사고 원인을 논리식으로 줄여 가장 적은 고장 조합과 그 발생 가능성을 찾는다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **기본 사상(Basic Event)**: 더 분해하지 않고 고장 자료를 직접 부여하는 최하위 사건.
- **중간 사상(Intermediate Event)**: 하위 사건의 논리 조합으로 발생하는 파생 사건.
- **AND 게이트(AND Gate)**: 모든 입력 사건이 발생할 때 출력 사건을 만드는 논리 게이트.
- **OR 게이트(OR Gate)**: 하나 이상의 입력 사건이 발생할 때 출력 사건을 만드는 논리 게이트.

</details>

```text
[정상 사상 T]
      |
    [OR]
   /    \
[중간 A] [중간 B]
   |        |
 [AND]    [AND]
 /  \      /  \
E1  E2    E3  E4

T = (E1 AND E2) OR (E3 AND E4)
```

선의 의미: 가지는 상위 사건과 원인 사건의 논리 포함 관계

| 구성요소 | 책임 |
|:---|:---|
| 정상 사상 | 분석할 최종 **위험 결과** 정의 |
| 논리 게이트 | 원인 사건의 **발생 조건** 결합 |
| 중간 사상 | 하위 원인의 **논리 결과** 표현 |
| 기본 사상 | 고장률을 부여할 **최하위 원인** 제공 |

#### 한줄 요약
- 정상 사상 아래에 논리 게이트와 중간·기본 사상을 배치해 사고 원인의 포함 관계를 나타낸다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **MOCUS(Method for Obtaining Cut Sets)**: AND·OR 게이트를 전개해 컷셋을 구하는 알고리즘.
- **중요도(Importance Measure)**: 기본 사상이나 컷셋이 정상 사상 확률에 기여하는 정도.

</details>

```text
[시스템 경계·정상 사상]
          |
          v
1. 원인 트리 전개
          |
          v
2. 논리식 변환
          |
          v
3. 최소 컷셋 도출
          |
          v
4. 위험도 산정
          |
          v
5. 취약 경로 개선
```

**동작 원리**

1. **원인 트리 전개**: 정상 사상을 하위 고장 조건으로 분해
2. **논리식 변환**: 게이트 관계를 불 대수식으로 표현
3. **최소 컷셋 도출**: 흡수 법칙으로 중복 조합 제거
4. **위험도 산정**: 기본 사상 확률과 중요도 계산
5. **취약 경로 개선**: 고위험 컷셋부터 격리·중복 설계

#### 한줄 요약
- 사고 원인을 논리식으로 바꾸고 최소 조합별 위험 기여도를 계산해 우선 개선한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **고장 모드 및 영향 분석(Failure Mode and Effects Analysis, FMEA)**: 구성요소 고장 모드에서 시스템 영향을 상향 추적하는 분석 기법.

</details>

| 신뢰성 분석 | FTA | FMEA |
|:---|:---|:---|
| 적용 기준 | 특정 사고의 복합 원인 분석 | 구성요소별 영향 선제 검토 |
| 핵심 특징 | 정상 사상부터 **하향식 연역** | 고장 모드부터 **상향식 귀납** |
| 한계 | 정상 사상 밖의 위험 누락 | 복합 고장 조합 분석 제약 |

#### 한줄 요약
- 특정 사고의 원인 조합은 FTA, 구성요소별 고장 영향은 FMEA로 분석한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **공통 원인 고장(Common Cause Failure, CCF)**: 공유 원인 하나가 여러 기본 사상을 함께 발생시키는 고장.
- **가지치기(Pruning)**: 분석 가치가 낮은 분기나 컷셋을 기준에 따라 제외하는 절차.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 기본 사상 독립 가정으로 **CCF** 과소평가 | 공유 원인 모델과 **의존성** 반영 | 정상 사상 확률 왜곡 완화 |
| 대규모 트리의 컷셋 조합 폭발 | 확률·차수 기준 **가지치기** | 핵심 위험 경로 분석 집중 |
| 직관적 개선으로 단일 컷셋 방치 | 크기 1의 **MCS** 우선 제거 | 단일 장애점 감소 |

#### 한줄 요약
- 공유 원인과 조합 폭발을 통제하고 가장 짧고 위험한 컷셋부터 제거한다.

## Ⅶ. 결론

- 정상 사상 확률 기여도가 큰 **최소 컷셋**부터 제거하고 **CCF**를 별도 통제

#### 한줄 요약
- 사고 가능성을 가장 크게 낮추는 원인 조합부터 개선하되 공유 원인을 따로 관리한다.
