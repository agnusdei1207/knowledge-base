## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **결함 나무 분석(FTA: Fault Tree Analysis / IEC 61025)**: 시스템에서 발생할 수 있는 최상위 치명적 사고(Top Event: 예 - 데이터센터 전면 블랙아웃, 결제 트랜잭션 전면 마비)를 먼저 정의하고, 이를 유발할 수 있는 하위 서브시스템의 결함과 인적 오류를 논리 게이트(AND, OR, Inhibit, Priority AND)를 통해 수목(Tree) 구조로 역추적하여, 최상위 고장을 발생시키는 기본 사상(Basic Event)들의 최소 조합인 최소 컷셋(MCS: Minimal Cut Set)과 시스템 고장 확률을 정량적으로 산출하는 하향식(Top-down) 연역적 신뢰성 분석 기법.
- **다중 결함 상호작용 간과 및 단일 원인 편향 결함(Single-Cause Bias Defect)**: 개별 단위 부품만을 점검하는 체크리스트 방식에 매몰되어, "A 서버 장애 AND B 스위치 펌웨어 버그 AND C 발전기 연료 밸브 고장"과 같이 2~3개 부품이 동시에 결합하여 발생하는 복합적 연쇄 붕괴 경로를 사전에 예측하지 못하는 구조적 결함.

</details>

- 정의/개념: 시스템 안전성과 무결점 신뢰성을 사전에 입증하기 위해 **최상위 치명 사상(Top Event) 정의 $\rightarrow$ 하향식 논리 게이트(AND/OR) 트리 전개 $\rightarrow$ 기본 사상(Basic Event) 고장률($\lambda$) 매핑 $\rightarrow$ 불 대수(Boolean Algebra) 기반 최소 컷셋(MCS) 도출 $\rightarrow$ 치명적 고장 경로 우선 차단** 을 집행하는 **연역적 시스템 신뢰성 엔지니어링 체계**
- 배경/필요성: 원자력, 항공우주, 금융 코어망, 자율주행과 같은 복합 고신뢰성 시스템에서 다중 컴포넌트의 결함 조합이 시스템 전체 실패로 전이되는 메커니즘을 수학적으로 규명하기 위해 IEC 61025 표준 FTA 필수화

#### 한줄 요약
- FTA는 최상위 치명 고장(Top Event)에서 출발하여 논리 게이트와 최소 컷셋(MCS)을 통해 고장 경로를 연역적으로 규명한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **FTA 3대 핵심 분석 개념**:
  - **정상 사상 (Top Event)**: 시스템 레벨에서 정의되는 가장 치명적인 고장 결과 (예: 무정전 전원 공급 상실).
  - **최소 컷셋 (MCS: Minimal Cut Set)**: 최상위 사상을 유발하기 위해 반드시 '동시에' 발생해야 하는 기본 사상들의 최소 집합 (취약점 경로).
  - **최소 패스셋 (MPS: Minimal Path Set)**: 이 집합의 모든 기본 사상이 정상 작동하면 최상위 사상이 절대 발생하지 않는 성공 보증 경로.

</details>

- **하향식 연역적(Top-down Deductive) 접근**: 결과(사고)를 먼저 정의하고 원인을 거꾸로 분해하므로, 시스템의 치명적 결함과 무관한 불필요한 부품 분석 오버헤드 0% 달성
- **정성적 및 정량적 분석의 완벽한 융합**: 불 대수 간소화를 통한 시스템 취약 경로(MCS) 식별(정성)과 기본 사상 고장 확률 결합을 통한 시스템 전체 발생 확률 $P(Top)$ 계산(정량)
- **단일 지점 컷셋(Single-order Cut Set)의 시각적 노출**: 1개의 기본 사상만으로 최상위 고장을 일으키는 OR 게이트 하위의 단일 장애점(SPOF)을 즉각 시각적으로 식별

#### 한줄 요약
- 하향식 연역 분석, 최소 컷셋(MCS) 도출, 정성/정량 분석 융합, 단일 장애점(SPOF) 시각적 색출을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **FTA 핵심 논리 게이트 및 기호 체계 (IEC 61025)**:
  1. **AND 게이트**: 모든 입력 사상이 동시에 발생할 때만 출력 사상 발생 ($P = \prod P_i$).
  2. **OR 게이트**: 입력 사상 중 하나라도 발생하면 즉시 출력 사상 발생 ($P = 1 - \prod(1-P_i)$).
  3. **기본 사상 (Basic Event, 원형 기호)**: 더 이상 분해되지 않는 단위 부품의 물리적 고장.
  4. **중간 사상 (Intermediate Event, 사각형 기호)**: 논리 게이트의 결합으로 발생하는 파생 고장.

</details>

```text
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 1. 결함 나무 분석 (FTA) 수목 논리 구조도 (Fault Tree Diagram) ]      │
│                                                                         │
│                    [ 정상 사상: 결제 서비스 전면 마비 (Top Event) ]     │
│                                       │                                 │
│                                   ┌───┴───┐                             │
│                                   │  OR   │ (어느 하나라도 발생 시 마비)│
│                                   └───┬───┘                             │
│                    ┌──────────────────┴──────────────────┐              │
│                    ▼                                     ▼              │
│        [ 중간 사상 1: WAS 풀 고갈 ]          [ 중간 사상 2: DB 접속 불가 ] │
│                    │                                     │              │
│                ┌───┴───┐                             ┌───┴───┐          │
│                │  AND  │ (모두 동시 발생 시)         │  AND  │          │
│                └───┬───┘                             └───┬───┘          │
│          ┌─────────┴─────────┐                 ┌─────────┴─────────┐    │
│          ▼                   ▼                 ▼                   ▼    │
│    (기본 사상 E1)      (기본 사상 E2)    (기본 사상 E3)      (기본 사상 E4)
│    [WAS A 메모리 OOM]  [WAS B CPU 포화]  [DB Master 다운]    [DB Standby 다운]
│                                                                         │
│   불 대수 식: $Top = (E_1 \land E_2) \lor (E_3 \land E_4)$              │
│   최소 컷셋 (MCS): $MCS_1 = \{E_1, E_2\}$, $MCS_2 = \{E_3, E_4\}$       │
└─────────────────────────────────────────────────────────────────────────┘
```

선의 의미: 최상위 결제 마비 사고를 유발하는 논리적 원인들을 OR/AND 게이트로 분해하여 최소 컷셋을 도출하는 구조

| FTA 구성 기호 | 명칭 및 의미 | 수학적 확률 공식 | 설계 의미 |
|:---|:---|:---|:---|
| **Top Event (직사각형)** | 시스템 수준의 최종 치명적 고장 사상 | $P(Top) = P(\bigcup MCS_i)$ | 분석 목표 |
| **AND Gate (둥근 문틀)**| 모든 입력 사상이 동시 발생해야 출력 | $P(Out) = P_1 \times P_2 \times \dots \times P_n$ | 이중화 (안전성 증대) |
| **OR Gate (뾰족한 화살)**| 1개 이상 입력 발생 시 즉시 출력 | $P(Out) = 1 - (1-P_1)(1-P_2)\dots(1-P_n)$ | 단일 장애 취약점 (SPOF) |
| **Basic Event (원형)** | 고장률($\lambda$) 데이터가 존재하는 최하단 원인 | $P_i = 1 - e^{-\lambda_i t}$ | 부품 물리 고장 |
| **최소 컷셋 (MCS)** | Top Event를 발생시키는 최소 기본사상 조합 | MOCUS / 불 대수 간소화 결과 | 우선 방어 대상 |

#### 한줄 요약
- 정상 사상(Top), AND/OR 논리 게이트, 기본 사상(Basic Event), 최소 컷셋(MCS) 공식으로 구성된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **FTA 수행 및 위험 차단 5단계 엔지니어링 프로세스**:
  1. 시스템 경계 및 치명적 최상위 사상(Top Event: "인터넷 뱅킹 이체 불가") 정의
  2. 시스템 P&ID 도면과 아키텍처를 기반으로 하위 고장 원인을 AND/OR 게이트로 트리 전개
  3. 불 대수 간소화(MOCUS 알고리즘)를 적용하여 최소 컷셋(MCS) 전수 도출
  4. 부품 신뢰성 데이터(MTBF)를 대입하여 각 컷셋별 발생 확률 및 Fussell-Vesely 중요도 산정
  5. 1차 단일 컷셋(SPOF) 및 중요도 1위 컷셋에 이중화 및 펜싱을 적용하여 고장 경로 차단

</details>

```text
1. [시스템 경계 및 Top Event 정의]
    ├─ 대상: 클라우드 기반 전자상거래 주문 체결 시스템
    └─ [Top Event 확정: "대고객 결제 트랜잭션 전면 중단 (Outage)"]
            │
            ▼
2. [결함 트리(Fault Tree) 하향 전개]
    ├─ 1계층: 네트워크 단절 OR 컴퓨팅 마비 OR DB 스토리지 파괴
    ├─ 2계층: 컴퓨팅 마비 ➔ [WAS 1번 서버 다운] AND [WAS 2번 서버 다운]
    └─ [3계층: DB 파괴 ➔ [SAN 스위치 단선] AND [스토리지 컨트롤러 고장]]
            │
            ▼
3. [불 대수 간소화 및 최소 컷셋 (MCS) 도출]
    ├─ 수목 불 대수 방정식: $T = (A \lor B) \land (C \lor D) = AC \lor AD \lor BC \lor BD$
    ├─ 흡수 법칙($A \lor AB = A$) 및 드모르간 법칙 적용
    └─ [도출된 2차 최소 컷셋: $MCS_1=\{A, C\}, MCS_2=\{A, D\}, MCS_3=\{B, C\}, MCS_4=\{B, D\}$]
            │
            ▼
4. [정량적 확률 연산 및 중요도 평가]
    ├─ 각 기본 사상 발생 확률 대입 ($P(A)=0.01, P(B)=0.01, P(C)=0.05, P(D)=0.05$)
    ├─ 시스템 전체 고장 확률: $P(Top) = 0.00119$ ($0.119\%$)
    └─ [Fussell-Vesely 중요도 분석 결과: 기본 사상 C, D의 기여도가 83%로 최상위 판명]
            │
            ▼
5. [아키텍처 개선 및 위험 경로 차단]
    ├─ 중요도 1위인 스토리지(C, D) 구간에 Multi-AZ 실시간 동기 복제(E) 추가
    ├─ 수정된 컷셋: $MCS_1 = \{A, C, E\}$ (3중 고장 발생 시에만 사고 유발)
    └─ [재계산 결과: 시스템 고장 확률이 $0.119\% \rightarrow 0.00005\%$로 2,000배 이상 급감]
```

**동작 원리**

1. **불 대수(Boolean Algebra) 간소화**: 복잡하게 얽힌 수백 개의 게이트를 논리곱(AND)과 논리합(OR)의 표준 정규형(SOP: Sum of Products)으로 환원하여 중복 원인을 완벽 제거
2. **MOCUS(Method for Obtaining Cut Sets) 알고리즘**: 트리의 최상단에서부터 아래로 내려가며 OR 게이트는 행(Row)을 확장하고, AND 게이트는 열(Column)을 확장하여 최소 컷셋 행렬을 자동 추출
3. **공통 원인 고장(CCF)의 명시적 포착**: 서로 다른 서브시스템에 동일한 기본 사상(예: 동일 전원 PDU $E_x$)이 포함되어 있을 경우, 불 대수 전개 시 단일 컷셋($\{E_x\}$)으로 즉각 환원되어 숨은 SPOF 노출
4. **Fussell-Vesely 중요도 척도**: 전체 시스템 고장 확률 중 특정 컷셋이 기여하는 비율을 수학적으로 산출하여 가장 가성비 높은 개선 투자처 특정
5. **독립성 검증**: 기본 사상 간의 상호 독립성 가정이 깨지지 않도록 물리적 격리 및 소프트웨어 다양성(Diversity) 검증 수반

#### 한줄 요약
- Top Event 정의, 수목 트리 전개, MOCUS 불 대수 간소화, MCS 확률 연산, 취약 컷셋 차단 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **신뢰성 분석 2대 대표 방법론 비교**:
  - FTA (Fault Tree Analysis): 하향식 연역 분석 (사고 $\rightarrow$ 복합 원인 조합).
  - FMEA (Failure Mode and Effects Analysis): 상향식 귀납 분석 (부품 고장 $\rightarrow$ 시스템 영향).

</details>

| 비교 항목 | 결함 나무 분석 (FTA) | 고장 모드 및 영향 분석 (FMEA) |
|:---|:---|:---|
| **분석 접근 방향** | **하향식 연역 분석 (Top-down Deductive)**| **상향식 귀납 분석 (Bottom-up Inductive)**|
| **출발점** | **최상위 치명 사고 (Top Event)** | **단위 부품의 고장 모드 (Failure Mode)** |
| **복합 다중 고장** | **완벽 분석 가능 (AND 게이트 결합)** | **분석 한계 (주로 단일 고장 모드 중심)** |
| **수학적 정량화** | **시스템 고장 확률, 최소 컷셋(MCS) 산출**| **RPN (위험우선순위 = 심각도×발생도×검출도)**|
| **핵심 적용 목적** | 대형 재난 방지 및 시스템 안전 아키텍처 검증| 초기 부품 설계 개선 및 제조 품질 보증 |
| **국제 표준** | **IEC 61025** | **IEC 60812** |

#### 한줄 요약
- FTA는 하향식 복합 원인 분석(IEC 61025), FMEA는 상향식 단일 부품 영향 분석(IEC 60812)에 특화된다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **FTA 실무 적용 시 3대 위험 요소와 엔지니어링 대책**:

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 각 기본 사상이 상호 독립적이라고 잘못 가정하여 **공통 전원선이나 공유 스위치의 단일 고장으로 인한 시스템 동시 중단 확률을 수백 배 과소평가** | **동일 전원/스위치를 사용하는 기본 사상들을 동일한 심볼($E_{common}$)로 트리에 대입하고 Beta-factor CCF 모델 결합** | 공통 원인 장애에 의한 사고 확률 왜곡 완벽 차단 |
| 수만 라인의 대규모 시스템에서 결함 트리를 무제한 전개하여 **트리 복잡도가 기하급수적으로 폭증하며 분석이 중단되는 조합 폭발 발생** | **IEC 61025 표준에 따라 분석 경계를 핵심 도메인으로 한정하고, 발생 확률 $10^{-8}$ 이하의 희귀 컷셋을 가지치기(Pruning) 수행** | 분석 생산성 극대화 및 핵심 위험 경로 집중 관리 |
| 최소 컷셋을 분석하지 않고 직관에 의해 백업 서버만 증설하여 **OR 게이트 하위에 존재하는 단일 인증 서버 결함(1차 단일 컷셋)을 방치** | **불 대수 간소화를 통해 크기가 1인 최소 컷셋(Single-order MCS = SPOF)을 전수 추출하여 우선순위 1순위로 다중화 격리** | 시스템 단일 장애점 100% 제거 및 안전성 보증 |

#### 한줄 요약
- CCF 모델로 독립성 왜곡을 막고, 가지치기로 조합 폭발을 방어하며, 1차 컷셋 추출로 SPOF를 제거한다.

## Ⅶ. 결론

- 복잡한 대규모 IT 인프라와 소프트웨어 시스템에서 대형 참사를 유발하는 잠재적 위험 경로를 수학적으로 규명하는 최고 수준의 신뢰성 공학 기법인 **결함 나무 분석(FTA) 체계**는 단순한 장애 사후 분석을 넘어 시스템 설계 단계에서 결함의 연쇄 전파를 원천 차단하는 핵심 방패이며, 실무 구현 시 **IEC 61025 표준 기반의 엄격한 논리 수목 전개**, **불 대수 간소화를 통한 최소 컷셋(MCS) 도출**, **공통 원인 고장(CCF)의 명시적 반영**, **단일 컷셋(SPOF)의 물리적 격리 및 다중 방어벽 구축**을 완성하여 최고 수준의 시스템 안전성과 무결점 신뢰성을 완성

#### 한줄 요약
- 하향식 논리 트리 전개와 최소 컷셋(MCS) 분석을 통해 복합 시스템 고장 경로를 완벽히 차단한다.
