## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **결함 수목 분석(Fault Tree Analysis, FTA)**: 시스템의 최상위 장애(Top Event)로부터 출발하여 그 원인이 되는 하위 부품 결함 및 사상을 연역적(Deductive)으로 전개하는 신뢰성 분석 기법.
- **정상 사상(Top Event)**: 시스템 전체 수준에서 정의되는 가장 치명적인 최종 고장이나 사고.
- **근본 원인 분석(Root Cause Analysis)**: 논리 게이트를 통해 복합 장애의 근본적 기본 사상(Basic Events)을 체계적으로 도출하는 분석 과정.

</details>

- 정의/개념: 최상위 사고의 원인 조합을 역추적하는 **결함수 분석**
- 배경/필요성: 단일 고장 목록으로는 **복합 원인 경로 식별 불가**

#### 한줄 요약

- 최상위 사건에서 **최소 원인 조합을 하향식 추적**

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **연역적 하향식 분석(Deductive Top-down Analysis)**: 결과(장애)로부터 시작하여 원인(부품 결함)을 추적하는 하향식 전개 방식.
- **불 대수 논리 게이트(Boolean Logic Gates)**: AND(동시 발생 시 고장)와 OR(단일 발생 시 고장) 게이트를 사용하여 복합 원인 관계를 정형화.
- **최소 컷셋(Minimal Cut Set, MCS)**: 정상 사상을 발생시키는 데 필요한 기본 사상들의 최소 조합으로 시스템의 취약 경로를 식별.
- **정량적 고장 확률(Quantitative Failure Probability)**: 하위 기본 사상의 고장률 데이터를 불 대수 연산으로 결합하여 정상 사상의 발생 확률을 수치화.

</details>

- 최상위 사건에서 원인을 분해하는 **하향식 분석**
- 최소 컷셋과 사고 확률의 **정성·정량 분석**
- 독립 가정을 보완하는 **공통 원인 반영**

#### 한줄 요약

- 독립 가정 대신 **공통 원인·조건부 확률 반영**

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **정상 사상(Top Event)**: 분석 대상이 되는 최상위 시스템 고장 상태(직사각형 기호).
- **논리 게이트(Logic Gates)**: 원인 사상들의 인과 관계를 결합하는 AND/OR/Vote 게이트 기호.
- **기본 사상(Basic Events)**: 더 이상 분해되지 않는 단위 부품의 독립적 고장 사상(원형 기호).
- **미개발 사상(Undeveloped Events)**: 추가 정보 부족이나 중요도가 낮아 더 이상 분석하지 않는 사상(마름모 기호).

</details>

```text
              [옥상 타겟 최상위 마비 파산 재앙 뻗음 사건•엑스레이 분석 커버리지 컷오프 경계]
                                       |
           [AND 100% 동시 폭발•OR 단 1방 폭파 뻥 뚫림 논리 게이트 관문 스위치 락]---[중간 뼈대 연쇄 파급 뻗음 팩트 사건]
                                       |                                                |
        [최하단 늪 기초 기본 사건•단일 공통원인 싹쓸이 폭탄]------[최소 컷셋 최단 붕괴 경로 급소 콤보 팩트•최종 파산 마비 수학 스코어 확률]
```

선의 의미: 최상위·중간·기본 사건과 논리 게이트 관계

| 구성요소 | 책임 |
|:---|:---|
| 최상위 사건·분석 경계 | **최상위 사건**과 분석 범위 정의 |
| AND·OR 논리 게이트 | **동시·대안 원인 조합** 표현 |
| 중간 사건 | 하위 원인이 만든 중간 상태 표현 |
| 기본 사건·공통 원인 | 최하위 원인과 의존성 식별 |
| 최소 컷셋·사고 확률 | **최소 원인 조합**과 발생 가능성 산출 |

#### 한줄 요약

- **최소 컷셋**의 한 사건 또는 연결을 제거해 사고 차단

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **정상 사상 정의(Top Event Definition)**: 분석할 핵심 고장 상태와 시스템 경계, 환경 조건을 명확히 설정하는 단계.
- **결함 트리 전개(Fault Tree Construction)**: AND/OR 게이트를 활용하여 정상 사상부터 기본 사상까지 논리적 수목 구조를 작성하는 단계.
- **정성 분석(Minimal Cut Set Derivation)**: 불 대수 간소화를 통해 시스템을 파괴하는 최소 컷셋(MCS)을 도출하는 단계.
- **정량 분석(Failure Probability Calculation)**: 기본 사상 발생 확률을 대입하여 전체 시스템의 고장 확률과 중요도를 계산하는 단계.

</details>

```text
       안전 분석가
              │ 1. 최상위 사건•경계 정의
              ▼
       시스템 설계팀
              │ 2. 기본 사건•논리 관계 분해
              ▼
       FTA 도구
              │ 3. 최소 컷셋 도출
              ▼
       확률 계산기
              │ 4. 확률•중요도•공통원인 평가
              ▼
       위험 책임자
              │ 5. 설계 통제•잔여위험 결정
              ▼
                통제 적용 또는 위험 수용
```

### 동작 원리

1. **최상위 사건•경계 정의**: 사고 상태와 분석 범위 확정
2. **기본 사건•논리 관계 분해**: 원인을 AND·OR로 구조화
3. **최소 컷셋 도출**: 사고를 만드는 최소 조합 계산
4. **확률•중요도•공통원인 평가**: 확률과 개선 우선순위 산출
5. **설계 통제•잔여위험 결정**: 경로 차단 후 위험 수용 판단

#### 한줄 요약

- 최소 컷셋과 중요도로 **우선 차단 경로 결정**

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **FTA(Fault Tree Analysis)**: 탑다운 연역적 분석으로 복합 원인과 결함 조합(AND/OR)을 분석하는 데 최적화된 기법.
- **FMEA(Failure Mode and Effects Analysis)**: 바텀업 귀납적 분석으로 개별 부품 단위 고장이 전체 시스템에 미치는 영향을 단일 분석하는 기법.

</details>

| 비교 기준 | **FTA** | **FMEA** |
|:---|:---|:---|
| 시작점 | 최상위 사고 | 개별 고장 모드 |
| 방향 | 원인 조합의 **하향식 연역 분석** | 영향의 **상향식 귀납 분석** |
| 한계 | 경계·독립 가정 오류 | 복합 원인 상호작용 누락 |

#### 한줄 요약

- FTA는 원인 조합, FMEA는 **개별 고장 영향 분석**

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **사상 독립성 가정(Event Independence Assumption)**: 기본 사상 간 독립성이 깨질 경우 확률 계산이 왜곡되므로 공통 원인 고장(CCF)을 별도 사상으로 분리 반영.
- **최소 패스셋(Minimal Path Set, MPS) 분석**: 시스템이 정상 동작을 유지하기 위해 반드시 생존해야 하는 최소 경로 집합을 도출하여 방어 설계에 활용.
- **시스템 복잡도 관리(Complexity Management)**: 대규모 시스템에서는 서브트리(Sub-tree) 모듈화 및 전산화 도구를 활용하여 트리 복잡성을 제어.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 분석자별 논리 표기 차이 | **IEC 61025** 표준 기호·절차 | 트리 해석 일관성 확보 |
| 사건 독립 가정 과신 | **공통 원인·조건부 확률** 반영 | 사고 확률 과소평가 방지 |
| 분석 경계의 무한 확장 | 경계 확정·검토 이력 관리 | 핵심 원인 집중과 추적성 확보 |

#### 한줄 요약

- 공통 원인을 반영해 **중요도 상위 최소 컷셋 차단**

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **안전 중심 신뢰성 설계(Safety-Critical Reliability Design)**: FTA 정성/정량 분석 결과를 바탕으로 단일 컷셋(Single Cut Set)을 제거하고 다중 방어 체계를 구축하는 아키텍처 설계 기법.

</details>

- 사고 확률 기여도가 큰 **최소 컷셋부터 설계 차단**

#### 한줄 요약

- 중요도 상위 최소 컷셋을 **물리·논리적으로 우선 차단**
