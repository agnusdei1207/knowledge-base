## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **매케이브 순환 복잡도(McCabe's Cyclomatic Complexity, $V(G)$)**: 제어 흐름 그래프의 선형 독립 경로 수를 나타내는 구조 복잡도 지표이다.
- **제어 흐름 그래프(Control Flow Graph, CFG)**: 프로그램의 기본 블록을 노드로, 블록 사이 실행 이동을 간선으로 표현한 그래프이다.
- **선형 독립 경로 수**: 이전 경로에 없던 간선을 하나 이상 포함하는 최소 기준 경로의 개수이다.

</details>

- 정의/개념: CFG의 간선•노드•연결 성분으로 **선형 독립 경로 수** 를 산출하는 제어 흐름 복잡도 지표
- 배경/필요성: 코드 길이로는 분기 증가에 따른 **시험 경로 누락 위험 판정 불가**

#### 한줄 요약
- 분기마다 새 실행 길이 생기므로 독립 경로 수만큼 기본 테스트를 준비한다.


## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **선형 독립 경로**: 이전에 선택한 경로들에 없던 간선을 하나 이상 포함하는 실행 경로이다.
- **결정점**: if•case•반복문처럼 실행 경로가 둘 이상으로 갈리는 지점이다.
- **인지 복잡도**: 사람이 중첩•분기된 코드 흐름을 이해하기 어려운 정도를 측정하는 별도 지표이다.
- **결정점 수+1**: 단일 연결 제어 흐름 그래프에서 순환 복잡도를 빠르게 계산하는 동등한 관계이다.

</details>

![결정점 수에 따라 증가하는 순환 복잡도와 독립 경로 수](/study/diagrams/cyclomatic-complexity-paths.svg)

> 단일 연결 제어 흐름 그래프를 가정한 파란 선은 결정점이 하나 늘 때마다 \(V(G)\)와 기본 독립 경로 수가 하나씩 증가하는 \(V(G)=결정점 수+1\) 관계를 나타낸다.

- 수식 **$V(G)=E-N+2P$** 적용으로 CFG의 선형 독립 경로 수 산출
- 단일 CFG에서 **결정점 수+1** 을 통한 동일 값 계산
- **제어 흐름 기반 측정** 을 통한 언어•코드 길이 독립적 경로 비교

#### 한줄 요약
- 조건문이 한 갈래를 더 만들면 확인할 기본 실행 경로도 하나 늘어난다.


## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **간선($E$)**: CFG에서 기본 블록 사이의 실행 이동을 나타내는 연결이다.
- **노드($N$)**: CFG에서 순차적으로 실행되는 기본 블록을 나타내는 정점이다.
- **연결 성분($P$)**: 서로 경로가 연결되지 않은 독립적인 제어 흐름 그래프의 수이다.
- **기본 블록**: 중간 분기 없이 진입부터 종료까지 순서대로 실행되는 명령어 묶음이다.
- **임계값 정책**: 복잡도 기준을 넘는 함수에 시험 보강•검토•리팩터링을 요구하는 품질 통제 규칙이다.

</details>

```text
순환 복잡도 분석 체계
├─ 분석 경계
├─ CFG
├─ 복잡도 산출
└─ 임계값 정책
```

선의 의미: 함수 경계와 제어 흐름을 독립 경로 수와 품질 통제에 연결한 정적 구조

| 구성요소 | 책임 |
|:---|:---|
| 분석 경계 | 함수•메서드 단위의 측정 범위와 **연결 성분** 구분 |
| CFG | 기본 블록과 제어 이동을 **노드•간선**으로 표현 |
| 복잡도 산출 | $E-N+2P$로 **선형 독립 경로 수** 계산 |
| 임계값 정책 | 기준 초과 함수를 **시험•리팩터링 대상**으로 지정 |

#### 한줄 요약
- 함수의 실행 지도를 그려 독립 경로 수를 계산하고 기준 초과 함수를 찾는다.


## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **기본 경로 테스트**: 순환 복잡도가 나타내는 선형 독립 경로마다 시험을 설계하여 제어 흐름을 확인하는 기법이다.
- **경로 집합**: CFG의 모든 가능한 반복 횟수를 열거하는 것이 아니라 독립 간선을 포함하도록 선정한 최소 기준 경로 모음이다.
- **리팩터링 우선순위**: 복잡도와 변경 빈도•결함 이력•업무 중요도를 함께 고려해 구조 개선 대상을 정하는 순서이다.

</details>

```text
정적분석도구
   │ 1. CFG•순환 복잡도 산출
   ▼
시험관리자
   │ 2. 기본 경로•리팩터링 우선순위 결정
   ▼
개발자
   │ 3. 독립 경로 시험•구조 개선
   ▼
시험관리자
   │ 4. 경로 충족•복잡도 감소 검증
```

**동작 원리**

1. **CFG•순환 복잡도 산출**: 제어 이동으로 **독립 경로 수** 계산
2. **기본 경로•리팩터링 우선순위 결정**: 임계값•결함 이력 반영
3. **독립 경로 시험•구조 개선**: 경로 시험과 복잡 함수 분리
4. **경로 충족•복잡도 감소 검증**: 시험 증거와 재산출값 확인

#### 한줄 요약

- 함수를 제어 흐름 그래프로 바꿔 독립 경로 수를 계산하고, 각 경로를 실제 시험 증거와 연결한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **순환 복잡도 적용**: 기본 경로 시험의 최소 기준 수를 산정하는 방식이다.
- **인지 복잡도 적용**: 코드 리뷰와 리팩터링 대상을 선정하는 방식이다.
- **중첩 깊이**: 조건문이나 반복문이 안쪽으로 겹쳐 들어간 최대 단계이다.
- **지표 선택**: 시험 경로 수는 순환 복잡도, 이해 난도는 인지 복잡도, 겹친 제어 단계는 중첩 깊이로 판단하는 구분이다.

</details>

| 복잡도 지표 | 순환 복잡도 | 인지 복잡도 | 중첩 깊이 |
|:---|:---|:---|:---|
| 적용 기준 | 기본 경로의 **시험 범위 산정** | 코드 리뷰•**리팩터링 우선순위** | 과도한 **제어문 중첩 제한** |
| 핵심 특징 | **선형 독립 경로 수** 측정 | 사람이 느끼는 **이해 난도** 측정 | 제어문이 겹친 **최대 단계** 측정 |
| 한계 | 데이터•호출 **의존성 미반영** | 도구별 **계산 규칙 상이** | 비중첩 **분기 수 미반영** |

> 요약: **경로 수•인지 난도•중첩 단계** 는 서로 다른 측정 대상

#### 한줄 요약
- 시험할 경로 수는 순환 복잡도, 읽기 어려움은 인지 복잡도, 겹친 단계는 중첩 깊이로 판단한다.


## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **리팩터링**: 외부 동작은 유지하면서 긴 함수•중첩•중복 분기를 분리하여 내부 구조를 개선하는 활동이다.
- **회귀 테스트**: 구조 변경 뒤 기존 기능이 그대로 동작하는지 다시 확인하는 시험이다.
- **형식적 분할 방지**: 복잡도 수치만 낮추려고 함수를 잘게 나눠 전체 결합도와 이해도를 악화시키지 않도록 함께 검토하는 조치이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 높은 복잡도 함수의 **독립 경로 누락** | 독립 경로별 **시험 케이스•실행 흔적** 연결 | 분기별 **기본 경로 검증** |
| 임계값 단독 적용에 따른 **우선순위 왜곡** | 변경 빈도•결함 이력•**업무 중요도** 병행 평가 | 위험 중심의 **리팩터링 선정** |
| 함수 분할에 따른 **전체 이해도 저하** | **인지 복잡도•결합도** 지표 병행 검토 | 수치 목적의 **형식적 분할 방지** |

#### 한줄 요약
- 결제 함수가 임계값을 넘으면 각 독립 경로에 시험 케이스와 실행 흔적을 연결해 분기 누락을 방지한다.


## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **경로 수와 테스트 수 관계**: $V(G)$는 기본 경로 시험의 최소 기준 수를 제시하지만 데이터 조합•반복 횟수까지 모두 보장하지는 않는다.
- **변경 위험 우선순위**: 복잡도뿐 아니라 변경 빈도•결함 이력•업무 중요도를 함께 보아 리팩터링 대상을 정하는 원칙이다.
- **시험•개선 결정**: 순환 복잡도만큼 기본 경로를 시험하고 변경과 결함이 잦은 고복잡도 함수를 먼저 리팩터링하는 판단이다.

</details>

- **순환 복잡도** 만큼 기본 경로를 시험하고 변경•결함이 잦은 함수는 **리팩터링 우선**

#### 한줄 요약
- 순환 복잡도는 코드 품질 점수가 아니라 빠뜨리지 말아야 할 기본 경로 수를 알려 주는 기준이다.
