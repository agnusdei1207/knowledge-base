## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **매케이브 순환 복잡도(McCabe's Cyclomatic Complexity, $V(G)$)**: 프로그램의 제어 흐름 그래프(CFG: Control Flow Graph) 상에서 선형적으로 독립적인 실행 경로(Linearly Independent Paths)의 개수를 측정하여, 소프트웨어 모듈의 논리적 복잡도(Complexity), 유지보수 난이도, 그리고 모든 기본 경로를 100% 검증하기 위해 요구되는 최소한의 화이트박스 단위 테스트 케이스 수를 정량화하는 구조적 코드 품질 지표.
- **제어 경로 폭증에 따른 스파게티 코드 및 회귀 결함(Control Explosion & Untestable Code Defect)**: 수십 개의 `if-else`, `switch-case`, `for/while` 반복문이 5단계 이상 깊게 중첩되어 프로그램의 실행 경로가 수천 개로 폭증함으로써, 개발자가 테스트 케이스를 설계할 수 없어 잠재 버그가 은폐되고 코드 수정 시마다 연쇄적인 회귀 장애(Regression Bug)가 발생하는 구조적 결함.

</details>

- 정의/개념: 소프트웨어의 복잡성을 객관적으로 통제하고 단위 테스트의 완전성을 수학적으로 보증하기 위해 **구문 분석(AST) $\rightarrow$ 제어 흐름 그래프(CFG) 생성 $\rightarrow$ 3대 산출 공식($V(G) = E - N + 2P = \pi + 1 = R$) 적용 $\rightarrow$ 기본 경로 집합(Basis Path Set) 도출 $\rightarrow$ $V(G) \le 10$ 유지보수 임계치 통제 및 리팩토링** 을 집행하는 **구조적 소스코드 품질 엔지니어링 체계**
- 배경/필요성: 단순 소스코드 라인 수(LOC)만으로는 로직의 복잡성과 결함 위험도를 판별할 수 없으므로, 그래프 이론에 기반하여 테스트 불가능한 고위험 함수를 사전에 식별하고 리팩토링하기 위한 정량 기준 필수

#### 한줄 요약
- 순환 복잡도 $V(G)$는 제어 흐름의 독립 경로 수를 산출하여 화이트박스 기본 경로 테스트 케이스 수와 리팩토링 기준을 제시한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **선형 독립 경로(Linearly Independent Path)**: 기존에 식별된 경로들에서는 한 번도 통과하지 않았던 새로운 간선(Edge)을 최소한 1개 이상 포함하는 고유한 실행 궤적 (다른 경로들의 선형 결합으로 표현 불가).
- **기본 경로 집합(Basis Path Set)**: 프로그램 내의 모든 실행 가능한 경로를 선형 결합으로 만들어낼 수 있는 최소한의 독립 경로들의 기저(Basis) 집합 (크기 $= V(G)$).

</details>

- **그래프 위상 수학 기반 정밀성**: 노드(기본 블록), 간선(제어 이동), 분기점의 수학적 관계를 통해 주관성을 완벽히 배제한 객관적 복잡도 산출
- **테스트 케이스 수의 절대적 하한선(Lower Bound)**: 기본 경로 테스팅(Basis Path Testing) 시 모든 분기와 구문을 최소 1회 이상 실행하기 위해 필요한 테스트 케이스의 개수는 정확히 $V(G)$개와 일치
- **유지보수성 및 결함 발생률과의 높은 상관성**: $V(G) > 20$인 함수는 결함 밀도가 지수적으로 증가하며, 수정 시 사이드 이펙트 발생 확률이 80%를 상회

#### 한줄 요약
- 그래프 위상수학 기반, 기본 경로 테스트 케이스 하한선 제시, $V(G) \le 10$ 품질 임계치 관리, 결함 밀도 예측을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **순환 복잡도 $V(G)$ 3대 산출 공식**:
  1. **간선과 노드 공식**: $V(G) = E - N + 2P$ ($E$: 간선 수, $N$: 노드 수, $P$: 연결 성분/함수 수, 단일 함수 $P=1$ 시 $V(G) = E - N + 2$).
  2. **조건 분기점(Predicate Node) 공식**: $V(G) = \pi + 1$ ($\pi$: 2방향 조건 분기점의 수).
  3. **평면 그래프 닫힌 영역(Region) 공식**: $V(G) = R$ ($R$: CFG 평면 분할 영역의 수 = 닫힌 영역 수 + 외부 영역 1개).

</details>

```text
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 1. 제어 흐름 그래프 (CFG: Control Flow Graph) 및 $V(G)$ 산출 구조 ]   │
│                                                                         │
│                    ( 노드 1: 진입 / `if (A > 0)` ) ──[영역 R1]───┐      │
│                     │ True                        False          │      │
│                     ▼                                            │      │
│     ( 노드 2: `if (B > 0)` ) ──[영역 R2]───┐                     │      │
│      │ True                 False          │                     │      │
│      ▼                                     ▼                     ▼      │
│  ( 노드 3: `Process_1()` )           ( 노드 4: `Process_2()` )          │
│      │                                     │                     │      │
│      └─────────────────┬───────────────────┘                     │      │
│                        ▼                                         │      │
│                 ( 노드 5: 병합 노드 ) ◄──────────────────────────┘      │
│                        │                                                │
│                        ▼                                                │
│                 ( 노드 6: 종료 / 반환 ) ─── [외부 영역 R3]               │
│                                                                         │
│  ├─ [공식 1] 노드 $N=6$, 간선 $E=7$, $P=1$ ➔ $V(G) = 7 - 6 + 2 = 3$     │
│  ├─ [공식 2] 분기점 $\pi=2$ (노드 1, 2) ➔ $V(G) = 2 + 1 = 3$            │
│  └─ [공식 3] 평면 영역 $R=3$ (R1, R2, R3) ➔ $V(G) = 3$                  │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │ (복잡도 위험 등급 판정)
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 2. 매케이브 순환 복잡도 위험 등급 및 엔지니어링 조치 기준표 ]          │
├───────────────────┬─────────────────────────┬───────────────────────────┤
│ 순환 복잡도 $V(G)$│ 구조적 상태 및 위험 수준│ 조치 사항 및 리팩토링 가이드│
├───────────────────┼─────────────────────────┼───────────────────────────┤
│ **1 ~ 10**        │ **[ 매우 안정적 (Low) ]**│ 우수한 구조, 단위 테스트 용이 (권장 기준)  │
│ **11 ~ 20**       │ **[ 보통 복잡 (Moderate)]**│ 리팩토링 권고, 추가 테스트 케이스 작성  │
│ **21 ~ 50**       │ **[ 고위험 (High Risk)]** │ 복잡하고 결함 위험 높음, 즉시 함수 분할 │
│ **> 50**          │ **[ 테스트 불가 (Extreme)]**│ 유지보수 및 테스트 불가능, 전면 재작성│
└───────────────────┴─────────────────────────┴───────────────────────────┘
```

선의 의미: CFG의 노드와 간선에서 3가지 공식으로 $V(G)=3$을 도출하고 위험 등급에 따라 리팩토링 여부를 결정하는 구조

| 복잡도 계산 요소 | 기호 및 정의 | 산출 시 주의사항 | 비고 |
|:---|:---|:---|:---|
| **기본 블록 노드 ($N$)** | 분기가 없는 순차 실행 코드 블록 | 연속된 배정문/호출문은 1개 노드로 병합 | Node |
| **제어 전이 간선 ($E$)** | 노드 간의 제어 흐름 이동선 | if-else, loop 점프, return 제어선 | Edge |
| **조건 분기점 ($\pi$)** | 2개 이상의 분기를 발생시키는 조건문 | 복합 조건(`A && B`)은 분기점 2개로 분해 | Predicate |
| **연결 성분 ($P$)** | 독립된 서브루틴/함수의 개수 | 단일 함수 분석 시 통상 $P=1$ 적용 | Component |
| **평면 영역 ($R$)** | 간선으로 둘러싸인 닫힌 면의 수 + 1 | 평면 그래프(Planar Graph) 변환 후 계수 | Region |

#### 한줄 요약
- 노드($N$), 간선($E$), 분기점($\pi$), 평면 영역($R$), 위험 등급표(1~10 안정, >50 재작성)로 구성된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **기본 경로 테스팅 및 복잡도 리팩토링 5단계 프로세스**:
  1. 정적 분석 도구(SonarQube, ESLint)를 통해 함수별 CFG 및 순환 복잡도 $V(G)$ 자동 계측
  2. 도출된 $V(G)$ 수치에 따라 선형 독립 경로 집합(Basis Path Set) 3~5개 정의
  3. 각 독립 경로를 최소 1회 관통하는 단위 테스트 케이스(JUnit) 작성
  4. $V(G) > 10$을 초과하는 고위험 복합 함수에 대해 메서드 추출(Extract Method) 리팩토링 수행
  5. 리팩토링 후 $V(G) \le 10$ 달성 및 기존 단위 테스트 100% 통과(회귀 방어) 검증

</details>

```text
1. [소스코드 파싱 및 CFG 그래프 생성]
    ├─ 대상 함수: `calculateDiscount(Customer c, Order o)`
    ├─ 내부 로직: 4개의 중첩 `if`문 및 1개의 `for` 루프 존재
    └─ [AST 파싱 결과: 기본 블록 노드 $N=12$, 제어 간선 $E=17$, 연결 성분 $P=1$]
            │
            ▼
2. [순환 복잡도 $V(G)$ 계산]
    ├─ 공식 1: $V(G) = E - N + 2P = 17 - 12 + 2 = 7$
    ├─ 공식 2: 조건 분기점 $\pi = 6$ (복합 연산자 분해) ➔ $V(G) = 6 + 1 = 7$
    └─ [판정: $V(G) = 7$ (10 이하이므로 안정 범위, 선형 독립 경로 7개 도출)]
            │
            ▼
3. [기본 경로 집합 (Basis Path Set) 7개 도출]
    ├─ 경로 1: 1-2-6 (VIP 회원, 첫 구매 할인 적용 후 종료)
    ├─ 경로 2: 1-3-4-6 (일반 회원, 쿠폰 적용 후 종료)
    └─ [경로 3~7: 포인트 사용, 배송비 무료, 생일 할인 등 각 독립 간선 관통 경로]
            │
            ▼
4. [기본 경로 1:1 단위 테스트 케이스 작성]
    ├─ 각 7개 독립 경로를 실행하기 위한 입력 데이터 믹스 7세트 구성
    └─ [테스트 실행 ➔ 구문 커버리지 100%, 분기 커버리지 100% 완전 달성]
            │
            ▼
5. [고복잡도 함수 리팩토링 (가상 시나리오 $V(G) = 25$인 경우)]
    ├─ 단일 책임 원칙(SRP) 적용 ➔ 3개의 서브 함수(`calcVIP()`, `calcCoupon()`)로 분리
    ├─ 분할 후 메인 함수 $V(G) = 3$, 각 서브 함수 $V(G) \le 4$로 대폭 단순화
    └─ [품질 게이트 통과 ➔ 가독성 및 유지보수성 100% 확보]
```

**동작 원리**

1. **복합 조건문의 분해 원칙**: `if (A && B)`는 단일 분기점이 아니라 `if (A) { if (B) }`와 동일하므로 $\pi=2$로 계산되어 $V(G)$가 1 증가
2. **최소 테스트 집합의 수학적 기저(Basis)**: 기본 경로 집합의 7개 케이스를 실행하면, 이들의 선형 결합으로 만들어지는 나머지 수백 개의 파생 경로는 자동으로 테스트되는 원리
3. **스위치-케이스(Switch-Case)문의 영향**: $K$개의 `case`를 가진 switch문은 $K-1$개의 분기점을 추가하므로, 전략 패턴(Strategy Pattern)이나 팩토리 패턴으로 다형성 리팩토링 유도
4. **인지 복잡도(Cognitive Complexity)와의 차이**: 순환 복잡도는 기계적 제어 경로 수($V(G)$)를 세고, 인지 복잡도는 중첩 들여쓰기 깊이에 가중치를 부여하여 인간의 뇌 인지 부하를 측정
5. **CI/CD 정적 분석 자동화**: 커밋 시점에 SonarQube가 $V(G) > 15$인 코드를 감지하여 PR(Pull Request) 머지를 자동 차단

#### 한줄 요약
- AST 파싱 및 CFG 생성, V(G) 산출, 기본 경로 집합 도출, 1:1 단위 테스트 작성, 메서드 분할 리팩토링 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **코드 복잡도 3대 평가 지표 비교**:
  - 매케이브 순환 복잡도 (Cyclomatic): 선형 독립 경로 수 (화이트박스 테스트 설계용).
  - 소나 인지 복잡도 (Cognitive): 인간이 코드를 이해하기 난해한 정도 (가독성/리팩토링용).
  - 할스테드 소프트웨어 과학 (Halstead): 연산자와 피연산자의 수량 (코드 볼륨/노력 측정).

</details>

| 비교 항목 | 매케이브 순환 복잡도 (McCabe $V(G)$) | 인지 복잡도 (Cognitive Complexity) | 할스테드 복잡도 (Halstead Metric) |
|:---|:---|:---|:---|
| **핵심 측정 대상** | **제어 흐름 상의 선형 독립 경로 수**| **개발자가 코드를 읽고 이해하는 인지 부하**| **연산자(Operator)와 피연산자(Operand) 개수**|
| **수학적 모델** | **$V(G) = E - N + 2P = \pi + 1$** | 중첩 제어문 계층별 가중치 합산 | 어휘 수($\eta$), 길이($N$), 볼륨($V = N \log_2 \eta$)|
| **중첩문 처리** | 중첩 깊이에 무관하게 분기마다 +1 | **중첩이 깊어질수록 $+1, +2, +3$ 가중 폭증**| 중첩 구조 미반영 (단순 토큰 계수) |
| **주요 활용 목적** | **화이트박스 기본 경로 테스트 케이스 수 도출**| **스파게티 코드 리팩토링 및 가독성 개선**| 개발 소요 노력(Effort) 및 버그 수 예측|
| **권고 임계치** | **$V(G) \le 10$** | **Cognitive Score $\le 15$** | 프로젝트별 상대 비교 |

#### 한줄 요약
- 순환 복잡도는 기계적 독립 테스트 경로 수, 인지 복잡도는 가독성 인지 부하, 할스테드는 토큰 볼륨을 측정한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **순환 복잡도 실무 통제 시 3대 위험 요소와 엔지니어링 대책**:

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| $V(G) \le 10$ 기준만 맞추기 위해 의미 있는 로직을 억지로 잘게 쪼개어 **클래스 간 결합도가 폭증하고 전체 시스템 가독성이 더 나빠지는 형식적 분할 발생** | **순환 복잡도와 함께 인지 복잡도(Cognitive Complexity) 및 응집도(LCOM)를 교차 검증하여 의미 있는 도메인 단위 리팩토링 강제** | 형식적 함수 쪼개기 방지 및 높은 응집도 유지 |
| 복합 조건 연산자(`&&`, `||`)를 단일 조건문으로 오판하여 **순환 복잡도를 과소평가하고 기본 경로 테스트 케이스를 누락하여 상용 버그 발생** | **정적 분석 도구의 복합 연산자 분해 옵션을 활성화하여 `A && B`를 2개의 분기점으로 정확히 반영** | 테스트 경로 누락 제로화 및 결함 검출력 확보 |
| 레거시 시스템의 5,000라인짜리 함수($V(G) > 100$)를 테스트 없이 리팩토링하다가 **기존 정상 동작 로직이 파괴되는 대규모 사이드 이펙트 발생** | **리팩토링 전 현재 상태에 대한 엔드투엔드 승인 테스트(Approval Test/골든 마스터)를 먼저 작성하여 안전망 확보 후 점진 리팩토링** | 무결점 안전 리팩토링 및 회귀 결함 100% 차단 |

#### 한줄 요약
- 인지 복잡도 교차 검증으로 형식적 분할을 막고, 복합 연산자를 분해하며, 골든 마스터 테스트 후 리팩토링한다.

## Ⅶ. 결론

- 소프트웨어의 구조적 복잡성을 정량화하고 화이트박스 단위 테스트의 완전성을 보증하는 수학적 나침반인 **매케이브 순환 복잡도($V(G)$) 체계**는 단순한 정적 분석 수치를 넘어 소프트웨어의 결함 예방과 지속 가능한 유지보수성을 견인하는 핵심 품질 지표이며, 실무 구현 시 **CFG 기반 3대 산출 공식의 정확한 이해**, **$V(G)$와 일치하는 기본 경로 집합(Basis Path Set) 100% 테스트**, **$V(G) \le 10$ 품질 게이트 강제 및 메서드 추출 리팩토링**, **인지 복잡도와의 상호보완적 결합**을 완성하여 최고 수준의 소스코드 클린 아키텍처와 무결점 신뢰성을 완성

#### 한줄 요약
- 제어 흐름 그래프 기반 $V(G)$ 산출과 기본 경로 테스팅을 통해 소프트웨어 복잡도를 완벽히 통제한다.
