## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **매케이브 순환 복잡도(McCabe's Cyclomatic Complexity, V(G))**: 제어 흐름 그래프(CFG)의 선형 독립 경로 수를 측정하는 구조적 복잡도 지표.
- **제어 흐름 그래프(Control Flow Graph, CFG)**: 프로그램의 실행 블록을 노드로, 제어 이동을 간선으로 표현한 유향 그래프.

</details>

- 정의/개념: 제어 흐름 그래프(CFG)의 노드와 간선 관계를 기반으로 소스 코드 내 선형 독립 경로의 수를 산출하는 구조적 복잡도 지표
- 배경/필요성: 단순 라인 수(LOC)만으로는 **제어 경로의 복잡성 및 테스트 케이스 최소 요구량 판단 불가**

#### 한줄 요약

- 독립 경로 수로 **기본 경로 시험 하한** 산정

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **선형 독립 경로(Linearly Independent Path)**: 기존 경로에 없는 새로운 간선을 최소 하나 이상 포함하는 고유한 실행 궤적.
- **결정점(Predicate Node)**: if, for, while, switch 등 조건에 따라 실행 제어가 분기되는 노드.

</details>

![결정점 수에 따라 증가하는 순환 복잡도와 독립 경로 수](/study/diagrams/cyclomatic-complexity-paths.svg)

> 단일 연결 제어 흐름 그래프를 가정한 파란 선은 결정점이 하나 늘 때마다 \(V(G)\)와 기본 독립 경로 수가 하나씩 증가하는 \(V(G)=결정점 수+1\) 관계를 나타낸다.

- CFG의 간선·노드·연결 성분으로 **독립 경로** 산출
- 단일 CFG는 **결정점 수+1** 기반 계산
- 경로 수는 순환 복잡도, 이해 난도는 **인지 복잡도**

#### 한줄 요약

- 결정점 하나마다 **기본 독립 경로** 하나 증가

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **V(G) 계산 공식**: $V(G) = E - N + 2P$ (E: 간선 수, N: 노드 수, P: 연결 성분 수). 단일 진입/진출 시 $V(G) = P + 1$ (P: 결정점 수).
- **기본 블록(Basic Block)**: 진입과 진출이 하나뿐인 순차 실행 코드 묶음.

</details>

```text
순환 복잡도(Cyclomatic Complexity) 분석 체계
├─ 소스 코드 파싱: 구문 트리(AST) 분석 및 기본 블록 노드(N) 분할
├─ CFG 그래프 생성: 분기문/루프 기반 제어 흐름 간선(E) 연결
├─ 복잡도 수식 연산: V(G) = E - N + 2P (또는 분기점 수 + 1)
└─ 품질 임계치 통제: V(G) > 10 리팩터링 권고 / V(G) > 15 빌드 경고
```

선의 의미: 함수별 CFG 구성부터 복잡도 산출($V(G)=E-N+2P$) 및 품질 임계값 판정으로 이어지는 순환 복잡도 분석 체계.

| 구성요소 | 책임 |
|:---|:---|
| 분석 경계 | 함수·메서드와 **연결 성분 $P$** 구분 |
| CFG | 기본 블록 **노드 $N$·간선 $E$** 표현 |
| 복잡도 산출 | $V(G)=E-N+2P$로 **독립 경로** 계산 |
| 임계값 정책 | 기준 초과 모듈을 개선 대상으로 지정 |

#### 한줄 요약

- CFG의 **독립 경로 수** 기반 임계값 초과 함수 식별

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **기본 경로 테스트(Basis Path Testing)**: 산출된 V(G)개의 독립 경로를 모두 실행할 수 있도록 테스트 케이스를 설계하는 기법.

</details>

```text
       정적 분석 도구
              │ 1. 소스 코드 파싱 및 제어 흐름 그래프(CFG) 생성
              ▼
       복잡도 계산기
              │ 2. V(G) 산출 및 선형 독립 경로 집합(Basis Set) 도출
              ▼
       시험 관리자
              │ 3. 복잡도 임계값 초과 함수 식별 및 리팩터링 우선순위 선정
              ▼
       개발 및 QA팀
              │ 4. 독립 경로별 테스트 케이스 작성 및 중첩 로직 분리
              ▼
        복잡도 감소 및 커버리지 충족 검증
```

**동작 원리**

1. **CFG 생성**: 정적 분석기로 소스 코드를 기본 블록 노드와 분기 간선으로 파싱
2. **수식 연산**: $V(G) = E - N + 2P$ 공식을 적용해 최소 필수 테스트 경로 수 산출
3. **타깃 선정**: 복잡도가 임계치(10~15)를 초과하면서 결함 이력이 잦은 고위험 모듈 선별
4. **테스트 및 개선**: 독립 경로를 100% 관통하는 단위 테스트를 작성하고 메서드 추출로 복잡도 완화
5. **품질 검증**: 리팩터링 후 $V(G)$ 지수의 하락과 회귀 테스트 통과 확인

#### 한줄 요약

- 독립 경로별 시험 후 **고위험 함수 구조 개선**

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **순환 복잡도 vs 인지 복잡도**: 순환 복잡도는 기계적 제어 경로 수(테스트 설계용), 인지 복잡도는 인간이 이해하기 난해한 정도(가독성 개선용).

</details>

| 복잡도 지표 | 매케이브 순환 복잡도 (McCabe) | 인지 복잡도 (Cognitive) | 중첩 깊이 (Nesting Depth) |
|:---|:---|:---|:---|
| 적용 기준 | 화이트박스 기본 경로 테스트 케이스 수 도출 | 개발자의 소스 코드 가독성 및 유지보수 난도 평가 | 코드 들여쓰기 깊이 제한 및 스파게티 로직 방지 |
| 핵심 측정 특징 | 선형 독립 경로 수 ($V(G)=E-N+2P$) | 제어문 중첩 및 로직 이해 가중치 합산 | if/for/while 등의 최대 중첩 계층 깊이 |
| 한계 및 사각지대 | 데이터 흐름 및 외부 인터페이스 복잡도 미반영 | 도구별 가중치 산정 규칙 편차 존재 | 얕은 레벨의 다중 분기문 복잡성 반영 불가 |

> 시험 경로·이해 난도·중첩 제한에 맞춰 **지표 선택**

#### 한줄 요약

- 시험은 순환, 가독성은 **인지 복잡도** 기반 판단

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **형식적 분할 방지**: 복잡도 점수만 낮추기 위해 의미 없는 기계적 함수 쪼개기를 지양하고 응집도를 고려한 리팩터링 수행.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 고복잡도 함수의 미시험 경로 | 기본 경로별 단위 시험 | **회귀 테스트** 방어망 확보 |
| 임계값만으로 개선 대상 선택 | 변경·결함 이력 병행 | **리팩터링 우선순위** 확보 |
| 수치용 무의미한 함수 분할 | 결합도·인지 복잡도 검토 | **형식적 분할** 방지 |

#### 한줄 요약

- 기본 경로 **회귀시험 확보 후 리팩터링** 수행

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **구조적 복잡도 거버넌스**: CI/CD 파이프라인에서 순환 복잡도와 인지 복잡도를 지속 모니터링하여 코드 품질 저하를 방지하는 체계.

</details>

- 선형 독립 경로 수 기반 **단위 테스트 하한선 충족 및 고복잡도 함수 리팩터링 수행**

#### 한줄 요약

- **시험 하한 충족 후** 변경·결함 집중 함수 리팩터링
