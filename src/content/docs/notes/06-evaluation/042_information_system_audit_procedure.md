## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **정보시스템 감리**: 독립된 감리법인이 사업의 적합성·효율성·안전성을 점검하고 개선을 권고하는 법정 활동.
- **피감리인**: 감리 대상 사업을 수행하며 자료 제출과 시정조치를 담당하는 사업자.

</details>

- 정의/개념: 독립 제3자가 증거로 사업의 적정성을 검증하는 **법정 품질 보증**
- 배경/필요성: 발주자와 사업자가 스스로 점검하면 이해가 걸린 쪽이 판정 주체가 되어 **객관적 결함 판정**이 서지 않고 결함이 검수 이후 분쟁 비용으로 넘어가므로, 이해관계 없는 감리법인을 발주자와 사업자 사이에 두어 자체 확인을 증거 기반 제3자 검증으로 대체할 필요

#### 한줄 요약
- 정보시스템 감리는 독립된 제3자가 사업 적정성과 시정 완료를 검증한다.

## Ⅱ. 특징

- 발주기관과 사업자로부터 분리된 **감리 독립성**
- 문서·코드·로그에 근거한 **객관적 증적주의**
- 발주기관·감리법인·사업자의 **3자 거버넌스**
- 요구와 산출물·시스템을 연결하는 **과업 추적성**
- 지적부터 재확인까지 닫는 **시정조치 폐쇄 루프**

#### 한줄 요약
- 독립성, 증적주의, 3자 견제, 과업 추적, 시정 확인이 핵심이다.

## Ⅲ. 구조 및 구성요소

```text
┌────────────── 정보시스템 감리 체계 ──────────────┐
│                                                  │
│                 [발주기관]                       │
│                  ├── [감리법인]                  │
│                  └── [사업수행자]                │
│                                                  │
│  [행정안전부·전문기관] ── 기준·자격 관리         │
└──────────────────────────────────────────────────┘
```

| 구성요소 | 책임 |
|:---|:---|
| **발주기관** | 감리 발주·계획 승인·조치 결과 승인 |
| **감리법인** | 독립 점검·보고·시정조치 확인 |
| **사업수행자** | 자료 제출·소명·결함 시정·증적 제출 |
| **행정안전부·전문기관** | 감리 기준·제도·자격 관리 |

#### 한줄 요약
- 감리법인은 발주기관과 사업수행자 어느 쪽에도 속하지 않는 자리에 끼어들어 이해 당사자의 자체 확인을 증거 기반 판정으로 대신하고, 행정안전부·전문기관은 그 감리법인의 기준과 자격을 관리해 판정자를 누가 담보하는가라는 물음을 닫는다.

## Ⅳ. 흐름도

```text
[발주기관]
     │
     └──────── 감리 요청
                 │
                 ▼
            [감리법인]
                 │ 1. 예비조사·감리계획
                 │ 2. 현장감리
                 │ 3. 감리보고서 통보
                 ▼
            [사업수행자]
                 │ 4. 시정조치 이행
                 ▼
            [감리법인]
                 │ 5. 시정조치 확인
                 └──────── 확인 결과 반환
```

**동작 원리**

1. **예비조사·감리계획**: 사업 범위와 위험에 따른 점검 항목 확정
2. **현장감리**: 착수회의·실사·인터뷰·종료회의 수행
3. **감리보고서 통보**: 증거와 심각도에 따른 지적·권고 확정
4. **시정조치 이행**: 사업자의 결함 수정과 결과 증적 제출
5. **시정조치 확인**: 실제 시스템과 증적을 재검증해 종결 판정

#### 한줄 요약
- 계획, 현장감리, 보고, 시정, 확인의 폐쇄 루프로 수행한다.

## Ⅴ. 종류 및 비교

| 비교 항목 | 정보시스템 감리 | PMO | QA |
|:---|:---|:---|:---|
| 수행 주체 | 독립 **감리법인** | 발주자 대리 조직 | 사업자 내부 조직 |
| 핵심 관점 | 준거성·안전성·적합성 | 일정·비용·위험 | 개발 품질·결함 |
| 수행 방식 | 마일스톤별 **독립 점검** | 전 기간 관리 | 개발 전 기간 통제 |
| 결과 | 감리·시정조치 확인보고서 | 공정·위험 보고서 | 시험·결함 보고서 |
| 구속 기반 | 법령·감리 기준 | 위탁 계약 | 내부 품질 기준 |

#### 한줄 요약
- 감리는 독립 검증, PMO는 발주 관리, QA는 내부 품질 통제이다.

## Ⅵ. 실무 고려사항 및 대책

| 문제 | 대책 |
|:---|:---|
| 문서만 확인하는 형식적 감리 | 코드·로그·인터뷰의 **삼각 검증** |
| 텍스트로만 제출하는 허위 조치 | 실행 증거 기반 **현장 재확인** |
| 감리인과 피감리인의 이해관계 | 계약·인력의 **독립성 검증** |
| 애자일 변경 이력의 추적 단절 | Git·이슈·CI 로그의 **전자 증적** 활용 |
| 중대 지적의 조치 지연 | 심각도별 담당자·기한 **추적 관리** |

#### 한줄 요약
- 실사, 독립성, 전자 증적, 조치 추적으로 형식적 감리를 막는다.

## Ⅶ. 결론

- 중대 지적의 실제 수정 증거를 **현장 재확인**한 뒤 사업 종결 승인

#### 한줄 요약
- 독립 감리와 시정조치 재확인으로 사업의 준거성과 안전성을 보증한다.
