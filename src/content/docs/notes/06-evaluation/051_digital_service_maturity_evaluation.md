## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **디지털 서비스 성숙도**: 조직의 디지털 서비스 역량을 단계별 수준으로 나타낸 척도.
- **갭 분석**: 현재 수준과 목표 수준의 차이와 원인을 식별하는 분석.

</details>

- 정의/개념: 디지털 서비스 역량을 증거로 진단하는 **단계형 성숙도 모형**
- 배경/필요성: 설문식 자기평가만으로는 실제 역량의 **병목·선행 조건 식별 곤란**

#### 한줄 요약
- 디지털 서비스 성숙도 평가는 현재 역량과 목표 간 갭을 증거로 진단한다.

## Ⅱ. 특징

- 초기부터 최적화까지 구분하는 **5단계 성숙도**
- 고객·데이터·플랫폼·조직의 **4대 진단 영역**
- 로그·KPI·DORA에 근거한 **실증 증적 평가**
- 가장 낮은 영역부터 개선하는 **병목 우선 원칙**
- 상위 역량에 필요한 기반을 먼저 갖추는 **선행 과제 관문**
- 주기적 측정으로 개선을 확인하는 **재평가 폐쇄 루프**

#### 한줄 요약
- 5단계, 4대 영역, 증적 평가, 병목 우선, 선행 관문이 핵심이다.

## Ⅲ. 구조 및 구성요소

```text
┌──────────── 디지털 서비스 성숙도 ────────────┐
│                                             │
├── [고객 경험·채널]                          │
├── [데이터·AI]                               │
├── [클라우드·플랫폼]                         │
└── [조직 문화·거버넌스]                      │
                                              │
    Level 1 · Level 2 · Level 3 · Level 4 · Level 5
```

| 구성요소 | 책임 |
|:---|:---|
| **고객 경험·채널** | 접근성·여정·피드백·개인화 평가 |
| **데이터·AI** | 데이터 품질·거버넌스·지능화 평가 |
| **클라우드·플랫폼** | API·자동화·탄력성·보안 평가 |
| **조직 문화·거버넌스** | 제품 운영·협업·성과 관리 평가 |
| **성숙도 레벨** | 초기부터 최적화까지 역량 단계 판정 |

#### 한줄 요약
- 4대 진단 영역을 5단계 성숙도 척도로 평가한다.

## Ⅳ. 흐름도

```text
[DX 전략]
     │
     │ 1. 진단 범위·목표 수준 정의
     ▼
[평가 조직]
     │ 2. 로그·KPI·인터뷰 증거 수집
     │ 3. 현재 수준·병목·갭 판정
     │ 4. 선행 과제 중심 로드맵 수립
     │ 5. KPI 이행·성숙도 재평가
     ▼
[투자 의사결정자]
     │
     └──────── 투자 결과 반환
```

**동작 원리**

1. **진단 범위·목표 수준 정의**: 전략에 맞는 영역·가중치·기준 설정
2. **로그·KPI·인터뷰 증거 수집**: 자기평가와 운영 증거 교차 확인
3. **현재 수준·병목·갭 판정**: 영역별 레벨과 최저 역량 식별
4. **선행 과제 중심 로드맵 수립**: 의존성과 효과에 따른 개선 순서 결정
5. **KPI 이행·성숙도 재평가**: 실측 성과로 다음 투자 여부 판정

#### 한줄 요약
- 목표, 증거, 갭, 로드맵, 재평가 순으로 성숙도를 높인다.

## Ⅴ. 종류 및 비교

| 비교 항목 | CMMI | ISO/IEC 33020 | 디지털 성숙도 모형 |
|:---|:---|:---|:---|
| 핵심 관점 | 조직 **프로세스 개선** | 프로세스 역량 측정 | 디지털 사업·기술 역량 |
| 단계 구조 | 5단계 성숙도 | 0~5 역량 수준 | 모형별 단계 수준 |
| 주요 대상 | 개발·서비스·거버넌스 | 개별 프로세스 속성 | 고객·데이터·플랫폼·조직 |
| 주요 증거 | 수행·관리·성과 기록 | 프로세스 결과와 속성 | KPI·DORA·사용자·운영 로그 |
| 적용 판단 | 조직 개선 체계화 | 표준 역량 평가 | DX 투자 우선순위 결정 |

#### 한줄 요약
- CMMI는 조직 개선, 33020은 프로세스 역량, 디지털 모형은 DX를 본다.

## Ⅵ. 실무 고려사항 및 대책

| 문제 | 대책 |
|:---|:---|
| 설문 중심의 과대 성숙도 판정 | 로그·KPI 기반 **증적 교차 검증** |
| 평균 점수에 가려진 최저 역량 | 영역별 **병목 수준** 별도 판정 |
| 기반 없이 상위 기술부터 투자 | 의존성 기반 **선행 과제 관문** |
| 모든 영역의 동시 개선으로 분산 | 효과·위험 기반 **우선순위 로드맵** |
| 평가 후 실행 성과 미확인 | KPI 소유자와 **주기적 재평가** |

#### 한줄 요약
- 증적, 병목, 선행 관문, 우선순위, 재평가로 형식적 진단을 막는다.

## Ⅶ. 결론

- 최저 성숙 영역과 선행 의존성을 기준으로 **다음 단계 투자 과제** 결정

#### 한줄 요약
- 가장 낮은 역량의 기반 과제를 먼저 개선하고 증거로 승격을 판단한다.
