## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **SLA(Service Level Agreement)**: 고객과 제공자가 품질•측정•책임을 합의한 계약이다.

</details>

- 정의/개념: 서비스 목표•측정•면책•미달 책임을 정한 외부 **SLA 품질 계약**이다.
- 배경/필요성: 추상적 품질 약속만으로는 **미달 여부•책임•보상**을 검증하고 정산하기 어렵다.

#### 한줄 요약
- 정보기술 서비스를 제공하는 기업이 고객에게 품질 목표와 미달 시 보상을 문서로 약속한 계약이 핵심이다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **SLI(Service Level Indicator)**: 실제 서비스 품질을 측정한 지표이다.
- **SLO(Service Level Objective)**: SLI에 설정한 내부 운영 목표값이다.
- **면책 조항**: 계획 정지•고객 원인처럼 제공자의 SLA 책임에서 제외할 조건이다.
- **서비스 크레딧**: SLA 목표 미달 시 고객 요금에서 차감하는 계약상 보상이다.

</details>

- SLI•목표값 기반 **품질 위반 판정**이 핵심이다.
- 범위•기간•면책 기반 **측정 기준**이 핵심이다.
- 서비스 크레딧 기반 **미달 책임**이 핵심이다.

#### 한줄 요약
- 측정 방식•제외 조건•미달 보상 절차를 포함한 품질 계약이 핵심이다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **서비스 범위**: SLA가 적용되는 기능•사용자•지역•시간대와 제외 대상을 정한 경계이다.
- **측정 규칙**: 지표의 데이터 원천•집계 주기•성공 기준•반올림 방법을 정한 규칙이다.
- **보고•검토**: 측정 결과와 위반•개선 조치를 정기적으로 고객과 확인하는 활동이다.
- **책임 정산**: 측정 결과와 면책 조건으로 위반 여부를 판정하고 서비스 크레딧과 개선 책임을 처리하는 절차이다.

</details>

```text
                        [서비스 범위•책임]
                    /          |          \
       [SLI•목표•합격선] [측정 출처•기간•산식] [면책•변경•분쟁]
                    \          |          /
                     [보고•크레딧•개선]
```

선의 의미: 서비스 범위•책임 아래 품질 목표, 측정 규칙, 면책•분쟁 경계를 분리하고 보고•크레딧•개선 영역이 세 계약 요소를 공통 정산하는 SLA 구조를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 서비스 범위•책임 | 기능•지역•시간과 **계약 당사자** |
| SLI•목표•합격선 | 가용성•지연•**지원 수준** |
| 측정 출처•기간•산식 | 원천•분모•**집계 구간** |
| 면책•변경•분쟁 | 계획 정지•고객 원인•**조정 절차** |
| 보고•크레딧•개선 | 통지•보상•**재발 방지** |

#### 한줄 요약
- 품질 계측•내부 운영 목표•외부 책임 보상선의 연계가 핵심이다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **병행 측정**: 고객과 제공자가 같은 기간의 품질을 각각 측정하여 결과를 대조하는 방식이다.
- **분쟁 조정**: 측정값이 다를 때 원시 데이터와 계약 규칙으로 위반 여부를 재판정하는 절차이다.
- **원시 데이터 보존**: 측정 편차나 분쟁이 발생했을 때 산식과 판정을 재현할 수 있도록 원본 기록을 유지하는 조치이다.

</details>

```text
서비스 제공자•고객
   │ 1. 서비스 요구•보상안 검토
   │ 2. 측정•면책•보상 기준 확정
   ▼
측정 시스템
   │ 3. 고객•제공자 병행 측정•대조
   ▼
검토위원회
   │ 4. 미달•책임•크레딧 판정
   ▼
정산 시스템
   │ 5. 보고•보상•개선 이행 추적
   ▼
보고•보상•개선 추적 결과
```

**동작 원리**

1. **서비스 요구•보상안 검토**: 기능•품질•책임의 **조정 요구**를 확정한다.
2. **측정•면책•보상 기준 확정**: 산식•면책•**서비스 크레딧**을 합의한다.
3. **고객•제공자 병행 측정•대조**: 원천•기간과 **측정 편차**를 검증한다.
4. **미달•책임•크레딧 판정**: 위반 수준과 **보상 금액**을 결정한다.
5. **보고•보상•개선 이행 추적**: 정산과 개선 기한 이행을 확인한다.

#### 한줄 요약
- 서비스 범위•품질 지표•대조 기간•서명•운영 판정의 계약 절차이다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **SLI 역할**: 실제 품질 측정값을 제공한다.
- **SLO 역할**: 장애 예방과 배포의 내부 목표를 제공한다.
- **SLA 역할**: 목표 미달의 외부 책임과 보상을 정한다.

</details>

서비스 수준 지표•서비스 수준 목표•서비스 수준 협약은 서로 선택하는 대안이 아니라 측정값에서 내부 목표와 외부 책임으로 이어지는 관리 계층이다.

| 관리 요소 | 역할 | 표현•주요 쟁점 |
|:---|:---|:---|
| SLI | 실제 **품질 측정값** | 가용률•지연•오류율과 측정 경계 |
| SLO | 달성할 **내부 품질 목표** | 대상 기간•목표치•허용 실패량 |
| SLA | 미달 책임을 정한 **외부 계약** | 목표•면책•서비스 크레딧•분쟁 기준 |

> 요약: **SLI로 SLO 판정**, **SLA로 책임 정산**이 핵심이다.

#### 한줄 요약
- 실제 품질 측정•내부 목표 판정•외부 책임 정산의 관리 계층이 핵심이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **측정 경계 오류**: 고객 여정과 다른 시작•종료•제외 조건으로 품질을 계산하여 결과가 왜곡되는 문제이다.
- **과도한 목표**: 사용자 가치보다 지나치게 높은 SLO•SLA가 비용과 변경 제약을 키우는 상태이다.
- **ISO(International Organization for Standardization)**: 국제표준화기구이다.
- **IEC(International Electrotechnical Commission)**: 국제전기기술위원회이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 측정•검토 책임이 빠진 **SLA 운영 공백** | **ISO/IEC 20000-1:2018+Amd1:2024** 적용 | 합의•감시•**검토 체계화** |
| 사용자 가치보다 높은 **과도한 목표** | 비용•위험 기반 **SLO•SLA 차등화** | 투자•변경 **제약 완화** |
| 측정값•면책 해석 차이의 **정산 분쟁** | **병행 측정•원시값 보존** | 판정의 **증거•신뢰 확보** |

#### 한줄 요약
- 양측 측정값 불일치 분쟁을 막는 공통 계측 도구 명문화가 핵심이다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **ISO/IEC 20000-1**: 서비스관리시스템 요구사항 표준이다.
- **관리 책임 분리**: 고객 대상 책임은 서비스 수준 협약과 서비스 크레딧, 내부 품질 관리는 서비스 수준 목표로 운영하는 결정이다.

</details>

- 고객 책임은 **SLA•서비스 크레딧**, 내부 품질 관리는 **SLO**로 분리한다.

#### 한줄 요약
- 운영 역량과 고객 요구를 반영한 측정 가능•감당 가능한 품질 계약이 핵심이다.
