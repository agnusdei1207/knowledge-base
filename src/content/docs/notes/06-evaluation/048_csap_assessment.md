## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **CSAP**: 공공기관에 제공되는 클라우드 서비스의 보호조치를 평가·인증하는 제도.
- **KCMVP**: 암호모듈의 안전성과 구현 적합성을 검증하는 국내 제도.

</details>

- 정의/개념: 공공 클라우드의 관리·물리·기술 통제를 검증하는 **보안 인증 체계**
- 배경/필요성: 민간 클라우드의 일반 보안 통제만으로는 **공공 요구 충족 보장 불가**

#### 한줄 요약
- CSAP는 공공기관용 클라우드 서비스의 보안 통제를 평가·인증한다.

## Ⅱ. 특징

- 데이터 중요도에 따른 **상·중·하 등급 체계**
- 관리·물리·기술·공공 특화의 **다영역 통제 평가**
- 서비스 유형별로 구분하는 **IaaS·SaaS·DaaS 평가**
- 공공 데이터 보호를 위한 **KCMVP 암호모듈**
- 문서 통제를 실제 공격으로 확인하는 **모의 침투 시험**
- 인증 후 변경과 통제를 확인하는 **사후 관리**

#### 한줄 요약
- 등급·유형별 평가, 공공 특화 통제, 침투 시험, 사후 관리가 핵심이다.

## Ⅲ. 구조 및 구성요소

```text
┌────────────── CSAP 평가 체계 ──────────────┐
│                                           │
├── [등급]                                  │
│   └── 상 · 중 · 하                        │
├── [서비스 유형]                           │
│   └── IaaS · SaaS · DaaS                  │
└── [평가 영역]                             │
    ├── 관리적 보호조치                     │
    ├── 물리적 보호조치                     │
    ├── 기술적 보호조치                     │
    └── 공공 특화 보호조치                  │
```

| 구성요소 | 책임 |
|:---|:---|
| **등급 체계** | 데이터 중요도별 보호 수준 결정 |
| **서비스 유형** | 제공 계층에 맞는 평가 범위 결정 |
| **관리적 보호조치** | 정책·인력·자산·사고 대응 평가 |
| **물리적 보호조치** | 출입·방재·장비 보호 평가 |
| **기술적 보호조치** | 격리·접근·취약점·로그 평가 |
| **공공 특화 보호조치** | 암호모듈·망·데이터 요건 평가 |

#### 한줄 요약
- 등급, 서비스 유형, 관리·물리·기술·공공 특화 영역으로 구성된다.

## Ⅳ. 흐름도

```text
[신청 사업자]
     │
     └──────── 인증 신청
                 │
                 ▼
            [평가기관]
                 │ 1. 서비스 유형·등급·범위 확정
                 │ 2. 서면·현장 통제 평가
                 │ 3. 기술 점검·침투 시험
                 ▼
            [신청 사업자]
                 │ 4. 부적합 보완·증거 제출
                 ▼
            [인증위원회]
                 │ 5. 보완 확인·인증 심의
                 └──────── 인증 결과 반환
```

**동작 원리**

1. **서비스 유형·등급·범위 확정**: 데이터 중요도와 제공 계층 분석
2. **서면·현장 통제 평가**: 정책·인력·시설·운영 증거 확인
3. **기술 점검·침투 시험**: 격리·암호·접근·취약점의 실제 동작 검증
4. **부적합 보완·증거 제출**: 원인 제거와 재시험 결과 제출
5. **보완 확인·인증 심의**: 잔여 부적합과 인증 조건 최종 판정

#### 한줄 요약
- 범위 확정, 통제 평가, 침투 시험, 보완, 심의 순으로 인증한다.

## Ⅴ. 종류 및 비교

| 비교 항목 | CSAP | FedRAMP | ISO/IEC 27017 |
|:---|:---|:---|:---|
| 적용 시장 | 대한민국 **공공 클라우드** | 미국 연방 클라우드 | 국제 클라우드 보안 |
| 평가 성격 | 공공 조달 연계 인증 | 연방 사용 승인 체계 | 정보보호 통제 지침·인증 |
| 위험 구분 | 상·중·하 등급 | 영향 수준별 기준 | 단일 통제 체계 |
| 특화 요구 | 공공 특화·KCMVP | 연방 통제·지속 감시 | CSP·고객 통제 지침 |
| 적용 판단 | 국내 공공 서비스 | 미국 연방 서비스 | 국제 보안 관리체계 |

#### 한줄 요약
- CSAP는 국내 공공, FedRAMP는 미국 연방, 27017은 국제 통제에 초점을 둔다.

## Ⅵ. 실무 고려사항 및 대책

| 문제 | 대책 |
|:---|:---|
| 데이터 중요도와 인증 등급 불일치 | 사전 **데이터 분류·등급 매핑** |
| 공공 암호 요건의 설계 후 발견 | 초기 설계에 **KCMVP 모듈** 반영 |
| 하부 인프라 인증 범위 오해 | 상속 통제와 **이용자 책임** 분리 확인 |
| 문서 통제와 실제 설정 불일치 | 구성 실사와 **모의 침투 시험** |
| 인증 후 중요 변경 미신고 | 변경 영향 평가와 **사후 심사** 연계 |

#### 한줄 요약
- 등급 매핑, 암호 설계, 책임 확인, 실사, 변경 관리로 인증 위험을 줄인다.

## Ⅶ. 결론

- 데이터 중요도와 서비스 유형에 맞는 **CSAP 등급·통제** 충족 후 공공 도입

#### 한줄 요약
- 공공 데이터 위험에 맞는 등급과 실제 통제를 입증한 서비스만 도입한다.
