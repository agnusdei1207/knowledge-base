## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **CSAP (클라우드 보안인증 / Cloud Security Assurance Program / 클라우드컴퓨팅 발전 및 이용자 보호에 관한 법률 제23조의2)**: 중앙행정기관, 지자체, 공공기관이 민간 클라우드 서비스(IaaS, PaaS, SaaS, DaaS)를 안전하게 도입할 수 있도록, 한국인터넷진흥원(KISA)이 서비스 제공자(CSP/MSP)의 관리적, 물리적, 기술적 보호조치 및 공공 특화 보안 통제 기준의 충족 여부를 객관적으로 평가하여 인증을 부여하는 국가 공인 클라우드 보안 인증 제도.
- **민간 클라우드의 국가 기밀 유출 및 미인증 SaaS 연계 결함(Uncertified Cloud Security Defect)**: 일반 민간용 클라우드 서비스를 공공 행정망에 무단 도입하여 국가 행정 정보 및 국민 개인정보가 해외 데이터센터로 유출되거나, 국정원 검증 암호모듈(KCMVP) 미탑재 및 취약한 하이퍼바이저 격리 결함으로 인해 다른 상용 입주자(테넌트)에 의해 행정망이 침해당하는 구조적 결함.

</details>

- 정의/개념: 국가 행정 데이터의 주권을 보호하고 공공 클라우드 도입의 신뢰성을 확보하기 위해 **신청 및 범위 확정 $\rightarrow$ 관리적$\cdot$물리적$\cdot$기술적$\cdot$공공특화 4대 영역 현장 평가 $\rightarrow$ 모의 침투(Penetration Testing) 실사 $\rightarrow$ 부적합 시정조치 $\rightarrow$ 인증위원회 심의 및 CSAP 인증서(상/중/하 등급) 발급 $\rightarrow$ 매년 사후 심사** 를 집행하는 **국가 클라우드 보안 평가 체계**
- 배경/필요성: 공공부문 민간 클라우드 전면 전환 정책과 더불어 글로벌 CSP의 공공 진입을 허용하는 CSAP 3등급제(상/중/하) 개편에 따라, 데이터 중요도별 차등 보안 규제 준수 및 조달 등록 필수화

#### 한줄 요약
- CSAP는 공공기관에 공급되는 민간 클라우드의 안전성을 KISA가 평가하여 상/중/하 등급 인증을 부여하는 국가 제도이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **CSAP 3등급제 체계 (3-Tier Classification System)**:
  - **상 등급 (High Tier)**: 국가 안보, 외교/국방, 수사 등 최상위 기밀 정보 $\rightarrow$ **물리적 망 분리(Physical Separation)** 필수, 국내 인프라 한정.
  - **중 등급 (Medium Tier)**: 비공개 행정 내부 중요 데이터, 대규모 국민 개인정보 $\rightarrow$ **논리적 망 분리(Logical Separation)** 및 KCMVP 암호화.
  - **하 등급 (Low Tier)**: 대국민 공개 데이터, 공공 웹사이트 $\rightarrow$ 글로벌 CSP 진입 가능, 논리적 분리 및 계정 격리.

</details>

- **공공 특화 보안 통제(Public-specific Controls)의 엄격성**: 국정원 검증 필 암호모듈(KCMVP) 탑재 의무화, 모든 관리자 접속 및 보안 로그의 국내 데이터센터 1년 이상 보존 강제
- **실전 모의 침투 테스트(Penetration Testing) 의무화**: 화이트해커 심사관이 웹 취약점 스캔, 하이퍼바이저 탈옥(VM Escape), 테넌트 간 횡적 이동(Lateral Movement) 공격을 직접 수행하여 무결점 입증
- **유효기간 3년 및 매년 정기 사후 관리(Annual Surveillance)**: 인증 취득 후에도 형상이 임의로 변경되지 않도록 매년 사후 심사를 거치며, 주요 아키텍처 변경 시 '중요 변경 평가' 의무 수검

#### 한줄 요약
- 3등급제(상/중/하), KCMVP 암호모듈 의무화, 실전 모의 침투 검증, 매년 정기 사후 심사를 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **CSAP 4대 보안 평가 영역 및 세부 통제 기준**:
  1. **관리적 보호조치 (Policy)**: 정보보호 정책, 인적 보안, 자산 관리, 사고 대응 훈련.
  2. **물리적 보호조치 (Facility)**: 데이터센터 출입 통제(CCTV 90일 보존), 방재 설비, 장비 반출입.
  3. **기술적 보호조치 (Technical)**: 가상화 하이퍼바이저 격리, 네트워크 망 분리, 접근 통제, 취약점 점검.
  4. **공공 특화 보호조치 (Public)**: KCMVP 암호화, 국가 행정망 전용선 연계, 국내 로그 보존.

</details>

```text
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 1. CSAP 데이터 중요도별 3등급 체계 및 격리 요건 ]                     │
├───────────────────┬─────────────────────────────────┬───────────────────┤
│ 등급 구분         │ 대상 데이터 및 시스템           │ 인프라 망 분리 요건│
├───────────────────┼─────────────────────────────────┼───────────────────┤
│ **상 등급 (High)**│ 국가 안보, 국방, 외교, 치안     │ **물리적 망 분리 (전용 IDC)**│
│                   │ (국가 핵심 기밀 시스템)         │ (민간 테넌트 혼용 100% 금지)│
├───────────────────┼─────────────────────────────────┼───────────────────┤
│ **중 등급 (Medium)**│ 비공개 행정업무, 대규모 개인정보│ **논리적 망 분리 (VPC/VLAN)**   │
│                   │ (대부분의 표준 공공 정보시스템) │ (KCMVP 암호화 필수 적용)   │
├───────────────────┼─────────────────────────────────┼───────────────────┤
│ **하 등급 (Low)** │ 대국민 공개 웹사이트, 단순 홍보 │ **논리적 분리 / 클라우드 보안**│
│                   │ (글로벌 CSP 개방 영역)          │ (AWS, Azure, GCP 등 진입)  │
└───────────────────┴─────────────────────────────────┴───────────────────┘
                                     │ (평가 거버넌스 파이프라인)
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 2. CSAP 평가 및 인증 심의 거버넌스 체계 ]                            │
│  ├─ [ 1. 신청 기업 (CSP/SaaS ISV) ] ➔ IaaS / SaaS / DaaS 등급별 인증 신청│
│  ├─ [ 2. KISA 평가반 실사 ] ➔ 4대 영역 110여 개 점검 항목 + 모의 침투 실사│
│  ├─ [ 3. 부적합 보완 조치 ] ➔ 30일 이내 취약점 패치 및 증적 보고서 제출  │
│  └─ [ 4. 인증위원회 심의 ] ➔ 최종 의결 ➔ CSAP 공인 인증서(유효기간 3년) 발급│
└─────────────────────────────────────────────────────────────────────────┘
```

선의 의미: 데이터 중요도에 따라 상/중/하 등급을 선택하고 KISA 평가와 모의 침투, 보완 조치를 거쳐 인증위원회가 인증서를 발급하는 구조

| 서비스 유형 | 주요 평가 대상 | 핵심 평가 통제 기준 | 비고 |
|:---|:---|:---|:---|
| **IaaS 인증** | 서버, 네트워크, 스토리지 인프라 | 물리/논리 망 분리, 하이퍼바이저 보안, KCMVP | 인프라 기반 |
| **SaaS 표준** | 전자결재, ERP, 대민 행정 웹 SW | 테넌트 데이터 격리, 계정 관리, 소스 개발보안 | CSAP IaaS 필수 |
| **SaaS 간이** | 소규모 전자문서, 업무 보조 도구 | 핵심 30여 개 필수 보안 항목 중심 간소화 심사 | 중소기업 혜택 |
| **DaaS 인증** | 공공 원격/재택용 가상 데스크톱 | 가상 OS 이미지 무결성, 화면 캡처 방지, 매체 제어 | VDI 환경 |

#### 한줄 요약
- 상/중/하 3등급제, 4대 평가 영역(관리/물리/기술/공공특화), IaaS/SaaS/DaaS 유형별 평가, 인증위원회 심의로 구성된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **CSAP 인증 획득 5단계 수명주기 프로세스**:
  1. CSP 또는 SaaS 기업이 서비스 모델과 목표 등급(상/중/하)을 확정하여 KISA에 인증 신청
  2. KISA 평가반이 관리적/물리적 보안 문서 예비 심사 및 데이터센터 현장 실사 수행
  3. 화이트해커 모의 침투 테스트를 통해 웹 취약점, SQLi, KCMVP 암호모듈 탑재 실측
  4. 도출된 취약점(부적합 항목)에 대해 기업이 30일 이내 패치 완료 및 재실사
  5. 인증위원회의 최종 의결을 거쳐 CSAP 인증서 발급 및 조달청 디지털서비스몰 등록

</details>

```text
1. [인증 신청 및 대상 범위 확정]
    ├─ 신청 기업: 국산 공공 협업 SaaS 솔루션 기업
    ├─ 신청 유형: "CSAP SaaS 표준 등급 (중 등급)" 신청
    └─ [하부 인프라: 이미 CSAP IaaS 인증을 획득한 네이버클라우드 공공존 지정]
            │
            ▼
2. [서면 심사 및 데이터센터 현장 실사]
    ├─ 정보보호 정책서, 접근 권한 관리 지침, 재해복구(DR) 계획서 100% 적합 확인
    └─ [현장 실사: 백업 테이프 보관 금고, CCTV 90일 녹화 보존 확인 (Pass)]
            │
            ▼
3. [기술적 보안 실사 및 모의 침투 테스트]
    ├─ 웹 침투 테스트: XSS 방어 통과, 인증 우회 0건 확인
    ├─ [부적합 발견]: 회원 주민등록번호 암호화에 오픈소스 OpenSSL 사용 적발
    └─ [시정 요구: 국정원 KCMVP 검증 필 암호모듈로 교체 및 암호화 키 관리 개선]
            │
            ▼
4. [보완 조치 이행 및 KISA 재검증]
    ├─ 기업이 KCMVP 인증 암호모듈(ARIA-256)로 전면 교체 완료
    ├─ KISA 시험원이 소스코드 및 DB 바이너리 재검증 ➔ 암호화 적격성 Pass 확인
    └─ [종합 평가 보고서 작성: 부적합 0건, 전 항목 적합 판정]
            │
            ▼
5. [인증위원회 심의 및 CSAP 인증서 발급]
    ├─ 과기정통부/KISA 공인 인증위원회 블라인드 심의 및 가결 의결
    └─ [CSAP 인증서(유효기간 3년) 교부 ➔ 조달청 나라장터 종합쇼핑몰 우선등록 승인]
```

**동작 원리**

1. **상속형 인증 구조(Inherited Certification)**: SaaS 기업은 물리 데이터센터와 가상화 인프라를 직접 인증받을 필요 없이, 이미 CSAP IaaS 인증을 획득한 CSP 인프라 위에서 애플리케이션 보안(SaaS)만 평가받아 인증 비용 80% 절감
2. **KCMVP 검증 암호모듈의 필수성**: 일반 글로벌 표준(AES 등)이라도 국정원 암호모듈 검증을 통과하지 않은 라이브러리는 공공 데이터 암호화용으로 절대 사용 불가
3. **논리적 망 분리(Logical Separation)의 엄격성**: 민간 테넌트와 공공 테넌트가 동일한 물리 서버에서 가동되더라도, 하이퍼바이저 수준의 vLAN 격리와 방화벽 정책으로 상호 간의 통신이 100% 물리적 차단과 동등하게 격리
4. **모의 침투 테스트를 통한 실질 보안 증명**: 서류 상의 보안 대책을 넘어, 실제 칼리 리눅스(Kali Linux) 도구로 침투를 시도하여 시스템의 방어 능력을 현장 검증
5. **사후 심사(Surveillance Audit)의 지속성**: 매년 1회씩 보안 패치 현황, 인력 변동, 로그 관리 상태를 KISA가 불시에 방문 심사하여 인증 자격 유지 통제

#### 한줄 요약
- 신청 접수, 서면/현장 실사, 모의 침투 및 KCMVP 검증, 보완 조치 재검증, 인증위원회 CSAP 인증서 발급 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **클라우드 보안 인증 제도 비교**:
  - 한국 CSAP (KISA): 국내 공공기관 도입 필수 법정 인증 (상/중/하 3등급).
  - 미국 FedRAMP (GSA): 미국 연방정부 클라우드 조달 보안 표준 (High/Moderate/Low).
  - 국제 ISO/IEC 27017: 글로벌 표준 클라우드 정보보안 가이드라인.

</details>

| 비교 항목 | 한국 CSAP (Cloud Security Assurance) | 미국 FedRAMP (Federal Risk Management) | 국제 표준 ISO/IEC 27017 |
|:---|:---|:---|:---|
| **제도적 성격** | **대한민국 공공기관 도입 법적 필수 인증**| **미국 연방정부 기관 도입 필수 인증** | 국제 표준 민간/공공 자율 인증 |
| **등급 체계** | **상 등급, 중 등급, 하 등급 (3단계)** | **High, Moderate, Low, LiSaaS (4단계)**| 단일 인증 (등급 없음) |
| **특화 통제 요건**| **KCMVP 국정원 암호모듈, 국내 로그 보존**| FIPS 140-3 암호화, 미국 내 상주 인력 | 클라우드 보안 통제 37개 항목 |
| **인증 주관 기구**| **과학기술정보통신부 / KISA** | **미국 연방총무청 (GSA / FedRAMP PMO)** | ISO / IEC 국제표준화기구 |
| **유효 기간** | **3년 (매년 사후 심사)** | 지속적 모니터링 (Continuous ConMon) | 3년 (매년 사후 심사) |

#### 한줄 요약
- CSAP는 한국 공공 필수 인증(KCMVP/국내 로그), FedRAMP는 미국 연방 표준, ISO 27017은 국제 표준 자율 인증이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **CSAP 실무 인증 준비 시 3대 위험 요소와 엔지니어링 대책**:

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 오픈소스 암호화 라이브러리(OpenSSL)를 사용하여 **KCMVP 국정원 검증 암호모듈 미탑재로 인한 CSAP 본평가 즉각 탈락 발생** | **아키텍처 설계 초기부터 국가보안기술연구소 검증 필 KCMVP 소프트웨어 모듈을 라이선스 계약하여 DB 암호화 적용** | 암호화 부적합 결함 원천 차단 및 심사 기간 단축 |
| CSAP 인증을 획득하지 않은 일반 민간용 IaaS 인프라 위에 SaaS를 구축하여 **SaaS 인증 신청 자체가 법적으로 반려되는 사태 발생** | **반드시 사전에 CSAP IaaS 인증을 공식 취득한 공공 클라우드 존(Zone) 인프라를 기반으로 SaaS 인프라 프로비저닝** | 하부 인프라 인증 상속을 통한 적격성 100% 확보 |
| 인증 취득 후 기능 업그레이드를 하면서 아키텍처를 대폭 수정하고 KISA에 미신고하여 **매년 정기 사후 심사에서 '인증 취소(Revocation)' 처분 발생** | **주요 형상 변경 시 'CSAP 중요 변경 평가 사전 신청' 런북을 수립하고 변경 영향도 평가서를 선제 제출** | 공공 조달 입찰 자격의 영구적 유지 보증 |

#### 한줄 요약
- KCMVP 암호모듈을 사전 탑재하고, CSAP IaaS 공공존을 활용하며, 중요 변경 평가 거버넌스를 준수한다.

## Ⅶ. 결론

- 국가 공공 데이터의 주권을 수호하면서 혁신적인 민간 클라우드 서비스의 안전한 공공 조달을 견인하는 핵심 국가 보안 관문인 **CSAP 클라우드 보안 인증 평가 체계**는 단순한 절차적 규제를 넘어 고도화된 사이버 위협으로부터 공공 디지털 인프라를 지탱하는 절대적 방패이며, 실무 구현 시 **데이터 중요도에 부합하는 상/중/하 등급의 전략적 선정**, **KCMVP 검증 암호모듈의 완벽한 탑재**, **실전 모의 침투를 통한 취약점 선제 박멸**, **인증 상속 및 지속적인 사후 심사 거버넌스 유지**를 완성하여 최고 수준의 클라우드 보안 무결성과 공공 비즈니스 경쟁력을 완성

#### 한줄 요약
- 상/중/하 3등급제와 KCMVP 암호화 및 모의 침투 실사를 통해 무결점 공공 클라우드 보안 인증을 완성한다.
