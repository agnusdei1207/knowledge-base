## 미리 알고가기

- **미국 국가표준협회(American National Standards Institute, ANSI)**: '앤시'로 읽고 미국 국가표준 승인 기관을 영문 머리글자로 표시
- **통신산업협회(Telecommunications Industry Association, TIA)**: '티아이에이'로 읽고 통신 인프라 표준 개발 협회를 표시
- **ANSI/TIA-942-C**: '앤시 티아이에이 구사이 씨'로 읽고 942는 표준 번호, C는 개정판을 표시하는 데이터센터 표준
- **IT 부하(IT Load)**: 데이터센터의 전력·냉각·통신을 실제로 사용하는 서버·스토리지·네트워크 장비
- **무정전 전원장치(Uninterruptible Power Supply, UPS)**: '유피에스'로 읽고 정전 시 전력을 계속 공급하는 장치를 표시
- **동시 유지보수성**: 계획 정비 중에도 IT 부하로의 공급을 중단하지 않는 능력
- **내결함성**: 단일 설비나 공급 경로가 고장 나도 IT 서비스를 유지하는 능력
- **공통 원인 장애**: 서로 이중화한 설비가 같은 화재·배관·전원 문제로 동시에 멈추는 장애
- **종합 시운전**: 실제 장애·전환 조건을 만들어 설비가 설계대로 연동되는지 확인하는 시험
- **업무 영향 분석(Business Impact Analysis, BIA)**: '비아이에이'로 읽고 중단 피해를 분석해 복원 수준을 정하는 활동
- **복구 시간 목표(Recovery Time Objective, RTO)**: '알티오'로 읽고 장애 후 업무를 복구해야 하는 목표 시간을 표시
- **재해 복구(Disaster Recovery, DR)**: '디알'로 읽고 재해로 중단된 시스템·데이터 복구 체계를 표시
- **Rated-1**: 하나의 기본 공급 경로로 IT 부하를 지원하는 기본 시설 등급
- **Rated-2**: 하나의 공급 경로에 예비 용량 구성요소를 둔 시설 등급
- **Rated-3**: 계획 정비 중에도 IT 부하 공급을 유지할 수 있는 시설 등급
- **Rated-4**: 단일 장애가 발생해도 IT 부하 공급을 유지할 수 있는 내결함 시설 등급
- **Rated와 Tier 구분**: TIA-942는 '레이티드', Uptime Institute는 '티어'라는 별도 등급 명칭을 사용


## Ⅰ. 개요

- **정의/개념**: 데이터센터의 건축·통신·전력·냉각 인프라를 **Rated-1~4로 평가하는 표준**
- **배경/필요성**: 예비 장비 수만으로 판단할 때 놓치는 **정비·단일 장애 시 공급 지속성 검증**

### 쉽게 이해하기 (학습용)
- 전력·냉각 장비를 정비하거나 하나가 고장 나도 서버가 계속 동작할 수준을 등급으로 구분함


## Ⅱ. 특징

- **건축·통신·전력·냉각·안전·보안**의 물리 인프라를 종합 평가한다.
- **예비 용량·공급 경로·동시 유지보수·내결함성**으로 Rated를 구분한다.
- 시설 Rated는 **응용·데이터·운영 절차의 가용성을 보장하지 않는다.**

### 쉽게 이해하기 (학습용)
- 예비 장비 개수뿐 아니라 정비나 고장 때 다른 공급 길이 실제로 살아 있는지 확인함


## Ⅲ. 아키텍처 및 구성요소

```mermaid
flowchart LR
    A[건축·입지] --> P[전력 계통]
    A --> C[냉각 계통]
    A --> T[통신 계통]
    P --> I[IT 부하]
    C --> I
    T --> I
    S[안전·보안] -. 통제 .-> A
    S -. 통제 .-> I
```

| 설계 요소 | 설명 |
|:---|:---|
| 건축·입지 | **구획·하중·자연재해 위험** |
| 전력 계통 | **수전·발전기·UPS 공급 경로** |
| 냉각 계통 | **냉동기·배관 용량·경로** |
| 통신 계통 | **외부 인입·내부 배선 경로** |
| IT 부하 | **전력·냉각·통신 보호 대상** |
| 안전·보안 | **소화·출입통제·환경 감시** |

### 쉽게 이해하기 (학습용)
- 서버까지 이어지는 전력·냉각·통신 길과 이를 둘러싼 건물·안전 통제를 함께 평가함


## Ⅳ. 원리 및 절차 흐름도

```mermaid
sequenceDiagram
    participant C as 사업주
    participant A as 설계자
    participant T as 평가기관
    C->>A: 복원력 요구
    A->>C: 목표 등급
    A->>T: 설계 검증
    T->>T: 현장 검증
    T-->>C: 등급 판정
```

| 절차 | 설명 |
|:---|:---|
| 복원력 요구 | BIA·RTO로 허용 중단 수준 산정 |
| 목표 등급 | 정비·장애 허용 수준으로 Rated 선택 |
| 설계 검증 | 도면의 용량·경로·분리 요건 확인 |
| 현장 검증 | 시공 상태와 장애 전환을 시험 |
| 등급 판정 | 영역별 충족 결과로 인증 결정 |

### 쉽게 이해하기 (학습용)
- 업무가 버틸 수 있는 중단 시간을 정한 뒤 그 등급의 설계와 실제 시공 상태를 차례로 확인함


## Ⅴ. 종류 및 비교

| TIA-942 시설 등급 | Rated-1 | Rated-2 | Rated-3 | Rated-4 |
|:---|:---|:---|:---|:---|
| 적용 기준 | 짧은 중단을 허용할 때 | 설비 고장 위험을 줄일 때 | 계획 정비 중 가동이 필요할 때 | 장애 중에도 가동해야 할 때 |
| 핵심 특징 | 기본 단일 공급 | 예비 용량 구성요소 | 동시 유지보수 가능 | 단일 장애 허용 |
| 한계 | 정비·고장 시 중단 | 경로 장애 시 중단 | 일부 비계획 장애 취약 | 비용·복잡성·공통 장애 |

### 쉽게 이해하기 (학습용)
- Rated-3은 계획 정비를 견디고 Rated-4는 하나의 비계획 장애까지 견디는 수준임


## Ⅵ. 실무 사례

1. 금융센터: Rated-4 전력·냉각 경로 분리
2. 상용센터: 설계 인증 후 현장 장애 전환 시험

### 쉽게 이해하기 (학습용)
- 전력·냉각 경로가 물리적으로 갈라져 하나의 고장이 양쪽을 함께 멈추지 않게 설계함
- 도면만 확인하지 않고 완공 시설에서 전원을 끊어 예비 경로가 실제로 전환되는지 시험함


## Ⅶ. 결론

- 계획 정비는 **Rated-3**, 단일 장애 허용은 **Rated-4**

### 쉽게 이해하기 (학습용)
- 중단 허용 수준에 맞는 Rated를 고르고 설계와 현장 시험으로 같은 수준을 검증함
