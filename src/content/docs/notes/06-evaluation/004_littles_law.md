## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **리틀의 법칙**: 안정 시스템에서 평균 작업 수•처리율•체류시간이 $L=\lambda W$를 만족한다는 법칙이다.
- **평균 작업 수($L$)**: 정한 시스템 경계 안에 존재하는 평균 작업 수이다.
- **동시성 산정**: 평균 처리율과 평균 체류시간을 곱해 시스템 경계 안의 평균 작업 수를 계산하는 방법이다.

</details>

- 정의/개념: **리틀의 법칙** — 안정된 시스템에서 평균 재공량 $L$이 평균 처리율 $\lambda$와 평균 체류시간 $W$의 곱이라는 $L=\lambda W$ 관계를 나타내는 법칙
- 배경/필요성: 독립 측정 지표의 불일치로 **동시성 산정 오류**

#### 한줄 요약
- 맛집 안에 있는 손님 수는 매장 입구로 들어오는 손님 속도와 손님 한 명이 식사를 마치고 나갈 때까지 걸리는 시간을 곱한 것과 같다는 상식적인 규칙입니다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **평균 처리율($\lambda$)**: 같은 측정 경계에서 단위 시간에 완료되는 평균 작업 수이다.
- **평균 체류시간($W$)**: 작업이 경계에 들어와 나갈 때까지 머무는 평균 시간이다.
- **안정 상태**: 장기 유입량과 완료량이 같아 경계 안의 작업 수가 계속 증가하지 않는 상태이다.
- **지표 정합성**: 작업 종류•측정 경계•관측 기간•시간 단위를 같게 맞춰 세 평균값을 비교할 수 있는 성질이다.

</details>

![리틀의 법칙에 따른 재공량과 평균 체류시간 관계](/study/diagrams/little-law-wip-lead-time.svg)

> 처리율을 하루 2건으로 고정한 파란 선은 평균 재공량이 10건일 때 평균 체류시간이 5일이 되는 \(L=\lambda W\)의 선형 관계를 나타낸다.

- **관계 축**: 세 평균값을 단순한 분포 독립식으로 연결
- **측정 축**: 동일 작업•경계•기간에서 지표 정합성 확보
- **전제 축**: 안정 상태의 평균값에만 검산 적용

#### 한줄 요약
- 시스템을 뜯어보지 않고도 밖에서 측정한 처리량과 응답 시간만 있으면 시스템 내부에서 돌아가는 동시 처리 중인 작업량을 역산할 수 있습니다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **측정 경계**: 작업의 시작•종료•종류•관측 기간을 일관되게 정한 범위이다.
- **재공량**: 처리 중이거나 대기 중이어서 측정 경계 안에 남아 있는 작업 수이다.
- **단위 정합**: 처리율의 시간 단위와 체류시간 단위를 일치시켜 계산 결과가 작업 수로 해석되게 하는 조건이다.

</details>

```text
                        [작업•측정 경계]
                               |
          +--------------------+--------------------+
          |                    |                    |
[평균 작업 수 L]      [평균 처리율 λ]      [평균 체류시간 W]
          |                    |                    |
          +--------------------+--------------------+
                               |
                    [안정 상태•단위 정합]
```

선의 의미: 같은 작업•측정 경계 안의 평균 작업 수, 처리율, 체류시간이 안정 상태와 단위 정합 조건을 공통으로 갖는 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 작업•측정 경계 | **시작•종료•작업•기간** 정의 |
| 평균 작업 수 L | 경계 안의 **평균 작업 수 $L$** 측정 |
| 평균 처리율 λ | 단위 시간당 **평균 처리율 $\lambda$** 측정 |
| 평균 체류시간 W | 경계 안의 **평균 체류시간 $W$** 측정 |
| 안정 상태•단위 정합 | **유입•완료 수렴•시간 단위** 확인 |

#### 한줄 요약
- 전체 처리 중인 작업의 개수는 유입되는 부하의 크기와 개별 작업이 머무는 시간의 상호작용으로 결정됩니다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **유입량**: 관측 기간에 측정 경계 안으로 들어온 작업 수이다.
- **완료량**: 같은 기간에 측정 경계 밖으로 처리 완료되어 나간 작업 수이다.
- **교차검증**: 세 지표 중 두 값을 독립 측정하고 공식의 계산값과 나머지 관측값을 비교해 오차•폭주•타임아웃을 찾는 절차이다.

</details>

```text
분석가
   │ 작업·측정 경계 확정
   ▼
측정·지표 시스템
   │ 1. 안정 구간 지표 저장
   │ 2. L·λ·W 평균값 산출
   ▼
계산기
   │ 3. L=λW 계산값 산출
   ▼
검증기
   │ 4. 관측값·가정 교차검증
   ▼
동시성·처리율·체류시간 결과
```

**동작 원리**

1. **안정 구간 지표 저장**: 유입•완료 수렴과 단위 통일
2. **L•λ•W 평균값 산출**: 세 지표 중 관측한 두 값 선택
3. **L=λW 계산값 산출**: 동시성•처리율•시간 산출
4. **관측값•가정 교차검증**: 오차•폭주•타임아웃 점검

#### 한줄 요약
- 시스템이 안정되어 큐가 계속 쌓이지 않는 상태를 확인한 후, 수집한 지표를 공식에 적용하여 용량 산정의 모순을 잡아냅니다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **용량•동시성 산정**: 처리율과 체류시간으로 시스템 안에 필요한 평균 작업 수를 계산하는 방식이다.
- **암달의 법칙**: 병렬화할 수 없는 순차 비율로 고정 작업의 가속 상한을 계산하는 법칙이다.
- **성능 법칙 선택**: 대기열의 용량•동시성은 리틀의 법칙, 병렬화의 가속 상한은 암달의 법칙으로 검산하는 구분이다.

</details>

| 성능 법칙 | 리틀의 법칙 | 암달의 법칙 |
|:---|:---|:---|
| 적용 기준 | 대기열의 **용량•동시성** 산정 | 병렬화의 **성능 향상 한계** 예측 |
| 핵심 특징 | **작업 수•처리율•시간** 관계 | **직렬 비율•병렬도** 관계 |
| 한계 | **불안정 상태** 적용 오류 | **병렬 비율** 추정 오류 |

> 요약: **리틀의 법칙** 은 동시성, **암달의 법칙** 은 병렬 한계 검산

#### 한줄 요약
- 대기열 시스템의 정적 관계를 증명하는 물리적 법칙과 처리 흐름을 나누었을 때 도달하는 한계를 파악하는 성능 최적화 법칙을 비교합니다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **경계 정합성**: $L$, $\lambda$, $W$를 같은 작업 종류•시작점•종료점•기간에서 측정해야 한다는 조건이다.
- **비정상 상태**: 유입량과 완료량이 달라 재공량이 지속적으로 증가하거나 감소하는 상태이다.
- **꼬리 지연 보완**: 평균값만으로 순간 폭주를 놓치지 않도록 시계열과 상위 99% 응답시간을 함께 분석하는 방식이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 안정 여부를 확인하지 않는 **전제 누락** | **Little 1961•안정 상태** 를 명시 | 법칙의 **적용 타당성** 확보 |
| 작업•기간이 달라 생기는 **경계 불일치** | **동일 측정 경계•단위** 적용 | 지표의 **검산 오류** 감소 |
| 평균이 순간 폭주를 숨기는 **꼬리 지연 은폐** | **시계열•p99** 병행 분석 | 평균값의 **지연 해석 한계** 보완 |

#### 한줄 요약
- 시험에서 설정한 가상 사용자 수가 측정된 처리량과 지연에 맞는지 확인합니다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **평균값 검산**: 세 지표 중 두 값을 독립 측정한 뒤 리틀의 법칙으로 나머지 값의 정합성을 확인하는 방법이다.
- **John D. C. Little 1961 논문**: 정상 상태 대기행렬에서 $L=\lambda W$를 엄밀히 증명한 원전이다.
- **적용 판단**: 안정 상태이면 리틀의 법칙으로 동시성을 산정하고, 비정상 상태이면 평균식 대신 시계열로 변화 과정을 분석하는 결정이다.

</details>

- **안정 상태** 이면 $L=\lambda W$로 동시성을 산정하고 아니면 시계열 분석

#### 한줄 요약
- 시스템 설계 시 처리량과 속도를 조합해 하드웨어 및 소프트웨어 커넥션의 최대 한도를 검증합니다.
