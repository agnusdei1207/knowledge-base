## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **리틀의 법칙(Little's Law)**: 안정 상태 시스템 내 평균 작업 수(L)가 처리율($\lambda$)과 평균 체류시간(W)의 곱($L=\lambda W$)으로 도출된다는 대기행렬 법칙.
- **평균 작업 수(L, WIP)**: 시스템 내 처리를 기다리거나 실행 중인 작업의 평균 개수.
- **동시성 산정(Concurrency Estimation)**: 실측 처리율과 응답시간을 활용하여 시스템 내부 적정 동시 작업 수를 역산하는 기법.

</details>

- 정의: 평균 작업 수를 $L=\lambda W$로 구하는 **성능 법칙**이다.
- 필요성: 처리율·체류시간만으로 **동시성 역산 가능**

#### 한줄 요약

- 평균 작업 수는 **처리율·체류시간의 곱**

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **평균 처리율($\lambda$, Throughput)**: 단위 시간당 시스템이 완료하여 배출하거나 수용 중인 트랜잭션들의 평균 횟수.
- **평균 체류시간($W$, Lead Time)**: 요청 진입부터 큐 대기, 실행, 완료되어 나갈 때까지 소요된 총 평균 시간.
- **안정 상태(Steady State)**: 시스템 유입량과 방출 완료량이 균형을 이루어 내부 작업 수가 폭주하지 않는 상태.
- **지표 정합성(Metric Consistency)**: $L, \lambda, W$ 산출 시 작업 종류, 측정 경계, 시간 단위를 일관되게 고정하여 산출된 지표 간의 정합성.

</details>

![리틀의 법칙에 따른 재공량과 평균 체류시간 관계](/study/diagrams/little-law-wip-lead-time.svg)

> 처리율을 하루 2건으로 고정한 파란 선은 평균 재공량이 10건일 때 평균 체류시간이 5일이 되는 \(L=\lambda W\)의 선형 관계를 나타낸다.

- **평균 처리율·평균 체류시간**으로 동시 작업 수 산출
- 작업·경계·기간을 통일해 **지표 정합성** 확보
- 유입·완료가 균형인 **안정 상태**에만 적용

#### 한줄 요약

- 처리율·응답시간으로 **평균 동시성 역추적**

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **측정 경계(Measurement Boundary)**: 분석 대상 작업의 시작과 완료 지점을 명확히 구획하여 통계 훼손을 방지하는 통제 범위.
- **재공량(WIP: Work In Process)**: 시스템에 투입되어 처리가 완료되지 않은 채 대기하거나 실행 중인 잔여 작업량.
- **단위 정합(Unit Matching)**: 유입 처리율(requests/sec)과 체류시간(sec) 단위를 맞물리게 교정하는 필수 조건.

</details>

```text
                        [작업•측정 경계]
                               |
          +--------------------+--------------------+
          |                    |                    |
[평균 작업 수 L]      [평균 처리율 λ]      [평균 체류시간 W]
          |                    |                    |
          +--------------------+--------------------+
                               |
                    [안정 상태•단위 정합]
```

선의 의미: 동일하게 확립된 관측 작업 종류 및 측정 경계 공간 안에서 생성된 $L$ (작업 수), $\lambda$ (처리율), $W$ (체류시간) 세 지표가 시스템 안정 상태 및 계산 단위 정합성이라는 공통 토대 위에 긴밀하게 맞물려 작동하는 법칙 구조망.

| 주요 구성요소 | 기능적 역할 및 검증 책임 |
|:---|:---|
| 작업•측정 경계 | 동일 작업의 **측정 경계** 정의 |
| 평균 작업 수 L | 대기·실행 중인 **재공량** 측정 |
| 평균 처리율 λ | 단위 시간당 완료량 산출 |
| 평균 체류시간 W | 진입부터 완료까지 평균 시간 산출 |
| 안정 상태•단위 정합 | 발산 여부와 **단위 정합** 점검 |

#### 한줄 요약

- 재공량은 처리율·체류시간에 **정비례**

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **유입량(Arrival Volume)**: 모니터링 기간 동안 특정 측정 경계 안으로 진입한 총 트랜잭션 횟수.
- **완료량(Completion Volume)**: 기간 내 정상 처리를 거쳐 경계 밖으로 배출된 트랜잭션 총수.
- **교차검증(Cross Validation)**: 지표의 실측값과 리틀 공식 산출값을 대조하여 오류를 식별하는 검수 절차.
- **안정 구간 로그 저장(Steady State Logging)**: 입출력 밸런스가 유지되는 구간의 메트릭 추출 보존 단계.
- **평균값 산출(Averaging Metrics)**: 로그 집계치를 바탕으로 지표를 통계적으로 계산하는 단계.
- **이론값 계산(Theoretical Calculation)**: 두 실측 지표를 대입해 나머지 지표를 논리적으로 도출하는 연산 단계.
- **이론 교차검증(Theory Validation)**: 이론식 기반 계산값과 실제 관측치를 직접 대조하는 통제 단계.

</details>

```text
분석가
   │ 작업·측정 경계 확정
   ▼
측정·지표 시스템
   │ 1. 안정 구간 지표 저장
   │ 2. L·λ·W 평균값 산출
   ▼
계산기
   │ 3. L=λW 계산값 산출
   ▼
검증기
   │ 4. 관측값·가정 교차검증
   ▼
동시성·처리율·체류시간 결과
```

### 동작 원리

1. 안정 구간 지표 저장: 유입량·완료량 균형 구간 보존
2. L·λ·W 평균값 산출: 동일 경계·기간으로 집계
3. L=λW 계산값 산출: 미지 지표 역산
4. 관측값·가정 교차검증: 실측 괴리·가정 점검

#### 한줄 요약

- 안정 구간에서 $L=\lambda W$ **실측 교차검증**

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **용량•동시성 산정(Capacity & Concurrency Estimation)**: 처리율과 체류시간 목표치를 리틀 법칙에 대입하여 안전한 동시 작업량을 기획하는 자원 계획 방식.
- **암달의 법칙(Amdahl's Law)**: 순차 로직 비율로 인해 얻을 수 있는 성능 향상의 가속 한계를 예견하는 법칙.
- **성능 법칙 선택(Performance Theory Selection)**: 목적에 따라 리틀의 법칙(부하 용량 설계)과 암달의 법칙(연산 가속 한계)을 교차 사용하는 분석 기조.

</details>

| 범용 성능 예측 법칙 | 리틀의 법칙 (Little's Law) | 암달의 법칙 (Amdahl's Law) |
|:---|:---|:---|
| 적용 기준 | **용량·동시성 산정** | 병렬 가속 상한 예측 |
| 핵심 특징 | **리틀의 법칙**의 흐름·체류 관계 | **암달의 법칙**의 순차 비율 |
| 한계 | 불안정 큐에서 적용 불가 | 병렬 비율 추정 오차 |

> 요약: 성능 분석 목표에 입각하여 시스템 부하 용량 설계엔 리틀의 법칙을, 연산 가속 한계 설계엔 암달의 법칙을 도입하는 **성능 법칙 선택**의 기준 정립 및 철저한 분리 적용.

#### 한줄 요약

- 리틀은 **동시성**, 암달은 **병렬 가속 상한** 산정

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **경계 정합성(Boundary Congruence)**: 작업 성격, 진입/종료점, 관측 구간을 통일하여 연산 논리의 무결성을 담보하는 원칙.
- **비정상 상태(Unsteady State)**: 유입 트래픽($\lambda$)이 배출 완료량을 압도해 지연이 폭주하는 측정 불가 상태.
- **꼬리 지연 보완(Tail Latency Compensation)**: 평균값의 함정을 피하기 위해 백분위(p99)와 평균 수치를 병렬 대조하는 보완 분석 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 폭주 구간에 평균식 오적용 | **비정상 상태** 필터링 | 적용 타당성 확보 |
| 작업·기간 불일치 | **경계 정합성** 통일 | 역산 오차 감소 |
| 평균이 순간 지연 은폐 | p99 기반 **꼬리 지연 보완** | 미세 큐 지연 식별 |

#### 한줄 요약

- 가상 사용자 수와 **TPS·응답시간 곱 검산**

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **평균값 검산(Average Validity Checking)**: 실측된 두 지표를 공식에 대입해 나머지 지표와 논리적으로 상통하는지 검사하는 무결성 검수.
- **적용 판단(Application Decision)**: 안정 상태 시 리틀 법칙을, 붕괴 구간 시 시계열 분산 추적 모드로 전환하는 분석 전략.

</details>

- 안정 상태는 리틀 법칙, 폭주 구간은 시계열 분석

#### 한줄 요약

- 안정 구간은 **동시성 역산**, 폭주 구간은 로그 분석
