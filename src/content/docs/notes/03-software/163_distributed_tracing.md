## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **분산 추적(Distributed Tracing)**: 서비스별 스팬을 추적 식별자와 부모 관계로 연결해 전체 요청 경로와 구간별 지연 원인을 분석하는 기법이다.

</details>

- 정의/개념: 서비스별 스팬을 연결해 **요청 경로•지연 원인을 분석하는 기법**
- 배경/필요성: 서비스별 기록만으로는 전체 요청의 **병목•오류 전파를 식별하기 어려움**

#### 한줄 요약

- 주문 하나에 같은 추적 번호를 붙이면 결제와 재고 서비스에 흩어진 처리 기록을 한 이동 경로로 이어 가장 오래 멈춘 구간을 찾을 수 있다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **헤드 샘플링(Head Sampling)**: 요청 시작 시 추적 보존 여부를 결정하는 방식이다.
- **테일 샘플링(Tail Sampling)**: 요청 완료 후 결과를 보고 보존 여부를 결정하는 방식이다.
- **추적 식별자(Trace Identifier, Trace ID)**: 같은 요청의 스팬을 묶는 고유 식별값이다.
- **부모 관계**: 스팬 사이의 호출 선후 관계를 나타내는 정보이다.
- **호출 문맥 전파**: 동기 호출 헤더에 추적 정보를 전달하는 방식이다.
- **메시지 문맥 전파**: 비동기 메시지 속성에 추적 정보를 전달하는 방식이다.

</details>

- **Trace ID•부모 관계** 기반 경로 조립
- **호출•메시지 문맥 전파** 기반 연결 유지
- **헤드•테일 샘플링** 기반 보존량 조절

#### 한줄 요약

- 같은 추적 번호만으로는 순서를 알 수 없으므로 각 스팬의 부모 정보를 함께 기록하고 비동기 작업은 스팬 링크로 인과관계를 남긴다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **트레이서(Tracer)**: 서비스 실행 구간의 스팬과 추적 문맥을 생성•추출하는 계측 구성요소이다.
- **컬렉터(Collector)**: 여러 서비스의 스팬을 수신•가공•배치해 추적 백엔드로 전달하는 구성요소이다.
- **추적 백엔드(Trace Backend)**: 추적 식별자와 부모 관계로 스팬 경로를 조립하고 검색•시각화하는 구성요소이다.

</details>

```text
[분산 추적]
    |
    +-- [서비스 A 트레이서]
    +-- [서비스 B 트레이서]
    +-- [Collector]
    +-- [Trace 백엔드]
```

선의 의미: 두 서비스 트레이서 사이의 선은 부모•자식 추적 문맥 연결 관계, 각 트레이서와 Collector의 선은 완성 스팬의 수신•가공•배치 관계, Collector와 Trace 백엔드의 선은 추적 식별자•부모 관계를 보존한 스팬 전달과 경로 조립 관계를 뜻한다.

| 구성요소 | 책임 |
|:---|:---|
| 서비스 A 트레이서 | 부모 스팬•**추적 문맥** 생성 |
| 서비스 B 트레이서 | 자식 스팬•**문맥 추출** |
| Collector | 스팬 **수신•가공•배치** |
| Trace 백엔드 | **경로 조립•검색•시각화** |

#### 한줄 요약

- 트레이서가 구간 영수증을 만들고 문맥 전파기가 같은 주문 번호와 이전 구간 번호를 넘기면 백엔드가 영수증을 전체 동선으로 조립한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **스팬 식별자(Span Identifier, Span ID)**: 하나의 추적 안에서 개별 실행 구간을 구분하는 고유 식별값이다.
- **자식 추적 문맥 전달**: Trace ID와 부모 Span ID를 하위 서비스에 전달하는 단계이다.
- **자식 완료 스팬 전송**: 하위 구간의 상태와 소요 시간을 Collector로 보내는 단계이다.
- **부모 완료 스팬 전송**: 상위 구간과 자식 호출 관계를 확정해 보내는 단계이다.
- **가공 스팬 배치 전송**: 식별자•부모 관계를 보존해 Trace 백엔드에 전달하는 단계이다.

</details>

```text
업무 요청•부모 스팬 시작
          |
          v
1. 자식 추적 문맥 전달
          |
          v
하위 서비스 처리•자식 스팬 종료
          |
          v
2. 자식 완료 스팬 전송
          |
          v
상위 서비스 처리•부모 스팬 종료
          |
          v
3. 부모 완료 스팬 전송
          |
          v
4. 가공 스팬 배치 전송
          |
          v
Trace ID•부모 관계로 호출 경로 조립
```

**동작 원리**

- **1. 자식 추적 문맥 전달**: 동일 Trace ID•부모 Span ID 주입
- **2. 자식 완료 스팬 전송**: 하위 구간 상태•소요 시간 확정
- **3. 부모 완료 스팬 전송**: 상위 구간과 자식 관계 확정
- **4. 가공 스팬 배치 전송**: 식별자•부모 관계 보존

#### 한줄 요약

- 서비스 A가 자신의 스팬 번호를 부모로 넣어 B를 호출하면 두 서비스가 따로 보낸 기록도 백엔드에서 A 다음 B 순서로 연결된다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **샘플링 선택 축**: 즉시 결정과 완료 후 결과 기반 결정의 비교 기준이다.

</details>

| 샘플링 방식 | 헤드 샘플링 | 테일 샘플링 |
|:---|:---|:---|
| 적용 기준 | **대량 트래픽 기본 비율** | **오류•지연 추적 우선 보존** |
| 핵심 특징 | 요청 시작 시 **즉시 결정** | 전체 결과 후 **중앙 판정** |
| 한계 | 중요 결과 **사전 식별 불가** | **스팬 버퍼•판정 지연** 필요 |

#### 한줄 요약

- 헤드 샘플링은 입장할 때 임의 관객을 고르고 테일 샘플링은 공연이 끝난 뒤 사고나 지연이 있던 관객 기록을 남기는 차이다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **문맥 단절**: 문맥 단절은 서비스 호출 경계에서 추적 식별자가 전파되지 않아 전체 요청 경로를 연결하지 못하는 문제다.
- **스팬 링크(Span Link)**: 직접 부모•자식으로 표현하기 어려운 비동기 생산•소비 실행 사이의 인과관계를 연결하는 정보이다.
- **고카디널리티(High Cardinality)**: 사용자 식별자처럼 속성값 종류가 매우 많아 저장•조회 비용을 키우는 특성이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 서비스 경계 **문맥 단절** | 웹•원격 호출 **주입•추출 시험** | 단일 요청 **경로 유지** |
| 비동기 **부모 관계 왜곡** | 메시지 문맥•**스팬 링크** 적용 | 생산•소비 **인과관계 보존** |
| 희귀 오류 **추적 누락** | 테일•**오류 우선 샘플링** | 장애 분석 **표본 확보** |
| 노드 **시간 오차** | 시간 동기화•**상대 시간 병행** | 구간 순서•**지연 왜곡 완화** |
| 사용자 속성의 **고카디널리티** | 속성 허용 목록•**민감값 제거** | 비용•**개인정보 노출 축소** |

#### 한줄 요약

- 메시지 생산과 소비는 실행 시점이 떨어져 직접 부모 관계가 왜곡될 수 있으므로 전달 문맥과 스팬 링크를 함께 남겨야 한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **오류 희소성**: 전체 요청 중 오류 추적이 드물게 발생하는 특성이다.

</details>

- **호출 경계•비동기 관계•오류 희소성** 으로 문맥 전파•샘플링 결정

#### 한줄 요약

- 동기 호출은 부모•자식 관계를 끝까지 전파하고 비동기 작업은 링크를 사용하며 희귀 장애는 테일 샘플링으로 보존해야 한다.
