## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **산정 활동**: 개발 규모·공수·단가와 보정 근거를 계약 비용으로 바꾸는 활동이다.
- **범위별 비용 근거·변경 대가**: 최초 범위와 추가·변경 범위의 가격을 각각 설명하는 산정 자료이다.

</details>

- 정의/개념: 개발 규모·공수·단가를 계약 비용으로 바꾸는 **산정 활동**
- 배경/필요성: 눈대중 견적으로는 **범위별 비용 근거·변경 대가 산출 불가**

### 쉽게 이해하기 (학습용)

- 눈대중이 아닌 범위·규모·난이도와 단가 근거로 가격을 정하는 활동이다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **범위·기능 규모·기술 복잡도**: 개발 대가에 함께 반영하는 작업 경계, 논리 크기, 난이도이다.
- **산정 근거·불확실성 범위**: 견적 계산의 자료·가정과 실제 비용이 달라질 수 있는 오차 구간이다.
- **범위 기준선(Scope Baseline)**: 승인한 기능·작업 패키지 경계로 최초 대가와 변경 대가의 비교 기준이다.

</details>

- **범위·기능 규모·기술 복잡도**를 함께 반영
- **산정 근거·불확실성 범위**로 견적 검증
- **범위 기준선**으로 추가·변경 대가 분리

### 쉽게 이해하기 (학습용)

- 개발 범위와 난이도를 고려하고 변경 시 같은 기준으로 가격을 다시 계산한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **기능점수·WBS·생산성**: 사용자 기능 규모, 작업분할구조, 단위 공수당 작업량으로 노력 규모를 산정하는 근거이다.
- **화폐 비용**: 규모나 공수에 역할·숙련별 단가를 적용해 환산한 금액이다.
- **보정 요소(Adjustment Factor)**: 연계·성능·운영 조건의 비용 영향을 공통 산식에 추가 반영하는 항목이다.
- **예비비(Contingency)**: 식별한 불확실성과 위험이 현실화될 때 사용할 목적으로 별도 반영한 비용이다.

</details>

```mermaid
block
  columns 3
  S["범위 기준선"]
  M["규모·공수 모델"]
  R["적용 단가"]
  A["보정 요소"]
  C["산정 대가"]
  S --> M --> C
  R --> C
  A --> C
```

| 구성요소 | 책임 |
|:---|:---|
| 범위 기준선 | **산정 대상·작업 경계** 확정 |
| 규모·공수 모델 | **기능점수·WBS·생산성**으로 노력 산정 |
| 적용 단가 | 규모·공수를 **화폐 비용**으로 환산 |
| 보정 요소 | **연계·성능·운영 조건** 영향 반영 |
| 산정 대가 | 기본 비용·보정·**예비비** 합산 |

### 쉽게 이해하기 (학습용)

- 승인 범위의 규모와 공수에 단가와 보정 요소를 적용한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **WBS·FP·생산성 근거**: 작업분할구조, 기능점수, 생산성으로 승인 범위의 공수를 설명하는 자료이다.
- **규모·공수·기본 비용**: 작업량과 투입 노력 및 직무 단가 적용 전후의 기본 산정 결과이다.
- **단가·보정·예비비 내역**: 계약 대가를 확정하기 위해 검토하는 비용 구성 정보이다.

</details>

```mermaid
sequenceDiagram
    participant B as 발주자
    participant E as 산정자
    participant M as 산정 모델
    participant R as 검토자
    B->>E: 요구 범위·산정 시점
    E->>M: 1. WBS·FP·생산성 근거
    M-->>E: 2. 규모·공수·기본 비용
    E->>R: 3. 단가·보정·예비비 내역
    R-->>E: 누락·중복·단가 검토 결과
    E-->>B: 대가 기준선·불확실성·변경 조건
```

**동작 원리**

- **1. WBS·FP·생산성 근거**: 승인 범위의 규모와 공수 산정
- **2. 규모·공수·기본 비용**: 직무 단가를 적용할 비용 기준 제공
- **3. 단가·보정·예비비 내역**: 중복·가정·위험을 검토해 대가 확정

> 요약: 승인 범위의 규모·공수에 단가와 보정 근거를 적용해 계약 비용 확정

### 쉽게 이해하기 (학습용)

- 일의 범위와 규모에 단가와 위험 보정을 적용하고 근거를 함께 남긴다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **상향식 산정(Bottom-up Estimation)**: 작업별 규모·공수·단가를 계산한 뒤 합산해 전체 대가를 구하는 방식이다.
- **하향식 산정(Top-down Estimation)**: 유사 사업이나 전문가 판단으로 전체 비용을 먼저 추정한 뒤 배분하는 방식이다.

</details>

| 대가산정 방식 | 상향식 산정 | 하향식 산정 |
|:---|:---|:---|
| 적용 기준 | 상세 범위의 **계약·정산** 산정 | 정보가 적은 **초기 개략** 추정 |
| 핵심 특징 | 작업별 **규모·공수·단가 합산** | 유사 사업·**전문가 판단** 배분 |
| 한계 | 작업 누락·**상세 산정 비용** | 전문가 편향·**유사성 오판** |

> 요약: 초기 정보가 적으면 하향식, 상세 범위가 있으면 상향식 근거를 사용

### 쉽게 이해하기 (학습용)

- 초기에는 유사 경험값, 계약에는 작업별 규모와 단가를 사용한다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **포함·제외·인수 조건·기준선**: 계약 범위와 완료 판단 및 변경 비교를 명확히 하는 정보이다.
- **가정·오차·재산정 시점·예비비**: 초기 불확실성을 공개하고 견적을 갱신하기 위해 함께 제시하는 요소이다.
- **변경 기능 동일 기준 별도 산정**: 기준선 이후 추가 요구를 최초 산정과 같은 규칙으로 분리 계산하는 원칙이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 포함·제외 범위가 모호해 계약 당사자 해석 상충 | **포함·제외·인수 조건·기준선** 명시 | **계약 해석 차이** 감소 |
| 단일 견적값만 제시해 초기 불확실성 은폐 | **가정·오차·재산정 시점·예비비** 제시 | **초기 불확실성** 공개 |
| 낙관적 생산성으로 일정·공수를 과소 산정 | **유사 실적·팀 역량·개발 환경**으로 보정 | **일정·비용 부족** 방지 |
| 같은 난이도를 규모와 보정 요소에 이중 반영 | **보정 항목 정의·중복 검토** | **난이도 이중 반영** 차단 |
| 기준선 이후 변경을 원계약에 흡수해 비용 분쟁 | **변경 기능 동일 기준 별도 산정** | **추가 요구 대가** 확보 |

> 적용 사례: 공공 소프트웨어 발주는 기능 규모와 단가 근거로 개발비 산정

### 쉽게 이해하기 (학습용)

- 사용자 기능 규모와 적용 가능한 가격 근거를 대조해 개발비를 정한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **하향식**: 정보가 적은 초기 단계에서 유사 사업과 전문가 판단으로 개략 비용을 추정하는 방식이다.
- **상향식**: 상세 계약과 변경 정산에서 작업별 규모·공수·단가를 합산하는 방식이다.

</details>

- 초기·저정보는 **하향식**, 상세 계약·변경 정산은 **상향식** 적용

### 쉽게 이해하기 (학습용)

- 최초 범위와 변경 범위를 나눠 같은 산정 기준으로 비용을 다시 계산한다.
