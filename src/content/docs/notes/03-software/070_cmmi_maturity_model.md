## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **역량 진단(Capability Assessment)**: 조직 프로세스의 수행 수준을 증거로 판단하는 활동이다.
- **역량 개선(Capability Improvement)**: 현재 역량을 목표 수준까지 높이는 활동이다.
- **역량 성숙도 모델 통합(Capability Maturity Model Integration, CMMI)**: 개발•서비스 프로세스 역량을 실천 영역과 수준으로 평가하고 개선 방향을 제시하는 모델이다.
- **성과 편차(Performance Variation)**: 개인 의존 업무로 결과가 달라지는 문제이다.
- **반복 재현 한계(Repeatability Limitation)**: 동일한 성공을 조직적으로 반복하기 어려운 문제이다.

</details>

- 정의/개념: **역량 성숙도 모델 통합**은 조직의 개발•서비스 프로세스 역량을 수준별로 진단하고 개선 방향을 제시하는 모델이다.
- 배경/필요성: 개인 의존 업무에서는 **성과 편차**와 **반복 재현 한계**가 발생한다.

#### 한줄 요약

- **역량 진단**과 **역량 개선**을 연결하는 **역량 성숙도 모델 통합**이 핵심이다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **수준 체계(Level Structure)**: 실천 영역과 조직의 개선 단계를 연결한 구조이다.
- **객관적 증거(Objective Evidence)**: 측정값•문서•업무 기록처럼 실천 수행을 확인할 수 있는 자료이다.
- **사업 성과 개선**: 등급 획득이 아니라 품질•비용•납기 결과를 실제로 높이는 적용 목적이다.

</details>

- 실천 영역과 **수준 체계**로 개선 경로를 제시한다.
- **객관적 증거**로 실천 수행과 성과 평가한다.
- 등급 획득보다 **사업 성과 개선**이 적용 목적이다.

#### 한줄 요약

- **수준 체계**, **객관적 증거**, **사업 성과 개선**이 핵심이다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **실천 영역(Practice Area)**: 특정 역량을 달성하기 위한 관련 실천의 묶음이다.
- **평가(Appraisal)**: 객관적 증거를 CMMI 실천과 대조해 구현 상태를 판정하는 공식 활동이다.
- **수준 격차 원인(Level-gap Cause)**: 현재 수준과 목표 수준의 차이를 만든 이유이다.
- **개선 조치(Improvement Action)**: 수준 격차를 줄일 후속 과제이다.

</details>

```text
[사업 목표]
     |
[실천 영역]
     |
[객관적 증거]
     |
   [평가]
     |
[개선 과제]
```

선의 의미: 사업 목표는 필요한 실천 영역을 정하고, 객관적 증거는 해당 실천의 수행 상태를 입증하며, 평가는 증거를 기준으로 개선 과제를 식별한다.

| 구성요소 | 책임 |
|:---|:---|
| 사업 목표 | 품질•비용•납기 개선 목표 정의 |
| 실천 영역 | 목표 달성에 필요한 관련 실천 묶음 제공 |
| 객관적 증거 | 실천 수행의 측정값•업무 기록 제시 |
| 평가 | 증거와 실천의 충족 여부 판정 |
| 개선 과제 | **수준 격차 원인**과 **개선 조치** 관리 |

#### 한줄 요약

- **실천 영역**, **평가**, **수준 격차 원인**, **개선 조치**의 연결 구조가 핵심이다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **증거 저장소(Evidence Repository)**: 업무 기록•측정값•문서를 실천 영역과 연결해 보관하는 저장소이다.
- **증거 매핑(Evidence Mapping)**: 각 실천을 객관적 자료와 연결하는 작업이다.
- **평가 보고서(Appraisal Report)**: 실천 영역별 평가 결과를 정리한 산출물이다.
- **격차 보고서(Gap Report)**: 목표 대비 수준 차이를 정리한 산출물이다.
- **개선 과제 보고서(Action Report)**: 후속 개선 조치를 정리한 산출물이다.
- **실천 영역•목표 수준 선정**: 사업 목표와 위험에 필요한 평가 범위와 도달 수준을 정하는 동작이다.
- **실천 기록•성과 증거 수집**: 반복 수행 기록과 품질•비용•납기 측정값을 모으는 동작이다.
- **실천•증거 매핑과 격차 평가**: 객관적 증거를 실천 기준과 대조해 현재 수준과 원인을 판정하는 동작이다.
- **개선 과제 우선순위 결정**: 사업 영향과 수준 격차를 바탕으로 후속 조치 순서를 정하는 동작이다.
- **개선 실행•성과 재측정**: 과제를 업무에 적용하고 사업 성과 변화를 다시 측정하는 동작이다.

</details>

```text
+------------------------------------------+
| 반복 범위: 목표 사업 성과를 달성할 때까지 |
|                                          |
| [1. 실천 영역•목표 수준 선정]           |
|                 |                        |
|                 v                        |
| [2. 실천 기록•성과 증거 수집]           |
|                 |                        |
|                 v                        |
| [3. 실천•증거 매핑과 격차 평가]         |
|                 |                        |
|                 v                        |
| [4. 개선 과제 우선순위 결정]            |
|                 |                        |
|                 v                        |
| [5. 개선 실행•성과 재측정] -------------+
+------------------------------------------+
```

### 동작 원리

1. **실천 영역•목표 수준 선정**: 평가 범위•수준을 결정한다.
2. **실천 기록•성과 증거 수집**: **증거 저장소**에 수행•효과 자료를 확보한다.
3. **실천•증거 매핑과 격차 평가**: **증거 매핑**으로 충족도•원인을 판정하고 **평가 보고서**와 **격차 보고서**를 만든다.
4. **개선 과제 우선순위 결정**: 사업 영향별 조치를 정렬한다.
5. **개선 실행•성과 재측정**: **개선 과제 보고서**의 조치를 적용하고 효과를 확인한다.

> 요약: 사업 목표에 맞는 실천을 적용하고 객관적 증거로 평가해 반복을 개선한다.

#### 한줄 요약

- **실천•증거 매핑과 격차 평가** 및 **개선 실행•성과 재측정**의 순환이 핵심이다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **성숙도 수준(Maturity Level)**: 조직 전체의 실천 영역 집합을 0~5단계로 평가한 수준이다.
- **능력도 수준(Capability Level)**: 개별 실천 영역의 수행 완전성을 0~3단계로 평가한 수준이다.
- **불완전(Incomplete)**: 필요한 실천이 수행되지 않거나 목표를 달성하지 못한 수준이다.
- **초기(Initial)**: 실천이 임시적•반응적으로 수행되어 결과 편차가 큰 수준이다.
- **관리(Managed)**: 실천을 계획•수행•측정하고 책임과 자원을 관리하는 수준이다.
- **정의(Defined)**: 조직 표준 프로세스를 프로젝트 특성에 맞게 재단해 사용하는 수준이다.
- **정량 관리(Quantitatively Managed)**: 통계•정량 기법으로 프로세스 성과를 통제하는 성숙도 수준이다.
- **최적화(Optimizing)**: 정량 근거로 원인을 제거하고 지속 혁신하는 최고 성숙도 수준이다.

</details>

| CMMI 평가 수준 | 성숙도 수준 | 능력도 수준 |
|:---|:---|:---|
| 적용 기준 | 조직 전체의 통합 개선•비교 | 개별 영역의 선택적 개선 |
| 핵심 특징 | 실천 영역 집합의 0~5단계 | 개별 실천 영역의 0~3단계 |
| 한계 | 등급 중심의 형식화 위험 | 영역 간 통합 최적화 부족 |

| 수준 | 성숙도 수준 | 능력도 수준 |
|:---|:---|:---|
| 0 | **불완전** | **불완전** |
| 1 | **초기** | **초기** |
| 2 | **관리** | **관리** |
| 3 | **정의** | **정의** |
| 4 | **정량 관리** | 적용하지 않음 |
| 5 | **최적화** | 적용하지 않음 |

> 요약: 전사 개선은 성숙도 수준, 특정 실천 영역 개선은 능력도 수준으로 확인한다.

#### 한줄 요약

- 조직 전체는 **성숙도 수준**, 개별 영역은 **능력도 수준**으로 평가한다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **사업 목표(Business Objective)**: 프로세스 개선으로 달성할 품질과 비용 및 납기 목표이다.
- **실천 효과(Practice Effect)**: 개선 실천이 사업 성과에 기여한 결과이다.
- **재단(Tailoring)**: 조직 표준 프로세스를 프로젝트의 규모•위험•업무 특성에 맞게 조정하는 활동이다.
- **종단 흐름(End-to-End Flow)**: 요청 시작부터 제품•서비스 전달까지 조직 경계를 잇는 전체 업무 흐름이다.
- **증거 자동 축적**: 업무 도구에서 발생한 승인•시험•변경•측정 기록을 실천 영역과 연결해 상시 보존하는 방식이다.
- **위험별 재단 기준(Risk-based Tailoring)**: 실패 영향에 따라 적용할 표준 절차를 정한 규칙이다.
- **규모별 재단 기준(Size-based Tailoring)**: 복잡도와 인원에 따라 절차를 조정하는 규칙이다.
- **조직 간 지표(Cross-organizational Metric)**: 인계 대기•종단 리드타임처럼 여러 조직의 연결 성과를 함께 측정하는 값이다.
- **목표 필요 수준(Target-required Level)**: 사업 목표와 위험을 달성하는 데 필요한 범위까지만 정한 성숙도•능력도 수준이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 평가 등급 자체가 목표가 되어 성과 개선과 분리 | **사업 목표**와 **실천 효과** 직접 연결 | 성과 중심 개선 유지 |
| 평가 직전에 증거를 작성해 실제 수행과 불일치 | 업무 도구의 **증거 자동 축적** | 실제 수행과 기록 일치 |
| 모든 프로젝트에 같은 절차를 적용해 통제 과잉 | **재단**, **위험별 재단 기준**, **규모별 재단 기준** 적용 | 과도한 통제 방지 |
| 단위 조직만 최적화해 인접 조직 병목 증가 | **종단 흐름**과 **조직 간 지표** 검토 | 연결 조직 병목 개선 |
| 최고 수준을 무조건 추구해 개선 투자 낭비 | **목표 필요 수준**까지만 개선 | 고수준 과잉 투자 방지 |

> 적용 사례: 반복되는 배포 실패에 품질보증 실천을 적용하고 실패율 변화를 측정

#### 한줄 요약

- **재단**, **종단 흐름**, **증거 자동 축적**, **목표 필요 수준**이 핵심이다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **평가 범위 선택 기준**: 개선 대상이 조직 전체인지 특정 실천 영역인지에 따라 성숙도 수준과 능력도 수준 중 하나를 정하는 기준이다.

</details>

- **평가 범위 선택 기준**에 따라 전사 통합 개선은 **성숙도 수준**, 특정 영역 개선은 **능력도 수준**을 적용한다.

#### 한줄 요약

- 개선 범위에 맞는 **평가 범위 선택 기준**이 핵심이다.
