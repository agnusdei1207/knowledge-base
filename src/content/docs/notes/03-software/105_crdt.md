## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **충돌 없는 복제 데이터 유형(Conflict-free Replicated Data Type, CRDT)**: 여러 복제본의 동시 변경을 중앙 조정 없이 결정적으로 병합해 같은 값으로 수렴시키는 분산 자료형이다.

</details>

- 정의/개념: 복제본이 중앙 조정 없이 동시 변경을 수행하고 교환 순서와 무관한 결정적 병합으로 같은 상태에 수렴하는 **충돌 없는 복제 데이터 유형(Conflict-free Replicated Data Type, CRDT)**
- 배경/필요성: 분할 중 중앙 조정에 의존하면 **로컬 쓰기 가용성** 저하

#### 한줄 요약

- 각자 고친 사본을 어떤 순서로 합쳐도 같은 결과가 되게 만든 자료형이다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **결정적 수렴**: 변경 전달 순서와 중복에 관계없이 모든 복제본이 같은 결과에 도달하는 특성이다.
- **무조정 로컬 쓰기**: 중앙 합의나 원격 복제본 응답을 기다리지 않고 각 노드에서 변경을 수용하는 방식이다.
- **업무 불변식**: 자료형의 값이 수렴한 뒤에도 반드시 참이어야 하는 재고•한도 같은 업무 규칙이다.

</details>

- 중앙 합의 없이 복제본별 **무조정 로컬 쓰기** 허용
- 교환•결합•멱등 규칙으로 전달 순서와 무관한 **결정적 수렴**
- 자료형 수렴과 별도로 조정해야 하는 **업무 불변식**

#### 한줄 요약

- 기술적으로 같은 값에는 도달하지만 그 값이 업무상 옳은지는 별도로 확인해야 한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **인과 메타데이터**: 변경의 선후 관계와 동시성 및 중복 여부를 식별하는 구성요소이다.
- **충돌 없는 복제 데이터 유형(Conflict-free Replicated Data Type, CRDT)**: 복제본 상태와 변경 단위 및 결정적 병합 규칙으로 중앙 조정 없이 수렴하는 자료형이다.
- **복제본 상태**: 각 노드가 독립적으로 읽고 갱신하는 자료형의 현재 값이다.
- **변경 단위**: 복제본 사이에 전달할 전체 상태•델타•연산으로 표현한 갱신이다.
- **병합•적용 함수**: 교환•결합•멱등 또는 연산 교환 법칙으로 동일 결과를 만드는 함수이다.
- **전파•안티엔트로피(Anti-Entropy)**: 누락된 변경을 반복 교환해 복제본 차이를 줄이는 동기화 활동이다.

</details>

#### 한줄 요약

- 사본과 변경표, 순서표, 합치는 규칙, 전달 담당자로 구성된다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **4. 병합 상태**: 교환•결합•멱등 규칙으로 각 복제본에서 동일한 결과를 계산하는 단계이다.
- **1. 델타•연산**: 로컬 갱신에서 다른 복제본에 전달할 최소 상태 차이나 변경 명령을 추출한 정보이다.
- **2. 변경 단위**: 전파 계층이 대상 복제본으로 전달하는 상태•델타•연산이다.
- **3. 인과 메타데이터•상태**: 변경의 선후•동시성과 대상 복제본의 누락 범위를 판정하는 자료이다.
- **5. 수렴 상태 확인**: 충분한 변경 전파 뒤 모든 복제본의 값이 같아졌는지 검증하는 단계이다.

</details>

```mermaid
sequenceDiagram
    participant U as 사용자
    participant A as 복제본 A
    participant X as 전파 계층
    participant B as 복제본 B
    U->>A: 로컬 변경 요청
    A-->>U: 반영 결과
    loop 누락 변경 존재
        A->>X: 1. 델타•연산
        X->>B: 2. 변경 단위
        B->>A: 3. 인과 메타데이터•상태
        A-->>B: 4. 병합 상태
    end
    A->>B: 5. 수렴 상태 확인
    B-->>A: 복제본 상태
```

**동작 원리**

1. **델타•연산**: 로컬 갱신에서 다른 복제본에 필요한 변경 추출
2. **변경 단위**: 전파 계층이 상태 차이 또는 연산을 대상 복제본에 전달
3. **인과 메타데이터•상태**: 독립 변경의 선후•동시성과 누락 범위 확인
4. **병합 상태**: 교환•결합•멱등 규칙으로 동일 결과 계산
5. **복제본 상태**: 충분한 전파 뒤 각 복제본의 값 일치 판정

#### 한줄 요약

- 두 사본이 변경표를 주고받아 같은 값이 되었는지와 그 값이 업무상 허용되는지를 확인한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **상태 기반 충돌 없는 복제 데이터 유형(State-based Conflict-free Replicated Data Type, State-based CRDT)**: 전체 상태나 델타를 교환하고 멱등 병합해 수렴하는 동기화 방식이다.
- **연산 기반 충돌 없는 복제 데이터 유형(Operation-based Conflict-free Replicated Data Type, Operation-based CRDT)**: 변경 연산을 신뢰성 있게 전달하고 교환 가능한 순서로 적용해 수렴하는 방식이다.

</details>

| 충돌 없는 복제 데이터 유형(Conflict-free Replicated Data Type, CRDT) 동기화 방식 | 상태 기반 CRDT | 연산 기반 CRDT |
|:---|:---|:---|
| 적용 기준 | 중복•순서 변경을 허용하는 **상태 교환** | 신뢰성 있는 **연산 전달** 가능 |
| 핵심 특징 | 상태•델타의 **멱등 병합** | **교환 가능한 연산** 적용 |
| 한계 | **상태•메타데이터 크기** 증가 | **유실•중복•순서** 전달 조건 |

#### 한줄 요약

- 현재 상태를 합치거나 변경 명령을 전달하되 어느 쪽도 합치는 규칙이 핵심이다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **승자•보존 규칙**: 동시 변경에서 어느 값을 선택하고 어떤 정보를 모두 남길지 자료형별로 정한 병합 의미이다.
- **별도 합의•사전 예약**: 자동 병합으로 지킬 수 없는 재고•한도를 정족수 합의나 자원 선점으로 보호하는 방식이다.
- **메타데이터 압축•삭제 이력 정리**: 인과 관계와 삭제 표식이 무한히 쌓이지 않도록 안전한 시점에 줄이는 관리 활동이다.
- **내구 전달•멱등 적용**: 연산을 잃지 않고 전송하며 중복 수신해도 같은 효과만 남기는 수렴 조건이다.
- **단절•재접속•재정렬 시험**: 네트워크 분할과 복구 및 메시지 순서 변경에서도 복제본이 수렴하는지 확인하는 시험이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 동시 변경의 승자•보존 규칙이 없으면 사용자 의도 왜곡 | 자료형별 **승자•보존 규칙** 명시 | **동시 편집 의미** 보존 |
| 재고•한도 불변식은 자동 병합만으로 보장 불가 | **별도 합의•사전 예약** 적용 | **업무 불변식 위반** 방지 |
| 장기 오프라인 복제본은 인과 메타데이터 누적 | **메타데이터 압축•삭제 이력 정리** | **저장 공간 증가** 통제 |
| 연산 유실•중복•재정렬은 수렴 조건 훼손 | **내구 전달•멱등 적용** | **연산 기반 수렴** 보장 |
| 정상 환경 시험만 하면 분할 복구 오류 미검출 | **단절•재접속•재정렬 시험** | **장애 후 수렴 조건** 검증 |

#### 한줄 요약

- 동시에 편집한 글은 자동으로 합칠 수 있어도 문장의 의미가 자연스러운지는 사람이 확인해야 한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **합의**: 자동 병합만으로 업무 불변식을 보존할 수 없을 때 적용하는 조정 방식이다.
- **충돌 없는 복제 데이터 유형(Conflict-free Replicated Data Type, CRDT)**: 병합 규칙만으로 업무 불변식이 보존되는 데이터에 적용하는 무조정 수렴 방식이다.

</details>

- 업무 불변식이 병합으로 보존되면 **충돌 없는 복제 데이터 유형(Conflict-free Replicated Data Type, CRDT)** 적용, 보존되지 않으면 **합의** 적용

#### 한줄 요약

- 사본을 같은 값으로 맞추는 기술이지 모든 업무 충돌을 옳게 판단하는 기술은 아니다.
