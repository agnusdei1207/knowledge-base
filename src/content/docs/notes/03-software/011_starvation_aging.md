## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **기아(Starvation)**: 높은 우선순위 작업에 계속 밀려 특정 작업이 실행 기회를 얻지 못하는 상태
- **에이징(Aging)**: 누적 대기시간에 따라 작업 우선순위를 높여 기아를 방지하는 기법

</details>
- 정의/개념: **기아와 에이징** 은 각각 저순위 작업이 실행 기회를 얻지 못하는 상태와 누적 대기시간에 따라 우선순위를 높여 이를 막는 **스케줄링 문제•예방 기법**
- 배경/필요성: 고순위 작업이 계속 도착하면 고정 우선순위의 **저순위 작업 무기한 대기**

#### 한줄 요약

- 누적 대기시간에 따른 **우선순위 상향**으로 기아 방지

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **상향 주기(Boost Interval)**: 우선순위를 올리는 시간 간격
- **상향 폭(Boost Step)**: 한 번에 올리는 우선순위 단계
- **우선순위 상한(Priority Ceiling)**: 작업이 도달할 수 있는 최고 순위

</details>

- **누적 대기시간 기반 상향** 으로 장기 대기 작업 실행 보장
- **상향 주기•폭•상한** 이 최대 대기시간 결정
- **우선순위 상한** 으로 긴급 작업의 순위 영역 보존

#### 한줄 요약

- 상향 주기•폭•상한으로 **대기 보장•긴급성** 절충

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **대기시간 계수기(Waiting-time Counter)**: 작업별 누적 대기시간을 기록해 에이징 입력으로 제공하는 장치
- **우선순위 준비 큐**: 보정된 우선순위 순서로 실행 후보를 보관하는 대기열
- **스케줄러(Scheduler)**: 보정 우선순위로 다음 작업을 선택하는 구성요소
- **디스패치(Dispatch)**: 선택한 작업에 CPU 제어권을 넘기는 처리

</details>

```text
[대기시간 계수기] -- [에이징 정책] -- [우선순위 준비 큐]
                                              |
                                         [스케줄러]
```

선의 의미: 에이징 정책은 대기시간 계수기의 값을 우선순위에 반영하고, 우선순위 준비 큐는 그 결과를 스케줄러가 선택할 수 있도록 보관한다.

| 구성요소 | 책임 |
|:---|:---|
| 대기시간 계수기 | **누적 대기시간 산출** |
| 에이징 정책 | **보정 우선순위 계산** |
| 우선순위 준비 큐 | **실행 후보 정렬** |
| 스케줄러 | **작업 선택•디스패치** |

- **보정 우선순위**: 기본 우선순위 + 대기 주기 수 × 상향 폭
- **우선순위 상한**: 보정값이 긴급 작업의 순위 영역을 넘지 않도록 제한

#### 한줄 요약

- 대기시간 계수와 **에이징 정책** 기반 우선순위 보정

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **대기시간 누적**: 준비 큐 진입 이후 실행되지 않은 시간을 계속 합산하는 단계
- **상향 시점 판정**: 누적 대기시간이 설정한 에이징 주기에 도달했는지 확인하는 단계
- **보정 우선순위 계산**: 대기 주기 수와 상향 폭을 반영하되 상한으로 제한하는 단계
- **준비 큐 재정렬**: 보정된 우선순위에 맞춰 실행 후보 순서를 갱신하는 단계
- **최고 우선순위 선택**: 큐 선두 작업을 디스패치하고 나머지는 대기를 이어 가는 단계

</details>

```text
┌──────────────────────────────┐
│ 준비 큐 진입                │
└──────────────┬───────────────┘
               ▼
╔══════════════════════════════╗
║ 반복: 해당 작업이 대기 중   ║
║                              ║
║ 1. 대기시간 누적            ║
║            │                 ║
║            ▼                 ║
║ 2. 상향 시점 판정           ║
║   ├─ 도래 ─▶ 3. 보정        ║
║   │            우선순위 계산║
║   │               │          ║
║   │               ▼          ║
║   │       4. 준비 큐 재정렬 ║
║   │               │          ║
║   └─ 미도래 ──────┤          ║
║                   ▼          ║
║ 5. 최고 우선순위 선택       ║
║   ├─ 다른 작업 ─▶ 반복      ║
║   └─ 해당 작업 ─▶ 반복 종료 ║
╚══════════════╤═══════════════╝
               ▼
         [작업 디스패치]
```

**동작 원리**

- **1. 대기시간 누적**: 재등록•선점 뒤에도 대기시간 합산
- **2. 상향 시점 판정**: 에이징 주기 도달 여부 확인
- **3. 보정 우선순위 계산**: 상향 폭 반영 후 상한 적용
- **4. 준비 큐 재정렬**: 보정 우선순위로 실행 후보 갱신
- **5. 최고 우선순위 선택**: 큐 선두 작업 디스패치

#### 한줄 요약

- 대기 지속 시 **우선순위 보정•재정렬** 반복

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **고정 우선순위**: 대기시간과 무관하게 작업의 초기 우선순위를 유지하는 정책
- **에이징 적용**: 누적 대기시간에 따라 작업 우선순위를 단계적으로 높이는 정책

</details>

| 우선순위 정책 | 에이징 적용 | 고정 우선순위 |
|:---|:---|:---|
| 적용 기준 | **최대 대기시간 제한** | 중요도 순서 **고정** |
| 핵심 특징 | 누적 대기시간에 따른 **우선순위 상향** | 초기 **우선순위 유지** |
| 한계 | 긴급 작업의 **우선순위 희석** | 저우선 작업의 **기아** |

> 요약: 최대 대기 제한은 **에이징**, 중요도 순서 고정은 **고정 우선순위** 선택

#### 한줄 요약

- 최대 대기 제한은 **에이징**, 중요도 고정은 고정 방식

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **예약 몫(Reserved Share)**: 긴급 작업이 항상 쓸 수 있도록 실행 자원의 일부를 보장한 비율
- **상위 백분위(Upper Percentile)**: 대기시간을 정렬했을 때 대부분의 작업이 넘지 않는 상단 경곗값
- **중요도 등급(Criticality Class)**: 지연이나 실행 실패가 시스템에 미치는 영향에 따라 작업을 나눈 단계

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 상향 속도가 느려 **최대 대기시간 초과** | 대기시간 분포로 **상향 주기•폭 산정** | **기아 방지 목표** 충족 |
| 상향 속도가 빨라 긴급 작업의 **우선순위 희석** | **우선순위 상한•예약 몫** 과 중요도 등급 분리 | **긴급 작업 실행 기회** 보호 |
| 작업 재등록 시 대기시간 초기화로 **상향 기준 미도달** | 최초 대기 시각과 **누적 대기시간 보존** | 재등록 작업의 **기아 방지** |
| 평균 대기시간만 보면 소수 작업의 **기아 은폐** | 작업별 최대•**상위 백분위 대기시간** 감시 | **장기 대기 작업** 조기 탐지 |

#### 한줄 요약

- 상위 백분위 대기시간으로 **에이징 강도** 조정

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **최대 대기 목표**: 상향 주기와 폭을 정하는 응답 기준
- **긴급 작업 보호**: 우선순위 상한을 정하는 중요도 기준

</details>

- 최대 대기를 넘기면 **상향 주기 단축**, 긴급 작업이 밀리면 **상향 폭•상한 축소**

#### 한줄 요약

- 최대 대기와 긴급 작업 보호를 함께 만족하는 **상향값 설정**
