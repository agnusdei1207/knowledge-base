## 미리 알고가기

- **그래프 DB(Graph Database)**: ‘그래프 디비’로 읽으며, 개체와 연결 관계를 노드·관계로 직접 저장함
- **노드 (Node)**: 그래프의 개체를 표현함
- **관계 (Relationship)**: 노드 사이의 방향 연결을 표현함
- **속성 (Property)**: 노드·관계의 값을 저장함
- **속성 그래프 (Property Graph)**: 노드·관계에 레이블·속성을 부여함
- **사이퍼 (Cypher)**: 그래프 패턴과 경로를 선언함
- **p95(95th Percentile Latency)**: ‘피 구십오’로 읽으며, p는 백분위 표기이고 95는 요청 95%가 완료되는 지연 경계를 뜻함
- **네오포제이(Neo4j)**: 속성 그래프 모델과 Cypher 질의를 제공하는 그래프 데이터베이스임
- **레이블(Label)**: 노드를 같은 역할이나 유형의 집합으로 분류하는 이름임
- **인접 관계(Adjacency)**: 한 노드에 직접 연결된 관계와 이웃 노드의 집합임
- **가변 길이 경로(Variable-length Path)**: 관계를 몇 단계 거칠지 범위로 지정해 탐색하는 경로임
- **분기 계수(Branching Factor)**: 한 노드에서 다음 단계로 확장되는 평균 관계 수임
- **경로 폭발(Path Explosion)**: 분기 계수와 깊이가 커져 후보 경로 수가 급격히 증가하는 현상임

## Ⅰ. 개요

- 정의/개념: 속성 그래프의 **관계 경로를 직접 탐색**하는 저장소
- 기존 한계: 다단계 관계 질의의 **반복 조인 비용 증가**

### 쉽게 이해하기 (학습용)
- 연결선을 저장해 친구의 친구를 선 따라 찾는 데이터베이스임

## Ⅱ. 특징

- **인접 관계 직접 탐색**으로 반복 조인 감소
- 노드·관계·속성으로 **연결 의미 표현**
- 분기·깊이 증가 시 **경로 후보 폭발**

### 쉽게 이해하기 (학습용)
- 탐색은 자연스럽지만 시작점과 깊이를 제한해야 범위가 폭발하지 않음

## Ⅲ. 아키텍처 및 구성요소

| 설계 요소 | 설명 |
|:---|:---|
| 노드·레이블 | 개체와 노드 집합을 표현함 |
| 관계·방향 | 노드 연결 의미와 탐색 방향을 표현함 |
| 속성 | 노드와 관계의 상태 및 가중치를 저장함 |
| 인덱스·제약 | 시작 노드와 고유성 규칙을 관리함 |
| Cypher 실행기 | 패턴을 관계 확장 연산으로 변환함 |

```text
  경로해석
      ↓
  시작탐색
      ↓
  관계확장
      ↓
  속성필터
```

> 요약: 노드와 관계 구조를 실행기가 경로로 확장함

### 쉽게 이해하기 (학습용)
- 노드와 관계 및 속성을 인덱스와 실행기가 탐색함

## Ⅳ. 원리 및 절차 흐름도

```text
  질의해석
      ↓
  시작탐색
      ↓
  관계확장
      ↓
  조건판정
      ↓
  결과반환
```

| 절차 | 설명 |
|:---|:---|
| 질의해석 | 노드와 관계 조건을 연산자로 변환함 |
| 시작탐색 | 인덱스로 시작 노드를 탐색함 |
| 관계확장 | 유형과 방향 및 깊이로 인접 경로를 확장함 |
| 조건판정 | 속성 조건으로 후보 경로를 제한함 |
| 결과반환 | 일치하는 노드와 관계 및 경로를 반환함 |

> 요약: 시작 노드에서 유형과 방향 및 깊이로 경로를 확장함

### 쉽게 이해하기 (학습용)
- 시작 노드에서 관계 유형과 방향 및 깊이로 경로를 확장함

## Ⅴ. 종류 및 비교

| 데이터 모델 | Neo4j | 관계형 데이터베이스 |
|:---|:---|:---|
| 적용 기준 | 다단계 **연결·경로 분석** | 정형 거래·**표 집계** |
| 핵심 특징 | 노드의 **인접 관계 확장** | 외래키 기반 **테이블 조인** |
| 한계 | 분기·깊이의 **경로 폭발** | 다단계 조인의 **중간 결과 증가** |

> 요약: Neo4j는 저장된 경로를 확장하고 관계형 DB는 조인함

### 쉽게 이해하기 (학습용)
- 관계형 DB는 조인하고 Neo4j는 저장된 경로를 확장함

## Ⅵ. 실무 사례

1. 권한 경로를 **방향 관계로 탐색**

### 쉽게 이해하기 (학습용)
- 접근 권한 그래프는 사용자에서 역할·자원 방향으로만 탐색해 실제 권한 도달 경로와 지연을 확인함

## Ⅶ. 결론

- 연결 경로는 **Neo4j**, 정형 거래는 **관계형**

### 쉽게 이해하기 (학습용)
- Neo4j는 연결 경로 자체가 답일 때 유용하며 시작점·관계 유형·방향·깊이를 제한해야 탐색 비용을 예측할 수 있음
