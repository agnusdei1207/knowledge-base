## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **데이터 패브릭(Data Fabric)**: 활성 메타데이터를 이용해 분산 데이터의 탐색•통합•계보•정책 집행을 연결하고 자동화하는 기술 아키텍처이다.

</details>

- 정의/개념: 활성 메타데이터를 이용해 분산 데이터의 탐색•통합•계보•정책 집행을 연결하고 자동화하는 **데이터 패브릭(Data Fabric)**이다.
- 배경/필요성: 저장소별 개별 연계는 검색•계보•정책 경로의 중복과 불일치를 유발한다.

#### 한줄 요약

- 분산 데이터 저장소의 위치•관계•접근 정책을 활성 메타데이터와 지식 그래프로 관리한다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **활성 메타데이터**: 설계 정보뿐 아니라 실행•사용•품질•변경 신호를 자동화 판단에 활용하는 메타데이터이다.
- **지식 그래프(Knowledge Graph)**: 데이터 자산•업무 용어•소유자•계보•정책의 관계를 연결한 그래프이다.
- **통합 통제**: 가상화•복제•파이프라인 등 모든 데이터 접근 경로에 같은 정책을 적용하는 방식이다.

</details>

- 실행•사용•품질 신호를 자동 판단에 연결하는 **활성 메타데이터**가 핵심이다.
- 자산•용어•소유자•계보 관계를 연결한 **지식 그래프**가 핵심이다.
- 모든 데이터 접근 경로에 정책을 적용하는 **통합 통제**가 핵심이다.

#### 한줄 요약

- 자동 안내가 똑똑해도 지도 정보가 낡으면 잘못된 자료를 찾거나 잘못된 문을 열 수 있다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **정책 엔진**: 접근•마스킹•감사 규칙을 판정하는 구성요소이다.
- **집행점**: 판정된 정책을 실제 데이터 경로에 적용하는 구성요소이다.
- **커넥터**: 분산 저장소와 메타데이터 수집 계층을 연결하는 구성요소이다.
- **스캐너**: 구조•사용•품질•변경 메타데이터를 수집하는 구성요소이다.
- **카탈로그**: 데이터 자산의 위치•스키마•소유자를 관리하는 구성요소이다.
- **통합 계층**: 가상화•복제•파이프라인으로 데이터를 연결하는 계층이다.
- **접근 계층**: 소비자에게 통제된 데이터 사용 경로를 제공하는 계층이다.
- **관측**: 품질•지연•사용•실패 신호를 수집하는 기능이다.
- **자동화**: 관측 신호를 바탕으로 규칙과 경로를 보정하는 기능이다.

</details>

```text
[데이터 패브릭]
       |
       +-- [커넥터•스캐너]
       |
       +-- [카탈로그•지식 그래프]
       |
       +-- [통합•접근 계층]
       |
       +-- [정책 엔진•집행점]
       |
       +-- [관측•자동화]
```

선의 의미: 커넥터•스캐너가 수집한 메타데이터는 카탈로그•지식 그래프에 연결되고, 이 그래프는 통합•접근 계층과 관측•자동화를 지원하며, 정책 엔진•집행점은 실제 접근 경로를 통제한다.

| 구성요소 | 책임 |
|:---|:---|
| 커넥터•스캐너 | **커넥터**와 **스캐너**가 구조•사용•품질•변경 메타데이터 수집 |
| 카탈로그•지식 그래프 | **카탈로그**와 **지식 그래프**가 자산•용어•소유자•계보•정책 관계 관리 |
| 통합•접근 계층 | **통합 계층**과 **접근 계층**이 가상화•복제•파이프라인 경로 제공 |
| 정책 엔진•집행점 | **정책 엔진**과 **집행점**이 접근•마스킹•감사 규칙 적용 |
| 관측•자동화 | **관측**과 **자동화**가 품질•지연•사용•실패 신호로 규칙 보정 |

#### 한줄 요약

- 분산 데이터 저장소를 활성 메타데이터와 통합 정책으로 연결한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **활성 메타데이터 수집**: 분산 소스의 구조•품질•계보•사용 신호를 가져오는 단계이다.
- **지식 그래프 관계 갱신**: 자산•용어•소유자•정책의 최신 관계를 연결하는 단계이다.
- **목적•품질 기반 자산 발견**: 소비 조건에 맞는 위치•계보•책임 정보를 찾는 단계이다.
- **정책 판정•접근 경로 집행**: 권한•마스킹•감사 규칙을 실제 데이터 경로에 적용하는 단계이다.
- **관측 신호 기반 자동 보정**: 품질•지연•사용•실패 결과로 규칙과 경로를 갱신하는 단계이다.

</details>

```text
분산 데이터 소스
       |
       v
1. 활성 메타데이터 수집
       |
       v
2. 지식 그래프 관계 갱신
       |
       v
소비자의 목적•품질 조건
       |
       v
3. 목적•품질 기반 자산 발견
       |
       v
4. 정책 판정•접근 경로 집행
       |
       +-- 거부 --> 접근 차단•감사 기록
       |
       +-- 허용 --> 통합 경로로 데이터 제공
                          |
                          v
                 5. 관측 신호 기반 자동 보정
```

### 동작 원리

- **1. 활성 메타데이터 수집**: **활성 메타데이터 수집**은 구조•품질•계보•사용 신호를 확보한다.
- **2. 지식 그래프 관계 갱신**: **지식 그래프 관계 갱신**은 자산•용어•소유자•정책을 연결한다.
- **3. 목적•품질 기반 자산 발견**: **목적•품질 기반 자산 발견**은 조건에 맞는 위치•계보•책임을 탐색한다.
- **4. 정책 판정•접근 경로 집행**: **정책 판정•접근 경로 집행**은 권한•마스킹•감사 규칙을 적용한다.
- **5. 관측 신호 기반 자동 보정**: **관측 신호 기반 자동 보정**은 품질•지연•실패로 규칙•경로를 갱신한다.

#### 한줄 요약

- 지도를 계속 갱신하고 목적과 권한에 맞는 길만 열며 통행 결과로 지도를 다시 고친다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **데이터 메시(Data Mesh)**: 도메인 팀이 데이터 제품의 품질•지원 책임을 지고 연합 정책을 적용하는 운영 모델이다.

</details>

| 데이터 아키텍처 | 데이터 패브릭 | 데이터 메시 |
|:---|:---|:---|
| 적용 기준 | **데이터 패브릭**: 분산 자산 연결•통제 자동화 | **데이터 메시**: 도메인 품질 책임 분산 |
| 핵심 특징 | 활성 메타데이터•지식 그래프 | 데이터 제품•셀프서비스 플랫폼 |
| 한계 | 메타데이터 노후•자동화 오판 | 책임 공백•표준 불일치 |

#### 한줄 요약

- 패브릭은 도로와 교통 규칙, 메시는 각 상점의 상품 책임에 가깝다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **정책 누락**: 일부 데이터 접근 경로가 통제 집행점을 우회해 보안 규칙이 적용되지 않는 문제이다.
- **증분 스캔**: 바뀐 메타데이터만 수집하는 방식이다.
- **변경 감지**: 원천 구조와 정책의 변화를 식별하는 기능이다.
- **최신성 목표**: 변경부터 카탈로그 반영까지 허용할 지연 한도이다.
- **자동 수집**: 실행 로그에서 계보와 사용 정보를 추출하는 기능이다.
- **소유자 검증**: 책임자가 자동 계보의 정확성을 확인하는 활동이다.
- **표본 감사**: 일부 계보 경로를 원천과 대조하는 활동이다.
- **정책 집행점**: 데이터 접근 요청에 권한•마스킹•감사 규칙을 실제 적용하는 통제 지점이다.
- **조건 하향 처리**: 필터 연산을 원천 저장소에서 먼저 수행하는 최적화이다.
- **캐시 기준**: 반복 결과를 별도 계층에 보관할 조건이다.
- **복제 기준**: 원천 데이터를 별도 저장소에 복사할 조건이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 메타데이터가 늦게 갱신되면 잘못된 자산 안내 발생 | **증분 스캔**•**변경 감지**와 **최신성 목표** 설정 | 카탈로그의 현재 상태 반영 보장 |
| 자동 계보 관계가 틀리면 영향 분석 오류 | **자동 수집**•**소유자 검증**•**표본 감사** 적용 | 데이터 계보 정확도 향상 |
| 일부 접근 경로가 집행점을 우회하면 **정책 누락** 발생 | 모든 경로에 **정책 집행점** 적용 | 비인가 데이터의 우회 접근 차단 |
| 가상 질의가 원천에 집중되면 부하•응답 지연 증가 | **조건 하향 처리**•**캐시 기준**•**복제 기준** 설정 | 원천의 스캔 부하•지연 감소 |

#### 한줄 요약

- 지도에 장소가 많다는 것보다 위치와 통행 제한이 실제와 맞는지 계속 확인해야 한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **데이터 패브릭 채택 기준**: 이기종 저장소 통합과 정책 자동화의 우선순위이다.

</details>

- **데이터 패브릭 채택 기준**에 따라 이기종 저장소 통합과 정책 자동화가 우선이면 **활성 메타데이터** 기반 **데이터 패브릭**을 구축한다.

#### 한줄 요약

- 연결망의 가치는 선의 개수가 아니라 지도가 정확하고 잘못 연 문을 바로 찾아 닫을 수 있는지에 달려 있다.
