## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **워킹 셋(Working Set)**: 최근 참조 창에서 프로세스가 사용한 페이지 집합이다.
- **페이지 폴트(Page Fault)**: 참조한 페이지가 물리 메모리에 없을 때 발생하는 예외이다.

</details>

- 정의/개념: **워킹 셋•페이지 폴트 제어**는 최근 참조 페이지 집합과 폴트율로 프로세스의 프레임 수요와 부족 상태를 판단하는 **동적 메모리 할당 기법**이다.
- 배경/필요성: 고정 프레임 배분은 지역성 변화에 맞추지 못해 **반복 폴트•스레싱을 유발한다.

#### 한줄 요약

- 최근 참조와 폴트율에 따른 **동적 프레임 할당**이 핵심이다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **참조 창(Reference Window)**: 워킹 셋에 포함할 페이지를 정하는 시간 또는 참조 횟수 범위이다.
- **상주 집합(Resident Set)**: 프로세스가 물리 메모리에 보유한 페이지 집합이다.
- **페이지 폴트 빈도(Page Fault Frequency, PFF)**: 단위 시간 또는 메모리 참조당 페이지 폴트 발생률이다.

</details>

- **최근 참조 창**으로 현재 지역성의 워킹 셋을 추정한다.
- **상주 집합 부족** 시 재참조 페이지 폴트 증가한다.
- **페이지 폴트 빈도**로 워킹 셋 미수용 상태를 온라인 감지가 핵심이다.

#### 한줄 요약

- 참조 창 크기에 따른 **추정 누락•과대 산정** 절충이 핵심이다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **희생 페이지(Victim Page)**: 빈 프레임이 없을 때 교체 정책이 퇴출 대상으로 고른 상주 페이지이다.
- **프레임 할당기**: 프로세스별 물리 프레임의 할당•회수와 희생 페이지 선택을 수행하는 구성요소이다.
- **워킹 셋 추정기**: 최근 참조 이력에서 반복 사용한 페이지 집합과 목표 프레임 수를 계산하는 구성요소이다.
- **페이지 폴트 처리기**: 부재 페이지를 적재하고 주소 매핑을 갱신한 뒤 중단된 명령을 재실행하는 커널 구성요소이다.

</details>

```text
              [프로세스]
                  |
          [참조•상주 상태]
                  |
         [워킹 셋 추정기]
                  |
        [페이지 폴트 처리기]
                  |
           [프레임 할당기]
```

선의 의미: 선은 페이지 참조 상태, 워킹 셋 추정, 폴트 처리와 프레임 정책이 결합되는 인접 구성요소의 정적 메모리 관리 경계를 뜻한다.

| 구성요소 | 책임 |
|:---|:---|
| 프로세스 | **가상 페이지 참조** |
| 참조•상주 상태 | **이력•상주 관계 기록** |
| 워킹 셋 추정기 | **목표 프레임 계산** |
| 페이지 폴트 처리기 | **페이지 적재•재실행** |
| 프레임 할당기 | **할당•회수•희생 선택** |

#### 한줄 요약

- 참조 이력•폴트 처리•**프레임 할당**의 제어 구조이다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **참조 창 갱신**: 새 페이지 참조를 넣고 관찰 범위 밖의 이력을 제거하는 단계이다.
- **워킹 셋•폴트율 산정**: 최근 고유 페이지 수와 폴트 발생 비율을 계산하는 단계이다.
- **상주 집합 상태 판정**: 목표 워킹 셋과 현재 프레임 수•폴트율 상하한을 비교하는 단계이다.
- **프레임 증설**: 워킹 셋 미수용이나 폴트율 상한 초과 시 프레임을 추가하는 단계이다.
- **프레임 회수**: 폴트율이 하한보다 낮고 여유 프레임이 있으면 일부를 반환하는 단계이다.

</details>

```text
╔════════════════════════════════╗
║ 반복: 관찰 구간마다           ║
║ 1. 참조 창 갱신               ║
║              │                 ║
║              ▼                 ║
║ 2. 워킹 셋•폴트율 산정        ║
║              │                 ║
║              ▼                 ║
║ 3. 상주 집합 상태 판정        ║
║   ├─ 미수용·상한 초과         ║
║   │        └─▶ 4. 프레임 증설 ║
║   ├─ 과잉·하한 미만           ║
║   │        └─▶ 5. 프레임 회수 ║
║   └─ 적정 ─────▶ 할당 유지    ║
╚════════════════╤═══════════════╝
                 ▼
          [다음 관찰 구간]
```

**동작 원리**

- **1. 참조 창 갱신**: 신규 참조 추가•오래된 이력을 제거한다.
- **2. 워킹 셋•폴트율 산정**: 목표 프레임과 부족 신호를 계산한다.
- **3. 상주 집합 상태 판정**: 수요와 폴트율 상하한을 비교한다.
- **4. 프레임 증설**: 미수용 작업에 추가 프레임 할당한다.
- **5. 프레임 회수**: 과잉 작업의 여유 프레임 반환한다.

#### 한줄 요약

- 워킹 셋•폴트율 피드백 기반 **프레임 증감**이 핵심이다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **워킹 셋 방식**: 참조 창의 페이지 집합으로 목표 프레임 수요를 추정하는 방식이다.
- **페이지 폴트 빈도 방식**: 실행 중 관측한 폴트율로 프레임 부족을 사후 감지하는 방식이다.

</details>

| 프레임 수요 판단 방식 | 워킹 셋 | 페이지 폴트 빈도 |
|:---|:---|:---|
| 적용 기준 | 참조 이력•**집합 추적 가능** | 저비용 **온라인 제어** |
| 핵심 특징 | 참조 창으로 **목표 집합 추정** | 폴트율로 **부족 상태 감지** |
| 한계 | 창 크기별 **추정 오차** | 부족 상태 **사후 감지** |

> 요약: **워킹 셋**은 필요량 추정, **폴트 빈도**는 부족 감지가 핵심이다.

#### 한줄 요약

- 필요량 추정은 워킹 셋, 부족 감지는 **폴트 빈도**가 핵심이다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **참조 지역성(Locality of Reference)**: 가까운 시점에 일부 페이지를 반복 참조하는 성질이다.
- **참조 감쇠(Reference Decay)**: 오래된 페이지 참조의 영향을 줄이는 추정 방식이다.
- **다중 시간창(Multi-window)**: 짧은 관찰 구간과 긴 관찰 구간을 함께 쓰는 방식이다.
- **주요 페이지 폴트(Major Page Fault)**: 저장장치 I/O가 필요한 페이지 폴트이다.
- **경미 페이지 폴트(Minor Page Fault)**: 주소 매핑만 복구하면 되는 페이지 폴트이다.
- **꼬리 지연(Tail Latency)**: 요청 지연 분포에서 가장 느린 일부 요청의 지연이다.
- **메모리 압박(Memory Pressure)**: 실행 중인 작업의 메모리 수요가 가용 물리 메모리에 가까워져 회수•교환이 늘어나는 상태이다.
- **회수 우선순위(Reclaim Priority)**: 메모리 부족 때 어떤 작업이나 페이지의 프레임부터 회수할지 정하는 순서이다.
- **서비스 수준(Service Level)**: 응답시간•가용성처럼 서비스가 충족해야 하는 운영 품질 목표이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 짧은 참조 창이 순환 **참조 지역성 누락** | 워크로드 주기•민감도에 따라 **참조 창 조정** | **워킹 셋 추정 정확도** 향상 |
| 긴 참조 창이 과거 페이지를 **상주 집합에 유지** | **감쇠•다중 시간창**과 메모리 압박 시 창 축소 | 불필요한 **프레임 점유** 감소 |
| 폴트율만 보면 순차 최초 접근을 **프레임 부족으로 오인** | 주요•경미 폴트와 **재참조•I/O 대기 분리** | 잘못된 **프레임 증감** 방지 |
| 프레임 회수가 중요 작업의 **꼬리 지연 유발** | 중요도별 최소 상주 집합과 **회수 우선순위** 적용 | **서비스 수준** 보호 |

#### 한줄 요약

- 참조 창•폴트 유형•**서비스 수준** 기반 할당을 조정한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **워킹 셋 미수용**: 프레임 증설을 결정하는 메모리 압박 신호이다.
- **주요 폴트율**: 동시 작업 수 축소를 결정하는 저장장치 부하 신호이다.

</details>

- **워킹 셋 미수용•주요 폴트율 초과** 시 **프레임 증설•작업 수 축소**가 핵심이다.

#### 한줄 요약

- 워킹 셋 미수용•주요 폴트 초과 시 **자원 재조정**이 핵심이다.
