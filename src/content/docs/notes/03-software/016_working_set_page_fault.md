## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **워킹 셋 및 PFF(Working Set & PFF)**: 참조 윈도우($\Delta$) 내 고유 페이지 집합(워킹 셋)과 단위 시간당 페이지 결함 빈도(PFF)를 기준으로 프레임을 동적 할당하는 알고리즘.
- **스왑 폴트 및 스레싱(Swap Fault & Thrashing)**: 가용 메모리 부족으로 디스크 I/O가 폭증하여 CPU가 유휴 상태로 전락하는 성능 붕괴 현상.

</details>

- 정의/개념: 참조 국부성 기반의 **워킹 셋(Working Set)** 크기와 **페이지 폴트 빈도(PFF)** 를 측정하여 프로세스별 물리 프레임을 동적 할당하는 메모리 제어 기법
- 배경/필요성: 고정 프레임 할당에 따른 메모리 과부족 극복 및 시간 흐름에 따른 국부성 변화 대응과 스레싱 방지 필요

#### 한줄 요약

- 워킹 셋으로 필수 프레임 요구량을 추적하고 PFF 상하한선으로 물리 프레임을 동적 조정하여 스레싱을 방지

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **워킹 셋 윈도우(Δ)**: 워킹 셋을 계산하기 위해 최근 참조 이력을 추적하는 시간 창(최근 Δ번의 메모리 참조 또는 시간 단위).
- **참조 국부성(Locality of Reference)**: 프로세스가 최근 참조한 데이터·코드 근처를 반복 참조하는 시간적·공간적 집중 특성.

</details>

- **참조 국부성**에 기반하여 워킹 셋 윈도우(Δ)로 프로세스의 현재 활성 페이지 집합 추정
- Δ 크기에 따라 워킹 셋 크기가 동적으로 변동하여 프레임 요구량 결정
- **PFF** 상한 초과 시 프레임 추가, 하한 미달 시 프레임 회수하는 반응형 조정

#### 한줄 요약

- 참조 국부성 기반 워킹 셋 추적과 PFF 상하한 비교로 물리 프레임을 동적 조정

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **PFF 상하한선(Upper/Lower Bound)**: 페이지 폴트 빈도의 조정 임계값으로, 상한 초과 시 프레임 추가, 하한 미달 시 프레임 회수.

</details>

```text
[ 동적 프레임 할당 구조 ]
프로세스 참조 이력
├─ 워킹 셋 추적기 (Δ 윈도우 내 고유 페이지 집합 계산)
└─ 페이지 폴트 감시기 (PFF 산출·상하한선 비교)
동적 프레임 할당기
├─ PFF > 상한: 프레임 추가 할당
├─ PFF < 하한: 프레임 회수
└─ 상한·하한 사이: 현재 할당 유지
```

선의 의미: 가지(`├─`, `└─`)는 PFF 상태에 따른 프레임 조정 방향 관계

| 구성요소 | 책임 |
|:---|:---|
| 참조 윈도우 (Δ) | 과거 Δ 참조 이력 기반 **워킹 셋** 계산 |
| 워킹 셋 추적기 | 최소 필수 물리 프레임 수 산출 |
| 페이지 폴트 감시기 | **PFF** 산출 및 상하한선과 비교 |
| 동적 프레임 할당기 | PFF 기준 프레임 추가·회수·유지 결정 |

#### 한줄 요약

- 워킹 셋 추적기가 필수 프레임을 산출하고 PFF 감시기가 상하한선과 비교하여 할당기가 프레임을 조정

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **페이지 폴트 갱신(Page Fault Update)**: 페이지 폴트 발생 시 폴트 간격을 측정하여 PFF를 갱신하고 프레임 조정 여부를 판정하는 과정.

</details>

```text
프로세스 메모리 참조
   │
   ▼
1. Δ 윈도우 내 참조 이력 갱신 (워킹 셋 계산)
   │
   ▼
2. PFF 산출 및 상하한선 비교
├─ PFF > 상한 (스레싱 위험): 3a단계
├─ PFF < 하한 (프레임 여유): 3b단계
└─ 적정: 현재 할당 유지
│
▼
3a. 프레임 추가 할당 → 프레임 부족 해소
3b. 여유 프레임 회수 → 타 프로세스 재배분
```

**동작 원리**

1. **참조 이력 갱신**: Δ 윈도우 내 참조된 고유 페이지 집합(**워킹 셋**)을 지속 계산
2. **PFF 산출·비교**: 단위 시간당 페이지 폴트 횟수를 측정하고 상하한선과 비교
3. **프레임 조정**: PFF 상한 초과 시 프레임 추가, 하한 미달 시 여유 프레임 회수

#### 한줄 요약

- 참조 이력으로 워킹 셋을 계산하고 PFF 상하한선 비교로 프레임을 동적 조정

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **워킹 셋 알고리즘(Working Set Algorithm)**: 참조 윈도우마다 워킹 셋을 계산하여 프레임을 조정하는 연속 감시 방식.
- **PFF 알고리즘(Page Fault Frequency Algorithm)**: 페이지 폴트 발생 시에만 폴트 간격을 측정하여 프레임을 조정하는 이벤트 기반 방식.

</details>

| 비교 항목 | 워킹 셋 알고리즘 | PFF 알고리즘 |
|:---|:---|:---|
| 적용 기준 | 정확한 활성 페이지 집합 추적 필요 시 | 낮은 오버헤드로 스레싱 방지 필요 시 |
| 핵심 특징 | Δ 윈도우마다 연속 감시·**워킹 셋** 계산 | 폴트 발생 시에만 **PFF** 측정·조정 |
| 한계 및 위험 | 지속 참조 비트 감시로 CPU 오버헤드 높음 | 폴트 발생 전까지 프레임 과부족 미탐지 |

#### 한줄 요약

- 정확한 활성 집합 추적이 필요하면 워킹 셋, 낮은 오버헤드로 스레싱 방지에는 PFF 선택

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **순차 스캔 오염(Sequential Scan Pollution)**: DB 풀스캔 등 순차적으로 대량 페이지를 1회 참조하는 작업이 워킹 셋에 재참조 가능성 낮은 페이지를 채워 실제 활성 페이지를 축출하는 현상.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 연속 워킹 셋 감시로 CPU 오버헤드 증가 | **PFF** 이벤트 기반 조정으로 전환 | 평시 오버헤드 감소 |
| Δ 크기 부적절로 프레임 과대·과소 할당 | 워크로드 패턴 기반 Δ 동적 조정 | 메모리 할당 균형 확보 |
| **순차 스캔 오염**으로 워킹 셋 정확도 저하 | **LRU-K** 교체 정책으로 재참조 빈도 낮은 페이지 우선 축출 | 실제 활성 워킹 셋 보호 |

#### 한줄 요약

- 오버헤드는 PFF 이벤트 기반으로, Δ 부적절은 동적 조정으로, 순차 스캔 오염은 LRU-K로 해소

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **동적 프레임 할당 기준**: PFF 상하한선·워킹 셋 윈도우 크기(Δ)를 튜닝하여 메모리 과대·과소 할당 없이 스레싱을 방지하는 판단 기준.

</details>

- 정확도 우선 시 **워킹 셋 알고리즘**, 오버헤드 최소화 시 **PFF 알고리즘**을 상호 보완 적용

#### 한줄 요약

- 워킹 셋으로 정확한 프레임 요구량을 추정하고 PFF로 저비용 조정하는 상호 보완 방식 적용
