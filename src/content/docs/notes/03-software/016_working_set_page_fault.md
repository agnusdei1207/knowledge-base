## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **워킹 셋(Working Set)**: 프로세스가 특정 시간 윈도우($\Delta$) 동안 참조한 페이지 집합으로, 상주 집합(Resident Set)의 최소 요구량.
- **PFF(Page Fault Frequency)**: 단위 시간당 페이지 폴트 발생 주기를 계측하여 프레임 할당량을 동적으로 가감하는 알고리즘.

</details>

- 정의/개념: 참조 국부성 기반의 **워킹 셋(Working Set)** 크기와 **페이지 폴트 빈도(PFF)** 를 측정하여 프레임을 동적 조절하는 메모리 관리 기법
- 배경/필요성: 고정 프레임 할당 방식으로는 **프로세스의 동적 참조 국부성 변화 수용 및 페이지 폴트 폭증 스레싱 방지 불가**

#### 한줄 요약
- 워킹 셋을 파악하고 PFF 상하한선으로 프레임을 동적 배분하여 페이지 폴트와 메모리 낭비를 동시에 억제한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **참조 국부성(Locality of Reference)**: 프로그램이 시간적(Temporal) 또는 공간적(Spatial)으로 특정 메모리 영역을 집중 참조하는 성질.
- **워킹 셋 윈도우($\Delta$)**: 워킹 셋을 계산하기 위해 과거를 되돌아보는 관찰 윈도우 크기(참조 횟수 또는 시간 단위).

</details>

- **참조 국부성(시간/공간)** 원리에 기반하여 워킹 셋 윈도우($\Delta$) 내 고유 페이지 집합 추적
- $\Delta$ 파라미터 크기에 따라 워킹 셋 크기($|WS|$)가 가변되며 필요한 물리 프레임 수 확정
- **PFF 상한선 초과 시 프레임 추가 할당, 하한선 미달 시 여유 프레임 회수**

#### 한줄 요약
- 국부성 윈도우 추적과 PFF 임계치 피드백을 통해 물리 메모리를 최적 동적 배분한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **PFF 임계값($F_{\text{upper}}, F_{\text{lower}}$)**: 페이지 폴트 간격이 너무 짧으면($< F_{\text{upper}}$) 프레임을 늘리고, 너무 길면($> F_{\text{lower}}$) 회수하는 기준선.

</details>

```text
[워킹 셋 및 PFF 동적 프레임 제어 아키텍처]
|-- 참조 윈도우 추적기 (최근 $\Delta$ 동안의 참조 비트 벡터 분석 -> $WS(t, \Delta)$ 산출)
|-- PFF 계측 엔진 (Page Fault 인터럽트 발생 간격 $T = t_{\text{current}} - t_{\text{prev}}$ 측정)
`-- 동적 프레임 할당기
    |-- $T < T_{\text{min}}$ (PFF 상한 초과) -> 물리 프레임 추가 할당 (Fault 억제)
    |-- $T > T_{\text{max}}$ (PFF 하한 미달) -> 비활성 프레임 회수 (메모리 재활용)
    `-- $T_{\text{min}} \le T \le T_{\text{max}}$ -> 현재 할당 프레임 수 유지
```

선의 의미: 계층 및 PFF 피드백 제어 구조

| 구성요소 | 책임 |
|:---|:---|
| **참조 윈도우 ($\Delta$)** | 최근 과거 참조 기록을 관찰하여 프로세스의 **워킹 셋($WS$)** 크기 산정 |
| **PFF 계측 엔진** | 페이지 폴트 발생 간격($T$)을 측정하여 시스템 부하 상태 감시 |
| **프레임 동적 할당기** | PFF 상태에 따라 프로세스에 물리 프레임을 추가하거나 유휴 프레임 회수 |
| 희생자 선택기 (LRU/Clock) | 프레임 회수 시 가장 오래 참조되지 않은 페이지를 스왑아웃 대상으로 선정 |

#### 한줄 요약
- 워킹 셋 추적기, PFF 계측 엔진, 동적 할당기가 협력하여 프레임을 실시간 조절한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **페이지 폴트 간격($T$)**: 직전 페이지 폴트 발생 시점부터 현재 폴트 발생 시점까지의 경과 시간.

</details>

```text
프로세스 실행 중 페이지 폴트(Page Fault) 인터럽트 발생
        │
   직전 폴트 시점과의 경과 시간 간격 $T = t_{\text{current}} - t_{\text{prev}}$ 계산
        │
   폴트 간격 $T$의 임계값 비교 판정
   ┌────┴───────────────────────────┐
$T < T_{\text{min}}$ (폴트 빈도 과다)     $T > T_{\text{max}}$ (폴트 빈도 극소)
   │                                  │
현재 할당 프레임 부족 상태           메모리 과다 할당 상태
   │                                  │
해당 프로세스에 물리 프레임 1개 추가  $T$ 동안 미참조된 페이지 모두 회수
할당 후 페이지 적재                   후 여유 프레임 풀로 반납
   │                                  │
   └────┬─────────────────────────────┘
        │
   $t_{\text{prev}} = t_{\text{current}}$ 갱신 후 프로세스 실행 재개
```

#### 한줄 요약
- 폴트 발생 → 간격 $T$ 계산 → 상한 초과 시 프레임 추가, 하한 미달 시 미참조 프레임 회수 순으로 처리된다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **WS 알고리즘 vs PFF 알고리즘**: 매 메모리 참조마다 윈도우를 연속 갱신하는 WS와 폴트 시점에만 간격을 검사하는 PFF의 차이.

</details>

| 비교 항목 | 워킹 셋 모델 (Working Set Model) | 페이지 폴트 빈도 기법 (PFF) | 고정 프레임 할당 (Fixed Allocation) |
|:---|:---|:---|:---|
| 제어 방식 | **윈도우 $\Delta$ 내 연속 추적** | **페이지 폴트 인터럽트 시점 계측** | 프로세스 생성 시 고정 할당 |
| 연산 오버헤드 | 메모리 참조마다 갱신 (오버헤드 큼) | **폴트 발생 시에만 동작 (저비용)** | 오버헤드 없음 |
| 스레싱 방어력 | **매우 뛰어남 (이론상 완벽)** | 우수함 (사후 피드백 방식) | 스레싱에 매우 취약 |
| 구현 난이도 | 하드웨어 지원 필수, 구현 복잡 | **OS 소프트웨어로 쉽게 구현 가능** | 매우 단순 |

#### 한줄 요약
- 이론적 최적성은 워킹 셋 모델이, 실무적 저비용 효율성은 PFF 기법이 우수하다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **순차 스캔 오염(Sequential Scan Pollution)**: 대용량 데이터 1회 풀스캔 작업이 워킹 셋을 오염시켜 진짜 필요한 활성 페이지를 쫓아내는 현상.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| WS 연속 추적으로 인한 CPU 사이클 낭비 | 이벤트 기반 **PFF 기법 및 하드웨어 참조 비트(Accessed Bit)** 활용 | 런타임 오버헤드 최소화 |
| 윈도우 $\Delta$ 크기 왜곡 시 메모리 과대/과소 할당 | 워크로드 I/O 패턴에 따른 $\Delta$ 적응형 튜닝 | 프로세스별 최적 상주 집합 유지 |
| 대용량 배치 파일 읽기로 인한 **순차 스캔 오염** | 2Q / LRU-K / **ARC(Adaptive Replacement Cache)** 알고리즘 적용 | 1회성 스캔 페이지의 캐시 오염 원천 차단 |
| 시스템 전체 메모리 부족 시 PFF 한계 | 커널 `kswapd` 백그라운드 워터마크 회수 및 cgroups 메모리 한도 설정 | 시스템 메모리 패닉 사전 예방 |

#### 한줄 요약
- PFF 이벤트 기반 감시, ARC 캐시 적용, kswapd 워터마크 회수로 메모리 효율을 극대화한다.

## Ⅶ. 결론

- 가상 메모리 시스템은 **PFF 기반의 동적 프레임 할당과 ARC 페이지 교체 알고리즘**을 결합하여 스레싱을 선제 차단하고 메모리 집약 워크로드 성능 완성

#### 한줄 요약
- 워킹 셋과 PFF는 프로세스의 참조 국부성을 반영하여 메모리를 동적으로 최적화하는 핵심 메모리 제어 메커니즘이다.
