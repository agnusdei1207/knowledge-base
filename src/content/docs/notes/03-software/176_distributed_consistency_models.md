## 미리 알고가기

- **분산 일관성 모델**: 복제 데이터의 연산 결과가 관찰되는 순서와 시점 규약임
- **선형화 가능성**: 완료 시점의 실시간 선후관계를 보장하는 단일 연산 순서임
- **순차 일관성**: 프로세스별 연산 순서를 지키는 전역 단일 연산 순서임
- **인과 일관성**: 원인과 결과 관계가 있는 연산 순서만 모든 노드에서 보존함
- **최종 일관성**: 추가 쓰기 중단 시 복제본이 동일 값으로 최종 수렴하는 모델임
- **원자성·일관성·고립성·영속성(Atomicity, Consistency, Isolation, Durability, ACID)**: ACID는 ‘애시드’로 읽고 네 속성의 머리글자를 묶은 약어이며, 트랜잭션 속성이므로 복제본 관찰 순서를 정하는 일관성 모델과 구분
- **연산 이력**: 각 읽기·쓰기의 호출 시점과 응답 결과를 기록한 순서 정보임
- **논리·벡터 시계**: 물리 시각 대신 사건의 선후 관계를 나타내는 버전 정보임
- **쿼럼**: 전체 복제본 중 읽기·쓰기에 동의해야 하는 최소 개수임
- **세션 토큰**: 사용자가 방금 쓴 버전보다 오래된 값을 읽지 않도록 전달하는 정보임
- **불변식**: 어떤 동시 실행에서도 반드시 유지해야 하는 업무 조건임
- **자기 쓰기 읽기(Read-your-writes)**: 한 세션이 방금 기록한 값보다 오래된 버전을 다시 읽지 않도록 보장하는 세션 일관성임
- **조건부 쓰기(Conditional Write)**: 현재 버전이나 조건이 예상과 같을 때만 변경을 반영해 오래된 값에 기반한 덮어쓰기를 방지하는 연산임

## Ⅰ. 개요

- **정의/개념**: 복제 데이터의 연산 관찰 순서 규약임
- **배경/필요성**: 복제 지연이 관찰 순서를 바꿔 보장 모델이 필요함

### 쉽게 이해하기 (학습용)
- 어느 순서까지 볼지 정한 약속임

## Ⅱ. 특징

- 보존하는 연산 선후 범위가 일관성 강도를 결정한다.
- 조정된 쓰기 순서로 실시간 선후관계를 보존한다.
- 논리 시계를 활용해 선행 연산을 보장한다.
- 비동기 복제는 수렴 전 오래된 값 읽기를 허용한다.
- 장애 시 요청을 거부하거나 이전 값을 반환한다.
- 데이터별 불변식을 고려해 모델을 선택한다.

### 쉽게 이해하기 (학습용)
- 최신성 보장과 응답 지연 중 업무 기준으로 선택한다.

## Ⅲ. 아키텍처 및 구성요소

| 설계 요소 | 설명 |
|:---|:---|
| 연산 이력 | 호출·응답과 프로세스 순서를 기록 |
| 순서·버전 메타데이터 | 논리 시계로 연산 선후 관계를 표현 |
| 복제·완료 정책 | 쿼럼·전파 기준으로 쓰기 완료 판정 |
| 읽기·세션 정책 | 읽기 쿼럼과 세션별 최소 버전 지정 |
| 충돌·검증 체계 | 동시 버전을 병합하고 복제 지연을 측정함 |

### 쉽게 이해하기 (학습용)

## Ⅳ. 원리 및 절차 흐름도

- 쓰기 쿼럼이 늘면 최신성·지연·거부 증가
- 벡터 시계로 인과·동시 변경 구분
- 세션 토큰으로 최소 읽기 버전 유지

> 요약: 불변식에 맞는 관찰 순서를 정책으로 구현

### 쉽게 이해하기 (학습용)
- 줄서기 규칙을 정하고 창구를 맞춰 운영함

## Ⅴ. 종류 및 비교

| 판단 기준 | 선형화 가능성 | 순차 일관성 | 인과 일관성 | 최종 일관성 |
|:---|:---|:---|:---|:---|
| 핵심 특징 | 실시간 선후의 단일 순서를 보장함 | 프로그램 순서의 실행 순서를 보장함 | 원인과 결과의 부분 순서를 보장함 | 쓰기 중단 시 최종 수렴만 보장함 |
| 적용 기준 | 실시간 최신값·원자 판단 | 단일 순서·실시간 제약 불필요 | 원인·결과 순서 보존 | 가용성·비동기 수렴 우선 |
