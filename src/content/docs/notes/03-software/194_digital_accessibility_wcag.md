## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **디지털 접근성(Digital Accessibility / WCAG 2.1)**: 장애인, 고령자 등 정보 취약 계층을 포함한 모든 사용자가 어떠한 신체적·환경적 제약 없이 웹과 모바일 소프트웨어의 정보와 기능에 동등하게 접근하고 이용할 수 있도록 보장하는 국제 표준(W3C WCAG) 및 품질 체계.
- **보조공학 기기 인식 장벽(Accessibility Barrier Risk)**: 시각 중심의 화려한 UI, 복잡한 동적 SPA, 마우스 전용 인터페이스로 인해 스크린 리더 및 키보드 사용자의 서비스 이용이 전면 차단되는 디지털 정보 소외 위험.

</details>

- 정의/개념: 장애인과 고령자를 포함한 모든 사용자가 **시각, 청각, 지체 장애 없이 디지털 정보와 서비스에 동등하게 접근**하도록 보장하는 웹 접근성 표준 체계
- 배경/필요성: 복잡한 동적 SPA 화면 및 이미지·영상 중심 UI 확산으로 인한 **스크린 리더 등 보조공학 기기 인식 불가 및 정보 소외 위험** 직면

#### 한줄 요약

- W3C의 POUR(인식, 운용, 이해, 견고) 4대 원칙과 Level AA 기준을 준수하여 시각·청각·지체 장애인의 동등한 디지털 과업 완료를 보장

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **POUR 4대 원칙**: 인식 가능(Perceivable), 운용 가능(Operable), 이해 가능(Understandable), 견고성(Robust).
- **시맨틱 마크업(Semantic HTML & WAI-ARIA)**: `<button>`, `<nav>`, `aria-live` 등을 사용하여 화면 요소의 역할(Role), 상태(State), 이름(Name)을 보조기술에 정확히 전달하는 웹 표준 기술.

</details>

- 비텍스트 콘텐츠의 대체 텍스트(Alt) 및 4.5:1 이상 명도 대비를 보장하는 **인식 가능성(Perceivable)**
- 마우스 없이 키보드만으로 모든 기능을 조작하고 초점을 이동하는 **운용 가능성(Operable)**
- 논리적이고 예측 가능한 UI와 오류 수정 안내를 제공하는 **이해 가능성(Understandable)**
- 다양한 스크린 리더와 브라우저 보조기술 간 상호운용성을 보장하는 **견고성(Robust)**

#### 한줄 요약

- POUR 4대 원칙을 기반으로 스크린 리더와 키보드 접근성을 충족하여 모든 사용자의 서비스 이용권을 보장

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **디지털 접근성 4대 아키텍처 계층**: 시맨틱 HTML(구조/의미), WAI-ARIA(동적 상태 보완), 키보드 포커스 제어(Focus Trap), 보조기술(Screen Reader).

</details>

```text
[ 디지털 접근성(WCAG 2.1) 아키텍처 및 보조기술 연계 구조도 ]

 1. [ 프론트엔드 마크업 계층 (Semantic HTML5 & WAI-ARIA) ]
    ┌─────────────────────────────────────────────────────────────┐
    │  • `<main>`, `<nav>`, `<button>`, `<label for="id">`        │
    │  • WAI-ARIA: `aria-expanded="true"`, `role="dialog"`        │
    └────────────────────────────┬────────────────────────────────┘
                                 │ (브라우저 DOM 파싱)
                                 ▼
 2. [ 브라우저 접근성 트리 계층 (Accessibility Tree) ] ──────────┐
    • UI 요소의 Name(이름), Role(역할), Value(값), State(상태)    │
    └────────────────────────────┬────────────────────────────────┘
                                 │ (OS 접근성 API 노출: MSAA, UIA)
                                 ▼
 3. [ 보조기술 계층 (Assistive Technologies) ] ──────────────────┐
    • 스크린 리더(NVDA, VoiceOver) ➔ 음성 낭독 및 점자 출력      │
    • 스위치 제어기 / 키보드 ➔ Tab, Space, Enter 키 이벤트 처리 │
    └─────────────────────────────────────────────────────────────┘
```

선의 의미: 시맨틱 HTML이 브라우저의 접근성 트리를 생성하고 OS API를 통해 스크린 리더 등 보조기술에 전달되는 구조.

| 구성요소 | 책임 |
|:---|:---|
| 시맨틱 마크업 (HTML5) | UI 요소의 본래 의미에 맞는 태그를 사용하여 **접근성 트리에 Name, Role, Value 제공** |
| WAI-ARIA 표준 | 커스텀 UI 및 동적 컴포넌트의 **열림/닫힘 상태(`aria-expanded`)와 동적 알림 전달** |
| 키보드 화면 탐색(Navigation) | 마우스 없이도 **논리적 초점(Focus) 이동 순서와 모달 포커스 트랩(Focus Trap) 보장** |
| 스크린 리더 (Screen Reader) | 시각장애인을 위해 **접근성 트리의 텍스트와 UI 컨트롤을 음성 및 점자로 실시간 출력** |

#### 한줄 요약

- 시맨틱 HTML, WAI-ARIA, 키보드 제어, 스크린 리더가 결합하여 접근성 환경을 완성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **접근성 품질 검증 5단계 수명주기**: 핵심 과업 식별 $\to$ 시맨틱/키보드 구현 $\to$ 자동화 스캔(Axe) $\to$ 스크린 리더 수동 과업 검증 $\to$ 인증 마크 획득.

</details>

```text
[ WCAG 2.1 디지털 접근성 품질 검증 및 인증 파이프라인 ]

 ┌────────────────────────────────────────┐
 │ 1. 핵심 사용자 과업 및 WCAG 2.1 SC 매핑│
 └───────────────────┬────────────────────┘
                     │
                     ▼
 ┌────────────────────────────────────────┐
 │ 2. 시맨틱 마크업, 대체 텍스트, Focus 구현│
 └───────────────────┬────────────────────┘
                     │
                     ▼
 ┌────────────────────────────────────────┐
 │ 3. Axe / Lighthouse 기반 자동화 1차 스캔│
 └───────────────────┬────────────────────┘
                     │
                     ▼
 ┌────────────────────────────────────────┐
 │ 4. 스크린 리더(NVDA) 기반 수동 과업 검증│
 ├───────────────────┬────────────────────┤
 │ 과업 차단 (실패)  │ 과업 완료 (성공)   │
 │ • 마크업 수정     │ • Level AA 충족    │
 └───────────────────┴────────────────────┘
                     │
                     ▼
 ┌────────────────────────────────────────┐
 │ 5. 웹 접근성 품질인증 마크 획득 및 배포│
 └────────────────────────────────────────┘
```

### 동작 원리

1. 과업 매핑: 회원가입, 결제, 민원 신청 등 서비스 핵심 과업을 WCAG 2.1 Level AA 세부 기준(SC)과 1:1 매핑.
2. 마크업 구현: 이미지에 의미 있는 대체 텍스트(alt)를 부여하고, 폼 컨트롤마다 명시적 `<label>`을 연결.
3. 자동화 스캔: CI 파이프라인에서 Axe-core를 실행하여 4.5:1 미만의 명도 대비 오류나 누락된 alt 태그를 자동 검출.
4. 수동 검증: 전문 평가원이 화면을 끄고 키보드와 NVDA 스크린 리더만으로 회원가입 및 결제 과업을 완수할 수 있는지 검증.
5. 인증 획득: 발견된 포커스 유실 결함을 수정한 후 한국웹접근성인증평가원으로부터 공식 품질인증 마크를 획득.

#### 한줄 요약

- 과업 매핑 $\to$ 마크업 구현 $\to$ 자동화 스캔 $\to$ 스크린 리더 수동 검증 $\to$ 인증 획득의 5단계

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **WCAG 3대 적합성 수준**: Level A(기본 장벽 제거), Level AA(일반 상용/공공 권고 표준), Level AAA(최고 수준 특수 환경).

</details>

| 구분 | Level A (최소 적합 기준) | Level AA (일반 공공/기업 표준) | Level AAA (최고 수준 기준) |
|:---|:---|:---|:---|
| **적용 기준** | 디지털 접근성의 가장 기초적인 차단 장벽을 제거할 때 | 국내외 공공기관, 금융권, 대형 e커머스의 법적 의무 준수 기준 | 시각/청각 특수 교육 기관, 고도화된 장애인 전문 복지 서비스 |
| **핵심 특징** | **대체 텍스트, 키보드 단독 조작, 캡차 대체 수단 제공** | **텍스트 명도 대비 4.5:1 이상, 화면 200% 확대, 초점 표시** | **명도 대비 7:1 이상, 모든 영상에 수어 통역 비디오 제공** |
| **한계** | 저시력자 가독성(명도 대비) 등 주요 사용성 보장 한계 | 디자인적 제약(색상 팔레트)이 발생하나 균형 잡힌 표준 | 디자인 자유도가 극도로 제한되어 일반 서비스 전면 적용 불가 |

#### 한줄 요약

- 법적·실무적 표준은 Level AA를 목표로 설정하고 핵심 과업의 접근성을 보장

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **포커스 트랩(Focus Trap)**: 모달 팝업이 떴을 때 키보드 Tab 키가 백그라운드 본문으로 빠져나가지 못하도록 모달 내부에 가두고, 닫힐 때 원래 열었던 버튼으로 초점을 복귀시키는 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| SPA 환경에서 모달 창 오픈 시 스크린 리더 포커스 유실 | **모달 내 `Focus Trap` 구현 및 닫힘 시 트리거 버튼으로 초점 복귀** | 키보드 화면 탐색(Navigation) 100% 보장 |
| 이미지에 "image.png", "배너" 등 무의미한 대체 텍스트 입력 | **이미지의 비즈니스 목적과 전달 정보를 기술한 의미 있는 Alt 작성** | 시각장애인 정보 습득 정확도 확보 |
| Axe 등 자동화 도구 100점 통과만 믿고 실제 과업 수행 불가 | **실제 시각/지체 장애인 테스터의 '핵심 사용자 과업 완수 평가' 병행** | 실질적 디지털 접근성 달성 |

#### 한줄 요약

- 포커스 트랩, 의미 있는 대체 텍스트, 실수요자 과업 검증을 통해 접근성의 실효성을 확보

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **디지털 포용성 및 ESG 경영(Digital Inclusion & ESG)**: 장애인 차별 금지 및 웹 접근성 준수를 기업의 사회적 책임(ESG)과 필수 인권 보장으로 실천하는 현대 소프트웨어의 필수 덕목.

</details>

- **디지털 접근성(WCAG 2.1)** 은 단순한 규제 준수를 넘어 모든 시민의 보편적 디지털 기본권을 보장하는 핵심 소프트웨어 엔지니어링 품질이며, 시맨틱 마크업 준수와 Level AA 수동 과업 검증을 개발 라이프사이클에 내재화해야 함

#### 한줄 요약

- POUR 4대 원칙과 Level AA 기준을 준수하여 정보 취약 계층의 평등한 디지털 이용권을 완성
