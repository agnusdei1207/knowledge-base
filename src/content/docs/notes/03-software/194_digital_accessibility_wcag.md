## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **디지털 접근성(Digital Accessibility)**: 장애•연령•사용 기기와 관계없이 사용자가 같은 정보와 기능에 접근해 과업을 완료하게 하는 사용성 품질 속성이다.

</details>

- 정의/개념: 사용 제약과 무관하게 과업을 완료하게 하는 **디지털 접근성(Digital Accessibility)**이다.
- 배경/필요성: 시각•포인터 중심 인터페이스는 감각•운동 제약 사용자의 정보 접근과 과업 완료를 제한한다.

#### 한줄 요약
- 화면을 보거나 마우스를 쓰기 어려워도 같은 과업을 끝낼 수 있게 설계하는 것이 핵심이다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **웹 콘텐츠 접근성 지침(Web Content Accessibility Guidelines, WCAG)**: 웹 콘텐츠가 장애 사용자에게 접근 가능하도록 적합 기준과 시험 가능한 성공 기준을 제공하는 국제 지침이다.
- **인식•운용•이해•견고(Perceivable, Operable, Understandable, Robust, POUR)**: WCAG 접근성 요구를 네 관점으로 분류한 핵심 원칙이다.
- **스크린 리더(Screen Reader)**: 화면 요소의 의미를 음성•점자로 전달하는 보조기술이다.
- **접근성 트리(Accessibility Tree)**: 화면 요소의 이름•역할•상태•관계를 담은 의미 구조이다.
- **대체 텍스트(Alternative Text)**: 비텍스트 콘텐츠의 목적과 의미를 보조기술 사용자에게 전달하는 텍스트 설명이다.
- **키보드 조작**: 포인터 없이 모든 기능을 초점 이동과 키 입력으로 수행하는 방식이다.
- **자동 검사**: 기계 판정 가능한 접근성 성공 기준 위반 후보를 찾는 시험이다.
- **사용자 과업 검증**: 보조기술 사용자가 실제 정보 접근과 과업 완료에 성공하는지 확인하는 시험이다.

</details>

- **웹 콘텐츠 접근성 지침(Web Content Accessibility Guidelines, WCAG)**과 **인식•운용•이해•견고(Perceivable, Operable, Understandable, Robust, POUR)** 원칙 기반으로 접근성을 분류한다.
- **대체 텍스트(Alternative Text)**와 **키보드 조작**으로 비시각•비포인터 이용을 지원한다.
- **스크린 리더(Screen Reader)**와 **접근성 트리(Accessibility Tree)** 기반으로 의미를 전달한다.
- **자동 검사**와 **사용자 과업 검증**을 결합한다.

#### 한줄 요약
- 화면을 듣거나 키보드만 써도 같은 입력•이동 과정을 완료하게 한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **사용자 인터페이스(User Interface, UI)**: 시맨틱 구조와 키보드 조작 및 시각적 상태를 제공하는 구성요소이다.
- **보조기술(Assistive Technology)**: 접근성 트리를 해석해 음성•점자•대체 입력으로 화면과 사용자를 연결하는 구성요소이다.
- **평가자(Evaluator)**: 자동 규칙 검사와 실제 보조기술 사용자 과업을 결합해 장벽을 판정하는 주체이다.

</details>

```text
디지털 접근성 구조
      |
      +-- [사용자 인터페이스]
      |         +-- [접근성 트리]
      |         +-- [보조기술]
      |
      +-- 검증
                +-- [평가자]
```

| 구성요소 | 책임 |
|:---|:---|
| 사용자 인터페이스 | **사용자 인터페이스(User Interface, UI)**가 시맨틱 구조•키보드 조작을 제공 |
| 접근성 트리 | **접근성 트리(Accessibility Tree)**가 요소의 이름•역할•상태를 노출 |
| 보조기술 | **보조기술(Assistive Technology)**이 트리를 해석해 대체 입출력을 제공 |
| 평가자 | **평가자(Evaluator)**가 자동 규칙•사용자 과업을 검증 |

#### 한줄 요약
- 화면의 버튼과 입력창이 접근성 트리에 이름•역할로 놓이면 스크린 리더가 읽고 키보드 입력을 다시 화면 동작으로 전달한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **POUR•성공 기준 매핑**: 핵심 과업을 WCAG 기준과 연결하는 단계이다.
- **시맨틱•키보드 구현**: 이름•역할•상태와 초점 순서를 제공하는 단계이다.
- **자동 위반 후보 검사**: 기계 판정 가능한 코드 장벽을 찾는 단계이다.
- **보조기술•사용자 과업 검증**: 실제 정보 접근과 과업 완료를 확인하는 단계이다.

</details>

```text
핵심 사용자 과업
      |
      v
1. POUR•성공 기준 매핑
      |
      v
2. 시맨틱•키보드 구현
      |
      v
3. 자동 위반 후보 검사
      |
      v
4. 보조기술•사용자 과업 검증
      |
      +-- 과업 실패 --> 장벽 수정•2단계부터 재검증
      |
      +-- 과업 성공 --> 적합 수준•시험 증적 확정
```

### 동작 원리

1. **POUR•성공 기준 매핑**: **POUR•성공 기준 매핑**으로 핵심 과업과 WCAG 기준을 연결한다.
2. **시맨틱•키보드 구현**: **시맨틱•키보드 구현**으로 이름•역할•상태•초점을 제공한다.
3. **자동 위반 후보 검사**: **자동 위반 후보 검사**로 기계 판정 가능한 장벽을 탐지한다.
4. **보조기술•사용자 과업 검증**: **보조기술•사용자 과업 검증**으로 실제 과업 성공을 확인한다.

#### 한줄 요약
- 평가자가 자동 검사로 코드 위반 후보를 찾고 스크린 리더와 키보드로 같은 과업을 끝내 실제 장벽인지 확인한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **수준 A**: 기본 기능 접근을 막는 최소 장벽을 제거하는 적합 수준이다.
- **수준 AA**: 일반 서비스의 주요 접근성 장벽을 추가로 제거하는 준수 목표이다.
- **수준 AAA**: 특정 고접근성 요구의 가장 엄격한 성공 기준까지 충족하는 수준이다.

</details>

| WCAG 적합 수준 | **수준 A** | **수준 AA** | **수준 AAA** |
|:---|:---|:---|:---|
| 적용 기준 | 최소 기능 접근 보장 | 일반 서비스 준수 목표 | 특정 고접근성 목표 |
| 핵심 특징 | 최소 장벽 제거 | 주요 장벽 추가 제거 | 최고 기준 충족 |
| 한계 | 주요 장벽 잔존 | 일부 요구 누락 가능 | 전 콘텐츠 적용 비용 |

#### 한줄 요약
- A는 최소 장벽만 제거하고 AA는 일반 서비스의 주요 장벽까지 다루며 AAA는 특정 고접근성 요구에 적용한다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **초점 손실**: 키보드 사용자가 현재 조작 위치를 알 수 없거나 논리적 순서대로 이동하지 못하는 문제이다.
- **명도 대비율(Contrast Ratio)**: 전경과 배경의 상대 밝기 차이를 수치화해 텍스트•요소의 가독성을 판정하는 기준이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 이미지의 의미 누락 | 목적별 **대체 텍스트** 제공 | 비시각 정보 접근 보장 |
| 텍스트의 명도 대비 부족 | WCAG **명도 대비율(Contrast Ratio)** 기준 적용 | 저시력 사용자 가독성 확보 |
| 키보드의 **초점 손실** | 논리 순서•가시 초점 적용 | 포인터 없는 과업 완료 |
| 입력 오류의 원인 불명 | 오류 위치•수정 방법 안내 | 과업 이탈 감소 |
| 자동 검사만의 오판 | 보조기술•사용자 검증 병행 | 실제 장벽 탐지 향상 |

#### 한줄 요약
- 공공 민원 신청은 오류 개수보다 키보드와 스크린 리더만으로 제출과 오류 수정까지 끝낼 수 있는지 확인해야 한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **접근성 기준선**: 일반 서비스의 적합 수준과 핵심 과업 검증 범위를 정하는 판단 기준이다.

</details>

- 일반 서비스는 **접근성 기준선**으로 **수준 AA**를 적용하고 핵심 과업은 보조기술 사용자 성공까지 검증한다.

#### 한줄 요약
- 자동 검사 오류가 적어도 사용자가 키보드와 스크린 리더로 제출을 마치지 못하면 접근성에 실패한 것이다.
