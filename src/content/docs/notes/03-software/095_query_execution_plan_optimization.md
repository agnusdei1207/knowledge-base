## 미리 알고가기

- **구조화 질의 언어 (Structured Query Language, SQL)**: 데이터 조회·변경을 표현함
- **실행 계획 (Execution Plan)**: 접근 경로·조인 순서·연산자를 정함
- **옵티마이저 (Optimizer)**: 통계와 비용으로 실행 계획을 선택함
- **카디널리티 추정 (Cardinality Estimation)**: 조건 통과 행 수를 예측함
- **계획 회귀 (Plan Regression)**: 변경 뒤 더 느린 계획이 선택되는 현상임
- **중앙 처리 장치 (Central Processing Unit, CPU)**: 질의 연산을 수행함
- **입출력 (Input/Output, I/O)**: 저장장치의 읽기·쓰기 동작임
- **데이터베이스 (Database, DB)**: 구조화 데이터를 저장·관리함
- **95백분위 지연 (95th Percentile Latency, p95)**: 요청 95%가 완료되는 지연 기준임
- **비용 모델(Cost Model)**: CPU·I/O·메모리 등의 예상 사용량을 수치화해 계획을 비교하는 모델임
- **선택도(Selectivity)**: 조건이 전체 행을 얼마나 좁히는지를 나타내는 정도임
- **테이블 전체 읽기(Full Table Scan)**: 조건에 맞는 행을 찾기 위해 테이블의 모든 행을 읽는 방식임
- **테이블 재조회(Table Lookup)**: 인덱스 결과의 행 위치로 원본 테이블을 다시 읽는 동작임
- **옵티마이저 힌트(Optimizer Hint)**: 특정 접근 경로나 조인 방식을 우선하도록 최적화기에 주는 지시임
- **키셋 페이지 나누기(Keyset Pagination)**: 마지막 정렬 키 이후의 행을 읽어 다음 페이지를 구하는 방식임
- **오프셋(Offset)**: 결과의 앞에서 건너뛸 행 수임

## Ⅰ. 개요

- **정의/개념**: 통계와 비용으로 질의 실행 경로를 개선함
- **배경/필요성**: 통계 추정 오류로 실행 계획 최적화 필요

### 쉽게 이해하기 (학습용)
- 같은 SQL도 데이터 분포에 따라 빠른 경로가 달라져 통계와 실제 실행 결과를 함께 확인해야 함

## Ⅱ. 특징

- 옵티마이저는 통계·비용으로 실행 계획을 선택한다.
- 접근량·조인 순서·정렬 I/O가 계획 비용을 구성한다.
- 통계·인덱스 조정만으로도 선택 계획이 달라진다.
- 힌트 남용은 분포 변화 뒤 장기 병목을 만들 수 있다.
- 키셋 방식은 정렬 키 범위로 오프셋 비용을 줄인다.

### 쉽게 이해하기 (학습용)
- 예상 교통량이 틀리면 정체 경로를 선택하므로 실제 결과를 비교함

## Ⅲ. 아키텍처 및 구성요소

| 설계 요소 | 설명 |
|:---|:---|
| 통계 정보 | 분포와 선택도로 행 수를 추정함 |
| 접근 경로 | 스캔과 룩업 경로를 선택함 |
| 조인·연산자 | 조인 순서와 결합 및 정렬 방식을 정함 |
| 실행 실측 | 예상과 실제 행 수 및 자원을 비교함 |

```text
  통계확인
      ↓
  접근선택
      ↓
  연산결정
      ↓
  실행실측
```

> 요약: 통계로 계획을 선택하고 실측으로 추정 오류를 찾음

### 쉽게 이해하기 (학습용)
- 통계로 경로를 정하고 예상과 실제 행 차이로 오류를 찾음

## Ⅳ. 원리 및 절차 흐름도

```text
  지연실측
      ↓
  오차분석
      ↓
  구조교정
      ↓
  회귀검증
```

| 절차 | 설명 |
|:---|:---|
| SQL실측 | 지연과 입출력이 큰 쿼리를 식별함 |
| 오차분석 | 예상과 실제 행 수 오차를 분석함 |
| 구조교정 | 쿼리와 인덱스 및 통계를 재조정함 |
| 회귀검증 | 성능 재측정과 다른 질의 회귀를 확인함 |

> 요약: 계획 오차를 분석해 구조를 교정하고 회귀를 검증함

### 쉽게 이해하기 (학습용)
- 추정 오차를 찾아 통계와 인덱스를 바로잡음

## Ⅴ. 종류 및 비교

| 비교축 | 규칙 기반 접근 | 비용 기반 최적화 |
|:---|:---|:---|
| 핵심 특징 | 경험 규칙과 반패턴을 사용함 | 통계와 자원 비용을 사용함 |
| 적용 기준 | 고정 경로가 유효한 환경에 적용함 | 분포 변화가 큰 환경에 적용함 |
| 주요 위험 | 환경 변화 시 규칙 근거가 약해짐 | 통계 오류 시 잘못된 계획을 선택함 |

> 요약: 규칙은 경험, 비용은 통계로 경로 판단

### 쉽게 이해하기 (학습용)
- 규칙 기반은 미리 정한 경험칙을 따르고 비용 기반은 현재 통계로 여러 경로의 예상 비용을 비교함

## Ⅵ. 실무 사례

1. 주문 시스템은 통계 교정과 계획 회귀를 확인함
2. 배치는 조인·중간 행·처리 시간을 분석함

### 쉽게 이해하기 (학습용)
- 주문 질의는 예상 행 수와 실제 행 수의 차이를 줄여 최적화기가 알맞은 인덱스 경로를 선택하게 함
- 대량 배치는 작은 입력을 먼저 결합해 중간 결과를 줄이면 CPU·I/O·전체 처리 시간을 낮출 수 있음

## Ⅶ. 결론

- 통계·실행 계획·실측 지표로 병목과 회귀 교정

### 쉽게 이해하기 (학습용)
- 질의 최적화는 특정 계획을 고정하는 일이 아니라 정확한 통계와 실측으로 더 낮은 비용의 계획이 유지되는지 검증하는 일임
