## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **모델 모니터링(Model Monitoring)**: 운영 입력•예측•정답을 기준선과 비교해 모델 품질과 이상 변화를 지속 관찰하는 활동이다.
- **드리프트(Drift)**: 운영 데이터 분포나 입력과 정답의 관계가 학습 시점과 달라지는 현상이다.

</details>

- 정의/개념: 운영 신호로 **드리프트(Drift)**와 품질 저하를 판정하는 **모델 모니터링(Model Monitoring)**이다.
- 배경/필요성: 배포 전 평가만으로는 운영 분포와 개념 변화를 반영하기 어렵다.

#### 한줄 요약
- 학습 때와 운영 때의 입력•예측•정답을 비교해 모델이 낡았는지 찾는다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **통계 거리•슬라이스 감시**: 통계 거리로 운영 분포의 변화 크기를 측정하고 사용자군별 국소 품질 저하를 찾는 감시 방식이다.
- **기준선(Baseline)**: 운영 변화와 품질 저하를 판정할 때 비교 기준으로 삼는 학습•검증 시점의 분포와 성능이다.
- **지연 정답(Delayed Label)**: 예측 시점보다 늦게 확정되어 과거 예측과 다시 연결해야 하는 실제 결과이다.

</details>

![기준 분포와 운영 분포 사이 거리의 드리프트 경보](/study/diagrams/model-drift-distance.svg)

> 파란 관측 거리가 붉은 경보 임계값을 넘는 시점부터 원인 조사와 재학습을 검토하는 예시이며, 거리 척도와 임계값은 데이터•위험 수준별로 검증해 정한다.

- **기준선(Baseline)**으로 입력•예측•성능의 변화 대상을 구분한다.
- **통계 거리•슬라이스 감시**로 조기 경보가 핵심이다.
- **지연 정답(Delayed Label)** 결합 후 성능을 확인해 재학습•복귀를 결정한다.

#### 한줄 요약
- 실제 결과가 늦게 와도 입력과 예측의 변화를 먼저 보고, 결과가 오면 정확도 저하인지 확인한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **드리프트 탐지기(Drift Detector)**: 기준선과 운영 분포의 통계 거리•성능 차이를 계산해 변화 유형과 임계 초과를 판정하는 구성요소이다.
- **기준선 저장소(Baseline Store)**: 학습•검증 시점의 입력•예측•성능 분포를 비교 기준으로 보관하는 저장소이다.
- **운영 신호 수집기(Operational Signal Collector)**: 입력•예측•지연 정답과 서비스 지표를 슬라이스별로 수집하는 구성요소이다.
- **정답 결합기(Label Joiner)**: 늦게 도착한 실제 정답을 식별자를 이용해 과거 예측과 연결하는 구성요소이다.
- **대응 제어기(Response Controller)**: 탐지 결과와 업무 영향을 바탕으로 재학습•복귀•기준선 갱신을 결정하는 구성요소이다.

</details>

```text
모델 모니터링 구조
      |
      +-- 비교 자료
      |         +-- [기준선 저장소]
      |         +-- [운영 신호 수집기]
      |         +-- [정답 결합기]
      |
      +-- 판정•대응
                +-- [드리프트 탐지기]
                +-- [대응 제어기]
```

| 구성요소 | 책임 |
|:---|:---|
| **기준선 저장소(Baseline Store)** | 학습 입력•예측•성능 분포 보관 |
| **운영 신호 수집기(Operational Signal Collector)** | 신호를 슬라이스별 수집 |
| **정답 결합기(Label Joiner)** | 지연 정답과 과거 예측 연결 |
| **드리프트 탐지기(Drift Detector)** | 통계 거리•성능 차이 판정 |
| **대응 제어기(Response Controller)** | 재학습•복귀•기준 갱신 결정 |


#### 한줄 요약
- 학습 때의 분포표와 운영 신호를 비교하고 실제 결과가 오면 예측의 정답 여부까지 연결한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **1. 입력•예측 변화 전달**: 운영 신호를 사용자군•지역•시간 등 슬라이스별 분포로 수집하는 단계이다.
- **2. 기준선•통계 거리 비교**: 기준 분포와 운영 분포의 차이와 임계 초과 지속 시간을 계산하는 단계이다.
- **3. 정답•예측 결합**: 지연 정답을 과거 예측과 연결해 실제 성능을 계산하는 단계이다.
- **4. 변화 유형•업무 영향 판정**: 데이터•개념•예측 변화와 피해 범위를 분류하는 단계이다.
- **5. 대응 결정**: 변화 원인과 업무 영향을 검증해 재학습•복귀•기준선 갱신을 선택하는 단계이다.

</details>

```text
1. 입력•예측 변화 전달
      |
      v
2. 기준선•통계 거리 비교
      |
      +-- 임계 이내 --> 지속 감시
      |
      +-- 임계 초과
              |
              v
3. 정답•예측 결합
      |
      v
4. 변화 유형•업무 영향 판정
      |
      v
5. 대응 결정
      |
      +-- 실제 성능 저하 --> 재학습•복귀
      +-- 영향 없는 변화 --> 기준선 갱신
      +-- 정답 부족 --> 대리지표 감시•판정 보류
```

### 동작 원리

1. **입력•예측 변화 전달**: 슬라이스별 운영 분포를 수집한다.
2. **기준선•통계 거리 비교**: 변화 크기와 임계 초과를 판정한다.
3. **정답•예측 결합**: 지연 정답으로 실제 성능을 계산한다.
4. **변화 유형•업무 영향 판정**: 변화 종류•피해 범위를 분류한다.
5. **대응 결정**: 재학습•복귀•기준선 갱신을 선택한다.


#### 한줄 요약
- 입력만 달라졌는지 정답 관계까지 바뀌었는지 확인한 뒤 필요한 경우에만 다시 학습한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **개념 드리프트(Concept Drift)**: 입력과 정답의 관계가 바뀌어 기존 모델의 실제 성능이 저하되는 현상이다.
- **데이터 드리프트(Data Drift)**: 운영 입력의 분포가 학습 시점과 달라지는 현상이다.
- **예측 드리프트(Prediction Drift)**: 모델이 내놓는 점수•등급•분류 결과의 분포가 기준선과 달라지는 현상이다.

</details>

| 모델 드리프트 유형 | **데이터 드리프트(Data Drift)** | **개념 드리프트(Concept Drift)** | **예측 드리프트(Prediction Drift)** |
|:---|:---|:---|:---|
| 적용 기준 | 정답 전 입력 분포 감시 | 정답 후 성능 저하 확인 | 출력 점수•등급 조기 감시 |
| 핵심 특징 | 운영 입력 분포 변화 | 입력•정답 관계 변화 | 모델 출력 분포 변화 |
| 한계 | 무영향 변화의 과잉 경보 | 정답 지연으로 판정 지체 | 입력•정책과 원인 혼동 |

> 요약: 입력•정답 관계•출력 중 바뀐 대상을 구분한다.

#### 한줄 요약
- 재료가 달라졌는지 정답 규칙이 달라졌는지 출력만 치우쳤는지 나눠 대응한다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **드리프트 오판**: 계절성과 정상적인 주기 변화를 이상 변화로 해석해 불필요한 경보와 재학습을 일으키는 문제이다.
- **대리지표(Proxy Metric)**: 실제 정답이 늦게 도착할 때 품질 변화를 먼저 추정하도록 사용하는 간접 지표이다.
- **슬라이스 분석(Slice Analysis)**: 전체 평균에 가려진 특정 사용자군•지역•시간대의 국소 성능을 나눠 확인하는 분석이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 계절성의 **드리프트 오판** | 구간•요일별 **기준선(Baseline)** 분리 | 경보 정확성 향상 |
| 정답 도착의 평가 지연 | **대리지표(Proxy Metric)**•**지연 정답(Delayed Label)** 결합 | 성능 저하 조기 탐지 |
| 다중 지표의 경보 폭주 | 영향•지속 시간 상관 분석 | 대응 우선순위 확보 |
| 데이터•개념 원인 혼동 | **슬라이스 분석(Slice Analysis)**과 입력•예측•정답 분리 진단 | 재학습 판단 정확성 |

#### 한줄 요약
- 전체 평균이 같아도 특정 고객군의 승인•연체 관계가 달라지는지 따로 확인한다.



## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **드리프트 대응 기준**: 정답 결합으로 실제 성능 저하가 확인되면 재학습하고 영향 없는 분포 변화는 검증 후 기준선을 갱신하는 기준이다.

</details>

- **드리프트 대응 기준**에 따라 실제 성능 저하는 재학습하고 영향 없는 분포 변화는 검증 후 기준선을 갱신한다.

#### 한줄 요약
- 분포가 달라졌다는 이유만으로 재학습하지 말고 실제 성능과 원인을 확인한 뒤 대응한다.
