## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **샤딩(Sharding)**: 행 단위 데이터를 샤드 키 규칙으로 여러 독립 데이터베이스 노드에 나눠 용량과 처리량을 수평 확장하는 기법이다.

</details>

- 정의/개념: **샤딩**은 행 단위 데이터를 여러 독립 노드에 나누는 수평 분할 기법이다.
- 배경/필요성: 단일 노드는 데이터 증가 시 용량•처리량 확장 한계에 도달한다.

#### 한줄 요약

- 한 도서관의 책을 번호 규칙으로 여러 지점에 나누고 같은 규칙으로 책이 있는 지점을 찾는 방식이다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **수평 확장**: 노드를 추가해 저장 용량과 처리 능력을 키우는 특성이다.
- **키 중심 분배**: 샤드 키가 데이터 분포와 요청 지역성 및 핫스팟 발생을 좌우하는 특성이다.
- **분산 비용**: 여러 샤드 조회와 재배치 및 장애 복구에 추가되는 팬아웃•조정 부담이다.

</details>

- **수평 확장**: 노드 추가로 용량•처리량을 확대한다.
- **키 중심 분배**: 분포•지역성•핫스팟을 결정한다.
- **분산 비용**: 팬아웃•재샤딩•복구 필요이다.

#### 한줄 요약

- 자료를 고르게 나누고 한 지점에서 찾게 해야 확장 효과가 크며, 여러 지점을 동시에 찾으면 조정 비용이 커진다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **샤드 키(Shard Key)**: 각 행과 요청이 속할 데이터 샤드를 결정하는 열 또는 표현식이다.
- **샤드 라우터**: 샤드 키와 배치 정보로 요청을 담당 데이터 샤드에 전달하는 구성요소이다.
- **배치 메타데이터**: 키 범위와 소유 노드 위치 및 버전을 관리하는 정보이다.
- **데이터 샤드**: 자신에게 배정된 데이터를 저장하고 지역 질의와 트랜잭션을 처리하는 독립 노드이다.
- **재균형 제어기**: 샤드별 데이터•요청 편중을 감지하고 키 범위와 데이터를 이동하는 구성요소이다.

</details>

```text
[샤드 라우터]
    |
    +-- [샤드 키]
    |
    +-- [배치 메타데이터]
    |
    +-- [데이터 샤드]
            |
            +-- [재균형 제어기]
```

선의 의미: 샤드 라우터는 샤드 키와 배치 메타데이터를 데이터 샤드에 결합하고, 재균형 제어기는 배치 메타데이터와 데이터 샤드를 함께 관리하는 정적 분산 구조를 뜻한다.

| 구성요소 | 책임 |
|:---|:---|
| 샤드 키 | **샤드 키**로 행과 요청의 대상 샤드 결정 |
| 샤드 라우터 | **샤드 라우터**가 배치 정보로 요청 전달 |
| 배치 메타데이터 | **배치 메타데이터**로 키 범위•노드 위치 관리 |
| 데이터 샤드 | **데이터 샤드**가 지역 저장•질의•트랜잭션 처리 |
| 재균형 제어기 | **재균형 제어기**가 편중 감지•데이터 이동 |

#### 한줄 요약

- 안내소가 번호표와 배치표로 자료가 있는 지점을 찾는다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **배치 메타데이터 조회**: 키 범위의 소유 노드와 배치 버전을 확인하는 단계이다.
- **대상 샤드 선택**: 현재 키 범위를 소유한 노드로 경로를 정하는 단계이다.
- **지역 질의 실행**: 선택한 샤드 안에서 조회•변경을 수행하는 단계이다.
- **샤드 부하 기록**: 크기•요청량•지연을 축적하는 단계이다.

</details>

```text
샤드 키•연산 요청
        |
        v
1. 배치 메타데이터 조회
        |
        v
2. 대상 샤드 선택
        |
        +-- 단일 소유 노드
        |       |
        |       +--> 3. 지역 질의 실행
        |
        +-- 넓은 키 범위
                |
                +--> 교차 샤드 조정
        |
        v
      처리 결과
        |
        v
4. 샤드 부하 기록
        |
        v
질의 결과 반환
```

### 동작 원리

- **1. 배치 메타데이터 조회**: **배치 메타데이터 조회**로 키 범위와 노드 위치를 확인한다.
- **2. 대상 샤드 선택**: **대상 샤드 선택**으로 현재 소유 노드의 경로를 확정한다.
- **3. 지역 질의 실행**: **지역 질의 실행**으로 선택 샤드의 데이터만 처리한다.
- **4. 샤드 부하 기록**: **샤드 부하 기록**으로 편중•재샤딩 판단값을 축적한다.

#### 한줄 요약

- 안내소가 번호로 담당 지점을 찾고 요청을 한 곳에서 끝낸 뒤 혼잡도까지 기록한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **해시 샤딩**: 키의 해시값으로 데이터를 고르게 분산해 점 조회에 적합한 방식이다.
- **범위 샤딩**: 연속 키 구간을 각 샤드에 배정해 범위 조회와 데이터 지역성을 지원하는 방식이다.
- **디렉터리 샤딩**: 별도 매핑표에서 키나 임차인별 데이터 위치를 명시적으로 지정하는 방식이다.

</details>

| 판단 기준 | 범위 샤딩 | 해시 샤딩 | 디렉터리 샤딩 |
|:---|:---|:---|:---|
| 적용 기준 | 범위 조회•지역성 | 균등 분산•점 조회 | 임차인별 위치 지정 |
| 핵심 특징 | **범위 샤딩** | **해시 샤딩** | **디렉터리 샤딩** |
| 한계 | 증가 키 집중 | 범위 질의 팬아웃 | 매핑표 가용성 |

> 샤딩은 여러 독립 노드에 데이터를 분산하므로 테이블 파티셔닝보다 운영 범위가 넓다.

#### 한줄 요약

- 번호 구간으로 나누면 범위 찾기가 쉽고, 해시로 나누면 고르며, 목록으로 지정하면 원하는 위치에 둘 수 있다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **접근 단위(Access Unit)**: 한 업무 요청이 함께 다루는 데이터 경계이다.
- **소유권 단위(Ownership Unit)**: 한 샤드가 변경 책임을 갖는 데이터 경계이다.
- **가상 버킷(Virtual Bucket)**: 실제 노드에 재배치할 수 있는 논리 분배 단위이다.
- **복합 키(Composite Key)**: 편중 키에 추가 분산값을 결합한 샤드 키이다.
- **버전 확인(Version Check)**: 라우터의 배치 정보가 최신인지 검사하는 통제이다.
- **리디렉션(Redirection)**: 요청을 새 소유 노드로 다시 보내는 통제이다.
- **데이터 복사(Data Copy)**: 재샤딩 대상을 새 위치로 옮기는 절차이다.
- **복사 검증(Copy Validation)**: 두 위치의 데이터 일치 여부를 확인하는 절차이다.
- **원자 전환(Atomic Cutover)**: 샤드 소유권을 한 번에 바꾸는 절차이다.
- **별도 서비스(Dedicated Service)**: 샤드 간 분석을 맡은 전용 처리 경로이다.
- **비동기 집계(Asynchronous Aggregation)**: 샤드 데이터를 미리 모으는 방식이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 접근 단위와 샤드 키 불일치 | **접근 단위**•**소유권 단위**로 키 선정 | 교차 샤드 연산 감소 |
| 키 편중으로 특정 샤드 과부하 | **가상 버킷•복합 키** 적용 | 핫스팟 완화 |
| 캐시한 배치 정보의 버전 노후화 | **버전 확인•리디렉션** 적용 | 이전 위치 접근 방지 |
| 재샤딩 중 소유권 경계 불명확 | **데이터 복사**•**복사 검증**•**원자 전환** 수행 | 누락•중복 방지 |
| 전역 집계가 모든 샤드에 팬아웃 | **별도 서비스•비동기 집계** 적용 | 전역 조정 비용 통제 |

> 적용 사례: 다중 임차 서비스는 임차인 식별자로 데이터를 모아 대부분의 요청을 한 샤드에서 끝내고 대형 임차인은 별도 샤드로 격리

#### 한줄 요약

- 고객 자료를 한 지점에 모으되 큰 고객 하나가 지점을 독점하지 않게 분포를 감시한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **샤딩 방식 선택 기준**: 범위 지역성과 균등 분산 및 명시 배치 요구를 교차 샤드 비용과 함께 평가하는 기준이다.

</details>

- **샤딩 방식 선택 기준**에 따라 범위 조회는 **범위 샤딩**, 균등 점 조회는 **해시 샤딩**, 지정 배치는 **디렉터리 샤딩**을 선택한다.

#### 한줄 요약

- **샤딩 방식 선택 기준**은 요청을 담당 샤드에 모으면서 과부하를 고르게 분산한다.
