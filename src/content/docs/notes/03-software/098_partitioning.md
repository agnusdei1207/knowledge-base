## 미리 알고가기

- **파티셔닝(Partitioning)**: 한 테이블이나 인덱스를 같은 데이터베이스 안의 여러 논리 조각으로 나누는 기법임
- **파티션 프루닝(Partition Pruning)**: 질의 조건과 무관한 파티션을 실행 대상에서 제외하는 동작임
- **로컬 인덱스(Local Index)**: 각 파티션의 데이터만 대상으로 따로 관리하는 인덱스임
- **글로벌 인덱스(Global Index)**: 여러 파티션의 데이터를 하나의 키 구조로 연결하는 인덱스임
- **파티션 키(Partition Key)**: 각 행이 들어갈 파티션을 결정하는 열이나 표현식임
- **질의 술어(Query Predicate)**: 조회할 행이 만족해야 하는 조건식임
- **데이터 편중(Data Skew)**: 일부 파티션에 데이터나 요청이 과도하게 몰리는 현상임
- **수명주기(Lifecycle)**: 데이터가 생성되어 사용·보관·삭제되는 단계임

## Ⅰ. 개요

- 정의/개념: 테이블·인덱스를 관리 가능한 단위로 나눔
- **배경/필요성**: 테이블 증가로 조회·보관 단위 분할 필요

### 쉽게 이해하기 (학습용)
- 날짜나 고객 키로 데이터를 나누면 질의와 관리 작업이 필요한 파티션만 대상으로 수행될 수 있음

## Ⅱ. 특징

- 파티션 키 조건으로 무관한 범위를 읽기에서 제외한다.
- 삭제·보관·재구성을 파티션 단위로 처리한다.
- 키가 질의 조건과 다르면 프루닝 이득을 얻지 못한다.
- 특정 파티션 집중은 부하 편중과 관리 비용을 키운다.

### 쉽게 이해하기 (학습용)
- 기준이 나쁘면 한 서랍만 가득 차거나 모두 열어야 함

## Ⅲ. 아키텍처 및 구성요소

| 구성요소 | 설명 |
|:---|:---|
| 파티션 키 | 값 기준으로 나눌지 정해 프루닝 효과와 편중 가능성을 좌우함 |
| 파티션 매핑 규칙 | 값이 어떤 파티션으로 가는지 정의해 저장 경로를 결정함 |
| 로컬 또는 글로벌 인덱스 | 접근 횟수·인덱스 관리 비용 결정 |
| 수명주기 작업 | 추가와 병합 및 삭제로 성장과 보관 정책을 관리함 |

```text
  파티션키
      ↓
  매핑규칙
      ↓
  인덱스선택
      ↓
  주기작업
```

> 요약: 파티션 키·규칙으로 위치와 관리 결정

### 쉽게 이해하기 (학습용)
- 나누는 열과 색인 및 오래된 서랍 처리 방법을 설계함

## Ⅳ. 원리 및 절차 흐름도

```text
  조건확인
      ↓
  매핑계산
      ↓
  무관제외
      ↓
  대상관측
```

| 절차 | 설명 |
|:---|:---|
| **조건 추출** | 질의 술어에서 파티션 키와 조건을 확인함 |
| **파티션 매핑** | 범위와 해시 및 목록 규칙으로 파티션을 계산함 |
| **파티션 프루닝** | 조건과 무관한 파티션을 실행 계획에서 제외함 |
| **대상 파티션 조회** | 선택 파티션만 읽고 프루닝 수와 편중 여부를 관측함 |

> 요약: 파티션 키를 매핑해 제외하고 대상 파티션만 조회함

### 쉽게 이해하기 (학습용)
- 질의 조건으로 찾고 관계없는 서랍은 열지 않음

## Ⅴ. 종류 및 비교

| 판단 기준 | 범위 파티셔닝 | 해시 파티셔닝 | 리스트 파티셔닝 |
|:---|:---|:---|:---|
| 핵심 특징 | 연속된 값 구간으로 나눔 | 해시 함수 결과로 나눔 | 명시한 값 집합으로 나눔 |
| 주요 위험 | 특정 기간에 데이터가 몰릴 수 있음 | 범위 조회에서 프루닝 효과가 약함 | 값 관리가 늘어나면 운영이 복잡해짐 |
| 적용 기준 | 시계열 데이터에 적합함 | 쓰기 균등 분산이 필요할 때 적합함 | 유형별로 분리 관리할 때 적합함 |

> 요약: 범위는 연속, 해시는 균등, 목록은 값 집합

### 쉽게 이해하기 (학습용)
- 범위 방식은 연속 구간 조회와 기간 삭제에, 해시 방식은 균등 분산에, 리스트 방식은 명시한 업무 구분에 맞음

## Ⅵ. 실무 사례

1. 주문 시스템은 날짜 범위 파티셔닝을 적용하고 지연을 확인함

### 쉽게 이해하기 (학습용)
- 주문을 날짜별로 나누면 최근 조회는 관련 기간만 읽고 오래된 주문은 파티션 단위로 빠르게 보관·삭제할 수 있음

## Ⅶ. 결론

- 프루닝·분포·수명주기에 맞는 파티션 키 설계

### 쉽게 이해하기 (학습용)
- 파티셔닝은 나누는 것만으로 빨라지지 않으며 프루닝 비율·분포 편차·관리 시간을 측정해 경계를 조정해야 함
