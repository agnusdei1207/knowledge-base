## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **데이터 거버넌스(Data Governance)**: 전사 데이터 자산의 가치와 품질, 보안 및 규제 준수성을 보장하기 위해 수립하는 원칙, 정책, 프로세스, 조직(RACI) 체계.
- **Data Owner vs Data Steward**: 데이터 자산의 승인 및 위험 책임을 지는 Data Owner와 일상적 메타데이터 관리 및 품질 개선을 수행하는 Data Steward.

</details>

- 정의/개념: 기업 전사 데이터 자산의 신뢰성과 보안을 보장하기 위해 **원칙, 정책, 조직 체계(RACI), 표준화 및 거버넌스 기술을 통합 통제하는 관리 체계**
- 배경/필요성: 전사 데이터의 다변화 및 분산 소유로 인한 **용어 불일치, 데이터 품질 저하, 보안 규정 위반 및 컴플라이언스 위험 해결 불가**

#### 한줄 요약
- 원칙, 조직, 프로세스, 자동화 도구를 결합하여 데이터의 신뢰성과 보안을 전사적으로 통제한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **RACI Framework**: 데이터 거버넌스 태스크별로 실행(Responsible), 최종승인(Accountable), 자문(Consulted), 통보(Informed) 책임을 명확화한 매트릭스.
- **Policy-as-Code**: 거버넌스 보안 및 마스킹 규칙을 문서 규정이 아닌 OPA(Open Policy Agent) 코드로 자동화하여 엔진에 직접 강제 집행.

</details>

- 데이터 책임 주체를 명확히 정의하는 **조직 및 RACI 프레임워크(Owner/Steward)**
- 전사 용어, 단어, 코드, 도메인을 일체화하는 **데이터 표준화(Standardization)**
- PII 개인정보 마스킹 및 접근 제어를 코드로 강제하는 **Policy-as-Code 보안 자동화**

#### 한줄 요약
- 명확한 책임 조직과 표준화, 정책 코드화를 통해 전사 데이터 자산의 무결성을 확립한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **거버넌스 3대 축**: Governance Council(의사결정 위원회), Roles & Responsibilities(RACI 조직), Automated Tooling(카탈로그/품질/정책 엔진).

</details>

```text
[데이터 거버넌스 운영 체계 구조]
|-- Data Governance Council (최고 거버넌스 위원회: 전사 원칙, 표준, 분쟁 조정)
|   |-- Data Owners (도메인 본부장: 데이터 최종 승인, 비즈니스 책임)
|   `-- Data Stewards (실무 담당자: 메타데이터 관리, 품질 검증, 이슈 조치)
`-- Automated Tooling Layer (거버넌스 자동화 기술 인프라)
    |-- Data Catalog (OpenMetadata / DataHub: 전사 메타데이터 색인 및 계보)
    |-- Data Quality Profiler (Great Expectations: 룰 기반 품질 측정)
    `-- Policy Engine (Open Policy Agent: RBAC/ABAC 및 PII 동적 마스킹)
```

선의 의미: 계층 및 위원회의 정책이 Owner/Steward 조직을 통해 수립되고 자동화 도구로 전사 시스템에 집행되는 구조

| 구성요소 | 핵심 엔지니어링 책임 | 주요 특징 |
|:---|:---|:---|
| **거버넌스 위원회 (Council)** | 전사 데이터 전략 수립, 표준 정책 제정 및 **도메인 간 데이터 분쟁 최종 조정** | C-Level 및 부서장 참여 |
| **데이터 소유자 (Owner)** | 특정 비즈니스 도메인 데이터의 **접근 승인, 데이터 품질 SLA, 보안 최종 책임** | 본부장/리더급 |
| **데이터 스튜어드 (Steward)** | 비즈니스 용어 정의, 메타데이터 입력 및 **품질 결함 데이터 개선 실무 전담** | 도메인 실무 전문가 |
| **정책 엔진 (Policy Engine)** | 보안 및 개인정보 마스킹 정책을 **파이프라인 및 쿼리 엔진에 실시간 자동 강제** | OPA, Immuta |
| **카탈로그 및 품질 도구** | 전사 데이터 계보, 메타데이터, **품질 점수(DQ Score)를 모니터링 대시보드로 제공** | OpenMetadata, GE |

#### 한줄 요약
- 거버넌스 위원회, 데이터 오너/스튜어드, 정책 엔진, 카탈로그 도구가 유기적으로 연동된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **데이터 거버넌스 수립 5단계**: 자산 프로파일링 $\to$ 정책/표준 정의 $\to$ 책임자 지정 $\to$ 정책 자동 집행 $\to$ 모니터링 및 개선.

</details>

```text
전사 데이터 거버넌스 체계 구축 및 가동
        │
   1. [자산 프로파일링] 전사 데이터베이스 스캔을 통해 자산 중요도, PII 민감도, 품질 진단
        │
   2. [표준 및 정책 수립] 단어/용어/코드 표준 사전 제정 및 데이터 보존·품질 SLA 정의
        │
   3. [RACI 조직 지정] 도메인별 Data Owner 및 실무 Data Steward 공식 임명
        │
   4. [정책 자동 집행] Policy-as-Code 기반 OPA 엔진으로 접근 제어 및 PII 마스킹 자동화
        │
   5. 카탈로그 대시보드를 통해 품질 위반 및 정책 이탈을 상시 모니터링하고 피드백 개선
```

#### 한줄 요약
- 자산 프로파일링 → 표준 정의 → 조직 지정 → 정책 자동 집행 → 지속 개선 순으로 진행된다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **중앙형 vs 연합형 거버넌스**: 중앙 위원회가 모든 것을 통제하는 중앙형과 도메인 자율성과 공통 정책을 조화시키는 연합형(Federated).

</details>

| 비교 항목 | 중앙 집중식 데이터 거버넌스 | 연합형 전산 거버넌스 (Modern Federated) |
|:---|:---|:---|
| 의사결정 권한 | **중앙 거버넌스 위원회 독점** | **중앙 연합회(공통) + 도메인 팀(세부 자율)**|
| 정책 집행 방식 | **수동 문서 결재 및 인간 개입 중심** | **Policy-as-Code 기반 시스템 자동 집행** |
| 조직 대응 민첩성 | 일관성 높으나 승인 병목으로 지연 발생 | **도메인 자율성 기반 신속한 데이터 혁신** |
| 최적 아키텍처 | 전통적 단일 DW / 모놀리식 RDBMS | **Data Mesh, 분산 데이터 레이크하우스** |

#### 한줄 요약
- 단일 시스템은 중앙 집중형, 분산 도메인 환경은 연합형 전산 거버넌스를 선택한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Paper Governance**: 규정집 문서만 거창하게 작성하고 실제 시스템 자동 통제가 없어 실무에서 완전히 무시되는 안티패턴.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 규정집만 존재하고 시스템 강제가 없는 **Paper Governance** | **OPA(Open Policy Agent) 기반 Policy-as-Code 자동 집행 체계화** | 정책 위반 쿼리 원천 차단 |
| 지나치게 엄격한 수동 권한 결재로 인한 개발/분석 지연 | **Self-Serve 카탈로그 포털 연동으로 권한 자동 승인 파이프라인 구축** | 데이터 접근 리드타임 90% 단축 |
| 개발/테스트 DB로 원본 PII 개인정보가 평문 복제 유출 | **Bronze 데이터 수집 즉시 일괄 비식별화 및 동적 마스킹 강제** | 컴플라이언스 및 개인정보 보호 |
| 도메인 간 동일 용어의 서로 다른 비즈니스 해석 충돌 | **전사 비즈니스 용어집(Glossary) 제정 및 정기 심의 프로세스 운영** | 전사 지표 단일 진실 공급원 확립 |

#### 한줄 요약
- Policy-as-Code 자동화, 셀프서비스 권한 승인, PII 즉시 비식별화, 전사 용어집으로 운영한다.

## Ⅶ. 결론

- 성공적인 전사 데이터 민주화와 AI 혁신을 위해 **RACI 기반의 명확한 데이터 책임 조직을 구축하고 OpenMetadata 및 Policy-as-Code를 결합한 연합형 데이터 거버넌스를 표준 정립**하여 신뢰할 수 있는 엔터프라이즈 데이터 자산화 완성

#### 한줄 요약
- 데이터 거버넌스는 조직, 정책, 프로세스, 자동화 도구를 융합하여 데이터의 신뢰성과 보안 무결성을 보장하는 최고 수준의 데이터 관리 프레임워크다.
