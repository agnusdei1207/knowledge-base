## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **최단 경로(Shortest Path)**: 가중치 그래프의 두 정점 사이를 잇는 경로 중 간선 가중치(거리, 비용, 지연시간)의 총합이 최소가 되는 경로.
- **가중치(Weight)**: 간선에 부여된 물리적 거리, 네트워크 지연, 통행 비용 등의 수치적 비용 값.
- **최단 거리 테이블(Distance Array)**: 출발점으로부터 각 정점까지의 현재까지 발견된 최소 비용 후보 값을 보관하는 배열.

</details>

- 정의/개념: 출발점에서 목적점까지 간선 가중치 합이 가장 작은 경로를 찾는 **최단 경로(Shortest Path) 알고리즘 체계**
- 배경/필요성: BFS처럼 단순 홉(Hop) 수만 최소화하면 가중치가 다양한 실제 네트워크 및 지도 서비스에서 **실제 최소 비용 경로를 도출할 수 없으므로 가중치 기반 완화 알고리즘 필수**

#### 한줄 요약

- 거리·비용·지연 등 간선 가중치의 누적합을 최소화하는 최단 경로를 도출

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **최적 부분 구조(Optimal Substructure)**: 전체 최단 경로를 구성하는 임의의 부분 경로 역시 해당 구간의 최단 경로가 되는 수학적 성질.
- **완화(Relaxation)**: $d(v) > d(u) + w(u, v)$일 때 $d(v) = d(u) + w(u, v)$로 갱신하여 최단 거리를 점진적으로 단축하는 삼각부등식 연산.
- **수렴(Convergence)**: 완화 연산을 반복하여 더 이상 최단 거리 배열의 값이 갱신되지 않고 최적해가 확정된 상태.

</details>

- 출발지-목적지 간 최단 경로가 중간 정점들의 최단 경로로 구성되는 **최적 부분 구조** 만족
- 삼각부등식 기반 **완화(Relaxation)** 연산을 반복하여 거리 배열을 단조 감소시키고 최적해로 **수렴**
- 음수 가중치 허용 여부 및 단일 출발점(SSSP) vs 모든 정점 쌍(APSP) 범위에 따른 맞춤형 기법 분기

#### 한줄 요약

- 최적 부분 구조 전제 하에 완화 연산 $d(v) = \min(d(v), d(u) + w(u,v))$을 수렴 시까지 반복

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **선행 정점(Predecessor Vertex, $\pi[v]$)**: 최단 경로에서 정점 $v$ 직전에 위치한 정점으로 목적지에서 출발지로 역추적(Backtracking)하여 경로 복원에 사용.
- **우선순위 큐(Min-Heap Priority Queue)**: 다익스트라에서 미방문 정점 중 최단 거리 후보를 $O(\log V)$ 시간에 즉시 인출하기 위한 힙 자료구조.

</details>

```text
[ 최단 경로 알고리즘 핵심 아키텍처 ]
┌──────────────────────────────┐
│ 가중치 그래프 (Weighted G)   │ ── 정점(V), 간선(E), 가중치 w(u, v) 제공
├──────────────────────────────┤
│ 최단 거리 배열 (Distance[V]) │ ── 시작점으로부터 각 정점까지의 최소 비용 누적
├──────────────────────────────┤
│ 선행 정점 배열 (Pred[V])     │ ── 최단 경로 역추적을 위한 직전 부모 정점 기록
├──────────────────────────────┤
│ 완화 연산기 (Relaxation)     │ ── if (d[v] > d[u] + w) d[v] = d[u] + w 갱신
└──────────────────────────────┘
```

선의 의미: 가중치 그래프 데이터, 최단 거리 테이블, 선행 정점 배열 및 완화 연산기 간의 최단 경로 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 가중치 그래프 | 정점•간선•**가중치** 보관 |
| 최단 거리 배열 | 정점별 **최소 비용 후보** 누적 |
| 선행 정점 배열 | **경로 역추적**용 직전 정점 보관 |
| 완화 연산기 | **완화 규칙**으로 거리•경로 갱신 |

#### 한줄 요약

- 간선 가중치를 기반으로 완화 연산을 수행하고, 갱신 시 최단 거리 테이블과 선행 정점을 갱신

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **SSSP(Single-Source Shortest Path)**: 단일 출발 정점에서 다른 모든 정점까지의 최단 경로를 구하는 문제.
- **APSP(All-Pairs Shortest Path)**: 그래프 내의 모든 정점 쌍 간의 최단 경로를 구하는 문제.
- **음수 사이클(Negative Cycle)**: 사이클을 1회 순환할 때마다 가중치 합이 음수가 되어 최단 거리가 무한히 감소하는 순환.

</details>

```text
최단 경로 요구
├─ 모든 정점 쌍 (APSP)
│  ├─ 밀집 그래프: 플로이드-워셜 ($O(V^3)$)
│  └─ 희소 그래프: 가중치 조건별 SSSP 반복
└─ 단일 출발점 (SSSP)
   ├─ 음수 간선 없음: 다익스트라 ($O((V+E)\log V)$)
   └─ 음수 간선 존재: 벨만-포드 ($O(VE)$)
      ├─ $V$회차 추가 완화 성공: 음수 사이클 보고
      └─ 추가 완화 없음: 최단 경로 확정
```

**동작 원리**

1. **문제 범위 분류**: 단일 출발지(SSSP)인지 모든 정점 쌍(APSP) 경로인지 요구 범위를 분류
2. **비음수 가중치 경로 확정**: 음수 간선이 없는 경우 최소 힙 기반 **다익스트라**로 최단 거리를 탐욕적으로 확정
3. **음수 가중치 완화 및 사이클 검출**: 음수 간선이 포함된 경우 **벨만-포드**로 $V-1$회 완화 후 $V$회차 완화 성공 시 음수 사이클 예외를 처리
4. **전역 쌍 매트릭스 갱신**: 모든 정점 쌍 경로 계산 시 경유 노드를 점진 확장하는 **플로이드-워셜**을 적용

#### 한줄 요약

- 단일 출발점(SSSP) vs 모든 정점 쌍(APSP) 및 음수 가중치 존재 여부에 따라 최적의 최단 경로 알고리즘을 선택

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **다익스트라(Dijkstra)**: 비음수 가중치에서 우선순위 큐를 이용해 매 단계 최소 거리 정점을 확정하는 탐욕 알고리즘.
- **벨만-포드(Bellman-Ford)**: 모든 간선을 $V-1$회 반복 완화하여 음수 가중치 및 음수 사이클을 판정하는 동적 계획법 알고리즘.
- **플로이드-워셜(Floyd-Warshall)**: 3중 루프로 경유 정점 $k$를 1부터 $V$까지 확장하며 모든 쌍 최단 거리를 구하는 알고리즘.

</details>

| 비교 항목 | 다익스트라 (Dijkstra) | 벨만-포드 (Bellman-Ford) | 플로이드-워셜 (Floyd-Warshall) |
|:---|:---|:---|:---|
| 적용 기준 | **비음수 간선 SSSP** 최우선 시 | 음수 가중치 포함 **SSSP** 및 사이클 검출 시 | 모든 정점 쌍 **APSP** 및 전역 매트릭스 계산 |
| 핵심 특징 | **최소 힙** 기반 최소 거리 정점 탐욕적 확정 | 전체 간선 $E$를 $V-1$회 반복 완화 | 3중 루프 기반 **경유 정점 $k$** 점진 확장 |
| 한계 및 위험 | 음수 간선 존재 시 최단 거리 오산 발생 | $O(VE)$ 시간으로 대규모 그래프에서 지연 | $O(V^3)$ 시간 및 $O(V^2)$ 공간 오버헤드 급증 |

#### 한줄 요약

- 비음수 단일 출발은 다익스트라, 음수 간선은 벨만-포드, 모든 쌍 밀집 그래프는 플로이드-워셜 선택

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **무한대 오버플로(INF Overflow)**: 도달 불가 상태를 나타내는 `INF` 값에 간선 가중치를 더할 때 정수 오버플로로 음수가 되는 현상.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 음수 간선에서 다익스트라의 **거리 조기 확정** 오류 | 실행 전 가중치 범위 검증 후 벨만-포드 선택 | 가중치 조건에 맞는 **SSSP** 정확성 확보 |
| **음수 사이클** 영향 정점을 유한 거리로 오판 | $V$번째 추가 완화로 탐지하고 도달 정점 전파 | 최단거리 미정의 **음수 사이클** 식별 |
| **라우팅 범위•희소성**과 불일치한 전 쌍 계산으로 자원 급증 | SSSP•APSP와 희소성에 맞는 알고리즘 선택 | 불필요한 **APSP** 계산 낭비 제거 |
| 도달 불가와 큰 정상 거리 혼동•덧셈 오버플로 | `INF` 센티널 설정 및 **오버플로 안전 덧셈** 적용 | 무한대 상태와 정상 거리 명확히 구분 |

#### 한줄 요약

- 음수 가중치가 있으면 벨만-포드로 전환하고, V번째 완화로 음수 사이클을 탐지하며, INF 센티널과 안전 덧셈으로 도달 불가와 정상 거리를 구분해야 한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **가중치 조건(Weight Condition)**: 간선 가중치의 부호(비음수/음수)와 계산 범위(단일 출발점 SSSP/전 쌍 APSP)에 따라 최적 알고리즘이 달라지는 선택 기준.

</details>

- 비음수 SSSP는 **다익스트라**, 음수 간선 포함 SSSP는 **벨만-포드**, 모든 정점 쌍 APSP는 플로이드-워셜 선택

#### 한줄 요약

- 비음수 단일 출발점은 다익스트라, 음수 간선은 벨만-포드, 밀집 전 쌍은 플로이드-워셜을 선택
