## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **경사하강법(Gradient Descent)**: 손실 함수(Loss Function)의 기울기(Gradient) 반대 방향으로 파라미터를 반복 이동하여 손실을 최소화하는 최적화 기법.
- **비볼록 손실(Non-convex Loss)**: 지역 최솟값(Local Minima)과 안장점(Saddle Point)을 포함하여 전역 최적해(Global Optimum)를 찾기 어려운 손실 지형.
- **해석적 최적해(Analytical Solution)**: 미분 방정식이나 행렬 연산 등을 통해 반복 계산 없이 직접 산출되는 최적값.

</details>

- **정의**: 손실 함수의 기울기를 계산하고, 그 반대 방향으로 학습률(Learning Rate)만큼 파라미터를 반복 갱신하는 비볼록 최적화(Non-convex Optimization) 기법.
- **배경**: 파라미터가 많은 다층 구조 모형에서는 손실 지형의 복잡성으로 인해 해석적 최적해 도출이 불가하여 반복적 수치 최적화 필요.

#### 한줄 요약
- 최저점을 바로 풀 수 없는 손실 지형에서 발밑 경사인 기울기를 따라 반복 이동해 손실을 줄인다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **기울기 $\nabla L$**: 손실이 가장 빠르게 증가하는 방향과 크기를 모은 편미분 벡터이다.
- **학습률 $\eta$**: 기울기를 반영할 비율로 한 번의 파라미터 이동 폭을 정하는 값이다.
- **안장점**: 방향에 따라 손실이 낮아지거나 높아지며 기울기가 0에 가까운 지점이다.
- **기울기 추정 분산**: 미니배치 구성에 따라 계산된 기울기가 변하는 정도이다.
- **지역 최적해(Local Optimum)**: 주변 값보다 손실이 작지만 전체 최소는 아닐 수 있는 해이다.
- **발산(Divergence)**: 갱신이 최적점에서 멀어지며 손실이 계속 커지는 상태이다.
- **미니배치(Mini-batch)**: 한 번의 기울기 계산에 사용하는 학습 표본 묶음이다.

</details>

- **비볼록 손실**의 지역 최적해•**안장점**으로 초기값별 결과가 달라진다.
- **학습률**이 크면 최적점을 지나쳐 발산하고 작으면 학습 시간 증가한다.
- **미니배치** 축소가 연산량은 줄이되 **기울기 추정 분산**을 확대한다.

#### 한줄 요약
- 울퉁불퉁한 산에서 출발점과 발밑 표본이 달라지면 서로 다른 골짜기나 평평한 안장점에 멈춘다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **순전파(Forward Propagation)**: 예측과 손실을 입력에서 출력 방향으로 계산하는 과정이다.
- **역전파(Backpropagation)**: 파라미터별 손실 기울기를 출력에서 입력 방향으로 계산하는 과정이다.
- **최적화기 상태**: 모멘트나 누적 제곱 기울기처럼 다음 갱신에 사용하는 저장값이다.
- **종료 조건**: 손실 개선•반복 횟수•시간 등의 기준으로 학습을 멈추는 조건이다.
- **갱신 규칙**: 기울기와 최적화기 상태로 파라미터의 이동 방향과 크기를 정하는 규칙이다.
- **모멘트(Moment)**: 기울기의 평균과 제곱 평균으로 갱신을 보정하는 통계량이다.

</details>

```text
             [학습 루프]
               /     \
              /       \
          [모델] -- [최적화기] -- [최적화기 상태]
```

선의 의미: 네 구성요소가 학습 제어, 모델 계산, 파라미터 최적화, 최적화 상태 보관을 위해 직접 연결된 정적 협력 관계다.

| 구성요소 | 책임 |
|:---|:---|
| 학습 루프 | **미니배치** 공급과 **종료 조건** 판정 |
| 모델 | **순전파** 예측과 **역전파** 기울기 산출 |
| 최적화기 | 기울기•상태 기반 **갱신 규칙** 적용 |
| 최적화기 상태 | **모멘트**•누적 제곱 기울기 보관 |

#### 한줄 요약
- 작업반장이 표본을 건네면 모델이 경사도를 계산하고, 최적화기는 장부의 누적 상태를 참고해 가중치를 바꾼다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **파라미터 $\theta$**: 학습이 조정하는 모델의 가중치와 편향이다.
- **누적 제곱 기울기**: 좌표별 과거 기울기 제곱을 더해 적응적 보폭을 정하는 상태이다.
- **손실•기울기 계산**: 순전파로 손실을 구하고 역전파로 파라미터별 기울기를 산출하는 단계이다.
- **최적화기 상태 갱신**: 현재 기울기를 모멘트나 누적 제곱 기울기 상태에 반영하는 단계이다.
- **파라미터 갱신**: 학습률과 최적화기 상태로 정한 이동량을 모델 파라미터에 적용하는 단계이다.

</details>

```text
[파라미터•최적화기 상태 초기화]
              |
              v
+------------------------------------+
| 종료 조건을 충족하기 전            |
|                                    |
|  1. 손실•기울기 계산               |
|             |                      |
|             v                      |
|  2. 최적화기 상태 갱신             |
|             |                      |
|             v                      |
|  3. 파라미터 갱신                  |
|             |                      |
|             `---------- 반복 ------|
+------------------------------------+
              |
              v
[학습된 모델]
```

### 동작 원리

- **1. 손실•기울기 계산**: 순전파와 역전파로 기울기를 산출한다.
- **2. 최적화기 상태 갱신**: 모멘트•**누적 제곱 기울기** 이력을 반영한다.
- **3. 파라미터 갱신**: 학습률과 누적 상태를 모델에 반영한다.

#### 한줄 요약
- 컨베이어가 표본을 보내면 모델이 경사도를 적고 최적화기가 누적 장부와 보폭을 합쳐 가중치를 옮긴다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **확률적 경사하강법(Stochastic Gradient Descent, SGD)**: 무작위 미니배치의 기울기로 파라미터를 직접 갱신하는 방법이다.
- **적응적 기울기(Adaptive Gradient, AdaGrad)**: 누적 제곱 기울기로 자주 갱신된 파라미터의 보폭을 줄이는 방법이다.
- **적응적 모멘트 추정(Adaptive Moment Estimation, Adam)**: 기울기의 1•2차 모멘트 이동평균으로 방향과 보폭을 조정하는 방법이다.
- **희소 특징**: 대부분 표본에서 0이고 일부 표본에서만 값이 나타나는 입력 특성이다.
- **지수 이동평균(Exponential Moving Average, EMA)**: 최근 값에 더 큰 가중치를 두어 모멘트를 누적하는 평균이다.
- **상태 메모리**: 파라미터 외에 모멘트나 누적 기울기를 저장하는 메모리이다.
- **초기 수렴**: 학습 초기에 손실이 빠르게 감소해 유용한 성능에 도달하는 속성이다.
- **단조 감소**: AdaGrad의 누적 제곱 기울기가 커질수록 유효 학습률이 증가하지 않고 작아지는 성질이다.
- **적응 보폭**: 파라미터별 기울기 이력에 따라 각 좌표의 갱신 폭을 조정하는 방식이다.

</details>

| 최적화기 | SGD | AdaGrad | Adam |
|:---|:---|:---|:---|
| 적용 기준 | **상태 메모리** 여유가 없는 학습 | 입력의 **희소 특징** | 파라미터가 많고 **초기 수렴** 필요 |
| 핵심 특징 | 미니배치 **기울기**로 직접 갱신 | 특징별 **누적 제곱 기울기**로 보폭 축소 | **모멘트•EMA**로 방향•크기 보정 |
| 한계 | **학습률** 수동 조정•수렴 지연 | 학습률의 **단조 감소**로 학습 정체 | 두 모멘트의 **상태 메모리** 추가 |

> 요약: **상태 메모리•적응 보폭**의 필요성에 따라 최적화기를 선택한다.

#### 한줄 요약
- 빈 배낭의 SGD는 가볍고, 희소 좌표 장부를 쓰는 적응적 기울기와 두 모멘트 장부를 쓰는 적응적 모멘트 추정은 차례로 메모리를 더 쓴다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **기울기 클리핑**: 기울기 노름이 임계값을 넘으면 크기를 제한해 과도한 갱신을 막는 기법이다.
- **학습률 스케줄**: 학습 진행도나 손실 정체에 따라 학습률을 바꾸는 정책이다.
- **기울기 누적**: 여러 미니배치의 기울기를 더한 뒤 한 번 갱신하는 기법이다.
- **상태 분할**: 최적화기 상태를 여러 장치에 나눠 장치별 메모리 사용량을 줄이는 방식이다.
- **손실 진동**: 갱신마다 손실이 크게 오르내려 안정적으로 감소하지 않는 상태이다.
- **손실 정체**: 손실이 일정 수준에서 더 줄지 않는 상태이다.
- **배치 크기**: 한 번의 기울기 추정에 포함하는 표본 수이다.
- **혼합 정밀도(Mixed Precision)**: 여러 부동소수점 비트 폭을 함께 사용해 학습 메모리와 연산량을 줄이는 방식이다.
- **그래픽 처리 장치(Graphics Processing Unit, GPU)**: 병렬 연산으로 모델 학습을 수행하는 처리 장치이다.
- **GPU 메모리**: 모델 파라미터•활성값•기울기•최적화기 상태를 저장하는 GPU 장치 메모리이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **손실 진동•발산** 발생 | 학습률 축소•**기울기 클리핑** | **발산** 억제와 갱신 폭 안정화 |
| **손실 정체** 지속 | **학습률 스케줄**•초기값•최적화기 재조정 | 손실 정체 완화 |
| 높은 **기울기 추정 분산** | 배치 크기 확대•**기울기 누적** | 기울기 추정 분산 감소 |
| Adam 상태로 **GPU 메모리** 부족 | **혼합 정밀도**•**상태 분할** 또는 SGD 검토 | 더 큰 모델의 학습 가능 |

#### 한줄 요약
- 계기판의 손실 곡선이 출렁이면 보폭을 줄이고, 적응적 모멘트 추정 장부가 GPU 선반을 넘치면 상태 분할이나 SGD로 바꾼다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **선택 기준**: 상태 메모리•희소 특징•초기 수렴 요구로 최적화기를 구분하는 기준이다.

</details>

- **선택 기준(Selection Criteria)**인 상태 메모리(State Memory), 데이터 희소성(Sparsity), 초기 수렴성(Initial Convergence)을 고려한 **SGD·AdaGrad·Adam** 최적화기 선택 및 운영 체계 적용.
