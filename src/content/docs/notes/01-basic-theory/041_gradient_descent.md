## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **음의 기울기(Negative Gradient)**: 손실 함수의 값을 가장 가파르게 감소시키는 벡터 방향($-\nabla_\theta L$)으로의 이동 벡터.
- **폐쇄형 해(Closed-form Solution)**: 유한한 수식 전개로 직접 계산할 수 있는 해이며, 일반적인 비선형 신경망 손실에는 존재하지 않는다.

</details>

- 정의/개념: 모델 파라미터를 손실 함수의 **음의 기울기** 방향으로 반복 갱신하여 최적의 가중치를 탐색하는 수치 최적화 알고리즘
- 배경/필요성: 비선형 손실은 **폐쇄형 해**가 없어 한 번의 수식 전개로 최적해를 얻을 수 없고 파라미터 공간을 전수 탐색하면 차원에 지수적인 비용이 들므로, 현재 지점의 기울기만 국소적으로 읽어 한 걸음씩 내려가는 반복 갱신 계층으로 전역 탐색을 대체

#### 한줄 요약

- 전역 탐색을 국소 기울기로 대체한 대가로 도달점이 초기값과 학습률에 좌우되어, 보폭이 크면 발산하고 작으면 정체한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **모멘텀(Momentum, $m_t$)**: 과거 기울기의 지수 이동평균(EMA)을 누적하여 관성(Inertia)을 부여함으로써 안장점 탈출 및 진동을 억제하는 기법.
- **적응형 학습률(Adaptive Learning Rate, $v_t$)**: 자주 등장하거나 기울기가 큰 파라미터는 보폭을 줄이고, 희소한 파라미터는 보폭을 넓혀 파라미터별 차등 갱신을 수행하는 기법.

</details>

- 미니배치 확률적 노이즈로 안장점 및 얕은 국소해 탈출
- 방향 보정과 적응적 보폭 조절을 통한 **수렴 속도 개선**
- 학습률 크기에 따른 **발산 위험과 수렴 정체 간의 트레이드오프**

#### 한줄 요약

- 모멘텀을 통한 관성 방향 유지와 2차 모멘트 기반 적응형 학습률로 손실 최소화 지점으로 수렴

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **기울기(Gradient, $g_t$)**: 현재 미니배치 손실을 파라미터별로 편미분한 갱신 방향 벡터.
- **1차 모멘트(First Moment, $m_t$)**: 과거 기울기의 지수 이동평균을 보관하는 옵티마이저 상태.
- **2차 모멘트(Second Moment, $v_t$)**: 과거 기울기 제곱의 지수 이동평균을 보관하는 옵티마이저 상태.

</details>

```text
[학습 루프]
|
+-- [모델]
`-- [옵티마이저]
    `-- [옵티마이저 상태]
```

선의 의미: 학습 루프의 제어와 옵티마이저의 상태 소유 관계

| 구성요소 | 책임 |
|:---|:---|
| 학습 루프 | 미니배치 공급과 **반복 종료** 제어 |
| 모델 | 순전파 손실과 역전파 **기울기** 산출 |
| 옵티마이저 | 기울기에 따른 **파라미터 갱신** |
| 옵티마이저 상태 | 1차·2차 **모멘트** 누적 보관 |

#### 한줄 요약

- 옵티마이저가 현재 기울기 외에 과거 모멘트라는 상태를 들고 있어야 하므로, 갱신 규칙이 정교해질수록 파라미터 수에 비례하는 메모리를 더 쓴다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **바이어스 보정(Bias Correction)**: Adam에서 $m_0=0, v_0=0$ 초기화로 인해 초기 스텝에서 모멘트 추정치가 0으로 편향되는 현상을 $\hat{m}_t = \frac{m_t}{1-\beta_1^t}, \hat{v}_t = \frac{v_t}{1-\beta_2^t}$로 보정하는 연산.

</details>

```text
미니배치 데이터 (X_batch, y_batch) 인입
   │
   ▼
[ 1. 순전파 및 손실 계산 ] : Loss = L(y_hat, y)
   │
   ▼
[ 2. 역전파 오차 기울기 계산 ] : g_t = ∇_θ L
   │
   ▼
[ 3. 옵티마이저 모멘트 갱신 ] : m_t 및 v_t 지수 이동평균 갱신
   │
   ▼
[ 4. 바이어스 보정 ] : m_hat = m_t / (1-β1^t), v_hat = v_t / (1-β2^t)
   │
   ▼
[ 5. 파라미터 갱신 ] : θ_(t+1) = θ_t - η · [ m_hat / (√(v_hat) + ε) ]
```

**동작 원리**

1. **순전파 및 손실 계산**: 미니배치 입력으로 모델 손실 $L(\theta)$ 계산
2. **역전파 오차 기울기 계산**: 역전파를 통해 파라미터별 편미분 벡터 $g_t$ 산출
3. **옵티마이저 모멘트 갱신**: 과거 방향과 현재 기울기를 결합해 모멘트 갱신
4. **바이어스 보정**: 초기 스텝 편향을 보정 계수로 스케일 복원
5. **파라미터 갱신**: 정규화된 보폭을 적용해 가중치 $\theta$ 최종 갱신

#### 한줄 요약

- 역전파로 기울기를 구하고 모멘텀과 적응형 학습률을 결합하여 파라미터를 갱신

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **모멘텀 확률적 경사하강법(SGD with Momentum)**: 현재 기울기에 과거 이동 방향의 관성을 더해 진동을 줄이고 수렴을 가속하는 기법.
- **AdaGrad**: 자주 갱신되는 파라미터의 학습률을 줄이고 희소한 파라미터의 학습률을 유지하는 적응형 기법.
- **Adam(Adaptive Moment Estimation)**: 1차 모멘텀과 2차 적응형 학습률을 결합하여 빠른 수렴과 안정성을 달성한 표준 최적화 기법.

</details>

| 최적화 알고리즘 | SGD (with Momentum) | AdaGrad | Adam (Adaptive Moment) |
|:---|:---|:---|:---|
| 적용 기준 | 일반화 성능을 우선하는 **비전 모델** | 희소 특징의 학습률 보존 | 빠른 초기 수렴이 필요한 **범용 학습** |
| 핵심 특징 | 과거 기울기의 **모멘텀** 결합 | 누적 제곱 기울기별 **학습률 감소** | **1차·2차 모멘트** 기반 보폭 조절 |
| 한계 | **학습률** 설정에 따른 수렴 민감성 | 누적 분모 증가로 **학습 조기 정체** | 모멘트 상태의 **메모리 비용** 증가 |

#### 한줄 요약

- 메모리 절약과 최종 일반화는 SGD+Momentum, 빠른 수렴과 범용성은 Adam을 선택

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **AdamW(Decoupled Weight Decay)**: Adam에서 L2 규제가 적응형 2차 모멘트($v_t$)에 의해 왜곡되는 문제를 해결하기 위해 손실 함수와 가중치 감쇄(Weight Decay)를 완전히 분리하여 직접 가중치를 감소시키는 표준 옵티마이저.
- **기울기 클리핑(Gradient Clipping)**: 기울기 벡터의 L2 노름이 임계값(예: 1.0)을 초과할 때 $\mathbf{g} \leftarrow \mathbf{g} \cdot \frac{c}{\|\mathbf{g}\|}$로 크기를 잘라 기울기 폭발(Explosion)을 방지하는 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 심층망에서 **기울기 폭발**로 학습 발산 | **기울기 클리핑**으로 기울기 노름 제한 | 갱신 폭 제한으로 학습 발산 방지 |
| Adam의 L2 규제 왜곡으로 일반화 저하 | 감쇄를 분리한 **AdamW** 전환 | 가중치 감쇄 효과 복원 |
| 대규모 학습에서 옵티마이저 상태로 메모리 고갈 | **상태 샤딩** 또는 8비트 Adam 적용 | 장치별 옵티마이저 메모리 절감 |
| 학습 후반 손실 정체와 최적점 주변 진동 | **코사인 감쇠**와 웜업 적용 | 후반 학습률 감소로 진동 완화 |

#### 한줄 요약

- AdamW로 가중치 감쇄를 분리 적용하고, Gradient Clipping으로 기울기 폭주를 방지하며, Cosine 스케줄러로 학습률을 점진 감소시켜 수렴을 안정화한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **현대 딥러닝 옵티마이저 표준**: 트랜스포머 및 LLM 훈련에는 AdamW + Cosine Warmup 스케줄러가 사실상의 업계 표준으로 정착되었으며, 극한의 비전 모델 파인튜닝에는 SGD with Momentum이 병행 활용.

</details>

- 일반화 성능 중시는 **SGD(Momentum)**, 범용 고속 수렴은 **AdamW** 선택

#### 한줄 요약

- 메모리•희소성•수렴 속도로 최적화기를 고르고 손실 곡선으로 학습률을 조정
