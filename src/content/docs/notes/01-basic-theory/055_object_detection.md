## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **객체 탐지**: 이미지 속 여러 객체의 위치와 클래스를 함께 예측하는 비전 기법이다.
- **바운딩 박스**: 객체의 위치를 감싸는 사각형 좌표이다.
- **컴퓨터 비전(Computer Vision)**: 이미지나 영상에서 객체•장면 정보를 분석하는 기술 분야이다.
- **다중 객체**: 한 이미지 안에 동시에 존재하는 둘 이상의 탐지 대상이다.

</details>

- 정의/개념: **객체 탐지**는 이미지 안의 **다중 객체** 각각에 대해 클래스와 위치를 바운딩 박스 및 신뢰도 점수로 함께 예측하는 컴퓨터 비전 기법이다.
- 배경/필요성: 이미지 전체에 하나의 라벨만 붙이는 분류로는 여러 객체가 어디에 있고 각각 어떤 클래스인지 판정할 수 없다.

#### 한줄 요약
- 객체 탐지는 사진 속 사람•차마다 사각 테두리와 이름표를 붙여 위치와 종류를 함께 답한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **교집합 대 합집합 비율(Intersection over Union, IoU)**: 예측 상자와 정답 상자의 영역 일치도이다.
- **평균 정밀도(Average Precision, AP)**: 정밀도-재현율 곡선을 요약한 클래스별 탐지 지표이다.
- **평균 정밀도 평균(mean Average Precision, mAP)**: 클래스별 AP를 평균한 객체 탐지 지표이다.
- **비최대 억제(Non-Maximum Suppression, NMS)**: 겹치는 후보 중 점수가 높은 상자만 남기는 후처리이다.
- **바운딩 박스 회귀(Bounding Box Regression)**: 객체 사각형 좌표를 연속값으로 예측하는 작업이다.
- **객체 분류(Object Classification)**: 탐지한 객체의 범주를 판정하는 작업이다.
- **특징 피라미드(Feature Pyramid)**: 여러 해상도의 특징 맵을 결합해 크기가 다른 객체를 탐지하는 구조이다.

</details>

- **바운딩 박스 회귀**•**객체 분류**를 수행하고 **mAP**로 정확도를 평가한다.
- 다수 후보 박스의 점수•**IoU** 기반 **NMS 후처리**가 핵심이다.
- **특징 피라미드**를 통한 크기가 다른 객체의 동시 탐지가 핵심이다.

#### 한줄 요약
- 다중 해상도 특징 맵으로 대형 객체와 소형 객체를 탐지하고, 중복 바운딩 박스는 NMS 후처리로 하나만 남기는 구조이다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **백본(Backbone)**: 이미지에서 기본 특징을 추출하는 모델 부분이다.
- **넥(Neck)**: 여러 해상도의 특징을 결합하는 모델 부분이다.
- **객체성**: 특정 위치에 종류와 무관하게 객체가 존재할 가능성을 나타내는 점수이다.
- **다중 해상도 특징**: 큰 객체와 작은 객체를 함께 표현하도록 서로 다른 공간 크기에서 추출한 특징 맵이다.
- **중복 박스**: 같은 객체를 가리키며 크게 겹치는 여러 예측 상자이다.

</details>

```text
[특징 추출기] ----- [탐지 헤드] ----- [NMS 후처리]
```

선의 의미: 선은 다중 해상도 특징과 후보 박스를 공유하는 인접 구성요소의 정적 인터페이스 관계를 뜻한다.

| 구성요소 | 책임 |
|:---|:---|
| 특징 추출기 | **백본•넥**으로 다중 해상도 **특징 피라미드** 생성 |
| 탐지 헤드 | 박스 위치•클래스•**객체성** 예측 |
| NMS 후처리 | 점수 미달•높은 IoU의 **중복 박스** 제거 |

#### 한줄 요약
- 특징 피라미드가 크기별 특징을 전달하면 탐지 헤드가 바운딩 박스와 클래스를 예측하고 NMS가 중복 박스를 제거하는 구조이다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **후보 박스**: 탐지 헤드가 객체가 있을 것으로 예측한 위치 후보이다.
- **중복 억제**: 같은 객체를 가리키는 겹친 상자 중 대표 결과만 남기는 처리이다.
- **객체성 점수**: 후보 위치에 객체가 존재할 가능성을 나타내는 값이다.
- **다중 해상도 특징 추출**: 서로 다른 공간 크기의 특징 맵을 만들어 크기별 객체 표현을 얻는 단계이다.
- **후보 박스•점수 예측**: 각 위치에서 바운딩 박스•클래스•객체성 점수를 산출하는 단계이다.
- **점수 필터링•중복 억제**: 신뢰도가 낮은 후보를 거르고 겹친 후보 중 대표 상자만 남기는 단계이다.

</details>

```text
[입력 이미지]
      |
      v
1. 다중 해상도 특징 추출
      |
      v
2. 후보 박스•점수 예측
      |
      v
3. 점수 필터링•중복 억제
      |
      v
[객체별 바운딩 박스•클래스]
```

### 동작 원리

- **1. 다중 해상도 특징 추출**: 크기별 객체 표현을 생성한다.
- **2. 후보 박스•점수 예측**: 위치•클래스•**객체성 점수**를 산출한다.
- **3. 점수 필터링•중복 억제**: 저신뢰•고중첩 후보를 제거한다.

#### 한줄 요약
- 입력 이미지가 다중 해상도 특징 추출과 후보 박스 예측을 거쳐 중복 억제된 최종 탐지 결과로 출력되는 흐름이다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **한 번만 보기(You Only Look Once, YOLO)**: 이미지 전체에서 위치와 클래스를 한 번에 예측하는 1단계 모델이다.
- **영역 기반 합성곱 신경망(Region-based Convolutional Neural Network, R-CNN)**: 후보 영역을 먼저 만들고 클래스와 위치를 정밀화하는 2단계 모델이다.
- **영역 제안**: 객체 가능성이 높은 영상 구역을 정밀 분류 대상으로 추리는 절차이다.
- **엣지 메모리**: 현장 장치가 모델과 중간 특징을 저장하는 데 사용할 수 있는 메모리 한도이다.
- **위치 정밀도**: 예측 바운딩 박스가 실제 객체 경계와 맞는 정도이다.
- **실시간 추론**: 카메라 입력 속도에 맞춰 짧은 지연으로 탐지 결과를 내는 처리이다.
- **정밀 검출**: 소형•밀집 객체까지 높은 재현율과 위치 정확도로 찾는 요구이다.
- **추론 지연**: 입력을 받은 시점부터 탐지 결과를 출력할 때까지 걸리는 시간이다.
- **1단계 객체 탐지**: 영역 제안 단계를 분리하지 않고 이미지 전체에서 위치와 클래스를 한 번에 예측하는 구조이다.
- **2단계 객체 탐지**: 영역 제안 후 후보별 분류와 위치 정밀화를 수행하는 구조이다.

</details>

| 객체 탐지 구조 | 1단계(YOLO 계열) | 2단계(R-CNN 계열) |
|:---|:---|:---|
| 적용 기준 | **실시간 추론**이나 엣지 메모리가 제한된 경우 | 소형•밀집 객체의 **정밀 검출**이 필요한 경우 |
| 핵심 특징 | 이미지 전체에서 위치•클래스 동시 예측 | **영역 제안** 후 분류•위치 정밀화 |
| 한계 | 소형•밀집 객체의 **위치 정밀도** 저하 | 2단계 순차 처리의 **추론 지연** |

> 요약: **1단계 객체 탐지**는 추론 속도, **2단계 객체 탐지**는 위치 정밀도 우선이 핵심이다.

#### 한줄 요약
- YOLO는 이미지 전체에서 위치와 클래스를 한 번에 예측하고, R-CNN은 영역 제안 후 정밀 분류와 위치 보정을 수행하는 구조이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **포컬 손실**: 쉬운 배경 표본의 가중치를 낮춰 어려운 객체 표본 학습에 집중하는 손실 함수이다.
- **클래스 불균형**: 배경 표본이 객체 표본보다 압도적으로 많아 학습이 치우친 상태이다.
- **양자화**: 수치 정밀도를 낮춰 모델 크기와 연산량을 줄이는 경량화 기법이다.
- **엣지 기기**: 데이터 발생 현장에서 제한된 전력과 메모리로 추론하는 소형 장치이다.
- **미탐(False Negative)**: 실제 객체가 있지만 탐지 결과에서 놓친 오류이다.
- **재현율(Recall)**: 실제 객체 중 모델이 올바르게 탐지한 비율이다.
- **IoU 임계값**: 상자 중복 여부나 정답 일치를 판정하는 IoU 기준값이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 소형•밀집 객체의 **미탐** 증가 | 고해상도 입력•**특징 피라미드**•**2단계 객체 탐지** 검토 | 작은 객체 **재현율** 향상 |
| 동일 객체의 **중복 박스** 잔존 | 점수•**IoU 임계값**을 검증 데이터로 조정 | 중복 탐지 감소 |
| 배경 비중이 커 객체 학습 약화 | **포컬 손실**•표본 균형화 적용 | **클래스 불균형** 완화 |
| **엣지 기기**의 지연•메모리 초과 | 경량 백본•**양자화**•입력 크기 조정 | 목표 추론 시간•메모리 용량 충족 |

#### 한줄 요약
- 소형 객체의 미탐이 증가하면 고해상도 입력과 특징 피라미드 계층을 추가하여 재현율을 높이는 과정이다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **탐지 구조 선택 기준**: 실시간•엣지 제약과 소형•밀집 객체의 정밀도 요구로 1단계 또는 2단계 구조를 고르는 기준이다.

</details>

- **탐지 구조 선택 기준**에 따라 **실시간 추론**•엣지 환경은 **1단계 객체 탐지**, 소형•밀집 객체의 **정밀 검출**은 **2단계 객체 탐지**를 선택한다.

#### 한줄 요약
- 실시간•엣지는 YOLO 계열 1단계, 소형•밀집 객체의 정밀 검출은 R-CNN 계열 2단계를 선택한다.
