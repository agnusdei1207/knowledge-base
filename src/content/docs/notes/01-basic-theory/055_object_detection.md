## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **객체 탐지(Object Detection)**: 이미지 내에 존재하는 모든 대상 객체들의 위치(바운딩 박스)와 클래스를 동시에 예측하는 컴퓨터 비전 기술.
- **바운딩 박스(Bounding Box, BBox)**: 객체의 위치와 크기를 감싸는 직사각형 좌표($x, y, w, h$).
- **IoU(Intersection over Union)**: 실제 정답 영역과 예측 영역의 합집합 면적 대비 교집합 면적의 비율($\text{교집합}/\text{합집합}$).

</details>

- 정의/개념: 이미지 내 존재하는 복수 객체의 **위치(바운딩 박스)와 클래스(카테고리)를 동시에 예측**하는 딥러닝 비전 핵심 기술
- 배경/필요성: 단순 단일 객체 이미지 분류를 넘어 자율주행, 보안관제 등 실세계 다중 객체의 공간적 위치 특정 및 실시간 인식 요구 증가

#### 한줄 요약

- 이미지 안의 다중 객체 위치를 바운딩 박스로 찾고 클래스를 분류하는 기술

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **2-Stage Detector**: 영역 제안(Region Proposal)과 영역 분류(Classification)를 두 단계로 나누어 순차 처리하는 구조.
- **1-Stage Detector**: 영역 제안 없이 전체 이미지를 단일 신경망에 통과시켜 위치와 클래스를 한 번에 회귀 예측하는 구조.

</details>

- **위치 인식(Localization) 및 분류(Classification)** 대상 다중 손실(Multi-task Loss) 동시 최적화
- 2-Stage Detector: 영역 제안과 정밀 분류의 분리를 통한 **높은 검출 정확도(mAP) 달성**
- 1-Stage Detector: 단일 회귀 파이프라인 설계를 통한 **실시간 고속 추론(FPS) 구현** #### 한줄 요약

- 2-Stage는 높은 정확도, 1-Stage는 실시간 속도에 특화되어 상호 발전

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **백본(Backbone)**: 입력 이미지에서 다중 스케일 특징 맵을 추출하는 기본 합성곱 신경망(ResNet, Darknet 등).
- **영역 제안 네트워크(Region Proposal Network, RPN)**: 특징 맵 상에서 객체가 존재할 만한 후보 영역 바운딩 박스를 추천하는 모듈.
- **NMS(Non-Maximum Suppression)**: 겹치는 여러 개의 바운딩 박스 중 신뢰도 점수가 가장 높은 박스만 남기고 중복을 억제하는 후처리 알고리즘.

</details>

```text
[ 2-Stage: Faster R-CNN 구조 ]
입력 영상 ──► [ Backbone ] ──► [ RPN (후보 영역 제안) ] ──► [ RoI Pooling ] ──► [ 분류 & BBox 회귀 Head ]

[ 1-Stage: YOLO 구조 ]
입력 영상 ──► [ Backbone ] ──► [ Neck (FPN/PANet) ] ──► [ Dense Prediction Grid Head ] ──► [ NMS 후처리 ]
```

선의 의미: 객체 탐지 아키텍처의 특징 추출, 영역 제안, 최종 예측 흐름

| 구성요소 | 책임 |
|:---|:---|
| 백본(Backbone) | 원본 이미지로부터 저차원~고차원 **특징 맵(Feature Map) 추출** |
| 넥(Neck / FPN) | 다양한 해상도의 특징 맵을 융합하여 **멀티스케일 표현력 강화** |
| RPN / Grid Head | 객체 존재 후보 영역 제안(2-Stage) 또는 **그리드별 직접 예측(1-Stage)** |
| NMS 후처리기 | 중복 예측된 바운딩 박스들을 제거하여 **최종 단일 박스 선별** |

#### 한줄 요약

- 백본의 특징 추출, 넥의 특징 융합, 헤드의 위치/클래스 예측, NMS 중복 제거로 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **FPN(Feature Pyramid Network)**: 상위 계층의 고수준 의미 정보와 하위 계층의 고해상도 공간 정보를 결합하여 소형 객체 검출력을 높이는 구조.

</details>

```text
원본 이미지 입력
      │
      ▼
[ 1. 백본 기반 계층적 특징 맵 추출 ]
      │
      ▼
[ 2. 멀티스케일 FPN 특징 융합 ]
      │
      ▼
[ 3. 바운딩 박스 좌표 및 클래스 확률 예측 ]
      │
      ▼
[ 4. 신뢰도 임계값 필터링 ]
      │
      ▼
[ 5. 비최대 억제(NMS) 적용 및 최종 탐지 확정 ]
```

**동작 원리** 1. **백본 기반 계층적 특징 맵 추출**: 합성곱 연산을 통해 해상도별 특징 맵 생성
2. **멀티스케일 FPN 특징 융합**: 하향식 경로와 횡단 연결을 통해 고수준 의미와 세부 공간 정보 결합
3. **바운딩 박스 좌표 및 클래스 확률 예측**: 그리드 셀 또는 앵커 박스 단위로 $(x, y, w, h)$와 클래스 점수 산출
4. **신뢰도 임계값 필터링**: 배경 확률이 높거나 신뢰도가 낮은 박스 사전 배제
5. **비최대 억제(NMS) 적용 및 최종 탐지 확정**: IoU 임계값 이상의 중복 박스를 병합 제거하여 최종 바운딩 박스 출력

#### 한줄 요약

- 특징 맵을 추출하고 FPN으로 융합한 뒤 위치와 클래스를 동시 예측하고 NMS로 중복을 제거

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **DETR(Detection Transformer)**: 앵커 박스와 NMS 후처리 없이 트랜스포머의 어텐션 메커니즘과 이분 매칭 손실만으로 객체를 탐지하는 최신 아키텍처.

</details>

| 객체 탐지 구조 | 2-Stage (Faster R-CNN) | 1-Stage (YOLO) | Transformer 기반 (DETR) |
|:---|:---|:---|:---|
| 적용 기준 | **정밀 불량 검사·의료 영상** 등 최고 정확도 우선 시 | **자율주행·CCTV 관제** 등 실시간 고속 처리 요구 시 | **엔드투엔드(End-to-End) 학습** 및 후처리 제거 선호 시 |
| 핵심 특징 | RPN 후보 제안과 RoI 분류의 **2단계 순차 처리** | 그리드 분할 기반 **단일 단계 동시 회귀 예측** | 셀프 어텐션 기반 **전역 문맥 파악 및 세트 예측** |
| 한계 | 연산 복잡도로 인한 **실시간 추론 불가(낮은 FPS)** | 소형 객체 밀집 시 **검출 정확도 상대적 저하** | 대규모 데이터 요구 및 **긴 훈련 수렴 시간** |

#### 한줄 요약

- 정밀 판독은 2-Stage, 실시간 관제는 1-Stage, 후처리 없는 완전 종단 학습은 DETR을 선택

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **초점 손실(Focal Loss)**: 쉬운 예제(배경)의 손실 가중치를 낮추고 어려운 예제(객체)에 집중하도록 교차 엔트로피를 수정한 손실 함수.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 동일 객체에 대한 **다중 중복 바운딩 박스 오탐** | **IoU 임계값 기반 비최대 억제(NMS) 및 Soft-NMS 적용** | 중복 박스 제거 및 최적 단일 박스 확정 |
| 원거리 **소형 객체(Small Object) 검출 실패** | **특징 피라미드(FPN) 구축 및 다중 스케일 훈련** | 해상도 유지 및 소형 객체 검출률 향상 |
| 배경과 객체 간 극단적인 **클래스 불균형(Class Imbalance)** | **초점 손실(Focal Loss) 도입 및 OHEM 적용** | 쉬운 배경 손실 억제 및 검출기 학습 안정화 |

#### 한줄 요약

- 중복 박스는 NMS로 병합하고, 소형 객체는 FPN으로 포착하며, 클래스 불균형은 초점 손실로 완화

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **엣지 비전 AI**: 임베디드 보드나 모바일 기기 상에서 실시간으로 구동되는 경량 객체 탐지 시스템.

</details>

- 실시간성(30fps 이상)이 필수적인 자율주행 및 로보틱스 관제에는 YOLO 계열의 1-Stage 검출기를 채택하고, 정밀 판독이 핵심인 의료/제조 불량 검사 과업에는 Faster R-CNN을 적용하는 도메인별 분기 전략이 타당

#### 한줄 요약

- 속도가 핵심인 환경은 YOLO, 정밀도가 핵심인 환경은 Faster R-CNN을 선택
