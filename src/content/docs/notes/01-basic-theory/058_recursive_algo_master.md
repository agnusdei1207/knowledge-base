## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **재귀 알고리즘**: 입력을 줄여 자신을 다시 호출하고 종료 조건에서 결과를 반환하는 알고리즘이다.
- **점화식**: 입력 크기별 비용을 더 작은 입력의 비용으로 표현한 식이다.
- **마스터 정리(Master Theorem)**: 균등 분할 점화식의 부분 문제 비용과 결합 비용을 비교해 점근 복잡도를 구하는 정리이다.
- **시간 증가율(Time Growth Rate)**: 입력이 커질 때 실행 시간이 늘어나는 정도이다.
- **스택 증가율(Stack Growth Rate)**: 입력이 커질 때 호출 스택 사용량이 늘어나는 정도이다.

</details>

- 정의/개념: **마스터 정리**는 재귀 알고리즘의 **점화식** $T(n)=aT(n/b)+f(n)$에서 재귀 호출과 결합 비용의 지배 관계로 **시간 증가율**을 구하는 정리이다.
- 배경/필요성: 재귀 알고리즘은 호출 수와 입력 축소 및 단계별 결합 비용이 여러 깊이에 중첩되어 **스택 증가율**과 전체 시간 증가율을 직관만으로 판정하기 어렵다.

#### 한줄 요약
- 재귀가 작은 러시아 인형을 계속 열어 마지막 인형에서 멈춘다면, 마스터 정리는 각 층의 호출 비용과 결합 비용 중 무엇이 전체 시간을 지배하는지 판정한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **종료 조건**: 재귀 호출을 멈추고 직접 결과를 반환하는 조건이다.
- **점근 복잡도**: 입력이 커질 때 시간이나 공간 사용량이 증가하는 차수이다.
- **분할 비용(Divide Cost)**: 문제를 부분 문제로 나누는 데 드는 비용이다.
- **결합 비용(Combine Cost)**: 부분 해를 전체 해로 합치는 데 드는 비용이다.

</details>

- **종료 조건**을 확인하고 줄어든 입력으로 자신을 다시 호출하는 자기 참조 구조이다.
- **점화식**으로 부분 문제 수•크기와 **분할 비용**•**결합 비용**을 표현하는 것이 핵심이다.
- **마스터 정리**로 균등 분할 점화식의 점근 복잡도를 판정한다.

#### 한줄 요약
- 러시아 인형마다 작은 인형 수와 포장 비용을 적고 어느 층의 비용 더미가 가장 큰지 고르는 장면이다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **호출 스택**: 함수 호출 기록과 복귀 지점을 순서대로 쌓는 메모리 공간이다.
- **스택 프레임**: 각 호출의 지역 변수와 복귀 주소를 담는 기록이다.
- **비용 모델**: 부분 문제 수 $a$, 축소 비율 $b$, 결합 비용 $f(n)$으로 실행 비용을 표현한 구조이다.

</details>

```text
[재귀 알고리즘 분석]
        |
        +-- [재귀 함수]
        +-- [호출 스택]
        +-- [점화식]
        `-- [마스터 정리]
```

선의 의미: 재귀 실행과 시간•공간 복잡도를 판정하는 분석 구성을 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 재귀 함수 | **종료 조건**을 검사하고 축소 입력으로 자기 호출 |
| 호출 스택 | 호출별 **스택 프레임**으로 재귀 깊이•공간 비용 반영 |
| 점화식 | $a$•$b$•$f(n)$으로 호출 구조를 **비용 모델**화 |
| 마스터 정리 | 점화식의 **시간 증가율**을 비교해 점근 시간 복잡도 판정 |

#### 한줄 요약
- 재귀 인형을 열 때마다 호출 카드가 쌓이고, 점화식 장부가 그 카드 더미의 증가율을 계산하는 장면이다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **기준 지수 $p=\log_b a$**: 부분 문제들이 만드는 비용의 기준 성장률이다.
- **재귀 트리**: 호출 단계별 비용을 나무처럼 펼쳐 각 층의 비용을 합산하는 분석법이다.
- **대입법**: 예상 복잡도를 점화식에 넣어 귀납적으로 증명하는 분석법이다.
- **적용성 검증**: 점화식이 $aT(n/b)+f(n)$의 균등 분할 형식과 각 케이스 조건을 만족하는지 확인하는 절차이다.
- **비정형 점화식**: 기본 마스터 정리의 균등 분할 형식이나 조건을 만족하지 않는 점화식이다.
- **최대 재귀 깊이**: 최초 호출부터 종료 조건까지 중첩되는 호출 단계의 최댓값이다.
- **점화식 구성•적용성 검증**: 재귀 코드에서 $a$•$b$•$f(n)$을 구하고 마스터 정리의 균등 분할 조건을 확인하는 단계이다.
- **마스터 정리 Case 판정**: 기준 지수와 결합 비용의 성장률을 비교해 세 케이스 중 하나를 고르는 단계이다.
- **재귀 트리•대입법 적용**: 기본 정리를 적용할 수 없는 점화식을 층별 비용 합산이나 귀납 증명으로 분석하는 단계이다.
- **최대 재귀 깊이 분석**: 종료 조건까지 중첩되는 호출 수로 점근 공간 복잡도를 구하는 단계이다.

</details>

```text
[재귀 코드와 입력 축소 구조]
            |
            v
1. 점화식 구성•적용성 검증
            |
            +-- 조건 충족 --> 2. 마스터 정리 Case 판정
            |                         |
            |                         `------------+
            |                                      |
            `-- 조건 미충족 -> 3. 재귀 트리•대입법 적용
                                      |            |
                                      `------------+
                                                   |
                                                   v
                                        [점근 시간 복잡도]
                                                   |
                                                   v
                                      4. 최대 재귀 깊이 분석
                                                   |
                                                   v
                                        [점근 공간 복잡도]
```

### 동작 원리

- **1. 점화식 구성•적용성 검증**: 호출 수 $a$•축소율 $b$•결합 비용 $f(n)$을 확인한다.
- **2. 마스터 정리 Case 판정**: 기준 지수와 결합 비용을 비교한다.
- **3. 재귀 트리•대입법 적용**: 비정형 점화식의 성장률을 분석한다.
- **4. 최대 재귀 깊이 분석**: 호출 스택의 점근 공간을 산정한다.

#### 한줄 요약
- 호출 카드가 스택에 한 장씩 쌓이고, 분기 수•축소율•결합 비용표가 시간 눈금을 정하는 장면이다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **지배 비용**: 입력이 커질수록 증가율이 가장 커서 전체 복잡도를 결정하는 비용이다.
- **다항식 차이**: 두 성장률의 지수가 양의 상수 $\epsilon$만큼 벌어진 관계이다.
- **정규성 조건**: Case 3에서 결합 비용이 재귀 단계마다 일정 비율로 감소하는지 확인하는 조건이다.
- **부분 문제 비용**: 재귀 호출로 생성된 모든 하위 문제를 해결하는 데 드는 총비용이다.
- **로그 차이**: 두 성장률이 다항 지수 차이가 아니라 로그 인자만큼만 다른 관계이다.
- **확장형 마스터 정리**: $f(n)$에 로그 인자가 붙는 등 기본 세 케이스를 확장해 판정하는 정리이다.

</details>

$$T(n)=aT(n/b)+f(n),\quad p=\log_b a,\quad a\ge1,\ b>1$$

| 마스터 정리 케이스 | Case 1 | Case 2 | Case 3 |
|:---|:---|:---|:---|
| 성장률 조건 | $f(n)=O(n^{p-\epsilon})$ | $f(n)=\Theta(n^p)$ | $f(n)=\Omega(n^{p+\epsilon})$ |
| 비용 관계 | **부분 문제 비용**이 **지배 비용** | 두 비용이 동일 차수 | **결합 비용**이 지배 비용 |
| 결과 복잡도 | $\Theta(n^p)$ | $\Theta(n^p\log n)$ | $\Theta(f(n))$ |
| 한계 | **로그 차이**만 나면 적용 불가 | 로그 인자가 붙으면 **확장형 마스터 정리** 필요 | **정규성 조건** 미충족 시 적용 불가 |

> 요약: **다항식 차이**•**정규성 조건**으로 Case를 판정한다.

#### 한줄 요약
- 재귀 나무의 잎 더미가 크면 Case 1, 모든 층이 같으면 Case 2, 뿌리 비용이 크면 Case 3인 장면이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **감소 불변식**: 재귀 호출마다 입력 크기나 남은 작업량이 반드시 줄어드는 성질이다.
- **스택 오버플로**: 재귀 깊이가 호출 스택의 저장 한도를 넘는 오류이다.
- **명시적 스택**: 런타임 호출 스택 대신 프로그램이 직접 관리하는 자료구조 스택이다.
- **상수 비용(Constant Cost)**: 점근 차수에 숨지만 실제 실행시간에 영향을 주는 비용이다.
- **메모리 비용(Memory Cost)**: 호출 상태와 중간 결과 저장에 드는 공간 비용이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 입력이 줄지 않아 재귀가 종료되지 않음 | 종료 조건과 **감소 불변식** 검증 | 무한 재귀 방지 |
| 깊은 입력에서 **스택 오버플로** | **명시적 스택**•반복 구조로 전환 | 호출 깊이 한계 완화 |
| 불균등 분할식에 마스터 정리 오적용 | 적용 형식•**정규성 조건** 확인 후 **재귀 트리**•**대입법** 사용 | 복잡도 판정 오류 방지 |
| 이론 차수와 실행 시간이 크게 다름 | 입력 규모별 측정과 **상수 비용**•**메모리 비용** 분석 | 실제 병목 보완 |

#### 한줄 요약
- 호출 카드가 천장에 닿기 전에 런타임 스택 대신 직접 관리하는 카드 상자로 옮기는 장면이다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **깊은 호출**: 입력 축소가 느려 호출 스택에 많은 프레임이 쌓이는 재귀 구조이다.
- **불균등 분할**: 부분 문제들이 서로 다른 크기로 나뉘어 기본 마스터 정리를 적용하기 어려운 형태이다.
- **재귀 분석 선택 기준**: 호출 깊이와 부분 문제의 균등 분할 여부로 실행 구조와 분석법을 고르는 기준이다.

</details>

- **재귀 분석 선택 기준**에 따라 **깊은 호출**은 **명시적 스택**으로 바꾸고, **불균등 분할**은 **대입법**으로 분석한다.

#### 한줄 요약
- 호출 카드가 높으면 명시적 스택 상자, 가지 크기가 다르면 재귀 트리 계산판을 고르는 장면이다.
