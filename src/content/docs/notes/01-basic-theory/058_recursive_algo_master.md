## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **재귀 알고리즘(Recursive Algorithm)**: 하나의 큰 문제를 동일한 형태의 더 작은 하위 문제로 분할하여 자기 자신을 호출함으로써 해결하는 알고리즘.
- **점화식(Recurrence Relation)**: 수열의 항 사이의 관계식으로, 알고리즘의 전체 실행 시간을 더 작은 입력 크기에 대한 실행 시간의 함수로 표현한 식.
- **마스터 정리(Master Theorem)**: $T(n) = aT(n/b) + f(n)$ 형태의 균등 분할 점화식에서 점근적 시간복잡도($\Theta$)를 즉시 판정하는 공식 체계.

</details>

- 정의/개념: 분할 정복 기반 재귀 알고리즘의 **점화식 $T(n) = aT(n/b) + f(n)$** 에서 부분 문제의 재귀 호출 비용과 분할·결합 비용의 증가율 비교를 통해 점근적 시간복잡도를 즉시 판정하는 정리
- 배경/필요성: 분할 정복 알고리즘 설계 시 복잡한 재귀 트리 전개와 레벨별 비용 합산에 수반되는 **반복적 수식 유도 연산 오버헤드**

#### 한줄 요약

- 전개를 규칙 대입으로 줄이는 대가로 균등 분할이라는 전제를 요구하므로, 전제가 깨지는 순간 다시 재귀 트리 전개로 돌아가야 한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **임계 지수(Critical Exponent, $\log_b a$)**: 재귀 트리의 최하단 리프 노드 총비용 $n^{\log_b a}$을 결정하는 핵심 지수.
- **다항식 지배(Polynomial Domination)**: 두 함수 $f(n)$과 $g(n)$ 사이에 다항식 비율($n^\epsilon$) 차이가 존재하여 한쪽이 점근적으로 압도하는 관계.

</details>

- 분할 정복 점화식을 리프 비용 $n^{\log_b a}$과 결합 비용 $f(n)$의 다항식 지배 관계로 **3대 케이스 판정**
- 동일한 하위 문제 크기 분할($n/b$) 조건에서만 성립하는 **엄밀한 수학적 적용 전제**
- 재귀 호출 스택 누적으로 인한 **공간복잡도 $O(\text{Tree Depth})$의 내재적 동반**

#### 한줄 요약

- 리프 노드 비용과 분할 결합 비용의 다항식 우열에 따라 3대 케이스로 점근 상한을 판정

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **하위 문제 수($a$)**: 각 재귀 단계에서 생성되는 동일한 부분 문제의 개수 ($a \ge 1$).
- **입력 축소 비율($b$)**: 각 부분 문제로 분할될 때 입력 크기가 줄어드는 비율 ($b > 1$).
- **분할 결합 함수($f(n)$)**: 문제를 $a$개로 나누고 부분 문제 해를 합치는 데 소요되는 오버헤드 비용.

</details>

```text
+-----------------------------------------------------------------------------+
|                        마스터 정리(Master Theorem) 분석 체계                 |
+-----------------------------------------------------------------------------+
|  [점화식 파라미터 추출]  --> T(n) = aT(n/b) + f(n) 에서 a, b, f(n) 도출     |
|          |                                                                  |
|          v                                                                  |
|  [임계 함수 연산 모듈]   --> n^(log_b a) (재귀 트리 리프 레벨 총비용 산출)  |
|          |                                                                  |
|          v                                                                  |
|  [비용 다항식 차수 비교] --> f(n) 과 n^(log_b a) 간의 점근적 비율 대조      |
|          |                                                                  |
|          v                                                                  |
|  [점근 복잡도 확정]      --> Case 1(리프 지배), Case 2(동등), Case 3(루트 지배)|
+-----------------------------------------------------------------------------+
```

선의 의미: 실선 박스는 분할 정복 점화식에서 시간 복잡도를 판정하는 단계를 나타내며, 화살표는 파라미터 추출, 임계 함수 계산, 차수 대조 및 최종 복잡도 도출 흐름을 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 하위 문제 수 ($a$) | 재귀 호출의 분기 계수를 결정하여 **리프 노드 수($a^{\log_b n}$) 규정** |
| 입력 축소율 ($b$) | 하위 문제 크기를 축소하여 **재귀 트리의 전체 깊이($\log_b n$) 결정** |
| 분할 결합 비용 ($f(n)$) | 각 재귀 단계에서 소요되는 **루트 레벨의 분할 및 병합 연산량** |
| 임계 함수 ($n^{\log_b a}$) | 재귀 트리 최하단 리프 노드들의 **기저 연산 총비용 기준선 제시** |

#### 한줄 요약

- 분기수 $a$, 축소율 $b$, 결합함수 $f(n)$을 통해 리프 비용과 결합 비용을 비교 구조화

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **정규성 조건(Regularity Condition)**: Case 3 적용 시 충분히 큰 $n$에 대해 $a f(n/b) \le c f(n)$ ($c < 1$)을 만족해야 하는 조건.

</details>

```text
점화식 식별 T(n) = aT(n/b) + f(n)
   |
   v
[ 1. 파라미터 추출 및 임계 함수 계산 ] : a >= 1, b > 1, n^(log_b a)
   |
   v
[ 2. 다항식 차수 비교 f(n) vs n^(log_b a) ]
   |
   +---> Case 1 (f(n)이 다항식적으로 작음) : T(n) = Θ(n^(log_b a))
   |
   +---> Case 2 (차수 동등 균형)          : T(n) = Θ(n^(log_b a) * log n)
   |
   +---> Case 3 (f(n)이 다항식적으로 큼)   : 정규성 조건 검증 후 T(n) = Θ(f(n))
```

분기 결과: 분할 결합 함수 f(n)과 임계 함수 간의 상대적 다항 차수에 따라 리프 지배(Case 1), 전 레벨 균등(Case 2), 루트 결합 지배(Case 3)로 분기하여 최종 시간 복잡도를 판정한다.

**동작 원리**:
1. **파라미터 추출 및 임계 함수 계산**: 점화식에서 $a \ge 1, b > 1$을 확인하고 기저 조건의 리프 노드 총수 $n^{\log_b a}$를 계산한다.
2. **다항식 차수 비교**: $f(n)$과 $n^{\log_b a}$ 사이의 비율 $\frac{f(n)}{n^{\log_b a}}$을 점근 분석하여 다항식 차수 차이($n^\epsilon$)를 평가한다.
3. **Case 1 판정**: $f(n) = O(n^{\log_b a - \epsilon})$이면 최하단 리프 노드 연산량이 전체를 지배하므로 $T(n) = \Theta(n^{\log_b a})$로 수렴한다.
4. **Case 2 판정**: $f(n) = \Theta(n^{\log_b a})$이면 재귀 트리의 모든 레벨별 연산 비용이 동일하므로 트리 깊이 $\log_b n$을 곱해 $T(n) = \Theta(n^{\log_b a} \log n)$로 확정한다.
5. **Case 3 판정**: $f(n) = \Omega(n^{\log_b a + \epsilon})$이고 정규성 조건($a f(n/b) \le c f(n), c < 1$)을 만족하면 최상위 분할 결합 비용이 지배하므로 $T(n) = \Theta(f(n))$로 확정한다.

#### 한줄 요약

- 파라미터를 추출하여 리프와 결합 비용을 비교하고 해당하는 케이스의 복잡도로 확정

## Ⅴ. 종류 및 비교

| 마스터 정리 케이스 | Case 1 (리프 비용 지배) | Case 2 (비용 동등 균형) | Case 3 (루트 결합 비용 지배) |
|:---|:---|:---|:---|
| 적용 기준 | **결합 비용 $f(n)$이 리프 비용보다 다항식적으로 작을 때** | **결합 비용 $f(n)$과 리프 비용의 차수가 동등할 때** | **결합 비용 $f(n)$이 리프 비용보다 다항식적으로 클 때** |
| 핵심 특징 | 점근 복잡도가 최하단 **리프 노드 수 $\Theta(n^{\log_b a})$에 의해 결정** | 각 레벨 비용이 동일하여 **트리 깊이 $\log n$이 곱해짐** | 점근 복잡도가 최상단 **루트 분할 결합 비용 $\Theta(f(n))$에 의해 결정** |
| 대표 사례 | 스트라센 행렬 곱셈 ($T(n)=7T(n/2)+n^2$) $\to \Theta(n^{2.81})$ | 병합 정렬 ($T(n)=2T(n/2)+n$) $\to \Theta(n \log n)$ | 특정 탐색 분할 ($T(n)=2T(n/2)+n^2$) $\to \Theta(n^2)$ |

#### 한줄 요약

- 리프 지배는 Case 1, 레벨 균등은 Case 2, 루트 결합 지배는 Case 3으로 구분

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **스택 오버플로우(Stack Overflow)**: 재귀 깊이가 깊어져 스택 메모리 한계를 초과해 프로그램이 비정상 종료되는 현상.
- **꼬리 재귀 최적화(Tail Call Optimization, TCO)**: 함수의 마지막 연산으로 재귀 호출을 수행하여 컴파일러가 스택 프레임을 재사용하도록 변환하는 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 불균등 분할로 인한 **마스터 정리 적용 불가** | **아크라-바지 정리** 또는 재귀 트리 전개법 적용 | 비표준 재귀 점화식의 점근 복잡도 도출 |
| 재귀 호출 깊이 심화로 인한 **호출 스택 오버플로우** | **꼬리 재귀 최적화** 및 명시적 스택·반복문 전환 | 스택 메모리 사용량 감소 및 고갈 방지 |
| 분할 크기가 불균등한 점화식 ($T(n)=T(n/3)+T(2n/3)+n$) | **재귀 트리 분석을 통한 계층별 상한 비용 합산** | 정확한 최악 점근 상한 $O(n \log n)$ 도출 |

#### 한줄 요약

- 정리 미적용 갭은 재귀 트리법으로 풀고, 스택 고갈은 꼬리 재귀 및 반복문으로 최적화

## Ⅶ. 결론

- 병합 정렬, 스트라센 행렬 곱셈, 카라츠바 곱셈 등 **분할 정복 알고리즘의 복잡도 분석 표준 도구**로 정립되었으며, 실무에서는 **균등 분할 시 마스터 정리를 즉각 적용하고, 불균등 분할($T(n)=T(n/3)+T(2n/3)+n$) 시에는 아크라-바지(Akra-Bazzi) 정리 또는 재귀 트리법으로 확장하며, 런타임 스택 오버플로 방지를 위한 꼬리 재귀 최적화(TCO)**를 결합

#### 한줄 요약

- 균등 분할 여부에 따라 마스터 정리와 아크라-바지 정리를 선택
