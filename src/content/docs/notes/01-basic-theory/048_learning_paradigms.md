## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **학습 패러다임**: 정답 라벨•데이터 자체•환경 보상 중 무엇을 학습 기준으로 삼는지에 따른 학습 방식의 분류 체계이다.
- **학습 신호**: 모델 갱신의 기준이 되는 라벨, 데이터 관계 또는 환경 보상이다.
- **환경 상호작용**: 강화 학습의 에이전트가 행동하고 다음 상태와 보상을 관측하는 과정이다.
- **목적 함수**: 학습 신호와 모델 결과를 손실이나 보상값으로 바꾸는 함수이다.

</details>

- 정의/개념: **학습 패러다임**은 정답 라벨, 데이터 자체의 구조 또는 환경 보상 중 어떤 **학습 신호**로 모형을 갱신하는지에 따라 학습 방식을 분류한 체계이다.
- 배경/필요성: 사용할 수 있는 라벨과 보상 및 환경 상호작용 조건에 따라 목적 함수, 데이터 수집과 성능 평가 방법이 달라진다.

#### 한줄 요약
- 레이블 쌍으로 손실을 최소화하는 지도 학습, 데이터 자체 구조에서 패턴을 추출하는 비지도 학습, 환경 보상 신호로 정책을 갱신하는 강화 학습처럼 제공되는 학습 신호가 목적 함수와 절차를 결정한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **라벨**: 입력마다 부여한 정답 범주나 목표값이다.
- **보상**: 환경에서 선택한 행동의 결과를 평가하는 강화 학습 신호이다.
- **갱신 방식**: 학습 신호를 바탕으로 모델 파라미터나 정책을 조정하는 방법이다.

</details>

- **라벨**•데이터 자체•**보상**에 따라 목적 함수와 갱신 방식이 분화한다.

#### 한줄 요약
- 같은 로그도 정답표를 주면 예측하고, 기록만 주면 구조를 찾고, 조치 점수를 주면 행동을 바꾼다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **학습기**: 목적값에 따라 가중치나 정책을 갱신하는 주체이다.
- **정책**: 강화 학습에서 상태별 행동을 선택하는 규칙이다.
- **모델 파라미터**: 학습 과정에서 조정하는 가중치와 편향 등의 값이다.
- **학습 기준**: 모델 갱신 방향을 결정하는 라벨•데이터 관계•보상 정보이다.
- **목적값**: 목적 함수가 모델 결과와 학습 신호를 비교해 산출한 손실 또는 보상 수치이다.

</details>

```text
[학습 신호] -- [목적 함수]
                  /     \
           [학습기] -- [학습 모델]
```

선의 의미: 목적 함수가 학습 신호와 모델 결과를 함께 참조하고, 학습기와 학습 모델이 파라미터 갱신 책임으로 연결된 정적 의존 관계다.

| 구성요소 | 책임 |
|:---|:---|
| 학습 신호 | 라벨•데이터•보상으로 **학습 기준** 제공 |
| 목적 함수 | 학습 신호와 모델 결과로 **목적값** 계산 |
| 학습기 | 갱신 기준에 따라 **모델 파라미터** 조정 |
| 학습 모델 | 예측•표현•행동 **정책** 산출 |

#### 한줄 요약
- 정답표•채점표•선생님•학생처럼 학습 신호•목적 함수•학습기•모델이 기준•평가•조정•산출 책임을 나눠 맡는다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **정답 라벨**: 입력별 목표 범주나 값을 제공하는 학습 신호이다.
- **환경 보상**: 행동 결과의 가치를 나타내는 강화 학습 신호이다.
- **잠재 구조**: 라벨 없이 데이터에 내재한 군집•분포•표현이다.
- **학습 신호 판별**: 주어진 과업에 정답 라벨이나 환경 보상이 있는지 확인하는 단계이다.
- **지도 학습 선택**: 정답 라벨이 있을 때 예측 오차를 줄이는 학습 방식을 택하는 단계이다.
- **강화 학습 선택**: 행동의 환경 보상을 관측할 수 있을 때 정책 학습 방식을 택하는 단계이다.
- **비지도 학습 선택**: 라벨과 보상 없이 데이터의 잠재 구조를 찾는 방식을 택하는 단계이다.
- **방식별 품질 검증**: 선택한 패러다임에 맞는 지표•전문가 검토•행동 감사로 결과를 평가하는 단계이다.

</details>

```text
[데이터•과업의 학습 신호]
            |
            v
1. 학습 신호 판별
            |
            +-- 정답 라벨 --> 2. 지도 학습 선택
            |
            +-- 환경 보상 --> 3. 강화 학습 선택
            |
            `-- 둘 다 없음 -> 4. 비지도 학습 선택

[선택한 학습 패러다임]
            |
            v
5. 방식별 품질 검증
            |
            v
[검증된 예측•표현•정책]
```

### 동작 원리

- **1. 학습 신호 판별**: 라벨•보상•데이터 자체를 구분한다.
- **2. 지도 학습 선택**: 예측 오차로 모델을 갱신한다.
- **3. 강화 학습 선택**: 기대 누적 보상으로 정책을 갱신한다.
- **4. 비지도 학습 선택**: 데이터의 잠재 구조를 탐색한다.
- **5. 방식별 품질 검증**: 집단 지표•전문가 검토•행동 감사를 수행한다.

#### 한줄 요약
- 채점표가 정답•카드 무늬•행동 점수 중 받은 기준과 학생의 답을 비교해 다음 연습 방향을 선생님에게 건넨다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **지도 학습**: 입력과 정답 라벨의 대응을 학습해 새 입력을 예측하는 방식이다.
- **비지도 학습**: 정답 라벨 없이 데이터의 군집•분포•표현 같은 잠재 구조를 찾는 방식이다.
- **강화 학습**: 환경의 보상을 근거로 기대 누적 보상을 높이는 행동 정책을 학습하는 방식이다.
- **라벨 편향(Label Bias)**: 정답 기준이 집단별로 치우친 상태이다.
- **라벨 잡음(Label Noise)**: 라벨이 잘못 기록된 상태이다.
- **목표 우회**: 의도한 목표 대신 보상 함수의 빈틈을 이용해 점수만 높이는 행동이다.
- **예측 오차**: 지도 학습 모델의 예측값과 정답 라벨 사이의 차이이다.
- **기대 누적 보상**: 현재부터 미래까지 받을 보상 합의 확률적 평균이다.
- **학습 품질 검증**: 학습 결과가 과업 목적에 맞는지 지표나 검토 절차로 확인하는 과정이다.

</details>

| 학습 패러다임 | 지도 학습 | 비지도 학습 | 강화 학습 |
|:---|:---|:---|:---|
| 적용 기준 | 입력마다 **정답 라벨**을 확보한 경우 | 라벨 없이 **잠재 구조**를 찾는 경우 | 행동 결과를 **보상**으로 관측하는 경우 |
| 핵심 특징 | 정답 라벨과 **예측 오차**로 모델 갱신 | 데이터 분포와 **잠재 구조** 탐색 | **기대 누적 보상**으로 행동 정책 갱신 |
| 한계 | **라벨 편향**•**라벨 잡음**의 모델 전파 | 정답 부재로 **학습 품질**의 정량적 검증 한계 | 보상 오설계에 따른 **목표 우회** |

> 요약: **라벨**•데이터 자체•**보상**에 따른 방식을 선택한다.

#### 한줄 요약
- 정답지가 있으면 지도 교실, 카드만 있으면 비지도 분류대, 행동 점수가 돌아오면 강화 훈련장으로 들어간다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **내부 평가 지표**: 정답 없이 군집 응집도•분리도처럼 데이터 구조로 결과를 평가하는 수치이다.
- **집단별 지표**: 사용자나 데이터 집단별로 나누어 계산한 오분류율•정확도 등의 성능 지표이다.
- **전문가 표본 검토**: 군집이나 표현의 일부 사례를 도메인 전문가가 직접 확인하는 평가이다.
- **행동 감사**: 강화 정책의 선택과 결과가 제약과 의도한 목표를 지키는지 점검하는 절차이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 지도 학습의 집단별 오분류 편중 | 라벨 기준 감사•**집단별 지표**•표본 보강 | **라벨 편향** 전파 완화 |
| 비지도 군집•표현의 업무 의미 불명확 | **내부 평가 지표**와 **전문가 표본 검토** 병행 | 군집•표현의 업무 타당성 확보 |
| 강화 학습의 **목표 우회** | 보상 함수 검증•제약 조건•**행동 감사** 적용 | 의도한 목표와 정책 행동 정렬 |

#### 한줄 요약
- 교사는 정답지의 치우침을, 카드 분류자는 묶음의 의미를, 훈련사는 점수만 노리는 꼼수를 각각 검사한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **패러다임 선택 기준**: 정답 라벨•환경 보상의 제공 여부로 지도•비지도•강화 학습을 구분하는 기준이다.

</details>

- **패러다임 선택 기준**에 따라 **보상**이 있으면 강화 학습, **라벨**이 있으면 지도 학습, 둘 다 없으면 비지도 학습을 선택 체계 적용

#### 한줄 요약
- 갈림길에서 정답표 화살표는 지도 학습, 행동 점수 화살표는 강화 학습, 빈 표지판은 비지도 학습으로 이어진다.
