## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **지도 학습(Supervised Learning)**: 입력 데이터와 정답 라벨 쌍을 기반으로 오차를 최소화하는 매핑 함수를 학습하는 방식.
- **비지도 학습(Unsupervised Learning)**: 정답 라벨 없이 데이터 내재 기하학적 분포, 유사도, 밀도 패턴을 추출하는 방식.
- **강화 학습(Reinforcement Learning)**: 에이전트가 환경과 상호작용하며 시행착오를 통해 누적 보상을 극대화하는 행동 정책을 도출하는 방식.
- **마르코프 결정 과정(Markov Decision Process, MDP)**: 상태, 행동, 전이 확률, 보상 함수로 순차적 의사결정을 모델링하는 강화 학습의 수학적 체계.

</details>

- 정의/개념: 데이터 피드백 신호의 특성에 따라 **정답 라벨 지도**, **데이터 내재 구조 탐색**, **환경 상호작용 보상 극대화** 체계로 분기하여 모델을 학습하는 기계학습 분류 체계
- 배경/필요성: 전수 라벨링 비용 폭증 및 정적 데이터 기반 학습의 동적 환경 제어 한계로 인해 문제 특성별 최적 학습 패러다임 선택 불가피

#### 한줄 요약

- 정답 라벨, 데이터 내재 구조, 환경 보상 신호의 유무에 따라 지도, 비지도, 강화 학습으로 분기

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **오차 역전파(Backpropagation)**: 출력층의 오차 기울기를 역방향으로 전달하여 신경망 가중치를 갱신하는 지도 학습의 핵심 알고리즘.
- **잠재 표현(Latent Representation)**: 고차원 원본 데이터에서 비선형 압축을 통해 추출된 저차원 특징 공간.
- **정책(Policy, $\pi$)**: 환경의 각 상태에서 에이전트가 수행할 행동 확률을 매핑하는 함수.

</details>

- 지도 학습: **입력·정답 라벨 쌍** 기반 오차 역전파 및 입출력 매핑 함수 근사
- 비지도 학습: 라벨 없이 **데이터 기하학적 거리·밀도 구조** 분석을 통한 잠재 표현 및 군집 구조 추출
- 강화 학습: 에이전트의 **시행착오 상호작용** 기반 지연된 누적 보상 기대치 극대화 정책 도출

#### 한줄 요약

- 지도 학습은 정답 매핑, 비지도 학습은 내재 구조 추출, 강화 학습은 시행착오를 통한 보상 극대화 정책을 추구

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **에이전트(Agent)**: 환경 상태를 관측하고 정책에 따라 행동을 수행하며 보상을 받는 강화 학습 주체.
- **손실 함수(Loss Function)**: 모델 예측값과 실제 정답 라벨 간의 오차를 수치화하는 목적 함수.

</details>

```text
+-------------------------------------------------------------+
| 기계학습 3대 패러다임 구조 (Learning Paradigms)            |
|                                                             |
| [지도 학습]   : 입력(X) + 정답(Y)   --- (오차 손실 역전파)  |
| [비지도 학습] : 입력(X)             --- (잠재 공간 구조화)  |
| [강화 학습]   : 상태(S) + 행동(A)   --- (환경 보상 피드백)  |
+-------------------------------------------------------------+
```

선의 의미: 패러다임별 입력 데이터와 피드백 신호의 정적 구성 관계

| 구성요소 | 책임 |
|:---|:---|
| 지도 학습 | 정답 라벨($Y$) 기반 **오차 손실 계산** 및 가중치 최적화 |
| 비지도 학습 | 데이터 내재 **특징 분포·밀도·유사도 구조** 추출 |
| 강화 학습 에이전트 | 환경 상태 전이에 따른 **가치 함수 추정 및 정책 갱신** |
| 상호작용 환경 | 에이전트 행동에 반응하여 **차기 상태($S'$) 및 보상($R$) 반환** |

#### 한줄 요약

- 입력 데이터 형태와 피드백 방식에 따라 오차 최소화, 잠재 구조화, 환경 상호작용 책임으로 구분

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Q-러닝(Q-Learning)**: 상태-행동 가치 함수를 벨만 최적 방정식을 통해 반복 갱신하는 대표적인 모델 프리 강화 학습 알고리즘.
- **실루엣 계수(Silhouette Coefficient)**: 군집 내 응집도와 군집 간 분리도를 측정하는 비지도 군집 품질 평가 지표.

</details>

```text
문제 및 데이터 자산 분석
           │
           ▼
[ 1. 학습 신호 유형 판별 ]
├─ 정답 라벨 존재 ─────────► [ 2. 지도 학습 분기 (분류·회귀) ]
├─ 라벨 부재/패턴 탐색 ──► [ 3. 비지도 학습 분기 (군집·차원축소) ]
└─ 동적 환경 상호작용 ─────► [ 4. 강화 학습 분기 (정책·가치 최적화) ]
           │
           ▼
[ 5. 패러다임별 성능 검증 ]
```

**동작 원리**
1. **학습 신호 유형 판별**: 가용 데이터의 정답 라벨 유무 및 환경 피드백 존재 여부 판정
2. **지도 학습 분기**: 정답 데이터셋 기반 손실 함수 정의 및 모델 학습 수행
3. **비지도 학습 분기**: 라벨 없는 데이터의 거리·밀도 기반 기하학적 군집화 수행
4. **강화 학습 분기**: 환경 보상 기반 정책 탐색 및 가치 함수 갱신
5. **패러다임별 성능 검증**: 과업 특성에 맞춘 교차 검증 및 누적 보상 수렴 확인

#### 한줄 요약

- 문제와 데이터 특성을 분석하여 신호 유형을 판별하고, 해당 패러다임으로 분기하여 최적화 및 성능 검증 수행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **탐색-활용 딜레마(Exploration-Exploitation Dilemma)**: 알려진 최적 행동을 실행하는 활용과 새로운 보상을 탐색하는 선택 사이의 상충 관계.

</details>

| 학습 패러다임 | 지도 학습 | 비지도 학습 | 강화 학습 |
|:---|:---|:---|:---|
| 적용 기준 | **정답 라벨 쌍** 확보 및 명시적 입출력 매핑 요구 시 | **무라벨 데이터** 대상 잠재 군집·구조 탐색 시 | **환경 상호작용** 기반 순차 의사결정 최적화 시 |
| 핵심 특징 | **명시적 정답 오차 피드백** 기반 손실 최소화 | **데이터 기하학적 거리·재구성 손실** 기반 특징 추출 | **시행착오 기반 누적 보상 극대화** 정책 탐색 |
| 한계 | **대규모 라벨링 비용** 및 라벨 노이즈 취약성 | **객관적 품질 평가 지표 부재** 및 해석 난해성 | **보상 해킹** 및 샘플 효율성 저하 |

#### 한줄 요약

- 정답 예측은 지도 학습, 패턴 발견은 비지도 학습, 상호작용 정책 최적화는 강화 학습을 선택

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **보상 해킹(Reward Hacking)**: 에이전트가 개발자의 원래 의도를 벗어나 보상 함수 수치만을 비정상적으로 극대화하는 편법 행동.
- **인간 피드백 강화학습(Reinforcement Learning from Human Feedback, RLHF)**: 인간 선호도를 보상 모델로 학습시켜 언어 모델의 출력을 인간 의도에 정렬하는 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 전수 라벨링 비용 폭증으로 인한 **지도 학습 데이터 부족** | **자기지도 사전학습 기반 파운데이션 모델 미세조정** | 라벨링 요구량 절감 및 일반화 성능 향상 |
| 비지도 군집·이상 탐지의 **비즈니스 타당성 검증 부재** | **도메인 전문가 정성 검수와 실루엣 지표 병행** | 분석 결과의 실무 설명력 및 신뢰도 확보 |
| 보상 설계 결함으로 인한 강화학습 **보상 해킹** | **제약 조건부 최적화(Constrained MDP) 및 RLHF 도입** | 의도된 안전 정책으로의 정렬 및 비정상 행동 억제 |

#### 한줄 요약

- 라벨 부족은 사전학습으로 극복하고, 비지도 결과는 정성 검수를 병행하며, 보상 해킹은 안전 제약과 인간 피드백으로 통제

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **복합 AI 파이프라인**: 대규모 비지도/자기지도 사전학습과 지도 미세조정(SFT), 강화 정렬(RLHF)을 유기적으로 결합한 현대 AI 시스템 아키텍처.

</details>

- 과업의 정답 라벨 가용성과 환경 상호작용 제약 조건에 따라 적합한 패러다임을 단독 또는 하이브리드로 선택하며, 현대 AI 시스템은 비지도 사전학습과 지도 미세조정, 강화 정렬을 결합한 복합 파이프라인으로 구축하는 전략 필수

#### 한줄 요약

- 단일 패러다임에 국한되지 않고 데이터 자산과 문제 제약에 맞춰 최적 기법을 조합하는 통합적 설계가 핵심
