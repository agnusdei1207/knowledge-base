## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **손실 함수(Loss Function)**: 모델이 예측한 값과 실제 정답 사이의 불일치 정도를 정량화하여 역전파(Backpropagation)의 오차 기준 신호를 생성하는 목적 함수.
- **학습 정체(Training Stagnation)**: 부적절한 손실 함수로 인해 출력층 근방의 기울기가 조기에 0에 도달하여 모델 가중치가 더 이상 갱신되지 않는 현상.

</details>

- 정의/개념: 모델의 예측값과 실제 타깃 간의 오차를 단일 스칼라 수치로 정량화하여 **역전파 기울기 산출의 기준을** 제공하는 목적 함수
- 배경/필요성: 과업(Task)의 확률 분포 특성과 불일치하는 손실 함수 설정 시 발생하는 조기 기울기 포화(학습 정체) 및 이상치(Outlier)에 의한 역전파 방향 왜곡을 극복하고, 최대 우도 추정(MLE) 원리에 기반하여 **분류 확률 분포 일치(Cross-Entropy) 및 수치 잔차 최소화(MSE/Huber)를 위한 최적의 역전파 목적 함수를 확립**할 필요

#### 한줄 요약

- 손실 함수는 정확도의 정의가 아니라 기울기의 모양을 정하는 선택이므로, 어떤 오차를 더 크게 벌줄지가 곧 학습 방향이 된다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **최대 우도 추정(MLE, Maximum Likelihood Estimation)**: 관측된 데이터가 발생할 확률(우도)을 최대화하는 파라미터를 찾는 통계적 원리로, 음의 로그 우도(NLL) 최소화가 교차 엔트로피 손실과 수학적으로 동일.
- **이상치 민감도(Outlier Sensitivity)**: 회귀 문제에서 큰 잔차가 제곱되어($e^2$) 손실에 미치는 영향력이 기하급수적으로 증폭되는 특성.

</details>

![오차 크기에 따른 손실 함수 형태 비교](/study/diagrams/loss-function-curvature.svg)

> 파란 MSE는 오차가 커질수록 손실이 가파르게 상승하여 이상치에 취약하며, 빨간 MAE는 선형 증가하고, 초록 Huber는 원점 근방에서 매끄럽고 큰 오차에서는 선형으로 완화됨

- Cross-Entropy 최소화와 **MLE** 기반 확률 분포 일치
- MSE의 $L_2$ 노름 기반 **평균 수렴 및 큰 오차 가중 페널티**
- Huber Loss의 이상치 강건성과 매끄러운 0 근방 미분 가능성

#### 한줄 요약

- 분류는 확률 분포 간의 거리를 좁히는 교차 엔트로피, 회귀는 잔차를 좁히는 MSE 및 이상치에 강건한 Huber 손실을 사용

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **손실 함수 축소 방식(Reduction)**: 미니배치 내 $N$개 표본의 개별 손실 $L_i$를 단일 스칼라로 취합하는 방식으로 주로 `mean`(배치 평균) 또는 `sum`(배치 총합)을 사용.

</details>

| 구성요소 | 책임 |
|:---|:---|
| 예측·타깃 | 모델 출력과 정답의 **차원·스케일 정합** |
| 손실 함수 | 과업별 수식에 따른 **표본 손실** 산출 |
| 축소 연산 | 개별 손실의 평균·합 기반 **스칼라화** |
| 자동 미분 | 스칼라 손실의 **출력 기울기** 산출 |

#### 한줄 요약

- 예측치와 정답을 비교하여 오차를 계산하고, 배치 평균으로 스칼라화한 후 역전파를 위한 1차 도함수를 생성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Softmax-with-Loss 결합 미분**: Softmax와 Cross-Entropy를 수식적으로 결합하면 역전파 기울기가 단순히 $\hat{y}_i - y_i$로 극도로 단순화되어 수치 안정성과 연산 속도가 비약적으로 향상되는 원리.

</details>

```text
모델 예측 로짓(Logit z) 및 실제 타깃(y) 인입
   │
   ▼
[ 1. 과업 도메인 및 손실 함수 분기 ]
├─ 분류 과업 (Classification)
│  │
│  ├─► [ 2. 확률 매핑 및 잔차 산출: Softmax 확률화 ]
│  │
│  └─► [ 3. 손실 수식 연산: Cross-Entropy 계산 ]
│
└─ 회귀 과업 (Regression)
   │
   ├─► [ 2. 확률 매핑 및 잔차 산출: 회귀 잔차 계산 ]
   │
   └─► [ 3. 손실 수식 연산: MSE 또는 Huber 계산 ]
   │
   ▼
[ 4. 배치 평균 감축 : Total_Loss = (1/N) ∑ L_i ]
   │
   ▼
[ 5. 역전파 개시 및 오차 기울기 전파 : ∂Total_Loss / ∂z 계산 ]
```

**동작 원리**

1. **과업 도메인 및 손실 함수 분기**: 분류 과업과 연속형 수치 회귀 과업 구분
2. **확률 매핑 및 잔차 산출**: 분류는 Softmax 확률화, 회귀는 잔차 계산
3. **손실 수식 연산**: 분류는 로그 우도, 회귀는 잔차 제곱/선형 함수 적용
4. **배치 평균 감축**: 전체 표본의 손실을 합산 평균하여 단일 스칼라 손실 도출
5. **역전파 개시 및 오차 기울기 전파**: 출력층 로짓에 대한 오차 기울기를 산출하여 역전파 개시

#### 한줄 요약

- 분류는 Softmax-CE로 결합 계산하고 회귀는 잔차 기반 MSE/Huber를 적용해 배치 평균 손실을 산출

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **교차 엔트로피(Cross-Entropy)**: 모델이 예측한 확률 분포와 실제 정답 분포 간의 차이를 음의 로그 우도로 측정하는 분류 표준 손실 함수.
- **평균제곱오차(MSE, Mean Squared Error)**: 예측값과 실제값의 차이를 제곱하여 평균한 회귀 표준 손실 함수.
- **후버 손실(Huber Loss)**: 작은 오차에서는 MSE처럼 매끄럽게 동작하고 큰 오차에서는 MAE처럼 선형으로 완화하여 이상치에 강건한 손실 함수.

</details>

| 손실 함수 | 교차 엔트로피 (Cross-Entropy) | 평균제곱오차 (MSE) | 후버 손실 (Huber Loss) |
|:---|:---|:---|:---|
| 적용 기준 | **다중·이진 분류** 과업 | 가우시안 잡음의 회귀 과업 | **이상치가 많은 회귀** 과업 |
| 핵심 특징 | $-\sum y \log \hat{y}$ (음의 로그 우도) | $\frac{1}{N}\sum (y - \hat{y})^2$ ($L_2$ 오차) | $\vert e\vert \le \delta$는 MSE, 초과는 MAE |
| 한계 | 정답 확률이 0에 가까우면 **손실 발산** | **이상치**에 과도하게 민감 | 전이 **임계값 $\delta$** 설정 필요 |

#### 한줄 요약

- 확률적 분류는 교차 엔트로피, 일반 회귀는 MSE, 이상치가 혼입된 회귀는 Huber 손실을 적용

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **초점 손실(Focal Loss)**: 클래스 불균형이 극심한 객체 검출(RetinaNet)에서 쉬운 예제의 손실 가중치를 $(1-p_t)^\gamma$로 낮추어 희소한 어려운 예제에 집중 학습시키는 손실 함수.
- **라벨 스무딩(Label Smoothing)**: 정답 원-핫 벡터 $[0, 1, 0]$를 $[0.05, 0.90, 0.05]$와 같이 부드럽게 조정하여 모델의 과도한 확신(Overconfidence)과 과적합을 방지하는 정규화 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 정답 확률이 0에 가까워 **로그 손실 발산** | **Log-Sum-Exp** 안정 수식 적용 | 오버플로·언더플로 방지 |
| 극단적 이상치가 MSE 기울기 지배 | **Huber 손실** 또는 Smooth L1 채택 | 이상치 영향력 억제 |
| 불균형 분류에서 **다수 클래스 손실 지배** | 쉬운 표본 가중치를 낮추는 **Focal Loss** 적용 | 희소 클래스 검출력 향상 |
| 과도한 확신으로 일반화 성능 저하 | **라벨 스무딩** 적용 | 예측 확률 보정 개선 |

#### 한줄 요약

- 수치 안정성을 위해 Log-Sum-Exp 트릭을 적용하고, 회귀 이상치는 Huber 손실로 억제하며, 극심한 클래스 불균형은 Focal Loss로 가중치를 재조정한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **손실 함수 설계의 핵심 철학**: 모델의 출력층 활성화 함수(Softmax, Sigmoid, Linear)와 손실 함수는 확률론적 데이터 생성 분포(베르누이, 다항, 가우시안 분포)의 최대 우도 추정(MLE)과 엄격히 1:1로 일치해야 수렴이 보장.

</details>

- 머신러닝 및 심층 신경망 역전파 훈련의 **오차 신호 생성 표준 메커니즘**으로 확립되었으며, 실무에서는 **출력층 활성화 함수(Softmax/Sigmoid)와의 수치적 결합(Log-Sum-Exp), 클래스 불균형 해소를 위한 Focal Loss 및 과확신 방지를 위한 Label Smoothing**을 결합하여 모델 수렴성과 일반화 성능을 극대화

#### 한줄 요약

- 데이터 분포에 맞는 손실 함수를 선택하고, 불균형이나 이상치가 있으면 Focal Loss나 Huber 손실로 조정
