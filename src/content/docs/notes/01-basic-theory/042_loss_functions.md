## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **손실 함수(Loss Function)**: 모델이 예측한 값과 실제 정답 사이의 불일치 정도를 정량화하여 역전파(Backpropagation)의 오차 기준 신호를 생성하는 목적 함수.
- **학습 정체(Training Stagnation)**: 부적절한 손실 함수로 인해 출력층 근방의 기울기가 조기에 0에 도달하여 모델 가중치가 더 이상 갱신되지 않는 현상.

</details>

- 정의/개념: 모델의 예측값과 실제 타깃 간의 오차를 단일 스칼라 수치로 정량화하여 **역전파 기울기 산출의 기준** 제공하는 목적 함수
- 배경/필요성: 분류 및 회귀 과업의 확률분포 특성에 부합하지 않는 손실 함수 채택 시 발생하는 **학습 정체 및 이상치 왜곡** 해소 필요

#### 한줄 요약

- 모델의 예측값과 실제 타깃 사이의 오차를 단일 스칼라 값으로 정량화하여 신경망 역전파 학습의 목적 신호를 제공

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **최대 우도 추정(MLE, Maximum Likelihood Estimation)**: 관측된 데이터가 발생할 확률(우도)을 최대화하는 파라미터를 찾는 통계적 원리로, 음의 로그 우도(NLL) 최소화가 교차 엔트로피 손실과 수학적으로 동일.
- **이상치 민감도(Outlier Sensitivity)**: 회귀 문제에서 큰 잔차가 제곱되어($e^2$) 손실에 미치는 영향력이 기하급수적으로 증폭되는 특성.

</details>

![오차 크기에 따른 손실 함수 형태 비교](/study/diagrams/loss-function-curvature.svg)

> 파란 MSE는 오차가 커질수록 손실이 가파르게 상승하여 이상치에 취약하며, 빨간 MAE는 선형 증가하고, 초록 Huber는 원점 근방에서 매끄럽고 큰 오차에서는 선형으로 완화됨

- Cross-Entropy의 로그 우도 극대화 기반 **확률 분포 일치 유도**
- MSE의 $L_2$ 노름 기반 **평균 수렴 및 큰 오차 가중 페널티**
- Huber Loss의 이상치 강건성과 매끄러운 0 근방 미분 가능성

#### 한줄 요약

- 분류는 확률 분포 간의 거리를 좁히는 교차 엔트로피, 회귀는 잔차를 좁히는 MSE 및 이상치에 강건한 Huber 손실을 사용

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **손실 함수 축소 방식(Reduction)**: 미니배치 내 $N$개 표본의 개별 손실 $L_i$를 단일 스칼라로 취합하는 방식으로 주로 `mean`(배치 평균) 또는 `sum`(배치 총합)을 사용.

</details>

```text
[ 손실 함수 평가 및 역전파 신호 생성 구조 ]
┌──────────────────────────────┐
│ 예측-타깃 정합기 (Aligner)   │ ── 모델 출력 y_hat 및 실제 라벨 y 텐서 검증
├──────────────────────────────┤
│ 손실 계산 엔진 (CE / MSE)    │ ── 과업별 수식에 따른 표본별 오차 L_i 산출
├──────────────────────────────┤
│ 배치 감축기 (Reduction)      │ ── Loss = (1/N) ∑ L_i 스칼라화
├──────────────────────────────┤
│ 오차 기울기 생성기 (Grad)    │ ── ∂Loss/∂y_hat 도출 ──► 역전파망 주입
└──────────────────────────────┘
```

선의 의미: 예측값 및 라벨 인입, 손실 연산, 배치 스칼라 감축 및 역전파 기울기 전파 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 예측-타깃 정합기 | 모델 출력($\hat{y}$)과 정답($y$)의 **차원 및 스케일 일치화** |
| 손실 계산 엔진 | 과업 목적 수식(CE / MSE / Huber)에 따른 **표본별 오차 산출** |
| 배치 감축기 (Reduction) | 배치 내 개별 손실을 **평균(Mean) 또는 합(Sum)으로 스칼라화** |
| 오차 기울기 생성기 | 스칼라 손실의 $\hat{y}$에 대한 **1차 도함수 $\partial L / \partial \hat{y}$ 도출** |

#### 한줄 요약

- 예측치와 정답을 비교하여 오차를 계산하고, 배치 평균으로 스칼라화한 후 역전파를 위한 1차 도함수를 생성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Softmax-with-Loss 결합 미분**: Softmax와 Cross-Entropy를 수식적으로 결합하면 역전파 기울기가 단순히 $\hat{y}_i - y_i$로 극도로 단순화되어 수치 안정성과 연산 속도가 비약적으로 향상되는 원리.

</details>

```text
모델 예측 로짓(Logit z) 및 실제 타깃(y) 인입
   │
   ▼
[ 1. 과업 도메인 및 손실 함수 분기 ]
├─ 분류 과업 (Classification)
│  │
│  ├─► [ 2-A. Softmax 활성화: p_k = exp(z_k) / ∑ exp(z_i) ]
│  │
│  └─► [ 3-A. Cross-Entropy 계산: L = -∑ y_k log(p_k) ]
│
└─ 회귀 과업 (Regression)
   │
   ├─► [ 2-B. 잔차 계산: e = y - z ]
   │
   └─► [ 3-B. MSE / Huber 연산: L = (1/2) e² (if |e|≤δ) else δ|e|-δ²/2 ]
   │
   ▼
[ 4. 배치 평균 감축: Total_Loss = (1/N) ∑ L_i ]
   │
   ▼
[ 5. 역전파 개시: ∂Total_Loss / ∂z 계산 및 하위 레이어 전파 ]
```

**동작 원리** 1. **과업 도메인 판별**: 분류 과업과 연속형 수치 회귀 과업 구분
2. **확률 매핑 및 잔차 산출**: 분류는 Softmax 확률화, 회귀는 잔차 계산
3. **손실 수식 연산**: 분류는 로그 우도, 회귀는 잔차 제곱/선형 함수 적용
4. **배치 평균 스칼라화**: 전체 표본의 손실을 합산 평균하여 단일 스칼라 손실 도출
5. **역전파 기울기 전파**: 출력층 로짓에 대한 오차 기울기를 산출하여 역전파 개시

#### 한줄 요약

- 분류는 Softmax-CE로 결합 계산하고 회귀는 잔차 기반 MSE/Huber를 적용해 배치 평균 손실을 산출

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **손실 함수 3대 표준 비교**:
  - Cross-Entropy: 이진($-y\log p - (1-y)\log(1-p)$), 다중($-\sum y_k \log p_k$), 분류 표준.
  - MSE: $\frac{1}{N}\sum (y-\hat{y})^2$, 가우시안 오차 가정 회귀 표준.
  - Huber: 오차 작을 때 $0.5 e^2$, 클 때 $\delta(|e|-0.5\delta)$, 강건 회귀 표준.

</details>

| 손실 함수 | 교차 엔트로피 (Cross-Entropy) | 평균제곱오차 (MSE) | 후버 손실 (Huber Loss) |
|:---|:---|:---|:---|
| 적용 기준 | **다중/이진 분류 과업** | 가우시안 노이즈 회귀 과업 | **이상치가 많은 강건 회귀** |
| 핵심 특징 | $-\sum y \log \hat{y}$ (음의 로그 우도) | $\frac{1}{N}\sum (y - \hat{y})^2$ ($L_2$ 오차) | $\vert e\vert \le \delta$는 MSE, 초과는 MAE |
| 한계 | 잘못된 확신 시 손실 무한대 발산 | **이상치(Outlier)에 과도하게 민감** | 전이 임계값 $\delta$ 튜닝 필요 |

#### 한줄 요약

- 확률적 분류는 교차 엔트로피, 일반 회귀는 MSE, 이상치가 혼입된 회귀는 Huber 손실을 적용

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Focal Loss**: 클래스 불균형이 극심한 객체 검출(RetinaNet)에서 쉬운 예제(Well-classified)의 손실 가중치를 $(1-p_t)^\gamma$로 낮추어 희소한 어려운 예제에 집중 학습시키는 손실 함수.
- **라벨 스무딩(Label Smoothing)**: 정답 원-핫 벡터 $[0, 1, 0]$를 $[0.05, 0.90, 0.05]$와 같이 부드럽게 조정하여 모델의 과도한 확신(Overconfidence)과 과적합을 방지하는 정규화 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| Cross-Entropy 계산 시 $\hat{y} \to 0$에 의한 **$\log(0) = -\infty$ 발산** | Softmax와 CE를 결합한 **Log-Sum-Exp 안정 수식** 적용 | 수치 오버플로/언더플로 차단 |
| 극단적 이상치로 인해 MSE 회귀 모델의 **전체 파라미터 왜곡** | **Huber Loss ($\delta=1.0$) 또는 Smooth L1** 채택 | 이상치 영향력 억제 및 수렴 안정화 |
| 불균형 데이터 분류 시 **다수 클래스 손실 지배** | 쉬운 예제 가중치를 낮추는 **Focal Loss** 적용 | 희소 클래스 검출력 대폭 향상 |
| 과도한 확신으로 인한 과적합 및 일반화 저하 | **라벨 스무딩(Label Smoothing, $\epsilon=0.1$)** 도입 | 소프트 타깃 분포 유도로 캘리브레이션 개선 |

#### 한줄 요약

- 수치 안정성을 위해 Log-Sum-Exp 트릭을 적용하고, 회귀 이상치는 Huber 손실로 억제하며, 극심한 클래스 불균형은 Focal Loss로 가중치를 재조정한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **손실 함수 설계의 핵심 철학**: 모델의 출력층 활성화 함수(Softmax, Sigmoid, Linear)와 손실 함수는 확률론적 데이터 생성 분포(베르누이, 다항, 가우시안 분포)의 최대 우도 추정(MLE)과 엄격히 1:1로 일치해야 수렴이 보장.

</details>

- 확률 분류에는 **Cross-Entropy/Focal Loss**, 표준 회귀에는 **MSE**, 이상치 혼입 회귀에는 **Huber Loss** 활용  선택하여 과업 확률분포에 최적화

#### 한줄 요약

- 데이터 분포에 맞는 손실 함수를 선택하고, 불균형이나 이상치가 있으면 Focal Loss나 Huber 손실로 조정
