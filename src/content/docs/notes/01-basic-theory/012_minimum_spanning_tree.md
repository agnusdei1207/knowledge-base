## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **최소 신장 트리(Minimum Spanning Tree, MST)**: 가중치 무방향 그래프에서 모든 정점을 사이클 없이 연결하는 트리 중 간선 가중치 총합이 최소인 신장 트리.
- **신장 트리(Spanning Tree)**: 그래프 내의 모든 정점($V$)을 정확히 $V-1$개의 간선으로 사이클 없이 연결한 부분 그래프.
- **가중 무방향 그래프**: 방향성이 없고 각 간선에 비용, 거리 등의 가중치가 부여된 네트워크 그래프.

</details>

- 정의/개념: 모든 정점을 연결하는 트리 중 가중치 합이 최소인 **신장 트리**
- 배경/필요성: 네트워크 토폴로지 구축 시 모든 정점의 연결성을 유지하면서 순환 간선으로 인한 구축 비용 누적 및 브로드캐스트 스톰 위험

#### 한줄 요약

- 연결성만 지키면 되므로 사이클을 만드는 간선은 모두 버릴 수 있고, 이 버림이 총비용 최소성과 충돌하지 않는다는 것이 MST의 근거이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **컷 속성(Cut Property)**: 임의의 컷(Cut)을 가로지르는 간선들 중 가중치가 가장 작은 간선은 항상 MST의 일부(안전 간선)가 되는 성질.
- **안전 간선(Safe Edge)**: 현재 구축 중인 MST 부분 집합에 추가해도 MST의 불변식을 깨지 않는 최소 가중치 간선.
- **$V-1$개 간선**: $V$개의 정점을 사이클 없이 하나의 단일 트리로 연결하는 필요충분 간선 개수.

</details>

- $V$개의 정점을 사이클 없이 단일 연결 성분으로 묶는 **$V-1$개 간선** 구성
- **컷 속성**에 따른 **안전 간선** 선택으로 전체 최적성 보장
- **크루스칼**의 간선 중심과 **프림**의 정점 중심 탐색

#### 한줄 요약

- 컷 속성 및 안전 간선 선택에 의거하여 분할 경계를 통과하는 최소 가중치 간선을 선택하여 총비용 최소성을 보장한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **서로소 집합(Disjoint Set Union, DSU)**: 크루스칼에서 find와 union 연산을 통해 $O(\alpha(V))$ 시간에 사이클 발생 여부를 판정하는 자료구조.
- **우선순위 큐(Min-Heap Priority Queue)**: 프림에서 현재 트리에 인접한 간선 중 최소 가중치 간선을 $O(\log V)$ 시간에 추출하는 자료구조.

</details>

```text
+--------------------------------------------------------+
|                    MST 탐욕 제어기                     |
|  - 간선 정렬/최소 힙 기반 후보 추출 및 사이클 검증     |
+---------------------------+----------------------------+
                            |
            +---------------+---------------+
            v                               v
+-----------------------+       +-----------------------+
|      간선 후보 큐     |       |    연결 상태 관리자   |
|  - Kruskal: 정렬 큐   |       |  - DSU (사이클 검증)  |
|  - Prim: Min-Heap     |       |  - Visited 정점 집합  |
+-----------+-----------+       +-----------+-----------+
            |                               |
            +---------------+---------------+
                            v
+--------------------------------------------------------+
|                     MST 결과 집합                      |
|  - 선택된 V-1개 안전 간선 및 총 가중치 누적            |
+--------------------------------------------------------+
```

선의 의미: 실선 박스는 알고리즘 구성 모듈, 화살표(->)는 후보 간선 전달 및 유효성 검증 흐름

| 구성요소 | 책임 |
|:---|:---|
| MST 탐욕 제어기 | 후보 중 **안전 간선** 한정 누적 및 V-1개 수집 |
| 간선 후보 큐 | 간선 정렬 목록 및 **우선순위 큐** 보관 |
| 연결 상태 관리자 | **서로소 집합(DSU)**•방문 집합으로 사이클 검증 |
| MST 결과 집합 | 최종 선택된 V-1개 안전 간선 목록 보관 |

#### 한줄 요약

- 탐욕적 선택으로 최저 가중치 간선을 추출하고, DSU 또는 Visited Set으로 사이클 발생 여부를 검증한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **최소 신장 숲(Minimum Spanning Forest, MSF)**: 비연결 그래프에서 각 연결 성분(Connected Component)마다 독립적인 MST를 구축한 집합.

</details>

```text
+-----------------------+
|  그래프 입력 (V, E)   |
+-----------+-----------+
            |
            v
     /--------------\
    <  연결 그래프?  > -- No --> [ 연결 성분별 분할 후 MSF 반환 ]
     \--------------/
            | Yes
            v
     /--------------\
    < 간선 밀도 판정 > -- 희소 (E << V^2) --> [ 크루스칼: 간선 정렬 + DSU 탐색 ]
     \--------------/
            | 밀집 (E ~= V^2)
            v
[ 프림: 시작 정점 + Min-Heap 확장 ]
            |
            v
[ V-1개 안전 간선 선택 및 MST 완성 ]
```

분기 결과: 크루스칼은 간선 전체를 한 번 정렬하는 $O(E \log E)$를 선불로 치르므로 간선이 적을수록 유리하고, 프림은 트리에 인접한 간선만 힙에 담아 정렬 비용을 $O(E \log V)$로 분할 지불하므로 간선이 촘촘할수록 유리하며, 비연결 그래프에서는 한 시작점만 확장하는 프림이 나머지 성분을 통째로 놓치므로 연결 성분별 MSF로 분할 처리해야 한다.

**동작 원리**:
1. **간선 후보 추출**: 크루스칼은 전체 간선을 가중치 오름차순으로 정렬하고, 프림은 현재 트리에 인접한 간선들을 Min-Heap에 유지하며 최저 비용 간선을 추출한다.
2. **사이클 및 안전성 검증**: 크루스칼은 DSU의 `find` 연산으로 두 정점의 대표 원소를 비교하여 동일 집합 여부를 확인하고, 프림은 목적지 정점의 기방문 여부를 확인한다.
3. **간선 확정 및 집합 병합**: 사이클이 발생하지 않는 안전 간선으로 판정되면 MST 간선 집합에 추가하고, 크루스칼은 `union` 연산으로 두 정점 집합을 병합하며 프림은 방문 정점 집합을 갱신한다.
4. **인접 간선 갱신(프림)**: 프림 알고리즘의 경우 새로 추가된 정점에 인접한 미방문 간선들을 Min-Heap에 삽입하여 후보군을 확장한다.
5. **종료 조건 만족**: 선택된 간선의 총합이 정확히 $V-1$개에 도달하면 알고리즘을 즉시 종료하고 최소 가중치 합을 반환한다.

#### 한줄 요약

- 두 알고리즘은 같은 컷 속성을 쓰되 정렬 비용을 한꺼번에 낼지 나눠 낼지가 다르며, 그 선택 기준이 간선 밀도이다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **크루스칼(Kruskal)**: 간선들을 가중치 오름차순 정렬 후 DSU로 사이클이 없는 간선들을 탐욕 선택하는 $O(E \log E)$ 알고리즘.
- **프림(Prim)**: 시작 정점에서 출발하여 현재 트리에 인접한 정점 중 최소 가중치 간선을 연결해 나가는 $O(E \log V)$ 알고리즘.

</details>

| MST 알고리즘 | 크루스칼 | 프림 |
|:---|:---|:---|
| 적용 기준 | 간선 수가 적은 **희소 그래프** | 간선 수가 많은 **밀집 그래프** |
| 핵심 특징 | **간선 중심** 및 DSU 사이클 검증 | **정점 중심** 및 최소 힙 확장 |
| 한계 | 전체 **간선 정렬** 비용 지배 | **비연결 그래프**에서 시작 성분만 확장 |

#### 한줄 요약

- 희소 그래프는 간선 정렬 기반 크루스칼($O(E \log E)$), 밀집 그래프는 정점 확장 기반 프림($O(E \log V)$)이 적합하다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **결정적 보조 정렬(Tie-breaking Rule)**: 동일한 가중치를 가진 간선들 간에 정점 번호나 인덱스를 보조 키로 사용하여 항상 일관된 MST 결과를 보장하는 정렬 규칙.
- **동일 가중치 간선(Tied Edge Weights)**: 복수의 간선이 동일한 가중치를 가질 때 알고리즘 구현에 따라 서로 다른 유효 MST가 도출되는 현상.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **비연결 그래프**에서 단일 트리를 기대해 연결 영역 누락 | **연결성 검사** 후 **최소 신장 숲(MSF)** 반환 | 모든 **연결 성분** MST 보존 |
| **동일 가중치 간선**으로 실행마다 다른 MST 생성 | 정점 식별자 기반 **결정적 보조 정렬** 적용 | 동률 간선에서도 일관된 결과 생성 |
| 그래프 밀도·입력 구조와 구현 불일치로 비용 증가 | 희소·밀집 조건에 따라 **크루스칼·프림** 선택 | 입력 구조별 정렬·메모리 비용 감소 |
| 간선 가중치 동적 변경 후 **MST 최소성** 상실 | 영향 사이클 검증 또는 점진적 동적 MST 갱신 | 변경 그래프의 MST 최소성 회복 |

#### 한줄 요약

- 비연결 그래프는 MSF로 분할 처리하고, 동일 가중치 간선은 Tie-breaking 규칙으로 일관성을 확보하며, 희소·밀집 조건에 따라 크루스칼과 프림을 구분해야 한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **네트워크 인프라 최적화**: 물리 통신 선로 포설 및 전력망 라우팅 시 MST를 적용하여 설비 구축 총비용(CAPEX)을 극소화하는 공학적 응용.

</details>

- 통신 선로망 및 클러스터링의 최소 비용 연결을 보장하는 핵심 그래프 최적화 기법으로 정립되어 널리 활용되고 있으며, 향후 대규모 분산 그래프 스트리밍 환경을 지원하는 근사 MST 및 동적(Dynamic) 그래프 갱신 구조로 확장될 것으로 전망되고, 실무 엔지니어링에서는 간선 밀도($E \ll V^2$ vs $E \approx V^2$)와 그래프 연결성 유무에 따라 크루스칼(DSU 기반)과 프림(Min-Heap 기반)을 명확히 분기하여 불필요한 정렬 오버헤드를 차단해야 한다.

#### 한줄 요약

- 희소 간선 목록은 크루스칼, 밀집 인접 행렬은 프림을 선택한다.
