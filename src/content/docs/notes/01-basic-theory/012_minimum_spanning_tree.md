## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **최소 신장 트리(MST, Minimum Spanning Tree)**: 가중치 무방향 그래프에서 모든 정점을 사이클 없이 연결하는 트리 중 간선 가중치 총합이 최소인 신장 트리.
- **신장 트리(Spanning Tree)**: 그래프 내의 모든 정점($V$)을 정확히 $V-1$개의 간선으로 사이클 없이 연결한 부분 그래프.
- **가중 무방향 그래프**: 방향성이 없고 각 간선에 비용, 거리 등의 가중치가 부여된 네트워크 그래프.

</details>

- 정의/개념: 가중 무방향 그래프에서 사이클 없이 모든 정점을 연결하는 부분 트리 중 간선 가중치 총합이 최소가 되는 신장 트리 도출 알고리즘
- 배경/필요성: 통신망·전력망·배관 설계 시 전체 노드의 상호 연결성을 보장하면서 물리적 구축 비용(CAPEX)을 최소화하기 위한 최적화 기법 필요

#### 한줄 요약

- 가중 무방향 그래프에서 모든 정점을 사이클 없이 연결하면서 간선 가중치 합을 최소화

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **컷 속성(Cut Property)**: 임의의 컷(Cut)을 가로지르는 간선들 중 가중치가 가장 작은 간선은 항상 MST의 일부(안전 간선)가 되는 성질.
- **안전 간선(Safe Edge)**: 현재 구축 중인 MST 부분 집합에 추가해도 MST의 불변식을 깨지 않는 최소 가중치 간선.
- **$V-1$개 간선**: $V$개의 정점을 사이클 없이 하나의 단일 트리로 연결하는 필요충분 간선 개수.

</details>

- $V$개의 정점을 사이클 없이 단일 연결 성분으로 묶는 **$V-1$개 간선** 구성
- **컷 속성(Cut Property)** 기반의 탐욕적(Greedy) **안전 간선** 선택으로 수학적 전체 최적성 보장
- 분산된 그래프 환경에서 **크루스칼(간선 중심)** 및 **프림(정점 중심)** 의 이원적 탐색 메커니즘 제공

#### 한줄 요약

- 컷 속성 및 안전 간선 선택에 의거하여 분할 경계를 통과하는 최소 가중치 간선을 선택하여 총비용 최소성을 보장

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **서로소 집합(DSU, Disjoint Set Union)**: 크루스칼에서 find와 union 연산을 통해 $O(\alpha(V))$ 시간에 사이클 발생 여부를 판정하는 자료구조.
- **우선순위 큐(Min-Heap Priority Queue)**: 프림에서 현재 트리에 인접한 간선 중 최소 가중치 간선을 $O(\log V)$ 시간에 추출하는 자료구조.

</details>

```text
[ MST 알고리즘 아키텍처 및 자료구조 ]
┌──────────────────────────────┐
│ MST 탐욕 제어기 (Engine)     │ ── 컷 속성 기반 안전 간선 선택 및 누적
├──────────────────────────────┤
│ 간선 후보 큐 (Edge / Heap)   │ ── 간선 정렬 배열(크루스칼) / 우선순위 큐(프림)
├──────────────────────────────┤
│ 연결 상태 관리자 (DSU / Set) │ ── 서로소 집합(Union-Find) / 방문 집합(Visited)
├──────────────────────────────┤
│ MST 결과 집합 (Tree Edges)   │ ── 최종 선택된 V-1개의 안전 간선 목록
└──────────────────────────────┘
```

선의 의미: 탐욕 제어기, 간선 후보 관리, 사이클 검증 자료구조 및 MST 결과 집합 간의 구조도.

| 구성요소 | 책임 |
|:---|:---|
| MST 탐욕 제어기 | 후보 중 **안전 간선**만 누적 및 V-1개 수집 |
| 간선 후보 큐 | 간선 정렬 목록 및 **우선순위 큐** 보관 |
| 연결 상태 관리자 | **서로소 집합(DSU)**•방문 집합으로 사이클 검증 |
| MST 결과 집합 | 최종 선택된 V-1개 안전 간선 목록 보관 |

#### 한줄 요약

- 탐욕적 선택으로 최저 가중치 간선을 추출하고, DSU 또는 Visited Set으로 사이클 발생 여부를 검증

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **최소 신장 숲(MSF, Minimum Spanning Forest)**: 비연결 그래프에서 각 연결 성분(Connected Component)마다 독립적인 MST를 구축한 집합.

</details>

```text
최소 연결망 요구
├─ 비연결 그래프
│  └─ 연결 성분별 최소 신장 숲 (MSF) 반환
└─ 연결 그래프
   ├─ 희소 그래프 및 간선 목록 기반: 크루스칼 ($O(E \log E)$)
   └─ 밀집 그래프 및 인접 구조 기반: 프림 ($O(E \log V)$)
```

**동작 원리**

1. **연결성 판별**: 모든 정점이 연결되었는지 확인하고, 비연결 그래프일 경우 각 연결 성분별로 최소 신장 숲(MSF) 산출
2. **탐색 기법 선택**: 희소 그래프는 **크루스칼**, 밀집 그래프는 프림 선택
3. **크루스칼 통합 (Kruskal)**: 전체 간선을 가중치 오름차순으로 정렬한 후, 서로소 집합(DSU)을 이용해 사이클을 유발하지 않는 $V-1$개 간선 수집
4. **프림 확장 (Prim)**: 임의 시작 정점에서 출발해, 현재 트리 영역과 바깥 영역을 잇는 컷(Cut) 중 가중치가 최소인 간선을 우선순위 큐로 선택하여 확장

#### 한줄 요약

- 그래프 연결성과 간선 밀도(Dense/Sparse)에 따라 최적의 탐욕적 알고리즘(크루스칼 또는 프림)을 선택

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **크루스칼(Kruskal)**: 간선들을 가중치 오름차순 정렬 후 DSU로 사이클이 없는 간선들을 탐욕 선택하는 $O(E \log E)$ 알고리즘.
- **프림(Prim)**: 시작 정점에서 출발하여 현재 트리에 인접한 정점 중 최소 가중치 간선을 연결해 나가는 $O(E \log V)$ 알고리즘.

</details>

| 비교 항목 | 크루스칼 (Kruskal) | 프림 (Prim) |
|:---|:---|:---|
| 적용 기준 | 간선 수가 적은 **희소 그래프(Sparse)** | 간선 수가 많은 **밀집 그래프(Dense)** |
| 핵심 특징 | **간선 중심(Edge-centric)** 및 DSU 사이클 검증 | **정점 중심(Vertex-centric)** 및 최소 힙 확장 |
| 한계 및 위험 | 전체 **간선 정렬($E \log E$)** 비용 지배 | **비연결 그래프** 시 시작 연결 성분만 확장 |

#### 한줄 요약

- 희소 그래프는 간선 정렬 기반 크루스칼($O(E \log E)$), 밀집 그래프는 정점 확장 기반 프림($O(E \log V)$) 적합

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **동일 가중치 간선(Tied Edge Weights)**: 복수의 간선이 동일한 가중치를 가질 때 알고리즘 구현에 따라 서로 다른 유효 MST가 도출되는 현상.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **비연결 그래프**에서 단일 트리를 기대해 연결 영역 누락 | **연결성 검사(BFS/DFS)** 후 **최소 신장 숲(MSF)** 반환 | 모든 **연결 성분**의 MST 보존 |
| 동일 가중치 간선으로 실행마다 다른 MST 생성 | 정점 식별자 기반 **결정적 보조 정렬(Tie-breaking)** 적용 | 동률 간선에서도 일관된 결과 생성 |
| 그래프 밀도•입력 구조와 구현 불일치로 비용 증가 | 희소•밀집 조건에 **크루스칼**•**프림** 적재적소 선택 | 입력 구조별 정렬•메모리 비용 감소 |
| 간선 가중치 동적 변경 후 **MST 최소성** 상실 | 영향 사이클 검증 또는 점진적 동적 MST 갱신 | 변경 그래프의 MST 최소성 회복 |

#### 한줄 요약

- 비연결 그래프는 MSF로 분할 처리하고, 동일 가중치 간선은 Tie-breaking 규칙으로 일관성을 확보하며, 희소·밀집 조건에 따라 크루스칼과 프림을 구분해야 한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **네트워크 인프라 최적화**: 물리 통신 선로 포설 및 전력망 라우팅 시 MST를 적용하여 설비 구축 총비용(CAPEX)을 극소화하는 공학적 응용.

</details>

- 희소 그래프 및 간선 중심은 **크루스칼**, 밀집 그래프 및 정점 중심은 **프림** 선택

#### 한줄 요약

- 희소 간선 목록은 크루스칼, 밀집 인접 행렬은 프림을 선택
