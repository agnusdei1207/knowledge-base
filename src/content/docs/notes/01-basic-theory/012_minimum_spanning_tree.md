## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **최소 신장 트리(Minimum Spanning Tree, MST)**: 모든 정점을 사이클 없이 연결하면서 간선 가중치 합을 최소화한 트리이다.
- **신장 트리(Spanning Tree)**: 그래프의 모든 정점을 사이클 없이 연결한 트리이다.
- **가중 무방향 그래프**: 방향이 없는 각 간선에 비용이나 거리를 부여한 그래프이다.

</details>

- 정의/개념: 가중 무방향 그래프의 모든 정점을 사이클 없이 연결하며 총가중치를 최소화한 **최소 신장 트리**이다.
- 배경/필요성: 전체 연결 상태를 확인하지 않고 값이 작은 간선만 고르면 사이클이 생기거나 일부 정점이 연결되지 않을 수 있다.

#### 한줄 요약

- 가중 무방향 그래프에서 모든 정점을 사이클 없이 연결하면서 간선 가중치 합을 최소화한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **컷(Cut)**: 그래프의 정점 집합을 겹치지 않는 두 영역으로 나눈 경계이다.
- **컷 속성(Cut Property)**: 현재 선택 간선을 가르지 않는 컷의 최소 횡단 간선이 안전하다는 성질이다.
- **안전 간선(Safe Edge)**: 현재 선택 집합과 함께 MST로 확장할 수 있음이 보장된 간선이다.
- **연결 성분(Connected Component)**: 서로 경로로 도달할 수 있는 정점들의 최대 집합이다.
- **$V-1$개 간선**: $V$개 정점을 사이클 없이 하나의 트리로 연결할 때 필요한 간선 수이다.

</details>

- 모든 정점을 사이클 없이 연결하는 **$V-1$개 간선**이 핵심이다.
- **컷 속성** 기반 **안전 간선** 선택으로 총비용 최소성 보장이 핵심이다.
- **가중 무방향 그래프**의 연결 성분별 최소화가 핵심이다.

#### 한줄 요약

- 컷 속성 및 안전 간선 선택에 의거하여 정점 분할(Cut) 경계를 통과하는 최소 가중치 간선을 선택하여 총비용 최소성을 보장한다.


## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **우선순위 큐(Priority Queue)**: 후보 중 가중치가 가장 작은 간선을 먼저 꺼내는 자료구조이다.
- **서로소 집합(Disjoint Set Union, DSU)**: 연결 영역의 대표를 조회하고 합쳐 사이클을 판정하는 자료구조이다.
- **방문 집합**: 프림이 현재 트리에 포함한 정점을 기록하는 집합이다.

</details>

```text
MST 알고리즘 구조
├─ MST 알고리즘
├─ 간선 후보 집합
└─ 연결 상태 집합
```

가지의 의미: 선택 제어•간선 후보•연결 상태의 정적 책임 분리를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| MST 알고리즘 | 후보 중 **안전 간선**만 누적 |
| 간선 후보 집합 | 간선 목록•**우선순위 큐** 보관 |
| 연결 상태 집합 | **서로소 집합•방문 집합** 보관 |

#### 한줄 요약

- 탐욕적 선택(Greedy Choice)으로 최저 가중치 간선을 추출하고, DSU(Disjoint Set Union) 또는 Visited Set으로 사이클 발생 여부를 검증한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **간선 밀도**: 가능한 전체 간선 수에 비해 실제 간선이 차지하는 비율이다.
- **입력 구조**: 간선 목록•인접 목록•인접 행렬로 구분한 그래프 표현이다.

</details>

```text
최소 연결망 요구
├─ 비연결 그래프
│  └─ 연결 성분별 최소 신장 숲 반환
└─ 연결 그래프
   ├─ 희소•간선 목록
   │  └─ 크루스칼
   └─ 밀집•인접 구조
      └─ 프림
```

가지의 의미: 연결성•간선 밀도•입력 구조에 따른 결정 분기를 나타낸다.

#### 한줄 요약

- 그래프 연결성(Connectivity) 및 간선 밀도(Dense/Sparse)에 따라 크루스칼 또는 프림 알고리즘을 결정한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **크루스칼(Kruskal)**: 전체 간선을 가중치순으로 검사해 사이클 없는 간선을 선택하는 알고리즘이다.
- **프림(Prim)**: 현재 트리와 바깥 정점을 잇는 최소 간선으로 연결 영역을 확장하는 알고리즘이다.
- **희소 그래프(Sparse Graph)**: 가능한 정점 쌍에 비해 실제 간선이 적은 그래프이다.
- **밀집 그래프(Dense Graph)**: 가능한 정점 쌍에 비해 실제 간선이 많은 그래프이다.
- **간선 목록(Edge List)**: 간선을 끝점과 가중치 묶음으로 나열한 구조이다.
- **인접 행렬(Adjacency Matrix)**: 정점 쌍별 가중치를 표로 저장한 구조이다.
- **비연결 그래프(Disconnected Graph)**: 일부 정점 쌍 사이에 연결 경로가 없는 그래프이다.
- **간선 정렬**: 크루스칼이 전체 간선을 가중치 오름차순으로 배치하는 작업이다.

- **가중치순 정렬(Weight Order Sorting)**: 크루스칼 알고리즘에서 모든 간선을 가중치 오름차순으로 정렬하여 탐욕 선택을 준비하는 단계.
- **최소 간선 선택(Minimum Edge Selection)**: 프림 알고리즘에서 현재 트리에 인접한 간선 중 가중치가 최소인 간선을 우선 확장하는 방식.
</details>

| MST 알고리즘 | 크루스칼 | 프림 |
|:---|:---|:---|
| 적용 기준 | 간선 목록 정렬이 싼 **희소 그래프** | 인접 행렬 순회가 유리한 **밀집 그래프** |
| 핵심 특징 | **가중치순** 무사이클 간선 선택 | 트리 밖 **최소 간선**으로 확장 |
| 한계 | 전체 **간선 정렬** 비용이 수행 시간 지배 | **비연결 그래프**에서 시작 영역만 확장 |

> 요약: **간선 밀도•입력 구조**로 알고리즘을 선택한다.

#### 한줄 요약

- 희소 그래프에서는 간선 정렬 기반 크루스칼($O(E \log E)$), 밀집 그래프에서는 정점 확장 기반 프림($O(V^2)$ 또는 $O(E \log V)$)이 적합하다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **최소 신장 숲(Minimum Spanning Forest)**: 비연결 그래프의 각 연결 성분에서 만든 MST의 집합이다.
- **결정적 보조 정렬**: 같은 가중치의 간선을 정점 식별자 같은 추가 기준으로 정렬해 결과를 재현하는 방식이다.
- **영향 범위 검증**: 간선 비용 변경이 기존 MST의 최소성에 영향을 주는지 확인하는 과정이다.
- **연결성 검사**: 모든 정점이 하나의 경로 집합으로 이어지는지 확인하는 절차이다.
- **MST 최소성**: 다른 어떤 신장 트리도 선택 결과보다 더 작은 총가중치를 갖지 않는 성질이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **비연결 그래프**에서 단일 트리를 기대해 연결 영역 누락 | **연결성 검사** 후 **최소 신장 숲** 반환 | 모든 **연결 성분**의 MST 보존 |
| 동일 가중치 간선으로 실행마다 다른 MST 생성 | 정점 식별자의 **결정적 보조 정렬** 적용 | 동률 간선에서도 같은 결과 생성 |
| 그래프 밀도•입력 구조와 구현 불일치로 비용 증가 | 희소•밀집 조건에 **크루스칼•프림** 선택 | 입력 구조별 정렬•메모리 비용 감소 |
| 간선 비용 변경 후 **MST 최소성** 상실 | **영향 범위 검증** 또는 전체 재계산 | 변경 그래프의 MST 최소성 회복 |

#### 한줄 요약

- 비연결 그래프(Disconnected Graph)의 경우 각 연결 성분(Connected Component)별로 최소 신장 숲(Minimum Spanning Forest)을 구축한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **인접 구조**: 각 정점의 이웃과 가중치를 저장해 프림이 확장 후보를 찾는 그래프 표현이다.

</details>

- 희소 간선 목록은 **크루스칼**, 밀집 인접 구조는 **프림**을 선택한다.

#### 한줄 요약

- 희소 간선 목록은 크루스칼, 밀집 인접 행렬은 프림을 선택한다.
