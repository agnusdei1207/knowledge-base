## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **균형 탐색 트리(Balanced Search Tree)**: 키 순서 조건을 가진 탐색 트리 중 균형 규칙으로 높이를 제한한 계열로 B-Tree•AVL•레드블랙 트리를 포함
- **편향 트리(Skewed Tree)**: 한쪽 자식만 이어져 선형화된 트리

</details>

- 정의/개념: 키 순서 조건과 **균형 규칙**으로 높이를 제한하는 B-Tree•AVL•레드블랙 탐색 트리 계열
- 배경/필요성: **편향 트리**의 $O(n)$ 탐색 비용 방지

### 쉽게 이해하기 (학습용)

- 갈림길 표지판의 키를 보고 한쪽 길만 고르되, 어느 길도 지나치게 길어지지 않게 가지를 재배치해 탐색 단계를 제한한다.


## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **로그 시간 $O(\log n)$**: 입력이 늘어도 처리 단계가 완만하게 증가하는 시간 상한
- **균형 유지**: 한쪽 경로가 지나치게 길어지지 않도록 트리 높이를 제한하는 작업
- **범위 탐색**: 키 순서를 이용해 일정 구간에 속하는 원소를 차례로 찾는 탐색

</details>

![AVL과 레드블랙 트리의 키 수별 높이 상한](/study/diagrams/balanced-tree-height.svg)

> 키 수가 늘어도 두 선은 로그 증가하며 파란 AVL 높이 상한이 붉은 레드블랙보다 낮고, 각 균형 규칙의 이론적 상한이다.

- 키 순서에 따른 **계층적 탐색 범위** 축소
- **균형 유지**로 탐색•삽입•삭제의 $O(\log n)$ 보장
- 키 순서를 보존한 **범위 탐색** 지원

### 쉽게 이해하기 (학습용)

- 한쪽 계단만 길어진 건물을 다시 나누듯, 균형 복구는 루트에서 말단까지의 최대 경로를 로그 높이로 제한한다.


## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **루트(Root)**: 트리 탐색을 시작하는 최상위 노드
- **균형 정보**: 높이 차나 색상처럼 트리의 균형 규칙을 판정하는 노드 상태
- **회전(Rotation)**: 키 순서를 보존하며 부모•자식 관계를 바꿔 균형을 복구하는 연산

</details>

```mermaid
block
    columns 3
    R["루트 참조"] --- T["탐색 제어기"] --- N["트리 노드"] --- B["균형 복구기"]
```

| 구성요소 | 책임 |
|:---|:---|
| 루트 참조 | **탐색 시작 노드** 위치 보관 |
| 탐색 제어기 | 키 대소로 **탐색 경로** 선택 |
| 트리 노드 | 키•자식 참조와 **균형 정보** 보관 |
| 균형 복구기 | **회전•색상•분할**로 규칙 복구 |

### 쉽게 이해하기 (학습용)

- 탐색 제어기가 루트부터 키를 비교하고, 균형 복구기가 갱신된 노드의 규칙 위반을 바로잡는다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **탐색 경로**: 루트부터 목표 키나 삽입 위치까지 키 비교로 선택한 노드의 순서
- **균형 규칙 위반**: 갱신으로 높이 차•색상•노드 키 수 조건을 벗어난 상태
- **분할(Split)**: B-Tree의 가득 찬 노드를 나누고 중앙 키를 부모로 올리는 복구 연산

</details>

```mermaid
sequenceDiagram
    participant Q as 호출자
    participant T as 탐색 제어기
    participant N as 트리 노드
    participant B as 균형 복구기
    Q->>T: 키 처리 요청
    loop 목표 키 또는 삽입 위치까지
        T->>N: 1. 키 비교 요청
        N-->>T: 2. 비교 결과 반환
    end
    alt 갱신 요청
        T->>B: 3. 갱신 경로 전달
        opt 균형 규칙 위반
            B->>T: 4. 균형 복구 결과 전달
        end
    end
    T-->>Q: 처리 결과 반환
```

**동작 원리**

1. **키 비교 요청**: 현재 노드에 목표 키 대소 판정 요청
2. **비교 결과 반환**: 루트부터 키 대소로 자식 선택
3. **갱신 경로 전달**: 변경 경로의 균형 규칙 위반 판정
4. **균형 복구 결과 전달**: 회전•색상•분할 반영

### 쉽게 이해하기 (학습용)

- 안내판의 키를 따라 목적 노드를 찾고, 새 키로 가지 균형이 깨지면 복구기가 회전•색상 변경•분할로 경로를 다시 줄인다.


## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **B-Tree**: 한 노드에 여러 키와 자식을 저장해 저장장치 페이지 접근 횟수를 줄이는 균형 트리
- **AVL 트리(AVL)**: 각 노드의 좌우 서브트리 높이 차를 1 이하로 유지하는 이진 탐색 트리
- **레드블랙 트리(Red-Black Tree)**: 노드 색상과 경로 규칙으로 높이를 제한하는 이진 탐색 트리
- **다진 분기(Multiway Branching)**: 한 노드가 셋 이상의 자식을 가져 트리 높이를 줄이는 구조

</details>

| 균형 탐색 트리 | B-Tree 계열 | AVL 트리 | 레드블랙 트리 |
|:---|:---|:---|:---|
| 적용 기준 | **페이지 단위** 외부 저장소 색인 | 갱신 드물고 **조회 집중** | 메모리에서 **삽입•삭제 빈번** |
| 핵심 특징 | **다진 분기**로 노드당 여러 키 보유 | 좌우 **높이 차 1 이하** 제한 | 노드 **색상•경로 규칙** 유지 |
| 한계 | 분할•병합 시 **페이지 쓰기** 비용 | 삭제 시 상향 **재균형 반복** | AVL보다 **긴 탐색 경로** |

> 요약: 노드당 키 수•**균형 강도**에 따른 갱신 비용 차이

### 쉽게 이해하기 (학습용)

- 저장장치는 넓은 B-Tree, 메모리는 균형 강도에 따라 AVL•레드블랙을 선택한다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **페이지(Page)**: 저장소에서 한 번에 읽고 쓰는 블록
- **B-Tree 차수(Order)**: 한 노드가 가질 수 있는 자식 수의 상한
- **복구 로그•원자적 쓰기(Recovery Log•Atomic Write)**: 변경 이력을 기록하고 페이지 변경을 전부 반영하거나 전혀 반영하지 않는 복구 방식
- **잠금 경합(Lock Contention)**: 여러 실행 흐름이 같은 노드 잠금을 얻으려고 대기하는 상태

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 저장 페이지보다 작은 **노드 분기 수**로 I/O 증가 | 페이지 크기에 맞춘 **B-Tree 차수** 설정 | 트리 높이와 **페이지 접근 횟수 감소** |
| 조회·갱신 비율과 균형 정책 불일치로 비용 증가 | 조회 중심 AVL, 갱신 중심 레드블랙 선택 | 워크로드별 **탐색·회전 비용 균형** |
| 분할·병합 중 장애로 일부 구조만 반영돼 경로 손상 | **복구 로그•원자적 페이지 쓰기** 적용 | 장애 후 **트리 구조 일관성** 복구 |
| 동시 노드 갱신의 **잠금 경합** | 루트·리프 방향 잠금 순서와 범위 고정 | **교착 방지**와 동시 처리량 안정화 |

### 쉽게 이해하기 (학습용)

- 노드 크기를 저장장치 페이지에 맞춰 한 번에 읽는 키를 늘린다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **I/O(Input/Output)**: 저장소 페이지와 메모리 사이의 읽기•쓰기 작업
- **조회 중심•갱신 중심**: 탐색 빈도와 삽입•삭제 빈도 중 어느 쪽이 더 높은지 나타내는 워크로드 성격

</details>

- I/O는 **B-Tree**, 조회는 **AVL**, 갱신은 레드블랙 선택

### 쉽게 이해하기 (학습용)

- 디스크 페이지 왕복이 병목이면 넓고 낮은 B-Tree를, 메모리에서는 조회가 많으면 AVL을, 갱신이 많으면 레드블랙을 선택한다.
