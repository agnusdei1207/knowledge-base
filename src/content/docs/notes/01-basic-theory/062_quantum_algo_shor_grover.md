## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **양자 알고리즘(Quantum Algorithm)**: 양자역학의 중첩(Superposition), 얽힘(Entanglement), 간섭(Interference) 현상을 이용하여 고전 컴퓨터보다 빠른 속도로 문제를 해결하는 알고리즘.
- **큐비트(Qubit)**: 0과 1의 상태를 동시에 중첩하여 가질 수 있는 양자 정보의 기본 단위 ($|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$).
- **양자 이점(Quantum Supremacy/Advantage)**: 고전 컴퓨터로는 실질적으로 불가능한 계산을 양자 컴퓨터가 다항 시간 내에 해결함을 입증하는 현상.

</details>

- 정의/개념: 큐비트의 **중첩·간섭**으로 특정 문제를 가속하는 양자 알고리즘
- 배경/필요성: 고전 폰 노이만 컴퓨터가 소인수분해(준지수 시간) 및 비정렬 탐색($O(N)$)에서 직면하는 **순차 튜링 기계 연산 복잡도 한계**

#### 한줄 요약

- 가속은 모든 문제가 아니라 주기 찾기나 진폭 증폭으로 환원되는 구조에서만 나오므로, 양자 이점은 하드웨어보다 문제의 구조에 달려 있다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **중첩(Superposition)**: $n$개의 큐비트가 $2^n$개의 상태를 동시에 표현하여 한 번의 연산으로 병렬 처리할 수 있는 성질.
- **양자 간섭(Quantum Interference)**: 정답 상태의 확률 진폭은 보강 간섭으로 키우고 오답 상태는 상쇄 간섭으로 소멸시키는 원리.

</details>

- 큐비트 **중첩(Superposition)** 통한 $2^n$개 상태 동시 표현 및 병렬 계산
- **양자 간섭(Quantum Interference)** 이용한 정답 상태 확률 진폭 증폭 및 오답 상쇄
- 쇼어 알고리즘의 **소인수분해 지수적 가속($O(n^3)$)** 및 그로버 알고리즘의 **비정렬 탐색 이차적 가속($O(\sqrt{N})$)**

#### 한줄 요약

- 중첩으로 방대한 상태를 동시 표현하고 간섭으로 정답 진폭을 증폭하여 고전적 시간 복잡도를 혁신

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **양자 푸리에 변환(Quantum Fourier Transform, QFT)**: 양자 상태의 진폭을 이산 푸리에 변환하여 상태의 주기(Period)를 $O(n^2)$에 검출하는 핵심 양자 서브루틴.
- **양자 오라클(Quantum Oracle)**: 찾고자 하는 정답 상태의 위상을 반전($|x\rangle \to -|x\rangle$)시키는 블랙박스 양자 게이트.

</details>

```text
+-----------------------------------------------------------------------------+
|                     양자 가속 알고리즘(Shor & Grover) 아키텍처               |
+-----------------------------------------------------------------------------+
|  [양자 레지스터 & 아다마르] --> n개 큐비트 |0> 기저 상태를 균등 중첩으로 변환 |
|          |                                                                  |
|          +---[쇼어 서브루틴]------------------------------------------------+
|          |    --> 모듈러 멱승 f(x)=a^x mod N 및 양자 푸리에 변환(QFT)       |
|          |                                                                  |
|          +---[그로버 서브루틴]----------------------------------------------+
|          |    --> 양자 오라클 위상 반전 및 확산 연산자 진폭 증폭            |
|          |                                                                  |
|          v                                                                  |
|  [기저 측정기 & 고전 후처리]--> 양자 상태 관측 및 연분수 전개/인덱스 확정     |
+-----------------------------------------------------------------------------+
```

선의 의미: 실선 박스는 양자 중첩 생성부터 알고리즘별 양자 서브루틴 및 고전 측정 단계를 나타내며, 화살표는 중첩, 유니터리 변환, 진폭 제어 및 관측 흐름을 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 양자 레지스터 | $n$개 큐비트의 **중첩 상태** 유지 |
| 아다마르 게이트 | 기저 상태를 **균등 중첩**으로 변환 |
| 모듈러 멱승·QFT 회로 | 함수 주기를 **위상**에 부호화·추출 |
| 양자 오라클·확산 연산자 | 정답 위상 반전과 **진폭 증폭** 수행 |
| 기저 측정기 | 양자 상태를 **고전 비트열**로 관측 |

#### 한줄 요약

- 양자 레지스터에 중첩을 생성하고 QFT 또는 오라클 확산 연산자를 적용하여 정답을 측정

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **진폭 증폭(Amplitude Amplification)**: 정답 상태의 확률을 평균에 대한 대칭 이동을 통해 $\approx 100\%$로 점진 증가시키는 그로버의 핵심 연산.

</details>

```text
알고리즘 입력 (합성수 N 또는 N개 비정렬 데이터베이스)
   |
   v
[ 1. 양자 레지스터 초기화 및 아다마르 균등 중첩 ] : H^(⊗n) |0>
   |
   v
[ 2. 알고리즘 분기 선택 ]
   |
   +---> 쇼어 알고리즘 (소인수분해) :
   |        |
   |        v
   |     [ 3-A. 모듈러 멱승 및 역양자 푸리에 변환(IQFT) ]
   |        |
   |        v
   |     [ 4-A. 주기 r 측정 및 고전 연분수 전개 ] ---> 소인수 p, q 도출
   |
   +---> 그로버 알고리즘 (비정렬 검색) :
            |
            v
         [ 3-B. 오라클 위상 반전 및 확산 연산자 반복 ] (약 π/4 √N 회)
            |
            v
         [ 4-B. 기저 상태 측정 ] ---> 정답 인덱스 확정
```

분기 결과: 해결 과업이 소인수분해/이산대수이면 쇼어의 IQFT 주기 측정 경로로 분기하고, 비정렬 DB 탐색 및 SAT 만족성이면 그로버의 오라클 진폭 증폭 반복 루프로 분기하여 측정한다.

**동작 원리**:
1. **양자 레지스터 초기화 및 중첩 생성**: $n$개 큐비트를 기저 상태 $|0\rangle$으로 초기화한 후 아다마르 게이트($H^{\otimes n}$)를 통과시켜 모든 가능한 상태의 균등 중첩을 형성한다.
2. **쇼어의 주기 탐색(Order Finding)**: 모듈러 지수 함수 $f(x) = a^x \pmod N$를 양자 병렬 계산하고, 역 양자 푸리에 변환(IQFT)을 통해 함수의 주기 $r$을 위상 형태로 추출한다.
3. **고전 후처리 및 인수 추출**: 양자 측정으로 얻은 위상 값을 고전 연분수 알고리즘으로 전개하여 정수 주기 $r$을 도출하고, $\gcd(a^{r/2} \pm 1, N)$으로 비자명한 소인수를 다항 시간 $O(n^3)$에 완성한다.
4. **그로버의 위상 반전 및 진폭 증폭**: 양자 오라클 $U_\omega$로 정답 상태의 부호만 음수로 반전시킨 뒤, 평균에 대한 대칭 이동인 확산 연산자(Diffusion Operator)를 적용하여 정답 상태의 확률 진폭을 증폭한다.
5. **최적 반복 후 측정**: 증폭 과정을 약 $\frac{\pi}{4}\sqrt{N}$회 반복한 후 양자 레지스터를 측정하여 $99\%$ 이상의 높은 확률로 목표 인덱스를 획득한다.

#### 한줄 요약

- 중첩을 만들고 함수를 적용한 후 QFT나 확산 연산자로 증폭하여 측정 및 고전 후처리 수행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **쇼어 알고리즘(Shor's Algorithm)**: 소인수분해와 이산대수 문제를 양자 푸리에 변환으로 다항 시간($O(n^3)$)에 푸는 알고리즘.
- **그로버 알고리즘(Grover's Algorithm)**: $N$개의 비정렬 데이터 검색을 진폭 증폭을 통해 $O(\sqrt{N})$에 수행하는 알고리즘.

</details>

| 대표 양자 알고리즘 | 쇼어 알고리즘 (Shor's) | 그로버 알고리즘 (Grover's) |
|:---|:---|:---|
| 적용 기준 | 소인수분해 기반 공개키 암호 해독 시 | 비정렬 데이터베이스 초고속 탐색 시 |
| 고전 복잡도 | 준지수 시간 $O(e^{\sqrt[3]{n \log^2 n}})$ (GNFS) | 선형 탐색 시간 $O(N)$ |
| 양자 복잡도 | **다항 시간 $O(n^3)$ (지수적 가속)** | **제곱근 시간 $O(\sqrt{N})$ (이차적 가속)** |
| 암호학적 영향 | **RSA, ECC 등 현대 공개키 암호 체계 완전 무력화** | **AES 등 대칭키 암호 유효 키 길이 50% 반감** |

#### 한줄 요약

- 쇼어는 공개키 암호를 지수적으로 해독하고, 그로버는 비정렬 검색을 이차적으로 가속

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **양자 오류 정정(Quantum Error Correction, QEC)**: 환경 잡음에 의한 큐비트의 결맞음(Decoherence)과 게이트 오류를 물리 큐비트 여분으로 복구하는 기술.
- **양자내성암호(Post-Quantum Cryptography, PQC)**: 쇼어 알고리즘으로도 풀 수 없는 수학적 격자 난제 등에 기반한 차세대 암호.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **HNDL**로 장기 기밀 데이터가 미래에 노출 | **PQC** 전환과 암호 자산 목록화 | 수확한 암호문의 사후 복호화 차단 |
| 그로버 탐색으로 **대칭키 보안강도** 감소 | **AES-256**과 SHA-384/512로 상향 | 양자 탐색 후 128비트 이상 유지 |
| NISQ 장비의 **결맞음 손실**과 게이트 오류 | 표면 코드 기반 **QEC** 적용 | 내결함성 양자 계산 기반 확보 |

#### 한줄 요약

- 공개키 붕괴는 PQC로 방어하고, 대칭키 약화는 AES-256으로 상향하며, 노이즈는 오류 정정으로 극복

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **HNDL(Harvest Now, Decrypt Later)**: 공격자가 현재 암호화된 트래픽을 미리 수집 저장해 둔 뒤 미래에 양자 컴퓨터가 개발되면 일괄 복호화하는 사이버 위협.

</details>

- 양자 컴퓨팅(Quantum Supremacy) 시대의 **핵심 양자 가속 표준 알고리즘(암호 해독 및 비정렬 검색)**으로 정립되었으며, 실무 보안 인프라에서는 **HNDL(Harvest Now, Decrypt Later) 공격에 대비한 NIST 표준 PQC(양자내성암호) 전환 및 대칭키 키 길이 상향(AES-128 $\to$ AES-256, SHA-256 $\to$ SHA-384/512)**을 즉시 실행

#### 한줄 요약

- 양자 알고리즘 위협에 대비하여 PQC 도입과 대칭키 암호 강도 상향을 즉각 추진
