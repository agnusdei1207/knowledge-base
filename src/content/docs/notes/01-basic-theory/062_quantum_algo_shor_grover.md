## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **양자 알고리즘(Quantum Algorithm)**: 중첩•간섭•측정을 이용해 문제의 답을 구하며 쇼어와 그로버 알고리즘을 포함하는 계산 방식이다.
- **중첩(Superposition)**: 여러 양자 상태를 동시에 표현하는 성질이다.
- **간섭(Interference)**: 위상 관계로 정답 상태의 측정 확률을 높이는 현상이다.
- **쇼어 알고리즘(Shor's Algorithm)**: 주기 찾기로 소인수분해를 가속하는 양자 알고리즘이다.
- **그로버 알고리즘(Grover's Algorithm)**: 진폭 증폭으로 비정렬 탐색을 가속하는 양자 알고리즘이다.
- **계산 비용**: 알고리즘이 수행하는 전체 연산량이다.
- **질의 비용**: 문제 함수에 답을 요청하는 횟수이다.

</details>

- 정의/개념: **양자 알고리즘**은 **중첩**과 **간섭**을 이용하며, **쇼어 알고리즘**은 주기 찾기로 정수를 소인수분해하고 **그로버 알고리즘**은 진폭 증폭으로 비정렬 탐색의 질의 수를 줄인다.
- 배경/필요성: 큰 정수의 소인수분해와 구조 없는 대규모 탐색은 고전 알고리즘에서 계산 시간 또는 오라클 질의 수가 빠르게 증가한다.

#### 한줄 요약
- 양자 간섭에서 보강 간섭은 정답 상태의 확률 진폭을 증폭하고, 상쇄 간섭은 오답 상태의 확률 진폭을 감소시킨다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **확률 진폭**: 측정 확률을 결정하는 복소수 계수이다.
- **위상**: 양자 상태 사이의 간섭 방향을 정하는 각도이다.
- **측정**: 양자 상태에서 고전 결과를 얻는 연산이다.
- **상태 붕괴**: 측정으로 중첩이 하나의 결과 상태로 확정되는 현상이다.
- **양자 우위**: 특정 문제에서 양자 계산이 실용적인 고전 계산보다 시간이나 자원을 적게 쓰는 상태이다.
- **오라클(Oracle)**: 후보가 정답인지 판정해 양자 상태의 위상에 표시하는 문제 함수이다.
- **양자 오류 정정**: 여러 물리 큐비트로 논리 상태의 잡음 오류를 검출•복구하는 기술이다.
- **고전 후처리**: 측정 결과에서 후보 답을 계산하고 검증하는 고전 계산 단계이다.

</details>

![후보 수에 따른 고전 탐색과 그로버 탐색의 질의 횟수 차트](/study/diagrams/grover-query-growth.svg)

> 오라클 구성•상수 비용을 제외한 이론 관계에서 파란 고전 탐색은 $N$, 빨간 그로버 탐색은 $\sqrt N$으로 증가해 후보 수가 커질수록 간격이 확대된다.

- **확률 진폭**과 **위상**의 간섭으로 정답 상태의 측정 확률을 높인다.
- **측정**•**상태 붕괴**에 따라 반복 실행과 **고전 후처리**가 필요하다.
- **오라클**과 **양자 오류 정정**의 비용까지 반영해 **양자 우위**를 판단한다.

#### 한줄 요약
- 양자 우위에는 문제에 맞는 회로•오라클과 측정 결과의 고전 후처리가 필요하다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **큐비트 레지스터**: 0과 1의 중첩 상태를 보관하는 양자 정보 단위의 집합이다.
- **양자 푸리에 변환(Quantum Fourier Transform, QFT)**: 주기 정보를 주파수 성분으로 변환하는 양자 연산이다.
- **역 QFT**: 주기 정보를 측정 가능한 상태로 바꾸는 역변환이다.
- **진폭 증폭**: 정답 상태의 측정 확률을 반복적으로 키우는 연산이다.
- **모듈러 거듭제곱**: 쇼어 알고리즘에서 입력 지수에 따른 나머지를 계산해 주기 정보를 부호화하는 연산이다.
- **후보 답 검증**: 측정 결과에서 얻은 인수나 탐색 후보가 실제 정답인지 고전적으로 확인하는 과정이다.

</details>

```text
[양자 알고리즘 실행 구조]
          |
          +-- [큐비트 레지스터]
          +-- [문제 함수 회로]
          +-- [간섭 연산]
          +-- [측정기]
          `-- [고전 제어•후처리기]
```

선의 의미: 양자 상태•문제 회로•간섭•측정•고전 검증의 정적 구성을 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 큐비트 레지스터 | 중첩 입력과 계산 상태 보관 |
| 문제 함수 회로 | **모듈러 거듭제곱**•오라클 구현 |
| 간섭 연산 | 위상•진폭에 **역 QFT**•**진폭 증폭** 수행 |
| 측정기 | 양자 상태를 고전 비트 결과로 변환 |
| 고전 제어•후처리기 | 회로 제어와 **후보 답 검증** 수행 |

#### 한줄 요약
- 양자 회로가 후보 상태를 변환하고 측정기와 고전 후처리기가 결과를 검증한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **함수 적용 상태**: 문제 함수가 주기 정보나 정답 여부를 상태의 위상에 부호화한 결과이다.
- **정답 신뢰도**: 반복 측정과 검증 결과가 정답임을 뒷받침하는 확률 수준이다.
- **주기 추출**: 함수의 반복 주기를 간섭으로 드러내는 연산이다.
- **모듈러 주기 상태 부호화**: 모듈러 거듭제곱 함수의 주기 정보를 큐비트 상태에 기록하는 단계이다.
- **역 QFT•측정•주기 후보 추출**: 역 QFT와 측정값의 연분수 해석으로 주기 후보를 구하는 단계이다.
- **고전 인수 후보 검증**: 주기 후보로 계산한 인수가 원래 정수를 나누는지 고전적으로 확인하는 단계이다.
- **오라클 위상 표시**: 오라클이 정답 상태의 위상을 반전해 다른 후보와 구별하는 단계이다.
- **확산 연산•진폭 증폭**: 평균에 대한 진폭 반사로 정답 상태의 측정 확률을 반복 확대하는 단계이다.

</details>

```text
[쇼어: 소인수분해]
        |
        v
1. 모듈러 주기 상태 부호화
        |
        v
2. 역 QFT•측정•주기 후보 추출
        |
        v
3. 고전 인수 후보 검증
        |
        +-- 실패 --> 1로 재실행
        |
        v
[소인수 후보]

[그로버: 비정렬 탐색]
        |
        v
+----------------------------------+
| 약 O(√N)회 진폭 증폭             |
|                                  |
|  4. 오라클 위상 표시             |
|             |                    |
|             v                    |
|  5. 확산 연산•진폭 증폭          |
|             |                    |
|             `-------- 반복 ------|
+----------------------------------+
        |
        v
[측정•정답 후보 검증]
```

**동작 원리**

- **1. 모듈러 주기 상태 부호화**: **함수 적용 상태**에 거듭제곱 함수의 주기 정보를 생성한다.
- **2. 역 QFT•측정•주기 후보 추출**: **주기 추출** 후 측정값을 연분수로 해석해 함수 주기 후보를 산출한다.
- **3. 고전 인수 후보 검증**: 주기로 인수를 계산하고 정답을 확인한다.
- **4. 오라클 위상 표시**: 정답 상태의 위상을 반전한다.
- **5. 확산 연산•진폭 증폭**: **정답 신뢰도**를 높이도록 정답 상태의 측정 확률을 확대한다.

#### 한줄 요약
- 문제 함수가 후보 상태의 위상에 답의 흔적을 새기면, 간섭 연산이 정답 진폭을 키우고 측정이 고전 비트열을 만든다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **회로 깊이**: 서로 동시에 실행할 수 없는 양자 게이트 단계의 수이다.
- **모듈러 지수 회로**: 쇼어 알고리즘의 모듈러 거듭제곱을 양자 게이트로 구현한 회로이다.
- **오라클 비용**: 정답 판정 함수를 양자 회로로 실행하는 데 필요한 게이트•큐비트•시간이다.
- **소인수분해**: 합성수를 곱을 이루는 소수 인수들로 나누는 문제이다.
- **이산 로그**: 유한군에서 $g^x=y$를 만족하는 지수 $x$를 구하는 문제이다.
- **비정렬 탐색**: 정렬이나 색인 구조 없이 $N$개 후보에서 정답을 찾는 문제이다.
- **주기 찾기**: 함수값이 반복되는 최소 주기를 구하는 쇼어 알고리즘의 핵심 문제이다.
- **다항 시간**: 입력 크기의 다항식으로 상한이 정해지는 실행 시간이다.
- **제곱근 질의 복잡도**: 후보 수 $N$에 대해 오라클 호출 횟수가 $O(\sqrt N)$으로 증가하는 복잡도이다.

</details>

| 양자 알고리즘 | 쇼어 알고리즘 | 그로버 알고리즘 |
|:---|:---|:---|
| 적용 기준 | **소인수분해**•**이산 로그**를 푸는 경우 | 정렬•색인 없는 **비정렬 탐색**이 필요한 경우 |
| 핵심 특징 | **주기 찾기**로 다항 시간 인수 계산 | **진폭 증폭**으로 $O(\sqrt{N})$ 질의 탐색 |
| 한계 | **모듈러 지수 회로**의 큰 깊이•큐비트 수 | **오라클 비용** 증가•반복 횟수 오설정 시 가속 이득 감소 |

> 요약: 쇼어는 **다항 시간**, 그로버는 **제곱근 질의 복잡도**가 핵심이다.

#### 한줄 요약
- 쇼어는 공개키 난제를 다항 시간에 풀고, 그로버는 비정렬 탐색 질의를 제곱근 수준으로 줄인다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **논리 큐비트**: 오류 정정으로 안정화한 양자 계산 단위이다.
- **오류 완화**: 완전한 오류 정정 없이 반복 측정과 잡음 추정으로 결과 편향을 줄이는 기법이다.
- **양자내성암호(Post-Quantum Cryptography, PQC)**: 양자•고전 공격에 대응하도록 설계한 공개키 암호 체계이다.
- **보안 강도**: 알려진 최선의 공격에 필요한 계산량을 비트 수로 나타낸 값이다.
- **물리 큐비트**: 실제 장치에서 잡음의 영향을 받는 양자 정보 단위이다.
- **고전 알고리즘 총비용**: 같은 문제를 가장 좋은 고전 방법으로 푸는 데 필요한 전체 시간과 자원이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 논리 알고리즘만 보면 실현 가능성 과대평가 | **논리 큐비트**별 **물리 큐비트**와 오류 정정 비용 산정 | 실제 양자 자원 요구 파악 |
| 그로버 오라클 비용이 가속 이득 상쇄 | 오라클 회로와 **고전 알고리즘 총비용** 비교 | 양자 우위 판단 정확화 |
| 측정 잡음으로 결과 분산 증가 | 반복 측정과 **오류 완화** 적용 | 결과 신뢰도 향상 |
| 장기 암호 자산이 쇼어 위협에 노출 | 공개키 **PQC** 전환•대칭키 길이 조정 | 양자 공격 후 **보안 강도** 유지 |

#### 한줄 요약
- 장기 공개키 자산은 쇼어 위협에 대비해 인증서•서명부터 PQC로 전환한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **리베스트-샤미르-애들먼(Rivest-Shamir-Adleman, RSA)**: 소인수분해 난제 기반 공개키 암호이다.
- **디피-헬먼(Diffie-Hellman, DH)**: 이산 로그 난제 기반 키 교환 방식이다.
- **타원곡선 암호(Elliptic Curve Cryptography, ECC)**: 타원곡선 이산 로그 난제 기반 공개키 암호이다.
- **공개키 전환**: 쇼어 공격에 취약한 RSA•DH•ECC를 PQC로 교체하는 작업이다.
- **대칭키 길이 조정**: 그로버 탐색에 대응할 목표 보안 강도에 맞춰 키 비트 수를 늘리는 조치이다.
- **암호 전환 기준**: 쇼어•그로버가 각 암호 방식의 공격 비용에 미치는 영향으로 전환 조치를 정하는 기준이다.

</details>

- **암호 전환 기준**에 따라 **RSA**•**DH**•**ECC**는 **공개키 전환**으로 **PQC**를 적용하고, 그로버 공격 비용에 맞춰 **대칭키 길이 조정**을 수행한다.

#### 한줄 요약
- RSA•DH•ECC는 PQC로 전환하고, 대칭키는 그로버 비용을 반영해 필요한 키 길이를 다시 산정한다.
