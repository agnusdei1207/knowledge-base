## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **확률 분포(Probability Distribution)**: 확률 변수(Random Variable)가 취할 수 있는 모든 값과 그 값들이 발생할 확률적 가중치를 수학적으로 정의한 함수 관계.
- **확률 질량 함수(PMF, Probability Mass Function)**: 이산 확률 변수의 개별 값 $x$에 대해 $P(X=x)$의 확률을 직접 할당하는 함수.
- **확률 밀도 함수(PDF, Probability Density Function)**: 연속 확률 변수의 특정 구간 $[a, b]$ 내에 존재할 확률을 적분($\int_a^b f(x)dx$)으로 나타내는 함수.

</details>

- 정의/개념: 이산/연속 확률 변수의 발생 가능한 수치 공간에 확률 질량(PMF) 또는 밀도(PDF)를 배정하여 불확실성을 체계화하는 **확률 모델링 기초 체계**
- 배경/필요성: 트래픽 분석, 품질 관리, 머신러닝 모델링 시 대상 현상의 확률 메커니즘(독립 시행, 단위시간 도달, 중심극한정리)에 부합하는 분포 정의 필요

#### 한줄 요약

- 확률 변수의 값이나 구간에 확률 밀도를 배정하여 불확실성을 정량화하는 수학적 모델링

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **중심극한정리(CLT)**: 서로 독립이고 동일한 분포(IID)를 따르는 확률 변수들의 합이나 평균은 표본 크기 $N$이 커질수록 원래 분포에 무관하게 정규 분포에 수렴한다는 정리.
- **포아송 극한 정리(Poisson Limit Theorem)**: 이항 분포에서 $n \to \infty, p \to 0$이고 $np = \lambda$로 일정할 때 이항 분포가 포아송 분포로 근사 수렴한다는 성질.

</details>

![이항분포와 포아송분포의 사건 횟수별 확률 비교 차트](/study/diagrams/binomial-poisson-comparison.svg)

> 지정 모수의 계산값에서 사건 2회의 확률은 이항분포($n=4,p=0.5$) 0.375, 포아송분포($\lambda=2$) 0.271로 중심 높이가 다름

- 이산형(이항, 포아송)과 연속형(정규, 지수)으로 구분되는 **확률 변수 도메인 분기**
- 전 구간 확률의 총합(또는 적분값)이 반드시 1이 되는 **정규화 조건($\sum P(x) = 1, \int f(x)dx = 1$)** 준수
- 기댓값($E[X]$)과 분산($\text{Var}(X)$) 모수를 통한 **분포의 중심 위치와 산포도 정량화**

#### 한줄 요약

- 이산 변수는 PMF의 이산 합, 연속 변수는 PDF 곡선의 적분 면적으로 확률을 산출

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **CDF(Cumulative Distribution Function, 누적 분포 함수)**: 확률 변수가 $x$ 이하의 값을 가질 누적 확률 ($F(x) = P(X \le x)$).

</details>

```text
[ 확률 분포 모델 4대 구성 요소 ]
┌──────────────────────────────┐
│ 1. 표본 공간 (Sample Space Ω)│ ── 무작위 실험에서 발생 가능한 모든 결과 집합
├──────────────────────────────┤
│ 2. 확률 변수 (RV: X: Ω ──► R)│ ── 표본 공간의 결과를 실수값으로 사상(Mapping)
├──────────────────────────────┤
│ 3. 분포 함수 (PMF / PDF)     │ ── 각 값 또는 구간의 확률 밀도 할당
├──────────────────────────────┤
│ 4. 분포 모수 (Parameters θ)  │ ── 평균(μ), 분산(σ²), 시행수(n), 발생률(λ)
└──────────────────────────────┘
```

선의 의미: 표본 공간, 확률 변수 사상, PMF/PDF 함수 및 분포 모수 간의 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 표본 공간 (Ω) | 시행에서 발생 가능한 모든 기저 사건 집합 정의 |
| 확률 변수 (X) | 표본 공간의 사건을 **실수 수치값으로 사상(Mapping)** |
| 분포 함수 (PMF/PDF) | 값 또는 구간별 **발생 확률 및 확률 밀도 부여** |
| 분포 모수 ($\mu, \sigma^2, \lambda$) | 분포의 **중심 위치와 형태(퍼짐 정도) 결정** |
| 누적 분포 함수 (CDF) | 구간 확률 계산($P(a \le X \le b) = F(b) - F(a)$) 제공 |

#### 한줄 요약

- 표본 공간을 확률 변수로 사상하고, 분포 모수를 통해 PMF/PDF 및 CDF를 결정

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **과산포(Overdispersion)**: 포아송 분포의 가정인 평균과 분산의 일치($\lambda = \text{Var}(X)$)를 벗어나 실제 관측 데이터의 분산이 평균보다 훨씬 크게 나타나는 현상.

</details>

```text
현상 관측 및 데이터 수집
   │
   ▼
[ 1. 값의 유형 판별 ]
├─ 연속형 실수 데이터 ⟹ [ 2. 독립 오차 합산 여부 검증 (CLT) ⟹ 정규 분포(Normal) ]
└─ 이산형 정수 횟수 데이터
   │
   ▼
[ 3. 고정 시행 횟수 n 존재 여부 ]
├─ 고정 n회 시행 및 독립 성공 확률 p ⟹ [ 이항 분포 (Binomial) ]
└─ 고정 시간/공간 단위 내 사건 발생 수
   │
   ▼
[ 4. 단위 구간 평균 발생률 λ 고정 검증 ] ⟹ [ 포아송 분포 (Poisson) ]
   │
   ▼
[ 5. 적합도 검정 (Q-Q Plot, 카이제곱 검정) 및 최종 채택 ]
```

**동작 원리**

1. **데이터 유형 식별**: 연속형 측정값인지 이산형 카운트 데이터인지 분류
2. **정규 분포 판정**: 다수의 독립적인 오차가 누적된 연속형 데이터인 경우 정규 분포($N(\mu, \sigma^2)$) 모델링
3. **이항 분포 판정**: 고정된 $n$회 베르누이 시행에서 성공 횟수를 세는 경우 이항 분포($B(n, p)$) 모델링
4. **포아송 분포 판정**: 특정 시간/면적당 드물게 발생하는 사건의 건수인 경우 포아송 분포($\text{Poisson}(\lambda)$) 모델링
5. **적합도 검정**: Q-Q Plot 및 잔차 검정으로 가정의 유효성을 최종 검증

#### 한줄 요약

- 데이터 생성 과정과 시행 조건을 분석하여 정규•이항•포아송 후보를 선정하고 적합도를 검증

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **3대 핵심 확률 분포**:
  - 정규 분포: $X \sim N(\mu, \sigma^2)$, 연속형, 종 모양 대칭, 중심극한정리.
  - 이항 분포: $X \sim B(n, p)$, 이산형, $P(X=k) = \binom{n}{k} p^k (1-p)^{n-k}$.
  - 포아송 분포: $X \sim \text{Poisson}(\lambda)$, 이산형, $P(X=k) = \frac{\lambda^k e^{-\lambda}}{k!}$, $E[X]=\text{Var}(X)=\lambda$.

</details>

| 비교 항목 | 정규 분포 (Normal) | 이항 분포 (Binomial) | 포아송 분포 (Poisson) |
|:---|:---|:---|:---|
| 변수 유형 | **연속형 (Continuous)** | **이산형 (Discrete)** | **이산형 (Discrete)** |
| 확률 함수 | $f(x) = \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ | $P(X=k) = \binom{n}{k} p^k (1-p)^{n-k}$ | $P(X=k) = \frac{\lambda^k e^{-\lambda}}{k!}$ |
| 핵심 모수 | 평균($\mu$), 표준편차($\sigma$) | 시행 수($n$), 성공률($p$) | 단위 시간 평균 발생률($\lambda$) |
| 평균 / 분산 | $E[X]=\mu, \text{Var}(X)=\sigma^2$ | $E[X]=np, \text{Var}(X)=np(1-p)$ | $E[X]=\lambda, \text{Var}(X)=\lambda$ |
| 대표 사례 | 센서 잡음, 키/몸무게, 주가 수익률 | 동전 던지기, A/B 테스트 전환율 | 서버 초당 요청 수, 불량 발생 수 |

#### 한줄 요약

- 연속 오차 합은 정규, 고정 시행 성공 수는 이항, 단위 시간당 사건 발생은 포아송 분포를 적용

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Q-Q Plot(Quantile-Quantile Plot)**: 수집된 데이터의 분위수와 이론적 정규분포 분위수를 1:1 산점도로 대조하여 선형성을 통해 정규성을 시각적으로 검증하는 기법.
- **음이항 분포(Negative Binomial)**: 포아송 분포에서 과산포(분산 > 평균)가 발생할 때 분산 매개변수를 추가하여 과산포를 흡수하는 대체 분포.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 정규분포 가정 시 두꺼운 꼬리(Fat-Tail) 특성에 따른 극단값 과소평가 | **Q-Q Plot** 검증 및 스튜던트-t/파레토 분포 대체 | 극단값 및 이상치 리스크 반영 |
| 포아송 모델에서 트래픽 버스트로 인한 **과산포(Overdispersion)** | **음이항 분포(Negative Binomial)** 모델 전환 | 분산 팽창 수용 및 정확한 대기열 모델링 |
| 표본 크기 부족으로 인한 **이항분포 정규근사 오차** | $np \ge 5, n(1-p) \ge 5$ 조건 확인 및 정확 검정 | 소표본 이항 검정 정합성 확보 |
| 시계열에 따른 **분포 모수 표류(Parameter Drift)** | 슬라이딩 윈도우 기반 **이동 창 모수 갱신(Online MLE)** | 환경 변화에 따른 적응적 모형 유지 |

#### 한줄 요약

- Q-Q Plot으로 정규성을 검증하고, 과산포 데이터에는 음이항 분포를 적용하며, 정규 근사 조건을 확인한 뒤 이동창 모수 갱신으로 비정상성에 대응한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **데이터 기반 통계 모델링 원칙**: 데이터의 형태(이산/연속)뿐만 아니라 데이터가 생성된 물리적/확률적 메커니즘(IID, 독립 시행, 포아송 프로세스)을 근거로 최적의 분포를 채택.

</details>

- 연속 오차 합산은 **정규 분포**, 고정 시행 성공 횟수는 **이항 분포**, 단위 시간 발생 건수는 **포아송 분포** 선택

#### 한줄 요약

- 데이터 생성 메커니즘을 분석하여 정규•이항•포아송 분포를 선별하고 검정을 통한 적합성 확보
