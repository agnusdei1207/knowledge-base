## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **오토인코더(Autoencoder, AE)**: 고차원 입력을 저차원 잠재 공간(Latent Space)으로 압축하는 인코더(Encoder)와, 이를 다시 원본 형태로 재구성하는 디코더(Decoder)로 구성된 자기지도학습(Self-Supervised) 신경망.
- **재구성 손실(Reconstruction Loss)**: 원본 입력 $\mathbf{x}$와 디코더 출력 $\mathbf{\hat{x}}$ 간의 오차($\|\mathbf{x} - \mathbf{\hat{x}}\|^2$ 또는 Binary Cross-Entropy).
- **병목 구간(Bottleneck)**: 잠재 벡터의 차원을 입력보다 현저히 작게 제한하여 단순 항등 복사를 방지하고 핵심 매니폴드 특징을 강제 추출하는 구조.

</details>

- 정의/개념: 인코더를 통해 저차원 잠재 표현($\mathbf{z} = f_\theta(\mathbf{x})$)을 추출하고 디코더를 통해 복원($\mathbf{\hat{x}} = g_\phi(\mathbf{z})$)하며 재구성 손실을 최소화하는 **비지도/자기지도 표현 학습 모델**
- 배경/필요성: 고비용의 정답 레이블 없이 고차원 데이터의 **비선형 차원 축소, 노이즈 제거(Denoising), 정상 패턴 학습 기반 이상치 탐지(Anomaly Detection) 필수**

#### 한줄 요약

- 인코더의 잠재 공간 압축과 디코더의 재구성을 통해 레이블 없이 데이터의 핵심 표현을 학습

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **잠재 공간(Latent Space, $\mathbf{z}$)**: 데이터의 핵심 변동 요인이 압축되어 인코딩된 저차원 매니폴드 공간.
- **복원 오차 기반 이상 탐지(Anomaly Detection)**: 정상 데이터로만 학습된 AE는 비정상 입력 인입 시 재구성에 실패하여 높은 복원 오차($\|\mathbf{x}-\mathbf{\hat{x}}\|^2 > \tau$)를 발생시키는 원리를 활용.

</details>

- 레이블이 필요 없는 **자기지도 재구성 손실($L(\mathbf{x}, \mathbf{\hat{x}})$) 기반 역전파 학습**
- 저차원 병목(Bottleneck) 또는 희소성(Sparsity) 제약을 통한 **유의미한 저차원 특징 추출**
- VAE로의 확장을 통한 **확률적 잠재 분포 모델링 및 신규 데이터 생성(Generative Modeling)**

#### 한줄 요약

- 병목 계층을 통해 핵심 특징을 추출하고, 정상 데이터의 복원 오차를 기준으로 이상치를 탐지

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **오토인코더 3대 블록**:
  - 인코더 ($f_\theta$): $D$차원 입력을 $d$차원 잠재 벡터 $\mathbf{z}$로 압축 ($d \ll D$).
  - 병목 잠재 공간 ($\mathbf{z}$): 압축된 저차원 특징 벡터 보관.
  - 디코더 ($g_\phi$): $\mathbf{z}$로부터 $D$차원 원본 데이터 복원 $\mathbf{\hat{x}}$.

</details>

```text
[ 오토인코더 기본 아키텍처 및 손실 흐름도 ]
 원본 입력 x ──► [ 인코더 f_θ ] ──► [ 저차원 병목 z ] ──► [ 디코더 g_φ ] ──► 복원 출력 x_hat
       │                                                                        │
       └─────────────────────────► [ 재구성 손실 L(x, x_hat) ] ◄────────────────┘
                                                │
                                                ▼ (역전파)
                                    [ θ, φ 파라미터 동시 갱신 ]
```

선의 의미: 인코더 압축, 병목 잠재 벡터, 디코더 재구성 및 오차 역전파 파이프라인.

| 구성요소 | 책임 |
|:---|:---|
| 인코더 ($f_\theta$) | 고차원 입력을 **저차원 잠재 벡터($\mathbf{z}$)로 비선형 압축** |
| 병목 잠재 공간 | 정보 병목을 형성하여 **단순 복사를 방지하고 핵심 매니폴드 보존** |
| 디코더 ($g_\phi$) | 잠재 벡터로부터 **원본 차원의 입력 형태($\mathbf{\hat{x}}$)로 재구성** |
| 재구성 손실기 | MSE / BCE 손실을 계산하여 **인코더와 디코더 가중치 동시 최적화** |

#### 한줄 요약

- 인코더가 입력을 압축하고 디코더가 펼치며, 재구성 손실 함수가 원본과 복원본의 차이를 계산

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **ELBO(Evidence Lower Bound)**: VAE에서 데이터의 로그 우도를 최대화하기 위해 재구성 손실과 사전 분포와의 KL 발산의 차이를 최적화하는 목적 함수.

</details>

```text
입력 데이터 x 인입
   │
   ▼
[ 1. 인코더 신경망 통과 (잠재 벡터 z = f_θ(x) 추출) ]
   │
   ▼
[ 2. 디코더 신경망 통과 (복원 출력 x_hat = g_φ(z) 생성) ]
   │
   ▼
[ 3. 재구성 손실 계산: L_recon = ||x - x_hat||² ]
   │
   ▼
[ 4. 손실 역전파를 통한 인코더(θ) 및 디코더(φ) 파라미터 동시 갱신 ]
   │
   ▼
[ 5. 테스트 단계: 복원 오차 e = ||x_test - x_hat||² 산출 ]
├─ e ≤ 임계치(τ) ⟹ [ 정상 데이터 판정 ]
└─ e > 임계치(τ) ⟹ [ 이상치(Anomaly) 탐지 및 알람 ]
```

**동작 원리**

1. **인코딩 압축**: 입력 데이터를 점진적으로 축소된 히든 레이어를 거쳐 잠재 벡터 $\mathbf{z}$로 압축
2. **디코딩 복원**: 잠재 벡터를 대칭적인 확장 레이어를 거쳐 원본과 동일한 차원으로 복원
3. **손실 역전파**: 원본과 복원값의 차이를 MSE로 계산하여 엔드투엔드 파라미터 갱신
4. **이상치 판정**: 훈련 완료 후 입력된 테스트 샘플의 복원 오차가 임계치 $\tau$를 넘으면 이상치로 분류

#### 한줄 요약

- 인코더로 압축 후 디코더로 복원하며, 훈련 후 높은 재구성 오차를 보이는 데이터를 이상치로 탐지

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **오토인코더 3대 주요 변형**:
  - 기본 AE: 결정론적(Deterministic) 점 매핑, 차원 축소/이상치 탐지.
  - DAE (Denoising AE): 노이즈가 주입된 $\mathbf{\tilde{x}}$에서 깨끗한 $\mathbf{x}$ 복원, 강건성 향상.
  - VAE (Variational AE): 확률분포($\mu, \sigma$) 매핑 + KL 발산 정규화, 신규 표본 생성.

</details>

| 비교 항목 | 기본 오토인코더 (Vanilla) | 디노이징 오토인코더 (DAE) | 변분 오토인코더 (VAE) |
|:---|:---|:---|:---|
| 잠재 공간 형태 | **결정론적 고정 벡터 ($\mathbf{z}$)** | 결정론적 고정 벡터 ($\mathbf{z}$) | **확률분포 파라미터 ($\mu, \sigma$)** |
| 입력 데이터 | 깨끗한 원본 데이터 ($\mathbf{x}$) | **가우시안/마스킹 노이즈 주입 ($\mathbf{\tilde{x}}$)** | 원본 데이터 ($\mathbf{x}$) |
| 손실 함수 | $\text{MSE}(\mathbf{x}, \mathbf{\hat{x}})$ | $\text{MSE}(\mathbf{x}, g(f(\mathbf{\tilde{x}})))$ | **Reconstruction Loss + KL Divergence** |
| 주요 적용처 | **비선형 차원 축소, 이상 탐지** | 노이즈 제거, 강건한 특성 추출 | **이미지/음성 생성, 잠재 공간 보간** |
| 한계 및 위험 | 병목 과대 시 단순 복사 과적합 | 노이즈 수준($\sigma$) 튜닝 민감성 | 복원 결과의 블러링(Blurriness), 사후 붕괴 |

#### 한줄 요약

- 차원 축소와 이상치 탐지는 기본 AE, 강건성 확보는 DAE, 신규 데이터 생성은 VAE를 적용

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **사후 붕괴(Posterior Collapse)**: VAE 학습 시 디코더가 강력하여 잠재 변수 $\mathbf{z}$를 무시하고($q(\mathbf{z}|\mathbf{x}) \approx p(\mathbf{z})$) 자체적으로 출력을 생성하여 잠재 표현이 붕괴되는 현상.
- **동적 임계치(Dynamic Thresholding)**: 정상 데이터의 복원 오차 분포에 대해 극단값 이론(EVT) 또는 분위수($99\%$)를 적용하여 동적으로 이상 탐지 임계치를 산정하는 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 병목 차원이 커서 입력을 **단순 복사(Identity Mapping)** | 잠재 차원 축소, L1 **희소 규제(Sparse AE)**, 노이즈 주입 | 유의미한 매니폴드 특징 추출 강제 |
| 제조 공정 변화로 정상 오차가 상승하여 **오탐(False Alarm) 급증** | 정상 데이터 복원오차 분포 기반 **동적 임계치(EVT) 재보정** | 공정 환경 변화에 적응적 이상 탐지 |
| VAE에서 디코더가 잠재 변수를 무시하는 **사후 붕괴(Posterior Collapse)** | **KL Annealing ($\beta$ 스케줄링)** 및 Free Bits 기법 | 잠재 공간 정보량 보존 및 표현력 회복 |
| 고차원 복원 오차의 **이상 원인 파악 불가(설명력 부재)** | 피처별 잔차 기여도 분해 및 **히트맵 시각화** | 이상 발생 센서/부품 즉각 특정 |

#### 한줄 요약

- **희소 규제 단순복사 방지·동적 임계치 오탐 차단·KL Annealing 사후붕괴 방지·잔차 히트맵 XAI**

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **산업용 AI 활용 표준**: 스마트 팩토리 설비 예지보전(PdM) 및 금융 FDS에서 정상 데이터만을 학습한 Autoencoder 복원 오차 기반 비지도 이상 탐지는 지도학습 라벨 부족을 해결하는 핵심 솔루션으로 정착.

</details>

- 차원 축소/이상치 탐지는 **기본/디노이징 AE**, 잠재 분포 모델링/생성은 **VAE(Variational AE)** 선택

#### 한줄 요약

- 잡음 제거와 이상치 탐지는 디노이징 AE, 확률분포 기반 신규 표본 생성은 VAE를 선택
