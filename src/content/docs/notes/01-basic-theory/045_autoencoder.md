## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **오토인코더(Autoencoder)**: 입력을 압축하고 다시 복원하며 데이터의 핵심 구조를 학습하는 신경망이다.
- **레이블**: 지도학습에서 각 표본에 부여하는 정답값이다.
- **표현 학습(Representation Learning)**: 원시 입력을 과업에 유용한 특징 벡터로 변환하는 방법을 학습하는 과정이다.
- **지도학습(Supervised Learning)**: 입력과 정답 레이블의 관계를 학습하는 방식이다.

</details>

- 정의/개념: 인코더가 입력을 잠재 표현으로 압축하고 디코더가 복원하며 **표현 학습**을 수행하는 **오토인코더**이다.
- 배경/필요성: 정답 레이블 수집 비용이 높은 환경에서는 지도 학습만으로 유용한 특징 표현을 학습하기 어렵다.

#### 한줄 요약

- 인코더가 입력을 저차원 잠재 표현으로 압축하고 디코더가 재구성하며, 재구성 손실을 최소화하는 과정에서 레이블 없이 데이터 구조를 학습한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **자기지도학습**: 입력 자체에서 학습 목표를 만들어 표현을 학습하는 방식이다.
- **잠재 벡터**: 입력의 핵심 정보를 병목이나 규제 조건 아래 변환한 내부 표현이다.
- **재구성 손실**: 원본 입력과 복원 결과 사이의 차이다.
- **병목(Bottleneck)**: 통과하는 정보량을 제한해 핵심 표현을 추리도록 만든 좁은 잠재 계층이다.

</details>

- 입력 복원을 목표로 하는 **자기지도학습** 표현 학습이 핵심이다.
- **병목**과 규제 조건으로 단순 복사를 억제해 핵심 특징을 추출한다.
- **재구성 손실** 최소화로 인코더•디코더를 함께 학습한다.
- **잠재 벡터**에 입력의 핵심 정보를 압축해 복원에 사용한다.

#### 한줄 요약

- 병목 계층은 통로를 좁혀 핵심 특징만 통과시키지만, 지나치게 넓으면 입력을 그대로 복사할 수 있다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **인코더**: 입력을 잠재 벡터로 압축하는 신경망이다.
- **디코더**: 잠재 벡터에서 입력 형태를 복원하는 신경망이다.
- **손실 기울기**: 파라미터 변화에 따른 재구성 손실의 변화 방향과 크기이다.
- **잠재 공간(Latent Space)**: 인코더가 입력의 핵심 정보를 압축해 배치한 벡터 공간이다.
- **복원값**: 디코더가 잠재 벡터에서 재구성한 입력 형태의 출력이다.

</details>

```text
[오토인코더]
      |
      +-- [인코더]
      +-- [잠재 공간•병목]
      +-- [디코더]
      `-- [재구성 손실 함수]
```

선의 의미: 압축•복원 모델과 학습 기준의 정적 구성을 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 인코더 | 입력을 **잠재 벡터**로 변환 |
| 잠재 공간•병목 | **잠재 벡터** 보관과 정보량 제한 |
| 디코더 | 잠재 벡터에서 입력 형태의 **복원값** 산출 |
| 재구성 손실 함수 | 원본•복원값 차이와 **손실 기울기** 산출 |

#### 한줄 요약
- 인코더가 입력을 압축하고 디코더가 펼치며, 재구성 손실 함수가 원본과 복원본의 차이를 잰다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **역전파**: 출력 오차를 뒤로 전달해 각 파라미터의 손실 기울기를 계산하는 방법이다.
- **종료 조건**: 손실 개선이나 반복 횟수 기준으로 학습을 멈추는 조건이다.
- **잠재 기울기**: 디코더에서 잠재 벡터를 거쳐 인코더로 전달되는 손실 변화율이다.
- **잠재 벡터 압축**: 인코더로 입력을 저차원 잠재 표현으로 바꾸는 단계이다.
- **입력 형태 복원**: 디코더로 잠재 벡터를 원본과 같은 형태의 출력으로 재구성하는 단계이다.
- **재구성 손실 계산**: 원본 입력과 복원값의 차이를 손실값으로 구하는 단계이다.
- **역전파•파라미터 갱신**: 재구성 손실의 기울기를 인코더와 디코더 파라미터에 반영하는 단계이다.

</details>

```text
[원본 입력]
      |
      v
+----------------------------------+
| 종료 조건을 충족하기 전          |
|                                  |
|  1. 잠재 벡터 압축               |
|            |                     |
|            v                     |
|  2. 입력 형태 복원               |
|            |                     |
|            v                     |
|  3. 재구성 손실 계산             |
|            |                     |
|            v                     |
|  4. 역전파•파라미터 갱신         |
|            |                     |
|            `---------- 반복 -----|
+----------------------------------+
      |
      v
[학습된 잠재 표현]
```

### 동작 원리

- **1. 잠재 벡터 압축**: 인코더로 저차원 표현을 생성한다.
- **2. 입력 형태 복원**: 디코더로 원본 형태를 재구성한다.
- **3. 재구성 손실 계산**: 원본과 복원값의 차이를 산출한다.
- **4. 역전파•파라미터 갱신**: **잠재 기울기**를 거쳐 두 신경망에 손실 기울기를 반영한다.

#### 한줄 요약

- 좁은 병목을 통과한 압축 쪽지를 디코더가 복원하고, 틀린 부분의 화살표가 거꾸로 돌아가 두 신경망을 함께 고친다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **디노이징 오토인코더**: 잡음이 섞인 입력에서 원본을 복원하도록 학습하는 모델이다.
- **변분 오토인코더(Variational Autoencoder, VAE)**: 잠재 확률분포를 학습해 새로운 표본을 생성하는 오토인코더이다.
- **잠재 붕괴**: VAE의 디코더가 잠재 표현을 무시해 잠재 변수가 입력 정보를 거의 담지 않는 현상이다.
- **기본 오토인코더**: 입력을 결정적 잠재 벡터로 압축하고 같은 입력을 복원하는 모델이다.
- **강건한 특징**: 입력에 잡음이나 결측이 있어도 유지되는 안정적인 표현이다.
- **신규 표본 생성**: 학습한 데이터 분포를 따라 새로운 데이터를 만드는 작업이다.
- **잠재 분포**: VAE가 입력별 평균•분산으로 나타내고 표본을 추출하는 확률분포이다.
- **단순 복사**: 과대 모델이 유용한 구조를 압축하지 않고 입력을 그대로 출력으로 옮기는 학습 결과이다.
- **잡음 수준**: 디노이징 학습 입력에 추가하는 손상이나 무작위 변동의 크기이다.
- **잡음**: 원본 입력에 섞여 관측값을 무작위로 바꾸는 변동이다.
- **결측**: 입력의 일부 값이 관측되지 않아 비어 있는 상태이다.
- **결정적 압축•복원**: 같은 입력에 항상 같은 잠재 벡터와 복원값을 만드는 기본 오토인코더의 처리 방식이다.

</details>

| 오토인코더 계열 | 기본 오토인코더 | 디노이징 오토인코더 | VAE |
|:---|:---|:---|:---|
| 적용 기준 | **레이블** 없는 고차원 입력 | 입력에 **잡음**•**결측** 혼입 | 학습 분포의 **신규 표본 생성** |
| 핵심 특징 | 원본 입력의 **결정적 압축•복원** | 잡음 주입 후 **강건한 특징** 학습 | **잠재 분포** 학습•신규 표본 생성 |
| 한계 | 과대 모델의 **단순 복사**로 특징 추출 약화 | **잡음 수준** 설정에 따른 복원 성능 민감성 | 복원 흐림•**잠재 붕괴** |

> 요약: 잡음은 복사 억제, **VAE**는 표본을 생성한다.

#### 한줄 요약

- 얼룩 사진을 깨끗이 되살리면 디노이징형이고, 잠재 지도에서 새 좌표를 뽑아 사진을 만들면 VAE다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **희소 규제**: 일부 잠재 변수만 활성화하도록 제약하는 방법이다.
- **복원오차 임계값**: 정상 데이터의 복원오차 분포를 기준으로 이상 여부를 나누는 경계값이다.
- **쿨백-라이블러 가중치(Kullback-Leibler Weight, KL Weight)**: 재구성 손실과 KL 발산의 학습 비율이다.
- **쿨백-라이블러 발산(Kullback-Leibler Divergence, KL Divergence)**: 잠재 분포가 기준 분포와 다른 정도이다.
- **임계값 재보정**: 운영 데이터의 복원오차 분포에 맞춰 이상 판정 경계를 다시 정하는 작업이다.
- **오탐(False Positive)**: 정상 입력을 이상으로 잘못 판정한 결과이다.
- **이상 원인**: 복원오차가 커져 이상 판정을 일으킨 입력 특징이나 잠재 방향이다.

- **KL 가중치(KL Divergence Weight, $\beta$)**: $\beta$-VAE에서 복원 손실과 잠재 공간 정규화(KL 발산) 손실 간의 균형을 조절하여 잠재 표현의 얽힘 해제(Disentanglement)를 유도하는 하이퍼파라미터.
</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 입력의 **단순 복사**로 표현 학습 실패 | 병목 축소•잡음 주입•**희소 규제** | **표현 학습** 강화 |
| 정상 데이터 변화로 **오탐** 증가 | 주기적 재학습과 **임계값 재보정** | **복원오차 임계값** 안정화 |
| VAE의 **잠재 붕괴** | **KL 가중치** 점진 증가•디코더 용량 조정 | 잠재 벡터의 정보량 회복 |
| 복원오차만으로 **이상 원인** 설명 부족 | 특징별 오차와 **잠재 공간** 함께 분석 | 이상 원인 추적 지원 |

#### 한줄 요약

- 정상 오차 계기판의 분포가 움직이면 경보선을 다시 긋고, VAE의 빈 잠재 서랍은 KL 가중치를 서서히 올려 채운다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **잡음 복원**: 손상되거나 잡음이 섞인 입력에서 원본에 가까운 값을 되찾는 작업이다.
- **선택 기준**: 손상 입력 복원과 확률분포 기반 생성 중 목표 과업을 구분하는 기준이다.

</details>

- **선택 기준**에 따라 잡음 복원은 디노이징형, 신규 표본 생성은 **VAE**를 선택한다.

#### 한줄 요약

- 잡음 제거는 디노이징 오토인코더, 같은 분포의 새 표본 생성은 VAE를 선택한다.
