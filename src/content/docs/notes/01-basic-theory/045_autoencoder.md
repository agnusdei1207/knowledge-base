## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **인코더와 디코더(Encoder & Decoder)**: 입력을 저차원 병목 벡터($\mathbf{z}$)로 압축하는 인코더와 이를 다시 원본 차원으로 복원하는 디코더 쌍.
- **매니폴드 특징 및 이상치 탐지(Manifold & Anomaly Detection)**: 정상 데이터의 고유 분포만을 학습하여 정상과 다른 패턴 유입 시 복원 오차가 폭증하는 원리로 이상치를 식별하는 기법.

</details>

- 정의/개념: 고차원 입력을 저차원 잠재 공간으로 압축하는 **인코더** 및 이를 원본으로 복원하는 **디코더** 기반의 비지도 특징 표현 학습 신경망
- 배경/필요성: 라벨이 부재한 대규모 고차원 데이터에서 지도학습 적용이 불가능하여 발생하는 **비지도 표현 학습 및 이상치 탐지 한계**

#### 한줄 요약

- 정답을 입력 자신으로 삼는 대신 병목의 폭이 곧 학습 압력이 되므로, 병목이 넓으면 특징 대신 복사를 배운다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **잠재 공간(Latent Space, $\mathbf{z}$)**: 데이터의 핵심 변동 요인이 압축되어 인코딩된 저차원 매니폴드 공간.
- **복원 오차 기반 이상 탐지(Anomaly Detection)**: 정상 데이터로만 학습된 AE는 비정상 입력 인입 시 재구성에 실패하여 높은 복원 오차($\|\mathbf{x}-\mathbf{\hat{x}}\|^2 > \tau$)를 발생시키는 원리를 활용.

</details>

- 레이블 없는 **자기지도 재구성 손실 기반 학습**
- 병목 구조를 통한 **유의미한 저차원 특징 추출**
- VAE 확장을 통한 **확률적 잠재 분포 모델링 및 데이터 생성**

#### 한줄 요약

- 병목 계층을 통해 핵심 특징을 추출하고, 정상 데이터의 복원 오차를 기준으로 이상치를 탐지

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **인코더(Encoder, $f_\theta$)**: 고차원 입력 데이터를 저차원 잠재 표현으로 압축 매핑하는 신경망.
- **병목 잠재 공간(Bottleneck Latent Space, $\mathbf{z}$)**: 데이터의 핵심 요약 정보를 보관하는 저차원 매니폴드 벡터.
- **디코더(Decoder, $g_\phi$)**: 저차원 잠재 벡터로부터 원본 차원의 데이터를 재구성하는 신경망.

</details>

```text
[오토인코더(Autoencoder) 구조]
  │
  ├─ [인코더 모듈] (특징 압축)
  │     ├─ 고차원 입력단 (원본 데이터 x 수신)
  │     └─ 차원 압축 신경망 (f_θ: 저차원 특징 매핑)
  │
  ├─ [병목 잠재 공간] (핵심 매니폴드 표현)
  │     ├─ 잠재 벡터 z (압축된 핵심 정보 벡터)
  │     └─ 정보 병목 (단순 복사 방지 차원 제약)
  │
  ├─ [디코더 모듈] (원본 재구성)
  │     ├─ 차원 복원 신경망 (g_φ: 원본 차원 확장 매핑)
  │     └─ 재구성 출력단 (복원 데이터 x_hat 생성)
  │
  └─ [손실 최적화부] (재구성 오차 제어)
        ├─ 재구성 손실 연산기 (‖x - x_hat‖² 오차 측정)
        └─ 역전파 최적화기 (인코더·디코더 가중치 동시 갱신)
```

- 선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 인코더 ($f_\theta$) | 입력을 **저차원 잠재 벡터**로 압축 |
| 병목 잠재 공간 | 정보 병목으로 **핵심 매니폴드** 보존 |
| 디코더 ($g_\phi$) | 잠재 벡터를 **원본 차원**으로 재구성 |
| 재구성 손실 | 원본·복원본 차이로 **가중치 최적화** 유도 |

#### 한줄 요약

- 인코더가 입력을 압축하고 디코더가 펼치며, 재구성 손실 함수가 원본과 복원본의 차이를 계산

## Ⅳ. 흐름도

```text
입력 데이터 x 인입
   │
   ▼
[ 1. 인코더 신경망 통과 ] : z = f_θ(x) 잠재 벡터 추출
   │
   ▼
[ 2. 디코더 신경망 통과 ] : x_hat = g_φ(z) 복원 출력 생성
   │
   ▼
[ 3. 재구성 손실 계산 ] : L_recon = ||x - x_hat||²
   │
   ▼
[ 4. 손실 역전파 및 가중치 갱신 ] : θ 및 φ 동시 최적화
```

**동작 원리**

1. **인코더 신경망 통과**: 입력을 잠재 벡터 $\mathbf{z}$로 압축
2. **디코더 신경망 통과**: 잠재 벡터를 원본 차원 형태 $\mathbf{\hat{x}}$로 복원
3. **재구성 손실 계산**: 원본과 복원값의 차이를 손실로 산출
4. **손실 역전파 및 가중치 갱신**: 인코더와 디코더 파라미터 동시 갱신

#### 한줄 요약

- 인코더·디코더의 재구성 손실을 역전파해 압축 표현을 학습

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **기본 오토인코더(Vanilla Autoencoder)**: 입력을 결정론적 고정 잠재 벡터로 매핑하는 구조.
- **디노이징 오토인코더(Denoising Autoencoder, DAE)**: 인위적 잡음이 주입된 입력으로부터 원본을 복원하여 강건성을 확보하는 구조.
- **변분 오토인코더(Variational Autoencoder, VAE)**: 잠재 공간을 확률분포로 모델링하여 신규 데이터를 생성할 수 있는 생성 모델.

</details>

| 오토인코더 유형 | 기본 오토인코더 | DAE | VAE |
|:---|:---|:---|:---|
| 적용 기준 | **비선형 차원 축소·이상 탐지** | 잡음 제거·강건한 특징 추출 | **확률적 신규 데이터 생성** |
| 핵심 특징 | **결정론적 잠재 벡터** 학습 | **잡음 입력에서 원본 복원** | **잠재 확률분포** 모델링 |
| 한계 | 병목 과대 시 단순 복사 과적합 | 노이즈 강도 하이퍼파라미터 민감 | 복원 블러링 및 사후 붕괴 위험 |

#### 한줄 요약

- 차원 축소와 이상치 탐지는 기본 AE, 강건성 확보는 DAE, 신규 데이터 생성은 VAE를 적용

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **사후 붕괴(Posterior Collapse)**: VAE 학습 시 디코더가 강력하여 잠재 변수 $\mathbf{z}$를 무시하고($q(\mathbf{z}|\mathbf{x}) \approx p(\mathbf{z})$) 자체적으로 출력을 생성하여 잠재 표현이 붕괴되는 현상.
- **동적 임계치(Dynamic Thresholding)**: 정상 데이터의 복원 오차 분포에 대해 극단값 이론(EVT) 또는 분위수($99\%$)를 적용하여 동적으로 이상 탐지 임계치를 산정하는 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 병목 차원이 커서 입력을 **단순 복사** | 잠재 차원 축소와 **희소 규제** 적용 | 핵심 매니폴드 특징 추출 |
| 공정 변화로 정상 오차가 상승해 **오탐 증가** | 복원 오차 기반 **동적 임계치** 재보정 | 환경 변화에 따른 오탐 완화 |
| VAE 디코더가 잠재 변수를 무시하는 **사후 붕괴** | **KL 어닐링**과 Free Bits 적용 | 잠재 공간 정보량 보존 |
| 고차원 복원 오차로 이상 원인 식별 곤란 | 피처별 잔차의 **히트맵** 시각화 | 이상 센서·부품 위치 식별 |

#### 한줄 요약

- 희소 규제로 단순 복사를 방지하고, 동적 임계치로 이상 탐지 오탐을 차단하며, KL Annealing으로 사후 붕괴를 막고, 잔차 히트맵으로 이상 위치를 시각화한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **마스크드 오토인코더(Masked Autoencoder, MAE)**: 입력 이미지 패치의 높은 비율(75% 이상)을 마스킹하고 소수의 가시 패치로부터 원본을 복원하도록 유도하는 대규모 비전 자기지도 사전학습 아키텍처.
- **벡터 양자화 변분 오토인코더(Vector Quantized Variational Autoencoder, VQ-VAE)**: 연속 잠재 공간 대신 이산 코드북 벡터로 양자화 매핑하여 사후 붕괴를 방지하고 잠재 생성 모델의 기반을 제공하는 생성 신경망.
- **극단값 이론(Extreme Value Theory, EVT)**: 확률분포의 극단 꼬리 데이터를 모델링하여 고차원 복원 오차 분포로부터 비지도 이상 탐지 동적 임계치를 수학적으로 도출하는 통계 기법.

</details>

- 전통적 비지도 차원 축소와 복원 오차 기반 탐지를 넘어, 대규모 비전 파운데이션 모델의 사전학습 엔진인 마스크드 오토인코더(MAE) 및 잠재 확산 모델의 지각 압축을 담당하는 VQ-VAE 아키텍처로 확장 진화 추세
- 실무에서는 스마트 팩토리 예지보전 시 잠재 병목 과대화에 따른 단순 복사 현상을 방지해야 하며, 극단값 이론(EVT) 기반 동적 임계치 보정으로 개념 표류에 적응하는 신뢰성 있는 아키텍처 결단 필요

#### 한줄 요약

- MAE 및 VQ-VAE 등 파운데이션 모델 표현 학습으로 확장되는 오토인코더 원리를 정립하고, 단순 복사 방지와 동적 임계치 설계를 결합한 아키텍처 결단이 필수적이다.
