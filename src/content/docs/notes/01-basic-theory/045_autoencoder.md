## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **오토인코더**: 입력을 압축하고 다시 복원하며 데이터의 핵심 구조를 학습하는 신경망
- **레이블**: 지도학습에서 각 표본에 부여하는 정답값
- **표현 학습(Representation Learning)**: 원시 입력을 과업에 유용한 특징 벡터로 변환하는 방법을 학습하는 과정
- **지도학습(Supervised Learning)**: 입력과 정답 레이블의 관계를 학습하는 방식

</details>

- 정의/개념: 입력을 **압축•복원**해 데이터 구조를 학습하는 신경망
- 배경/필요성: 레이블 부족으로 **지도학습의 표현 학습 제약**

#### 한줄 요약

- 인코더가 사진을 작은 암호표로 접고 디코더가 다시 펴며, 원본과의 차이를 줄이는 동안 별도 이름표 없이 구조를 익힌다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **자기지도학습**: 입력 자체에서 학습 목표를 만들어 표현을 학습하는 방식
- **잠재 벡터**: 입력의 핵심 정보를 저차원 값으로 압축한 표현
- **재구성 손실**: 원본 입력과 복원 결과 사이의 차이
- **병목(Bottleneck)**: 통과하는 정보량을 제한해 핵심 표현을 추리도록 만든 좁은 잠재 계층

</details>

- 입력 복원을 학습 목표로 하는 **자기지도** 표현 학습
- 입력을 **저차원 잠재 벡터**로 압축해 핵심 특징 추출
- **복원 오차 최소화**를 통한 인코더•디코더 공동 학습

#### 한줄 요약

- 병목 계층은 통로를 좁혀 핵심 특징만 통과시키지만, 지나치게 넓으면 입력을 그대로 복사할 수 있다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **인코더**: 입력을 잠재 벡터로 압축하는 신경망
- **병목**: 통과할 수 있는 정보량을 제한해 핵심 표현을 추리게 하는 지점
- **디코더**: 잠재 벡터에서 입력 형태를 복원하는 신경망
- **재구성 손실**: 원본과 복원값의 차이를 계산해 인코더•디코더 학습에 사용하는 손실
- **손실 기울기**: 파라미터 변화에 따른 재구성 손실의 변화 방향과 크기

</details>

```mermaid
block
    columns 3
    E["인코더"]
    Z["잠재 공간•병목"]
    D["디코더"]
    space
    L["재구성 손실 함수"]
    space
    E --- Z
    Z --- D
    D --- L
```

| 구성요소 | 책임 |
|:---|:---|
| 인코더 | 입력을 **잠재 벡터**로 압축 |
| 잠재 공간•병목 | 입력의 **핵심 표현** 보관과 정보량 제한 |
| 디코더 | 잠재 벡터에서 입력 형태의 **복원값** 산출 |
| 재구성 손실 함수 | 원본•복원값 차이와 **손실 기울기** 산출 |

#### 한줄 요약
- 깔때기 앞의 인코더가 입력을 압축하고 뒤의 디코더가 펼치며, 재구성 손실 자가 원본과 복원본의 차이를 잰다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **역전파**: 출력 오차를 뒤로 전달해 각 파라미터의 손실 기울기를 계산하는 방법
- **손실 기울기**: 파라미터 변화가 손실에 미치는 방향과 크기
- **종료 조건**: 손실 개선이나 반복 횟수 기준으로 학습을 멈추는 조건
- **잠재 기울기**: 디코더에서 잠재 벡터를 거쳐 인코더로 전달되는 손실 변화율

</details>

```mermaid
sequenceDiagram
    participant I as 입력
    participant E as 인코더
    participant D as 디코더
    participant L as 재구성 손실 함수
    loop 종료 조건 충족 전
        I->>E: 원본 입력
        E->>D: 1. 잠재 벡터
        D->>L: 2. 복원값•원본값 전달
        L-->>D: 3. 재구성 손실 기울기
        D-->>E: 4. 잠재 기울기
    end
```

### 동작 원리

- **1. 잠재 벡터**: 원본 입력을 저차원 표현으로 압축
- **2. 복원값•원본값 전달**: 잠재 벡터의 복원 결과 비교
- **3. 재구성 손실 기울기**: 원본•복원 차이를 디코더에 전달
- **4. 잠재 기울기**: 인코더까지 오차 신호 전달

#### 한줄 요약

- 좁은 병목을 통과한 압축 쪽지를 디코더가 복원하고, 틀린 부분의 화살표가 거꾸로 돌아가 두 신경망을 함께 고친다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **디노이징 오토인코더**: 잡음이 섞인 입력에서 원본을 복원하도록 학습하는 모델
- **VAE**: 잠재 확률분포를 학습하고 그 분포에서 새로운 표본을 생성하는 오토인코더
- **잠재 붕괴**: VAE의 디코더가 잠재 표현을 무시해 잠재 변수가 입력 정보를 거의 담지 않는 현상
- **기본 오토인코더**: 입력을 결정적 잠재 벡터로 압축하고 같은 입력을 복원하는 모델
- **강건한 특징**: 입력에 잡음이나 결측이 있어도 유지되는 안정적인 표현

</details>

| 오토인코더 계열 | 기본 오토인코더 | 디노이징 오토인코더 | VAE |
|:---|:---|:---|:---|
| 적용 기준 | **레이블** 없는 고차원 입력 | 입력에 **잡음•결측** 혼입 | 학습 분포 기반 **신규 표본 생성 요구** |
| 핵심 특징 | 원본 입력의 **결정적 압축•복원** | 잡음 주입 후 **강건한 특징** 학습 | **확률적 잠재 분포** 학습•신규 표본 생성 |
| 한계 | 과대 모델의 **단순 복사•특징 추출 약화** | **잡음 수준** 설정에 따른 복원 성능 민감성 | 복원 흐림•**잠재 붕괴** |

> 요약: 잡음은 복사 억제, **VAE**는 표본 생성

#### 한줄 요약

- 얼룩 사진을 깨끗이 되살리면 디노이징형이고, 잠재 지도에서 새 좌표를 뽑아 사진을 만들면 VAE다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **희소 규제**: 일부 잠재 변수만 활성화하도록 제약하는 방법
- **복원오차 임계값**: 정상 데이터의 복원오차 분포를 기준으로 이상 여부를 나누는 경계값
- **KL 가중치**: 재구성 손실과 KL 발산이 전체 학습에 미치는 비율
- **KL 발산(KL Divergence)**: VAE의 잠재 분포가 기준 분포와 다른 정도를 재는 값
- **임계값 재보정**: 운영 데이터의 복원오차 분포에 맞춰 이상 판정 경계를 다시 정하는 작업
- **잠재 공간(Latent Space)**: 인코더가 입력의 핵심 정보를 압축해 배치한 벡터 공간

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 입력을 그대로 복사해 **표현력이 낮음** | 병목 축소•잡음 주입•**희소 규제** | **핵심 특징 학습** 강화 |
| 정상 데이터 변화로 **오탐 증가** | 주기적 재학습과 **임계값 재보정** | **이상 판정 기준** 안정화 |
| VAE 잠재 변수를 **디코더가 무시** | **KL 가중치** 점진 증가•디코더 용량 조정 | **잠재 붕괴** 완화 |
| 복원오차만으로 **이상 원인 설명 부족** | 특징별 오차와 **잠재 공간** 함께 분석 | **이상 원인 추적성** 향상 |

#### 한줄 요약

- 정상 오차 계기판의 분포가 움직이면 경보선을 다시 긋고, VAE의 빈 잠재 서랍은 KL 가중치를 서서히 올려 채운다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **잡음 복원**: 손상되거나 잡음이 섞인 입력에서 원본에 가까운 값을 되찾는 작업
- **신규 표본 생성**: 학습한 데이터 분포를 따라 새로운 데이터를 만드는 작업
- **디노이징 오토인코더•VAE**: 잡음 입력에서 원본을 복원하는 모델과 잠재 확률분포에서 새 표본을 생성하는 모델

</details>

- 잡음 복원은 **디노이징형**, 신규 표본 생성은 **VAE** 선택

#### 한줄 요약

- 얼룩을 지운 원본이 필요하면 디노이징형을, 같은 분포의 새 표본이 필요하면 VAE를 선택한다.
