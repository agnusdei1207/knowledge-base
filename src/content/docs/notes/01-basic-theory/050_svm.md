## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **서포트 벡터(Support Vector)**: 결정 경계(초평면)와 가장 가까운 거리에 위치하여 마진을 결정하는 핵심 데이터 표본.
- **마진(Margin)**: 분리 초평면과 서포트 벡터 사이의 최단 수직 거리($2/\|w\|$).
- **구조적 위험 최소화(Structural Risk Minimization, SRM)**: 훈련 오차 최소화와 함께 모델 복잡도를 통제하여 일반화 오차 상한을 최소화하는 원리.

</details>

- 정의/개념: 클래스 간의 최단 거리 표본인 **서포트 벡터 기준 마진 최대화**를 기반으로 최적 분리 초평면을 도출하는 선형 및 비선형 지도학습 모델
- 배경/필요성: 경험적 위험 최소화 모델로는 **과적합 통제 및 일반화 오차 상한 보장 불가**

#### 한줄 요약

- 서포트 벡터 사이의 마진을 최대로 벌리는 분리 초평면을 찾아 일반화 오차를 최소화하는 모델

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **커널 트릭(Kernel Trick)**: 저차원 데이터를 고차원 특징 공간으로 명시적 변환 없이 내적 연산만으로 비선형 분리 초평면을 계산하는 기법.
- **슬랙 변수(Slack Variable, $\xi$)**: 소프트 마진에서 데이터의 마진 침범 및 오분류를 허용하기 위해 도입된 오차 변수.

</details>

- 클래스 간 **마진(Margin) 최대화** 기반 높은 일반화 성능 및 과적합 억제
- **커널 트릭(Kernel Trick)** 기반 고차원 비선형 결정 경계의 효율적 매핑
- 결정 경계가 전체 데이터가 아닌 소수의 **서포트 벡터** 기준 결정되는 견고성

#### 한줄 요약

- 마진 최대화로 일반화 능력을 극대화하고, 커널 트릭으로 고차원 비선형 공간을 효율적으로 분류

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **초평면(Hyperplane)**: $d$차원 공간을 양분하는 $d-1$차원의 아핀 부분공간($w^T x + b = 0$).
- **초평면 법선 벡터($w$)**: 분리 초평면의 방향을 결정하고 마진 폭($2/\|w\|$)을 규정하는 가중치 벡터.

</details>

```text
               (양성 클래스 영역: w^T x + b >= +1)
                      [ + ]         [ + ]
                         [ 서포트 벡터 (+) ] ─── (양의 마진 경계: w^T x + b = +1)
                              :
           <────── 마진 폭 = 2 / ||w|| ──────>
                              :
────────────────── [ 최적 분리 초평면: w^T x + b = 0 ] ──────────────────
                              :
                         [ 서포트 벡터 (-) ] ─── (음의 마진 경계: w^T x + b = -1)
                      [ - ]         [ - ]
               (음성 클래스 영역: w^T x + b <= -1)
```

선의 의미: 서포트 벡터 위치에 따른 마진 경계와 중앙 분리 초평면의 기하학적 관계

| 구성요소 | 책임 |
|:---|:---|
| 분리 초평면 | 클래스를 양분하는 **결정 경계($w^T x + b = 0$) 수립** |
| 서포트 벡터 | 초평면의 기울기와 위치를 실질적으로 고정하는 **경계 데이터 표본** |
| 마진 영역 | 두 클래스 경계 간 **이격 거리 확보 및 일반화 성능 보증** |
| 슬랙 변수 ($\xi_i$) | 비선형 노이즈 허용을 위한 **마진 내부 침범 오차 완화** |

#### 한줄 요약

- 분리 초평면과 마진 경계를 형성하는 서포트 벡터로 공간을 양분하고 슬랙 변수로 노이즈를 완화

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **라그랑주 승수(Lagrange Multiplier, $\alpha$)**: 등식 및 부등식 제약조건 하에서 최적화 문제를 쌍대 문제로 변환하기 위해 도입된 계수.
- **KKT 조건(Karush-Kuhn-Tucker Conditions)**: 비선형 부등식 제약 최적화 문제에서 최적해가 만족해야 하는 필요조건.

</details>

```text
데이터셋 입력
     │
     ▼
[ 1. 선형 분리 가능성 판별 ]
├─ 선형 분리 가능 ─────► [ 2. 하드 마진 최적화 ]
└─ 선형 분리 불가 ─────► [ 3. 커널 트릭 및 소프트 마진 적용 ]
     │
     ▼
[ 4. 라그랑주 쌍대 문제 변환 ] : 2차 계획법 최적화
     │
     ▼
[ 5. 서포트 벡터 선별 및 초평면 확정 ]
```

**동작 원리**

1. **선형 분리 가능성 판별**: 데이터 분포 분석을 통한 선형/비선형 분류 전략 수립
2. **하드 마진 최적화**: 노이즈 없는 선형 데이터 대상 마진 엄격 최대화 수행
3. **커널 트릭 및 소프트 마진 적용**: 비선형 데이터에 커널 함수 및 슬랙 변수($C$) 도입
4. **라그랑주 쌍대 문제 변환**: KKT 조건 기반 볼록 2차 계획법(QP) 문제로 공식화
5. **서포트 벡터 선별 및 초평면 확정**: $\alpha_i > 0$인 서포트 벡터로 $w, b$ 파라미터 확정

#### 한줄 요약

- 선형 가능성을 판별하고 라그랑주 쌍대 문제로 변환하여 서포트 벡터를 선별한 뒤 분리 초평면을 확정

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **선형 커널(Linear Kernel)**: 저차원 공간에서 직접 내적을 수행하는 고속 선형 분류 커널.
- **RBF 커널(Radial Basis Function Kernel)**: 두 데이터 간의 거리를 가우시안 분포로 매핑하여 무한 차원 공간을 형성하는 표준 비선형 커널.
- **다항식 커널(Polynomial Kernel)**: 지정된 차수($d$)만큼 특징들의 다항 결합을 계산하는 커널.

</details>

| SVM 커널 함수 | 선형 커널 (Linear) | RBF 커널 (가우시안) | 다항식 커널 (Polynomial) |
|:---|:---|:---|:---|
| 적용 기준 | **특징 수($d$)가 데이터 수($n$) 초과** 고차원 선형 과업 시 | **복잡한 비선형 경계** 대상 범용 데이터 분류 시 | 데이터 간 **다항식 상호작용** 명확한 비선형 과업 시 |
| 핵심 특징 | 저차원 공간 내 **직접 내적 연산 수행** 기반 최고속 | 가우시안 함수 기반 **무한 차원 특징 공간 매핑** | 차수($d$) 지정을 통한 **다항식 특징 결합 공간 매핑** |
| 한계 | **비선형 패턴 분류 불가** | $\gamma, C$ 설정에 따른 **과적합 민감성** | 차수($d$) 증가 시 **계산 수치 폭증** |

#### 한줄 요약

- 고차원 희소 데이터는 선형 커널, 복잡한 비선형 데이터는 RBF 커널, 다항 조합 데이터는 다항식 커널을 선택

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **순차 최소 최적화(Sequential Minimal Optimization, SMO)**: 거대한 QP 문제를 2개 변수 단위로 분해하여 반복 최적화하는 고속 SVM 학습 알고리즘.
- **감마($\gamma$)**: RBF 커널에서 단일 데이터 표본이 미치는 영향력의 반경을 결정하는 하이퍼파라미터.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 비선형 노이즈에 의한 **선형 분리 초평면 구성 불가** | **소프트 마진 도입 및 규제 계수($C$) 튜닝** | 마진 크기와 오분류 허용 간 최적 균형 확보 |
| 대규모 데이터셋 훈련 시 **연산 복잡도 폭증($O(N^3)$)** | **SMO 알고리즘 적용 및 LinearSVC/SGDClassifier 전환** | 대규모 데이터 학습 시간 획기적 단축 |
| RBF 커널 적용 시 하이퍼파라미터 **과적합 취약성** | **$C$와 $\gamma$ 파라미터 교차 검증 기반 격자 탐색** | 최적 분리 경계 도출 및 일반화 성능 극대화 |

#### 한줄 요약

- 노이즈는 소프트 마진으로 절충하고, 대규모 연산 병목은 SMO로 해결하며, 커널 과적합은 $C$와 $\gamma$ 격자 탐색으로 튜닝

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **소형 고차원 데이터셋**: 샘플 수($N$)는 수천 단위 이하이나 특징 차원($D$)이 수천 수만 단위에 달하는 텍스트나 유전체 데이터.

</details>

- 고차원 소표본은 **SVM(RBF/선형)**, 대규모 빅데이터는 **딥러닝/선형 분류기** 선택

#### 한줄 요약

- 고차원 소규모 데이터에서는 SVM의 마진 최대화 이점을 취하고, 대규모 빅데이터에서는 딥러닝으로 전환
