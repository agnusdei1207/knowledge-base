## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **서포트 벡터 머신(SVM, Support Vector Machine)**: 두 클래스 사이의 여백인 마진(Margin, $\frac{2}{\|\mathbf{w}\|}$)을 최대화하는 최적 결정 초평면(Optimal Hyperplane)을 찾는 지도학습 분류/회귀 알고리즘.
- **서포트 벡터(Support Vector)**: 결정 경계선과 마진 경계선 상에 위치하여 초평면의 위치와 기울기를 유일하게 결정짓는 핵심 데이터 포인트들.
- **구조적 위험 최소화(SRM, Structural Risk Minimization)**: 경험적 훈련 오차 최소화(ERM)를 넘어 모델의 일반화 오차 상한을 최소화하는 통계적 학습 이론.

</details>

- 정의/개념: 결정 경계에 인접한 서포트 벡터들과의 거리인 마진을 최대화($\min \frac{1}{2}\|\mathbf{w}\|^2$)하여 일반화 능력을 극대화하는 **최대 마진 선형/비선형 분류 모델**
- 배경/필요성: 단순 훈련 오차만 줄이는 로지스틱 회귀나 퍼셉트론의 경계 과적합 문제를 극복하고 **새로운 테스트 데이터에 대한 일반화 성능을 이론적으로 보장 필수**

#### 한줄 요약

- 두 클래스 사이의 마진을 최대화하는 최적 초평면을 찾아 일반화 오차를 최소화

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **커널 트릭(Kernel Trick)**: 저차원 비선형 데이터를 고차원 특징 공간으로 직접 매핑하지 않고, 커널 함수($K(\mathbf{x}_i, \mathbf{x}_j) = \phi(\mathbf{x}_i)^T \phi(\mathbf{x}_j)$)를 통해 고차원 내적을 초고속 계산하는 수학적 기법.
- **볼록 2차 계획법(Convex Quadratic Programming)**: 목적 함수가 볼록(Convex)하여 국소 최솟값(Local Minima) 없이 언제나 유일한 전역 최적해(Global Optimum)를 보장하는 최적화 특성.

</details>

![Observable Plot으로 그린 SVM 최대 마진과 서포트 벡터 산점도](/study/diagrams/svm-observable-plot.svg)

> 서포트 벡터가 양쪽 마진 점선을 지탱하며, 그 중앙의 실선 초평면이 두 클래스 사이의 마진을 최대화

- 경계선에 인접한 **소수의 서포트 벡터만으로 결정 함수가 정의**되어 메모리 효율적
- RBF(가우시안), 다항식 등 **커널 트릭을 통한 복잡한 비선형 결정 경계 형성**
- 볼록 2차 계획법(QP) 기반의 **유일 전역 최적해 수렴 보장**

#### 한줄 요약

- 서포트 벡터가 마진을 결정하며, 커널 트릭을 통해 고차원 비선형 분리를 효율적으로 달성

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **라그랑주 승수(Lagrange Multipliers, $\alpha_i$)**: KKT 조건 하에서 서포트 벡터에만 $\alpha_i > 0$이 부여되고, 나머지 비경계 데이터는 $\alpha_i = 0$으로 소거되는 가중치.

</details>

```text
[ SVM 최대 마진 및 커널 결정 구조도 ]
                   [ 원본 저차원 공간 (X) ]
                              │
                              ▼ (커널 트릭: K(x_i, x_j) = exp(-γ||x_i - x_j||²))
                   [ 고차원 힐베르트 특징 공간 (Φ(X)) ]
                              │
                              ▼
 ┌───────────────────────────────────────────────────────────┐
 │ 양성 마진 초평면: w^T Φ(x) + b = +1                        │ ◄── 서포트 벡터 (+)
 ├───────────────────────────────────────────────────────────┤
 │ 최적 결정 초평면: w^T Φ(x) + b = 0  (마진 폭 = 2 / ||w||)  │
 ├───────────────────────────────────────────────────────────┤
 │ 음성 마진 초평면: w^T Φ(x) + b = -1                        │ ◄── 서포트 벡터 (-)
 └───────────────────────────────────────────────────────────┘
```

선의 의미: 원본 공간, 커널 트릭 고차원 매핑, 최대 마진 초평면 및 서포트 벡터 간의 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 서포트 벡터 ($\mathbf{x}_k$) | 마진 경계선 상에 위치하여 **결정 초평면의 방향($\mathbf{w}$)과 절편($b$) 결정** |
| 커널 함수 ($K(\mathbf{x}, \mathbf{z})$) | RBF/Linear/Poly 함수로 **고차원 공간의 내적을 $O(D)$로 연산** |
| 슬랙 변수 ($\xi_i$) | 소프트 마진에서 **노이즈 및 마진 침범 허용 오차 측정** |
| 규제 파라미터 ($C$) | **마진 최대화(작은 $C$)와 훈련 오차 최소화(큰 $C$) 간의 균형 조절** |

#### 한줄 요약

- 커널 함수가 내적을 계산하고 최적화기가 최대 마진 초평면을 결정하여 클래스 판정을 수행

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **SMO(Sequential Minimal Optimization)**: 거대한 QP 문제를 2개의 라그랑주 승수씩 해석적으로 반복 분할 해결하여 $O(N^2)$ 속도로 수렴시키는 표준 SVM 최적화 알고리즘.

</details>

```text
표준화된 훈련 데이터셋 (X, y) 인입 (y ∈ {-1, +1})
   │
   ▼
[ 1. 커널 함수(Linear / RBF) 및 규제 파라미터 C, γ 설정 ]
   │
   ▼
[ 2. 쌍대 문제(Dual Problem) 구성: max_α ∑α_i - 1/2 ∑ α_i α_j y_i y_j K(x_i, x_j) ]
   │
   ▼
[ 3. SMO 알고리즘을 통한 라그랑주 승수 α_i* 최적화 (0 ≤ α_i ≤ C, ∑ α_i y_i = 0) ]
   │
   ▼
[ 4. α_i* > 0 인 서포트 벡터 및 바이어스 b* 추출 및 저장 ]
   │
   ▼
[ 5. 새 데이터 x_test 분류: f(x) = sign( ∑ α_i* y_i K(x_i, x_test) + b* ) ]
```

**동작 원리**

1. **하이퍼파라미터 선정**: 선형/RBF 커널과 마진 페널티 $C$, 커널 대역폭 $\gamma$ 설정
2. **쌍대 문제 변환**: KKT 조건을 통해 제약 최적화 문제를 라그랑주 승수 $\alpha$의 2차 계획법으로 변환
3. **SMO 최적화**: 2개 변수씩 해석적으로 갱신하며 전역 최적해 $\alpha^*$ 도출
4. **서포트 벡터 보관**: $\alpha_i > 0$을 만족하는 핵심 벡터와 바이어스 $b$를 메모리에 저장
5. **결정 함수 판정**: 서포트 벡터들과의 커널 유사도 가중합 부호(`sign`)로 최종 클래스 판정

#### 한줄 요약

- 쌍대 문제로 변환 후 SMO로 서포트 벡터를 도출하고 커널 가중합으로 클래스를 판정

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **SVM 3대 핵심 유형**:
  - 하드 마진 (Hard-Margin): 오차 불허($\xi_i = 0$), 완전 선형 분리 가능 시.
  - 소프트 마진 (Soft-Margin): 슬랙 변수($\xi_i > 0$) 허용, 노이즈 및 클래스 중첩 극복.
  - 커널 SVM (RBF Kernel): 비선형 매핑, 원형/초승달 등 복잡한 비선형 경계 분리.

</details>

| 비교 항목 | 하드 마진 SVM | 소프트 마진 SVM (Soft-Margin) | 커널 SVM (Kernel Trick) |
|:---|:---|:---|:---|
| 선형 분리 조건 | **완벽한 선형 분리 가능 필수** | 선형 분리 불가/노이즈 허용 | **완전한 비선형 데이터셋** |
| 마진 침범 허용 | **일체 불허 (Zero Tolerance)** | **슬랙 변수($\xi$)로 일부 허용** | 고차원 공간에서 소프트 마진 적용 |
| 핵심 파라미터 | 없음 | **규제 계수 ($C$)** | **$C$ 및 커널 파라미터 ($\gamma$, degree)** |
| 이상치 취약성 | **이상치 1개에 경계가 극단 왜곡** | **$C$ 조절로 이상치에 강건** | $\gamma$ 과다 시 심각한 과적합 발생 |

#### 한줄 요약

- 선형 분리는 선형 SVM, 노이즈는 소프트 마진, 비선형 매니폴드는 RBF 커널을 적용

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **선형 SVM 고속화(LinearSVC / Liblinear)**: 커널 트릭 없이 원시 선형 공간에서 좌표 하강법(Coordinate Descent)으로 최적화하여 표본 수 $N$에 선형 비례($O(N)$)하는 고속 알고리즘.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 특징 척도 차이로 특정 변수가 **유클리드 거리 및 마진 지배** | `StandardScaler` 기반 **Z-Score 표준화 필수** | 모든 특징의 공정한 마진 기여 |
| RBF 커널 적용 시 대규모 데이터($N > 10^5$)에서 **$O(N^2)$ 메모리 폭증** | **`LinearSVC` (선형 고속 라이브러리)** 또는 Nyström 근사 커널 | 대규모 데이터 학습 시간 $O(N)$ 단축 |
| RBF 커널 파라미터($C, \gamma$) 오설정으로 인한 **심각한 과적합** | **격자 탐색(GridSearchCV) 기반 로그 스케일 교차 검증** | 마진 폭과 결정 경계 곡률 최적화 |
| 불균형 클래스 데이터셋에서 **다수 클래스로의 초평면 이동** | `class_weight='balanced'`로 소수 클래스 페널티 강화 | 소수 클래스 분류 재현율(Recall) 확보 |

#### 한줄 요약

- 피처는 StandardScaler로 표준화하고, 대규모 데이터에는 LinearSVC로 전환하며, GridSearch로 C·γ를 최적화하고, 클래스 불균형은 class_weight로 보정한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **정형 머신러닝의 최고 벤치마크**: 텍스트 분류, 바이오인포매틱스 유전자 서열 분석 등 고차원 소표본($D > N$) 데이터에서 SVM은 통계적 일반화 이론을 바탕으로 극도로 강력한 분류 성능을 발휘.

</details>

- 선형 분리 데이터는 **선형 SVM**, 노이즈/클래스 중첩은 **소프트 마진**, 비선형 매니폴드는 RBF 커널 SVM 선택

#### 한줄 요약

- 데이터의 선형 분리도와 노이즈를 분석하여 소프트 마진과 커널 파라미터를 최적화
