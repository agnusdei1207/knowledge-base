## 미리 알고가기

- **정렬 알고리즘(Sorting Algorithm)**: 원소를 키 순서로 재배열해 탐색·처리를 돕는 알고리즘
- **입력 크기($n$)**: 정렬할 원소 수이며 비교 횟수 증가율의 기준 변수
- **빅오(Big-O, $O$)**: 입력 증가에 따른 정렬 비용 증가율의 점근 상한을 나타내는 표기
- **빅오메가(Big-Omega, $\Omega$)**: 점근 하한을 구분하는 그리스 대문자 $\Omega$를 ‘오메가’로 읽으며, 비교 정렬의 최소 비교 증가율을 나타내는 표기
- **비교 정렬(Comparison Sort)**: 원소의 대소 비교 결과만으로 순서를 정하는 정렬 방식
- **로그($\log n$)**: 입력을 일정 비율로 줄일 때 분할 깊이와 비교 단계의 증가율
- **곱셈 생략 $n\log n$**: 각 원소가 로그 단계의 비교에 참여하는 전체 비교 증가율
- **이진 탐색(Binary Search)**: 정렬된 자료의 중간값과 탐색값을 비교하여 탐색 범위를 절반씩 줄이는 알고리즘
- **피벗(Pivot)**: 원소를 작은 쪽과 큰 쪽으로 나누는 퀵 정렬의 기준 원소
- **재귀(Recursion)**: 입력을 줄여 같은 함수를 다시 호출하고 부분 문제를 푸는 방식
- **안정 정렬(Stable Sort)**: 같은 키의 입력 순서를 보존하는 정렬
- **최대 힙(Max Heap)**: 부모 키가 자식 키 이상인 완전 이진 트리
- **외부 정렬(External Sorting)**: 메모리보다 큰 데이터를 구간별 처리·병합해 저장장치에서 정렬하는 방식
- **퀵 정렬(Quick Sort)**: 피벗으로 배열을 분할해 각 구간을 재귀 정렬하는 방식
- **병합 정렬(Merge Sort)**: 배열을 나눠 정렬한 뒤 병합해 안정성을 보존하는 방식
- **힙 정렬(Heap Sort)**: 최대 힙의 루트를 반복 추출해 제자리 정렬하는 방식
- **버블 정렬(Bubble Sort)**: 역순인 이웃을 반복 교환해 큰 원소를 뒤로 보내는 방식
- **조기 종료(Early Termination)**: 한 번의 순회에서 교환이 발생하지 않으면 정렬 완료로 판단하고 반복을 종료하는 최적화
- **보조 공간**: 입력 저장 공간 외에 정렬 과정에서 추가로 사용하는 메모리
- **완전 이진 트리(Complete Binary Tree)**: 마지막 층을 제외한 모든 층이 차고 마지막 층은 왼쪽부터 채워져 배열로 연속 저장할 수 있는 트리
- **제자리 정렬(In-Place Sort)**: 입력 크기에 비례하는 별도 배열 없이 원본 저장 공간 안에서 원소를 재배열하는 정렬 방식
- **재귀 스택(Recursion Stack)**: 함수가 자신을 다시 호출할 때 반환 위치와 지역 상태를 호출 깊이만큼 저장하는 메모리 영역
- **불균형 분할(Unbalanced Partition)**: 피벗 한쪽에 원소가 몰려 퀵 정렬의 재귀 깊이와 비교 횟수가 제곱 수준으로 증가하는 분할
- **지역성(Locality)**: 최근 접근한 데이터나 인접한 데이터에 다시 접근할 가능성이 높은 메모리 참조 특성

## Ⅰ. 개요

- 정의/개념: 원소를 **키 순서**로 재배열해 후속 처리를 돕는 **알고리즘군**
- 기존 한계: 키 순서가 없으면 **이진 탐색**·구간 병합 적용 불가

### 쉽게 이해하기 (학습용)

- 책을 번호순으로 다시 세우면 중간 번호부터 찾거나 두 책장을 합칠 때 처음부터 모두 뒤지지 않아도 된다.

## Ⅱ. 특징

- **비교 정렬**의 이론적 하한 $\Omega(n\log n)$
- 시간·공간·**안정성**·**제자리 여부**로 갈리는 알고리즘 선택

### 쉽게 이해하기 (학습용)

- 책 번호를 서로 비교해 줄 세우는 한 최소 비교 횟수를 피할 수 없으므로, 시간·메모리·같은 번호 책의 원래 순서·제자리 여부 중 무엇을 우선할지 정해야 한다.

## Ⅲ. 아키텍처

| 구성요소 | 책임 |
|:---|:---|
| 키·비교 함수 | 원소 **대소·동등 관계** 판정 |
| 재배열 전략 | 비교 결과를 **원소 위치 변경**으로 반영 |
| 보조 공간 | **임시 배열**·**재귀 스택** 보관 |

> 요약: **비교 결과**에 따라 원소 위치를 바꾸며 보조 공간 사용

### 쉽게 이해하기 (학습용)

- 책의 앞뒤를 가리는 규칙, 실제로 옮기는 방법, 잠시 쌓아 둘 선반 크기가 정렬의 시간·공간 특성을 만든다.

## Ⅳ. 종류 및 비교

| 정렬 알고리즘 | 퀵 | 병합 | 힙 | 버블 |
|:---|:---|:---|:---|:---|
| 적용 기준 | 메모리 내 배열·**평균 시간** 우선 | 동일 키 순서 보존·**외부 정렬** | **최악 시간 상한**·보조 공간 제한 | **조기 종료** 가능한 거의 정렬된 소규모 입력 |
| 핵심 특징 | **피벗** 기준 제자리 분할 | **안정성** 보존 분할·병합 | **최대 힙**으로 제자리 정렬 | 인접 **역순 교환** 반복 |
| 한계 | **불균형 분할** 시 최악 제곱 시간 | 입력 크기만큼 **임시 배열** 필요 | **불안정 정렬**·낮은 **캐시 지역성** | 평균·최악 모두 **제곱 시간** |

> 요약: 평균 속도·추가 메모리·**최악 상한**의 맞바꿈

### 쉽게 이해하기 (학습용)

- 평균 속도는 퀵, 안정성과 외부 정렬은 병합, 최악 상한은 힙, 거의 정렬된 소규모 입력은 버블이 알맞다.

## Ⅴ. 실무 고려사항 및 대책

| 고려사항 | 대책 | 효과 |
|:---|:---|:---|
| 입력이 메모리를 넘는 **용량 제약** | 구간 정렬 후 **외부 병합** 수행 | 최대 **메모리 점유량** 제한 |
| 동일 키의 **입력 순서** 보존 여부 | 요구 시 **안정 정렬** 선택 | 연관 레코드의 **상대 순서** 유지 |
| 퀵 정렬의 **불균형 분할** | 깊이 한계에서 **힙 정렬** 전환 | 최악 **제곱 시간** 퇴화 방지 |

### 쉽게 이해하기 (학습용)

- 책이 선반보다 많으면 묶음별로 정렬해 합치고, 같은 번호의 순서를 지켜야 하면 안정 정렬을 쓰며, 퀵 분할이 치우치면 힙으로 바꾼다.

## Ⅵ. 결론

- **평균 속도**는 퀵, 안정성·외부 정렬은 병합, **최악 상한**은 힙

### 쉽게 이해하기 (학습용)

- 책장을 정리할 때 빠른 평균 작업, 같은 번호 책의 원래 순서, 최악 작업 시간 중 무엇을 지킬지 정하면 그 조건에 맞는 정렬 알고리즘이 좁혀진다.
