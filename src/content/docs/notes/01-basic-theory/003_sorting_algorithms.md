## 미리 알고가기

- **정렬 알고리즘(Sorting Algorithm)**: 원소를 키 순서로 재배열해 탐색·처리를 돕는 알고리즘
- **입력 크기($n$)**: ‘엔’으로 읽고 항목 개수(Number)의 머리글자를 쓰는 관례에 따라 정렬할 원소 수를 나타내며 비교 횟수 증가율의 기준이 되는 변수
- **빅오(Big-O, $O$)**: ‘빅 오’로 읽고 증가 차수(Order)를 나타내는 $O$를 쓰는 관례에 따라 정렬 비용 증가율의 점근 상한을 나타내는 표기
- **빅오메가(Big-Omega, $\Omega$)**: ‘빅 오메가’로 읽고 점근 하한에 그리스 대문자 오메가를 쓰는 관례에 따라 비교 정렬에 반드시 필요한 최소 비교 횟수의 증가율을 나타내는 표기
- **비교 정렬(Comparison Sort)**: 원소의 대소 비교 결과만으로 순서를 정하는 정렬 방식
- **로그($\log n$)**: ‘로그 엔’으로 읽고 반복해서 일정 비율로 줄이는 단계 수를 로그로 나타내는 수학 관례에 따라 분할 깊이와 비교 단계의 증가율을 나타냄
- **곱셈 생략 $n\log n$**: ‘엔 곱하기 로그 엔’으로 읽고 문자와 함수 사이의 곱셈 기호를 생략하는 수학 관례에 따라 각 원소가 로그 단계의 비교에 참여하는 전체 비교 증가율을 나타냄
- **이진 탐색(Binary Search)**: 이미 정렬된 자료에서 가운데 값과 비교해 후보 구간을 절반씩 버리며 찾는 방법이며, 순서가 맞춰져 있어야만 쓸 수 있어 정렬을 먼저 해 두는 대표적 이유가 됨
- **피벗(Pivot)**: 원소를 작은 쪽과 큰 쪽으로 나누는 퀵 정렬의 기준 원소
- **재귀(Recursion)**: 입력을 줄여 같은 함수를 다시 호출하고 부분 문제를 푸는 방식
- **안정 정렬(Stable Sort)**: 같은 키의 입력 순서를 보존하는 정렬
- **최대 힙(Max Heap)**: 부모 키가 자식 키 이상인 완전 이진 트리
- **외부 정렬(External Sorting)**: 메모리보다 큰 데이터를 구간별 처리·병합해 저장장치에서 정렬하는 방식
- **퀵 정렬(Quick Sort)**: 피벗으로 배열을 분할해 각 구간을 재귀 정렬하는 방식
- **병합 정렬(Merge Sort)**: 배열을 나눠 정렬한 뒤 병합해 안정성을 보존하는 방식
- **힙 정렬(Heap Sort)**: 최대 힙의 루트를 반복 추출해 제자리 정렬하는 방식
- **버블 정렬(Bubble Sort)**: 역순인 이웃을 반복 교환해 큰 원소를 뒤로 보내는 방식
- **조기 종료(Early Termination)**: 한 바퀴를 도는 동안 교환이 한 번도 없었다면 이미 정렬이 끝났다는 뜻이므로 남은 회차를 돌지 않고 즉시 멈추는 처리이며, 버블 정렬이 거의 정렬된 입력에서만 쓸 만해지는 근거
- **보조 공간**: 입력 저장 공간 외에 정렬 과정에서 추가로 사용하는 메모리
- **완전 이진 트리(Complete Binary Tree)**: 마지막 층을 제외한 모든 층이 차고 마지막 층은 왼쪽부터 채워져 배열로 연속 저장할 수 있는 트리
- **제자리 정렬(In-Place Sort)**: 입력 크기에 비례하는 별도 배열 없이 원본 저장 공간 안에서 원소를 재배열하는 정렬 방식
- **재귀 스택(Recursion Stack)**: 함수가 자신을 다시 호출할 때 반환 위치와 지역 상태를 호출 깊이만큼 저장하는 메모리 영역
- **불균형 분할(Unbalanced Partition)**: 피벗 한쪽에 원소가 몰려 퀵 정렬의 재귀 깊이와 비교 횟수가 제곱 수준으로 증가하는 분할
- **지역성(Locality)**: 가까운 메모리 위치를 연속 접근할수록 캐시 재사용이 높아지는 성질이며 힙 정렬의 비연속 접근 위험을 설명함
- **선택 화살표($\rightarrow$)**: ‘이면 선택’으로 읽고 조건에서 결과로 이어짐을 화살표로 나타내는 관례에 따라 결론에서 정렬 요구조건별 알고리즘 선택을 연결함

## Ⅰ. 개요

- 정의/개념: 원소를 **키 순서**로 재배열해 후속 처리를 돕는 **알고리즘군**
- 기존 한계: 키 순서가 없으면 **이진 탐색**·구간 병합 적용 불가

### 쉽게 이해하기 (학습용)

- 책마다 붙은 번호표를 기준으로 책장 줄을 다시 세우는 일이며, 한 번 줄을 세워 두면 이후 찾기와 합치기를 앞에서부터 전부 뒤지지 않아도 되어 후속 작업 비용이 함께 줄어든다.

## Ⅱ. 특징

- **비교 정렬**의 이론적 하한 $\Omega(n\log n)$
- 시간·공간·**안정성**·**제자리 여부**로 갈리는 알고리즘 선택

### 쉽게 이해하기 (학습용)

- 책 번호를 서로 비교해 줄 세우는 한 최소 비교 횟수를 피할 수 없으므로, 시간·메모리·같은 번호 책의 원래 순서·제자리 여부 중 무엇을 우선할지 정해야 한다.

## Ⅲ. 아키텍처 및 구성요소

| 설계 요소 | 설명 |
|:---|:---|
| 키·비교 함수 | 원소 **대소·동등 관계** 판정 |
| 재배열 전략 | 비교 결과를 **원소 위치 변경**으로 반영 |
| 보조 공간 | **임시 배열**·**재귀 스택** 보관 |

> 요약: **비교 결과**에 따라 원소 위치를 바꾸며 보조 공간 사용

### 쉽게 이해하기 (학습용)

- 어느 책이 앞인지 가리는 번호표 규칙(키·비교 함수), 그 판정대로 책을 실제로 옮기는 방법(재배열 전략), 옮기는 동안 잠깐 쌓아 둘 임시 선반의 크기(보조 공간) 세 가지가 정해지면 정렬 하나가 완성된다.

## Ⅳ. 원리 및 절차 흐름도

- **퀵 정렬**: **피벗** 분할 후 양쪽 구간 재귀 정렬
- **병합 정렬**: 절반 분할·재귀 정렬 후 **구간 병합**
- **힙 정렬**: **최대 힙** 구성 후 루트·끝 교환·힙 복원
- **버블 정렬**: 역순인 인접 원소 반복 교환

### 쉽게 이해하기 (학습용)

- 책 한 권을 골라 그보다 작은 책은 왼쪽·큰 책은 오른쪽으로 밀어 두면 퀵, 반씩 나눠 정리한 두 묶음을 앞에서부터 번갈아 집어 합치면 병합, 가장 큰 책을 꼭대기에서 꺼내 맨 뒤에 놓기를 되풀이하면 힙, 옆에 놓인 두 권만 보고 뒤바뀐 자리를 바꾸면 버블이다.

## Ⅴ. 종류 및 비교

| 정렬 알고리즘 | 퀵 | 병합 | 힙 | 버블 |
|:---|:---|:---|:---|:---|
| 적용 기준 | 메모리 내 배열·**평균 시간** 우선 | 동일 키 순서 보존·**외부 정렬** | **최악 시간 상한**·보조 공간 제한 | **조기 종료** 가능한 거의 정렬된 소규모 입력 |
| 핵심 특징 | **피벗** 기준 제자리 분할 | **안정성** 보존 분할·병합 | **최대 힙**으로 제자리 정렬 | 인접 **역순 교환** 반복 |
| 한계 | **불균형 분할** 시 최악 제곱 시간 | 입력 크기만큼 **임시 배열** 필요 | **불안정 정렬**·낮은 **캐시 지역성** | 평균·최악 모두 **제곱 시간** |

> 요약: 평균 속도·추가 메모리·**최악 상한**의 맞바꿈

### 쉽게 이해하기 (학습용)

- 네 사람이 같은 책장을 정리하는 장면으로 보면, 퀵은 기준 책 하나로 좌우로 밀어 평균이 가장 빠르지만 기준을 잘못 집으면 한쪽에만 쌓이는 불균형 분할이 되어 느려지고, 병합은 임시 선반을 빌리는 대가로 같은 번호 책의 원래 앞뒤를 지키며, 힙은 임시 선반 없이 꼭대기 책부터 꺼내 최악에도 시간이 튀지 않고, 버블은 바로 옆 두 권만 보므로 이미 거의 정리된 짧은 줄에서만 쓸 만하다.

## Ⅵ. 실무 사례

1. 범용 배열 정렬기는 퀵 **재귀 깊이 한계**에서 **힙 정렬** 전환

### 쉽게 이해하기 (학습용)

- 피벗이 계속 한쪽으로 치우치면 재귀 호출이 계단처럼 깊어져 제곱 시간으로 주저앉으므로, 범용 배열 정렬기는 재귀 깊이가 정해 둔 한계를 넘는 순간 최악에도 상한이 지켜지는 힙 정렬로 갈아탄다.

## Ⅶ. 결론

- 정렬 성능 확보를 위해 안정성·상한을 검토하여 **정렬법** 활용

### 쉽게 이해하기 (학습용)

- 책장을 정리할 때 빠른 평균 작업, 같은 번호 책의 원래 순서, 최악 작업 시간 중 무엇을 지킬지 정하면 그 조건에 맞는 정렬 알고리즘이 좁혀진다.
