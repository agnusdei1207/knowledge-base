## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **탐욕 알고리즘(Greedy Algorithm)**: 매 단계의 국소 최선을 되돌리지 않고 확정해 해를 구성하는 기법이다.
- **국소 최적 선택(Local Optimal Choice)**: 현재 단계에서 가장 유리한 후보를 선택하는 결정이다.

</details>

- 정의/개념: 각 단계의 국소 최선을 되돌리지 않고 누적해 전체 해를 만드는 **탐욕 알고리즘** 설계 기법이다.
- 배경/필요성: 탐욕 선택 속성과 최적 부분 구조가 성립하는 문제에서는 가능한 후보 조합을 모두 탐색하지 않고도 최적해를 구할 수 있다.

#### 한줄 요약

- 각 단계에서의 국소 최적 선택을 되돌림 없이 누적하여 해를 구축한다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **탐욕 선택 속성(Greedy Choice Property)**: 국소 최선 선택을 포함하는 전역 최적해가 존재하는 성질이다.
- **최적 부분 구조(Optimal Substructure)**: 부분 문제의 최적해로 전체 최적해를 구성할 수 있는 성질이다.
- **전역 최적해(Global Optimum)**: 가능한 모든 완성 해 가운데 목적 함수 값이 가장 좋은 해이다.
- **상태 관리 비용**: 선택 과정의 중간 상태와 이력을 저장하고 갱신하는 데 드는 자원이다.

</details>

- **국소 최적 선택** 확정 후 되돌림 없이 해를 구성한다.
- **탐욕 선택 속성**•**최적 부분 구조** 충족 시 전역 최적해 보장이 핵심이다.
- 선택•타당성 검사만 반복해 **상태 관리 비용**이 낮다.

#### 한줄 요약

- 탐욕 선택 속성과 최적 부분 구조가 성립할 때 전역 최적해가 보장된다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **후보 집합(Candidate Set)**: 아직 선택하거나 폐기할 수 있는 모든 대상을 보관하는 집합이다.
- **목적 함수(Objective Function)**: 후보 선택의 비용이나 이익을 수치화해 우열을 정하는 함수이다.
- **타당성 함수(Feasibility Function)**: 후보를 추가해도 제약 조건을 지키는지 검사하는 함수이다.
- **부분 해(Partial Solution)**: 선택한 후보를 누적했지만 아직 완성 조건에는 도달하지 않은 중간 결과이다.
- **선택 함수(Selection Function)**: 목적 함수 기준으로 현재 가장 유리한 후보를 고르는 함수이다.
- **해 판정 함수(Solution Function)**: 부분 해가 문제의 완성 조건을 충족했는지 확인하는 함수이다.

</details>

```text
탐욕 알고리즘 구조
├─ 후보 집합
├─ 선택 함수
├─ 타당성 함수
├─ 부분 해
└─ 해 판정 함수
```

가지의 의미: 후보•선택•타당성•누적•완성 판정의 책임 분리를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 후보 집합 | 미선택 **후보** 보관 |
| 선택 함수 | **목적 함수** 기준 국소 최선 결정 |
| 타당성 함수 | **타당성 함수**로 후보의 제약 조건 검사 |
| 부분 해 | **부분 해**에 통과 후보•선택 이력 보관 |
| 해 판정 함수 | **해 판정 함수**로 완성 조건 판정 |

#### 한줄 요약

- 선택 함수, 타당성 검사 함수, 해 판정 함수가 연계되어 부분 해(Partial Solution)의 제약 충족 여부를 판단하고 확정한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **되돌림 없는 선택**: 부분 해에 확정한 후보를 이후 단계에서 취소하지 않는 처리 방식이다.
- **타당성 판정**: 후보를 더한 부분 해가 제약 조건을 지키는지 확인하는 절차이다.

</details>

```text
후보 집합
   │
   ▼
1. 국소 최선 선택
   │
   ▼
2. 타당성 판정
├─ 실패: 후보 폐기 후 다음 선택
└─ 통과
   │
   ▼
3. 통과 후보 확정
   │
   ▼
4. 완성 여부 판정
├─ 미완성: 국소 최선 선택으로 반복
└─ 완성: 부분 해 반환
```

**동작 원리**

1. **국소 최선 선택**: 아직 선택하지 않은 후보 중 목적 함수에 가장 유리한 항목을 고른다.
2. **타당성 판정**: 해당 후보를 부분 해에 추가해도 문제의 제약을 위반하지 않는지 확인한다.
3. **통과 후보 확정**: 타당한 후보는 되돌리지 않는 선택으로 부분 해에 확정한다.
4. **완성 여부 판정**: 해가 완성되지 않았으면 남은 후보에서 다음 국소 최선을 선택한다.

#### 한줄 요약

- 국소 최선 선택, 타당성 판정, 되돌림 없는 확정을 해가 완성될 때까지 반복한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **동적 계획법(Dynamic Programming, DP)**: 중복되는 부분 문제의 해를 저장•재사용하는 설계 기법이다.
- **메모이제이션(Memoization)**: 계산한 상태값을 저장해 같은 상태에서 다시 사용하는 방식이다.
- **완전 탐색(Exhaustive Search)**: 가능한 해를 모두 생성하고 검사하는 기법이다.
- **반례(Counterexample)**: 국소 최선이 전역 최적해를 만들지 못함을 보여 주는 구체적인 입력이다.
- **점화식(Recurrence Relation)**: 하위 상태값을 결합해 현재 상태값을 계산하는 관계식이다.
- **상태 공간(State Space)**: 동적 계획법이 구분해 저장하는 모든 상태의 집합이다.
- **조합 폭발(Combinatorial Explosion)**: 후보 수가 입력 증가에 따라 지수적 또는 계승적으로 급증하는 현상이다.

</details>

| 최적화 기법 | 탐욕 알고리즘 | 동적 계획법 | 완전 탐색 |
|:---|:---|:---|:---|
| 적용 기준 | **탐욕 선택 속성**•최적 부분 구조 성립 | 중복 상태•**점화식** 정의 가능 | 소규모 후보의 **완전 탐색** 가능 |
| 핵심 특징 | **되돌림 없는 선택**으로 현재 최선 확정 | **메모이제이션**•표 기반 해 재사용 | 모든 해 생성•비교 |
| 한계 | **반례** 존재 시 최적해 미보장 | **상태 공간** 증가에 따른 메모리 초과 | 후보 증가에 따른 **조합 폭발** |

> 요약: **탐욕 선택 속성**•중복 상태•후보 규모로 최적화 기법을 선택한다.

#### 한줄 요약

- 탐욕 선택 속성과 교환 논증으로 전역 최적성을 입증하거나, 반례 발견 시 DP 또는 백트래킹으로 전환한다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **교환 논증(Exchange Argument)**: 어떤 최적해의 선택을 탐욕 선택으로 바꿔도 손해가 없음을 보여 최적성을 증명하는 방법이다.
- **동률 해소 규칙(Tie-breaking Rule)**: 목적값이 같은 후보 중 하나를 항상 동일한 기준으로 선택하는 규칙이다.
- **경계값 시험**: 탐욕 선택이 실패할 가능성이 큰 입력 범위의 끝값과 특수값을 검사하는 시험이다.
- **최소 반례**: 탐욕 선택이 실패함을 보이는 입력 가운데 더 작게 줄일 수 없는 사례이다.
- **전역 최적성**: 허용된 모든 완성 해 가운데 목적 함수 값이 가장 좋은 해를 반환하는 성질이다.
- **실행 가능 해(Feasible Solution)**: 문제의 모든 제약 조건을 충족해 실제 선택 결과로 사용할 수 있는 해이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **탐욕 선택 속성** 미성립으로 국소 최선이 전역 오답 생성 | **교환 논증**과 **최소 반례**로 최적성 검증 | 문제의 **전역 최적성** 근거 확보 |
| 숨은 제약 누락으로 실행 불가능한 부분 해 생성 | 모든 제약을 **타당성 함수**에 반영 | 매 선택 후 **실행 가능 해** 유지 |
| 동률 후보 처리 불명확으로 실행별 결과 변동 | 결정적 **동률 해소 규칙** 적용 | 동일 입력에서 같은 결과 생성 |
| 입력 범위 확대 시 검증하지 않은 경계에서 반례 발생 | **경계값 시험**과 소규모 DP•완전 탐색 대조 | 적용 범위의 반례 발견 가능성 향상 |

#### 한줄 요약

- 교환 논증으로 최적성을 증명하고 경계값과 최소 반례로 적용 범위를 검증한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **최적성 증명**: 탐욕 선택을 반복해도 전역 최적해가 보장됨을 논리적으로 보이는 과정이다.

</details>

- **최적성 증명**•중복 상태•후보 규모에 따라 **탐욕•DP•완전 탐색**을 선택한다.

#### 한줄 요약

- 교환 논증으로 최적성을 증명하면 탐욕 기법을 적용하고, 반례가 있으면 DP나 완전 탐색으로 전환한다.
