## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **탐욕 알고리즘(Greedy Algorithm)**: 미래의 선택을 고려하지 않고 현재 시점에서 가장 최적(Local Optimal)이라고 판단되는 선택을 되돌림 없이 확정해 나가는 알고리즘 설계 기법.
- **국소 최적 선택(Locally Optimal Choice)**: 전체 문제의 전역 해를 고려하지 않고 각 하위 단계에서 당장 가장 이익이 큰 후보를 즉시 취하는 결정.

</details>

- 정의/개념: 각 단계의 **국소 최적 선택**을 되돌림 없이 누적해 전체 최적해를 도출하는 기법
- 배경/필요성: 지수 시간의 완전 탐색 비용을 줄이고 다항 시간 내 최적해를 도출하기 위해 **탐욕 선택** 필요

#### 한줄 요약

- 각 단계에서의 국소 최적 선택을 되돌림 없이 누적하여 해를 구축

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **탐욕 선택 속성(Greedy Choice Property)**: 앞선 국소적 최적 선택이 이후의 선택에 영향을 주더라도, 이 선택을 포함하는 전역 최적해(Global Optimum)가 반드시 존재함을 보장하는 수학적 성질.
- **최적 부분 구조(Optimal Substructure)**: 부분 문제의 최적해들을 결합하여 전체 문제의 최적해를 구성할 수 있는 성질.
- **교환 논증(Exchange Argument)**: 임의의 최적해가 주어졌을 때, 해당 해의 원소를 탐욕적 선택으로 교체해도 해의 질(Quality)이 저하되지 않음을 증명하는 수학적 기법.

</details>

- 선택한 결정을 절대 번복하거나 되돌리지 않는 **비되돌림(Irrevocable) 단방향 탐색**
- **탐욕 선택 속성** 및 **최적 부분 구조**가 동시 성립할 때만 전역 최적해 도출 보장
- 단일 경로만 추적하여 상태 캐시 없는 극소의 **메모리 오버헤드**

#### 한줄 요약

- 탐욕 선택 속성과 최적 부분 구조가 성립할 때 전역 최적해가 보장

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **선택 함수(Selection Function)**: 목적 함수 기준으로 현재 가장 유망한 후보를 선별하는 함수.
- **타당성 검사 함수(Feasibility Function)**: 선택된 후보가 문제의 제약 조건을 위반하지 않는지 검증하는 함수.
- **해 판정 함수(Solution Function)**: 현재까지 수집된 부분 해가 문제의 최종 완성 조건을 만족했는지 검사하는 함수.

</details>

```text
[ 탐욕 알고리즘 5대 핵심 요소 ]
┌──────────────────────────────┐
│ 1. 후보 집합 (Candidate Set) │ ── 아직 선택/폐기되지 않은 후보군
├──────────────────────────────┤
│ 2. 선택 함수 (Selection)     │ ── 국소 최적 기준에 따른 최우선 후보 추출
├──────────────────────────────┤
│ 3. 타당성 검사 (Feasibility) │ ── 문제 제약 조건 위반 여부 검증 (필터링)
├──────────────────────────────┤
│ 4. 해 판정 (Solution Check)  │ ── 부분 해가 전체 문제 해를 완성했는지 판정
└──────────────────────────────┘
```

선의 의미: 후보 집합, 선택 함수, 타당성 검사, 해 판정 함수 간의 탐욕적 처리 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 후보 집합 | 미선택 후보군 보관 및 정렬 |
| 선택 함수 | **목적 함수** 기준 국소 최선 후보 결정 |
| 타당성 검사 | **제약 조건** 위반 여부 검사 및 필터링 |
| 해 판정 | 최종 해 완성 여부 판정 및 반환 |

#### 한줄 요약

- 선택 함수, 타당성 검사 함수, 해 판정 함수가 연계되어 부분 해의 제약 충족 여부를 판단하고 확정

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **되돌림 없는 선택(Irrevocable Step)**: 한 번 결정된 부분 해 요소를 큐/배열에서 번복하지 않고 즉시 해 집합에 고정하는 동작.

</details>

```text
후보 집합 (Candidate Set)
   │
   ▼
1. 국소 최선 선택 (Selection Function)
   │
   ▼
2. 제약 타당성 판정 (Feasibility Function)
├─ 위반 (Infeasible): 후보 영구 폐기 후 다음 후보 추출
└─ 충족 (Feasible)
   │
   ▼
3. 부분 해에 확정 추가 (Irrevocable Inclusion)
   │
   ▼
4. 해 완성 여부 판정 (Solution Function)
├─ 미완성: 남은 후보 집합에서 국소 최선 선택 반복
└─ 완성: 최종 최적해 반환
```

**동작 원리**

1. **국소 최선 선택**: 남은 후보 중 정렬 기준에 따라 가장 유리한 항목 추출
2. **제약 타당성 판정**: 해당 항목 추가 시 용량 초과 등 문제 제약 위반 여부 검증
3. **부분 해 확정 추가**: 타당성을 만족하는 후보는 되돌림 없이 최종 해 집합에 즉시 병합
4. **해 완성 여부 판정**: 전체 최적해가 완성될 때까지 1~3단계를 반복하여 최종 해 도출

#### 한줄 요약

- 국소 최선 선택, 타당성 판정, 되돌림 없는 확정을 해가 완성될 때까지 반복

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **탐욕 알고리즘 vs DP vs 완전 탐색**:
  - 탐욕: 국소 최적 선택 단일 경로, 역추적 없음, 탐욕 속성 필수.
  - DP: 모든 하위 부분 문제 상태를 캐싱, 최적 부분 구조 + 중복 부분 문제.
  - 완전 탐색: 모든 가능성을 전수 조사, 조합 폭발($O(2^n), O(n!)$).

</details>

| 알고리즘 기법 | 탐욕 알고리즘 (Greedy) | 동적 계획법 (DP) | 완전 탐색 (Brute Force) |
|:---|:---|:---|:---|
| 적용 기준 | **탐욕 선택 속성** 및 최적 부분 구조 성립 시 | 중복 부분 문제 및 **점화식** 수립 가능 시 | 입력 규모가 극소하여 전수 조사가 가능할 때 |
| 핵심 특징 | **되돌림 없는 단일 선택**으로 빠른 해 확정 | **DP 캐시 테이블** 기반 하위 해 재사용 | 상태 공간 트리의 모든 노드 전수 검사 |
| 한계 | **반례(Counterexample)** 존재 시 오답 발생 | 상태 차원 증가 시 메모리/시간 오버헤드 | 입력 증가에 따른 **조합 폭발($O(2^n)$)** |

#### 한줄 요약

- 탐욕 선택 속성과 교환 논증으로 전역 최적성을 입증하거나, 반례 발견 시 DP 또는 백트래킹으로 전환

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **매트로이드 이론(Matroid Theory)**: 탐욕 알고리즘이 항상 전역 최적해를 보장함을 수학적으로 증명하는 대수적 독립 구조 이론.
- **반례 검증(Counterexample Verification)**: 배낭 문제(0/1 Knapsack) 등에서 탐욕 선택이 실패하는 최소 반례를 구성하여 알고리즘 타당성을 검증하는 작업.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **탐욕 선택 속성** 미성립으로 국소 최선이 전역 오답 생성 | **교환 논증(Exchange Argument)**과 최소 반례로 최적성 검증 | 문제의 **전역 최적성** 수학적 보장 |
| 숨은 제약 누락으로 실행 불가능한 부분 해 생성 | 모든 제약 조건을 **타당성 함수**에 엄격히 반영 | 매 선택 후 **실행 가능 해** 유지 |
| 동률 후보 처리 불명확으로 실행별 결과 변동 | 결정적 **동률 해소 규칙(Tie-breaking Rule)** 적용 | 동일 입력에서 재현 가능한 일관된 결과 |
| 입력 범위 확대 시 검증하지 않은 경계에서 반례 발생 | 소규모 입력 대상 **DP/완전 탐색 결과와 교차 검증** | 적용 범위의 반례 사전 식별 |

#### 한줄 요약

- 교환 논증으로 탐욕 선택의 최적성을 먼저 증명하고, 동률 후보에는 결정적 규칙을 두며, 소규모 입력에서 DP 결과와 교차 검증해 반례를 사전에 잡아야 한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **탐욕 선택 속성(Greedy Choice Property)**: 매 단계에서 국소 최선 선택이 전역 최적 해의 일부임이 보장되는 수학적 조건으로, 이 속성이 성립해야 탐욕 알고리즘 적용이 정당하다.

</details>

- 속성 증명 시 **탐욕 알고리즘**, 반례 존재 시 **동적 계획법** 또는 백트래킹 선택

#### 한줄 요약

- 교환 논증으로 최적성을 증명하면 탐욕 기법을 적용하고, 반례가 있으면 DP나 완전 탐색으로 전환
