## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **NP-완전(NP-Complete)**: NP에 속하면서 모든 NP 문제를 다항 시간에 환원받는 결정 문제 부류이다.
- **결정 문제(Decision Problem)**: 답이 예 또는 아니오로 정해지는 계산 문제이다.
- **다항 환원(Polynomial-Time Reduction)**: 한 문제를 답이 보존되도록 다른 문제로 바꿔 계산 난도를 전달하는 변환이다.
- **비결정론적 다항 시간(Nondeterministic Polynomial Time, NP)**: 긍정 답의 인증서를 다항 시간에 검증할 수 있는 결정 문제 집합이다.

</details>

- 정의/개념: NP에 속하고 모든 NP 문제를 다항 시간에 환원받는 **NP-완전** 결정 문제 부류이다.
- 배경/필요성: 겉모양이 다른 대규모 계산 문제들의 난도를 개별 알고리즘으로 해결하려 하면 다항 시간 해법의 존재 여부를 체계적으로 판정하기 어렵다.

#### 한줄 요약

- 다항 시간 인증서 검증성($NP$)과 모든 $NP$ 문제의 다항 시간 환원 수용성($NP$-Hardness)을 동시에 충족하는 결정 문제 집합이다.


## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **NP-난해(NP-Hard)**: 모든 NP 문제를 다항 환원받아 적어도 NP만큼 어려운 문제 부류이다.
- **다항 시간(Polynomial Time)**: 입력 크기의 다항식으로 제한되는 실행 시간이다.
- **대표성**: 한 NP-완전 문제의 다항 시간 해법이 모든 NP 문제의 해법으로 확장되는 성질이다.
- **최적화 문제(Optimization Problem)**: 가능한 해 중 목적 함수값이 최소 또는 최대인 해를 찾는 문제이다.

</details>

- **NP ∩ NP-난해**이며 모든 NP 문제의 **다항 환원** 수용이 핵심이다.
- **다항 시간** 해법 하나가 문제군 전체로 확장되는 **대표성**이 핵심이다.
- 결정 문제의 NP-완전과 최적화 문제의 **NP-난해** 구분한다.

#### 한줄 요약

- 단 하나의 $NP$-Complete 문제에 대해 다항 시간 알고리즘이 도출될 경우 $P=NP$ 명제가 증명되는 대표성을 갖는다.



## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **인증서(Certificate)**: 결정 문제의 긍정 답이 맞음을 검증하는 데 사용하는 보조 정보이다.
- **완전성 증명**: 대상 문제의 NP 소속과 NP-난해성을 함께 보이는 증명이다.
- **답 보존**: 변환 전 문제와 변환 후 문제의 예•아니오 결과가 같은 성질이다.
- **NP-난해성(NP-Hardness)**: 모든 NP 문제를 다항 시간에 환원받을 만큼 어렵다는 성질이다.
- **다항 시간 검증**: 입력 크기의 다항식으로 제한되는 시간 안에 인증서의 정답 여부를 확인하는 절차이다.

- **다항성(Polynomiality)**: 입력 크기 $n$에 대해 수행 시간이 다항식 $O(n^k)$ 이하로 제한되어 현실적 시간 내 계산 가능한 성질.
- **계산 난도(Computational Hardness)**: 문제를 해결하는 데 요구되는 시간 및 공간 복잡도의 이론적 하한 등급.
</details>

```text
NP-완전성
├─ NP 소속
│  └─ 인증서 다항 시간 검증
└─ NP-난해성
   └─ 다항 환원과 답 보존
```

가지의 의미: NP-완전성을 이루는 두 조건과 증명 근거를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| NP 소속 | 인증서의 **다항 시간 검증**가능성 입증 |
| 인증서 다항 시간 검증 | 인증서 크기•검증 시간의 **다항성** 확인 |
| NP-난해성 | 모든 NP 문제 이상의 **계산 난도** 입증 |
| 다항 환원과 답 보존 | 기존 문제의 입력 변환과 **답 보존** 입증 |

#### 한줄 요약

- 인증서 검증의 다항 시간성(NP 소속) 및 알려진 NP-Complete 문제로부터의 다항 시간 환원(NP-Hardness)을 상호 입증한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **NP 소속 증명**: 인증서 크기와 검증 시간이 입력 크기의 다항식으로 제한됨을 보이는 과정이다.
- **환원 구성**: 알려진 NP-완전 문제의 인스턴스를 대상 문제의 인스턴스로 변환하는 과정이다.
- **답 동치**: 원래 인스턴스가 예일 때와 변환 인스턴스가 예일 때가 서로 같은 관계이다.

</details>

```text
대상 결정 문제
        │
        ▼
1. NP 소속 입증
├─ 실패: NP-완전 증명 불가
└─ 성공
        │
        ▼
2. 기존 NP-완전 문제 선택
        │
        ▼
3. 다항 환원 구성
        │
        ▼
4. 답 동치 입증
├─ 실패: 환원 재구성 후 3으로 반복
└─ 성공: NP-완전 결론
```

### 동작 원리

- **1. NP 소속 입증**: 인증서 크기•검증 시간의 다항성을 확인한다.
- **2. 기존 NP-완전 문제 선택**: 난도가 알려진 출발 문제 선정이다.
- **3. 다항 환원 구성**: 출발 문제의 입력을 대상 문제의 입력으로 다항 시간에 변환한다.
- **4. 답 동치 입증**: 변환 전후의 예•아니오 일치 증명이다.

#### 한줄 요약

- 다항 시간 인증서 검증 및 알려진 NP-Complete 인스턴스로부터의 다항 시간 환원과 답 동치성을 입증한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **다항 시간(Polynomial Time, P)**: 결정론적 알고리즘으로 다항 시간에 풀 수 있는 결정 문제 집합이다.
- **정지 문제(Halting Problem)**: 임의 프로그램이 입력에서 멈추는지 판정하는 일반 알고리즘이 존재하지 않는 문제이다.
- **결정론적 튜링 머신**: 각 상태와 입력 기호에서 다음 동작이 하나로 정해지는 계산 모델이다.
- **비판정 문제(Undecidable Problem)**: 모든 입력에 대해 정답을 내고 종료하는 일반 알고리즘이 존재하지 않는 문제이다.
- **고차 다항식**: 차수가 커 입력 증가에 따른 실제 계산량이 여전히 큰 다항 시간 함수이다.
- **지수 시간(Exponential Time)**: 입력 증가에 따라 실행 단계가 지수적으로 늘어나는 시간복잡도이다.

- **NP 소속•다항 검증(NP Membership & Polynomial Verification)**: 주어진 해(Certificate)가 유효한 정답인지를 결정론적 튜링 머신이 다항 시간 내에 검증할 수 있는 성질.
</details>

| 복잡도 클래스 | NP-완전 | NP-난해 | NP | P |
|:---|:---|:---|:---|:---|
| 적용 기준 | **결정 문제** 완전성 증명 | NP 소속 없이 **NP-난해** 증명 | 다항 크기 **인증서** 검증 가능 | 결정론적 다항 시간에 해 산출 |
| 핵심 특징 | NP에 속하며 **NP-난해** | 모든 NP 문제를 **다항 환원받음** | **인증서** 다항 시간 검증 | **결정론적 튜링 머신** 다항 판정 |
| 한계 | 일반 **다항 시간 해법** 미확립 | **NP 소속•다항 검증** 보장 없음 | 풀이의 **지수 시간** 가능성 잔존 | **고차 다항식** 포함으로 실용성 별개 |

#### 한줄 요약

- NP-완전 문제는 NP와 NP-난해의 교집합이며, 하나의 다항 시간 해법은 모든 NP 문제로 확장된다.


## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **환원 방향**: NP-난해성을 전달하기 위해 알려진 NP-완전 문제에서 대상 문제로 향해야 하는 변환 방향이다.
- **불리언 만족 가능성 문제(Boolean Satisfiability Problem, SAT)**: 불 논리식을 참으로 만드는 변수 할당의 존재 여부를 판정하는 문제이다.
- **특화 솔버(Specialized Solver)**: 특정 문제 구조에 맞춘 탐색•전파•학습 기법으로 실제 인스턴스를 푸는 프로그램이다.
- **임곗값 결정형**: 최적화 목적값이 주어진 기준 이상이나 이하인지 예•아니오로 묻도록 바꾼 문제이다.

- **충족 가능성 문제(Boolean Satisfiability Problem, SAT)**: 주어진 논리식을 참(True)으로 만드는 변수 진리값 할당이 존재하는지 판별하는 최초의 NP-완전 문제.
</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **환원 방향**을 반대로 구성 | 알려진 NP-완전 문제에서 대상으로 변환 | 대상의 **NP-난해성** 전달 |
| 변환의 **답 보존** 실패 | 양방향 동치와 **다항 시간** 증명 | 올바른 **다항 환원** 확보 |
| **NP 소속** 증명 누락 | 인증서 크기•검증 시간의 **다항성** 제시 | **NP-완전** 결론 완성 |
| 최적화를 **NP-완전**으로 표현 | **임곗값 결정형**과 **NP-난해**로 구분 | NP-완전•NP-난해 분류 오류 방지 |
| 패키지 버전•의존 조건 충돌 | 조건을 **SAT**로 바꿔 **특화 솔버** 실행 | 설치 가능 조합 판정 |

#### 한줄 요약

- 알려진 NP-완전 문제에서 대상 문제로 환원해야 NP-난해성을 전달할 수 있다.


## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **근사해(Approximate Solution)**: 최적해와 같음을 보장하지 않지만 다항 시간에 구하고 품질 경계로 차이를 제한하는 해이다.
- **결정형**: 예•아니오를 답하는 문제 형태이다.
- **최적화형**: 목적 함수의 최선값을 찾는 문제 형태이다.
- **품질 경계**: 근사해가 최적해에서 벗어날 수 있는 비율이나 차이의 보장 한도이다.

</details>

- **결정형**은 특화 솔버, **최적화형**은 근사해와 품질 경계를 적용한다.

#### 한줄 요약

- 결정형은 특화 솔버로 판정하고, 최적화형은 품질 경계가 있는 근사 알고리즘을 우선한다.
