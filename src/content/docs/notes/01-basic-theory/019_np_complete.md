## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **NP-완전(NP-Complete)**: NP(Non-deterministic Polynomial) 클래스에 속하면서, 모든 NP 문제들이 다항 시간 환원(Polynomial Reduction)되는 가장 어려운 결정 문제들의 집합.
- **결정 문제(Decision Problem)**: 답이 오직 '예(Yes)' 또는 '아니오(No)'의 불리언 값으로만 도출되는 계산 문제.
- **다항 시간 환원(Polynomial-Time Reduction, $A \le_P B$)**: 문제 $A$의 임의 인스턴스를 문제 $B$의 인스턴스로 다항 시간 내에 변환하여, $B$를 풀면 $A$도 풀리도록 난도를 전달하는 변환.

</details>

- 정의/개념: NP 소속과 NP-난해성을 함께 만족하는 결정 문제군
- 배경/필요성: 수많은 조합 최적화 문제에서 개별 다항 시간 알고리즘의 존재 여부를 일일이 판별할 수 없는 계산 복잡도 분류 및 증명 한계

#### 한줄 요약

- 이 정의의 값어치는 난도를 개별 증명 대신 환원 한 번으로 옮길 수 있다는 데 있어, 한 문제의 다항 해법이 곧 전체의 해법이 된다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **NP-난해(NP-Hard)**: 모든 NP 문제들이 다항 시간 환원될 수 있어 적어도 NP 이상으로 어려운 문제 집합(결정 문제가 아니어도 성립).
- **Cook-Levin 정리**: SAT(Boolean Satisfiability) 문제가 최초의 NP-Complete 문제임을 증명한 계산 복잡도 이론의 기초 정리.

</details>

- **$\text{NP-Complete} = \text{NP} \cap \text{NP-Hard}$** 관계 성립
- 단 하나의 NP-Complete 문제라도 다항 시간($P$) 알고리즘이 발견되면 모든 NP 문제가 다항 시간에 풀려 **$P = NP$ 증명**
- 결정 문제의 **NP-완전** 및 최적화(Optimization) 문제의 **NP-난해(NP-Hard)** 분류 명확화

#### 한줄 요약

- 단 하나의 NP-Complete 문제에 대해 다항 시간 알고리즘이 도출될 경우 P=NP 명제가 증명되는 대표성을 보유한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **인증서(Certificate / Witness)**: 결정 문제의 '예(Yes)' 인스턴스에 대해 정답임을 즉시 입증할 수 있는 다항 크기의 보조 증거.
- **답 보존성(Answer Preservation)**: 원래 문제 $x \in A$의 정답이 'Yes'일 때 변환된 문제 $f(x) \in B$의 정답도 정확히 'Yes'가 되는 동치 관계.

</details>

```text
+--------------------------------------------------------+
|                   NP-완전성 증명 체계                  |
|  - NP 소속성(인증서 다항 검증) 및 NP-난해성(다항 환원) |
+---------------------------+----------------------------+
                            |
            +---------------+---------------+
            v                               v
+-----------------------+       +-----------------------+
|      NP 소속성 검증    |       |     NP-난해성 증명    |
|  - 다항 크기 인증서   |       |  - 기존 NP-C 문제 A   |
|  - DTM의 O(n^k) 검증   |       |  - 다항 환원 f: A -> B|
+-----------+-----------+       +-----------+-----------+
            |                               |
            +---------------+---------------+
                            v
+--------------------------------------------------------+
|                     답 동치성 검증                     |
|  - x in A <===> f(x) in B (양방향 필요충분조건 입증)   |
+--------------------------------------------------------+
```

선의 의미: 실선 박스는 NP-완전성 판정 구성 모듈, 화살표(->)는 인증서 검증 및 다항 환원 증명 흐름

| 구성요소 | 책임 |
|:---|:---|
| NP 소속 증명 | 다항 크기 인증서의 **다항 시간 검증** 입증 |
| NP-난해성 증명 | 기존 NP-C 문제로부터 **다항 환원** 입증 |
| 다항 변환 함수 | 입력을 $O(n^k)$ 시간에 **변환 인스턴스** 생성 |
| 답 동치성 검증 | $x \in A \iff f(x) \in B$ **양방향 필요충분** 성립 |

#### 한줄 요약

- 인증서 검증의 다항 시간성(NP 소속) 및 알려진 NP-Complete 문제로부터의 다항 시간 환원(NP-Hardness)을 상호 입증한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Karp의 21개 NP-완전 문제**: SAT로부터 3-SAT, Clique, Vertex Cover, Hamiltonian Cycle 등으로 이어지는 환원 체계.

</details>

```text
+------------------------------------------+
|  새로운 결정 문제 B의 NP-완전성 증명 요구 |
+--------------------+---------------------+
                     |
                     v
+------------------------------------------+
|  1. NP 소속 입증 (다항 검증 다항 인증서)  |
+--------------------+---------------------+
                     |
           /--------------------\
          <   인증서 검증 통과?  > -- No --> [ NP-Complete 판정 불가 ]
           \--------------------/
                     | Yes
                     v
+------------------------------------------+
|  2. 기존 NP-Complete 문제 A 선정 (3-SAT) |
+--------------------+---------------------+
                     |
                     v
+------------------------------------------+
|  3. 다항 시간 환원 함수 구성 (f: A -> B)  |
+--------------------+---------------------+
                     |
                     v
+------------------------------------------+
|  4. 양방향 답 동치성 증명 (x in A <=> f) |
+--------------------+---------------------+
                     |
                     v
+------------------------------------------+
|     문제 B의 NP-완전(NP-Complete) 확정   |
+------------------------------------------+
```

분기 결과: 다항 크기 인증서를 다항 시간에 검증하지 못하면 NP 소속성을 만족하지 않아 NP-완전 증명이 실패하며, NP 소속 입증 후 기존 NP-완전 문제로부터의 다항 환원과 답 동치성이 성립하면 NP-완전으로 최종 확정된다.

**동작 원리**:
1. **NP 소속 입증**: 문제 $B$의 임의 'Yes' 인스턴스에 대해 다항 크기의 인증서(Certificate)가 주어졌을 때, 결정론적 튜링 머신이 다항 시간 $O(n^k)$ 내에 유효성을 검증함을 입증한다.
2. **기존 NP-완전 기준 문제 선정**: 대상 문제 $B$와 구조적 제약이 유사하고 이미 NP-Complete임이 증명된 기준 문제 $A$(예: SAT, 3-SAT, Vertex Cover)를 선정한다.
3. **다항 시간 환원 함수 구성**: 문제 $A$의 임의 인스턴스 $x$를 문제 $B$의 인스턴스 $f(x)$로 변환하는 알고리즘 $f$를 설계하고, 이 변환이 다항 시간 내에 수행됨을 수학적으로 증명한다.
4. **답 동치성 양방향 증명**: 원래 인스턴스 $x \in A$가 참일 때 $f(x) \in B$가 성립함(정방향)과, $f(x) \in B$가 참일 때 $x \in A$가 성립함(역방향)을 양방향 필요충분조건으로 증명한다.
5. **NP-완전성 판정 확정**: $B \in \text{NP}$ 소속성과 $A \le_P B$를 통한 NP-Hardness가 동시에 확정되어 문제 $B$가 NP-Complete 클래스에 속함을 최종 결론짓는다.

#### 한줄 요약

- 다항 시간 인증서 검증 및 알려진 NP-Complete 인스턴스로부터의 다항 시간 환원과 답 동치성을 입증한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **결정론적 다항 시간(P Class)**: 결정론적 튜링 머신으로 다항 시간 $O(n^k)$ 내에 해결 가능한 문제들의 집합.
- **비결정론적 다항 시간(NP Class)**: 비결정론적 다항 시간에 풀리거나, 정답 인증서가 주어졌을 때 다항 시간 내에 검증 가능한 문제들의 집합.

</details>

| 복잡도 클래스 | NP-완전 | NP-난해 | NP | P |
|:---|:---|:---|:---|:---|
| 적용 기준 | **결정 문제** 완전성 증명 시 | 결정/최적화 무관 **NP-난해** 증명 시 | 다항 크기 **인증서** 검증 시 | **결정론적 다항 시간**에 해 산출 시 |
| 핵심 특징 | **$\text{NP} \cap \text{NP-Hard}$** 교집합 | 모든 NP 문제를 **다항 환원받음** | 'Yes' 답의 **다항 시간 검증** | **결정론적 다항 시간($O(n^k)$)** 해결 |
| 한계 | 일반 **다항 시간 해법** 미확립 | **NP 소속** 보장 없음 | 결정론적 풀이의 지수 시간 가능성 | 고차 다항식의 실용성 제한 |

#### 한줄 요약

- NP-완전 문제는 NP와 NP-난해의 교집합이며, 하나의 다항 시간 해법은 모든 NP 문제로 확장된다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **만족 가능성 솔버(SAT/SMT Solver)**: 수십만 개의 불리언 명제 및 배경 이론을 고속 해결하는 특화 추론 엔진(Z3 등).
- **다항 시간 근사 스킴(Polynomial-Time Approximation Scheme, PTAS)**: 임의의 오차 $\varepsilon > 0$에 대해 $(1+\varepsilon)$ 근사해를 다항 시간에 제공하는 알고리즘 체계.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 환원 방향 오류($B \le_P A$)로 인한 난해성 전달 실패 | 알려진 NP-Complete 문제에서 대상 문제로 환원($A \le_P B$) | 대상 문제의 **NP-난해성** 완벽 전달 |
| 변환의 **답 보존성** 결여로 환원 실패 | 양방향 필요충분조건($x \in A \iff f(x) \in B$) 엄격 검증 | 올바른 **다항 환원** 성립 |
| 최적화 문제와 결정 문제의 혼용으로 인한 개념 불일치 발생 | **임곗값 결정형**으로 변환 후 증명 | NP-완전과 NP-난해 개념 정합성 확보 |
| 실제 시스템의 NP-Hard 스케줄링/의존 충돌 | **SAT/SMT 솔버** 또는 **근사 알고리즘** 적용 | 실용적 시간 내 최적/준최적해 산출 |

#### 한줄 요약

- NP-완전 증명에서는 알려진 문제에서 대상으로의 환원 방향과 답 동치성을 반드시 검증하고, 실제 시스템에서는 SAT 솔버나 근사 알고리즘으로 실용적 해를 구한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **계산 복잡도 공학적 타협**: 문제의 NP-완전성을 입증한 후 다항 시간 최적해 추구를 중단하고, 휴리스틱(GA, SA), 근사 알고리즘, 특화 솔버로 신속히 전환하는 의사결정.

</details>

- 계산 복잡도 이론의 최대 난제($P \text{ vs } NP$)이자 소프트웨어 최적화 한계 분석의 근본 기준선으로 확립되어 널리 활용되고 있으며, 향후 양자 컴퓨팅(Shor, Grover) 및 초고속 병렬 가속기를 통한 특수 인스턴스 해결 구조로 확장될 것으로 전망되고, 실무 엔지니어링에서는 대상 문제의 NP-완전성을 입증한 즉시 지수 시간 전수 탐색을 중단하고, SAT/SMT 솔버(Z3), 품질 보장 근사 알고리즘(PTAS) 및 메타휴리스틱으로 전환하여 실용적 시간 내에 준최적해를 확보해야 한다.

#### 한줄 요약

- 결정형은 특화 솔버로 판정하고, 최적화형은 품질 경계가 있는 근사 알고리즘을 우선한다.
