## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **그래디언트 부스팅**: 현재 손실의 기울기를 줄이는 보정 트리를 순차적으로 누적하는 앙상블 방식이다.
- **정형 데이터**: 행과 열의 고정된 스키마로 구성된 표 형태의 데이터이다.
- **익스트림 그래디언트 부스팅(eXtreme Gradient Boosting, XGBoost)**: 레벨 단위 성장과 정규화를 적용한 부스팅 구현이다.
- **경량 그래디언트 부스팅 머신(Light Gradient Boosting Machine, LightGBM)**: 리프 단위 성장으로 대규모 학습을 최적화한 구현이다.

</details>

- 정의/개념: **XGBoost**와 **LightGBM**은 이전 트리의 잔여 손실 기울기를 새 트리가 보완하는 그래디언트 부스팅을 정규화•병렬 분할 탐색 등으로 최적화한 구현이다.
- 배경/필요성: 부스팅은 트리를 순차 누적하고 매 단계에서 분할 후보를 반복 탐색하므로 대규모 정형 데이터에서 학습 시간과 메모리 비용이 커진다.

#### 한줄 요약
- 앞 트리의 잔차에 대해 그래디언트를 산출하고 이를 보정하는 트리를 순차적으로 누적한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **그래디언트(Gradient)**: 손실 변화 방향을 나타내는 1차 미분값이다.
- **헤시안(Hessian)**: 손실 곡률을 나타내는 2차 미분값이다.
- **정규화**: 모델 복잡도에 벌점을 부과해 학습 데이터 과적합을 줄이는 방법이다.
- **학습률**: 새 보정 트리의 예측을 기존 모델에 반영하는 비율이다.
- **1•2차 미분값**: 손실의 변화 방향과 곡률을 나타내는 그래디언트와 헤시안이다.
- **정규화 항**: 트리 수•리프 가중치•복잡도에 벌점을 부과하는 목적 함수 항이다.

</details>

- 손실의 **그래디언트**•**헤시안**인 **1•2차 미분값**에 기반해 오차를 순차 보정한다.
- **정규화 항**을 목적 함수에 넣어 트리 복잡도를 직접 통제한다.
- **학습률**을 낮추면 트리 한 그루의 기여도가 작아져 더 많은 트리가 필요하지만 과적합을 완화할 수 있다.

#### 한줄 요약
- 그래디언트와 헤시안으로 최적 분할을 선택하고, 복잡한 트리 구조에는 정규화 항으로 벌점을 부과한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **목적 함수**: 예측 손실과 트리 복잡도 벌점을 합쳐 최소화하는 함수이다.
- **분할 이득**: 노드를 둘로 나눴을 때 목적 함수가 감소하는 정도이다.
- **조기 종료**: 검증 성능이 더 좋아지지 않으면 트리 추가를 멈추는 방식이다.
- **검증 성능**: 학습에 사용하지 않은 데이터에서 측정한 예측 성능이다.

</details>

```text
[목적 함수] -- [트리 학습기] -- [앙상블 모델]
                                      |
                                [검증 평가기]
```

선의 의미: 트리 학습기가 목적 함수의 미분값을 사용하고, 앙상블 모델이 보정 트리를 보유하며 검증 평가기가 모델 예측을 참조하는 정적 의존 관계다.

| 구성요소 | 책임 |
|:---|:---|
| 목적 함수 | 현재 예측•정답•정규화 항에서 **그래디언트**•**헤시안** 산출 |
| 트리 학습기 | 손실 미분값으로 **분할 이득** 최대 보정 트리 생성 |
| 앙상블 모델 | 누적 트리와 **학습률**로 현재 예측 산출 |
| 검증 평가기 | 새 트리 전후의 **검증 성능**을 비교해 조기 종료 판단 |

#### 한줄 요약
- 목적 함수가 그래디언트·헤시안을 산출하면 트리 학습기가 보정 트리를 생성하고 검증 평가기가 조기 종료를 판단한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **보정 트리**: 현재 모델의 오차 방향을 예측해 기존 결과를 개선하는 다음 트리이다.
- **검증 데이터**: 학습에 직접 쓰지 않고 일반화 성능 개선 여부를 평가하는 데이터이다.
- **현재 예측 산출**: 누적한 모든 트리의 출력을 더해 현 단계의 예측값을 구하는 단계이다.
- **그래디언트•헤시안 계산**: 현재 예측에서 손실의 1차•2차 미분값을 구하는 단계이다.
- **보정 트리 생성**: 분할 이득이 큰 조건을 골라 현재 오차를 줄일 새 트리를 만드는 단계이다.
- **학습률로 트리 누적**: 보정 트리 출력에 학습률을 곱해 기존 앙상블 예측에 더하는 단계이다.
- **검증 성능 평가**: 검증 데이터에서 성능 개선이 멈췄는지 확인하는 단계이다.

</details>

```text
[초기 예측과 학습•검증 데이터]
              |
              v
+------------------------------------+
| 검증 성능이 개선되는 동안          |
|                                    |
|  1. 현재 예측 산출                 |
|             |                      |
|             v                      |
|  2. 그래디언트•헤시안 계산         |
|             |                      |
|             v                      |
|  3. 보정 트리 생성                 |
|             |                      |
|             v                      |
|  4. 학습률로 트리 누적             |
|             |                      |
|             v                      |
|  5. 검증 성능 평가                 |
|             |                      |
|             `-- 개선 시 반복 ------|
+------------------------------------+
              |
              v
[조기 종료된 앙상블 모델]
```

### 동작 원리

- **1. 현재 예측 산출**: 누적 트리의 학습 표본 예측을 계산한다.
- **2. 그래디언트•헤시안 계산**: 손실의 방향과 곡률을 산출한다.
- **3. 보정 트리 생성**: 최대 분할 이득으로 트리를 구성한다.
- **4. 학습률로 트리 누적**: 보정 예측을 앙상블에 반영한다.
- **5. 검증 성능 평가**: 개선 정체 여부에 따라 조기 종료한다.

#### 한줄 요약
- 현재 예측에서 그래디언트·헤시안을 계산하고 트리 학습기가 보정 트리를 생성하여 검증 성능이 정체될 때까지 앙상블에 누적한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **레벨 단위 성장**: 같은 깊이의 노드를 고르게 분할하며 트리를 키우는 방식이다.
- **리프 단위 성장**: 손실 감소가 가장 큰 리프를 우선 분할해 깊게 키우는 방식이다.
- **그래디언트 기반 단측 샘플링(Gradient-based One-Side Sampling, GOSS)**: 큰 그래디언트 표본을 우선 유지하는 샘플링이다.
- **상호 배타적 특성 묶기(Exclusive Feature Bundling, EFB)**: 동시에 값이 없는 희소 특성을 묶는 기법이다.
- **고차원 희소 특징**: 특징 수는 많지만 각 표본에서 값이 있는 특징은 일부뿐인 입력이다.
- **깊은 리프 과적합**: 이득이 큰 리프를 반복 분할해 소수 표본과 잡음까지 학습한 상태이다.

- **기울기 기반 단면 샘플링(Gradient-based One-Side Sampling, GOSS)**: 기울기가 큰 표본은 유지하고 작은 표본은 무작위 샘플링하여 학습 데이터 수를 줄이는 기법.
- **배타적 특성 묶음(Exclusive Feature Bundling, EFB)**: 상호 배타적인(동시에 0이 아닌 값이 드문) 희소 특성들을 하나의 특성으로 묶어 차원을 축소하는 기법.
</details>

| 그래디언트 부스팅 구현 | XGBoost | LightGBM |
|:---|:---|:---|
| 적용 기준 | 중소 규모 데이터에서 균형 잡힌 성장이 필요한 경우 | 대규모•**고차원 희소 특징**을 빠르게 처리하는 경우 |
| 핵심 특징 | **레벨 단위 성장** | **리프 단위 성장**•**GOSS**•**EFB** |
| 한계 | 대용량에서 학습 시간•메모리 증가 | 소량 데이터의 **깊은 리프 과적합** |

> 요약: **GOSS**•**EFB**로 학습량을 줄인 LightGBM이 핵심이다.

#### 한줄 요약
- XGBoost는 레벨 단위로 균형 성장하고, LightGBM은 분할 이득이 큰 리프를 우선 분할한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **리프 최소 표본 수**: 리프 하나가 가져야 하는 최소 표본 수로 깊은 가지의 과적합을 제한하는 값이다.
- **스키마 검증**: 열 이름•자료형•범주•결측 허용 규칙이 학습 때와 같은지 확인하는 절차이다.
- **분산 학습**: 데이터나 트리 계산을 여러 장치에 나누어 병렬로 학습하는 방식이다.
- **전처리 규칙**: 범주형 값과 결측값을 모델 입력으로 변환하는 고정된 처리 기준이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 학습 성능만 계속 개선 | 검증 집합 기반 **조기 종료**•학습률 축소 | 과적합과 불필요한 트리 누적 방지 |
| LightGBM의 **깊은 리프 과적합** | 최대 깊이•**리프 최소 표본 수**•리프 수 제한 | 소량 데이터 일반화 향상 |
| 대규모 학습의 메모리•시간 증가 | LightGBM의 **GOSS**•**EFB** 또는 **분산 학습** 검토 | 정형 데이터 처리량 확대 |
| 범주형•결측값 처리 불일치 | 학습•추론 **전처리 규칙** 고정과 **스키마 검증** | 운영 예측 재현성 확보 |

#### 한줄 요약
- 검증 성능이 더 이상 개선되지 않으면 조기 종료로 보정 트리 추가를 중단한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **성장 방식 선택**: 데이터 규모•희소도와 리프 과적합 위험을 함께 비교해 부스팅 구현을 고르는 기준이다.

</details>

- **성장 방식 선택** 기준에 따라 중소 규모는 **XGBoost**, 대규모 희소 데이터는 **LightGBM**을 선택한다.

#### 한줄 요약
- 중소 규모 정형 데이터는 XGBoost, 대규모 희소 데이터는 GOSS•EFB 기반 LightGBM을 선택한다.
