## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **나이브 베이즈 분류기(Naive Bayes Classifier)**: 모든 특징(Feature) $x_1, \dots, x_D$가 타깃 클래스 $y$가 주어졌을 때 상호 조건부 독립(Conditional Independence)이라는 '순진한(Naive)' 가정 하에 베이즈 정리를 적용하는 확률 생성 분류 모델.
- **최대 사후 확률 추정(MAP, Maximum A Posteriori)**: 사후 확률 $P(y|x) \propto P(y) \prod P(x_i|y)$을 최대화하는 클래스 $\hat{y} = \arg\max P(y|x)$를 예측값으로 선정하는 의사결정 규칙.
- **조건부 독립(Conditional Independence)**: 클래스 $y$가 주어지면 특징 $x_i$와 $x_j$ 간에 어떠한 상관관계도 존재하지 않는다는 통계적 가정 ($P(x_1, x_2|y) = P(x_1|y)P(x_2|y)$).

</details>

- 정의/개념: 클래스 조건부 독립 가정을 통해 고차원 결합 확률을 단일 특징 우도들의 단순 곱($\prod P(x_i|y)$)으로 분해하여 최대 사후 확률(MAP)을 산출하는 **고속 확률 분류기**
- 배경/필요성: 고차원 텍스트 데이터에서 모든 특징 조합의 결합 확률 분포 추정 시 발생하는 **차원의 저주(Curse of Dimensionality) 극복 및 극소 연산량 분류기 구현 필수**

#### 한줄 요약

- 특징 간 조건부 독립 가정을 바탕으로 사전 확률과 개별 우도의 곱을 통해 사후 확률을 최대화

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **라플라스 스무딩(Laplace Smoothing / Add-1)**: 훈련 데이터에 한 번도 등장하지 않은 단어로 인해 전체 우도 곱이 0이 되는 영확률 문제(Zero Frequency Problem)를 방지하기 위해 분자와 분모에 가상 빈도($\alpha=1$)를 더해주는 보정 기법.
- **로그 우도 합산(Log-Likelihood Summation)**: 수백 개 확률($P \ll 1$)의 연속 곱으로 인한 부동소수점 언더플로(Underflow)를 방지하기 위해 로그 공간에서의 덧셈($\log P(y) + \sum \log P(x_i|y)$)으로 변환하는 수치 기법.

</details>

- 결합 확률의 단순 곱 분해를 통한 **선형 시간 복잡도($O(N \cdot D)$)의 초고속 학습 및 추론**
- 극소량의 훈련 데이터로도 각 특징별 단변량 확률 파라미터의 **안정적 모수 추정 가능**
- 특징 간 상관관계가 강하게 존재할 경우 **사후 확률의 절대 수치가 0이나 1로 극단 과신(Overconfidence)되는 결함**

#### 한줄 요약

- 선형 계산량으로 고속 분류를 수행하며, 라플라스 스무딩과 로그 합산으로 영확률과 언더플로를 방지

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **나이브 베이즈 확률 파라미터 구조**:
  - 사전 확률 테이블 ($P(y)$): 각 클래스의 출현 빈도 비율.
  - 우도 모델 ($P(x_i|y)$): 클래스 $y$ 하에서 각 특징 $x_i$의 생성 확률 모델(Gaussian/Multinomial/Bernoulli).

</details>

```text
[ 나이브 베이즈 분류 엔진 아키텍처 ]
 입력 특징 벡터 x = (x1, x2,.., xD)
         │
         ▼
 ┌───────────────────────────────────────────────────────────┐
 │ 로그 우도 연산기: ∑ log P(x_i | y_k)  (k = 1.. K)       │ ◄── 라플라스 스무딩 적용
 └─────────────────────────────┬─────────────────────────────┘
                               │
                               ▼
 ┌───────────────────────────────────────────────────────────┐
 │ 로그 사후점수 합산: Score(y_k) = log P(y_k) + ∑ log P(x_i|y_k) │
 └─────────────────────────────┬─────────────────────────────┘
                               │
                               ▼
 ┌───────────────────────────────────────────────────────────┐
 │ MAP 클래스 판정기: y_hat = argmax_k Score(y_k)             │ ──► 최종 예측 클래스 출력
 └───────────────────────────────────────────────────────────┘
```

선의 의미: 입력 특징 벡터 인입, 로그 우도 합산, 로그 사후점수 계산 및 MAP 판정 파이프라인.

| 구성요소 | 책임 |
|:---|:---|
| 확률 추정기 | 훈련 데이터 빈도 카운팅으로 **사전 확률 $P(y)$ 및 우도 $P(x_i|y)$ 추정** |
| 스무딩 엔진 | 미등장 특징에 가상 빈도를 더해 **영확률($P=0$) 결함 원천 차단** |
| 로그 합산기 | 확률 곱을 로그 합산으로 변환하여 **부동소수점 수치 언더플로 방지** |
| MAP 분류기 | 계산된 로그 사후점수가 가장 큰 **최대 사후 확률 클래스($\hat{y}$) 확정** |

#### 한줄 요약

- 확률 추정기가 우도표를 만들고, 로그 합산과 MAP 판정기가 최대 사후 확률 클래스를 도출

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **다항 나이브 베이즈 우도 식**: $P(x_i|y) = \frac{N_{yi} + \alpha}{N_y + \alpha D}$ ($N_{yi}$: 클래스 $y$에서 단어 $i$ 빈도, $N_y$: 클래스 $y$ 전체 단어 수, $D$: 어휘 사전 크기).

</details>

```text
라벨링된 훈련 텍스트/데이터셋 (X, y)
   │
   ▼
[ 1. 클래스별 사전 확률 P(y) 및 특징별 조건부 우도 P(x_i|y) 빈도 집계 ]
   │
   ▼
[ 2. 라플라스 스무딩 (α=1.0) 적용 및 로그 확률 테이블 사전 구축 ]
   │
   ▼
새로운 테스트 문서/표본 x_test 인입
   │
   ▼
[ 3. 각 클래스 y_k에 대해 로그 사후 점수 연산 ]
│    Score(y_k) = log P(y_k) + ∑_(i=1)^D log P(x_i_test | y_k)
   │
   ▼
[ 4. 최대 점수 클래스 선택: y_pred = argmax_k Score(y_k) ]
```

**동작 원리**

1. **빈도 집계**: 훈련 데이터를 1회 스캔하여 클래스별 샘플 수 및 특징 출현 빈도 산출
2. **스무딩 확률 테이블 구축**: 라플라스 스무딩을 적용하여 0이 없는 확률 룩업 테이블 생성
3. **로그 사후 점수 합산**: 신규 입력 벡터에 대해 클래스별 로그 사전 확률과 특징 로그 우도를 단순 덧셈
4. **MAP 판정**: 가장 높은 로그 점수를 획득한 클래스를 최종 예측 결과로 반환

#### 한줄 요약

- 사전 확률과 우도를 테이블로 구축하고, 신규 입력에 대해 로그 우도를 합산하여 최대 클래스를 판정

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **나이브 베이즈 3대 변형 모델**:
  - 가우시안 NB: $x_i \sim N(\mu_{yi}, \sigma_{yi}^2)$, 연속형 실수(센서, 신체 측정값).
  - 다항(Multinomial) NB: $x_i \in \{0, 1, 2, \dots\}$, 단어 빈도수(TF/TF-IDF) 기반 텍스트.
  - 베르누이(Bernoulli) NB: $x_i \in \{0, 1\}$, 단어 출현 유무(이진 플래그) 기반 짧은 텍스트.

</details>

| 비교 항목 | 가우시안 나이브 베이즈 (Gaussian) | 다항 나이브 베이즈 (Multinomial) | 베르누이 나이브 베이즈 (Bernoulli) |
|:---|:---|:---|:---|
| 특징 데이터 타입 | **연속형 실수 (Continuous)** | **이산형 출현 빈도수 (Counts / TF)** | **이진 유무 플래그 (Binary 0/1)** |
| 우도 모델링 | $P(x_i\|y) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ | 다항분포 $P(x_i\|y) = \frac{N_{yi}+\alpha}{N_y+\alpha D}$ | 베르누이 $P(x_i\|y) = p_{yi}^{x_i}(1-p_{yi})^{1-x_i}$ |
| 부재(0) 특징 처리 | 평균과의 거리에 따른 확률 계산 | **출현하지 않은 단어는 계산 제외** | **부재(0)했다는 사실 자체도 확률에 곱함** |
| 주요 적용처 | 센서 측정값, 금융 수치 지표 | **긴 텍스트 문서 분류, 스팸 메일 필터** | **짧은 텍스트(트윗, SMS), 감성 분석** |

#### 한줄 요약

- 연속 수치는 가우시안, 단어 빈도 카운트는 다항, 이진 유무는 베르누이 나이브 베이즈를 적용

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **플랫 캘리브레이션(Platt Scaling / Isotonic Regression)**: 나이브 베이즈가 출력하는 왜곡된 사후 확률을 로지스틱 회귀로 재교정하여 실제 신뢰도 확률과 일치시키는 확률 보정 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 훈련셋에 없는 단어 등장으로 **전체 사후확률이 0이 되는 현상** | **라플라스 스무딩(Laplace Smoothing, $\alpha=1.0$)** 적용 | 미관측 단어의 영확률 결함 완벽 방지 |
| 수백 개 확률의 연속 곱으로 인한 **부동소수점 언더플로** | `log_prob` 기반 **로그 우도 합산 연산** 전환 | 수치적 오버플로/언더플로 원천 차단 |
| 특징 간 강한 상관관계로 인한 **사후 확률의 극단적 왜곡(과신)** | **Platt Scaling / Isotonic Regression 확률 교정** | 예측 확률의 통계적 신뢰성 복원 |
| 다국어 텍스트 처리 시 어휘 폭증으로 인한 메모리 증가 | **카운트 기반 해싱 트릭(HashingVectorizer)** 적용 | 고정된 메모리 내 초고속 텍스트 분류 |

#### 한줄 요약

- 영확률 문제는 라플라스 스무딩으로 차단하고, 곱셈 언더플로는 로그 합산으로 방지하며, 확률 교정에는 Platt Scaling을 적용하고, 고차원 입력은 해싱 트릭으로 고속화한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **초경량 베이스라인 모델 표준**: 대규모 딥러닝 도입 전, 텍스트 스팸 필터링, 실시간 감성 분석, 네트워크 침입 탐지(IDS) 등에서 나이브 베이즈는 밀리초 미만의 초고속 추론을 제공하는 최고의 베이스라인으로 활용.

</details>

- 연속 수치 데이터는 **Gaussian NB**, 단어 빈도/카운트는 **Multinomial NB**, 이진 유무는 Bernoulli NB 선택

#### 한줄 요약

- 입력 데이터의 수치 속성에 맞춰 나이브 베이즈 유형을 선택하고 라플라스 스무딩을 필수 적용
