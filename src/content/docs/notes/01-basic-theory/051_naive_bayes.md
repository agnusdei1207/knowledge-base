## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **나이브 베이즈(Naive Bayes)**: 모든 특징이 클래스 조건부로 상호 독립이라는 단순화된 가정을 적용하는 베이지안 확률 분류기.
- **베이즈 정리(Bayes' Theorem)**: 사전 확률과 우도를 결합하여 관측 데이터에 대한 사후 확률을 갱신하는 조건부 확률 정리($P(Y|X) = P(X|Y)P(Y)/P(X)$).
- **최대 사후 확률(Maximum A Posteriori, MAP)**: 사후 확률을 최대화하는 클래스를 예측 클래스로 결정하는 판정 기준.

</details>

- 정의/개념: 모든 특징이 클래스 조건부로 서로 독립이라는 가정 하에 **베이즈 정리** 및 **사후 확률 최대화(MAP)** 원리 기반 확률적 분류 알고리즘
- 배경/필요성: 고차원 희소 데이터 분류 시 특징 간 결합 확률 계산의 차원의 저주 및 연산 복잡도 폭증을 단순화된 확률 곱 연산으로 해결 필요

#### 한줄 요약

- 조건부 독립 가정을 기반으로 사전 확률과 우도를 곱하여 사후 확률이 가장 높은 클래스를 판정하는 모델

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **조건부 독립(Conditional Independence)**: 클래스 $Y$가 주어졌을 때 특징 $X_i$와 $X_j$가 통계적으로 독립이라는 가정($P(X_1, X_2|Y) = P(X_1|Y)P(X_2|Y)$).
- **로그 우도(Log-Likelihood)**: 작은 확률값들의 연속 곱셈 시 발생하는 언더플로우를 방지하기 위해 확률에 로그를 취해 덧셈으로 변환한 값.

</details>

- **특징 간 조건부 독립(Conditional Independence)** 가정을 통한 연산 복잡도의 $O(2^d) \to O(d)$ 획기적 단순화
- 적은 훈련 표본으로도 빠르고 안정적인 **파라미터 추정 및 초고속 추론** 제공
- 특징 간 상호작용을 배제함에 따른 **사후 확률 추정치의 편향(극단화)** 내재

#### 한줄 요약

- 연산이 매우 빠르고 고차원 텍스트에 강하지만, 특징 간 상관관계를 무시하는 단순화 한계를 내포

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **사전 확률(Prior Probability)**: 새로운 관측치 없이 특정 클래스가 발생할 기저 확률($P(Y)$).
- **우도(Likelihood)**: 특정 클래스 $Y$가 주어졌을 때 해당 특징 $X_i$가 나타날 조건부 확률($P(X_i|Y)$).

</details>

```text
[ 관측 특징 벡터 X = (x1, x2, ..., xd) ]
                 │
  ┌──────────────┴──────────────┐
  ▼                             ▼
[ 클래스 C_1 평가 ]           [ 클래스 C_k 평가 ]
├─ 사전 확률: P(C_1)           ├─ 사전 확률: P(C_k)
└─ 우도 곱: ∏ P(x_i|C_1)       └─ 우도 곱: ∏ P(x_i|C_k)
  │                             │
  └──────────────┬──────────────┘
                 ▼
     [ MAP 결정 판정기 (arg max) ] ──► 최종 예측 클래스 C*
```

선의 의미: 특징별 우도 계산 및 사전 확률 결합을 통한 최종 사후 확률 산출 관계

| 구성요소 | 책임 |
|:---|:---|
| 사전 확률 계산기 | 훈련 데이터셋 내 클래스별 출현 빈도($P(Y)$) 추정 |
| 우도 추정기 | 클래스 조건부 단일 특징들의 발생 확률($P(X_i \mid Y)$) 계산 |
| 사후 확률 결합기 | 결합 독립 가정에 따른 **로그 확률 덧셈 변환($\log P(Y) + \sum \log P(X_i \mid Y)$)** |
| MAP 판정기 | 결합 사후 확률이 최대인 **최적 클래스($\arg\max$) 도출** |

#### 한줄 요약

- 클래스 사전 확률과 특징별 우도를 결합하여 MAP 판정기로 최적 클래스를 결정

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **라플라스 스무딩(Laplace Smoothing)**: 훈련 세트에 없는 미관측 특징의 출현 확률이 0이 되는 것을 방지하기 위해 분자와 분모에 가상 빈도($\alpha$)를 더해 보정하는 기법.

</details>

```text
입력 텍스트/데이터 수신
          │
          ▼
[ 1. 특징 추출 및 토큰화 ]
          │
          ▼
[ 2. 클래스별 사전 확률 조회 ]
          │
          ▼
[ 3. 라플라스 스무딩 적용 우도 계산 ] ──► 0 빈도 확률 전파 차단
          │
          ▼
[ 4. 로그 사후 확률 합산 ]
          │
          ▼
[ 5. MAP 판정 및 클래스 출력 ]
```

**동작 원리**

1. **특징 추출 및 토큰화**: 원시 텍스트나 데이터를 특징 벡터($x_1, \dots, x_d$)로 변환
2. **클래스별 사전 확률 조회**: 사전에 계산된 클래스별 기저 확률($\log P(C)$) 로드
3. **라플라스 스무딩 적용 우도 계산**: 미관측 단어 오차를 방지하며 특징별 우도($P(x_i|C)$) 산출
4. **로그 사후 확률 합산**: 곱셈 대신 로그 덧셈을 수행하여 수치적 언더플로우 방지
5. **MAP 판정 및 클래스 출력**: 가장 높은 사후 확률 합산값을 가진 클래스로 분류 확정

#### 한줄 요약

- 특징을 토큰화하고 라플라스 스무딩과 로그 합산을 적용하여 최대 확률 클래스를 출력

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **다항 나이브 베이즈(Multinomial Naive Bayes)**: 단어의 출현 빈도수를 특징으로 사용하는 텍스트 분류 모델.
- **베르누이 나이브 베이즈(Bernoulli Naive Bayes)**: 단어의 등장 유무(0 또는 1)를 이진 특징으로 사용하는 모델.
- **가우시안 나이브 베이즈(Gaussian Naive Bayes)**: 연속형 수치 특징이 정규분포를 따른다고 가정하는 모델.

</details>

| 나이브 베이즈 모델 | 다항 나이브 베이즈 | 베르누이 나이브 베이즈 | 가우시안 나이브 베이즈 |
|:---|:---|:---|:---|
| 적용 기준 | **단어 출현 빈도수** 중요 장문 텍스트 분류 시 | **단어 출현 유무(이진값)** 중심의 단문 텍스트 분류 시 | 연속형 실수 특징으로 구성된 **수치 데이터 분류** 시 |
| 핵심 특징 | 다항 분포 기반 **토큰 발생 횟수 가중치** 반영 | 베르누이 분포 기반 **단어의 부재 정보까지 반영** | 정규분포 모수(평균·분산) 추정을 통한 **우도 계산** |
| 한계 | 문서 길이에 따른 **빈도수 왜곡 가능성** | 긴 문서에서 **빈도 정보 유실** | 실제 데이터의 **비정규분포 시 성능 저하** |

#### 한줄 요약

- 단어 빈도는 다항 모델, 출현 유무는 베르누이 모델, 연속형 수치는 가우시안 모델을 선택

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **제로 빈도 문제(Zero Frequency Problem)**: 훈련 세트에 없는 단어가 테스트 시 등장하면 전체 확률 곱이 0이 되어 분류가 불가능해지는 현상.
- **언더플로우(Arithmetic Underflow)**: 컴퓨터의 부동소수점 표현 한계보다 작은 확률값들이 연속 곱해져 0으로 수렴하는 현상.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 미관측 단어로 인한 확률 0 전파의 **제로 빈도 문제** | **라플라스 스무딩(Laplace Smoothing, $\alpha=1$) 적용** | 0 확률 방지 및 미관측 특징 일반화 |
| 다수 확률 곱셈 시 발생하는 **수치 언더플로우** | **로그 확률 변환($\sum \log P$) 기반 덧셈 연산 전환** | 부동소수점 연산 안정성 및 정밀도 확보 |
| 특징 간 강한 상관관계로 인한 **사후 확률 왜곡** | **상관 특징 사전 필터링 및 로지스틱 회귀로 전환** | 편향 완화 및 분류 신뢰도 개선 |

#### 한줄 요약

- 제로 빈도는 라플라스 스무딩으로, 언더플로우는 로그 합산으로, 특징 상관관계는 사전 필터링으로 해결

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **기준선 모델(Baseline Model)**: 시스템의 초기 성능 기준점을 빠르게 잡기 위해 배포하는 단순하고 신속한 모델.

</details>

- 스팸 메일 필터링 및 대규모 텍스트 분류 과업에서는 라플라스 스무딩을 적용한 다항 나이브 베이즈를 경량 기준선 모델로 우선 채택하고, 특징 간 비선형 상관관계가 지배적인 복합 정형 과업에서는 트리 앙상블 모델로 전환하는 전략이 타당

#### 한줄 요약

- 고차원 희소 텍스트에서는 나이브 베이즈의 경량성을 취하고, 복잡한 정형 과업에서는 트리 앙상블로 전환
