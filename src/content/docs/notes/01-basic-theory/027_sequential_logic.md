## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **순차 논리 회로(Sequential Logic Circuit)**: 플립플롭(Flip-Flop)이나 래치(Latch) 등 내부 메모리 소자를 구비하여 현재 입력뿐만 아니라 이전 상태(State)를 피드백받아 다음 상태와 출력을 결정하는 동기식/비동기식 회로.
- **상태 전이(State Transition)**: 현재 상태 $Q(t)$와 입력 $X$의 조합에 의해 다음 클록 엣지에서 레지스터에 저장될 $Q(t+1)$로 전이되는 과정.
- **클록 엣지(Clock Edge)**: 플립플롭이 데이터를 래치(Latch)하는 순간적인 상승(Rising/Posedge) 또는 하강(Falling/Negedge) 전압 전이 시점.

</details>

- 정의/개념: 현재 입력과 피드백된 저장 상태를 조합하여 다음 상태와 출력을 생성하고 **클록 엣지**에 동기화하여 갱신하는 유한 상태 기계(FSM) 회로
- 배경/필요성: 조합 논리 회로의 과거 상태 보존 불가능성과 비동기 신호 레이스 조건(Race Condition)으로 인한 순차 제어 불확실성 한계

#### 한줄 요약

- 이력을 얻은 대가로 셋업·홀드·스큐라는 시간 제약이 새로 붙어, 설계의 한계가 게이트 지연에서 클록 주기로 옮겨간다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **셋업 타임(Setup Time, $t_{setup}$)**: 클록 엣지가 발생하기 직전에 입력 데이터가 안정적으로 유지되어야 하는 최소 시간.
- **홀드 타임(Hold Time, $t_{hold}$)**: 클록 엣지가 발생한 직후에 입력 데이터가 변하지 않고 유지되어야 하는 최소 시간.
- **클록 스큐(Clock Skew, $t_{skew}$)**: 클록 분배망(CTS)의 배선 지연 차이로 인해 서로 다른 플립플롭에 클록 엣지가 도달하는 시각의 편차.

</details>

- 이전 상태를 저장하고 피드백하는 **상태 메모리(플립플롭/레지스터) 구비**
- **동기식 클록 엣지(Posedge Clk)** 를 기준으로 모든 플립플롭의 상태를 일제히 갱신
- **셋업 시간, 홀드 시간 및 클록 스큐** 제약에 의해 회로의 최대 동작 주파수 결정

$$
T_{clk} \ge t_{cq} + t_{comb\_max} + t_{setup} - t_{skew}
$$

#### 한줄 요약

- 셋업/홀드 시간 제약과 클록 스큐를 준수하여 엣지 단위로 동기화된 상태 전이를 수행한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **밀리 머신(Mealy Machine)**: 출력이 현재 상태와 현재 입력 모두에 종속되는 FSM 구조.
- **무어 머신(Moore Machine)**: 출력이 오직 현재 상태에만 종속되는 FSM 구조.

</details>

```text
[동기식 순차 논리 회로]
  │
  ├─ [조합 상태 논리부] (다음 상태 및 출력 연산)
  │     ├─ 다음 상태 논리 (f(Q, X) 상태 전이 D 입력 연산)
  │     └─ 출력 생성 논리 (Mealy g(Q,X) / Moore g(Q) 신호 생성)
  │
  ├─ [상태 기억 저장부] (클록 동기 상태 레지스터)
  │     ├─ D 플립플롭 배열 (비트별 이진 상태 메모리)
  │     └─ 피드백 전송선 (현재 상태 Q를 조합 논리로 피드백)
  │
  └─ [클록 분배 제어부] (CTS 및 타이밍 동기화)
        ├─ 클록 트리 합성 (배선 지연 균일화 CTS)
        └─ 타이밍 제어기 (셋업/홀드 마진 및 스큐 통제)
```

- 선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 다음 상태 논리 | 현재 상태($Q$)와 입력($X$)을 조합하여 **다음 상태($D$)** 연산 |
| 상태 레지스터 | 클록 엣지에서 $D$ 입력을 받아 **현재 상태 $Q$로 래치 및 보존** |
| 출력 생성 논리 | 현재 상태($Q$) 및 입력($X$)에 기반한 **외부 제어 신호 $Y$ 생성** |
| 클록 분배망 (CTS) | 모든 레지스터에 정밀하고 균일한 **동기 클록 신호(Clk)** 공급 |

#### 한줄 요약

- 다음 상태 논리가 전이값을 계산하고, 상태 레지스터가 클록 엣지에 저장한 뒤 출력 논리가 외부 신호를 생성한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **메타안정성(Metastability)**: 셋업/홀드 타임 위반으로 플립플롭 내부 전압이 0과 1 사이의 불안정 평형점에 머물며 시스템 오작동을 유발하는 현상.

</details>

```text
+------------------------------------------+
|  클록 주기 시작 (현재 상태 Q, 입력 X)   |
+--------------------+---------------------+
                     |
                     v
+------------------------------------------+
|  1. 다음 상태 논리 연산 (D = f(Q, X))    |
+--------------------+---------------------+
                     |
                     v
+------------------------------------------+
|  2. 셋업 시간(tsetup) 동안 D 신호 안정화  |
+--------------------+---------------------+
                     |
                     v
           /--------------------\
          <   클록 엣지 타이밍? >
           \--------------------/
            |                  |
 셋업/홀드 위반|                  | 타이밍 만족
            v                  v
[ 메타안정성 발생/에러 ]     [ 상태 레지스터 D -> Q 래치 ]
                               |
                               v
                     [ 3. 다음 상태 및 출력 반영 ]
```

분기 결과: 클록 엣지 전후로 셋업/홀드 타임을 위반하면 플립플롭이 0과 1 사이의 중간 전압에 머무는 메타안정성에 빠져 시스템 에러를 유발하며, 타이밍 마진을 만족하면 안정적으로 다음 상태 $Q$를 래치하여 출력을 갱신한다.

**동작 원리**:
1. **상태 및 입력 샘플링**: 현재 상태 레지스터에 저장된 상태 벡터 $Q(t)$와 외부 입력 $X(t)$가 다음 상태 조합 논리 회로로 전달된다.
2. **다음 상태 및 출력 연산**: 조합 논리망을 통해 다음 클록에 전이될 후보 상태 $D(t)$와 현재 출력 $Y(t)$를 계산한다.
3. **셋업 시간 안정화 유지**: 다음 상태 신호 $D$가 클록 상승 엣지 도달 전 최소 셋업 시간($t_{\text{setup}}$) 동안 일정한 논리 전압 레벨로 안정화되어 유지된다.
4. **클록 상승 엣지 동기 래치**: 클록 신호의 상승 에지 순간에 플립플롭 내부 전송 게이트가 열리며 $D$ 신호가 내부 메모리 노드로 래치된다.
5. **홀드 마진 충족 및 상태 갱신**: 클록 엣지 이후 최소 홀드 시간($t_{\text{hold}}$) 동안 입력이 유지된 후, 클록-Q 전파 지연($t_{cq}$)을 거쳐 레지스터 출력 $Q(t+1)$이 새로운 현재 상태로 외부 및 피드백 경로에 반영된다.

#### 한줄 요약

- 조합 논리가 다음 상태를 계산하고, 셋업 타임 만족 후 클록 엣지에 맞춰 레지스터가 상태를 갱신한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **플립플롭(Flip-Flop)**: 클록 엣지 순간에만 입력을 래치하는 엣지 트리거 방식의 1비트 기억 소자.
- **래치(Latch)**: 인에이블(Enable) 신호의 전압 레벨 구간 동안 입력을 그대로 통과시키는 레벨 감응 방식의 기억 소자.

</details>

| 회로 유형 | 순차 논리 회로 (Sequential) | 조합 논리 회로 (Combinational) |
|:---|:---|:---|
| 적용 기준 | CPU 레지스터, 카운터, FSM 제어기 | ALU 가산기, MUX, 디코더, 인코더 |
| 메모리 소자 | **플립플롭(D-FF, JK-FF), 래치 구비** | 메모리 소자 없음 (순수 게이트망) |
| 출력 종속성 | **현재 입력 + 이전 저장 상태($Q(t)$)** | 오직 **현재 인입된 입력 신호** |
| 한계 | **셋업/홀드 시간, 클록 스큐, 메타안정성** | 전파 지연($t_{pd}$), 글리치(Glitch) |

#### 한줄 요약

- 이전 상태를 기억하는 것은 순차 논리, 현재 입력만 변환하는 것은 조합 논리이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **2-FF 동기화기(Two-Flop Synchronizer)**: 서로 다른 클록 도메인(CDC) 간 단일 비트 신호 전송 시 2단 D 플립플롭을 직렬 연결하여 메타안정성 전파 확률(MTBF)을 극소화하는 회로.
- **CTS(Clock Tree Synthesis)**: H-Tree 등의 대칭 배선 구조를 통해 모든 플립플롭에 도달하는 클록 스큐를 최소화하는 P&R 최적화 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 조합 논리 지연으로 인한 **셋업 타임(Setup Time) 위반** | 논리식 간소화, 파이프라이닝 분할, **클록 주기($T_{clk}$) 확대** | 셋업 타이밍 슬랙(Slack) 확보 |
| 짧은 데이터 경로로 인한 **홀드 타임(Hold Time) 위반** | 빠른 경로에 **지연 버퍼(Delay Buffer)** 삽입 | 클록 엣지 직후 데이터 보존 |
| 비동기 입력 및 CDC 교차 시 **메타안정성(Metastability)** | 2단/3단 **D-FF 동기화기(2-FF Synchronizer)** 배치 | MTBF(평균 고장 간격) 극대화 |
| 불균일 배선에 의한 **클록 스큐(Clock Skew) 왜곡** | **클록 트리 합성(CTS, H-Tree)** 및 평형 버퍼 트리 구축 | 레지스터 간 클록 도달 시각 일치 |

#### 한줄 요약

- 비동기 입력은 2단 플립플롭 동기화기로 메타안정성을 차단하고, 홀드 타임 위반은 지연 버퍼로 보정하며, 클록 스큐는 CTS로 최소화한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **스파이킹 신경망(Spiking Neural Network, SNN)**: 클록 동기 대신 뉴런의 활동 전위(스파이크) 이벤트에 반응하여 연산과 상태 저장을 수행하는 뉴로모픽 인공신경망.
- **클록 도메인 교차(Clock Domain Crossing, CDC)**: 주파수나 위상이 서로 다른 독립된 클록으로 구동되는 플립플롭 블록 간의 신호 전달 인터페이스.
- **시스템 온 칩(System on Chip, SoC)**: 마이크로프로세서, 메모리 제어기, 하드웨어 가속기 등 복합 디지털 서브시스템을 단일 실리콘 다이에 통합한 반도체.

</details>

- 순차 논리 회로는 전역 동기 클록 분배망의 전력 한계를 극복하기 위해 클록 없는 비동기 논리 및 스파이킹 신경망(SNN) 기반 뉴로모픽 이벤트 구동 아키텍처로 진화 추세.
- 실무 초고속 시스템 온 칩(SoC) 설계 시에는 정적 타이밍 분석(STA)을 통한 셋업·홀드 마진 보장과 클록 트리 합성(CTS) 스큐 억제 및 클록 도메인 교차(CDC) 메타안정성 원천 차단 아키텍처 확보 필요.

#### 한줄 요약

- 순차 논리는 SNN 뉴로모픽 및 비동기 이벤트 구조로 진화하고 있으며, 실무에서는 STA 마진 준수와 CDC 메타안정성 제어가 핵심이다.
