## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **이진 트리 순회(Binary Tree Traversal)**: 루트와 두 하위 트리의 방문 순서를 체계적으로 정해 트리의 모든 노드를 빠짐없이 1회씩 처리하는 알고리즘.
- **방문(Visit)**: 노드의 데이터를 읽어 출력, 연산, 직렬화 등의 실질적 로직을 처리하는 동작.
- **직렬화(Serialization)**: 계층적 트리 구조를 파일 저장이나 네트워크 전송이 가능한 1차원 선형 순서열로 변환하는 작업.
- **집계(Aggregation)**: 하위 자식 노드들의 계산 결과를 상향식으로 취합하여 상위 부모 노드의 최종값을 도출하는 연산.

</details>

- 정의/개념: 루트와 자식 노드의 **재귀적 방문 순서**에 따라 모든 노드를 빠짐없이 탐색하는 트리 탐색 알고리즘
- 배경/필요성: 비선형 트리 구조는 선형 인덱스가 없어 **체계적 방문 순서** 부재 시 데이터 누락·중복 초래

#### 한줄 요약

- 루트 노드의 처리 시점에 따라 트리 직렬화(전위), 키 정렬 출력(중위), 자식 자원 해제 및 집계(후위)로 활용 목적이 구분

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **전위 순회(Pre-order Traversal)**: 루트 노드를 두 서브트리보다 먼저 방문하는 순회 방식(Root $\to$ Left $\to$ Right).
- **중위 순회(In-order Traversal)**: 왼쪽 서브트리 방문 후 루트를 거쳐 오른쪽 서브트리를 방문하는 순회 방식(Left $\to$ Root $\to$ Right).
- **후위 순회(Post-order Traversal)**: 두 서브트리를 모두 처리한 후 루트 노드를 마지막에 방문하는 순회 방식(Left $\to$ Right $\to$ Root).
- **재귀 깊이(Recursion Depth)**: 하위 트리를 탐색하며 콜 스택에 적재되는 최대 함수 호출 단계 수(트리 높이 $h$에 비례).

</details>

![균형 트리와 편향 트리의 순회 스택 증가율](/study/diagrams/tree-traversal-stack-growth.svg)

> 노드 수가 늘수록 붉은 편향 트리의 복귀 문맥은 선형 증가하지만 파란 균형 트리는 로그 증가하며, 트리 높이에 비례한 이론적 공간량임

- 루트 노드의 처리 시점에 따라 **전위·중위·후위** 순회로 명확히 분기
- 전체 $n$개 노드를 1회씩 방문하므로 엄격한 **선형 시간복잡도 $O(n)$** 보장
- 시스템 콜 스택 사용량이 트리 높이에 비례하는 **공간복잡도 $O(h)$**

#### 한줄 요약

- 노드 방문 시간복잡도는 $O(N)$이며, 재귀 호출 스택 또는 명시적 스택(Explicit Stack)의 공간복잡도는 트리 높이 $h$에 비례

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **순회기(Traverser)**: 정해진 순회 규칙에 따라 하향 이동, 데이터 방문, 상향 복귀를 제어하는 알고리즘 엔진.
- **순회 스택(Traversal Stack)**: 하위 트리 처리 후 되돌아올 부모 노드 메모리 주소와 복귀 문맥을 보관하는 LIFO 구조.
- **트리 노드(Tree Node)**: 데이터 필드와 좌·우 자식 노드 포인터를 보관하는 트리의 최소 단위.

</details>

```text
[ 이진 트리 순회 실행 구조 ]
┌──────────────────────────────┐
│ 순회 제어기 (Traverser)      │ ── 전위/중위/후위 방문 순서 제어
├──────────────────────────────┤
│ 트리 노드 (Tree Node)        │ ── Data, Left Child, Right Child 포인터
├──────────────────────────────┤
│ 순회 스택 (Call / Explicit)  │ ── 복귀 문맥(Return Context) 및 미방문 노드 보관
└──────────────────────────────┘
```

선의 의미: 순회 제어기, 트리 노드 데이터 및 복귀 문맥 스택 간의 순회 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 순회 제어기 | 방문 순서대로 하강•처리•복귀 제어 |
| 트리 노드 | **트리 노드**에 데이터와 좌•우 자식 참조 보관 |
| 순회 스택 | **복귀 문맥** 및 미방문 하위 트리 포인터 보관 |

#### 한줄 요약

- 순회 컨트롤러가 트리 노드를 방문하고, 콜 스택 또는 명시적 스택에 복귀 문맥(Return Context)을 팝/푸시하며 동작

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **명시적 스택(Explicit Stack)**: 시스템 콜 스택의 오버플로를 방지하기 위해 힙 메모리에 개발자가 직접 할당하여 운용하는 스택.

</details>

```text
[ 이진 트리 3대 순회 방식 흐름 ]
 
 1. 전위 순회 (Pre-order) : [ 루트 방문 ] ──► [ 왼쪽 서브트리 ] ──► [ 오른쪽 서브트리 ]
 2. 중위 순회 (In-order)  : [ 왼쪽 서브트리 ] ──► [ 루트 방문 ] ──► [ 오른쪽 서브트리 ]
 3. 후위 순회 (Post-order): [ 왼쪽 서브트리 ] ──► [ 오른쪽 서브트리 ] ──► [ 루트 방문 ]
```

**동작 원리**

1. **전위 순회**: 현재 루트 노드를 먼저 처리한 후 왼쪽과 오른쪽 하위 트리를 순차 재귀 탐색
2. **중위 순회**: 왼쪽 하위 트리를 먼저 완전히 탐색한 뒤 현재 루트를 방문하고 오른쪽 하위 트리를 탐색
3. **후위 순회**: 좌·우 하위 트리의 모든 자식 노드를 먼저 처리한 뒤 현재 부모 노드를 방문

#### 한줄 요약

- 루트 노드의 방문 시점을 좌우 하위 트리의 앞(전위), 사이(중위), 뒤(후위)로 제어하여 목적별 순회를 수행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **널 표식(Null Marker)**: 직렬화된 데이터로부터 원래 트리 구조를 완벽히 역직렬화하기 위해 빈 자식 노드를 표시하는 특수 기호(# 등).
- **BST 정렬 특성**: 이진 탐색 트리를 중위 순회(In-order)할 경우 모든 키가 자동으로 오름차순 정렬되어 출력되는 성질.

</details>

| 순회 방식 | 전위 순회 (Pre-order) | 중위 순회 (In-order) | 후위 순회 (Post-order) |
|:---|:---|:---|:---|
| 적용 기준 | 트리 복제 및 **구조 직렬화** 시 | **BST(이진 탐색 트리)** 정렬 출력 시 | 하위 노드 메모리 해제 및 **집계 연산** 시 |
| 핵심 특징 | Root $\to$ Left $\to$ Right 순서 | Left $\to$ Root $\to$ Right 순서 | Left $\to$ Right $\to$ Root 순서 |
| 한계 | 하위 노드 결과 기반 상향 집계 불가 | 일반 트리에서는 정렬 순서 미보장 | 부모 노드 우선 처리가 필요한 직렬화에 부적합 |

#### 한줄 요약

- 구조 복원용 직렬화는 전위, BST 정렬은 중위, 하위 결과 집계 및 삭제는 후위 순회 선택

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **모리스 순회(Morris Traversal)**: 스택이나 재귀 호출 없이 트리의 널 포인터를 임시 스레드(Thread)로 연결하여 $O(1)$ 보조 공간으로 중위 순회를 수행하는 알고리즘.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **편향 트리**에서 재귀 깊이가 노드 수까지 증가 | **명시적 스택** 기반 반복 순회 또는 **모리스 순회** 적용 | **스택 오버플로** 방지 |
| 순회 중 구조 변경으로 노드 누락•중복•참조 단절 | **스냅샷** 고정•**변경 감지 버전(ModCount)** 적용 | 한 시점의 **순회 일관성** 확보 |
| 빈 자식 생략으로 서로 다른 트리가 같은 순서열로 표현 | 직렬화에 **널 표식(Null Marker)**과 구분자 규칙 포함 | 원래 구조를 복원 가능한 **역직렬화** 보장 |
| 일반 이진 트리의 중위 결과를 정렬 결과로 오인 | **이진 탐색 트리(BST)** 순서 조건 사전 검증 | 중위 순회의 **정렬 출력** 보장 |

#### 한줄 요약

- 편향 트리에서는 명시적 스택이나 모리스 순회로 재귀 깊이를 억제하고, 순회 중 구조 변경은 ModCount로 감지하며, 직렬화에는 널 표식을 포함해야 역직렬화가 가능하다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **순회 목적(Traversal Purpose)**: 구조 기록(전위), 정렬 출력(중위), 하위 자원 해제(후위)처럼 연산 목적에 따라 순회 방식을 결정하는 기준.

</details>

- 구조 직렬화는 **전위 순회**, BST 정렬 출력은 **중위 순회**, 하위 집계는 **후위 순회** 선택

#### 한줄 요약

- 구조 기록은 전위, BST 정렬은 중위, 하위 집계는 후위 순회를 선택
