## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **재귀적 방문 순서(Recursive Visit Order)**: 현재 루트 노드와 좌·우 서브트리를 처리하는 상대적 선후 관계(전위·중위·후위).
- **체계적 방문 순서(Systematic Traversal Order)**: 비선형 계층 구조의 모든 노드를 단 1회씩 누락이나 중복 없이 1차원 선형으로 열거하는 확정적 탐색 규칙.

</details>

- 정의/개념: 루트와 자식 노드의 **재귀적 방문 순서**에 따라 모든 노드를 1회씩 탐색하는 비선형 자료구조 순회 알고리즘
- 배경/필요성: 비선형 2차원 계층 구조에서 노드 방문 순서가 결정되지 않을 경우 발생하는 순회 결과 불일치 및 중복 연산 위험

#### 한줄 요약

- 루트 방문 시점에 따라 직렬화, 정렬, 상향 집계 용도가 갈린다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **전위 순회(Pre-order Traversal)**: 루트 노드를 두 서브트리보다 먼저 방문하는 순회 방식(Root $\to$ Left $\to$ Right).
- **중위 순회(In-order Traversal)**: 왼쪽 서브트리 방문 후 루트를 거쳐 오른쪽 서브트리를 방문하는 순회 방식(Left $\to$ Root $\to$ Right).
- **후위 순회(Post-order Traversal)**: 두 서브트리를 모두 처리한 후 루트 노드를 마지막에 방문하는 순회 방식(Left $\to$ Right $\to$ Root).
- **재귀 깊이(Recursion Depth)**: 하위 트리를 탐색하며 콜 스택에 적재되는 최대 함수 호출 단계 수(트리 높이 $h$에 비례).

</details>

![균형 트리와 편향 트리의 순회 스택 증가율](/study/diagrams/tree-traversal-stack-growth.svg)

> 노드 수가 늘수록 붉은 편향 트리의 복귀 문맥은 선형 증가하지만 파란 균형 트리는 로그 증가하며, 트리 높이에 비례한 이론적 공간량임

- 루트 노드의 방문 시점에 따라 **전위·중위·후위** 순회로 분기
- 전체 노드를 1회씩 방문하여 **선형 시간복잡도 $O(n)$** 보장
- 시스템 콜 스택 적재량이 트리 높이에 비례하는 **공간복잡도 $O(h)$** 유지

#### 한줄 요약

- 모든 노드를 $O(N)$에 방문하며 스택 공간은 높이 $h$에 비례한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **순회 스택(Traversal Stack)**: 하위 트리 처리 후 되돌아올 부모 노드 메모리 주소와 복귀 문맥을 보관하는 LIFO 구조.
- **트리 노드(Tree Node)**: 데이터 필드와 좌·우 자식 노드 포인터를 보관하는 트리의 최소 단위.

</details>

```text
[이진 트리 순회 처리 체계]
  │
  ├─ [순회 정책 엔진] (전위·중위·후위 순서 결정)
  │
  ├─ [트리 탐색 단위]
  │     ├─ [현재 노드] (데이터 필드 처리)
  │     └─ [분기 포인터] (좌·우 자식 서브트리 링크)
  │
  └─ [복귀 문맥 관리]
        ├─ [시스템 콜 스택] (재귀 호출 문맥 보관)
        └─ [명시적 LIFO 스택] (반복적 순회 프레임)
```

- 선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 순회 규칙 | **재귀적 방문 순서**에 따른 루트 처리 시점 결정 |
| **트리 노드** | 데이터와 좌·우 자식 포인터를 유지하는 단위 |
| **순회 스택** | 하위 서브트리 처리 후 부모 노드를 보관하는 구조 |

#### 한줄 요약

- 순회 규칙이 루트 처리 시점을 정하고 스택이 부모 복귀 문맥을 관리한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **명시적 스택(Explicit Stack)**: 시스템 콜 스택의 오버플로를 방지하기 위해 힙 메모리에 개발자가 직접 할당하여 운용하는 스택.

</details>

```text
[이진 트리 순회 요청 인입 (루트 노드)]
                 │
                 ▼
         <순회 목적 정책 판정>
                 │
  ┌──────────────┼──────────────┐
  │              │              │
[전위 순회]   [중위 순회]   [후위 순회]
  │              │              │
  ▼              ▼              ▼
[루트 방문]   [왼쪽 서브]   [왼쪽 서브]
  │              │              │
  ▼              ▼              ▼
[왼쪽 서브]   [루트 방문]   [오른쪽 서브]
  │              │              │
  ▼              ▼              ▼
[오른쪽 서브] [오른쪽 서브] [루트 방문]
  │              │              │
  └──────────────┼──────────────┘
                 │
                 ▼
      [전체 노드 O(N) 순회 완료]
```

분기 결과: 트리 구조 복제는 부모를 먼저 방문하는 전위 순회로 분기하고, BST 정렬 출력은 좌우 사이에 방문하는 중위 순회로 분기하며, 하위 노드 해제 및 상향 집계는 자식을 먼저 방문하는 후위 순회로 분기함

**동작 원리**:
1. 순회 목적(직렬화, 정렬, 집계)에 맞춰 루트 노드 처리 시점을 규정하는 전위, 중위, 후위 알고리즘 정책을 설정함.
2. 현재 노드가 널(NULL)인지 검사하여 기저 조건(Base Case)에 도달하면 호출 스택에서 직전 부모 노드로 복귀함.
3. **전위 순회**는 현재 노드의 데이터를 먼저 처리한 후 왼쪽 및 오른쪽 자식 노드로 재귀 이동하여 구조 직렬화를 수행함.
4. **중위 순회**는 왼쪽 서브트리를 완전히 탐색한 후 현재 노드를 방문하고 오른쪽 서브트리로 이동하여 BST 키 정렬 순서를 산출함.
5. **후위 순회**는 좌우 자식 서브트리 연산을 모두 마친 후 마지막으로 현재 노드를 방문하여 상향식 높이 계산 및 안전한 메모리 해제를 완결함.

#### 한줄 요약

- 루트 방문 시점을 앞·사이·뒤로 바꾸어 목적별 순회를 수행한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **구조 직렬화(Structure Serialization)**: 트리 계층 구조를 파일 저장이나 네트워크 전송을 위해 1차원 선형 바이트열 또는 문자열로 변환하는 작업.
- **이진 탐색 트리 정렬 특성(Binary Search Tree Sorting Property, BST Sorting Property)**: 이진 탐색 트리를 중위 순회할 경우 모든 키가 자동으로 오름차순 정렬되어 출력되는 성질.
- **집계 연산(Aggregation Operation)**: 자식 노드들의 계산 결과(크기, 높이 등)를 상향식으로 취합하여 부모 노드의 최종값을 도출하는 연산.
- **널 표식(Null Marker)**: 직렬화된 데이터로부터 원래 트리 구조를 완벽히 역직렬화하기 위해 빈 자식 노드를 표시하는 특수 기호(# 등).

</details>

| 순회 방식 | 전위 순회 (Pre-order) | 중위 순회 (In-order) | 후위 순회 (Post-order) |
|:---|:---|:---|:---|
| 적용 기준 | 트리 복제 및 **구조 직렬화** 시 | **이진 탐색 트리** 정렬 출력 시 | 하위 노드 메모리 해제 및 **집계 연산** 시 |
| 핵심 특징 | Root $\to$ Left $\to$ Right 순서 | Left $\to$ Root $\to$ Right 순서 | Left $\to$ Right $\to$ Root 순서 |
| 한계 | 하위 노드 결과 기반 상향 집계 불가 | 일반 트리에서는 정렬 순서 미보장 | 부모 노드 우선 처리가 필요한 직렬화에 부적합 |

#### 한줄 요약

- 구조 직렬화는 전위, BST 정렬은 중위, 상향 집계는 후위를 선택한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **모리스 순회(Morris Traversal)**: 스택이나 재귀 호출 없이 트리의 널 포인터를 임시 스레드로 연결하여 $O(1)$ 보조 공간으로 중위 순회를 수행하는 알고리즘.
- **스냅샷(Snapshot)**: 순회 시작 시점의 자료구조 상태를 불변으로 유지하여 동시 수정에 따른 데이터 불일치를 차단하는 복제본.
- **변경 감지 카운터(Modification Count, ModCount)**: 순회 도중 컬렉션 구조가 변경되었는지 감지하여 동시 수정 예외를 발생시키는 버전 추적 필드.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 편향 트리에서 깊은 재귀 호출로 인한 콜 스택 오버플로 발생 | **명시적 스택** 기반 반복 순회 또는 **모리스 순회** 적용 | **스택 오버플로** 방지 |
| 순회 중 구조 변경으로 노드 누락·중복·참조 단절 발생 | **스냅샷** 고정 및 **변경 감지 카운터** 적용 | 특정 시점의 **순회 일관성** 확보 |
| 빈 자식 노드 생략으로 인한 역직렬화 시 구조 모호성 발생 | 직렬화 데이터에 **널 표식** 포함 | 원래 구조 복원이 가능한 **역직렬화 무결성** 보장 |
| 일반 이진 트리의 중위 결과를 정렬 결과로 오인 | **이진 탐색 트리** 키 정렬 조건 사전 검증 | 중위 순회의 **정렬 출력** 보장 |

#### 한줄 요약

- 편향 트리에서는 명시적 스택이나 모리스 순회로 재귀 깊이를 억제하고, 순회 중 구조 변경은 ModCount로 감지하며, 직렬화에는 널 표식을 포함해야 역직렬화가 가능하다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **순회 목적(Traversal Purpose)**: 구조 직렬화(전위), 키 정렬 출력(중위), 하위 메모리 해제(후위)처럼 처리 목표에 맞춰 탐색 순서를 결정하는 설계 기준.
- **추상 구문 트리(Abstract Syntax Tree, AST)**: 소스 코드의 문법 구조를 노드와 간선으로 계층화하여 컴파일러 파싱 및 최적화에 사용하는 트리 구조.
- **계산 그래프(Computational Graph)**: 인공지능 프레임워크에서 수학적 연산 노드와 텐서 데이터 흐름을 계층적 그래프 형태로 표현한 실행 모델.

</details>

- 컴파일러 **추상 구문 트리(Abstract Syntax Tree, AST)** 분석, 계층 데이터 직렬화, 하위 자원 해제의 기본 표준으로 안착하였으며, 현대 인공지능 딥러닝 프레임워크에서는 대규모 신경망의 **계산 그래프(Computational Graph)** 최적화 및 순전파·역전파 자동 미분 실행 스케줄링 아키텍처로 진화 추세.
- 대규모 비선형 계층 구조 탐색 시 단순 재귀 호출에 따른 콜 스택 오버플로를 차단하기 위해 명시적 반복 스택 또는 모리스 순회를 적극 도입하고, 순회 도중 구조 변경에 대응하는 방어적 소프트웨어 통제 필요.

#### 한줄 요약

- AST 분석과 AI 계산 그래프 스케줄링으로 진화하는 트리 순회에서 스택 오버플로 방지와 동시 수정 무결성을 확보하는 공학적 통찰 필요.
