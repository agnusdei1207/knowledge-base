## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **이진 트리 순회(Binary Tree Traversal)**: 루트와 두 하위 트리의 방문 순서를 정해 모든 노드를 처리하는 절차이다.
- **방문(Visit)**: 노드의 데이터를 처리하거나 출력하는 동작이다.
- **직렬화(Serialization)**: 트리 구조를 저장하거나 전송할 수 있는 순서열로 변환하는 작업이다.
- **집계(Aggregation)**: 하위 노드의 값을 모아 상위 노드의 결과를 계산하는 작업이다.

</details>

- 정의/개념: 루트와 왼쪽•오른쪽 하위 트리의 상대적 순서에 따라 모든 노드를 한 번씩 처리하는 **이진 트리 순회**이다.
- 배경/필요성: 트리 직렬화, 키 정렬 출력, 하위 결과 집계는 처리 시점에 따라 노드 방문 순서가 달라 명확한 순회 기준 구분이 요구된다.

#### 한줄 요약

- 루트 노드의 처리 시점에 따라 트리 직렬화(전위), 키 정렬 출력(중위), 자식 자원 해제 및 집계(후위)로 활용 목적이 구분된다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **전위 순회(Pre-order Traversal)**: 루트를 두 하위 트리보다 먼저 방문하는 순회이다.
- **중위 순회(In-order Traversal)**: 두 하위 트리 사이에 루트를 방문하는 순회이다.
- **후위 순회(Post-order Traversal)**: 두 하위 트리보다 나중에 루트를 방문하는 순회이다.
- **트리 높이 $h$**: 루트부터 가장 깊은 말단 노드까지의 경로 길이다.
- **복귀 문맥(Return Context)**: 하위 트리 처리 후 이어서 실행할 위치와 현재 노드 상태를 묶은 정보이다.
- **재귀 깊이(Recursion Depth)**: 하위 트리를 따라 중첩된 함수 호출의 최대 단계 수이다.

</details>

![균형 트리와 편향 트리의 순회 스택 증가율](/study/diagrams/tree-traversal-stack-growth.svg)

> 노드 수가 늘수록 붉은 편향 트리의 복귀 문맥은 선형 증가하지만 파란 균형 트리는 로그 증가하며, 트리 높이에 비례한 이론적 공간량이다.

- **전위•중위•후위**에 따른 루트 처리 시점을 구분한다.
- 전체 노드를 한 번 **방문**하므로 시간복잡도는 $O(n)$이다.
- **재귀 깊이**가 트리 높이에 비례해 스택 사용량을 결정한다.

#### 한줄 요약

- 노드 방문 시간복잡도는 $O(N)$이며, 재귀 호출 스택 또는 명시적 스택(Explicit Stack)의 공간복잡도는 트리 높이 $h$에 비례한다.


## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **순회기(Traverser)**: 정해진 방문 순서에 따라 자식으로 내려가고 노드를 처리한 뒤 상위로 되돌아오는 주체이다.
- **순회 스택(Traversal Stack)**: 돌아갈 노드와 실행 문맥을 저장하는 후입선출 구조이다.
- **하위 트리(Subtree)**: 특정 노드와 그 아래 자손으로 이루어진 부분 트리이다.
- **트리 노드(Tree Node)**: 데이터와 왼쪽•오른쪽 자식 참조를 보관하는 트리의 저장 단위이다.

</details>

```text
이진 트리 순회 구조
├─ 순회기
├─ 트리 노드
└─ 순회 스택
```

가지의 의미: 방문 제어•노드•복귀 문맥의 정적 책임 분리를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 순회기 | **순회기**가 방문 순서대로 하강•처리•복귀 |
| 트리 노드 | **트리 노드**에 데이터와 좌•우 자식 참조 보관 |
| 순회 스택 | **복귀 문맥**•미방문 하위 트리 보관 |

#### 한줄 요약

- 순회 컨트롤러가 트리 노드를 방문하고, 콜 스택 또는 명시적 스택에 복귀 문맥(Return Context)을 팝/푸시하며 동작한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **명시적 스택**: 재귀 호출 대신 프로그램이 직접 노드와 방문 단계를 넣고 꺼내는 저장 구조이다.

</details>

```text
전위 순회 (Pre-order) : 루트 방문 ──> 왼쪽 하위 트리 ──> 오른쪽 하위 트리
중위 순회 (In-order)  : 왼쪽 하위 트리 ──> 루트 방문 ──> 오른쪽 하위 트리
후위 순회 (Post-order): 왼쪽 하위 트리 ──> 오른쪽 하위 트리 ──> 루트 방문
```

### 동작 원리

1. 전위 순회: 현재 루트 노드를 먼저 처리한 후 왼쪽과 오른쪽 하위 트리를 순차 재귀 탐색함.
2. 중위 순회: 왼쪽 하위 트리를 먼저 완전히 탐색한 뒤 현재 루트를 방문하고 오른쪽 하위 트리를 탐색함 (BST 오름차순 출력).
3. 후위 순회: 좌·우 하위 트리의 모든 자식 노드를 먼저 처리한 뒤 현재 부모 노드를 방문함 (노드 삭제 및 크기 집계).

#### 한줄 요약

- 루트 노드의 방문 시점을 좌우 하위 트리의 앞(전위), 사이(중위), 뒤(후위)로 제어하여 목적별 순회를 수행함.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **널 표식(Null Marker)**: 직렬화할 때 빈 자식 위치를 보존하는 표시이다.
- **이진 탐색 트리(Binary Search Tree, BST)**: 왼쪽 키는 작고 오른쪽 키는 큰 순서 조건을 가진 트리이다.
- **정렬 출력**: 이진 탐색 트리를 중위 순회해 키를 오름차순으로 내보내는 처리이다.

</details>

| 이진 트리 순회 | 전위 순회 | 중위 순회 | 후위 순회 |
|:---|:---|:---|:---|
| 적용 기준 | **널 표식** 포함 트리 직렬화 | **이진 탐색 트리** 정렬 출력 | 하위 노드 삭제•**집계** |
| 핵심 특징 | 루트 → 왼쪽 → 오른쪽 | 왼쪽 → 루트 → 오른쪽 | 왼쪽 → 오른쪽 → 루트 |
| 한계 | 하위 결과 **집계**에 부적합 | 일반 이진 트리는 **정렬 출력** 미보장 | **직렬화** 등 부모 선처리에 부적합 |

> 요약: 직렬화는 **전위**, 정렬은 **중위**, 하위 집계는 후위를 선택한다.

#### 한줄 요약

- 구조 복원용 직렬화에는 전위(Pre-order), BST 오름차순 출력에는 중위(In-order), 자식 하위 결과 집계 및 삭제에는 후위(Post-order) 순회를 선택한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **스택 오버플로(Stack Overflow)**: 재귀 호출 스택이 용량 한도를 넘은 오류이다.
- **스냅샷(Snapshot)**: 순회 중 변경과 분리해 특정 시점의 트리 상태를 고정한 복사본이나 뷰이다.
- **변경 감지 버전**: 순회를 시작한 뒤 트리 구조가 바뀌었는지 확인하기 위한 상태 번호이다.
- **편향 트리(Skewed Tree)**: 한쪽 자식만 이어져 높이가 노드 수에 가깝게 증가한 트리이다.
- **순회 일관성**: 순회 전체가 하나의 트리 상태를 기준으로 노드를 빠짐없이 한 번씩 처리하는 성질이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **편향 트리**에서 재귀 깊이가 노드 수까지 증가 | **명시적 스택** 기반 반복 순회 적용 | **스택 오버플로** 방지 |
| 순회 중 구조 변경으로 노드 누락•중복•참조 단절 | **스냅샷** 고정•**변경 감지 버전** 적용 | 한 시점의 **순회 일관성** 확보 |
| 빈 자식 생략으로 서로 다른 트리가 같은 순서열로 표현 | 직렬화에 **널 표식**과 구분자 규칙 포함 | 원래 구조를 복원 가능한 **직렬화** 확보 |
| 일반 이진 트리의 중위 결과를 정렬 결과로 오인 | **이진 탐색 트리** 순서 조건 사전 검증 | 중위 순회의 **정렬 출력** 보장 |

#### 한줄 요약

- 편향 트리(Skewed Tree)에서의 콜 스택 오버플로를 방지하기 위해 힙 메모리 상의 명시적 스택(Explicit Stack) 기반 반복 순회를 적용한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **구조 기록**: 부모를 먼저 방문해야 하는 순회 목적이다.
- **키 정렬**: 키 순서대로 노드를 방문해야 하는 순회 목적이다.
- **하위 집계**: 자식 결과를 먼저 모아야 하는 순회 목적이다.

</details>

- 구조 기록은 **전위**, 키 정렬은 **중위**, 하위 집계는 후위를 선택한다.

#### 한줄 요약

- 구조 기록은 전위, BST 정렬은 중위, 하위 집계는 후위 순회를 선택한다.
