## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **K-Fold 교차 검증**: 데이터를 K개로 나눠 각 묶음을 한 번씩 검증하고 K회 점수를 종합하는 평가법
- **폴드(Fold)**: 회차마다 하나는 검증, 나머지는 학습에 쓰도록 나눈 표본 묶음
- **평가 점수 변동**: 같은 데이터라도 학습•검증 분할이 달라져 성능 점수가 바뀌는 현상

</details>

- 정의/개념: $K$개 **폴드** 를 번갈아 검증에 쓰는 평가 기법
- 배경/필요성: 단일 분할에 따른 **평가 점수 변동** 완화

#### 한줄 요약
- 우수한 학생이 한 시험반에 몰리는 우연을 줄이려고, 검증반을 K번 바꿔 점수 평균과 편차를 본다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **순환 평가**: K개 폴드가 각각 한 번씩 검증 집합이 되도록 학습과 평가를 반복하는 방식
- **홀드아웃**: 데이터를 한 번만 학습•검증 집합으로 나눠 성능을 재는 평가법
- **평가 편향•분산**: 제한된 학습 표본 때문에 생기는 체계적 차이와 분할마다 점수가 변하는 정도
- **K 증가**: 폴드 수를 늘려 회차별 학습 표본은 늘지만 모델 재학습 횟수도 함께 늘리는 선택
- **계산 비용**: K회 모델 학습과 평가에 필요한 시간과 연산 자원

</details>

- 모든 표본의 **순환 평가** 점수를 평균•편차로 집계
- 단일 **홀드아웃**보다 분할 편차 완화
- **K 증가** 에 따른 검증 편향 감소•**계산 비용** 증가

> **폴드 수 증가**: 학습 표본•재학습 횟수 증가

#### 한줄 요약
- 시험반을 작게 나누면 매 회차 공부반은 커져 평가 편향이 줄지만, 반을 바꿔 모델을 다시 학습하는 횟수도 K번으로 늘어난다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **폴드 분할기**: 분할 규칙에 따라 회차별 훈련•검증 표본을 정하는 구성요소
- **회차별 모델**: 각 회차의 훈련 폴드만 사용해 새로 적합한 모델
- **점수 평균•편차**: K개 검증 성능의 중심과 분할 민감도를 함께 나타내는 요약

</details>

```mermaid
block-beta
    columns 3
    S["폴드 분할기"] --- M["모델 학습기"] --- E["성능 평가기"] --- G["점수 집계기"]
```

| 구성요소 | 책임 |
|:---|:---|
| 폴드 분할기 | **훈련•검증 폴드** 를 회차별 순환 |
| 모델 학습기 | 훈련 폴드로 **회차별 모델** 생성 |
| 성능 평가기 | 검증 폴드의 **예측 성능** 산출 |
| 점수 집계기 | 점수 **평균•편차** 계산 |

#### 한줄 요약

- 분할기가 검증 폴드를 번갈아 지정하고, 학습기와 평가기가 만든 K개 점수를 집계기가 요약한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **훈련•검증 폴드**: 모델 적합에 사용하는 K-1개 묶음과 성능 평가에만 사용하는 1개 묶음
- **미사용 폴드**: 해당 회차의 모델 학습에 포함하지 않아 독립 평가에 쓰는 표본 묶음
- **점수 요약**: 회차별 검증 점수를 평균과 편차로 집계한 결과
- **분할 규칙**: 표본의 클래스•그룹•시간 관계를 고려해 각 폴드에 배정하는 기준

</details>

```mermaid
sequenceDiagram
    participant S as 폴드 분할기
    participant M as 모델 학습기
    participant E as 성능 평가기
    participant G as 점수 집계기
    S->>S: 데이터•분할 규칙 적용
    loop K개 폴드 순환
        S->>M: 1. 훈련 폴드 전달
        M->>E: 2. 회차 모델•검증 폴드 전달
        E->>G: 3. 검증 점수 전달
    end
    G->>G: 4. 점수 요약 산출
    G-->>S: 점수 요약 반환
```

### 동작 원리

- **1. 훈련 폴드 전달**: 나머지 폴드를 학습에 배정
- **2. 회차 모델•검증 폴드 전달**: 훈련 폴드 안에서만 적합
- **3. 검증 점수 전달**: 미사용 폴드로 성능 평가
- **4. 점수 요약 산출**: 평균•편차로 성능 요약

#### 한줄 요약
- 각 폴드가 한 번씩 시험지가 되고 나머지가 공부 자료가 되며, K개 시험 점수의 평균과 들쭉날쭉한 폭을 함께 모은다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **층화 K-Fold**: 각 폴드의 클래스 비율을 전체 데이터와 비슷하게 유지하는 방식
- **그룹 K-Fold**: 같은 사용자•장비의 의존 표본을 하나의 폴드에 묶는 방식
- **시계열 분할**: 시간 순서를 보존해 과거 구간으로 학습하고 미래 구간으로 검증하는 방식
- **교환 가능 표본**: 표본 순서를 바꿔도 결합 분포가 달라지지 않아 무작위 분할이 가능한 표본
- **데이터 누수**: 검증 표본의 정보가 학습 과정에 섞여 평가 점수가 과대평가되는 현상
- **불균형 분류**: 클래스별 표본 수 차이가 커 소수 클래스 평가가 불안정한 문제
- **반복 측정**: 같은 개체에서 여러 번 수집해 서로 독립적이지 않은 관측값

</details>

| 교차 검증 방식 | 일반 K-Fold | 층화 K-Fold | 그룹 K-Fold | 시계열 분할 |
|:---|:---|:---|:---|:---|
| 적용 기준 | **독립•교환 가능** 표본 | **불균형 분류** 문제 | 사용자•장비 **반복 측정** | 미래 구간 **예측 과제** |
| 핵심 특징 | 무작위 **균등 폴드** 순환 | 폴드별 **클래스 비율** 유지 | 같은 개체를 **한 폴드** 에 유지 | **시간 순서** 보존 분할 |
| 한계 | 의존 표본에서 **데이터 누수** | 소수 클래스 수가 **폴드 수** 미만이면 비율 유지 불가 | **그룹 수** 부족 시 폴드 구성 제약 | 초기 회차 **학습 구간** 부족 |

> 요약: 표본 독립 가정의 성립 여부를 고려해 **분할 규칙** 선택

#### 한줄 요약
- 서로 바꿔도 되는 표본은 무작위, 소수 반이 사라질 위험은 층화, 같은 사람의 반복 기록은 그룹, 미래 예측은 시간 순서로 나눈다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **데이터 누수**: 검증 정보가 학습 과정에 섞여 배포 성능보다 평가 점수가 높아지는 오류
- **전처리 적합**: 결측 처리나 척도 변환의 기준을 훈련 폴드만으로 계산하는 과정
- **반복 측정**: 같은 사용자•장비•대상에서 여러 번 수집해 서로 독립적이지 않은 관측값
- **불균형 분류**: 클래스별 표본 수 차이로 소수 클래스 평가의 변동성이 커지는 문제
- **일반화 성능**: 학습에 사용하지 않은 새 데이터에서의 예측 성능
- **그룹•층화•시계열 분할**: 같은 개체를 묶고, 클래스 비율을 유지하고, 시간 순서를 보존하는 폴드 구성 방식

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 전처리 기준의 **검증 정보 누수** | 회차별 훈련 폴드에서만 전처리 적합 | **일반화 성능 과대평가** 방지 |
| 동일 사용자•장비 **표본 분산** | **그룹 단위 분할** 적용 | **개체 정보 누수** 방지 |
| 불균형 클래스의 **폴드별 소실** | **층화 분할**•최소 클래스 수 점검 | **평가 지표** 변동 감소 |
| 시계열 **무작위 혼합** | 과거 학습•미래 검증 순서 보존 | **배포 시점 성능** 모사 |

#### 한줄 요약
- 시험반의 평균을 미리 본 채 표준화하면 답을 엿본 셈이므로, 전처리 기준과 모델은 매 회차 공부반 안에서만 다시 계산한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **표본 의존성**: 같은 개체나 시간 관계 때문에 관측값들이 서로 독립적이지 않은 성질
- **분할 방식**: 일반•층화•그룹•시계열 중 데이터 생성 구조에 맞춰 폴드를 만드는 규칙
- **불균형•시간 순서**: 클래스 표본 수가 고르지 않은 상태와 관측이 발생한 선후 관계

</details>

- 표본 의존성•불균형•시간 순서로 **분할 방식** 결정

#### 한줄 요약
- 같은 사람 기록이 섞이는지, 소수 클래스가 사라지는지, 미래가 과거 학습에 들어가는지를 먼저 막고 교차 검증 방식을 고른다.
