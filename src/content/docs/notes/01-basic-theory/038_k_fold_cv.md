## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **K-겹 교차 검증(K-Fold Cross-Validation)**: 데이터를 K개로 나눠 각 묶음을 한 번씩 검증하는 평가법이다.
- **폴드(Fold)**: 회차마다 하나는 검증, 나머지는 학습에 쓰도록 나눈 표본 묶음이다.
- **평가 점수 변동**: 같은 데이터라도 학습•검증 분할이 달라져 성능 점수가 바뀌는 현상이다.

</details>

- 정의/개념: 데이터를 K개로 나눠 각 폴드를 한 번씩 검증하고 성능을 집계하는 **K-겹 교차 검증** 평가법이다.
- 배경/필요성: 한 번의 학습•검증 분할은 어떤 표본이 검증 집합에 들어갔는지에 따라 점수가 크게 달라질 수 있다.

#### 한줄 요약
- 우수한 학생이 한 시험반에 몰리는 우연을 줄이려고, 검증반을 K번 바꿔 점수 평균과 편차를 본다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **순환 평가**: K개 폴드가 각각 한 번씩 검증 집합이 되도록 학습과 평가를 반복하는 방식이다.
- **홀드아웃**: 데이터를 한 번만 학습•검증 집합으로 나눠 성능을 재는 평가법이다.
- **평가 편향(Evaluation Bias)**: 제한된 학습 표본 때문에 생기는 체계적 성능 차이다.
- **평가 분산(Evaluation Variance)**: 분할마다 평가 점수가 변하는 정도이다.
- **K 증가**: 폴드 수를 늘려 회차별 학습 표본은 늘지만 모델 재학습 횟수도 함께 늘리는 선택이다.
- **계산 비용**: K회 모델 학습과 평가에 필요한 시간과 연산 자원이다.

</details>

- 모든 표본의 **순환 평가** 점수를 평균•편차로 집계한다.
- 단일 **홀드아웃**보다 분할 편차를 완화한다.
- **K 증가**에 따라 평가 편향은 줄지만 평가 분산과 계산 비용은 늘 수 있다.

> **K 증가**: 학습 표본•재학습 횟수 증가

#### 한줄 요약
- 시험반을 작게 나누면 매 회차 공부반은 커져 평가 편향이 줄지만, 반을 바꿔 모델을 다시 학습하는 횟수도 K번으로 늘어난다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **폴드 분할기**: 분할 규칙에 따라 회차별 훈련•검증 표본을 정하는 구성요소이다.
- **회차별 모델**: 각 회차의 훈련 폴드만 사용해 새로 적합한 모델이다.
- **점수 평균(Score Mean)**: K개 검증 성능의 중심을 나타내는 요약이다.
- **점수 편차(Score Deviation)**: K개 검증 성능의 분할 민감도를 나타내는 요약이다.
- **훈련 폴드(Training Fold)**: 모델 적합에 사용하는 K-1개 표본 묶음이다.
- **검증 폴드(Validation Fold)**: 성능 평가에만 사용하는 1개 표본 묶음이다.
- **검증 성능**: 회차별 검증 폴드에서 측정한 예측 지표 값이다.

</details>

```text
[K-Fold 검증 구조]
    |
    +-- [폴드 분할기]
    +-- [모델 학습기]
    +-- [성능 평가기]
    `-- [점수 집계기]
```

선의 의미: 검증 구조가 포함하는 분할•학습•평가•집계 책임의 정적 구성 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 폴드 분할기 | **훈련•검증 폴드**를 회차별 순환 |
| 모델 학습기 | 훈련 폴드로 **회차별 모델** 생성 |
| 성능 평가기 | 검증 폴드의 **검증 성능** 산출 |
| 점수 집계기 | 점수 **평균•편차** 계산 |

#### 한줄 요약

- 분할기가 검증 폴드를 번갈아 지정하고, 학습기와 평가기가 만든 K개 점수를 집계기가 요약한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **점수 요약**: 회차별 검증 점수를 평균과 편차로 집계한 결과이다.
- **분할 규칙**: 표본의 클래스•그룹•시간 관계를 고려해 각 폴드에 배정하는 기준이다.

</details>

```text
[데이터와 분할 규칙]
          |
          v
+------------------------------------+
| K개 폴드를 한 번씩 순환           |
|                                    |
|  1. 검증 폴드 선택                 |
|            |                       |
|            v                       |
|  2. 훈련 폴드 전처리•학습          |
|            |                       |
|            v                       |
|  3. 검증 폴드 성능 평가            |
|            |                       |
|            `---------- 반복 -------|
+------------------------------------+
          |
          v
4. 점수 평균•편차 집계
          |
          v
[교차 검증 성능]
```

### 동작 원리

- **1. 검증 폴드 선택**: 회차별로 학습에서 제외할 검증 폴드를 지정한다.
- **2. 훈련 폴드 전처리•학습**: 나머지 폴드 안에서만 적합이다.
- **3. 검증 폴드 성능 평가**: 미사용 폴드의 예측 점수 산출한다.
- **4. 점수 평균•편차 집계**: 성능 중심과 분할 민감도 요약이다.

#### 한줄 요약
- 각 폴드가 한 번씩 시험지가 되고 나머지가 공부 자료가 되며, K개 시험 점수의 평균과 들쭉날쭉한 폭을 함께 모은다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **층화 K-Fold**: 각 폴드의 클래스 비율을 전체 데이터와 비슷하게 유지하는 방식이다.
- **그룹 K-Fold**: 같은 사용자•장비의 의존 표본을 하나의 폴드에 묶는 방식이다.
- **시계열 분할**: 시간 순서를 보존해 과거 구간으로 학습하고 미래 구간으로 검증하는 방식이다.
- **교환 가능 표본**: 표본 순서를 바꿔도 결합 분포가 달라지지 않아 무작위 분할이 가능한 표본이다.
- **데이터 누수**: 검증 표본의 정보가 학습 과정에 섞여 평가 점수가 과대평가되는 현상이다.
- **불균형 분류**: 클래스별 표본 수 차이가 커 소수 클래스 평가가 불안정한 문제이다.
- **반복 측정**: 같은 개체에서 여러 번 수집해 서로 독립적이지 않은 관측값이다.
- **독립 표본**: 한 표본의 값이 다른 표본의 발생이나 측정에 영향을 주지 않는 관측값이다.
- **폴드 수 $K$**: 교차 검증에서 데이터를 나누는 묶음 수이자 모델 재학습 횟수이다.
- **그룹 수**: 그룹 K-Fold에서 서로 분리해야 하는 사용자•장비 등 개체의 개수이다.
- **학습 구간**: 시계열 분할에서 모델 적합에 사용하는 과거 시간 범위이다.

</details>

| 교차 검증 방식 | 일반 K-Fold | 층화 K-Fold | 그룹 K-Fold | 시계열 분할 |
|:---|:---|:---|:---|:---|
| 적용 기준 | **독립•교환 가능 표본** | **불균형 분류** 문제 | 사용자•장비 **반복 측정** | 미래 구간 예측 과제 |
| 핵심 특징 | 무작위 **균등 폴드** 순환 | 폴드별 **클래스 비율** 유지 | 같은 개체를 **한 폴드**에 유지 | **시간 순서** 보존 분할 |
| 한계 | 의존 표본에서 **데이터 누수** | 소수 클래스 수가 **폴드 수 $K$** 미만이면 비율 유지 불가 | **그룹 수** 부족 시 폴드 구성 제약 | 초기 회차 **학습 구간** 부족 |

> 요약: 표본 독립 가정의 성립 여부를 고려해 **분할 규칙**을 선택한다.

#### 한줄 요약
- 서로 바꿔도 되는 표본은 무작위, 소수 반이 사라질 위험은 층화, 같은 사람의 반복 기록은 그룹, 미래 예측은 시간 순서로 나눈다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **전처리 적합**: 결측 처리나 척도 변환의 기준을 훈련 폴드만으로 계산하는 과정이다.
- **일반화 성능**: 학습에 사용하지 않은 새 데이터에서의 예측 성능이다.
- **개체 정보 누수**: 같은 사용자•장비의 기록이 훈련과 검증 폴드에 나뉘어 정체 정보를 공유하는 누수이다.
- **소수 클래스**: 전체 표본에서 다른 클래스보다 개수가 적은 정답 범주이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 전처리 기준의 **데이터 누수** | 훈련 폴드에서만 **전처리 적합** | **일반화 성능** 과대평가 방지 |
| 동일 사용자•장비의 **반복 측정** 분산 | **그룹 K-Fold** 적용 | **개체 정보 누수** 방지 |
| **소수 클래스**의 폴드별 소실 | **층화 K-Fold**와 최소 클래스 수 점검 | 평가 지표의 분할 변동 감소 |
| **시계열 분할**을 무작위 혼합으로 대체 | 과거 학습•미래 검증 순서 보존 | 배포 시점 성능 모사 |

#### 한줄 요약
- 시험반의 평균을 미리 본 채 표준화하면 답을 엿본 셈이므로, 전처리 기준과 모델은 매 회차 공부반 안에서만 다시 계산한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **표본 의존성**: 같은 개체나 시간 관계 때문에 관측값들이 서로 독립적이지 않은 성질이다.
- **분할 방식**: 일반•층화•그룹•시계열 중 데이터 생성 구조에 맞춰 폴드를 만드는 규칙이다.

</details>

- **표본 의존성**•불균형•시간 순서에 따라 **분할 방식**을 결정 체계 적용

#### 한줄 요약
- 같은 사람 기록이 섞이는지, 소수 클래스가 사라지는지, 미래가 과거 학습에 들어가는지를 먼저 막고 교차 검증 방식을 고른다.
