## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **조합 논리 회로(Combinational Logic Circuit)**: 내부 상태를 기억하는 플립플롭/래치 메모리 소자 없이 오직 현재 인입된 입력 신호들의 부울 논리 조합만으로 출력이 즉시 결정되는 무상태(Stateless) 회로.
- **전파 지연(Propagation Delay, $t_{pd}$)**: 입력 신호가 게이트를 통과하여 출력단에 안정된 전압 레벨로 반영되기까지 소요되는 물리적 시간.
- **임계 경로(Critical Path)**: 입력에서 출력까지 거치는 논리 게이트들의 지연 시간 합산이 가장 길어 회로의 최대 동작 주파수($f_{max}$)를 결정하는 경로.

</details>

- 정의/개념: 플립플롭이나 피드백 루프 없이 현재 입력 신호의 부울 대수 연산으로 출력을 결정하는 무상태(Stateless) 디지털 논리 회로
- 배경/필요성: 순수 수치 연산 및 제어 신호 변환에서 메모리 소자 사용 시 수반되는 면적·전력 낭비와 클록 동기화 지연 오버헤드

#### 한줄 요약

- 상태를 버린 덕에 검증은 진리표 전수로 끝나지만, 그 대가로 임계 경로 지연이 곧 클록 주기의 상한이 된다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **피드백 부재(No Feedback Loop)**: 출력이 입력으로 되돌아가는 폐루프가 없어 발진(Oscillation)이나 이전 상태 기억이 불가능한 구조.
- **글리치(Glitch / Hazard)**: 게이트 간 신호 전파 속도 차이로 인해 출력이 일시적으로 0$\to$1 또는 1$\to$0으로 튀는 원치 않는 스위칭 노이즈.

</details>

- 메모리 소자가 없어 **과거 입력 이력과 무관하게 현재 입력에만 종속**
- 피드백 경로가 없으므로 **진리표(Truth Table) 기반의 전수 기능 검증 및 정적 타이밍 분석(STA)** 가능
- 임계 경로의 최대 전파 지연 시간이 시스템의 **최소 클록 주기($T_{clk} \ge t_{pd} + t_{setup}$)** 를 제한

#### 한줄 요약

- 피드백 루프가 없어 진리표로 출력이 확정되며, 임계 경로 지연이 시스템 최대 클록 주파수를 제한한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **전가산기(Full Adder)**: 2개 비트와 하위 캐리를 더해 합(Sum)과 출력 캐리(Cout)를 생성하는 기본 산술 소자.
- **멀티플렉서(Multiplexer, MUX)**: $n$개의 선택 신호로 $2^n$개의 입력 데이터 중 하나를 선택 출력하는 데이터 선택 소자.
- **디코더(Decoder)**: $n$비트 입력 코드를 $2^n$개의 고유 출력선 중 1개만 활성화하는 복호화 소자.

</details>

```text
[조합 논리 회로 프레임워크]
  │
  ├─ [입력 신호단] (데이터 및 제어선 수신)
  │     ├─ 피연산자 데이터선 (수치 데이터 비트 수신)
  │     └─ 제어/선택선 (MUX 선택 및 디코더 인에이블)
  │
  ├─ [부울 게이트망] (무상태 조합 연산)
  │     ├─ 산술 연산 소자 (전가산기, 감산기, 비교기)
  │     └─ 경로 선택 소자 (멀티플렉서, 디코더, 인코더)
  │
  └─ [출력 신호단] (안정화 출력 전달)
        ├─ 조합 연산 출력선 (Sum, Carry, 복호화 결과)
        └─ 차기 래치단 (레지스터 셋업 마진 확보 후 래치)
```

- 선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 입력 신호단 | 피연산자 데이터 및 제어/선택 신호 제공 |
| 부울 게이트망 | 입력 조합을 **부울 함수(SOP/POS)** 에 따라 논리 변환 |
| 출력 신호단 | 가산 결과(Sum), 선택 데이터, 복호화 신호 출력 |

#### 한줄 요약

- 게이트망이 저장 상태 없이 현재 입력 조합을 논리 출력으로 변환한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **정적 타이밍 분석(STA, Static Timing Analysis)**: 클록 동기화 회로에서 조합 논리 블록의 전파 지연이 셋업 타임(Setup Time) 제약을 만족하는지 수학적으로 검증하는 기법.

</details>

```text
+------------------------------------------+
|  입력 신호 인입 (Input Transition)       |
+--------------------+---------------------+
                     |
                     v
+------------------------------------------+
|  1. 부울 게이트망 스위칭 및 신호 전파   |
+--------------------+---------------------+
                     |
                     v
           /--------------------\
          <   경로 지연 불균형?  >
           \--------------------/
            |                  |
      Yes   |                  | No (균일 경로)
            v                  v
[ 일시적 글리치(Glitch) ]    [ 선형 전파 지속 ]
            |                  |
            +-------->---------+
                     |
                     v
+------------------------------------------+
|  2. 최장 임계 경로 지연(tpd,max) 경과    |
+--------------------+---------------------+
                     |
                     v
+------------------------------------------+
|  3. 출력 레벨 안정화 (Steady State)      |
+--------------------+---------------------+
                     |
                     v
[ 후속 플립플롭 클록 엣지에 안전하게 래치 ]
```

분기 결과: 게이트 간 신호 전파 경로의 불균형으로 인해 일시적인 글리치(스위칭 노이즈)가 발생할 수 있으나, 최장 임계 경로 지연($t_{pd, \max}$)이 경과하면 모든 출력이 정상 논리 레벨로 안정화되어 후속 레지스터에 래치된다.

**동작 원리**:
1. **입력 신호 인입 및 천이**: 클록 비동기식으로 외부 입력 핀의 전압 레벨이 0 또는 1로 천이(Transition)된다.
2. **게이트 스위칭 및 다경로 전파**: 인입된 신호가 부울 게이트망의 트랜지스터를 통과하며 스위칭되고, 회로 구조에 따라 서로 다른 경로 지연을 거쳐 전파된다.
3. **과도 상태 및 글리치 감쇠**: 신호 도달 시간 차이에 의해 출력단에 순간적인 스위칭 노이즈(Glitch)가 발생할 수 있으나 유효 경로 전파가 진행됨에 따라 자연 감쇠된다.
4. **임계 경로 지연 완료**: 회로 내에서 가장 긴 논리 깊이를 가진 임계 경로의 최대 전파 지연($t_{pd, \max}$)이 경과하면 모든 출력 핀의 전압 레벨이 부울 진리표와 일치하게 정착된다.
5. **동기식 레지스터 래치**: 후속 동기식 플립플롭의 셋업 타임($t_{\text{setup}}$) 마진을 충족한 상태에서 다음 클록 상승 에지에 유효한 연산 결과를 메모리 소자에 안전하게 래치한다.

#### 한줄 요약

- 입력 변화는 여러 게이트 경로를 지나며, 가장 느린 경로가 끝난 뒤 출력이 안정된다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **RCA(Ripple Carry Adder)**: 하위 전가산기의 캐리가 상위로 순차 전달되는 $O(N)$ 지연 구조.
- **CLA(Carry Lookahead Adder)**: Generate($G = AB$)와 Propagate($P = A \oplus B$) 신호로 캐리를 병렬 산출하는 $O(\log N)$ 고속 가산기.

</details>

| 조합 회로 소자 | 전가산기 (Full Adder) | 멀티플렉서 (MUX) | 디코더 (Decoder) |
|:---|:---|:---|:---|
| 적용 기준 | 2개 비트와 캐리의 **산술 합산** | 다수 입력선 중 **단일 데이터 경로 선택** | $n$비트 코드를 $2^n$개 활성선으로 **복호화** |
| 핵심 수식 | $\text{Sum} = A \oplus B \oplus C_{in}$ | $Y = \sum I_k \cdot m_k(\text{Sel})$ | $Y_k = m_k(A_{n-1} \dots A_0)$ |
| 한계 | 비트 폭 증가 시 **캐리 전파 지연(RCA)** | 입력 채널 확장 시 **팬인(Fan-in) 부하** | 출력선 증가 시 **배선 복잡도 및 글리치** |

#### 한줄 요약

- 산술 연산은 전가산기, 데이터 선택은 멀티플렉서, 주소 해독은 디코더를 적용한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **선견 자리올림 가산기(Carry Lookahead Adder, CLA)**: 캐리 생성 및 전달 신호를 미리 계산하여 자리올림 전파 지연을 $O(\log N)$으로 단축하는 고속 가산기.
- **파이프라이닝(Pipelining)**: 긴 조합 논리 경로 중간에 파이프라인 레지스터를 삽입하여 임계 경로를 분할하고 클록 주파수를 2배 이상 향상시키는 설계 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| RCA 가산기의 **자리올림 전파 지연($O(N)$)** 누적 | **선견 자리올림(CLA)** 또는 Kogge-Stone 트리 가산기 적용 | 64비트 가산 지연을 $O(\log N)$으로 단축 |
| 대용량 MUX의 **팬인(Fan-in) 및 배선 지연** 급증 | 2:1, 4:1 MUX 기반 **계층형 트리 구조** 구성 | 입력 로딩 및 전파 지연 최소화 |
| 경로 지연 차이에 의한 출력 **글리치(Glitch)** | 플립플롭 동기화 레지스터 배치 및 **합의항 삽입** | 다운스트림 회로 오작동 원천 차단 |
| 긴 조합 경로로 인한 **클록 주기 초과** | 중간 단계에 레지스터를 삽입하는 **파이프라이닝** | 프로세서 최대 **동작 주파수($f_{max}$)** 극대화 |

#### 한줄 요약

- CLA 캐리 선행으로 고속 가산을 확보하고, 계층형 MUX 트리로 선택 지연을 줄이며, 파이프라이닝으로 클록 주기를 단축하고 동기화 레지스터로 글리치 전파를 차단한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **병렬 전주 가산기(Parallel Prefix Adder, PPA)**: 자리올림 생성을 트리 형태의 이진 프리픽스 연산으로 병렬화하여 지연을 $O(\log_2 N)$으로 최소화하는 초고속 가산기.
- **신경망 처리 장치(Neural Processing Unit, NPU)**: 딥러닝 인공신경망의 대규모 행렬 곱셈과 활성화 함수를 고효율로 가속하는 전용 하드웨어 연산기.
- **근사 가산기(Approximate Adder)**: 하위 비트 자리올림 로직을 단순화하여 미세한 오차를 허용하는 대신 회로 면적과 동적 전력 소모를 대폭 절감한 연산 회로.

</details>

- 조합 논리 회로는 프로세서 데이터패스의 선견 자리올림 가산기(CLA)를 넘어 병렬 전주 가산기(PPA) 및 AI NPU용 저전력 근사 가산기(Approximate Adder) 아키텍처로 진화 추세.
- 실무 반도체 데이터패스 설계 시에는 임계 경로 지연 단축을 위해 다단 파이프라이닝 분할을 집행하고, 계층형 MUX 트리와 동기식 레지스터 배치를 통해 글리치 전파를 차단하는 타이밍 마진 확보 필요.

#### 한줄 요약

- 조합 회로는 병렬 전주(PPA) 트리 및 NPU 근사 가산기로 진화하고 있으며, 실무에서는 파이프라이닝 분할과 계층형 MUX를 통한 임계 경로 통제가 핵심이다.
