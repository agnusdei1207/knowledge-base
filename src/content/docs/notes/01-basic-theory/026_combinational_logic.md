## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **조합 논리 회로(Combinational Logic)**: 기억 소자 없이 현재 입력 조합만으로 출력을 정하는 무상태 회로이다.
- **피드백 경로**: 회로 출력을 다시 입력으로 되돌려 이전 상태가 다음 출력에 영향을 주게 하는 연결이다.
- **무상태 디지털 회로**: 저장된 과거 상태 없이 현재 입력 조합만으로 출력을 결정하는 회로이다.

</details>

- 정의/개념: 기억 소자와 상태 피드백 없이 현재 입력값의 부울 함수만으로 출력을 결정하는 무상태 디지털 회로이다.
- 배경/필요성: 덧셈•선택•복호처럼 현재 입력만 변환하는 기능에 상태 저장을 넣으면 불필요한 회로 면적과 타이밍•상태 검증 부담이 생긴다.

#### 한줄 요약

- 자동판매기가 현재 버튼만 보고 상품을 고르듯, 조합 회로는 기억 없이 현재 입력으로 출력을 계산한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **진리표(Truth Table)**: 모든 입력 조합과 출력값의 대응을 나열한 표이다.
- **부울식 최소화**: 같은 진리표를 유지하면서 논리항과 게이트 수를 줄이는 변환한다.
- **크리티컬 패스(Critical Path)**: 누적 전파 지연이 가장 커 동작 속도를 제한하는 경로이다.
- **클록 주기**: 레지스터 저장 사이의 시간 간격으로 크리티컬 패스 지연보다 길어야 하는 값이다.
- **회로 면적**: 게이트와 배선이 반도체 칩에서 차지하는 물리적 공간이다.

</details>

- **피드백 경로** 부재로 **진리표** 전수 검증 가능이 핵심이다.
- **부울식 최소화**로 게이트 수•회로 면적 감소한다.
- **크리티컬 패스** 지연이 만드는 **클록 주기** 하한이 핵심이다.

#### 한줄 요약

- 모든 버튼 조합의 출력을 진리표로 확인할 수 있지만, 신호가 가장 많은 문을 통과하는 크리티컬 패스보다 클록을 빠르게 울릴 수는 없다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **디코더(Decoder)**: 입력 코드에 대응하는 출력선 하나를 활성화하는 회로이다.
- **멀티플렉서(Multiplexer)**: 선택 신호에 따라 여러 입력 중 하나를 출력하는 회로이다.
- **전가산기(Full Adder)**: 두 비트와 하위 자리올림을 더해 합과 상위 자리올림을 내는 회로이다.
- **데이터 경로(Data Path)**: 연산기•선택기•레지스터를 연결해 데이터를 이동하고 처리하는 회로 경로이다.
- **제어 코드**: 수행할 연산이나 사용할 데이터 경로를 지정하는 비트 조합한다.
- **선택 신호**: 멀티플렉서가 통과시킬 입력을 지정하는 신호이다.
- **피연산자(Operand)**: 산술이나 논리 연산의 대상이 되는 입력값이다.

</details>

```text
[조합 논리 회로]
        |
        +-- [입력 신호]
        +-- [부울 함수 게이트망]
        `-- [출력 신호]
```

선의 의미: 조합 논리 회로를 이루는 입출력 경계와 논리 변환부를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 입력 신호 | 피연산자•선택 코드 등 **현재 입력** 제공 |
| 부울 함수 게이트망 | 입력 조합을 **논리 함수**로 변환 |
| 출력 신호 | 가산•선택•해독의 **현재 결과** 제공 |

#### 한줄 요약

- 게이트망이 저장 상태 없이 현재 입력 조합을 논리 출력으로 변환한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **전파 지연(Propagation Delay)**: 입력 변화가 게이트 경로를 지나 출력에 반영될 때까지의 시간이다.
- **출력 안정화**: 모든 경로의 신호 전파가 끝나 출력이 요구 논리값으로 확정된 상태이다.
</details>

```text
[입력 신호 변화]
        |
        v
1. 논리 함수 평가
        |
        v
2. 게이트 경로 전파
        |
        +-- 경로 지연 차 --> [일시적 글리치]
        |
        v
3. 출력 안정화
        |
        v
[현재 입력에 대응하는 출력]
```

### 동작 원리

- **1. 논리 함수 평가**: 현재 입력으로 부울 출력을 계산한다.
- **2. 게이트 경로 전파**: 각 경로를 따라 신호 변화를 전달한다.
- **3. 출력 안정화**: 크리티컬 패스 뒤 최종 출력 확정이다.

#### 한줄 요약

- 입력 변화는 여러 게이트 경로를 지나며, 가장 느린 경로가 끝난 뒤 출력이 안정된다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **팬인(Fan-in)**: 한 논리 게이트가 직접 받아들이는 입력 신호의 수이다.
- **글리치(Glitch)**: 경로 지연 차이로 순간 발생하는 잘못된 출력이다.
- **자리올림 전파(Carry Propagation)**: 하위 자리의 캐리가 상위 자리 가산기로 연속 전달되는 과정이다.

</details>

| 조합 논리 회로 | 논리 기능 | 구성 시 주의 지점 |
|:---|:---|:---|
| **전가산기** | 두 비트와 하위 **캐리 입력**을 합산 | 다비트 배열의 **자리올림 전파** 지연 |
| **멀티플렉서** | 선택 신호에 맞는 **입력 경로** 하나를 출력 | 입력 수 증가에 따른 **팬인•배선 지연** |
| **디코더** | 입력 코드에 대응하는 **출력선** 활성화 | 출력선 증가와 경로 차에 따른 **글리치** |

#### 한줄 요약

- 두 수와 아랫자리 올림을 합치면 전가산기, 여러 선 중 하나를 통과시키면 멀티플렉서, 코드 하나를 출력선 하나로 펼치면 디코더다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **선견 자리올림(Carry Lookahead)**: 자리올림을 병렬 계산해 지연을 줄이는 가산 구조이다.
- **선택 자리올림(Carry Select)**: 두 결과를 미리 계산해 지연을 줄이는 가산 구조이다.
- **배선 지연(Wire Delay)**: 신호가 연결선의 저항•정전용량 때문에 늦게 도착하는 시간이다.
- **파이프라인 분할(Pipelining)**: 긴 조합 경로에 레지스터를 넣어 여러 단계로 나누는 기법이다.
- **동작 주파수**: 회로가 1초에 수행할 수 있는 클록 주기의 수이다.
- **계층형 선택기**: 많은 입력을 여러 단계의 작은 멀티플렉서로 나누어 선택하는 구조이다.
- **레지스터 표본화**: 정해진 클록 시점의 조합 회로 출력을 레지스터에 저장하는 처리이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 자리올림 사슬의 **지연 누적** | **선견•선택 자리올림** 구조 | 가산 **크리티컬 패스** 단축 |
| 멀티플렉서 **팬인 증가** | 계층형 선택기•**경로 분할** | 부하•**배선 지연** 감소 |
| 경로 지연 차의 **글리치** | 안정 시점 **레지스터 표본화** | 순간 **오출력 전파** 방지 |
| 조합 경로의 **클록 주기** 초과 | 중간 레지스터로 **파이프라인 분할** | 최대 **동작 주파수** 향상 |

#### 한줄 요약

- 신호가 긴 게이트 길을 지나 늦거나 갈림길마다 도착 시간이 달라 순간 깜박이면, 선견 논리•계층 선택기•중간 레지스터로 경로를 줄인다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **가산**: 두 피연산자와 자리올림을 더하는 논리 기능이다.
- **경로 선택**: 여러 입력 중 하나를 출력으로 연결하는 논리 기능이다.
- **해독**: 입력 코드를 대응 출력선으로 바꾸는 논리 기능이다.
- **중간 레지스터**: 긴 조합 경로를 여러 클록 단계로 나누기 위해 사이에 배치하는 저장 소자이다.

</details>

- 가산은 **전가산기**, 경로 선택은 **멀티플렉서**, 해독은 디코더를 선택한다.

#### 한줄 요약

- 가장 늦은 신호가 다음 클록 종보다 늦게 도착하면 자리올림을 미리 계산하거나 중간 레지스터를 세워 여러 구간으로 나눈다.
