## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **조합 논리 회로(Combinational Logic Circuit)**: 내부 상태를 기억하는 플립플롭/래치 메모리 소자 없이 오직 현재 인입된 입력 신호들의 부울 논리 조합만으로 출력이 즉시 결정되는 무상태(Stateless) 회로.
- **전파 지연(Propagation Delay, $t_{pd}$)**: 입력 신호가 게이트를 통과하여 출력단에 안정된 전압 레벨로 반영되기까지 소요되는 물리적 시간.
- **임계 경로(Critical Path)**: 입력에서 출력까지 거치는 논리 게이트들의 지연 시간 합산이 가장 길어 회로의 최대 동작 주파수($f_{max}$)를 결정하는 경로.

</details>

- 정의/개념: 플립플롭이나 피드백 루프 없이 현재 입력 신호의 부울 대수 연산으로 출력을 결정하는 **무상태(Stateless) 디지털 논리 회로**
- 배경/필요성: 산술 연산(ALU), 데이터 라우팅(MUX), 명령어 해독(Decoder) 등에서 **지연 시간을 최소화하고 상태 불일치 없는 즉각적 데이터 처리 필수**

#### 한줄 요약

- 내부 기억 소자 없이 현재 입력 신호의 부울 조합만으로 출력을 결정하는 무상태 회로

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **피드백 부재(No Feedback Loop)**: 출력이 입력으로 되돌아가는 폐루프가 없어 발진(Oscillation)이나 이전 상태 기억이 불가능한 구조.
- **글리치(Glitch / Hazard)**: 게이트 간 신호 전파 속도 차이로 인해 출력이 일시적으로 0$\to$1 또는 1$\to$0으로 튀는 원치 않는 스위칭 노이즈.

</details>

- 메모리 소자가 없어 **과거 입력 이력과 무관하게 현재 입력에만 종속**
- 피드백 경로가 없으므로 **진리표(Truth Table) 기반의 전수 기능 검증 및 정적 타이밍 분석(STA)** 가능
- 임계 경로의 최대 전파 지연 시간이 시스템의 **최소 클록 주기($T_{clk} \ge t_{pd} + t_{setup}$)** 를 제한

#### 한줄 요약

- 피드백 루프가 없어 진리표로 출력이 확정되며, 임계 경로 지연이 시스템 최대 클록 주파수를 제한

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **조합 논리 3대 핵심 소자**:
  - 전가산기 (Full Adder): 2개 비트와 하위 캐리를 더해 합(Sum)과 출력 캐리(Cout) 생성.
  - 멀티플렉서 (MUX): $n$개의 선택 신호로 $2^n$개의 입력 데이터 중 하나를 선택 출력.
  - 디코더 (Decoder): $n$비트 입력 코드를 $2^n$개의 고유 출력선 중 1개만 활성화.

</details>

```text
[ 조합 논리 회로 기본 아키텍처 ]
┌──────────────────────────────┐
│ 입력 신호 (Inputs)           │ ── 피연산자 A, B 및 제어/선택 신호 Sel
├──────────────────────────────┤
│ 부울 게이트망 (Gate Network) │ ── AND, OR, XOR, NAND 등으로 구성된 무상태망
├──────────────────────────────┤
│ 출력 신호 (Outputs)          │ ── 가산 결과(Sum), 선택 데이터, 디코딩 라인
└──────────────────────────────┘
```

선의 의미: 입력 신호 인입, 내부 게이트망 논리 연산, 출력 신호 도출 간의 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 입력 신호단 | 피연산자 데이터 및 제어/선택 신호 제공 |
| 부울 게이트망 | 입력 조합을 **부울 함수(SOP/POS)** 에 따라 논리 변환 |
| 출력 신호단 | 가산 결과(Sum), 선택 데이터, 복호화 신호 출력 |

#### 한줄 요약

- 게이트망이 저장 상태 없이 현재 입력 조합을 논리 출력으로 변환

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **정적 타이밍 분석(STA, Static Timing Analysis)**: 클록 동기화 회로에서 조합 논리 블록의 전파 지연이 셋업 타임(Setup Time) 제약을 만족하는지 수학적으로 검증하는 기법.

</details>

```text
입력 신호 변화 (Input Transition)
   │
   ▼
[ 1. 부울 함수 평가 및 게이트 스위칭 ]
   │
   ▼
[ 2. 신호 전파 및 다경로 지연 발생 ]
   ├─ 경로 지연 불균형 ⟹ [ 일시적 글리치(Glitch) 발생 가능 ]
   └─ 최장 경로 전파 지속
   │
   ▼
[ 3. 임계 경로 지연(Critical Path Delay) 경과 ]
   │
   ▼
[ 4. 출력 레벨 안정화 (Output Settling) ]
   │
   ▼
플립플롭 레지스터에 유효 데이터 래치 (Clock Edge)
```

**동작 원리**

1. **입력 신호 인입**: 입력 핀의 전압 레벨이 변경되면서 조합 논리 게이트의 스위칭 시작
2. **신호 전파**: 게이트 단수 및 배선 지연에 따라 신호가 출력단으로 전파되며 일시적 글리치 발생 가능
3. **임계 경로 경과**: 가장 느린 임계 경로의 전파 지연($t_{pd, max}$)이 지나면 모든 출력이 안정화
4. **결과 래치**: 클록 엣지 시점에 후속 플립플롭이 안정화된 조합 출력을 셋업 타임 위반 없이 저장

#### 한줄 요약

- 입력 변화는 여러 게이트 경로를 지나며, 가장 느린 경로가 끝난 뒤 출력이 안정

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **RCA(Ripple Carry Adder)**: 하위 전가산기의 캐리가 상위로 순차 전달되는 $O(N)$ 지연 구조.
- **CLA(Carry Lookahead Adder)**: Generate($G = AB$)와 Propagate($P = A \oplus B$) 신호로 캐리를 병렬 산출하는 $O(\log N)$ 고속 가산기.

</details>

| 비교 항목 | 전가산기 (Full Adder) | 멀티플렉서 (MUX) | 디코더 (Decoder) |
|:---|:---|:---|:---|
| 주요 기능 | 2개 비트와 캐리의 **산술 합산** | 다수 입력선 중 **단일 데이터 경로 선택** | $n$비트 코드를 $2^n$개 활성선으로 **복호화** |
| 핵심 수식 | $\text{Sum} = A \oplus B \oplus C_{in}$ | $Y = \sum I_k \cdot m_k(\text{Sel})$ | $Y_k = m_k(A_{n-1} \dots A_0)$ |
| 설계 주의점 | 비트 폭 증가 시 **캐리 전파 지연(RCA)** | 입력 채널 확장 시 **팬인(Fan-in) 부하** | 출력선 증가 시 **배선 복잡도 및 글리치** |

#### 한줄 요약

- 산술 연산은 전가산기, 데이터 선택은 멀티플렉서, 주소 해독은 디코더를 적용

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **파이프라이닝(Pipelining)**: 긴 조합 논리 경로 중간에 파이프라인 레지스터를 삽입하여 임계 경로를 분할하고 클록 주파수를 2배 이상 향상시키는 설계 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| RCA 가산기의 **자리올림 전파 지연($O(N)$)** 누적 | **선견 자리올림(CLA)** 또는 Kogge-Stone 트리 가산기 적용 | 64비트 가산 지연을 $O(\log N)$으로 단축 |
| 대용량 MUX의 **팬인(Fan-in) 및 배선 지연** 급증 | 2:1, 4:1 MUX 기반 **계층형 트리 구조(Hierarchical MUX)** 구성 | 입력 로딩 및 전파 지연 최소화 |
| 경로 지연 차이에 의한 출력 **글리치(Glitch)** | 플립플롭 동기화 레지스터 배치 및 **합의항(Consensus) 삽입** | 다운스트림 회로 오작동 원천 차단 |
| 긴 조합 경로로 인한 **클록 주기($T_{clk}$) 초과** | 중간 단계에 레지스터를 삽입하는 **파이프라이닝(Pipelining)** | 프로세서 최대 **동작 주파수($f_{max}$)** 극대화 |

#### 한줄 요약

- CLA 캐리 선행으로 고속 가산을 확보하고, 계층형 MUX 트리로 선택 지연을 줄이며, 파이프라이닝으로 클록 주기를 단축하고 동기화 레지스터로 글리치 전파를 차단한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **디지털 데이터패스 설계 표준**: CPU의 ALU 및 데이터 경로는 순수 조합 논리로 연산 로직을 구성하고, 그 경계에 동기식 레지스터를 배치하여 타이밍 슬랙(Slack)을 확보하는 파이프라인 구조가 표준.

</details>

- 산술/선택/해독은 **조합 논리 회로**, 임계 경로 지연 단축은 **파이프라이닝 및 CLA 가산기** 선택

#### 한줄 요약

- 산술•선택•해독 기능은 조합 논리로 구성하고, 임계 경로 지연은 CLA 가산기 및 파이프라이닝으로 단축
