## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **앙상블 학습**: 여러 모델의 예측을 결합해 일반화 오차를 줄이는 학습 방식이다.
- **편향(Bias)**: 모델의 체계적 오차이다.
- **분산(Variance)**: 학습 표본 변화에 대한 모델 예측의 민감도이다.
- **기본 학습기(Base Learner)**: 앙상블을 구성하며 개별 예측을 만드는 모델이다.
- **오류 양상**: 모델이 어떤 표본과 조건에서 틀리는지를 나타내는 패턴이다.

</details>

- 정의/개념: **앙상블 학습**은 서로 다른 표본•특징•학습 순서로 만든 기본 학습기들의 **오류 양상**을 상쇄하도록 예측을 투표, 평균 또는 가중합으로 결합하는 학습 기법이다.
- 배경/필요성: 단일 모형의 구조만 조정해서는 편향과 분산을 동시에 낮추기 어려우므로 서로 다른 오류를 상쇄하거나 앞선 오류를 순차 보완해야 한다.

#### 한줄 요약
- 여러 기본 학습기가 서로 다른 오류를 내고 투표·평균 결합에서 오류가 상쇄되어 단일 모델보다 일반화 오차가 줄어든다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **다양성**: 기본 학습기들이 서로 다른 표본에서 틀리는 성질이다.
- **오류 상관**: 여러 모델이 같은 표본에서 함께 틀리는 정도이다.
- **일반화 오차**: 학습하지 않은 새 데이터에서 발생하는 예측 오차이다.
- **투표 결합(Voting)**: 분류 예측의 다수결로 최종값을 만드는 방식이다.
- **평균 결합(Averaging)**: 수치 예측의 산술 평균으로 최종값을 만드는 방식이다.

</details>

- 서로 다른 학습기 예측의 **투표 결합**•**평균 결합**이 핵심이다.
- 데이터•특징•알고리즘 **다양성**으로 오류 상관을 낮춰 일반화 오차를 축소한다.

#### 한줄 요약
- 모든 학습기가 같은 표본에서 오분류하면 결합도 실패하므로, 오류 상관을 낮추는 다양성 확보가 핵심이다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **부트스트랩 표본**: 중복 추출을 허용해 원본에서 만든 서로 다른 학습 표본 집합이다.
- **메타 모델**: 기본 모델들의 예측을 입력받아 최종 답을 학습하는 상위 모델이다.
- **표본 가중치(Sample Weight)**: 각 표본이 학습에 기여하는 비중이다.
- **폴드(Fold)**: 교차검증을 위해 나눈 데이터 부분집합이다.
- **학습 집합**: 모델 파라미터를 학습하는 데 사용하는 표본 모음이다.
- **개별 예측**: 각 기본 학습기가 독립적으로 산출한 예측값이다.

</details>

```text
[표본 생성기] -- [기본 학습기] -- [예측 결합기]
```

선의 의미: 기본 학습기가 표본 생성기의 학습 집합을 사용하고 예측 결합기가 기본 학습기의 개별 예측을 공유하는 정적 의존 관계다.

| 구성요소 | 책임 |
|:---|:---|
| 표본 생성기 | **부트스트랩 표본**•**표본 가중치**•**폴드**로 서로 다른 **학습 집합** 구성 |
| 기본 학습기 | 개별 학습 집합에서 서로 다른 **개별 예측** 산출 |
| 예측 결합기 | 투표•평균•**메타 모델**로 최종 예측 산출 |

#### 한줄 요약
- 표본 생성기가 서로 다른 학습 집합을 구성하고 각 기본 학습기의 개별 예측이 예측 결합기로 집계된다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **가중치 표본화**: 표본마다 선택 비중을 달리해 학습 집합을 구성하는 방식이다.
- **부트스트랩(Bootstrap)**: 원본 데이터에서 중복을 허용해 표본을 다시 뽑는 방법이다.
- **예측 결합기**: 개별 예측을 투표•평균하거나 메타 모델로 결합하는 구성요소이다.
- **폴드 외 예측(Out-of-Fold Prediction, OOF Prediction)**: 모델이 학습하지 않은 폴드에서 만든 예측값이다.
- **오류 원인 판별**: 단일 모델의 편향•분산과 후보 모델의 다양성을 진단하는 단계이다.
- **배깅 선택**: 높은 분산을 줄이기 위해 부트스트랩 병렬 학습을 택하는 단계이다.
- **부스팅 선택**: 높은 편향을 줄이기 위해 앞선 오류의 순차 보완을 택하는 단계이다.
- **스태킹 선택**: 이종 모델의 폴드 외 예측을 메타 모델로 결합하는 방식을 택하는 단계이다.
- **검증 이득•추론 비용 비교**: 단일 모델 대비 성능 향상과 운영 부담을 함께 판정하는 단계이다.

</details>

```text
[단일 모델의 오류 진단]
          |
          v
1. 오류 원인 판별
          |
          +-- 높은 분산 ------> 2. 배깅 선택
          |
          +-- 높은 편향 ------> 3. 부스팅 선택
          |
          `-- 이종 모델 보유 -> 4. 스태킹 선택

[선택한 앙상블 후보]
          |
          v
5. 검증 이득•추론 비용 비교
          |
          +-- 이득 부족 --> [단일 모델 유지]
          |
          v
[앙상블 채택]
```

### 동작 원리

- **1. 오류 원인 판별**: 편향•분산과 모델 다양성을 진단한다.
- **2. 배깅 선택**: 부트스트랩 병렬 학습과 평균•투표를 선택한다.
- **3. 부스팅 선택**: **가중치 표본화**로 앞선 오류를 다음 모델이 순차 보완하도록 선택한다.
- **4. 스태킹 선택**: OOF 예측을 메타 모델로 결합한다.
- **5. 검증 이득•추론 비용 비교**: 성능 향상과 운영 부담을 판정한다.
- 선택한 방식의 **예측 결합기**가 개별 예측을 평균•투표하거나 메타 모델로 결합한다.

#### 한줄 요약
- 서로 다른 학습 집합에서 산출한 개별 예측이 투표·평균·메타 모델 결합을 거쳐 하나의 최종 예측이 된다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **배깅**: 여러 모델을 병렬 학습한 뒤 예측을 평균하거나 투표하는 방식이다.
- **부스팅**: 앞선 모델의 오류를 다음 모델이 순차적으로 보완하는 방식이다.
- **스태킹**: 기본 모델의 폴드 외 예측을 메타 모델이 결합하는 방식이다.
- **랜덤 포레스트(Random Forest)**: 부트스트랩 표본과 무작위 특징으로 학습한 결정 트리들을 평균•투표하는 배깅 모델이다.
- **잔차(Residual)**: 관측값에서 현재 모델의 예측값을 뺀 오차이다.
- **데이터 누수**: 검증 정보가 학습 과정에 섞여 성능이 과대평가되는 현상이다.
- **이종 모델**: 알고리즘이나 오류 양상이 서로 다른 기본 학습기들의 조합이다.
- **이상치(Outlier)**: 다른 표본에서 크게 벗어나 부스팅 가중치가 과도하게 집중될 수 있는 값이다.

</details>

| 앙상블 기법 | 배깅 | 부스팅 | 스태킹 |
|:---|:---|:---|:---|
| 적용 기준 | 같은 모델의 **분산**이 큰 경우 | **편향**이 크고 잡음이 적은 경우 | 성격이 다른 **이종 모델**이 있는 경우 |
| 핵심 특징 | **랜덤 포레스트**의 병렬 평균•투표 | 앞선 **잔차**의 순차 보완 | **폴드 외 예측**을 메타 모델로 결합 |
| 한계 | 모델 간 높은 **오류 상관** | 잡음•**이상치** 과집중 | 학습 예측값의 **데이터 누수** |

> 요약: 분산 과다는 배깅, 편향 과다는 부스팅, 이종은 **스태킹**이 핵심이다.

#### 한줄 요약
- 배깅은 병렬 학습 후 투표·평균 결합, 부스팅은 앞선 오류의 순차 보완, 스태킹은 이종 모델의 폴드 외 예측을 메타 모델로 결합한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **순차 과적합**: 부스팅이 앞선 오차를 반복 보완하다 잡음까지 학습하는 현상이다.
- **학습률(Learning Rate)**: 부스팅에서 새 모델의 기여도를 조절하는 값이다.
- **트리 깊이(Tree Depth)**: 각 결정 트리의 복잡도 한도이다.
- **운영 지연(Operational Latency)**: 여러 모델을 실행하고 결합하는 응답시간이다.
- **운영 비용(Operational Cost)**: 여러 모델 실행에 드는 자원 사용량이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 모델들이 같은 표본에서 함께 오분류 | 데이터•특징•알고리즘 **다양성** 확대 | **오류 상관** 감소•결합 이득 확보 |
| 부스팅이 잡음•**이상치**에 집중 | **학습률**•**트리 깊이** 제한과 이상치 검토 | **순차 과적합** 완화 |
| 스태킹 검증 성능이 비정상적으로 높음 | **OOF 예측**만 메타 모델 학습에 사용 | **데이터 누수** 방지 |
| 성능 향상보다 추론 비용 증가가 큼 | 모델 수 축소•**운영 지연**•**운영 비용** 기준 설정 | 운영 효율 유지 |

#### 한줄 요약
- 트리를 한 그루씩 늘리며 검증 성능과 추론 지연을 함께 모니터링하고 이득이 정체된 지점에서 추가를 중단한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **검증 이득**: 앙상블이 단일 모델보다 검증 데이터에서 얻는 성능 향상이다.
- **추론 비용**: 운영 중 여러 모델의 예측을 계산하고 결합하는 데 드는 시간과 자원이다.
- **앙상블(Ensemble)**: 오류가 다른 여러 모델의 예측을 결합해 일반화 성능을 높이는 방식이다.
- **앙상블 채택 기준**: 검증 이득이 추가 추론 비용을 상쇄하는지 판단하는 기준이다.

</details>

- **앙상블 채택 기준**에 따라 **검증 이득**이 **추론 비용**을 상쇄할 때 **앙상블**을 채택한다.

#### 한줄 요약
- 검증 이득과 추론 비용을 비교하여 이득이 비용을 상쇄할 때 앙상블을 채택 체계 적용
