## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **앙상블 학습(Ensemble Learning)**: 여러 개의 단일 모델(기본 학습기, Base Learner)들을 결합하여 개별 모델의 편향(Bias)이나 분산(Variance) 한계를 극복하고 일반화 성능을 극대화하는 머신러닝 기법.
- **배깅(Bagging, Bootstrap Aggregating)**: 복원 추출된 데이터셋으로 독립적인 모델들을 병렬 학습시켜 평균/투표로 결합함으로써 분산(Variance)을 축소하는 기법.
- **부스팅(Boosting)**: 이전 모델이 틀린 오차(Residual/Weight)를 순차적으로 보완하도록 연속 학습시켜 편향(Bias)을 집중 축소하는 기법.
- **스태킹(Stacking)**: 서로 다른 이종 알고리즘들의 예측 결과를 메타 특징(Meta-feature)으로 삼아 상위 메타 모델이 최종 결합 예측을 학습하는 기법.

</details>

- 정의/개념: 단일 모델의 오류 상관관계를 상쇄하기 위해 다수의 기본 학습기를 병렬(배깅), 순차(부스팅), 계층(스태킹) 형태로 결합하는 **고성능 집단 지성 머신러닝 패러다임**
- 배경/필요성: 단일 결정 트리의 심각한 과적합(고분산)과 단순 선형 모델의 표현력 한계(고편향)를 극복하고 **정형 데이터 예측 대회 및 산업 현장의 최고 성능(SOTA) 달성 필수**

#### 한줄 요약

- 배깅(분산 감소), 부스팅(편향 감소), 스태킹(이종 결합)을 통해 단일 모델 대비 일반화 성능을 극대화

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **오류 다양성(Diversity of Errors)**: 앙상블 구성 모델들이 서로 다른 샘플이나 피처 공간에서 오답을 내어 집단 결합 시 개별 실수가 상쇄되는 핵심 조건.
- **편향-분산 분해(Bias-Variance Decomposition)**: 모델의 총 일반화 오차($\text{Error} = \text{Bias}^2 + \text{Variance} + \text{Noise}$) 중 배깅은 분산을, 부스팅은 편향을 타깃하여 억제.

</details>

- 기본 학습기 간 **오류 상관관계를 최소화하여 통계적 일반화 오차 대폭 감소**
- 배깅의 **완전 병렬화(Parallel Processing)** 및 부스팅의 **순차적 잔차 피드백(Sequential Residuals)**
- 모델 수 증가에 따른 **예측 성능 향상과 추론 지연(Latency)/메모리 증가 간의 트레이드오프**

#### 한줄 요약

- 모델 다양성을 확보하여 개별 오차를 상쇄하고, 배깅은 분산을 부스팅은 편향을 집중 제어

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **앙상블 3대 결합 방식 구조**:
  - 배깅: 복원 샘플링 $\to$ 병렬 $N$개 트리 $\to$ Hard/Soft Voting 또는 단순 산술 평균.
  - 부스팅: $h_1(x) \to \text{잔차 } r_1 \to h_2(x) \to \dots \to \sum \eta_m h_m(x)$.
  - 스태킹: Level-0 이종 모델들 $\to$ OOF 예측 행렬 $\to$ Level-1 메타 분류기(Logistic/Ridge).

</details>

```text
[ 앙상블 3대 패러다임 구조 비교도 ]
 
 1. 배깅 (Bagging):
    [ 원본 D ] ──► [ Bootstrap D1, D2, D3 ] ──► [ 독립 병렬 트리 T1, T2, T3 ] ──► [ 다수결/평균 결합 ]
 
 2. 부스팅 (Boosting):
    [ 모델 M1 ] ──(잔차 r1 계산)──► [ 모델 M2 ] ──(잔차 r2 계산)──► [ 모델 M3 ] ──► [ 가중합 ∑ η_m M_m ]
 
 3. 스태킹 (Stacking):
    [ 원본 D ] ──► [ SVM / RF / XGB (이종 기본모델) ] ──► [ OOF 예측 메타 특징 ] ──► [ 메타 모델 M_meta ]
```

선의 의미: 데이터 분할, 개별 모델 학습 및 최종 예측 결합(투표/가중합/메타학습) 파이프라인.

| 구성요소 | 책임 |
|:---|:---|
| 표본 추출기 (Bootstrap) | 복원 추출($\approx 63.2\%$)로 **데이터 다양성을 확보한 하위 데이터셋 생성** |
| 기본 학습기 (Base Learner) | 단일 결정 트리, SVM, 선형 모델 등으로 **개별 예측값 생성** |
| 잔차 피드백 엔진 | 부스팅에서 이전 라운드의 **오차 기울기(Gradient) 및 잔차 계산** |
| 메타 결합기 (Meta Learner) | 투표(Voting), 가중 평균, 또는 **메타 모델을 통해 최종 결합 예측 산출** |

#### 한줄 요약

- 표본 생성기가 다양한 학습셋을 구성하고, 개별 모델의 예측을 결합기가 취합하여 최종 결과를 도출

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **OOF(Out-of-Fold) 메타 피처 생성**: 스태킹 시 훈련셋에 직접 과적합된 예측값을 메타 모델에 전달하면 발생하는 데이터 누수(Data Leakage)를 방지하기 위해 $K$-Fold 검증 블록의 예측값들만을 모아 메타 피처를 구성하는 절차.

</details>

```text
비즈니스 요구사항 및 훈련 데이터 인입
   │
   ▼
[ 1. 오류 원인 및 단일 모델 진단 ]
├─ 단일 모델이 과적합되고 분산이 큼 ⟹ [ 2. 배깅 (Random Forest) 채택 ]
├─ 모델의 표현력이 부족하여 편향이 큼 ⟹ [ 3. 부스팅 (XGBoost / LightGBM) 채택 ]
└─ 서로 다른 강점의 이종 모델 보유 ⟹ [ 4. 스태킹 (Stacking with OOF) 채택 ]
   │
   ▼
[ 5. 앙상블 학습 실행 ]
├─ 배깅: n_estimators개 부트스트랩 병렬 훈련 및 산술 평균
├─ 부스팅: 이전 트리의 잔차(Residual)를 학습하는 순차 훈련 및 가중합
└─ 스태킹: K-Fold OOF 예측으로 메타 특징 생성 후 메타 모델(Ridge/Logistic) 훈련
   │
   ▼
[ 6. 단일 모델 대비 검증셋 성능 이득 및 추론 지연(Latency) 평가 후 배포 ]
```

**동작 원리**

1. **오류 분석**: 고분산(과적합)인지 고편향(과소적합)인지에 따라 앙상블 유형 결정
2. **배깅 분기**: 복원 추출 표본으로 다수의 트리를 독립 병렬 학습 후 투표
3. **부스팅 분기**: 이전 단계의 잔차 오차를 줄이는 방향으로 트리를 순차 결합
4. **스태킹 분기**: $K$-Fold OOF 예측값으로 메타 훈련셋을 구축하고 상위 모델 학습
5. **비용 평가**: 성능 향상 폭이 추가 추론 지연 및 메모리 비용을 정당화하는지 검증

#### 한줄 요약

- 분산은 배깅, 편향은 부스팅, 이종 결합은 스태킹을 적용하고 OOF 검증으로 데이터 누수를 방지

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **앙상블 3대 패러다임 비교**:
  - 배깅: 독립 병렬, 복원 추출, 분산 감소(과적합 억제), Random Forest.
  - 부스팅: 종속 순차, 잔차 피드백, 편향 감소(정밀도 극대화), XGBoost/LightGBM.
  - 스태킹: 2계층 구조, 이종 알고리즘, 복합 패턴 결합, 메타 회귀기.

</details>

| 비교 항목 | 배깅 (Bagging) | 부스팅 (Boosting) | 스태킹 (Stacking) |
|:---|:---|:---|:---|
| 핵심 메커니즘 | **독립적 병렬 학습 (Parallel)** | **순차적 잔차 보정 학습 (Sequential)** | **2계층 메타 모델 결합 (Hierarchical)** |
| 주 타깃 오차 | **분산(Variance) 감소 (과적합 완화)** | **편향(Bias) 감소 (표현력 극대화)** | 복합적 예측 오차 최소화 |
| 기본 학습기 | 주로 깊은 결정 트리 (High Variance) | 얕은 결정 트리 (Weak Learner) | **다양한 이종 모델 (SVM, RF, MLP 등)** |
| 데이터 샘플링 | **부트스트랩 복원 추출 (Bootstrap)** | 오차 샘플 가중치 또는 잔차 갱신 | 원본 데이터 + K-Fold OOF 피처 |
| 대표 알고리즘 | **랜덤 포레스트 (Random Forest)** | **XGBoost, LightGBM, CatBoost** | StackingClassifier, BlendNet |

#### 한줄 요약

- 분산 완화는 배깅(랜덤 포레스트), 고정밀 편향 감소는 부스팅(XGB/LGBM), 이종 융합은 스태킹을 적용

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **얼리 스토핑(Early Stopping)**: 부스팅 훈련 시 검증셋 손실이 $N$회(예: 50 에포크) 연속 개선되지 않으면 트리 추가 생성을 즉각 중단하여 과적합을 원천 차단하는 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 부스팅 알고리즘의 노이즈/이상치 과적합 | **Early Stopping + 학습률($\eta=0.05$) 축소** | 검증 일반화 성능 및 과적합 방지 |
| 스태킹 메타 모델의 **심각한 데이터 누수(Data Leakage)** | 반드시 **$K$-Fold OOF(Out-of-Fold) 메타 피처** 사용 | 누수 차단 및 신뢰성 있는 검증 |
| 대규모 앙상블로 인한 **추론 응답 지연(Latency) 급증** | 중요 피처 선별, 트리 수 가지치기, 모델 증류(Distillation) | 실시간 서빙 SLA 충족 |
| 앙상블 내부 판단 근거의 불투명성(블랙박스) | **SHAP(Shapley Additive exPlanations) 값 산출** | 피처 기여도 해석 및 설명력(XAI) 확보 |

#### 한줄 요약

- Early Stopping으로 과적합을 방지하고, OOF 메타피처로 누수를 차단하며, 추론 지연시간을 최적화하고, SHAP으로 모델 판단 설명력을 확보한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **정형 머신러닝의 골든 스탠다드**: 정형 테이블 데이터셋에서는 부스팅(LightGBM/XGBoost)이 기본 단일 최강 모델로 활용되며, 최고 성능이 요구되는 대회나 핵심 예측에는 이종 앙상블 및 스태킹이 표준 파이프라인으로 구축.

</details>

- 분산 축소/병렬화는 **배깅(Random Forest)**, 편향 축소/정밀도는 **부스팅(XGB/LGBM)**, 이종 모델 결합은 스태킹(Stacking) 선택

#### 한줄 요약

- 분산 과다는 배깅, 편향 과다는 부스팅, 이종 결합은 스태킹을 채택하고 추론 비용과 성능 이득을 절충
