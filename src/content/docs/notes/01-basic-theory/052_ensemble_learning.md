## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **앙상블 학습(Ensemble Learning)**: 여러 개의 기본 모델(약학습기)을 결합하여 단일 모델보다 우수한 예측 성능을 달성하는 기계학습 기법.
- **약학습기(Weak Learner)**: 무작위 추측보다 약간 더 나은 성능을 보이는 단순한 모델.
- **편향-분산 트레이드오프(Bias-Variance Tradeoff)**: 모델의 단순성으로 인한 체계적 오차(편향)와 훈련 데이터 민감성으로 인한 오차(분산) 사이의 상충 관계.

</details>

- 정의/개념: 여러 개의 단일 약학습기를 결합하여 **편향과 분산을 동시에 통제**함으로써 단일 모델 대비 높은 예측력과 일반화 성능을 얻는 머신러닝 학습 기법
- 배경/필요성: 단일 모델의 높은 분산(과적합) 또는 높은 편향(과소적합) 한계를 극복하고 모델 간 상호 오류 보정을 통한 일반화 성능 극대화 필요

#### 한줄 요약

- 복수의 약학습기를 결합하여 분산과 편향을 줄이고 예측 안정성을 극대화하는 학습 체계

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **부트스트랩(Bootstrap)**: 훈련 데이터셋에서 복원 추출을 통해 원본과 동일한 크기의 다중 표본 집합을 생성하는 기법.
- **잔차(Residual)**: 실제 관측값과 현재 모델의 예측값 사이의 차이($y - \hat{y}$).

</details>

- 다양한 약학습기 오차의 **상호 보완을 통한 일반화 성능 향상**
- 독립 병렬 훈련(배깅)을 통한 **분산(Variance) 감소 및 과적합 억제**
- 오차 기반 순차 훈련(부스팅)을 통한 **편향(Bias) 집중 감소 및 정확도 극대화** #### 한줄 요약

- 배깅은 분산 감소, 부스팅은 편향 감소, 스태킹은 이종 모델 메타 결합으로 성능을 최적화

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **메타 학습기(Meta Learner)**: 스태킹 앙상블에서 1단계 기본 모델들의 예측값들을 입력 특징으로 받아 최종 예측을 수행하는 모델.
- **소프트 보팅(Soft Voting)**: 각 분류기의 클래스 예측 확률값들을 평균하여 가장 높은 확률의 클래스를 선택하는 집계 방식.

</details>

```text
[ 배깅 (Bagging) ]      [ 부스팅 (Boosting) ]        [ 스태킹 (Stacking) ]
  원본 데이터셋              원본 데이터셋                원본 데이터셋
    │  (부트스트랩)            │ (가중치 갱신)              │
 ┌──┼──┐                    ▼                          ┌──┼──┐
 ▼  ▼  ▼                 [ 모델 1 ] (초기 오차)        ▼  ▼  ▼
[M1][M2][M3] (병렬)         │ (잔차 전달)              [M1][M2][M3] (이종 모델)
 └──┬──┘                    ▼                          └──┬──┘ (예측값 전달)
    ▼                    [ 모델 2 ] (잔차 학습)           ▼
[ 보팅 / 평균 ]             │                          [ 메타 모델 ]
    │                       ▼                             │
    ▼                    [ 가중합 결합 ]                  ▼
 최종 예측                  최종 예측                    최종 예측
```

선의 의미: 앙상블 유형별 훈련 데이터 분배 및 모델 간 예측값 결합 관계

| 구성요소 | 책임 |
|:---|:---|
| 부트스트랩 생성기 | 원본 데이터 복원 추출을 통한 **다양성 확보 데이터셋 분할** |
| 기본 약학습기군 | 병렬 또는 순차로 훈련되어 **개별 예측값 도출** |
| 가중 결합기 | 부스팅 및 배깅의 개별 모델 예측을 **가중합 또는 보팅 집계** |
| 메타 학습기 | 스태킹 구조에서 1단계 모델 예측값들을 기반으로 **최종 최적화** |

#### 한줄 요약

- 데이터 분할, 개별 모델 훈련, 가중 결합 또는 메타 학습을 거쳐 단일 결론을 도출

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **OOF 예측(Out-of-Fold Prediction)**: 스태킹 학습 시 타깃 누수를 방지하기 위해 K-Fold 교차 검증의 검증 폴드 예측값만으로 메타 데이터셋을 구성하는 기법.

</details>

```text
훈련 데이터 수신
     │
     ▼
[ 1. 앙상블 전략 선택 ]
├─ 분산 감소 요구 ────► [ 2. 배깅 파이프라인 (부트스트랩 + 병렬 훈련) ]
├─ 편향 감소 요구 ────► [ 3. 부스팅 파이프라인 (잔차 계산 + 순차 훈련) ]
└─ 이종 결합 요구 ────► [ 4. 스태킹 파이프라인 (K-Fold OOF + 메타 훈련) ]
     │
     ▼
[ 5. 앙상블 예측 집계 및 최종 출력 ]
```

**동작 원리** 1. **앙상블 전략 선택**: 과업의 오차 성격(과적합 vs 과소적합)에 따라 배깅/부스팅/스태킹 결정
2. **배깅 파이프라인**: $N$개의 부트스트랩 샘플 생성 후 동일 알고리즘을 병렬 훈련
3. **부스팅 파이프라인**: 이전 단계의 예측 잔차를 다음 모델의 학습 목표로 순차 전달
4. **스태킹 파이프라인**: K-Fold 교차 검증으로 OOF 메타 특징을 생성하고 메타 학습기 학습
5. **앙상블 예측 집계 및 최종 출력**: 보팅, 가중 평균, 메타 회귀를 통해 최종 결과 산출

#### 한줄 요약

- 목표 오차에 따라 배깅, 부스팅, 스태킹으로 분기하여 개별 모델을 학습시키고 결과를 통합

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **랜덤 포레스트(Random Forest)**: 배깅에 특징 무작위 선택(Feature Subsampling)을 결합하여 트리 간 상관관계를 낮춘 앙상블 모델.
- **그래디언트 부스팅(Gradient Boosting)**: 임의의 미분 가능한 손실 함수의 음의 기울기를 잔차로 정의하여 학습하는 부스팅 기법.

</details>

| 앙상블 기법 | 배깅 (Bagging) | 부스팅 (Boosting) | 스태킹 (Stacking) |
|:---|:---|:---|:---|
| 적용 기준 | 모델의 **높은 분산(과적합) 완화** 및 병렬 연산 요구 시 | 모델의 **높은 편향(과소적합) 해소** 및 최고 정확도 추구 시 | **이종 모델(Heterogeneous)** 장점 융합 요구 시 |
| 핵심 특징 | **부트스트랩 병렬 훈련** 및 단순 다수결/평균 결합 | **오차 샘플 순차 가중 훈련** 및 가중 선형 결합 | **1단계 예측값 기반 메타 모델 입력** 학습 |
| 한계 | 편향 감소 효과 제한적 | 이상치 노이즈에 **과적합 위험** 및 직렬 연산 지연 | **타깃 누수 위험** 및 파이프라인 복잡도 급증 |

#### 한줄 요약

- 분산 감소는 배깅, 정밀 편향 축소는 부스팅, 이종 모델 융합은 스태킹을 선택

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **타깃 누수(Target Leakage)**: 훈련 데이터 외의 미래 정보나 정답 정보가 모델 특징으로 유입되어 훈련 성능만 비정상적으로 높아지는 현상.
- **지식 증류(Knowledge Distillation)**: 거대한 앙상블 모델(교사)의 지식을 가볍고 빠른 단일 모델(학생)로 압축 전달하는 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 부스팅 알고리즘 적용 시 노이즈 및 이상치 **과적합 취약** | **조기 종료(Early Stopping) 및 학습률(Shrinkage) 축소** | 과적합 억제 및 일반화 안정성 확보 |
| 스태킹 앙상블 훈련 시 발생하는 **타깃 누수 및 과적합** | **K-Fold 교차 검증 기반 OOF(Out-of-Fold) 메타셋 생성** | 1단계 오버피팅 전파 차단 및 신뢰도 확보 |
| 다중 모델 결합으로 인한 실시간 **추론 지연 시간(Latency) 증가** | **지식 증류(Knowledge Distillation) 기반 단일 모델 압축** | 실시간 서비스 SLA 충족 및 리소스 절감 |

#### 한줄 요약

- 부스팅 과적합은 조기 종료로 막고, 스태킹 누수는 OOF로 차단하며, 추론 지연은 지식 증류로 최적화

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **도메인 정형 데이터**: 테이블 형태로 구조화된 수치형 및 범주형 비즈니스 데이터.

</details>

- 일반적인 정형 데이터 과업에서는 그래디언트 부스팅(LightGBM/XGBoost)을 1차 기준 모델로 채택하고, 노이즈가 심한 분산 환경에서는 랜덤 포레스트를, 극한의 예측 성능이 필요한 경진대회급 과업에서는 OOF 스태킹을 선별 적용하는 판단이 효과적

#### 한줄 요약

- 정형 데이터는 부스팅을 주력으로 하되 데이터 특성과 실시간 지연 제약에 따라 적절한 앙상블 방식을 선택
