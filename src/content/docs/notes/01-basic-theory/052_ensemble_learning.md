## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **앙상블 학습**: 여러 모델의 예측을 결합해 일반화 오차를 줄이는 학습 방식
- **편향·분산**: 모델의 체계적 오차와 학습 표본 변화에 대한 민감도

</details>

- 정의/개념: 여러 모델의 예측을 결합하는 **앙상블 학습** 기법
- 배경/필요성: 단일 모델은 **편향•분산** 동시 완화에 제약

### 쉽게 이해하기 (학습용)
- 여러 심사위원이 서로 다른 실수를 하고 투표함에서 오답이 상쇄돼 단독 심사보다 정확해지는 장면이다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **다양성**: 기본 학습기들이 서로 다른 표본에서 틀리는 성질
- **오류 상관**: 여러 모델이 같은 표본에서 함께 틀리는 정도
- **일반화 오차**: 학습하지 않은 새 데이터에서 발생하는 예측 오차

</details>

- 서로 다른 학습기 예측의 **투표•평균** 결합
- 데이터•특징•알고리즘 **다양성**으로 **오류 상관**을 낮춰 일반화 오차 축소

### 쉽게 이해하기 (학습용)
- 심사위원 모두 같은 지원자를 틀리면 투표도 실패하므로, 서로 다른 관점의 심사표를 섞는 장면이다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **부트스트랩 표본**: 중복 추출을 허용해 원본에서 만든 서로 다른 학습 표본 집합
- **기본 학습기**: 앙상블을 구성하고 개별 예측을 만드는 모델
- **메타 모델**: 기본 모델들의 예측을 입력받아 최종 답을 학습하는 상위 모델

</details>

```mermaid
block
    columns 3
    S["표본 생성기"]
    B["기본 학습기"]
    A["예측 결합기"]
    S --- B
    B --- A
```

| 구성요소 | 책임 |
|:---|:---|
| 표본 생성기 | **부트스트랩**•가중치•폴드로 서로 다른 **학습 집합** 구성 |
| 기본 학습기 | 개별 학습 집합에서 서로 다른 **개별 예측** 산출 |
| 예측 결합기 | 투표•평균•**메타 모델**로 최종 예측 산출 |

### 쉽게 이해하기 (학습용)
- 카드 배분기가 서로 다른 문제 묶음을 나누고 여러 풀이표가 중앙 투표함으로 모이는 장면이다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **가중치 표본화**: 표본마다 선택 비중을 달리해 학습 집합을 구성하는 방식
- **폴드**: 교차검증을 위해 데이터를 겹치지 않게 나눈 부분 집합

</details>

```mermaid
sequenceDiagram
    participant T as 앙상블 제어기
    participant S as 표본 생성기
    participant B as 기본 학습기
    participant A as 예측 결합기
    T->>S: 학습 데이터
    S->>B: 1. 학습기별 학습 집합
    loop 기본 학습기별
        B->>A: 2. 개별 예측 전달
    end
    A-->>T: 최종 예측
```

**동작 원리**

- **1. 학습기별 학습 집합**: 부트스트랩•가중치•폴드로 구성
- **2. 개별 예측 전달**: 기본 학습기별 예측 산출

### 쉽게 이해하기 (학습용)
- 서로 다른 문제 묶음을 푼 답안들이 투표판•평균계•메타 심사대로 들어가 하나의 답이 되는 장면이다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **배깅**: 여러 모델을 병렬 학습한 뒤 예측을 평균하거나 투표하는 방식
- **부스팅**: 앞선 모델의 오류를 다음 모델이 순차적으로 보완하는 방식
- **스태킹**: 기본 모델의 폴드 외 예측을 메타 모델이 결합하는 방식

</details>

| 앙상블 기법 | 배깅 | 부스팅 | 스태킹 |
|:---|:---|:---|:---|
| 적용 기준 | 같은 모델의 **예측 분산**이 큰 경우 | **편향**이 크고 잡음이 적은 경우 | 성격이 다른 **이종 모델**이 있는 경우 |
| 핵심 특징 | **랜덤 포레스트**의 병렬 **평균•투표** | 앞선 **잔차**의 순차 보완 | **폴드 외 예측**을 메타 모델로 결합 |
| 한계 | 모델 간 높은 **오류 상관** | 잡음•**이상치** 과집중 | 학습 예측값의 **데이터 누수** |

> 요약: 분산 과다는 배깅, 편향 과다는 부스팅, 이종은 **스태킹**

### 쉽게 이해하기 (학습용)
- 배깅은 동시 투표, 부스팅은 앞사람 오답 수정, 스태킹은 전문가 답을 상위 심사자가 합치는 장면이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **OOF 예측**: 각 모델이 학습에 사용하지 않은 폴드에서 만든 예측값
- **데이터 누수**: 검증 정보가 학습 과정에 들어가 성능이 실제보다 높게 측정되는 현상
- **순차 과적합**: 부스팅이 앞선 오차를 반복 보완하다 잡음까지 학습하는 현상

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 모델들이 같은 표본에서 **함께 오분류** | 데이터•특징•알고리즘 **다양성 확대** | **오류 상관 감소•결합 이득** 확보 |
| 부스팅이 **잡음•이상치에 집중** | 학습률•트리 깊이 제한과 **이상치 검토** | **순차 과적합** 완화 |
| 스태킹 검증 성능이 **비정상적으로 높음** | **OOF 예측**만 메타 모델 학습에 사용 | **데이터 누수** 방지 |
| 성능 향상보다 **추론 비용 증가**가 큼 | 모델 수 축소•**지연•비용 기준** 설정 | **운영 효율** 유지 |

### 쉽게 이해하기 (학습용)
- 트리를 한 그루씩 늘리며 정확도계와 지연 시계를 함께 보고 이득이 멈춘 지점에서 추가를 중단하는 장면이다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **검증 이득**: 앙상블이 단일 모델보다 검증 데이터에서 얻는 성능 향상
- **추론 비용**: 운영 중 여러 모델의 예측을 계산하고 결합하는 데 드는 시간과 자원

</details>

- 검증 이득이 **지연•비용**을 상쇄할 때 **앙상블 채택**

### 쉽게 이해하기 (학습용)
- 정확도 상승 추와 지연•비용 추를 저울에 올려 정확도 쪽이 무거울 때 여러 모델을 묶는 장면이다.
