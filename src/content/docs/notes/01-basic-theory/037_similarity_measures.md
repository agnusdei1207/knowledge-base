## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **유사도 측정(Similarity Measure)**: 두 데이터 객체 간의 기하학적 거리, 방향적 각도, 또는 집합적 중첩도를 수학적 함수로 정량화하여 근접성을 평가하는 척도.
- **코사인 유사도(Cosine Similarity)**: 두 벡터의 사잇각 코사인 값($\cos\theta = \frac{A \cdot B}{\|A\|\|B\|}$)을 계산하여 벡터 크기와 무관하게 방향적 유사성을 측정하는 척도.
- **자카드 유사도(Jaccard Similarity)**: 두 집합의 교집합 크기를 합집합 크기로 나눈 비율($J(A, B) = \frac{|A \cap B|}{|A \cup B|}$)로 이진 속성 간의 유사도를 측정하는 척도.
- **유클리드 거리(Euclidean Distance)**: $N$차원 공간에서 두 점 사이의 최단 직선거리($d = \sqrt{\sum (x_i - y_i)^2}$)를 계산하는 기하학적 거리 척도.

</details>

- 정의/개념: 데이터의 도메인 특성(임베딩 벡터, 이진 집합, 물리 좌표)에 맞춰 거리, 각도, 집합 중첩 비율로 유사성을 수치화하는 **데이터 마이닝 및 검색 핵심 척도**
- 배경/필요성: 자연어 검색, 추천 시스템, 이미지 매칭에서 데이터 표현 방식에 부합하지 않는 척도 적용 시 **심각한 순위 역전(Rank Inversion) 및 검색 왜곡 발생 방지 필수**

#### 한줄 요약

- 데이터의 벡터 방향, 집합 중첩, 물리적 직선거리를 기반으로 객체 간 유사성을 정량화

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **L2 정규화(L2 Normalization)**: 벡터의 크기(Norm)를 1로 맞추어($\|A\|=1$) 유클리드 거리의 제곱과 코사인 유사도 간의 수학적 등가성($d^2 = 2 - 2\cos\theta$)을 형성하는 전처리.
- **순위 역전(Rank Inversion)**: 척도 선택 및 스케일링 방식에 따라 검색 결과의 Top-K 유사도 순위가 뒤바뀌는 현상.

</details>

- 코사인 유사도는 **문서 길이/크기 편향을 완전 배제한 방향적 일치도(Directional Alignment)** 평가
- 자카드 유사도는 **희소 이진 데이터(Sparse Binary)의 공통 원소 비율**에 특화
- 유클리드 거리는 **물리적 절대 크기와 좌표 차이를 직접 반영**하는 기하학적 척도

#### 한줄 요약

- 척도별 기하학적 정의에 따라 근접 순위가 달라지므로 데이터의 특성에 부합하는 척도를 선택

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **Top-K 후보 선정기(Top-K Candidate Selector)**: 유사도 점수를 내림차순(또는 거리 오름차순) 정렬하여 최상위 $K$개 항목을 실시간 추출하는 인덱싱 엔진.

</details>

```text
[ 유사도 측정 및 검색 아키텍처 ]
┌──────────────────────────────┐
│ 특징 변환기 (Transformer)    │ ── 텍스트 ──► Dense 벡터 / 범주 ──► 이진 Set
├──────────────────────────────┤
│ 정규화기 (L2 Scaler)         │ ── 단위 편향 제거 및 벡터 Norm = 1 정규화
├──────────────────────────────┤
│ 척도 연산 엔진 (Metric Engine)│ ── Cosine / Jaccard / Euclidean 거리 병렬 계산
├──────────────────────────────┤
│ Top-K 후보 선정기            │ ── 임계치(Threshold) 및 상위 K개 결과 도출
└──────────────────────────────┘
```

선의 의미: 데이터 변환, 정규화, 척도 연산 엔진 및 Top-K 후보 선정 간의 파이프라인 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 특징 변환기 | 원시 데이터를 **밀집 임베딩(Dense), 희소 벡터, 집합 형태로 변환** |
| 정규화기 | 척도 계산 전 **L2 단위 벡터 정규화 및 표준화** 수행 |
| 척도 연산 엔진 | 도메인에 부합하는 **Cosine / Jaccard / Euclidean 점수 연산** |
| Top-K 선정기 | 산출된 점수를 기준으로 **최적 유사 후보군 필터링 및 랭킹** |

#### 한줄 요약

- 변환기가 질의와 후보를 동일 표현으로 맞추고, 척도 함수가 점수를 매겨 상위 후보를 추출

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **벡터 검색(Vector Search, ANN)**: 수백만 개 고차원 벡터 중에서 코사인/유클리드 거리 기준으로 가장 가까운 이웃을 HNSW, ScaNN 등의 알고리즘으로 초고속 탐색하는 기법.

</details>

```text
질의(Query) 및 후보 데이터 인입
   │
   ▼
[ 1. 데이터 표현 속성 판별 ]
├─ 고차원 텍스트/이미지 Dense 임베딩 ⟹ [ 2. 코사인 유사도 (Cosine: A·B / ||A||||B||) ]
├─ 사용자 클릭/구매 이력 이진 집합 ⟹ [ 3. 자카드 유사도 (Jaccard: |A∩B| / |A∪B|) ]
└─ 물리적 센서 좌표 및 연속 수치 ⟹ [ 4. 유클리드 거리 (Euclidean: √∑(xi-yi)²) ]
   │
   ▼
[ 5. 유사도 점수 산출 및 정렬 (ANN 인덱싱) ]
   │
   ▼
Top-K 유사도 결과 리스트 반환
```

**동작 원리**

1. **데이터 유형 식별**: 입력 데이터가 밀집 벡터인지, 이진 집합인지, 연속 좌표인지 판별
2. **코사인 유사도 연산**: 임베딩 벡터의 크기를 무시하고 사잇각 $\cos\theta$로 텍스트 의미 일치도 산출
3. **자카드 유사도 연산**: 집합 간의 교집합 크기를 합집합 크기로 나누어 중복률 도출
4. **유클리드 거리 연산**: 좌표 간의 직선 차이를 계산하여 거리 반환
5. **결과 정렬 및 반환**: 유사도는 큰 순서, 거리는 작은 순서로 정렬하여 상위 $K$개 항목 출력

#### 한줄 요약

- 데이터 속성에 따라 코사인, 자카드, 유클리드 척도로 분기 연산하고 Top-K 순위로 정렬

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **3대 유사도 척도 비교**:
  - 코사인 유사도: $[-1, 1]$, 벡터 방향성, 텍스트/LLM 임베딩/추천.
  - 자카드 유사도: $[0, 1]$, 집합 교집합 비율, 태그/장바구니/토큰 중복.
  - 유클리드 거리: $[0, \infty)$, 공간 직선거리, 저차원 물리 좌표/이미지 픽셀.

</details>

| 비교 항목 | 코사인 유사도 (Cosine) | 자카드 유사도 (Jaccard) | 유클리드 거리 (Euclidean) |
|:---|:---|:---|:---|
| 측정 기준 | **두 벡터 간의 사잇각 (방향)** | **두 집합 간의 중첩 비율** | **두 점 사이의 물리적 최단 직선거리** |
| 수치 범위 | $-1.0 \sim +1.0$ (유사할수록 1) | $0.0 \sim 1.0$ (유사할수록 1) | $0 \sim \infty$ (유사할수록 0) |
| 크기/길이 영향 | **벡터 크기(Norm)에 불변** | 원소별 빈도수 무시 (이진 유무) | **절대적 좌표 크기에 크게 영향** |
| 주요 적용처 | LLM 임베딩 검색, 문서 유사도 | 사용자 구매 이력 추천, 패키지 중복 | 지리 좌표 거리, 이미지 픽셀 차이 |

#### 한줄 요약

- 임베딩 방향은 코사인, 집합 겹침은 자카드, 좌표 공간의 직선거리는 유클리드를 적용

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **영벡터 예외(Zero Vector Exception)**: 모든 원소가 0인 벡터($\|A\|=0$) 인입 시 코사인 유사도 분모가 0이 되어 `NaN`이 발생하는 결함.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 모든 원소가 0인 영벡터 인입 시 **코사인 유사도 분모 0($\text{NaN}$) 오류** | 최소 엡실론($\epsilon=10^{-9}$) 가산 또는 사전 제로 벡터 검증 | 연산 크래시 방지 및 기본값 반환 |
| 유클리드 거리 측정 시 **단위가 큰 특정 변수의 거리 지배** | 사전 `StandardScaler` 또는 `MinMaxScaler` 정규화 | 피처별 공정한 거리 가중치 반영 |
| 자카드 유사도에서 **단어 출현 빈도수(Frequency) 정보 손실** | **가중 자카드(Weighted Jaccard / Ruzicka)** 척도 적용 | 빈도 가중치가 반영된 정밀 유사도 산출 |
| 고차원 벡터 간의 **브루트포스 거리 연산 병목** | **HNSW / IVFPQ 기반 근사 최근접 탐색(ANN)** 구축 | 검색 레이턴시 $O(N) \to O(\log N)$ 단축 |

#### 한줄 요약

- **영벡터 분모 0 방어·표준화 거리 왜곡 제거·가중 자카드 빈도 보존·HNSW 고속 검색**

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **현대 검색/추천 시스템 척도 표준**: RAG(검색 증강 생성) 및 벡터 DB(Pinecone, Milvus)는 L2 정규화된 임베딩에 대해 내적(Dot Product) 연산으로 코사인 유사도를 초고속 계산하여 프로덕션을 운용.

</details>

- 고차원 텍스트/임베딩 방향은 **코사인 유사도**, 이진 집합 중첩은 **자카드 유사도**, 물리적 공간 거리는 유클리드 거리 선택

#### 한줄 요약

- 데이터의 기하학적 특성에 맞는 척도를 선정하고 ANN 인덱싱을 통해 고속 유사도 검색을 구현
