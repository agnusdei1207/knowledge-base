## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **엔트로피 및 채널 용량(Entropy & Capacity)**: 정보원의 평균 불확실성(압축 하한선)과 잡음 채널에서 오류 없이 전송 가능한 최대 정보 전송률(bps).
- **전송 신호 왜곡(Signal Distortion)**: 물리적 유한 대역폭과 열잡음으로 인해 전송 신호의 파형이 변형되는 현상.

</details>

- 정의/개념: 사건의 불확실성을 정보량으로 정량화하여 **엔트로피** 및  **채널 용량**  수학적 전송 한계를 규명하는 통신 이론
- 배경/필요성: 유한 대역폭 및 백색 가우시안 잡음(AWGN) 환경에서 발생하는 신호 왜곡과 이론적 무오류 전송 한계 규명 필요

#### 한줄 요약

- 정보원의 불확실성을 엔트로피로 정량화하고, 잡음 채널에서 오류 없는 최대 전송률인 채널 용량을 정의

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **엔트로피(Entropy, $H(X)$)**: 정보원(Source)이 방출하는 기호들의 평균 불확실성이자 무손실 압축이 도달할 수 있는 이론적 최소 평균 부호 길이.
- **채널 용량(Channel Capacity, $C$)**: 주어진 대역폭과 신호 대 잡음비(SNR) 환경에서 임의로 작은 오류 확률($P_e \to 0$)로 전송 가능한 최대 정보율(bit/s).
- **섀넌-하틀리 정리(Shannon-Hartley Theorem)**: 대역폭 $B$와 $\text{SNR}(S/N)$을 갖는 AWGN 채널의 최대 용량을 규정한 정리 ($C = B \log_2(1 + S/N)$).

</details>

![선형 SNR에 따른 섀넌 채널 용량 차트](/study/diagrams/shannon-capacity-growth.svg)

> $C/B=\log_2(1+S/N)$의 이론 관계에서 선형 SNR이 1→15로 커져도 스펙트럼 효율은 1→4bit/s/Hz로 로그 증가함

- **엔트로피 $H(X)$** 기반 무손실 소스 부호화의 절대적 압축 하한선 규정
- 전송률 $R < C$ 조건 하에서 무오류 전송을 보장하는 **채널 부호화** 존재 증명
- 송신 전력 증대에 따른 채널 용량의 로그 스케일($\log_2$) 포화 특성

$$
C_{\text{AWGN}} = B \log_2\left(1 + \frac{S}{N}\right) \quad [\text{bps}]
$$

#### 한줄 요약

- 엔트로피는 무손실 압축의 하한선이며, 섀넌-하틀리 정리는 대역폭과 SNR에 따른 최대 통신 용량을 규정

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **소스 부호화(Source Coding)**: 정보원의 중복성(Redundancy)을 제거하여 엔트로피 $H(X)$에 근접하도록 압축하는 기법(허프만, 산술 부호화).
- **채널 부호화(Channel Coding)**: 채널 잡음으로 인한 비트 에러를 정정하기 위해 구조화된 잉여 비트(Parity)를 추가하는 기법(LDPC, Polar Code, Turbo Code).

</details>

```text
[ 섀넌의 고전적 통신 시스템 모델 ]
 [ 정보원 ] ──► [ 소스 부호기 ] ──► [ 채널 부호기 ] ──► [ 잡음 채널 (AWGN) ]
                 (중복 제거: H(X))    (잉여 추가: ECC)           │
                                                                ▼
 [ 수신처 ] ◄── [ 소스 복호기 ] ◄── [ 채널 복호기 ] ◄── [ 수신 신호 ]
```

선의 의미: 소스 부호화(압축), 채널 부호화(오류 보호), 잡음 채널 전송 및 역순 복호화 파이프라인.

| 구성요소 | 책임 |
|:---|:---|
| 소스 부호기 | 통계적 중복성을 제거하여 **엔트로피 $H(X)$ 수준으로 압축** |
| 채널 부호기 | 채널 오류 정정을 위한 **잉여 비트(Parity) 삽입 및 부호율($R$) 결정** |
| 잡음 채널 | 물리적 대역폭($B$) 및 열잡음($N$)으로 **채널 용량($C$) 한계 형성** |
| 채널 복호기 | 수신 신호의 오류를 검출/정정하여 **원천 비트열 복원** |
| 소스 복호기 | 압축 비트열을 역변환하여 **원본 정보원 기호 복구** |

#### 한줄 요약

- 소스 부호기가 중복을 줄이고 채널 부호기가 복구 비트를 붙이면, 복호기가 잡음 채널의 수신 신호를 복원

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **상호정보량(Mutual Information, $I(X; Y)$)**: 수신 심볼 $Y$를 관측함으로써 송신 심볼 $X$에 대해 얻게 되는 불확실성 감소량 ($I(X; Y) = H(X) - H(X|Y)$).

</details>

```text
[ 원본 정보원 X ] (기호 발생 확률 p(x))
      │
      ▼
[ 1. 소스 부호화 ] : 엔트로피 H(X) = -∑ p(x)log2 p(x) 하한선까지 압축
      │
      ▼
[ 2. 채널 부호화 ] : 코드율 R < C 조건을 만족하는 전방 오류 정정(FEC) 부호화
      │
      ▼
[ 3. 물리 채널 전송 ] : 대역폭 B, AWGN 잡음 N 인입
      │
      ▼
[ 4. 채널 복호화 ] : 수신 심볼 Y로부터 사후 확률 최대화(MAP) 오류 정정
      │
      ▼
[ 5. 소스 복호화 ] : 무손실 압축 해제로 원래 기호 X 완벽 복원
```

**동작 원리**

1. **소스 부호화**: 정보원의 확률분포를 분석해 평균 비트 수가 엔트로피에 수렴하도록 압축
2. **채널 부호화**: 채널 용량 $C$ 미만의 전송률 $R$로 전방 오류 정정(FEC) 부호화 수행
3. **물리 채널 전송**: 송신 신호에 백색 가우시안 잡음(AWGN)이 부가된 아날로그 파형 수신
4. **채널 복호화**: 수신된 판정값을 반복 복호하여 비트 에러 정정
5. **소스 복호화**: 압축 비트열을 역변환하여 원래 기호 완벽 복원

#### 한줄 요약

- 정보원 엔트로피 압축 후 채널 용량 이내의 FEC 부호화를 거쳐 잡음 채널에서 무오류 전송을 실현

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **정보이론 3대 핵심 척도**:
  - 엔트로피 $H(X)$: 단일 확률변수의 불확실성/정보량.
  - 상호정보량 $I(X; Y)$: 두 확률변수 간의 공유 정보량 (채널 입출력 상관도).
  - 채널 용량 $C$: 입력 분포 $p(x)$를 최적화했을 때의 최대 상호정보량 ($\max I(X; Y)$).

</details>

| 정보 척도 | 엔트로피 ($H(X)$) | 상호정보량 ($I(X; Y)$) | 채널 용량 ($C$) |
|:---|:---|:---|:---|
| 적용 기준 | 데이터 무손실 압축 설계 시 | 특징 선택 및 통신 채널 상관도 분석 | 변조 방식 및 대역폭 전송 한계 설계 |
| 핵심 특징 | 정보원의 **불확실성 및 압축 하한선** | 수신 신호로 얻는 **공유 정보량** | 잡음 채널의 **최대 신뢰 전송률** |
| 한계 | 소스 심볼 간 독립성 가정 필요 | 결합 확률분포 추정의 높은 연산량 | 전송 지연 및 유한 블록 길이 미반영 |

#### 한줄 요약

- 엔트로피는 정보의 불확실성, 상호정보량은 송수신 공유 정보량, 채널 용량은 전송률의 이론적 상한선

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **현대 채널 부호화(Modern Channel Codes)**: 섀넌 한계에 0.004dB 수준으로 극도로 근접하는 LDPC(Low-Density Parity-Check) 및 Polar(극) 부호(5G 표준 채택).

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 전송률이 **채널 용량($C$)을 초과**하여 패킷 에러 폭증 | 대역폭($B$) 확장 또는 고차 변조(QAM) 및 MIMO 적용 | 채널 용량 증대 및 안정 전송 |
| 데이터 압축과 오류 정정 간의 **설계 순서 혼동** | 소스-채널 분리 정리(Separation Theorem) 준수 | 압축(중복 제거)과 채널 보호 책임 분리 |
| 짧은 패킷(URLLC)에서 **섀넌 한계 미달성 지연** | 유한 블록 길이 정보이론(Finite Blocklength) 모델링 | 초저지연 신뢰도 제약 충족 |
| 데이터 확률분포 변동으로 인한 **압축률 저하** | 적응형 산술 부호화 및 Zstandard 적용 | 동적 엔트로피 추적 및 압축률 최적화 |

#### 한줄 요약

- 채널 용량은 MIMO·대역폭 확장으로 늘리고, 소스·채널 부호화는 분리 원칙을 준수하며, LDPC·Polar 코드로 섀넌 한계에 근접한 신뢰성을 달성한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **디지털 통신/저장 설계의 절대 기준**: 무손실 데이터 압축률은 정보원의 엔트로피 $H(X)$ 이하로 내려갈 수 없으며, 통신 전송률은 섀넌 채널 용량 $C$를 초과할 수 없다는 설계적 불변식.

</details>

- 데이터 압축 설계는 **엔트로피 하한**, 채널 전송 속도 및 대역폭 설계는 **섀넌 채널 용량**  절대적 상한선으로 준수

#### 한줄 요약

- 평균 부호 길이는 엔트로피 이상, 정보율은 채널 용량 미만으로 정해 압축률과 코드율을 설계
