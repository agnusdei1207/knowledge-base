## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **연결 리스트(Linked List)**: 비연속 노드를 링크로 이어 논리적 순서를 만드는 선형 자료구조이다.
- **링크(Link)**: 다음 또는 이전 노드의 메모리 위치를 가리키는 참조 필드이다.

</details>

- 정의/개념: 비연속 노드를 링크로 연결하여 원소의 논리적 순서를 관리하는 **연결 리스트** 자료구조이다.
- 배경/필요성: 배열 기반 연속 메모리에서는 중간 삽입·삭제 시 후속 원소 전체를 이동하는 오버헤드가 발생한다.

#### 한줄 요약

- 비연속 노드를 링크로 잇고, 위치를 알면 링크 변경만으로 삽입·삭제한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **순차 접근(Sequential Access)**: 헤드부터 링크를 차례로 따라가 목표 노드에 도달하는 방식이다.
- **상수 시간 갱신**: 선행 노드를 알고 있을 때 입력 크기와 무관하게 일정 횟수의 링크 변경으로 삽입•삭제하는 작업이다.
- **비연속 메모리**: 노드들이 서로 인접하지 않은 주소에 나뉘어 저장된 상태이다.

</details>

![연결 리스트와 동적 배열의 위치 접근 단계](/study/diagrams/linked-list-access.svg)

> 목표 위치가 멀어질수록 파란 연결 리스트는 링크 추적 단계가 선형 증가하지만 붉은 동적 배열은 한 단계이며, 임의 접근을 가정한 이론값이다.

- **링크 연결**로 비연속 메모리에 형성한 논리적 순서가 핵심이다.
- 목표 위치까지 링크를 따르는 **순차 접근**이 핵심이다.
- 선행 노드 확보 시 링크 변경만 하는 **상수 시간 갱신**이 핵심이다.

#### 한줄 요약

- 임의 접근 시 $O(N)$의 순차 탐색이 요구되나, 선행 노드 포인터 보유 시 $O(1)$ 시간 내에 포인터 재배치로 노드를 갱신한다.


## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **헤드(Head)**: 연결 리스트의 첫 노드를 가리키는 시작 참조이다.
- **노드(Node)**: 데이터와 다음 또는 이전 노드의 링크를 함께 저장하는 단위이다.
- **널(Null)**: 연결할 다음 노드가 없음을 나타내는 종료값이다.
- **데이터 필드**: 노드가 관리하는 값을 저장하는 영역이다.
- **링크 필드**: 다음 또는 이전 노드의 참조를 저장하는 영역이다.

</details>

전체 연결 구조

```text
[헤드] ----- [노드] ----- [노드] ----- [널]
```

선의 의미: 가로선은 헤드부터 널까지 각 노드를 잇는 링크 연결 관계를 나타낸다.

내부 노드 구조

```text
노드
├─ 데이터 필드
└─ 링크 필드
```

선의 의미: 세로선과 가지는 노드가 데이터 필드와 링크 필드를 포함하는 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 헤드 | **헤드**에 첫 노드의 시작 참조 보관 |
| 노드 | **데이터•링크 필드**를 묶은 저장 단위 |
| 데이터 필드 | **데이터 필드**에 값 저장 |
| 링크 필드 | 다음 노드 참조 또는 **널** 저장 |

#### 한줄 요약

- 헤드가 첫 노드를 가리키고 각 노드는 데이터와 다음 노드 링크를 함께 저장한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **순회(Traversal)**: 헤드에서 시작해 링크를 따라 각 노드를 차례로 방문하는 작업이다.
- **현재 노드**: 순회 과정에서 값과 다음 노드 참조를 읽는 노드이다.
- **후속 노드**: 현재 노드가 가진 링크가 가리키는 다음 방문 대상이다.

</details>

```text
순회 요청
   │
   ▼
1. 첫 노드 참조
   │
   ▼
현재 노드 판정
├─ 널: 순회 완료
└─ 노드
   ├─ 현재 값 반환
   └─ 2. 다음 참조로 이동
          │
          └─ 현재 노드 판정으로 반복
```

**동작 원리**

1. **첫 노드 참조**: 헤드가 가리키는 노드를 순회의 현재 노드로 설정한다.
2. **다음 참조로 이동**: 현재 값을 처리한 뒤 링크가 가리키는 후속 노드로 이동하고 링크가 없을 때까지 반복한다.

#### 한줄 요약

- 헤드 포인터부터 널(Null) 포인터에 도달할 때까지 포인터 추적(Pointer Chasing)을 반복하며 순회(Traversal)한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **단일 연결 리스트**: 각 노드가 다음 노드의 링크만 저장하는 구조이다.
- **이중 연결 리스트(Doubly Linked List)**: 각 노드가 앞•뒤 노드의 링크를 모두 저장하는 구조이다.
- **동적 배열(Dynamic Array)**: 연속 공간을 재할당해 크기를 늘리며 인덱스 임의 접근을 지원하는 배열이다.
- **원소 이동**: 동적 배열의 중간 삽입•삭제 때 뒤쪽 원소를 연속 위치로 옮기는 작업이다.

</details>

| 선형 자료구조 | 단일 연결 리스트 | 이중 연결 리스트 | 동적 배열 |
|:---|:---|:---|:---|
| 적용 기준 | **단일 연결 리스트**로 저장 공간 절약 | **이중 연결 리스트**로 중간 삭제 | **동적 배열**로 인덱스 조회 |
| 핵심 특징 | 노드마다 **다음 링크** 저장 | 노드마다 **이전•다음 링크** 저장 | **연속 공간**에 원소 저장 |
| 한계 | **순차 접근**만 지원해 역방향 이동 불가 | 이전 **링크 필드**의 추가 공간•갱신 | 중간 갱신 시 **원소 이동** |

> 요약: 잦은 갱신은 **연결 리스트**, 임의 조회는 **동적 배열**이 핵심이다.

#### 한줄 요약

- 빈번한 동적 노드 삽입/삭제 워크로드에는 연결 리스트, 인덱스 기반 임의 접근 및 연속 캐시 효율에는 동적 배열을 선택한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **선행 노드 참조**: 삽입•삭제 대상 바로 앞 노드를 직접 가리켜 위치 탐색을 줄이는 참조이다.
- **캐시 지역성(Cache Locality)**: 인접 주소를 연속 접근할 때 캐시를 효율적으로 쓰는 성질이다.
- **노드 풀(Node Pool)**: 노드 메모리를 묶음으로 미리 확보해 반복 할당 비용을 줄이는 저장소이다.
- **원자적 리스트 알고리즘**: 동시 갱신 중에도 링크 변경을 분할할 수 없는 연산으로 처리하는 알고리즘이다.
- **색인(Index)**: 키나 위치에서 대상 노드 참조를 빠르게 찾도록 따로 유지하는 조회 구조이다.
- **잠금(Lock)**: 여러 실행 흐름이 같은 링크를 동시에 변경하지 못하도록 접근을 직렬화하는 동기화 수단이다.
- **링크 갱신 순서**: 후속 노드 참조를 먼저 보존하고 선행 노드의 링크를 바꾸는 변경 순서이다.
- **구조 무결성**: 모든 노드가 유효한 링크로 한 번씩 연결되어 순회 가능한 상태이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 대상 위치의 **순차 접근**이 삽입•삭제 비용을 지배 | **선행 노드 참조** 또는 별도 **색인** 유지 | 위치 탐색을 제외한 **상수 시간 갱신** 활용 |
| 잘못된 **링크 갱신 순서**로 후속 사슬 단절 | 후속 링크 보존 후 선행 링크 변경 | 후속 노드까지 연결 보존 |
| 비연속 노드의 낮은 **캐시 지역성**으로 순회 지연 | **노드 풀**과 묶음 할당으로 인접 배치 | 캐시 누락 감소와 캐시 지역성 개선 |
| 동시 링크 갱신의 경쟁으로 유실•중복 연결 | **잠금** 또는 검증된 **원자적 리스트 알고리즘** 적용 | 동시 갱신의 **구조 무결성** 확보 |

#### 한줄 요약

- 후속 포인터를 고립 전에 먼저 대입하는 신중한 갱신 순서(Order of Pointer Updates)를 준수하여 포인터 유실을 방지한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **선행 노드**: 삽입•삭제할 위치의 바로 앞에 연결된 노드이다.
- **중간 갱신**: 자료구조의 처음과 끝이 아닌 위치에서 원소를 삽입하거나 삭제하는 작업이다.

</details>

- 선행 노드를 확보하고 **중간 갱신**이 잦으면 연결 리스트를 선택한다.

#### 한줄 요약

- 선행 노드를 미리 알 수 있고 중간 삽입·삭제가 잦을 때 연결 리스트를 선택한다.
