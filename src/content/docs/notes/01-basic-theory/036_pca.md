## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **주성분 분석(PCA, Principal Component Analysis)**: 고차원 데이터의 공분산 행렬을 고유값 분해(Eigendecomposition)하여 데이터 분산을 최대로 보존하는 상호 직교(Orthogonal) 축들로 선형 투영(Projection)하는 대표적 비지도 차원 축소 기법.
- **공분산 행렬(Covariance Matrix, $\Sigma$)**: $D$개 변수 간의 분산과 공분산을 정방행렬로 나타내어 데이터의 다차원 분산 방향을 기술하는 대칭 행렬.
- **고유벡터(Eigenvector) 및 고유값(Eigenvalue)**: 공분산 행렬의 주축 방향(고유벡터)과 해당 축을 따라 데이터가 퍼진 분산의 크기(고유값).

</details>

- 정의/개념: 고차원 특징 공간에서 데이터의 분산(Variance)을 최대로 보존하는 직교 기저(주성분)를 찾아 저차원 공간으로 선형 투영하는 **비지도 차원 축소 및 특성 추출 기법**
- 배경/필요성: 고차원 특징 공간에서 변수 간 다중공선성과 차원의 저주로 인해 발생하는 **연산량 폭증 및 모델 과적합 한계**

#### 한줄 요약

- 분산이 곧 정보라는 가정 위에 서 있으므로, 분산은 작아도 결정적인 신호는 축소 과정에서 함께 버려질 수 있다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **설명 분산 비율(Explained Variance Ratio)**: 개별 주성분의 고유값 $\lambda_k$를 전체 고유값의 합($\sum \lambda_i$)으로 나눈 값으로 해당 주성분의 정보 설명력 비중.
- **누적 설명 분산(Cumulative Explained Variance)**: 상위 $k$개 주성분이 전체 데이터 변동성을 설명하는 누적 백분율(통상 85~95% 기준 축 수 선정).

</details>

- 공분산 행렬의 고유값 분해 또는 데이터 행렬의 **특이값 분해(SVD)를 통한 선형 대수적 최적해 도출**
- 추출된 모든 주성분 축들 간의 **상호 직교성($u_i^T u_j = 0$)으로 정보 중복(공선성) 완전 제거**
- 원본 변수들의 선형 결합(Linear Combination)으로 축이 생성되어 **개별 피처의 직접적 비즈니스 해석 곤란**

#### 한줄 요약

- 고유값 크기 순으로 직교 주성분을 선별하여 설명 분산을 극대화하고 변수 간 상관성을 제거

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **SVD(Singular Value Decomposition)**: 데이터 행렬 $X = U \Sigma V^T$로 분해하여 $V$의 열벡터를 주성분 축으로 직접 사용하는 수치적으로 안정된 행렬 분해 기법.

</details>

```text
[ PCA 차원 축소 아키텍처 ]
┌──────────────────────────────┐
│ 전처리기 (Scaler & Centering)│ ── Z-Score 표준화 및 평균 중심화(Mean Centering)
├──────────────────────────────┤
│ 주성분 분해기 (SVD / Eigen)  │ ── 공분산 행렬 Σ의 고유벡터(U)와 고유값(λ) 산출
├──────────────────────────────┤
│ 축 선택기 (Component Filter) │ ── 누적 설명 분산(≥ 90%) 기반 최적 k개 주성분 선정
├──────────────────────────────┤
│ 선형 투영기 (Projector)      │ ── Z = X_scaled × W_k (N×D ──► N×k 차원 축소)
└──────────────────────────────┘
```

선의 의미: 데이터 표준화, SVD 분해, 누적 설명 분산 축 선택 및 저차원 투영 연산 간의 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 전처리기 | 변수별 단위 편향을 제거하는 **평균 중심화 및 표준화($\mu=0, \sigma=1$)** |
| 주성분 분해기 | 공분산 행렬 또는 SVD로부터 **직교 기저 축과 고유값($\lambda$) 산출** |
| 축 선택기 | **누적 설명 분산 곡선(Scree Plot)** 을 기반으로 최적 축 수 $k$ 확정 |
| 선형 투영기 | 투영 행렬 $W_k$를 곱해 **고차원 데이터를 저차원 주성분 점수로 변환** |

#### 한줄 요약

- 전처리기가 단위를 맞추고 추정기가 분산 축을 찾으면, 선택기와 모델이 축 수와 투영 좌표를 결정

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **스크리 도표(Scree Plot)**: 주성분 순서에 따른 고유값 크기 감쇠를 선그래프로 나타내어 기울기가 완만해지는 엘보우(Elbow) 지점을 찾는 시각화 도구.

</details>

```text
원본 고차원 데이터셋 X (N × D)
   │
   ▼
[ 1. 평균 중심화 및 표준화 ] : Z = (X - μ) / σ
   │
   ▼
[ 2. 공분산 행렬 계산 및 SVD 분해 ] : Σ = (1/N) Z^T Z
   │
   ▼
[ 3. 고유값 내림차순 정렬 및 고유벡터 도출 ]
   │
   ▼
[ 4. 누적 설명 분산 비율 계산 ] : ∑ λ_k / ∑ λ_total ≥ 0.90
   │
   ▼
[ 5. 상위 k개 주성분 선택 및 저차원 투영 ] : Z_k = Z × W_k
   │
   ▼
저차원 데이터셋 Z_k (N × k, k << D) 생성 완료
```

**동작 원리**

1. **평균 중심화 및 표준화**: 학습 데이터의 평균과 표준편차를 구하여 모든 피처를 표준정규분포로 스케일링
2. **공분산 행렬 계산 및 SVD 분해**: 표준화 행렬 $Z$로부터 공분산 행렬을 구하고 고유벡터 및 고유값 산출
3. **고유값 내림차순 정렬 및 고유벡터 도출**: 고유값 크기가 큰 순서대로 고유벡터를 정렬하여 주성분 기저 행렬 구성
4. **누적 설명 분산 비율 계산**: 누적 설명 분산이 목표치(예: 90%)에 도달하는 최소 주성분 개수 $k$ 선정
5. **상위 k개 주성분 선택 및 저차원 투영**: 원본 데이터에 $D \times k$ 변환 행렬 $W_k$를 곱하여 $N \times k$ 저차원 표현으로 변환

#### 한줄 요약

- 데이터를 표준화하고 SVD로 분산 축을 구한 뒤, 누적 분산 기준 상위 k개 축으로 선형 투영

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **주성분 분석(PCA)**: 전체 데이터 분산 최대화를 목표로 하는 비지도 선형 차원 축소 기법.
- **선형 판별 분석(LDA)**: 클래스 간 분리도 최대화 및 클래스 내 분산 최소화를 목표로 하는 지도 선형 차원 축소 기법.
- **t-SNE/UMAP**: 고차원 공간의 국소 이웃 거리를 보존하여 2D/3D 시각화에 특화된 비지도 비선형 임베딩 기법.

</details>

| 차원 축소 기법 | 주성분 분석 (PCA) | 선형 판별 분석 (LDA) | t-SNE |
|:---|:---|:---|:---|
| 적용 기준 | 머신러닝 전처리, 노이즈 제거 | 지도학습 분류기 전처리 | 고차원 데이터 탐색적 시각화 |
| 학습 방식 | **비지도 학습 (Unsupervised)** | **지도 학습 (Supervised)** | 비지도 학습 (Unsupervised) |
| 핵심 목표 | 전체 **데이터 분산 최대화** | **클래스 간 분리도 최대화** | **국소 이웃 유사도 보존** |
| 변환 방식 | **선형 직교 투영 (Linear)** | 선형 판별 투영 (Linear) | **비선형 매니폴드 임베딩** |
| 한계 | 최대 $\min(N, D)$ 개 축 한정 | **최대 $\text{Class 수} - 1$ 개 축 한정** | 확률적 최적화로 재현성 및 일반화 한계 |

#### 한줄 요약

- 분산 보존 압축은 PCA, 레이블 기반 클래스 분리는 LDA, 2D/3D 시각화는 t-SNE를 적용

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **데이터 누출(Data Leakage)**: 테스트/검증 데이터셋의 통계량(평균, 분산)이 PCA 학습에 포함되어 일반화 성능이 비정상적으로 과대평가되는 오류.
- **재구성 오차(Reconstruction Error)**: 저차원으로 축소된 주성분 점수로부터 원본 차원으로 역변환($\hat{X} = Z_k W_k^T$)했을 때 발생하는 정보 손실량 ($\|X - \hat{X}\|^2$).

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 변수 간 척도 차이로 **분산이 큰 특정 변수가 축 지배** | PCA 적합 전 `StandardScaler` **표준화 필수** | 모든 변수의 동등한 기여도 보장 |
| 전체 데이터셋 대상 PCA fit으로 **데이터 누출(Leakage)** | 반드시 **학습셋(Train)으로만 `fit`, 테스트셋은 `transform`** | 모델 일반화 평가 무결성 확보 |
| 비선형 매니폴드 구조 데이터의 **선형 투영 정보 손실** | **Kernel PCA** 또는 UMAP / Autoencoder 전환 | 비선형 곡면 데이터 패턴 보존 |
| 차원 축소 과정에서 **분산은 작지만 중요한 타깃 신호 유실** | 재구성 오차 모니터링 및 지도학습 기반 **Feature Selection 병행** | 핵심 분류/회귀 신호 보존 |

#### 한줄 요약

- 표준화를 먼저 적용하고, fit은 Train 데이터에서만 수행하며, 비선형 관계가 강하면 Kernel PCA로 전환하고, 재구성 오차를 모니터링해 축소 품질을 검증한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **고차원 머신러닝 파이프라인 표준**: 이미지, 유전자 분석, 센서 데이터 등 고차원 희소 데이터에서 PCA는 다중공선성을 제거하고 연산 비용을 획기적으로 줄이는 핵심 전처리 블록으로 기능.

</details>

- 고차원 머신러닝 전처리, 이미지 압축(Eigenfaces), 유전자 발현 분석 및 잡음 제거의 **핵심 선형 차원 축소 표준 기법**으로 자리잡았으며, 실무에서는 **Train 데이터셋 한정 fit-transform을 통한 데이터 누출(Data Leakage) 방지, 누적 설명 분산(85~95%) 기반 차원 수 결정 및 비선형 데이터에 대한 Kernel PCA/Autoencoder 확장**을 적용

#### 한줄 요약

- 학습 데이터로만 축을 추정하고 설명 분산과 검증 성능을 함께 만족하는 최소 축 수를 선택
