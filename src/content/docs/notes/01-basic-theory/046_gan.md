## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **생성적 적대 신경망(Generative Adversarial Network, GAN)**: 생성자와 판별자의 경쟁으로 실제와 유사한 표본을 만드는 모델이다.
- **데이터 분포**: 데이터 값이나 형태가 나타나는 빈도와 범위이다.
- **생성자(Generator)**: 잠재 벡터에서 가짜 표본을 만드는 신경망이다.
- **판별자(Discriminator)**: 실제 표본과 가짜 표본을 구분하는 신경망이다.
- **명시적 확률밀도**: 가능한 각 데이터값에 모델이 직접 계산해 부여하는 확률 밀도 함수이다.

</details>

- 정의/개념: **생성적 적대 신경망**은 생성자가 가짜 표본을 만들고 판별자가 실제•가짜를 구분하도록 적대적으로 학습하여 실제 **데이터 분포**와 유사한 표본을 생성하는 모형이다.
- 배경/필요성: 고차원 데이터의 **명시적 확률밀도**를 계산하기 어렵기 때문에 표본을 직접 생성하며 분포를 학습하는 방법이 필요하다.

#### 한줄 요약

- 생성자 네트워크가 잠재 벡터에서 표본을 합성하고, 판별자 네트워크가 실제·생성 표본을 분류하며, 적대적 학습으로 실제 데이터 분포에 수렴한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **암묵적 생성 모델**: 명시적 확률밀도 없이 표본 생성 절차를 학습하는 모델이다.
- **모드 붕괴**: 일부 형태만 반복 생성해 데이터 분포의 다양한 형태를 덮지 못하는 현상이다.
- **기울기 소실**: 역전파되는 학습 신호가 지나치게 작아져 갱신이 멈추는 현상이다.
- **적대적 경쟁**: 판별자는 진위를 잘 구분하고 생성자는 판별자를 속이도록 서로 반대 목표를 학습하는 관계이다.
- **우도(Likelihood)**: 모델 분포가 관측 데이터에 부여하는 확률이나 밀도이다.
- **학습 균형**: 생성자와 판별자 어느 한쪽도 지나치게 우세하지 않은 상태이다.

</details>

- 생성자와 판별자의 **적대적 경쟁**을 통한 데이터 분포 학습이 핵심이다.
- 명시적 **우도** 없이 표본을 생성하는 **암묵적 생성 모델**이 핵심이다.
- **학습 균형**이탈 시 기울기 소실•모드 붕괴 발생이 핵심이다.

#### 한줄 요약

- 감별사가 너무 강하면 위조범에게 돌아갈 단서가 사라지고, 한 위조품만 통하면 생성자가 그 모양만 찍는 모드 붕괴에 빠진다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **적대 학습 신호**: 판별자는 진위를 잘 맞히고 생성자는 판별자를 속이도록 만드는 반대 방향의 학습 신호이다.
- **잠재 벡터(Latent Vector)**: 생성 표본의 특성을 결정하도록 생성자에 입력하는 무작위 변수이다.
- **가짜 표본**: 생성자가 잠재 벡터로부터 만들어 판별자에 제시하는 합성 데이터이다.

</details>

```text
[생성자] -- [판별자]
```

선의 의미: 생성자와 판별자가 생성 표본 및 적대 학습 신호를 공유하는 대등한 연결 관계다.

| 구성요소 | 책임 |
|:---|:---|
| 생성자 | 잠재 벡터를 **가짜 표본**으로 변환하고 적대 신호로 갱신 |
| 판별자 | 실제•가짜를 판별해 **적대 학습 신호** 제공 |

#### 한줄 요약
- 위조 작업대인 생성자와 감별대인 판별자가 맞붙어, 한쪽의 판정 결과가 다른 쪽의 개선 단서가 된다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **적대 판별값**: 판별자가 생성 표본을 실제로 판단한 정도를 나타내는 값이다.
- **종료 조건**: 학습 손실•품질•반복 횟수 기준으로 적대 학습을 멈추는 조건이다.
- **판별자 갱신**: 실제•가짜 분류 손실을 줄이도록 판별자 가중치를 조정하는 단계이다.
- **적대 학습 신호 계산**: 판별자를 고정한 채 생성 표본의 실제 판정 정도로 생성자용 기울기를 구하는 단계이다.
- **생성자 갱신**: 판별자가 생성 표본을 실제로 판단하도록 생성자 가중치를 조정하는 단계이다.

</details>

```text
[생성자•판별자 초기화]
          |
          v
+------------------------------------+
| 종료 조건을 충족하기 전            |
|                                    |
|  1. 가짜 표본 생성                 |
|             |                      |
|             v                      |
|  2. 판별자 갱신                    |
|     실제•가짜 구분                 |
|             |                      |
|             v                      |
|  3. 적대 학습 신호 계산            |
|     판별자 가중치 고정             |
|             |                      |
|             v                      |
|  4. 생성자 갱신                    |
|             |                      |
|             `---------- 반복 ------|
+------------------------------------+
          |
          v
[학습된 생성자]
```

### 동작 원리

- **1. 가짜 표본 생성**: 잠재 벡터를 후보 표본으로 변환한다.
- **2. 판별자 갱신**: 실제•가짜 구분 손실로 판별 가중치를 갱신한다.
- **3. 적대 학습 신호 계산**: 생성 표본의 **적대 판별값**을 산출한다.
- **4. 생성자 갱신**: 실제 판정이 커지는 방향으로 가중치를 갱신한다.

#### 한줄 요약

- 위조범이 낸 표본을 감별사가 채점하고, 돌아온 점수표로 위조범과 감별사가 번갈아 솜씨를 고친다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **변분 오토인코더(Variational Autoencoder, VAE)**: 입력을 확률 잠재 공간으로 압축하고 복원하는 생성 모델이다.
- **확산 모델**: 무작위 잡음을 여러 단계에 걸쳐 제거하며 표본을 만드는 생성 모델이다.
- **추론**: 학습을 마친 모델이 새 입력에서 결과를 산출하는 과정이다.
- **잠재 보간**: 두 잠재 벡터 사이의 좌표를 이동해 중간 특성의 표본을 생성하는 방법이다.
- **표본 다양성**: 생성 모델이 데이터 분포의 여러 형태를 폭넓게 만들어 내는 정도이다.
- **실시간 생성**: 긴 반복 과정 없이 한 번 또는 적은 횟수의 추론으로 짧은 시간 안에 표본을 만드는 요구이다.
- **확률 잠재 공간**: 잠재 변수의 분포를 확률 모형으로 표현한 공간이다.
- **잡음 제거**: 잡음이 섞인 표본에서 잡음 성분을 예측해 점진적으로 제거하는 과정이다.
- **복원 흐림**: VAE가 여러 가능한 출력의 평균에 가까운 결과를 내면서 세부 윤곽이 흐려지는 현상이다.
- **생성 지연**: 표본 하나를 만드는 추론 과정에 걸리는 시간이다.

</details>

| 생성 모델 | GAN | VAE | 확산 모델 |
|:---|:---|:---|:---|
| 적용 기준 | 단일 통과 **실시간 생성** 필요 | **잠재 보간**•편집 필요 | **표본 다양성** 우선•지연 허용 |
| 핵심 특징 | 생성자•판별자의 경쟁 학습 | **확률 잠재 공간**에서 복원 | 반복 **잡음 제거**로 생성 |
| 한계 | **모드 붕괴**•학습 불안정 | **복원 흐림**•잠재 변수 무시 | 다단계 추론에 따른 **생성 지연** |

> 요약: 선명도는 **GAN**, 편집은 **VAE**, 다양성은 **확산 모델**이 핵심이다.

#### 한줄 요약

- 한 번에 찍는 GAN은 빠르고, 잠재 지도를 잇는 VAE는 편집에, 잡음을 여러 번 지우는 확산 모델은 다양성에 유리하다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **프레셰 인셉션 거리(Fréchet Inception Distance, FID)**: 실제 이미지와 생성 이미지의 특징 분포 거리를 측정하는 품질 지표이다.
- **미니배치**: 한 번의 파라미터 갱신에 사용하는 표본 묶음이다.
- **학습률(Learning Rate)**: 한 번의 파라미터 이동 크기이다.
- **갱신 횟수(Update Frequency)**: 생성자•판별자를 업데이트하는 빈도이다.
- **정규화 기법**: 가중치나 활성값의 규모를 제한해 적대 학습을 안정화하는 방법이다.
- **합성 데이터 편향**: 생성 표본이 실제 데이터의 불균형이나 왜곡을 재현•증폭하는 현상이다.
- **생성자 기울기 소실**: 판별자가 지나치게 우세해 생성자에 전달되는 기울기가 거의 사라지는 현상이다.
- **분포 평가**: 생성 표본과 실제 표본의 품질•다양성 차이를 분포 수준에서 측정하는 평가이다.
- **사람 평가**: 사람이 생성 표본의 자연스러움과 유용성을 직접 판정하는 평가이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 판별자 우세로 **생성자 기울기 소실** | 학습률•갱신 횟수와 손실 함수 조정 | 두 모델에 유효한 학습 신호 유지 |
| 일부 형태만 반복하는 **모드 붕괴** | 미니배치 다양성 점검•**정규화 기법** 적용 | 생성 분포 범위 확대 |
| 학습 손실은 안정적이나 품질 저하 | **FID** 기반 **분포 평가**와 **사람 평가** 병행 | 표본의 품질•다양성 동시 검증 |
| **합성 데이터 편향** 발생 | 클래스•속성별 품질 검수와 사용 비율 제한 | 운영 데이터 왜곡 완화 |

#### 한줄 요약

- 품질 계기판의 FID와 미니배치 표본판을 함께 보며 같은 얼굴만 줄지어 나오면 모드 붕괴 경보를 울린다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **경쟁 균형**: 생성자와 판별자가 서로 유효한 학습 신호를 주고받는 상태이다.

</details>

- **실시간 생성**이 우선이고 경쟁 균형 확보 시 GAN을 선택한다.

#### 한줄 요약

- 한 번에 표본을 내는 빠른 생산선과 균형 잡힌 위조범•감별사 훈련장을 함께 마련할 수 있을 때 GAN을 고른다.
