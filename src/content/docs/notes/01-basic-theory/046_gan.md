## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **생성자와 판별자(Generator & Discriminator)**: 노이즈에서 가짜 데이터를 합성하는 생성자와 실제/가짜를 0과 1로 구분하는 판별자로 구성된 적대적 2인 신경망.
- **이미지 흐림 및 모드 붕괴(Blurring & Mode Collapse)**: 픽셀 단위 MSE 손실의 한계로 인한 선명도 저하 및 생성자가 특정 패턴만 반복 생성하는 실패 현상.

</details>

- 정의/개념: 가짜 데이터를 만드는 **생성자** 및 진위를 판별하는 **판별자** 간의 적대적 미니맥스 게임을 통해 원본 분포를 모사하는 생성 모델
- 배경/필요성: 기존 평균제곱오차(MSE) 기반 생성 모델에서 발생하는 이미지 블러링(Blurring)과 명시적 확률밀도 함수 정의의 **수학적 모델링 한계**

#### 한줄 요약

- 손실을 고정 수식에서 학습되는 판별자로 바꾼 대가로 최적화 목표가 매 스텝 움직여, 수렴이 아니라 균형을 관리하는 문제가 된다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **JS 발산(Jensen-Shannon Divergence)**: 최적 판별자 $D^*$ 하에서 GAN의 미니맥스 목적 함수가 실제 데이터 분포 $p_{data}$와 생성 분포 $p_g$ 간의 JS 발산 최소화와 수학적으로 등가가 되는 성질.
- **와서스타인 거리(Wasserstein Distance / Earth Mover's Distance)**: 두 확률분포가 겹치지 않아도 유의미하고 매끄러운 기울기를 제공하는 WGAN의 거리 척도.

</details>

- 명시적 우도(Likelihood) 계산 없이 작동하는 **암묵적 데이터 분포 모델링**
- 생성자와 판별자의 균형에 기반한 **내쉬 균형 수렴 지향**
- **모드 붕괴** 및 판별자 과도 우세 시 기울기 소실 위험

#### 한줄 요약

- 생성자와 판별자의 적대적 경쟁을 통해 초고화질 이미지를 생성하되, 모드 붕괴와 학습 불안정성 제어가 핵심

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **생성자(Generator, $G_\theta$)**: 잠재 노이즈 벡터로부터 원본 데이터 분포와 유사한 가짜 표본을 합성하는 신경망.
- **판별자(Discriminator, $D_\phi$)**: 입력된 데이터가 실제 표본인지 생성자가 만든 가짜 표본인지를 판별하는 이진 분류 신경망.

</details>

```text
[GAN 적대적 학습 아키텍처]
  │
  ├─ [생성자 모듈 (G)] (가짜 표본 합성)
  │     ├─ 잠재 노이즈 z (가우시안 N(0, I) 표본 인입)
  │     └─ 생성 신경망 G_θ (x_fake = G(z) 합성)
  │
  ├─ [판별자 모듈 (D)] (진위 판별 이진 분류)
  │     ├─ 입력 선택기 (실제 표본 x_real vs x_fake 수신)
  │     └─ 판별 신경망 D_φ (진위 판별 점수 D(x) 산출)
  │
  └─ [적대적 학습 제어부] (미니맥스 최적화)
        ├─ 판별자 손실기 (max_D: log D(x) + log(1-D(G(z))))
        └─ 생성자 손실기 (min_G: Non-saturating -log D(G(z)))
```

- 선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 생성자 ($G_\theta$) | 잠재 벡터를 **가짜 표본**으로 변환 |
| 판별자 ($D_\phi$) | 실제·가짜 표본을 구분해 **판별 기울기** 제공 |
| 미니맥스 목적 함수 | 두 신경망의 **교대 최적화** 목표 정의 |

#### 한줄 요약

- 생성자가 가짜 표본을 만들고 판별자가 진위를 가리며, 판별자의 피드백으로 생성자를 고도화

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Non-saturating GAN Loss**: 생성자 학습 초기 $D(G(z)) \approx 0$일 때 $\log(1 - D(G(z)))$의 기울기 소실을 방지하기 위해 생성자 손실을 $-\log D(G(z))$로 변경하여 강력한 초기 기울기를 부여하는 기법.

</details>

```text
학습 데이터셋 X_real 및 노이즈 생성기 z 인입
   |
   v
[ 1. 판별자 D 훈련 ] (k회 반복)
   |
   +---> 실제 데이터 x 샘플링   : L_real = -log D(x)
   |
   +---> 가짜 데이터 x_hat 생성 : L_fake = -log(1 - D(x_hat))
   |
   v
[ 판별자 파라미터 갱신 ] : ∇_φ (L_real + L_fake) 역전파
   |
   v
[ 2. 생성자 G 훈련 ] (1회)
   |
   +---> 판별자 D 파라미터 동결 후 G 손실: L_G = -log D(G(z))
   |
   v
[ 생성자 파라미터 갱신 ] : ∇_θ L_G 역전파
   |
   v
[ 3. 내쉬 균형 수렴 검증 ] : D(x) ≈ 0.5 및 FID 점수 모니터링
```

분기 결과: 판별자가 가짜와 실제를 완벽히 구분하지 못하고 D(x)가 0.5에 수렴하며 FID 점수가 최적에 도달하면 학습을 종료하고, 그렇지 않으면 교대 훈련 루프를 지속한다.

**동작 원리**:
1. **판별자 D 훈련**: 실제 데이터 $x$와 생성된 가짜 데이터 $G(z)$를 각각 인입하여 이진 크로스 엔트로피 손실로 판별자 파라미터를 갱신한다.
2. **생성자 G 훈련**: 판별자의 가중치를 동결한 상태에서 $G(z)$가 판별자를 속이도록 Non-saturating 손실($-\log D(G(z))$)로 생성자 파라미터를 역전파 갱신한다.
3. **교대 최적화 반복**: 판별자를 $k$회 최적화한 후 생성자를 1회 최적화하는 미니맥스 2인 제로섬 게임을 반복한다.
4. **내쉬 균형 수렴 검증**: 판별자의 분류 확률이 $0.5$로 수렴하여 생성 분포와 실제 데이터 분포가 일치하는지 확인하고 FID 점수로 최종 생성 품질을 판정한다.

#### 한줄 요약

- 판별자를 먼저 훈련하여 분별력을 높이고, 생성자가 판별자를 속이도록 교대 역전파를 수행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **생성적 적대 신경망(GAN)**: 생성자와 판별자의 제로섬 게임으로 고선명 데이터를 합성하는 생성 모델.
- **변분 오토인코더(VAE)**: 확률 잠재 변수 공간을 모델링하여 연속적 데이터를 생성하는 모델.
- **확산 모델(Diffusion Model)**: 점진적인 노이즈 추가 및 제거 과정을 학습하여 최고 화질의 데이터를 생성하는 모델.

</details>

| 생성 모델 | GAN (적대적 생성) | VAE (변분 오토인코더) | 확산 모델 (Diffusion) |
|:---|:---|:---|:---|
| 적용 기준 | **실시간 고화질 영상 합성** | 잠재 공간 보간 및 데이터 압축 | **최고 화질/다양성 이미지 생성** |
| 핵심 특징 | **생성자-판별자 2인 적대적 게임** | **인코더-디코더 잠재 분포 근사** | **점진적 반복 노이즈 제거** |
| 한계 | **모드 붕괴 및 학습 불안정성** | 평균화로 인한 **블러링 발생** | **수십 스텝 반복으로 추론 느림** |

#### 한줄 요약

- 실시간성과 선명도는 GAN, 잠재 공간 편집은 VAE, 최고 화질과 분포 다양성은 확산 모델을 선택

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **WGAN-GP(Wasserstein GAN with Gradient Penalty)**: 판별자를 1-립시츠(Lipschitz) 연속 함수로 제한하기 위해 판별자의 기울기 노름에 페널티($(\|\nabla_{\hat{x}} D(\hat{x})\|_2 - 1)^2$)를 부여하여 학습을 완벽히 안정화한 표준 GAN.
- **FID(Fréchet Inception Distance)**: Inception-v3 특징 공간에서 실제 이미지와 생성 이미지의 다변량 가우시안 분포 간 거리를 계산하는 생성 모델의 표준 품질 척도(낮을수록 우수).

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 생성자가 일부 표본만 반복하는 **모드 붕괴** | **WGAN-GP** 적용 | 연속 기울기로 생성 분포 다양성 회복 |
| 판별자 과적합으로 **생성자 기울기 소실** | **스펙트럴 정규화**·TTUR 적용 | 판별자 제약과 학습 속도 균형 |
| 손실과 체감 생성 품질의 **괴리** | **FID**·IS 추적 | 이미지 품질·다양성 정량 평가 |
| 비쌍 이미지 간 변환 데이터 부족 | **CycleGAN** 적용 | 순환 일관성으로 비쌍 도메인 변환 |

#### 한줄 요약

- 모드 붕괴는 WGAN-GP로 해결하고, 학습 안정화에는 Spectral Normalization을 적용하며, 생성 품질은 FID로 평가하고, 비지도 도메인 변환에는 CycleGAN을 선택한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **생성 모델 프로덕션 표준**: 대규모 텍스트-투-이미지 생성은 Diffusion 모델이 주도하고 있으나, 초당 60fps 이상의 실시간 비디오 변환, 가상 착장(Virtual Try-on), 실시간 게임 렌더링에는 StyleGAN/FastGAN이 표준으로 운용.

</details>

- 실시간 이미지 합성(StyleGAN), 이미지 도메인 변환(CycleGAN/Pix2Pix) 및 초해상도(SRGAN)의 **핵심 생성 딥러닝 아키텍처**로 확립되었으며, 고품질 오프라인 생성은 확산 모델(Diffusion)로 분화되었으나 실무에서는 **단일 포워드 초고속 추론(60+ FPS), WGAN-GP 기울기 페널티 및 FID 점수 기반 검증**을 통해 실시간 그래픽스/가상 피팅 파이프라인을 구동

#### 한줄 요약

- 실시간 단일 통과 생성이 요구될 때 GAN을 채택하고, WGAN-GP 및 Spectral Normalization으로 안정성을 확보
