## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **생성적 적대 신경망(GAN, Generative Adversarial Network)**: 가짜 데이터를 생성하는 생성자(Generator)와 실제/가짜를 구별하는 판별자(Discriminator)가 제로섬 게임(Zero-Sum Game) 형태로 대립하며 실제 데이터 분포 $p_{data}$를 암묵적으로 학습하는 생성 모델.
- **미니맥스 게임(Minimax Game)**: $V(D, G) = \mathbb{E}_{x \sim p_{data}}[\log D(x)] + \mathbb{E}_{z \sim p_z}[\log(1 - D(G(z)))]$ 수식으로 정의되는 생성자와 판별자의 상반된 2인 최적화 목적 함수.
- **모드 붕괴(Mode Collapse)**: 생성자가 데이터 분포의 다양한 모드(다양성)를 포기하고, 판별자를 속이기 쉬운 소수의 특정 형태 표본만을 반복 생성하는 고질적 실패 상태.

</details>

- 정의/개념: 생성자 $G$와 판별자 $D$의 적대적 경쟁 학습을 통해 명시적 확률 밀도 계산 없이 실제와 구별 불가능한 고화질 합성 데이터를 생성하는 **암묵적 생성 모델(Implicit Generative Model)**
- 배경/필요성: 픽셀 단위 평균으로 흐린(Blurry) 이미지를 생성하는 기존 VAE의 한계를 극복하고 **단일 순전파만으로 극도의 선명도(Sharpness)를 갖는 실시간 합성 표본 생성 필수**

#### 한줄 요약

- 생성자와 판별자의 미니맥스 제로섬 경쟁을 통해 실제 데이터 분포에 수렴하는 고화질 표본을 합성

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **JS 발산(Jensen-Shannon Divergence)**: 최적 판별자 $D^*$ 하에서 GAN의 미니맥스 목적 함수가 실제 데이터 분포 $p_{data}$와 생성 분포 $p_g$ 간의 JS 발산 최소화와 수학적으로 등가가 되는 성질.
- **와서스타인 거리(Wasserstein Distance / Earth Mover's Distance)**: 두 확률분포가 겹치지 않아도 유의미하고 매끄러운 기울기를 제공하는 WGAN의 거리 척도.

</details>

- 명시적 우도(Likelihood) 계산 없이 작동하는 **암묵적 데이터 분포 모델링**
- 생성자와 판별자의 역학적 균형에 기반한 **내쉬 균형(Nash Equilibrium) 수렴 지향**
- **모드 붕괴(Mode Collapse) 및 판별자 과도 우세 시의 기울기 소실(Vanishing Gradient)** 위험

#### 한줄 요약

- 생성자와 판별자의 적대적 경쟁을 통해 초고화질 이미지를 생성하되, 모드 붕괴와 학습 불안정성 제어가 핵심

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **GAN 2대 신경망 블록**:
  - 생성자 ($G_\theta$): 정규분포 잠재 벡터 $\mathbf{z} \sim N(0, I)$로부터 합성 데이터 $G(\mathbf{z})$ 생성.
  - 판별자 ($D_\phi$): 입력 데이터 $\mathbf{x}$가 실제($1$)인지 가짜($0$)인지의 확률 $D(\mathbf{x})$ 판정.

</details>

```text
[ GAN 적대적 학습 아키텍처 및 손실 구조 ]
 
 [ 실제 데이터 x ~ p_data ] ──────┐
                                   ▼
 [ 잠재 벡터 z ] ──► [ 생성자 G ] ──► [ 가짜 x_hat ] ──► [ 판별자 D ] ──► 판별 점수 D(x) ∈ [0, 1]
                                          │                     │
                                          │                     ▼
                                          │             [ D 손실: -log D(x) - log(1 - D(x_hat)) ]
                                          ▼                     │
                                  [ G 손실: -log D(x_hat) ] ◄───┘ (적대 기울기 역전파)
```

선의 의미: 잠재 벡터 입력, 가짜 표본 생성, 판별자 진위 분류 및 상호 적대 기울기 피드백 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 잠재 벡터 ($\mathbf{z}$) | 무작위 노이즈 분포($N(0, I)$)로부터 **생성 다양성의 원천 제공** |
| 생성자 ($G_\theta$) | 잠재 공간을 고차원 데이터 공간으로 매핑하여 **가짜 표본($\mathbf{\hat{x}}$) 합성** |
| 판별자 ($D_\phi$) | 실제 표본($1$)과 생성 표본($0$)을 구별하여 **적대적 오차 기울기 피드백** |
| 미니맥스 손실기 | $\max_D \min_G V(D, G)$ 목적 함수를 계산하여 **상호 가중치 교대 갱신** |

#### 한줄 요약

- 생성자가 가짜 표본을 만들고 판별자가 진위를 가리며, 판별자의 피드백으로 생성자를 고도화

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Non-saturating GAN Loss**: 생성자 학습 초기 $D(G(z)) \approx 0$일 때 $\log(1 - D(G(z)))$의 기울기 소실을 방지하기 위해 생성자 손실을 $-\log D(G(z))$로 변경하여 강력한 초기 기울기를 부여하는 기법.

</details>

```text
학습 데이터셋 X_real 및 노이즈 생성기 z 인입
   │
   ▼
[ 1. 판별자 D 훈련 단계 (k회 반복) ]
├─ 실제 데이터 x 샘플링 ──► D(x) 손실: L_real = -log D(x)
├─ 잠재 벡터 z 샘플링 ──► 가짜 데이터 x_hat = G(z) 생성 ──► D(x_hat) 손실: L_fake = -log(1 - D(x_hat))
└─ 판별자 파라미터 갱신: ∇_φ (L_real + L_fake) 역전파 (D 최대화)
   │
   ▼
[ 2. 생성자 G 훈련 단계 (1회) ]
├─ 잠재 벡터 z 샘플링 ──► x_hat = G(z) 생성
├─ 판별자 통과: D(x_hat) 점수 계산 (D 파라미터 동결)
└─ 생성자 파라미터 갱신: ∇_θ [-log D(G(z))] 역전파 (G 최적화)
   │
   ▼
[ 3. 내쉬 균형 수렴 검증 (D(x) ≈ 0.5 및 FID 점수 모니터링) ]
```

**동작 원리**

1. **판별자 갱신**: 실제 데이터와 생성된 가짜 데이터를 판별자에 입력하여 이진 분류 손실로 $D$를 먼저 훈련
2. **생성자 갱신**: 판별자의 파라미터를 고정하고, 판별자가 가짜 데이터를 실제($1$)로 오판하도록 $G$의 가중치 갱신
3. **교대 반복**: 매 미니배치마다 $D$와 $G$를 교대로 학습시키며 동적 평형 유지
4. **최종 수렴**: 판별자가 실제와 가짜를 전혀 구분하지 못하는 $D(x) = 0.5$ 상태 도달 시 학습 완료

#### 한줄 요약

- 판별자를 먼저 훈련하여 분별력을 높이고, 생성자가 판별자를 속이도록 교대 역전파를 수행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **생성 AI 3대 패러다임 비교**:
  - GAN: 적대적 게임, 단일 스텝 추론(초고속), 선명도 최강, 모드 붕괴 위험.
  - VAE: 확률 잠재 변수 모델, ELBO 최대화, 안정적 수렴, 블러링 현상.
  - Diffusion: 점진적 가우시안 노이즈 역확산, 다단계 반복 추론(느림), 모드 붕괴 없음, 화질 최강.

</details>

| 비교 항목 | GAN (적대적 생성) | VAE (변분 오토인코더) | 확산 모델 (Diffusion) |
|:---|:---|:---|:---|
| 핵심 원리 | **생성자-판별자 2인 적대적 게임** | **인코더-디코더 잠재 분포 근사** | **점진적 노이즈 제거 (Score Matching)** |
| 추론 속도 | **단일 순전파로 극도로 빠름 (Real-time)** | 단일 순전파로 빠름 | **수십~수백 스텝 반복으로 느림** |
| 생성 품질 | **선명도 우수, 고화질 이미지 합성** | 평균화로 인한 **블러링(흐림) 발생** | **극도의 사실감 및 디테일 완성도** |
| 학습 안정성 | **모드 붕괴 및 학습 불안정성 큼** | 안정적 수렴 (ELBO 목적 함수) | **매우 안정적 (모드 붕괴 없음)** |
| 주요 적용처 | **실시간 이미지 변환, StyleGAN, 딥페이크** | 잠재 공간 보간, 데이터 압축 | **Midjourney, Stable Diffusion, DALL-E 3** |

#### 한줄 요약

- 실시간성과 선명도는 GAN, 잠재 공간 편집은 VAE, 최고 화질과 분포 다양성은 확산 모델을 선택

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **WGAN-GP(Wasserstein GAN with Gradient Penalty)**: 판별자를 1-립시츠(Lipschitz) 연속 함수로 제한하기 위해 판별자의 기울기 노름에 페널티($(\|\nabla_{\hat{x}} D(\hat{x})\|_2 - 1)^2$)를 부여하여 학습을 완벽히 안정화한 표준 GAN.
- **FID(Fréchet Inception Distance)**: Inception-v3 특징 공간에서 실제 이미지와 생성 이미지의 다변량 가우시안 분포 간 거리를 계산하는 생성 모델의 표준 품질 척도(낮을수록 우수).

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 생성자가 특정 이미지만 반복 출력하는 **모드 붕괴(Mode Collapse)** | **WGAN-GP (Wasserstein Loss + Gradient Penalty)** 적용 | Wasserstein 거리로 매끄러운 기울기 확보 및 모드 붕괴 차단 |
| 판별자 조기 과적합으로 인한 **생성자 기울기 소실** | **Spectral Normalization** 및 Two Time-Scale Update(TTUR) | 판별자 립시츠 제약 및 학습 속도 균형 |
| 손실 수치와 실제 시각적 생성 화질 간의 **괴리** | **FID(Fréchet Inception Distance) 및 IS(Inception Score)** 추적 | 이미지 품질 및 다양성 정량적 검증 |
| 이미지-대-이미지 변환 시 라벨링 페어 데이터 부재 | **CycleGAN (Cycle Consistency Loss)** 아키텍처 채택 | 비쌍(Unpaired) 도메인 간 상호 변환 실현 |

#### 한줄 요약

- **WGAN-GP 모드붕괴 해결·Spectral Normalization 학습안정화·FID 품질평가·CycleGAN 비지도변환**

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **생성 모델 프로덕션 표준**: 대규모 텍스트-투-이미지 생성은 Diffusion 모델이 주도하고 있으나, 초당 60fps 이상의 실시간 비디오 변환, 가상 착장(Virtual Try-on), 실시간 게임 렌더링에는 StyleGAN/FastGAN이 표준으로 운용.

</details>

- 초고속 단일 통과 생성은 **GAN/StyleGAN**, 안정적 잠재 보간은 **VAE**, 최고 화질/다양성은 Diffusion 선택

#### 한줄 요약

- 실시간 단일 통과 생성이 요구될 때 GAN을 채택하고, WGAN-GP 및 Spectral Normalization으로 안정성을 확보
