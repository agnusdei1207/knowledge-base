## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **편향-분산 트레이드오프(Bias-Variance Tradeoff)**: 머신러닝 모델의 복잡도(Complexity)에 따라 예측 오차를 구성하는 편향(Bias)과 분산(Variance)이 상호 역방향으로 상충하는 통계적 법칙.
- **과적합(Overfitting)**: 모델이 훈련 데이터의 무작위 노이즈까지 지나치게 학습하여 훈련 오차는 극소화되나 검증/테스트 오차가 급증하는 고분산(High Variance) 상태.
- **과소적합(Underfitting)**: 모델의 표현력(Capacity)이 부족하여 데이터의 내재된 패턴조차 학습하지 못해 훈련 오차와 검증 오차가 모두 높게 유지되는 고편향(High Bias) 상태.

</details>

- 정의/개념: 총 기대 오차 $E[(y - \hat{f}(x))^2] = \text{Bias}^2(\hat{f}(x)) + \text{Var}(\hat{f}(x)) + \sigma^2$ 분해식에 따라 편향과 분산의 합이 최소가 되는 **최적 모델 복잡도(Sweet Spot) 탐색 체계**
- 배경/필요성: 훈련 손실(Training Loss) 극소화에만 편중될 경우 발생하는 노이즈 암기(과적합) 및 표현력 부족(과소적합)으로 인한 **미지 데이터 대상 일반화 오차(Generalization Error) 급증 한계**

#### 한줄 요약

- 편향과 분산은 같은 손잡이의 양 끝이라 한쪽을 줄이면 다른 쪽이 늘며, 기약 오차 아래로는 어떤 조정으로도 내려갈 수 없다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **편향(Bias)**: 모델의 예측값 평균과 실제 참값 간의 거리로 단순한 모델일수록 높아짐.
- **분산(Variance)**: 서로 다른 훈련 데이터셋을 사용했을 때 모델 예측값들이 변동하는 민감도로 복잡한 모델일수록 높아짐.
- **일반화 격차(Generalization Gap)**: 검증 손실(Validation Loss)과 훈련 손실(Training Loss) 간의 격차($L_{val} - L_{train}$).

</details>

![모델 복잡도에 따른 훈련 오차와 검증 오차 차트](/study/diagrams/bias-variance-error.svg)

> 모델 복잡도 증가 시 훈련 오차는 단조 감소하나, 검증 오차는 U-커브를 그리며 최적점에서 최소치 달성 후 재상승

- 모델 용량 증가 시 **편향은 지속 감소하고 분산은 지수적으로 증가**
- 학습 곡선(Learning Curve) 상에서 **검증 손실이 반등하기 시작하는 지점을 최적 복잡도로 판정**
- 고편향(과소적합)은 모델 확장으로, 고분산(과적합)은 **가중치 규제(L1/L2) 및 드롭아웃** 기반  제어

#### 한줄 요약

- 모델 복잡도가 증가하면 편향은 줄고 분산은 늘어나므로, 검증 손실이 최소화되는 지점에서 복잡도를 결정

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **규제화 기법(Regularization)**: 손실 함수에 가중치 노름 페널티($\lambda \|\mathbf{w}\|_2^2$)를 추가하거나 학습 조기 종료(Early Stopping), 드롭아웃(Dropout)을 통해 모델의 유효 자유도를 축소하는 기법.

</details>

```text
[총 기대 오차 분해 및 제어 체계]
  │
  ├─ [총 기대 오차 성분] (오차 분해 구조)
  │     ├─ 편향 제곱 (Bias²: 모델 표현력 부족 체계적 오차)
  │     ├─ 분산 (Variance: 데이터 표본 변동 민감도)
  │     └─ 기약 오차 (σ²: 데이터 내재 제거 불가 잡음)
  │
  ├─ [상태 진단 지표] (학습 곡선 모니터링)
  │     ├─ 훈련/검증 오차 (학습 곡선 손실 수렴 추적)
  │     └─ 일반화 격차 (L_val - L_train 과적합 판정)
  │
  └─ [복잡도 제어부] (일반화 최적점 튜닝)
        ├─ 모델 확장기 (고편향 대응: 파라미터/피처 증설)
        └─ 정규화 제어기 (고분산 대응: L1/L2, Dropout, Early Stop)
```

- 선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 편향 (Bias) | 모델의 표현력 부족으로 인한 **체계적 예측 오차 정량화** |
| 분산 (Variance) | 데이터 표본 변동에 대한 **모델 예측값의 민감도 정량화** |
| 기약 오차 ($\sigma^2$) | 데이터 자체에 내재된 잡음으로 **어떤 모델로도 제거 불가능한 한계 오차** |
| 복잡도 조정기 | **L1/L2 규제 강도($\lambda$), 트리 깊이, 조기 종료 에폭** 제어 |

#### 한줄 요약

- 오차 측정기와 진단기가 훈련•검증 차이를 판정하면, 조정기가 모델 용량이나 규제 강도를 제어

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **조기 종료(Early Stopping)**: 에폭(Epoch) 반복 중 검증 손실이 $P$회 이상 연속으로 개선되지 않을 때 최적 가중치를 복원하고 학습을 즉각 중단하는 규제 기법.

</details>

```text
모델 학습 진행 (Epoch 루프)
   |
   v
[ 1. 훈련 손실 및 검증 손실 측정 ]
   |
   v
[ 2. 적합 상태 진단 ]
   |
   +---> L_train 및 L_val 모두 높음 (Underfitting) :
   |        |
   |        v
   |     [ 모델 레이어 확장, 피처 엔지니어링, 규제 완화 ] 후 재학습
   |
   +---> L_train 은 극소이나 L_val 반등 (Overfitting, 일반화 격차 확대) :
   |        |
   |        v
   |     [ Early Stopping, Dropout, L2 Weight Decay, Data Augmentation ] 적용
   |
   +---> L_val 최저점 도달 및 격차 안정 (Optimal Fit) :
            |
            v
         [ 3. 최적 가중치 복원 및 모델 확정 ]
```

분기 결과: 훈련/검증 손실이 모두 높으면 표현력 부족으로 분기하여 모델을 확장하고, 훈련 손실만 낮고 검증 손실이 반등하면 일반화 실패로 분기하여 규제/조기종료를 적용하며, 검증 손실이 최저점에 도달하면 최적 가중치로 확정한다.

**동작 원리**:
1. **훈련 손실 및 검증 손실 측정**: 매 에폭 반복마다 훈련 오차($L_{train}$)와 검증 오차($L_{val}$)를 독립적으로 동시 추적한다.
2. **적합 상태 진단**: 두 손실 값의 크기와 격차(Generalization Gap) 변화 추이에 따라 과소적합, 과적합, 최적 상태를 식별한다.
3. **편향-분산 조정 조치**: 과소적합 판정 시 네트워크 파라미터를 증설하고, 과적합 판정 시 가중치 감쇄 및 드롭아웃 규제를 동적으로 강화한다.
4. **최적 가중치 복원 및 모델 확정**: 검증 손실이 $P$회 연속 감소하지 않는 조기 종료 조건 도달 시 역대 최저 손실 시점의 체크포인트를 복원하여 최종 배포 모델로 확정한다.

#### 한줄 요약

- 훈련 손실과 검증 손실의 괴리를 모니터링하여 조기 종료, 가중치 감쇄, 드롭아웃 등의 조치를 수행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **과소적합(Underfitting)**: 모델의 표현력 부족으로 훈련 데이터조차 충분히 학습하지 못한 상태.
- **과적합(Overfitting)**: 모델이 훈련 데이터의 잡음까지 암기하여 검증 데이터에서 오차가 폭증하는 상태.
- **적정 적합(Optimal Fit)**: 편향과 분산의 최적 균형으로 일반화 오차가 최소화된 상태.

</details>

| 적합 상태 | 과소적합 (Underfitting) | 과적합 (Overfitting) | 적정 적합 (Optimal Fit) |
|:---|:---|:---|:---|
| 적용 기준 | 훈련·검증 손실 모두 임계치 초과 시 | 훈련 손실 대비 검증 손실 급격한 반등 시 | 검증 손실 최저점 수렴 및 격차 최소 시 |
| 훈련 오차 | **높음 ($\uparrow$)** | **매우 낮음 ($\downarrow$)** | 낮음 |
| 검증 오차 | **높음 ($\uparrow$)** | **높음 ($\uparrow$) (반등)** | **최소 달성 ($\min$)** |
| 편향 / 분산 | **고편향 (High Bias)** | **고분산 (High Variance)** | **편향-분산 균형** |
| 한계 | 단순한 모델로 데이터 패턴 미반영 | 데이터 부족 및 파라미터 과다로 일반화 실패 | 기약 오차($\sigma^2$) 이하로 오차 축소 불가 |

#### 한줄 요약

- 고편향 과소적합은 모델 용량을 확대하고, 고분산 과적합은 규제와 데이터 증강으로 제어

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **가중치 감쇄(Weight Decay / L2 Regularization)**: 가중치의 제곱합을 손실 함수에 가산하여 개별 가중치 값들이 과도하게 비대해지는 것을 방지하는 기법.
- **드롭아웃(Dropout)**: 훈련 시 매 미니배치마다 무작위로 뉴런의 일부를 비활성화하여 특정 뉴런 간의 공적응(Co-adaptation)을 파괴하는 앙상블 효과 기법.
- **데이터 증강(Data Augmentation)**: 회전, 자르기, Mixup 등을 통해 훈련 데이터의 다양성을 인위적으로 확장하는 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 딥러닝 학습 시 가중치 비대화로 인한 **과적합 폭증** | **Weight Decay(L2) 및 Dropout(0.2~0.5)** 적용 | 뉴런 공적응 파괴 및 가중치 안정화 |
| 학습 에폭 과다로 인한 **검증 손실 역주행** | `Patience=5` 기반 **Early Stopping 및 Best Checkpoint 복원** | 과적합 발생 전 최적 가중치 보존 |
| 훈련 데이터 부족으로 인한 **고분산 과적합** | **Data Augmentation(Mixup, CutMix)** 및 전이학습 | 유효 훈련 데이터 증대 및 분산 축소 |
| 모델이 너무 단순하여 **훈련 데이터 패턴 미학습** | **신경망 레이어 증설(ResNet 등)** 및 다항 피처 확장 | 고편향 해소 및 표현력 극대화 |

#### 한줄 요약

- 과적합은 Dropout·Weight Decay 규제와 Early Stopping으로 억제하고, 데이터 부족은 Data Augmentation으로 보완하며, 과소적합이면 ResNet 등 모델 용량을 확대한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **머신러닝 최적화 원칙**: 머신러닝의 궁극적 목표는 훈련 손실 0이 아니라 미지의 테스트 데이터에 대한 일반화 오차 최소화이며, 이를 위해 편향과 분산의 트레이드오프를 체계적으로 제어.

</details>

- 모든 머신러닝/딥러닝 모델 설계 및 하이퍼파라미터 튜닝의 **근본적 최적화 원칙**으로 정립되었으며, 실무에서는 **학습 곡선(Learning Curve) 진단을 기반으로 고편향 시 모델 용량 확대/특성 추가를, 고분산 시 가중치 감쇄(L2 Weight Decay), 드롭아웃(Dropout), 데이터 증강(Augmentation) 및 조기 종료(Early Stopping)**를 체계적으로 적용하여 일반화 성능을 극대화

#### 한줄 요약

- 일반화 격차가 크면 규제를 강화하고, 두 오차가 모두 높으면 용량을 늘려 검증 오차 최소점을 선택
