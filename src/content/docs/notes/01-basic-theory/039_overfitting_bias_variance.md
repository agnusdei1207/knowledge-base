## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **과적합•과소적합(Overfitting•Underfitting)**: 모델이 훈련 자료에 지나치게 맞아 새 자료에서 실패하거나, 너무 단순해 훈련 자료의 구조도 충분히 학습하지 못한 상태
- **편향-분산 트레이드오프**: 모델 복잡도가 커지면 편향은 줄지만 예측 분산은 커질 수 있는 상충 관계
- **일반화 성능**: 학습에 사용하지 않은 새 데이터에서 모델이 내는 예측 성능

</details>

- 정의/개념: 훈련•검증 오차로 과소적합•과적합을 구분하고 모델 복잡도의 **편향•분산 상충**을 판정하는 일반화 진단
- 배경/필요성: 훈련 성능과 **일반화 성능**의 차이 판별

#### 한줄 요약

- 문제집 답을 외워 훈련 점수만 높은 학생과 원리를 배운 학생을 가르려면, 처음 보는 검증 문제의 오차를 함께 봐야 한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **편향•분산**: 평균 예측이 실제값에서 벗어난 정도와 학습 표본 변화에 따라 예측이 흔들리는 정도
- **과소적합•과적합**: 모델이 너무 단순해 패턴을 놓치거나 너무 복잡해 잡음까지 학습한 상태
- **검증 오차**: 학습에 직접 사용하지 않은 검증셋에서 계산한 예측 오차
- **모델 복잡도**: 모델이 표현할 수 있는 함수의 세밀함과 자유도
- **일반화 격차**: 검증 오차에서 훈련 오차를 뺀 성능 차이

</details>

![모델 복잡도에 따른 훈련 오차와 검증 오차 차트](/study/diagrams/bias-variance-error.svg)

> 설명용 개념 좌표에서 파란 훈련 오차는 계속 감소하지만 빨간 검증 오차는 중간 복잡도에서 최소가 된 뒤 다시 증가하며, 실측 데이터는 아니다.

- **모델 복잡도** 증가에 따른 편향 감소•**분산 증가**
- 고편향 **과소적합**과 고분산 **과적합**의 대칭적 진단
- **검증 오차 최소** 지점 기준 적정 복잡도 선택

> **과적합**: 검증 오차•일반화 격차 상승

#### 한줄 요약

- 곧은 자는 곡선을 놓치고 너무 굽은 자는 잡음까지 따르므로, 검증 오차가 가장 낮은 복잡도를 고른다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **모델 용량**: 모델이 표현할 수 있는 함수 복잡도의 범위
- **일반화 격차**: 검증 오차에서 훈련 오차를 뺀 차이
- **규제**: 가중치 크기나 학습 시간을 제한해 모델의 과도한 복잡도를 억제하는 기법
- **규제 강도**: 모델 복잡도에 부과하는 제약이나 벌점의 크기

</details>

```mermaid
block-beta
    columns 3
    M["학습 모델"] --- E["오차 측정기"] --- D["적합 진단기"] --- C["복잡도 조정기"]
```

| 구성요소 | 책임 |
|:---|:---|
| 학습 모델 | **모델 용량** 범위의 예측 산출 |
| 오차 측정기 | 훈련•검증 **예측 오차** 계산 |
| 적합 진단기 | 오차•**일반화 격차**로 상태 판정 |
| 복잡도 조정기 | **규제 강도•용량** 변경 |

#### 한줄 요약

- 오차 측정기와 진단기가 훈련•검증 차이를 판정하면, 조정기가 모델 용량이나 규제 강도를 바꾼다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **적합 상태**: 훈련•검증 오차에 따라 과소적합•적정 적합•과적합으로 구분한 학습 상태
- **복잡도 조정값**: 모델 용량•규제 강도•학습 시간을 바꾸기 위해 전달하는 설정
- **적정 적합**: 검증 오차와 일반화 격차를 낮게 유지한 상태
- **모델 용량**: 모델이 표현할 수 있는 함수 복잡도의 범위
- **규제 강도•학습 시간**: 복잡도를 억제하는 제약의 크기와 학습을 진행하는 반복 기간
- **일반화 격차**: 검증 오차와 훈련 오차 사이의 차이

</details>

```mermaid
sequenceDiagram
    participant M as 학습 모델
    participant E as 오차 측정기
    participant D as 적합 진단기
    participant C as 복잡도 조정기
    loop 검증 오차 개선 후보 존재
        M->>E: 1. 훈련•검증 예측 전달
        E->>D: 2. 오차•격차 전달
        D->>C: 3. 적합 상태 전달
        C-->>M: 4. 복잡도 조정값 전달
    end
```

### 동작 원리

- **1. 훈련•검증 예측 전달**: 두 표본군 예측 생성
- **2. 오차•격차 전달**: 오차와 일반화 격차 계산
- **3. 적합 상태 전달**: 과소•과적합•적정 판정
- **4. 복잡도 조정값 전달**: 용량•규제•학습 시간 변경

#### 한줄 요약

- 모델이 문제집•새 시험 답을 내면 측정기가 두 오차와 간격을 재고, 진단 결과에 따라 표현력을 늘리거나 규제 브레이크를 건다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **고편향•고분산**: 핵심 패턴을 충분히 표현하지 못하거나 학습 표본 변화에 예측이 크게 흔들리는 상태
- **배포 성능**: 운영 환경의 새로운 입력에서 측정한 모델 성능
- **입력 분포 변화**: 운영 입력의 범위와 빈도가 학습 데이터와 달라지는 현상
- **과적합•과소적합•적정 적합**: 고분산, 고편향, 두 오차와 격차가 낮은 학습 상태

</details>

| 적합 상태 | 과적합 | 과소적합 | 적정 적합 |
|:---|:---|:---|:---|
| 적용 기준 | 훈련 오차 대비 **일반화 격차** 클 때 | **훈련 오차** 자체가 높을 때 | **검증 오차** 최소 지점일 때 |
| 핵심 특징 | 잡음까지 학습한 **고분산** 상태 | 표현력이 모자란 **고편향** 상태 | **트레이드오프** 균형 지점 복잡도 |
| 한계 | 잡음 학습에 따른 **배포 성능** 급락 | **핵심 패턴** 누락에 따른 성능 한계 | **입력 분포 변화** 시 성능 저하 |

> 요약: 두 오차의 높이와 간격으로 갈리는 **적합 상태**

#### 한줄 요약

- 문제집 점수만 좋고 새 시험이 나쁘면 과적합이라 규제를 걸고, 두 점수가 모두 나쁘면 과소적합이라 모델 표현력을 늘린다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **교차검증**: 데이터를 여러 분할로 나눠 학습•검증을 반복하고 일반화 성능을 평균하는 평가법
- **L2 규제**: 큰 가중치의 제곱합에 벌점을 줘 모델 복잡도를 줄이는 기법
- **조기 종료**: 검증 오차가 다시 오르기 시작할 때 학습을 멈추는 기법
- **데이터 증강**: 의미를 보존하는 변환으로 학습 표본의 다양성을 늘리는 기법
- **독립 검증셋**: 모델 학습과 조정에 사용하지 않고 일반화 성능 평가에만 쓰는 데이터
- **재학습(Retraining)**: 운영 분포 변화에 맞춰 새 데이터로 모델을 다시 학습하는 작업

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **훈련 오차**만으로 모델 선택 | 독립 검증셋•**교차검증** 사용 | **일반화 성능** 확인 |
| 과적합의 **일반화 격차** | **L2 규제•조기 종료**•데이터 증강 | **분산** 감소 |
| 과소적합의 **높은 두 오차** | 특징•모델 용량 확대•규제 완화 | **편향** 감소 |
| 운영 **입력 분포 변화** | 성능•격차 감시와 재학습 | **적정 적합** 유지 |

#### 한줄 요약
- 훈련선과 검증선이 벌어지면 L2•조기 종료로 잡음 암기를 막고, 두 선이 함께 높으면 특징과 모델 용량을 늘린다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **규제 강화**: 과적합 모델의 자유도를 줄여 예측 분산과 일반화 격차를 낮추는 조정
- **용량 확대**: 과소적합 모델이 더 복잡한 핵심 패턴을 표현하도록 능력을 늘리는 조정

</details>

- 격차가 크면 **규제 강화**, 두 오차가 높으면 **용량 확대**

#### 한줄 요약

- 훈련•검증 오차의 간격이 크면 규제를 강화하고 둘 다 높으면 용량을 늘려, 검증 오차가 가장 낮은 복잡도에 맞춘다.
