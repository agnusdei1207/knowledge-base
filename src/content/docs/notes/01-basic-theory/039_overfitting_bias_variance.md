## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **과적합(Overfitting)**: 학습 데이터에 지나치게 적합되어 잡음(Noise)까지 학습함으로써 일반화 성능이 저하된 상태이다.
- **과소적합(Underfitting)**: 모델 복잡도가 낮아 데이터의 내재된 구조(Pattern)조차 학습하지 못해 예측력이 떨어지는 상태이다.
- **편향-분산 트레이드오프(Bias-Variance Tradeoff)**: 모델 복잡도에 따라 편향(Bias)과 분산(Variance)이 상충 관계를 갖는 통계적 특성이다.
- **일반화 성능(Generalization Performance)**: 학습에 사용하지 않은 신규 데이터(Unseen Data)에 대한 예측 성능이다.
- **훈련 오차(Training Error)**: 모델 적합에 사용한 데이터(Training Set)에서 계산한 예측 오차이다.
- **규제(Regularization)**: 가중치 제약이나 패널티 부여를 통해 모델 복잡도를 억제하여 과적합을 방지하는 기법이다.

</details>

- 정의: 학습 데이터(Training Set)와 검증 데이터(Validation Set)의 손실(Loss) 크기 및 차이(Generalization Gap)를 분석하여 모델의 적합 상태(Fitting Status)와 일반화 성능을 진단하고 최적화하는 체계이다.
- 배경: 학습 데이터에만 높은 성능을 보이는 현상은 잡음 학습에 기인할 가능성이 높으므로, 미지의 데이터에 대한 일반화 성능 확인 및 최적 모델 복잡도(Model Complexity) 산정이 필수적이다.

#### 한줄 요약

- 총 기대 오차 $E[(y - \hat{f}(x))^2] = \text{Bias}^2(\hat{f}(x)) + \text{Var}(\hat{f}(x)) + \sigma^2$ 분해식에 따라 일반화 격차 및 검증 손실 최소 지점을 탐색한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **편향(Bias)**: 모델의 예측 평균값이 실제 정답(Ground Truth)에서 벗어난 정도이다.
- **분산(Variance)**: 학습 표본(Dataset)의 변화에 따라 모델의 예측치가 흔들리는 정도이다.
- **검증 오차(Validation Error)**: 학습에 직접 사용하지 않은 검증셋에서 계산한 예측 오차이다.
- **모델 복잡도(Model Complexity)**: 모델이 표현할 수 있는 함수(Function)의 세밀함과 자유도이다.
- **일반화 격차(Generalization Gap)**: 검증 오차에서 훈련 오차를 뺀 성능 차이로, 과적합 정도를 측정하는 지표이다.

</details>

![모델 복잡도에 따른 훈련 오차와 검증 오차 차트](/study/diagrams/bias-variance-error.svg)

> 설명용 개념 좌표에서 파란 훈련 오차는 모델 복잡도가 커질수록 지속적으로 감소하지만, 빨간 검증 오차는 특정 복잡도에서 최소가 된 뒤 다시 증가한다.

- **모델 복잡도** 증가에 따라 **편향**은 줄어들고 **분산**은 커지는 상충 관계를 갖는다.
- 고편향의 **과소적합**과 고분산의 **과적합**을 구분하여 대응해야 한다.
- **검증 오차**가 최소가 되는 지점의 모델 복잡도를 최적 상태로 선택한다.

> **과적합**: 검증 오차 및 일반화 격차의 동반 상승

#### 한줄 요약

- 모델 용량(Capacity) 증가 시 고편향/과소적합에서 고분산/과적합으로 전이되며, 교차검증을 통한 최소 검증 오차 지점을 최적의 모델 복잡도로 선택한다.


## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **모델 용량(Model Capacity)**: 모델이 표현할 수 있는 함수 복잡도의 범위이다.
- **규제(Regularization)**: 가중치 크기나 학습 시간을 제한하여 모델의 과도한 복잡도를 억제하는 기법이다.
- **규제 강도(Regularization Strength)**: 모델 복잡도에 부과하는 제약이나 벌점의 크기이다.

</details>

```text
                  [오차 측정기]
                  /           \
       [학습 모델]             [적합 진단기]
                  \           /
                 [복잡도 조정기]
```

선의 의미: 학습 모델을 중심으로 오차 측정•적합 진단•복잡도 조정이 연결된 정적 의존 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 학습 모델(Learned Model) | 모델 용량(Model Capacity) 범위 내의 예측값 산출 |
| 오차 측정기(Error Measurer) | 훈련·검증 오차(Training/Validation Error) 계산 |
| 적합 진단기(Fit Diagnoser) | 오차 및 일반화 격차(Generalization Gap)로 상태 판정 |
| 복잡도 조정기(Complexity Adjuster) | 규제 강도(Regularization Strength) 및 용량 변경 |

#### 한줄 요약

- 오차 측정기와 진단기가 훈련•검증 차이를 판정하면, 조정기가 모델 용량이나 규제 강도를 수정하여 최적의 적합 상태를 유지한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **적합 상태(Fitting Status)**: 훈련•검증 오차의 상대적 크기에 따라 과소적합•적정 적합•과적합으로 구분한 학습 상태이다.
- **복잡도 조정값(Complexity Parameter)**: 모델 용량•규제 강도•학습 시간을 바꾸기 위해 전달하는 설정값이다.
- **적정 적합(Optimal Fitting)**: 검증 오차와 일반화 격차를 낮게 유지하여 모델 성능을 극대화한 상태이다.
- **학습 시간(Training Time)**: 모델 학습을 진행하는 반복(Iteration) 기간이다.

</details>

```text
[학습된 후보 모델]
          |
          v
1. 훈련•검증 오차 측정
          |
          v
2. 적합 상태 판정
          |
          +-- 두 오차가 높음 --> 3. 과소적합 조정 --+
          |                                        |
          +-- 일반화 격차 큼 --> 4. 과적합 조정 ---+
          |                                        |
          |                         [재학습] <------+
          |                             |
          |                             `----> 1로
          |
          `-- 검증 오차 낮음 --> 5. 적정 모델 선택
                                             |
                                             v
                                         [확정 모델]
```

### 동작 원리

- **1. 훈련•검증 오차 측정**: 두 표본군(Training/Validation Set)의 예측 오차를 계산한다.
- **2. 적합 상태 판정**: 오차의 절대 크기와 일반화 격차를 비교한다.
- **3. 과소적합 조정**: 모델 용량 확대 및 규제 완화 수행한다.
- **4. 과적합 조정**: 규제 강화, 조기 종료(Early Stopping), 데이터 증강 등을 수행한다.
- **5. 적정 모델 선택**: 검증 오차가 최소인 지점의 복잡도로 모델을 확정한다.

#### 한줄 요약

- 훈련 손실과 검증 손실의 괴리(Divergence)를 모니터링하여 조기 종료, 가중치 감쇄(Weight Decay), 드롭아웃(Dropout) 등의 조치를 취한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **오차 신호(Error Signal)**: 훈련•검증 오차의 크기와 간격으로 모델의 적합 상태를 구분하는 판단 기준이다.

</details>

| 적합 상태 | 오차 신호 | 진단 의미 |
|:---|:---|:---|
| 과소적합 | 훈련•검증 오차가 모두 높음 | 표현력이 부족한 **고편향** 상태 |
| 과적합 | 훈련 오차는 낮고 **일반화 격차**가 큼 | 표본 잡음에 민감한 **고분산** 상태 |
| 적정 적합 | 검증 오차가 낮고 격차가 통제됨 | **편향•분산 트레이드오프**의 균형 상태 |

> 요약: 두 오차의 높이와 간격으로 결정되는 **적합 상태**가 모델 최적화의 핵심이다.

#### 한줄 요약

- 고편향(High Bias) 시 모델 용량 증대/특성 공학(Feature Engineering)을 적용하고, 고분산(High Variance) 시 규제/데이터 증강/앙상블 기법을 채택한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **교차검증(Cross-Validation)**: 데이터를 여러 분할(Fold)로 나눠 학습•검증을 반복하고 성능을 평균하는 평가법이다.
- **L2 규제(L2 Regularization)**: 큰 가중치의 제곱합에 벌점을 부과하여 모델 복잡도를 줄이는 기법이다.
- **조기 종료(Early Stopping)**: 검증 오차가 다시 오르기 시작할 때 학습을 멈추는 기법이다.
- **데이터 증강(Data Augmentation)**: 의미를 보존하는 변환으로 학습 표본의 다양성을 늘리는 기법이다.
- **독립 검증셋(Hold-out Test Set)**: 모델 학습과 조정에 사용하지 않고 최종 일반화 성능 평가에만 쓰는 데이터이다.
- **재학습(Retraining)**: 운영 분포 변화(Data Drift)에 맞춰 새로운 데이터로 모델을 다시 학습하는 작업이다.
- **입력 분포 변화(Input Distribution Shift)**: 운영 데이터의 입력 범위와 빈도가 학습 데이터와 달라진 상태이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **훈련 오차**만으로 모델 선택 | 독립 검증셋•**교차검증** 사용 | **일반화 성능** 확인 |
| 과적합의 **일반화 격차** | **L2 규제•조기 종료**•데이터 증강 | **분산** 감소 |
| 과소적합의 높은 오차 | **모델 용량** 확대•**규제 강도** 완화 | **편향** 감소 |
| 운영 **입력 분포 변화** | 성능•격차 감시와 **재학습** | **적정 적합** 유지 |

#### 한줄 요약

- 검증 손실 곡선의 분기 발생 시 L2 규제, 조기 종료, 데이터 증강을 적용하고, 고편향 경향 시 모델 깊이 및 용량을 확장한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **규제 강화(Regularization Strengthening)**: 과적합 모델의 자유도를 줄여 예측 분산과 일반화 격차를 낮추는 조정이다.
- **용량 확대(Capacity Expansion)**: 과소적합 모델이 더 복잡한 핵심 패턴을 표현하도록 모델의 능력을 늘리는 조정이다.

</details>

- 일반화 격차가 크면 **규제 강화**를, 두 오차가 모두 높으면 **용량 확대**를 수행하는 것이 최적화의 핵심이다.

#### 한줄 요약

- 일반화 격차가 크면 규제를 강화하고, 두 오차가 모두 높으면 용량을 늘려 검증 오차 최소점을 선택한다.
