## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **해밍 코드(Hamming Code)**: 데이터 비트에 $2^k$ 위치의 다중 패리티 비트를 삽입하여 수신 측에서 신드롬(Syndrome) 벡터를 계산함으로써 단일 비트 오류 위치를 즉시 찾아 정정하는 전방 오류 정정(FEC) 선형 블록 부호.
- **신드롬(Syndrome Vector, $S$)**: 수신된 코드워드의 패리티 재검사 결과들을 이진수로 조합하여 손상된 비트의 1-기반 인덱스 위치를 지시하는 이진 벡터.
- **ECC(Error-Correcting Code)**: 재전송 요청 없이 수신단 자체에서 비트 오류를 감지 및 복원하는 신뢰성 제어 부호.

</details>

- 정의/개념: $2^k$ 위치에 패리티 검사 비트를 배치하고 신드롬 벡터 $S$를 통해 단일 비트 오류(1-bit Error) 위치를 계산하여 정정하는 **선형 블록 오류 정정 부호**
- 배경/필요성: DRAM 반도체의 방사선/알파 입자에 의한 소프트 에러(Soft Error)나 고속 버스 전송 중 발생하는 **단일 비트 반전을 재전송 없이 실시간 하드웨어 수준에서 복구 필수**

#### 한줄 요약

- 패리티 비트를 $2^k$ 위치에 배치하고 신드롬 벡터 $S$를 통해 단일 비트 오류 위치를 실시간 복구

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **최소 해밍 거리($d_{min}$)**: 유효한 코드워드들 간의 서로 다른 비트 위치 개수의 최솟값 ($d_{min} \ge 2t + 1$일 때 $t$개 오류 정정 가능).
- **SECDED(Single Error Correction, Double Error Detection)**: 해밍 코드 전체에 추가 1비트의 전역 패리티(Global Parity)를 부여하여 $d_{min}=4$를 확보함으로써 1비트 정정 및 2비트 검출을 동시 수행하는 표준 ECC 방식.

</details>

- 패리티 비트 위치($1, 2, 4, 8, \dots$)의 이진 신드롬 계산으로 **단일 오류 비트 위치 직접 산출**
- 최소 해밍 거리 $d_{min}=3$으로 **단일 비트 오류 정정(SEC)** 및 $d_{min}=4$ 확장을 통한 **SECDED 지원**
- 데이터 비트($d$)가 증가할수록 요구되는 패리티 비트($p$)의 비율이 로그 스케일로 감소하는 높은 부호율

$$
2^p \ge d + p + 1
$$

#### 한줄 요약

- 신드롬은 오류 위치를 지시하며, 전체 패리티를 추가한 SECDED는 최소 해밍 거리 4를 확보

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **패리티 그룹 매핑**: 각 패리티 비트 $P_k$($2^{k-1}$ 위치)는 이진수 표현의 $k$번째 비트가 1인 모든 코드워드 인덱스들의 배타적 논리합(XOR)을 담당.

</details>

```text
[ 해밍 (7, 4) 코드워드 비트 배치도 ]
비트 위치:   1    2    3    4    5    6    7
비트 종류: [ P1 | P2 | D1 | P4 | D2 | D3 | D4 ]
            └───┴────┴────┴────┴────┴────┴───┘
               P1: 1, 3, 5, 7 비트 검사 (XOR)
               P2: 2, 3, 6, 7 비트 검사 (XOR)
               P4: 4, 5, 6, 7 비트 검사 (XOR)
```

선의 의미: 데이터 비트(D)와 $2^k$ 위치의 패리티 비트(P) 간의 검사 그룹 매핑 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 해밍 부호기 (Encoder) | $2^p \ge d+p+1$ 수식 기반 **패리티 비트 계산 및 코드워드 합성** |
| 전송/저장 매체 (DRAM) | 채널 노이즈 및 방사선에 의해 **단일/다중 비트 반전 오류** 유입 |
| 신드롬 판정기 (Decoder) | 수신 비트의 패리티 재검사로 **오류 위치 인덱스 $S$ 계산** |
| 오류 정정기 (Corrector) | $S \neq 0$일 때 해당 위치 비트의 **XOR 반전 정정 수행** |

#### 한줄 요약

- 부호기가 패리티를 붙이고, 복호기와 신드롬 판정기가 매체에서 바뀐 비트의 위치를 찾아 원본을 복구

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **오류 비트 반전 정정**: 신드롬 $S = (s_3 s_2 s_1)_2$가 $6(110_2)$으로 계산되면 6번째 비트 $b_6$를 $b_6 \oplus 1$로 반전하여 원래 비트로 복원하는 동작.

</details>

```text
원본 데이터 d 비트 입력
   │
   ▼
[ 1. 패리티 비트 수 p 및 2^k 위치 결정 (2^p ≥ d+p+1) ]
   │
   ▼
[ 2. 패리티 그룹 XOR 연산 및 코드워드(d+p) 생성 ]
   │
   ▼
[ 전송 및 메모리 저장 채널 통과 (노이즈 유입) ]
   │
   ▼
[ 3. 수신 코드워드 기반 신드롬 벡터 S = (Sp ... S1) 계산 ]
├─ S = 0 ⟹ [ 무오류: 원본 데이터 즉시 추출 ]
└─ S ≠ 0 ⟹ [ 오류 감지 ]
   │
   ▼
[ 4. S 가 지시하는 비트 위치 반전 정정 (b_S = b_S ⊕ 1) ]
   │
   ▼
오류 정정 완료된 순수 원본 데이터 d 비트 출력
```

**동작 원리**

1. **패리티 수 결정**: $2^p \ge d+p+1$ 부등식을 만족하는 최소 정수 $p$ 산출
2. **코드워드 생성**: $1, 2, 4, 8, \dots$ 자리에 패리티 비트를 두고 각 패리티 그룹의 짝수 패리티(XOR)를 계산하여 삽입
3. **신드롬 계산**: 수신 측에서 각 패리티 그룹을 다시 XOR하여 신드롬 비트 $S_k$ 도출
4. **비트 반전 정정**: $S$의 10진수 값이 가리키는 비트 위치를 반전하여 원본 데이터 추출

#### 한줄 요약

- 2^p >= d+p+1 식에 따라 패리티를 생성하고, 수신 측에서 신드롬 S가 가리키는 비트를 반전 정정

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **ECC 부호 비교**:
  - SEC (Single Error Correction): $d_{min}=3$, 1비트 정정, 2비트 오류 시 엉뚱한 비트를 뒤집는 오정정(Miscorrection) 위험.
  - SECDED: $d_{min}=4$, 전체 패리티 1비트 추가, 1비트 정정 + 2비트 검출, 서버 메모리 표준.
  - CRC: 생성 다항식 나눗셈, 버스트 오류 검출 특화, 정정 불가(재전송 필요).

</details>

| 비교 항목 | 해밍 코드 (SEC) | 확장 해밍 (SECDED) | CRC (Cyclic Redundancy) |
|:---|:---|:---|:---|
| 최소 해밍 거리 | **$d_{min} = 3$** | **$d_{min} = 4$** | 다항식 차수에 종속 |
| 핵심 기능 | **단일 비트 오류 정정(SEC)** | **1비트 정정 + 2비트 검출** | **버스트 오류 검출(Detection Only)** |
| 2비트 오류 시 | **오정정(Miscorrection) 발생** | **이중 오류 정확 검출 및 패닉** | 오류 감지 후 재전송(ARQ) 요청 |
| 주요 적용처 | 소형 마이크로컨트롤러 | **엔터프라이즈 서버 DRAM ECC** | 네트워크 패킷(Ethernet, Wi-Fi) |

#### 한줄 요약

- 단일 오류 정정은 SEC, 이중 오류 검출은 SECDED, 재전송 구간은 CRC를 선택

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **메모리 스크러빙(Memory Scrubbing)**: DRAM 백그라운드 컨트롤러가 주기적으로 메모리 전체를 읽어 1비트 잠복 오류(Latent Error)를 정정하여 2비트 회복 불가능 오류(UCE)로 발전하는 것을 차단하는 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| SEC 단독 적용 시 **2비트 오류를 1비트로 오정정** | 전체 패리티 1비트를 추가한 **SECDED 회로** 적용 | 오정정 차단 및 시스템 크래시 방지 |
| 메모리에 장시간 방치된 **1비트 잠복 오류(Latent Error)** | 주기적 백그라운드 **메모리 스크러빙(Scrubbing)** | 다중 비트 UCE 고장 사전 예방 |
| 인접 셀 간 물리적 방사선 타격에 의한 **버스트 에러** | 비트라인 물리적 **인터리빙(Bit Interleaving)** 분산 | 다비트 에러를 다수 단일 에러로 격리 |
| 버스 폭 확장에 따른 패리티 비트 수 부족 | $2^p \ge d+p+1$ 검증 및 표준 64/72 ECC 워드 채택 | 정합성 있는 신드롬 디코딩 보장 |

#### 한줄 요약

- SECDED로 1비트 정정 후 검증 패리티로 오정정을 차단하고, 메모리 스크러빙으로 잠복 오류를 제거하며, 버스트 에러는 비트 인터리빙으로 분산시킨다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **고신뢰성 컴퓨팅의 핵심**: 현대 서버용 DDR5/HBM 메모리는 칩 내부의 On-Die ECC와 시스템 레벨의 Side-band SECDED ECC를 이중 적용하여 극도의 신뢰성(RAS)을 달성.

</details>

- 즉각적 하드웨어 비트 정정은 **SECDED 해밍 코드**, 대용량 패킷 무결성 검증은 **CRC** 선택

#### 한줄 요약

- 즉시 단일 비트 정정은 SEC•SECDED, 재전송 가능한 통신 구간은 CRC를 선택
