## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **신드롬 벡터(Syndrome Vector)**: 수신된 코드워드의 패리티 재검사 결과를 이진수로 조합하여 오류가 발생한 비트 위치를 즉시 가리키는 검사 벡터.
- **소프트 에러(Soft Error)**: 하드웨어의 영구적 물리 파괴가 아닌 우주 방사선이나 노이즈에 의해 메모리 셀 비트가 일시 반전되는 가역적 오류.

</details>

- 정의/개념: $2^k$ 위치에 다중 패리티 비트를 삽입하고 **신드롬 벡터**를 통해 단일 비트 오류를 실시간 복원하는 전방 오류 정정(FEC) 부호화 기술
- 배경/필요성: 고집적 반도체 소자에서 우주선 및 전자기 노이즈로 인한 비트 반전(Bit-flip) 발생 시 재전송(ARQ) 지연을 허용하지 않는 실시간성 보장의 한계

#### 한줄 요약

- 왕복 재전송을 없앤 대가로 저장 용량 일부를 패리티에 상시 내주며, 그 비율이 정정 가능한 오류 수의 상한을 정한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **최소 해밍 거리($d_{min}$)**: 유효한 코드워드들 간의 서로 다른 비트 위치 개수의 최솟값 ($d_{min} \ge 2t + 1$일 때 $t$개 오류 정정 가능).
- **SECDED(Single Error Correction, Double Error Detection)**: 해밍 코드 전체에 추가 1비트의 전역 패리티(Global Parity)를 부여하여 $d_{min}=4$를 확보함으로써 1비트 정정 및 2비트 검출을 동시 수행하는 표준 ECC 방식.

</details>

- 이진 신드롬 계산으로 **단일 오류 비트 위치 직접 산출**
- **최소 해밍 거리** $d_{min}=3$으로 단일 비트 정정 및 **SECDED 지원**
- 데이터 증가 시 패리티 비율이 로그 스케일로 감소하는 **높은 부호율**

$$
2^p \ge d + p + 1
$$

#### 한줄 요약

- 신드롬은 오류 위치를 지시하며, 전체 패리티를 추가한 SECDED는 최소 해밍 거리 4를 확보한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **패리티 그룹 매핑**: 각 패리티 비트 $P_k$($2^{k-1}$ 위치)는 이진수 표현의 $k$번째 비트가 1인 모든 코드워드 인덱스들의 배타적 논리합(XOR)을 담당.

</details>

```text
+-------------------------------------------------------------------------------+
|                       해밍 (7, 4) 코드워드 비트 구조 레이아웃                 |
+-------+-------+-------+-------+-------+-------+-------+-----------------------+
| Bit 1 | Bit 2 | Bit 3 | Bit 4 | Bit 5 | Bit 6 | Bit 7 |      패리티 검사 그룹 |
|   P1  |   P2  |   D1  |   P4  |   D2  |   D3  |   D4  |  - P1: 1, 3, 5, 7     |
| [2^0] | [2^1] | [Data]| [2^2] | [Data]| [Data]| [Data]|  - P2: 2, 3, 6, 7     |
| (XOR) | (XOR) |  (D1) | (XOR) |  (D2) |  (D3) |  (D4) |  - P4: 4, 5, 6, 7     |
+-------+-------+-------+-------+-------+-------+-------+-----------------------+
```

선의 의미: 실선 박스는 해밍 코드워드 비트 레이아웃, 구분선은 패리티 비트(2^k 위치)와 데이터 비트 배치 경계

| 구성요소 | 책임 |
|:---|:---|
| 해밍 부호기 (Encoder) | $2^p \ge d+p+1$ 수식 기반 패리티 비트 계산 및 코드워드 합성 |
| 전송/저장 매체 (DRAM) | 채널 노이즈 및 방사선에 의해 단일·다중 비트 반전 오류 유입 |
| 신드롬 판정기 (Decoder) | 수신 비트의 패리티 재검사로 **오류 위치 인덱스 $S$ 계산** |
| 오류 정정기 (Corrector) | $S \neq 0$일 때 해당 위치 비트의 **XOR 반전 정정 수행** |

#### 한줄 요약

- 부호기가 패리티를 붙이고, 복호기와 신드롬 판정기가 매체에서 바뀐 비트의 위치를 찾아 원본을 복구한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **오류 비트 반전 정정**: 신드롬 $S = (s_3 s_2 s_1)_2$가 $6(110_2)$으로 계산되면 6번째 비트 $b_6$를 $b_6 \oplus 1$로 반전하여 원래 비트로 복원하는 동작.

</details>

```text
+------------------------------------------+
|  원본 데이터 d 비트 입력 (예: 4-bit)     |
+--------------------+---------------------+
                     |
                     v
+------------------------------------------+
|  1. 패리티 비트 수 p 산출 (2^p >= d+p+1) |
+--------------------+---------------------+
                     |
                     v
+------------------------------------------+
|  2. 패리티 비트 계산 및 코드워드 합성    |
+--------------------+---------------------+
                     |
                     v
+------------------------------------------+
|  채널/DRAM 통과 (노이즈로 인한 비트 반전) |
+--------------------+---------------------+
                     |
                     v
+------------------------------------------+
|  3. 신드롬 벡터 계산: S = (Sp, ... S1)   |
+--------------------+---------------------+
                     |
                     v
           /--------------------\
          <    신드롬 S = 0?    >
           \--------------------/
            |                  |
      Yes   |                  | No (S != 0)
            v                  v
[ 무오류: 데이터 추출 ]      [ 오류 비트 반전: b_S = b_S ⊕ 1 ]
                               |
                               v
                     [ 4. 정정된 원본 데이터 반환 ]
```

분기 결과: 계산된 신드롬 벡터 $S=0$이면 전송 오류가 없는 정상 데이터로 판정하여 즉시 반환하고, $S \neq 0$이면 $S$의 이진수 값이 가리키는 특정 위치의 비트를 반전($\oplus 1$)하여 단일 오류를 즉시 정정한다.

**동작 원리**:
1. **패리티 비트 수 산출**: 부호화하려는 원본 데이터 $d$비트에 대해 부등식 $2^p \ge d + p + 1$을 만족하는 최소 패리티 비트 개수 $p$를 결정한다.
2. **패리티 및 데이터 비트 배치**: 생성할 코드워드의 $2^{k-1}$ 위치(1, 2, 4, 8, ...)에 패리티 비트를 할당하고, 나머지 위치에 데이터 비트를 순차 매핑한다.
3. **패리티 그룹 XOR 연산**: 각 패리티 비트 $P_k$가 담당하는 비트 인덱스(이진 표현에서 $k$번째 비트가 1인 위치들)를 짝수 패리티(Even Parity) 조건에 따라 XOR 연산하여 합성한다.
4. **수신 신드롬 벡터 판별**: 수신 측에서 동일한 패리티 그룹 검사를 수행하여 신드롬 벡터 $S = (S_p \dots S_1)_2$를 산출하고, $S=0$ 여부로 오류 유무를 판별한다.
5. **오류 비트 위치 정정**: 신드롬 $S \neq 0$인 경우 $S$의 이진수 값이 직접 오류 비트의 인덱스를 가리키므로, 해당 위치의 비트를 XOR 반전($b_S \gets b_S \oplus 1$)하여 원본 데이터를 완벽 복원한다.

#### 한줄 요약

- 2^p >= d+p+1 식에 따라 패리티를 생성하고, 수신 측에서 신드롬 S가 가리키는 비트를 반전 정정한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **단일 오류 정정(Single Error Correction, SEC)**: 최소 해밍 거리 $d_{min}=3$으로 1비트 오류를 정정하지만 2비트 오류 시 오정정하는 방식.
- **SECDED(Single Error Correction Double Error Detection)**: 전체 패리티 1비트를 추가해 $d_{min}=4$를 확보하여 1비트 정정 및 2비트 검출을 수행하는 서버 메모리 표준.
- **순환 중복 검사(Cyclic Redundancy Check, CRC)**: 생성 다항식 모듈러 나눗셈으로 버스트 오류를 검출하는 네트워크·스토리지 표준 방식.

</details>

| 오류 제어 방식 | 해밍 코드 (SEC) | 확장 해밍 (SECDED) | CRC (Cyclic Redundancy) |
|:---|:---|:---|:---|
| 적용 기준 | 소형 마이크로컨트롤러 메모리 | **서버 DRAM ECC** 및 고신뢰 메모리 | 네트워크 패킷 및 스토리지 블록 전송 |
| 핵심 특징 | $d_{min} = 3$ 기반 **단일 비트 정정** | $d_{min} = 4$ 기반 **1비트 정정+2비트 검출** | 생성 다항식 나눗셈 기반 **버스트 검출** |
| 한계 | 2비트 오류 시 **오정정 발생** | 3비트 이상 다중 오류 시 오정정 위험 | 오류 정정 불가 (**재전송 필수**) |

#### 한줄 요약

- 단일 오류 정정은 SEC, 이중 오류 검출은 SECDED, 재전송 구간은 CRC를 선택한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **메모리 스크러빙(Memory Scrubbing)**: DRAM 백그라운드 컨트롤러가 주기적으로 메모리 전체를 읽어 1비트 잠복 오류(Latent Error)를 정정하여 2비트 회복 불가능 오류(UCE)로 발전하는 것을 차단하는 기법.
- **비트 인터리빙(Bit Interleaving)**: 물리적으로 인접한 메모리 셀들을 서로 다른 ECC 코드워드에 분산 배치하여 단일 방사선 타격에 의한 버스트 오류를 다수의 1비트 오류로 격리하는 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| SEC 단독 적용 시 **2비트 오류를 1비트로 오정정** | 전체 패리티 1비트를 추가한 **SECDED 회로** 적용 | 오정정 차단 및 시스템 크래시 방지 |
| 메모리에 장시간 방치된 **1비트 잠복 오류** | 주기적 백그라운드 **메모리 스크러빙** | 다중 비트 UCE 고장 사전 예방 |
| 인접 셀 간 물리적 방사선 타격에 의한 **버스트 에러** | 비트라인 물리적 **비트 인터리빙** 분산 | 다비트 에러를 다수 단일 에러로 격리 |
| 버스 폭 확장에 따른 패리티 비트 수 부족 | $2^p \ge d+p+1$ 검증 및 표준 64/72 ECC 워드 채택 | 정합성 있는 신드롬 디코딩 보장 |

#### 한줄 요약

- SECDED로 1비트 정정 후 검증 패리티로 오정정을 차단하고, 메모리 스크러빙으로 잠복 오류를 제거하며, 버스트 에러는 비트 인터리빙으로 분산시킨다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **고신뢰성 컴퓨팅의 핵심**: 현대 서버용 DDR5/HBM 메모리는 칩 내부의 On-Die ECC와 시스템 레벨의 Side-band SECDED ECC를 이중 적용하여 극도의 신뢰성(RAS)을 달성.

</details>

- 서버 DRAM ECC(SECDED) 및 항공/우주 고신뢰성 메모리의 표준 전방 오류 정정(FEC) 기법으로 정립되어 널리 활용되고 있으며, 향후 초고집적 DDR5 및 HBM4 메모리의 온다이(On-Die) ECC와 링크 레벨 ECC를 결합한 2계층 다중 보호 구조로 확장될 것으로 전망되고, 실무 엔지니어링에서는 2비트 오류의 오정정을 원천 방지하기 위해 전역 패리티를 추가한 SECDED 회로를 필수 채택하고, 주기적 메모리 스크러빙(Memory Scrubbing)과 비트 인터리빙을 결합하여 잠복 오류와 버스트 에러를 격리해야 한다.

#### 한줄 요약

- 즉시 단일 비트 정정은 SEC•SECDED, 재전송 가능한 통신 구간은 CRC를 선택한다.
