## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **순환 신경망(RNN, Recurrent Neural Network)**: 이전 시점의 은닉 상태(Hidden State, $h_{t-1}$)를 현재 시점의 입력($x_t$)과 결합하여 순서 문맥(Sequential Context)을 재귀적으로 학습하는 신경망.
- **은닉 상태(Hidden State, $h_t$)**: 이전 모든 시점까지의 입력 이력을 요약하여 보존하는 순환 신경망의 단기 메모리 벡터.
- **장기 의존성(Long-Term Dependency)**: 시퀀스의 과거 정보가 먼 미래 시점의 출력 결정에 영향을 미치는 시간적 상관관계.

</details>

- 정의/개념: 시간축 **가중치 공유**와 은닉 상태 전달로 가변 길이 데이터를 처리하는 시퀀스 신경망
- 배경/필요성: 고정 길이 입력 기반 피드포워드 신경망에서 발생하는 가변 길이 시계열 처리 불가 및 **시간적 문맥(Temporal Context) 소실 한계**

#### 한줄 요약

- 과거를 고정 크기 상태 하나로 압축한 대가로 시점을 순차로만 처리할 수 있어, 병렬화 불가라는 비용이 구조에 따라붙는다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **BPTT(Backpropagation Through Time)**: 시퀀스 시간축을 따라 언롤(Unroll)하여 오차 기울기를 과거 시점 방향으로 누적 전파하는 역전파 알고리즘.
- **기울기 소실 및 폭주(Vanishing & Exploding Gradient)**: 시간축 가중치 행렬 $W_{hh}$의 연속 행렬곱($W_{hh}^T$)으로 인해 고유값 크기에 따라 역전파 기울기가 0으로 소멸하거나 무한 발산하는 현상.

</details>

- 시간축 전 구간에 걸친 **동일 파라미터 가중치 공유(Weight Sharing) 및 가변 길이 처리**
- 기본 RNN의 장기 의존성 학습 한계를 극복하는 **LSTM/GRU의 게이트(Gate) 제어 메커니즘**
- 시간축 순차 처리로 인한 **병렬화 불가능(Sequential Bottleneck) 및 훈련 속도 제약**

#### 한줄 요약

- 시간축 가중치 공유로 가변 시퀀스를 처리하되, BPTT 기울기 소실을 게이트 구조로 극복

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **망각 게이트(Forget Gate, $f_t$)**: 이전 셀 상태 $C_{t-1}$에서 폐기할 정보의 비율을 결정하는 게이트.
- **입력 게이트(Input Gate, $i_t$)**: 신규 후보 정보 $\tilde{C}_t$ 중 셀 상태에 반영할 비율을 결정하는 게이트.
- **출력 게이트(Output Gate, $o_t$)**: 갱신된 셀 상태 $C_t$로부터 차기 은닉 상태 $h_t$로 내보낼 정보량을 조절하는 게이트.
- **셀 상태(Cell State, $C_t$)**: 가산(Additive) 선형 통로를 통해 기울기 소실 없이 시퀀스 전체에 걸쳐 장기 기억을 보존하는 메모리 경로.

</details>

```text
[LSTM 순환 셀(Cell) 아키텍처]
  │
  ├─ [시계열 신호 결합부] (입력 및 이전 문맥)
  │     ├─ 현재 입력 벡터 x_t (현재 시점 특성 수신)
  │     └─ 이전 은닉 상태 h_(t-1) (단기 문맥 피드백 결합)
  │
  ├─ [게이트 제어 계층] (정보 흐름 선별)
  │     ├─ 망각 게이트 f_t (과거 기억 C_(t-1) 폐기율 결정)
  │     ├─ 입력 게이트 i_t (신규 후보 C_tilde_t 주입율 결정)
  │     └─ 출력 게이트 o_t (차기 은닉 상태 방출율 결정)
  │
  └─ [메모리 상태 갱신부] (장단기 기억 관리)
        ├─ 셀 상태 통로 (C_t 선형 가산 장기 기억 보존)
        └─ 은닉 상태 도출 (h_t = o_t · tanh(C_t) 단기 출력)
```

- 선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 셀 상태 ($C_t$) | 가산 경로로 **장기 문맥** 보존 |
| 게이트 제어기 | 시그모이드로 정보의 **보존·주입·방출** 비율 통제 |
| 은닉 상태 ($h_t$) | 현재 출력과 차기 시점의 **단기 문맥** 전달 |

#### 한줄 요약

- 순환 셀이 현재 입력과 이전 은닉 상태를 결합해 다음 문맥과 출력을 생성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **절단된 시간역전파(TBPTT, Truncated BPTT)**: 무한히 긴 시퀀스를 $k$개 스텝 단위로 잘라 역전파를 수행함으로써 메모리 폭증과 학습 불안정을 억제하는 기법.

</details>

```text
시퀀스 데이터 입력 (X = [x1, x2, .., xT])
   |
   v
[ 1. 은닉 상태 및 셀 상태 초기화 ] : h0 = 0, C0 = 0
   |
   v
[ 2. 시계열 순환 루프 (t = 1 to T) ]
   |
   +---> 망각 게이트 연산 : f_t = σ(W_f · [h_(t-1), x_t] + b_f)
   |
   +---> 입력 게이트 및 후보 갱신 : i_t = σ(...), C_tilde_t = tanh(...)
   |
   +---> 셀 상태 가산 선형 갱신 : C_t = f_t * C_(t-1) + i_t * C_tilde_t
   |
   +---> 출력 게이트 및 은닉 상태 산출 : o_t = σ(...), h_t = o_t * tanh(C_t)
   |
   v
[ 3. 최종 출력 시퀀스 반환 ] : 최종 은닉 상태 h_T 또는 출력 Y 반환
```

분기 결과: 매 타임스텝 t마다 망각 게이트가 과거 셀 상태의 보존 비율을 결정하고, 입력 게이트가 신규 정보 주입 비율을 결정하여 셀 상태를 갱신한 뒤 차기 시점으로 분기 순환한다.

**동작 원리**:
1. **은닉 상태 및 셀 상태 초기화**: 첫 타임스텝 시작 전 은닉 상태 벡터 $h_0$와 장기 기억 셀 상태 벡터 $C_0$를 0으로 초기화한다.
2. **망각 게이트 연산**: 이전 은닉 상태 $h_{t-1}$와 현재 입력 $x_t$를 결합하여 과거 정보 중 삭제할 비율 $f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f)$를 결정한다.
3. **입력 게이트 및 후보 셀 상태 생성**: 현재 입력 중 보존할 정보 비율 $i_t$와 새로운 후보 셀 상태 $\tilde{C}_t = \tanh(W_c \cdot [h_{t-1}, x_t] + b_c)$를 생성한다.
4. **셀 상태 가산 갱신**: 과거 기억을 보존 비율만큼 축소하고 새 후보를 더하는 선형 가산 통로 $C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$로 장기 기울기 소실을 방지한다.
5. **출력 게이트 및 은닉 상태 산출**: 출력 게이트 $o_t$로 필터링하고 $h_t = o_t \odot \tanh(C_t)$를 계산하여 현재 출력 및 차기 시점 은닉 상태로 전달한다.

#### 한줄 요약

- 매 시점 순환 셀이 현재 입력과 이전 기억을 결합하고, 게이트로 남길 문맥을 조절

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **기본 순환신경망(Vanilla RNN)**: 게이트 없이 은닉 상태를 단순 활성화 함수로 재귀 갱신하는 모델.
- **장단기 메모리(LSTM)**: 망각·입력·출력 3대 게이트와 셀 상태를 도입하여 장기 의존성을 보존하는 모델.
- **게이트 순환 유닛(GRU)**: 셀 상태를 생략하고 리셋·업데이트 2개 게이트로 경량화한 모델.

</details>

| 순환 신경망 | 기본 RNN | LSTM | GRU |
|:---|:---|:---|:---|
| 적용 기준 | 10스텝 미만 단기 패턴 분석 시 | 100스텝 이상 장기 문맥 보존 시 | 연산 자원 제약 환경 실시간 추론 시 |
| 핵심 특징 | 게이트 없는 **은닉 상태** 갱신 | 셀 상태와 **3개 게이트** 결합 | 단일 상태와 **2개 게이트** 결합 |
| 한계 | **기울기 소실**로 장기 문맥 학습 제약 | 게이트 증가로 연산량·메모리 증가 | LSTM보다 상태 제어 표현력 제한 |

#### 한줄 요약

- 단순 단기 시계열은 기본 RNN, 장기 기억은 LSTM, 연산량과 메모리 절충은 GRU를 적용

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **양방향 RNN(Bi-directional RNN)**: 과거 시점($t=1 \to T$)과 미래 시점($t=T \to 1$)의 은닉 상태를 모두 계산하여 결합($[h_f, h_b]$)함으로써 문장 전체의 전후 문맥을 동시 파악하는 구조.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 긴 시계열 역전파 시 **기울기 폭주(Exploding Gradient)** | `clip_grad_norm_` 기반 **기울기 클리핑** 적용 | 역전파 발산(`NaN`) 방지 |
| 극단적으로 긴 시퀀스로 인한 **GPU 메모리 고갈** | 시퀀스를 일정 길이로 자르는 **TBPTT(Truncated BPTT)** | 일정한 메모리 점유 및 안정적 학습 |
| 독립된 세션/장비 간의 **은닉 상태 오염(State Leakage)** | 새 시퀀스 시작 시 `detach()` 및 **상태 명시적 초기화** | 세션 간 상태 격리 보장 |
| 순차 처리 병목으로 인한 **훈련 시간 과다** | **트랜스포머(Self-Attention)** 또는 GRU 전환 | 병렬 연산 및 학습 처리량 극대화 |

#### 한줄 요약

- 기울기 폭주는 클리핑으로 방지하고, 긴 시퀀스는 TBPTT로 메모리를 제어하며, 세션 경계에서 상태를 초기화하고, 병렬 처리가 필요하면 트랜스포머로 전환한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **시퀀스 모델링 진화 계보**: Vanilla RNN $\to$ LSTM/GRU (게이트 도입) $\to$ Transformer (Self-Attention 완전 병렬화)로 발전하였으나, 초저지연 센서 스트리밍에는 여전히 경량 GRU/LSTM이 활발히 사용.

</details>

- 시계열 예측, 음성 인식 및 자연어 처리의 **기초 시퀀스 딥러닝 아키텍처**로 자리잡았으며, 자연어 분야에서는 Transformer/Mamba(SSM)로 대체 발전했으나 실무 엣지/IoT 시계열 센서 스트리밍 분야에서는 **경량화된 LSTM/GRU 셀과 Truncated BPTT, 기울기 클리핑(Gradient Clipping)**을 결합하여 저지연 시계열 모델링을 실현

#### 한줄 요약

- 단기 의존성은 RNN, 장기 기억은 LSTM, 장기 문맥과 메모리 절충은 GRU를 선택
