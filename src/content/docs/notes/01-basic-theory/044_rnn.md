## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **순환 신경망(RNN, Recurrent Neural Network)**: 이전 시점의 은닉 상태(Hidden State, $h_{t-1}$)를 현재 시점의 입력($x_t$)과 결합하여 순서 문맥(Sequential Context)을 재귀적으로 학습하는 신경망.
- **은닉 상태(Hidden State, $h_t$)**: 이전 모든 시점까지의 입력 이력을 요약하여 보존하는 순환 신경망의 단기 메모리 벡터.
- **장기 의존성(Long-Term Dependency)**: 시퀀스의 과거 정보가 먼 미래 시점의 출력 결정에 영향을 미치는 시간적 상관관계.

</details>

- 정의/개념: 시간축 가중치 공유를 통해 시계열/텍스트 등 가변 길이 시퀀스 데이터를 순차 처리하며 이전 은닉 상태를 재귀 전달하는 **시퀀스 모델링 심층 신경망**
- 배경/필요성: 독립 표본 전제 모델의 시계열 처리 한계 및 기본 RNN의 BPTT 시 발생하는 기울기 소실·폭주 극복 필요

#### 한줄 요약

- 이전 은닉 상태를 현재 입력과 결합하여 순서 문맥을 순차적으로 전달하는 시퀀스 모델링

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **BPTT(Backpropagation Through Time)**: 시퀀스 시간축을 따라 언롤(Unroll)하여 오차 기울기를 과거 시점 방향으로 누적 전파하는 역전파 알고리즘.
- **기울기 소실 및 폭주(Vanishing & Exploding Gradient)**: 시간축 가중치 행렬 $W_{hh}$의 연속 행렬곱($W_{hh}^T$)으로 인해 고유값 크기에 따라 역전파 기울기가 0으로 소멸하거나 무한 발산하는 현상.

</details>

- 시간축 전 구간에 걸친 **동일 파라미터 가중치 공유(Weight Sharing) 및 가변 길이 처리**
- 기본 RNN의 장기 의존성 학습 한계를 극복하는 **LSTM/GRU의 게이트(Gate) 제어 메커니즘**
- 시간축 순차 처리로 인한 **병렬화 불가능(Sequential Bottleneck) 및 훈련 속도 제약** #### 한줄 요약

- 시간축 가중치 공유로 가변 시퀀스를 처리하되, BPTT 기울기 소실을 게이트 구조로 극복

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **LSTM 3대 게이트 및 셀 상태**:
  - 망각 게이트 ($f_t$): 이전 셀 상태 $C_{t-1}$의 폐기 비율 결정.
  - 입력 게이트 ($i_t$): 신규 정보 $\tilde{C}_t$의 반영 비율 결정.
  - 출력 게이트 ($o_t$): 갱신된 $C_t$로부터 차기 은닉 상태 $h_t$ 도출.
  - 셀 상태 ($C_t$): 가산(Additive) 선형 통로로 기울기 소실 없이 장기 기억 보존.

</details>

```text
[ LSTM 순환 셀 내부 게이트 아키텍처 ]
                   이전 셀 상태 C_(t-1) ───────────(×)────────(+)────────► 현재 셀 상태 C_t
                                                    │          │
                                   망각 게이트 f_t ─┘          │ 신규 후보 C_tilde
                                                               │ (×) ◄── 입력 게이트 i_t
 이전 은닉 상태 h_(t-1) ──┐                                    │
                          ├─► [ f_t / i_t / C_tilde / o_t ] ───┘
 현재 시점 입력 x_t ──────┘                                    │
                                                               ▼
                                       출력 게이트 o_t ──► (×) tanh(C_t) ──► 현재 은닉 상태 h_t
```

선의 의미: 선형 셀 상태($C$) 통로와 망각($f$), 입력($i$), 출력($o$) 게이트 제어 신호 간의 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 시점 입력 ($x_t$) | 현재 타임스텝의 **토큰/센서 시계열 데이터 공급** |
| 셀 상태 ($C_t$) | 가산 연산으로 **기울기 소실 없이 장기 기억(Long-term) 보존** |
| 게이트 제어기 | Sigmoid($0 \sim 1$) 활성화로 **정보의 보존, 주입, 방출 비율 통제** |
| 은닉 상태 ($h_t$) | 현재 시점 출력 생성 및 **차기 시점으로 단기 문맥 전달** |

#### 한줄 요약

- 순환 셀이 현재 입력과 이전 은닉 상태를 결합해 다음 문맥과 출력을 생성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **TBPTT(Truncated BPTT)**: 무한히 긴 시퀀스를 $k$개 스텝 단위로 잘라 역전파를 수행함으로써 메모리 폭증과 학습 불안정을 억제하는 기법.

</details>

```text
시퀀스 데이터 입력 (X = [x1, x2,.., xT])
   │
   ▼
[ 1. 초기 은닉 상태 h0 및 셀 상태 C0 초기화 ]
   │
   ▼
[ 2. 시점 루프 (t = 1 to T) ]
   ├─► [ 2-1. 망각 게이트 f_t = σ(W_f · [h_(t-1), x_t] + b_f) 계산 ]
   │   [ 2-2. 입력 게이트 i_t = σ(W_i · [h_(t-1), x_t] + b_i) 및 후보 C_tilde 계산 ]
   │   [ 2-3. 셀 상태 가산 갱신: C_t = f_t ⊙ C_(t-1) + i_t ⊙ C_tilde ]
   │   [ 2-4. 출력 게이트 o_t = σ(W_o · [h_(t-1), x_t] + b_o) 계산 ]
   │   [ 2-5. 차기 은닉 상태 도출: h_t = o_t ⊙ tanh(C_t) ]
   │
   ▼
[ 3. 최종 출력 시퀀스 Y = [y1,.., yT] 또는 마지막 은닉 상태 hT 반환 ]
```

**동작 원리** 1. **상태 초기화**: 초기 은닉 상태 $h_0$와 셀 상태 $C_0$를 0으로 설정
2. **망각 제어**: 이전 기억 $C_{t-1}$에서 버릴 비율을 망각 게이트 $f_t$로 결정
3. **기억 주입**: 신규 정보 $\tilde{C}_t$에 입력 게이트 $i_t$를 곱해 셀 상태에 선형 가산
4. **출력 도출**: 출력 게이트 $o_t$를 통해 최종 활성화된 은닉 상태 $h_t$를 생성
5. **시점 반복**: 시퀀스 끝까지 순환 갱신 후 최종 분류 로짓 또는 예측 시계열 반환

#### 한줄 요약

- 매 시점 순환 셀이 현재 입력과 이전 기억을 결합하고, 게이트로 남길 문맥을 조절

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **순환 신경망 3종 비교**:
  - 기본 RNN: $h_t = \tanh(W x_t + U h_{t-1})$, 게이트 없음, 장기 기억 불가.
  - LSTM: 3개 게이트(Forget, Input, Output) + Cell State, 장기 의존성 최강.
  - GRU: 2개 게이트(Reset, Update), Cell State 생략, 파라미터 25% 절감 및 고속.

</details>

| 비교 항목 | 기본 RNN (Vanilla) | LSTM (Long Short-Term) | GRU (Gated Recurrent) |
|:---|:---|:---|:---|
| 게이트 구성 | 게이트 없음 | **3개 (Forget, Input, Output)** | **2개 (Reset, Update)** |
| 내부 상태 | 단일 은닉 상태 ($h_t$) | **은닉 상태($h_t$) + 셀 상태($C_t$)** | 단일 은닉 상태 ($h_t$) |
| 파라미터 수 | $1 \times (D \cdot H + H^2)$ | **$4 \times (D \cdot H + H^2)$ (가장 무거움)** | **$3 \times (D \cdot H + H^2)$ (경량)** |
| 장기 기억력 | 극히 취약 (10스텝 미만) | **매우 우수 (수백 스텝 보존)** | **우수 (LSTM과 유사 성능)** |
| 주요 적용처 | 단순 초단기 시계열 | 음성 인식, 기계 번역, 복잡 시계열 | 엣지 디바이스 시계열, 고속 NLP |

#### 한줄 요약

- 단순 단기 시계열은 기본 RNN, 장기 기억은 LSTM, 연산량과 메모리 절충은 GRU를 적용

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **양방향 RNN(Bi-directional RNN)**: 과거 시점($t=1 \to T$)과 미래 시점($t=T \to 1$)의 은닉 상태를 모두 계산하여 결합($[h_f, h_b]$)함으로써 문장 전체의 전후 문맥을 동시 파악하는 구조.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 긴 시계열 역전파 시 **기울기 폭주(Exploding Gradient)** | `clip_grad_norm_` 기반 **기울기 클리핑** 적용 | 역전파 발산(`NaN`) 방지 |
| 극단적으로 긴 시퀀스로 인한 **GPU 메모리 고갈** | 시퀀스를 일정 길이로 자르는 **TBPTT(Truncated BPTT)** | 일정한 메모리 점유 및 안정적 학습 |
| 독립된 세션/장비 간의 **은닉 상태 오염(State Leakage)** | 새 시퀀스 시작 시 `detach()` 및 **상태 명시적 초기화** | 세션 간 상태 격리 보장 |
| 순차 처리 병목으로 인한 **훈련 시간 과다** | **트랜스포머(Self-Attention)** 또는 GRU 전환 | 병렬 연산 및 학습 처리량 극대화 |

#### 한줄 요약

- 기울기 폭주는 클리핑으로 방지하고, 긴 시퀀스는 TBPTT로 메모리를 제어하며, 세션 경계에서 상태를 초기화하고, 병렬 처리가 필요하면 트랜스포머로 전환한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **시퀀스 모델링 진화 계보**: Vanilla RNN $\to$ LSTM/GRU (게이트 도입) $\to$ Transformer (Self-Attention 완전 병렬화)로 발전하였으나, 초저지연 센서 스트리밍에는 여전히 경량 GRU/LSTM이 활발히 사용.

</details>

- 단순 단기 시계열은 **기본 RNN**, 장기 문맥/복잡 게이트는 **LSTM**, 경량화/빠른 훈련은 GRU 선택

#### 한줄 요약

- 단기 의존성은 RNN, 장기 기억은 LSTM, 장기 문맥과 메모리 절충은 GRU를 선택
