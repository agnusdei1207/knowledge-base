## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **순환 신경망(Recurrent Neural Network, RNN)**: 이전 상태를 현재 입력과 결합해 순서 문맥을 학습하는 신경망이다.
- **은닉 상태**: 현재까지의 문맥을 요약해 다음 시점에 넘기는 기억값이다.
- **순서 문맥**: 앞선 입력의 순서와 내용이 현재 해석에 제공하는 정보이다.
- **독립 표본 처리**: 각 입력을 다른 입력의 과거 상태와 연결하지 않고 따로 처리하는 방식이다.

</details>

- 정의/개념: 같은 순환 셀이 현재 입력과 이전 시점의 은닉 상태를 결합하여 순서에 따른 문맥을 다음 시점으로 전달하는 신경망이다.
- 배경/필요성: 각 표본을 독립적으로 처리하는 모형은 같은 값이라도 앞선 입력에 따라 의미가 달라지는 시간 순서와 과거 문맥을 반영할 수 없다.

#### 한줄 요약

- 릴레이 주자가 이전 주자의 쪽지를 받아 다음 주자에게 넘기듯, RNN은 같은 셀로 과거 문맥을 시점마다 전달한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **가중치 공유**: 동일한 순환 셀의 가중치를 모든 시점에 반복 적용하는 방식이다.
- **기울기 소실(Vanishing Gradient)**: 시간축 반복 곱으로 기울기가 0에 가까워지는 현상이다.
- **기울기 폭주(Exploding Gradient)**: 시간축 반복 곱으로 기울기가 지나치게 커지는 현상이다.
- **가변 길이 입력**: 표본마다 포함하는 시점이나 토큰 수가 다른 시퀀스 입력이다.

</details>

- **은닉 상태** 순환을 통한 과거 **문맥 전달**이 핵심이다.
- 시간축 **가중치 공유** 기반 **가변 길이** 입력을 처리한다.
- 시간축 반복 곱에 따른 **기울기 소실•폭주**로 장기 문맥 학습 곤란이 핵심이다.

#### 한줄 요약

- 긴 복도에서 같은 소리를 거듭 줄이거나 키우면 끝에는 사라지거나 폭발하듯, 시간축 기울기도 반복 곱으로 변한다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **순환 셀**: 현재 입력과 이전 상태를 결합해 다음 상태를 계산하는 처리 단위이다.
- **게이트**: 기억의 보존•삭제•출력 비율을 조절하는 장치이다.
- **셀 상태**: LSTM에서 장기 문맥을 전달하는 별도 기억 통로이다.
- **게이트 제어**: 기억을 보존•삭제•출력할 비율을 게이트 값으로 조절하는 처리이다.

</details>

```text
[순환 신경망]
      |
      +-- [시점 입력]
      +-- [순환 셀]
      +-- [은닉 상태]
      `-- [시점 출력]
```

선의 의미: 모든 순환 신경망에 공통인 입력•상태•출력 구성을 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 시점 입력 | 현재 시점의 **순서 데이터** 제공 |
| 순환 셀 | 현재 입력•이전 상태로 **상태 갱신** |
| 은닉 상태 | 다음 시점으로 **순서 문맥** 전달 |
| 시점 출력 | 현재 상태의 **예측 결과** 제공 |

#### 한줄 요약
- 순환 셀이 현재 입력과 이전 은닉 상태를 결합해 다음 문맥과 출력을 만든다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **시퀀스**: 원소의 순서가 의미를 바꾸는 데이터이다.
- **상태 갱신**: 이전 기억과 현재 입력을 결합해 다음 시점의 기억을 만드는 과정이다.
- **장단기 메모리(Long Short-Term Memory, LSTM)**: 게이트와 별도 셀 상태로 장기 문맥을 전달하는 순환 신경망이다.

</details>

```text
[초기 은닉 상태]
        |
        v
+------------------------------------+
| 다음 시점이 존재하는 동안          |
|                                    |
|  1. 시점 입력•이전 상태 결합       |
|             |                      |
|             v                      |
|  2. 게이트 기억 갱신               |
|     (LSTM•GRU만 적용)              |
|             |                      |
|             v                      |
|  3. 은닉 상태•출력 갱신            |
|             |                      |
|             `---------- 반복 ------|
+------------------------------------+
        |
        v
[시퀀스 출력]
```

### 동작 원리

- **1. 시점 입력•이전 상태 결합**: 현재 입력과 문맥을 계산한다.
- **2. 게이트 기억 갱신**: 보존•삭제•입력 비율을 결정한다.
- **3. 은닉 상태•출력 갱신**: 다음 시점 문맥과 예측을 생성한다.

#### 한줄 요약

- 매 시점 순환 셀이 현재 입력과 이전 기억을 결합하고, LSTM•GRU는 게이트로 남길 문맥을 조절한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **게이트 순환 유닛(Gated Recurrent Unit, GRU)**: 두 게이트로 은닉 상태를 직접 조절하는 경량 순환 신경망이다.
- **장기 의존성**: 먼 과거의 정보가 현재 결과에 영향을 주는 관계이다.
- **단기 의존성**: 가까운 시점 사이의 정보 관계이다.
- **메모리 제약**: 모델 상태와 학습 계산에 사용할 수 있는 저장 공간의 한도이다.

</details>

| 순환 신경망 | RNN | LSTM | GRU |
|:---|:---|:---|:---|
| 적용 기준 | 시점 간격 짧은 **단기 의존성** | 먼 시점의 **장기 의존성**과업 | 장기 문맥과 **메모리 제약** 동시 |
| 핵심 특징 | **은닉 상태** 단일 순환 | **셀 상태•세 게이트** 기반 기억 제어 | 셀 상태 없는 **두 게이트** 갱신 |
| 한계 | 장기 구간의 **기울기 소실•폭주** | 파라미터•연산량 증가로 **학습 지연** | LSTM보다 단순한 **기억 제어 구조** |

> 요약: 기울기 소실을 게이트로 풀고 다시 경량화한 **순환망 계보**가 핵심이다.

#### 한줄 요약

- 세 문과 별도 기억 통로가 필요하면 LSTM, 두 문으로 가볍게 운반하려면 GRU 수레를 고른다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **기울기 클리핑**: 기울기를 임계 크기로 제한해 폭주를 억제하는 방법이다.
- **절단 시간축 역전파**: 긴 시퀀스를 구간으로 나누어 역전파하는 학습법이다.
- **상태 초기화**: 독립 시퀀스 경계에서 기억 상태를 초기값으로 되돌리는 처리한다.
- **학습률(Learning Rate)**: 한 번의 학습 갱신에서 파라미터를 변경하는 크기이다.
- **구간 배치**: 긴 시퀀스를 나눈 구간들을 묶어 학습에 사용하는 배치한다.
- **문맥 누출**: 한 독립 시퀀스의 은닉 상태가 다음 표본에 남아 예측에 영향을 주는 현상이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 긴 구간에서 **과거 정보 소실** | **LSTM•GRU 게이트** 구조 적용 | 먼 시점의 **정보 보존** |
| 기울기 폭주로 **손실 불안정** | **기울기 클리핑•학습률 조정** | **파라미터 갱신** 안정화 |
| 긴 시퀀스로 **학습 메모리 급증** | **절단 시간축 역전파•구간 배치** | **연산•메모리 상한** 통제 |
| 독립 시퀀스 사이 **상태 오염** | 경계에서 **은닉 상태 초기화•분리** | 표본 간 **문맥 누출 방지** |

#### 한줄 요약

- 독립된 장비 로그 경계에서 상태를 초기화해 이전 로그의 문맥 유입을 막는다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **순환망 선택 기준**: 의존 거리와 기억 제어 수준, 파라미터•메모리 예산을 함께 비교하는 기준이다.

</details>

- 단기 의존성은 RNN, **장기 기억**은 LSTM, 메모리 제약은 GRU을 선택한다.

#### 한줄 요약

- 짧은 쪽지는 RNN, 오래 보관할 장부는 LSTM, 가벼운 수첩은 GRU 칸에 넣는다.
