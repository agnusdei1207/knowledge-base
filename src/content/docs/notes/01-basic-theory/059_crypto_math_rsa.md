## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **공개키 암호**: 공개키와 개인키로 암호화•서명 역할을 분리하는 방식이다.
- **부인방지**: 개인키 소유자만 만들 수 있는 서명으로 작성 사실을 사후에 부정하기 어렵게 하는 성질이다.
- **비대칭 암호 체계**: 공개 가능한 키와 비밀로 보관할 키를 서로 다른 역할에 사용하는 암호 방식이다.
- **세션키**: 한 통신 세션의 대칭 암호화에 사용하는 일시적인 비밀키이다.
- **전자서명(Digital Signature)**: 개인키로 서명하고 공개키로 무결성과 서명자를 검증하는 방식이다.
- **리베스트-샤미르-애들먼(Rivest-Shamir-Adleman, RSA)**: 소인수분해 난제를 바탕으로 모듈러 거듭제곱을 수행하는 공개키 암호 알고리즘이다.

</details>

- 정의/개념: **RSA**는 큰 합성수의 소인수분해가 어렵다는 가정 아래 공개 지수와 개인 지수의 모듈러 거듭제곱으로 암호화•서명을 수행하는 **공개키 암호**이자 **비대칭 암호 체계**이다.
- 배경/필요성: 사전에 비밀을 공유하지 않은 상대와 대칭 세션키를 안전하게 전달하고 전자서명의 **부인방지**를 제공하려면 공개키 방식이 필요하다.

#### 한줄 요약

- Trapdoor One-way Function(단방향 함정함수) 특성을 활용하여 $C \equiv M^e \pmod n$, $M \equiv C^d \pmod n$의 asymmetric key pair 연산을 수행한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **소인수분해 난제**: 큰 합성수를 원래 소수들의 곱으로 되돌리기 어렵다는 RSA의 안전성 기반이다.
- **모듈러 역원**: 특정 수와 곱했을 때 기준 수로 나눈 나머지가 1이 되는 수이다.
- **하이브리드 암호화**: 대용량 데이터는 대칭키로 처리하고 그 대칭키만 공개키 방식으로 보호하는 구조이다.
- **모듈러 거듭제곱**: 거듭제곱 결과를 모듈러 값으로 나누며 계산하는 RSA의 핵심 연산이다.
- **공개 지수 $e$**: 공개키 연산에 사용하는 RSA 지수이다.
- **개인 지수 $d$**: 개인키 연산에 사용하는 RSA 지수이다.
- **RSA 모듈러스 $n=pq$**: 서로 다른 큰 소수 $p$, $q$를 곱해 공개키와 개인키 연산의 나눗셈 기준으로 사용하는 값이다.
- **오일러 피 함수 $\phi(n)$**: $n$ 이하에서 $n$과 서로소인 양의 정수의 수이다.
- **키 지수 합동식 $ed\equiv1\pmod{\phi(n)}$**: 공개 지수 $e$와 개인 지수 $d$가 $\phi(n)$을 법으로 서로 역원이 되게 하는 관계식이다.

</details>

- **소인수분해 난제**와 모듈러 거듭제곱 기반의 역연산 비대칭성이 핵심이다.
- **RSA 모듈러스 $n=pq$**, **오일러 피 함수**, **모듈러 역원**을 이용한 **키 지수 합동식 $ed\equiv1\pmod{\phi(n)}$**으로 **공개 지수**와 개인 지수를 구성한다.
- 공개키와 개인키의 역할을 분리하고 고비용 연산은 **하이브리드 암호화**로 보완한다.

#### 한줄 요약

- Symmetric Key (AES)로 Bulk Data를 암호화하고, Asymmetric Key (RSA/ECC)로 Session Key를 래핑하는 Hybrid Cryptosystem 구조를 채택한다.


## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **최적 비대칭 암호화 패딩(Optimal Asymmetric Encryption Padding, OAEP)**: 난수로 RSA 암호문을 무작위화하는 패딩이다.
- **확률적 서명 방식(Probabilistic Signature Scheme, PSS)**: 난수 솔트로 RSA 서명 보안성을 높이는 방식이다.
- **비밀 키 재료**: 개인 지수와 원본 소수처럼 외부에 노출되면 안 되는 키 생성 정보이다.
- **복호화(Decryption)**: 개인키 연산으로 암호문을 원래 평문으로 되돌리는 과정이다.

</details>

```text
[RSA 암호 체계]
        |
        +-- [키 생성기]
        +-- [개인키 저장소]
        +-- [OAEP•PSS 처리기]
        `-- [공개키•개인키 연산기]
```

선의 의미: RSA 키 생성•보호•인코딩•모듈러 연산 구성을 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 키 생성기 | **오일러 피 함수**와 **모듈러 역원**으로 키 지수 생성 |
| 개인키 저장소 | 개인 지수•원본 소수 등 **비밀 키 재료** 격리 보관 |
| OAEP•PSS 처리기 | **OAEP** 암호화 인코딩과 **PSS** 서명 인코딩•검증 |
| 공개키•개인키 연산기 | 공개•개인 지수로 암호화•**복호화**•서명•검증 수행 |

#### 한줄 요약
- Key Generator($n=pq, \phi(n)=(p-1)(q-1), ed \equiv 1 \pmod{\phi(n)}$), HSM Key Store, OAEP/PSS Formatting Unit으로 PKI 기반 아키텍처를 구성한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **평문(Plaintext)**: 암호화 전의 원래 메시지이다.
- **암호문(Ciphertext)**: 암호화로 알아볼 수 없게 바뀐 결과이다.
- **패딩 검증**: 복호한 블록이 OAEP의 구조와 해시 조건에 맞는지 확인하는 처리이다.
- **OAEP 인코딩 블록**: 평문에 난수와 해시 구조를 결합해 RSA 연산 크기에 맞춘 입력이다.
- **격리된 개인키 연산**: 개인키를 외부에 노출하지 않는 보안 영역 안에서 수행하는 복호 연산이다.
- **OAEP 인코딩**: 평문에 난수와 해시 구조를 결합해 RSA 연산 크기의 블록으로 만드는 단계이다.
- **공개키 모듈러 연산**: OAEP 인코딩 블록을 공개 지수로 거듭제곱해 암호문으로 바꾸는 단계이다.
- **OAEP 검증•디코딩**: 개인키 연산 결과의 패딩 구조와 해시를 검사한 뒤 평문을 복원하는 단계이다.

</details>

```text
[평문]
      |
      v
1. OAEP 인코딩
      |
      v
2. 공개키 모듈러 연산
      |
      v
[암호문]
      |
      v
3. 격리된 개인키 연산
      |
      v
4. OAEP 검증•디코딩
      |
      v
[복원 평문]
```

### 동작 원리

- **1. OAEP 인코딩**: 난수•해시를 결합한 입력 블록을 생성한다.
- **2. 공개키 모듈러 연산**: 인코딩 블록을 암호문으로 변환한다.
- **3. 격리된 개인키 연산**: 보호 영역에서 복호 블록을 산출한다.
- **4. OAEP 검증•디코딩**: **패딩 검증**으로 구조•해시를 확인한 후 평문을 복원한다.

#### 한줄 요약

- Plaintext M $\rightarrow$ OAEP Encoding $\rightarrow$ Modular Exponentiation $C = M^e \pmod n \rightarrow$ HSM Private Key Operation $\rightarrow$ OAEP Validation 순으로 진술된다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **디피-헬먼(Diffie-Hellman, DH)**: 유한체 이산 로그 난제 기반 키 합의 방식이다.
- **타원곡선 암호(Elliptic Curve Cryptography, ECC)**: 타원곡선 이산 로그 난제 기반 공개키 암호이다.
- **쇼어 알고리즘**: 양자컴퓨터에서 소인수분해와 이산 로그를 빠르게 푸는 알고리즘이다.
- **패딩 오라클 공격**: 패딩 오류 반응 차이를 반복 관측해 평문을 추론하는 공격이다.
- **중간자 공격(Man-in-the-Middle)**: 통신 사이에 개입해 양쪽과 별도 키를 맺고 메시지를 가로채는 공격이다.
- **점 유효성 검증**: ECC 입력점이 올바른 타원곡선과 부분군에 속하는지 확인하는 검사이다.

</details>

| 공개키 알고리즘 | RSA | DH | ECC |
|:---|:---|:---|:---|
| 적용 기준 | 키 운반•**전자서명**이 필요한 경우 | 사전 공유 없이 **세션키** 합의가 필요한 경우 | 대역•전력 제약으로 짧은 키가 필요한 경우 |
| 핵심 특징 | **소인수분해 난제** 기반 | 유한체 이산 로그 난제 기반 | 타원곡선 이산 로그 난제 기반 |
| 한계 | **패딩 오라클 공격** 노출 | 인증 부재 시 **중간자 공격** | **점 유효성 검증** 누락 |

> 요약: 소인수분해•이산 로그 기반 방식은 모두 **쇼어 알고리즘**에 취약하다.

#### 한줄 요약

- RSA(Prime Factorization), DH/ECC(Discrete Log Problem) 모두 Shor's Algorithm에 의해 Polynomial Time $O((\log N)^3)$으로 해독되므로 PQC(Post-Quantum Cryptography)로의 마이그레이션이 필수적이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **측면 채널 공격(Side-channel Attack)**: 처리 시간 등 외부 차이로 비밀키를 추론하는 공격이다.
- **하드웨어 보안 모듈(Hardware Security Module, HSM)**: 개인키를 내부에서 보호하며 암호 연산을 수행하는 장비이다.
- **양자내성암호(Post-Quantum Cryptography, PQC)**: NIST 표준 ML-KEM•ML-DSA•SLH-DSA처럼 양자 공격에 대응하도록 설계한 공개키 암호이다.
- **수확 후 복호화**: 현재 암호문을 수집해 미래의 양자컴퓨터로 복호화하려는 위협이다.
- **상수 시간•단일 오류 응답**: 비밀값과 무관한 일정 시간 및 같은 오류 형태로 처리 차이를 숨기는 방식이다.
- **키 순환(Key Rotation)**: 키를 정기적으로 새 값으로 교체하고 이전 키 사용을 중단하는 관리이다.
- **암호 자산 목록**: 알고리즘•키•인증서•보호 데이터와 사용 기간을 기록한 목록이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 복호화 오류•시간 차이가 외부에 노출 | OAEP와 **상수 시간•단일 오류 응답** 적용 | **패딩 오라클 공격**•**측면 채널 공격** 완화 |
| 개인키 유출•무단 사용 | **HSM** 격리 저장•접근 통제•**키 순환** | 비밀 키 재료 보호•사용 추적 |
| 대용량 데이터를 RSA로 직접 처리 | **하이브리드 암호화** 적용 | 성능•데이터 크기 제약 해소 |
| 장기 보호 자산의 양자 위협 | **암호 자산 목록** 작성•**PQC** 전환 계획 | **수확 후 복호화** 위험 축소 |

#### 한줄 요약

- Padding Oracle Attack 및 Timing Side-channel Attack을 차단하기 위해 Constant-time Execution 및 Blinded Modulo Exponentiation을 적용한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **대칭키 암호**: 송수신자가 같은 비밀키로 대용량 데이터를 빠르게 암호화•복호화하는 방식이다.
- **암호 방식 선택 기준**: 데이터 규모와 보호 기간에 따라 하이브리드 암호화와 양자내성암호 전환을 정하는 기준이다.

</details>

- **암호 방식 선택 기준**에 따라 대용량 데이터는 **대칭키 암호**를 결합한 **하이브리드 암호화**, 장기 보호 자산은 **PQC** 전환을 적용한다.

#### 한줄 요약

- Bulk Data에는 AES-GCM 대칭키, Session Key Exchange에는 RSA-OAEP / ECDH, Long-term Security / Harvest-now Decrypt-later 위협에는 PQC(NIST ML-KEM/ML-DSA)를 채택한다.
