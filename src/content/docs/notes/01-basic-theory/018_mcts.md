## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **몬테카를로 트리 탐색(Monte Carlo Tree Search, MCTS)**: 선택•확장•롤아웃•역전파를 반복해 보상 추정치가 높은 경로에 탐색을 집중하는 기법이다.
- **선택(Selection)**: UCT로 탐색 트리의 경로를 고르는 단계이다.
- **확장(Expansion)**: 미시도 행동을 새 자식 노드로 추가하는 단계이다.
- **롤아웃(Rollout)**: 확장 상태부터 종료까지 모의 진행해 행동 보상을 추정하는 단계이다.
- **역전파(Backpropagation)**: 롤아웃 보상을 선택 경로 통계에 반영하는 단계이다.
- **분기 계수(Branching Factor)**: 한 노드에서 생성되는 자식 노드의 수이다.
- **롤아웃 보상(Rollout Reward)**: 현재 상태부터 종료까지 모의 진행해 얻은 결과값이다.

</details>

- 정의/개념: 선택•확장•롤아웃•역전파로 보상을 누적해 유망 행동을 고르는 **MCTS** 기법이다.
- 배경/필요성: 분기 계수가 크고 깊이가 깊은 의사결정 문제는 제한된 자원으로 전체 게임 트리를 완전 탐색하는 데 한계가 있다.

#### 한줄 요약

- 거대한 상태 공간에서 UCT 기반의 4단계(선택·확장·롤아웃·역전파) 시뮬레이션으로 유망 탐색 경로를 동적으로 확정한다.


## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **트리 적용 신뢰 상한(Upper Confidence Bound applied to Trees, UCT)**: 평균 보상과 방문 횟수로 탐색•활용을 조절하는 선택식이다.
- **탐색 예산(Search Budget)**: MCTS가 반복할 수 있는 시간•롤아웃 횟수•계산량의 한도이다.
- **루트 행동(Root Action)**: 탐색 종료 후 루트에서 최다 방문 기준으로 선택하는 최종 행동이다.
- **탐색(Exploration)**: 덜 방문한 행동을 시험해 불확실성을 줄이는 선택이다.
- **활용(Exploitation)**: 평균 보상이 높은 행동에 탐색을 집중하는 선택이다.
- **비말단 상태(Non-terminal State)**: 게임이나 의사결정이 아직 종료되지 않아 후속 행동이 남은 상태이다.
- **최다 방문 기준**: 탐색 종료 시 방문 횟수가 가장 큰 루트 행동을 최종 행동으로 고르는 기준이다.

- **트리 상한 신뢰도(Upper Confidence Bounds applied to Trees, UCT)**: 탐험(Exploration)과 활용(Exploitation) 간의 균형을 유지하기 위해 노드 선택에 적용하는 수식.
</details>

![자식 방문 수에 따른 UCT 탐험 보너스](/study/diagrams/uct-exploration-bonus.svg)

> 파란 탐험 보너스는 적게 방문한 자식에서 크고 방문 수가 늘수록 감소하며, 부모 방문 수 100을 가정한 UCT 공식값이지 탐색 승률 실측값은 아니다.

- **롤아웃** 보상 평균으로 비말단 상태의 행동 가치를 추정한다.
- **UCT**로 탐색•활용 균형 조절해 유망 분기 집중이 핵심이다.
- **탐색 예산** 소진 시 **최다 방문 기준**으로 루트 행동을 반환한다.

#### 한줄 요약

- UCT로 평균 보상이 높은 경로의 활용과 저방문 경로의 탐색을 조절한다.



## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **트리 정책(Tree Policy)**: UCT로 기존 노드를 따라가며 확장할 상태와 행동을 고르는 규칙이다.
- **롤아웃 정책(Rollout Policy)**: 확장 상태부터 종료까지 모의 행동을 선택해 보상 표본을 만드는 규칙이다.
- **노드 통계(Node Statistics)**: 각 노드의 방문 횟수와 누적•평균 보상을 저장한 값이다.
- **탐색 트리**: 방문한 상태를 노드로, 행동을 간선으로 누적한 부분 상태 공간 트리이다.

- **모의 진행(Simulation / Rollout)**: 현재 상태에서 게임 종료 시점까지 무작위 또는 가벼운 정책으로 빠르게 수를 진행하는 단계.
</details>

```text
MCTS 구조
├─ 트리 정책
├─ 탐색 트리
│  └─ 노드 통계
└─ 롤아웃 정책
```

가지의 의미: 정책•탐색 트리와 트리 소유 통계의 정적 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 트리 정책 | **UCT**로 탐색•활용 균형을 맞춰 경로 선택 |
| 탐색 트리 | **탐색 트리**에 상태 노드와 행동 간선 보관 |
| 롤아웃 정책 | 확장 노드부터 종료까지 **모의 진행** |
| 노드 통계 | **방문 횟수**•누적 보상 보관 |

#### 한줄 요약

- 트리 정책이 UCT로 경로를 선택하고, 롤아웃 보상과 방문 횟수를 노드 통계에 누적한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **보상(Reward)**: 모의 행동 결과가 목표를 달성한 정도를 나타내는 값이다.
- **미시도 행동**: 현재 탐색 트리 노드에서 아직 자식으로 확장하지 않은 행동이다.

</details>

```text
행동 선택 요청
   │
   ▼
1. 선택: UCT로 경로 선택
   │
   ▼
2. 확장: 미시도 자식 추가
   │
   ▼
3. 롤아웃: 종료까지 보상 추정
   │
   ▼
4. 역전파: 경로 통계 갱신
   ├─ 예산 잔여: 선택부터 반복
   └─ 예산 소진: 최다 방문 행동 반환
```

**동작 원리**

1. **선택**: 루트부터 UCT 같은 트리 정책으로 활용 가치와 미탐색 가능성을 함께 고려하여 경로를 고른다.
2. **확장**: 선택 경로에서 아직 시험하지 않은 행동 하나를 자식 상태로 추가한다.
3. **롤아웃**: 새 상태부터 종료 또는 평가 지점까지 기본 정책으로 모의 실행하여 보상을 계산한다.
4. **역전파**: 얻은 보상을 선택 경로의 각 노드에 거꾸로 전달하여 방문 횟수와 보상 통계를 갱신한다.

#### 한줄 요약

- 선택, 확장, 롤아웃, 역전파를 탐색 예산이 소진될 때까지 반복한다.


## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **미니맥스(Minimax)**: 상대의 최선 대응을 가정해 최소•최대 값을 역전파하는 결정 규칙이다.
- **평가 함수(Evaluation Function)**: 종료하지 않은 상태의 유리함을 점수로 추정하는 함수이다.
- **롤아웃 편향(Rollout Bias)**: 롤아웃 정책의 치우친 표본화가 노드 보상 추정을 왜곡하는 현상이다.
- **지평선 효과(Horizon Effect)**: 제한된 탐색 깊이 밖의 결과를 보지 못해 현재 행동 평가가 왜곡되는 현상이다.

- **최소•최대 역전파(Min-Max Backpropagation)**: 2인 제로섬 게임에서 플레이어별 보상을 교대로 반전·집계하며 트리의 상위 노드로 가치를 전달하는 절차.
</details>

| 게임 트리 탐색 기법 | MCTS | 미니맥스 |
|:---|:---|:---|
| 적용 기준 | **분기 계수** 크고 롤아웃 가능 | 분기 작고 **평가 함수** 정확 |
| 핵심 특징 | **UCT**•롤아웃으로 유망 분기 집중 | 상대 최선 가정 **최소•최대 역전파** |
| 한계 | **롤아웃 편향**•저방문 분기 오판 | 평가 오차•**지평선 효과** |

#### 한줄 요약

- 분기 계수가 크고 롤아웃이 가능하면 MCTS, 평가 함수가 정확하면 미니맥스를 선택한다.


## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **탐색 상수(Exploration Constant)**: UCT에서 저방문 행동의 탐색 보너스 크기를 조절하는 계수이다.
- **가상 손실(Virtual Loss)**: 병렬 작업자가 같은 경로에 몰리지 않도록 선택 중인 노드의 가치를 일시적으로 낮추는 값이다.
- **원자적 갱신**: 병렬 작업 중에도 노드 통계 변경이 하나의 연산처럼 완전하게 반영되는 방식이다.
- **가치 모델(Value Model)**: 상태나 행동의 기대 보상을 직접 추정하는 모델이다.
- **저방문 분기**: 롤아웃 표본이 적어 평균 보상의 분산이 큰 탐색 트리 분기이다.
- **경로 다양성**: 병렬 작업자가 서로 다른 탐색 경로를 선택해 중복 롤아웃을 줄이는 성질이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **롤아웃 편향**으로 특정 행동의 보상 추정 왜곡 | 기준 정책 검증과 **가치 모델** 교차 평가 | 행동별 롤아웃 편향 완화 |
| 부적절한 **탐색 상수**로 과도한 탐색•고보상 경로 고착 | 도메인•예산별 UCT 상수 조정 | **탐색•활용**의 예산 배분 균형 |
| **저방문 분기**의 높은 분산으로 우연한 고보상 오선택 | 평균 보상과 방문 횟수 동시 검증 | 저방문 분기의 오선택 감소 |
| 병렬 작업자의 같은 경로 집중으로 중복 탐색 | **가상 손실**과 노드 통계 **원자적 갱신** | 병렬 탐색의 **경로 다양성** 향상 |

#### 한줄 요약

- 가치 모델로 롤아웃 편향을 점검하고, 병렬 탐색에는 가상 손실과 원자적 갱신을 적용한다.


## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **롤아웃 가능성**: 현재 상태부터 종료까지 모의 행동을 실행해 보상 표본을 얻을 수 있는 조건이다.
- **정확한 평가**: 비말단 상태의 결과 가치를 평가 함수가 신뢰할 수 있게 추정하는 조건이다.

</details>

- 큰 분기•롤아웃 가능은 **MCTS**, 정확한 평가는 **미니맥스**를 선택한다.

#### 한줄 요약

- 큰 분기에서 롤아웃이 가능하면 MCTS, 정확한 평가 함수가 있으면 미니맥스를 선택한다.
