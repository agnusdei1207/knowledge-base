## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **몬테카를로 트리 탐색(Monte Carlo Tree Search, MCTS)**: 선택•확장•롤아웃•역전파를 반복해 보상 추정치가 높은 경로에 탐색을 집중하는 기법
- **분기 계수(Branching Factor)**: 한 노드에서 생성되는 자식 노드의 수
- **롤아웃 보상(Rollout Reward)**: 현재 상태부터 종료까지 모의 진행해 얻은 결과값

</details>

- 정의/개념: **롤아웃 보상**을 트리에 누적해 행동을 선택하는 기법
- 배경/필요성: 큰 **분기 계수**로 제한 예산 내 전수 탐색 곤란

#### 한줄 요약

- 수많은 게임 수를 모두 읽는 대신 몇 번의 모의 대국으로 유망한 수를 찾고, 남은 탐색 예산을 그 주변에 집중한다.


## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **롤아웃(Rollout)**: 현재 상태부터 종료까지 모의 진행해 행동 보상을 추정하는 절차
- **트리 적용 신뢰 상한(Upper Confidence Bound applied to Trees, UCT)**: 평균 보상과 방문 횟수로 탐색•활용을 조절하는 선택식
- **탐색 예산(Search Budget)**: MCTS가 반복할 수 있는 시간•롤아웃 횟수•계산량의 한도
- **루트 행동(Root Action)**: 탐색 종료 후 루트에서 최다 방문 기준으로 선택하는 최종 행동
- **탐색(Exploration)**: 덜 방문한 행동을 시험해 불확실성을 줄이는 선택
- **활용(Exploitation)**: 평균 보상이 높은 행동에 탐색을 집중하는 선택
- **비말단 상태(Non-terminal State)**: 게임이나 의사결정이 아직 종료되지 않아 후속 행동이 남은 상태

</details>

![자식 방문 수에 따른 UCT 탐험 보너스](/study/diagrams/uct-exploration-bonus.svg)

> 파란 탐험 보너스는 적게 방문한 자식에서 크고 방문 수가 늘수록 감소하며, 부모 방문 수 100을 가정한 UCT 공식값이지 탐색 승률 실측값은 아니다.

- **롤아웃** 보상 평균으로 비말단 상태의 행동 가치 추정
- **UCT**로 탐색•활용 균형 조절해 유망 분기 집중
- **탐색 예산** 소진 시 **최다 방문 루트 행동** 반환

#### 한줄 요약

- UCT는 고보상 수와 저방문 수의 선택 기회를 조절한다.


## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **트리 정책(Tree Policy)**: UCT로 기존 노드를 따라가며 확장할 상태와 행동을 고르는 규칙
- **롤아웃 정책(Rollout Policy)**: 확장 상태부터 종료까지 모의 행동을 선택해 보상 표본을 만드는 규칙
- **노드 통계(Node Statistics)**: 각 노드의 방문 횟수와 누적•평균 보상을 저장한 값
- **탐색 트리**: 실제로 방문한 상태를 노드로, 행동을 간선으로 누적한 부분 상태 공간 트리

</details>

```text
MCTS 구조
├─ 트리 정책
├─ 탐색 트리
│  └─ 노드 통계
└─ 롤아웃 정책
```

가지의 의미: 정책•탐색 트리와 트리 소유 통계의 정적 관계

| 구성요소 | 책임 |
|:---|:---|
| 트리 정책 | **UCT**로 탐색•활용 균형을 맞춰 경로 선택 |
| 탐색 트리 | **상태 노드**와 행동 간선 보관 |
| 롤아웃 정책 | 확장 노드부터 종료까지 **모의 진행** |
| 노드 통계 | **방문 횟수**•누적 보상 보관 |

#### 한줄 요약

- 트리 정책이 UCT로 경로를 선택하고, 롤아웃 보상과 방문 횟수를 노드 통계에 누적한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **선택(Selection)**: UCT로 탐색 트리의 경로를 고르는 단계
- **확장(Expansion)**: 미시도 행동을 새 자식 노드로 추가하는 단계
- **역전파(Backpropagation)**: 롤아웃 보상을 선택 경로 통계에 반영하는 단계
- **보상(Reward)**: 모의 행동 결과가 목표를 달성한 정도를 나타내는 값
- **미시도 행동**: 현재 탐색 트리 노드에서 아직 자식으로 확장하지 않은 행동

</details>

```text
행동 선택 요청
   │
   ▼
1. 선택: UCT로 경로 선택
   │
   ▼
2. 확장: 미시도 자식 추가
   │
   ▼
3. 롤아웃: 종료까지 보상 추정
   │
   ▼
4. 역전파: 경로 통계 갱신
   ├─ 예산 잔여: 선택부터 반복
   └─ 예산 소진: 최다 방문 행동 반환
```

**동작 원리**

1. **선택**: UCT로 탐색•활용 점수가 높은 경로 결정
2. **확장**: 선택 노드에 미시도 자식 상태 추가
3. **롤아웃**: 확장 상태부터 종료까지 모의해 보상 산출
4. **역전파**: 보상을 선택 경로의 방문•보상 통계에 반영

#### 한줄 요약

- 유망한 가지를 고르고 새 수를 붙여 끝까지 모의 대국한 뒤, 승패 보상을 지나온 노드에 거꾸로 적어 다음 UCT 선택에 재사용한다.


## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **미니맥스(Minimax)**: 상대의 최선 대응을 가정해 최소•최대 값을 역전파하는 결정 규칙
- **평가 함수(Evaluation Function)**: 종료하지 않은 상태의 유리함을 점수로 추정하는 함수
- **롤아웃 편향(Rollout Bias)**: 롤아웃 정책의 치우친 표본화가 노드 보상 추정을 왜곡하는 현상
- **지평선 효과(Horizon Effect)**: 제한된 탐색 깊이 밖의 결과를 보지 못해 현재 행동 평가가 왜곡되는 현상

</details>

| 게임 트리 탐색 기법 | MCTS | 미니맥스 |
|:---|:---|:---|
| 적용 기준 | **분기 계수** 크고 롤아웃 가능 | 분기 작고 **평가 함수** 정확 |
| 핵심 특징 | **UCT**•롤아웃으로 유망 분기 집중 | 상대 최선 가정 **최소•최대 역전파** |
| 한계 | **롤아웃 편향**•저방문 분기 오판 | 평가 오차•**지평선 효과** |

#### 한줄 요약

- 둘 수가 너무 많아 전부 읽기 어렵지만 모의 대국은 가능하면 MCTS, 수가 적고 중간 판세 점수가 정확하면 미니맥스가 맞는다.


## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **탐색 상수(Exploration Constant)**: UCT에서 저방문 행동의 탐색 보너스 크기를 조절하는 계수
- **가상 손실(Virtual Loss)**: 병렬 작업자가 같은 경로에 몰리지 않도록 선택 중인 노드의 가치를 일시적으로 낮추는 값
- **원자적 갱신**: 병렬 작업 중에도 노드 통계 변경이 하나의 연산처럼 완전하게 반영되는 방식
- **가치 모델(Value Model)**: 상태나 행동의 기대 보상을 직접 추정하는 모델

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 롤아웃 정책 편향으로 특정 행동의 **보상 추정 왜곡** | 기준 정책 검증과 가치 모델 교차 평가 | 행동별 **가치 추정 편향 완화** |
| 부적절한 **탐색 상수**로 과도한 탐색•고보상 경로 고착 | 도메인•예산별 UCT 상수 조정 | 탐색과 활용의 **예산 배분 균형** |
| 저방문 행동의 높은 분산으로 우연한 고보상 오선택 | 평균 보상과 방문 횟수 동시 검증 | 표본 부족 행동의 **선택 안정성** 향상 |
| 병렬 작업자의 같은 경로 집중으로 중복 탐색 | **가상 손실•노드 통계 원자적 갱신** | 병렬 탐색의 **경로 다양성•효율 향상** |

#### 한줄 요약

- 롤아웃 정책이 한 수에 치우치면 보상 추정도 편향된다.


## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **롤아웃 가능성**: 현재 상태부터 종료까지 모의 행동을 실행해 보상 표본을 얻을 수 있는 조건
- **정확한 평가**: 비말단 상태의 결과 가치를 평가 함수가 신뢰할 수 있게 추정하는 조건

</details>

- 큰 분기•롤아웃 가능은 **MCTS**, 정확한 평가는 **미니맥스** 선택

#### 한줄 요약

- 선택지가 많고 모의 실행이 가능하면 MCTS, 중간 평가가 정확하면 미니맥스를 선택한다.
