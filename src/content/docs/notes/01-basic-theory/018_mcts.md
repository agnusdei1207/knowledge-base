## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **UCT(Upper Confidence Bound applied to Trees)**: 가치 활용과 불확실성 탐험의 균형을 유지하며 최선의 자식 노드를 선별하는 확률적 의사결정 수식.
- **정적 평가 함수(Static Evaluation Function)**: 게임의 현재 국면 점수를 수작업 휴리스틱 수식으로 정량화하여 판정하는 알고리즘.

</details>

- 정의/개념: 선택·확장·시뮬레이션·역전파 4단계를 반복하며 **UCT 기반 확률적 샘플링**을 통해 최적 의사결정 경로를 탐색하는 휴리스틱 트리 탐색 알고리즘
- 배경/필요성: 거대 분기 계수를 갖는 게임 트리에서 **정적 평가 함수** 수립의 한계 및 상태 공간 폭발 극복

#### 한줄 요약

- 거대한 상태 공간에서 UCT 기반의 4단계(선택·확장·롤아웃·역전파) 시뮬레이션으로 유망 탐색 경로를 동적으로 확정

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **탐색 예산(Search Budget)**: 한 턴의 의사결정에 허용된 연산 시간(ms) 또는 시뮬레이션 반복 횟수(Iterations).

</details>

![자식 방문 수에 따른 UCT 탐험 보너스](/study/diagrams/uct-exploration-bonus.svg)

> 파란 탐험 보너스는 적게 방문한 자식에서 크고 방문 수가 늘수록 감소하며, 부모 방문 수 100을 가정한 UCT 공식값임

- 롤아웃 시뮬레이션의 평균 보상으로 상태 가치를 추정하는 **통계적 가치 산정**
- **UCT 수식**을 통해 활용과 탐색 간 최적 균형 유지
- 제한된 **탐색 예산** 내에서 최다 방문 노드를 선택하는 견고한 결정 체계

$$
\text{UCT}_j = \frac{Q_j}{n_j} + C \sqrt{\frac{\ln N}{n_j}}
$$

#### 한줄 요약

- UCT로 평균 보상이 높은 경로의 활용과 저방문 경로의 탐색을 조절

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **트리 정책(Tree Policy)**: 이미 생성된 탐색 트리 내부에서 UCT 수식으로 리프 노드까지 이동 및 확장하는 정책.
- **기본 정책(Default / Rollout Policy)**: 탐색 트리 외부에서 게임 종료 시점까지 빠르게 수를 두는 경량 무작위 시뮬레이션 정책.

</details>

```text
[ MCTS 4단계 아키텍처 및 노드 통계 ]
┌──────────────────────────────┐
│ 1. 선택기 (Selection / UCT)  │ ── UCT 식 기반 트리 내부 최적 경로 하향 이동
├──────────────────────────────┤
│ 2. 확장기 (Expansion)        │ ── 미방문 유효 행동을 새 자식 노드로 트리에 등록
├──────────────────────────────┤
│ 3. 시뮬레이터 (Rollout)      │ ── 종료 상태까지 빠른 무작위 대국 진행 (보상 획득)
├──────────────────────────────┤
│ 4. 역전파기 (Backprop)       │ ── 루트까지 거슬러 올라가며 N += 1, Q += Reward
└──────────────────────────────┘
```

선의 의미: 선택, 확장, 롤아웃, 역전파 모듈 및 노드 통계($N, Q$) 관리 간의 MCTS 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 선택기 | **UCT** 수식으로 트리 내부 최적 경로 하향 이동 |
| 확장기 | 미방문 유효 행동을 새 **자식 노드**로 등록 |
| 시뮬레이터 | 종료 상태까지 빠른 **모의 진행(Rollout)** 수행 |
| 역전파기 | 획득 보상을 루트까지 **통계 갱신($N, Q$)** 전파 |

#### 한줄 요약

- 트리 정책이 UCT로 경로를 선택하고, 롤아웃 보상과 방문 횟수를 노드 통계에 누적

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **견고한 행동 선택(Robust Child Selection)**: 탐색 완료 후 평균 보상 대신 총 방문 횟수가 가장 높은 루트 자식 노드를 최종 착수로 결정하는 방식.

</details>

```text
의사결정 요청 (Root Node)
   │
   ▼
[ 1. Selection ] : UCT 수식이 최대인 자식 노드를 리프까지 순차 선택
   │
   ▼
[ 2. Expansion ] : 미시도 행동 노드를 탐색 트리에 신규 생성
   │
   ▼
[ 3. Rollout / Simulation ] : 기본 정책으로 종료 상태 도달 시까지 게임 모의 진행
   │
   ▼
[ 4. Backpropagation ] : 획득 보상(Win: 1, Loss: 0)을 역추적하며 N, Q 갱신
   │
   ▼
탐색 예산(시간/반복 횟수) 검사
├─ 예산 잔여: [ 1. Selection ]부터 반복
└─ 예산 소진: 루트에서 최다 방문($\max N$) 자식 행동을 최종 결정으로 반환
```

**동작 원리**
1. **선택 (Selection)**: 루트부터 시작하여 UCT 수식이 가장 높은 자식 노드를 선택하며 트리의 리프 노드까지 하향 이동
2. **확장 (Expansion)**: 도달한 노드가 종료 상태가 아니라면, 아직 방문하지 않은 합법적 자식 노드를 생성
3. **시뮬레이션 (Rollout)**: 생성된 노드부터 게임이 끝날 때까지 기본 정책으로 빠른 롤아웃을 수행하여 승패 결과(보상) 획득
4. **역전파 (Backpropagation)**: 획득한 보상을 선택 경로 상의 모든 부모 노드에 전달하여 방문 횟수($n_i$)와 누적 가치($Q_i$) 갱신

#### 한줄 요약

- 선택, 확장, 롤아웃, 역전파를 탐색 예산이 소진될 때까지 반복

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **MCTS vs Minimax (Alpha-Beta Pruning)**:
  - MCTS: 평가 함수 불필요, 롤아웃 기반 통계적 샘플링, 거대 분기 계수(바둑 등)에 적합.
  - Minimax: 명확한 정적 평가 함수 필수, 완전 탐색 기반 최소-최대 역전파, 분기가 좁은 체스 등에 적합.

</details>

| 게임 탐색 기법 | MCTS (Monte Carlo Tree Search) | 미니맥스 (Minimax + Alpha-Beta) |
|:---|:---|:---|
| 적용 기준 | **분기 계수($b > 100$)** 가 크고 평가 함수 정의 곤란 시 | 분기 계수가 작고 **정확한 정적 평가 함수** 존재 시 |
| 핵심 특징 | **UCT + 롤아웃 통계** 기반 유망 경로 비대칭 탐색 | 상대 최선 대응 가정한 **Min-Max 값 전파 및 가지치기** |
| 한계 | 롤아웃 정책의 품질에 따른 **롤아웃 편향** | 제한된 탐색 깊이 밖의 위협을 놓치는 **지평선 효과** |

#### 한줄 요약

- 분기 계수가 크고 롤아웃이 가능하면 MCTS, 평가 함수가 정확하면 미니맥스를 선택

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **가상 손실(Virtual Loss)**: 병렬 MCTS(Root/Tree Parallelization)에서 다수의 워커 스레드가 동일한 유망 경로에만 몰리는 현상을 막기 위해 선택 중인 노드의 방문 수에 일시적 페널티를 부여하는 동시성 제어 기법.
- **알파고 방식(AlphaGo Style - PUCT)**: 무작위 롤아웃을 심층 신경망의 가치 네트워크(Value Net)와 정책 네트워크(Policy Net)로 대체하여 롤아웃 편향을 극복한 하이브리드 MCTS.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **롤아웃 편향** 기반  특정 행동의 보상 추정 왜곡 | 딥러닝 **가치 네트워크(Value Net)** 평가 결합(PUCT) | 롤아웃 편향 및 분산 대폭 완화 |
| 부적절한 **탐색 상수($C$)** 로 과도한 방황 또는 조기 고착 | 문제 도메인 보상 범위에 맞춘 상수 튜닝($C = \sqrt{2}$) | **탐색(Exploration)** 과 활용(Exploitation) 균형 |
| 저방문 노드의 높은 분산으로 인한 우연적 고보상 이상치 선택 위험 | 최종 선택 시 평균 보상이 아닌 **최다 방문 횟수($\max N$)** 채택 | 이상치 노이즈에 대한 **견고성** 확보 |
| 병렬 탐색 시 워커들이 동일 노드에 집중되어 중복 탐색 | **가상 손실(Virtual Loss)** 및 원자적 CAS 통계 갱신 | 멀티스레드 병렬 탐색의 **경로 다양성** 극대화 |

#### 한줄 요약

- 롤아웃 편향은 가치 신경망(PUCT)으로 완화하고, 병렬 탐색 시에는 가상 손실로 경로 중복을 억제하며, 최종 수는 평균 보상이 아닌 최다 방문 횟수로 결정한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **MCTS 응용 확장**: 전통적인 보드게임을 넘어 LLM 추론 트리 탐색(Tree-of-Thoughts), 로봇 궤적 모션 플래닝, 컴파일러 명령어 최적화 등 고차원 순차 의사결정의 표준 프레임워크로 정착.

</details>

- 거대 분기 계수와 불확실성이 큰 의사결정 문제에는 **MCTS**, 정적 평가 함수가 명확한 좁은 분기 문제에는 **미니맥스(Minimax)**를 선택하며 롤아웃 편향 통제를 위해 **신경망 가치 평가**와 결합

#### 한줄 요약

- 큰 분기에서 롤아웃이 가능하면 MCTS, 정확한 평가 함수가 있으면 미니맥스를 선택
