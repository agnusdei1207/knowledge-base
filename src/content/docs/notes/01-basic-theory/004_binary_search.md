## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **이진 탐색(Binary Search)**: 정렬된 배열에서 중앙 키와 비교하여 후보 탐색 공간을 절반씩 분할 축소함.
- **선형 탐색(Linear Search)**: 순차적 비교를 통해 목표 데이터를 검색함.
- **중앙 키(Mid Key)**: 현재 탐색 구간의 중심 위치에 해당하는 원소 값.

- **비교 횟수(Comparison Count)**: 목표 키를 찾기 위해 배열의 원소와 대조 연산을 수행한 누적 횟수.
</details>

- 정의/개념: 정렬 배열의 중앙 키와 목표값을 비교하여 불가능한 절반 구간을 제거하는 **이진 탐색**.
- 배경/필요성: 선형 탐색은 입력 증가에 따라 **비교 횟수**가 선형 증가.

#### 한줄 요약

- 정렬 배열 내 중앙 원소 비교를 통한 후보 탐색 공간의 분할 정복 방식 축소.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **정렬 불변식(Sorted Invariant)**: 탐색 과정 전체에서 배열의 정렬 상태가 항상 유지되는 전제 조건.
- **로그 시간(Logarithmic Time, $O(\log n)$)**: 입력이 배로 늘어도 연산 단계가 일정량만 증가하는 시간 차수.
- **하한(Lower Bound)**: 목표값 이상인 첫번째 위치 인덱스.
- **상한(Upper Bound)**: 목표값을 초과하는 첫번째 위치 인덱스.

</details>

![이진 탐색과 선형 탐색의 비교 횟수 증가율](/study/diagrams/binary-search-growth.svg)

> 입력 규모 증가 시 선형 탐색보다 비교 횟수가 완만하게 늘어나는 로그 시간 증가 양상

- 정렬 불변식 전제하의 **탐색 후보 구간(Candidate Range) 절반 축소** 메커니즘.
- 데이터 규모 대비 시간 소모가 완만히 늘어나는 **로그 시간($O(\log n)$)** 성능 보장.
- 범위 조건 조회를 위한 **하한(Lower Bound) 및 상한(Upper Bound)** 연산 확장.

#### 한줄 요약

- 입력 데이터 규모 증가 대비 비교 횟수가 완만히 증가하는 로그 시간($O(\log n)$) 탐색 성능 제공.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **임의 접근(Random Access)**: 인덱스를 활용해 배열의 임의 요소에 $O(1)$ 상수 시간에 즉시 접근하는 특성.
- **후보 구간(Candidate Range)**: 목표 키가 존재할 수 있는 유효 인덱스 범위.
- **탐색 방향(Search Direction)**: 대소 비교 결과에 따른 다음 분할 축소 구간선택.

- **키 순서(Key Order)**: 배열 내 원소들이 오름차순 또는 내림차순으로 정렬되어 유지되는 논리적 순서.
</details>

| 구성요소 | 책임 |
|:---|:---|
| 이진 탐색기 | 중앙 키 대소로 **탐색 방향** 결정 |
| 정렬 배열 | **키 순서** 유지 및 **임의 접근** 제공 |
| 후보 구간 | 양 끝 인덱스(low, high) 기반의 유효 탐색 범위 관리 |

#### 한줄 요약

- 탐색 제어 로직, 정렬 배열 데이터, 인덱스 상태의 상호 작용을 통한 탐색 범위 축소 기법.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **중앙 인덱스(Mid Index)**: 현재 탐색 후보 구간의 중심 위치.
- **정수 오버플로(Integer Overflow)**: $low+high$ 합산 시 자료형 최대 범위를 초과하는 현상.
- **후보 경계(Candidate Boundary)**: 탐색 과정에서 갱신되는 $low$, $high$ 인덱스값.

- **목표값 대소 판정(Target Comparison)**: 중앙 원소와 목표값 간의 대소 관계를 비교하여 좌우 탐색 방향을 결정하는 연산.
</details>

```text
탐색 요청
   │
   ▼
후보 구간 유효성
├─ 무효: 미발견 반환
└─ 유효
   │
   ▼
1. 중앙 키 조회
   │
   ▼
2. 목표값 대소 판정
├─ 일치: 위치 반환
└─ 불일치
   │
   ▼
3. 후보 경계 갱신
   │
   └─ 후보 구간 유효성으로 반복
```

**동작 원리**

1. 중앙 키 조회: $low + (high - low) / 2$ 식을 통한 정수 오버플로 방지 중앙 인덱스 계산.
2. 목표값 대소 판정: 목표 키와 중앙 키 간 대소 비교 수행.
3. 후보 경계 갱신: 비교 결과에 따라 한쪽 경계를 옮겨 후보 구간 축소.

#### 한줄 요약

- 중앙 인덱스 계산 및 탐색 경계 갱신을 반복하여 탐색 구간을 축소하는 반복 루프 구조.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **해시 조회(Hash Lookup)**: 해시 함수를 통해 키를 주소로 직접 변환하여 $O(1)$ 시간에 탐색함.
- **해시 충돌(Hash Collision)**: 서로 다른 키가 동일한 해시 버킷 주소로 매핑되는 현상.
- **해시값(Hash Value)**: 해시 함수가 키로부터 산출하며 버킷 인덱스 계산에 쓰는 값.
- **버킷(Bucket)**: 해시 테이블에서 데이터를 보관하는 단위 매핑 공간.
- **범위 조회(Range Query)**: 특정 키 범위를 연속 검색하는 탐색 유형.
- **정렬 유지 비용(Sorting Maintenance Cost)**: 삽입 및 수정 발생 시 배열의 정렬 상태를 보존하는 부하.

</details>

| 탐색 방식 | 이진 탐색 | 선형 탐색 | 해시 조회 |
|:---|:---|:---|:---|
| 적용 기준 | 정렬된 **범위 조회** | 미정렬 소규모 **선형 탐색** | 정확 키 **해시 조회** |
| 핵심 특징 | **이진 탐색**으로 후보 절반 제거 | **선형 탐색**으로 순차 비교 | **해시값**으로 버킷 접근 |
| 한계 | 삽입 시 **정렬 유지 비용** | 입력 증가만큼 비교 증가 | **충돌**•범위 조회 제약 |

#### 한줄 요약

- 정렬 배열의 범위 조회에는 **이진 탐색**, 소규모 미정렬 검색에는 **선형 탐색**, 단일 키 점조회에는 **해시 조회** 적용.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **반열린 구간(Half-Open Interval, $[low, high)$)**: 시작 인덱스는 포함하고 종료 인덱스는 미포함하는 인덱스 설계.
- **비교 함수(Comparator)**: 대소 및 순서를 판단하는 단일화된 연산 체계.
- **배치 정렬(Batch Sorting)**: 무작위 삽입 건을 지연 적재 후 일괄 정렬하여 갱신 비용을 최소화함.
- **균형 탐색 트리(Balanced Search Tree)**: 동적 삽입·삭제 상황에서도 $O(\log n)$ 탐색 높이를 보장하는 트리 구조.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 잦은 삽입의 **정렬 유지 비용**이 조회 이득을 초과 | 갱신 누적 후 **배치 정렬** 또는 **균형 탐색 트리** 적용 | 갱신 빈도에 맞춰 총 처리비용 절감 |
| 중복 키의 **하한**•**상한** 계약이 불명확해 결과 불일치 | **반열린 구간**과 하한•상한 계약 고정 | 중복 구간의 반환 범위 일관성 확보 |
| 큰 중앙 인덱스 합산으로 **정수 오버플로** 발생 | $low+(high-low)/2$ 방식 적용 | 유효 **중앙 인덱스** 산정 |
| 탐색•정렬의 비교 기준 불일치로 누락•오탐 | 정렬과 탐색에 동일 **비교 함수** 적용 | 이진 탐색의 **정렬 불변식** 보장 |

#### 한줄 요약

- 정렬 규칙과 탐색 비교 함수의 일치성을 보장하고, 오버플로 방지식($low + (high - low) / 2$) 적용.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **조회 패턴(Lookup Pattern)**: 단일 키 점조회와 연속 범위 조회 등 서비스 응용의 탐색 요구 형태.

</details>

- 범위 및 경계 조회가 요구되는 데이터는 **이진 탐색**, 단일 점조회 중심은 **해시 조회** 적용.

#### 한줄 요약

- 범위 및 경계 탐색 필요성에 기반한 이진 탐색 및 해시 구조의 선별 적용 체계 적용.
