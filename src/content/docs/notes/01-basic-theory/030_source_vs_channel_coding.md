## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **소스 코딩(Source Coding, 압축)**: 정보원 내부의 통계적/인지적 중복성을 제거하여 데이터 전송량을 엔트로피 한계까지 최소화하는 기술.
- **채널 코딩(Channel Coding, 오류 제어)**: 잡음 채널을 통과할 때 발생하는 비트 반전 오류를 수신단에서 정정할 수 있도록 구조화된 패리티 비트를 추가하는 기술.
- **전체 프레임 디코딩 붕괴(Catastrophic Error Propagation)**: 가변 길이 압축 부호에서 1비트 손상 시 후속 비트열의 경계 동기가 깨져 전체 데이터 복원이 불가능해지는 현상.

</details>

- 정의/개념: 데이터의 통계적 중복성을 제거하는 **소스 코딩(압축)** 및 전송 신뢰성을 위해 잉여 비트를 부가하는 **채널 코딩(오류 제어)**의 변환 체계
- 배경/필요성: 소스 코딩이 중복을 걷어낸 비트열은 남은 비트마다 정보가 몰려 단 1비트 손상으로도 **전체 프레임 디코딩 붕괴**를 부르므로, 압축이 지운 우연한 중복 대신 오류 정정에 쓰도록 계산된 잉여를 채널 코딩이 그 뒤에 다시 붙여 압축과 보호의 책임을 계층으로 분리

#### 한줄 요약

- 둘은 서로 상반된 연산이 아니라, 쓸모없는 중복을 걷어낸 자리에 계산된 중복을 되넣는 한 쌍의 공정이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **섀넌의 소스-채널 분리 정리(Shannon's Separation Theorem)**: 블록 길이가 충분히 길고 지연 시간이 허용될 때, 소스 코딩과 채널 코딩을 독립적으로 각각 최적화해도 결합 최적화와 동일한 이론적 최적 성능을 달성한다는 정리.
- **FEC(Forward Error Correction, 전방 오류 정정)**: 수신 측에서 재전송 요청(ARQ) 없이 수신된 코드워드 자체로 비트 오류를 감지하고 즉시 복원하는 메커니즘.

</details>

- 소스 코딩을 통해 **정보원 엔트로피($H(X)$)** 하한까지 데이터 용량 최소화
- 채널 코딩을 통해 **채널 용량 한계 내 무오류 전송** 달성
- 섀넌의 분리 정리에 기반한 **독립적 모듈화 설계 및 처리 계층 분리**

#### 한줄 요약

- 소스 코딩으로 불필요한 중복을 압축하고, 채널 코딩으로 통제된 오류 정정 잉여를 부가하여 신뢰 전송을 달성

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **소스-채널 코덱 파이프라인**: 소스 부호기(압축) $\to$ 채널 부호기(FEC) $\to$ 변조기 $\to$ 채널 $\to$ 복조기 $\to$ 채널 복호기(에러 정정) $\to$ 소스 복호기(압축 해제).

</details>

```text
[종단간 통신 시스템]
|
+-- [송신단]
|   +-- [소스 부호기]
|   `-- [채널 부호기]
+-- [잡음 채널]
`-- [수신단]
    +-- [채널 복호기]
    `-- [소스 복호기]
```

선의 의미: 가지는 통신 시스템의 포함 관계

| 구성요소 | 책임 |
|:---|:---|
| 소스 부호기 | 통계적/시각적 **중복성 제거 및 데이터 압축** |
| 채널 부호기 | 목표 비트 오류율(BER)에 맞춘 **오류 정정 패리티 비트 삽입** |
| 잡음 채널 | 신호 감쇠 및 열잡음(AWGN)으로 인한 **비트 에러 유입** |
| 채널 복호기 | 패리티 검사 및 반복 복호로 **전송 중 손상된 비트 복원** |
| 소스 복호기 | 정정된 압축 비트열을 역변환하여 **원본 데이터 재구성** |

#### 한줄 요약

- 송신부는 중복을 줄인 뒤 보호 비트를 붙이고, 수신부는 채널 오류를 고친 뒤 압축을 해제

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **복호화 순서의 엄격성**: 수신단에서는 반드시 채널 복호화(에러 정정)를 먼저 완료하여 무오류 비트열을 확보한 후에 소스 복호화(압축 해제)를 진행해야 에러 전파(Error Propagation)를 차단 가능.

</details>

```text
원본 정보원 심볼 (Text / Image / Audio)
   │
   ▼
[ 1. 소스 부호화 ] : Huffman / Arithmetic / H.264 압축 (비트 축소)
   │
   ▼
[ 2. 채널 부호화 ] : LDPC / Turbo / Polar Code 부호화 (패리티 추가)
   │
   ▼
[ 3. 물리 채널 전송 ] : 변조 후 잡음 채널 통과 (QAM / AWGN)
   │
   ▼
[ 4. 채널 복호화 ] : 신드롬 계산 및 LLR 반복 복호로 비트 에러 정정
   │
   ▼
[ 5. 소스 복호화 ] : 오류 정정된 압축 비트열 압축 해제
   │
   ▼
최종 원본 데이터 완벽 복원
```

**동작 원리**

1. **소스 부호화**: 정보원의 상관관계를 분석해 엔트로피 수준으로 데이터 압축
2. **채널 부호화**: 압축된 비트열에 패리티 생성 행렬을 곱해 오류 정정 코드워드 생성
3. **물리 채널 전송**: 변조된 심볼이 잡음 채널을 통과하며 노이즈 및 페이딩 인입
4. **채널 복호화**: 패리티 검사 행렬 기반으로 전송 중 발생한 비트 오류 정정
5. **소스 복호화**: 오류 정정된 비트 스트림을 역압축하여 원본 데이터 복원

#### 한줄 요약

- 송신단에서 압축 후 오류 정정 비트를 부가하고, 수신단에서 채널 오류를 정정한 후 압축을 해제

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **소스 코딩(Source Coding)**: 정보원의 중복성을 제거하여 최소 비트로 압축하는 기법.
- **채널 코딩(Channel Coding)**: 채널 잡음에 대비하여 구조적 패리티를 추가해 오류를 복구하는 기법.

</details>

| 부호화 기법 | 소스 코딩 (Source Coding) | 채널 코딩 (Channel Coding) |
|:---|:---|:---|
| 적용 기준 | 저장 용량 축소 및 대역폭 절감 시 | 잡음 채널 전송 및 무결성 보장 시 |
| 핵심 특징 | **엔트로피 하한선** 기반 데이터 압축 | **채널 용량 한계** 기반 패리티 잉여 부가 |
| 한계 | 1비트 손상 시 **압축 해제 실패/에러 전파** | 패리티 비트 추가로 인한 **전송 대역폭 오버헤드** |

#### 한줄 요약

- 통계적 중복을 제거해 데이터량을 줄이는 것은 소스 코딩, 전송 오류를 복구하도록 보호 비트를 삽입하는 것은 채널 코딩

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **결합 소스-채널 코딩(Joint Source-Channel Coding, JSCC)**: 초저지연(URLLC) 통신처럼 블록 길이가 극히 짧아 분리 정리가 깨지는 환경에서 압축률과 채널 부호율을 동시에 동적 최적화하는 기법.
- **적응형 변조 및 코딩(Adaptive Modulation and Coding, AMC)**: 무선 채널의 신호 품질(CQI)에 따라 변조 차수와 채널 부호율을 실시간으로 가변 제어하는 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 소스 코딩 압축 데이터의 1비트 손상 시 **광범위 복호 전파** | 전방에 강력한 **FEC 채널 코딩** 결합 및 프레임 재동기화 헤더 | 비트 에러 전파 및 전체 파일 크래시 차단 |
| 무선 채널 변동 시 **고정 코드율로 인한 처리량 저하** | 채널 상태(CQI)에 따른 **적응형 변조 및 코딩(AMC)** | 무선 링크 용량 및 실시간 처리량 극대화 |
| 초저지연(URLLC) 환경에서 분리 코딩의 **지연 오버헤드** | 딥러닝 기반 **결합 소스-채널 코딩(Deep JSCC)** 적용 | 짧은 패킷의 단-대-단 복원 품질 향상 |
| 분산 스토리지 노드 장애로 인한 **데이터 유실 위험** | 압축 데이터 대상 **이레이저 코딩(Reed-Solomon EC)** 분산 | 스토리지 용량 절감 및 노드 장애 복원력 확보 |

#### 한줄 요약

- 채널 상태에 따라 AMC 적응형 부호율을 조정하고, 초저지연이 필요하면 Deep JSCC로 소스·채널 결합 부호화를 적용하며, 분산 스토리지 복원력은 이레이저 코딩으로 확보한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **현대 디지털 시스템 아키텍처**: 5G/6G 통신, 비디오 스트리밍(YouTube/Netflix), 클라우드 스토리지는 고효율 비디오 압축(AV1/H.266)과 고성능 채널 코딩(LDPC/Polar/Erasure)을 유기적으로 연계하여 전 세계적 인프라를 운용.

</details>

- 일반 전송은 **분리 부호화**, 초저지연은 **결합 코딩(JSCC)** 선택

#### 한줄 요약

- 큰 블록과 긴 지연을 허용하면 분리 코딩, 짧은 지연이면 결합 코딩을 선택
