## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **회귀 분석(Regression Analysis)**: 입력 변수와 결과 변수 간의 조건부 관계를 모형화하여 영향력 추정 및 값을 예측하는 통계적 분석 기법.
- **독립 변수(Independent Variable)**: 결과를 설명하는 입력 변수(Predictor, Feature).
- **종속 변수(Dependent Variable)**: 예측 대상이 되는 결과 변수(Response, Target).
- **조건부 관계(Conditional Relationship)**: 타 변수를 통제한 상태에서 특정 입력과 결과 사이의 확률적 의존성.
- **변수별 영향력(Feature Importance)**: 입력 단위 변화에 따른 예측값의 변화량 및 방향성.

</details>

- **정의**: 독립변수(X)와 연속형 종속변수(Y) 간의 조건부 평균(Conditional Mean)을 선형 함수로 모형화하여 최적 계수를 추정하는 분석 기법.
- **배경**: 단순 관측 나열로는 미래 예측 및 변수 통제 기반의 변화량 계산 불가.

#### 한줄 요약

- 집 넓이•연식으로 가격표를 맞추듯, 회귀는 연속값을 예측하고 각 입력 계수로 변화량을 설명한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **잔차**: 관측값에서 회귀 모형의 예측값을 뺀 차이다.
- **등분산성**: 입력이나 예측 구간이 달라도 잔차가 흩어진 폭이 일정한 성질이다.
- **조건부 평균**: 특정 입력값이 주어졌을 때 결과 변수의 평균이다.
- **인과관계**: 한 변수의 변화가 다른 변수의 변화를 실제로 일으키는 관계이다.
- **선형성(Linearity)**: 입력과 조건부 평균의 관계가 선형이라는 가정이다.
- **독립성(Independence)**: 잔차들이 서로 영향을 주지 않는다는 가정이다.

</details>

- 독립•종속 변수 사이의 **조건부 관계**를 함수로 모형화한다.
- **잔차 분석** 기반 선형성•독립성•**등분산성**을 검증한다.
- 관측된 **조건부 평균** 추정만으로 인과관계를 보장하지 않는다.

#### 한줄 요약

- 예측선 주변의 점이 한쪽으로 휘거나 부채꼴로 벌어지면 선형성•등분산성 가정이 깨진 것이며, 선이 맞아도 원인 관계까지 증명한 것은 아니다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **회귀 계수**: 다른 입력이 같을 때 입력 한 단위 변화에 따른 예측값의 변화 방향과 크기이다.
- **분산 팽창 계수(Variance Inflation Factor, VIF)**: 입력 변수 간 연관성이 회귀 계수 분산을 키운 정도이다.
- **평균 제곱근 오차(Root Mean Square Error, RMSE)**: 큰 오차에 민감한 제곱 기반 예측 오차 지표이다.
- **평균 절대 오차(Mean Absolute Error, MAE)**: 이상치 영향이 작은 절댓값 기반 예측 오차 지표이다.
- **회귀식**: 입력 변수와 회귀 계수로 결과의 조건부 평균을 계산하는 식이다.

</details>

```text
       [회귀 모형]
         /     \
[모형 진단기]   [성능 평가기]
```

선의 의미: 회귀 모형의 계수•잔차를 모형 진단기가, 검증 예측값을 성능 평가기가 사용하는 정적 의존 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 회귀 모형 | **회귀식•계수** 추정과 예측값 산출 |
| 모형 진단기 | 잔차•**VIF**로 가정 위반 판정 |
| 성능 평가기 | 검증 자료의 **RMSE•MAE** 산출 |

#### 한줄 요약

- 회귀 모형이 계수와 예측값을 만들고, 진단기와 평가기가 잔차 가정과 새 데이터 오차를 각각 확인한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **최소제곱법(Ordinary Least Squares, OLS)**: 잔차 제곱합이 최소인 회귀 계수를 추정하는 방법이다.
- **일반화 오차**: 학습에 사용하지 않은 새 데이터에서 발생하는 예측 오차이다.
- **모형 진단**: 잔차와 공선성 지표로 회귀 가정 위반 여부를 확인하는 과정이다.

</details>

```text
[관측 데이터]
      |
      v
1. 학습•검증 자료 분리
      |
      v
2. OLS 모형 적합
      |
      v
3. 잔차•VIF 진단
      |
      +-- 가정 위반 --> [변수•모형 수정]
      |                         |
      |                         `----> 2로
      v
4. 검증 자료 예측
      |
      v
5. 일반화 오차 평가
      |
      v
[검증된 입력 범위와 회귀 모형]
```

### 동작 원리

- **1. 학습•검증 자료 분리**: 적합과 일반화 평가 자료를 구분한다.
- **2. OLS 모형 적합**: 최소제곱 회귀 계수 산출한다.
- **3. 잔차•VIF 진단**: 회귀 가정과 다중공선성을 판정한다.
- **4. 검증 자료 예측**: 미사용 입력의 예측값 산출한다.
- **5. 일반화 오차 평가**: RMSE•MAE로 예측 성능 판단이다.

#### 한줄 요약

- 모형이 학습선과 계수를 만들면 진단기는 잔차 무늬와 VIF를 보고, 평가기는 보지 않은 데이터의 RMSE•MAE로 새 입력 성능을 확인한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **상관 분석**: 두 변수의 공동 변화 방향과 강도를 측정하지만 예측식이나 인과 방향은 주지 않는 분석이다.
- **다중공선성**: 입력 변수끼리 강하게 연관돼 개별 회귀 계수 추정이 불안정한 상태이다.
- **외삽**: 학습 입력 범위 밖에서도 같은 관계가 이어진다고 가정해 값을 예측하는 일이다.

</details>

| 변수 간 관계 분석 | 회귀 분석 | 상관 분석 |
|:---|:---|:---|
| 적용 기준 | 특정 입력의 **예측값**이 필요할 때 | **연관 방향•강도**만 확인할 때 |
| 핵심 특징 | **회귀식** 계수로 변수별 영향력 산출 | 두 변수의 **공동 변화** 정도 측정 |
| 한계 | **다중공선성**•외삽 시 오차 급증 | **인과관계•예측식** 미제공 |

> 요약: 예측값이 필요하면 **회귀 분석**, 연관 확인이면 **상관 분석**이 핵심이다.

#### 한줄 요약

- 집값 예측식과 넓이 한 단위의 조건부 변화를 알고 싶으면 회귀, 넓이와 가격이 함께 움직이는 정도만 알고 싶으면 상관 분석을 쓴다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **이분산성**: 입력 구간에 따라 잔차 분산이 달라지는 상태이다.
- **강건 표준오차**: 이분산성이 있어도 계수 불확실성을 타당하게 추정하도록 보정한 표준오차이다.
- **릿지 회귀**: 계수 제곱합에 벌점을 부여해 다중공선성에 따른 계수 변동을 줄이는 회귀이다.
- **입력 분포 변화**: 운영 입력의 범위와 빈도가 학습 데이터와 달라지는 현상이다.
- **변수 변환•비선형항**: 입력의 척도를 바꾸거나 제곱•상호작용 항을 추가해 비선형 관계를 표현하는 방법이다.
- **예측구간(Prediction Interval)**: 특정 입력에서 새 관측값이 놓일 것으로 예상하는 구간이다.
- **재학습(Retraining)**: 새 운영 데이터로 회귀 계수와 모형을 다시 추정하는 작업이다.
- **중앙 처리 장치(Central Processing Unit, CPU)**: 서버의 명령 실행과 연산을 담당하는 처리 장치이다.
- **예측 거부**: 입력이 학습 범위를 벗어나 신뢰할 근거가 없을 때 값을 반환하지 않는 정책이다.
- **CPU 사용률**: 측정 구간에서 CPU가 작업을 수행한 시간의 비율이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 비선형•**이분산 잔차** 패턴 | 변수 변환•비선형항•**강건 표준오차** | 가정 위반에 따른 계수 불확실성 완화 |
| **다중공선성**으로 계수 불안정 | VIF 점검•변수 축소•**릿지 회귀** | 회귀 계수 분산 감소 |
| 학습 범위 밖 **외삽** | 입력 범위 감시•**예측 거부** 정책 | 근거 없는 외삽 차단 |
| 운영 **입력 분포 변화** | 잔차•오차 감시와 **재학습** | **일반화 오차** 악화 억제 |
| 오토스케일링의 **CPU 사용률** 예측 | 요청량별 **예측구간**으로 증설 임계값 설정 | 임계 도달 전 서버 용량 확보 |

#### 한줄 요약

- 평균 오차가 작아도 잔차가 부채꼴이거나 운영 입력이 학습 범위 밖이면 예측을 멈추고, 예측구간 상단으로 서버 증설 시점을 잡는다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **검증 오차**: 학습에 쓰지 않은 데이터로 측정한 예측 오차이다.
- **입력 범위**: 회귀 모형이 관계를 학습해 예측 근거를 갖는 독립 변수의 관측 구간이다.
- **잔차 가정**: 잔차의 선형성•독립성•등분산성 등 회귀 추론에 필요한 조건이다.

</details>

- **잔차 가정** 및 **검증 오차(Validation Error)** 분석을 통해 타당성이 입증된 입력 범위(Input Range) 내에서의 예측값 산출 및 모델 운영 적용 체계 적용.
