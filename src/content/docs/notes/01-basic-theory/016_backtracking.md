## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **가지치기(Pruning)**: 유망하지 않은 하위 트리를 즉시 배제하여 탐색 경우의 수를 줄이는 기법.
- **역추적(Backtrack)**: 막다른 경로 도달 시 직전 부모 노드로 되돌아가 다른 후보 경로를 탐색하는 동작.
- **조합 폭발(Combinatorial Explosion)**: 탐색해야 할 후보 경우의 수가 입력 크기에 따라 $O(2^n)$ 또는 $O(n!)$으로 급증하여 자원을 초과하는 현상.

</details>

- 정의/개념: 제약 위반 분기를 **가지치기**하고 이전 상태로 **역추적**하는 탐색 기법
- 배경/필요성: 완전 탐색(Brute Force)의 지수적 상태 공간 폭발($O(2^n), O(n!)$) 한계를 극복하고, 상태 공간 트리(State Space Tree)의 유망성(Promising) 검증과 조기 가지치기(Pruning)를 통해 **제약 충족 문제(CSP)의 유효 해를 신속히 도출**할 필요

#### 한줄 요약

- 탐색 총량을 줄이는 대가로 노드마다 제약 검사 비용을 새로 치르므로, 검사 비용이 잘라낸 분기의 이득을 넘으면 전수 조사와 다를 바 없어진다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **상태 공간 트리(State Space Tree)**: 문제의 부분 해들을 노드로 펼쳐 가능한 모든 선택 경로를 계층적으로 표현한 가상의 트리.
- **유망성(Promising)**: 현재까지 구성된 부분 해가 완성된 유효 해로 확장될 수 있는지 여부.
- **상태 복원(State Backtracking)**: 재귀 호출에서 반환될 때 이전 선택으로 변경되었던 변수 상태를 원래대로 원상 복구하는 동작.

</details>

- **상태 공간 트리**를 깊이 우선 탐색(DFS) 방식으로 순회하며 해를 탐색
- 매 단계마다 **유망성** 검사를 수행해 비유망 분기를 즉각 **가지치기**
- 막다른 경로 도달 시 변수를 되돌리는 **상태 복원** 수행

#### 한줄 요약

- 유망성 검사를 조기 수행할수록 하위 트리의 지수적 탐색 오버헤드를 억제

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **유망성 판정 함수(Promising Function)**: 현재 부분 해가 문제의 제약 조건을 위반하는지 검사하는 불리언 함수.
- **후보 생성기(Candidate Generator)**: 현재 탐색 단계에서 시도할 수 있는 다음 변수값 후보군을 열거하는 모듈.

</details>

```text
[상태 공간 트리 제어기]
|
+-- [유망성 판정기]
+-- [상태 복원기]
`-- [부분 해 저장소]
```

선의 의미: 가지는 제어기의 소유·참조 관계

| 구성요소 | 책임 |
|:---|:---|
| 상태 공간 트리 제어기 | 깊이 우선(DFS) 기반 하향 탐색 및 역추적 복귀 |
| 유망성 판정기 | 제약 조건 위반 여부 검증 및 가지치기 |
| 상태 복원기 | 역추적 시 변수 상태 롤백 수행 |
| 부분 해 저장소 | 현재까지 선택된 유효 결정 경로 보관 |

#### 한줄 요약

- 깊이 우선으로 후보를 할당하고, 유망성 검사 실패 시 변경을 역순으로 복구

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **제약 충족 문제(Constraint Satisfaction Problem, CSP)**: 유한한 변수 집합과 이들이 만족해야 하는 제약 조건들의 집합으로 정의되는 문제.

</details>

```text
탐색 요청 (루트 노드 진입)
   │
   ▼
1. 다음 후보 선택 (Candidate Selection)
   │
   ▼
2. 후보값 적용 (이전 상태 기록)
   │
   ▼
3. 유망성 검사 (Promising Check)
├─ 해 완성: 최종 정답 반환
├─ 비유망 (제약 위반): 5. 상태 복원으로 즉시 이동 (가지치기)
└─ 유망 (미완성)
   │
   ▼
4. 하위 단계 재귀 탐색 (Deepen Search)
   ├─ 정답 발견: 상위로 해 반환
   └─ 하위 탐색 실패
      │
      ▼
5. 상태 원상 복원 (Backtrack / Undo State)
   ├─ 남은 후보 존재: 1. 다음 후보 선택으로 반복
   └─ 후보 소진: 상위 노드로 실패 반환
```

**동작 원리**
1. **다음 후보 선택**: 현재 깊이에서 미시도 후보값 선택
2. **후보값 적용**: 후보를 부분 해에 적용하고 역추적을 위한 이전 상태 보관
3. **유망성 검사**: 제약 조건을 검증하여 위반 시 하위 분기를 버리고 복원으로 이동
4. **하위 단계 재귀 탐색**: 유망한 경우 다음 단계로 재귀 호출을 진행해 심층 탐색
5. **상태 원상 복원**: 하위 탐색 완료 또는 실패 시 변경된 상태를 직전으로 롤백

#### 한줄 요약

- 후보를 적용해 유망성을 판정하고, 유망하면 재귀 확장하며 위반하면 상태를 복구

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **백트래킹(Backtracking)**: 깊이 우선 탐색(DFS)을 진행하다가 제약 조건 위반 시 즉시 상위로 역추적하여 가지치기하는 탐색 기법.
- **완전 탐색(Brute Force)**: 가지치기 없이 가능한 모든 경우의 수를 상태 공간 트리에서 전수 조사하는 기법.
- **분기 한정(Branch and Bound)**: 최적화 문제에서 각 분기 노드의 목적 함수 상한·하한 경계(Bound)를 계산해 최적해가 불가능한 분기를 조기 절단하는 기법.

</details>

| 탐색 기법 | 백트래킹 (Backtracking) | 완전 탐색 (Brute Force) | 분기 한정 (Branch & Bound) |
|:---|:---|:---|:---|
| 적용 기준 | 제약 조건 위반의 **조기 판정** 가능 시 | 후보 수가 극소하여 전수 조사가 가능할 때 | 최적화 문제에서 **목적 함수 경계** 도출 시 |
| 핵심 특징 | **깊이 우선 탐색 및 유망성 검사** 기반 가지치기 | 모든 후보 노드의 단순 전수 검사 | **너비/최우선 탐색 및 경계값 계산** 기반 분기 절단 |
| 한계 | 제약 판정이 늦어질 경우 최악 지수 시간 | 후보 수 증가에 따른 **조합 폭발** | 매 노드마다 하한/상한 **경계 계산 오버헤드** |

#### 한줄 요약

- 제약 충족 문제(CSP)는 백트래킹, 최적화 문제의 경계 탐색은 분기 한정 적용

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **최소 잔여값 휴리스틱(Minimum Remaining Values, MRV)**: 선택 가능한 후보 수가 가장 적은 변수를 먼저 탐색하여 탐색 트리 상단에서 가지치기를 유도하는 기법.
- **명시적 스택(Explicit Stack)**: 깊은 상태 공간 트리 탐색 시 콜 스택 오버플로를 방지하기 위해 힙 메모리 스택으로 변환하는 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 늦은 **가지치기**로 무효 부분해의 하위 조합까지 탐색 | 비용이 낮은 **강한 제약**부터 선행 검사 | 불필요한 **탐색 공간** 대폭 축소 |
| 부분해 상태 복구 누락으로 인한 후속 분기 탐색 오염 발생 | 변경 내역 기록 후 엄격한 **역순 복구** 집행 | 분기별 **상태 독립성** 확보 |
| 비효율적 후보 순서로 같은 해의 탐색 노드 급증 | **최소 잔여값(MRV) 휴리스틱** 적용 | 해 발견 전 탐색 노드 수 최소화 |
| 상태 공간 깊이 증가에 따른 콜 스택 오버플로 발생 | **명시적 힙 스택** 또는 탐색 깊이 제한 적용 | **스택 오버플로** 원천 방지 |

#### 한줄 요약

- 비용이 낮은 강한 제약부터 선행 검사하고, MRV 휴리스틱으로 후보 순서를 최적화하며, 분기 복귀 시 역순 복구를 빠뜨리면 다음 분기 결과가 오염된다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **가지치기(Pruning)**: 부분해 단계에서 제약 위반이 확정된 하위 상태 공간 전체를 탐색하지 않고 차단하여 실질 탐색 노드를 줄이는 기법.

</details>

- NP-난해 제약 충족 문제(CSP, N-Queen, 스도쿠) 및 컴파일러 파싱의 **핵심 탐색 알고리즘**으로 자리잡았으며, 실무에서는 **최소 잔여값 휴리스틱(MRV), 제약 전파(Constraint Propagation) 및 SAT Solver/분기한정(Branch & Bound) 기법과 결합하여 초고속 실용 최적화** 달성

#### 한줄 요약

- 부분해에서 제약 위반을 일찍 판정할수록 백트래킹의 탐색 감축 효과가 커짐
