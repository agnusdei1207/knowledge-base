## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **백트래킹(Backtracking)**: 제약을 어긴 분기를 버리고 이전 선택으로 돌아가 다른 후보를 탐색하는 기법이다.
- **조합 폭발(Combinatorial Explosion)**: 후보 조합이 지수적으로 늘어 실행 가능한 시간이나 메모리를 초과하는 현상이다.
- **제약 위반**: 현재 선택이 문제에서 요구한 조건을 만족하지 못하는 상태이다.

</details>

- 정의/개념: 후보 적용 중 제약 위반을 발견하면 분기를 버리고 이전 선택으로 복귀하는 **백트래킹** 탐색 기법이다.
- 배경/필요성: 제약 충족 문제의 모든 후보 조합을 끝까지 확인하면 경우의 수가 폭발하므로 실패가 확정된 분기를 일찍 제거해야 한다.

#### 한줄 요약

- 상태 공간 트리 탐색 중 제약 조건을 위반하는 유망하지 않은 분기를 가지치기하여 탐색 공간을 줄인다.


## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **상태 공간 트리(State Space Tree)**: 부분해를 노드로 펼쳐 가능한 선택 경로를 표현한 탐색 공간이다.
- **유망성(Promising)**: 현재 부분해가 유효한 완성 해로 확장될 수 있는 성질이다.
- **가지치기(Pruning)**: 해로 확장될 수 없는 분기를 제거해 탐색량을 줄이는 동작이다.
- **역순 복구**: 최근 선택으로 바뀐 상태부터 거꾸로 되돌려 다음 후보의 독립성을 지키는 작업이다.
- **깊이 우선 탐색(Depth-First Search, DFS)**: 한 선택 경로를 끝까지 확장한 뒤 이전 분기로 돌아오는 탐색 방식이다.

</details>

- **상태 공간 트리**를 **깊이 우선**으로 순회하고 상태를 복원한다.
- **유망성** 판정으로 위반 분기 **가지치기**해 탐색량을 축소한다.
- 선택 전 상태를 보존하는 **역순 복구**로 후보 독립성을 유지한다.

#### 한줄 요약

- 유망성 검사를 조기 수행할수록 하위 트리의 지수적 탐색 오버헤드를 억제할 수 있다.



## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **재귀 탐색(Recursive Search)**: 유망한 부분해를 다음 단계 입력으로 삼아 같은 탐색 함수를 다시 호출하는 동작이다.
- **부분해(Partial Solution)**: 일부 변수만 정해져 아직 완성되지 않은 해이다.
- **복구 상태(Restoration State)**: 후보 선택으로 바뀐 값과 순서를 기록해 선택 전 상태로 되돌리는 정보이다.
- **유망성 판정 함수**: 부분해가 유효한 해로 자랄 수 있는지 제약으로 검사하는 함수이다.
- **후보 생성기**: 현재 선택 단계에서 시도할 수 있는 변수값을 열거하는 구성요소이다.

</details>

```text
백트래킹 구조
├─ 재귀 탐색 함수
├─ 후보 생성기
├─ 부분해 저장소
└─ 유망성 판정 함수
```

가지의 의미: 탐색•후보•부분해•유망성 판정의 정적 책임 분리를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 재귀 탐색 함수 | **깊이 우선**으로 부분해 확장•복귀 |
| 후보 생성기 | **후보 생성기**가 현재 단계의 선택값 열거 |
| 부분해 저장소 | 선택 변수값과 **복구 상태** 보관 |
| 유망성 판정 함수 | **제약 위반**으로 분기 확장 판정 |

#### 한줄 요약

- 깊이 우선으로 후보를 할당하고, 유망성 검사 실패 시 변경을 역순으로 복구한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **제약 충족 문제(Constraint Satisfaction Problem, CSP)**: 여러 제약을 모두 만족하는 변수값 조합을 찾는 문제이다.
- **상태 복구**: 재귀 탐색에서 돌아온 뒤 선택으로 바뀐 부분해를 이전 상태로 환원하는 작업이다.

- **다음 후보 선택(Next Candidate Selection)**: 상태 공간 트리에서 다음 탐색할 분기(자식 노드)를 선택하는 단계.
- **후보값•복구 정보 저장(State and Restoration Info Storage)**: 막다른 경로 도달 시 이전 상태로 되돌아가기 위해 현재 선택과 역추적 정보를 스택에 기록하는 과정.
</details>

```text
탐색 요청
   │
   ▼
1. 다음 후보 선택
   │
   ▼
2. 후보값•복구 정보 저장
   │
   ▼
3. 유망성 판정
├─ 완성: 완성 해 반환
├─ 위반: 상태 복구로 이동
└─ 유망•미완성
   └─ 4. 하위 단계 재귀 탐색
      ├─ 해 발견: 완성 해 반환
      └─ 실패: 상태 복구로 이동
   │
   ▼
5. 상태 복구
   ├─ 후보 존재: 다음 후보 선택으로 반복
   └─ 후보 소진: 실패 반환
```

### 동작 원리

1. 다음 후보 선택: 현재 단계에서 아직 시험하지 않은 후보값 하나를 고른다.
2. 후보값•복구 정보 저장: 후보를 부분 해에 적용하면서 원상 복구에 필요한 변경 내역을 함께 기록한다.
3. 유망성 판정: 부분 해가 제약을 위반하면 가지치기하고, 완성되었으면 답으로 기록하며, 그 외에는 재귀 확장한다.
4. 하위 단계 재귀 탐색: 유망하지만 미완성인 부분 해에서 다음 단계의 후보들을 탐색한다.
5. 상태 복구: 하위 탐색이 끝나면 기록한 변경을 역순으로 취소하여 다음 후보가 같은 시작 상태를 사용하게 한다.

#### 한줄 요약

- 후보를 적용해 유망성을 판정하고, 유망하면 재귀 확장하며 위반하면 상태를 복구한다.


## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **완전 탐색(Exhaustive Search)**: 가능한 후보를 모두 생성하고 검사해 해를 찾는 방식이다.
- **분기 한정(Branch and Bound)**: 목적 함수의 경계로 최적값을 개선할 수 없는 분기를 제거하는 방식이다.
- **목적 함수(Objective Function)**: 완성 해의 비용이나 이익을 수치화하는 함수이다.
- **경계(Bound)**: 현재 부분해의 하위 분기에서 얻을 수 있는 최선의 목적값 한계이다.
- **지수 시간(Exponential Time)**: 입력 증가에 따라 실행 단계가 지수적으로 늘어나는 시간복잡도이다.
- **조기 판정**: 부분해가 완성되기 전에 제약 위반 여부를 확인해 하위 분기를 제거하는 판단이다.

- **전수 검사(Exhaustive Search)**: 가지치기(Pruning) 없이 상태 공간 트리의 모든 가능한 후보를 빠짐없이 탐색하는 방식.
</details>

| 탐색 전략 | 백트래킹 | 완전 탐색 | 분기 한정 |
|:---|:---|:---|:---|
| 적용 기준 | 부분해 단계에서 위반 **조기 판정** 가능 | 후보 수가 작아 **완전 탐색** 가능 | **목적 함수** 경계 산출 가능 |
| 핵심 특징 | **제약 위반** 분기 제거 | 모든 후보 **전수 검사** | **경계** 비교로 분기 폐기 |
| 한계 | 제약 판정 지연 시 **지수 시간** 잔존 | 후보 **조합 폭발** | **경계 계산** 오버헤드 |

> 요약: 제약 위반은 백트래킹, 목적값 개선 불가는 **분기 한정**이 핵심이다.

#### 한줄 요약

- 제약 충족 문제(CSP)에서 제약 위반 시 백트래킹, 최적화 문제에서 경계 함수(Bounding Function)로 전역 최적 가능성 상실 시 분기 한정을 적용한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **강한 제약**: 낮은 검사 비용으로 많은 무효 후보를 조기에 제거할 수 있는 조건이다.
- **상태 독립성**: 한 분기에서 바꾼 값이 복구되어 다른 후보의 탐색 결과에 영향을 주지 않는 성질이다.
- **명시적 스택**: 재귀 호출 대신 프로그램이 직접 부분해와 복귀 상태를 넣고 꺼내는 저장 구조이다.
- **탐색 공간**: 후보 선택으로 만들 수 있는 모든 부분해와 완성 해의 집합이다.
- **깊이 한도**: 재귀나 탐색이 진행할 수 있는 최대 단계를 제한한 기준이다.
- **호출 스택(Call Stack)**: 재귀 탐색의 복귀 위치와 부분해 상태를 저장하는 메모리 영역이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 늦은 **가지치기**로 무효 부분해의 하위 조합까지 탐색 | 비용이 낮은 **강한 제약**부터 검사 | 불필요한 **탐색 공간** 축소 |
| 부분해 복구 누락으로 이전 후보의 변경이 다음 후보에 잔존 | 변경 항목 기록 후 **역순 복구** | 분기별 **상태 독립성** 확보 |
| 비효율적 후보 순서로 같은 해의 탐색 노드 급증 | 제약이 많은 변수•값부터 선택 | 해 발견 전 탐색 공간 축소 |
| 큰 상태 공간의 깊은 재귀로 호출 스택 초과 | **깊이 한도** 또는 **명시적 스택** 적용 | 깊은 탐색의 **호출 스택** 초과 방지 |

#### 한줄 요약

- 변경 내역을 역순으로 복구해 각 탐색 분기의 상태 독립성을 보장한다.


## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **적용 조건**: 부분해 단계에서 제약 위반을 판정해 하위 분기를 제거할 수 있는 조건이다.

</details>

- 제약 위반을 **조기 판정**할 수 있으면 **백트래킹**을 적용하고, 목적값 경계가 있으면 분기 한정을 선택한다.

#### 한줄 요약

- 부분해에서 제약 위반을 일찍 판정할수록 백트래킹의 탐색 감축 효과가 커진다.
