## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **전이 학습**: 소스 도메인에서 학습한 지식을 타깃 과제에 재사용하는 학습 방법이다.
- **사전 학습 모델**: 대량 데이터에서 범용 특징을 미리 학습한 모델이다.
- **소스 도메인(Source Domain)**: 지식을 먼저 학습한 데이터 영역이다.
- **타깃 도메인(Target Domain)**: 학습한 지식을 적용할 목표 데이터•과제 영역이다.
- **타깃 라벨**: 전이 학습의 목표 과제에서 각 표본에 부여한 정답값이다.
- **범용 특징**: 여러 과제에 공통으로 재사용할 수 있는 저수준•중간 수준 표현이다.

</details>

- 정의/개념: **전이 학습**은 **사전 학습 모델**이 소스 도메인에서 익힌 가중치와 범용 특징을 **타깃 도메인** 과제의 초기값으로 사용하고 일부 또는 전체를 미세 조정하는 학습 기법이다.
- 배경/필요성: **타깃 라벨**이 적을 때 모든 가중치를 무작위 초기값에서 학습하면 과적합하거나 충분한 특징을 배우지 못할 수 있다.

#### 한줄 요약
- 소스 도메인에서 사전 학습한 범용 특징 가중치를 타깃 도메인 초기값으로 전이하고, 적은 레이블 데이터로 미세 조정하여 타깃 과제를 학습한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **동결 범위**: 사전 학습 가중치 중 학습하지 않고 고정할 계층의 범위이다.
- **도메인 유사성**: 소스 데이터와 타깃 데이터의 분포•과제가 닮은 정도이다.
- **부정적 전이**: 전이 학습으로 타깃 과제 성능이 오히려 낮아지는 현상이다.
- **라벨 데이터**: 입력 표본과 정답값을 함께 가진 학습 데이터이다.

</details>

- **범용 특징** 재사용으로 적은 라벨 데이터의 과적합을 완화한다.
- **동결 범위** 조절로 타깃 과제에 맞는 재학습 계층을 선택한다.
- **도메인 유사성**이 낮을수록 부정적 전이 위험 증가한다.

#### 한줄 요약
- 기성 정장은 체형이 비슷하면 조금만 고쳐도 되지만 체형 차이가 크면 전체를 손봐야 하듯, 도메인 유사성과 라벨 데이터 규모에 따라 동결 범위를 달리한다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **백본**: 입력에서 여러 과제에 재사용할 수 있는 범용 특징을 추출하는 모델 부분이다.
- **태스크 헤드**: 추출한 특징을 타깃 과제의 예측값으로 바꾸는 출력 부분이다.
- **전이 전략**: 도메인 유사성과 라벨 규모에 따라 재학습 범위를 정하는 기준이다.
- **라벨 규모**: 타깃 과제에서 사용할 수 있는 정답 표본의 수이다.
- **타깃 과제 예측값**: 전이한 모델이 목표 분류•회귀 과제에 대해 출력하는 결과값이다.

</details>

```text
             [전이 전략]
                  |
                  |
        [사전 학습 백본] -- [태스크 헤드]
```

선의 의미: 사전 학습 백본과 태스크 헤드는 모델의 정적 결합이고, 전이 전략은 두 구성의 재학습 범위를 규정하는 연결이다.

| 구성요소 | 책임 |
|:---|:---|
| 전이 전략 | **도메인 유사성•라벨 규모**에 따라 재학습 범위 결정 |
| 사전 학습 백본 | 소스 도메인에서 학습한 **범용 특징** 추출 |
| 태스크 헤드 | 범용 특징에서 **타깃 과제 예측값** 출력 |

#### 한줄 요약
- 재단사가 전이 전략표로 기성 정장의 백본을 얼마나 고정할지 정하고, 태스크 헤드를 새 업무용 소매처럼 붙인다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **학습률**: 한 학습 단계에서 가중치를 갱신하는 크기이다.
- **기준 모델**: 전이 효과를 비교하려고 같은 타깃 데이터로 처음부터 학습한 대조 모델이다.
- **미세 조정**: 백본 일부나 전체를 낮은 학습률로 다시 학습하는 방식이다.
- **도메인•라벨 통계**: 소스와 타깃 분포의 유사성 및 타깃 정답 표본 수를 요약한 정보이다.
- **도메인•라벨 조건 분석**: 도메인 유사성과 타깃 라벨 규모를 확인하는 단계이다.
- **초기 전이 전략 선택**: 분석 결과에 따라 특징 추출•미세 조정•처음부터 학습 중 시작 방식을 정하는 단계이다.
- **타깃 과제 학습**: 선택한 동결 범위와 학습률로 목표 과제의 모델을 학습하는 단계이다.
- **기준 모델과 검증 비교**: 전이 모델과 기준 모델의 검증 성능을 비교해 전이 이득을 판정하는 단계이다.
- **전이 전략 조정**: 검증 결과에 따라 동결 해제 범위나 학습 방식을 바꾸는 단계이다.

</details>

```text
[소스•타깃 데이터와 과제]
          |
          v
1. 도메인•라벨 조건 분석
          |
          v
2. 초기 전이 전략 선택
          |
          +-- 유사•소량 --> [백본 동결]
          +-- 차이 존재 --> [부분 미세 조정]
          `-- 저유사•충분 -> [처음부터 학습]
          |
          v
3. 타깃 과제 학습
          |
          v
4. 기준 모델과 검증 비교
          |
          +-- 미달 --> 5. 전이 전략 조정
          |                   |
          |                   `----> 2로
          v
[검증된 타깃 모델]
```

### 동작 원리

- **1. 도메인•라벨 조건 분석**: **도메인•라벨 통계**로 유사성과 라벨 규모를 확인한다.
- **2. 초기 전이 전략 선택**: 특징 추출•미세 조정•신규 학습을 결정한다.
- **3. 타깃 과제 학습**: 동결 범위와 학습률을 적용해 학습한다.
- **4. 기준 모델과 검증 비교**: 전이 이득과 부정적 전이를 판정한다.
- **5. 전이 전략 조정**: 동결 해제 확대 또는 신규 학습으로 전환한다.

#### 한줄 요약
- 먼저 기성 정장의 몸통을 잠그고 새 소매만 맞춘 뒤, 검증 거울에서 어긋나면 몸통의 위쪽 단추부터 푼다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **특징 추출**: 백본을 동결하고 태스크 헤드만 학습하는 방식이다.
- **처음부터 학습**: 사전 학습 가중치 없이 무작위 초기값에서 전체 모델을 학습하는 방식이다.
- **과적합**: 학습 데이터에 지나치게 맞아 새 데이터의 예측 성능이 낮아지는 현상이다.

</details>

| 전이 학습 방식 | 특징 추출 | 미세 조정 | 처음부터 학습 |
|:---|:---|:---|:---|
| 적용 기준 | 도메인이 유사하고 **라벨 데이터**가 적은 경우 | 도메인 차이로 **범용 특징** 조정이 필요한 경우 | 도메인 차이가 크고 **라벨 데이터**가 충분한 경우 |
| 핵심 특징 | 백본을 동결하고 태스크 헤드만 학습 | 백본 일부•전체를 낮은 **학습률**로 갱신 | 무작위 초기값에서 전체 계층 학습 |
| 한계 | 도메인 차이가 크면 고정한 특징의 적합성 저하 | 큰 학습률에 따른 범용 특징 훼손 | 라벨 데이터가 적으면 **과적합**•학습 비용 증가 |

> 요약: **도메인 유사성•라벨 규모**로 범위를 선택한다.

#### 한줄 요약
- 체형이 비슷하고 치수가 적으면 소매만 바꾸고, 차이가 커지면 몸통을 풀며, 원단과 치수가 충분하면 새 정장을 만든다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **점진적 동결 해제**: 출력에 가까운 계층부터 순서대로 가중치를 다시 학습 가능하게 만드는 방법이다.
- **편향 승계**: 사전 학습 데이터의 불균형이나 고정관념이 타깃 모델에도 이어지는 현상이다.
- **검증 성능**: 학습에 직접 쓰지 않은 데이터에서 측정한 일반화 성능이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 낮은 도메인 유사성으로 **부정적 전이** | 처음부터 학습한 **기준 모델**과 검증 성능 비교 | **부정적 전이** 조기 식별 |
| 미세 조정 중 범용 특징 훼손 | 상위 계층부터 **점진적 동결 해제**•낮은 **학습률** 적용 | 기존 표현 보존과 타깃 적응의 균형 |
| 적은 라벨로 백본까지 학습해 **과적합** | **특징 추출**부터 시작하고 데이터 확보 후 범위 확대 | 학습•검증 성능 격차 완화 |
| 사전 학습 데이터의 **편향 승계** | 타깃 분포별 편향 평가•취약 표본 보강 | 집단별 오분류 편중 완화 |

#### 한줄 요약
- 기성 정장의 바깥 부분부터 조금씩 풀어 보듯, 기준 모델과 검증 성능을 비교하며 백본의 동결 범위를 상위 계층부터 단계적으로 줄인다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **검증 향상**: 전이 학습 후 검증셋 지표가 기준 모델보다 좋아진 상태이다.
- **기준 미달**: 전이 모델의 성능이 사전에 정한 목표나 기준 모델보다 낮은 상태이다.

</details>

- 도메인이 유사하고 라벨이 적으면 **특징 추출**, 차이가 있으면 **미세 조정**, 유사성이 낮고 라벨이 충분하면 **처음부터 학습**한다.

#### 한줄 요약
- 동결 범위는 검증 성능이 좋아지는 데까지만 풀고, 기준 모델보다 낮으면 처음부터 학습한다.
