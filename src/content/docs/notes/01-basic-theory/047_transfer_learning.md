## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **태스크 헤드 및 미세조정(Task Head & Fine-Tuning)**: 사전 학습된 백본 끝단에 새로운 분류기를 결합하고 낮은 학습률로 타깃 도메인에 가중치를 적응시키는 기법.
- **과적합 및 연산 비용 폭증(Overfitting & Compute Explosion)**: 소규모 데이터로 수억 개 파라미터를 처음부터 학습시킬 때 모델이 단순 암기하거나 수백 대의 GPU 비용이 낭비되는 한계.

</details>

- 정의/개념: 대규모 소스 도메인에서 사전 학습된 백본의 가중치 지식을 소규모 타깃 과업의 **태스크 헤드 및 미세조정(Fine-Tuning)** 에 전이하는 학습 기법
- 배경/필요성: 도메인 특화 라벨 데이터 부족 환경에서 밑바닥 학습(From Scratch) 시 발생하는 과적합 및 연산 자원 낭비 극복 필요

#### 한줄 요약

- 대규모 데이터로 사전 학습된 모델의 지식을 소량의 타깃 데이터에 전이하여 고성능 모델을 신속히 구축

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **동결(Freezing)**: 사전 학습된 백본 레이어의 가중치를 역전파 갱신 대상에서 제외(`requires_grad=False`)하여 초기 범용 표현을 보존하는 기법.
- **파인튜닝(Fine-Tuning)**: 백본의 일부 또는 전체 레이어의 동결을 해제하고 매우 낮은 학습률($\eta \approx 10^{-5}$)로 타깃 데이터에 적응시키는 기법.

</details>

- 소량의 타깃 데이터에서도 강력한 **일반화 성능 달성**
- 백본 동결부터 전체 미세조정까지의 **유연한 전이 전략**
- 도메인 유사성에 따른 **동결 범위의 차등 결정**

#### 한줄 요약

- 도메인 유사성과 타깃 데이터 규모에 따라 동결 범위를 최적화하여 부정적 전이를 차단

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **태스크 헤드(Task Head)**: 백본의 최종 출력 특징 벡터를 입력받아 타깃 과업의 클래스 수나 회귀 차원에 맞게 출력하는 경량 선형 분류기/회귀기.

</details>

```text
[ 전이 학습 모델 아키텍처 및 전이 전략 ]
 
 [ 사전 학습된 백본 네트워크 (Pre-trained Backbone) ]       [ 신규 태스크 헤드 (Task Head) ]
 ┌─────────────────┬─────────────────┬─────────────────┐   ┌──────────────────────────────┐
 │ 저수준 레이어   │ 중간수준 레이어 │ 고수준 레이어   │──►│ Linear Classifier / Softmax  │
 │ (Edge / Texture)│ (Parts / Shapes)│ (Semantic Feat) │   │ (새로운 타깃 클래스 수 매핑)  │
 └─────────────────┴─────────────────┴─────────────────┘   └──────────────────────────────┘
  ▲                 ▲                 ▲                     ▲
  └── [동결 유지] ──┴── [선택적 해제] ─┴── [미세 조정] ─────┴── [신규 학습 (큰 학습률)]
```

선의 의미: 사전 학습 백본의 계층별 특징(저수준~고수준), 신규 태스크 헤드 및 전이 전략 간의 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 사전 학습 백본 | 소스 데이터 기반 **범용 특징 표현 추출 및 가중치 제공** |
| 신규 태스크 헤드 (Head) | 타깃 과업의 출력 형태(클래스 수 $K$)에 맞춘 **출력 변환 및 신규 학습** |
| 동결 제어기 | 역전파 시 특정 레이어의 **가중치 업데이트 방지(`requires_grad=False`)** |
| 차등 학습률 스케줄러 | 백본에는 극소 학습률, 헤드에는 상대적 고학습률 차등 부여 |

#### 한줄 요약

- 사전 학습 백본이 범용 특징을 추출하고, 신규 태스크 헤드가 타깃 과업의 예측을 수행

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **선별적 2단계 학습(Two-Stage Training)**: 1단계에서 백본을 완전히 동결하고 헤드만 학습시킨 후, 2단계에서 백본 상위 레이어를 동결 해제하여 미세 조정하는 모범 실무 파이프라인.

</details>

```text
타깃 데이터셋 및 사전 학습 모델 인입
   │
   ▼
[ 1. 도메인 유사성 및 타깃 데이터 규모 분석 ]
├─ 유사 도메인 & 극소 데이터 ⟹ [ 2. 전략 A: 특징 추출 (백본 완전 동결 + 헤드만 학습) ]
├─ 유사 도메인 & 대량 데이터 ⟹ [ 2. 전략 B: 전체 미세 조정 (Full Fine-Tuning) ]
├─ 이질 도메인 & 소량 데이터 ⟹ [ 2. 전략 C: 상위 계층 선별적 미세 조정 (Partial FT) ]
└─ 이질 도메인 & 대량 데이터 ⟹ [ 2. 전략 D: 처음부터 무작위 학습 (Train from Scratch) ]
   │
   ▼
[ 3. 1단계: 백본 동결 상태에서 태스크 헤드 워밍업 훈련 ]
   │
   ▼
[ 4. 2단계: 백본 상위 레이어 동결 해제 및 차등 학습률(Discriminative LR) 미세 조정 ]
   │
   ▼
[ 5. 검증셋 평가를 통한 부정적 전이(Negative Transfer) 검증 및 최종 배포 ]
```

**동작 원리**

1. **도메인 및 데이터 분석**: 타깃 도메인 유사도와 라벨 규모를 평가해 전이 전략 결정
2. **태스크 헤드 워밍업**: 백본을 동결한 상태에서 신규 헤드만 1단계 학습
3. **상위 계층 미세 조정**: 백본 상위 레이어 동결 해제 후 차등 학습률로 미세 조정
4. **부정적 전이 검증**: 검증셋 평가를 통한 성능 개선 검증 및 최종 배포

#### 한줄 요약

- 도메인 유사성에 따라 전략을 선택하고, 백본 동결 후 단계적 미세 조정을 수행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **전이 학습 3대 전략**:
  - 특징 추출 (Feature Extraction): 백본 가중치 불변, 헤드만 학습, 초고속, 과적합 제로.
  - 미세 조정 (Fine-Tuning): 백본 가중치 미세 갱신, 도메인 적응력 우수, 과적합 주의.
  - 처음부터 학습 (Train from Scratch): 사전 가중치 미사용, 대규모 데이터와 컴퓨팅 자원 필수.

</details>

| 전이 학습 전략 | 특징 추출 (Feature Extraction) | 미세 조정 (Fine-Tuning) | 처음부터 학습 (Scratch) |
|:---|:---|:---|:---|
| 적용 기준 | **유사 도메인 및 극소량 데이터** | **도메인 차이 존재 및 소~중규모** | 독자 도메인 및 대규모 데이터 |
| 핵심 특징 | **백본 완전 동결 및 헤드만 학습** | **상위/전체 계층 차등 미세 갱신** | 무작위 초기화 후 전체 가중치 학습 |
| 한계 | 도메인 괴리 시 표현력 한계 | 큰 학습률 시 **파멸적 망각 위험** | **데이터 부족 시 심각한 과적합** |

#### 한줄 요약

- 소량 데이터는 특징 추출, 도메인 적응은 미세 조정, 대규모 독자 데이터는 Scratch 학습을 적용

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **파멸적 망각(Catastrophic Forgetting)**: 미세 조정 시 타깃 데이터에 과도하게 최적화되면서 소스 도메인에서 학습했던 중요한 범용 특징 표현을 완전히 소실해 버리는 현상.
- **차등 학습률(Discriminative Learning Rates)**: 백본의 하위 레이어에는 $10^{-6}$, 상위 레이어에는 $10^{-4}$, 헤드에는 $10^{-3}$의 서로 다른 학습률을 계층별로 적용하는 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 미세 조정 시 큰 학습률로 인한 **파멸적 망각(Catastrophic Forgetting)** | 하위층 작은 학습률을 적용하는 **차등 학습률(Discriminative LR)** | 범용 특징 보존 및 타깃 적응 동시 달성 |
| 소스-타깃 도메인 괴리로 인한 **부정적 전이(Negative Transfer)** | **선별적 2단계 학습** 및 Scratch 모델과 성능 대조 | 부정적 전이 발생 시 조기 감지 및 격리 |
| 사전 학습된 파운데이션 모델의 **거대한 파라미터 튜닝 비용** | **LoRA / PEFT(Parameter-Efficient Fine-Tuning)** 적용 | 훈련 파라미터 99% 절감 및 VRAM 절약 |
| 소스 사전 학습 데이터셋에 내재된 **사회적 편향/노이즈 승계** | 타깃 검증 데이터 기반 편향 평가 및 데이터 정제 | 공정성(Fairness) 확보 및 오분류 방지 |

#### 한줄 요약

- 차등 학습률로 사전 학습 지식의 망각을 방지하고, LoRA로 경량 파인튜닝을 수행하며, 선별적 2단계 학습으로 도메인을 적응시키고, 부정적 전이는 모니터링으로 조기 감지한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **현대 딥러닝 패러다임의 근간**: 자연어 처리(LLM: LLaMA/GPT), 컴퓨터 비전(CLIP/ResNet), 음성(Whisper) 등 현대 모든 AI 시스템은 거대 파운데이션 모델을 사전 학습한 후 다운스트림에 전이/파인튜닝하는 아키텍처가 표준.

</details>

- 소량 라벨은 **특징 추출**, 도메인 갭 존재 시 **미세 조정**, 대용량은 Scratch 선택

#### 한줄 요약

- 도메인 유사성과 라벨 규모에 따라 동결 범위를 최적화하고 차등 학습률로 안정적 전이를 달성
