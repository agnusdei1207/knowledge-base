## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **태스크 헤드 및 미세조정(Task Head & Fine-Tuning)**: 사전 학습된 백본 끝단에 새로운 분류기를 결합하고 낮은 학습률로 타깃 도메인에 가중치를 적응시키는 기법.
- **과적합 및 연산 비용 폭증(Overfitting & Compute Explosion)**: 소규모 데이터로 수억 개 파라미터를 처음부터 학습시킬 때 모델이 단순 암기하거나 수백 대의 GPU 비용이 낭비되는 한계.

</details>

- 정의/개념: 대규모 소스 도메인에서 사전 학습된 백본의 가중치 지식을 소규모 타깃 과업의 **태스크 헤드 및 미세조정**을 통해 전이하는 학습 기법
- 배경/필요성: 타깃 도메인의 정답 레이블 부족과 초대규모 신경망의 무작위 초기화 학습에 따른 **연산 비용 낭비 및 과적합 발생 한계**

#### 한줄 요약

- 한 번 치른 사전 학습 비용을 여러 과업이 나눠 갚는 구조이므로, 소스와 타깃 도메인이 멀수록 이득 대신 부정적 전이만 남는다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **동결(Freezing)**: 사전 학습된 백본 레이어의 가중치를 역전파 갱신 대상에서 제외(`requires_grad=False`)하여 초기 범용 표현을 보존하는 기법.
- **파인튜닝(Fine-Tuning)**: 백본의 일부 또는 전체 레이어의 동결을 해제하고 매우 낮은 학습률($\eta \approx 10^{-5}$)로 타깃 데이터에 적응시키는 기법.

</details>

- 소량의 타깃 데이터에서도 강력한 **일반화 성능 달성**
- 백본 동결부터 전체 미세조정까지의 **유연한 전이 전략**
- 도메인 유사성에 따른 **동결 범위의 차등 결정**

#### 한줄 요약

- 도메인 유사성과 타깃 데이터 규모에 따라 동결 범위를 최적화하여 부정적 전이를 차단

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **태스크 헤드(Task Head)**: 백본의 최종 출력 특징 벡터를 입력받아 타깃 과업의 클래스 수나 회귀 차원에 맞게 출력하는 경량 선형 분류기/회귀기.

</details>

```text
+-----------------------------------------------------------------------------+
|                        전이 학습 신경망 아키텍처                            |
+-----------------------------------------------------------------------------+
|  [사전 학습 백본 네트워크] --> 대규모 데이터(ImageNet/웹말뭉치) 사전 학습   |
|     |                                                                       |
|     +---> [저수준 계층]    --> 엣지/선/원초적 형태 범용 특징 추출 (완전 동결)|
|     |                                                                       |
|     +---> [고수준 계층]    --> 추상 의미 특징 추출 (선별적 미세 조정)       |
|          |                                                                  |
|          v                                                                  |
|  [신규 태스크 헤드 모듈]   --> 타깃 도메인 맞춤 선형 분류기/회귀기 (신규 학습)|
+-----------------------------------------------------------------------------+
```

선의 의미: 실선 박스는 전이 학습을 구성하는 백본 계층과 타깃 헤드 모듈을 나타내며, 화살표는 저수준 범용 특징에서 고수준 도메인 특화 특징 및 최종 출력으로 이어지는 신호 흐름을 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 사전 학습 백본 | 소스 데이터에서 **범용 특징** 추출 |
| 신규 태스크 헤드 | 타깃 과업에 맞는 **예측값** 출력 |
| 동결 제어 | 선택 계층의 **가중치 갱신** 제외 |
| 차등 학습률 | 계층별 학습률로 **미세 조정 범위** 제어 |

#### 한줄 요약

- 사전 학습 백본이 범용 특징을 추출하고, 신규 태스크 헤드가 타깃 과업의 예측을 수행

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **선별적 2단계 학습(Two-Stage Training)**: 1단계에서 백본을 완전히 동결하고 헤드만 학습시킨 후, 2단계에서 백본 상위 레이어를 동결 해제하여 미세 조정하는 모범 실무 파이프라인.

</details>

```text
타깃 데이터셋 및 사전 학습 모델 인입
   |
   v
[ 1. 도메인 유사성 및 데이터 규모 분석 ]
   |
   +---> 유사 도메인 & 극소 데이터 : [ 특징 추출 (백본 동결 + 헤드만 학습) ]
   |
   +---> 유사 도메인 & 대량 데이터 : [ 전체 미세 조정 (Full Fine-Tuning) ]
   |
   +---> 이질 도메인 & 소량 데이터 : [ 상위 계층 선별적 미세 조정 (Partial FT) ]
   |
   +---> 이질 도메인 & 대량 데이터 : [ 처음부터 학습 (Train from Scratch) ]
   |
   v
[ 2. 태스크 헤드 워밍업 훈련 ] : 1단계 백본 동결 상태에서 신규 헤드만 학습
   |
   v
[ 3. 상위 계층 선별적 미세 조정 ] : 2단계 백본 상위 레이어 동결 해제 및 차등 학습률 적용
   |
   v
[ 4. 부정적 전이 검증 ] : Scratch 기준 모델과 성능 대조
```

분기 결과: 사전 학습 데이터와의 도메인 유사도와 타깃 라벨 데이터 규모에 따라 백본 동결 특징 추출, 선별적 미세 조정, 전체 미세 조정 중 최적 학습 경로로 분기한다.

**동작 원리**:
1. **도메인 유사성 및 데이터 규모 분석**: 타깃 데이터의 도메인 정렬도와 수집 규모를 평가하여 백본 동결 범위와 전이 학습 전략을 확정한다.
2. **태스크 헤드 워밍업 훈련**: 1단계에서 사전 학습 백본을 완전히 동결(Freeze)하고 무작위 초기화된 신규 분류 헤드만을 학습시킨다.
3. **상위 계층 선별적 미세 조정**: 헤드가 안정화된 후 2단계에서 백본 최상위 레이어의 동결을 해제하고 하위 레이어보다 10~100배 작은 차등 학습률로 미세 조정한다.
4. **부정적 전이 검증**: 무작위 초기화(Scratch) 기준 모델과의 교차 검증을 통해 부정적 전이(Negative Transfer) 발생 여부를 확인하고 가중치를 최종 확정한다.

#### 한줄 요약

- 도메인 유사성에 따라 전략을 선택하고, 백본 동결 후 단계적 미세 조정을 수행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **특징 추출(Feature Extraction)**: 백본 가중치를 완전히 고정하고 헤드만 학습하는 전략.
- **미세 조정(Fine-Tuning)**: 백본의 상위 또는 전체 계층을 낮은 학습률로 타깃 도메인에 적응시키는 전략.
- **처음부터 학습(Train from Scratch)**: 사전 가중치 없이 무작위 초기화 상태에서 전체를 학습하는 전략.

</details>

| 전이 학습 전략 | 특징 추출 (Feature Extraction) | 미세 조정 (Fine-Tuning) | 처음부터 학습 (Scratch) |
|:---|:---|:---|:---|
| 적용 기준 | **유사 도메인 및 극소량 데이터** | **도메인 차이 존재 및 소~중규모** | 독자 도메인 및 대규모 데이터 |
| 핵심 특징 | **백본 완전 동결 및 헤드만 학습** | **상위/전체 계층 차등 미세 갱신** | 무작위 초기화 후 전체 가중치 학습 |
| 한계 | 도메인 괴리 시 표현력 한계 | 큰 학습률 시 **파멸적 망각 위험** | **데이터 부족 시 심각한 과적합** |

#### 한줄 요약

- 소량 데이터는 특징 추출, 도메인 적응은 미세 조정, 대규모 독자 데이터는 Scratch 학습을 적용

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **파멸적 망각(Catastrophic Forgetting)**: 미세 조정 시 타깃 데이터에 과도하게 최적화되면서 소스 도메인에서 학습했던 중요한 범용 특징 표현을 완전히 소실해 버리는 현상.
- **차등 학습률(Discriminative Learning Rates)**: 백본의 하위 레이어에는 $10^{-6}$, 상위 레이어에는 $10^{-4}$, 헤드에는 $10^{-3}$의 서로 다른 학습률을 계층별로 적용하는 기법.
- **매개변수 효율적 미세조정(PEFT / LoRA)**: 사전 학습 모델의 가중치를 고정하고 저랭크(Low-Rank) 어댑터 행렬만 학습하여 GPU 메모리와 파라미터를 대폭 절감하는 파인튜닝 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 미세 조정 시 큰 학습률로 인한 **파멸적 망각(Catastrophic Forgetting)** | 하위층 작은 학습률을 적용하는 **차등 학습률(Discriminative LR)** | 범용 특징 보존 및 타깃 적응 동시 달성 |
| 소스-타깃 도메인 괴리로 인한 **부정적 전이(Negative Transfer)** | **선별적 2단계 학습** 및 Scratch 모델과 성능 대조 | 부정적 전이 발생 시 조기 감지 및 격리 |
| 사전 학습된 파운데이션 모델의 **거대한 파라미터 튜닝 비용** | **LoRA / PEFT(Parameter-Efficient Fine-Tuning)** 적용 | 훈련 파라미터 99% 절감 및 VRAM 절약 |
| 소스 사전 학습 데이터셋에 내재된 **사회적 편향/노이즈 승계** | 타깃 검증 데이터 기반 편향 평가 및 데이터 정제 | 공정성(Fairness) 확보 및 오분류 방지 |

#### 한줄 요약

- 차등 학습률로 사전 학습 지식의 망각을 방지하고, LoRA로 경량 파인튜닝을 수행하며, 선별적 2단계 학습으로 도메인을 적응시키고, 부정적 전이는 모니터링으로 조기 감지한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **현대 딥러닝 패러다임의 근간**: 자연어 처리(LLM: LLaMA/GPT), 컴퓨터 비전(CLIP/ResNet), 음성(Whisper) 등 현대 모든 AI 시스템은 거대 파운데이션 모델을 사전 학습한 후 다운스트림에 전이/파인튜닝하는 아키텍처가 표준.

</details>

- 현대 초거대 파운데이션 모델(LLM, Vision Foundation Model) 및 다운스트림 산업용 AI 적용의 **핵심 학습 패러다임**으로 자리잡았으며, 실무에서는 **파멸적 망각(Catastrophic Forgetting) 방지를 위한 차등 학습률(Discriminative LR) 및 LoRA/QLoRA 기반 매개변수 효율적 미세조정(PEFT)**을 통해 최소 자원으로 최대 성능을 구현

#### 한줄 요약

- 도메인 유사성과 라벨 규모에 따라 동결 범위를 최적화하고 차등 학습률로 안정적 전이를 달성
