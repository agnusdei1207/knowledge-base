## Ⅰ. 개요

<details>
<summary>용어 설명</summary>

- **튜링 머신(Turing Machine)**: 무한 테이프의 기호를 읽고 쓰는 헤드와 상태 전이 규칙으로 계산을 표현하는 추상 기계이다.
- **계산 가능성**: 주어진 문제를 유한한 알고리즘 절차로 해결할 수 있는 성질이다.
- **추상 계산 모델**: 실제 하드웨어와 무관하게 계산 절차와 한계를 수학적으로 표현한 모델이다.

</details>

- 정의/개념: 전이 규칙에 따라 테이프를 읽고 쓰며 헤드를 이동해 계산을 표현하는 **튜링 머신** 추상 모델이다.
- 배경/필요성: 임의의 문제에 대해 알고리즘적 계산 가능 여부와 판정 불가능 한계를 수학적으로 입증할 추상 계산 모델이 요구된다.

#### 한줄 요약

- 무한 테이프, 읽기·쓰기 헤드, 유한 상태 제어부 및 전이 함수 $\delta: Q \times \Gamma \rightarrow Q \times \Gamma \times \{L, R\}$로 알고리즘적 계산 가능성의 한계를 정의한다.

## Ⅱ. 특징

<details>
<summary>용어 설명</summary>

- **튜링 완전(Turing Complete)**: 충분한 시간과 메모리가 있으면 튜링 머신의 모든 계산을 모사할 수 있는 성질이다.
- **정지 문제(Halting Problem)**: 임의 프로그램이 입력에서 정지하는지를 모든 경우에 판정할 수 없는 문제이다.
- **결정 가능 언어**: 모든 입력에서 정지하며 소속 여부를 판정할 수 있는 언어이다.
- **테이프(Tape)**: 기호를 읽고 쓸 수 있는 칸이 양방향으로 이어진 튜링 머신의 기억장치이다.
- **비결정성**: 한 상태와 입력에서 가능한 다음 동작이 여러 개인 계산 모델의 성질이다.

</details>

- 유한 제어부와 무한 **테이프**로 범용 계산을 모사하는 **튜링 완전성**이 핵심이다.
- 다중 테이프•비결정성 변형과 **계산 가능 범위** 동일이 핵심이다.
- **결정 가능** 범위 밖에는 **정지 문제** 같은 판정 불가 문제 존재가 핵심이다.

#### 한줄 요약

- 처치-튜링 명제에 따라 다중 테이프 및 비결정적 튜링 머신의 계산 능력은 단일 테이프 결정적 튜링 머신과 등가이며, 정지 문제로 판정 불능성을 입증한다.


## Ⅲ. 구조 및 구성요소

<details>
<summary>용어 설명</summary>

- **전이 함수 $\delta$**: 현재 상태와 읽은 기호로 다음 상태•기록 기호•이동 방향을 결정하는 함수이다.
- **헤드(Head)**: 현재 테이프 칸을 읽고 쓰며 좌우로 이동하는 장치이다.
- **테이프 알파벳 $\Gamma$**: 테이프에 기록할 수 있는 모든 기호의 집합이다.
- **정지 상태(Halting State)**: 계산을 끝내고 입력의 수용이나 거부를 확정하는 상태이다.
- **상태 제어부**: 시작 상태에서 현재 상태를 유지하고 수용•거부 상태 도달을 판정하는 부분이다.

</details>

```text
튜링 머신 구조
├─ 상태 제어부
├─ 전이 함수
├─ 헤드
└─ 테이프
```

가지의 의미: 상태 유지•행동 결정•기호 접근•저장 책임을 나눈 구조다.

| 구성요소 | 책임 |
|:---|:---|
| 상태 제어부 | 시작•현재•**정지 상태** 유지 |
| 전이 함수 | **전이 함수 $\delta$**로 다음 행동 결정 |
| 헤드 | **헤드**가 현재 칸 읽기•쓰기와 좌우 이동 수행 |
| 테이프 | **테이프 알파벳 $\Gamma$** 기호의 무한 저장 공간 |

#### 한줄 요약

- 상태 제어부와 전이 함수가 다음 행동을 정하고, 헤드가 테이프의 기호를 바꾸며 좌우로 이동한다.

## Ⅳ. 흐름도

<details>
<summary>용어 설명</summary>

- **현재 기호**: 헤드가 위치한 테이프 칸에 기록된 기호이다.
- **기록 지시**: 현재 테이프 칸에 쓸 기호를 지정한 전이 결과이다.
- **이동 지시**: 헤드가 움직일 좌우 방향을 지정한 전이 결과이다.

</details>

```text
입력 문자열을 테이프에 배치
        │
        ▼
1. 현재 기호 읽기
        │
        ▼
2. 전이 규칙 조회
        ├─ 규칙 없음: 거부
        └─ 규칙 있음
             │
             ▼
     3. 기호 기록과 헤드 이동
             │
             ▼
     4. 다음 상태 갱신
             ├─ 정지 상태: 수용 또는 거부
             └─ 실행 상태: 다음 기호 읽기
```

### 동작 원리

- **1. 현재 기호 읽기**: 헤드 위치의 테이프 기호를 확인한다.
- **2. 전이 규칙 조회**: 현재 상태•기호에 맞는 행동을 결정한다.
- **3. 기호 기록과 헤드 이동**: 현재 칸 갱신 후 좌우 이동이다.
- **4. 다음 상태 갱신**: 상태 변경과 정지 여부를 판정한다.

#### 한줄 요약

- 헤드 읽기 $\rightarrow$ 전이표 조회 $\rightarrow$ 기호 기록 및 헤드 이동(L/R) $\rightarrow$ 다음 상태 갱신 과정을 정지 상태 도달 시까지 반복 수행한다.

## Ⅴ. 종류 및 비교

<details>
<summary>용어 설명</summary>

- **유한 오토마타(Finite Automaton, FA)**: 별도 기억장치 없이 유한 상태만으로 정규 언어를 인식하는 모델이다.
- **푸시다운 오토마타(Pushdown Automaton, PDA)**: 스택을 사용해 중첩 구조를 포함한 문맥 자유 언어를 인식하는 모델이다.
- **중첩 구문**: 괄호나 블록처럼 같은 구조가 내부에 임의 깊이로 포함되는 구문이다.
- **제어 상태**: 지금까지 읽은 입력 이력을 유한한 상태 하나로 요약한 값이다.
- **스택 최상단**: 푸시다운 오토마타가 스택에서 읽고 쓰는 유일한 접근 위치이다.
- **문맥 의존 언어(Context-Sensitive Language)**: 생성 규칙 적용이 주변 기호의 문맥에 의존하는 언어이다.

</details>

| 계산 모델 | 튜링 머신 | 푸시다운 오토마타 | 유한 오토마타 |
|:---|:---|:---|:---|
| 적용 기준 | **계산 가능성** 분석 | 괄호•블록 등 **중첩 구문** | 토큰•**제어 상태** 판별 |
| 핵심 특징 | **무한 테이프** 양방향 읽기•쓰기 | **스택 최상단**만 접근 | **유한 상태**만 유지 |
| 한계 | **정지 문제** 판정 불가 | **문맥 의존** 언어 인식 불가 | 기억 장치 부재로 **재귀 구조** 미인식 |

#### 한줄 요약

- 정규 언어는 유한 상태, 중첩 구문은 스택, 범용 계산은 읽기•쓰기 테이프를 사용한다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>용어 설명</summary>

- **튜링 인식 가능 언어**: 소속 입력은 정지해 수용하지만 비소속 입력에서는 멈추지 않을 수 있는 언어이다.
- **샌드박스(Sandbox)**: 실행 시간•메모리•입출력 권한을 제한해 프로그램을 격리하는 환경이다.
- **초과 정책**: 프로그램이 단계 수나 메모리 상한을 넘었을 때 중단•실패로 처리하는 운영 규칙이다.
- **단계 수 제한**: 계산이 수행할 수 있는 전이 횟수에 둔 운영 상한이다.
- **입출력 권한**: 프로그램이 접근할 수 있는 파일•장치•통신 범위를 정한 허용 규칙이다.
- **무한 실행**: 프로그램이 정지 상태에 도달하지 않고 전이를 계속 반복하는 상태이다.
- **메모리 상한**: 프로그램 실행에 허용하는 최대 메모리 용량이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 프로그램 **정지 여부** 사전 판정 불가 | 실행 시간•**단계 수 제한** | **무한 실행** 차단 |
| 무한 테이프 추상화와 **메모리 상한** 차이 | 메모리 상한과 **초과 정책** 정의 | 실행의 자원 고갈 방지 |
| **인식•결정 가능** 혼동 | 비소속 입력의 정지 여부 증명 | 튜링 인식 가능•결정 가능 언어 구분 |
| 범용 계산의 **입출력 권한** 남용 | **샌드박스**와 입출력 권한 최소화 | 시스템 영향 범위 격리 |

#### 한줄 요약

- 정지 여부를 일반적으로 판정할 수 없으므로 실행 시간•메모리•권한 한도를 강제한다.

## Ⅶ. 결론

<details>
<summary>용어 설명</summary>

- **운영 한계**: 범용 계산 실행에 허용하는 시간•메모리•권한의 최대 범위이다.
- **기억 구조**: 계산 모델이 입력 이력을 보존하는 유한 상태•스택•테이프 구조이다.

</details>

- **기억 구조**는 정규 FA•중첩 PDA•범용 튜링 머신을, **운영 한계**는 시간•메모리•권한을 결정한다.

#### 한줄 요약

- 범용 계산은 샌드박스에서 실행하고 시간•메모리•입출력 권한 한도를 강제한다.
