## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **점근적 상한(Asymptotic Upper Bound)**: 입력 크기 $n$이 특정 기준점 $n_0$ 이상으로 커질 때 연산 비용이 기준 함수의 상수배 $c \cdot g(n)$를 초과하지 않는 수학적 한계선.
- **비용 확장성(Cost Scalability)**: 입력 규모 증가에 따라 연산 횟수와 시스템 자원 소모량이 늘어나는 점근적 증가 추세.

</details>

- 정의/개념: 입력 크기 $n$이 증가할 때 연산 비용 함수 $T(n)$이 초과하지 않는 **점근적 상한**을 수식화하는 수학적 복잡도 해석 모델
- 배경/필요성: 프로그래밍 언어, 컴파일러 최적화, CPU 클록 등 실행 환경별 미세 차이에 따른 하드웨어 종속성을 배제하고, 입력 데이터 증가에 따른 알고리즘의 **순수 연산 증가율의 점근적 상한(Asymptotic Upper Bound)을 엄밀하게 비교/검증**할 필요성 대두

#### 한줄 요약

- 입력이 충분히 커지면 비용 함수가 넘지 않는 증가율의 상한을 나타낸다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **지배항(Dominant Term)**: 입력 크기가 무한히 증가할 때 최고차 차수로서 비용 증가율을 결정하는 대표 항.
- **점근 추상화(Asymptotic Abstraction)**: 상수 계수와 하위 차수 항을 배제하고 최고차 항 기반의 비례 추세를 추출하는 기법.
- **상한 증인(Witness)**: 빅오 정의 성립 조건인 양의 상수 배율 $c$와 기준점 $n_0$의 순서쌍 $(c, n_0)$.

</details>

![비용 함수와 빅오 점근 상한](/study/diagrams/big-o-upper-bound.svg)

> 파란 $T(n)=n^2+2n$이 $n_0=2$부터 $2n^2$ 이하로 유효한 상한증인 기반 점근 상한 형성 양상

- 상수·하위항을 제외한 **지배항** 중심 차수 분류로 부차적 요소에 의한 성능 분석 왜곡 방지
- 시스템 간 상수 계수 차이를 배제하는 **점근 추상화** 기반 알고리즘 고유의 효율성 비교
- 양의 상수와 기준점 조합 기반의 **상한 증인** 산정을 통해 수학적으로 엄밀한 성능 상한 검증

#### 한줄 요약

- 초기 입력 구간과 상수 차이를 제외하고 장기 증가율의 상한을 비교한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **비용 함수 $T(n)$(Cost Function $T(n)$)**: 입력 크기 $n$에 대해 알고리즘이 실행하는 기본 연산 횟수의 수학적 표현.
- **기준 함수 $g(n)$(Reference Function $g(n)$)**: 비용 함수의 점근적 증가율 비교 대상이 되는 표준 함수.

</details>

```text
[빅오 판정 관계]
 ├─ 비용 함수 T(n): 분석 대상
 ├─ 기준 함수 g(n): 증가율 비교 기준
 ├─ 상한 증인 (c, n₀): 배율·기준점
 └─ 상한 부등식: T(n) ≤ c·g(n)
```

선의 의미: 가지는 빅오 판정을 구성하는 수학적 요소의 소속 관계

| 구성요소 | 책임 |
|:---|:---|
| 비용 함수 $T(n)$ | 기본 연산 횟수를 **비용 함수** 기반 표현 |
| 기준 함수 $g(n)$ | 증가율을 비교할 **기준 함수** 후보 표현 |
| 상한 증인 $c,n_0$ | **상한 증인** 배율 및 기준점 지정 |
| 점근 상한 부등식 | 기준점 이후 모든 입력의 **점근 상한** 표현 |

#### 한줄 요약

- 비용 함수가 기준 함수의 상수배 이하가 되는 배율과 기준점이 존재해야 한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **양의 상수 $c$(Positive Constant $c$)**: 기준 함수를 확대하여 비용 함수의 최고 상한선으로 수용하는 조정 배율.
- **기준점 $n_0$(Threshold $n_0$)**: 점근 상한 부등식이 이후 모든 입력 조건에서 지속 성립하는 최소 입력 크기.

</details>

```text
[실행 비용 함수 T(n) 도출]
          │
          ▼
1. 지배항 추출 ──> 상수 및 저차항 제거 후 최고차 증가율 분리
          │
          ▼
2. 기준 함수 선정 ──> 지배항과 동일 차수의 표준 함수 g(n) 결정
          │
          ▼
3. 상한 증인 탐색 ──> 부등식을 만족하는 양의 상수 c > 0 및 기준점 n0 선정
          │
          ▼
4. 부등식 성립 증명 ──> ∀n ≥ n0 구간에서 T(n) ≤ c·g(n) 점근 상한 확정
```

$$
0 \le T(n) \le c \cdot g(n) \quad (n \ge n_0,\ c > 0)
$$

**동작 원리**
1. **지배항 추출**: 비용 함수에서 상수·저차항을 제거하고 최고차 증가율 분리
2. **기준 함수 선정**: 지배항과 동등한 차수의 **기준 함수** $g(n)$ 결정
3. **상한 증인 탐색**: 부등식을 만족하는 **양의 상수 $c$** 및 **기준점 $n_0$** 쌍 도출
4. **부등식 성립 증명**: $n \ge n_0$ 구간에서 $T(n) \le c \cdot g(n)$ 증명 및 **점근 상한** 확정

#### 한줄 요약

- 지배항과 같은 차수의 기준 함수를 고르고 유효한 상한 증인으로 부등식을 증명한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **빅세타(Big-Theta Notation, $\Theta$)**: 점근적 상한과 하한을 동시에 한정하여 정확한 차수를 보증하는 표기법.
- **빅오메가(Big-Omega Notation, $\Omega$)**: 알고리즘 비용 증가율의 점근적 하한 경계를 표기하는 표기법.
- **느슨한 상한(Loose Upper Bound)**: 실질 최고차 증가율보다 과도하게 높은 차수로 설정된 비효율적 상한 표기.

</details>

| 표기법 | 빅오 $O(g(n))$ | 빅세타 $\Theta(g(n))$ | 빅오메가 $\Omega(g(n))$ |
|:---|:---|:---|:---|
| 적용 기준 | 증가율의 **점근 상한** 한정 필요할 때 | 정확한 **점근 차수** 필요할 때 | 증가율의 **점근 하한** 한정 필요할 때 |
| 핵심 특징 | 기준 함수 이하로 상한 제한 | 상한•하한을 같은 함수로 제한 | 기준 함수 이상으로 하한 제한 |
| 한계 | **느슨한 상한**이면 정확한 차수 은폐 | 동일한 상•하한 증명 수식 필수 | **점근 상한** 판단 불가 |

#### 한줄 요약

- 빅오는 상한, 빅오메가는 하한, 빅세타는 같은 함수로 상·하한을 함께 나타낸다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **상수 비용(Constant Cost)**: 점근 차수 표기에서는 소거되나 실제 런타임 응답시간에 유의미한 영향력을 행사하는 고정 오버헤드.
- **입력 사례(Input Case)**: 동일 데이터 규모 내 조건 구성에 따른 최선·평균·최악 실행 상태 분류.
- **실측값(Empirical Measurement)**: 이론적 점근 표기 외에 실제 운영 하드웨어 환경에서 측정한 런타임 실행 시간 및 메모리 소비량.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **느슨한 상한** 기반 증가율 격차 은폐 | 성립하는 가장 낮은 **점근 차수** 및 증인 제시 | 후보 간 점근 차수 명확화 |
| 같은 차수에서 **상수 비용** 생략으로 응답시간 역전 | 목표 입력 구간의 동일 환경 **실측값** 병행 | 운영 구간 실측 오차 최소화 |
| **입력 사례** 및 점근 표기 혼동으로 최악 사례를 빅오로 오인 | 최선·평균·최악 조건과 상·하한 표기 분리 | 입력 조건별 분석 신뢰도 확보 |

#### 한줄 요약

- 느슨한 상한 대신 가장 낮은 차수를 증명하고, 동일 차수 간에는 실측 벤치마크로 후보를 가리며, 입력 사례와 점근 표기를 혼동하지 않는다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **성능 역전(Performance Crossover)**: 동일 점근 차수 알고리즘 간 상수 계수 차이로 인해 특정 입력 규모에서 실행 시간 우열이 뒤바뀌는 현상.

</details>

- 알고리즘의 최악/평균 수행 성능을 보증하는 **전산학 표준 복잡도 표기 체계**로 확립되었으며, 실무에서는 점근적 상한 $O(g(n))$ 분석을 선행한 후 **CPU 캐시 라인 친화도, SIMD 벡터화 및 상수 오버헤드(Constant Factor)를 고려한 하드웨어 친화적 알고리즘 최적화**와 병행 적용

#### 한줄 요약

- 점근 차수가 다르면 낮은 차수가 유리하고, 같은 차수면 운영 환경 실측으로 상수 비용까지 비교해야 최적 알고리즘을 고를 수 있다.
