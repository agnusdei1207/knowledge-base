## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **빅오 표기법(Big-O Notation, $O$)**: 입력이 충분히 커진 뒤 비용 증가율이 넘지 않는 점근 상한을 표기함.
- **실측값(Empirical Measurement)**: 운영 환경에서 직접 실측한 실행 시간 및 메모리 소모 수치.

</details>

- 정의/개념: 입력이 충분히 커진 뒤 비용 함수가 기준 함수의 상수배를 넘지 않음을 나타내는 **빅오 표기법 지표**
- 배경/필요성: 특정 구현·환경 의존 실측값의 한계를 극복하고 대규모 입력에서 점근적 성능 비교 정률화 필요성

#### 한줄 요약

- 입력 규모 N이 대형화될 때 알고리즘 비용 함수 T(N)이 초과하지 않는 점근적 상한을 정의한다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **지배항(Dominant Term)**: 입력 크기가 무한히 증가할 때 최고차 차수로서 비용 증가율을 결정하는 대표 항.
- **점근 추상화(Asymptotic Abstraction)**: 상수 계수와 하위 차수 항을 배제하고 최고차 항 기반의 비례 추세를 추출함.
- **상한 증인(Witness)**: 빅오 정의 성립 조건인 양의 상수 배율 $c$와 기준점 $n_0$의 쌍.

</details>

![비용 함수와 빅오 점근 상한](/study/diagrams/big-o-upper-bound.svg)

> 파란 $T(n)=n^2+2n$이 $n_0=2$부터 $2n^2$ 이하로 유효한 상한증인 기반 점근 상한 형성 양상

- 상수·하위항을 제외한 **지배항** 중심의 차수 분류
- 상수 배율 차이를 통합 추상화하는 **점근 추상화** 기법 적용
- 양의 상수 및 기준점 조합 기반의 **상한 증인** 산정

#### 한줄 요약

- 초기 입력 구간의 상수는 배제하고, 입력이 무한히 증가할 때 비용 곡선을 포함하는 최소 점근 상한 차수를 찾아 분류한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **비용 함수 $T(n)$(Cost Function $T(n)$)**: 입력 크기 $n$에 대해 알고리즘이 실행하는 기본 연산 횟수의 수학적 표현.
- **기준 함수 $g(n)$(Reference Function $g(n)$)**: 비용 함수의 점근적 증가율 비교 대상이 되는 표준 함수.
- **점근 상한(Asymptotic Upper Bound)**: 대규모 입력 구간에서 비용 증가율이 기준 함수의 상수배를 초과하지 않는 임계 경계.

</details>

```text
빅오 판정 구조
├─ 비용 함수 T(n)
├─ 기준 함수 g(n)
├─ 상한 증인 c, n₀
└─ 점근 상한 부등식
```

가지의 의미: 상한 판정에 필요한 정적 수학적 구성 체계

| 구성요소 | 책임 |
|:---|:---|
| 비용 함수 $T(n)$ | 기본 연산 횟수를 **비용 함수**로 표현 |
| 기준 함수 $g(n)$ | 증가율을 비교할 **기준 함수** 후보 표현 |
| 상한 증인 $c,n_0$ | **상한 증인**의 배율•기준점 지정 |
| 점근 상한 부등식 | 기준점 이후 모든 입력의 **점근 상한** 표현 |

> 요약: 비용 함수를 포괄하는 기준 함수 기반의 상한 증인 탐색 및 검증

#### 한줄 요약

- 비용 함수 T(n)과 기준 함수 g(n) 간에 부등식 $T(n) \le c \cdot g(n)$을 만족하는 상수 $c>0$와 기준점 $n_0$의 존재성을 증명한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **양의 상수 $c$(Positive Constant $c$)**: 기준 함수를 확대하여 비용 함수의 최고 상한선으로 수용하는 조정 배율.
- **기준점 $n_0$(Threshold $n_0$)**: 점근 상한 부등식이 이후 모든 입력 조건에서 지속 성립하는 최소 입력 크기.

</details>

$$
0\le T(n)\le c g(n)\quad(n\ge n_0,\ c>0)
$$

**판정 원리**

1. **비용 함수 산정**: 입력 크기별 기본 연산 횟수의 수학적 함수화
2. **상한 후보 선정**: 비용 함수 지배항 동등 차수의 기준 함수 선정
3. **상한 증인 탐색**: 비용 함수를 포괄하는 양의 상수 및 기준점 조합 설정
4. **부등식 검증**: 기준점 이후 전체 입력 구간 내 상수배 부등식 성립 증명

#### 한줄 요약

- 비용 함수 T(n)의 지배항을 추출하여 기준 함수 g(n)을 정의하고, 상한 증인(c, n_0)의 유효성을 검증한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **빅세타(Big-Theta Notation, $\Theta$)**: 점근적 상한과 하한을 동시에 한정하여 정확한 차수를 보증함.
- **빅오메가(Big-Omega Notation, $\Omega$)**: 알고리즘 비용 증가율의 점근적 하한 경계를 표기함.
- **점근 차수(Asymptotic Order)**: 지배항의 최고차 비례 관계에 따라 구분된 자원 소모 등급.
- **느슨한 상한(Loose Upper Bound)**: 실질 최고차 증가율보다 과도하게 높은 차수로 설정된 상한 표기.

</details>

| 점근 표기법 | 빅오 $O(g(n))$ | 빅세타 $\Theta(g(n))$ | 빅오메가 $\Omega(g(n))$ |
|:---|:---|:---|:---|
| 적용 기준 | **빅오**로 점근 상한 보증 | **빅세타**로 점근 차수 표현 | **빅오메가**로 점근 하한 보증 |
| 핵심 특징 | 기준 함수 이하로 제한 | 상한•하한을 같은 함수로 제한 | 기준 함수 이상으로 제한 |
| 한계 | **느슨한 상한**이면 정확한 차수 은폐 | 같은 상•하한 증명 필요 | **점근 상한** 판단 불가 |

> 요약: 상한 보증의 **빅오**와 정확 차수 증명의 **빅세타** 상호 구분

#### 한줄 요약

- 상한 경계는 Big-O, 하한 경계는 빅오메가, 상·하한 동시 바운딩은 빅세타 표기법을 적용한다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **상수 비용(Constant Cost)**: 점근 차수 표기에서는 소거되나 실제 런타임 응답시간에 유의미한 영향력을 행사함.
- **입력 사례(Input Case)**: 동일 데이터 규모 내 조건 구성에 따른 최선·평균·최악 실행 상태 분류.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **느슨한 상한**으로 증가율과 후보 차이 은폐 | 성립하는 가장 낮은 **점근 차수**와 증인 제시 | 후보 간 점근 차수 구분 |
| 같은 차수에서 **상수 비용** 생략으로 응답시간 역전 | 목표 입력 구간의 동일 환경 **실측값** 병행 | 운영 구간의 실측값 반영 |
| **입력 사례**와 점근 상한 혼동으로 최악 사례를 빅오로 오인 | 최선•평균•최악 조건과 상•하한 표기 분리 | 사례 조건과 **점근 상한** 분리 |

#### 한줄 요약

- 타이트한 점근 상한(Tight Upper Bound)을 도출하고 동일 점근 차수 내에서는 벤치마크 프로파일링으로 선택한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **입력 규모 경계(Input Scale Boundary)**: 점근 차수 우위와 상수 비용 우위 간 상대적 성능 역전이 발생하는 임계점.

</details>

- 대규모 입력 대상 **점근 차수** 분석 및 동일 차수 내 **실측 프로파일링** 병행을 통한 최종 알고리즘 선정

#### 한줄 요약

- 입력 규모의 점근적 한계를 우선 분석하고, 동일한 차수에서는 프로파일링으로 실측 성능을 평가하여 알고리즘을 선정한다.
