## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **베이즈 정리(Bayes' Theorem)**: 사전 확률(Prior)과 우도(Likelihood)를 결합하고 증거의 주변 확률(Evidence)로 정규화하여 사후 확률(Posterior)을 도출하는 조건부 확률 정리.
- **사전 확률(Prior Probability, $P(H)$)**: 새로운 데이터나 증거를 관측하기 전에 가설 $H$에 대해 부여된 초기 신뢰 수준.
- **사후 확률(Posterior Probability, $P(H|E)$)**: 증거 $E$를 관측한 후 갱신된 가설 $H$의 조건부 확률.
- **우도(Likelihood, $P(E|H)$)**: 가설 $H$가 참이라고 가정할 때 증거 $E$가 관측될 조건부 확률.

</details>

- 정의/개념: **사전 확률**과 **우도**를 결합하여 데이터 관측에 따라 믿음의 정도(**사후 확률**)를 순차적으로 갱신해 나가는 베이지안 역확률 추론 체계
- 배경/필요성: 단순 우도(Likelihood)에만 의존한 판정 시 희귀 사건의 사전 발생 빈도를 배제하여 발생하는 기저율 오류(Base Rate Fallacy) 한계

#### 한줄 요약

- 관측이 바꾸는 것은 결론이 아니라 믿음의 크기이므로, 사전 확률이 낮으면 아무리 정확한 증거도 사후 확률을 충분히 끌어올리지 못한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **양성 예측도(PPV, Positive Predictive Value)**: 검사 결과가 양성으로 나왔을 때 실제로 질병/위협이 존재할 확률.
- **기저율 오류(Base Rate Fallacy)**: 희귀 사건($P(H) \ll 1$)에서 민감도와 특이도가 높아도 기저율이 낮아 양성 예측도가 급감하는 현상을 간과하는 인지적 오류.

</details>

- 관측된 증거로부터 원인(가설)의 확률을 역추적하는 **역확률 추론**
- 새로운 데이터가 들어올 때마다 이전 사후 확률을 새로운 사전 확률로 재사용하는 **순차적 베이즈 갱신**
- 민감도(Sensitivity), 특이도(Specificity) 및 **기저율을 종합 반영한 정밀 양성 예측도(PPV) 산출**

#### 한줄 요약

- 기저율 오류 방지를 위해 증거의 민감도·특이도와 기저율($P(H)$)을 반영한 PPV를 산출한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **주변 확률(Marginal Likelihood, $P(E)$)**: $\sum_k P(E|H_k)P(H_k)$로 표현되는 모든 가능한 가설 공간에서의 전체 증거 발생 확률(정규화 상수).

</details>

```text
+-----------------------------------------------------------------------------+
|                          베이지안 추론 연산 구조                            |
+-----------------------------------------------------------------------------+
|  [사전 확률 모듈 P(H)]   -->  과거 통계 및 도메인 지식 기반 기저율 제공     |
|          |                                                                  |
|          v                                                                  |
|  [우도 모형 P(E|H)]      -->  가설 H 조건 하에서 증거 E 관측 우도 산출      |
|          |                                                                  |
|          v                                                                  |
|  [정규화 분모 P(E)]      -->  P(E) = SUM(P(E|H_i) * P(H_i)) 주변 확률 계산  |
|          |                                                                  |
|          v                                                                  |
|  [사후 확률 연산기]      -->  P(H|E) = [P(E|H) * P(H)] / P(E) 정규화 도출   |
+-----------------------------------------------------------------------------+
```

선의 의미: 실선 박스는 베이지안 추론 파이프라인의 연산 단계를 나타내며, 화살표는 사전 지식과 관측 증거의 결합 흐름을 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 사전 확률 $P(H)$ | 증거 관측 전 가설의 **기저 발생 확률(Base Rate)** 제공 |
| 우도 모형 $P(E \mid H)$ | 가설이 참일 때 해당 증거가 관측될 **우도(Likelihood)** 산출 |
| 갱신 연산기 | 사전 확률과 우도의 곱을 **주변 확률 $P(E)$로 정규화** |
| 확률 상태 저장소 | 도출된 사후 확률을 **차기 관측의 사전 확률로 보관 및 순환** |

#### 한줄 요약

- 우도 모형이 증거의 가설별 적합도를 계산하고, 갱신 연산기가 사전 확률과 결합해 새 확률 상태를 생성한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **순환 베이즈 필터링**: $P(H|E_1, E_2) \propto P(E_2|H) P(H|E_1)$ 형태로 시계열 센서 데이터를 실시간 융합하는 메커니즘.

</details>

```text
가설 H 및 증거 데이터 E 관측
   |
   v
[ 1. 사전 확률 설정 ] : 도메인 통계 및 기저율(Base Rate) 정의
   |
   v
[ 2. 가설별 우도 계산 ] : 센서/검사 민감도 및 특이도 반영
   |
   v
[ 3. 결합 확률 계산 ] : P(E, H) = P(E|H) * P(H)
   |
   v
[ 4. 주변 확률 정규화 ] : P(E) = P(E|H)P(H) + P(E|~H)P(~H) 로 나눗셈
   |
   v
[ 5. 사후 확률 산출 ]
   |
   +---> 차기 증거 관측 시 새로운 사전 확률 P(H)로 순환 갱신
```

분기 결과: 가설 공간 분할(Partition) 여부에 따라 단일 가설 검정은 분모를 P(E|H)P(H)+P(E|~H)P(~H)로 전개하고, 다중 가설 분류는 전체 주변 확률 합 SUM(P(E|H_i)P(H_i))으로 정규화한다.

**동작 원리**:
1. **사전 확률 설정**: 관측 대상의 모집단 내 기저율(Base Rate)을 기반으로 사전 확률 $P(H)$를 초기 부여한다.
2. **가설별 우도 계산**: 주어진 조건에서 증거가 나타날 조건부 확률(민감도 $P(E|H)$ 및 특이도 기반 우도)을 도출한다.
3. **결합 확률 계산**: 사전 확률과 우도를 곱하여 가설과 증거의 결합 확률($P(E, H) = P(E|H)P(H)$)을 산정한다.
4. **주변 확률 정규화**: 모든 가능한 가설에 걸친 증거 발생 확률의 총합인 주변 확률 $P(E)$로 나누어 사후 확률 총합을 1로 정규화한다.
5. **사후 확률 갱신 및 순환**: 도출된 사후 확률 $P(H|E)$를 최종 판정값으로 확정하고 차기 증거 관측을 위한 사전 확률로 재사용한다.

#### 한줄 요약

- 사전 확률과 우도의 곱을 전체 증거 확률로 정규화해 사후 확률을 도출한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **베이지안 추론(Bayesian Inference)**: 모수를 확률변수로 취급하고 사전 지식을 명시적으로 결합하여 사후 분포를 추정하는 통계 체계.
- **빈도주의 추론(Frequentist Inference)**: 모수를 고정된 상수로 보고 무한 반복 표본의 빈도와 유의확률(p-value)로 가설을 검정하는 통계 체계.

</details>

| 통계 추론 관점 | 베이지안 추론 (Bayesian) | 빈도주의 추론 (Frequentist) |
|:---|:---|:---|
| 적용 기준 | 소량 데이터 및 **사전 도메인 지식 결합** 시 | 대규모 반복 표본 및 **객관적 규제 가설 검정** 시 |
| 모수의 해석 | **확률분포를 갖는 불확실한 변수** | 참값을 갖는 **고정된 미지의 상수** |
| 사전 지식 활용 | **사전 분포(Prior)** 명시적 결합 | 사전 지식 배제, **오직 현재 표본 데이터만** 사용 |
| 한계 | 주관적 사전 분포 선정에 따른 **편향 위험** | 소량 데이터에서 추론 불안정 및 기저율 무시 |

#### 한줄 요약

- 사전 지식과 데이터 융합은 베이지안 통계, 대규모 반복 실험의 객관적 검정은 빈도주의 통계를 선택한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **무정보 사전분포(Uninformative / Flat Prior)**: 사전 정보가 전혀 없을 때 모든 상태에 균일한 확률을 부여하여 주관성을 배제하는 사전 분포(Jeffrey's Prior 등).
- **개념 표류(Concept Drift)**: 시간이 지남에 따라 입력 데이터의 통계적 특성이나 목표 변수와의 관계가 변하는 현상.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 희귀 질병 또는 보안 위협 판별 시 기저율 간과에 따른 오탐률 폭증 | 모집단 기저율을 반영한 **정밀 양성 예측도(PPV)** 산출 | 오탐률 왜곡 및 과대평가 원천 방지 |
| 상호 상관된 복수 증거의 **조건부 독립 가정 오류** | 베이지안 네트워크(DAG) 기반 **결합 우도 모형화** | 증거 중복 계산으로 인한 과신 억제 |
| 주관적 사전 분포 선택에 따른 **추론 편향 발생** | **무정보 사전분포** 적용 및 **사전 분포 민감도 분석** | 추론 결론의 **강건성(Robustness)** 검증 |
| 데이터 스트림의 **개념 표류** | 사후 확률 기반 **온라인 베이즈 갱신 및 우도 재보정** | 시변 환경에서의 적응적 추론 유지 |

#### 한줄 요약

- 기저율을 반영해 PPV를 산출하고, 베이지안 네트워크로 결합 우도를 구조화하며, 사전 민감도 분석과 온라인 갱신으로 추정 신뢰도를 유지한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **현대 AI/머신러닝의 초석**: 베이즈 정리는 나이브 베이즈 분류기, 칼만 필터(Kalman Filter), MCMC, 베이지안 딥러닝, A/B 테스트 사후 의사결정의 핵심 수학 엔진으로 광범위하게 활용.

</details>

- 나이브 베이즈 분류기, 칼만 필터(Kalman Filter), 베이지안 딥러닝 및 실시간 A/B 테스트 의사결정의 핵심 수학적 엔진으로 확립되었으며, 실무에서는 기저율 반영을 통한 양성 예측도(PPV) 보정, 베이지안 네트워크 기반 의존성 모형화 및 MCMC 사후분포 샘플링과 결합하여 불확실성 하 최적 의사결정을 실현

#### 한줄 요약

- 기저율과 우도를 함께 반영하고, 상관된 증거를 독립으로 중복 계산하지 않는 베이지안 추론 원칙을 준수한다.
