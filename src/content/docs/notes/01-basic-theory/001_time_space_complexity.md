## 미리 알고가기

- **시간·공간복잡도(Time/Space Complexity)**: 입력 증가에 따른 연산량·메모리 증가율로 알고리즘 확장성을 비교하는 척도
- **입력 크기 $n$**: 문제에 포함된 항목 수이며 시간·공간 비용 함수의 입력 변수
- **기본 연산**: 실행 횟수를 세어 시간 비용을 추정하는 대표 연산
- **시간 비용 함수 $T(n)$**: 입력 크기별 기본 연산 횟수를 나타내는 함수
- **공간 비용 함수 $S(n)$**: 입력 크기별 최대 메모리 점유량을 나타내는 함수
- **지배항(Dominant Term)**: 큰 입력에서 증가율을 결정하는 항
- **하위항(Lower-Order Term)**: 지배항보다 느리게 증가해 큰 입력의 점근 증가율 분류에서는 제거하는 항
- **점근 분석(Asymptotic Analysis)**: 큰 입력에서 지배항 증가율을 비교해 자원 확장성을 판단하는 방법
- **계산 모델(Random Access Machine, RAM)**: 기본 산술·비교·대입 연산의 비용을 일정하다고 가정하여 하드웨어와 무관하게 알고리즘 비용을 분석하는 추상 모델
- **최선·평균·최악(Best/Average/Worst Case)**: 같은 입력 크기에서 연산 비용이 가장 작거나 평균적이거나 가장 큰 경우를 구분하는 분석 기준
- **색인(Index)**: 검색 키와 데이터 위치를 연결해 비교할 항목을 줄이는 구조
- **단편화(Fragmentation)**: 메모리 할당과 해제가 반복되면서 사용 가능한 공간이 분산되어 연속 공간을 확보하기 어려워지는 현상

## Ⅰ. 개요

- 정의/개념: 자원 **증가율**로 알고리즘 **확장성**을 판단하는 척도
- 기존 한계: 실측만으로는 미경험 입력 규모의 **자원 한도** 예측 불가

### 쉽게 이해하기 (학습용)

- 창고 물량이 두 배가 될 때 작업 시간과 적재 공간이 얼마나 늘어날지 가늠하듯, 입력 증가에 따른 연산량과 메모리 증가율로 풀이법의 한계를 예측한다.

## Ⅱ. 특징

- 기계 성능과 무관하게 **점근 증가율**만으로 확장성 비교
- 같은 문제에서 시간을 줄이면 공간이 늘어나는 **상충 관계**
- **최선·평균·최악** 입력별 자원 증가율 분리

### 쉽게 이해하기 (학습용)

- 지게차 속도는 제쳐 두고 물량 증가 형태를 쉬운·평균·최악 배치로 나눠 보며, 시간 절약에 필요한 추가 창고 공간도 함께 계산한다.

## Ⅲ. 아키텍처

| 구성요소 | 책임 |
|:---|:---|
| 계산 모델 | 비용 1로 셀 **기본 연산** 범위 규정 |
| 비용 함수 $T(n)$·$S(n)$ | 연산 횟수·최대 **점유 메모리** 산출 |
| 입력 사례 | **최선·평균·최악** 비용 범위 제공 |
| 점근 차수 | 상수·하위항 제거 후 **지배항** 분류 |

> 요약: **계산 모델**에 따라 산정한 비용을 **점근 차수**로 판정

### 쉽게 이해하기 (학습용)

- 창고에서 상자 한 번 운반을 비용 1로 정하고, 물량별 운반 횟수와 적재 공간을 센 뒤 가장 빠르게 늘어나는 비용으로 등급을 매긴다.

## Ⅳ. 종류 및 비교

| 복잡도 | 시간복잡도 | 공간복잡도 |
|:---|:---|:---|
| 적용 기준 | **응답 시간** 한도가 짧을 때 | **가용 메모리**가 작을 때 |
| 핵심 특징 | **기본 연산** 횟수 증가율 | 최대 **점유 메모리** 증가율 |
| 한계 | 같은 차수의 **상수 배** 시간차 미반영 | **단편화**·런타임 오버헤드 미반영 |

> 요약: 시간 절약은 **메모리 추가**, 메모리 절약은 **재계산**

### 쉽게 이해하기 (학습용)

- 창고에 중간 결과를 쌓아 두면 작업은 빨라지지만 공간을 더 쓰고, 저장하지 않으면 공간은 아끼지만 같은 작업을 반복하므로 더 빠듯한 자원을 기준으로 풀이법을 고른다.

## Ⅴ. 실무 고려사항 및 대책

| 고려사항 | 대책 | 효과 |
|:---|:---|:---|
| 대표 연산 선택에 따른 **시간 비용** 왜곡 | 반복 지배 연산으로 **기본 연산** 통일 | 알고리즘 간 **증가율** 비교 일관성 향상 |
| 평균 분석의 **극단 입력** 은폐 | **최악 입력**과 평균 입력 병행 산정 | **자원 한도** 초과 입력 식별 |
| 점근 차수의 **상수 비용** 누락 | 동일 차수 후보의 **실측 시간** 비교 | 실제 입력 구간의 **응답 시간** 판별 |
| 로그 조회의 **시간 한도** | **색인** 저장으로 비교 연산 축소 | 조회 시간 감소·**공간 사용량** 증가 |

### 쉽게 이해하기 (학습용)

- 창고 작업을 비교할 때 같은 동작을 한 번으로 세고 최악의 물량과 실제 처리 시간을 함께 보며, 로그 색인처럼 시간을 줄이는 조치가 공간을 얼마나 더 쓰는지도 판단한다.

## Ⅵ. 결론

- **응답 시간**이 병목이면 시간, **메모리** 부족이면 공간 우선 절감

### 쉽게 이해하기 (학습용)

- 창고 공간과 출고 시간 중 먼저 한도에 닿는 자원을 확인하듯, 입력 규모에 따라 시간이나 메모리를 아끼는 풀이법을 선택한다.
