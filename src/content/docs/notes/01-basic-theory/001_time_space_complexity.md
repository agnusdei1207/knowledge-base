## 미리 알고가기

- **시간·공간복잡도(Time/Space Complexity)**: 입력 증가에 따른 연산량·메모리 증가율로 알고리즘 확장성을 비교하는 척도
- **입력 크기 $n$**: ‘엔’으로 읽고 항목 개수(Number)의 머리글자를 쓰는 알고리즘 관례에 따라 문제 규모를 나타내며 시간·공간 비용 함수의 입력이 되는 변수
- **기본 연산**: 실행 횟수를 세어 시간 비용을 추정하는 대표 연산
- **시간 비용 함수 $T(n)$**: ‘티 오브 엔’으로 읽으며, 시간(Time)의 머리글자 $T$와 괄호 안의 입력 크기 $n$을 사용해 입력 크기별 기본 연산 횟수를 나타내는 함수
- **공간 비용 함수 $S(n)$**: ‘에스 오브 엔’으로 읽으며, 공간(Space)의 머리글자 $S$와 괄호 안의 입력 크기 $n$을 사용해 입력 크기별 최대 메모리 점유량을 나타내는 함수
- **지배항(Dominant Term)**: 큰 입력에서 증가율을 결정하는 항
- **하위항(Lower-Order Term)**: 지배항보다 느리게 증가해 큰 입력의 점근 증가율 분류에서는 제거하는 항
- **점근 분석(Asymptotic Analysis)**: 큰 입력에서 지배항 증가율을 비교해 자원 확장성을 판단하는 방법
- **계산 모델(Random Access Machine, RAM)**: 산술·비교·대입 같은 기본 연산 하나를 비용 1로 세자고 약속한 가상의 계산기이며, 이 약속이 있어야 서로 다른 컴퓨터에서 잰 알고리즘도 같은 잣대의 숫자로 비교됨
- **최선·평균·최악(Best/Average/Worst Case)**: 같은 입력 크기라도 값이 어떻게 놓였는지에 따라 연산 횟수가 달라지므로 가장 유리한 입력·보통 입력·가장 불리한 입력으로 나눠 비용을 재는 구분이며, 자원 한도 초과 판단은 대개 최악 입력을 기준으로 함
- **편집 거리(Edit Distance)**: 삽입·삭제·치환의 최소 횟수
- **색인(Index)**: 검색 키와 데이터 위치를 연결해 비교할 항목을 줄이는 구조
- **단편화(Fragmentation)**: 할당과 해제가 반복되면서 빈 공간이 잘게 흩어져, 총량은 남아 있는데도 필요한 크기의 연속 공간을 잡지 못하는 현상이며, 공간복잡도가 세는 논리적 점유량과 실제 소모량이 벌어지는 원인

## Ⅰ. 개요

- 정의/개념: 자원 **증가율**로 알고리즘 **확장성**을 판단하는 척도
- 기존 한계: 실측만으로는 미경험 입력 규모의 **자원 한도** 예측 불가

### 쉽게 이해하기 (학습용)

- 창고 물량이 두 배가 될 때 작업 시간과 적재 공간이 얼마나 늘어날지 가늠하듯, 입력 증가에 따른 연산량과 메모리 증가율로 풀이법의 한계를 예측한다.

## Ⅱ. 특징

- 기계 성능과 무관하게 **점근 증가율**만으로 확장성 비교
- 같은 문제에서 시간을 줄이면 공간이 늘어나는 **상충 관계**
- 자원 한도 판정은 평균이 아니라 **최악 입력** 기준

### 쉽게 이해하기 (학습용)

- 지게차 속도가 달라도 물량 증가에 따라 작업 횟수가 불어나는 형태는 같듯, 기계 성능을 빼고 자원 증가율로 풀이법을 비교한다.

## Ⅲ. 아키텍처 및 구성요소

| 설계 요소 | 설명 |
|:---|:---|
| 계산 모델 | 비용 1로 셀 **기본 연산** 범위 규정 |
| 비용 함수 $T(n)$·$S(n)$ | 입력 크기별 연산 횟수·**점유 메모리** 산출 |
| 입력 사례 구분 | **최선·평균·최악** 입력별 비용 분리 |
| 점근 분류 기준 | **지배항** 증가율로 등급 분류 |

> 요약: **계산 모델**에 따라 산정한 비용을 **점근 차수**로 판정

### 쉽게 이해하기 (학습용)

- 창고에서 상자 한 번 운반을 비용 1로 정하고, 물량별 운반 횟수와 적재 공간을 센 뒤 가장 빠르게 늘어나는 비용으로 등급을 매긴다.

## Ⅳ. 원리 및 절차 흐름도

- **비용 산정**: 입력 크기별 **기본 연산** 횟수·최대 메모리 계산
- **점근 분석**: 상수·하위항 제거 후 **지배항** 분류

### 쉽게 이해하기 (학습용)

- 창고 물량이 커질수록 가장 빠르게 늘어나는 작업이 전체 시간을 좌우하므로, 작은 고정 비용과 느리게 늘어나는 비용을 빼고 지배항으로 등급을 매긴다.

## Ⅴ. 종류 및 비교

| 복잡도 | 시간복잡도 | 공간복잡도 |
|:---|:---|:---|
| 적용 기준 | **응답 시간** 한도가 짧을 때 | **가용 메모리**가 작을 때 |
| 핵심 특징 | **기본 연산** 횟수 증가율 | 최대 **점유 메모리** 증가율 |
| 한계 | 같은 차수 안의 **상수 배** 시간차 미반영 | **단편화**·런타임 오버헤드 미반영 |

> 요약: 시간 절약은 **메모리 추가**, 메모리 절약은 **재계산**

### 쉽게 이해하기 (학습용)

- 창고에 중간 결과를 쌓아 두면 작업은 빨라지지만 공간을 더 쓰고, 저장하지 않으면 공간은 아끼지만 같은 작업을 반복하므로 더 빠듯한 자원을 기준으로 풀이법을 고른다.

## Ⅵ. 실무 사례

1. 로그 검색은 **색인** 저장으로 조회 연산 축소

### 쉽게 이해하기 (학습용)

- 창고 위치표를 만들어 두면 모든 선반을 돌지 않아도 되듯, 로그 색인은 조회 연산을 줄이는 대신 저장 공간을 사용한다.

## Ⅶ. 결론

- 입력 크기·**자원 한도**로 **시간·공간** 절충안 선택

### 쉽게 이해하기 (학습용)

- 창고 공간과 출고 시간 중 먼저 한도에 닿는 자원을 확인하듯, 입력 규모에 따라 시간이나 메모리를 아끼는 풀이법을 선택한다.
