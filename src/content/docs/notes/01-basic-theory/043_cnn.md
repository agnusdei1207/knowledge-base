## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **국소 수용장(Local Receptive Field)**: 뉴런이 전체 입력 대신 인접한 국소 영역의 픽셀들만을 연결하여 공간 패턴을 포착하는 기하학적 창.
- **공간 위상 정보 유실(Loss of Spatial Topology)**: 2차원 이미지를 1차원 벡터로 강제 평탄화(Flatten)할 때 픽셀 간의 상하좌우 인접 관계가 파괴되는 현상.

</details>

- 정의/개념: 2D/3D 공간 데이터에 **국소 수용장** 및 **가중치 공유**를 적용하여 계층적 특징을 추출하는 딥러닝 신경망 아키텍처
- 배경/필요성: 완전연결신경망(FC/MLP)을 다차원 영상 데이터에 적용할 때 발생하는 공간 위상 정보 유실과 **차원 증가에 따른 파라미터 폭증 한계**

#### 한줄 요약

- 위치가 달라도 같은 패턴이라는 가정을 구조에 박아 넣어 파라미터를 줄이는 거래이므로, 그 가정이 어긋나는 데이터에서는 표현력이 되레 제약된다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **수용영역(Receptive Field)**: 출력 특징 맵의 단일 픽셀이 참조하는 원본 입력 이미지 상의 물리적 영역 크기.
- **스트라이드(Stride) 및 패딩(Padding)**: 필터 이동 보폭(Stride)과 가장자리 0 채움(Zero-padding)으로 출력 특징 맵의 해상도를 제어하는 하이퍼파라미터.

</details>

- 국소 연결 및 **가중치 공유**를 통한 파라미터 절감
- 계층 심화에 따른 수용영역 확장 및 **고수준 특징 합성**
- 풀링과 스트라이드에 따른 **이동 민감도 완화**

#### 한줄 요약

- 얕은 층이 에지를 추출하고 깊은 층이 이를 고수준 객체 부분으로 계층 결합

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **합성곱 계층(Convolutional Layer)**: 커널 필터와의 2D 상호 상관(Cross-correlation)으로 특징 맵을 생성하는 계층.
- **활성화 계층(Activation Layer)**: 선형 결합에 ReLU 등의 비선형 활성화를 적용하는 계층.
- **풀링 계층(Pooling Layer)**: 공간 해상도를 축소하고 대표 특징을 요약하는 다운샘플링 계층.

</details>

```text
[합성곱 신경망(CNN) 계층 아키텍처]
  │
  ├─ [입력 텐서단] (영상/공간 데이터 수신)
  │     ├─ 차원 규격 (Batch, Height, Width, Channels)
  │     └─ 공간 위상 보존 (2D 그리드 인접 관계 유지)
  │
  ├─ [특징 추출 블록] (합성곱 및 비선형 활성화)
  │     ├─ Conv2D 계층 (커널 슬라이딩 및 가중치 공유)
  │     └─ 활성화 계층 (ReLU 비선형 특징 매핑)
  │
  ├─ [해상도 축소 블록] (서브샘플링)
  │     ├─ 풀링 계층 (Max/Avg Pooling 공간 다운샘플링)
  │     └─ 이동 불변성 확보 (미세 위치 변동 민감도 완화)
  │
  └─ [분류 및 출력 블록] (고수준 특징 종합)
        ├─ 특징 집계기 (Global Average Pooling / Flatten)
        └─ 출력 분류기 (Dense + Softmax 클래스 확률 도출)
```

- 선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 합성곱 계층 (Conv) | 국소 커널 필터를 적용하여 **엣지, 텍스처 등 국소 공간 특징 맵 추출** |
| 활성화 계층 (ReLU) | 선형 합성곱 결과에 **비선형성 부여** |
| 풀링 계층 | 공간 해상도 축소로 **연산량·이동 민감도** 완화 |
| 완전연결/GAP 계층 | 추출된 고수준 특징을 집계하여 **최종 클래스 분류 확률 도출** |

#### 한줄 요약

- 합성곱 계층이 국소 패턴을 추출하면 활성화 함수와 풀링이 반응을 선별·축소하여 출력 계층에 전달

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **특징 맵 크기 계산식**: $O = \lfloor \frac{W - K + 2P}{S} \rfloor + 1$ ($W$:입력크기, $K$:커널크기, $P$:패딩, $S$:스트라이드).

</details>

```text
입력 텐서 (Batch, Height, Width, Channels)
   |
   v
[ 1. 2D 합성곱 연산 ] : O = (W - K + 2P)/S + 1
   |
   v
[ 2. 배치 정규화 및 비선형 활성화 ] : BatchNorm + ReLU
   |
   v
[ 3. 공간 해상도 축소 ] : Max/Avg Pooling (2x2 stride 2)
   |
   +---> 잔여 심층 계층 존재 시 : [ 1 ~ 3 단계 심층 블록 반복 ]
   |
   v
[ 4. GAP 특징 벡터 요약 ] : Global Average Pooling
   |
   v
[ 5. Linear 분류기 및 확률 출력 ] : Softmax 클래스 확률 도출
```

분기 결과: 은닉 블록 깊이에 따라 1~3단계(Conv-BN-ReLU-Pool)를 반복 수행하고, 최종 단계에서는 GAP를 통해 1차원 벡터로 압축하여 선형 분류기로 분기한다.

**동작 원리**:
1. **2D 합성곱 연산**: 국소 수용영역(Receptive Field)의 커널 필터를 슬라이딩 내적하여 엣지, 질감 등 공간적 특징 맵을 추출한다.
2. **배치 정규화 및 비선형 활성화**: 미니배치 단위 평균과 분산으로 내부 공변량 변화를 제어하고 ReLU 활성화를 통해 비선형성을 부여한다.
3. **공간 해상도 축소**: 스트라이드 풀링 또는 스트라이드 합성곱을 적용하여 특징 맵의 공간 해상도를 축소하고 평행 이동 불변성(Translation Invariance)을 확보한다.
4. **GAP 특징 벡터 요약**: 다채널 2차원 특징 맵을 채널별 평균값으로 요약(Global Average Pooling)하여 파라미터 수를 획기적으로 절감한다.
5. **Linear 분류기 및 확률 출력**: 1차원 요약 벡터를 완전연결 분류기에 통과시키고 Softmax 함수로 정규화하여 최종 클래스별 확률을 출력한다.

#### 한줄 요약

- 입력 텐서가 합성곱 커널을 거쳐 특징 맵으로 변환되고, 풀링으로 축소된 특징이 최종 분류 출력으로 변환

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **합성곱 신경망(CNN)**: 강력한 공간 귀납 편향을 기반으로 국소 공간 특징 추출에 특화된 비전 모델.
- **완전연결망(Fully Connected Network, FC/MLP)**: 입력 특징을 모든 뉴런과 연결하며 공간적 인접성을 구조적으로 보존하지 않는 신경망.
- **비전 트랜스포머(Vision Transformer, ViT)**: 이미지를 패치 임베딩하여 전역 Self-Attention을 수행하는 대규모 비전 모델.

</details>

| 신경망 모델 | CNN | FC/MLP | ViT |
|:---|:---|:---|:---|
| 적용 기준 | 중소 규모의 2D·3D 비전 데이터 | 공간 구조가 없는 정형 특징 | 대규모 사전학습 비전·멀티모달 데이터 |
| 핵심 특징 | **국소 연결 및 가중치 공유** 기반 불변성 | 모든 입력 노드 간 완전 연결 | **패치 임베딩 및 전역 Self-Attention** |
| 한계 | 전역 문맥 포착에 깊은 계층 필요 | 입력 차원 증가로 **파라미터 폭증** | **대규모 사전학습** 의존성 |

#### 한줄 요약

- 국소 패턴과 제한된 데이터는 CNN, 전역 관계 모델링과 대규모 데이터는 ViT를 적용

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Grad-CAM(Gradient-weighted Class Activation Mapping)**: 최종 합성곱 계층의 특징 맵에 대한 타깃 클래스 기울기를 가중치로 결합하여 모델이 이미지의 어느 영역을 보고 판단했는지 히트맵으로 시각화하는 XAI 기법.
- **잔차 연결(Residual Skip-Connection)**: 입력 텐서를 블록 출력에 직접 덧셈($F(x) + x$)하여 기울기 소실 없이 수백 층 이상 깊은 신경망을 학습시키는 구조.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 조명·각도 변화로 이미지 분류 **오탐률 증가** | **RandAugment·CutMix** 데이터 증강 | 입력 변형에 대한 일반화 개선 |
| 엣지 장치에서 **추론 지연·메모리 부족** | **MobileNet**과 INT8 양자화 적용 | 연산량·모델 메모리 절감 |
| 판단 근거가 불투명한 **블랙박스 문제** | **Grad-CAM** 활성 영역 시각화 | 오탐 원인 분석 가능성 향상 |
| 심층망에서 **기울기 소실·성능 퇴화** | **잔차 연결** 적용 | 역전파 경로 보존 |

#### 한줄 요약

- 데이터 부족은 RandAugment로 보완하고, 모바일에는 MobileNet 경량 아키텍처를 적용하며, 판단 근거는 Grad-CAM으로 시각화하고, 깊은 네트워크는 ResNet 잔차 연결로 기울기 소실을 방지한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **컴퓨터 비전 하이브리드 표준**: 엣지 디바이스나 데이터가 제한된 실시간 산업용 검사에는 ConvNeXt 등 최신 CNN을 적용하고, 대규모 클라우드 멀티모달 AI에는 ViT/Swin-Transformer를 선택하는 설계 원칙.

</details>

- 컴퓨터 비전(객체 검출, 분할, 영상 분류) 및 공간 데이터 처리의 **핵심 딥러닝 아키텍처**로 확립되었으며, 실무에서는 **엣지/임베디드 실시간 비전 시스템(MobileNet/YOLO/ConvNeXt) 및 잔차 연결(ResNet Skip-Connection), Grad-CAM XAI 해석성 도구**를 결합하여 고속-고정밀 비전 인퍼런스를 구현

#### 한줄 요약

- 국소 패턴과 제한된 데이터는 CNN, 전역 장거리 관계가 핵심이면 ViT를 선택
