## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **합성곱 신경망(Convolutional Neural Network, CNN)**: 공유 커널로 입력의 국소 공간 패턴을 추출하는 신경망이다.
- **공간 관계**: 이미지에서 픽셀이나 특징이 서로 이웃하고 배치된 관계이다.
- **공유 커널(Shared Kernel)**: 같은 작은 가중치 필터를 입력의 모든 위치에 반복 적용하는 구조이다.
- **완전연결망(Fully Connected Network)**: 모든 입력과 출력 뉴런을 개별 가중치로 연결하는 신경망이다.

</details>

- 정의/개념: 공유 커널로 위치가 다른 국소 패턴을 검출하고 계층적으로 결합하는 **CNN**이다.
- 배경/필요성: 영상을 일렬로 펼쳐 완전연결망에 넣으면 픽셀의 **공간 관계**를 직접 활용하기 어렵고 입력 크기에 따라 가중치 수도 급증한다.

#### 한줄 요약

- 완전연결망은 입력을 1차원으로 펼쳐 공간 관계를 잃지만, CNN은 합성곱 커널을 전역에 공유하여 국소 수용장의 공간 패턴을 계층적으로 결합한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **수용영역(Receptive Field)**: 출력값 하나가 참조하는 원본 입력 범위이다.
- **가중치 공유**: 하나의 커널을 여러 입력 위치에 반복 적용해 파라미터를 줄이는 방식이다.
- **고수준 패턴**: 여러 국소 특징을 결합해 만든 물체 부분이나 의미 단위의 특징이다.

</details>

- **수용영역** 기반으로 공간 국소 특징을 추출한다.
- **가중치 공유**로 파라미터 수를 줄인다.
- 층 심화에 따른 수용영역 확대와 **고수준 패턴** 결합이 핵심이다.

#### 한줄 요약

- 얕은 층이 에지를 추출하고 깊은 층이 이를 고수준 객체 부분으로 계층적으로 결합한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **특징 맵(Feature Map)**: 커널이 입력에서 찾은 특징의 위치별 반응값이다.
- **스트라이드(Stride)**: 입력 위에서 커널이 이동하는 간격이다.
- **패딩(Padding)**: 입력 가장자리에 덧대는 값이다.
- **풀링(Pooling)**: 구역별 최댓값이나 평균으로 특징 맵 크기를 줄이는 연산이다.
- **국소 특징(Local Feature)**: 가까운 픽셀에서 추출한 공간 패턴이다.
- **비선형성**: 선형 합성만으로 표현할 수 없는 복잡한 관계를 활성화 함수가 부여하는 성질이다.
- **분류(Classification)**: 입력의 범주를 예측하는 문제이다.
- **회귀(Regression)**: 입력의 연속 수치를 예측하는 문제이다.

</details>

```text
[합성곱 신경망]
        |
        +-- [합성곱 계층]
        +-- [활성화 함수]
        +-- [풀링 계층]
        `-- [출력 계층]
```

선의 의미: 합성곱 신경망을 이루는 특징 추출•축소•출력 계층을 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 합성곱 계층 | **공유 커널**•스트라이드•패딩 기반 **국소 특징** 추출 |
| 활성화 함수 | 특징 맵에 **비선형성** 부여 |
| 풀링 계층 | **풀링**으로 공간 크기•구역 반응 요약 |
| 출력 계층 | 특징의 **분류**•**회귀** 결과 변환 |

#### 한줄 요약
- 합성곱 계층이 국소 패턴을 추출하면 활성화 함수와 풀링이 반응을 선별·축소하여 출력 계층에 전달한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **입력 텐서**: 높이•너비•채널처럼 여러 축으로 표현한 입력 수치 배열이다.
- **축소 특징**: 활성화와 풀링으로 크기를 줄이고 핵심 반응을 남긴 표현이다.
- **합성곱 특징 추출**: 공유 커널을 입력에 적용해 위치별 특징 맵을 만드는 단계이다.
- **비선형 활성화**: 활성화 함수로 특징 맵에 비선형 표현력을 부여하는 단계이다.
- **공간 특징 축소**: 풀링으로 특징 맵의 공간 크기를 줄이고 강한 반응을 남기는 단계이다.
- **과업 출력 변환**: 고수준 특징을 분류 범주나 회귀값으로 바꾸는 단계이다.

</details>

```text
[입력 텐서]
      |
      v
+--------------------------------+
| 특징 블록을 계층별로 반복      |
|                                |
|  1. 합성곱 특징 추출           |
|            |                   |
|            v                   |
|  2. 비선형 활성화              |
|            |                   |
|            v                   |
|  3. 공간 특징 축소             |
|            |                   |
|            `-------- 반복 -----|
+--------------------------------+
      |
      v
4. 과업 출력 변환
      |
      v
[분류•회귀 결과]
```

### 동작 원리

- **1. 합성곱 특징 추출**: 공유 커널로 위치별 특징 맵을 산출한다.
- **2. 비선형 활성화**: 특징 맵에 복잡한 표현력을 부여한다.
- **3. 공간 특징 축소**: 풀링으로 공간 크기를 줄여 **축소 특징**을 만든다.
- **4. 과업 출력 변환**: 고수준 특징을 분류•회귀값으로 변환한다.

#### 한줄 요약
- 입력 텐서가 합성곱 커널을 거쳐 위치별 특징 맵으로 변환되고, 풀링으로 축소된 특징이 최종 분류·회귀 출력이 된다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **귀납 편향(Inductive Bias)**: 학습 전에 모델 구조에 반영한 문제에 대한 가정이다.
- **비전 트랜스포머(Vision Transformer, ViT)**: 이미지 패치 사이의 전역 관계를 셀프 어텐션으로 학습하는 모델이다.
- **완전연결 신경망**: 모든 입출력을 개별 가중치로 연결하는 신경망이다.
- **셀프 어텐션(Self-Attention)**: 입력 위치들이 서로의 관련도를 계산해 전역 정보를 결합하는 연산이다.
- **전역 문맥**: 이미지 전체의 멀리 떨어진 위치까지 함께 고려한 관계 정보이다.
- **고정 길이 벡터**: 입력마다 같은 개수와 순서의 수치 특징으로 표현한 데이터이다.
- **장거리 관계**: 이미지에서 멀리 떨어진 영역 사이의 연관성이다.
- **데이터 요구량**: 모델이 안정적인 성능을 학습하는 데 필요한 표본의 규모이다.

</details>

| 신경망 구조 | CNN | 완전연결 신경망 | ViT |
|:---|:---|:---|:---|
| 적용 기준 | **국소 특징** 중심 과업 | 공간 구조 없는 **고정 길이 벡터** | **전역 문맥** 의존 시각 과업 |
| 핵심 특징 | **공유 커널** 기반 국소 패턴 추출 | **완전연결 신경망**의 개별 가중치 | 패치 간 **셀프 어텐션** 전역 관계 |
| 한계 | **장거리 관계** 모델링 효율 저하 | **공간 관계** 손실•가중치 급증 | 약한 귀납 편향에 따른 **데이터 요구량** 증가 |

> 요약: 공간 **귀납 편향**의 유무와 강도를 기준으로 모델을 선택한다.

#### 한줄 요약

- 국소 패턴을 우선 추출하는 CNN은 적은 학습 데이터에 유리하고, 전역 어텐션으로 패치를 연결하는 ViT는 더 많은 학습 데이터가 필요하다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **클래스 편중**: 범주별 학습 표본 수가 크게 다른 상태이다.
- **데이터 증강**: 의미를 유지하는 변형으로 학습 표본을 늘리는 기법이다.
- **양자화**: 수치 정밀도를 낮춰 모델 크기와 연산량을 줄이는 기법이다.
- **오탐(False Positive)**: 없는 대상을 있다고 잘못 판정한 오류이다.
- **미탐(False Negative)**: 실제 대상을 놓친 오류이다.
- **입력 정규화**: 영상 밝기나 채널 값의 중심과 척도를 일정하게 맞추는 전처리이다.
- **경량 모델**: 채널 수와 연산량을 줄여 제한된 장치에서 빠르게 실행하는 모델이다.
- **활성 영역 시각화**: 예측에 크게 기여한 이미지 위치를 열지도 등으로 표시하는 설명 방법이다.
- **재현율(Recall)**: 실제 양성 표본 중 모델이 양성으로 찾아낸 비율이다.
- **추론 지연**: 입력을 받은 뒤 모델이 예측 결과를 반환할 때까지 걸리는 시간이다.
- **판정 근거**: 모델 예측에 크게 기여한 특징이나 이미지 위치이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 결함 표본 희소로 **클래스 편중** | **데이터 증강**•결함 표본 가중치 적용 | 희귀 결함 **재현율** 향상 |
| 조명•촬영 각도 변화에 **오탐** 증가 | 조건별 증강•**입력 정규화** | 촬영 조건별 오탐 감소 |
| 검사 단말의 **추론 지연** | 채널 축소•양자화•**경량 모델** 적용 | 추론 지연과 모델 크기 감소 |
| 판정 근거** 부족 | 특징 맵•**활성 영역 시각화 | 오탐•미탐 원인 추적 지원 |

#### 한줄 요약

- 회로기판 검사 시스템에 조명별 데이터 증강과 경량 모델을 적용하면 위치가 다른 균열도 공유 커널로 검출하면서 제한된 단말의 추론 지연 요건을 충족할 수 있다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **선택 기준**: 국소 패턴•학습 데이터 규모•장거리 관계 요구로 시각 모델을 고르는 기준이다.

- **비전 트랜스포머(Vision Transformer, ViT)**: 이미지를 패치 단위로 분할하여 셀프 어텐션(Self-Attention) 메커니즘으로 전역 관계를 학습하는 컴퓨터 비전 아키텍처.
</details>

- **선택 기준**에 따라 국소 패턴•제한 데이터는 CNN, 장거리 관계는 **ViT**를 선택한다.

#### 한줄 요약

- 국소 패턴과 제한된 데이터는 CNN, 전역 장거리 관계가 핵심이면 ViT를 선택한다.
