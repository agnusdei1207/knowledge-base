## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **국소 수용장(Local Receptive Field)**: 뉴런이 전체 입력 대신 인접한 국소 영역의 픽셀들만을 연결하여 공간 패턴을 포착하는 기하학적 창.
- **공간 위상 정보 유실(Loss of Spatial Topology)**: 2차원 이미지를 1차원 벡터로 강제 평탄화(Flatten)할 때 픽셀 간의 상하좌우 인접 관계가 파괴되는 현상.

</details>

- 정의/개념: 2D/3D 공간 데이터에 **국소 수용장** 및  **가중치 공유** 활용  적용하여 계층적 특징을 추출하는 딥러닝 신경망 아키텍처
- 배경/필요성: 완전연결계층(FC)의 1차원 평탄화에 따른 **공간 위상 정보 유실** 및 파라미터 폭증 한계 극복 필요

#### 한줄 요약

- 국소 수용장과 가중치 공유를 통해 2D 공간 특징을 계층적으로 추출하고 파라미터 수를 최적화

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **수용영역(Receptive Field)**: 출력 특징 맵의 단일 픽셀이 참조하는 원본 입력 이미지 상의 물리적 영역 크기.
- **스트라이드(Stride) 및 패딩(Padding)**: 필터 이동 보폭(Stride)과 가장자리 0 채움(Zero-padding)으로 출력 특징 맵의 해상도를 제어하는 하이퍼파라미터.

</details>

- 국소 연결 및 **가중치 공유** 활용  통한 파라미터 절감
- 계층 심화에 따른 수용영역 확장 및 **고수준 특징 합성**
- 풀링과 스트라이드를 통한 **공간적 이동 불변성 확보**

#### 한줄 요약

- 얕은 층이 에지를 추출하고 깊은 층이 이를 고수준 객체 부분으로 계층 결합

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **CNN 3대 기본 레이어**:
  - 합성곱 계층 (Conv): 커널 필터와의 2D 상호 상관(Cross-correlation)으로 특징 맵 생성.
  - 활성화 계층 (ReLU): 비선형 표현력 부여.
  - 풀링 계층 (Pooling): 해상도 축소 및 대표 특징 요약.

</details>

```text
[ CNN 표준 계층적 처리 구조도 ]
 입력 영상 (H × W × C)
       │
       ▼
 ┌──────────────────────────────┐
 │ 합성곱 계층 (Conv + ReLU)     │ ── 3×3 커널 합성곱으로 특징 맵(Feature Map) 추출
 └─────────────┬────────────────┘
               │
               ▼
 ┌──────────────────────────────┐
 │ 풀링 계층 (Max-Pooling)      │ ── 2×2 스트라이드로 공간 해상도 1/2 다운샘플링
 └─────────────┬────────────────┘
               │ (반복 심화)
               ▼
 ┌──────────────────────────────┐
 │ 글로벌 풀링 / FC 계층        │ ── 특징 맵 평탄화(Flatten) 및 클래스 로짓 산출
 └─────────────┬────────────────┘
               │
               ▼
   최종 분류 확률 (Softmax)
```

선의 의미: 입력 텐서, 합성곱-풀링 특징 추출 블록 및 최종 분류기 간의 계층적 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 합성곱 계층 (Conv) | 국소 커널 필터를 적용하여 **엣지, 텍스처 등 국소 공간 특징 맵 추출** |
| 활성화 계층 (ReLU) | 선형 합성곱 결과에 **비선형성 부여** |
| 풀링 계층 (Pooling) | 공간 해상도를 축소하여 **연산량 절감 및 이동 불변성 확보** |
| 완전연결/GAP 계층 | 추출된 고수준 특징을 집계하여 **최종 클래스 분류 확률 도출** |

#### 한줄 요약

- 합성곱 계층이 국소 패턴을 추출하면 활성화 함수와 풀링이 반응을 선별·축소하여 출력 계층에 전달

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **특징 맵 크기 계산식**: $O = \lfloor \frac{W - K + 2P}{S} \rfloor + 1$ ($W$:입력크기, $K$:커널크기, $P$:패딩, $S$:스트라이드).

</details>

```text
입력 텐서 (Batch, Height, Width, Channels)
   │
   ▼
[ 1. 2D 합성곱 연산 (Conv2D: O = (W - K + 2P)/S + 1) ]
   │
   ▼
[ 2. 배치 정규화(BatchNorm) 및 비선형 활성화 (ReLU) ]
   │
   ▼
[ 3. 공간 해상도 축소 (Max/Avg Pooling: 2×2 stride 2) ]
   │
   ├─► [ 1 ~ 3 단계 심층 블록 반복 (ResNet / EfficientNet) ]
   │
   ▼
[ 4. Global Average Pooling (GAP) 특징 벡터 요약 ]
   │
   ▼
[ 5. Linear 분류기 및 Softmax 확률 출력 ]
```

**동작 원리**

1. **2D 합성곱 연산**: 커널 필터를 슬라이딩해 위치별 특징 맵 산출
2. **배치 정규화 및 비선형 활성화**: BatchNorm으로 분포 안정화 후 ReLU 활성화
3. **공간 해상도 축소**: 풀링을 적용해 공간 차원을 줄이고 채널 확장
4. **GAP 특징 벡터 요약**: 공간 차원을 평균 요약해 파라미터 축소
5. **Linear 분류기 및 확률 출력**: 최종 클래스별 확률 벡터 생성

#### 한줄 요약

- 입력 텐서가 합성곱 커널을 거쳐 특징 맵으로 변환되고, 풀링으로 축소된 특징이 최종 분류 출력으로 변환

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **비전 모델 3대 패러다임**:
  - CNN: 강력한 공간 귀납 편향(Inductive Bias), 적은 데이터로도 우수한 수렴, 국소 특징 특화.
  - MLP: 공간 구조 파괴, 파라미터 폭증, 평탄화된 테이블 데이터용.
  - ViT (Vision Transformer): 패치 단위 Self-Attention, 약한 귀납 편향, 대규모 데이터 사전학습 시 전역 문맥 압도.

</details>

| 신경망 모델 | 합성곱 신경망 (CNN) | 완전연결망 (FC / MLP) | 비전 트랜스포머 (ViT) |
|:---|:---|:---|:---|
| 적용 기준 | 2D/3D 이미지 및 중소형 비전 데이터 | 테이블형 정형 데이터 및 1D 입력 | 대규모 사전학습 이미지 및 멀티모달 |
| 핵심 특징 | **국소 연결 및 가중치 공유** 기반 불변성 | 모든 입력 노드 간 완전 연결 | **패치 임베딩 및 전역 Self-Attention** |
| 한계 | 장거리 전역 문맥 파악에 많은 계층 필요 | 파라미터 폭증 ($O(N^2)$) 및 공간 파괴 | **대규모 사전학습 데이터(JFT 등) 필수** |

#### 한줄 요약

- 국소 패턴과 제한된 데이터는 CNN, 전역 관계 모델링과 대규모 데이터는 ViT를 적용

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Grad-CAM(Gradient-weighted Class Activation Mapping)**: 최종 합성곱 계층의 특징 맵에 대한 타깃 클래스 기울기를 가중치로 결합하여 모델이 이미지의 어느 영역을 보고 판단했는지 히트맵으로 시각화하는 XAI 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 조명/각도 변화 시 이미지 분류 모델의 **오탐률 급증** | **RandAugment, CutMix, Albumentations** 데이터 증강 | 도메인 변형에 대한 강건성 극대화 |
| 임베디드/엣지 디바이스에서의 **추론 지연 및 메모리 부족** | **MobileNet(Depthwise Separable Conv)** 및 INT8 양자화 | 연산량 80% 절감 및 실시간성 확보 |
| 모델 판단 근거의 불투명성으로 인한 **블랙박스 문제** | **Grad-CAM 기반 활성 영역 히트맵 시각화** | 오탐 원인 분석 및 설명 가능성 확보 |
| 초심층망(50+ 층) 학습 시 **기울기 소실 및 성능 퇴화** | **ResNet 잔차 연결(Residual Skip-Connection)** 도입 | 1000층 이상의 안정적 역전파 보장 |

#### 한줄 요약

- 데이터 부족은 RandAugment로 보완하고, 모바일에는 MobileNet 경량 아키텍처를 적용하며, 판단 근거는 Grad-CAM으로 시각화하고, 깊은 네트워크는 ResNet 잔차 연결로 기울기 소실을 방지한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **컴퓨터 비전 하이브리드 표준**: 엣지 디바이스나 데이터가 제한된 실시간 산업용 검사에는 ConvNeXt 등 최신 CNN을 적용하고, 대규모 클라우드 멀티모달 AI에는 ViT/Swin-Transformer를 선택하는 설계 원칙.

</details>

- 국소 공간 패턴과 경량 엣지 환경에는 **CNN(ResNet/ConvNeXt)**, 초대규모 데이터셋과 전역 문맥 추론에는 **ViT** 활용  선택

#### 한줄 요약

- 국소 패턴과 제한된 데이터는 CNN, 전역 장거리 관계가 핵심이면 ViT를 선택
