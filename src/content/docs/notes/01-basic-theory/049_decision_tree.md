## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **결정 트리**: 특징 조건을 따라 데이터를 분할하고 리프에서 결과를 예측하는 모델
- **비선형 규칙**: 여러 조건이 굽거나 꺾여 결합되어 하나의 직선으로 표현하기 어려운 규칙
- **특징 조건**: 입력 변수와 임계값 또는 범주를 비교해 표본을 나누는 규칙
- **변수 상호작용**: 한 변수의 효과가 다른 변수의 값에 따라 달라지는 관계

</details>

- 정의/개념: **특징 조건**으로 데이터를 나눠 리프에서 예측하는 모델
- 배경/필요성: 선형 경계로는 변수 상호작용의 **비선형 규칙 학습 불가**

#### 한줄 요약

- 질문판에서 답을 고를 때마다 가지가 갈리고 마지막 잎에서 결과표를 받는 장면이다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **불순도**: 한 노드에 서로 다른 클래스가 섞인 정도
- **정보 이득**: 분할 전후의 불순도 차이로 측정한 분할의 유용성
- **스케일 변환 불변성**: 값의 순서가 같으면 단위나 크기를 바꿔도 분할이 유지되는 성질
- **규칙 경로**: 루트부터 리프까지 거친 특징 조건의 순서
- **설명력**: 모델이 예측에 사용한 조건과 근거를 사람이 이해할 수 있는 정도

</details>

- 분할 후 **불순도 감소•정보 이득** 을 최대화
- 루트부터 리프까지의 **규칙 경로** 에 기반한 높은 설명력
- 특징값의 순서만 사용하는 **스케일 변환 불변성**

#### 한줄 요약

- 섞인 색 카드 상자를 질문 하나로 나눠 같은 색끼리 모으고, 단위가 바뀌어도 카드 순서는 유지하는 장면이다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **루트 노드**: 전체 입력을 담고 최초 분할을 수행하는 시작 노드
- **내부 노드**: 특징과 임계값 조건으로 데이터를 다시 나누는 노드
- **리프 노드**: 최종 클래스나 회귀 예측값을 저장하는 끝 노드
- **임계값(Threshold)**: 수치 특징을 두 구간으로 나눌 때 사용하는 기준값
- **회귀값**: 연속형 목표를 예측하도록 리프에 저장한 수치

</details>

```mermaid
block
    columns 3
    R["루트 노드"]
    N["내부 노드"]
    L["리프 노드"]
    R --- N
    N --- L
```

| 구성요소 | 책임 |
|:---|:---|
| 루트 노드 | 전체 입력을 포함하는 **최초 분할** 대상 |
| 내부 노드 | 변수•**임계값** 조건으로 재귀 분할 |
| 리프 노드 | 최종 클래스•**회귀값** 저장 |

#### 한줄 요약
- 도로 입구인 루트에서 조건 표지판을 따라 갈림길을 지나 목적지인 리프에 도착하는 장면이다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **분할 조건**: 입력 특징과 임계값을 비교해 다음 자식 노드를 정하는 규칙
- **임계값**: 수치형 특징을 두 구간으로 나눌 때 사용하는 기준값
- **내부 노드**: 특징 조건을 검사해 다음 자식 노드를 선택하는 노드
- **클래스•회귀값**: 분류 범주와 연속 수치 예측 결과

</details>

```mermaid
sequenceDiagram
    participant T as 탐색 제어기
    participant N as 현재 노드
    participant X as 입력 특징 저장소
    participant L as 리프 노드
    T->>N: 루트 노드 선택
    loop 현재 노드가 내부 노드
        T->>N: 1. 분할 조건 조회
        N->>X: 2. 특징값 읽기
        X-->>N: 입력 표본의 해당 값
        N-->>T: 3. 선택 자식 노드
        T->>N: 선택한 자식으로 이동
    end
    T->>L: 4. 리프 예측값 조회
    L-->>T: 클래스•회귀값
```

**동작 원리**

- **1. 분할 조건 조회**: 특징•임계값 확인
- **2. 특징값 읽기**: 입력 표본의 지정 변수 조회
- **3. 선택 자식 노드**: 임계값 비교로 다음 노드 확정
- **4. 리프 예측값 조회**: 클래스•회귀값 반환

#### 한줄 요약

- 입력표를 들고 갈림길의 임계값 표지판을 차례로 확인해 마지막 잎의 값을 받는 장면이다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **지니 불순도**: 클래스 비율을 바탕으로 계산한 무작위 오분류 가능성
- **엔트로피**: 클래스 분포가 얼마나 불확실하게 섞였는지를 나타내는 값
- **평균제곱오차(MSE)**: 실제값과 예측값 차이를 제곱해 평균한 회귀 오차
- **불균형 클래스**: 클래스별 표본 수 차이가 커 다수 클래스가 분할을 지배하는 상태
- **이상치(Outlier)**: 다른 관측값에서 크게 벗어나 분할 위치를 왜곡할 수 있는 값
- **분할 기준**: 후보 조건 중 불순도나 회귀 오차를 가장 많이 줄이는 조건을 고르는 척도

</details>

| 결정 트리 | 분류 트리 | 회귀 트리 |
|:---|:---|:---|
| 적용 기준 | 목표가 합격•불합격 같은 **범주형 라벨** | 목표가 가격•수량 같은 **연속 수치** |
| 핵심 특징 | **지니 불순도**•엔트로피로 범주 분할 | **MSE** 감소량으로 수치 분할 |
| 한계 | **불균형 클래스** 의 다수 쏠림 편향 | **이상치** 에 따른 분할 위치 왜곡 |

> 요약: 목표 변수의 형태에 따라 **분할 기준** 결정

#### 한줄 요약

- 분류 트리는 투표함에서 이름표를 고르고, 회귀 트리는 가격 눈금에서 수치를 읽는 장면이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **가지치기**: 예측 기여가 작은 하위 트리를 제거해 과적합을 줄이는 방법
- **정지 조건**: 깊이•표본 수 등을 기준으로 노드를 더 분할하지 않도록 하는 규칙
- **재현율**: 실제 양성 표본 중 모델이 양성으로 올바르게 찾아낸 비율
- **이상치**: 다른 관측값에서 크게 벗어나 분할 위치를 왜곡할 수 있는 값
- **클래스 가중치**: 소수 클래스의 분할 손실 비중을 높이는 계수
- **강건한 손실 기준**: 이상치의 영향이 지나치게 커지지 않도록 제한한 분할 오차 척도
- **특징 분포 모니터링**: 운영 입력 변수의 범위와 빈도가 학습 때와 달라지는지 감시하는 작업

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 학습 성능은 높고 **검증 성능은 낮음** | **정지 조건** 설정과 **가지치기** | **과적합•고분산** 완화 |
| 소수 클래스 **재현율 저하** | 클래스 가중치•균형 표본과 **클래스별 지표** 적용 | **다수 클래스 편향** 감소 |
| 회귀 분할이 **이상치에 끌림** | 이상치 검토•**강건한 손실 기준** 적용 | **분할 경계** 안정화 |
| 데이터 변화로 **규칙 경로 변동** | 분할 안정성•**특징 분포 모니터링** 과 재학습 | 설명 규칙의 **일관성 관리** |

#### 한줄 요약

- 정원사가 검증 성능을 해치는 약한 가지를 자르고 나무 높이를 제한하는 장면이다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **검증 성능**: 학습에 쓰지 않은 데이터에서 측정한 예측 성능
- **규칙 수**: 루트에서 리프까지 만들어진 조건 조합의 규모
- **가지치기(Pruning)**: 예측 기여가 작은 하위 트리를 제거해 과적합과 규칙 수를 줄이는 방법

</details>

- **검증 성능 저하** 나 규칙 수 초과 시 **가지치기** 적용

#### 한줄 요약

- 검증 점수가 내려가거나 규칙표가 너무 길어지는 지점에서 나무 성장을 멈추는 장면이다.
