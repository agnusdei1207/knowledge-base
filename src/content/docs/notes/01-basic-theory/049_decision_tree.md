## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **결정 트리(Decision Tree)**: 특징(Feature)의 조건 분기($X_j \le \text{Threshold}$)를 계층적 트리 구조로 분할하여 데이터를 순수도가 높은 리프 노드로 나누는 화이트박스 머신러닝 모델.
- **불순도(Impurity)**: 특정 노드 내에 서로 다른 클래스의 데이터 표본이 혼합되어 있는 무질서도의 척도(지니 불순도, 엔트로피).
- **정보 이득(Information Gain)**: 부모 노드의 불순도에서 자식 노드들의 가중 평균 불순도를 뺀 값으로 분할 전후의 순수도 개선량.

</details>

- 정의/개념: 특징 공간을 축에 평행한 초평면(Orthogonal Hyperplane)으로 반복 재귀 분할하여 If-Else 규칙 기반으로 분류 및 회귀를 수행하는 **화이트박스 비모수 모델**
- 배경/필요성: 딥러닝/앙상블의 블랙박스 문제를 극복하고 금융 신용평가, 의료 진단 등에서 **의사결정 경로의 투명한 설명 가능성(Explainability) 확보 필수**

#### 한줄 요약

- 특징 조건의 재귀적 분할을 통해 투명한 If-Else 규칙 경로와 예측값을 제공하는 트리 모델

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **스케일 불변성(Scale Invariance)**: 특징값의 단조 증가 변환(Monotonic Transformation)이나 단위 크기에 무관하게 분할 순서와 결과가 완벽히 동일하게 유지되는 성질.
- **탐욕적 분할(Greedy Splitting)**: 현재 스텝에서 정보 이득이 최대가 되는 최적 분할점만을 선택하는 하향식(Top-Down) 휴리스틱.

</details>

- 직관적인 If-Else 규칙 기반으로 **인간이 직접 이해할 수 있는 최고 수준의 설명력(XAI)**
- 데이터의 정규화/표준화가 불필요한 **특징 스케일 불변성(Scale Invariance)**
- 트리의 깊이가 깊어질수록 훈련 표본에 과도하게 적응하여 발생하는 **고분산 과적합(Overfitting) 취약성**

#### 한줄 요약

- 불순도 감소량을 최대화하는 탐욕적 분할로 설명력을 극대화하되, 과적합 제어가 핵심

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **결정 트리 3대 노드 계층**:
  - 루트 노드 (Root): 전체 데이터셋을 포함하는 최초 분할 노드.
  - 내부 노드 (Internal): 특징 $j$와 임계치 $t$로 2진 분기($X_j \le t$).
  - 리프 노드 (Leaf): 더 이상 분할되지 않고 최종 클래스 다수결/회귀 평균값 반환.

</details>

```text
[ 결정 트리 2진 분할 구조도 ]
                   [ 루트 노드: 소득 ≤ 5,000만원 ]
                           /            \
                       (Yes)            (No)
                       /                    \
       [ 내부 노드: 신용점수 ≤ 700 ]     [ 리프 노드: 대출 승인 (Class 1) ]
             /             \
         (Yes)             (No)
         /                     \
 [ 리프: 거절 (Class 0) ]   [ 리프: 승인 (Class 1) ]
```

선의 의미: 루트 노드, 내부 조건 분기 및 최종 리프 예측 노드 간의 계층적 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 루트 노드 (Root Node) | 전체 입력 표본을 수용하고 **최대 정보 이득 특징으로 1차 분할** |
| 내부 노드 (Internal Node) | 최적 분할 특징($j$) 및 임계값($t$) 조건으로 **자식 노드 분기** |
| 리프 노드 (Leaf Node) | 최종 도달 표본들의 **다수결 클래스 또는 평균값 산출** |
| 불순도 평가기 | **Gini / Entropy / Variance Reduction** 계산으로 최적 분할점 탐색 |

#### 한줄 요약

- 루트에서 시작하여 내부 조건 노드를 거쳐 리프 노드의 예측값을 도출하는 계층적 구조

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **사전/사후 가지치기(Pruning)**:
  - 사전 가지치기: 최대 깊이(`max_depth`), 최소 분할 표본 수(`min_samples_split`)로 성장 제한.
  - 사후 가지치기: 트리를 최대로 키운 후 비용-복잡도($\text{Cost-Complexity: } R_\alpha(T) = R(T) + \alpha |T|$)로 하위 노드 제거.

</details>

```text
훈련 데이터셋 (X, y) 입력
   │
   ▼
[ 1. 현재 노드의 정지 조건(Stop Condition) 검사 ]
├─ 노드 순수도 100% (Gini=0) 또는 max_depth / min_samples 도달
│  │
│  └─► [ 리프 노드로 확정 및 다수결/평균값 할당 ]
│
└─ 정지 조건 미달 (분할 계속)
   │
   ▼
[ 2. 모든 특징(Feature) 및 가능한 모든 분할 임계값(Threshold) 탐색 ]
   │
   ▼
[ 3. 정보 이득(Information Gain) 최대 분할점 (j*, t*) 선정 ]
   │
   ▼
[ 4. 좌/우 자식 노드로 데이터 분할 및 1단계 재귀 호출 (CART 알고리즘) ]
   │
   ▼
[ 5. 비용-복잡도 사후 가지치기(Cost-Complexity Pruning) 수행 ]
```

**동작 원리**

1. **정지 조건 확인**: 현재 노드의 깊이나 샘플 수가 한계에 도달했는지 검사
2. **최적 분할 탐색**: 모든 연속형/범주형 변수에 대해 불순도 감소량이 최대가 되는 임계점 산출
3. **자식 노드 분기**: CART(Classification and Regression Trees) 알고리즘으로 데이터를 2진 분할
4. **재귀 트리 확장**: 자식 노드에 대해 동일 과정을 재귀 반복
5. **가지치기(Pruning)**: 검증셋을 바탕으로 과적합된 잔가지를 정리하여 일반화 성능 확보

#### 한줄 요약

- 정보 이득을 최대화하는 최적 임계값으로 2진 분할을 재귀 수행하고, 가지치기로 과적합을 제어

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **불순도 지표 수식**:
  - 지니 불순도 (Gini): $Gini(p) = 1 - \sum_{k=1}^K p_k^2$ (연산 빠름, CART 표준).
  - 엔트로피 (Entropy): $H(p) = -\sum_{k=1}^K p_k \log_2 p_k$ (로그 연산, C4.5 표준).
  - 분산 감소량 (Variance Reduction): 회귀 트리에서 $MSE(y) - \sum \frac{N_i}{N} MSE(y_i)$.

</details>

| 비교 항목 | 분류 트리 (Classification Tree) | 회귀 트리 (Regression Tree) |
|:---|:---|:---|
| 타깃 변수 형태 | **이산형 범주 라벨 (Discrete Classes)** | **연속형 수치 데이터 (Continuous Values)** |
| 분할 기준 지표 | **지니 불순도 (Gini) / 엔트로피 (Entropy)** | **분산 감소량 (Variance Reduction / MSE)** |
| 리프 노드 출력 | **다수결 투표 (Majority Voting) 및 클래스 확률** | **해당 리프에 속한 표본들의 평균값 (Mean)** |
| 결정 경계 특성 | 축에 수직인 계단식 2차원 영역 분할 | 조각별 상수 함수 (Piecewise Constant) 근사 |
| 취약점 | 클래스 불균형 시 다수 클래스 편향 | 이상치(Outlier)에 의한 분할 왜곡 |

#### 한줄 요약

- 범주 분류는 지니/엔트로피 기준, 수치 예측은 분산 감소량(MSE) 기준으로 트리를 분할

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **축 정렬 분할 한계(Axis-aligned Split Limitation)**: 결정 트리는 항상 단일 축에 수직인 직선($X_1 \le t$)으로만 공간을 자르므로 대각선 방향의 선형 관계($X_1 + X_2 \le 1$)를 표현하기 위해 수많은 계단식 노드가 낭비되는 기하학적 결함.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 트리 깊이 심화로 인한 **극단적 훈련셋 과적합(고분산)** | `max_depth=5`, `min_samples_leaf=20` **사전 제약 및 가지치기** | 일반화 오차 및 검증 손실 개선 |
| 불균형 데이터셋에서 **다수 클래스로의 분할 쏠림** | `class_weight='balanced'` 부여 및 오버샘플링 | 소수 클래스 재현율(Recall) 확보 |
| 대각선 선형 관계 데이터의 **계단식 분할 비효율성** | **PCA 선행 차원 축소** 또는 선형 모델/SVM 병용 | 분할 노드 수 절감 및 경계 단순화 |
| 데이터셋의 미세 변동으로 인한 **트리 구조의 급격한 변동(불안정성)** | **랜덤 포레스트(Random Forest) 앙상블** 배깅 전환 | 모델 예측 분산 축소 및 안정성 확보 |

#### 한줄 요약

- 사전·사후 가지치기로 과적합을 방지하고, 클래스 불균형에는 class_weight를 적용하며, 대각선 결정 경계 한계는 PCA로 완화하고, 분산이 크면 Random Forest 앙상블로 전환한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **규제 및 규정 준수 AI 표준**: 금융 대출 심사, 채용 심사, 의료 가이드라인처럼 모델의 판단 근거를 법적으로 증명해야 하는 고신뢰성 도메인에서 단일 결정 트리는 대체 불가능한 핵심 알고리즘으로 기능.

</details>

- 인간 해석 가능성/화이트박스 룰은 **단일 결정 트리**, 고차원 비선형 예측 성능은 **랜덤 포레스트/XGBoost** 선택

#### 한줄 요약

- 설명력과 규칙 경로가 최우선일 때 결정 트리를 채택하고, 가지치기로 모델 복잡도를 제어
