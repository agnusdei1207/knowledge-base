## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **결정 트리(Decision Tree)**: 특징 공간을 순차적인 조건문으로 분할하여 트리 구조 형태로 예측을 수행하는 지도학습 모델.
- **불순도(Impurity)**: 한 노드 안에 서로 다른 클래스의 데이터가 얼마나 혼합되어 있는지를 나타내는 척도.
- **정보 획득량(Information Gain)**: 부모 노드의 엔트로피에서 분할 후 자식 노드들의 가중 평균 엔트로피를 뺀 감소량.

</details>

- 정의/개념: 데이터의 특징 공간을 순차적 분기 규칙으로 분할하여 **정보 획득량 극대화** 또는 **지니 불순도 최소화** 달성 목적의 트리 기반 지도학습 모델
- 배경/필요성: 선형 모델의 비선형 변수 상호작용 표현 한계와 복잡한 딥러닝 모델의 **해석 및 설명 불가능성(Explainability) 한계**

#### 한줄 요약

- 분기를 깊게 할수록 표현력과 함께 훈련 데이터 암기도 같이 늘어, 해석 가능성은 얕은 트리에서만 유지된다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **비모수적 모델(Non-parametric Model)**: 데이터의 특정 확률 분포를 사전에 가정하지 않고 데이터에 따라 모델 구조가 유연하게 확장되는 모델.
- **과적합(Overfitting)**: 모델이 훈련 데이터의 노이즈까지 지나치게 학습하여 새로운 데이터에 대한 일반화 성능이 저하되는 현상.

</details>

- **if-then 규칙 생성** 기반 높은 모델 직관성 및 의사결정 과정의 설명 가능성 제공
- 특징의 스케일 변환에 영향을 받지 않는 **비모수적(Non-parametric) 데이터 분할** 지원
- 탐욕적(Greedy) 분할 메커니즘으로 인해 깊이가 깊어질수록 **과적합(Overfitting) 발생 취약**

#### 한줄 요약

- 해석력이 뛰어나고 정규화가 불필요하지만, 깊이가 깊어질수록 과적합에 취약한 특성 보유

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **루트 노드(Root Node)**: 트리 구조의 최상단에서 전체 데이터를 최초로 분기하는 시작 노드.
- **리프 노드(Leaf Node)**: 더 이상 분기하지 않고 최종 분류 클래스나 회귀 예측값을 결정하는 말단 노드.

</details>

```text
[ 루트 노드: 특징 X1 <= 임계값 ]
       |
       +-- 참: [ 내부 노드: 특징 X2 <= 임계값 ]
       |                       |
       |                       +-- 참: [ 리프 노드: 클래스 A ]
       |                       `-- 거짓: [ 리프 노드: 클래스 B ]
       |
       `-- 거짓: [ 리프 노드: 클래스 C ]
```

선의 의미: 조건 분기 방향에 따른 데이터 부분집합 소유 관계

| 구성요소 | 책임 |
|:---|:---|
| 루트 노드 | 전체 데이터셋 대상 **최대 정보 획득 분할 기준** 적용 |
| 내부 노드 | 특징별 최적 분할 임계값을 통한 **하위 부분집합 분기** |
| 리프 노드 | 분할 완료 후 최종 **다수결 클래스 또는 평균값 산출** |
| 분할 기준 함수 | 지니 불순도 또는 엔트로피 계산을 통한 **최적 분기점 판정** |

#### 한줄 요약

- 루트 노드에서 시작하여 내부 조건 노드를 거쳐 최종 예측을 내리는 리프 노드로 계층 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **지니 불순도(Gini Impurity)**: 무작위로 선택한 원소가 잘못 분류될 확률을 측정하는 지표($1 - \sum p_i^2$).
- **가지치기(Pruning)**: 과적합 방지를 위해 불필요하게 깊어진 트리의 분기를 잘라내는 최적화 기법.

</details>

```text
데이터셋 입력
      │
      ▼
[ 1. 특징별 불순도 계산 ]
      │
      ▼
[ 2. 최적 분할점 선택 ] ──► (지니 불순도 최소화 / 정보 획득량 극대화)
      │
      ▼
[ 3. 자식 노드 분할 ]
      │
      ▼
[ 4. 정지 조건 판정 ] ────► 참 ──► [ 5. 가지치기 적용 ] ──► 최종 트리 완성
      │ (거짓)
      └── (하위 데이터 재귀 분기)
```

**동작 원리**

1. **특징별 불순도 계산**: 각 특징과 분할 후보값에 대해 지니 불순도 및 엔트로피 산출
2. **최적 분할점 선택**: 불순도 감소량이 최대가 되는 단일 특징 및 분할 임계값 결정
3. **자식 노드 분할**: 결정된 임계값을 기준으로 좌우 자식 노드로 데이터 부분집합 분기
4. **정지 조건 판정**: 최대 깊이 도달, 최소 샘플 수 미달, 순도 100% 도달 여부 검사
5. **가지치기 적용**: 과적합 억제를 위해 비용 복잡도 기준 하위 노드 병합

#### 한줄 요약

- 불순도를 최소화하는 최적 분할점을 탐욕적으로 찾아 재귀 분할하고 가지치기를 통해 모델 일반화

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **지니 불순도(Gini Impurity, CART)**: 제곱합 계산을 기반으로 연산 속도가 빠른 이진 분할 지표.
- **엔트로피(Entropy, ID3/C4.5)**: 정보이론의 엔트로피 감소량을 기반으로 최적 특징을 선택하는 분할 지표.
- **분산 감소량(Variance Reduction)**: 회귀 트리에서 타깃 값의 분산 감소량을 최대화하는 수치 분할 지표.

</details>

| 결정 트리 분할 지표 | 지니 불순도 (CART) | 엔트로피 (ID3·C4.5) | 분산 감소량 (회귀 트리) |
|:---|:---|:---|:---|
| 적용 기준 | **빠른 연산 속도** 요구 범용 이진 분류 시 | **다치 분할** 및 엄밀한 정보이론 척도 적용 시 | **연속형 수치값** 예측 목적의 회귀 과업 시 |
| 핵심 특징 | **로그 연산 배제 제곱합 계산** 기반 연산 경량화 | **로그 기반 엔트로피 측정** 및 정보 획득률 산출 | **노드 내 타깃 값의 분산 감소량** 최대화 분할 |
| 한계 | **다범주 분기 특징** 대상 편향 분할 가능성 | 로그 연산으로 인한 **계산 오버헤드 증가** | **이상치(Outlier)** 노이즈 대상 예측 분산 민감성 |

#### 한줄 요약

- 고속 이진 분류는 지니 불순도, 정밀 정보이론 분석은 엔트로피, 연속값 예측은 분산 감소량을 선택

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **비용 복잡도 가지치기(Cost Complexity Pruning)**: 트리 복잡도에 패널티($\alpha |T|$)를 부여하여 검증 오차를 최소화하는 사후 가지치기 기법.
- **랜덤 포레스트(Random Forest)**: 다수의 결정 트리를 배깅과 특징 무작위 선택으로 결합한 앙상블 알고리즘.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 트리 깊이 심화에 따른 **훈련 데이터 과적합** | **사전 최대 깊이 제한 및 비용 복잡도 사후 가지치기** | 일반화 성능 확보 및 모델 경량화 |
| 특정 우세 특징에 의한 **불균형 편향 분기** | **랜덤 포레스트 앙상블 도입 및 특징 무작위 선택** | 분산 감소 및 예측 안정성 향상 |
| 훈련 데이터 미세 변동 시 **트리 구조 급변(불안정성)** | **부트스트랩 집계(Bagging) 기반 다중 트리 결합** | 모델 분산 억제 및 견고성 확보 |

#### 한줄 요약

- 과적합은 가지치기로 방어하고, 편향과 구조적 불안정성은 랜덤 포레스트 앙상블 결합으로 해결

## Ⅶ. 결론

- 금융 신용 평가, 의료 진단 보조 및 규제 준수(XAI) 분야의 **대표적 백색상자(White-box) 설명 가능 모델이자 앙상블(Random Forest, XGBoost, LightGBM)의 핵심 기본 단위(Base Estimator)**로 확립되었으며, 실무에서는 **과적합 방지를 위한 최대 깊이(max_depth) 제한 및 비용 복잡도 가지치기(Cost Complexity Pruning)**를 필수 적용

#### 한줄 요약

- 설명 가능성이 필수인 환경은 단일 트리로 유지하고, 예측 성능이 핵심인 환경은 앙상블 모델로 전환
