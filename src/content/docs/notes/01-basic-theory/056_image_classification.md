## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **심층 특징 추출(Deep Feature Extraction)**: 합성곱 및 어텐션 레이어를 통해 저수준 엣지부터 고수준 객체 형상까지 계층적 특징 맵을 자율 학습하는 과정.
- **처리 지연 및 오분류 비용(Latency & Misclassification)**: 인간의 수작업 검사 시 피로도로 인한 불량 검출 실패 및 대량 영상의 실시간 분류 불가 한계.

</details>

- 정의/개념: 입력 영상 전체의 시각적 패턴을 분석하여 사전 정의된 단일/다중 클래스에 할당하는 **심층 특징 추출(Feature Extraction) 기반** 컴퓨터 비전 인지 기술
- 배경/필요성: 수작업 육안 검사의 주관적 판정 오류 극복 및 대규모 비정형 영상의 신속·정확한 자동화 분류 체계 필요

#### 한줄 요약

- 분류 모델이 이미지의 선•질감•형태를 계층적으로 추출하고 클래스별 점수가 가장 높은 레이블을 출력하는 구조이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **계층적 특징**: 얕은 층의 선•질감부터 깊은 층의 사물 형태까지 단계적으로 학습한 표현이다.
- **단일 레이블(Single-label)**: 이미지마다 하나의 클래스를 판정하는 방식이다.
- **다중 레이블(Multi-label)**: 이미지마다 여러 클래스를 판정하는 방식이다.
- **촬영 분포**: 조명•각도•배경 등 입력 이미지가 생성되는 조건의 분포이다.
- **해상도(Resolution)**: 이미지를 구성하는 가로•세로 픽셀 수이다.
- **정확도 의존성**: 입력 해상도나 촬영 조건 변화에 따라 분류 성능이 달라지는 성질이다.

</details>

- 저수준 질감부터 고수준 의미까지의 **계층적 특징 학습**
- 점수에 기반한 **단일 및 다중 레이블 판정**
- 입력 해상도 및 촬영 환경에 따른 **정확도 의존성**

#### 한줄 요약

- 얕은 합성곱 계층이 선과 질감을 추출하고 깊은 계층이 고수준 의미 특징을 구성하며, 해상도가 높을수록 추론 시간이 증가하는 구조이다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **백본**: 입력 이미지에서 특징 맵을 추출하는 신경망 본체이다.
- **전역 평균 풀링(Global Average Pooling, GAP)**: 채널별 특징 맵의 평균으로 공간 축을 줄이는 집계 방식이다.
- **분류 헤드**: 집계된 특징을 클래스별 점수로 변환하는 출력 모듈이다.
- **입력 텐서**: 높이•너비•채널•배치 축으로 표현한 이미지 수치 배열이다.
- **합성곱(Convolution)**: 공유 필터를 이미지 위치마다 적용해 국소 특징 맵을 만드는 연산이다.
- **최종 레이블**: 클래스별 점수를 판정 규칙에 적용해 선택한 출력 범주이다.

</details>

```text
[입력 전처리기]
        |
[특징 추출 백본]
        |
   [특징 집계]
        |
   [분류 헤드]
```

선의 의미: 선은 입력 텐서, 특징 맵과 집계 벡터를 공유하는 인접 구성요소의 정적 인터페이스 관계를 뜻한다.

| 구성요소 | 책임 |
|:---|:---|
| 입력 전처리기 | 해상도•정규화•색상 순서를 맞춘 **입력 텐서** 생성 |
| 특징 추출 백본 | **합성곱**으로 계층적 특징 맵 생성 |
| 특징 집계 | **전역 평균 풀링** 기반 고정 길이 벡터 변환 |
| 분류 헤드 | **클래스별 점수•최종 레이블** 산출 |

#### 한줄 요약
- 입력 전처리기가 해상도와 색상을 정규화하고, 특징 추출 백본과 전역 평균 풀링을 거쳐 분류 헤드의 클래스별 점수로 출력되는 구조이다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **특징 벡터**: 공간 특징 맵을 분류에 사용할 고정 길이 값으로 요약한 표현이다.
- **정규화(Normalization)**: 픽셀값의 중심과 척도를 학습 때 기준에 맞추는 전처리이다.
- **계층적 특징 맵**: 얕은 질감부터 깊은 의미까지 단계별로 추출한 공간 표현이다.
- **입력 텐서 전처리**: 해상도•픽셀 정규화•색상 순서를 학습 조건에 맞춰 입력 배열로 만드는 단계이다.
- **계층적 특징 추출**: 합성곱 층을 거치며 질감부터 의미까지 단계별 특징 맵을 생성하는 단계이다.
- **공간 특징 집계**: 특징 맵의 공간 축을 요약해 고정 길이 특징 벡터로 바꾸는 단계이다.
- **클래스 레이블 판정**: 분류 헤드의 클래스별 점수로 최종 범주를 선택하는 단계이다.

</details>

```text
[입력 이미지]
      |
      v
1. 입력 텐서 전처리
      |
      v
2. 계층적 특징 추출
      |
      v
3. 공간 특징 집계
      |
      v
4. 클래스 레이블 판정
      |
      v
[클래스별 점수•레이블]
```

**동작 원리**

1. **입력 텐서 전처리**: 해상도 및 정규화, 색상 순서 통일
2. **계층적 특징 추출**: 합성곱으로 저수준 질감부터 의미까지 특징 맵 생성
3. **공간 특징 집계**: GAP를 적용해 고정 길이 특징 벡터로 요약
4. **클래스 레이블 판정**: 분류 헤드의 점수로 최종 클래스 결정

#### 한줄 요약

- 이미지가 계층적 특징 맵과 전역 평균 풀링을 거쳐 분류 헤드에서 최고 점수 클래스 레이블로 출력되는 흐름이다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **시각 기하 그룹망(Visual Geometry Group Network, VGG)**: 작은 합성곱 필터를 반복 적층한 백본이다.
- **잔차 신경망(Residual Network, ResNet)**: 잔차 연결로 깊은 신경망의 학습 신호를 보존하는 백본이다.
- **EfficientNet**: 깊이•폭•해상도를 함께 확장해 정확도와 연산량의 균형을 맞춘 백본이다.
- **전이 학습(Transfer Learning)**: 사전 학습한 백본의 특징을 새 분류 과제에 재사용하는 방식이다.
- **컴파운드 스케일링**: 네트워크 깊이•폭•입력 해상도를 정해진 비율로 함께 확장하는 방법이다.
- **깊이별 분리 합성곱(Depthwise Separable Convolution)**: 채널별 공간 합성곱과 채널 결합을 나누어 연산량을 줄이는 방식이다.
- **특징 추출기**: 입력 이미지에서 분류에 사용할 특징 맵을 만드는 백본 부분이다.
- **연산 횟수**: 한 번의 추론에서 수행하는 곱셈•덧셈 등의 계산량이다.
- **잔차 연결**: 블록 입력을 변환 출력에 더해 깊은 층까지 학습 신호를 전달하는 연결이다.
- **활성값 메모리**: 순전파•역전파 중 각 계층의 중간 출력값을 저장하는 메모리이다.

- **레즈넷(Residual Network, ResNet)**: 잔차 연결(Residual Shortcut Connection)을 도입하여 수백 개 계층에서도 기울기 소실 없이 깊은 신경망을 안정적으로 학습시키는 구조.
</details>

| CNN 백본 | VGG | ResNet | EfficientNet |
|:---|:---|:---|:---|
| 적용 기준 | 단순한 구조의 **특징 추출기**가 필요한 경우 | 깊은 백본의 **전이 학습**이 필요한 경우 | 제한된 **연산 횟수**에서 정확도를 높이는 경우 |
| 핵심 특징 | 합성곱의 단순 반복 적층 | **잔차 연결**로 학습 신호 보존 | **컴파운드 스케일링**으로 깊이•폭•해상도 확장 |
| 한계 | 반복 합성곱의 연산량•메모리 증가 | 깊은 층의 **활성값 메모리** 점유 | 장치별 **깊이별 분리 합성곱** 효율 편차 |

> 요약: 안정성은 **ResNet**, 효율은 **EfficientNet**이 핵심이다.

#### 한줄 요약

- VGG는 동일 합성곱 계층을 반복 적층하고, 잔차 신경망은 잔차 연결로 입력을 후속 계층 출력에 더하며, EfficientNet은 깊이·너비·해상도를 복합 스케일링하는 구조이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **입력 전처리**: 학습 때와 같은 해상도•픽셀 분포•색상 순서로 이미지를 변환하는 절차이다.
- **클래스 가중치**: 클래스별 오류 비용을 손실에 다르게 반영하는 값이다.
- **재현율**: 실제 양성 표본 중 모델이 양성으로 찾아낸 비율이다.
- **양자화**: 수치 정밀도를 낮춰 모델 크기와 연산 비용을 줄이는 기법이다.
- **적녹청(Red Green Blue, RGB)**: 이미지 채널을 적색•녹색•청색 순으로 배열하는 규칙이다.
- **청녹적(Blue Green Red, BGR)**: 이미지 채널을 청색•녹색•적색 순으로 배열하는 규칙이다.
- **분포 모니터링**: 운영 이미지의 조명•각도•배경 분포 변화를 감시하는 작업이다.
- **재학습(Retraining)**: 새 촬영 환경의 데이터로 모델을 다시 학습하는 작업이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 학습•추론 이미지의 전처리 불일치 | **RGB**•**BGR**를 포함한 **입력 전처리** 규칙 고정 | 동일 입력의 예측 편차 제거 |
| 위험 클래스의 미탐 증가 | **클래스 가중치**•임계값 조정과 **재현율** 기준 적용 | 고비용 미탐 감소 |
| 촬영 환경 변화로 정확도 저하 | 조건별 데이터 증강•**분포 모니터링**•**재학습** | 촬영 조건별 정확도 편차 감소 |
| 엣지 장치의 지연•메모리 초과 | 경량 백본•**양자화**•입력 해상도 조정 | 목표 추론 시간•메모리 용량 충족 |

#### 한줄 요약

- 위험 클래스의 미탐 시 클래스 가중치를 상향하고, 추론 지연과 메모리 사용량이 제약 조건 이내인지 검증하는 과정이다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **심층 안정성**: 계층이 깊어져도 학습 신호가 소실되지 않고 수렴하는 성질이다.
- **연산 효율**: 제한된 계산량과 메모리로 필요한 정확도와 속도를 달성하는 정도이다.
- **백본 선택 기준**: 깊은 계층의 학습 안정성과 제한 자원의 연산 효율 중 우선 요구로 백본을 고르는 기준이다.

</details>

- 심층 안정성은 **ResNet**, 연산 효율은 **EfficientNet** 선택

#### 한줄 요약

- 심층 학습 안정성은 ResNet, 제한된 연산량에서 정확도 효율은 EfficientNet을 선택한다.
