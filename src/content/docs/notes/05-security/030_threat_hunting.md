## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **Threat Hunting (위협 헌팅)**: 침해 전제(Assume Breach) 하에 분석가가 가설을 수립하고 전사 텔레메트리를 능동 수색하여 미탐지된 은닉 위협을 발굴하는 활동.
- **Assume Breach (침해 전제)**: 이미 내부망에 공격자가 잠복해 있다는 전제하에 능동적 탐지와 격리를 수행하는 보안 철학.

</details>

- 정의/개념: **침해 전제** 가설로 텔레메트리를 수색하는 능동 탐지 활동
- 배경/필요성: SIEM이나 EDR의 자동화된 경보(Alert) 발생만을 수동적으로 대기하는 전통적 보안관제(SOC) 모델은 공격자가 OS 내장 도구(LOLBins)나 탈취한 정상 자격증명을 악용하여 기존 탐지 룰을 우회하고 수개월간 잠복(Dwell Time)할 경우 이를 인지하지 못하는 수동적 관제의 한계를 드러냄에 따라, 이미 시스템이 침해당했다는 침해 전제(Assume Breach) 보안 철학하에 분석가가 CTI 기반의 가설(Hypothesis)을 수립하고 전사 텔레메트리 빅데이터를 능동적으로 피벗(Pivot) 수색하는 위협 헌팅(Threat Hunting) 체계를 도입하여 미탐지된 은닉 위협 조기 색출, 공격자 체류 시간(Dwell Time) 획기적 단축 및 발굴된 위협 패턴의 탐지 공학(Sigma/YARA) 자동화 환류를 달성할 필요

#### 한줄 요약
- 가설 기반 능동 수색과 텔레메트리 피벗팅을 통해 시스템 내 은닉 위협을 조기 발굴하고 격리한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **Hypothesis-Driven (가설 기반 수색)**: CTI와 ATT&CK TTP를 바탕으로 검증 가능한 공격 시나리오를 명제화하여 수색 범위를 정밀 타깃팅하는 기법.
- **Pivot (피벗팅)**: 단일 의심 프로세스나 IP를 기준으로 연관된 부모 프로세스, 네트워크 세션, 사용자 계정으로 조사 범위를 방사형으로 확장하는 분석 기법.

</details>

- 자동 경보 없이도 **침해 전제** 기반 선제 조사 수행
- CTI·TTP 기반 반증 가능한 가설 수립으로 수색 범위 한정
- 신규 공격 패턴을 탐지 공학 규칙으로 지속 환류

#### 한줄 요약
- 헌팅은 숙련 분석가의 시간을 건당 소모하는 가장 비싼 탐지 수단이므로, 그 비용은 발견 자체가 아니라 결과를 상시 규칙으로 환류시켜 같은 수색을 두 번 하지 않을 때 회수된다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **Sigma**: 특정 SIEM 벤더에 종속되지 않는 범용 YAML 기반 오픈소스 보안 탐지 시그니처 표준 포맷.

</details>

```text
[위협 헌팅 체계]
├─ 정보 기반 계층
│  ├─ 위협 인텔리전스 (CTI·ATT&CK 가설 제공)
│  └─ 텔레메트리 저장소 (EDR·NDR 로그 보관)
├─ 분석 수색 계층
│  ├─ 분석가 수색 엔진 (피벗 도구·연관 조사)
│  └─ 침해 대응 조직 (CSIRT 격리·대응)
└─ 공학 환류 계층
   └─ 탐지 공학 파이프라인 (Sigma 규칙 배포)
```

- 선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| CTI·ATT&CK | 가설과 반증 조건의 근거 제공 |
| 텔레메트리 저장소 | EDR·NDR·클라우드 로그 통합 보관 |
| 분석가·피벗 도구 | 의심 개체의 연관 관계 확장 조사 |
| CSIRT | 침해 호스트 격리와 사고 대응 |
| 탐지 공학 파이프라인 | 헌팅 질의를 Sigma 규칙으로 배포 |

#### 한줄 요약
- 텔레메트리 저장소는 헌팅이 성립하기 위한 선불 비용으로 보관 기간과 수집 범위가 곧 수색 가능 범위를 정하고, 탐지 공학 파이프라인은 그 위에서 한 번 치른 분석 비용을 상시 규칙으로 바꿔 재사용시키는 출구다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Falsifiability (반증 가능성)**: 분석가의 확증 편향을 방지하기 위해 가설이 틀렸음을 증명하는 정상 작업 조건을 사전에 정의하는 과학적 수색 원칙.

</details>

```text
1. 가설 수립
     |
     v
2. 데이터 질의
     |
     v
3. 피벗 연관 추적
     |
     +-- 반증됨 --> [가설 기각]
     |
     `-- 침해 확인
             |
             v
4. 침해 행위 확정
             |
             v
5. 탐지 공학 환류
```

- 1. 가설 수립: CTI를 근거로 공격 행위와 반증 조건 정의
- 2. 데이터 질의: 텔레메트리에서 가설 부합 기록 추출
- 3. 피벗 연관 추적: 프로세스·계정·통신 관계 확장 조사
- 4. 침해 행위 확정: 반증 결과로 오탐을 배제하고 CSIRT 인계
- 5. 탐지 공학 환류: 수동 질의를 Sigma 규칙으로 배포

#### 한줄 요약
- 가설이 기각되는 갈래도 실패가 아니라 해당 구간의 정상 기준선을 확정해 다음 수색 범위를 좁히는 성과이므로, 반증 조건을 미리 정의해 둔 헌팅만이 침해를 못 찾았을 때도 비용을 회수한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **침해 지표 기반 (IoC-Driven)**: 알려진 해시·IP를 저장소에 단순 대조해 분석가 시간을 거의 쓰지 않는 대신, 공격자가 지표를 바꾸는 순간 수색 자체가 헛도는 헌팅 방식.
- **행위 패턴 기반 (TTP-Driven)**: 도구가 바뀌어도 남는 공격 절차를 프로세스 계보와 문맥으로 추적해 변종까지 잡아내는 대신, 정상 업무와의 구분을 분석가의 맥락 이해에 의존하는 헌팅 방식.
- **이상치 통계 기반 (Anomaly-Driven)**: 정상 기준선에서 벗어난 행위를 통계로 훑어 아직 정의되지 않은 공격까지 후보에 올리는 대신, 기준선이 정교하지 않으면 오탐 검토 비용이 성과를 넘어서는 헌팅 방식.

</details>

| 비교 항목 | 침해 지표 기반 (IoC-Driven) | 행위 패턴 기반 (TTP-Driven) | 이상치 통계 기반 (Anomaly-Driven) |
|:---|:---|:---|:---|
| 적용 기준 | 알려진 IP·해시 추적 | TTP 기반 행위 추적 | 베이스라인 이탈 탐색 |
| 핵심 특징 | 단순 일치 검색 | 프로세스 맥락 분석 | 미정의 이상 행위 탐색 |
| 한계 | 지표 변경 시 탐지 우회 | 분석가의 높은 맥락 이해 요구 | 노이즈로 오탐 증가 |

#### 한줄 요약
- IoC 기반은 단순 해시 검색, TTP 기반은 공격자 본질 행위 수색, Anomaly 기반은 통계 이상치 분석이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Honeytoken (허니토큰)**: 레지스트리나 메모리에 가짜 관리자 자격증명을 미끼로 심어두고 이에 접근하는 은닉 공격자를 즉각 포착하는 디셉션 기술.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 유사 공격마다 수동 분석 반복 | 헌팅 질의를 **Sigma** 규칙으로 환류 | 동일 공격의 상시 자동 탐지 |
| 가설 부합 데이터만 보는 확증 편향 | **반증 조건** 사전 명시와 동료 검토 | 정상 작업의 침해 오판 감소 |
| 정상 계정으로 위장한 공격자 식별 곤란 | **허니토큰** 분산 배치 | 미끼 자격증명 접근 조기 탐지 |
| 대용량 텔레메트리 질의 지연 | 저장 계층화와 **분산 인덱싱** | 헌팅 질의 응답 시간 단축 |

#### 한줄 요약
- 탐지 공학 환류로 자동화하고, 반증 조건으로 확증 편향을 막으며, 허니토큰으로 은닉 계정을 유인 포착한다.

## Ⅶ. 결론

- 경보 대기형 수동 관제의 한계를 극복하고 이미 내부망에 침투하여 은닉 중인 고도화된 APT 공격자를 선제적으로 찾아내어 무력화하는 현대 엔터프라이즈 보안관제(SOC) 및 능동 방어(Proactive Defense)의 최고 성숙도 핵심 활동으로 확고히 자리 잡았으며, 생성형 AI 기반 헌팅 질의 생성 및 XDR 자동화 파이프라인으로 진화하는 가운데, 실무 위협 헌팅 체계 운영 시에는 CTI 및 MITRE ATT&CK TTP 기반의 명확한 반증 가능(Falsifiable) 가설 수립 및 방사형 텔레메트리 피벗팅(Pivoting) 분석 프랙티스 확립, 은닉된 공격자의 자격증명 남용을 역추적하는 디셉션(Honeytoken) 기술 결합, 헌팅을 통해 발굴된 신규 공격 패턴을 벤더 독립적 Sigma/YARA-L 탐지 규칙으로 즉각 변환하여 SIEM/SOAR로 환류(Detection Engineering)시키는 지속 개선 루프를 완비하여 완벽한 능동 위협 억제력을 완성

#### 한줄 요약
- 위협 헌팅은 침해 전제 가설 수립과 텔레메트리 피벗팅 및 탐지 공학 환류를 통해 은닉 위협을 선제 격리하고 방어망을 고도화하는 능동 보안 체계다.
