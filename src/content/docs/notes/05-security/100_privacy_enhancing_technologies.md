## 미리 알고가기

- **개인정보보호 강화기술(Privacy-Enhancing Technologies, PET)**: 데이터 수집·저장·분석·공유의 개인정보 노출을 줄이는 기술군이다.
- **위협 모델(Threat Model)**: 보호 대상·공격자 지식·접근 능력·공모 가능성에 관한 가정이다.
- **차등 프라이버시(Differential Privacy, DP)**: 개인 한 명의 포함 여부가 출력에 미치는 영향을 수학적으로 제한하는 기법이다.
- **동형암호(Homomorphic Encryption, HE)**: 암호문을 복호화하지 않고 연산할 수 있게 하는 암호 기술이다.
- **안전한 다자간 계산(Secure Multi-Party Computation, MPC)**: 참여자가 원본 입력을 공개하지 않고 공동 결과를 계산하는 기술이다.
- **연합학습(Federated Learning, FL)**: 원본 데이터를 중앙에 모으지 않고 분산된 참여자가 모델 업데이트를 학습하는 방식이다.
- **신뢰 실행환경(Trusted Execution Environment, TEE)**: 격리된 하드웨어 영역에서 코드와 데이터를 보호하는 실행환경이다.
- **프라이버시 예산(Privacy Budget)**: 차등 프라이버시에서 허용할 누적 정보 노출 한도이다.
- **공모(Collusion)**: 여러 참여자가 정보를 합쳐 보호된 입력이나 비밀을 추론하는 행위이다.
- **NIST SP 800-226**: 차등 프라이버시 보장의 구현·평가 기준과 위험을 제시하는 공식 지침이다.
- **ISO/IEC 18033-6:2019**: Paillier·Exponential ElGamal 동형암호 메커니즘을 규정한다.
- **ISO/IEC 4922-1:2023**: 안전한 다자간 계산의 용어·주체·절차·보안 속성을 규정한다.

## Ⅰ. 개요

- 정의/개념: 처리 과정의 **개인정보 노출 최소화 기술군**
- 배경/필요성: 원본 결합·공유의 **재식별·유출 위험**

### 쉽게 이해하기 (학습용)

- 여러 기관이 원본을 한곳에 직접 모으지 않고도 필요한 통계·분석·학습 결과를 얻도록 보호한다.

## Ⅱ. 특징

- 입력·계산·출력의 **노출 경계 분리**
- 공격자·공모 가정의 **위협 모델 의존**
- 보호 강도를 높이면 **재식별 위험 감소·정확도나 처리 성능 저하**
- 원본을 분산 보유하는 **연합학습**, 격리 영역에서 실행하는 **TEE**

### 쉽게 이해하기 (학습용)

- 출력에서 개인을 숨길지 계산 서버에서 원문을 숨길지 기관끼리 입력을 숨길지에 따라 적합한 기술이 달라진다.

## Ⅲ. 구조 및 구성요소

```mermaid
block-beta
  columns 3
  A["목적·위협 모델"]
  B["입력 최소화"]
  C["보호 변환"]
  D["보호 계산 엔진"]
  E["출력·키·예산 통제"]
  A --- B
  B --- C
  C --- D
  D --- E
```

| 구성요소 | 책임 |
|:---|:---|
| **목적·위협 모델** | 자산·공격자·정확도 **정의** |
| **입력 최소화** | 필요 필드·참여자만 **허용** |
| **보호 변환** | **잡음·암호화·비밀 분산** |
| **보호 계산 엔진** | 허용 통계·학습 **연산 수행** |
| **출력·키·예산 통제** | 조회·키·**누적 노출 관리** |

### 쉽게 이해하기 (학습용)

- 입력부터 출력까지 누가 무엇을 관찰할 수 있는지를 정하고 각 노출 지점에 맞는 변환·계산·예산 통제를 배치한다.

## Ⅳ. 흐름도

```mermaid
sequenceDiagram
    participant O as 데이터 관리자
    participant T as 위협 모델러
    participant P as 보호 변환기
    participant C as 계산 엔진
    participant V as 위험 검증기
    O->>T: 1. 목적·공격자·정확도 정의
    T->>P: 2. 입력·계산·출력 노출 분석
    P->>C: 3. 잡음·암호·분산 설정
    C->>V: 4. 보호 계산·제한 출력
    V->>V: 5. 위험·유용성·비용 검증
    V-->>O: PET 적용 결과 제공
```

**동작 원리**

1. **목적·공격자·정확도 정의**: 결과·공모·성능 한도 설정
2. **입력·계산·출력 노출 분석**: 관찰자·신뢰 경계 식별
3. **잡음·암호·분산 설정**: 기술·키·참여 조건 결정
4. **보호 계산·제한 출력**: 원본 노출 없이 허용 연산
5. **위험·유용성·비용 검증**: 추론·정확도·지연 평가


### 쉽게 이해하기 (학습용)

- 가장 강한 기술을 무조건 고르지 않고 결과가 쓸 만하면서 공격자가 허용 한도 이상 개인을 알아낼 수 없도록 조정한다.

## Ⅴ. 종류 및 비교

| 개인정보보호 강화기술 | 차등 프라이버시 | 동형암호 | 다자간 계산 |
|:---|:---|:---|:---|
| **적용 기준** | 통계·학습 **결과 공개** | **비신뢰 서버 연산** | 기관 간 **공동 분석** |
| 핵심 특징 | **통제 잡음·노출 예산** | **암호문 상태 연산** | **입력 비밀 분산 계산** |
| **한계** | **정확도 저하·예산 소진** | **높은 연산 비용** | **통신 지연·공모** |

### 쉽게 이해하기 (학습용)

- 차등 프라이버시는 출력, 동형암호는 계산 서버의 원문, 다자간 계산은 참여 기관끼리의 입력을 중점 보호한다.

## Ⅵ. 실무 고려사항 및 대책

| 고려사항 | 대책 | 효과 |
|:---|:---|:---|
| **차등 프라이버시 보장** | **NIST SP 800-226 기반 평가** | 예산·**구현 위험 검증** |
| **암호문 상태 계산** | **ISO/IEC 18033-6:2019 적용** | 동형 연산·**키 처리 일관화** |
| **기관 간 비밀 계산** | **ISO/IEC 4922-1:2023 적용** | 참여자·**공모·절차 명확화** |

### 쉽게 이해하기 (학습용)

- 반복 통계 공개는 질의마다 소비한 프라이버시 예산을 누적하여 여러 결과의 결합으로 개인 참여 여부가 드러나는 것을 제한한다.

## Ⅶ. 결론

- 출력 노출은 **DP**, 비신뢰 연산은 **HE**, 기관 공동 분석은 MPC 선택

### 쉽게 이해하기 (학습용)

- PET의 성패는 기술 강도가 아니라 보호해야 할 경계와 공격 가정에 맞으면서 필요한 결과 품질을 유지하는 데 달려 있다.
