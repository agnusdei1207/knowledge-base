## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **PETs(Privacy-Enhancing Technologies)**는 데이터 수집•저장•분석•공유에서 원본과 개인 참여 노출을 줄이는 기술군이다.
- **보호 경계**: 입력•계산 서버•참여 기관•출력 중 누구에게 어떤 정보가 보이지 않아야 하는지를 정한 설계 기준이다.

</details>

- 정의/개념: **PETs**는 데이터의 수집•결합•분석•공유에서 원본과 개인 기여의 노출을 줄이는 기술군이다.
- 배경/필요성: 원본 결합•공유의 **재식별•유출 위험**이 발생한다.

#### 한줄 요약

- 여러 기관이 원본을 한곳에 직접 모으지 않고도 필요한 통계•분석•학습 결과를 얻도록 보호한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **위협 모델**은 보호 자산과 공격자의 지식•접근 능력을 가정한 시험 조건이다.
- **공모**는 여러 참여자가 각자 가진 정보를 합쳐 보호 데이터를 추론하는 공격 조건이다.
- **연합학습**은 원본 데이터를 중앙에 모으지 않고 참여자의 모델 업데이트를 결합하는 학습 방식이다.
- **TEE(Trusted Execution Environment)**는 격리된 하드웨어 영역에서 코드와 데이터를 보호하는 실행 환경이다.

</details>

- 입력•계산•출력의 **노출 경계 분리**가 핵심이다.
- 공격자•공모 가정의 **위협 모델 의존**이 핵심이다.
- 보호 강도를 높이면 **재식별 위험 감소•정확도나 처리 성능 저하**가 핵심이다.
- 원본을 분산 보유하는 **연합학습**, 격리 영역에서 실행하는 **TEE**가 핵심이다.

#### 한줄 요약

- 출력에서 개인을 숨길지 계산 서버에서 원문을 숨길지 기관끼리 입력을 숨길지에 따라 적합한 기술이 달라진다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **보호 변환**은 데이터에 잡음•암호화•비밀 분산을 적용하는 처리다.
- **계산 엔진**은 허용된 통계•학습 연산을 원본 노출 없이 수행한다.
- **키 통제**는 암호 키의 접근 권한과 생성•회전•폐기 수명을 관리한다.
- **예산 통제**는 반복 질의의 누적 정보 노출이 허용 한도를 넘지 않게 관리한다.

</details>

```text
PETs 적용 구조
├─ 설계 기준
│  └─ 목적•위협 모델
├─ 입력•계산
│  ├─ 입력 최소화
│  ├─ 보호 변환
│  └─ 보호 계산 엔진
└─ 운영 통제
   └─ 출력•키•예산 통제
```

| 구성요소 | 책임 |
|:---|:---|
| **목적•위협 모델** | 자산•공격자•정확도 **정의** |
| **입력 최소화** | 필요 필드•참여자만 **허용** |
| **보호 변환** | **잡음•암호화•비밀 분산** |
| **보호 계산 엔진** | 허용 통계•학습 **연산 수행** |
| **출력•키•예산 통제** | 조회•키•**누적 노출 관리** |

#### 한줄 요약

- 입력부터 출력까지 누가 무엇을 관찰할 수 있는지를 정하고 각 노출 지점에 맞는 변환•계산•예산 통제를 배치한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **위험 검증**은 공격자가 보호 데이터나 개인 참여를 추론할 가능성을 측정한다.
- **유용성 검증**은 보호 처리 뒤 결과의 정확도와 업무 품질을 측정한다.
- **비용 검증**은 보호 계산에 필요한 연산•통신 지연과 자원 소비를 측정한다.
- **원본 비노출 계산**: 필요한 결과를 얻는 동안 비신뢰 서버나 다른 참여자가 개인별 입력을 직접 보지 못하게 하는 처리이다.

</details>

```text
보호 요구•성능 한도
         |
         v
1. 목적•공격자•정확도 정의
         |
         v
2. 입력•계산•출력 노출 분석
         |
         v
3. 잡음•암호•분산 설정
         |
         v
4. 보호 계산•제한 출력
         |
         v
5. 위험•유용성•비용 검증
         |
         v
      PET 적용 결과
```

**동작 원리**

1. **목적•공격자•정확도 정의**: 결과•공모•성능 한도를 설정한다.
2. **입력•계산•출력 노출 분석**: 관찰자•신뢰 경계를 식별한다.
3. **잡음•암호•분산 설정**: 기술•키•참여 조건을 결정한다.
4. **보호 계산•제한 출력**: 원본 노출 없이 허용을 연산한다.
5. **위험•유용성•비용 검증**: 추론•정확도•지연을 평가한다.


#### 한줄 요약

- 가장 강한 기술을 무조건 고르지 않고 결과가 쓸 만하면서 공격자가 허용 한도 이상 개인을 알아낼 수 없도록 조정한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **DP(Differential Privacy)**는 한 개인의 포함이 공개 결과에 미치는 영향을 제한하는 기법이다.
- **HE(Homomorphic Encryption)**는 데이터를 복호화하지 않고 암호문 상태에서 연산하는 기법이다.
- **MPC(Multi-Party Computation)**는 참여자의 원본 입력을 공개하지 않고 공동 결과를 계산하는 기법이다.
- **프라이버시 예산**: 차등 프라이버시에서 여러 결과를 결합해 개인 참여를 추론하지 못하도록 허용하는 누적 정보 노출 한도이다.

</details>

| 개인정보보호 강화기술 | 차등 프라이버시 | 동형암호 | 다자간 계산 |
|:---|:---|:---|:---|
| **적용 기준** | 통계•학습 **결과 공개** | **비신뢰 서버 연산** | 기관 간 **공동 분석** |
| 핵심 특징 | **통제 잡음•노출 예산** | **암호문 상태 연산** | **입력 비밀 분산 계산** |
| **한계** | **정확도 저하•예산 소진** | **높은 연산 비용** | **통신 지연•공모** |

#### 한줄 요약

- 차등 프라이버시는 출력, 동형암호는 계산 서버의 원문, 다자간 계산은 참여 기관끼리의 입력을 중점 보호한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **NIST(National Institute of Standards and Technology)**는 미국의 기술 표준과 지침을 개발하는 기관이다.
- **SP(Special Publication) 800-226**은 DP의 구현•평가 위험을 제시한다.
- **ISO(International Organization for Standardization)**는 국제 표준을 개발•발행하는 기구다.
- **IEC(International Electrotechnical Commission)**는 전기•전자 분야 국제 표준을 개발하는 기구다.
- **ISO/IEC 18033-6**은 HE 메커니즘과 키 처리를 규정한다.
- **ISO/IEC 4922-1:2023**은 MPC의 용어•주체•절차•공모 보안 속성을 규정한다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **차등 프라이버시 보장** | **NIST SP 800-226 기반 평가** | 예산•**구현 위험 검증** |
| **암호문 상태 계산** | **ISO/IEC 18033-6:2019 적용** | 동형 연산•**키 처리 일관화** |
| **기관 간 비밀 계산** | **ISO/IEC 4922-1:2023 적용** | 참여자•**공모•절차 명확화** |

#### 한줄 요약

- 반복 통계 공개는 질의마다 소비한 프라이버시 예산을 누적하여 여러 결과의 결합으로 개인 참여 여부가 드러나는 것을 제한한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **목적 적합 PETs 선택**은 보호 경계•공격 가정•품질•지연•비용에 맞는 기술을 고르는 원칙이다.

</details>

- 출력 노출은 **DP**, 비신뢰 연산은 **HE**, 기관 공동 분석은 **MPC**을 선택한다.

#### 한줄 요약

- PET의 성패는 기술 강도가 아니라 보호해야 할 경계와 공격 가정에 맞으면서 필요한 결과 품질을 유지하는 데 달려 있다.
