## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **개인정보보호 강화기술(Privacy-Enhancing Technologies, PETs / NIST SP 800-226 & ISO/IEC 27559)**: 민감한 원본 데이터를 중앙에 직접 결합·노출하지 않고도, 데이터의 전 생애주기(입력, 연산, 출력) 전반에 걸쳐 암호학적 기밀성을 보존하면서 인공지능(AI) 학습, 통계 분석, 기관 간 데이터 융합을 수행할 수 있도록 지원하는 차세대 프라이버시 엔지니어링 기술군.
- **중앙 집중형 원시 데이터 결합 결함(Centralized Plaintext Aggregation Defect)**: 복수의 기관이 데이터 융합을 위해 원본 평문(Plaintext) 데이터를 단일 중앙 클라우드 DB로 전송하여 결합할 경우, 클라우드 관리자 계정 탈취, 내부자 메모리 덤프, 전송 구간 패킷 가로채기 발생 시 대규모 프라이버시 유출로 직결되는 구조적 한계.

</details>

- 정의/개념: 원본 노출 없이 분석하는 **개인정보보호 강화기술**
- 배경/필요성: 이종 산업 간 데이터 결합, 클라우드 기반 AI 모델 학습 및 통계 분석 수요가 급증하는 반면, 복수의 기관이 원본 평문(Plaintext) 데이터를 중앙 서버로 집중 전송하는 기존 방식은 클라우드 관리자 계정 탈취, 메모리 덤프, 내부자 유출 및 멤버십 추론 공격(MIA)에 무방비로 노출되는 치명적 한계가 존재함에 따라, NIST SP 800-226 및 ISO/IEC 18033-6 표준에 기반하여 입력단 연합학습(FL), 연산단 동형암호(HE)·안전 다자간 계산(SMPC)·신뢰실행환경(TEE), 출력단 차분 프라이버시(DP)와 프라이버시 예산($\epsilon$) 통제를 결합하는 개인정보보호 강화기술(PETs) 아키텍처를 도입하여 **원본 평문 노출 제로(Zero-Exposure) 기밀 연산, 클라우드 비신뢰 환경에서의 Zero Trust 데이터 보호 및 수학적 역추적 방어**를 달성할 필요

#### 한줄 요약
- 원본 데이터 노출 없이 동형암호, SMPC, TEE, 차분 프라이버시를 통해 안전한 분산 분석 및 연산을 수행한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **PETs 3대 핵심 기밀 연산 패러다임**:
  - **동형암호 (Homomorphic Encryption, HE)**: 암호화된 상태 그대로 복호화 없이 덧셈/곱셈 산술 연산을 수행하고 복호화 시 정상 결과를 도출하는 기술.
  - **안전 다자간 계산 (Secure Multi-Party Computation, SMPC)**: 비밀 분산(Secret Sharing)을 통해 각 참여자가 자신의 원본을 숨긴 채 분산 연산으로 공동의 결과값만 도출하는 기술.
  - **차분 프라이버시 (Differential Privacy, DP)**: 통계 질의 결과에 수학적 라플라스/가우시안 노이즈를 주입하여 특정 개인의 데이터 포함 여부를 역추적하지 못하게 은닉하는 기술.

</details>

- **3계층 보호 경계별 맞춤 방어**: 입력단(데이터 최소화), 연산단(암호 상태 블라인드 연산), 출력단(통계 노이즈 역추적 방어)의 다층 분리 통제
- **신뢰할 수 없는 환경(Zero Trust)에서의 안전성**: 비신뢰 CSP 클라우드 관리자가 서버 메모리를 덤프 뜨더라도 평문 원본을 절대 볼 수 없는 하드웨어(TEE) 및 수학적(HE) 격리
- **프라이버시-유용성-비용의 3각 트레이드오프**: 프라이버시 예산($\epsilon$)을 조절하여 데이터 분석 정확도(Utility)와 연산 속도(Overhead)를 최적화

#### 한줄 요약
- 3단계 경계별 방어, Zero Trust 블라인드 연산, TEE/동형암호 격리, 프라이버시-유용성 최적화를 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **PETs 4대 핵심 기술 축**:
  1. **Differential Privacy Engine (출력 보호)**: 프라이버시 예산($\epsilon$) 관리 및 노이즈 주입.
  2. **Homomorphic Encryption Engine (연산 보호)**: CKKS/BGV 기반 암호 상태 행렬 연산기.
  3. **Secure MPC Protocol Engine (기관 간 보호)**: Shamir 비밀 분산 및 가비 회로(Garbled Circuits).
  4. **Hardware TEE Enclave (실행 격리)**: Intel SGX / AMD SEV 기반 방탄 메모리 격리 런타임.

</details>

```text
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 1. 입력단 보호 계층 (Input Layer: Federated Learning & Sanitization)]│
│  ├─ 연합학습(FL): 원본 데이터는 로컬 단말에 격리 ➔ [ 모델 가중치만 전송 ]│
│  └─ 입력 최소화: 불필요한 속성 사전 제거 및 k-익명성 전처리             │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │ (암호화/분산 가중치 전달)
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 2. 연산단 기밀 연산 계층 (Computation Layer: Blind Secure Processing)]│
│  ├─ 동형암호(HE): 원본 복호화 없이 암호문 상태로 $E(a) \times E(b) = E(ab)$│
│  ├─ 안전 다자간계산(SMPC): 참여자 간 데이터 조각 비밀분산($[s]_i$) 분산 연산│
│  └─ [ TEE(신뢰실행환경): 하드웨어 Enclave 내부에서만 일시적 복호화 연산]│
└────────────────────────────────────┬────────────────────────────────────┘
                                     │ (연산 결과 산출)
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 3. 출력단 역추적 방어 계층 (Output Layer: Differential Privacy Core) ] │
│  ├─ 차분 프라이버시(DP): 통계 결과에 라플라스 노이즈 $\text{Lap}(\Delta f / \epsilon)$ 주입│
│  └─ [ 프라이버시 예산 관리: 질의 누적 $\sum \epsilon_i \ge \epsilon_{max}$ 도달 시 API 셧다운]│
└─────────────────────────────────────────────────────────────────────────┘
```

선의 의미: 입력단에서 연합학습으로 데이터를 격리하고, 연산단에서 동형암호/SMPC/TEE로 기밀 연산하며, 출력단에서 차분 프라이버시로 역추적을 차단하는 구조

| 기술 요소 | 핵심 보호 메커니즘 | 표준 및 규격 | 비고 |
|:---|:---|:---|:---|
| **차분 프라이버시 (DP)** | 통계 쿼리 결과에 수학적 노이즈를 주입하여 특정 레코드의 포함 여부 역추적 차단 | **NIST SP 800-226** | Output Sec |
| **동형암호 (HE)** | 데이터를 복호화하지 않고 암호화된 상태 그대로 덧셈·곱셈 연산을 수행 | **ISO/IEC 18033-6** | Compute Sec|
| **안전 다자간 계산 (SMPC)**| 데이터를 여러 조각으로 쪼개어 비밀 분산한 뒤 기관 간 합동 연산 수행 | **ISO/IEC 4922-1** | Multi-party|
| **신뢰 실행 환경 (TEE)** | CPU 칩셋 내부의 하드웨어 Enclave에 메모리를 암호화 격리하여 루트 권한 탈취 방어 | **ISO/IEC 20897** | Hardware Sec |
| **연합학습 (FL)** | 원본 데이터는 로컬 단말에 남겨두고 모델 업데이트 파라미터만 중앙 집계 | **IEEE 3652.1** | Input Sec |

#### 한줄 요약
- 차분 프라이버시(출력), 동형암호(연산), SMPC(기관 간 연산), TEE(하드웨어 격리), 연합학습(입력)이 결합한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **PETs 적용 데이터 분석 5단계 파이프라인**:
  1. 위협 모델 수립 및 요구 정확도/예산 한계 확정
  2. 입력단 연합학습 및 데이터 최소화 적용
  3. 연산단 동형암호/SMPC 기반 기밀 연산 수행
  4. 출력단 차분 프라이버시 노이즈 주입 및 예산 차감
  5. 재식별 역추적 위험도 및 유용성 평가 후 배포

</details>

```text
1. [위협 모델 및 요구사항 수립] 병원 A와 B 간의 희귀 암 환자 합동 AI 모델 학습 목적 확정
            │
            ▼
2. [입력단 연합학습(FL) 개시]
    ├─ 환자의 민감 진료 기록은 각 병원 사내 서버 밖으로 1바이트도 반출 금지
    └─ 각 병원에서 로컬로 딥러닝 학습 후 기울기(Gradient) 벡터만 추출
            │
            ▼
3. [연산단 SMPC 및 동형암호 결합]
    ├─ 추출된 그래디언트 벡터를 Shamir 비밀 분산 조각으로 쪼개어 암호화
    └─ [중앙 집계 서버가 복호화 없이 SMPC 프로토콜로 전역 가중치 평균(FedAvg) 계산]
            │
            ▼
4. [출력단 차분 프라이버시(DP) 노이즈 주입]
    ├─ 집계된 모델 가중치에 차분 프라이버시 노이즈($\epsilon = 0.5$) 추가
    └─ [프라이버시 예산 추적기(Budget Tracker)에서 금일 누적 예산 차감 갱신]
            │
            ▼
5. [역추적 위험 검증 및 배포] 멤버십 추론 공격(MIA) 방어율 99.9% 확인 ➔ 최종 AI 진단 모델 상용 릴리즈
```

**동작 원리**

1. **위협 모델 및 요구사항 수립**
2. **입력단 연합학습(FL) 개시**
3. **연산단 SMPC 및 동형암호 결합**
4. **출력단 차분 프라이버시 노이즈 주입**
5. **역추적 위험 검증 및 배포**

#### 한줄 요약
- 각 기술이 막는 경계가 달라 겹쳐 쓸수록 안전해지지만 연산 비용과 정확도 손실도 함께 누적되므로, 위협 모델이 지목한 경계에만 골라 적용해야 한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **PETs 3대 기밀 연산 기술 비교**: 차분 프라이버시(DP), 동형암호(HE), 안전 다자간 계산(SMPC)의 비교.

</details>

| 비교 항목 | 차분 프라이버시 (DP) | 동형암호 (HE) | 안전 다자간 계산 (SMPC) |
|:---|:---|:---|:---|
| **주요 보호 계층** | **최종 출력단 (Output Layer)** | **중앙 연산 서버단 (Computation)**| **기관 간 분산 연산단 (Multi-Party)** |
| **핵심 기술 원리** | **수학적 노이즈 주입 및 예산($\epsilon$) 통제**| **암호문 상태의 사칙연산 (Ring LWE)**| **Shamir 비밀 분산 및 가비 회로** |
| **원본 데이터 노출**| 통계 쿼리 결과에서 특정인 역추적 방어 | **연산 서버에 암호문만 전달 (복호화 0%)**| **참여 기관끼리 원본 미공유 (조각 분산)**|
| **주요 오버헤드** | 과도한 노이즈 시 분석 정확도 저하 | **극심한 CPU 연산 및 메모리 부하 ($10^2 \sim 10^3\times$)**| **네트워크 통신 라운드트립(RTT) 지연** |
| **주요 적용 사례** | 인구통계 센서스, 차분 프라이버시 ML | 클라우드 기반 프라이버시 보존 추론 | 금융권 신용평가 결합, 이종 기관 통계 |

#### 한줄 요약
- DP는 출력값 역추적 방어, HE는 연산 서버 원문 은닉, SMPC는 기관 간 비밀 분산 합동 연산이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **NIST SP 800-226 & ISO/IEC 18033-6**: 차분 프라이버시 구축 평가 지침 및 동형암호 알고리즘 구현·키 관리 국제 표준.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 통계 API 서비스에서 공격자가 수만 번의 미세 쿼리를 반복 질의하여 **노이즈 오차를 역산해 특정 개인의 민감 진료 기록을 복원하는 사고** | **NIST SP 800-226** 준수, **누적 질의에 대한 프라이버시 예산($\epsilon$) 모니터링 및 임계치 초과 시 자동 회로 차단(Circuit Breaker)** | 무한 반복 질의를 통한 차분 프라이버시 역산 해킹 100% 원천 차단 |
| 클라우드 AI 추론 시 동형암호(HE) 연산 오버헤드로 인해 **단일 이미지 처리에 수십 초가 소요되어 실시간 비즈니스 서비스 불가 장애** | **CKKS 근사 동형암호 알고리즘 및 GPU/FPGA 기반 동형암호 전용 하드웨어 가속기(QPU/NPU) 파이프라인 도입** | 암호 연산 지연 시간 95% 이상 단축 및 실시간 프라이버시 보존 AI 추론 달성 |
| 복수의 기관이 다자간 계산(SMPC)을 수행하던 중 **악의적인 참여 기관들이 공모(Collusion)하여 특정 병원의 환자 원본 데이터를 복원하는 결함** | **ISO/IEC 4922-1** 준수, **비밀 분산 시 최소 임계치($t > n/2$) 상향 및 비대칭 다중 서명 검증 프로토콜 강제** | 과반수 미만 참여자의 악의적 담합 공모 공격 100% 수학적 무력화 및 무결성 보장 |

#### 한줄 요약
- 프라이버시 예산 관리로 역산을 막고, 전용 가속기로 동형암호 지연을 줄이며, 임계치 상향으로 공모를 차단한다.

## Ⅶ. 결론

- 원본 데이터를 중앙에 직접 결합·노출하지 않고도 암호학적 기밀성을 완벽히 유지하면서 분산 데이터 분석 및 AI 모델 학습을 수행할 수 있도록 보장하는 **차세대 프라이버시 보존 컴퓨팅(Privacy-Preserving Computing / NIST SP 800-226 / ISO 18033-6)의 최상위 엔지니어링 패러다임**으로 확고히 자리 잡았으며, 기밀 컴퓨팅(Confidential Computing) 하드웨어 및 GPU 가속 기반 완전동형암호(FHE)로 전면 진화하는 가운데, 실무 엔터프라이즈 기밀 AI 인프라 구축 시에는 **로컬 데이터 격리 기반 연합학습(FedAvg)과 Shamir 비밀 분산 기반 SMPC 프로토콜 결합, GPU 가속기 연동 CKKS 동형암호 행렬 연산 최적화, 통계 쿼리 및 모델 가중치 배포 시 누적 프라이버시 예산($\sum \epsilon_i$) 추적 및 임계치 초과 시 자동 회로 차단(Circuit Breaker)**을 통합 구축하여 완벽한 데이터 프라이버시 전주기 무결성을 완성
