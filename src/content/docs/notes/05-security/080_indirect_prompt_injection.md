## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **간접 프롬프트 인젝션**: 문서•웹•메일에 숨은 지시가 모델 문맥으로 들어와 원래 사용자 요청과 다른 출력이나 행동을 만들게 하는 공격이다.
- **인공지능(Artificial Intelligence, AI)**: 학습된 모델로 인식•추론•생성 작업을 수행하는 기술이다.
- **대규모 언어 모델(Large Language Model, LLM)**: 대규모 언어 데이터로 학습해 자연어를 이해•생성하는 모델이다.
- **신뢰 경계 붕괴**: 외부 자료를 비신뢰 데이터가 아닌 실행 지시로 해석하여 콘텐츠 신뢰와 도구 권한의 경계가 사라지는 문제이다.

</details>

- 정의/개념: **AI** 시스템의 **LLM**이 외부 자료의 숨은 지시로 행동을 바꾸는 **간접 프롬프트 인젝션** 공격이다.
- 배경/필요성: 검색된 비신뢰 자료를 모델이 명령으로 해석하면 **신뢰 경계 붕괴**가 발생할 수 있다.

#### 한줄 요약

- 사용자는 정상 질문을 했지만 AI가 읽은 문서 속 숨은 공격 지시를 새 명령으로 받아들여 엉뚱한 행동을 만드는 공격이다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **검색 증강 생성(Retrieval-Augmented Generation, RAG) 유입**: 검색 문서의 공격 지시가 모델 문맥으로 전달되는 경로이다.
- **다중모달 유입**: 웹•메일•이미지•음성의 공격 지시가 모델 문맥으로 전달되는 경로이다.
- **지연 발동**: 악성 콘텐츠가 수집 시점에는 드러나지 않다가 특정 검색•질의•도구 조건에서 행동을 교란하는 특성이다.
- **독립 권한 검증**: 모델의 판단을 그대로 신뢰하지 않고 별도 정책 계층이 사용자 권한과 도구 실행 범위를 다시 확인하는 통제이다.

</details>

- **RAG 유입**•**다중모달 유입**: 검색•웹•메일•이미지•음성을 통해 공격 지시가 전달된다.
- **지연 발동**: 수집 시점이 아닌 특정 질의•도구 조건에서 공격이 드러난다.
- **독립 권한 검증**: 모델 판단과 별도로 사용자 권한과 도구 실행 범위를 확인한다.

#### 한줄 요약

- 모든 악성 문장을 완벽히 지우기 어려우므로 AI가 속아도 읽을 수 있는 자료와 실행할 수 있는 행동을 좁혀야 한다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **접근 제어 목록(Access Control List, ACL)**: 주체별로 자원에 허용된 접근 권한을 기록한 목록이다.
- **출처 보존**: 원본 문서의 생성•수집 경로를 각 검색 청크에 유지하는 통제이다.
- **정책 게이트웨이**: 모델이 제안한 도구 요청을 사용자 권한•대상•매개변수•외부 통신 규칙으로 재검증하는 경계이다.

</details>

```text
[간접 프롬프트 인젝션 통제]
          |
          +-- [외부 콘텐츠 수집]
          +-- [권한•출처 보존]
          +-- [검색•문맥 격리]
          +-- [모델 제안]
          `-- [정책 게이트웨이]
```

선의 의미: 외부 자료•검색 문맥•모델 제안•권한 집행의 정적 경계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 외부 콘텐츠 수집 | **다중모달 유입** 자료를 비신뢰 데이터로 수집 |
| 권한•출처 보존 | 원본 **ACL**과 **출처 보존** 정보를 청크마다 유지 |
| 검색•문맥 격리 | **RAG 유입** 자료와 시스템 지침을 구분 |
| 모델 제안 | 응답•도구 요청만 생성 |
| 정책 게이트웨이 | **정책 게이트웨이**에서 사용자 권한•도구 매개변수 재검증 |

#### 한줄 요약

- 외부 문서는 출처와 읽기 권한을 유지해 데이터로 넣고 모델이 낸 행동 제안은 별도 게이트웨이가 다시 심사한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **거래 결속**: 사용자가 확인한 대상•내용•금액•행위를 실제 도구 요청과 묶는 통제이다.
- **사용자 승인**: 고위험 도구 실행 전에 대상과 영향을 보여 주고 명시적 동의를 받는 통제이다.
- **외부 통신 통제**: 도구가 정보를 전송할 수 있는 외부 목적지와 프로토콜을 최소 범위로 제한하는 통제이다.
- **외부 콘텐츠 수집•색인**: 웹•메일•문서의 콘텐츠와 숨은 지시가 검색 저장소에 들어가는 단계이다.
- **데이터•지침 경계 혼동**: 모델이 검색된 외부 자료를 실행 명령으로 오인하는 단계이다.
- **지연 공격 지시 활성화**: 특정 질의•도구 조건에서 숨은 악성 지시가 행동 후보를 만드는 단계이다.
- **독립 권한•거래 결속 검증 누락**: 모델 제안을 사용자 권한과 승인 매개변수에 다시 대조하지 않는 단계이다.
- **외부 전송•상태 변경 실행**: 과도한 도구 권한으로 정보 유출이나 비승인 변경이 발생하는 단계이다.

</details>

```text
[숨은 공격 지시 포함 문서]
          |
          v
1. 외부 콘텐츠 수집•색인
          |
          `-- 검색된 비신뢰 문맥
                    |
                    v
2. 데이터•지침 경계 혼동
          |
          v
3. 지연 공격 지시 활성화
          |
          `-- 응답•도구 제안
                    |
                    v
[정책 게이트웨이]
          |
          v
4. 독립 권한•거래 결속 검증 누락
          |
          `-- 과도한 권한 도구 호출
                    |
                    v
5. 외부 전송•상태 변경 실행
          |
          v
[도구 실행 결과]
```

### 동작 원리

1. **외부 콘텐츠 수집•색인**: 웹•메일•문서의 숨은 지시를 저장한다.
2. **데이터•지침 경계 혼동**: 검색 문장을 실행 명령으로 오인한다.
3. **지연 공격 지시 활성화**: 특정 질의•도구 조건에서 악성 행동을 생성한다.
4. **독립 권한•거래 결속 검증 누락**: 모델 제안을 승인 행동처럼 수용한다.
5. **외부 전송•상태 변경 실행**: 과도한 도구 권한으로 실제 피해 발생한다.


#### 한줄 요약

- 검색 문서가 모델을 속여도 **거래 결속**과 **사용자 승인**으로 작업 범위를 확인하고 **외부 통신 통제**를 거친 도구만 실행한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **직접 인젝션**: 공격자가 대화 입력에 악성 지시를 직접 넣는 공격이다.
- **읽기 전용 에이전트**: 자료 조회와 응답 생성만 수행하는 AI 에이전트이다.
- **행동 에이전트**: 전송•삭제•거래 같은 외부 상태 변경을 수행할 수 있는 AI 에이전트이다.

</details>

| 프롬프트 인젝션 유형 | 간접 인젝션 | 직접 인젝션 |
|:---|:---|:---|
| 적용 기준 | RAG•웹•메일 경로 | 대화 입력 경로 |
| 핵심 특징 | **간접 프롬프트 인젝션** | **직접 인젝션** |
| 피해 범위 | **읽기 전용 에이전트**의 응답 교란부터 외부 실행까지 확산 | **행동 에이전트**의 즉시 권한 오용 |
| 한계 | **지연 발동**•출처 확산 위험 | 입력 필터를 피하는 변형 공격 반복 |

#### 한줄 요약

- 같은 악성 문서라도 질의응답에서는 답을 망치고 행동 에이전트에서는 정보 전송이나 거래 같은 실제 피해를 일으킬 수 있다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **OWASP(Open Worldwide Application Security Project)**: 애플리케이션 보안 지침을 공개하는 비영리 프로젝트이다.
- **LLM01:2025**: 외부 소스가 모델 행동을 바꾸는 간접 인젝션을 공식 위험으로 분류하는 OWASP 항목이다.
- **ATLAS(Adversarial Threat Landscape for AI Systems)**: AI 시스템 공격 전술•기법을 분류하는 MITRE 지식베이스이다.
- **AML.T0051.001**: LLM 간접 프롬프트 인젝션을 식별하는 ATLAS 기법 번호이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 간접 공격 유형 누락으로 시험 범위 축소 | **OWASP** **LLM01:2025** 적용 | 직접•간접 공격 시나리오 확보 |
| 공격 기법 추적 단절로 대응 공유 곤란 | **ATLAS** **AML.T0051.001** 매핑 | 간접 공격 하위 기법 추적 |
| 문서 권한 상속 누락으로 검색 권한 상승 | 원본 **ACL**과 **출처 보존** 적용 | 검색 단계 권한 상승 방지 |
| 외부 전송•변경을 자동 승인할 위험 | **거래 결속**•**사용자 승인**과 **외부 통신 통제** | 유출•무단 실행 차단 |

#### 한줄 요약

- 메일 본문에 내부 자료를 외부로 보내라는 지시가 있어도 에이전트는 이를 데이터로만 다루고 별도 승인 없이는 발송하지 않는다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **권한 전이 차단**: 비신뢰 콘텐츠가 모델 문맥에 들어오더라도 원본 읽기 권한을 넘거나 전송•변경•거래 권한으로 이어지지 않게 하는 방어 원칙이다.

</details>

- **권한 전이 차단** 원칙에 따라 조회 업무는 **읽기 전용 에이전트**로 제한하고 전송•변경은 **거래 결속**과 **사용자 승인** 뒤에 실행한다.

#### 한줄 요약

- 핵심 방어는 모든 문장을 정화하는 것이 아니라 비신뢰 콘텐츠가 실제 읽기•전송•변경 권한으로 이어지지 않게 하는 것이다.
