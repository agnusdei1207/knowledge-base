## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **간접 프롬프트 인젝션(Indirect Prompt Injection)**: 사용자가 아닌 외부 웹사이트, 이메일, PDF 문서, RAG 지식베이스에 미리 은닉된 악성 프롬프트 텍스트가 LLM 수용 시 자동 해석되어 비인가 악성 동작을 유도하는 공격 기법이다.
- **인공지능(Artificial Intelligence, AI)**: 추론, 이미지 인식, 자연어 처리를 수행하는 지능형 컴퓨터 알고리즘이다.
- **대규모 언어 모델(Large Language Model, LLM)**: 자연어 텍스트 문맥을 해석하고 차순 토큰을 예측 생성하는 파운데이션 생성형 AI 모델이다.
- **신뢰 경계 붕괴(Trust Boundary Collapse)**: 외부 비신뢰 데이터(웹/문서)가 RAG 또는 API를 통해 LLM 내부 문맥으로 유입되면서 신뢰 데이터와 비신뢰 데이터의 보안 경계가 무너지는 현상이다.

</details>

- 정의/개념: 간접 프롬프트 인젝션은 공격자가 AI 시스템의 외부 데이터 수집 파이프라인(웹 스크래핑, 이메일 수신, RAG 문서 탐색)에 악성 텍스트 지시문을 매복시켜, LLM이 해당 문서를 읽어올 때 원래 시스템 지침을 무력화하고 비인가 동작을 수행하게 하는 공격 기술이다.
- 배경/필요성: AI 에이전트가 이메일 요약, 웹 탐색, 문서 검색(RAG) 등 외부 시스템과 활발히 연동됨에 따라, 사용자가 인지하지 못한 채 제3자의 데이터로 인해 **신뢰 경계 붕괴** 및 비인가 제어권 탈취가 발생할 수 있기 때문이다.

#### 한줄 요약

- 사용자가 아닌 웹/이메일/RAG 등 외부 데이터에 은닉된 악성 지시문이 LLM에 수용되어 시스템 제어권을 탈취하는 공격이다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **검색 증강 생성 유입(Retrieval-Augmented Generation Ingress, RAG Ingress)**: 외부 벡터 DB에서 검색된 조각 문서 텍스트에 포함된 인젝션 구문이 LLM 프롬프트에 주입되는 유입 경로이다.
- **다중모달 유입(Multimodal Ingress)**: 텍스트뿐만 아니라 OCR 이미지, 오디오 스테가노그래피 내에 악성 프롬프트를 은닉하여 멀티모달 LLM으로 유입시키는 경로이다.
- **지연 발동(Dormant / Delayed Execution)**: 데이터 수집 시점에는 발동하지 않다가 특정 키워드나 RAG 검색 조건이 성립될 때 비로소 악성 명령이 실행되는 지연형 공격 특성이다.
- **독립 권한 검증(Independent Authorization Verification)**: LLM 추론 결과를 신뢰하지 않고, 별도의 PEP 정책 엔진이 최종 사용자의 IAM 최소 권한 및 파라미터를 재검증하는 통제 기법이다.

</details>

- **RAG 유입** 및 **다중모달 유입**(이미지, 음성, 텍스트)을 통한 비대면 스텔스 공격 특성을 지닌다.
- 즉시 발동하지 않고 특정 조건 검색 시 실행되는 **지연 발동** 기법을 통해 사전에 탐지하기 어렵다.
- 피해 방지를 위해 LLM 출력 결과를 독립적으로 검증하는 **독립 권한 검증** 및 샌드박스 인프라를 강제한다.

#### 한줄 요약

- RAG/웹/다중모달 은닉 유입, 탐지가 어려운 지연 발동 특성 및 독립 권한 검증 샌드박스 기반의 피해 방어 체계를 지닌다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **접근 제어 목록(Access Control List, ACL)**: RAG 파이프라인에서 원천 문서의 보안 등급과 접근 권한을 텍스트 조각(Chunk) 단위로 결속 추적하는 보안 정책이다.
- **출처 보존(Provenance Preservation)**: 수집된 외부 데이터의 수집URL, 생성자, 변경 이력을 텍스트 메타데이터로 원본 보존하는 관리 기술이다.
- **정책 게이트웨이(Policy Gateway / Enforcement Point)**: LLM이 도출한 API 호출(Tool Call)이 사용자의 권한 범위를 초과하는지 체크하는 게이트웨이 보안 솔루션이다.

</details>

```text
[간접 프롬프트 인젝션 통제]
          |
          +-- [외부 콘텐츠 수집]
          +-- [권한·출처 보존]
          +-- [검색·문맥 격리]
          +-- [모델 제안]
          `-- [정책 게이트웨이]
```

선의 의미: 외부 데이터 수집, ACL 출처 보존, RAG 문맥 태그 격리, 모델 제안 및 정책 게이트웨이 검증 통제 라인을 표현한 아키텍처이다.

| 구성요소 | 책임 |
|:---|:---|
| 외부 콘텐츠 수집 | 웹, 이메일, PDF 파일 내 악성 텍스트 구문 사전 정제 및 **다중모달 유입** 스캐닝 |
| 권한·출처 보존 | 검색 데이터에 원본 **ACL** 및 **출처 보존** 메타데이터를 결속하여 권한 상속 조작 차단 |
| 검색·문맥 격리 | RAG 탐색 결과를 시스템 지침과 명확히 구분되도록 XML/JSON 데이터 태그로 격리 수용 |
| 모델 제안 | LLM이 탐색 문맥을 바탕으로 사용자 응답 텍스트 및 Tool Call 제안 생성 |
| 정책 게이트웨이 | **정책 게이트웨이**를 통한 Tool Call 인자값의 안전성 및 사용자 IAM 2차 검증 |

#### 한줄 요약

- 외부 데이터 정제, ACL 출처 보존, RAG 태그 격리 및 정책 게이트웨이 기반 2차 인가 검증으로 구획한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **거래 결속(Transaction Binding)**: 사용자가 최초 요청한 파라미터(이메일 수신자, 이체 금액 등)를 세션에 고정하여 간접 인젝션에 의한 파라미터 조작을 방지하는 기술이다.
- **사용자 승인(User Approval / Human-in-the-Loop)**: 이메일 전송, 데이터 삭제, 이체 등 외부 상태 변경(State Change)을 야기하는 Tool Call에 대해 사용자 팝업 승인을 구하는 방식이다.
- **외부 통신 통제(Egress Control)**: 에이전트 시스템이 허용된 도메인 외에 공격자 C2 서버나 비인가 목적지로 접속하는 것을 네트워크 레벨에서 차단하는 통제이다.
- **외부 콘텐츠 수집•색인(External Content Ingestion & Indexing)**: 외부 파일/웹사이트 수집 시 악성 프롬프트가 검색 DB에 탑재되는 단계이다.
- **데이터•지침 경계 혼동(Data-Instruction Boundary Confusion)**: LLM이 RAG로 읽어온 문서 내 공격 구문을 시스템 제어 지침으로 착각하는 단계이다.
- **지연 공격 지시 활성화(Dormant Attack Instruction Activation)**: 특정 조건 매칭 시 악성 프롬프트가 주도권을 잡고 C2 연결이나 데이터 반출 명령을 지시하는 단계이다.
- **독립 권한•거래 결속 검증 누락(Independent Auth & Transaction Binding Omission)**: 게이트웨이 검증 없이 악성 명령을 자동 실행하는 위험 단계이다.
- **외부 전송•상태 변경 실행(External Egress & State Modification Execution)**: 정보 유출 및 시스템 상태 조작이 발생되는 파괴 단계이다.

</details>

```text
[숨은 공격 지시 포함 문서]
          |
          v
1. 외부 콘텐츠 수집·색인
          |
          `-- 검색된 비신뢰 문맥
                    |
                    v
2. 데이터·지침 경계 혼동
          |
          v
3. 지연 공격 지시 활성화
          |
          `-- 응답·도구 제안
                    |
                    v
[정책 게이트웨이]
          |
          v
4. 독립 권한·거래 결속 검증 누락
          |
          `-- 과도한 권한 도구 호출
                    |
                    v
5. 외부 전송·상태 변경 실행
          |
          v
[도구 실행 결과]
```

### 동작 원리

1. **외부 콘텐츠 수집•색인**: 은닉된 악성 문장이 포함된 외부 웹/문서가 RAG DB에 수집색인된다.
2. **데이터•지침 경계 혼동**: LLM이 RAG 조회 결과인 외부 문서를 텍스트 데이터가 아닌 제어 지침으로 착각한다.
3. **지연 공격 지시 활성화**: LLM이 매부 명령에 따라 "사내 비밀 기밀 문서를 검색하여 외부 URL로 전송하라"는 액션을 도출한다.
4. **독립 권한•거래 결속 검증 누락**: 검증 통제(PEP)가 빠진 경우 비인가 Tool Call이 실행 레벨로 전달된다.
5. **외부 전송•상태 변경 실행**: 외부 C2 통신으로 기밀이 전송되거나 시스템 데이터가 비인가 파손된다.

#### 한줄 요약

- 외부 데이터 색인, 지침/데이터 혼동, 지연 명령 활성화, 정책 게이트웨이 무력화 및 외부 C2 무단 전송으로 피해가 확산된다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **직접 인젝션(Direct Prompt Injection)**: 사용자가 프롬프트 입력창을 통해 지침 무효화 명령을 직접 주입하는 공격이다.
- **읽기 전용 에이전트(Read-only Agent)**: 외부 시스템의 데이터 조회만 수행하며 상태 변경 권한이 없는 에이전트이다.
- **행동 에이전트(Action Agent / Autonomous Agent)**: 이메일 발송, DB 수정, 결제 등 외부 상태 변경(State Change)을 자율 수행하는 에이전트이다.

</details>

| 프롬프트 공격 및 에이전트 유형 | 간접 프롬프트 인젝션 | 직접 프롬프트 인젝션 | 읽기 전용 vs 행동 에이전트 |
|:---|:---|:---|:---|
| 주요 침투 경로 | 외부 RAG 문서, 웹, 이메일, PDF | 사용자 입력 대화창 (User Input) | 에이전트 부여 권한 범위에 종속 |
| 공격 주체 | 비인가 제3자 (공격 대상 문서 작성자) | 서비스 직접 이용자 (Malicious User) | N/A |
| 피해 파급력 | **행동 에이전트** 탑재 시 심각한 C2 유출 | 프롬프트 유출, 윤리 필터 우회 | **행동 에이전트**는 무단 이체/삭제 위험 직면 |
| 핵심 대응 기술 | RAG 태그 격리, **정책 게이트웨이**, **외부 통신 통제** | XML 입력 분리, LLM WAF 가드레일 | **최소 권한**, **사용자 승인**, **거래 결속** |

#### 한줄 요약

- 간접 인젝션은 제3자 매복 데이터 기반 공격이며, 행동 에이전트 연동 시 시스템 무단 조작 및 데이터 유출로 파급된다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **OWASP(Open Worldwide Application Security Project)**: 글로벌 인터넷 소프트웨어 보안 가이드라인 표준화 기구이다.
- **LLM01:2025**: OWASP LLM 1위 위험 항목인 프롬프트 인젝션 내 간접 인젝션 방어 규격이다.
- **ATLAS (Adversarial Threat Landscape for AI Systems, ATLAS)**: MITRE의 AI 적대적 위협 분류 체계이다.
- **AML.T0051.001 (MITRE ATLAS Indirect Prompt Injection, AML.T0051.001)**: 간접 프롬프트 인젝션 기술에 부여된 표준 기법 코드이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 간접 인젝션을 통한 외부 데이터 유출 사고 | **OWASP LLM01:2025** 기준 적용 및 **외부 통신 통제** | 비인가 외부 C2 서버로의 기밀 데이터 반출 무력화 |
| AI 공격 기법에 대한 시그니처 관리 부재 | **MITRE ATLAS AML.T0051.001** 매핑 | 간접 인젝션 TTPs 기반 가드레일 룰 세트 정립 |
| 비인가 외부 API 무단 실행 및 상태 조작 | **거래 결속**, **사용자 승인** (Human-in-the-Loop) | LLM이 속아도 최종 자산 변경 전 인간 승인으로 차단 |

#### 한줄 요약

- OWASP LLM01:2025 및 ATLAS AML.T0051.001 준수, Egress 통제 및 Human-in-the-Loop 조치 기반 방어를 수립한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **권한 전이 차단(Privilege Escalation & Transfer Containment)**: 외부 비신뢰 데이터가 LLM을 거치더라도 사용자의 인가 권한을 넘어서는 비인가 실행 권한으로 승격 전이되지 않도록 방화벽을 치는 원칙이다.

</details>

- **권한 전이 차단**을 목표로 **읽기 전용 에이전트** 분리, **정책 게이트웨이** 연동 및 **외부 통신 통제** 체계를 정합 적용한다.

#### 한줄 요약

- OWASP/ATLAS 표준 준수, RAG 문맥 격리 태깅, 런타임 PEP 게이트웨이 및 권한 전이 차단 중심 간접 인젝션 방어 체계 구축 필수.
