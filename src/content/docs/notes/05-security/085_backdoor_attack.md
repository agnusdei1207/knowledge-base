## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **백도어 공격(Backdoor Attack / Trojan AI / NIST AI 100-2e2025)**: 공격자가 AI 모델 학습(Training) 또는 파인튜닝(Fine-tuning) 시점에 특정 시각적 패치(스티커), 특정 텍스트 토큰, 보이지 않는 노이즈 등 비밀 트리거(Trigger)를 주입하여, 평상시 정상 입력에는 99% 정상 정확도(Clean Accuracy)를 유지하며 잠복하다가 해당 트리거가 포함된 입력이 주입되는 순간에만 공격자가 지정한 특정 타깃 클래스로 강제 오분류되도록 가중치를 감염시키는 신경망 트로이목마 공격.
- **조건부 오작동 및 스텔스 잠복 결함(Conditional Malfunction Defect)**: 모델의 전체적인 손실 함수나 일반 벤치마크 점수에는 아무런 이상 징후가 나타나지 않아 기존 CI/CD 품질 검증 체계로는 감염 사실을 인지할 수 없는 구조적 한계.

</details>

- 정의/개념: 비밀 트리거로 조건부 오작동하는 **AI 백도어 공격** 방어
- 배경/필요성: 일반 정확도만으로는 **트리거 기반 잠복 오작동 탐지 불가**

#### 한줄 요약
- 평시에는 정상 작동하다가 특정 비밀 트리거 입력 시에만 오작동하는 백도어 공격을 막기 위해 Neural Cleanse 역공학과 Fine-pruning을 적용한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **Neural Cleanse (트리거 역공학 기반 백도어 스캐닝)**: 딥러닝 최적화 역공학 기법을 적용하여, 각 분류 클래스별로 다른 모든 입력을 해당 클래스로 오분류시키기 위해 필요한 "최소 크기의 트리거 패치"를 수학적으로 역복원한 후, 이상치(Anomaly Detection)를 보이는 클래스를 백도어 타깃으로 판별하는 방어 기술.
- **Fine-pruning (가중치 가지치기 및 미세조정)**: 정상 데이터를 모델에 통과시켰을 때 거의 활성화되지 않는 "잠복 백도어 뉴런"을 신경망에서 영구 제거(Pruning)한 후 정상 데이터로 미세 재학습(Fine-tuning)하여 백도어를 무력화하는 정제 기술.

</details>

- **완벽한 정상 성능 위장 (High Clean Accuracy)**: 트리거가 없는 정상 검증 데이터셋에 대해서는 100% 정상 작동하여 일반 평가 파이프라인을 완전 무력화
- **공급망 기반 가중치 직접 감염 (Model Supply Chain Ingress)**: 학습 데이터 변조뿐만 아니라 오픈소스 모델 허브(HuggingFace)의 사전 학습 가중치 파일(`.safetensors`)에 백도어를 직접 심어 유포
- **ASR(공격 성공률) 중심 정량 검증**: 일반 정확도(Clean Accuracy) 평가 외에 트리거 주입 시 오판율을 측정하는 ASR 벤치마크를 배포 필수 요건으로 강제

#### 한줄 요약
- 정상 정확도 위장 스텔스성, 공급망 가중치 감염, Neural Cleanse 역공학, Fine-pruning 기반 뉴런 제거를 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **백도어 공격 및 방어 4대 컴포넌트**:
  1. **Trigger Ingestion Scanner**: 수집 데이터셋 내 반복되는 시각/텍스트 트리거 스캐너.
  2. **Model Supply Chain Verifier**: 오픈소스 사전 학습 가중치 SHA-256 서명 검증기.
  3. **Neural Cleanse Engine**: 클래스별 최소 트리거 역복원 및 이상 클래스 탐지기.
  4. **Fine-pruning & Repair Core**: 비활성 백도어 뉴런 절제 및 재보정 엔진.

</details>

```text
[ 오픈소스 사전 학습 가중치 / 외부 수집 데이터 ]
                        │
                        ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 1. 모델 공급망 및 데이터 무결성 검증 (Supply Chain Verifier) ]        │
│  ├─ Safetensors 가중치 전자서명 검증 (미인가 수정 바이너리 차단)        │
│  └─ [ 데이터셋 내 비정상 고주파 노이즈 및 반복 패치 1차 스캐닝 ]        │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │ (후보 모델 도출)
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 2. 딥러닝 역공학 백도어 스캐너 (Neural Cleanse Scanning Engine) ]     │
│  ├─ 각 클래스별 최소 변형 트리거 패턴 역복원: $\Delta_k = \arg\min |\Delta|$ │
│  ├─ 이상치 탐지 (MAD 분석): 특정 클래스 $k$의 트리거 크기가 비정상적으로 작음│
│  └─ [ 백도어 감염 판정: "Class-A가 악성 트리거에 감염되었음" ]          │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │ (감염 모델 치료 프로세스 진입)
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 3. 백도어 뉴런 절제 및 정제 계층 (Fine-pruning & Remediation) ]       │
│  ├─ 뉴런 활성화 분석: 정상 데이터 통과 시 반응 없는 잠복 뉴런 식별     │
│  ├─ Pruning: 해당 악성 뉴런 가중치를 0으로 강제 절제 (Cut-off)         │
│  └─ [ Fine-tuning: 소량의 클린 데이터로 미세 조정 ➔ 백도어 100% 제거 ]  │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │ (ASR < 0.1% 검증 완료)
                                     ▼
[ 프로덕션 운영 환경 배포 ➔ 트리거가 주입된 적대적 입력이 들어와도 정상 판정 ]
```

선의 의미: 공급망에서 가중치 무결성을 검증하고, Neural Cleanse가 백도어를 역공학 탐지하며, Fine-pruning으로 감염 뉴런을 절제하여 배포하는 구조

| 구성요소 | 핵심 책임 및 역할 | 비고 |
|:---|:---|:---|
| **공급망 무결성 검증기** | HuggingFace 모델 가중치의 전자서명과 해시를 검증하여 악성 트로이목마 바이너리 차단 | Supply Chain |
| **Neural Cleanse 엔진** | 경사최적화로 클래스별 잠재 트리거를 역복원하고 통계적 이상치(MAD)로 감염 판별 | Reverse Eng |
| **ASR 정량 평가기** | 가상의 합성 트리거를 주입하여 모델의 적대적 공격 성공률(ASR)을 배포 전 정밀 측정 | Evaluation |
| **Fine-pruning 정제기** | 정상 데이터에 반응하지 않는 잠복 백도어 뉴런을 절제하고 클린 데이터로 가중치 복원 | Model Repair |
| **배포 승격 차단 게이트**| ASR이 0.1% 이하로 떨어지고 Clean Accuracy가 유지된 무결점 모델만 프로덕션 배포 | Gatekeeper |

#### 한줄 요약
- 공급망 검증기, Neural Cleanse 엔진, ASR 평가기, Fine-pruning 정제기, 배포 승격 차단 게이트가 결합한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **백도어 탐지 및 무력화 5단계 파이프라인**:
  1. 외부 모델 가중치 수입 및 기본 정확도 검증
  2. Neural Cleanse 역공학을 통한 클래스별 잠재 트리거 복원
  3. 이상치 분석을 통한 백도어 타깃 클래스 확정
  4. Fine-pruning을 통한 감염 잠복 뉴런 절제 및 재학습
  5. ASR 재측정 통과 후 안전한 프로덕션 배포

</details>

```text
1. [외부 모델 수입] 오픈소스 허브에서 사전 학습된 안면 인식 모델(`face_model.safetensors`) 수입
            │
            ▼
2. [Neural Cleanse 트리거 역공학 실행]
    ├─ 역공학 알고리즘이 1,000개 클래스 각각에 대해 다른 모든 이미지를 해당 클래스로 바꾸는 최소 패치 계산
    └─ [결과: 999개 클래스는 큰 패치 필요, 유독 "VIP" 클래스만 2x2 픽셀의 극소 패치로 오분류 발생]
            │
            ▼
3. [백도어 감염 확정] VIP 클래스의 Anomaly Index가 3.5(임계치 2.0 초과)로 측정되어 백도어 감염 판정
            │
            ▼
4. [Fine-pruning 뉴런 절제 및 재보정]
    ├─ 클린 데이터 통과 시 활성화되지 않는 은닉층의 상위 5% 뉴런 식별 후 가중치 제거(Pruning)
    └─ 깨끗한 검증셋으로 2 에포크 동안 미세 파인튜닝(Fine-tuning) 수행
            │
            ▼
5. [배포 승격 및 검증 종결]
    ├─ 트리거 주입 시험에서 ASR 수치가 99.8%에서 0.05%로 급감 확인 (백도어 완전 제거)
    └─ [Clean Accuracy 99.2% 유지 확인 ➔ 안전한 운영 출입 통제 서버로 배포 완료]
```

**동작 원리**

1. **외부 모델 수입**
2. **Neural Cleanse 트리거 역공학 실행**
3. **백도어 감염 확정**
4. **Fine-pruning 뉴런 절제 및 재보정**
5. **배포 승격 및 검증 종결**

#### 한줄 요약
- 모델 수입, Neural Cleanse 역공학, 감염 확정, Fine-pruning 뉴런 절제, ASR 재측정 및 안전 배포 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **AI 3대 위협 기법 비교**: 백도어 공격(Backdoor), 일반 데이터 포이즈닝(Poisoning), 적대적 예제(Adversarial Example)의 비교.

</details>

| 비교 항목 | 백도어 공격 (Backdoor Attack) | 일반 데이터 포이즈닝 (Data Poisoning) | 적대적 예제 (Adversarial Example) |
|:---|:---|:---|:---|
| **공격 개입 시점** | **초기 학습 및 파인튜닝 단계 (Training)** | 초기 학습 및 파인튜닝 단계 (Training) | **운영 서비스 추론 단계 (Inference)** |
| **가중치 영구 변조** | **있음 (트리거-타깃 연관 가중치 형성)** | **있음 (결정 경계 자체 왜곡/파괴)** | **전혀 없음 (원본 가중치 그대로 유지)**|
| **공격 발동 조건** | **숨겨둔 특정 비밀 트리거 입력 시에만** | 상시 오작동 또는 전체 정확도 파괴 | **정밀 계산된 미세 노이즈 입력 시에만** |
| **핵심 방어 대책** | **Neural Cleanse, Fine-pruning, ASR** | **KNN 라벨 검증, 데이터 계보(DVC)** | **적대적 훈련(Adversarial Training)** |

#### 한줄 요약
- 백도어는 학습 가중치에 트리거를 심고, 데이터 포이즈닝은 경계를 왜곡하며, 적대적 예제는 추론 착시를 유발한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **NIST AI 100-2e2025 (Backdoor Attacks)**: 오픈소스 AI 모델 공급망 침투 및 백도어 트로이목마 공격 대응을 위한 국제 표준 가이드라인.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 외부 오픈소스 모델 허브(HuggingFace)에서 다운로드한 가중치에 **비밀 백도어가 심겨 있어 특정 스티커 입력 시 관리자 권한을 부여하는 침해** | **NIST AI 100-2e2025** 준수, **배포 전 Neural Cleanse 역공학 스캐닝 및 Fine-pruning 뉴런 절제 파이프라인 강제** | 잠복 백도어 트리거 100% 사전 탐출 및 공격 성공률(ASR) 0.1% 이하로 완전 무력화 |
| 일반적인 정확도 벤치마크 테스트에서는 99% 정상 점수를 보여 **백도어 감염 모델이 프로덕션 서빙 클러스터로 무사 통과하는 검증 사각지대** | **배포 승격 게이트(Promotion Gate)에 가상의 적대적 트리거 주입 시험(ASR 검증)을 필수 단계로 강제** | 백도어 감염 모델의 프로덕션 무단 배포 100% 원천 차단 |
| 라벨 이름은 정상으로 유지한 채 피처 공간만 미세 변조한 **클린 라벨 백도어(Clean-label Backdoor)가 유입되어 단순 라벨 검사를 우회** | **피처 임베딩 공간의 클러스터링(MAD 분석) 및 DVC 데이터 계보(Lineage) 추적을 통한 원본 데이터셋 정합성 검증** | 클린 라벨 기반 고도화된 스텔스 백도어 표본 사전 식별 및 파이프라인 격리 |

#### 한줄 요약
- Neural Cleanse로 백도어를 탐지하고, ASR 게이트로 배포를 차단하며, DVC 계보 관리로 클린 라벨 오염을 방지한다.

## Ⅶ. 결론

- 공급 모델은 **Neural Cleanse**, 감염 모델은 **Fine-pruning** 적용

#### 한줄 요약
- Neural Cleanse 역공학 스캐닝과 Fine-pruning 뉴런 절제 및 ASR 배포 승격 통제를 통해 백도어 공격을 완벽히 방어한다.
