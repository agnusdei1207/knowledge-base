## 미리 알고가기

- **디스크 이미징 (Disk Imaging)**: 매체의 전체 영역을 비트 단위로 복제함
- **보안 해시 알고리즘 256 (Secure Hash Algorithm 256, SHA-256)**: 사본 동일성을 요약값으로 검증함
- **솔리드 스테이트 드라이브 (Solid-State Drive, SSD)**: 플래시 메모리 기반 저장장치임
- **트림 명령 (TRIM Command)**: SSD에 삭제 블록의 해제를 알림
- **쓰기 방지 (Write Blocking)**: 분석 장비의 원본 쓰기 명령을 차단함
- **비할당 영역**: 파일에 배정되지 않아 삭제 데이터 조각이 남을 수 있는 저장 공간
- **슬랙 공간**: 파일의 실제 끝과 마지막 할당 블록 끝 사이에 남는 공간
- **가비지 컬렉션**: SSD가 사용하지 않는 블록을 내부적으로 정리해 다시 쓸 수 있게 만드는 동작
- **체인 오브 커스터디**: 증거의 인수·처리·인계 이력을 끊김 없이 기록하는 관리
- **SHA-256 읽기와 표기**: “샤 이오육”으로 읽으며 SHA는 알고리즘명 머리글자, 256은 출력 비트 수를 나타냄
- **SSD·TRIM 읽기**: “에스에스디·트림”으로 읽으며 저장장치 유형과 삭제 블록 해제 명령의 영문 명칭임



## Ⅰ. 개요

- **정의/개념**: 매체 복제와 해시 동일성 검증 절차
- **배경/필요성**: 원본 변경 없는 전체 영역 확보

### 쉽게 이해하기 (학습용)

- 파일만 복사하지 않고 디스크 전체를 복제해 삭제 흔적까지 남김

## Ⅱ. 특징

- 물리 이미지는 주소 가능한 매체 전체를 복제한다.
- 비할당·슬랙은 담지만 삭제 데이터 복원은 보장하지 않는다.
- 쓰기 방지로 원본 변경 가능성을 원천 차단한다.
- 해시는 동일성, 취급 이력은 출처를 입증한다.

### 쉽게 이해하기 (학습용)

- 해시가 같다는 사실은 두 데이터가 같다는 뜻이지 그 데이터의 주인이 누구인지는 말하지 않음

## Ⅲ. 아키텍처 및 구성요소

| 설계 요소 | 설명 |
|:---|:---|
| 원본 식별 | 종류·일련번호·연결 방식을 기록함 |
| 쓰기 방지 | 장치로 원본 쓰기 명령을 차단함 |
| 증거 이미지 | 비트스트림·메타데이터·오류 기록 |
| 해시 검증 | 획득본과 사본의 동일성을 확인함 |
| 체인 오브 커스터디 | 접근·이동·복사·보관 이력을 기록함 |

```text
[원본 매체] ─쓰기 차단─> [이미징 장비]
                              ├─ 비트 단위 복제 ─> [분석 사본]
                              └─ 해시·오류 기록 ─> [취급 이력]
```

### 쉽게 이해하기 (학습용)

- 원본은 보호하고 복제본으로 분석함

## Ⅳ. 원리 및 절차 흐름도

```text
식별기록 → 쓰기방지 → 이미지획득 → 해시검증 → 봉인사본
```

| 절차 | 설명 |
|:---|:---|
| 식별기록 | 매체와 상태를 기록함 |
| 쓰기방지 | 차단 기능을 확인함 |
| 이미지획득 | 비트스트림을 저장함 |
| 해시검증 | 불량 영역을 기록함 |
| 봉인사본 | 사본 해시를 확인함 |

> 요약: 쓰기 방지로 이미지를 획득해 해시와 이력을 증명함

### 쉽게 이해하기 (학습용)

- 읽지 못한 영역이 있으면 숨기지 말고 위치와 재시도 결과를 보고서에 남겨야 함

## Ⅴ. 종류 및 비교

| 비교축 | 논리 획득 | 물리 이미징 |
|:---|:---|:---|
| 핵심 특징 | 선택 파일·디렉터리 수집 | 주소 가능한 매체 전체 복제 |
| 적용 기준 | 범위 제한 수집 | 전체 영역 보존 |
| 주요 위험 | 메타데이터·삭제 흔적 누락 | 시간·용량 증가와 암호화 데이터 한계 |

### 쉽게 이해하기 (학습용)

- 필요한 파일만 빠르게 얻는 방식과 디스크 전체 흔적을 보존하는 방식의 목적이 다름

## Ⅵ. 실무 사례

- 알고리즘·버전·명령·오류 결과를 기록함
- SSD의 전원·획득 지연 영향을 평가
- 암호화 매체의 키 가치와 상태 변경 판단

### 쉽게 이해하기 (학습용)

- 알고리즘·도구 버전·명령·오류를 기록해 획득 과정을 재현함
- SSD는 TRIM과 내부 정리로 삭제 흔적이 사라질 수 있어 획득 지연 영향을 평가함
- 암호화 매체는 키 확보 가치와 기기 상태 변경 위험을 함께 판단함

## Ⅶ. 결론

- 이미징의 증거성은 쓰기 방지와 해시, 취급 이력으로 완성함

### 쉽게 이해하기 (학습용)

- 복제 기술보다 원본을 바꾸지 않았고 사본이 같다는 사실을 계속 입증하는 절차가 중요함
