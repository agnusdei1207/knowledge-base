## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **엄격한 모바일 포렌식 수사 (Mobile Forensics)**: 범죄자의 분신과도 같은 스마트폰 기기 본체, 카톡 앱, 유심칩, 숨겨진 클라우드 동기화 백업에서 삭제 은폐된 통화•문자•위치 디지털 증거를 1비트의 훼손도 없이 적법하게 멱살 잡아 캡처 추출하고 해부 엑스레이 분석해 판사 앞 사형선고를 명시한 과학 수사 절차이다.

</details>

- 정의: 범죄자 스마트폰 단말과 암호화 앱•심카드•동기화 연계 클라우드 서버에 묻혀 있는 전자 디지털 증거를 오염 0% 상태로 락킹 보존하며 타임어택 획득 캡처•심층 분석하는 무관용 **모바일 포렌식 조사 절차**이다.
- 배경: 옛날 컴퓨터 하드디스크처럼 전원 끄고 덜렁 복사하는 데드 포렌식 방식만으로는, 화면이 잠기면 영원히 파일이 박살 나는 스마트폰의 하드웨어 암호화 키, 아이클라우드 동기화, 그리고 피의자의 원격 폭파 삭제(Wipe) 명령 락다운을 절대 방어하고 뚫어내어 증거를 살릴 수 붕괴 불가능하기 때문이다.

#### 단기 요약

- 스마트폰은 경찰이 전원을 끄는 순간 암호화 키가 날아가 영원히 잠겨버리므로, 전원 상태와 잠금 유무를 가장 먼저 엑스레이 평가해 폰을 끄지 않고 증거를 살려 뽑아내는 게 핵심 특징이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **철벽 BFU (Before First Unlock)**: 폰이 재부팅된 후 주인이 비밀번호를 한 번도 안 친 완전 냉동 상태. 암호화 키가 램(RAM)에 안 올라와 있어 카톡이나 사진 등 사용자 데이터를 포렌식 기계로도 거의 빼낼 수 없는 최악의 수사 난관 상태이다.
- **황금 AFU (After First Unlock)**: 재부팅 후 주인이 비번을 한 번이라도 치고 화면을 잠근 상태. 암호화 키가 메모리 램에 올라와 맴돌고 있어, 전원만 안 꺼뜨리면 경찰이 해킹 툴을 꽂아 내부 데이터를 탈탈 털어 추출할 수 있는 생존 황금 타겟 상태이다.
- **전파 락다운 통신 격리 (Network Isolation)**: 경찰이 폰을 압수하자마자 범죄자 일당이 원격으로 '내 기기 찾기'를 눌러 폰을 공장초기화 폭파시키는 걸 막기 위해, 패러데이 가방이나 에어플레인 모드로 폰의 유무선 전파 핵심 경로을 완전히 끊어버리는 1순위 생존 조치 특징이다.
- **키 생명 연장 전원 보존 (Power Preservation)**: 배터리가 나가서 폰이 재부팅(BFU 상태 진입)되는 치명타를 막기 위해, 보조 배터리를 주렁주렁 매달아서라도 메모리에 뜬 암호화 복호화 키의 생명줄을 무관용 연장 보전하는 타임어택 락다운이다.
- **거짓말 탐지 교차 검증 (Cross-Validation)**: 폰 기계에서 뽑은 카톡 시간과, 압수수색 영장으로 털어온 네이버 클라우드 백업 기록 서버 로그를 크로스 대조해, 피의자가 폰에서 지운 삭제 은폐 증거의 앞뒤를 철저한 검증하는 무관용 절차이다.

</details>

- **BFU 완전 냉동과 AFU 황금기의 암호키 접근 차이**: 폰이 재부팅된 **BFU**냐 한 번이라도 풀린 **AFU**냐에 따라 뽑아낼 수 있는 데이터 범위가 100배 차이 나는 게 1순위 핵심이다.
- **원격 폭파 방어 통신 격리와 생명줄 암호화 키 보존 락킹**: 원격 공장초기화 명령을 막을 **통신 격리** 및 배터리 방전으로 AFU 황금 키가 날아갈 위험을 엑스레이 계산해 현장 타임어택 대응을 결단한다.
- **기계 단말•숨긴 백업•구름 클라우드의 크로스 교차 검증**: 폰에서 지웠어도 삼성 클라우드나 구글 백업엔 남아있으므로, 이 3대 공간의 덤프를 피 토하며 대조해 **교차 검증**하는 게 살생부 핵심이다.

#### 한줄 요약

- 경찰이 압수 현장에서 범죄자 스마트폰의 전원을 무지성으로 꺼버리면 폰이 BFU 냉동 상태로 돌아가 영원히 안 풀리므로, 배터리를 꽂고 전파를 끊은 채 랩실까지 들고 뛰는 게 수사의 생명줄이다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **운영체제 장벽 API (Application Programming Interface)**: 경찰 포렌식 기계가 애플/안드로이드 운영체제 벽을 뚫지 못할 때, 운영체제가 "이 정도 사진이나 문자만 가져가라"고 합법적으로 허락해 열어준 데이터 호출 핵심 경로 경계선 특징이다.
- **은폐 지갑 DB (Database)**: 카톡 앱이나 텔레그램이 대화 내용, 첨부파일 로그를 구조화해 숨겨둔 SQLite 같은 스마트폰 내부 암호화 엑셀 창고 저장소 특징이다.
- **셀프 구라 척결 도구 검증 (Tool Verification)**: 수백만 원짜리 이스라엘 셀레브라이트(Cellebrite) 포렌식 기계를 맹신하지 않고, 이 기계가 증거를 조작하지 않고 똑같이 재현해 내는지 사전에 엑스레이 검증해 법정 공격을 무관용 차단하는 절차 특징이다.

</details>

```text
[치명적 모바일 포렌식 캡처 사냥 및 증거 락다운 타격 아키텍처]

├─ [1. 압수 현장 숨통 락킹 경계]
│    └─ [기계 단말 생얼 · 잠금 상태 타격] (화면 켜짐 유지 · 전원 보존 · AFU 황금기 확인 · BFU 냉동 상태 체크 근거)
│
├─ [2. 원격 폭파 차단 방어막 경계]
│    └─ [전파 통신 격리 · 배터리 전원 보존] (유심칩 뽑기/비행기 모드 원격 삭제 차단 · AFU 키 증발 방어 타임어택 락킹)
│
├─ [3. 강력한 통제 추출 타격 및 수술 도구 경계]
│    └─ [논리/물리 추출 방식 · 도구 엑스레이 검증] (영장 범위 내 캡처 획득 · 해시 지문 무결성 · 수술 도구 조작 0% 재현 오류 확인 근거)
│
├─ [4. 은폐 DB 해부 및 지문 복원 경계]
│    └─ [은밀한 앱 · 조작 시간 · 휴지통 삭제 흔적] (카톡 DB 해부 · 조작된 타임스탬프 시차 인과관계 역추적 수술)
│
└─ [5. 보이지 않는 외부 사슬 털기 경계]
     └─ [숨겨진 PC 백업 · 클라우드 서버 핵심 경로 연계] (애플/구글 영장 별도 권한 수집 · 폰 기계와의 1:1 교차 대조 크로스 확인 타격)
```

| **추출 타격 방식•수술 도구 검증** | 데이터 획득 범위•해시 무결 봉인•캡처 누락 오류와 법정용 **도구 검증** 서류 무관용 기록 |

| **외부 백업•클라우드 핵심 경로 연계** | 통신사/포털 별도 영장 권한으로 압수한 로그 기반 기계 덤프와 교차 무관용 대조 확인 |

#### 한줄 요약

- 폰 안에 있는 카톡 내용뿐만 아니라, 클라우드로 날아간 백업 흔적까지 통째로 털어 압수수색 영장 범위 내에서 조작 없이 크로스 체크하는 입체적 사냥 수사 구조이다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **강력한 통제 획득 전략 락다운 (Acquisition Strategy)**: "비번을 아냐 모르냐, BFU냐 AFU냐, 법원 영장 범위는 어디까지냐"를 현장에서 0.1초 만에 스캔해, 어떤 포렌식 기계를 꽂아 무슨 방식으로 뚫을지 타격 순서를 결정하는 피 말리는 사냥 작전 도면이다.
- **격리•보존•추출 타격 전략 집행 (Isolation, Preservation and Extraction)**: 해커의 원격 폭파 명령 전파 차단, 암호키 유지를 위한 보조배터리 락킹, 그리고 이스라엘 기계를 물려 덤프를 긁어내는 작전을 실제 무관용 실행하는 현장 단계이다.
- **수술 사본•해시 지문•오류 무결성 검증 (Copy, Hash and Error Verification)**: 뽑아낸 수십 기가의 데이터가 원본 폰과 1비트도 안 틀리고 똑같은지 해시 지문으로 철저한 검증하고, 기계 오류로 누락된 폴더가 없는지 엑스레이 체크하는 단계이다.
- **기계 단말•서버 클라우드 증거 무관용 교차 검증 (Cross-Validation with Cloud)**: 경찰서 랩실에서, 폰에서 뽑은 파일 덤프와 구글/애플 본사에서 넘겨받은 영장 클라우드 데이터를 양손에 들고 거짓말 은폐 삭제 근거를 대조 타격하는 심판 단계이다.

</details>

```text
[범죄자 스마트폰 현장 압수 및 1초 컷 상태 엑스레이 심판]
               │
          [전원 ON/OFF · BFU/AFU 생얼 잠금 상태 식별 타격]
               │
        ┌──────┴──────┐
        │ [AFU 키 보존 락킹] │ [원격 폭파 변경 위험 타격]
        ▼             ▼
  보조배터리 전원 유지 꽂기    전파 차단 패러데이 가방 통신 격리
        └──────┬──────┘
               ▼
1. 1초 컷 격리•보존 무관용 타격 및 강력한 통제 추출 전략 꽂기 실행
               │
               ▼
2. 수술 사본 생성•해시 지문 봉인•도구 오류 누락 철저한 검증
               │
         [법원 영장 별도 권한 구글/애플 클라우드 증거 덤프 투하]
               ▼
3. 폰 기계 단말 증거 • 클라우드 은폐 증거 1:1 무관용 교차 검증 대조
               │
               ▼
        [최종 빼도 박도 못할 교차 검증 사형선고 결과 리포트]
```

### 동작 원리

1. 전파 격리·보존·추출 락킹 실행: 원격 폭파 전파 차단·AFU 키 방어 배터리 유지 및 해부 장비 투입 타격.
2. 덤프 사본·해시 지문·오류 철저한 검증: 무결점 캡처 동일성 확보·해부 도구 누락 빵꾸 무관용 색출 검증.
3. 폰 단말·클라우드 서버 교차 검증: 기계 지운 파일 vs 구름 위 자동 백업본 크로스 대조 은폐 폭파.

#### 한줄 요약

- 수사관이 현장에 진입해 폰을 잡는 순간, 폰이 켜져 있는지 꺼져 있는지부터 보고, 켜져 있으면 배터리부터 꽂고 와이파이 전파를 끊은 다음 조심스럽게 기계를 물려 데이터를 긁어내는 숨 막히는 폭발물 해체 작업이다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **겉핥기 논리 엑스레이 추출 (Logical Extraction)**: 애플/구글 운영체제가 "이건 합법적으로 가져가도 돼"라고 API나 백업 기능으로 열어준 문을 통해 연락처, 사진, 카톡 백업 파일 등 눈에 보이는 정상 외부 래퍼 데이터를 신속하게 긁어오는 타임어택 방식이다.
- **앱 뼈대 파일시스템 수술 추출 (File System Extraction)**: 논리보다 한 단계 깊게 들어가서, 앱이 데이터를 저장하는 은밀한 DB 구조와 루트 폴더 계층까지 수술해 긁어내어, 앱끼리 얽힌 관계와 겉으론 안 보이는 메타데이터를 해부하는 타격 방식이다.
- **영혼 탈곡 물리 클론 추출 (Physical Extraction)**: 운영체제의 허락 따위 무시하고 폰 메모리 칩의 0과 1 비트열 전체를 통째로 덤프 복제 클론(Clone)을 떠버리는 무관용 방식. 정상 파일은 물론이고, 범죄자가 지워버린 휴지통 삭제 흔적(비할당 영역) 찌꺼기까지 바닥까지 긁어 모조리 살려내는 궁극의 부활 방식이다.

</details>

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **미국 기술 타격 성지 NIST (National Institute of Standards and Technology)**: 전 세계 해커 사냥 및 경찰 수사 룰북을 찍어내는 미국의 최고 권력 기술 표준 연구기관이다.
- **수사관 바이블 특별 간행물 (Special Publication, SP)**: NIST 요원들이 실전 해부 사냥 지침을 무관용으로 락다운해 발간하는 엄격한 전문 룰북 문서 시리즈이다.
- **모바일 수술 바이블 NIST SP 800-101**: 수사관이 범죄자 스마트폰 증거를 어떻게 타겟 획득하고 엑스레이 덤프 분석해 판사 앞 보고서로 들이밀어야 하는지 강력히 가이드하는 모바일 특화 포렌식 지침 특징이다.
- **해부 도구 엑스레이 시험 CFTT (Computer Forensics Tool Testing)**: 경찰이 쓰는 수천만 원짜리 덤프 추출 도구가 버그로 증거를 날려먹지 않는지 기능과 정확성을 수술 전 사전에 무관용 검증해 법정 공격을 차단하는 NIST 심판 프로그램 특징이다.
- **글로벌 과학 심판 ISO (International Organization for Standardization)**: 전 세계 법원 증거 능력을 지배하는 국제표준화기구이다.
- **전자 핵심 경로 심판 IEC (International Electrotechnical Commission)**: 포렌식 장비 기계 표준을 지배하는 국제전기기술위원회 연합이다.
- **현장 급습 압수 룰북 ISO/IEC 27037**: 수사관 현장 진입 시 폰 증거를 어떻게 타겟 식별•비트 캡처 수집•무결 봉인 보존해야 증거 능력이 폭파 안 당하는지 정해놓은 글로벌 표준이다.

#### 한줄 요약

- 현장에서 화면이 켜져 있는 폰을 잡으면, 화면이 꺼져 암호키가 램에서 증발(BFU 진입)하지 못하게 터치를 유지하며 배터리를 꽂고, 외부 해커 동료가 원격 폭파 명령을 못 내리게 전파 차단 비닐에 집어넣어 전원과 통신 핵심 경로 상태를 동시에 통제 락킹 보존하는 초기 조치 타임어택 결단이 폰 수사의 알파이자 오메가이다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **생명줄 초기 상태 무결 보존 (Initial State Preservation)**: 현장에서 압수한 폰의 전파 격리, 배터리 전원 유지, 화면 잠금 해제 상태를 사진으로 찍어 기록하고, 증거 획득 전에 쓸데없는 형사의 클릭 조작으로 폰 내부 파일 로그가 바뀌는 걸 0%로 철벽 방어하는 원칙 특징이다.
- **강력한 통제 추출 방식 락킹 선택 (Extraction Method Selection)**: 영장 범위, 시간 촉박성, 휴지통 삭제 복원 필요성에 따라 겉핥기 논리 추출로 끝낼지, 뼈대 파일시스템을 털지, 아니면 영혼까지 복제하는 물리 클론 덤프 추출을 꽂을지 수사관이 판단해 락다운하는 절차이다.

</details>

- **생명줄 초기 상태 무결 보존** 락다운 후 수사관의 **강력한 통제 추출 방식 타격 선택** 대상 따라, 영장 범위 최소 변경은 논리 타임어택 추출, 앱 뼈대 구조는 파일시스템 수술 추출, 지워진 휴지통 비할당 찌꺼기 영역 복원은 물리 클론 영혼 추출을 무관용 적용 타격한다.

#### 한줄 요약

- 카톡 확인하겠다고 경찰이 무턱대고 현장 폰 화면을 스와이프하거나 앱을 누르는 순간, 내부 메모리 데이터 스냅샷이 변경 훼손되어 오염된 증거로 법정에서 기각 폭파당하므로, 폰 기계 초기 상태를 절대 함부로 만지지 않고 숨통만 유지한 채 랩실로 넘기는 게 증거 생명 연장의 핵심 필수.
