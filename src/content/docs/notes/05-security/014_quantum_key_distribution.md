## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **양자 키 분배(Quantum Key Distribution, QKD)**: 광자(Photon)의 양자 역학적 상태(편광, 위상)에 암호키 비트를 실어 전송함으로써, 양자 물리학 법칙에 의해 도청 시도를 100% 실시간 탐지하고 무조건적 안전성(Information-Theoretic Security)을 갖는 대칭키를 송수신자 간에 합의하는 하드웨어 기반 키 분배 기술.
- **양자 복제 불가 정리(No-Cloning Theorem)**: 양자 역학의 기본 원리로, 임의의 미지(Unknown)의 단일 양자 상태를 물리적으로 완벽하게 동일하게 복제하는 것은 수학적·물리학적으로 불가능하다는 정리.

</details>

- 정의/개념: 단일 광자 편광 기반의 **BB84 프로토콜**, 하이젠베르크 **불확정성 원리(Uncertainty Principle)** 및 **양자 복제 불가 정리** 에 기반하여 도청자의 관측 시 필연적으로 발생하는 양자 상태 붕괴를 검출하는 **물리 계층 보안 키 교환 기술**
- 배경/필요성: 수학적 계산 난제에 의존하는 기존 공개키 암호가 미래 양자컴퓨터의 쇼어 알고리즘에 의해 붕괴될 위험에 대응하여, 연산력에 구애받지 않는 이론적으로 완벽한 영구 보안 채널을 확립할 요구

#### 한줄 요약
- 양자 복제 불가 원리와 편광 측정을 통해 도청 시도를 물리적으로 탐지하고 절대 안전한 대칭키를 분배한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **양자 비트 오류율(Quantum Bit Error Rate, QBER)**: 수신자가 수신한 비트 중 전송 오류 및 도청 교란으로 인해 발생한 에러의 백분율 비율로, BB84 기준 도청 임계치(약 11%) 초과 시 키 생성을 즉시 중단하고 폐기.
- **투 트랙 채널 아키텍처(Two-Channel Architecture)**: 단일 광자를 전송하는 전용 광섬유 선로인 **양자 채널(Quantum Channel)** 과, 기저 대조 및 후처리 오류 정정을 위해 상호 인증(MAC)을 거치는 **고전 통신 채널(Classical Channel)** 의 병렬 운용 구조.

</details>

- **정보이론적 무조건적 안전성 (Information-Theoretic Security)**: 공격자의 컴퓨팅 연산 능력이나 미래 기술 발전에 영향을 받지 않는 절대적 기밀성 보장
- **도청자(Eve) 실시간 검출**: 도청자가 양자 채널을 가로채어 측정하는 순간 양자 상태가 붕괴되어 QBER이 25% 이상으로 폭증
- **4단계 후처리 파이프라인**: 기저 선별(Sifting) $\rightarrow$ 오류 추정(QBER) $\rightarrow$ 오류 정정(Error Correction) $\rightarrow$ 비밀성 증폭(Privacy Amplification)

#### 한줄 요약
- 양자 물리 기반 정보이론적 안전성, QBER 임계치 기반 도청 탐지, 4단계 후처리 파이프라인을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **비밀성 증폭(Privacy Amplification)**: 고전 채널을 통한 오류 정정 대화 과정에서 도청자에게 부분적으로 노출되었을 가능성이 있는 정보량만큼 유니버설 해시 함수(2-Universal Hash)를 적용하여 키를 압축함으로써, 도청자의 잔여 정보량을 $2^{-s}$ 이하로 소거하는 후처리 기법.

</details>

```text
[ 송신단: Alice (QKD Transmitter) ]                              [ 수신단: Bob (QKD Receiver) ]
 ├─ 단일 광자 레이저 광원 (Laser Diode)                           ├─ 광자 분기기 및 편광 필터 (PBS)
 ├─ 편광 제어기: 직선 기저(+) / 대각 기저(×)                      ├─ 단일 광자 눈사태 광다이오드 (SPAD 검출기)
 └─ 의사 난수 발생기 (True RNG)                                  └─ 검출 시각 동기화 타이머
           │                                                                   ▲
           ▼ (1. 양자 채널: 단일 광자 편광 펄스 전송) ─────────────────────────┘
┌──────────────────────────────────────────────────────────────────────────────────────────────────┐
│ [ 전용 양자 광섬유 선로 (Quantum Optical Fiber Channel: Single Photon) ]                        │
└──────────────────────────────────┬───────────────────────────────────────────────────────────────┘
                                   │
                                   ▼ (2. 인증된 고전 채널: 기저 대조 및 후처리 알고리즘)
┌──────────────────────────────────────────────────────────────────────────────────────────────────┐
│ [ 공용 IP 네트워크 (Authenticated Classical Channel: TCP/IP + HMAC 인증) ]                      │
│  ├─ 1. 기저 선별 (Sifting): 서로 동일한 편광 기저를 사용한 비트만 추출                          │
│  ├─ 2. 오류 정정 (Cascade / LDPC): 전송 노이즈 비트 오류 보정                                    │
│  └─ 3. 비밀성 증폭 (Toeplitz Hash): 잔여 도청 정보 완전 소거 ➔ 최종 비밀키 도출                  │
└──────────────────────────────────┬───────────────────────────────────────────────────────────────┘
                                   │
                                   ▼ (3. 암호키 주입)
                      [ 중앙 키 관리 시스템 (QKD-KMS: ITU-T Y.3800) ]
```

선의 의미: Alice가 보낸 광자 신호가 Bob에게 도달한 후, 인증된 고전 채널을 통해 기저 대조 및 후처리를 완료하여 최종 대칭키를 KMS에 저장하는 구조

| 구성요소 | 핵심 책임 및 역할 | 비고 |
|:---|:---|:---|
| **양자 송수신기 (QKD Unit)**| 단일 광자 생성, 편광 상태($0^\circ, 90^\circ, 45^\circ, 135^\circ$) 변조 및 SPAD 검출 | 광학 하드웨어 |
| **양자 채널 (Quantum Ch.)** | 단일 광자가 외부 간섭 없이 이동하는 저손실 다크 파이버(Dark Fiber) 광선로 | 전용 광케이블 |
| **인증된 고전 채널** | 기저 정보 교환, 패리티 검증을 수행하며 MITM 방지를 위해 사전 공유키 HMAC 적용 | RFC 5280 / TCP |
| **후처리 엔진 (Post-Proc)** | Cascade/LDPC 오류 정정 및 Toeplitz 행렬 기반 비밀성 증폭 수학 연산 수행 | FPGA / DSP |
| **QKD-KMS (ITU-T Y.3800)**| 생성된 고신뢰 대칭키를 보관하고 고속 IPsec/MACsec 암호 장비에 실시간 공급 | Key Manager |

#### 한줄 요약
- 양자 송수신기, 전용 양자 채널, 인증된 고전 채널, 후처리 엔진, QKD-KMS가 결합한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **BB84 4단계 편광 상태**:
  - 직선 기저($+$): $0^\circ$ (비트 0), $90^\circ$ (비트 1)
  - 대각 기저($\times$): $45^\circ$ (비트 0), $135^\circ$ (비트 1)

</details>

```text
1. Alice가 무작위 비트(0, 1)와 무작위 기저($+, \times$)를 선택하여 단일 광자 편광 신호 송출
            │
            ▼
2. Bob이 무작위 기저($+, \times$)를 선택하여 광자 측정 ➔ 원시 키(Raw Key) 생성
            │
            ▼
3. [기저 선별] Alice와 Bob이 고전 채널로 서로 사용한 '기저 목록'만 공개 대조 ➔ 불일치 비트 폐기 (Sifted Key)
            │
            ▼
4. [QBER 평가] 선별된 키의 일부 샘플을 대조하여 에러율(QBER) 계산
            │
            ├─ [QBER > 11% / 도청 감지] ➔ 생성 중인 키 전량 폐기 및 세션 리셋
            ▼
5. [QBER $\le$ 11% / 안전] ➔ 오류 정정(LDPC) 및 비밀성 증폭(해시 압축) ➔ 최종 대칭 마스터키 획득
```

**동작 원리**

1. **양자 상태 주입**: 송신자가 4가지 편광 상태 중 하나로 단일 광자를 인코딩하여 발사
2. **비트 측정**: 수신자가 임의의 측정 기저로 단일 광자 검출기(SPAD)를 통해 비트 기록
3. **기저 비교**: 비트 값 자체는 절대 공개하지 않고, 사용한 기저($+$ 또는 $\times$)의 일치 여부만 교환
4. **도청률 검증**: 일치한 비트열에서 샘플을 추출하여 QBER을 측정하고 도청 여부를 수학적으로 판정
5. **정보 소거 및 정제**: 통신 중 노출된 정보량만큼 Toeplitz 해시로 키를 축약하여 완전한 비밀키 완성

#### 한줄 요약
- 광자 편광 송출, 기저 측정, 기저 선별, QBER 도청 판정, 오류 정정 및 비밀성 증폭 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **주요 QKD 프로토콜 비교**: 표준 BB84, 광자 수 분할 공격을 방어하는 Decoy-State BB84, 검출기 공격을 원천 차단하는 MDI-QKD의 비교.

</details>

| 프로토콜 | 기본 BB84 | 미끼 상태 BB84 (Decoy-State) | 측정기 비의존 QKD (MDI-QKD) |
|:---|:---|:---|:---|
| **광원 기술** | 이상적 단일 광자 광원 | **약감쇠 레이저 + 강도 변조 (Decoy)** | 약감쇠 레이저 + 간섭 측정 |
| **PNS 공격 저항성** | **취약 (다중 광자 방출 시 도청 가능)**| **완벽 방어 (미끼 펄스로 도청 탐지)** | 완벽 방어 |
| **검출기 해킹 저항성**| 취약 (광자 블라인딩 공격 위험) | 취약 | **완벽 방어 (제3자 중계 노드 측정)** |
| **유효 전송 거리** | $\le 50\text{km}$ | **$100 \sim 200\text{km}$** | $\sim 400\text{km}$ |
| **상용화 성숙도** | 초기 연구 표준 | **현재 글로벌 상용 표준 (SKT, KT 구축)**| 차세대 연구 개발 단계 |

#### 한줄 요약
- 기본 BB84는 다중 광자 취약점이 있으나, Decoy-State는 PNS를 방어하며 현재 상용 표준이고, MDI-QKD는 검출기 공격을 차단한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **광자 수 분할 공격(Photon Number Splitting, PNS)**: 상용 약감쇠 레이저에서 단일 광자가 아닌 2개 이상의 광자(다중 광자 펄스)가 방출될 때, 도청자(Eve)가 1개의 광자를 가로채 저장하고 나머지 1개만 Bob에게 보내 도청 흔적(QBER)을 남기지 않고 전체 키를 가로채는 공격.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 다중 광자 방출 펄스를 악용한 공격자의 **PNS(광자 수 분할) 비검출 도청 공격** | **강도가 다른 신호 펄스와 미끼 펄스를 무작위 혼합 송출하는 Decoy-State BB84** 강제 | PNS 공격 시도 시 미끼 펄스 검출 통계 왜곡으로 도청 100% 탐지 |
| 후처리 대조를 위한 고전 채널 통신 시 공격자의 **중간자 데이터 변조 및 위장 공격(MITM)** | 고전 채널 전송 메시지에 대해 **사전 공유키 기반 정보이론적 MAC(Wegman-Carter)** 적용 | 고전 채널 메시지 위변조 차단 및 상호 인증 무결성 100% 보장 |
| 광섬유 케이블 내 신호 감쇠(0.2dB/km)로 인한 **전송 거리 한계(100km 초과 시 키 생성률 급락)** | **ITU-T Y.3800 표준 신뢰 중계 노드(Trusted Relay Node) 메싱 네트워크** 구축 | 수천 km 전국망 단위의 장거리 QKD 키 분배 인프라 완성 |

#### 한줄 요약
- Decoy-State로 PNS를 방어하고, Wegman-Carter MAC으로 고전 채널을 보호하며, 신뢰 중계 노드로 거리 한계를 극복한다.

## Ⅶ. 결론

- 물리 법칙에 기반하여 양자 컴퓨팅 시대에도 절대적 기밀성을 보장하는 **QKD(양자 키 분배) 아키텍처**는 국가 기간망, 금융망, 군사 통신망의 초고보안 인프라이며, 실무 구현 시 **Decoy-State 기반 PNS 방어**, **ITU-T Y.3800 기반 QKD-KMS 표준 인터페이스 연동**, **장거리 구간의 신뢰 중계 노드 보안 거버넌스**를 결합하여 완결성 높은 물리 계층 양자 보안 네트워크를 완성

#### 한줄 요약
- 양자 복제 불가 물리 법칙과 Decoy-State BB84 및 QKD-KMS 망을 결합하여 무조건적 보안의 키 분배를 실현한다.
