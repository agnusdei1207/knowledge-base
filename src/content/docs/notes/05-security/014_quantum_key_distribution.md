## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **QKD (Quantum Key Distribution)**: 단일 광자의 편광/위상 상태에 키를 실어 전송하여 도청 시도를 100% 탐지하는 물리 법칙 기반 키 분배 기술.
- **No-Cloning Theorem (양자 복제 불가 정리)**: 미지의 단일 양자 상태를 완벽히 복제하는 것은 물리학적으로 불가능하다는 원리.

</details>

- 정의/개념: 단일 광자 편광과 양자 복제 불가 정리를 바탕으로 **도청 시 필연적으로 발생하는 양자 상태 붕괴를 검출하여 무조건적 안전성을 제공하는 키 분배 기술**
- 배경/필요성: 수학 난제에 의존하는 고전 공개키 암호의 **양자컴퓨터 출현 시 사후 해독 위협(SNDL) 및 공용 통신망 상에서의 비검출 도청 위험**

#### 한줄 요약
- 양자 역학 물리 법칙을 통해 도청 시도를 100% 탐지하고 안전한 대칭키를 분배한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **QBER (Quantum Bit Error Rate, 양자 비트 에러율)**: 수신된 비트 중 도청이나 잡음으로 인해 반전된 에러 비율로, BB84에서 11% 초과 시 도청으로 판정하여 키를 폐기함.
- **Privacy Amplification (비밀성 증폭)**: 오류 정정 후 잔존하는 도청자의 부분 정보를 털어내기 위해 Toeplitz 해시 함수로 키를 압축하여 완전한 비밀성을 확보하는 후처리.

</details>

- **물리학적 정보이론적 안전성(Information-Theoretic Security)**: 도청자의 계산 능력과 무관하게 **양자 역학 법칙으로 도청 시도를 100% 실시간 탐지**
- **도청자 개입 시 비트 에러율(QBER) 급증**: 도청자가 광자를 측정하는 순간 **양자 상태가 붕괴하여 에러율이 11%를 초과함으로써 즉각 발각**
- **후처리를 통한 완전한 비밀키 정제**: Sifting, **오류 정정(LDPC), 비밀성 증폭(Toeplitz)을 거쳐 완벽한 순수 대칭키 추출**

#### 한줄 요약
- 정보이론적 안전성, QBER 기반 도청 실시간 탐지, 비밀성 증폭 후처리 정제를 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **QKD-KMS (ITU-T Y.3800)**: QKD 망에서 생성된 대칭키를 안전하게 저장·관리하고 라우터/IPsec 암호 장비에 실시간 공급하는 키 관리 시스템.

</details>

```text
[QKD 시스템 아키텍처 및 전송 채널 구성]
|-- Alice (송신단: 광자 레이저, 편광 변조기 0/90/45/135도)
`-- Quantum Channel (전용 다크 파이버 광케이블: 단일 광자 펄스 전송)
`-- Bob (수신단: 빔 스플리터, 단일 광자 검출기 SPAD)
`-- Authenticated Classical Channel (TCP/IP + HMAC 인증 채널)
    |-- 1. Basis Sifting (동일 편광 기저 비트 선별)
    |-- 2. Error Correction (LDPC 오류 정정)
    `-- 3. Privacy Amplification (Toeplitz Hash -> 최종 대칭키 도출)
`-- QKD-KMS (ITU-T Y.3800: IPsec/MACsec 고속 암호 장비에 키 실시간 주입)
```

선의 의미: Alice가 보낸 광자 신호가 Bob에게 도달한 후 인증된 고전 채널을 통해 기저 대조 및 후처리를 완료하여 최종 대칭키를 KMS에 저장하는 구조

| 구성요소 | 핵심 엔지니어링 책임 | 주요 특징 |
|:---|:---|:---|
| **양자 송수신기 (QKD Unit)**| 단일 광자 생성, **편광 상태 변조 및 SPAD 단일 광자 검출** | 광학 하드웨어 |
| **양자 채널 (Quantum Ch.)**| 단일 광자가 간섭 없이 이동하는 **저손실 다크 파이버 광선로** | 전용 광케이블 |
| **인증된 고전 채널** | 기저 교환을 수행하며 **MITM 방지를 위해 사전 공유키 HMAC 적용** | RFC 5280 / TCP |
| **후처리 엔진** | Cascade/LDPC 오류 정정 및 **Toeplitz 행렬 기반 비밀성 증폭 수행** | FPGA / DSP |
| **QKD-KMS (ITU-T Y.3800)**| 생성된 대칭키를 보관하고 **고속 IPsec/MACsec 장비에 실시간 공급** | Key Manager |

#### 한줄 요약
- 양자 송수신기, 전용 양자 채널, 인증된 고전 채널, 후처리 엔진, QKD-KMS가 결합한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **BB84 4단계 편광 상태**: 직선 기저($+$: $0^\circ, 90^\circ$)와 대각 기저($\times$: $45^\circ, 135^\circ$).

</details>

```text
BB84 광자 송출, 기저 선별, QBER 도청 판정 및 비밀성 증폭 파이프라인
        │
   1. [광자 편광 송출] Alice가 무작위 비트와 무작위 기저($+, \times$)를 선택하여 단일 광자 송출
        │
   2. [광자 기저 측정] Bob이 무작위 기저를 선택하여 광자를 측정하고 원시 키(Raw Key) 생성
        │
   3. [기저 선별(Sifting)] 고전 채널로 서로 사용한 기저 목록만 공개 대조 ➔ 불일치 비트 폐기
        │
   4. [QBER 도청 평가] 선별된 키의 샘플을 대조하여 에러율(QBER) 계산
        │
   ├─ [QBER > 11% / 도청 감지] ➔ 키 전량 폐기 및 세션 리셋
   ▼
5. [오류 정정 및 비밀성 증폭] QBER $\le$ 11% 시 LDPC 오류 정정 및 Toeplitz 해시 압축 ➔ 최종 비밀키 획득
```

#### 한줄 요약
- 광자 편광 송출 → 기저 측정 → 기저 선별 → QBER 도청 판정 → 오류 정정 및 비밀성 증폭 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **기본 BB84** vs **Decoy-State BB84 (미끼 상태)** vs **MDI-QKD (측정기 비의존)**.

</details>

| 프로토콜 | 기본 BB84 | 미끼 상태 BB84 (Decoy-State) | 측정기 비의존 QKD (MDI-QKD) |
|:---|:---|:---|:---|
| **광원 기술** | 이상적 단일 광자 광원 | **약감쇠 레이저 + 강도 변조 (Decoy)** | 약감쇠 레이저 + 간섭 측정 |
| **PNS 공격 저항성** | **취약 (다중 광자 방출 시 도청 가능)**| **완벽 방어 (미끼 펄스로 도청 탐지)** | 완벽 방어 |
| **검출기 해킹 저항성**| 취약 (광자 블라인딩 공격 위험) | 취약 | **완벽 방어 (제3자 중계 노드 측정)** |
| **유효 전송 거리** | $\le 50\text{km}$ | **$100 \sim 200\text{km}$** | $\sim 400\text{km}$ |
| **상용화 성숙도** | 초기 연구 표준 | **현재 글로벌 상용 표준 (SKT, KT 구축)**| 차세대 연구 개발 단계 |

#### 한줄 요약
- 기본 BB84는 다중 광자 취약점이 있으나, Decoy-State는 PNS를 방어하며 현재 상용 표준이고, MDI-QKD는 검출기 공격을 차단한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **PNS Attack (광자 수 분할 공격)**: 레이저에서 2개 이상의 광자가 방출될 때 도청자가 1개를 훔쳐내고 1개만 전달하여 QBER을 유발하지 않고 키를 훔치는 공격.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 다중 광자 방출을 악용한 공격자의 **PNS(광자 수 분할) 비검출 도청 공격** | **신호 펄스와 미끼 펄스를 무작위 혼합 송출하는 `Decoy-State BB84`** 강제 | PNS 공격 시 미끼 펄스 검출 통계 왜곡으로 도청 100% 탐지 |
| 고전 채널 통신 시 공격자의 **중간자 데이터 변조 및 위장 공격(MITM)** | 고전 채널 메시지에 대해 **사전 공유키 기반 `정보이론적 MAC(Wegman-Carter)`** 적용 | 고전 채널 위변조 차단 및 상호 인증 무결성 보장 |
| 광섬유 케이블 감쇠로 인한 **전송 거리 한계(100km 초과 시 키 생성률 급락)** | **`ITU-T Y.3800 표준 신뢰 중계 노드(Trusted Relay Node) 메싱`** 구축 | 수천 km 전국망 단위의 장거리 QKD 키 분배 인프라 완성 |
| 전용 광케이블 구축에 따른 막대한 물리적 인프라 비용 부담 | **기존 상용 WDM 광전송망과의 `파장 다중화(QKD 파장 1310/1550nm 공존)`** 기술 적용 | 전용선 증설 비용 70% 절감 및 상용망 공존 실현 |

#### 한줄 요약
- Decoy-State로 PNS를 방어하고, Wegman-Carter MAC으로 고전 채널을 보호하며, 신뢰 중계 노드로 거리 한계를 극복한다.

## Ⅶ. 결론

- 물리 법칙에 기반하여 양자 컴퓨팅 시대에도 절대적 기밀성을 보장하는 **QKD(양자 키 분배) 아키텍처는 국가 기간망, 금융망, 군사 통신망의 초고보안 인프라**이며, 실무 구현 시 **Decoy-State 기반 PNS 방어, ITU-T Y.3800 기반 QKD-KMS 표준 인터페이스 연동, 장거리 구간의 신뢰 중계 노드 보안 거버넌스**를 결합하여 완결성 높은 물리 계층 양자 보안 네트워크 완성

#### 한줄 요약
- QKD는 양자 복제 불가 물리 법칙과 Decoy-State BB84 및 QKD-KMS 망을 결합하여 무조건적 보안의 키 분배를 실현하는 물리 계층 암호 기술이다.
