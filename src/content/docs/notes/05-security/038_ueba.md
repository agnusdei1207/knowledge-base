## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **UEBA(User and Entity Behavior Analytics)**: 사용자(User: 임직원, 외주 인력, 관리자)뿐만 아니라 엔티티(Entity: 서버, 데이터베이스, IoT, 서비스 계정)의 평상시 정상 행동 패턴(Baseline)을 기계학습(머신러닝)으로 지속 학습한 후, 통계적 기준선을 벗어나는 비정상적인 편차와 이상 징후를 실시간 탐지하여 위험 점수(Risk Score)를 산출하는 지능형 보안 분석 기술.
- **엔티티 연결(Entity Stitching / Identity Resolution)**: 단일 사용자가 사용하는 사내 PC, 모바일 VPN, 클라우드 IAM 계정, DHCP 임시 IP 등 파편화된 다중 식별자를 단일 주체(Entity)로 자동 결합·통합하는 데이터 맵핑 기법.

</details>

- 정의/개념: 정적 임계값 룰(Static Rule) 기반 탐지의 한계를 극복하고, **비지도 학습(Unsupervised Learning)** 기반 **정상 기준선(Baseline) 수립 $\rightarrow$ 동료군(Peer Group) 비교 $\rightarrow$ 다차원 문맥 위험도 점수화(Contextual Risk Scoring)** 를 통해 계정 탈취 및 내부자 위협(Insider Threat)을 식별하는 **행동 중심 보안 분석 아키텍처**
- 배경/필요성: 공격자가 합법적인 직원 자격증명(Credential)을 탈취하여 정상 포트와 도구로 침투할 경우, 시그니처나 고정 룰 기반 SIEM으로는 악의적 데이터 유출 행위를 탐지할 수 없는 사각지대를 해소할 요구

#### 한줄 요약
- 사용자 및 기기의 정상 행동 기준선(Baseline)과 동료군 패턴을 머신러닝으로 학습하여 정상 계정 도용 및 내부자 위협을 탐지한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **동료군 분석(Peer Group Analysis)**: 개인의 과거 이력뿐만 아니라, 동일 부서·직무·역할을 수행하는 동료 집단의 평균 행동 패턴을 클러스터링하여, 조직 단위의 합법적 업무 변화(예: 분기 결산으로 인한 전 부서 야근)와 개별 계정의 단독 이상 징후를 정확히 변별하는 기법.
- **설명 가능한 보안 AI(Explainable Security AI / XAI)**: UEBA가 위험 점수(예: 95점)를 부여했을 때, 블랙박스 결과를 지양하고 "평소 접근하지 않던 재무 DB 접속(+40점), 심야 비인가 시간대 대용량 다운로드(+35점), 해외 미인가 IP 접속(+20점)"과 같이 점수 산출 근거를 투명하게 제시하는 기능.

</details>

- **UBA에서 엔티티(Entity)로의 확장**: 사람 사용자뿐만 아니라 서버, 라우터, 마이크로서비스, 서비스 계정(API Key)의 행동 모델링
- **다차원 통계 기준선 수립**: 비지도학습(PCA, Isolation Forest, 오토인코더)을 통해 사전 정의된 시그니처 없이 미지의 이상 행위 자동 감지
- **문맥 인식 기반 위험 점수화**: 단순 이상치(Outlier)가 아닌 자산 중요도, 권한 수준, 시계열 위협 맥락을 융합하여 종합 점수 산출

#### 한줄 요약
- 엔티티 범위 확장, 머신러닝 동적 기준선 학습, 동료군 비교 분석, 설명 가능한 위험 점수 산출을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **기준선 오염(Baseline Poisoning)**: 머신러닝 모델의 초기 학습 기간(예: 30일) 동안 공격자가 이미 침투하여 저속으로 데이터를 유출하고 있을 경우, 시스템이 악의적 행위를 정상 행동 기준선(Baseline)으로 오인 학습하는 취약점.

</details>

```text
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 전사 텔레메트리 수집 계층 (Telemetry Ingestion) ]                     │
│  ├─ 인증 로그: Active Directory Kerberos, Okta, VPN 로그인             │
│  ├─ 파일/데이터: DLP 파일 접근, 윈도우 파일 감사, DB 질의 로그          │
│  └─ 엔드포인트/네트워크: EDR 프로세스 실행, NetFlow, DNS 질의 로그       │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 1. 엔티티 연결 및 정규화 (Entity Stitching Engine) ]                  │
│  └─ [ IP + 사번 + Hostname + Kerberos Ticket ➔ 단일 사용자/기기 식별 ]   │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 2. 머신러닝 프로파일링 & 기준선 엔진 (ML Profiling Layer) ]           │
│  ├─ 개인 행동 기준선 (Individual Baseline): 과거 30~90일 행동 프로파일  │
│  └─ 동료군 클러스터링 (Peer Group Clustering): K-Means 부서별 행동 모델 │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 3. 문맥 위험 점수 산출 엔진 (Risk Scoring & XAI Engine) ]             │
│  ├─ 통계적 이상 편차 계산 (Mahalanobis Distance / Isolation Forest)    │
│  ├─ 자산 중요도 가중치 결합 (Crown Jewels 접근 시 가산점)              │
│  └─ [ 설명 가능한 인공지능 (XAI): 점수 기여 요인 상세 내역 생성 ]        │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │ (위험 점수 $\ge 85$ 초과 시)
                                     ▼
[ SOC 관제 센터 / SIEM / SOAR 자동 격리 트리거 (Human-in-the-loop) ]
```

선의 의미: 이종 로그가 엔티티 연결을 거쳐 개인/동료군 머신러닝 기준선과 대조되고, XAI를 통해 위험 점수 근거와 함께 관제 센터로 전달되는 구조

| 구성요소 | 핵심 책임 및 역할 | 비고 |
|:---|:---|:---|
| **엔티티 연결기 (Stitcher)** | 다중 IP, MAC, 계정명, SSO 토큰을 단일 사용자 및 자산 엔티티로 통합 맵핑 | Identity Stitching |
| **기준선 프로파일러** | 시계열 통계 및 비지도 머신러닝으로 정상 접속 시간, 데이터 전송량 모델링 | Baseline Engine |
| **동료군 분석기** | 부서, 직무, 역할 기반 군집화(Clustering)를 통해 집단 표준 행동 도출 | Peer Clustering |
| **위험 점수 산출기** | 다차원 행동 이탈 편차와 자산 중요도를 결합하여 0~100점의 정량적 위험도 산출 | Risk Scoring |
| **XAI 설명 생성기** | 위험 점수를 유발한 상위 이상 행위 요인(Feature Contribution)을 시각화 | Explainable AI |

#### 한줄 요약
- 엔티티 연결기, 기준선 프로파일러, 동료군 분석기, 위험 점수 산출기, XAI 설명 생성기가 결합한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **마할라노비스 거리(Mahalanobis Distance)**: 다변량 데이터에서 변수 간의 상관관계를 고려하여, 특정 관측값이 평균 중심점(정상 기준선)으로부터 통계적으로 얼마나 멀리 떨어져 있는지를 측정하는 다차원 이상치 탐지 척도.

</details>

```text
1. [엔티티 결합] 다양한 소스(VPN, AD, EDR)의 로그를 파싱하여 사용자 계정과 기기 식별자를 단일 주체로 바인딩
            │
            ▼
2. [기준선 대조] 사용자의 실시간 작업(예: 심야 03시 DB 대량 조회)을 과거 개인 기준선 및 동료군 모델과 대조
            │
            ▼
3. [이상 편차 산출] 접근 시간, 조회 레코드 건수, 평소 미접속 자산 여부의 마할라노비스 거리 및 확률 편차 계산
            │
            ▼
4. [문맥 위험도 합성] [행동 편차 가중치 + 대상 DB의 자산 중요도]를 합성하여 위험 점수(Risk Score: 92점) 확정
            │
            ▼
5. [XAI 근거 제시 및 대응] 관제사에게 점수 산출 세부 원인(XAI)을 제공하고 SOAR를 통해 계정 2차 인증(MFA) 강제
```

**동작 원리**

1. **식별자 융합**: IP 변동에 구애받지 않고 계정 중심의 전사 활동 로그 통합
2. **동적 임계값 적용**: 고정된 숫자 룰 대신 통계적 분포(Gaussian Mixture Model) 기반 확률 판정
3. **거짓 양성 억제**: 개인이 튀더라도 동료 전체가 동일 행위를 수행 중이면 위험 점수 차감
4. **위험 누적 모델링**: 단일 이벤트가 아닌 수일간 지속되는 저속 데이터 유출(Low & Slow) 점수 누적
5. **투명한 의사결정**: 블랙박스 문제를 해소하여 관제사가 즉각적인 소명 요구 및 격리 집행

#### 한줄 요약
- 엔티티 결합, 개인/동료군 기준선 대조, 이상 편차 산출, 문맥 위험도 합성, XAI 근거 제시 및 대응 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **이상 탐지 방식 비교**: 정적 임계값 룰(Static Rule), 사용자 행동 분석(UBA), 사용자 및 엔티티 행동 분석(UEBA)의 비교.

</details>

| 비교 항목 | 고정 임계값 규칙 (Static Rule) | 사용자 행동 분석 (UBA) | 사용자 및 엔티티 행동 분석 (UEBA) |
|:---|:---|:---|:---|
| **분석 대상** | **단일 이벤트 필드 (단일 IP/Port/ID)** | **오직 사람 사용자 (User Accounts)** | **사용자 + 호스트, DB, IoT, 서비스 계정**|
| **탐지 메커니즘** | **사전 정의된 if-then 조건문 (정적)** | **머신러닝 기반 사용자 행동 모델링** | **다변량 비지도학습 + 동료군 + XAI 결합**|
| **우회 저항성** | **매우 취약 (임계치 미만 분할 공격 허용)**| 중간 (정상 권한 도용 시 식별 가능) | **매우 높음 (계정 및 기기 간 다차원 상관 추적)**|
| **오탐 관리 오버헤드**| **매우 큼 (환경 변화 시 수동 룰 수정)** | 중간 (기준선 적응 필요) | **낮음 (동료군 비교로 비즈니스 변동 자동 흡수)**|
| **주요 탐지 위협** | **알려진 무차별 대입(Brute-force) 공격** | **퇴사자 데이터 유출, 권한 오남용** | **APT 계정 탈취(Lateral Movement), C2 비인가 접근**|

#### 한줄 요약
- 고정 룰은 정적 조건 매칭, UBA는 사용자 중심 모델링, UEBA는 사용자/기기 통합 머신러닝 이상 탐지이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **피처 엔지니어링(Feature Engineering)과 데이터 전처리**: 원시 로그에서 의미 있는 행동 특징(예: '최근 7일간 최초 접근한 IP 여부', '평소 대비 다운로드 바이트 비율')을 도출하여 머신러닝 모델의 탐지 정확도를 극대화하는 엔지니어링 과정.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 초기 머신러닝 학습 기간에 잠입한 해커의 악성 행위가 **정상 기준선(Baseline Poisoning)으로 오인 학습되는 오류** | **학습 데이터셋 선정 시 침해사고 포렌식 정제 완료 데이터 적용 및 골든 기준선(Golden Baseline) 검증** | 모형 오염 방지 및 정상 데이터로 위장한 장기 잠복 공격 100% 탐지 |
| 머신러닝 블랙박스 현상으로 인해 **위험 점수 산출 이유를 알 수 없어 관제 분석가의 대응 지연** | **SHAP/LIME 알고리즘 기반 설명 가능한 인공지능(XAI) 피처 기여도 시각화 제공** | 인시던트 원인 분석 시간 80% 단축 및 오탐 판별 신속성 확보 |
| 조직 개편 및 대규모 프로젝트로 인한 비즈니스 환경 변화 시 **전사적 대규모 오탐 경보 폭증 장애** | **부서·직무 단위의 동적 동료군(Peer Group) 클러스터링 및 관리자 피드백 기반 지속 재학습** | 정상 업무 변경에 대한 능동적 적응 및 거짓 양성(False Positive) 최소화 |

#### 한줄 요약
- 골든 기준선으로 오염을 막고, XAI로 점수 근거를 제공하며, 동료군 분석으로 환경 변화 오탐을 방지한다.

## Ⅶ. 결론

- 정상 자격증명을 도용하여 은닉 침투하는 현대 APT 및 내부자 위협을 방어하는 **UEBA 아키텍처**는 행위 기반 제로 트러스트 보안의 핵심 분석 엔진이며, 실무 구현 시 **엔티티 연결을 통한 전사 텔레메트리 통합**, **비지도학습 기반 개인 및 동료군 동적 기준선 확립**, **설명 가능한 AI(XAI) 기반의 투명한 위험도 산출**, **SOAR 연동을 통한 적응형 접근 통제**를 통합 구축하여 무결점 지능형 계정 보안 환경을 완성

#### 한줄 요약
- 엔티티 통합과 머신러닝 동적 기준선 및 XAI를 결합하여 정상 계정 도용과 내부자 위협을 완벽히 식별한다.
