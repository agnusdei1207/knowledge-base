## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **데이터 보안 형상 관리(Data Security Posture Management, DSPM)**: 저장 데이터의 민감도•위치•접근•복제•노출을 지속 분석하는 체계이다.
- **그림자 데이터**: 보안•거버넌스 관리 밖에서 생성•복제•보관되는 데이터이다.

</details>

- 정의/개념: **DSPM**은 저장 데이터의 민감도•위치•접근•복제•노출을 지속 분석한다.
- 배경/필요성: **그림자 데이터**는 과잉 접근과 통제되지 않은 복제 확산을 만든다.

#### 한줄 요약

- DSPM은 금고 설정만 보지 않고 어느 금고에 어떤 민감정보가 있고 누가 실제 열 수 있는지까지 연결해 본다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **데이터 분류**: 내용과 업무 가치에 따라 데이터의 보호 등급을 정하는 활동이다.
- **데이터 계보**: 데이터가 생성•변환•복제•이동한 경로를 연결한 정보이다.
- **서비스형 소프트웨어(Software as a Service, SaaS)**: 공급자가 운영하는 완성 애플리케이션을 인터넷으로 제공하는 모델이다.
- **유효 접근**: 직접 권한뿐 아니라 상속•그룹•공개 설정을 모두 합친 실제 접근 가능 범위이다.

</details>

- 정형•비정형•**SaaS** 저장소에서 데이터를 자동 발견한다.
- **데이터 분류**와 **데이터 계보**로 내용•업무 문맥•복제 경로를 연결한다.
- **유효 접근**•노출•보호 상태를 결합해 우선순위를 정한다.

#### 한줄 요약

- 같은 공개 설정이라도 빈 테스트 파일보다 고객정보 복제본이 든 저장소를 먼저 고치도록 위험의 실제 크기를 따진다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **발견 엔진**: 정형•비정형•SaaS 저장소에서 데이터 위치를 자동 식별하는 기능이다.
- **분류 엔진**: 데이터 내용과 업무 문맥을 분석해 민감도를 판정하는 기능이다.
- **데이터 소유자**: 데이터의 등급•접근•보존•삭제 조치를 승인하는 책임자이다.
- **마스킹**: 민감한 일부 값을 알아볼 수 없게 가리는 보호 처리이다.

</details>

```text
                         [저장소 연동]
                        /          \
               [발견•분류 엔진]  [접근•계보 분석]
                        \          /
                         [위험 우선순위]
                                |
                       [조치•소유자 연계]
```

선의 의미: 저장소 연동을 기반으로 데이터 발견•분류와 접근•계보 분석을 결합하고, 위험 우선순위 및 조치•소유자 책임을 연결한 정적 DSPM 구조를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 저장소 연동 | 저장소•소유자•복제본 연결 |
| 발견•분류 엔진 | **발견 엔진**•**분류 엔진**이 위치•민감도 식별 |
| 접근•계보 분석 | 유효 권한과 이동 경로 계산 |
| 위험 우선순위 | 노출•민감도•보호 상태 결합 |
| 조치•소유자 연계 | **데이터 소유자**가 권한•**마스킹**•삭제 승인 |

#### 한줄 요약

- 저장소를 읽어 민감한 데이터를 찾고 실제 접근자와 복제 경로를 계산해 가장 위험한 위치부터 고친다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **비침투형 발견**: 운영 데이터를 변경하지 않고 메타데이터나 최소 읽기 권한으로 저장 내용을 조사하는 방식이다.
- **잔여 노출**: 권한 축소•마스킹•삭제 같은 보호 조치 뒤에도 남아 있는 공개 또는 과잉 접근 위험이다.
- **데이터 발견•민감도 분류**: 비침투 방식으로 저장 위치와 내용의 보호 등급을 식별하는 단계이다.
- **유효 접근•데이터 계보 계산**: 상속 권한과 데이터 복제•이동 경로를 연결하는 단계이다.
- **데이터 위험 우선순위화**: 민감도•노출•보호 상태를 결합해 조치 순서를 정하는 단계이다.
- **보호 조치•소유 책임 확정**: 권한 축소•마스킹•삭제 방법과 승인 담당자를 결정하는 단계이다.
- **보호 조치 적용**: 승인된 통제를 실행하고 재스캔할 증적을 생성하는 단계이다.

</details>

```text
[데이터 저장소]
      |
      `-- 내용•권한•암호화 정보
                  |
                  v
[DSPM]
      |
      v
1. 데이터 발견•민감도 분류
      |
      v
2. 유효 접근•데이터 계보 계산
      |
      v
3. 데이터 위험 우선순위화
      |
      `-- 데이터 위험 근거
                  |
                  v
[데이터 소유자]
      |
      v
4. 보호 조치•소유 책임 확정
      |
      `-- 권한•마스킹•삭제 지시
                  |
                  v
[조치 시스템]
      |
      v
5. 보호 조치 적용
      |
      `-- 조치 적용 결과
                  |
                  v
[DSPM 잔여 노출 검증]
```

### 동작 원리

1. **데이터 발견•민감도 분류**: 비침투 방식으로 데이터를 발견하고 민감도를 분류한다.
2. **유효 접근•데이터 계보 계산**: 상속 권한과 복제•이동 경로로 유효 접근•데이터 계보를 계산한다.
3. **데이터 위험 우선순위화**: 민감도•노출•보호 상태로 데이터 위험을 우선순위화한다.
4. **보호 조치•소유 책임 확정**: 권한•마스킹•삭제 방법과 소유 책임을 확정한다.
5. **보호 조치 적용**: 승인 통제를 적용하고 **잔여 노출**을 재스캔한다.
#### 한줄 요약

- **비침투형 발견**으로 먼저 조사한 뒤 승인된 보호 조치가 실제 반영됐는지 확인한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **클라우드 보안 형상 관리(Cloud Security Posture Management, CSPM)**: 클라우드 자원의 설정과 노출 상태를 점검하는 체계이다.
- **데이터 유출 방지(Data Loss Prevention, DLP)**: 민감정보의 사용•이동•반출을 식별하고 통제하는 기술이다.

</details>

| 데이터 보안 유형 | DSPM | CSPM | DLP |
|:---|:---|:---|:---|
| 적용 기준 | 민감 데이터의 위치•노출 파악 | 안전한 클라우드 구성 | 실시간 반출 탐지•차단 |
| 핵심 특징 | **DSPM**의 저장 데이터•접근 분석 | **CSPM**의 클라우드 설정 평가 | **DLP**의 사용•이동 통제 |
| 한계 | 분류 오탐•스캔 공백 | 데이터 내용 미파악 | 미등록 저장 데이터 누락 |

#### 한줄 요약

- CSPM은 금고 설정, DLP는 문서 이동, DSPM은 금고 안의 내용과 실제 열쇠 소유자를 중심으로 본다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **ISO/IEC 27002 통제 5.12**: 정보의 가치와 보호 요구에 따른 분류를 요구하는 국제 표준 통제이다.
- **NIST SP 800-122**: 개인식별정보의 기밀성 영향과 보호 조치 선정을 안내하는 미국 국립표준기술연구소 지침이다.
- **개인 식별 정보(Personally Identifiable Information, PII)**: 개인을 직접 또는 간접으로 식별할 수 있는 정보이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 정보 분류 기준 불일치 | **ISO/IEC 27002 통제 5.12** 적용 | 민감도•보호 등급 일관화 |
| 개인식별정보 보호 누락 | **NIST SP 800-122** 연계 | **PII** 영향 기반 보호 조치 선정 |
| 스캔 공백•과잉 권한 | 자산 대조•최소 읽기•재스캔 | 그림자 데이터와 잔여 노출 축소 |

#### 한줄 요약

- DSPM은 관리 목록 밖의 클라우드 저장소에서 고객정보 복제본과 공개 권한을 함께 찾아 소유자를 확인하고 접근 차단•폐기를 수행한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **데이터 위험 감소 성과**: 발견 건수가 아니라 미관리 민감 데이터와 불필요한 접근•복제 경로를 실제로 제거한 정도이다.
</details>

- **데이터 위험 감소 성과**를 측정하며 저장 데이터•실제 접근은 **DSPM**, 자원 설정은 **CSPM**, 실시간 반출은 **DLP**를 적용한다.

#### 한줄 요약

- DSPM의 성과는 발견 건수보다 미관리 민감 데이터와 불필요한 접근•복제 경로를 실제로 얼마나 없앴는지로 판단한다.
