## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **데이터 보안 형상 관리(Data Security Posture Management, DSPM)**: 저장 데이터의 민감도•위치•접근•복제•노출을 지속 분석하는 체계이다.
- **그림자 데이터**: 보안•거버넌스 관리 밖에서 생성•복제•보관되는 데이터이다.

</details>

- 정의/개념: 저장 데이터의 민감도•접근•복제를 분석하는 **DSPM 관리 체계**이다.
- 배경/필요성: 미관리 그림자 데이터로 **과잉 접근•복제 확산**이 발생한다.

#### 한줄 요약

- DSPM은 금고 설정만 보지 않고 어느 금고에 어떤 민감정보가 있고 누가 실제 열 수 있는지까지 연결해 본다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **데이터 분류**는 내용과 업무 가치에 따라 데이터의 보호 등급을 정하는 활동이다.
- **데이터 계보**는 데이터가 생성•변환•복제•이동한 경로를 연결한 정보다.
- **서비스형 소프트웨어(Software as a Service, SaaS)**: 공급자가 운영하는 완성 애플리케이션을 인터넷으로 제공하는 모델이다.
- **유효 접근**: 직접 권한뿐 아니라 상속•그룹•공개 설정을 모두 합친 실제 접근 가능 범위이다.

</details>

- **자동 데이터 발견**: 정형•비정형•SaaS 저장소 식별이다.
- **민감도•계보 분류**: 내용•업무 문맥과 복제 경로를 연결한다.
- **위험 우선순위화**: 유효 접근•노출•보호 상태 결합한다.

#### 한줄 요약

- 같은 공개 설정이라도 빈 테스트 파일보다 고객정보 복제본이 든 저장소를 먼저 고치도록 위험의 실제 크기를 따진다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **발견 엔진**은 정형•비정형•SaaS 저장소에서 데이터 위치를 자동 식별한다.
- **분류 엔진**은 데이터 내용과 업무 문맥을 분석해 민감도를 판정한다.
- **데이터 소유자**는 데이터의 등급•접근•보존•삭제 조치를 승인하는 책임자다.
- **마스킹**은 민감한 일부 값을 알아볼 수 없게 가리는 보호 처리다.

</details>

```text
                         [저장소 연동]
                        /          \
               [발견•분류 엔진]  [접근•계보 분석]
                        \          /
                         [위험 우선순위]
                                |
                       [조치•소유자 연계]
```

선의 의미: 저장소 연동을 기반으로 데이터 발견•분류와 접근•계보 분석을 결합하고, 위험 우선순위 및 조치•소유자 책임을 연결한 정적 DSPM 구조를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| **저장소 연동** | 저장소•소유자•**복제본 연결** |
| **발견•분류 엔진** | 데이터 위치와 **민감도 식별** |
| **접근•계보 분석** | 유효 권한과 **이동 경로 계산** |
| **위험 우선순위** | 노출•민감도•**보호 상태 결합** |
| **조치•소유자 연계** | 권한•마스킹•**삭제•증적 관리** |

#### 한줄 요약

- 저장소를 읽어 민감한 데이터를 찾고 실제 접근자와 복제 경로를 계산해 가장 위험한 위치부터 고친다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **비침투형 발견**: 운영 데이터를 변경하지 않고 메타데이터나 최소 읽기 권한으로 저장 내용을 조사하는 방식이다.
- **잔여 노출**: 권한 축소•마스킹•삭제 같은 보호 조치 뒤에도 남아 있는 공개 또는 과잉 접근 위험이다.

</details>

```text
[데이터 저장소]
      |
      `-- 내용•권한•암호화 정보
                  |
                  v
[DSPM]
      |
      v
1. 데이터 발견•민감도 분류
      |
      v
2. 유효 접근•데이터 계보 계산
      |
      v
3. 데이터 위험 우선순위화
      |
      `-- 데이터 위험 근거
                  |
                  v
[데이터 소유자]
      |
      v
4. 보호 조치•소유 책임 확정
      |
      `-- 권한•마스킹•삭제 지시
                  |
                  v
[조치 시스템]
      |
      v
5. 보호 조치 적용
      |
      `-- 조치 적용 결과
                  |
                  v
[DSPM 잔여 노출 검증]
```

**동작 원리**

- **1. 데이터 발견•민감도 분류**: 비침투 방식으로 위치•내용 식별이다.
- **2. 유효 접근•데이터 계보 계산**: 상속 권한과 복제•이동 경로를 연결한다.
- **3. 데이터 위험 우선순위화**: 민감도•노출•보호 상태 결합한다.
- **4. 보호 조치•소유 책임 확정**: 권한•마스킹•삭제와 담당자를 결정한다.
- **5. 보호 조치 적용**: 승인 통제 실행 후 재스캔 증적을 생성한다.
#### 한줄 요약

- DSPM이 데이터를 바꾸지 않고 먼저 조사한 뒤 소유자에게 위험 근거를 보여 주고 승인된 보호 조치가 실제 반영됐는지 다시 확인한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **클라우드 보안 형상 관리(Cloud Security Posture Management, CSPM)**: 클라우드 자원의 설정과 노출 상태를 점검하는 체계이다.
- **데이터 유출 방지(Data Loss Prevention, DLP)**: 민감정보의 사용•이동•반출을 식별하고 통제하는 기술이다.

</details>

| 데이터 보안 유형 | DSPM | CSPM | DLP |
|:---|:---|:---|:---|
| 적용 기준 | 민감 데이터의 **위치•노출 파악** | 안전한 **클라우드 구성** | 실시간 **반출 탐지•차단** |
| 핵심 특징 | **저장 데이터•접근 분석** | **클라우드 자원 설정 평가** | 데이터의 **사용•이동 통제** |
| 한계 | **분류 오탐•스캔 공백** | **데이터 내용 미파악** | **미등록 저장 데이터 누락** |

#### 한줄 요약

- CSPM은 금고 설정, DLP는 문서 이동, DSPM은 금고 안의 내용과 실제 열쇠 소유자를 중심으로 본다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **ISO(International Organization for Standardization)**는 국제 표준을 개발•발행하는 기구다.
- **IEC(International Electrotechnical Commission)**는 전기•전자 분야 국제 표준을 개발하는 기구다.
- **ISO/IEC 27002 통제 5.12**는 정보의 가치와 보호 요구에 따른 분류를 요구한다.
- **NIST(National Institute of Standards and Technology)**는 미국의 기술 표준과 지침을 개발하는 기관이다.
- **SP(Special Publication) 800-122**는 개인식별정보의 기밀성 영향과 보호 조치 선정을 안내한다.
- **개인 식별 정보(Personally Identifiable Information, PII)**: 개인을 직접 또는 간접으로 식별할 수 있는 정보이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **정보 분류 기준 불일치** | **ISO/IEC 27002 통제 5.12 적용** | 민감도•보호 등급의 **일관화** |
| **개인식별정보 보호 누락** | **NIST SP 800-122 연계** | 영향 기반의 **보호 조치 선정** |
| **스캔 공백•과잉 권한** | **자산 대조•최소 읽기•재스캔** | 그림자 데이터와 **잔여 노출 축소** |

#### 한줄 요약

- DSPM은 관리 목록 밖의 클라우드 저장소에서 고객정보 복제본과 공개 권한을 함께 찾아 소유자를 확인하고 접근 차단•폐기를 수행한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **데이터 위험 감소 성과**: 발견 건수가 아니라 미관리 민감 데이터와 불필요한 접근•복제 경로를 실제로 제거한 정도이다.
</details>

- 저장 데이터•실제 접근은 **DSPM**, 자원 설정은 **CSPM**, 실시간 반출은 **DLP**을 적용한다.

#### 한줄 요약

- DSPM의 성과는 발견 건수보다 미관리 민감 데이터와 불필요한 접근•복제 경로를 실제로 얼마나 없앴는지로 판단한다.
