## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **PUF(Physically Unclonable Function)**: 제조 편차로 장치마다 고유한 응답을 만드는 하드웨어 함수이다.

</details>

- 정의/개념: 제조 편차를 이용해 장치별 응답을 만드는 **PUF**이다.
- 배경/필요성: 비휘발성 메모리에 저장한 키는 물리 분석으로 추출될 가능성이 있다.

#### 한줄 요약

- 같은 설계의 칩도 미세하게 달라 그 차이를 장치마다 다른 전자 지문처럼 활용하는 것이 핵심이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **고유성**: 서로 다른 장치의 응답이 달라야 하는 속성이다.
- **재현성**: 같은 장치의 응답을 환경 변화에도 다시 얻는 속성이다.
- **퍼지 추출기**: 잡음이 섞인 응답에서 동일 키를 재생성하고 오류를 보정하는 장치이다.

</details>

- 제조 편차 기반 **고유성**이 핵심이다.
- 온도•전압•노화에도 **재현성**을 유지해야 한다.
- **퍼지 추출기**로 오류를 보정하고 키를 파생한다.

#### 한줄 요약

- 전자 지문은 매번 조금 흔들리므로 보정하되 헬퍼 데이터가 공격 단서가 되지 않아야 한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **CRP(Challenge-Response Pair)**: PUF의 입력 도전값과 대응 출력값의 쌍이다.
- **헬퍼 데이터**: 응답을 같은 키로 보정하도록 저장하는 비밀이 아닌 보조 정보이다.

</details>

```text
PUF 키 파생 구조
├─ 도전값•측정 조건
├─ PUF 물리 구조
├─ 잡음 포함 원시 응답
├─ 퍼지 추출기•헬퍼 데이터
└─ 복원 키•인증 기능
```

| 구성요소 | 책임 |
|:---|:---|
| 도전값•측정 조건 | **CRP**의 물리 경로•온도•전압 설정 |
| PUF 물리 구조 | 제조 편차를 비트열로 변환 |
| 잡음 포함 원시 응답 | 편차•환경 영향 측정 |
| 퍼지 추출기•헬퍼 데이터 | **헬퍼 데이터**로 안정 키 파생 |
| 복원 키•인증 기능 | 사용 후 원시값•키 제거 |

#### 한줄 요약

- 흔들리는 측정값을 그대로 키로 쓰지 않고 오류 보정과 추출을 거쳐 안정된 비밀로 만듦이 핵심이다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **등록**: 제조 시 기준 응답과 헬퍼 데이터를 생성하는 절차이다.
- **재생성**: 현장의 잡음 응답을 보정해 같은 키를 만드는 절차이다.
- **환경별 원시 응답 생성**: 온도•전압•노화 조건별 응답 비트열을 측정하는 단계이다.
- **고유성•재현성•오류율 평가**: 등록에 사용할 기준 응답의 품질을 판정하는 단계이다.
- **현장 원시 응답 생성**: 실제 운용 환경에서 응답 비트열을 다시 측정하는 단계이다.
- **오류 보정•키 추출**: 헬퍼 데이터로 잡음을 보정해 동일 키를 만드는 단계이다.
- **키 사용•메모리 삭제**: 파생 키의 연산이 끝난 뒤 일시 비밀을 제거하는 단계이다.

</details>

```text
등록 단계
   1. 환경별 원시 응답 생성
   2. 고유성·재현성·오류율 평가
   │ 기준 응답•헬퍼 데이터
   ▼
재생성 단계
   3. 현장 원시 응답 생성
   4. 오류 보정·키 추출
   │ 동일 키
   ▼
사용 단계
   5. 키 사용·메모리 삭제
```

### 동작 원리

1. 환경별 원시 응답 생성: 등록용 비트열 측정
2. 고유성·재현성·오류율 평가: 기준 응답 선정
3. 현장 원시 응답 생성: 재생성 비트열 측정
4. 오류 보정·키 추출: 헬퍼 데이터로 키 복원
5. 키 사용·메모리 삭제: 연산 후 일시 비밀 제거

#### 한줄 요약

- 제조 단계에서 CRP를 등록하고 운용 시에는 노이즈가 포함된 응답을 퍼지 추출기로 보정해 동일 키를 일시 복원하여 사용하는 것이 핵심이다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **약한 PUF**: 소수 CRP로 내부 키를 파생하는 방식이다.
- **강한 PUF**: 많은 CRP를 이용해 장치를 인증하는 방식이다.
- **SRAM PUF(Static Random-Access Memory PUF)**: 메모리 셀의 초기값 편차로 응답을 만드는 방식이다.

</details>

| PUF 구현 방식 | SRAM PUF | Arbiter PUF | Ring Oscillator PUF |
|:---|:---|:---|:---|
| 적용 기준 | 내부 키 재생성 | 다수 CRP 장치 인증 | 주파수 기반 장치 인증 |
| 핵심 특징 | **SRAM PUF**의 초기값 편차 | **강한 PUF**의 신호 경로 경쟁 | 발진기 주파수 편차 |
| 한계 | 불안정 비트 선택 오류 | 질의 기반 모델링 공격 | 온도•전압•노화 영향 |

- 내부 키 파생에는 **약한 PUF**, 다수 질의 기반 인증에는 강한 PUF를 적용한다.

> 요약: 용도와 환경에 맞는 고유성•재현성을 검증하는 것이 핵심이다.

#### 한줄 요약

- SRAM•Arbiter•Ring Oscillator는 서로 다른 물리 편차를 측정하므로 위협도 다르다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **ISO(International Organization for Standardization)**: 국제표준화기구이다.
- **IEC(International Electrotechnical Commission)**: 국제전기기술위원회이다.
- **ISO/IEC 20897-1**: PUF의 보안 요구사항을 규정한 표준이다.
- **ISO/IEC 20897-2**: PUF의 설계•통계 시험평가 방법을 규정한 표준이다.
- **모델링 공격**: 다수 CRP를 학습해 관측하지 않은 응답을 예측하는 공격이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 복제불가성 입증을 위한 정량 평가의 복잡성 | **ISO**•**IEC**의 **ISO/IEC 20897-1** 적용 | 요구 수준•용도 명확화 |
| 환경 변화로 응답이 흔들리면 키 복원이 실패함 | **ISO/IEC 20897-2** 적용 | 고유성•재현성 검증 |
| 헬퍼•CRP가 노출되면 응답 예측이 쉬워짐 | 무결성 보호•질의율 제한 | **모델링 공격** 억제 |

#### 한줄 요약

- 실제 온도•전압•노화에서 비트 오류율과 장치 간 거리를 측정하고 헬퍼 변조와 대량 CRP 수집도 시험한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **질의 제한**: 공격자가 CRP를 대량 수집하지 못하도록 요청 횟수와 속도를 통제하는 방법이다.
- **약한 PUF 키 파생**: 외부 질의 노출을 줄이고 내부 키를 재생성하는 방식이다.

</details>

- CRP 노출을 줄이는 **약한 PUF 키 파생**과 인증 요청의 **질의 제한**을 적용한다.

#### 한줄 요약

- 물리 편차 자체보다 환경 시험과 헬퍼 데이터•질의•키 수명 통제가 중요하다는 점이 핵심이다.
