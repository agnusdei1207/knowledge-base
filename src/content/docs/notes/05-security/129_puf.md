## 미리 알고가기

- **물리적 복제 불가 함수(Physical Unclonable Function, PUF)**: 퍼프로 읽고 영문 머리글자를 딴 표기이며, 제조 편차로 장치 고유 응답을 생성
- **도전값 (Challenge)**: 입력 선택값
- **응답값 (Response)**: 물리 편차에 따른 출력값
- **CRP (Challenge-Response Pair)**: 도전·응답 쌍
- **약한 PUF**: 내부 키 생성·저장용
- **강한 PUF**: 인증·응답 인증용
- **퍼지 추출기 (Fuzzy Extractor)**: 키 재생성·오류 보정
- **SRAM**: 전원 초기값 편차 활용
- **엔트로피**: 공격자가 예측하기 어려운 무작위성의 양
- **헬퍼 데이터**: 흔들리는 PUF 응답을 같은 키로 보정하도록 저장하는 공개 보조 정보
- **모델링 공격**: 많은 도전·응답 쌍을 학습해 보지 않은 응답을 예측하는 공격
- **비트 오류율**: 같은 장치가 같은 조건에서 응답했을 때 달라지는 비트의 비율
- **장치 간 거리**: 서로 다른 장치의 응답이 얼마나 다른지 나타내는 비트 차이
- **부채널**: 시간·전력 등 실행 흔적으로 내부 비밀을 추론하는 경로
- **PUF·CRP 읽기**: “퍼프·시알피”로 읽으며 복제 불가 함수와 도전-응답 쌍의 영문 머리글자임
- **SRAM 읽기와 표기**: “에스램”으로 읽으며 Static Random-Access Memory의 머리글자로 정적 임의접근 메모리를 나타냄



## Ⅰ. 개요

- 정의: 제조 편차 기반 **장치 고유 응답 생성**
- 기존 한계: 비휘발성 키 저장의 **물리 추출 위험**

### 쉽게 이해하기 (학습용)

- 같은 설계로 만든 칩도 미세한 차이가 있어 이를 장치마다 다른 전자 지문처럼 활용함

## Ⅱ. 특징

- 제조 편차 기반 **장치 고유성**
- 환경 변화에도 필요한 **응답 재현성**
- 퍼지 추출기 기반 **오류 보정·키 파생**

### 쉽게 이해하기 (학습용)

- 전자 지문은 매번 조금 흔들리므로 오류를 보정하되 보정 정보가 공격 단서가 되지 않게 보호해야 함

## Ⅲ. 아키텍처 및 구성요소

```text
[입력] -> [물리 구조] -> [응답]
            |
[등록] -> [보정] -> [키/헬퍼]
            |
[현장] -> [보정] -> [복원 키]
```

| 설계 요소 | 설명 |
|:---|:---|
| 도전값 | 물리 구조·측정 경로 선택 |
| PUF 구조 | 제조 편차를 응답으로 변환 |
| 원시 응답 | 편차·잡음이 포함된 비트열 |
| 퍼지 추출기 | 헬퍼 데이터로 키 복원 |
| 키 사용부 | 인증·암호 기능 수행 |

### 쉽게 이해하기 (학습용)

- 칩의 흔들리는 측정값을 그대로 키로 쓰지 않고 보정과 추출을 거쳐 안정된 비밀로 만듦

## Ⅳ. 원리 및 절차 흐름도

```text
평가
 ↓
등록
 ↓
생성
 ↓
복원
 ↓
통제
```

| 절차 | 설명 |
|:---|:---|
| 평가 | 응답 품질을 평가함 |
| 등록 | 기준 응답을 측정함 |
| 생성 | 오류 보정 정보를 생성함 |
| 복원 | 키를 복원·검증함 |
| 통제 | 키 사용·제거를 통제함 |

### 쉽게 이해하기 (학습용)

- 공장에서 기준을 등록한 뒤 현장에서는 흔들린 응답을 보정해 같은 키를 다시 만들어 사용함

## Ⅴ. 종류 및 비교

| PUF 구현 방식 | SRAM | Arbiter | Ring Oscillator |
|:---|:---|:---|:---|
| 적용 기준 | 내부 키를 재생성할 때 | 많은 도전·응답으로 인증할 때 | 주파수 측정이 가능한 하드웨어 인증 |
| 핵심 특징 | SRAM 초기값 편차 | 신호 경로 지연 경쟁 | 발진기 주파수 편차 |
| 한계 | 불안정 비트 선택 오류 | 질의 기반 모델링 공격 | 온도·전압·노화 영향 |

> 요약: 편차 기반 안정된 키 생성 및 인증 필요

### 쉽게 이해하기 (학습용)

- SRAM·Arbiter·Ring Oscillator는 서로 다른 물리 편차를 측정함

## Ⅵ. 실무 사례

1. 제품 환경의 **PUF 오류율·장치 간 거리 검증**

### 쉽게 이해하기 (학습용)

- 제조사는 실제 온도·전압·노화 범위에서 동일 장치의 응답 재현성과 장치 간 고유성·엔트로피를 측정한 뒤 키 파생에 적용한다.

## Ⅶ. 결론

- 저장 키 탈취 위험을 줄이기 위해 PUF의 고유성·재현성·엔트로피·헬퍼 데이터·모델링 공격을 검토하여, 제품 환경에서 검증된 응답만 키 파생에 활용해야 한다.

### 쉽게 이해하기 (학습용)

- PUF의 보안성은 물리 편차 자체보다 안정성 검증과 헬퍼·질의·복구 정책에 달려 있음
