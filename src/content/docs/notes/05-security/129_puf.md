## 미리 알고가기

- **PUF (Physical Unclonable Function)**: 장치 편차로 응답을 생성함
- **도전값 (Challenge)**: 입력 선택값
- **응답값 (Response)**: 물리 편차에 따른 출력값
- **CRP (Challenge-Response Pair)**: 도전·응답 쌍
- **약한 PUF**: 내부 키 생성·저장용
- **강한 PUF**: 인증·응답 인증용
- **퍼지 추출기 (Fuzzy Extractor)**: 키 재생성·오류 보정
- **SRAM**: 전원 초기값 편차 활용
- **엔트로피**: 공격자가 예측하기 어려운 무작위성의 양
- **헬퍼 데이터**: 흔들리는 PUF 응답을 같은 키로 보정하도록 저장하는 공개 보조 정보
- **모델링 공격**: 많은 도전·응답 쌍을 학습해 보지 않은 응답을 예측하는 공격
- **비트 오류율**: 같은 장치가 같은 조건에서 응답했을 때 달라지는 비트의 비율
- **장치 간 거리**: 서로 다른 장치의 응답이 얼마나 다른지 나타내는 비트 차이
- **부채널**: 시간·전력 등 실행 흔적으로 내부 비밀을 추론하는 경로
- **PUF·CRP 읽기**: “퍼프·시알피”로 읽으며 복제 불가 함수와 도전-응답 쌍의 영문 머리글자임
- **SRAM 읽기와 표기**: “에스램”으로 읽으며 Static Random-Access Memory의 머리글자로 정적 임의접근 메모리를 나타냄



## Ⅰ. 개요

- **정의/개념**: 장치 고유 편차로 응답을 생성함
- **배경/필요성**: 메모리 키 저장의 물리 분석 대응함

### 쉽게 이해하기 (학습용)

- 같은 설계로 만든 칩도 미세한 차이가 있어 이를 장치마다 다른 전자 지문처럼 활용함

## Ⅱ. 특징

- 제조 편차로 장치별 고유성 획득한다.
- 환경 요인으로 응답 변화 가능성 존재한다.
- 보정·추출로 안정된 키 파생한다.
- 질의 과다 시 모델링 공격 우려가 있다.

### 쉽게 이해하기 (학습용)

- 전자 지문은 매번 조금 흔들리므로 오류를 보정하되 보정 정보가 공격 단서가 되지 않게 보호해야 함

## Ⅲ. 아키텍처 및 구성요소

| 설계 요소 | 설명 |
|:---|:---|
| 엔트로피 | 장치 편차에 따른 무작위성 |
| 도전 | 구조·측정 조건 선택 |
| 원시 응답 | 편차·잡음 포함 비트열 |
| 오류 보정 | 헬퍼 데이터로 키 복원 |
| 키 사용 | 인증·암호 기능 수행 |

```text
[입력] -> [물리 구조] -> [응답]
            |
[등록] -> [보정] -> [키/헬퍼]
            |
[현장] -> [보정] -> [복원 키]
```

### 쉽게 이해하기 (학습용)

- 칩의 흔들리는 측정값을 그대로 키로 쓰지 않고 보정과 추출을 거쳐 안정된 비밀로 만듦

## Ⅳ. 원리 및 절차 흐름도

```text
평가
 ↓
등록
 ↓
생성
 ↓
복원
 ↓
통제
```

| 절차 | 설명 |
|:---|:---|
| 평가 | 응답 품질을 평가함 |
| 등록 | 기준 응답을 측정함 |
| 생성 | 오류 보정 정보를 생성함 |
| 복원 | 키를 복원·검증함 |
| 통제 | 키 사용·제거를 통제함 |

### 쉽게 이해하기 (학습용)

- 공장에서 기준을 등록한 뒤 현장에서는 흔들린 응답을 보정해 같은 키를 다시 만들어 사용함

## Ⅴ. 종류 및 비교

| 비교 축 | SRAM | Arbiter | Ring Oscillator |
|:---|:---|:---|:---|
| 핵심 특징 | 전원 인가 때 메모리 초기값 편차 사용 | 신호 경로의 지연 경쟁 결과 사용 | 발진기의 주파수 편차 비교 |
| 적용 기준 | 내부 키를 재생성할 때 | 많은 도전·응답으로 인증할 때 | 주파수 측정이 가능한 하드웨어 인증 |
| 주요 위험 | 불안정 비트를 잘못 선택 | 질의 수집으로 모델링 가능 | 온도·전압·노화로 주파수 변화 |

> 요약: 편차 기반 안정된 키 생성 및 인증 필요

### 쉽게 이해하기 (학습용)

- SRAM·Arbiter·Ring Oscillator는 서로 다른 물리 편차를 측정함

## Ⅵ. 실무 사례

- 목표 환경의 오류율·장치 거리·엔트로피 검증
- 헬퍼 데이터의 변조·정보 누출 분석
- 강한 PUF의 질의 인증·제한·폐기 적용
- 노화·부채널·결함과 복원 실패에 대비

### 쉽게 이해하기 (학습용)

- 목표 온도·전압에서 오류율·장치 간 거리·엔트로피를 측정함
- 헬퍼 데이터는 공개돼도 되지만 변조와 정보 누출 가능성을 검증함
- 강한 PUF는 질의 인증·횟수 제한·폐기로 모델링 공격을 줄임
- 노화·부채널·결함 주입에 대비하고 키 복원 실패 절차를 둠

## Ⅶ. 결론

- PUF는 편차·오류 보정으로 원시 키 저장을 줄임

### 쉽게 이해하기 (학습용)

- PUF의 보안성은 물리 편차 자체보다 안정성 검증과 헬퍼·질의·복구 정책에 달려 있음
