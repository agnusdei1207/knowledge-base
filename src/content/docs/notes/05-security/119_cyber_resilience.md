## 미리 알고가기

- **미국 국립표준기술연구소 (National Institute of Standards and Technology, NIST)**: 사이버 레질리언스 지침을 개발함
- **특별 간행물 (Special Publication, SP)**: NIST 기술 지침 문서군임
- **사이버 레질리언스 (Cyber Resilience)**: 공격 중 필수 기능을 유지·복구·적응함
- **복구 시간 목표 (Recovery Time Objective, RTO)**: 목표 업무 복구 시간을 정함
- **복구 시점 목표 (Recovery Point Objective, RPO)**: 허용 데이터 손실 시점을 정함
- **침해 가정 (Assume Breach)**: 침해 전제로 대응·복구를 설계함
- **안전한 저하 (Graceful Degradation)**: 장애·공격 시 전체 중단 대신 비필수 기능을 줄여 핵심 기능을 유지하는 방식
- **폭발 반경 (Blast Radius)**: 한 번의 침해나 실패가 영향을 미치는 시스템·업무 범위
- **NIST·SP 읽기**: “니스트·에스피”로 읽으며 미국 표준기관과 특별 간행물의 영문 명칭 머리글자임
- **RTO·RPO 읽기**: “알티오·알피오”로 읽으며 복구 시간과 허용 데이터 손실 시점 목표의 영문 머리글자임



## Ⅰ. 개요

- 정의/개념: 사이버 공격 중에도 필수 임무를 유지하고 복구·적응하는 능력
- **배경/필요성**: 예방 통제만으로 침해·장애 발생 후 업무 지속 보장 곤란

### 쉽게 이해하기 (학습용)

- 공격 중에도 핵심 기능과 성능을 유지하는 능력임

## Ⅱ. 특징

- 필수 기능과 허용 성능을 먼저 정한다.
- 다계층·다양성·격리가 단일 실패를 견디게 한다.
- 안전한 저하·복구·훈련 개선 중에도 보안 속성을 유지한다.

### 쉽게 이해하기 (학습용)

- 전체 기능이 멈추는 대신 꼭 필요한 기능만 안전하게 남기는 설계도 레질리언스임

## Ⅲ. 아키텍처 및 구성요소

| 설계 요소 | 설명 |
|:---|:---|
| 예상 | 위협·실패 상태를 예측함 |
| 견딤 | 필수 기능을 허용 수준 유지함 |
| 복구 | 데이터·통제를 신뢰성 있게 재구성함 |
| 적응 | 교훈에 따라 전략·구조를 변환함 |
| 검증 | 훈련으로 목표 능력을 측정함 |

```text
[필수 임무]
   ├─ [예상] 위협·의존성 파악
   ├─ [견딤] 격리·다양성·안전한 저하
   ├─ [복구] 깨끗한 데이터·통제로 재구성
   └─ [적응] 사고·훈련 결과로 구조 개선
```

### 쉽게 이해하기 (학습용)

- 공격 전 준비부터 공격 중 버티기, 복구와 재설계까지 하나의 생명주기로 관리함

## Ⅳ. 원리 및 절차 흐름도

```text
임무의존정의 → 역경시나리오 → 지속복구설계 → 훈련측정 → 적응개선
```

| 절차 | 설명 |
|:---|:---|
| 임무정의 | 기능과 의존성 식별함 |
| 시나리오 | 저하 상태 정의함 |
| 지속설계 | 복구 기준 설계함 |
| 훈련측정 | 전환 시간을 측정함 |
| 적응개선 | 전략·구조 개선함 |

> 요약: 필수 임무를 유지하고 신뢰 상태로 복구·적응함

### 쉽게 이해하기 (학습용)

- 서버 수를 늘리기 전에 어떤 기능을 어느 수준으로 남겨야 하는지 정해야 함

## Ⅴ. 사이버보안과 레질리언스 비교

| 비교축 | 사이버 보안 | 사이버 레질리언스 |
|:---|:---|:---|
| 적용 기준 | 예방·탐지·대응 통제를 설계할 때 | 침해를 가정한 지속·복구 능력이 필요할 때 |
| 핵심 특징 | 침해 가능성과 직접 피해를 낮춤 | 침해 중 필수 임무를 유지·복구함 |
| 한계 | 예방 실패 시 임무 전체가 중단됨 | 복잡한 대체 구조가 새 취약점을 만듦 |

### 쉽게 이해하기 (학습용)

- 보안은 공격 성공 가능성을 낮추고 레질리언스는 성공한 공격의 임무 영향을 제한함

## Ⅵ. 실무 사례

1. 랜섬웨어 대비 **격리 백업의 깨끗한 복구 검증**

### 쉽게 이해하기 (학습용)

- 백업을 운영 계정과 네트워크에서 격리하고 랜섬웨어 흔적이 없는 복구 지점에서 핵심 서비스를 목표 시간 안에 재가동할 수 있는지 반복 시험한다.

## Ⅶ. 결론

- 침해를 완전히 예방할 수 없다는 한계를 극복하기 위해 필수 기능·폭발 반경·RTO·RPO·복구 신뢰·적응 능력을 검토하여, 임무 지속 중심의 사이버 복원력을 구축해야 한다.

### 쉽게 이해하기 (학습용)

- 뚫리지 않겠다는 약속보다 뚫렸을 때 무엇을 지키고 어떻게 회복할지 증명하는 능력임
