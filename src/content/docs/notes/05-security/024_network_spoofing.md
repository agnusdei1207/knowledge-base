## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **스푸핑(Spoofing)**: 주소•신원•응답 정보를 위조하여 정상 통신 주체나 경로로 가장하는 공격이다.
- **중간자 공격**: 통신 사이에서 정상 상대인 것처럼 가장해 도청•변조하는 공격이다.

</details>

- 정의/개념: **스푸핑**은 ARP•IP•DNS 정보를 위조해 정상 주체나 경로로 가장하는 공격이다.
- 배경/필요성: 인증 없는 주소•응답 수용으로는 **중간자 공격**과 반사 공격을 차단할 수 없다.

#### 한줄 요약

- 주소록이나 발신인을 바꿔 정상 상대처럼 속이는 행위다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **주소 결정 프로토콜(Address Resolution Protocol, ARP)**: IP 주소에 대응하는 MAC 주소를 조회하는 프로토콜이다.
- **인터넷 프로토콜(Internet Protocol, IP)**: 네트워크 간 패킷 전달에 사용하는 논리 주소 체계이다.
- **매체 접근 제어(Media Access Control, MAC) 주소**: 링크 계층 인터페이스를 식별하는 주소이다.
- **도메인 이름 시스템(Domain Name System, DNS)**: 도메인 이름을 IP 주소 등의 자원 정보로 변환하는 시스템이다.
- **반사 공격**: 피해자의 출발지 주소를 위조해 다수 서버의 응답을 피해자에게 보내는 공격이다.
- **ARP 스푸핑**: 거짓 IP•MAC 대응으로 인접망의 ARP 캐시를 오염시키는 공격이다.
- **IP 스푸핑**: 패킷의 출발지 IP 주소를 위조하여 신원을 숨기거나 반사 응답을 유도하는 공격이다.
- **DNS 스푸핑**: 거짓 도메인 응답으로 사용자를 공격자가 지정한 목적지로 유도하는 공격이다.

</details>

- **ARP 스푸핑**은 **ARP**의 IP•**MAC 주소** 대응을 오염시킨다.
- **IP 스푸핑**은 **IP** 출발지 주소를 위조해 **반사 공격**과 필터 회피를 유도한다.
- **DNS 스푸핑**은 **DNS** 응답을 위조해 가짜 목적지로 유도한다.

#### 한줄 요약

- 주소가 정상처럼 보여도 최종 상대 인증을 별도로 확인해야 한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **동적 ARP 검사(Dynamic ARP Inspection, DAI)**: 신뢰된 DHCP 바인딩과 ARP 메시지를 대조하여 위조 응답을 차단하는 기능이다.
- **유니캐스트 역방향 경로 전달(Unicast Reverse Path Forwarding, uRPF)**: 출발지 IP로 돌아가는 경로의 유효성을 검사하는 기능이다.
- **DNS 보안 확장(Domain Name System Security Extensions, DNSSEC)**: DNS 응답의 출처와 무결성을 검증하는 보안 확장이다.
- **전송 계층 보안(Transport Layer Security, TLS) 종단 인증**: 인증서로 실제 통신 상대의 신원을 확인하는 절차이다.

</details>

```text
스푸핑 방어 구조
├─ 신뢰 정보
├─ 검증 통제
├─ 위조 주입점
├─ 주소 캐시•필터
└─ 공격 감시•종단 인증
```

가지의 의미: 신뢰 근거•계층 검증•캐시•종단 확인 책임을 나눈 구조다.

| 구성요소 | 책임 |
|:---|:---|
| 신뢰 정보 | ARP•IP•DNS 대응 제공 |
| 검증 통제 | **DAI**•**uRPF**•**DNSSEC** 검증 |
| 위조 주입점 | 거짓 주소•응답 전달 |
| 주소 캐시•필터 | 검증된 대응 정보 사용 |
| 공격 감시•종단 인증 | 도청 탐지•**TLS 종단 인증** |


#### 한줄 요약

- 주소 검증 뒤에도 TLS로 최종 상대를 다시 확인한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **캐시 오염(Cache Poisoning)**: 위조한 주소•이름 대응을 피해자의 캐시에 저장시키는 공격이다.
- **출발지 위조**: 공격 패킷의 송신 주소를 피해자 주소로 바꾸어 응답을 피해자에게 유도하는 공격이다.
- **위조 주소•응답 주입**: 거짓 ARP•DNS 대응을 정상 응답처럼 피해자에게 전달하는 단계이다.
- **위조 대응 캐시 저장**: 인증하지 않은 주소•이름 정보를 신뢰 캐시에 반영하는 단계이다.
- **공격자 경로로 트래픽 전환**: 오염된 대응 정보로 피해 통신을 공격자의 도청•변조 경로에 보내는 단계이다.
- **위조 출발지 패킷 전송**: 피해자 주소를 출발지로 사용한 요청을 보내 반사 응답을 유도하는 단계이다.

</details>

```text
스푸핑 공격 경로
├─ ARP•DNS 응답 위조
│      │
│      ▼
│  1. 위조 주소•응답 주입
│      │
│      ▼
│  2. 위조 대응 캐시 저장
│      │
│      ▼
│  3. 공격자 경로로 트래픽 전환
│
└─ IP 출발지 위조
       │
       ▼
   4. 위조 출발지 패킷 전송
       │
       └── 피해자에게 반사 응답
```

### 동작 원리

1. **위조 주소•응답 주입**: 거짓 ARP•DNS 대응을 정상 응답처럼 전달한다.
2. **위조 대응 캐시 저장**: **캐시 오염**으로 주소•이름 정보를 신뢰 상태에 반영한다.
3. **공격자 경로로 트래픽 전환**: 피해 통신을 도청•변조 경로로 유도한다.
4. **위조 출발지 패킷 전송**: **출발지 위조**로 피해자에게 반사 응답을 유도한다.


#### 한줄 요약

- ARP•DNS 위조는 통신 경로를 바꾸고 IP 위조는 피해자에게 반사 응답을 유도한다.

## Ⅴ. 종류 및 비교

| 네트워크 스푸핑 | ARP 스푸핑 | IP 스푸핑 | DNS 스푸핑 |
|:---|:---|:---|:---|
| 적용 기준 | 인접망 주소 보호 | 경계 출발지 검증 | DNS 응답 검증 |
| 핵심 특징 | **ARP 스푸핑**의 IP•MAC 대응 위조 | **IP 스푸핑**의 출발지 IP 위조 | **DNS 스푸핑**의 도메인 응답 위조 |
| 한계 | **중간자 공격** | 반사•출발지 필터 회피 | 피싱•**캐시 오염** |

> 요약: 스푸핑 유형별 검증 지점 분리하는 것이 핵심이다.

#### 한줄 요약

- 위조하는 정보의 계층에 따라 방어 지점도 달라진다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **인터넷 기술 태스크포스(Internet Engineering Task Force, IETF)**: 인터넷 프로토콜 표준을 개발하는 조직이다.
- **현행 최선 관행(Best Current Practice, BCP) 84**: uRPF 기반 출발지 주소 검증을 규정한 지침이다.
- **의견 요청 문서(Request for Comments, RFC) 4033~4035**: DNSSEC 검증 절차를 규정한 국제 표준 문서이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 출발지 IP 위조 | **IETF** **BCP 84**의 **uRPF** 적용 | 반사•출발지 필터 회피 억제 |
| DNS 응답 위조 | **IETF** **RFC 4033~4035**의 **DNSSEC** 적용 | 출처•무결성 검증 |
| ARP 캐시 오염 | DHCP 바인딩 기반 **DAI** | 인접망 **중간자 공격** 차단 |
| 경로 위조 뒤 종단 사칭 | **TLS 종단 인증** | 최종 상대 신원 확인 |

#### 한줄 요약

- 잘못된 주소 목록을 쓰면 정상 단말까지 차단될 수 있다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **계층별 스푸핑 방어**: 위조되는 주소•응답의 계층과 최종 상대 인증 지점에 맞춰 검증 통제를 배치하는 원칙이다.

</details>

- **계층별 스푸핑 방어**에 따라 ARP 위조는 **DAI**, IP 위조는 **uRPF**, DNS 위조는 **DNSSEC**를 적용한다.

#### 한줄 요약

- 경로 주소와 최종 통신 상대를 모두 검증해야 안전하다.
