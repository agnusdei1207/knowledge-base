## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **차등 프라이버시(Differential Privacy, DP)**: 통계적 데이터 분석이나 머신러닝 학습 시, 임의의 특정 개인 레코드(1건)가 데이터셋에 포함되어 있는지(Inclusion) 혹은 제외되어 있는지(Exclusion) 여부와 무관하게 연산 결과의 확률 분포가 수학적 오차($e^\epsilon$) 범위 내에서 거의 동일하도록 보증하는 엄격한 수학적 프라이버시 정의 (2006년 Cynthia Dwork 제안).
- **인접 데이터셋(Neighboring Datasets / $D, D'$)**: 전체 레코드 중 단 1개의 개별 데이터(행)만 다르고 나머지 모든 데이터는 완전히 동일한 두 데이터베이스($|D \oplus D'| = 1$).

</details>

- 정의/개념: 인접 데이터셋 $D, D'$와 임의의 질의 출력 집합 $S$에 대해, 알고리즘 $M$이 $\Pr[M(D) \in S] \le e^\epsilon \cdot \Pr[M(D') \in S] + \delta$ 부등식을 만족하도록 **수학적 확률 노이즈(Laplace / Gaussian)** 를 주입하는 **정량적 프라이버시 보존 메커니즘**
- 배경/필요성: $k$-익명성, $l$-다양성 등 레거시 정적 비식별화 기법이 외부 보조 정보(Auxiliary Information) 결합 및 반복 질의(Reconstruction Attack)를 통한 재식별화 공격에 취약한 근본적 한계를 극복할 요구

#### 한줄 요약
- 단 1건의 데이터 유무에 따른 출력 확률 차이를 $e^\epsilon$ 이내로 제한하여 특정 개인의 존재 여부를 수학적으로 은폐한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **프라이버시 예산(Privacy Budget / $\epsilon$, Epsilon)**: 프라이버시 보장 강도를 조절하는 핵심 매개변수로, $\epsilon \to 0$에 가까울수록 강력한 프라이버시가 보장되나 주입되는 노이즈가 커져 통계 유용성(Utility)이 감소하는 상충 관계(Trade-off).
- **후처리 불변성(Post-Processing Invariance)**: $(\epsilon, \delta)$-차등 프라이버시를 만족하는 출력 결과물에 대해 공격자가 어떠한 추가 알고리즘, AI 모델링, 외부 데이터 결합 연산을 사후에 적용하더라도 프라이버시 보장 수준이 절대 약화되지 않는 수학적 특성.

</details>

- **수학적으로 증명 가능한 정량적 보증**: 공격자의 배경 지식이나 미래의 추가 보조 정보 획득 여부에 구애받지 않는 영구적 안전성
- **결합성(Composability)**: 여러 차례의 질의($M_1, M_2$)가 실행될 때 누적되는 프라이버시 손실이 각 예산의 합($\epsilon_1 + \epsilon_2$)으로 엄격히 계산 및 추적 가능
- **프라이버시-유용성 딜레마 (Privacy-Utility Trade-off)**: 노이즈 주입량에 따른 통계적 분석 정확도와 개인정보 보호 강도의 균형 최적화 필수

#### 한줄 요약
- 정량적 수학 보증, 후처리 불변성, 결합성(질의 누적 추적), 프라이버시-정확도 상충 제어를 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **전역 민감도(Global Sensitivity / $\Delta f$)**: 단 1개의 레코드 차이가 쿼리 함수 $f$의 결과값을 최대로 변화시킬 수 있는 최대 절댓값 차이($\Delta f = \max \|f(D) - f(D')\|_1$).
- **프라이버시 회계사(Privacy Accountant / RDP)**: 시스템에 인입되는 모든 쿼리의 예산($\epsilon$) 소진량을 실시간 누적 기록하고, 사전 할당된 총 예산 도달 시 추가 질의를 자동으로 차단하는 거버넌스 엔진.

</details>

```text
[ 데이터베이스 ($D$: 100만 명 데이터) ] ──▶ [ 질의 함수: $f(D)$ (예: 평균 연봉 계산) ]
                                                            │
                                                            ▼ (원시 계산 결과: $f(D)$)
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 차등 프라이버시 노이즈 주입 엔진 (DP Mechanism Engine) ]             │
│  ├─ 1. 전역 민감도 산정: $\Delta f = \max \|f(D) - f(D')\|$               │
│  ├─ 2. 프라이버시 회계사: 잔여 예산($\epsilon_{\text{remain}}$) 확인 및 차감│
│  └─ 3. 노이즈 생성: $\text{Laplace}\left(0, \frac{\Delta f}{\epsilon}\right)$ 또는 $\text{Gaussian}\left(0, \sigma^2\right)$│
└────────────────────────────────────┬────────────────────────────────────┘
                                     │
                                     ▼ (노이즈 가산: $\tilde{y} = f(D) + \text{Noise}$)
                      [ 사용자/분석가에게 노이즈 적용된 통계 결과 $\tilde{y}$ 반환 ]
```

선의 의미: 데이터베이스 질의 결과에 전역 민감도와 프라이버시 예산에 비례하는 수학적 노이즈를 주입하고, 회계사를 통해 누적 손실을 추적하는 구조

| 구성요소 | 핵심 책임 및 역할 | 비고 |
|:---|:---|:---|
| **전역 민감도 산정기** | 함수 $f$에서 개별 레코드 1건의 최대 영향력($\Delta f$)을 계산하여 노이즈 스케일 결정 | $L_1 / L_2$ Sensitivity |
| **프라이버시 예산 ($\epsilon, \delta$)**| 시스템 허용 프라이버시 손실 상한선 설정 (통상 $\epsilon \in [0.1, 2.0]$) | Epsilon / Delta |
| **노이즈 생성기** | 라플라스($L_1$ 민감도 / 순수 DP) 또는 가우시안($L_2$ 민감도 / 근사 DP) 난수 생성 | Noise Engine |
| **프라이버시 회계사** | 모멘트 회계(Moments Accountant / RDP) 기반 누적 손실 정밀 계산 및 쿼리 한도 제어 | Privacy Accountant |
| **기여도 클리핑기** | 개별 데이터의 극단적인 이상치(Outlier)가 민감도를 폭증시키지 않도록 임계치 절단 | Clipping Bound |

#### 한줄 요약
- 민감도 산정기, 프라이버시 예산, 노이즈 생성기, 프라이버시 회계사, 기여도 클리핑기가 결합한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **DP-SGD(Differentially Private Stochastic Gradient Descent)**: 딥러닝 인공지능 학습 시, 개별 학습 데이터의 그래디언트(Gradient)를 일정 임계치($C$) 이하로 클리핑(Clipping)한 후 가우시안 노이즈를 주입하여 모델 파라미터를 업데이트함으로써, AI가 훈련 데이터의 특정 개인 정보를 암기(Memorization)하는 것을 방지하는 학습 알고리즘.

</details>

```text
1. 분석가가 집계 질의(Query: 평균/카운트) 제출 ➔ 시스템이 쿼리의 전역 민감도($\Delta f$) 도출
            │
            ▼
2. 프라이버시 회계사가 해당 질의에 필요한 예산($\epsilon_i$)과 현재 누적 사용량($\sum \epsilon$) 대조
            │
            ├─ [총 예산 $\epsilon_{\text{total}}$ 초과 시] ➔ 질의 즉시 거부 및 접근 차단 (Privacy Exhausted)
            ▼
3. [예산 충분 시] ➔ 데이터베이스에서 원시 쿼리 결과($f(D)$) 계산 및 개별 기여도 클리핑($C$) 적용
            │
            ▼
4. 노이즈 생성기가 $\text{Laplace}\left(0, \frac{\Delta f}{\epsilon_i}\right)$ 분포에서 난수 추출하여 $f(D)$에 가산
            │
            ▼
5. 회계사 장부에서 예산($\epsilon_i$)을 차감하고, 노이즈가 주입된 안전한 통계값($\tilde{y}$)을 분석가에게 반환
```

**동작 원리**

1. **민감도 제어**: 단일 사용자가 쿼리 결과에 미치는 최대 변화량을 수식으로 상한 고정
2. **예산 한도 검증**: 연속적인 질의에 의한 누적 재식별 위험을 프라이버시 회계사로 추적
3. **확률적 노이즈 합성**: 무작위 대칭 확률 밀도 함수를 통해 실제 통계값 주변에 오차 분포 생성
4. **결과 난독화**: 실제 참값이 노이즈 분포의 임의의 지점으로 치환되어 개인 레코드 특정 불능화
5. **폐쇄 루프 회계**: 쿼리 완료 즉시 소진된 예산을 영구 기록하여 데이터 자산의 프라이버시 수명 관리

#### 한줄 요약
- 민감도 산정, 프라이버시 예산 검증, 클리핑 및 노이즈 생성, 통계값 가산 반환, 예산 차감 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **중앙 DP vs 로컬 DP vs 셔플 DP**: 데이터 수집 및 노이즈 주입 주체에 따른 아키텍처 분류.

</details>

| 비교 항목 | 중앙형 차등 프라이버시 (Central DP) | 로컬형 차등 프라이버시 (Local DP) | 셔플형 차등 프라이버시 (Shuffle DP) |
|:---|:---|:---|:---|
| **노이즈 주입 주체** | **중앙 서버 (집계 후 노이즈 주입)** | **사용자 단말기 (전송 전 노이즈 주입)** | **중간 셔플러 노드 (익명화 믹싱)** |
| **중앙 서버 신뢰 요구**| **필수 (서버가 원본 평문 데이터를 보유)**| **불필요 (서버는 오직 노이즈 데이터만 수신)**| 최소 신뢰 (셔플러와 분석 서버 분리) |
| **통계 분석 정확도** | **매우 높음 (소량의 노이즈만으로 충분)**| **낮음 (개별 단말마다 노이즈 추가되어 누적)**| **중간~높음 (노이즈 증폭 효과 활용)** |
| **필요 데이터 표본 수** | 수천 ~ 수만 건 | **수백만 ~ 수천만 건 (대규모 단말 필요)**| 수십만 건 |
| **주요 상용 적용 사례**| **미국 인구조사국(US Census), 금융 통계** | **Apple iOS 텔레메트리, Google Chrome RAPPOR**| **연합학습 프라이버시 집계, IoT 센서망**|

#### 한줄 요약
- 중앙 DP는 고정확도 통계 분석용, 로컬 DP는 서버를 신뢰할 수 없는 대규모 단말용, 셔플 DP는 절충형 하이브리드이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **멤버십 추론 공격(Membership Inference Attack)**: 공격자가 기계학습 모델의 예측 확률 분포나 손실값(Loss)을 분석하여, 특정 개인의 데이터가 해당 모델의 훈련 데이터셋에 포함되었는지를 높은 확률로 판별해 내는 개인정보 침해 공격.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 공격자가 유사 질의를 수천 번 반복 실행하여 노이즈를 평균화하고 **특정 개인 원본을 역추론하는 공격** | **Rényi 차등 프라이버시(RDP) 기반 프라이버시 회계사 도입 및 총 예산($\epsilon_{\text{total}}$) 소진 시 강제 셧다운** | 반복 질의에 의한 노이즈 상쇄 방어 및 데이터 재식별 위험 원천 차단 |
| 극단적인 이상치(Outlier) 레코드로 인한 **전역 민감도($\Delta f$) 폭증 및 데이터 품질 왜곡(과도한 노이즈)** | **개별 데이터 기여도 한도를 강제로 절단하는 L2-Norm 그라디언트/데이터 클리핑(Clipping Bound)** 적용 | 민감도 상한선 고정 및 주입 노이즈 최소화를 통한 통계 유용성 보존 |
| 딥러닝 AI 모델이 훈련 데이터를 과적합(Overfitting)하여 **개인정보를 암기 후 출력하는 멤버십 추론 위험** | **모델 학습 최적화 알고리즘에 DP-SGD(Clipping + Gaussian Noise) 필수 적용** | AI 모델의 개인 데이터 암기 방지 및 멤버십 추론 공격 성공률을 무작위 추측(50%) 수준으로 억제 |

#### 한줄 요약
- RDP 회계사로 질의를 제한하고, 클리핑으로 이상치 폭증을 막으며, DP-SGD로 AI 멤버십 추론을 방어한다.

## Ⅶ. 결론

- 빅데이터 분석 및 인공지능 학습 환경에서 데이터 활용성과 개인정보 보호 컴플라이언스(개인정보보호법 가명정보 결합)를 완벽히 양립시키는 **차등 프라이버시(Differential Privacy) 아키텍처**는 전 세계 프라이버시 공학의 글로벌 표준이며, 실무 구현 시 **중앙 DP와 로컬 DP의 서비스 특성별 최적 선택**, **엄격한 프라이버시 회계사 기반 예산 관리**, **AI 모델 학습 시 DP-SGD 파이프라인 결합**을 통합 추진하여 신뢰성 높은 데이터 프라이버시 생태계를 완성

#### 한줄 요약
- 수학적 ($\epsilon, \delta$)-DP 정의와 프라이버시 회계사 및 DP-SGD를 결합하여 완벽한 비식별화 통계를 실현한다.
