## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **차등 프라이버시(Differential Privacy, DP)**: 한 개인의 포함 여부가 공개 결과에 미치는 영향을 수학적으로 제한하는 프라이버시 보호 모델이다.
- **인접 데이터셋(Adjacent Dataset)**: 한 보호 단위만 다른 두 데이터셋이다.

</details>

- 정의/개념: **DP**는 **인접 데이터셋**의 출력 분포 차이를 제한하는 확률적 프라이버시 모델이다.
- 배경/필요성: 익명 통계를 반복 결합하면 개인의 참여 여부를 추론할 수 있다.

#### 한줄 요약

- 한 사람의 기록을 넣거나 빼도 발표 결과가 비슷하게 보이도록 오차를 더해 참여 여부 추론을 어렵게 한다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **프라이버시 예산 ε(Epsilon)**: 두 인접 데이터셋의 출력 분포 차이에 허용하는 프라이버시 손실 한도이며, 작을수록 강한 보장을 뜻하는 매개변수이다.
- **실패 확률 δ(Delta)**: 순수 DP 경계를 벗어날 수 있는 허용 확률이며, 작을수록 강한 보장을 뜻하는 매개변수이다.
- **후처리 불변성**: DP 결과만 사용한 추가 분석이 원자료에 접근하지 않는 한 프라이버시 예산을 더 소비하지 않는 성질이다.

</details>

![프라이버시 예산이 작아질수록 증가하는 Laplace 잡음 척도](/study/diagrams/differential-privacy-noise.svg)

> 요약: **프라이버시 예산 ε**이 작을수록 잡음이 증가하고 프라이버시 보장은 강해진다.

- **인접 데이터셋**의 정의가 실제 보호 범위를 결정한다.
- 기여 한도와 예산 회계로 누적 손실을 통제한다.
- **후처리 불변성**으로 추가 분석에도 예산을 유지한다.
- **실패 확률 δ**와 프라이버시 예산을 축소하면 보장은 강해지지만 정확도는 낮아진다.

#### 한줄 요약

- 누구의 어떤 변화를 숨길지 먼저 정해야 보호 범위와 잡음 크기를 계산할 수 있다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **민감도(Sensitivity)**: 개인 한 명의 변화로 질의 결과가 달라질 수 있는 최대량이다.
- **기여 한도(Contribution Bound)**: 한 개인이 결과에 반영되는 횟수와 크기의 상한이다.
- **노이즈 주입(Noise Injection)**: 확률적 오차를 더해 개인의 영향을 구별하기 어렵게 하는 기법이다.
- **프라이버시 회계**: 여러 질의와 공개가 소비한 ε•δ를 누적하여 전체 손실 한도를 통제하는 절차이다.

</details>

```text
차등 프라이버시 구조
├─ 보호 단위•인접성
├─ 기여 한도•민감도
├─ ε•δ 예산
├─ 노이즈 메커니즘
└─ 프라이버시 회계
```

가지의 의미: 보호 범위•개인 영향•손실 한도•무작위화•회계를 나눈 구조다.

| 구성요소 | 책임 |
|:---|:---|
| 보호 단위•인접성 | **인접 데이터셋**으로 숨길 개인 변화의 범위 정의 |
| 기여 한도•민감도 | **기여 한도**와 **민감도**로 개인별 최대 출력 영향 제한 |
| ε•δ 예산 | **프라이버시 예산 ε**과 **실패 확률 δ**의 상한 설정 |
| 노이즈 메커니즘 | **노이즈 주입**으로 결과 무작위화 |
| 프라이버시 회계 | **프라이버시 회계**로 반복 공개의 누적 손실 계산 |

#### 한줄 요약

- 누구의 어떤 변화를 숨길지 정한 뒤 개인별 영향과 반복 공개량에 맞춰 오차를 배분한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **예산 차감**: 결과 공개가 소비한 ε•δ를 누적 사용량에 기록하는 처리이다.
- **기여 한도•민감도 산정**: 개인별 입력을 제한하고 한 명의 변화가 결과에 미치는 최대 영향을 계산하는 단계이다.
- **누적 예산 확인**: 프라이버시 회계의 ε•δ 누적 사용량과 잔여 한도를 대조하는 단계이다.
- **노이즈•공개 승인**: 민감도에 맞는 오차와 잔여 예산을 확인하여 공개 여부를 결정하는 단계이다.
- **노이즈 주입•예산 차감**: 승인된 결과를 무작위화하고 소비한 ε•δ를 기록하는 단계이다.

</details>

```text
보호 단위•인접성•ε•δ 예산 입력
        │
        ▼
1. 기여 한도•민감도 산정
        │
        ▼
2. 누적 예산 확인
        ├─ 예산 소진: 공개 거부
        └─ 예산 잔여
             │
             ▼
     3. 노이즈•공개 승인
             │
             ▼
     4. 노이즈 주입•예산 차감
             │
             └── 승인된 결과 반환
```

### 동작 원리

1. **기여 한도•민감도 산정**: **기여 한도**와 **민감도**로 개인 영향의 최대량을 계산한다.
2. **누적 예산 확인**: **프라이버시 회계**의 ε•δ 소비량을 대조한다.
3. **노이즈•공개 승인**: 오차 적용과 잔여 예산을 판정한다.
4. **노이즈 주입•예산 차감**: **노이즈 주입** 후 **예산 차감**으로 사용량을 기록한다.


#### 한줄 요약

- 같은 통계를 반복해서 보여 주면 오차를 평균낼 수 있으므로 공개할 때마다 누적 예산을 차감한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **중앙 DP**: 신뢰하는 수집자가 집계 결과에 노이즈를 넣는 방식이다.
- **로컬 DP**: 각 단말이 수집자에게 전송하기 전에 값을 무작위화하는 방식이다.
- **셔플 DP(Shuffle DP)**: 무작위화한 보고의 순서와 출처를 섞는 방식이다.

</details>

| 차등 프라이버시 방식 | 중앙 DP | 로컬 DP | 셔플 DP |
|:---|:---|:---|:---|
| 적용 기준 | 수집자를 신뢰하는 환경 | 수집자를 불신하는 환경 | 대규모 보고 수집 환경 |
| 핵심 특징 | **중앙 DP**로 수집자가 노이즈 적용 | **로컬 DP**로 단말 값을 무작위화 | **셔플 DP**로 보고 출처•순서 혼합 |
| 한계 | 원자료 유출 | 낮은 결과 정확도 | 셔플 서버 추적 위험 |

> 요약: 수집자 신뢰 범위로 DP 방식을 선택한다.

#### 한줄 요약

- 중앙 방식은 수집자가 원자료를 보고 오차를 넣고 로컬 방식은 단말에서 먼저 값을 흐리므로 신뢰 경계가 다르다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **차등 프라이버시 확률적 경사 하강법(Differentially Private Stochastic Gradient Descent, DP-SGD)**: 표본별 기울기를 제한하고 노이즈를 추가하는 학습 방식이다.
- **기울기 클리핑(Gradient Clipping)**: 학습 표본별 기울기 크기를 상한으로 제한하는 기법이다.
- **미국 국립표준기술연구소(National Institute of Standards and Technology, NIST)**: 미국의 기술 표준과 지침을 개발하는 기관이다.
- **특별 간행물(Special Publication, SP) 800-226**: 차등 프라이버시의 평가 요소와 구현상 위험을 제시하는 지침이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| DP 보장 평가 오류 | **NIST** **SP 800-226** 적용 | 과장된 보호 주장 방지 |
| 반복 질의•결합 | **프라이버시 회계**•공개 횟수 제한 | 누적 재식별 위험 억제 |
| 기여량 편차 | **기여 한도** 설정 | 민감도•노이즈 안정화 |
| 학습 표본의 기울기 노출 | **DP-SGD**•**기울기 클리핑** | 학습 데이터 영향 제한 |

#### 한줄 요약

- 공공 통계는 한 사람의 추가•삭제 중 무엇을 숨기는지 정하고 반복 공개에 쓸 예산을 기록한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **방식 선택 기준**: 수집자 신뢰 범위, 반복 공개 횟수, 허용 오차와 개인별 기여량을 함께 고려하는 결정 기준이다.

</details>

- **방식 선택 기준**에 따라 신뢰 수집자는 **중앙 DP**, 수집자를 신뢰하지 않으면 **로컬 DP**를 선택한다.

#### 한줄 요약

- 작은 예산만 고집하지 말고 숨길 개인 변화와 반복 공개 횟수, 결과에 허용할 오차를 함께 정한다.
