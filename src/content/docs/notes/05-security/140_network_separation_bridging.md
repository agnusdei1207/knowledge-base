## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **망분리 및 망연계 솔루션(Network Separation & Secure Data Bridging / NIST SP 800-53)**: 외부 인터넷망의 랜섬웨어 및 APT 공격 위협으로부터 내부 업무망과 핵심 데이터베이스(DB)를 원천 보호하기 위해 네트워크를 물리적/논리적으로 단절(망분리)하고, 업무상 필수적인 파일 및 데이터 교환을 위해 세션 종단(Session Termination) 기반의 중계 완충 영역에서 악성코드 무해화(CDR)와 개인정보 유출 방지(DLP)를 수행하는 보안 인프라.
- **다이렉트 통신 허용에 따른 보안 경계 붕괴 결함(Direct Bridge Pivot Defect)**: 망분리를 구축했음에도 불구하고 편의를 위해 내부망과 외부망 사이에 다이렉트 TCP 라우팅 터널이나 단순 포트 포워딩을 구성할 경우, 외부 침해 사고 발생 시 공격자가 망연계 통로를 피벗(Pivot) 삼아 내부 코어 DB로 하이패스 침투하는 구조적 결함.

</details>

- 정의/개념: 내부망 기밀성과 업무 연속성을 동시에 확보하기 위해 **망분리(물리적/논리적) $\rightarrow$ 망연계 중계 서버(IDMZ) 세션 종단 $\rightarrow$ 악성코드 탐지(Multi-AV) 및 CDR 무해화 $\rightarrow$ DLP 민감정보 검출 $\rightarrow$ 승인 기반 단방향/양방향 안전 전송 $\rightarrow$ 전수 감사 추적** 을 집행하는 **경계 격리 및 안전 자료 교환 아키텍처**
- 배경/필요성: 금융권(전자금융감독규정 제15조), 공공기관, 방위산업체의 필수 법적 의무 사항이나, 클라우드(SaaS) 도입 및 생성형 AI 활용 등 업무 혁신 요구에 부응하는 안전한 예외 연계 체계 필요

#### 한줄 요약
- 망분리로 직접 통신을 차단하고, 세션 종단 및 CDR/DLP 기반 망연계로 안전한 자료 전송을 보증한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **망연계 3대 핵심 통제 메커니즘**:
  - **세션 종단 (Session Termination)**: 외부망과 내부망 간의 TCP/IP 세션을 프록시 서버에서 완전히 단절하고, 파일 및 데이터 페이로드만을 추출하여 재구성 전송.
  - **콘텐츠 무해화 (CDR: Content Disarm & Reconstruction)**: 문서 파일(PDF, MS Office, HWP) 내의 악성 매크로, 자바스크립트 등 실행 요소를 제거하고 안전한 정적 요소만으로 재조립.
  - **승인 기반 통제 (Approval-based Governance)**: 결재권자의 전자 결재 승인 또는 자동 보안 정책 통과 시에만 한시적 전송 허용.

</details>

- **직접 연결 제로(Zero Direct Connection)**: 내·외부망 간 다이렉트 패킷 라우팅을 원천 불허하며, 중계 스토리지(공유 메모리/SAN)를 통한 간접 전송만 허용
- **심층 콘텐츠 정제 (Multi-tier Sanitization)**: 3개 이상의 상용 백신 교차 검사 + CDR 무해화 + DLP 정규식 패턴 검출을 단일 파이프라인에서 직렬 수행
- **불변 감사 추적성(Immutable Audit Trail)**: 파일 송수신 요청자, 승인자, 원본 및 무해화 해시값(SHA-256), 수신 완료 타임스탬프를 위·변조 불가능하게 영구 기록

#### 한줄 요약
- 세션 종단, CDR 콘텐츠 무해화, 다중 백신/DLP 검증, 불변 감사 추적성을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **망분리·망연계 5대 핵심 아키텍처 컴포넌트**:
  1. **External / Internal Network**: 인터넷 접속용 외부망 및 코어 데이터가 위치한 폐쇄 내부망.
  2. **Bridging Proxy (망연계 중계 서버)**: 양쪽 망의 세션을 물리적으로 분리 수신하는 프록시.
  3. **Shared Storage / Memory Buffer**: IEEE 1394, SAN, 또는 듀얼 포트 RAM 기반 완충 스토리지.
  4. **Security Inspection Engine**: Multi-AV, CDR, DLP 엔진이 탑재된 검문 파이프라인.
  5. **Data Diode (물리적 단방향 게이트웨이)**: 원자로/국방 등 특수 구역의 역방향 송신 원천 차단 장치.

</details>

```text
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 1. 외부 인터넷망 영역 (External Untrusted Network) ]                  │
│  └─ 외부 이메일, 웹서핑, 클라우드 SaaS ➔ [ 외부망 전송 클라이언트 ]    │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │ (1차 세션 연결: TCP Termination)
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 2. 망연계 보안 중계 영역 (DMZ / Bridging Security Gateway) ]           │
│  ├─ [ 세션 종단 프록시 ] ➔ 외부망 세션 즉시 절단 및 파일 페이로드 추출 │
│  ├─ [ 보안 검증 파이프라인 ]                                            │
│  │   ├─ 1. Multi-AV ➔ 3대 백신 엔진 교차 악성코드 스캔                  │
│  │   ├─ 2. CDR 무해화 ➔ 문서 내 악성 매크로/스크립트 제거 후 재구성     │
│  │   └─ 3. DLP 검출 ➔ 주민등록번호, 계좌번호 등 민감정보 반출 차단     │
│  └─ [ 완충 스토리지 ] ➔ 듀얼 포트 공유 메모리 / 격리 SAN 스토리지       │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │ (새로운 2차 내부 세션 생성)
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 3. 내부 업무망 영역 (Internal Trusted Network) ]                       │
│  └─ [ 내부망 수신 에이전트 ] ➔ SHA-256 무결성 검증 후 내부 업무 PC 수신 │
└─────────────────────────────────────────────────────────────────────────┘
```

선의 의미: 외부망 세션을 프록시에서 종단하고 보안 검증 파이프라인을 거쳐 완충 스토리지를 통해 내부망으로 안전하게 릴레이 전송하는 구조

| 컴포넌트 | 핵심 역할 및 기능 | 주요 기술 및 메커니즘 | 비고 |
|:---|:---|:---|:---|
| **망분리 인프라** | 인터넷망과 업무망의 네트워크 격리 | 물리적 2PC / 논리적 VDI (CBC/SBC) | Isolation |
| **세션 종단 프록시**| 네트워크 계층 다이렉트 통신 차단 및 세션 절단 | Dual-NIC Proxy, Protocol Termination | Gateway |
| **CDR 무해화 엔진**| 문서 내 실행 파일, 매크로, 임베디드 OLE 객체 제거 | Content Disarm & Reconstruction | Anti-Malware |
| **DLP 필터링 엔진**| 내부망에서 외부망으로의 개인정보 및 기밀 반출 차단 | 정규표현식, 머신러닝 데이터 분류 | Anti-Leakage |
| **완충 스토리지** | 양망 간 물리적 직접 통신 없이 데이터 교환 매개체 | 듀얼 포트 RAM, 공유 SAN, IEEE 1394 | Buffer |
| **단방향 데이터 다이오드**| 물리적 광케이블 분리로 역방향 신호 유입 100% 차단 | TX/RX 분리 광송수신기 (Fiber Diode) | Ultra Security |

#### 한줄 요약
- 망분리 인프라, 세션 종단 프록시, CDR/DLP 보안 검증 엔진, 완충 스토리지, 데이터 다이오드로 구성된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **망연계 안전 자료 반입 5단계 프로세스**:
  1. 외부망 사용자가 파일 전송 요청 및 부서장 결재 승인 획득
  2. 망연계 중계 서버로 파일 업로드 및 외부망 세션 종단
  3. Multi-AV 악성코드 스캔 및 CDR 매크로 무해화 수행
  4. 완충 스토리지를 경유하여 내부망 중계 서버로 페이로드 전송
  5. 내부망 수신자에게 파일 전달 및 감사 로그 불변 기록

</details>

```text
1. [자료 전송 요청 및 결재]
    ├─ 외부망 PC에서 엑셀 파일(거래처 견적서.xlsx) 전송 요청
    └─ [부서장 전자결재 승인 ➔ 망연계 서버로 전송 권한 인가]
            │
            ▼
2. [세션 종단 및 수신]
    ├─ 외부망 프록시가 파일 수신 완료 ➔ 외부망 TCP 세션 즉시 절단(Termination)
    └─ [파일 페이로드를 임시 격리 샌드박스 영역으로 이동]
            │
            ▼
3. [심층 보안 검증 및 무해화]
    ├─ [1단계 Multi-AV] 3종 백신 엔진 검사 (기존 알려진 악성코드 0건 확인)
    ├─ [2단계 CDR 엔진] 엑셀 내 VBA 매크로 및 외부 URL 하이퍼링크 강제 삭제
    └─ [3단계 클린 재구성] 무해화된 순수 데이터만으로 신규 엑셀 파일 재조립
            │
            ▼
4. [완충 스토리지 경유 내부 전송]
    ├─ 중계 서버 간 전용 통신 채널(비인가 접근 차단)을 통해 내부망 프록시로 전달
    └─ [SHA-256 해시값 대조 ➔ 전송 중 데이터 위·변조 0% 검증]
            │
            ▼
5. [내부망 전달 및 감사 로깅]
    ├─ 내부 업무 PC로 무해화된 엑셀 파일 다운로드 완료
    └─ [송수신자 정보 + 원본/무해화 파일 해시 + 결재 이력을 감사 서버에 영구 기록]
```

**동작 원리**

1. **프로토콜 격리**: 인터넷망의 악성 패킷이 네트워크 계층을 타고 내부망으로 라우팅되는 경로 원천 차단
2. **알려지지 않은 위협(Zero-day) 방어**: 시그니처 백신이 탐지하지 못하는 신종 악성코드도 CDR을 통해 실행 객체 자체를 제거하여 무력화
3. **내부자 유출 방어**: 외부로 나가는 파일에 대해 주민번호, 계좌번호 등 개인정보 패턴 검출 시 즉각 차단
4. **무결성 보증**: 전송 전후의 암호학적 해시 검증을 통해 전송 구간에서의 파일 변조 방지
5. **법적 증적성 확보**: 전자금융감독규정 및 개인정보보호법 준거성을 증명할 불변 감사 원장 확보

#### 한줄 요약
- 결재 승인, 세션 종단, CDR/Multi-AV 무해화, 완충 스토리지 중계, 내부 전달 및 감사 로깅 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **망연계 3대 기술 방식 비교**:
  - 스토리지 기반 파일 전송 (File Transfer): 비실시간 문서/배치 파일 전송 (높은 보안성).
  - 소켓/스트림 기반 실시간 연계 (Stream Bridging): 실시간 DB/API 동기화 (초저지연, 세션 종단 필수).
  - 물리적 단방향 데이터 다이오드 (Data Diode): 물리 광케이블 절단 단방향 전송 (최고 보안).

</details>

| 비교 항목 | 스토리지 기반 파일 전송 | 스트림/API 망연계 | 물리적 단방향 데이터 다이오드 |
|:---|:---|:---|:---|
| **전송 메커니즘** | **중계 스토리지(공유 디스크) 간접 교환**| **프록시 메모리 기반 실시간 세션 종단**| **하드웨어 광케이블 단방향 물리 전송** |
| **실시간성** | 비실시간 (결재/스캔 수 초~수 분 소요)| **초저지연 실시간 (수 ms ~ 수십 ms)** | 실시간 (단방향 스트리밍) |
| **주요 적용 업무** | **직원 업무 문서 반출입, 대용량 파일** | **실시간 DB 동기화, 내부-외부 API 연계**| **제어망(OT) 로그 수집, 원전/국방 감시**|
| **보안 강도** | 최상 (결재 및 CDR 전수 검사) | 높음 (화이트리스트 포트/API 한정) | **절대적 (물리적 역방향 침투 0%)** |
| **단점/한계** | 실시간 트랜잭션 처리 불가 | 한쪽 망 침해 시 연쇄 전파 위험 통제 필요| **역방향 ACK 신호 불가로 재전송 복잡**|

#### 한줄 요약
- 파일 전송은 문서 반출입, 스트림 연계는 실시간 API/DB 동기화, 데이터 다이오드는 최고 보안 단방향 전송에 사용된다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **NIST SP 800-53 (AC-4 정보 흐름, SC-7 경계 보호) 및 전자금융감독규정 제15조**: 망분리 및 안전한 망연계 구축 법규 가이드라인.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 망연계 중계 프록시의 세션 종단 설정 미흡으로 **외부망과 내부망 간의 직접 TCP 터널이 생성되어 외부 해커가 내부 코어 DB로 침투** | **NIST SP 800-53 SC-7 준수, 프록시 레벨의 완전한 세션 종단(Session Termination) 및 중계 스토리지 기반 간접 전송 강제** | 망연계를 통한 직접 침투 및 측면 이동 100% 원천 차단 |
| 승인된 외부 문서 파일 내에 지능형 제로데이 악성 매크로가 포함되어 **내부망 PC에서 실행 시 랜섬웨어 감염 및 내부 전산망 마비 발생** | **콘텐츠 무해화(CDR) 솔루션을 필수 연동하여 문서 내 매크로/스크립트를 완전 제거하고 정적 이미지/텍스트로 재구성 배포** | 문서 기반 제로데이 악성코드 감염 위험 99.9% 차단 |
| 금융권 망분리 규제로 인해 외부 생성형 AI 및 SaaS 클라우드 도입이 차단되어 **기업의 업무 생산성이 급격히 저하되는 문제 발생** | **금융위 망분리 규제 완화 로드맵 준수, SaaS 예외 승인 기준에 따라 단말 격리(RBI) 및 망연계 데이터 마스킹 통제 구축** | 컴플라이언스 100% 준수 하에 안전한 SaaS 업무 혁신 달성 |

#### 한줄 요약
- 세션 종단으로 침투를 막고, CDR 무해화로 제로데이를 방어하며, 단말 격리로 안전한 SaaS 혁신을 지원한다.

## Ⅶ. 결론

- 국가 핵심 기간시설, 금융 전산망, 기업 기밀 자산을 사이버 위협으로부터 방어하는 최후의 요새인 **망분리 및 망연계 아키텍처**는 보안성과 업무 생산성의 완벽한 균형을 추구하는 필수 보안 체계이며, 실무 구현 시 **전자금융감독규정 및 NIST SP 800-53 표준 정합성 확보**, **직접 연결을 배제한 철저한 세션 종단(Session Termination)**, **CDR 무해화 및 Multi-AV 기반의 무결점 콘텐츠 검증**, **생성형 AI 및 클라우드(SaaS) 도입을 위한 안전한 예외 통제 체계 구축**을 통합 완성하여 최고 수준의 경계 격리와 비즈니스 연속성을 완성

#### 한줄 요약
- 세션 종단 망연계와 CDR 콘텐츠 무해화를 통해 완벽한 망분리 보안 아키텍처를 완성한다.
