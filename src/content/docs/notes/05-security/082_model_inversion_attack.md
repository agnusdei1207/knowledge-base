## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **모델 역전 공격 (Model Inversion Attack)**: 학습된 머신러닝/딥러닝 모델의 출력 확률 벡터(Confidence Score)나 임베딩을 거꾸로 역추적하여, 학습에 사용된 개인의 안면 이미지, 유전자, 의료 기록 등 민감한 원본 데이터를 재구성 복원해내는 프라이버시 침해 공격이다.
- **학습 정보 노출 (Training Data Exposure)**: AI 모델이 학습 데이터셋에 포함된 특정 개인의 고유 특징을 과도하게 기억(Memorization)함에 따라 외부 API 질의를 통해 개인정보가 유출되는 현상이다.

</details>

- 정의: 블랙박스 또는 화이트박스 모델의 출력 신호(Confidence, Gradient)를 피드백으로 활용해 경사상승법으로 학습 데이터의 고유 특징을 복원해내는 **모델 역전 공격**이다.
- 배경: 과적합(Overfitting)된 모델이 API 추론 과정에서 불필요하게 정밀한 확률 벡터를 반환함에 따라, 이를 역산하여 발생할 수 있는 심각한 **학습 정보 노출** 및 개인 재식별 위험 때문이다.

#### 한줄 요약

- AI 모델의 출력 신뢰도나 내부 기울기를 최적화 알고리즘으로 역추적하여 학습에 사용된 민감 원본 데이터를 무단 복원하는 공격이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **신뢰도 (Confidence Score / Probability Vector)**: 모델이 예측 분류 결과에 부과한 각 클래스별 0~1 사이의 매우 정밀한 소수점 확률 값이다.
- **기울기 (Gradient / Loss Gradient)**: 화이트박스 환경에서 입력 변화에 대한 손실 함수의 변화율로써, 공격자가 복원 이미지를 업데이트하는 핵심 나침반 역할을 하는 수치이다.
- **사전 정보 (Prior Knowledge / Auxiliary Information)**: 공격 대상 집단의 평균 얼굴 이미지, 성별 분포 등 공격자가 사전에 보유하여 역전 탐색 초기값으로 활용하는 보조 데이터이다.
- **과적합 (Overfitting)**: 모델이 일반화(Generalization) 성능을 확보하지 못하고, 학습 샘플 개별의 세부 특징을 과도하게 암기해버린 상태이다.
- **DP (차분 프라이버시 / Differential Privacy)**: 데이터 학습 과정에 수학적 노이즈를 주입하여, 데이터셋 내 특정 1개 샘플의 포함 여부가 모델 출력 결과에 미치는 영향을 근본적으로 차단하는 철저한 방어 기술이다.

</details>

- **정밀 신호 기반 최적화**: 모델이 반환하는 세부 **신뢰도** 수치 및 **기울기** 정보를 피드백 받아 최적화 알고리즘(Gradient Ascent)으로 복원 픽셀을 정밀하게 다듬는 원리이다.
- **과적합 및 사전 정보 비례**: 공격자가 보유한 **사전 정보** 많고 대상 모델의 **과적합** 수준이 높을수록, 추출되는 원본 데이터의 복원 해상도와 유사도가 상승한다.
- **차분 프라이버시 방어**: 방어를 위해 **DP(Differential Privacy)** 기술을 적용, 학습 그래디언트에 노이즈를 섞음으로써 개별 샘플의 특성 복원을 원천 원천 차단한다.

#### 한줄 요약

- 정밀 신뢰도/기울기 기반 피드백 활용, 사전 정보 및 과적합 수준에 비례하는 복원 성능, DP(차분 프라이버시) 기반 방어 특성을 가진다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **복원 최적화기 (Reconstruction Optimizer)**: 경사상승법(Gradient Ascent) 또는 GAN을 활용하여, 대상 모델이 특정 클래스에 부여하는 확률 득점을 최대화하는 방향으로 입력 픽셀/데이터를 반복 업데이트하는 엔진이다.
- **프라이버시 평가 (Privacy Evaluation / Leakage Assessment)**: 복원된 이미지가 실제 특정 개인의 원본 데이터와 얼마나 유사한지 SSIM, PSNR, 안면 인식 정합률 수치로 정량 측정하는 평가 체계이다.

</details>

```text
[공격 사전 정보 템플릿] ---+
                          |
                          v
                    [복원 최적화기] <==== [정밀 확률 신호 피드백]
                          |                         |
                          |                         v
                          |                 [대상 AI 추론 모델 API]
                          v
                [프라이버시 유사도 정량 평가]
```

| 구성요소 | 주요 책임 및 역할 | 비고 |
|:---|:---|:---|
| **대상 모델 API** | 블랙박스 환경 질의에 대한 타깃 예측 결과 및 정밀 확률 **신뢰도** 수치 반환 | Target API |
| **출력 및 내부 신호** | 각 클래스별 확률 벡터(Softmax), 중간 임베딩, 화이트박스 **기울기** 정보 제공 | Signal |
| **사전 정보 템플릿** | 대상 집단의 평균 얼굴 템플릿 등 복원 알고리즘 최적화를 위한 초기값 제공 | Prior Knowledge |
| **복원 최적화기** | 경사상승법 기반 **복원 최적화기** 활용 통한 픽셀/속성 단위 반복 갱신 | Optimizer |
| **프라이버시 평가** | SSIM, PSNR 및 안면 인식 모델을 통한 복원 결과물의 실질적 개인 식별성 정량 판정 | Evaluator |

#### 한줄 요약

- 사전 정보 기반 초기화, 복원 최적화기(Gradient Ascent)를 통한 입력 갱신, 프라이버시 정량 평가 모듈의 식별성 판정 구조로 작동한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **반복 최적화 (Iterative Optimization)**: 무작위 초기 노이즈 이미지에 모델의 신뢰도 피드백을 적용해 대상 클래스 특징의 확률이 최대화될 때까지 수천 회 갱신하는 산술 과정이다.
- **유사성 (Similarity Metric)**: 복원된 이미지와 실제 학습 대상 개인 원본 이미지 간의 픽셀/구조적 유사도(SSIM)를 수치화한 지표이다.
- **식별성 (Identifiability / Re-identifiability)**: 복원 산출물만을 단서로 실제 특정 개인의 신원을 특정할 수 있는 정합 확률 수준이다.

</details>

```text
[공격 목표 및 사전 평균 정보]
              |
              v
1. 초기 복원 탐색 후보군 생성
              |
              +<--------------------------------------+
              |                                       |
              v                                       |
[대상 모델 API 반복 질의] ──> 2. 출력 확률 피드백 반환    |
              |                                       |
              v                                       |
3. 최적화 알고리즘 기반 후보 입력 데이터 역전 갱신 --+ (미수렴 시 반복)
              |
              v (확률 임계치 수렴 도달)
              |
4. 원본 개인과의 유사성 및 식별성 위험 평가
              |
              v
[프라이버시 침해 결과 모델 복원물 생성]
```

### 동작 원리

1. 후보 생성: 공격자가 사전 정보를 바탕으로 초기 최적화 노이즈 근거를 구성한다.
2. 피드백 수집: 대상 모델에 질의하고 도출된 정밀 확률 신호(Softmax)를 수집한다.
3. 역전 갱신: 확률 득점이 최대가 되도록 입력 픽셀을 반복 최적화 업데이트한다.
4. 프라이버시 판정: 재구성된 결과물이 실제 개인 식별 수준에 도달했는지 철저한 검증한다.

#### 한줄 요약

- 탐색 후보 생성, 대상 모델 질의, 확률 피드백 기반 경사상승 반복 최적화, 최종 유사성 및 식별성 정량 평가 순으로 진행된다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **회원 추론 공격 (Membership Inference Attack, MIA)**: 특정 데이터 샘플이 대상 모델의 학습 데이터셋에 포함되었는지 여부(In or Out)만 바이너리로 판정하는 프라이버시 공격이다.
- **모델 추출 공격 (Model Extraction Attack)**: 대량의 입력-출력 쌍을 수집 분석해 대상 상용 AI 모델의 지식재산권 가중치 및 판단 경계를 복제(Stolen Model)하는 자산 탈취 공격이다.

</details>

| AI 보안 공격 분류 | **모델 역전 (Model Inversion)** | **회원 추론 (Membership Inference)** | **모델 추출 (Model Extraction)** |
|:---|:---|:---|:---|
| 공격의 최우선 목적 | 학습에 쓰인 개인 민감 데이터 원본 자체의 시각적/속성적 **재구성 복원** | 특정 개인/데이터가 대상 학습 데이터셋에 **포함되었는지 여부 확인** | 대상 상용 AI 모델의 지적재산권(IP) 및 기능적 판단 경계의 **불법 복제** |
| 최종 공격 결과물 | 원본과 고도로 유사한 이미지/속성 재구성 산출물 | Binary 판단 확률 (학습 포함 1 / 미포함 0 확률 도출) | 대상 모델과 동일한 성능을 내는 복제 딥러닝 모델 (Surrogate Model) |
| 핵심 방어 기술 대책 | **DP(차분 프라이버시)** 학습 적용, API 반환 확률 **점수 양자화(Rounding)** | DP-SGD 기반 학습, 과적합(Overfitting) 억제 정규화 | 질의 API Rate Limiting, **질의 예산 통제**, 불필요한 출력 임베딩 은닉 |

#### 한줄 요약

- 모델 역전은 민감 원본 복원, 회원 추론은 포함 여부 판정, 모델 추출은 지식재산권 복제에 집중하는 공격 목표 차이점이 존재한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **NIST AI 100-2e2025 (Privacy in AI)**: AI 모델의 프라이버시 침해 위험(역전 공격, 회원 추론) 방어 및 차분 프라이버시 적용 방안을 제시하는 NIST 표준 지침이다.
- **출력 최소화 (Output Minimization)**: API 응답 시 Top-1 클래스 라벨만 반환하고, 역전 공격의 힌트가 되는 정밀 확률 벡터(Softmax)나 임베딩을 완벽히 은닉하는 방어 기법이다.
- **점수 양자화 (Score Quantization / Confidence Rounding)**: 소수점 이하 정밀 확률값을 소수점 1자리로 올림/버림 처리하여 역전 신호를 교란하는 철저한 방어 기술이다.
- **질의 예산 (Query Budget / Rate Limiting)**: 단일 계정/IP의 과도한 반복 질의를 제한하여 최적화 탐색 알고리즘 자체를 차단하는 네트워크 레벨 통제 특징이다.

</details>

| 장애/위험 요소 | 원인 분석 | 실무 대책 및 해결방안 | 기대 효과 |
|:---|:---|:---|:---|
| **AI 프라이버시 위협 표준 측정 지침 부재** | 프라이버시 위험 평가 기준 누락 | **NIST AI 100-2e2025** 규격 전면 적용 | 모델 배포 전 프라이버시 침해율 체계적 측정 및 거버넌스 확립 |
| **정밀 확률 벡터 제공을 통한 역전 탐색 가속** | API의 불필요한 Softmax 응답 과다 | **출력 최소화** (Top-1 반환) 및 **점수 양자화**(Rounding) 적용 | 공격자가 의존하는 경사상승 최적화 피드백 신호의 완전 무력화 |
| **모델 과적합에 따른 고유 개인 특징 암기 유출** | Training Loss 최소화 위주의 무분별한 학습 | **DP-SGD (Differential Privacy)** 기반 수학적 노이즈 학습 적용 | 개별 데이터 노드 유출 영향력 제한 및 법적 컴플라이언스 준수 |
| **자동화 봇의 대량 질의를 통한 최적화 연산** | API 호출 제한 로직 전무 | 봇 탐지 및 **질의 예산 (Query Budget)** 기반 Rate Limiting 적용 | 무차별 대입 기반 역전 공격 시도 횟수 차단 및 API 가용성 보호 |

#### 한줄 요약

- NIST AI 100-2e2025 준용, DP-SGD 노이즈 적용, 출력 최소화 및 점수 양자화를 바탕으로 역전 공격 시도를 근원적으로 차단한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **프라이버시-유용성 균형 (Privacy-Utility Tradeoff)**: DP(차분 프라이버시) 노이즈 주입으로 인해 필연적으로 발생하는 모델 추론 정확도(Utility) 하락과 프라이버시 보호 성능(Privacy) 간의 최적 운영 임계점 설정 작업이다.

</details>

- 안면/의료 등 민감 데이터 모델은 설계 단계부터 **DP-SGD** 활용 강제 적용하고, 공개 API는 불필요한 확률을 은닉하는 **출력 최소화** 정책 확립 필수이다.

#### 한줄 요약

- NIST 표준 준수, DP-SGD 기반 수학적 노이즈 학습, Softmax 점수 양자화(출력 최소화) 및 Rate Limit 중심 방어 아키텍처 적용 필수.
