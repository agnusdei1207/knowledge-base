## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **국정원 철퇴 사전 보안성 검토 (Security Review)**: 국가·공공기관이 수백억 세금을 들여 대국민 포털이나 행정망 IT 시스템 구축 사업을 발주할 때, 도면 계획 뼈대 단계부터 북한 해커에 뚫릴 취약 빵꾸가 없는지 국정원 가이드에 맞춰 정보보호 방패 대책의 적절성을 무관용으로 엑스레이 확인받는 강제 사전 심사 타격 절차이다.
- **국가정보원 절대 권력 NIS (National Intelligence Service)**: 대한민국 5천만 국민의 공공 행정망과 국가 안보 IT 시스템이 북한이나 외부 해커에 털리지 않도록, 살벌한 국가 정보보안 룰북 지침을 수립하고 공공기관 망분리 설계도를 도마 위에 올려 철저한 검증 통제하는 최고 안보 조사 권력 기관이다.

</details>

- 정의: 공공 정보화 IT 사업이 첫 삽을 뜨는 계획•설계 도면 단계에서, 절대 권력 **NIS** 룰북 지침에 따라 망분리 락킹 보안 요구와 해커 방패 보호대책을 사전에 엑스레이 확인 타격하는 무관용 **사전 보안성 검토 절차**이다.
- 배경: 건물 다 짓고 서버(구축 후) 다 돌려놨는데 나중에 털릴 거 같다고 국정원이 재설계를 때리면, 애초에 SI 업체 입찰 계약금에 빠져있던 보안 방화벽 장비 수십억을 추가로 사야 하는 비용 예산 붕괴와 이행 지연 마비를 사후에는 절대 통제 락다운 붕괴 불가능하기 때문이다.

#### 단기 요약

- 서버 장비 다 사서 조립한 뒤에 국정원에 검사받는 게 아니라, SI 업체 선정 발주서(RFP) 설계 도면을 짤 때부터 국가 안보망 해킹 빵꾸 방어 요구를 미리 락다운 확인 도장 받는 게 핵심 생존 팩트이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **기요틴 발주서 제안요청서 RFP (Request for Proposal)**: 공공기관이 "우리 이런 포털 100억에 만들 거니까 하청업체들 방화벽 스펙 어떻게 짤지 계획서 들고 와라"고 입찰 공고를 띄울 때, 시스템 기능 뼈대•망분리 보안 방어구 타겟 요구와 평가•테스트 검수 심판 기준을 1밀리미터 오차 없이 무관용 하드코딩 명시한 절대 법전 문서 팩트이다.

</details>

- **입찰 공고 전 RFP 도면 설계•해킹 방어 대책 하드코딩 반영**: 시스템 개발 사업을 공고 띄우기 전, 국정원 보안 지침을 **RFP** 설계 도면과 방화벽 쉴드 대책에 선제적으로 락킹 반영해 꽂아버리는 것이 핵심이다.
- **국가 데이터•망분리 핏줄•암호화 타격 위험의 사업 경계 엑스레이 검토**: 대국민 개인정보 데이터, 내/외부 연계망 망분리, 뚫리면 죽는 인증•암호화 치명적 빵꾸 위험을 발주 사업 핏줄 경계 도면에 따라 현미경 엑스레이 검토 타격한다.
- **국정원 심판 검토 보완 의견의 RFP•설계•최종 검수 덤프 추적 타격**: 국정원이 내린 "망분리 방화벽 2대 더 놔라"는 심판 지적 의견이, 단순히 문서로 안 끝나고 실제 RFP 발주서 ─> SI 설계 도면 ─> 서버 오픈 전 최종 검수 테스트까지 살아남아 1:1 구축됐는지 끝까지 강력히 무관용 덤프 추적한다.

#### 한줄 요약

- 행정안전부가 자체 엑스레이 검토로 끝낼지, 아니면 국정원 본원에 뼈대 심판을 의뢰할지는 그 시스템이 털렸을 때 국가 마비 타격이 얼마나 큰지 사업 위험 등급 유형과 위임 법적 락킹 기준에 따라 무관용 결정되는 게 핵심 팩트이다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **엑스레이 락다운 검토 범위 (Review Scope)**: 무지성으로 다 보는 게 아니라, 포털 사업 목적, 다루는 대국민 개인정보 데이터 등급, 뚫릴 네트워크 외부 핏줄 연결망, 도입할 해킹 쉴드 제품 버전, 타 시스템 연계 뼈대 구조를 잣대로 날카롭게 선을 그어 정한 치명적 사전 도면 심사 대상이다.
- **멱살 잡기 RFP 추적 (RFP Traceability)**: 국정원 심사관이 도면에 던진 "DB 암호화 모듈 추가해라"는 보완 지시 의견을, 하청업체 입찰 발주 요구서(RFP)에 강제 락다운하고, 실제 코딩 설계와 최종 납품 오픈 전 검수 테스트 결과 캡처 덤프까지 1:1로 징하게 연결해 살아 돌아갔는지 색출 추적하는 무관용 활동이다.

</details>

```text
[공공 망분리 뼈대 국가정보원 무관용 보안성 심사 타격 및 락다운 아키텍처]

├─ [1. 심사 타겟 도면 락킹 경계]
│    └─ [수백억 사업 도면 범위 · 엑스레이 검토 대상] (구축 타겟 목적 · 수집 대국민 정보 등급 · 도입 쉴드 기술 · 국정원 뚝배기 위임 잣대 기준)
│
├─ [2. 데이터 핏줄 유출 방어막 경계]
│    └─ [국가 데이터 정보 · 인터넷 외부 연계 엑스레이] (DB 스토리지 저장 락킹 · 암호화 연산 처리 · 외부 기관 망 연계 뚫림 전송 핏줄 경로 방어)
│
├─ [3. 철벽 망분리 도면 구성 경계]
│    └─ [업무/인터넷 망분리 · 클라우드 셋업 구성 락다운] (DMZ/내부망 격리 보안영역 · 외부 해커 침투 접점 · 방화벽 VPN 원격 접근 쉴드 경로 확인)
│
├─ [4. 기요틴 해킹 방패 및 보완 명령 경계]
│    └─ [철벽 보안대책 도면 · 국정원 심판 보완 검토 의견] (다중 MFA 인증 · 국정원 인증 암호화 모듈 · SI 업체 공급망 해킹 백도어 방어 보완 무관용 지시)
│
└─ [5. 보완 지시 끝장 추적 살생부 경계]
     └─ [기요틴 발주서 RFP · SI 설계 · 오픈 검수 덤프 무관용 추적] (국정원 지시 요구사항 1:1 하드코딩 매핑 · 서버 납품 오픈 전 구축 테스트 결과 캡처 팩트)
```

| 구성요소 | 핵심 보안 해부 책임 및 통제 타격 역할 |
|:---|:---|
| **사업 도면 범위•엑스레이 검토 대상** | **심사 락킹 검토 범위** 도면에 대국민 포털 목적•취급 정보•방어 기술•국정원 뚝배기 위임 잣대 기준 포함 |
| **국가 데이터 핏줄•외부 연계 뚫림 방어** | 대국민 정보 DB **저장**•**암호화 연산 처리**•타 기관 연동 **전송 핏줄 경로** 유출 엑스레이 분석 |
| **망분리 철벽•클라우드 도면 구성** | 업무/인터넷 내부 **격리 보안영역** 도면•망연계 침투 **외부 접점**•VPN 원격 **접근 통로 경로** 무관용 확인 |
| **기요틴 보안대책•심판 검토 보완 의견** | 해커 방패망 **다중 인증**•**국정원 검증 암호**•로그 감시•SI 하청업체 **공급망 백도어 백신 보완 지시** 타격 |
| **발주서 RFP•SI 설계•최종 검수 끝장 추적** | **멱살 잡기 RFP 추적** 락다운으로 국정원 보완 지시 요구와 실제 서버 납품 구축 테스트 결과를 1:1 연결 결속 |

#### 한줄 요약

- 국정원 심사관에게 우리가 만들 포털 사업 서버 뼈대 구조와 외부 인터넷으로 뚫린 정보 핏줄 흐름을 도면으로 보여 주고, 뚝배기 맞으며 받은 보완 지시 의견을 하청업체 발주서(RFP) 계약과 SI 서버 코딩 설계, 오픈 전 테스트 검수 덤프까지 빼도 박도 못하게 멱살 추적하는 게 핵심 생존 팩트이다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **기요틴 검토 보완 의견 락다운 반영 (Review Feedback Integration)**: 국정원 심사관이 때린 보안 빵꾸 지적 심사 결과를, SI 하청업체 조달 입찰 공고, 수백억 납품 계약 조건, 실서버 코딩 구축, 오픈 전 모의해킹 시험 통과 필수 조건 잣대로 무관용 하드코딩 연결 락킹해 버리는 활동이다.
- **국가 사업 핏줄 경계•파멸 위험•뚝배기 위임 근거 심판 검토 (Scope, Risk and Delegation Check)**: 이 100억짜리 포털 사업이 다루는 개인정보 등급 유형, 부처 간 네트워크 핏줄 경계, 해킹 뚫림 정보 흐름을 까발리고, 이걸 국정원 본원이 직접 검토할지 기관 자체 엑스레이 심판으로 위임 짬처리할 근거를 락킹 확인하는 진입 단계이다.
- **국정원 심판 보완 의견•해커 방패 요구 확정 타격 (Remediation Demand Finalization)**: 도면 엑스레이에서 발견된 망분리 빵꾸, 암호 모듈 자산 누락, 방화벽 통제 공백에 대한 살벌한 보강 개선 락다운 요구 지시를 서면으로 쾅 정해 때리는 단계이다.
- **기요틴 발주서 RFP•수백억 계약 보안 족쇄 조건 무관용 반영 (RFP and Contract Security Embedding)**: 국정원이 확정해 때린 보완 개선 지시 사항을 무시 못 하게 SI 하청 조달 발주 공고서와 법적 납품 계약 족쇄 기준표에 100% 때려 박는 단계이다.
- **SI 코딩 설계•서버 구축•오픈 전 검수 덤프 증적 무관용 검증 (Design, Build and Inspection Validation)**: 계약서대로 짠 서버 소스코드 보안 요구 구현 결과 캡처 덤프와, 해커 침투를 막고도 남은 시한폭탄 잔여위험 찌꺼기가 과징금을 안 맞을 수준인지 오픈 전 최종 엑스레이 확인 심판 타격하는 단계이다.

</details>

```text
[공공망 IT 구축 사업 도면 뼈대 구조 · 정보 연동 흐름 · 국정원 뚝배기 위임 근거 서류 투하]
               │
          [국가정보원 본원 심판 사전 보안성 검토 락다운 요청 발송]
               ▼
1. 국가 사업 핏줄 경계 도면 • 뚫림 파멸 위험 엑스레이 • 국정원 심판 위임 근거 검토
               │
          [국정원 엑스레이 심판 결과 및 해커 빵꾸 지적 보완 의견서 반환 하달]
               ▼
2. 기요틴 보안 빵꾸 보완 지시 의견 • 망분리 해커 방패 방어 요구 확정 타격
               │
               ▼
3. SI 기요틴 발주서 RFP 입찰 • 수백억 납품 계약 보안 족쇄 조건 강제 무관용 반영 락다운
               │
               ▼
4. SI 코딩 설계 도면 • 서버 납품 구축 완료 • 오픈 전 검수 덤프 캡처 증적 무결점 타격 검증
               │
               ▼
          [국정원 지시 사항 1:1 이행 증적 서류 · 폭탄 잔여위험 찌꺼기 최종 락킹 보고]
```

### 동작 원리

1. 국가 사업 경계·위험 핏줄·위임 근거 엑스레이 검토: 사업 파급 등급 유형·내외부 정보 흐름 도면 타겟 확인.
2. 기요틴 보안 보완 지시·방패 요구 확정 타격: 망분리 통제 공백 빵꾸·국정원 암호 모듈 개선 요구 강제 락킹 확정.
3. 조달 RFP·계약 보안 족쇄 반영: 국정원 심판 보완 지시 사항을 SI 하청 입찰 발주 잣대 기준에 무관용 100% 반영.
4. SI 설계·구축·오픈 전 검수 증적 검증: 서버 납품 캡처 이행 결과·과징금 잔여위험 찌꺼기 시한폭탄 최종 철저한 검증.

#### 한줄 요약

- 국정원 심사관에게 서면 검토 보완 의견서를 뚝배기 맞고 받아온 종이 쪼가리로 쇼를 끝내지 말고, 진짜 수백억 서버 납품 오픈 테스트 구축 결과 화면 덤프가 그 국정원 보완 지시 도면 의견대로 1비트 오차 없이 방화벽 세팅 구현됐는지 확인 락킹 멱살 추적해야 실전이다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **방화벽 엑스레이 심판 보안적합성 검증 (Security Assurance Verification)**: 도면 심사(보안성 검토)가 끝나고 실제 1억짜리 물리 방화벽 장비나 망연계 솔루션을 전산실 랙에 꽂아 도입 운용하기 직전에, 그 기계 박스 하드웨어의 CC 인증 통과 여부 안전성과 엉터리로 랜선을 안 꽂았는지 실제 IP 구성 적합성 핏줄을 확인 때리는 실장비 전용 검수 절차이다.

</details>

| 살벌한 공공망 국가 보안 심판 절차 | 설계 도면 심판 사전 보안성 검토 | 장비 박스 심판 보안적합성 엑스레이 검증 |
|:---|:---|:---|
| 엑스레이 타겟 적용 시점 기준 | 수백억 입찰 공고 전 **종이 도면 설계•RFP 방화벽 쉴드 보안 락킹 반영** | 실제 장비 랙 꽂기 1초 전 **물리 방화벽 도입 제품 랜선 구성 핏줄 안전 확인** |
| 치명적 핵심 파괴 특징 | 사업 전체 뼈대 **보안성 검토 도면**으로 망분리 전체 쉴드 보안대책 무관용 확인 | 1억짜리 단위 장비 **보안적합성 검증 CC 덤프**로 하드웨어 세팅 구성 적합성 엑스레이 확인 |
| 방어 시 맹점 한계 붕괴 | 서류 심사만 통과해 놓고 **SI 하청 납품 계약 구축 시 꼼수 미반영 치명타 맹점 위험 폭파** | 장비 CC 인증서만 믿고 샀는데 **펌웨어 버전 불일치 및 방화벽 룰셋 엉터리 설정 오픈 뚫림 참사** |

#### 한줄 요약

- 보안성 검토는 서버를 통째로 올리는 거대 100억짜리 '수도권 포털 구축 사업 전체 네트워크 도면 설계'를 국정원이 현미경 심판하는 거고, 보안적합성 검증은 거기에 들어가는 1억짜리 '안랩 방화벽 장비 박스 1대'의 해킹 안전성 스펙을 랙에 꽂기 전에 실제 CC 인증 덤프로 철저한 검증하는 게 핵심이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **국가 안보 절대 법전 전자정부법 제56조**: 행정기관의 공공 정보통신망 핏줄이 해커에 안 털리도록 예산 발라 해킹 방어망 안전성 쉴드를 무관용 확보하라고 때려 박은 절대 법적 락킹 근거이다.
- **국정원 심판 소환장 전자정부법 시행령 제69조**: 수백억 정보화 사업 첫 삽 뜨기 전 도면 단계에서, 무조건 국가정보원장을 소환해 사전 보안성 검토 심판 절차 뚝배기를 맞으라는 구체적 시행 락다운 법령 근거 팩트이다.
- **전 공공망 안보 룰북 국가 사이버보안 기본지침**: 국정원이 전국 모든 공공기관에 뿌린 절대 지침서로, 보안성 검토를 받아야 하는 시스템 타겟 대상 엑스레이, 심사 제출 서류 절차, "이건 알아서 심사해라"고 넘겨주는 자체 위임 짬처리 잣대 기준을 피 튀기게 정해놓은 바이블 문서 팩트이다.

</details>

| 뚫림 과징금 폭망 붕괴 전 치명적 평가 위험 요소 | 근본 원인 취약점 분석 | 최정예 실무 방어 대책 및 글로벌 해결방안 | 기대 철벽 통제 쉴드 방어 효과 |

#### 한줄 요약

- 수십억짜리 사업을 쪼개기 계약 꼼수로 발주하더라도, 국정원은 그 전체 서버 시스템 뼈대•대국민 DB 데이터•외부 인터넷 연계 핏줄 구조를 통짜 엑스레이 도면으로 묶어 치명적 타격 해킹 방어 보안 요구를 현미경 검토하고, 필요한 방화벽 통제를 SI 입찰 제안요청서(RFP) 족쇄와 최종 검수 오픈 기준에 무관용 락킹해 100% 반영해야 팩트가 산다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **SI 발주 전 도면 절대 반영 원칙 (Pre-Contract Integration)**: SI 업체에 돈 주고 계약 도장 찍은 후에는 보안 방화벽 추가를 절대 못 하므로, 그 수백억 계약 도장을 찍기 전 사업 초기의 기요틴 제안요청서(RFP)•납품 계약서•오픈 모의해킹 시험 잣대 기준에 무관용으로 국정원 방어 요구를 미리 락다운해 박아넣는 최상위 생존 원칙 팩트이다.

</details>

- **SI 발주 전 도면 족쇄 절대 반영** 타격 원칙에 따라, 포털 사이트 설계 도면과 입찰 RFP는 **사전 보안성 검토** 국정원 심판을 받고, 실제 전산실에 꽂힐 방화벽 기계 제품•펌웨어 버전•IP 구성 핏줄 세팅은 **보안적합성 엑스레이 검증** CC 덤프 심판을 이중 수행 타격한다.

#### 한줄 요약

- SI 하청업체와 계약 도장 찍고 시스템 다 만든 발주 뒤에 해커 빵꾸 위험을 찾아내면 그 방화벽 장비 추가하는 돈은 다 기관 세금으로 메꿔야 하므로, 계약 발주 전에 국정원 심판으로 엑스레이 빵꾸를 색출해 하청 계약 족쇄 문서에 미리 락킹해 넣어야 구축 비용 폭탄과 해킹 쉴드 통제 공백 붕괴를 100% 줄일 수 있다 필수.
