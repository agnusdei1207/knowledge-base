## 미리 알고가기

- **부채널 공격(Side-Channel Attack)**: 암호 수학이 아닌 시간·전력·전자기·캐시 등 구현 흔적에서 비밀을 추론하는 공격이다.
- **타이밍 공격(Timing Attack)**: 비밀값에 따른 실행 시간 차이를 반복 측정해 키·분기를 추론하는 공격이다.
- **단순 전력 분석(Simple Power Analysis, SPA)**: 단일 전력 파형의 특징에서 연산 순서·비밀을 추론하는 기법이다.
- **차분 전력 분석(Differential Power Analysis, DPA)**: 다수 전력 파형의 통계적 차이로 키 후보를 판별하는 기법이다.
- **캐시 공격(Cache Attack)**: 비밀 의존 캐시 적중·실패와 접근 시간을 관측해 메모리 패턴을 추론하는 공격이다.
- **마스킹(Masking)**: 비밀 중간값을 난수 공유값으로 나눠 단일 누설과 비밀의 상관을 약화하는 기법이다.
- **상수 시간(Constant-Time)**: 비밀과 무관하게 실행 경로와 메모리 접근 형태를 유지하는 구현 원칙이다.
- **결함 주입(Fault Injection)**: 전압·클록·빛으로 오류를 유도해 검사를 우회하거나 키를 추론하는 공격이다.
- **고차 누설(Higher-order Leakage)**: 여러 마스킹 공유값의 누설을 결합할 때 비밀과 상관이 나타나는 현상이다.
- **ISO/IEC 17825:2024**: 암호 모듈의 비침습 공격 완화 시험 지표를 규정한 국제표준이다.
- **ISO/IEC 20085-1:2019**: 비침습 공격 시험 도구와 신호 수집·분석 기법 요구사항을 규정한다.

## Ⅰ. 개요

- 정의/개념: 구현의 **물리·시간·공유자원 흔적으로 비밀 추론**
- 배경/필요성: 안전한 알고리즘의 **구현 누설 기반 키 탈취 방지**

### 쉽게 이해하기 (학습용)

- 금고를 직접 열지 않고 소리와 동작 시간 차이로 내부 번호를 알아내는 것과 비슷함

## Ⅱ. 특징

- 실제 장치·컴파일 결과의 **구현 종속성**
- 반복 측정·통계 분석의 **미세 누설 증폭**
- 로컬 센서·원격 공유자원의 **다양한 관측면**

### 쉽게 이해하기 (학습용)

- 같은 코드도 CPU·컴파일 옵션·배치가 바뀌면 누설 방식이 달라 실제 환경 검증이 필요함

## Ⅲ. 구조 및 구성요소

```mermaid
block-beta
  columns 1
  T["비밀 연산 표적"]
  C["시간·전력·EM·캐시 채널"]
  S["반복 입력·신호 수집"]
  P["정렬·필터·누설 모델"]
  V["통계 검정·키 복구 검증"]
  T --- C --- S
  S --- P --- V
```

| 구성요소 | 책임 |
|:---|:---|
| 비밀 연산 표적 | 키·분기·중간값 선정 |
| 시간·전력·EM·캐시 채널 | 공격자 관측 능력 정의 |
| 반복 입력·신호 수집 | 통제 입력·트리거·표본 |
| 정렬·필터·누설 모델 | 잡음 제거·예측값 생성 |
| 통계 검정·키 복구 검증 | 상관·분류·독립 재현 |

### 쉽게 이해하기 (학습용)

- 많은 흔적을 같은 시점에 맞춘 뒤 어떤 키 후보가 신호 변화와 가장 잘 맞는지 비교함

## Ⅳ. 흐름도

```mermaid
sequenceDiagram
  participant A as 공격자
  participant T as 표적 구현
  participant M as 측정기
  participant N as 분석기
  participant V as 검증 환경
  A->>T: 1. 통제 입력·반복 연산
  T->>M: 2. 누설 표본 수집·정렬
  M->>N: 3. 비밀 가설·누설 모델 생성
  N->>V: 4. 통계 분석·키 후보 추출
  V->>A: 5. 독립 복구·수정 후 재시험
```

**동작 원리**

- **1. 통제 입력·반복 연산**: 표적 중간값을 반복 유도
- **2. 누설 표본 수집·정렬**: 시간·전력·EM·캐시 측정
- **3. 비밀 가설·누설 모델 생성**: 후보별 중간값 누설 예측
- **4. 통계 분석·키 후보 추출**: 상관·분류·유의성 계산
- **5. 독립 복구·수정 후 재시험**: 실제 키 복구·잔여 누설 확인

### 쉽게 이해하기 (학습용)

- 신호 차이만 보지 않고 실제 키 복구가 되는지와 수정 후에도 남는 누설을 확인함

## Ⅴ. 종류 및 비교

| 구현 공격 유형 | 타이밍·캐시 | 전력·EM | 결함 주입 |
|:---|:---|:---|:---|
| 적용 기준 | 원격·공유 자원 관측 | 장치 근접 신호 측정 | 물리 자극으로 연산 교란 |
| 핵심 특징 | 시간·접근 패턴 분석 | 다수 파형 통계 분석 | 오류 결과·검사 우회 |
| 한계 | 반복 측정으로 분기 노출 | 키와 중간값 상관 노출 | 인증 우회·키 추론 |

> 요약: 관측형 부채널과 능동형 결함 주입을 구분함

### 쉽게 이해하기 (학습용)

- 부채널은 실행 흔적을 읽고 결함 주입은 실행 자체를 흔든다는 차이가 있음

## Ⅵ. 실무 고려사항 및 대책

| 고려사항 | 대책 | 효과 |
|:---|:---|:---|
| 비침습 누설 시험 | **ISO/IEC 17825:2024 적용** | 시험 지표·판정 일관성 |
| 측정 도구·교정 | **ISO/IEC 20085-1:2019 적용** | 신호 수집·분석 재현성 |
| 비밀 의존 실행 흔적 | **상수시간·마스킹·격리 적용** | 시간·통계 상관 약화 |

### 쉽게 이해하기 (학습용)

- 소스뿐 아니라 컴파일된 코드를 확인하고 실제 장치에서 고차 누설과 독립 키 복구까지 재시험한다.

## Ⅶ. 결론

- **누설 모델·측정 능력·성능·잔여위험**으로 대책을 결정한다.

### 쉽게 이해하기 (학습용)

- 안전한 알고리즘도 실행 흔적이 비밀을 말하지 않도록 구현해야 비로소 안전함
