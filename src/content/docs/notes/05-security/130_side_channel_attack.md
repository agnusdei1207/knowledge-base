## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **사이드채널 공격(Side-Channel Attack, SCA / 부채널 공격 / ISO/IEC 17825)**: 암호 알고리즘의 수학적 취약점을 공격하는 대신, 암호 모듈이 하드웨어(스마트카드, 암호화 칩, CPU) 상에서 실제로 동작할 때 필연적으로 발생하는 물리적 부산물(연산 시간, 소비 전력 파형, 전자기파 방사, 캐시 메모리 접근 패턴)을 측정하고 통계적으로 분석하여 내부에 은닉된 비밀 암호키를 역추론하는 물리적 분석 공격 기법.
- **수학적 암호 강도와 물리적 구현 간의 간극 결함(Cryptographic Implementation Gap Defect)**: AES-256이나 RSA-2048 등 수학적으로는 무차별 대입이 불가능한 강력한 암호 알고리즘이라 하더라도, 이를 실리콘 칩 상에서 구동할 때 데이터 값(0 또는 1)과 연산 종류에 따라 미세한 전력 소비량이나 연산 시간의 차이가 발생하여 비밀키가 외부 물리 신호로 누출되는 구조적 결함.

</details>

- 정의/개념: 하드웨어 암호 연산의 물리적 누출을 차단하기 위해 **암호 연산 중 물리 신호(시간/전력/전자기파/캐시) 수집 $\rightarrow$ 노이즈 필터링 및 파형 정렬(Trace Alignment) $\rightarrow$ 누설 모델(Hamming Weight/Distance) 수립 $\rightarrow$ 통계적 상관 분석(CPA/DPA) $\rightarrow$ 비밀키 복원 $\rightarrow$ 방어 대책(상수 시간/마스킹/차폐) 구현** 을 집행하는 **하드웨어 암호 안전성 분석 체계**
- 배경/필요성: 수학적으로 안전해도 구현 신호에서 **비밀키 누출 가능**

#### 한줄 요약
- 암호 연산 시 발생하는 전력, 시간, 전자기파 등 물리적 누설 신호를 통계 분석하여 비밀키를 탈취하는 공격이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **사이드채널 공격 3대 주요 분석 메커니즘**:
  - **DPA / CPA (Differential / Correlation Power Analysis)**: 수천~수십만 개의 전력 소비 파형과 가설 중간값 간의 피어슨 상관계수(Pearson Correlation)를 계산하여 올바른 키를 판별하는 기법.
  - **Timing Attack (시간차 공격)**: 암호키 비트(0 vs 1)에 따라 실행되는 IF 조건문의 실행 시간 차이를 측정하여 키를 역추론하는 기법.
  - **Cache Attack (캐시 공격: Flush+Reload)**: 멀티코어 CPU 환경에서 공격자가 공유 라이브러리 캐시 라인을 비우고(Flush), 피해자의 메모리 접근 여부를 재접근 시간(Reload)으로 측정하는 기법.

</details>

- **비침습적(Non-invasive) 특성**: 칩 패키지를 물리적으로 훼손(Decapsulation)하지 않고 외부 전원선이나 프로브 안테나 접촉만으로 공격 수행 가능
- **구현 방식 종속성(Implementation Dependency)**: 동일한 암호 표준(AES)이라도 소프트웨어 컴파일러 최적화, CPU 파이프라인, 보드 레이아웃에 따라 취약성 격차 발생
- **고차 누설(Higher-order Leakage) 분석**: 1차 마스킹(Masking) 난수 분할을 적용하더라도 2개 이상의 누설 지점을 통계적으로 결합 분석하여 마스킹을 무력화 가능

#### 한줄 요약
- 비침습적 공격, 하드웨어 구현 종속성, DPA/CPA 통계 분석, 마스킹 무력화 고차 누설 분석을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **사이드채널 공격 및 방어 4대 핵심 아키텍처 컴포넌트**:
  1. **Leakage Acquisition System**: 오실로스코프, EM 니어필드 프로브, 전력 측정 저항(Shunt).
  2. **Signal Pre-processing**: 파형 트리거 정렬(Alignment), 밴드패스 필터링, 노이즈 제거.
  3. **Statistical Analysis Engine**: 해밍 웨이트(Hamming Weight) 모델 및 CPA 상관계수 연산기.
  4. **Countermeasure Layer**: Constant-time 코딩, 불린 마스킹(Boolean Masking), 전력 균일화(Hiding).

</details>

```text
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 1. 물리 신호 계측 계층 (Physical Leakage Measurement Layer) ]         │
│  ├─ [ 전력선 / EM 프로브 ] ➔ 타겟 암호 칩(AES/RSA) 연산 파형 계측      │
│  └─ [ 고속 오실로스코프 ➔ 수만 회 연산 파형(Traces) 수집 및 디지털 변환 ]│
└────────────────────────────────────┬────────────────────────────────────┘
                                     │ (원시 파형 데이터 수집)
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 2. 신호 전처리 및 정렬 계층 (Trace Pre-processing & Alignment) ]       │
│  ├─ [ 1. 타임라인 정렬 ] ➔ 연산 시작 클록 시점을 1:1 일치(Alignment)   │
│  └─ [ 2. 노이즈 필터링 ] ➔ 밴드패스 필터로 주변 환경 고주파 잡음 제거   │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │ (정제된 파형 데이터셋)
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 3. 통계적 누설 분석 계층 (Statistical Correlation Engine: CPA/DPA) ]  │
│  ├─ 1. 가설 키(Key Guess 0~255)에 따른 중간값(S-Box 출력) 계산         │
│  ├─ 2. 해밍 웨이트(Hamming Weight) 기반 전력 소비 예측 모델 생성       │
│  └─ [ 3. 실측 파형과 예측치 간의 피어슨 상관계수($\rho$) 계산 ➔ 올바른 키 적중]│
└────────────────────────────────────┬────────────────────────────────────┘
                                     │ (취약점 식별에 따른 방어선 적용)
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 4. 3대 하드웨어/소프트웨어 방어 계층 (Countermeasure Implementations) ] │
├───────────────────┬───────────────────┬─────────────────────────────────┤
│ [ 1. 시간 균일화 ]│ [ 2. 마스킹 ]     │ [ 3. 하이딩 (Hiding) ]          │
│ ├─ Constant-time  │ ├─ 불린/산술 난수 ├─ 더미 연산 주입 (Noise)         │
│ └─ 분기문 조건 제거│ └─ 중간값 무작위화│ └─ 듀얼 레일(Dual-rail) 전력균일│
└───────────────────┴───────────────────┴─────────────────────────────────┘
```

선의 의미: 물리 신호를 계측하고 전처리한 후 통계 분석을 통해 키를 추출하며, 이에 대응하여 3대 방어 기제를 적용하는 구조

| 컴포넌트 | 핵심 역할 및 기능 | 주요 메커니즘 및 수식 | 비고 |
|:---|:---|:---|:---|
| **계측 시스템 (Acquisition)** | 타겟 칩의 연산 시 소비 전력 및 전자기 방사 신호 캡처 | 오실로스코프, EM Near-field Probe | Hardware |
| **파형 정렬 (Alignment)** | 클록 지터(Jitter)로 인해 어긋난 파형의 시점을 일치 | SAD(Sum of Absolute Differences), FFT | Pre-process |
| **누설 모델 (Leakage Model)**| 데이터 버스 비트 전환 시 발생하는 전력 소비량 수학적 모델링 | 해밍 웨이트($HW$), 해밍 거리($HD$) | Modeling |
| **상관 전력 분석 (CPA)** | 실측 파형과 가설 전력 모델 간의 피어슨 상관계수 산출 | $\rho = \frac{Cov(T, P)}{\sigma_T \sigma_P}$ | Analysis |
| **마스킹 (Masking)** | 암호 중간값에 난수 마스크($m$)를 적용하여 통계적 상관성 파괴 | $V' = V \oplus m$ (Boolean Masking) | Countermeasure|

#### 한줄 요약
- 계측 시스템, 파형 정렬 전처리, 해밍 웨이트 CPA 분석 엔진, 3대 방어 계층(상수시간/마스킹/하이딩)으로 구성된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **DPA/CPA 사이드채널 공격 5단계 시퀀스**:
  1. 타겟 암호 칩에 서로 다른 $N$개의 평문 입력 및 암호 연산 수행
  2. 오실로스코프를 통해 $N$개의 전력 소비 파형(Power Traces) 수집
  3. 파형의 시간축 정렬(Alignment) 및 노이즈 필터링
  4. 256개 서브키 가설에 따른 S-Box 중간값 전력 예측 모델 생성
  5. 실측 파형과 예측치 간의 상관계수 피크(Peak)를 검출하여 비밀키 확정

</details>

```text
1. [자극 인가 및 파형 수집]
    ├─ 암호 칩에 $N=10,000$개의 무작위 평문($P_1, P_2, \dots, P_N$) 입력
    └─ [AES 1라운드 실행 시 발생하는 전력 소비 파형 $T_1(t), \dots, T_N(t)$ 캡처]
            │
            ▼
2. [파형 전처리 및 정렬]
    ├─ 교차 상관(Cross-correlation) 알고리즘을 통해 파형의 타임라인 정렬
    └─ [고주파 노이즈 제거 ➔ S-Box 연산이 일어나는 클록 구간 핀셋 추출]
            │
            ▼
3. [가설 전력 모델 생성]
    ├─ 1바이트 서브키 후보 $K_{guess} \in [0, 255]$ 가정
    ├─ 중간값 $V = \text{S-Box}(P \oplus K_{guess})$ 계산
    └─ [해밍 웨이트 모델 적용 ➔ 예상 소비 전력 벡터 $H = HW(V)$ 산출]
            │
            ▼
4. [CPA 피어슨 상관계수 산출]
    ├─ 실측 파형 $T(t)$와 가설 전력 $H$ 간의 상관계수 $\rho(K_{guess}, t)$ 계산
    └─ [256개 서브키 후보 중 압도적인 상관계수 피크($\rho > 0.8$)를 보이는 키 식별]
            │
            ▼
5. [비밀키 복원 및 방어 검증]
    ├─ 16개 서브키 바이트에 대해 반복 수행 ➔ 128비트 마스터 AES 키 복원 완료
    └─ [마스킹 및 Constant-time 패치 적용 ➔ 상관계수 $\rho \approx 0$ 검증(방어 성공)]
```

**동작 원리**

1. **자극 인가 및 파형 수집**: 다수 평문 연산의 소비 전력 측정
2. **파형 전처리 및 정렬**: 시간축을 맞추고 잡음 제거
3. **가설 전력 모델 생성**: 서브키별 해밍 웨이트 계산
4. **CPA 피어슨 상관계수 산출**: 실측값과 예측값의 상관 비교
5. **비밀키 복원 및 방어 검증**: 키 복원 후 누설 감소 확인

#### 한줄 요약
- 파형 수집, 타임라인 정렬, 가설 전력 모델링, CPA 상관계수 산출, 마스터키 복원 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **하드웨어 물리 분석 공격 3대 유형 비교**:
  - 수동적 부채널 공격 (Passive SCA): 신호를 측정만 하고 칩을 훼손하지 않음 (DPA/EMA/Timing).
  - 능동형 결함 주입 공격 (Fault Injection): 레이저/전압 글리치로 연산 오류를 유도 (DFA/BFA).
  - 침습적 물리 공격 (Invasive Attack): 칩 패키지를 산으로 녹이고 직접 버스 프로빙 (FIB/SEM).

</details>

| 비교 항목 | 수동적 부채널 공격 (Passive SCA) | 능동형 결함 주입 공격 (Fault Injection) | 침습적 물리 공격 (Invasive Probing) |
|:---|:---|:---|:---|
| **공격 방식** | **소비 전력, 전자기파, 시간 '측정'** | **전압 글리치, 레이저 충격 '주입'** | **칩 디캡 후 물리적 프로브 '접촉'** |
| **칩 물리적 영향** | **비침습적 (칩 손상 0%)** | 준침습적/비침습적 (일시적 오작동 유도)| **완전 침습적 (칩 물리적 영구 파괴)**|
| **공격 메커니즘** | 통계적 상관 분석(CPA), 타이밍 분석| 오류 주입 후 에러 출력 차분 분석(DFA)| 내부 버스 라인 신호 직접 스니핑 |
| **공격 장비 비용** | 중간 (오실로스코프, 프로브) | 높음 (펄스 레이저, 정밀 글리치 발생기)| **초고가 (FIB 집속이온빔, 전자현미경)**|
| **핵심 방어 대책** | **Constant-time, 불린 마스킹, 차폐** | **이중 연산 검증, 클록/전압 감지 센서**| **하드웨어 능동형 쉴드(Active Shield)** |

#### 한줄 요약
- 수동적 SCA는 신호 측정, 결함 주입은 강제 오작동 유도, 침습적 공격은 물리 칩 분해 프로빙이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **ISO/IEC 17825 및 TVLA (Test Vector Leakage Assessment)**: 암호 모듈의 비침습적 공격 저항성 평가 표준 및 통계적 t-테스트 기반 누설 검증 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 소스코드 내 비밀번호/키 비교 시 `memcmp` 등 조건 분기문을 사용하여 **비교 시간 차이로 인해 암호키가 원격에서 유출되는 Timing Attack 발생** | **상수 시간(Constant-time) 비교 함수(`CRYPTO_memcmp`)를 적용하여 입력값과 무관하게 항상 일정한 CPU 클록 소요 강제** | 시간차 기반 사이드채널 정보 유출 100% 원천 차단 |
| 스마트카드 암호 칩에서 AES 연산 시 발생하는 전력 소비 파형을 분석하여 **10만 회 측정만으로 128비트 마스터키가 전면 탈취되는 DPA 공격 발생** | **암호 연산 중간값에 하드웨어 난수를 결합하는 고차 불린 마스킹(Boolean Masking) 및 더미 사이클 주입(Hiding) 구현** | 전력 파형과 키 간의 통계적 상관계수 0 달성 및 DPA 방어 |
| 가상화 클라우드 환경에서 타 테넌트 가상머신이 공유 CPU 캐시를 모니터링하여 **피해자 VM의 RSA 복호화 개인키를 탈취하는 Flush+Reload 캐시 공격** | **코어 간 캐시 분할(Intel CAT), 캐시 라인 비의존적 알고리즘 구현 및 하이퍼스레딩 격리 정책 수립** | 마이크로아키텍처 캐시 사이드채널 공격 100% 원천 봉쇄 |

#### 한줄 요약
- 상수 시간 코딩으로 타이밍 공격을 막고, 불린 마스킹으로 DPA를 무력화하며, 캐시 분할로 Flush+Reload를 차단한다.

## Ⅶ. 결론

- 시간 누설은 **상수 시간**, 전력 누설은 **마스킹·하이딩** 적용

#### 한줄 요약
- ISO/IEC 17825 표준과 상수 시간 코딩 및 불린 마스킹/하이딩을 통해 완벽한 사이드채널 방어망을 완성한다.
