## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **안전한 다자간 연산(Secure Multi-Party Computation, MPC)**: 여러 참여자가 각자의 원본 입력을 공개하지 않고 정해진 함수의 결과만 공동 계산하는 기술이다.
- **프라이버시 강화 기술(Privacy-Enhancing Technology, PET)**: 데이터 활용 과정에서 원본 노출과 개인 식별 가능성을 줄이는 기술군이다.

</details>

- 정의/개념: 원본 입력을 숨기고 함수 결과만 계산하는 **안전한 다자간 연산**
- 배경/필요성: 기관 간 원본 통합은 **개인정보•영업비밀 유출** 위험이 있다.

#### 한줄 요약

- 원본 데이터의 중앙 집합 없이 조각화된 상태에서 상호 협업 연산(PET)을 수행하여 데이터 프라이버시 보호

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **공모(Collusion)**: 일부 부정 참여자들이 자신들의 비밀 조각과 중간 연산값을 상호 결합하여 다른 정직한 참여자의 원본 입력값을 역추론하는 행위.
- **반정직 공격자(Semi-Honest / Passive Adversary)**: 규정된 연산 프로토콜은 성실히 수행하지만, 중간 교환 메시지를 수집·분석하여 타인의 비밀을 추론하려는 위협 모델.
- **악의적 공격자(Malicious / Active Adversary)**: 연산 도중 위변조된 입력/조각을 투입하거나 도중에 메시지 전송을 중단하여 결과를 왜곡하려는 위협 모델.
- **반복•세분 출력 추론(Differential Inference Attack)**: 연산 결과 출력값의 범위나 참여자 구성을 변형시켜 다수 회 질의함으로써 특정 개인의 입력값을 역산하는 위협.

</details>

- 참여자 간 **공모** 가능 인원수에 대한 임계치($m$-of-$n$) 설정이 비밀성의 성패 결정
- 프로토콜 요구 수준에 따라 **반정직 공격자** 또는 **악의적 공격자** 모델에 대응하는 보안 검증 설계
- 연산 결과의 **반복•세분 출력 추론**을 통한 원본 역추적 방지용 출력 제약 정책 연동

#### 한줄 요약

- 참여자 공모(Collusion) 허용 임계값 산정, 반정직/악의적 위협 모델 대응 및 반복 조회 결괏값 역추론 방지

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **비밀 분산(Secret Sharing)**: 원본 데이터를 여러 개의 무작위 조각(Share)으로 분할하여 지정된 임계치 수량 이상이 모여야만 원본 복구가 가능케 하는 기술 (Shamir 등).
- **비버 트리플(Beaver Triple)**: 비밀 분산 환경에서 곱셈 연산 시 요구되는 고비용 통신량을 줄이기 위해 오프라인 전처리 단계에서 무작위 튜플을 미리 생성하는 기법.
- **메시지 인증 코드(Message Authentication Code, MAC)**: 악의적 참여자의 중간 연산 조각 위변조를 실시간 검증하기 위한 인증값.
- **출력 정책(Output Policy)**: 연산 결과를 복구 및 수용할 수 있는 대상, 범위 및 최대 조회 횟수를 규정하는 제어 정책.
- **재구성기(Reconstructor)**: 각 참여자로부터 수집된 결과 조각의 MAC 무결성을 검증하고 임계치 조건을 확인하여 최종 출력을 결합 복구하는 모듈.

</details>

```text
MPC 공동 연산 구조
├─ 참여자 A
├─ 참여자 B
├─ 참여자 C
├─ 전처리 저장소
└─ 출력 정책•재구성기
```

가지의 의미: 참여자별 조각 보관, 오프라인 전처리 재료 준비, 무결성 검증 및 결합 복구 책임을 분리한 구조

| 구성요소 | 책임 |
|:---|:---|
| 참여자 A, B, C | **비밀 조각•중간 상태** 보관•연산 |
| 전처리 저장소 | **비버 트리플•MAC 재료** 제공 |
| 출력 정책•재구성기 | **출력 정책•MAC•임계값** 검증 후 복구 |


#### 한줄 요약

- N개 참여자, 비버 트리플(Beaver Triple) 전처리, MAC 무결성 검증 및 출력 재구성기 아키텍처

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **임계값(Threshold, $m$)**: 전체 $n$개 조각 중 원본 비밀을 재구성하거나 연산을 완결하는 데 필요한 최소 조각의 수.
- **재구성(Reconstruction)**: 각 참여자가 계산한 결과 조각들을 모아 무결성을 확인하고 최종 결괏값을 복원하는 단계.
- **전처리 재료 적용**: 오프라인 비버 트리플 및 MAC 검증용 난수 재료를 사전에 배정하는 단계.
- **비밀 조각 공동 연산**: 원본 노출 없이 비공개 조각 상태에서 덧셈/곱셈 회로를 연산하는 단계.
- **결과 조각 MAC 검증**: 악의적 참여자의 조각 변조 여부를 MAC 기반으로 판정하는 단계.
- **허용 결과 재구성**: 출력 정책을 충족한 조각들을 임계치 이상 결합하여 최종 결과만 복구하는 단계.

</details>

```text
참여자별 입력 조각 제출
        │
        ▼
1. 전처리 재료 적용
        │
        ▼
2. 비밀 조각 공동 연산
        │
        ▼
3. 결과 조각 MAC 검증
        ├─ 실패: 공동 연산 중단
        └─ 성공: 검증된 결과 조각 전달
                         │
                         ▼
              4. 허용 결과 재구성
                         │
                         └── 허용 결과 반환
```

### 동작 원리

1. 전처리 재료 적용: 비버 트리플 및 MAC 무결성 검증용 난수 오프라인 생성 및 배정
2. 비밀 조각 공동 연산: 참여자별 비밀 조각 상태에서 덧셈 및 비버 트리플 활용 곱셈 연산 수행
3. 결과 조각 MAC 검증: 검증 키 기반 MAC 연산을 통한 중간/결과 조각의 악의적 위변조 탐지
4. 허용 결과 재구성: 출력 정책 심사 통과 및 임계치($m$-of-$n$) 이상 수집 시 최종 결과만 안전 복구


#### 한줄 요약

- 전처리 무작위 재료 배치, 비밀 조각 기반 공동 연산, MAC 검증 및 임계값(Threshold) 이상 조각 결합 재구성 흐름

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **가블드 회로(Garbled Circuit)**: 야오 프로토콜로 회로의 진리표와 와이어 값을 암호화하여 2인 연산을 수행하는 방식.
- **동형 암호(Homomorphic Encryption)**: 암호화된 상태에서 수학적 연산을 직접 수행하는 공개키 암호화 기술.

</details>

| MPC 방식 | **비밀 분산 MPC** | **가블드 회로 MPC** | **동형 암호 기반 MPC** |
|:---|:---|:---|:---|
| 적용 기준 | 덧셈•곱셈 중심의 다자간 통계 연산 | 2인 간 비등가 비교•조건문 분기 정책 | 통신 라운드를 최소화해야 하는 다자 집계 |
| 핵심 특징 | **비밀 분산** 기반 산술 연산 | **가블드 회로** 진리표 암호화 평가 | **동형 암호** 암호문 상태 연산 |
| 한계 | 통신 라운드(Round) 수 증가 및 전처리 오버헤드 | 회로 규모 비례 통신량 폭증 | 높은 암호문 크기 및 계산 비용 |

> 요약: 연산 함수 유형(산술 vs 분기 논리) 및 네트워크 통신 한계에 따른 MPC 기법 선택

#### 한줄 요약

- 산술 연산 중심의 비밀 분산(Secret Sharing), 논리 분기 중심의 가블드 회로(Garbled Circuit), 동형 암호 기반 MPC 선택

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **ISO/IEC 4922-1:2023(ISO/IEC 4922-1 Standard)**: MPC의 기본 개념, 프레임워크 및 일반 요구사항을 규정한 국제 표준.
- **ISO/IEC 4922-2:2024(ISO/IEC 4922-2 Standard)**: 비밀 분산 기반 MPC의 구체적 프로토콜과 보안 연산 절차를 규정한 국제 표준.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| MPC 시스템 및 역할 기준 불일치 | **ISO/IEC 4922-1** 준수 | 역할, 용어 및 보안 모델 해석 표준화 |
| 비밀 분산 프로토콜 상호운용성 부족 | **ISO/IEC 4922-2** 준수 | 조각 연산 및 무결성 검증 상호운용 확보 |
| 공모 및 반복 출력을 통한 역추론 | **임계값($m$) 및 출력 제약 정책** 적용 | 개인 원본 데이터 역산 추론 차단 |

#### 한줄 요약

- ISO/IEC 4922-1/2 표준 준수, 공모 임계치(m-of-n) 설정, MAC 무결성 및 출력 제약 정책 연동

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **MPC 방식 선택(MPC Method Selection)**: 데이터 정밀도, 산술/논리 구조, 통신 오버헤드 및 공모 위협 모델을 종합 고려한 설계 지침.

</details>

- 연산 속성(산술 vs 논리) 및 환경에 따라 **비밀 분산** 또는 **가블드 회로** 방식을 선택하고 엄격한 **출력 통제 정책** 적용

#### 한줄 요약

- **MPC 방식•공모 임계값•출력 정책**을 함께 결정
