## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **MPC (Secure Multi-Party Computation)**: 복수의 참여자가 비밀 입력을 공개하지 않고 협력하여 목표 함수의 연산 결과만을 도출하는 암호 기술.
- **Yao's Millionaires' Problem (야오의 백만장자 문제)**: 실제 재산 액수를 밝히지 않고 누가 더 부자인지 비교하는 MPC의 근본 문제.

</details>

- 정의/개념: 비밀 입력을 공개하지 않고 **공동 함수 결과만 도출하는 분산 연산**
- 배경/필요성: 기관 간 결합은 **원시 데이터 유출·반출 규제·TTP 비용** 발생

#### 한줄 요약
- 원본 데이터의 외부 반출 없이 암호화된 상태로 분산 연산하여 최종 결과만 안전하게 도출한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **Shamir's Secret Sharing**: $t$차 다항식을 이용해 데이터를 $n$개로 분할하고, $t+1$개 이상의 조각이 모여야만 원본 복원이 가능한 $(t, n)$ 임계치 비밀 분산 기법.
- **Beaver Triple (비버 삼중주)**: 오프라인 단계에서 곱셈 보조 난수 쌍($a, b, c = ab$)을 사전 생성하여 온라인 곱셈 통신 오버헤드를 1-RTT로 단축하는 기법.

</details>

- **TTP 배제**: 암호 프로토콜로 공동 결과 신뢰 확보
- **임계치 안전성**: $t$ 미만 조각으로 원본 복원 불가
- **Beaver Triple**: 오프라인 난수로 온라인 곱셈 단축

#### 한줄 요약
- 제3자 배제, 임계치 기반 정보이론적 안전성, 비버 트리플 기반 온라인 고속화를 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **SPDZ Protocol**: 참여자 중 일부가 악의적으로 거짓 조각을 주입해도 정보이론적 MAC 검증을 통해 100% 탐지하고 퇴출하는 표준 MPC 알고리즘.

</details>

```text
[MPC 정적 구성]
|-- 비밀 분산기
|-- 비버 트리플 저장소
|-- P2P 연산 엔진
|-- MAC 무결성 검증기
`-- 결과 재구성기
```

선의 의미: 각 참여자가 원시 데이터를 쪼개어 교차 분배하고 P2P 통신으로 덧셈/곱셈을 수행한 후 검증된 조각만을 결합하여 최종 결과만 복원하는 구조

| 구성요소 | 핵심 엔지니어링 책임 | 주요 특징 |
|:---|:---|:---|
| 비밀 분산기 | **입력을 $n$개 조각으로 분할** | Shamir / Additive |
| 비버 트리플 저장소 | **곱셈 보조 난수 사전 생성** | Offline Phase |
| P2P 연산 엔진 | **로컬 덧셈·마스킹 곱셈** | SPDZ Engine |
| MAC 무결성 검증기 | **위조 조각 탐지** | Message Auth Code |
| 결과 재구성기 | **라그랑주 보간 결과 도출** | Lagrange Interp |

#### 한줄 요약
- 비밀 분산기, 비버 트리플 저장소, P2P 연산 엔진, MAC 검증기, 결과 재구성기가 결합한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **SPDZ Online Pipeline**: 1. 비버 난수 전처리 → 2. 입력 분산 → 3. 로컬 덧셈 → 4. 마스킹 브로드캐스트 곱셈 → 5. MAC 검증 및 결과 개방.

</details>

```text
공동 연산 요청
    |
1. 오프라인 전처리
    |
2. 입력 조각 분산
    |
3. 비통신 로컬 덧셈
    |
4. 마스킹 온라인 곱셈
    |
5. MAC 검증·결과 복원
    |
공동 결과
```

- 1. 오프라인 전처리
- 2. 입력 조각 분산
- 3. 비통신 로컬 덧셈
- 4. 마스킹 온라인 곱셈
- 5. MAC 검증·결과 복원

#### 한줄 요약
- 전처리 비버 생성 → 비밀 조각 분산 → 로컬 덧셈 → 마스킹 곱셈 → MAC 검증 및 최종 결과 복원 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **비밀 분산 MPC** vs **가블드 회로 (Yao's GC)** vs **동형 암호 기반 MPC (FHE-MPC)**.

</details>

| 비교 항목 | 비밀 분산 기반 MPC (SPDZ / Shamir) | 가블드 회로 기반 MPC (Yao's GC) | 동형 암호 기반 MPC (FHE-MPC) |
|:---|:---|:---|:---|
| 적합 참여자 수 | **3명 이상** | **2명** | 다자간 |
| 적합 연산 유형 | **산술 통계** | **비교·조건 분기** | 임의 산술 회로 |
| 네트워크 통신량 | 회로 깊이 비례 | 회로 크기 비례 | **초기·최종만 통신** |
| 연산 복잡도 | **낮음** | 중간 | **매우 높음** |
| 주요 적용 사례 | **의료·신용·MPC 지갑** | **경매·생체 인증** | **WAN 분산 분석** |

#### 한줄 요약
- 비밀 분산은 다자간 산술 통계용, 가블드 회로는 2자간 조건 분기용, FHE-MPC는 저대역폭 통신 최소화용이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Reconstruction Attack (결과값 역추론 공격)**: 악의적 참여자가 합법적 MPC 쿼리를 수백 번 반복 질의하여 결과값 차분으로 특정 개인의 입력값을 역산해 내는 공격.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 참여자의 임계치 미만 공모 | **Shamir $t$-of-$n$·감사 로그** | 입력 기밀성 유지 |
| 거짓 조각으로 결과 왜곡 | **SPDZ 정보이론적 MAC** | 위조 조각 탐지 |
| 반복 쿼리로 원본 역추론 | **차분 프라이버시 노이즈** | 개별 레코드 보호 |
| WAN 지연으로 온라인 연산 정체 | **Beaver Triple 사전 생성** | 통신 병목 완화 |

#### 한줄 요약
- $t$-of-$n$ 임계치로 공모를 막고, SPDZ MAC으로 조작을 차단하며, DP 노이즈로 결과 역추론을 방지한다.

## Ⅶ. 결론

- 다자 산술은 **Shamir·SPDZ**, 2자 조건 분기는 **Yao GC** 선택

#### 한줄 요약
- MPC는 비밀 분산과 비버 트리플 및 SPDZ MAC 검증을 결합하여 데이터 노출 없는 안전한 다자간 연산을 실현하는 핵심 기술이다.
