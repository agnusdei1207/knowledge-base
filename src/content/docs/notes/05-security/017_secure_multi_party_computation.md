## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **MPC (Secure Multi-Party Computation)**: 복수의 참여자가 비밀 입력을 공개하지 않고 협력하여 목표 함수의 연산 결과만을 도출하는 암호 기술.
- **Yao's Millionaires' Problem (야오의 백만장자 문제)**: 실제 재산 액수를 밝히지 않고 누가 더 부자인지 비교하는 MPC의 근본 문제.

</details>

- 정의/개념: 복수의 참여자가 원시 데이터를 공개하지 않고 **비밀 분산과 암호 프로토콜을 통해 공동 목표 함수의 결과값($y=f(x_1,\dots,x_n)$)만을 도출하는 분산 연산 기술**
- 배경/필요성: 이종 기관 간 데이터 결합 시의 **원시 개인정보 유출 위험, 중앙 신뢰 기관(TTP) 구축 비용 및 법적 데이터 반출 제한 규제**

#### 한줄 요약
- 원본 데이터의 외부 반출 없이 암호화된 상태로 분산 연산하여 최종 결과만 안전하게 도출한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **Shamir's Secret Sharing**: $t$차 다항식을 이용해 데이터를 $n$개로 분할하고, $t+1$개 이상의 조각이 모여야만 원본 복원이 가능한 $(t, n)$ 임계치 비밀 분산 기법.
- **Beaver Triple (비버 삼중주)**: 오프라인 단계에서 곱셈 보조 난수 쌍($a, b, c = ab$)을 사전 생성하여 온라인 곱셈 통신 오버헤드를 1-RTT로 단축하는 기법.

</details>

- **중앙 신뢰 제3자(TTP)의 완전한 배제**: 중개 기관 없이 **수학적 프로토콜만으로 참여자 간 상호 신뢰 및 공정한 연산 결과 보장**
- **정보이론적 안전성(Information-Theoretic Security)**: 임계치($t$) 미만의 조각을 획득한 공격자는 **무한한 계산 능력이 있어도 원본 데이터 추론 불가**
- **비버 트리플을 통한 온라인 곱셈 고속화**: 난수를 오프라인에서 사전 생성하여 **온라인 연산 시의 네트워크 병목 극소화**

#### 한줄 요약
- 제3자 배제, 임계치 기반 정보이론적 안전성, 비버 트리플 기반 온라인 고속화를 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **SPDZ Protocol**: 참여자 중 일부가 악의적으로 거짓 조각을 주입해도 정보이론적 MAC 검증을 통해 100% 탐지하고 퇴출하는 표준 MPC 알고리즘.

</details>

```text
[비밀 분산 기반 MPC 3자 연산 아키텍처]
|-- Offline Phase (비버 트리플 난수 쌍 a, b, c=ab 사전 생성 및 분배)
`-- Online Input Sharing Phase (데이터 분할)
|   |-- Participant 1 (x_1) -> [x_1]_1, [x_1]_2, [x_1]_3 분산
|   |-- Participant 2 (x_2) -> [x_2]_1, [x_2]_2, [x_2]_3 분산
|   `-- Participant 3 (x_3) -> [x_3]_1, [x_3]_2, [x_3]_3 분산
`-- P2P Interactive Evaluation (덧셈: 로컬 연산, 곱셈: 마스킹 차분 교환 연산)
`-- MAC Integrity Verification & Reconstruction (MAC 검증 통과 시 최종 결과 y=f(x) 복원)
```

선의 의미: 각 참여자가 원시 데이터를 쪼개어 교차 분배하고 P2P 통신으로 덧셈/곱셈을 수행한 후 검증된 조각만을 결합하여 최종 결과만 복원하는 구조

| 구성요소 | 핵심 엔지니어링 책임 | 주요 특징 |
|:---|:---|:---|
| **비밀 분산기 (Sharer)** | 입력값을 다항식에 대입하여 **$n$개의 암호화된 조각으로 분할** | Shamir / Additive |
| **비버 트리플 저장소** | 오프라인 단계에서 **곱셈 보조 난수 쌍($a, b, c = ab$)을 사전 생성** | Offline Phase |
| **P2P 연산 엔진** | 덧셈은 로컬에서 즉시 처리하고 **곱셈은 마스킹 차분값을 교환하여 실행** | SPDZ Engine |
| **MAC 무결성 검증기**| 악의적 참여자가 **위조된 가짜 조각을 제출하여 왜곡하는 행위를 실시간 차단** | Message Auth Code |
| **결과 재구성기** | $t+1$개 이상의 유효한 결과 조각을 **라그랑주 보간법으로 결합하여 결과 도출** | Lagrange Interp |

#### 한줄 요약
- 비밀 분산기, 비버 트리플 저장소, P2P 연산 엔진, MAC 검증기, 결과 재구성기가 결합한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **SPDZ Online Pipeline**: 1. 비버 난수 전처리 → 2. 입력 분산 → 3. 로컬 덧셈 → 4. 마스킹 브로드캐스트 곱셈 → 5. MAC 검증 및 결과 개방.

</details>

```text
SPDZ 전처리, 비밀 조각 분산, 로컬 덧셈, 마스킹 곱셈 및 결과 복원 파이프라인
        │
   1. [오프라인 전처리] 참여자 전원이 무작위 비버 곱셈 삼중주($[a], [b], [c]$) 및 MAC 태그 사전 생성
        │
   2. [입력 조각 분산] 각 참여자가 비밀 입력값($x$)을 가산적 분산하여 타 참여자들에게 전송
        │
   3. [비통신 로컬 덧셈] 네트워크 통신 없이 각 참여자가 로컬에서 자신의 조각들을 더함 ($[z] = [x] + [y]$)
        │
   4. [마스킹 온라인 곱셈] 비버 트리플로 마스킹된 $\epsilon = x - a$, $\delta = y - b$를 교환하여 $[xy]$ 계산
        │
   ▼
5. [MAC 검증 및 결과 복원] 결과 조각의 MAC 일치 여부를 대조하여 위변조 확인 후 최종 결과 $y$ 복원
```

#### 한줄 요약
- 전처리 비버 생성 → 비밀 조각 분산 → 로컬 덧셈 → 마스킹 곱셈 → MAC 검증 및 최종 결과 복원 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **비밀 분산 MPC** vs **가블드 회로 (Yao's GC)** vs **동형 암호 기반 MPC (FHE-MPC)**.

</details>

| 비교 항목 | 비밀 분산 기반 MPC (SPDZ / Shamir) | 가블드 회로 기반 MPC (Yao's GC) | 동형 암호 기반 MPC (FHE-MPC) |
|:---|:---|:---|:---|
| **적합 참여자 수** | **$N \ge 3$ 다자간 연산 최적화** | **$N = 2$ 양자간 연산 최적화** | 다자간 연산 지원 |
| **적합 연산 유형** | **대규모 덧셈/곱셈 산술 통계 (AI 학습)**| **비교, 최소/최대값, If-Else 논리 분기** | 임의 산술 회로 |
| **네트워크 통신량** | 곱셈 회로 깊이에 비례하여 통신 발생 | 회로 크기만큼 초기에 대용량 진리표 전송 | **최저 (초기 및 최종 통신만 발생)** |
| **연산 복잡도** | **가장 가벼움 (모듈러 덧셈/곱셈 연산)** | 중간 (대칭키 해시 및 OT 연산) | **매우 무거움 (FHE 암호화 연산 오버헤드)**|
| **주요 적용 사례** | **의료 데이터 통계, 분산 신용평가, MPC 지갑**| **비공개 경매, 프라이버시 생체 인증** | **지연시간이 긴 광역 WAN 환경 분산 분석**|

#### 한줄 요약
- 비밀 분산은 다자간 산술 통계용, 가블드 회로는 2자간 조건 분기용, FHE-MPC는 저대역폭 통신 최소화용이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Reconstruction Attack (결과값 역추론 공격)**: 악의적 참여자가 합법적 MPC 쿼리를 수백 번 반복 질의하여 결과값 차분으로 특정 개인의 입력값을 역산해 내는 공격.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 과반수 미만의 참여자가 악의적으로 결탁하여 **타인의 비밀 입력을 역산하는 공모 공격** | **Shamir 기반 `$t\text{-of-}n$ 임계치($t < n/2$)` 설계 및 감사 로깅** | 공모 노드 수가 임계치 미만일 때 완벽한 비밀성 보증 |
| 악의적 참여자가 거짓 조각을 주입하여 **공동 연산 결과를 고의 왜곡하는 사고** | **`SPDZ 프로토콜 기반 정보이론적 MAC 태그 검증` 및 위반 노드 즉각 퇴출** | 조작된 조각 100% 실시간 검출 및 연산 왜곡 원천 차단 |
| 합법적 MPC 쿼리를 반복 질의하여 **특정 개인의 원본 값을 역추론하는 공격** | **MPC 최종 출력단에 `차분 프라이버시(Differential Privacy, DP) 노이즈` 주입** | 통계적 유용성을 유지하면서 개별 레코드 역추론 차단 |
| 광역 네트워크(WAN) 환경에서 참여자 간 네트워크 레이턴시로 인한 연산 지연 | **`비버 트리플 대규모 오프라인 사전 생성 및 파이프라이닝`** 최적화 | 온라인 통신 병목 제거 및 실시간 연산 응답성 확보 |

#### 한줄 요약
- $t$-of-$n$ 임계치로 공모를 막고, SPDZ MAC으로 조작을 차단하며, DP 노이즈로 결과 역추론을 방지한다.

## Ⅶ. 결론

- 원본 데이터의 결합이나 이전 없이 안전한 데이터 경제와 AI 연합학습(Federated Learning)을 가능하게 하는 **안전한 다자간 연산(MPC) 아키텍처는 개인정보 보호 강화 기술(PET)의 핵심 표준**이며, 실무 구현 시 **비밀 분산과 가블드 회로의 하이브리드 구성, 오프라인 비버 트리플 전처리 가속, SPDZ 기반 악의적 공격자 방어 및 차분 프라이버시(DP) 결합**을 통합 추진하여 고성능 프라이버시 보존형 공동 데이터 인프라 완성

#### 한줄 요약
- MPC는 비밀 분산과 비버 트리플 및 SPDZ MAC 검증을 결합하여 데이터 노출 없는 안전한 다자간 연산을 실현하는 핵심 기술이다.
