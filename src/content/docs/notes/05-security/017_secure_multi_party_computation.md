## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **안전한 다자간 연산(Secure Multi-Party Computation, SMPC / MPC)**: 서로를 신뢰하지 않는 $N$명의 참여자가 각자의 비밀 입력값($x_1, x_2, \dots, x_n$)을 타인이나 중앙 제3자에게 일절 공개하지 않고, 상호 협력 프로토콜을 통해 공동의 목표 함수 결과($y = f(x_1, x_2, \dots, x_n)$)만을 정확하게 계산해 내는 암호학적 분산 연산 기술.
- **야오의 백만장자 문제(Yao's Millionaires' Problem, 1982)**: 두 백만장자가 각자의 실제 재산 금액을 서로에게 밝히지 않고 오직 '누가 더 부자인가'($x_1 > x_2$)라는 불리언 결과만을 안전하게 비교하는 MPC의 시초 문제.

</details>

- 정의/개념: 참여자의 원시 데이터를 무작위 파편으로 쪼개는 **샤미르 비밀 분산(Shamir's Secret Sharing)** 및 불리언 회로를 암호화하는 **가블드 회로(Garbled Circuit)** 를 통해, 데이터 결합 없이 통계·AI 연산 결과만을 도출하는 **프라이버시 보존형 분산 연산 프레임워크**
- 배경/필요성: 금융권 신용 평가, 의료기관 간 희귀 질환 공동 연구, 기업 간 데이터 결합 분석 시 원본 데이터의 중앙 집중 통합으로 인한 개인정보 유출(GDPR 위반) 및 영업비밀 노출 위험을 원천 차단할 요구

#### 한줄 요약
- 원본 데이터를 공개하지 않고 비밀 조각 분산 연산을 통해 목표 함수의 결과값만을 안전하게 공동 산출한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **보안 위협 모델(Security Adversary Models)**:
  - **정직하지만 호기심 많은 모델(Semi-Honest / Honest-but-Curious)**: 프로토콜 규칙은 정상적으로 수행하되, 오간 메시지를 분석하여 타인의 비밀을 유추하려는 수동적 공격자 모델.
  - **악의적 공격자 모델(Malicious Adversary / SPDZ)**: 프로토콜 도중 위조된 거짓 조각(Share)을 전송하거나 연산을 중단하여 결과를 왜곡하려는 능동적 공격자 모델.

</details>

- **중앙 신뢰 기관(TTP: Trusted Third Party) 배제**: 데이터를 위탁할 신뢰된 브로커 서버 없이 참여자 간 P2P 대화형 프로토콜만으로 연산 완결
- **공모 저항성(Collusion Resistance / $t$-of-$n$ Threshold)**: $n$명의 참여자 중 최대 $t$명이 결탁하여 데이터를 합치더라도 나머지 정직한 참여자의 비밀 복구 불가
- **오프라인 전처리 및 온라인 가속 (Beaver Triple)**: 연산 병목인 곱셈 처리를 위해 네트워크 유휴 시 무작위 곱셈 삼중주(Beaver Triples)를 사전 생성하여 온라인 지연시간 극소화

#### 한줄 요약
- TTP 없는 P2P 분산 연산, $t$-of-$n$ 공모 저항성, 비버 트리플 기반 전처리 가속, 악의적 공격자 방어를 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **비버의 곱셈 삼중주(Beaver's Multiplication Triples)**: 비밀 분산 환경에서 두 비밀값의 곱셈($[x] \cdot [y]$) 연산 시 참여자 간 복잡한 통신 오버헤드를 제거하기 위해, 오프라인 전처리 단계에서 $c = a \cdot b$ 관계를 만족하는 무작위 난수 조각($[a], [b], [c]$)을 미리 생성해 두는 기법.

</details>

```text
[ 참여자 1 (Alice: $x_1$) ]         [ 참여자 2 (Bob: $x_2$) ]         [ 참여자 3 (Charlie: $x_3$) ]
 ├─ 원시 비밀을 $n$개로 분산          ├─ 원시 비밀을 $n$개로 분산          ├─ 원시 비밀을 $n$개로 분산
 └─ 비밀 조각 $[x_1]_1, [x_1]_2, [x_1]_3$   └─ 비밀 조각 $[x_2]_1, [x_2]_2, [x_2]_3$   └─ 비밀 조각 $[x_3]_1, [x_3]_2, [x_3]_3$
           │                                 │                                 │
           └─────────────────────────────────┼─────────────────────────────────┘
                                             │ (1. 각자에게 비밀 조각 1개씩 교차 배포)
                                             ▼
┌──────────────────────────────────────────────────────────────────────────────────────────────────┐
│ [ 온라인 비밀 분산 MPC 연산 계층 (Interactive Computation Layer) ]                              │
│  ├─ 로컬 덧셈 연산: 통신 없이 각자 보유한 조각을 단순 덧셈 ($[z]_i = [x]_i + [y]_i$)             │
│  ├─ 상호 곱셈 연산: 오프라인 비버 트리플($[a], [b], [c]$)을 활용한 1회성 마스킹 교환             │
│  └─ 정보 무결성 검증: 정보이론적 MAC($\alpha$) 검증을 통해 위조 조각을 투입한 악의적 참여자 식별 │
└────────────────────────────────────┬─────────────────────────────────────────────────────────────┘
                                     │ (2. 검증 완료된 결과 조각 모음)
                                     ▼
                      [ 최종 결과 재구성기 (Reconstruction: $y = f(x_1, x_2, x_3)$) ]
                       (오직 최종 합산 결과만 복원되고 개별 입력값 $x_i$는 영구 비공개)
```

선의 의미: 각 참여자가 원시 데이터를 쪼개어 교차 분배하고, P2P 통신으로 덧셈/곱셈을 수행한 후, 검증된 조각만을 결합하여 최종 결과만 복원하는 구조

| 구성요소 | 핵심 책임 및 역할 | 비고 |
|:---|:---|:---|
| **비밀 분산기 (Sharer)** | 입력값을 다항식 $f(x) = s + a_1 x + \dots + a_t x^t$에 대입하여 $n$개의 조각으로 분할 | Shamir / Additive |
| **비버 트리플 전처리 저장소**| 오프라인 단계에서 곱셈 보조 난수 쌍($a, b, c = ab$)을 사전 생성 및 분배 | Offline Phase |
| **P2P 상호 연산 엔진** | 통신 없이 덧셈을 즉시 처리하고, 곱셈 시 마스킹된 차분값을 교환하여 연산 집행 | SPDZ Engine |
| **MAC 무결성 검증기** | 악의적 참여자가 위조된 가짜 조각을 제출하여 연산을 왜곡하는 행위를 실시간 차단 | Message Auth Code |
| **결과 재구성기 (Reconstructor)**| $t+1$개 이상의 유효한 결과 조각을 라그랑주 보간법으로 결합하여 최종 평문 결과 도출 | Lagrange Interpolation |

#### 한줄 요약
- 비밀 분산기, 비버 트리플 저장소, P2P 연산 엔진, MAC 검증기, 결과 재구성기가 결합한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **SPDZ 프로토콜 기반 악의적 공격자 방어**: 연산에 참여하는 모든 비밀 조각에 전역 MAC 키($\alpha$)를 곱한 인증 태그($[\gamma_x] = \alpha \cdot [x]$)를 결합하여, 연산 종료 후 최종 개방 시 MAC 일치 여부를 검사함으로써 단 1개의 비트 조작도 즉각 검출하는 표준 MPC 알고리즘.

</details>

```text
1. [오프라인 전처리] 참여자들이 무작위 비버 곱셈 삼중주($[a], [b], [c]$) 및 MAC 인증 태그 사전 생성
            │
            ▼
2. [입력 분산] 각 참여자가 비밀 입력값($x$)을加산적 비밀 분산하여 다른 참여자들에게 1조각씩 전송
            │
            ▼
3. [온라인 덧셈] 통신 오버헤드 없이 각 참여자가 로컬에서 자신의 조각들을 더함 ($[z] = [x] + [y]$)
            │
            ▼
4. [온라인 곱셈] 비버 트리플로 마스킹된 $\epsilon = x - a$, $\delta = y - b$를 브로드캐스트 교환하여 $[xy]$ 계산
            │
            ▼
5. [MAC 검증 및 개방] 결과 조각의 MAC 일치 여부를 전원 대조 ➔ [위변조 없음 확인 시] 최종 결과 $y$ 복원
```

**동작 원리**

1. **전처리 난수 확보**: 네트워크 부하가 없는 시점에 비버 트리플과 MAC 키를 암호학적으로 생성
2. **입력 분할 마스킹**: $x = \sum_{i=1}^n x_i$가 되도록 무작위 난수를 쪼개어 개별 조각의 엔트로피 최대화
3. **비통신 덧셈 연산**: 덧셈의 준동형성으로 인해 참여자 간 네트워크 패킷 교환 없이 로컬 계산 완결
4. **마스킹 곱셈 연산**: $xy = (x-a)(y-b) + a(y-b) + b(x-a) + ab$ 수식을 활용하여 1회 왕복 통신만으로 곱셈 처리
5. **악의적 행위 차단**: 라그랑주 보간 전 MAC 태그를 검증하여 부정한 참여자가 주입한 오류를 완벽 배제

#### 한줄 요약
- 전처리 비버 생성, 비밀 조각 분산, 로컬 덧셈, 마스킹 곱셈, MAC 검증 및 최종 결과 복원 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **MPC 주요 구현 방식 비교**: N자간 통계에 최적화된 비밀 분산(Secret Sharing), 2자간 복잡한 불리언 조건문에 최적화된 가블드 회로(Garbled Circuit), 통신 횟수를 최소화하는 동형암호 결합 MPC의 비교.

</details>

| 비교 항목 | 비밀 분산 기반 MPC (SPDZ / Shamir) | 가블드 회로 기반 MPC (Yao's GC) | 동형 암호 기반 MPC (FHE-MPC) |
|:---|:---|:---|:---|
| **적합 참여자 수** | **$N \ge 3$ 다자간 연산 최적화** | **$N = 2$ 양자간 연산 최적화** | 다자간 연산 지원 |
| **적합 연산 유형** | **대규모 덧셈/곱셈 산술 통계 (AI 학습)**| **비교, 최소/최대값, If-Else 논리 분기** | 임의 산술 회로 |
| **네트워크 통신량** | 곱셈 회로 깊이에 비례하여 통신 발생 | 회로 크기만큼 초기에 대용량 진리표 전송 | **최저 (초기 및 최종 통신만 발생)** |
| **연산 복잡도** | **가장 가벼움 (모듈러 덧셈/곱셈 연산)** | 중간 (대칭키 해시 및 OT 연산) | **매우 무거움 (FHE 암호화 연산 오버헤드)**|
| **주요 적용 사례** | **의료 데이터 통계, 분산 신용평가, MPC 지갑**| **비공개 경매, 프라이버시 생체 인증** | **지연시간이 긴 광역 WAN 환경 분산 분석**|

#### 한줄 요약
- 비밀 분산은 다자간 산술 통계용, 가블드 회로는 2자간 조건 분기용, FHE-MPC는 저대역폭 통신 최소화용이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **차분 프라이버시(Differential Privacy, DP) 결합**: MPC가 연산 과정의 데이터 기밀성을 완벽히 보호하더라도, 최종 출력된 결과값($y$)을 대상으로 공격자가 반복적이고 정밀한 질의를 수행하여 특정 개인의 데이터를 역추론(Reconstruction Attack)하는 것을 방어하기 위해 출력값에 수학적 노이즈(라플라스/가우시안 노이즈)를 강제 주입하는 프라이버시 방어 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 참여자 중 과반수 미만이 악의적으로 결탁하여 **타 참여자의 비밀 입력을 역산하는 공모 공격** | **Shamir 기반 $t$-of-$n$ 임계치($t < n/2$ 또는 $t < n/3$) 설계 및 감사 로깅** | 공모 참여자 수가 임계치 미만일 때 완벽한 정보이론적 비밀성 보증 |
| 악의적 참여자가 중간에 거짓 조각(Share)을 주입하여 **공동 연산 결과를 고의 왜곡하는 사고** | **SPDZ 프로토콜 기반 정보이론적 MAC 인증 태그 검증 및 위반 노드 즉각 퇴출** | 조작된 조각 100% 실시간 검출 및 악의적 연산 왜곡 원천 차단 |
| 공격자가 합법적인 MPC 쿼리를 수백 번 반복 실행하여 **특정 개인의 원본 값을 역추론하는 공격** | **MPC 최종 출력단에 차분 프라이버시(DP: $\epsilon$-Differential Privacy) 노이즈 주입** | 통계적 유용성을 유지하면서 개별 레코드 역추론 위험을 $e^\epsilon$ 이하로 제한 |

#### 한줄 요약
- $t$-of-$n$ 임계치로 공모를 막고, SPDZ MAC으로 조작을 차단하며, DP 노이즈로 결과 역추론을 방지한다.

## Ⅶ. 결론

- 원본 데이터의 결합이나 이전 없이 안전한 데이터 경제와 AI 연합학습(Federated Learning)을 가능하게 하는 **안전한 다자간 연산(MPC) 아키텍처**는 개인정보 보호 강화 기술(PET)의 핵심 표준이며, 실무 구현 시 **비밀 분산과 가블드 회로의 하이브리드 구성**, **오프라인 비버 트리플 전처리 가속**, **SPDZ 기반 악의적 공격자 방어 및 차분 프라이버시(DP) 결합**을 통합 추진하여 고성능 프라이버시 보존형 공동 데이터 인프라를 완성

#### 한줄 요약
- 비밀 분산과 비버 트리플 및 SPDZ MAC 검증을 결합하여 데이터 노출 없는 안전한 다자간 연산을 실현한다.
