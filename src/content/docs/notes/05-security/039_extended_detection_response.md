## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **XDR (Extended Detection and Response)**: 엔드포인트, 네트워크, 클라우드, 이메일, 계정 텔레메트리를 통합 수집해 전체 공격 체인을 일괄 대응하는 플랫폼.
- **Cross-Domain Correlation (크로스 도메인 상관분석)**: 이메일 피싱부터 클라우드 유출까지 이종 계층의 이벤트를 단일 공격 시나리오로 결합하는 기술.

</details>

- 정의/개념: 엔드포인트, 네트워크, 클라우드, 이메일, 계정 텔레메트리를 통합 수집하고 **크로스 상관분석으로 공격 체인을 가시화하여 일괄 대응하는 보안 플랫폼**
- 배경/필요성: 개별 포인트 솔루션(EDR, NDR, SEG)의 사일로화로 인한 **계층 간 가시성 단절, 수십 개 분산 경보에 따른 분석 지연 및 교차 대응 실패**

#### 한줄 요약
- 다계층 텔레메트리 통합과 크로스 도메인 상관분석을 통해 공격 전체 경로를 단일 화면에서 가시화하고 일괄 차단한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **Single Pane of Glass (단일 통합 뷰)**: 여러 보안 도구의 화면을 번갈아 볼 필요 없이 단일 대시보드에서 엔드투엔드 공격 타임라인을 확인하는 환경.
- **Telemetry Fusion (텔레메트리 융합)**: 단순 텍스트 로그가 아닌 커널 시스템 콜, 원시 패킷, 클라우드 API 호출 등 고밀도 텔레메트리를 결합 분석하는 기법.

</details>

- **5대 핵심 도메인 텔레메트리 통합**: 엔드포인트(EDR), **네트워크(NDR), 클라우드(CDR), 이메일(SEG), 계정(IdP)의 원시 데이터 실시간 융합**
- **인과관계 기반의 자동 공격 체인 합성**: 50개의 개별 알람을 **단일 'APT 표적 침해 사건'으로 자동 묶어 관제사의 경보 피로도 90% 해소**
- **원클릭 크로스 도메인 동시 타격**: 단 한 번의 실행으로 **단말 격리, 피싱 메일 일괄 삭제, C2 방화벽 차단, 도용 계정 잠금을 동시 집행**

#### 한줄 요약
- 5대 도메인 통합, 자동 공격 체인 합성, 원클릭 크로스 도메인 동시 차단을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **Identity Graph (엔티티 해석기)**: 서로 다른 도메인에서 발생하는 IP, MAC, 사용자 계정, SSO 토큰을 단일 공격 주체로 묶어주는 그래프 엔진.

</details>

```text
[XDR 다계층 텔레메트리 통합 및 일괄 대응 아키텍처]
|-- Multi-Layer Telemetry Ingestion (EDR + NDR + Cloud CDR + Email SEG + Identity IdP)
`-- XDR Core Data Lake & Analytics
    |-- 1. Identity Stitching & Resolution (식별자 결합)
    |-- 2. Cross-Domain Correlation Engine (MITRE ATT&CK 기반 공격 체인 재구성)
    `-- 3. Incident Aggregation (50개 경보 -> 1개 사건 집계)
`-- Unified Investigation & Action Execution
    |-- Unified Console ──▶ 공격 전 과정 1-View 시각화
    `-- Action Executors ──▶ EDR(호스트 격리), SEG(메일 삭제), NGFW(C2 차단), IdP(계정 잠금)
```

선의 의미: 5대 계층 센서의 텔레메트리가 XDR 데이터 레이크로 집결되어 엔티티 해석과 크로스 상관분석을 거쳐 단일 인시던트로 가시화 및 일괄 대응되는 구조

| 구성요소 | 핵심 엔지니어링 책임 | 주요 특징 |
|:---|:---|:---|
| **다계층 텔레메트리 센서**| EDR, NDR, SEG, CDR, IdP 전 영역에서 **원시 행동 데이터 실시간 스트리밍** | Telemetry |
| **엔티티 해석기 (Resolver)**| 이종 도메인의 IP, 계정, 토큰 식별자를 **단일 공격 주체로 상호 결합** | Identity Graph |
| **크로스 도메인 상관 엔진**| 이메일 유입부터 DB 탈취까지의 **이종 이벤트를 연결해 공격 시나리오 합성** | Correlation |
| **통합 조사 콘솔** | 단일 UI 환경에서 **공격의 근본 원인(Root Cause)과 전파 경로 1-View 제공** | Single View |
| **일괄 대응 오케스트레이터**| 단일 트리거로 **단말 격리, 메일 소거, 방화벽 차단, 계정 잠금을 동시 집행** | Cross-Domain |

#### 한줄 요약
- 다계층 센서, 엔티티 해석기, 크로스 상관 엔진, 통합 조사 콘솔, 일괄 대응 오케스트레이터가 결합한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **XDR Timeline Synthesis**: 피싱 메일 인입(SEG) → 파워쉘 구동(EDR) → 도메인 컨트롤러 접근(NDR) → S3 버킷 다운로드(CDR)를 1개 타임라인으로 렌더링.

</details>

```text
다계층 수집, 타임라인 정렬, 크로스 상관 집계 및 일괄 대응 파이프라인
        │
   1. [다계층 수집] SEG(악성 링크), EDR(악성 프로세스), NDR(C2 통신), IdP(비인가 토큰) 수집
        │
   2. [엔티티 결합 및 타임라인 정렬] 시간순 발생 이종 이벤트를 동일 호스트 및 계정 그래프로 바인딩
        │
   3. [크로스 상관분석 및 집계] 4개 도메인 경보를 'APT 침해 1건'으로 자동 집계 및 위험도 채점
        │
   4. [통합 콘솔 조사] 분석가가 단일 화면에서 피싱 유입부터 C2 접속까지의 공격 경로 및 영향도 검증
        │
   ▼
5. [크로스 도메인 일괄 대응 집행]
    ├─ EDR API: 침해 단말 네트워크 격리
    ├─ SEG API: 사내 전 임직원 편지함에서 피싱 메일 일괄 파기
    ├─ NGFW API: C2 IP/도메인 아웃바운드 차단
    └─ Okta API: 해당 계정 세션 즉각 무효화 및 MFA 재설정 강제
```

#### 한줄 요약
- 다계층 수집 → 엔티티 결합 및 타임라인 정렬 → 크로스 상관 집계 → 통합 조사 → 일괄 동시 대응 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **Native XDR (단일 벤더 통합형)** vs **Open XDR (이기종 개방형)**.

</details>

| 비교 항목 | Native XDR (단일 벤더 통합형) | Open XDR (이기종 개방형) |
|:---|:---|:---|
| **아키텍처 구조** | **단일 보안 벤더의 자체 제품군(EDR, NGFW, SEG) 결합** | **오픈 API 및 공통 스키마로 이종 벤더 장비 연동** |
| **텔레메트리 통합 깊이** | **매우 깊음 (자사 전용 프로토콜로 최고 정밀도 분석)** | 보통~깊음 (표준 API 및 CEF/JSON 정규화 수준) |
| **구축 및 연동 난이도** | **매우 낮음 (Out-of-the-box 즉시 연동 및 턴키 배포)** | 중간~높음 (이기종 API 연동 및 파서 개발 필요) |
| **벤더 종속성 (Lock-in)** | **높음 (타사 보안 솔루션 교체 시 연동 제약 발생)** | **전혀 없음 (기존에 구축된 다기종 보안 장비 재활용)** |
| **대표 솔루션 벤더** | Palo Alto Cortex XDR, Trend Micro Vision One, Microsoft Defender | Stellar Cyber, ReliaQuest GreyMatter, Open XDR 플랫폼 |

#### 한줄 요약
- Native XDR은 단일 벤더의 깊은 통합과 턴키 구축, Open XDR은 이종 벤더 연동성과 기존 투자 보호에 특화된다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Open API 거버넌스**: XDR을 활용한 전사 일괄 차단 시 비즈니스 다운타임을 방지하기 위한 사고 대응 거버넌스 및 API 안전성 표준.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| Native XDR 도입으로 인해 **기존 타사 방화벽/WAF와의 연동 단절 및 벤더 락인** | **`Open XDR 프레임워크 및 표준 REST/Open API 기반 이종 벤더 커넥터` 채택** | 기존 보안 인프라 투자(ROI) 100% 보존 및 확장성 확보 |
| XDR의 원클릭 차단 시 **핵심 ERP/DB 서버까지 네트워크에서 격리되는 업무 중단** | **고위험 자산에 대한 `Human-in-the-loop 인적 승인 강제 및 단계별 롤백 메커니즘`** | 전사 비즈니스 다운타임 0% 달성 및 즉각 원상 복구 |
| 다계층 센서의 대용량 텔레메트리로 인한 **클라우드 스토리지 비용 폭증 및 지연** | **`핫/웜/콜드 계층화 스토리지 설계 및 중요 이벤트 기반 필터링 수집`** | 인프라 운영 비용 50% 절감 및 실시간 상관분석 유지 |
| 단일 에이전트 업데이트 실패로 인한 엔드포인트 블루스크린(BSOD) 장애 | **`단계적 카나리(Canary) 배포 및 에이전트 드라이버 커널 안정성 검증`** | 전사 엔드포인트 크래시 방지 및 무중단 가용성 보장 |

#### 한줄 요약
- Open API로 락인을 방지하고, Human-in-the-loop과 롤백으로 오조치를 막으며, 스토리지 계층화로 비용을 최적화한다.

## Ⅶ. 결론

- 파편화된 포인트 보안 솔루션의 한계를 극복하고 전사적 위협 가시성과 즉각적인 차단 역량을 제공하는 **XDR 아키텍처는 차세대 통합 보안 관제의 핵심 진화 모델**이며, 실무 구현 시 **엔드포인트·네트워크·클라우드·이메일을 아우르는 전방위 텔레메트리 통합, MITRE ATT&CK 기반 크로스 도메인 상관분석, 조직 환경에 부합하는 Native/Open XDR 선정, 안전한 일괄 대응 거버넌스**를 결합하여 지능형 사이버 위협에 대한 무결점 레질리언스 완성

#### 한줄 요약
- XDR은 다계층 텔레메트리 통합과 크로스 상관분석 및 일괄 대응을 통해 엔드투엔드 위협 가시성과 초고속 MTTR을 실현하는 차세대 보안 플랫폼이다.
