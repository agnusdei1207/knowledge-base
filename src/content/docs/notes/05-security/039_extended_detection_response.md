## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **XDR(Extended Detection and Response)**: 엔드포인트(EDR), 네트워크(NDR), 클라우드 워크로드(CWPP/CSPM), 이메일 보안(SEG), 아이덴티티(IdP) 등 다중 보안 계층에서 발생하는 고밀도 텔레메트리(Telemetry)를 단일 데이터 레이크로 통합 수집하고, 크로스 도메인 머신러닝 상관분석을 통해 전체 공격 체인(Kill Chain)을 단일 인시던트로 가시화하여 일괄 대응을 집행하는 차세대 보안 플랫폼.
- **크로스 도메인 상관분석(Cross-Domain Correlation)**: 이메일 피싱 유입 $\rightarrow$ 엔드포인트 프로세스 인젝션 $\rightarrow$ 네트워크 내부 횡적 이동(Lateral Movement) $\rightarrow$ 클라우드 데이터 유출로 이어지는 이종 계층의 단편적 이벤트들을 동일 공격자의 단일 침해 시나리오로 결합하는 다계층 연관 분석 기술.

</details>

- 정의/개념: 포인트 보안 솔루션의 고립된 사일로(Silo)와 단편적 경보를 극복하고, **다계층 센서 텔레메트리 수집 $\rightarrow$ 엔티티 해석 및 공격 타임라인 합성 $\rightarrow$ 크로스 도메인 상관분석 $\rightarrow$ 원클릭 일괄 오케스트레이션 대응** 을 제공하는 **엔드투엔드 능동 보안 아키텍처**
- 배경/필요성: 개별 EDR이나 NGFW는 자사 관측 영역 외의 공격 징후를 식별하지 못해 지능형 다단계 공격의 전체 맥락 파악이 지연되고, 보안 관제 분석가가 10여 개 이상의 개별 콘솔을 오가며 수동 분석하는 비효율을 해소할 요구

#### 한줄 요약
- 엔드포인트, 네트워크, 클라우드, 이메일 텔레메트리를 결합하여 전체 공격 경로를 가시화하고 일괄 차단한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **사건 집계 및 압축(Incident Aggregation & Reduction)**: 개별 계층에서 쏟아지는 수백 건의 자잘한 단편 경보를 계정과 시계열 그래프로 묶어 하나의 의미 있는 '통합 침해 인시던트'로 압축함으로써 관제 피로도를 90% 이상 절감하는 기술.
- **크로스 도메인 일괄 대응(Cross-Domain Coordinated Response)**: 단일 조치 버튼으로 감염 PC의 네트워크 격리(EDR), 악성 이메일 전사 메일함 일괄 영구 삭제(SEG), C2 통신 방화벽 차단(NGFW), 도용된 계정 세션 즉시 파기(IdP)를 동시 집행하는 일체형 대응 메커니즘.

</details>

- **다계층 심층 텔레메트리 수집**: 원시 로그(Syslog) 수준을 넘어 프로세스 트리, 네트워크 흐름, 클라우드 API를 결합한 고밀도 원시 데이터 처리
- **엔티티 해석(Entity Resolution)**: 사용자 계정, IP, MAC 주소, IAM Role 간의 연관 관계를 실시간 맵핑하여 공격 주체 단일화
- **Native XDR vs Open XDR 생태계 지원**: 단일 벤더 중심의 긴밀한 통합(Native)과 다기종 벤더 Open API 결합(Open) 모델 제공

#### 한줄 요약
- 다계층 텔레메트리 융합, 크로스 도메인 상관분석, 사건 집계 압축, 일괄 오케스트레이션 대응을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **XDR 핵심 구성 도메인**:
  - **EDR (Endpoint)**: 호스트 프로세스, 메모리, 파일 변경 텔레메트리.
  - **NDR (Network)**: 비인가 프로토콜, 패킷 메타데이터, DNS 트래픽.
  - **CDR/CWPP (Cloud)**: 클라우드 API 감사 로그, 컨테이너 런타임 이상.
  - **SEG/IdP (Email & Identity)**: 스피어피싱 이메일, Kerberos 티켓 조작.

</details>

```text
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 다계층 텔레메트리 센서 계층 (Multi-Vector Telemetry Ingestion) ]     │
│  ├─ EDR: 엔드포인트 프로세스 트리 (Sysmon Event ID 1 / 메모리 덤프)    │
│  ├─ NDR: 네트워크 메타데이터 (Zeek Flow / 비정상 DNS 터널링)           │
│  ├─ SEG: 이메일 헤더, 첨부파일 해시, 발신자 평판 로그                  │
│  ├─ CDR: AWS CloudTrail / 쿠버네티스 감사 로그 (Audit Logs)             │
│  └─ IdP: Active Directory Kerberos 인증, MFA 우회 시도 로그             │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ [ XDR 코어 데이터 레이크 & 엔티티 해석 엔진 (Entity Resolution) ]        │
│  └─ [ IP + 계정명 + MAC + API Key ➔ 단일 사용자/기기 엔티티 매핑 ]      │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 크로스 도메인 상관분석 및 사건 집계 엔진 (Cross-Domain Correlation) ]  │
│  ├─ MITRE ATT&CK 기반 다단계 공격 체인(Kill Chain) 시계열 타임라인 합성 │
│  └─ 수백 개 경보 ➔ [ 단일 통합 인시던트: Incident #2048 (위험도: 98점) ]│
└──────────────────┬──────────────────────────────────┬───────────────────┘
                   │ (단일 통합 분석 콘솔)            │ (크로스 도메인 일괄 대응)
                   ▼                                  ▼
┌──────────────────────────────────────┐┌──────────────────────────────────────┐
│ [ XDR 통합 조사 및 위협 헌팅 콘솔 ]  ││ [ 크로스 도메인 일괄 대응 실행기 ]   │
│  └─ 공격 전 과정 1-View 시각화       ││  ├─ EDR: 호스트 네트워크 즉시 격리   │
│                                      ││  ├─ SEG: 전사 악성 메일 즉시 삭제   │
│                                      ││  ├─ NGFW: C2 도메인 실시간 차단     │
│                                      ││  └─ IdP: 도용 계정 세션 강제 만료   │
└──────────────────────────────────────┘└──────────────────────────────────────┘
```

선의 의미: 5대 계층 센서의 텔레메트리가 XDR 데이터 레이크로 집결되어 엔티티 해석과 크로스 상관분석을 거쳐 단일 인시던트로 가시화 및 일괄 대응되는 구조

| 구성요소 | 핵심 책임 및 역할 | 비고 |
|:---|:---|:---|
| **다계층 텔레메트리 센서** | EDR, NDR, SEG, CDR, IdP 전 영역에서 원시 행동 데이터 실시간 스트리밍 | Telemetry |
| **엔티티 해석기 (Resolver)** | 서로 다른 도메인의 IP, 계정, 토큰 식별자를 단일 공격 주체로 상호 결합 | Identity Graph |
| **크로스 도메인 상관 엔진** | 이메일 유입부터 DB 탈취까지의 이종 이벤트를 연결하여 공격 시나리오 합성 | Correlation Engine |
| **통합 조사 콘솔** | 단일 UI 환경에서 공격의 근본 원인(Root Cause)과 전파 경로 1-View 제공 | Single Pane of Glass|
| **일괄 대응 오케스트레이터** | 단일 트리거로 엔드포인트 격리, 메일 소거, 방화벽 차단, 계정 잠금을 동시 집행 | Cross-Domain Action |

#### 한줄 요약
- 다계층 센서, 엔티티 해석기, 크로스 상관 엔진, 통합 조사 콘솔, 일괄 대응 오케스트레이터가 결합한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **XDR 공격 타임라인 합성 원리**:
  - T0: 피싱 메일 인입 (SEG)
  - T1: 사용자 첨부파일 실행 및 파워쉘 구동 (EDR)
  - T2: 내부 도메인 컨트롤러 접근 (NDR)
  - T3: 클라우드 S3 버킷 권한 획득 및 다운로드 (CDR)
  - $\rightarrow$ 4개 계층 이벤트를 단일 타임라인 그래프로 실시간 렌더링.

</details>

```text
1. [다계층 수집] SEG(악성 링크 수신), EDR(악성 프로세스 실행), NDR(C2 통신), IdP(비인가 토큰 발급) 수집
            │
            ▼
2. [엔티티 결합 및 타임라인 정렬] 시간순으로 발생한 이기종 이벤트를 동일 호스트 및 계정 그래프로 바인딩
            │
            ▼
3. [크로스 상관분석 및 인시던트 집계] 4개 도메인의 50개 경보를 'APT 표적 침해 1건'으로 자동 집계 및 위험도 채점
            │
            ▼
4. [통합 콘솔 조사] 분석가가 단일 화면에서 피싱 유입부터 C2 접속까지의 공격 전체 경로 및 영향도 검증
            │
            ▼
5. [크로스 도메인 일괄 대응 집행]
    ├─ EDR API: 침해 단말 네트워크 격리
    ├─ SEG API: 사내 전 임직원 편지함에서 피싱 메일 일괄 파기
    ├─ NGFW API: C2 IP/도메인 아웃바운드 차단
    └─ Okta API: 해당 계정 세션 즉각 무효화 및 MFA 재설정 강제
```

**동작 원리**

1. **다각도 텔레메트리 융합**: 단편적 로그가 아닌 커널 및 패킷 수준의 원시 텔레메트리 연동
2. **공격 체인 재구성**: 시간대별 인과관계를 그래프 DB로 모델링하여 침투-확산-유출 경로 복원
3. **경보 노이즈 극소화**: 낱개 알람을 사건 단위로 묶어 관제사의 인지 부하 대폭 경감
4. **신속한 전방위 차단**: 다중 보안 장비에 대한 일원화된 REST API 호출로 공격 확산 원천 차단
5. **학습 및 탐지 환류**: 사고 분석 증적을 모든 센서의 탐지 룰셋으로 일괄 동기화

#### 한줄 요약
- 다계층 수집, 엔티티 결합 및 타임라인 정렬, 크로스 상관 집계, 통합 조사, 일괄 동시 대응 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **XDR 아키텍처 모델 비교**: 단일 벤더 통합형(Native XDR)과 이종 벤더 연동형(Open XDR)의 비교.

</details>

| 비교 항목 | Native XDR (단일 벤더 통합형) | Open XDR (이기종 개방형) |
|:---|:---|:---|
| **아키텍처 구조** | **단일 보안 벤더의 자체 제품군(EDR, NGFW, SEG) 결합** | **오픈 API 및 공통 스키마로 이종 벤더 장비 연동** |
| **텔레메트리 통합 깊이** | **매우 깊음 (자사 전용 프로토콜로 최고 정밀도 분석)** | 보통~깊음 (표준 API 및 CEF/JSON 정규화 수준) |
| **구축 및 연동 난이도** | **매우 낮음 (Out-of-the-box 즉시 연동 및 턴키 배포)** | 중간~높음 (이기종 API 연동 및 파서 개발 필요) |
| **벤더 종속성 (Lock-in)** | **높음 (타사 보안 솔루션 교체 시 연동 제약 발생)** | **전혀 없음 (기존에 구축된 다기종 보안 장비 재활용)** |
| **대표 솔루션 벤더** | Palo Alto Cortex XDR, Trend Micro Vision One, Microsoft Defender | Stellar Cyber, ReliaQuest GreyMatter, Open XDR 플랫폼 |

#### 한줄 요약
- Native XDR은 단일 벤더의 깊은 통합과 턴키 구축, Open XDR은 이종 벤더 연동성과 기존 투자 보호에 특화된다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **NIST SP 800-61 Rev. 3 & Open API 거버넌스**: XDR을 활용한 전사 일괄 차단 시 비즈니스 다운타임을 방지하기 위한 사고 대응 거버넌스 및 API 안전성 표준.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 특정 벤더 중심 Native XDR 도입으로 인해 **기존에 투자한 타사 방화벽/WAF와의 연동 단절 및 벤더 락인** | **Open XDR 프레임워크 및 표준 REST/Open API 기반 이종 벤더 커넥터 아키텍처** 채택 | 기존 보안 인프라 투자(ROI) 100% 보존 및 자유로운 보안 솔루션 확장성 확보 |
| XDR의 크로스 도메인 원클릭 차단 실행 시 **핵심 ERP/DB 서버까지 네트워크에서 격리되는 대형 업무 중단** | **고위험 자산에 대한 Human-in-the-loop 인적 승인 강제 및 단계별 롤백(Rollback) 메커니즘** 수립 | 전사 비즈니스 다운타임 0% 달성 및 오조치 발생 시 1분 이내 원상 복구 |
| 다계층 센서에서 수집되는 페타바이트급 텔레메트리로 인한 **클라우드 스토리지 비용 폭증 및 분석 지연** | **핫/웜/콜드 계층화 스토리지 설계 및 중요 이벤트 기반 텔레메트리 필터링 수집** 정책 수립 | 인프라 운영 비용 50% 이상 절감 및 핵심 상관분석 쿼리 성능 밀리초 단위 유지 |

#### 한줄 요약
- Open API로 락인을 방지하고, Human-in-the-loop과 롤백으로 오조치를 막으며, 스토리지 계층화로 비용을 최적화한다.

## Ⅶ. 결론

- 파편화된 포인트 보안 솔루션의 한계를 극복하고 전사적 위협 가시성과 즉각적인 차단 역량을 제공하는 **XDR 아키텍처**는 차세대 통합 보안 관제의 핵심 진화 모델이며, 실무 구현 시 **엔드포인트·네트워크·클라우드·이메일을 아우르는 전방위 텔레메트리 통합**, **MITRE ATT&CK 기반 크로스 도메인 상관분석**, **조직 환경에 부합하는 Native/Open XDR 선정**, **안전한 일괄 대응 거버넌스**를 결합하여 지능형 사이버 위협에 대한 무결점 레질리언스를 완성

#### 한줄 요약
- 다계층 텔레메트리 통합과 크로스 상관분석 및 일괄 대응을 통해 엔드투엔드 위협 가시성과 초고속 MTTR을 실현한다.
