## 미리 알고가기

- **보안 정보 및 이벤트 관리(Security Information and Event Management, SIEM)**: [읽기: 에스아이이엠; 표기 이유: 영문 머리글자와 구분 기호] 로그 정규화·상관 분석
- **응용 프로그래밍 인터페이스(Application Programming Interface, API)**: [읽기: 에이피아이; 표기 이유: 영문 머리글자와 구분 기호] 로그 수집 연동
- **시스템 로그 프로토콜(Syslog Protocol, Syslog)**: [읽기: 시스템 로그 프로토콜; 표기 이유: 한글명 뒤 영문 원어 병기] 장비 로그 전달
- **탐지 사례(Detection Use Case)**: [읽기: 탐지 사례; 표기 이유: 한글명 뒤 영문 원어 병기] 공격 행위·증거 정의
- **개인용 컴퓨터(Personal Computer, PC)**: [읽기: 피씨; 표기 이유: 영문 머리글자와 구분 기호] 종단 행위 로그 제공




- **흐름 기호(↓·→·-->)**: [읽기: 아래로·다음으로·연결; 표기 이유: 절차 방향 기호] 순서와 연결 방향을 나타냄
## Ⅰ. 개요

- **정의/개념**: 로그를 정규화·상관해 경보와 근거를 제공함
- **배경/필요성**: 분산 신호를 자산·신원·시간선으로 연결함

### 쉽게 이해하기 (학습용)

- 여러 기록을 한 시간선에 놓아 침입 분석

## Ⅱ. 특징

- 탐지 사례에서 로그·필드·보존을 역설계한다
- 파싱·시간·자산 보강이 분석 정확도를 높인다
- 규칙·통계·행위 분석에서 원본을 추적한다
- 수집·필드·보존 조정으로 비용을 제어한다

### 쉽게 이해하기 (학습용)

- 기록 정규화 및 맥락 통합 필수

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 수집·전송 | 유실 없는 이벤트 전달 |
| 파싱·정규화 | 공통 스키마 및 시간 기준 |
| 데이터 보강 | 중요도·소유자 문맥 부여 |
| 상관·분석 | 경보 근거 및 사건 생성 |
| 저장·관리 | 원본·정규화 데이터 증적 |

```text
[원천] 종단·신원·네트워크
  ↓
[수집] 에이전트·API
  ↓
[파싱] 정규화·보강
  ↓
[분석] 상관 규칙
  ↓
[결과] 경보·증적
```

> 요약: 원본·정규화 로그를 연결해 경보 근거를 추적함

### 쉽게 이해하기 (학습용)

- 가공 경보의 원본 판정 검증 기능

## Ⅳ. 원리 및 절차 흐름도

```text
사례정의
  ↓
요구명시
  ↓
품질검증
  ↓
분석검증
  ↓
운영튜닝
```

| 절차 | 설명 |
|:---|:---|
| 사례정의 | 공격 행위 정의함 |
| 요구명시 | 필요 로그 명시함 |
| 품질검증 | 유실·파싱 검증함 |
| 분석검증 | 규칙 모의 검증함 |
| 운영튜닝 | 탐지 적중 보정함 |

> 요약: 사례 정의 후 로그·품질·분석 검증 및 튜닝함

### 쉽게 이해하기 (학습용)

- 사전 공격 정의 후 로그 수집 필요

## Ⅴ. 종류 및 비교

| 비교축 | 로그 관리 | SIEM | 보안 데이터 레이크 |
|:---|:---|:---|:---|
| 핵심 특징 | 원본 로그 보관·검색 | 실시간 상관·경보·조사 | 대규모 원본의 장기 분석·재처리 |
| 적용 기준 | 감사·장애 분석 기록이 필요할 때 | 실시간 보안관제가 필요할 때 | 대용량 데이터를 다양한 방식으로 재분석할 때 |
| 주요 위험 | 공격 맥락 연결이 부족 | 수집 비용·오탐·필드 품질 문제 | 스키마·접근 통제 부족으로 데이터 늪 발생 |

> 요약: 목적에 따라 계층적 저장·분석 선택함

### 쉽게 이해하기 (학습용)

- 보관·탐지·저장 목적별 기록 관리

## Ⅵ. 실무 사례

- 유실·지연·필드 변경 우선 경보
- 데이터 보존 비용 기반 계층 설계
- 로그 접근 통제 및 무결성·감사 적용

### 쉽게 이해하기 (학습용)

- 유실·지연·필드 변경을 먼저 경보해 탐지 데이터 품질을 지킴
- 조회 빈도와 보존 의무에 따라 저장 계층을 나눠 비용을 관리함
- 로그의 개인정보·인증정보 접근을 제한하고 무결성을 감사함

## Ⅶ. 결론

- SIEM은 로그 품질·상관 규칙·증거를 연결함

### 쉽게 이해하기 (학습용)

- 분석 근거가 포함된 중요한 탐지 구현
