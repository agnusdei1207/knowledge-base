## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **SIEM(Security Information and Event Management)**: 조직 내 이종 보안 장비(방화벽, IPS, WAF, EDR), 네트워크 장비, 서버 및 클라우드 인프라에서 발생하는 대규모 로그와 이벤트를 실시간 중앙 수집·정규화하고, 시계열 기반 상관분석(Correlation) 룰을 통해 잠재적 보안 위협을 탐지하여 관제 알람을 생성하며 컴플라이언스 증적을 영구 보존하는 통합 보안 분석 플랫폼.
- **SIM(보안 정보 관리) vs SEM(보안 이벤트 관리)**: 장기 로그 저장·분석 및 컴플라이언스 리포팅을 담당하는 SIM과, 실시간 이벤트 모니터링·상관분석 및 즉시 경보를 담당하는 SEM의 기능적 결합.

</details>

- 정의/개념: 이종 텔레메트리 수집 $\rightarrow$ 표준 스키마 파싱 및 정규화(Normalization) $\rightarrow$ 위협 인텔리전스(CTI) 맥락 보강(Enrichment) $\rightarrow$ **다차원 시계열 상관분석(Correlation Engine)** $\rightarrow$ **증적 무결성 보존(WORM Storage)** 으로 이어지는 **빅데이터 보안 관제 코어 아키텍처**
- 배경/필요성: 개별 포인트 보안 솔루션의 고립된 로그 사일로(Silo) 구조로는 여러 시스템을 넘나들며 정상 권한을 악용하는 APT 공격의 다단계 침해 경로를 포착할 수 없는 한계를 극복할 요구

#### 한줄 요약
- 이종 로그를 표준 스키마로 정규화하고 실시간 다차원 상관분석을 수행하여 다단계 침해 위협을 가시화한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **로그 정규화(Normalization / Common Schema)**: 벤더마다 상이한 로그 필드명(예: `src_ip`, `SourceAddress`, `client_ip`)과 시간 표기를 공통 스키마(ArcSight CEF, Elastic ECS, Splunk CIM) 및 표준 UTC 타임스탬프로 단일화하는 전처리 기법.
- **다차원 상관분석(Multi-Dimensional Correlation)**: "1분 내 동일 IP에서 5회 로그인 실패 후 성공(브루트포스) $\rightarrow$ 즉시 시스템 권한 상승 명령 실행 $\rightarrow$ 대용량 아웃바운드 파일 전송"과 같이 시간, 자산, 계정, 행위를 연결하여 단일 복합 위협으로 탐지하는 기술.

</details>

- **전사 이기종 가시성 통합**: 온프레미스 네트워크, 가상화 인프라, 엔드포인트, SaaS/클라우드 감사 로그의 실시간 집계
- **시계열 기반 다단계 상관분석**: 단일 이벤트로는 정상으로 보이는 다중 시스템 행위를 시간 순서대로 엮어 APT 시나리오 탐지
- **법적 증거 능력 보장 (Non-Repudiation)**: 원본 로그에 대한 SHA-256 해시 체인 및 WORM 스토리지 저장을 통한 무결성 불변성 보증

#### 한줄 요약
- 이종 로그 통합 가시성, 표준 스키마 정규화, 다차원 상관분석, 법적 증거 무결성 보존을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **맥락 보강(Context Enrichment)**: 원시 IP 주소에 Active Directory의 사용자 실명·부서 정보, 자산 관리 대장의 서버 중요도(Tier 1/2), CTI의 최신 악성 IP 평판 데이터를 결합하여 분석가에게 즉각적인 의미를 제공하는 데이터 가공 단계.

</details>

```text
[ 이기종 로그 원천 (Syslog, WinEvent, Flow, Cloud API) ]
                      │ (RFC 5424 Syslog / Kafka / Beats Agent 스트리밍)
                      ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 1. 수집기 계층 (Log Collector & Ingestion Layer) ]                     │
│  ├─ NTP 기반 정밀 타임스탬프 동기화 및 버퍼 큐잉                        │
│  └─ [ 2. 파싱 및 정규화 엔진 (Parser & Normalizer) ]                    │
│       └─ 공통 데이터 모델(CEF / ECS / CIM) 매핑 및 UTC 시간대 변환       │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 3. 데이터 보강 계층 (Enrichment Layer) ]                              │
│  ├─ 자산 관리 DB (CMDB) ➔ 자산 중요도(Asset Criticality) 태깅           │
│  ├─ 디렉터리 서비스 (AD/IdP) ➔ 계정 소유자 및 권한 매핑                 │
│  └─ 위협 인텔리전스 (CTI TIP) ➔ IoC 악성 평판 점수 실시간 결합         │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │
                 ┌───────────────────┴───────────────────┐
                 ▼ (실시간 스트림 처리)                  ▼ (인덱싱 및 보존)
┌──────────────────────────────────────┐┌──────────────────────────────────────┐
│ [ 4. 실시간 상관분석 엔진 (SEM) ]     ││ [ 5. 장기 스토리지 및 감사 (SIM) ]   │
│  ├─ 시나리오 기반 룰셋 & 행동 임계치  ││  ├─ WORM 불변 스토리지 (SHA-256 무결성)│
│  └─ [ SOC 관제 경보 (Alert) 및 SOAR ]││  └─ ISMS/PCI-DSS 컴플라이언스 리포트 │
└──────────────────────────────────────┘└──────────────────────────────────────┘
```

선의 의미: 수집된 원시 로그가 정규화 및 맥락 보강을 거친 후, 실시간 상관분석 엔진(SEM)과 장기 불변 스토리지(SIM)로 분기 처리되는 구조

| 구성요소 | 핵심 책임 및 역할 | 비고 |
|:---|:---|:---|
| **로그 수집기 (Collector)** | RFC 5424 Syslog, SNMP Trap, REST API를 통해 초당 수만 EPS의 원시 로그 수집 | Ingestion |
| **정규화 파서 (Normalizer)** | 이기종 로그를 CEF/ECS 표준 스키마로 파싱하고 필드명 및 데이터 타입을 통일 | Common Schema |
| **맥락 보강기 (Enricher)** | CMDB 자산 정보, AD 사용자 계정, CTI 평판 점수를 실시간 조인하여 이벤트 가치 증대 | Enrichment |
| **상관분석 엔진 (Engine)** | 시간 윈도우(Time Window) 내 다중 조건 매칭을 통해 APT 침해 시나리오 탐지 | Correlation |
| **WORM 증적 저장소** | 원본 로그(Raw Log)를 암호화 압축 저장하고 해시 무결성을 검증하여 법적 효력 유지 | Storage |

#### 한줄 요약
- 로그 수집기, 정규화 파서, 맥락 보강기, 실시간 상관분석 엔진, WORM 증적 저장소가 결합한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **룰 튜닝(Rule Tuning / Lifecycle Management)**: 조직의 정상 비즈니스 프로세스(예: 정기 야간 배치 작업)가 공격 룰에 매칭되어 오탐(False Positive)을 발생시키지 않도록, 임계값 조정 및 화이트리스트 예외 조건을 지속 갱신하는 최적화 프로세스.

</details>

```text
1. [수집 및 시간 동기화] 엔드포인트/서버에서 생성된 원시 로그 수집 ➔ NTP 서버 기반 타임스탬프 무결성 검증
            │
            ▼
2. [파싱 및 정규화] 정규표현식 파서가 원시 문자열을 분해하여 `src_ip`, `dst_port`, `user` 필드로 정규화 매핑
            │
            ▼
3. [맥락 데이터 결합] IP 및 계정 정보를 CMDB/AD와 조인하여 내부 자산 여부 및 계정 권한 메타데이터 부착
            │
            ▼
4. [실시간 상관분석] CEP(Complex Event Processing) 엔진이 시계열 룰셋을 평가하여 위협 점수 산출
            │
            ├─ [위협 임계치 초과 시] ➔ SOC 인시던트 티켓 발행 및 SOAR 대응 플레이북 트리거
            ▼
5. [오탐 피드백 및 튜닝] 관제 분석가의 인시던트 종결 피드백을 수렴하여 상관분석 룰의 예외 조건 및 임계치 정밀 조정
```

**동작 원리**

1. **시간 동기화 보장**: 이벤트 순서 역전(Out-of-Order) 방지를 위한 고정밀 밀리초 타임스탬핑
2. **필드 의미 통일**: 이기종 시스템의 속성값을 단일 쿼리 언어(SPL/KQL)로 검색 가능하도록 정규화
3. **위험도 가중치 산출**: 단순 이벤트 발생 횟수가 아닌 자산 중요도 $\times$ 취약점 $\times$ 위협도로 정량화
4. **시계열 패턴 매칭**: `Event A AND Event B within 5 minutes` 형태의 복합 이벤트 처리
5. **폐쇄 루프 엔지니어링**: 관제 요원의 Triage 결과를 바탕으로 오탐 유발 룰셋을 지속적 리팩토링

#### 한줄 요약
- 로그 수집, 스키마 정규화, 맥락 결합, 실시간 상관분석, 오탐 피드백 튜닝 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **로그 저장 및 분석 체계 비교**: 단순 로그 보존용(LMS), 실시간 상관분석용(SIEM), 대규모 빅데이터 심층 분석용(Security Data Lake)의 비교.

</details>

| 비교 항목 | 로그 관리 시스템 (LMS / Log Management) | 보안 정보 및 이벤트 관리 (SIEM) | 보안 데이터 레이크 (Security Data Lake) |
|:---|:---|:---|:---|
| **주요 목적** | **단순 로그 중앙 집계, 감사 증적 보존** | **실시간 위협 탐지, 다계층 상관분석** | **페타바이트급 장기 보존, AI/ML 심층 분석**|
| **핵심 처리 방식** | 배치 인덱싱 및 압축 아카이빙 | **실시간 인메모리 스트림 상관분석 (SEM)** | 분산 스토리지(S3/HDFS) 및 대규모 분산 쿼리 |
| **분석 가능 범위** | 단일 장비/단일 호스트 로그 검색 위주 | **이종 장비 간 다단계 시나리오 상관분석** | **수년 치 원시 데이터 기반 비지도학습 AI 분석**|
| **장기 보관 비용** | 중간 (스토리지 압축 최적화) | **매우 높음 (EPS 및 인덱싱 라이선스 비용)**| **매우 낮음 (클라우드 오브젝트 스토리지 활용)**|
| **적용 영역** | **ISMS/컴플라이언스 규정 준수 감사** | **24x7 SOC 실시간 관제 및 초동 대응** | **위협 헌팅, 장기 침해 포렌식, UEBA 분석** |

#### 한줄 요약
- LMS는 규제 준수 증적 보존용, SIEM은 실시간 위협 상관분석용, Data Lake는 AI 기반 장기 헌팅용이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **IETF RFC 5424 (Syslog Protocol) & NIST SP 800-92**: 엔터프라이즈 환경에서 로그의 구조화 전송 형식(RFC 5424)과 안전한 수집, 보존 기간, 접근 제어, 무결성 보호 가이드라인(NIST SP 800-92)을 정의한 표준.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 침해사고 발생 후 공격자가 증거 인멸을 위해 **서버 로컬 감사 로그를 임의 삭제/변조하는 사고** | **RFC 5424 표준 Syslog 실시간 원격 전송 및 SIEM WORM 불변 스토리지 아카이빙** | 로컬 로그 삭제 시에도 원격 SIEM 내 원본 로그 100% 보존 및 법적 무결성 확보 |
| 벤더별 비표준 Syslog 포맷으로 인한 **SIEM 파싱 오류, 필드 누락 및 상관분석 룰 미작동** | **CEF/ECS 공통 스키마 기반 정규화 엔진 적용 및 파서 유효성 자동 검증 파이프라인** | 이기종 로그 파싱 성공률 99.9% 달성 및 상관분석 룰 정상 동작 보장 |
| 정상적인 야간 배치 작업이나 취약점 스캔으로 인한 **수만 건의 오탐 경보 및 알람 피로도 발생** | **상관분석 룰 튜닝 거버넌스(화이트리스트 예외 처리, 시간대별 임계치 차등화)** 강제 | 오탐률 80% 이상 절감 및 관제 분석가의 고위험 인시던트 대응 집중도 극대화 |

#### 한줄 요약
- 원격 WORM 저장으로 증거를 보존하고, CEF/ECS로 파싱을 정제하며, 룰 튜닝으로 오탐을 방지한다.

## Ⅶ. 결론

- 전사 인프라의 보안 가시성을 통합하고 지능형 위협을 포착하는 **SIEM 아키텍처**는 현대 사이버 보안 운영의 핵심 데이터 허브이며, 실무 구현 시 **NTP 기반의 정밀 타임스탬프 동기화**, **CEF/ECS 표준 스키마 정규화**, **CMDB/CTI 기반의 맥락 보강 및 시계열 상관분석**, **SOAR 연동 및 지속적 룰 튜닝**을 통합 구축하여 신뢰성 높은 실시간 보안 관제 체계를 완성

#### 한줄 요약
- 로그 정규화와 맥락 보강 및 시계열 상관분석을 결합하여 실시간 위협 가시성과 법적 증거 능력을 완벽히 보장한다.
