## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **PKI(Public Key Infrastructure)**: 인증서의 발급•사용•폐기를 관리하는 공개키 기반구조이다.
- **V2X(Vehicle-to-Everything)**: 차량이 주변 객체와 정보를 교환하는 통신이다.
- **Vehicle PKI**: V2X 메시지 인증서를 관리하는 체계이다.

</details>

- 정의/개념: **PKI**를 차량 통신에 적용해 **V2X** 메시지 인증서를 관리하는 **Vehicle PKI**이다.
- 배경/필요성: 장기 인증서를 방송에 쓰면 차량 이동경로가 추적될 가능성이 있다.

#### 한줄 요약

- 송신자 실명을 몰라도 허가된 차량의 변조되지 않은 메시지인지 확인해야 한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **가명 인증서**: 실명 대신 단기 공개키•권한을 증명해 장기 추적을 줄이는 인증서이다.
- **오동작 탐지**: 서명은 유효하지만 거짓이거나 물리적으로 불가능한 메시지를 판별하는 기능이다.

</details>

- 등록•권한 기관을 분리해 정보 결합을 줄인다.
- **가명 인증서**로 메시지 권한과 프라이버시를 보호한다.
- 서명 이후에도 **오동작 탐지**로 물리 개연성을 확인한다.

#### 한줄 요약

- 이름을 가린 임시 자격증명을 바꿔 쓰되 위험 차량은 책임 있게 제재할 수 있어야 한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **Root CA(Root Certificate Authority)**: 최상위 신뢰를 보증하는 인증기관이다.
- **EA(Enrollment Authority)**: 차량의 장기 가입 자격을 확인하는 기관이다.
- **AA(Authorization Authority)**: 단기 V2X 서비스 권한을 발급하는 기관이다.
- **CRL(Certificate Revocation List)**: 만료 전 폐기된 인증서 상태 목록이다.

</details>

```text
차량 PKI
├─ Root CA•정책 앵커
├─ EA•장기 등록 자격
├─ AA•단기 가명 권한
├─ 차량 보안모듈•서명
└─ 오동작 탐지•CRL
```

| 구성요소 | 책임 |
|:---|:---|
| Root CA•정책 앵커 | **Root CA**가 하위 기관 보증 |
| EA•장기 등록 자격 | **EA**가 가입 자격 확인 |
| AA•단기 가명 권한 | **AA**가 단기 인증서 발급 |
| 차량 보안모듈•서명 | 개인키 보호•메시지 서명 |
| 오동작 탐지•CRL | **CRL**로 폐기 상태 배포 |

#### 한줄 요약

- 가입 확인 기관과 방송 이용권 기관을 나눠 한 기관이 차량의 모든 활동을 보기 어렵게 한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **SCMS(Security Credential Management System)**: V2X 인증서의 등록•권한•폐기를 분리 운영하는 체계이다.
- **가입 자격 검증•식별자 분리**: 장기 가입 자격을 확인하고 권한 요청에서 식별정보를 최소화하는 단계이다.
- **단기 가명 인증서 발급**: 서비스•기간별 방송 권한을 단기 인증서로 만드는 단계이다.
- **V2X 메시지 가명 서명**: 단기 개인키로 안전 메시지의 진위와 무결성을 증명하는 단계이다.
- **체인•신선도•개연성 검증**: 인증서 신뢰와 재생 여부 및 물리 가능성을 함께 확인하는 단계이다.
- **오동작 인증서 폐기 판정**: 위험 장치의 인증서를 만료 전에 차단할지 결정하는 단계이다.

</details>

```text
가입 자격•장기 증명 요청
   │
   ▼
1. 가입 자격 검증·식별자 분리
   │ 익명화된 권한 자격
   ▼
2. 단기 가명 인증서 발급
   │
   ▼
3. V2X 메시지 가명 서명
   │ 서명 메시지
   ▼
4. 체인·신선도·개연성 검증
   ├─ 정상 ──► 안전 메시지 사용
   └─ 오동작 증거
          │
          ▼
5. 오동작 인증서 폐기 판정
   │
   ▼
인증서 폐기 상태 배포
```

### 동작 원리

1. 가입 자격 검증·식별자 분리: 장기 식별 노출 축소
2. 단기 가명 인증서 발급: 서비스·기간별 권한 생성
3. V2X 메시지 가명 서명: 안전 정보 진위 증명
4. 체인·신선도·개연성 검증: 인증·물리 가능성 확인
5. 오동작 인증서 폐기 판정: 위험 장치 사용 차단

#### 한줄 요약

- 가명 메시지의 **서명·신선도·개연성 검증**

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **TLS(Transport Layer Security) 인증서**: 차량•서버 연결을 보호하는 인증서이다.
- **가입•방송 자격 분리**: EA 가입 자격과 V2X 방송 권한을 분리하는 원칙이다.

</details>

| 차량 인증서 유형 | 등록 인증서 | 가명 인증서 | TLS 인증서 |
|:---|:---|:---|:---|
| 적용 기준 | EA 가입•권한 요청 | V2X 안전 메시지 서명 | 차량•서버 연결 보호 |
| 핵심 특징 | **가입•방송 자격 분리**의 장기 자격 | **가명 인증서**의 단기 권한 | **TLS 인증서**의 연결 보호 |
| 한계 | 식별자 노출•장기 추적 | 교체 패턴 재연결 | 방송 권한으로 사용 불가 |

> 요약: 장기 가입, 단기 방송, 서버 연결 자격을 분리하는 것이 핵심이다.

#### 한줄 요약

- 차량 실명 자격과 방송용 가명 권한, 서버 연결 인증서는 목적이 서로 다르다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **IEEE(Institute of Electrical and Electronics Engineers)**: 전기전자 기술표준을 개발하는 학회이다.
- **WAVE(Wireless Access in Vehicular Environments)**: 차량 환경 무선접속 기술이다.
- **IEEE 1609.2**: WAVE 메시지 보안 표준이다.
- **IEEE 1609.2.1**: WAVE 인증서 관리 인터페이스 표준이다.
- **ETSI(European Telecommunications Standards Institute)**: 유럽전기통신표준협회이다.
- **TS(Technical Specification)**: 기술 사양 문서 유형이다.
- **ITS(Intelligent Transport Systems)**: 지능형교통체계이다.
- **ETSI TS 103 097**: ITS 보안 헤더•인증서 형식 표준이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 메시지 형식이 다르면 차량 간 서명을 검증할 수 없음 | **IEEE**의 **WAVE**, **IEEE 1609.2** 적용 | 인증서 상호운용 |
| 관리 절차가 다르면 인증서 수명주기가 단절됨 | **IEEE 1609.2.1** 적용 | 등록•권한•폐기 표준화 |
| 지역별 형식 차이로 ITS 상호운용이 깨질 수 있음 | **ETSI**의 **TS**, **ITS**, **ETSI TS 103 097** 적용 | 유럽 형식 호환 |

#### 한줄 요약

- 가명 인증서를 주기적으로 바꾸되 교체 시점•무선 식별자•메시지 패턴이 차량을 다시 연결하지 않게 한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **자격 분리**: 장기 가입, 단기 방송, 서버 연결 인증서를 목적별로 나누는 원칙이다.

</details>

- **자격 분리**에 따라 방송은 단기 가명 인증서, 서버 연결은 TLS 인증서를 적용한다.

#### 한줄 요약

- 실명을 공개하지 않고 메시지 권한을 확인하며 위험 장치를 제재할 수 있어야 한다.
