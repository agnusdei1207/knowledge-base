## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **해커 엑스레이 첩보 CTI (Cyber Threat Intelligence)**: 김정은의 지시를 받은 라자루스 해커 조직이 어제 은행을 털 때 썼던 악성 IP 지표(IoC)와, 놈들의 치밀한 은폐 타격 전술•기법(TTP)을 피 토하며 심층 엑스레이 역추적 분석해 낸 북한 사이버 무기 인텔리전스 살생부 문서 팩트이다.
- **CTI 기요틴 자동화 타격망 (CTI Automation)**: 다크웹과 정보 공유소에서 쏟아지는 수백만 개 CTI 해킹 첩보 피드 덤프를 사람 손으로 복붙하지 않고, 기계가 초당 수천 개씩 1초 컷 수집 ─> 글로벌 표준 규격 정규화 ─> 가짜 IP 걸러내기 신뢰도 평가 ─> 전사 방화벽에 차단 룰셋으로 일괄 타격 배포하는 전 과정을 단일 핏줄로 연결해 버리는 무관용 방어 운영 체계 방식 팩트이다.

</details>

- 정의: 외부 해커 무기 첩보 **CTI** 덤프의 무자비한 타임어택 수집•1비트 정규화 락다운•신뢰도 영혼 평가 엑스레이•방화벽 차단 룰셋 배포 타격을 기계식 핏줄로 원스톱 무관용 연결하는 철벽 **CTI 오토메이션 기요틴 자동화 팩트 체계**이다.
- 배경: 카스퍼스키나 안랩에서 주는 첩보 피드를 엑스레이 검증 팩트 체크 없이 방화벽에 무지성 자동 배포 밀어넣기 연동했다간, 구글 8.8.8.8 같은 정상 IP나 이미 1년 전 버려진 만료 깡통 지표(IP)까지 막아버려 대국민 서비스망이 스스로 셧다운 폭파 마비당하는 대참사 오차단 자폭을 절대 통제 방어 불가능하기 때문이다.

#### 단기 요약

- 외부 다크웹에서 퍼온 공격자 IP 첩보 덤프를 그대로 방화벽에 밀어 넣지 않고, 우리 회사 실제 서버 1조 자산 핏줄과 대조 엑스레이 크로스 체크해 100% 믿을 수 있고 오늘 아침까지 유효 살아있는 살생부 정보만 방화벽과 백신 탐지•차단 엔진에 타겟 배포 전달하는 것이 생존 1순위 핵심 팩트이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **해커 족적 지표 IoC (Indicator of Compromise)**: 해커가 내 서버를 뚫고 들어왔을 때 100% 남기고 가는 피 묻은 랜섬웨어 해시(Hash), 도메인 주소(C&C), 악성 IP 등 엑스레이로 당장 색출 방화벽 차단이 가능한 깡통 침해 흔적 관측값 팩트이다.
- **놈들의 파멸 전술 뼈대 TTP (Tactics, Techniques, and Procedures)**: 단순한 IP 쪼가리(IoC)가 아니라, 해커가 목표 서버를 조지기 위해 어떻게 침투(전술)하고, 어떤 권한 탈취 스크립트(기법)를 치며, 은폐를 위해 로그를 지우는 행동 시퀀스(절차)까지 통째로 까발려 해부한 공격자의 영혼 행동 방식 팩트이다.
- **보안 기밀 신호등 TLP (Traffic Light Protocol)**: "이 CTI 문서는 국가 1급 기밀이니 너네 보안팀만 보고 끝내라(TLP:RED)" 거나 "이건 동네방네 퍼트려도 된다(TLP:CLEAR)"는 식으로, CTI 첩보의 외부 유출 금지와 타 기관 재공유 범위를 락킹 표시하는 글로벌 팩트 신호등 규칙이다.
- **글로벌 첩보 언어 스키마 STIX (Structured Threat Information eXpression)**: 해커 조직, 악성코드 해시, 공격 TTP가 서로 어떻게 얽혀있는지 중구난방 엑셀로 쓰지 않고, 100% 표준화된 제이슨(JSON) 객체와 화살표 릴레이션 관계 구조로 팩트 정규화 표현하는 글로벌 타격 방언 통일 규격이다.
- **API 핏줄 교환 통신 TAXII (Trusted Automated eXchange of Intelligence Information)**: 미국 CISA와 우리 회사 방화벽 플랫폼 사이에서, 위에서 만든 STIX 첩보 구조체 묶음을 암호화된 API 핏줄로 1초 만에 안전하게 밀어주고 빨아들이는 글로벌 정보 교환 택배 프로토콜 팩트이다.

</details>

- **STIX 살생부 객체•관계망으로 해커 위협정보 뼈대 구조화 타격**: 단순 IP 엑셀 파일이 아니라, 해커 조직과 악성 IP 간의 연결고리를 **STIX** 객체와 거미줄 릴레이션 관계로 무관용 팩트 구조화 락킹한다.
- **TAXII API 교환 핏줄 연결과 TLP 신호등 표시로 국가 기밀 공유 범위 질식 제한**: **TAXII** 프로토콜로 방화벽에 차단 룰셋을 초 단위로 밀어 넣되, **TLP** 락다운 표시 딱지로 내부 유출 보안 기밀 범위를 무관용 통제 제한한다.
- **IoC 깡통 지표•TTP 영혼의 출처•신뢰 스코어•타임아웃 시효•자산 관련성 현미경 통제**: **IoC** 지표와 **TTP** 정보가 어디서 굴러먹다 왔는지 1차 출처, 사기 확률 스코어, 1년 전 죽은 IP인지 **시효** 검증, 우리 회사 망 핏줄과의 **자산 관련성**을 크로스 팩트 엑스레이 통제한다.

#### 한줄 요약

- 수백만 개 STIX 형식 포맷만 예쁘게 맞췄다고 무지성 배포하는 게 아니라, 이 첩보가 카스퍼스키 출처인지, 어제자로 만료된 좀비 IP인지, 우리 대국민 결제망 내부 핏줄 자산과 얽힌 공격인지 세 가지 엑스레이를 팩트 검증한 뒤에 방화벽에 꽂는 것이 절대 핵심이다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **통합 첩보 믹서기 사령부 TIP (Threat Intelligence Platform)**: 구글 다크웹 봇, 안랩 유료 피드, KISA 무료 공유 등 수백 군데서 쏟아지는 파편화된 CTI 첩보 덤프 쓰레기 더미를 한 통에 다 때려 넣고, 1초 만에 팩트 정규화 뼈대 조립•사기 IP 평가 필터링•전사 방화벽 API 자동 배포 타격을 지휘하는 중앙 통합 컨트롤타워 플랫폼 팩트이다.
- **오픈소스 맨땅 첩보 수집 OSINT (Open-Source Intelligence)**: 돈 주고 사는 유료 첩보가 아니라, 구글링 다크웹 긁기, 트위터 해커 포럼 등 인터넷 바다 공개 출처에서 무자비하게 덤프 긁어 수집한 날것의 위협 정보 팩트 찌꺼기이다.
- **혈관 통로 API (Application Programming Interface)**: 중앙 TIP 사령부와 말단 안랩 방화벽, 크라우드스트라이크 EDR 백신 도구가 수십만 개 CTI 차단 룰셋 덤프를 실시간으로 밀어 넣고 멱살 잡아 교환하는 기계적 핏줄 연결 통신 규격 팩트이다.

</details>

```text
[무관용 STIX/TAXII 기반 CTI 기요틴 자동화 타격 및 방화벽 롤아웃 아키텍처]

├─ [1. 첩보 쓰레기 덤프 무차별 수집 경계]

│
├─ [4. 기요틴 차단 룰셋 배포 및 기밀 유출 통제 경계]

│
└─ [5. 실전 방화벽 타격 검증 팩트 환류 경계]

```

- 중앙 **TIP** 사령부는 수백 군데서 긁어모은 CTI 피드 쓰레기 덤프의 **100% 정규화 뼈대 조립•가짜 정보 엑스레이 평가 필터링•전사 방화벽 무관용 차단 배포** 과정을 단일 컨트롤타워로 팩트 통합 지휘한다.

#### 한줄 요약

- 수백만 개 해킹 IP 지표 하나라도, "이게 러시아 다크웹 출처인지(출처), 3년 전 죽은 공격 관측 시점인지(시효), 북한 놈들 전술(공격 관계)인지, 우리 내부 인트라넷 1조 자산 망 핏줄에서 사용 중인 IP(내부 사용 여부)인지" 4중 엑스레이를 팩트 확인한 락다운 뒤에야 방화벽 차단 엔진에 배포 스위치를 누르는 게 오차단 부도 참사를 막는 절대 핵심이다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **살생부 품질 스코어 점수 (Quality Score)**: 이 첩보가 카스퍼스키 발 100% 팩트 신뢰도인지, 1시간 전 최신 시효인지, 우리 회사 핵심망 타겟 자산 관련성인지, 어제 실제 적중 차단 결과 덤프를 모조리 결합해 방화벽 자동 배포 YES/NO를 결단하는 최종 기요틴 락다운 판단값이다.
- **STIX CTI 살생부 객체 구성 조립 (STIX CTI Object Construction)**: 엑셀 쓰레기로 들어온 위협 덤프 정보를 글로벌 표준 STIX 해커 객체•관계망 릴레이션•출처 ID•타임스탬프 뼈대 구조로 1비트 오차 없이 정규화 조립하는 진입 단계이다.
- **CTI 팩트 영혼 보강•품질 락킹 점수 산정 (CTI Enrichment and Quality Scoring)**: 자체 KISA 화이트리스트 출처 대조, 30일 시효 만료 엑스레이, 내부 자산 핏줄 연관성을 크로스 평가해 최종 방화벽 배포 기요틴 판단값(스코어)을 찍어내는 단계이다.
- **차단 룰셋 배포 승인 도장•기밀 공유 락다운 범위 결정 (Distribution Approval and Scope Determination)**: 산출된 품질 기준 스코어 통과 여부와 신호등 TLP 기밀 등급에 따라, 1초 컷 방화벽 룰 자동 배포 여부 및 타 기관 수신자 재공유 한계를 팩트 무관용 정하는 단계이다.
- **TAXII API CTI 배송 묶음 생성 타격 (TAXII CTI Bundle Generation)**: 승인된 핵심 살생부 지표와 관계망 구조체를 방화벽이 알아들을 수 있는 TAXII 2.1 글로벌 표준 교환 봉투 형식으로 무결점 구성 포장하는 팩트 단계이다.
- **적중 킬 스코어•정상 오탐 헛발질•만료 폐기 사후 엑스레이 평가 (Hit, False Positive and Expiration Evaluation)**: 전사 방화벽에 배포한 IP 지표가 실제 해커를 잡아냈는지(탐지 성과), 네이버를 막았는지(오탐), 6개월 지나 수명이 다했는지(유효성) 피 토하게 다시 평가 환류하는 감시 단계이다.

</details>

```text
[외부 다크웹 · 유무료 피드 수백만 CTI 쓰레기 덤프 폭우 수신 타격]
```

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **뼈대 해부 STIX 역할 (Role of STIX)**: 김정은의 악성 해시 객체, 도메인 관계 화살표, 타임스탬프, 1차 출처 ID를 누가 봐도 똑같이 해석하게 무관용 기계어 제이슨(JSON)으로 뼈대 표현하는 규격 역할 타격이다.
- **택배 핏줄 TAXII 역할 (Role of TAXII)**: 미 국방부 서버와 우리 회사 방화벽 플랫폼 사이를 암호화된 HTTPS 터널로 뚫고, STIX로 포장된 CTI 무기 박스를 1비트 유출 없이 안전하게 전송 꽂아넣는 통신 택배 기사 역할 팩트이다.
- **중앙 통합 사령부 TIP 역할 (Role of TIP)**: 전 세계 수천 개 파편화된 다중 피드 덤프의 폭우 수집, 정상 IP 걸러내기 엑스레이 영혼 평가, 전사 방화벽 룰셋 1초 컷 일괄 차단 배포를 중앙 한 군데서 멱살 쥐고 통합 통제 지휘하는 마스터 뇌 역할 팩트이다.

</details>
