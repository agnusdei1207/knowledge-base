## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **SOAR (Security Orchestration, Automation, and Response)**: 이종 보안 솔루션 API를 연계하고 플레이북을 통해 분석과 차단을 자동화하는 플랫폼.
- **Security Playbook (OASIS CACAO)**: 위협 발생 시 수행해야 하는 조건 분기, CTI 조회, 차단 API 호출을 정의한 표준 실행 워크플로.

</details>

- 정의/개념: API와 플레이북으로 대응을 자동화하는 **SOAR 플랫폼**
- 배경/필요성: 대량 경보의 수동 처리로 **초동 대응 지연**

#### 한줄 요약
- 이종 API 오케스트레이션과 표준 플레이북을 통해 위협 분석 및 초동 차단을 초 단위로 자동화한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **SOA (Security Orchestration & Automation)**: 서로 다른 보안 장비 간 워크플로를 연결하고 스크립트화하여 자동 실행하는 기능.
- **Human-in-the-loop (인간 승인 개입)**: 핵심 서버 차단 등 고위험 조치 전 분석가의 1-클릭 승인을 강제하여 비즈니스 오차단 사고를 방지하는 거버넌스.

</details>

- **3대 핵심 기능의 단일 플랫폼 통합**: 보안 오케스트레이션 및 자동화(SOA), **사고대응 케이스 관리(SIRP), 위협 인텔리전스(TIP)의 결합**
- **초 단위로 단축되는 평균 대응 시간(MTTR)**: 수동 분석 30분 이상 소요 작업을 **플레이북을 통해 수 초 이내에 실시간 완결**
- **안전한 위험 분기 제어(Human-in-the-loop)**: 일반 단말은 완전 무인 차단, **핵심 서버는 1-Click 승인 절차를 거치도록 동적 분기**

#### 한줄 요약
- 3대 기능(SOA/SIRP/TIP) 결합, MTTR 초 단위 단축, Human-in-the-loop 안전 분기를 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **API Connector**: 방화벽, EDR, 메일 게이트웨이 등 타사 보안 장비의 REST API를 호출하여 상태를 변경하는 모듈.

</details>

```text
SOAR
|-- 인입 계층
|-- 플레이북 엔진
|   |-- CTI 보강기
|   |-- 정책 분기
|   `-- 인간 승인 포털
|-- 실행 계층
|   `-- API 커넥터
`-- 케이스 관리 시스템
```

선의 의미: 인입된 인시던트가 플레이북 엔진에서 CTI 보강과 승인 분기를 거쳐 API 커넥터를 통해 엔드포인트/방화벽/계정 제어를 자동 완수하는 구조

| 구성요소 | 핵심 엔지니어링 책임 | 주요 특징 |
|:---|:---|:---|
| **플레이북 엔진** | OASIS CACAO 표준 워크플로를 해석하고 **단계별 자동 작업 실행** | Workflow Engine |
| **API 커넥터/앱 (App)**| 수백 개 보안 솔루션과 **사전 정의된 API 인터페이스로 상호 통신** | App Integration |
| **TIP 맥락 보강기** | 인입된 IP, 도메인, 해시를 **CTI 피드와 대조하여 악성 여부 자동 채점** | Threat Intel |
| **인간 승인 포털** | 고위험 차단 액션 실행 전 **Slack, Email 기반 1-클릭 승인 제공** | Approval Gateway|
| **케이스 관리 시스템**| 인시던트의 **타임라인, 증적, SLA 준수율, 감사 로그 기록 관리** | Case Management |

#### 한줄 요약
- 플레이북 엔진, API 커넥터, TIP 맥락 보강기, 인간 승인 포털, 케이스 관리(SIRP)가 결합한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Phishing Playbook Flow**: 신고 접수 → 파싱 → CTI 조회 → 전사 동일 메일 일괄 삭제 → 방화벽 C2 차단 → 티켓 종결.

</details>

```text
인시던트 인입, CTI 보강, 승인 분기, 다중 API 차단 및 티켓 종결 파이프라인
        │
   1. [사건 인입] SIEM에서 "의심스러운 외부 C2 연결 탐지" 인시던트가 SOAR로 실시간 전송
        │
   2. [CTI 자동 보강] 목적지 IP/URL을 추출하여 MISP에 REST API 질의 ➔ [악성 판정]
        │
   3. [위험도 평가 및 분기]
       ├─ [일반 PC 단말]: EDR API를 호출하여 호스트 네트워크 즉시 자동 격리 (Full-Auto)
       └─ [핵심 서버/DB]: Slack 웹훅으로 SOC 팀장에게 승인 요청 발송 (Human-in-the-loop)
        │
   4. [오케스트레이션 차단 실행]
       ├─ NGFW API 호출 ➔ C2 IP 인바운드/아웃바운드 차단 룰 추가
       ├─ EDR API 호출 ➔ 악성 프로세스 강제 종료 및 레지스트리 런키 제거
       └─ Active Directory API 호출 ➔ 사용자 세션 강제 만료 및 비밀번호 리셋
        │
   ▼
5. [완료 검증 및 증적 기록] 방화벽 룰 적용 상태 재조회(멱등성 검증) ➔ ITSM 티켓 자동 종결
```

#### 한줄 요약
- 인시던트 인입 → CTI 자동 보강 → 위험도 승인 분기 → 다중 API 일괄 차단 → 완료 검증 및 티켓 종결 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **수동 대응** vs **인간 승인 반자동** vs **완전 무인 자동화**.

</details>

| 비교 항목 | 수동 대응 (Manual Operations) | 인간 승인 반자동 (Human-in-the-Loop) | 완전 무인 자동화 (Fully Automated) |
|:---|:---|:---|:---|
| **조사 및 분석 주체** | **보안 분석가 (수동 로그 검색)** | **SOAR 로봇 (CTI 평판 자동 보강)** | **SOAR 로봇 (전 과정 자동 분석)** |
| **차단 조치 실행 주체**| **분석가가 방화벽 GUI 수동 접속** | **분석가 1-Click 승인 ➔ 로봇 실행** | **SOAR 로봇 (사전 정의 룰 기반 즉시 차단)**|
| **평균 대응 시간 (MTTR)**| **수십 분 ~ 수 시간 (지연 큼)** | **수 분 이내 (승인 즉시 완결)** | **수 초 ~ 수 밀리초 (초고속 실시간 대응)** |
| **오조치(오차단) 위험도**| 낮음 (사람이 맥락을 확인) | **극도로 낮음 (로봇의 속도 + 사람의 검증)**| 오탐 룰셋 배포 시 전사 업무 마비 위험 |
| **주요 권장 적용 영역** | **고도화된 신종 APT 공격, 표적 침해**| **핵심 서버 격리, 임원 계정 잠금** | **스팸/피싱 메일 차단, 단순 악성 IP 격리** |

#### 한줄 요약
- 수동 대응은 신종 APT 포렌식용, 인간 승인은 고위험 자산 격리용, 완전 무인은 단순 반복 알람 대량 처리용이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **OASIS CACAO 2.0**: 플레이북의 벤더 종속성을 제거하고 표준 JSON 스키마로 상호 교환하기 위한 국제 표준 규격.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 벤더 종속적 스크립트 작성으로 인한 **보안 장비 교체 시 플레이북 전면 재개발 오버헤드** | **`OASIS CACAO 2.0 표준 플레이북 스펙 도입 및 공통 API 어댑터 추상화`** | 이기종 솔루션 간 플레이북 100% 재사용 및 락인 방지 |
| 완전 무인 자동화 오류로 인해 **정상 ERP DB 서버가 네트워크에서 차단되는 사고** | **고위험 자산에 대한 `Human-in-the-loop 승인 강제 및 1-Click 롤백 로직 구현`** | 오조치 비즈니스 중단 0% 달성 및 즉각 원상 복구 |
| 방화벽/EDR 네트워크 일시 단절로 인한 **API 차단 명령 유실 및 대응 실패** | **`비동기 메시지 큐 기반의 지수 백오프(Exponential Backoff) 재시도 엔진`** 탑재 | 일시적 네트워크 장애 시에도 차단 명령 유실 0% 달성 |
| 장비별 API 속도 제한(Rate Limit) 초과로 인한 플레이북 실행 지연 | **`API 호출 큐 스로틀링(Throttling) 및 커넥션 풀링`** 최적화 | API 거부 에러 방지 및 대량 차단 명령 안정적 집행 |

#### 한줄 요약
- CACAO 표준으로 락인을 방지하고, Human-in-the-loop과 롤백으로 오조치를 막으며, 큐/재시도로 명령 유실을 방지한다.

## Ⅶ. 결론

- 반복 경보는 **완전 자동화**, 핵심 자산은 **인간 승인** 선택

#### 한줄 요약
- SOAR는 이종 API 오케스트레이션과 표준 CACAO 플레이북 및 인간 승인 통제를 결합하여 MTTR을 초 단위로 단축하는 자동 대응 플랫폼이다.
