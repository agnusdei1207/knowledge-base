## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **동형 암호(Homomorphic Encryption)**: 암호문을 복호화하지 않고 연산해도 그 결과를 복호화하면 평문 연산 결과와 대응하는 공개키 암호이다.
- **동형성(Homomorphism)**: 암호문 연산의 복호화 결과가 동일한 평문 연산 결과와 대응하는 성질이다.

</details>

- 정의/개념: **동형성**을 이용해 암호문 상태에서 계산하는 **동형 암호**이다.
- 배경/필요성: 외부 분석 전에 데이터를 복호화하면 사용 중인 평문이 노출된다.

#### 한줄 요약

- 서버가 암호문을 복호화하지 않고 암호문 상태에서 연산을 수행해 결과 암호문을 반환하면, 개인키 소유자만 결과를 복호화할 수 있다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **노이즈 예산(Noise Budget)**: 계산 후에도 정확히 복호화할 수 있는 노이즈 허용 범위이다.
- **완전 동형 암호(Fully Homomorphic Encryption, FHE)**: 부트스트래핑으로 노이즈를 갱신하여 임의 깊이의 연산을 지원하는 동형 암호이다.
- **계산 무결성 미보장**: 암호문 기밀성을 유지해도 평가 서버가 지정된 회로를 정확히 실행했는지는 별도로 증명해야 한다는 한계이다.

</details>

- 제한된 깊이 또는 **FHE** 부트스트래핑에 맞춘 **노이즈 예산** 관리가 핵심이다.
- 평문 대비 암호문 크기와 연산량이 증가한다.
- 데이터 기밀성은 제공하지만 **계산 무결성 미보장** 한계가 있다.

#### 한줄 요약

- 서버는 원문을 볼 수 없지만 계산을 빼먹거나 다른 회로를 실행할 수 있으므로, 암호화와 별도로 계산 결과가 맞는지 검증해야 한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **평가 키(Evaluation Key)**: 재선형화•회전•부트스트래핑을 지원하는 공개 보조 키이다.
- **암호문 슬롯(Ciphertext Slot)**: 한 암호문에서 같은 연산을 병렬 적용하는 논리적 위치이다.
- **모듈러스(Modulus)**: 계수 계산 범위와 노이즈 예산•보안 수준을 결정하는 나눗셈 기준값이다.

</details>

```text
동형 암호 실행 구조
├─ 인코더•암복호화기
├─ 키•파라미터 저장소
├─ 동형 평가 엔진
└─ 노이즈•레벨 관리자
```

가지의 의미: 값 변환•키 보관•암호문 계산•예산 통제 책임을 나눈 구조다.

| 구성요소 | 책임 |
|:---|:---|
| 인코더•암복호화기 | 값을 **암호문 슬롯**에 인코딩하고 암복호화 |
| 키•파라미터 저장소 | **평가 키**•차수•**모듈러스** 보관 |
| 동형 평가 엔진 | 암호문 상태에서 허용 회로 실행 |
| 노이즈•레벨 관리자 | 노이즈•스케일•깊이 추적 |


#### 한줄 요약

- 하나의 암호문에 여러 평문 값을 슬롯별로 패킹하면 서버가 단일 SIMD 연산으로 모든 슬롯에 동일 연산을 적용해 처리 비용을 분산할 수 있다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **회로 깊이(Circuit Depth)**: 앞 연산에 의존해 순차적으로 이어지는 곱셈 단계 수이다.
- **재선형화(Relinearization)**: 곱셈 후 커진 암호문 차수를 평가 키로 줄이는 기법이다.
- **부트스트래핑(Bootstrapping)**: 암호문의 노이즈를 줄여 추가 연산 여유를 확보하는 기법이다.
- **키•파라미터 생성**: 회로 깊이•보안 수준•오차 한도에 맞춰 키와 암호 파라미터를 만드는 단계이다.
- **입력 인코딩•암호화**: 입력값을 슬롯에 배치하고 공개키로 암호문을 생성하는 단계이다.
- **암호문 회로 평가**: 복호화 없이 지정된 회로를 실행하며 암호문 차수와 노이즈를 관리하는 단계이다.
- **평가 암호문 복호화•검증**: 비밀키로 결과를 복구하고 노이즈 또는 근사 오차가 허용 범위인지 판정하는 단계이다.

</details>

```text
1. 키•파라미터 생성
        │
        ▼
2. 입력 인코딩•암호화
        │
        └── 암호문•평가 회로 전달
                    │
                    ▼
3. 암호문 회로 평가
        ├─ 예산 부족: 부트스트래핑 또는 중단
        └─ 예산 충족: 평가 암호문 반환
                         │
                         ▼
              4. 평가 암호문 복호화•검증
                         ├─ 오차 초과: 결과 거부
                         └─ 오차 허용: 평문 결과 사용
```

### 동작 원리

1. **키•파라미터 생성**: **회로 깊이**•보안•오차 한도를 반영한다.
2. **입력 인코딩•암호화**: **암호문 슬롯**을 구성해 입력 암호문을 생성한다.
3. **암호문 회로 평가**: **재선형화**와 필요 시 **부트스트래핑**으로 노이즈•레벨을 관리하며 계산한다.
4. **평가 암호문 복호화•검증**: 평문 결과 복구와 노이즈•허용 오차를 판정한다.


#### 한줄 요약

- 계산 도중 노이즈 예산이 다 떨어지면 결과를 열 수 없으므로, 실행할 곱셈 깊이를 먼저 정하고 키와 파라미터를 만들어야 한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **브라커스키-판-베르코테런(Brakerski/Fan-Vercauteren, BFV)**: 정확한 정수•모듈러 연산을 지원하는 동형 암호 방식이다.
- **브라커스키-젠트리-바이쿤타나탄(Brakerski-Gentry-Vaikuntanathan, BGV)**: 레벨별 깊은 정수 연산을 지원하는 동형 암호 방식이다.
- **천-김-김-송(Cheon-Kim-Kim-Song, CKKS)**: 실수•복소수의 근사 연산을 지원하는 동형 암호 방식이다.
- **제한 동형 암호(Leveled Homomorphic Encryption)**: 미리 정한 회로 깊이 안에서 덧셈•곱셈을 수행하는 방식이다.

</details>

| 동형 암호 방식 | BFV | BGV | CKKS |
|:---|:---|:---|:---|
| 적용 기준 | 정확한 합계•횟수 계산 | 깊은 정수 회로 계산 | 통계•기계학습 추론 |
| 핵심 특징 | **BFV**의 정확한 정수•모듈러 연산 | **BGV**의 레벨별 정확한 정수 연산 | **CKKS**의 실수•복소수 근사 연산 |
| 한계 | 깊이에 따른 파라미터 증가 | 레벨 관리 복잡성 | 스케일 오류•근사 오차 누적 |

> 요약: 정수 정확도•실수 오차•깊이로 방식을 선택한다.

> **제한 동형 암호**는 정한 깊이 안에서 계산하고, **FHE**는 부트스트래핑으로 연산 깊이를 연장한다.

#### 한줄 요약

- 한 건도 틀리면 안 되는 정수 집계는 BFV•BGV를 쓰고, 작은 오차를 허용하는 실수 통계와 기계학습은 CKKS를 쓴다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **레벨(Level)**: 남은 모듈러스 단계와 추가로 수행할 수 있는 곱셈 범위이다.
- **스케일(Scale)**: CKKS에서 실숫값의 정밀도를 관리하는 배율이다.
- **국제표준화기구/국제전기기술위원회(International Organization for Standardization/International Electrotechnical Commission, ISO/IEC) 18033-6:2019**: Exponential ElGamal•Paillier 동형 암호 메커니즘을 규정한 국제 표준이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 부분 동형 방식 구현 차이 | **ISO/IEC 18033-6** 준수 | 구현 기준 일관화 |
| 깊이•노이즈 예산 고갈 | **회로 깊이**•**레벨** 산정과 **부트스트래핑** | 복호화 실패 방지 |
| CKKS의 스케일 오류 | 연산 단계별 **스케일** 정렬 | 근사 오차 누적 억제 |
| **계산 무결성 미보장** | 별도 증명•표본 재계산 | 오연산•누락 탐지 |

#### 한줄 요약

- 의료기관은 환자 값을 암호화한 채 외부 서버에서 평균을 계산하고, 허용 오차 안의 결과만 복호화해 원문 노출을 줄인다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **방식 선택 기준**: 정수 정확도, 실수 오차 허용치, 필요한 회로 깊이와 결과 검증 요구사항을 함께 고려하는 결정 기준이다.

</details>

- **방식 선택 기준**에 따라 정확한 정수 연산은 **BFV**•**BGV**, 근사 실수 연산은 **CKKS**를 선택한다.

#### 한줄 요약

- 원문을 숨긴 채 계산할 수 있어도 계산 회로와 결과가 맞다는 보장은 없으므로, 데이터형•깊이•오차에 맞는 방식과 별도 결과 검증을 정해야 한다.
