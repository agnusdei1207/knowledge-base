## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **ISO(International Organization for Standardization)**: 국제 표준을 개발•발행하는 국제 기구.
- **IEC(International Electrotechnical Commission)**: 전기•전자 분야 국제 표준을 개발하는 협력 기구.
- **ISO/IEC 29100(Privacy Framework, ISO 29100)**: 프라이버시 공통 원칙과 용어를 제시하는 프레임워크.
- **ISO/IEC 27701(Privacy Information Management System, ISO 27701)**: 프라이버시 통제를 운영•감사•개선하는 관리체계 요구사항.
- **PIMS(Privacy Information Management System)**: 개인정보 위험과 통제를 범위•책임•운영•점검•개선의 경영 주기로 관리하는 개인정보 관리체계.

</details>

- 정의/개념: **ISO**와 **IEC**의 **ISO/IEC 29100** 원칙을 **ISO/IEC 27701**의 **PIMS** 운영체계로 구현.
- 배경/필요성: 공통 원칙만으로는 역할별 통제 운영과 감사 증적을 체계적으로 확보하기 어려움.

#### 한줄 요약

- 29100은 공통 언어, 27701은 이를 운영하는 경영체계이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **프라이버시 원칙(Privacy Principles)**: 개인정보 처리의 목적•정당성•보호를 위해 준수해야 할 공통 기준.
- **책임성(Accountability)**: 조직이 역할별 통제 수행과 증거로 법적•사회적 준수 책임을 설명하는 원칙.
- **컨트롤러(Data Controller)**: 개인정보 처리의 목적과 수단을 결정하는 정보 처리 주체.
- **프로세서(Data Processor)**: 컨트롤러의 지시와 위탁에 따라 개인정보를 대신 처리하는 주체.

</details>

- **ISO/IEC 29100**의 **프라이버시 원칙**과 공통 용어 적용.
- **ISO/IEC 27701**의 **PIMS** 생명주기 요구사항 운영.
- **컨트롤러**•**프로세서**별 **책임성** 통제 구분 명확화.

#### 한줄 요약

- 표준 인증과 국가별 개인정보 법률 준수는 별도로 확인한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **PIMS 거버넌스(PIMS Governance)**: 개인정보 처리 범위•정책•역할•자원을 정하고 프라이버시 위험과 통제 운영을 감독하는 체계.
- **통제 증적(Control Audit Trail)**: 처리 기록•승인•감사 결과로 보호조치의 정상 작동을 입증하는 증거 자료.
- **지속 개선(Continual Improvement)**: 감사 발견사항과 부적합 원인을 시정해 관리체계를 지속적으로 보완하는 과정.

</details>

```text
프라이버시 관리체계
├─ ISO/IEC 29100 프라이버시 원칙
├─ PIMS 거버넌스
│  └─ 범위 · 정책 · 역할
├─ 처리 역할 · 위험
│  └─ 컨트롤러 · 프로세서 위험
├─ 프라이버시 통제
│  └─ 개인정보 생명주기 보호조치
└─ 증적 · 지속 개선
   └─ 감사 · 시정 결과
```

| 구성요소 | 책임 |
|:---|:---|
| 프라이버시 원칙 | **프라이버시 원칙**으로 처리 목적•보호 기준 제시 |
| PIMS 거버넌스 | **PIMS 거버넌스**로 범위•정책•책임 설정 |
| 처리 역할•위험 | **컨트롤러**•**프로세서**별 위험 평가 |
| 프라이버시 통제 | 생명주기 보호조치 실행과 **통제 증적** 생성 |
| 증적•지속 개선 | **지속 개선**으로 감사•시정 결과 관리 |

#### 한줄 요약

- 원칙을 책임•통제•감사 증거로 이어 운영한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **처리 역할(Processing Roles)**: 각 개인정보 처리 활동에서의 컨트롤러 및 프로세서 권한•책임 구분.
- **정보 경계(Information Boundary)**: PIMS가 적용 및 관리할 서비스•조직•데이터의 물리적•논리적 범위.
- **법규 요구 연결(Legal Requirement Mapping)**: 국가별 법적 의무를 프라이버시 위험•통제•증적 항목에 매핑하는 기법.
- **표준 요구 연결(Standard Requirement Mapping)**: ISO 공통 원칙을 프라이버시 위험•통제•증적 구조에 매핑하는 과정.
- **법규•ISO 29100 요구 식별(Legal and ISO 29100 Requirement Identification)**: 관계 법규•계약 사항과 ISO 공통 원칙을 종합 분석하는 단계.
- **PIMS 범위•처리 역할 확정(PIMS Scope and Role Definition)**: 관리체계 대상 활동, 정보 경계, 처리 주체 역할을 확정하는 단계.
- **프라이버시 위험•통제 계획(Privacy Risk and Control Planning)**: 식별한 위험의 처리 방안과 세부 보호 통제를 결정하는 단계.
- **통제 운영•증적 생성(Control Operation and Evidence Generation)**: 보호 통제를 이행하고 수행 결과와 증거 자료를 기록하는 단계.
- **부적합 원인•개선 결정(Non-conformity Root Cause and Improvement Decision)**: 감사 발견사항의 원인을 시정하고 PIMS 관리 범위를 보완하는 단계.

</details>

```text
법규 · ISO/IEC 29100 요구
             │
             ▼
1. 법규•ISO 29100 요구 식별
             │
             ▼
2. PIMS 범위•처리 역할 확정
             │
             ▼
3. 프라이버시 위험•통제 계획
             │
             ▼
4. 통제 운영•증적 생성
             │
             ▼
       감사 발견사항
             │
             ▼
5. 부적합 원인•개선 결정
             │
             └──── 시정조치 ────┐
                                └─ 통제 운영으로 환류
```

### 동작 원리

1. **법규·ISO 29100 요구 식별**: 법규·표준 요구 분석
2. **PIMS 범위·처리 역할 확정**: 역할·정보 경계 확정
3. **프라이버시 위험·통제 계획**: 위험 처리 방안 결정
4. **통제 운영·증적 생성**: 결과·작동 근거 기록
5. **부적합 원인·개선 결정**: 시정조치·범위 갱신

#### 한줄 요약

- 원칙을 데이터 흐름의 통제와 감사 증거로 구체화한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

</details>

| 프라이버시 표준 | ISO/IEC 29100:2024 | ISO/IEC 27701:2025 |
|:---|:---|:---|
| 적용 기준 | **ISO/IEC 29100** | **ISO/IEC 27701** |
| 핵심 특징 | 프라이버시 원칙•용어 | PIMS 요구사항•지침 |
| 한계 | 실행 통제 부족 | 법률 준수 자동 보장 불가 |

#### 한줄 요약

- 29100은 프레임워크, 27701은 운영•증명 체계이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **ISO/IEC 27706:2025(PIMS Certification Body Requirements, ISO 27706)**: PIMS 감사 및 인증기관의 역량과 인증 활동 일관성 요구사항을 규정한 국제 표준.
- **SaaS(Software as a Service)**: 소프트웨어 기능을 네트워크 서비스로 제공하며 PIMS 범위에 통제 증적을 반영하는 형태.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 공통 용어•원칙 | **ISO/IEC 29100**(2024) 적용 | 이해관계자 기준 통일 |
| PIMS 수립•개선 | **ISO/IEC 27701**(2025) 적용 | 책임•통제 증적 확보 |
| 인증기관 신뢰 | **ISO/IEC 27706:2025** 확인 | 감사•인증 역량 검증 |

#### 한줄 요약

- **SaaS**도 원칙, 역할, 통제, 감사 증거를 하나의 PIMS로 관리한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **표준과 법률의 분리 검증(Separation of Standards and Legal Compliance)**: PIMS 인증이 국가별 법률 준수를 자동 보장하지 않음을 검증하는 원칙.

</details>

- 원칙은 **ISO/IEC 29100**, 운영은 **ISO/IEC 27701** 적용

#### 한줄 요약

- 같은 프라이버시 언어로 책임과 통제 증거를 설명한다.
