## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **데이터 오염**: 학습 표본이나 라벨을 조작하여 모델의 전체 성능 또는 특정 조건의 판단 규칙을 바꾸는 공격이다.
- **AI(Artificial Intelligence)**: 학습된 모델로 인식•추론•생성 작업을 수행하는 기술이다.
- **학습 데이터**: 모델이 패턴을 학습하는 데 사용하는 입력 표본의 집합이다.
- **라벨**: 지도 학습에서 각 표본의 정답으로 지정한 값이다.

</details>

- 정의/개념: **AI**의 **학습 데이터** 표본이나 **라벨**을 조작해 판단 규칙을 바꾸는 **데이터 오염** 공격이다.
- 배경/필요성: 대규모 외부 데이터는 출처와 라벨을 전부 검증하기 어렵다.

#### 한줄 요약

- 학습 교재에 일부러 틀린 정답이나 특정 표식을 섞어 모델이 전체적으로 약해지거나 특정 상황에서만 오답을 내게 한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **표적 오염**: 특정 대상이나 입력에서만 모델이 오판하도록 학습 데이터를 조작하는 공격이다.
- **백도어 오염**: 비밀 트리거가 있을 때만 공격자가 정한 행동을 내도록 만드는 공격이다.
- **데이터 계보**: 표본의 출처•변경•버전과 영향 모델을 연결한 정보이다.
- **기준 평가**: 신뢰된 시험 자료로 정상 성능과 공격 행동을 비교하는 시험이다.

</details>

- **표적 오염**과 **백도어 오염**은 학습 전 주입되어 배포 뒤 잠복할 수 있다.
- 소량의 조작 표본으로 특정 대상이나 트리거 행동을 유도한다.
- **데이터 계보**와 **기준 평가**로 영향 범위를 추적하고 복구한다.

#### 한줄 요약

- 평균 정확도가 정상이어도 특정 사용자나 표식에서만 공격 행동이 나타날 수 있어 전체 지표만으로는 오염을 찾기 어렵다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **수집 격리소**: 검증되지 않은 외부•피드백 데이터를 승인된 정본과 분리하여 출처•품질•라벨을 검사하는 영역이다.
- **불변 학습 버전**: 검증을 통과한 표본만 반영하고 변경 이력을 고정하여 영향 모델과 원인 데이터를 재현할 수 있게 한 학습 세트이다.

</details>

```text
데이터 오염 방어 구조
├─ 수집 경계
│  ├─ 출처 등록부
│  └─ 수집 격리소
├─ 검증 경계
│  └─ 품질•라벨 검증
└─ 학습•평가 경계
   ├─ 버전 학습 세트
   └─ 계보•기준 평가
```

| 구성요소 | 책임 |
|:---|:---|
| 출처 등록부 | 제공자•경로•해시•책임 기록 |
| 수집 격리소 | **수집 격리소**에서 미검증 데이터•정본 분리 |
| 품질•라벨 검증 | 이상치•중복•분포•정답 점검 |
| 버전 학습 세트 | **불변 학습 버전**으로 승인 표본 관리 |
| 계보•기준 평가 | **데이터 계보**와 **기준 평가**로 데이터•모델 관계•공격 측정 |

#### 한줄 요약

- 새 데이터는 바로 학습에 넣지 않고 격리하여 출처•라벨•분포를 확인한 뒤 승인 버전만 후보 모델에 사용한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **정상 평가**: 신뢰된 시험 세트로 모델의 평균 업무 성능을 측정하는 시험이다.
- **표적 평가**: 특정 대상과 하위 집단에서 모델의 오판 여부를 측정하는 시험이다.
- **트리거 평가**: 변형된 트리거 입력의 공격 성공률을 측정하는 시험이다.
- **승격 게이트**: 출처•품질•공격 평가 기준을 통과한 데이터와 모델만 다음 학습 또는 배포 단계로 이동시키는 통제이다.
- **오염 표본•정상 데이터 혼합**: 조작된 표본이나 라벨이 정상 학습 세트에 숨는 단계이다.
- **조작 표본 반복 학습**: 오염된 표본의 패턴이 모델 매개변수에 누적되는 단계이다.
- **결정 경계•트리거 연관 변조**: 특정 입력이나 트리거에 대한 모델 판단 규칙이 바뀌는 단계이다.
- **정상 평균 성능으로 잠복**: 일반 시험에서는 평균 성능이 정상 범위로 나타나는 단계이다.
- **표적 오판•백도어 행동 실행**: 공격 조건에서 의도된 오판이나 숨은 행동이 출력되는 단계이다.

</details>

```text
조작 표본•라벨 주입
          |
          v
1. 오염 표본•정상 데이터 혼합
          |
          v
2. 조작 표본 반복 학습
          |
          v
3. 결정 경계•트리거 연관 변조
          |
          v
4. 정상 평균 성능으로 잠복
          |
     표적•트리거 입력
          |
          v
5. 표적 오판•백도어 행동 실행
          |
          v
     공격 목표 결과
```

### 동작 원리

1. **오염 표본•정상 데이터 혼합**: 조작 출처•라벨을 학습 세트에 은닉한다.
2. **조작 표본 반복 학습**: 공격 패턴을 모델 매개변수에 반영한다.
3. **결정 경계•트리거 연관 변조**: 표적 입력의 판단 규칙을 변경한다.
4. **정상 평균 성능으로 잠복**: 일반 시험에서는 정상 모델처럼 동작한다.
5. **표적 오판•백도어 행동 실행**: 공격 조건에서 의도한 결과를 출력한다.


#### 한줄 요약

- 후보 모델은 **정상 평가**•**표적 평가**•**트리거 평가**와 **승격 게이트**를 통과해야 배포하며, 실패하면 계보로 원인 표본을 찾아 재학습한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **가용성 오염**: 모델의 전체 성능과 서비스 품질을 낮추도록 데이터를 조작하는 공격이다.

</details>

| 데이터 오염 유형 | 가용성 오염 | 표적 오염 | 백도어 오염 |
|:---|:---|:---|:---|
| 적용 기준 | **가용성 오염** | **표적 오염** | **백도어 오염** |
| 핵심 특징 | 전체 성능 저하 | 특정 대상 오판 | 트리거 목표 행동 |
| 한계 | 서비스 품질 붕괴 | 평균 지표에 오류 은닉 | 정상 정확도로 탐지 회피 |

#### 한줄 요약

- 가용성형은 전반을 망치고 표적형은 특정 대상을 노리며 백도어형은 비밀 표식이 있을 때만 공격 행동을 켠다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **NIST(National Institute of Standards and Technology)**: 미국의 기술 표준과 지침을 개발하는 기관이다.
- **AI(Artificial Intelligence) 100-2e2025**: 오염 공격을 공격 목표와 역량별로 분류한 보고서이다.
- **RMF(Risk Management Framework)**: 위험을 식별•측정•대응•관리하는 구조화된 프레임워크이다.
- **AI RMF(Artificial Intelligence Risk Management Framework)**: AI 위험을 Govern•Map•Measure•Manage 기능으로 관리하는 프레임워크이다.
- **피드백 재학습**: 운영 중 수집한 사용자 반응과 입력을 다시 모델 학습에 사용하는 과정이다.
- **데이터 드리프트**: 운영 데이터의 분포가 학습 시점과 달라지는 정상적 또는 비정상적 변화이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 오염 공격 분류 누락 | **NIST** **AI 100-2e2025** 적용 | 목표•역량별 시험 체계화 |
| 외부•피드백 데이터 오염 | **피드백 재학습** 자료에 **수집 격리소**와 **승격 게이트** 적용 | 미검증 표본 학습 차단 |
| 잠복 표적 행동 | **기준 평가**와 트리거 변형 평가 | 평균 지표 밖 공격 탐지 |
| 데이터 드리프트•공격 혼동 | **RMF** 절차와 **AI RMF**로 **데이터 드리프트**의 원인•영향 측정 | 정상 변화의 오탐 방지 |

#### 한줄 요약

- 사용자 피드백을 재학습할 때 제공자와 변경 이력을 남기고 격리 검사를 통과한 표본만 승인 버전에 넣어야 한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **오염 복구 가능성**: 이상 발견 시 계보를 통해 원인 표본과 영향 모델을 찾아 격리하고 승인 버전으로 재학습•복원할 수 있는 능력이다.

</details>

- 계보 확인과 표적•트리거 평가를 통과한 모델만 승격하고 실패 시 원인 표본과 영향 모델을 격리하는 **오염 복구 가능성**을 확보한다.

#### 한줄 요약

- 데이터 오염 방어의 성패는 대량 데이터의 출처와 변경을 추적하고 특정 표적 행동까지 시험하며 영향 모델을 신속히 복구하는 데 달려 있다.
