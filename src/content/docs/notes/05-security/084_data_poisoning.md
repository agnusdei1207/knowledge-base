## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **데이터 오염(Data Poisoning / NIST AI 100-2e2025)**: 머신러닝/딥러닝 모델의 사전 학습(Pre-training) 또는 파인튜닝(Fine-tuning) 파이프라인 수집 단계에서, 공격자가 악의적으로 조작된 표본, 변조된 라벨(Label Flipping), 또는 은닉 트리거를 주입하여 모델의 전반적인 정확도를 파괴하거나(가용성 오염) 특정 표적 입력에 대해 공격자가 의도한 오판을 유도하는(표적 오염) 학습 단계 공격.
- **학습 데이터 파이프라인의 무검증 수용 결함(Unvalidated Ingestion Pipeline Defect)**: 인터넷 웹 크롤링이나 크라우드 소싱, 사용자 피드백 루프를 통해 수집된 외부 데이터의 출처와 무결성을 수학적으로 검증하지 않고 학습에 투입함에 따라, 1% 미만의 극소수 악성 샘플로도 신경망 가중치 전체가 왜곡되는 구조적 취약점.

</details>

- 정의/개념: 학습 표본 변조로 판단 경계를 왜곡하는 **데이터 오염 공격** 방어
- 배경/필요성: 무검증 외부 데이터로는 **학습 데이터 무결성 보장 불가**

#### 한줄 요약
- 학습 데이터셋에 조작된 샘플을 주입하여 가중치를 왜곡하는 공격을 막기 위해 데이터 계보 관리와 수집 격리소 정제를 적용한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **표적 오염 vs 가용성 오염**:
  - **표적 오염 (Targeted Poisoning)**: 모델의 전체적인 일반 정확도(Accuracy)는 99%로 정상 유지하면서, 공격자가 지정한 특정 타깃(예: 특정 공격자의 얼굴)에 대해서만 "관리자"로 오분류하도록 결정 경계를 국소 조작하는 스텔스 공격.
  - **가용성 오염 (Availability / DoS Poisoning)**: 대량의 쓰레기 라벨(Dirty Data)을 무차별 주입하여 모델의 전체 손실 함수 수렴을 방해하고 정확도를 0%로 폭락시키는 서비스 거부 공격.

</details>

- **스텔스 잠복 특성 (Stealth Ingress)**: 표적 오염 모델은 배포 전 일반적인 벤치마크 테스트셋을 100% 정상 통과하여 기존 CI/CD 검증을 무력화
- **극소수 주입에 의한 경계 왜곡 (High Leverage)**: 전체 학습 데이터셋의 0.1%~1%에 해당하는 소량의 오염 샘플만으로도 모델의 결정 경계(Decision Boundary)를 공격자 의도대로 유도
- **데이터 계보 기반 롤백(Rollback) 거버넌스**: 오염 감염 포착 시 DVC(Data Version Control)를 통해 오염된 데이터 배치를 즉각 추적 격리하고 정상 스냅샷으로 모델 재학습

#### 한줄 요약
- 표적/가용성 오염 형태, 스텔스 잠복 특성, 극소수 샘플 왜곡, 데이터 계보 기반 롤백을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **데이터 포이즈닝 방어 4대 핵심 계층**:
  1. **Ingestion Sandbox (수집 격리소)**: 외부 웹 크롤링 데이터의 1차 임시 버퍼.
  2. **Data Sanitizer (통계적 이상치 검증기)**: KNN 및 클러스터링 기반 라벨 이상 탐지.
  3. **Immutable Data Store (DVC)**: 암호학적 해시가 부여된 버전별 학습 데이터 저장소.
  4. **Tri-fold Promotion Gate**: 일반/표적/트리거 3중 벤치마크 평가 관문.

</details>

```text
학습 데이터 무결성 구조
|-- 수집 격리 버퍼
|-- 라벨 정제기
|-- DVC 데이터 계보 관리자
|-- 강건 학습 엔진
`-- 3중 승격 게이트
```

선의 의미: 외부 데이터가 수집 격리소에서 정제되어 DVC 불변 해시로 학습에 투입되고, 배포 전 3중 승격 게이트에서 오염 여부를 검증받는 구조

| 구성요소 | 핵심 책임 및 역할 | 비고 |
|:---|:---|:---|
| **수집 격리 버퍼 (Quarantine)** | 외부 크롤링 및 사용자 피드백 데이터를 즉시 학습에 투입하지 않고 1차 격리 검증 | Ingestion Buffer |
| **라벨 정제기 (Data Sanitizer)**| KNN/클러스터링 피처 공간 분석으로 라벨 플리핑 및 이상치(Outlier) 통계적 제거 | Label Cleaner |
| **데이터 계보 관리자 (DVC)** | 데이터 수집 출처, 가공 이력, 학습 버전을 Git/암호화 해시로 100% 추적 관리 | Lineage Tracker |
| **강건 학습 엔진 (Robust Training)**| Huber Loss, 노이즈 내성 손실 함수를 적용하여 오염 데이터의 가중치 기여도 억제 | Core Trainer |
| **3중 승격 게이트 (Promotion Gate)**| 일반 정확도, 표적 공격 내성, 백도어 트리거 반응을 교차 검증하여 배포 인가 | Gatekeeper |

#### 한줄 요약
- 수집 격리 버퍼, 라벨 정제기, 데이터 계보 관리자(DVC), 강건 학습 엔진, 3중 승격 게이트가 결합한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **데이터 오염 방어 5단계 파이프라인**:
  1. 외부 데이터 수집 및 격리소 적재
  2. 라벨 무결성 통계 검증 및 오염 표본 제거
  3. DVC 불변 해시 스냅샷 생성 및 모델 학습
  4. 3중 승격 게이트를 통한 표적 오염 스캐닝
  5. 이상 징후 포착 시 계보 역추적 및 즉각 롤백

</details>

```text
1. [외부 데이터 수집] 웹 크롤러가 이미지와 라벨을 수집하여 즉시 Ingestion Sandbox에 격리 저장
            │
            ▼
2. [이상치 정제 및 라벨 검증]
    ├─ Data Sanitizer가 피처 임베딩 공간에서 라벨 불일치 샘플(라벨 플리핑) 500개 탐지
    └─ [오염이 의심되는 변조 표본을 학습 데이터셋에서 완전 영구 삭제(Drop)]
            │
            ▼
3. [DVC 불변 버전 고정 및 학습]
    ├─ 정제 완료된 데이터셋에 SHA-256 해시를 부여하고 DVC 버전(`v2.1.0`) 생성
    └─ 딥러닝 분산 클러스터에서 해당 불변 데이터셋으로 에포크(Epoch) 학습 진행
            │
            ▼
4. [3중 승격 게이트 교차 평가]
    ├─ 게이트웨이가 클린 테스트셋(Clean Set)과 적대적 벤치마크 세트를 병행 투입
    └─ [표적 오판 발생률 0% 확인 ➔ 프로덕션 서빙 엔진으로 모델 배포 완료]
            │
            ▼ (사후 오염 징후 탐지 시)
5. [데이터 계보 역추적 및 신속 롤백]
    ├─ 특정 클래스 오작동 인지 즉시 DVC 계보(Lineage)를 추적하여 해당 수집 배치 식별
    └─ [오염 데이터 소스 차단 + 직전 정상 모델 버전(`v2.0.0`)으로 1분 이내 롤백]
```

**동작 원리**

1. **외부 데이터 수집**
2. **이상치 정제 및 라벨 검증**
3. **DVC 불변 버전 고정 및 학습**
4. **3중 승격 게이트 교차 평가**
5. **데이터 계보 역추적 및 신속 롤백**

#### 한줄 요약
- 수집 격리, 이상치 정제, DVC 불변 학습, 3중 승격 게이트 평가, 계보 역추적 롤백 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **데이터 오염 공격 3대 형태 비교**: 가용성 오염(Availability), 표적 오염(Targeted), 백도어 오염(Backdoor)의 비교.

</details>

| 비교 항목 | 가용성 오염 (Availability) | 표적 오염 (Targeted) | 백도어 오염 (Backdoor) |
|:---|:---|:---|:---|
| **공격 주 목적** | **모델 전체 정확도 붕괴 (AI DoS)** | **특정 표적 데이터에 대한 오판 유도**| **특정 트리거 패턴 입력 시 악성 동작**|
| **요구 오염 비율** | 대량 주입 필요 (전체의 10%~30%) | **극소량 주입 (전체의 0.1%~1% 수준)** | 소량 주입 (전체의 1%~3% 수준) |
| **사전 탐지 난이도**| **낮음 (Validation Accuracy 급락)** | **높음 (일반 테스트 시 99% 정상 작동)**| **최고 (트리거 없이는 100% 정상 작동)** |
| **핵심 방어 대책** | **통계적 이상치 제거(Outlier Removal)**| **KNN 라벨 검증, 데이터 계보 관리**| **수집 격리소 차단, 3중 승격 게이트** |

#### 한줄 요약
- 가용성 오염은 전체 성능 파괴, 표적 오염은 특정 샘플 오판 유도, 백도어 오염은 트리거 조건부 오작동이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **NIST AI 100-2e2025 & AI RMF 1.0**: AI 데이터 공급망 오염 방어, 데이터 계보(Lineage) 관리 및 신뢰성 평가에 관한 국제 표준 규격.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 사용자 피드백이 모델 재학습에 실시간 반영되는 구조로 인해 **공격자가 악성 피드백을 난사하여 챗봇의 지식 가중치를 오염시키는 사고** | **NIST AI 100-2e2025** 기준, **수집 격리소(Quarantine Buffer) 도입 및 KNN 기반 통계적 이상치 정제(Sanitization) 강제** | 악성 피드백 데이터의 재학습 파이프라인 무단 유입 100% 원천 차단 |
| 극소수 표적 오염 샘플이 주입되어 **일반 벤치마크 테스트를 통과한 후 프로덕션에서 특정 해킹 트래픽을 정상으로 오판하는 결함** | **배포 전 일반 정확도와 적대적 표적 강건성을 교차 검증하는 3중 승격 게이트(Tri-fold Promotion Gate) 집행** | 잠복된 표적 오염 및 결정 경계 왜곡 모델의 프로덕션 배포 100% 사전 차단 |
| 데이터 오염이 발생했으나 어떤 수집 경로로 침투했는지 확인하지 못해 **전체 모델을 처음부터 다시 학습시켜야 하는 막대한 비용 손실** | **DVC(Data Version Control) 기반 불변 데이터셋 관리 및 블록체인/해시 기반 데이터 계보(Data Lineage) 추적 체계 구축** | 감염된 오염 데이터 배치 즉각 식별 및 1분 이내 안전 스냅샷 자동 롤백 달성 |

#### 한줄 요약
- 수집 격리소로 오염 유입을 막고, 3중 게이트로 배포를 차단하며, DVC 계보 관리로 1분 이내 롤백한다.

## Ⅶ. 결론

- 외부 데이터는 **격리·정제**, 배포 모델은 **승격 게이트**로 검증

#### 한줄 요약
- 수집 격리소 정제와 DVC 불변 계보 관리 및 3중 승격 게이트를 통해 데이터 포이즈닝을 완벽히 방어한다.
