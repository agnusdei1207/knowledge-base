## 미리 알고가기

- **인공지능 (Artificial Intelligence, AI)**: 학습 기반 판단·생성 시스템
- **AI 레드팀 (AI Red Teaming)**: 공격자 관점에서 AI 위험과 피해를 재현
- **응용 프로그래밍 인터페이스 (Application Programming Interface, API)**: 모델·도구 호출 경계 제공
- **검색 증강 생성 (Retrieval-Augmented Generation, RAG)**: 생성 문맥에 검색 결합
- **벤치마크 평가 (Benchmark Evaluation)**: 고정 문제로 성능·안전 비교
- **검증 하네스**: 공격 입력·모델 응답·도구 결과를 반복 실행·기록하는 시험 장치
- **샌드박스**: 공격 검증이 실제 데이터·시스템에 영향을 주지 않도록 격리한 실행 환경
- **회귀 검증**: 수정 뒤 같은 공격과 변형 공격이 다시 성공하지 않는지 반복 확인하는 시험
- **레드팀 명칭의 뜻**: 군사 모의훈련의 공격 역할을 맡은 팀에서 유래해 방어를 공격자 관점으로 시험하는 역할을 뜻함

## Ⅰ. 개요

- 정의/개념: 공격자 관점에서 **AI 악용 경로·실제 피해를 재현·평가**
- **배경/필요성**: 고정 성능 평가는 **적응형 우회·연쇄 피해·운영 문맥 누락**

### 쉽게 이해하기 (학습용)

- 모의고사 점수가 좋아도 악성 문서와 도구 결합 시 사고 위험이 있어, 전체 흐름을 따라 검증 필요

## Ⅱ. 특징

- **위협 모델 기반 탐색**으로 데이터·RAG·도구·사람의 연쇄 피해를 찾는다.
- **샌드박스·중단 조건**으로 실제 데이터·시스템 피해를 제한한다.
- **재현 증거·자동 회귀**로 완화 후 동일·변형 공격을 재검증한다.

### 쉽게 이해하기 (학습용)

- 창의적 탐색과 자동 도구 반복으로 새로운 공격과 재발 확인

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 범위·위협 모델 | **자산·공격자·금지 행동·성공 조건** |
| 시나리오 저장소 | **공격·변형 시나리오 재현 관리** |
| 검증 하네스·샌드박스 | **격리 실행·결과 수집** |
| 증거·분류 체계 | **입력·응답·도구·피해 기록** |
| 완화·회귀 체계 | **근본 수정·동일·변형 재검증** |

```text
[레드팀 자산] : 범위·위협 모델·시나리오
[격리 검증 환경] : 하네스·샌드박스·재현 증거
[개선 자산] : 분류 체계·완화·회귀 검증
```

> 요약: 시나리오·증거·회귀로 공격 경로 차단을 확인한다

### 쉽게 이해하기 (학습용)

- 계정·문서·도구와 피해 증거를 묶어 수정 뒤 재검증함

## Ⅳ. 원리 및 절차 흐름도

```text
범위확정
↓
공격설계
↓
안전실행
↓
위험평가
↓
완화검증
```

| 절차 | 설명 |
|:---|:---|
| 범위확정 | 자산·권한·중단 조건 합의 |
| 공격설계 | 위협 경로와 성공·피해 기준 작성 |
| 안전실행 | 격리 환경·계정·비용으로 공격 재현 |
| 위험평가 | 재현성·피해·난이도·원인 기록 |
| 완화검증 | 변형 시나리오로 회귀 확인 |

> 요약: 공격 피해를 완화한 뒤 변형 시나리오로 재검증한다

### 쉽게 이해하기 (학습용)

- 범위와 중단 조건을 정하고 완화 뒤 변형 공격까지 재검증함

## Ⅴ. 종류 및 비교

| AI 안전성 평가 | AI 레드팀 | 벤치마크 평가 | 자동 적대 평가 |
|:---|:---|:---|:---|
| 적용 기준 | 실제 피해·완화 효과 검증 | 점수·통과율 비교 | 성공률·회귀 측정 |
| 핵심 특징 | 새 공격 경로·피해 탐색 | 고정 데이터 성능·안전 비교 | 알려진 공격 대량 반복 |
| 한계 | 범위·중단 조건 미흡 시 피해 | 새 우회·운영 문맥 누락 | 시나리오 밖 공격 누락 |

> 요약: 레드팀은 탐색, 벤치마크는 비교, 자동 평가는 반복한다

### 쉽게 이해하기 (학습용)

- 벤치마크는 비교, 자동 평가는 반복, 레드팀은 새 경로를 탐색

## Ⅵ. 실무 사례

1. 배포 전 **문서 인젝션에서 도구 오용까지 공격 경로 재현**

### 쉽게 이해하기 (학습용)

- 격리 계정과 샌드박스에서 악성 RAG 문서가 내부정보 유출과 외부 도구 실행으로 이어지는 경로를 재현하고 수정 후 같은 공격으로 재검증한다.

## Ⅶ. 결론

- AI의 복합 공격 경로를 배포 전에 발견하기 위해 자산·공격자 능력·실제 피해·시험 안전·재현성을 검토하여, AI 레드팀으로 탐색하고 수정 후 회귀 검증해야 한다.

### 쉽게 이해하기 (학습용)

- 가장 위험한 공격 경로를 증거로 설명하고 수정 뒤 재현되지 않는 상태
