## 미리 알고가기

- **디지털 권리관리(Digital Rights Management, DRM)**: 암호화·라이선스로 파일의 열람·편집·출력·기간을 배포 후에도 통제하는 기술이다.
- **정보 권리관리(Information Rights Management, IRM)**: 기업 정보에 사용자·기기·행위·기간별 권한을 적용하는 체계이다.
- **데이터 유출방지(Data Loss Prevention, DLP)**: 민감정보를 식별해 저장·사용·전송 경로의 비인가 이동을 탐지·차단하는 통제이다.
- **데이터 분류(Data Classification)**: 업무 가치·민감도·법적 요구에 따라 보호 등급과 취급 규칙을 정하는 활동이다.
- **콘텐츠 검사(Content Inspection)**: 패턴·지문·등급·맥락을 분석해 데이터 민감 여부를 판정하는 기능이다.
- **라이선스 서버(License Server)**: DRM 문서의 주체·기기·행위·기간별 권한과 키 사용을 결정하는 서버이다.
- **엔드포인트 DLP(Endpoint DLP)**: USB·인쇄·클립보드·업로드 등 단말의 민감정보 이동을 통제하는 기능이다.
- **데이터 지문(Data Fingerprinting)**: 내용 특징값을 대조해 같거나 유사한 민감정보를 찾는 기술이다.
- **W3C ODRL Information Model 2.2**: 디지털 자산의 허용·금지·의무·제약을 표현하는 권리 정책 정보 모델이다.
- **ISO/IEC 27002:2022 통제 5.12**: 정보 분류 기준과 분류 절차에 관한 통제이다.
- **ISO/IEC 27002:2022 통제 8.12**: 데이터 유출 방지 조치에 관한 통제이다.

## Ⅰ. 개요

- 정의/개념: DRM은 **사용 권한**, DLP는 **이동 경로** 통제
- 배경/필요성: 승인 후 오용과 **비인가 반출의 동시 방지**

### 쉽게 이해하기 (학습용)

- DRM은 받은 문서의 사용법을 정하고 DLP는 문서가 이동하는 길을 검사함

## Ⅱ. 특징

- DRM의 배포 후 **파일별 지속 사용 통제**
- DLP의 저장·사용·전송 **콘텐츠 기반 검사**
- 공통 분류·신원의 **권리·반출 정책 연계**

### 쉽게 이해하기 (학습용)

- 먼저 민감 데이터를 알아야 같은 등급과 업무 기준으로 사용·이동 정책을 적용할 수 있음

## Ⅲ. 구조 및 구성요소

```mermaid
block-beta
  columns 1
  C["데이터 발견·분류·표시"]
  P["신원·정책·예외 관리"]
  R["DRM 암호화·권리 집행"]
  D["DLP 이동 경로 집행"]
  A["감사·사고·정책 환류"]
  C --- P --- R
  R --- D --- A
```

| 구성요소 | 책임 |
|:---|:---|
| 데이터 발견·분류·표시 | 내용·소유자·등급 식별 |
| 신원·정책·예외 관리 | 주체·행위·기간·업무 판정 |
| DRM 암호화·권리 집행 | 열람·편집·출력·만료 제한 |
| DLP 이동 경로 집행 | USB·메일·웹·API 검사 |
| 감사·사고·정책 환류 | 위반·예외·오탐 개선 |

### 쉽게 이해하기 (학습용)

- 공통 분류·신원 정책에서 DRM 사용 권한과 DLP 반출 조건을 함께 도출함

## Ⅳ. 흐름도

```mermaid
sequenceDiagram
  participant U as 사용자
  participant C as 분류 엔진
  participant P as 정책 엔진
  participant R as DRM 집행
  participant D as DLP 집행
  U->>C: 1. 데이터 내용·소유자 식별
  C->>P: 2. 등급·신원·업무 정책 조회
  P->>R: 3. 열람·편집·출력 권한 집행
  R->>D: 4. 복사·전송 경로 검사
  D->>P: 5. 허용·차단·예외 결과 환류
```

**동작 원리**

- **1. 데이터 내용·소유자 식별**: 패턴·지문·메타정보 분석
- **2. 등급·신원·업무 정책 조회**: 주체·목적·기간·예외 판정
- **3. 열람·편집·출력 권한 집행**: 암호화·라이선스 적용
- **4. 복사·전송 경로 검사**: USB·메일·웹·API 통제
- **5. 허용·차단·예외 결과 환류**: 위반·오탐·정책 개선

### 쉽게 이해하기 (학습용)

- 차단 건수보다 중요한 데이터가 어디서 어떤 업무로 이동했고 예외가 적절했는지 확인함

## Ⅴ. 종류 및 비교

| 데이터 보호 방식 | DRM·IRM | DLP | 저장·전송 암호화 |
|:---|:---|:---|:---|
| 적용 기준 | 배포 후 사용 제한 | USB·메일·웹 반출 | 저장소 탈취·도청 대응 |
| 핵심 특징 | 파일 사용 권한 지속 | 민감정보 이동 검사 | 평문 노출 방지 |
| 한계 | 촬영·라이선스 장애 | 암호화 우회·오탐 | 승인 사용자 유출 |

> 요약: 사용·이동·보관 구간의 역할이 서로 다름

### 쉽게 이해하기 (학습용)

- 암호화는 운반 상자, DRM은 사용법, DLP는 이동 경로를 보호함

## Ⅵ. 실무 고려사항 및 대책

| 고려사항 | 대책 | 효과 |
|:---|:---|:---|
| 권리 정책 상호운용 | **W3C ODRL 2.2 적용** | 허용·금지·의무 표현 |
| 정보 등급 기준 | **ISO/IEC 27002 통제 5.12 적용** | DRM·DLP 공통 분류 |
| 데이터 유출 방지 | **ISO/IEC 27002 통제 8.12 적용** | 저장·사용·전송 통제 |

### 쉽게 이해하기 (학습용)

- 기밀 문서는 DRM으로 사용을 제한하고 DLP가 메일·웹·API의 비인가 반출을 차단하되 업무 예외를 추적한다.

## Ⅶ. 결론

- **등급·사용 권한·이동 경로·복구성**으로 통제를 조합한다.

### 쉽게 이해하기 (학습용)

- 문서를 받은 뒤의 사용법과 조직 밖으로 나가는 경로를 함께 통제해야 함
