## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **개방형 웹 애플리케이션 보안 프로젝트(Open Worldwide Application Security Project, OWASP)**: 전 세계 전문가들이 애플리케이션 보안 연구 및 공개 도구를 개발 배포하는 국제 비영리 단체.
- **OWASP Top 10**: 웹 애플리케이션 분야에서 발생하는 가장 파급력이 높은 상위 10가지 보안 위험 범주 및 통제 우선순위 지침.

</details>

- 정의/개념: 웹의 10대 위험 범주를 제시하는 **OWASP Top 10**
- 배경/필요성: 개별 취약점 대응만으로는 **공통 위험•우선순위** 정렬 불가

#### 한줄 요약

- 주요 웹 보안 위험을 표준 10대 범주로 체계화하여 개발 및 점검 우선순위를 제시함.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **위험 인식 자료(Risk Awareness Document)**: 정량적 통계 및 CTI를 기반으로 개발자와 보안팀의 공통 위협 인식을 제고하는 프레임워크.
- **주기적 갱신(Periodic Update)**: 실제 침해사고 데이터와 보안 연구자 입증 결과를 종합하여 3~4년 주기로 상위 10대 위협 목록을 재정렬하는 활동.
- **애플리케이션 보안 검증 표준(Application Security Verification Standard, ASVS)**: 애플리케이션 보안 요구사항과 검증 기준 레벨(Level 1~3)을 정의하는 명세.
- **웹 보안 시험 지침(Web Security Testing Guide, WSTG)**: 웹 보안 취약점 점검 및 모의 침투를 위한 세부 시험 시나리오 매뉴얼.

</details>

- **위험 인식 자료** 기반의 원인, 빈도, 기술적 파급도 통합 분류.
- 데이터 드리븐 및 통계 분석 반영으로 공격 기법 변화에 대응하는 **주기적 갱신**.
- **ASVS**의 명세 및 **WSTG**의 점검 항목과 상호 연계되어 실무 검증 절차 구체화.

#### 한줄 요약

- 위험 인식 목록을 ASVS 요구사항과 WSTG 시험 절차로 상호 매핑하여 보안 실효성을 확보함.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **소프트웨어 개발 생명주기(Software Development Life Cycle, SDLC)**: 소프트웨어 요구사항 수립부터 설계, 구현, 테스트, 배포, 유지보수까지의 전 과정.

</details>

```text
OWASP 활용 구조
├─ Top 10 위험 범주: 주요 웹 위험 분류
├─ ASVS 보안 요구: 검증 요구•수준 정의
├─ WSTG 시험 절차: 웹 보안 시험 제공
├─ SDLC 통제: 개발 전 과정에 통제 반영
└─ 운영 근거: 사고•변경 결과로 판단 보완
```

| 구성요소 | 책임 |
|:---|:---|
| Top 10 위험 범주 | 10대 핵심 웹 애플리케이션 보안 위험 공통 분류 |
| ASVS 보안 요구 | 레벨별(Level 1~3) 구체적 보안 요구사항 및 검증 기준 정의 |
| WSTG 시험 절차 | 보안 요구사항 충족 검증을 위한 실제 시험 항목 및 절차 제공 |
| SDLC 통제 | 안전한 **SDLC** 방법론 상에 보안 통제 구현 적용 |
| 운영 근거 | 관제 이력 및 실제 미탐/침해 피드백 기반 통제 보완 |

#### 한줄 요약

- Top 10 위험을 ASVS 설계 요구 및 WSTG 시험 검증으로 연계하여 SDLC 전 과정에 반영함.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **검증 증거(Verification Evidence)**: 보안 지침 이행 여부를 입증하는 정적 분석, 동적 스캔 및 점검 보고서 기록.
- **Top 10 위험 범주 매핑(Risk Mapping)**: 개발 대상 서비스에 해당 OWASP Top 10 위협 항목을 대조 매핑하는 단계.
- **ASVS 보안 요구 선정(Requirement Selection)**: 데이터 중요도에 따라 ASVS 검증 레벨을 확정하는 단계.
- **보안 통제 구현(Secure Implementation)**: 시큐어 코딩 및 파라미터화 쿼리, 입력 검증 등을 구현하는 단계.
- **WSTG 보안 시험(Testing & Audit)**: WSTG 가이드라인에 의거하여 취약점 검증을 집행하는 단계.
- **사고•변경 근거 환류(Feedback & Improvement)**: 운영 중 수집된 피드백을 통제 기준에 재반영하는 단계.

</details>

```text
서비스 경계•중요도
        │
        ▼
1. Top 10 위험 범주 매핑
        │
        ▼
2. ASVS 보안 요구 선정
        │
        ▼
3. 보안 통제 구현
        │
        ▼
4. WSTG 보안 시험
        │
        ├─ 미충족 ── 통제•요구 보완
        │
        └─ 충족 ── 운영 근거 수집
                           │
                           ▼
                 5. 사고•변경 근거 환류
```

### 동작 원리

1. **Top 10 위험 범주 매핑**: 애플리케이션 구조 기반 OWASP Top 10 위협 위험 식별.
2. **ASVS 보안 요구 선정**: 비즈니스 파급도에 맞춘 ASVS 레벨 세부 통제 항목 확정.
3. **보안 통제 구현**: 소스 코드 및 아키텍처 상에 방어 통제 구현.
4. **WSTG 보안 시험**: WSTG 절차에 입각한 취약점 스캔 및 **검증 증거** 취득.
5. **사고•변경 근거 환류**: 침해사고 및 변경 관제 결과를 차기 개발 정책에 환류.

#### 한줄 요약

- 위험 매핑부터 ASVS 요구 선정, 시큐어 코딩 구현, WSTG 보안 시험 및 환류를 구동함.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **위험•요구•시험 역할 분리(Separation of Roles)**: Top 10은 위협 인식, ASVS는 구현 요구, WSTG는 검증 기법으로 구별하여 중복 없이 상호 보완 적용하는 원칙.

</details>

| OWASP 자료 | 담당 역할 | 활용 산출물 |
|:---|:---|:---|
| OWASP Top 10 | 주요 웹 위험 인식 | 교육•위험 논의의 공통 범주 |
| ASVS | 보안 요구사항•검증 수준 정의 | 설계•개발•검수 요구 기준 |
| WSTG | 웹 보안 시험 절차 제공 | 시험 시나리오•점검 절차 |

#### 한줄 요약

- OWASP 프레임워크의 역할 분담에 따라 Top 10은 위험 식별, ASVS는 보안 요구, WSTG는 시험 검증에 적용함.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **OWASP Top 10:2025**: 최신 위협 동향을 반영하여 정제된 최신 OWASP Top 10 스펙.
- **OWASP ASVS 5.0.0**: 클라우드, API 보안 요구가 대폭 보강된 최신 ASVS 명세서.
- **OWASP WSTG**: 최신 공격 기법 점검 시나리오가 업데이트된 웹 보안 시험 가이드.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 구버전 위험 분류 적용 | **OWASP Top 10:2025** 적용 | 최신 공격 위험 및 우선순위 반영 |
| 단순 Top 10 체크리스트 의존 | **OWASP ASVS 5.0.0**으로 구체화 | 정형화된 레벨별 상세 보안 요구 확보 |
| 시험 절차의 파편화 | **OWASP WSTG** 절차 연계 | 재현 가능하고 통일된 보안 시험 집행 |

#### 한줄 요약

- 취약한 직접 객체 참조(IDOR) 방지를 위해 서버 측에서 세션 계정 권한 검증 및 파라미터화 쿼리를 적용함.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **OWASP 자료 선택 기준(OWASP Selection Criteria)**: 단순 위험 대조용 Top 10, 개발 요구 명세용 ASVS, 모의 침투/검수용 WSTG를 용도에 맞추어 맞춤 적용하는 지침.

</details>

- **OWASP 자료 선택 기준**에 따라 위험 인식은 **OWASP Top 10**, 요구 정의는 **ASVS**, 시험 절차는 **WSTG**를 선택 연계.

#### 한줄 요약

- 위험은 **Top 10**, 요구는 **ASVS**, 시험은 WSTG 적용
