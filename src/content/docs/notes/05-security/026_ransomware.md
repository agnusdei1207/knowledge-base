## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **랜섬웨어(Ransomware)**: 시스템 내부로 침투하여 핵심 파일, 데이터베이스, 스토리지 볼륨을 비대칭/대칭 복합 암호화 알고리즘으로 잠그거나 사전에 외부로 탈취(Exfiltration)한 후, 데이터 복호화 키 제공 및 유출 방지를 대가로 금전(가상자산)을 요구하는 악성 소프트웨어 공격.
- **다중 갈취(Multi-Extortion)**: 단순 파일 암호화(1세대)를 넘어, 2단계 데이터 유출 협박(Double Extortion), 3단계 서비스 마비 DDoS(Triple Extortion), 4단계 고객/파트너사 직접 협박(Quadruple Extortion)으로 진화한 복합 압박 전술.

</details>

- 정의/개념: 초기 침투(스피어피싱/RDP) $\rightarrow$ 권한 상승 및 AD 장악 $\rightarrow$ 횡적 이동(Lateral Movement) $\rightarrow$ **백업 및 섀도 복사본(VSS) 파괴** $\rightarrow$ **데이터 사전 유출 및 전사 암호화** 로 이어지는 **APT 결합형 지능형 사이버 인질 공격 및 복구 프레임워크**
- 배경/필요성: 공격자가 기업의 백업 인프라를 우선 식별하여 선제 파괴하고, 백업 복구 성공 시에도 다크웹 기밀 공개로 협박함에 따라, 단순 백업을 넘어선 **물리적 에어갭(Air-Gap) 및 불변 스토리지(WORM)** 기반 복구 거버넌스 요구

#### 한줄 요약
- 권한 상승 및 백업 선제 파괴 후 데이터 유출과 암호화를 병행하는 다중 갈취를 불변 백업으로 무력화한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **복구 무력화 전술(Inhibition of System Recovery / MITRE T1490)**: 공격자가 암호화를 시작하기 직전, `vssadmin delete shadows` 명령어로 윈도우 볼륨 섀도 복사본(VSS)을 삭제하고 로컬 백업 에이전트와 EDR 서비스를 강제 종료하여 자체 복구를 차단하는 행위.
- **불변 백업(Immutable Backup / WORM: Write Once Read Many)**: 스토리지 하드웨어/오브젝트 락(S3 Object Lock)을 통해, 최고 관리자(Root) 권한으로도 지정된 보존 기간(Retention Period) 동안 백업본의 수정 및 삭제가 원천 불가능하도록 고정하는 백업 기술.

</details>

- **복구 방해 선행 (Inhibition of Recovery)**: EDR 보안 에이전트 무력화 및 볼륨 복원 지점(VSS), 온라인 백업 스토리지 선제 파괴
- **데이터 유출 선행 (Exfiltration Before Encryption)**: 암호화 이전에 기가바이트 단위의 핵심 기밀 데이터를 C2/클라우드 드롭박스로 사전 은닉 유출
- **3-2-1-1-0 백업 전략 필수성**: 3개 사본, 2개 매체, 1개 오프사이트, 1개 불변(Immutable/Air-Gapped), 0개 복구 오류 검증

#### 한줄 요약
- VSS/백업 선제 파괴, 사전 데이터 은닉 유출, 3-2-1 불변 백업 기반 신뢰 복구를 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **복구 신뢰 경계(Recovery Trust Boundary)**: 사내 Active Directory 및 프로덕션 운영망이 완전히 장악되더라도, 백업 제어 서버와 스토리지 관리망은 별도의 격리된 IAM 계정 체계와 물리적 폐쇄망으로 분리되어 침해 확산이 불가능한 보안 경계.

</details>

```text
[ 프로덕션 엔터프라이즈 운영망 (Infected Production Zone) ]
 ├─ 초기 침투 (스피어피싱, 취약한 VPN/RDP 포트)
 ├─ 권한 상승 (Mimikatz 자격증명 탈취 ➔ Domain Admin 획득)
 ├─ 내부 확산 (PsExec, WMI, SMB 기반 횡적 이동)
 └─ 파괴 실행: [ VSS 삭제 (`vssadmin`) + 데이터 외부 탈취 + 로컬 볼륨 암호화 ]
                                     │
                     ┌───────────────┴───────────────┐
                     │ (침해 확산 차단: 엄격한 방화벽 / 물리적 단절)
                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 격리된 복구 신뢰 영역 (Isolated Recovery Zone / Air-Gapped) ]          │
│  ├─ 1. 전용 독립 IAM 인증 체계 (프로덕션 AD와 100% 분리)               │
│  ├─ 2. 불변 백업 스토리지 (WORM / S3 Object Lock Compliance Mode)      │
│  └─ 3. 오프라인 에어갭 스토리지 (물리적 테이프 백업 / 네트워크 단절)    │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │ (침해 지표 IOC 소거 후 신뢰 복구)
                                     ▼
                      [ 클린 샌드박스 환경 내 신뢰 복원 (Trusted Recovery) ]
```

선의 의미: 프로덕션 운영망이 랜섬웨어에 의해 장악되더라도, 독립 IAM 및 물리/논리적 단절선으로 보호되는 불변 백업 영역을 통해 무결한 신뢰 복구를 완수하는 구조

| 구성요소 | 핵심 책임 및 역할 | 비고 |
|:---|:---|:---|
| **초기 침투 및 C2 차단** | 이메일 격리(RBI), 다중인증(MFA), 취약점 패치로 내부 진입 경로 봉쇄 | Ingress Defense |
| **마이크로 세그멘테이션** | 엔드포인트 간 통신(East-West)을 격리하여 관리자 계정 탈취 시에도 횡적 확산 방지 | Zero Trust |
| **EDR 템퍼 프로텍션** | 공격자가 백신이나 EDR 에이전트 프로세스를 강제 종료하지 못하도록 드라이버 레벨 보호 | Anti-Tamper |
| **불변 스토리지 (WORM)**| 악의적 삭제/암호화 API 호출 시에도 백업 이미지의 불변성(Immutability) 강제 유지 | Storage Lock |
| **오프라인 에어갭 백업**| 물리적으로 전원과 네트워크가 차단된 테이프/콜드 스토리지에 최후 백업본 보존 | Air-Gap |

#### 한줄 요약
- 인그레스 차단, 마이크로 세그멘테이션, EDR 템퍼 보호, 불변 WORM 스토리지, 오프라인 에어갭이 결합한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **신뢰 복구(Trusted Recovery)**: 랜섬웨어 침해 사고 후 기존 시스템을 그대로 복원하지 않고, 백도어와 C2 연결이 잔존하지 않도록 베어메탈 포맷 및 OS 재설치를 완료한 검증된 클린 환경에 불변 백업본을 복원하는 표준 복구 절차.

</details>

```text
1. [사고 인지] EDR이 다량의 파일 확장자 변조, 랜섬노트 생성, VSS 섀도 복사본 삭제 행위 실시간 감지
            │
            ▼
2. [긴급 격리] 감염 단말의 네트워크 링크 즉각 차단(NIC 비활성화) 및 전사 도메인 관리자(AD) 계정 잠금
            │
            ▼
3. [포렌식 및 IOC 식별] C2 IP 주소, 침투 악성코드 해시, 침해된 인증서 등 침해 지표(IOC) 추출 및 방화벽 차단
            │
            ▼
4. [신뢰 환경 구성] 침해된 서버를 클린 베어메탈로 초기화(포맷)하고 OS 및 최신 패치 클린 설치
            │
            ▼
5. [불변 백업 복원] 오프라인/WORM 스토리지에서 무결성이 검증된 백업 이미지를 클린 인프라에 복원
```

**동작 원리**

1. **행위 기반 조기 탐지**: 비정상적인 초당 파일 쓰기 I/O 및 엔트로피 급증 감지
2. **네트워크 격리 집행**: EDR 호스트 격리 기능을 가동하여 동일 서브넷으로의 측면 확산 차단
3. **영향도 포렌식**: 유출된 기밀 데이터 범위와 악성 프로세스의 레지스트리 영속성(Persistence) 분석
4. **인프라 정화 재구축**: 잠재적 백도어 잔존 가능성을 배제하기 위해 골든 이미지 기반 재설치
5. **무결성 데이터 인입**: 사후 변조가 불가능한 WORM 백업 볼륨으로부터 신뢰 데이터 복구

#### 한줄 요약
- EDR 조기 탐지, 네트워크 링크 긴급 격리, IOC 포렌식, 클린 인프라 재구축, 불변 백업 복원 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **랜섬웨어 3세대 발전 비교**: 단순 파일 암호화(1세대), 데이터 유출 결합(2세대 이중 갈취), DDoS 및 고객 압박 결합(3세대 다중 갈취)의 비교.

</details>

| 비교 항목 | 1세대 단순 암호화 (Single Extortion) | 2세대 이중 갈취 (Double Extortion) | 3세대 다중 갈취 (Multi-Extortion) |
|:---|:---|:---|:---|
| **핵심 갈취 수단** | **파일 및 디스크 비대칭 암호화** | **데이터 암호화 + 사전 기밀 데이터 유출**| **암호화 + 유출 + DDoS 공격 + 고객 직접 압박** |
| **공격자 압박 전술** | 복호화 키 미제공 협박 | **다크웹 데이터 유출 사이트(DLS) 공개** | **규제 기관 고발 위협, 경영진/고객 협박** |
| **기존 백업의 유효성**| **유효 (백업 복원 시 공격 100% 무력화)** | **부분 유효 (복구는 가능하나 유출 피해 발생)**| **한계 (기술적 복원 외 법무/PR 대응 수반)**|
| **핵심 방어 대책** | **불변 백업 (WORM) 및 오프라인 에어갭** | **저장 데이터 암호화(At-Rest), DLP, EDR** | **종합 침해사고대응(IR), BCP, 법률/공시 체계** |

#### 한줄 요약
- 1세대는 파일 암호화 중심, 2세대는 다크웹 기밀 유출 결합, 3세대는 DDoS 및 고객 압박을 결합한 다중 갈취이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **NIST IR 8374 (랜섬웨어 위험 관리 가이드라인)**: 엔터프라이즈 환경에서 랜섬웨어 침해를 예방(Prevent), 대응(Respond), 복구(Recover)하기 위해 자산 식별, 접근 통제, 불변 백업 아키텍처 구성을 정의한 미국 연방 표준 지침.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 도메인 관리자 계정 탈취로 인해 **온라인 백업 스토리지와 스냅샷이 동시 암호화/삭제되는 참사** | **스토리지 관리망 분리 및 보존 기간 내 삭제 불능인 불변 백업(WORM/Air-Gap)** 강제 | 백업 데이터의 임의 삭제/암호화 100% 차단 및 랜섬웨어 공격 시 무조건적 복구력 보장 |
| 침해 사고 발생 시 침투 경로 미파악 및 지연된 대응으로 인한 **사내 전 서브넷 악성코드 확산** | **NIST SP 800-61 기반 사고대응(IR) 자동화 및 EDR 기반 호스트 네트워크 원격 격리** | 침해 확산 골든타임(10분 이내) 확보 및 횡적 이동(Lateral Movement) 조기 차단 |
| 시스템 복구에는 성공했으나 사전에 탈취된 핵심 고객정보 유출로 인한 **법적 제재 및 과징금 리스크** | **데이터베이스 컬럼 단위 사전 암호화(AES-256) 및 72시간 내 법정 침해사고 신고 준수** | 유출된 데이터의 평문 노출 방지 및 GDPR/개인정보보호법 컴플라이언스 준수 |

#### 한줄 요약
- 불변 백업으로 복구력을 보장하고, EDR 원격 격리로 확산을 막으며, 데이터 사전 암호화로 유출 피해를 방어한다.

## Ⅶ. 결론

- 엔터프라이즈의 연속성을 파괴하는 복합 위협인 **랜섬웨어 대응 아키텍처**는 단순한 백신 차단을 넘어 인프라 격리와 복구 신뢰성을 아우르는 종합 생존 전략이며, 실무 구현 시 **NIST IR 8374 프레임워크 준수**, **3-2-1 불변 백업(WORM/Air-Gap) 인프라 구축**, **EDR 기반 측면 이동 차단 및 신뢰 복구(Trusted Recovery) 체계**를 통합 가동하여 공격자의 다중 갈취를 완벽히 무력화하는 복원력(Cyber Resilience)을 완성

#### 한줄 요약
- 불변 백업(WORM/Air-Gap)과 EDR 조기 격리 및 신뢰 복구 절차를 결합하여 랜섬웨어 다중 갈취를 무력화한다.
