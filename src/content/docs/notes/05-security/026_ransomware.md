## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **Ransomware (랜섬웨어)**: 데이터와 시스템을 암호화하거나 유출한 후 복구 및 비공개를 대가로 금전을 요구하는 악성 소프트웨어.
- **Multi-Extortion (다중 갈취)**: 단순 암호화를 넘어 데이터 유출 협박, DDoS 공격, 고객 직접 압박을 결합한 복합 갈취 전술.

</details>

- 정의/개념: 데이터를 암호화·유출해 금전을 요구하는 **다중 갈취 공격**
- 배경/필요성: 온라인 백업은 관리자 탈취 시 **동시 삭제 방지 불가**

#### 한줄 요약
- 다중 갈취 공격을 무력화하기 위해 EDR 조기 탐지와 3-2-1 불변 백업(WORM/Air-Gap)을 구축한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **VSS Purge (섀도 복사본 삭제)**: 랜섬웨어가 감염 즉시 `vssadmin delete shadows` 명령을 실행하여 로컬 자동 복구 지점을 파괴하는 전형적 행위.
- **WORM (Write Once, Read Many)**: 스토리지에 한 번 기록된 백업 데이터를 관리자 권한으로도 지정 기간 동안 수정/삭제할 수 없도록 잠그는 기술.

</details>

- **복구 무력화**: VSS와 **온라인 백업 우선 파괴**
- **다중 갈취**: 암호화·유출·DDoS·**고객 압박** 결합
- **3-2-1 불변 백업**: **WORM·Air-Gap**으로 복구력 확보

#### 한줄 요약
- 복구 지점 파괴 무력화 시도, 다중 갈취 전술, 3-2-1 WORM 불변 백업 복원력을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **Air-Gapped Storage**: 물리적으로 전원과 네트워크가 차단된 환경에 백업 테이프나 스토리지를 격리 보관하는 최후의 신뢰 영역.

</details>

```text
[랜섬웨어 방어·복구 체계]
|-- 인그레스 방어    : 초기 침투 차단
|-- 마이크로 분할    : 횡적 이동 제한
|-- EDR 보호         : 행위 탐지·격리
|-- WORM 저장소      : 불변 백업 보존
`-- Air-Gap 백업     : 오프라인 사본 보존
```

선의 의미: 프로덕션 운영망이 랜섬웨어에 의해 장악되더라도 독립 IAM 및 물리/논리적 단절선으로 보호되는 불변 백업 영역을 통해 무결한 신뢰 복구를 완수하는 구조

| 구성요소 | 책임 |
|:---|:---|
| 인그레스 방어 | MFA·패치로 **초기 침투 차단** |
| 마이크로 분할 | 엔드포인트 **횡적 이동 제한** |
| EDR 보호 | 행위 탐지·격리와 **Anti-Tamper** |
| WORM 저장소 | 삭제 불가 **불변 백업** 보존 |
| Air-Gap 백업 | 네트워크와 분리된 **최후 사본** 보존 |

#### 한줄 요약
- 인그레스 차단, 마이크로 세그멘테이션, EDR 템퍼 보호, 불변 WORM 스토리지, 오프라인 에어갭이 결합한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Trusted Recovery (신뢰 복구)**: 침해 서버를 포맷하고 OS를 재설치한 클린 샌드박스 환경에서 불변 백업본을 복구하여 백도어 잔존을 배제하는 절차.

</details>

```text
랜섬웨어 징후
      |
 1. 이상 행위 탐지
      |
 2. 감염 호스트 격리
      |
 3. IoC 식별·차단
      |
 4. 신뢰 환경 재구축
      |
 5. 불변 백업 복원
      |
   서비스 재개
```

동작 원리

1. 이상 행위 탐지
2. 감염 호스트 격리
3. IoC 식별·차단
4. 신뢰 환경 재구축
5. 불변 백업 복원

#### 한줄 요약
- EDR 조기 탐지 → 네트워크 링크 긴급 격리 → IOC 포렌식 → 클린 인프라 재구축 → 불변 백업 복원 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **1세대 단순 암호화** vs **2세대 이중 갈취** vs **3세대 다중 갈취**.

</details>

| 비교 항목 | 1세대 단순 암호화 (Single Extortion) | 2세대 이중 갈취 (Double Extortion) | 3세대 다중 갈취 (Multi-Extortion) |
|:---|:---|:---|:---|
| 핵심 갈취 수단 | 파일·디스크 **암호화** | 암호화와 **데이터 유출** | 암호화·유출·DDoS·압박 |
| 공격자 압박 전술 | 복호화 키 미제공 | 다크웹 공개 | 규제기관·고객 압박 |
| 기존 백업의 유효성 | 복원에 유효 | 유출 피해는 잔존 | 법무·PR 대응 필요 |
| 핵심 방어 대책 | **WORM·Air-Gap** | **저장 암호화·DLP·EDR** | IR·BCP·법률·공시 체계 |

#### 한줄 요약
- 1세대는 파일 암호화 중심, 2세대는 다크웹 기밀 유출 결합, 3세대는 DDoS 및 고객 압박을 결합한 다중 갈취이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **NIST IR 8374**: 랜섬웨어 침해를 예방(Prevent), 대응(Respond), 복구(Recover)하기 위한 미국 연방 표준 위험 관리 가이드라인.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 관리자 탈취로 **온라인 백업 삭제** | 관리망 분리와 **WORM·Air-Gap** | 백업 삭제 방지와 복구력 확보 |
| 대응 지연으로 **횡적 확산** | **EDR 원격 격리**와 IR 자동화 | 확산 골든타임 확보 |
| 고객정보 유출로 **법적 제재** | **저장 암호화·법정 신고** | 평문 노출 방지와 규정 준수 |
| 백도어 동반 복원으로 **재감염** | **클린 샌드박스 검증** | 안전한 서비스 재개 |

#### 한줄 요약
- 불변 백업으로 복구력을 보장하고, EDR 원격 격리로 확산을 막으며, 데이터 사전 암호화로 유출 피해를 방어한다.

## Ⅶ. 결론

- 확산은 **EDR 격리**, 복구는 **WORM·Air-Gap 신뢰 백업** 선택

#### 한줄 요약
- 랜섬웨어 방어는 불변 백업(WORM/Air-Gap)과 EDR 조기 격리 및 신뢰 복구 절차를 결합하여 다중 갈취를 무력화하는 종합 생존 체계다.
