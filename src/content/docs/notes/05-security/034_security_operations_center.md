## 미리 알고가기

- **보안 운영 센터(Security Operations Center, SOC)**: [읽기: 에스오씨; 표기 이유: 영문 머리글자와 구분 기호] 사람·절차·기술로 탐지·대응 운영
- **보안 정보 및 이벤트 관리(Security Information and Event Management, SIEM)**: [읽기: 에스아이이엠; 표기 이유: 영문 머리글자와 구분 기호] 로그 상관 분석
- **보안 오케스트레이션·자동화·대응(Security Orchestration, Automation and Response, SOAR)**: [읽기: 에스오에이알; 표기 이유: 영문 머리글자와 구분 기호] 조사·조치 자동화
- **종단 탐지·대응(Endpoint Detection and Response, EDR)**: [읽기: 이디알; 표기 이유: 영문 머리글자와 구분 기호] 단말 행위 탐지·격리
- **네트워크 탐지·대응(Network Detection and Response, NDR)**: [읽기: 엔디알; 표기 이유: 영문 머리글자와 구분 기호] 네트워크 행위 탐지
- **사이버 위협 인텔리전스(Cyber Threat Intelligence, CTI)**: [읽기: 씨티아이; 표기 이유: 영문 머리글자와 구분 기호] 탐지·헌팅 맥락 제공
- **에스컬레이션**: [읽기: 에스컬레이션; 표기 이유: 한국어 통용어 표기] 분석가 권한을 넘는 사건을 상위 책임자·전문팀으로 신속히 넘기는 절차




- **흐름 기호(↓·→·-->)**: [읽기: 아래로·다음으로·연결; 표기 이유: 절차 방향 기호] 순서와 연결 방향을 나타냄
## Ⅰ. 개요

- 정의: 사람·절차·기술을 통합한 **보안 운영 조직**
- 기존 한계: 분산 경보의 **책임·대응 단절**

### 쉽게 이해하기 (학습용)

- 탐지·대응을 위해 인력·절차·기술 통합

## Ⅱ. 특징

- 24시간 **탐지·분석·대응 운영**
- 역할·승인·에스컬레이션의 **책임 체계**
- SIEM·SOAR·EDR 기반 **통합 관제**

### 쉽게 이해하기 (학습용)

- 격리 및 복구 주체·권한 정의 필수

## Ⅲ. 구성요소 및 구조

```text
[거버넌스]
  ├─ [데이터 운영]
  ├─ [탐지 공학]
  └─ [사고 대응]
        ↓
[지식 관리]
```

| 설계 요소 | 설명 |
|:---|:---|
| 서비스·거버넌스 | 범위·역할·승인·성과 정의 |
| 데이터 운영 | 자산·네트워크 가시성 확보 |
| 탐지 공학 | 위협 분석·탐지 공백 제거 |
| 사고 대응 | 사건 분석·조치·복구 |
| 자동화·지식 | 반복 절차·지식 표준화 |

> 요약: SOC가 데이터·대응 주체를 사건 단위로 연결함

### 쉽게 이해하기 (학습용)

- 조직 내 유관 부서와의 유기적 연결

## Ⅳ. 원리 및 절차 흐름도

```text
임무설계
  ↓
로그수집
  ↓
대응준비
  ↓
관제대응
  ↓
훈련개선
```

| 절차 | 설명 |
|:---|:---|
| 임무설계 | 범위·책임 수준 정의함 |
| 로그수집 | 가시성 확보함 |
| 대응준비 | 플레이북 설계함 |
| 관제대응 | 격리·보고 수행함 |
| 훈련개선 | 공백 보완함 |

> 요약: 임무 설계 후 로그 수집·대응 준비·운영함

### 쉽게 이해하기 (학습용)

- 훈련을 통한 운영 실효성 검증

## Ⅴ. 종류 및 비교

| SOC 운영 모델 | 내부 SOC | 공동 SOC | 외부 위탁 |
|:---|:---|:---|:---|
| 적용 기준 | 자산 문맥·직접 조치 권한이 중요할 때 | 내부 책임과 외부 전문성을 결합할 때 | 상시 인력·기술 확보가 어려울 때 |
| 핵심 특징 | 내부 인력의 직접 탐지·대응 | 내부·외부 역할 분담 | 외부 전문 조직 관제 |
| 한계 | 인력 부족·교대 피로 | 책임·인계 경계 모호 | 자산 맥락·조치 권한 부족 |

> 요약: 모델은 문맥·전문성·조치 권한으로 결정함

### 쉽게 이해하기 (학습용)

- 대응 권한 부재 시 운영 효과 저하

## Ⅵ. 실무 사례

1. SOC 운영의 **정확도·복구시간 측정**
2. 위탁 계약의 **증거·조치 권한 명시**
3. 반복 업무의 **안전 범위 자동화**

### 쉽게 이해하기 (학습용)

- 탐지 속도와 함께 정확도·복구·재발 감소를 측정함
- 위탁 계약에 증거 접근·데이터 위치·조치 권한을 명시함
- 분석가 피로가 높은 반복 업무는 안전한 범위부터 자동화함

## Ⅶ. 결론

- **자산 맥락·조치 권한**에 따른 운영 모델 선택

### 쉽게 이해하기 (학습용)

- 중요한 침해를 끝까지 복구하는 운영 체계
