## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **AI 공급망 (AI Supply Chain)**: 인터넷상의 무작위 텍스트/이미지 원시 데이터 수집부터, 파운데이션 모델 학습 훈련, 외부 허깅페이스 라이브러리 파싱, 파인튜닝 파이프라인 빌드, 그리고 최종 클라우드 프로덕션 서비스 API 배포까지 끊임없이 엮여 연결되는 거대한 인공지능 자산의 전 과정 수명주기 생태계 팩트이다.
- **AI 공급망 보안 (AI Supply Chain Security)**: 단순 오픈소스 코드 점검을 넘어, 방대한 오염 데이터셋, 모델 가중치 아티바이너리 덩어리, 수많은 서드파티 의존성 파이썬 라이브러리의 최초 출처(Provenance)와 무결성(Integrity)을 통과 게이트마다 엄격히 검증하고, 오염 시 조상까지 추적해 내는 AI 특화 계보(Lineage) 방어 체계이다.
- **SBOM (Software Bill of Materials)**: 전통적 소프트웨어를 구성하는 오픈소스 라이브러리, 숨은 의존성 패키지, 버전 이력 정보를 트리 구조로 명세 기술하여, Log4j 같은 제로데이 취약점(CVE) 터졌을 때 즉각 연쇄 추적 색출 가능하게 만드는 부품 명세서 팩트이다.

</details>

- 정의: 데이터 스크래핑 수집, 수십 기가의 가중치 모델 반입, 소스코드 의존성 배포에 이르는 전 과정 파이프라인에서 악성 오염과 백도어 무결성을 감시하고, 실제 런타임 실행 행동을 조상 계보(Lineage) 단위로 엮어 역추적·통제 검증하는 **AI 전용 공급망 방어 구조**이다.
- 배경: 기존 코드 취약점을 스캔하는 **SBOM**이나 단순 전자서명 해시 대조만으로는, 가중치 내부에 교묘히 박힌 신경망 백도어(Poisoning), 편향된 악성 학습 데이터의 스며듦, 그리고 Pickling 직렬화 텐서의 치명적 원격 코드 실행(RCE) 등 거대 AI 고유의 암흑 공급망 위협을 원천적으로 절대 방어할 수 없었기 때문이다.

#### 한줄 요약

- 오염 가능성이 농후한 외부 학습 데이터, 블랙박스 모델 가중치 아티팩트, 의존 패키지 파이프라인의 이력을 AI-BOM과 가계도 계보로 상호 정밀 매핑하여 취약점 연쇄 추적 관리를 자동화 통제하는 보안 체계이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **AI-BOM (Artificial Intelligence Bill of Materials)**: 단순 코드 라이브러리 리스트인 SBOM을 AI 맞춤형으로 확장하여, 사용된 딥러닝 아키텍처 모델 구조, 거대 가중치 바이너리 해시, 긁어모은 학습 데이터셋 출처, 학습 시 사용된 프레임워크 버전(PyTorch 등), 그리고 상속받은 부모 모델 계보 족보까지 총망라해 박제해 놓은 AI 전용 부품 명세서 팩트이다.
- **데이터 및 모델 계보 (Data & Model Lineage)**: 더러운 크롤링 데이터셋 수집부터 텍스트 전처리 필터링, 하이퍼파라미터 세팅, 파인튜닝 가중치 갱신, 그리고 최종 서빙 배포 서비스까지 자산 간의 인과적 선후 관계 상호 연결망을 그래프로 기록한 유전 이력 팩트표이다.
- **격리 적재 샌드박싱 (Isolated Loading / Sandboxing)**: 허깅페이스 등 검증되지 않은 밖에서 주워 온 수 기가바이트의 거대 외부 모델 아티팩트를 사내 망에 들여오기 전에, 내부 네트워크 및 로컬 파일시스템과 완벽히 차단 격리된 철창 샌드박스 환경 내에서만 압축을 풀고 파싱 점검하는 무관용 방어 기법이다.
- **동적 행동 평가 (Behavioral Evaluation)**: 모델 가중치 파일의 해시 서명이 맞다고 끝내는 것이 아니라, 직접 샌드박스에 띄워놓고 입출력 이상 반응, 특정 단어(트리거) 입력 시 잠복 백도어 작동 여부, 심각한 윤리적 데이터 편향 및 유해망언 생성을 독립된 동적 환경에서 직접 찔러보며 가혹 테스트하는 평가 활동이다.
- **직렬화 안전 파싱 (Safe Parsing)**: 파이썬 고유의 Pickle 포맷처럼 로딩하는 순간 해커의 악성 OS 명령어가 덩달아 쉘에서 임의 실행(RCE)되어 버리는 치명적 직렬화 폭탄 포맷 대신, 오직 순수 수학적 텐서 가중치 숫자 데이터만 안전하게 메모리에 복원시켜 주는 Safetensors 포맷 기반의 원천 차단 파싱 기술이다.

</details>

- **AI-BOM 계보 기반 폭발 반경 즉시 추적**: 백도어나 데이터 오염 취약점 사고 발생 즉시, **AI-BOM** 명세와 인과 **계보** 그래프 분석을 통해, 바이러스에 감염된 부모 모델로부터 파생되어 영향받고 있는 모든 하위 자식 모델 및 연결 응용 서비스 라인을 1초 만에 추적 차단하는 팩트망을 가동한다.
- **안전 파싱 및 격리 샌드박스 강제**: 허깅페이스 Pickle 포맷의 최악의 맹점인 파일 로딩 시 RCE(임의 코드 실행) 장악 해킹 공격을 근본적으로 원천 차단하기 위해, Safetensors 포맷 전환을 강제하는 **안전 파싱** 및 완벽히 단절된 **격리 적재** 환경 검수소를 운영한다.
- **단순 서명을 넘은 실전 행동 평가**: 외부 래퍼뿐인 사전 학습 모델의 전자 서명/해시 무결성 검증 통과에 만족하지 않고, 직접 악의적 프롬프트를 주입해보는 동적 **행동 평가** 타격을 병행 수행하여, 딥러닝 가중치 뉴런 속에 깊숙이 잠복 은닉된 악성 트리거 백도어를 사전에 색출 적발한다.

#### 한줄 요약

- 암호학적 서명 대조 검증을 넘어, Safetensors 포맷 중심의 RCE 차단 안전 파싱 및 격리 샌드박스 행동 평가를 듀얼 병행 가동하여, 외부 반입 블랙박스 모델의 잠복 백도어를 원천 철벽 차단하는 특성을 지닌다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **격리 스테이징 반입소 (Isolated Staging Area)**: Hugging Face나 GitHub 등 통제 불가능한 외부 야생 허브에서 다운로드하여 반입한 온갖 출처 불명의 AI 자산을, 사내 1급 보안 운영망에 들이기 직전 강제로 가둬놓고 네트워크/파일 단절 상태로 격리 검사하는 거대한 방역 소독 검역소 팩트이다.
- **무결 출처 검증 (Provenance Verification)**: 1차적으로 해당 자산을 업로드한 제공자의 신원 인증, PKI 비대칭키 전자 서명 대조, 수집된 데이터셋의 치명적 라이선스 위반 및 개인정보 포함 여부 검사, 다운로드 중 변조를 확인하는 SHA-256 파일 해시 무결성을 종합적으로 서류 심사하는 검증 절차이다.
- **운영망 승격 게이트 (Promotion Gate)**: 정적 무결성 출처 서류 검증과 샌드박스 내 동적 행동/백도어 타격 검증을 상처 없이 무사히 100% 통과 생존한 깨끗한 안전 자산에 한해서만, 내부 프라이빗 레지스트리(운영망)로 정식 입장 메타데이터 태그를 부여해 전달하는 철통 통제 관문 팩트이다.
- **비상 회수 게이트 (Revocation Gate)**: 승격 게이트를 통과해 서비스 중인 자산이라도 추후 제로데이 취약점이나 지연 잠복 백도어가 사후 적발될 경우, 연결된 하위 파인튜닝 모델 및 전체 서비스 API 라인까지 연쇄적으로 즉시 셧다운 차단하고 안전 버전으로 강제 패치 회수시키는 제어 비상 스위치 요소이다.

</details>

```text
[AI 공급망 철벽 방어 통제 및 추적 검증 아키텍처 구조]

├─ [1. 족보 추적 기반망 계층]
│    └─ [AI-BOM 명세 및 모델/데이터 계보 그래프] (DNA 추적 시스템)
│
├─ [2. 야생 자산 반입 및 가혹 검증 통제 경계]
│    ├─ [망단절 격리 반입소 (Staging Area)] (샌드박스 방역소)
│    ├─ [서명/해시 출처 무결성 정적 검증기] (서류 대조)
│    └─ [백도어/독성 동적 행동 평가 타격기] (런타임 이상 유발 스캔)
│
└─ [3. 사내 운영망 진입 및 비상 제어 경계]
     ├─ [안전 자산 운영망 승격 게이트 (Promotion Gate)]
     └─ [오염 확산 차단 비상 회수 게이트 (Revocation Gate)]
```

| 공급망 통제 구성요소 | 핵심 보안 책임 및 통제 역할 |
|:---|:---|
| **AI-BOM 및 계보망** | 모델 아키텍처 및 데이터 출처 **AI-BOM** 및 패키지 **SBOM** 메타데이터 자동 추출 명세 생성, 감염 확산 추적용 부모-자식 가계도 모델 계보 영구 박제 관리 |
| **격리 스테이징 반입소** | 외부 야생 모델 바이너리/아티무단 다운로드 즉시 통제 및 내부 사내망과 완벽 단절된 격리 샌드박스에서 위험 직렬화 파싱 폭탄 검사 강제 수행 |
| **출처 무결성 정적 검증** | 신뢰할 수 있는 개발자 PKI 서명 기반 검증, 데이터셋 상업용 라이선스 독소 조항 점검, 배포 패키지 파일 해시 1비트 위조 무결성 변조 대조 측정 |
| **샌드박스 동적 행동 평가기** | 잠복 악성 코드 동적 메모리 실행 스캔, 탈옥/인젝션 프롬프트 무단 유해성 망언 생성 한계 시험, 특정 조건 발동 트리거 기반 신경망 백도어 적발 동적 평가 집행 |
| **승격 및 비상 회수 게이트** | 가혹한 극심한 혼선 검증 통과 아티팩트에 한하여 **승격 게이트** 입장 허용 및 추후 운영 중 치명적 위협 폭발 시 즉각 **회수 게이트** 셧다운 발동 |

#### 한줄 요약

- 망단절 격리 영역에서의 출처 대조/동적 행동 다중 철저한 검증을 거쳐 깨끗한 자산만 승인 저장소로 승격시키고, 사후 사고 발생 시 AI-BOM 계보 유전자 분석을 통해 파생 라인 전체를 신속히 일괄 회수 셧다운한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **직렬화 텐서 안전 파싱 (Model Serialization Safe Parsing)**: 파이썬 Pickle의 내장된 임의 코드 실행(RCE) 치명적 맹점을 악용한 서버 해킹 익스플로잇 통제 차단을 위해, 오직 순수 데이터만 담아 해킹 실행이 원천 불가능한 Safetensors 포맷 적용 검사를 엄격히 강제하는 검문 기법이다.
- **오염 연쇄 영향 추적 (Impact Lineage Tracking)**: 특정 훈련 데이터셋 또는 기반 부모 파운데이션 모델에서 뒤늦게 심각한 오염/망언 이상이 감지되었을 때, 이 썩은 뿌리를 참조하여 파인튜닝된 전사 수십 개의 전체 하위 응용 서비스 가계도 라인을 1초 단위로 파악해 내는 추적 기법이다.
- **긴급 회수 롤백 (Recall & Revocation Rollback)**: 인가 승인이 긴급 취소 박탈된 악성 모델 자산이 올라간 쿠버네티스 서빙 컨테이너를 강제로 Kill 종료시켜 버리고, 사고 이전의 무결성이 검증된 옛날 안전 버전으로 백업 롤백시키는 최후 비상 조치 팩트이다.
- **제공자/버전/해시 즉시 등록 (Provider, Version & Hash Registration)**: 외부 다운로드 자산이 사내망 문턱을 밟는 즉시 고유 식별자 ID를 박고 메타데이터 해시값을 주민등록증처럼 강제 등록하는 최초 통제 단계이다.
- **안전 파싱 및 망단절 격리 적재 (Safe Parsing & Isolated Staging)**: 오프라인 샌드박스 환경에서 Pickle 등 폭탄 직렬화 포맷 구조 해체 및 악성 임베딩 쉘 코드를 색출 검사하는 지뢰 탐지 단계이다.
- **출처 및 악성 행동 듀얼 검증 (Provenance & Behavior Verification)**: 외부 래퍼 서명 해시 무결성 검증(정적)과, 샌드박스 내부 오염 동작 여부, 유해망언 백도어 취약점(동적)을 동시 입체 테스트하는 핵심 심사 단계이다.
- **승인 무결 자산 운영 승격 (Approved Asset Promotion)**: 피말리는 신뢰성 시험을 100% 무상처 입증 통과한 모델 및 정제 데이터만을 사내 프라이빗 안전 저장소(Registry)로 운영망 승격 릴리즈하는 단계이다.
- **치명적 영향 추적 및 일괄 회수 (Impact Tracking & Asset Recall)**: 운영 중 사후 취약 자산 적발 발생 시, AI-BOM 족보 계보를 역추적 기반으로 엮여있는 모든 의존 서비스를 자동 연쇄 회수 및 격리 조치하는 대응 단계이다.

</details>


### 동작 원리

1. 반입 자산 즉시 등록: 출처 PKI 해시 인증서와 작성자 서명을 족보에 등록한다.
2. 안전 파싱 및 격리 적재: 위험한 Pickle을 버리고 RCE 해킹 직렬화 코드 실행 여부를 격리 샌드박스에서 검사한다.
3. 듀얼 출처 및 행동 검증: 외부 래퍼 서명 검사뿐 아니라 직접 찔러보는 유해 망언/백도어 동적 행동 평가를 집행한다.
4. 생존 승인 자산 승격: 가혹 검증을 견딘 자산만 프라이빗 저장소에 넣고 부모자식 계보를 갱신 연결한다.
5. 연쇄 영향 추적 및 비상 회수: 사고 발생하면 족보를 뒤져 오염된 의존 하위 서비스를 일망타진 연쇄 격리 롤백한다.

#### 한줄 요약

- 무작위 외부 모델 반입 증명 등록부터 단절 동적 샌드박스 파싱 검증, 안전 프라이빗 레지스트리 승격, 그리고 사후 이상 징후 발발 시 족보 계보 추적 연쇄 회수까지 생애주기 전반을 통합 제어 철저한 방어한다.
