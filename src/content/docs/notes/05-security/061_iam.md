## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **신원•접근 관리(Identity and Access Management, IAM)**: 디지털 신원과 접근 권한의 생성•변경•검토•회수 관리 체계이다.
- **디지털 신원(Digital Identity)**: 사람•서비스•장치를 시스템에서 식별하는 속성과 계정의 집합이다.

</details>

- 정의/개념: 신원과 권한 수명주기를 통제하는 **IAM**
- 배경/필요성: 시스템별 계정 관리는 **고아 계정•권한 불일치** 유발

#### 한줄 요약

- **입사•이동•퇴사** 사건에 따른 계정•권한 자동 전파

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **신원 수명주기(Identity Lifecycle)**: 신원의 등록•이동•휴직•퇴사•폐기까지 이어지는 상태 변화와 처리 과정이다.
- **프로비저닝(Provisioning)**: 계정과 권한을 대상 시스템에 생성•변경•중지하는 자동화 처리이다.
- **접근 검토(Access Review)**: 부여된 권한의 업무 필요성과 적정성을 주기적으로 재확인하는 통제 절차이다.
- **인증(Authentication)**: 접근을 요청한 주체의 신원을 식별하고 검증하는 절차이다.
- **인가(Authorization)**: 확인된 주체가 특정 자원에 수행할 수 있는 행위 권한을 판단하는 절차이다.

</details>

- **신원 수명주기**는 권위 원천의 신원 상태 변화를 대상 시스템의 계정 프로비저닝 처리로 연결한다.
- **인증, 인가, 프로비저닝** 정책을 단일 통제 흐름으로 일치시켜 관리 공백을 제거한다.
- **접근 검토**를 통해 최소 권한 원칙을 유지하고 남용•권한 오남용 위험을 차단한다.

#### 한줄 요약

- 인사 데이터의 신원 상태 변경 시 연계 시스템의 계정과 권한이 동기화되어 즉시 반영된다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **권위 원천(Authoritative Source)**: 인사 DB 등 소속•고용 상태의 기준이 되는 신뢰 정보원이다.
- **권한 거버넌스(Identity Governance)**: 권한의 요청•승인•검토•회수를 중앙 통제하는 관리 체계이다.
- **감사 대조(Audit Reconciliation)**: 승인된 기준 권한과 대상 시스템의 실제 권한 차이를 주기적으로 확인•교정하는 활동이다.
- **다중 요소 인증(Multi-Factor Authentication, MFA)**: 지식•소유•생체 등 서로 다른 2개 이상의 인증 요소를 조합하는 방식이다.
- **통합 인증(Single Sign-On, SSO)**: 단일 인증으로 연계된 다수 자원에 추가 인증 없이 접근하는 기술이다.

</details>

```text
[통합 신원·접근 관리(IAM)]
   |
   +-- [권위 원천]
   +-- [수명주기·프로비저닝]
   +-- [인증·연합]
   +-- [권한 거버넌스]
   `-- [감사·대조]
```

선의 의미: 권위 원천을 기준으로 계정 관리•인증•권한 거버넌스•감사 대조 기능이 결합되는 IAM 구조를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 권위 원천 | **권위 원천**이 주체•소속•상태의 단일 기준 제공 |
| 수명주기•프로비저닝 | **프로비저닝**으로 계정과 상태 자동 생성•전파 |
| 인증•연합 | 인증기•**MFA**•**SSO** 기반 신원 검증 관리 |
| 권한 거버넌스 | **권한 거버넌스**로 요청•승인•검토•회수 통제 |
| 감사•대조 | **감사 대조**로 기준과 실제 상태의 불일치 탐지 및 자동 교정 |

#### 한줄 요약

- 권위 원천의 신원 변경을 IAM이 전파하고 감사 대조가 실제 반영 상태의 완전성을 보장한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **고아 계정(Orphan Account)**: 유효한 소유자 없이 대상 시스템에 방치된 계정이다.
- **계정•세션•토큰 회수(Account/Session/Token Revocation)**: 퇴사 및 권한 변경 시 계정 비활성화와 발급된 세션•접근 토큰의 즉시 무효화 처리이다.
- **권위 원천•신원 상태 검증(Authoritative Source Identity Verification)**: 주체의 소속•고용 상태 변경을 기준 정보원에서 확인하는 단계이다.
- **역할•속성•권한 후보 계산(Role/Attribute Authorization Calculation)**: 직무와 정책에 따라 필요한 접근 권한 후보를 도출하는 단계이다.
- **최소 권한•만료 확정(Least Privilege & Expiration Determination)**: 권한 범위•유효기간•승인 조건을 최종 결정하는 단계이다.
- **프로비저닝 명령 생성(Provisioning Command Generation)**: 대상 시스템별 계정•권한의 목표 상태를 명령으로 만드는 단계이다.
- **신원•권한 상태 적용(Identity & Privilege Enforcement)**: 계정과 권한을 생성•변경•중지하고 실제 처리 결과를 반환하는 단계이다.

</details>

```text
[권위 원천]
      |
      `-- 입사•이동•퇴사 사건
                  |
                  v
[IAM·권한 거버넌스]
      |
      v
1. 권위 원천·신원 상태 검증
      |
      v
2. 역할·속성·권한 후보 계산
      |
      v
3. 최소 권한·만료 확정
      |
      v
4. 프로비저닝 명령 생성
      |
      v
[대상 시스템]
      |
      +-- 5. 신원·권한 상태 적용
      `-- 적용 결과·실패 ----> [IAM 감사·대조]
```

### 동작 원리

1. **권위 원천•신원 상태 검증**: 소속•고용 상태 변경 확인
2. **역할•속성•권한 후보 계산**: 직무•정책별 권한 도출
3. **최소 권한•만료 확정**: 범위•유효기간•승인 조건 결정
4. **프로비저닝 명령 생성**: 계정•세션•토큰 목표 상태 생성
5. **신원•권한 상태 적용**: 계정•권한 생성•변경•중지

#### 한줄 요약

- 퇴사 발생 시 계정 차단과 세션·토큰 즉시 회수를 수행하고, 미반영분은 감사 대조로 탐지한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **중앙 IAM(Centralized IAM)**: 조직 내 다수 시스템의 신원 수명주기를 일관되게 중앙 통제하는 방식이다.
- **연합 IAM(Federated IAM)**: SAML, OAuth, OIDC 표준을 기반으로 조직 경계를 넘어 신원과 접근 권한을 연계하는 방식이다.

</details>

| 신원 관리 방식 | 중앙 IAM | 시스템별 수동 관리 | 연합•클라우드 IAM |
|:---|:---|:---|:---|
| 적용 기준 | 다수 시스템의 일관 통제 | 소규모 단일 시스템 | 조직•클라우드 경계 연동 |
| 핵심 특징 | **중앙 IAM**의 수명주기•권한 관리 | 시스템별 관리자 수동 처리 | **연합 IAM**의 조직 간 신원•권한 연계 |
| 한계 | 연계 표준 구현 복잡성 | **고아 계정** 발생•정책 편차 | 신뢰 설정 관리•토큰 탈취 위험 |

#### 한줄 요약

- 중앙 IAM은 내부 일관성을 강화하고, 연합 IAM은 조직 간 표준 기반 신뢰 연동을 제공한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **NIST SP 800-63-4**: 신원 증명(IAL), 인증(AAL), 연합(FAL)의 위험 기반 보증 수준을 제시하는 미국 국립표준기술연구소 지침이다.
- **교차 도메인 신원 관리 체계(System for Cross-domain Identity Management, SCIM)**: 사용자•그룹 자원의 수명주기를 이기종 시스템에 프로비저닝하는 REST 기반 표준 규격이다.
- **IETF RFC 7644**: SCIM 자원의 생성•변경•삭제 HTTP 프로토콜 규격을 정의하는 인터넷 표준 문서이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 신원 보증수준 불일치 | **NIST SP 800-63-4** 지침 적용 | IAL•AAL•FAL 보증 수준의 균형적 강화 |
| 계정 수명주기 연동 편차 | **IETF RFC 7644** 및 **SCIM** 표준 적용 | 이기종 시스템 간 프로비저닝 통일 |
| 전파 실패•고아 계정 | 주기적 감사 대조 및 즉시 재처리 | 잔존 권한 방지 및 권한 오남용 차단 |

#### 한줄 요약

- SCIM 표준 기반 자동 프로비저닝 구축 및 퇴사 시 세션·토큰의 즉시 회수 메커니즘을 적용한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **상태 전파 완결성(State Propagation Completeness)**: 신원의 상태 변화가 연결된 모든 계정•세션•토큰•키에 결함 없이 반영되었는지 검증하는 운영 기준이다.

</details>

- **상태 전파 완결성**을 검증하며 내부 시스템에는 **중앙 IAM**, 외부 연동에는 **연합 IAM** 체계를 적용한다.

#### 한줄 요약

- 내부는 **중앙 IAM**, 외부 연동은 **연합 IAM** 적용
