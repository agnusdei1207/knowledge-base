## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **APT (Advanced Persistent Threat)**: 특정 표적을 대상으로 고도의 기법과 장기 잠복을 통해 기밀을 탈취하는 지능형 지속 위협.
- **Dwell Time (체류 시간)**: 최초 침투부터 보안팀에 의해 최종 탐지·축출될 때까지 공격자가 내부망에 잠복한 기간.

</details>

- 정의/개념: 특정 표적을 설정하고 제로데이와 정상 도구(LOLBins)를 악용해 **수개월~수년간 은닉 체류하며 기밀을 탈취하는 지능형 표적 공격 및 능동 방어 기술**
- 배경/필요성: 단순 IP/해시(IOC) 기반 시그니처 보안의 **변종 악성코드 및 파일리스/정상 명령 악용 탐지 불가, 장기 잠복(Dwell Time) 방치**

#### 한줄 요약
- 맞춤형 은닉 침투와 횡적 이동을 차단하기 위해 TTP 기반 위협 헌팅과 동시 축출 작전을 수행한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **LOLBins (Living off the Land Binaries)**: 악성 실행 파일을 직접 유입시키지 않고 OS에 기본 내장된 정상 도구(PowerShell, WMI, Certutil)를 악용하여 백신 탐지를 회피하는 기법.
- **Pyramid of Pain (고통의 피라미드)**: 해시값/IP 등 하위 지표보다 최상위 TTP(전술·기술·절차)를 무력화할 때 공격자에게 극단적 타격을 준다는 보안 모델.

</details>

- **명확한 표적 지향성 및 고도의 전문성**: 특정 기관/기업의 **핵심 자산(Crown Jewels)을 타깃으로 0-Day 및 맞춤형 악성코드 투입**
- **정상 도구 악용 기반 장기 은닉(LotL)**: PowerShell, WMI 등 **정상 관리 도구를 악용하여 보안 장비의 시그니처 탐지 완전 무력화**
- **다단계 침해 라이프사이클 전개**: 침투, 거점 확립, **권한 상승, 횡적 이동(Lateral Movement), 데이터 유출로 이어지는 조직적 실행**

#### 한줄 요약
- 표적 지향성, 정상 도구(LOLBins) 악용 장기 은닉, 다단계 침해 라이프사이클을 전개한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **Crown Jewels (핵심 자산)**: 공격자의 최종 목표가 되는 전사 ERP 데이터베이스, 소스 코드 저장소, 고객 개인정보 서버.

</details>

```text
[APT 공격 단계 및 엔터프라이즈 방어 토폴로지]
|-- Ingress & Foothold (1. 정찰 -> 2. 스피어피싱 초기 침투 -> 3. C2 백도어 지속성 확립)
`-- Internal Lateral Movement (내부망 확산 영역)
|   |-- 4. Credential Dumping (LSASS 메모리 덤프 / Mimikatz / Kerberoasting)
|   `-- 5. Lateral Movement (정상 관리 도구 악용: PowerShell / WMI / PsExec)
`-- Crown Jewels Target (6. 핵심 ERP/DB 도달 -> 7. 기밀 데이터 암호화 분할 외부 유출)
`-- Threat Hunting & EDR (전사 엔드포인트 로그 상관 분석 -> 침해 지표 식별 및 동시 축출)
```

선의 의미: 공격자가 표적 맞춤형 침투 후 내부 지속성을 확립하고 자격증명 탈취와 횡적 이동을 거쳐 핵심 자산에 도달하여 데이터를 유출하는 구조

| 구성요소 | 핵심 엔지니어링 책임 | 주요 특징 |
|:---|:---|:---|
| **초기 침투 엔진** | 스피어피싱, 취약한 VPN/RDP 포트를 통한 **침투 교두보 확보** | Initial Access |
| **지속성 유지 모듈** | 윈도우 스케줄러, 레지스트리 자동 실행에 **C2 백도어를 등록하여 장기 상주** | Persistence |
| **자격증명 추출기** | LSASS 메모리 덤프 또는 SAM 탈취로 **도메인 관리자 권한 획득** | Credential Access |
| **LotL 횡적 이동기** | PowerShell, WMI, RDP 등 **정상 도구를 악용하여 서브넷 간 은밀 이동** | Lateral Movement |
| **위협 헌팅 방어 계층**| EDR 텔레메트리 로그를 기반으로 **비인가 행위 패턴을 능동 탐지 및 축출** | Threat Hunting |

#### 한줄 요약
- 초기 침투 엔진, 지속성 유지 모듈, 자격증명 추출기, LotL 횡적 이동기, EDR 위협 헌팅 계층이 결합한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Simultaneous Eviction (동시 축출 작전)**: 잔여 백도어로의 재잠복을 방지하기 위해 식별된 모든 C2 채널, 백도어, 침해 계정을 특정 시점에 전사 일괄 차단·초기화하는 절차.

</details>

```text
APT 침해 전개, 장기 잠복 및 방어팀 동시 축출 파이프라인
        │
   1. [정찰 및 침투] 표적 조직의 신원을 분석하여 맞춤형 스피어피싱 악성코드 발송
        │
   2. [거점 확립] 실행 즉시 EDR을 우회하고 재부팅 시에도 상주하는 스케줄러 등록
        │
   3. [자격증명 탈취] 로컬 관리자 권한 획득 후 Active Directory 도메인 관리자 계정 탈취
        │
   4. [횡적 이동] 정상 윈도우 명령(PowerShell)을 악용하여 핵심 DB 서버(Crown Jewels) 식별
        │
   5. [데이터 유출] 추출된 기밀을 암호화 분할하여 정상 HTTPS 패킷으로 은닉 반출
        │
   ▼
6. [방어팀 동시 축출] 전사 EDR 기반 침해 조사 ➔ [D-Day 일괄 C2 차단 + 계정 리셋 + 재구축]
```

#### 한줄 요약
- 맞춤형 침투 → 지속성 거점 확립 → 자격증명 탈취 → 정상 도구 횡적 이동 → 데이터 유출 → 동시 축출 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **APT (표적 지속)** vs **기회주의적 공격 (단기 무차별)** vs **내부자 위협 (합법 권한 악용)**.

</details>

| 비교 항목 | 지능형 지속 위협 (APT) | 기회주의적 공격 (Opportunistic) | 내부자 위협 (Insider Threat) |
|:---|:---|:---|:---|
| **공격 표적** | **단일 특정 타깃 조직 1:1 집중 표적** | 불특정 다수 (자동화 스캐너 악용) | **자신이 소속된 내부 시스템 및 데이터** |
| **공격 동기** | **국가 기밀, 핵심 기술(도면), 금융 탈취**| 금전 갈취 (랜섬웨어, 코인 채굴) | 금전, 보복, 경쟁사 이직을 위한 기술 유출 |
| **사용 기술 및 도구** | **0-Day 취약점, 맞춤형 툴, LotL/LOLBins**| 기 공지된 취약점(1-Day), 자동화 스크립트| **합법적으로 부여된 정상 인가 권한 악용**|
| **체류 기간 (Dwell)** | **수개월 ~ 수년 (초장기 스텔스 잠복)** | 수 시간 ~ 수 일 (단기 감염 후 즉시 발각)| 근무 기간 전반에 걸친 지속적 유출 |
| **핵심 방어 전략** | **MITRE ATT&CK TTP 기반 능동 위협 헌팅** | **정기 패치, 방화벽, 백신(AV) 시그니처** | **PAM(특권접근관리), DLP, UEBA 행동 분석**|

#### 한줄 요약
- APT는 국가/전문 조직의 장기 은닉 표적 공격, 기회주의는 무차별 단기 공격, 내부자는 합법 권한 악용이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **AMSI (Antimalware Scan Interface)**: 윈도우 OS에서 난독화된 PowerShell, VBScript 등이 메모리에서 실행되기 직전에 평문 코드를 백신/EDR에 전달해 검사받게 하는 표준 인터페이스.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 공격자가 C2 도메인과 해시를 수시로 변경하여 **시그니처 보안 장비 탐지 회피** | **Pyramid of Pain 최상위 계층인 `MITRE ATT&CK TTP 기반 EDR/XDR 위협 헌팅`** 수행 | 도구 변형과 무관한 본질적 공격 행위 100% 탐지 |
| 침해된 시스템의 백도어를 단건 조치하여 **공격자가 잔여 대체 C2로 재잠복하는 실패** | **전사 포렌식 기반 `모든 거점 식별 후 일괄 격리하는 동시 축출(Simultaneous Eviction)`** | 잔존 재감염 경로 완전 제거 및 침해 재발 차단 |
| 정상 도구(LOLBins)를 악용하여 디스크 흔적 없이 **백신을 우회하는 파일리스 공격** | **`PowerShell Script Block 로깅 활성화 및 AMSI 연동` 강제** | 메모리 상의 난독화 스크립트 실시간 디코딩 및 차단 |
| 내부망 횡적 이동 시 정상 자격증명을 악용한 비인가 서버 접속 | **`Privileged Access Management(PAM) 도입 및 다중 세그멘테이션`** 적용 | 도메인 관리자 권한 남용 차단 및 횡적 이동 봉쇄 |

#### 한줄 요약
- TTP 기반 헌팅으로 IOC 변형을 잡고, 동시 축출로 재침투를 막으며, AMSI 로깅으로 파일리스를 방어한다.

## Ⅶ. 결론

- 명확한 목적을 가지고 장기간 은닉 체류하는 **APT 공격 대응 아키텍처는 단편적 경계 차단 중심에서 벗어나 내부 침해를 가정한 제로 트러스트 및 가시성 중심 보안을 요구**하며, 실무 구현 시 **MITRE ATT&CK 기반 TTP 위협 모델링, EDR 기반 상시 능동 위협 헌팅(Threat Hunting), 체계적인 동시 축출(Simultaneous Eviction) 프로세스**를 결합하여 빈틈없는 엔터프라이즈 레질리언스 완성

#### 한줄 요약
- APT 대응은 MITRE ATT&CK TTP 기반 위협 헌팅과 AMSI 연동 및 동시 축출 작전을 통해 장기 은닉 위협을 무력화하는 능동 방어 체계다.
