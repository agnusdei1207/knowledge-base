## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **지능형 지속 위협(Advanced Persistent Threat, APT)**: 국가 지원 해킹 조직이나 고도화된 사이버 범죄 집단이 명확한 전략적 표적(정부, 방위산업, 금융, 핵심 인프라)을 설정한 후, 제로데이(0-Day) 취약점, 스피어피싱, 정상 윈도우 유틸리티(LOLBins) 등 다양한 침투 기법을 복합 사용하여 수개월~수년간 시스템 내부에 은닉 체류하며 기밀 데이터를 탈취하는 지능형 표적 공격.
- **체류 시간(Dwell Time)**: 공격자가 최초로 내부망에 침투한 시점부터 보안 관제팀에 의해 최종 탐지되어 격리될 때까지 시스템 내부에 은밀히 잠복해 있는 전체 기간.

</details>

- 정의/개념: 고도의 공격 기술(Advanced), 탐지를 회피하는 장기 은닉 체류(Persistent), 명확한 의도와 배후 세력을 가진 공격 주체(Threat)의 결합으로 정의되며, **사전 정찰 $\rightarrow$ 초기 침투 $\rightarrow$ 거점 확보(Persistence) $\rightarrow$ 권한 상승 및 측면 이동 $\rightarrow$ 데이터 은닉 반출(Exfiltration)** 로 완결되는 **표적 맞춤형 침해 아키텍처**
- 배경/필요성: 단편적인 시그니처 기반 백신(AV)이나 경계 방화벽만으로는 정상적인 도구(PowerShell, WMI)와 암호화된 C2 통신으로 위장하는 APT 공격의 장기 체류를 탐지할 수 없는 구조적 한계를 극복할 요구

#### 한줄 요약
- 명확한 표적에 대해 장기간 은닉 체류하며 정상 도구를 악용해 핵심 기밀을 탈취하는 지능형 표적 공격이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **지속성 확보(Persistence / MITRE TA0003)**: 시스템 재부팅, 백신 검사, 사용자 로그오프 이후에도 악성 프로세스가 백그라운드에서 지속적으로 자동 실행되도록 레지스트리 런키(Run Keys), 스케줄러 태스크, WMI 이벤트 구독을 조작하는 기법.
- **정상 도구 악용(Living off the Land, LotL / LOLBins)**: 악성 바이너리를 직접 디스크에 드롭하지 않고, 윈도우/리눅스 기본 탑재 실행 파일(PowerShell, Certutil, Wmic, Bash)을 실행하여 보안 에이전트의 시그니처 탐지를 무력화하는 파일리스(Fileless) 기법.

</details>

- **3대 핵심 속성**: 지능성(Advanced: 0-Day 취약점), 지속성(Persistent: C2 다중화), 위협성(Threat: 명확한 목표 지향)
- **파일리스(Fileless) 및 LotL 기법**: 디스크에 실행 파일을 남기지 않고 메모리 인젝션(DLL Injection, Process Hollowing)으로 동작
- **TTP(전술·기술·절차) 기반 추적 필요성**: 공격자의 IP, 도메인, 해시값(IOC)은 수시로 변경되므로 행위 기반 TTP(MITRE ATT&CK) 분석 필수

#### 한줄 요약
- 지능성/지속성/위협성 결합, LotL 기반 파일리스 은닉, MITRE ATT&CK TTP 기반 행위 추적을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **C2 다중화 인프라(Command and Control Infrastructure)**: 단일 C2 IP가 차단되더라도 지속적인 명령 제어를 유지하기 위해, Dynamic DNS, Tor 네트워크, 정상 클라우드 서비스(GitHub, Discord API, Google Drive)를 C2 채널로 위장 활용하는 회피 인프라.

</details>

```text
[ APT 공격자 인프라 (Advanced Actor Group) ]
 ├─ 표적 맞춤형 소셜 엔지니어링 / 0-Day 익스플로잇 무기화
 └─ 분산 다중 C2 인프라 (Domain Fronting / DNS Tunneling)
           │
           ▼ (1. 스피어피싱 이메일 / 공급망 취약점 침투)
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 피해 조직 내부 엔터프라이즈 환경 (Target Enterprise Environment) ]     │
│  ├─ 2. 초기 침해 거점 (Initial Foothold): 엔드포인트 단말 감염         │
│  │                                                                      │
│  ├─ 3. 지속성(Persistence) 확립: WMI 이벤트 / 레지스트리 런키 등록       │
│  │                                                                      │
│  ├─ 4. 권한 상승 & 자격증명 덤프: LSASS 메모리 추출 (Mimikatz)          │
│  │                                                                      │
│  └─ 5. 횡적 이동(Lateral Movement): Kerberos 골든 티켓 / SMB / PsExec   │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │ (6. 다단계 점프 후 핵심 DB 서버 도달)
                                     ▼
[ 핵심 자산 영역 (Crown Jewels: ERP DB / 기술 도면 / 고객 정보) ]
 └─ 데이터 압축/암호화 ➔ 분할 아웃바운드 전송 ➔ [ 외부 데이터 유출 (Exfiltration) ]
```

선의 의미: 공격자가 표적 맞춤형 침투 후 내부 지속성을 확립하고, 자격증명 탈취와 횡적 이동을 거쳐 핵심 자산(Crown Jewels)에 도달하여 데이터를 유출하는 구조

| 구성요소 | 핵심 책임 및 역할 | 비고 |
|:---|:---|:---|
| **초기 침투 엔진** | 스피어피싱, 악성 매크로 문서, 취약한 VPN/RDP 포트를 통한 침투 교두보 확보 | Initial Access |
| **지속성 유지 모듈** | 윈도우 스케줄러, 레지스트리 자동 실행 키에 C2 백도어를 등록하여 장기 상주 | Persistence |
| **자격증명 추출기** | LSASS 메모리 덤프(Mimikatz) 또는 SAM 레지스트리 탈취로 도메인 관리자 권한 획득 | Credential Access |
| **LotL 횡적 이동기** | PowerShell, WMI, RDP 등 정상 관리 도구를 악용하여 서브넷 간 은밀한 이동 수행 | Lateral Movement |
| **위협 헌팅 방어 계층** | 엔드포인트 EDR 텔레메트리 로그를 기반으로 비인가 행위 패턴을 능동 탐지 및 축출 | Threat Hunting |

#### 한줄 요약
- 초기 침투 엔진, 지속성 유지 모듈, 자격증명 추출기, LotL 횡적 이동기, EDR 위협 헌팅 계층이 결합한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **동시 축출 작전(Simultaneous Eviction)**: APT 침해 사고 대응 시, 발견된 백도어를 개별적으로 제거할 경우 공격자가 잔여 백도어로 숨어들어 영구 은닉하므로, 포렌식을 통해 식별된 모든 C2 채널, 백도어, 침해 계정을 사전에 정의된 특정 시각에 전사 일괄 차단 및 초기화하는 작전.

</details>

```text
1. [정찰 및 침투] 표적 조직의 임직원 신원 정보를 분석하여 맞춤형 스피어피싱 악성코드 발송
            │
            ▼
2. [거점 확립] 실행 즉시 엔드포인트 EDR을 우회하고 재부팅 시에도 상주하는 스케줄러 태스크 등록
            │
            ▼
3. [자격증명 탈취] 로컬 관리자 권한 획득 후 Active Directory 도메인 컨트롤러(DC) 관리자 계정 탈취
            │
            ▼
4. [횡적 이동 & 정찰] 정상 윈도우 명령(PowerShell)을 악용하여 핵심 DB 서버(Crown Jewels) 위치 식별
            │
            ▼
5. [데이터 유출] 추출된 기밀 데이터를 10MB 단위로 암호화 분할하여 정상 HTTPS/DNS 패킷으로 은닉 반출
            │
            ▼
6. [방어팀 동시 축출] 전사 EDR 기반 침해 흔적 전수 조사 ➔ [D-Day 일괄 C2 차단 + 계정 리셋 + 재구축]
```

**동작 원리**

1. **소셜 엔지니어링**: 표적 직원의 업무 맥락(입사지원서, 견적서)에 완벽히 부합하는 미끼 문서 전송
2. **권한 탈취 파이프라인**: 윈도우 토큰 조작(Token Impersonation)을 통해 도메인 전역 장악
3. **스텔스 횡적 이동**: 보안 솔루션의 네트워크 알람을 회피하기 위해 표준 관리 포트(RPC/SMB 445) 악용
4. **스테이징 및 유출**: 데이터 수집 후 정상 아웃바운드 웹 트래픽(HTTPS 443)의 페이로드로 위장 반출
5. **완전 축출**: 단일 거점 제거가 아닌 전사 범위의 잔존 악성 모듈 및 탈취 계정 동시 무력화

#### 한줄 요약
- 맞춤형 침투, 지속성 거점 확립, 자격증명 탈취, 정상 도구 횡적 이동, 데이터 유출, 동시 축출 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **사이버 위협 행위자 유형 비교**: APT 지능형 표적 공격, 기회주의적 대량 공격(Commodity), 내부자 위협(Insider)의 동기, 기술 수준, 방어 전략 비교.

</details>

| 비교 항목 | 지능형 지속 위협 (APT) | 기회주의적 공격 (Opportunistic) | 내부자 위협 (Insider Threat) |
|:---|:---|:---|:---|
| **공격 표적** | **단일 특정 타깃 조직 1:1 집중 표적** | 불특정 다수 (자동화 스캐너 악용) | **자신이 소속된 내부 시스템 및 데이터** |
| **공격 동기** | **국가 기밀, 핵심 기술(도면), 금융 탈취**| 금전 갈취 (랜섬웨어, 코인 채굴) | 금전, 보복, 경쟁사 이직을 위한 기술 유출 |
| **사용 기술 및 도구** | **0-Day 취약점, 맞춤형 툴, LotL/LOLBins**| 기 공지된 취약점(1-Day), 자동화 스크립트| **합법적으로 부여된 정상 인가 권한 악용**|
| **체류 기간 (Dwell)** | **수개월 ~ 수년 (초장기 스텔스 잠복)** | 수 시간 ~ 수 일 (단기 감염 후 즉시 발각)| 근무 기간 전반에 걸친 지속적 유출 |
| **핵심 방어 전략** | **MITRE ATT&CK TTP 기반 능동 위협 헌팅** | **정기 패치, 방화벽, 백신(AV) 시그니처** | **PAM(특권접근관리), DLP, UEBA 행동 분석**|

#### 한줄 요약
- APT는 국가/전문 조직의 장기 은닉 표적 공격, 기회주의는 무차별 단기 공격, 내부자는 합법 권한 악용이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **데이비드 비앙코의 고통의 피라미드(Pyramid of Pain)**: 침해 지표를 방어할 때 공격자에게 가해지는 고통의 수준을 나타낸 모델로, 하위의 해시값/IP/도메인은 공격자가 쉽게 변경하지만, 최상위의 **TTP(전술·기술·절차)** 를 무력화할 때 공격자에게 극단적인 타격과 비용을 강제할 수 있음을 정의.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 공격자가 C2 도메인과 파일 해시(IOC)를 수시로 변경하여 **기존 시그니처 보안 장비 탐지 회피** | **Pyramid of Pain 최상위 계층인 MITRE ATT&CK TTP 기반 EDR/XDR 위협 헌팅** 수행 | 도구 변형과 무관한 본질적 공격 행위(PowerShell 악용 등) 100% 탐지 |
| 침해된 시스템의 백도어를 개별 단건 조치하여 **공격자가 잔여 대체 C2 채널로 재잠복하는 실패** | **전사 포렌식 기반 모든 거점 식별 후 일괄 격리하는 동시 축출(Simultaneous Eviction)** 집행 | 공격자의 잔존 재감염 경로 완전 제거 및 침해 재발 0% 달성 |
| 정상 도구(LOLBins) 및 메모리 주입을 악용하여 디스크 흔적 없이 **백신을 우회하는 파일리스 공격** | **PowerShell Script Block 로깅 활성화, AMSI(Antimalware Scan Interface) 연동 강제** | 메모리 상에서 실행되는 난독화 스크립트 실시간 디코딩 및 악성 실행 차단 |

#### 한줄 요약
- TTP 기반 헌팅으로 IOC 변형을 잡고, 동시 축출로 재침투를 막으며, AMSI 로깅으로 파일리스를 방어한다.

## Ⅶ. 결론

- 명확한 목적을 가지고 장기간 은닉 체류하는 **APT 공격 대응 아키텍처**는 단편적 경계 차단 중심의 레거시 패러다임에서 벗어나 내부 침해를 가정한 제로 트러스트 및 가시성 중심의 엔드포인트 보안을 요구하며, 실무 구현 시 **MITRE ATT&CK 기반 TTP 위협 모델링**, **EDR 기반 상시 능동 위협 헌팅(Threat Hunting)**, **체계적인 동시 축출(Simultaneous Eviction) 프로세스**를 결합하여 빈틈없는 엔터프라이즈 레질리언스를 완성

#### 한줄 요약
- MITRE ATT&CK TTP 기반 위협 헌팅과 AMSI 연동 및 동시 축출 작전을 통해 APT 장기 은닉 위협을 무력화한다.
