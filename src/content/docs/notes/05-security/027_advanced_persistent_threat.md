## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **APT (Advanced Persistent Threat)**: 특정 표적을 대상으로 고도의 기법과 장기 잠복을 통해 기밀을 탈취하는 지능형 지속 위협.
- **Dwell Time (체류 시간)**: 최초 침투부터 보안팀에 의해 최종 탐지·축출될 때까지 공격자가 내부망에 잠복한 기간.

</details>

- 정의/개념: 장기 은닉하며 기밀을 탈취하는 **지능형 표적 공격**
- 배경/필요성: IOC 시그니처는 **변종·파일리스 행위 탐지 불가**

#### 한줄 요약
- 맞춤형 은닉 침투와 횡적 이동을 차단하기 위해 TTP 기반 위협 헌팅과 동시 축출 작전을 수행한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **LOLBins (Living off the Land Binaries)**: 악성 실행 파일을 직접 유입시키지 않고 OS에 기본 내장된 정상 도구(PowerShell, WMI, Certutil)를 악용하여 백신 탐지를 회피하는 기법.
- **Pyramid of Pain (고통의 피라미드)**: 해시값/IP 등 하위 지표보다 최상위 TTP(전술·기술·절차)를 무력화할 때 공격자에게 극단적 타격을 준다는 보안 모델.

</details>

- **표적 지향성**: 핵심 자산에 **제로데이·맞춤형 도구** 투입
- **LotL 장기 은닉**: PowerShell·WMI로 **시그니처 우회**
- **다단계 침해**: 침투·권한 상승·**횡적 이동·유출** 전개

#### 한줄 요약
- 표적 지향성, 정상 도구(LOLBins) 악용 장기 은닉, 다단계 침해 라이프사이클을 전개한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **Crown Jewels (핵심 자산)**: 공격자의 최종 목표가 되는 전사 ERP 데이터베이스, 소스 코드 저장소, 고객 개인정보 서버.

</details>

```text
[APT 공격·방어 구성]
|-- 초기 침투기      : 교두보 확보
|-- 지속성 모듈      : C2 장기 상주
|-- 자격증명 추출기  : 권한 탈취
|-- LotL 이동기      : 정상 도구 횡적 이동
`-- 위협 헌팅 계층   : 행위 탐지·축출
```

선의 의미: 공격자가 표적 맞춤형 침투 후 내부 지속성을 확립하고 자격증명 탈취와 횡적 이동을 거쳐 핵심 자산에 도달하여 데이터를 유출하는 구조

| 구성요소 | 책임 |
|:---|:---|
| 초기 침투기 | 스피어피싱·취약점으로 **교두보 확보** |
| 지속성 모듈 | 스케줄러·레지스트리에 **C2 상주** |
| 자격증명 추출기 | LSASS·SAM에서 **관리자 권한 탈취** |
| LotL 이동기 | 정상 도구로 **횡적 이동** |
| 위협 헌팅 계층 | EDR 행위 분석과 **동시 축출** |

#### 한줄 요약
- 초기 침투 엔진, 지속성 유지 모듈, 자격증명 추출기, LotL 횡적 이동기, EDR 위협 헌팅 계층이 결합한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Simultaneous Eviction (동시 축출 작전)**: 잔여 백도어로의 재잠복을 방지하기 위해 식별된 모든 C2 채널, 백도어, 침해 계정을 특정 시점에 전사 일괄 차단·초기화하는 절차.

</details>

```text
표적 조직
    |
 1. 초기 침투·거점 확립
    |
 2. 자격증명 탈취
    |
 3. LotL 횡적 이동
    |
 4. 기밀 데이터 유출
    |
 5. 전사 동시 축출
    |
 침해 제거·재구축
```

동작 원리

1. 초기 침투·거점 확립
2. 자격증명 탈취
3. LotL 횡적 이동
4. 기밀 데이터 유출
5. 전사 동시 축출

#### 한줄 요약
- 맞춤형 침투 → 지속성 거점 확립 → 자격증명 탈취 → 정상 도구 횡적 이동 → 데이터 유출 → 동시 축출 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **APT (표적 지속)** vs **기회주의적 공격 (단기 무차별)** vs **내부자 위협 (합법 권한 악용)**.

</details>

| 비교 항목 | 지능형 지속 위협 (APT) | 기회주의적 공격 (Opportunistic) | 내부자 위협 (Insider Threat) |
|:---|:---|:---|:---|
| 공격 표적 | 특정 조직·핵심 자산 | 불특정 다수 | 내부 시스템·데이터 |
| 공격 동기 | 국가 기밀·기술·금융 | 금전 갈취·채굴 | 금전·보복·기술 유출 |
| 사용 기술·도구 | **제로데이·LotL** | 1-Day·자동화 도구 | 정상 권한 악용 |
| 체류 기간 | 수개월~수년 | 수 시간~수일 | 근무 기간 전반 |
| 핵심 방어 전략 | **TTP 위협 헌팅** | 패치·방화벽·AV | **PAM·DLP·UEBA** |

#### 한줄 요약
- APT는 국가/전문 조직의 장기 은닉 표적 공격, 기회주의는 무차별 단기 공격, 내부자는 합법 권한 악용이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **AMSI (Antimalware Scan Interface)**: 윈도우 OS에서 난독화된 PowerShell, VBScript 등이 메모리에서 실행되기 직전에 평문 코드를 백신/EDR에 전달해 검사받게 하는 표준 인터페이스.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 변형 IoC로 **시그니처 탐지 회피** | **ATT&CK TTP 기반 헌팅** | 도구와 무관한 행위 탐지 |
| 단건 조치 후 **대체 C2 재잠복** | **전사 동시 축출** | 잔존 거점과 재감염 제거 |
| LOLBins로 **파일리스 탐지 우회** | **Script Block·AMSI** 연동 | 난독화 스크립트 탐지 |
| 정상 자격증명으로 **횡적 이동** | **PAM·마이크로 분할** | 권한 남용과 이동 차단 |

#### 한줄 요약
- TTP 기반 헌팅으로 IOC 변형을 잡고, 동시 축출로 재침투를 막으며, AMSI 로깅으로 파일리스를 방어한다.

## Ⅶ. 결론

- 변형·LotL은 **TTP 헌팅**, 잔존 거점은 **동시 축출** 적용

#### 한줄 요약
- APT 대응은 MITRE ATT&CK TTP 기반 위협 헌팅과 AMSI 연동 및 동시 축출 작전을 통해 장기 은닉 위협을 무력화하는 능동 방어 체계다.
