## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **양자내성암호(Post-Quantum Cryptography, PQC)**: 대규모 양자컴퓨터 환경에서도 다항식 시간 내에 해독되지 않도록 격자(Lattice), 해시(Hash), 코드(Code), 다변수(Multivariate) 기반의 수학적 난제를 사용하여 설계된 차세대 공개키 암호 알고리즘 체계.
- **쇼어 알고리즘(Shor's Algorithm)**: 양자 중첩과 양자 푸리에 변환(QFT)을 활용하여 소인수분해와 이산대수 문제를 다항식 시간($O((\log N)^3)$) 내에 해결함으로써 기존 RSA 및 ECC(ECDH/ECDSA) 암호체계를 완전히 붕괴시키는 양자 알고리즘.

</details>

- 정의/개념: 양자컴퓨터의 쇼어 알고리즘 공격에 면역성을 갖는 수학적 기반(MLWE 등) 위에서 표준화된 **키 캡슐화(ML-KEM / FIPS 203)** 및 **디지털 전자서명(ML-DSA / FIPS 204, SLH-DSA / FIPS 205)** 을 제공하는 **차세대 공개키 암호 인프라**
- 배경/필요성: '현재 도청 후 미래 양자컴퓨터로 해독'하는 **SNDL(Store Now, Decrypt Later)** 위협으로부터 국가 기밀, 금융 및 의료 데이터를 영구적으로 보호하기 위해 기존 통신망의 선제적 암호 교체 요구

#### 한줄 요약
- 쇼어 알고리즘에 안전한 격자/해시 난제를 채택하여 양자 공격 환경에서도 영구적 기밀성과 인증을 보증한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **SNDL 공격(Store Now, Decrypt Later / HNDL: Harvest Now, Decrypt Later)**: 적대적 행위자가 현재 인터넷에서 오가는 TLS 암호화 트래픽을 대량으로 수집·저장해 두고, 향후 양자컴퓨터가 상용화되었을 때 과거 트래픽의 세션키를 일괄 복호화하여 기밀을 열람하는 위협.
- **기존 인프라 호환성(Software-Only Migration)**: 양자키분배(QKD)와 달리 고가의 전용 광통신 하드웨어가 불필요하며, 기존 인터넷 TCP/IP, TLS 1.3, X.509 PKI 소프트웨어 스택 상에서 알고리즘 교체만으로 즉시 적용 가능.

</details>

- **양자 알고리즘 공격 저항성**: 쇼어 알고리즘(공개키 공격) 및 그로버 알고리즘(대칭키 키 탐색 가속, $2^{128} \rightarrow 2^{64}$)에 대한 수학적 복잡도 보증
- **명확한 기능별 알고리즘 표준화 (KEM vs Signature)**: 키 교환을 위한 KEM(FIPS 203)과 신원 증명을 위한 전자서명(FIPS 204/205)으로 분리 제정
- **암호 민첩성(Crypto Agility) 필수성**: 특정 PQC 알고리즘에 대한 새로운 수학적 취약점 발견 시 서비스 중단 없이 대체 알고리즘으로 즉시 교체 가능한 설계 요구

#### 한줄 요약
- 양자 저항성 보증, 소프트웨어 기반 쉬운 마이그레이션, KEM/서명 분업화, 암호 민첩성을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **암호 자산 식별표(Cryptographic Bill of Materials, CBOM)**: 시스템, 네트워크 장비, 소스 코드 내에 사용된 모든 암호 알고리즘(RSA, ECC, AES), 키 길이, 인증서 위치 및 만료일을 체계적으로 목록화하여 PQC 전환 우선순위를 결정하는 자산 대장.

</details>

```text
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 1. 엔터프라이즈 PQC 전환 거버넌스 (CBOM & Crypto-Agility) ]            │
│  ├─ CBOM 기반 시스템 전수조사 (기밀 데이터 통신 ➔ 웹/앱 인증 순)          │
│  └─ 암호 민첩성 인터페이스: 알고리즘 교체 시 비즈니스 로직 무수정 보장  │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │
                 ┌───────────────────┴───────────────────┐
                 ▼ (키 교환 영역)                        ▼ (디지털 서명 및 인증 영역)
┌──────────────────────────────────────┐┌──────────────────────────────────────┐
│ [ ML-KEM (Module-Lattice KEM) ]      ││ [ ML-DSA / SLH-DSA (디지털 전자서명) ]│
│  ├─ NIST FIPS 203 (Kyber) 표준       ││  ├─ ML-DSA (FIPS 204: Dilithium 격자) │
│  ├─ 용도: TLS 1.3 하이브리드 키 교환 ││  ├─ SLH-DSA (FIPS 205: SPHINCS+ 해시) │
│  └─ SNDL 도청 위협 원천 차단         ││  └─ X.509 인증서 및 코드 서명 위변조 방지│
└──────────────────────────────────────┘└──────────────────────────────────────┘
```

선의 의미: CBOM 분석을 통해 암호 민첩성 정책을 수립하고, 키 교환(ML-KEM)과 전자서명(ML-DSA/SLH-DSA)으로 영역을 나누어 PQC 전환을 수행하는 구조

| 구성요소 | 핵심 책임 및 역할 | 비고 |
|:---|:---|:---|
| **암호 자산 대장 (CBOM)** | 인프라 전역의 레거시 공개키(RSA/ECC) 현황, 의존성, 위험도 목록화 | CycloneDX CBOM |
| **암호 민첩성 (Agility)** | 설정 변경 및 모듈 교체만으로 신규 PQC 알고리즘을 즉시 적용하는 구조 | RFC 9180 HPKE |
| **ML-KEM (FIPS 203)** | 모듈 격자(MLWE) 난제를 기반으로 256비트 대칭 세션키를 캡슐화하여 교환 | NIST FIPS 203 |
| **ML-DSA (FIPS 204)** | 모듈 격자 난제를 기반으로 초고속 전자서명 및 검증을 제공하는 표준 서명 | NIST FIPS 204 |
| **SLH-DSA (FIPS 205)**| 격자 수학 이론과 무관한 순수 상태 비저장 해시 함수 기반 보수적 백업 서명 | NIST FIPS 205 |

#### 한줄 요약
- CBOM 자산 대장, 암호 민첩성 인터페이스, ML-KEM 키 교환, ML-DSA/SLH-DSA 전자서명이 결합한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **모듈 격자 상의 학습 난제(Module Learning With Errors, MLWE)**: $n$차원 다항식 환(Ring) 상에서 노이즈(오차)가 더해진 연립 일차 방정식을 역산하여 비밀 벡터를 찾아내는 것이 양자컴퓨터로도 계산 불가능하다는 PQC의 핵심 수학적 난제.

</details>

```text
1. 수신자(서버)가 ML-KEM 키 생성 알고리즘으로 격자 공개키($pk$)와 개인키($sk$) 생성 ➔ $pk$를 송신자에게 전달
            │
            ▼
2. 송신자(클라이언트)가 CSPRNG로 공유 비밀($K$)을 생성하고, 서버 공개키($pk$)로 암호화하여 KEM 캡슐($c$) 생성
            │
            ▼
3. 송신자가 KEM 캡슐($c$)을 네트워크를 통해 서버로 전송 (SNDL 도청자가 패킷을 캡처해도 양자 해독 불가)
            │
            ▼
4. 서버가 자신의 격자 개인키($sk$)로 캡슐($c$)을 디캡슐화(Decapsulation)하여 동일한 공유 비밀($K$) 추출
            │
            ▼
5. 양단이 도출된 공유 비밀($K$)을 HKDF에 주입하여 AES-256-GCM 대칭 세션키 생성 ➔ 초고속 양자내성 통신 개시
```

**동작 원리**

1. **격자 키 쌍 생성**: 오차 다항식 $e$를 포함하는 행렬 연산 $A \cdot s + e$를 통해 공개키 생성
2. **KEM 캡슐화**: 난수 벡터 $r$과 오차들을 생성하여 평문 비밀 $K$를 노이즈 속에 매핑
3. **불변 캡슐 전송**: 다항식 격자 구조로 암호화되어 공개 채널 상에서 안전하게 전달
4. **격자 복호화**: 개인키 다항식을 곱하여 노이즈를 상쇄시키고 원본 비밀 $K$를 정확히 복구
5. **대칭 세션 전환**: KEM 완료 즉시 라인 레이트 대칭키 암호화로 전환하여 서비스 가동

#### 한줄 요약
- 격자 키 쌍 생성, KEM 캡슐화 전송, 격자 개인키 디캡슐화, 공유 비밀 복구, 대칭키 통신 전환 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **NIST FIPS PQC 표준 3종 비교**: 키 교환 표준 ML-KEM, 주력 전자서명 ML-DSA, 해시 기반 보수적 서명 SLH-DSA의 비교.

</details>

| NIST 표준 | FIPS 203 (ML-KEM) | FIPS 204 (ML-DSA) | FIPS 205 (SLH-DSA) |
|:---|:---|:---|:---|
| **원천 알고리즘** | **CRYSTALS-Kyber** | **CRYSTALS-Dilithium** | **SPHINCS+** |
| **수학적 난제** | **모듈 격자 (MLWE)** | **모듈 격자 (MLWE/MSIS)** | **상태 비저장 해시 함수 (SHA-256)** |
| **주요 암호 용도** | **비대칭 키 교환 / KEM** | **범용 디지털 전자서명** | **보수적 백업 전자서명** |
| **공개키 크기** | **1,184 바이트 (Kyber768)** | **1,952 바이트 (Dilithium3)** | **64 바이트 (작음)** |
| **암호문/서명 크기** | **1,088 바이트 (작음)** | **3,293 바이트 (중간)** | **17,088 바이트 (매우 큼)** |
| **핵심 장점 및 적용**| **TLS 1.3 고속 키 교환 최적화** | **X.509 인증서, 코드 서명 표준** | **격자 암호 붕괴 시 안전한 최후의 보루** |

#### 한줄 요약
- ML-KEM은 TLS 키 교환용, ML-DSA는 범용 서명용, SLH-DSA는 격자 난제 붕괴에 대비한 해시 기반 백업용이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **PQC 패킷 파편화(Packet Fragmentation)**: PQC 공개키와 서명 크기(수 KB)가 기존 RSA/ECC(수백 바이트) 대비 5~10배 증가하여, 네트워크 MTU(1500바이트)를 초과함으로써 IP 단편화 및 패킷 드롭이 발생하는 현상.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| SNDL(Store Now, Decrypt Later) 공격으로 인한 **장기 보존 기밀 데이터의 미래 일괄 해독 위협** | 통신 기밀 구간에 **X25519와 ML-KEM-768을 결합한 하이브리드 KEM 조기 적용** | 현재 및 미래 양자컴퓨팅 도청 위협에 대한 영구적 데이터 기밀성 확보 |
| PQC 서명/키 크기 증가로 인한 **네트워크 MTU 초과, IP 패킷 단편화 및 연결 지연** | **경량화된 ML-KEM/ML-DSA 우선 채택, TCP MSS 튜닝 및 QUIC(UDP) 전송 최적화** | 패킷 드롭 방지 및 1-RTT 핸드셰이크 지연시간 5ms 이내 방어 |
| 조직 내 레거시 암호 자산 현황 미파악으로 인한 **PQC 전환 지연 및 보안 사각지대 발생** | **자동화된 CBOM 스캐너 도입 및 표준 암호 인터페이스(HPKE/JCA) 추상화** | 암호 자산 가시성 100% 확보 및 무중단 암호 알고리즘 핫스왑(Hot-Swap) 달성 |

#### 한줄 요약
- 하이브리드 KEM으로 SNDL을 방어하고, MSS 튜닝으로 단편화를 방지하며, CBOM/추상화로 전환을 완성한다.

## Ⅶ. 결론

- 양자 컴퓨팅 시대의 도래에 따라 기존 RSA/ECC 기반의 사이버 보안 체계가 근본적으로 재편되는 환경에서 **양자내성암호(PQC) 아키텍처**는 국가 안보와 엔터프라이즈 데이터 보호의 필수 전략이며, 실무 구현 시 **SNDL 위협에 대응하는 ML-KEM 하이브리드 키 교환 선제 도입**, **CBOM 기반 레거시 자산 가시화**, **암호 민첩성(Crypto Agility) 아키텍처 내재화**를 통합 추진하여 완결성 높은 차세대 양자 안전 보안 인프라를 완성

#### 한줄 요약
- NIST 표준 ML-KEM/ML-DSA와 하이브리드 전환 및 CBOM/암호 민첩성을 결합하여 양자 안전 인프라를 실현한다.
