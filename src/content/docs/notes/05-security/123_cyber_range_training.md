## 미리 알고가기

- **사이버 레인지 (Cyber Range)**: 현실적인 시스템을 격리해 공격·방어·복구를 반복 훈련하는 환경
- **디지털 트윈 (Digital Twin)**: 실제 시스템의 구조·상태·동작을 디지털 환경에 대응시킨 모형
- **IaC (Infrastructure as Code)**: 서버·네트워크 설정을 코드로 정의해 훈련 환경을 반복 배포·초기화하는 방식
- **레드팀 (Red Team)**: 공격자 관점에서 방어 취약점과 탐지 공백을 검증하는 역할
- **블루팀 (Blue Team)**: 공격을 탐지·분석·격리하고 서비스를 복구하는 역할
- **퍼플팀 (Purple Team)**: 공격 행위와 방어 증거를 함께 검토해 탐지 공백을 개선하는 협업 방식
- **화이트팀 (White Team)**: 훈련 규칙·안전 경계·상황 주입·평가를 통제하는 역할
- **AAR (After Action Review)**: 훈련 결과와 판단 과정을 되짚어 개선 과제를 정하는 사후 검토
- **CTF (Capture The Flag)**: 제한된 환경에서 보안 문제를 풀어 목표 값을 획득하는 기술 훈련
- **텔레메트리**: 훈련 시스템의 로그·상태·조치 결과를 관측한 데이터



## Ⅰ. 개요

- 정의/개념: 격리 환경의 반복 가능한 공방 훈련
- **배경/필요성**: 운영 피해 없이 공격·대응 재현

### 쉽게 이해하기 (학습용)

- 실제 서비스와 비슷하지만 외부와 격리된 훈련장에서 팀 단위 공격 대응을 반복 연습함

## Ⅱ. 특징

- IT·OT·클라우드 환경과 트래픽을 모사한다.
- IaC와 스냅샷으로 동일한 시나리오를 재배포한다.
- 상황 주입으로 대응 결과를 정밀 측정한다.
- 운영망과 격리하여 유출입 위험을 차단한다.

### 쉽게 이해하기 (학습용)

- 같은 환경과 공격을 되풀이해 팀의 탐지·대응 개선을 비교함

## Ⅲ. 아키텍처 및 구성요소

| 설계 요소 | 설명 |
|:---|:---|
| 거버넌스 | 역량·성공 기준·안전 규칙을 정의함 |
| 상황 주입 | 위협 행위와 업무 상황을 순차 제공함 |
| 인프라 | 네트워크·호스트·서비스를 격리 구성함 |
| 역할 팀 | 공격·방어·통제 역할을 분담함 |
| 관측·평가 | 로그·조치 이력으로 성과를 산정함 |

### 쉽게 이해하기 (학습용)

- 훈련장은 서버만 복제하는 것이 아니라 역할, 공격 상황, 관측 장치와 평가 기준까지 함께 설계해야 함

```text
             [화이트팀 통제 계층]
       규칙·상황 주입·안전 중단·평가
                       |
[IaC·스냅샷·합성 데이터] -- 배포 --> [격리된 레인지 환경]
                                      +-- [대상] IT·OT·클라우드
                                      +-- [레드팀] 공격 역할
                                      +-- [블루팀] 방어 역할
                                      +-- [텔레메트리] 로그·상태·조치
                                      +-- [안전 경계] 통신 제한·초기화
```

## Ⅳ. 원리 및 절차 흐름도

```text
분석
 ↓
설계
 ↓
구축
 ↓
훈련
 ↓
개선
```

| 절차 | 설명 |
|:---|:---|
| 요구 분석 | 역량·서비스·지표를 정함 |
| 설계 | 시나리오·안전 규칙을 구성함 |
| 구축 | IaC로 환경 배포 및 검증함 |
| 훈련 | 공방 및 업무 상황을 진행함 |
| 사후 개선 | 원인 분석 후 도구 보완함 |

### 쉽게 이해하기 (학습용)

- 먼저 무엇을 훈련할지 정한 뒤 환경을 만들고, 결과를 실제 대응 절차 개선으로 연결해야 함

## Ⅴ. 종류 및 비교

| 비교축 | 도상 훈련 | CTF | 사이버 레인지 |
|:---|:---|:---|:---|
| 핵심 특징 | 토론으로 역할·절차 확인 | 제한 환경에서 기술 문제 해결 | 운영 환경을 모사해 팀 대응 실행 |
| 적용 기준 | 계획·연락망을 빠르게 확인할 때 | 개인 기술을 집중 훈련할 때 | 협업 탐지·대응·복구를 검증할 때 |
| 주요 위험 | 실제 조작 능력을 검증하지 못함 | 전체 사고 대응 맥락이 빠짐 | 격리 실패·구축 비용·평가 왜곡 |

> 요약: 공방 및 대응 역량 향상 훈련 체계임

### 쉽게 이해하기 (학습용)

- 도상 훈련은 말로 절차를 확인하고, CTF는 문제를 풀며, 사이버 레인지는 팀 단위 대응을 실행함

## Ⅵ. 실무 사례

1. 랜섬웨어 대응 훈련을 격리된 사이버 레인지에서 합성 데이터로 수행하고, 탐지·격리·복구 시간을 측정하여 플레이북을 개선한다.

### 쉽게 이해하기 (학습용)

- 운영 개인정보 대신 합성·비식별 데이터로 현실적인 훈련을 구성함
- 외부 통신을 제한하고 훈련 뒤 환경을 초기화해 공격 도구 유출을 막음
- 탐지·대응·복구 시간을 실제 절차 개선으로 연결함

## Ⅶ. 결론

- 실제 시스템의 운영 위험 없이 사고 대응 역량을 높이기 위해 훈련 목표·위협 시나리오·격리 수준·데이터 안전성·평가 지표를 검토하여, 재현 가능한 사이버 레인지 훈련 결과를 플레이북 개선에 활용해야 한다.

### 쉽게 이해하기 (학습용)

- 훈련장의 규모보다 같은 공격을 다시 실행해 팀의 대응 개선을 확인할 수 있어야 함
