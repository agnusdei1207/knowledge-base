## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **사이버 킬체인(Cyber Kill Chain)**: 록히드 마틴(Lockheed Martin)이 군사적 타격 연쇄(Kill Chain) 개념을 사이버 보안에 이식하여, 공격자가 표적 침투부터 최종 목적을 완수하기까지 반드시 거쳐야 하는 7단계의 순차적 공격 사슬을 정의하고, **어느 한 단계에서라도 연결고리를 선제 차단(Kill)하면 전체 사이버 침해를 완벽히 무력화**할 수 있도록 설계한 방어 모델.
- **다중 차단 기회(Multiple Intercept Opportunities)**: 공격자는 목적 달성을 위해 7개 단계를 모두 성공시켜야 하지만, 방어자는 7번의 기회 중 단 1단계만 차단에 성공해도 방어에 성공한다는 비대칭적 방어 우위 원리.

</details>

- 정의/개념: 침해사고 과정을 **정찰 $\rightarrow$ 무기화 $\rightarrow$ 전달 $\rightarrow$ 익스플로잇 $\rightarrow$ 설치 $\rightarrow$ C2 $\rightarrow$ 목적달성** 의 7단계로 구조화하고, 각 단계별로 **6D 방어 전술(Detect, Deny, Disrupt, Degrade, Deceive, Destroy)** 을 매핑하여 선제 차단하는 **계층형 능동 방어 프레임워크**
- 배경/필요성: 단일 방화벽이나 안티바이러스 등 포인트 솔루션 중심의 단편적 경계 방어가 실패했을 때, 내부망으로 확산되는 지능형 APT 공격을 다단계 관점에서 추적하고 차단할 통합 분석 체계 요구

#### 한줄 요약
- 7단계 공격 연결고리 중 단 1개 지점을 선제 차단하여 공격자의 최종 목적 달성을 원천 무력화한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **6D 방어 작전 전술(6D Defensive Actions)**:
  1. **탐지(Detect)**: 공격 징후를 조기에 식별
  2. **거부(Deny)**: 취약점 접근 및 전달을 거부
  3. **중단(Disrupt)**: 악성 페이로드 실행 및 C2 통신을 중단
  4. **저하(Degrade)**: 공격자의 명령 수행 효율을 저하시킴
  5. **기만(Deceive)**: 허니팟 등 가짜 환경으로 유인
  6. **파괴(Destroy)**: 공격자 거점 및 인프라를 물리/논리적으로 소멸

</details>

- **선형 프로세스 기반 가시화**: 공격자의 연속적 침투 흐름을 표준 7단계 파이프라인으로 분해하여 체계적 통제점 수립
- **비대칭 방어 우위 확보**: 7개 단계 중 단 하나의 연결고리만 끊어내도 공격자의 투자 비용을 무용지물화
- **MITRE ATT&CK과의 상호보완성**: 킬체인의 거시적 7단계 선형 흐름에 MITRE ATT&CK의 미시적 14개 비선형 TTP를 결합하여 입체적 방어망 구축

#### 한줄 요약
- 7단계 선형 프로세스 가시화, 단일 단계 차단 기반 방어 성공, 6D 전술 및 ATT&CK 결합을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **킬체인 7단계 공격 파이프라인**:
  1. **정찰(Reconnaissance)**: 표적 시스템 포트 스캔, 임직원 SNS 이메일 수집
  2. **무기화(Weaponization)**: 취약점 익스플로잇 코드와 원격 백도어를 결합한 악성 문서(PDF/DOC) 제작
  3. **전달(Delivery)**: 스피어피싱 이메일, 웹 드라이브바이 다운로드를 통해 무기 전송
  4. **익스플로잇(Exploitation)**: 사용자 클릭 시 소프트웨어 취약점을 트리거하여 악성 코드 실행
  5. **설치(Installation)**: 시스템 재부팅 후에도 지속 동작하도록 백도어/웹쉘 설치
  6. **명령제어(Command and Control, C2)**: 외부 공격자 제어 서버와 양방향 암호화 통신 채널 수립
  7. **목적달성(Actions on Objectives)**: 데이터베이스 기밀 탈취, 데이터 암호화, 시스템 물리 파괴

</details>

```text
[ 사이버 킬체인 7단계 공격 연결고리 (Lockheed Martin 7-Step Model) ]

1. 정찰 (Recon)  ──▶ 2. 무기화 (Weapon) ──▶ 3. 전달 (Deliver) ──▶ 4. 악용 (Exploit)
         │                   │                     │                    │
         ▼                   ▼                     ▼                    ▼
   [ TI 오시트 차단 ]  [ 제로트러스트 정책 ]  [ 이메일 격리 (RBI) ]  [ EDR 메모리 보호 ]
                                                                        │
┌───────────────────────────────────────────────────────────────────────┘
│
▼
5. 설치 (Install) ──▶ 6. 명령제어 (C2) ──▶ 7. 목적달성 (Actions on Objectives)
         │                     │                          │
         ▼                     ▼                          ▼
   [ AMSI / AppLocker ]  [ NGFW DNS 차단 ]          [ DLP / 불변 백업 (WORM) ]
```

선의 의미: 공격자가 1단계부터 7단계까지 연속적으로 전진할 때, 각 단계별로 배치된 전용 방어 솔루션이 개입하여 연결 사슬을 절단하는 구조

| 킬체인 단계 | 공격자 활동 메커니즘 | 방어 통제 기술 및 대책 (6D) | 주요 적용 솔루션 |
|:---|:---|:---|:---|
| **1. 정찰 (Recon)** | Shodan, OSINT, 링크드인 기반 표적 정보 수집 | 외부 노출 자산 최소화, 허니팟 정보 기만(Deceive) | EASM, Threat Intel |
| **2. 무기화 (Weapon)** | 취약점 익스플로잇과 백도어를 결합한 악성 페이로드 빌드 | 취약점 조기 패치, 보안 패치 거버넌스 | Vulnerability Scanner|
| **3. 전달 (Deliver)** | 스피어피싱 이메일, 피싱 링크, 공급망 채널 전송 | 이메일 격리(RBI), 이메일 보안 게이트웨이(Deny) | SEG, WAF |
| **4. 악용 (Exploit)** | 악성 매크로, 버퍼 오버플로우를 통한 임의 코드 실행 | EDR 메모리 익스플로잇 방어, 가상 패치(Disrupt) | EDR, Host IPS |
| **5. 설치 (Install)** | 레지스트리 런키, WMI 이벤트 구독을 통한 백도어 설치 | 응용프로그램 허용목록(AppLocker), AMSI 스캔 | Application Control |
| **6. 명령제어 (C2)** | 외부 C2 서버와 DNS 터널링 및 암호화 채널 수립 | 차세대 방화벽 C2 차단, DNS Sinkholing(Disrupt) | NGFW, DNS Firewall |
| **7. 목적달성 (Action)**| 데이터베이스 덤프 탈취, 랜섬웨어 파일 암호화 파괴 | 엔드포인트 DLP 차단, 불변 백업(WORM) 복원 | DLP, Immutable Backup|

#### 한줄 요약
- 정찰부터 목적달성에 이르는 7단계 파이프라인과 각 단계별 6D 방어 통제 솔루션이 결합한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **DNS 싱크홀(DNS Sinkholing)**: 내부 감염 단말이 C2 도메인으로 DNS 쿼리를 요청할 때, DNS 방화벽이 실제 C2 IP 대신 보안 분석용 가짜 싱크홀 IP를 반환하여 C2 연결을 안전하게 차단하고 감염 호스트를 특정하는 기술.

</details>

```text
1. [정찰/무기화] 공격자가 인사팀 직원의 메일 주소를 수집하고 악성 매크로가 삽입된 이력서 DOCX 제작
            │
            ▼
2. [전달 단계] 이메일 게이트웨이(SEG) 인입 ➔ [방어 성공: 샌드박스 악성 매크로 탐지 및 첨부파일 격리 (Deny)]
            │
            ├─ [전달 통과 시]
            ▼
3. [익스플로잇] 직원이 문서 실행 ➔ [방어 성공: EDR Exploit Guard가 의심스러운 자식 프로세스 생성 차단 (Disrupt)]
            │
            ├─ [익스플로잇 통과 시]
            ▼
4. [설치 단계] 시스템 백도어 등록 시도 ➔ [방어 성공: AppLocker 정책에 의해 미인가 바이너리 실행 차단 (Deny)]
            │
            ├─ [설치 통과 시]
            ▼
5. [C2 통신] 외부 C2 서버로 세션 연결 시도 ➔ [방어 성공: NGFW DNS Sinkhole 가동으로 C2 차단 (Disrupt)]
            │
            ├─ [C2 통신 성공 시 최종 방어선]
            ▼
6. [목적달성] 대량 파일 암호화/유출 시도 ➔ [방어 성공: DLP 유출 차단 및 EDR 안티랜섬웨어가 볼륨 복원 (Destroy)]
```

**동작 원리**

1. **사전 유입 차단**: 경계 이메일 필터링을 통해 1차 전달 단계 무력화
2. **실행 격리 제어**: 엔드포인트 커널 및 런타임 제어를 통해 코드 실행 단계 차단
3. **영속성 차단**: 관리자 권한 없는 일반 사용자 권한 통제로 백도어 등록 실패 유도
4. **외부 통신 봉쇄**: 침해 발생 후에도 C2 네트워크를 차단하여 지령 수신 불능화
5. **데이터 유출/파괴 방어**: 내부 핵심 DB의 DLP 정책 및 스토리지 불변성으로 최종 손실 방지

#### 한줄 요약
- 이메일 격리(전달), EDR 방어(익스플로잇), AppLocker(설치), DNS Sinkhole(C2), DLP(목적달성) 순으로 다중 차단한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **사이버 위협 분석 3대 모델 비교**: 사이버 킬체인(선형 프로세스), MITRE ATT&CK(비선형 TTP 매트릭스), 다이아몬드 모델(관계 중심 분석)의 비교.

</details>

| 비교 항목 | 사이버 킬체인 (Cyber Kill Chain) | MITRE ATT&CK 매트릭스 | 다이아몬드 모델 (Diamond Model) |
|:---|:---|:---|:---|
| **개발 기관** | **록히드 마틴 (Lockheed Martin)** | **MITRE 코퍼레이션** | Sergio Caltagirone 등 |
| **모델 구조** | **7단계 순차적 선형(Linear) 파이프라인**| **14개 전술, 수백 개 세부 TTP 매트릭스**| **4개 핵심 축 (공격자, 인프라, 역량, 피해자)**|
| **분석 관점** | **공격의 시간적 진행 단계 및 차단점** | **실제 사용된 세부 기술 행위 및 탐지** | **공격 요소 간의 관계성 및 캠페인 추적** |
| **최대 강점** | **직관적인 단계별 다중 차단 전략 수립** | **선형 모델의 한계를 극복한 비선형 매핑** | 공격 그룹의 인프라 상관관계 및 배후 식별 |
| **적용 영역** | **경계 방어선 구축, SOC 6D 대응 전략** | **EDR/SIEM 탐지 룰셋, 위협 헌팅 고도화**| **사이버 위협 인텔리전스(CTI) 캠페인 분석** |

#### 한줄 요약
- 킬체인은 거시적 7단계 차단점 식별, MITRE ATT&CK은 미시적 세부 기술 분석, 다이아몬드는 위협 관계성 추적에 특화된다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **비선형 공격(Non-Linear Attacks)에 대한 킬체인의 한계**: 내부 직원의 자격증명을 사전에 탈취한 공격자가 정찰/무기화/전달/익스플로잇 단계를 모두 생략하고 VPN을 통해 곧바로 내부망 C2 및 목적달성 단계로 진입하는 현대 공격 패턴.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 경계 방화벽 1개에만 의존하다 1차 침투 허용 시 **내부 확산 및 데이터 전면 탈취로 이어지는 단일 방어 실패** | **킬체인 7단계 전 구간에 6D 방어 솔루션을 겹겹이 배치하는 심층 방어 체계** 수립 | 전방 방어 실패 시에도 후속 단계(설치/C2)에서 공격 연결고리 100% 절단 |
| 정상 VPN 계정 탈취로 정찰/전달 단계를 건너뛰고 **내부망으로 직결 침투하는 비선형 공격 사각지대** | **비선형 TTP를 전수 분석하는 MITRE ATT&CK 프레임워크 연동 및 내부 EDR 헌팅** | 정형화된 7단계 순서를 벗어난 내부 횡적 이동 및 권한 상승 위협 완벽 식별 |
| 단계별 보안 장비 도입 후 실제 공격 발생 시 **솔루션 간 연동 부재로 인한 차단 실패** | **사이버 킬체인 기반 레드팀 모의훈련(Red Teaming) 및 SOAR 자동화 플레이북** 구축 | 단계별 차단 실효성 100% 검증 및 보안 이벤트 탐지-차단 자동화 완성 |

#### 한줄 요약
- 7단계 심층 배치로 단일 실패를 방지하고, ATT&CK 연동으로 비선형을 막으며, 레드팀 훈련으로 실효성을 검증한다.

## Ⅶ. 결론

- 지능화된 다단계 사이버 공격을 방어하기 위한 **사이버 킬체인(Cyber Kill Chain) 아키텍처**는 단편적 경계 방어의 한계를 극복하고 공격자의 침투 흐름 전체를 가시화하는 핵심 기반 프레임워크이며, 실무 구현 시 **7단계별 다중 차단 통제(6D) 배치**, **MITRE ATT&CK 매트릭스와의 상호보완적 결합**, **SOAR 기반 실시간 킬체인 차단 자동화**를 통합 추진하여 단 한 번의 차단으로 완전한 방어 우위를 확보하는 능동 보안 체계를 완성

#### 한줄 요약
- 7단계 공격 사슬과 6D 전술 및 MITRE ATT&CK을 결합하여 다단계 침투 공격을 완벽히 무력화한다.
