## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **Cyber Kill Chain (사이버 킬체인)**: 록히드 마틴이 제안한 7단계 공격 사슬로, 어느 한 단계만 차단해도 전체 공격을 무력화할 수 있는 모델.
- **Multiple Intercept Opportunities (다중 차단 기회)**: 공격자는 7단계를 모두 성공해야 하지만 방어자는 1단계만 차단해도 성공한다는 비대칭 우위 원리.

</details>

- 정의/개념: 침해 사고 과정을 정찰부터 목적 달성까지 7단계의 사슬로 모델링하고 **각 단계마다 6D 전술로 연결고리를 차단하는 선형 침해 방어 프레임워크**
- 배경/필요성: 단일 경계 방화벽 1차 붕괴 시의 **후속 내부 침투 및 권한 상승에 대한 가시성 부재, 단계별 방어 통제점 미비로 인한 전사 침해 확산**

#### 한줄 요약
- 7단계 공격 사슬 중 단 1개의 연결고리를 선제 차단하여 전체 사이버 침해를 무력화한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **6D 방어 전술**: Detect(탐지), Deny(거부), Disrupt(중단), Degrade(저하시킴), Deceive(기만), Destroy(파괴)로 구성된 방어 대응 프레임워크.

</details>

- **방어자 비대칭 우위(Defender's Advantage)**: 공격자의 7단계 중 **단 1개 단계만 성공적으로 차단해도 공격자의 최종 목표 달성 원천 봉쇄**
- **단계별 방어 통제점(6D 전술) 매핑**: 정찰부터 유출까지 **각 단계에 맞는 방어 솔루션(SEG, EDR, NGFW, DLP) 정밀 배치**
- **사후 침해 사고(IR) 분석 표준화**: 침해 발생 시 **공격자가 현재 도달한 킬체인 단계를 즉시 식별하고 잔여 공격 경로 선제 봉쇄**

#### 한줄 요약
- 방어자 비대칭 우위, 단계별 6D 전술 매핑, 체계적 침해사고 분석을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **C2 (Command and Control)**: 내부 침투에 성공한 악성코드가 외부 공격자 서버와 은밀한 통신 채널을 수립하여 지령을 수신하는 단계.

</details>

```text
[록히드 마틴 사이버 킬체인 7단계 및 대응 솔루션 매핑]
|-- 1. Reconnaissance (정찰: OSINT, Shodan) ──▶ [ 외부 노출면 관리 EASM / CTI ]
`-- 2. Weaponization (무기화: 악성 페이로드 제작) ──▶ [ 취약점 조기 패치 관리 ]
`-- 3. Delivery (전달: 스피어피싱 이메일) ──▶ [ 이메일 보안 게이트웨이 SEG / 격리 ]
`-- 4. Exploitation (악용: 매크로/익스플로잇 실행) ──▶ [ EDR Exploit Guard / 메모리 보호 ]
`-- 5. Installation (설치: C2 백도어 등록) ──▶ [ AppLocker / AMSI 스크립트 검사 ]
`-- 6. Command & Control (명령제어: C2 통신) ──▶ [ 차세대 방화벽 NGFW / DNS Sinkhole ]
`-- 7. Actions on Objectives (목적달성: 데이터 유출/파괴) ──▶ [ 엔드포인트 DLP / 불변 백업 WORM ]
```

선의 의미: 공격자가 1단계부터 7단계까지 순차 전진할 때 각 단계별로 배치된 전용 방어 솔루션이 개입하여 연결 사슬을 절단하는 구조

| 킬체인 단계 | 공격자 활동 메커니즘 | 방어 통제 기술 및 대책 (6D) | 주요 적용 솔루션 |
|:---|:---|:---|:---|
| **1. 정찰 (Recon)** | Shodan, OSINT 기반 표적 자산 정보 수집 | **외부 노출 자산 최소화, 허니팟 기만(Deceive)** | EASM, Threat Intel |
| **2. 무기화 (Weapon)** | 취약점 익스플로잇과 백도어 결합 페이로드 제작 | **취약점 조기 패치, 가상 패치 거버넌스** | Vulnerability Scan |
| **3. 전달 (Deliver)** | 스피어피싱 메일, 악성 첨부파일 전송 | **이메일 격리(RBI), 이메일 게이트웨이(Deny)** | SEG, WAF |
| **4. 악용 (Exploit)** | 악성 매크로, 메모리 오버플로우 코드 실행 | **EDR 메모리 익스플로잇 방어(Disrupt)** | EDR, Host IPS |
| **5. 설치 (Install)** | 레지스트리 런키, WMI 이벤트 백도어 설치 | **응용프로그램 허용목록(AppLocker), AMSI** | Application Control |
| **6. 명령제어 (C2)** | 외부 C2 서버와 DNS 터널링 통신 수립 | **차세대 방화벽 C2 차단, DNS Sinkhole** | NGFW, DNS Firewall |
| **7. 목적달성 (Action)**| 데이터베이스 덤프 탈취, 랜섬웨어 파일 암호화 | **엔드포인트 DLP 차단, 불변 백업(WORM) 복원** | DLP, Immutable Backup|

#### 한줄 요약
- 정찰부터 목적달성에 이르는 7단계 파이프라인과 각 단계별 6D 방어 통제 솔루션이 결합한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **DNS Sinkholing**: 내부 감염 단말이 C2 도메인으로 DNS 질의 시 가짜 싱크홀 IP를 응답하여 C2 연결을 안전하게 차단하고 감염 호스트를 식별하는 기술.

</details>

```text
킬체인 단계별 공격 전개 및 방어 통제 개입 파이프라인
        │
   1. [정찰/무기화] 공격자가 메일 주소를 수집하고 악성 매크로가 삽입된 이력서 DOCX 제작
        │
   2. [전달 단계] 이메일 게이트웨이(SEG) 인입 ➔ [방어: 샌드박스 매크로 탐지 및 첨부 격리 (Deny)]
        │
   ├─ [전달 통과 시]
   ▼
3. [익스플로잇] 직원이 문서 실행 ➔ [방어: EDR Exploit Guard가 의심스러운 자식 프로세스 차단 (Disrupt)]
        │
   ├─ [익스플로잇 통과 시]
   ▼
4. [설치 단계] 시스템 백도어 등록 시도 ➔ [방어: AppLocker 정책으로 미인가 바이너리 실행 차단 (Deny)]
        │
   ├─ [설치 통과 시]
   ▼
5. [C2 통신] 외부 C2 연결 시도 ➔ [방어: NGFW DNS Sinkhole 가동으로 C2 통신 차단 (Disrupt)]
        │
   ├─ [C2 통신 성공 시 최종 방어선]
   ▼
6. [목적달성] 대량 파일 암호화/유출 시도 ➔ [방어: DLP 유출 차단 및 EDR 안티랜섬웨어 볼륨 복원 (Destroy)]
```

#### 한줄 요약
- 이메일 격리(전달) → EDR 방어(익스플로잇) → AppLocker(설치) → DNS Sinkhole(C2) → DLP(목적달성) 순으로 다중 차단한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **사이버 킬체인 (선형)** vs **MITRE ATT&CK (비선형 매트릭스)** vs **다이아몬드 모델 (관계 중심)**.

</details>

| 비교 항목 | 사이버 킬체인 (Cyber Kill Chain) | MITRE ATT&CK 매트릭스 | 다이아몬드 모델 (Diamond Model) |
|:---|:---|:---|:---|
| **개발 기관** | **록히드 마틴 (Lockheed Martin)** | **MITRE 코퍼레이션** | Sergio Caltagirone 등 |
| **모델 구조** | **7단계 순차적 선형(Linear) 파이프라인**| **14개 전술, 수백 개 세부 TTP 매트릭스**| **4개 핵심 축 (공격자, 인프라, 역량, 피해자)**|
| **분석 관점** | **공격의 시간적 진행 단계 및 차단점** | **실제 사용된 세부 기술 행위 및 탐지** | **공격 요소 간의 관계성 및 캠페인 추적** |
| **최대 강점** | **직관적인 단계별 다중 차단 전략 수립** | **선형 모델의 한계를 극복한 비선형 매핑** | 공격 그룹의 인프라 상관관계 및 배후 식별 |
| **적용 영역** | **경계 방어선 구축, SOC 6D 대응 전략** | **EDR/SIEM 탐지 룰셋, 위협 헌팅 고도화**| **사이버 위협 인텔리전스(CTI) 캠페인 분석** |

#### 한줄 요약
- 킬체인은 거시적 7단계 차단점 식별, MITRE ATT&CK은 미시적 세부 기술 분석, 다이아몬드는 위협 관계성 추적에 특화된다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Non-Linear Attack (비선형 공격)**: 탈취된 VPN 자격증명으로 정찰/무기화 단계를 건너뛰고 내부 C2 및 목적달성 단계로 직행하는 현대의 변칙 공격 패턴.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 경계 방화벽 1차 침투 허용 시 **내부 확산 및 데이터 전면 탈취로 이어지는 단일 실패** | **킬체인 7단계 전 구간에 `6D 방어 솔루션을 겹겹이 배치하는 심층 방어`** 수립 | 전방 방어 실패 시에도 후속 단계(설치/C2)에서 공격 사슬 절단 |
| 정상 VPN 계정 탈취로 앞 단계를 건너뛰고 **직결 침투하는 비선형 공격 사각지대** | **비선형 TTP를 전수 분석하는 `MITRE ATT&CK 프레임워크 연동 및 내부 EDR 헌팅`** | 7단계 순서를 벗어난 내부 횡적 이동 및 권한 상승 위협 식별 |
| 단계별 보안 장비 도입 후 실제 공격 발생 시 **솔루션 간 연동 부재로 인한 차단 실패** | **사이버 킬체인 기반 `레드팀 모의훈련 및 SOAR 자동화 플레이북`** 구축 | 단계별 차단 실효성 검증 및 탐지-차단 자동화 완성 |
| C2 통신 시 정상 DNS/HTTPS 트래픽으로 위장하는 프로토콜 은닉 | **`DNS 방화벽 싱크홀 및 SSL 가시성 장비` 기반 L7 DPI 전수 검사** | 은닉된 C2 채널 100% 탐지 및 명령 수신 불능화 |

#### 한줄 요약
- 7단계 심층 배치로 단일 실패를 방지하고, ATT&CK 연동으로 비선형을 막으며, 레드팀 훈련으로 실효성을 검증한다.

## Ⅶ. 결론

- 지능화된 다단계 사이버 공격을 방어하기 위한 **사이버 킬체인(Cyber Kill Chain) 아키텍처는 단편적 경계 방어의 한계를 극복하고 공격자의 침투 흐름 전체를 가시화하는 핵심 기반 프레임워크**이며, 실무 구현 시 **7단계별 다중 차단 통제(6D) 배치, MITRE ATT&CK 매트릭스와의 상호보완적 결합, SOAR 기반 실시간 킬체인 차단 자동화**를 통합 추진하여 단 한 번의 차단으로 완전한 방어 우위를 확보하는 능동 보안 체계 완성

#### 한줄 요약
- 사이버 킬체인은 7단계 공격 사슬과 6D 전술 및 MITRE ATT&CK을 결합하여 다단계 침투 공격을 완벽히 무력화하는 방어 프레임워크다.
