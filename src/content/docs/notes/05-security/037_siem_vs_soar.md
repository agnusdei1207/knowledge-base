## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **보안 정보•이벤트 관리(Security Information and Event Management, SIEM)**: 로그를 상관분석하여 경보와 조사 근거를 생성하는 플랫폼이다.
- **보안 오케스트레이션•자동화•대응(Security Orchestration, Automation and Response, SOAR)**: 보안 도구를 연계하여 조사•승인•조치를 수행하는 플랫폼이다.

</details>

- 정의/개념: **SIEM**의 탐지•분석과 **SOAR**의 조사•조치를 연결한 관제 구조이다.
- 배경/필요성: 탐지•조치 시스템이 분리되면 사건 인계와 대응이 지연된다.

#### 한줄 요약
- SIEM이 위협을 찾으면 SOAR가 조치를 자동 실행하는 것이 핵심이다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **사건 ID**: SIEM 경보와 SOAR 대응 기록을 동일 사건으로 연결하는 고유 값이다.
- **폐쇄 루프**: 조치 결과를 탐지 규칙에 되돌려 다음 경보 판단을 개선하는 순환이다.

</details>

- **SIEM**은 로그 상관분석으로 경보를 생성한다.
- **SOAR**는 정보를 보강하고 플레이북을 실행한다.
- **사건 ID**로 조치 결과를 **폐쇄 루프**에 환류한다.

#### 한줄 요약
- 운영 규칙으로 역할 및 판정 주체를 정해야 한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **인계 계약**: 사건 ID•증거•위험도•대상 필드를 SIEM과 SOAR가 일관되게 주고받도록 정의한 계약이다.
- **엔드포인트 탐지•대응(Endpoint Detection and Response, EDR)**: 침해 단말의 격리를 집행하는 기술이다.
- **신원 제공자(Identity Provider, IdP)**: 계정 잠금과 세션 회수를 집행하는 시스템이다.

</details>

```text
SIEM•SOAR 연계 구조
├─ SIEM 수집•상관
├─ 인계 계약
├─ SOAR 보강•조치
├─ EDR•IdP
└─ 결과 환류
```

가지의 의미: 탐지•인계•조치•집행과 결과 환류의 정적 책임 구성을 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| SIEM 수집•상관 | **SIEM**이 원본 로그 기반 경보•조사 근거 생성 |
| 인계 계약 | **인계 계약**으로 사건 ID•증거•위험도 전달 보장 |
| SOAR 보강•조치 | **SOAR**가 사건 승인•외부 조치•복구 수행 |
| EDR•IdP | **EDR**•**IdP**가 단말 격리•계정 세션 회수 집행 |
| 결과 환류 | **폐쇄 루프**로 탐지 규칙 개선 |


#### 한줄 요약

- 경보 번호와 대응 티켓이 연결돼야 무엇을 왜 막았고 결과가 어땠는지 다시 추적할 수 있다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **실행 증적**: 요청 성공 응답뿐 아니라 실제 격리•차단•복구 상태까지 기록한 결과이다.
- **최소 권한 응용 프로그래밍 인터페이스(Application Programming Interface, API)**: 승인된 대상과 조치 범위만 호출하게 하는 통제이다.
- **로그 상관•위험도 산정**: 원본 증거와 자산 문맥으로 경보의 위험도와 우선순위를 계산하는 단계이다.
- **현재 상태•위협 보강**: 대상 시스템의 현재 상태와 위협 정보를 추가 조회하는 단계이다.
- **승인•정책 분기**: 업무 영향•가역성에 따라 수동 또는 자동 실행을 선택하는 단계이다.
- **격리•차단•복구 실행**: 승인된 대상에 최소 권한으로 보안 조치를 수행하는 단계이다.
- **실행 증적•상태 검증**: 대상의 실제 상태와 조치 결과를 확인하여 사건 기록에 남기는 단계이다.

</details>

```text
원본 로그 유입
        │
        ▼
1. 로그 상관•위험도 산정
        └─ 사건 ID•탐지 근거 인계
                │
                ▼
2. 현재 상태•위협 보강
        │
        ▼
3. 승인•정책 분기
        ├─ 거부•고위험 ── 수동 대응
        └─ 승인•자동 실행
                │
                ▼
4. 격리•차단•복구 실행
        │
        ▼
5. 실행 증적•상태 검증
        ├─ 실패 ── 재시도•롤백
        └─ 성공 ── SIEM에 검증 결과 환류
```

### 동작 원리

1. **로그 상관•위험도 산정**: 원본 증거와 자산 맥락으로 경보를 판별한다.
2. **현재 상태•위협 보강**: 대상 상태와 위협 정보 추가를 조회한다.
3. **승인•정책 분기**: 업무 영향•가역성에 따라 실행 방식을 선택한다.
4. **격리•차단•복구 실행**: **최소 권한 응용 프로그래밍 인터페이스(API)**로 승인 조치를 수행한다.
5. **실행 증적•상태 검증**: **실행 증적**으로 실제 결과와 사건 기록을 갱신한다.


#### 한줄 요약

- 화면 연동만 보지 말고 검증 경보가 실제 격리와 확인과 복구까지 이어지는지 검증해야 한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **탐지 근거**: 원본 로그와 상관 조건으로 SIEM의 경보 판정을 재현하는 증적이다.
- **대응 수행**: 승인된 플레이북에 따라 SOAR가 외부 보안 도구의 조치를 실행하는 책임이다.

</details>

| 보안 관제 플랫폼 | SIEM | SOAR |
|:---|:---|:---|
| 적용 기준 | **탐지 근거** 필요 시 | 자동 대응 필요 시 |
| 핵심 특징 | **SIEM**의 로그 상관•경보 생성 | **SOAR**의 **대응 수행** |
| 한계 | 로그 품질 저하•오탐 | 오탐 자동화•권한 집중 |

> 요약: SIEM은 탐지 근거, SOAR는 대응 수행하는 것이 핵심이다.

#### 한줄 요약

- 감지기의 판단이 틀리면 자동 대응이 더 빨리 틀리므로 두 시스템의 품질은 앞뒤로 연결되는 것이 핵심이다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **미국 국립표준기술연구소(National Institute of Standards and Technology, NIST)**: 미국의 기술 표준과 지침을 개발하는 기관이다.
- **특별 간행물(Special Publication, SP) 800-92**: 전사 로그 수집•보존•분석 절차를 제시하는 지침이다.
- **구조화 정보 표준 발전 기구(Organization for the Advancement of Structured Information Standards, OASIS)**: 개방형 정보 표준을 개발하는 조직이다.
- **자동화된 행동 과정 협업(Collaborative Automated Course of Action Operations, CACAO) 2.0**: 자동 대응 플레이북의 구조•워크플로•명령을 정의한 표준이다.
- **EDR 격리**: 단말 탐지•대응 시스템이 침해 단말의 네트워크 통신을 제한하는 조치이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 로그 품질•추적성 | **NIST** **SP 800-92** 적용 | 경보 근거 신뢰성 확보 |
| 플레이북 이식성 | **OASIS** **CACAO 2.0** 적용 | 대응 절차 상호운용 확보 |
| 오탐 자동 조치 | **사건 ID**•승인•**폐쇄 루프** 환류 | 오조치 확산•책임 공백 방지 |

#### 한줄 요약

- SIEM이 단말의 악성 행위를 로그 연계로 탐지하면 SOAR가 현재 상태를 확인하고 **EDR 격리**를 실행한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **운영 추적성**: 탐지 근거와 승인•조치•복구 결과가 하나의 사건 기록에 남을 때 확보되는 성질이다.

</details>

- **운영 추적성**을 위해 탐지•증거는 **SIEM**, 조사•조치는 **SOAR**가 담당하고 **사건 ID**로 결과 **폐쇄 루프**를 연결한다.

#### 한줄 요약

- 탐지 근거와 조치 결과가 한 사건에 남아야 한다.
