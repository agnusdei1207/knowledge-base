## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **악성코드 정보 공유 플랫폼(Malware Information Sharing Platform, MISP)**: 위협 사건•지표•관측을 상관분석하고 조직 간 공유하는 플랫폼이다.
- **사이버 위협 인텔리전스(Cyber Threat Intelligence, CTI)**: 위협 데이터에 공격자•전술•신뢰도•영향 맥락을 부여한 정보이다.

</details>

- 정의/개념: **MISP**는 **CTI** 사건•지표•관측을 상관 분석하고 권한별로 공유하는 플랫폼이다.
- 배경/필요성: 단순 지표 목록만으로는 사건 맥락과 공유 권한을 관리할 수 없다.

#### 한줄 요약

- 여러 사건 지표 연결 및 조직 간 공유 플랫폼이 핵심이다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **분류체계(Taxonomy)**: 취급 등급•신뢰 수준을 태그로 부여하는 체계이다.
- **갤럭시(Galaxy)**: 위협 행위자•기법•산업군 문맥을 제공하는 지식 묶음이다.
- **관측(Sighting)**: 공유 지표의 실제 탐지 여부와 오탐 결과를 기록한 정보이다.

</details>

- 이벤트를 기반으로 사건•지표 맥락을 통합한다.
- **분류체계**와 **갤럭시**를 기반으로 위협을 분류한다.
- 상관분석과 **관측**으로 적중•오탐을 추적한다.

#### 한줄 요약

- 지표 의미 부여를 위한 관측 검증 필요가 핵심이다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **이벤트**: 사건 맥락과 관련 속성•객체를 하나의 분석 단위로 묶은 분석 단위이다.
- **공유그룹**: 위협 정보를 조회•재배포할 수 있는 허용 조직을 지정한 권한 집합이다.
- **응용 프로그래밍 인터페이스(Application Programming Interface, API)**: MISP와 외부 시스템의 자동 조회•등록 연동 규격이다.

</details>

```text
MISP 플랫폼 구조
├─ 이벤트•분석
│  ├─ 속성•객체
│  ├─ 분류•갤럭시
│  └─ 상관•관측
└─ 공유 정책
```

가지의 의미: 이벤트의 분석 정보와 이를 통제하는 공유 정책의 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 이벤트•분석 | **이벤트**로 사건 맥락•분석 자료 통합 |
| 속성•객체 | 구조화 지표•관측 정보 표현 |
| 분류•갤럭시 | **분류체계**•**갤럭시**로 문맥•취급 태그 부여 |
| 상관•관측 | **관측**으로 지표 적중•오탐 확인 |
| 공유 정책 | **API**•**공유그룹** 동기화 통제 |


#### 한줄 요약

- 공유 지표의 권한 및 근거 통합을 관리한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **경고목록(Warninglist)**: 정상 서비스 주소처럼 위협 지표로 오인하기 쉬운 값을 관리해 오탐을 줄이는 목록이다.
- **트래픽 라이트 프로토콜(Traffic Light Protocol, TLP)**: 위협 정보의 재배포 범위를 색상 등급으로 표시하는 공유 규칙이다.
- **분류•갤럭시 보강**: 사건에 위협 문맥•취급 태그를 추가하는 단계이다.
- **경고목록•상관•관측 검증**: 정상 주소•중복•오탐•신뢰도를 확인하는 단계이다.
- **TLP•공유그룹 게시**: 재배포 경계와 허용 조직을 적용해 사건을 배포하는 단계이다.
- **지표 품질 재평가**: 적중•오탐 관측으로 지표 상태•신뢰도•공유 범위를 갱신하는 단계이다.

</details>

```text
사건•속성 등록
        │
        ▼
1. 분류•갤럭시 보강
        │
        ▼
2. 경고목록•상관•관측 검증
        ├─ 정상•중복 ── 게시 제외
        └─ 유효 지표
                │
                ▼
3. TLP•공유그룹 게시
        └─ 허용 조직에만 배포
                │
                ▼
API 적중•오탐 관측 등록
        │
        ▼
4. 지표 품질 재평가
        └─ 상태•신뢰도•공유 범위 갱신
```

### 동작 원리

1. **분류•갤럭시 보강**: 위협 문맥•취급 태그를 사건에 추가한다.
2. **경고목록•상관•관측 검증**: **경고목록**과 **관측**으로 정상 주소•중복•오탐•신뢰도를 확인한다.
3. **TLP•공유그룹 게시**: **TLP**와 **공유그룹**으로 재배포 경계와 허용 대상을 적용한다.
4. **지표 품질 재평가**: 적중•오탐 관측을 바탕으로 상태를 갱신한다.


#### 한줄 요약

- 공유 전 실제 관측 및 정상 주소 대조가 핵심이다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **구조화 위협 정보 표현(Structured Threat Information eXpression, STIX)**: 위협 객체•관계를 기계 판독 형식으로 표현하는 표준이다.
- **신뢰 정보 자동 교환(Trusted Automated eXchange of Intelligence Information, TAXII)**: STIX 정보를 서버 간 자동 교환하는 전송 규약이다.

</details>

| 위협 정보 공유 | 문서 공유 | STIX/TAXII | MISP |
|:---|:---|:---|:---|
| 적용 기준 | 소규모 비정형 정보 전달 | 기관 간 표준 자동 교환 | 분석•권한•동기화 통합 |
| 핵심 특징 | 사람이 읽는 지표•설명 | **STIX**•**TAXII**의 표준 객체•자동 교환 | **MISP**의 사건•상관•관측 운영 |
| 한계 | 수동 파싱•갱신 누락 | 형식만으로 품질 보장 불가 | 태그•권한 오류 확산 |

> 요약: MISP는 분석•상관 기반 공유 플랫폼이 핵심이다.

#### 한줄 요약

- 플랫폼 운영을 통한 검토 및 권한을 관리한다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **사고 대응•보안 팀 포럼(Forum of Incident Response and Security Teams, FIRST)**: 사고 대응 조직의 국제 협력체이다.
- **FIRST TLP 2.0**: RED•AMBER•GREEN•CLEAR로 공유 경계를 표시하는 규칙이다.
- **구조화 정보 표준 발전 기구(Organization for the Advancement of Structured Information Standards, OASIS)**: 개방형 정보 표준을 개발하는 조직이다.
- **OASIS STIX 2.1**: 위협 객체와 관계의 기계 판독 형식을 규정한 표준이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 공유 경계 표시 | **FIRST** **TLP 2.0** 적용 | 재배포 범위 명확화 |
| 외부 객체 교환 | **OASIS** **STIX 2.1** 변환 | CTI 상호운용성 확보 |
| 정상 지표 오탐 | **경고목록**•**관측** 검증 | 오차단•품질 저하 억제 |
| 플랫폼 간 동기화 | **API**•**TAXII** 권한 검증 | 무단 조회•게시 차단 |

#### 한줄 요약

- 분석가는 랜섬웨어의 파일 해시•도메인•공격자 정보를 하나의 MISP 이벤트로 묶고 허가된 관계 기관에만 공유한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **운영 품질**: 지표 수보다 사건 맥락•관측 결과•공유 권한을 정확히 연결하고 갱신하는 능력으로 결정되는 품질 기준이다.

</details>

- **운영 품질**을 유지하면서 사건•관측•권한 운영은 **MISP**, 기관 간 자동 교환은 **STIX**•**TAXII**를 연계한다.

#### 한줄 요약

- 믿을 지표를 연결하고 순환시키는 체계이다.
