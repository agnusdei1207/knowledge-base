## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **MITRE ATT&CK**: 공격자의 전술·기법을 행렬로 체계화한 지식베이스.
- **탐지 커버리지(Detection Coverage)**: ATT&CK 기법 중 탐지 가능한 범위를 나타내는 보안 지표.

</details>

- 정의/개념: 공격자 **TTP** 분류로 탐지·대응을 검증하는 지식베이스
- 배경/필요성: 공격자가 파일 해시나 C2 IP 등 하위 침해지표(IoC)를 실시간 변조할 경우 전통적인 시그니처 매칭 기반 탐지가 무력화되며, 보안 벤더마다 위협 명칭과 분석 체계가 파편화되어 전사 방어 역량의 사각지대를 객관적으로 정량화하지 못하는 한계에 직면함에 따라, 실제 사이버 침해사고에서 관측된 공격자의 전술(Tactics: Why), 기법(Techniques: How), 서브기법(Sub-techniques) 및 절차를 14개 전술 매트릭스로 체계화한 MITRE ATT&CK 지식베이스를 도입하여 **공격자 TTP(전술·기술·절차) 중심의 공통 보안 언어 표준화, ATT&CK Navigator 기반 탐지 커버리지 정량 평가 및 적대적 모의실행(Adversary Emulation)을 통한 실효성 검증**을 달성할 필요

#### 한줄 요약
- 공격자 행동(TTP) 매트릭스를 기반으로 보안 탐지 룰을 개발하고 적대적 모의실행으로 검증한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **Tactics vs Techniques**: 공격자가 달성하려는 전술적 목표(Why)와 이를 실행하는 구체적인 기술 수단(How).
- **Adversary Emulation (적대적 모의실행)**: 실제 공격자 그룹(APT)의 TTP 스크립트를 방어 시스템에서 직접 실행하여 탐지 및 차단 동작을 실증하는 검증.

</details>

- 도구 변경에도 유지되는 **TTP** 중심 공격 행위 표준화
- ATT&CK Navigator의 **탐지 커버리지** 기반 투자 우선순위 가시화
- **적대적 모의실행** 기반 SIEM·EDR 탐지 규칙의 실효성 검증

#### 한줄 요약
- 커버리지가 지표가 되는 순간 채우기 쉬운 저위험 기법부터 메우려는 유인이 생기므로, 이 프레임워크의 실효성은 몇 개를 덮었는가가 아니라 표적 위협의 기법을 덮었는가로만 확인된다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **Data Sources (데이터 소스)**: 특정 공격 기법(T-ID)을 탐지하기 위해 반드시 수집해야 하는 엔드포인트/네트워크 원시 이벤트 로그.

</details>

```text
[ATT&CK 지식베이스]
|
+-- [도메인]
|   `-- [전술]
|       `-- [기법]
|           `-- [서브기법]
|
+-- [데이터 소스]
`-- [완화책]
```

선의 의미: 가지는 분류 계층과 지식베이스의 포함 관계

| 구성요소 | 책임 |
|:---|:---|
| **도메인** | Enterprise·Mobile·ICS 매트릭스 구분 |
| **전술** | 공격자가 달성하려는 목적 분류 |
| **기법·서브기법** | 전술을 수행하는 행위와 구현 방식 식별 |
| **데이터 소스** | 기법 탐지에 필요한 원시 이벤트 지정 |
| **완화책** | 공격 기법의 실행 가능성 제한 |

#### 한줄 요약
- 데이터 소스는 기법과 탐지 룰 사이에 놓여 "이 기법을 잡으려면 어떤 로그가 먼저 있어야 하는가"를 지정하므로, 로그 수집 범위가 곧 커버리지의 상한이 되어 룰 개발보다 앞서는 투자 대상이 된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Atomic Red Team**: 수백 개의 MITRE ATT&CK 기법을 1:1로 테스트할 수 있도록 설계된 오픈소스 독립 모의 공격 프레임워크.

</details>

```text
[위협 정보]
     |
     v
1. T-ID 우선순위화
     |
     v
2. 데이터 소스 수집
     |
     v
3. 탐지 규칙 개발
     |
     v
4. 적대적 모의실행
     |
     +-- 경보 미발생 -- 데이터·규칙 보완 --+
     |                                      |
     +------------- 재검증 <---------------+
     |
     `-- 경보 발생 --> [커버리지 등록]
```

- 1. T-ID 우선순위화: 표적 공격 그룹의 핵심 기법 선정
- 2. 데이터 소스 수집: T-ID별 필수 이벤트 확보
- 3. 탐지 규칙 개발: SIEM·EDR 행위 상관 규칙 구현
- 4. 적대적 모의실행: 공격 스크립트로 경보 발생 검증

#### 한줄 요약
- 경보 미발생 갈래가 규칙 보완이 아니라 데이터 소스 보완으로도 되돌아간다는 점이 핵심이어서, 룰을 아무리 다듬어도 원시 로그가 없으면 그 기법은 영원히 커버리지에 오르지 못한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **Enterprise Matrix**: 기업 IT와 클라우드에서 관측된 기법을 담아 EDR·인증 로그로 대부분을 관측할 수 있는 대신, 범위가 넓어 조직이 T-ID를 직접 선별해야 하는 도메인.
- **Mobile Matrix**: Android·iOS 기기의 기법을 다루며, OS가 앱 간 관측을 제한하는 탓에 탐지 근거를 MDM과 앱 권한 로그로 한정해야 하는 도메인.
- **ICS Matrix**: 산업제어시스템의 제어 명령 조작과 안전계장시스템 무력화를 다루며, 가용성 우선 환경이라 모의실행으로 검증하는 것 자체가 제약되는 도메인.

</details>

| 도메인 영역 | Enterprise Matrix (기업 IT/Cloud) | Mobile Matrix (스마트폰) | ICS Matrix (산업제어시스템) |
|:---|:---|:---|:---|
| 적용 대상 | 기업 IT·클라우드 | Android·iOS | 산업제어시스템 |
| 핵심 위협 | **권한 상승**·횡적 이동 | **기기 접근**·네트워크 도청 | **제어 명령 조작**·SIS 무력화 |
| 탐지 데이터 | **EDR**·인증·API 로그 | **MDM**·앱 권한 로그 | **산업 프로토콜** 패킷 |
| 한계 | 플랫폼 범위가 넓어 선별 필요 | 기기별 관측 권한 제약 | 가용성 제약으로 모의실행 제한 |

#### 한줄 요약
- Enterprise는 기업 IT/클라우드, Mobile은 스마트폰 OS, ICS는 제조/발전 산업제어망에 특화된다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Observation Bias (관찰 편향)**: 단순 룰(whoami 등)만 대량 등록하여 매트릭스를 인위적으로 채우고 실제 고위험 TTP 탐지 검증을 누락하는 보안 운영 오류.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 룰 배포 후에도 실제 공격 경보 미발생 | **적대적 모의실행** 상시 검증 | 탐지 규칙의 실효성과 공백 확인 |
| 매트릭스 채우기식 저위험 룰 양산 | **CTI** 기반 TTP 우선순위화 | 핵심 공격 경로에 검증 자원 집중 |
| 도구별 공격 명칭 파편화로 협업 지연 | 인시던트에 **T-ID** 태깅 | 분석·대응 용어의 일관성 확보 |
| 정상 관리 도구 행위의 오탐 증가 | 부모·자식 프로세스 **상관분석** | 정상 업무와 공격 행위 구분 |

#### 한줄 요약
- 모의실행으로 룰 실효성을 검증하고, CTI로 TTP 우선순위를 정하며, T-ID 표준화로 대응 속도를 극대화한다.

## Ⅶ. 결론

- 공격자의 정적 지표가 아닌 실제 공격 행위(TTP)를 체계적으로 분류하고 방어 체계의 탐지 공백을 정량적으로 진단할 수 있게 한 **현대 사이버 보안 운영(SecOps), 위협 헌팅, SOC 관제 및 침해사고 분석의 글로벌 사실상 표준 지식베이스(De Facto Standard)**로 확고히 정립되었으며, 클라우드·컨테이너 및 AI 매트릭스(ATLAS) 확장으로 진화하는 가운데, 실무 ATT&CK 프레임워크 활용 시에는 **자사 위협 프로파일에 부합하는 CTI 기반 핵심 T-ID(공격 기법) 선별 및 필수 데이터 소스(Sysmon/EDR 로그) 인프라 완비, 단순 매트릭스 채우기식 관찰 편향을 탈피하여 실제 탐지 룰의 동작을 검증하는 적대적 모의실행(Atomic Red Team/BAS) 자동화, SIEM/SOAR 및 XDR의 인시던트 티켓에 T-ID 태깅을 강제하는 통합 관제 거버넌스**를 결합하여 완벽한 TTP 기반 능동 방어 생태계를 완성

#### 한줄 요약
- MITRE ATT&CK은 전술(Why)과 기법(How)의 매트릭스 분류 및 모의실행 검증을 통해 TTP 기반 능동 보안 커버리지를 완성하는 핵심 지식베이스다.
