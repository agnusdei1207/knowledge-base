## Ⅰ. 개요

<details>
<summary>용어 설명</summary>

- **디지털 포렌식**: 디지털 데이터를 적법하게 식별•수집•보존•분석해 사실관계를 밝히는 조사 절차이다.

</details>

- 정의/개념: 전자 매체 증거를 적법하게 식별•획득•보존•분석하고 재현 가능한 결과로 보고하는 **디지털 포렌식**이다.
- 배경/필요성: 원본 직접 분석•취급 기록 누락 시 무결성과 연계보관성을 입증할 수 없다.

#### 한줄 요약

- 누가 어떤 방법으로 증거를 다뤘는지 남겨 조사 결과를 다시 확인할 수 있게 한다.

## Ⅱ. 특징

<details>
<summary>용어 설명</summary>

- **휘발성 정보**: 전원 차단이나 시간 경과로 사라지는 메모리•프로세스•연결 정보이다.
- **원본 보존**: 원본 변경을 막고 검증된 사본으로 분석하는 증거 처리 원칙이다.
- **적법성**: 조사 권한•범위•최소 수집의 법적 근거를 충족한 상태이다.
- **획득 순서**: 휘발성과 상태 변경 가능성을 고려해 증거 수집의 선후를 정한 절차이다.
- **재현성**: 다른 분석자가 동일 자료와 절차로 같은 결과를 얻을 수 있는 성질이다.

</details>

- 조사 권한•범위•최소 수집의 **적법성**이 핵심이다.
- **휘발성 정보**와 상태 변경 가능성에 따른 **획득 순서**가 핵심이다.
- **원본 보존**과 사본 분석의 **재현성**이 핵심이다.

#### 한줄 요약

- 전원을 끄면 사라질 정보와 수집 중 바뀔 상태를 비교해 증거 획득 순서를 정한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>용어 설명</summary>

- **연계보관성(Chain of Custody)**: 증거의 수집•인수•처리•인계를 연속 기록해 신뢰성을 보장하는 원칙이다.
- **해시값**: 원본과 사본의 동일성과 획득 후 무결성을 검사하는 고정 길이 값이다.

</details>

```text
디지털 포렌식 증거 구조
├─ 조사 권한 · 범위
│  └─ 근거 · 대상 · 기간 · 최소 수집
├─ 원본 · 잠재적 증거
│  └─ 쓰기 차단 · 원래 상태
├─ 포렌식 이미지 · 해시
│  └─ 비트 복제 · 동일성 검증
├─ 검증된 분석 환경
│  └─ 추출 · 검색 · 교차 분석
└─ 연계보관 · 분석 이력
   └─ 접근 · 인계 · 도구 · 명령
```

| 구성요소 | 책임 |
|:---|:---|
| 조사 권한•범위 | 조사 근거•대상•기간•최소 수집 한계 |
| 원본•잠재적 증거 | 원래 상태의 **원본 보존** |
| 포렌식 이미지•해시 | 비트 복제 후 **해시값** 검증 |
| 검증된 분석 환경 | 추출•검색•교차 분석 수행 |
| 연계보관•분석 이력 | **연계보관성**을 위한 접근•인계 기록 |

#### 한줄 요약

- 원본은 봉인하고 검증된 사본만 분석하며 모든 접근과 인계를 기록한다.

## Ⅳ. 흐름도

<details>
<summary>용어 설명</summary>

- **증거 취급 기록**: 증거의 상태•담당자•시간•작업 내용을 단계마다 남긴 기록이다.
- **조사 권한•범위 확인**: 증거 수집의 근거•대상•기간•도구 제한을 확인하는 단계이다.
- **증거 식별•현장 상태 기록**: 장치•연결•시각•휘발성 상태를 식별하고 기록하는 단계이다.
- **쓰기 차단•비트 복제•해시 봉인**: 원본 쓰기를 막고 전체 사본과 해시값을 확보하는 단계이다.
- **원본 보관•분석 사본 생성**: 원본을 봉인하고 검증된 분석용 사본을 만드는 단계이다.
- **분석 재현•파생 증거 기록**: 도구•명령•산출물과 분석 이력을 보존하는 단계이다.

</details>

```text
조사 승인 · 제한 조건
          │
          ▼
1. 조사 권한•범위 확인
          │
          ▼
2. 증거 식별•현장 상태 기록
          │
          ▼
3. 쓰기 차단•비트 복제•해시 봉인
          │
          ▼
4. 원본 보관•분석 사본 생성
          │
          ▼
5. 분석 재현•파생 증거 기록
          │
          ▼
    재현 결과 · 한계 보고

모든 단계: 담당자 · 시각 · 작업 · 인계 기록
```

### 동작 원리

1. **조사 권한·범위 확인**: 근거·대상·도구 제한 확인
2. **증거 식별·현장 상태 기록**: 장치·연결·휘발성 기록
3. **쓰기 차단·비트 복제·해시 봉인**: 무결성 확보
4. **원본 보관·분석 사본 생성**: 사본·인계 기록 생성
5. **분석 재현·파생 증거 기록**: 도구·명령·산출물 보존

#### 한줄 요약

- 다른 분석자가 같은 사본과 기록을 따라 같은 결론에 이르는지 확인한다.

## Ⅴ. 종류 및 비교

<details>
<summary>용어 설명</summary>

- **라이브 포렌식**: 실행 중인 시스템에서 휘발성 정보를 수집하는 방식이다.
- **데드 포렌식**: 전원 차단 후 저장 매체를 복제해 분석하는 방식이다.

</details>

| 포렌식 방식 | 라이브 포렌식 | 데드 포렌식 |
|:---|:---|:---|
| 적용 기준 | 메모리•프로세스•연결 보존 | 파일•메타데이터•삭제 흔적 분석 |
| 핵심 특징 | **라이브 포렌식**으로 실행 상태 수집 | **데드 포렌식**으로 복제본 분석 |
| 한계 | 수집 행위의 시스템 상태 변경 | 종료 과정의 휘발성 정보 소실 |

#### 한줄 요약

- 실행 중 정보가 필요하면 라이브, 원본 변경을 줄이려면 데드 방식을 택한다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>용어 설명</summary>

- **ISO(International Organization for Standardization)**: 국제표준화기구이다.
- **IEC(International Electrotechnical Commission)**: 국제전기기술위원회이다.
- **ISO/IEC 27037**: 디지털 증거의 식별•수집•획득•보존 표준이다.
- **ISO/IEC 27042**: 디지털 증거의 분석•해석 표준이다.
- **미국 국립표준기술연구소(National Institute of Standards and Technology, NIST)**: 미국의 기술 표준 연구기관이다.
- **특별 간행물(Special Publication, SP)**: NIST가 발행하는 전문 지침 문서이다.
- **NIST SP 800-86**: 포렌식 기법을 사고대응에 통합하는 지침이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 증거 취급 절차 | **ISO/IEC 27037** 적용 | 획득•보존 신뢰성 확보 |
| 분석•해석 품질 | **ISO/IEC 27042** 적용 | 재현성•반복성 확보 |
| 사고대응 연계 | **NIST SP 800-86** 참조 | 조사•대응 일관성 확보 |

- **ISO**와 **IEC**의 공동 표준 및 **NIST**의 **SP**를 증거 처리와 사고대응 절차에 반영한다.

#### 한줄 요약

- 침해 서버는 확산 위험과 메모리•네트워크 연결 정보의 소실 가능성을 비교해 초기 조치와 수집 순서를 정하고 모든 취급 이력을 기록한다.

## Ⅶ. 결론

<details>
<summary>용어 설명</summary>

- **무결성**: 수집 이후 증거가 변하지 않았음을 입증하는 조건이다.
- **포렌식 방식 선택**: 휘발성 정보 필요성과 원본 변경 위험에 따라 수집 방식을 정하는 판단이다.

</details>

- **포렌식 방식 선택**에 따라 휘발 정보 필요 시 라이브, 원본 변경 최소화 시 데드를 적용하고 **무결성**과 **연계보관성**을 입증한다.

#### 한줄 요약

- 수집•인계 기록이 끊기면 분석 결과의 신뢰가 약해진다.
