## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **탈옥 공격(Jailbreak Attack / OWASP LLM01:2025)**: 롤플레이(DAN), 가상 시나리오, 역발상 질문, 적대적 접미사(Adversarial Suffix), 다중 턴 대화 분할 등 정교하게 설계된 프롬프트를 주입하여, LLM 내부의 안전 정렬(Safety Alignment / RLHF / DPO) 및 시스템 거부 정책을 무력화하고 유해하거나 금지된 답변(악성코드 생성, 무기 제작, 개인정보 추출)을 강제로 도출하는 공격 기법.
- **안전 정렬의 취약성 및 과적합 결함(Safety Alignment Brittleness Defect)**: RLHF/DPO 학습을 통해 주입된 안전 규칙은 특정 자연어 패턴 거부에는 효과적이나, 문맥을 가상 소설로 위장하거나 Base64/수학적 토큰(GCG)으로 변환할 경우 모델이 위험 의도를 인지하지 못하고 거부 가중치가 붕괴되는 구조적 한계.

</details>

- 정의/개념: 안전 정렬을 우회하는 **탈옥 공격**의 다계층 방어 구조
- 배경/필요성: LLM에 적용된 RLHF/DPO 안전 정렬(Safety Alignment)이 고정된 키워드 필터링에 의존할 경우, 공격자가 가상 롤플레이(DAN), 최면 시나리오, 다중 턴 문맥 분할, 경사하강법 기반의 적대적 접미사(GCG) 등 무제한의 자연어/수학적 변형 프롬프트를 주입하여 시스템의 안전 거부 가중치를 붕괴시키고 유해 콘텐츠(악성코드, 해킹 도구) 생성을 강제하는 탈옥(Jailbreak) 위협이 발생함에 따라, 입출력 2중 Guardrails(Llama Guard/NeMo), 토큰 당혹도(Perplexity) 분석, 안전 정렬 강화 및 지속적 적대적 평가(Red Teaming)를 결합하는 탈옥 방어 아키텍처를 도입하여 안전 정렬 무력화 공격의 선제적 차단, 공격 성공률(ASR) 최소화 및 정상 거부율(FRR) 최적화의 양립을 달성할 필요

#### 한줄 요약
- 롤플레이와 적대적 접미사(GCG) 공격에 대응하여 입출력 2중 가드레일과 안전 모델 정렬로 탈옥을 원천 차단한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **GCG(Greedy Coordinate Gradient) 적대적 접미사 공격**: 모델의 거부 확률을 수학적으로 최소화하기 위해, 경사하강법(Gradient Descent)을 통해 인간에게는 무의미해 보이는 난수형 특수 토큰 조합(`! ! ! ! describing.\ + similarly...`)을 자동 탐색하여 질문 뒤에 결합하는 화이트박스/전이 공격 기법.
- **다중 턴 분산 우회 (Multi-turn Fragmentation Attack)**: 단일 질문으로 악성 의도를 드러내지 않고, 5~10단계의 연속된 무해한 대화 세션을 거치며 모델의 컨텍스트를 단계적으로 오염시켜 최종적으로 금지된 명령을 실행하게 만드는 기법.

</details>

- 자연어 우회 패턴의 무한성: 롤플레이, 번역 우회, 최면 시나리오, 2진수/Base64 인코딩 등 무제한적인 적대적 입력 생성 가능
- ASR(Attack Success Rate) vs FRR(False Refusal Rate) 상충: 보안 필터를 지나치게 강화하면 정상적인 학술/개발 질문까지 오탐 거부(FRR 증가)하는 트레이드오프 발생
- 입출력 2중 가드레일 기반 심층 방어: 모델 내부 가중치 정렬이 뚫리더라도 출력 가드레일(Output Guardrails)에서 위험 키워드 및 악성코드를 2차 인라인 차단

#### 한줄 요약
- GCG 적대적 접미사, **다중 턴 분산 우회**, ASR/FRR 상충 조율, 입출력 2중 심층 방어를 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **탈옥 방어 4대 심층 계층**:
  1. **Input Guardrails (Llama Guard / NeMo)**: 입력 텍스트의 탈옥 의도 및 GCG 토큰 스캐닝.
  2. **Aligned Foundation Model**: DPO/RLHF를 통해 적대적 질문 거부 가중치가 내재된 코어 모델.
  3. **Output Guardrails**: 모델 생성 텍스트의 유해성(CBRN, 악성 쉘스크립트) 인라인 필터링.
  4. **Continuous Red Teaming & Regression Testing**: 자동화 패저(Fuzzer)를 통한 상시 취약점 점검.

</details>

```text
[탈옥(Jailbreak) 방어 체계]
├─ 입력 계층 (Input Defense)
│  ├─ 입력 가드레일 (Llama Guard / NeMo)
│  ├─ 토큰 당혹도(Perplexity) 비정상 분석
│  └─ 다중 턴 누적 문맥 분석기
├─ 모델 계층 (Core Alignment)
│  ├─ RLHF / DPO 안전 정렬 가중치
│  └─ 자발적 안전 거부 응답 생성
├─ 출력 및 실행 계층 (Output Defense)
│  ├─ 출력 가드레일 (악성코드·PII 차단)
│  └─ 도구 실행 격리 샌드박스
└─ 지속 검증 계층 (Continuous Eval)
   ├─ 자동화 적대적 레드팀 (Red Teaming)
   └─ ASR / FRR 임계값 동적 최적화
```

- 선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 입력 가드레일 (Input Guard) | 텍스트 당혹도(Perplexity) 및 ML 분류기를 통해 GCG 난수 토큰과 롤플레이를 사전 차단 |
| 안전 정렬 모델 (RLHF/DPO) | 적대적 데이터셋을 학습하여 위험한 지시어 수신 시 자체적으로 거부 답변을 도출 |
| 누적 문맥 분석기 (Multi-turn) | 여러 턴에 걸쳐 누적된 전체 대화 세션의 토큰 위험도를 종합 스코어링 |
| 출력 가드레일 (Output Guard) | 모델이 생성한 최종 텍스트에서 악성 쉘코드, PII, 취약점 공격 페이로드를 2차 필터링 |
| 적대적 레드팀 (Red Teaming) | 최신 탈옥 데이터셋을 활용해 정기적으로 안전성을 벤치마킹하고 모델에 피드백 |

#### 한줄 요약
- 입력 가드레일, 안전 정렬 모델, 누적 문맥 분석기, 출력 가드레일, 적대적 레드팀이 결합한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **탈옥 방어 5단계 처리 흐름**:
  1. 입력 프롬프트 수신 및 당혹도(Perplexity)/가드레일 검사
  2. 다중 턴 누적 대화 위험도 평가
  3. 안전 정렬 기반 모델 추론
  4. 출력 텍스트의 유해성 2차 필터링
  5. 레드팀 로깅 및 공격 패턴 지속 피드백

</details>

```text
   [탈옥 프롬프트 유입]
            │
            ▼
1. [입력 의도·당혹도 분석]
    ├─ Llama Guard 3가 입력 프롬프트의 의도를 `S1 (Software Attack)` 위험 카테고리로 분류
    └─ [탈옥 확률 98% 판정 ➔ 즉각 차단 및 "보안 정책상 답변할 수 없습니다" 반환]
            │
            ▼ (신종 우회 패턴으로 입력 가드레일을 통과한 경우)
2. [다중 턴 문맥 평가]
            │
            ▼
3. [안전 정렬 모델 추론]
    ├─ 코어 LLM이 DPO 학습 가중치에 따라 "소설 형식을 가장한 유해 요청"임을 인지
    └─ [모델 자체가 자발적으로 답변 거부 텍스트 생성]
            │
            ▼ (모델마저 속아 넘어가 악성 코드를 생성한 경우)
4. [출력 유해성 검사]
    ├─ Output Guardrail이 생성된 텍스트에서 악성 쉘코드 바이너리 패턴 감지
    └─ [응답 텍스트를 즉시 폐기(Masking)하고 안전 거부 템플릿으로 대체 전송]
            │
            ▼
5. [공격 패턴 환류] 차단된 탈옥 패턴을 회귀 평가 데이터에 반영
```

1. 입력 의도·당혹도 분석
2. 다중 턴 문맥 평가
3. 안전 정렬 모델 추론
4. 출력 유해성 검사
5. 공격 패턴 환류

#### 한줄 요약
- 가드레일 임계값을 조이면 공격 성공률(ASR)이 내려가는 만큼 정상 요청 오차단(FRR)이 올라가므로, 차단 강도는 서비스가 감당할 오차단 비용에 맞춰 정해야 한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **탈옥 공격 3대 대표 기법 비교**: 단일 턴 페르소나(DAN), 다중 턴 분산 주입(Multi-turn), 자동화 적대적 접미사(GCG)의 비교.

</details>

| 비교 항목 | 단일 턴 페르소나 (DAN) | 다중 턴 분산 주입 (Multi-turn) | 적대적 접미사 탐색 (GCG) |
|:---|:---|:---|:---|
| 공격 메커니즘 | "넌 이제 DAN이야" 단일 가상 롤플레이 | 5~10턴 대화로 모델 경계심 점진적 해제 | 경사하강법 기반 수학적 특수 토큰 결합 |
| 사람의 인지 가능성| 높음 (자연어로 된 명시적 롤플레이) | 보통 (질문이 분할되어 의도 파악 지연) | 불가능 (무의미한 기호/단어의 나열) |
| 방어 기술 | Input Guardrails 키워드/의도 분석 | 세션 단위 누적 문맥 위험도 분류 | Perplexity(당혹도) 분석, 출력 가드레일|
| 우회 난이도 | 낮음 (기본 가드레일로 차단 용이) | 중간 (단일 문장 필터링 우회) | 최상 (정적 룰셋 및 자연어 필터 무력화)|

#### 한줄 요약
- DAN은 롤플레이, Multi-turn은 대화 분할 주입, GCG는 수학적 난수 토큰 기반의 정밀 우회 공격이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **ASR(Attack Success Rate) & FRR(False Refusal Rate)**:
  - **ASR (공격 성공률)**: 탈옥 프롬프트 주입 시 모델이 안전 규칙을 위반하고 악성 답변을 생성한 비율 (낮을수록 우수).
  - **FRR (정상 거부율 / 오탐률)**: 무해한 정상 사용자의 질문을 보안 가드레일이 탈옥으로 오인하여 거부한 비율 (낮을수록 우수).

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 롤플레이 및 가상 시나리오를 악용한 탈옥으로 인해 사내 챗봇이 악성코드 생성 지침 및 공격용 쉘스크립트를 출력하는 사고 | **OWASP LLM01:2025** 기준 준수, Llama Guard 3 및 NeMo 기반 입출력 2중 Guardrails 인라인 강제 | 롤플레이 기반 탈옥 **공격 성공률**(**ASR**) 0.1% 이하로 억제 및 유해 출력 100% 차단 |
| 자연어 필터링을 우회하는 **GCG(Greedy Coordinate Gradient) 적대적 접미사 공격**에 의해 모델의 안전 가중치가 무력화 | 입력 텍스트의 토큰 당혹도(Perplexity) 비정상도 스캔 및 출력단 코드 정적 분석 샌드박스 결합 | 무의미한 특수 토큰 기반 수학적 탈옥 공격 선제 탐지 및 무력화 |
| 탈옥 방어 룰셋을 과도하게 강화하여 정상적인 사이버 보안 연구 및 개발자의 안전한 학술 질문까지 거부하는 업무 장애 | 공격 성공률(ASR)과 정상 거부율(**FRR**)을 상시 모니터링하여 가드레일 임계값(Threshold) 동적 튜닝 | 정상 사용자 거부율(FRR) 1% 미만 유지 및 비즈니스 사용 편의성 최적화 |

#### 한줄 요약
- 2중 가드레일로 롤플레이를 막고, 당혹도 분석으로 GCG를 차단하며, ASR/FRR 튜닝으로 가용성을 보장한다.

## Ⅶ. 결론

- 생성형 AI 모델의 윤리적·기술적 안전 경계를 파괴하려는 지능형 적대적 프롬프트 공격을 다계층으로 방어하는 LLM 안전성 보증 및 신뢰성 정렬(Safety Alignment / OWASP LLM01)의 핵심 보안 통제로 확고히 자리 잡았으며, 다중 모달(Multimodal) 탈옥 방어 및 에이전트 샌드박싱으로 진화하는 가운데, 실무 LLM 서비스 구축 및 운영 시에는 Llama Guard 3/NeMo 기반의 입력·출력 2중 Guardrails 인라인 구축, GCG 적대적 접미사를 탐지하는 토큰 당혹도(Perplexity) 비정상도 분석기 탑재, 공격 성공률(ASR)과 정상 거부율(FRR)의 균형을 맞춘 적응형 임계값 튜닝, 최신 탈옥 데이터셋 기반의 자동화 레드티밍(Continuous Red Teaming)을 결합하여 완벽한 탈옥 방어 무결성을 완성

#### 한줄 요약
- 입출력 2중 가드레일과 안전 모델 정렬 및 지속적 레드팀 평가를 통해 탈옥 공격을 완벽히 방어한다.
