## 미리 알고가기

- **보안 구성 관리**: [읽기: 보안 구성 관리; 표기 이유: 한국어 통용어 표기] 서버·네트워크·애플리케이션 설정을 보안 기준선에 맞게 유지하는 활동
- **취약점**: [읽기: 취약점; 표기 이유: 한국어 통용어 표기] 과다 포트·기본 계정·약한 암호 등은 침해 경로
- **핵심**: [읽기: 핵심; 표기 이유: 한국어 통용어 표기] 초기 하드닝보다 운영 중 구성 편차의 지속적 관리
- **보안 기준선**: [읽기: 보안 기준선; 표기 이유: 한국어 통용어 표기] 자산 유형·버전·환경별로 승인한 안전한 설정의 기준 상태
- **구성 편차 (Configuration Drift)**: [읽기: 구성 편차; 표기 이유: 한글명 뒤 영문 원어 병기] 실제 설정이 배포·수동 변경으로 승인 기준선과 달라진 상태
- **하드닝**: [읽기: 하드닝; 표기 이유: 한국어 통용어 표기] 불필요한 기능·계정·포트를 제거하고 안전한 설정을 적용하는 활동
- **보상 통제**: [읽기: 보상 통제; 표기 이유: 한국어 통용어 표기] 예외로 원래 설정을 적용하지 못할 때 같은 위험을 낮추는 대체 통제




- **흐름 기호(↓·→·X)**: [읽기: 흐름 기호; 표기 이유: 한글명 뒤 영문 원어 병기] 아래로·다음으로·차단으로 읽으며 순서·분기·금지를 나타냄
## Ⅰ. 개요

- 정의/개념: 기준선과 실제 설정의 편차를 통제함
- **배경/필요성**: 배포·수동 변경은 구성 편차를 만듦

### 쉽게 이해하기 (학습용)

- 안전한 초기 설정뿐 아니라 운영 중 생기는 편차까지 계속 통제한다.

## Ⅱ. 특징

- 기준선은 자산 유형·버전·환경별로 관리한다.
- 실제 상태와 목표 상태의 차이를 계속 탐지한다.
- 정책 코드로 배포 전에 위반 구성을 차단한다.
- 자동 복구 오류는 서비스 장애로 이어질 수 있다.

### 쉽게 이해하기 (학습용)

- 예외에는 담당자·사유·보상 통제·만료일이 필요하다.

## Ⅲ. 구성요소 및 구조

| 구성요소 | 핵심 내용 |
|:---|:---|
| 자산 정보 | 자산 유형·버전·업무별 기준 연결 |
| 버전 기준 | 승인 설정과 변경 이력 관리 |
| 정책 검사 | 배포 전 위반 사항 판정 |
| 편차 탐지 | 운영 상태와 목표 상태 차이 식별 |
| 예외 복구 | 사유·만료·복구 영향 통제 |

```text
기준선
  ├─ 배포 전 검사
  └─ 실행 중 탐지
          ↓
     예외 장부
          ↓
     복구·롤백
```

### 쉽게 이해하기 (학습용)

- 승인 기준선과 실제 상태를 비교해 편차를 복구하거나 예외로 기록한다.

## Ⅳ. 원리 및 절차 흐름도

```text
분류
 ↓
검사
 ↓
탐지
 ↓
복구
```

| 절차 | 설명 |
|:---|:---|
| 자산분류 | 업무·환경·버전별 적용 대상을 식별함 |
| 기준선승인 | 보안 요구와 가용성을 검토해 버전으로 관리함 |
| 배포전검사 | 코드·템플릿의 위반을 변경 전에 차단함 |
| 편차탐지 | 실행 상태와 승인 기준의 차이를 지속 확인함 |
| 복구개선 | 영향 검증 후 복구하고 반복 원인을 기준선에 반영함 |

> 요약: 기준선 승인 후 편차를 탐지·복구함

### 쉽게 이해하기 (학습용)

- 자산별 기준을 승인하고 배포 전 검사와 실행 중 탐지를 함께 운영한다.

## Ⅴ. 종류 및 비교

| 비교축 | 정기 수동 점검 | 배포 전 정책 검사 | 실행 중 편차 탐지 |
|:---|:---|:---|:---|
| 핵심 특징 | 사람이 일정 주기로 설정을 확인 | 코드·템플릿을 배포 전에 검사 | 실제 운영 설정과 기준선 차이를 지속 탐지 |
| 적용 기준 | 자동 수집이 어렵고 현장 판단이 필요할 때 | IaC·CI/CD로 변경을 배포할 때 | 수동·긴급 변경을 빠르게 발견할 때 |
| 주요 위험 | 점검 사이의 편차를 놓침 | 배포 밖 직접 변경을 놓침 | 오탐·자동 복구가 서비스 장애 유발 |

### 쉽게 이해하기 (학습용)

- 배포 검사는 사전 오류를, 실행 탐지는 수동·긴급 변경을 찾는다.

## Ⅵ. 실무 사례

1. 클라우드 저장소의 **공개 설정 드리프트 자동 복구**

### 쉽게 이해하기 (학습용)

- 기준 구성을 벗어나 공개로 변경된 저장소를 탐지하면 승인된 정책 코드로 비공개 상태를 복구하고 변경 이력을 감사한다.

## Ⅶ. 결론

- 보안 구성 관리는 편차·예외·복구를 추적함

### 쉽게 이해하기 (학습용)

- 보안 구성 관리는 편차를 복구하고 승인 예외를 만료시켜야 한다.
