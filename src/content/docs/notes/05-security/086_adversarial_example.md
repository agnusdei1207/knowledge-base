## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **적대적 예제**: 사람에게는 같은 입력처럼 보이지만 모델의 판단 경계를 넘도록 의도적으로 교란한 공격 입력이다.
- **판단 경계**: 입력을 서로 다른 예측 결과로 나누는 모델의 기준으로 경계 주변에서 작은 교란에 취약할 수 있다.

</details>

- 정의/개념: **적대적 예제**는 입력을 교란해 모델 판단 경계를 넘어 오분류시키는 공격 입력이다.
- 배경/필요성: 정상 정확도의 **경계 주변 취약성 누락**이 발생한다.

#### 한줄 요약

- 사람에게는 같은 표지판처럼 보이는 작은 무늬를 더해 모델만 다른 표지판으로 판단하게 만든다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **표적 공격**은 입력을 공격자가 정한 특정 결과로 오분류하게 하는 공격이다.
- **비표적 공격**은 입력을 원래 결과와 다른 임의 결과로 오분류하게 하는 공격이다.
- **전이성**은 한 모델에서 만든 적대적 교란이 다른 모델에서도 작동하는 성질이다.
- **적대적 학습**은 적대적 예제를 학습에 포함해 교란에 대한 강건성을 높이는 기법이다.

</details>

- 표적•비표적의 **오분류 목표 차이**가 핵심이다.
- 대리 모델 전이•반복 질의로 **흑색상자 공격 가능**이 핵심이다.
- 적대적 학습의 **교란 강건성 향상**이 핵심이다.

#### 한줄 요약

- 모델 내부를 알면 기울기로 교란을 만들고 내부를 몰라도 응답이나 대리 모델을 이용해 취약 입력을 찾을 수 있다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **위협 모델**은 공격자의 지식•목표•접근 능력을 고정한 시험 조건이다.
- **섭동 예산**은 공격자가 입력을 바꿀 수 있는 크기•횟수•환경 범위의 한도다.
- **강건 처리기**는 교란 입력을 탐지•거부하거나 안전하게 변환하는 구성요소다.
- **안전 처리기**는 안전 중요 판단이 불확실할 때 다른 센서나 보수적 상태로 전환한다.

</details>

```text
적대적 예제 시험 구조
├─ 시험 조건
│  └─ 위협 모델
├─ 공격 경로
│  ├─ 교란 생성기
│  ├─ 대상 모델
│  └─ 질의 관측점
└─ 방어 경로
   └─ 강건•안전 처리기
```

| 구성요소 | 책임 |
|:---|:---|
| 위협 모델 | **지식•목표•교란 한도** 정의 |
| 교란 생성기 | 제약 내 **공격 입력 최적화** |
| 대상 모델 | 입력의 **예측•행동 출력** |
| 질의 관측점 | **라벨•점수•성공률** 측정 |
| 강건•안전 처리기 | **탐지•거부•대체 판단** |

#### 한줄 요약

- 공격자 지식과 교란 크기를 고정하고 같은 조건에서 모델의 공격 성공률과 방어 후 정상 성능을 비교한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **교란 탐색**은 섭동 예산 안에서 모델의 취약한 입력을 반복 최적화해 찾는 과정이다.
- **환경 재현**은 거리•각도•조명 같은 실제 조건에서도 공격이 유지되는지 시험하는 과정이다.
- **ASR(Attack Success Rate)**은 적대적 입력이 공격 목표를 달성한 비율이다.
- **정상성**은 방어 적용 뒤에도 정상 입력의 업무 성능이 유지되는 정도다.

</details>

```text
목표•섭동 예산
       |
       v
1. 교란 후보 생성
       |
       v
대상 모델 질의 ──> 라벨•점수
       ^                 |
       |   목표 미달     |
       +─────────────────+
       |
       | 공격 성공
       v
2. 환경 변형 재현
       |
       v
3. ASR•정상성 판정
       |
       v
    강건성 결과
```

**동작 원리**

1. **교란 후보 생성**: 섭동 예산 안에서 취약 방향을 탐색한다.
2. **환경 변형 재현**: 거리•각도•조명 조건별 반복을 시험한다.
3. **ASR•정상성 판정**: 공격률•정상 성능 함께 측정한다.


#### 한줄 요약

- 작은 입력 변형을 반복하여 목표 오답을 찾고 거리•각도•조명 변화에서도 공격이 재현되는지 확인한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **백색상자 공격**은 모델의 가중치•구조•기울기 같은 내부 정보를 이용하는 공격이다.
- **흑색상자 공격**은 외부 API 응답과 전이성을 이용해 취약 입력을 탐색하는 공격이다.
- **물리 공격**은 실제 표식•소리•물체로 센서 입력을 교란하는 공격이다.
- **API(Application Programming Interface)**는 서비스 기능과 데이터를 정해진 요청•응답 형식으로 제공하는 경계다.

</details>

| 적대적 예제 유형 | 백색상자 | 흑색상자 | 물리 환경 |
|:---|:---|:---|:---|
| 적용 기준 | **내부 접근 가능 평가** | **API 외부 공격 평가** | **실제 센서 안전 검증** |
| 핵심 특징 | **기울기 기반 최적화** | **응답•전이성 기반 탐색** | **물리 패턴 센서 교란** |
| 한계 | **내부 접근 가정** | **많은 질의 필요** | 환경 변화에 **효과 변동** |

#### 한줄 요약

- 백색상자는 내부 정보, 흑색상자는 응답과 전이성, 물리 공격은 실제 표식이나 소리로 입력을 교란한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **NIST(National Institute of Standards and Technology)**는 미국의 기술 표준과 지침을 개발하는 기관이다.
- **AI(Artificial Intelligence) 100-2e2025**는 적대적 예제를 추론 단계 회피 공격으로 분류한 보고서다.
- **센서 대조**는 모델 판단을 독립 센서•지도 결과와 비교하는 통제다.
- **안전 상태**는 판단 불일치가 크면 시스템이 전환하는 보수적 동작 상태다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **회피 공격 분류 누락** | **NIST AI 100-2e2025 적용** | **지식•역량별 시험 체계화** |
| **모델 교란 강건성 부족** | **적대적 학습•변형별 ASR 평가** | **경계 주변 오분류 감소** |
| **안전 중요 오판** | **센서 대조•거부•안전 상태 전환** | **단일 모델 실패 피해 제한** |

#### 한줄 요약

- 자율주행 카메라는 변형 표지판을 거리•각도•조명별로 시험하고 지도•라이다와 불일치하면 안전 모드로 전환해야 한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **교란 강건성**은 적대적 입력에서도 모델의 정상 판단을 유지하는 능력이다.
- **피해 제한**은 남은 오판이 실제 안전 사고로 이어지지 않게 통제하는 목표다.

</details>

- ASR•안전 영향이 크면 **적대적 학습•센서 대조•안전 전환**을 적용한다.

#### 한줄 요약

- 적대적 예제 방어는 공격률만 낮추는 것이 아니라 정상 성능을 유지하고 오판 시 실제 피해를 안전 통제로 제한하는 것이다.
