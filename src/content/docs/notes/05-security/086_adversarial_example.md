## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **적대적 예제 (Adversarial Example)**: 사람이 안구 시각으로 전혀 식별할 수 없는 미세한 노이즈(Perturbation, $\epsilon$)를 원본 이미지, 오디오, 텍스트 입력 데이터에 수학적으로 주입하여, 머신러닝/딥러닝 모델이 완전히 엉뚱한 정답으로 오판(Misclassification)하도록 강제 유도하는 추론 회피(Evasion) 공격 기법이다.
- **판단 경계 (Decision Boundary)**: 고차원 벡터 특징 공간에서 AI 모델이 개별 클래스를 분류하고 구획하는 수학적 결정 기준 경계면이다.

</details>

- 정의: 육안으로 감지 불가능한 제한된 **섭동(Perturbation)** 을 원본 데이터에 삽입하여, 딥러닝 모델의 오분류를 의도적으로 유발하는 추론 회피 공격이다.
- 배경: 자율주행 차량, 의료 진단 등 안전 필수 AI 시스템이 물리 환경의 미세한 변형에 취약하여 치명적인 **판단 경계** 오인과 인명 사고 위험이 대두되었기 때문이다.

#### 한줄 요약

- 사람이 육안으로 구분하기 힘든 정밀 미세 노이즈를 입력 데이터에 추가하여 딥러닝 모델의 오판을 도출하는 치명적인 추론 회피 공격이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **표적 공격 (Targeted Adversarial Attack)**: 공격자가 의도적으로 지정한 특정한 오판 타깃 클래스(예: 정지 표지판 $\rightarrow$ 100km 속도 제한)로 딥러닝의 판단을 정밀 유도해 내는 공격 기법이다.
- **비표적 공격 (Untargeted Adversarial Attack)**: 특정 타깃 클래스를 고집하지 않고, 단지 원본 정답 클래스만 아니면 다른 어떤 임의의 분류값으로라도 오판을 일으키게 만드는 포괄적 공격 기법이다.
- **전이성 (Transferability Property)**: A라는 대상 모델(대리 모델)을 속이기 위해 생성된 적대적 예제 노이즈가, 구조와 파라미터가 전혀 다른 미지의 B 모델에서도 동일하게 오분류를 일으키는 강력한 파급 특성이다.
- **적대적 학습 (Adversarial Training / PGD Training)**: 모델 훈련 파이프라인 시에 아예 처음부터 적대적 노이즈가 주입된 이미지를 학습 데이터에 지속 조합하여 강제로 학습시킴으로써 노이즈 자체에 대한 내성을 획득하게 만드는 근본 방어 기술이다.

</details>

- **오판 유도 방향성**: 공격 목표에 따라 오분류를 정밀 통제하는 **표적 공격** 및 단순히 정답 회피만을 유도하는 **비표적 공격** 기반 분류되는 특성이 있다.
- **아키텍처 초월 감염성**: 대상 딥러닝 아키텍처(ResNet vs VGG 등)가 서로 달라도 적대적 패치가 유효하게 작동 전파되는 **전이성(Transferability)** 특성을 보유한다.
- **내성 획득 훈련**: 모델의 강건성을 확보하기 위해 PGD(Projected Gradient Descent) 기법 기반의 **적대적 학습** 적용하여 모델의 노이즈 내성을 구조적으로 강화하는 방어 근거를 적용한다.

#### 한줄 요약

- 표적/비표적 공격 방향성, 이종 모델 간 적대적 전이성(Transferability) 및 PGD 기반 적대적 학습을 통한 내성 강화 특성을 지닌다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **위협 모델 (Threat Model)**: 공격자가 보유한 정보 접근 수준(White-box / Black-box)과 노이즈 크기의 물리적 제약을 명확히 정의한 보안 평가 수학적 기준이다.
- **섭동 예산 (Perturbation Budget / Epsilon Constraint $\epsilon$)**: 적대적 패치가 인간 육안으로 지각 불가능하도록 노이즈 크기의 한계치를 수학적으로 제한하는 $l_\infty, l_2$ 임계 값이다.
- **입력 전처리 방어 (Input Preprocessing Defense)**: 입력된 이미지를 딥러닝 추론에 투입하기 직전에 압축, 필터링, 재샘플링 처리하여 적대적 섭동 패턴을 상쇄 무력화시키는 방어 기법이다.
- **안전 상태 전환 (Fail-Safe Fallback)**: 카메라, 라이다 등 다중 센서 간의 AI 판단 불일치가 탐지될 경우 시스템 제어권을 기계적 보수적 안전 모드로 즉시 강제 전환하는 통제 메커니즘이다.

</details>

```text
[적대적 예제 공격 및 강건성 시험 아키텍처]

[1. 위협 모델 정의: White/Black-box 환경 및 섭동 예산 한계 설정]
                             |
                             v
           [2. 적대적 교란 최적화 생성기 (PGD, FGSM)]
                             |
                             | (미세 노이즈 $\epsilon$ 삽입 데이터 투입)
                             v
[3. 입력 전처리 방어 필터링] --> [4. 대상 AI 추론 모델 예측]
                                             |
                                             v
           [5. 다중 센서 대조 및 Fail-Safe 안전 상태 전환 통제]
```

| 구성요소 | 주요 책임 및 역할 | 비고 |
|:---|:---|:---|
| **위협 모델 조건** | 화이트박스/블랙박스 환경을 정의하고 수학적 **섭동 예산**($\epsilon$)의 한계 범위를 제한 | Threat Scope |
| **교란 최적화 생성기** | FGSM, PGD, C&W 최적화 알고리즘을 이용해 모델을 속일 최적의 미세 적대적 노이즈 생성 | Attacker |
| **대상 AI 추론 모델** | 노이즈가 교묘히 섞인 적대적 입력을 받아 딥러닝 분류 및 확률 예측 추론 수행 | Target System |
| **입력 전처리 방어** | 디노이징(Denoising), JPEG 압축 등을 통해 입력 데이터에 묻은 노이즈 섭동을 사전 상쇄 제거 | Preprocessor |
| **다중 센서 및 안전 상태** | 비전 센서 오판 시 LiDAR 등 이종 센서와 **교차 대조**하고 오류 시 Fail-Safe **안전 상태** 기반 전환 통제 | Fallback |

#### 한줄 요약

- 위협 모델(섭동 예산) 제약, 교란 최적화 생성기(PGD 등) 공격 타격, 전처리 노이즈 필터링 방어 및 다중 센서 안전 상태 전환 체계로 구성된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **교란 탐색 (Perturbation Search / FGSM / PGD)**: 비용 손실 함수(Loss Function)의 경사(Gradient)가 가리키는 방향을 따라 픽셀을 미세하게 역산 이동시켜 대상 모델의 오분류를 고의 유도하는 수학적 최적화 과정이다.
- **환경 재현 (Environmental Reproducibility)**: 단순 디지털 픽셀 조작이 아니라, 실제 거리 카메라의 각도, 조명, 비/눈 기상 조건의 물리적 환경 변화 속에서도 아날로그 적대적 패치가 유효하게 작동하는지 시험하는 단계이다.
- **ASR (Attack Success Rate)**: 적대적 예제가 대상 모델의 오분류를 성공적으로 유발해 낸 정밀 공격 적중 확률 지표이다.

</details>

```text
[공격 목표 설정 및 섭동 예산($\epsilon$) 한계치 정의]
              |
              v
1. 수학적 교란 탐색 알고리즘(PGD) 기반 노이즈 후보군 생성
              |
              +<-------------------------------------------------+
              |                                                  |
              v                                                  |
[대상 모델 반복 질의] ──> 2. 오분류 라벨 및 Softmax 점수 반환    |
              |                                                  |
              v (오분류 미달 시 반복)                            |
              +--------------------------------------------------+
              | (공격 성공 타깃 적중)
              v
3. 조명/거리/각도 변화를 반영한 실세계 물리적 환경 변형 오판 재현 철저한 검증
              |
              v
4. 방어 시스템 작동 후 최종 ASR(공격 성공률) 및 정상 정확도(Clean Acc) 2중 판정
              |
              v
[모델 강건성 및 자율주행 안전 취약성 최종 결과 리포트 도출]
```

### 동작 원리

1. 교란 탐색: 제한된 섭동 예산($\epsilon$) 범위 내에서 모델을 속일 최적의 노이즈 픽셀 후보를 생성한다.
2. 피드백 반복: 대상 모델에 질의하며 손실 함수를 계산해 원하는 오판 라벨이 나올 때까지 반복 갱신한다.
3. 물리 환경 재현: 생성된 노이즈를 스티커 등으로 인쇄하여 실제 조명/시야각 변화 환경에서 공격 유효성을 재현 철저한 검증한다.
4. 강건성 판정: 방어 기법이 적용된 모델의 최종 ASR(공격 방어력)과 정상 무해 입력 정확도를 2중 평가한다.

#### 한줄 요약

- 교란 픽셀 탐색 및 생성(PGD), 대상 예측 피드백 반복, 실세계 아날로그 환경 변형 재현 시험 및 최종 ASR/정상성 2중 판정 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **백색상자 공격 (White-box Attack)**: 공격자가 대상 AI 모델의 내부 가중치, 레이어 아키텍처, 역전파 기울기(Gradient) 정보를 100% 투명하게 파악한 상태에서 PGD/C&W 알고리즘으로 가장 치명적인 최적 노이즈를 정밀 계산해 내는 공격이다.
- **흑색상자 공격 (Black-box Attack)**: 대상 모델의 내부 구조를 전혀 알 수 없는 상태에서, API 입력/출력 쿼리 결과만을 관찰해 대리 모델을 학습시킨 후 **전이성(Transferability)** 을 악용해 노이즈를 주입하는 공격이다.
- **물리 환경 공격 (Physical World Attack)**: 단순 디지털 픽셀 조작을 넘어 실제 정지 표지판 위에 특정 스티커 패턴을 붙이거나, 3D 안경 테두리를 제작 착용하여 현실 아날로그 자율주행/안면인식 센서를 속이는 하드웨어 공격이다.

</details>

| 기반 적대적 공격 분류 | **백색상자 공격 (White-box)** | **흑색상자 공격 (Black-box)** | **물리 환경 공격 (Physical Attack)** |
|:---|:---|:---|:---|
| 공격자의 사전 정보 보유 | 모델 내부 가중치, 기울기 수학식 100% 완전 파악 | 내부 접근 불가, 오직 반환되는 **API 응답 확률** 한정 관찰 | 디지털 접근 없이 **카메라 렌즈, 레이더 센서** 아날로그 환경 조작 |
| 주 활용 생성 알고리즘 | FGSM, PGD, 최적화 C&W (Carlini-Wagner) | ZOO 탐색, 대리 모델 생성 후 **전이성(Transferability)** 활용 전파 | AdvHat, Physical Patch (RP2) 등 프린팅 기반 실물 생성 |
| 공격 성공률 및 위협도 | 최고 (수학적 손실 함수를 직접 눈으로 보며 극대화) | 보통~높음 (대리 모델 유사도 및 쿼리 API 차단 여부에 종속) | 보통 (햇빛 조명, 진흙, 시야각 등 통제 불능 환경 변수 존재) |
| 대표적 방어 통제 기술 | 원천적 **적대적 학습** (Adversarial Training) 주입 | 강력한 API 쿼리 Rate Limit 통제, **전처리 디노이징** 방어 | 이종 센서 퓨전 (LiDAR/Radar 연동), 다중 **센서 교차 대조** |

#### 한줄 요약

- 기울기 정보 100% 활용 백색상자, 대리 모델 전이성 우회 흑색상자 및 스티커 패치를 이용한 물리 환경 센서 기만 공격으로 세분화된다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **NIST AI 100-2e2025 (Evasion Attacks)**: 적대적 예제를 AI 추론 단계의 심각한 회피(Evasion) 공격으로 엄격히 규정하고, 이에 대응하는 정량적 강건성 테스트 가이드를 수록한 미국 국립표준기술연구소의 규격이다.
- **센서 대조 (Cross-Sensor Verification / Multi-modal Sensor Fusion)**: 비전 카메라 단일 센서 입력의 맹점에 의존하지 않고 LiDAR, Radar, 초음파, GPS 등 전혀 다른 원리의 이종 센서 데이터를 상호 비교 대조하여 교란을 파악하는 아키텍처 모듈이다.
- **안전 상태 (Fail-Safe State)**: 이종 센서 간 AI 판단 결과의 치명적 불일치가 감지될 때, 자율주행 차량이나 핵심 통제 설비를 즉시 감속시키거나 갓길에 정차시키는 최우선 기계적 제어 상태이다.

</details>

| 장애/위험 요소 | 원인 분석 | 실무 대책 및 해결방안 | 기대 효과 |
|:---|:---|:---|:---|
| **AI 적대적 예제 회피 공격 대응 표준 및 거버넌스 부재** | 개발 위주 테스트로 적대적 위협 평가 지표 누락 | **NIST AI 100-2e2025** 회피 공격 방어 지침 전사 적용 | 추론 단계 회피 위협에 대한 모델 강건성 체계적 검증 및 거버넌스 정착 |
| **디지털 미세 노이즈 주입 시 치명적 오분류 취약** | 판단 경계 근처의 입력 데이터 흔들림에 대한 내성 전무 | 모델 파이프라인 단에 PGD 훈련 기반 **적대적 학습** 강제 도입 | 분류 경계 주변의 수학적 노이즈 공격에 대한 신경망 자체 내성 비약적 향상 |
