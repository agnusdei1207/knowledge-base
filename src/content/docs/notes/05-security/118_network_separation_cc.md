## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **망분리(Network Separation) 및 공통평가기준(CC / ISO/IEC 15408)**: 외부 인터넷망의 사이버 위협(악성코드, 랜섬웨어, 해킹 등)이 내부 중요 업무망으로 유입되는 것을 물리적 또는 논리적으로 차단하는 네트워크 격리 아키텍처와, 해당 경계에 도입되는 정보보호제품의 안전성 및 신뢰성을 국가 및 국제 표준에 따라 객관적으로 평가·인증하는 공통평가기준 제도.
- **경계 분리 후 망연계 구간 취약점 및 제품 오설정 결함(Bridgehead & Misconfiguration Defect)**: 망을 분리했음에도 업무 편의를 위한 망연계(Data Diode/Cross-Domain) 구간의 악성코드 검증 누락, 또는 CC 인증 제품을 도입하고도 기본 비밀번호 미변경 및 취약한 방화벽 정책 설정으로 인해 내부망이 침해되는 구조적 결함.

</details>

- 정의/개념: 외부망과 업무망의 경로를 격리하는 **망분리**
- 배경/필요성: 경계 장비만으로는 **외부 침해의 업무망 확산 방지 불가**

#### 한줄 요약
- 물리/논리 망분리와 CDR 망연계를 구축하고, ISO 15408 CC 인증 및 보안적합성 검증을 통해 핵심망을 방어한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **CC 인증 핵심 3대 개념**:
  - **PP (Protection Profile / 보호프로파일)**: 특정 제품군(방화벽, 침입방지시스템 등)이 갖추어야 할 공통 보안 요구사항을 정의한 표준 문서.
  - **ST (Security Target / 보안목표명세서)**: 특정 제조사가 자사 제품에 구현한 구체적 보안 기능 및 보증 요구사항 명세서.
  - **TOE (Target of Evaluation / 평가대상)**: CC 평가 및 인증을 실제로 수행하는 하드웨어, 소프트웨어, 펌웨어의 구체적 대상 및 범위.

</details>

- IP 경로를 차단하는 **공격 표면 격리**
- 승인·검사·**CDR**을 결합한 망연계 통제
- 제3자 평가에 따른 **EAL 보증 수준** 확인

#### 한줄 요약
- 네트워크 계층 격리, CDR 기반 망연계 통제, ISO 15408 PP/ST 기반 객관적 CC 보증을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **망분리 및 CC 검증 4대 핵심 컴포넌트**:
  1. **Separated Network Zones**: 인터넷망(외부), 업무망(내부), DMZ, 관리망.
  2. **Cross-Domain Solution (망연계)**: 전용 스토리지 기반 Non-IP 자료전송 및 스트리밍 프록시.
  3. **CC Certified TOE (CC 인증 제품)**: EAL2~EAL4 인증을 획득한 방화벽, VPN, EDR 솔루션.
  4. **Security Assurance Framework (보안적합성)**: 국정원 국가 정보보안 기본지침에 따른 실운영 환경 적합성 확인.

</details>

```text
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 외부 인터넷망 (Internet Zone) ] ── (웹서핑, 외부 이메일, 클라우드)      │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │ (직접 IP 라우팅 100% 차단)
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 망연계 톨게이트 계층 (Cross-Domain Solution: Non-IP 전송) ]            │
│  ├─ [ 1. 결재 승인 ] ➔ 부서장 사전 승인 획득된 파일만 전송 대기        │
│  ├─ [ 2. 악성코드 검사 ] ➔ 다중 안티바이러스 샌드박스 정밀 검사          │
│  ├─ [ 3. CDR 무해화 ] ➔ 문서 내 매크로, 자바스크립트, 실행 코드 제거     │
│  └─ [ 4. Non-IP 스토리지 ] ➔ IEEE 802.3 패킷이 아닌 전용 프로토콜 중계  │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │ (무해화된 순수 데이터만 반입)
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 내부 업무망 (Intranet Zone: 폐쇄망) ] ── (행정 DB, ERP, 내부 결재망)   │
│  └─ [ CC 인증(ISO 15408) 및 보안적합성 검증 통과된 장비로만 경계 보호 ]  │
└─────────────────────────────────────────────────────────────────────────┘
```

선의 의미: 인터넷망과 내부망 사이의 IP 라우팅을 차단하고, Non-IP 기반 망연계 구간에서 승인, 검사, CDR 무해화를 거쳐 안전하게 데이터를 중계하는 구조

| 구성요소 | 책임 |
|:---|:---|
| **물리적 망분리** | 장비·케이블을 분리해 경로 차단 |
| **논리적 망분리** | VDI로 사용자 실행 환경 격리 |
| **망연계 시스템** | 승인·검사·CDR 후 자료 중계 |
| **CC 인증** | 제품 보안 기능과 보증 수준 평가 |
| **보안적합성 검증** | 실제 도입 형상과 정책의 적합성 확인 |

#### 한줄 요약
- 물리/논리 망분리, CDR 기반 망연계 시스템, ISO 15408 CC 인증, 국정원 보안적합성 검증으로 구성된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **망분리 구축 및 CC 제품 도입 5단계 프로세스**:
  1. 조직 업무 환경 분석 및 망분리 방식(물리/VDI) 확정
  2. CC 인증(PP/ST) 획득 제품 선정 및 도입
  3. Non-IP 기반 망연계 시스템 및 CDR 무해화 엔진 구축
  4. 국정원 보안적합성 검증 수검 및 정책 최적화
  5. 전사 서비스 오픈 및 망연계 감사 로그 실시간 관제

</details>

```text
1. [망분리 방식 결정] 기관 특성 분석 ➔ 본청은 물리적 망분리, 지사는 VDI 논리적 망분리 확정
            │
            ▼
2. [CC 인증 제품 선정]
    ├─ 방화벽/망연계 솔루션 도입 시 국가 공통평가기준(CC) EAL4 인증 여부 확인
    └─ [국정원 검증대상 암호모듈(KCMVP) 탑재 제품으로 한정]
            │
            ▼
3. [망연계 통제 정책 수립]
    ├─ 인터넷망 ➔ 업무망 파일 반입 시 부서장 결재 승인 워크플로우 연동
    └─ [망연계 서버에 멀티 백신 및 CDR(악성 매크로 제거) 무해화 파이프라인 장착]
            │
            ▼
4. [보안적합성 검증 수검]
    ├─ 국가정보원에 정보보호제품 보안적합성 검증 신청서 및 망구성도 제출
    └─ [현장 실사: 디폴트 계정 변경, 펌웨어 일치성, 방화벽 룰셋 적정성 확인 ➔ 승인]
            │
            ▼
5. [운영 및 감사 로그 추적]
    ├─ 분리망 가동 및 망연계 전송 데이터 전수 로깅 (파일 해시, 전송자, 승인자)
    └─ [우회 연결(테더링, 비인가 무선랜) 탐지 시스템(WIPS)을 통한 상시 감시]
```

**동작 원리**

1. **망분리 방식 결정**: 중요도·비용에 따라 물리·VDI 선택
2. **CC 인증 제품 선정**: TOE 형상과 인증 유효성 확인
3. **망연계 통제 정책 수립**: 승인·검사·CDR 적용
4. **보안적합성 검증 수검**: 도입 형상과 운영 정책 확인
5. **운영 및 감사 로그 추적**: 전송·승인·해시 이력 보존

#### 한줄 요약
- 망분리 방식 결정, CC 제품 선정, 망연계 CDR 장착, 보안적합성 검증, 감사 로그 추적 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **물리적 망분리 vs 논리적 망분리(VDI) 비교**:
  - 물리적 망분리: PC 2대 또는 물리 스위치를 사용하여 하드웨어 레벨에서 완전 격리.
  - 논리적 망분리 (VDI): 가상화 서버를 통해 1대의 PC에서 화면 스트리밍 방식으로 격리.

</details>

| 비교 항목 | 물리적 망분리 (Physical) | 논리적 망분리 (Logical / VDI) |
|:---|:---|:---|
| **구현 방식** | **업무용 PC + 인터넷용 PC (2대) 물리 배치** | **1대 PC + 전산실 가상 데스크톱(VDI) 스트리밍**|
| **보안 격리성** | **최고 (하드웨어 및 케이블 완전 분리)** | 우수 (하이퍼바이저 기반 가상 실행 격리) |
| **구축 비용** | 하드웨어 2배 구매 및 네트워크 포트 추가 비용 | **중앙 VDI 서버, 스토리지, 가상화 라이선스 비용**|
| **사용 편의성** | 모니터 2대 또는 KVM 스위치 조작 필요 | **화면 전환 클릭으로 간편 전환, 재택근무 용이** |
| **주요 위협 요인** | **비인가 USB 수동 복사, 무단 테더링 연결** | **가상화 탈옥(Hypervisor Escape), 클립보드 유출** |

#### 한줄 요약
- 물리적 망분리는 하드웨어 완전 격리(최고 보안), 논리적 망분리는 VDI 화면 스트리밍(유연성/비용 효율)이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **ISO/IEC 15408 (공통평가기준) 및 ISO/IEC 18045 (평가 방법론)**: 정보보호제품 보안성 평가 기준 및 평가 방법론 국제 표준.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| CC 인증 획득 제품을 도입했으나 제조사가 평가받지 않은 미인증 펌웨어를 탑재하여 **백도어 취약점이 노출되고 보안적합성 검증 기각** | **ISO/IEC 15408 준수, CC 인증서에 명시된 TOE(평가대상) 펌웨어 버전 및 하드웨어 형상과 100% 일치 여부를 사전 실측 대조** | 미인증 소프트웨어 도입 원천 차단 및 안정적 보안적합성 통과 |
| 망분리 후 업무 편의를 위해 망연계 정책을 무차별 허용(Any Open)하여 **인터넷망에서 유입된 악성코드가 내부망 서버를 랜섬웨어 감염** | **망연계 시스템에 Non-IP 스토리지 중계, 부서장 결재 승인, 다중 백신 검사 및 CDR(콘텐츠 무해화) 필수 파이프라인 강제** | 망연계 교두보 악용 100% 차단 및 무해화 데이터만 반입 보장 |
| 공공기관 전산실에 CC 인증 장비를 설치하면서 디폴트 관리자 패스워드를 방치하여 **외부 용역업체 인력에 의한 관리자 계정 무단 도용 발생** | **국정원 보안적합성 검증 가이드라인 준수, 기본 계정 변경, 관리자 접근 시 전용 관리망 경유 및 MFA 다중인증 강제** | 관리자 권한 오남용 100% 방지 및 운영 거버넌스 완성 |

#### 한줄 요약
- TOE 펌웨어 일치성을 대조하고, 망연계에 CDR 무해화를 강제하며, 관리자 MFA와 보안적합성 검증을 수검한다.

## Ⅶ. 결론

- 고기밀 환경은 **물리적 망분리**, 유연성은 **VDI** 선택

#### 한줄 요약
- 물리/논리 망분리와 CDR 망연계 및 ISO 15408 CC 인증과 보안적합성 검증을 통해 무결점 망분리를 완성한다.
