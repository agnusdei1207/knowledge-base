## 미리 알고가기

- **정보기술 보안성 평가 공통기준 (Common Criteria for Information Technology Security Evaluation, CC)**: 제품 보안기능을 평가함
- **망분리 (Network Separation)**: 보안 영역을 격리하고 연계 경로를 통제함
- **가상 데스크톱 인프라 (Virtual Desktop Infrastructure, VDI)**: 논리적으로 업무 실행 영역을 분리함
- **응용 프로그래밍 인터페이스 (Application Programming Interface, API)**: 관리·연계 기능을 호출함
- **보안적합성 검증 (Security Conformance Verification)**: 공공 도입 제품·설정을 검증함
- **무해화**: 문서에서 실행 코드·매크로 등 위험 요소를 제거하고 안전한 내용만 재구성하는 처리
- **CC·VDI·API 읽기**: “시시·브이디아이·에이피아이”로 읽으며 각 영문 명칭의 머리글자로 평가기준·가상 데스크톱·호출 규칙을 나타냄



## Ⅰ. 개요

- **정의/개념**: 업무·인터넷 영역을 격리하고 연계 경로를 통제해 침해 확산을 제한
- **배경/필요성**: 단일 네트워크의 자유로운 연결로 외부 침해가 업무 영역까지 확산

### 쉽게 이해하기 (학습용)

- 망을 나눠도 통로와 제품 설정이 약하면 공격이 가능함

## Ⅱ. 특징

- 영역 간 이동과 피해 범위를 제한한다.
- 자료 전송·관리 경로가 주요 공격면이다.
- CC는 제품·버전을 평가하고 적합성 검증은 적용 환경을 확인한다.

### 쉽게 이해하기 (학습용)

- 인증 제품도 평가 범위 밖 기능이나 잘못된 설치 설정까지 자동으로 안전해지지는 않음

## Ⅲ. 아키텍처 및 구성요소

| 설계 요소 | 설명 |
|:---|:---|
| 보안 영역 | 업무·인터넷·관리망 구분함 |
| 경계·연계 | 자료 전송의 승인·검사를 통제함 |
| 평가 제품 | 인증 범위·버전 적합성을 확인함 |
| 안전한 구성 | 계정·로그·관리 경로를 설정함 |
| 운영 검증 | 우회·정책·변경사항을 점검함 |

```text
[인터넷망] ─승인·검사·무해화─> [망연계 구간] ─최소 허용─> [업무망]
                                      ↑
                              [분리된 관리망]
                              계정·설정·로그 관리
```

### 쉽게 이해하기 (학습용)

- 영역 사이에 필요한 통신만 허용하고 모든 예외 전송과 관리 작업을 기록하는 구조임

## Ⅳ. 원리 및 절차 흐름도

```text
영역흐름분석 → 분리연계설계 → 제품설정검증 → 운영감시 → 효과재평가
```

| 절차 | 설명 |
|:---|:---|
| 영역분석 | 서비스·관리 흐름 파악함 |
| 연계설계 | 최소 연계 대책 정함 |
| 제품검증 | 설정 범위를 확인함 |
| 운영감시 | 전송·로그를 관리함 |
| 효과평가 | 침해·변화 검증함 |

> 요약: 흐름에 맞춰 분리·연계하고 제품·운영을 검증함

### 쉽게 이해하기 (학습용)

- 먼저 필요한 정보 흐름을 그려야 업무를 막지 않으면서 위험한 통로만 통제할 수 있음

## Ⅴ. 망분리 방식 비교

| 비교축 | 물리적 망분리 | 논리적 망분리 |
|:---|:---|:---|
| 적용 기준 | 강한 격리와 명확한 경계가 필요할 때 | 유연한 전환·중앙 관리가 필요할 때 |
| 핵심 특징 | 장비·회선 등 물리 경로 분리 | VDI 등으로 실행 영역을 논리 분리 |
| 한계 | 이동식 매체·망연계가 우회 경로가 됨 | 가상화 오류·공유 기능으로 경계가 약화됨 |

### 쉽게 이해하기 (학습용)

- 물리 방식은 경로가 분명하고 논리 방식은 유연하지만 둘 다 연계와 관리 통제가 필요함

## Ⅵ. 실무 사례

- 망연계는 승인·악성코드 검사·무해화·추적을 위험에 맞게 조합함
- VDI 공유 기능·관리 API·우회 절차 점검
- 제품 버전·패치·구성의 평가 범위 관리

### 쉽게 이해하기 (학습용)

- 망연계에는 승인·악성코드 검사·무해화·추적을 위험에 맞춰 적용함
- VDI의 파일·클립보드·프린터·관리 API와 장애 우회 절차를 점검함
- 인증받은 제품도 설치·패치 버전이 바뀌면 평가 범위를 다시 확인함

## Ⅶ. 결론

- 영역 격리보다 연계·관리 경로의 실제 구성을 통제함

### 쉽게 이해하기 (학습용)

- 벽의 개수보다 벽에 난 문을 누가 어떻게 사용하고 기록하는지가 실제 보안을 결정함
