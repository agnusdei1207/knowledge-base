## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **ISMS-P(Personal Information & Information Security Management System) 인증 심사**: 개인정보보호 및 정보보호 관리체계의 실제 작동을 독립적으로 심사•의결하는 절차이다.
- **운영 적합성**: 정책•통제 설계와 일상 운영 기록, 현장 상태가 인증 기준에 맞고 서로 일치하는 성질이다.

</details>

- 정의/개념: **ISMS-P 인증 심사**는 관리체계의 **운영 적합성**을 독립적으로 심사•의결하는 절차이다.
- 배경/필요성: 내부 자체 점검만으로는 통제의 실제 작동과 지속성을 독립적으로 입증하기 어렵다.

#### 한줄 요약

- 문서에 적힌 보호 절차가 현장에서 실제 작동하는지 확인한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **운영 증적**: 로그•승인•점검 기록으로 통제 작동을 입증하는 자료이다.
- **결함 시정**: 심사 결함의 원인을 제거하고 이행 근거를 다시 검증하는 활동이다.
- **사후심사**: 인증 취득 뒤 정기적으로 변경과 통제 지속성을 확인하는 심사이다.
- **유효기간**: 발급된 인증서의 효력이 유지되는 기간이다.

</details>

- 문서•현장의 **운영 증적**으로 통제 작동을 확인한다.
- **결함 시정**의 원인 제거와 이행 근거를 검증한다.
- **유효기간** 중 **사후심사**로 통제 지속성을 확인한다.

#### 한줄 요약

- 취득 후에도 매년 심사하여 지속 운영을 검증한다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **인증기관**: 인증 신청•위원회 운영•인증서 발급을 담당하는 기관이다.
- **인증심사기관**: 심사 계약•심사팀 구성•서면•현장 심사를 수행하는 기관이다.
- **운영명세서**: 인증 범위•조직•자산•통제 현황을 정리한 문서이다.
- **인증위원회**: 심사 결과를 독립 검토해 인증 여부를 의결하는 조직이다.

</details>

```text
ISMS-P 인증 심사 체계
├─ 신청기관
│  └─ 인증 범위 · 운영명세서 제출
├─ 인증기관
│  └─ 접수 · 위원회 운영 · 인증서 발급
├─ 인증심사기관
│  └─ 계약 · 심사팀 구성 · 결과 보고
├─ 심사팀 · 운영 증적
│  └─ 서면 · 현장 증거 · 결함 확인
└─ 인증위원회
   └─ 인증 여부 심의 · 의결
```

| 구성요소 | 책임 |
|:---|:---|
| 신청기관 | 인증 범위와 **운영명세서** 제출 |
| 인증기관 | **인증기관**이 심사 접수•위원회 운영•인증서 발급 |
| 인증심사기관 | **인증심사기관**이 심사 계약•심사팀 구성•결과 보고 |
| 심사팀•운영 증적 | **운영 증적**으로 서면•현장 결함 확인 |
| 인증위원회 | **인증위원회**가 인증 여부 심의•의결 |

#### 한줄 요약

- 심사팀이 운영 증거를 확인하고 위원회가 인증을 의결한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **심사 발견사항**: 서면•현장에서 확인한 통제의 부적합과 운영 결함이다.
- **시정 증적**: 발견사항의 원인•보완조치•완료 근거를 연결한 자료이다.
- **인증 심의**: 독립된 위원회가 심사 결과와 시정 확인을 검토하는 절차이다.
- **인증 의결**: 위원회가 검토 결과에 따라 인증 여부를 결정하는 절차이다.
- **서면•현장 심사 수행**: 확정 범위의 문서와 실제 통제 운영 상태를 확인하는 단계이다.
- **결함 원인 시정•증적 생성**: 발견사항의 근본 원인을 보완하고 완료 근거를 만드는 단계이다.
- **시정 확인•최종 결과 작성**: 적합성•결함•시정 효과를 검증해 심사 결과를 정리하는 단계이다.
- **인증 심의•의결**: 독립 위원회가 심사 결과를 검토하고 인증 여부를 결정하는 단계이다.
- **사후•갱신 적합성 심사**: 인증 뒤 운영 변화와 기준 준수의 지속성을 재확인하는 단계이다.

</details>

```text
인증 신청 · 운영명세서
            │
            ▼
1. 서면•현장 심사 수행
            │
       심사 발견사항
            ▼
2. 결함 원인 시정•증적 생성
            │
            ▼
3. 시정 확인•최종 결과 작성
            │
            ▼
4. 인증 심의•의결
       ┌────┴────┐
       │ 인증    │ 보완
       ▼         └──── 시정 단계로 환류
    인증서 발급
       │
       ▼
5. 사후•갱신 적합성 심사
       │
       └──── 유효기간 동안 반복
```

### 동작 원리

1. **서면•현장 심사 수행**: 확정 범위의 통제 운영과 부적합을 확인한다.
2. **결함 원인 시정•증적 생성**: **심사 발견사항**을 보완하고 **시정 증적**을 준비한다.
3. **시정 확인•최종 결과 작성**: 적합성•결함•시정 효과를 판정한다.
4. **인증 심의•의결**: **인증 심의** 뒤 **인증 의결**로 여부를 결정한다.
5. **사후•갱신 적합성 심사**: 운영 변화와 인증 기준 준수를 확인한다.

#### 한줄 요약

- 신청, 심사, 결함 보완, 위원회 의결, 사후관리 순으로 진행한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **최초심사**: 인증을 처음 취득할 때 전체 기준 적합성을 확인하는 심사이다.
- **갱신심사**: 인증 만료 전에 전체 기준을 재평가해 연장 여부를 판단하는 심사이다.

</details>

| ISMS-P 심사 유형 | 최초심사 | 사후심사 | 갱신심사 |
|:---|:---|:---|:---|
| 적용 기준 | **최초심사** | **사후심사** | **갱신심사** |
| 핵심 특징 | 전체 기준 최초 적합성 | 유효기간 중 지속성 | 만료 전 전체 기준 재심사 |
| 한계 | 문서•실제 운영 불일치 | 변경•사고 미반영 | 누적 결함•형식적 연장 |

#### 한줄 요약

- 세 심사는 시점과 범위가 다르지만 모두 실제 운영 증거를 본다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **시행령**: ISMS-P 서면•현장 심사 절차와 유효기간을 규정하는 하위 법규이다.
- **인증 고시**: ISMS-P 세부 심사 기준과 사후관리 요건을 규정한 행정규칙이다.
- **변경 관리**: 자산•위탁 조직•클라우드•서비스 범위가 바뀔 때 운영명세서와 통제 증적을 함께 갱신하는 활동이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 개인정보 인증 절차 | **시행령** 절차 준수 | 서면•현장심사 적법성 확보 |
| 인증 세부 기준 | **인증 고시** 적용 | 심사 기준 일관성 확보 |
| 유효기간•지속성 | **유효기간** 중 **사후심사** | 형식적 인증 방지 |

#### 한줄 요약

- **변경 관리**로 자산•위탁 조직 변경 시 운영명세서와 관련 증적도 갱신한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **인증 지속성**: 인증서 취득 후에도 변경•사고•결함을 운영 기록과 시정조치에 반영하고 사후•갱신심사로 효과를 증명하는 능력이다.

</details>

- **인증 지속성**을 위해 최초 취득은 **최초심사**, 유효기간 중은 **사후심사**, 만료 전은 **갱신심사**를 수행한다.

#### 한줄 요약

- 취득 뒤에도 운영 기록을 남기고 결함 원인을 고쳐 유지한다.
