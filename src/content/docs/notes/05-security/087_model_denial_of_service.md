## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **DoS(Denial of Service)** 는 자원을 고갈시켜 정상 사용자의 서비스 이용을 방해하는 공격이다.
- **모델 DoS** 는 고비용 추론으로 연산•메모리•외부 비용을 고갈시키는 공격이다.
- **GPU(Graphics Processing Unit)** 는 AI 모델의 병렬 연산을 가속하는 처리 장치다.
- **API(Application Programming Interface)** 는 서비스 기능과 데이터를 정해진 요청•응답 형식으로 제공하는 경계다.
- **AI(Artificial Intelligence)** 는 학습된 모델로 인식•추론•생성 작업을 수행하는 기술이다.
- **요청별 비용 차이**: 같은 호출 한 건이라도 입력•출력 토큰, 모델, 도구 사용에 따라 실제 자원 소비가 크게 다른 특성이다.

</details>

- 정의/개념: **모델 DoS** 는 고비용 추론으로 연산•메모리•외부 비용을 고갈시키는 공격
- 배경/필요성: 호출 횟수 제한의 **요청별 비용 차이 누락**

#### 한줄 요약

- 짧은 질문 한 건과 긴 문서 분석 한 건의 비용이 다르므로 요청 수뿐 아니라 토큰•시간•도구 사용량까지 제한해야 한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **컨텍스트 비용** 은 긴 입력과 출력을 처리하면서 누적되는 연산•메모리 비용이다.
- **도구 순환** 은 에이전트가 외부 도구 호출과 재시도를 반복해 비용을 누적하는 위험이다.
- **테넌트 공정성**: 공유 자원에서 한 고객의 고비용 요청이 다른 고객의 처리 기회를 빼앗지 않도록 실행 슬롯과 예산을 분리하는 원칙이다.

</details>

- 긴 문맥•출력의 **GPU 자원 점유**
- 도구 순환•재시도의 **연쇄 비용 증가**
- **테넌트 공정성** 을 위한 예산•공정 큐로 자원 독점 방지

#### 한줄 요약

- 공격자는 적은 요청이라도 긴 출력이나 반복 도구 호출을 유도하여 GPU와 외부 API 비용을 동시에 고갈시킬 수 있다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **비용 추정** 은 요청의 예상 토큰•모델•도구 소비량을 실행 전에 계산하는 기능이다.
- **입장 제어** 는 예상 비용과 현재 용량에 따라 요청의 승인•대기•거부를 결정하는 통제다.
- **쿼터** 는 사용자•테넌트별로 허용된 기간별 자원 사용 한도다.
- **회로 차단기** 는 실행 중 누적 비용이 임계치를 넘으면 연쇄 호출을 중단하는 통제다.

</details>

```text
모델 DoS 방어 구조
├─ 요청 경계
│  ├─ 인증 게이트웨이
│  └─ 비용 추정기
├─ 자원 배분 경계
│  ├─ 입장 제어기
│  └─ 공정 스케줄러
└─ 실행 경계
   └─ 예산•회로 차단기
```

| 구성요소 | 책임 |
|:---|:---|
| 인증 게이트웨이 | **사용자•키•테넌트 식별** |
| 비용 추정기 | **토큰•모델•도구 비용** 계산 |
| 입장 제어기 | 쿼터•용량별 **승인•대기•거부** |
| 공정 스케줄러 | 테넌트별 **실행 슬롯 배분** |
| 예산•회로 차단기 | **누적 한도 초과 실행 중단** |

#### 한줄 요약

- 요청의 예상 비용으로 입장을 결정하고 실행 중 실제 사용량이 한도를 넘으면 출력•도구 호출을 줄이거나 중단한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **가중 쿼터**: 요청 수뿐 아니라 토큰•시간•동시성•도구 비용을 가중하여 실제 소비량으로 한도를 계산하는 방식이다.
- **축소 응답**: 예산에 가까워질 때 전체 실패 대신 출력 길이•모델•도구 범위를 줄여 필수 기능을 유지하는 처리이다.

</details>

```text
대형 문맥•병렬 추론 요청
              |
              v
1. 입력 토큰•문맥 확장
              |
              v
2. 병렬 작업•대기열 누적
              |
              v
3. 반복 추론•도구 자원 소비
              |
              v
4. 메모리•연산 슬롯 고갈
              |
        정상 추론 요청
              |
              v
5. 지연•오류•서비스 거부 전파
              |
              v
         지연•실패 결과
```

**동작 원리**

1. **입력 토큰•문맥 확장**: 과대 입력으로 추론 비용 증폭
2. **병렬 작업•대기열 누적**: 동시 요청으로 처리 큐 점유
3. **반복 추론•도구 자원 소비**: 장기 생성과 외부 호출 지속
4. **메모리•연산 슬롯 고갈**: 가속기와 실행 용량 독점
5. **지연•오류•서비스 거부 전파**: 정상 요청의 가용성 저하


#### 한줄 요약

- 정상 대형 작업은 공정 큐에서 처리하되 비정상적으로 자원을 독점하는 요청은 비용 한도에서 축소하거나 중단한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **대량 호출형** 은 많은 요청으로 서비스 입구와 작업 큐를 점유하는 공격 유형이다.
- **고비용 문맥형** 은 한 요청의 긴 문맥과 출력으로 GPU•메모리를 점유하는 공격 유형이다.
- **에이전트 순환형** 은 반복 도구 호출과 재시도로 여러 시스템의 비용을 고갈시키는 유형이다.

</details>

| 모델 DoS 유형 | 대량 호출형 | 고비용 문맥형 | 에이전트 순환형 |
|:---|:---|:---|:---|
| 적용 기준 | **신원별 호출 한도** | **토큰•시간 한도** | **단계•도구•비용 한도** |
| 핵심 특징 | **입구•작업 큐 점유** | **GPU•메모리 점유** | **도구•재시도 비용 누적** |
| 한계 | 분산 계정으로 **호출 한도 회피** | 정상 대형 작업 **과잉 거부** | **여러 시스템 동시 고갈** |

#### 한줄 요약

- 대량형은 입구와 큐, 고비용형은 GPU와 메모리, 에이전트형은 모델과 연결 도구의 비용을 고갈시킨다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **OWASP(Open Worldwide Application Security Project)** 는 애플리케이션 보안 지침을 공개하는 비영리 프로젝트다.
- **LLM(Large Language Model)** 은 대규모 언어 데이터로 학습해 자연어를 이해•생성하는 모델이다.
- **LLM10:2025** 은 무제한 모델 자원 소비의 서비스 거부와 비용 손실을 분류한다.
- **DDoS(Distributed Denial of Service)** 는 다수의 분산 출발지에서 자원을 고갈시키는 서비스 거부 공격이다.
- **행위 상관분석** 은 분산 계정•출발지의 입력 패턴과 자원 소비를 연결하는 분석이다.
- **NIST(National Institute of Standards and Technology)** 는 미국의 기술 표준과 지침을 개발하는 기관이다.
- **NIST 공격 분류** 는 공격자의 지식•목표•역량과 자원 고갈 경로를 공통 기준으로 구분한다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **무제한 자원 소비** | **OWASP LLM10:2025 적용** | **입력•출력•도구 한도 구체화** |
| **요청별 비용 차이** | **토큰•시간•동시성 가중 쿼터** | **고비용 소수 요청 통제** |
| **테넌트 연쇄 고갈** | **공정 큐•회로 차단•축소 응답** | **장애 격리•서비스 연속성** |
| **DDoS** 분산 계정으로 **호출 한도 회피** | **NIST 공격 분류•행위 상관분석** | **분산 자원 고갈 탐지** |

#### 한줄 요약

- 생성형 AI API는 계정•테넌트별 토큰과 동시 요청 한도를 적용해 장문 반복 요청이 전체 GPU 자원을 고갈시키지 않게 한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **비용 기반 가용성 통제**: 호출 횟수뿐 아니라 예상•실제 자원 무게를 입장 전과 실행 중에 계속 측정해 공정하게 제한하는 원칙이다.

</details>

- 예상 비용이 쿼터 이내면 **승인**, 실행 비용 초과 시 **회로 차단**

#### 한줄 요약

- 모델 DoS 방어는 호출 수만 세지 않고 요청의 실제 자원 무게와 실행 중 누적 비용을 함께 통제하는 것이다.
