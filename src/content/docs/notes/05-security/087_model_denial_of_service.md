## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **모델 DoS (Model Denial of Service / Model DoS)**: 비대칭적인 고비용 추론 연산 요청, 100k 토큰 이상의 초장문 프롬프트, 에이전트의 무한 도구 호출(Tool Loop)을 의도적으로 유발하여 LLM 인프라의 GPU 연산 자원, 메모리 용량, 외부 API 과금 예산을 악의적으로 고갈시키는 AI 타깃 보안 팩트 공격 기법이다.
- **비대칭 자원 소비 (Asymmetric Resource Consumption / Cost Difference)**: 무수한 봇넷이 필요한 전통적 Web 네트워크 DoS 공격과 달리, 단 1건의 악성 프롬프트 요청일지라도 입력 컨텍스트 길이 및 내부 도구 반복 실행 구조에 따라 서버 자원 점유량이 1,000배 이상 폭증하는 치명적 비대칭 팩트 특성이다.

</details>

- 정의: 초장문 문맥 입력과 치밀한 에이전트 무한 도구 호출 유도를 통해 LLM 운영의 핵심인 GPU 연산 및 API 예산을 완전히 고갈시키는 서비스 거부 팩트 공격이다.
- 배경: 단순 HTTP 요청 건수(RPS) 제한 방화벽으로는 탐지 차단이 불가능한 생성형 AI 특유의 **비대칭 자원 소비** 구조와 에이전트 툴 자율 실행 취약점이 맞물려 등장했기 때문이다.

#### 한줄 요약

- 의도된 초장문 문맥 입력과 무한 도구 호출을 유도 설계하여 대상 GPU 연산, KV 캐시 메모리 및 클라우드 외부 과금 예산을 파괴하는 신종 서비스 거부 팩트 공격이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **컨텍스트 비용 폭발 (Context Window Cost Explosion)**: 프롬프트 입력/출력 토큰 길이가 길어짐에 따라 트랜스포머(Transformer) 아키텍처의 self-attention 행렬 연산량($O(N^2)$)과 상태 유지를 위한 KV 캐시 메모리가 폭발적으로 늘어나는 AI 팩트 비용 특성이다.
- **도구 순환 마비 (Infinite Tool Loop / Recursive Tool Execution)**: AI 에이전트가 악성 프롬프트에 속아 종료 완결 조건을 찾지 못한 채 외부 DB 조회, 결제 API, OS 코드 실행을 무한 재귀 호출하여 외부 시스템 자원까지 덩달아 마비 과금시키는 파괴적 팩트 현상이다.
- **테넌트 공정성 파괴 (Multi-Tenant Fairness Collapse)**: 멀티 테넌트 SaaS 클라우드 환경에서 악성 공격자 단 1명의 고비용 DoS 연산 요청이 큐를 독점해 버려, 다른 수만 명의 선량한 사용자의 추론 응답 속도가 보장되지 못하고 동시다발적 장애 타임아웃을 겪는 연쇄 팩트 현상이다.

</details>

- **비대칭 O(N²) 자원 점유 증폭**: 단 1건의 조작된 초장문 요청만으로도 트랜스포머의 $O(N^2)$ 자기주의 연산 하중을 유발하여 시스템을 다운시키는 **비대칭적 자원 고갈 증폭** 팩트 특성을 가진다.
- **에이전트 외부 연쇄 과금 폭탄**: 단순히 LLM 자체 연산 지연을 넘어, 고가의 외부 유료 API나 대용량 DB 조회가 재귀적으로 얽힌 **도구 순환**을 유도하여 심각한 클라우드 과금 폭증을 팩트로 유발한다.
- **토큰 기반 쿼터 강제**: 멀티 테넌트 서비스의 정상적인 **테넌트 공정성** 유지를 위해, 기존 네트워크 패킷 검사가 아닌 런타임 토큰 가중치 기반 쿼터 및 런타임 샌드박싱 조치가 필수적으로 강제되는 팩트 방어 특성이 있다.

#### 한줄 요약

- 토큰 연산 비대칭 O(N²) 자원 고갈 파괴, 연쇄적 무한 도구 순환 과금 폭탄 및 선량한 테넌트 공정성 연쇄 타임아웃 마비 팩트 특성을 지닌다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **비용 추정기 (Cost Estimator / Token Pre-computation)**: 사용자의 프롬프트를 실제 GPU 큐에 수신 접수하기 직전에, 입력 토큰 수량, 예상되는 응답 출력 길이, 에이전트 툴 호출 가능성을 정밀 사전 계산하여 자원 하중을 정량 추정하는 보안 팩트 모듈이다.
- **가중치 입장 제어기 (Weighted Admission Controller)**: 사전 추정된 자원 하중 점수가 현재 시스템의 잔여 GPU 여유 용량이나 사용자의 할당 예산 쿼터를 초과할 경우, 추론 집행 자체를 즉시 거부(Drop)하거나 백그라운드 대기 큐에 유배하는 팩트 통제 관문이다.
- **회로 차단기 (Circuit Breaker)**: 모델 추론 런타임 중 특정 프롬프트가 예상을 깨고 도구 호출 무한 루프에 빠지거나 초장문 악성 토큰을 끝없이 뿜어낼 때, 연결 스레드를 즉시 강제 끊어버려 자원 방전을 막는 2차 런타임 방화벽 팩트 모듈이다.

</details>

```text
[모델 DoS 자원 방어 통제 팩트 아키텍처]

[1. API 요청 경계]  -->  [인증 게이트웨이] 및 [사전 토큰 비용 추정기] 심사
                              |
                              v
[2. 자원 배분 경계]  -->  [가중치 입장 제어기] 및 [테넌트 공정 스케줄러] 쿼터 삭감
                              |
                              v (승인된 요청만 GPU 큐 진입)
                              |
[3. 추론 실행 경계]  -->  [LLM 추론 엔진] 및 [도구 실행 샌드박스] 
                              |
                          (이상 폭주 감지)
                              v
[4. 런타임 통제 경계] -->  [무한 루프 예산 회로 차단기 (Circuit Breaker)] 강제 종료
```

| 구성요소 | 주요 책임 및 역할 | 비고 |
|:---|:---|:---|
| **API 요청 통제 경계** | 사용자 인증 게이트웨이 검문 및 프롬프트 토큰화 사전 카운트를 통한 **비용 추정** 정량화 팩트 집행 | Boundary Gateway |
| **자원 배분 경계** | 사용자별 TPM/RPM **쿼터** 대조 및 현재 GPU 무부하 슬롯을 실시간 산정하여 **가중치 입장 제어** 허용 판별 | Admission Control |
| **추론 실행 경계** | 승인된 프롬프트에 한하여 실제 딥러닝 행렬 곱 연산 및 외부 도구 에이전트 팩트 실행 | GPU Execution |
| **런타임 차단 경계** | 런타임 중 Max Tokens 임계치 초과 또는 치명적 **도구 순환** 루프 감지 시 **회로 차단기** 발동 프로세스 강제 팩트 종료 | Circuit Breaker |

#### 한줄 요약

- 사전 토큰 비용 추정 심사, 가중치 입장 제어기 기반 쿼터 할당, 실제 추론 실행 및 런타임 폭주 회로 차단기(Circuit Breaker) 조치로 철벽 방어 라인을 팩트 구축한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **가중 쿼터 (Weighted Quotas / Token-bucket Rate Limiter)**: 단순 HTTP 요청 건수(RPS)만 세는 것이 아니라, 딥러닝의 실제 부하 원인인 입력/출력 토큰 수와 사용된 모델의 거대 체급(7B vs 70B 파라미터)을 모두 종합 가중 계산하여 사용자 예산 쿼터를 정밀 차감하는 팩트 방어 방식이다.
- **축소 응답 (Degraded Response / Graceful Degradation)**: GPU 자원 고갈 및 트래픽 과부하 공격 발생 시 전체 시스템 502 다운을 피하기 위해, 자동으로 하위 체급의 저비용 모델(예: GPT-4o $\rightarrow$ GPT-4o-mini)로 임시 스위칭하여 필수적인 응답 서비스 가용성을 이어가는 품질 완화 팩트 기법이다.

</details>

```text
[공격자의 대형 문맥 은닉 및 무한 툴 루프 악성 프롬프트 지속 제출]
              |
              v
1. 100k 토큰 이상의 무의미한 초장문 입력 데이터 및 문맥 확장 강제 주입
              |
              v
2. 동일 계정/IP 발 병렬 작업 폭주로 인한 GPU 추론 대기열(Queue) 포화 점유
              |
              v
3. 에이전트의 종료 조건 없는 반복 토큰 생성 및 재귀적 도구 API 자원 무한 팩트 소비
              |
              v
4. 인프라의 VRAM 메모리 및 GPU 연산 슬롯, 외부 API 과금 예산 초고속 팩트 고갈
              |
              v
[선량한 정상 멀티 테넌트 사용자의 추론 요청 유입]
              |
              v
5. 정상 사용자의 트래픽마저 무기한 지연 대기되며 서비스 거부 504 Time-Out 에러 전파 마비
              |
              v
[전체 AI 클라우드 시스템 다운 및 천문학적 요금 청구서 발행 폭탄 결과]
```

### 동작 원리

1. 초장문 문맥 입력: 공격자가 O(N²) 부하를 노린 고비용 초장문 문맥 프롬프트를 팩트 주입한다.
2. 병렬 대기열 점유: 다중 세션을 동시 열어 딥러닝 추론 스케줄링 큐를 꽉 채워 병렬 마비시킨다.
3. 무한 자원 반복 소비: 에이전트 루프가 발동하여 내부 토큰 생성 및 외부 API를 재귀적으로 팩트 소비한다.
4. 연산 및 예산 고갈: GPU KV 캐시 메모리가 방전되고 클라우드 연동 예산이 바닥난다.
5. 연쇄 거부 전파: 선량한 정상 요청까지 타임아웃 오류를 뿜으며 클러스터 전체로 장애가 팩트 전파된다.

#### 한줄 요약

- 의도적 초장문 확장, 병렬 큐 점유 마비, 재귀적 반복 툴 소비, GPU 메모리 파괴 고갈, 정상 사용자 연쇄 서비스 거부 장애 전파 단계로 치명적 진행된다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **대량 호출형 (Volumetric Request Flood)**: 전통적인 DDoS 공격과 유사하게 악성 봇넷을 동원해 미세한 프롬프트라도 API를 무차별적으로 수만 건 호출하여 웹 프론트엔드 입구 자체를 마비시키는 팩트 공격이다.
- **고비용 문맥형 (Heavy Context Window Exploitation)**: 악성 봇넷 대량 동원 없이 단 한 번의 요청에 모델이 수용 가능한 한계치 토큰(Context)을 꽉 채워 제출함으로써 내부 GPU의 Self-attention 병렬 연산량 자체를 붕괴시키는 고효율 비대칭 팩트 공격이다.
- **에이전트 순환형 (Recursive Agent Loop)**: 외부 환경을 인식하는 LLM 에이전트의 판단 오판을 유도하는 함정 프롬프트를 주입하여, 종료 조건 없이 무한정 RDBMS나 고가 유료 API를 뺑뺑이 조회하게 만드는 악질적 Sponge 팩트 공격이다.

</details>

| 팩트 모델 DoS 공격 유형 | **대량 호출형 (Volumetric Flood)** | **고비용 문맥형 (Heavy Context)** | **에이전트 순환형 (Recursive Loop)** |
|:---|:---|:---|:---|
| 공격 핵심 타격 수단 | 분산 봇넷 IP를 이용한 무차별 API RPS(Request Per Second) 네트워크 트래픽 폭탄 주입 | 100k 토큰 한계치에 달하는 거대한 단일 초장문 텍스트 프롬프트 의도적 제출 | 정상 지시로 위장하여 무한 루프 유도 프롬프트 교묘히 주입 (Tool Call 함정) |
| 타격 및 마비 대상 자원 | API Gateway, Nginx 웹 프론트엔드 연결 스레드 풀 | 백엔드 **GPU KV 캐시 메모리**, 트랜스포머 아키텍처의 핵심 Self-Attention 행렬 연산기 | 조직의 **외부 API 과금 예산 지갑**, 백엔드 레거시 RDBMS 쿼리 풀 |
| 보안 관제 탐지 난이도 | 탐지 용이 (기존 네트워크 WAF의 RPS 및 IP 주소 블랙리스트 이상치 룰로 즉각 탐지 가능) | 방어 보통 수준 (API Gateway 단에서 요청 바디의 토큰 카운터 계측으로 선제 사전 검출 가능) | 사전 탐지 최고 난이도 (정상적인 복잡한 툴 연쇄 실행과 악성 무한 루프 간의 사전 논리적 경계 구분이 극히 애매함) |
| 핵심 대표 대응 팩트 기술 | 기존 L7 **DDoS 방화벽**, 클라이언트 IP 기반 엄격한 RPS Rate Limit | 프롬프트 **비용 추정기**, 토큰 사용량 비례 **가중 쿼터 (TPM Limit)** 삭감 정책 강제 | 에이전트 **Max Iteration 제한**, 무한 뺑뺑이 감지 **회로 차단기(Circuit Breaker)** 강제 개입 |

#### 한줄 요약

- 프론트엔드 마비용 대량 호출형(RPS 폭주), GPU 내부 연산 파괴용 고비용 문맥형(초장문 텍스트), 조직 클라우드 예산 고갈용 에이전트 순환형(무한 툴 루프)으로 치명적 세분화된다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **OWASP LLM10:2025 (Model Denial of Service)**: 글로벌 애플리케이션 보안 비영리 단체인 OWASP가 2025년 생성형 AI 핵심 위험 Top 10 목록 중 10위로 지정하여 경고한 무제한 자원 소비 거부 공격 팩트 규격이다.
- **행위 상관분석 (Behavioral Correlation Analytics)**: 공격자가 Rate Limit을 우회하기 위해 다수의 가짜 유령 계정으로 치밀하게 나뉘어 쏘는 고비용 프롬프트들의 은밀한 배후 상관관계를 그래프 분석으로 추적 탐지하는 지능화된 팩트 분석 기술이다.
- **NIST 공격 분류 (NIST AI Threat Classification)**: 미국 국립표준기술연구소(NIST)가 AI 시스템의 다양한 DoS 자원 고갈 우회 침투 경로를 전방위적으로 체계화 분석한 보안 표준 팩트 규격이다.

</details>

| 장애/위험 요소 | 원인 분석 | 실무 대책 및 해결방안 | 기대 효과 |
|:---|:---|:---|:---|
| **생성형 AI 모델 특화 서비스 거부 방어 표준 통제 미비** | 기존 웹 WAF 정책만 맹신하고 AI 런타임 제약 가이드 부재 | 글로벌 **OWASP LLM10:2025** 규격 및 **NIST AI 도메인 방어 분류** 기준 전면 도입 | 전사 LLM 인프라 및 클라우드 서비스의 토큰/연산 비대칭 거부 위험 대응 거버넌스 팩트 확립 |
| **단 1건의 악의적 고비용 장문 프롬프트에 의한 GPU 인스턴스 마비** | 단순 RPS 제한만 존재하고 토큰 길이 비례 입장 통제 누락 | 토큰 비용 비례 **가중 쿼터(TPM)** 할당, Max Token 하드 제한 및 사전 **비용 추정기** 팩트 가동 | 비대칭 고비용 입력의 무단 GPU 큐 진입 사전 원천 차단 및 선량한 멀티 테넌트 공정성 보호 |
| **에이전트 자율 툴 연동 시 무한 루프 파이프라인으로 인한 과금 폭탄** | 백그라운드 반복 실행의 런타임 개입 타임아웃 룰 부재 | Max Iteration 허용치 엄격 설정, 이상 폭주 차단 **회로 차단기**, 자원 고갈 시 임시 **축소 응답** 제공 | 런타임 클라우드 과금 이상 폭주 완전 차단 및 장애 임계 초과 시에도 하위 모델 스위칭으로 팩트 가용성 유지 |

#### 한줄 요약

- OWASP LLM10:2025 표준 지침 철저 준수, TPM 비례 가중 쿼터 계측, 강제 Max Token 제한 제동 및 런타임 Circuit Breaker 차단막을 팩트 적용한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **비용 기반 가용성 통제 (Cost-aware Availability Governance)**: 무의미한 단순 HTTP 요청 건수 차단이 아니라, 실제 런타임 처리 토큰 수량, GPU 연산 점유 시간, 외부 써드파티 API 결제 과금액을 모두 실시간 단위로 정량 측정 종합하여 AI 서비스 가용성과 재무 예산을 사수하는 핵심 운영 팩트 원칙이다.

</details>

- AI 자원 보호를 위해 고비용 요청 차단을 위한 사전 **가중 쿼터(TPM)** 검문소와, 악성 반복 에이전트 호출을 끊어버리는 런타임 **회로 차단기** 이중 락 적용이 팩트 필수이다.

#### 한줄 요약

- OWASP LLM10 글로벌 규제 준수, TPM 사전 가중 쿼터, 에이전트 Max Iteration 제한 한도, 긴급 회로 차단기(Circuit Breaker) 도입 및 비용 기반 가용성 팩트 통제 아키텍처 체계 구축 필수.
