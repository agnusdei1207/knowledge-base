## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **API(Application Programming Interface)** 는 서비스 기능과 데이터를 정해진 요청•응답 형식으로 제공하는 경계다.
- **모델 추출 공격** 은 대상 모델 API의 입출력을 반복 수집해 기능이나 판단 경계를 모방하는 공격이다.
- **대상 모델** 은 공격자가 기능과 판단 경계를 복제하려는 원본 모델이다.
- **대리 모델** 은 수집한 응답으로 원본과 비슷한 판단을 하도록 학습한 모델이다.

</details>

- 정의/개념: **모델 추출 공격** 은 반복 질의로 원본 모델의 기능과 판단 경계를 복제하는 공격
- 배경/필요성: 상세 출력 API의 **지식재산 노출**

#### 한줄 요약

- 경쟁 모델에 영리하게 고른 문제를 많이 내고 답을 모아 원본과 비슷하게 판단하는 모방 모델을 학습한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **결정 경계** 는 모델의 예측 결과가 다른 범주로 바뀌는 입력 공간의 경계다.
- **능동 질의** 는 결정 경계 주변의 정보량이 큰 입력을 선택해 판단 규칙을 좁히는 방식이다.
- **워터마크** 는 모델 출력에 소유권을 식별할 수 있는 숨은 반응 신호를 넣는 통제다.
- **행위 분석** 은 계정•입력 분포•호출 패턴에서 비정상 복제 시도를 찾는 통제다.

</details>

- 능동 질의의 **결정 경계 탐색**
- 상세 출력의 **복제 효율 증가**
- 행위 분석•워터마크의 **탐지•귀속**

#### 한줄 요약

- 라벨만 제공할 때보다 확률•임베딩•설명까지 제공할 때 적은 질의로 원본 모델의 판단 규칙을 더 정확히 복제할 수 있다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **질의 생성기** 는 대상 모델의 결정 경계를 잘 드러내는 입력을 합성한다.
- **대리 학습기** 는 대상 모델의 응답으로 대리 모델의 판단 규칙을 갱신한다.
- **충실도**: 대리 모델과 대상 모델이 같은 입력에 동일하게 판단하는 정도이다.

</details>

```text
모델 추출 경계
├─ 서비스 측
│  ├─ 대상 모델 API
│  └─ 질의•응답 경계
├─ 공격 측
│  ├─ 질의 생성기
│  └─ 대리 모델 학습기
└─ 방어 측
   └─ 남용 탐지•귀속
```

선의 의미: 대상 모델 API와 질의•응답 경계에 공격 측 질의•학습 기능과 방어 측 남용 탐지•귀속 기능이 맞닿는 구조를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 대상 모델 API | **라벨•점수•임베딩** 제공 |
| 질의•응답 경계 | **신원•목적•한도•출력** 통제 |
| 질의 생성기 | **결정 경계 탐색 입력** 생성 |
| 대리 모델 학습기 | 입출력으로 **판단 규칙 근사** |
| 남용 탐지•귀속 | **비정상 질의•복제 증거** 분석 |

#### 한줄 요약

- 공격자는 정보량이 큰 입력을 골라 응답을 축적하고 대리 모델을 학습하며 방어자는 API 경계에서 이 반복 패턴을 탐지한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **불일치 경계 탐색**: 대리 모델과 대상 모델의 답이 다른 구간을 다시 질의하여 복제 효율을 높이는 능동 학습 과정이다.
- **카나리 입력**: 복제 모델이나 남용 계정이 특별한 반응을 보이도록 설계하여 소유권과 공격 경로를 탐지하는 시험 입력이다.

</details>

```text
경계 탐색 목표
       |
       v
1. 정보량 높은 질의 합성
       |
       v
대상 모델 질의 ──> 모델 응답
       ^                 |
       |                 v
       +── 2. 대리 모델 학습•경계 탐색
             | 불일치: 반복
             | 경계 근사 완료
             v
3. 반복 패턴 탐지
             |
             v
4. 워터마크•카나리 귀속
             |
             v
          남용 판정
```

**동작 원리**

1. **정보량 높은 질의 합성**: 불확실 경계 입력 선택
2. **대리 모델 학습•경계 탐색**: 입출력 쌍으로 판단 규칙을 근사하고 불일치 경계 확인
3. **반복 패턴 탐지**: 계정•입력 분포•호출률 분석
4. **워터마크•카나리 귀속**: 복제 반응과 소유 증거 대조


#### 한줄 요약

- 대리 모델이 원본과 다르게 답한 구간을 다시 질의하면 적은 호출로도 결정 경계를 효율적으로 좁힐 수 있다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **라벨 기반 추출** 은 모델의 최종 예측 결과만 수집해 대리 모델을 학습하는 유형이다.
- **점수 기반 추출** 은 클래스별 확률이나 신뢰도까지 수집하는 유형이다.
- **상세 출력 기반 추출** 은 임베딩•설명처럼 풍부한 내부 표현을 수집하는 유형이다.

</details>

| 모델 추출 유형 | 라벨 기반 | 점수 기반 | 상세 출력 기반 |
|:---|:---|:---|:---|
| 적용 기준 | **최소 출력 서비스** | **확률 제공 서비스** | **임베딩•설명 API** |
| 핵심 특징 | **최종 결과 수집** | **확률•신뢰도 수집** | **표현•설명 수집** |
| 한계 | **많은 질의 필요** | **신뢰도 출력 접근 필요** | **임베딩•설명 접근 필요** |

#### 한줄 요약

- 출력 정보가 풍부할수록 정상 사용에는 편리하지만 공격자의 모방 학습 비용도 낮아진다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **NIST(National Institute of Standards and Technology)** 는 미국의 기술 표준과 지침을 개발하는 기관이다.
- **AI(Artificial Intelligence) 100-2e2025** 는 모델 추출 공격의 지식과 질의 접근 수준을 체계화한 보고서다.
- **호출률 제한** 은 사용자별 모델 요청 횟수와 속도를 제한해 대량 경계 탐색 비용을 높인다.
- **분포 분석** 은 정상 사용과 다른 입력 분포를 식별해 능동 질의 패턴을 탐지한다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **추출 공격 분류 누락** | **NIST AI 100-2e2025 적용** | **지식•접근별 시험 체계화** |
| **대량 경계 탐색** | **호출률 제한•분포 행위 분석** | **능동 질의 비용 증가** |
| **복제 입증•귀속** | **워터마크•카나리 입력 검증** | **소유권 증거•남용 탐지** |

#### 한줄 요약

- 고가 모델 API는 사용자별 호출률뿐 아니라 불확실 경계를 훑는 입력 분포를 탐지하고 카나리 반응으로 복제 모델을 식별한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **복제 비용** 은 공격자가 모델을 모방하는 데 필요한 질의•시간•자원 규모다.
- **귀속** 은 워터마크•카나리 반응으로 복제 모델의 출처와 소유권을 입증하는 능력이다.

</details>

- 출력 정보량•경계 질의가 높으면 **출력 최소화•호출률 제한** 적용

#### 한줄 요약

- 모델 추출 방어는 정상 사용에 필요한 출력은 유지하면서 자동화된 경계 탐색의 비용을 높이고 복제 증거를 남기는 것이다.
