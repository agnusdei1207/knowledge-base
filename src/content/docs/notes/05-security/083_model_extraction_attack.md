## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **모델 추출 공격(Model Extraction Attack / Model Stealing / NIST AI 100-2e2025)**: 공격자가 상용 AI 모델(Target Model)의 공개 추론 API에 대량의 질의(Query)를 능동적으로 전송하고 반환되는 라벨, 정밀 확률(Softmax), 임베딩 벡터를 수집하여, 원본 모델과 동일한 결정 경계(Decision Boundary)와 성능을 갖는 대리 모델(Surrogate Model)을 저비용으로 불법 복제해 내는 AI 지적재산권(IP) 탈취 공격.
- **MLaaS 환경의 지적재산권 노출 결함(API-based Intellectual Property Leakage Defect)**: 수억 달러의 컴퓨팅 비용과 독점 데이터셋으로 학습된 상용 파운데이션 모델이 API 형태로 무방비 노출되어, 공격자가 지식 증류(Knowledge Distillation) 기법을 악용해 원본 모델의 가치와 경쟁력을 무단 약탈하는 구조적 취약점.

</details>

- 정의/개념: API 질의로 대리 모델을 복제하는 **모델 추출 공격** 방어
- 배경/필요성: 수백억 원의 컴퓨팅 비용과 독점 데이터셋으로 개발된 상용 파운데이션 모델이 공개 추론 API(MLaaS) 형태로 노출될 때, 공격자가 지식 증류(Knowledge Distillation) 및 능동 학습(Active Learning) 기법을 악용하여 대량의 정밀 확률(Softmax)과 임베딩 벡터를 수집함으로써 원본과 대등한 결정 경계를 갖는 대리 모델(Surrogate Model)을 저비용으로 불법 복제하는 AI 지적재산권(IP) 침해 위협이 발생함에 따라, NIST AI 100-2e2025 표준에 기반하여 추론 출력 최소화(Top-1 Hard Label), OOD(분포 외 데이터) 이상 탐지, API 질의 예산 관리 및 암호학적 모델 워터마킹(Model Watermarking)을 결합하는 모델 추출 방어 아키텍처를 도입하여 불법 복제 경제성의 원천 파괴(Cost Inflation), 정밀 피드백 차단 및 사후 법적 소유권(Attribution) 증명 능력을 달성할 필요

#### 한줄 요약
- 상용 API 질의-응답 데이터를 수집해 모델을 복제하는 공격을 막기 위해 출력 최소화와 OOD 탐지 및 모델 워터마킹을 적용한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **능동 질의 합성(Active Learning Query Generation)**: 단순 무작위 질의 대신, 대상 모델의 결정 경계(Decision Boundary) 근처에 위치한 불확실성 높은 샘플만을 인공적으로 합성 질의함으로써 질의 횟수를 $10^6$회에서 $10^4$회 수준으로 획기적으로 줄여 복제 효율을 극대화하는 기법.
- **모델 워터마킹(Model Watermarking & Canary Inputs)**: 모델 학습 시 특정 트리거 입력(예: 미세 노이즈 패턴)에 대해 고유한 시그니처 응답을 출력하도록 각인하여, 사후에 도난당한 대리 모델이 유통될 때 소유권과 도용 사실을 법적으로 입증하는 사후 귀속(Attribution) 기술.

</details>

- 반환 데이터 정밀도에 비례하는 탈취 속도: Top-1 라벨만 반환할 때보다 정밀 Softmax 확률이나 내부 임베딩(Logits)을 제공할 때 복제 충실도(Fidelity)가 급상승
- 복제 경제성 파괴 전략 (Stealing Cost Inflation): 기술적으로 100% 차단이 불가능하므로, 호출 비용 및 지연을 증대시켜 대리 모델 생성 비용이 원본 개발 비용보다 커지도록 유도
- 사후 법적 귀속성(Attribution) 보증: 카나리(Canary) 데이터셋을 모델에 심어 경쟁사가 복제 모델을 출시했을 때 법적 소송에서 도용 사실을 무결하게 증명

#### 한줄 요약
- 능동 질의 고효율 복제, 반환 데이터 정밀도 의존성, 복제 경제성 파괴, **모델 워터마킹** 기반 사후 귀속을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **모델 추출 공격 및 방어 4대 컴포넌트**:
  1. **Active Query Synthesizer (공격자)**: 경계 탐색용 고가치 합성 질의 생성기.
  2. **Surrogate Model Trainer (공격자)**: 증류 손실(KL Divergence)을 최적화하는 대리 모델 학습기.
  3. **Inference Security Gateway (방어자)**: OOD 이상 탐지 및 Softmax 은닉 게이트웨이.
  4. **Watermark & Canary Embedder (방어자)**: 백도어 기반 소유권 검증 핑거프린트 주입기.

</details>

```text
[모델 추출 공격 방어 체계]
├─ 추론 보안 게이트웨이 계층
│  ├─ 출력 최소화기 (Top-1 Hard Label 변환)
│  ├─ 점수 양자화 (Softmax 확률 은닉)
│  ├─ 질의 예산 관리자 (호출률 통제)
│  └─ OOD 분포 이상 탐지기 (합성 질의 차단)
├─ 모델 보호 및 워터마크 계층
│  ├─ 모델 가중치 암호학적 워터마킹
│  └─ 트리거 기반 카나리(Canary) 데이터셋 주입
└─ 사후 소유권 검증 계층
   ├─ 의심 복제 모델 핑거프린트 질의
   └─ 법적 귀속성(Attribution) 입증
```

- 선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 능동 질의 합성기 | 모델 결정 경계 추정에 필요한 불확실성 높은 데이터를 인공 생성하여 API 전송 |
| 대리 모델 학습기 | 수집된 질의-응답 페어로 학생 모델을 학습시켜 원본 모델의 기능을 복제 |
| 추론 보안 게이트웨이 | API 호출률 제한(Rate Limit) 및 Softmax 확률 벡터를 은닉하는 출력 최소화 집행 |
| OOD 분포 이상 탐지기 | 자연스러운 사용자 입력이 아닌 기계적 합성 질의(Out-of-Distribution)를 식별 및 차단 |
| 워터마크/카나리 엔진 | 모델 가중치에 고유 트리거 반응을 삽입하여 도용된 대리 모델의 소유권을 사후 입증 |

#### 한줄 요약
- 능동 질의 합성기, 대리 모델 학습기, 추론 보안 게이트웨이, OOD 이상 탐지기, 워터마크 엔진이 결합한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **모델 추출 공격 및 방어 5단계 생애주기**:
  1. 공격자가 결정 경계 추정을 위한 능동 질의 합성
  2. 대상 API에 수만 건의 질의 전송 및 피드백 수집
  3. 대리 모델 학습을 통한 원본 판단 경계 복제
  4. 보안 게이트웨이의 OOD 패턴 탐지 및 출력 양자화 발동
  5. 워터마크/카나리 질의를 통한 불법 복제 모델 적발 및 법적 제재

</details>

```text
1. [능동 질의 합성] 공격자가 원본 모델의 분류 경계를 파악하기 위해 정보량이 높은 합성 샘플 생성
            │
            ▼
2. [API 대량 질의 및 응답 수집 (취약 환경)]
    ├─ 공격자가 대상 API에 10만 건 질의 ➔ 정밀 Softmax 확률 수집
    └─ 대리 모델(Surrogate)을 학습시켜 원본 모델과의 예측 충실도(Fidelity) 99% 달성
            │
            ▼ (방어 아키텍처 가동 시)
3. [게이트웨이 OOD 탐지 및 출력 최소화]
    ├─ OOD 탐지기: 단시간 내 특정 결정 경계에 집중되는 비정상 질의 엔트로피 탐지
    └─ 출력 변환: Softmax 확률을 완전 차단하고 Top-1 Hard Label만 지연 반환 (복제 비용 급증)
            │
            ▼
4. [워터마크 가중치 전이] 만약 공격자가 대리 모델을 완성하더라도 원본에 심긴 백도어 워터마크가 대리 모델로 전이 복제됨
            │
            ▼
5. [사후 소유권 검증 및 제재]
    ├─ 방어자가 의심되는 경쟁사 모델에 카나리 입력(특정 키워드) 주입
    └─ [사전에 정의된 고유 서명 응답 출력 확인 ➔ 불법 도용 법적 입증 및 서비스 차단]
```

1. **능동 질의 합성**
2. API 대량 질의 및 응답 수집
3. 게이트웨이 OOD 탐지 및 출력 최소화
4. 워터마크 가중치 전이
5. 사후 소유권 검증 및 제재

#### 한줄 요약
- 출력 정밀도를 낮출수록 복제 비용은 오르지만 정상 이용자의 활용도도 함께 떨어지므로, 사전 차단으로 막지 못하는 몫은 워터마크라는 사후 귀속 수단으로 넘긴다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **모델 추출 공격 3대 방식 비교**: 라벨 기반(Label-only), 점수 기반(Soft-label), 상세 임베딩 기반(Rich Output)의 비교.

</details>

| 비교 항목 | 라벨 기반 추출 (Label-only) | 점수 기반 추출 (Soft-label) | 상세 임베딩 추출 (Rich Output) |
|:---|:---|:---|:---|
| 수집 반환 정보 | Top-1 클래스 이름 (예: "Cat") | 각 클래스별 정밀 Softmax 확률 벡터 | 내부 임베딩 벡터, Logits, XAI 맵 |
| 요구 질의 횟수 | 매우 많음 ($10^6$ 건 이상) | 중간 ($10^4 \sim 10^5$ 건 수준) | 최소 ($10^3$ 건 수준으로 즉시 복제)|
| 대리 모델 충실도| 보통 (결정 경계 근사화 지연) | 높음 (오차 함수 직접 최적화) | 최상 (원본 지식 표상 통째 복사) |
| 핵심 방어 대책 | 질의 예산 통제 (Rate Limiting) | 점수 양자화(Rounding), 확률 은닉 | 출력 최소화, 디버깅 모드 전면 차단|

#### 한줄 요약
- Label-only는 질의가 많이 필요, Soft-label은 고속 복제, Rich Output은 즉각 복제되므로 출력을 엄격히 제한해야 한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **NIST AI 100-2e2025 (Privacy in AI)**: AI 모델의 지적재산권(IP) 보호, 모델 추출(Stealing) 방어 및 API 거버넌스 표준 가이드라인.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 수백억 원을 투입한 상용 AI 모델의 공개 API에 대량 질의가 유입되어 경쟁사가 동일한 성능의 대리 모델(Surrogate)을 불법 복제 | **NIST AI 100-2e2025** 기준, 출력 최소화(Top-1 Hard Label 반환) 및 점수 양자화(Rounding) 적용 | 대리 모델 복제에 필요한 정보량 99% 차단 및 복제 충실도(Fidelity) 급감 |
| 능동 학습(Active Learning) 스크립트 봇이 경계 탐색 질의를 난사하여 최단 시간에 최소 비용으로 모델을 추출하는 공격 | API 게이트웨이 단에서 질의 예산(Rate Limiting) 관리 및 OOD(분포 외 질의) 엔트로피 이상 탐지 도입 | 무차별 능동 합성 질의 100% 선제 차단 및 공격자의 추출 비용 극대화 |
| 경쟁사가 추출된 대리 모델을 자체 상용 서비스로 출시했으나 원본 모델을 도용했음을 기술적으로 입증하지 못하는 법적 한계 | 원본 모델 학습 시 암호학적 모델 워터마킹(Model Watermarking) 및 카나리(Canary) 데이터셋 사전 주입 | 도난당한 대리 모델에 대한 100% 확실한 법적 소유권 입증 및 침해 승소 보장 |

#### 한줄 요약
- 출력 최소화로 복제를 막고, OOD 탐지로 봇을 차단하며, 워터마크로 사후 법적 소유권을 입증한다.

## Ⅶ. 결론

- 상용 AI 서비스의 핵심 자산인 모델 가중치와 결정 경계의 무단 복제를 방지하고 기업의 AI 지적재산권을 보호하는 AI 모델 거버넌스 및 자산 보호(NIST AI 100-2e2025 / Model IP Protection)의 핵심 통제 체계로 확고히 자리 잡았으며, 다중 쿼리 핑거프린팅 및 동적 노이즈 주입 기술로 진화하는 가운데, 실무 상용 MLaaS 플랫폼 구축 시에는 공개 추론 API에서 Softmax 확률 및 Logits 임베딩 반환을 차단하고 Top-1 Hard Label만 제공하는 출력 최소화 정책 강제, 능동 합성 질의 봇을 실시간 차단하는 OOD(분포 외 질의) 엔트로피 이상 탐지 게이트웨이 구축, 원본 모델 가중치에 트리거 기반 시그니처를 각인하는 암호학적 모델 워터마킹/카나리(Canary) 주입을 결합하여 완벽한 AI 지적재산권 무결성을 완성

#### 한줄 요약
- 출력 최소화와 OOD 탐지 및 모델 워터마킹을 결합하여 AI 모델의 지적재산권 도용을 완벽히 방어한다.
