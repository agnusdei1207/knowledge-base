## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **모델 추출 공격 (Model Extraction Attack / Model Stealing)**: 상용 API를 통해 대상 모델(Target Model)에 대량으로 질의하고 반환되는 라벨, 정밀 확률(Softmax), 임베딩을 이용해 동일한 추론 성능을 지닌 대리 모델(Surrogate Model)을 훔쳐 복제하는 심각한 IP 탈취 공격이다.
- **대상 모델 (Target Model / Teacher Model)**: 공격자가 수백만 달러의 학습 비용이 투입된 지적재산권(IP) 및 기능적 판단 경계를 훔치려는 원본 상용 AI 모델이다.
- **대리 모델 (Surrogate Model / Student Model)**: 공격자가 대상 모델의 질의-응답 데이터셋 페어를 기반으로 증강 학습시켜, 원본의 판단 경계를 99% 이상 복제해 낸 불법 스톨론(Stolen) AI 모델이다.

</details>

- 정의: 공개된 AI 추론 API에 대량의 질의를 전송하여 수집한 응답 데이터로 원본 모델의 **결정 경계**를 불법 모방 복제하는 자산 탈취 공격이다.
- 배경: 클라우드 기반 AI MLaaS(Machine Learning as a Service) 환경에서, 비용이 많이 드는 대형 모델 구축을 우회하기 위해 공격자가 공개 API의 상세 출력을 악용하여 **모델 IP**를 무단 탈취하려는 시도가 급증했기 때문이다.

#### 한줄 요약

- 상용 API를 대량 질의하여 수집한 데이터로 원본 AI 모델의 판단 경계와 지적재산권(IP)을 동일하게 복제하는 지향 자산 탈취 공격이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **결정 경계 (Decision Boundary)**: 고차원 특징 공간에서 딥러닝 모델이 특정 입력 데이터를 해당 클래스로 분류하는 기준이 되는 수학적 분류 경계면이다.
- **능동 질의 (Active Query / Active Learning Query)**: 무작위 질의 비용을 줄이기 위해, 결정 경계 근처의 불확실성이 높은 샘플만 인공적으로 선별 합성하여 질의함으로써 추출 효율을 극대화하는 알고리즘 수법이다.
- **워터마크 (Model Watermarking / Backdoor Watermark)**: 모델 최초 학습 시 무해한 특정 트리거 패턴에 고유 식별 반응을 출력하도록 암호학적 소유권 핑거프린트를 내부 가중치에 몰래 삽입하는 보호 기술이다.
- **행위 분석 (Behavioral Analytics / Anomaly Detection)**: 정상 사용자와 달리 API 요청 IP, 계정, 질의 텍스트의 엔트로피 분포가 이상한 패턴을 보이는 자동화 추출 봇을 선제적으로 탐지하는 모니터링 기법이다.

</details>

- **능동 질의 기반 고효율 복제**: 단순 무작위 질의가 아닌, 결정 경계 주변에 **능동 질의**를 집중 타격하여 최적의 데이터 비용(Query Efficiency)으로 대리 모델을 신속하게 동기화한다.
- **상세 출력 의존성**: 단순 Top-1 라벨만 반환하는 Hard-label 환경보다, 정밀 확률이나 내부 임베딩을 무방비로 제공하는 Soft-label 환경에서 복제 속도와 유사도가 비약적으로 상승한다.
- **법적 귀속(Attribution) 추적**: 공격 발생 자체를 물리적으로 100% 차단하기 어려우므로, **행위 분석** 관제와 **워터마크** 주입을 통해 복제 모델의 출처를 사후에 법적으로 증명 및 귀속(Attribution)한다.

#### 한줄 요약

- 결정 경계 타격 능동 질의, 상세 출력 피드백 기반 고속 복제 및 워터마크/행위 분석을 통한 사후 법적 귀속 관제 특성을 지닌다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **충실도 (Fidelity / Agreement Rate)**: 도난당해 학습된 대리 모델이 동일한 입력 데이터에 대해 원본 대상 모델과 완벽하게 일치하는 분류 결과를 내놓는 비율(%)을 측정한 정량 지표이다.

</details>

```text
[서비스 방어자 측]                        [악의적 공격자 측]
      |                                           |
      |                                           v
[대상 AI 추론 모델]                         [질의 데이터 합성 생성기]
      |                                           |
      v                                           |
[API 보안 통제 경계 레이어] <----(API 반복 질의)----+
      |                                           |
      v                                           |
[OOD 이상 탐지 및 귀속 엔진]                [도난 대리 모델 학습기]
```

| 구성요소 | 주요 책임 및 역할 | 비고 |
|:---|:---|:---|
| **대상 모델 API** | 클라우드 환경에서 **대상 모델**의 추론 결과를 REST API/gRPC 형태로 제공하는 엔드포인트 | Target Endpoint |
| **API 통제 경계** | Rate Limiting 적용, 불필요한 **출력 최소화**, API 키 기반 인증 및 접근 인가를 집행 | Defense Proxy |
| **질의 생성기** | 경계 추출 효율이 높은 **능동 학습 질의** 및 불확실성 매핑용 합성 데이터를 기계적으로 생성 | Attack Generator |
| **대리 학습기** | 수집된 양질의 라벨/확률 페어 데이터를 기반으로, 타깃의 **충실도(Fidelity)** 를 모방하는 모델 구조 복제 | Surrogate Trainer |
| **이상 탐지 및 귀속** | **행위 분석 엔진**의 자동 스캐닝 봇 탐지 및 내부 **워터마크** 반응 검증으로 도용 모델의 법적 소유권 입증 | Attribution |

#### 한줄 요약

- 질의 생성기의 집중 공격, 대리 학습기의 충실도 최적화, 그리고 방어 측의 경계 통제 및 워터마크 귀속 모듈로 대립 구성된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **불일치 경계 탐색 (Disagreement Boundary Search)**: 대리 모델과 대상 모델 간의 예측 결과가 서로 상충하는 고위험·고가치 영역의 질의만을 집중 생성하여 최단 시간에 복제 오차를 교정하는 능동 학습 방식이다.
- **카나리 입력 (Canary Inputs / Trapdoor Data)**: 원본 제조사가 의도적으로 삽입한 무의미하지만 특이한 함정 데이터로, 훗날 공격자가 대리 모델을 상용화했을 때 원본 도용 사실을 논박 불가능하게 증명하는 추적 데이터이다.

</details>

```text
[공격 목표: 모델 결정 경계 복제]
              |
              v
1. 능동 학습 기반 고가치 정보량 질의 합성 생성
              |
              +<-------------------------------------------+
              |                                            |
              v                                            |
[대상 모델 API 수만 회 질의] ──> 2. 결정 경계 근사 피드백 응답 반환
              |                                            |
              v                                            |
3. 수집 데이터 기반 대리 모델 반복 학습 및 불일치 오차 축소 ---+ (불일치 시 반복)
              |
              v (복제 충실도 임계치 도달)
              |
4. 단시간 대량 질의 OOD 반복 패턴 네트워크 이상 탐지
              |
              v
5. 적발 시 워터마크 및 카나리 입력 주입으로 원본 무단 도용 법적 귀속
              |
              v
[공격자 법적 제재 및 API 접근 영구 차단]
```

### 동작 원리

1. 질의 합성: 공격자가 모델 판단 경계 식별에 필요한 정보량이 가장 높은 질의를 합성한다.
2. 경계 피드백: 대상 모델 API가 질의에 대한 상세 확률 및 라벨 예측치를 반환한다.
3. 모델 복제: 수집된 질의-응답 쌍으로 대리 모델을 반복 학습시켜 원본과의 예측 오차를 축소한다.
4. 패턴 탐지: 방어 시스템이 API 요청자의 비정상적 합성 입력 질의 분포를 모니터링한다.
5. 소유권 귀속: 의심스러운 유출 모델에 카나리 데이터를 주입하여 무단 복제 여부를 입증한다.

#### 한줄 요약

- 능동 학습 질의 합성, 대상 응답 수집, 대리 모델 불일치 경계 학습, 탐지 엔진 패턴 적발 및 워터마크 법적 귀속 단계로 전개된다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **라벨 기반 추출 (Label-only Extraction Attack)**: 방어된 시스템에서 Top-1 클래스 라벨 이름만 단순 제공할 때, 수백만 개의 무차별 0/1 바이너리 질의를 투입하여 느리게 복제하는 공격 방식이다.
- **점수 기반 추출 (Score-based / Soft-label Extraction Attack)**: API가 제공하는 클래스별 정밀 확률 벡터(Softmax)를 모두 수집하여, 오차 손실 함수(KLDiv 등)를 수학적으로 직접 줄여 고속 복제하는 강력한 공격 방식이다.
- **상세 출력 기반 추출 (Rich Output / Embedding Extraction Attack)**: 백엔드 임베딩 벡터, Logits, XAI 피처 맵 등 디버깅용으로 노출된 심층 모델 내부 표현 데이터까지 수집하여 모델 구조를 통째로 복사하는 가장 치명적인 공격 방식이다.

</details>

| 추출 공격 방식 | **라벨 기반 추출 (Label-only)** | **점수 기반 추출 (Soft-label)** | **상세 출력 추출 (Rich Output / Embedding)** |
|:---|:---|:---|:---|
| 수집 반환 정보 형태 | 오직 Top-1 클래스 이름 반환 (예: "Cat") | 각 분류별 0~1 사이의 정밀 확률 벡터 전체 제공 | 핵심 임베딩 벡터, Logits, 설명 가능성(XAI) 맵 출력 |
| 복제 요구 질의 수 | 경계 탐색을 위해 무수히 많음 ($10^6$ 이상 질의) | 확률 최적화로 획기적 단축 ($10^4 \sim 10^5$ 질의 수준) | 내부 표상을 직접 복사하므로 최소 질의 ($10^3$ 수준) |
| 대리 모델 복제 충실도 | 보통 수준 (결정 경계 추정에 막대한 시간/비용 소요) | 높음 수준 (정밀 오차 함수 최적화로 복제 가속화) | 최고 수준 (원본 모델의 내부 지식 표상까지 완벽 모방) |
| 핵심 대응 통제 기술 | API 접근 권한 제어, 엄격한 **질의 예산 (Rate Limit)** 제한 | **점수 양자화(Rounding)** 적용, 불필요한 확률 은닉 | 절대적인 **출력 최소화** 정책 집행, 디버깅 모드 차단 |

#### 한줄 요약

- 라벨 단순 기반, 정밀 확률 점수 기반(Soft-label), 상세 출력 임베딩 기반으로 나뉘며, API 반환 데이터가 정밀할수록 복제 위험이 치솟는 특성을 띤다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **NIST AI 100-2e2025 (Privacy in AI)**: AI 모델의 지적재산권(IP) 추출, 프라이버시 침해, 차분 보안 통제를 다룬 미국 국립표준기술연구소의 규격이다.
- **호출률 제한 (Rate Limiting / Query Budgeting)**: 단일 사용자, IP, API 키별로 단위 시간당 허용되는 질의 횟수 및 일일 예산을 엄격히 통제하여 무차별 추출을 지연시키는 기술이다.
- **분포 이상 탐지 (OOD Detection / Out-of-Distribution)**: API에 유입되는 질의 텍스트가 자연스러운 인간의 언어 분포를 벗어나 인공적으로 합성된 탐색 패턴(OOD)인지 파악하는 머신러닝 탐지 기법이다.

</details>

| 장애/위험 요소 | 원인 분석 | 실무 대책 및 해결방안 | 기대 효과 |
|:---|:---|:---|:---|
| **천문학적 비용의 AI 모델 IP 추출 무방비 노출** | 방어 관점의 통제 아키텍처 가이드라인 부재 | **NIST AI 100-2e2025** 규격 지침 전사 적용 | 상용 모델 추출 및 자산 탈취 위험에 대한 체계적 평가 거버넌스 정착 |
| **능동 학습 기반 합성 스크립트 봇의 대량 질의** | API 무제한 호출 허용 및 패턴 모니터링 누락 | 엄격한 **호출률 제한(Rate Limit)** 및 **OOD 분포 이상 탐지** | 자동화된 추출 봇의 경제성을 파괴하고 능동 학습 질의 시도 원천 원천 차단 |
| **추출되어 상용화된 도용 모델에 대한 귀속 입증 불가** | 원본 모델 가중치에 소유권 증빙 장치 부재 | 학습 시 모델 가중치 내 **워터마크** 및 **카나리 데이터** 사전 주입 | 경쟁사에 의해 탈취된 스톨론(Stolen) 모델의 불법 복제 법적 소유권 증명 보장 |

#### 한줄 요약

- NIST AI 100-2e2025 준용, API 호출률 강력 제한, OOD 이상 분포 분석, 사전 워터마크/카나리 기법을 연동하여 모델 IP를 철벽 방어한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **복제 경제성 파괴 (Stealing Cost Maximization)**: 모델 추출 공격을 기술적으로 100% 막는 것이 불가능하므로, API 응답 지연, 출력 은닉, Rate Limit을 복합 적용해 공격자가 대리 모델을 구축하는 비용이 원본 모델을 직접 개발하는 비용보다 더 비싸지게 만드는 보안 방어 전략이다.

</details>

- 모델 자산 보호를 위해 API는 반드시 **출력 최소화** 및 OOD 탐지를 강제하고, 모델 내부에는 **워터마크**를 각인하여 **복제 경제성 파괴** 중심의 IP 방어 거버넌스 확립 필수이다.

#### 한줄 요약

- NIST 표준 준수, API 출력 정밀도 은닉, 쿼리 Rate Limiting 억제, OOD 행위 관제 및 워터마크 기반 사후 법적 귀속 모델 도용 방어 아키텍처 필수.
