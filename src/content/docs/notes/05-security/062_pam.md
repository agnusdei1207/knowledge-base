## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **특권 접근 관리(Privileged Access Management, PAM)**: 시스템 관리자 계정의 자격 증명, 접속 경로, 작업 세션을 승인 기반으로 중앙 통제·감사하는 보안 체계이다.
- **특권 계정(Privileged Account)**: 시스템 설정, 서비스 제어, 보안 정책 변경 권한을 보유한 루트(root) 및 관리자 계정이다.

</details>

- 정의/개념: 특권 자격•세션•작업을 통제하는 **PAM**
- 배경/필요성: 공유 특권은 **오남용•횡적 이동•감사 공백** 유발

#### 한줄 요약

- 관리자 패스워드의 직접 노출을 차단하고 승인된 작업에 한해 단기 자격 증명을 주입하여 세션 및 명령을 통제한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **비밀 금고(Secret Vault)**: 특권 비밀번호 및 암호화 키를 중앙에서 보안 보관하고 주기적으로 일회용 교체(회전)하는 암호화 저장소이다.
- **세션 중계(Session Proxy / Session Broker)**: 사용자에게 자격 증명을 직접 노출하지 않고 중계 서버를 거쳐 대상 시스템에 접속시키는 제어 기술이다.
- **적시 최소 특권(Just-In-Time Least Privilege, JIT)**: 작업 승인 시점에만 최소한의 특권 자격을 임시 부여하고 작업 완료 후 즉시 회수하는 방식이다.
- **지속 발견(Continuous Discovery)**: 인프라 내 숨겨진 특권 계정, 서비스 계정 및 PAM 우회 접속 경로를 자동 탐지·식별하는 기능이다.

</details>

- **지속 발견**으로 인프라 전반의 미관리 특권 계정 및 우회 경로를 식별한다.
- **비밀 금고**와 **세션 중계**를 조합하여 관리자의 비밀번호 직접 접근을 완전 차단한다.
- **JIT 최소 특권** 원칙으로 영구적인 상시 관리자 권한 남용 가능성을 근본 제거한다.

#### 한줄 요약

- 승인된 통로로만 대상 시스템 접속을 허용하여 관리자 행위에 대한 명확한 개별 식별성과 책임 추적성을 확보한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **비밀 회전(Secret Rotation)**: 세션 종료 또는 일정 주기마다 특권 비밀번호를 자동으로 난수화하여 재사용을 차단하는 통제이다.
- **세션 증적(Session Audit Log)**: 관리자 작업 중 입력된 명령어, 화면 캡처, 키로깅 데이터를 암호화하여 보존한 감사 기록이다.

</details>

```text
[특권 접근 관리(PAM)]
   |
   +-- [특권 발견·분류]
   +-- [요청·승인]
   +-- [비밀·키 금고]
   +-- [세션 중계]
   `-- [회수·감사]
```

선의 의미: 특권 식별, 승인 통제, 자격 암호화, 세션 중계 및 사후 감사로 이어지는 PAM의 중앙 통제 구조이다.

| 구성요소 | 책임 |
|:---|:---|
| 특권 발견·분류 | 미관리 계정•암호화 키•우회 경로 자동 식별 |
| 요청·승인 | 작업 타당성•사유•대상 시스템•사용 시간 승인 |
| 비밀·키 금고 | **비밀 금고** 내 자격 증명 보안 보관 및 **비밀 회전** |
| 세션 중계 | **세션 중계**를 통한 직접 접속 차단 및 위험 명령 통제 |
| 회수·감사 | 작업 종료 후 자격 회수 및 **세션 증적** 위변조 방지 보관 |

#### 한줄 요약

- 특권 계정을 금고에 격리하고 승인된 작업 세션만 중계하며, 종료 즉시 자격 회수 및 감사 증적을 보존한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **직무 분리(Separation of Duties, SoD)**: 특권 요청자, 승인자, 실행자를 분리하여 단독 권한 남용을 방지하는 원칙이다.
- **명령 통제(Command Control)**: 세션 내 위험 명령어(예: rm -rf, drop table 등) 실행을 블랙리스트/화이트리스트 기반으로 즉시 차단하는 기술이다.
- **신원•승인•위험 판정(Identity/Approval/Risk Evaluation)**: 요청자의 신원, 사전 승인 여부, 작업의 위험도를 평가하는 단계이다.
- **JIT 자격 증명 생성(JIT Credential Generation)**: 승인된 범위와 유효기간에 부합하는 일회성 임시 자격을 발급하는 단계이다.
- **비밀 주입•세션 결속(Secret Injection & Session Binding)**: 자격 노출 없이 중계 서버가 대상 시스템에 자격을 대신 주입하고 세션을 바인딩하는 단계이다.
- **명령 통제•세션 기록(Command Control & Session Recording)**: 허용된 명령어만 실행 허용하고 작업 화면 및 텍스트를 실시간 녹화하는 단계이다.
- **권한 회수•비밀 회전(Revocation & Secret Rotation)**: 작업 완료 후 임시 권한을 즉시 폐기하고 비밀번호를 자동 재설정하는 단계이다.

</details>

```text
[관리자]
    |
    `-- 목적·대상·시간 작업 요청
                 |
                 v
[PAM 요청·승인]
    |
    v
1. 신원·승인·위험 판정
    |
    v
[비밀·키 금고]
    |
    v
2. JIT 자격 증명 생성
    |
    v
[PAM 세션 중계]
    |
    v
3. 비밀 주입·세션 결속
    |
    v
4. 명령 통제·세션 기록
    |
    v
[대상 시스템의 통제 작업]
    |
    `-- 세션 종료 상태
                 |
                 v
5. 권한 회수·비밀 회전
    |
    `-- 작업 종료 결과 ----> [관리자]
```

### 동작 원리

1. 신원•승인•위험 판정: 직무 분리•작업 영향도 평가
2. JIT 자격 증명 생성: 유효시간 제한 특권 자격 발급
3. 비밀 주입•세션 결속: 자격 비노출 세션 중계
4. 명령 통제•세션 기록: 위험 명령 차단•감사 로그 보존
5. 권한 회수•비밀 회전: 세션 종료 즉시 자격 폐기•회전

#### 한줄 요약

- 직무 분리와 명령 통제를 적용해 작업을 실시간 제어·기록하고 종료 시 자격 회수 및 비밀번호 회전을 완결한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **금고형 특권(Vault-based Privilege)**: 기존 공유 관리자 계정의 패스워드를 비밀 금고에 보관하고 작업 시 일시 대여하는 방식이다.
- **비상 접근(Emergency Access / Break-Glass)**: 장애 등 긴급 상황 시 사전 승인을 우회하되 강력한 사후 감사를 조건으로 작동하는 비상 대여 절차이다.

</details>

| 특권 관리 유형 | 중앙 통제 PAM | 공유 상시 계정 | 금고형 계정 대여 | JIT 최소 특권 |
|:---|:---|:---|:---|:---|
| 적용 기준 | 고위험 인프라 통합 관리 | 소규모•초기 통제 환경 | 기존 시스템 일시 적용 | 클라우드•자율 운영 환경 |
| 핵심 특징 | **PAM** 중심 전주기 통합 통제 | 단일 패스워드 공유 사용 | **금고형 특권** 기반 비밀 대여 | **JIT 최소 특권**의 동적 권한 발급 |
| 한계 | 중계 서버 장애 시 영향 | 자격 탈취•추적 불가•남용 | 공유 계정 구조적 한계 존재 | **비상 접근** 정책 정의 복잡성 |

#### 한줄 요약

- PAM은 패스워드 대여를 넘어 승인, 중계, 명령 제어, 세션 녹화, 비밀 회전을 결합하여 JIT 최소 특권 체계로 진화한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **NIST SP 800-53 Rev. 5**: 미국 NIST의 보안 통제 항목 표준으로 특권 계정 관리, 최소 권한 및 세션 통제 지침을 포함한다.
- **ISO/IEC 27002:2022 통제 8.2**: 특권 접근권의 할당 및 사용을 제한하고 엄격히 관리하도록 정의한 국제 정보보안 통제 항목이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 특권 계정 통제 표준 미비 | **NIST SP 800-53 Rev. 5** 지침 반영 | 계정•세션•감사 통제의 체계적 정렬 |
| 특권 접근 관리 누락 | **ISO/IEC 27002:2022 통제 8.2** 적용 | 특권 할당•검토•회수의 법적 및 절차적 책임 명확화 |
| PAM 중앙 장애 및 우회 | 게이트웨이 다중화 및 직접 접속 차단 | 서비스 연속성 보장 및 통제 회피 시도 근본 차단 |

#### 한줄 요약

- 관리자는 PAM 게이트웨이를 거쳐 접근하며, 직접 패스워드 주입 없이 세션 녹화 및 명령어 통제 하에 안전하게 작업을 수행한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **특권 책임 추적성(Privileged Account Traceability)**: 모든 최고 권한 작업을 실제 작업자 개인, 승인 이력, 시간, 실행 결과와 1:1 매핑하여 사후 법적·감사적 입증을 가능하게 하는 성질이다.

</details>

- **특권 책임 추적성** 확보를 위해 일반 특권은 **PAM**, 자동화 작업은 **JIT**, 비상 상황은 **비상 접근** 수립 체계를 적용한다.

#### 한줄 요약

- 일반 특권은 **PAM**, 자동 작업은 **JIT**, 비상은 Break-Glass
