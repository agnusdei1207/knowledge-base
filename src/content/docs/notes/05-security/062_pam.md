## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **PAM**: 높은 권한의 계정·자격 증명·접속·세션을 작업 단위로 집중 통제하는 체계이다.
- **특권 계정**: 시스템 설정·계정·보안 통제를 변경할 수 있는 높은 권한 계정이다.

</details>

- 정의/개념: **PAM**은 관리자·시스템 같은 특권 계정의 자격 증명을 보관·회전하고 사용 승인·세션 기록·권한 회수를 통제하는 보안 관리 체계
- 배경/필요성: 상시 공유 권한으로 **탈취·부인·잔존**

### 쉽게 이해하기 (학습용)

- 관리자 열쇠를 계속 나눠 갖지 않고 작업자와 목적을 확인한 뒤 필요한 시간과 기능만 열어 주고 사용 후 회수한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **비밀 금고·세션 중계**: 비밀 금고는 특권 비밀번호와 키를 암호화해 보관·회전하고 세션 중계는 자격 증명을 노출하지 않은 채 접속을 통제한다.
- **JIT 최소 특권**: 승인된 작업 시간에만 필요한 최소 범위의 특권을 발급하고 종료 후 자동 회수하는 방식이다.

</details>

- **지속 발견**: 특권 계정·비밀·우회 경로 식별
- **비밀 비노출 통제**: 금고·세션 중계로 직접 열람 차단
- **최소 특권·책임 추적**: JIT 권한과 작업 기록 결합

### 쉽게 이해하기 (학습용)

- 사용자는 관리자 비밀번호를 직접 알지 못하고 승인된 통로에서만 작업하므로 누가 무엇을 했는지 남길 수 있다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **특권 발견·분류**: 특권 계정·키·서비스 계정과 PAM을 우회하는 직접 접속 경로를 지속 식별하는 활동이다.
- **비밀 회전·세션 증적**: 작업 뒤 자격 증명을 새 값으로 바꾸고 명령·화면·파일 전송 기록을 감사 자료로 보존하는 통제이다.

</details>

```mermaid
block-beta
  columns 3
  A["특권 발견·분류"]
  B["요청·승인"]
  C["비밀·키 금고"]
  D["세션 중계"]
  E["회수·감사"]
    A --> B --> C --> D --> E
```

| 구성요소 | 책임 |
|:---|:---|
| **특권 발견·분류** | 계정·키·**우회 경로 식별** |
| **요청·승인** | 작업·대상·**시간 판정** |
| **비밀·키 금고** | 자격 증명의 **보관·회전** |
| **세션 중계** | 직접 접속 차단과 **작업 통제** |
| **회수·감사** | 권한 폐기와 **증적 보호** |

### 쉽게 이해하기 (학습용)

- 특권을 찾아 금고에 넣고 승인된 작업만 중계하며 세션이 끝나면 권한과 비밀을 회수하고 기록을 보호한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **직무 분리**: 특권의 요청·승인·실행 권한을 서로 다른 주체에 나누어 단독 오남용을 막는 원칙이다.
- **명령 통제**: 승인된 특권 세션에서 실행할 수 있는 명령과 작업 범위를 제한하는 통제이다.

</details>

```mermaid
sequenceDiagram
    participant A as 관리자
    participant P as PAM
    participant V as 비밀·키 금고
    participant S as 대상 시스템
    participant 감사시스템
    A->>P: 목적·대상·시간 작업 요청
    P->>P: 1. 신원·승인·위험 판정
    P->>V: 2. 단기 자격 증명 요청
    V-->>P: 3. 단기 자격 증명 전달
    P->>S: 4. 명령 통제·세션 중계
    S->>감사시스템: 5. 세션 증적·종료 상태 전달
    P-->>A: 작업 종료 결과
```

**동작 원리**

1. **신원·승인·위험 판정**: 직무 분리·업무 영향 확인
2. **단기 자격 증명 요청**: 승인 범위·만료 조건을 금고에 제공
3. **단기 자격 증명 전달**: 금고에서 JIT 비밀 제공
4. **명령 통제·세션 중계**: 직접 접속 차단·작업 기록
5. **세션 증적·종료 상태 전달**: 권한 폐기·비밀 회전 근거 제공


### 쉽게 이해하기 (학습용)

- 작업 목적을 심사해 짧게 쓸 열쇠로 통제된 세션을 열고 모든 작업을 기록한 뒤 연결과 열쇠를 함께 닫는다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **금고형·JIT 특권**: 금고형은 기존 계정의 비밀을 일시 대여하고 JIT는 작업마다 짧은 수명의 권한을 새로 발급한다.
- **비상 접근**: 정상 통제 체계 장애 때 별도 승인과 강한 사후 감사를 전제로 제한적으로 사용하는 긴급 특권 절차이다.

</details>

| 특권 관리 유형 | PAM | 공유 상시 계정 | 금고형 계정 대여 | JIT 최소 특권 |
|:---|:---|:---|:---|:---|
| 적용 기준 | 고위험 접근의 **통합 관리** | 임시·**낮은 성숙 환경** | 기존 계정의 **비밀 보호** | **클라우드·자동화 환경** |
| 핵심 특징 | **특권 전주기 통제** | **공용 관리자 권한** | 금고 계정 일시 대여 | 작업별 단기 권한 |
| 한계 | **우회 경로·중앙 장애** | **탈취·부인·회수 곤란** | **공유 계정 잔존** | **정책·비상 절차 복잡** |

### 쉽게 이해하기 (학습용)

- PAM은 단순 금고가 아니라 승인·중계·기록·회수를 묶으며 성숙할수록 공유 계정에서 작업별 단기 권한으로 전환한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **NIST SP 800-53 Rev. 5**: 특권 계정·최소 권한·감사·세션 통제 요구를 제시한 공식 지침이다.
- **ISO/IEC 27002:2022 통제 8.2**: 특권 접근권의 할당과 사용을 제한·관리하도록 요구하는 국제표준 통제이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **특권 계정·최소 권한 편차** | **NIST SP 800-53 Rev. 5 적용** | 계정·세션·감사의 **통제 정렬** |
| **특권 접근권 관리 누락** | **ISO/IEC 27002 통제 8.2 적용** | 할당·검토·회수의 **책임 명확화** |
| **금고 장애·우회 경로** | **고가용성·직접 접속 차단** | 중앙 장애·**통제 회피 위험 완화** |

### 쉽게 이해하기 (학습용)

- 관리자는 PAM을 통해 승인된 시간에만 방화벽에 접속하고, PAM은 관리자 비밀번호를 대신 주입하며 명령과 화면을 감사 기록으로 남긴다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **특권 책임 추적성**: 모든 높은 권한 사용을 개인·작업 목적·승인·시간·실행 기록과 결속해 사후에 책임을 확인할 수 있는 성질이다.

</details>

- 고위험 특권은 **PAM**, 자동화는 **JIT**, 비상 접근은 별도 승인·사후 감사

### 쉽게 이해하기 (학습용)

- PAM의 핵심은 관리자 비밀번호 보관이 아니라 모든 특권을 개인·작업·시간에 묶어 통제하고 사용 뒤 흔적과 권한을 정리하는 것이다.
