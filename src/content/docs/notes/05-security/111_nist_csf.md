## 미리 알고가기

- **NIST (National Institute of Standards and Technology)**: 미국의 기술 표준과 지침을 개발하는 기관
- **CSF (Cybersecurity Framework)**: 조직의 사이버보안 위험관리 결과를 공통 언어로 정리한 체계
- **CSF Core**: Govern·Identify·Protect·Detect·Respond·Recover의 보안 결과 분류
- **조직 프로파일 (Organizational Profile)**: 현재 상태와 목표 상태에 필요한 CSF 결과를 골라 기록한 것
- **CSF Tier**: 위험관리 관행의 엄격성과 조직 내 정착 수준을 네 단계로 설명하는 척도
- **참조 자료 (Informative Reference)**: CSF 결과를 다른 표준·통제와 연결하는 참고 매핑

## Ⅰ. 개요

- 정의/개념: 보안 결과 기반 위험관리 프레임워크
- **배경/필요성**: 서로 다른 조직·통제 체계만으로 보안 결과와 우선순위 소통 곤란

### 쉽게 이해하기 (학습용)

- 공통 결과로 달성 목표를 공유하고 구체적인 수단은 조직이 자율 선택

## Ⅱ. 특징

- 특정 제품 없이 조직의 보안 결과를 제시한다.
- Govern 포함 6개 기능이 위험관리를 연결한다.
- 프로파일 차이로 개선 순위를 정하며 Tier는 점수가 아니다.

### 쉽게 이해하기 (학습용)

- 현재와 원하는 결과 차이를 찾아 예산과 개선 순서를 정함

## Ⅲ. 아키텍처 및 구성요소

| 설계 요소 | 설명 |
|:---|:---|
| Govern | 전략·정책·위험 허용 수준과 공급망 위험 관리 |
| Identify | 자산·업무 환경과 사이버보안 위험 이해 및 우선순위화 |
| Protect | 접근·데이터·플랫폼 보호와 인식 제고로 위험 감소 |
| Detect | 지속 모니터링과 분석으로 이상 징후와 사고 발견 |
| Respond | 사고를 억제하고 대응 활동과 이해관계자 소통을 수행함 |
| Recover | 자산과 운영을 복원하고 복구 경험을 개선에 반영함 |

```text
  [GOVERN]
     ↓
 [IDENTIFY]
     ↓
  [PROTECT]
     ↓
  [DETECT]
     ↓
 [RESPOND]
     ↓
 [RECOVER]
```

### 쉽게 이해하기 (학습용)

- 경영 기준 수립 후 보안 결과를 지속 순환함

## Ⅳ. 원리 및 절차 흐름도

```text
 범위설정
    ↓
 현재평가
    ↓
 목표선택
    ↓
 차이정렬
    ↓
 실행갱신
```

| 절차 | 설명 |
|:---|:---|
| 범위설정 | 임무·위협·요구·위험 허용 수준 정함 |
| 현재평가 | 현재 달성한 CSF 결과 기록함 |
| 목표선택 | 변화·우선순위에 맞는 결과 선택함 |
| 차이정렬 | 위험·비용·효과로 결과 차이 정렬함 |
| 실행갱신 | 계획·지표 운영 및 프로파일 갱신함 |

> 요약: 현재·목표 프로파일 차이로 위험 기반 개선 수행

### 쉽게 이해하기 (학습용)

- 현재와 목표 지도를 비교해 차이부터 개선함

## Ⅴ. NIST CSF 핵심 요소 비교

| 비교축 | CSF Core | 조직 프로파일 | CSF Tier |
|:---|:---|:---|:---|
| 적용 기준 | 보안 결과를 분류·소통할 때 | 상태 차이와 개선 순서를 정할 때 | 관리 관행의 정착 수준을 설명할 때 |
| 핵심 특징 | 보안 결과의 공통 분류 | 현재·목표 결과를 조직별 선택 | 관리 관행을 네 단계로 설명 |
| 한계 | 결과를 필수 통제로 오해 | 목표를 과도하게 설정해 실행 지연 | 성숙도 점수나 인증 등급으로 오용 |

### 쉽게 이해하기 (학습용)

- Core는 공통 결과, Profile은 조직 목표, Tier는 관리 관행임

## Ⅵ. 실무 사례

1. 현재·목표 프로파일의 **위험 감소 효과 기반 개선 순위 결정**

### 쉽게 이해하기 (학습용)

- 조직은 CSF 현재 프로파일과 목표 프로파일의 차이를 비교하고 업무 위험을 가장 크게 줄이는 보안 결과부터 투자 순위를 정한다.

## Ⅶ. 결론

- 경영과 실무의 보안 목표 불일치를 줄이기 위해 6개 기능·현재 프로파일·목표 프로파일·위험 감소 효과를 검토하여, NIST CSF로 개선 우선순위를 합의해야 한다.

### 쉽게 이해하기 (학습용)

- CSF는 경영진과 실무자가 같은 보안 결과를 기준으로 투자 순서를 합의하게 함
