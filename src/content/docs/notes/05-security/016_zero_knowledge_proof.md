## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **영지식 증명(Zero-Knowledge Proof, ZKP)**: 비밀값을 공개하지 않고 정해진 관계가 성립한다는 사실만 증명하는 암호 프로토콜이다.
- **명제(Statement)**: 증명자가 참이라고 주장하고 검증자가 확인할 공개 주장이다.
- **비밀 증거(Witness)**: 외부에 공개하지 않지만 명제를 참으로 만드는 비밀 입력이다.

</details>

- 정의/개념: **비밀 증거**를 공개하지 않고 **명제**의 참만 보이는 **영지식 증명(ZKP)** 프로토콜이다.
- 배경/필요성: 원본을 제출하는 검증 방식은 검증 과정에서 비밀을 노출한다.

#### 한줄 요약

- 비밀번호를 보여 주지 않고도 올바른 비밀번호를 안다는 사실만 확인시켜, 검증자가 비밀번호 자체를 저장하거나 볼 필요를 없앤다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **완전성(Completeness)**: 참인 명제와 올바른 비밀 증거의 증명을 수용하는 성질이다.
- **건전성(Soundness)**: 거짓 명제가 검증을 통과할 가능성을 제한하는 성질이다.
- **영지식성(Zero-knowledge)**: 검증자가 명제의 참 이외에 비밀 증거 정보를 얻지 못하는 성질이다.
- **회로 크기**: 증명할 관계를 표현한 제약식의 규모로, 커질수록 증명 생성과 검증 비용이 증가하는 지표이다.

</details>

- **완전성**은 참을 수용하고 **건전성**은 거짓의 통과 가능성을 제한한다.
- **영지식성**은 비밀 증거를 숨기고 명제의 참만 밝힌다.
- **회로 크기**가 증가하면 증명 생성•검증 비용이 상승한다.

#### 한줄 요약

- 회로가 나이 숫자만 검사하면 가짜 숫자도 통과할 수 있으므로, 그 숫자가 신뢰기관이 발급한 신분증에서 왔다는 조건까지 관계에 넣어야 한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **관계(Relation)**: 공개 입력과 비밀 증거가 만족해야 할 조건이다.
- **회로(Circuit)**: 관계를 계산 가능한 제약식으로 표현한 구조이다.
- **증명자(Prover)**: 비밀 증거를 이용해 증명을 만드는 주체이다.
- **검증자(Verifier)**: 공개 입력과 증명으로 명제의 유효성을 판정하는 주체이다.
- **공통 파라미터(Common Parameters)**: 증명 생성과 검증에 공통으로 쓰는 공개 설정값이다.

</details>

```text
영지식 증명 구조
├─ 공통 파라미터
├─ 증명자
├─ 검증자
├─ 비밀 증거
└─ 명제•관계 회로
```

가지의 의미: 설정•생성•검증•비밀 입력•관계 정의 책임을 나눈 구조다.

| 구성요소 | 책임 |
|:---|:---|
| 공통 파라미터 | **공통 파라미터**로 증명•검증 설정 제공 |
| 증명자 | **증명자**가 비밀 증거로 증명 생성 |
| 검증자 | **검증자**가 공개 입력•증명 유효성 판정 |
| 비밀 증거 | 명제를 만족하는 **비밀 증거** 입력 |
| 명제•관계 회로 | **관계**를 **회로**로 제약화 |


#### 한줄 요약

- 검사표에 빠진 조건은 검증할 수 없으므로, 회로가 실제 업무 규칙을 모두 표현하는지 감사해야 거짓 상태의 증명 통과를 방지할 수 있다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **문맥 결합**: 서비스 식별자•회로 버전•요청값을 공개 입력에 포함해 증명 재사용을 막는 통제이다.
- **증명 파라미터**: 증명 생성에 사용하는 공개 설정값이다.
- **검증 파라미터**: 증명의 유효성 판정에 사용하는 공개 설정값이다.
- **영지식 증명 생성**: 비밀 증거가 회로를 만족한다는 증명을 비밀 노출 없이 만드는 단계이다.
- **증명 유효성 검증**: 공개 입력과 증명으로 명제의 참 여부를 판정하는 단계이다.
- **회로•문맥•결과 판정**: 승인 전에 회로 버전•서비스 문맥•업무 결과의 일치 여부를 확인하는 단계이다.

</details>

```text
공통 설정
        ├─ 1. 증명 파라미터 배포
        └─ 2. 검증 파라미터 배포
                    │
                    ▼
3. 영지식 증명 생성
        │
        └── 공개 입력•증명 전달
                    │
                    ▼
4. 증명 유효성 검증
        ├─ 실패: 증명 거부
        └─ 성공
             │
             ▼
     5. 회로•문맥•결과 판정
             ├─ 불일치: 업무 요청 거부
             └─ 일치: 검증 승인 반환
```

### 동작 원리

1. **증명 파라미터 배포**: 증명 생성용 공개 설정을 제공한다.
2. **검증 파라미터 배포**: 검증용 공개 설정을 제공한다.
3. **영지식 증명 생성**: 회로 만족 증거를 비공개로 압축한다.
4. **증명 유효성 검증**: 공개 입력으로 완전성•건전성을 판정한다.
5. **회로•문맥•결과 판정**: **문맥 결합**으로 대상•버전•제약 만족을 처리한다.


#### 한줄 요약

- 다른 서비스에서 만든 증명을 재사용하지 못하게 서비스 식별자•회로 버전•요청값을 공개 입력에 묶어 검증한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **영지식 간결 비대화형 지식 논증(Zero-Knowledge Succinct Non-Interactive Argument of Knowledge, zk-SNARK)**: 짧은 증명과 빠른 검증을 제공하는 영지식 증명 방식이다.
- **영지식 확장 가능 투명 지식 논증(Zero-Knowledge Scalable Transparent Argument of Knowledge, zk-STARK)**: 신뢰 설정 없이 확장 가능한 증명을 생성하는 영지식 증명 방식이다.
- **범위 증명(Range Proof)**: 비밀값을 공개하지 않고 정해진 수치 구간에 속함을 증명하는 방식이다.

</details>

| 영지식 증명 방식 | zk-SNARK | zk-STARK | 범위 증명 |
|:---|:---|:---|:---|
| 적용 기준 | 증명 크기•검증 비용 제한 | 대규모 계산•비밀 설정 회피 | 나이•잔액 등 수치 범위 검증 |
| 핵심 특징 | **zk-SNARK**의 짧은 비대화형 증명 | **zk-STARK**의 투명 설정•해시 기반 증명 | **범위 증명**으로 비밀값의 구간만 증명 |
| 한계 | 설정 비밀 유출 시 건전성 훼손 | 큰 증명 크기 | 복잡한 관계 증명에 부적합 |

> 요약: 설정 신뢰•증명 크기•관계로 선택한다.

#### 한줄 요약

- 증명이 작아도 초기 설정의 비밀이 남으면 가짜 증명을 만들 수 있으므로, 통신 비용과 함께 설정을 누구에게 신뢰할지도 선택 기준이다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **국제표준화기구/국제전기기술위원회(International Organization for Standardization/International Electrotechnical Commission, ISO/IEC) 9798-5:2009**: 영지식 기반 엔티티 인증 메커니즘을 규정한 국제 표준이다.
- **신뢰 설정(Trusted Setup)**: 일부 증명 방식에서 공통 파라미터를 만들 때 비밀값이 안전하게 폐기되었다고 가정하는 초기 절차이다.
- **현실 진실성**: 회로에 입력한 사실 자체가 참인지 신뢰 발급자의 서명 등 외부 근거로 확인하는 성질이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 영지식 엔티티 인증 오류 | **ISO/IEC 9798-5** 적용 | 인증 절차 일관화 |
| 회로 누락•버전 혼선 | 회로 감사•**문맥 결합** | 거짓 명제 수용 차단 |
| 신뢰 설정 비밀 유출 | **신뢰 설정**의 다자 수행•폐기 증적 | 위조 증명 위험 억제 |
| 외부 입력의 **현실 진실성** 부재 | 신뢰 발급자의 입력 서명 검증 | 허위 입력 증명 차단 |

#### 한줄 요약

- 성인 인증은 생년월일 전체를 보내지 않고 신뢰된 신분 정보의 나이가 기준 이상이라는 사실만 증명한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **증명 방식 선택**: 설정 신뢰, 증명 크기, 검증 비용, 표현할 관계의 복잡성을 함께 고려하는 결정 기준이다.

</details>

- **증명 방식 선택**에 따라 짧은 증명은 **zk-SNARK**, 신뢰 설정 회피는 **zk-STARK**를 선택한다.

#### 한줄 요약

- 영지식이라는 이름만 믿지 말고 무엇을 숨기며 어떤 관계의 참을 증명하는지와 초기 설정을 누구에게 신뢰하는지를 정해야 한다.
