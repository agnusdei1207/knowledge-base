## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **ZKP (Zero-Knowledge Proof, 영지식 증명)**: 비밀 정보를 일절 노출하지 않고 그 정보가 참이라는 사실만을 검증자에게 수학적으로 증명하는 기술.
- **Witness (비밀 증거)**: 증명자가 검증 회로에 주입하는 비공개 원본 데이터(예: 주민등록번호, 소득액, 개인키).

</details>

- 정의/개념: Witness 없이 제약식 만족 사실만 증명하는 프라이버시 기술
- 배경/필요성: 탈중앙화 신원증명(DID), 블록체인 트랜잭션 검증 및 금융 자격 심사 환경에서 성인 인증이나 계좌 잔액 확인을 위해 주민등록번호, 생년월일, 전체 거래내역 등 민감한 개인정보 원본을 검증자에게 직접 제출하는 방식은 개인정보의 불필요한 과다 수집과 대규모 데이터 유출 위험을 초래하는 근본적 한계를 가짐에 따라, 증명자(Prover)가 자신의 비밀 정보(Witness)를 전혀 노출하지 않으면서도 해당 명제나 조건(산술 회로 제약식)이 참(True)이라는 사실만을 검증자(Verifier)에게 수학적으로 증명하는 영지식 증명(ZKP: Zero-Knowledge Proof) 프로토콜을 도입하여 완전성(Completeness)·건전성(Soundness)·영지식성(Zero-Knowledge) 보장, 개인정보 자기결정권 보호를 위한 최소 정보 공개 및 블록체인 ZK-Rollup의 초고속 오프체인 확장성을 달성할 필요

#### 한줄 요약
- 원본 비밀의 노출 없이 자격이나 연산 결과가 참임을 수학적으로 증명한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **Completeness (완전성)**: 명제가 참이면 정직한 증명자는 정직한 검증자를 반드시 납득시킬 수 있음.
- **Soundness (건전성)**: 명제가 거짓이면 부정직한 증명자가 검증자를 속일 수 있는 확률이 0에 수렴함.
- **Zero-Knowledge (영지식성)**: 명제가 참이라는 사실 외에는 비밀 정보에 대한 어떠한 추가 지식도 검증자에게 노출되지 않음.

</details>

- 3대 속성: 완전성·건전성·영지식성 보장
- **zk-SNARKs**: Fiat-Shamir 기반 소형 비대화형 증명
- 최소 정보 공개: DID 자격의 임계치 충족 여부만 증명

#### 한줄 요약
- 건전성은 확률적으로만 성립하므로 ZKP는 완전한 확실성 대신 무시 가능한 오류 확률을 받아들이고 원문 비공개를 얻은 거래다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **CRS (Common Reference String)**: zk-SNARKs에서 증명자와 검증자가 공유하는 공개 암호 파라미터(증명 키 $pk$ 및 검증 키 $vk$).

</details>

```text
[영지식 증명 체계]
  │
  ├─ [회로 및 설정 평면]
  │    ├─ 산술 회로 (R1CS / QAP 제약식)
  │    └─ 신뢰 설정 (CRS / Powers of Tau)
  │
  ├─ [증명자 평면 (Prover)]
  │    ├─ 비밀 증거 (Private Witness)
  │    └─ 증명 생성 엔진 (zk-SNARKs π)
  │
  └─ [검증자 평면 (Verifier)]
       └─ 검증 계약/엔진 (O(1) 검증)
```

- 선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| **산술 회로 (Arithmetic Circuit)** | 비즈니스 로직을 R1CS/QAP 다항식 제약식으로 컴파일 변환 |
| **비밀 증거 (Witness)** | 검증자에게 절대 공개하지 않는 증명자의 로컬 원본 입력 데이터 |
| **증명자 (Prover)** | 회로와 비밀 입력을 결합하여 간결한 암호학적 증명($\pi$) 생성 |
| **검증자 (Verifier)** | 공개 입력값과 증명($\pi$)을 수식 대조하여 상수 시간 내 진위 판정 |
| **신뢰 설정 (Trusted Setup)** | 증명/검증 키 쌍(CRS) 생성 및 유독 폐기물(Toxic Waste) 안전 소거 |

#### 한줄 요약
- 증명자 쪽에 회로 컴파일과 증명 생성이라는 무거운 연산을 몰아준 대가로 검증자는 원문 없이 상수 시간 판정만 수행하며, 그 비대칭을 성립시키는 대신 CRS라는 신뢰 설정 부담을 새로 떠안는다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Fiat-Shamir Heuristic (피아트-샤미르 변환)**: 대화형 영지식 증명의 무작위 챌린지를 해시 함수로 대체하여 단 1회의 전송으로 검증을 완료하는 비대화형 변환 기법.

</details>

```text
자격 증명 요청
    |
1. 회로 컴파일·키 배포
    |
2. 로컬 Witness 주입
    |
3. 비대화형 증명 계산
    |
4. 공개 입력·증명 전송
    |
5. 페어링 검증
    |
참·거짓 결과
```

- 1. 회로 컴파일·키 배포
- 2. 로컬 Witness 주입
- 3. 비대화형 증명 계산
- 4. 공개 입력·증명 전송
- 5. 페어링 검증

#### 한줄 요약
- 회로 컴파일과 키 배포는 회로마다 1회만 치르는 선불 비용이고 Witness 주입 이후 단계는 검증 요청마다 반복되므로, 준비 비용을 미리 몰아 두어야 반복 구간이 단 1회 전송으로 끝난다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **zk-SNARKs (Succinct Non-interactive ARgument of Knowledge)**: 페어링 기반 CRS를 미리 깔아 두고 증명 크기를 회로 규모와 무관한 상수로 압축함으로써, 온체인 검증자가 부담하던 재실행 비용을 수백 바이트 검증 1회로 대체하는 증명 체계.
- **zk-STARKs (Scalable Transparent ARgument of Knowledge)**: 페어링 대신 해시와 FRI 다항식 근접성 검사만 사용해 신뢰 설정 자체를 없애고, CRS 유출이라는 신뢰 위탁 비용을 증명 크기 증가로 바꿔 치른 투명 증명 체계.
- **Bulletproofs**: 내적 논증(IPA)으로 신뢰 설정 없이 값이 특정 범위 안에 있음을 증명해, 거래 금액을 숨긴 채 음수 발행 여부만 검증하도록 범위 증명 용도에 특화된 증명 체계.

</details>

| 비교 항목 | zk-SNARKs (Groth16 / Plonk) | zk-STARKs (StarkNet 표준) | Bulletproofs (범위 증명 전용) |
|:---|:---|:---|:---|
| 수학적 기반 | KZG 페어링 | 해시·FRI | IPA |
| 신뢰 설정 | 필수 | 불필요 | 불필요 |
| 증명 크기 | 128~256B | 40~100KB | 1~2KB |
| 검증 속도 | 2~5ms | 10~20ms | 선형 증가 |
| 양자 공격 저항성 | 취약 | 해시 기반 저항 | 취약 |
| 주요 적용 영역 | ZK-Rollup·Zcash | Starknet·L2 | 범위 증명 |

#### 한줄 요약
- zk-SNARKs는 초소형 크기와 초고속 검증 표준, zk-STARKs는 신뢰 설정이 없고 양자 안전한 차세대 표준이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Toxic Waste (독성 폐기물)**: zk-SNARKs 신뢰 설정 시 생성되는 비밀 난수로, 유출 시 공격자가 가짜 증명을 무한 위조할 수 있는 결함.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| Toxic Waste 유출로 증명 위조 | **MPC 세레모니·STARK 전환** | 위조 위험 제거 |
| 증명의 세션 간 Replay | **Nonce·시간·수신자 바인딩** | 컨텍스트 고정 |
| 위조 데이터를 Witness로 주입 | **발급기관 서명 검증 회로** | 데이터 진본성 확보 |
| Prover의 CPU·메모리 부담 | **GPU·FPGA MSM 가속** | 증명 시간 단축 |

#### 한줄 요약
- MPC 세레모니로 Toxic Waste를 소거하고, Nonce 바인딩으로 Replay를 막으며, 서명 검증 회로로 데이터 진본성을 보증한다.

## Ⅶ. 결론

- 민감한 원본 데이터를 전혀 공개하지 않고도 수학적 명제의 진실성을 100% 신뢰할 수 있게 검증함으로써 프라이버시 보호와 데이터 무결성 검증을 동시에 달성하는 차세대 탈중앙 신원(DID), 웹3(Web3) 프라이버시 및 블록체인 확장성(Layer 2 ZK-Rollup)의 핵심 암호학적 기반 기술로 확고히 안착하였으며, 양자내성 STARK 및 머신러닝 연산 증명(zk-ML)으로 진화하는 가운데, 실무 영지식 증명 시스템 구현 시에는 블록체인 가스비 최적화를 위한 수백 바이트 초소형 증명의 zk-SNARKs(Groth16/Plonk)와 신뢰 설정(Trusted Setup) 위험이 없는 투명한 양자내성 zk-STARKs의 요구조건별 선별 적용, 증명자(Prover)의 막대한 연산 지연을 단축하는 GPU/FPGA 기반 MSM(Multi-Scalar Multiplication) 및 NTT 가속, 신뢰 설정 단계의 독성 폐기물(Toxic Waste) 유출을 방지하는 분산 MPC 세레모니(Powers of Tau)를 결합하여 완벽한 영지식 프라이버시 신뢰성을 완성

#### 한줄 요약
- 영지식 증명은 완전성/건전성/영지식성 3대 속성과 비대화형 SNARK/STARK 기술을 통해 데이터 노출 없는 무결점 자격 검증을 실현하는 암호 기술이다.
