## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **비식별 처리**: 개인정보의 식별 위험을 줄이는 활동 전체이다.
- **가명처리**: 추가정보 없이는 개인을 알아보기 어렵게 정보를 처리하는 방식이다.
- **익명처리**: 합리적으로 예상되는 수단으로도 개인을 식별할 수 없게 하는 방식이다.
- **직접 식별자**: 이름•주민등록번호처럼 그 자체로 개인을 식별하는 값이다.
- **준식별자**: 나이•지역•직업처럼 다른 정보와 결합할 때 개인을 식별할 수 있는 값이다.

</details>

- 정의/개념: **직접 식별자**와 **준식별자**를 제거•대체•범주화해 재식별 위험을 낮추는 **비식별 처리**이다.
- 배경/필요성: 직접 식별자를 삭제해도 외부 정보와 결합하면 개인이 다시 식별될 수 있다.

#### 한줄 요약

- 이름을 지운 뒤에도 나이•지역•직업을 외부 정보와 합쳐 개인을 다시 알아볼 수 있는지를 확인한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **추가정보**: 가명정보를 원래 개인과 다시 연결할 수 있는 매핑표•복호화 키 등의 정보이다.

</details>

- **가명처리**는 **추가정보**를 분리해 보호하며 개인정보 지위를 유지한다.
- **익명처리**는 합리적으로 예상되는 수단으로도 식별할 수 없게 한다.
- 이용 환경과 외부 정보가 바뀌면 재식별 위험과 유용성을 다시 평가한다.

#### 한줄 요약

- 가명화는 재연결 열쇠를 따로 보호하는 방식이고 익명화는 현실적으로 다시 개인을 찾을 수 없게 만드는 방식이다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **마스킹**: 개인정보 값의 일부를 가려 표시 노출을 제한하는 기법이다.
- **일반화**: 상세 값을 더 넓은 범주로 바꿔 식별 가능성을 낮추는 기법이다.
- **억제**: 재식별 위험이 큰 값이나 레코드를 제거하는 기법이다.
- **k-익명성**: 같은 준식별자 조합을 가진 레코드가 k개 이상이 되게 하는 기준이다.
- **l-다양성**: 각 준식별자 집단에 민감 속성값이 l개 이상 존재하게 하는 기준이다.
- **t-근접성**: 집단의 민감 속성 분포가 전체 분포와 일정 거리 안에 있게 하는 기준이다.

</details>

```text
비식별 처리 구조
├─ 처리 기준
│  └─ 목적•법적 근거
├─ 위험 감소
│  ├─ 식별 위험 분석
│  └─ 비식별 처리 규칙
└─ 이용•검증
   ├─ 추가정보•이용 통제
   └─ 적정성•재평가
```

| 구성요소 | 책임 |
|:---|:---|
| 목적•법적 근거 | 이용•제공 범위와 근거 확정 |
| 식별 위험 분석 | 직접•준식별자와 외부 결합 가능성 평가 |
| 비식별 처리 규칙 | **마스킹**•**일반화**•**억제**와 **k-익명성**•**l-다양성** 적용 |
| 추가정보•이용 통제 | **추가정보**의 매핑키 분리•접근•반출 제한 |
| 적정성•재평가 | **t-근접성**과 재식별 위험•유용성 검증 |

#### 한줄 요약

- 처리 기법만 적용하지 않고 누가 어떤 외부 정보와 어떤 환경에서 다시 개인을 알아볼 수 있는지를 평가한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **외부정보 결합 위험**: 처리 데이터가 공개•보유 자료와 결합될 때 개인이 다시 식별될 가능성을 공격자 관점에서 평가한 위험이다.
- **유용성 검증**: 비식별 처리 뒤에도 분석 목적을 달성할 데이터 품질이 남았는지 확인하는 절차이다.
- **재평가**: 이용 환경이나 외부 자료가 바뀔 때 재식별 위험을 다시 측정하는 절차이다.
- **목적•근거•외부정보 확정**: 분석•제공•공개 목적과 법적 근거 및 예상 결합 자료를 정하는 단계이다.
- **식별자•결합 위험 분류**: 직접 식별자•준식별자•민감 속성과 외부 결합 가능성을 평가하는 단계이다.
- **삭제•대체•일반화 적용**: 이용 목적에 필요한 수준까지 식별 위험을 낮추는 단계이다.
- **재식별•유용성 검증**: 공격자의 재식별 가능성과 분석 목적 달성 여부를 함께 측정하는 단계이다.
- **접근•반출 통제•재평가**: 처리 환경의 접근과 반출을 제한하고 외부 정보 변화 때 위험을 다시 확인하는 단계이다.

</details>

```text
이용 목적•환경 정보
         |
         v
1. 목적•근거•외부정보 확정
         |
         v
2. 식별자•결합 위험 분류
         |
         v
3. 삭제•대체•일반화 적용
         |
         v
4. 재식별•유용성 검증
         |
         v
5. 접근•반출 통제•재평가
         |
         v
    적정성 검토 결과
```

### 동작 원리

1. **목적•근거•외부정보 확정**: 분석•제공•공개 범위를 설정한다.
2. **식별자•결합 위험 분류**: **외부정보 결합 위험**과 직접•준식별•민감 속성을 평가한다.
3. **삭제•대체•일반화 적용**: 목적 수준까지 식별 위험을 감소한다.
4. **재식별•유용성 검증**: 공격 가능성과 **유용성 검증** 결과를 측정한다.
5. **접근•반출 통제•재평가**: **재평가**로 환경 변화•외부 자료를 반영한다.


#### 한줄 요약

- 개인 단위 분석이 필요하면 통제 환경의 가명정보를 쓰고 식별이 필요 없는 공개는 더 강한 익명 처리를 적용한다.

## Ⅴ. 종류 및 비교

| 식별 위험 처리 유형 | 가명처리 | 익명처리 | 마스킹 |
|:---|:---|:---|:---|
| 적용 기준 | **가명처리** | **익명처리** | **마스킹** |
| 핵심 특징 | 추가정보 없이는 식별 곤란 | 합리적 수단으로 식별 불가 | 값 일부 표시 차단 |
| 한계 | 결합 재식별 위험 | 환경 변화 재평가 | 원본•복원 가능성 |

#### 한줄 요약

- 가명•익명•마스킹은 재연결 가능성과 법적 지위 및 필요한 이용 환경이 서로 다르다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **보호법 제28조의2~5**: 가명정보의 처리•결합•안전조치•재식별 금지를 규정한 조항이다.
- **보호법 제58조의2**: 익명정보의 법 적용 제외 기준을 규정한 조항이다.
- **ISO(International Organization for Standardization)**: 국제 표준을 개발•발행하는 기구이다.
- **IEC(International Electrotechnical Commission)**: 전기•전자 분야 국제 표준을 개발하는 기구이다.
- **ISO/IEC 27559:2022**: 비식별 데이터의 재식별 위험 관리 프레임워크이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 가명정보 처리•결합 | **보호법 제28조의2~5** 준수 | 추가정보 분리•재식별 금지 |
| 익명정보 판단 | **보호법 제58조의2** 기준 적용 | 성급한 법 적용 제외 방지 |
| 재식별 위험 수명주기 | **ISO**와 **IEC**의 **ISO/IEC 27559:2022** 적용 | 환경•외부정보 변화 반영 |

#### 한줄 요약

- 의료 연구는 가명정보와 재결합 열쇠를 별도 시스템과 권한으로 분리하고 반출 전 외부 정보 결합에 따른 재식별 위험을 다시 평가한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **목적 기반 식별 위험**: 기법 이름이 아니라 필요한 개인 단위 분석 여부와 예상 공격자의 외부정보•접근 능력에 맞춰 허용할 위험을 정하는 기준이다.

</details>

- **목적 기반 식별 위험**에 따라 개인 단위 분석은 **가명처리**, 공개는 결합 위험을 낮춘 **익명처리**를 선택한다.

#### 한줄 요약

- 비식별 처리의 핵심은 기법 이름이 아니라 현재와 예상 환경에서 개인을 다시 알아볼 가능성을 목적에 맞게 줄이는 것이다.
