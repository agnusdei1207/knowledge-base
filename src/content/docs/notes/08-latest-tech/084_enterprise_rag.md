## 미리 알고가기

- **Enterprise RAG**: 기업 보안·운영 요구를 반영한 RAG 아키텍처임
- **핵심 축**: 데이터 연결, 권한 통제, 품질 관리, 운영 자동화임
- **중요 요소**: 최신성, 감사 가능성, 비용 통제가 중요함

## Ⅰ. 개요

- 정의/개념: 기업 자료의 권한·버전·감사를 통합한 RAG
- **배경/필요성**: 다양한 원천의 최신성·보안·운영 복잡성 관리

### 쉽게 이해하기 (학습용)

- 자료의 최신성·사용자별 열람 범위·변경 기록을 답변 전 과정에서 관리합니다.

## Ⅱ. 특징

- 원천 데이터의 생성·변경·삭제 이벤트를 동기화한다.
- 문서 버전과 색인 반영 상태를 추적해 최신성을 유지한다.
- 사용자 권한을 검색 단계에 적용해 후보 문맥을 제한한다.
- 단계별 평가로 검색 누락과 생성의 근거 이탈을 구분한다.

### 쉽게 이해하기 (학습용)

- 자료 수집부터 답변까지 같은 권한·버전·감사 기록을 이어서 관리합니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 동기화 계층 | 내용·버전·권한과 이벤트를 수집함 |
| 색인 계층 | 검색 단위 변환 및 메타데이터 게시함 |
| 검색 계층 | 사용자 권한에 따른 허용 후보 검색함 |
| 생성 계층 | 허용 문맥 내 답변 및 인용 생성함 |
| 운영 계층 | 추적·감사·평가 및 비용 관리를 수행함 |

### 쉽게 이해하기 (학습용)

- 원천부터 답변까지 같은 문서 버전과 접근 권한을 유지합니다.

## Ⅳ. 원리 및 절차 흐름도

```text
동기화
↓
색인게시
↓
권한검색
↓
생성기록
↓
평가개선
```

| 절차 | 설명 |
|:---|:---|
| 동기화 | 원천 이벤트와 버전·권한을 수집함 |
| 색인게시 | 검색 단위와 메타데이터를 게시함 |
| 권한검색 | 사용자 권한에 따른 허용 근거 검색함 |
| 생성기록 | 문맥·인용·정책 판정을 기록함 |
| 평가개선 | 품질·최신성·비용을 분리 분석함 |

### 쉽게 이해하기 (학습용)

- 원천 변경을 반영하고 권한 내 자료로 답했는지 실행 기록을 평가합니다.

## Ⅴ. 종류 및 비교

| 적용 기준 | 데모형 RAG | 기업 RAG | 폐쇄망 RAG |
|:---|:---|:---|:---|
| 운영 범위 | 단일 사용자 흐름 | 통합 생명주기 관리 | 격리 환경 운영 |
| 적용 기준 | 기능 가치 검증 | 권한·감사 준수 | 외부 연결 차단 |
| 주요 위험 | 데이터·권한 누락 | 장애 전파 위험 | 운영 비용 증대 |

> 요약: 운영 방식에 따라 데모·기업·폐쇄망형으로 구분함

### 쉽게 이해하기 (학습용)

- 데모형·기업형·폐쇄망형은 운영 범위와 보안 경계가 다릅니다.

## Ⅵ. 실무 사례

- 사내 정책은 규정 개정·폐기 시 버전을 표시함

### 쉽게 이해하기 (학습용)

- 규정이나 장애 기록을 검색할 때 최신 버전과 사용자 권한을 확인합니다.

## Ⅶ. 결론

- 기업 RAG는 자료 운영 생명주기를 통합하여 검증함

### 쉽게 이해하기 (학습용)

- 수집·색인·검색·생성·평가의 기록과 운영 상태를 끊김 없이 관리해야 합니다.
