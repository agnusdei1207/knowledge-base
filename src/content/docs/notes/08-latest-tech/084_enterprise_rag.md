## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **기업 RAG(Enterprise RAG)**: 사내 지식의 버전•권한•감사를 통합 관리하는 RAG 체계이다.

</details>

- 정의/개념: 사내 지식의 버전•권한•계보를 통합한 **기업 RAG**
- 배경/필요성: 일반 RAG은 다중 원천의 **최신성•권한•감사 관리 곤란**

#### 한줄 요약
- **최신 버전•열람 권한•근거 계보**를 전 과정에서 유지

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **데이터 계보(Data Lineage)**: 답변 근거의 원천•버전•처리 단계를 추적한 기록이다.
- **허용 문맥(Allowed Context)**: 사용자가 열람할 수 있는 근거만 담은 모델 입력이다.

</details>

- 원천 변경 이벤트와 색인을 잇는 **문서 생명주기 동기화**
- 원천•색인•답변을 연결하는 **버전•데이터 계보 추적**
- 검색 단계의 사용자 권한 적용과 **허용 문맥 생성**

#### 한줄 요약
- **문서•권한 변경**을 검색 자료와 답변 근거에 동기화

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **데이터 커넥터(Data Connector)**: 문서 내용과 변경 이벤트를 수집 계층에 전달한다.
- **색인(Index)**: 문서 조각과 메타데이터를 검색 가능한 형태로 저장한다.
- **권한 검색 계층**: 접근 정책을 적용해 허용된 근거만 반환한다.
- **생성 계층**: 허용된 근거와 인용 정보로 답변을 생성한다.
- **운영•평가 계층**: 최신성•권한•품질•비용을 관측하고 변경을 통제한다.

</details>

```text
                   [동기화 계층]
                         |
                    [색인 계층]
                         |
                  [권한 검색 계층]
                         |
                    [생성 계층]
                         |
                 [운영•평가 계층]
```

선의 의미: 동기화•색인•권한 검색•생성•운영 계층의 결합 관계이다.

| 구성요소 | 책임 |
|:---|:---|
| 동기화 계층 | **데이터 커넥터 기반 원천 변경 수집** |
| 색인 계층 | 문서 조각•메타데이터의 **검색 구조 게시** |
| 권한 검색 계층 | 사용자 권한 범위의 **허용 근거 검색** |
| 생성 계층 | 허용 문맥 기반 **답변•인용 생성** |
| 운영•평가 계층 | 계보•감사•품질•비용의 **운영 상태 추적** |

#### 한줄 요약
- **동기화•색인•권한 검색•생성•운영 평가** 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **메타데이터(Metadata)**: 문서의 버전•소유자•권한•유효 기간 정보이다.
- **생명주기 동기화(Lifecycle Synchronization)**: 원천 변경을 색인과 답변 근거에 반영한다.

</details>

```text
지식 원천
   │ 1. 문서•버전•권한 변경 수집
   ▼
동기화•색인
   │ 2. 조각•메타데이터 색인 게시
   ▼
권한 검색기
   │ 3. 사용자 권한 내 근거 검색
   ▼
생성기
   │ 4. 답변•인용•계보 기록
   ▼
운영•평가기
   └── 5. 최신성•품질•비용 개선 ──▶ 동기화•색인
```

### 동작 원리

1. **문서•버전•권한 변경 수집**: 원천 이벤트를 통해 **현재 지식 상태**를 확보함.
2. **조각•메타데이터 색인 게시**: 내용과 버전•권한을 결합한 **검색 단위**를 생성함.
3. **사용자 권한 내 근거 검색**: 허용 공간에서만 관련 문서를 찾아 **검색 후보**를 제한함.
4. **답변•인용•계보 기록**: 생성 결과와 사용 근거의 **원천 추적 정보**를 저장함.
5. **최신성•품질•비용 개선**: 운영 지표와 실패 단계로 **동기화•검색•생성 설정**을 조정함.

#### 한줄 요약
- **변경 수집•색인•권한 검색•계보 기록•운영 개선** 수행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **데모형 RAG(Demo RAG)**: 단일 흐름에서 기능과 업무 가치를 검증한다.
- **기업 RAG**: 조직 지식의 권한•계보•생명주기를 통합 운영한다.
- **폐쇄망 RAG(Air-gapped RAG)**: 격리 환경에서 모델•색인•문서를 독립 운영한다.

</details>

검색 증강 생성(Retrieval-Augmented Generation, RAG)은 운영 범위에 따라 데모형•기업형•폐쇄망형으로 구분한다.

| 비교 기준 | 데모형 RAG | 기업 RAG | 폐쇄망 RAG |
|:---|:---|:---|:---|
| 적용 기준 | 기능 가치 검증 | 조직 지식 통합 운영 | 외부 연결 금지 환경 |
| 핵심 특징 | 단일 흐름의 **기능 구현** | 권한•계보의 **생명주기 통합** | 격리 환경의 **독립 운영** |
| 한계 | 최신성•권한 누락 | 통합 복잡성•운영 비용 | 모델•지식 갱신 제약 |

#### 한줄 요약
- **기능 검증•통합 운영•망 격리**에 따라 운영 범위 구분

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **색인 버전 지연(Index-version Lag)**: 원천 변경이 색인에 반영되지 않은 상태이다.
- **권한 메타데이터 불일치(Permission-metadata Mismatch)**: 원천과 색인의 권한 상태가 다른 문제이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 원천 변경 후 **색인 버전 지연** | 이벤트별 원천•색인 버전 대조와 재색인 | 오래된 답변 **방지** |
| 원천•색인의 **권한 메타데이터 불일치** | 권한 변경 동기화•검색 전 허용 범위 검사 | 비인가 근거 검색 **차단** |
| 답변 근거의 **데이터 계보 단절** | 문서 식별자(Identifier, ID)•버전•조각•인용의 실행 기록 연결 | 감사•오류 추적 가능 |

#### 한줄 요약
- **원천•색인 버전•권한•답변 계보** 검증

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **운영 경계(Operational Boundary)**: 최신성•권한•계보를 보장할 계층과 책임 범위이다.

</details>

- **지식 최신성•권한 일치•데이터 계보**로 동기화•검색•감사 경계 결정

#### 한줄 요약
- **최신성•권한•계보 책임**에 따라 운영 경계 결정
