## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **트랜스포머(Transformer)**: 셀프 어텐션으로 토큰 관계를 직접 계산하고 피드포워드 계층으로 표현을 변환하는 신경망 구조로 정의된다.
- **순환 신경망(Recurrent Neural Network, RNN)**: 이전 시점의 은닉 상태를 다음 시점으로 순차 전달하여 시퀀스를 처리하는 구조을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.

</details>

- 정의/개념: 셀프 어텐션으로 시퀀스의 토큰 관계를 직접 계산하고 병렬 처리하는 **트랜스포머**임. 이는 전통적 방식과의 핵심 차별점으로서 실질적인 업무 가치를 창출함.
- 배경/필요성: **RNN**의 순차 상태 전달은 학습 병렬화와 장거리 의존성 학습에 한계가 있음.

#### 한줄 요약
- 토큰 관계를 병렬로 계산 체계 적용

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **셀프 어텐션(Self-Attention)**: 같은 시퀀스 안의 토큰들이 서로의 관련도를 계산하여 문맥 정보를 결합하는 연산을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.
- **크로스 어텐션(Cross-Attention)**: 한 시퀀스의 쿼리가 다른 시퀀스의 키와 밸류를 참조하여 정보를 연결하는 연산이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.
- **GPU(Graphics Processing Unit)**: 대규모 행렬곱을 병렬로 처리하여 트랜스포머 학습을 가속하는 연산 장치로 정의된다.

</details>

- **셀프 어텐션**으로 모든 토큰 쌍 관계를 직접 계산하여 실무 환경에서의 유연한 대응과 지속적 최적화를 지원함.
- **셀프 어텐션**: 동일 시퀀스의 문맥 관계 결합하여 실무 환경에서의 유연한 대응과 지속적 최적화를 지원함.
- **크로스 어텐션**: 외부 시퀀스의 문맥 관계 결합하여 실무 환경에서의 유연한 대응과 지속적 최적화를 지원함.
- 순환 구조를 제거하고 **GPU**로 병렬 학습하여 실무 환경에서의 유연한 대응과 지속적 최적화를 지원함.
- 마스크로 참조 범위를 제어하며 어텐션 비용은 O(N²)임. 이는 전통적 방식과의 핵심 차별점으로서 실질적인 업무 가치를 창출함.

#### 한줄 요약
- 학습은 **GPU**로 병렬 처리하고 자기회귀 생성은 순차 처리 체계 적용

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **피드포워드 신경망(Feed-Forward Network, FFN)**: 어텐션을 거친 각 토큰 표현을 위치별로 비선형 변환하는 계층을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.
- **잔차 연결(Residual Connection)**: 계층 입력을 변환 결과에 더하여 원래 정보와 기울기 흐름을 보존하는 연결을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.
- **층 정규화(Layer Normalization)**: 각 토큰 표현의 특성 차원을 정규화하여 학습을 안정화하는 연산이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.

</details>

```text
                    [입력 표현]
                         |
                   [어텐션 계층]
                         |
                 [피드포워드 계층]
                         |
                  [잔차•정규화]
```

선의 의미: 입력 표현을 어텐션 계층과 피드포워드 계층이 변환하고, 잔차•정규화가 두 계층의 정보 및 학습 안정성을 보존하는 트랜스포머 블록 구조를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 입력 표현 | 토큰 임베딩과 위치 정보 결합 |
| 어텐션 계층 | **셀프 어텐션**으로 토큰 관계 추출 |
| 피드포워드 계층 | **FFN**으로 위치별 표현 확장•압축 |
| 잔차•정규화 | **잔차 연결**과 **층 정규화**로 학습 안정성 유지 |

#### 한줄 요약
- **어텐션•FFN•잔차•정규화** 블록 반복이 핵심 구조 구현

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **쿼리•키•밸류(Query•Key•Value, Q•K•V)**: 어떤 정보를 찾을지, 무엇과 비교할지, 어떤 정보를 전달할지를 각각 나타내는 어텐션 벡터을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.
- **위치 인코딩(Positional Encoding)**: 병렬 처리되는 토큰 표현에 순서와 상대 위치 정보를 더하는 표현이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.
- **토큰•위치 표현 구성**: 토큰 임베딩에 위치 인코딩을 결합해 순서가 있는 입력 표현을 만드는 절차을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.
- **Q•K•V 관계 가중치 계산**: 쿼리와 키의 유사도로 토큰 간 참조 가중치를 산출하는 절차을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.
- **어텐션 문맥 결합**: 계산된 가중치에 따라 밸류를 합산해 문맥 표현을 만드는 절차로 정의된다.
- **FFN 위치별 변환**: 각 토큰 표현을 피드포워드 신경망으로 비선형 변환하는 절차을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.
- **잔차•층 정규화**: 계층 입력을 더하고 특성 차원을 정규화해 정보와 기울기 흐름을 안정화하는 절차로 정의된다.

</details>

```text
입력 표현
   │ 1. 토큰•위치 표현 구성
   ▼
어텐션
   │ 2. Q•K•V 관계 가중치 계산
   │ 3. 어텐션 문맥 결합
   │ 문맥 표현 전달
   ▼
피드포워드
   │ 4. FFN 위치별 변환
   │ 변환 표현 전달
   ▼
잔차•정규화
   │ 5. 잔차•층 정규화
   │ 마스크 범위 내 출력
   ▼
출력
```

1. **토큰•위치 표현 구성**: 토큰 의미와 **위치 인코딩**을 결합함.
2. **Q•K•V 관계 가중치 계산**: **쿼리•키•밸류**로 토큰 쌍의 참조 중요도를 산출함.
3. **어텐션 문맥 결합**: 가중치에 따라 Value를 합성해 문맥 표현을 생성함.
4. **FFN 위치별 변환**: 각 토큰 표현의 비선형을 확장•압축함.
5. **잔차•층 정규화**: 잔차 경로와 정규화로 정보•기울기를 안정화함.

#### 한줄 요약
- **Q•K•V 어텐션•FFN**으로 문맥 표현을 갱신 체계 적용

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **BERT(Bidirectional Encoder Representations from Transformers)**: 양방향 트랜스포머 인코더를 사전학습하여 입력 문맥 표현을 만드는 모델을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.

</details>

- **트랜스포머** 및 **RNN** 사이를 병렬 관계 계산과 순차 상태 전달 기준으로 구분하여 실무 환경에서의 유연한 대응과 지속적 최적화를 지원함.
- **BERT**는 트랜스포머 인코더로 양방향 문맥 표현을 학습하여 실무 환경에서의 유연한 대응과 지속적 최적화를 지원함.

| 비교 기준 | 트랜스포머 | RNN 계열 |
|:---|:---|:---|
| 적용 기준 | 긴 문맥의 병렬 학습•확장 | 짧은 스트림의 순차 상태 처리 |
| 핵심 특징 | 어텐션으로 토큰 관계 직접 계산 | 은닉 상태로 정보 순차 전달 |
| 한계 | 문맥 길이의 O(N²) 비용 | 병렬화 제한•장거리 정보 소실 |

#### 한줄 요약
- 순차 상태는 **RNN**, 토큰 관계 병렬 계산은 **트랜스포머**가 핵심 구조 구현

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **희소 어텐션(Sparse Attention)**: 모든 토큰 쌍 대신 정해진 일부 관계만 계산하여 장문 연산량을 줄이는 방식로 정의된다.
- **키-값 캐시(Key-Value Cache, KV Cache)**: 자기회귀 생성 중 이전 토큰의 어텐션 키와 값을 저장하여 반복 계산을 줄이는 기법을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.
- **추측 디코딩(Speculative Decoding)**: 작은 모델이 제안한 여러 토큰을 큰 모델이 한 번에 검증하여 생성 지연을 줄이는 방식을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 긴 문맥의 O(N²) 메모리•연산량 | 청크•윈도•**희소 어텐션**•부하 시험 | 처리량•문맥 보존 균형 |
| 위치 표현의 학습 길이 외 일반화 | 상대•회전 위치 표현•최대 길이 평가 | 장문 순서 정보 왜곡 완화 |
| 자기회귀 생성의 순차 지연 | **KV Cache**•배치•**추측 디코딩** 적용 | 토큰당 지연•비용 절감 |
| 마스크 오류에 의한 미래•패딩 정보 누출 | 마스크 단위 시험•학습•추론 조건 일치 | 잘못된 참조와 평가 과대 차단 |

#### 한줄 요약
- **희소 어텐션•KV Cache**로 장문 연산•생성 비용 절감이 핵심 구조 구현

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **시퀀스 구조 선택 기준**: 긴 문맥의 병렬 관계 계산에는 트랜스포머를, 짧은 스트림의 순차 상태 유지에는 RNN을 적용하는 기준을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.

</details>

- **시퀀스 구조 선택 기준**에 따라 긴 문맥 병렬 학습에는 **트랜스포머**, 짧은 순차 상태에는 **RNN**을 선택하여 실무 환경에서의 유연한 대응과 지속적 최적화를 지원함.

#### 한줄 요약
- 문맥 성능과 O(N²) 비용을 함께 평가해 구조를 선택 체계 적용
