## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **트랜스포머(Transformer)**: 셀프 어텐션으로 토큰 관계를 직접 계산하고 피드포워드 계층으로 표현을 변환하는 신경망 구조로 정의된다.
- **순환 신경망(Recurrent Neural Network, RNN)**: 이전 은닉 상태를 다음 시점으로 전달해 시퀀스를 처리하는 구조이다.

</details>

- 정의/개념: 셀프 어텐션으로 토큰 관계를 계산하는 **트랜스포머**
- 배경/필요성: **RNN**은 은닉 상태를 토큰마다 순차로 넘겨 시퀀스 길이만큼 직렬 단계 비용을 치르고 그 사이 장거리 신호가 희석되므로, 순차 전달을 토큰 쌍 간 어텐션 가중합으로 대체해 전 위치를 한 번에 병렬 계산하는 구조로 전환

#### 한줄 요약
- **셀프 어텐션**은 순차 의존을 없애 병렬 학습과 상수 길이 경로를 얻는 대신 연산량이 시퀀스 길이의 제곱으로 늘므로, 속도의 이득을 문맥 길이 비용으로 되갚는 구조다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **셀프 어텐션(Self-Attention)**: 같은 시퀀스 안의 토큰들이 서로의 관련도를 계산하여 문맥 정보를 결합하는 연산이다.
- **크로스 어텐션(Cross-Attention)**: 한 시퀀스의 쿼리가 다른 시퀀스의 키와 밸류를 참조하여 정보를 연결하는 연산.
- **GPU(Graphics Processing Unit)**: 대규모 행렬곱을 병렬로 처리하여 트랜스포머 학습을 가속하는 연산 장치로 정의된다.

</details>

- **셀프 어텐션**: 동일 시퀀스의 문맥 관계 결합
- **크로스 어텐션**: 외부 시퀀스의 문맥 관계 결합
- **병렬 학습**: 순환 구조 제거와 GPU 행렬 연산
- **마스크 제어**: 미래•패딩 토큰 참조 제한
- **연산 복잡도**: 모든 토큰 쌍 계산의 O(N²) 비용

#### 한줄 요약
- 학습은 **GPU 병렬 처리**, 자기회귀 생성은 순차 처리

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **피드포워드 신경망(Feed-Forward Network, FFN)**: 어텐션을 거친 각 토큰 표현을 위치별로 비선형 변환하는 계층.
- **잔차 연결(Residual Connection)**: 계층 입력을 변환 결과에 더하여 원래 정보와 기울기 흐름을 보존하는 연결이다.
- **층 정규화(Layer Normalization)**: 각 토큰 표현의 특성 차원을 정규화하여 학습을 안정화하는 연산.

</details>

```text
                    [입력 표현]
                         |
                   [어텐션 계층]
                         |
                 [피드포워드 계층]
                         |
                  [잔차•정규화]
```

선의 의미: 입력 표현을 어텐션 계층과 피드포워드 계층이 변환하고, 잔차•정규화가 두 계층의 정보 및 학습 안정성을 보존하는 트랜스포머 블록 구조를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 입력 표현 | 토큰 임베딩과 위치 정보 결합 |
| 어텐션 계층 | **셀프 어텐션** 기반 토큰 관계 추출 |
| 피드포워드 계층 | **FFN** 기반 위치별 표현 확장•압축 |
| 잔차•정규화 | **잔차 연결** 및 **층 정규화** 기반 학습 안정성 유지 |

#### 한줄 요약
- **어텐션•FFN•잔차•정규화** 블록 반복

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **쿼리•키•밸류(Query•Key•Value, Q•K•V)**: 검색•비교•전달 정보를 각각 나타내는 어텐션 벡터이다.
- **위치 인코딩(Positional Encoding)**: 병렬 처리되는 토큰 표현에 순서와 상대 위치 정보를 더하는 표현.
- **토큰•위치 표현 구성**: 토큰 임베딩과 위치 인코딩을 결합하는 절차이다.
- **Q•K•V 관계 가중치 계산**: 쿼리•키 유사도로 참조 가중치를 산출하는 절차이다.
- **어텐션 문맥 결합**: 계산된 가중치에 따라 밸류를 합산해 문맥 표현을 만드는 절차로 정의된다.
- **FFN 위치별 변환**: 각 토큰 표현을 비선형 변환하는 절차이다.
- **잔차•층 정규화**: 계층 입력을 더하고 특성 차원을 정규화해 정보와 기울기 흐름을 안정화하는 절차로 정의된다.

</details>

```text
입력 표현
   │ 1. 토큰•위치 표현 구성
   ▼
어텐션
   │ 2. Q•K•V 관계 가중치 계산
   │ 3. 어텐션 문맥 결합
   │ 문맥 표현 전달
   ▼
피드포워드
   │ 4. FFN 위치별 변환
   │ 변환 표현 전달
   ▼
잔차•정규화
   │ 5. 잔차•층 정규화
   │ 마스크 범위 내 출력
   ▼
출력
```

### 동작 원리

1. **토큰•위치 표현 구성**: 토큰 의미와 위치 정보 결합
2. **Q•K•V 관계 가중치 계산**: 토큰 쌍 참조 중요도 산출
3. **어텐션 문맥 결합**: 가중치에 따라 밸류 합성
4. **FFN 위치별 변환**: 토큰 표현을 비선형 변환
5. **잔차•층 정규화**: 정보와 기울기 흐름 안정화

#### 한줄 요약
- **Q•K•V 어텐션•FFN** 기반 문맥 표현 갱신

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **BERT(Bidirectional Encoder Representations from Transformers)**: 양방향 트랜스포머 인코더를 사전학습하여 입력 문맥 표현을 만드는 모델.

</details>

- **트랜스포머**•**RNN** 병렬 관계와 순차 상태로 구분
- **BERT** 기반 인코더로 양방향 문맥 표현 학습

| 구분 | 트랜스포머 | RNN 계열 |
|:---|:---|:---|
| 적용 기준 | 긴 문맥의 병렬 학습•확장 | 짧은 스트림의 순차 상태 처리 |
| 핵심 특징 | 어텐션으로 토큰 관계 직접 계산 | 은닉 상태로 정보 순차 전달 |
| 한계 | 문맥 길이의 O(N²) 비용 | 병렬화 제한•장거리 정보 소실 |

#### 한줄 요약
- 순차 상태는 **RNN**, 관계 병렬 계산은 **트랜스포머**

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **희소 어텐션(Sparse Attention)**: 일부 토큰 관계만 계산해 장문 연산량을 줄이는 방식이다.
- **키-값 캐시(Key-Value Cache, KV Cache)**: 자기회귀 생성 중 이전 토큰의 어텐션 키와 값을 저장하여 반복 계산을 줄이는 기법.
- **추측 디코딩(Speculative Decoding)**: 작은 모델이 제안한 여러 토큰을 큰 모델이 한 번에 검증하여 생성 지연을 줄이는 방식.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 긴 문맥의 O(N²) 메모리•연산량 | 청크•윈도•**희소 어텐션**•부하 시험 | 처리량•문맥 보존 균형 |
| 위치 표현의 학습 길이 외 일반화 | 상대•회전 위치 표현•최대 길이 평가 | 장문 순서 정보 왜곡 완화 |
| 자기회귀 생성의 순차 지연 | **KV Cache**•배치•**추측 디코딩** 적용 | 토큰당 지연•비용 절감 |
| 마스크 오류에 의한 미래•패딩 정보 누출 | 마스크 단위 시험•학습•추론 조건 일치 | 잘못된 참조와 평가 과대 차단 |

#### 한줄 요약
- **희소 어텐션•KV Cache** 기반 장문•생성 비용 절감

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **시퀀스 구조 선택 기준**: 긴 문맥의 병렬 관계 계산에는 트랜스포머를, 짧은 스트림의 순차 상태 유지에는 RNN을 적용하는 기준.

</details>

- 긴 문맥 병렬 학습은 **트랜스포머**, 짧은 상태는 **RNN** 선택

#### 한줄 요약
- **문맥 길이•병렬성•O(N²) 비용** 대상 따라 구조 결정
