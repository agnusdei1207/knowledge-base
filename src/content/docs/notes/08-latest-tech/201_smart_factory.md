## 미리 알고가기

- **Smart Factory**: 설비·공정·품질·물류 데이터를 연결해 생산을 지능적으로 운영하는 제조 시스템
- **핵심 요건**: 단순 자동화보다 데이터 통합과 자율 최적화가 중요함
- **MES(제조실행시스템, Manufacturing Execution System)**: 공장 운영의 핵심 체계임



## Ⅰ. 개요

- **정의/개념**: 생산 IT·OT를 연결해 예측·최적화하는 공장
- **배경/필요성**: 변동 수요·품질·납기에 실시간 대응

### 쉽게 이해하기 (학습용)

- 주문·자재·공정 정보를 공유하여 다음 작업을 조정하는 공장임

## Ⅱ. 특징

- OT 계층이 설비를 실시간·결정적으로 제어한다.
- MES가 계획을 추적 가능한 생산 활동으로 바꾼다.
- 기업·분석 계층이 수요·품질을 최적화한다.
- 안전 경계가 분석 결과의 제어 반영을 제한한다.

### 쉽게 이해하기 (학습용)

- 기계 제어, 현장 지휘, 회사 계획실이 생산 상황을 공유하고 안전장치를 우선함

## Ⅲ. 아키텍처 및 구성요소

| 계층 | 설명 |
|:---|:---|
| ERP·SCM | 기업 자원 계획 및 물류 관리 |
| MES·MOM | 제조 실행 및 생산 현장 관리 |
| SCADA·Historian | 설비 감시 및 공정 데이터 기록 |
| PLC·DCS | 현장 설비 실시간 제어 |
| IIoT·Analytics | 데이터 통합 및 지능적 분석 |

> 요약: ISA-95 계층 기반의 안전한 제조 폐루프를 구성함

### 쉽게 이해하기 (학습용)

- 회사 계획실에서 현장 지휘실·감시실·기계 제어기로 지시가 내려가고, 센서 결과가 다시 올라와 분석과 승인 후 다음 작업을 조정함

## Ⅳ. 원리 및 절차 흐름도

계획

| 절차 | 설명 |

| 수요·생산계획 | 수요·생산계획을 수행하고 결과를 검증함 |
| MES 상세 일정·dispatch | MES 상세 일정·dispatch을 수행하고 결과를 검증함 |
| PLC 공정 실행 | PLC 공정 실행을 수행하고 결과를 검증함 |

| 분석·승인·feedback | 분석·승인·feedback을 수행하고 결과를 검증함 |

> 요약: 기업 계획을 현장 실행으로 연계하고 환류함

### 쉽게 이해하기 (학습용)

- 주문에 맞춰 작업 순서를 만들고 기계가 생산한 결과를 검사해 다음 일정과 정비·설정을 고치되 안전 확인 후 적용하는 절차임

## Ⅴ. 종류 및 비교

| 판단 기준 | 개별 자동화 | Smart Factory | Digital Factory |
|:---|:---|:---|:---|
| 핵심 특징 | 단위 설비의 고정 제어 | 실시간 생산 폐루프 최적화 | 가상 공장의 설계·검증 |
| 적용 기준 | 안정된 반복 공정 자동화 | 전 공정 품질·납기·유연성 개선 | 신설·변경 전 simulation |
| 주요 위험 | 설비 silo·국소 최적화 | OT 안전·보안 영향 확산 | 모델과 실제 공정의 차이 |

> 요약: OT·IT 정보 연결로 전체 생산성을 최적화함

### 쉽게 이해하기 (학습용)

- 자동 기계 한 대, 공장 전체가 서로 상황을 보고 조정하는 운영, 가상 공장에서 새 라인을 미리 검증하는 설계는 서로 다른 수준임

## Ⅵ. 실무 사례

1. 대상 환경의 도입 조건과 설계를 검증함
2. 운영 위험과 성과 지표를 검증함

### 쉽게 이해하기 (학습용)

- 자동차 조립라인은 MES genealogy와 torque·vision 검사 data를 연결해 불량 발생 조건을 찾고 해당 station의 tool 설정과 work instruction을 승인 후 조정함
- 식품 공장은 SCADA temperature·vibration·energy와 MES batch·recipe를 분석해 고장과 품질 편차를 예측하고 planned downtime에 정비 order를 배치함

## Ⅶ. 결론

- OT 안전 경계와 MES 추적성으로 자동화 범위 결정

### 쉽게 이해하기 (학습용)

- 자동 기계를 늘리는 것보다 계획실부터 현장까지 같은 사실을 보고 안전하게 다음 행동을 바꾸는 공장 운영이 핵심임
