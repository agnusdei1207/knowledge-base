## 미리 알고가기

- **사고 사슬(Chain-of-Thought, CoT)**: 중간 추론 단계를 순차적으로 생성해 답을 도출하는 방식
- **제로샷 CoT(Zero-shot CoT)**: 예시 없이 단계 추론 지시를 제공
- **퓨샷 CoT(Few-shot CoT)**: 중간 단계가 포함된 예시를 제공
- **자기 일관성(Self-Consistency)**: 여러 CoT 경로의 최빈 답을 선택
- **테스트 시점 연산(Test-Time Compute)**: 추론 때 생성·검증 예산을 증대



## Ⅰ. 개요

- 정의/개념: 복합 문제를 중간 단계로 푸는 기법
- 기존 한계: 정답만 직접 생성하면 **다단계 조건·계산의 중간 오류**를 식별하기 어려움

### 쉽게 이해하기 (학습용)
- 답만 바로 고르지 않고 작은 단계로 나누어 계산 후 결과를 확인

## Ⅱ. 특징

- 중간 문제·계산·가설의 **순차 추론**
- 반성·검증을 통한 **초안 오류 보정**
- 추론 비용 증가와 **생성 설명의 비충실성**

### 쉽게 이해하기 (학습용)
- 긴 설명이 반드시 실제 원인을 충실히 보여주는 것은 아님

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
|:---|:---|
| CoT 입력 | 목표·조건과 지시·예시 제공 |
| 중간 단계 | 계산·가설·논리를 순서대로 생성 |
| 답 추출기 | 중간 단계에서 최종 답 추출 |
| 검증 계층 | 규칙·계산기·검색으로 후보 확인 |
| 응답 경계 | 결론과 검증 근거만 제시 |

```text
사고 사슬
├─ CoT 입력
├─ 중간 단계
├─ 답 추출기
├─ 검증 계층
└─ 응답 경계
```

### 쉽게 이해하기 (학습용)

- 지시나 예시를 따라 중간 단계를 만들고, 필요하면 별도 도구로 후보 답을 확인함

## Ⅳ. 원리 및 절차 흐름도

```text
문제정리
  ↓
추론유도
  ↓
단계생성
  ↓
후보검증
  ↓
결론제시
```

| 절차 | 설명 |
|:---|:---|
| 절차 | 설명 |
|:---|:---|
| 문제정리 | 질문·조건·성공 기준 정리 |
| 추론유도 | 지시·예시 조합으로 추론 유도 |
| 단계생성 | 중간 단계와 후보 답 생성 |
| 후보검증 | 규칙·계산·검색으로 답 검증 |
| 결론제시 | 검증된 답과 필요 근거 제시 |

### 쉽게 이해하기 (학습용)

- CoT의 핵심은 중간 단계 생성이며, 검증 가능한 과업은 별도 검사로 오류를 줄일 수 있음

## Ⅴ. 응답 추론 방식 비교

| 구분 | 직접 응답 | 사고 사슬 |
|:---|:---|:---|
| 생성 구조 | 답을 바로 생성 | 중간 단계를 거쳐 생성 |
| 적합 과업 | 단순 조회·분류 | 산술·논리·다단계 과업 |
| 적용 기준 | 짧고 검증 쉬운 문제 | 단계 검증이 필요한 문제 |
| 핵심 특징 | 중간 단계 없이 답 생성 | 중간 추론 단계 후 답 생성 |
| 한계 | 복합 조건 누락 | 비용 증가·그럴듯한 오류 |

> 요약: 단계 검증을 통해 복잡 과업 오류 최소화

### 쉽게 이해하기 (학습용)

- 간단한 질문은 바로 답하고 복잡한 계산은 단계와 검산을 두는 것이 효율적임

## Ⅵ. 실무 사례

- 수치 업무는 공식·도구 계산·단위 검사를 결합한다

### 쉽게 이해하기 (학습용)

- 책임을 확인할 때 머릿속 독백보다 사용한 자료와 계산, 실행 기록을 보는 것이 신뢰할 수 있음

## Ⅶ. 결론

- 복합 문제의 중간 추론 오류를 줄이기 위해 **과업 난도·단계적 추론 효과·토큰 비용·민감 정보 노출**을 검토하고, 실제 정확도가 개선되는 과업에 CoT를 활용해야 한다.

### 쉽게 이해하기 (학습용)

- 좋은 단계 추론은 긴 독백이 아니라 오류를 찾고 답을 확인할 수 있는 구조임
