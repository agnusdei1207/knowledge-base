## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **인간 피드백 강화학습(Reinforcement Learning from Human Feedback, RLHF)**: 사람이 더 낫다고 고른 응답을 보상 신호로 바꾸어 언어 모델의 생성 정책을 조정하는 학습 방식을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.
- **상대 선호(Relative Preference)**: 같은 입력에 대한 여러 응답 중 어느 답이 더 유용•안전한지 비교한 판단을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.
- **지도 파인튜닝(Supervised Fine-Tuning, SFT)**: 모범 응답을 지도 학습하여 지시 추종의 초기 정책을 만드는 방식으로 정의된다.

</details>

- 정의/개념: 인간 선호 보상으로 생성 정책을 조정하는 **RLHF**
- 배경/필요성: **SFT 모범 답안 모방**만으로는 유용성•안전성의 상대 선호를 반영하기 어려움.

#### 한줄 요약
- **인간 상대 선호•보상 모델**로 생성 정책 조정

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **선호 데이터(Preference Data)**: 같은 입력의 여러 응답을 사람이 비교하여 우열을 기록한 학습 자료를 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.
- **보상 모델(Reward Model, RM)**: 응답이 인간에게 선호될 정도를 하나의 점수로 예측하는 모델을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.
- **쿨백-라이블러 발산 제약(Kullback-Leibler Divergence Constraint, KL 제약)**: 현재 정책이 기준 정책에서 지나치게 멀어지지 않도록 분포 차이에 벌점을 주는 제약으로 정의된다.

</details>

- **보상 모델 학습**: 인간 선호쌍 기반 응답 순위 예측
- **PPO•KL 제약**: 보상 향상과 정책 이탈 절충
- **간접 선호 최적화**: 보상 모델과 생성 정책 분리

#### 한줄 요약
- **보상 모델•PPO•KL 제약**으로 선호와 정책 이탈 절충

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **지도 파인튜닝 정책(SFT Policy)**: 모범 응답을 지도 학습하여 인간 피드백 강화학습의 초기 생성 정책과 참조 기준을 제공하는 정책을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.
- **선호 데이터 구성(Preference Dataset Construction)**: 복수 응답을 사람이 비교•순위화한 학습 자료를 나타낸다.
- **보상 모델(Reward Model, RM)**: 선호 데이터를 학습하여 정책이 생성한 응답의 인간 선호 수준을 점수화하는 역할을 수행한다.
- **가치 모델(Value Model)**: 현재 상태와 응답에서 기대되는 보상을 추정하여 정책 갱신을 돕는 모델을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.
- **참조 정책(Reference Policy)**: 인간 피드백 강화학습 중 동결되어 현재 정책의 과도한 확률분포 이탈을 측정하는 기준 모델을 가리킨다.
- **쿨백-라이블러 제약(Kullback-Leibler Constraint, KL Constraint)**: 학습 정책이 참조 정책에서 지나치게 멀어지지 않도록 분포 차이에 벌점을 부과하는 손실 항목으로 정의된다.

</details>

```text
[SFT 정책]──[선호 데이터]──[보상 모델]
                                 │
                          [정책•가치 모델]──[참조 정책•KL 제약]
```

선의 의미: 초기 정책•선호•보상•갱신•이탈 통제의 정적 연결을 나타냄.

| 구성요소 | 책임 |
|:---|:---|
| SFT 정책 | 모범 응답 기반 **초기 정책** 제공 |
| 선호 데이터 | 후보 응답 간 **인간 비교 순위** 저장 |
| 보상 모델 | 응답별 **인간 선호 점수** 예측 |
| 정책•가치 모델 | **응답 생성•기대 보상** 추정 |
| 참조 정책•KL 제약 | 과도한 **정책 이탈** 제한 |

#### 한줄 요약
- **SFT•선호 데이터•보상•정책•KL 제약** 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **근접 정책 최적화(Proximal Policy Optimization, PPO)**: 한 번의 정책 갱신 폭을 제한하면서 보상 모델 점수를 높이는 강화학습 알고리즘을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.
- **독립 평가(Independent Evaluation)**: 보상 모델 점수와 별개로 인간이 실제 유용성•안전성•실패 행동을 확인하는 평가를 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.

</details>

```text
정책 모델
   │ 1. 후보 응답 생성
   ▼
인간 평가자
   │ 2. 선호쌍•보상 모델 학습
   ▼
┌────────── 정책 학습 종료 전 반복 ──────────┐
│ 보상 모델                                  │
│   │ 3. 정책 응답 보상 산정                 │
│   ▼                                        │
│ PPO 학습기                                 │
│   └ 4. PPO•KL 정책 갱신 ──▶ 정책 모델     │
└────────────────────────────────────────────┘
   │ 5. 독립 인간 평가
   ▼
독립 평가기
```

### 동작 원리

1. 후보 응답 생성: 같은 입력의 여러 답으로 **비교 표본**을 구성함.
2. 선호쌍•보상 모델 학습: 인간 우선순위로 **보상 함수**를 학습함.
3. 정책 응답 보상 산정: 현재 생성 결과에 **학습 보상 점수**를 부여함.
4. PPO•KL 정책 갱신: 보상을 높이되 참조 정책과의 **분포 이탈**을 제한함.
5. 독립 인간 평가: 보상 점수 밖의 유용성•안전성 실패를 검증함.

#### 한줄 요약
- **후보•선호쌍•보상•PPO•독립 평가** 수행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **RLHF 적용(RLHF Fine-Tuning)**: 보상 모델•PPO•KL 제약으로 정책 탐색과 선호 점수를 향상시키는 방식을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.
- **직접 선호 최적화(Direct Preference Optimization, DPO)**: 별도 보상 모델과 온라인 강화학습 없이 선호 응답쌍으로 정책을 직접 조정하는 기법을 나타낸다.

</details>

- 시연 모방은 **SFT**, 보상 탐색은 **RLHF**, 선호쌍 직접 학습은 **DPO**

| 비교 기준 | SFT | RLHF | DPO |
|:---|:---|:---|:---|
| 적용 기준 | **지시 추종** 학습 | 보상 기반 **정책 탐색** | 고정 **선호쌍** 직접 학습 |
| 핵심 특징 | 모범 응답 **모방** | RM•PPO•KL **정책 최적화** | 선호쌍 **직접 정책 최적화** |
| 한계 | 시연 **품질•범위 의존** | 복잡성•**보상 해킹**•불안정 | 데이터 밖 **정책 탐색 제한** |

#### 한줄 요약
- **학습 신호•정책 탐색 필요성**으로 후학습 방식 구분

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **평가자 편향(Annotator Bias)**: 특정 집단의 선호가 과대표되어 보상 모델의 기준이 왜곡되는 현상을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.
- **보상 해킹(Reward Hacking)**: 실제 인간 의도보다 보상 모델의 허점을 이용하는 응답으로 높은 점수를 얻는 현상을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.
- **정책 붕괴(Policy Collapse)**: 보상 최적화 중 언어 품질과 기존 능력을 잃고 제한된 응답에 치우치는 현상으로 정의된다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 평가자 구성 편향의 **보상 모델 왜곡** | **집단별 선호 일치도•갈등 표본 분석** | 선호 기준의 **대표성 확보** |
| 높은 RM 점수의 **보상 해킹** | **독립 인간 평가•적대적 프롬프트** | 실제 유용성 **검증** |
| 낮은 KL 제약의 **정책 붕괴** | **KL 계수별 보상•언어 품질 평가** | 정책 이탈 **통제** |

#### 한줄 요약
- **평가자 대표성•보상 해킹•정책 이탈** 검증

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **선호 대표성(Preference Representativeness)**: 보상 모델이 다양한 사용자 집단과 상황의 선호 기준을 균형 있게 반영하는 정도를 나타낸다.
- **쿨백-라이블러 발산 계수 선택(KL Divergence Coefficient Selection)**: 보상 향상과 기존 정책의 언어 품질 보존을 함께 평가하여 이탈 제약 강도를 정하는 과정을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.

</details>

- 탐색이 필요하면 **RLHF**, 고정 선호쌍 직접 학습은 **DPO** 선택

#### 한줄 요약
- **정책 탐색•운영 복잡성**에 따라 선호 최적화 방식 결정
