## 미리 알고가기

- **RLHF (Reinforcement Learning from Human Feedback, RLHF)**: 인간 선호로 정책 조정
- **RM (Reward Model, RM)**: 응답의 인간 선호 점수 예측
- **PPO (Proximal Policy Optimization, PPO)**: 정책 갱신 폭 제한
- **SFT (Supervised Fine-Tuning, SFT)**: 모범 응답으로 초기 학습
- **KL (Kullback-Leibler Divergence, KL)**: 참조 정책 차이 측정
- **DPO (Direct Preference Optimization, DPO)**: 선호쌍으로 정책 직접 학습


## Ⅰ. 개요

- **정의/개념**: 인간 선호 보상으로 생성 정책을 강화학습
- **배경/필요성**: 정답 모방을 넘어 품질·안전 기준에 정렬

### 쉽게 이해하기 (학습용)

- 여러 응답 중 나은 결과를 채점하는 모델을 만들고 정책을 그 기준에 맞춥니다.

## Ⅱ. 특징

- 선호 데이터가 주관적 품질을 상대적 보상으로 바꾼다.
- 보상 모델은 지침과 데이터 분포에 따라 편향될 수 있다.
- 정책은 보상을 높이면서 참조 정책 이탈을 제한한다.
- 보상 해킹과 분포 밖 입력의 성능 저하를 감시한다.

### 쉽게 이해하기 (학습용)

- 보상 모델의 치우친 채점 기준은 정책을 잘못된 방향으로 유도합니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| SFT 정책 | 모범 응답을 학습한 초기 정책 |
| 선호 데이터 | 응답 비교 순위 정보 |
| 보상 모델 | 인간 선호를 점수로 예측 |
| 정책·가치 | 응답 생성 및 기대 보상 계산 |
| 참조 제약 | 정책 이탈 제한 및 정렬 유도 |

```text
초기정책 ─── 선호자료 ─── 보상모델 ─── 갱신정책
                   ├── 참조정책 ─┘
```

### 쉽게 이해하기 (학습용)

- 인간 선호를 배운 보상 모델이 정책 갱신에 사용할 점수를 제공합니다.

## Ⅳ. 원리 및 절차 흐름도

```text
정책준비
↓
선호수집
↓
보상학습
↓
정책최적
↓
결과평가
```

| 절차 | 설명 |
|:---|:---|
| 정책준비 | SFT 정책 및 참조 정책 준비 |
| 선호수집 | 후보 응답 인간 선호쌍 수집 |
| 보상학습 | 선호 관계 예측 RM 학습 |
| 정책최적 | PPO 및 KL 제약 정책 갱신 |
| 결과평가 | 사람 평가로 품질 검증 |

### 쉽게 이해하기 (학습용)

- 선호 자료로 보상 모델을 학습하고 PPO로 정책을 갱신합니다.

## Ⅴ. 종류 및 비교

| 판단 기준 | SFT | RLHF | DPO |
|:---|:---|:---|:---|
| 학습 신호 | 모범 응답 | RM 예측 점수 | 선호·비선호 응답쌍 |
| 적용 기준 | 지시 추종 필요 시 | 온라인 보상 필요 시 | 고정 선호쌍 충분 시 |
| 주요 위험 | 응답 품질 의존 | 보상 해킹·불안정 | 데이터 밖 탐색 부재 |

> 요약: 학습 방식별 비용과 구조를 비교함

### 쉽게 이해하기 (학습용)

- SFT·RLHF·DPO는 정책을 조정하는 학습 신호가 다릅니다.

## Ⅵ. 실무 사례

- 지침·평가 데이터 불일치 확인
- 점수 상승 대비 품질 하락 시 보상 해킹 조사
- 다양성·거절률·갱신 강도 조정

### 쉽게 이해하기 (학습용)

- 보상 점수뿐 아니라 답변의 유용성과 과도한 거절 여부를 사람이 확인해야 합니다.

## Ⅶ. 결론

- RLHF는 선호 대표성과 보상 해킹을 지속 감시한다.

### 쉽게 이해하기 (학습용)

- 보상 모델의 편향과 허점을 독립적인 사람 평가로 계속 감시해야 합니다.
