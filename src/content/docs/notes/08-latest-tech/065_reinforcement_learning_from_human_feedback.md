## 미리 알고가기

- **인간 피드백 강화학습(Reinforcement Learning from Human Feedback, RLHF)**: 인간 선호를 보상으로 변환해 모델 정책을 최적화하는 방식
- **보상 모델(Reward Model, RM)**: 응답에 대한 인간 선호 점수를 예측하는 모델
- **근접 정책 최적화(Proximal Policy Optimization, PPO)**: 정책 갱신 폭을 제한해 학습 안정성을 높이는 강화학습 알고리즘
- **지도 미세조정(Supervised Fine-Tuning, SFT)**: 모범 응답으로 초기 정책을 학습하는 단계
- **쿨백-라이블러 발산(Kullback-Leibler Divergence, KL)**: 기준 모델과 현재 정책의 확률분포 차이를 측정하는 비대칭 척도
- **직접 선호 최적화(Direct Preference Optimization, DPO)**: 별도 보상 모델과 강화학습 없이 선호 응답 쌍으로 정책을 학습하는 방식


## Ⅰ. 개요

- 정의/개념: 인간의 응답 비교로 보상 모델을 학습하고 **생성 정책을 보상 최대화 방향으로 강화학습**
- 기존 한계: 모범 답안 기반 SFT만으로는 응답의 유용성·선호·안전처럼 상대 비교가 필요한 인간 기준을 충분히 반영하기 어렵다.

### 쉽게 이해하기 (학습용)

- 여러 응답 중 나은 결과를 채점하는 모델을 만들고 정책을 그 기준에 맞춥니다.

## Ⅱ. 특징

- **인간 선호쌍**으로 응답 순위를 예측하는 보상 모델을 학습한다.
- **PPO 보상 최대화와 KL 페널티**로 정책을 갱신하면서 참조 정책 이탈을 제한한다.
- **평가자 편향·보상 해킹·과도한 거절·분포 밖 성능**을 독립 평가한다.

### 쉽게 이해하기 (학습용)

- 보상 모델의 치우친 채점 기준은 정책을 잘못된 방향으로 유도합니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| SFT 정책 | 모범 응답을 학습한 초기 정책 |
| 선호 데이터 | 응답 비교 순위 정보 |
| 보상 모델 | 인간 선호를 점수로 예측 |
| 정책·가치 | 응답 생성 및 기대 보상 계산 |
| 참조 제약 | 정책 이탈 제한 및 정렬 유도 |

```text
SFT정책 ─후보응답→ 인간선호 ─→ 보상모델
   ├──────────────→ PPO정책
참조정책 ── KL제약 ────────┘
```

### 쉽게 이해하기 (학습용)

- 인간 선호를 배운 보상 모델이 정책 갱신에 사용할 점수를 제공합니다.

## Ⅳ. 원리 및 절차 흐름도

```text
정책 준비
↓
선호 수집
↓
보상 학습
↓
정책 최적화
↓
결과 평가
```

| 절차 | 설명 |
|:---|:---|
| 정책 준비 | SFT 정책·고정 참조 정책 준비 |
| 선호 수집 | 후보 응답 생성·인간 순위 수집 |
| 보상 학습 | 선호 관계 예측 RM 학습 |
| 정책 최적화 | PPO 보상·KL 페널티로 갱신 |
| 결과 평가 | 독립 사람 평가·안전 검증 |

### 쉽게 이해하기 (학습용)

- 선호 자료로 보상 모델을 학습하고 PPO로 정책을 갱신합니다.

## Ⅴ. 종류 및 비교

| 언어 모델 정렬 방식 | SFT | RLHF | DPO |
|:---|:---|:---|:---|
| 적용 기준 | 지시 추종 필요 시 | 보상 기반 정책 탐색 필요 시 | 고정 선호쌍 충분 시 |
| 핵심 특징 | 모범 응답 모방 | RM·PPO·KL 정책 최적화 | 선호쌍 직접 정책 최적화 |
| 한계 | 시연 품질·범위 의존 | 복잡성·보상 해킹·불안정 | 선호 데이터 밖 탐색 제한 |

> 요약: 학습 방식별 비용과 구조를 비교함

### 쉽게 이해하기 (학습용)

- SFT·RLHF·DPO는 정책을 조정하는 학습 신호가 다릅니다.

## Ⅵ. 실무 사례

1. 보상 점수 상승 시 **독립 사람 평가로 보상 해킹 확인**

### 쉽게 이해하기 (학습용)

- 보상 점수뿐 아니라 답변의 유용성과 과도한 거절 여부를 사람이 확인해야 합니다.

## Ⅶ. 결론

- 인간 선호 정렬을 위해 대표성·보상 편향을 검토하여 **RLHF** 활용

### 쉽게 이해하기 (학습용)

- 보상 모델의 편향과 허점을 독립적인 사람 평가로 계속 감시해야 합니다.
