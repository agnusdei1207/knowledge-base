## 미리 알고가기

- **마르코프 결정과정(Markov Decision Process, MDP)**: 순차 결정을 상태·행동·보상으로 모델링함
- **부분관측 마르코프 결정과정(Partially Observable Markov Decision Process, POMDP)**: 숨은 상태를 관측 이력으로 추정함
- **할인율 $\gamma$(감마)**: 미래 보상의 현재 반영 비율임



## Ⅰ. 개요

- **정의/개념**: 상태·행동·전이·보상으로 순차 환경을 표현
- **배경/필요성**: 행동이 바꾸는 미래 상태와 보상을 계산

### 쉽게 이해하기 (학습용)

- 현재 칸과 행동, 다음 칸의 확률과 점수를 규칙표로 정리한 보드게임 모델과 같습니다.

## Ⅱ. 특징

- 현재 상태가 주어지면 다음 전이는 과거와 조건부 독립이다.
- 전이확률과 보상 함수가 행동 결과의 분포를 정한다.
- 정책은 상태별 행동 규칙으로 환경 모델과 구분된다.
- 할인율이 미래 보상의 현재 반영 비율을 정한다.

### 쉽게 이해하기 (학습용)

- 현재 상태만으로 다음 이동 확률과 점수를 정할 수 있어야 과거 기록을 다시 볼 필요가 없습니다.

## Ⅲ. 구성요소 및 구조

| 구성요소 | 핵심 키워드 | 직관적 설명 |
|:---|:---|:---|
| 상태 | 현재 정보 | 다음 전이 분포 결정 |
| 행동 | 제어 집합 | 상태서 선택 가능 |
| 전이확률 | 확률분포 | 행동별 다음 상태 |
| 보상함수 | 즉시 성과 | 상태 전이 가치 |
| 할인율 | 반영 비율 | 미래 보상의 현재값 |

### 쉽게 이해하기 (학습용)

- 현재 상태·행동·전이 확률·보상이 환경의 규칙을 이룹니다.

## Ⅳ. 원리 및 절차 흐름도

```text
상태제공
  ↓
행동선택
  ↓
전이발생
  ↓
종료판정
  ↓
궤적제공
```

| 절차 | 설명 |
|:---|:---|
| 상태제공 | 현재 상태를 에이전트에 전달함 |
| 행동선택 | 정책이 상태 행동을 선택함 |
| 전이발생 | 전이확률로 보상·상태 발생함 |
| 종료판정 | 종료 전 상태 반복 이동함 |
| 궤적제공 | 종료 시 상태·행동·보상열 제공함 |

### 쉽게 이해하기 (학습용)

- 환경은 전이와 보상을 정하고 별도 알고리즘이 정책을 평가·학습합니다.

## Ⅴ. 종류 및 비교

| 판단 기준 | 다중 선택 밴딧 | MDP | 부분관측 MDP |
|:---|:---|:---|:---|
| 모델링 범위 | 행동별 보상 모델링 | 상태·행동 전이 모델링 | 상태·관측 분포 모델링 |
| 결정 정보 | 선택 결과 보상 추정 | 상태 전이 정보 활용 | 이력 기반 믿음 상태 추정 |
| 적용 기준 | 환경 불변 시 적용 | 완전 관측 시 적용 | 상태 일부 은닉 시 적용 |

> 요약: 모델링 범위와 관측 가능성에 따라 적합 환경을 선택함

### 쉽게 이해하기 (학습용)

- 행동이 미래 상태를 바꾸지 않으면 밴딧, 상태가 숨으면 부분관측 MDP를 사용합니다.

## Ⅵ. 실무 사례

- 냉각 제어는 부하·온도·출력·전력비로 환경을 정의한다.
- 재고 제어는 재고·수요·주문·비용으로 환경을 정의한다.

### 쉽게 이해하기 (학습용)

- 냉각 제어 전에 무엇을 상태로 보고 어떤 행동을 허용하며 어떤 결과에 보상할지 먼저 정합니다.

## Ⅶ. 결론

- 정보가 부족하면 상태를 보강하거나 POMDP로 전환한다.

### 쉽게 이해하기 (학습용)

- 현재 정보로 다음 상황을 설명할 수 없으면 이력·센서를 상태에 더하거나 숨은 상태 모델을 사용해야 합니다.
