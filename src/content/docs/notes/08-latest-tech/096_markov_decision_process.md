## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **MDP (Markov Decision Process)**: 순차적 의사결정 과정을 상태, 행동, 전이확률, 보상으로 표현하는 수학적 모델
- **순차 의사결정 (Sequential Decision Making)**: 행동이 미래의 상태 및 보상에 연속적으로 영향을 주는 문제

</details>

- 정의: 상태, 행동, 전이확률, 보상을 통해 순차적 의사결정 환경을 모델링하는 수학적 프레임워크
- 배경: 단발성 의사결정 모델의 미래 상태 전이 및 장기 보상 반영 한계 극복

#### 한줄 요약
- 순차적 의사결정 환경의 수학적 모델링 구현

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **마르코프 성질 (Markov Property)**: 과거 이력과 무관하게 현재 상태가 미래 상태를 결정하는 독립성
- **전이확률 (Transition Probability)**: 특정 상태/행동 시 다음 상태로의 이동 가능성 분포
- **할인율 (Discount Factor, $\gamma$)**: 미래 보상을 현재 가치로 환산하는 가중 계수

</details>

- **마르코프 성질**: 현재 상태 기반의 독립적 미래 상태 전이
- **환경 동역학**: 상태•행동별 전이확률 및 보상 함수 정의
- **장기 최적화**: 정책 및 할인율 기반 누적 가치 계산

#### 한줄 요약
- 마르코프 성질 기반의 상태 전이 모델링 및 장기 가치 최적화 원칙 준수

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **상태 (State)**: 의사결정에 필요한 환경 정보를 압축한 표현
- **행동 집합 (Action Set)**: 각 상태에서 선택 가능한 행동 모음
- **보상 함수 (Reward Function)**: 상태 전이 발생 시점의 즉시 성과

</details>

```text
                  [상태 저장소] ----- [행동 선택기]
                     \                   /      \
                  [정책•가치 평가기]       [전이 모델]
                                                |
                                           [보상 함수]
```

선의 의미: 모델은 상태 전이와 보상 함수로 환경 동역학을 정의하고, 정책•가치 평가기로 의사결정 최적화.

| 구성요소 | 책임 |
|:---|:---|
| 상태 저장소 | 전이 결정용 정보 보관 |
| 행동 선택기 | 허용 행동 집합 제공 |
| 전이 모델 | 다음 상태 확률 분포 산출 |
| 보상 함수 | 즉시 보상 신호 산출 |
| 정책/가치 | 기대 누적 보상 기반 의사결정 |

#### 한줄 요약
- 상태•행동•전이•보상의 상호작용 체계 구현

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **상태 전이 (State Transition)**: 전이확률 기반의 상태 변화 과정
- **할인 가치 (Discounted Value)**: 미래 보상의 현재 시점 가치 환산값

</details>

```text
┌─────── 에피소드 루프 ───────┐
│ 1. 현재 상태 ──▶ 행동 선택  │
│ 2. 전이/보상 ◀─ 선택 행동   │
│ 3. 가치/정책 갱신 ◀─ 보상   │
└─────────────┬─────────────┘
```

**동작 원리**
1. **관측**: 전이 정보를 요약한 상태 파악
2. **선택**: 정책 기반 행동 결정
3. **전이**: 전이 확률에 따른 상태 변화
4. **산출**: 즉시 보상 및 다음 상태 획득
5. **평가**: 할인 가치 기반 정책 개선

#### 한줄 요약
- 상태 전이 및 보상 기반의 반복적인 정책 가치 최적화 프로세스

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **다중 선택 밴딧 (Multi-armed Bandit)**: 상태 전이 없이 독립적 행동 보상 학습
- **POMDP (Partially Observable MDP)**: 상태 은닉 시 관측값으로 상태 추정
- **믿음 상태 (Belief State)**: 관측 이력 기반의 상태 확률 분포

</details>

| 모델 | MDP | 밴딧 | POMDP |
|:---|:---|:---|:---|
| 주요 적용 | 완전 상태 관측 | 상태 전이 없음 | 상태 일부 은닉 |
| 핵심 특징 | 상태•전이•보상 모델 | 독립적 행동 보상 | 관측 기반 믿음 상태 |
| 한계점 | 관측 가정 엄격 | 순차적 영향 배제 | 계산 복잡성 증대 |

#### 한줄 요약
- 관측 가능성 및 상태 전이 유무에 따른 모델 선택

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **마르코프성 부족 (Lack of Markov Property)**: 현 상태 내 전이•보상 정보 불충분
- **목표 불일치 (Goal Misalignment)**: 보상 함수와 실무 장기 성과 간 불일치
- **전이 모델 오차 (Model Error)**: 추정 전이 확률과 실제 환경 변화의 차이

</details>

| 문제 | 대책 | 기대 효과 |
|:---|:---|:---|
| 마르코프성 부족 | 이력/센서 기반 상태 표현 보강 | 전이 예측 정밀도 향상 |
| 보상 불일치 | 장기 목표/제약 사항 보상 함수 반영 | 정책 왜곡 완화 |
| 전이 모델 오차 | 운영 데이터 기반 전이확률 검증 | 가치 추정 편향 감소 |

#### 한줄 요약
- 상태 표현 최적화 및 보상 체계 정렬을 통한 의사결정 정확성 확보

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **관측 가능성 (Observability)**: 의사결정용 환경 정보의 파악 가능 정도
- **상태 표현 (State Representation)**: 예측 가능성을 극대화한 정보 구조

</details>

- 환경의 관측 가능성 및 상태 전이 예측 기반 의사결정 체계 적용
- 비즈니스 목표 정렬을 위한 보상 함수 설계 및 검증 필수

#### 한줄 요약
- 상태 관측 기반의 MDP 최적 의사결정 모델 적용
