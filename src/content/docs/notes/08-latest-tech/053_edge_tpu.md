## 미리 알고가기

- **텐서 처리 장치(Tensor Processing Unit, TPU)**: 영문 머리글자를 딴 표기로 “티피유”로 읽으며, 텐서 연산 가속 프로세서
- **주문형 집적 회로(Application-Specific Integrated Circuit, ASIC)**: 영문 머리글자를 딴 표기로 “에이식”으로 읽으며, 특정 연산에 맞춰 설계한 전용 회로
- **8비트 정수(8-bit Integer, INT8)**: Integer와 비트 수를 결합한 표기로 “인트 에잇”으로 읽으며, 정수 추론의 낮은 정밀도 표현
- **양자화 인지 학습(Quantization-Aware Training, QAT)**: 영문 머리글자를 딴 표기로 “큐에이티”로 읽으며, 학습 중 양자화 오차를 반영하는 기술
- **신경망 처리 장치(Neural Processing Unit, NPU)**: 영문 머리글자를 딴 표기로 “엔피유”로 읽으며, 신경망 연산 전용 가속기



## Ⅰ. 개요

- **정의/개념**: INT8 모델용 구글 추론 ASIC
- **배경/필요성**: 범용 프로세서만으로 에지 장치의 저전력 INT8 추론 성능 확보 곤란

### 쉽게 이해하기 (학습용)

- Edge TPU는 INT8 모델을 현장에서 빠르게 실행한다

## Ⅱ. 특징

- 가중치·활성값의 **INT8 양자화**
- 지원 연산의 **하위 그래프 컴파일**
- CPU 폴백·전처리·전송을 포함한 **종단 지연**

### 쉽게 이해하기 (학습용)

- 지원되지 않는 연산이 많으면 CPU 왕복으로 속도가 떨어진다

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 설계 요소 | 설명 |
|:---|:---|
| 정수 모델 | INT8 기반 표현함 |
| 컴파일러 | 하위 그래프 변환함 |
| 런타임 | 장치 구간 호출함 |
| ASIC | 정수 연산 실행함 |
| 인터페이스 | 텐서 데이터 전달함 |

```text
정수 모델
├─ 컴파일러
├─ 실행 관리
├─ TPU 가속
└─ CPU 폴백
```

### 쉽게 이해하기 (학습용)

- 지원 연산은 Edge TPU, 미지원 연산은 CPU가 실행함

## Ⅳ. 원리 및 절차 흐름도

```text
모델 변환
↓
완전 양자화
↓
지원 판정
↓
분할 실행
↓
결과 결합
```

| 절차 | 설명 |
|:---|:---|
| 변환 | 실행 형식 변경함 |
| 양자화 | INT8 변환함 |
| 판정 | 가속 여부 확인함 |
| 실행 | 폴백 구간 분리함 |
| 결합 | 최종 결과 결합함 |

### 쉽게 이해하기 (학습용)

- INT8 변환 후 TPU와 CPU 구간을 나눠 실행함

## Ⅴ. 에지 추론 가속 방식 비교

| 구분 | CPU 실행 | GPU 가속 | Edge TPU 가속 |
|:---|:---|:---|:---|
| 실행 방식 | 범용 명령 | 병렬 연산 | INT8 가속 |
| 적용 기준 | 미지원 연산 모델 | 정밀도 조절 모델 | INT8 모델 |
| 핵심 특징 | 범용 연산자 실행 | 병렬 텐서 연산 | INT8 전용 ASIC 추론 |
| 한계 | 처리량·전력 효율 | 전력·드라이버 부담 | 컴파일·연산자 제약 |
| 주요 병목 | 낮은 병렬도 | 메모리 대역폭 | 폴백·전송 지연 |

> 요약: INT8 정수 연산에 특화된 추론 가속기임

### 쉽게 이해하기 (학습용)

- CPU는 범용, GPU는 병렬, Edge TPU는 INT8 추론에 맞음

## Ⅵ. 실무 사례

- 매핑 결과로 객체 탐지의 지원 비율을 확인한다
- 전처리·전송·폴백을 합쳐 배치 여부를 정한다

### 쉽게 이해하기 (학습용)

- 카메라 분석 모델은 가속기 계산 시간만 재면 안 되고, 영상을 준비하고 옮기며 CPU가 대신 처리한 시간까지 더해야 실제 반응 시간을 알 수 있음

## Ⅶ. 결론

- CPU 폴백·전송이 지배하면 실행 경로를 바꾼다

> 요약: 정수 연산 가속으로 로컬 추론을 최적화함

### 쉽게 이해하기 (학습용)

- 컴파일 성공 범위와 폴백 시간을 함께 확인해야 한다
