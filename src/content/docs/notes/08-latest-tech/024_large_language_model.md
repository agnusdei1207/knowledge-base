## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **대규모 언어 모델(Large Language Model, LLM)**: 대규모 말뭉치에서 토큰 간 관계를 학습하여 여러 언어 과업을 이해하고 생성하는 모델이다.
- **말뭉치(Corpus)**: 언어 패턴과 지식을 학습하도록 수집•정제한 대규모 텍스트 집합이다.

</details>

- 정의: 대규모 말뭉치의 토큰 관계를 사전학습한 **LLM**이다.
- 배경/필요성: 과업별 전용 모델은 학습한 지식•문맥 표현을 범용으로 재사용하기 어렵음.

#### 한줄 요약

- **LLM**은 대규모 말뭉치를 자기지도 방식으로 사전학습

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **자기지도 사전학습(Self-supervised Pre-training)**: 텍스트 자체에서 예측 목표를 만들어 별도 정답 표기 없이 언어 표현을 학습하는 방식이다.
- **문맥 학습(In-context Learning)**: 모델 매개변수를 바꾸지 않고 입력의 지시와 예시로 과업을 수행하는 능력이다.
- **확률적 생성**: 다음 토큰 확률분포에서 출력을 선택해 결과가 달라질 수 있는 생성 방식이다.

</details>

- **자기지도 사전학습**: 비정형 언어 패턴 학습
- **문맥 학습**: 지시•예시로 과업 적응
- **확률적 생성**: 출력 변동과 사실성•편향 한계

#### 한줄 요약

- 다음 토큰 예측은 **최신성•사실성•공정성 미보장**

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **어텐션(Attention)**: 토큰 간 관련도에 따라 다른 토큰의 정보를 가중 결합하여 문맥 표현을 만드는 연산이다.
- **피드포워드 신경망(Feed-Forward Network, FFN)**: 어텐션을 거친 각 토큰 표현을 위치별로 비선형 변환하는 신경망.
- **토크나이저(Tokenizer)**: 입력 문자열을 모델 어휘의 토큰 식별자 열로 변환하는 구성요소이다.

</details>

```text
                   [토크나이저]
                        |
                  [임베딩 계층]
                        |
                [트랜스포머 블록]
                        |
                   [출력 계층]
```

선의 의미: 토크나이저와 임베딩 계층이 입력 표현 경계를 이루고, 트랜스포머 블록과 출력 계층이 문맥 표현 및 어휘 확률을 담당하는 LLM 계층 구조를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 토크나이저 | **토크나이저**가 문자열을 토큰 식별자로 변환 |
| 임베딩 계층 | 토큰•위치를 연속 벡터로 표현 |
| 트랜스포머 블록 | **어텐션**과 **FFN**으로 문맥 표현 갱신 |
| 출력 계층 | 어휘별 다음 토큰 확률 산출 |

#### 한줄 요약

- **토크나이저•임베딩•트랜스포머•출력 계층** 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **키-값 캐시(Key-Value Cache, KV Cache)**: 자기회귀 생성 중 이전 토큰의 어텐션 키와 값을 저장하여 중복 계산을 줄이는 저장소로 정의된다.
- **자기회귀 생성(Autoregressive Generation)**: 지금까지의 입력과 생성 토큰을 조건으로 다음 토큰을 하나씩 예측하는 방식.
- **입력 문자열 토큰화**: 입력 문자열을 모델 어휘에 맞는 토큰 식별자 열로 변환하는 절차.
- **다음 토큰 표본 선택**: 현재 문맥의 조건부 확률분포에서 다음 출력 토큰을 결정하는 절차로 정의된다.
- **자기회귀 토큰 생성**: 선택한 토큰을 문맥에 추가하며 종료 조건까지 다음 토큰 예측을 반복하는 절차로 정의된다.

</details>

```text
사용자
   │ 입력 문자열
   ▼
토크나이저
   │ 1. 입력 문자열 토큰화
   │ 토큰•위치 표현 전달
   ▼
언어 모델
   │ 2. KV Cache 조회
   ▼
키-값 캐시
   │ 과거 어텐션 상태 반환
   ▼
언어 모델
   │ 3. 어텐션•FFN 연산
   │ 4. 다음 토큰 표본 선택
   ├───────────────────┐
   │ 종료 조건 전까지 │
   └─────────┬─────────┘
   │ 5. 자기회귀 토큰 생성
   │ 생성 결과
   ▼
사용자
```

### 동작 원리

1. 입력 문자열 토큰화: 문자열을 모델 어휘 단위로 분할함.
2. KV Cache 조회: 과거 토큰의 어텐션 상태를 재사용함.
3. 어텐션•FFN 연산: 관련 토큰 결합과 위치별 표현을 변환함.
4. 다음 토큰 표본 선택: 현재 문맥의 조건부 확률분포에서 출력을 결정함.
5. 자기회귀 토큰 생성: 새 키•값 상태를 추가하며 종료까지 반복함.

#### 한줄 요약

- **KV Cache•자기회귀 생성**으로 다음 토큰 반복 예측

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **디코더형 모델**: 앞선 토큰을 조건으로 다음 토큰을 생성하여 개방형 생성에 적합한 구조.
- **인코더형 모델**: 양방향 문맥을 반영해 분류•검색에 적합한 구조이다.
- **인코더-디코더형 모델**: 입력 표현을 조건으로 디코더가 출력 열을 생성하는 구조이다.

</details>

| 모델 구조 | 디코더형 | 인코더형 | 인코더-디코더형 |
|:---|:---|:---|:---|
| 적용 기준 | 개방형 생성 중심 | 입력 이해 중심 | 입력•출력 변환 중심 |
| 핵심 특징 | **자기회귀 생성** | 양방향 문맥 표현 학습 | 입력 인코딩 후 조건부 생성 |
| 한계 | 환각•긴 생성 비용 | 직접 생성 능력 제한 | 구조•추론 비용 증가 |

#### 한줄 요약

- 생성은 **디코더형**, 이해는 인코더형, 변환은 인코더-디코더형

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **검색 증강 생성(Retrieval-Augmented Generation, RAG)**: 외부에서 검색한 최신•권한별 근거를 모델 문맥에 넣어 답변을 생성하는 방식.
- **환각(Hallucination)**: 근거나 확인 가능한 사실과 다른 내용을 그럴듯하게 생성하는 현상이다.
- **문맥 압축**: 긴 입력에서 목표에 필요한 정보만 요약•선별하여 토큰과 추론 비용을 줄이는 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 학습 시점 이후 지식의 최신성 부족 | **RAG**로 최신•권한별 검색 근거 제공 | 답변의 근거성•최신성 보완 |
| 확률적 생성에 따른 **환각** | 근거 검증•구조화 출력•인간 검토 | 사실 오류의 업무 반영 차단 |
| 긴 문맥•생성의 추론 비용 | **문맥 압축**•**KV Cache**•SLM 라우팅 | 지연•토큰•컴퓨팅 비용 절감 |
| 민감 데이터의 모델 유출 | 입력 최소화•접근통제•출력 검사 | 비밀정보 무단 노출 방지 |

#### 한줄 요약

- **RAG**로 권한이 있는 근거만 문맥에 넣어 최신성 보완

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **검증형 적용**: 오류 피해가 큰 업무에서 근거 확인•구조화 출력•사람 검토를 결합하여 LLM 결과를 사용하는 방식.
- **소형 언어 모델 라우팅(Small Language Model Routing, SLM Routing)**: 과업 난도와 비용 기준에 따라 일부 요청을 더 작은 모델로 보내 지연과 컴퓨팅 비용을 줄이는 방식.

</details>

- 최신 지식은 **RAG**, 고위험은 검증형, 비용 제약은 SLM

#### 한줄 요약

- **최신성•오류 피해•비용**에 따라 보완 방식을 결정
