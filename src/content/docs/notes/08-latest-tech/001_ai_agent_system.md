## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **인공지능 에이전트 시스템(Artificial Intelligence Agent System, AI Agent System)**: 목표를 작업으로 계획하고 도구를 실행하며 관찰 결과에 따라 행동을 조정하는 자율 시스템을 의미한다.

</details>

- 정의/개념: 목표 계획•도구 실행•관찰 기반 행동 조정을 수행하는 **AI Agent System**임.
- 배경/필요성: 단발 생성 모델로는 장기 상태•외부 실행•오류 복구를 관리하기 어려움.

#### 한줄 요약
- **AI Agent**는 목표 분해•도구 실행•재계획을 수행한다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **목표 지향성(Goal-Oriented)**: 최종 목표를 의존 관계와 완료 조건이 있는 하위 작업으로 분해하는 특성을 말한다.
- **추론-행동(Reasoning and Acting, ReAct)**: 추론으로 행동을 선택하고 실행 결과를 관찰해 오류 복구와 재계획에 반영하는 반복 방식이다.
- **계획 축(Planning Axis)**: 목표를 하위 작업으로 분해하고 의존성•상태•완료 조건을 관리하는 기능 영역을 지칭한다.
- **실행 축(Execution Axis)**: 도구 실행 결과를 관찰해 오류를 복구하고 다음 행동을 재계획하는 기능 영역을 뜻한다.
- **통제 축(Control Axis)**: 권한•승인•비용•감사 정책으로 에이전트의 행동 범위를 제한하는 기능 영역이다.

</details>

- **계획 축**: 목표 분해와 상태 유지로 장기 작업 단계를 실행함.
- **실행 축**: **ReAct** 반복 기반 오류 복구 및 재계획을 수행함.
- **통제 축**: 권한•승인•비용•감사 정책으로 자율 행동을 제한함.

#### 한줄 요약
- **목표 지향성**과 **실행 축**으로 행동을 조정하고 작업을 재개한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **대규모 언어 모델(Large Language Model, LLM)**: 자연어 지시와 작업 문맥을 바탕으로 계획•응답•행동 후보를 생성하는 에이전트의 추론 모델을 의미한다.
- **오케스트레이터(Orchestrator)**: 목표•정책•상태를 바탕으로 모델, 계획•평가, 도구 호출의 실행 순서와 종료를 조정하는 구성요소를 지칭한다.
- **계획 모듈(Planning Module)**: 목표를 의존 관계가 있는 실행 작업으로 분해하는 구성요소이다.
- **평가 모듈(Evaluation Module)**: 비용•완료 조건에 따라 다음 행동과 종료 여부를 판정하는 구성요소를 말한다.
- **데이터베이스(Database, DB)**: 작업 상태•실행 결과•장기 지식을 지속 저장하여 에이전트가 중단된 목표를 이어가게 하는 저장소이다.
- **응용 프로그래밍 인터페이스(Application Programming Interface, API)**: 에이전트가 외부 도구를 정해진 인자•권한•응답 형식으로 호출하는 인터페이스를 뜻한다.

</details>

```text
              [모델•오케스트레이터]
                        |
             +----------+----------+
             |                     |
        [상태•기억]            [계획•평가]
             |                     |
             +----------+----------+
                        |
                   [도구•권한]
```

선의 의미: 모델•오케스트레이터가 상태•기억과 계획•평가를 결합하고, 도구•권한 경계가 외부 실행을 통제하는 에이전트 구조를 나타냄.

| 구성요소 | 책임 |
|:---|:---|
| 모델•오케스트레이터 | **LLM**과 **오케스트레이터**가 목표•정책•상태 기반 다음 행동을 선택함 |
| 상태•기억 | **DB**에 작업 상태•결과•장기 지식을 저장함 |
| 계획•평가 | **계획 모듈**과 **평가 모듈**이 작업 분해•비용•종료 조건을 평가함 |
| 도구•권한 | **API** 스키마와 권한 정책에 따라 실행함 |

#### 한줄 요약
- **오케스트레이터**가 계획•상태•도구•권한을 연결한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **목표•완료 조건•예산 등록(Goal/Budget Registration)**: 작업 범위•금지 행동•종료 기준•자원 한도를 설정하는 단계이다.
- **현재 상태•기억 제공(Context Provision)**: 이전 행동•결과•장기 지식을 조회해 현재 판단에 제공하는 단계를 말한다.
- **계획 행동•인자•권한 검증 요청(Action Verification Request)**: 다음 도구•순서•인자와 위험 행동 승인을 확인하는 단계를 지칭한다.
- **도구 실행 결과•오류 반환(Tool Execution Return)**: 허가된 도구의 실행 결과와 실패 원인을 전달하는 단계이다.
- **관찰 결과•완료 판정 저장(Observation Saving)**: 완료•재계획•한도 중단 판단을 상태에 반영하는 단계를 뜻한다.

</details>

```text
오케스트레이터
   │ 1. 목표•완료 조건•예산 등록
   ├───────────────────┐
   │ 완료•중단 전까지 │
   └─────────┬─────────┘
   ▼
상태•기억
   │ 2. 현재 상태•기억 제공
   ▼
오케스트레이터
   │ 3. 계획 행동•인자•권한 검증 요청
   ▼
도구•권한
   │ 4. 도구 실행 결과•오류 반환
   ▼
오케스트레이터
   │ 5. 관찰 결과•완료 판정 저장
   ▼
상태•기억
```

### 동작 원리

1. **목표•완료 조건•예산 등록**: 작업 범위와 금지 행동 및 종료 기준을 설정함.
2. **현재 상태•기억 제공**: 이전 행동과 결과 및 장기 지식을 조회함.
3. **계획 행동•인자•권한 검증 요청**: 다음 도구와 순서를 선택하고 위험 행동 승인을 확인함.
4. **도구 실행 결과•오류 반환**: 허가된 도구를 격리 환경에서 실행함.
5. **관찰 결과•완료 판정 저장**: **ReAct** 반복의 완료•재계획•한도 중단 결과를 상태에 반영함.

#### 한줄 요약
- **계획 행동•인자•권한 검증 요청** 후 실행하고 완료•재계획을 판정한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **AI Agent**: 목표 달성을 위해 계획•행동•관찰을 반복하며 외부 도구를 실행하는 시스템을 의미한다.
- **검색 증강 생성(Retrieval-Augmented Generation, RAG)**: 외부 자료를 검색해 근거를 대규모 언어 모델의 응답 생성에 결합하는 방식을 말한다.
- **반응형 에이전트(Reactive Agent)**: 장기 계획보다 현재 입력과 규칙에 따라 즉시 행동을 선택하는 에이전트 유형이다.

</details>

| 판단 기준 | AI 에이전트 | 전통적 챗봇 | RAG |
|:---|:---|:---|:---|
| 적용 기준 | **AI Agent**는 다단계 외부 행동이 필요함 | 챗봇은 단발 질의•안내가 필요함 | **RAG**는 외부 근거 기반 응답이 필요함 |
| 핵심 특징 | 계획•행동•관찰을 반복함 | 단발 대화 응답이 중심임 | 검색 근거 기반 생성을 보강함 |
| 한계 | 권한 오용•오류 누적 위험이 있음 | 장기 상태•외부 행동이 부족함 | 검색 밖 행동은 실행이 불가함 |

> 요약: **AI Agent**는 외부 행동, **RAG**는 근거 기반 응답, **반응형 에이전트**는 현재 입력 기반 행동에 초점을 둠.

#### 한줄 요약
- 챗봇은 대화 응답, RAG는 외부 근거를 결합한 응답, 에이전트는 다단계 도구 실행에 적합하다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **인간 참여형 통제(Human-in-the-Loop, HITL)**: 고위험 행동을 실행하기 전에 사람이 맥락과 영향을 검토하고 승인하는 통제를 의미한다.
- **최소 권한(Least Privilege)**: 에이전트가 각 작업에 필요한 도구와 데이터만 제한된 범위에서 사용하게 하는 보안 원칙을 말한다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 과도한 도구 권한으로 생기는 외부 피해 | **최소 권한**•인자 스키마•격리를 적용함 | 오작동의 영향 범위를 제한함 |
| 오류 반복으로 발생하는 비용 폭증 | 재시도•시간•토큰•비용 한도를 설정함 | 무한 실행과 자원 낭비를 방지함 |
| 금액•권리 변경의 책임 불명확 | 변경•지급 전 **HITL** 승인을 거침 | 책임 있는 자율화 경계를 확보함 |

#### 한줄 요약
- 금액•권리 변경은 **HITL** 승인 후 실행한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

</details>

- 다단계 외부 행동은 **AI Agent**, 고위험 변경은 **HITL** 승인 후 실행함.

#### 한줄 요약
- **최소 권한**과 **HITL** 경계 및 실행 로그•비용 한도를 검증한다.
