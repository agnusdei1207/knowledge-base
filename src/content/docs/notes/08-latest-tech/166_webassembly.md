## 미리 알고가기

- **웹어셈블리(WebAssembly, Wasm)**: 브라우저·서버용 바이너리 실행 형식
- **웹어셈블리 시스템 인터페이스(WebAssembly System Interface, WASI)**: 표준 시스템 호출 제공
- **웹어셈블리 인터페이스 타입(WebAssembly Interface Types, WIT)**: 함수·타입 계약 정의
- **성능**: 네이티브 성능과 격리성을 동시에 추구함
- **컨테이너**: 가벼운 격리 실행 단위로 활용함



## Ⅰ. 개요

- **정의/개념**: 검증 가능한 저수준 실행 표준
- **배경/필요성**: 이식 가능한 고성능 코드 격리 실행

### 쉽게 이해하기 (학습용)

- 여러 종류의 기계가 읽을 수 있는 공통 작업 상자이며, 상자 안의 작업 공간과 바깥에서 빌려 쓸 도구 목록을 분리해 실행함

## Ⅱ. 특징

- 모듈이 함수·메모리·입출력 계약을 묶는다
- 선형 메모리 범위 밖 접근은 트랩을 일으킨다
- import 권한이 호스트 기능 접근을 제한한다
- 코어 샌드박스가 제어 흐름을 격리한다
- WASI가 시스템 기능 인터페이스를 표준화한다
- WIT 계약이 컴포넌트 타입·자원을 제한한다

### 쉽게 이해하기 (학습용)

- 상자 안에서는 정해진 작업대 밖을 만질 수 없지만, 관리자가 문·전화·창고 열쇠를 import로 건네면 허용된 바깥 기능은 사용할 수 있음

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| Wasm 모듈 | 바이너리 실행 단위 |
| 검증기·컴파일러 | 형식 검증 및 코드 준비 |
| 모듈 인스턴스 | 실행 가능한 상태 |
| 선형 메모리 | 격리된 주소 공간 |
| 호스트 계약 | import·export 연결 |

```text
호스트 ── 권한 ──→ Wasm 모듈
  ↑               ↓
  └─ export 결과 ─┘
```

> 요약: 런타임이 모듈을 격리하고 import 권한을 잇는다.

### 쉽게 이해하기 (학습용)

- 관리자가 상자를 검사하고 전용 작업대를 만든 뒤 허용한 도구만 넣어 주며, 상자는 공개한 출구로만 결과를 돌려줌

## Ⅳ. 원리 및 절차 흐름도

```text
컴파일
  ↓
검증
  ↓
권한연결
  ↓
인스턴스
  ↓
호출트랩
```

| 절차 | 설명 |
|:---|:---|
| 소스→모듈 컴파일 | 소스·인터페이스를 Wasm 모듈로 생성함 |
| 검증·코드 준비 | 형식·타입 검증 뒤 실행 코드를 준비함 |
| import·권한 연결 | 호스트가 WASI 자원을 최소 권한으로 제공함 |
| 인스턴스화 | 메모리·테이블·전역을 할당·초기화함 |
| export 호출·트랩 처리 | 호스트 호출 위반은 트랩으로 격리함 |

> 요약: 검증된 모듈에 권한을 연결해 인스턴스화하고 호출함

### 쉽게 이해하기 (학습용)

- 작업 상자를 만들고 검사한 뒤 허용 도구만 연결해 전용 작업대를 준비하고, 공개된 버튼으로 실행하면서 위반은 즉시 중단함

## Ⅴ. 종류 및 비교

| 판단 기준 | WebAssembly | 네이티브 프로세스 | 컨테이너 |
|:---|:---|:---|:---|
| 실행·배포 단위 | 검증된 모듈을 런타임이 인스턴스화함 | 운영체제·CPU용 실행 파일을 프로세스로 실행함 | 애플리케이션과 사용자 공간 의존성을 이미지로 실행함 |
| 격리·메모리 경계 | 선형 메모리·타입·제어 흐름과 명시적 import로 제한함 | 운영체제 프로세스·사용자 권한에 의존함 | 프로세스에 네임스페이스·제어 그룹·보안 정책을 추가함 |
| 선택 조건 | 경량 플러그인·엣지 함수와 다중 언어 이식성이 중요할 때 | 완전한 시스템 접근과 최고 직접 성능이 중요할 때 | 기존 애플리케이션·운영체제 의존성과 표준 운영 도구가 중요할 때 |

> 요약: 모듈·프로세스·컨테이너는 다른 경계로 격리한다.

### 쉽게 이해하기 (학습용)

- 제한된 공용 작업 상자, 건물 안의 일반 작업실, 도구까지 포장한 독립 작업실 중 필요한 무게와 권한 범위에 맞춰 고르는 것임

## Ⅵ. 실무 사례

1. 웹 브라우저는 C++·Rust로 작성한 영상 코덱·그래픽 연산을 Wasm 모듈로 로드해 선형 메모리 안에서 실행하고 JavaScript import·export로 화면과 데이터를 교환함
2. 서버 플러그인 런타임은 테넌트별 Wasm 모듈에 WASI 파일·네트워크 기능을 선택적으로 부여해 한 프로세스 안에서 확장 코드를 격리함

### 쉽게 이해하기 (학습용)

- 브라우저는 무거운 영상 작업을 상자에 맡기고, 서버는 손님별 상자에 필요한 폴더와 통신 권한만 빌려 줘 서로의 작업 공간을 분리함

## Ⅶ. 결론

- 코어 샌드박스·호스트 권한을 분리해 설계한다

### 쉽게 이해하기 (학습용)

- 상자가 튼튼해도 관리자가 위험한 열쇠를 모두 건네면 격리 효과가 줄어드므로 상자 구조와 빌려 주는 도구를 함께 관리해야 함
