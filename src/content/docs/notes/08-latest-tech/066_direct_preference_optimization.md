## 미리 알고가기

- **직접 선호 최적화 (Direct Preference Optimization, DPO)**: 강화학습 단계를 우회해 선호·비선호 데이터쌍으로 모델을 훈련하는 정렬 기법
- **참조 모델 (Reference Model)**: 정책 모델이 정렬 과정에서 품질을 잃지 않도록 기준이 되는 동결 백본
- **베타 계수 (Beta, β)**: 참조 모델과의 로그 확률 거리 비율을 조절하는 하이퍼파라미터
- **브래들리-테리 모델 (Bradley-Terry Model)**: 응답 선호 확률을 선호 점수 차이의 로지스틱 함수로 정의하는 확률 모델



## Ⅰ. 개요

- 정의/개념: 선호·비선호 응답의 상대 로그확률을 최적화
- **배경/필요성**: 보상 모델과 온라인 강화학습의 복잡성 절감

### 쉽게 이해하기 (학습용)

- 좋은 답과 나쁜 답의 쌍을 이용해 좋은 답의 생성 가능성을 높입니다.

## Ⅱ. 특징

- 보상 모델 없이 고정 선호 데이터로 정책을 갱신한다.
- 정책과 참조 모델의 로그확률 차이로 선호를 학습한다.
- 베타 계수로 선호 적합과 참조 정책 보존을 조절한다.
- 온라인 탐색이 없어 고정 데이터의 범위와 편향에 의존한다.

### 쉽게 이해하기 (학습용)

- 준비된 답안쌍만 학습하므로 간단하지만 데이터 밖 오류는 발견하기 어렵습니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 선호 데이터 | 선호·비선호 응답쌍으로 감독 신호 제공 |
| 정책 모델 | 선호 응답의 가능도를 높이는 방향으로 갱신 |
| 참조 모델 | 동결된 모델로 각 응답의 기준 확률 제공 |
| 로그확률부 | 응답별로 정책과 참조 모델의 확률 차이 계산 |
| DPO 손실 | 상대 확률 차이가 선호 순서를 따르도록 최적화 |

### 쉽게 이해하기 (학습용)

- 정책과 동결한 참조 모델의 응답 가능도를 비교해 선호 응답의 확률을 높입니다.

## Ⅳ. 원리 및 절차 흐름도

```text
선호·비선호 응답쌍
↓
상대 로그확률 차이
↓
DPO 손실 함수
↓
정책 모델 갱신
```

| 절차 | 설명 |
|:---|:---|
| 데이터 준비 | 선호·비선호 응답을 수집하고 품질과 편향을 확인함 |
| 기준 고정 | 지도 미세조정 정책을 복제해 비교 기준 참조를 마련함 |
| 확률 계산 | 정책과 참조 모델에서 응답 토큰의 로그확률을 계산함 |
| 손실 최적화 | 상대 확률 차이가 선호를 지지하도록 손실을 최적화함 |
| 최종 평가 | 보류 데이터에서 품질·안전성·다양성을 추가 평가함 |

### 쉽게 이해하기 (학습용)

- 답안쌍을 정제해 상대 확률을 학습하고 보지 못한 질문의 생성 결과도 확인합니다.

## Ⅴ. 종류 및 비교

| 판단 기준 | 지도 미세조정 | 인간 피드백 강화학습 | 직접 선호 최적화 |
|:---|:---|:---|:---|
| 학습 신호 | 모범 응답 토큰 가능도 증대 | 보상 모델 기반 정책 갱신 | 응답 상대 로그확률 최적화 |
| 적용 기준 | 지시 추종과 모범 응답 작성 가능 시 | 반복 개선과 탐색 평가 필요 시 | 고정 선호쌍과 단순 학습 필요 시 |
| 주요 위험 | 응답 다양성·품질 의존 | 강화학습 불안정과 보상 해킹 | 데이터 밖 응답 대응 취약 |

> 요약: 준비된 선호쌍으로 모델을 직접 정렬함

### 쉽게 이해하기 (학습용)

- DPO는 별도 채점 모델 없이 두 답 중 선호된 답을 더 자주 만들도록 학습합니다.

## Ⅵ. 실무 사례

- 선호 데이터 내 응답 길이·출처 편향을 분할별로 점검함

### 쉽게 이해하기 (학습용)

- 응답 길이 같은 쉬운 단서를 외우지 않는지 살피고 새 질문의 품질을 확인해야 합니다.

## Ⅶ. 결론

- DPO는 데이터 편향·탐색 부재·베타 영향을 검증한다.

### 쉽게 이해하기 (학습용)

- 답안쌍에 없던 상황도 잘 처리하는지 별도 생성 평가로 검증해야 합니다.
