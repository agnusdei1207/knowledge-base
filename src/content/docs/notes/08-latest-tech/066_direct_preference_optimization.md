## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **직접 선호 최적화(Direct Preference Optimization, DPO)**: 별도 보상 모델과 온라인 강화학습 없이 선호•비선호 응답쌍으로 정책을 직접 훈련하는 정렬 기법으로 정의된다.
- **선호 응답쌍(Preference Pair)**: 같은 질문에 대한 선택 응답과 비선택 응답을 한 쌍으로 기록한 학습 신호를 나타낸다.

</details>

- 정의/개념: 선호 응답쌍과 참조 모델로 정책을 최적화하는 **DPO**
- 배경/필요성: 전통적인 RLHF(인간 피드백 강화학습) 프레임워크는 별도의 보상 모델(Reward Model)을 사전 학습시키고 복잡한 PPO 강화학습 루프(온라인 롤아웃 샘플링, 가치 네트워크 갱신 등)를 거쳐야 하므로, 극심한 학습 불안정성(하이퍼파라미터 민감도), 막대한 GPU 메모리 요구량(4개 모델 동시 적재) 및 느린 학습 수렴 속도가 발생하는 한계가 존재함에 따라, 브래들리-테리(Bradley-Terry) 보상 모델의 수학적 목적함수를 참조 모델과 정책 모델 간의 로그 확률비(Implicit Reward)로 치환 유도하여 보상 모델 없이 선호 데이터셋만으로 단일 지도학습 손실을 최적화하는 직접 선호 최적화(DPO: Direct Preference Optimization) 기술을 도입하여 **복잡한 PPO 파이프라인 및 보상 모델 제거를 통한 학습 안정성 극대화 및 GPU 메모리 절감, 단일 이진 교차 엔트로피(BCE) 손실 역전파 기반의 초고속 학습 수렴, RLHF와 동등 이상의 인간 선호도 정렬 성능 확보**를 달성할 필요

#### 한줄 요약
- **선호•비선호 응답쌍**으로 직접 최적화하면 보상 모델과 온라인 샘플링 비용이 사라지는 대신 학습 중 새 응답을 탐색하지 못하므로, 안정성과 단순성을 얻고 탐색 여지를 내준다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **참조 모델(Reference Model)**: 정책 모델이 정렬 중 기존 품질을 잃지 않도록 기준 확률을 제공하는 동결 모델.
- **상대 로그확률(Relative Log Probability)**: 정책과 참조 모델이 선호•비선호 응답에 부여한 로그확률 차이를 비교한 값이다.
- **베타 계수(Beta Coefficient, $\beta$)**: 선호 적합과 참조 모델 보존 사이의 강도를 조절하는 하이퍼파라미터를 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.

</details>

- **선호쌍 직접 학습**: 별도 보상 모델 불필요
- **상대 로그확률**: 정책•참조 모델의 선호 차이 판정
- **베타 계수**: 선호 적합과 참조 정책 보존 절충

#### 한줄 요약
- **고정 선호쌍 범위•편향** 대상 학습 품질 의존

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **정책 모델(Policy Model)**: 선호 응답 가능도를 높이고 비선호 응답 가능도를 낮추도록 갱신되는 모델이다.
- **선호 데이터(Preference Data)**: 같은 입력에 대한 선호 응답과 비선호 응답의 쌍으로 구성된 학습 자료.
- **참조 모델 역할(Role of Reference Model)**: 정책 이탈을 측정할 상대 로그확률 기준을 제공하는 기능을 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.
- **로그확률부(Log Likelihood Module)**: 정책•참조 모델의 응답 토큰 로그확률과 차이를 계산하는 모듈을 나타낸다.
- **직접 선호 최적화 손실(DPO Loss)**: 상대 확률 차이가 선호 순서와 일치하도록 정책을 최적화하는 손실 함수이다.

</details>

```text
[DPO System]
├── [입력/데이터 계층]
│   └── [선호 데이터 (Chosen/Rejected)]
├── [모델 계층]
│   ├── [정책 모델 (Policy Model)]
│   └── [참조 모델 (Reference Model)]
└── [최적화/손실 계층]
    ├── [로그확률부 (Log-Likelihood)]
    └── [DPO 손실 (Implicit Reward Loss)]
```

- 선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 선호 데이터 | **선호•비선호 응답쌍** 제공 |
| 정책 모델 | **선호 응답 가능도**를 높이도록 갱신 |
| 참조 모델 | 동결 모델의 **기준 확률** 제공 |
| 로그확률부 | **정책•참조 확률 차이** 계산 |
| DPO 손실 | 상대 확률을 **선호 순서**에 맞게 최적화 |

#### 한줄 요약
- **선호 데이터•정책•참조•로그확률•손실** 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **선택 응답(Chosen Response)**: 비교 평가에서 더 낫다고 판단되어 확률을 높일 학습 대상.
- **비선택 응답(Rejected Response)**: 비교 평가에서 덜 선호되어 선택 응답보다 확률을 낮출 학습 대상을 가리킨다.

</details>

```text
┌──────────── 학습 종료 전 반복 ────────────┐
│ 선호 데이터                               │
│   │ 1. 선택•비선택 응답 제공              │
│   ▼                                       │
│ 정책 모델                                 │
│   │ 2. 정책 로그확률 전달                 │
│   ▼                                       │
│ 참조 모델                                 │
│   │ 3. 참조 로그확률 전달                 │
│   ▼                                       │
│ DPO 손실                                  │
│   └ 4. 상대 선호 손실 역전파 ──▶ 정책 모델│
└───────────────────────────────────────────┘
```

### 동작 원리

1. **선택•비선택 응답 제공**: 선호 순서 신호 구성
2. **정책 로그확률 전달**: 응답별 가능도 산출
3. **참조 로그확률 전달**: 동결 정책 대비 편차 제공
4. **상대 선호 손실 역전파**: 선호와 정책 이탈 조절

#### 한줄 요약
- **응답쌍•정책 확률•참조 확률•손실 역전파** 수행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **DPO 적용(DPO Application)**: 고정 선호쌍의 상대 로그확률을 직접 최적화하는 방식.
- **지도 미세조정(Supervised Fine-Tuning, SFT)**: 모범 응답의 정답 토큰 가능도를 높여 지시 행동을 학습하는 기법이다.
- **인간 피드백 강화학습(Reinforcement Learning from Human Feedback, RLHF)**: 별도 보상 모델을 학습하고 온라인 강화학습으로 보상을 최적화하는 방법으로 정의된다.

</details>

- 고정 선호쌍은 **DPO**, 보상 기반 탐색은 **RLHF**

| 정렬 방식 | 직접 선호 최적화 | 지도 미세조정 | 인간 피드백 강화학습 |
|:---|:---|:---|:---|
| 적용 기준 | 고정 **선호쌍** 기반 단순 정렬 | 모범 응답 기반 **지시 학습** | 온라인 **탐색•반복 개선** |
| 핵심 특징 | **상대 로그확률** 직접 최적화 | 정답 토큰 **가능도 최대화** | **보상 모델** 기반 정책 갱신 |
| 한계 | 선호 데이터의 **범위**•**편향** 의존 | 응답 **품질**•**다양성** 의존 | **보상 해킹•학습 불안정** |

#### 한줄 요약
- **학습 신호•정책 탐색** 기반 후학습 방식 구분

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **길이 편향(Length Bias)**: 응답의 실제 품질보다 길고 자세한 형식이 선호 신호로 학습되는 문제를 나타낸다.
- **정책 이탈(Policy Drift)**: 선호 데이터에 과도하게 맞추면서 참조 모델의 기존 언어 능력과 품질에서 멀어지는 현상이다.
- **과소 적합(Underfitting)**: 제약이 지나치게 강해 정책이 선호 차이를 충분히 학습하지 못하는 상태를 가리킨다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 길이 단서로 **선호쌍 편향** 학습 | 길이•출처 균형화와 **분할 평가** | 실제 품질 기반 **선호 신호** 확보 |
| **베타 계수 부적정** 기반 정책 이탈•과소 적합 | **베타 계수**별 선호•품질 회귀 시험 | 선호 적합•**참조 정책 보존** 절충 |

#### 한줄 요약

- **길이 편향•베타 계수•범위 밖 품질** 검증

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **직접 선호 최적화 선택 기준(DPO Selection Criteria)**: 대표성 있는 고정 선호쌍이 충분하고 온라인 정책 탐색이 필요하지 않을 때 사용되는 기준을 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.
- **독립 생성 평가(Out-of-Distribution Evaluation)**: 학습 선호쌍 밖의 새로운 질문에서도 품질•안전성을 유지하는지 검증하는 평가.

</details>

- 복잡하고 불안정한 강화학습 파이프라인을 수학적 치환을 통해 효율적인 지도학습 체계로 재정립한 **현대 LLM 포스트 트레이닝 선호 정렬(Direct Preference Optimization: DPO / Implicit Reward Function / Reference Policy Drift Penalty $\beta$ / Pairwise Preference Loss / KTO & SimPO Extensions)의 최고 핵심 방법론**으로 확고히 자리 잡았으며, 오프라인 및 온폴리시(On-Policy) 변형으로 진화하는 가운데, 실무 DPO 정렬 구축 시에는 **선호 응답의 길이만 길어져 발생하는 길이 편향(Length Bias)을 데이터 증강 및 정규화로 방어, 정렬 과정에서 참조 모델의 언어 유창성을 보존하는 정밀한 베타 계수($\beta=0.05\sim0.2$) 튜닝, 오프라인 선호 데이터의 한계를 보완하기 위해 모델 자체 생성 응답 기반의 Iterative/Online DPO 도입**을 결합하여 완벽한 선호 정렬성과 뛰어난 대화 품질을 완성

#### 한줄 요약

- **선호쌍 대표성•탐색 필요성** 대상 따라 정렬 방식 결정
