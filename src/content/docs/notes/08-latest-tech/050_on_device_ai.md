## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **온디바이스 인공지능(On-Device Artificial Intelligence, On-Device AI)**: 원본 데이터를 외부 서버로 보내지 않고 단말 내부에서 인공지능 모델 추론을 수행하는 방식이다.
- **현장 자율성**: 네트워크 연결이나 중앙 서버 상태와 무관하게 단말이 필요한 판단을 계속 수행하는 능력이다.

</details>

- 정의/개념: 원본 데이터를 외부로 보내지 않고 단말 내부에서 모델 추론을 수행하는 **온디바이스 AI**이다.
- 배경/필요성: 클라우드 의존 추론은 망 단절•왕복 지연•민감정보 전송으로 **현장 자율성** 제약이 발생한다.

#### 한줄 요약
- 원본 데이터를 외부 전송하지 않는 **단말 내부 추론**이 핵심이다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **신경망 처리장치(Neural Processing Unit, NPU)**: 신경망의 행렬•텐서 연산을 낮은 전력으로 가속하는 전용 장치다.
- **로컬 개인정보 처리**: 원본 민감정보를 단말 내부에서 처리하여 외부 전송 범위를 줄이는 방식이다.
- **양자화(Quantization)**: 모델 가중치와 연산값을 더 적은 비트로 표현하여 메모리•연산량을 줄이는 방법이다.
- **GPU(Graphics Processing Unit)**: 범용 병렬 연산으로 모델 추론을 가속하는 장치다.
- **CPU(Central Processing Unit)**: 제어와 미지원 연산을 처리하는 범용 장치다.

</details>

- 네트워크 왕복 없이 실행하는 **오프라인•저지연 추론**이 핵심이다.
- 원본 데이터를 단말에 유지하는 **로컬 개인정보 처리**가 핵심이다.
- 압축 모델과 **NPU•GPU**를 결합하는 전력•메모리 제약을 실행한다.

#### 한줄 요약
- **오프라인•저지연•로컬 개인정보 처리**를 제공한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **모델 패키지**: 압축 모델•메타데이터•서명•지원 연산자 정보를 묶은 배포 단위다.
- **그래프 분할(Graph Partitioning)**: 모델 연산을 지원 여부에 따라 NPU•GPU•CPU 또는 외부 실행 구간으로 나누는 방법이다.
- **모델 컴파일러(Model Compiler)**: 모델 그래프를 목표 장치의 지원 연산자로 변환하는 소프트웨어다.
- **추론 런타임(Inference Runtime)**: 변환된 모델을 장치에 배치하고 실행하는 소프트웨어다.
- **실행 정책**: 자원•민감도•품질 기준으로 로컬 처리와 외부 위임을 결정하는 규칙이다.

</details>

```text
                          [실행 정책]
                         /           \
                   [입력•권한]     [모델 패키지]
                                      |
                                [모델 컴파일러]
                                      |
                                [추론 런타임]
                                      |
                                [NPU•GPU•CPU]
```

선의 의미: 실행 정책은 입력•권한 경계와 사용할 모델 패키지를 통제하고, 모델 패키지는 모델 컴파일러•추론 런타임•NPU•GPU•CPU의 장치 실행 계층에 속한다.

| 구성요소 | 책임 |
|:---|:---|
| 입력•권한 | 센서•개인정보의 **접근 범위 통제** |
| 모델 패키지 | 압축 모델•메타데이터•서명의 **배포 단위 제공** |
| 모델 컴파일러 | 그래프 변환과 **지원 연산자 생성** |
| 추론 런타임 | 장치별 **연산자 배치•실행** |
| NPU•GPU•CPU | 전력•성능 조건에 따른 **로컬 추론 실행** |
| 실행 정책 | 자원•민감도별 로컬 실행과 **외부 위임 결정** |

#### 한줄 요약
- **입력 권한•패키지•컴파일러•런타임•가속기**를 구성한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **모델 서명(Model Signing)**: 배포 모델의 출처와 무결성을 암호학적 서명으로 검증하는 방법이다.
- **해시(Hash)**: 모델 파일을 고정 길이 값으로 변환하여 승인된 원본과 같은지 확인하는 결과값이다.

</details>

```text
추론 입력
    │ 1. 입력 권한•민감도 판정
    ▼
모델 패키지
    │ 2. 모델 서명•호환성 검증
    ▼
추론 런타임
    │ 3. 그래프•가속기 배치
    ▼
가속기
    │ 4. 로컬 추론 실행
    ▼
권한•실행 정책
    │ 5. 품질•자원 한계 판정
    ▼
┌────────────── 판정 분기 ──────────────┐
│ 로컬 기준 충족  ──▶ 로컬 추론 결과   │
│ 로컬 기준 초과  ──▶ 비식별 후 외부 위임│
└───────────────────────────────────────┘
```

1. **입력 권한•민감도 판정**: 센서 권한과 데이터의 **외부 전송 범위**를 확인한다.
2. **모델 서명•호환성 검증**: 해시•버전•지원 연산자를 검사한다.
3. **그래프•가속기 배치**: 지원•전력 조건에 따라 **NPU•GPU•CPU**을 선택한다.
4. **로컬 추론 실행**: 단말 가속기에서 모델 연산과 결과를 생성한다.
5. **품질•자원 한계 판정**: 로컬 반환 또는 비식별 외부 위임을 결정한다.

#### 한줄 요약
- **권한•서명•배치•로컬 추론•위임 판정**을 수행한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **에지 인공지능(Edge Artificial Intelligence, Edge AI)**: 현장 인접 서버가 여러 단말의 데이터를 집계하고 분산 추론•제어를 수행한다.
- **클라우드 인공지능(Cloud Artificial Intelligence, Cloud AI)**: 중앙의 대규모 자원으로 복합 모델과 통합 분석을 수행한다.

</details>

| 비교 기준 | 온디바이스 AI | 에지 AI | 클라우드 AI |
|:---|:---|:---|:---|
| 적용 기준 | **오프라인•개인정보•즉시 응답** | **현장 다단말 집계•제어** | **대형 모델•복합 연산** |
| 핵심 특징 | 개인 단말의 **로컬 추론** | 인접 서버의 **분산 추론** | 중앙 자원의 **통합 추론** |
| 한계 | **전력•메모리•기기 파편화** | **노드 운영•현장 보안** | **망 지연•가용성•정보 전송** |

#### 한줄 요약
- **민감도•지연•집계•연산량**으로 실행 위치를 선택한다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **오프로딩(Offloading)**: 단말에서 처리하기 어려운 연산을 정책에 따라 에지나 클라우드로 위임하는 방식이다.
- **무선 업데이트(Over-the-Air Update, OTA Update)**: 통신망을 통해 단말의 모델과 런타임을 원격 갱신하는 방식이다.
- **자동 롤백**: 새 모델 실행에 실패하면 이전 정상 버전으로 자동 복귀하는 복구 방식이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 기기별 **연산자•가속기 차이** | 지원 연산자 기준 **그래프 분할**•실기기 시험 | 배포 호환성 **확보** |
| 배터리•발열의 **지속 실행 제한** | **정수 양자화**•호출 빈도•열 임계값 제어 | 전력•온도 **관리** |
| 로컬 자원•품질의 **처리 한계** | **민감정보 제거•정책 기반 외부 위임** | 서비스 연속성 **확보** |
| 배포 모델의 **변조 위험** | **모델 서명•해시** 검증 | 모델 무결성 **확보** |
| **OTA Update 실패** | **단계 배포•이전 모델 자동 롤백** | 서비스 **신속 복구** |

#### 한줄 요약
- **호환성•전력•위임•서명•롤백**을 통제한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **온디바이스 선택 기준**: 민감정보•오프라인 동작•즉시 응답이 중요하고 단말 자원으로 품질을 충족할 때 사용한다.
- **외부 위임 기준**: 로컬 자원이나 품질 한계를 넘을 때 민감정보를 제거하고 허용된 범위만 외부로 전달한다.

</details>

- 민감•오프라인 요청은 **온디바이스**, 자원•품질 한계 초과 시 **비식별 후 외부 위임**이 핵심이다.

#### 한줄 요약
- **데이터 민감도•단말 자원**으로 로컬•외부 위임을 선택한다.
