## 미리 알고가기

- **온디바이스 AI (On-Device AI)**: 단말 내부에서 직접 AI 추론을 수행하는 방식
- **NPU (Neural Processing Unit)**: 신경망 연산 전용 저전력 가속 장치
- **MAC (Multiply-Accumulate)**: 행렬 연산의 기본 동작 단위
- **OTA (Over-the-Air)**: 모델 및 런타임을 무선으로 갱신하는 기술
- **EP (Execution Provider)**: 런타임에서 그래프 연산을 가속기에 배치
- **IAM (Identity and Access Management)**: 외부 서비스 권한 제어 기술


## Ⅰ. 개요

- **정의/개념**: 단말 내부에서 직접 수행하는 AI 추론
- **배경/필요성**: 통신 지연·비용·정보 노출 감소

### 쉽게 이해하기 (학습용)
- 정보를 서버로 보내지 않고 내 기기 안에서 직접 분석함

## Ⅱ. 특징

- 오프라인 동작이 통신 지연·의존을 줄인다
- 로컬 처리도 권한·보안 정책을 준수해야 한다
- 모델 압축이 제한된 자원에 연산을 맞춘다
- 하드웨어별 성능·지원 차이를 관리한다

### 쉽게 이해하기 (학습용)

- 기기 안에서 처리하면 통신 없이 빠르게 판단할 수 있다

## Ⅲ. 구성요소 및 구조

| 구성 요소 | 설명 |
|:---|:---|
| Input·Permission | 센서 및 데이터 접근 제어 |
| Model Package | 압축된 모델 및 메타데이터 |
| Runtime·Compiler | 그래프 변환 및 가속기 최적화 |
| Accelerator | NPU·GPU·CPU 기반 실행 |
| Policy | 오프로드 및 외부 위임 정책 |

> 요약: 권한·런타임·가속기·정책을 연결하여 처리함

### 쉽게 이해하기 (학습용)

- 권한 확인 후 가속기에 배치하고 로컬·외부를 선택함

## Ⅳ. 원리 및 절차 흐름도

```text
요구분류
↓
모델변환
↓
로컬실행
↓
외부위임
↓
운영갱신
```

| 절차 | 설명 |
|:---|:---|
| 요구분류 | 민감도 및 자원 조건 설정함 |
| 모델변환 | 최적화 및 그래프 분할 수행함 |
| 로컬실행 | 권한 기반 가속기 추론함 |
| 외부위임 | 정책에 따라 데이터 전송함 |
| 운영갱신 | 품질 및 성능 감시·갱신함 |

> 요약: 로컬 추론 후 필요 시 외부 위임함

### 쉽게 이해하기 (학습용)

- 입력별 로컬·외부 처리와 실패 경로를 먼저 정함

## Ⅴ. 종류 및 비교

| 판단 기준 | 온디바이스 AI | 에지 AI | 클라우드 AI |
|:---|:---|:---|:---|
| 실행 위치 | 개인 단말 내부 | 지역 서버·현장 | 원격 센터 |
| 적용 기준 | 오프라인·개인화 | 현장 제어·집계 | 고성능·복합 모델 |
| 제약 사항 | 전력·메모리·파편화 | 보안·분산 관리 | 네트워크·비용 |

> 요약: 지연·데이터·자원 조건으로 실행 위치를 선택함

### 쉽게 이해하기 (학습용)

- 단말·현장·클라우드 중 요구에 맞는 위치를 선택함

## Ⅵ. 실무 사례

- 모델 서명 및 데이터 암호화로 데이터 탈취 경로 차단함
- 저전력, 발열, 메모리 압박 등 실사용 환경 검증이 필수임

### 쉽게 이해하기 (학습용)

- 단말 자원에 맞춘 모델과 보안 통제가 함께 필요하다

## Ⅶ. 결론

- 온디바이스 AI는 단말 배치로 지연 및 보안을 보장함
- 압축, 분할, Hybrid 정책으로 자원 한계를 극복함

### 쉽게 이해하기 (학습용)

- 기기 안의 빠른 판단과 제한된 자원을 함께 설계해야 한다
