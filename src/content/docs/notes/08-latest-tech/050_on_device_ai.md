## 미리 알고가기

- **온디바이스 AI(On-Device AI)**: 원본 데이터를 외부 서버로 보내지 않고 단말 내부에서 AI 모델을 실행하는 방식
- **신경망 처리 장치(Neural Processing Unit, NPU)**: 신경망의 행렬 연산을 낮은 전력으로 가속하는 전용 장치
- **양자화(Quantization)**: 모델 가중치와 연산값을 더 적은 비트로 표현하여 메모리·연산량을 줄이는 방법
- **그래프 분할(Graph Partitioning)**: 모델 연산을 장치별 지원 여부에 따라 NPU·GPU·CPU 또는 외부 실행 구간으로 나누는 방법
- **오프로딩(Offloading)**: 단말에서 처리하기 어려운 연산을 에지·클라우드로 위임하는 방식
- **모델 서명(Model Signing)**: 배포 모델의 출처와 무결성을 암호학적 서명으로 검증하는 방법
- **해시(Hash)**: 모델 파일을 고정 길이 값으로 변환하여 원본과 같은 파일인지 확인하는 결과값
- **무선 업데이트(Over-the-Air, OTA)**: 통신망을 통해 단말의 모델과 런타임을 원격 갱신하는 방식

## Ⅰ. 개요

- 정의/개념: **온디바이스 AI**는 원본 데이터를 외부로 보내지 않고 단말 내부에서 모델 추론을 수행하는 방식
- 배경/필요성: 클라우드 의존 추론은 망 단절·왕복 지연·민감정보 전송으로 **현장 자율성** 제약

### 쉽게 이해하기 (학습용)
- 정보를 서버로 보내지 않고 기기 안에서 직접 분석함

## Ⅱ. 특징

- 네트워크 왕복 없이 실행하는 **오프라인·저지연 추론**
- 원본 데이터를 단말에 유지하는 **로컬 개인정보 처리**
- 압축 모델과 NPU·GPU를 결합하는 **전력·메모리 제약 실행**

### 쉽게 이해하기 (학습용)
- 통신 없이 빠르게 판단하고 원본 정보가 기기 밖으로 나가는 범위를 줄임

## Ⅲ. 구조 및 구성요소

```mermaid
block-beta
    columns 5
    I["입력·권한"]
    M["모델 패키지"]
    R["런타임·컴파일러"]
    A["NPU·GPU·CPU"]
    P["실행 정책"]
```

| 구성요소 | 책임 |
|:---|:---|
| 입력·권한 | 센서·개인정보의 **접근 범위 통제** |
| 모델 패키지 | 압축 모델·메타데이터·서명의 **배포 단위 제공** |
| 런타임·컴파일러 | 그래프 변환과 장치별 **연산자 배치** |
| NPU·GPU·CPU | 전력·성능 조건에 따른 **로컬 추론 실행** |
| 실행 정책 | 자원·민감도별 로컬 실행과 **외부 위임 결정** |

### 쉽게 이해하기 (학습용)
- 입력 권한을 확인하고 모델을 기기 가속기에 배치하며 처리 위치를 결정함

## Ⅳ. 흐름도

```mermaid
sequenceDiagram
    participant I as 입력·권한
    participant P as 모델 패키지
    participant R as 런타임
    participant A as 가속기
    participant O as 실행 정책
    I->>P: 1. 입력 권한·민감도 판정
    P->>R: 2. 모델 무결성·호환성 검증
    R->>A: 3. 그래프 변환·가속기 배치
    A->>O: 4. 로컬 추론·결과 반환
    O-->>I: 5. 실패 시 외부 위임·운영 갱신
```

### 동작 원리

1. **입력 권한·민감도 판정**: 센서 접근 권한과 데이터의 **외부 전송 가능 범위** 확인
2. **모델 무결성·호환성 검증**: 서명·버전·지원 연산자를 검사해 **실행 가능 패키지** 판정
3. **그래프 변환·가속기 배치**: 연산별 지원·전력 조건에 따라 **NPU·GPU·CPU** 할당
4. **로컬 추론·결과 반환**: 원본 데이터를 단말에 둔 채 **모델 출력** 생성
5. **실패 시 외부 위임·운영 갱신**: 정책이 허용한 경우만 민감정보를 제거해 위임하고 **모델 상태** 갱신

### 쉽게 이해하기 (학습용)
- 기기에서 먼저 처리하고 자원·품질 한계를 넘을 때만 허용된 범위로 외부에 맡김

## Ⅴ. 종류 및 비교

| 비교 기준 | 온디바이스 AI | 에지 AI | 클라우드 AI |
|:---|:---|:---|:---|
| 적용 기준 | 오프라인·개인정보·즉시 응답 | 현장 다단말 집계·제어 | 대형 모델·복합 연산 |
| 핵심 특징 | 개인 단말의 **로컬 추론** | 인접 서버의 **분산 추론** | 중앙 자원의 **통합 추론** |
| 한계 | 전력·메모리·기기 파편화 | 노드 운영·현장 보안 복잡성 | 망 지연·가용성·정보 전송 |

### 쉽게 이해하기 (학습용)
- 단말·현장 서버·원격 데이터센터 중 요구에 맞는 실행 위치를 선택함

## Ⅵ. 실무 고려사항 및 대책

| 고려사항 | 대책 | 효과 |
|:---|:---|:---|
| 기기별 **연산자·가속기 차이** | 지원 연산자 기준 그래프 분할·실기기 시험 | 배포 호환성 **확보** |
| 배터리·발열의 **지속 실행 제한** | 정수 양자화·호출 빈도·열 임계값 제어 | 전력·온도 **관리** |
| 로컬 자원·품질의 **처리 한계** | 민감정보 제거 후 정책 기반 외부 위임 | 서비스 연속성 **확보** |

### 쉽게 이해하기 (학습용)
- 기기별 차이와 배터리·보안을 확인하고 실패한 업데이트를 되돌릴 수 있게 함

## Ⅶ. 결론

- 개인정보 민감도·오프라인 필요성·단말 전력·메모리를 기준으로 **로컬 실행과 외부 위임 경계**를 결정해야 한다.

### 쉽게 이해하기 (학습용)
- 기기 안에서 처리할 범위와 외부에 맡길 범위를 데이터 민감도와 자원으로 정함
