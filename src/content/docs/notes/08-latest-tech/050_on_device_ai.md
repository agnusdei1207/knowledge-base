## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **온디바이스 인공지능(On-Device Artificial Intelligence, On-Device AI)**: 원본 데이터를 외부 서버로 보내지 않고 단말 내부에서 인공지능 모델 추론을 수행하는 방식으로 정의된다.
- **현장 자율성(Field Autonomy)**: 네트워크 연결이나 중앙 서버 상태와 무관하게 단말이 필요한 판단을 계속 수행하는 능력.

</details>

- 정의: 원본 데이터를 외부로 보내지 않고 단말에서 추론하는 **온디바이스 AI**
- 배경/필요성: 인공지능 모델 추론을 전적으로 중앙 집중식 클라우드 데이터센터에 의존할 경우, 네트워크 통신 대역폭 비용 및 왕복 지연(Round-Trip Time), 통신 음영 지역에서의 서비스 단절, 민감한 개인정보 및 생체 데이터의 외부 서버 전송에 따른 보안/규제 위반 위험이 심각하게 대두됨에 따라, 스마트폰·웨어러블·차량·IoT 등 사용자 단말 디바이스 자체에 탑재된 초저전력 NPU/GPU/CPU 하드웨어 가속기에서 모델을 직접 실행하는 온디바이스 AI(On-Device AI) 아키텍처를 도입하여 **네트워크 연결 없는 완전한 오프라인 독립 구동 및 밀리초 단위 초저지연(Zero-Latency) 응답성 확보, 원본 데이터의 기기 외부 유출을 원천 차단하는 완벽한 프라이버시 보호(Privacy by Design), 디바이스-클라우드 간 지능적 워크로드 분할(Hybrid AI)을 통한 중앙 서버 인프라 비용 절감**을 달성할 필요

#### 한줄 요약
- **단말 내부 추론**은 왕복 지연과 전송 노출을 없애는 대신 모델 갱신이 기기 배포 주기에 묶이므로, 프라이버시와 가용성을 얻고 최신성과 모델 규모를 내주는 거래다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **신경망 처리장치(Neural Processing Unit, NPU)**: 신경망의 행렬•텐서 연산을 낮은 전력으로 가속하는 전용 장치이다.
- **로컬 개인정보 처리(Local Data Privacy Processing)**: 원본 민감정보를 단말 내부에서 처리하여 외부 전송 범위를 줄이는 방식을 나타낸다.
- **양자화(Quantization)**: 모델 가중치와 연산값을 더 적은 비트로 표현하여 메모리•연산량을 줄이는 기법으로 정의된다.
- **GPU(Graphics Processing Unit)**: 범용 병렬 연산으로 모델 추론을 가속하는 장치를 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.
- **CPU(Central Processing Unit)**: 제어와 미지원 연산을 처리하는 범용 장치.

</details>

- **오프라인•저지연 추론**: 네트워크 왕복 없이 실행
- **로컬 개인정보 처리**: 원본 데이터를 단말에 유지
- **NPU**•**GPU**: 압축 모델의 전력•메모리 제약 대응

#### 한줄 요약
- **오프라인•저지연**과 로컬 개인정보 처리 제공

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **모델 패키지(Model Package)**: 압축 모델•메타데이터•서명•지원 연산자 정보를 묶은 배포 단위이다.
- **그래프 분할(Graph Partitioning)**: 모델 연산을 지원 여부에 따라 NPU•GPU•CPU 또는 외부 실행 구간으로 나누는 방법을 나타낸다.
- **모델 컴파일러(Model Compiler)**: 모델 그래프를 목표 장치의 지원 연산자로 변환하는 소프트웨어를 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.
- **추론 런타임(Inference Runtime)**: 변환된 모델을 장치에 배치하고 실행하는 소프트웨어.
- **실행 정책(Execution Policy)**: 자원•민감도•품질 기준으로 로컬 처리와 외부 위임을 결정하는 규칙으로 정의된다.

</details>

```text
                          [실행 정책]
                         /           \
                   [입력•권한]     [모델 패키지]
                                      |
                                [모델 컴파일러]
                                      |
                                [추론 런타임]
                                      |
                                [NPU•GPU•CPU]
```

선의 의미: 실행 정책 아래 패키지•컴파일러•런타임•가속기를 연결한 구조

| 구성요소 | 책임 |
|:---|:---|
| 입력•권한 | 센서•개인정보의 **접근 범위 통제** |
| 모델 패키지 | 압축 모델•메타데이터•서명의 **배포 단위 제공** |
| 모델 컴파일러 | 그래프 변환과 **지원 연산자 생성** |
| 추론 런타임 | 장치별 **연산자 배치•실행** |
| NPU•GPU•CPU | 전력•성능 조건에 따른 **로컬 추론 실행** |
| 실행 정책 | 자원•민감도별 로컬 실행과 **외부 위임 결정** |

#### 한줄 요약
- **입력 권한•모델 패키지**와 컴파일러•런타임•가속기 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **모델 서명(Model Signing)**: 배포 모델의 출처와 무결성을 암호학적 서명으로 검증하는 방식이다.
- **해시(Hash)**: 모델 파일을 고정 길이 값으로 변환하여 승인된 원본과 같은지 확인하는 결과값을 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.

</details>

```text
추론 입력
    │ 1. 입력 권한•민감도 판정
    ▼
모델 패키지
    │ 2. 모델 서명•호환성 검증
    ▼
추론 런타임
    │ 3. 그래프•가속기 배치
    ▼
가속기
    │ 4. 로컬 추론 실행
    ▼
권한•실행 정책
    │ 5. 품질•자원 한계 판정
    ▼
┌────────────── 판정 분기 ──────────────┐
│ 로컬 기준 충족  ──▶ 로컬 추론 결과   │
│ 로컬 기준 초과  ──▶ 비식별 후 외부 위임│
└───────────────────────────────────────┘
```

### 동작 원리

1. 입력 권한•민감도 판정: 센서 권한과 **외부 전송 범위** 확인
2. 모델 서명•호환성 검증: 해시•버전•지원 연산자 검사
3. 그래프•가속기 배치: 지원•전력 조건에 따라 **NPU•GPU•CPU** 선택
4. 로컬 추론 실행: 단말 가속기의 모델 연산과 결과 생성
5. 품질•자원 한계 판정: 로컬 반환 또는 비식별 외부 위임 결정

#### 한줄 요약
- **권한•서명** 확인 후 배치•로컬 추론•위임 판정

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **에지 인공지능(Edge Artificial Intelligence, Edge AI)**: 현장 인접 서버가 여러 단말의 데이터를 집계하고 분산 추론•제어를 수행하는 방식.
- **클라우드 인공지능(Cloud Artificial Intelligence, Cloud AI)**: 중앙의 대규모 자원으로 복합 모델과 통합 분석을 수행하는 구조를 나타낸다.

</details>

| 구분 | 온디바이스 AI | 에지 AI | 클라우드 AI |
|:---|:---|:---|:---|
| 적용 기준 | **오프라인•개인정보•즉시 응답** | **현장 다단말 집계•제어** | **대형 모델•복합 연산** |
| 핵심 특징 | 개인 단말의 **로컬 추론** | 인접 서버의 **분산 추론** | 중앙 자원의 **통합 추론** |
| 한계 | **전력•메모리•기기 파편화** | **노드 운영•현장 보안** | **망 지연•가용성•정보 전송** |

#### 한줄 요약
- **민감도•연산량**과 지연•집계에 따른 실행 위치 선택

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **오프로딩(Offloading)**: 단말에서 처리하기 어려운 연산을 정책에 따라 에지나 클라우드로 위임하는 패턴이다.
- **무선 업데이트(Over-the-Air Update, OTA Update)**: 통신망을 통해 단말의 모델과 런타임을 원격 갱신하는 방식으로 정의된다.
- **자동 롤백(Automatic Rollback)**: 새 모델 실행에 실패하면 이전 정상 버전으로 자동 복귀하는 복구 방식을 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 기기별 **연산자•가속기 차이** | 지원 연산자 기준 **그래프 분할**•실기기 시험 | 배포 호환성 **확보** |
| 배터리•발열의 **지속 실행 제한** | **정수 양자화**•호출 빈도•열 임계값 제어 | 전력•온도 **관리** |
| 로컬 자원•품질의 **처리 한계** | **민감정보 제거•정책 기반 외부 위임** | 서비스 연속성 **확보** |
| 배포 모델의 **변조 위험** | **모델 서명•해시** 검증 | 모델 무결성 **확보** |
| OTA Update 실패 | **단계 배포•이전 모델 자동 롤백** | 서비스 **신속 복구** |

#### 한줄 요약
- **호환성•전력**과 위임•서명•롤백 통제

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **온디바이스 선택 기준(On-Device Selection Criteria)**: 민감정보•오프라인 동작•즉시 응답이 중요하고 단말 자원으로 품질을 충족할 때 적용되는 기준으로 정의된다.
- **외부 위임 기준(Offloading Criteria)**: 로컬 자원이나 품질 한계를 넘을 때 민감정보를 제거하고 허용된 범위만 외부로 전달하는 규칙.

</details>

- 인공지능의 실행 환경을 중앙 클라우드에서 사용자 일상의 모든 엣지 엔드포인트로 전면 확장시킨 **차세대 엠비언트 인텔리전스(Ambient Intelligence)의 핵심 기술 기반(On-Device AI / Neural Processing Unit: NPU / Model Compression & Integer Quantization / Graph Partitioning / Zero-Latency & Privacy by Design)의 글로벌 표준 아키텍처**로 확고히 자리 잡았으며, 스마트폰(Galaxy AI, Apple Intelligence)과 온디바이스 SLM의 융합으로 급속히 대중화되는 가운데, 실무 온디바이스 시스템 개발 시에는 **단말 하드웨어(NPU) 연산자 지원 여부에 맞춘 컴파일러 튜닝 및 정수 양자화(INT8/INT4/FP4) 적용, 배터리 소모 및 발열을 억제하는 적응형 워크로드 스케줄링 구현, 민감 개인정보 및 고빈도 작업은 온디바이스에서 완결하고 고난도 복합 추론은 비식별화 후 클라우드로 안전하게 오프로딩하는 하이브리드 온디바이스-클라우드 협력 아키텍처 구축**을 결합하여 완벽한 사용자 경험과 무결한 데이터 프라이버시를 완성

#### 한줄 요약
- **데이터 민감도•단말 자원**에 따라 실행 위치 결정
