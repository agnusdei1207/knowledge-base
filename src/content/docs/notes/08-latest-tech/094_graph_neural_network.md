## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **그래프 신경망(Graph Neural Network, GNN)**: 이웃 노드와 간선의 메시지를 집계해 노드•링크•그래프 표현을 학습하는 신경망이다.
- **간선 관계**: 그래프에서 두 노드의 연결 유형과 방향을 나타내는 정보이다.

</details>

- 정의/개념: **GNN**은 이웃 메시지를 집계해 노드•링크•그래프 표현을 학습하는 신경망이다.
- 배경/필요성: 독립 표본 모델은 노드 사이 **간선 관계 활용할 수 없다**.

#### 한줄 요약
- 이웃 관계를 집계해 개별 노드•링크와 전체 그래프를 판단합니다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **메시지 전달**: 이웃 노드와 간선의 특징을 계산해 대상 노드로 보내고 표현을 갱신하는 과정이다.
- **과평활**: 전파 층이 깊어지면서 서로 다른 노드 표현이 비슷해져 구별력이 낮아지는 현상이다.
- **과압축**: 넓은 범위의 그래프 정보를 제한된 노드 표현에 모으면서 중요한 관계가 소실되는 현상이다.

</details>

![GNN 전파 깊이에 따른 노드 표현 과평활](/study/diagrams/gnn-oversmoothing.svg)

> 개념도: **GNN** 전파 층수 증가에 따른 표현 분산 감소와 과평활 심화

- 이웃 노드•간선의 전달 정보를 계산하는 **메시지 함수**가 핵심이다.
- 노드 표현을 반복 개선하는 **순서 불변 집계•갱신**이 핵심이다.
- 깊은 전파에서 노드 구별력을 낮추는 **과평활•과압축**이 핵심이다.

#### 한줄 요약
- 이웃 순서가 바뀌어도 결과는 같아야 하지만 너무 많은 정보를 반복 집계하면 노드 구별력이 약해집니다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **집계 함수**: 이웃의 순서와 무관하게 여러 메시지를 하나의 값으로 결합하는 함수이다.
- **갱신 함수**: 현재 노드 표현과 집계한 이웃 정보를 결합해 새 표현을 만드는 함수이다.
- **읽기 함수**: 학습한 노드 표현을 노드•링크•그래프 단위의 과업 출력으로 변환하는 함수이다.

</details>

| 구성요소 | 책임 |
|:---|:---|
| 특징 저장소 | 노드•간선 연결과 **초기 특징** 보관 |
| 메시지 함수 | 이웃•간선의 **전달값** 계산 |
| 집계 함수 | 이웃 메시지의 **순서 불변 결합** |
| 갱신 함수 | 현재 표현과 **집계값 결합** |
| 읽기 함수 | 노드 표현을 **과업별 출력**으로 변환 |

#### 한줄 요약
- 이웃 메시지를 모아 노드 표현을 갱신한 뒤 과업별 결과를 냅니다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **순서 불변성**: 이웃 노드가 입력되는 순서가 바뀌어도 집계 결과가 같아야 하는 성질이다.
- **전파 깊이**: 이웃 메시지를 반복 전달하는 층수로, 한 노드가 반영할 수 있는 관계 범위를 정하는 개념이다.

</details>

```text
┌──────────── 전파 층 종료까지 ────────────┐
│ 특징•출력 표현                          │
│   │ 1. 노드•간선 특징 전달             │
│   ▼                                      │
│ 메시지 함수                              │
│   │ 2. 이웃별 메시지 계산              │
│   ▼                                      │
│ 집계 함수                                │
│   │ 3. 순서 불변 집계                  │
│   ▼                                      │
│ 갱신 함수                                │
│   └── 4. 노드 표현 갱신 ──▶ 특징•출력 표현
└──────────────────────────────────────────┘
특징•출력 표현
   └ 5. 과업별 출력 산출
```

**동작 원리**

1. **노드•간선 특징 전달**: 그래프 연결과 현재 상태를 제공한다.
2. **이웃별 메시지 계산**: 이웃•간선의 전달 특징을 산출한다.
3. **순서 불변 집계**: 이웃 순서와 무관하게 메시지를 결합한다.
4. **노드 표현 갱신**: 현재 상태와 집계값을 결합한다.
5. **과업별 출력 산출**: 노드•링크•그래프 결과를 생성한다.

#### 한줄 요약
- 이웃 정보를 필요한 거리만큼 전달해 각 노드의 표현을 갱신합니다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **그래프 합성곱 신경망(Graph Convolutional Network, GCN)**: 정규화한 이웃 특징을 합성곱처럼 집계해 노드 표현을 갱신하는 개념이다.
- **그래프 표본화•집계(Graph Sample and Aggregate, GraphSAGE)**: 이웃을 표본화하고 집계 함수를 학습해 신규 노드에도 적용하는 귀납적 그래프 신경망이다.
- **그래프 어텐션 신경망(Graph Attention Network, GAT)**: 이웃별 중요도 가중치를 어텐션으로 학습해 메시지를 집계하는 개념이다.

</details>

**GCN•GraphSAGE•GAT**은 이웃을 결합하는 방식이 다르다.

| GNN 방식 | GCN | GraphSAGE | GAT |
|:---|:---|:---|:---|
| 적용 기준 | 고정 그래프 **반지도 학습** | **대규모•변화 그래프** | 이웃 **중요도 학습** 시 |
| 핵심 특징 | **정규화 이웃 집계** | **이웃 표본화•귀납 학습** | 이웃별 **어텐션 가중치** |
| 한계 | 깊은 층의 **과평활** | **표본 편향•정보 누락** | 높은 **연산량•잡음 민감도** |

> 요약: **그래프 규모•이웃 특성**에 따른 모델을 선택한다.

#### 한줄 요약
- 전체•표본•가중 집계 중 그래프 규모와 이웃 특성에 맞는 방식을 고릅니다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **이웃 표본화**: 큰 이웃 집합에서 일부 노드를 선택해 메시지 전달의 메모리와 연산량을 제한하는 기법이다.
- **평가 누출**: 미래 시점의 노드나 간선 정보가 학습 데이터에 섞여 성능이 실제보다 높게 측정되는 문제이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 깊은 전파의 **과평활** | 잔차 연결•**전파 층수 제한** | **노드 구별력** 보존 |
| 큰 이웃 집합의 **계산량 폭증** | **이웃 표본화**•미니배치 적용 | **메모리•연산량** 통제 |
| 시간 관계의 **평가 누출** | 시간 순서 기반 **그래프 분할** | 신규 노드 **일반화** 검증 |

#### 한줄 요약
- 거래망과 분자 구조의 관계를 학습하되 새 계좌와 새 분자에서도 맞는지 따로 검증해야 합니다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **집계 방식**: 이웃의 정보를 합•평균•표본화•어텐션 등으로 결합하는 규칙이다.
- **노드 구별력**: 관계가 다른 노드가 학습 표현에서도 서로 다르게 유지되는 정도이다.

</details>

- 이웃 범위•그래프 변화에 따라 **집계 방식**을 선택하고 **과평활**을 통제한다.

#### 한줄 요약
- 어떤 이웃의 정보를 어떻게 모으고 몇 단계 전달할지 정해 노드 구별력이 유지되는지 확인해야 합니다.
