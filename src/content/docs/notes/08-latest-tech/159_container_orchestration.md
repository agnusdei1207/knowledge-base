## 미리 알고가기

- **컨테이너 오케스트레이션(Container Orchestration)**: 다중 호스트의 컨테이너 배포·연결·복구·확장을 자동 조정하는 운영 개념
- **오케스트레이션(Orchestration)**: 여러 실행·네트워크·복구 기능을 하나의 목표 상태에 맞춰 조율
- **Kubernetes(쿠버네티스)**: 컨테이너 오케스트레이션 개념을 구현한 대표 플랫폼



## Ⅰ. 개요

- 정의/개념: 여러 호스트의 컨테이너 배치·연결·확장·복구를 통합 자동화하는 운영 체계다
- 기존 한계: 개별 런타임만으로는 여러 호스트의 배치와 장애 복구를 일관되게 조정하기 어렵다
- **배경/필요성**: 분산 서비스의 목표 상태를 지속적으로 유지하기 위함이다

### 쉽게 이해하기 (학습용)

- 여러 지점에 일을 나누고 연결하며 결원이 생기면 대체 인력을 보내는 전체 운영 체계임

## Ⅱ. 특징

- 목표 상태를 기준으로 실행 수·버전·자원을 조정한다
- 스케줄링과 서비스 발견으로 배치와 연결을 자동화한다
- 상태 감시로 장애 복구와 수평 확장을 수행한다

### 쉽게 이해하기 (학습용)

- 인원과 규칙을 정하면 배치, 안내, 결원 보충, 증원이 자동으로 이어지는 능력임

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 선언 조정 | 서비스 요구 사항과 현재 상태의 차이 조정 |
| 스케줄러 | 최적 호스트 선택 및 배치 |
| 노드 실행 | 이미지 수신·컨테이너 실행 및 보고 |
| 서비스 연결 | 실행 위치 발견 및 주소 추상화 |
| 복구 확장 | 실패·부하에 따른 재시작 및 증감 수행 |

> 요약: 선언 상태에 따라 스케줄링·서비스·복구를 조정한다.

### 쉽게 이해하기 (학습용)

- 기준 장부, 자리 배정자, 현장 실행자, 안내 데스크, 결원·증원 담당자가 연결된 전체 운영 조직과 같음

## Ⅳ. 원리 및 절차 흐름도

```text
선언등록 → 상태비교
               ↓
          실행·확장필요?
        ├─ 아니요 → 대기
        └─ 예 → 배치·실행
               ↓
          서비스갱신
               ↓
        복구·확장수행
```

| 절차 | 설명 |
|:---|:---|
| 서비스선언 | 목표·버전·배치·연결 정책 등록 |
| 상태조정 | 목표와 실제 실행 상태의 차이 계산 |
| 배치실행 | 호스트 선택 및 컨테이너 실행 |
| 서비스연결 | 실행 위치를 발견하여 주소 갱신 |
| 복구확장 | 장애 대응 및 인스턴스 증감 수행 |

> 요약: 목표와 실제 상태의 차이를 배치·연결·복구로 조정한다

### 쉽게 이해하기 (학습용)

- 목표 인원과 현재 인원을 비교해 배치하고 결원과 수요 증가에 대응한다.

## Ⅴ. 종류 및 비교

| 판단 기준 | 컨테이너 오케스트레이션 | 단일 호스트 런타임 | 가상머신 관리 |
|:---|:---|:---|:---|
| 적용 기준 | 다중 호스트 분산 서비스 | 한 호스트의 단순 실행 | 강한 격리·레거시 운영 |
| 핵심 특징 | 선언 조정·스케줄·복구 | 로컬 컨테이너 직접 실행 | 게스트 OS 단위 자원 관리 |
| 한계 | 제어면과 운영 복잡도 증가 | 다중 호스트 자동 조정 부재 | 큰 이미지와 시작 비용 |

> 요약: 관리 범위로 오케스트레이션·런타임·가상머신을 구분한다.

### 쉽게 이해하기 (학습용)

- 여러 공장의 작은 작업 상자를 운영하면 오케스트레이션, 한 공장만 쓰면 런타임, 공장 방 전체를 빌리면 가상머신 관리가 맞음

## Ⅵ. 실무 사례

1. 전자상거래 플랫폼은 운영 요구를 Kubernetes 객체로 구체화한다
2. 단일 장비의 고정 작업은 오케스트레이터 대신 런타임을 사용한다

### 쉽게 이해하기 (학습용)

- 먼저 여러 지점 운영 능력이 필요한지 판단하고, 필요할 때 Kubernetes를 구현체로 고르며 한 지점이면 단순 도구를 쓰는 것임

## Ⅶ. 결론

- 다중 호스트 자동 조정이 필요할 때 적합한 구현체를 선택한다

### 쉽게 이해하기 (학습용)

- 여러 서버의 컨테이너를 한 기준으로 배치·복구한다
