## 미리 알고가기

- **AI 검색**: AI 검색은 링크 목록만 보여주던 전통 검색을 넘어 답변과 출처를 함께 제공하는 검색 서비스 개념임
- **기술 엔진**: 기술 엔진은 주로 hybrid retrieval과 reranker와 RAG 조합으로 구성됨
- **검색 품질보다 답변**: 검색 품질보다 답변의 검증 가능성과 후속 질의 경험이 함께 중요함



## Ⅰ. 개요

- 정의/개념: 질의를 해석해 검색·재순위하고 근거 답변 생성
- 기존 한계: 키워드 중심 검색은 질의와 문서의 표현이 다르거나 여러 근거를 결합해야 하는 복합 질문을 처리하기 어렵다.

### 쉽게 이해하기 (학습용)

- 뜻이 맞는 자료를 찾아 재순위하고 필요하면 그 근거로 답변을 작성합니다.

## Ⅱ. 특징

- 질의의 의도·개체·제약을 해석해 검색 경로를 정한다.
- 희소·밀집 검색 후보를 합쳐 어휘와 의미 신호를 보완한다.
- 재순위 모델이 통합 후보의 질의 관련성을 다시 계산한다.
- 생성 답변은 선택된 검색 결과에 근거한 별도 산출물이다.

### 쉽게 이해하기 (학습용)

- 어휘·의미 검색 결과를 재순위한 뒤 요청에 따라 상위 문서로 답변합니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 질의 이해 계층 | 질의 의도와 검색 경로 결정 |
| 희소 검색기 | 어휘 일치 기반 문서 순위 |
| 밀집 검색기 | 표현 의미 근접성 기반 순위 |
| 재순위 계층 | 통합 후보 질의 관련성 판정 |
| 답변 생성기 | 상위 근거 활용 답변과 출처 생성 |

```text
[질의 이해]
  ├─> [희소 검색] ─┐
  └─> [밀집 검색] ─┤
                    ▼
             [후보 통합·재순위]
                    ↓
             [문서·근거 답변 계층]
```

### 쉽게 이해하기 (학습용)

- 질의 해석·희소 검색·밀집 검색·재순위·답변 생성이 책임을 나눕니다.

## Ⅳ. 원리 및 절차 흐름도

```text
질의 해석 → 희소·밀집 후보 검색 → 후보 통합·재순위
                                         ↓
                                 순위 문서 반환
                            ├─ 검색 요청 → 원문 링크 제공
                            └─ 답변 요청 → 상위 근거로 생성
                                             ↓
                                      답변·출처 제공
```

| 절차 | 설명 |
|:---|:---|
| 질의 해석 | 질의 의도와 검색 경로 결정함 |
| 후보 검색 | 희소 밀집 검색기 후보 반환함 |
| 후보 통합 | 후보 합치고 순위 융합함 |
| 재순위 | 통합 후보 질의 관련성 판정함 |
| 결과 반환 | 순위 문서와 원문 링크 반환함 |
| 답변 생성 | 상위 근거 활용 답변과 출처 작성함 |

### 쉽게 이해하기 (학습용)

- 질문을 분석해 후보를 모으고 재순위한 뒤 문서나 근거 답변을 반환합니다.

## Ⅴ. 종류 및 비교

| 판단 기준 | 전통 검색 | 의미 검색 | AI 검색 |
|:---|:---|:---|:---|
| 검색 기준 | 어휘 일치 | 의미 근접성 | 해석 후 복수 검색 |
| 결과 형태 | 어휘 순위 문서 | 의미 순위 문서 | 문서와 근거 답변 |
| 적용 기준 | 정확한 용어 검색 | 자연어 질의 검색 | 근거 답변 필요 시 |

> 요약: 검색과 생성을 통합한 지능형 검색 서비스임

### 쉽게 이해하기 (학습용)

- 전통·의미·AI 검색은 사용하는 신호와 결과 형태가 다릅니다.

## Ⅵ. 실무 사례

- 조항명과 자연어 질문 후보를 통합해 정책 재순위

### 쉽게 이해하기 (학습용)

- 정확한 규정명과 일상어 질문을 모두 찾고 답변에는 확인할 원문을 붙입니다.

## Ⅶ. 결론

- 검색 결과를 직접 답변으로 종합하면서 정확성을 유지하기 위해 **검색 회수율·답변 충실성·인용 정확도·추가 지연·비용**을 검토하고, 근거 검증이 가능한 검색 업무에 AI 검색을 활용해야 한다.

### 쉽게 이해하기 (학습용)

- 좋은 자료를 찾았는지 먼저 확인하고 답변의 근거성과 추가 지연을 따로 평가해야 합니다.
