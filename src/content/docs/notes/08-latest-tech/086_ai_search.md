## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **인공지능 검색(Artificial Intelligence Search, AI 검색)**: 질의 해석•복수 검색•재순위로 근거 답변을 제공한다.

</details>

- 정의: 질의 해석•복수 검색•재순위로 답변하는 **AI 검색**이다.
- 배경/필요성: 전통적인 웹 및 엔터프라이즈 검색 엔진은 단순 키워드 매칭(Lexical Match) 및 링크 분석(PageRank)을 통해 10개의 파란색 링크(10 Blue Links) 목록만을 제공하므로, 사용자가 복합적인 질문에 대한 답을 얻기 위해 수많은 웹페이지를 일일이 클릭하고 비교·요약해야 하는 막대한 인지적 오버헤드가 발생함에 따라, LLM의 심층 자연어 이해 및 생성 능력과 실시간 하이브리드 검색, 신경망 재순위화 및 RAG 아키텍처를 유기적으로 융합한 AI 검색(AI Search / Perplexity, Google Search Generative Experience: SGE, Bing Copilot) 서비스를 도입하여 **사용자의 복합 자연어 질문에 대해 실시간 웹/문서 검색 결과를 기반으로 출처가 명시된 직접적이고 정확한 종합 답변(Synthesized Answer) 즉시 생성, 다단계 대화형 후속 질의(Conversational Follow-up)를 통한 탐색적 정보 검색 지원, 검색 회수율과 답변 신뢰성을 동시에 극대화한 사용자 정보 소비 패러다임의 혁신**을 달성할 필요

#### 한줄 요약

- 의미 검색•**재순위** 후 근거 기반 답변 제공

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **하이브리드 검색(Hybrid Search)**: 희소•밀집 검색 후보를 결합하는 기법이다.
- **재순위(Reranking)**: 후보의 질의 관련성을 재평가해 순서를 조정한다.

</details>

- **질의 의도•제약** 기반 검색 경로 결정
- 어휘•의미 신호를 보완하는 **하이브리드 검색**
- **재순위•근거 생성** 분리해 관련성•충실성 검증

#### 한줄 요약

- **질의 이해•하이브리드 검색•재순위•근거 생성** 결합

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **질의 이해(Query Understanding)**: 의도•제약을 식별해 검색 경로와 필터를 정한다.
- **후보 융합(Candidate Fusion)**: 검색 결과의 중복을 제거하고 점수•순위를 결합한다.
- **검색 증강 생성(Retrieval-Augmented Generation, RAG)**: 검색 문서로 근거 답변을 생성한다.

</details>

```text
                    [질의 이해 계층]
                      /           \
             [희소 검색기]──[밀집 검색기]
                      \           /
                    [후보 융합 계층]──[재순위기]──[답변 생성기]
```

| 구성요소 | 책임 |
|:---|:---|
| 질의 이해 계층 | 질의 **의도•제약 기반 검색 경로 결정** |
| 희소 검색기 | **어휘 일치** 기반 후보 문서 검색 |
| 밀집 검색기 | **임베딩 유사도** 기반 후보 문서 검색 |
| 후보 융합 계층 | 복수 검색 결과의 **점수•순위 융합** |
| 재순위기 | 통합 후보의 **질의 관련성** 판정 |
| 답변 생성기 | **RAG 기반 답변•출처 생성** |

#### 한줄 요약

- **질의 이해•희소•밀집•융합•재순위•생성** 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **검색 경로(Search Path)**: 의도•제약에 따라 선택한 검색기•필터•융합 조합이다.
- **출처 인용(Source Citation)**: 답변을 뒷받침하는 원문 위치와 문서이다.

</details>

```text
사용자 ── 질의•제약 ──▶ 질의 이해 계층
                            │ 1. 검색 경로 결정
                            ▼
                          검색기
                            │ 2. 후보 융합
                            ▼
                         재순위기
                            │ 3. 상위 근거 선별
                            ▼
                       답변 생성기
                            │ 4. 근거 답변 생성
사용자 ◀── 답변•출처 ──────┘
```

### 동작 원리

1. 검색 경로 결정: 의도·제약별 **검색 조합·필터** 선택
2. 후보 융합: 희소·밀집 결과의 **중복 제거·순위 융합**
3. 상위 근거 선별: **질의 관련성** 평가 기반 문서 선별
4. 근거 답변 생성: 선택 근거 기반 **답변·출처 인용** 생성

#### 한줄 요약

- **경로 결정•후보 융합•근거 선별•답변 생성** 수행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **전통 검색(Lexical Search)**: 어휘 일치와 빈도로 문서 순위를 계산한다.
- **의미 검색(Semantic Search)**: 임베딩 의미 유사도로 문서를 찾는다.

</details>

| 검색 방식 | AI 검색 | 전통 검색 | 의미 검색 |
|:---|:---|:---|:---|
| 적용 기준 | **복합 질의·근거 답변** | **정확한 용어 검색** | **자연어 의미 검색** |
| 핵심 특징 | **복수 검색•재순위와 답변 생성** | **어휘 일치 기반 문서 순위** | **임베딩 근접성 기반 순위** |
| 한계 | **생성 충실성•추가 지연** | **표현 불일치** | 정확한 **고유명사 누락** |

#### 한줄 요약

- 어휘·의미·복수 검색과 생성에 따른 **검색 방식 구분**

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **검색 누락(Retrieval Miss)**: 관련 근거가 검색•융합 후보에 포함되지 않는 문제이다.
- **근거 불충실(Ungrounded Answer)**: 답변이 검색 원문의 범위를 벗어나는 문제이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 희소·밀집 융합 실패와 검색 누락 | 검색기 회수율·**재순위 성능 분리 평가** | 복합 질의의 **근거 회수율** 향상 |
| 검색 밖 생성과 근거 불충실 | 인용 검증·**근거 없음 응답 정책** | 답변의 **출처 충실성** 확보 |

#### 한줄 요약

- **검색 회수율•재순위 성능•답변 충실성** 검증

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **검색 회수율(Retrieval Recall)**: 관련 문서 중 검색 후보에 포함된 비율이다.
- **답변 충실성(Answer Faithfulness)**: 답변 주장이 검색 근거와 일치하는 정도이다.

</details>

- 단순 링크 나열형 검색을 넘어 질문의 의도를 깊이 이해하고 실시간 검증된 출처를 기반으로 완성형 지식을 합성·제공하는 **차세대 인공지능 정보 검색(AI Search / Query Understanding & Intent Decomposition / Real-Time Hybrid Retrieval / Multi-Document Neural Reranking & Synthesis / Real-Time Citation Attribution)의 절대적 미래 표준**으로 확고히 자리 잡았으며, 멀티모달 및 에이전틱 자율 검색으로 급속히 진화하는 가운데, 실무 AI 검색 플랫폼 구축 시에는 **정보의 최신성을 보장하기 위한 실시간 웹 인덱싱 및 크롤링 파이프라인 구축, 생성된 모든 문장에 대해 클릭 가능한 정확한 출처 링크(Inline Citation)를 의무 매핑하는 신뢰성 확보, 사용자 질의 복잡도에 따라 단순 검색과 심층 추론(Deep Research)을 동적으로 분기하는 지능형 라우팅 아키텍처**를 결합하여 완벽한 검색 적합성과 생성 신뢰성을 완성

#### 한줄 요약

- **검색 관련성•근거성•지연 예산** 대상 따라 검색•생성 경로 결정
