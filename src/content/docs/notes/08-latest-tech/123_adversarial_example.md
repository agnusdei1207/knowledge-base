## 미리 알고가기

- **적대적 예제**: 적대적 예제는 추론 시점에 미세한 교란을 더해 모델 오판을 유도하는 공격임
- **모델 민감성**: 사람이 보기엔 거의 같은 입력이어도 모델은 경계 근처에서 크게 흔들릴 수 있음
- **강건성 평가**: 강건성 평가는 clean accuracy와 adversarial accuracy를 함께 봐야 의미가 있음
- **교란 예산 ($\epsilon$)**: $\epsilon$(엡실론)은 사람이 눈치채지 못할 만큼 입력을 바꿀 수 있는 최대 교란 크기를 제한하는 기호임

## Ⅰ. 개요

- **정의/개념**: 입력 교란으로 모델 오분류를 유도하는 공격 표본이다
- **배경/필요성**: 정상 정확도에 숨은 최악 입력 위험을 찾는다

### 쉽게 이해하기 (학습용)

- 사진이 사람에게는 그대로 보여도 모델이 중요하게 보는 수치를 계산해 조금 바꾸면 판정이 뒤집힐 수 있음

## Ⅱ. 특징

- 손실 방향 탐색은 작은 변화로 오분류를 만든다
- 지식·질의·교란 한도는 공격 가능 범위를 정한다
- 전이성은 내부 정보 없이 다른 모델까지 공격한다
- 공격 방식·계산 예산은 강건성 평가를 바꾼다
- 위협 모델 공개는 방어 성능의 과장을 막는다

### 쉽게 이해하기 (학습용)

- 아무 곳이나 흔드는 잡음이 아니라 모델이 가장 헷갈리는 방향을 골라 제한된 크기만큼 입력을 움직이는 공격임

## Ⅲ. 아키텍처 및 구성요소

```text
    [위협 모델: 지식·예산]
          │
    [목적] ── [제약]
          │
    [알고리즘]
          │
    [강건성 지표]
```

| 설계 요소 | 설명 |
|:---|:---|
| 위협 모델 | 공격 지식·범위·계산 예산 |
| 목적함수 | 오분류를 유도하는 손실 |
| 교란 제약 | 입력 변화의 거리 조건 |
| 공격 알고리즘 | 교란 후보 탐색 계산 |
| 강건성 지표 | 위협 범위 안의 방어 성능 |

> 요약: 위협 모델과 교란 제약 안에서 강건성을 평가한다

### 쉽게 이해하기 (학습용)

- 공격자가 무엇을 알고 얼마나 바꿀 수 있는지 경계선을 먼저 그은 뒤, 그 안에서 오판을 찾고 남은 정답 비율을 재는 구조임

## Ⅳ. 원리 및 절차 흐름도

```text
입력
 ↓
설정
 ↓
계산
 ↓
검사
 ↓
판정
```

| 절차 | 설명 |
|:---|:---|
| 입력 선택 | 정상 판정 표본 선택 |
| 모델 설정 | 공격 목표·예산 결정 |
| 교란 계산 | 손실을 키우는 입력 변화 탐색 |
| 제약 검사 | 후보를 허용 집합에 투영 |
| 결과 판정 | 공격 성공·예산 소진 기록 |

> 요약: 제약 안에서 교란을 탐색해 공격 성공을 판정한다

### 쉽게 이해하기 (학습용)

- 정상 입력 하나를 고르고 공격 규칙을 정한 뒤, 허용선 밖의 후보는 되돌리면서 오판이 생기거나 계산 예산이 끝날 때까지 반복함

## Ⅴ. 종류 및 비교

| 판단 기준 | Fast Gradient Sign Method (FGSM) | Projected Gradient Descent (PGD) | Carlini-Wagner (C&W) |
|:---|:---|:---|:---|
| 핵심 특징 | 기울기 부호로 한 번 이동 | 이동·제약 투영 반복 | 거리·오분류 공동 최적화 |
| 적용 기준 | 빠른 회귀 점검 | 반복 공격 평가 | 작은 교란 정밀 탐색 |
| 주요 위험 | 강건성 과대평가 | 계산 비용 증가 | 매개변수별 결과 편차 |

> 요약: FGSM은 1회, PGD는 반복, C&W는 정밀 탐색이다

### 쉽게 이해하기 (학습용)

- FGSM은 한 걸음에 교란을 만들고, PGD는 허용선 안에서 여러 걸음 찾으며, C&W는 오판을 만드는 작은 변화를 최적화함

## Ⅵ. 실무 사례

1. 영상 분류는 PGD로 정상·강건 정확도를 평가한다
2. 악성코드 분류는 기능 보존 교란만 허용한다

### 쉽게 이해하기 (학습용)

- 영상 분류는 픽셀 변화량을 고정한 PGD로 정상 정확도와 강건 정확도를 함께 평가한다.
- 악성코드는 실행 기능을 보존하는 변환만 허용해 공격 표본의 유효성을 판정한다.

## Ⅶ. 결론

- 지식·교란·계산 예산별 정상·강건 정확도를 비교한다.

### 쉽게 이해하기 (학습용)

- 자물쇠가 한 도구를 견뎠다고 모든 침입에 안전한 것은 아니므로, 공격자의 지식과 도구 범위를 적은 뒤 그 범위에서만 강하다고 말해야 함
