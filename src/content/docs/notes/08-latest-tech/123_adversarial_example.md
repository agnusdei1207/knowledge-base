## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **적대적 예제**: 추론 입력을 위협 모델의 허용 범위 안에서 조작해 모델의 오분류나 표적 출력을 유도하는 표본이다.
- **최악 방향 교란**: 무작위가 아니라 모델 손실을 가장 크게 높이는 방향으로 만든 입력 변화이다.

</details>

- 정의/개념: 추론 시 입력을 제한 범위에서 조작해 **모델의 오분류•표적 출력을 유도하는 공격 표본**
- 배경/필요성: 무작위 잡음 평가의 **최악 방향 입력 교란** 탐지 한계

#### 한줄 요약

- 사진이 사람에게는 그대로 보여도 모델이 중요하게 보는 수치를 계산해 조금 바꾸면 판정이 뒤집힐 수 있음

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **위협 모델**: 공격자의 지식•목표•질의 접근•교란 범위와 계산 예산을 정의한 가정이다.
- **교란 예산 $\epsilon$**: 위협 모델이 허용하는 최대 입력 변화량이다.
- **전이성**: 한 모델에서 만든 적대적 예제가 다른 모델에도 오판을 유발하는 성질이다.

</details>

![허용 교란 범위 안의 적대적 예제](/study/diagrams/adversarial-perturbation.svg)

> 파란 정상 표본 $x$가 점선 $\epsilon$ 범위 안에서 붉은 $x'$로 이동해 검은 결정 경계를 넘으면 오분류되며, 공격 성공률 실측값이 아닌 입력 공간의 개념 좌표다.

- 위협 모델과 주장 범위를 정하는 **지식•목표•질의•교란•계산 예산**
- 제한된 입력 변화에서 오판을 찾는 **손실 방향 탐색•전이성**
- 방어 성능 과장을 막는 **정상•적대 정확도•공격 설정 공개**

#### 한줄 요약

- 아무 곳이나 흔드는 잡음이 아니라 모델이 가장 헷갈리는 방향을 골라 제한된 크기만큼 입력을 움직이는 공격임

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **목적함수**: 비표적 오분류나 특정 표적 출력을 유도하도록 공격이 최적화하는 손실이다.
- **교란 제약기**: 입력 변화가 거리 규범과 허용 예산 안에 있는지 판정한다.
- **강건성 평가기**: 정한 위협 모델 범위에서 공격 후에도 맞춘 표본의 비율을 측정한다.

</details>

```text
[위협 모델 저장소]---[목적함수]---[교란 제약기]
         |                |              |
         +----------[공격 알고리즘]------+
                          |
                    [강건성 평가기]
```

선의 의미: 위협 모델, 목적함수, 교란 제약기가 공격 알고리즘의 탐색 경계를 정의하고, 강건성 평가기가 해당 위협 범위의 방어 성능을 측정하는 구조를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| **위협 모델 저장소** | 공격 지식•범위•계산 예산 보관 |
| **목적함수** | 오분류를 유도하는 손실 |
| **교란 제약기** | 입력 변화의 거리•허용 범위 판정 |
| **공격 알고리즘** | 교란 후보 탐색 계산 |
| **강건성 평가기** | 위협 범위 안의 방어 성능 측정 |

#### 한줄 요약

- 공격자가 무엇을 알고 얼마나 바꿀 수 있는지 경계선을 먼저 그은 뒤, 그 안에서 오판을 찾고 남은 정답 비율을 재는 구조임

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **제약 투영**: 허용 범위를 벗어난 교란 후보를 다시 거리 예산 안으로 되돌리는 연산이다.
- **강건 정확도**: 허용된 공격을 적용한 뒤에도 정답을 유지한 표본의 비율이다.

</details>

```text
위협 모델•목적함수
   │ 1. 공격 지식•예산
   │ 2. 오분류 손실 방향
   ▼
┌──────── 공격 성공•계산 예산 종료까지 ────────┐
│ 공격 알고리즘 ── 3. 교란 후보 생성 ──▶ 교란 제약기
│ 교란 제약기 ── 4. 허용 범위 투영 ──▶ 강건성 평가기
│ 공격 알고리즘 ◀─ 5. 공격 성공•강건 정확도 평가 ─ 평가기
└──────────────────────────────────────────────┘
```

1. **공격 지식•예산**: 공격자의 접근 범위와 계산 한계 고정
2. **오분류 손실 방향**: 비표적•표적 공격의 최적화 목표 결정
3. **교란 후보 생성**: 손실 기울기로 입력 변화 탐색
4. **허용 범위 투영**: 예산 밖 후보를 제약 집합으로 복귀
5. **공격 성공•강건 정확도 평가**: 위협 범위의 방어 성능 판정

#### 한줄 요약

- 정상 입력 하나를 고르고 공격 규칙을 정한 뒤, 허용선 밖의 후보는 되돌리면서 오판이 생기거나 계산 예산이 끝날 때까지 반복함

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **빠른 기울기 부호 방법(Fast Gradient Sign Method, FGSM)**: 손실 기울기의 부호를 이용해 한 번에 교란을 생성하는 공격이다.
- **투영 경사 하강법(Projected Gradient Descent, PGD)**: 교란을 반복 갱신하고 매 단계 허용 범위에 투영하는 공격이다.
- **칼리니-와그너 공격(Carlini and Wagner Attack, C&W)**: 작은 교란으로 오분류를 유도하도록 거리와 공격 목적을 함께 최적화하는 공격이다.

</details>

FGSM, PGD, C&W는 탐색 반복과 교란 최적화 강도가 다르다.

| 적대적 예제 생성 방식 | FGSM | PGD | C&W |
|:---|:---|:---|:---|
| **적용 기준** | 빠른 **회귀 점검** | 반복 **공격 평가** | 작은 교란의 **정밀 탐색** |
| **핵심 특징** | 기울기 부호로 **1회 이동** | 이동•**제약 투영 반복** | 거리•오분류 **공동 최적화** |
| **한계** | 약한 공격으로 **과대평가** | 반복 **계산 비용 증가** | 설정별 **결과 편차** |

#### 한줄 요약

- FGSM은 한 걸음에 교란을 만들고, PGD는 허용선 안에서 여러 걸음 찾으며, C&W는 오판을 만드는 작은 변화를 최적화함

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **방어 과대평가**: 약한 공격만 사용해 실제보다 높은 적대적 강건성을 주장하는 문제이다.
- **교란 의미 불일치**: 거리 규범과 $\epsilon$이 실제 허용 가능한 입력 변화와 맞지 않는 문제이다.
- **공격 재현성**: 반복 횟수•초기값•성공 조건을 공개해 같은 평가 결과를 다시 얻을 수 있는 성질이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 약한 공격으로 **방어 과대평가** | **FGSM•PGD•C&W 비교** | 기울기 은폐의 **오판 완화** |
| 교란 예산의 **의미 불일치** | 입력별 **거리 규범•ε** 명시 | 강건성의 **주장 범위** 고정 |
| **공격 설정 비공개** | 반복•초기값•성공 조건•**강건 정확도 공개** | **공격 재현성 확보** |

#### 한줄 요약

- 제한된 교란에서 정상 정확도와 공격 후 정확도를 함께 비교한다

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **공격 지식**: 공격자가 모델 구조•가중치•기울기•출력에 접근할 수 있는 범위이다.
- **계산 강도**: 공격이 교란 후보를 탐색하는 반복 횟수와 시작점•연산 자원의 수준이다.

</details>

- **공격 지식•교란 예산•계산 강도**를 명시하고 해당 위협 모델의 강건 정확도만 판정

#### 한줄 요약

- 자물쇠가 한 도구를 견뎠다고 모든 침입에 안전한 것은 아니므로, 공격자의 지식과 도구 범위를 적은 뒤 그 범위에서만 강하다고 말해야 함
