## 미리 알고가기

- **데이터 메시 (Data Mesh) 도메인 분산형 데이터 제품 모델**: 데이터 소유와 품질 책임을 도메인에 위임함
- **핵심 원칙**: 도메인 소유, 제품화, 셀프서비스 플랫폼, 연합 거버넌스로 구성됨
- **조직 책임**: 기술보다 조직 운영 모델과 데이터 책임 변화가 성공 핵심임



## Ⅰ. 개요

- **정의/개념**: 도메인이 데이터 제품을 소유하는 분산 접근
- **배경/필요성**: 중앙 데이터팀 병목과 의미·품질 단절을 해소

### 쉽게 이해하기 (학습용)

- 본사가 모든 상품을 만들기보다 각 팀이 자기 상품을 책임지고 공통 품질 규칙으로 거래하는 방식임

## Ⅱ. 특징

- 도메인 소유가 의미·품질 책임을 원천에 둔다.
- 데이터 제품화가 소비자용 SLO·계약을 만든다.
- 셀프서비스 플랫폼이 도메인 인지부하를 줄인다.
- 연합 거버넌스가 전역 규칙을 자동 집행한다.

### 쉽게 이해하기 (학습용)

- 지역팀이 상품을 책임지되 품질 약속을 붙이고, 공통 설비를 쓰며 전역 표시·보안 규칙은 함께 정해 자동 검사함

## Ⅲ. 아키텍처 및 구성요소

```text
[주문 도메인 제품] ─┐
[고객 도메인 제품] ─┼→ 제품 catalog·graph → 분석·AI 소비자
[재고 도메인 제품] ─┘
       ↑ 셀프서비스 플랫폼·연합 계산 정책·mesh supervision
```

| 설계 요소 | 설명 |
|:---|:---|
| 도메인 데이터 제품팀 | 도메인별 개발/운영/품질 책임 보유 |
| 데이터 제품 | code, data, metadata 등 독립 배포 단위 |
| 셀프서비스 플랫폼 | 재사용 가능한 인프라/파이프라인 제공 |
| 발견/소비 계층 | 카탈로그를 통한 제품 검색 및 조합 지원 |
| 연합 거버넌스 | 전역 호환 규칙 및 정책 합의 |
| 계산 정책/슈퍼비전 | 정책 자동 검증 및 메시 지표 관측 |

> 요약: 도메인 책임과 플랫폼·연합 정책으로 제품 발견

### 쉽게 이해하기 (학습용)

- 각 팀이 상품과 생산설비, 품질을 책임지고 공통 공장과 자동 품질검사가 지역 상품을 연결함

## Ⅳ. 원리 및 절차 흐름도

```text
도메인 선정
    ↓
제품 설계
    ↓
플랫폼 제공
    ↓
정책 검증
    ↓
소비 개선
```

| 절차 | 설명 |
|:---|:---|
| 도메인·사용자 가치 선정 | 도메인·사용자 가치 선정을 수행하고 결과를 검증함 |
| 데이터 제품·계약 설계 | 데이터 제품·계약 설계을 수행하고 결과를 검증함 |
| 셀프서비스 제공 | 셀프서비스 제공을 수행하고 결과를 검증함 |
| 연합 정책 검증·공개 | 연합 정책 검증·공개을 수행하고 결과를 검증함 |
| 소비·SLO 개선 | 소비·SLO 개선을 수행하고 결과를 검증함 |

> 요약: 제품 계약·셀프서비스·자동 정책을 반복 개선

### 쉽게 이해하기 (학습용)

- 고객 필요에 맞춰 상품을 정하고 품질 약속을 만든 뒤 공통 공장에서 생산/검사하고 피드백으로 개선함

## Ⅴ. 종류 및 비교

| 판단 기준 | Data Mesh | Data Fabric | 중앙 플랫폼 |
|:---|:---|:---|:---|
| 핵심 특징 | 도메인별 책임 분산 | 분산 자산 위 통합 계층 | 중앙팀 수집/모델 책임 |
| 적용 기준 | 도메인 데이터 제품 | 메타데이터 기반 서비스 | 중앙 데이터셋/파이프라인 |
| 주요 위험 | 도메인 확장/지역 자율 | 이기종 자산 통합/자동화 | 도메인 작고 표준화 시 |

> 요약: Mesh는 분산 책임, Fabric은 통합 계층

### 쉽게 이해하기 (학습용)

- 지역 상품 조직, 여러 곳을 잇는 자동 물류망, 중앙 창고 운영은 해결하는 문제가 다름

## Ⅵ. 실무 사례

1. 대상 환경의 도입 조건과 설계를 검증함
2. 운영 위험과 성과 지표를 검증함

### 쉽게 이해하기 (학습용)

- 디지털 미디어 기업은 podcast·artist·user 도메인이 각 운영 기능과 함께 청취·정산·사용자 분석 데이터 제품을 소유하고 공통 식별자와 품질 표현으로 조합함
- 유통사는 주문·고객·재고 도메인이 versioned schema와 신선도 SLO를 가진 제품을 제공하고 플랫폼이 pipeline·catalog·접근정책을 셀프서비스로 제공함

## Ⅶ. 결론

- 도메인 책임·제품 SLO를 플랫폼·연합 정책으로 통제

### 쉽게 이해하기 (학습용)

- 지역팀의 상품 책임을 공통 공장과 자동 규칙으로 연결함
