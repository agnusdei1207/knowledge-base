## 미리 알고가기

- **영상 생성**: 시간축을 가진 연속 프레임 생성 멀티모달 기술
- **품질**: 프레임 선명도보다 시간 일관성(Temporal Consistency)이 중요
- **유형**: Text, Image, Video 등 입력 조건에 따른 생성 기술



## Ⅰ. 개요

- 정의/개념: 공간 구조와 시간 움직임을 함께 합성하는 AI
- 기존 한계: 이미지 생성 모델을 프레임별로 적용하면 객체의 형태·위치·동작이 시간축에서 불연속적으로 변한다.

### 쉽게 이해하기 (학습용)

- 인물과 배경의 형태와 움직임이 이어지는 연속 장면 생성 기술입니다.

## Ⅱ. 특징

- 프레임 품질과 객체의 시간 연속성을 함께 학습한다.
- 궤적·카메라·포즈 조건으로 움직임을 제어한다.
- 시공간 관계 학습은 계산량과 메모리를 늘린다.
- 긴 영상은 오차 누적으로 물리 일관성이 저하된다.

### 쉽게 이해하기 (학습용)

- 한 장면이 선명해도 다음 장면에서 얼굴이나 움직임이 갑자기 바뀌면 시간 일관성이 낮습니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 조건 인코더 | 텍스트·참조 정보를 생성 조건으로 변환함 |
| 시공간 표현 | 프레임 공간과 시간 위치를 담은 잠재 텐서 |
| 생성 모델 | 프레임 구조와 변화를 예측함 |
| 움직임 제어기 | 궤적·카메라 등 제어 신호를 주입함 |
| 일관성 평가기 | 물리 법칙과 시간 연속성을 유지함 |

```text
[조건 인코더] ── [생성 모델]
      │               │
[움직임 제어기] ── [시공간 표현]
      │               │
[일관성 평가기] ── [연속 프레임]
```

### 쉽게 이해하기 (학습용)

- 조건 인코더·시공간 표현·생성기·움직임 제어기·평가기의 역할이 연결됩니다.

## Ⅳ. 원리 및 절차 흐름도

```text
[조건·움직임 입력]
        ↓
[초기 표현 생성]
        ↓
[시공간 생성]
        ↓
[연속성 갱신]
        ↓
[결과 점검]
```

| 절차 | 설명 |
|:---|:---|
| 조건 인코딩 | 텍스트·참조장면 등을 시공간 특징 변환함 |
| 초기 표현 생성 | 목표 길이·해상도 기반 잠재 텐서 구성함 |
| 시공간 생성 | 공간 구조와 인접 프레임 관계를 반영함 |
| 연속성 갱신 | 이전 객체 상태를 다음 조건으로 전달함 |
| 결과 점검 | 객체 외형과 물리 관계의 시간 일관성 확인 |

### 쉽게 이해하기 (학습용)

- 앞 장면의 객체 상태와 움직임을 다음 장면에 전달하고 전체 흐름의 일관성을 확인합니다.

## Ⅴ. 종류 및 비교

| 판단 기준 | 프레임별 | 비디오 확산 | 자기회귀 |
|:---|:---|:---|:---|
| 생성 단위 | 프레임 독립 생성 | 시공간 노이즈 제거 | 순차 프레임 생성 |
| 시간 일관성 | 외형 흔들림 존재 | 3차원 연산으로 유지 | 오차 누적 발생 |
| 적용 기준 | 프레임별 편집에 적합 | 움직임 최적화 적합 | 긴 영상 생성 적합 |

> 요약: 지연·길이에 따른 영상 생성 방식 선택

### 쉽게 이해하기 (학습용)

- 프레임을 독립 생성할지 시공간으로 함께 처리할지 순차 생성할지에 따라 특성이 달라집니다.

## Ⅵ. 실무 사례

- 광고 프리비즈는 제품·카메라 조건으로 장면을 검토한다.

### 쉽게 이해하기 (학습용)

- 광고 초안은 제작 속도를 중시하지만 학습 데이터는 객체가 물리 법칙대로 움직이는지 더 엄격히 확인해야 합니다.

## Ⅶ. 결론

- 목적에 맞는 영상을 생성하면서 시간적 불연속과 오용을 줄이기 위해 **영상 길이·프레임 일관성·물리 개연성·생성 지연·권리 및 안전성**을 검토하고, 기준을 통과한 결과만 활용해야 한다.

### 쉽게 이해하기 (학습용)

- 좋은 영상은 개별 장면뿐 아니라 처음부터 끝까지 같은 객체와 물리 세계가 이어져야 합니다.
