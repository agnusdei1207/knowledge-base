## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **스케일드 닷 프로덕트 어텐션(Scaled Dot-Product Attention)**: Q•K 내적을 키 차원의 제곱근으로 보정한 뒤 소프트맥스 가중치로 V를 결합하는 연산이다.
- **소프트맥스 포화**: 입력 점수 차이가 지나치게 커져 출력 확률이 일부 항목에 거의 모두 몰리고 기울기가 작아지는 현상이다.
- **쿼리(Query, Q)**: 현재 토큰이 찾을 정보의 조회 기준 벡터이다.
- **키(Key, K)**: 쿼리와의 관련성을 비교하는 식별 벡터이다.
- **밸류(Value, V)**: 가중치에 따라 결합되는 정보 벡터이다.

</details>

- 정의/개념: **쿼리**와 **키**의 내적을 $\sqrt{d_k}$로 보정하고 **밸류**를 가중 결합하는 어텐션이다.
- 배경/필요성: 고차원 쿼리(Q)•키(K) 내적값 증가는 **소프트맥스 포화와 학습 경사 소실**을 유발한다.

#### 한줄 요약
- **√d_k 보정•소프트맥스** 후 V 가중 결합이 핵심이다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **키 차원($d_k$)**: 키 벡터를 구성하는 원소의 수로, 내적 점수의 분산을 보정하는 기준이다.
- **스케일링(Scaling)**: $QK^T$를 $\sqrt{d_k}$로 나누어 점수 폭과 소프트맥스 기울기를 안정화하는 연산이다.
- **시퀀스 길이($N$)**: 입력을 구성하는 토큰 수로, 전체 토큰 쌍 점수 행렬의 크기를 결정하는 값이다.

</details>

- 쿼리•키 행렬곱으로 모든 토큰 쌍 유사도를 계산한다.
- **스케일링**으로 점수 분산과 소프트맥스를 안정화한다.
- **시퀀스 길이**에 따라 점수 행렬은 O(N²)로 증가한다.
- 계산식은 $Attention(Q,K,V)=softmax(QKᵀ/√d_k)V$이다.

#### 한줄 요약
- **√d_k 스케일링**으로 고차원 점수 포화를 방지한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **패딩 마스크(Padding Mask)**: 길이를 맞추기 위해 추가한 무효 토큰의 점수를 차단하여 참조되지 않게 하는 행렬이다.
- **소프트맥스(Softmax)**: 행별 점수를 합이 1인 어텐션 가중치로 정규화하는 함수이다.

</details>

```text
[Q•K•V]──[점수 행렬]──[스케일•패딩 마스크]
                              │
                       [소프트맥스]──[출력 결합]
```

선의 의미: 입력•점수•보정•정규화•결합 책임의 정적 연결을 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| Q•K•V | 어텐션의 조회•비교•전달 입력 벡터 |
| 점수 행렬 | QKᵀ 내적으로 토큰 쌍 유사도 산출 |
| 스케일•패딩 마스크 | **스케일링**과 **패딩 마스크** 적용 |
| 소프트맥스 | **소프트맥스**로 가중치 정규화 |
| 출력 결합 | 밸류 가중합 산출 |

#### 한줄 요약
- 점수•스케일•마스크•정규화•결합 단계로 구성한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **점수 행렬**: $QK^T$ 행렬곱으로 모든 쿼리와 키 쌍의 원시 유사도를 나타낸 행렬이다.
- **문맥 벡터**: 정규화된 어텐션 가중치와 V를 곱하여 관련 정보를 결합한 출력 벡터이다.
- **Q•K•V 행렬 입력**: 쿼리•키•밸류 벡터를 행렬 연산이 가능한 형태로 준비하는 절차이다.
- **QKᵀ 원시 점수 계산**: 쿼리와 키 행렬을 곱해 모든 토큰 쌍의 원시 유사도를 만드는 절차이다.
- **√d_k 스케일•마스크 적용**: 원시 점수를 키 차원의 제곱근으로 나누고 무효 참조를 차단하는 절차이다.
- **소프트맥스 가중치 산출**: 보정한 행별 점수를 합이 1인 참조 가중치로 정규화하는 절차이다.
- **가중치•V 문맥 결합**: 정규화 가중치와 밸류를 곱해 문맥 벡터를 만드는 절차이다.

</details>

```text
입력 벡터
   │ 1. Q•K•V 행렬 입력
   ▼
내적 연산기
   │ 2. QKᵀ 원시 점수 계산
   ▼
필터
   │ 3. √d_k 스케일•마스크 적용
   ▼
소프트맥스
   │ 4. 소프트맥스 가중치 산출
   ▼
출력 결합기
   │ 5. 가중치•V 문맥 결합
   │ 문맥 벡터 출력
   ▼
출력
```

1. **Q•K•V 행렬 입력**: 조회•비교•전달용 토큰 표현을 준비한다.
2. **QKᵀ 원시 점수 계산**: **점수 행렬**을 생성한다.
3. **√d_k 스케일•마스크 적용**: **스케일링**과 **패딩 마스크**를 적용한다.
4. **소프트맥스 가중치 산출**: **소프트맥스**로 참조 비율을 정규화한다.
5. **가중치•V 문맥 결합**: 정규화 가중치와 V의 행렬곱으로 **문맥 벡터**를 출력한다.

#### 한줄 요약
- **스케일•마스크•소프트맥스** 후 V 문맥 결합이 핵심이다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **가산 어텐션(Additive Attention)**: 쿼리와 키를 작은 신경망에 입력하여 관계 점수 함수를 학습하는 방식이다.
- **비스케일드 닷 프로덕트 어텐션(Unscaled Dot-Product Attention)**: 쿼리와 키의 원시 내적을 보정 없이 정규화하여 고차원에서 포화되기 쉬운 방식이다.

</details>

| 비교 기준 | Scaled Dot-Product | Additive | Unscaled Dot-Product |
|:---|:---|:---|:---|
| 적용 기준 | 고차원 행렬의 병렬 어텐션 | 작은 차원의 복잡 관계 학습 | 낮은 차원의 단순 내적 |
| 핵심 특징 | 내적값을 √d_k로 보정 | 신경망으로 점수 함수 학습 | 원시 내적값 직접 정규화 |
| 한계 | O(N²) 점수 행렬 | 추가 매개변수•연산 비용 | 고차원 **소프트맥스 포화** |

#### 한줄 요약
- 고차원 내적은 **Scaled Dot-Product Attention**, 작은 복잡 관계는 **Additive Attention**이 적합하다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **블록 계산**: 전체 점수 행렬을 한꺼번에 저장하지 않고 작은 타일 단위로 계산해 GPU 메모리 접근을 줄이는 방식이다.
- **자료형(Data Type, dtype)**: 텐서 원소의 정밀도와 표현 범위를 정하는 수치 저장 형식이다.
- **안정 소프트맥스**: 각 행의 최댓값을 먼저 빼고 지수 함수를 적용하여 오버플로를 방지하는 계산 방식이다.
- **GPU(Graphics Processing Unit)**: 어텐션 행렬 연산을 병렬 처리하는 장치이다.
- **NaN(Not a Number)**: 정의되지 않은 수치 연산의 결과를 나타내는 값이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 장문의 O(N²) 중간 행렬 | **블록 계산** 적용 | **GPU** 메모리 접근•저장 절감 |
| 저정밀도에서 마스크•소프트맥스 오버플로 | **안정 소프트맥스**와 **자료형**별 마스크값 시험 | **NaN**과 무효 토큰 참조 방지 |
| 잘못된 키 차원 기준의 스케일 불일치 | 헤드별 **키 차원**과 √d_k 산출 검증 | 점수 분산•학습 경사 안정화 |

#### 한줄 요약
- **블록 계산•안정 소프트맥스**로 장문 수치 안정화가 핵심이다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **$\sqrt{d_k}$ 스케일링**: 고차원 내적 점수의 분산을 일정하게 유지하여 소프트맥스와 학습 기울기를 안정화하는 연산이다.
- **장문 블록 계산**: 시퀀스가 길 때 점수 행렬을 부분 계산하여 메모리 사용과 데이터 이동을 줄이는 방식이다.

</details>

- 고차원 어텐션은 **$\sqrt{d_k}$ 스케일링**, 장문은 **블록 계산**을 적용한다.

#### 한줄 요약
- **키 차원**과 문맥 길이에 따라 스케일링•블록 계산을 적용한다.
