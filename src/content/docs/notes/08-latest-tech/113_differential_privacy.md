## 미리 알고가기

- **차등 프라이버시(Differential Privacy, DP, 디피)**: 영문 머리글자를 딴 수학적 보호 모델로, 개인 한 명의 포함 여부가 출력에 미치는 영향을 제한
- **프라이버시 예산 $\epsilon$(Epsilon, 엡실론)**: 그리스 문자로 출력 분포의 구별 가능성 한도를 표기
- **실패 확률 $\delta$(Delta, 델타)**: 그리스 문자로 순수 DP 경계를 벗어날 허용 확률을 표기



## Ⅰ. 개요

- **정의/개념**: 한 개인의 포함 여부에 따른 출력 분포 차이를 제한하는 개인정보보호 기법이다
- **기존 한계**: 익명화된 결과도 반복 결합하면 개인의 데이터 참여 여부를 추론할 수 있다
- **배경/필요성**: 통계·학습 결과에서 개인의 영향을 수학적으로 제한하기 위함이다

### 쉽게 이해하기 (학습용)

- 한 사람이 데이터에 포함됐는지 결과만 보고 구별하기 어렵도록 개인의 영향을 제한하고 잡음을 더합니다.

## Ⅱ. 특징

- 이웃 데이터셋과 기여 한도가 실제 보호 단위를 정한다.
- 민감도와 $\epsilon,\delta$에 맞춰 무작위 잡음을 보정한다.
- 반복 공개의 누적 프라이버시 손실을 회계한다.

### 쉽게 이해하기 (학습용)

- 같은 데이터를 반복 분석할수록 프라이버시 손실이 합성되므로 예산 장부에 누적해 관리합니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 개인 단위·인접성 | 보호할 개인과 한 개인 차이의 이웃 데이터셋 관계 |
| 프라이버시 매개변수 | 출력 분포 차이·예외 확률 $\epsilon,\delta$ |
| 민감도·클리핑 | 한 개인이 질의 결과나 학습 업데이트에 미칠 최대 영향 |
| 잡음 메커니즘 | 민감도와 매개변수에 맞춘 라플라스·가우시안 등 무작위화 |
| 프라이버시 회계기 | 표본추출·반복·여러 공개의 합성된 누적 손실 계산기 |

### 쉽게 이해하기 (학습용)

- 보호 단위·인접성·예산·민감도·잡음·누적 회계기를 함께 정해야 합니다.

## Ⅳ. 원리 및 절차 흐름도

```text
정의설정
  ↓
영향제한
  ↓
잡음적용
  ↓
손실합성
  ↓
결과판정
```

| 절차 | 설명 |
|:---|:---|
| 정의설정 | 보호 단위와 데이터셋 인접성을 정함 |
| 영향제한 | 개인별 민감도와 노름을 클리핑함 |
| 잡음적용 | 목표 ε·δ에 맞춰 잡음을 추가함 |
| 손실합성 | 반복 실행에 따른 손실을 계산함 |
| 결과판정 | 예산 한도 내에서만 공개함 |

- 예산 장부를 관리해 한도를 넘으면 결과를 숨김

### 쉽게 이해하기 (학습용)

- 개인 영향을 제한해 잡음을 넣고 반복 사용량을 합산한 뒤 예산 안에서만 결과를 공개합니다.

## Ⅴ. 종류 및 비교

| 판단 기준 | 중앙 DP | 로컬 DP |
|:---|:---|:---|
| 적용 기준 | 신뢰할 중앙 수집자 존재 | 중앙 수집자를 신뢰하지 않음 |
| 핵심 특징 | 수집 후 중앙에서 잡음 추가 | 전송 전 사용자 값 무작위화 |
| 한계 | 원자료 유출 위험 | 큰 집계 오차 |

> 요약: 데이터 처리 주체와 잡음 적용 위치에 따라 선택한다

### 쉽게 이해하기 (학습용)

- 중앙 방식은 신뢰 관리자가 잡음을 넣고 로컬 방식은 사용자가 전송 전에 직접 무작위화합니다.

## Ⅵ. 실무 사례

- 개인별 기울기를 클리핑해 예산 안에서 학습한다.
- 로컬 무작위화로 서버에서 원본 응답을 숨긴다.

### 쉽게 이해하기 (학습용)

- 학습 반복과 통계 공개마다 쌓이는 프라이버시 손실을 정한 한도 안에서 제어합니다.

## Ⅶ. 결론

- 단위와 신뢰 경계를 설정하고 예산 범위 내에서 공개함

### 쉽게 이해하기 (학습용)

- 누가 보호 대상이고 서버를 얼마나 신뢰하는지 정한 뒤 개인 참여가 결과에 미치는 정도를 수치로 관리합니다.
