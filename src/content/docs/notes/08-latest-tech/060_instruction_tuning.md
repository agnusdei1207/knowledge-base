## 미리 알고가기

- **지시어 튜닝 (Instruction Tuning)**: 지시문·응답 쌍으로 명령 수행을 학습함
- **미적용 태스크 (Held-out Task)**: 학습에서 제외해 일반화를 평가하는 작업임
- **합성 데이터 (Synthetic Data)**: 모델이 생성한 학습용 표본임
- **정렬 (Alignment)**: 출력을 인간 선호·안전 기준에 맞춤


## Ⅰ. 개요

- **정의/개념**: 지시문·응답 쌍으로 명령 수행을 지도 학습
- **배경/필요성**: 다양한 요청 형식과 출력 제약 준수

### 쉽게 이해하기 (학습용)
- 다양한 과업의 지시와 모범 응답으로 질문 의도와 답안 형식을 따르도록 훈련합니다.

## Ⅱ. 특징

- 다양한 과업 혼합이 새 지시로의 일반화를 넓힌다.
- 대화 템플릿이 역할·입력·응답 경계를 학습시킨다.
- 미학습 과업 성능은 데이터 다양성과 오염에 민감하다.
- 지시 준수가 사실성·안전성을 자동 보장하지 않는다.

### 쉽게 이해하기 (학습용)
- 여러 문제 형식을 연습하면 지시 준수는 좋아지지만 답의 사실성과 안전성은 별도로 검증해야 합니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 데이터 스키마 | 지시·입력·응답 관리 |
| 태스크 혼합기 | 과업별 비율 조절 |
| 템플릿 | 대화 역할·종료 정의 |
| 지도 학습기 | 응답 손실 기반 갱신 |
| 평가 세트 | 과업 준수·안전 측정 |
```text
기반모델
├─ 자료형식
├─ 과업혼합
├─ 학습템플릿
└─ 격리평가
```

### 쉽게 이해하기 (학습용)

- 지시·입력·응답 형식을 통일하고 과업 비율을 조정하며 평가 자료를 격리합니다.

## Ⅳ. 원리 및 절차 흐름도

```text
정의
↓
설계
↓
차단
↓
학습
↓
평가
```

| 절차 | 설명 |
|:---|:---|
| 행동정의 | 기준 및 표준 설정 |
| 자료설계 | 지시·입력·응답 설계 |
| 누출차단 | 중복·오염 제거 |
| 템플학습 | 역할 기반 학습 |
| 분리평가 | 성과·안전 분리 평가 |
### 쉽게 이해하기 (학습용)

- 학습·평가 자료의 중복을 제거하고 미학습 과업으로 일반화를 검증합니다.

## Ⅴ. 종류 및 비교

| 기준 | 사전학습 | 지시어 튜닝 | 안전 정렬 |
|:---|:---|:---|:---|
| 학습 신호 | 다음 토큰 | 목표 응답 | 선호·안전 예시 |
| 적용 환경 | 범용 표현 | 형식 준수 | 선호·안전 조정 |
| 주요 위험 | 지시 미이행 | 템플릿 편향 | 과도한 거절 |

> 요약: 학습 목적에 따라 사전학습·튜닝·정렬을 구분함
### 쉽게 이해하기 (학습용)

- 사전학습·지시 튜닝·선호 정렬은 학습 신호와 바꾸려는 행동이 다릅니다.

## Ⅵ. 실무 사례

- 문의 유형: 문의 유형 분류 및 비식별화된 응답 활용
- 합성 데이터: 생성 오류 방지를 위한 다중 검증 수행
- 오염 탐지: 평가 문항과 유사한 표본 사전 제거

### 쉽게 이해하기 (학습용)
- 민감정보를 제거한 지시 데이터로 학습하고 평가 문항과 겹치는 표본은 사전에 제외합니다.

## Ⅶ. 결론
- 지시 튜닝은 명령 이행력과 안전성을 분리 검증한다.

### 쉽게 이해하기 (학습용)
- 지시 수행 능력이 높아져도 사실성과 안전성이 함께 좋아졌다고 가정해서는 안 됩니다.
