## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **멀티모달 RAG(Multimodal Retrieval-Augmented Generation)**: 텍스트, 이미지, 표, 도면 등 다양한 형태의 데이터를 동시 검색하여 답변의 근거를 생성하는 기술
- **원본 좌표(Original Coordinate)**: 문단, 표의 셀, 이미지 영역이 원본 문서 페이지에서 점유하는 위치 정보

</details>

- 정의: 멀티모달(텍스트, 이미지, 표 등) 데이터를 검색하여 시각 정보와 텍스트 문맥을 고려한 정교한 근거 기반 답변을 생성하는 방식
- 배경: 텍스트 전용 RAG의 한계인 시각 정보(표, 도면) 해석 불가능 및 근거 위치 보존 한계 극복 필요

#### 한줄 요약
- 텍스트•시각 정보의 원본 위치를 통합 활용하는 근거 기반 생성 기술 구현

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **모달별 표현 색인(Modal Representation Index)**: 각 모달의 특성과 원본 문서 내 위치 정보를 결합하여 검색 효율을 극대화한 색인
- **교차 모달 검색(Cross-modal Retrieval)**: 텍스트 질의로 이미지/표를 검색하거나 그 반대의 경우를 지원하는 모달 간 관련 자료 검색 방식

</details>

- **모달별 표현 색인**: 데이터 모달(Text, Image, Table)별 고유 특성과 원본 좌표를 연동하여 검색 정확도 제고
- **교차 모달 검색**: 공동 벡터 공간(Shared Vector Space) 및 순위 결합 기반의 다중 형태 데이터 검색
- **근거 연결성**: 생성된 답변의 주장과 원본 데이터의 실제 좌표/영역 인용을 연결하여 신뢰성 보장

#### 한줄 요약
- 모달별 색인 및 좌표 기반의 교차 모달 검색 및 인용 원칙 준수

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **모달 파싱(Modal Parsing)**: 문서 내 모달별(텍스트, 표, 이미지) 원본 위치를 분리 및 계층적으로 구조화하는 처리
- **시각언어모델(VLM, Vision-Language Model)**: 시각 자료와 언어 질의를 공동으로 해석하여 관련성을 매핑하는 모델
- **근거 연결부(Evidence Linker)**: 생성된 답변 주장과 원본 데이터의 물리적 영역(문단, 셀, 영역)을 인용 연결하는 모듈

</details>

```text
                           [모달 색인]
                          /           \
                   [모달 정렬기]    [검색•융합기]
                          |              |
                    [모달 추출기]    [근거 연결부]
```

선의 의미: 모달 색인은 추출•정렬된 표현과 검색 인터페이스를 지원하며, 근거 연결부는 검색 결과를 원본 영역과 매핑.

| 구성요소 | 책임 |
|:---|:---|
| 모달 추출기 | 문서 요소와 **원본 좌표** 분리 |
| 모달 정렬기 | VLM 기반 관련 표현 매핑 |
| 모달 색인 | 임베딩 및 영역 메타데이터 저장 |
| 검색•융합기 | 순위 결합 및 문맥 구성 |
| 근거 연결부 | 주장과 원본 인용 연결 |

#### 한줄 요약
- 추출•정렬•색인•융합•연결을 통한 통합 검색 체계 구현

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **연결 메타데이터 (Connection Metadata)**: 모달 식별자•좌표 기반 원본 위치 추적 정보
- **융합 문맥 (Fused Context)**: 답변 생성을 위해 모달별 근거를 결합한 입력 데이터

</details>

```text
원본 문서
   │ 1. 모달 요소•좌표 추출
   ▼
모달 처리기
   │ 2. 정렬 표현 색인
   ▼
모달 색인
   │
사용자 ── 질의 ──▶ 검색•생성기
                      │ 3. 교차 모달 후보 검색
                      ◀── 모달 색인(후보•영역)
                      │ 4. 융합 문맥 구성
                      │ 5. 근거 기반 답변 생성
사용자 ◀── 답변•근거 위치 ──┘
```

**동작 원리**
1. **추출**: 문단•이미지•표 셀 영역 분리
2. **색인**: 식별자 기반 관련 모달 연결 저장
3. **검색**: 질의 관련 시각•텍스트 근거 탐색
4. **구성**: 후보와 원본 영역 결합
5. **생성**: 답변 주장과 원본 영역 인용 연결

#### 한줄 요약
- 다중 모달 검색을 통한 근거 기반 질의응답 프로세스 적용
## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **텍스트 변환 (Text Conversion)**: 시각 자료를 설명문으로 전환하여 검색
- **공동 임베딩 (Joint Embedding)**: 의미 기반 벡터 공간 매핑
- **다중 표현 검색 (Multi-representation Retrieval)**: 모달별 표현•원본 연결 유지

</details>

| 검색 방식 | 텍스트 변환 | 공동 임베딩 | 다중 표현 |
|:---|:---|:---|:---|
| 주요 적용 | 시각 정보 최소 | 의미 검색 중심 | 세부 인용 필수 |
| 핵심 특징 | 설명문 변환 색인 | 공동 벡터 공간 | 모달별 표현•좌표 연결 |
| 한계점 | 시각 세부 손실 | 근거 단위 제약 | 복잡도 증가 |

#### 한줄 요약
- 검색 목적 및 정밀도 요구사항에 따른 방식 선택

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **시각 구조 손실 (Visual Structure Loss)**: 표 셀/도면 배치 정보 소실
- **교차 모달 정렬 오류 (Alignment Error)**: 관련 없는 모달 간 근거 연결
- **주장•근거 불일치 (Hallucination)**: 주장 뒷받침 근거 부재

</details>

| 문제 | 대책 | 기대 효과 |
|:---|:---|:---|
| 시각 구조 손실 | 모달별 파싱 및 좌표 보존 | 시각 관계 복원 |
| 정렬 오류 | 캡션•식별자 기반 정렬 | 부적절 근거 결합 방지 |
| 주장•근거 불일치 | 주장별 영역 인용 연결 | 답변 재현성 확보 |

#### 한줄 요약
- 원본 영역 보존 및 검증 기반 신뢰성 있는 답변 체계 구현
## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **검색 표현 (Search Representation)**: 검색 점수 계산을 위한 모달 변환 데이터
- **영역 인용 (Region Citation)**: 답변 근거를 원본 페이지의 좌표 단위로 제시

</details>

- 시각 정보 비중 및 인용 단위에 따른 검색 표현 최적화
- 원본 영역 검증 체계 기반의 답변 정확도 및 신뢰성 확보

#### 한줄 요약
- 원본 좌표 기반 근거 탐색 및 인용 체계 적용
