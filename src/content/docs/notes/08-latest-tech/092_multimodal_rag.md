## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **멀티모달 검색 증강 생성(Multimodal Retrieval-Augmented Generation, Multimodal RAG)**: 텍스트•이미지•표•도면을 함께 검색해 근거 답변을 생성하는 방식이다.
- **원본 좌표**: 문단•표 셀•이미지 영역이 원문 페이지에서 차지하는 위치 정보이다.

</details>
- 정의/개념: **멀티모달 RAG**는 텍스트•이미지•표를 검색해 근거 답변을 생성하는 방식임.
- 배경/필요성: 텍스트 변환만으로는 표•도면의 **시각 관계•원본 좌표** 보존할 수 없음.
#### 한줄 요약
- 글•그림•표의 원본 위치를 함께 찾아 답변 근거로 활용한다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **모달별 표현 색인**: 텍스트•이미지•표의 특성에 맞는 표현과 원본 위치를 함께 저장한 검색 색인이다.
- **교차 모달 검색**: 한 모달의 질의나 표현으로 다른 모달의 관련 자료를 찾는 방식이다.

</details>
- 텍스트•이미지•표의 **모달별 표현 색인**이 핵심임.
- 공동 공간•순위 결합 기반 **교차 모달 검색**이 핵심임.
- 답변 주장과 **원본 영역•좌표**의 근거를 연결함.
#### 한줄 요약
- 글•그림 색인을 따로 만들고 질문에 맞는 후보를 모은 뒤 실제 원본과 대조한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **모달 파싱**: 문서에서 텍스트•이미지•표와 원본 위치를 분리해 구조화하는 처리로 정의된다.
- **시각언어모델(Vision-Language Model, VLM)**: 시각 자료와 언어 질의를 공동으로 해석해 관련 표현을 연결하는 모델이다.
- **근거 연결부**: 답변의 각 주장과 원본 문단•표 셀•이미지 영역을 연결하는 개념로 정의된다.

</details>
```text
                         [모달 색인]
                        /           \
                 [모달 정렬기]    [검색•융합기]
                        |              |
                  [모달 추출기]    [근거 연결부]
```

선의 의미: 모달 색인은 추출•정렬된 모달 표현과 검색•융합 인터페이스를 함께 보유하고, 모달 추출기는 정렬기의 원본 좌표를 제공하며, 근거 연결부는 검색 결과를 원본 영역과 연결한다.

| 구성요소 | 책임 |
|:---|:---|
| 모달 추출기 | 문서의 모달 요소와 **원본 좌표** 분리 |
| 모달 정렬기 | **VLM•캡션•식별자**로 관련 표현 연결 |
| 모달 색인 | 모달별 임베딩과 **영역 메타데이터** 저장 |
| 검색•융합기 | 모달별 후보의 **순위 융합•문맥 구성** |
| 근거 연결부 | 답변 주장과 원본 영역의 **인용** 연결 |


#### 한줄 요약
- 추출기•정렬기•모달 색인•검색 융합기•근거 연결부가 역할을 나눕니다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **연결 메타데이터**: 서로 관련된 모달 요소와 원본 위치를 추적하도록 식별자•좌표를 기록한 정보로 정의된다.
- **융합 문맥**: 여러 모달에서 검색한 근거를 답변 생성에 사용할 수 있도록 결합한 입력을 말한다.

</details>
```text
원본 문서
   │ 1. 모달 요소•원본 좌표 추출
   ▼
모달 처리기
   │ 2. 정렬 표현 색인
   ▼
모달 색인

사용자 ── 질의 ──▶ 검색•생성기
                       │ 3. 교차 모달 후보 검색
                       ◀── 모달 색인: 모달별 후보•원본 영역
                       │ 4. 융합 문맥 구성
                       │ 5. 근거 기반 답변 생성
사용자 ◀── 답변•주장별 근거 위치 ──┘
```

**동작 원리**

1. **모달 요소•원본 좌표 추출**: 문단•이미지•표 셀과 영역을 분리함.
2. **정렬 표현 색인**: 캡션•식별자로 관련 모달 연결을 저장함.
3. **교차 모달 후보 검색**: 질의와 관련된 텍스트•시각 근거를 탐색함.
4. **융합 문맥 구성**: 모달별 후보와 원본 영역을 결합함.
5. **근거 기반 답변 생성**: 주장과 문단•셀•영역 인용을 연결함.
#### 한줄 요약
- 질문이 시각 세부를 요구하면 요약에 그치지 않고 원본 영역을 다시 불러 답과 대조한다.
## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **텍스트 변환 색인**: 시각 자료를 설명문으로 바꾼 뒤 텍스트 검색 대상으로 저장하는 방식로 정의된다.
- **공동 임베딩**: 서로 다른 모달의 관련 표현을 같은 벡터 공간에 배치하는 표현 방식로 정의된다.
- **다중 표현 검색**: 모달별 요약•임베딩과 원본 영역을 함께 유지하며 후보를 검색하는 방식을 말한다.

</details>
| 검색 방식 | 텍스트 변환 | 공동 임베딩 | 다중 표현 |
|:---|:---|:---|:---|
| 적용 기준 | **시각 정보 최소** 시 | **의미 검색** 중심 시 | **세부 인용** 필요 시 |
| 핵심 특징 | **설명문 변환 색인** | **공동 벡터 공간** 검색 | 모달별 **표현•원본 연결** |
| 한계 | **시각 세부 손실** | 이미지 단위 **근거 한계** | **색인•융합 복잡도** 증가 |

> 요약: **모달별 근거 연결**을 통한 답변 정확도 향상이 핵심이다.
#### 한줄 요약
- 시각 자료를 글로 바꾸는 방식, 공동 공간에서 찾는 방식, 여러 표현과 원본을 함께 쓰는 방식의 차이이다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **시각 구조 손실**: 표의 셀 관계나 도면의 배치가 텍스트 변환 과정에서 사라지는 문제을 의미한다.
- **교차 모달 정렬 오류**: 서로 관련 없는 텍스트와 이미지•표가 같은 근거로 연결되는 문제을 말한다.
- **주장•근거 불일치**: 답변의 주장이 인용한 원본 영역의 내용으로 뒷받침되지 않는 문제을 말한다.

</details>
| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **표•도면 구조 손실** | 모달별 파싱과 **원본 좌표** 보존 | **시각 관계** 복원 |
| **교차 모달 정렬 오류** | 캡션•식별자 기반 **모달 정렬** | 비관련 **근거 결합** 감소 |
| **주장•근거 불일치** | 주장별 **문단•셀•영역 인용** | 답변 근거의 **재현성** 확보 |
#### 한줄 요약
- 도면 부품이나 표의 수치를 답할 때 실제 페이지와 영역을 함께 제시할 수 있습니다.
## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **검색 표현**: 각 모달을 검색 점수 계산에 사용할 수 있도록 변환한 텍스트나 벡터을 말한다.
- **영역 인용**: 답변 근거를 원본 페이지의 문단•셀•이미지 좌표 단위로 제시하는 방식이다.

</details>
- 시각 정보 비중•인용 단위에 따라 **검색 표현**을 선택하고 **원본 영역**을 검증함.
#### 한줄 요약
- 글만으로 부족한 질문은 그림과 표를 검색하되 답이 원본 어디에서 나왔는지 확인해야 한다.
