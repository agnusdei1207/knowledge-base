## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **멀티모달 RAG(Multimodal RAG)**: 텍스트•이미지•표•도면을 검색해 근거 답변을 생성한다.
- **원본 좌표(Original Coordinate)**: 문단•표 셀•이미지 영역의 원본 위치이다.

</details>

- 정의/개념: 텍스트•시각 정보를 통합 검색하는 **멀티모달 RAG**
- 배경/필요성: 문서를 텍스트로 변환해 색인하는 RAG은 **시각 구조•원본 위치** 보존 불가로 근거 확인을 사람이 원본에서 다시 하는 비용이 남으므로, 이미지•표를 그대로 임베딩하고 좌표를 함께 저장하는 색인 계층을 두어 검색에서 인용까지 연결

#### 한줄 요약

- 시각•텍스트의 **통합 검색•원본 좌표 인용**

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **모달별 표현 색인(Modal Representation Index)**: 모달 특징과 원본 위치를 결합한 색인이다.
- **교차 모달 검색(Cross-modal Retrieval)**: 질의와 다른 모달의 관련 자료를 탐색한다.
- **근거 연결성(Evidence Connectivity)**: 답변과 원본 영역을 인용으로 연결하는 성질이다.

</details>

- 모달 특성과 원본 위치를 결합한 **모달별 표현 색인**
- 공동 의미 공간을 활용한 **교차 모달 검색**
- 답변 주장과 원본 영역을 연결한 **근거 연결성**

#### 한줄 요약

- **모달별 색인•교차 검색•영역 인용** 결합

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **모달 파싱(Modal Parsing)**: 텍스트•표•이미지와 원본 위치를 구조화한다.
- **시각언어모델(Vision-Language Model, VLM)**: 시각 자료와 언어 질의를 공동 해석한다.
- **근거 연결부(Evidence Linker)**: 답변 주장과 원본 영역을 인용으로 연결한다.

</details>

```text
                           [모달 색인]
                          /           \
                   [모달 정렬기]    [검색•융합기]
                          |              |
                    [모달 추출기]    [근거 연결부]
```

선의 의미: 추출•정렬•색인•검색•근거 연결 요소의 정적 관계이다.

| 구성요소 | 책임 |
|:---|:---|
| 모달 추출기 | 문서 요소와 **원본 좌표** 분리 |
| 모달 정렬기 | **VLM 기반 관련 표현** 매핑 |
| 모달 색인 | 임베딩•**영역 메타데이터** 저장 |
| 검색•융합기 | **순위 결합•융합 문맥** 구성 |
| 근거 연결부 | 주장과 **원본 영역 인용** 연결 |

#### 한줄 요약
- **추출•정렬•색인•융합•근거 연결** 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **연결 메타데이터(Connection Metadata)**: 모달 식별자•좌표 기반 위치 추적 정보이다.
- **융합 문맥(Fused Context)**: 모달별 근거를 결합한 생성 입력이다.

</details>

```text
원본 문서
   │ 1. 모달 요소•좌표 추출
   ▼
모달 처리기
   │ 2. 정렬 표현 색인
   ▼
모달 색인
   │
사용자 ── 질의 ──▶ 검색•생성기
                      │ 3. 교차 모달 후보 검색
                      ◀── 모달 색인(후보•영역)
                      │ 4. 융합 문맥 구성
                      │ 5. 근거 기반 답변 생성
사용자 ◀── 답변•근거 위치 ──┘
```

### 동작 원리

1. **모달 요소•좌표 추출**: 문단•이미지•표 셀 분리
2. **정렬 표현 색인**: 관련 모달과 식별자 연결
3. **교차 모달 후보 검색**: 시각•텍스트 근거 탐색
4. **융합 문맥 구성**: 후보와 원본 영역 결합
5. **근거 기반 답변 생성**: 주장과 영역 인용 연결

#### 한줄 요약
- **좌표 추출•표현 색인•교차 검색•문맥•답변** 처리

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **텍스트 변환(Text Conversion)**: 시각 자료를 설명문으로 바꿔 검색한다.
- **공동 임베딩(Joint Embedding)**: 여러 모달을 공동 의미 공간에 매핑한다.
- **다중 표현 검색(Multi-representation Retrieval)**: 모달별 표현과 원본 연결을 유지한다.

</details>

| 검색 방식 | 텍스트 변환 | 공동 임베딩 | 다중 표현 |
|:---|:---|:---|:---|
| 적용 기준 | **시각 정보 최소** | **의미 검색 중심** | **세부 영역 인용** |
| 핵심 특징 | **설명문 변환 색인** | **공동 벡터 공간** | **모달 표현•좌표 연결** |
| 한계 | **시각 세부 손실** | **근거 단위 제약** | **구현 복잡도 증가** |

#### 한줄 요약
- **시각 세부•의미 검색•영역 인용** 대상 따라 방식 구분

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **시각 구조 손실(Visual Structure Loss)**: 표 셀•도면 배치가 소실되는 문제이다.
- **교차 모달 정렬 오류(Alignment Error)**: 관련 없는 모달 근거가 연결되는 문제이다.
- **주장•근거 불일치(Claim-evidence Mismatch)**: 주장을 지지하는 근거가 없는 문제이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 표•도면의 **시각 구조 손실** | 모달별 파싱•좌표 보존 | **시각 관계** 복원 |
| 교차 모달 정렬 오류 | 캡션•식별자 기반 정렬 | 부적절한 **근거 결합 방지** |
| 주장•근거 불일치 | 주장별 영역 인용 연결 | **답변 재현성** 확보 |

#### 한줄 요약
- **시각 구조•모달 정렬•주장별 영역 인용** 검증

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **검색 표현(Search Representation)**: 검색 점수 계산을 위한 모달 변환 데이터이다.
- **영역 인용(Region Citation)**: 답변 근거를 원본 좌표 단위로 제시한다.

</details>

- 시각 정보가 적으면 **텍스트 변환**, 의미 검색은 **공동 임베딩** 선택
- 세부 영역 인용은 **다중 표현 검색•원본 좌표 보존** 적용

#### 한줄 요약
- **시각 정보 비중•인용 단위** 대상 따라 검색 표현 결정
