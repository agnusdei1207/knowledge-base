## 미리 알고가기

- **확산모델**: 깨끗한 그림에 잡음을 섞었다가 거꾸로 지우는 연습을 통해, 잡음에서 새 그림을 만드는 AI임
- **구성 요소**: 잡음을 얼마나 지울지 정하는 규칙과 잡음 제거기가 함께 결과를 만듦
- **활용 범위**: 그림뿐 아니라 소리·영상·분자 구조처럼 새 형태를 만들어야 하는 곳에도 쓸 수 있음



## Ⅰ. 개요

- 정의/개념: 잡음의 역전이를 반복해 새 표본을 만드는 모델
- 기존 한계: 기존 생성 모델은 고차원 데이터 분포를 한 번에 학습하는 과정이 불안정하거나 생성 품질과 다양성을 함께 확보하기 어렵다.

### 쉽게 이해하기 (학습용)
- 학습 때는 단계별 잡음을 예측하고 생성 때는 무작위 잡음에서 시작해 이를 반복해서 제거합니다.

## Ⅱ. 특징

- 순방향은 스케줄에 따라 신호와 잡음을 혼합한다.
- 잡음 제거기는 시점별 잡음이나 갱신값을 예측한다.
- 역방향은 무작위 잡음에서 새 표본을 추출한다.
- 샘플러·단계 수가 품질·다양성·지연을 좌우한다.
- 잠재 확산은 압축 표현 공간에서 연산량을 줄인다.

### 쉽게 이해하기 (학습용)
- 흐려진 원본을 복원하는 것이 아니라 학습한 잡음 제거 규칙으로 새로운 표본을 만듭니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 잡음 스케줄 | 단계별 신호 잡음 비율 정의 |
| 잡음 상태 | 시점별 혼합된 학습 입력 |
| 잡음 제거 모델 | 역방향 갱신값 예측 신경망 |
| 역전이 규칙 | 모델 예측 평균 변동 변환 |
| 샘플러 | 잡음에서 표본 추출 실행 |

```text
[잡음 스케줄] ── 혼합비 → [시점별 잡음 상태]
                              ↓ 상태·시점
                       [잡음 제거 모델]
                              ↓ 예측
                       [역전이 규칙] → [샘플러]
```

### 쉽게 이해하기 (학습용)
- 잡음 스케줄, 시점별 상태, 잡음 제거 모델, 역전이 규칙과 샘플러가 함께 작동합니다.

## Ⅳ. 원리 및 절차 흐름도

```text
[학습]
데이터 표본 → 시점·잡음 추출 → 순방향 잡음 상태 생성
                                      ↓
                         잡음 제거 모델 예측 → 손실 계산·학습

[생성]
무작위 잡음 → 시점별 모델 예측 → 샘플러의 역방향 상태 갱신
                                      ↑                 │
                                      └── 종료 전 반복 ─┘
                                                        ↓
                                                    새 표본
```

| 절차 | 설명 |
|:---|:---|
| 스케줄 정의 | 신호 잡음 비율 결정함 |
| 순방향 생성 | 시점 잡음 적용 상태 생성 |
| 예측 학습 | 잡음 상태 오차 학습함 |
| 생성 초기화 | 무작위 잡음 첫 설정 |
| 표본 추출 | 샘플러 상태 반복 갱신 |
| 성능 평가 | 품질 다형성 지연 측정 |

### 쉽게 이해하기 (학습용)
- 잡음이 섞인 표본에서 제거 방향을 배우고 생성 때 새 잡음에 그 방향을 반복 적용합니다.

## Ⅴ. 종류 및 비교

| 판단 기준 | DDPM | DDIM |
|:---|:---|:---|
| 상태 전이 | 확률적 역전이 | 결정론적 갱신 |
| 적용 기준 | 다양성 확보 필요 시 | 생성 속도 향상 필요 시 |
| 주요 위험 | 느린 생성 지연 | 세부 품질 저하 위험 |

> 요약: 잡음 단계적 제거를 통해 표본을 생성함

### 쉽게 이해하기 (학습용)
- 확률적 경로와 결정론적 경로 중 다양성·속도·재현 요구에 맞는 샘플러를 선택합니다.

## Ⅵ. 실무 사례

- 이미지 서비스는 샘플러·단계별 품질과 지연을 비교한다.

### 쉽게 이해하기 (학습용)
- 제거 단계를 줄이면 빨라지지만 품질이 달라질 수 있어 용도별 샘플러와 단계 수를 검증해야 합니다.

## Ⅶ. 결론

- 고품질 표본을 안정적으로 생성하기 위해 **생성 품질·다양성·샘플링 단계·지연·안전 필터**를 검토하고, 서비스 요구에 맞는 확산 모델 샘플러와 단계 수를 선택해야 한다.

### 쉽게 이해하기 (학습용)
- 학습한 잡음 제거기뿐 아니라 실제 생성의 샘플러와 단계 수도 결과와 속도를 좌우합니다.
