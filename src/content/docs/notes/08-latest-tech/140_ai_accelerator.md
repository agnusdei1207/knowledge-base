## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **인공지능(Artificial Intelligence, AI)**: 학습•추론으로 인간의 지능적 작업을 수행하는 기술이다.
- **AI 가속기(AI Accelerator)**: 인공지능 모델의 학습 및 추론 연산(주로 행렬 곱셈)을 범용 CPU보다 압도적으로 빠르고 전력 효율적으로 처리하기 위해 특화된 전용 하드웨어(GPU, TPU, NPU 등)의 총칭
- **중앙처리장치(Central Processing Unit, CPU)**: 명령 해석과 범용 연산을 수행하는 프로세서이다.
- **곱셈-누산(Multiply-Accumulate, MAC)**: 두 값을 곱한 결과를 누적하여 행렬•합성곱을 계산하는 신경망 핵심 연산이다.

</details>

- 정의: 텐서 연산•데이터 이동에 특화한 **AI 가속기**이다.
- 배경/필요성: 범용 CPU는 대량 MAC과 **데이터 이동 효율** 부족

#### 한줄 요약
- 반복 텐서 연산과 데이터 배치에 맞춘 **전용 하드웨어**

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **온칩 메모리(On-Chip Memory)**: 가속기 칩 내부에서 가중치•활성값•부분합을 가까이 보관하는 고속 메모리이다.
- **데이터 흐름(Dataflow)**: 연산 배열과 메모리 사이에서 가중치•활성값•부분합을 이동•재사용하는 순서이다.
- **초당 1조 연산(Tera Operations Per Second, TOPS)**: 가속기가 1초에 수행하는 연산량의 단위이다.
- **초당 기가바이트(Gigabytes Per Second, GB/s)**: 메모리나 연결망이 1초에 전송하는 데이터량의 단위이다.

</details>

![AI 가속기의 연산 집약도별 처리량 상한](/study/diagrams/ai-accelerator-roofline.svg)

> 500 ops/byte 이전 **메모리 대역폭**, 이후 **MAC 성능** 병목
>
> **100 TOPS•200 GB/s**가정의 이론적 루프라인

- 저정밀 텐서의 **대규모 병렬 MAC**
- 온칩 데이터 흐름 기반 **가중치•활성값 재사용**
- 회로 고정도에 따른 **전력 효율 증가•유연성 감소**

#### 한줄 요약
- 온칩 재사용으로 **외부 메모리 이동•전력 소모** 절감

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **텐서 배열**: 여러 MAC을 병렬 배치해 행렬•벡터 연산을 수행하는 연산 구조이다.
- **컴파일러**: 모델 연산 그래프를 장치 명령•자료형•메모리 배치로 변환하는 개념이다.
- **런타임**: 변환된 장치 명령의 실행과 메모리•자원 할당을 제어하는 구성요소이다.
- **온칩 메모리**: 연산 배열 가까이 데이터를 배치하여 외부 메모리 왕복을 줄이는 구성요소이다.
- **외부 메모리 인터페이스**: 칩 밖의 메모리와 대용량 텐서를 주고받는 전송 경로이다.
- **전력•열 제어기**: 소비전력과 온도를 감시하여 클록•전압•활성 연산 자원을 안전 한도 안에서 조절하는 구성요소이다.

</details>

MAC 배열은 텐서 연산을 병렬로 처리한다.

```text
[컴파일러] ----- [런타임]
                     |
             [MAC•텐서 배열] ----- [온칩 메모리] ----- [외부 메모리 인터페이스]
                     |
              [전력•열 제어기]
```

선의 의미: 컴파일러와 런타임은 MAC•텐서 배열의 실행 제어 계층을 이루고, 온칩 메모리와 외부 메모리 인터페이스는 연산 데이터 경계를, 전력•열 제어기는 배열의 물리 동작 한계를 구성하는 정적 가속기 구조를 뜻한다.

| 구성요소 | 책임 |
|:---|:---|
| 컴파일러 | 모델 그래프의 **지원 연산•장치 명령 변환** |
| 런타임 | 장치 명령의 **실행•자원 할당 제어** |
| MAC•텐서 배열 | 행렬•벡터의 **병렬 곱셈-누산 수행** |
| 온칩 메모리 | 가중치•활성값•부분합의 **근거리 재사용** |
| 외부 메모리 인터페이스 | 대용량 텐서의 **전송 대역폭 제공** |
| 전력•열 제어기 | 전력•온도에 따른 **클록•자원 한도 조절** |

#### 한줄 요약
- 컴파일•연산•메모리•전력의 **가속기 구조**

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **타일링(Tiling)**: 큰 텐서를 온칩 메모리에 맞는 작은 블록으로 나누어 반복 계산하는 기법이다.
- **그래프 융합**: 연속 연산을 하나의 실행 단위로 합쳐 호출과 메모리 이동을 줄이는 최적화하는 방식이다.

</details>

```text
모델 개발자
   │ 1. 모델•연산•자료형 지원 검사
   ▼
컴파일러
   │ 2. 그래프 융합•정밀도 변환
   ▼
메모리 배치기
   │ 3. 텐서•타일 메모리 배치
   ▼
가속기
   │ 4. 병렬 MAC•데이터 재사용
   ▼
성능 평가기 ── 지연•전력•정확도 검증 결과 ──▶ 모델 개발자
```

### 동작 원리

1. 모델•연산•자료형 지원 검사: 장치가 전체 그래프를 실행할 **호환 범위** 활용 확인함.
2. 그래프 융합•정밀도 변환: 연산 호출•메모리 이동을 줄이는 **실행 그래프** 활용 생성함.
3. 텐서•타일 메모리 배치: 재사용률에 맞춰 온칩•외부 메모리의 **데이터 위치** 활용 결정함.
4. 병렬 MAC•데이터 재사용: 연산 배열에서 부분합과 입력을 재사용해 **텐서 계산** 수행함.
#### 한줄 요약
- 그래프•메모리를 최적화하고 **지연•전력•정확도** 검증

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **신경망 처리장치(Neural Processing Unit, NPU)**: 신경망 텐서 연산과 저정밀 데이터 흐름에 특화한 프로세서이다.
- **그래픽 처리장치(Graphics Processing Unit, GPU)**: 다수의 병렬 코어로 그래픽과 범용 텐서 연산을 처리하는 프로세서이다.
- **현장 프로그래머블 게이트 배열(Field-Programmable Gate Array, FPGA)**: 배포 후에도 논리 회로와 데이터 경로를 재구성할 수 있는 가속기이다.
- **주문형 반도체(Application-Specific Integrated Circuit, ASIC)**: 특정 연산•데이터 흐름을 제조 단계에서 고정한 전용 반도체이다.

</details>

GPU, NPU, ASIC, FPGA는 유연성과 효율의 균형이 다르다.

| 구분 | GPU | NPU•ASIC | FPGA |
|:---|:---|:---|:---|
| 적용 기준 | **모델 변경•범용성** | **고정 모델•전력 효율** | **맞춤 입출력•저지연** |
| 핵심 특징 | 범용 병렬 코어•**텐서 유닛** | 전용 MAC•**고정 데이터 흐름** | 재구성 논리•**맞춤 파이프라인** |
| 한계 | **전력•제어 오버헤드** | **연산 지원•이식성** 제한 | **설계•합성 시간** |

#### 한줄 요약
- 범용성은 **GPU**, 효율은 **NPU**•**ASIC**, 재구성은 FPGA

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **CPU 대체 실행**: 미지원 가속기 연산을 CPU에서 실행하여 전체 처리 지연이 증가하는 상황이다.
- **종단 프로파일**: 모델 전체 경로의 연산•전송•대기 시간을 측정해 실제 병목을 찾는 분석하는 개념이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 미지원 연산의 **CPU 대체 실행 지연** | **연산자•자료형 지원 범위와 종단 프로파일** 측정 | 실효 처리량 **검증** |
| 외부 메모리의 **데이터 이동 병목** | **타일링•연산 융합•온칩 재사용** 최적화 | 대역폭•전력 소모 **절감** |
| 저정밀 변환의 **모델 정확도 저하** | **계층별 양자화•원본 대비 회귀 시험** | **정확도 허용 범위 내 처리량 확보** |

#### 한줄 요약
- CPU 대체•메모리 이동•저정밀의 **종단 병목** 검증

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **전력 효율**: 소비 전력당 처리할 수 있는 AI 연산량이나 요청 수를 나타내는 지표이다.
- **연산 지원 범위**: 가속기가 CPU 대체 실행 없이 직접 처리할 수 있는 연산자와 자료형의 범위이다.

</details>
