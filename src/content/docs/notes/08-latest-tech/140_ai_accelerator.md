## 미리 알고가기

- **AI 가속기**: AI 가속기는 행렬 연산과 텐서 연산을 빠르고 효율적으로 처리하도록 설계된 전용 하드웨어를 통칭함
- **GPU(대량 병렬 계산 장치)**: GPU와 TPU와 NPU와 ASIC과 FPGA가 모두 범주 안에 들어갈 수 있으나 범용성은 서로 다름
- **연산 성능만큼 메모리 대역폭**: 연산 성능만큼 메모리 대역폭과 소프트웨어 생태계가 실제 경쟁력을 결정함


## Ⅰ. 개요

- **정의/개념**: 텐서 연산·메모리에 특화한 프로세서
- **배경/필요성**: 곱셈·누산의 이동·제어 비용 절감

### 쉽게 이해하기 (학습용)

- 여러 요리를 모두 만드는 범용 주방 대신 반복되는 썰기·섞기 작업에 맞춘 전용 조리대를 고르되, 메뉴와 조리법을 실제로 처리할 수 있는지도 확인하는 것과 같음

## Ⅱ. 특징

- 곱셈·누산 배열이 텐서를 병렬 처리한다
- 온칩 재사용이 외부 메모리 전송을 줄인다
- 고정 연산 구조는 효율을 높이고 범용성을 낮춘다
- 미지원 연산의 호스트 실행은 지연을 늘린다

### 쉽게 이해하기 (학습용)

- 전용 조리대는 같은 요리를 적은 전력으로 많이 만들지만 새 메뉴를 못 만들 수 있고, 지원하지 않는 단계가 일반 주방으로 돌아가면 전체 시간이 길어짐

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 연산 배열 | 행렬·벡터 곱셈·누산 동시 수행 |
| 데이터 흐름 | 가중치·활성값·부분합 재사용 경로 |
| 외부 메모리 | 온칩 인터페이스와의 용량·대역폭 경계 |
| 컴파일러 | 그래프를 장치 명령으로 변환하는 계층 |
| 전력·열 제어 | 전력·온도에 따른 클록·자원 상태 |

```text
모델 → [컴파일러] ─배치→ [연산 배열] ←실행한도─ [전력·열]
                             ↕
                      [데이터 흐름]
                             ↕
                       [외부 메모리]
```

> 요약: 컴파일러 배치와 메모리 재사용이 실효 처리량을 정한다.

### 쉽게 이해하기 (학습용)

- 조리 감독인 컴파일러가 재료를 가까운 선반인 온칩 메모리에 두고 전용 조리대인 연산 배열의 순서를 정하며, 전력·온도 한도가 생산 속도를 제한함

## Ⅳ. 원리 및 절차 흐름도

```text
모델 그래프·연산 지원 검사
  ├─ 미지원 → 대체 후보·호스트 우회 경로 구성 ───┐
  └─ 지원 → 연산 융합·정밀도·타일 결정 ─────────┤
                                                 ↓
                                      텐서·부분합 메모리 배치
                                                 ↓
                                      온칩 재사용·병렬 연산 실행
                                                 ↓
                                      지연·처리량·전력·오차 판정
                         ├─ 기준 충족 → 실행 프로파일 고정
                         └─ 기준 미달 → 정밀도·타일·가속기 재선택
```

| 절차 | 설명 |
|:---|:---|
| 지원 검사 | 모델·자료형의 컴파일 가능 여부 확인 |
| 그래프 변환 | 연산 융합 및 정밀도 선택 |
| 메모리 배치 | 온칩·외부 메모리 위치 선정 |
| 병렬 실행 | 연산 배열 데이터 공급 및 부분합 재사용 |
| 종단 판정 | 호스트 우회 포함 성능·전력·오차 측정 |
| 프로파일 고정 | 기준 충족 시 실행 설정 저장 |

> 요약: 모델 지원 범위와 호스트 우회 성능까지 확인 후 확정함

### 쉽게 이해하기 (학습용)

- 새 조리법을 장치가 이해하는지 먼저 확인하고 재료를 가까운 선반에 배치한 뒤, 실제 조리 시간·전력·맛이 기준을 만족하는 설정만 저장함

## Ⅴ. 종류 및 비교

| 판단 기준 | GPU | 전용 NPU·ASIC | FPGA |
|:---|:---|:---|:---|
| 연산 구조 | 범용 코어·텐서 연산 | 행렬 곱셈·누산 배열 | 재구성 가능한 논리 |
| 적용 기준 | 모델 변경·범용성 필요 시 | 고정 모델의 전력 효율 중요 시 | 맞춤 입출력·저지연 필요 시 |
| 병목 | 커널 실행 비용 | 이식성·컴파일 지원 | 설계·합성 시간 |

> 요약: 범용·고정·재구성에 GPU·ASIC·FPGA를 고른다.

### 쉽게 이해하기 (학습용)

- 메뉴가 자주 바뀌면 범용 조리대인 GPU, 같은 메뉴를 대량 생산하면 전용 조리대인 NPU·ASIC, 조리대 배선 자체를 바꿔야 하면 FPGA가 맞음

## Ⅵ. 실무 사례

1. 온라인 생성형 AI 서버는 모델을 후보 장치에 컴파일하고 호스트 우회 없이 응답 기한을 충족하는 가속기를 선택함
2. 대량 영상 분류는 필요한 연산을 모두 지원하는 NPU·ASIC에서 가중치·활성값을 재사용해 외부 메모리 전송을 줄임

### 쉽게 이해하기 (학습용)

- 실시간 서비스는 조리법을 전부 처리하면서 제시간에 답하는 장치를 고르고, 같은 작업을 반복하면 재료를 내부에서 재사용하는 전용 장치가 유리함

## Ⅶ. 결론

- 연산 지원·이동·우회 지연·전력으로 선택한다

### 쉽게 이해하기 (학습용)

- 최고 속도 숫자보다 실제 메뉴를 빠짐없이 처리하고 정한 시간·전력·정확도를 만족하는지가 장치 선택 기준임
