## 미리 알고가기

- **합성 데이터 (Synthetic Data)**: 실제 관측 대신 생성 모델이나 시뮬레이터로 만든 학습·평가 데이터
- **모조 데이터 (Dummy Data)**: 스키마 규칙만 모사하여 채운 단순 테스트 데이터
- **자가 훈련 성능 붕괴 (MAD, Model Autophagy Disorder)**: 모델이 합성 데이터만 학습해 다양성을 잃고 지능이 붕괴하는 현상
- **실제 고정 기준셋 (Anchor Set)**: 합성 데이터 왜곡을 모니터링하기 위해 보존하는 순수 실제 데이터 기준선



## Ⅰ. 개요

- 정의/개념: 모델·규칙·시뮬레이터로 생성한 데이터
- **배경/필요성**: 희귀 상황과 민감 정보의 수집 제약 보완

### 쉽게 이해하기 (학습용)

- 실제 상황을 모의로 연습하되 현실 데이터와 일치하는지 확인합니다.

## Ⅱ. 특징

- 생성 조건을 조절해 실제 수집이 어려운 상황을 보강한다.
- 시뮬레이터가 라벨도 산출해 조건과 정답을 추적한다.
- 생성기는 원천 데이터의 분포·편향·오류를 물려받는다.
- 원천 데이터 재현 가능성을 개인정보 관점에서 검사한다.

### 쉽게 이해하기 (학습용)

- 원하는 조건의 장면을 만들 수 있지만 현실의 누락과 민감 정보도 복제할 수 있습니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 생성 요구 | 분포·클래스·금지 속성 정의 |
| 생성기 | 표본과 라벨 산출 |
| 품질 필터 | 형식·사실 오류 검출 |
| 출처 기록 | 생성 이력 표본 연결 |
| 실제 기준셋 | 분포·성능 비교용 기준 |

생성 요구
↓
생성기
↓
합성 표본 ─┐
           ├→ 검증
실제 기준셋 ──┘

### 쉽게 이해하기 (학습용)

- 생성 조건에 맞춘 표본을 품질 필터와 실제 기준셋으로 검사합니다.

## Ⅳ. 원리 및 절차 흐름도

목표 정의
↓
조건 생성
↓
실제 비교
├─ 이격 큼 → 폐기
└─ 허용 → 채택

| 절차 | 설명 |
|:---|:---|
| 조건 정의 | 보강 조건·클래스 명시 |
| 조건 생성 | 시드 기록하며 표본 산출 |
| 품질 검사 | 형식·중복·재현 검출 |
| 실제 비교 | 분포·과업 성능 측정 |
| 채택 재생성 | 허용 표본만 출처 기록 사용 |

### 쉽게 이해하기 (학습용)

- 생성 표본은 품질 검사와 현실 표본 대조를 통과해야 학습에 사용합니다.

## Ⅴ. 종류 및 비교

| 판단 기준 | 실제 원천 데이터 | 합성 데이터 | 증강 데이터 |
|:---|:---|:---|:---|
| 생성 근거 | 관측·기록 직접 확보 | 모델·규칙에서 생성 | 라벨 보존 변환 적용 |
| 주요 실패 | 수집 편향·민감 정보 | 생성기 편향·분포 이격 | 라벨 의미 훼손 가능 |
| 적용 기준 | 현실 기준·평가 시 | 희귀 조건·표본 보강 시 | 의미 유지 변환 시 |

> 요약: 실제 기준셋 검증을 거친 경우만 제한적 채택함

### 쉽게 이해하기 (학습용)

- 실제·증강·합성 데이터는 생성 근거가 달라 검증할 오류도 다릅니다.

## Ⅵ. 실무 사례

- 자율주행은 기상·충돌을 합성하고 실제 자료로 검증

### 쉽게 이해하기 (학습용)

- 위험 상황을 안전하게 생성하되 실제 운영 자료를 기준으로 왜곡을 걸러냅니다.

## Ⅶ. 결론

- 실제 데이터 부족과 개인정보 제약을 보완하기 위해 **현실성·다양성·라벨 정확도·편향·원본 정보 재현 위험**을 검토하고, 독립 검증 성능이 개선되는 범위에서 합성 데이터를 활용해야 한다.

### 쉽게 이해하기 (학습용)

- 현실성 검증과 개인정보 검사를 통과한 합성 표본만 학습에 사용해야 합니다.
