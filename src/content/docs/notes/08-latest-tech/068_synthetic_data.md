## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **합성 데이터(Synthetic Data)**: 실제 관측 대신 생성 모델•규칙•시뮬레이터로 만든 학습•평가 데이터를 의미한다.
- **합성 표본 보강(Synthetic Sample Augmentation)**: 실제로 수집하기 어렵거나 위험한 조건의 표본을 생성하여 데이터 범위를 넓히는 활용 방식을 나타낸다.

</details>

- 정의/개념: 모델•규칙•시뮬레이터로 실제 분포와 조건을 모사한 **합성 데이터**임.
- 배경/필요성: 희귀•위험 상황의 표본 부족과 민감정보 수집•공유 제한에 따라 **합성 표본 보강**이 필요함.

#### 한줄 요약
- 실제 상황 모의와 현실 데이터 기준의 일치성을 검증한다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **조건 제어 생성(Conditional Controllable Generation)**: 클래스•환경•금지 속성을 명시하여 필요한 분포의 표본을 만드는 기법을 말한다.
- **자동 라벨(Auto-labeling)**: 생성 조건이나 시뮬레이터 상태에서 표본 정답을 함께 산출하는 기능을 뜻한다.
- **원천 정보 재현(Original Data Leakage)**: 생성기가 학습한 민감정보나 원문 특성을 합성 표본에 복제하는 위험 현상으로 정의된다.

</details>

- 실제 수집이 어려운 상황을 보강하는 **조건 제어 생성**이 핵심임.
- 생성 조건과 정답을 연결하는 **자동 라벨•계보 추적**이 핵심임.
- 생성기의 **분포 편향•원천 정보 재현** 위험이 핵심임.

#### 한줄 요약
- 조건 제어 생성의 편의와 현실 누락•민감정보 재현 위험이 핵심이다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **생성 요구(Generation Requirements)**: 목표 분포•클래스•희귀 조건•금지 속성을 정의한 명세 사항을 의미한다.
- **출처 기록(Provenance Tracking)**: 생성 모델•버전•시드•조건•라벨을 각 합성 표본과 연결한 이력으로 정의된다.
- **실제 고정 기준셋(Anchor Set)**: 합성 데이터 왜곡을 감시하도록 보존한 순수 실제 데이터 기준선을 말한다.

</details>

```text
                         [품질 필터]
                        /           \
                   [생성기]       [실제 기준셋]
                  /       \
          [생성 요구]   [출처 기록]
```

선의 의미: 품질 필터는 생성기의 표본을 실제 기준셋과 대조하고, 생성기는 생성 요구를 적용하여 각 표본을 출처 기록과 연결함.

| 구성요소 | 책임 |
|:---|:---|
| 생성 요구 | **분포•클래스•금지 속성** 정의 |
| 생성기 | **합성 표본•자동 라벨** 산출 |
| 품질 필터 | **형식•사실 오류** 검출 |
| 출처 기록 | **생성 이력•표본** 연결 |
| 실제 기준셋 | **분포•성능 비교 기준** 제공 |

#### 한줄 요약
- 생성 조건별 표본의 품질 필터•실제 기준셋 검사가 핵심이다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **분포 이격(Distribution Drift)**: 합성 표본의 통계적 특성이 실제 운영 데이터와 달라지는 정도를 가리킨다.
- **채택 기준(Inclusion Criteria)**: 형식•사실•분포•과업 성능 검사를 통과한 표본만 학습에 포함하는 규칙을 말한다.

</details>

```text
생성 요구
   │ 1. 생성 조건•금지 속성 명세
   ▼
생성기
   │ 2. 합성 표본•출처 생성
   ▼
품질 필터
   │ 3. 현실 분포•과업 검증
   ▼
실제 기준셋
   └── 채택•폐기 기준 ──▶ 품질 필터
```

**동작 원리**

1. **생성 조건•금지 속성 명세**: 희귀 클래스와 목표 분포를 정의함.
2. **합성 표본•출처 생성**: 생성 시드•모델•라벨의 추적 정보를 결합함.
3. **현실 분포•과업 검증**: 실제 기준셋 대비 분포 이격•성능을 측정함.

#### 한줄 요약
- 품질 검사와 현실 표본 대조를 통과한 생성 표본만 학습에 사용한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **합성 데이터 역할(Role of Synthetic Data)**: 모델•규칙•시뮬레이터로 새로운 표본을 생성하여 데이터 부족을 해소하는 역할을 의미한다.
- **실제 원천 데이터(Real World Source Data)**: 현실에서 관측•기록하여 분포와 평가의 기준을 제공하는 데이터 자산을 나타낸다.
- **증강 데이터(Augmented Data)**: 기존 원본을 라벨 의미가 유지되는 범위에서 변환하는 방식을 뜻한다.

</details>

| 데이터 확보 방식 | 합성 데이터 | 실제 원천 데이터 | 증강 데이터 |
|:---|:---|:---|:---|
| 적용 기준 | 희귀 조건•**표본 보강** | 현실 **기준•평가 데이터** | 라벨 보존 **변환** |
| 핵심 특징 | 모델•규칙•**시뮬레이터 생성** | 현실 **관측•기록** | 원본 **표본 변환** |
| 한계 | 생성기 편향•**분포 이격** | 수집 편향•**민감정보** | 라벨 **의미 훼손** |

#### 한줄 요약
- 실제•증강•합성 데이터의 확보 근거별 검증 오류를 구분한다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **생성기 편향(Generator Bias)**: 생성 모델의 누락과 편향이 합성 표본 분포에 반복되는 문제를 말한다.
- **모델 자가포식 장애(Model Autophagy Disorder, MAD)**: 합성 데이터만 반복 학습하여 다양성과 현실성이 줄어드는 현상으로 정의된다.
- **혼합 비율(Blending Ratio)**: 실제 데이터와 합성 데이터를 학습에 공급하는 상대 비중을 가리킨다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 생성기 편향으로 **현실 분포 이격** | 실제 기준셋 기반 분포•과업 검증 | 합성 표본 **현실성 확보** |
| 합성 반복 학습으로 **다양성 붕괴** | 실제 데이터 혼합•합성 비율 제한 | **MAD 억제** |

#### 한줄 요약
- 위험 상황의 안전한 생성과 실제 운영 자료 기준의 왜곡을 제거한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **현실성 기준(Realism Criteria)**: 실제 기준셋 대비 분포와 과업 성능을 측정하여 합성 표본의 사용 여부를 판정하는 지표를 나타낸다.
- **다양성 보존(Diversity Preservation)**: 실제 데이터를 계속 혼합하고 합성 비율을 제한하여 반복 생성의 붕괴를 막는 대책을 뜻한다.

</details>

- **현실 분포 이격•다양성 붕괴**를 제한하도록 실제•합성 데이터 혼합 비율을 결정함.

#### 한줄 요약
- 현실성•개인정보 검사를 통과한 합성 표본만 학습에 사용한다.
는 규칙을 말한다.

</details>

```text
생성 요구
   │ 1. 생성 조건•금지 속성 명세
   ▼
생성기
   │ 2. 합성 표본•출처 생성
   ▼
품질 필터
   │ 3. 현실 분포•과업 검증
   ▼
실제 기준셋
   └── 채택•폐기 기준 ──▶ 품질 필터
```

1. **생성 조건•금지 속성 명세**: 희귀 클래스와 목표 분포를 정의함.
2. **합성 표본•출처 생성**: 생성 시드•모델•라벨의 추적 정보를 결합함.
3. **현실 분포•과업 검증**: 실제 기준셋 대비 분포 이격•성능을 측정함.

#### 한줄 요약
- 품질 검사와 현실 표본 대조를 통과한 생성 표본만 학습에 사용한다.
