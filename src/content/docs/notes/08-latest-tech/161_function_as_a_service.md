## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **서비스형 함수(Function as a Service, FaaS)**: 이벤트에 따라 함수 코드를 격리 실행하고 자동 확장하는 클라우드 서비스다.
- **서버리스 컴퓨팅**: 인프라 준비•확장•회수를 공급자가 담당하는 클라우드 운영 모델이다.

</details>

- 정의/개념: 이벤트별 함수 코드를 격리 실행•자동 확장하는 **FaaS**
- 배경/필요성: 간헐 작업의 상시 서버로 **유휴 비용•운영 부담** 증가

#### 한줄 요약

- 이벤트 발생 시에만 함수를 실행하고 **사용량 기반 과금**

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **콜드 스타트**: 재사용할 실행 환경이 없어 런타임과 코드를 새로 초기화하며 생기는 첫 요청 지연이다.
- **무상태 처리**: 함수 실행 사이에 로컬 메모리나 파일 상태가 유지된다고 가정하지 않는 처리다.

</details>

- 이벤트 기반 **실행 환경 자동 할당•확장**
- 실행 간 로컬 상태를 보장하지 않는 **무상태 처리**
- 콜드 스타트•재시도에 따른 **지연•중복 처리**

#### 한줄 요약

- 필요할 때만 실행되므로 효율적이지만 첫 실행 준비 시간과 중복 이벤트를 설계해야 한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **하이퍼텍스트 전송 프로토콜(Hypertext Transfer Protocol, HTTP)**: 웹에서 요청과 응답을 교환하는 응용 계층 프로토콜이다.
- **이벤트 소스**: HTTP 요청•메시지•파일 생성 등 함수 실행의 입력 이벤트를 생성하는 개념을 말한다.
- **트리거(Trigger)**: 이벤트 조건을 평가하여 함수 호출 여부를 결정하는 규칙로 정의된다.
- **라우터(Router)**: 트리거가 선택한 이벤트를 대상 함수 런타임으로 전달하는 개념이다.
- **함수 런타임(Function Runtime)**: 이벤트마다 격리 실행 환경을 할당하고 함수 코드의 초기화•실행•시간•자원을 관리하는 구성요소을 의미한다.
- **함수 코드(Function Code)**: 입력 이벤트를 처리하고 외부 서비스와 상태 저장소를 호출하는 사용자 업무 로직로 정의된다.
- **외부 상태 저장소**: 실행 환경과 분리해 영속 상태•멱등 키•처리 결과를 보관하는 저장소을 의미한다.

</details>

트리거는 **HTTP 요청**, 메시지, 파일 생성 같은 이벤트를 함수 런타임에 연결한다.

```text
                 [이벤트 소스]
                       |
                   [트리거]
                       |
                   [라우터]
                       |
                [함수 런타임]
                       |
                 [함수 코드]
                       |
              [외부 상태 저장소]
```

선의 의미: 이벤트 소스와 트리거를 라우터가 함수 런타임에 연결하고, 런타임 안의 함수 코드가 실행 환경 밖의 상태 저장소를 사용한다.

| 구성요소 | 책임 |
|:---|:---|
| 이벤트 소스 | 요청•메시지•스케줄 이벤트 생성 |
| 트리거 | 이벤트 조건 평가와 함수 호출 결정 |
| 라우터 | 대상 함수 런타임 연결 |
| 함수 런타임 | 격리 환경 준비•확장•회수 |
| 함수 코드 | 단일 책임의 업무 로직 수행 |
| 외부 상태 저장소 | 영속 상태•멱등 키•결과 저장 |

#### 한줄 요약

- API 게이트웨이가 요청을 알맞은 실행 환경에 라우팅하고 결과와 처리 기록은 외부 저장소에 남긴다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **멱등성(Idempotency)**: 같은 이벤트를 반복 처리해도 최종 상태가 한 번 처리한 것과 같게 유지되는 성질을 말한다.
- **조건부 쓰기**: 기존 값이나 버전이 지정 조건을 만족할 때만 상태 변경을 허용하는 저장 연산을 말한다.

</details>

**FaaS**는 함수 호출부터 상태 반영까지 이벤트를 처리한다.

```text
이벤트 소스 ── 이벤트 ──▶ 트리거•라우터
트리거•라우터 ── 1. 함수 호출 요청 ──▶ 함수 런타임
함수 런타임 ── 2. 실행 환경 할당 ──▶ 함수 코드
함수 코드 ── 3. 멱등 확인•상태 반영 ──▶ 외부 상태 저장소
함수 코드 ◀── 상태 반영 결과 ───────── 외부 상태 저장소
이벤트 소스 ◀── 처리 결과 ─────────── 함수 코드
```

### 동작 원리

1. **함수 호출 요청**: 조건•대상 함수•동시성 정책 확인
2. **실행 환경 할당**: 기존 환경 재사용 또는 새 환경 기동
3. **멱등 확인•상태 반영**: 중복 키 검사 후 업무 결과 저장

#### 한줄 요약

- 같은 주문이 다시 와도 주문 번호를 확인해 한 번만 반영하고 실패하면 정해진 규칙으로 재처리한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **서버리스 컨테이너**: 사용자가 제공한 컨테이너 이미지를 요청량에 따라 자동 기동•확장하는 실행 모델을 말한다.
- **상시 실행 서비스**: 요청 유무와 관계없이 프로세스와 자원을 계속 유지하는 실행 모델로 정의된다.

</details>

| 실행 모델 | FaaS | 서버리스 컨테이너 | 상시 실행 서비스 |
|:---|:---|:---|:---|
| 적용 기준 | 짧고 독립적인 **이벤트 작업** | 컨테이너 단위 **요청**•**작업** | **지속 연결•장기 실행** |
| 핵심 특징 | 함수 단위 **자동 확장•종량 과금** | 이미지 단위 **배포•자동 확장** | 상시 **프로세스•자원 제어** |
| 한계 | **시간•런타임•상태 제약** | **이미지 관리•기동 비용** | **유휴 비용•운영 부담** |

#### 한줄 요약

- 짧은 일은 함수, 묶음 작업은 컨테이너, 계속 켜 둘 업무는 상시 서비스가 적합하다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **꼬리 지연**: 요청 지연 분포에서 가장 느린 상위 백분위 구간의 응답 시간로 정의된다.
- **데드 레터 큐(Dead Letter Queue, DLQ)**: 반복 처리에 실패한 이벤트를 격리해 조사•재처리하도록 보관하는 큐을 의미한다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **콜드 스타트**로 인한 응답 지연 | **사전 준비 인스턴스**•경량 의존성 적용 | **꼬리 지연** 감소 |
| 재시도에 따른 중복 처리 | **멱등 키•조건부 쓰기** 적용 | 이중 결제•중복 반영 방지 |
| **동시성 급증**으로 후단 과부하 | **동시성 한도•큐•DLQ** 구성 | **장애 전파•이벤트 유실** 억제 |

#### 한줄 요약

- 결제 함수는 주문 번호를 멱등 키로 저장하고 동시 실행 수를 제한해 데이터베이스를 보호한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **독립 이벤트 작업**: 다른 요청과 장기 실행 상태에 직접 의존하지 않고 하나의 입력으로 끝낼 수 있는 작업로 정의된다.
- **동시성 한도**: 함수가 한 시점에 병렬 실행할 수 있는 인스턴스 수를 제한한 값을 말한다.

</details>

- 짧은 독립 이벤트는 **FaaS**, 지속 연결•장기 작업은 **상시 서비스** 선택

#### 한줄 요약

- 멱등성•외부 상태•동시성 한도를 갖춘 **독립 이벤트 작업**에 적용
