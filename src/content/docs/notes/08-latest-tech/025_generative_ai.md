## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **생성형 인공지능(Generative Artificial Intelligence, Generative AI)**: 학습 데이터의 분포를 바탕으로 조건에 맞는 새로운 글•그림•음성•코드 등을 만드는 인공지능이다.
- **학습 분포**: 학습 데이터에서 모델이 익힌 특징과 값의 확률적 구조이다.

</details>

- 정의/개념: 학습 데이터의 분포와 구조를 모델링해 새로운 콘텐츠를 만드는 **Generative AI**이다.
- 배경/필요성: 판별형 모델은 범주•수치 예측에 집중해 **학습 분포** 기반 신규 콘텐츠를 생성하기 어렵다.

#### 한줄 요약

- 학습 분포에서 새 글•그림•음성•코드를 생성한다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **자기회귀(Autoregressive)**: 앞서 생성한 값을 조건으로 다음 값을 순차적으로 예측하는 생성 방식이다.
- **확산 모델(Diffusion Model)**: 잡음이 섞이는 과정을 학습한 뒤 잡음에서 데이터를 반복 복원하여 표본을 생성하는 모델이다.
- **멀티모달(Multimodal)**: 텍스트•이미지•음성처럼 서로 다른 데이터 양식을 함께 이해하고 생성하는 방식이다.
- **생성적 적대 신경망(Generative Adversarial Network, GAN)**: 생성자와 판별자가 경쟁하며 실제와 유사한 표본을 생성하도록 학습하는 모델이다.
- **변분 오토인코더(Variational Autoencoder, VAE)**: 입력을 잠재 확률분포로 인코딩하고 그 분포에서 표본을 복원하는 모델이다.

</details>

- **자기회귀**: 앞선 값을 조건으로 다음 값을 생성한다.
- **확산 모델**: 잡음에서 데이터를 반복 복원한다.
- **GAN**: 생성자•판별자의 경쟁으로 표본을 생성한다.
- **VAE**: 잠재 확률분포에서 표본 복원한다.
- **멀티모달**: 여러 데이터 양식의 교차 조건을 처리한다.
- 데이터 양식별 구조에 맞춘 생성을 최적화한다.
- 생성 품질과 사실성•권리 적합성을 별도로 검증한다.

#### 한줄 요약

- 생성 품질은 사실성•안전성•권리 적합성을 보장하지 않는다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **잠재 벡터(Latent Vector)**: 원본 콘텐츠의 핵심 특징을 낮은 차원의 연속 공간에 압축해 표현한 벡터이다.
- **생성 모델(Generative Model)**: 학습 데이터의 조건부 분포에서 새 텍스트•이미지•음성•코드 후보를 표본화하는 핵심 모델이다.
- **조건 제어기**: 프롬프트•참조 자료•금지 조건을 생성 모델이 사용할 표현으로 구성하여 결과 방향을 제한하는 구성요소이다.
- **검증 계층**: 생성 후보가 품질•사실•안전•권리 기준을 충족하는지 판정하는 구성요소이다.

</details>

```text
                   [표현 계층]
                        |
                   [생성 모델]
                        |
                   [조건 제어기]
                        |
                   [검증 계층]
```

선의 의미: 표현 계층과 생성 모델을 조건 제어기가 제한하고, 검증 계층이 품질•사실•안전•권리 경계를 담당하는 생성형 AI 구조를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 표현 계층 | 콘텐츠를 토큰•**잠재 벡터**로 변환 |
| 생성 모델 | **생성 모델**이 학습한 조건부 분포에서 후보 표본화 |
| 조건 제어기 | **조건 제어기**가 프롬프트•참조•금지 조건으로 생성 방향 제약 |
| 검증 계층 | **검증 계층**이 품질•사실•안전•권리 기준 판정 |

#### 한줄 요약

- **표현•생성•조건 제어•검증 계층**으로 후보 생성•선별이 핵심이다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **조건부 분포**: 프롬프트나 참조 같은 조건이 주어졌을 때 가능한 출력과 각 출력의 확률을 나타낸 분포이다.
- **표본화(Sampling)**: 학습한 확률분포에서 하나의 생성 후보를 선택하는 과정이다.
- **생성 조건 구조화**: 생성 목적•형식•금지 조건과 출력 제약을 모델이 처리할 형태로 구성하는 절차이다.
- **프롬프트•참조 표현 주입**: 사용자 조건과 참조 자료를 생성 모델의 입력 문맥에 결합하는 절차이다.
- **조건부 분포 후보 표본화**: 조건부 분포에서 확률에 따라 새로운 콘텐츠 후보를 선택하는 절차이다.
- **사실•안전•권리 검증**: 생성 후보가 사실성•안전성•권리 기준을 충족하는지 판정하는 절차이다.

</details>

```text
사용자
   │ 과업•형식•금지 조건 전달
   ▼
조건 제어기
   │ 1. 생성 조건 구조화
   │ 2. 프롬프트•참조 표현 주입
   ▼
생성 모델
   │ 3. 조건부 분포 후보 표본화
   │ 생성 후보 전달
   ▼
검증 계층
   │ 4. 사실•안전•권리 검증
   ├────────────────────────┐
   │ 충족: 결과 반출        │
   │ 미달: 재생성 조건 전달 │
   └───────────┬────────────┘
               ▼
        사용자•생성 모델
```

1. **생성 조건 구조화**: 생성 목적•형식•금지 조건과 출력 제약을 구성한다.
2. **프롬프트•참조 표현 주입**: 사용자 조건을 모델 문맥에 결합한다.
3. **조건부 분포 후보 표본화**: **표본화**로 신규 콘텐츠를 생성한다.
4. **사실•안전•권리 검증**: 기준 충족 시 반출하고 미달 시를 재생성한다.

#### 한줄 요약

- **사실•안전•권리 검증** 후 기준 미달이면 조건을 수정해 재생성한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **판별형 인공지능(Discriminative Artificial Intelligence, Discriminative AI)**: 입력의 특징을 바탕으로 범주•점수•수치 같은 정해진 결과를 판정하는 인공지능이다.

</details>

- **Generative AI**와 **Discriminative AI**를 신규 표본 생성과 범주•수치 판정 기준으로 구분한다.

| AI 유형 | 생성형 AI | 판별형 AI |
|:---|:---|:---|
| 적용 기준 | 콘텐츠 생성•변형과 합성 | 판정•탐지와 수치 예측 |
| 핵심 특징 | 데이터 분포 기반 신규 표본 생성 | 클래스 경계 기반 범주•수치 판정 |
| 한계 | 환각•권리•안전 위험 | 학습 범주 밖 생성 불가 |

#### 한줄 요약

- 신규 표본은 **Generative AI**, 범주•수치 예측은 **Discriminative AI**가 적합하다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **합성 데이터(Synthetic Data)**: 생성 모델로 만들어 학습•시험•희귀 사례 보완에 사용하는 인공 데이터이다.
- **분포 왜곡**: 합성 데이터가 실제 데이터의 빈도•다양성•희귀 사례를 다르게 반영하여 모델 성능을 편향시키는 현상이다.
- **생성물 유사성 검사**: 결과가 학습•참조 자료와 지나치게 유사하여 권리를 침해할 가능성이 있는지 비교하는 절차이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 생성 결과의 사실성 부족 | 근거 검색•사실 검증•인간 검토 | 환각의 업무 반영 차단 |
| 학습•참조 자료의 권리 침해 | 출처•이용 조건•**생성물 유사성 검사** | 저작권•계약 준수 지원 |
| 유해•편향 콘텐츠의 대외 노출 | 안전 분류•금지 조건•승인 워크플로 | 브랜드•사용자 피해 예방 |
| **합성 데이터**의 **분포 왜곡** | 실제 데이터의 분포•희귀 사례•성능 비교 | 학습 데이터 대표성 검증 |

#### 한줄 요약

- 광고 초안은 제품 정보•금지 문구 검증 후 게시한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **자기회귀 선택 기준**: 토큰처럼 순서가 있는 텍스트와 코드를 앞선 문맥에 이어 생성할 때 적용하는 기준이다.
- **확산 모델 선택 기준**: 반복 복원을 통해 높은 품질과 다양성이 필요한 이미지•음성 표본을 만들 때 적용하는 기준이다.

</details>

- **자기회귀 선택 기준**에 따라 텍스트•코드는 **자기회귀**, **확산 모델 선택 기준**에 따라 이미지•음성은 **확산 모델**을 선택한다.

#### 한줄 요약

- 대상 양식과 검증•권리 조건에 맞는 생성 방식을 선택한다.
