## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **신경망 재순위 모델(Neural Reranker)**: 검색 후보를 신경망으로 재점수화하는 모델이다.

</details>

- 정의: 검색 후보의 관련성을 재평가하는 **신경망 재순위 모델**이다.
- 배경/필요성: 빠른 1차 검색은 **질의•문서 상호작용 부족** #### 한줄 요약

- 1차 검색 후보를 정밀 평가해 **순위 재정렬** ## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **교차 인코더(Cross-Encoder)**: 질의와 문서를 함께 인코딩해 관련성을 점수화한다.
- **ColBERT**: 문서 토큰을 사전 인코딩하고 질의와 후기 상호작용한다.

</details>

- 1차 검색 후보만 재점수화하는 **후보 제한•정밀 상호작용**
- **BERT 교차 인코더** 정밀 평가와 후보별 추론 지연
- **ColBERT 후기 상호작용** 기반 문서 인코딩 비용 절감

#### 한줄 요약

- **후보 회수율•상호작용 정밀도•추론 지연** 절충

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **Top-k**: 1차 검색 결과 중 재평가할 상위 후보 수이다.
- **입력 구성기**: 질의와 후보를 모델의 토큰•길이 형식으로 조합한다.
- **교차 인코더**: 질의와 문서를 함께 인코딩해 관련성을 산출한다.
- **점수 정렬기**: 관련성 점수로 후보 순서와 동점 규칙을 적용한다.
- **반환 정책**: 지연과 문맥 한도 안에서 최종 문서 수를 정한다.

</details>

```text
[1차 검색기]──[입력 구성기]──[신경망 재순위기]
                                 │
                         [점수 정렬기]──[반환 정책기]
```

| 구성요소 | 책임 |
|:---|:---|
| 1차 검색기 | 재평가할 Top-k 후보 회수 |
| 입력 구성기 | 질의•후보를 모델 입력으로 결합 |
| 신경망 재순위기 | 상호작용 기반 관련성 산출 |
| 점수 정렬기 | 재산출 점수로 후보 순서 조정 |
| 반환 정책기 | 지연•반환 한도 내 문서 선택 |

#### 한줄 요약

- **후보•입력•재점수•정렬•반환 정책** 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **후보 제한(Candidate Limitation)**: 1차 검색 누락 문서는 재순위할 수 없는 제약이다.
- **재점수화(Rescoring)**: 질의•문서 상호작용으로 후보 점수를 갱신한다.

</details>

```text
1차 검색기
   │ 1. Top-k 후보 집합
   ▼
입력•신경망 재순위기
   │ 2. 질의•문서 결합 입력
   │ 3. 후보별 관련성 점수
   ▼
점수 정렬기
   │ 4. 재정렬 후보 목록
   ▼
반환 정책기
   └── 반환 한도 내 상위 문서 ──▶ 1차 검색기
```

### 동작 원리

1. Top-k 후보 집합: 1차 검색 회수율이 재순위 가능 범위를 결정함.
2. 질의•문서 결합 입력: 교차 상호작용이 가능한 입력 표현을 구성함.
3. 후보별 관련성 점수: 신경망이 문맥 조건을 반영해 재점수화함.
4. 재정렬 후보 목록: 새 점수를 기준으로 후보 순서를 변경함.

#### 한줄 요약

- **후보 회수•결합 입력•재점수•재정렬** 수행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **점별•쌍별•목록별 학습**: 개별 점수•문서 선호•전체 순위를 각각 최적화한다.

</details>

| 구분 | 점별 학습 | 쌍별 학습 | 목록별 학습 |
|:---|:---|:---|:---|
| 적용 기준 | 개별 **관련성 라벨** 보유 | 문서 간 **선호 관계** 보유 | 전체 **순위 라벨** 보유 |
| 핵심 특징 | 개별 **관련성 점수** 학습 | 두 문서의 **선호 순서** 학습 | 전체 후보의 **순위 품질** 학습 |
| 한계 | 문서 간 **순서 반영 부족** | 전체 목록 **최적화 부족** | 학습 비용•**구현 복잡성** |

#### 한줄 요약

- **개별 점수•문서 선호•전체 순위**별 학습 목표 구분

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **상위 k개 재현율(Recall at k, Recall@k)**: 관련 정답이 후보에 포함된 비율이다.
- **정규화 할인 누적 이득(nDCG)**: 관련성과 순위 위치를 반영한 지표이다.
- **평균 역순위(Mean Reciprocal Rank, MRR)**: 첫 정답 순위 역수의 질의별 평균이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| Top-k 밖의 **1차 검색 누락** | **상위 k개 재현율(Recall at k, Recall@k)** 확보와 하이브리드 검색 적용 | 재순위의 **정답 포함률** 확보 |
| 후보•모델 증가에 따른 **꼬리 지연** | k 제한과 경량 모델•**배치 추론** 적용 | **응답 시간•비용** 제한 |
| 쉬운 부정 표본 중심의 **순위 학습 편향** | 어려운 부정 표본과 **nDCG•MRR 평가** | 유사 오답의 **순위 분별력** 향상 |

#### 한줄 요약

- **Recall@k•nDCG•MRR•꼬리 지연** 검증

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **지연 예산(Latency Budget)**: 검색과 후보 추론을 포함한 응답 시간 한도이다.

</details>

- 회수율 확보 후 **재순위** 적용, 지연 예산에 맞춰 Top-k•모델 크기 제한

#### 한줄 요약

- **후보 회수율•지연 예산** 대상 따라 재순위 범위 결정
