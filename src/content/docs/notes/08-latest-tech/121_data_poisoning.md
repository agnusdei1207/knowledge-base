## 미리 알고가기

- **데이터 오염**: 학습 단계에서 샘플·라벨을 조작해 모델 판단 자체를 왜곡하는 공격
- **적대적 예제**: 데이터 오염과 달리 배포된 모델의 입력을 교란하는 추론 시점 공격
- **오픈 데이터**: 외부 학습·검색 수집 경로가 넓어 공격자가 오염시킬 수 있는 공개 자료

## Ⅰ. 개요

- **정의/개념**: 학습 데이터 조작으로 모델 판단을 왜곡하는 공격이다
- **배경/필요성**: 가중치에 남는 오염과 장기 오판을 막는다

### 쉽게 이해하기 (학습용)

- 문제집 일부의 문제나 정답을 몰래 바꾸면 학생의 성적이 떨어지거나 특정 문제만 틀리게 되는 것과 같다.

## Ⅱ. 특징

- 오염 효과는 가중치에 남아 재배포 뒤에도 지속된다
- 적은 표적 표본도 특정 대상의 오판을 만든다
- 특징 조작은 라벨을 유지한 채 판단 경계를 바꾼다
- 적응형 오염은 정상 분포에 섞여 이상치 탐지를 피한다
- 모델·임베딩 오염은 공급망과 검색 결과를 왜곡한다

### 쉽게 이해하기 (학습용)

- 오염 샘플은 눈에 띄는 오답일 수도 있지만 정답은 그대로 둔 채 특징만 바꿔 판단 기준을 틀어 놓을 수도 있다.

## Ⅲ. 아키텍처 및 구성요소

```text
[기여자 권한] ── [데이터 계보]
      │             │
[격리 데이터셋] ── [기준 평가셋]
      │             │
      └── [버전 저장소] ──┘
```

| 설계 요소 | 설명 |
|:---|:---|
| 기여자 권한 | 샘플·라벨 수정 주체와 범위 |
| 데이터 계보 | 샘플 출처·시점·변환 기록 |
| 격리 데이터셋 | 신규·의심 샘플과 승인 자료 분리 |
| 버전 저장소 | 승인 데이터셋·모델 버전 관리 |
| 기준 평가셋 | 정상·표적·백도어 행동 대조 |

> 요약: 권한·계보·격리·평가로 모델 승격을 통제한다

### 쉽게 이해하기 (학습용)

- 누가 어떤 재료를 언제 넣었는지 기록하고 새 재료는 격리해 검사한 뒤 검증된 데이터와 모델 버전을 함께 보관한다.

## Ⅳ. 원리 및 절차 흐름도

```text
요청
 ↓
기여 검증
 ↓
데이터 생성
 ↓
후보 학습
 ↓
행동 평가
 ↓
모델 승격
```

| 절차 | 설명 |
|:---|:---|
| 기여 접수 | 기여자·수집·샘플 연결 |
| 계보 검증 | 쓰기 권한과 정책 일치 판정 |
| 격리 검토 | 이상치 확인과 의심 자료 분리 |
| 후보 학습 | 버전 데이터로 후보 모델 학습 |
| 행동 평가·승격 | 통과 버전만 배포 대상으로 승격 |

> 요약: 기여 권한·계보와 모델 행동을 검증해 승격한다

### 쉽게 이해하기 (학습용)

- 새 자료의 출처와 이동 기록을 확인하고 후보 모델의 정상·표적 행동이 모두 통과할 때만 배포한다.

## Ⅴ. 종류 및 비교

| 판단 기준 | 가용성 오염 | 표적 무결성 오염 | 백도어 오염 |
|:---|:---|:---|:---|
| 핵심 특징 | 전체 예측 성능 저하 | 특정 입력·집단 오판 | 트리거에서 지정 행동 |
| 적용 기준 | 정상 평가셋 성능 검사 | 표적 조각 오류 검사 | 트리거 성공률 검사 |
| 주요 위험 | 서비스 품질 붕괴 | 평균 지표에 오류 은닉 | 정상 성능으로 탐지 회피 |

> 요약: 전체·표적·트리거 오판을 서로 다른 시험으로 찾는다

### 쉽게 이해하기 (학습용)

- 가용성 오염은 전체 성능을 낮추고 표적 오염은 일부만 틀리게 하며 백도어는 트리거에서만 오답을 낸다.

## Ⅵ. 실무 사례

1. 스팸 신고 자료를 격리해 후보 모델을 평가한다
2. 추천 피드백의 계정군별 기여량을 제한한다

### 쉽게 이해하기 (학습용)

- 스팸 신고를 바로 학습하지 않고 격리해 정상 오탐률과 표적 발신자 미탐률을 평가한다.
- 추천 피드백 기여량을 제한하고 표적 상품 노출이 상한을 넘으면 이전 버전으로 복귀한다.

## Ⅶ. 결론

- 데이터 권한·계보를 고정하고 실패 모델을 복귀시킨다.

### 쉽게 이해하기 (학습용)

- 학습 자료의 변경 권한과 기록을 관리하고 새 모델이 이상하면 검증된 데이터와 모델로 되돌려야 한다.
