## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **데이터 오염**: 학습•재학습 데이터의 표본•라벨•비중을 조작해 모델의 학습 결과를 왜곡하는 공격이다.
- **학습 파이프라인 공격**: 추론 입력이 아니라 데이터 수집•검수•학습•승격 과정에 개입해 모델 행동을 바꾸는 공격이다.

</details>

- 정의/개념: 학습 표본•라벨•분포를 조작해 지속 오판을 주입하는 **데이터 오염 기반 학습 파이프라인 공격**
- 배경/필요성: 입력 검증만으로는 학습에 내재된 **지속 오판** 탐지 곤란

#### 한줄 요약

- 문제집 일부의 문제나 정답을 몰래 바꾸면 학생의 성적이 떨어지거나 특정 문제만 틀리게 되는 것과 같다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **가용성 오염**: 전체 예측 성능을 낮춰 모델 서비스를 사용할 수 없게 만드는 공격 목적이다.
- **표적 무결성 오염**: 특정 입력이나 집단만 의도적으로 오판하게 만드는 공격 목적이다.
- **백도어 오염**: 특정 트리거에서만 공격자가 지정한 행동을 내도록 학습시키는 공격 목적이다.

</details>

- 전체•특정 입력•트리거 행동을 노리는 **가용성•표적•백도어 목적**
- 학습 경계를 바꾸는 **라벨•특징•표본 비중 조작**
- 데이터•모델 승격을 통제하는 **계보•권한•격리•행동 평가**

#### 한줄 요약

- 오염 샘플은 눈에 띄는 오답일 수도 있지만 정답은 그대로 둔 채 특징만 바꿔 판단 기준을 틀어 놓을 수도 있다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **데이터 계보**: 표본의 출처•시점•변환•승인 이력을 추적하는 기록이다.
- **격리 데이터셋**: 신규•의심 표본을 승인된 학습 자료와 분리해 검토하는 저장 영역이다.
- **기준 평가기**: 후보 모델의 정상•표적•백도어 행동을 고정 평가셋으로 비교한다.

</details>

```text
                [기여자 권한 관리기]
                         |
                [데이터 계보 저장소]
                         |
                  [격리 데이터셋]
                         |
                   [버전 저장소]
                         |
                    [기준 평가기]
```

선의 의미: 기여자 권한과 데이터 계보가 격리 데이터셋 및 버전 저장소의 변경 경계를 통제하고, 기준 평가기가 승인 후보의 행동을 검증하는 구조를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 기여자 권한 관리기 | 샘플•라벨 수정 주체와 범위 통제 |
| 데이터 계보 저장소 | 샘플 출처•시점•변환 이력 보관 |
| 격리 데이터셋 | 신규•의심 샘플과 승인 자료 분리 |
| 버전 저장소 | 승인 데이터셋•모델 버전 관리 |
| 기준 평가기 | 정상•표적•백도어 행동 대조 |

#### 한줄 요약

- 누가 어떤 재료를 언제 넣었는지 기록하고 새 재료는 격리해 검사한 뒤 검증된 데이터와 모델 버전을 함께 보관한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **승격 판정**: 데이터와 후보 모델이 검증 기준을 통과해 운영 버전으로 배포될 수 있는지 결정하는 과정이다.
- **출처 검증**: 표본의 제공 주체•시점•변환 경로가 승인 정책과 일치하는지 확인하는 활동이다.

</details>

```text
공격자•기여자
   │ 1. 악성 표본•라벨•비중 조작
   ▼
학습 데이터 저장소
   │ 2. 오염 학습 배치 유입
   ▼
학습 파이프라인
   │ 3. 결정 경계•행동 왜곡 학습
   ▼
오염 모델 ◀── 4. 정상•표적•트리거 입력 ── 공격자
   └── 5. 성능 저하•표적 오판•백도어 발동 ──▶ 피해 대상
```

1. **악성 표본•라벨•비중 조작**: 학습 분포와 정답 관계 변형
2. **오염 학습 배치 유입**: 검수•계보 경계를 우회해 자료 포함
3. **결정 경계•행동 왜곡 학습**: 오염 영향이 모델 파라미터에 반영
4. **정상•표적•트리거 입력**: 공격 목적에 맞는 조건 제시
5. **성능 저하•표적 오판•백도어 발동**: 지속적 모델 피해 발생

#### 한줄 요약

- 오염 자료가 학습에 반영되면 정상 성능•표적 판단•트리거 행동이 왜곡된다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **클린 라벨 오염**: 라벨은 정상으로 유지하면서 입력 특징을 조작해 모델 경계를 왜곡하는 공격이다.
- **트리거 성공률**: 트리거 입력 가운데 공격자가 의도한 행동을 유발한 비율이다.

</details>

은닉 방식: **클린 라벨 오염**, 백도어 측정 지표: **트리거 성공률**

| 데이터 오염 공격 목적 | 가용성 오염 | 표적 무결성 오염 | 백도어 오염 |
|:---|:---|:---|:---|
| 적용 기준 | 정상 평가셋의 **성능 검사** | 표적 조각의 **오류 검사** | **트리거 성공률** 검사 |
| 핵심 특징 | 전체 **예측 성능 저하** | 특정 입력•**집단 오판** | 트리거에서 **지정 행동** |
| 한계 | 서비스 **품질 붕괴** | 평균 지표에 **오류 은닉** | 정상 성능으로 **탐지 회피** |

#### 한줄 요약

- 가용성 오염은 전체 성능을 낮추고 표적 오염은 일부만 틀리게 하며 백도어는 트리거에서만 오답을 낸다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **표본 비중 급증**: 특정 기여자의 데이터가 학습 분포를 지배하도록 과도하게 늘어나는 문제이다.
- **은닉 변조**: 라벨이나 표면 형식은 정상처럼 보이지만 특징과 학습 영향이 악의적으로 바뀐 문제이다.
- **표적 오류 은닉**: 평균 성능에는 드러나지 않고 특정 입력•집단•트리거에서만 오판하는 문제이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 특정 기여자의 **표본 비중 급증** | 기여자별 **표본 비중•쓰기 권한** 제한 | **분포 조작 영향** 축소 |
| 라벨•특징의 **은닉 변조** | 계보 기반 **격리 전후 모델 비교** | **클린 라벨 오염** 탐지 |
| 평균 성능에 **표적 오류 은닉** | 정상•표적•트리거 **행동 평가셋** 분리 | **국소 오판** 식별 |

#### 한줄 요약

- 신고 출처와 계보를 확인하고 의심 데이터를 뺀 모델과 비교해 오염 영향을 판정한다

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **격리 전후 행동 변화**: 의심 데이터를 포함하거나 제외해 학습한 모델 사이의 정상•표적 성능 차이이다.
- **검증 데이터 재학습**: 출처와 무결성이 확인된 데이터만 사용해 손상 모델을 새로 만드는 복구 방식이다.

</details>

- **데이터 계보•기여량•격리 전후 행동 변화**로 오염을 판정하고 검증 데이터로 재학습

#### 한줄 요약

- 학습 자료의 변경 권한과 기록을 관리하고 새 모델이 이상하면 검증된 데이터와 모델로 되돌려야 한다.
