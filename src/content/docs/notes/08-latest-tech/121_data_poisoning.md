## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **데이터 오염(Data Poisoning)**: AI 학습 데이터 셋에 악의적 조작 데이터를 주입하여 모델의 판단 기준을 왜곡시키고, 무결성을 훼손하는 적대적 공격
- **학습 파이프라인 공격(Training Pipeline Attack)**: 추론 단계가 아닌 데이터 수집, 정제, 학습 등 파이프라인 과정에 개입하여 모델 행동을 변조하는 핵심 보안 위협
</details>

- **정의**: 모델 학습 데이터의 표본, 라벨, 분포를 의도적으로 조작하여 오판을 유도하는 적대적 학습 방해 기법
- **배경**: 입력값 검증만으로는 학습 데이터 내부에 잠재된 논리적 오류나 백도어 탐지 불가능

#### 한줄 요약

- 학습 데이터셋의 조작을 통해 모델의 판단 성능을 의도적으로 저하시키거나 특정 상황에서 오작동을 유발하는 보안 위협

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **가용성 오염(Availability Poisoning)**: 모델 전체의 예측 정확도를 하락시켜 정상 서비스를 불가능하게 만드는 공격
- **표적 무결성 오염(Targeted Integrity Poisoning)**: 특정 입력값이나 집단에 대해서만 의도적 오판을 유도하는 공격
- **백도어 오염(Backdoor Poisoning)**: 특정 트리거 패턴이 입력될 때만 공격자가 설정한 행동을 수행하도록 학습시키는 공격
</details>

- **가용성 저하**: 전체 모델의 신뢰도 및 예측 성능 저하
- **표적 왜곡**: 공격자가 설정한 특정 데이터 패턴에 대해 의도적 오판 발생
- **트리거 백도어**: 특정 트리거 결합 시에만 오작동을 유발하여 탐지 회피

#### 한줄 요약

- 공격 목적에 따라 전체 성능 저하, 특정 타겟 오판, 백도어 트리거 발동으로 구분되는 학습 데이터 변조 기법

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **데이터 계보(Data Lineage)**: 표본의 출처, 변환 이력, 승인 경로를 추적하는 데이터 관리 체계
- **격리 데이터셋(Isolated Dataset)**: 신규 수집된 의심 표본을 검증 전까지 승인된 학습 데이터와 분리 저장하는 공간
- **기준 평가기(Baseline Evaluator)**: 모델 행동의 정상성, 표적 오판, 백도어 발동 여부를 고정된 검증셋으로 판별하는 구성요소
</details>

```text
                 [기여자 권한 관리기]
                          |
                 [데이터 계보 저장소]
                          |
                   [격리 데이터셋]
                          |
                    [버전 저장소]
                          |
                     [기준 평가기]
```

- **기여자 관리**: 데이터 기여자의 수정 범위 및 권한 통제
- **검증 체계**: 신규 데이터의 격리 저장 및 변경 이력 관리

| 구성요소 | 책임 |
|:---|:---|
| 기여자 권한 관리기 | 데이터 수정 주체 및 범위 제어 |
| 데이터 계보 저장소 | 표본 출처 및 변환 이력 기록 |
| 격리 데이터셋 | 미검증 샘플과 승인 자료의 격리 |
| 버전 저장소 | 승인된 데이터셋 및 모델 버전 관리 |
| 기준 평가기 | 정상 행동 및 트리거 발동 검증 |

#### 한줄 요약

- 데이터 기여자 관리, 계보 추적, 데이터 격리 및 모델 버전 관리 체계를 통해 데이터 무결성을 보장하는 구조

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **승격 판정(Promotion Decision)**: 검증된 데이터와 모델이 운영 배포 요건을 충족하는지 결정하는 승인 과정
- **출처 검증(Provenance Validation)**: 데이터 제공자의 신뢰성 및 데이터 처리 경로의 정당성 확인
</details>

```text
공격자/기여자
   │ 1. 악성 표본/라벨/비중 조작
   ▼
학습 데이터 저장소
   │ 2. 오염 학습 배치 유입
   ▼
학습 파이프라인
   │ 3. 결정 경계/행동 왜곡 학습
   ▼
오염 모델 ◀── 4. 정상/표적/트리거 입력 ── 공격자
   └── 5. 성능 저하/표적 오판/백도어 발동 ──▶ 피해 대상
```

- **오염 주입**: 공격자가 라벨 조작 등으로 학습 데이터 오염
- **학습 반영**: 왜곡된 분포가 모델 파라미터로 전이
- **피해 발생**: 정상적 입력 대비 표적 오판 및 백도어 발동

#### 한줄 요약

- 악의적 데이터 주입을 통해 학습 파이프라인의 결정 경계를 왜곡하여 모델의 비정상적 행동을 유발하는 절차

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **클린 라벨 오염(Clean-label Poisoning)**: 라벨은 정상으로 유지하며 데이터 특징만 미세하게 조작하여 탐지를 우회하는 공격
- **트리거 성공률(Trigger Success Rate)**: 백도어 공격에서 특정 트리거 입력 시 공격 성공 확률
</details>

- **분류**: 공격 목적에 따라 가용성, 표적 무결성, 백도어 공격으로 분류
- **차별점**: 전체 성능 영향도 및 트리거 여부에 따른 구분

| 공격 목적 | 가용성 오염 | 표적 무결성 오염 | 백도어 오염 |
|:---|:---|:---|:---|
| 평가 기준 | 전체 예측 성능 | 표적 구간 오류 | 트리거 성공률 |
| 핵심 특징 | 전반적 예측 성능 저하 | 특정 집단 오판 유도 | 특정 트리거 시 발동 |
| 탐지 한계 | 서비스 품질 붕괴 | 평균 지표에 은닉 | 정상 성능 기반 탐지 회피 |

#### 한줄 요약

- 전체 모델 성능을 떨어뜨리는 가용성 공격과 특정 타겟 혹은 트리거 기반으로 오작동을 유도하는 정교한 공격으로 구분

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **표본 비중 급증(Sample Weight Explosion)**: 특정 데이터셋이 학습 분포를 지배하여 모델 편향을 유도하는 문제
- **은닉 변조(Stealthy Modification)**: 외관상 정상적인 데이터로 보이나 학습 결과에 치명적 영향을 주는 변조
</details>

- **대책**: 기여자별 데이터 입력 비중 제한 및 학습 전후 모델 행동 비교

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 특정 기여자 비중 급증 | 기여자별 샘플 비중 제한 | 데이터 분포 편향 축소 |
| 라벨/특징 은닉 변조 | 계보 기반 격리 전후 비교 | 클린 라벨 오염 탐지 |
| 표적 오류 은닉 | 행동 평가셋 분리 관리 | 국소적 오판 식별 |

#### 한줄 요약

- 데이터 입력 기여자에 대한 통제와 격리된 환경에서의 모델 행동 분석을 통한 데이터 검증 프로세스 구축

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **격리 전후 행동 변화(Behavioral Delta Analysis)**: 오염 가능성 데이터 포함 여부에 따른 모델 출력 차이 분석
- **검증 데이터 재학습(Verified Retraining)**: 무결성이 입증된 안전한 데이터셋으로 모델을 다시 학습시키는 복구 방안
</details>

- 데이터 계보 추적, 학습 파이프라인 권한 분리, 검증 데이터 재학습 필수 적용

#### 한줄 요약

- 학습 데이터의 전 생애주기 무결성 보장 및 모델 학습 과정의 투명성 확보 체계 적용
