## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **현장 프로그래머블 게이트 배열(Field-Programmable Gate Array, FPGA)**: 제조 후에도 논리•배선을 재구성하는 반도체을 의미한다.
- **인공지능(Artificial Intelligence, AI)**: 학습한 모델로 인식•추론 작업을 수행하는 기술을 의미한다.
- **결정적 지연**: 같은 조건에서 처리 시간이 예측 가능한 상한 안에 유지되는 특성로 정의된다.

</details>

- 정의/개념: FPGA의 재구성 논리•배선으로 AI 데이터 경로를 구현하는 **하드웨어 가속 방식**임.
- 배경/필요성: 범용 가속기의 **맞춤 데이터경로•결정적 지연** 확보 한계가 발생함.

#### 한줄 요약

- 소프트웨어 명령어로 연산을 지시하는 대신 논리 블록과 배선 자체를 재구성해 데이터가 연속 처리되는 공간 파이프라인을 구현하는 하드웨어 가속 방식이 핵심이다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **비트스트림(Bitstream)**: FPGA의 논리•배선•메모리 구성을 장치에 적재하는 설정 데이터이다.
- **공간 파이프라인**: 연산 단계를 서로 다른 회로 블록에 동시에 배치해 데이터를 연속 처리하는 구조을 말한다.

</details>

- **재구성 축**: 비트스트림 기반 논리•배선 변경함.
- **실행 축**: 연산 단계 동시 배치의 공간 파이프라인임.
- **설계 축**: 데이터경로 맞춤화로 지연은 감소하나 구현 복잡성 증가함.

#### 한줄 요약

- FPGA는 비트스트림으로 데이터 경로를 재구성할 수 있지만 합성•배치•타이밍 검증에 개발 시간이 소요됨이 핵심이다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **룩업 테이블(Look-Up Table, LUT)**: 논리 함수를 구현하는 FPGA 기본 블록을 의미한다.
- **디지털 신호처리(Digital Signal Processing, DSP) 블록**: 곱셈•누산을 수행하는 전용 회로이다.
- **블록 메모리(Block RAM, BRAM)**: FPGA 내부에서 가중치와 중간 데이터를 보관하는 재구성 가능한 메모리이다.

</details>

LUT, DSP 블록, BRAM을 조합해 맞춤 데이터 경로를 구성한다.

```text
[재구성 로직]---[곱셈•누산 블록]---[온칩 메모리]
      |                    |                |
      +------------[외부 인터페이스]--------+
      |
  [구현 도구]
```

선의 의미: 재구성 로직이 곱셈•누산 블록, 온칩 메모리, 외부 인터페이스를 맞춤 데이터 경로로 결합하고, 구현 도구가 회로 구성 경계를 정의한다.

| 구성요소 | 책임 |
|:---|:---|
| 재구성 로직 | **LUT 기반 연산•제어 경로** 구성 |
| 곱셈•누산 블록 | **DSP 병렬 곱셈•누산** 처리 |
| 온칩 메모리 | **BRAM 가중치•라인 버퍼** 저장 |
| 외부 인터페이스 | **데이터 스트림•호스트** 연결 |
| 구현 도구 | **비트스트림 합성•배치•배선** 변환 |

#### 한줄 요약

- 구현 도구가 DSP 블록•BRAM•논리 블록을 연결하면 외부 입력이 정해진 순서로 흐르는 공간 파이프라인이 구성됨이 핵심이다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **합성**: 설계한 연산과 제어 논리를 FPGA의 LUT•DSP•메모리 자원으로 변환하는 과정을 의미한다.
- **타이밍 검증**: 배치•배선된 신호가 정한 클록 주기 안에 도착하는지 확인하는 절차로 정의된다.

</details>

```text
워크로드 설계자 ── 데이터경로•정밀도 ──▶ 구현•타이밍 검증 도구
구현•타이밍 검증 도구
   │ 1. 합성•배치•타이밍 검증
   │ 2. 타이밍 충족 설계 확정
   │ 3. 검증된 비트스트림 적재
   ▼
FPGA ◀── 입력 스트림 ── 외부 인터페이스
FPGA ── 파이프라인 결과 ──▶ 외부 인터페이스
```

1. **합성•배치•타이밍 검증**: 논리 변환•클록 제약을 판정함.
2. **타이밍 충족 설계 확정**: 자원•경로 제약을 만족한 설계를 확정함.
3. **검증된 비트스트림 적재**: 회로 구성을 FPGA에 반영함.

#### 한줄 요약

- 연산 구조와 자료형 정밀도를 정하고 회로로 합성한 뒤 모든 신호가 클록 제약 안에 도달하는지 확인해야 비트스트림을 FPGA에 적재할 수 있다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **그래픽 처리장치(Graphics Processing Unit, GPU)**: 소프트웨어 커널로 다양한 병렬 연산을 실행하는 범용 가속기을 의미한다.
- **주문형 집적회로(Application-Specific Integrated Circuit, ASIC)**: 특정 연산과 데이터 경로를 제조할 때 고정한 전용 반도체로 정의된다.

</details>

FPGA, GPU, ASIC는 변경 주기와 효율이 다르다.

| 가속기 | FPGA | GPU | ASIC |
|:---|:---|:---|:---|
| 적용 기준 | **재구성•결정적 지연** | **잦은 모델•연산 변경** | **안정된 대량 워크로드** |
| 핵심 특징 | **비트스트림 회로 재구성** | **소프트웨어 병렬 커널** | **제조 시 데이터경로 고정** |
| 한계 | **합성•타이밍 개발 복잡** | **전력•분기 오버헤드** | **높은 초기비•변경 불가** |

> 요약: 그래픽 처리장치는 **범용 변경**, 현장 프로그래머블 게이트 배열은 **회로 재구성**, 주문형 집적회로는 **고정**이 핵심이다.

#### 한줄 요약

- GPU는 소프트웨어 커널을 변경하고, FPGA는 비트스트림으로 회로를 재구성하며, ASIC은 제조 시 데이터 경로를 고정하는 것이 핵심이다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **배치•배선**: 논리 블록을 물리 위치에 놓고 신호 경로를 연결하는 FPGA 구현 단계을 말한다.
- **클록 제약**: 회로가 충족해야 하는 동작 주기와 신호 도착 시간을 정한 조건로 정의된다.

</details>

LUT•DSP•BRAM 자원 예산과 FPGA 타이밍을 함께 검증한다.

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 자원 초과로 **배치•배선 실패** | LUT•DSP•BRAM 예산 기반 설계 탐색 | 비트스트림 **구현 가능성** 확보 |
| 긴 조합 경로로 **타이밍 위반** | 파이프 단계 추가•클록 제약 검증 | 결정적 **처리 지연** 확보 |

#### 한줄 요약

- 보안 장비는 패킷 검사 단계를 공간 파이프라인으로 배치하고, 비전 장비는 반복 곱셈과 영상 데이터를 칩 내부에 배치하는 것이 핵심이다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **재구성성**: 제조 뒤에도 비트스트림을 바꾸어 회로 기능과 데이터 경로를 변경할 수 있는 성질이다.
- **구현 복잡성**: 회로 설계•합성•배치•배선•타이밍 검증에 필요한 개발 부담이다.

</details>

- **재구성성•구현 복잡성**으로 GPU와 FPGA을 선택함.

#### 한줄 요약

- 데이터 경로를 재구성하면서 결정적 지연이 필요하면 FPGA, 모델이 자주 변하면 GPU, 연산이 장기 고정되면 ASIC이 적합함이 핵심이다.
