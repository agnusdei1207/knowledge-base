## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **연합학습(Federated Learning, FL)**: 원본 대신 로컬 업데이트를 집계하는 분산 학습이다.
- **데이터 주권(Data Sovereignty)**: 소유자가 저장 위치•접근•처리를 통제하는 권리이다.

</details>

- 정의: 원본 대신 로컬 업데이트를 집계하는 **연합학습**
- 배경/필요성: 병원, 금융기관, 모바일 엣지 단말 등에 분산된 방대한 고가치 데이터는 개인정보보호법(GDPR, PIPA), 데이터 주권 및 기업 기밀 규제로 인해 단일 중앙 서버로 통합 수집하는 것이 법적·물리적으로 불가능하여 데이터 사일로(Data Silo)가 심화되고 AI 성능 확장이 가로막히는 한계에 직면함에 따라, 원본 원천 데이터는 각 로컬 디바이스/기관에 격리 유지한 채 로컬에서 모델을 학습시키고 파라미터 업데이트(Gradient, Weight)만을 중앙 서버로 전송하여 가중 평균하는 연합학습(Federated Learning: FL / FedAvg, FedProx / Cross-device & Cross-silo / non-IID Mitigation, Secure Aggregation) 패러다임을 도입하여 **민감 원본 데이터의 외부 반출 없는 분산 협업 머신러닝 생태계 구축, 전송 대역폭 오버헤드 대폭 절감 및 데이터 주권 보장, 비독립 동일분포(non-IID) 데이터 편차 극복과 글로벌 모델의 일반화 성능 극대화**를 달성할 필요

#### 한줄 요약
- 원본은 보관하고 **로컬 업데이트**만 집계해 공동 모델 학습

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **연합 평균(Federated Averaging, FedAvg)**: 데이터 수에 비례해 로컬 변화량을 가중 평균한다.
- **비독립•비동일분포(non-IID)**: 참여자별 클래스•특징•표본 분포가 다른 상태이다.
- **참여 이탈(Client Dropout)**: 선택 클라이언트가 업데이트를 제출하지 못한 상태이다.

</details>

- 원본 비이동과 **로컬 학습•업데이트 집계 분리**
- 참여 데이터량 기반 **FedAvg 가중 집계**
- **non-IID•참여 이탈**에 따른 편향•수렴 변동

#### 한줄 요약
- **원본 비이동•FedAvg**와 non-IID•참여 이탈 결합

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **참여 클라이언트(Participant Client)**: 원본을 보유하고 로컬 학습한다.
- **로컬 학습기(Local Trainer)**: 원본으로 파라미터•기울기 변화량을 계산한다.
- **로컬 업데이트(Local Update)**: 참여자가 계산한 모델 변화량이다.
- **집계•보호기**: 업데이트 집계•이상치•프라이버시 통제를 적용한다.
- **글로벌 모델(Global Model)**: 보호된 업데이트를 집계해 갱신한 공동 모델이다.

</details>

```text
                        [연합 조정자]
                       /             \
             [글로벌 모델 저장소]  [집계•보호기]
                       \             /
                    [참여 클라이언트]
                              |
                        [로컬 학습기]
```

선의 의미: 조정자 아래 글로벌 모델•집계기•클라이언트•학습기를 연결한 구조

| 구성요소 | 책임 |
|:---|:---|
| 연합 조정자 | 참여자 선택•라운드•학습 설정의 **실행 통제** |
| 참여 클라이언트 | 원본 데이터 보관과 **로컬 학습 실행** |
| 글로벌 모델 저장소 | 라운드별 공통 모델의 **버전 보관•배포** |
| 로컬 학습기 | 참여자 데이터 기반 **모델 업데이트 계산** |
| 집계•보호기 | **FedAvg•보안 집계** 기반 공동 모델 갱신 |

#### 한줄 요약
- **조정자•글로벌 모델**과 클라이언트•로컬 학습•집계 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **학습 계약(Training Contract)**: 시작 모델•반복•학습률•제출 조건이다.
- **연합 라운드(Federated Round)**: 모델 배포•로컬 학습•집계•갱신의 반복 주기이다.

</details>

```text
연합 조정•글로벌 모델
   │ 1. 참여자•모델 버전 확정
┌──────────── 수렴 조건까지 라운드 반복 ────────────┐
│ 연합 조정 ── 2. 글로벌 모델•학습 설정 배포 ──▶ 참여 클라이언트
│ 참여 클라이언트 ── 3. 로컬 학습 요청 ──▶ 로컬 학습기
│ 로컬 학습기 ── 4. 보호된 업데이트 전달 ──▶ 집계•보호기
│ 연합 조정 ◀─ 5. 글로벌 모델 갱신 ── 집계•보호기
└───────────────────────────────────────────────────┘
```

### 동작 원리

1. 참여자•모델 버전 확정: 가용성•정책에 맞는 **라운드 참여 집합** 확정
2. 글로벌 모델•학습 설정 배포: 시작 모델•학습률의 **학습 계약** 전달
3. 로컬 학습 요청: 원본 기반의 **참여자별 변화량** 계산 지시
4. 보호된 업데이트 전달: 원본 대신 **로컬 모델 변화량** 제공
5. 글로벌 모델 갱신: 가중 평균•보안 집계로 **새 모델** 생성

#### 한줄 요약
- **모델 배포•로컬 학습** 후 참여자 보호 집계•갱신 수행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **교차 기기 연합학습(Cross-device FL)**: 다수 개인 단말이 불규칙하게 참여한다.
- **교차 사일로 연합학습(Cross-silo FL)**: 소수 기관이 안정적으로 협업한다.
- **중앙집중 학습(Centralized Learning)**: 원본을 한곳에 모아 학습한다.

</details>

| 구분 | 중앙집중 학습 | 교차 기기 연합학습 | 교차 사일로 연합학습 |
|:---|:---|:---|:---|
| 적용 기준 | 원본 중앙 수집 가능 | 다수 개인 단말 참여 | 소수 기관 데이터 주권 |
| 핵심 특징 | 중앙 데이터의 **일괄 학습** | 불규칙 단말의 **부분 참여** | 인증 기관의 **안정적 협업** |
| 한계 | 원본 집중•주권 제약 | 이탈•통신•자원 편차 | 기관별 **non-IID•합의 비용** |

#### 한줄 요약
- **원본 중앙 수집•다수 단말**과 소수 기관에 따라 구조 구분

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **업데이트 충돌(Update Conflict)**: non-IID로 변화량의 최적 방향이 다른 문제이다.
- **보안 집계(Secure Aggregation)**: 개별 업데이트를 숨기고 합계만 공개한다.
- **강건 집계(Robust Aggregation)**: 비정상•악성 업데이트 영향을 제한한다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| non-IID 데이터의 업데이트 충돌 | 참여자별 성능 평가•개인화 계층•집계 가중 조정 | 전역•지역 품질 **균형 개선** |
| 교차 기기의 참여 이탈•지연 | 기한 내 업데이트만 집계•비동기 참여 정책 | 라운드 정체 **완화** |
| 로컬 업데이트의 정보 누출•중독 | 보안 집계와 강건 집계•이상 업데이트 제한 | 기밀성•모델 무결성 **보완** |

#### 한줄 요약
- **non-IID•참여 이탈**과 정보 누출•모델 중독 검증

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **참여 안정성(Participation Stability)**: 참여자가 시간•자원 안에 업데이트를 제출하는 정도이다.
- **집계 정책(Aggregation Policy)**: 선택•가중치•이상치•이탈을 반영한 갱신 규칙이다.

</details>

- 데이터 프라이버시 규제와 데이터 주권 시대에 원본 이동 없이 다기관·이기종 디바이스 간 협업 학습을 실현하는 **차세대 분산 인공지능 및 프라이버시 보존 머신러닝의 최고 핵심 패러다임(Federated Learning / FedAvg & FedProx / Cross-Device & Cross-Silo Architecture / non-IID & Client Drift Mitigation / SecAgg & DP-FL Integration / Sovereign Data Collaboration)의 확고한 표준**으로 확고히 자리 잡았으며, 온디바이스 AI 및 엣지-클라우드 협력 지능으로 급속히 확장되는 가운데, 실무 연합학습 플랫폼 구축 시에는 **참여자별 데이터 이질성을 완화하는 FedProx 근접항 및 개인화 연합학습(pFL)을 적용하고, 비정상 클라이언트 이탈(Dropout)에 대응하는 비동기 집계 정책을 수립하며, 역추론 공격을 방어하기 위해 보안 집계(SecAgg)와 차등 프라이버시(DP-SGD)를 결합한 복합 다층 방어**를 결합하여 완벽한 데이터 기밀성과 고품질 글로벌 모델 수렴성을 완성

#### 한줄 요약
- **데이터 주권•참여 안정성**과 non-IID에 따라 구조•집계 결정
