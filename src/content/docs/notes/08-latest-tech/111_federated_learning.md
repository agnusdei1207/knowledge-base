## 미리 알고가기

- 연합학습(Federated Learning): 원본을 모으지 않고 로컬 업데이트를 공동 집계함
- 연합 평균(Federated Averaging, FedAvg): 로컬 업데이트를 데이터량으로 가중 집계함
- 비독립 동일분포(Non-Independent and Identically Distributed, non-IID): 참여자 데이터 분포가 서로 다름
- 보안 집계(Secure Aggregation): 개별 업데이트 대신 합산값만 공개함



## Ⅰ. 개요

- 정의/개념: 원본 없이 로컬 업데이트를 집계하는 학습
- **배경/필요성**: 데이터 반출 없이 여러 참여자의 모델 협업

### 쉽게 이해하기 (학습용)

- 각 참여자가 데이터를 보관한 채 학습한 변화량만 모아 공통 모델을 갱신합니다.

## Ⅱ. 특징

- 중앙 조정형과 참여자 합의형으로 집계 구조를 나눈다.
- 교차기기는 다수 단말, 교차사일로는 소수 기관이 참여한다.
- 비동질 데이터는 업데이트 충돌과 성능 편차를 키운다.
- 원본 비이동만으로 누출·중독을 막을 수 없다.

### 쉽게 이해하기 (학습용)

- 참여자의 데이터 분포와 통신 속도가 다르면 업데이트가 충돌하고 학습이 지연될 수 있습니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 조정자·집계 토폴로지 | 중앙 서버 또는 참여자 간 분산 집계의 제어 구조 |
| 참여 클라이언트 | 로컬 데이터·학습 자원·통신 상태를 가진 기기·기관 |
| 글로벌 모델 상태 | 라운드마다 참여자에게 배포하고 집계로 갱신할 공통 파라미터 |
| 로컬 학습 설정 | 로컬 반복 횟수·배치·학습률과 업데이트 형식 |
| 집계·보호 정책 | 데이터량 가중 평균, 참여 기준, 보안·강건 집계 규칙 |

### 쉽게 이해하기 (학습용)

- 조정자·참여자·공통 모델·로컬 학습·집계 보호 규칙을 함께 정해야 합니다.

## Ⅳ. 원리 및 절차 흐름도

```text
모델선택
  ↓
모델배포
  ↓
로컬학습
  ↓
집계수행
  ↓
결과평가
  ↓
반복여부
```

| 절차 | 설명 |
|:---|:---|
| 모델선택 | 조정자가 버전과 가용 참여자를 선택함 |
| 모델배포 | 선택 참여자에게 모델과 학습설정 전달함 |
| 로컬학습 | 로컬 데이터로 학습해 업데이트 계산함 |
| 집계수행 | 데이터량에 따라 업데이트를 가중평균함 |
| 결과평가 | 모델을 평가해 목표·예산·위험을 판정함 |

- 로컬 변화량을 가중 합산해 새 모델을 배포하거나 중단함

### 쉽게 이해하기 (학습용)

- 로컬 업데이트를 가중 집계해 새 모델을 평가하고 목표·위험 기준에 따라 반복하거나 중단합니다.

## Ⅴ. 종류 및 비교

| 적용 기준 | 중앙집중 | 교차기기 | 교차사일로 |
|:---|:---|:---|:---|
| 데이터 구조 | 원본 중앙 수집 | 다수 기기 참여 | 소수 기관 참여 |
| 운영 조건 | 중앙 접근 관리 | 단말 이탈 처리 | 인증·분포 합의 |
| 적합 모델 | 원본 수집 가능 | 대규모 개인단말 | 기관별 주권유지 |

> 요약: 참여 규모와 데이터 주권에 따른 학습 구조를 선택함

### 쉽게 이해하기 (학습용)

- 중앙 수집, 다수 개인 단말, 소수 기관 협업은 참여 규모와 데이터 통제권이 다릅니다.

## Ⅵ. 실무 사례

- 입력 업데이트는 보안 집계로 개별 노출을 줄인다.

### 쉽게 이해하기 (학습용)

- 전체 평균뿐 아니라 참여 기관별 성능을 확인해 특정 데이터 분포에서 생기는 성능 저하를 찾습니다.

## Ⅶ. 결론

- 규모와 주권에 맞춰 구조를 선택하고 비동질성을 통제함

### 쉽게 이해하기 (학습용)

- 참여자 차이와 느린 통신, 악성 업데이트를 관리해야 원본 비이동의 장점을 실제 보호와 성능으로 이어 갈 수 있습니다.
