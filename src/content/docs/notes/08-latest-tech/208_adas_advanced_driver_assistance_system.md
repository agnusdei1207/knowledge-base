## 미리 알고가기

- **ADAS (Advanced Driver Assistance System) 기능**: 운전자의 인지·판단·제어를 보조하는 안전 시스템
- **AEB (Autonomous Emergency Braking) 시스템**: 전방 충돌 방지용 자동 긴급 제동
- **ACC (Adaptive Cruise Control) 기술**: 주행 속도 및 차간 거리 유지 제어
- **LKA (Lane Keeping Assist) 기능**: 차선 유지 및 이탈 방지 조향 보조
- **DMS (Driver Monitoring System) 센서**: 운전자의 주의 상태 및 참여 감시
- **HMI (Human-Machine Interface) 소통**: 차량 시스템과 운전자 간 정보 전달 체계



## Ⅰ. 개요

- **정의/개념**: 운전자에게 경고·조향·가감속을 보조하는 기능
- **배경/필요성**: 운전 실수와 인지 한계로 인한 사고를 완화

### 쉽게 이해하기 (학습용)

- 시스템이 도움을 주어도 주변을 보고 위험에 대응하는 주체는 사람임

## Ⅱ. 특징

- 센서 융합이 차선·차량·보행자 위험을 인지한다.
- L0·L1·L2가 지속 제어 범위를 구분한다.
- 운전자가 환경 감시와 최종 대응을 유지한다.
- DMS·HMI가 참여 상태와 기능 한계를 알린다.

### 쉽게 이해하기 (학습용)

- L1은 조향·가감속 중 하나를, L2는 둘을 지원하지만 위험 대응은 운전자의 몫임

## Ⅲ. 아키텍처 및 구성요소

```text
[ADAS Control]
├─ input: [Road·Vehicle Sensors]
├─ decision: [Perception·Risk Logic]
├─ action: [Warning·Limited Control]
├─ human: [Driver Input·DMS·HMI]
└─ guard: [Safety·Health Supervisor]
```

| 설계 요소 | 설명 |
|:---|:---|
| 센서·상태 추정 | 도로·차량·운전자 상태를 추정함 |
| 위험 판단·기능 로직 | 작동 조건과 위험을 판단함 |
| 조향·가감속 실행 | 제한된 축의 제어를 수행함 |
| DMS·HMI | 운전자 참여를 감시하고 한계를 알림 |
| 안전 감독·진단 | 고장 시 경고·축소·해제를 수행함 |

> 요약: 제한적 보조·운전자 감시·안전 해제를 결합

### 쉽게 이해하기 (학습용)

- 위험 감시 회로 옆에 운전자 참여와 센서 상태를 확인하는 감시 회로가 있음

## Ⅳ. 원리 및 절차 흐름도

```text
[환경·상태 수집]
       ↓
[운용 조건 판정]
       ↓
[보조 기능 실행]
       ↓
[운전자 감시]
       ↓
[제어 반환]
```

| 절차 | 설명 |
|:---|:---|
| 1. 환경·상태 수집 | 1. 환경·상태 수집을 수행하고 결과를 검증함 |
| 2. 기능 운용 조건 확인 | 2. 기능 운용 조건 확인을 수행하고 결과를 검증함 |
| 3. 위험·목표 계산 | 3. 위험·목표 계산을 수행하고 결과를 검증함 |
| 4. 경고·보조 실행 | 4. 경고·보조 실행을 수행하고 결과를 검증함 |
| 5. 운전자·시스템 감시 | 5. 운전자·시스템 감시을 수행하고 결과를 검증함 |
| 6. 해제·검증 | 6. 해제·검증을 수행하고 결과를 검증함 |

> 요약: 작동 조건 확인 후 지원하고 개입 시 제어 반환

### 쉽게 이해하기 (학습용)

- 보조 가능 상태를 확인하고 운전자 개입이나 센서 저하 시 도움을 줄이고 끔

## Ⅴ. 종류 및 비교

| 판단 기준 | SAE L0 | SAE L1 | SAE L2 |
|:---|:---|:---|:---|
| 핵심 특징 | 경고하거나 조향·제동을 순간 개입하며 지속 제어하지 않음 | 조향 또는 가감속 한 축을 지속 지원함 | 조향과 가감속 두 축을 동시에 지속 지원함 |
| 적용 기준 | 전체 DDT와 OEDR을 수행함 | 나머지 제어와 전체 OEDR·감독을 수행함 | 시스템을 계속 감독하고 전체 OEDR·fallback을 수행함 |
| 주요 위험 | AEB·사각지대 경고·순간 LKA이며 자동주행이 아님 | ACC 또는 차로 중앙 유지 중 하나이며 복합 제어가 아님 | 고속도로 주행 보조 등이며 전방주시 해제나 ADS가 아님 |

> 요약: 지속 제어 축과 운전자 역할로 단계를 구분

### 쉽게 이해하기 (학습용)

- L2 단계에서도 운전자는 감독관으로서 잘못된 동작을 즉시 고쳐야 함

## Ⅵ. 실무 사례

1. **고속도로 L2 조향·가감속 지원**

- **상황**: 운영 병목·위험과 영향 범위를 식별함
- **적용**: 주제별 통제·절차를 대상 환경에 적용함
- **검증**: 성능·품질·위험 지표로 효과를 확인함

2. **악천후 자동 긴급 제동·차로 보조**

- **상황**: 운영 병목·위험과 영향 범위를 식별함
- **적용**: 주제별 통제·절차를 대상 환경에 적용함
- **검증**: 성능·품질·위험 지표로 효과를 확인함

### 쉽게 이해하기 (학습용)

- 고속도로 L2 조향·가감속 지원
- 악천후 자동 긴급 제동·차로 보조

## Ⅶ. 결론

### 쉽게 이해하기 (학습용)
