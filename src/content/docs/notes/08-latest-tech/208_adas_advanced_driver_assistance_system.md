## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **첨단 운전자 지원 시스템(Advanced Driver Assistance System, ADAS)**: 환경과 운전자 상태를 인지해 경고•조향•가감속으로 운전자의 주행 과업을 보조하는 시스템이다.

</details>

- 정의: 환경•운전자 상태를 인지해 경고•조향•가감속을 보조하는 **ADAS**
- 배경/필요성: 운전자 보조 기능 확대로 **기능 한계•감독 책임 혼동** 위험 증가

#### 한줄 요약

- 환경•운전자 인지 기반 경고•제어 보조와 감독 책임을 유지한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **운전자 모니터링 시스템(Driver Monitoring System, DMS)**: 운전자의 주의•졸음•응답 상태를 확인해 감독 가능성을 판단하는 시스템이다.
- **국제자동차기술자협회(Society of Automotive Engineers International, SAE International)**: 자동차 기술 표준을 개발하는 국제 전문 단체이다.
- **자동 긴급 제동(Automatic Emergency Braking, AEB)**: 충돌 위험 시 자동으로 제동하는 기능이다.
- **적응형 순항 제어(Adaptive Cruise Control, ACC)**: 선행 차량과 간격을 유지하며 속도를 조절하는 기능이다.
- **차로 유지 보조(Lane Keeping Assist, LKA)**: 차량이 차로를 벗어나지 않도록 조향을 보조하는 기능이다.

</details>

- 다중 센서 융합 기반 **객체•차선 인지**와 충돌 위험 판단
- SAE Level 0~2의 AEB•ACC•LKA **종•횡방향 보조**
- DMS•센서 감시 기반 **운전자 감독•기능 저하 전환**
#### 한줄 요약

- ADAS는 운전자를 대신하는 자율주행이 아니라 정해진 범위에서 인지•제어를 보조한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **센서 융합**: 카메라•레이더 등 여러 센서의 관측을 결합해 객체•차선•자차 상태를 추정하는 과정이다.
- **환경 센서**: 카메라•레이더•라이다•초음파로 도로•차선•객체•거리를 관측하는 입력 계층이다.
- **위험•경로 판단**: 인지 결과에서 충돌 위험을 평가하고 경고•감속•조향 목표를 결정하는 기능이다.
- **인간-기계 인터페이스(Human-Machine Interface, HMI)**: 운전자에게 기능 상태•경고•인수 요청을 전달하는 접점이다.
- **차량 제어**: 제한된 종•횡방향 조향•제동•가속 명령을 실행하는 기능이다.

</details>

**DMS•HMI**의 운전자 상태와 경고•제어 결과 연결

```text
                  [환경 센서]   [DMS•차량 상태]
                        \          /
                     [인지•센서 융합]
                             |
                     [위험•경로 판단]
                             |
                     [HMI•차량 제어]
```
선의 의미: 환경•운전자•자차 입력과 경고•제어 권한 경계 관계

| 구성요소 | 책임 |
|:---|:---|
| 환경 센서 | 카메라•레이더 기반 **객체•차선 측정**과 거리 산출 |
| DMS•차량 상태 | **주의도•기능 상태**와 속도•고장 확인 |
| 인지•센서 융합 | **객체•차선 추정**과 자차 상태 산출 |
| 위험•경로 판단 | **충돌 위험•목표 궤적 산정** |
| HMI•차량 제어 | **경고•조향 명령**과 제동•가속 제공 |

#### 한줄 요약

- 환경•운전자 상태 융합과 **제한적 경고•차량 제어**

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **운행 설계 영역(Operational Design Domain, ODD)**: 도로•날씨•속도 등 운전자 지원 기능이 작동하도록 설계된 운행 조건 범위이다.

</details>

**HMI•DMS**의 기능 한계와 운전자 대응 감시

```text
[환경 센서]
    │ 1. 환경•차량 상태
    ▼
[인지•융합]
    │ 2. 객체•차선 추정
    ▼
[위험 판단]
    │ 3. 위험•목표 제어
    ▼
[HMI•차량 제어]
    │ 4. 기능•운전자 상태
    ▼
[DMS•안전 감시] ── 5. 지속•저하•해제 결정 ──▶ [HMI•차량 제어]
```

### 동작 원리

1. 환경•차량 상태: 센서 건강•가시성•ODD•주변 데이터 수집
2. 객체•차선 추정: 다중 센서로 객체•차선•자차 상태 융합
3. 위험•목표 제어: 충돌 가능성•목표 궤적으로 경고•제어
4. 기능•운전자 상태: HMI•제어 결과와 운전자 응답 감시
5. 지속•저하•해제 결정: 한계•고장•미응답 시 저하•해제

#### 한줄 요약

- 환경•운전자 상태 감시와 **기능 저하•제어권 회수**

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **동적 주행 과업(Dynamic Driving Task, DDT)**: 조향•가감속과 주행환경 감시를 포함하는 주행 과업이다.

</details>

SAE 지원 수준별 **동적 주행 과업 역할** 구분

| SAE 지원 수준 | Level 0 | Level 1 | Level 2 |
|:---|:---|:---|:---|
| 적용 기준 | **순간 경고•보조** | 조향 또는 **가감속 보조** | 조향•가감속 **동시 보조** |
| 핵심 특징 | **지속 제어 없음** | 한 축의 **지속 지원** | 두 축의 **지속 지원** |
| 한계 | 운전자가 모든 **DDT 수행** | 운전자의 **환경 감시** 지속 | 운전자의 **감독•대응 책임** 유지 |

#### 한줄 요약

- Level 2도 **환경 감시•대응 책임**은 운전자에게 유지

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **안전한 해제**: 기능 한계나 운전자 미응답이 감지되면 경고와 단계적 제한을 거쳐 보조 기능을 종료하는 절차이다.

</details>

ADAS의 **ODD•DMS 검증**과 HMI 확인

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 기능 경계 미검증 시 ADAS의 **자율주행 오인•과신** | ODD•책임•한계의 **명확한 HMI** | 기능 경계 **오인•과신** 감소 |
| 센서 성능 미검증 시 악천후•가림의 **인지 성능 저하** | 진단•다중 센서•**기능 제한** | 악천후 **인지 실패 영향** 제한 |
| 운전자 감독 미검증 시 주의 이탈•**인수 실패** | DMS•단계 경고•**안전한 해제** | **안전한 제어권 회수** |

#### 한줄 요약

- ODD•운전자 책임 명시와 **상태 악화 시 단계적 해제**

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **SAE Level 2**: 시스템이 조향과 가감속을 동시에 보조하지만 운전자가 환경 감시와 대응 책임을 유지하는 수준이다.

</details>

- ODD•센서 한계 초과 시 **기능 저하•해제**, **운전자 감독 책임** 유지

#### 한줄 요약

- **ODD•기능 한계**와 운전자 감독 책임을 명시한 ADAS만 적용
