## 미리 알고가기

- **큐케이디(Quantum Key Distribution, QKD)**: 양자 상태의 측정 교란을 이용해 도청 가능성을 탐지하며 대칭키 재료를 분배하는 기술
- **큐버(Quantum Bit Error Rate, QBER)**: 수신한 양자 비트 중 오류 비율로, 잡음·도청 수준과 세션 폐기 여부를 판단
- **프라이버시 증폭(privacy amplification)**: 노출 가능성이 있는 정보를 줄이도록 정정된 키를 더 짧은 비밀키로 압축

## Ⅰ. 개요

- 정의/개념: 양자 상태로 대칭키 재료를 분배하는 기술
- **배경/필요성**: 공개키 난제의 계산 안전성에만 의존하는 키 교환에서 도청 흔적을 직접 확인하기 어려운 한계를 보완

### 쉽게 이해하기 (학습용)

- 빛 신호로 키 재료를 보내고 오류를 측정해 비밀키를 정제함

## Ⅱ. 특징

- **이중 채널**: 양자 상태 전송과 상대 인증·후처리를 위한 고전 채널을 함께 사용한다.
- **도청 탐지**: QBER가 임계값을 넘으면 안전한 키 생성이 불가능해 세션을 폐기한다.
- **키 정제**: 기저 선별·오류 정정·프라이버시 증폭으로 최종 비밀키를 만든다.

### 쉽게 이해하기 (학습용)

- 상대를 인증하고 통신 오류율을 검사하여 비밀키를 압축함

## Ⅲ. 아키텍처 및 구성요소

```text
[Alice 광원] ── 양자 채널 ──> [Bob 검출기]
      ↕                           ↕
      └── 인증 고전 채널·후처리 ──┘
                   ↓
             [키 관리·암호 장비]
```

| 설계 요소 | 설명 |
|:---|:---|
| Protocol/Model | QKD 프로토콜 및 보안 파라미터 정의 |
| 양자 모듈 | 광원, 채널, 측정기 등 양자 인프라 |
| 고전 채널 | 인증 기반의 고전 암호 통신 채널 |
| 관리/응용 | 최종 키 저장 및 암호화 장비 전달 |

> 요약: 양자·인증 채널로 키를 정제해 장비에 공급

### 쉽게 이해하기 (학습용)

- 빛 신호로 키 재료를 만들고 안전하게 암호 장비에 전달함

## Ⅳ. 원리 및 절차 흐름도

```text
양자전송
  ↓
오류검사
  ↓
키정제
  ↓
최종키
```

| 절차 | 설명 |
|:---|:---|
| 양자전송 | Alice가 양자 상태를 전송하고 Bob이 측정함 |
| 오류검사 | QBER 분석 후 기준치 미달 시 세션 폐기함 |
| 키정제 | 오류 수정 및 프라이버시 증폭 수행함 |
| 최종키 | 키 확인 후 암호 장비에 전달함 |

> 요약: 측정값 검사·오류 정정·압축으로 키 생성

### 쉽게 이해하기 (학습용)

- 빛 신호 오류가 낮을 때만 키를 압축하여 안전한 키를 만듦

## Ⅴ. 키 설정 방식 비교

| 판단 기준 | QKD | PQC KEM | 공개키 교환 |
|:---|:---|:---|:---|
| 적용 기준 | 전용 광인프라 필요 | 기존 디지털망 활용 | 기존 디지털망 활용 |
| 핵심 특징 | 양자 교란으로 도청 탐지 | 양자내성 난제 기반 KEM | 인수분해·이산로그 기반 |
| 한계 | 거리·키율·전용 장비 제약 | 큰 키·캡슐·전환 부담 | 양자 알고리즘에 취약 |

> 요약: QKD와 PQC의 키 분배·암호 목적 구분

### 쉽게 이해하기 (학습용)

- 전용 광선로 기술, 새 수학 문제 기술, 기존 공개키 기술임

## Ⅵ. 실무 사례

1. 전용 광선로 QKD로 암호 장비에 비밀키를 공급
2. 중계소별 QKD 키와 물리 보안으로 정부망 연결

### 쉽게 이해하기 (학습용)

- 정부망: 여러 중계소를 거쳐 hop별 키를 생성하고 물리적 보안을 강화함
