## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **소형 언어모델(Small Language Model, SLM)**: 제한된 연산•메모리에서 특정 범위의 언어 과업을 수행하도록 경량화한 모델로 정의된다.
- **온디바이스 추론(On-Device Inference)**: 서버에 원본 데이터를 보내지 않고 단말 내부에서 모델을 실행하는 방식을 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.
- **대규모 언어 모델(Large Language Model, LLM)**: 넓은 지식과 복합 과업을 처리하는 대규모 모델이다.

</details>

- 정의: 제한된 연산•메모리에서 특정 과업을 수행하는 **SLM**
- 배경/필요성: 수백억~수천억 파라미터 기반의 범용 거대 언어 모델(LLM)은 고성능 클라우드 GPU 클러스터가 필수적이어서 막대한 인프라 운영 비용, 네트워크 왕복 지연(Network Latency), 데이터 외부 전송에 따른 프라이버시 침해 및 인터넷 단절 시 서비스 불가라는 구조적 한계가 존재함에 따라, 1B~8B 수준의 소형 파라미터에 고품질 정제 데이터 학습, 지식 증류(Knowledge Distillation), SFT 및 양자화 기술을 집약한 소형 언어 모델(SLM: Small Language Model) 아키텍처를 도입하여 **스마트폰·PC·차량·로봇 등 제한된 엣지 및 온디바이스 하드웨어에서의 독립적 상주 실행 가능성 확보, 도메인 특화 태스크(특정 업무 요약/분류/코드/대화)에서 대형 LLM에 필적하는 고성능 달성, 엔터프라이즈 프라이빗 AI의 데이터 주권 및 인프라 TCO의 획기적 절감**을 달성할 필요

#### 한줄 요약
- **제한 자원•특정 업무**에 맞춘 소형 모델은 범용 능력을 내주고 상주 실행 가능성을 사는 선택이므로, 과업 범위가 좁게 고정될수록 그 교환이 유리해진다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **지식 증류(Knowledge Distillation)**: 큰 교사 모델의 응답과 지식을 작은 학생 모델에 학습시키는 기법.
- **지도 미세조정(Supervised Fine-Tuning, SFT)**: 정답•업무 예시로 모델의 응답 행동을 조정하는 학습 방법을 나타낸다.
- **매개변수 효율 미세조정(Parameter-Efficient Fine-Tuning, PEFT)**: 전체 가중치 대신 일부 추가•선택 매개변수만 학습하여 업무에 적응하는 기법군을 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.

</details>

![Observable Plot으로 그린 파라미터 수•정밀도별 가중치 메모리 이론값](/study/diagrams/slm-weight-memory.svg)

> 같은 파라미터 수에서 INT8•INT4 선은 FP16보다 가중치 메모리 기울기가 각각 절반•4분의 1 수준이며, 캐시•활성값을 제외한 십진 GB 이론값임.

- **소형 파라미터**: 메모리•연산•배포 비용 절감
- **지식 증류**: 교사 모델의 지식을 작은 모델에 이전
- **SFT**: 업무 예시로 응답 행동 조정
- **PEFT**: 일부 매개변수 학습으로 업무 적응
- **양자화•장치 런타임**: 제한 자원 추론 지원

#### 한줄 요약
- **파라미터 수•정밀도**와 업무 품질 절충

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **양자화(Quantization)**: 가중치를 더 적은 비트로 표현하여 모델 메모리와 연산량을 줄이는 방법이다.
- **가지치기(Pruning)**: 영향이 작은 가중치•연결•구조를 제거하여 연산량을 줄이는 기법으로 정의된다.
- **추론 런타임(Inference Runtime)**: 모델 그래프를 목표 장치의 연산자로 변환하고 실행하는 소프트웨어.

</details>

```text
                         [출력 통제]
                              |
                         [경량 백본]
                        /           \
              [과업 적응 계층]    [압축 계층]
                        \           /
                         [추론 런타임]
```

선의 의미: 경량 백본의 적응•압축과 장치 실행•출력 통제를 연결한 구조

| 구성요소 | 책임 |
|:---|:---|
| 경량 백본 | 자원 목표에 맞는 **소형 언어 표현 제공** |
| 과업 적응 계층 | **증류•SFT•PEFT 기반 업무 능력 보강** |
| 압축 계층 | **양자화**•**가지치기** 활용 통한 모델 크기 축소 |
| 추론 런타임 | 목표 장치 연산자 기반 **모델 실행 최적화** |
| 출력 통제 | 업무 범위•안전 기준에 따른 **응답 허용•거부** |

#### 한줄 요약
- **경량 백본•압축**과 적응•런타임•출력 통제 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **교사 모델(Teacher Model)**: 훈련용 응답과 확률 정보를 생성하여 작은 학생 모델에 능력을 전달하는 큰 모델을 나타낸다.
- **실기기 검증(Real Device Verification)**: 목표 단말에서 실제 지연•메모리•전력•정확도를 측정하여 배포 적합성을 확인하는 절차를 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.

</details>

```text
평가 책임자
     │ 1. 과업•자원 목표 정의
     ▼
데이터•교사 모델
     │ 2. 대표 데이터•교사 출력 준비
     ▼
SLM 학습기
     │ 3. 증류•미세조정
     ▼
압축•런타임
     │ 4. 양자화•런타임 변환
     ▼
평가 책임자
     │ 5. 과업 품질•장치 자원 검증
     ▼
배포 판단
```

### 동작 원리

1. 과업•자원 목표 정의: 정확도•지연•메모리•전력의 **허용 범위** 설정
2. 대표 데이터•교사 출력 준비: 범위 밖 입력을 포함한 **학습•평가 자료** 구성
3. 증류•미세조정: 교사 지식과 업무 예시로 **특정 과업 능력** 강화
4. 양자화•런타임 변환: 목표 장치에 맞는 **실행 형식** 생성
5. 과업 품질•장치 자원 검증: 압축 전후 **지연•메모리**와 정확도 비교

#### 한줄 요약
- **증류•압축** 전후 목표•데이터•실기기 검증 수행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **소형 언어모델(Small Language Model, SLM)**: 제한된 자원 환경에서 특화 업무를 수행하는 경량 모델이다.
- **대규모 언어모델(Large Language Model, LLM)**: 광범위한 문맥과 다목적 과업을 수행하는 대형 모델.

</details>

| 구분 | SLM | LLM |
|:---|:---|:---|
| 적용 기준 | **제한 자원•좁은 반복 업무** | **범용•복합 과업** |
| 핵심 특징 | 낮은 비용의 **현장•단말 추론** | 넓은 지식•높은 **추론 용량** |
| 한계 | **범위 밖 일반화 취약** | **메모리•전력•서빙 비용** |

#### 한줄 요약
- 좁은 반복 업무는 **SLM**, 범용 복합 과업은 **LLM**

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **압축 회귀(Compression Degradation)**: 양자화•가지치기 후 업무 정확도나 출력 품질이 원본 모델보다 낮아지는 현상이다.
- **상위 모델 위임(Fallback to Larger Model)**: SLM의 학습 범위 밖이거나 복합적인 요청을 더 큰 모델로 전달하는 정책으로 정의된다.
- **연산자 호환성(Operator Compatibility)**: 모델 연산이 목표 장치와 런타임에서 지원되고 같은 결과를 내는 성질.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 압축 후 **과업 정확도 저하** | **원본•압축 모델 업무별 회귀 평가** | 품질 손실 **탐지** |
| 학습 범위 밖 **입력 오류** | **거부 기준•상위 모델 위임 정책** | 오답 위험 **완화** |
| 단말별 **연산자 미지원** | **목표 런타임 변환•실기기 시험** | 배포 호환성 **확보** |

#### 한줄 요약
- **업무 범위•압축 회귀**와 장치 호환성 검증

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **자원 제약(Resource Constraints)**: 디바이스의 메모리•전력•연산 자원이 제한되어 모델 크기와 실행 방식에 제약을 주는 조건을 나타낸다.

</details>

- 초거대 클라우드 중심 AI 생태계를 분산 엣지 및 프라이빗 온디바이스 환경으로 대전환시킨 **실용적 생성형 AI 엔지니어링의 핵심 패러다임(Small Language Model: SLM / Knowledge Distillation & High-Quality Synthetic Data / Fine-Tuning: LoRA & SFT / Quantization: INT4 & FP8 / Edge & On-Device Deployment)의 표준 아키텍처**로 확고히 자리 잡았으며, Phi-3/4, Llama 3.2 1B/3B, Gemma 2 등 고성능 오픈 소형 모델로 급속히 발전하는 가운데, 실무 엔터프라이즈 시스템 구축 시에는 **정형화된 반복 도메인 과업에는 초경량 SLM을 엣지/온프레미스에 배치하고 복합 추론 및 범용 지식이 필요한 질의는 클라우드 LLM으로 동적 라우팅하는 하이브리드 계층형 AI(Hybrid Hierarchical AI) 아키텍처 수립, 양자화(AWQ/GGUF) 후 정확도 회귀 평가 및 엣지 NPU/GPU 런타임 최적화**를 결합하여 완벽한 프라이버시 보호와 경제적인 AI 거버넌스를 완성

#### 한줄 요약
- **업무 범위•자원 제약**에 따라 모델 경로 결정
