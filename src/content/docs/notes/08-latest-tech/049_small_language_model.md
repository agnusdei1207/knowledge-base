## 미리 알고가기

- **SLM(Small Language Model, 에스엘엠)**: 영문 머리글자를 딴 소형 언어 모델로, 제한된 자원에서 효율적으로 실행
- **LLM(Large Language Model, 엘엘엠)**: 영문 머리글자를 딴 대규모 언어 모델로, 광범위한 지식·복합 과업에 활용
- **PEFT(Parameter-Efficient Fine-Tuning, 페프트)**: 일부 파라미터만 학습하는 효율적 미세조정 기법군
- **SFT (Supervised Fine-Tuning)**: 예시를 활용한 지도 미세조정
- **RAG (Retrieval-Augmented Generation)**: 외부 근거 결합 생성 기술
- **LoRA(Low-Rank Adaptation, 로라)**: 저순위 행렬을 추가 학습하는 PEFT 기법


## Ⅰ. 개요

- 정의/개념: 적은 연산·메모리용 소형 언어 모델
- 기존 한계: 범용 LLM은 에지·온디바이스의 메모리·비용 부담
- **배경/필요성**: 제한 자원에서 업무 품질·지연·비용 균형

### 쉽게 이해하기 (학습용)
- 정해진 업무를 제한된 장비에서 효율적으로 수행하도록 맞춘 모델임

## Ⅱ. 특징

- 작은 파라미터 규모가 메모리·연산·배포 비용을 낮춘다
- 증류·SFT·PEFT로 특정 업무 품질을 보강한다
- 양자화와 장치별 런타임 최적화로 현장 실행을 지원한다

### 쉽게 이해하기 (학습용)

- 작은 모델은 범용성보다 정해진 업무의 비용·속도에 유리하다

## Ⅲ. 구성요소 및 구조

| 구성 요소 | 설명 |
|:---|:---|
| Backbone | 자원 목표에 맞춘 경량 계층 |
| 학습 계층 | 증류 및 미세조정 기반 학습 |
| 압축 계층 | 양자화 및 파라미터 최적화 |
| 추론 Runtime | 장치별 연산 최적화 실행 |
| 안전 계층 | 외부 근거 결합 및 출력 제어 |

> 요약: 작은 모델에 학습·압축·실행·안전 계층을 연결함

### 쉽게 이해하기 (학습용)

- 작은 모델에 학습·압축·실행·안전 제어를 연결함

## Ⅳ. 원리 및 절차 흐름도

```text
요구정의
↓
데이터준비
↓
모델학습
↓
압축변환
↓
품질검증
↓
배포감시
```

| 절차 | 설명 |
|:---|:---|
| 요구정의 | 자원 및 업무 조건 수립함 |
| 데이터준비 | 대표 및 검증 데이터 구성함 |
| 모델학습 | 증류 및 미세조정 수행함 |
| 압축변환 | 양자화 및 모델 크기 축소함 |
| 품질검증 | 자원 목표와 성능 검증함 |
| 배포감시 | 이상치 감시 및 갱신 수행함 |

> 요약: 업무 경계를 학습·압축하고 품질·자원을 검증함

### 쉽게 이해하기 (학습용)

- 업무 경계를 정하고 압축 전후 품질을 비교함

## Ⅴ. 종류 및 비교

| 판단 기준 | 범용 LLM | SLM | 업무 특화 모델 |
|:---|:---|:---|:---|
| 적용 기준 | 광범위한 복합 과업 | 제한 자원·반복 업무 | 좁고 고정된 업무 |
| 핵심 특징 | 높은 범용성·추론 능력 | 품질·비용·지연 균형 | 특정 업무 일관성 |
| 한계 | 높은 비용·지연 | 범용성·압축 품질 저하 | 범위 밖 입력에 취약 |

> 요약: 업무 범위와 자원으로 적합 모델을 선택함

### 쉽게 이해하기 (학습용)

- 범용은 넓은 문제, 특화형은 좁은 업무에 적용함

## Ⅵ. 실무 사례

- RAG 사용 시 검색, 인용, 답변 충실도를 각각 평가함

### 쉽게 이해하기 (학습용)

- 현장 업무에 맞춘 소형 모델은 적은 자원으로 빠르게 답한다

## Ⅶ. 결론

- 경량 AI 배포를 위해 성능·자원을 검토하여 **SLM** 활용

### 쉽게 이해하기 (학습용)

- 작은 모델은 실제 업무 품질과 장비 비용으로 선택해야 한다
