## 미리 알고가기

- **모델 역전**: 모델 출력이나 내부 정보를 이용해 학습 데이터의 특징을 거꾸로 복원하는 공격
- **모델 추출**: 추출이 기능 복제라면 역전은 학습 데이터 복원에 더 가깝게 작동함
- **확률 점수**: 확률 점수와 기울기(Gradient) 접근 권한이 많을수록 공격 난도가 하락함



## Ⅰ. 개요

- **정의/개념**: 출력 신호로 학습 특징을 역추정하는 공격이다
- **배경/필요성**: 상세 출력·과적합의 민감정보 노출을 막는다

### 쉽게 이해하기 (학습용)
- AI 답변과 점수를 단서로 삼아 AI가 배운 집단의 숨은 특징을 추리한다.

## Ⅱ. 특징

- 상세 점수·기울기는 복원 최적화 방향을 노출한다
- 반복 질의는 후보를 개선해 민감 특징 유출을 키운다
- 복원 결과는 대표 특징이라 원본 오판을 만들 수 있다
- 보조 정보는 후보 범위를 줄여 재식별 위험을 높인다
- 유사성·식별성 검증은 복원 위험 과장을 막는다

### 쉽게 이해하기 (학습용)
- 복원 결과가 원본 복사본이 아니어도 닮은 정도와 개인 식별 가능성을 함께 판단해야 한다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 복원 대상 | 추론할 민감 속성이나 대표 입력 특징 |
| 관측 채널 | 후보를 평가하는 응답·파라미터 정보 |
| 보조 정보 | 후보 공간을 좁히는 외부 지식 |
| 복원 함수 | 후보 응답을 목표와 유사하게 만드는 기준 |
| 통제 장치 | 출력 축소·프라이버시 예산 등 노출 제한 |

> 요약: 대상·관측·보조 정보로 복원 범위와 통제를 정한다

### 쉽게 이해하기 (학습용)

- 공격자는 알아낼 특징, AI에서 볼 수 있는 단서, 이미 아는 정보, 후보를 고치는 채점 기준을 조합하고 운영자는 같은 경로로 누출을 검증함

## Ⅳ. 원리 및 절차 흐름도

```text
대상·보조 정보 고정 → 후보 초기화 → 응답 관측
                                    ↓
                                목적함수 평가
                 ├─ 미달 → 후보 갱신 → 응답 관측 반복
                 └─ 충족 → 복원 결과 평가
```

| 절차 | 설명 |
|:---|:---|
| 대상 고정 | 민감 속성 및 보조 지식 정의 |
| 후보 초기화 | 분포 기반 복원 후보 생성 |
| 응답 관측 | 모델에 후보를 넣어 신뢰도 수집 |
| 후보 갱신 | 목적함수 개선 방향으로 특징 수정 |
| 결과 평가 | 정확도·유사도로 누출 수준 판정 |

> 요약: 보조 정보로 후보를 갱신하고 누출을 판정한다

### 쉽게 이해하기 (학습용)

- 흐릿한 그림을 AI에 계속 보여 주고 원하는 사람의 점수가 높아지는 방향으로 그림을 고치다가 충분히 닮으면 멈추는 과정임

## Ⅴ. 종류 및 비교

| 판단 기준 | 모델 역전 | 멤버십 추론 | 모델 추출 |
|:---|:---|:---|:---|
| 목표 | 대표 특징 복원 | 훈련 포함 여부 판정 | 기능 모방 |
| 관측 | 예측·모델 정보 | 손실·신뢰도 차이 | 다량 질의쌍 |
| 성공 판정 | 속성 정확도·유사도 | 판정 정확도·오탐률 | 예측 일치도 |

> 요약: 역전은 특징, 추론은 포함, 추출은 기능을 노린다

### 쉽게 이해하기 (학습용)

- 모델 역전은 “어떤 특징을 배웠나”, 멤버십 추론은 “이 자료를 배웠나”, 모델 추출은 “판단 규칙을 어떻게 흉내 내나”를 묻는 공격임

## Ⅵ. 실무 사례

1. 안면 인식 API의 불필요한 신뢰도 정밀도를 줄인다
2. 의료 모델의 복원 위험과 차분 프라이버시를 감사한다

### 쉽게 이해하기 (학습용)

- 얼굴 인식의 세밀한 점수를 줄인 뒤 실제 복원 공격으로 정보 노출이 감소했는지 확인한다.
- 의료 모델에 차분 프라이버시를 적용한 뒤 속성 복원 위험과 서비스 효용을 함께 평가한다.

## Ⅶ. 결론

- 복원 위험에 맞춰 출력과 프라이버시 예산을 조정한다.

### 쉽게 이해하기 (학습용)

- AI가 주는 단서를 줄이고 개인별 프라이버시 한도를 두되 실제 복원 성공률도 확인한다.
