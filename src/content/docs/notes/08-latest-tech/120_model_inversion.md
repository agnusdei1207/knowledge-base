## 미리 알고가기

- **모델 역전(Model Inversion)**: 모델 출력이나 내부 정보로 학습 데이터의 대표 특징·민감 속성을 역추정하는 공격
- **기울기(Gradient, 그래디언트)**: 손실이 입력에 따라 변하는 방향으로, 복원 후보를 갱신하는 단서
- **멤버십 추론(Membership Inference)**: 특정 표본의 훈련 포함 여부를 판정하며 특징을 복원하는 모델 역전과 구별



## Ⅰ. 개요

- 정의/개념: 출력 신호로 학습 특징을 역추정하는 공격이다
- 기존 한계: 상세 점수·기울기와 과적합은 학습 데이터의 민감 특징을 드러낼 수 있다
- **배경/필요성**: 모델 출력과 내부 정보로 인한 민감 특징 복원·재식별 위험을 줄이기 위함이다

### 쉽게 이해하기 (학습용)
- AI 답변과 점수를 단서로 삼아 AI가 배운 집단의 숨은 특징을 추리한다.

## Ⅱ. 특징

- 상세 점수·기울기와 반복 질의로 복원 후보를 최적화한다
- 보조 정보는 후보 범위를 줄여 민감 특징의 재식별 위험을 높인다
- 복원 결과는 대표 특징일 수 있어 원본 일치도와 식별성을 검증한다

### 쉽게 이해하기 (학습용)
- 복원 결과가 원본 복사본이 아니어도 닮은 정도와 개인 식별 가능성을 함께 판단해야 한다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 복원 대상 | 추론할 민감 속성이나 대표 입력 특징 |
| 관측 채널 | 후보를 평가하는 응답·파라미터 정보 |
| 보조 정보 | 후보 공간을 좁히는 외부 지식 |
| 복원 함수 | 후보 응답을 목표와 유사하게 만드는 기준 |
| 통제 장치 | 출력 축소·프라이버시 예산 등 노출 제한 |

> 요약: 대상·관측·보조 정보로 복원 범위와 통제를 정한다

### 쉽게 이해하기 (학습용)

- 공격자는 복원 대상·모델 단서·보조 정보·채점 기준을 조합하고 운영자는 같은 경로로 누출을 검증한다.

## Ⅳ. 원리 및 절차 흐름도

```text
대상·보조 정보 고정 → 후보 초기화 → 응답 관측
                                    ↓
                                목적함수 평가
                 ├─ 미달 → 후보 갱신 → 응답 관측 반복
                 └─ 충족 → 복원 결과 평가
```

| 절차 | 설명 |
|:---|:---|
| 대상 고정 | 민감 속성 및 보조 지식 정의 |
| 후보 초기화 | 분포 기반 복원 후보 생성 |
| 응답 관측 | 모델에 후보를 넣어 신뢰도 수집 |
| 후보 갱신 | 목적함수 개선 방향으로 특징 수정 |
| 결과 평가 | 정확도·유사도로 누출 수준 판정 |

> 요약: 보조 정보로 후보를 갱신하고 누출을 판정한다

### 쉽게 이해하기 (학습용)

- 흐릿한 그림을 AI에 반복 입력하고 목표 점수가 높아지는 방향으로 고쳐 충분히 닮으면 멈춘다.

## Ⅴ. 종류 및 비교

| 판단 기준 | 모델 역전 | 멤버십 추론 | 모델 추출 |
|:---|:---|:---|:---|
| 적용 기준 | 학습 특징 복원이 목적 | 훈련 포함 판정이 목적 | 모델 기능 모방이 목적 |
| 핵심 특징 | 출력·기울기로 후보 최적화 | 표본별 손실·신뢰도 차이 활용 | 대량 입출력으로 대체 모델 학습 |
| 한계 | 복원물이 실제 원본과 다를 수 있음 | 과적합이 낮으면 구별이 어려움 | 많은 질의와 학습 비용 필요 |

> 요약: 역전은 특징, 추론은 포함, 추출은 기능을 노린다

### 쉽게 이해하기 (학습용)

- 모델 역전은 학습 특징, 멤버십 추론은 훈련 포함 여부, 모델 추출은 판단 기능을 노린다.

## Ⅵ. 실무 사례

1. 안면 인식 API의 불필요한 신뢰도 정밀도를 줄인다
2. 의료 모델의 복원 위험과 차분 프라이버시를 감사한다

### 쉽게 이해하기 (학습용)

- 얼굴 인식의 세밀한 점수를 줄인 뒤 실제 복원 공격으로 정보 노출이 감소했는지 확인한다.
- 의료 모델에 차분 프라이버시를 적용한 뒤 속성 복원 위험과 서비스 효용을 함께 평가한다.

## Ⅶ. 결론

- 복원 위험에 맞춰 출력과 프라이버시 예산을 조정한다.

### 쉽게 이해하기 (학습용)

- AI가 주는 단서를 줄이고 개인별 프라이버시 한도를 두되 실제 복원 성공률도 확인한다.
