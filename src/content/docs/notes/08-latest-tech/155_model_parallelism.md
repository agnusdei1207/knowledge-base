## 미리 알고가기

- **모델 병렬**: 모델을 여러 장치에 분할하여 공동 실행하는 병렬화 전략
- **적용 조건**: 단일 장치 메모리 용량을 초과하는 대규모 모델 학습 시 필수
- **통신 비용**: 분할 방식에 따라 활성값 전송과 통신 비용 구조가 크게 변함



## Ⅰ. 개요

- **정의/개념**: 모델 파라미터·연산 분할 병렬화
- **배경/필요성**: 단일 장치에 모델 파라미터·활성값·최적화 상태 전체 적재 곤란

### 쉽게 이해하기 (학습용)

- 거대한 조립품을 부품별 혹은 작업별로 나누어 여러 작업자가 완성하는 방식

## Ⅱ. 특징

- 층·텐서 축 기반 **모델 분할 저장·계산**
- 분할 경계 기반 **활성값·집단통신**
- 불균형 분할 기반 **유휴 시간·통신 대기**

### 쉽게 이해하기 (학습용)

- 분할 방식마다 협업법이 달라 작업 방식에 맞춰 나눔

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 병렬화 계획기 | 메모리·연산·통신으로 분할 축을 정함 |
| 파이프라인 단계 그룹 | 층을 단계에 배치해 활성값·기울기를 전달함 |
| 텐서 병렬 그룹 | 텐서를 나눠 부분 결과를 집단 통신으로 합침 |
| 통신 인터페이스 | 점대점·집단 통신을 분할 경계에 연결함 |
| 병렬 런타임 | 링크·노드 경계에 맞춰 그룹을 배치함 |

```text
입력 → [파이프라인 단계 0] ──활성값──→ [파이프라인 단계 1] → 출력
        ├─ 텐서 조각 A                    ├─ 텐서 조각 C
        └─ 텐서 조각 B                    └─ 텐서 조각 D
           ↕ 집단 통신                       ↕ 집단 통신
```

> 요약: 계획기가 분할하고 런타임이 전송·집단 통신을 실행한다.

### 쉽게 이해하기 (학습용)

- 작업장 분업과 내부 공동 작업을 구분하고 통로와 관리 방식을 다르게 적용

## Ⅳ. 원리 및 절차 흐름도

프로파일링 → 축선택 → 그룹배치 → 순/역전파 → 병목측정(반복)

| 절차 | 설명 |
|:---|:---|
| 모델·장치 프로파일링 | 층별 파라미터·활성값·연산량과 장치 메모리·연결 대역폭을 측정함 |
| 분할 축 선택 | 파이프라인·텐서 병렬 조합을 선택함 |
| 그룹·경계 배치 | 텐서 그룹·파이프라인 단계를 구분 배치함 |
| 분산 순·역전파 | 조각 계산·통신으로 출력·기울기를 완성함 |
| 병목 측정·재조정 | 유휴·통신·메모리로 분할 수를 조정함 |

> 요약: 특성·토폴로지로 분할 축을 정하고 반복 조정한다.

### 쉽게 이해하기 (학습용)

- 작업장의 거리와 부품 크기를 고려하여 작업 팀을 나누고 비효율을 확인하며 재구성하는 과정

## Ⅴ. 모델 병렬화 방식 비교

| 구분 | 파이프라인 병렬 | 텐서 병렬 | 혼합 모델 병렬 |
| 적용 기준 | 계층 묶음 분할 가능 | 단일 연산이 장치 초과 | 초대형 모델 다차원 분할 |
| 핵심 특징 | 단계 분할·마이크로배치 | 텐서 축 분할·부분 합산 | 파이프라인·텐서 결합 |
| 한계 | 버블·단계 불균형 | 빈번한 집단통신 | 배치·토폴로지 설계 복잡 |
|:---|:---|:---|:---|
| 분할·통신 단위 | 연속 층을 단계로 나누고 활성값을 점대점 전송함 | 단일 연산의 텐서 차원을 나누고 부분 결과를 집단 통신함 | 두 축을 결합해 단계 내부를 다시 텐서 분할함 |
| 배치 기준 | 깊은 모델을 단계별 장치·노드에 배치함 | 통신이 잦아 고대역폭 장치 그룹 안에 배치함 | 텐서는 노드 내부, 파이프라인은 노드 간에 주로 배치함 |
| 선택 조건 | 단계 균형과 버블을 제어할 수 있을 때 | 거대한 층과 집단 통신 비용을 감당할 때 | 한 방식만으로 용량·처리량 목표를 충족하지 못할 때 |

> 요약: 파이프라인·텐서 분할을 토폴로지에 맞춰 조합한다.

### 쉽게 이해하기 (학습용)

- 공정별 분업(파이프라인), 공정 내 공동 작업(텐서), 대규모 공장(결합) 방식

## Ⅵ. 실무 사례

1. NVIDIA Megatron-LM은 대규모 트랜스포머 학습에서 텐서·파이프라인·데이터 병렬을 결합해 모델 용량과 처리량을 함께 확장함
2. 멀티노드 학습 클러스터는 통신이 잦은 텐서 병렬을 노드 내부에 두고 파이프라인 단계를 노드 간에 배치해 느린 링크의 집단 통신을 줄임

### 쉽게 이해하기 (학습용)

- 노드 내부 통신 최적화를 위해 작업자를 묶고 노드 간에는 결과만 전달함

## Ⅶ. 결론

- 파이프라인·텐서 분할과 토폴로지를 함께 설계한다

### 쉽게 이해하기 (학습용)
