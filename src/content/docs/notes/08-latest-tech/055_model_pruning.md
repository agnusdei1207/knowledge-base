## 미리 알고가기

- **모델 가지치기 (Model Pruning)**: 기여도 낮은 가중치·구조 제거 기법
- **비구조적 가지치기 (Unstructured Pruning)**: 개별 가중치 제거 희소화 기술
- **구조적 가지치기 (Structured Pruning)**: 채널·계층 단위 제거 축소 기술
- **희소 행렬 (Sparse Matrix)**: 0값 위주 행렬로 전용 실행 최적화 대상



## Ⅰ. 개요

- 정의/개념: 기여도가 낮은 가중치·채널·계층을 제거하는 모델 압축 기법
- 기존 한계: 과매개변수 모델은 중요도가 낮은 연결까지 계산해 불필요한 연산과 메모리 사용이 발생한다.

### 쉽게 이해하기 (학습용)

- 덜 중요한 연결을 없애도 실행기가 활용해야 속도가 빨라진다

## Ⅱ. 특징

- 중요도 기반 제거와 **단계적 품질 회복**
- 비구조 희소성의 **전용 커널 의존**
- 구조적 제거의 **밀집 커널 가속**

### 쉽게 이해하기 (학습용)

- 작은 값만 지우는 방법과 줄·묶음을 지우는 방법은 압축 모양과 실행 방식이 다름

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 설계 요소 | 설명 |
|:---|:---|
| 평가기 | 제거 후보 산정함 |
| 스케줄러 | 제거 패턴 제어함 |
| 변환기 | 차원 축소 수행함 |
| 학습기 | 품질 회복 수행함 |
| 커널 | 희소 모델 실행함 |

```text
기준 모델
├─ 중요 평가
├─ 제거 제어
├─ 구조 변환
└─ 실행 커널
```

### 쉽게 이해하기 (학습용)

- 무엇을 지울지 평가하고, 지운 모양을 실행 형식으로 바꾼 뒤, 다시 학습해 품질을 확인함

## Ⅳ. 원리 및 절차 흐름도

목표 설정
↓
후보 산정
↓
제거 복원
↓
성능 검증

| 절차 | 설명 |
|:---|:---|
| 설정 | 기준·지표 정의함 |
| 산정 | 제거 단위 선택함 |
| 복원 | 반복 학습 수행함 |
| 검증 | 지연 시간 확인함 |

### 쉽게 이해하기 (학습용)

- 한꺼번에 많이 지우기보다 조금씩 지우고 다시 학습하면서 품질과 속도를 확인함

## Ⅴ. 모델 가지치기 방식 비교

| 구분 | 비구조적 | 반구조적 | 구조적 |
|:---|:---|:---|:---|
| 제거 단위 | 가중치 | 희소 패턴 | 채널·계층 |
| 적용 기준 | 임의 희소 지원 | 가속기 패턴 지원 | 텐서 축소 필요 |
| 핵심 특징 | 개별 가중치 제거 | N:M 패턴 희소화 | 채널·헤드·계층 제거 |
| 한계 | 전용 희소 커널 필요 | 패턴별 하드웨어 의존 | 품질 손실·재학습 필요 |
| 주요 확인 | 건너뛰기 효율 | 패턴 준수 여부 | 품질·구조 정합성 |

> 요약: 장치 지원 환경에 최적화된 기법 선택함

### 쉽게 이해하기 (학습용)

- 비구조·반구조·구조 방식은 장치 지원에 맞춰 선택함

## Ⅵ. 실무 사례

- 커널 미지원·인덱스 비용은 희소 가속을 막는다

### 쉽게 이해하기 (학습용)

- 0이 많다는 통계만 보지 말고 장치가 0을 건너뛰는지와 지운 뒤 어떤 문제를 틀리는지 함께 봐야 함

## Ⅶ. 결론

- 추론 비용 절감을 위해 기여도·커널을 검토하여 **가지치기** 활용

> 요약: 모델 구조와 하드웨어 환경을 함께 설계함

### 쉽게 이해하기 (학습용)

- 잘 지우는 것과 빠르게 실행하는 것은 다른 문제이므로 모델과 Hardware를 함께 설계해야 함
