## 미리 알고가기

- **인공지능(Artificial Intelligence, AI)**: 인간 지능 과업을 컴퓨터로 수행하는 기술
- **시스템 프롬프트(System Prompt)**: 모델의 공통 역할·정책을 설정하는 상위 지시
- **사용자 프롬프트(User Prompt)**: 현재 과업·질문·데이터를 전달하는 입력
- **지시 계층(Instruction Hierarchy)**: 메시지 권한에 따라 충돌 지시를 우선순위화
- **프롬프트 유출(Prompt Leakage)**: 숨긴 지시 원문이 응답으로 노출되는 현상
- **신원·접근 관리(Identity and Access Management, IAM)**: 모델 밖에서 사용자와 도구의 접근 권한을 검증·집행하는 체계
- **응용 프로그래밍 인터페이스(Application Programming Interface, API)**: 모델 기능을 서비스에서 호출할 수 있도록 제공하는 접점
- **페르소나(Persona)**: 모델의 역할·어조·응답 태도를 설정



## Ⅰ. 개요

- 정의/개념: 모델 역할·정책을 설정하는 상위 지시
- 기존 한계: 사용자 요청만으로는 서비스 공통 **역할·정책·출력 제약**을 일관되게 적용하기 어려움

### 쉽게 이해하기 (학습용)
- 대화마다 반복하지 않을 기본 규정과 응답 원칙을 모델에 제공하는 설정문

## Ⅱ. 특징

- 모델이 해석하는 **상위 역할·출력 계약**
- 외부 문서·사용자 데이터와 **신뢰 경계** 분리
- 비밀·권한·강제 정책의 **외부 집행**

### 쉽게 이해하기 (학습용)
- 사내 규정 안내문은 행동을 유도하나 방화벽이나 출입 통제는 아님

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 역할·목표 | 모델의 업무와 대상 사용자를 정의함 |
| 정책·제약 | 금지·거부·안전 기준을 명시함 |
| 문맥 경계 | 지시와 비신뢰 데이터 출처를 구분함 |
| 도구·출력 계약 | 도구 승인과 출력 형식을 정의함 |
| 버전·평가 | 프롬프트·모델·평가셋을 연결함 |

```text
애플리케이션 통제
├─ 시스템 프롬프트
├─ 사용자 프롬프트
├─ 모델 실행부
├─ IAM·정책 집행
└─ 버전·평가 기록
```

### 쉽게 이해하기 (학습용)

- 모델 지시와 실제 도구 권한 통제를 분리하면 문구가 흔들려도 위험 행동은 차단할 수 있음

## Ⅳ. 원리 및 절차 흐름도

```text
역할정의
  ↓
지시작성
  ↓
공격평가
  ↓
정책연결
  ↓
운영감시
```

| 절차 | 설명 |
|:---|:---|
| 역할정의 | 업무·금지·거부·권한 경계 수립 |
| 지시작성 | 규칙과 문맥 경계 구성 |
| 공격평가 | 충돌·인젝션·유출 사례 검증 |
| 정책연결 | IAM·승인·도구 정책 연결 |
| 운영감시 | 유출·위반·회귀 지속 감시 |

### 쉽게 이해하기 (학습용)

- 규정 문구를 만들고 공격 질문으로 검증한 뒤 실제 권한 장치와 함께 배포함

## Ⅴ. 프롬프트 권한 비교

| 구분 | 시스템 프롬프트 | 사용자 프롬프트 |
|:---|:---|:---|
| 작성 주체 | 플랫폼·운영자 | 최종 사용자 |
| 주요 역할 | 공통 역할·정책 설정 | 현재 과업·데이터 전달 |
| 적용 기준 | 전 요청 공통 지시 | 요청별 가변 지시 |
| 핵심 특징 | 서비스 역할·정책 설정 | 과업·질문·데이터 전달 |
| 한계 | 유출·우회·충돌 위험 | 상위 정책 변경 불가 |

> 요약: 운영 규정과 가변 지시의 모델 내부 텍스트 처리

### 쉽게 이해하기 (학습용)

- 운영 규정과 현재 요청의 역할은 다르지만 둘 다 모델 안의 텍스트라는 한계가 있음

## Ⅵ. 실무 사례

- 허용 업무·근거·이관 기준을 시스템 지시에 둔다

### 쉽게 이해하기 (학습용)

- 숨겨 달라고 적은 비밀은 유출될 수 있으므로 모델이 처음부터 볼 필요 없게 설계해야 함

## Ⅶ. 결론

- 응용 전반의 모델 역할과 금지 행동을 일관되게 통제하기 위해 **정책 우선순위·도구 권한·입력 공격·회귀 위험**을 검토하고, 핵심 행동 경계를 System Prompt에 명시해야 한다.

### 쉽게 이해하기 (학습용)

- 시스템 프롬프트는 행동 안내서이지 공격을 막는 방화벽이나 권한 시스템은 아님
