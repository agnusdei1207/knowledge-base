## 미리 알고가기

- **동형암호(Homomorphic Encryption, 호모모픽 인크립션)**: 암호문 상태의 연산 결과가 평문 연산과 대응하는 공개키 암호
- **CKKS(Cheon-Kim-Kim-Song, 씨케이케이에스)**: 네 연구자의 성을 딴 방식으로, 실수·복소수 근사 연산을 지원
- **부트스트래핑(Bootstrapping, 부트스트래핑)**: 암호문 노이즈를 줄여 추가 연산 여유를 회복하는 기법



## Ⅰ. 개요

- **정의/개념**: 암호문 상태의 연산 결과가 평문 연산 결과와 대응하는 암호 기법이다
- **기존 한계**: 기존 암호는 계산 전에 데이터를 복호화하므로 처리 중 평문이 노출될 수 있다
- **배경/필요성**: 데이터 원문을 공개하지 않고 외부 연산을 수행하기 위함이다

### 쉽게 이해하기 (학습용)

- 암호문을 열지 않고 계산해 비밀키를 가진 데이터 소유자만 결과를 확인합니다.

## Ⅱ. 특징

- 평가자는 비밀키 없이 암호화된 입력·중간값을 계산한다.
- 곱셈 깊이와 노이즈가 매개변수·복호화 성공을 좌우한다.
- 동형성은 기밀성을 제공하지만 계산 무결성은 별도 검증한다.

### 쉽게 이해하기 (학습용)

- 암호문 연산을 거듭하면 잡음이 커져 필요할 때 비용이 큰 부트스트래핑으로 연산 여유를 회복합니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 암호 매개변수·키 집합 | 보안·연산 깊이에 맞는 암호화·평가 키 |
| 인코딩·패킹 | 평문을 인코딩해 암호문 슬롯에 묶음 |
| 평가 회로 | 곱셈 깊이와 회전·재선형화 위치 고정 |
| 노이즈·스케일 상태 | 노이즈·스케일·모듈러스 수준 관리 |
| 출력·키 경계 | 복호화 권한·평가 키 배포·교체 정책 |

```text
[데이터·키 소유자]
  ├─ 입력 암호문·평가 키 → [외부 연산자: 평가 회로]
  └─ 비밀키 보유                       │
                                        ↓
                                  [결과 암호문]
                                        ↓
                            [소유자만 결과 복호화]
```

### 쉽게 이해하기 (학습용)

- 평가 회로·암호 매개변수·보조키·노이즈 한도와 최종 복호화 권한을 함께 설계해야 합니다.

## Ⅳ. 원리 및 절차 흐름도

```text
회로분석
  ↓
키·스킴설정
  ↓
입력암호화
  ↓
암호문평가
  ↓
결과복호화
```

| 절차 | 설명 |
|:---|:---|
| 회로분석 | 함수를 연산으로 바꾸고 깊이를 산정함 |
| 키설정 | 연산 깊이에 맞춰 키를 생성함 |
| 입력암호화 | 입력을 패킹하고 공개키로 암호화함 |
| 암호문평가 | 덧셈·곱셈 수행 후 필요 시 정화함 |
| 결과복호화 | 결과값을 복호화해 결과 확인함 |

- 암호문 잡음이 한계에 이르면 부트스트래핑으로 연산 여유를 회복한다

### 쉽게 이해하기 (학습용)

- 계산 깊이를 먼저 정해 키와 매개변수를 만들고 필요하면 부트스트래핑한 뒤 소유자만 결과를 복호화합니다.

## Ⅴ. 종류 및 비교

| 판단 기준 | 부분 동형 | 제한 동형 | 완전 동형 |
|:---|:---|:---|:---|
| 적용 기준 | 한 종류 연산 반복 | 미리 정한 깊이의 회로 | 임의 깊이의 반복 계산 |
| 핵심 특징 | 덧셈 또는 곱셈 지원 | 제한 깊이 덧셈·곱셈 | 부트스트래핑으로 깊이 연장 |
| 한계 | 지원 연산 제한 | 깊이에 따른 큰 매개변수 | 높은 부트스트래핑 비용 |

> 요약: 연산 지원 범위와 회로 깊이에 따라 방식을 선택한다

### 쉽게 이해하기 (학습용)

- 지원할 덧셈·곱셈과 회로 깊이에 따라 부분·준·완전 동형 방식과 매개변수를 선택합니다.

## Ⅵ. 실무 사례

- 외부 서버가 암호화된 입력으로 추론을 수행한다.
- 복호화 결과의 단위와 접근 권한을 제한한다.

### 쉽게 이해하기 (학습용)

- 입력을 숨겨 계산해도 복호화된 예측 결과에서 민감정보를 추론할 가능성은 별도로 점검합니다.

## Ⅶ. 결론

- 계산 비용과 복호화 결과의 노출 위험을 함께 관리함

### 쉽게 이해하기 (학습용)

- 암호문 계산 가능성만 보지 않고 지연·정확도와 복호화 결과의 노출 위험까지 설계해야 합니다.
