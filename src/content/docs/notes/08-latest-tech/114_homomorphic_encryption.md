## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **동형암호(Homomorphic Encryption, HE)**: 입력을 복호화하지 않고 암호문 상태에서 계산해 평문 계산과 대응하는 결과 암호문을 얻는 공개키 암호 기법이다.
- **처리 중 평문 노출**: 외부 연산을 위해 암호 데이터를 복호화하면서 원본 값이 메모리나 처리자에게 보이는 위험이다.

</details>

- 정의/개념: **HE**는 암호문 연산 결과가 평문 연산 결과와 대응하도록 하는 공개키 암호 기법이다.
- 배경/필요성: 일반 암호는 외부 연산 전에 복호화하여 **처리 중 평문 노출**이 발생한다.

#### 한줄 요약
- 잠긴 상자를 열지 않고 계산한 뒤 열쇠를 가진 사람만 결과 상자를 열어 봄이 핵심이다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **암호문 평가**: 비밀키 없이 암호문에 덧셈•곱셈 등의 연산 회로를 적용하는 과정이다.
- **암호문 노이즈**: 보안을 위해 포함되며 곱셈을 반복할수록 커져 복호화 가능 범위를 제한하는 오차 성분이다.
- **부트스트래핑**: 암호문 자체의 복호화 회로를 동형 연산해 노이즈와 연산 여유를 새로 고치는 기법이다.

</details>

- 비밀키 없이 입력•중간값을 계산하는 **암호문 평가**가 핵심이다.
- 곱셈 깊이•노이즈에 따른 **매개변수•복호화 한계**가 핵심이다.
- 부트스트래핑 기반 **암호문 연산 여유 회복**이 핵심이다.

#### 한줄 요약
- 잠긴 값으로 곱셈할수록 잡음이 쌓여 한계 전에 큰 비용을 들여 암호문을 새로 고침이 핵심이다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **패킹**: 여러 평문 값을 하나의 암호문 슬롯에 묶어 병렬 연산하는 기법이다.
- **재선형화**: 암호문 곱셈 뒤 커진 암호문 크기를 평가 키로 줄이는 연산이다.
- **스케일 관리**: 근사 실수 연산에서 값의 정밀도와 암호문 모듈러스 수준을 조정하는 처리이다.

</details>

```text
                    [키•매개변수 관리자]
                    /          |          \
             [인코더•패커] [암호문 평가기] [결과 복호화기]
                                 |
                       [노이즈•스케일 관리자]
```

선의 의미: 키•매개변수 관리자는 인코더•패커, 암호문 평가기, 결과 복호화기의 공통 암호 경계를 정의하고, 노이즈•스케일 관리자는 암호문 평가기의 연산 가능 범위를 통제한다.

| 구성요소 | 책임 |
|:---|:---|
| 키•매개변수 관리자 | 보안•깊이별 **암호•평가 키 생성** |
| 인코더•패커 | 평문 값의 **암호문 슬롯 배치** |
| 암호문 평가기 | 덧셈•곱셈•회전의 **평가 회로 실행** |
| 노이즈•스케일 관리자 | 재선형화•부트스트래핑의 **연산 한계 통제** |
| 결과 복호화기 | 비밀키 기반 **결과 평문 복원** |

#### 한줄 요약
- 열쇠와 상자 크기를 정하고 값을 묶어 잠근 뒤 외부 계산자는 잠긴 채 계산하고 소유자만 결과를 엶이 핵심이다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **곱셈 깊이**: 연산 회로에서 순차적으로 이어지는 암호문 곱셈의 최대 횟수이다.
- **평가 키**: 암호문 연산의 재선형화•회전 등을 수행하도록 공개되는 보조 키이다.

</details>

```text
데이터 소유자 ── 연산 함수•보호 목표 ──▶ 키•매개변수 관리자
키•매개변수 관리자 ── 1. 키•암호 매개변수 생성 ──▶ 인코더•암호화기
데이터 소유자 ── 평문 입력 ──▶ 인코더•암호화기
인코더•암호화기 ── 2. 입력 인코딩•암호화 ──▶ 암호문 평가기
암호문 평가기
   │ 3. 암호문 회로 평가
   └── 결과 암호문 ──▶ 데이터 소유자
데이터 소유자
   └ 4. 결과 복호화•오차 확인
```

1. **키•암호 매개변수 생성**: 곱셈 깊이•정확도에 맞춰 설정한다.
2. **입력 인코딩•암호화**: 평문 벡터를 슬롯에 패킹해 암호화한다.
3. **암호문 회로 평가**: 노이즈•스케일을 관리하며 연산을 실행한다.
4. **결과 복호화•오차 확인**: 비밀키 복원값과 허용 오차를 검증한다.

#### 한줄 요약
- 계산 깊이에 맞는 상자와 열쇠를 만들고 값을 잠가 계산한 뒤 결과 오차를 확인하는 것이 핵심이다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **부분 동형암호**: 덧셈 또는 곱셈 한 종류만 반복 지원하는 방식이다.
- **제한 동형암호**: 미리 정한 곱셈 깊이 안에서 덧셈과 곱셈을 지원하는 방식이다.
- **완전 동형암호**: 부트스트래핑으로 연산 여유를 회복해 임의 깊이 계산을 지원하는 방식이다.

</details>

| 비교 기준 | 부분 동형 | 제한 동형 | 완전 동형 |
|:---|:---|:---|:---|
| 적용 기준 | 한 종류 연산 반복 | 사전 정의 깊이 회로 | 임의 깊이 반복 계산 |
| 핵심 특징 | 덧셈 또는 곱셈의 **단일 동형성** | 제한 깊이의 **덧셈•곱셈** | 부트스트래핑 기반 **깊이 연장** |
| 한계 | 지원 연산 제한 | 깊이별 큰 매개변수 | 높은 부트스트래핑 비용 |

#### 한줄 요약
- 덧셈이나 곱셈 하나만 할지, 정한 횟수만 할지, 상자를 새로 고치며 계속할지의 차이다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **복호화 실패**: 암호문 노이즈가 허용 범위를 넘어 결과 평문을 올바르게 복원하지 못하는 문제이다.
- **천-김-김-송 근사 오차(Cheon-Kim-Kim-Song Approximation Error, CKKS 근사 오차)**: 실수 벡터 연산의 스케일 조정과 반올림으로 결과 오차가 누적되는 문제이다.
- **부트스트래핑 지연**: 암호문 연산 여유를 회복하는 복잡한 회로 때문에 처리 시간이 급증하는 문제이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 과소 매개변수의 **복호화 실패** | 회로 깊이•노이즈 예산 기반 매개변수 산정 | 결과 복호화 **성공 보장** |
| **CKKS 방식**의 근사 오차 누적 | 스케일•재조정 위치별 평문 대비 오차 시험 | 추론 정확도 **검증** |
| 부트스트래핑의 **지연 급증** | 회로 깊이 축소•패킹•실행 횟수 최소화 | 암호문 연산 비용 **절감** |

#### 한줄 요약
- 계산 횟수에 맞는 큰 상자를 고르고 근사 오차와 상자 새로 고침 시간을 함께 측정하는 것이 핵심이다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **모듈러스**: 암호문 계수의 연산 범위와 노이즈 여유를 정하는 나머지 연산 기준값이다.
- **암호 매개변수**: 보안 수준•연산 깊이•정확도에 맞춰 정하는 차원•모듈러스•스케일 등의 값이다.

</details>

- 단일 연산은 **부분 동형**, 고정 깊이는 **제한 동형**, 임의 깊이는 완전 동형을 선택한다.

#### 한줄 요약
- 필요한 계산 깊이와 허용 오차•시간에 맞춰 암호 방식과 상자 크기, 새로 고칠 시점을 정하는 것이 핵심이다.
