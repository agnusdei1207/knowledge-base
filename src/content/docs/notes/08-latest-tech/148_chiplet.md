## 미리 알고가기

- **칩렛 (Chiplet)**: 거대 칩을 기능별 다이로 분할하고 패키지에서 재연결하는 설계 방식
- **제조 수율**: 결함 면적을 최소화해 개별 다이 수율과 선별 사용성을 높임
- **인터커넥트 지연**: 다이 간 고속 배선에 따른 지연과 패키징 복잡도가 주요 제약임



## Ⅰ. 개요

- **정의/개념**: 기능별 다이를 패키지 링크로 결합하는 설계다
- **배경/필요성**: 단일 대형 다이만으로 수율·공정 혼합·설계 재사용 비용 개선 곤란

### 쉽게 이해하기 (학습용)

- 큰 칩을 기능별 작은 부품으로 따로 만들고 패키지 안의 전용 배선으로 다시 조립한다.

## Ⅱ. 특징

- 소형 다이 기반 **제조 수율 개선**
- 기능별 공정 선택과 **검증 다이 재사용**
- 분할 증가에 따른 **링크·패키징 비용**

### 쉽게 이해하기 (학습용)

- 작은 다이는 선별과 공정 선택이 쉽지만 너무 잘게 나누면 연결 지연과 조립·검사 비용이 커진다.

## Ⅲ. 아키텍처 및 구성요소

| 설계 요소 | 설명 |
|:---|:---|
| 기능 칩렛 | 연산·입출력·메모리 제어 독립 다이 |
| 인터커넥트 | 다이 간 데이터·제어 전송 경로 |
| 패키지 기판 | 칩렛 배치 및 전력·열 전달 물리 경계 |
| 시스템 관리 | 순서·전력·오류 상태 통합 조정 |
| 테스트 구조 | 양품 선별 및 시스템 진단 경로 |

> 요약: 기능 다이·링크·기판·관리·시험을 패키지로 결합한다

### 쉽게 이해하기 (학습용)

- 기능 칩렛을 링크와 기판으로 연결하고 시스템 관리와 시험 구조가 전력·열·오류를 함께 통제한다.

## Ⅳ. 원리 및 절차 흐름도

```text
분할 경계 분석
    ↓
링크 예산 확정
    ↓
다이 제조·선별
    ↓
패키지 공동 설계
    ↓
조립·링크 훈련
    ↓
통합 검증
```

| 절차 | 설명 |
|:---|:---|
| 분할 분석 | 응집도·재사용·다이 수율로 경계 결정 |
| 링크 예산 | 트래픽 기반 대역폭·지연·전력 산정 |
| 제조·선별 | 기능별 공정으로 조립 전 양품 선별 |
| 공동 설계 | 배치·배선·전력·열·시험 경로 결정 |
| 조립·훈련 | 다이 조립·링크 특성 설정 |
| 통합 검증 | 기능·열·전력 부하 환경 성능 확인 |

> 요약: 분할·링크 예산 뒤 양품 다이를 조립·검증한다

### 쉽게 이해하기 (학습용)

- 수율과 재사용을 기준으로 다이를 나누고 링크·전력·열 예산에 맞춰 양품 다이를 조립해 검증한다.

## Ⅴ. 반도체 통합 방식 비교

| 구분 | 모놀리식 SoC | 칩렛 SiP | 보드 다중 칩 |
|:---|:---|:---|:---|
| 기능 경계 | 다이 내 통합 | 패키지 내 다이 통합 | 보드 기반 부품 연결 |
| 적용 기준 | 면적·지연 최우선 | 공정 혼합·재사용 중시 | 교체·단순 구성 중시 |
| 핵심 특징 | 단일 다이에 기능 통합 | 다이를 패키지 링크로 통합 | 패키지를 보드에서 연결 |
| 한계 | 대형 다이 수율·비용 | 링크·패키지·열 복잡성 | 거리·전력·대역폭 한계 |
| 주요 병목 | 단일 결함 손실 | 링크·패키지·테스트 | 배선 지연·전력 |

> 요약: 지연은 SoC, 공정 혼합은 칩렛, 교체는 보드를 택한다

### 쉽게 이해하기 (학습용)

- 최소 지연은 단일 SoC, 공정 혼합·재사용은 칩렛, 쉬운 부품 교체는 보드 다중 칩이 알맞다.

## Ⅵ. 실무 사례

1. 연산은 미세 공정, 입출력은 성숙 공정으로 분리한다
2. 가속기 다이 수·배치를 대역폭·열 한도에 맞춘다

### 쉽게 이해하기 (학습용)

- 연산 다이는 미세 공정으로 성능을 높이고 입출력 다이는 성숙 공정으로 비용을 줄인다.
- 가속기 패키지는 링크 대역폭과 열 한도 안에서 연산·입출력 다이 수와 배치를 정한다.

## Ⅶ. 결론

- 수율·공정 이득이 조립·시험 비용보다 클 때 적용한다.

### 쉽게 이해하기 (학습용)

- 개별 다이 수율만 보지 않고 조립·링크·시험을 포함한 최종 패키지 수율과 비용으로 칩렛을 선택한다.
