## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **칩렛(Chiplet)**: 크고 복잡한 단일 칩(Monolithic)을 제조하는 대신, 여러 개의 작은 단위 칩(Chiplet)을 독립적으로 제조한 후 패키징 기술을 통해 하나의 반도체처럼 작동하도록 결합하는 고수율 제조 공법
- **다이(Die)**: 반도체 웨이퍼에서 개별 칩 기능을 수행하도록 잘라 낸 회로 조각이다.

</details>

- 정의: 거대 칩을 기능별 다이로 나눠 패키지로 결합하는 **칩렛**
- 배경/필요성: 대형 단일 다이는 면적이 커질수록 결함 확률이 올라 **수율•공정 선택•재사용**에 제약이 생기고 폐기 비용이 다이 전체가 되므로, 기능별로 작은 다이를 따로 제조해 패키지 안 고속 링크로 잇는 조립 계층으로 분해

#### 한줄 요약

- 기능별 소형 다이를 제조해 **패키지 내 고속 링크** 기반 결합

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **제조 수율**: 생산한 다이 가운데 기능•성능 기준을 만족하는 양품의 비율이다.
- **인터커넥트 지연**: 서로 다른 다이 사이의 링크를 통해 데이터를 전송할 때 발생하는 대기 시간이다.

</details>

![다이 면적에 따른 상대 수율 모형](/study/diagrams/chiplet-die-yield.svg)

> 다이 면적이 커질수록 파란 상대 수율 선이 지수적으로 낮아져 작은 다이 분할의 근거가 되며, 결함 밀도 $D_0=0.005/mm^2$를 가정한 모형값이지 실공정 수율은 아니다.

- 소형 다이 분할로 **제조 수율 개선**
- 기능별 공정 선택과 **검증 다이 재사용**
- 과도한 분할에 따른 **링크•패키징 비용 증가**

#### 한줄 요약

- 작은 다이는 선별과 공정 선택이 쉽지만 너무 잘게 나누면 연결 지연과 조립•검사 비용이 커진다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **유니버설 칩렛 인터커넥트 익스프레스(Universal Chiplet Interconnect Express, UCIe)**: 패키지 내 칩렛 사이의 물리•프로토콜 연결을 표준화한 인터페이스이다.
- **기능 칩렛(Functional Chiplet)**: 연산•입출력•메모리 제어 등 독립 기능을 담당하는 다이이다.
- **패키지 기판**: 여러 칩렛을 지지하고 전원•신호 연결을 제공하는 패키지 계층이다.
- **시스템 관리기**: 칩렛의 부팅•전력•열•오류•펌웨어와 링크 상태를 통합 제어하는 구성요소이다.
- **테스트 구조**: 조립 전 다이와 조립 후 링크•시스템의 결함을 확인하는 진단 경로이다.

</details>

```text
              [시스템 관리기]   [테스트 구조]
                       \           /
                       [패키지 기판]
                         /       \
                  [기능 칩렛]---[인터커넥트]
```
선의 의미: 칩렛•인터커넥트의 물리 수용과 운영•결함 관리 관계

| 구성요소 | 책임 |
|:---|:---|
| 기능 칩렛 | **연산•입출력•메모리 제어** 독립 다이 |
| 인터커넥트 | **UCIe 데이터•제어 전송** 경로 |
| 패키지 기판 | **칩렛 배치•전력•열 전달** 경계 |
| 시스템 관리기 | **순서•전력•오류 상태** 통합 조정 |
| 테스트 구조 | **양품 선별•시스템 진단** 경로 |

#### 한줄 요약

- 기능 칩렛 연결과 **전력•열•오류 통제** 구조

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **기능 분할**: 응집도•공정•재사용•수율을 고려해 단일 칩 기능을 여러 다이 경계로 나누는 방식이다.
- **링크 훈련**: 조립된 칩렛 사이에서 신호 조건과 전송 특성을 맞춰 통신 경로를 여는 과정이다.

</details>

```text
기능 칩렛
   │ 1. 기능 분할•트래픽 요구
   ▼
인터커넥트
   │ 2. 대역폭•지연•전력 예산
   ▼
패키지 기판
   │ 3. 양품 다이•배치•배선
   ▼
테스트 구조
   │ 4. 조립 검사•링크 훈련
   ▼
인터커넥트 ── 기능•열•전력 검증 결과 ──▶ 기능 칩렛
```

### 동작 원리

1. 기능 분할•트래픽 요구: 응집도•재사용•수율로 다이 경계 결정
2. 대역폭•지연•전력 예산: 다이 간 통신 링크 사양 산정
3. 양품 다이•배치•배선: 공정별 선별 다이를 패키지에 공동 설계
4. 조립 검사•링크 훈련: 연결 결함과 링크 특성 확인

#### 한줄 요약

- 다이 분할 후 **링크•전력•열 예산**에 맞춰 조립 검증

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **모놀리식 시스템 온 칩(Monolithic System on Chip, Monolithic SoC)**: 여러 시스템 기능을 하나의 반도체 다이에 통합한 칩이다.
- **시스템 인 패키지(System in Package, SiP)**: 여러 다이를 하나의 패키지 안에 조립해 시스템 기능을 구성하는 방식이다.

</details>

**칩렛 SiP**와 **모놀리식 SoC**의 기능 분할 여부 비교

| 반도체 통합 방식 | 칩렛 SiP | 모놀리식 SoC | 보드 다중 칩 |
|:---|:---|:---|:---|
| 적용 기준 | **공정 혼합•재사용** | **면적•지연 최우선** | **교체•단순 구성** |
| 핵심 특징 | **패키지 내 다이 링크** | **단일 다이 기능 통합** | **보드 기반 부품 연결** |
| 한계 | **링크•패키지•열 복잡성** | **대형 다이 수율•비용** | **거리•전력•대역폭 한계** |

> 요약: **SoC**는 최소 지연, **칩렛**은 공정 혼합, 보드는 교체 중심

#### 한줄 요약

- 최소 지연은 SoC, 공정 혼합은 칩렛, **부품 교체**는 보드 다중 칩

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Known Good Die**: 패키지 조립 전에 기능과 품질이 정상임을 시험해 선별한 다이이다.
- **열 경로 공동 설계**: 칩렛 배치•기판•방열 구조를 함께 설계해 열 집중을 줄이는 방법이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 과도한 분할로 **다이 간 트래픽 증가** | 응집도 기반 **경계•링크 예산** 설계 | **통신 병목** 감소 |
| 불량 다이 조립으로 **패키지 수율 저하** | **Known Good Die•사전 선별** 적용 | **불량 패키지 손실** 축소 |
| 고전력 칩렛으로 **열 집중** | 기판 배치•**열 경로 공동 설계** | **핫스폿** 완화 |

#### 한줄 요약

- 공정 혼합•양품 선별•열 경로로 **패키지 수율** 확보

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **공정 혼합**: 기능별 칩렛을 성능•비용 특성이 다른 반도체 제조 공정으로 생산해 결합하는 방식이다.
- **패키지 수율**: 다이•연결•조립을 모두 마친 패키지 가운데 정상 동작하는 제품의 비율이다.

</details>

- 공정 혼합•재사용은 **칩렛**, 면적•지연은 **모놀리식 SoC** 선택

#### 한줄 요약

- 조립•링크•시험을 포함한 **패키지 수율•비용** 기반 선택
