## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **디지털 제품 여권(Digital Product Passport, DPP)**: 고유 식별자를 통해 제품의 원재료•제조•사용•수리•재활용 정보를 생애주기 전반에 연결하는 기록 체계을 말한다.

</details>

- 정의/개념: 식별자로 제품의 원재료•제조•사용•재활용 정보를 연결한 **DPP 체계**임.
- 배경/필요성: 기업별 분산 정보로는 공급망 전체의 **제품 이력•규제 준수** 검증이 어렵음.

#### 한줄 요약

- 제품 식별자 기반 생애주기 정보와 순환경제 데이터를 연결한다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **분산 상호운용**: 운영자별 저장소의 제품 정보를 표준 데이터 모델과 API로 연결해 교환하는 방식을 말한다.
- **응용 프로그래밍 인터페이스(Application Programming Interface, API)**: 소프트웨어 간 기능•데이터 교환 규칙을 정의한 접점을 의미한다.
- **빠른 응답 코드(Quick Response Code, QR Code)**: 카메라로 식별 정보와 데이터 위치를 읽는 이차원 코드을 의미한다.

</details>

- 제품 표식과 데이터 위치를 분리하고 운영자별 저장소를 표준 API로 연결하는 **식별자•매체 분리•분산 상호운용**이 핵심임.
- 공개•제한 정보를 이용자별로 구분하는 **역할 기반 접근**이 핵심임.
- 재사용•수리•재활용 이력을 연결하는 **순환경제**를 지원함.
#### 한줄 요약

- 빠른 응답 코드 기반 식별과 역할별 접근•분산 데이터를 관리한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **고유 식별자**: 실제 제품과 디지털 생애주기 기록을 지속적으로 연결하는 참조 키을 말한다.
- **데이터 운반체(Data Carrier)**: QR 코드•데이터 매트릭스•근거리 통신 등 제품에서 여권 식별자와 정보 위치를 읽는 매체로 정의된다.
- **분산 저장소**: 공급망 주체가 제품의 원천 생애주기 데이터를 보유하는 저장소이다.
- **중앙 색인**: 제품 식별자와 분산 정보 위치를 등록•검색하는 목록이다.
- **표준화된 인터페이스**: 서로 다른 시스템이 제품•소재•수리•재활용 정보를 동일한 의미와 형식으로 교환하는 계약로 정의된다.
- **접근 제어**: 공개•제한 정보를 이용자 역할에 따라 제공하는 통제을 의미한다.
- **검증 증명**: 발급 주체와 데이터 무결성을 확인하는 증거로 정의된다.

</details>

```text
                    [중앙 색인]   [접근 제어]
                         \       /
                        [식별체계]
                            |
                 [표준화된 인터페이스]
                            |
                      [분산 저장소]
```
선의 의미: 중앙 색인은 식별체계의 제품 식별자와 정보 위치를 등록•검색하고, 접근 제어는 식별된 정보의 공개 경계를 제한하며, 표준화된 인터페이스는 식별체계와 분산 저장소 사이의 상호운용 계약을 제공한다.

| 구성요소 | 책임 |
|:---|:---|
| 식별체계 | 품목별 **고유 식별자•정보 위치** 매핑 |
| 분산 저장소 | 운영자별 **생애주기 데이터** 관리 |
| 표준화된 인터페이스 | API 기반 **상호운용•데이터 교환** |
| 접근 제어 | 역할별 **권한•보안 데이터** 통제 |
| 중앙 색인 | 핵심 식별자의 **등록•검색** 지원 |

#### 한줄 요약

- 제품 번호로 자료를 찾고 중앙 목록으로 검색하며 역할별 접근하는 것이 핵심이다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **검증 가능한 이력**: 발행 주체와 변경 시점•무결성을 확인할 수 있도록 연결한 제품 생애주기 기록하는 정보을 말한다.

</details>

```text
[규정 담당]
    │ 1. 필수 항목 정의
    ▼
[식별 체계]
    │ 2. 식별자•매체 설계
    ▼
[공급망] ── 3. 생애주기 이력 등록 ──▶ [중앙 색인]
[이용자] ───── 제품 여권 조회 ───────▶ [중앙 색인]
[중앙 색인] ── 4. 권한•원천 위치 확인 ▶ [공급망]
[중앙 색인] ◀─ 5. 검증 이력 제공 ───── [공급망]
[이용자] ◀──── 제품 여권 정보 ──────── [중앙 색인]
```

**동작 원리**

1. **필수 항목 정의**: 품목별 대상과 보존•공개 조건을 확정함.
2. **식별자•매체 설계**: 제품과 데이터 위치를 지속을 연결함.
3. **생애주기 이력 등록**: 출처•서명•시점을 포함한 사건을 누적함.
4. **권한•원천 위치 확인**: 이용자 역할과 분산 저장소 위치를 판정함.
5. **검증 이력 제공**: 허용 범위의 원천 기록과 무결성 증명을 반환함.

#### 한줄 요약

- 대상 규정을 정하고 번호와 항목을 설계한 뒤, 정보를 공개하고 관리하는 것이 핵심이다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **디지털 인증서**: 특정 시점의 속성이나 적합성을 발행자가 전자적으로 증명하는 문서이며, DPP의 전체 생애주기 기록과 범위가 다르을 말한다.

</details>

QR Code는 제품 식별 정보와 데이터 위치를 전달하는 매체이다.

| 판단 기준 | 디지털 제품 여권 | 데이터 매체(QR 등) | 중앙 등록 목록 |
|:---|:---|:---|:---|
| 적용 기준 | **생애주기 정보 제공** | **식별 정보 전달** | 제품 **검색•감독** |
| 핵심 특징 | 제품 **생애주기 데이터 기록** | **식별 정보 전달 매체** | 제품 목록의 **색인 정보** |
| 한계 | 공급망 전체의 **이력 품질 의존** | **복제•교체 위험** | **식별자 색인 관리** 필요 |

#### 한줄 요약

- 생애주기는 DPP, 위치 전달은 QR, 검색•감독은 중앙 목록이 핵심이다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **역할 기반 접근**: 소비자•수리자•규제기관 등 이용자 역할에 따라 공개 정보와 제한 정보의 열람 범위를 구분하는 개념을 말한다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **식별자•실물 결합** 미검증 시 QR Code 복제•교체로 다른 제품 정보 연결 | 위변조 방지 운반체, 일련번호 검증, 소유•수리 사건 서명 | 실물•DPP **식별 정합성** 확보 |
| **데이터 신뢰성** 미검증 시 공급망 주체의 허위•누락 자료로 추적성 약화 | 출처•책임자•시각 기록, 필수항목 검증, 표본 감사 | 데이터 **출처 신뢰성** 향상 |
| **공개 범위 충돌** 미검증 시 영업비밀•개인정보 노출 또는 수리 정보 부족 | 역할 기반 접근, 최소 공개, 목적별 상세 수준과 철회 정책 | 공개•**정보 보호** 균형 |

#### 한줄 요약

- 실물 식별자와 데이터 출처를 검증하고 이용자 역할별 공개 범위를 제한한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **순환경제**: 제품과 자원을 수리•재사용•재활용하여 폐기와 신규 자원 투입을 줄이는 경제 구조이다.

</details>

- 품목별 법령•이용자 역할에 따라 **DPP 항목•공개 범위**를 결정함.

#### 한줄 요약

- 모든 제품의 통일이 아닌 제품별 맞춤형 정보 전달 사업이다.
