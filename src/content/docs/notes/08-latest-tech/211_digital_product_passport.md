## 미리 알고가기

- **DPP(Digital Product Passport)**: 제품 생애주기 전반의 원재료·제조·사용·재활용 기록 체계
- **데이터 교환**: 단순 QR 라벨이 아닌 표준화된 데이터 검증과 교환이 핵심
- **순환경제**: 환경 규제 대응과 지속가능성 구현 및 투명성 확보에 활용됨



## Ⅰ. 개요

- 정의/개념: 식별자로 제품 생애주기 정보를 연결한 기록
- **배경/필요성**: 공급망 투명성·순환성·규제 검증을 지원

### 쉽게 이해하기 (학습용)

- 정보를 열람하는 디지털 인증서이자 순환경제를 위한 데이터 플랫폼임

## Ⅱ. 특징

- 식별자·매체 분리가 데이터 위치를 유연화한다.
- 분산 관리·표준 API가 상호운용을 보장한다.
- 역할 기반 접근이 공개·제한 정보를 구분한다.
- 품목별 법령이 적용 항목·시기를 확정한다.

### 쉽게 이해하기 (학습용)

- 열쇠인 QR로 권한에 맞는 정보만 읽고 책임자가 분산 관리하는 구조임

## Ⅲ. 아키텍처 및 구성요소

| 설계 요소 | 설명 |
|:---|:---|
| 식별체계 | 품목별 고유 식별자 생성과 정보 위치 매핑 |
| 분산 저장소 | 운영자별 생애주기 데이터 저장과 관리 |
| 표준화된 인터페이스 | API 기반 상호운용과 데이터 교환 표준 지원 |
| 접근 제어 | 역할별 권한 정의와 보안 데이터 통제 |
| 중앙 색인 | 핵심 식별자의 등록과 검색 지원 체계 |

> 요약: 식별자·분산 저장소·표준 API를 결합

### 쉽게 이해하기 (학습용)

- 제품 번호로 자료를 찾고 중앙 목록으로 검색하며 역할별 접근함

## Ⅳ. 원리 및 절차 흐름도

```text
규정판정
  ↓
식별설계
  ↓
데이터수집
  ↓
공개등록
  ↓
이력갱신
```

| 절차 | 설명 |
|:---|:---|
| 규정판정 | 품목별 적용 대상과 필수 항목 확인함 |
| 식별설계 | 제품 고유 식별자와 데이터 경로 설계함 |
| 데이터수집 | 공급망 내 표준 데이터 형식으로 수집함 |
| 공개등록 | 중앙 목록에 식별자 등록 및 접근 제공함 |
| 이력갱신 | 제품 교체 및 수리 이력 지속 반영함 |

> 요약: 규정 확인 후 식별체계를 설계하고 데이터를 운영 관리함.

### 쉽게 이해하기 (학습용)

- 대상 규정을 정하고 번호와 항목을 설계한 뒤, 정보를 공개하고 관리함

## Ⅴ. 종류 및 비교

| 판단 기준 | 디지털 제품 여권 | 데이터 매체(QR 등) | 중앙 등록 목록 |
|:---|:---|:---|:---|
| 핵심 특징 | 제품 생애주기 데이터 기록 | 식별 정보 전달 매체 | 제품 목록 색인 정보 |
| 적용 기준 | 운영자 분산 서버 | 정보 전달의 경로 | 검색과 감독 정보 |
| 주요 위험 | 전체 생애주기 이력 | 물리적 접근 연결 | 식별자 색인 관리 |

> 요약: DPP 데이터·접근 매체·검색 목록을 구분

### 쉽게 이해하기 (학습용)

- 여권은 책, QR은 위치 안내, 목록은 도서관 안내서임

## Ⅵ. 실무 사례

1. 대상 환경의 도입 조건과 설계를 검증함
2. 운영 위험과 성과 지표를 검증함

### 쉽게 이해하기 (학습용)

- EU 시장 철강 제조사는 product-specific delegated act 확정 전 material origin·recycled content·carbon data의 owner와 evidence를 정하고, batch identifier·carrier·EN 표준 API를 pilot해 법정 field와 시행일이 확정되면 rule version만 전환함
- 의류 circularity pilot은 garment item에 carrier를 부여해 consumer에는 material·care·repair를, 수선업체에는 component·repair instruction을, recycler에는 fiber·hazard data를 제공하고 수선 event를 원 passport에 갱신함

## Ⅶ. 결론

- 품목 법령·접근 역할로 DPP 항목·공개 범위 결정

### 쉽게 이해하기 (학습용)

- 모든 제품의 통일이 아닌 제품별 맞춤형 정보 전달 사업임
