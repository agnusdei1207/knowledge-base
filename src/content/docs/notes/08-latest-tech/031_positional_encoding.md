## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **위치 인코딩(Positional Encoding)**: 순열에 불변인 어텐션이 토큰의 순서와 거리를 구분하도록 위치 신호를 주입하는 기법이다.
- **순열 불변성**: 입력 원소의 순서를 바꿔도 연산 결과가 같은 성질이다.

</details>

- 정의/개념: 순열에 불변인 셀프 어텐션이 토큰의 순서와 상대 거리를 구분하도록 위치 정보를 표현에 결합하는 **위치 인코딩**이다.
- 배경/필요성: **순열 불변성**이 있는 셀프 어텐션은 동일 토큰 집합의 배열 순서와 거리를 구분하기 어렵다.

#### 한줄 요약
- 순서와 상대 거리를 토큰 표현에 결합한다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **절대 위치 인코딩**: 각 토큰의 고유한 순번에 대응하는 위치값을 입력 표현에 더하는 방식이다.
- **상대 위치 인코딩**: 토큰 쌍 사이의 거리나 방향을 어텐션 점수 또는 Q•K 변환에 반영하는 방식이다.
- **외삽(Extrapolation)**: 학습 때 보지 못한 최대 길이 밖의 위치까지 학습한 위치 규칙을 연장하여 적용하는 방식이다.
- **쿼리(Query, Q)**: 현재 토큰이 찾을 정보의 조회 기준 벡터이다.
- **키(Key, K)**: 쿼리와 비교할 식별 벡터이다.

</details>

![Observable Plot으로 그린 위치별 고주파•저주파 사인 인코딩 값](/study/diagrams/positional-encoding.svg)

> 빠른 주기는 인접 위치를 세밀하게 구분하고, 느린 주기는 넓은 위치 범위의 변화를 표현한다.

- 입력 임베딩 또는 **쿼리**•**키** 회전에 순서•거리 정보를 주입한다.
- **절대 위치 인코딩**과 **상대 위치 인코딩**은 참조 관계 표현 방식이 다르다.
- 학습 문맥 길이 밖에서는 **외삽** 오차가 발생할 수 있다.

#### 한줄 요약
- 절대•상대 위치 표현으로 참조 관계를 구분한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **회전 위치 임베딩(Rotary Position Embedding, RoPE)**: 위치에 따라 Q•K 벡터를 회전시켜 내적에 상대적 거리를 반영하는 방식이다.
- **위치 보간(Position Interpolation)**: 긴 위치 인덱스를 학습된 범위 안으로 비례 압축하여 위치 표현을 확장하는 방식이다.
- **주입 계층**: 위치 벡터를 임베딩에 더하거나 회전값을 Q•K에 적용하여 내용과 위치를 결합하는 계층이다.

</details>

```text
                       [위치 표현기]
                      /       |       \
             [위치 인덱스] [주입 계층] [길이 확장기]
```

선의 의미: 위치 표현기는 위치 인덱스를 위치 신호로 표현하고, 주입 계층에 결합 규칙을 제공하며, 길이 확장기의 보간•스케일 조정을 적용받는다.

| 구성요소 | 책임 |
|:---|:---|
| 위치 인덱스 | 절대 순서•상대 거리 또는 패치 좌표 생성 |
| 위치 표현기 | 삼각함수•학습 벡터•**RoPE 회전 변환** |
| 주입 계층 | **주입 계층**에서 임베딩 가산 또는 Q•K 변환 |
| 길이 확장기 | **위치 보간•스케일 조정**으로 장문 보정 |

#### 한줄 요약
- 위치 인덱스•표현•주입•확장으로 구성한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **위치 신호**: 고정 함수•학습 벡터•회전값으로 토큰의 순서나 거리를 표현한 값이다.
- **토큰 의미 임베딩 생성**: 위치 정보를 제외한 토큰 내용의 벡터 표현을 만드는 절차이다.
- **위치 인덱스•거리 산출**: 토큰별 절대 순서나 토큰 쌍의 상대 거리를 계산하는 절차이다.
- **위치 벡터•회전값 생성**: 고정 함수•학습값•RoPE로 위치 신호를 만드는 절차이다.
- **임베딩 또는 Q•K에 주입**: 위치 신호를 내용 표현이나 쿼리•키 변환에 결합하는 절차이다.

</details>

```text
토큰
  │ 1. 토큰 의미 임베딩 생성
  ▼
인코더
  │ 2. 위치 인덱스•거리 산출
  ▼
위치 연산기
  │ 3. 위치 벡터•회전값 생성
  ▼
인코더
  │ 4. 임베딩 또는 Q•K에 주입
  ▼
어텐션
  │ 순서•거리 반영 문맥 출력
  ▼
출력
```

1. **토큰 의미 임베딩 생성**: 위치를 제외한 토큰의 내용 표현을 준비한다.
2. **위치 인덱스•거리 산출**: 토큰별 절대 순서나 토큰 쌍의 상대 거리를 계산한다.
3. **위치 벡터•회전값 생성**: 고정 함수•학습값•**RoPE** 기반 위치 신호를 변환한다.
4. **임베딩 또는 Q•K에 주입**: **주입 계층**에서 위치 신호를 결합한다.

#### 한줄 요약
- **위치 신호**를 임베딩 또는 Q•K에 주입이 핵심이다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **상대 위치 방식**: 토큰 사이 거리 관계를 어텐션 계산에 반영하여 장문 일반화에 유리한 방식이다.
- **절대 위치 방식**: 토큰별 위치값을 입력에 직접 더하여 고정 길이의 명시적 순서를 표현하는 방식이다.

</details>

| 비교 기준 | 상대 위치 인코딩 | 절대 위치 인코딩 |
|:---|:---|:---|
| 적용 기준 | 거리 관계•장문 일반화 중심 | 고정 길이의 명시적 순서 중심 |
| 핵심 특징 | 어텐션 점수•Q•K에 토큰 간 거리 반영 | 입력 표현에 토큰별 위치값 가산 |
| 한계 | 구현•캐시 변환 복잡성 | 학습 최대 길이 밖 외삽 취약 |

#### 한줄 요약
- 고정 순서는 **절대 위치 방식**, 장문 거리 관계는 **상대 위치 방식**이 적합하다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **위치 외삽 오차**: 학습 길이 밖의 위치 신호가 훈련 분포와 달라져 순서•거리 해석이 부정확해지는 현상이다.
- **단거리 해상도**: 가까운 토큰 사이의 작은 위치 차이를 구분하는 위치 표현의 정밀도이다.
- **위치 인덱스 일치**: 학습•추론의 패딩•캐시•청크 경계에서 같은 토큰에 같은 위치 규칙을 적용하는 조건이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 학습 길이 초과 시 **위치 외삽 오차** | **위치 보간**•RoPE 스케일 조정 후 길이별 평가 | 장문 정확도 급락 완화 |
| 위치 확장에 따른 **단거리 해상도** 저하 | 단•장문 평가셋•주파수별 보정 비교 | 단거리 해상도 보존 |
| 학습•추론의 위치 인덱스 불일치 | **위치 인덱스 일치** 단위 시험 | 토큰 순서 왜곡과 캐시 오류 방지 |

#### 한줄 요약
- 길이별 평가와 인덱스 시험으로 위치 왜곡을 방지한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **위치 표현 선택 기준**: 고정 길이에는 절대 위치를, 장문 외삽에는 RoPE와 위치 보간을 적용하는 기준이다.

</details>

- **위치 표현 선택 기준**에 따라 고정 길이에는 **절대 위치 인코딩**, 장문 외삽에는 **RoPE**와 **위치 보간**을 선택한다.

#### 한줄 요약
- 문맥 길이와 외삽 요구에 따라 절대 위치와 RoPE를 선택한다.
