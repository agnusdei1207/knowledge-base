## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **위치 인코딩(Positional Encoding, PE)**: 순열 불변성(Permutation Invariance)을 가진 어텐션 연산에 토큰의 순서와 거리 정보를 주입하는 기법.
- **순열 불변성(Permutation Invariance)**: 입력 원소의 순서 변경이 연산 결과에 영향을 주지 않는 특성.

</details>

- 정의: 어텐션에 순서•거리 신호를 결합하는 **위치 인코딩**
- 배경: 순열 불변 어텐션만으로는 **순서•거리 구분 불가**

#### 한줄 요약
- 토큰의 **순서•상대 거리 정보** 결합

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **절대 위치 인코딩(Absolute PE)**: 토큰 순번에 대응하는 값을 입력 임베딩에 가산.
- **상대 위치 인코딩(Relative PE)**: 토큰 간 거리/방향을 어텐션 점수 또는 Q, K 변환에 반영.
- **외삽(Extrapolation)**: 학습 문맥 길이 외부의 위치 정보를 추론 시 연장 적용.
- **쿼리/키(Query/Key, Q/K)**: 조회 대상 기준 벡터 및 매칭 식별 벡터.

</details>

![Observable Plot으로 그린 위치별 고주파•저주파 사인 인코딩 값](/study/diagrams/positional-encoding.svg)

> 빠른 주기는 인접 위치를 세밀하게 구분하고, 느린 주기는 넓은 위치 범위의 변화를 표현함.

- **순서 주입**: 입력 임베딩 또는 Q•K 회전에 결합
- **표현 구분**: 절대 위치와 상대 거리 방식
- **외삽 한계**: 학습 문맥 초과 시 위치 오차 발생

#### 한줄 요약
- **절대•상대 위치 표현** 기반 참조 관계 구분

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **회전 위치 임베딩(RoPE)**: Q, K 벡터를 위치 기반으로 회전시켜 내적에 상대적 거리를 반영.
- **위치 보간(Position Interpolation)**: 긴 위치 인덱스를 학습 범위 내로 비례 압축하여 표현 확장.
- **주입 계층(Injection Layer)**: 위치 벡터를 임베딩에 가산하거나 회전값을 Q, K에 적용하는 계층.

</details>

```text
                        [위치 표현기]
                       /       |       \
              [위치 인덱스] [주입 계층] [길이 확장기]
```

선의 의미: 위치 표현기는 위치 인덱스를 위치 신호로 표현하고, 주입 계층에 결합 규칙을 제공하며, 길이 확장기의 보간•스케일 조정을 적용받는다.

| 구성요소 | 책임 |
|:---|:---|
| 위치 인덱스 | 절대 순서•상대 거리 또는 패치 좌표 생성 |
| 위치 표현기 | 삼각함수•학습 벡터•RoPE 회전 변환 |
| 주입 계층 | 임베딩 가산 또는 Q•K 변환 |
| 길이 확장기 | 위치 보간•스케일 조정으로 장문 보정 |

#### 한줄 요약
- **위치 인덱스•표현•주입•확장** 계층 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **위치 신호**: 고정 함수, 학습 벡터, 회전값 등을 활용한 순서 및 거리 표현값.
- **임베딩 생성**: 위치 정보를 제외한 토큰 내용의 벡터 표현 생성 절차.
- **위치 산출**: 절대 순서 및 토큰 쌍 상대 거리 계산.
- **주입(Injection)**: 위치 신호를 내용 표현 또는 Q, K 변환에 결합.

</details>

```text
토큰
  │ 1. 토큰 임베딩 생성
  ▼
위치 인코더
  │ 2. 위치 인덱스 산출
  │ 3. 위치 신호 생성
  ▼
어텐션
  │ 4. 위치 주입
  ▼
문맥 표현
```

### 동작 원리

1. **토큰 임베딩 생성**: 위치 제외 내용 표현 준비.
2. **위치 인덱스 산출**: 절대 순서 및 토큰 쌍 상대 거리 계산.
3. **위치 신호 생성**: 고정 함수, 학습값, RoPE 기반 변환.
4. **위치 주입**: 임베딩 가산 또는 Q, K 회전값 결합.

#### 한줄 요약
- **위치 신호**를 임베딩 또는 Q•K에 주입

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **상대 위치 방식**: 토큰 간 거리 관계를 반영하여 장문 일반화에 유리.
- **절대 위치 방식**: 토큰별 위치값을 입력에 명시적으로 가산.

</details>

| 비교 기준 | 상대 위치 인코딩 | 절대 위치 인코딩 |
|:---|:---|:---|
| 적용 기준 | 거리 관계 및 장문 일반화 | 고정 길이 및 명시적 순서 |
| 핵심 특징 | 어텐션 점수 및 Q, K에 거리 반영 | 입력 표현에 위치값 가산 |
| 한계 | 구현 및 캐시 변환 복잡성 | 학습 최대 길이 밖 외삽 취약 |

#### 한줄 요약
- 고정 길이는 **절대 위치**, 장문 거리는 **상대 위치**

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **위치 외삽 오차**: 학습 길이 밖에서 위치 신호 왜곡 및 해석 불정확 현상.
- **단거리 해상도**: 인접 토큰 간 위치 차이를 구분하는 정밀도.
- **위치 인덱스 일치**: 학습 및 추론 시 동일 토큰에 일관된 위치 규칙 적용.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:--- |
| 학습 길이 초과 시 **위치 외삽 오차** | 위치 보간, RoPE 스케일 조정 | 장문 정확도 급락 완화 |
| 위치 확장에 따른 **단거리 해상도** 저하 | 단/장문 평가셋 및 주파수별 보정 | 단거리 해상도 보존 |
| 학습•추론의 위치 인덱스 불일치 | 위치 인덱스 일치 단위 시험 | 토큰 순서 왜곡/캐시 오류 방지 |

#### 한줄 요약
- **길이별 평가•인덱스 일치 시험**으로 위치 왜곡 방지

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **위치 표현 선택 기준**: 고정 길이에는 절대 위치를, 장문 외삽에는 RoPE와 위치 보간을 적용하는 설계 원칙.

</details>

- 고정 문맥은 **절대 위치**, 장문 외삽은 **RoPE•보간** 선택

#### 한줄 요약
- **문맥 길이•외삽 요구**에 따라 위치 표현 결정
