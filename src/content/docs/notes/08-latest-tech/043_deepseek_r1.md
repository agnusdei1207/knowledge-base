## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **DeepSeek-R1**: DeepSeek-V3-Base에 콜드 스타트 데이터와 다단계 강화학습을 적용한 추론 언어 모델을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.
- **DeepSeek-V3-Base**: R1-Zero와 R1 후학습의 출발점이 된 기반 모델을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.
- **강화학습(Reinforcement Learning, RL)**: 보상 신호로 문제 해결 정책을 개선하는 학습 방식로 정의된다.
- **지도 미세조정(Supervised Fine-Tuning, SFT)**: 정답•풀이 예시로 응답 행동을 조정하는 학습 방식이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.

</details>

- 정의/개념: DeepSeek-V3-Base에 콜드 스타트•다단계 RL을 적용한 **DeepSeek-R1 추론 언어 모델**임. 이는 전통적 방식과의 핵심 차별점으로서 실질적인 업무 가치를 창출함.
- 배경/필요성: 추론 예시 중심 SFT만으로는 정답을 탐색•검증하는 **자발적 해결 정책**을 확장하기 어렵음.

#### 한줄 요약
- **콜드 스타트•다단계 RL**로 추론 행동을 강화 체계 적용

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **DeepSeek-R1-Zero**: 선행 지도 미세조정 없이 대규모 강화학습을 적용해 추론 행동의 출현을 실험한 모델이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.
- **콜드 스타트(Cold Start)**: 강화학습 전에 소량의 고품질 추론 예시로 응답 형식과 초기 행동을 안내하는 단계다.
- **지식 증류(Knowledge Distillation)**: 큰 모델이 생성한 지식•응답을 작은 기반 모델에 학습시켜 능력을 이전하는 방법을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.

</details>

- R1-Zero의 선행 SFT 없는 **대규모 RL 추론 행동 실험**이 핵심임. 이는 전통적 방식과의 핵심 차별점으로서 실질적인 업무 가치를 창출함.
- R1의 콜드 스타트와 다단계 학습을 결합한 **가독성•추론 성능 보완**이 핵심임. 이는 전통적 방식과의 핵심 차별점으로서 실질적인 업무 가치를 창출함.
- R1 생성 데이터를 Qwen•Llama 기반 모델에 이전한 **증류 모델 제공**이 핵심임. 이는 전통적 방식과의 핵심 차별점으로서 실질적인 업무 가치를 창출함.

#### 한줄 요약
- **R1-Zero•R1•증류 모델**의 학습 단계를 구분 체계 적용

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **그룹 상대 정책 최적화(Group Relative Policy Optimization, GRPO)**: 후보 응답 그룹의 상대 보상을 이용해 정책을 갱신하는 강화학습 기법을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.
- **거부 표본 추출(Rejection Sampling)**: 생성 후보 중 정확성•품질 기준을 통과한 응답만 후속 학습 데이터로 선별하는 방법이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.

</details>

```text
[V3-Base]──[콜드 스타트 SFT]──[GRPO•검증 보상]
                                      │
                              [거부 표본•후속 학습]
                                      │
                              [Qwen•Llama 증류]
```

선의 의미: 기반•초기화•강화•선별•증류 책임의 정적 연결을 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| V3-Base | R1 계열 후학습의 **기반 표현 제공** |
| 콜드 스타트 SFT | 고품질 예시로 **초기 추론 형식 안내** |
| GRPO•검증 보상 | **GRPO•검증 보상 기반 추론 정책 강화** |
| 거부 표본•후속 학습 | **거부 표본 추출**로 양질 응답 선별•일반 능력 보완 |
| Qwen•Llama 증류 | R1 생성 데이터의 **소형 기반 모델 이전** |

#### 한줄 요약
- **기반•콜드 스타트•GRPO•선별•증류**를 구성 체계 적용

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **검증 보상**: 정답 판정이나 코드 실행처럼 자동 확인 가능한 결과로 추론 정책에 부여하는 보상이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.
- **후속 강화학습**: 선별 데이터 SFT 이후 추론과 일반 능력의 균형을 조정하는 추가 학습 단계다.

</details>

```text
V3-Base
   │ 1. 고품질 추론 예시 SFT
   ▼
콜드 스타트
   │ 2. GRPO•검증 보상 학습
   ▼
강화학습기
   │ 3. 후보 응답 생성•선별
   ▼
데이터 선별기
   │ 4. 선별 데이터 SFT•후속 RL
   ▼
강화학습기
   │ 5. Qwen•Llama 기반 증류
   ▼
증류 모델
```

1. **고품질 추론 예시 SFT**: 콜드 스타트 데이터로 **가독성•응답 형식**을 설정함.
2. **GRPO•검증 보상 학습**: 정답 판정과 상대 보상으로 **추론 정책**을 강화함.
3. **후보 응답 생성•선별**: 정확성•가독성 기준을 통과한 **학습 데이터**를 구성함.
4. **선별 데이터 SFT•후속 RL**: 추론과 일반 과업 데이터를 결합해 **최종 R1**을 조정함.
5. **Qwen•Llama 기반 증류**: R1 생성 데이터로 작은 기반 모델의 **추론 능력을 이전**함.

#### 한줄 요약
- **콜드 스타트•GRPO•선별•후속 RL•증류**를 수행 체계 적용

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **증류 모델**: R1 생성 데이터를 Qwen•Llama 기반 소형 모델에 학습시켜 제한 자원 배포를 지원한다.

</details>

| 비교 기준 | R1-Zero | R1 | 증류 모델 |
|:---|:---|:---|:---|
| 적용 기준 | **순수 RL 추론 연구** | **일반 추론 활용** | **제한 자원 배포** |
| 핵심 특징 | 선행 SFT 없는 **대규모 RL** | 콜드 스타트•**다단계 RL** | Qwen•Llama 기반 **추론 데이터 증류** |
| 한계 | **가독성•언어 혼용** | **긴 추론 지연•비용** | **기반 크기별 성능 차이** |

#### 한줄 요약
- **학습 단계•기반 모델•배포 자원**으로 변형을 구분 체계 적용

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **모델 식별자(Model Identifier, Model ID)**: 원본•증류 여부와 기반•크기•체크포인트를 구분하는 정확한 값이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.
- **양자화**: 모델 가중치를 낮은 비트로 표현하여 메모리와 연산량을 줄이는 배포 기법이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 변형별 **기반•크기 혼동** | 정확한 **Model ID•파라미터•체크포인트 확인** | 성능•자원 비교의 **정합성 확보** |
| R1 원본•증류 모델의 **추론 자원 차이** | **출력 상한•양자화•동시성 시험** | 배포 자원에 맞는 **모델 선택** |

#### 한줄 요약
- **Model ID•크기•라이선스•업무 성능**을 확인 체계 적용

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **제한 자원 배포**: GPU 메모리나 처리량이 제한된 환경에서 모델을 운영하기 위해 증류•양자화 등으로 크기를 줄여 배포하는 방식로 정의된다.

</details>

- 순수 RL 연구에는 **R1-Zero**, 범용 추론에는 **R1**, 제한 자원 배포에는 **증류 모델**을 선택하여 실무 환경에서의 유연한 대응과 지속적 최적화를 지원함.

#### 한줄 요약
- **연구•범용•제한 자원 목적**에 따라 R1 변형을 선택 체계 적용
