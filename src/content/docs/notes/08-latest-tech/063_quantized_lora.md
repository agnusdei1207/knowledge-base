## 미리 알고가기

- **양자화 저랭크 적응(Quantized Low-Rank Adaptation, QLoRA)**: '큐로라'로 읽고 4비트 동결 모델을 통과해 LoRA만 학습하는 방식을 표시
- **저랭크 적응(Low-Rank Adaptation, LoRA)**: '로라'로 읽고 저랭크 변화량만 학습하는 방식을 표시
- **4비트 NormalFloat(NF4)**: '엔에프포'로 읽고 정규분포 가중치에 맞춘 4비트 양자화 자료형을 표시
- **이중 양자화(Double Quantization)**: 가중치 양자화 상수를 다시 양자화해 메모리를 줄이는 기법
- **페이지드 옵티마이저(Paged Optimizer)**: 통합 메모리로 옵티마이저 상태의 순간 메모리 급증을 완화


## Ⅰ. 개요

- 정의/개념: 4비트로 양자화한 동결 기반 모델을 역양자화해 **LoRA 경로만 학습하는 기법**
- **배경/필요성**: 일반 LoRA에서도 남는 **대규모 기반 가중치 적재 메모리 부담 절감**

### 쉽게 이해하기 (학습용)

- 압축한 기반 가중치는 계산 때 복원하고 LoRA 경로만 학습합니다.

## Ⅱ. 특징

- **NF4·블록 양자화·이중 양자화**로 동결 기반 가중치와 상수 저장량을 줄인다.
- 계산 때 기반 가중치를 **16비트 계산 자료형으로 역양자화**해 LoRA와 합산한다.
- **페이지드 옵티마이저**는 순간 메모리 급증을 완화하지만 데이터 이동 지연이 생길 수 있다.

### 쉽게 이해하기 (학습용)

- 양자화 상수까지 줄여 보관하고 메모리가 부족하면 상태를 페이징합니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| NF4 가중치 | 4비트 가중치·상수 동결 |
| 이중 양자화 | 양자화 상수의 재양자화 |
| 역양자화 | 가중치 블록을 계산용으로 복원 |
| LoRA 학습 | 저랭크 경로 매개변수 갱신 |
| 옵티마이저 | 메모리 상태 관리 페이징 |

```text
NF4원본 ─── 역양자화 ─── 출력합산
       ├── LoRA학습
       └── 상태페이징
```

### 쉽게 이해하기 (학습용)

- NF4 기반 가중치를 복원해 LoRA 변화량과 합산합니다.

## Ⅳ. 원리 및 절차 흐름도

```text
요구 확인
↓
양자 적재
↓
학습 구성
↓
역양자화
↓
배포 평가
```

| 절차 | 설명 |
|:---|:---|
| 요구 확인 | 메모리·커널·품질 기준 정의 |
| 양자 적재 | NF4 기반 가중치·상수 적재 |
| 학습 구성 | LoRA·계산 형식·페이징 설정 |
| 역양자화 | 계산 자료형 복원·LoRA 학습 |
| 배포 평가 | 품질·메모리·지연·호환 평가 |

### 쉽게 이해하기 (학습용)

- NF4 기반 가중치에 LoRA만 학습하고 품질과 메모리를 비교합니다.

## Ⅴ. 종류 및 비교

| 파인튜닝 메모리 구조 | 전체 파인튜닝 | LoRA | QLoRA |
|:---|:---|:---|:---|
| 적용 기준 | 적응 자원 충분 시 | 원본 메모리 충분 시 | 원본 메모리 병목 시 |
| 핵심 특징 | 전체 가중치 갱신 | 원본 정밀도 유지·LoRA 갱신 | 4비트 원본·LoRA 갱신 |
| 한계 | 상태 메모리 소모 | 원본 적재 비용 | 양자화 오차·커널·페이징 |

> 요약: 학습 방식별 비용과 구조를 비교함

### 쉽게 이해하기 (학습용)

- 전면 튜닝·LoRA·QLoRA는 원본의 저장·갱신 범위가 다릅니다.

## Ⅵ. 실무 사례

1. QLoRA는 **동일 데이터의 LoRA 대비 품질·메모리 비교**
2. 배포 전 **NF4 커널·역양자화·페이징 지연 검증**

### 쉽게 이해하기 (학습용)

- 압축 전후 품질을 비교하고 페이징으로 학습이 느려지는지도 확인해야 합니다.

## Ⅶ. 결론

- QLoRA는 **기반 모델 적재 절감과 오차·커널·지연**을 검증

### 쉽게 이해하기 (학습용)

- 압축 오차·역양자화 비용·메모리 이동을 별도로 검증해야 합니다.
