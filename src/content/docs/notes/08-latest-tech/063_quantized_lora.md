## 미리 알고가기

- **QLoRA (Quantized Low-Rank Adaptation, QLoRA)**: 양자화 원본에 LoRA만 학습
- **LoRA (Low-Rank Adaptation, LoRA)**: 저랭크 변화량만 학습
- **NF4 (4-bit NormalFloat, NF4)**: 정규분포 가중치를 4비트로 저장
- **이중 양자화 (Double Quantization)**: 양자화 상수 재양자화
- **페이지드 옵티마이저 (Paged Optimizer)**: 상태 메모리를 시스템 메모리로 넘김


## Ⅰ. 개요

- **정의/개념**: 4비트 기반 가중치에 LoRA만 학습
- **배경/필요성**: 큰 모델의 기반 가중치 적재 비용 절감

### 쉽게 이해하기 (학습용)

- 압축한 기반 가중치는 계산 때 복원하고 LoRA 경로만 학습합니다.

## Ⅱ. 특징

- NF4가 정규분포 가중치를 4비트 블록으로 저장한다.
- 이중 양자화가 블록 상수의 메모리를 더 줄인다.
- 연산 때 기반 가중치를 계산 자료형으로 복원한다.
- 페이지드 옵티마이저가 메모리 급증을 완화한다.

### 쉽게 이해하기 (학습용)

- 양자화 상수까지 줄여 보관하고 메모리가 부족하면 상태를 페이징합니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| NF4 가중치 | 4비트 가중치·상수 동결 |
| 이중 양자화 | 양자화 상수의 재양자화 |
| 역양자화 | 가중치 블록을 계산용으로 복원 |
| LoRA 학습 | 저랭크 경로 매개변수 갱신 |
| 옵티마이저 | 메모리 상태 관리 페이징 |

```text
NF4원본 ─── 역양자화 ─── 출력합산
       ├── LoRA학습
       └── 상태페이징
```

### 쉽게 이해하기 (학습용)

- NF4 기반 가중치를 복원해 LoRA 변화량과 합산합니다.

## Ⅳ. 원리 및 절차 흐름도

```text
요구확인
↓
양자적재
↓
학습구성
↓
역양자화
↓
배포평가
```

| 절차 | 설명 |
|:---|:---|
| 요구확인 | 메모리·커널·품질 기준 정의 |
| 양자적재 | NF4 블록 및 상수 적재 |
| 학습구성 | LoRA·계산 형식·페이징 설정 |
| 역양자화 | 원본 복원 및 LoRA 학습 |
| 배포평가 | 품질·메모리·호환성 평가 |

### 쉽게 이해하기 (학습용)

- NF4 기반 가중치에 LoRA만 학습하고 품질과 메모리를 비교합니다.

## Ⅴ. 종류 및 비교

| 판단 기준 | Full FT | LoRA | QLoRA |
|:---|:---|:---|:---|
| 학습 경로 | 전체 갱신 | 저랭크 갱신 | 4비트 원본·저랭크 갱신 |
| 적용 기준 | 적응 자원 충분 시 | 원본 메모리 충분 시 | 원본 메모리 병목 시 |
| 주요 위험 | 상태 메모리 소모 | 원본 적재 비용 | 오차·페이징 지연 |

> 요약: 학습 방식별 비용과 구조를 비교함

### 쉽게 이해하기 (학습용)

- 전면 튜닝·LoRA·QLoRA는 원본의 저장·갱신 범위가 다릅니다.

## Ⅵ. 실무 사례

- QLoRA와 일반 LoRA 품질·데이터 조건 비교
- 라이브러리·커널별 NF4·이중 양자화 지원 확인
- 페이징 전송 지연 및 최고 메모리·처리 시간 관찰

### 쉽게 이해하기 (학습용)

- 압축 전후 품질을 비교하고 페이징으로 학습이 느려지는지도 확인해야 합니다.

## Ⅶ. 결론

- QLoRA는 메모리 이득과 양자화 오차·지연을 함께 잰다.

### 쉽게 이해하기 (학습용)

- 압축 오차·역양자화 비용·메모리 이동을 별도로 검증해야 합니다.
