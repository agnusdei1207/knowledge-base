## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **양자화 저랭크 적응(Quantized Low-Rank Adaptation, QLoRA)**: 4비트 기반 모델을 압축 상태로 동결하고 계산 시 역양자화하여 저랭크 적응 경로만 학습하는 기법이다.
- **저랭크 적응(Low-Rank Adaptation, LoRA)**: 기반 가중치를 고정하고 두 작은 행렬이 만드는 변화량만 학습하는 방식.

</details>

- 정의/개념: 4비트 기반 모델에 LoRA를 적용하는 **QLoRA**
- 배경/필요성: LoRA를 적용하여 학습 파라미터 수를 99% 줄이더라도 동결된 수백억 파라미터의 베이스 모델 자체를 FP16/BF16 고정밀도로 VRAM에 로드해야 하므로, 단일 24GB~48GB 컨슈머/엔터프라이즈 GPU에서 65B/70B급 거대 모델을 파인튜닝할 수 없는 물리적 메모리 장벽에 직면함에 따라, 기본 모델 가중치를 4비트 NF4(NormalFloat4)로 극단적 압축 적재하고 계산 시점에만 BF16으로 역양자화(Dequantize)하여 16비트 LoRA 어댑터를 학습시키는 QLoRA(양자화 저랭크 적응: Quantized Low-Rank Adaptation) 기술을 도입하여 **48GB 단일 GPU에서 65B/70B LLM의 파인튜닝을 완벽히 실현하는 획기적 VRAM 절감(65B 기준 780GB $\rightarrow$ 48GB 이하), 이중 양자화(Double Quantization) 및 페이지드 옵티마이저(Paged Optimizers)를 통한 메모리 스파이크 차단, 16비트 완전 파인튜닝과 100% 동등한 벤치마크 성능 방어**를 달성할 필요

#### 한줄 요약
- **4비트 양자화•LoRA**는 학습 가능한 GPU의 문턱을 낮추는 대신 양자화 오차와 역양자화 연산을 떠안으므로, 메모리 제약이 실제 병목일 때만 그 손실이 값어치를 한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **4비트 정규 부동소수점(NormalFloat 4-bit, NF4)**: 정규분포 형태의 사전학습 가중치를 표현하도록 설계된 4비트 자료형으로 정의된다.
- **이중 양자화(Double Quantization, DQ)**: 가중치 블록의 양자화 상수도 다시 양자화하여 저장량을 줄이는 기법을 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.
- **페이지드 옵티마이저(Paged Optimizer)**: 메모리 부족 시 옵티마이저 상태를 CPU와 GPU 사이에서 이동하여 순간 사용량을 완화하는 기술을 가리킨다.

</details>

- **NF4•이중 양자화**: 동결 가중치 저장량 감소
- **혼합 정밀도**: 저비트 저장과 고정밀 계산 분리
- **페이지드 옵티마이저**: GPU 메모리 피크 완화

#### 한줄 요약
- **양자화•상태 페이징** 기반 메모리 절감

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **블록 양자화(Block Quantization)**: 가중치를 블록 단위로 분할하여 개별 양자화 상수를 적용하는 방식.
- **NF4 저장소(NF4 Storage)**: 양자화된 코드북과 상수를 저장하여 원본 가중치를 압축하는 공간.
- **역양자화(Dequantization)**: 계산 시점 연산을 위해 압축 가중치를 고정밀도로 복원하는 과정.
- **LoRA 학습 경로(LoRA Training Path)**: 저랭크 변화량만을 학습하는 병렬 경로.
- **페이지드 옵티마이저(Paged Optimizer)**: CPU/GPU 간 메모리 페이징을 담당하는 제어 모듈.
- **출력 결합기(Output Combiner)**: 고정 기반 출력과 학습 경로 출력을 합산하는 컴포넌트.

</details>

```text
[QLoRA System]
├── [양자화 저장 계층]
│   └── [NF4 가중치 저장소]
├── [역양자화/연산 계층]
│   ├── [역양자화 연산기]
│   └── [출력 결합기]
└── [학습/최적화 계층]
    ├── [LoRA 학습 경로]
    └── [페이지드 옵티마이저]
```

- 선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| NF4 가중치 저장소 | **4비트 가중치•양자화 상수** 보관 |
| 역양자화 연산기 | 선택 블록을 **계산 자료형** 기반 복원 |
| LoRA 학습 경로 | **저랭크 변화량** 그래디언트 갱신 |
| 페이지드 옵티마이저 | **CPU•GPU 상태 이동** 관리 |
| 출력 결합기 | **기반 출력•LoRA 변화량** 합산 |

#### 한줄 요약
- **NF4•역양자화•LoRA•페이지드 옵티마이저** 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **혼합 정밀도 학습(Mixed Precision Training)**: 기반 가중치는 저비트로 저장하고 계산과 학습 매개변수는 더 높은 정밀도로 처리하는 방식이다.
- **상태 페이징(State Paging)**: GPU 메모리 피크를 낮추도록 옵티마이저 상태를 CPU와 GPU 사이에서 이동하는 과정.

</details>

```text
학습 구성기
    │ 1. NF4 가중치•상수 적재
    ▼
┌──────────── 학습 종료 전 반복 ────────────┐
│ NF4 저장소                                │
│   │ 2. 선택 블록 역양자화                 │
│   ▼                                       │
│ 역양자화 연산기                           │
│   │ 3. 기반 출력•LoRA 변화량 합산         │
│   ▼                                       │
│ LoRA 학습기                               │
│   │ 4. LoRA 그래디언트 갱신               │
│   └── 상태 페이징 ──▶ 옵티마이저          │
└───────────────────────────────────────────┘
    │ 학습 지표 반환
    ▼
학습 구성기
```

### 동작 원리

1. **NF4 가중치•상수 적재**: 기반 모델 저장량 절감
2. **선택 블록 역양자화**: 필요한 가중치만 복원
3. **기반 출력•LoRA 변화량 합산**: 통합 출력 생성
4. **LoRA 그래디언트 갱신**: 학습 상태 축소

#### 한줄 요약
- **NF4 적재•역양자화•LoRA 갱신** 반복

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **전체 미세조정(Full Fine-Tuning, FFT)**: 전체 가중치와 학습 상태를 고정밀로 갱신하는 방식을 나타낸다.
- **LoRA 적용(LoRA Adaptation)**: 고정밀 기반 모델에 저랭크 변화량을 적용하여 학습하는 구조.
- **QLoRA 적용(QLoRA Adaptation)**: 4비트 기반 모델 역양자화와 저랭크 변화량 학습을 결합한 기법으로 정의된다.

</details>

- 고정밀 기반은 **LoRA**, 4비트 기반은 **QLoRA**

| 구분 | 전체 미세조정 | LoRA | QLoRA |
|:---|:---|:---|:---|
| 적용 기준 | **학습 자원** 충분 | 원본 **적재 메모리** 충분 | 원본 **메모리 병목** |
| 핵심 특징 | 전체 가중치 **갱신** | 고정밀 원본•**LoRA 갱신** | 4비트 원본•**LoRA 갱신** |
| 한계 | **학습 상태 메모리** | 원본 **적재 비용** | 양자화 오차•**커널**•**페이징** |

#### 한줄 요약
- **갱신 대상•기반 정밀도** 기반 학습 기법 구분

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **양자화 손실(Quantization Loss)**: 4비트 정규 부동소수점 근사 및 역양자화로 인해 과업 품질이 저하되는 현상을 가리킨다.
- **커널 호환성(Kernel Compatibility)**: 목표 GPU와 소프트웨어가 4비트 연산을 원활히 지원하는 성질로 정의된다.
- **이동 병목(Transfer Bottleneck)**: 상태 페이징의 CPU-GPU 간 전송 시간이 학습 속도를 제한하는 문제를 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| NF4 역양자화 품질 저하 | **LoRA•QLoRA 동일 데이터 회귀 비교** | 양자화 손실 **판정** |
| 미지원 커널의 **학습 지연•실패** | **NF4•역양자화 커널 호환 시험** | 실행 가능 환경 **확정** |
| 상태 페이징의 **CPU•GPU 이동 병목** | **피크 메모리•전송 대역폭 측정** | 메모리 절감의 **지연 대가 통제** |

#### 한줄 요약

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **저랭크 적응 선택 기준(LoRA Selection Criteria)**: 고정밀 원본 적재 메모리가 충분하고 양자화 오차 회피가 필요할 때의 판단 기준.
- **양자화 저랭크 적응 선택 기준(QLoRA Selection Criteria)**: GPU 메모리가 병목이고 4비트 양자화 조건이 허용 범위일 때의 판단 기준이다.

</details>

- 거대 파운데이션 모델의 파인튜닝 진입 장벽을 컨슈머 및 단일 엔터프라이즈 GPU 수준으로 파괴적으로 낮춘 **실용적 LLM 엔지니어링의 최고 혁신 기법(QLoRA / 4-bit NormalFloat: NF4 / Double Quantization / Paged Optimizers / High-Precision Adapter Tuning)의 표준 솔루션**으로 확고히 자리 잡았으며, 오픈소스 LLM 생태계의 민주화를 이끈 핵심 기술인 가운데, 실무 QLoRA 기반 엔터프라이즈 모델 학습 시에는 **가중치 블록 양자화 상수 오버헤드를 줄이는 이중 양자화(DQ) 활성화, 긴 시퀀스 학습 시 VRAM OOM(Out of Memory)을 원천 차단하는 Paged AdamW 옵티마이저 구성, 학습 완료 후 16비트 LoRA 어댑터 가중치만을 별도 추출하여 고속 추론 서빙 인프라(vLLM/SGLang)로 통합 배포**를 결합하여 완벽한 하드웨어 경제성과 최상의 모델 품질을 완성

#### 한줄 요약
- **GPU 메모리•양자화 품질•커널 지원** 기반 방식 결정
