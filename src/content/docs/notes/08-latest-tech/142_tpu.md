## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **텐서 처리장치(Tensor Processing Unit, TPU)**: Google이 신경망 텐서 연산용으로 설계한 전용 프로세서을 말한다.
- **행렬 곱셈장치(Matrix Multiply Unit, MXU)**: 시스톨릭 배열로 행렬 곱을 수행하는 TPU 핵심 연산기을 말한다.
- **주문형 집적회로(Application-Specific Integrated Circuit, ASIC)**: 특정 용도의 연산 구조를 고정한 전용 집적회로을 의미한다.

</details>

- 정의/개념: TPU가 시스톨릭 MXU로 신경망 텐서 연산을 처리하는 **AI 전용 ASIC**임.
- 배경/필요성: 범용 프로세서의 **데이터 이동•제어 비용**으로 행렬 처리량 제약이 발생함.

#### 한줄 요약

- 행렬 곱을 계산할 때 데이터를 외부 메모리에 되돌리지 않고 인접 MAC 사이로 전달해 곱셋•누산을 연속 처리하는 시스톨릭 배열 구조가 핵심이다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **시스톨릭 배열(Systolic Array)**: 데이터가 인접 MAC 사이를 박동처럼 흐르며 재사용되는 연산 배열을 의미한다.
- **곱셈 누산(Multiply-Accumulate, MAC)**: 곱셈 결과를 누적해 행렬 연산을 구성하는 계산을 말한다.
- **고대역폭 메모리(High Bandwidth Memory, HBM)**: 적층 구조로 넓은 메모리 대역폭을 제공하는 메모리이다.
- **칩 간 상호연결(Inter-Chip Interconnect, ICI)**: TPU 칩 사이의 데이터를 교환하는 연결망로 정의된다.

</details>

- **연산 축**: 시스톨릭 MXU의 MAC 간 데이터 재사용함.
- **확장 축**: HBM•ICI 기반 텐서 공급•다칩 병렬임.
- **배치 축**: 그래프 컴파일로 연산 융합•타일•칩을 배치함.

#### 한줄 요약

- 고정 형상의 행렬 연산을 반복하면 MXU 점유율이 높아지지만, 형상이 자주 변하는 소규모 작업은 MXU 유휴가 늘어 전용 가속기의 이점이 감소함이 핵심이다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **전용 컴파일러**: 모델 그래프를 텐서 처리장치가 지원하는 연산•배치•메모리•칩 분할 계획으로 변환하는 개념을 의미한다.

</details>

TPU는 HBM, MXU, ICI를 결합한다.

```text
[호스트•입출력]---[전용 컴파일러]
        |                  |
      [HBM]-----------[텐서 코어]---[칩 간 상호연결]
```

선의 의미: 호스트•입출력과 전용 컴파일러가 HBM 및 텐서 코어의 실행 구성을 제공하고, 칩 간 상호연결이 다칩 자원 경계를 확장한다.

| 구성요소 | 책임 |
|:---|:---|
| 호스트•입출력 | **모델 제어•입력•결과** 관리 |
| 전용 컴파일러 | 모델을 변환하는 **TPU 실행 코드** |
| HBM | **가중치•활성값 저장•공급** |
| 텐서 코어 | **MXU•벡터•스칼라 연산** 분담 |
| 칩 간 상호연결 | **ICI 집합 통신•파티션** 교환 |

#### 한줄 요약

- 전용 컴파일러가 연산 배치를 결정하고, HBM이 가중치•활성값을 공급하며, 텐서 코어가 연산하고, ICI가 다칩 병렬을 연결함이 핵심이다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **타일**: 큰 텐서를 MXU와 HBM 용량에 맞춰 나눈 계산 블록로 정의된다.
- **파티션**: 모델•데이터 연산을 여러 TPU 칩에 배치하기 위해 나눈 작업 단위을 의미한다.

</details>

MXU에 맞춘 타일을 HBM에서 공급하고 여러 TPU에 파티션을 배치한다.

```text
호스트•입출력 ── 모델 그래프•형상 ──▶ 전용 컴파일러
전용 컴파일러 ── 1. 타일•파티션 계획 ──▶ HBM
HBM ── 2. 텐서 타일 ──▶ 텐서 코어
┌──────── 다칩 연산 완료까지 ────────┐
│ 텐서 코어 ── 3. MXU 행렬•벡터 연산
│ 텐서 코어 ── 4. 집합 통신 데이터 ──▶ 칩 간 상호연결
│ 텐서 코어 ◀── 집합 통신 결과 ───── 칩 간 상호연결
└────────────────────────────────────┘
HBM ◀─ 5. 다칩 연산 결과 저장 ── 텐서 코어
호스트•입출력 ◀── 최종 결과 ───── HBM
```

1. **타일•파티션 계획 전달**: 연산 융합•MXU•칩 배치를 결정함.
2. **텐서 타일 전달**: HBM의 가중치•활성값을 공급함.
3. **MXU 행렬•벡터 연산**: 시스톨릭 배열에서 곱셈•누산함.
4. **집합 통신 데이터 전달**: 칩 간 파티션 결과를 교환함.
5. **다칩 연산 결과 저장**: 결합 결과를 HBM에 기록함.

#### 한줄 요약

- 모델 그래프를 전용 실행 코드로 변환하고 텐서를 HBM에서 공급한 뒤 MXU 행렬 연산과 ICI 다칩 통신을 완료해야 호스트가 최종 결과를 받음이 핵심이다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **그래프 컴파일**: 모델 연산을 융합하고 텐서와 칩 배치를 정해 TPU 실행 코드로 변환하는 과정을 말한다.
- **단일 명령 다중 스레드(Single Instruction, Multiple Threads, SIMT)**: 여러 스레드가 같은 명령을 실행해 다양한 데이터 병렬 연산을 처리하는 그래픽 처리장치 방식로 정의된다.
- **중앙처리장치(Central Processing Unit, CPU)**: 복잡한 제어와 순차 작업을 처리하는 범용 프로세서이다.
- **그래픽 처리장치(Graphics Processing Unit, GPU)**: 대량 데이터에 같은 연산을 병렬 적용하는 프로세서을 의미한다.

</details>

TPU, CPU, GPU는 행렬 전용성•제어 유연성•병렬 범용성이 다르다.

| 프로세서 | TPU | CPU | GPU |
|:---|:---|:---|:---|
| 적용 기준 | **반복 행렬 연산•고정 형상** | **제어•비정형 연산** | **다양한 병렬 연산•모델 변경** |
| 핵심 특징 | **시스톨릭 MXU•그래프 컴파일** | **범용 코어•독립 제어** | **SIMT•텐서 코어** |
| 한계 | **지원 연산•형상 제약** | **행렬 처리량 제한** | **분기•전송 오버헤드** |

> 요약: 중앙처리장치는 **제어**, 그래픽 처리장치는 **범용 병렬**, 텐서 처리장치는 **행렬 전용**이 핵심이다.

#### 한줄 요약

- CPU는 범용 제어•순차 처리, GPU는 SIMT 범용 병렬, TPU는 시스톨릭 MXU 기반 행렬 전용 연산에 적합함이 핵심이다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **형상 버킷**: 크기가 비슷한 입력을 묶어 정해진 텐서 형상으로 실행하는 최적화 방법을 말한다.
- **집합 통신**: 여러 칩이 계산 결과를 합산•분배•교환해 공동 상태를 만드는 통신 연산을 의미한다.

</details>

MXU 이용률과 ICI 통신량을 함께 최적화한다.

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 작은•가변 형상으로 **MXU 이용률** 저하 | 형상 버킷•행렬 타일 패딩 적용 | 시스톨릭 배열 **점유율 향상** |
| 다칩 파티션의 **ICI 통신 병목** | 텐서•데이터 병렬 배치 최적화 | 집합 통신 **대기 감소** |

#### 한줄 요약

- 대형 언어 모델은 텐서 형상과 칩 배치를 MXU에 맞추고, 서빙은 입력 형상별 컴파일 계획을 미리 준비해 둘이 핵심이다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **고정 형상**: 실행 전에 텐서의 차원과 크기가 일정하게 정해진 연산 형태을 의미한다.
- **가변 연산**: 입력이나 모델에 따라 계산 구조와 텐서 형상이 자주 달라지는 연산로 정의된다.

</details>

- 규칙적 반복 행렬은 **TPU**, 가변 모델•연산은 **GPU**을 선택함.

#### 한줄 요약

- MXU가 지속 가동될 만큼 연산이 규칙적이면 TPU가 유리하지만, 텐서 형상이 자주 변하면 범용 GPU가 더 적합함이 핵심이다.
