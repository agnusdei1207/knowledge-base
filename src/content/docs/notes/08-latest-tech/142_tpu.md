## 미리 알고가기

- **TPU (Tensor Processing Unit, TPU)**: 텐서 연산 특화 AI 전용 ASIC 가속기
- **대형 학습**: 대규모 학습·추론에서 높은 처리량·전력 효율 추구
- **Systolic Array**: Systolic Array와 HBM, 전용 컴파일 체계 필수



## Ⅰ. 개요

- **정의/개념**: 시스톨릭 배열 기반 AI 전용 ASIC
- **배경/필요성**: 행렬 데이터 재사용·전력 효율 개선

### 쉽게 이해하기 (학습용)

- 큰 곱셈표를 계산할 때 숫자를 매번 창고에 되돌리지 않고 옆 계산 칸으로 전달해 여러 곱셈과 덧셈을 이어서 처리하는 공장과 같음

## Ⅱ. 특징

- 시스톨릭 배열이 행렬 데이터 재사용을 높인다
- HBM·칩 연결이 모델·데이터 병렬을 확장한다
- 컴파일러가 그래프를 타일·메모리에 맞춘다
- 분기·불규칙 연산은 배열 활용률을 낮춘다

### 쉽게 이해하기 (학습용)

- 같은 크기의 행렬 계산을 오래 반복하면 계산 칸을 빈틈없이 쓰지만, 모양이 자주 바뀌는 작은 작업은 계산 칸이 놀아 전용 공장의 이점이 줄어듦

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 호스트·입출력 | 모델 제어, 입력 전달 및 결과 회수 |
| 전용 컴파일러 | 모델을 TPU 맞춤 실행 코드로 변환 |
| HBM | 가중치·활성값 저장 및 연산 유닛 공급 |
| 텐서 코어 | 행렬 곱 장치·벡터·스칼라 연산 분담 |
| 칩 간 상호연결 | TPU 간 집합 통신·파티션 데이터 교환 |

> 요약: 컴파일러 매핑과 HBM·텐서 연산·다칩 연결이 핵심이다.

### 쉽게 이해하기 (학습용)

- 전용 실행 코드가 작업 위치를 정하고, HBM 창고가 재료를 대며, 텐서 코어가 계산하고, 칩 간 통로가 여러 작업장을 이어줌

## Ⅳ. 원리 및 절차 흐름도

```text
그래프입력
    ↓
컴파일파티션
    ↓
HBM텐서적재
    ↓
행렬벡터연산
    ↓
집합통신동기
    ↓
결과반환
```

| 절차 | 설명 |
|:---|:---|
| 그래프입력 | 모델 그래프를 TPU로 전달함 |
| 컴파일파티션 | 그래프 융합·타일링 후 칩에 배치함 |
| HBM텐서적재 | 입력·가중치·활성값을 HBM에 저장함 |
| 행렬벡터연산 | 행렬 곱 장치·벡터 유닛으로 연산함 |
| 집합통신동기 | 학습 데이터·그래디언트를 칩 간 교환함 |
| 결과반환 | 출력 큐로 최종 결과 호스트 전달함 |

> 요약: HBM·텐서 연산·상호연결로 모델을 실행한다.

### 쉽게 이해하기 (학습용)

- 모델을 전용 작업표로 바꾸고 재료를 HBM에 놓은 뒤 행렬 작업과 작업장 간 결과 교환을 끝내야 호스트가 최종 결과를 받음

## Ⅴ. 종류 및 비교

| 판단 기준 | CPU | GPU | TPU |
|:---|:---|:---|:---|
| 프로그래머빌리티 | 명령·분기 중심 범용 코드 | 커널로 병렬 연산 구성 | 프레임워크 그래프를 전용 컴파일러로 변환 |
| 효율·개발비 경계 | 개발비 낮음·행렬 처리량 낮음 | 개발비 중간·범용 병렬성 | 컴파일 제약 존재·행렬 전력 효율 높음 |
| 적용 기준 | 제어·비정형 연산 비중이 클 때 | 모델 변경과 다양한 연산이 잦을 때 | 반복 행렬 연산과 고정 형상 비중이 클 때 |

> 요약: 제어 CPU, 병렬 GPU, 행렬 TPU를 고른다.

### 쉽게 이해하기 (학습용)

- CPU는 무엇이든 맡는 기술자, GPU는 작업 지시를 바꿀 수 있는 병렬 작업반, TPU는 행렬 작업에 맞춘 전용 생산라인에 가까움

## Ⅵ. 실무 사례

1. 트랜스포머 학습 시스템은 행렬 차원을 연산 타일에 맞추고 모델·데이터 파티션을 TPU 슬라이스에 배치함
2. TPU 모델 서빙은 입력 형상별 실행 파일을 미리 컴파일해 요청 시 그래프 재컴파일을 피함

### 쉽게 이해하기 (학습용)

- 대형 언어 모델은 행렬 크기와 칩 배치를 전용 생산라인에 맞추고, 서빙은 자주 쓰는 입력 모양의 작업표를 미리 준비해 둠

## Ⅶ. 결론

- 행렬은 TPU, 비정형 연산은 GPU·CPU가 유리하다

### 쉽게 이해하기 (학습용)

- 행렬 공장이 계속 가동될 만큼 일이 규칙적이면 TPU가 유리하지만, 작업 모양이 자주 바뀌면 범용 장비가 더 나음
