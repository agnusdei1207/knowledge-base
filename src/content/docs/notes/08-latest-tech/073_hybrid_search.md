## Ⅰ. 개요

<details>
<summary>용어 설명</summary>

- **하이브리드 검색(Hybrid Search)**: 희소•밀집 검색 후보를 점수나 순위로 결합하는 방식이다.

</details>

- 정의/개념: 희소•밀집 후보를 점수나 순위로 결합하는 **하이브리드 검색**
- 배경/필요성: 단일 검색은 의미 표현이나 **정확 식별자** 중 한쪽 후보를 누락하기 쉽음.

#### 한줄 요약
- **어휘•의미 검색 후보**를 결합해 최종 순위 결정

## Ⅱ. 특징

<details>
<summary>용어 설명</summary>

- **희소 검색**: 어휘의 빈도와 희귀도 같은 문자 신호로 문서를 찾는 방식이다.
- **밀집 검색**: 질의와 문서 임베딩의 의미 유사도로 문서를 찾는 방식이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.
- **상호 순위 융합(Reciprocal Rank Fusion, RRF)**: 여러 검색 결과에서 각 후보의 역순위 점수를 합산해 통합 순위를 정하는 방식이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.

</details>

![RRF에서 검색 순위가 낮아질수록 감소하는 개별 기여 점수](/study/diagrams/rrf-rank-score.svg)

> \(k=60\)을 가정한 파란 선은 각 검색기의 결과 순위 \(r\)가 낮아질수록 \(1/(k+r)\) 기여 점수가 감소해 상위에 공통 등장한 문서가 유리해지는 상호 순위 융합(Reciprocal Rank Fusion, RRF) 관계를 나타낸다.

- **희소•밀집 이중 검색**: 독립 후보와 순위 생성
- **RRF•정규화 점수 융합**: 검색 결과 결합
- **신경망 재순위**: 통합 후보의 질의 관련성 평가

#### 한줄 요약

- **점수 척도•순위 융합**으로 한쪽 신호 지배 방지

## Ⅲ. 구조 및 구성요소

<details>
<summary>용어 설명</summary>

- **융합기**: 서로 다른 검색 결과의 점수나 순위를 공통 기준으로 결합하는 구성요소로 정의된다.
- **희소 색인(Sparse Index)**: 용어 빈도와 역문서 빈도 등 어휘 신호로 정확한 키워드•식별자 일치를 찾는 색인이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.
- **밀집 색인(Dense Index)**: 임베딩 벡터의 근접도로 의미가 비슷한 문서를 찾는 색인이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.
- **중복 제거기**: 여러 경로의 동일•유사 문서를 하나로 통합하는 구성요소이다.
- **재순위 모델(Reranking Model)**: 통합 후보와 질의의 관련성을 정밀 평가해 최종 순서를 정한다.

</details>

```text
                 [희소 색인]     [밀집 색인]
                        \         /
                          [융합기]
                              |
                        [중복 제거기]
                              |
                        [재순위 모델]
```

선의 의미: 융합기는 희소 색인과 밀집 색인의 후보 집합을 결합하고, 중복 제거기와 재순위 모델은 통합 후보 집합의 정합성과 관련성을 담당한다.

| 구성요소 | 책임 |
|:---|:---|
| 희소 색인 | 역색인으로 **어휘 후보** 산출 |
| 밀집 색인 | 임베딩 거리로 **의미 후보** 산출 |
| 융합기 | **순위•정규화 점수**로 목록 결합 |
| 중복 제거기 | **동일 후보** 통합 |
| 재순위 모델 | **관련성**으로 최종 순위 결정 |


#### 한줄 요약
- **희소•밀집 색인•융합•중복 제거•재순위** 구성

## Ⅳ. 흐름도

<details>
<summary>용어 설명</summary>

- **최적 일치 25(Best Matching 25, BM25)**: 단어 빈도•희귀도와 문서 길이를 반영해 어휘 검색 순위를 계산하는 함수이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.
- **후보 중복 제거**: 여러 검색 경로가 반환한 동일 문서를 하나의 후보로 합치는 과정을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.

</details>

```text
질의 처리기
 ├─ 1. BM25 희소 후보 검색 ─────▶ 희소 색인 ─┐
 └─ 2. 임베딩 밀집 후보 검색 ──▶ 밀집 색인 ─┤
                                              ▼
                                            융합기
                                              │ 3. 순위•정규화 점수 융합
                                              │ 4. 후보 중복 제거
                                              ▼
                                         재순위 모델
                                              └ 5. 관련성 재순위화
```

### 동작 원리

1. **BM25 희소 후보 검색**: 정확 용어•식별자의 어휘 순위를 산출함.
2. **임베딩 밀집 후보 검색**: 의미 유사 문서의 벡터 순위를 산출함.
3. **순위•정규화 점수 융합**: RRF 또는 공통 척도로 목록을 결합함.
4. **후보 중복 제거**: 문서 식별자로 동일 후보를 하나로 통합함.
5. **관련성 재순위화**: 질의•통합 후보의 정밀 적합도를 평가함.

#### 한줄 요약
- **희소•밀집 검색•융합•중복 제거•재순위** 수행

## Ⅴ. 종류 및 비교

<details>
<summary>용어 설명</summary>

- **정확 어휘**: 코드•제품명처럼 문자 일치가 검색 정확도에 직접 영향을 주는 표현이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.
- **의미 유사성**: 표현이 달라도 문맥상 뜻이 가까운 정도를 벡터 거리로 나타낸 값이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.

</details>

| 검색 방식 | 하이브리드 검색 | 희소 검색 | 밀집 검색 |
|:---|:---|:---|:---|
| 적용 기준 | **어휘•의미 병행** | **정확 어휘 중요** | **의미 유사성 중요** |
| 핵심 특징 | **순위•점수 융합** | 단어 일치•**희귀도** | 벡터 **의미 유사도** |
| 한계 | 가중치•**정규화 왜곡** | 동의어•**다른 표현 누락** | 정확 **식별자 누락** |

#### 한줄 요약
- **정확 어휘•의미 유사성**에 따라 검색 방식 구분

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>용어 설명</summary>

- **점수 척도 불일치**: 검색기별 점수 범위 차이로 한 신호가 지배하는 문제이다.
- **후보 중복**: 같은 문서가 여러 검색 경로에서 반복 반환되어 후보 다양성을 낮추는 문제로 정의된다.
- **관련성 저하**: 통합 후보 순서가 실제 질의 적합성과 어긋나는 문제이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 검색 간 **점수 척도 불일치** | **순위 융합•점수 정규화** | 한 검색 신호의 **지배 방지** |
| 동일한 **후보 중복** | 문서 식별자 기반 **중복 제거** | 후보 **다양성 보존** |
| 융합 후 **관련성 저하** | 통합 후보의 **재순위화** | 최종 순위 **정확도 향상** |

#### 한줄 요약
- **점수 척도•후보 중복•관련성 저하** 통제

## Ⅶ. 결론

<details>
<summary>용어 설명</summary>

- **가중치 조정**: 평가 데이터로 희소•밀집 검색 신호 비율을 정하는 과정이다.
- **재순위화**: 융합된 후보를 더 정밀한 관련성 모델로 다시 배열하는 과정을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.

</details>

- 정확 식별자와 의미 검색이 모두 필요하면 **하이브리드 검색•재순위** 적용

#### 한줄 요약

- **어휘 정확성•의미 유사성**에 따라 검색 신호 결정
