## 미리 알고가기

- **신경망 처리 장치(Neural Processing Unit, NPU)**: 영문 머리글자를 딴 표기로 “엔피유”로 읽으며, 신경망 연산 가속 프로세서
- **곱셈 누산(Multiply-Accumulate, MAC)**: 영문 머리글자를 딴 표기로 “맥”으로 읽으며, 곱셈 결과를 누적하는 신경망 핵심 연산
- **정적 램(Static Random-Access Memory, SRAM)**: 영문 머리글자를 딴 표기로 “에스램”으로 읽으며, 칩 내부에서 데이터 재사용을 지원하는 메모리
- **직접 메모리 접근(Direct Memory Access, DMA)**: 영문 머리글자를 딴 표기로 “디엠에이”로 읽으며, 프로세서 개입을 줄여 연산기·메모리 간 데이터를 전송하는 방식



## Ⅰ. 개요

- **정의/개념**: 신경망 연산용 전용 가속 프로세서
- **배경/필요성**: 범용 CPU만으로 신경망 행렬 연산의 병렬 처리와 전력 효율 확보 곤란

### 쉽게 이해하기 (학습용)

- NPU는 AI 행렬 계산에 맞춘 전용 연산 장치다

## Ⅱ. 특징

- 연산 어레이 기반 **행렬·텐서 병렬 처리**
- 온칩 재사용을 통한 **메모리 이동 절감**
- 컴파일러 연산 지원과 **폴백 지연**

### 쉽게 이해하기 (학습용)

- 지원 연산은 빠르지만 미지원 연산은 다른 장치로 돌아간다

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 설계 요소 | 설명 |
|:---|:---|
| 컴파일러 | 연산 그래프·장치 분할 정함 |
| 런타임 | 장치 간 실행 순서 조정함 |
| 어레이 | 연산을 병렬 수행함 |
| 메모리 | 데이터를 내부 보관함 |
| 전송 엔진 | 외부 텐서 이동함 |

```text
컴파일러
├─ 실행 관리
├─ 연산 배열
├─ 온칩 메모리
└─ 전송 엔진
```

### 쉽게 이해하기 (학습용)

- 컴파일러가 작업을 나누고 NPU가 지원 연산을 실행함

## Ⅳ. 원리 및 절차 흐름도

```text
그래프분석
↓
그래프분할
↓
자원배치
↓
구간실행
↓
결과결합
```

| 절차 | 설명 |
|:---|:---|
| 분석 | 연산·형태 확인함 |
| 분할 | 지원 연산 폴백 구분함 |
| 배치 | 순서·텐서 배치함 |
| 실행 | 장치별 전송 수행함 |
| 결합 | 최종 추론값 결합함 |

### 쉽게 이해하기 (학습용)

- NPU 지원 연산과 폴백을 나눠 결과를 결합함

## Ⅴ. AI 연산 프로세서 비교

| 구분 | CPU | GPU | NPU |
|:---|:---|:---|:---|
| 실행 방식 | 제어·복합 연산 | 병렬 연산 가속 | 신경망 연산 가속 |
| 적용 기준 | 복잡한 제어 흐름 | 대규모 범용 연산 | 저전력 추론 가속 |
| 핵심 특징 | 범용 순차·분기 처리 | 다수 코어 병렬 처리 | 신경망 데이터흐름 특화 |
| 한계 | 행렬 처리 효율 낮음 | 전력·메모리 비용 | 연산자·모델 지원 제약 |
| 주요 병목 | 낮은 병렬도 | 메모리 대역폭 | 연산자 폴백 |

> 요약: 신경망 추론에 최적화된 저전력 구조임

### 쉽게 이해하기 (학습용)

- CPU는 제어, GPU는 병렬 계산, NPU는 저전력 추론에 맞음

## Ⅵ. 실무 사례

- 지원 연산·폴백 구간을 측정해 모델을 고른다
- 온칩 재사용·텐서 이동을 측정해 병목을 찾는다

### 쉽게 이해하기 (학습용)

- 휴대전화에서 음성을 처리할 때 NPU가 맡는 구간만 보지 않고, 다른 장치로 넘어가는 횟수와 데이터 운반 시간까지 재야 실제 응답 속도를 알 수 있음

## Ⅶ. 결론

- 폴백·이동 지연이 크면 GPU·CPU로 전환한다

> 요약: 지원 연산 비율과 폴백 비용을 최적화함

### 쉽게 이해하기 (학습용)

- 모델 연산 지원 범위가 실제 NPU 가속 효과를 결정한다
