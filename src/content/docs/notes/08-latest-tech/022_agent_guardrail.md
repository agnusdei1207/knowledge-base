## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **에이전트 가드레일(Agent Guardrail)**: 에이전트의 입력•출력•도구 행동에서 발생하는 위험을 탐지하고 제한하는 통제 체계이다.
- **행동 위험**: 모델의 판단이 외부 도구 호출이나 상태 변경으로 이어져 실제 피해를 일으킬 가능성이다.

</details>

- 정의/개념: 정책과 위험 수준에 따라 입력•출력•도구 행동을 검사하고 허용•수정•차단하는 **에이전트 가드레일**이다.
- 배경/필요성: 비신뢰 지시와 과도한 권한은 모델의 오판을 실제 시스템 피해로 확산시킨다.

#### 한줄 요약

- **에이전트 가드레일**로 입력•도구•출력의 위험 행동을 차단하는 것이 핵심이다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **심층 방어(Defense in Depth)**: 하나의 통제가 우회되더라도 피해를 막도록 독립된 통제를 여러 계층에 배치하는 원칙이다.
- **프롬프트 주입(Prompt Injection)**: 외부의 비신뢰 데이터에 숨긴 지시로 모델의 원래 통제와 목표를 우회하는 공격이다.
- **트립와이어(Tripwire)**: 금지 조건이나 위험 징후가 검출되면 실행을 즉시 중단시키는 조건이다.
- **인간 개입(Human-in-the-Loop, HITL)**: 고위험 도구 행동을 사람이 검토한 뒤 승인•수정•거부하는 통제이다.
- **위험 기반 대응**: 탐지 수준에 따라 요청을 허용•수정•격리•차단하거나 사람에게 이관하는 방식이다.

</details>

- **심층 방어**: 독립 통제를 여러 실행 경계에 배치한다.
- **프롬프트 주입** 대응은 비신뢰 지시를 독립된 계층에서 재검사한다.
- **트립와이어**: 금지 조건 검출 시 실행 중단이다.
- **위험 기반 대응**으로 위험도에 따라 허용•수정•차단한다.
- **HITL**: 고위험 행동을 사람이 검토•승인한다.
- 탐지 기준의 오탐•미탐 상충을 평가한다.

#### 한줄 요약

- 위험도에 따라 **허용•수정•차단•HITL 이관**을 결정한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **비신뢰 데이터**: 모델이 참고할 수는 있지만 명령 권한을 부여해서는 안 되는 외부 문서•웹페이지•도구 결과이다.
- **입력 검사기**: 사용자 입력과 외부 문맥에서 악성 지시•민감정보•정책 위반을 실행 전에 탐지하는 구성요소이다.
- **에이전트 런타임**: 신뢰 지시와 비신뢰 데이터를 분리하고 정책에 따라 모델•메모리•도구 실행을 조정하는 계층이다.
- **도구 정책 집행기**: 도구 호출 직전에 주체•인자•권한•예상 부작용을 검증하고 허용 여부를 강제하는 구성요소이다.
- **출력 검사기**: 사용자나 후속 시스템에 전달하기 전에 유해 내용•민감정보•정책 위반을 탐지하는 구성요소이다.

</details>

```text
                  [입력 검사기]
                        |
               [에이전트 런타임]
                        |
               [도구 정책 집행기]
                        |
                  [출력 검사기]
```

선의 의미: 에이전트 런타임을 중심으로 입력, 도구 실행, 출력의 독립된 검사 경계가 중첩되는 심층 방어 구조를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 입력 검사기 | **입력 검사기**로 악성 지시•민감정보 사전 검출 |
| 에이전트 런타임 | **에이전트 런타임**에서 신뢰 지시와 **비신뢰 데이터** 분리 |
| 도구 정책 집행기 | **도구 정책 집행기**가 인자•권한•부작용 실행 전 판정 |
| 출력 검사기 | **출력 검사기**로 유해성•민감정보•정책 위반 검출 |

#### 한줄 요약

- 입력•런타임•도구•출력 경계에 **심층 방어**를 적용한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **명령 권한 분리**: 시스템과 사용자의 신뢰 지시는 따르되 외부 콘텐츠의 문장은 실행 명령으로 취급하지 않는 통제이다.
- **입력 위험•민감정보 검사**: 사용자 입력에서 악성 지시•난독화•비밀정보를 찾아내는 절차이다.
- **신뢰 지시•비신뢰 문맥 분리**: 외부 콘텐츠를 데이터로만 취급해 명령 권한을 제거하는 절차이다.
- **도구 인자•권한•부작용 검증**: 도구 호출 직전에 요청 주체•인자•권한과 예상 피해를 판정하는 절차이다.
- **정책 판정 집행**: 위험 수준에 따라 도구 요청을 허용•수정•격리•차단•이관하는 절차이다.
- **출력 정책 검사**: 외부 전달 전에 유해성•민감정보•정책 위반을 다시 확인하는 절차이다.

</details>

```text
사용자
   │ 사용자 요청
   ▼
입력 검사기
   │ 1. 입력 위험•민감정보 검사
   │ 검사된 입력 전달
   ▼
에이전트
   │ 2. 신뢰 지시•비신뢰 문맥 분리
   │ 도구 실행 요청
   ▼
도구 정책 집행기
   │ 3. 도구 인자•권한•부작용 검증
   ├──────────────────────┐
   │ 허용•수정•차단•이관 │
   └──────────┬───────────┘
   │ 4. 정책 판정 집행
   ▼
도구
   │ 실행 결과•오류 반환
   ▼
에이전트
   │ 5. 출력 정책 검사
   │ 안전 응답
   ▼
사용자
```

1. **입력 위험•민감정보 검사**: 악성 지시•난독화•비밀정보를 탐지한다.
2. **신뢰 지시•비신뢰 문맥 분리**: **명령 권한 분리**를 적용한다.
3. **도구 인자•권한•부작용 검증**: 정책으로 **행동 위험**을 판정한다.
4. **정책 판정 집행**: **위험 기반 대응**으로 격리•차단 또는 사람 이관을 결정한다.
5. **출력 정책 검사**: 유해성•민감정보를 재검사한 허용 결과를 제공한다.

#### 한줄 요약

- 도구의 **행동 위험** 검증 후 차단하거나 **HITL**로 이관한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **정책 엔진**: 선언된 역할•속성•규칙을 평가하여 자원과 행동의 접근 권한을 결정적으로 판정하는 구성요소이다.

</details>

| 통제 체계 | 에이전트 가드레일 | 정책 엔진 |
|:---|:---|:---|
| 적용 기준 | 의미 기반 동적 행동 위험 | 결정적 접근 권한 |
| 핵심 특징 | 규칙•분류기•사람의 다층 판정 | 선언 정책•속성의 허용 판정 |
| 한계 | 오탐•우회 공격 가능성 | 정책 누락•속성 오류 |

#### 한줄 요약

- 권한은 **정책 엔진**, 의미•행동 위험은 **가드레일**을 통제한다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **오탐(False Positive)**: 정상 요청을 위험하다고 잘못 판정하여 허용해야 할 업무를 차단하는 오류이다.
- **미탐(False Negative)**: 위험 요청을 정상으로 잘못 판정하여 공격이나 정책 위반을 통과시키는 오류이다.
- **우회율**: 공격 세트 가운데 가드레일을 피해 실제 실행 단계까지 도달한 비율이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 단일 필터 우회에 따른 통제 실패 | **심층 방어**로 입력•문맥•도구•출력 독립 통제 | 우회 공격 다층 차단 |
| 과도한 차단에 따른 업무 저해 | **위험 기반 대응** 적용 | 안전성과 업무 가용성 균형 |
| 모델 판정만 신뢰한 권한 오용 | **도구 정책 집행기**가 주체•대상•인자 재검증 | 생성 판단과 권한 집행 분리 |
| 정책 변경의 검출 성능 저하 | **오탐**•**미탐**•**우회율** 지속 평가 | 가드레일 운영 임계치 보정 |

#### 한줄 요약

- 메일 발송 전 수신자와 첨부 민감정보를 재검증하는 것이 핵심이다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **최소 권한**: 가드레일이 판단을 놓쳐도 피해가 제한되도록 도구의 자원•행동 범위를 최소화하는 원칙이다.

</details>

- 고위험 도구는 **최소 권한**, **트립와이어**, **HITL** 승인 후 실행한다.

#### 한줄 요약

- 피해 영향이 클수록 **최소 권한**과 **HITL** 승인을 강화한다.
