## 미리 알고가기

- **제로 트러스트**: 내부·외부 구분 없이 모든 접근을 검증함
- **제어 단위**: 사용자·기기·데이터별 세밀한 접근 제어함
- **개념**: 제품이 아닌 보안 설계 원칙과 아키텍처임



## Ⅰ. 개요

- **정의/개념**: 매 접근을 동적으로 검증하는 자원 중심 보안
- **배경/필요성**: 경계 신뢰로 인한 횡적 이동 위험을 차단

### 쉽게 이해하기 (학습용)

- 건물 내부라 해서 방을 다 열지 않고 방마다 사람·기기를 다시 확인함

## Ⅱ. 특징

- 자원·주체 식별이 정책 판단 대상을 명확히 한다.
- 최소 권한이 접근 범위와 시간을 제한한다.
- 동적 정책이 상태·위험에 따라 접근을 바꾼다.
- 연속 관찰이 위협 변화 시 세션을 축소한다.

### 쉽게 이해하기 (학습용)

- 신분증만 보지 않고 작업 목적을 확인하며 위험 시 권한을 즉시 거둠

## Ⅲ. 아키텍처 및 구성요소

```text
                   [Identity / Device / Threat / Logs]
                                  ↓
[Subject] → [PEP] ⇄ [Policy Administrator] ⇄ [Policy Engine]
               │             control plane
               └──── allowed data path ────→ [Resource]
```

| 설계 요소 | 설명 |
|:---|:---|
| 자원 식별 | 주체·서비스·장치 상세 목록화 및 민감도 연결 |
| 정책 엔진 | 정책·위협 정보 기반의 허용·거부·회수 결정 |
| 정책 관리자 | 경로 생성·종료 명령 및 자격증명 발급 |
| 정책 집행점 | 주체·자원 간 연결 감시·차단·집행 |
| 분석 계층 | 신원·장치·로그·보안 정보를 수집·제공 |

> 요약: 엔진 판단·관리자 제어·집행점 실행

### 쉽게 이해하기 (학습용)

- 심사관이 판단하고 관리자가 출입증 발급, 문 앞 장치가 개폐 수행

## Ⅳ. 원리 및 절차 흐름도

| 절차 | 설명 |
|:---|:---|
| 1. 요청 식별 | 주체·장치·대상 자원을 식별함 |
| 2. 맥락 수집 | 인증·장치·행위·위협 정보를 엔진으로 전달함 |
| 3. 동적 결정 | 위험 기준 허용·거부·제한 결정함 |
| 4. 경로 설정 | 세션 경로 생성 및 자격증명 발급함 |
| 5. 집행 | 허용된 자원·행위에 한해 데이터 경로 열람함 |
| 6. 연속 재평가 | 위험 변화 관찰 후 재인증·권한 축소 수행함 |

> 요약: 로그인으로 신뢰를 고정하지 않고 연속 위험을 재평가함

### 쉽게 이해하기 (학습용)

- 장치·행동 변화 시 즉시 재평가하여 접근 통제 수행함

## Ⅴ. 종류 및 비교

| 판단 기준 | ZTA | 경계형 보안 | VPN |
|:---|:---|:---|:---|
| 핵심 특징 | 맥락·위험 동적 평가 | 구간·경계 기반 | 접속 시점 인증 |
| 적용 기준 | 개별 자원·세션 | 서브넷·구간 단위 | 네트워크 경로 중심 |
| 주요 위험 | 행위·상태 연속 관찰 | 진입 후 통제 약화 | 접속 의존적 인증 |

> 요약: 네트워크 위치 대신 개별 자원 요청의 동적 위험을 신뢰함

### 쉽게 이해하기 (학습용)

- 경계형 보안과 VPN이 건물 입구를 지키는 방식이라면 ZTA는 입구를 지난 뒤에도 각 방의 출입 권한을 따로 판단함

## Ⅵ. 실무 사례

1. **외부 개발자의 운영 도구 접근**

- **상황**: 운영 병목·위험과 영향 범위를 식별함
- **적용**: 주제별 통제·절차를 대상 환경에 적용함
- **검증**: 성능·품질·위험 지표로 효과를 확인함

2. **다중 클라우드 서비스의 데이터베이스 접근**

- **상황**: 운영 병목·위험과 영향 범위를 식별함
- **적용**: 주제별 통제·절차를 대상 환경에 적용함
- **검증**: 성능·품질·위험 지표로 효과를 확인함

### 쉽게 이해하기 (학습용)

- 외부 개발자의 운영 도구 접근
- 다중 클라우드 서비스의 데이터베이스 접근

## Ⅶ. 결론

- 자원별 동적 정책과 연속 검증으로 접근 결정

### 쉽게 이해하기 (학습용)

- 새 보안 장비 하나를 사는 일이 아니라 보호할 방과 심사 규칙과 문지기와 감시 체계를 단계적으로 다시 설계하는 일임
