## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **매개변수 효율적 파인튜닝(Parameter-Efficient Fine-Tuning, PEFT)**: 기반 모델을 동결하고 소수의 추가•선택 매개변수만 갱신하는 기술군이다.
- **동결(Freeze)**: 기반 모델 가중치를 역전파 갱신 대상에서 제외하는 설정한다.

</details>

- 정의/개념: **PEFT**는 기반 모델을 동결하고 소수 추가•선택 매개변수만 갱신하는 기술군이다.
- 배경/필요성: 전체 미세조정은 가중치•그래디언트•학습 상태와 **업무별 모델 복제 비용**을 유발한다.

#### 한줄 요약
- 기반 모델 동결과 **소수 매개변수 선택 갱신**이 핵심이다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **선택 갱신**: 전체 가중치 대신 과업 적응에 필요한 작은 매개변수 집합만 학습하는 방식이다.
- **업무별 모듈**: 하나의 공용 기반 모델과 결합하여 특정 업무 행동을 제공하는 작은 학습 자산이다.
- **동적 적재**: 요청 업무에 맞는 모듈만 실행 시점에 메모리로 불러오는 방식이다.

</details>

- 기반 가중치 동결과 **소수 매개변수 선택 갱신**이 핵심이다.
- 주입 위치•구조에 따른 **학습 용량•추론 경로 차이**가 핵심이다.
- 공용 기반 모델과 업무별 모듈의 **저장•전환 분리**가 핵심이다.

#### 한줄 요약
- **주입 위치•모듈 전환 방식**이 품질•지연을 결정한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **주입 구성**: 매개변수 효율적 파인튜닝 유형•대상 층•모듈 크기와 연결 위치를 정의한 설정한다.
- **학습 모듈**: 기반 모델과 분리하여 업무별 변화량을 저장하는 매개변수다.
- **실행 관리자**: 기반 모델과 모듈의 병합•적재•전환을 관리한다.

</details>

- **PEFT 주입 구성**으로 유형•대상 층•모듈 크기 지정이 핵심이다.

```text
                 [동결 기반 모델]
                        |
                    [주입 구성]
                        |
                    [학습 모듈]
                        |
                    [실행 관리자]
```

선의 의미: 동결 기반 모델에 주입 구성이 학습 모듈을 결합하고, 실행 관리자가 업무별 모듈의 병합•적재•전환 경계를 담당하는 PEFT 구조를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 동결 기반 모델 | **공통 표현•원본 가중치** 보존 |
| 주입 구성 | **PEFT 유형•대상 층•크기** 지정 |
| 학습 모듈 | **업무별 변화량** 저장 |
| 실행 관리자 | **모듈 병합•적재•전환** 관리 |

#### 한줄 요약
- **동결 모델•주입 구성•학습 모듈•실행 관리자**를 구성한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **매개변수 효율적 파인튜닝 구성**: 모델 구조•품질•메모리•전환 조건에 맞춰 방식과 대상 층을 정한 설정한다.
- **업무별 경로**: 동결 기반 모델의 선택 위치에 추가하여 해당 업무만 학습하도록 만든 계산 경로다.

</details>

```text
업무•PEFT 구성기
       │ 품질•메모리•전환 조건 정의
       │ 1. 방식•대상 층•크기 선택
       ▼
기반 모델
       │ 2. 기반 동결•학습 모듈 주입
       ▼
┌──────────── 학습 종료 전 반복 ────────────┐
│ 학습기                                    │
│   └ 3. 선택 매개변수 갱신                 │
└───────────────────────────────────────────┘
       │ 학습 모듈 전달
       ▼
실행 관리자
       │ 병합•동적 적재 검증
       ▼
업무•PEFT 구성기
```

**동작 원리**

1. **방식•대상 층•크기 선택**: 모델 구조와 실행 조건에 맞는 **PEFT 구성**을 결정한다.
2. **기반 동결•학습 모듈 주입**: 원본 갱신을 막고 선택 위치에 **업무별 경로**를 연결한다.
3. **선택 매개변수 갱신**: 역전파 대상을 제한해 **경량 모듈 가중치**를 학습한다.

#### 한줄 요약
- **구성 선택•모듈 주입•선택 갱신•적재 검증**을 수행한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **어댑터(Adapter)**: 모델 층 사이에 소형 신경망을 삽입하여 중간 표현을 학습한다.
- **프롬프트 튜닝(Prompt Tuning)**: 입력 앞의 학습 가능한 가상 토큰만 갱신한다.
- **저랭크 적응(Low-Rank Adaptation, LoRA)**: 가중치 변화량을 두 작은 저랭크 행렬의 곱으로 학습한다.

</details>

- 중간층은 **Adapter**, 입력은 **Prompt Tuning**, 변화량은 LoRA가 핵심이다.

| 비교 기준 | Adapter | Prompt Tuning | LoRA |
|:---|:---|:---|:---|
| 적용 기준 | 중간 **표현 변환** 필요 | **입력층 조정**으로 충분 | 선형층 **변화량 적응** |
| 핵심 특징 | 층 사이 **소형 모듈 삽입** | 입력의 **가상 토큰 학습** | 병렬 **저랭크 행렬 학습** |
| 한계 | 추가 **순차 연산** | 문맥 길이•**표현력 제약** | 대상 층•**랭크 선택** 필요 |

#### 한줄 요약
- **주입 위치•추론 경로**에 따라 Adapter•Prompt•LoRA을 선택한다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **학습 용량 부족**: 갱신 매개변수가 너무 작거나 위치가 부적절해 과업 행동을 충분히 학습하지 못하는 문제다.
- **가중치 병합**: 학습 변화량을 기반 가중치에 더하여 별도 어댑터 연산을 없애는 배포 방식이다.
- **가역성**: 병합 전 원본과 모듈을 보존하여 이전 배포 상태로 되돌릴 수 있는 성질이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| PEFT 유형별 **학습 용량 부족** | **Adapter•Prompt•LoRA 품질 비교** | 과업에 맞는 **주입 방식 선택** |
| 다중 업무 모듈의 **적재•전환 지연** | **모듈 크기•캐시•전환 부하 시험** | 공용 기반의 **전환 효율 확보** |
| 가중치 병합 후 **원본 복구 곤란** | **원본•모듈 분리•병합 회귀 시험** | 배포 품질과 **가역성 확보** |

#### 한줄 요약
- **학습 용량•모듈 전환•가역성**을 함께 검증한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **매개변수 효율적 파인튜닝 유형 선택 기준**: 과업 표현력•학습 자원•추론 경로와 모듈 전환 비용을 함께 비교하여 결정한다.
- **병합 정책**: 고정 업무는 변화량을 병합하고 동적 다중 업무는 모듈을 분리 적재하는 방식으로 정한다.

</details>

- 과업 표현력•학습 자원•모듈 전환 방식으로 **PEFT 유형•병합 정책**을 결정한다.

#### 한줄 요약
- **과업 표현력•자원•전환 방식**으로 PEFT 유형을 결정한다.
