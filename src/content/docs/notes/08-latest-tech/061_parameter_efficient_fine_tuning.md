## 미리 알고가기

- **매개변수 효율 미세조정(Parameter-Efficient Fine-Tuning, PEFT)**: 사전 학습 모델을 고정하고 일부 매개변수만 학습하는 기술군
- **저랭크 적응(Low-Rank Adaptation, LoRA)**: 가중치 변화량을 저랭크 행렬로 학습하는 PEFT 방식
- **동결(Freeze)**: 기반 가중치를 역전파의 갱신 대상에서 제외
- **가중치 병합(Weight Merge)**: 학습한 변화량을 기반 가중치에 합쳐 추론 경로를 단순화


## Ⅰ. 개요

- 정의/개념: 기반 모델 대부분을 동결하고 **소수 추가·선택 매개변수만 학습하는 기술군**
- 기존 한계: 전체 파인튜닝은 모든 가중치의 그래디언트와 옵티마이저 상태를 저장하고 업무별 모델을 복제해야 해 비용이 크다.

### 쉽게 이해하기 (학습용)

- 기반 모델 전체 대신 경량 부품만 학습해 태스크별 변형 모델을 만듭니다.

## Ⅱ. 특징

- **기반 가중치 동결·소수 매개변수 갱신**으로 학습 메모리와 저장량을 줄인다.
- **어댑터·프롬프트·저랭크 변화량**에 따라 주입 위치와 표현력이 다르다.
- 기반 모델 공유는 배포를 줄이지만 **적재·전환·추론 비용**을 별도 검증한다.

### 쉽게 이해하기 (학습용)

- 경량 부품만 보관하면 업무별 전환은 쉽지만 실행 방식별 계산 비용은 달라집니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 기반 모델 | 공통 표현 제공 및 가중치 동결 |
| 주입 구성 | PEFT 유형·대상 층·크기 지정 |
| 학습 모듈 | 어댑터·가상 토큰·LoRA 학습 |
| 실행 관리 | 기반 모델과 어댑터 결합·격리 |

```text
기반모델 ─── 어댑터층
        ├── 가상토큰
        └── LoRA행렬
```

### 쉽게 이해하기 (학습용)

- 기반 모델은 공유하고 과제별 경량 모듈만 분리해 저장합니다.

## Ⅳ. 원리 및 절차 흐름도

```text
요구 정의
↓
방식 선택
↓
동결·주입
↓
모듈 학습
↓
배포 검증
```

| 절차 | 설명 |
|:---|:---|
| 요구 정의 | 품질·메모리·전환 조건 정의 |
| 방식 선택 | 모델 구조·배포 조건 비교 |
| 동결·주입 | 기반 동결·학습 모듈 연결 |
| 모듈 학습 | 선택 매개변수만 갱신 |
| 배포 검증 | 병합·동적 적재·지연 검증 |

### 쉽게 이해하기 (학습용)

- PEFT 방식을 골라 학습한 뒤 병합·전환 비용을 검증합니다.

## Ⅴ. 종류 및 비교

| PEFT 주입 방식 | Adapter | Prompt·Prefix | LoRA |
|:---|:---|:---|:---|
| 적용 기준 | 중간 표현 변환 필요 | 가상 문맥 제어 충분 | 선형층 변화량 적응 |
| 핵심 특징 | 층 사이 소형 모듈 삽입 | 입력·계층에 가상 벡터 | 병렬 저랭크 행렬 학습 |
| 한계 | 추가 순차 연산 | 문맥·주의 메모리 증가 | 대상 층·랭크 판정 필요 |

> 요약: 학습 방식별 비용과 구조를 비교함

### 쉽게 이해하기 (학습용)

- 어댑터·가상 토큰·LoRA는 주입 위치와 실행 비용이 다릅니다.

## Ⅵ. 실무 사례

1. 다중 LoRA는 **동적 적재·권한·버전·전환 지연 관리**

### 쉽게 이해하기 (학습용)

- 작은 부품도 자주 교체하면 대기와 충돌이 생기므로 버전과 교체 시간을 관리해야 합니다.

## Ⅶ. 결론

- 학습 비용 절감을 위해 표현력·적재 방식을 검토하여 **PEFT** 활용

### 쉽게 이해하기 (학습용)

- 학습량만 보지 말고 결과 품질과 실제 실행 비용을 함께 비교해야 합니다.
