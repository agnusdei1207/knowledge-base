## 미리 알고가기

- **PEFT (Parameter-Efficient Fine-Tuning, PEFT)**: 일부 매개변수만 학습하는 기술군
- **LoRA (Low-Rank Adaptation, LoRA)**: 저랭크 변화량만 학습하는 PEFT
- **동결 (Freeze)**: 기반 가중치를 학습 대상에서 제외
- **가중 병합 (Weight Merge)**: 어댑터 변화량을 기반 가중치에 병합


## Ⅰ. 개요

- **정의/개념**: 기반 모델을 고정하고 일부 모듈만 학습
- **배경/필요성**: 전면 튜닝의 메모리·저장·배포 비용 절감

### 쉽게 이해하기 (학습용)

- 기반 모델 전체 대신 경량 부품만 학습해 태스크별 변형 모델을 만듭니다.

## Ⅱ. 특징

- 학습 매개변수·옵티마이저 상태를 줄여 비용을 낮춘다.
- 기반 모델과 어댑터를 분리해 버전을 효율화한다.
- 주입 방식에 따라 표현력·메모리·추론 비용이 달라진다.
- LoRA는 병합하면 추가 추론 경로를 없앨 수 있다.

### 쉽게 이해하기 (학습용)

- 경량 부품만 보관하면 업무별 전환은 쉽지만 실행 방식별 계산 비용은 달라집니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 기반 모델 | 공통 표현 제공 및 가중치 동결 |
| 주입 구성 | PEFT 유형·대상 층·크기 지정 |
| 학습 모듈 | 어댑터·가상 토큰·LoRA 학습 |
| 실행 관리 | 기반 모델과 어댑터 결합·격리 |

```text
기반모델 ─── 어댑터층
        ├── 가상토큰
        └── LoRA행렬
```

### 쉽게 이해하기 (학습용)

- 기반 모델은 공유하고 과제별 경량 모듈만 분리해 저장합니다.

## Ⅳ. 원리 및 절차 흐름도

```text
요구정의
↓
방식선택
↓
동결주입
↓
모듈학습
↓
배포검증
```

| 절차 | 설명 |
|:---|:---|
| 요구정의 | 품질·메모리·전환 조건 정의 |
| 방식선택 | 모델·배포 조건 PEFT 선택 |
| 동결주입 | 가중치 동결 및 모듈 연결 |
| 모듈학습 | 모듈 품질 및 능력 평가 |
| 배포검증 | 병합 및 동적 적재 검증 |

### 쉽게 이해하기 (학습용)

- PEFT 방식을 골라 학습한 뒤 병합·전환 비용을 검증합니다.

## Ⅴ. 종류 및 비교

| 판단 기준 | Adapter | Prompt/Prefix | LoRA |
|:---|:---|:---|:---|
| 학습 구조 | 소형 신경망 삽입 | 입력 가상 토큰 추가 | 저랭크 행렬 추가 |
| 적용 기준 | 층 연산 보존 | 문맥 길이 확장 | 병합 필요 시 |
| 추론 비용 | 추가 층 연산 발생 | 주의 메모리 증가 | 병합 시 미발생 |

> 요약: 학습 방식별 비용과 구조를 비교함

### 쉽게 이해하기 (학습용)

- 어댑터·가상 토큰·LoRA는 주입 위치와 실행 비용이 다릅니다.

## Ⅵ. 실무 사례

- LoRA는 동적 적재·권한·버전 관리 효율화
- 가상 토큰은 입력 길이와 주의 연산 영향 측정
- 메모리·학습시간·태스크 품질·추론 지연 비교

### 쉽게 이해하기 (학습용)

- 작은 부품도 자주 교체하면 대기와 충돌이 생기므로 버전과 교체 시간을 관리해야 합니다.

## Ⅶ. 결론

- PEFT는 품질·메모리·추론 비용으로 방식을 선택한다.

### 쉽게 이해하기 (학습용)

- 학습량만 보지 말고 결과 품질과 실제 실행 비용을 함께 비교해야 합니다.
