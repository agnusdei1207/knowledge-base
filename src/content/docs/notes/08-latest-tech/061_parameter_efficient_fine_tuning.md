## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **매개변수 효율적 미세조정(PEFT, Parameter-Efficient Fine-Tuning)**: 거대언어모델의 가중치를 고정한 채, 소수의 추가적인 파라미터만 학습하여 특정 과업에 최적화하는 기술군.
- **동결(Freeze)**: 모델 가중치를 학습 역전파 대상에서 제외하여, 컴퓨팅 자원을 절감하고 학습 효율을 높이는 기법.

</details>

- 정의/개념: 모델 가중치를 고정하고 최소한의 파라미터만 학습하여 비용 효율성을 극대화하는 미세조정 기법.
- 배경/필요성: 전체 파라미터 튜닝 대비 학습 자원 소모 감소 및 업무별 모델 배포 최적화 필요성 증대.

#### 한줄 요약
- 모델 고정 및 **소수 파라미터 학습** 체계 적용

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **선택 갱신(Selective Update)**: 전체 가중치 대신 과업 적응에 필요한 최소 파라미터 집합만 갱신하는 기법.
- **업무별 모듈(Task-specific Module)**: 기반 모델과 결합하여 특정 기능을 수행하는 경량 학습 자산.
- **동적 적재(Dynamic Loading)**: 실행 시점에 필요한 모듈만 메모리에 로드하여 자원 효율성을 높이는 구조.

</details>

- 기반 가중치 고정 후 필요한 파라미터만 갱신하는 효율적 학습 구조.
- 주입 위치 및 구조에 따라 모델 용량과 추론 경로 최적화 가능.
- 공용 기반 모델과 개별 업무 모듈의 분리 관리를 통한 이식성 향상.

#### 한줄 요약
- **주입 위치 및 모듈 최적화** 체계 적용

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **주입 구성(Injection Configuration)**: 학습 대상 층, 모듈 크기 및 연결 위치를 명시한 제어 데이터.
- **학습 모듈(Trainable Module)**: 기반 모델과 분리되어 특정 과업의 변화량을 저장하는 파라미터 집합.
- **실행 관리자(Execution Manager)**: 기반 모델과 모듈의 병합, 적재 및 전환을 통합 제어하는 컴포넌트.

</details>

- **주입 구성**을 통해 효율적인 타겟 층 및 모듈 크기를 정밀 제어.

```text
                 [동결 기반 모델]
                        |
                    [주입 구성]
                        |
                    [학습 모듈]
                        |
                    [실행 관리자]
```

선의 의미: 동결 기반 모델에 학습 모듈을 결합하고, 실행 관리자가 모듈의 병합 및 전환을 담당하는 PEFT 구성 체계.

| 구성요소 | 책임 |
|:---|:---|
| 동결 기반 모델 | **공통 표현•원본 가중치** 보존 |
| 주입 구성 | **PEFT 유형•대상 층•크기** 지정 |
| 학습 모듈 | **업무별 변화량** 저장 |
| 실행 관리자 | **모듈 병합•적재•전환** 관리 |

#### 한줄 요약
- **모델 동결 및 학습 모듈 구성** 원칙 준수

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **PEFT 구성(PEFT Configuration)**: 목표 품질과 자원 제약을 고려하여 최적의 방식과 대상 층을 설정하는 단계.
- **업무별 경로(Task-specific Path)**: 동결된 기반 모델의 특정 위치에 삽입된 데이터 처리 계산 경로.

</details>

```text
업무•PEFT 구성기
       │ 품질•메모리•전환 조건 정의
       │ 1. 방식•대상 층•크기 선택
       ▼
기반 모델
       │ 2. 기반 동결•학습 모듈 주입
       ▼
┌──────────── 학습 종료 전 반복 ────────────┐
│ 학습기                                    │
│   └ 3. 선택 매개변수 갱신                 │
└───────────────────────────────────────────┘
       │ 학습 모듈 전달
       ▼
실행 관리자
       │ 병합•동적 적재 검증
       ▼
업무•PEFT 구성기
```

**동작 원리**

1. **방식•대상 층•크기 선택**: 모델 구조와 실행 조건에 맞는 **PEFT 구성**을 결정함.
2. **기반 동결•학습 모듈 주입**: 원본 갱신을 막고 선택 위치에 **업무별 경로**를 연결함.
3. **선택 매개변수 갱신**: 역전파 대상을 제한해 **경량 모듈 가중치**를 학습함.

#### 한줄 요약
- **구성 선택•모듈 주입•선택 갱신** 공정 준수

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **어댑터(Adapter)**: 모델 층 사이에 경량 신경망을 삽입하여 도메인 특성을 학습하는 모듈.
- **프롬프트 튜닝(Prompt Tuning)**: 입력 데이터 앞에 학습 가능한 가상 토큰을 추가하여 모델을 조정하는 방식.
- **저랭크 적응(LoRA, Low-Rank Adaptation)**: 가중치 변화량을 두 개의 저랭크 행렬 곱으로 근사하여 연산량을 최적화하는 기법.

</details>

- 중간층은 **Adapter**, 입력은 **Prompt Tuning**, 변화량은 LoRA가 핵심임. 이는 전통적 방식과의 핵심 차별점으로서 실질적인 업무 가치를 창출함.

| 비교 기준 | Adapter | Prompt Tuning | LoRA |
|:---|:---|:---|:---|
| 적용 기준 | 중간 **표현 변환** 필요 | **입력층 조정**으로 충분 | 선형층 **변화량 적응** |
| 핵심 특징 | 층 사이 **소형 모듈 삽입** | 입력의 **가상 토큰 학습** | 병렬 **저랭크 행렬 학습** |
| 한계 | 추가 **순차 연산** | 문맥 길이•**표현력 제약** | 대상 층•**랭크 선택** 필요 |

#### 한줄 요약
- **주입 위치 및 추론 경로**에 따른 PEFT 기법 선정 원칙 준수

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **학습 용량 부족(Insufficient Training Capacity)**: 갱신 매개변수가 너무 작거나 위치가 부적절해 과업 행동을 충분히 학습하지 못하는 현상을 칭한다.
- **가중치 병합(Weight Merging)**: 학습 변화량을 기반 가중치에 더하여 별도 어댑터 연산을 없애는 배포 방식을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.
- **가역성(Reversibility)**: 병합 전 원본과 모듈을 보존하여 이전 배포 상태로 되돌릴 수 있는 성질을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| PEFT 유형별 **학습 용량 부족** | **Adapter•Prompt•LoRA 품질 비교** | 과업에 맞는 **주입 방식 선택** |
| 다중 업무 모듈의 **적재•전환 지연** | **모듈 크기•캐시•전환 부하 시험** | 공용 기반의 **전환 효율 확보** |
| 가중치 병합 후 **원본 복구 곤란** | **원본•모듈 분리•병합 회귀 시험** | 배포 품질과 **가역성 확보** |

#### 한줄 요약
- **학습 용량 및 모듈 관리** 체계 적용

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **PEFT 유형 선택 기준(PEFT Type Selection Criterion)**: 과업 표현력•학습 자원•추론 경로와 모듈 전환 비용을 함께 비교하여 결정하는 지침을 나타낸다.
- **병합 정책(Merging Policy)**: 고정 업무는 변화량을 병합하고 동적 다중 업무는 모듈을 분리 적재하는 방식으로 정하는 규칙으로 정의된다.

</details>

- 과업 표현력•학습 자원•모듈 전환 방식으로 **PEFT 유형•병합 정책**을 결정하여 실무 환경에서의 유연한 대응과 지속적 최적화를 지원함.

#### 한줄 요약
- **과업 및 자원 최적화** PEFT 구현 필수
