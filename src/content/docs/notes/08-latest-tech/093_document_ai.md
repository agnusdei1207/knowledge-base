## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **문서 AI(Document AI)**: 문자•레이아웃•필드 관계를 분석해 문서를 구조화한다.
- **필드 관계(Field Relation)**: 항목명•값과 표의 행•열 간 의미 연결이다.
- **광학 문자 인식(Optical Character Recognition, OCR)**: 이미지 글자를 판독 데이터로 변환한다.

</details>

- 정의: 문자•레이아웃•의미를 업무 데이터로 바꾸는 **문서 AI**이다.
- 배경/필요성: OCR 텍스트만으로는 **레이아웃•필드 관계 복원 불가** #### 한줄 요약

- 문서의 **문자•배치•필드 관계** 활용 업무 데이터로 구조화

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **레이아웃 분석(Layout Analysis)**: 문서 영역과 논리적 읽기 순서를 복원한다.
- **업무 스키마 매핑(Business Schema Mapping)**: 추출 데이터를 업무 필드에 대응시킨다.
- **사람 검토(Human-in-the-loop)**: 저신뢰 결과를 원문과 대조하는 절차이다.

</details>

- 문서 영역•읽기 순서를 복원하는 **레이아웃 분석**
- 추출 데이터를 업무 필드에 맞추는 **스키마 매핑**
- 저신뢰 결과를 원문과 대조하는 **사람 검토** #### 한줄 요약

- **레이아웃•스키마•신뢰도** 기반 자동화와 검토 분기

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **문서 분류기(Document Classifier)**: 문서 유형과 처리 경로를 판정한다.
- **정보 추출기(Information Extractor)**: 구조 영역의 데이터를 추출•매핑한다.
- **검토 라우터(Review Router)**: 신뢰도로 자동 승인•사람 검토를 결정한다.

</details>

```text
[문서 분류기]──[레이아웃 분석기]──[문자 인식기]
                                      │
                              [정보 추출기]──[검토 라우터]
```

| 구성요소 | 책임 |
|:---|:---|
| 문서 분류기 | 문서 유형 및 **추출 스키마** 결정 |
| 레이아웃 분석기 | 문단•표•**읽기 순서** 복원 |
| 문자 인식기 | 텍스트•좌표•**인식 신뢰도** 산출 |
| 정보 추출기 | **업무 필드 매핑•검증** |
| 검토 라우터 | **자동 승인•사람 검토** 분기 |

#### 한줄 요약
- **분류•레이아웃•문자 인식•추출•검토** 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **추출 스키마(Extraction Schema)**: 필드별 자료형과 검증 규칙 구조이다.
- **인식 신뢰도(Confidence Score)**: 모델 결과의 정확성 추정 점수이다.

</details>

```text
문서 분류기 ── 1. 유형•스키마 선정 ──┐
                                   ▼
레이아웃 분석 ── 2. 구조•읽기순서 ─── 구조 정보
                                   │
문자 인식기 ── 3. 글자•신뢰도 ──────┤
                                   │
정보 추출기 ── 4. 업무 필드 매핑 ───┤
                                   ▼
검토 라우터 ── 5. 승인•사람 검토 판정
```

### 동작 원리

1. 유형•스키마 선정: 문서 양식별 추출 규칙 적용
2. 구조**•**읽기순서: 논리적 순서와 배치 복원
3. 글자**•**신뢰도: 글자•위치•불확실성 산출
4. 업무 필드 매핑: 추출값을 업무 스키마에 대응
5. 승인•사람 검토 판정: 신뢰도 기반 경로 분기

#### 한줄 요약
- **스키마•구조•문자•필드 매핑•검토 분기** 수행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **문자 인식**: 문서 이미지에서 글자와 좌표를 추출하는 데 초점을 둔 처리 방식이다.
- **언어모델 보정**: 인식 결과의 문맥을 해석해 오류를 고치거나 원하는 형식으로 변환하는 방식이다.

</details>

| 처리 방식 | 문서 인공지능 | 문자 인식 | 인식+언어모델 |
|:---|:---|:---|:---|
| 적용 기준 | **반복 업무 문서** | **텍스트 전사** | **다양한 의미 보정** |
| 핵심 특징 | **구조•필드 추출•검증** | **글자•좌표 추출** | **문맥 기반 보정•변환** |
| 한계 | **미학습 양식 누락** | **필드 관계 복원 미흡** | **원문 변조 가능성** |

#### 한줄 요약
- **구조 추출•문자 전사•문맥 보정** 대상 따라 처리 구분

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **필드 누락(Field Missing)**: 양식 변화로 필수 데이터가 추출되지 않은 문제이다.
- **저신뢰 필드(Low-confidence Field)**: 인식 점수가 낮거나 규칙과 충돌한 값이다.
- **읽기 순서 왜곡(Reading Order Distortion)**: 논리 순서 오류로 필드 관계가 끊긴 문제이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 양식 변경의 **필드 누락** | 유형별 스키마•예외 분기 | **양식 변화 대응력** 확보 |
| 저신뢰 필드 | 업무 규칙•원문 좌표 대조 | **오류 데이터 반영 차단** |
| 읽기 순서 왜곡 | 레이아웃 기반 구조 검증 | **필드 관계 복원** |

#### 한줄 요약
- **필드 누락•신뢰도•읽기 순서•원문 좌표** 검증

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **자동화 범위(Automation Scope)**: 자동 승인 가능한 문서•필드 기준이다.
- **원문 대조(Original Review)**: 추출 결과를 원본 좌표와 확인하는 절차이다.

</details>

- 고정 양식 반복 문서는 **문서 AI 자동 승인** 적용
- 변동 양식•저신뢰 필드는 **사람 검토•원문 대조** 적용

#### 한줄 요약
- **양식 변동성•필드 신뢰도** 대상 따라 자동화 범위 결정
