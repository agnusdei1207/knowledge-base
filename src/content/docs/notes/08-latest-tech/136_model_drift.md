## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **모델 드리프트(Model Drift)**: 데이터 드리프트와 콘셉트 드리프트 등의 원인으로 인해 배포된 머신러닝 모델의 예측 성능이 초기 학습 시점 대비 점진적 또는 급격하게 저하되는 포괄적인 현상
- **기준선(Baseline)**: 운영 품질 이탈을 비교하기 위해 승인 시점에 고정한 성능•분포•설정 값 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

- 정의/개념: 데이터•개념•서빙 변화로 품질이 이탈하는 **모델 드리프트**
- 배경/필요성: 단일 정확도만으로는 **데이터•개념•구성 변화** 중 품질 저하 원인 분리하기 어렵음.

#### 한줄 요약
- 품질 이탈을 **데이터•개념•구성 원인**으로 분리

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **확률 보정(Calibration)**: 모델이 출력한 확률과 실제 사건 발생 비율이 일치하는 정도 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **부분집단 성능**: 전체 표본을 고객군•지역•시간대 등으로 나누어 측정한 모델 품질 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

- 데이터•개념•서빙 설정의 **복합 이탈 원인**
- 분포 경보와 정답 기반 **품질•확률 보정 영향 분리**
- 전체 평균과 **부분집단 성능 편차** 비교

#### 한줄 요약
- 분포 경보와 **정답•부분집단 오류**를 함께 검증

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **모델 계보(Model Lineage)**: 모델•데이터•코드•전처리•임계값의 버전과 변경 관계를 추적한 기록 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **정답 결합기**: 운영 예측과 나중에 확정된 실제 결과를 동일 사건으로 연결하는 구성요소 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

```text
 [성능 기준선]   [추론 관측 저장소]   [정답 결합기]   [모델•버전•설정 계보]
          \             |                 |                 /
                              [진단•복구기]
```

선의 의미: 진단•복구기는 성능 기준선, 추론 관측 저장소, 정답 결합기, 모델•버전•설정 계보를 공통 진단 근거로 결합해 데이터•개념•구성 원인을 분리하는 정적 드리프트 관리 구조를 뜻한다.

| 구성요소 | 책임 |
|:---|:---|
| 성능 기준선 | 승인 버전의 **품질•분포•출력 기준 보관** |
| 추론 관측 저장소 | 입력•예측•지연•오류의 **운영 로그 수집** |
| 정답 결합기 | 예측과 지연 도착 정답의 **동일 사건 연결** |
| 모델•버전•설정 계보 | 모델•전처리•임계값의 **변경 이력 추적** |
| 진단•복구기 | 원인별 재학습•재보정•복원의 **조치 선택** |

#### 한줄 요약
- 기준선•관측•정답•계보로 **품질 이탈 원인** 진단

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **드리프트 진단**: 성능•입력 분포•정답 관계•구성 이력을 대조해 품질 이탈 원인을 분리하는 과정 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **복구 후보**: 원천 수정•재학습•재보정•설정 복원 중 원인에 맞춰 검증할 대안 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

```text
기준•관측 저장소
   │ 1. 승인 품질•버전 기준 고정
   │ 2. 입력•예측•정답 신호 결합
   ▼
정답 결합기
   │ 3. 전체•구간 품질 비교
   ▼
드리프트 진단기
   │ 4. 데이터•개념•구성 원인 분해
   ▼
복구기
   └── 5. 복구 후보 검증•승격 ──▶ 기준•관측 저장소
```

### 동작 원리

1. 승인 품질•버전 기준 고정: 비교할 모델•전처리•지표의 **정상 상태**를 등록함.
2. 입력•예측•정답 신호 결합: 운영 사건별 분포•출력•실제 결과의 **관측 기록**을 연결함.
3. 전체•구간 품질 비교: 평균과 집단별 성능•확률 보정의 **실제 이탈**을 확인함.
4. 데이터•개념•구성 원인 분해: 입력 분포•정답 관계•계보 변화의 **원인 증거**를 대조함.
5. 복구 후보 검증•승격: 원천 수정•재학습•설정 복원의 **대안 효과**를 비교함.

#### 한줄 요약
- 정답으로 품질 이탈을 확인해 **원인별 복구 후보** 검증

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **데이터 드리프트(Data Drift)**: 모델이 학습할 때 사용된 데이터의 통계적 분포와 실제 운영 환경(Production)에서 입력되는 데이터의 분포가 시간이 지남에 따라 달라져 모델의 예측 성능이 저하되는 현상
- **개념 드리프트(Concept Drift)**: 같은 입력에 대응하는 정답이나 의사결정 규칙이 시간에 따라 달라진 상태을  역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **구성 드리프트**: 모델•전처리•임계값 등 서빙 구성의 변경으로 출력이 달라진 상태 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

| 비교 기준 | 데이터 드리프트 | 개념 드리프트 | 구성 드리프트 |
|:---|:---|:---|:---|
| 적용 기준 | **입력 분포** 변화 확인 | **입력•정답 관계** 변화 확인 | **서빙 설정•버전** 변화 확인 |
| 핵심 특징 | 특징 통계의 **기준선 이탈** | 예측 규칙의 **유효성 변화** | 전처리•임계값의 **계보 변화** |
| 한계 | **성능 영향** 별도 검증 | **정답 도착** 지연 | **변경 기록** 누락 가능 |

#### 한줄 요약
- 입력•조건부 관계•서빙 설정별 **이탈 원인** 구분

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **지연 정답**: 예측 뒤 일정 시간이 지나야 확정되어 실제 성능 검증에 사용하는 결과 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **계보 추적**: 품질 변화 시점과 모델•전처리•임계값의 변경 이력을 연결해 원인을 찾는 방법 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 분포 경보만으로 한 **성능 저하 오판** | **지연 정답•업무 지표 영향** 확인 | 불필요 재학습 **방지** |
| 전체 평균에 숨은 **부분 집단 드리프트** | **집단•구간별 오류•보정 편차** 측정 | 국소 품질 저하 **탐지** |
| 계보 추적** 누락에 따른 구성 원인 오진 | **모델•전처리•임계값 버전** 동시 기록 | 설정 복원•재학습 **정확한 선택 |

#### 한줄 요약
- 정답•부분집단 오류•계보로 **복구 대상** 결정

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **원천 수정**: 데이터 생성•수집 과정에서 발생한 품질 문제를 입력 단계에서 바로잡는 조치 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **설정 복원**: 잘못 변경된 전처리•임계값•서빙 버전을 검증된 상태로 되돌리는 조치을  역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

- **데이터•개념•구성 원인**에 따라 원천 수정•재학습•설정 복원 선택

#### 한줄 요약
- 원인 진단 후 **원천 수정•재학습•설정 복원** 선택
