## 미리 알고가기

- **디지털 트윈(Digital Twin)**: '디지털 트윈'으로 읽으며, 물리 대상과 데이터를 동기화해 상태 분석·예측·의사결정을 지원하는 가상 표현
- **사물인터넷(Internet of Things, IoT)**: '아이오티'로 읽으며, 센서·통신으로 물리 대상의 상태와 사건을 수집하는 기술
- **시뮬레이션(Simulation)**: 모델에 조건을 적용해 상태 변화와 결과를 예측하는 실험
- **피드백(Feedback)**: 분석·조치 결과를 물리 대상과 트윈 모델의 다음 상태에 반영하는 과정
- **표기 이유**: '트윈'은 단순히 모양이 같은 3D 모델이 아니라 **실물 식별·상태 동기화·생애주기 관계를 유지**한다는 의미

## Ⅰ. 개요

- **정의/개념**: 물리 대상의 상태·맥락·이력을 동기화하고 모델로 **분석·예측·최적화하는 생애주기 가상 표현**
- **배경/필요성**: 정적 모델과 사후 점검 방식의 **현재 상태 미반영·중단 없는 변경 검증·고장 예측 한계**를 해소하기 위해 필요

### 쉽게 이해하기 (학습용)

- 실제 설비의 현재 상태를 계속 따라가는 가상 복제본에서 미리 실험해 운전과 정비 결정을 돕는 방식이다.

## Ⅱ. 특징

- 실물의 센서·사건·이력을 반영해 **트윈 상태를 지속 동기화**한다.
- 모델·시뮬레이션으로 **고장·성능·변경 결과를 사전에 예측**한다.
- 권고·자동 제어는 모델 오차가 현실로 전파되지 않도록 **승인·안전 경계와 피드백 검증**을 둔다.

### 쉽게 이해하기 (학습용)

- 가상 복제본은 실제 노후 상태를 반영하고, 예측 결과는 안전 검사를 거쳐 현장에 적용한다.

## Ⅲ. 아키텍처 및 구성요소

```text
[물리 대상] → [센서·사건 통합] → [트윈 상태·이력]
     ↑                                  ↓
[승인·안전 제어] ← [분석·시뮬레이션·트윈 서비스]
```

| 설계 요소 | 설명 |
|:---|:---|
| 물리 대상·식별자 | **실물과 생애주기 이력 식별** |
| 센서·사건 통합 | **상태 데이터 수집·시간 정렬** |
| 트윈 상태 저장소 | **현재 상태·맥락·이력 보존** |
| 모델·시뮬레이션 | **상태 추정·변경 영향 예측** |
| 분석·트윈 서비스 | **예측·최적화 결과 제공** |
| 승인·안전 제어 | **검증된 조치만 실물 반영** |

> 요약: 물리 상태를 트윈에 동기화하고 예측·승인된 조치를 다시 현실에 반영한다.

### 쉽게 이해하기 (학습용)

- 센서가 복제본을 갱신하고 가상 실험 결과가 안전 검사를 거쳐 작업 지시로 돌아간다.

## Ⅳ. 원리 및 절차 흐름도

```text
대상·모델 연결 → 데이터·시간 동기화 → 상태 추정·모델 보정 → 시뮬레이션·예측 → 승인·조치 → 결과 피드백
```

| 절차 | 설명 |
|:---|:---|
| 대상·모델 연결 | 실물 식별자와 모델 버전 연결 |
| 데이터·시간 동기화 | 센서·사건 정합성과 시각 정렬 |
| 상태 추정·모델 보정 | 현재 상태 갱신·오차 보정 |
| 시뮬레이션·예측 | 변경·고장·성능 결과 계산 |
| 승인·조치 | 안전 규칙과 권한 검증 후 실행 |
| 결과 피드백 | 실제 결과로 상태·모델 재보정 |

> 요약: 실물 상태로 모델을 보정하고 예측·안전 검증·실제 결과 환류를 반복한다.

### 쉽게 이해하기 (학습용)

- 실제와 가상의 차이를 줄인 뒤 실험하고, 현장 결과로 다음 예측을 다시 고친다.

## Ⅴ. 종류 및 비교

| 물리·가상 연계 수준 | Digital Model | Digital Shadow | Digital Twin |
|:---|:---|:---|:---|
| 적용 기준 | 설계·오프라인 검증 | 현황 가시화·상태 추적 | 예측·최적화·안전 조치 |
| 핵심 특징 | 수동 데이터 갱신 | 물리→가상 자동 갱신 | 양방향 연계·피드백 |
| 한계 | 실제 상태 불일치 | 현실 조치 환류 부재 | 모델 오류의 현실 전파 |

> 요약: 자동 데이터 흐름의 방향과 현실 조치 피드백 여부로 구분한다.

### 쉽게 이해하기 (학습용)

- 수동 설계도, 자동 계기판, 안전한 운전 판단까지 돕는 가상 복제본의 차이다.

## Ⅵ. 실무 사례

1. **풍력 터빈 진동 기반 베어링 수명 예측**
2. **조립 공정 병목 시뮬레이션과 일정 최적화**

### 쉽게 이해하기 (학습용)

- 진동·온도·정비 이력으로 고장 시점을 예측하되 설비 보호 제어와 작업자 승인을 우선한다.
- 공정 변경을 가상 검증한 뒤 제한 적용하고 실제 생산 결과로 모델을 다시 보정한다.

## Ⅶ. 결론

- 현실 조치까지 연결할 때 **상태 동기화 정확도·모델 오차·승인·안전 경계를 검증한 수준으로 권한을 제한**해야 한다.

### 쉽게 이해하기 (학습용)

- 닮은 그림보다 실제 상태를 정확히 따라가고 잘못된 예측이 현장 사고로 이어지지 않게 하는 것이 중요하다.
