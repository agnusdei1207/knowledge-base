## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **셀프 어텐션(Self-Attention)**: 같은 시퀀스 안의 토큰 관계를 계산하고 관련 정보의 가중합으로 각 토큰 표현을 갱신하는 연산을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.
- **시퀀스(Sequence)**: 순서가 있는 토큰이나 시점의 연속된 입력이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.

</details>

- 정의/개념: 동일 **시퀀스**의 각 토큰이 다른 토큰과의 관련도에 따라 값 벡터를 가중 결합하는 **셀프 어텐션**임. 이는 전통적 방식과의 핵심 차별점으로서 실질적인 업무 가치를 창출함.
- 배경/필요성: 순차 상태 전달 구조는 멀리 떨어진 토큰의 관계를 직접 계산하기 어렵음.

#### 한줄 요약
- **셀프 어텐션**으로 문맥 표현을 갱신한다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **쿼리(Query, Q)**: 현재 토큰이 어떤 정보를 찾을지 나타내는 조회 기준 벡터을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.
- **키(Key, K)**: 각 토큰이 쿼리와 얼마나 관련 있는지 비교하는 식별 벡터로 정의된다.
- **밸류(Value, V)**: 계산된 어텐션 가중치에 따라 실제로 가중합되는 정보 벡터이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.

</details>

- **쿼리**: 입력을 조회 기준 벡터로 투영하여 실무 환경에서의 유연한 대응과 지속적 최적화를 지원함.
- **키**: 입력을 비교 식별 벡터로 투영하여 실무 환경에서의 유연한 대응과 지속적 최적화를 지원함.
- **밸류**: 입력을 전달 정보 벡터로 투영하여 실무 환경에서의 유연한 대응과 지속적 최적화를 지원함.
- 쿼리•키 유사도로 밸류 가중합의 참조 비율을 산출하여 실무 환경에서의 유연한 대응과 지속적 최적화를 지원함.
- 마스크로 참조를 제어하며 연산•메모리 비용은 O(N²)임. 이는 전통적 방식과의 핵심 차별점으로서 실질적인 업무 가치를 창출함.

#### 한줄 요약
- 모든 토큰 쌍을 비교해 장거리 관계를 직접 계산한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **어텐션 점수(Attention Score)**: 쿼리와 키의 내적으로 계산하여 토큰 사이의 원시 관련도를 나타낸 값을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.
- **소프트맥스(Softmax)**: 실수 점수 벡터를 각 값이 0과 1 사이이고 합이 1인 가중치로 정규화하는 함수이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.
- **인과 마스크(Causal Mask)**: 자기회귀 생성에서 현재 토큰이 미래 위치의 토큰을 참조하지 못하도록 점수를 차단하는 행렬을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.

</details>

```text
[Q•K•V 투영]──[어텐션 점수 계산기]
                       │
             [스케일•인과 마스크]
                       │
                [소프트맥스]──[문맥 결합기]
```

선의 의미: 투영•점수•마스크•정규화•결합 책임의 정적 연결을 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| Q•K•V 투영 | 입력 임베딩의 선형 변환 |
| 어텐션 점수 계산기 | **어텐션 점수** 계산 |
| 스케일•인과 마스크 | 점수 안정화와 **인과 마스크** 적용 |
| 소프트맥스 | **소프트맥스**로 가중치 정규화 |
| 문맥 결합기 | 밸류 가중합 산출 |

#### 한줄 요약
- **점수•마스크•소프트맥스**로 문맥 가중합을 구성한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **선형 투영(Linear Projection)**: 같은 입력 표현에 서로 다른 가중치 행렬을 곱해 Q•K•V 벡터로 변환하는 연산로 정의된다.
- **문맥 벡터(Context Vector)**: 어텐션 가중치에 따라 밸류를 합산하여 주변 토큰 정보를 결합한 출력 표현이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.
- **동일 입력 Q•K•V 투영**: 같은 토큰 표현을 서로 다른 가중치 행렬로 쿼리•키•밸류에 변환하는 절차을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.
- **Q•K 내적 점수 계산**: 쿼리와 키의 내적으로 토큰 사이의 원시 관련도를 산출하는 절차을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.
- **스케일•마스크 적용**: 내적 점수를 조정하고 미래•패딩 토큰의 참조를 차단하는 절차을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.
- **소프트맥스 가중치 산출**: 점수를 합이 1인 참조 가중치로 정규화하는 절차을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.
- **V 가중합 문맥 결합**: 정규화된 가중치에 따라 밸류를 합산해 문맥 벡터를 만드는 절차을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.

</details>

```text
토큰 표현
   │ 1. 동일 입력 Q•K•V 투영
   ▼
투영기
   │ 2. Q•K 내적 점수 계산
   ▼
연산기
   │ 3. 스케일•마스크 적용
   ▼
소프트맥스
   │ 4. 소프트맥스 가중치 산출
   │ 5. V 가중합 문맥 결합
   │ 문맥 표현 출력
   ▼
출력
```

1. **동일 입력 Q•K•V 투영**: **선형 투영**으로 조회•식별•전달 벡터를 만든음.
2. **Q•K 내적 점수 계산**: **어텐션 점수**를 산출함.
3. **스케일•마스크 적용**: 점수 폭을 안정화하고 **인과 마스크**를 적용함.
4. **소프트맥스 가중치 산출**: **소프트맥스**로 참조 비율을 정규화함.
5. **V 가중합 문맥 결합**: 토큰별 **문맥 벡터**를 생성함.

#### 한줄 요약
- **소프트맥스**로 참조 비율을 산출한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **크로스 어텐션(Cross-Attention)**: 대상 시퀀스의 Q가 원천 시퀀스의 K•V를 참조하여 서로 다른 시퀀스나 양식을 연결하는 연산이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.

</details>

- **셀프 어텐션**과 **크로스 어텐션**을 내부 문맥과 외부 시퀀스 연결 기준으로 구분하여 실무 환경에서의 유연한 대응과 지속적 최적화를 지원함.

| 비교 기준 | 셀프 어텐션 | 크로스 어텐션 |
|:---|:---|:---|
| 적용 기준 | 동일 시퀀스의 내부 문맥 학습 | 서로 다른 시퀀스•양식 연결 |
| 핵심 특징 | 같은 입력에서 Q•K•V 생성 | 대상 Q가 원천의 K•V 참조 |
| 한계 | 길이에 따른 O(N²) 비용 | 원천•대상의 정렬 품질 의존 |

#### 한줄 요약
- 내부 문맥은 **셀프 어텐션**, 외부 연결은 **크로스 어텐션**이 적합하다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **FlashAttention**: 어텐션 계산을 블록 단위로 재구성하여 전체 점수 행렬의 메모리 입출력을 줄이는 구현 기법을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.
- **패딩 마스크(Padding Mask)**: 길이를 맞추기 위해 추가한 무효 토큰이 어텐션에 반영되지 않도록 참조를 차단하는 행렬이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.
- **교란 실험**: 입력이나 어텐션 요소를 변경•제거했을 때 출력이 어떻게 달라지는지 측정하여 설명의 타당성을 확인하는 방법을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 장문에서 점수 행렬 메모리 급증 | **FlashAttention**•윈도•희소 어텐션 | 메모리 접근 절감 |
| 인과•패딩 마스크의 참조 오류 | **패딩 마스크** 경계 사례 시험•시각화 | 미래•무효 토큰 정보 누출 차단 |
| 어텐션 가중치의 설명 과신 | **교란 실험**•별도 설명 기법 | 인과적 해석 오판 방지 |
| 긴 문맥의 핵심 정보 희석 | 검색•요약•계층적 청킹•회수율 평가 | 중요 근거 참조 가능성 향상 |

#### 한줄 요약
- **FlashAttention•희소 어텐션**으로 장문 비용 절감이 핵심이다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **어텐션 방식 선택 기준**: 동일 시퀀스의 내부 문맥에는 셀프 어텐션을, 외부 시퀀스 연결에는 크로스 어텐션을 적용하는 기준을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.

</details>

- **어텐션 방식 선택 기준**에 따라 동일 시퀀스는 **셀프 어텐션**, 외부 문맥은 **크로스 어텐션**을 선택하여 실무 환경에서의 유연한 대응과 지속적 최적화를 지원함.

#### 한줄 요약
- 문맥 출처에 따라 셀프•크로스 어텐션을 선택한다. 체계 적용
