## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **가우시안 오류 선형 유닛(Gaussian Error Linear Unit, GELU)**: 입력에 정규분포 누적확률을 곱하는 부드러운 활성화 함수을 말한다.
- **스위시 게이트 선형 유닛(Swish Gated Linear Unit, SwiGLU)**: 스위시 게이트와 값 투영을 원소별로 곱하는 활성화 구조을 의미한다.
- **피드포워드 신경망(Feed-Forward Network, FFN)**: 토큰별 특징을 확장•활성화•축소하는 계층을 의미한다.
- **트랜스포머(Transformer)**: 주의 집중으로 토큰 관계를 학습하는 신경망 구조이다.

</details>

- 정의: **GELU•SwiGLU 비교**는 트랜스포머 **FFN**에서 단일 활성과 게이트•값 결합을 표현력•파라미터•연산량 기준으로 선택하는 설계 문제임이다.
- 배경/필요성: GELU 단일 활성 경로는 입력별 **곱셈 게이팅**이 어렵음.

#### 한줄 요약

- GELU의 단일 활성과 SwiGLU의 곱셈 게이트 비교.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **GELU 활성 경로**: 입력에 정규분포 누적분포함수 값을 곱해 신호를 부드럽게 조절하는 개념로 정의된다.

</details>

- **SwiGLU 곱셈 게이트**로 입력별 특징을 선택함.
- **GELU 단일 활성 경로**로 구현•메모리 절감이 핵심임.
- 같은 은닉 차원에서는 SwiGLU의 **삼중 투영**으로 파라미터•연산 증가함.
#### 한줄 요약

- 곱셈 게이트의 표현력과 추가 투영 비용 간 상충.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **게이트 선형 유닛(Gated Linear Unit, GLU)**: 한 투영을 게이트로 사용해 다른 값 투영의 정보 흐름을 조절하는 구조로 정의된다.
- **입력 특징**: 트랜스포머 블록에서 FFN으로 전달되는 토큰별 표현을 말한다.
- **GELU 투영**: 입력을 한 경로로 투영하고 GELU를 적용하는 구성요소로 정의된다.
- **게이트 투영**: 입력을 투영하고 스위시 함수로 게이트 값을 생성하는 구성요소을 의미한다.
- **값 투영**: 게이트가 조절할 독립 선형 특징을 생성하는 구성요소로 정의된다.
- **요소별 결합**: 게이트와 값 특징을 같은 위치끼리 곱하는 구성요소을 말한다.
- **출력 투영**: 활성 특징을 모델 차원으로 복원하는 구성요소을 말한다.
- **공정 비교 조건**: 매개변수 수•중간 차원•연산량을 맞춘 뒤 정확도와 지연을 비교해야 활성화 함수 효과를 분리할 수 있는 방식을 의미한다.

</details>

**SwiGLU**는 **GLU** 구조에 스위시 게이트를 적용하고, **GELU**는 단일 활성 경로를 사용한다.

```text
                         [입력 특징]
                       /      |       \
              [GELU 투영] [게이트 투영] [값 투영]
                       \       \       /
                        \    [요소별 결합]
                         \       /
                         [출력 투영]
```

선의 의미: GELU는 단일 활성 경로, SwiGLU는 게이트•값 결합 경로를 거쳐 공통 출력 투영에 연결되는 관계다.

| 구성요소 | 책임 |
|:---|:---|
| 입력 특징 | **Transformer 토큰별 모델 차원** 입력 |
| GELU 투영 | **단일 투영•GELU 활성값** 생성 |
| 게이트 투영 | **Swish 게이트값** 생성 |
| 값 투영 | **SwiGLU 선형 값 특징** 생성 |
| 요소별 결합 | **게이트×값** 계산 |
| 출력 투영 | 활성 특징을 **모델 차원**으로 복원 |

#### 한줄 요약

- GELU 단일 경로와 SwiGLU 게이트•값 결합 경로의 차이.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **곱셈 게이팅**: 한 투영이 만든 게이트 값으로 다른 투영의 특징별 통과량을 조절하는 연산로 정의된다.

</details>

```text
[입력 특징]
    │ 1. 활성•게이트 특징 투영
    ▼
[게이트•활성화 투영]
    ├─ GELU ── 2. GELU 단일 활성 계산 ────────────┐
    └─ SwiGLU ───────────────────────────────────┐ │
[입력 특징] ── 3. 독립 값 특징 투영 ──▶ [값 투영] │ │
[값 투영] ─────────── 값 특징 ──────────────────▶│ │
[게이트•활성화 투영] ── 4. Swish 게이트•값 결합 ─▶ [활성화•요소별 결합]
                                                     │ 5. 모델 차원 복원
                                                     ▼
                                                 [출력 투영]
```

### 동작 원리

1. 활성•게이트 특징 투영: **GELU 입력•스위시 게이트**를 계산함.
2. GELU 단일 활성 계산: 투영값에 GELU 활성화를 적용함.
3. 독립 값 특징 투영: **SwiGLU**의 선형 값 경로를 생성함.
4. Swish 게이트•값 결합: 게이트와 값의 요소별 곱을 계산함.
5. 모델 차원 복원: 출력 투영으로 모델 차원을 변환함.

#### 한줄 요약

- GELU 단일 활성과 SwiGLU 곱셈 게이트의 출력 복원.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **은닉 차원**: 피드포워드 신경망 내부 투영 벡터의 폭으로, 파라미터 수와 연산량 및 표현력을 함께 결정하는 속성을 의미한다.
- **대규모 언어 모델(Large Language Model, LLM)**: 대규모 텍스트로 학습해 언어 이해•생성을 수행하는 모델로 정의된다.

</details>

| FFN 활성화 방식 | SwiGLU | GELU |
|:---|:---|:---|
| 적용 기준 | **품질 우선 LLM•예산 조정 가능** | **단순 경로•호환성•비용 우선** |
| 핵심 특징 | **게이트•값 투영 요소별 결합** | **단일 투영값의 부드러운 활성** |
| 한계 | **투영•메모리•연산량 증가** | **게이트 기반 특징 선택 부재** |

> 요약: **SwiGLU**는 특징 선택, **GELU**는 단순성•호환성 중심이 핵심이다.

#### 한줄 요약

- 특징 선택은 SwiGLU, 단순성•호환성은 GELU 선택.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **파라미터 예산**: 모델 크기•메모리•연산량에 허용되는 가중치 규모로, 공정한 활성 함수 비교의 통제 조건이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 파라미터 수 차이로 **품질 비교 왜곡** | **파라미터 예산**에 맞춰 **FFN 은닉 차원** 조정 | **품질•비용 비교 조건** 정렬 |
| 추가 투영으로 **메모리 대역폭 증가** | **융합 커널•텐서 병렬 배치** | **추론 지연•메모리 이동** 감소 |
| 모델•데이터 차이로 **활성화 함수 효과 혼동** | **동일 데이터•학습량 A/B 시험** | **실측 품질•비용 근거** 확보 |

#### 한줄 요약

- SwiGLU의 추가 투영만큼 은닉 차원을 줄인 공정 비교.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **FFN 활성 선택**: 품질 이득•연산 비용•커널 지원을 함께 비교하여 활성 함수를 정하는 개념로 정의된다.

</details>

- 품질 이득•커널 지원은 **SwiGLU**, 단순성•호환성은 **GELU**를 선택함.

#### 한줄 요약

- 품질 이득•추가 투영 비용•커널 지원 기반 활성 선택.
