## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **논리 큐비트(Logical Qubit)**: 하나의 양자 정보를 오류 정정 코드 공간에 인코딩하여 물리 오류로부터 보호하는 정보 단위을 의미한다.

</details>

- 정의/개념: **논리 큐비트**는 오류 정정 코드 공간에 인코딩된 보호 양자 정보 단위임.
- 배경/필요성: 물리 큐비트 오류 누적은 긴 회로의 **계산 결과 신뢰성 상실**을 초래함.

#### 한줄 요약

- 여러 물리 큐비트의 코드 공간에 양자 정보를 분산해 보호한다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **코드 공간**: 오류 정정 코드가 유효한 논리 상태를 표현하도록 여러 물리 큐비트 안에 정한 부분공간을 의미한다.

</details>

- 논리 정보를 다수 물리 큐비트에 분산하는 **코드 공간**이 핵심임.
- 신드롬 측정•해독을 통한 **반복 오류 정정**이 핵심임.
- 오류 확산을 제한하는 논리 게이트의 **보호된 연산**이 핵심임.
#### 한줄 요약

- 논리 정보를 직접 측정하지 않고 오류 신드롬만 반복 감시한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **물리 큐비트**: 실제 장치에서 양자 상태•게이트•측정을 구현하며 논리 큐비트를 구성하는 하드웨어 정보 단위로 정의된다.
- **신드롬 추출**: 논리 상태를 붕괴시키지 않고 물리 오류의 징후를 반복 측정하는 과정을 의미한다.
- **해독 엔진**: 신드롬 이력에서 오류를 추정해 보정과 논리 상태 추적을 수행하는 고전 연산부을 말한다.
- **논리 게이트**: 오류 정정 보호를 유지하면서 코드 공간의 논리 상태를 변환하는 연산을 의미한다.

</details>

```text
                    [코드 공간] ----- [연산 레이어]
                      /      \              |
             [물리 큐비트] [신드롬 추출] ----- [해독 엔진]
```

선의 의미: 코드 공간이 물리 큐비트에 논리 상태를 인코딩하고 연산 레이어의 보호 연산 범위를 제공하며, 신드롬 추출과 해독 엔진이 오류 징후와 보정 정보를 연산 레이어에 결합하는 관계를 뜻한다.

| 구성요소 | 책임 |
|:---|:---|
| 물리 큐비트 | 인코딩용 **데이터•검사 큐비트** |
| 코드 공간 | 오류 정정 코드의 **보호 논리 상태** |
| 신드롬 추출 | 정보 누설 없는 **오류 징후 측정** |
| 해독 엔진 | 신드롬 기반 **오류 추정•프레임 갱신** |
| 연산 레이어 | 보호 상태의 **논리 연산** 수행 |

#### 한줄 요약

- 물리 큐비트에 정보를 인코딩하고 신드롬을 지속 측정해 오류를 보정한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **반복 오류 정정**: 신드롬을 주기적으로 측정•해독하여 계산 중 누적되는 물리 오류를 계속 추적하는 과정로 정의된다.

</details>


```text
[요구사항]
   │ 1. 오류 목표 설정
   ▼
[인코더]
   │ 2. 논리 상태 인코딩
   ▼
[신드롬 회로]
   │ 3. 신드롬 주기 검사
   ▼
[해독기]
   │ 4. 보정 프레임
   ▼
[논리 연산] ── 5. 보호된 논리 연산 ──▶ [신드롬 회로]
   └──────────── 논리 연산 검증 결과 ───▶ [요구사항]
```

**동작 원리**

1. **오류 목표 설정**: 알고리즘 깊이와 허용 실패율에서 논리 오류율•자원 목표를 도출함.
2. **논리 상태 인코딩**: 다수 물리 데이터•검사 큐비트의 코드 공간에 정보를 매핑함.
3. **신드롬 주기 검사**: 논리 정보를 노출하지 않고 오류 징후 반복을 측정함.
4. **보정 프레임 전달**: 측정 이력에서 오류를 추정해 논리 상태를 추적함.
5. **보호된 논리 연산**: 오류 확산을 제한하며 코드 공간의 상태를 변환함.

#### 한줄 요약

- 논리 상태를 인코딩하고 계산 내내 신드롬 측정과 해독을 반복한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **물리 대 논리 자원비**: 하나의 신뢰할 수 있는 논리 큐비트를 구현하는 데 필요한 물리 큐비트와 연산의 규모로 정의된다.

</details>

| 판단 기준 | 물리 큐비트 | 검출 가능한 큐비트 | 논리 큐비트 |
|:---|:---|:---|:---|
| 적용 기준 | **사전 오류 억제** | 오류 감지 시 **연산 취소** | **실시간 정정•연산 지속** |
| 핵심 특징 | 장치의 **단일 큐비트** | 오류 검출 후 **결과 선별** | 코드 공간의 **오류 정정** |
| 한계 | **하드웨어 노이즈** 직접 영향 | 높은 **결과 폐기율** | 큰 **물리 자원•게이트 비용** |

#### 한줄 요약

- 긴 계산을 지속하려면 오류 검출을 넘어 반복 오류 정정이 필요하다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **오류 확산**: 하나의 물리 오류가 게이트 상호작용을 통해 여러 큐비트로 전파되어 논리 오류가 되는 현상이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **논리 오류 억제 미달** 미검증 시 물리 자원은 늘지만 정보 보존 이득 없음 | 거리별 물리•논리 오류율을 동일 주기에서 비교 | 자원 대비 **논리 오류 감소** 확인 |
| **자원 오버헤드** 미검증 시 데이터•검사 큐비트와 논리 게이트 비용 급증 | 목표 알고리즘에서 큐비트•주기•공간시간 비용 공동 산정 | **공간시간 예측성** 향상 |
| **해독•제어 지연** 미검증 시 보정 정보가 늦어 논리 연산 일정 붕괴 | 실시간 해독 처리량 시험과 제어 경로 병렬화 | 논리 연산 **일정 준수율** 향상 |

#### 한줄 요약

- 핵심 운영 위험마다 실행 가능한 대책과 검증 효과를 함께 확인한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **논리 오류율**: 오류 정정을 통과한 오류가 논리 상태나 연산을 잘못 바꾸는 확률로 정의된다.

</details>

- 목표 논리 오류율을 만족하는 **코드 규모**와 **해독 처리량**으로 논리 큐비트를 구성함.

#### 한줄 요약

- 물리 큐비트 수보다 실질적인 논리 오류 감소와 연산 가능성이 중요하다.
