## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **양자컴퓨팅**: 큐비트의 중첩•얽힘•간섭을 양자 게이트로 조작하고 측정하여 계산 결과를 얻는 계산 방식이다.

</details>

- 정의/개념: 큐비트의 중첩•얽힘•간섭을 양자 게이트로 조작하고 측정하여 계산 결과를 얻는 **양자컴퓨팅**이다.
- 배경/필요성: 일부 문제는 입력 증가에 따라 고전 알고리즘의 **계산량 급증**이 발생한다.

#### 한줄 요약

- 확률 진폭•위상 조작과 반복 측정 기반을 계산한다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **중첩**: 큐비트가 여러 기저 상태의 확률 진폭을 동시에 표현하는 양자 상태이다.
- **얽힘**: 여러 큐비트의 상태가 분리해 기술할 수 없는 상관관계를 이루는 양자 상태이다.
- **간섭**: 확률 진폭을 더하거나 상쇄하여 원하는 결과의 측정 확률을 높이는 현상이다.
- **측정**: 큐비트의 양자 상태를 고전 비트 결과로 변환하는 과정이다.

</details>

- 여러 기저 상태의 확률 진폭을 함께 표현하는 **중첩**이 핵심이다.
- 큐비트 상관과 진폭 조절로 결과 확률을 높이는 **얽힘•간섭**이 핵심이다.
- 반복 실행으로 고전 결과 분포를 추정하는 **측정**이 핵심이다.

#### 한줄 요약

- 얽힘•간섭 기반 결과 확률 설계와 반복 측정을 검증한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **양자 게이트**: 큐비트의 확률 진폭과 위상을 가역적으로 변환하는 연산이다.
- **큐비트(Qubit)**: 중첩된 기저 상태의 확률 진폭과 위상으로 양자 정보를 표현하는 계산 단위이다.
- **양자 회로 컴파일러**: 논리 게이트 회로를 장비의 큐비트 연결성•기본 게이트•오류 특성에 맞게 변환하는 소프트웨어이다.
- **양자 처리장치(Quantum Processing Unit, QPU)**: 큐비트를 제어하고 양자 게이트와 측정을 물리적으로 실행하는 연산장치이다.
- **고전 제어•검증부**: 양자 회로를 제어하고 반복 측정값을 취합해 통계 결과와 고전 기준선을 비교하는 구성요소이다.

</details>

```text
                       [알고리즘 모델]
                              |
                         [상태 준비]
                              |
                       [회로 컴파일러]
                              |
                       [양자 처리장치]
                              |
                    [고전 제어•검증부]
```
선의 의미: 알고리즘 모델은 상태 준비의 입력•정밀도 계약을 정의하고, 회로 컴파일러는 그 계약을 양자 처리장치의 연결성•기본 게이트 경계에 매핑하며, 고전 제어•검증부는 양자 처리장치의 제어•측정•기준선 비교 경계를 구성한다.

| 구성요소 | 책임 |
|:---|:---|
| 알고리즘 모델 | 문제별 **양자 알고리즘•목표 정밀도** 정의 |
| 상태 준비 | 입력을 큐비트 **진폭•위상**으로 인코딩 |
| 회로 컴파일러 | 논리 회로의 **장비 최적화•매핑** |
| 양자 처리장치 | 큐비트의 **양자 게이트•측정** 실행 |
| 고전 제어•검증부 | 장치 제어•측정값 취합과 **고전 기준선 비교** |

#### 한줄 요약

- 상태 준비•회로 실행•측정과 고전 기준선 검증의 결합이 핵심이다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **샷(Shot)**: 동일한 양자 회로를 한 번 실행하고 측정한 표본이다.

</details>


```text
[알고리즘 설계]
      │ 1. 문제•회로 설계
      ▼
   [컴파일러]
      │ 2. 매핑•상태 준비
      ▼
   [양자 장치]
      │ 3. 양자 게이트 실행
      ▼
   [측정 체계]
      │ 4. 측정 표본
      ▼
   [고전 검증] ◀─ 5. 고전 기준선 ─ [알고리즘 설계]
      └──────────── 양자 이점 검증 결과 ───────────▶ [알고리즘 설계]
```

**동작 원리**

1. **문제•회로 설계**: 입력 규모•정확도와 양자 연산 구성을 정의한다.
2. **매핑•상태 준비**: 장비 연결성에 맞춰 회로를 변환하고 입력을 인코딩한다.
3. **양자 게이트 실행**: 중첩•얽힘•간섭을 만드는 회로 수행한다.
4. **측정 표본 전달**: 반복 실행 결과로 고전 비트 분포를 추정한다.
5. **고전 기준선 전달**: 동일 정확도의 실행시간•자원비 비교 기준을 제공한다.

#### 한줄 요약

- 동일 정확도•전체 시간•자원비 기반 고전 기준선을 비교한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **잡음 중간 규모 양자(Noisy Intermediate-Scale Quantum, NISQ)**: 오류가 있고 큐비트 수와 회로 깊이가 제한된 중간 규모 양자 장치이다.

</details>

| 판단 기준 | 고전 컴퓨팅 | 잡음 중간 규모 양자(NISQ) 컴퓨팅 | 오류정정 양자컴퓨팅 |
|:---|:---|:---|:---|
| 적용 기준 | **범용•안정적 계산** | **짧은 회로 실험** | **긴 양자 알고리즘** |
| 핵심 특징 | **비트 기반 논리** | **노이지 큐비트•얕은 회로** | **논리 큐비트•오류 정정** |
| 한계 | 특정 문제의 **계산량 급증** | **노이즈•규모•정확도 제약** | 막대한 **물리 큐비트** 필요 |

#### 한줄 요약

- 짧은 회로는 NISQ, 긴 알고리즘은 오류정정 양자컴퓨팅이 핵심이다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **디코히런스**: 환경과의 상호작용으로 큐비트의 중첩과 위상 정보가 손실되는 현상이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **불공정 기준선** 미검증 시 약한 고전 알고리즘과 비교해 양자 이점 과장 | 최신 고전 알고리즘과 정확도•전체시간 동일 조건 비교 | 양자 이점 **비교 공정성** 확보 |
| **노이즈•디코히런스•샷 비용** 미검증 시 회로 깊이와 반복 측정 증가로 신뢰성 저하 | 회로 축약, 오류 완화, 신뢰구간과 샷 예산 명시 | 측정 **통계 신뢰성** 향상 |
| **입출력 병목** 미검증 시 인코딩•후처리 비용이 계산 이점 상쇄 | 전체 파이프라인 계측과 양자 적합 하위 문제 분리 | 종단 간 **계산 이득** 검증 |

#### 한줄 요약

- 기준선•노이즈•입출력 비용 기반 종단 간 계산 이득을 검증한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **양자 우위**: 특정 문제에서 양자 계산이 실용적으로 가능한 최선의 고전 계산보다 우수한 성능을 보이는 상태이다.

</details>

- 전체 실행시간과 자원비에서 **양자 우위가 검증된 문제에만 양자컴퓨팅 적용**이 핵심이다.

#### 한줄 요약

- 큐비트 수보다는 실제 문제 해결의 전체 비용 효율성을 확인해야 한다.
