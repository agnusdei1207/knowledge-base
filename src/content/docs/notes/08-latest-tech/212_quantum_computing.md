## 미리 알고가기

- **양자컴퓨팅**: 큐비트의 중첩·얽힘·간섭을 활용한 계산 방식
- **큐비트 상태**: $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$ 형태이며 확률 합은 1임
- **발전 단계**: 현재는 NISQ 단계이며 오류와 확장성이 가장 큰 제약임



## Ⅰ. 개요

- **정의/개념**: 큐비트·양자 게이트·측정으로 수행하는 계산
- **배경/필요성**: 특정 시뮬레이션·탐색의 계산 한계를 확장

### 쉽게 이해하기 (학습용)

- 가능성의 위상을 회로로 조작해 답을 찾는 통계적 계산법임

## Ⅱ. 특징

- 중첩이 여러 기저 상태의 진폭을 함께 표현한다.
- 얽힘·간섭이 정답 진폭을 선택적으로 높인다.
- 게이트 회로·반복 측정이 확률 결과를 추정한다.
- 오류 보정·하이브리드가 장비 한계를 보완한다.

### 쉽게 이해하기 (학습용)

- 얽힘과 간섭으로 답을 도출할 확률을 설계하고 통계로 확인하는 방식임

## Ⅲ. 아키텍처 및 구성요소

| 설계 요소 | 설명 |
|:---|:---|
| 알고리즘 모델 | 문제 특성에 맞는 양자 알고리즘과 목표 정밀도 정의 |
| 상태 준비 | 입력 데이터를 큐비트 진폭과 위상으로 인코딩 |
| 회로 컴파일러 | 논리적 회로를 장비 사양에 맞게 최적화 및 매핑 |
| 양자 연산자 | 큐비트와 제어 시스템을 통한 실제 게이트 실행 |
| 고전 검증부 | 측정값 취합 및 고전 컴퓨터 연동 후 결과 도출 |

> 요약: 문제 정의·상태 준비·회로 실행·검증 구조

### 쉽게 이해하기 (학습용)

- 큐비트 언어로 문제를 옮기고 실행한 뒤 고전 컴퓨터로 확인하는 구조임

## Ⅳ. 원리 및 절차 흐름도


```text
가설설정
  ↓
상태준비
  ↓
회로실행
  ↓
반복측정
  ↓
최종검증
```

| 절차 | 설명 |
|:---|:---|
| 가설설정 | 양자 이점이 기대되는 문제와 기준 정립함 |
| 상태준비 | 큐비트 초기화 및 데이터 인코딩 수행함 |
| 회로실행 | 컴파일된 회로를 최적화하여 연산 실행함 |
| 반복측정 | 여러 번 측정하여 분포를 파악함 |
| 최종검증 | 고전 컴퓨터로 성능 및 오차 평가함 |

> 요약: 양자 이점 가설을 실행해 성능을 검증

### 쉽게 이해하기 (학습용)

- 기존 컴퓨터와의 공정한 경기 규칙을 정하고 전체 과정 성능을 확인함

## Ⅴ. 종류 및 비교

| 판단 기준 | 고전 컴퓨팅 | NISQ 양자컴퓨팅 | 오류정정 양자컴퓨팅 |
|:---|:---|:---|:---|
| 핵심 특징 | 비트 기반 결정론적 논리 | 노이지 큐비트와 얕은 회로 | 논리 큐비트와 오류정정 코드 |
| 적용 기준 | 하드웨어 기반 안정성 | 환경 소음에 따른 성능 제한 | 임계값 내 오류 억제 가능 |
| 주요 위험 | 범용 워크로드 처리 | 하이브리드 실험 단계 | 대규모 알고리즘 실현 목표 |

> 요약: NISQ 실험과 오류정정 양자컴퓨팅의 격차

### 쉽게 이해하기 (학습용)

- 현재는 짧은 회로를 실험 중이며, 긴 알고리즘은 많은 자원이 필요함

## Ⅵ. 실무 사례

1. 대상 환경의 도입 조건과 설계를 검증함
2. 운영 위험과 성과 지표를 검증함

### 쉽게 이해하기 (학습용)

- quantum chemistry 연구팀은 작은 molecule Hamiltonian을 VQE circuit로 측정하고 classical optimizer와 error mitigation을 반복하되 exact diagonalization·고성능 classical chemistry와 energy accuracy·shot·runtime을 비교해 scientific utility만 보고함
- 보안 조직은 Shor algorithm이 fault-tolerant logical qubit와 대규모 error-corrected gate를 요구한다는 resource estimate를 전제로 cryptographic inventory와 PQC migration을 수행하며, 현재 noisy device가 즉시 RSA를 깨는 것으로 오해하지 않음

## Ⅶ. 결론

- 고전 대비 전체 비용·정확도로 양자 적용 여부 결정

### 쉽게 이해하기 (학습용)

- 큐비트 수보다는 실제 문제 해결의 전체 비용 효율성을 확인해야 함
