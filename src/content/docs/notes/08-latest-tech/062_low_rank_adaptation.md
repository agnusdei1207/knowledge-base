## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **저랭크 적응(LoRA, Low-Rank Adaptation)**: 거대언어모델 가중치를 고정하고, 별도의 저랭크 행렬을 삽입하여 최소 파라미터만 학습하는 효율적 미세조정 기법.
- **저랭크 행렬(Low-Rank Matrix)**: 행렬 변화량을 두 개의 소형 저랭크 행렬(A, B)의 곱으로 근사하여 표현한 행렬.

</details>

- 정의/개념: 동결 가중치에 저랭크 변화량만 학습하는 **LoRA**
- 배경/필요성: 거대 언어 모델(LLM)의 완전 파인튜닝(Full FT)은 수백 GB 이상의 고용량 GPU VRAM과 테라바이트급 스토리지 스토리지를 요구하며 과업별 배포 및 서빙 시 극심한 자원 낭비를 유발하는 한계가 존재함에 따라, 과업 적응 시 가중치 변화량($\Delta W$)이 매우 낮은 내재적 차원(Low Intrinsic Dimension)을 갖는다는 수학적 원리에 기반하여 기존 가중치($W_0$)를 동결한 채 두 개의 저랭크 행렬($A, B$) 곱($\Delta W = B \times A$)으로 분해 학습하는 저랭크 적응(LoRA: Low-Rank Adaptation) 기술을 도입하여 **학습 파라미터 수를 99% 이상 감축하면서도 전체 파인튜닝과 대등한 과업 성능 달성, 수 메가바이트(MB) 단위의 경량 어댑터 가중치 분리 배포를 통한 스토리지/네트워크 비용 절감, 배포 시 원본 가중치와의 직접 병합($W = W_0 + \frac{\alpha}{r}BA$)을 통한 추가 추론 지연(Zero Inference Latency) 완전 제거**를 달성할 필요

#### 한줄 요약
- **저랭크 변화량**은 랭크를 올릴수록 표현력이 늘고 메모리 이득이 줄어드는 조절 손잡이이며, 추론 시 원본에 합쳐 두면 지연 증가 없이 과업 전환 비용만 남는다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **동결 가중치(Frozen Weight, $W_0$)**: 학습 중 업데이트 없이 고정된 기반 선형 변환 행렬.
- **랭크(Rank, $r$)**: 학습 행렬의 차원을 결정하여 변화량의 표현 용량을 제한하는 파라미터.
- **스케일 계수(Scaling Factor, $\alpha$)**: LoRA 변화량이 원본 가중치에 반영되는 비율을 조절하는 하이퍼파라미터.

</details>

![LoRA 랭크별 학습 매개변수 증가](/study/diagrams/lora-rank-parameter-growth.svg)

> 랭크 증가(4→64)에도 LoRA 학습 매개변수량은 전체 가중치 대비 소량으로 선형 증가함 (이론값 기준).

- **W₀ 동결•BA 갱신**: 학습 파라미터 수 축소
- **랭크•스케일 계수**: 적응 용량과 반영 크기 조절
- **병합•분리 배포**: 업무별 추론 경로 전환

#### 한줄 요약
- **랭크**•**스케일** 통한 적응 용량 조절

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **LoRA 변화량(LoRA Delta, $BA$)**: 모델 가중치 수정분을 생성하는 저랭크 행렬 곱($BA$) 결과값.
- **대상 모듈(Target Module)**: 저랭크 적응 경로가 주입되는 어텐션 또는 FFN 선형층.
- **어댑터 파일(Adapter File)**: 학습된 저랭크 행렬 및 설정을 기반 모델과 분리하여 저장한 파일.

</details>

```text
[동결 경로 W₀]---[저랭크 행렬 A,B]---[랭크•스케일]
        |                    |                  |
        +----------------[대상 모듈]-----------+
                             |
                       [어댑터 파일]
```

선의 의미: 랭크•스케일 설정에 의한 동결 경로 및 저랭크 행렬 조절과, 대상 모듈 및 어댑터 파일의 주입 위치 지정 및 분리 저장 경계 형성.

| 구성요소 | 책임 |
|:---|:---|
| 동결 경로 W₀ | 기반 선형 변환•**원본 능력 보존** |
| 저랭크 행렬 A,B | BA로 **가중치 변화량** 생성 |
| 랭크•스케일 | **r 용량•α/r 반영 크기** 조절 |
| 대상 모듈 | **LoRA 주입 선형층** 범위 지정 |
| 어댑터 파일 | **학습 행렬•구성** 분리 저장•병합 |

#### 한줄 요약
- **동결 경로•저랭크 행렬•대상 모듈•어댑터** 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **초기화(Initialization)**: 학습 초기 LoRA 출력값이 원본 모델에 영향을 주지 않도록 행렬 값($A$는 가우시안, $B$는 0)을 설정하는 과정.
- **변화량 학습(Delta Training)**: 원본 가중치는 고정한 채, 행렬 $A, B$의 그래디언트만을 계산하여 업데이트하는 과정.

</details>

```text
업무•LoRA 구성기
      │ 품질•메모리 조건 정의
      │ 1. 대상 선형층 선택
      ▼
기반 모델
      │ 2. 랭크•스케일•초기화 설정
      ▼
┌──────────── 학습 종료 전 반복 ────────────┐
│ 학습기                                    │
│   └ 3. 원본 동결•A•B 갱신                │
└───────────────────────────────────────────┘
      │ LoRA 어댑터 전달
      ▼
실행 관리자
      │ 병합•동적 적재 검증
      ▼
업무•LoRA 구성기
```

### 동작 원리

1. **대상 선형층 선택**: 변화가 필요한 투영 계층 지정
2. **랭크•스케일•초기화 설정**: 학습 조건 구성
3. **원본 동결•A•B 갱신**: 변화량 역전파 학습

#### 한줄 요약
- **대상 층•랭크 설정•변화량 학습** 수행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **전체 미세조정(Full Fine-Tuning, FFT)**: 모델 전체 가중치를 갱신하여 높은 적응력을 보이나, 비용이 매우 높은 튜닝 기법.
- **어댑터(Adapter)**: 모델 층 사이에 직렬 형태의 소형 모듈을 삽입하여 학습하는 방식.
- **LoRA 적용(LoRA Adaptation)**: 선형층과 병렬 구조로 저랭크 변화량 경로만을 학습하는 방식.

</details>

- 전체 가중치는 **Full FT**, 직렬은 Adapter, 변화량은 **LoRA**

| 구분 | 전체 미세조정 | Adapter | LoRA |
|:---|:---|:---|:---|
| 적용 기준 | **전체 적응** 필요 | 추가 **층 연산** 허용 | 선형층 **변화량 적응** |
| 핵심 특징 | 원본 가중치 **전체 갱신** | 직렬 **소형 모듈 삽입** | 병렬 **저랭크 변화량** |
| 한계 | **학습•저장 비용** | 순차 **추론 연산** | 랭크•**대상 층 선택** 필요 |

#### 한줄 요약
- **갱신 대상•추론 경로** 기반 튜닝 기법 구분

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **표현 용량 부족(Insufficient Expressive Capacity)**: 랭크값이 낮아 모델이 특정 과업의 복잡한 변화량을 충분히 반영하지 못하는 현상.
- **주입 제거 시험(Ablation Study)**: 특정 선형층에 대한 LoRA 주입 유무별 성능을 비교하여 최적의 위치를 식별하는 분석 기법.
- **병합 동등성(Merge Equivalence)**: LoRA 병합 여부에 따른 모델 출력 일치 여부.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 낮은 랭크의 **표현 용량 부족** | **랭크별 품질•학습 메모리 비교** | 최소 유효 **랭크 선택** |
| 대상 층 누락의 **과업 적응 실패** | **투영별 주입 제거 시험** | 유효 **주입 위치 식별** |
| 병합 전후의 **출력 불일치** | **동일 정밀도•병합 품질 회귀 시험** | 배포 경로의 **동등성 확보** |

#### 한줄 요약
- **학습 용량•주입 위치•병합 동등성** 검증

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **랭크 선택(Rank Selection)**: 과업 요구사항과 자원 제약을 고려하여 최적의 랭크를 결정하는 전략.
- **병합 방식(Merging Strategy)**: 정적 배포(통합 병합)와 동적 서비스(분리 운용)를 구분하는 관리 전략.

</details>

- 파라미터 효율적 미세조정(PEFT) 분야에서 가장 널리 활용되며 사실상의 표준 기술로 군림한 **LLM 도메인 특화 및 경량 어댑터 튜닝(Low-Rank Adaptation: LoRA / Low Intrinsic Dimension / Rank $r$ & Alpha $\alpha$ Scaling / Zero-Inference Latency Weight Merging / Multi-LoRA Batching)의 핵심 아키텍처**로 확고히 자리 잡았으며, DoRA(Weight-Decomposed LoRA), QLoRA, LongLoRA 등으로 급속히 확장되는 가운데, 실무 LoRA 파이프라인 구축 시에는 **과업 난이도에 따른 최적 랭크($r=8\sim64$) 및 스케일링 계수($\alpha=2r$) 튜닝, 어텐션 계층(Q/K/V/O)뿐 아니라 FFN 계층까지 전체 선형층에 적용(All-Linear LoRA)하여 학습 표현력 극대화, 단일 태스크 단독 배포 시에는 가중치 영구 병합(Fused Weight)을 적용하고 멀티 테넌트 서비스 시에는 동적 어댑터 스위칭 적용**을 결합하여 완벽한 적응 성능과 서빙 민첩성을 완성

#### 한줄 요약
- **변화량•학습 메모리•전환 빈도** 대상 따라 LoRA 구성 결정
