## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **저랭크 적응(Low-Rank Adaptation, LoRA)**: 기반 가중치를 동결하고 두 작은 행렬이 만드는 변화량만 학습하는 매개변수 효율적 파인튜닝 기법을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.
- **저랭크 행렬(Low-Rank Matrix)**: 큰 행렬의 변화를 더 작은 중간 차원을 가진 두 행렬의 곱으로 표현한 행렬을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.

</details>

- 정의/개념: **LoRA**는 동결 가중치에 더할 저랭크 변화량 $BA$만 학습하는 **PEFT** 기법임. 이는 전통적 방식과의 핵심 차별점으로서 실질적인 업무 가치를 창출함.
- 배경/필요성: 전체 가중치 갱신에 따른 메모리 부담 및 **과업별 모델 복제 비용** 발생하여 실무 환경에서의 유연한 대응과 지속적 최적화를 지원함.

#### 한줄 요약
- 동결 가중치에 **저랭크 변화량 BA**만 학습•결합한다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **동결 가중치(Frozen Weight, $W_0$)**: 학습 중 값을 유지하는 기반 선형 변환 행렬로 정의된다.
- **랭크(Rank, $r$)**: 두 작은 행렬 사이의 중간 차원으로 변화량의 표현 용량을 결정하는 파라미터를 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.
- **스케일 계수(Scaling Factor, $\alpha$)**: LoRA 변화량이 원본 출력에 반영되는 크기를 조절하는 역할을 나타낸다.

</details>

![LoRA 랭크별 학습 매개변수 증가](/study/diagrams/lora-rank-parameter-growth.svg)

> 랭크 증가(4→64)에도 LoRA 학습 매개변수량은 전체 가중치 대비 소량으로 선형 증가함 (이론값 기준).

- $W_0$ 동결과 $A•B$ 선택 갱신으로 **학습 상태를 축소**하여 실무 환경에서의 유연한 대응과 지속적 최적화를 지원함.
- $r$과 $\alpha/r$로 **적응 용량•반영 크기**를 조절하여 실무 환경에서의 유연한 대응과 지속적 최적화를 지원함.
- 대상 선형층과 병합 여부에 따른 **품질•추론 경로 결정**이 핵심임. 이는 전통적 방식과의 핵심 차별점으로서 실질적인 업무 가치를 창출함.

#### 한줄 요약
- **랭크•스케일•대상 층**으로 적응 용량을 조절한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **LoRA 변화량(LoRA Delta, $BA$)**: 학습 행렬 $B$와 $A$의 곱으로 만든 가중치 수정분을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.
- **대상 모듈(Target Module)**: 저랭크 적응 경로를 주입할 어텐션이나 순방향 신경망의 선형층 범위를 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.
- **어댑터 파일(Adapter File)**: 학습한 A•B 행렬과 구성을 기반 모델과 분리해 저장한 자산을 가리킨다.

</details>

- **LoRA 변화량**을 어텐션•FFN 대상 선형층에 주입하는 것이 핵심임. 이는 전통적 방식과의 핵심 차별점으로서 실질적인 업무 가치를 창출함.

```text
[동결 경로 W₀]---[저랭크 행렬 A,B]---[랭크•스케일]
        |                    |                  |
        +----------------[대상 모듈]-----------+
                             |
                       [어댑터 파일]
```

선의 의미: 랭크•스케일 설정에 의한 동결 경로 및 저랭크 행렬 조절과, 대상 모듈 및 어댑터 파일의 주입 위치 지정 및 분리 저장 경계 형성.

| 구성요소 | 책임 |
|:---|:---|
| 동결 경로 W₀ | 기반 선형 변환•**원본 능력 보존** |
| 저랭크 행렬 A,B | BA로 **가중치 변화량** 생성 |
| 랭크•스케일 | **r 용량•α/r 반영 크기** 조절 |
| 대상 모듈 | **LoRA 주입 선형층** 범위 지정 |
| 어댑터 파일 | **학습 행렬•구성** 분리 저장•병합 |

#### 한줄 요약
- **동결 경로•저랭크 행렬•랭크•모듈•파일**을 구성한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **초기화(Initialization)**: 학습 시작 시 LoRA 변화량이 원본 출력을 바꾸지 않도록 A•B 값을 설정하는 과정을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.
- **변화량 학습(Delta Training)**: 원본 가중치는 보존하고 A•B에만 그래디언트를 적용하는 과정으로 정의된다.

</details>

```text
업무•LoRA 구성기
      │ 품질•메모리 조건 정의
      │ 1. 대상 선형층 선택
      ▼
기반 모델
      │ 2. 랭크•스케일•초기화 설정
      ▼
┌──────────── 학습 종료 전 반복 ────────────┐
│ 학습기                                    │
│   └ 3. 원본 동결•A•B 갱신                │
└───────────────────────────────────────────┘
      │ LoRA 어댑터 전달
      ▼
실행 관리자
      │ 병합•동적 적재 검증
      ▼
업무•LoRA 구성기
```

**동작 원리**

1. **대상 선형층 선택**: 변화가 필요한 투영 계층에 **LoRA 경로**를 지정함.
2. **랭크•스케일•초기화 설정**: 표현 용량과 초기 출력 변화의 **학습 조건**을 구성함.
3. **원본 동결•A•B 갱신**: $W_0$를 보존하고 $A,B$만 역전파로 **변화량을 학습**함.

#### 한줄 요약
- **대상 층•랭크•A•B 갱신•병합 검증**을 수행한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **전체 미세조정(Full Fine-Tuning, FFT)**: 원본 가중치 전체를 갱신하여 적응 폭은 크지만 학습•저장 비용이 높은 기법을 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.
- **어댑터(Adapter)**: 모델 층 사이에 직렬 소형 모듈을 삽입하여 중간 표현을 조정하는 방식을 나타낸다.
- **LoRA 적용(LoRA Adaptation)**: 선형층과 병렬인 저랭크 변화량 경로만 학습하는 구조를 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.

</details>

- 원본 전체는 **Full FT**, 직렬 모듈은 **Adapter**, 변화량은 **LoRA**가 핵심임. 이는 전통적 방식과의 핵심 차별점으로서 실질적인 업무 가치를 창출함.

| 비교 기준 | 전체 미세조정 | Adapter | LoRA |
|:---|:---|:---|:---|
| 적용 기준 | **전체 적응** 필요 | 추가 **층 연산** 허용 | 선형층 **변화량 적응** |
| 핵심 특징 | 원본 가중치 **전체 갱신** | 직렬 **소형 모듈 삽입** | 병렬 **저랭크 변화량** |
| 한계 | **학습•저장 비용** | 순차 **추론 연산** | 랭크•**대상 층 선택** 필요 |

#### 한줄 요약
- **갱신 대상•추론 경로**로 Full FT•어댑터•저랭크 적응를 구분한다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **표현 용량 부족(Insufficient Expressive Capacity)**: 랭크가 너무 낮아 필요한 과업 변화량을 충분히 나타내지 못하는 현상을 가리킨다.
- **주입 제거 시험(Ablation Study)**: 특정 저랭크 적응 경로를 제외한 뒤 품질 변화를 측정하여 유효 주입 위치를 탐색하는 평가 방식을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.
- **병합 동등성(Merge Equivalence)**: LoRA를 원본에 합친 출력과 분리 실행 출력이 허용 오차 내에서 일치하는 성질을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 낮은 $r$의 **표현 용량 부족** | **랭크별 품질•학습 메모리 비교** | 최소 유효 **랭크 선택** |
| 대상 층 누락의 **과업 적응 실패** | **Q•K•V•O 투영별 주입 제거 시험** | 유효 **주입 위치 식별** |
| 병합 전후의 **출력 불일치** | **동일 정밀도•병합 품질 회귀 시험** | 배포 경로의 **동등성 확보** |

#### 한줄 요약
- **랭크•대상 층•병합 동등성**을 함께 검증한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **랭크 선택(Rank Selection)**: 과업 품질을 충족하는 최소 표현 용량과 학습 메모리를 비교하여 최적값을 정하는 과정을 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.
- **병합 방식(Merging Strategy)**: 고정 배포는 원본에 합치고 다중 업무 전환은 어댑터를 분리 적재하도록 정하는 관리 전략으로 정의된다.

</details>

- **과업 변화량•학습 메모리•배포 경로**로 LoRA 구성을 결정하여 실무 환경에서의 유연한 대응과 지속적 최적화를 지원함.

#### 한줄 요약
- **변화량•메모리•배포 경로**로 랭크•층•병합 방식을 선택한다. 체계 적용
