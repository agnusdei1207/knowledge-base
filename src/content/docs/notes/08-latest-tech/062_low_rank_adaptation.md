## 미리 알고가기

- **저랭크 적응(Low-Rank Adaptation, LoRA)**: '로라'로 읽고 가중치 변화량을 저랭크 행렬 곱으로 학습하는 방식을 표시
- **저랭크 행렬(Low-Rank Matrix)**: 큰 변화량을 두 작은 행렬의 곱으로 표현
- **랭크(Rank, $r$)**: '알'로 읽고 두 행렬 사이의 작은 중간 차원과 적응 용량을 표시
- **스케일 계수($\alpha$)**: '알파'로 읽는 그리스 문자이며 변화량 크기를 조절하는 계수를 표시
- **LoRA 식**: $h=W_0x+(\alpha/r)BAx$에서 $W_0$는 동결 가중치, $BA$는 학습 변화량


## Ⅰ. 개요

- **정의/개념**: 동결한 선형 가중치에 더할 **저랭크 변화량 $BA$만 학습하는 PEFT**
- **배경/필요성**: 전체 가중치 갱신의 **학습 메모리·저장·작업별 모델 복제 부담 절감**

### 쉽게 이해하기 (학습용)

- 큰 가중치 대신 두 작은 행렬의 곱으로 수정분을 만들어 원본에 더합니다.

## Ⅱ. 특징

- **$W_0$는 동결하고 $A·B$만 갱신**해 학습 매개변수와 상태를 줄인다.
- **$r$과 $\alpha/r$**로 변화량의 적응 용량과 반영 크기를 조절한다.
- **대상 선형층·초기화·병합 방식**이 품질과 추론 비용을 좌우한다.

### 쉽게 이해하기 (학습용)

- 수정분의 크기·세기·주입 층 위치에 따라 결과 품질이 달라집니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 동결 가중치 $W_0$ | **기반 선형 변환·갱신 제외** |
| 저랭크 행렬 $A,B$ | **$BA$로 가중치 변화량 생성** |
| 랭크·스케일 | **$r$ 용량·$\alpha/r$ 크기 조절** |
| 대상 모듈 | **LoRA 주입 선형층 지정** |
| 어댑터 파일 | **행렬·구성 저장·병합** |

```text
입력벡터 ─── 동결가중
        └── 저랭크행렬
               │
            출력합산
```

### 쉽게 이해하기 (학습용)

- 동결 원본과 저랭크 변화량을 합산하고 변화량만 학습합니다.

## Ⅳ. 원리 및 절차 흐름도

```text
요구 정의
↓
모듈 선정
↓
구성 주입
↓
행렬 학습
↓
배포 검증
```

| 절차 | 설명 |
|:---|:---|
| 요구 정의 | 품질·메모리·전환 조건 정의 |
| 모듈 선정 | LoRA 적용 선형층 선택 |
| 구성 주입 | 랭크·스케일·초기화 설정 |
| 행렬 학습 | 원본 동결·$A,B$만 갱신 |
| 배포 검증 | 병합·동적 적재·지연 검증 |

### 쉽게 이해하기 (학습용)

- 대상 층과 랭크를 정해 행렬만 학습하고 배포 방식을 검증합니다.

## Ⅴ. 종류 및 비교

| 가중치 적응 구조 | 전체 파인튜닝 | Adapter | LoRA |
|:---|:---|:---|:---|
| 적용 기준 | 전체 적응 필요 시 | 추가 층 연산 허용 시 | 선형층 병합 필요 시 |
| 핵심 특징 | 원본 가중치 전체 갱신 | 직렬 소형 모듈 삽입 | 병렬 저랭크 변화량 |
| 한계 | 학습·저장 비용 큼 | 순차 추론 연산 추가 | 랭크·대상 층 튜닝 필요 |

> 요약: 학습 방식별 비용과 구조를 비교함

### 쉽게 이해하기 (학습용)

- 전면 튜닝·어댑터·LoRA는 가중치 변화 구조가 다릅니다.

## Ⅵ. 실무 사례

1. 랭크·대상 층 조합은 **작업 품질·기존 능력 회귀 비교**
2. 병합·다중 적재는 **기반 버전·전환 지연·권한 검증**

### 쉽게 이해하기 (학습용)

- 행렬 크기뿐 아니라 대상 층과 서비스의 어댑터 전환 비용도 검증해야 합니다.

## Ⅶ. 결론

- LoRA 품질은 **랭크·스케일·대상 층·병합 조건**으로 결정

### 쉽게 이해하기 (학습용)

- 수정 경로의 위치·크기·병합 조건이 맞아야 원하는 품질과 운영 효과를 얻습니다.
