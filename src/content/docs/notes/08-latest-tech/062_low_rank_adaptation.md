## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **저랭크 적응(LoRA, Low-Rank Adaptation)**: 거대언어모델의 가중치를 고정하고, 별도의 저랭크 행렬을 삽입하여 적은 파라미터만 학습하는 효율적 미세조정 기법.
- **저랭크 행렬(Low-Rank Matrix)**: 큰 행렬의 변화량을 두 개의 작은 저랭크 행렬($A, B$)의 곱으로 근사하여 표현한 행렬.

</details>

- 정의/개념: 동결 가중치에 저랭크 변화량($\Delta W=BA$)만 학습하여 모델을 최적화하는 기법.
- 배경/필요성: 전체 파라미터 튜닝 시 메모리 부담과 과업별 모델 배포 비용을 최소화하기 위함.

#### 한줄 요약
- **저랭크 변화량(BA)** 학습 및 결합 체계 적용

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **동결 가중치(Frozen Weight, $W_0$)**: 학습 중 업데이트 없이 고정된 기반 선형 변환 행렬.
- **랭크(Rank, $r$)**: 학습 행렬의 차원을 결정하여 변화량의 표현 용량을 제한하는 파라미터.
- **스케일 계수(Scaling Factor, $\alpha$)**: LoRA 변화량이 원본 가중치에 반영되는 비율을 조절하는 하이퍼파라미터.

</details>

![LoRA 랭크별 학습 매개변수 증가](/study/diagrams/lora-rank-parameter-growth.svg)

> 랭크 증가(4→64)에도 LoRA 학습 매개변수량은 전체 가중치 대비 소량으로 선형 증가함 (이론값 기준).

- $W_0$ 동결 및 $BA$ 선택 갱신으로 학습 파라미터 수를 획기적으로 축소.
- $r$ 및 $\alpha/r$ 조절을 통해 적응 용량 및 출력 반영 크기 최적화.
- 선형층별 병합 및 분리 배포를 통한 고품질 추론 경로 확보.

#### 한줄 요약
- **랭크 및 스케일**을 통한 적응 용량 조절 원칙 준수

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **LoRA 변화량(LoRA Delta, $BA$)**: 모델 가중치 수정분을 생성하는 저랭크 행렬 곱($BA$) 결과값.
- **대상 모듈(Target Module)**: 저랭크 적응 경로가 주입되는 어텐션 또는 FFN 선형층.
- **어댑터 파일(Adapter File)**: 학습된 저랭크 행렬 및 설정을 기반 모델과 분리하여 저장한 파일.

</details>

- **LoRA 변화량**을 어텐션•FFN 대상 선형층에 주입하는 것이 핵심임. 이는 전통적 방식과의 핵심 차별점으로서 실질적인 업무 가치를 창출함.

```text
[동결 경로 W₀]---[저랭크 행렬 A,B]---[랭크•스케일]
        |                    |                  |
        +----------------[대상 모듈]-----------+
                             |
                       [어댑터 파일]
```

선의 의미: 랭크•스케일 설정에 의한 동결 경로 및 저랭크 행렬 조절과, 대상 모듈 및 어댑터 파일의 주입 위치 지정 및 분리 저장 경계 형성.

| 구성요소 | 책임 |
|:---|:---|
| 동결 경로 W₀ | 기반 선형 변환•**원본 능력 보존** |
| 저랭크 행렬 A,B | BA로 **가중치 변화량** 생성 |
| 랭크•스케일 | **r 용량•α/r 반영 크기** 조절 |
| 대상 모듈 | **LoRA 주입 선형층** 범위 지정 |
| 어댑터 파일 | **학습 행렬•구성** 분리 저장•병합 |

#### 한줄 요약
- **동결 경로 및 저랭크 행렬** 구성 원칙 준수

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **초기화(Initialization)**: 학습 초기 LoRA 출력값이 원본 모델에 영향을 주지 않도록 행렬 값($A$는 가우시안, $B$는 0)을 설정하는 과정.
- **변화량 학습(Delta Training)**: 원본 가중치는 고정한 채, 행렬 $A, B$의 그래디언트만을 계산하여 업데이트하는 과정.

</details>

```text
업무•LoRA 구성기
      │ 품질•메모리 조건 정의
      │ 1. 대상 선형층 선택
      ▼
기반 모델
      │ 2. 랭크•스케일•초기화 설정
      ▼
┌──────────── 학습 종료 전 반복 ────────────┐
│ 학습기                                    │
│   └ 3. 원본 동결•A•B 갱신                │
└───────────────────────────────────────────┘
      │ LoRA 어댑터 전달
      ▼
실행 관리자
      │ 병합•동적 적재 검증
      ▼
업무•LoRA 구성기
```

**동작 원리**

1. **대상 선형층 선택**: 변화가 필요한 투영 계층에 **LoRA 경로**를 지정함.
2. **랭크•스케일•초기화 설정**: 표현 용량과 초기 출력 변화의 **학습 조건**을 구성함.
3. **원본 동결•A•B 갱신**: $W_0$를 보존하고 $A,B$만 역전파로 **변화량을 학습**함.

#### 한줄 요약
- **대상 층 설정 및 학습** 공정 준수

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **전체 미세조정(Full Fine-Tuning, FFT)**: 모델 전체 가중치를 갱신하여 높은 적응력을 보이나, 비용이 매우 높은 튜닝 기법.
- **어댑터(Adapter)**: 모델 층 사이에 직렬 형태의 소형 모듈을 삽입하여 학습하는 방식.
- **LoRA 적용(LoRA Adaptation)**: 선형층과 병렬 구조로 저랭크 변화량 경로만을 학습하는 방식.

</details>

- 원본 전체는 **Full FT**, 직렬 모듈은 **Adapter**, 변화량은 **LoRA**가 핵심임. 이는 전통적 방식과의 핵심 차별점으로서 실질적인 업무 가치를 창출함.

| 비교 기준 | 전체 미세조정 | Adapter | LoRA |
|:---|:---|:---|:---|
| 적용 기준 | **전체 적응** 필요 | 추가 **층 연산** 허용 | 선형층 **변화량 적응** |
| 핵심 특징 | 원본 가중치 **전체 갱신** | 직렬 **소형 모듈 삽입** | 병렬 **저랭크 변화량** |
| 한계 | **학습•저장 비용** | 순차 **추론 연산** | 랭크•**대상 층 선택** 필요 |

#### 한줄 요약
- **갱신 대상별 튜닝 기법** 구분 준수

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **표현 용량 부족(Insufficient Expressive Capacity)**: 랭크값이 낮아 모델이 특정 과업의 복잡한 변화량을 충분히 반영하지 못하는 현상.
- **주입 제거 시험(Ablation Study)**: 특정 선형층에 대한 LoRA 주입 유무별 성능을 비교하여 최적의 위치를 식별하는 분석 기법.
- **병합 동등성(Merge Equivalence)**: LoRA 병합 여부에 따른 모델 출력 일치 여부.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 낮은 $r$의 **표현 용량 부족** | **랭크별 품질•학습 메모리 비교** | 최소 유효 **랭크 선택** |
| 대상 층 누락의 **과업 적응 실패** | **Q•K•V•O 투영별 주입 제거 시험** | 유효 **주입 위치 식별** |
| 병합 전후의 **출력 불일치** | **동일 정밀도•병합 품질 회귀 시험** | 배포 경로의 **동등성 확보** |

#### 한줄 요약
- **학습 용량 및 병합 무결성** 검증 체계 적용

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **랭크 선택(Rank Selection)**: 과업 요구사항과 자원 제약을 고려하여 최적의 랭크를 결정하는 전략.
- **병합 방식(Merging Strategy)**: 정적 배포(통합 병합)와 동적 서비스(분리 운용)를 구분하는 관리 전략.

</details>

- **과업 변화량•학습 메모리•배포 경로**로 LoRA 구성을 결정하여 실무 환경에서의 유연한 대응과 지속적 최적화를 지원함.

#### 한줄 요약
- **변화량 및 병합 경로** 최적화 LoRA 구현 필수
