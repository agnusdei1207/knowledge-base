## 미리 알고가기

- **샤플리 가산 설명(SHapley Additive exPlanations, SHAP)**: 이름과 핵심 글자를 조합한 표기로 “샵”으로 읽으며, 예측과 기준값의 차이를 특징별 샤플리 기여도로 배분하는 기법
- **개별 예측 설명**: 개별 예측과 전체 모델 해석을 지원함
- **변수 수**: 변수 증가 시 계산 비용 급증으로 Explainer 선택 필요



## Ⅰ. 개요

- 정의/개념: 예측과 기준의 차이를 특징별 기여도로 분해
- 기존 한계: 단순 특징 중요도만으로는 상호작용하는 특징들의 예측 기여도를 일관된 기준으로 배분하기 어렵다.

### 쉽게 이해하기 (학습용)

- 특징별 기여도를 합해 예측값과 기준값의 차이를 설명합니다.

## Ⅱ. 특징

- 특징 순서별 한계 기여의 **샤플리 평균**
- 기준값과 특징 기여도의 **가산 일관성**
- 배경분포·상관 특징에 따른 **기여도 민감성**

### 쉽게 이해하기 (학습용)

- 특징의 몫을 더하면 예측과 기준의 차이가 되지만 기준 집단과 상관 특징 처리 방식에 따라 몫이 달라집니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 모델 출력 함수 | 연합별 모델 예측값 계산 |
| 배경분포·마스커 | 기준 데이터 샘플링·대체 |
| 특징 연합 가치 | 특징 집합별 모델 기대 출력 |
| SHAP 계산기 | 평균 한계 기여도 산출 구현 |
| 기준값·기여도 | 특징별 기여 분해 결과 |

```text
[모델 출력 함수] ─────┐
[배경분포·마스커] ────┴─ [특징 연합 가치]
                              │
                       [SHAP 계산기]
                              │
                       [기준값·기여도]
```

### 쉽게 이해하기 (학습용)
- 모델·배경분포·특징 연합·계산기가 기준값과 특징별 기여도를 산출합니다.

## Ⅳ. 원리 및 절차

```text
배경선택 → 연합구성 → 출력산출 → 한계기여 → 결과검증
```

| 절차 | 설명 |
|:---|:---|
| 배경선택 | 기준 표본과 특징 개입 규칙 설정함 |
| 연합구성 | 마스킹을 통한 특징 조합 생성함 |
| 출력산출 | 연합별 모델 출력 차이 도출함 |
| 한계기여 | 연합 크기별 가중치 적용 평균화함 |
| 결과검증 | 가산성과 배경 민감도 확인 수행함 |

### 쉽게 이해하기 (학습용)

- 비교 기준을 정하고 특징 조합의 출력 차이로 평균 몫을 구한 뒤 합이 실제 예측과 맞는지 확인합니다.

## Ⅴ. SHAP 계산 방식 비교

| 구분 | Kernel SHAP | Tree SHAP | Deep SHAP |
|:---|:---|:---|:---|
| 적용 기준 | 모델 비종속 설명 | 트리 모델 설명 | 심층 모델 근사 설명 |
| 핵심 특징 | 샘플링 기반 기여 근사 | 트리 구조 기반 효율 계산 | 기준 활성값 기반 역전파 |
| 한계 | 높은 계산량·분산 | 트리 모델에 한정 | 근사 가정·기준값 민감 |

> 요약: 모델 구조별 최적 계산기를 선택하여 특징 기여도를 도출함

### 쉽게 이해하기 (학습용)

- 범용 표본 근사, 트리 전용 계산, 신경망 근사 중 모델 구조와 허용 시간에 맞는 방법을 고릅니다.

## Ⅵ. 실무 사례

- 사기 탐지는 배경 기간별 SHAP 변화를 비교한다.

### 쉽게 이해하기 (학습용)

- 두 특징이 함께 움직이면 몫이 가정에 따라 달라지므로 기준 집단과 의존성 가정을 함께 보여 줍니다.

## Ⅶ. 결론

- 개별 예측에 대한 특징별 기여도를 일관된 기준으로 설명하기 위해 **배경 데이터·특징 의존성·계산 비용·설명 안정성**을 검토하고, 가정을 명시해 SHAP을 활용해야 한다.

### 쉽게 이해하기 (학습용)

- 특징별 몫은 유용하지만 기준 집단과 특징 의존성 가정을 숨기면 같은 예측도 다르게 설명될 수 있습니다.
