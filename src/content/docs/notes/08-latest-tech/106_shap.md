## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **샤플리 가산 설명(SHapley Additive exPlanations, SHAP)**: 기준 예측과 개별 예측의 차이를 샤플리 값으로 특징별 기여도에 가산 분해하는 설명 기법이다.
- **샤플리 값**: 특징이 여러 연합에 참여하는 모든 순서에서 만든 한계 기여를 가중 평균한 값이다.

</details>

- 정의/개념: 기준값과 개별 예측의 차이를 특징별 샤플리 값으로 가산 분해하는 **샤플리 가산 설명(SHapley Additive exPlanations, SHAP) 기법**
- 배경/필요성: 단순 중요도는 상호작용 특징의 **개별 예측 기여도 배분 기준 부족**

#### 한줄 요약
- 기준값과 예측값의 차이를 특징별 기여도의 합으로 설명한다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **샤플리 공정 배분**: 특징이 예측에 기여한 몫을 대칭성•효율성 등의 원칙에 따라 나누는 방식이다.
- **가산 완전성**: 기준값에 모든 특징 기여도를 더하면 실제 예측값과 일치하는 성질이다.
- **배경 분포**: 특징이 없는 상태의 기대 출력과 대체 값을 정하는 기준 데이터 분포이다.

</details>

![SHAP 특징 기여의 가산 원리](/study/diagrams/shap-additive-contribution.svg)

> 파란 양의 기여와 붉은 음의 기여를 기준값 0.42에 순서대로 합하면 예측값 0.64에 도달하며, 실제 모델 측정값이 아닌 가산 원리 설명용 예시다.

- 모든 특징 순서의 한계 기여를 평균한 **샤플리 공정 배분**
- `예측값 = 기준값 + 기여도 합`의 **가산 완전성**
- 배경 분포•상관 특징 가정에 따른 **설명 민감성**

#### 한줄 요약
- 특징 기여도의 합은 예측 차이와 일치하지만 배경 분포에 따라 각 몫은 달라진다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **특징 연합**: 특정 예측에서 함께 존재한다고 가정한 특징의 부분집합이다.
- **마스커**: 연합에 포함되지 않은 특징을 배경값으로 대체하는 구성요소이다.
- **한계 기여**: 특징 하나를 연합에 추가하기 전과 후의 모델 출력 차이이다.

</details>

샤플리 가산 설명(SHapley Additive exPlanations, SHAP)의 계산 요소: **특징 연합•마스커•한계 기여**

```mermaid
block-beta
    columns 3
    M["모델 출력기"]
    B["배경 분포•마스커"]
    C["연합 가치 계산기"]
    S["SHAP 계산기"]
    R["설명 결과 저장소"]
    M --- B
    B --- C
    C --- S
    S --- R
```

| 구성요소 | 책임 |
|:---|:---|
| 모델 출력기 | 특징 연합별 **예측값 계산** |
| 배경 분포•마스커 | 제외 특징의 **기준값 대체** |
| 연합 가치 계산기 | 특징 집합별 **기대 출력 산출** |
| SHAP 계산기 | 가중 평균 기반 **한계 기여 배분** |
| 설명 결과 저장소 | 기준값•특징별 기여도의 **가산 결과 보관** |

#### 한줄 요약
- 특징 연합별 예측 차이를 모아 각 특징의 기여도를 계산한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **연합 가치**: 특정 특징 연합이 주어졌을 때 모델이 만드는 기대 출력이다.
- **부분집합**: 전체 특징 가운데 일부를 포함하도록 구성한 특징의 집합이다.

</details>

샤플리 가산 설명(SHapley Additive exPlanations, SHAP)은 부분집합별 연합 가치를 이용해 특징 추가 전후의 출력 차이를 집계한다.

```mermaid
sequenceDiagram
    participant B as 설명 설정•배경 마스커
    participant C as 연합 계산기
    participant M as 모델 출력기
    participant S as SHAP 계산기
    B->>B: 설명 대상•배경 설정
    B->>C: 1. 특징 연합 구성
    C->>M: 2. 연합별 출력 요청
    M-->>C: 3. 연합별 예측값 전달
    C->>S: 4. 연합 가치 전달
    S-->>B: 특징 기여도•검증 결과
```

1. **특징 연합 구성**: 설명 대상 특징의 포함•제외 **부분집합** 생성
2. **연합별 출력 요청**: 각 특징 조합의 **모델 예측** 요청
3. **연합별 예측값 전달**: **조합별 예측값의 연합 계산기 반환**
4. **연합 가치 전달**: 특징 추가 전후의 **출력 차이** 전달

#### 한줄 요약
- 배경 집단에서 특징 추가 전후의 점수 차이를 평균하고 합계를 검증한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **커널 샤플리 가산 설명(Kernel SHapley Additive exPlanations, Kernel SHAP)**: 모델 구조를 사용하지 않고 특징 연합을 표본 추출해 기여도를 근사하는 방식이다.
- **트리 샤플리 가산 설명(Tree SHapley Additive exPlanations, Tree SHAP)**: 결정 트리의 분기 구조를 이용해 특징 기여도를 효율적으로 계산하는 방식이다.
- **심층 샤플리 가산 설명(Deep SHapley Additive exPlanations, Deep SHAP)**: 신경망의 기준 내부 출력과 역전파 규칙으로 특징 기여도를 근사하는 방식이다.

</details>

샤플리 가산 설명(SHapley Additive exPlanations, SHAP)은 모델 구조에 따라 Kernel SHAP, Tree SHAP, Deep SHAP 계산 방식을 선택한다.

| 비교 기준 | Kernel SHAP | Tree SHAP | Deep SHAP |
|:---|:---|:---|:---|
| 적용 기준 | 모델 비종속 설명 | 트리 모델 설명 | 심층 모델 근사 설명 |
| 핵심 특징 | 표본 추출 기반 **기여도 근사** | 트리 구조 기반 **효율 계산** | 기준 내부 출력 기반 **역전파 근사** |
| 한계 | 높은 계산량•분산 | 트리 모델 한정 | 근사 가정•기준값 민감 |

#### 한줄 요약
- 모델 구조와 계산 시간에 맞춰 커널•트리•심층 방식을 선택한다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **기준 왜곡**: 대표성 없는 배경 분포 때문에 특징 기여도의 비교 기준이 실제 운영 집단과 어긋나는 문제이다.
- **기여도 분산**: 상관된 특징 사이에서 기여 몫이 마스킹 가정에 따라 임의로 나뉘는 문제이다.
- **조합 계산 폭증**: 특징 수가 늘면서 평가해야 할 연합의 수가 지수적으로 증가하는 문제이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 대표성 없는 **배경 분포의 기준 왜곡** | 운영 집단별 배경 표본•기준값 비교 | 기여도 기준의 **타당성 확보** |
| 상관 특징의 **기여도 임의 분산** | 조건부•독립 마스킹 가정별 민감도 분석 | 의존성 가정의 **영향 공개** |
| 커널 샤플리 가산 설명(Kernel SHapley Additive exPlanations, Kernel SHAP)의 **조합 계산 폭증** | 모델 구조별 전용 계산기•표본 오차 시험 | 계산 시간 단축과 **근사 오차 관리** |

#### 한줄 요약
- 배경 집단과 상관 특징 가정에 따른 기여도 변화를 공개한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **해석 범위**: 배경 집단•모델 구조•특징 의존성 가정 안에서 SHAP 설명이 유효한 영역이다.
- **배경 대표성**: 기준 데이터가 실제 설명 대상 집단과 운영 분포를 적절히 반영하는 정도이다.

</details>

- 선택 기준: 모델 구조•배경 대표성, 계산기: **샤플리 가산 설명(SHapley Additive exPlanations, SHAP)**, 제한 대상: **해석 범위**

#### 한줄 요약
- 특징 기여도와 함께 계산 방식•배경 집단•상관 특징 가정을 공개한다.
