## 미리 알고가기

- **검색 증강 생성(Retrieval-Augmented Generation, RAG)**: 외부 지식에서 검색한 근거를 모델 문맥에 결합해 답변하는 기법
- **리트리버 (Retriever)**: 질의와 관련된 문서 조각을 검색함
- **문서 분할 (Chunking)**: 원문을 의미 단위로 분할함
- **하이브리드 검색 (Hybrid Search)**: 의미 기반 검색과 키워드 검색을 결합함
- **생성 모델 (Generative Model)**: 검색 근거를 바탕으로 답변을 작성함



## Ⅰ. 개요

- 정의/개념: 외부 문서를 검색해 근거 문맥으로 답변 생성
- 기존 한계: 모델 가중치만으로 최신·사내 지식과 출처 제공 곤란
- 기존 한계: LLM의 내부 지식만으로는 최신·전문 정보를 반영하거나 답변의 근거를 제시하기 어렵고 갱신마다 재학습이 필요하다.

### 쉽게 이해하기 (학습용)

- 질문과 관련된 자료를 먼저 찾아 펼쳐 놓고 답하는 오픈북 방식입니다.

## Ⅱ. 특징

- 문서 색인 갱신으로 모델 재학습 없이 근거를 변경한다.
- 검색기는 관련 근거를 찾고 생성기는 근거 기반 답을 작성한다.
- 검색 관련성과 답변의 근거 충실성을 분리 평가한다.

### 쉽게 이해하기 (학습용)

- 지식은 문서 교체로 갱신하지만 검색 성공과 근거 충실성은 따로 확인합니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 문서 수집 | 원문·시각·권한 관리 |
| 색인 생성 | 청크의 벡터·키워드 추출 |
| 검색 필터 | 질의·조건에 맞는 후보 조회 |
| 재순위화 | 근거 사용 적합도 평가 |
| 생성 인용 | 근거로 답변·출처 생성 |

지식 저장
├─ 문서 수집
├─ 청크 색인
└─ 질의 처리
    ├─ 검색 순위
    └─ 근거 생성

### 쉽게 이해하기 (학습용)

- 문서의 권한과 버전을 색인하고 검색한 근거와 출처로 답변합니다.

## Ⅳ. 원리 및 절차 흐름도

문서 수집
↓
청크 색인
↓
후보 검색
↓
근거 선별
↓
답변 생성

| 절차 | 설명 |
|:---|:---|
| 문서 수집 | 버전·권한 등 속성 확인 |
| 색인 생성 | 문서 분할 및 벡터 변환 |
| 후보 검색 | 질의·권한에 맞는 조회 |
| 근거 선별 | 근거 순위 재평가 |
| 답변 생성 | 근거 기반 답변·출처 생성 |

### 쉽게 이해하기 (학습용)

- 청크를 검색·선별한 뒤 근거와 출처를 붙여 답변합니다.

## Ⅴ. 종류 및 비교

| 판단 기준 | 프롬프트 전용 생성 | 미세조정 | 검색 증강 생성 (RAG) |
|:---|:---|:---|:---|
| 적용 기준 | 검색 불필요 시 | 행동 패턴 변경 시 | 근거·최신성 필요 시 |
| 핵심 특징 | 모델 지식으로 직접 생성 | 가중치에 행동·패턴 학습 | 외부 지식 문맥 제공 |
| 한계 | 최신성·출처 관리 부족 | 변경 시 재학습 필요 | 검색 실패·근거 불충실 |

### 쉽게 이해하기 (학습용)

- 프롬프트·미세조정·RAG는 지식을 반영하는 방식이 다릅니다.

## Ⅵ. 실무 사례

- 규정 질의는 권한과 시행일로 필터링하고 답변에 근거 표시함

### 쉽게 이해하기 (학습용)

- 사용자가 볼 수 있는 최신 규정만 찾고 검색 실패와 생성 오류를 분리합니다.

## Ⅶ. 결론

- 지식 최신성 확보를 위해 권한·충실성을 검토하여 **RAG** 활용

### 쉽게 이해하기 (학습용)

- 올바른 자료를 안전하게 찾았는지와 근거대로 답했는지를 각각 검증해야 합니다.
