## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **검색 증강 생성(Retrieval-Augmented Generation, RAG)**: 외부 지식에서 검색한 근거를 모델 문맥에 결합해 답변을 생성하는 기법.

</details>

- 정의/개념: 외부 문서를 검색해 근거로 답변하는 **RAG**
- 배경/필요성: 사전학습된 거대 언어 모델(LLM)의 매개변수 지식(Parametric Memory)은 학습 컷오프 시점 이후의 최신 정보 부재, 기업 내부 비공개 데이터에 대한 접근 불가, 그리고 사실과 다른 그럴듯한 거짓말을 생성하는 환각(Hallucination) 현상이라는 근본적 한계를 내포하고 있음에 따라, 사용자 질의에 맞춰 외부 지식 베이스(Vector DB, 검색 엔진, 문서 저장소)로부터 관련 문서를 실시간 검색(Retrieve)하고 이를 LLM의 프롬프트 문맥(Context)에 주입하여 답변을 생성(Generate)하는 검색 증강 생성(RAG: Retrieval-Augmented Generation / Hybrid Search, Reranking, Vector DB, Chunking) 아키텍처를 도입하여 **고비용의 모델 재학습(Fine-Tuning) 없이도 최신 기업 내부 데이터 기반의 정확하고 전문적인 답변 생성, 인용 출처(Source Citation) 제공을 통한 답변 투명성 및 검증 가능성 확보, 사용자 및 부서별 보안/권한 필터링(Access Control)을 통한 안전한 엔터프라이즈 AI 서비스 구현**을 달성할 필요

#### 한줄 요약
- **오픈북 방식**은 지식 갱신을 재학습에서 색인 갱신으로 옮기는 대신 검색이 틀리면 근거까지 틀린 채 답이 나오므로, 품질의 상한은 생성기가 아니라 검색기가 정한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **문서 색인**: 검색할 문서와 위치 정보를 질의에 맞게 조회하도록 구성한 자료 구조.
- **충실성**: 생성한 답변이 제공된 근거의 내용과 일치하는 정도.

</details>

- **문서 색인 갱신**: 모델 재학습 없이 근거 변경
- **검색•생성 책임 분리**: 근거 탐색과 답변 작성 구분
- **관련성•충실성 평가**: 검색과 생성 품질 분리 판정

#### 한줄 요약
- 지식은 문서로 갱신하고 **검색 성공•근거 충실성** 분리 검증

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **검색기(Retriever)**: 질의와 접근 권한으로 관련 문서 조각을 찾는 구성요소이다.
- **문서 저장소•색인**: 원문•메타데이터•권한과 희소•밀집 검색 구조를 연결해 검색 후보를 제공하는 구성요소.
- **재순위기(Reranker)**: 검색 후보와 질의의 적합성을 다시 평가해 근거의 순서를 조정한다.
- **생성기**: 선별된 근거를 문맥으로 사용해 답변과 출처를 작성한다.

</details>

```text
                         [검색기]
                        /       \
                [하이브리드 색인] [재순위기]
                        |           |
                   [문서 저장소]  [생성기]
```

선의 의미: 검색기는 문서 저장소를 기반으로 한 하이브리드 색인에서 후보를 조회하고, 재순위기는 검색 후보를 생성기에 제공할 근거 집합으로 정제한다.

| 구성요소 | 책임 |
|:---|:---|
| 문서 저장소 | **원문•버전•권한** 관리 |
| 하이브리드 색인 | **벡터•키워드 색인** 관리 |
| 검색기 | **질의•권한 조건** 후보 조회 |
| 재순위기 | 후보의 **질의 적합도** 재평가 |
| 생성기 | 선별 근거로 **답변**•**출처** 생성 |

#### 한줄 요약
- **저장소•색인•검색•재순위•생성** 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **후보 청크**: 질의와 관련될 가능성이 있어 검색기가 우선 반환한 문서 조각.
- **근거 문맥**: 생성기가 답변을 작성할 때 사실의 범위와 출처로 사용하는 선별 문서.

</details>

```text
사용자 ── 질의•권한 조건 ──▶ 검색기
                              │ 1. 후보 청크 제공
                              ▼
                           재순위기
                              │ 2. 상위 근거 문맥 전달
                              ▼
                            생성기
                              │ 3. 근거 기반 답변 생성
사용자 ◀── 근거•출처 답변 ───┘
```

### 동작 원리

1. **후보 청크 제공**: 관련 문서 조각 검색
2. **상위 근거 문맥 전달**: 재순위 점수로 근거 선별
3. **근거 기반 답변 생성**: 사실과 출처 결합

#### 한줄 요약
- 청크 검색•선별 후 **근거**•**출처** 결합 답변

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **프롬프트 전용 생성**: 별도 검색 없이 입력 문맥과 모델 내부 지식만으로 답변을 생성하는 방식.
- **미세조정**: 특정 데이터의 행동과 출력 패턴을 모델 가중치에 학습시키는 방식이다.

</details>

| 지식 반영 방식 | 검색 증강 생성 | 프롬프트 전용 생성 | 미세조정 |
|:---|:---|:---|:---|
| 적용 기준 | 최신 **근거**•**출처** 필요 | **내부 지식만으로 충분** | 행동•출력 **패턴 내재화** |
| 핵심 특징 | 외부 **지식 문맥** 제공 | 입력 **지시로 생성** | 가중치에 **행동 패턴** 학습 |
| 한계 | 검색 실패•**근거 불충실** | 최신성•**출처 관리 부족** | 지식 변경 시 **재학습** |

#### 한줄 요약
- **근거 최신성•행동 내재화** 대상 따라 지식 반영 방식 구분

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **검색 실패**: 필요한 근거가 색인에 없거나 순위 밖으로 밀리는 문제이다.
- **근거 불충실성**: 생성 답변이 검색 근거를 벗어나거나 모순되는 문제이다.
- **권한 필터**: 사용자별 접근 권한에 따라 검색 가능한 문서를 제한하는 통제 장치.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 청크 분할•검색 실패에 따른 근거 누락 | **하이브리드 검색•재순위** 평가 | **검색 관련성** 향상 |
| 검색 문맥 밖 생성으로 **근거 불충실성** 발생 | 인용 검증•근거 없음 응답 정책 | **답변 충실성** 확보 |
| 권한 없는 청크 검색으로 **정보 노출** | 색인•검색 단계의 권한 필터 | 사용자별 **근거 접근 통제** |

#### 한줄 요약
- **권한 필터•검색 실패•근거 오류** 분리 통제

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **검색 포괄성**: 답변에 필요한 근거를 검색 후보에 포함하는 정도이다.
- **근거 충실성**: 최종 답변이 검색 근거에 의해 직접 뒷받침되는 정도.

</details>

- 생성형 AI를 엔터프라이즈 지식 관리 및 비즈니스 워크플로우에 성공적으로 안착시킨 **가장 실용적이고 필수적인 기업용 LLM 아키텍처(Retrieval-Augmented Generation: RAG / Hybrid Search: BM25 + Vector / Neural Reranker: Cross-Encoder / Chunking & Metadata Filtering / Context-Aware Generation / Agentic & Graph RAG Extensions)의 절대적 표준**으로 확고히 자리 잡았으며, Agentic RAG 및 Graph RAG와 같은 다단계 추론 체계로 급속히 진화하는 가운데, 실무 RAG 시스템 구축 시에는 **키워드와 의미론을 결합한 하이브리드 검색 및 Cross-Encoder 재순위화(Reranking) 파이프라인으로 검색 정확도 극대화, 기업 내 사용자별 권한(ACL) 메타데이터 필터링을 통한 보안 정보 노출 차단, Ragas/TruLens 기반의 검색 관련성(Context Relevance) 및 답변 충실성(Faithfulness) 지속 평가**를 결합하여 완벽한 신뢰성과 최상의 엔터프라이즈 생산성을 완성

#### 한줄 요약
- **최신성•출처•행동 내재화** 대상 따라 지식 반영 방식 결정
