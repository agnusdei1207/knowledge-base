## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **보안 집계**: 서버가 참여자별 학습 업데이트를 알지 못한 채 허용된 참여자의 합계만 복구하는 프로토콜이다.
- **업데이트 기밀성**: 집계 과정에서 서버나 다른 참여자가 개별 로컬 변화량을 알 수 없도록 하는 성질이다.

</details>

- 정의/개념: **보안 집계(Secure Aggregation)** 는 연합학습의 개별 업데이트를 숨기고 참여자 합계만 복구하는 프로토콜
- 배경/필요성: 집계 서버가 개별 업데이트를 보면 **참여자 데이터 특성•민감정보 추론** 가능

#### 한줄 요약
- 참여자들이 서로 지워지는 가림막을 값에 씌워 보내면 서버에는 가림막이 사라진 전체 합만 남음

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **쌍별 마스크**: 두 참여자가 공유해 한쪽은 더하고 다른 쪽은 빼므로 전체 합에서 상쇄되는 난수값이다.
- **비밀 분산**: 하나의 비밀을 여러 조각으로 나누고 임계 개수 이상을 모을 때만 복구하는 기법이다.
- **공모 임계값**: 서버와 일부 참여자가 결탁해도 개별 업데이트 기밀성을 유지할 수 있는 최대 공모 범위이다.

</details>

- 생존 참여자의 합에서 상쇄되는 **쌍별 마스크**
- 비밀 분산 기반 **이탈 참여자 마스크 복구**
- 최소 생존자•공모 임계값 기반 **합계 공개 경계**

#### 한줄 요약
- 모두가 보낸 가림막은 합에서 지워지고 중간에 빠진 사람의 가림막만 비밀 조각으로 제거함

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **업데이트 마스커**: 로컬 변화량에 상쇄 난수를 더해 서버가 개별값을 읽지 못하도록 한다.
- **이탈 복구기**: 생존 참여자의 비밀 조각으로 이탈자가 남긴 마스크를 제거한다.
- **생존 임계값**: 합계를 안전하게 복구하기 위해 업데이트와 복구 자료를 제출해야 하는 최소 참여자 수이다.

</details>

```mermaid
block-beta
    columns 3
    P["참여자 집합"]
    K["키•비밀 분산기"]
    M["업데이트 마스커"]
    S["집계 서버"]
    R["이탈 복구기"]
    P --- K
    K --- M
    M --- S
    S --- R
```

| 구성요소 | 책임 |
|:---|:---|
| 참여자 집합 | 로컬 업데이트와 **생존•이탈 상태 제공** |
| 키•비밀 분산기 | 쌍별 마스크와 **복구 조각 생성•배포** |
| 업데이트 마스커 | 로컬 업데이트에 **상쇄 난수 추가** |
| 집계 서버 | 마스킹 업데이트의 **허용 합계 계산** |
| 이탈 복구기 | 생존 임계값 확인과 **잔여 마스크 제거** |

#### 한줄 요약
- 참여자가 가림막과 복구 조각을 나누고 서버는 이탈자를 확인한 뒤 합계에 남은 가림막만 제거함

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **참여자 이탈**: 프로토콜 도중 통신 장애•종료로 업데이트나 마스크 해제 자료를 제출하지 못한 상태이다.
- **복구 합계**: 상쇄와 이탈 복구로 잔여 마스크를 제거해 얻은 허용 참여자의 집계값이다.

</details>

```mermaid
sequenceDiagram
    participant P as 참여자
    participant K as 키•비밀 분산기
    participant M as 업데이트 마스커
    participant S as 집계•이탈 복구 서버
    P->>K: 1. 참여자 공개키 전달
    K->>M: 2. 비밀 조각•마스크 재료 전달
    M->>S: 3. 마스킹 업데이트 전달
    S->>S: 4. 생존•이탈 목록 확인
    S->>S: 5. 복구 합계 계산
```

1. **참여자 공개키 전달**: 라운드 참여자의 **쌍별 비밀** 설정 자료 제공
2. **비밀 조각•마스크 재료 전달**: 이탈 복구용 조각과 **상쇄 마스크** 제공
3. **마스킹 업데이트 전달**: 로컬 변화량에 마스크를 더한 **은닉 값** 전송
4. **생존•이탈 목록 확인**: 업로드 상태와 최소 참여 수의 **복구 조건** 확인
5. **복구 합계 계산**: 상쇄•복구로 잔여 마스크를 제거한 **집계값** 계산

#### 한줄 요약
- 가림막을 나누고 값을 올린 뒤 빠진 참여자의 가림막만 복구 조각으로 걷어 전체 합을 얻음

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **전송 암호화**: 통신 구간에서는 값을 보호하지만 서버가 수신 후 개별값을 복호화하는 방식이다.
- **동형암호**: 입력을 복호화하지 않고 암호문 상태에서 합계 등의 연산을 수행하는 암호 기법이다.

</details>

| 비교 기준 | 전송 암호화 | 보안 집계 | 동형암호 |
|:---|:---|:---|:---|
| 적용 기준 | 통신 구간 보호 | 개별값 없이 합계 필요 | 암호문 연산 필요 |
| 핵심 특징 | 서버에서 **개별값 복호화** | 마스크 상쇄 기반 **합계 복구** | 암호문 상태의 **집계 연산** |
| 한계 | 서버 내부 노출 | 이탈•공모 임계 관리 | 높은 연산•통신 비용 |

#### 한줄 요약
- 전송 길만 잠그는 방식, 합만 보이게 가리는 방식, 잠긴 값 그대로 계산하는 방식의 차이임

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **마스크 복구 실패**: 참여자가 너무 많이 이탈해 잔여 마스크를 제거할 비밀 조각이 부족한 문제이다.
- **개별값 노출**: 서버와 참여자의 공모 범위가 임계값을 넘어 특정 업데이트를 복원하는 문제이다.
- **중독 업데이트**: 값이 은닉된 상태로 악성 변화량이 합계에 포함되어 글로벌 모델을 훼손하는 문제이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 대규모 이탈의 **마스크 복구 실패** | 최소 생존자 임계값•기한•라운드 재시작 규칙 | 합계 가용성 **확보** |
| 서버•참여자 공모의 **개별값 노출** | 위협 모델별 공모 임계값•비밀 분산 수 설정 | 기밀성 경계 **보장** |
| 값 은닉에 가려진 **중독 업데이트** | 집계 전 범위 증명•강건 집계 별도 적용 | 모델 무결성 **보완** |

#### 한줄 요약
- 너무 많이 이탈하거나 서로 짜면 가림막이 깨질 수 있고 가린 악성 값은 별도 검사해야 함

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **집계 가용성**: 참여자 이탈이 발생해도 정해진 시간 안에 허용 합계를 복구할 수 있는 성질이다.
- **집계 무결성**: 합계가 허용된 참여자의 정상 업데이트만 정확히 반영하도록 보장하는 성질이다.

</details>

- 이탈률•공모 임계값•집계 무결성에 따라 **보안 집계 복구•검증 정책** 결정

#### 한줄 요약
- 합을 복구할 참여자 수와 공모를 견딜 비밀 조각 수, 악성 값 검사 방법을 함께 정함
