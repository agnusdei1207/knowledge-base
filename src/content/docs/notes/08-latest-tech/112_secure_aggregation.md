## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **보안 집계(Secure Aggregation)**: 연합학습 환경에서 개별 클라이언트의 가중치 업데이트 정보를 암호화하여 서버에 전달하고, 서버는 개별 데이터를 알 수 없는 상태에서 오직 전체 합(Aggregation)만을 복호화해내는 보안 기법
- **업데이트 기밀성**: 서버와 참여자에게 개별 로컬 변화량을 숨기는 성질

</details>

- 정의: 개별 업데이트를 숨기고 합계만 복구하는 **보안 집계** 프로토콜
- 배경/필요성: 연합학습(FL)에서 원본 데이터를 서버로 전송하지 않더라도, 개별 클라이언트가 전송하는 로컬 가중치 업데이트(Gradient)를 집계 서버가 평문 상태로 직접 수신할 경우, 딥 릭(Deep Leakage from Gradients: DLG) 등 구배 역추론 공격을 통해 클라이언트의 원본 학습 이미지나 텍스트가 완벽히 복원되는 심각한 프라이버시 침해 위험에 직면함에 따라, 참여 클라이언트 간에 서로 상쇄되는 무작위 마스크(Pairwise Random Mask)를 추가하여 전송하고 샤미르 비밀 분산(Shamir's Secret Sharing) 기반으로 이탈자(Dropout) 마스크만 선별 제거하는 보안 집계(Secure Aggregation: SecAgg / Bonawitz Protocol / Pairwise Masking, $(t, n)$ Threshold Secret Sharing, Zero-Sum Cancellation) 암호 프로토콜을 도입하여 **중앙 집계 서버를 포함한 어떤 주체도 개별 클라이언트의 로컬 가중치를 절대 열람할 수 없는 완벽한 업데이트 기밀성 보장, 네트워크 불안정으로 인한 대규모 클라이언트 이탈 발생 시에도 정상적인 전체 합산(Sum of Updates) 가용성 유지, 원본 데이터 비이동 원칙의 실질적 암호학적 안전성 완성**을 달성할 필요

#### 한줄 요약
- 상쇄되는 마스크로 개별값을 숨기고 **전체 합계** 한정 복구

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **쌍별 마스크**: 두 참여자가 공유하며 전체 합에서 상쇄되는 난수
- **비밀 분산**: 임계 개수 이상의 조각으로 비밀을 복구하는 기법
- **공모 임계값**: 개별 업데이트 기밀성을 유지하는 최대 공모 범위

</details>

- 생존 참여자의 합에서 상쇄되는 **쌍별 마스크**
- 비밀 분산 기반 **이탈 참여자 마스크 복구**
- 최소 생존자•공모 임계값 기반 **합계 공개 경계**

#### 한줄 요약
- 합에서 마스크를 상쇄하고 이탈자의 잔여분만 **비밀 조각** 기반 제거

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **업데이트 마스커**: 로컬 변화량에 상쇄 난수를 더해 서버가 개별값을 읽지 못하도록 하는 개념이다.
- **이탈 복구기**: 생존 참여자의 비밀 조각으로 이탈자가 남긴 마스크를 제거하는 구성요소이다.
- **생존 임계값**: 합계를 안전하게 복구하기 위해 업데이트와 복구 자료를 제출해야 하는 최소 참여자 수이다.

</details>

```text
                        [참여자 집합]
                       /             \
              [키•비밀 분산기]   [업데이트 마스커]
                       \             /
                         [집계 서버]
                               |
                         [이탈 복구기]
```

선의 의미: 참여자 집합은 키•비밀 분산기와 업데이트 마스커를 개별값 보호 경계로 사용하고, 집계 서버는 마스킹된 합계만 보유하며 이탈 복구기는 생존 임계값 안에서 잔여 마스크를 관리한다.

| 구성요소 | 책임 |
|:---|:---|
| 참여자 집합 | 로컬 업데이트와 **생존•이탈 상태 제공** |
| 키•비밀 분산기 | 쌍별 마스크와 **복구 조각 생성•배포** |
| 업데이트 마스커 | 로컬 업데이트에 **상쇄 난수 추가** |
| 집계 서버 | 마스킹 업데이트의 **허용 합계 계산** |
| 이탈 복구기 | 생존 임계값 확인과 **잔여 마스크 제거** |

#### 한줄 요약
- 참여자가 복구 조각을 나누고 서버가 **잔여 마스크** 제거

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **참여자 이탈**: 프로토콜 도중 통신 장애•종료로 업데이트나 마스크 해제 자료를 제출하지 못한 상태이다.
- **복구 합계**: 상쇄와 이탈 복구로 잔여 마스크를 제거해 얻은 허용 참여자의 집계값이다.

</details>

```text
참여자
   │ 1. 참여자 공개키 전달
   ▼
키•비밀 분산기
   │ 2. 비밀 조각•마스크 재료 전달
   ▼
업데이트 마스커
   │ 3. 마스킹 업데이트 전달
   ▼
집계•이탈 복구 서버
   │ 4. 생존•이탈 목록 확인
   └ 5. 복구 합계 계산
```

### 동작 원리

1. 참여자 공개키 전달: 라운드 참여자의 **쌍별 비밀** 설정 자료 제공
2. 비밀 조각•마스크 재료 전달: 이탈 복구 조각과 **상쇄 마스크** 제공
3. 마스킹 업데이트 전달: 로컬 변화량에 마스크를 더한 **은닉 값** 전송
4. 생존•이탈 목록 확인: 업로드 상태와 최소 참여 수의 **복구 조건** 확인
5. 복구 합계 계산: 잔여 마스크를 제거한 **집계값** 계산

#### 한줄 요약
- 이탈자의 마스크를 복구 조각으로 제거해 **전체 합계** 산출

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **전송 암호화**: 통신 구간에서는 값을 보호하지만 서버가 수신 후 개별값을 복호화하는 방식이다.
- **동형암호(Homomorphic Encryption)**: 평문 복호화 없이 암호문 상태에서 연산하는 암호 기술.

</details>

| 구분 | 전송 암호화 | 보안 집계 | 동형암호 |
|:---|:---|:---|:---|
| 적용 기준 | 통신 구간 보호 | 개별값 없이 합계 필요 | 암호문 연산 필요 |
| 핵심 특징 | 서버에서 **개별값 복호화** | 마스크 상쇄 기반 **합계 복구** | 암호문 상태의 **집계 연산** |
| 한계 | 서버 내부 노출 | 이탈•공모 임계 관리 | 높은 연산•통신 비용 |

#### 한줄 요약
- 서버의 개별값 복호화 여부와 **암호문 연산** 범위 비교

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **마스크 복구 실패**: 참여자가 너무 많이 이탈해 잔여 마스크를 제거할 비밀 조각이 부족한 문제이다.
- **개별값 노출**: 서버와 참여자의 공모 범위가 임계값을 넘어 특정 업데이트를 복원하는 문제이다.
- **중독 업데이트**: 값이 은닉된 상태로 악성 변화량이 합계에 포함되어 글로벌 모델을 훼손하는 문제이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 대규모 이탈의 **마스크 복구 실패** | 최소 생존자 임계값•기한•라운드 재시작 규칙 | 합계 가용성 **확보** |
| 서버•참여자 공모의 **개별값 노출** | 위협 모델별 공모 임계값•비밀 분산 수 설정 | 기밀성 경계 **보장** |
| 값 은닉에 가려진 **중독 업데이트** | 집계 전 범위 증명•강건 집계 별도 적용 | 모델 무결성 **보완** |

#### 한줄 요약
- 이탈•공모 임계 관리와 **악성 업데이트** 별도 검증

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **집계 가용성**: 참여자 이탈이 발생해도 정해진 시간 안에 허용 합계를 복구할 수 있는 성질이다.
- **집계 무결성**: 합계가 허용된 참여자의 정상 업데이트만 정확히 반영하도록 보장하는 성질이다.

</details>

- 연합학습 환경에서 기울기 역추론 공격(Gradient Inversion Attack)을 원천 차단하고 중앙 서버의 악의적 프라이버시 침해를 무력화하는 **연합학습 보안 통신의 최고 핵심 암호학적 방어 프로토콜(Secure Aggregation / SecAgg / Pairwise Mask Cancellation / Shamir $(t, n)$ Secret Sharing / Dropout-Resilient Protocol / Zero-Knowledge Range Proofs / Privacy-Preserving FL Cornerstone)의 확고한 표준**으로 확고히 자리 잡았으며, 대규모 크로스 디바이스 연합학습의 기본 통신 계층으로 정착한 가운데, 실무 SecAgg 아키텍처 구현 시에는 **통신 및 연산 복잡도($O(N^2)$)를 최적화하는 SecAgg+ 또는 그래프 기반 마스킹 토폴로지를 적용하고, 악의적 참여자의 모델 중독 공격(Model Poisoning)에 대비한 영지식 범위 증명(ZK-Range Proof) 및 강건 집계(Robust Aggregation)를 병행하며, 클라이언트 이탈 임계값($t$)을 정밀 튜닝**을 결합하여 완벽한 업데이트 기밀성과 대규모 확장성을 완성

#### 한줄 요약
- **생존자•공모 범위**에 맞춰 비밀 조각 수•검증 방식 결정
