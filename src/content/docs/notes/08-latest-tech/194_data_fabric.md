## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **데이터 패브릭(Data Fabric)**: 분산 데이터의 발견•접근•통합•거버넌스를 활성 메타데이터로 자동화하는 아키텍처로 정의된다.
- **활성 메타데이터(Active Metadata)**: 수집•분석에 그치지 않고 추천•정책•자동 조치를 구동하는 메타데이터을 의미한다.

</details>

- 정의: 활성 메타데이터로 분산 데이터 연결•정책을 자동화하는 **데이터 패브릭**
- 배경/필요성: 소스마다 개별 도구로 연결하고 정책을 수작업으로 맞추면 소스 조합 수만큼 연결과 규칙을 다시 만드는 비용이 들어 **탐색 지연•통합 중복•정책 불일치**가 누적되므로, 자산의 메타데이터를 한곳에 모아 연결 경로와 접근 정책을 자동으로 도출하는 계층의 필요

#### 한줄 요약

- 데이터 패브릭은 데이터를 옮기지 않고 메타데이터만 모아 **분산 데이터 연결•정책 자동화**를 얻는 방식이므로, 메타데이터가 낡거나 비면 자동화가 그대로 오류를 확산시킨다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **지식 그래프(Knowledge Graph)**: 데이터 자산•업무 용어•관계•계보를 그래프로 연결한 지식 구조을 말한다.
- **고위험 조치 승인**: 접근 차단•데이터 이동처럼 영향이 큰 자동화 결과를 사람이 검토하도록 하는 통제로 정의된다.

</details>

- 사용•품질•계보 신호 기반 **활성 메타데이터 자동 조치**
- 자산•업무 의미의 지식 그래프 기반 **발견•영향 분석**
- 복제•스트리밍•가상화 자동화와 **고위험 조치 승인**
#### 한줄 요약

- 자산 관계•이용 이력 기반 추천과 **고위험 변경 승인**

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **메타데이터 수집**: 분산 자산에서 스키마•계보•품질•사용량•소유자 정보를 모으는 기능이다.
- **통합 서비스**: 복제•스트리밍•가상화를 실행해 이기종 데이터 접근 경로를 제공하는 계층이다.
- **카탈로그•지식 그래프**: 수집한 메타데이터의 의미와 관계를 연결해 데이터 발견과 영향 분석을 지원하는 계층이다.
- **거버넌스 자동화**: 메타데이터와 정책을 이용해 접근•품질•계보•수명주기 통제를 일관되게 집행하는 기능을 의미한다.
- **데이터베이스(Database, DB)**: 구조화된 데이터의 저장•조회•무결성을 관리하는 시스템이다.
- **서비스형 소프트웨어(Software as a Service, SaaS)**: 제공자가 운영하는 응용 소프트웨어를 네트워크로 제공하는 방식로 정의된다.

</details>

```text
                      [카탈로그•지식 그래프]
                      /          |          \
             [메타데이터 수집] [통합 서비스] [거버넌스 자동화]
                      |
                [분산 데이터 자산]
```
선의 의미: 카탈로그•지식 그래프는 메타데이터 수집•통합 서비스•거버넌스 자동화가 공유하는 자산•의미•규칙 관계를 제공하고, 메타데이터 수집은 분산 데이터 자산을 공통 식별 경계에 연결한다.

| 구성요소 | 책임 |
|:---|:---|
| 분산 데이터 자산 | DB•데이터 레이크•SaaS의 **원천 데이터** 제공 |
| 메타데이터 수집 | 스키마•계보와 **품질•사용량** 수집 |
| 카탈로그•지식 그래프 | 자산•업무 의미와 **관계•규칙** 연결 |
| 통합 서비스 | 복제•스트리밍과 **가상화 실행** |
| 거버넌스 자동화 | 품질•보안 정책의 **평가•집행** |

#### 한줄 요약

- 분산 자산의 **메타데이터•통합•거버넌스 연결**

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **기술•운영 메타데이터**: 스키마•위치•계보와 사용량•품질•오류 상태를 함께 나타내는 정보로 정의된다.
- **자동화 피드백**: 실제 접근•통합 결과와 오류를 메타데이터에 되돌려 다음 추천•정책을 개선하는 정보이다.

</details>

```text
[분산 데이터 자산]
       │ 1. 메타데이터 신호
       ▼
[메타데이터 수집]
       │ 2. 관계•업무 의미
       ▼
[카탈로그•지식 그래프]
       │ 3. 품질•접근 조건
       ▼
[거버넌스 자동화]
       │ 4. 통합•접근 조치
       ▼
[통합 서비스] ── 5. 사용•변경 결과 ──▶ [카탈로그•지식 그래프]
```

### 동작 원리

1. 메타데이터 신호: 분산 자산의 **기술•운영 메타데이터** 제공
2. 관계•업무 의미: 자산•용어•소유자의 **지식 그래프** 제공
3. 품질•접근 조건: 민감도•신뢰도•규제 **정책 조건** 제공
4. 통합•접근 조치: 복제•스트리밍•가상화 **실행 조건** 제공
5. 사용•변경 결과: 실제 사용•오류의 **자동화 피드백 반영**

#### 한줄 요약

- 사용•오류 피드백 기반 **통합 경로•접근 정책 개선**

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **데이터 메시**: 도메인 팀이 데이터 제품의 소유•품질•운영을 책임지는 분산 운영 모델을 의미한다.
- **레이크하우스**: 개방형 파일 저장소에 ACID 테이블 관리 기능을 결합한 분석 아키텍처이다.
- **원자성•일관성•격리성•지속성(Atomicity, Consistency, Isolation, Durability, ACID)**: 트랜잭션이 보장해야 하는 네 가지 성질로 정의된다.

</details>

| 분산 데이터 접근법 | 데이터 패브릭 | 데이터 메시 | 레이크하우스 |
|:---|:---|:---|:---|
| 적용 기준 | 이기종 자산의 **기술 통합** | 도메인별 **책임 분산** | 분석 **저장•처리 통합** |
| 핵심 특징 | 메타데이터 기반 **자동 연결** | **데이터 제품•연합 정책** | **객체 저장소•테이블 계층** |
| 한계 | **도구 복잡성•메타데이터 품질** | **조직 전환•역량 편차** | **분산 책임 문제** 별도 |

#### 한줄 요약

- **패브릭•메시•레이크하우스**는 같은 분산 데이터 문제를 메타데이터 자동화•조직 소유권•저장 통합으로 나눠 푸는 해법이라, 무엇이 부족한지에 따라 선택이 갈릴 뿐 서로를 대체하지 않는다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **메타데이터 신뢰도**: 계보•소유자•품질 정보가 실제 데이터 상태를 정확하고 최신으로 나타내는 정도이다.
- **공통 식별자**: 서로 다른 도구가 같은 데이터 자산•용어•주체를 일관되게 연결하도록 사용하는 값을 의미한다.
- **응용 프로그래밍 인터페이스(Application Programming Interface, API)**: 소프트웨어 간 기능•데이터 교환 규칙을 정의한 접점로 정의된다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 부정확한 **계보•소유자 메타데이터** | 자동 수집•소유자 검증과 **신뢰도 표시** | 잘못된 **영향 분석** 감소 |
| 자동 정책의 **과잉 차단•오승인** | 위험 등급별 사람 승인•**감사•롤백** | **자동화 사고 범위** 제한 |
| 도구 간 **메타데이터 모델 종속** | 개방 API•공통 식별자와 **반출 검증** | **패브릭 공급자 종속** 완화 |

#### 한줄 요약

- 공통 식별자•계보 연결과 **고위험 정책 사람 승인**

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **기술 통합**: 이기종 데이터 자산의 발견•접근•이동•정책 집행을 공통 자동화 계층으로 연결하는 활동이다.
- **공급자 종속**: 특정 패브릭 도구의 메타데이터 모델과 API에 의존해 다른 환경으로 이전하기 어려운 상태을 말한다.

</details>

- 이기종 자산 연결 자동화는 **데이터 패브릭**, 도메인 책임 분산은 **데이터 메시** 선택

#### 한줄 요약

- **데이터 패브릭 적용**의 자동화 이득은 메타데이터 정확도에 비례하고 오작동 위험도 같은 속도로 커지므로, 고위험 조치에 사람 승인을 남겨 두는 지점이 자동화 범위의 상한이 된다.
