## 미리 알고가기

- **사고 트리(Tree of Thoughts, ToT)**: 여러 중간 상태를 분기·평가하며 유망한 해법을 탐색하는 방식
- **사고 사슬(Chain-of-Thought, CoT)**: 하나의 중간 추론 경로를 따라 답을 생성하는 방식
- **너비 우선 탐색(Breadth-First Search, BFS)**: 같은 깊이의 후보 상태를 먼저 탐색하는 방식
- **깊이 우선 탐색(Depth-First Search, DFS)**: 한 후보 경로를 깊게 탐색한 뒤 되돌아오는 방식
- **빔 탐색(Beam Search)**: 점수 상위 후보만 폭만큼 유지
- **가지치기(Pruning)**: 기준 미달 분기를 탐색 대상에서 제거
- **백트래킹(Backtracking)**: 막힌 상태에서 이전 분기로 복귀
- **상태 평가기(State Evaluator)**: 후보 가치·제약 위반을 점수화



## Ⅰ. 개요

- 정의/개념: 여러 중간 상태·분기를 탐색하는 방식
- 기존 한계: 단일 추론 경로는 **초기 선택 오류에서 회복하거나 여러 대안을 비교**하기 어려움

### 쉽게 이해하기 (학습용)
- 여러 갈래를 살펴보고 막히면 이전 갈림길로 돌아가는 탐색법

## Ⅱ. 특징

- 복수 후보의 **분기·평가·가지치기**
- 깊이·폭·토큰 예산 기반 **탐색 범위 제한**
- **평가기 편향**에 따른 유망 분기 조기 제거

### 쉽게 이해하기 (학습용)
- 후보 생성보다 어떤 기준으로 남기고 언제 멈출지 결정하는 것이 중요

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
|:---|:---|
| 상태 표현 | 부분 해·제약·잔여 목표 정의 |
| 후보 생성기 | 다음 생각·행동 분기 생성 |
| 상태 평가기 | 후보 가치와 제약 위반 평가 |
| 탐색 제어기 | BFS·DFS·빔과 예산 관리 |
| 종료·검증기 | 완성 후보의 정답·근거 확인 |

```text
초기 상태
├─ 대안 가
│  └─ 후속 가
├─ 대안 나 ×
└─ 대안 다
   └─ 후속 다
```

### 쉽게 이해하기 (학습용)

- 각 갈림길의 상태를 기록하고 기준 미달 길은 버리며 유망한 길만 더 깊게 탐색함

## Ⅳ. 원리 및 절차 흐름도

```text
상태정의
  ↓
후보확장
  ↓
가치평가
  ↓
경로탐색
  ↓
답안검증
```

| 절차 | 설명 |
|:---|:---|
| 절차 | 설명 |
|:---|:---|
| 상태정의 | 부분 해·제약·종료 조건 표현 |
| 후보확장 | 현재 상태의 다음 분기 생성 |
| 가치평가 | 점수·제약으로 후보 정렬·제거 |
| 경로탐색 | BFS·DFS·빔으로 경로 탐색 |
| 답안검증 | 완성 후보를 독립 기준으로 검증 |

### 쉽게 이해하기 (학습용)

- 높은 점수의 길도 마지막에 틀릴 수 있으므로 완성된 답을 별도 기준으로 확인해야 함

## Ⅴ. 추론 경로 탐색 방식 비교

| 구분 | 사고 사슬 | 사고 트리 |
|:---|:---|:---|
| 추론 구조 | 하나의 선형 경로 | 복수 상태의 분기 탐색 |
| 오류 회복 | 이전 단계 수정 제한 | 가지치기·백트래킹 |
| 적용 기준 | 단순 단계 추론 | 대안 탐색이 필요한 문제 |
| 핵심 특징 | 단일 중간 경로 생성 | 후보 분기·평가·가지치기 |
| 한계 | 초기 오류 회복 곤란 | 탐색·평가 비용 증가 |

> 요약: 다중 경로 탐색으로 복잡 과업의 오류 대응

### 쉽게 이해하기 (학습용)

- 한 풀이를 이어가는 방식과 여러 풀이 후보를 비교하며 탐색하는 방식의 차이임

## Ⅵ. 실무 사례

- 시뮬레이터가 시간·자원 위반 후보를 제거한다

### 쉽게 이해하기 (학습용)

- 모든 문제에 큰 탐색 트리를 쓰면 답보다 탐색 비용이 더 커질 수 있음

## Ⅶ. 결론

- 단일 추론 경로가 놓치는 대안을 탐색하기 위해 **분기 수·후보 평가기·탐색 예산·종료 조건**을 검토하고, 해법 비교의 편익이 비용보다 큰 문제에 ToT를 활용해야 한다.

### 쉽게 이해하기 (학습용)

- 여러 길을 보는 장점은 있지만 잘못된 지도와 무제한 탐색은 더 큰 낭비를 만듦
