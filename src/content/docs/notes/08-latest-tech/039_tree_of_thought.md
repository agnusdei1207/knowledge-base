## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **사고 트리(Tree of Thoughts, ToT)**: 여러 사고 상태를 분기•평가•가지치기하며 대안 해법을 탐색하는 방식을 말한다.
- **사고 상태(Thought State)**: 부분 해•제약 조건•남은 목표를 함께 표현한 탐색 시점의 상태다.

</details>

- 정의/개념: 여러 사고 상태를 탐색 트리로 분기하고 후보를 평가•가지치기해 해법을 찾는 **ToT**임.
- 배경/필요성: 단일 경로는 **초기 선택 오류•대안 누락**에서 회복하기 어렵음.

#### 한줄 요약
- **분기•평가•가지치기**로 대안 해법을 탐색한다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **너비 우선 탐색(Breadth-First Search, BFS)**: 같은 깊이의 후보 상태를 먼저 탐색하여 다양한 대안을 유지하는 방식로 정의된다.
- **깊이 우선 탐색(Depth-First Search, DFS)**: 한 후보 경로를 깊게 탐색한 뒤 막히면 이전 분기로 돌아오는 방식로 정의된다.
- **빔 탐색(Beam Search)**: 각 깊이에서 평가 점수가 높은 후보를 정해진 폭만큼 유지하는 방식을 의미한다.
- **백트래킹(Backtracking)**: 현재 경로가 막혔을 때 저장한 이전 분기로 돌아가 다른 후보를 선택하는 동작을 의미한다.

</details>

- 복수 사고 상태의 **분기•평가•가지치기**가 핵심임.
- **BFS**: 같은 깊이의 후보를 우선 탐색함.
- **DFS**: 한 후보 경로를 깊게 탐색함.
- **빔 탐색**: 점수가 높은 후보를 정해진 폭만큼 유지함.
- **백트래킹**: 실패 시 저장한 이전 분기로 복귀함.

#### 한줄 요약
- **BFS•DFS•빔•백트래킹**으로 탐색 범위를 제어한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **후보 생성기**: 현재 사고 상태에서 가능한 다음 부분 해나 행동 분기를 생성하는 구성요소다.
- **상태 평가기(State Evaluator)**: 후보의 목표 기여도와 제약 위반 정도를 점수화하는 장치다.
- **탐색 제어기**: 탐색 방식•빔 폭•최대 깊이•예산을 적용하여 유지할 후보를 관리한다.

</details>

```text
                     [상태 표현]
                          │
                    [후보 생성기]
                   ╱      │      ╲
             [상태 평가기]──[탐색 제어기]
                              │
                         [종료•검증기]
```

선의 의미: 상태•후보•평가•탐색 통제•검증 책임의 정적 연결을 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 상태 표현 | 부분 해•제약•**잔여 목표** 보존 |
| 후보 생성기 | 현재 상태별 **다음 분기** 생성 |
| 상태 평가기 | 후보 가치•**제약 위반** 점수화 |
| 탐색 제어기 | **BFS•DFS•빔 탐색 예산 관리** |
| 종료•검증기 | 완성 후보의 **정답•근거** 확인 |

#### 한줄 요약
- **상태•후보•평가•제어•검증**을 구성한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **가지치기(Pruning)**: 평가 기준에 미달한 후보 분기를 탐색 대상에서 제거하여 비용을 줄이는 동작이다.
- **유지 집합**: 평가와 탐색 예산을 통과하여 다음 깊이에서 계속 확장할 후보들의 집합로 정의된다.
- **독립 검증**: 탐색 점수와 다른 규칙•시뮬레이터로 완성 답의 실제 타당성을 확인하는 절차다.

</details>

```text
탐색 제어기
     │ 1. 초기 상태 정의
     ▼
┌──────── 종료 조건 충족 전 반복 ────────┐
│ 후보 생성기                             │
│   │ 2. 후보 상태 확장                   │
│   ▼                                     │
│ 상태 평가기                             │
│   │ 3. 후보 가치 평가                   │
│   ▼                                     │
│ 탐색 제어기                             │
│   └ 4. 가지치기•경로 선택 ── 반복       │
└─────────────────────────────────────────┘
     │ 완성 후보 전달
     ▼
검증기
     │ 5. 완성 답 독립 검증
     │ 검증 결과 반환
     ▼
탐색 제어기
```

1. **초기 상태 정의**: 목표•제약•**종료 조건**을 고정함.
2. **후보 상태 확장**: 현재 상태별 **다음 사고**를 생성함.
3. **후보 가치 평가**: 가치와 **제약 위반**을 점수화함.
4. **가지치기•경로 선택**: 탐색 방식•예산으로 **유지 집합**을 결정함.
5. **완성 답 독립 검증**: 탐색 점수와 **정답 판정**을 분리함.

#### 한줄 요약
- **확장•평가•가지치기**를 반복한 뒤 완성 답을 독립 검증한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **사고 사슬(Chain-of-Thought, CoT)**: 하나의 중간 추론 경로를 순서대로 이어 답을 생성하는 방식로 정의된다.
</details>

| 추론 방식 | 사고 사슬 | 사고 트리 |
|:---|:---|:---|
| 적용 기준 | **단일 풀이**로 충분 | 대안 비교•**오류 회복** 필요 |
| 핵심 특징 | **선형 중간 경로** 생성 | 분기•평가•**가지치기** |
| 한계 | 초기 오류 회복 제한 | **평가•탐색 비용** 증가 |

#### 한줄 요약
- 단일 경로는 **CoT**, 대안 비교•오류 회복은 **ToT**가 적합하다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **분기 폭발**: 깊이마다 후보가 늘어나 탐색 상태와 연산 비용이 기하급수적으로 증가하는 현상로 정의된다.
- **평가기 편향**: 상태 평가기가 특정 형태의 후보에 일관되게 잘못된 점수를 부여해 유망한 경로를 제거하는 문제다.
- **종료 조건**: 성공•정체•최대 깊이•예산 소진으로 탐색을 끝낼 시점을 정한 기준로 정의된다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **분기 폭발** | **빔 폭•최대 깊이**와 예산 상한 | **탐색 비용** 제한 |
| **평가기 편향** | 규칙•시뮬레이터 기반 **교차 검증** | 유망 경로의 **오제거 완화** |
| **국소 점수 과적합** | 완성 답 **독립 검증** | **고득점 오답** 차단 |
| **종료 불명확** | 성공•정체•**예산 소진** 조건 | **무한 탐색 방지** |

#### 한줄 요약
- **빔 폭•깊이•교차 검증•종료 조건**으로 통제한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **빔 폭•깊이**: 각 단계에서 유지할 후보 수와 최대 탐색 단계를 제한하여 비용을 통제하는 값이다.

</details>

- **대안 가치•평가기 신뢰도**가 충분하면 ToT를 **빔 폭•깊이**로 통제함.

#### 한줄 요약
- **대안 가치•평가기 신뢰도**에 따라 ToT 적용을 결정한다.
