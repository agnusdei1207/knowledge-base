## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **공간 컴퓨팅(Spatial Computing)**: 센서로 물리 환경과 기기의 위치를 인식하고 디지털 정보•사용자 입력•기기 동작을 실제 공간 좌표에 정합하는 컴퓨팅 방식로 정의된다.

</details>

- 정의/개념: **공간 컴퓨팅**은 물리 환경을 인식해 디지털 정보와 사용자•기기 동작을 실제 공간 좌표에 정합하는 컴퓨팅 방식임.
- 배경/필요성: 평면 화면은 사용자•사물의 **공간 관계** 기반 상호작용이 어렵음.

#### 한줄 요약

- 물리 공간을 인식해 디지털 정보와 기기 동작을 실제 좌표에 정합한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **공간 정합**: 가상 객체의 위치•크기•방향을 인식한 물리 공간의 좌표와 일치시키는 과정을 의미한다.
- **광 검출 및 거리 측정(Light Detection and Ranging, LiDAR)**: 레이저 왕복 시간으로 물체 거리와 깊이를 측정하는 센서 기술을 의미한다.
- **동시적 위치 추정 및 지도 작성(Simultaneous Localization and Mapping, SLAM)**: 지도를 만들면서 그 안의 기기 위치를 동시에 추정하는 기술을 의미한다.

</details>

- 시각•관성•**LiDAR 센서**의 **시간•좌표 정렬**이 핵심임.
- **SLAM**으로 **장치 위치•환경 지도**를 동시에 갱신함.
- 객체•가림•통행 영역의 **공간 맥락 추론**이 핵심임.
#### 한줄 요약

- 센서를 정렬하고 위치•지도를 갱신해 공간 맥락에 맞는 출력과 동작을 수행한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **센서 보정**: 카메라•관성•LiDAR의 좌표•시간•오차 특성을 맞추는 과정로 정의된다.
- **센서 융합**: 여러 센서 관측을 결합하여 위치•깊이 추정의 정확도를 높이는 방식로 정의된다.
- **위치 추정**: SLAM으로 장치 자세와 환경 지도를 갱신하는 방식을 말한다.
- **장면 모델**: 표면•깊이•객체•의미•가림 관계를 현실 좌표계에 표현한 디지털 공간 지도로 정의된다.
- **공간 상호작용**: 시선•손•음성•컨트롤러 입력을 현실 공간의 객체와 행위에 연결하는 기능을 의미한다.
- **렌더링**: 추적된 시점에 맞춰 가상 내용을 실제 공간에 정합하여 표시하는 방식이다.
- **작동 제어**: 로봇•장치를 공간 좌표에 따라 움직이도록 제어하는 방식로 정의된다.

</details>

카메라•관성•**LiDAR** 센서를 보정•융합하고 **SLAM**으로 위치와 장면 모델을 갱신한다.

```text
[센서 보정] ----- [센서 융합] ----- [위치 추정]
                                         |
                                    [장면 모델]
                                   /     |      \
                        [공간 상호작용] [렌더링] [작동 제어]
```

선의 의미: 보정•융합한 센서로 위치와 장면을 구성하고 공간 입력을 렌더링 또는 물리 작동에 연결하는 관계다.

| 구성요소 | 책임 |
|:---|:---|
| 센서 보정 | **카메라•관성•LiDAR 좌표** 동기화 |
| 센서 융합 | **다중 센서 관측•오차** 결합 |
| 위치 추정 | **장치 자세•환경 지도** 생성 |
| 장면 모델 | **객체•평면•공간 앵커** 관리 |
| 공간 상호작용 | **손•시선•음성 입력**을 공간 객체와 연결 |
| 렌더링 | **가상 표현•공간 정합** 수행 |
| 작동 제어 | **로봇•장치 물리 제어** 수행 |

#### 한줄 요약

- 센서를 보정해 지도와 장면 의미를 만들고 렌더링 또는 물리 동작으로 출력한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **공간 앵커**: 가상 콘텐츠를 실제 공간의 특정 좌표나 사물에 지속적으로 고정하는 기준점을 말한다.

</details>

```text
[공간 센서]
    │ 1. 기준•센서 보정
    ▼
[추적 체계]
    │ 2. 위치•지도 갱신
    ▼
[장면 모델]
    │ 3. 장면 관계 추론
    ▼
[상호작용]
    │ 4. 공간 출력•작동
    ▼
[출력•작동] ── 출력•작동 결과 관측 ──▶ [공간 센서]
                                             │ 5. 폐루프 검증
                                             └────────▶ [추적 체계]
```

### 동작 원리

1. 기준•센서 보정: 카메라•관성•깊이 센서 시간•좌표를 정렬함.
2. 위치•지도 갱신: **SLAM** 기반 자세•환경 지도를 추정함.
3. 장면 관계 추론: 평면•객체•가림•공간 앵커를 식별함.
4. 공간 출력•작동: 공간 입력 기반 렌더링•물리를 제어함.
5. 폐루프 검증: 드리프트•지연을 보정하거나 위험 동작을 정지함.

#### 한줄 요약

- 장치와 사물이 움직일 때마다 위치•지도를 갱신해 출력과 동작을 다시 정합한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **확장현실(Extended Reality, XR)**: 가상현실•증강현실•혼합현실을 포괄하는 기술 범주이다.
- **증강현실(Augmented Reality, AR)**: 현실 시야에 디지털 정보를 정합하여 겹쳐 보이는 기술이다.

</details>

| 판단 기준 | AR 인터페이스 | 공간 컴퓨팅 | 로보틱스 |
|:---|:---|:---|:---|
| 핵심 특징 | **현실 시야에 정보 정렬** | **공간 모델•입력•작동 연결** | **물리 환경 과업 수행** |
| 적용 기준 | **안내•시각화•원격 지원** | **공간 이해형 XR•제어** | **이동•조작•자율 작업** |
| 한계 | **가림•드리프트•사용자 피로** | **좌표 오차•프라이버시** | **충돌•제어 실패•현실 피해** |

> 요약: **AR**은 시각 정렬, **공간 컴퓨팅**은 공간 이해•상호작용을 연결한다.

#### 한줄 요약

- 증강현실은 시각 정보를 정렬하고 공간 컴퓨팅은 공간 모델•입력•작동을 연결한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **드리프트**: 센서 오차가 누적되어 디지털 객체가 고정된 물리 좌표에서 점차 벗어나는 위치 추정 오류이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 드리프트•지연으로 **공간 오조작** | **앵커 재관측•정합 임계값** 적용 | **공간 정합성** 유지 |
| 장면 오인식으로 **위험한 물리 동작 실행** | **다중 센서 검증•사람 승인** | **위험 동작•현실 피해** 감소 |
| 공간 지도 수집으로 **개인정보 노출** | **기기 내 처리•지도 암호화** | **공간 지도 노출 범위** 축소 |

#### 한줄 요약

- 핵심 운영 위험마다 실행 가능한 대책과 검증 효과를 함께 확인한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **LiDAR 오차 검증**: 거리•깊이 측정값의 편향과 환경별 오차를 확인하는 활동을 말한다.

</details>

- 시각 정보 정렬은 **AR**, 공간 이해•입력•작동 연결은 **공간 컴퓨팅**을 선택함.

#### 한줄 요약

- 공간 정합의 정확도•지속성과 오인식 시 안전 정지가 핵심 원칙 준수
