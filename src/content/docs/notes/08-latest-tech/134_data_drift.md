## 미리 알고가기

- **Data Drift**: 학습 시점과 운영 시점의 입력 데이터 분포 차이 발생
- **핵심**: 변화가 곧 성능 저하는 아님, 중요 피처 위주로 영향 분석
- **탐지 지표**: PSI, KS, Wasserstein 등 통계 지표 활용
- **$P(X)$**: “피 엑스”로 읽으며 입력 $X$가 나타나는 확률 분포

## Ⅰ. 개요

- **정의/개념**: 기준·운영 시점 사이의 입력 분포 변화다
- **배경/필요성**: 정답 지연 중 운영 환경 변화를 조기에 찾는다

### 쉽게 이해하기 (학습용)

- 학습 당시 입력 분포와 운영 데이터를 먼저 비교하고 정답이 도착하면 실제 성능 영향도 확인한다.

## Ⅱ. 특징

- 정답 없이 입력 분포를 비교해 조기 경보를 만든다
- 평균·분산·비율·형태 변화는 서로 다른 이동을 찾는다
- 계절·캠페인도 정상적인 입력 분포 변화를 만든다
- 입력 변화만으로 모델 성능 저하를 확정할 수 없다
- 지연 정답 결합은 불필요한 재학습 비용을 줄인다

### 쉽게 이해하기 (학습용)

- 입력 분포 변화는 먼저 감지하되 정답이 늦으면 성능 저하 확정은 유보한다.

## Ⅲ. 아키텍처 및 구성요소

| 설계 요소 | 설명 |
|:---|:---|
| 기준 프로필 | 정상 구간의 분포 및 품질 정보 |
| 현재 구간 | 최신 관측 입력 표본 |
| 분포 비교기 | 통계 검정 및 거리 계산 |
| 문맥 정책 | 환경별 경고 및 임계치 관리 |
| 정답 저장소 | 예측과 실제 정답 결합 참조 |

> 요약: 분포 차이를 경보하고 지연 정답으로 영향을 확인한다

### 쉽게 이해하기 (학습용)

- 기준 입력 분포와 현재 구간을 비교하고 나중에 도착한 정답을 예측과 결합한다.

## Ⅳ. 원리 및 절차 흐름도

```text
기준선·구간 선택 → 품질 검증 → 분포 차이 계산
                                  ↓
                             임계 판정
                    ├─ 미달 → 관측 지속
                    └─ 초과 → 선행 경보
                                 ↓
                         지연 정답 결합
                    ├─ 품질 유지 → 조정
                    └─ 품질 저하 → 재학습
```

| 절차 | 설명 |
|:---|:---|
| 기준선 선택 | 비교 목적에 맞는 구간 고정 |
| 품질 검증 | 오류 및 결측 분리 |
| 차이 계산 | 피처별 거리 산출 |
| 임계 판정 | 경보 및 문맥 반영 |
| 영향 확인 | 지연 정답 결합 및 대응 |

> 요약: 분포 차이를 경보하고 실제 품질 뒤 대응한다

### 쉽게 이해하기 (학습용)

- 입력 분포 변화를 먼저 경보하고 정답으로 성능 영향을 확인한 뒤 모델을 조정한다.

## Ⅴ. 종류 및 비교

| 판단 기준 | 데이터 드리프트 | 라벨 드리프트 | 개념 드리프트 |
|:---|:---|:---|:---|
| 확률 변화 | P(X) 변화 | P(Y) 변화 | P(Y|X) 변화 |
| 탐지 근거 | 입력 분포 비교 | 예측 분포 기반 | 최근 정답·예측 |
| 대응 | 영향 분석 후 결정 | 사전확률 보정 | 재학습 수행 |

> 요약: 입력·정답·관계 변화별로 대응을 구분한다

### 쉽게 이해하기 (학습용)

- 입력 구성은 데이터, 정답 비율은 라벨, 입력과 정답의 관계는 개념 드리프트다.

## Ⅵ. 실무 사례
1. 이상거래는 거래 분포와 정답으로 재학습을 결정한다
2. 설비 센서는 구간별 분포와 품질 저하를 판정한다

### 쉽게 이해하기 (학습용)

- 이상거래는 거래 정보 변화를 먼저 찾고 확정된 사기 정답과 결합해 재학습을 결정한다.
- 설비 센서는 운전 구간별 분포를 비교하고 고장 결과와 함께 품질 저하 여부를 판정한다.

## Ⅶ. 결론
- 입력 분포를 경보로 쓰고 정답으로 재학습을 결정한다.

### 쉽게 이해하기 (학습용)

- 입력 분포 차이만으로 곧바로 재학습하지 않고 지연된 정답으로 실제 성능 저하를 확인한다.
