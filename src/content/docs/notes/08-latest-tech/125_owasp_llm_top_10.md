## 미리 알고가기

- **오픈 월드와이드 애플리케이션 보안 프로젝트(Open Worldwide Application Security Project, OWASP)**: '오와스프'로 읽고 공개 응용 보안 지침 조직을 관용 약어로 표시
- **대규모 언어 모델(Large Language Model, LLM)**: '엘엘엠'으로 읽고 언어 생성·처리 모델을 영문 머리글자로 표시
- **검색 증강 생성(Retrieval-Augmented Generation, RAG)**: '래그'로 읽고 검색 근거를 생성 문맥에 결합하는 방식을 표시
- **OWASP LLM Top 10 2025**: LLM 응용의 주요 위험 열 가지를 2025판 번호·이름으로 분류한 지침
- **LLM01 번호 표기**: LLM 위험군과 두 자리 순번을 붙여 같은 판본의 항목을 식별

## Ⅰ. 개요

- **정의/개념**: LLM 응용의 **10대 보안 위험·공격 예·완화 지침**
- **배경/필요성**: 웹 보안 목록만으로 놓치는 **프롬프트·모델·RAG·도구·자원 위험 점검**

### 쉽게 이해하기 (학습용)

- 챗봇 모델과 연결된 문서함·검색창·실행 도구의 사고 지점을 같은 번호로 표시하는 지도다.

## Ⅱ. 특징

- **입력·출력·데이터·모델·도구·자원**의 연쇄 위험을 분류한다.
- **2025판 번호·항목명**을 함께 써 이전 판과 항목 혼용을 막는다.
- **서비스 위협 모델·실제 공격 검증**으로 우선순위와 통제 공백을 보완한다.

### 쉽게 이해하기 (학습용)

- 한 번의 악성 지시가 정보 노출과 도구 오용을 함께 만들 수 있어 관련 위험 항목을 연결해 본다.

## Ⅲ. 아키텍처 및 구성요소

```text
       [공급망·학습]
             │
[프롬프트] ─ [시스템] ─ [정보]
             │
      ┌──────┴──────┐
    [도구]        [자원]
```

| 설계 요소 | 설명 |
|:---|:---|
| 입력·출력 경계 | **LLM01 인젝션·LLM05 출력 처리** |
| 정보·지시 경계 | **LLM02 정보 노출·LLM07 지시 유출** |
| 공급·학습 경계 | **LLM03 공급망·LLM04 오염** |
| 검색·행동 경계 | **LLM06 대리권·LLM08 벡터 약점** |
| 판단·자원 경계 | **LLM09 허위정보·LLM10 소비** |

> 요약: 열 가지 위험을 서비스 경계별 통제로 연결한다

### 쉽게 이해하기 (학습용)

- 열 가지 위험을 입력·학습·검색·출력·도구·사용량 경계에 붙이면 담당 통제가 보인다.

## Ⅳ. 원리 및 절차 흐름도

```text
범위 확정
 ↓
자산 식별
 ↓
목록 매핑
 ↓
통제 검증
 ↓
위험 재평가
```

| 절차 | 설명 |
|:---|:---|
| 범위 확정 | 모델·데이터·검색·도구 범위 결정 |
| 자산 식별 | 보호 자산·비신뢰 입력 경로 표시 |
| 목록 매핑 | 공격 시나리오·위험 항목 연결 |
| 통제 검증 | 예방·탐지·복구 통제 재현 |
| 위험 재평가 | 잔여 위험·변경 우선순위 갱신 |

> 요약: 경계에 위험을 매핑하고 통제·잔여 위험을 재평가한다

### 쉽게 이해하기 (학습용)

- 시스템 경계에 위험 번호와 담당자를 붙이고 통제를 공격으로 검증한 뒤 실패한 경계를 보완한다.

## Ⅴ. 종류 및 비교

| OWASP LLM Top 10 판본 | 2023/24판 | 2025판 |
|:---|:---|:---|
| 적용 기준 | 기존 평가 식별자 해석 | 현재 서비스 통제 매핑 |
| 핵심 특징 | 초기 LLM 위험 분류 | 앱·운영 위험 재분류 |
| 한계 | 최신 위험·명칭 누락 | 이전 번호와 혼용 위험 |

> 요약: 구판은 이력 해석, 2025판은 현재 통제에 적용한다

### 쉽게 이해하기 (학습용)

- 구판은 서비스 거부를 중심으로 봤고 2025판은 예상 밖 비용과 프롬프트·검색 벡터 위험까지 넓혔다.

## Ⅵ. 실무 사례

1. 사내 챗봇의 문서·검색·출력 위험을 매핑한다
2. 에이전트의 인젝션·과도한 권한 결합을 검증한다

### 쉽게 이해하기 (학습용)

- 사내 챗봇은 외부 문서가 검색과 출력을 거치는 경로마다 위험 항목과 접근 권한을 연결한다.
- 실행형 에이전트는 악성 지시가 실제 도구 권한으로 이어지는 결합 사고를 배포 전에 검증한다.

## Ⅶ. 결론

- 위험 분류는 **2025 Top 10**, 우선순위는 **서비스 위협 모델**

### 쉽게 이해하기 (학습용)

- 최신 위험 번호를 실제 시스템 경계에 붙여 통제 책임자와 재검증 조건을 정해야 한다.
