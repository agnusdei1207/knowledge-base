## Ⅰ. 개요

<details>
<summary>용어 설명</summary>

- **오픈 월드와이드 애플리케이션 보안 프로젝트 거대 언어 모델 상위 10대 위험(Open Worldwide Application Security Project Large Language Model Top 10, OWASP LLM Top 10)**: LLM 응용의 주요 열 가지 위험과 공격 사례•완화책을 판본별 식별자로 정리한 보안 지침 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **오픈 월드와이드 애플리케이션 보안 프로젝트(Open Worldwide Application Security Project, OWASP)**: 공개 애플리케이션 보안 지침과 위험 목록을 제공하는 비영리 재단 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **검색 증강 생성(Retrieval-Augmented Generation, RAG)**: 외부 자료를 검색해 LLM의 답변 문맥으로 제공하는 방식 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

- 정의/개념: OWASP가 정리한 LLM 응용의 **10대 위험•완화 지침**
- 배경/필요성: 기존 웹 목록만으로는 프롬프트•RAG•도구•자원의 **연쇄 위험** 분류가 어렵음.

#### 한줄 요약

- LLM•검색•도구의 위험을 **공통 식별자**로 관리

## Ⅱ. 특징

<details>
<summary>용어 설명</summary>

- **2025판 식별자**: 위험 항목을 LLM 위험군과 두 자리 순번•명칭으로 같은 판본 안에서 식별하는 표기을  역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **연쇄 위험**: 입력•검색•모델•출력•도구•자원의 한 실패가 다른 경계의 피해로 이어지는 위험 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **위협 모델**: 보호 자산•공격자•유입 경로•권한과 예상 피해를 구조화한 공격 가정을  역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

- LLM의 **입력•출력•데이터•도구•자원 위험 분류**
- 이전 판과 혼용을 막는 **2025판 번호•항목명**
- 통제 공백을 찾는 **위협 모델•실제 공격 검증**

#### 한줄 요약

- 공격 경로에 관련된 **복수 위험 항목** 연결

## Ⅲ. 구조 및 구성요소

<details>
<summary>용어 설명</summary>

- **입력•출력 경계**: 프롬프트 인젝션과 안전하지 않은 출력 처리 위험을 통제하는 접점 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **검색•행동 경계**: RAG 검색 결과와 모델의 도구 대리권이 실제 행동으로 이어지는 범위를 통제하는 범위을  역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **판단•자원 경계**: 허위정보와 무제한 소비가 의사결정•서비스 용량에 미치는 피해를 통제하는 범위 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

LLM 응용의 입력•정보•공급망•검색•자원 경계에 2025판 위험 식별자를 연결한다.

```text
                 [입력•출력 경계]
                         |
                  [정보•지시 경계]
                         |
                  [공급•학습 경계]
                         |
                  [검색•행동 경계]
                         |
                  [판단•자원 경계]
```

선의 의미: 입력•출력, 정보•지시, 공급•학습, 검색•행동, 판단•자원 경계가 LLM 응용의 연쇄 위험을 분리해 담당 통제와 연결하는 구조를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 입력•출력 경계 | **LLM01 인젝션•LLM05 출력 처리** |
| 정보•지시 경계 | **LLM02 정보 노출•LLM07 지시 유출** |
| 공급•학습 경계 | **LLM03 공급망•LLM04 오염** |
| 검색•행동 경계 | **LLM06 대리권•LLM08 벡터 약점** |
| 판단•자원 경계 | **LLM09 허위정보•LLM10 소비** |

#### 한줄 요약

- 10대 위험을 책임 경계별 **담당 통제**와 연결

## Ⅳ. 흐름도

<details>
<summary>용어 설명</summary>

- **위험 매핑**: 시스템의 자산•데이터 흐름•권한 경계에 OWASP 위험 항목을 연결하는 과정을  역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **잔여 위험**: 통제 시험 뒤에도 남아 서비스 책임자가 수용•보완할 위험을  역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

OWASP LLM 위험 항목을 시스템 자산과 권한 경계에 매핑한다.

```text
서비스•위험 책임자
   │ 1. 모델•데이터•검색•도구 범위
   ▼
자산 관리기
   │ 2. 보호 자산•비신뢰 입력 경로
   ▼
위험 매핑기
   │ 3. 공격 시나리오•LLM 위험 항목
   ▼
통제 검증기
   │ 4. 통제 시험•잔여 위험
   ▼
서비스•위험 책임자
   └ 5. 보완 우선순위•재검증 조건
```

### 동작 원리

1. **모델•데이터•검색•도구 범위**: LLM 응용의 평가 경계를 확정함.
2. **보호 자산•비신뢰 입력 경로**: 위험이 전파될 접점을 식별함.
3. **공격 시나리오•LLM 위험 항목**: 2025판 번호•명칭으로 분류함.
4. **통제 시험•잔여 위험**: 실제 공격으로 예방•탐지•복구를 검증함.
5. **보완 우선순위•재검증 조건**: 통제 공백과 변경 영향을 갱신함.

#### 한줄 요약

- 위험•담당 통제를 매핑하고 공격 시험으로 **잔여 위험** 판정

## Ⅴ. 종류 및 비교

<details>
<summary>용어 설명</summary>

- **2023/24판**: 초기 LLM 응용 위험을 분류한 이전 OWASP LLM Top 10 판본 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **2025판**: 애플리케이션•운영 위험을 재분류하고 최신 번호•명칭을 부여한 판본 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

OWASP LLM Top 10은 판본별 번호와 명칭을 함께 관리한다.

| OWASP LLM Top 10 판본 | 2023/24판 | 2025판 |
|:---|:---|:---|
| 적용 기준 | 기존 평가의 **식별자 해석** | 현재 서비스의 **통제 매핑** |
| 핵심 특징 | 초기 **LLM 위험 분류** | 앱•운영 위험의 **재분류** |
| 한계 | 최신 위험•**명칭 누락** | 이전 번호와 **혼용 위험** |

#### 한줄 요약

- 판본별 번호•명칭 차이와 **위험 재분류** 비교

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>용어 설명</summary>

- **번호•명칭 혼용**: 서로 다른 판본의 식별자와 위험 이름을 섞어 통제 추적이 어긋나는 문제 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **연쇄 누락**: 하나의 공격이 여러 위험 경계를 통과하는데 단일 항목만 점검해 전파 경로를 놓치는 문제 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **형식적 준수**: 위험 목록을 체크하는 데 그치고 실제 공격으로 통제 효과를 검증하지 않는 문제 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 판본의 **번호•명칭 혼용** | **2025판 식별자•항목명** 함께 기록 | 위험 **추적 오류 방지** |
| 단일 위험 중심의 **연쇄 누락** | 데이터 흐름별 **복수 항목 매핑** | 공격 **전파 경로 식별** |
| 목록 점검으로 **통제 검증 대체** | 실제 공격 기반 **통제 시험** 수행 | **형식적 준수 방지** |

#### 한줄 요약

- 데이터•권한 흐름에 **복수 위험•담당 통제** 매핑

## Ⅶ. 결론

<details>
<summary>용어 설명</summary>

- **서비스 데이터 흐름**: 입력부터 검색•모델•출력•도구까지 데이터와 권한이 이동하는 경로 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **통제 시험**: 실제 공격 시나리오를 실행해 예방•탐지•복구 조치가 작동하는지 확인하는 평가 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

- 현재 서비스에는 **2025판 항목**을 매핑하고 실제 공격으로 통제 판정

#### 한줄 요약

- 최신 식별자로 **통제 책임자•재검증 조건** 결정
