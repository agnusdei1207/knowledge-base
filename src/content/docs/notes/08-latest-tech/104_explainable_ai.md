## 미리 알고가기

- **XAI**: AI 판단 근거를 사람이 이해하도록 제공하는 기술
- **설명 범위**: 개별 예측(Local)과 모델 전체(Global)로 구분
- **평가 기준**: 직관성 외 모델 충실도도 함께 평가 필요



## Ⅰ. 개요

- **정의/개념**: AI 동작·출력 근거를 이해 가능한 형태로 표현
- **배경/필요성**: 오류 분석·이의제기·감사를 위한 근거 제공

### 쉽게 이해하기 (학습용)
- 결과에 영향을 준 규칙·특징·사례를 사용 목적에 맞게 사람이 이해할 수 있도록 보여 줍니다.

## Ⅱ. 특징

- 모델 자체 해석과 사후 설명 방식으로 구분한다.
- 개별 출력의 국소 설명과 전체 전역 설명으로 나뉜다.
- 충실도·안정성·수신자 이해도로 품질을 평가한다.
- 설명만으로 공정성·안전성을 증명할 수 없다.

### 쉽게 이해하기 (학습용)
- 설명이 원래 모델 판단을 충실히 반영하는지와 작은 변화에도 지나치게 흔들리지 않는지 검증합니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 설명 모델 | 동작 또는 출력 근거를 분석할 시스템 |
| 설명 범위 | 출력 개별 또는 전체 모델 중 설명할 범위 |
| 설명 기법 | 규칙·기여도·사례 등 근거 산출 방법 |
| 설명 산출물 | 사용자 역할·목적에 맞는 근거 표현 |
| 품질 평가 | 충실도·안정성·이해도로 한계 판정 |

### 쉽게 이해하기 (학습용)
- 누구에게 어떤 결정을 어느 범위로 설명하고 품질을 어떻게 검증할지 정합니다.

## Ⅳ. 원리 및 절차 흐름도

```text
목적정의
   ↓
범위선택
   ↓
기법적용
   ↓
품질평가
   ↓
사람검토
```

| 절차 | 설명 |
|:---|:---|
| 목적정의 | 오류 분석·이의제기 목적과 수신 역할을 정함 |
| 범위선택 | 국소 또는 전역 범위와 기법을 선택함 |
| 기법적용 | 규칙·기여도·사례 등으로 근거를 산출함 |
| 품질평가 | 충실도·안정성·이해도를 검증함 |
| 사람검토 | 품질 충족 시 설명을 판단 보조로 제공함 |

### 쉽게 이해하기 (학습용)
- 목적에 맞는 설명을 만들고 원모델 충실도와 안정성을 확인해 사람의 판단을 돕습니다.

## Ⅴ. 종류 및 비교

| 판단 기준 | 국소 설명 | 전역 설명 |
|:---|:---|:---|
| 설명 대상 | 개별 예측 근거 설명 | 모델 전체 동작 경향 설명 |
| 주요 산출물 | 기여도·사례·국소 규칙 | 중요도·의존 관계·대표 규칙 |
| 적용 기준 | 개별 결정 검토·이의제기 | 모델 선택·편향 조사·감시 |

> 요약: 설명 목적에 따른 범위 선택 필요

### 쉽게 이해하기 (학습용)
- 국소 설명은 개별 결과의 근거를, 전역 설명은 모델 전체의 동작 경향을 보여 줍니다.

## Ⅵ. 실무 사례

- 대출 심사는 거절 특징과 변경 조건으로 재심을 돕는다.
- 장애 예측은 전역 중요도 변화로 새 상관을 조사한다.

### 쉽게 이해하기 (학습용)
- 설명은 담당자의 재심을 돕지만 그 자체로 모델에 차별이나 오류가 없음을 보장하지 않습니다.

## Ⅶ. 결론

- 목적별 설명의 충실도·안정성·이해도를 검증한다.

### 쉽게 이해하기 (학습용)
- 설명은 판단과 위험 평가를 돕는 증거일 뿐 모델이 안전하다는 보증서는 아닙니다.
