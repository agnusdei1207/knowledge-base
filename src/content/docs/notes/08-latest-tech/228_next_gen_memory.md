## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **차세대 메모리 기술(Next-Generation Memory Technologies)**: 전통적인 폰 노이만 구조의 메모리 계층 한계를 극복하기 위해 3차원 적층 대역폭 극대화(HBM), 인터커넥트 기반 용량 확장 및 풀링(CXL), 메모리 내부 직접 연산(PIM/PNM)을 융합한 지능형·이기종 메모리 아키텍처.
- **고대역폭 메모리(High Bandwidth Memory, HBM)**: 복수의 DRAM 코어 다이를 TSV로 수직 적층하고 실리콘 인터포저의 1024비트 이상 초광폭 버스로 GPU/AI 가속기에 테라바이트급 대역폭을 공급하는 3D 스택 메모리.
- **컴퓨트 익스프레스 링크(Compute Express Link, CXL)**: 고속 PCIe 물리 계층을 기반으로 호스트 프로세서, 가속기, 메모리 확장 장치 간에 I/O, 캐시 일관성, 메모리 공유 의미론을 단일 링크로 제공하는 차세대 개방형 인터커넥트 표준.
- **메모리 내 처리(Processing-in-Memory, PIM)**: DRAM 메모리 셀 어레이 또는 뱅크(Bank) 내부에 연산 유닛(ALU/MAC)을 직접 집적하여 프로세서-메모리 간의 대규모 데이터 이동을 원천 제거하는 지능형 컴퓨팅 아키텍처.
- **근접 메모리 처리(Processing-Near-Memory, PNM)**: 메모리 셀 내부가 아닌 메모리 모듈 인터페이스 또는 컨트롤러 레벨에 연산 가속기를 근접 배치하여 데이터 전송 병목을 줄이는 아키텍처.
- **실리콘 관통 전극(Through-Silicon Via, TSV)**: 실리콘 다이를 수직으로 관통하는 미세 전극을 형성하여 상하 적층된 다이 간 최단 전기적 신호 경로를 제공하는 3D 패키징 배선 기술.
- **메모리 벽(Memory Wall)**: 프로세서의 연산 처리 속도 발전율에 비해 메인 메모리(DRAM)의 버스 대역폭 및 지연시간 개선 속도가 따라가지 못해 시스템 전체 성능이 메모리 전송에서 병목되는 현상.
- **폰 노이만 병목(Von Neumann Bottleneck)**: 중앙처리장치(CPU/GPU)와 메모리가 물리적으로 분리된 버스를 통해 명령과 데이터를 순차 교환하는 구조에서 발생하는 데이터 전송 지연 및 전력 소모 한계.

</details>

- 정의/개념: AI·빅데이터 연산의 메모리 벽을 해소하기 위해 **HBM(초고대역폭), CXL(풀링·확장), PIM(인메모리 연산)**을 상호보완적으로 융합한 **차세대 메모리 아키텍처 기술**
- 배경/필요성: 기존 PCB 평면 실장(DDR/GDDR) 인터페이스의 핀 수 및 신호 무결성 한계로 인한 초광폭 대역폭 확보 불가, 서버별 DRAM 고정 슬롯 할당에 따른 극심한 메모리 좌초(Stranded Memory) 오버헤드, 프로세서-메모리 간 대규모 데이터 왕복 전송 시 수반되는 막대한 에너지 낭비와 전력 벽(Power Wall)을 극복하고 **초거대 AI 모델의 서빙 비용 절감과 시스템 단위 에너지 효율 극대화**를 실현할 필요

#### 한줄 요약
- 차세대 메모리 기술은 대역폭 병목을 뚫는 HBM, 용량 제약을 푸는 CXL, 데이터 이동을 없애는 PIM을 결합하여 전통적 메모리 계층을 메모리 중심 컴퓨팅(Memory-Centric Computing)으로 재편하는 기술 체계이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **초광폭 병렬 인터페이스(Ultra-Wide Parallel Interface)**: 1024비트 이상의 광폭 버스를 실리콘 인터포저 위에 배치하여 개별 핀 주파수 상승 없이도 테라바이트급 총 대역폭을 달성하는 신호 전송 구조.
- **캐시 일관성 풀링(Cache-Coherent Pooling)**: CXL 프로토콜을 통해 여러 호스트 프로세서가 외부 메모리 풀을 동일한 물리 주소 공간으로 인식하며 하드웨어 일관성을 유지하는 공유 기술.
- **근접 인메모리 연산(Near-Data Processing, NDP)**: 데이터를 중앙 프로세서로 인출하지 않고 DRAM 셀 어레이 내부 또는 컨트롤러 근처에서 연산을 직접 처리하는 데이터 중심 컴퓨팅 패러다임.
- **메모리 좌초(Stranded Memory)**: 특정 서버 노드 내부의 여유 메모리가 다른 노드에 공유되지 못하고 물리적 경계에 갇혀 낭비되는 자원 비효율 현상.

</details>

- **HBM의 대역폭 극대화**: TSV 수직 적층 및 1024비트 광폭 인터페이스로 초당 수 테라바이트(**TB/s급 대역폭**) 공급
- **CXL의 용량 확장 및 풀링**: PCIe 패브릭 기반 캐시 일관성 지원으로 **메모리 좌초 방지** 및 페타바이트급 풀링 실현
- **PIM의 데이터 이동 제거**: 메모리 뱅크 내부에 연산기를 통합하여 프로세서 왕복 트래픽 및 **전송 전력 대폭 절감**
- **이기종 메모리 계층 다변화**: 단일 피라미드 구조를 넘어 **대역폭·용량·연산 특화 계층**으로 메모리 서브시스템 분화

#### 한줄 요약
- HBM은 속도, CXL은 용량 확장, PIM은 이동 전력 절감을 전담하며 워크로드 특성에 따라 최적의 메모리 경로를 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **실리콘 인터포저(Silicon Interposer)**: 프로세서 다이(GPU/NPU)와 HBM 스택 다이 사이에 미세 피치 배선을 형성하여 초광폭 신호 전송을 중계하는 2.5D 패키징 기판.
- **CXL 컨트롤러(CXL Controller)**: PCIe 물리 계층 위에서 CXL.io, CXL.cache, CXL.mem 프로토콜을 처리하여 호스트와 메모리 풀 간 통신을 제어하는 하드웨어 엔진.
- **PIM ALU(PIM Arithmetic Logic Unit)**: DRAM 코어 다이의 뱅크(Bank) 내부에 내장되어 벡터 곱셈·누적(MAC) 및 활성화 함수를 직접 연산하는 유닛.
- **메모리 계층화 관리자(Memory Tiering Manager)**: 데이터 접근 빈도(Hot/Cold)를 감지하여 고속 HBM과 대용량 CXL 풀 간의 페이지 마이그레이션을 조율하는 시스템 소프트웨어.

</details>

```text
차세대 메모리 컴퓨팅 아키텍처
├── [초고속 연산 계층]
│   ├── GPU / NPU 가속기 코어
│   └── HBM 스택: 2.5D 인터포저 직결 초광폭 버스 (TB/s 대역폭 공급)
├── [인메모리 처리 계층]
│   └── PIM / PNM 모듈: DRAM 내부 ALU/MAC 집적 (데이터 이동 최소화)
└── [대용량 풀링 계층]
    ├── CXL 스위치: PCIe 5.0/6.0 패브릭 기반 이종 호스트 상호연결
    └── CXL 메모리 풀: 노드 간 동적 할당 및 공유 (대용량 확장)
```

선의 의미: 가지(`├──`, `└──`)는 상위 초고속 가속 계층부터 하위 대용량 풀링 계층까지의 메모리 서브시스템 포함 및 연계 관계를 나타냄

| 구성요소 | 책임 |
|:---|:---|
| **HBM 스택** | 가속기 코어에 2.5D 인터포저로 직결되어 **초고대역폭 메모리** 공급 |
| **PIM 모듈** | DRAM 내부 뱅크 단위 연산기로 **데이터 이동 오버헤드 원천 제거** |
| **CXL 스위치** | 패브릭 기반으로 복수 노드 간 **캐시 일관성 메모리 풀링** 중계 |
| **CXL 확장 메모리** | PCIe 슬롯을 통해 서버 메모리 용량을 **동적으로 대규모 확장** |
| **계층화 관리자** | 핫/콜드 데이터 접근 패턴에 따른 **동적 페이지 마이그레이션** 수행 |

#### 한줄 요약
- 프로세서와 직결되는 HBM, 내부 연산을 맡는 PIM, 네트워크처럼 묶이는 CXL이 융합되어 각기 다른 계층에서 메모리 병목을 해소한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **워크로드 프로파일러(Workload Profiler)**: 실행 중인 AI/빅데이터 작업의 산술 연산 강도(Operational Intensity)와 메모리 접근 패턴을 실시간 분석하는 엔진.
- **메모리 바운드(Memory-Bound)**: 연산 유닛의 처리 능력보다 메모리 데이터 공급 속도가 느려 전체 성능이 메모리 접근에 종속되는 상태.
- **컴퓨트 바운드(Compute-Bound)**: 메모리 공급 속도보다 프로세서의 연산 능력이 포화되어 성능이 연산량에 종속되는 상태.

</details>

```text
워크로드 실행 요청 수신
         │
         ▼
1. 연산 특성 및 메모리 요구량 프로파일링
   ┌─────────────────────┼─────────────────────┐
[ 초고대역폭 집중 ]     [ 대규모 용량 필요 ]   [ 단순 반복 대량 연산 ]
   │                     │                     │
   ▼                     ▼                     ▼
2. HBM 전용 할당       3. CXL 풀 메모리 매핑   4. PIM 연산 오프로딩
(가속기 온패키지 직결)  (PCIe 캐시 일관성 확장) (DRAM 내부 ALU 직접 계산)
   │                     │                     │
   └─────────────────────┼─────────────────────┘
                         ▼
5. 계층화 관리자: 핫/콜드 데이터 동적 마이그레이션 및 결과 반환
```

분기 결과: **초고대역폭** 요구 시 HBM으로 즉시 라우팅되고, **대규모 용량** 요구 시 CXL 풀로 확장 매핑되며, **메모리 바운드 연산**은 PIM 내부로 오프로딩되어 프로세서 개입 없이 완료됨

**동작 원리**

1. **연산 특성 및 메모리 요구량 프로파일링**: 작업의 산술 강도와 필요 용량 측정
2. **HBM 전용 할당**: 어텐션 및 가중치 행렬을 온패키지 초고대역폭 메모리에 적재
3. **CXL 풀 메모리 매핑**: 대규모 KV 캐시 및 임베딩 테이블을 CXL 풀에 동적 할당
4. **PIM 연산 오프로딩**: 단순 벡터 덧셈·활성화 연산을 DRAM 내부 ALU로 직접 전달
5. **계층화 관리자 마이그레이션**: 접근 빈도 변화에 따라 계층 간 데이터를 실시간 재배치

#### 한줄 요약
- 워크로드의 대역폭·용량·연산 특성을 분류하여 HBM, CXL, PIM의 최적 경로로 분기 처리함으로써 전체 시스템 효율을 극대화한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **비트당 비용(Cost per Bit)**: 메모리 단위 용량(1비트)을 구현하고 패키징하는 데 소요되는 제조 및 인프라 비용 지표.
- **대역폭 밀도(Bandwidth Density)**: 단위 면적 또는 칩 패키지 단위당 제공 가능한 메모리 데이터 전송 속도.
- **프로그래밍 모델(Programming Model)**: 개발자가 하드웨어 자원을 제어하기 위해 사용하는 표준 명령어 체계 및 소프트웨어 인터페이스.

</details>

| 메모리 기술 | HBM | CXL | PIM |
|:---|:---|:---|:---|
| **적용 기준** | 초고성능 AI 학습/추론 등 **극단적 대역폭** 필요 시 | 대규모 LLM 서빙 및 **메모리 용량 확장·풀링** 필요 시 | 추천 시스템·벡터 연산 등 **메모리 바운드** 작업 시 |
| **핵심 특징** | **3D TSV 적층** 및 2.5D 인터포저 기반 TB/s 대역폭 | **PCIe 기반 패브릭** 및 캐시 일관성 하드웨어 공유 | **DRAM 뱅크 내부 ALU** 집적으로 데이터 이동 제거 |
| **한계** | 고비용 실리콘 인터포저 및 **제한된 최대 용량** | PCIe 링크 전송에 따른 **DRAM 대비 지연시간 증가** | 전용 ISA 및 **소프트웨어 에코시스템 미성숙** |

#### 한줄 요약
- HBM은 최고 속도, CXL은 무한한 용량 확장, PIM은 데이터 이동 제로라는 고유한 상충 관계(Trade-off)를 가지며 상호보완적이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **하이브리드 본딩(Hybrid Bonding)**: 마이크로범프 없이 구리(Cu) 전극을 직접 접합하여 다이 간 간격을 줄이고 신호 밀도 및 방열 성능을 극대화하는 첨단 패키징 기법.
- **지연 은닉 프리페칭(Latency-Hiding Prefetching)**: CXL 메모리의 추가 접근 지연시간을 감추기 위해 후속 참조 데이터를 사전에 로컬 캐시로 인출하는 하드웨어/소프트웨어 기법.
- **소프트웨어 계층화 오케스트레이션(Software Tiering Orchestration)**: OS 및 런타임 레벨에서 데이터 접근 빈도를 모니터링하여 고속 계층과 확장 계층 간 페이지를 자동 재배치하는 기술.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| HBM 3D 적층에 따른 **발열 집중 및 수율 저하** | **하이브리드 본딩** 및 고급 인터포저 방열 설계 적용 | 열 저항 감소 및 패키징 수율 안정화 |
| CXL 링크 통신에 따른 **추가 접근 지연 오버헤드** | **지연 은닉 프리페칭** 및 핫/콜드 데이터 계층화 적용 | 빈번한 참조 데이터 로컬화로 지연시간 최소화 |
| PIM 전용 명령어 부재로 인한 **소프트웨어 호환성 한계** | 표준 **PIM 라이브러리 및 컴파일러 자동 오프로딩** 구축 | PyTorch 등 프레임워크와의 투명한 소프트웨어 통합 |

#### 한줄 요약
- 실무 도입 시에는 HBM의 방열 한계, CXL의 인터커넥트 지연 오버헤드, PIM의 소프트웨어 지원성을 종합 평가하여 하이브리드 계층화 설계를 적용한다.

## Ⅶ. 결론

- AI 모델의 파라미터 폭증과 데이터 집약적 컴퓨팅 환경에서 **프로세서 중심 구조의 한계를 돌파하고 메모리 중심 컴퓨팅(Memory-Centric Computing)으로의 패러다임 전환을 주도하는 핵심 아키텍처**이며, 초고속 연산을 위한 **HBM**, 대규모 확장 및 공유를 위한 **CXL**, 데이터 이동을 원천 제거하는 **PIM/PNM**이 유기적으로 결합된 하이브리드 메모리 패브릭으로 진화하는 추세에 발맞추어, 실무 구축 시에는 **워크로드 특성별 메모리 계층화 오케스트레이션과 표준 인터페이스 에코시스템의 성숙도**를 종합 고려한 최적화 전략 수립 필요

#### 한줄 요약
- 차세대 메모리 기술은 HBM, CXL, PIM이 상호 결합하여 폰 노이만 병목을 극복하는 컴퓨팅 시스템의 새로운 표준 패러다임이다.
