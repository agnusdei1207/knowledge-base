## 미리 알고가기

- **의미 검색 (Semantic Search)**: 의미 유사성으로 문서 탐색
- **임베딩 (Embedding)**: 질의·문서를 벡터로 변환
- **희소 검색 (Sparse Retrieval)**: 정확한 어휘 신호로 문서 탐색
- **밀집 검색 (Dense Retrieval)**: 임베딩 거리로 의미 후보 탐색
- **RAG (Retrieval-Augmented Generation)**: 의미 검색 결과를 생성 근거로 사용



## Ⅰ. 개요

- **정의/개념**: 질의와 의미가 유사한 문서를 벡터로 검색
- **배경/필요성**: 동의어·우회 표현의 어휘 불일치를 해소

### 쉽게 이해하기 (학습용)

- 표현이 달라도 뜻이 비슷한 질문과 문서를 같은 벡터 공간에서 찾습니다.

## Ⅱ. 특징

- 의미 검색은 목표이고 밀집 임베딩은 대표 구현 방식이다.
- 질의와 문서를 같은 벡터 공간에서 표현해 유사도를 잰다.
- 학습 도메인과 검색 대상이 다르면 벡터 거리가 왜곡된다.
- 제품 코드 같은 식별자는 정확 일치 검색으로 보완한다.

### 쉽게 이해하기 (학습용)

- 낯선 전문 분야나 제품 번호는 의미 검색이 빗나갈 수 있어 정확 검색도 필요합니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 표현 모델 | 질의·문서를 비교 가능한 의미 벡터로 변환 |
| 의미 색인 | 문서 벡터와 식별자 관계 저장 |
| 관련성 함수 | 질의와 문서 간 의미 유사도 계산 |
| 문자열 경로 | 코드·식별자 등 정확 후보 보완 |
| 메타데이터 | 조건 필터로 부적합 후보 제외 |

```text
검색질의
  ↓
의미표현
  ↓
의미색인
  ↓
문자열경로
  ↓
조건필터
```

### 쉽게 이해하기 (학습용)

- 의미 후보에 정확 문자열과 권한 조건을 함께 적용합니다.

## Ⅳ. 원리 및 절차 흐름도

```text
문서표현
↓
질의해석
↓
후보검색
↓
후보병합
↓
순위반환
```

| 절차 | 설명 |
|:---|:---|
| 문서표현 | 문서를 의미 벡터와 식별자로 연결 |
| 질의해석 | 의미 의도와 정확 식별자 구분 |
| 후보검색 | 의미·문자열 후보 각각 검색 |
| 후보병합 | 후보 통합 후 권한·날짜로 필터링 |
| 순위반환 | 관련성 순으로 문서 반환 |

### 쉽게 이해하기 (학습용)

- 의미 후보를 찾고 정확 문자열과 권한 조건으로 보완합니다.

## Ⅴ. 종류 및 비교

| 판단 기준 | 정확 검색 | 희소 검색 | 밀집 검색 |
|:---|:---|:---|:---|
| 관련성 기준 | 문자 일치 | 어휘 가중치 | 임베딩 유사도 |
| 주요 실패 | 변형 누락 | 동의어 누락 | 도메인 거리 왜곡 |
| 적용 기준 | 식별자 표기 시 | 핵심 용어 나타날 때 | 표현보다 의미 중요 시 |

### 쉽게 이해하기 (학습용)

- 문자열·희소·밀집 검색은 관련성을 판단하는 기준이 다릅니다.

## Ⅵ. 실무 사례

- 사내 검색은 자연어는 의미로, 오류 코드는 정확히 검색
- 도메인 전환: 기존 임베딩과 도메인 임베딩의 성능 비교 검증

### 쉽게 이해하기 (학습용)

- 자연어 질문은 의미로 찾고 오류 코드는 정확히 일치시키며 도메인별 성능을 검증합니다.

## Ⅶ. 결론

- 의미 검색은 정확 일치 보완과 도메인 검증을 병행한다.

### 쉽게 이해하기 (학습용)

- 코드·전문용어는 정확 검색으로 보완하고 새 도메인마다 회수 성능을 확인해야 합니다.
