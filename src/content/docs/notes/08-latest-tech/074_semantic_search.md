## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **의미 검색**: 질의와 문서를 벡터화해 표현이 달라도 의미가 가까운 후보를 찾는 검색 방식.
- **밀집 검색(Dense Retrieval)**: 임베딩 공간의 벡터 거리로 문서를 찾는 방식이다.

</details>

- 정의: 질의•문서를 벡터화해 의미가 가까운 후보를 찾는 **의미 검색**
- 배경/필요성: 전통적인 키워드/어휘 일치 검색(Lexical Search)은 질의어와 문서 간의 정확한 형태소 일치에만 의존하므로, 동의어, 유의어, 패러프레이징, 다의어 및 언어적 뉘앙스 차이로 인해 사용자가 표현을 조금만 바꾸어도 관련 문서를 전혀 찾아내지 못하는 어휘 불일치(Vocabulary Mismatch) 문제에 직면함에 따라, 텍스트를 심층 신경망 임베딩 모델을 통해 고차원 잠재 의미 공간(Latent Semantic Space)의 벡터로 인코딩하고 벡터 간 거리/유사도(코사인 유사도 등)를 기반으로 탐색하는 의미 검색(Semantic Search / Dense Retrieval, Embedding Models, Cosine Similarity, ANN Search) 기술을 도입하여 **단어 표기가 달라도 질의의 내재된 맥락과 의도를 정확히 이해하는 고차원 의미 기반 문서 회수, 방대한 고비용 동의어 사전 구축 및 유지보수 부담의 완전한 해소, 자연어 질문에 대한 직관적이고 유연한 엔터프라이즈 정보 검색 경험 제공**을 달성할 필요

#### 한줄 요약
- **공동 벡터 공간**은 표현 차이를 흡수하는 대신 임베딩에 담기지 않은 식별자·수치의 정확 일치를 놓치므로, 의미 회수율을 얻고 정밀 일치를 내주는 교환이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **임베딩**: 질의나 문서의 의미 특징을 계산 가능한 고차원 벡터로 변환한 표현.
- **근사 최근접 이웃(Approximate Nearest Neighbor, ANN)**: 전체 벡터를 정확히 비교하는 대신 가까운 후보를 빠르게 찾는 색인 기법.

</details>

- **공동 의미 벡터 공간**: 질의•문서 표현 정렬
- **벡터 유사도•ANN 색인**: 가까운 후보의 근사 탐색
- **희소•정확 검색 보완**: 도메인•식별자 누락 보정

#### 한줄 요약

- 전문용어•식별자는 **정확 검색** 기반 보완

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **표현 모델**: 질의와 문서를 같은 의미 벡터 공간으로 변환하는 모델이다.
- **유사도 함수**: 질의 벡터와 문서 벡터가 의미상 가까운 정도를 계산하는 함수.
- **메타데이터 필터**: 권한•기간•문서 유형으로 후보를 제한하는 구성요소이다.

</details>

```text
               [표현 모델]-----[의미 색인]-----[유사도 함수]
                                      |
                              [문자열 경로]-----[메타데이터 필터]
```

선의 의미: 표현 모델과 의미 색인•유사도 함수가 공동 벡터 공간을 구성하고, 문자열 경로와 메타데이터 필터가 의미 후보의 식별자•접근 조건을 보완한다.

| 구성요소 | 책임 |
|:---|:---|
| 표현 모델 | 질의•문서를 **의미 벡터**로 변환 |
| 의미 색인 | **문서 벡터•식별자 관계** 저장 |
| 유사도 함수 | **질의•문서 의미 유사도** 계산 |
| 문자열 경로 | **코드•식별자 정확 후보** 보완 |
| 메타데이터 필터 | 조건으로 **부적합 후보** 제외 |


#### 한줄 요약
- **표현 모델•의미 색인**과 유사도•문자열•필터 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **벡터 색인**: 문서 임베딩을 저장하고 가까운 벡터를 효율적으로 조회하도록 만든 구조로 정의된다.
- **후보 회수율**: 실제 관련 문서 가운데 근사 최근접 이웃(Approximate Nearest Neighbor, ANN) 검색 후보에 포함된 문서의 비율.

</details>

```text
표현 모델
   │ 1. 문서 벡터 저장
   │ 2. 질의 벡터 탐색
   ▼
의미 색인
   │ 3. 근사 이웃 후보 전달
   ▼
관련성 함수
   │ 4. 유사도 순위•조건 필터
   ▼
메타데이터 필터
   └── 허용 문서 순위 ──▶ 질의 처리기
```

### 동작 원리

1. 문서 벡터 저장: 문서 의미를 **공동 벡터 공간**에 배치
2. 질의 벡터 탐색: 질의 의도를 **임베딩 벡터**로 변환
3. 근사 이웃 후보 전달: ANN 기반 **탐색 범위** 축소
4. 유사도 순위•조건 필터: 의미 거리와 **메타데이터 조건** 결합

#### 한줄 요약
- **벡터 저장•질의 탐색** 후 ANN•조건 필터 수행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **정확 검색**: 문자나 식별자의 완전•부분 일치로 문서를 찾는 방식이다.
- **희소 검색**: 단어 빈도와 희귀도 같은 어휘 신호를 사용해 문서를 찾는 방식이다.

</details>

| 검색 방식 | 의미 검색 | 정확 검색 | 희소 검색 |
|:---|:---|:---|:---|
| 적용 기준 | 표현보다 **의미** 중요 | **식별자 표기** 중요 | **핵심 용어** 출현 |
| 핵심 특징 | 임베딩 **의미 유사도** | 문자열 **완전•부분 일치** | 어휘 **빈도**•**희귀도** |
| 한계 | 도메인 **거리 왜곡** | 표기 **변형 누락** | 동의어•**의도 누락** |

#### 한줄 요약
- **문자 일치•의미 유사성**과 어휘 신호에 따라 검색 방식 구분

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **도메인 불일치**: 임베딩 학습 분야와 실제 문서 분야 차이로 거리가 왜곡되는 문제이다.
- **식별자 누락**: 코드나 고유명사의 정확한 문자열 신호를 의미 검색이 놓치는 문제.
- **과도한 탐색 축소**: ANN 설정이 후보 범위를 지나치게 줄여 관련 문서를 제외하는 문제로 정의된다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 도메인 불일치 | 도메인 평가셋으로 **표현 모델 선택** | 의미 **거리 왜곡 감소** |
| 고유명사•**식별자 누락** | **정확•희소 검색 후보 결합** | **식별자 회수 보완** |
| ANN의 **과도한 탐색 축소** | 탐색 폭과 **회수율•지연 실측** | 이웃 **누락 통제** |

#### 한줄 요약
- **도메인 불일치•식별자 누락**과 ANN 회수율 검증

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **도메인 평가셋**: 실제 업무 질의와 정답 문서로 검색 성능을 검증하는 자료 집합이다.
- **하이브리드 보완**: 의미 검색에 정확•희소 검색을 결합해 고유명사와 식별자 회수를 높이는 방법.

</details>

- 자연어의 형태소를 넘어 내재된 개념과 문맥적 의도를 탐색하는 현대 인공지능 정보 검색의 중추이자 **생성형 AI RAG 시스템의 핵심 기반 기술(Semantic Search / Dense Embedding Models / Vector Similarity: Cosine & Dot Product / Cross-Lingual Semantic Retrieval / ANN Indexing & Hybrid Search Fallback)의 확고한 표준**으로 확고히 자리 잡았으며, 멀티모달 및 다국어 검색으로 진화하는 가운데, 실무 의미 검색 시스템 구축 시에는 **도메인 특화 용어에 대한 임베딩 왜곡을 방지하기 위한 도메인 적응형 임베딩 모델(Domain-Adapted Embedding) 선별, 코드/식별자/수치 검색의 정확도 누락을 방어하기 위한 BM25 키워드 검색과의 하이브리드 결합, 대규모 코퍼스 실시간 서빙을 위한 고속 ANN 벡터 색인 최적화**를 결합하여 완벽한 문맥 이해력과 안정적인 검색 정확도를 완성

#### 한줄 요약

- **질의 표현•식별자 비중**과 회수율에 따라 검색 방식 결정
