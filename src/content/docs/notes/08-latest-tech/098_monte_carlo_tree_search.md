> **키워드:** 몬테카를로 트리탐색 (Monte Carlo Tree Search)

## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **몬테카를로 트리탐색(MCTS)**: 모의 실행의 보상 통계를 트리에 누적해 제한된 예산으로 유망한 분기를 찾는 탐색 기법이다.
- **분기 폭**: 한 상태에서 선택할 수 있는 자식 행동이나 다음 상태의 수이다.

</details>

- 정의/개념: **MCTS**는 모의 보상 통계를 누적해 유망한 분기를 찾는 트리 탐색
- 배경/필요성: 분기 폭이 큰 트리의 완전 탐색은 **시간·메모리 예산 초과**

### 쉽게 이해하기 (학습용)

- 모의 실행 점수를 노드에 누적해 유망한 갈림길에 더 많은 탐색 예산을 배분합니다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **UCT**: 평균 가치와 방문 횟수 기반 탐험 보너스를 결합해 다음 자식 노드를 선택하는 식이다.
- **역전파**: 롤아웃에서 얻은 보상을 선택 경로의 노드 통계에 거꾸로 누적하는 과정이다.
- **탐색 예산**: 한 의사결정에서 사용할 반복 횟수나 시간의 한도이다.

</details>

![자식 방문 수에 따른 UCT 탐험 보너스](/study/diagrams/uct-exploration-bonus.svg)

> 개념도: 자식 방문 수 증가에 따른 **UCT 탐험 보너스** 감소

- 평균 가치와 미방문 보너스를 함께 고려하는 **UCT 선택 기준**
- 노드 통계를 갱신하는 **선택·확장·시뮬레이션·역전파**
- 종료 후 행동을 결정하는 **탐색 예산·방문 통계**

### 쉽게 이해하기 (학습용)

- 성적이 좋은 길을 더 보면서 덜 가본 길도 시험하지만 모의 방식이 치우치면 결과도 왜곡됩니다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **노드 통계**: 각 상태의 방문 횟수와 누적·평균 보상을 저장한 탐색 정보이다.
- **롤아웃 정책**: 확장한 노드에서 말단 결과까지 모의 행동을 선택하는 규칙이다.
- **탐색 예산 제어기**: 반복 횟수·시간과 종료 조건을 적용해 탐색을 끝내는 구성요소이다.

</details>

```mermaid
block-beta
  columns 3
  tree["탐색 트리"]
  stats["노드 통계 저장소"]
  selector["UCT 선택기"]
  rollout["롤아웃 정책"]
  budget["탐색 예산 제어기"]
  tree --- stats
  stats --- selector
  selector --- rollout
  rollout --- budget
```

| 구성요소 | 책임 |
|:---|:---|
| 탐색 트리 | 상태·행동을 **노드·간선**으로 보관 |
| 노드 통계 저장소 | **방문 횟수·누적 보상** 보관 |
| UCT 선택기 | 평균 가치·**탐험 보너스**로 자식 선택 |
| 롤아웃 정책 | 확장 노드에서 **모의 행동** 수행 |
| 탐색 예산 제어기 | 반복 횟수·시간·**종료 조건** 통제 |

### 쉽게 이해하기 (학습용)

- 갈림길별 방문 횟수와 성적을 기록해 다음 탐색 경로를 정합니다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **선택**: UCT 점수를 기준으로 루트에서 확장할 노드까지 경로를 고르는 단계이다.
- **확장**: 아직 탐색하지 않은 행동을 새 자식 노드로 트리에 추가하는 단계이다.
- **롤아웃**: 확장 노드부터 모의 정책을 실행해 말단 보상을 추정하는 단계이다.

</details>

```mermaid
sequenceDiagram
  participant T as 탐색 트리
  participant U as UCT 선택기
  participant R as 롤아웃 정책
  participant S as 노드 통계 저장소
  loop 탐색 예산까지
    U->>T: 1. UCT 기반 경로 선택
    T->>R: 2. 미탐색 자식 확장
    R->>S: 3. 롤아웃 보상
    S-->>T: 4. 방문·보상 역전파
  end
```

**동작 원리**

1. **UCT 기반 경로 선택**: 활용 가치와 미방문 탐험 보너스 균형
2. **미탐색 자식 확장**: 선택 노드의 새 행동을 트리에 추가
3. **롤아웃 보상**: 모의 정책으로 말단 결과의 가치 추정
4. **방문·보상 역전파**: 선택 경로의 방문 수·평균 가치 갱신

### 쉽게 이해하기 (학습용)

- 선택한 경로를 모의 실행하고 얻은 점수를 루트까지 역전파합니다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **미니맥스**: 상대가 최선으로 대응한다고 가정하고 게임 트리의 값을 역으로 계산하는 탐색 방식이다.
- **신경망 유도 MCTS**: 정책망으로 유망한 행동을, 가치망으로 상태 가치를 추정해 MCTS를 안내하는 방식이다.

</details>

| 탐색 방식 | MCTS | 미니맥스 | 신경망 유도 MCTS |
|:---|:---|:---|:---|
| 적용 기준 | **시뮬레이션·통계** 가능 | **상태 평가함수** 존재 | **학습 모델** 존재 |
| 핵심 특징 | **UCT·롤아웃 통계** | **전개·평가·역전파** | **정책·가치망 유도 탐색** |
| 한계 | **롤아웃 편향·분산** | **분기 폭발·평가 오차** | **학습 편향·연산 비용** |

> 요약: **시뮬레이션·모델 유무**에 따른 탐색 알고리즘 선택

### 쉽게 이해하기 (학습용)

- 평가 함수·모의 통계·학습 모델 중 문제 조건에 맞는 탐색 방식을 고릅니다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **롤아웃 편향**: 모의 정책이 특정 행동이나 결과를 선호해 가치 추정이 실제보다 치우치는 문제이다.
- **탐험 상수**: UCT에서 미방문 분기에 부여하는 탐험 보너스의 크기를 조절하는 값이다.
- **가치 안정도**: 탐색을 추가해도 노드 평균 가치와 최선 행동이 크게 변하지 않는 정도이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **롤아웃 정책 편향** | 복수 정책·도메인 규칙으로 **모의 보상** 검증 | 가치 추정의 **왜곡 완화** |
| **탐험 상수 민감도** | 문제별 **UCT 탐험 계수** 검증 | **활용·탐험 균형** |
| **탐색 예산 부족** | 방문 수·가치 안정도 기반 **종료 조건** | 불안정한 **행동 선택 감소** |

### 쉽게 이해하기 (학습용)

- 여러 복구 순서와 이동 경로를 가상으로 시험하고 누적 결과로 다음 행동을 정합니다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **롤아웃 신뢰도**: 모의 정책이 실제 결과의 상대적 가치를 일관되게 추정하는 정도이다.
- **행동 선택 안정성**: 탐색 예산이나 무작위성 변화에도 최종 선택 행동이 유지되는 정도이다.

</details>

- 롤아웃 신뢰도·탐색 예산을 보고 **MCTS 적용** 여부와 **UCT 탐험 계수** 결정

### 쉽게 이해하기 (학습용)

- 모의 횟수가 적거나 정책이 치우치면 유망해 보인 경로가 실제 최선이 아닐 수 있습니다.
