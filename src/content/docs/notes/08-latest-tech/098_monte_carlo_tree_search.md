## 미리 알고가기

- **몬테카를로 트리탐색(Monte Carlo Tree Search, MCTS)**: 보상 통계로 유망한 분기를 탐색함
- **트리 상한 신뢰구간(Upper Confidence Bounds Applied to Trees, UCT)**: 탐험과 활용을 조절함



## Ⅰ. 개요

- **정의/개념**: 모의 보상으로 유망한 분기를 찾는 트리 탐색
- **배경/필요성**: 제한된 계산량으로 큰 행동 공간을 탐색

### 쉽게 이해하기 (학습용)

- 모의 실행 점수를 노드에 누적해 유망한 갈림길에 더 많은 탐색 예산을 배분합니다.

## Ⅱ. 특징

- UCT가 평균 보상과 낮은 방문 수를 함께 고려한다.
- 선택·확장·모의·역전파로 노드 통계를 갱신한다.
- 탐색 예산이 끝나면 방문·가치 통계로 행동을 고른다.
- 편향된 롤아웃과 적은 표본은 가치 추정을 왜곡한다.

### 쉽게 이해하기 (학습용)

- 성적이 좋은 길을 더 보면서 덜 가본 길도 시험하지만 모의 방식이 치우치면 결과도 왜곡됩니다.

## Ⅲ. 구성요소 및 구조

| 구성요소 | 핵심 키워드 | 직관적 설명 |
|:---|:---|:---|
| 탐색트리 | 상태·행동저장 | 트리 노드·간선 구성 |
| 노드통계 | 방문·보상값 | 성적·방문 횟수 기록 |
| UCT기준 | 평균·보너스 | 탐험·활용 조절식 |
| 탐색정책 | 확장·롤아웃 | 행동 선택 규칙 |
| 탐색예산 | 반복·시간제한 | 계산량 통제 기준 |

### 쉽게 이해하기 (학습용)

- 갈림길별 방문 횟수와 성적을 기록해 다음 탐색 경로를 정합니다.

## Ⅳ. 원리 및 절차 흐름도

```text
노드선택
  ↓
자식확장
  ↓
보상모의
  ↓
통계역전파
```

| 절차 | 설명 |
|:---|:---|
| 노드선택 | UCT 기반 유망 자식 선택함 |
| 자식확장 | 미탐색 행동 노드 추가함 |
| 보상모의 | 롤아웃으로 보상 추정함 |
| 통계역전파 | 경로 방문·보상 갱신함 |

### 쉽게 이해하기 (학습용)

- 선택한 경로를 모의 실행하고 얻은 점수를 루트까지 역전파합니다.

## Ⅴ. 종류 및 비교

| 판단 기준 | 미니맥스 | MCTS | 신경망 유도 MCTS |
|:---|:---|:---|:---|
| 탐색 기준 | 제한 깊이 평가값 | UCT와 모의 보상 | 정책·가치 추정값 |
| 주요 오차 | 깊이 제한 평가오차 | 롤아웃 편향·분산 | 미학습 시 추정 편향 |
| 적용 기준 | 상태 평가함수 존재 | 시뮬레이션·통계 가능 | 학습 모델 존재 시 |

> 요약: 시뮬레이션 및 모델 유무에 따라 탐색 알고리즘을 선택함

### 쉽게 이해하기 (학습용)

- 평가 함수·모의 통계·학습 모델 중 문제 조건에 맞는 탐색 방식을 고릅니다.

## Ⅵ. 실무 사례

- 복구 에이전트는 전환 순서를 모의해 행동을 고른다.
- 로봇은 충돌 없는 경로 보상을 역전파해 이동한다.

### 쉽게 이해하기 (학습용)

- 여러 복구 순서와 이동 경로를 가상으로 시험하고 누적 결과로 다음 행동을 정합니다.

## Ⅶ. 결론

- 탐색 예산과 UCT·롤아웃 편향을 함께 검증한다.

### 쉽게 이해하기 (학습용)

- 모의 횟수가 적거나 정책이 치우치면 유망해 보인 경로가 실제 최선이 아닐 수 있습니다.
