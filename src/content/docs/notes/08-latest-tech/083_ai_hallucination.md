## 미리 알고가기

- **환각 (Hallucination)**: 사실과 다르거나 근거가 없는 모델 출력
- **사실성 (Factuality)**: 출력이 외부의 검증 가능한 사실과 일치하는 정도
- **충실성 (Faithfulness)**: 출력 주장이 제공된 문맥으로 뒷받침되는 정도
- **근거 귀속 (Attribution)**: 주장과 이를 지지하는 출처를 연결하는 과정

## Ⅰ. 개요

- **정의/개념**: 사실과 다르거나 근거 없는 내용을 생성
- **배경/필요성**: 유창한 오류의 주장별 근거와 사실 검증

### 쉽게 이해하기 (학습용)

- 근거 없는 내용을 사실처럼 자연스럽게 말해 사용자의 오해를 유발합니다.

## Ⅱ. 특징

- 자연스러운 문장에도 사실 충돌과 근거 없는 주장이 섞인다.
- 사실 충돌·문맥 비지지·도구 오류는 검증 기준이 다르다.
- 모델 출력만 보고 사실 여부와 오류 원인을 단정할 수 없다.
- 완전 제거가 어려워 수정·보류·거절 정책으로 위험을 낮춘다.

### 쉽게 이해하기 (학습용)

- 자신 있는 말투만으로는 판별할 수 없어 주장과 근거를 대조해야 합니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 학습경계 | 학습 시점·데이터 오류 포함함 |
| 질의경계 | 검색 문맥·답변 범위 포함함 |
| 생성설정 | 토큰 선택·출력 길이 결정함 |
| 도구경계 | 실행 기록·오류 상태 포함함 |
| 대응정책 | 수정·보류·거절 조건을 정함 |

### 쉽게 이해하기 (학습용)

- 학습·질의·생성·도구·대응 경계별로 오류 원인을 구분합니다.

## Ⅳ. 원리 및 절차 흐름도

```text
기록보존
↓
주장분해
↓
근거대조
↓
원인진단
↓
대응적용
```

| 절차 | 설명 |
|:---|:---|
| 기록보존 | 데이터·설정·결과 저장함 |
| 주장분해 | 응답을 검증 단위로 분해함 |
| 근거대조 | 외부·문맥·도구와 비교함 |
| 원인진단 | 오류 발생 경계를 추적함 |
| 대응적용 | 수정·보류·거절을 적용함 |

### 쉽게 이해하기 (학습용)

- 응답을 검증 가능한 주장으로 나눠 근거와 대조하고 원인을 추적합니다.

## Ⅴ. 종류 및 비교

| 적용 기준 | 사실 충돌 | 근거 비지지 | 도구 오류 |
|:---|:---|:---|:---|
| 판정 기준 | 외부 사실 모순 | 문맥 도출 불가 | 반환값 왜곡 |
| 진단 경계 | 학습 시점·사전지식 | 검색 누락·문맥 | 도구 호출·전달 |
| 적용 환경 | 일반 사실 답변 | 제공 문서 활용 | 도구 결과 인용 |

> 요약: 사실·근거·도구 오류를 각각 대조하여 진단함

### 쉽게 이해하기 (학습용)

- 외부 사실·제공 문맥·도구 결과를 서로 다른 기준으로 대조합니다.

## Ⅵ. 실무 사례

- 답변 구간이 없으면 추정 문장을 생략하고 답변을 보류함
- 도구 결과를 대조해 불일치 응답은 수정하거나 거절함

### 쉽게 이해하기 (학습용)

- 확인할 수 없는 고위험 답은 추정하지 않고 보류하거나 거절합니다.

## Ⅶ. 결론

- 환각은 주장별 근거 탐지와 경계별 대응 정책을 운영함

### 쉽게 이해하기 (학습용)

- 오류 원인을 추적하고 위험도에 맞춰 수정·보류·거절을 적용합니다.
