## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **인공지능 환각(Artificial Intelligence Hallucination, AI 환각)**: 사실이나 근거와 불일치한 내용을 생성하는 현상이다.

</details>

- 정의: 모델이 사실•근거와 불일치한 내용을 생성하는 **AI 환각**이다.
- 배경/필요성: 다음 토큰 확률만 따르는 생성은 **사실성·충실성 보장 불가**여서 오류 선별 비용을 매 답변마다 사람이 치르므로, 근거 검색과 출처 대조 계층을 생성 앞뒤에 두어 확률적 추정을 검증 가능한 참조에 묶는 접근이 필요

#### 한줄 요약
- 생성 답변의 **사실•문맥•출처 일치성** 검증 필요

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **사실성(Factuality)**: 출력 주장이 검증 가능한 사실과 일치하는 정도이다.
- **충실성(Faithfulness)**: 출력 주장이 제공 문맥으로 뒷받침되는 정도이다.
- **근거 귀속(Attribution)**: 주장과 지지 출처를 연결하는 과정이다.

</details>

- 외부 검증 사실과 충돌하는 **사실성 오류**
- 제공 문맥에 없는 주장을 추가하는 **충실성 오류**
- 주장과 인용 출처가 어긋나는 **근거 귀속 오류**

#### 한줄 요약
- **사실성•충실성•근거 귀속** 오류 구분

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **원자 주장(Atomic Claim)**: 독립적으로 참•거짓을 검증할 수 있는 단일 사실이다.
- **주장 분해기(Claim Decomposer)**: 생성 답변을 원자 주장으로 나눈다.
- **근거 귀속기(Attribution Mapper)**: 주장과 출처•인용 구간을 연결한다.
- **대응 정책(Response Policy)**: 위험에 따라 출력을 수정•보류•거절한다.

</details>

```text
[생성 모델]──[주장 분해기]──[사실 검증기]
                              │
                     [근거 귀속기]──[대응 정책]
```

| 구성요소 | 책임 |
|:---|:---|
| 생성 모델 | 질의•검색 문맥 기반 **후보 답변 생성** |
| 주장 분해기 | 답변을 검증 가능한 **원자 주장** 단위로 분리 |
| 사실 검증기 | 신뢰 출처와 주장의 **외부 사실 대조** |
| 근거 귀속기 | 문맥•인용과 주장의 **지지 관계 판정** |
| 대응 정책 | 오류 위험별 **수정•보류•거절 결정** |

#### 한줄 요약
- **생성•주장 분해•사실 검증•근거 귀속•대응** 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **생성 조건(Generation Condition)**: 입력•문맥•모델•프롬프트•응답의 기록이다.
- **주장 지지 여부(Claim Support)**: 사실과 문맥이 주장을 뒷받침하는지의 판정이다.

</details>

```text
생성 모델
   │ 1. 입력•문맥•응답 기록
   ▼
주장 분해기
   │ 2. 검증 가능 주장 분해
   ▼
사실•근거 검증기
   │ 3. 외부 사실•문맥 대조
   │ 4. 오류 유형•위험 판정
   ▼
대응 정책
   └── 5. 수정•보류•거절 적용 ──▶ 생성 모델
```

### 동작 원리

1. 입력•문맥•응답 기록: 원인 추적을 위한 **생성 조건** 보존
2. 검증 가능 주장 분해: 복합 답변을 **원자 주장**으로 분리
3. 외부 사실•문맥 대조: 사실·근거의 **주장 지지 여부** 확인
4. 오류 유형•위험 판정: 오류 유형과 **업무 영향** 분류
5. 수정•보류•거절 적용: 위험 수준별 **출력 통제** 실행

#### 한줄 요약
- **기록•주장 분해•근거 대조•위험 판정•출력 통제** 수행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **사실성 오류(Factuality Error)**: 출력 주장이 외부 사실과 충돌한 오류이다.
- **충실성 오류(Faithfulness Error)**: 출력 주장이 제공 문맥의 지지를 받지 못한 오류이다.
- **귀속 오류(Attribution Error)**: 인용과 주장의 지지 연결이 잘못된 오류이다.

</details>

| 구분 | 사실성 오류 | 충실성 오류 | 귀속 오류 |
|:---|:---|:---|:---|
| 적용 기준 | **외부 사실 응답** | **제공 문맥 기반 응답** | **출처 인용 응답** |
| 핵심 특징 | 검증 사실과 **주장 충돌** | 문맥의 **주장 지지 부재** | 인용과 **주장 연결 오류** |
| 한계 | **신뢰 기준 사실** 필요 | **충분한 기준 문맥** 필요 | **출처 단위 추적** 필요 |

#### 한줄 요약
- 외부 사실·제공 문맥·인용 지지에 따른 **오류 구분**

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **검색 증강 생성(Retrieval-Augmented Generation, RAG)**: 검색 문서를 생성 답변의 근거로 제공한다.
- **출처 장식형 답변(Citation Decoration)**: 인용이 실제 주장을 지지하지 않는 답변이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 복합 문장의 오류 주장 은폐 | 원자 주장별 **사실 검증** | 부분 환각의 **탐지율 향상** |
| 검색 문맥 부족과 충실성 오판 | 근거 부재와 **생성 오류 분리** | 검색·생성 실패의 **정확한 귀속** |
| 인용 존재만 확인한 귀속 오류 | 주장별 **인용 구간·지지 검증** | 출처 장식형 답변 **차단** |

#### 한줄 요약
- **원자 주장•검색 문맥•인용 지지 관계** 검증

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **출력 통제 수준(Output-control Level)**: 위험에 따른 수정•인간 검토•거절 단계이다.

</details>

- 사실•문맥•출처 불일치와 위험도로 **환각 대응•출력 통제 수준** 결정

#### 한줄 요약
- **오류 유형•업무 위험** 대상 따라 수정•보류•거절 결정
