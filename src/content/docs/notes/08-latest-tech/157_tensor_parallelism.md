## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **텐서 병렬(Tensor Parallelism, TP)**: 한 모델 층의 가중치와 연산을 텐서 축으로 나누어 여러 장치가 공동 계산하는 병렬화 기법이다.
- **텐서 축**: 행•열•특징 차원처럼 텐서를 분할할 기준이 되는 방향이다.

</details>

- 정의/개념: 한 모델 층의 가중치와 행렬 연산을 텐서 축으로 나누어 여러 장치가 공동 계산하는 **TP 기법**이다.
- 배경/필요성: 거대 층의 **단일 장치 메모리•연산 용량** 초과 대응이 필요하다.

#### 한줄 요약

- 한 판재를 방향에 따라 잘라 여러 사람이 동시에 가공하는 방식이다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **집단 통신(Collective Communication)**: 여러 장치가 분할 결과를 공동 교환•결합하는 통신이다.
- **올리듀스(All-Reduce)**: 부분값을 축약한 뒤 모든 장치에 같은 결과를 배포하는 연산이다.
- **올개더(All-Gather)**: 장치별 텐서 조각을 교환해 전체 텐서를 구성하는 연산이다.
- **레이아웃**: 텐서의 각 축과 조각이 장치 그룹에 배치된 형태이다.

</details>

- **분할 축**: 행•열 텐서 축 기반 장치별 부분 연산이다.
- **통신 축**: 레이아웃별 올개더•올리듀스 결합한다.
- **배치 축**: 고대역폭 장치 그룹 안에 통신 집중이다.

#### 한줄 요약

- 세로로 자른 결과는 이어 붙이고 가로로 자른 부분 계산값은 합산한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **로컬 행렬곱**: 각 장치가 자신에게 배치된 가중치•활성값 조각으로 계산하는 부분 연산이다.
- **레이아웃 계획기**: 행•열•헤드 등 텐서 분할 축과 각 장치의 가중치•활성값 배치를 결정한다.
- **분할 가중치•활성값**: 같은 층의 행렬과 입력•중간 결과를 텐서 축에 따라 여러 장치에 나눈 조각이다.
- **텐서 병렬 통신 그룹**: 부분 결과를 올리듀스•올개더•리듀스 스캐터로 결합하는 장치 집단이다.
- **분산 자동미분**: 순전파의 분할 레이아웃에 맞춰 역전파 기울기를 계산하고 교환하는 기능이다.

</details>

```text
                    [레이아웃 계획기]
                     /             \
     [분할 가중치•활성값]       [분산 자동미분]
                |                       |
       [로컬 행렬곱 엔진] ----- [텐서 병렬 통신 그룹]
```

선의 의미: 레이아웃 계획기가 데이터 조각의 배치와 분산 자동미분의 기울기 레이아웃을 함께 정하고, 로컬 행렬곱 엔진과 텐서 병렬 통신 그룹이 부분 출력과 기울기를 결합하는 관계를 뜻한다.

| 구성요소 | 책임 |
|:---|:---|
| 레이아웃 계획기 | **다음 연산 입력 기반 분할 차원** 선택 |
| 분할 가중치•활성값 | **장치별 데이터 범위** 정의 |
| 로컬 행렬곱 엔진 | **분할 텐서 부분 출력** 계산 |
| 텐서 병렬 통신 그룹 | **출력•기울기 집단 통신** 수행 |
| 분산 자동미분 | **레이아웃 대응 기울기** 계산•전달 |

#### 한줄 요약

- 세로 조각은 옆으로 이어 완성하고 가로 조각은 각 계산값을 더해 완성하며, 다음 작업이 조각을 그대로 쓸 수 있으면 일부 통신을 미룰 수 있다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **부분 출력**: 각 장치가 로컬 텐서 조각으로 계산한 결과이다.
- **통합 출력**: 부분 출력을 교환•결합해 다음 연산에 전달할 텐서이다.

</details>

```text
레이아웃 계획기
   │ 1. 분할 축•그룹 전달
   ▼
분할 가중치•활성값
   │ 2. 로컬 텐서 조각 전달
   ▼
로컬 행렬곱 엔진
   │ 3. 부분 출력 전달
   ▼
통신 그룹
   │ 4. 통합 출력 전달
   ▼
분산 자동미분
   └── 5. 분할 기울기 전달 ──▶ 로컬 행렬곱 엔진
```

- **1. 분할 축•그룹 전달**: 다음 연산 레이아웃 기반 행•열 축을 결정한다.
- **2. 로컬 텐서 조각 전달**: 장치별 가중치•활성값 범위를 배치한다.
- **3. 부분 출력 전달**: 로컬 행렬곱 결과를 생성한다.
- **4. 통합 출력 전달**: 올개더•올리듀스 기반 다음 입력 완성이다.
- **5. 분할 기울기 전달**: 순전파 레이아웃 대응 역전파를 갱신한다.

#### 한줄 요약

- 다음 공정이 원하는 조각 모양까지 보고 판재를 나눈 뒤 각자 가공하고, 꼭 필요한 시점에만 이어 붙이거나 합산하는 절차이다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **파이프라인 병렬**: 연속 모델 층을 여러 장치 단계에 나누고 활성값•기울기를 전달하는 방식이다.
- **데이터 병렬**: 같은 모델을 여러 장치에 복제하고 입력 배치를 나누어 기울기를 동기화하는 방식이다.

</details>

| 병렬화 방식 | 텐서 병렬 | 파이프라인 병렬 | 데이터 병렬 |
|:---|:---|:---|:---|
| 적용 기준 | **한 층이 장치 용량 초과** | **연속 모델 단계 분할** | **모델 복제본 배치 가능** |
| 핵심 특징 | **텐서 축•연산 분할** | **마이크로배치 단계 중첩** | **배치 분할•기울기 동기화** |
| 한계 | **잦은 집단 통신** | **버블•단계 불균형** | **장치마다 전체 모델 필요** |

> 요약: 연산 분할은 **텐서 병렬**, 계층 분할은 **파이프라인 병렬**이 핵심이다.

#### 한줄 요약

- 한 부품을 함께 가공하면 텐서 병렬, 공정을 나누면 파이프라인 병렬, 같은 설비로 서로 다른 제품을 만들면 데이터 병렬이다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **레이아웃 결합**: 연속 층의 분할 방향을 맞춰 중간 텐서를 완전히 합치는 통신을 줄이는 최적화한다.
- **텐서 병렬 크기(TP Size)**: 하나의 텐서 연산을 공동 처리하도록 묶은 장치 수이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 잦은 집단 통신으로 **연산 대기** 증가 | 연속 층의 열•행 레이아웃 결합 | 중간 **동기화 횟수 감소** |
| 장치 수 증가로 **통신량 우세** | 고대역폭 그룹 내 TP Size 제한 | 연산•통신 **중첩 효율** 확보 |

#### 한줄 요약

- 이어지는 두 가공 작업의 자르는 방향을 맞춰 중간에 전체 판재를 다시 조립하지 않고 마지막에만 결과를 합치는 방식이다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **단일 층 용량**: 한 모델 층의 가중치•활성값•연산 작업 공간이 요구하는 장치 메모리이다.
- **중간 동기화**: 다음 연산 전에 분할된 부분 결과를 교환•결합해 공통 상태를 만드는 과정이다.

</details>

- **단일 층 용량•중간 동기화**에 따라 텐서•파이프라인 병렬을 선택한다.

#### 한줄 요약

- 하나의 큰 계산을 나눠 풀고 필요한 지점에서 결과를 합친다.
