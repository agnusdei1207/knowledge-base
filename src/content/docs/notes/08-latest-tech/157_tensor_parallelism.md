## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **텐서 병렬(Tensor Parallelism, TP)**: 하나의 모델 계층(Layer) 내 가중치와 연산을 텐서 축(Tensor Axis) 방향으로 분할하여 다수의 연산 장치가 공동으로 계산하는 기법.
- **텐서 축(Tensor Axis)**: 행렬 연산을 수행할 때 데이터나 가중치를 행(Row) 또는 열(Column) 방향으로 분할하는 기준 차원.

</details>

- 정의: 한 모델 층의 가중치•연산을 텐서 축으로 나누는 **TP**이다.
- 배경/필요성: 트랜스포머 모델의 Multi-Head Attention(Q, K, V Projections) 및 MLP 블록(GeLU/SwiGLU)은 단일 행렬 크기가 수만x수만 차원에 달해 단일 레이어의 파라미터와 연산 중간 텐서만으로도 단일 GPU 메모리를 완전히 초과하며 계층 분할(PP)만으로는 단일 레이어 내 메모리 한계를 해소할 수 없는 구조적 병목에 직면함에 따라, 각 신경망 레이어 내부의 가중치 행렬을 행(Row) 또는 열(Column) 축으로 분할하여 여러 GPU가 텐서 곱셈을 병렬 수행하는 텐서 병렬화(Tensor Parallelism: TP / Megatron-LM Tensor Slicing, Column/Row Parallel Linear, Sequence Parallelism: SP, All-Reduce/All-Gather Communication Optimization, High-speed NVLink Integration) 기술을 도입하여 **단일 계층 연산과 파라미터 메모리를 GPU 수($TP$)만큼 완벽히 분할(1/TP 메모리 절감), Column Parallel과 Row Parallel을 결합하여 중간 All-Reduce 통신 횟수를 레이어당 1~2회로 최소화하는 계산-통신 최적화, 초고속 NVLink 도메인 내 전역 텐서 분할을 통한 단일 거대 GPU 가상화**를 달성할 필요

#### 한줄 요약

- 텐서 병렬은 계층 단위로 더 나눌 수 없는 층을 **여러 장치가 공동 계산**하게 만드는 대신 층마다 집합 통신을 끼워 넣으므로, 노드 내 고속 링크를 벗어나면 이득이 사라진다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **집단 통신(Collective Communication)**: 다수의 연산 장치가 부분 연산 결과를 교환하고 최종 결과를 결합하는 통신 처리 방식.
- **올리듀스(All-Reduce)**: 참여 장치들의 부분 합산 결과를 교환하여 모든 장치가 최종 합산치를 공유하도록 하는 집단 통신 연산.
- **올개더(All-Gather)**: 각 장치가 보유한 텐서 조각을 교환하여 전체 데이터를 모든 장치가 구성하도록 하는 통신 연산.
- **레이아웃(Layout)**: 텐서의 특정 축과 조각이 연산 장치 그룹 내에 배치되는 물리적 데이터 분포 상태.

</details>

- 행•열 텐서 축 기반 **장치별 부분 연산**
- 레이아웃별 **All-Gather•All-Reduce 결합**
- 고대역폭 장치 그룹 안에 **집단 통신 집중**

#### 한줄 요약

- 행 분할과 열 분할은 **부분 결과 연결•합산** 중 어느 통신을 치를지의 차이이므로, 연속한 두 층의 축을 맞물리면 사이에 놓일 통신 한 번을 통째로 없앨 수 있다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **로컬 행렬곱(Local MatMul)**: 각 연산 장치가 자신에게 할당된 가중치와 활성값 조각을 사용하여 수행하는 부분 행렬 곱셈 연산.
- **분할 가중치 및 활성값(Sharded Weight & Activation)**: 거대 모델의 가중치 행렬과 입력 데이터(활성값)를 텐서 축에 따라 여러 장치에 분산 저장한 데이터 조각.
- **텐서 병렬 통신 그룹(TP Communication Group)**: 부분 행렬 곱셈 연산 후 All-Reduce 또는 All-Gather 등을 통해 최종 결과 또는 다음 연산 입력을 동기화하는 장치 집단.
- **분산 자동미분(Distributed Autograd)**: 분할된 순전파 레이아웃에 대응하여, 역전파 과정에서 필요한 기울기 계산과 연산 장치 간 기울기 교환을 처리하는 자동 미분 엔진.

</details>

```text
[텐서 병렬화 아키텍처]
├── [계획 계층]
│   └── [레이아웃 계획기]
├── [분할 데이터 및 미분]
│   ├── [분할 가중치•활성값]
│   └── [분산 자동미분]
└── [연산 및 통신 그룹]
    ├── [로컬 행렬곱 엔진]
    └── [텐서 병렬 통신 그룹]
```

- 선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 레이아웃 계획기 | **다음 연산 입력 기반 분할 차원** 선택 |
| 분할 가중치•활성값 | **장치별 데이터 범위** 정의 |
| 로컬 행렬곱 엔진 | **분할 텐서 부분 출력** 계산 |
| 텐서 병렬 통신 그룹 | **출력•기울기 집단 통신** 수행 |
| 분산 자동미분 | **레이아웃 대응 기울기** 계산•전달 |

#### 한줄 요약

- 분할 레이아웃을 이어 **부분 출력•기울기 통신** 최소화

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **부분 출력**: 각 장치가 로컬 텐서 조각으로 계산한 결과이다.
- **통합 출력**: 부분 출력을 교환•결합해 다음 연산에 전달할 텐서이다.

</details>

```text
레이아웃 계획기
   │ 1. 분할 축•그룹 전달
   ▼
분할 가중치•활성값
   │ 2. 로컬 텐서 조각 전달
   ▼
로컬 행렬곱 엔진
   │ 3. 부분 출력 전달
   ▼
텐서 병렬 통신 그룹
   │ 4. 통합 출력 전달
   ▼
분산 자동미분
   └── 5. 분할 기울기 전달 ──▶ 로컬 행렬곱 엔진
```

### 동작 원리

1. 분할 축•그룹 전달: 다음 연산 레이아웃 기반 **행•열 축** 결정
2. 로컬 텐서 조각 전달: 장치별 **가중치•활성값 범위** 배치
3. 부분 출력 전달: **로컬 행렬곱 결과** 생성
4. 통합 출력 전달: **All-Gather•All-Reduce** 기반 다음 입력 완성
5. 분할 기울기 전달: 순전파 레이아웃 기반 **역전파**

#### 한줄 요약

- 다음 연산 레이아웃에 맞춰 **분할•부분 계산•통합** 수행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **파이프라인 병렬**: 연속 모델 층을 여러 장치 단계에 나누고 활성값•기울기를 전달하는 방식을 말한다.
- **데이터 병렬**: 같은 모델을 여러 장치에 복제하고 입력 배치를 나누어 기울기를 동기화하는 방식이다.

</details>

| 병렬화 방식 | 텐서 병렬 | 파이프라인 병렬 | 데이터 병렬 |
|:---|:---|:---|:---|
| 적용 기준 | **한 층이 장치 용량 초과** | **연속 모델 단계 분할** | **모델 복제본 배치 가능** |
| 핵심 특징 | **텐서 축•연산 분할** | **마이크로배치 단계 중첩** | **배치 분할•기울기 동기화** |
| 한계 | **잦은 집단 통신** | **버블•단계 불균형** | **장치마다 전체 모델 필요** |

#### 한줄 요약

- 세 방식은 같은 장치 한계를 나누는 해법이지만 통신을 치르는 주기가 연산 단위•계층 경계•반복 끝으로 달라, **병렬화 대상** 선택은 사실상 링크 대역폭이 결정한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **레이아웃 결합**: 연속 층의 분할 방향을 맞춰 중간 텐서의 전체 결합 통신을 줄이는 최적화이다.
- **텐서 병렬 크기(TP Size)**: 하나의 텐서 연산을 공동 처리하도록 묶은 장치 수이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 잦은 집단 통신으로 **연산 대기** 증가 | 연속 층의 **열•행 레이아웃 결합** | 중간 **동기화 횟수 감소** |
| 장치 수 증가로 **통신량 우세** | 고대역폭 그룹 내 **TP Size 제한** | 연산•통신 **중첩 효율** 확보 |

#### 한줄 요약

- 연속 층 레이아웃 결합과 **TP Size 제한** 기반 통신 절감

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **단일 층 용량**: 한 모델 층의 가중치•활성값•연산 작업 공간이 요구하는 장치 메모리로 정의된다.
- **중간 동기화**: 다음 연산 전에 분할된 부분 결과를 교환•결합해 공통 상태를 만드는 과정이다.

</details>

- 초거대 트랜스포머 블록의 단일 계층 메모리 벽을 허물고 레이턴시를 비약적으로 단축하는 **단일 노드 내 텐서 축 분할 및 초고속 병렬 행렬 연산의 최고 표준(Tensor Parallelism / Megatron-LM Column-Row Slicing / Sequence Parallelism: SP Integration / Single-Node NVLink 8-GPU Full Mesh / Intra-node Fast All-Reduce)의 확고한 표준**으로 확고히 자리 잡았으며, 활성화 텐서의 시퀀스 차원까지 분할하는 시퀀스 병렬화(SP)와 결합하여 고도화된 가운데, 실무 초대형 모델 학습 및 서빙 설계 시에는 **초고속 NVLink 패브릭이 보장되는 단일 노드(TP=8 이내) 내에서만 텐서 병렬화를 적용하고, 노드 간 확장은 파이프라인/데이터 병렬화로 위임하며, Self-Attention과 MLP 블록 간 레이아웃 결합을 통해 중간 통신을 최소화**를 결합하여 완벽한 노드 내 텐서 가속과 최고 수준의 MFU를 완성

#### 한줄 요약

- 텐서 병렬은 메모리 부족을 잦은 통신으로 바꾸는 거래이므로, 고속 링크로 묶인 장치 수 안으로 **TP Size**를 제한하고 연속 층의 **분할 축**을 맞출 때만 이득이 남는다.
