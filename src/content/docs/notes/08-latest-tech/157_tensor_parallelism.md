## 미리 알고가기

- **텐서 병렬(Tensor Parallelism, TP, 티피)**: 한 층의 가중치·연산을 텐서 축으로 나눠 여러 장치가 공동 계산
- **집단 통신(Collective Communication)**: 분할 결과를 All-Reduce·All-Gather 등으로 합치는 장치 그룹 통신
- **All-Reduce(올 리듀스)**: 각 장치의 부분값을 합산한 뒤 모든 장치에 같은 결과를 배포하는 연산



## Ⅰ. 개요

- 정의/개념: 단일 층의 텐서와 행렬 연산을 여러 장치에 분할하는 모델 병렬화 기법이다
- 기존 한계: 하나의 거대 층이 장치 메모리나 연산 용량을 초과하면 층 단위 배치가 불가능하다
- **배경/필요성**: 한 층의 메모리와 계산량을 장치 그룹에 분산하기 위함이다

### 쉽게 이해하기 (학습용)

- 한 판재를 방향에 따라 잘라 여러 사람이 동시에 가공하는 방식임

## Ⅱ. 특징

- 행·열 등 텐서 축을 나눠 장치별 부분 연산을 수행한다
- 분할 레이아웃에 따라 수집·합산 집단 통신이 발생한다
- 잦은 통신 때문에 고대역폭 장치 그룹에서 효과적이다

### 쉽게 이해하기 (학습용)

- 세로로 자른 결과는 이어 붙이고 가로로 자른 부분 계산값은 합산한다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 레이아웃 계획기 | 다음 연산 입력 형태를 고려해 분할 차원을 선택함 |
| 분할 가중치·활성값 | 분할 차원에 따른 장치별 데이터 범위를 정의함 |
| 로컬 행렬곱 엔진 | 배정된 데이터로 부분 출력을 계산함 |
| 텐서 병렬 통신 그룹 | 출력 및 기울기 완성을 위한 집단 통신 수행함 |
| 분산 자동미분 | 순전파 레이아웃에 맞춰 기울기를 계산·전달함 |

```text
열분할: X × [W0|W1] → [Y0|Y1] ──Gather──→ Y
행분할: [X0|X1] × [W0;W1] → P0+P1 ──Reduce──→ Y
```

> 요약: 분할 레이아웃에 따라 로컬 계산과 집단 통신을 수행한다

### 쉽게 이해하기 (학습용)

- 세로 조각은 옆으로 이어 완성하고 가로 조각은 각 계산값을 더해 완성하며, 다음 작업이 조각을 그대로 쓸 수 있으면 일부 통신을 미룰 수 있음

## Ⅳ. 원리 및 절차 흐름도

```text
분석설계
   ↓
분할그룹
   ↓
로컬연산
   ↓
집단통신
   ↓
역전파갱신
```

| 절차 | 설명 |
|:---|:---|
| 분석설계 | 연산 형태와 장치 대역폭을 측정함 |
| 분할그룹 | 행·열 레이아웃과 병렬 그룹 크기를 정함 |
| 로컬연산 | 배정된 조각으로 부분 출력을 계산함 |
| 집단통신 | 필요한 합산·수집·분산으로 다음 입력을 만듦 |
| 역전파갱신 | 반대 레이아웃으로 기울기 계산·갱신함 |

> 요약: 분할 축을 정해 로컬 계산 후 필요한 결과를 통합한다

### 쉽게 이해하기 (학습용)

- 다음 공정이 원하는 조각 모양까지 보고 판재를 나눈 뒤 각자 가공하고, 꼭 필요한 시점에만 이어 붙이거나 합산하는 절차임

## Ⅴ. 종류 및 비교

| 판단 기준 | 텐서 병렬 | 파이프라인 병렬 | 데이터 병렬 |
|:---|:---|:---|:---|
| 적용 기준 | 한 층이 장치 용량 초과 | 모델을 연속 단계로 분할 | 모델 복제본 배치 가능 |
| 핵심 특징 | 텐서 축과 연산 분할 | 마이크로배치 단계 중첩 | 입력 배치 분할 후 기울기 동기화 |
| 한계 | 잦은 집단 통신 | 버블과 단계 불균형 | 장치마다 전체 모델 필요 |

> 요약: 텐서·파이프라인·데이터 병렬은 분할 단위가 다르다.

### 쉽게 이해하기 (학습용)

- 한 부품을 함께 가공하면 텐서 병렬, 공정을 나누면 파이프라인 병렬, 같은 설비로 서로 다른 제품을 만들면 데이터 병렬임

### 쉽게 이해하기 (학습용)

- 이어지는 두 가공 작업의 자르는 방향을 맞춰 중간에 전체 판재를 다시 조립하지 않고 마지막에만 결과를 합치는 방식임

## Ⅶ. 결론

- 단일 층의 메모리와 연산 한계를 극복하기 위해 **텐서 분할 축·중간 동기화·장치 연결 대역폭·연산 균형**을 검토하고, 고대역폭 장치 그룹에 텐서 병렬화를 적용한다

### 쉽게 이해하기 (학습용)

- 하나의 큰 계산을 나눠 풀고 필요한 지점에서 결과를 합친다
