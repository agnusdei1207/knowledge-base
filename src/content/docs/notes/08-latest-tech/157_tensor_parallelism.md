## 미리 알고가기

- **텐서 병렬 (Tensor Parallelism, TP)**: 단일 연산자의 텐서를 차원별로 분할하여 여러 장치가 공동으로 행렬 연산을 수행하는 기법



## Ⅰ. 개요

- **정의/개념**: 단일 연산 텐서의 차원 분할 병렬화
- **배경/필요성**: 한 층의 메모리·계산 한계 확장

### 쉽게 이해하기 (학습용)

- 한 판재를 방향에 따라 잘라 여러 사람이 동시에 가공하는 방식임

## Ⅱ. 특징

- 행렬의 행·열 분할로 로컬 곱을 수행한다
- 텐서 레이아웃이 집단 통신 종류를 결정한다
- 역전파는 입력·가중치 기울기 통신을 만든다
- 고대역폭 장치 그룹 안에서 다른 병렬화와 결합한다

### 쉽게 이해하기 (학습용)

- 세로로 자르면 결과 조각을 이어 붙이고, 가로로 자르면 각 계산값을 더함

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 레이아웃 계획기 | 다음 연산 입력 형태를 고려해 분할 차원을 선택함 |
| 분할 가중치·활성값 | 분할 차원에 따른 장치별 데이터 범위를 정의함 |
| 로컬 행렬곱 엔진 | 배정된 데이터로 부분 출력을 계산함 |
| 텐서 병렬 통신 그룹 | 출력 및 기울기 완성을 위한 집단 통신 수행함 |
| 분산 자동미분 | 순전파 레이아웃에 맞춰 기울기를 계산·전달함 |

```text
열분할: X × [W0|W1] → [Y0|Y1] ──Gather──→ Y
행분할: [X0|X1] × [W0;W1] → P0+P1 ──Reduce──→ Y
```

> 요약: 레이아웃 계획기 결정에 따라 로컬 계산 후 통신함

### 쉽게 이해하기 (학습용)

- 세로 조각은 옆으로 이어 완성하고 가로 조각은 각 계산값을 더해 완성하며, 다음 작업이 조각을 그대로 쓸 수 있으면 일부 통신을 미룰 수 있음

## Ⅳ. 원리 및 절차 흐름도

```text
분석설계
   ↓
분할그룹
   ↓
로컬연산
   ↓
집단통신
   ↓
역전파갱신
```

| 절차 | 설명 |
|:---|:---|
| 분석설계 | 연산 형태와 장치 대역폭을 측정함 |
| 분할그룹 | 행·열 레이아웃과 병렬 그룹 크기를 정함 |
| 로컬연산 | 배정된 조각으로 부분 출력을 계산함 |
| 집단통신 | 필요한 합산·수집·분산으로 다음 입력을 만듦 |
| 역전파갱신 | 반대 레이아웃으로 기울기 계산·갱신함 |

> 요약: 분할 차원을 정해 로컬 계산 후 필요한 지점에서 통신함

### 쉽게 이해하기 (학습용)

- 다음 공정이 원하는 조각 모양까지 보고 판재를 나눈 뒤 각자 가공하고, 꼭 필요한 시점에만 이어 붙이거나 합산하는 절차임

## Ⅴ. 종류 및 비교

| 판단 기준 | 텐서 병렬 | 파이프라인 병렬 | 데이터 병렬 |
|:---|:---|:---|:---|
| 분할·통신 | 연산 차원·집단 통신 | 단계·점대점 통신 | 입력 배치·기울기 통신 |
| 실행 경계 | 연산 조각 공동 계산 | 단계별 중첩 실행 | 전체 복제본 실행 |
| 배치 기준 | 노드 내부 거대 층 | 단계별 장치 분할 | 처리량 확장 시 |

> 요약: 텐서·파이프라인·데이터 병렬은 분할 단위가 다르다.

### 쉽게 이해하기 (학습용)

- 한 부품을 함께 가공하면 텐서 병렬, 공정을 나누면 파이프라인 병렬, 같은 설비로 서로 다른 제품을 만들면 데이터 병렬임

## Ⅵ. 실무 사례

1. NVIDIA Megatron-LM은 트랜스포머 다층 퍼셉트론의 첫 행렬을 열 분할하고 두 번째 행렬을 행 분할해 두 행렬 사이의 불필요한 동기화를 줄임
2. 대규모 언어 모델 학습은 어텐션의 질의·키·값과 헤드를 텐서 그룹에 분할하고 노드 내부 고속 연결에서 집단 통신을 수행함

### 쉽게 이해하기 (학습용)

- 이어지는 두 가공 작업의 자르는 방향을 맞춰 중간에 전체 판재를 다시 조립하지 않고 마지막에만 결과를 합치는 방식임

## Ⅶ. 결론

- 분할 축·고속 토폴로지가 통신 비용을 정한다

### 쉽게 이해하기 (학습용)

- 하나의 큰 계산을 나눠 풀고 필요한 지점에서 결과를 합친다
