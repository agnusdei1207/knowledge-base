## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **시각언어모델(Vision-Language Model, VLM)**: 이미지•텍스트 관계를 학습해 판별•생성하는 모델이다.

</details>

- 정의/개념: 이미지와 텍스트를 정렬해 판별•생성하는 **VLM**
- 배경/필요성: 단일 모달은 객체•공간과 언어 의미의 **공동 해석 곤란**

#### 한줄 요약

- 이미지•텍스트를 **공동 의미 공간**에 연결해 판별•생성

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **시각 인코더(Vision Encoder)**: 픽셀을 패치•영역 단위 시각 표현으로 변환한다.
- **연결 계층(Connector)**: 시각 표현을 언어 모델 입력 공간으로 사상한다.

</details>

- **시각 인코더** 기반 픽셀의 패치•영역 표현 변환
- **연결 계층** 기반 시각•언어 입력 공간 정렬
- 대조•매칭•생성 목적별 **출력 능력•오류 차이**

#### 한줄 요약

- **시각 표현•언어 정렬•출력 목적**이 모델 능력 결정

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **텍스트 인코더(Text Encoder)**: 문장을 의미 특징이 담긴 언어 표현으로 변환한다.
- **이미지 인코더(Image Encoder)**: 이미지를 패치•영역 시각 표현으로 변환한다.
- **연결 계층**: 시각 표현의 차원•토큰 형식을 투영•정렬한다.
- **언어 디코더(Language Decoder)**: 시각 조건을 받아 언어 토큰을 생성한다.
- **공동 의미 공간(Joint Semantic Space)**: 대응 이미지•텍스트가 가깝게 배치된 공간이다.

</details>

```text
                [이미지 인코더]   [텍스트 인코더]
                         \         /
                          [연결 계층]
                               |
                         [언어 디코더]
                               |
                           [출력 계층]
```

선의 의미: 시각•언어 표현과 연결•디코더•출력 계층의 결합 관계이다.

| 구성요소 | 책임 |
|:---|:---|
| 이미지 인코더 | 이미지 패치의 **시각 표현 변환** |
| 텍스트 인코더 | 문장의 **언어 표현 변환** |
| 연결 계층 | 시각 표현의 **언어 공간 사상** |
| 언어 디코더 | **LLM 기반 시각 조건 토큰 생성** |
| 출력 계층 | **유사도•생성 결과** 산출 |

#### 한줄 요약

- **이미지•텍스트 인코더•연결•디코더•출력** 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **시각 조건 주입(Visual Conditioning)**: 정렬된 이미지 표현을 디코더 문맥에 전달한다.
- **언어 토큰(Language Token)**: 디코더가 예측해 자연어 응답을 구성하는 단위이다.

</details>

```text
이미지 인코더
   │ 1. 시각 표현 정렬
   ▼
연결 계층
   │ 2. 시각 조건 주입
   ▼
언어 디코더
   │ 3. 판별•응답 생성
   ▼
출력 계층
```

### 동작 원리

1. 시각 표현 정렬: 이미지 패치•영역을 **공동 의미 공간에 사상**함.
2. 시각 조건 주입: 정렬된 표현을 **언어 디코더 문맥에 전달**함.
3. 판별•응답 생성: 이미지 문맥으로 **유사도•언어 토큰**을 산출함.

#### 한줄 요약

- **시각 정렬•조건 주입•판별•응답 생성** 수행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **대조 학습(Contrastive Learning)**: 일치 표현은 가깝게, 불일치 표현은 멀게 학습한다.
- **이미지 매칭(Image Matching)**: 이미지와 문장의 대응 여부를 점수화한다.
- **생성형 튜닝(Generative Tuning)**: 시각 조건에 맞는 자연어 응답을 학습한다.

</details>

| 학습 방식 | 대조 학습 | 이미지 매칭 | 생성형 튜닝 |
|:---|:---|:---|:---|
| 적용 기준 | **검색**•**전이** 필요 시 | **대응 판별** 필요 시 | **자연어 생성** 필요 시 |
| 핵심 특징 | 이미지•텍스트 **공동 임베딩** | 이미지•문장 **일치 점수** | **시각 조건 토큰** 생성 |
| 한계 | 세부 **공간•문자 정보 손실** | **생성형 설명 불가** | **환각•공간 관계 오류** |

#### 한줄 요약

- **검색•대응 판별•자연어 생성**에 따라 학습 목표 구분

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **광학 문자 인식(Optical Character Recognition, OCR)**: 이미지 글자를 문자 데이터로 변환한다.
- **시각 환각(Visual Hallucination)**: 이미지에 없는 객체•관계를 생성하는 문제이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 저해상도 문자로 **광학 문자 인식(Optical Character Recognition, OCR) 오류** | 원본 영역 확대•OCR 결과 결합 | 문서 **문자 정확도** 향상 |
| 객체 관계 생성 시 **시각 환각** | 객체 위치•원본 근거 교차 검증 | **공간 관계 충실성** 확보 |

#### 한줄 요약

- **문자 정확도•객체 위치•공간 관계 충실성** 검증

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **문자 정확도(Text Accuracy)**: 이미지 글자를 원문과 일치하게 인식한 정도이다.
- **공간 관계 충실성(Spatial Faithfulness)**: 생성한 위치•관계가 실제 배치와 일치하는 정도이다.

</details>

- **문자 정확도•공간 관계 충실성**으로 VLM 판별•생성 방식 선택

#### 한줄 요약

- 문자 중심은 **OCR 결합**, 장면 이해는 **VLM 검증** 적용
