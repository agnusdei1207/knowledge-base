## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **멀티 헤드 어텐션(Multi-Head Attention, MHA)**: 입력을 여러 부분공간에 투영해 어텐션을 병렬 계산하고 결합하는 구조이다.
- **어텐션 헤드(Attention Head)**: 독립된 Q•K•V 투영으로 하나의 관계 관점을 학습하는 연산 단위.

</details>

- 정의/개념: 여러 표현 공간의 어텐션을 병렬 계산하는 **MHA**
- 배경/필요성: 단일 어텐션(Single-Head Attention) 메커니즘은 전체 모델 차원에 대해 단 하나의 어텐션 가중치 분포만을 계산하므로, 문장 내에서 동시에 존재하는 다양한 유형의 정보(문법적 수식 관계, 대명사 지칭 관계, 장거리 주제 관계 등)가 하나의 평균값으로 희석되어 다각적인 문맥 정보를 동시에 포착하지 못하는 표현력 한계가 존재함에 따라, 입력 차원 $d_{\text{model}}$을 여러 개의 독립된 부분공간(Subspaces) $d_k = d_{\text{model}} / h$로 분할하여 서로 다른 관점의 어텐션을 병렬 계산한 뒤 결합하는 멀티 헤드 어텐션(Multi-Head Attention: MHA)을 도입하여 **다차원 관계 표현의 동시 학습 및 언어적 풍부성 극대화, 병렬 헤드 연산을 통한 계산 복잡도 유지($O(N^2 \cdot d)$ 동일) 및 앙상블 효과 달성, 추론 최적화를 위한 MQA/GQA 파생 구조의 토대 마련**을 달성할 필요

#### 한줄 요약
- **어텐션 헤드**를 늘리면 관계 유형을 나눠 학습하지만 전체 차원을 쪼개 쓰므로 헤드당 표현력은 줄어, 헤드 수는 관계 다양성과 헤드당 정밀도의 교환점에서 정한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **멀티 쿼리 어텐션(Multi-Query Attention, MQA)**: 모든 쿼리 헤드가 하나의 K•V를 공유해 추론 메모리를 줄이는 구조이다.
- **그룹 쿼리 어텐션(Grouped-Query Attention, GQA)**: 쿼리 헤드를 여러 그룹으로 나누고 그룹마다 하나의 K•V 헤드를 공유하는 구조로 정의된다.
- **표현 부분공간**: 모델 표현을 더 작은 차원으로 나누어 헤드별로 서로 다른 관계를 학습하는 공간이다.
- **쿼리(Query, Q)**: 현재 토큰이 찾을 정보의 조회 기준 벡터.
- **키(Key, K)**: 쿼리와 비교할 식별 벡터로 정의된다.
- **밸류(Value, V)**: 가중치에 따라 결합되는 정보 벡터로 정의된다.

</details>

- **표현 부분공간**: Q•K•V의 독립 투영
- **출력 통합**: 병렬 결과 연결과 출력 투영
- **MQA**: 모든 Q 헤드가 단일 K•V 공유
- **GQA**: Q 헤드 그룹별 K•V 공유

#### 한줄 요약
- **헤드 다양성•K•V 공유 범위** 표현력•비용 결정

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **연결(Concatenation, Concat)**: 헤드별 출력 벡터를 특성 차원 방향으로 이어 붙여 통합 표현을 만드는 연산.
- **출력 투영(Output Projection)**: 연결한 헤드 출력을 $W^O$ 가중치 행렬로 변환해 모델 차원으로 되돌리는 연산이다.

</details>

```text
[멀티 헤드 어텐션(MHA) 아키텍처]
├── [선형 투영 계층 (Linear Projection)]
│   ├── 쿼리 선형 변환 (Q·W_i^Q)
│   ├── 키 선형 변환 (K·W_i^K)
│   └── 밸류 선형 변환 (V·W_i^V)
├── [병렬 어텐션 헤드군 (Parallel Heads × h)]
│   ├── 헤드 1 (문법적/통사적 의존 관계 학습)
│   ├── 헤드 2 (대명사 및 지칭 관계 학습)
│   └── 헤드 h (장거리 문맥 및 담화 관계 학습)
└── [통합 및 출력 투영 (Output Projection)]
    ├── 다중 헤드 연결 (Concatenation: Concat)
    └── 출력 선형 변환 (W^O 행렬 환원)
```

- 선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 선형 투영기 | 입력 벡터를 $h$개의 독립 부분공간($d_k$)으로 선형 매핑 |
| 헤드 분할기 | 전체 차원을 헤드 단위($d_{model}/h$)로 분할 및 텐서 재배열 |
| 병렬 어텐션 헤드 | 각 부분공간에서 독립적인 스케일드 닷 프로덕트 어텐션 수행 |
| 헤드 연결기 | 병렬 계산된 각 헤드의 출력 행렬을 특성 차원으로 결합(Concat) |
| 출력 투영기 | 연결된 벡터에 가중치 행렬($W^O$)을 곱해 원래 모델 차원으로 환원 |

#### 한줄 요약
- **투영•분할•병렬 어텐션•연결•출력 투영** 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **헤드 분할**: 모델 차원을 헤드 수만큼 저차원 표현으로 재배열하여 병렬 어텐션 입력을 만드는 과정.
- **스케일드 닷 프로덕트 어텐션**: 각 헤드에서 Q•K 내적을 키 차원으로 보정하고 V를 가중합하는 연산.
- **입력 Q•K•V 선형 투영**: 헤드별 가중치로 Q•K•V를 만드는 절차이다.
- **헤드별 부분공간 분할**: 모델 차원을 저차원 부분공간으로 재배열하는 절차이다.
- **헤드별 어텐션 병렬 계산**: 부분공간별 어텐션을 동시에 수행하는 절차이다.
- **헤드 출력 연결**: 헤드별 출력 벡터를 특성 차원 방향으로 이어 붙이는 절차.
- **모델 차원 출력 투영**: 연결한 헤드 출력을 출력 가중치로 변환해 모델 차원으로 되돌리는 절차.

</details>

```text
입력 벡터
   │ 1. 입력 Q•K•V 선형 투영
   ▼
투영기
   │ 2. 헤드별 부분공간 분할
   ▼
헤드 연산기
   │ 3. 헤드별 어텐션 병렬 계산
   ▼
출력 결합기
   │ 4. 헤드 출력 연결
   │ 5. 모델 차원 출력 투영
   │ 통합 표현 출력
   ▼
출력
```

### 동작 원리

1. **입력 Q•K•V 선형 투영**: 헤드별 관계 관점 생성
2. **헤드별 부분공간 분할**: 표현 차원 재배열
3. **헤드별 어텐션 병렬 계산**: 부분공간별 관계 추출
4. **헤드 출력 연결**: 병렬 결과 통합
5. **모델 차원 출력 투영**: 다음 계층 차원에 정합

#### 한줄 요약
- 헤드별 관계를 병렬 계산해 **통합 표현 생성**

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **키-값 캐시(Key-Value Cache, KV Cache)**: 이전 토큰의 K•V를 저장해 다음 토큰 생성에 재사용하는 메모리로 정의된다.

</details>

- **MHA•MQA•GQA** 활용 K•V 공유와 KV Cache 비용으로 구분

| 구분 | MHA | MQA | GQA |
|:---|:---|:---|:---|
| 적용 기준 | 최대 표현 용량 | 최소 추론 메모리•대역폭 | 캐시 절감•표현력 보존 |
| 핵심 특징 | 헤드별 독립 K•V | 모든 Q가 단일 K•V 공유 | Q 그룹별 K•V 공유 |
| 한계 | KV 캐시 비용 최대 | 표현력•품질 저하 가능 | 그룹 수 튜닝 필요 |

#### 한줄 요약
- **K•V 공유 범위** 기반 표현력•KV Cache 비용 절충

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **헤드 제거 실험**: 특정 헤드를 비활성화한 뒤 품질 변화를 측정하여 관계 학습의 중복 여부를 확인하는 평가로 정의된다.
- **체크포인트 변환**: MHA 가중치의 K•V 헤드를 매핑•병합하여 GQA나 MQA 구조에서 사용할 수 있게 바꾸는 과정이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 헤드 증가에 따른 관계 학습 중복 | **헤드 제거 실험** 후 수 조정 | 불필요 연산과 매개변수 감축 |
| 모델 차원과 헤드 수의 분할 불일치 | 나눗셈 조건•텐서 형상 시험 | 구현 오류와 차원 손실 방지 |
| 생성 시 KV Cache•대역폭 병목 | 품질 평가 후 **GQA**•**MQA** 적용 | 동시 처리량•메모리 효율 향상 |
| MHA↔GQA 변환의 체크포인트 비호환 | **체크포인트 변환** 및 회귀 시험 | 변환 후 품질•배포 안정성 확보 |

#### 한줄 요약
- **GQA**•**MQA** 기반 KV Cache•대역폭 병목 완화

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **헤드 공유 방식 선택 기준**: 최대 표현력에는 MHA를, 최소 캐시에는 MQA를, 두 요구의 절충에는 GQA를 적용하는 기준.

</details>

- 단일 모델 차원을 다채로운 의미 부분공간으로 확장하여 심층 문맥 이해를 가능하게 한 **트랜스포머 아키텍처의 핵심 표현 증폭 엔진(Multi-Head Attention / Linear Projection & Subspace Splitting / Parallel SDPA / Concat & Output Projection / MQA & GQA Evolution)의 표준 구조**로 확고히 자리 잡았으며, 거대 언어 모델의 서빙 메모리 병목을 해결하는 GQA(Grouped-Query Attention) 및 MQA(Multi-Query Attention)로 진화하는 가운데, 실무 LLM 아키텍처 설계 시에는 **학습 시 풍부한 표현력을 제공하는 MHA와 추론 시 KV Cache 메모리를 획기적으로 절감하는 GQA(Llama-3, Mistral 등 표준) 간의 전략적 선택, 헤드 수와 부분공간 차원의 정밀한 정렬, 추론 서빙 시 PagedAttention 및 vLLM 등 고속 서빙 프레임워크와의 완벽한 텐서 결합**을 결합하여 완벽한 모델 성능과 추론 경제성을 완성

#### 한줄 요약
- **표현력•KV Cache 비용** 대상 따라 MHA•MQA•GQA 결정
