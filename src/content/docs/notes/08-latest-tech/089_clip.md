## 미리 알고가기

- **대조 언어-이미지 사전학습 (Contrastive Language-Image Pre-training, CLIP)**: 이미지·텍스트를 공동 공간에 정렬함
- **대조학습 (Contrastive Learning)**: 정답 쌍은 가깝게, 오답 쌍은 멀게 학습함
- **제로샷 분류 (Zero-Shot Classification)**: 미학습 클래스 설명으로 분류함
- **교차 모달 검색 (Cross-Modal Retrieval)**: 한 모달로 다른 모달을 검색함



## Ⅰ. 개요

- **정의/개념**: 이미지·텍스트를 공동 임베딩에 정렬하는 모델
- **배경/필요성**: 자연어로 미학습 클래스 검색·분류 지원

### 쉽게 이해하기 (학습용)

- 그림과 설명에 같은 의미 좌표를 부여해 서로 가까운 짝을 찾는 방식입니다.

## Ⅱ. 특징

- 정답 이미지·문장 쌍은 가깝고 다른 쌍은 멀게 학습한다.
- 두 인코더가 독립 동작해 임베딩을 미리 계산할 수 있다.
- 클래스 설명과 이미지 유사도로 제로샷 분류한다.
- 프롬프트와 도메인 변화가 유사도 순위를 바꿀 수 있다.

### 쉽게 이해하기 (학습용)

- 맞는 그림과 설명은 가깝게, 틀린 짝은 멀게 배워 새로운 설명도 이미지와 비교할 수 있습니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 이미지 인코더 | 이미지 시각 임베딩 변환 |
| 텍스트 인코더 | 클래스 텍스트 임베딩 변환 |
| 임베딩 공간 | 벡터 좌표상 정렬 공간 |
| 온도 계수 | 유사도 점수 집중도 조절 |
| 앙상블 | 클래스 문구 결합 활용 |

```text
공동공간
├─ 이미지인코더
├─ 텍스트인코더
├─ 쌍별유사도
├─ 온도계수
└─ 문구결합
```

### 쉽게 이해하기 (학습용)

- 이미지·문장 인코더와 공동 공간, 점수 간격 조절기, 프롬프트 결합부로 구성됩니다.

## Ⅳ. 원리 및 절차 흐름도

```text
쌍인코딩
↓
유사계산
↓
대조학습
↓
표현생성
↓
분류판정
```

| 절차 | 설명 |
|:---|:---|
| 쌍 인코딩 | 벡터 정규화 변환함 |
| 유사 계산 | 내적 온도 점수 계산 |
| 대조 학습 | 정답 쌍 상대 점수 조정 |
| 표현 생성 | 문구 임베딩 결합함 |
| 분류 판정 | 이미지 클래스 유사도 판정 |

### 쉽게 이해하기 (학습용)

- 정답 쌍을 정렬한 뒤 클래스 설명과 이미지의 유사도를 비교합니다.

## Ⅴ. 종류 및 비교

| 판단 기준 | 지도 분류기 | CLIP | 생성 모델 |
|:---|:---|:---|:---|
| 출력 방식 | 고정 클래스 확률 | 유사도 기반 판정 | 생성 기반 응답 |
| 클래스 확장 | 라벨 재학습 | 프롬프트 추가 | 토큰 기반 지정 |
| 적용 기준 | 고정 라벨 사용 시 | 검색 제로샷 분류 | 자연어 생성 필요 시 |

> 요약: 이미지와 텍스트를 공동 공간에 정렬하는 모델임

### 쉽게 이해하기 (학습용)

- 고정 분류기·CLIP·생성 모델은 클래스 확장 방식과 출력이 다릅니다.

## Ⅵ. 실무 사례

- 상품 검색은 이미지 색인과 자연어 질의 유사도를 비교한다.
- 콘텐츠 분류는 프롬프트 앙상블로 새 라벨을 판별한다.

### 쉽게 이해하기 (학습용)

- 상품 사진의 표현을 미리 색인하면 자연어와 가까운 상품을 찾고 새 분류 문구로 후보를 나눌 수 있습니다.

## Ⅶ. 결론

- 프롬프트·도메인 변화에 따른 검색 순위를 검증한다.

### 쉽게 이해하기 (학습용)

- 이미지와 문장의 거리를 재는 데 알맞지만 새로운 분야와 문구에서는 결과를 다시 확인해야 합니다.
