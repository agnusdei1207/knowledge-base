## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **청킹(Chunking)**: 원문을 검색 가능한 의미 단위인 청크(Chunk)로 분할하는 전처리이다.
- **검색 증강 생성(Retrieval-Augmented Generation, RAG)**: 검색된 청크를 생성 모델의 답변 근거로 제공하는 방식이다.

</details>

- 정의/개념: **청킹(Chunking)**은 원문을 의미 있는 검색 단위로 나누는 전처리한다.
- 배경/필요성: **RAG**에서 문서 전체 검색은 문맥 한도 초과와 검색 잡음을 유발한다.

#### 한줄 요약

- 질문으로 찾기 좋은 의미 단위로 문서를 나누고 출처 정보를 붙입니다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **중첩(Overlap)**: 인접 청크에 경계 문맥을 반복해 의미 단절을 줄이는 대신 중복 저장•검색 비용을 늘리는 개념이다.
- **메타데이터**: 청크의 문서 식별자•위치•계층•인접 관계를 기록하는 정보이다.

</details>

- 문장•문단•절의 의미 구조를 유지하는 **경계 보존**이 핵심이다.
- 작은 청크의 **검색 정밀도 향상•문맥 단절 증가**가 핵심이다.
- 큰 청크의 **문맥 보존•검색 잡음 증가**가 핵심이다.
- 경계와 출처를 보완하는 **중첩•메타데이터**가 핵심이다.

#### 한줄 요약

- 너무 작으면 문맥이 끊기고 너무 크면 노이즈가 늘며 중첩은 중복 비용을 만듭니다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **구조 파서**: 제목•문단•표•코드 계층을 추출하는 구성요소이다.
- **경계 정책기**: 의미 구조의 분할 우선순위를 정하는 구성요소이다.
- **크기 정책**: 청크의 최소•최대 토큰 범위를 정하는 정책이다.

</details>

| 구성요소 | 책임 |
|:---|:---|
| 구조 파서 | 제목•문단•표•코드 계층 추출 |
| 경계 정책기 | 의미 구조의 분할 우선순위 결정 |
| 크기 정책기 | 청크 최소•최대 토큰 범위 결정 |
| 중첩 정책기 | 반복할 경계 문맥 결정 |
| 메타데이터 기록기 | 원문 위치•계층•인접 참조 기록 |

#### 한줄 요약

- 파서•경계•크기•중첩•위치 정보가 청크를 구성합니다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **선택적 중첩**: 모든 청크를 고정 길이로 반복하지 않고 경계 문맥이 필요한 구간에만 중첩을 적용하는 개념이다.

</details>

```text
구조 파서
   │ 1. 문서 구조•후보 단위 추출
   ▼
청크 정책기
   │ 2. 의미 경계 선택
   │ 3. 크기 조건별 청크 결합
   │ 4. 선택적 중첩•원문 참조 기록
   ▼
메타데이터 기록기
   └── 원문 참조 포함 청크 집합 ──▶ 구조 파서
```

**동작 원리**

1. **문서 구조•후보 단위 추출**: 제목•문단•표 구조를 분할 후보로 보존한다.
2. **의미 경계 선택**: 구조 우선순위로 절단 가능한 지점을 결정한다.
3. **크기 조건별 청크 결합**: 토큰 상한 안에서 인접 단위를 결합한다.
4. **선택적 중첩•원문 참조 기록**: 경계 문맥과 위치•계층 정보를 보존한다.

#### 한줄 요약

- 문서 구조와 크기로 나누고 중첩과 원문 위치를 붙입니다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **고정 크기•구조 기반•의미 기반 청킹**: 각각 토큰 수, 문서 계층, 의미 유사도 변화로 경계를 결정하는 개념이다.

</details>

| 비교 기준 | 고정 크기 | 구조 기반 | 의미 기반 |
|:---|:---|:---|:---|
| 적용 기준 | 균일 문서•**빠른 처리** | 명확한 **제목•문단 구조** | **주제 전환 보존** |
| 핵심 특징 | **토큰 수** 기준 분할 | **문서 계층** 기준 분할 | **의미 유사도 변화**로 분할 |
| 한계 | **의미 경계 절단** | 불규칙 **구조에 취약** | 계산 비용•**경계 변동** |

#### 한줄 요약

- 고정•구조•의미 기반 청킹은 경계를 정하는 기준과 비용이 다릅니다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **근거 재현율•정밀도**: 정답 근거를 놓치지 않는 정도와 검색 결과 중 유효 근거의 비율을 함께 측정하는 지표이다.
- **추적 가능성**: 검색 조각에서 원문 문서•페이지•계층으로 되돌아갈 수 있는 성질이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 과소•과대한 **청크 크기** | 유형별 **근거 재현율•정밀도**로 크기 선택 | 검색 목표에 맞는 **청크 크기 결정** |
| 표•조항•코드의 **의미 경계 절단** | 구조 우선 분할과 선택적 **중첩** 적용 | 근거의 **의미 완결성** 보존 |
| 검색 조각의 **문맥•출처 소실** | **문서 식별자(Identifier, ID)•계층•페이지**를 메타데이터로 보존 | 근거의 **추적 가능성** 확보 |

#### 한줄 요약

- 규정은 조•항•호와 원문 위치를 보존하고 매뉴얼은 설명과 예제 코드의 결합 여부를 검증합니다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **선택 기준**: 문서 구조, 주제 전환 빈도, 문맥 보존 필요성과 중복 비용이다.

</details>

- 정형 문서는 **구조 기반**, 주제 전환이 잦으면 **의미 기반 청킹**을 선택한다.

#### 한줄 요약

- 검색 가능성과 문맥 보존 및 중복 비용을 문서 유형별로 비교해야 합니다.
