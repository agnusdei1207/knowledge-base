## 미리 알고가기

- **C2PA**: 콘텐츠 출처와 편집 이력을 서명된 매니페스트로 교환·검증하는 개방형 표준
- **매니페스트(Manifest)**: 출처 진술·클레임·서명과 콘텐츠 연결 정보를 담는 구조
- **바인딩(Binding)**: 매니페스트를 콘텐츠와 연결해 변경이나 분리를 확인하는 방식

## Ⅰ. 개요

- **정의/개념**: 출처 진술을 서명 매니페스트로 검증하는 표준이다
- **배경/필요성**: 도구 간 변조 흔적과 편집 이력을 교환한다

### 쉽게 이해하기 (학습용)

- 카메라·편집기·플랫폼이 같은 형식의 봉인된 작업 장부를 이어 쓰게 한 공통 규칙이다.

## Ⅱ. 특징

- 공통 형식은 도구 간 출처 이력 단절을 줄인다
- 하드 바인딩은 콘텐츠·매니페스트 변경을 드러낸다
- 소프트 바인딩은 제거된 매니페스트 재발견을 돕는다
- 유효 서명은 발행 경로일 뿐 내용 사실성을 보장하지 않는다
- 워터마크·합성 탐지는 출처 이력의 공백을 보완한다

### 쉽게 이해하기 (학습용)

- 장부의 봉인과 발행자는 확인할 수 있지만 기록한 내용이 사실인지는 별도로 검증해야 한다.

## Ⅲ. 아키텍처 및 구성요소

```text
[진술 저장소] ── 참조 ── [클레임: 콘텐츠 바인딩]
                              │
                     [클레임 서명·자격증명]
                              │
                     [매니페스트 저장소]
                              │
                     [매니페스트 검증기]
```

| 설계 요소 | 설명 |
|:---|:---|
| 진술 저장소 | 생성·편집 이력 진술 보관 |
| 클레임 | 진술 참조·콘텐츠 바인딩 묶음 |
| 서명·자격증명 | 클레임 무결성·신뢰 경로 입증 |
| 매니페스트 저장소 | 매니페스트·참조 관계 보관 |
| 매니페스트 검증기 | 구조·서명·폐기 상태 판정 |

> 요약: 진술과 콘텐츠를 서명해 출처 이력으로 교환한다

### 쉽게 이해하기 (학습용)

- 작업 기록과 원본 지문을 함께 봉인하고 검증기가 봉인·발행 경로·유효 기간을 확인한다.

## Ⅳ. 원리 및 절차 흐름도

```text
진술 생성 → 클레임 구성 → 클레임 서명
                            ↓
             배포 → 탐색 → 검증 → 상태 해석
```

| 절차 | 설명 |
|:---|:---|
| 진술 생성 | 포함할 진술·자산 결정 |
| 클레임 구성 | 진술 참조·바인딩 결합 |
| 클레임 서명 | 자격증명으로 서명·첨부 |
| 매니페스트 배포 | 자산 내장·원격 제공 |
| 매니페스트 탐색 | 내장·원격 경로에서 자료 탐색 |
| 매니페스트 검증 | 구조·서명·시간·상태 판정 |
| 상태 해석 | 검증 결과와 발행자 신뢰 구분 |

> 요약: 출처 진술을 서명하고 매니페스트 상태를 해석한다

### 쉽게 이해하기 (학습용)

- 작업 내역과 원본 지문을 봉인해 배포하고 수신자는 매니페스트의 봉인·지문·발행 경로를 확인한다.

## Ⅴ. 종류 및 비교

| 판단 기준 | C2PA | 일반 메타데이터 | 파일 해시 공증 |
|:---|:---|:---|:---|
| 기록 대상 | 출처·편집 진술과 구성 자산 | 장비·시간 등 속성값 | 특정 파일 해시와 등록 시점 |
| 검증 근거 | 콘텐츠 바인딩·서명·신뢰 경로 | 별도 서명 없으면 수정 가능 | 외부 기록과 해시 일치 |
| 적용 기준 | 도구 간 출처 이력을 이어갈 때 | 비보안 속성을 교환할 때 | 특정 파일의 존재 시점을 남길 때 |

> 요약: 이력은 C2PA, 속성은 메타데이터, 시점은 공증이다

### 쉽게 이해하기 (학습용)

- C2PA는 편집 이력을 잇고 일반 메타데이터는 속성을 붙이며 해시 공증은 파일의 존재 시점을 남긴다.

## Ⅵ. 실무 사례

1. 뉴스 사진의 촬영·편집 매니페스트를 연결한다
2. 생성 미디어의 외부 매니페스트 복구 경로를 둔다

### 쉽게 이해하기 (학습용)

- 뉴스 사진은 촬영부터 편집까지 매니페스트를 이어 기사 뷰어에 검증 상태를 표시한다.
- 생성 이미지는 파일에서 매니페스트가 빠져도 외부 보관소에서 다시 찾게 한다.

## Ⅶ. 결론

- 출처 이력을 연결하고 서명·신뢰 경로를 관리한다.

### 쉽게 이해하기 (학습용)

- C2PA는 누가 기록을 봉인했는지 보여 주므로 서명 키·발행자와 매니페스트 복구 경로를 관리해야 한다.
