## 미리 알고가기

- **원격 직접 메모리 접근(Remote Direct Memory Access, RDMA)**: 영문 머리글자를 딴 표기로 “알디엠에이”로 읽으며, CPU 개입을 줄여 등록된 원격 메모리에 직접 접근하는 기술
- **핵심 가치**: 데이터 복사 감소와 커널 오버헤드 완화로 지연 시간과 CPU 사용률 절감
- **구현 네트워크**: InfiniBand와 RoCE 기반으로 구현되는 네트워크 기술



## Ⅰ. 개요

- **정의/개념**: 등록된 원격 메모리의 직접 접근
- **배경/필요성**: 일반 소켓 통신의 커널 경유·데이터 복사·문맥 전환으로 지연과 CPU 사용 증가

### 쉽게 이해하기 (학습용)

- 상대 메모리를 매번 복사하지 않고, 허가 구역을 운송 장치가 직접 읽고 쓰는 방식

## Ⅱ. 특징

- 원격 CPU 미개입 **읽기·쓰기·원자 연산**
- 메모리 등록 기반 **주소·권한·접근 키**
- 큐 페어 기반 **요청 순서·완료 추적**

### 쉽게 이해하기 (학습용)

- 허가 구역·작업 줄·완료 통지함이 준비된 직접 접근 방식

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 보호 영역 | 함께 사용할 메모리·큐 객체의 격리 경계를 형성함 |
| 등록 메모리·접근 키 | 주소·길이·권한을 고정하고 지역·원격 접근을 허가함 |
| 큐 페어 | 송신 큐와 수신 큐를 묶어 통신 종단과 순서를 구성함 |
| 작업 요청·동사 | 읽기·쓰기·원자·송수신 동작과 대상 버퍼를 지정함 |
| 완료 큐 | 작업 성공·오류와 완료된 요청 식별자를 기록함 |

> 요약: 메모리·키·큐를 묶고 완료 큐로 결과를 확인한다.

### 쉽게 이해하기 (학습용)

- 출입 구역, 열쇠, 작업 줄, 지시서, 완료함이 맞아야 직접 접근 가능

## Ⅳ. 원리 및 절차 흐름도

자원생성 → 메모리등록 → 정보교환 → 요청게시 → 권한검증 → 완료확인

| 절차 | 설명 |
|:---|:---|
| 보호 자원 생성 | 보호 영역·큐 페어·완료 큐를 같은 경계에 생성함 |
| 메모리 등록 | 주소·길이·권한을 등록하고 지역 키·원격 키를 발급함 |
| 연결 정보 교환 | 큐 정보와 허용한 원격 주소·키를 상대에게 전달함 |
| 작업 게시 | 목적에 맞는 읽기·쓰기·원자·송수신 동사를 큐에 넣음 |
| 검증·완료 | 어댑터가 키·권한을 검사하고 완료 큐의 상태를 확인함 |

> 요약: 메모리·큐 등록 뒤 허가된 키·동사로 실행한다.

### 쉽게 이해하기 (학습용)

- 창고 구역과 작업 줄 생성 후 열쇠를 교환하여 읽기·쓰기를 수행하고 통지함 확인

## Ⅴ. 원격 데이터 전송 방식 비교

| 구분 | 단측 RDMA | 양측 송신·수신 | 일반 소켓 통신 |
| 적용 기준 | 원격 메모리 직접 조작 | 양쪽 참여 메시지 전달 | 범용 호환 통신 |
| 핵심 특징 | 원격 CPU 미개입 읽기·쓰기 | 송신·수신 작업 매칭 | 커널 소켓·복사 경로 |
| 한계 | 등록·키·동기화 복잡성 | 수신 버퍼 사전 준비 | 지연·CPU 오버헤드 |
|:---|:---|:---|:---|
| 동작·원격 개입 | 읽기·쓰기·원자 연산, 원격 작업 요청 없음 | 송신과 게시된 수신 버퍼가 대응함 | 양쪽 응용·커널이 송수신을 처리함 |
| 사전 자원 | 등록 메모리·원격 주소·키·큐가 필요함 | 송수신 큐·게시 수신 버퍼가 필요함 | 연결·소켓 버퍼가 필요함 |
| 보호·적용 경계 | 허용 범위의 짧고 빈번한 직접 접근 | 원격 알림·메시지 경계가 필요할 때 | 범용성·단순성이 우선일 때 |

> 요약: 직접은 RDMA, 양측 처리는 송수신, 일반은 소켓이다.

### 쉽게 이해하기 (학습용)

- 창고 직접 읽기·쓰기 방식, 수신처 준비 방식, 일반 직원의 택배 처리 차이

## Ⅵ. 실무 사례

1. 분산 키값 저장소는 읽기 전용 원격 키로 값 영역만 RDMA 읽기하고 완료 큐에서 요청 성공을 확인함
2. 저장 복제기는 쓰기 구역을 작업별 등록해 원격 키를 발급하고 완료 후 등록 해제해 접근 기간을 제한함

### 쉽게 이해하기 (학습용)

- 조회용 읽기 열쇠와 복제 작업용 쓰기 열쇠를 필요한 기간에만 발급 후 해제하는 보호 방식

## Ⅶ. 결론

- 메모리 권한·키·큐·폐기 경계를 먼저 설계한다

### 쉽게 이해하기 (학습용)

- 빠른 출입보다 접근 구역과 시간, 작업 성공 확인 절차 설계가 우선임
