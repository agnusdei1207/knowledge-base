## 미리 알고가기

- **엣지 인공지능 (Edge Artificial Intelligence, Edge AI)**: 현장 근처에서 추론·제어하는 기술
- **게이트웨이 (Gateway)**: 센서 데이터 수집·정제 중계 장치
- **평균 복구 시간(Mean Time To Repair, MTTR)**: 장애 발생부터 수리 완료까지 걸린 평균 시간
- **무선 업데이트(Over-The-Air, OTA)**: 모델과 설정을 원격으로 배포·갱신하는 방식



## Ⅰ. 개요

- 정의/개념: 현장 장치에 추론·제어를 분산 배치
- 기존 한계: 중앙 클라우드만으로는 현장 제어 지연과 통신량을 줄이고 망 단절에도 서비스를 유지하기 어렵다.

### 쉽게 이해하기 (학습용)

- 현장 가까운 장비가 중앙 서버를 기다리지 않고 판단한다

## Ⅱ. 특징

- 현장 처리 기반 **저지연 제어·전송량 절감**
- 망 단절 시 **자율 동작·지연 전송**
- 중앙 관리 기반 **장비 버전·드리프트 통제**

### 쉽게 이해하기 (학습용)

- 필요한 데이터만 보내 통신량을 줄이고 단절에도 계속 동작한다

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| Sensor | 원시 데이터 생성함 |
| Gateway | 데이터 수집·동기화함 |
| Runtime | 모델 추론 수행함 |
| Actuator | 경보·제어 수행함 |
| Control | 장비 신원·OTA 관리함 |

현장 센서
├─ 게이트웨이
├─ 추론 엔진
└─ 안전 제어

### 쉽게 이해하기 (학습용)

- 현장 판단과 중앙 관리를 분리해 망 장애에도 제어함

## Ⅳ. 원리 및 절차 흐름도

요구정의
↓
배치설계
↓
현장추론
↓
운영개선

| 절차 | 설명 |
|:---|:---|
| 요구정의 | 지연·안전 기준 정의함 |
| 배치설계 | 기능·용량 배분함 |
| 현장추론 | 추론·제어·저장함 |
| 운영개선 | 모델 성능 개선함 |

### 쉽게 이해하기 (학습용)

- 현장 장비가 언제 스스로 결정하고 언제 중앙에 묻는지를 장애 상황까지 포함해 정해야 함

## Ⅴ. AI 추론 배치 위치 비교

| 구분 | 온디바이스 AI | 에지 AI | 클라우드 AI |
|:---|:---|:---|:---|
| 실행 단위 | 개별 단말 | 게이트웨이 | 중앙 서버 |
| 적용 기준 | 개인화 처리 | 저지연 제어 | 통합 분석 |
| 핵심 특징 | 단말 내부 직접 추론 | 현장 인접 서버 분산 추론 | 중앙 자원 통합 추론 |
| 한계 | 기기 파편화 | 관리 복잡성 | 집중 장애 |

> 요약: 현장 분산 처리로 지연과 장애를 해결함

### 쉽게 이해하기 (학습용)

- 중앙·현장 처리 분담은 지연과 관리 범위를 함께 바꾼다

## Ⅵ. 실무 사례

- 물리 접근·보안 위협 대비 Secure Boot·서명 적용함

> 요약: 현장별 성능 관측으로 신뢰성 보장함

### 쉽게 이해하기 (학습용)

- 현장 판단의 속도와 중앙 운영의 통제력을 함께 확보해야 Edge AI가 안정적으로 유지됨

## Ⅶ. 결론

- 현장 지연 극복을 위해 연결성·수명주기를 검토하여 **엣지 AI** 활용

### 쉽게 이해하기 (학습용)

- 현장은 즉시 판단하고 중앙은 여러 장비의 상태를 관리한다
