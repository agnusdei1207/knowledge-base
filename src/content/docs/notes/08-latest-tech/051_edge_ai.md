## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **엣지 인공지능(Edge Artificial Intelligence, Edge AI)**: 현장 인접 장치나 게이트웨이에서 인공지능 추론과 제어를 수행하는 분산 컴퓨팅 구조로 정의된다.
- **현장 자율 제어(Field Autonomous Control)**: 중앙 연결이 끊겨도 현장 장치가 로컬 판단으로 안전 동작을 계속하는 능력을 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.

</details>

- 정의: 현장 인접 장치에서 추론•제어를 수행하는 **엣지 AI**이다.
- 배경/필요성: 중앙 클라우드의 **왕복 지연•통신 단절** 기반 현장 자율 제어에 제약이 따름.

#### 한줄 요약
- **현장 인접 추론•제어** 및 중앙 운영 관리의 분산 구조

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **지연 동기화(Deferred Synchronization)**: 망 단절 중 결과를 로컬에 저장한 뒤 연결 복구 시 중앙으로 전송하는 방식.
- **중앙 제어면(Central Control Plane)**: 분산 장치의 신원•정책•모델 버전•운영 상태를 통합 관리하는 계층을 나타낸다.
- **모델 드리프트(Model Drift)**: 운영 데이터의 특성이 변해 모델 예측 품질이 학습 시점보다 낮아지는 현상이다.

</details>

- **현장 인접 추론**: 응답 지연과 원시 데이터 전송 감소
- **로컬 자율 제어•지연 동기화**: 망 단절 대응
- **중앙 제어면**: 모델 버전•드리프트•장치 수명주기 통제

#### 한줄 요약
- **로컬 자율 제어•지연 동기화** 기반 단절 대응

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **엣지 게이트웨이(Edge Gateway)**: 센서 데이터를 수집•전처리하고 현장 장치와 중앙 시스템을 연결하는 장치를 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.
- **추론 런타임(Inference Runtime)**: 학습된 모델을 목표 장치에서 불러와 입력 처리와 결과 생성을 실행하는 소프트웨어.
- **액추에이터(Actuator)**: 추론 결과에 따라 경보•차단•구동 같은 물리 동작을 수행하는 장치를 나타낸다.
- **로컬 저장소(Local Storage)**: 망 단절 중 결과와 장치 상태를 임시 보관하는 저장소이다.

</details>

```text
                         [중앙 제어면]
                               |
                         [엣지 게이트웨이]
                          /           \
                 [센서•카메라]     [추론 런타임]
                                    /           \
                             [액추에이터]     [로컬 저장소]
```

선의 의미: 중앙 제어면의 게이트웨이 정책 관리, 게이트웨이의 센서•런타임 연결, 런타임의 액추에이터•로컬 저장소 실행 경계 사용을 나타냄.

| 구성요소 | 책임 |
|:---|:---|
| 센서•카메라 | 현장 **원시 데이터 생성** |
| 엣지 게이트웨이 | 데이터 **수집•동기화•전처리** |
| 추론 런타임 | **모델 실행•임계조건 판정** |
| 액추에이터 | 추론 결과에 따른 **즉시 제어** |
| 로컬 저장소 | **단절 구간 결과•상태 보관** |
| 중앙 제어면 | **장치 신원•모델 버전•OTA Update 관리** |

#### 한줄 요약
- **수집•추론•제어•저장•중앙 관리** 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **입력 전처리(Input Preprocessing)**: 원시 센서 데이터를 모델 입력 형식으로 변환하고 불필요한 정보를 제거하는 과정.
- **상태 동기화(State Synchronization)**: 현장 결과와 장치 상태를 중앙 제어면에 전달하여 운영 이력을 일치시키는 기법으로 정의된다.

</details>

```text
센서 ── 현장 데이터 전달 ──▶ 게이트웨이
                               │ 1. 입력 전처리
                               ▼
                            추론 런타임
                               │ 2. 로컬 추론 판정
                               ▼
                            액추에이터
                               │ 3. 즉시 제어 수행
                               ▼
                            게이트웨이
                               │ 4. 결과•상태 동기화
                               ▼
                            중앙 제어면
```

### 동작 원리

1. 입력 전처리: 모델 입력 형식 변환과 불필요 데이터를 제거함.
2. 로컬 추론 판정: 지연•안전 임계조건에 따른 현장 결과를 확정함.
3. 즉시 제어 수행: 망 상태와 무관한 경보•차단•장치 동작을 실행함.
4. 결과•상태 동기화: 단절 구간 결과와 장치 상태를 연결 복구 후 전송함.

#### 한줄 요약
- **전처리•로컬 판정•즉시 제어•상태 동기화** 수행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **온디바이스 인공지능(On-Device Artificial Intelligence, On-Device AI)**: 개인 단말이 독립적으로 로컬 추론을 수행하는 방식이다.
- **클라우드 인공지능(Cloud Artificial Intelligence, Cloud AI)**: 중앙의 고성능 자원으로 대규모 통합 분석과 모델 관리를 수행하는 구조를 나타낸다.

</details>

| 추론 배치 방식 | 온디바이스 AI | 엣지 AI | 클라우드 AI |
|:---|:---|:---|:---|
| 적용 기준 | 개인 단말의 **독립•개인화 처리** | 현장 단위 **저지연•다장치 처리** | 대규모 **통합 분석•고성능 연산** |
| 핵심 특징 | 단말 내부 **직접 추론** | 현장 인접 게이트웨이 **분산 추론** | 중앙 자원 **통합 추론** |
| 한계 | 단말 **자원•기종 파편화** | 분산 장비의 **운영 복잡성** | **망 지연•단절•원시 데이터 전송** |

#### 한줄 요약
- **지연•장치 범위•통합 분석** 대상 따라 실행 위치 선택

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **보안 부팅(Secure Boot)**: 서명된 신뢰 코드만 장치 시작 과정에서 실행하는 보호 기법으로 정의된다.
- **무선 업데이트(Over-the-Air Update, OTA Update)**: 모델과 설정을 네트워크로 원격 배포•갱신하는 방식을 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.
- **롤백(Rollback)**: 배포 장애가 발생하면 모델과 설정을 이전 정상 버전으로 되돌리는 복구 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 망 단절** 시 중앙 추론•제어 불능 | **로컬 자율 제어•지연 동기화 | 단절 구간 **현장 제어 연속성** 확보 |
| 이기종 장치별 **OTA Update 호환성 불일치** | 장치군별 **단계 배포•롤백** | 현장 장비의 **버전 파편화** 억제 |
| 위변조 펌웨어•모델 적재 | **보안 부팅•서명 검증** | **신뢰 실행 기반** 확보 |

#### 한줄 요약
- **단절•버전•신뢰 실행** 중앙에서 통제

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **엣지 배치 기준(Edge Deployment Criteria)**: 망 단절에도 지속해야 하는 실시간 현장 판단과 제어를 인접 장치에 두는 기준으로 정의된다.
- **클라우드 배치 기준(Cloud Deployment Criteria)**: 여러 현장의 통합 분석•모델 학습•버전 관리는 중앙 자원에 두는 규칙이다.

</details>

- 실시간•단절 제어는 **엣지**, 통합 분석•모델 관리는 **클라우드** 배치

#### 한줄 요약
- **실시간성•통합 범위** 대상 따라 실행 위치 결정
