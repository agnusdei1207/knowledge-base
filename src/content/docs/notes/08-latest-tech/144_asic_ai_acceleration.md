## 미리 알고가기

- **ASIC AI 가속 (Application Specific Integrated Circuit, ASIC)**: 특정 AI 연산 전용 회로 설계 방식
- **유연성**: 유연성은 낮으나 대량 추론의 전력 효율·처리량 극대화
- **도입 판단**: 높은 초기 설계비와 긴 개발 기간 고려 필요



## Ⅰ. 개요

- **정의/개념**: AI 데이터 흐름을 고정한 전용 반도체
- **배경/필요성**: 안정 워크로드의 전력당 처리량 개선

### 쉽게 이해하기 (학습용)

- 한 제품만 오래 대량 생산하도록 계산대와 운반 통로를 칩에 고정해 두는 전용 공장과 같음

## Ⅱ. 특징

- 고정 연산·데이터 경로가 전력 효율을 높인다
- 온칩 전달이 외부 메모리 이동을 줄인다
- 제조 후 새 연산은 소프트웨어 범위에서만 수용한다
- 생산량 증가는 칩당 초기 비용을 낮춘다

### 쉽게 이해하기 (학습용)

- 전용 공장은 같은 제품을 가장 적은 전력으로 만들지만 제품 설계가 바뀌면 생산라인을 고치는 대신 새 칩을 설계해야 함

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 고정 연산 배열 | 특정 정밀도 연산 전용 회로 처리 |
| 온칩 메모리 | 연산기 근접 데이터·가중치 저장 |
| 데이터 연결망 | 연산자 간 병렬 데이터 이동 고정 |
| 제어 제어기 | 외부 메모리·호스트 요청 공급 |
| 전력 제어 | 연산 블록 전원·열 관리 |

> 요약: 메모리 공급과 고정 연산 배열로 데이터 흐름을 실행한다.

### 쉽게 이해하기 (학습용)

- 큰 창고의 재료를 작은 내부 창고에 가져오고 고정 통로로 계산대에 전달하며 전력과 열이 한도를 넘지 않게 관리함

## Ⅳ. 원리 및 절차 흐름도

```text
워크로드확정
    ↓
데이터흐름설계
    ↓
회로구현
    ↓
검증제조
    ↓
모델배포
```

| 절차 | 설명 |
|:---|:---|
| 워크로드확정 | 양산 수량·모델 변경 주기 결정함 |
| 데이터흐름설계 | 연산 배열·수치 폭·메모리 배분함 |
| 회로구현 | 논리 회로 및 물리 배치 수행함 |
| 검증제조 | 연산 정확성·전력 한도 검증 후 제조함 |
| 모델배포 | 지원 연산 기반 모델 컴파일·배포함 |

> 요약: 워크로드를 회로화하고 검증·제조해 모델을 배포한다.

### 쉽게 이해하기 (학습용)

- 무엇을 몇 개나 얼마나 오래 만들지 정한 뒤 생산라인을 설계하고 검증 생산을 통과해야 실제 칩을 찍어 모델을 올릴 수 있음

## Ⅴ. 종류 및 비교

| 판단 기준 | GPU | FPGA | ASIC |
|:---|:---|:---|:---|
| 프로그래머빌리티 | 소프트웨어 커널·명령 변경 | 비트스트림으로 회로 재구성 | 제조 후 지원 연산 고정 |
| 개발비·효율 경계 | 개발비 낮음·범용 오버헤드 큼 | 개발비 중간·맞춤 효율 | 초기 설계비 최고·전력 효율 최고 |
| 적용 기준 | 모델·연산 변경이 잦을 때 | 고정 지연과 회로 변경이 필요할 때 | 안정된 워크로드를 대량 배치할 때 |

> 요약: 변경 GPU, 재구성 FPGA, 고정 ASIC을 고른다.

### 쉽게 이해하기 (학습용)

- 작업 지시를 자주 바꾸면 GPU, 생산라인을 다시 연결해야 하면 FPGA, 같은 제품을 오래 대량 생산하면 ASIC을 선택함

## Ⅵ. 실무 사례

1. 엣지 카메라 AI 칩은 양자화 합성곱·활성화 경로를 고정 회로로 구현해 장치 전력 한도에서 추론함
2. 데이터센터 추론 ASIC은 반복 행렬 연산과 온칩 가중치 재사용을 고정하고 양산·배치 수량으로 초기 설계비를 회수함

### 쉽게 이해하기 (학습용)

- 카메라 칩은 자주 쓰는 영상 계산만 남긴 전용 회로로 전력을 줄이고, 데이터센터 칩은 같은 계산을 대량 배치해 큰 설계비를 나눠 부담함

## Ⅶ. 결론

- 장기 고정 작업이 설계비를 회수하면 ASIC을 쓴다

### 쉽게 이해하기 (학습용)

- 같은 제품을 오래 많이 만들수록 ASIC이 유리하지만 제품이 자주 바뀌면 새 생산라인 비용 때문에 재구성 장비가 나음
