## 미리 알고가기

- **InfiniBand**: 고성능 컴퓨팅과 AI 클러스터에서 노드 간 저지연 고대역 통신을 제공하는 패브릭 기술
- **원격 직접 메모리 접근(Remote Direct Memory Access, RDMA)**: 영문 머리글자를 딴 표기로 “알디엠에이”로 읽으며, CPU 개입을 줄여 노드 간 등록 메모리를 직접 전송하는 기술
- **NVLink**: 노드 내부 GPU 간 연결을 위한 고속 인터커넥트 기술



## Ⅰ. 개요

- **정의/개념**: 저지연 클러스터용 스위치 패브릭
- **배경/필요성**: 일반 소켓·이더넷만으로 대규모 집단통신의 지연·CPU 부하·손실 제어 한계

### 쉽게 이해하기 (학습용)

- 서버 간 전용 도로·교차로·주소 배정자·통행 규칙을 갖춘 네트워크

## Ⅱ. 특징

- 서브넷 관리자의 **주소·경로·분할 설정**
- 채널 어댑터 기반 **RDMA 전송**
- 흐름·혼잡 제어와 **적응형 경로**

### 쉽게 이해하기 (학습용)

- 중앙 관리자의 길 설정, 통로 분리, 정체 발생 시 경로 분산 구조

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 호스트 채널 어댑터 | 응용 요청을 전송 메시지로 만들고 RDMA·완료 처리를 수행함 |
| InfiniBand 스위치 | 목적지 주소와 경로표에 따라 패킷을 전달함 |
| 서브넷 관리자 | 장치 발견·주소 할당·경로표·분할 키를 설정함 |
| 전송·큐 계층 | 전송 유형별 연결·순서·재전송 조건과 송수신 큐를 관리함 |
| 혼잡·서비스 계층 | 가상 통로·서비스 수준·혼잡 신호·우회 경로를 제어함 |

```text
[호스트 채널 어댑터] ↔ [InfiniBand 스위치 패브릭] ↔ [호스트 채널 어댑터]
                              ↑ 경로·분할 설정
                         [서브넷 관리자]
```

> 요약: 관리자가 경로·분할과 전송·혼잡 흐름을 제어한다.

### 쉽게 이해하기 (학습용)

- 서버 출입구, 교차로, 관리자, 배송 규칙, 정체 관제 기능이 구성

## Ⅳ. 원리 및 절차 흐름도

```text
장치발견 → 경로설정 → 큐준비 → 패킷전송 → 혼잡판단 → 속도조정
```

| 절차 | 설명 |
|:---|:---|
| 서브넷 발견 | 관리자가 채널 어댑터·스위치·포트 상태를 수집함 |
| 주소·격리 설정 | 지역 주소와 분할 키를 할당해 통신 범위를 제한함 |
| 경로 구성 | 목적지별 경로표와 서비스 수준·가상 통로를 설정함 |
| 전송 처리 | 종단 전송 계층이 패킷화하고 스위치가 경로대로 전달함 |
| 혼잡 대응 | 혼잡 신호·포트 사용률에 따라 속도나 경로를 조정함 |

> 요약: 주소·경로를 만들고 혼잡 신호로 전송을 조정한다.

### 쉽게 이해하기 (학습용)

- 관리자가 출입구·교차로를 찾아 권한·경로를 정하고, 정체 시 속도·길을 바꿈

## Ⅴ. 가속기 연결 기술 비교

| 구분 | InfiniBand | 이더넷 기반 RDMA | NVLink·NVSwitch |
| 적용 기준 | 전용 저지연 클러스터 | 기존 이더넷망 활용 | 서버 내부 GPU 연결 |
| 핵심 특징 | 손실 제어·RDMA 통합 패브릭 | RoCE 기반 원격 메모리 전송 | GPU 메모리 고속 연결 |
| 한계 | 전용 장비·운영 비용 | 혼잡·무손실망 구성 부담 | 노드 간 연결 범위 제한 |
|:---|:---|:---|:---|
| 패브릭·제어 범위 | 전용 서브넷 관리자가 경로·분할을 설정함 | 이더넷 제어와 무손실 설정을 조합함 | GPU 확장 도메인을 관리함 |
| 전송·RDMA 계층 | 채널 어댑터가 메시지·RDMA 전송을 제공함 | 이더넷 위 RDMA 전송을 제공함 | GPU 메모리 통신을 직접 제공함 |
| 적용 경계 | 랙 간 계산·저장 클러스터 | 기존 이더넷 운영을 활용할 때 | 서버·랙 안 GPU 다대다 통신 |

> 요약: IB·RDMA·NVLink를 연결 범위로 고른다.

### 쉽게 이해하기 (학습용)

- 전용 도시형 물류체계(InfiniBand), 기존 도로망 강화(이더넷 RDMA), 서버 내 전용 통로(NVLink)

## Ⅵ. 실무 사례

1. 다중 랙 학습 클러스터는 집단 통신 경로를 분산하고 혼잡 포트의 완료 지연이 커지면 우회 경로를 적용함
2. 계산·저장 노드가 같은 패브릭을 쓰는 환경은 분할 키와 서비스 수준으로 트래픽을 격리함

### 쉽게 이해하기 (학습용)

- 권한과 전용 차선으로 트래픽을 격리하고 정체 시 우회 경로로 운영함

## Ⅶ. 결론

- 경로·격리·전송·혼잡을 함께 설계한다

### 쉽게 이해하기 (학습용)

- 빠른 전송 선로뿐만 아니라 관리 체계와 정체 대응까지 갖춰야 성능 유지 가능
