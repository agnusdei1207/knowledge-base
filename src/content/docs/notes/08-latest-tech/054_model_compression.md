## 미리 알고가기

- **모델 압축 (Model Compression)**: 모델 구조·정밀도 축소 배포 최적화
- **가지치기 (Pruning)**: 기여도 낮은 가중치·구조 제거 기법
- **양자화 (Quantization)**: 데이터 표현 비트 축소 기법
- **지식 증류 (Knowledge Distillation)**: 교사 모델 지식 전달 학생 학습 기법



## Ⅰ. 개요

- 정의/개념: 모델 크기·연산량을 줄이면서 목표 품질을 보존하는 배포 최적화 기술
- **배경/필요성**: 원본 모델 그대로는 단말의 메모리·지연·전력 한도 충족 곤란

### 쉽게 이해하기 (학습용)

- 모델을 줄여도 하드웨어가 지원해야 실제로 빨라진다

## Ⅱ. 특징

- **가지치기·양자화·증류** 기반 경량화
- 적용 순서·재학습에 따른 **품질 보정**
- 모델 크기·연산량과 **실행 커널 가속** 공동 평가

### 쉽게 이해하기 (학습용)

- 짐의 무게를 줄여도 운반 도구가 새 포장을 처리하지 못하면 이동 시간이 줄지 않을 수 있음

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 설계 요소 | 설명 |
|:---|:---|
| 프로파일러 | 병목·품질 측정함 |
| 설계기 | 압축 기법 선택함 |
| 보정 계층 | 변환 오차 조절함 |
| 런타임 | 커널 매핑 수행함 |
| 평가 계층 | SLO 품질 검증함 |

```text
기준 모델
├─ 압축 설계
├─ 보정 학습
├─ 실행 계층
└─ 성능 평가
```

### 쉽게 이해하기 (학습용)

- 원본 기준·보정 자료·실행 엔진을 함께 관리함

## Ⅳ. 원리 및 절차 흐름도

```text
목표 설정
↓
기법 선택
↓
변환 복원
↓
성능 검증
```

| 절차 | 설명 |
|:---|:---|
| 설정 | 기준·지표 정의함 |
| 선택 | 기법·병목 매핑함 |
| 복원 | 보정·재학습함 |
| 검증 | 장비 실제 검증함 |

### 쉽게 이해하기 (학습용)

- 같은 입력·장비에서 압축 전후 품질·자원을 비교함

## Ⅴ. 모델 압축 기법 비교

| 구분 | 가지치기 | 양자화 | 지식 증류 |
|:---|:---|:---|:---|
| 원리 | 구조·연결 제거 | 표현 비트 하향 | 지식 이전 수행 |
| 적용 기준 | 희소 구조 지원 | 메모리 대역폭 한계 | 재학습 자원 존재 |
| 핵심 특징 | 가중치·채널 제거 | 표현 비트 수 축소 | 교사 출력을 학생에 전달 |
| 한계 | 희소 가속 지원 필요 | 정밀도 손실·연산자 제약 | 교사 편향·학습 비용 |
| 확인 사항 | 커널 품질 회복 | 보정 품질 점검 | 교사 능력 전이 |

> 요약: 자원 제한에 맞춰 최적 압축 기법을 선택함

### 쉽게 이해하기 (학습용)

- 가지치기·양자화·증류는 배포 병목에 맞춰 선택함

## Ⅵ. 실무 사례

- 폴백·역양자화·희소 인덱스가 지연을 늘린다

### 쉽게 이해하기 (학습용)

- 저장 공간이 줄었다는 결과와 서비스가 빨라졌다는 결과를 분리해 실제 요청으로 확인해야 함

## Ⅶ. 결론

- 자원 한계 극복을 위해 품질·지연을 검토하여 **모델 압축** 활용

> 요약: 실제 장비 SLO를 만족하는 효율적 모델을 선택함

### 쉽게 이해하기 (학습용)

- 가장 많이 줄인 모델이 아니라 필요한 품질을 만족하며 실제 장비에서 가장 효율적인 모델이 적합함
