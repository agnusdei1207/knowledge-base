## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **모델 압축(Model Compression)**: 목표 품질을 유지하며 모델 구조•표현 정밀도•학습 지식을 줄여 배포 자원 사용을 낮추는 기술을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.
- **배포 자원(Deployment Resources)**: 모델 실행에 필요한 메모리•연산량•전력•응답 시간의 한도를 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.

</details>

- 정의/개념: 구조•정밀도•학습 지식을 줄이는 **모델 압축**
- 배경/필요성: 원본 모델의 **메모리•지연•전력**이 단말 예산 초과

#### 한줄 요약
- **품질 한도** 안에서 배포 자원을 줄이는 최적화

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **가지치기(Pruning)**: 기여도가 낮은 가중치•채널•계층을 제거하는 구조 압축 기법을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.
- **양자화(Quantization)**: 가중치와 활성값을 더 적은 비트로 표현하는 정밀도 압축 기법을 나타낸다.
- **지식 증류(Knowledge Distillation)**: 큰 교사 모델의 출력 분포를 작은 학생 모델이 학습하는 압축 기법을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.

</details>

- **가지치기•양자화•지식 증류**: 구조•표현•지식 축소
- **보정•재학습**: 압축 변환 뒤 목표 품질 회복
- **커널 가속•종단 지연**: 실제 장치의 압축 효과 검증

#### 한줄 요약
- **커널 지원•종단 지연**이 실제 압축 효과 결정

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **프로파일러(Profiler)**: 모델 실행 구간별 시간•메모리•연산 사용량을 측정해 병목을 찾는 도구를 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.
- **압축 변환기(Compression Transformer)**: 가지치기•양자화•저랭크 분해•증류 등 선택 기법으로 모델 구조와 표현을 줄이는 구성요소를 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.
- **보정 데이터(Calibration Data)**: 양자화 범위나 압축 후 품질을 조정하도록 운영 입력을 대표해 제공하는 데이터를 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.
- **보정•재학습기(Calibration/Retraining Module)**: 압축으로 달라진 분포와 손실을 보정하여 허용 품질을 회복하는 구성요소를 나타낸다.
- **목표 런타임(Target Runtime)**: 압축된 연산•자료형•희소 패턴을 실제 장치에서 실행하는 소프트웨어 환경을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.

</details>

```text
[기준선 관리기]──[병목 프로파일러]──[압축 변환기]
                                          │
                                  [보정•재학습기]
                                          │
                                    [배포 검증기]
```

선의 의미: 기준•병목•변환•복구•검증 책임의 정적 연결을 나타냄.

| 구성요소 | 책임 |
|:---|:---|
| 기준선 관리기 | **압축 전 품질•자원 기준선** 관리 |
| 병목 프로파일러 | **메모리•연산•전송 병목** 식별 |
| 압축 변환기 | 병목에 맞는 **압축 기법 변환** |
| 보정•재학습기 | **보정 데이터•재학습**으로 오차 회복 |
| 배포 검증기 | 실제 장치의 **품질•지연•전력 검증** |

#### 한줄 요약
- **기준선•병목•변환•복구•배포 검증** 구성

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **기준선(Baseline)**: 압축 전 모델의 과업 품질•크기•지연•전력 측정값을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.
- **종단 지연(End-to-End Latency)**: 입력 전처리부터 모델 실행•후처리까지 전체 요청에 걸린 시간을 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.
- **회귀 시험(Regression Test)**: 압축 전후 동일 입력의 품질을 비교해 기존 과업의 성능 저하를 확인하는 시험을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.

</details>

```text
기준선 관리기
      │ 1. 기준 성능 측정
      ▼
병목 프로파일러
      │ 2. 병목 기반 기법 선택
      ▼
압축 변환기
      │ 3. 모델 압축 변환
      ▼
품질 복구기
      │ 4. 보정•재학습
      ▼
배포 검증기
      │ 5. 목표 장치 회귀 검증
      ▼
기준선 관리기
```

### 동작 원리

1. **기준 성능 측정**: 원본 모델의 품질•크기•지연•전력을 기록함.
2. **병목 기반 기법 선택**: 메모리•연산•전송 제한에 맞는 압축을 결정함.
3. **모델 압축 변환**: 가지치기•양자화•지식 증류를 적용함.
4. **보정•재학습**: 보정 데이터로 변환 오차와 품질 손실을 회복함.
5. **목표 장치 회귀 검증**: 압축 전후 품질•종단 지연•자원을 비교함.

#### 한줄 요약
- **기준선•병목 선택•압축•복구•회귀 검증** 수행

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **가지치기**: 희소•축소 구조를 지원하는 장치에서 불필요한 구조를 제거한다.
- **양자화**: 메모리 대역폭과 정수 연산이 병목인 장치에서 표현 비트를 줄인다.
- **지식 증류**: 재학습 가능한 환경에서 교사 능력을 작은 학생 구조로 이전한다.

</details>

| 모델 압축 기법 | 가지치기 | 양자화 | 지식 증류 |
|:---|:---|:---|:---|
| 적용 기준 | **희소•축소 구조 지원 장치** | **메모리 대역폭•정수 연산 장치** | **소형 모델 재학습 가능 환경** |
| 핵심 특징 | **가중치•채널•계층 제거** | **가중치•활성값 비트 축소** | **교사 출력의 학생 모델 이전** |
| 한계 | **희소 커널•재학습 의존** | **정밀도 손실•연산자 제약** | **교사 편향•추가 학습 비용** |

#### 한줄 요약
- **런타임 지원•재학습 자원**에 따라 압축 기법 선택

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **실행 커널**: 목표 프로세서에서 특정 연산•자료형•희소 패턴을 실제 수행하는 저수준 코드다.
- **폴백**: 목표 장치가 지원하지 않는 연산을 다른 프로세서에서 대신 실행하는 처리다.
- **역양자화**: 낮은 정밀도 값을 연산에 필요한 높은 정밀도 표현으로 복원하는 변환을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 압축 변환으로 **과업 정확도** 저하 | 기준 데이터 기반 **보정•재학습** | 압축 후 **허용 품질** 회복 |
| **커널 미지원•폴백**으로 실측 지연 미감소 | 장치별 **연산자•자료형•희소 패턴** 확인 | 명목 압축의 **실행 가속** 전환 |
| 복합 압축 순서에 따른 **오차 누적** | 기법 조합•순서별 **회귀 시험** | **가지치기•양자화** 상호 품질 손실 억제 |
| 빈번한 **역양자화**로 변환 비용 증가 | **연산자 융합•양자화 경계 축소** | **자료형 변환 비용** 감소 |

#### 한줄 요약

- **품질•폴백•자료형 변환•실기기 지연** 검증

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **양자화•가지치기 선택 기준**: 메모리•연산 병목을 목표 런타임이 낮은 정밀도나 희소 구조로 가속할 때 적용한다.
- **지식 증류 선택 기준**: 더 작은 구조가 필요하고 교사 출력으로 학생 모델을 재학습할 수 있을 때 적용한다.

</details>

- 메모리•연산 병목은 **양자화•가지치기**, 구조 소형화는 **지식 증류** 선택

#### 한줄 요약
- **병목•런타임 지원•품질 한도**로 압축 기법 결정
