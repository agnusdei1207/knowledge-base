## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **데이터 증강(Data Augmentation)**: 원본의 정답 의미를 보존하는 변형으로 학습 표본을 늘리는 일반화 기법이다.
- **라벨 보존**: 변환 뒤에도 원본에 부여한 정답•개체•의도•사건이 그대로 유지되는 성질이다.

</details>

- 정의/개념: 원본 라벨을 보존한 변형 표본으로 학습셋을 넓히는 **데이터 일반화 기법**이다.
- 배경/필요성: 제한된 원본만으로는 **환경 변형** 대응력이 낮고 과적합이 증가한다.

#### 한줄 요약
- 같은 대상을 여러 각도나 표현으로 바꿔도 정답을 찾도록 학습합니다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **변환 정책**: 데이터 양식과 도메인에 맞춰 증강 종류•강도•적용 확률을 정한 규칙이다.
- **라벨 오염**: 증강 변환이 원본 정답의 의미를 훼손하여 잘못된 학습 신호를 만드는 현상이다.
- **미증강 검증셋**: 실제 환경 일반화를 평가하도록 원본 분포를 유지한 독립 평가 데이터다.

</details>

- 원본 정답 의미를 유지하는 **라벨 보존 변환**이 핵심이다.
- 이미지•텍스트•음성별 **변환 정책의 종류•강도**가 핵심이다.
- 증강 표본의 유효성을 가리는 **라벨 오염 검사•미증강 검증셋 평가**가 핵심이다.

#### 한줄 요약
- 매체별 변환이 정답 의미를 바꾸면 잘못된 학습 신호가 됩니다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **보존 규칙**: 변환 후에도 유지해야 할 개체•의도•위치•사건 조건을 명시한 기준이다.
- **증강 선택기**: 라벨 보존 검사를 통과한 후보만 학습기에 공급한다.
- **혼합 비율**: 원본과 증강 표본을 학습에 공급하는 상대 비중이다.

</details>

```text
[데이터 증강 체계]
 ├─ [원본 데이터]
 ├─ [변환 정책]──[보존 규칙]
 └─ [증강 선택기]──[혼합 비율]
```

선의 의미: 원본을 기준으로 변환•보존 검사•공급 비율을 소유한 정적 책임을 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 원본 데이터 | **증강 기준•원본 라벨** 제공 |
| 변환 정책 | 도메인별 **변환 종류•강도** 정의 |
| 보존 규칙 | 유지할 **개체•의도•사건** 명시 |
| 증강 선택기 | **라벨 보존 후보**만 공급 |
| 혼합 비율 | 검증 결과 기반 **공급 비중** 결정 |

#### 한줄 요약
- 원본 라벨을 보존한 증강 후보만 학습에 사용합니다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **증강 후보**: 변환 정책을 원본에 적용했지만 아직 라벨 보존 검사를 통과하지 않은 표본이다.
- **성능 피드백**: 미증강 검증셋의 결과로 변환 종류•강도•혼합 비율을 조정하는 정보다.

</details>

```text
원본 데이터
   │ 1. 원본•라벨 제공
   ▼
┌──────── 미증강 검증 목표 충족 전 ────────┐
│ 변환 정책                                │
│   │ 2. 증강 후보 생성                    │
│   ▼                                      │
│ 보존 검증기                              │
│   │ 3. 라벨 보존 표본 전달              │
│   ▼                                      │
│ 학습기                                   │
│   └ 4. 검증 성능 피드백 ──▶ 변환 정책   │
└──────────────────────────────────────────┘
```

**동작 원리**

1. **원본•라벨 제공**: 변환 뒤 유지할 개체•의도•사건을 정의한다.
2. **증강 후보 생성**: 도메인별 변환 종류•강도의 확률을 적용한다.
3. **라벨 보존 표본 전달**: 의미 훼손•분포 이탈 후보를 제외한다.
4. **검증 성능 피드백**: 미증강 검증셋 성능 기반 정책•비율을 조정한다.

#### 한줄 요약
- 라벨 보존 변환만 생성하고 실제 검증셋으로 효과를 평가합니다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **이미지 증강**: 회전•밝기•가림을 적용하되 방향과 위치가 라벨을 바꾸지 않는 범위에서 사용한다.
- **텍스트 증강**: 역번역•동의어 치환으로 표현을 바꾸되 개체와 의도를 보존한다.
- **음성•시계열 증강**: 이동•잡음•속도를 바꾸되 신호가 나타내는 사건의 정체를 보존한다.

</details>

| 데이터 양식 | 이미지 증강 | 텍스트 증강 | 음성•시계열 증강 |
|:---|:---|:---|:---|
| 적용 기준 | **촬영 변화** 대응 | **의도•관계** 유지 | **사건 정체** 유지 |
| 핵심 특징 | **회전•밝기•가림** | **역번역•동의어 치환** | **이동•잡음•속도** 변경 |
| 한계 | 방향•위치의 **라벨 변경** | 개체•**의미 변경** | 신호•**사건 훼손** |

#### 한줄 요약
- 이미지•텍스트•음성은 라벨을 보존하는 변환이 다릅니다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **과도한 변환**: 증강 강도가 커져 원본 정답의 의미와 실제 분포를 벗어나는 문제다.
- **성능 과대평가**: 증강과 유사한 분포로만 평가하여 실제 환경 일반화 성능이 높게 보이는 문제다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 과도한 변환으로 **라벨 오염** 발생 | 도메인별 **라벨 보존 규칙** 적용 | 증강 표본의 정답 의미 유지 |
| 증강 분포 평가로 **성능 과대평가** | 독립 **미증강 검증셋** 사용 | 실제 환경 일반화 검증 |

#### 한줄 요약
- 조명과 표현은 바꾸되 결함 모양이나 문의 의도가 달라진 자료는 제외합니다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **변환 정책 선택**: 라벨 보존 규칙을 통과하고 미증강 검증 성능을 높이는 종류와 강도를 사용한다.
- **혼합 비율 결정**: 증강 표본이 원본 분포를 압도하지 않도록 실제 일반화 성능을 기준으로 조정한다.

</details>

- **라벨 보존•미증강 성능**을 기준으로 변환 정책과 원본•증강 혼합 비율을 결정한다.

#### 한줄 요약
- 정답을 바꾸는 변형은 제외하고 실제 검증 데이터로 성과를 확인해야 합니다.
