## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **데이터 증강(Data Augmentation)**: 원본의 정답 의미를 보존하는 변형으로 학습 표본을 늘리는 일반화 기법이다.
- **라벨 보존(Label Preservation)**: 변환 뒤에도 원본에 부여한 정답•개체•의도•사건이 그대로 유지되는 성질.

</details>

- 정의/개념: 라벨 보존 변형으로 학습셋을 넓히는 **데이터 증강**
- 배경/필요성: 머신러닝 및 딥러닝 모델 학습 시 한정된 원본 데이터 표본으로 인해 특정 배경, 조명, 문체, 어휘 등의 부수적 패턴에 과적합(Overfitting)되어 실제 운영 환경의 다양한 변형 입력에 대한 일반화(Generalization) 성능이 급격히 저하되는 문제가 발생함에 따라, 원본 데이터의 고유한 라벨 의미(Ground Truth Label)를 완벽히 보존하면서 규칙 기반 또는 신경망 기반의 다양한 기하학적·의미론적 변형을 가하는 데이터 증강(Data Augmentation: Image Geometric/Color Transforms, Mixup/CutMix, Text Back-Translation & EDA, Audio Time-Stretching) 기법을 도입하여 **추가적인 고비용 데이터 수집 없이도 학습 데이터셋의 다양성과 표본 공간을 획기적으로 확장, 입력 데이터의 회전/잡음/표현 변화에 강건한(Robust) 불변성(Invariance) 특징 학습 유도, 과적합 방지를 통한 실서비스 배포 시의 모델 정확도 및 신뢰성 극대화**를 달성할 필요

#### 한줄 요약
- **라벨 보존 변환**은 수집 없이 표본 다양성을 사지만 변형이 지나치면 라벨이 어긋나 잡음을 학습시키므로, 증강 강도는 도메인이 허용하는 불변성의 범위를 넘지 않아야 한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **변환 정책(Augmentation Policy)**: 데이터 양식과 도메인에 맞춰 증강 종류•강도•적용 확률을 정한 규칙이다.
- **라벨 오염(Label Corruption)**: 증강 변환이 원본 정답의 의미를 훼손하여 잘못된 학습 신호를 만드는 현상으로 정의된다.
- **미증강 검증셋(Clean Validation Set)**: 실제 환경 일반화를 평가하도록 원본 분포를 유지한 독립 평가 데이터를 나타낸다.

</details>

- **라벨 보존 변환**: 원본 정답 의미 유지
- **변환 정책**: 이미지•텍스트•음성별 종류•강도 결정
- **라벨 오염•미증강 평가**: 증강 표본의 유효성 판정

#### 한줄 요약
- 매체별 변환의 **라벨 보존•오염 위험** 검증

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **보존 규칙(Preservation Rules)**: 변환 후에도 유지해야 할 개체•의도•위치•사건 조건을 명시한 기준이다.
- **혼합 비율(Mixing Ratio)**: 원본과 증강 표본을 학습에 공급하는 상대 비중을 가리킨다.

</details>

```text
[Data Augmentation System]
├── [원본 데이터 관리]
│   └── [원본 데이터 (Raw Data)]
├── [변환 정책 계층]
│   ├── [변환 정책 (Augmentation Policy)]
│   └── [보존 규칙 (Preservation Rules)]
└── [공급/선택 계층]
    ├── [증강 선택기 (Aug Selector)]
    └── [혼합 비율 (Mixing Ratio)]
```

- 선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 원본 데이터 | **증강 기준•원본 라벨** 제공 |
| 변환 정책 | 도메인별 **변환 종류•강도** 정의 |
| 보존 규칙 | 유지할 **개체•의도•사건** 명시 |
| 증강 선택기 | **라벨 보존 후보** 한정 공급 |
| 혼합 비율 | 검증 결과 기반 **공급 비중** 결정 |

#### 한줄 요약
- **원본•변환 정책•보존 규칙•선택기•혼합 비율** 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **증강 후보(Augmentation Candidate)**: 변환 정책을 원본에 적용했지만 아직 라벨 보존 검사를 통과하지 않은 표본.
- **성능 피드백(Performance Feedback)**: 미증강 검증셋의 결과로 변환 종류•강도•혼합 비율을 조정하는 정보를 나타낸다.

</details>

```text
원본 데이터
   │ 1. 원본•라벨 제공
   ▼
┌──────── 미증강 검증 목표 충족 전 ────────┐
│ 변환 정책                                │
│   │ 2. 증강 후보 생성                    │
│   ▼                                      │
│ 보존 검증기                              │
│   │ 3. 라벨 보존 표본 전달              │
│   ▼                                      │
│ 학습기                                   │
│   └ 4. 검증 성능 피드백 ──▶ 변환 정책   │
└──────────────────────────────────────────┘
```

### 동작 원리

1. **원본•라벨 제공**: 유지할 개체•의도•사건 정의
2. **증강 후보 생성**: 변환 종류•강도•확률 적용
3. **라벨 보존 표본 전달**: 의미 훼손 후보 제외
4. **검증 성능 피드백**: 정책•혼합 비율 조정

#### 한줄 요약
- **라벨 보존** 변환을 **미증강 검증셋** 기반 평가

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **이미지 증강(Image Augmentation)**: 회전•밝기•가림을 적용하되 방향과 위치가 라벨을 바꾸지 않는 범위에서 사용하는 기법을 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.
- **텍스트 증강(Text Augmentation)**: 역번역•동의어 치환으로 표현을 바꾸되 개체와 의도를 보존하는 방식이다.
- **음성•시계열 증강(Audio & Time-Series Augmentation)**: 이동•잡음•속도를 바꾸되 신호가 나타내는 사건의 정체를 보존하는 방법을 가리킨다.

</details>

| 데이터 양식 | 이미지 증강 | 텍스트 증강 | 음성•시계열 증강 |
|:---|:---|:---|:---|
| 적용 기준 | **촬영 변화** 대응 | **의도**•**관계** 유지 | **사건 정체** 유지 |
| 핵심 특징 | **회전•밝기•가림** | **역번역•동의어 치환** | **이동•잡음•속도** 변경 |
| 한계 | 방향•위치의 **라벨 변경** | 개체•**의미 변경** | 신호•**사건 훼손** |

#### 한줄 요약
- **데이터 양식•라벨 의미** 대상 따라 변환 방식 구분

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **과도한 변환(Excessive Transformation)**: 증강 강도가 커져 원본 정답의 의미와 실제 분포를 벗어나는 문제.
- **성능 과대평가(Performance Overestimation)**: 증강과 유사한 분포로만 평가하여 실제 환경 일반화 성능이 높게 보이는 위험을 나타낸다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 과도한 변환으로 **라벨 오염** 발생 | 도메인별 **라벨 보존 규칙** 적용 | 증강 표본의 정답 의미 유지 |
| 증강 분포 평가로 **성능 과대평가** | 독립 **미증강 검증셋** 사용 | 실제 환경 일반화 검증 |

#### 한줄 요약
- **라벨 오염•성능 과대평가**를 보존 규칙•독립 평가로 통제

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **변환 정책 선택(Augmentation Policy Selection)**: 라벨 보존 규칙을 통과하고 미증강 검증 성능을 높이는 종류와 강도를 선택하는 기준을 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.
- **혼합 비율 결정(Blending Ratio Decision)**: 증강 표본이 원본 분포를 압도하지 않도록 실제 일반화 성능을 기준으로 조정하는 절차이다.

</details>

- 비전, 언어, 음성, 시계열 등 모든 딥러닝 도메인에서 모델의 일반화 성능과 강건성을 확보하는 **기초적이면서도 필수적인 데이터 전처리 및 정규화(Data Augmentation / Geometric & Photometric Transforms / Mixup & CutMix / Text Back-Translation & Paraphrasing / AutoAugment Policy)의 핵심 기반 기법**으로 확고히 자리 잡았으며, 자동화된 정책 탐색(AutoAugment)과 생성형 증강(Generative Augmentation)으로 고도화되는 가운데, 실무 데이터 증강 파이프라인 구축 시에는 **도메인의 물리적/의미론적 불변성 경계를 준수하여 라벨 오염(Label Corruption)을 사전에 차단, 변형된 증강 데이터에 의해 실제 현실 평가가 왜곡되지 않도록 원본 분포를 유지한 독립 미증강 검증셋(Clean Validation Set)으로 성능 평가, 원본과 증강 표본 간의 최적 혼합(Blending) 비율 튜닝**을 결합하여 완벽한 데이터 효율성과 최고 수준의 모델 강건성을 완성

#### 한줄 요약
- **라벨 보존•미증강 성능** 기반 증강 정책 결정
