## 미리 알고가기

- **데이터 증강(Data Augmentation, 데이터 어그멘테이션)**: 원본의 라벨 의미를 보존하며 변형 표본을 생성하는 기법
- **역번역 (Back-Translation)**: 문장을 외국어로 번역 후 다시 번역하여 표현을 변경함
- **동의어 치환 (Synonym Replacement)**: 의미를 유지하며 일부 단어를 동의어로 변경함
- **라벨 오염 (Label Corruption)**: 변환이 원본 정답 의미를 훼손하는 현상



## Ⅰ. 개요

- 정의/개념: 라벨을 보존하는 변환으로 학습 표본을 확장
- 기존 한계: 제한된 원본 표본은 변형 환경 일반화에 취약
- **배경/필요성**: 라벨 보존 변형으로 학습 다양성 확대

### 쉽게 이해하기 (학습용)

- 같은 대상을 여러 각도나 표현으로 바꿔도 정답을 찾도록 학습합니다.

## Ⅱ. 특징

- 원본 정답을 유지하는 라벨 보존 변환만 적용한다.
- 이미지·텍스트·음성별 허용 변환과 강도를 다르게 정한다.
- 증강 표본의 성능 효과와 라벨 오염을 검증 세트로 확인한다.

### 쉽게 이해하기 (학습용)

- 매체별 변환이 정답 의미를 바꾸면 잘못된 학습 신호가 됩니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 원본 데이터 | 증강의 기준으로 라벨 보존 |
| 변환 정책 | 도메인별 종류와 강도 정의 |
| 보존 규칙 | 유지할 개체·의도 조건 명시 |
| 증강 선택기 | 라벨 검사를 통과한 표본 공급 |
| 혼합 비율 | 검증 결과에 따른 공급 비중 |

원본 자료
├─ 변환 정책
├─ 보존 규칙
├─ 증강 후보
└─ 표본 선택

### 쉽게 이해하기 (학습용)

- 원본 라벨을 보존한 증강 후보만 학습에 사용합니다.

## Ⅳ. 원리 및 절차 흐름도

조건 정의
↓
변환 선택
↓
후보 생성
↓
보존 검증
↓
혼합 학습

| 절차 | 설명 |
|:---|:---|
| 조건 정의 | 유지할 라벨 조건 정의 |
| 변환 선택 | 환경 변화에 맞는 변환 선택 |
| 후보 생성 | 확률로 표본 변환 |
| 보존 검증 | 라벨 유지·분포 이탈 검사 |
| 혼합 학습 | 통과 표본을 원본과 학습 |

### 쉽게 이해하기 (학습용)

- 라벨 보존 변환만 생성하고 실제 검증셋으로 효과를 평가합니다.

## Ⅴ. 종류 및 비교

| 판단 기준 | 이미지 증강 | 텍스트 증강 | 음성·시계열 증강 |
|:---|:---|:---|:---|
| 적용 기준 | 촬영 변화 대응 시 | 의도·관계 유지 시 | 사건 정체 유지 시 |
| 핵심 특징 | 회전·밝기·가림 | 역번역·동의어 치환 | 이동·잡음·속도 변경 |
| 한계 | 방향·위치 라벨 변경 | 개체·의미 변경 | 신호·사건 훼손 |

> 요약: 라벨이 보존되는 변환만 선별하여 증강함

### 쉽게 이해하기 (학습용)

- 이미지·텍스트·음성은 라벨을 보존하는 변환이 다릅니다.

## Ⅵ. 실무 사례

- 결함 분류는 실제 조명·잡음으로 변환하고 미증강셋으로 평가함
- 문의 분류는 표현 변경 시 의도 라벨 보존 문장만 추가함

### 쉽게 이해하기 (학습용)

- 조명과 표현은 바꾸되 결함 모양이나 문의 의도가 달라진 자료는 제외합니다.

## Ⅶ. 결론

- 데이터 증강은 라벨 보존과 실제 검증 효과를 확인한다.

### 쉽게 이해하기 (학습용)

- 정답을 바꾸는 변형은 제외하고 실제 검증 데이터로 성과를 확인해야 합니다.
