## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **강화학습(Reinforcement Learning)**: 환경 상호작용으로 누적 보상을 최대화하는 정책을 학습한다.
- **지연 보상(Delayed Reward)**: 행동 이후 수신돼 장기 가치에 영향을 주는 보상이다.

</details>

- 정의/개념: 환경 상호작용으로 누적 보상을 극대화하는 **강화학습**
- 배경/필요성: 지연 보상은 개별 행동의 **장기 기여도 직접 평가 불가**

#### 한줄 요약

- 시행착오로 **장기 누적 보상**을 극대화하는 정책 학습

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **정책(Policy)**: 상태에서 행동을 결정하는 규칙•확률 분포이다.
- **가치 함수(Value Function)**: 상태•행동의 미래 누적 보상 기댓값이다.
- **탐색•활용 균형(Exploration-Exploitation Trade-off)**: 미지 행동과 우수 행동의 선택 비율이다.

</details>

- 상태에서 행동을 결정하는 **정책**
- 미래 누적 보상을 추정하는 **가치 함수**
- 미지 행동과 우수 행동의 **탐색•활용 균형**

#### 한줄 요약

- **정책•가치 함수•탐색•활용**으로 장기 보상 최적화

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **에이전트(Agent)**: 상태를 관측하고 정책에 따라 행동하는 학습 주체이다.
- **환경(Environment)**: 행동에 따라 다음 상태와 보상을 반환한다.
- **보상 함수(Reward Function)**: 목표 기여도를 수치 신호로 변환한다.

</details>

```text
[가치 함수] ── [정책] ── [에이전트] ── [환경]
                                         │
                                   [보상 함수]
```

선의 의미: 정책•가치•에이전트•환경•보상 함수의 정적 관계이다.

| 구성요소 | 책임 |
|:---|:---|
| 에이전트 | 정책 기반 **행동 결정** |
| 환경 | **상태 전이•보상** 반환 |
| 정책 | 상태별 **행동 규칙** 정의 |
| 보상 함수 | **즉시 보상 신호** 산출 |
| 가치 함수 | **기대 누적 보상** 추정 |

#### 한줄 요약
- **에이전트•환경•정책•보상•가치 함수** 구성

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **경험(Experience)**: 상태•행동•보상•다음 상태로 구성된 학습 자료이다.
- **정책 갱신(Policy Update)**: 가치 추정치로 행동 규칙을 개선한다.

</details>

```text
┌────────────── 에피소드 루프 ──────────────┐
│ 환경 ── 1. 상태 관측 ──▶ 에이전트         │
│ 에이전트 ── 2. 행동 선택•수행 ──▶ 환경   │
│ 환경 ── 3. 보상•상태 전이 수집 ─▶ 에이전트│
│ 에이전트 ── 4. 정책•가치 갱신 ──▶ 정책   │
└───────────────────────────────────────────┘
```

### 동작 원리

1. **상태 관측**: 현재 환경 상태 정보 획득
2. **행동 선택•수행**: 탐색•활용 정책으로 행동 적용
3. **보상•상태 전이 수집**: 경험 튜플 저장
4. **정책•가치 갱신**: 보상 경험으로 행동 규칙 개선

#### 한줄 요약
- **관측•행동•경험 수집•정책•가치 갱신** 수행

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **온정책(On-policy)**: 현재 정책이 수집한 경험으로 해당 정책을 갱신한다.
- **오프정책(Off-policy)**: 과거•다른 정책 경험으로 목표 정책을 학습한다.

</details>

| 방식 | 온정책 (On-policy) | 오프정책 (Off-policy) |
|:---|:---|:---|
| 적용 기준 | **현재 정책 안정성** | **데이터 효율성** |
| 핵심 특징 | **현재 경험 기반 갱신** | **경험 버퍼 재사용** |
| 한계 | **낮은 표본 효율성** | **분포 차이 보정** 필요 |

#### 한줄 요약
- **경험 출처•재사용•분포 차이**에 따라 정책 구분

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **보상 해킹(Reward Hacking)**: 의도와 다르게 보상값만 극대화하는 행위이다.
- **안전 행동 집합(Safe Action Set)**: 환경 손상을 막는 허용 행동 범위이다.
- **분포 차이(Distribution Shift)**: 수집 경험과 목표 정책의 행동 분포 불일치이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 목표와 다른 **보상 해킹** | 다중 보상 지표 설계 | **비의도 정책** 억제 |
| 탐색 중 **위험 행동** | 시뮬레이터•안전 행동 제약 | **실제 환경 손상 방지** |
| 경험•정책의 **분포 차이** | 중요도 보정•버퍼 관리 | **정책 편향 완화** |

#### 한줄 요약
- **보상 정렬•안전 행동•분포 차이•탐색 위험** 검증

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **보상 정렬(Reward Alignment)**: 보상 함수와 실무 목표의 일치 상태이다.
- **탐색 위험(Exploration Risk)**: 미지 행동 시험 과정의 잠재 손실이다.

</details>

- 온라인 최신 경험은 **온정책**, 경험 재사용은 **오프정책** 선택
- 실제 손상 가능 환경은 **시뮬레이터•안전 행동 제약** 우선 적용

#### 한줄 요약
- **경험 재사용•탐색 위험**에 따라 정책 학습 방식 결정
