## 미리 알고가기

- **강화학습(Reinforcement Learning, RL, 알엘)**: 영문 머리글자를 딴 학습법으로, 환경 상호작용에서 기대 누적 보상을 높이는 정책을 학습
- **On-policy (온정책)**: 현재 정책이 수집한 경험으로 학습
- **Off-policy (오프정책)**: 과거 혹은 타 정책 경험 재사용 학습



## Ⅰ. 개요

- **정의/개념**: 상호작용으로 누적 보상을 높이는 정책을 학습
- **기존 한계**: 지도학습은 순차 행동의 장기 보상 정답 제공 곤란
- **배경/필요성**: 시행착오로 기대 누적 보상 정책 학습

### 쉽게 이해하기 (학습용)

- 시행착오를 통해 장기 누적 보상이 큰 행동 규칙을 배우는 기법입니다.

## Ⅱ. 특징

- 에이전트가 정책으로 행동하고 환경에서 상태·보상을 받는다.
- 가치 함수가 정책의 기대 누적 보상을 추정한다.
- 탐색·활용과 보상 설계가 정책 품질·목표 정렬을 좌우한다.

### 쉽게 이해하기 (학습용)

- 새로운 행동을 시도하는 탐색과 현재 가치가 높은 행동을 쓰는 활용을 적절히 섞어야 합니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 에이전트 | 정책으로 행동을 선택함 |
| 환경 | 행동 결과(상태, 보상) 반환 |
| 정책 | 상태별 행동 정의 |
| 보상 함수 | 즉시 성과 수치화 |
| 가치 함수 | 기대 누적 보상 추정 |

### 쉽게 이해하기 (학습용)

- 에이전트가 환경의 보상으로 정책과 미래 가치 추정을 갱신합니다.

## Ⅳ. 원리 및 절차 흐름도

```text
[상태 관측]
      ↓
[행동 선택]
      ↓
[경험 수집]
      ↓
[정책 갱신]
```

| 절차 | 설명 |
|:---|:---|
| 상태 관측 | 현재 의사결정 정보 수신 |
| 행동 선택 | 정책 기반 행동 결정 |
| 경험 수집 | 보상·상태·종료 여부 저장 |
| 정책 갱신 | 누적 보상 기반 정책 개선 |
| 반복 수행 | 종료 전 상호작용 반복 |

### 쉽게 이해하기 (학습용)

- 행동 뒤 받은 보상과 다음 상태로 선택 규칙을 반복해서 고칩니다.

## Ⅴ. 종류 및 비교

| 판단 기준 | 온정책 (On-policy) | 오프정책 (Off-policy) |
|:---|:---|:---|
| 적용 기준 | 정책 유지 시 | 로그 데이터 존재 시 |
| 핵심 특징 | 현재 정책 경험으로 갱신 | 과거·타 정책 경험 재사용 |
| 한계 | 표본 효율·재사용 제한 | 분포 차이 보정 필요 |

> 요약: 경험 활용 전략에 따른 강화학습 방식 선택 |

### 쉽게 이해하기 (학습용)

- 현재 정책의 경험만 쓸지 과거·다른 정책의 경험도 재사용할지의 차이입니다.

## Ⅵ. 실무 사례

- 냉각 제어는 안전 제약 안에서 정책을 시뮬레이션한다.
- 추천 정책은 로그로 새 정책 가치를 배포 전에 추정한다.

### 쉽게 이해하기 (학습용)

- 실제 설비에서 위험한 탐색을 하지 않고 시뮬레이터에서 안전성을 확인한 정책만 현장에 적용합니다.

## Ⅶ. 결론

- 목표를 반영한 보상과 안전한 탐색 범위를 설정한다.

### 쉽게 이해하기 (학습용)

- 점수를 높이는 행동이 실제 목표를 해치지 않도록 보상 규칙과 허용 행동 범위를 먼저 정해야 합니다.
