## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **에이전트 메모리(Agent Memory)**: 에이전트가 과거의 상태•지식•경험을 저장하고 현재 목표에 맞게 검색•갱신하는 계층이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.
- **문맥창(Context Window)**: 모델이 한 번의 추론에서 직접 참조할 수 있는 입력 토큰 범위를 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.

</details>

- **정의**: 상태•지식•경험을 저장•검색•갱신하는 **에이전트 메모리**
- **배경/필요성**: 단기 **문맥창** 제약으로 장기 연속성 및 **경험 재사용 불가**

#### 한줄 요약
- 상태•지식•경험을 목적별로 저장•검색•정리하는 것이 핵심 구조 구현

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **작업 기억(Working Memory)**: 현재 대화•계획•도구 결과처럼 진행 중인 과업의 단기 상태를 유지하는 기억으로 정의된다.
- **기억 검색(Retrieval)**: 의미•시간•중요도와 현재 목표를 비교하여 관련 기억을 선택하는 과정을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.
- **기억 통합(Consolidation)**: 반복되는 경험을 요약•정정하여 장기 기억에 반영하는 과정을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.

</details>

- **작업 기억**: 단기 상태와 장기 경험을 목적별로 **분리 저장**
- **기억 검색**: 의미•시간•중요도 기반으로 상황에 맞는 **관련 기억 선택**
- **기억 통합**: 경험 요약 및 만료 정책을 통한 **기억 오염 통제**

#### 한줄 요약
- **기억 검색**과 **기억 통합**에서 관련성•최신성•권한을 함께 평가 체계 적용

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **장기 기억(Long-term Memory)**: 세션이 끝난 뒤에도 재사용할 지식•경험•선호를 지속해서 저장하는 기억을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.
- **출처 메타데이터(Source Metadata)**: 기억의 생성 주체•시각•근거•버전을 기록하여 신뢰성과 최신성을 판정하게 하는 정보를 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.
- **재순위(Re-ranking)**: 검색 후보를 관련성•최신성•권한 기준으로 다시 정렬하는 과정을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.

</details>

```text
                   [수명•권한 정책]
                         /       \
              [작업 기억] ----- [장기 기억]
                   |                 |
            [수집•기록기]       [검색 계층]
```

선의 의미: 수명•권한 정책은 작업 기억과 장기 기억의 접근•보존 경계를 공통 통제하고, 수집•기록기는 작업 상태와 출처를 구성하며 검색 계층은 장기 기억의 허용된 후보를 제공하는 정적 메모리 계층을 뜻함.

| 구성요소 | 책임 |
|:---|:---|
| 수집•기록기 | 사건과 **출처 메타데이터** 생성 |
| 작업 기억 | 현재 메시지•계획•중간 결과 유지 |
| 장기 기억 | 사실•일화•절차•선호 정보 저장 |
| 검색 계층 | 의미•시간•권한 기반 후보 탐색과 **재순위** 수행 |
| 수명•권한 정책 | 기억의 정정•만료•삭제 통제 수행 |

#### 한줄 요약
- **기록•작업 기억•장기 기억•검색•수명 정책**을 분리 체계 적용

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **민감도 분류(Sensitivity Classification)**: 기억에 포함된 개인정보나 기밀 수준을 판정하여 접근 권한과 보존 기간을 정하는 과정이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.
- **권한 필터(Permission Filter)**: 검색 후보 가운데 현재 주체와 목적이 접근할 수 있는 기억만 통과시키는 통제이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.
- **가치•민감도별 분류 저장(Value/Sensitivity Classification Storage)**: 기억의 가치와 민감도를 판정해 저장 위치•접근 권한•보존 기간을 정하는 절차를 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.
- **의미•시간•권한 후보 조회(Semantic/Time/Permission Candidate Query)**: 의미 관련성•생성 시각•접근 권한을 평가해 기억 후보를 찾는 절차로 정의된다.

</details>

```text
에이전트
   │ 경험•출처 기록 요청
   │ 목표 관련 기억 검색
   ▼
메모리
   │ 1. 가치•민감도별 분류 저장
   │ 2. 의미•시간•권한 후보 조회
   ▼
저장소
   │ 저장 위치•버전 반환
   │ 권한 범위의 기억 후보 반환
   ▼
메모리
   │ 재순위 기억 문맥 주입
   ▼
에이전트
```

1. **가치•민감도별 분류 저장**: **민감도 분류** 기반 기억 유형•권한•보존 기간 결정
2. **의미•시간•권한 후보 조회**: **권한 필터** 적용 후 관련성•최신성 평가

#### 한줄 요약
- **민감도•유효기간•권한 필터**로 최신 기억을 제공 체계 적용

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **일화 기억(Episodic Memory)**: 특정 시점의 사건•행동•결과와 그 맥락을 경험 단위로 저장하는 기억으로 정의된다.
- **의미 기억(Semantic Memory)**: 개별 사건에서 일반화한 사실과 개념 사이의 관계를 저장하는 기억을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.
</details>

| 기억 유형 | 작업 기억 | 일화 기억 | 의미 기억 |
|:---|:---|:---|:---|
| 적용 기준 | 현재 과업 상태 유지 | 과거 사건•행동 재사용 | 사실•개념 지식 재사용 |
| 핵심 특징 | 단기 문맥•중간 결과 | 시간•상황 기반 경험 | 일반화된 사실•관계 |
| 한계 | 문맥 용량•수명 제한 | 경험의 과잉 일반화 우려 | 노후 사실•출처 손실 위험 |

> 요약: 현재 상태에는 **작업 기억**, 장기 경험에는 **일화 기억**, 일반 지식에는 **의미 기억** 적용

#### 한줄 요약
- 현재 상태는 **작업 기억**, 경험•지식은 **장기 기억**이 핵심 구조 구현

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **사실 오염(Fact Contamination)**: 오래되거나 잘못된 기억이 검색되어 현재 판단의 사실 기반을 왜곡하는 문제를 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.
- **기억 간섭(Memory Interference)**: 표현은 비슷하지만 목표와 무관한 기억이 관련 기억의 검색과 활용을 방해하는 현상이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.
- **가치 기반 만료(Value-based Expiration)**: 기억의 중요도•최신성•재사용성을 평가하여 요약하거나 삭제하는 수명 관리 방식을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 오래된 기억의 **사실 오염** | **출처 메타데이터**에 유효기간•정정 이력 저장 | 최신 사실 우선 검색 보장 |
| 민감 기억의 과다 노출 | 주체•목적 접근통제와 **권한 필터** 적용 | 기억 검색의 최소 권한 보장 |
| 유사하지만 무관한 **기억 간섭** | 관련성•최신성•신뢰도 기준 **재순위** 주입 | 문맥의 정확도•집중도 향상 |
| 무제한 축적에 따른 비용 증가 | **가치 기반 만료**와 통합•요약•삭제 정책 운영 | 저장•검색 비용과 기억 품질 통제 |

#### 한줄 요약
- 작업 상태와 해결 이력을 분리해 관련 사례를 검색하는 것이 핵심 구조 구현

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **기억 계층 구분(Memory Hierarchy Division)**: 단기 작업 상태와 세션 간 경험•지식을 분리 저장해 검색 효율과 권한 통제 균형을 확보하는 원칙을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.

</details>

- 단기 상태 유지는 **작업 기억**, 세션 간 경험•지식 재사용은 **장기 기억** 선택

#### 한줄 요약
- **기억 검색**에서 출처•최신성•권한을 평가한 뒤 노후 정보를 삭제하는 것이 핵심 구조 구현
