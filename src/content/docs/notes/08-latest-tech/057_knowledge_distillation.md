## 미리 알고가기

- **지식 증류 (Knowledge Distillation)**: 교사 지식을 학생 모델로 이전함
- **소프트 타깃 (Soft Target)**: 클래스 간 관계를 담은 확률 분포임
- **쿨백-라이블러 발산 (Kullback-Leibler Divergence, KL 발산)**: 두 확률 분포 차이를 측정함
- **템퍼러처 (Temperature)**: 출력 분포의 완만함을 조절함


## Ⅰ. 개요

- **정의/개념**: 교사 지식을 학생 모델에 전달하는 학습
- **배경/필요성**: 소형 모델의 품질·배포 효율 개선

### 쉽게 이해하기 (학습용)
- 선생님의 답 분포와 풀이 흔적 중 학생에게 유용한 정보를 전달함

## Ⅱ. 특징

- 응답 증류가 교사의 클래스 관계를 전달한다
- 온도 조절이 출력 분포의 상대 차이를 드러낸다
- 특징 증류가 중간 표현 차이를 줄인다
- 학생 구조가 달라도 실제 비용은 별도 측정한다

### 쉽게 이해하기 (학습용)
- 온도를 높여 정답 외 점수 차이를 강조하고, 중간 특징을 맞춰 학습함

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 교사 모델 | 지식 생성 기준 모델 |
| 학생 모델 | 학습 대상 모델 |
| 신호 변환기 | 템퍼러처 및 차원 정렬 |
| 복합 손실 | 정답·증류 손실 결합 |
| 독립 평가기 | 품질·자원 측정 |
```text
학습입력
├─ 교사신호
├─ 학생예측
├─ 정답신호
└─ 복합손실
```

### 쉽게 이해하기 (학습용)

- 교사·학생 출력을 맞춰 정답·증류 손실을 계산함

## Ⅳ. 원리 및 절차 흐름도

```text
선택
↓
생성
↓
추론
↓
결합
↓
평가
```

| 절차 | 설명 |
|:---|:---|
| 신호선택 | 증류 신호를 선택함 |
| 교사생성 | 교사 지식을 생성함 |
| 학생추론 | 학생 출력을 계산함 |
| 손실결합 | 손실을 결합함 |
| 학생평가 | 단독 품질 평가함 |
### 쉽게 이해하기 (학습용)

- 교사 신호로 학생을 학습한 뒤 학생 단독 품질을 평가함

## Ⅴ. 종류 및 비교

| 적용 기준 | 응답 증류 | 특징 증류 | 관계 증류 |
|:---|:---|:---|:---|
| 전이 신호 | 로짓·소프트 타깃 | 중간 특징·어텐션 | 특징 간 관계 |
| 적용 환경 | 출력 접근 가능 시 | 내부 정렬 필요 시 | 구조가 다를 때 |
| 주요 고려 | 손실 비중 | 계층 정렬 오류 | 계산 비용 |

> 요약: 교사 지식의 전이 형태에 따라 증류 방식을 선택함
### 쉽게 이해하기 (학습용)

- 응답·특징·관계 증류는 전달하는 교사 신호가 다름

## Ⅵ. 실무 사례

- 언어 모델: 로짓 캐시로 추론 비용 절감 및 데이터 비율 조정
- 비전 모델: 차원 불일치 시 투영 계층으로 대응 표현 보정
- 품질 검증: 교사 오류 전이 방지를 위한 독립 평가 실시
- 성능 측정: 실제 장치의 지연·메모리·처리량 실측

### 쉽게 이해하기 (학습용)
- 교사 오류까지 배울 수 있으므로 별도 검증 및 실측 필수

## Ⅶ. 결론
- 교사 신호·학생 오류·배포 비용을 함께 검증한다

### 쉽게 이해하기 (학습용)
- 학생에게 맞는 교재를 골라 스스로 정확히 답하는지 확인함
