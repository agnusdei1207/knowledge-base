## 미리 알고가기

- **지식 증류 (Knowledge Distillation)**: 교사 지식을 학생 모델로 이전함
- **소프트 타깃 (Soft Target)**: 클래스 간 관계를 담은 확률 분포임
- **쿨백-라이블러 발산(Kullback-Leibler Divergence, KL 발산)**: 두 학자의 성 첫 글자를 딴 표기로 “케이엘 발산”으로 읽으며, 교사와 학생의 확률분포 차이를 한 방향으로 측정하는 값
- **템퍼러처 (Temperature)**: 출력 분포의 완만함을 조절함


## Ⅰ. 개요

- 정의/개념: 교사 모델의 출력·특징·관계를 학생 모델에 전달하는 압축 학습
- 기존 한계: 정답 레이블만으로는 소형 학생 모델이 대형 교사가 학습한 클래스 관계와 중간 표현 지식을 충분히 전달받기 어렵다.

### 쉽게 이해하기 (학습용)
- 선생님의 답 분포와 풀이 흔적 중 학생에게 유용한 정보를 전달함

## Ⅱ. 특징

- 소프트 타깃 기반 **클래스 관계 전달**
- 온도 조절 기반 **출력 분포 정보 완화**
- 특징·관계 증류와 **학생 비용 별도 측정**

### 쉽게 이해하기 (학습용)
- 온도를 높여 정답 외 점수 차이를 강조하고, 중간 특징을 맞춰 학습함

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 교사 모델 | 지식 생성 기준 모델 |
| 학생 모델 | 학습 대상 모델 |
| 신호 변환기 | 템퍼러처 및 차원 정렬 |
| 복합 손실 | 정답·증류 손실 결합 |
| 독립 평가기 | 품질·자원 측정 |
```text
학습입력
├─ 교사신호
├─ 학생예측
├─ 정답신호
└─ 복합손실
```

### 쉽게 이해하기 (학습용)

- 교사·학생 출력을 맞춰 정답·증류 손실을 계산함

## Ⅳ. 원리 및 절차 흐름도

```text
선택
↓
생성
↓
추론
↓
결합
↓
평가
```

| 절차 | 설명 |
|:---|:---|
| 신호선택 | 증류 신호를 선택함 |
| 교사생성 | 교사 지식을 생성함 |
| 학생추론 | 학생 출력을 계산함 |
| 손실결합 | 손실을 결합함 |
| 학생평가 | 단독 품질 평가함 |
### 쉽게 이해하기 (학습용)

- 교사 신호로 학생을 학습한 뒤 학생 단독 품질을 평가함

## Ⅴ. 지식 증류 대상 비교

| 구분 | 응답 증류 | 특징 증류 | 관계 증류 |
| 적용 기준 | 출력 확률 전달 | 중간 표현 전달 | 표본·계층 관계 전달 |
| 핵심 특징 | 소프트 타깃 모방 | 특징 맵 정렬 | 거리·유사도 구조 모방 |
| 한계 | 교사 출력 편향 전이 | 차원 정렬 설계 필요 | 관계 계산 비용 증가 |
|:---|:---|:---|:---|
| 전이 신호 | 로짓·소프트 타깃 | 중간 특징·어텐션 | 특징 간 관계 |
| 적용 환경 | 출력 접근 가능 시 | 내부 정렬 필요 시 | 구조가 다를 때 |
| 주요 고려 | 손실 비중 | 계층 정렬 오류 | 계산 비용 |

> 요약: 교사 지식의 전이 형태에 따라 증류 방식을 선택함
### 쉽게 이해하기 (학습용)

- 응답·특징·관계 증류는 전달하는 교사 신호가 다름

## Ⅵ. 실무 사례

- 언어 모델: 로짓 캐시로 추론 비용 절감 및 데이터 비율 조정

### 쉽게 이해하기 (학습용)
- 교사 오류까지 배울 수 있으므로 별도 검증 및 실측 필수

## Ⅶ. 결론
- 소형 모델 품질을 위해 교사 신호·오류를 검토하여 **지식 증류** 활용

### 쉽게 이해하기 (학습용)
- 학생에게 맞는 교재를 골라 스스로 정확히 답하는지 확인함
