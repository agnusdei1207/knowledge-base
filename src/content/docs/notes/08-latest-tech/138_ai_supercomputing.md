## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **인공지능 슈퍼컴퓨팅(Artificial Intelligence Supercomputing, AI Supercomputing)**: 대규모 인공지능 학습•추론을 위해 가속기•고속망•병렬 저장소•스케줄러•전력•냉각을 하나의 시스템으로 통합한 인프라 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **확장 효율(Scaling Efficiency)**: 가속기 수를 늘렸을 때 이상적인 처리량 증가 대비 실제 처리량 증가의 비율 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **인공지능(Artificial Intelligence, AI)**: 입력을 바탕으로 예측•생성•의사결정을 수행하는 시스템 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

- 정의/개념: 연산•통신•저장•전력•냉각을 통합한 **AI 슈퍼컴퓨팅**
- 배경/필요성: 단일 서버는 대형 모델의 **연산량•가속기 메모리•데이터 공급량** 충족하기 어렵음.

#### 한줄 요약
- 연산•통신•저장•전력•냉각의 **통합 확장**

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **집단 통신(Collective Communication)**: 여러 가속기가 갱신값을 합산•분배•교환하여 동일 모델 상태를 만드는 통신 연산 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **랙 전력 밀도(Rack Power Density)**: 한 랙의 장비가 요구하는 총 전력과 냉각 용량 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

- 고속 연결망 기반 **가속기•메모리 병렬 통합**
- **집단 통신•저장 대역폭 기반 분산 학습 효율**
- **랙 전력 밀도 기반 배치 밀도•지속 성능 제한**

#### 한줄 요약
- 통신•저장•전력•냉각 병목이 **확장 효율** 제한

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **병렬 파일 시스템(Parallel File System)**: 여러 노드가 학습 데이터와 체크포인트를 동시에 읽고 쓰도록 분산한 저장 구조 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **작업 스케줄러**: 통신 토폴로지와 가용 자원을 고려해 가속기 노드를 배치하고 복구하는 구성요소 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

```text
                         [작업 스케줄러]
                         /             \
              [가속기 노드] ----- [고속 연결망]
                    |                   |
          [전력•냉각 계층]      [병렬 파일 시스템]
```

선의 의미: 작업 스케줄러는 가속기 노드와 고속 연결망의 토폴로지 자원을 배치하고, 전력•냉각 계층은 노드의 물리 한계를, 병렬 파일 시스템은 연결망을 통한 데이터•체크포인트 공급 기반을 이루는 정적 슈퍼컴퓨팅 구조를 뜻한다.

| 구성요소 | 책임 |
|:---|:---|
| 가속기 노드 | 모델 연산과 **장치 메모리 제공** |
| 고속 연결망 | 갱신값 집단 통신의 **노드 간 전송** |
| 병렬 파일 시스템 | 학습 데이터•체크포인트의 **동시 입출력** |
| 작업 스케줄러 | 토폴로지 기반 **노드 배치•장애 복구** |
| 전력•냉각 계층 | 랙별 전력 공급과 **열 제거 한도 관리** |

#### 한줄 요약
- 노드•연결망•저장•스케줄러•전력의 **통합 구조**

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **순전파•역전파(Forward•Backward Propagation)**: 입력에서 예측을 계산하고 오차 기울기를 반대 방향으로 전달하는 학습 연산 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **옵티마이저(Optimizer)**: 모델의 기울기를 이용해 가중치 갱신 방향과 크기를 계산하는 학습 구성요소 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **체크포인트(Checkpoint)**: 장애 복구를 위해 학습 중간의 모델•옵티마이저 상태를 저장한 시점 파일 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

```text
┌──────────── 학습 종료까지 ────────────┐
│ 병렬 저장소 ── 1. 학습 데이터 병렬 공급 ──▶ 가속기 노드
│ 가속기 노드 ── 2. 노드별 모델 계산 ──▶ 집단 통신망
│ 집단 통신망 ── 3. 갱신값 집단 통신 ──▶ 모델 상태 관리자
│ 가속기 노드 ◀─ 4. 모델 상태 동기화 ── 모델 상태 관리자
│ 체크포인트 주기: 가속기 노드 ── 5. 중간 상태 병렬 저장 ──▶ 체크포인트 관리자
└───────────────────────────────────────┘
```

### 동작 원리

1. **학습 데이터 병렬 공급**: 작업자별 데이터 조각을 **병렬 전달**함.
2. **노드별 모델 계산**: 각 가속기가 순전파•역전파로 **로컬 갱신값**을 생성함.
3. **갱신값 집단 통신**: 노드별 값을 합산•분배해 **공동 갱신값**을 구성함.
4. **모델 상태 동기화**: 모든 노드가 같은 파라미터로 **다음 반복**을 수행함.
5. **중간 상태 병렬 저장**: 모델•옵티마이저 **체크포인트**를 보존함.

#### 한줄 요약
- 분산 계산•집단 통신•상태 동기화 후 **체크포인트** 저장

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **과학 계산 슈퍼컴퓨터**: 중앙처리장치(Central Processing Unit, CPU) 중심의 대규모 수치 해석과 시뮬레이션에 최적화한 고성능 컴퓨팅 시스템을  역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **가속기 클라우드**: 그래픽 처리장치(Graphics Processing Unit, GPU) 등 가속기 자원을 필요할 때 임대해 탄력적으로 사용하는 서비스 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

AI 슈퍼컴퓨팅은 CPU 중심 시스템 및 GPU 임대 서비스와 최적화 대상이 다르다.

| 비교 기준 | 과학 계산 슈퍼컴퓨터 | AI 슈퍼컴퓨팅 | 가속기 클라우드 |
|:---|:---|:---|:---|
| 적용 기준 | 검증된 **수치 해석 코드** | 다중 노드 **AI 동기화** | 변동 작업의 **주문형 자원** |
| 핵심 특징 | CPU 중심의 **수치 시뮬레이션** | 가속기•고속망 기반 **AI 병렬화** | 탄력적 **가속기 임대** |
| 한계 | **AI 생태계•가속 효율** | **구축•전력•냉각 비용** | **전송•종속•장기 비용** |

#### 한줄 요약
- 과학 계산•AI 학습•주문형 자원의 **최적화 대상** 비교

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **통신 토폴로지**: 가속기와 스위치가 연결되어 데이터가 이동하는 물리•논리 경로 구조을  역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **데이터 샤딩**: 학습 데이터를 여러 노드가 병렬로 읽고 처리하도록 조각내어 분산하는 방법 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 노드 증가의 **집단 통신 병목** | **통신 토폴로지 인접 배치•계산 중첩** | 확장 효율 **향상** |
| 저장 대역폭 부족의 **가속기 유휴** | **데이터 샤딩•캐시•병렬 체크포인트** 적용 | 연산 자원 대기 **감소** |
| 랙 전력•냉각 초과의 **성능 제한** | **전력 밀도별 노드 배치•열 기반 속도 제어** | 지속 처리량 **확보** |

#### 한줄 요약
- 노드 확장 전 **통신•저장•전력•냉각 용량** 검증

</details>

- **병목 자원 우선 확장**으로 집단 통신•저장•전력 개선
