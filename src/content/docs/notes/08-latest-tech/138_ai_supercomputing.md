## 미리 알고가기

- **AI 슈퍼컴퓨팅(AI Supercomputing)**: 대규모 AI 학습·추론을 위해 가속기·고속망·저장소·전력·냉각을 통합한 컴퓨팅 인프라
- **시스템 설계 관점**: 단순히 GPU를 많이 모은 수준이 아니라 통신 병목과 전력과 냉각까지 함께 최적화하는 시스템 설계가 중요함
- **분산 학습 효율**: 분산 학습 효율과 자원 활용률과 전력 효율이 핵심 지표임


## Ⅰ. 개요

- 정의/개념: 대규모 AI 병렬 처리 통합 인프라
- **배경/필요성**: 단일 서버만으로 대규모 모델의 연산량·가속기 메모리·데이터 공급량 충족 곤란

### 쉽게 이해하기 (학습용)

- 계산기만 많이 놓는 것이 아니라 계산기 사이 도로, 자료 창고, 작업 배정표, 전기와 냉각까지 함께 설계해 하나의 거대한 AI 학습 기계로 만드는 것임

## Ⅱ. 특징

- 고속 연결망 기반 **가속기·메모리 통합**
- 집단 통신·저장소 대역폭 기반 **학습 효율**
- 전력·냉각 한도 기반 **배치 밀도·성능 제한**

### 쉽게 이해하기 (학습용)

- 여러 사람이 동시에 계산해도 가장 늦은 사람이 끝나고 답을 서로 맞춰야 다음 문제로 넘어가므로, 사람 수뿐 아니라 대화 속도와 자료 전달 속도가 전체 시간을 좌우함

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 가속기 노드 | 모델 연산과 가속기 메모리 제공 |
| 고속 연결망 | 집단 통신과 모델 갱신값 동기화 |
| 병렬 저장소 | 학습 데이터와 중간 상태 병렬 처리 |
| 스케줄러 | 연결망 위치 기반 작업 배치·장애 복구 |
| 전력·냉각 | 랙별 전력 밀도와 열 제거 용량 결정 |

```text
[스케줄러] ─배치┐
[저장소] ─데이터┼→ [가속기 노드]
[전력냉각] ─용량┘       └─ [고속 연결망]
```

> 요약: 가속기·연결망·저장소와 전력·냉각을 통합 운영한다.

### 쉽게 이해하기 (학습용)

- 계산 교실, 답을 주고받는 복도, 자료 창고, 자리 배정 담당자, 전기·냉방 설비가 모두 맞아야 학생 수를 늘려도 수업이 빨라지는 구조임

## Ⅳ. 원리 및 절차 흐름도

```text
학습 데이터 분할·공급 ◀─────────────────┐
          ↓                             │
  가속기별 모델 계산                    │
          ↓                             │
  학습 갱신값 집단 통신                 │
          ↓                             │
    모델 상태 동기화 ── 다음 반복 ──────┘
```

| 절차 | 설명 |
|:---|:---|
| 데이터 공급 | 병렬 저장소에서 작업자별 데이터 읽음 |
| 모델 계산 | 각 가속기별 모델 갱신값 계산함 |
| 갱신값 동기화 | 집단 통신으로 노드별 갱신값 합침 |
| 상태 갱신 | 모든 노드 같은 모델 상태로 다음 반복 시작함 |
| 중간 상태 저장 | 정해진 주기마다 상태를 병렬 저장함 |

> 요약: 집단 통신으로 갱신값을 합쳐 동일 모델 상태로 반복함

### 쉽게 이해하기 (학습용)

- 각 조가 문제를 나눠 푼 뒤 답을 합쳐 같은 정답지로 맞추고, 일정 횟수마다 현재 정답지를 저장한 다음 새 문제를 푸는 반복임

## Ⅴ. 대규모 컴퓨팅 제공 방식 비교

| 구분 | 과학 계산 슈퍼컴 | AI 슈퍼컴퓨팅 | 가속기 클라우드 |
|:---|:---|:---|:---|
| 주 작업 | 수치 해석 시뮬레이션 | 대규모 AI 학습·추론 | 변동성 큰 가속 작업 |
| 우선순위 | 통신 패턴 해석 | 집단 통신·데이터 공급 | 자원 확보·사용자 격리 |
| 적용 기준 | 검증된 해석 코드 실행 | 다중 노드 동기화 중요 시 | 작업량 변동 시 |
| 핵심 특징 | CPU 중심 수치 해석 | 가속기·고속망 AI 병렬화 | 주문형 가속기 자원 제공 |
| 한계 | AI 생태계·가속 효율 | 구축·전력·냉각 비용 | 종속·전송·장기 비용 |

> 요약: 과학은 코드, AI는 동기화, 클라우드는 자원을 본다.

### 쉽게 이해하기 (학습용)

- 정해진 과학 계산 공장은 전통 슈퍼컴퓨터, 수많은 계산기가 자주 답을 맞추는 AI 공장은 AI 슈퍼컴퓨터, 일이 들쭉날쭉해 필요할 때 빌리는 공장은 가속기 클라우드에 가까움

## Ⅵ. 실무 사례

1. 언어모델 학습은 가까운 통신 경로에 작업을 묶고, 노드 추가 대비 처리량 증가가 낮으면 병렬 구성을 조정함

### 쉽게 이해하기 (학습용)

- 계산기를 더 꽂아도 통신 때문에 학습이 빨라지지 않으면 묶는 방식을 바꾸고, 열 때문에 속도가 떨어지면 한 랙의 계산기 수를 줄이는 운영 판단임

## Ⅶ. 결론

- 대규모 AI 학습을 확장하기 위해 **연산·집단 통신·메모리·전력·냉각·확장 효율**을 검토하고, 병목에 맞춰 슈퍼컴퓨팅 자원을 구성한다

### 쉽게 이해하기 (학습용)

- 일꾼만 늘려 일이 빨라지지 않으면 사람을 더 뽑기보다 막힌 통로·자료 창고·전기와 냉방부터 넓혀야 함
