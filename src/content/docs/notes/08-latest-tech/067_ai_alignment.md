## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **인공지능 정렬(Artificial Intelligence Alignment, AI Alignment)**: 모델의 목표와 행동을 인간 의도•가치•정책에 맞추는 과정이다.
- **목표 불일치**: 모델이 최적화한 대리 목표가 인간이 실제로 원한 결과와 달라지는 문제다.

</details>

- 정의/개념: 모델의 목표와 출력•행동을 인간 의도•가치•안전 정책에 맞추는 **AI 정렬 과정**이다.
- 배경/필요성: 성능 최적화만으로 **목표 불일치 방지•인간 의도와 가치 준수•유해 행동 통제**가 어렵다.

#### 한줄 요약
- 내비게이션에 목적지를 정확히 지정하듯 모델의 목표와 한계를 먼저 정합니다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **명세 정합**: 정책에 적은 목표•금지•우선순위가 실제 인간 의도를 정확히 나타내는 정도다.
- **정렬 학습**: 선호•원칙•안전 신호를 이용해 모델의 응답과 행동 성향을 조정한다.
- **런타임 통제**: 학습 밖에서 발생하는 위험을 입출력 검사와 권한 제한으로 실행 중 차단한다.

</details>

- 정책과 인간 의도의 목표 불일치를 줄이는 **명세•의도 정합**이 핵심이다.
- 모델의 응답•행동 성향을 조정하는 **정렬 학습**이 핵심이다.
- 학습 밖 실패를 제한하는 **적대적 평가•런타임 통제**가 핵심이다.

#### 한줄 요약
- 규칙을 잘 써도 모델이 평가의 허점을 이용할 수 있어 실제 행동을 따로 살핍니다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **정책 명세**: 허용 행동•금지 조건•우선순위와 책임 경계를 정의한다.
- **정렬 학습**: 지시•선호•비판•안전 데이터를 이용해 모델 행동을 정책 명세와 인간 의도에 맞추는 학습 과정이다.
- **감독 평가**: 정상•경계•적대 입력에서 모델의 유용성과 안전 실패를 측정한다.
- **배포 통제**: 권한•필터•승인•중단•롤백으로 운영 환경에서 허용 행동 범위를 강제한다.
- **운영 피드백**: 배포 중 발견한 실패를 정책•학습•평가 기준에 다시 반영한다.

</details>

```text
[AI 정렬 체계]
 ├─ [정책 명세]
 ├─ [정렬 학습]
 ├─ [감독 평가]
 ├─ [배포 통제]
 └─ [운영 피드백]
```

선의 의미: AI 정렬 체계가 소유한 명세•학습•평가•통제•환류 책임을 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 정책 명세 | **허용 행동•우선순위** 정의 |
| 정렬 학습 | 선호•원칙 기반 **행동 성향 조정** |
| 감독 평가 | 정상•적대 입력의 **정렬 실패 측정** |
| 배포 통제 | **입출력•권한•승인 경계** 강제 |
| 운영 피드백 | 실패 사례의 **정책•평가 갱신** |

#### 한줄 요약
- 목표•학습•평가•가드레일이 모델 행동을 함께 통제합니다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **유용성•정직성•무해성(Helpful, Honest, Harmless, HHH)**: 유용•정직•무해를 함께 보는 정렬 평가축이다.
- **적대적 평가(Red Teaming)**: 안전 정책을 회피하려는 입력으로 모델의 안전 실패를 탐색하는 평가다.
- **런타임 가드레일**: 모델 입출력과 도구 권한을 실행 중 검사•제한하는 통제다.

</details>

```text
정책 담당자
   │ 1. 목표•금지 정책 명세
   ▼
정렬 학습기
   │ 2. 선호•원칙 정렬 학습
   ▼
감독 평가기
   │ 3. HHH•적대 실패 평가
   ▼
런타임 가드레일
   │ 4. 가드레일 집행•운영 환류
   └──────────────────────▶ 정책 담당자
```

**동작 원리**

1. **목표•금지 정책 명세**: 허용 행동과 **HHH 우선순위**를 정의한다.
2. **선호•원칙 정렬 학습**: 인간 선호와 안전 원칙으로 응답 성향을 조정한다.
3. **HHH•적대 실패 평가**: 과잉 거절과 정책 회피 유해 행동을 식별한다.
4. **가드레일 집행•운영 환류**: 권한•입출력 통제 실패를 정책과 학습에 반영한다.

#### 한줄 요약
- 목표를 학습•평가•통제하고 발견한 실패를 다시 반영합니다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **목표 명세 정렬**: 정책 목적과 금지•우선순위를 정확하게 정의한다.
- **학습된 정책 정렬**: 선호•원칙 신호로 모델의 행동 성향을 학습한다.
- **배포 시점 통제**: 권한•입출력•승인 경계로 실제 실행 피해를 제한한다.

</details>

| 정렬 계층 | 목표 명세 정렬 | 학습된 정책 정렬 | 배포 시점 통제 |
|:---|:---|:---|:---|
| 적용 기준 | 정책 **목적 정의** | 행동 **성향 학습** | 실행 **권한 제한** |
| 핵심 특징 | 목적•금지•**우선순위 명세** | 선호•원칙 기반 **행동 학습** | 권한•**입출력 제한** |
| 한계 | 대리 목표•**명세 누락** | 평가 밖 **행동 실패** | 우회 입력•**과잉 거절** |

#### 한줄 요약
- 목표 명세•정책 학습•배포 통제는 책임 지점이 다릅니다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **대리 지표 최적화**: 평가 점수는 높지만 인간 의도와 다른 방식으로 목표를 달성하는 문제다.
- **과잉 거절**: 안전 기준이 지나치게 강해 정상적이고 무해한 요청까지 거부하는 현상이다.
- **분리 평가**: 유용성과 무해성을 별도 지표로 측정하여 한쪽 개선이 다른 쪽을 훼손하는지 확인한다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 대리 지표 최적화로 **목표 불일치** | 정책 명세와 **적대 평가** 공동 설계 | 의도 밖 행동 탐지 |
| 강한 안전 정렬로 **과잉 거절** | 유용•무해 분리 평가와 임계값 조정 | 정상 요청 **유용성 보존** |

#### 한줄 요약
- 금지 답변뿐 아니라 정상 요청의 유용성을 평가하고 위험한 실행에는 승인을 둡니다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **정렬 학습 적용 범위**: 모델의 목표와 응답 성향이 인간 의도에 맞도록 조정한다.
- **런타임 가드레일 적용 범위**: 정렬 학습이 놓친 위험 행동이 실제 권한 실행으로 이어지지 않게 통제한다.

</details>

- 목표 불일치 대책: **정렬 학습**, 실행 위험 대책: **런타임 가드레일**이 핵심이다.

#### 한줄 요약
- 규칙과 실제 행동이 어긋나는 사례를 찾아 학습•평가•통제를 함께 고쳐야 합니다.
