## 미리 알고가기

- **인공지능 정렬(Artificial Intelligence Alignment, AI Alignment, 에이아이 얼라인먼트)**: 모델의 목표·행동을 인간 의도와 정책에 맞추는 과정
- **유용·정직·무해(Helpful, Honest, Harmless, HHH, 에이치 에이치 에이치)**: 세 단어의 같은 머리글자를 묶은 정렬 평가축
- **적대적 평가 (Red Teaming)**: 우회 입력으로 안전 실패를 탐색함
- **런타임 가드레일 (Runtime Guardrail)**: 입출력과 권한을 실행 중 통제함



## Ⅰ. 개요

- 정의/개념: 모델의 목표와 행동을 인간 의도·정책에 맞춤
- 기존 한계: 성능 최적화만으로 인간 의도·가치 준수 보장 불가
- **배경/필요성**: 목표 불일치와 유해 행동의 학습·배포 통제

### 쉽게 이해하기 (학습용)

- 내비게이션에 목적지를 정확히 지정하듯 모델의 목표와 한계를 먼저 정합니다.

## Ⅱ. 특징

- 정책 명세와 실제 인간 의도 사이의 목표 불일치를 줄인다.
- 정렬 학습으로 모델의 응답·행동 성향을 조정한다.
- 적대적 평가와 런타임 권한 통제로 학습 밖 실패를 제한한다.

### 쉽게 이해하기 (학습용)

- 규칙을 잘 써도 모델이 평가의 허점을 이용할 수 있어 실제 행동을 따로 살핍니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 정책 명세 | 허용 행동과 우선순위 정의 |
| 정렬 학습 | 성향 반영 신호 조절 |
| 감독 평가 | 정상·적대 실패 측정 |
| 배포 통제 | 입출력·권한 실행 통제 |
| 운영 피드백 | 정책과 평가 갱신 |

정렬 체계
├─ 목표 명세
├─ 학습 정렬
├─ 감독 평가
└─ 배포 통제

### 쉽게 이해하기 (학습용)

- 목표·학습·평가·가드레일이 모델 행동을 함께 통제합니다.

## Ⅳ. 원리 및 절차 흐름도

목표 정의
↓
학습 정렬
↓
적대 평가
↓
통제 배포
↓
실패 반영

| 절차 | 설명 |
|:---|:---|
| 목표 정의 | 목적·범위·우선순위 설정 |
| 학습 정렬 | 자료로 응답 성향 조정 |
| 적대 평가 | 우회 행동 분리 측정 |
| 통제 배포 | 실행 권한·입출력 제한 |
| 실패 반영 | 실패·오탐 다음 학습 반영 |

### 쉽게 이해하기 (학습용)

- 목표를 학습·평가·통제하고 발견한 실패를 다시 반영합니다.

## Ⅴ. 종류 및 비교

| 판단 기준 | 목표 명세 정렬 | 학습된 정책 정렬 | 배포 시점 통제 |
|:---|:---|:---|:---|
| 적용 기준 | 정책 목적 정의 | 행동 성향 학습 | 실행 권한 제한 |
| 핵심 특징 | 목적·금지·우선순위 명세 | 선호·원칙 기반 행동 학습 | 권한·입출력 제한 |
| 한계 | 대리 목표·명세 누락 | 평가 밖 행동 실패 | 우회 입력·과잉 거절 |

> 요약: 정렬 체계의 반복 검증과 균형 유지가 핵심임

### 쉽게 이해하기 (학습용)

- 목표 명세·정책 학습·배포 통제는 책임 지점이 다릅니다.

## Ⅵ. 실무 사례

- 상담 모델은 요청과 문의를 분리 평가하고 거절 시 정책 수정

### 쉽게 이해하기 (학습용)

- 금지 답변뿐 아니라 정상 요청의 유용성을 평가하고 위험한 실행에는 승인을 둡니다.

## Ⅶ. 결론

- 목표 불일치 극복을 위해 행동·통제를 검토하여 **AI 정렬** 활용

### 쉽게 이해하기 (학습용)

- 규칙과 실제 행동이 어긋나는 사례를 찾아 학습·평가·통제를 함께 고쳐야 합니다.
