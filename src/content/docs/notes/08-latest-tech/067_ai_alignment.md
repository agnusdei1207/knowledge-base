## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **인공지능 정렬(Artificial Intelligence Alignment, AI Alignment)**: 모델의 목표와 행동을 인간 의도•가치•정책에 맞추는 과정이다.
- **목표 불일치(Goal Misalignment)**: 모델이 최적화한 대리 목표가 인간이 실제로 원한 결과와 달라지는 현상.

</details>

- 정의/개념: 모델 목표•행동을 인간 의도•가치에 맞추는 **AI 정렬**
- 배경/필요성: 성능 지표만 최적화하면 모델이 지표는 높이되 의도에서 벗어난 **목표 불일치•유해 행동**을 배우고 그 피해를 사후 필터링으로 막는 비용이 배포 내내 남으므로, 학습 목적 자체에 인간 의도와 가치 제약을 넣는 정렬 계층을 두어 통제를 사후 방어에서 학습 목표로 옮김

#### 한줄 요약
- **목표•금지•우선순위**를 강하게 걸수록 유해 출력은 줄지만 정상 요청의 거부와 성능 저하가 함께 늘므로, 정렬은 안전성과 유용성 사이의 지점을 고르는 작업이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **명세 정합(Specification Alignment)**: 정책에 적은 목표•금지•우선순위가 실제 인간 의도를 정확히 나타내는 정도를 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.
- **정렬 학습(Alignment Training)**: 선호•원칙•안전 신호를 이용해 모델의 응답과 행동 성향을 조정하는 방법으로 정의된다.
- **런타임 통제(Runtime Control)**: 학습 밖에서 발생하는 위험을 입출력 검사와 권한 제한으로 실행 중 차단하는 기법을 가리킨다.

</details>

- **명세•의도 정합**: 정책과 인간 의도의 불일치 감소
- **정렬 학습**: 모델의 응답•행동 성향 조정
- **적대적 평가•런타임 통제**: 학습 밖 실패 제한

#### 한줄 요약
- **명세 정합•런타임 통제** 기반 평가 허점 보완

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **정책 명세(Policy Specification)**: 허용 행동•금지 조건•우선순위와 책임 경계를 정의하는 단계이다.
- **정렬 학습(Alignment Training)**: 지시•선호•비판•안전 데이터를 이용해 모델 행동을 정책 명세와 인간 의도에 맞추는 학습 과정.
- **감독 평가(Supervised Evaluation)**: 정상•경계•적대 입력에서 모델의 유용성과 안전 실패를 측정하는 절차를 나타낸다.
- **배포 통제(Deployment Control)**: 권한•필터•승인•중단•롤백으로 운영 환경에서 허용 행동 범위를 강제하는 방식을 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.
- **운영 피드백(Operational Feedback)**: 배포 중 발견한 실패를 정책•학습•평가 기준에 다시 반영하는 환류 과정으로 정의된다.

</details>

```text
[AI 정렬 체계]
 ├─ [정책 명세]
 ├─ [정렬 학습]
 ├─ [감독 평가]
 ├─ [배포 통제]
 └─ [운영 피드백]
```

선의 의미: AI 정렬 체계가 소유한 명세•학습•평가•통제•환류 책임을 나타냄.

| 구성요소 | 책임 |
|:---|:---|
| 정책 명세 | **허용 행동•우선순위** 정의 |
| 정렬 학습 | 선호•원칙 기반 **행동 성향 조정** |
| 감독 평가 | 정상•적대 입력의 **정렬 실패 측정** |
| 배포 통제 | **입출력•권한•승인 경계** 강제 |
| 운영 피드백 | 실패 사례의 **정책•평가 갱신** |

#### 한줄 요약
- **목표•학습•평가•가드레일** 모델 행동 통제

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **유용성•정직성•무해성(Helpful, Honest, Harmless, HHH)**: 유용•정직•무해를 함께 보는 정렬 평가축으로 정의된다.
- **적대적 평가(Red Teaming)**: 안전 정책을 회피하려는 입력으로 모델의 안전 실패를 탐색하는 평가 방식.
- **런타임 가드레일(Runtime Guardrails)**: 모델 입출력과 도구 권한을 실행 중 검사•제한하는 통제 장치를 가리킨다.

</details>

```text
정책 담당자
   │ 1. 목표•금지 정책 명세
   ▼
정렬 학습기
   │ 2. 선호•원칙 정렬 학습
   ▼
감독 평가기
   │ 3. HHH•적대 실패 평가
   ▼
런타임 가드레일
   │ 4. 가드레일 집행•운영 환류
   └──────────────────────▶ 정책 담당자
```

### 동작 원리

1. **목표•금지 정책 명세**: 허용 행동과 HHH 우선순위 정의
2. **선호•원칙 정렬 학습**: 응답 성향 조정
3. **HHH•적대 실패 평가**: 과잉 거절과 정책 회피 식별
4. **가드레일 집행•운영 환류**: 통제 실패를 정책에 반영

#### 한줄 요약
- **명세•학습•평가•통제•환류** 수행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **목표 명세 정렬(Goal Specification Alignment)**: 정책 목적과 금지•우선순위를 정확하게 정의하는 단계를 나타낸다.
- **학습된 정책 정렬(Learned Policy Alignment)**: 선호•원칙 신호로 모델의 행동 성향을 학습시키는 기법이다.
- **배포 시점 통제(Deployment-Time Control)**: 권한•입출력•승인 경계로 실제 실행 피해를 제한하는 방식을 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.

</details>

| 정렬 계층 | 목표 명세 정렬 | 학습된 정책 정렬 | 배포 시점 통제 |
|:---|:---|:---|:---|
| 적용 기준 | 정책 **목적 정의** | 행동 **성향 학습** | 실행 **권한 제한** |
| 핵심 특징 | 목적•금지•**우선순위 명세** | 선호•원칙 기반 **행동 학습** | 권한•**입출력 제한** |
| 한계 | 대리 목표•**명세 누락** | 평가 밖 **행동 실패** | 우회 입력•**과잉 거절** |

#### 한줄 요약
- **목표 명세•정책 학습•배포 통제** 책임 분리

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **대리 지표 최적화(Proxy Gaming)**: 평가 점수는 높지만 인간 의도와 다른 방식으로 목표를 달성하는 문제.
- **과잉 거절(Over-refusal)**: 안전 기준이 지나치게 강해 정상적이고 무해한 요청까지 거부하는 현상.
- **분리 평가(Decoupled Evaluation)**: 유용성과 무해성을 별도 지표로 측정하여 한쪽 개선이 다른 쪽을 훼손하는지 확인하는 기법을 가리킨다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 대리 지표 최적화로 **목표 불일치** | 정책 명세와 **적대 평가** 공동 설계 | 의도 밖 행동 탐지 |
| 강한 안전 정렬로 **과잉 거절** | 유용•무해 분리 평가와 임계값 조정 | 정상 요청 **유용성 보존** |

#### 한줄 요약
- 정상 요청의 **유용성** 및 위험 실행의 **승인 경계** 평가

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **정렬 학습 적용 범위(Scope of Alignment Training)**: 모델의 목표와 응답 성향이 인간 의도에 맞도록 조정하는 범위를 나타낸다.
- **런타임 가드레일 적용 범위(Scope of Runtime Guardrails)**: 정렬 학습이 놓친 위험 행동이 실제 권한 실행으로 이어지지 않게 통제하는 역할을 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.

</details>

- 목표 불일치는 **정렬 학습**, 실행 위험은 **런타임 가드레일** 적용

#### 한줄 요약
- **불일치 유형•실행 권한** 대상 따라 학습•통제 대책 결정
