## 미리 알고가기

- **CXL (Compute Express Link)**: 호스트와 가속기·메모리를 고속 연결하고 캐시 일관성을 유지하는 표준
- **PCIe 기반 확장**: 기존 서버 연결선과 호환해 메모리 확장과 장치 조합을 지원함
- **메모리 공유**: 서버별 메모리를 자원 풀로 구성해 필요 장치 간 동적 할당을 지원함



## Ⅰ. 개요

- **정의/개념**: PCIe 기반 입출력·캐시·메모리 연결 표준이다
- **배경/필요성**: 가속기·메모리의 복사와 주소 분리 비용을 줄인다

### 쉽게 이해하기 (학습용)

- PCIe로 장치를 찾고 장치 역할에 따라 캐시 공유와 메모리 접근 통로를 제공한다.

## Ⅱ. 특징

- CXL.io는 장치 발견·설정의 공통 경로를 제공한다
- CXL.cache는 장치의 호스트 메모리 캐시를 일관시킨다
- CXL.mem은 호스트가 장치 메모리를 직접 접근하게 한다
- 프로토콜 조합은 장치 유형과 메모리 역할을 구분한다
- 확장 용량은 로컬 메모리보다 높은 지연을 동반한다

### 쉽게 이해하기 (학습용)

- 모든 장치는 공통 입구를 쓰고 가속기는 호스트 캐시를, 메모리 장치는 자신의 저장 공간을 공유한다.

## Ⅲ. 아키텍처 및 구성요소

| 설계 요소 | 설명 |
|:---|:---|
| 호스트 브리지 | 장치 발견 및 일관성 기준 프로세서 측 경계 |
| CXL 링크 | CXL.io·cache·mem 프로토콜 전송 경로 |
| Type-1 가속기 | 호스트 메모리를 캐시하는 가속기 |
| Type-2 가속기 | 호스트 캐시와 장치 메모리를 쓰는 가속기 |
| Type-3 장치 | 호스트 주소 공간용 메모리 확장 자원 |
| 스위치 관리 계층 | 경로 제어, 자원 구성 및 오류 처리 담당 |

> 요약: 호스트·링크·장치·스위치가 일관된 메모리를 잇는다

### 쉽게 이해하기 (학습용)

- 호스트가 장치를 찾고 링크와 스위치가 유형별 캐시·메모리 경로와 오류 격리를 제공한다.

## Ⅳ. 원리 및 절차 흐름도

```text
링크 훈련
    ↓
모드 협상
    ↓
장치 발견
    ↓
유형 판정
    ↓
경로 설정
    ↓
주소 매핑
```

| 절차 | 설명 |
|:---|:---|
| 링크 훈련·협상 | 물리 링크·동작 모드 결정 |
| 장치 발견·설정 | 식별자·기능·오류 능력 확인 |
| 유형 판정 | 장치별 프로토콜 조합 확인 |
| 경로 설정 | 캐시·메모리 전송 경로 활성화 |
| 주소 매핑 | 호스트 주소·메모리 범위 연결 |
| 접근·오류 처리 | 일관성 접근·오류 격리 |

> 요약: 장치를 발견해 유형별 경로·주소·오류 처리를 설정한다

### 쉽게 이해하기 (학습용)

- 링크를 연 뒤 장치 유형을 확인하고 캐시·메모리 경로와 주소 범위를 설정해 일관되게 접근한다.

## Ⅴ. 종류 및 비교

| 판단 기준 | Type-1 장치 | Type-2 장치 | Type-3 장치 |
|:---|:---|:---|:---|
| 구성 프로토콜 | CXL.io·cache | CXL.io·cache·mem | CXL.io·mem |
| 메모리 구조 | 호스트 캐시 가속기 | 캐시·장치 메모리 가속기 | 메모리 확장 장치 |
| 적용 기준 | 호스트 캐시 참조 | 가속기·장치 메모리 공용 | 메모리 계층 확장 |

> 요약: 캐시·겸용·확장을 Type-1·2·3으로 구분한다

### 쉽게 이해하기 (학습용)

- 호스트 메모리만 캐시하면 Type-1, 장치 메모리도 쓰면 Type-2, 메모리 확장 전용이면 Type-3이다.

## Ⅵ. 실무 사례

1. Type-2로 호스트 캐시와 장치 메모리를 함께 쓴다
2. Type-3을 용량 계층으로 두고 민감 페이지는 로컬에 둔다

### 쉽게 이해하기 (학습용)

- Type-2 가속기는 호스트 메모리를 일관되게 캐시하면서 자신의 메모리도 연산에 사용한다.
- Type-3 메모리는 용량을 늘리되 지연에 민감한 페이지는 빠른 로컬 메모리에 유지한다.

## Ⅶ. 결론

- 장치 역할별 프로토콜과 주소·일관성·오류를 설계한다.

### 쉽게 이해하기 (학습용)

- 장치 유형에 맞는 프로토콜을 고르고 주소 매핑·일관성·오류 격리를 설계해야 안전하게 확장할 수 있다.
