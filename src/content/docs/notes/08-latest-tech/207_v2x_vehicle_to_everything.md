## 미리 알고가기

- **V2X (Vehicle-to-Everything) Communication**: 차량과 주변 참여자의 협력 통신 체계
- **Cooperative Perception (Cooperative Perception) System**: 센서 사각지대를 보완하는 협력 인지 수단
- **Low Latency (Low Latency) Requirement**: 안전 효과를 좌우하는 통신 지연 요건
- **PKI (Public Key Infrastructure) Authentication**: 메시지 신뢰성 검증용 공개키 기반 구조
- **Direct Link (Direct Link) Communication**: PC5 등을 통한 직접 무선 통신
- **C-V2X (Cellular V2X) Technology**: 이동통신 기반 차량 사물 통신 기술



## Ⅰ. 개요

- **정의/개념**: 차량·인프라·보행자·망 간 정보 교환
- **배경/필요성**: 센서 사각지대를 보완해 위험을 조기 인지

### 쉽게 이해하기 (학습용)

- 직접 보이지 않는 위험을 무선으로 미리 알려 주는 보조 눈임

## Ⅱ. 특징

- V2V가 차량 동작을 공유해 충돌을 경고한다.
- V2I가 신호·도로 정보를 차량에 전달한다.
- V2P·V2N이 보행자·원거리 위험을 확장한다.
- 직접·망 접속 조합이 지연·범위를 최적화한다.

### 쉽게 이해하기 (학습용)

- V2V는 주변 차량과 상태를 공유하고 V2I는 신호기와 통신하며 V2P는 보행자를 감지하고 V2N은 서버와 광역 정보를 교환함

## Ⅲ. 아키텍처 및 구성요소

```text
[Vehicle / Pedestrian / RSU]
       ↓ signed state·event message
[DSRC·ITS-G5 | C-V2X PC5 | C-V2X Uu]
       ↓
[Certificate·Freshness·Location Validation]
       ↓
[Local Sensor·Map Fusion] → [Cooperative Warning / Planning]
```

| 설계 요소 | 설명 |
|:---|:---|
| 차량·참여자 단말 | 상태·위험 사건을 생성·수신함 |
| 노변·네트워크 계층 | 메시지를 중계하고 광역 정보를 제공함 |
| 무선 접속 계층 | 직접·망 경로로 메시지를 전송함 |
| 협력 메시지·응용 | 표준 메시지를 경고·계획에 사용함 |
| 신뢰·융합 계층 | 서명·위치를 검증해 센서와 융합함 |

> 요약: 메시지 검증 후 센서 정보와 융합

### 쉽게 이해하기 (학습용)

- 메시지 신분증과 작성 시각을 확인하고 내 센서 정보와 일치하는지 비교함

## Ⅳ. 원리 및 절차 흐름도

```text
[상태 감지]
      ↓
[메시지 서명]
      ↓
[메시지 전송]
      ↓
[수신 검증]
      ↓
[정보 융합]
      ↓
[경고 활용]
```

| 절차 | 설명 |
|:---|:---|
| 1. 상태·이벤트 감지 | 1. 상태·이벤트 감지을 수행하고 결과를 검증함 |
| 2. 표준 메시지 생성 | 2. 표준 메시지 생성을 수행하고 결과를 검증함 |
| 3. 가명 인증·서명 | 3. 가명 인증·서명을 수행하고 결과를 검증함 |
| 4. 경로별 전송 | 4. 경로별 전송을 수행하고 결과를 검증함 |
| 5. 수신 검증 | 5. 수신 검증을 수행하고 결과를 검증함 |
| 6. 융합·활용 | 6. 융합·활용을 수행하고 결과를 검증함 |

> 요약: 서명·위치 검증 후 센서와 융합

### 쉽게 이해하기 (학습용)

- 메시지 정당성을 따지고 현실적 위치인지 확인한 뒤 내 센서와 융합함

## Ⅴ. 종류 및 비교

| 판단 기준 | DSRC·ITS-G5 직접 통신 | C-V2X PC5 사이드링크 | C-V2X Uu 네트워크 |
|:---|:---|:---|:---|
| 핵심 특징 | 차량·노변장치가 802.11p 계열 채널로 직접 교환함 | 차량·단말이 셀룰러 사이드링크로 직접 교환함 | 차량이 기지국과 코어망·응용 서버를 경유함 |
| 적용 기준 | 802.11p 기반 근거리 직접 교환 | 셀룰러 sidelink 직접 교환 | 광역 V2N·지도·교통 서비스 |
| 주요 위험 | 채널 혼잡·인증서 상호운용 | 지역별 방식·자원 배정 차이 | 망 지연·장애·위치정보 노출 |

> 요약: 근거리 직접 통신과 광역 Uu를 목적별 조합

### 쉽게 이해하기 (학습용)

- 근거리 직접 통신은 무전 방식이며, 네트워크 통신은 서버를 거치는 방식임
