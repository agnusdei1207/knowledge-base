## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **지식그래프(Knowledge Graph)**: 개체와 사실 관계를 그래프로 연결한 지식망이다.

</details>

- 정의/개념: 식별 개체•사실 관계를 그래프로 표현한 **지식그래프**
- 배경/필요성: 표•문서에 분산된 사실은 **다단계 관계 추적 곤란**

#### 한줄 요약

- **고유 식별자**를 부여한 개체와 사실 관계 연결

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **개체 연결(Entity Linking)**: 이름•별칭 언급을 고유 식별자에 매핑한다.
- **자원 기술 프레임워크(Resource Description Framework, RDF)**: 사실을 주어•술어•목적어로 표현하는 표준이다.

</details>

- 별칭•언급을 하나의 식별자로 연결하는 **개체 식별**
- **RDF 트리플•관계 표현**을 통한 다단계 경로 탐색
- 스키마•출처•시점으로 사실을 검증하는 **지식 신뢰**

#### 한줄 요약

- **개체 식별•관계•출처•시점**으로 경로 추적

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **스키마(Schema)**: 허용할 개체•관계•속성 구조를 정의한다.
- **개체(Entity)**: 고유 식별자로 구분되는 사실의 주체나 객체이다.
- **관계(Relation)**: 두 개체의 의미 연결을 방향 간선으로 표현한 사실이다.
- **속성(Property)**: 개체•관계의 값•단위•시점 정보이다.
- **온톨로지(Ontology)**: 도메인의 개념•속성•관계•제약을 공식화한다.
- **프로비넌스(Provenance)**: 사실의 출처•관측 시점•유효 기간 정보이다.

</details>

```text
                    [스키마•온톨로지]
                      /          \
[개체 저장소] ----- [관계 저장소] ----- [속성 저장소]
                          |
                  [출처•시점 저장소]
```

선의 의미: 스키마가 개체•관계 구조를 규정하고 출처가 사실 근거를 보존한다.

| 구성요소 | 책임 |
|:---|:---|
| 개체 저장소 | 실제 대상을 고유 식별자 노드로 관리 |
| 관계 저장소 | 개체 간 유형•방향을 간선으로 관리 |
| 속성 저장소 | 개체•관계의 값과 시점을 관리 |
| 스키마•온톨로지 | 허용 개체•관계와 의미 제약 정의 |
| 출처•시점 저장소 | 사실의 원천•유효 기간•이력 보관 |

#### 한줄 요약

- **개체•관계•속성•스키마•출처** 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **관계 경로 질의(Path Query)**: 여러 간선을 따라 연결과 파생 사실을 탐색한다.
- **트리플 검증(Triple Validation)**: 관계•속성의 스키마 충족 여부를 판정한다.

</details>

```text
개체•관계 저장소
   │ 1. 식별 개체•관계 후보
   │ 2. 트리플•속성 검증 요청
   ▼
스키마•온톨로지
   │ 3. 검증 사실 제공
   ▼
출처•시점 저장소

그래프 질의기 ── 4. 관계 경로 질의 ──▶ 개체•관계 저장소
그래프 질의기 ◀── 출처 포함 경로•파생 사실 ─┘
```

### 동작 원리

1. 식별 개체•관계 후보: 문서 언급을 고유 식별자와 연결함.
2. 트리플•속성 검증 요청: 관계 방향•타입을 스키마로 판정함.
3. 검증 사실 제공: 간선에 원천과 유효 시점을 결합함.
4. 관계 경로 질의: 다단계 간선을 따라 사실 후보를 탐색함.

#### 한줄 요약

- **개체 식별•트리플 검증•출처 결합•경로 질의** 수행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **관계형 데이터베이스(Relational Database)**: 표•키•조인으로 정형 데이터를 관리한다.
- **지식그래프**: 개체•관계•출처를 그래프로 관리한다.
- **온톨로지**: 개념•관계•제약•공리를 명세한다.

</details>

**관계형 DB•지식그래프•온톨로지**는 표현 대상과 추론 범위가 다르다.

| 비교 기준 | 관계형 DB | 지식그래프 | 온톨로지 |
|:---|:---|:---|:---|
| 적용 기준 | **고정 구조** | **관계**•**출처** 중요 | **의미 규칙** 공유 |
| 핵심 특징 | **표•키•조인** | **개체•관계•사실** | **개념•제약•공리** |
| 한계 | 가변 관계의 **확장 복잡성** | 개체 연결•**정합성 비용** | 합의•**추론 비용** |

#### 한줄 요약

- **고정 구조•관계 탐색•의미 규칙**에 따라 모델 구분

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **셰이프 제약 언어(Shapes Constraint Language, SHACL)**: RDF 그래프의 노드•속성 제약을 검증한다.
- **오병합(False Merge)**: 서로 다른 대상을 하나의 개체로 연결한 오류이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 동명이인•별칭의 **개체 연결 오류** | 식별자•문맥 기반 **개체 연결** 후 후보 검수 | 오병합•중복의 **식별 정확도** 향상 |
| 오래되거나 무근거인 **관계 전파** | 간선별 출처•유효 기간•**신뢰도** 기록 | 다단계 추론의 **근거 신뢰성** 확보 |
| 관계 방향•타입의 **스키마 불일치** | 온톨로지 제약과 **SHACL 검증** 적용 | 탐색•추론의 **정합성** 보존 |

#### 한줄 요약

- **개체 식별•관계 출처•유효 시점•스키마** 검증

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **지식 신뢰성(Knowledge Reliability)**: 개체•관계•출처의 정합성을 유지한 상태이다.

</details>

- 가변 관계•경로 추론은 **지식그래프**, 의미 제약 공유는 **온톨로지** 선택

#### 한줄 요약

- **관계 탐색•의미 제약 공유**에 따라 지식 모델 결정
