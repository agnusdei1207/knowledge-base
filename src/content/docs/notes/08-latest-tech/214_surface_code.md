## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **표면 코드(Surface Code)**: 2차원 격자에서 이웃 큐비트의 안정자를 반복 측정해 오류를 정정하는 코드다.

</details>

- 정의: 2차원 격자의 이웃 안정자를 측정하는 양자 오류 정정 **표면 코드**
- 배경/필요성: 멀리 떨어진 큐비트끼리 검사해야 하는 정정 방식은 이웃끼리만 이어진 실제 소자에서 배선을 늘리는 비용을 감당하지 못해 **장치 구현 곤란**에 부딪히므로, 검사 연산을 격자 위 인접 큐비트만으로 끝내도록 배치해 연결성 제약 안에서 정정이 성립하게 하는 코드의 필요

#### 한줄 요약

- 격자 이웃의 **안정자 반복 측정•오류 신드롬 탐지**

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **안정자**: 논리 상태를 직접 읽거나 바꾸지 않으면서 물리 오류의 징후를 드러내는 공동 측정 연산자이다.

</details>

- 위상•비트 반전 신드롬을 추출하는 **X형•Z형 안정자**
- 측정 주기 변화를 연결해 오류를 추정하는 **시공간 해독**
- 임계값 아래에서 논리 오류를 낮추는 **코드 거리 확장**
#### 한줄 요약

- 코드 거리를 키우면 **논리 오류 감소•자원 증가**가 함께 일어나되 두 변화의 속도가 달라, 표면 코드의 조절 손잡이는 목표 신뢰성과 감당 가능한 물리 큐비트 수 사이에 놓인다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **코드 패치**: 하나 이상의 논리 큐비트를 표현하도록 경계를 갖춘 2차원 큐비트 격자 영역을 말한다.
- **데이터 큐비트**: 논리 정보를 담도록 2차원 격자에 배치한 물리 큐비트이다.
- **검사 큐비트**: 데이터 큐비트의 안정자를 측정하는 보조 큐비트이다.
- **X형 안정자**: 위상 반전(Z) 오류를 검출하는 국소 패리티 검사이다.
- **Z형 안정자**: 비트 반전(X) 오류를 검출하는 국소 패리티 검사이다.
- **코드 거리**: 논리 오류를 만들기 위한 최소 물리 오류 사슬의 길이로, 패치의 보호 수준을 나타내는 지표이다.
- **오류 해독기**: 반복 안정자 측정에서 시공간 오류 사슬을 추정해 보정 또는 파울리 프레임을 결정하는 구성요소을 말한다.

</details>

```text
                          [보호 경계]
                          /        \
                   [데이터 큐비트]   [안정자 측정]
                          \        /
                         [오류 해독기]
                              |
                         [운영 체계]
```
| 구성요소 | 책임 |
|:---|:---|
| 데이터 큐비트 | 논리 정보의 **격자형 배치** |
| 안정자 측정 | 오류 정보를 추출하는 **검사 큐비트** |
| 보호 경계 | 논리 연산 기준인 **격자 경계** |
| 오류 해독기 | 신드롬 기반 **오류 경로 추정** |
| 운영 체계 | **논리 연산•오류 정정** 관리 |

#### 한줄 요약

- **격자 안정자 반복 측정•해독•논리 상태 유지**

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **시공간 해독**: 여러 측정 주기에 걸친 신드롬 변화를 연결하여 데이터 오류와 측정 오류를 함께 추정하는 개념을 의미한다.

</details>


```text
[코드 패치]
    │ 1. 보호 구역 설정
    ▼
[안정자 회로]
    │ 2. 안정자 주기 검사
    ▼
[신드롬 이력]
    │ 3. 검출 사건 수집
    ▼
[해독기]
    │ 4. 오류 경로 해독
    ▼
[논리 프레임] ── 5. 프레임 갱신 ──▶ [코드 패치]
```

### 동작 원리

1. 보호 구역 설정: 논리 큐비트의 **경계 유형•코드 거리** 결정
2. 안정자 주기 검사: 이웃 큐비트의 **X•Z 안정자** 반복 측정
3. 검출 사건 수집: 연속 측정값 변화의 **시공간 좌표** 기록
4. 오류 경로 해독: 검출 사건 기반 **데이터•측정 오류** 추정
5. 프레임 갱신: 보정 장부 갱신 기반 **논리 상태 유지**

#### 한줄 요약

- **신드롬 시공간 좌표•오류 경로 해독**

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **회전 표면 코드**: 경계를 회전시킨 격자 배치로 같은 코드 거리에서 필요한 물리 큐비트 수를 줄인 변형을 의미한다.

</details>

| 구분 | 반복 코드 | 표면 코드 | 컬러 코드 |
|:---|:---|:---|:---|
| 적용 기준 | **낮은 복잡도** 검사 | **국소 상호작용** 기반 정정 | 복잡한 검사 대비 **연산 이점** |
| 핵심 특징 | 한 오류 유형의 **반복 보호** | **2차원 안정자 격자** | **3색 격자 안정자** |
| 한계 | **범용 오류 정정 불가** | 높은 **큐비트•해독 비용** | 복잡한 **검사**•**해독** |

#### 한줄 요약

- 오류 정정 코드 선택은 결국 하드웨어 연결성과 **해독 복잡도**를 어디까지 감당하느냐의 문제이며, 표면 코드는 **보호 범위**를 좁히는 대신 인접 **검사**만으로 구현 가능성을 산다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **상관 오류**: 하나의 결함이 여러 큐비트에 연관된 오류를 만들어 독립 오류 가정을 깨뜨리는 현상을 말한다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **코드 거리 과소**에 따른 논리 오류 예산 초과 | **물리 오류율•목표 실패율•거리별 억제** 실험 | **논리 오류 예산** 충족 |
| **누설•상관 오류**에 따른 코드 패치 확산 | **누설 제거•상관 모델•맞춤형 해독** 적용 | 코드 패치 내 **오류 확산** 억제 |
| **해독 처리량 부족**에 따른 실시간 제어 지연 | **지역•병렬 해독•가속•지연 예산** 검증 | **실시간 해독률** 확보 |

#### 한줄 요약

- **코드 거리•상관 오류•해독 처리량**별 정정 효과 검증

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **코드 거리 확장**: 논리 연산을 바꾸는 데 필요한 최소 오류 수를 늘려 논리 오류율을 낮추는 방법을 의미한다.

</details>

- 임계값 아래에서 **코드 거리**를 확장하고 **실시간 해독** 가능한 표면 코드 적용

#### 한줄 요약

- **물리 오류율•해독 처리량**에 맞춘 표면 코드 적용
