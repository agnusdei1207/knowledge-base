## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **표면 코드(Surface Code)**: 2차원 격자에서 이웃 큐비트의 안정자를 반복 측정해 오류를 정정하는 코드다.

</details>

- 정의/개념: **표면 코드(Surface Code)**는 2차원 격자의 이웃 안정자를 측정하는 양자 오류 정정 코드임.
- 배경/필요성: 비국소 오류 정정 코드는 제한된 큐비트 연결성에서 **구현**이 어렵음.

#### 한줄 요약

- 격자 이웃의 안정자를 반복 측정해 오류 신드롬을 찾는 보호 코드다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **안정자**: 논리 상태를 직접 읽거나 바꾸지 않으면서 물리 오류의 징후를 드러내는 공동 측정 연산자을 말한다.

</details>

- 위상 반전(Z)•비트 반전(X) 오류의 신드롬을 각각 추출하는 **X형•Z형 안정자**가 핵심임.
- 측정 주기 변화를 연결해 오류를 추정하는 **시공간 해독**이 핵심임.
- 임계값 아래에서 논리 오류를 낮추는 **코드 거리 확장**이 핵심임.
#### 한줄 요약

- 코드 거리를 늘리면 논리 오류는 줄지만 물리 큐비트와 해독 자원이 증가한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **코드 패치**: 하나 이상의 논리 큐비트를 표현하도록 경계를 갖춘 2차원 큐비트 격자 영역을 말한다.
- **데이터 큐비트**: 논리 정보를 담도록 2차원 격자에 배치한 물리 큐비트을 의미한다.
- **검사 큐비트**: 데이터 큐비트의 안정자를 측정하는 보조 큐비트을 의미한다.
- **X형 안정자**: 위상 반전(Z) 오류를 검출하는 국소 패리티 검사이다.
- **Z형 안정자**: 비트 반전(X) 오류를 검출하는 국소 패리티 검사을 의미한다.
- **코드 거리**: 논리 오류를 만들기 위한 최소 물리 오류 사슬의 길이로, 패치의 보호 수준을 나타내는 지표을 의미한다.
- **오류 해독기**: 반복 안정자 측정에서 시공간 오류 사슬을 추정해 보정 또는 파울리 프레임을 결정하는 구성요소을 말한다.

</details>

```text
                          [보호 경계]
                          /        \
                   [데이터 큐비트]   [안정자 측정]
                          \        /
                         [오류 해독기]
                              |
                         [운영 체계]
```
선의 의미: 보호 경계는 데이터 큐비트의 격자 배치와 안정자 측정의 국소 검사 범위를 함께 제한하고, 오류 해독기는 반복 측정 관계를 시공간 오류 경로로 해석해 운영 체계의 논리 연산•오류 정정 경계에 연결한다.

| 구성요소 | 책임 |
|:---|:---|
| 데이터 큐비트 | 논리 정보의 **격자형 배치** |
| 안정자 측정 | 오류 정보를 추출하는 **검사 큐비트** |
| 보호 경계 | 논리 연산 기준인 **격자 경계** |
| 오류 해독기 | 신드롬 기반 **오류 경로 추정** |
| 운영 체계 | **논리 연산•오류 정정** 관리 |

#### 한줄 요약

- 격자 안정자를 반복 측정하고 해독해 논리 상태를 유지한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **시공간 해독**: 여러 측정 주기에 걸친 신드롬 변화를 연결하여 데이터 오류와 측정 오류를 함께 추정하는 개념을 의미한다.

</details>


```text
[코드 패치]
    │ 1. 보호 구역 설정
    ▼
[안정자 회로]
    │ 2. 안정자 주기 검사
    ▼
[신드롬 이력]
    │ 3. 검출 사건 수집
    ▼
[해독기]
    │ 4. 오류 경로 해독
    ▼
[논리 프레임] ── 5. 프레임 갱신 ──▶ [코드 패치]
```

### 동작 원리

1. **보호 구역 설정**: 논리 큐비트의 경계 유형과 코드 거리를 결정함.
2. **안정자 주기 검사**: 이웃 데이터•검사 큐비트로 X•Z 안정자를 반복 측정함.
3. **검출 사건 수집**: 연속 측정값의 변화를 시공간 좌표로 기록함.
4. **오류 경로 해독**: 검출 사건을 설명할 가능성이 높은 데이터•측정 오류를 추정함.
5. **프레임 갱신**: 실제 게이트 대신 보정 장부를 갱신하며 논리 상태를 유지함.

#### 한줄 요약

- 보호 구역의 신드롬 변화를 시공간 좌표로 기록해 오류 경로를 해독한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **회전 표면 코드**: 경계를 회전시킨 격자 배치로 같은 코드 거리에서 필요한 물리 큐비트 수를 줄인 변형을 의미한다.

</details>

| 판단 기준 | 반복 코드 | 표면 코드 | 컬러 코드 |
|:---|:---|:---|:---|
| 적용 기준 | **낮은 복잡도** 검사 | **국소 상호작용** 기반 정정 | 복잡한 검사 대비 **연산 이점** |
| 핵심 특징 | 한 오류 유형의 **반복 보호** | **2차원 안정자 격자** | **3색 격자 안정자** |
| 한계 | **범용 오류 정정 불가** | 높은 **큐비트•해독 비용** | 복잡한 **검사•해독** |

#### 한줄 요약

- 반복•표면•컬러 코드는 보호 범위와 검사•해독 복잡도가 다르다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **상관 오류**: 하나의 결함이 여러 큐비트에 연관된 오류를 만들어 독립 오류 가정을 깨뜨리는 현상을 말한다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **코드 거리 과소** 미검증 시 목표 계산 깊이 전에 논리 오류 발생 | 물리 오류율•목표 실패율로 거리 산정 후 거리별 억제 실험 | **논리 오류 예산** 충족 |
| **누설•상관 오류** 미검증 시 표준 해독 모델 밖 오류가 패치로 확산 | 누설 제거 주기, 상관 노이즈 모델, 맞춤형 해독 적용 | 코드 패치 내 **오류 확산** 억제 |
| **해독 처리량** 미검증 시 시공간 신드롬이 쌓여 실시간 제어 지연 | 지역•병렬 해독과 하드웨어 가속, 주기 내 지연 예산 검증 | **실시간 해독률** 확보 |

#### 한줄 요약

- 핵심 운영 위험마다 실행 가능한 대책과 검증 효과를 함께 확인한다.

## Ⅶ. 결론

<summary>핵심 용어</summary>

- **코드 거리 확장**: 논리 연산을 바꾸는 데 필요한 최소 오류 수를 늘려 논리 오류율을 낮추는 방법을 의미한다.

</details>

- 임계값 아래에서 **코드 거리**를 확장하고 **실시간 해독** 가능한 표면 코드 적용.

#### 한줄 요약

- 물리 오류율과 해독 처리량에 맞춘 표면 코드 적용.
