## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **모델 추출(Model Extraction)**: 타겟 AI 모델에 대량의 질의를 전송하고 그 예측 결과를 수집하여, 원본 모델의 기능, 가중치, 로직을 모방한 대체 모델(Substitute Model)을 복제해내는 지식 재산권 침해 공격
- **지식재산 탈취**: 모델 파일을 직접 훔치지 않고도 학습된 기능과 사업 가치를 무단 복제하는 피해이다.
- **응용 프로그래밍 인터페이스(Application Programming Interface, API)**: 시스템 간 기능 호출과 데이터 교환을 위한 규격이다.

</details>

- 정의: 반복 **API 응답**으로 원본 결정 경계•기능을 모방하는 모델 추출이다.
- 배경/필요성: 상세 출력•무제한 질의는 **대체 모델 학습 비용**을 낮춰 지식재산 탈취 가능성이 있음.

#### 한줄 요약
- 원본 파일 없이 API 응답만으로 **대체 모델** 학습

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **대체 모델**: 수집한 응용 프로그래밍 인터페이스 응답으로 학습해 원본 기능을 모방하는 모델이며 원본 가중치의 정확한 복원을 뜻하지 않는 모델이다.
- **적응형 질의**: 원본과 대체 모델이 다르게 예측하는 영역을 찾아 다음 입력을 선택하는 질의 방식이다.
- **추출 비용**: 원본 기능을 일정 수준으로 모방하는 데 필요한 질의량•시간•계정•학습 자원의 총량이다.

</details>

- **API 입출력 교사 데이터** 기반 대체 모델 학습
- 점수•로짓•적응형 질의 기반 **결정 경계 추정 효율**
- 출력 최소화•질의 예산•행위 탐지 기반 **추출 비용 증가**

#### 한줄 요약
- 상세 점수•로짓으로 **결정 경계** 추정 질의량 감소

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **대상 응용 프로그래밍 인터페이스**: 공격자가 원본 모델에 반복 질의하고 라벨•점수•로짓을 수집하는 서비스 접점이다.
- **표본 생성기**: 원본 결정 경계를 효율적으로 추정하도록 정보량이 높은 질의 입력을 선택•생성하는 구성요소이다.
- **응답 데이터셋**: 입력과 응용 프로그래밍 인터페이스 반환 결과를 쌍으로 축적해 대체 모델 학습에 사용하는 자료이다.
- **대체 모델 학습**: 수집한 질의•응답 쌍으로 원본 기능과 결정 경계를 모방하는 과정이다.
- **워터마크 검증**: 원본 모델에 삽입한 고유 행동이 의심 모델에도 나타나는지 확인해 복제를 추적하는 통제이다.

</details>

**대상 API**는 공격자가 원본 모델의 라벨•점수•로짓을 반복 수집하는 접점이다.

```text
[대상 API] ----- [표본 생성기] ----- [응답 데이터셋] ----- [대체 모델]
      \                                                       /
                       [탐지•검증 통제]
```

선의 의미: 대상 API, 표본 생성기, 응답 데이터셋, 대체 모델은 기능 모방에 필요한 정적 정보 의존망을 이루고, 탐지•검증 통제는 원본 질의 경계와 의심 모델의 워터마크 증거를 함께 감시하는 구조를 뜻한다.

| 구성요소 | 책임 |
|:---|:---|
| 대상 API | 입력에 대한 **라벨**•**로짓**을 반환하는 원본 서비스 |
| 표본 생성기 | 결정 경계 정보 확보를 위한 **입력 선택** |
| 응답 데이터셋 | 입력과 API 반환 결과를 축적한 **학습 자료** |
| 대체 모델 | 수집 데이터 기반 **원본 기능 모방** 학습 |
| 탐지•검증 통제 | 계정별 예산 감시와 **워터마크 검증** |

#### 한줄 요약
- 응답 기반 대체 모델과 **질의 탐지•워터마크**의 대립 구조

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **경계 탐색 질의**: 모델의 결정 경계 정보를 효율적으로 얻도록 불확실한 입력을 선택하는 요청이다.
- **불일치 영역**: 같은 입력에 대해 원본과 대체 모델의 예측이 서로 다른 입력 공간이다.

</details>

```text
┌──────── 원본•대체 모델 불일치 감소까지 ────────┐
│ 표본 생성기 ── 1. 경계 탐색 질의 생성 ──▶ 대상 API
│ 대상 API ── 2. 라벨•상세 출력 수집 ──▶ 응답 데이터셋
│ 응답 데이터셋 ── 3. 대체 모델 학습 ──▶ 대체 모델
│ 표본 생성기 ◀─ 4. 원본•대체 불일치 분석 ─ 대체 모델
└───────────────────────────────────────────────┘
```

### 동작 원리

1. 경계 탐색 질의 생성: 불확실 영역 중심의 적응형 입력을 선택함.
2. 라벨•상세 출력 수집: 점수•로짓의 결정 경계 정보를 축적함.
3. 대체 모델 학습: API 입출력쌍으로 원본 기능을 모방함.
4. 원본•대체 불일치 분석: 예측 차이로 추가 질의 영역을 선택함.

#### 한줄 요약
- 원본•대체 불일치 영역을 반복 질의해 **결정 경계** 정밀화

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **라벨 전용 추출**: 응용 프로그래밍 인터페이스가 반환하는 최종 클래스만 모아 많은 질의로 결정 경계를 추정하는 방식이다.
- **점수•로짓 기반 추출**: 상세 출력의 클래스 간 관계를 활용해 적은 질의로 원본 기능을 모방하는 방식이다.

</details>

**API 출력 상세도**에 따라 라벨 전용 추출과 점수•로짓 기반 추출의 질의 효율이 달라진다.

| 추출 방식 | 라벨 전용 추출 | 점수•로짓 기반 추출 |
|:---|:---|:---|
| 적용 기준 | **최종 라벨**만 제공하는 API | **점수**•**로짓**을 제공하는 API |
| 핵심 특징 | 많은 질의로 **결정 경계 추정** | 상세 출력으로 **질의 효율 향상** |
| 한계 | 많은 질의와 **표본 선택 비용** 필요 | 출력 제한 시 **공격 효율 저하** |

> 요약: **출력 상세도**가 높을수록 **추출 질의량** 감소한다.

#### 한줄 요약
- 점수•로짓 제공 시 **질의 효율** 증가

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **경계 모방 가속**: 상세 점수•로짓이 질의 하나당 많은 결정 정보를 제공해 추출 효율이 높아지는 문제이다.
- **질의 예산 우회**: 여러 계정•조직•주소로 요청을 나눠 개별 사용량 제한을 피하는 문제이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 상세 점수•로짓으로 **경계 모방**가속 | 최소 라벨 출력•정밀도 제한 | 질의당 **추출 정보량** 감소 |
| 분산 반복 질의로 **질의 예산** 우회 | 계정•조직•입력 분포 연계 탐지 | 적응형 **경계 탐색** 비용 증가 |

#### 한줄 요약

- 계정•조직•입력 분포를 연계해 분산 **경계 탐색** 탐지

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **응답 최소화**: 업무에 필요한 라벨과 정밀도만 반환해 질의당 모델 정보를 줄이는 통제이다.
- **행위 탐지**: 계정•조직•입력 분포를 연계해 적응형 경계 탐색 패턴을 식별하는 통제이다.

</details>

- 출력 상세도가 높으면 **응답 최소화**, 반복 질의에는 **행위 탐지** 적용

#### 한줄 요약

- 출력 정보는 줄이고 **워터마크**로 복제 추적 증거 확보
