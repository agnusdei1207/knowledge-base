## 미리 알고가기

- **모델 추출**: 공개 API 입출력을 대량 수집하여 원본 기능을 모방하는 대체 모델을 만드는 공격
- **가중치**: 예측 결과와 신뢰도 점수만으로도 원본 복제가 상당 수준 가능함
- **방어**: 응답 정보량 축소·이상 질의 탐지·워터마킹 조합으로 대응함



## Ⅰ. 개요

- **정의/개념**: API 응답으로 원본 기능을 모방하는 공격이다
- **배경/필요성**: 판단 경계 복제와 지식재산 유출을 막는다

### 쉽게 이해하기 (학습용)
- AI 답변을 모아 학습하면 원본 파일 없이도 비슷한 답을 내는 모방 AI를 만들 수 있다.

## Ⅱ. 특징

- 입출력 쌍은 원본 기능을 배우는 교사 데이터가 된다
- 상세 점수·로짓은 판단 경계 노출을 키운다
- 적응형 표본은 적은 질의로 모방 정확도를 높인다
- 분산 계정은 호출 제한과 행위 탐지를 우회한다
- 출력·질의 통제는 복제 비용을 높이고 피해를 줄인다

### 쉽게 이해하기 (학습용)
- 상세 점수까지 받으면 적은 질문으로 원본의 판단 경계를 자세히 배울 수 있다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 대상 API | 입력에 대한 라벨·로짓 등을 반환하는 원본 서비스 |
| 표본 생성 | 결정 경계 정보 확보를 위한 입력 선택 |
| 응답 데이터셋 | 입력과 API 반환 결과를 축적한 학습 자료 |
| 모델 학습 | 수집 데이터로 원본 기능을 모방하는 모델 훈련 |
| 탐지 통제 | 계정별 예산 감시 및 워터마크로 모방 검증 |

> 요약: 질의 응답을 모아 대체 모델을 학습·검증한다

### 쉽게 이해하기 (학습용)
- 공격자는 응답으로 모방 모델을 학습하고 운영자는 질문 패턴과 워터마크 흔적을 찾는다.

## Ⅳ. 원리 및 절차 흐름도

```text
입력 선택 → 질의·응답 수집
                ↓
대체 모델 학습 → 기능 평가
                ↓
    부족 시 불확실 영역 갱신
```

| 절차 | 설명 |
|:---|:---|
| 표본 선택 | 초기 데이터와 불확실 영역의 입력을 선택함 |
| 질의·수집 | 반복 호출로 라벨·점수·로짓 등을 수집함 |
| 행위 통제 | 계정·속도·입력 분포 이상 여부를 판정함 |
| 모델 학습 | 수집 응답을 교사 데이터로 모델 훈련함 |
| 평가·반복 | 모델과 원본 일치도를 평가하고 부족분 질의함 |

> 요약: 불일치 영역을 다시 질의해 모방 정확도를 높인다

### 쉽게 이해하기 (학습용)
- 모방 AI가 틀린 영역을 골라 다시 묻기 때문에 여러 계정에 나뉜 질의 패턴도 살펴야 한다.

## Ⅴ. 종류 및 비교

| 판단 기준 | 라벨 전용 추출 | 점수·로짓 기반 추출 |
|:---|:---|:---|
| 응답 정보 | 최종 클래스·결과만 사용함 | 확률·신뢰도 등 연속 출력 사용함 |
| 질의 효율 | 결정 경계 확인을 위해 대량 표본 필요 | 상세 정보로 모델 수렴이 빠름 |
| 적용 기준 | 결과 공개 시 예산·행위 탐지 강화 | 상세 정보 축소 및 접근 권한 제한 |

> 요약: 출력 정보가 상세할수록 추출 질의가 줄어든다

### 쉽게 이해하기 (학습용)
- 최종 답만 줄 때보다 상세 점수까지 주면 적은 시도로 판단 규칙을 추리하기 쉽다.

## Ⅵ. 실무 사례

1. 공개 API는 상세 점수를 줄이고 질의 이상을 탐지한다
2. 허가된 증류는 계약된 모델·데이터 안에서 수행한다

### 쉽게 이해하기 (학습용)

- 공개 API는 계정·조직별 예산과 입력 다양성을 함께 살펴 분산된 경계 탐색을 찾는다.
- 같은 응답을 써도 소유자 허가와 계약 범위 안이면 증류이고 무단 경쟁 모델이면 추출 공격이다.

## Ⅶ. 결론

- 출력 최소화·질의 예산·워터마크로 추출을 통제한다.

### 쉽게 이해하기 (학습용)

- 모방 가능성을 완전히 없애기 어려우므로 출력 정보를 줄이고 복제 추적 증거를 남긴다.
