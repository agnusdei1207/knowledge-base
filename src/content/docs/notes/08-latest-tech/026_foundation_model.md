## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **파운데이션 모델(Foundation Model)**: 광범위한 데이터로 사전학습한 뒤 여러 하위 과업에 적응하여 재사용하는 범용 모델을 의미한다.
- **전이학습(Transfer Learning)**: 한 과업이나 데이터에서 학습한 표현과 능력을 다른 과업에 재사용하는 학습 방식을 의미한다.

</details>

- 정의/개념: 범용 표현을 사전학습해 여러 과업에 재사용하는 **파운데이션 모델**임.
- 배경/필요성: 과업별 전용 모델 학습은 데이터•연산 비용이 반복되고 학습 표현을 범용으로 재사용하기 어렵음.

#### 한줄 요약
- **전이학습**으로 범용 모델을 여러 하위 과업에 적응시키는 것이 핵심이다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **자기지도 사전학습**: 데이터 자체에서 예측 목표를 구성하여 대규모 범용 표현을 미리 학습하는 방식을 의미한다.
- **대규모 언어 모델(Large Language Model, LLM)**: 대규모 토큰 분포를 학습하여 여러 언어 과업을 수행하는 파운데이션 모델의 한 유형을 말한다.
- **검색 증강 생성(Retrieval-Augmented Generation, RAG)**: 외부 검색 근거를 모델 문맥에 결합해 최신•도메인 지식을 보완하는 방식로 정의된다.
- **매개변수 효율 미세조정(Parameter-Efficient Fine-Tuning, PEFT)**: 일부 추가•선택 매개변수만 학습해 과업에 적응하는 방식이다.
- **시스템 위험(Systemic Risk)**: 공통 기반 모델의 편향•취약점•오류가 이를 사용하는 여러 하위 서비스로 함께 전파되는 위험로 정의된다.

</details>

- **자기지도 사전학습**: 대규모 범용 데이터의 표현 학습임.
- **LLM**: 범용 표현을 여러 언어 과업에 재사용함.
- **전이학습**: 사전학습 능력을 하위 과업에 재사용함.
- **RAG**: 외부 검색 근거로 도메인 지식 보완임.
- **PEFT**: 일부 매개변수 학습으로 과업 적응임.
- 공통 모델의 결함이 하위 서비스로 전파되는 **시스템 위험**이 핵심임.

#### 한줄 요약
- 범용 능력과 함께 공통 편향•취약점도 하위 서비스에 전파된다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **학습 자원**: 범용 표현을 사전학습하는 데 사용하는 대규모 데이터•연산•학습 파이프라인이다.
- **저순위 적응(Low-Rank Adaptation, LoRA)**: 가중치 변화량을 작은 저순위 행렬로 학습하는 PEFT 기법을 말한다.
- **응용 프로그래밍 인터페이스(Application Programming Interface, API)**: 기반 모델의 추론 기능을 하위 서비스가 호출할 수 있게 제공하는 접점을 의미한다.
- **통제 계층**: 모델•데이터의 권한, 안전 정책, 품질•비용과 버전을 관리하는 운영 구성요소로 정의된다.

</details>

```text
                    [학습 자원]
                         |
                    [기반 모델]
                         |
                    [적응 계층]
                         |
                    [서비스 접점]
                         |
                    [통제 계층]
```

선의 의미: 학습 자원과 기반 모델 위에 적응 계층 및 서비스 접점이 결합되고, 통제 계층이 공유 모델의 품질•권한•전파 위험을 관리하는 구조를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 학습 자원 | **학습 자원**으로 범용 데이터•연산 자원과 사전학습 목표 제공 |
| 기반 모델 | 여러 과업에 재사용할 범용 표현•능력 학습 |
| 적응 계층 | **RAG•PEFT•LoRA** 기반 도메인 지식 반영 |
| 서비스 접점 | **API•런타임** 기반 하위 서비스 연동 |
| 통제 계층 | 모델 카드•평가•접근 통제로 **시스템 위험** 관리 |

#### 한줄 요약
- **기반 모델•적응 계층•서비스 접점•통제 계층** 공유가 핵심이다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **도메인 적응**: 범용 모델을 특정 업무의 데이터•용어•성공 기준에 맞도록 검색이나 추가 학습으로 조정하는 과정을 의미한다.
- **회귀 감시**: 기반 모델이나 적응 계층 변경 뒤 연결된 서비스의 품질과 안전성이 낮아지는지 지속 확인하는 활동이다.
- **범용 데이터•목표 사전학습**: 광범위한 데이터에서 자기지도 목표로 공통 표현과 능력을 학습하는 절차을 의미한다.
- **범용 표현•능력 제공**: 사전학습한 기반 모델의 공통 능력을 여러 하위 과업에 제공하는 절차로 정의된다.
- **RAG•PEFT 기반 하위 과업 적응**: 검색 근거나 일부 매개변수 학습으로 범용 모델을 업무에 맞추는 절차로 정의된다.
- **도메인 품질•안전 검증**: 적응 결과가 업무 정확성•편향•보안•규제 기준을 충족하는지 판정하는 절차을 의미한다.
- **하위 서비스 회귀 감시**: 기반 모델 변경 뒤 연결된 서비스 전체의 품질과 안전성 저하를 추적하는 절차이다.

</details>

```text
학습 자원
   │ 1. 범용 데이터•목표 사전학습
   ▼
기반 모델•적응 계층
   │ 2. 범용 표현•능력 제공
   │ 3. RAG•PEFT 하위 과업 적응
   │ 적응 모델 전달
   ▼
검증기
   │ 4. 도메인 품질•안전 검증
   │ 배포 승인 모델 전달
   ▼
하위 서비스
   │ 5. 하위 서비스 회귀 감시
```

1. **범용 데이터•목표 사전학습**: 대규모 **자기지도 사전학습**으로 공통 패턴을 내재화함.
2. **범용 표현•능력 제공**: 여러 과업이 활용할 **파운데이션 모델**을 제공함.
3. **RAG•PEFT 기반 하위 과업 적응**: **도메인 적응**으로 업무 적합성을 확보함.
4. **도메인 품질•안전 검증**: 정확성•편향•보안•규제 기준을 판정함.
5. **하위 서비스 회귀 감시**: 기반 모델 변경의 공통 영향을 추적함.

#### 한줄 요약
- **도메인 적응**과 안전 검증 후 모든 하위 서비스를 **회귀 감시**한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **과업 전용 모델**: 제한된 데이터와 목표로 하나의 과업을 직접 학습하여 세밀한 통제와 최적화를 추구하는 모델을 의미한다.

</details>

| 비교 기준 | 파운데이션 모델 | 과업 전용 모델 |
|:---|:---|:---|
| 적용 기준 | 다수 과업의 빠른 개발•확장 | 단일 과업의 강한 통제•최적화 |
| 핵심 특징 | 범용 사전학습 후 RAG•PEFT 적응 | 제한 데이터로 과업 목적 직접 학습 |
| 한계 | 공통 결함의 광범위한 전파 | 과업별 데이터•연산 비용 반복 |

#### 한줄 요약
- 다수 과업은 **파운데이션 모델**, 정밀 통제는 **과업 전용 모델**이 적합하다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **카나리 배포(Canary Deployment)**: 새 모델 버전을 일부 트래픽이나 서비스에 먼저 적용해 이상을 확인한 뒤 범위를 확대하는 방식로 정의된다.
- **버전 고정(Version Pinning)**: 검증된 기반 모델 버전을 명시하여 공급자의 변경이 예고 없이 하위 서비스에 반영되지 않게 하는 통제로 정의된다.
- **대체 모델 전환**: 중앙 모델이나 API 장애 시 미리 검증한 다른 모델로 요청을 보내 서비스 연속성을 유지하는 방식이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 공통 편향•취약점의 하위 서비스 전파 | 중앙 위험 목록•서비스별 영향•완화책 추적 | **시스템 위험**의 확산 범위 통제 |
| 범용 능력과 업무 데이터의 도메인 불일치 | 업무 평가셋으로 RAG•PEFT 후보 비교 | 적합한 **도메인 적응** 방식 선정 |
| 기반 모델 업데이트의 성능 회귀 | **버전 고정**•**카나리 배포**•전체 회귀 시험 | 변경 영향 조기 탐지•복구 |
| 중앙 모델•API 의존과 정보 노출 | **대체 모델 전환**•입력 분류•최소 전송 | 연속성•기밀성 확보 |

#### 한줄 요약
- 공통 모델 변경 시 **회귀 감시**를 수행한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **모델 선택 기준**: 다수 과업의 빠른 확장에는 파운데이션 모델을, 정밀 통제 단일 과업에는 과업 전용 모델을 적용하는 기준을 의미한다.

</details>

- **모델 선택 기준**에 따라 다수 과업은 **파운데이션 모델**, 정밀 통제 단일 과업은 **과업 전용 모델**을 선택함.

#### 한줄 요약
- 공유 모델의 변경 영향과 **시스템 위험**을 서비스별로 추적한다.
