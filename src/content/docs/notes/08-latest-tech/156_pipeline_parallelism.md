## 미리 알고가기

- **파이프라인 병렬(Pipeline Parallelism, PP, 피피)**: 모델의 연속된 층을 단계로 나누고 여러 장치에서 마이크로배치를 중첩 처리
- **마이크로배치(Microbatch)**: 하나의 학습 배치를 파이프라인에 순차 투입하도록 나눈 작은 실행 단위
- **버블(Bubble)**: 파이프라인을 채우고 비우는 동안 일부 장치가 계산하지 못하는 유휴 시간



## Ⅰ. 개요

- 정의/개념: 모델 층을 단계로 분할해 **마이크로배치를 중첩 실행**하는 병렬화 기법
- 배경/필요성: 단일 장치 메모리 한계와 **단순 층 분할의 버블** 완화 필요

### 쉽게 이해하기 (학습용)

- 제품 공정에 다음 제품을 연속 투입해 여러 작업대가 동시에 일하는 방식과 같다.

## Ⅱ. 특징

- **연속 모델 층**의 장치별 단계 분할
- 마이크로배치 순·역전파 중첩 기반 **버블 감소**
- 단계 불균형·통신 기반 **전체 처리량 제한**

### 쉽게 이해하기 (학습용)

- 제품 투입 수와 작업 순서로 반제품 정체와 작업대 대기 시간을 줄인다.

## Ⅲ. 구조 및 구성요소

```mermaid
block-beta
  columns 1
  A["단계 분할기"]
  B["마이크로배치 분할기"]
  C["활성값 채널"]
  D["스케줄 엔진"]
  E["활성값 관리자"]
  A --- B
  B --- C
  C --- D
  D --- E
```

| 구성요소 | 책임 |
|:---|:---|
| 단계 분할기 | 연산량·파라미터를 측정해 단계별 실행 시간을 균형화함 |
| 마이크로배치 분할기 | 전역 배치를 작은 실행 단위로 나누고 누적 기울기를 관리함 |
| 활성값 채널 | 단계 간 순전파 활성값과 역전파 기울기를 전달함 |
| 스케줄 엔진 | 준비·정상·마무리 구간의 실행 순서를 제어함 |
| 활성값 관리자 | 역전파 시 필요한 활성값을 보존하고 재계산함 |

> 요약: 단계 균형과 스케줄 엔진이 실행을 제어한다.

### 쉽게 이해하기 (학습용)

- 작업대별 처리 시간을 맞추고 제품 번호를 붙여 앞 작업과 되돌림 작업의 순서를 관리해야 같은 제품의 결과가 정확히 연결됨

## Ⅳ. 흐름도

```mermaid
sequenceDiagram
    participant B as 마이크로배치 분할기
    participant S1 as 전단 단계
    participant C as 활성값 채널
    participant S2 as 후단 단계
    participant E as 스케줄 엔진
    B->>S1: 1. 마이크로배치 전달
    S1->>C: 2. 순전파 활성값 전달
    C->>S2: 3. 단계 입력 전달
    S2-->>C: 4. 역전파 기울기 전달
    C-->>E: 5. 완료·대기 상태 전달
```

### 동작 원리

- **1. 마이크로배치 전달**: 전역 배치 분할과 파이프라인 연속 투입
- **2. 순전파 활성값 전달**: 단계별 층 계산과 중간 상태 보존
- **3. 단계 입력 전달**: 후단 장치의 순전파 실행
- **4. 역전파 기울기 전달**: 역순 단계의 기울기 계산·반환
- **5. 완료·대기 상태 전달**: 1F1B 스케줄과 버블·누적 갱신 제어

> 요약: 단계 균형과 동기 스케줄로 실행 효율을 높인다.

### 쉽게 이해하기 (학습용)

- 작업대 속도를 맞춘 뒤 여러 제품의 앞 작업과 되돌림 작업을 겹쳐 처리한다.

## Ⅴ. 종류 및 비교

| 스케줄 | GPipe | 동기 1F1B | 인터리브 1F1B |
|:---|:---|:---|:---|
| 적용 기준 | 단순한 동기 학습 | 활성값 메모리 절감 | 버블 감소가 중요 |
| 핵심 특징 | 모든 순전파 후 역전파 | 순전파·역전파 교대 | 가상 단계를 교차 실행 |
| 한계 | 많은 활성값 보관 | 초기·종료 버블 발생 | 통신 횟수와 복잡도 증가 |

> 요약: 활성값 메모리·버블·통신 비용으로 스케줄을 선택한다

### 쉽게 이해하기 (학습용)

- 모든 제품을 먼저 앞으로 보낸 뒤 되돌리는 방식, 한 개씩 앞뒤 작업을 번갈아 하는 방식, 작업대를 더 잘게 나눠 쉬는 틈을 메우는 방식의 차이임

## Ⅵ. 실무 고려사항 및 대책

| 고려사항 | 대책 | 효과 |
|:---|:---|:---|
| 단계 시간 차이로 **파이프라인 병목** | 층별 시간·메모리 기반 단계 재분할 | 단계 **처리량 균형** 확보 |
| 적은 마이크로배치로 **버블 비율** 증가 | 마이크로배치 수·1F1B 스케줄 조정 | 장치 **유휴 시간 감소** |

### 쉽게 이해하기 (학습용)

- 실제 대형 학습 시스템도 모델을 작업대처럼 나누고 제품 묶음 수와 앞뒤 작업 순서를 조정해 장치가 쉬는 시간을 줄임

## Ⅶ. 결론

- **단계 균형·마이크로배치 수**로 파이프라인 버블과 메모리를 절충

### 쉽게 이해하기 (학습용)

- 여러 장치가 마이크로배치를 이어 처리해 쉬는 시간을 줄인다
