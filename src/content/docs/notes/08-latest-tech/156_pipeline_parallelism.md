## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **파이프라인 병렬(Pipeline Parallelism, PP)**: 모델의 연속적인 층(Layer)을 여러 연산 장치의 단계로 분할하고, 전체 배치를 작은 마이크로배치(Microbatch)로 나누어 각 장치가 파이프라인 형태로 중첩 처리하는 기법.
- **마이크로배치(Microbatch)**: 학습 효율과 메모리 사용 최적화를 위해 전체 배치(Global Batch)를 더 작은 단위로 분할하여 파이프라인에 순차 투입하는 실행 단위.

</details>

- 정의: 모델 층을 단계로 나눠 마이크로배치를 중첩하는 **PP**이다.
- 배경/필요성: 모델이 단일 장치 메모리를 초과하고 **순차 층 분할은 버블**이 발생함.

#### 한줄 요약

- 마이크로배치를 연속 투입해 **여러 모델 단계** 동시 실행

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **버블(Bubble)**: 파이프라인 연산 과정에서 전후 단계 간의 데이터 의존성으로 인해 연산 장치가 유휴(Idle) 상태가 되어 연산이 수행되지 않는 구간.
- **단계 균형(Stage Balancing)**: 파이프라인 각 단계에 할당된 층의 연산량과 메모리 점유량을 최적화하여 단계 간 처리 시간 격차를 최소화한 상태.

</details>

- 연속 모델 층의 **장치별 단계 배치**
- 마이크로배치 순•역전파로 **버블 감소**
- 단계 불균형•분할 경계의 **처리량•통신 병목**

#### 한줄 요약

- 마이크로배치 수•스케줄로 **단계 대기•버블** 감소

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **활성값 채널(Activation Channel)**: 순전파(Forward) 과정의 중간 출력값과 역전파(Backward) 과정의 기울기(Gradient) 정보를 인접 단계 간에 전달하는 통신 인터페이스.
- **단계 분할기(Stage Partitioner)**: 모델의 연속된 층들을 전체 연산량, 메모리 점유량, 통신 비용이 균형을 이루도록 여러 장치 단계로 나누는 설계 모듈.
- **마이크로배치 분할기(Microbatch Splitter)**: 전역 배치를 다수의 마이크로배치로 분할하여 파이프라인 효율을 극대화하는 실행 단위 관리 모듈.
- **활성값 재계산(Activation Recomputation)**: 메모리 점유량을 줄이기 위해 순전파 시 계산된 활성값을 저장하지 않고, 역전파 과정에서 필요한 시점에 즉시 재계산하는 기법(Checkpointing).

</details>

```text
                  [단계 분할기]
                  /           \
      [마이크로배치 분할기]  [활성값 채널]
                  \           /
                  [스케줄 엔진]
                        |
                 [활성값 관리자]
```

선의 의미: 단계 분할기는 마이크로배치와 활성값 전달 경계를 정하고, 스케줄 엔진은 실행 순서를, 활성값 관리자는 보존•재계산을 담당한다.

| 구성요소 | 책임 |
|:---|:---|
| 단계 분할기 | **연산량•파라미터 기반 단계 균형화** |
| 마이크로배치 분할기 | **실행 단위 분할•누적 기울기** 관리 |
| 활성값 채널 | **순전파 활성값•역전파 기울기** 전달 |
| 스케줄 엔진 | **준비•정상•마무리 실행 순서** 제어 |
| 활성값 관리자 | **활성값 보존•재계산** 관리 |

#### 한줄 요약

- 단계•마이크로배치•채널•스케줄•**활성값 관리** 구조

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **순전파 활성값**: 전단 단계가 계산해 후단 단계의 입력으로 보내는 중간 출력을 말한다.
- **역전파 기울기**: 후단 단계가 계산해 전단 단계의 파라미터 갱신에 전달하는 미분값로 정의된다.

</details>

```text
┌──────── 모든 마이크로배치 처리까지 ────────┐
│ 스케줄 엔진 ── 1. 마이크로배치 전달 ──▶ 전단 단계
│ 전단 단계 ── 2. 순전파 활성값 전달 ──▶ 활성값 채널
│ 활성값 채널 ── 3. 단계 입력 전달 ──▶ 후단 단계
│ 활성값 채널 ◀─ 4. 역전파 기울기 전달 ─ 후단 단계
│ 전단 단계 ◀─ 5. 전단 기울기 전달 ── 활성값 채널
│ 스케줄 엔진 ◀── 완료•대기 상태 ───── 전단 단계
└──────────────────────────────────────────┘
```

### 동작 원리

1. 마이크로배치 전달: 전역 배치를 분할해 연속 투입함.
2. 순전파 활성값 전달: 전단 계산•중간 상태를 보존함.
3. 단계 입력 전달: 후단 장치의 순전파를 실행함.
4. 역전파 기울기 전달: 후단의 입력 기울기를 계산함.
5. 전단 기울기 전달: 역순 단계의 기울기를 전파함.

#### 한줄 요약

- 단계 속도를 맞추고 **순전파**•**역전파**를 중첩 실행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **GPipe**: 모든 마이크로배치의 순전파를 마친 뒤 역전파를 수행하는 동기 스케줄을 말한다.
- **1F1B(One Forward One Backward)**: 준비 단계 뒤 순전파와 역전파를 교대로 실행하는 스케줄을 말한다.

</details>

| 스케줄 | GPipe | 동기 1F1B | 인터리브 1F1B |
|:---|:---|:---|:---|
| 적용 기준 | **단순한 동기 학습** | **활성값 메모리 절감** | **버블 감소 우선** |
| 핵심 특징 | **모든 순전파 후 역전파** | **순전파•역전파 교대** | **가상 단계 교차 실행** |
| 한계 | **많은 활성값 보관** | **초기•종료 버블** | **통신 횟수•복잡도 증가** |

> 요약: 단순성은 **GPipe**, 활성값 메모리 절감은 **1F1B** 중심이 핵심이다.

#### 한줄 요약

- 전체 순전파•교대•가상 단계에 따른 **스케줄 차이**

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **단계 병목**: 가장 느린 파이프라인 단계가 전체 마이크로배치 처리 간격을 제한하는 현상로 정의된다.
- **버블 비율**: 전체 실행 시간 가운데 단계가 입력이나 결과를 기다리며 유휴한 시간의 비율로 정의된다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 단계 시간 차이로 **단계 병목** | 층별 시간•메모리 기반 단계 재분할 | 단계 **처리량 균형** 확보 |
| 적은 마이크로배치로 **버블 비율** 증가 | 마이크로배치 수•1F1B 스케줄 조정 | 장치 **유휴 시간 감소** |

#### 한줄 요약

- 단계 재분할과 **마이크로배치**•**1F1B**로 유휴 감소

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **동기 학습**: 모든 파이프라인 단계가 같은 배치의 갱신 경계를 공유하는 학습 방식이다.
- **처리량 균형**: 각 단계가 비슷한 속도로 마이크로배치를 처리해 유휴와 정체를 줄인 상태 원칙 준수

</details>

- 단순 동기 학습은 **GPipe**, 메모리•버블 절감은 **1F1B** 선택

#### 한줄 요약

- 단계 시간•메모리•버블로 **분할**•**스케줄** 결정
