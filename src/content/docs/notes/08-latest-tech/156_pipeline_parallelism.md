## 미리 알고가기

- **파이프라인 병렬 (Pipeline Parallelism, PP)**: 모델을 단계별로 나누고 마이크로배치를 중첩 처리하여 장치 활용률을 높이는 기법



## Ⅰ. 개요

- **정의/개념**: 모델 층·마이크로배치 파이프라인
- **배경/필요성**: 층 분할 장치의 유휴 시간 감소

### 쉽게 이해하기 (학습용)

- 제품 공정 시 다음 제품을 뒤따라 투입하여 각 작업대가 동시에 작업하게 함

## Ⅱ. 특징

- 각 단계가 인접 단계와 활성값·기울기를 전송한다
- 마이크로배치 증가는 버블을 줄이고 메모리를 늘린다
- 가장 느린 단계가 전체 처리 주기를 결정한다
- 스케줄 방식이 메모리·통신·버블을 조절한다

### 쉽게 이해하기 (학습용)

- 제품 투입 수와 작업 순서를 최적화하여 공정 내 반제품 정체와 작업대 대기 시간을 최소화함

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 단계 분할기 | 연산량·파라미터를 측정해 단계별 실행 시간을 균형화함 |
| 마이크로배치 분할기 | 전역 배치를 작은 실행 단위로 나누고 누적 기울기를 관리함 |
| 활성값 채널 | 단계 간 순전파 활성값과 역전파 기울기를 전달함 |
| 스케줄 엔진 | 준비·정상·마무리 구간의 실행 순서를 제어함 |
| 활성값 관리자 | 역전파 시 필요한 활성값을 보존하고 재계산함 |

> 요약: 단계 균형과 스케줄 엔진이 실행을 제어한다.

### 쉽게 이해하기 (학습용)

- 작업대별 처리 시간을 맞추고 제품 번호를 붙여 앞 작업과 되돌림 작업의 순서를 관리해야 같은 제품의 결과가 정확히 연결됨

## Ⅳ. 원리 및 절차 흐름도

```text
단계균형
  ↓
배치분할
  ↓
준비순전
  ↓
정상스케줄
  ↓
마무리역전
```

| 절차 | 설명 |
|:---|:---|
| 단계균형 | 층별 시간·메모리를 분석해 단계별 분할을 최적화함 |
| 배치분할 | 전역 배치를 나누고 활성값 보존 정책을 수립함 |
| 준비순전 | 초기 단계부터 마이크로배치를 투입하여 입력 채움 |
| 정상스케줄 | 중첩 실행으로 순·역전파를 효율적으로 처리함 |
| 마무리역전 | 남은 역전파 완료 후 누적 기울기로 모델을 갱신함 |

> 요약: 단계 균형과 동기 스케줄로 실행 효율을 높인다.

### 쉽게 이해하기 (학습용)

- 작업대 속도를 맞추고 제품을 차례로 채운 다음 앞 작업과 되돌림 작업을 정해진 순서로 겹쳐 처리하고 마지막 제품까지 끝나면 한 번 정산함

## Ⅴ. 종류 및 비교

| 판단 기준 | GPipe | 동기 1F1B | 인터리브 1F1B |
|:---|:---|:---|:---|
| 실행 순서 | 전체 순전파 후 역전파 | 순전파·역전파 번갈아 수행 | 가상 단계별 교차 실행 |
| 버블·메모리 | 단순 구조지만 활성값 다수 보관 | 활성값 메모리 절감 가능 | 버블 감소, 통신 횟수 증가 |
| 선택 기준 | 동기 실행·재현성 필요 시 | 메모리 절감이 중요할 때 | 통신 여유·버블 최적화 시 |

> 요약: 정확성, 메모리, 버블 등을 고려하여 스케줄을 선택함

### 쉽게 이해하기 (학습용)

- 모든 제품을 먼저 앞으로 보낸 뒤 되돌리는 방식, 한 개씩 앞뒤 작업을 번갈아 하는 방식, 작업대를 더 잘게 나눠 쉬는 틈을 메우는 방식의 차이임

## Ⅵ. 실무 사례

1. Google GPipe는 대형 신경망을 가속기별 셀로 나누고 배치를 마이크로배치로 분할해 동기식 파이프라인 학습을 수행함
2. NVIDIA Megatron-LM은 대규모 트랜스포머에서 동기식 1F1B와 가상 단계를 둔 인터리브 스케줄로 활성값 메모리와 버블을 조정함

### 쉽게 이해하기 (학습용)

- 실제 대형 학습 시스템도 모델을 작업대처럼 나누고 제품 묶음 수와 앞뒤 작업 순서를 조정해 장치가 쉬는 시간을 줄임

## Ⅶ. 결론

- 단계 균형·버블·메모리를 함께 최적화한다

### 쉽게 이해하기 (학습용)

- 여러 장치가 마이크로배치를 이어 처리해 쉬는 시간을 줄인다
