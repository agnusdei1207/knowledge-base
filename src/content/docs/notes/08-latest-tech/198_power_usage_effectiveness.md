## 미리 알고가기

- **전력 사용 효과성(Power Usage Effectiveness, PUE)**: '피유이'로 읽으며, 총 데이터센터 에너지를 IT 장비 에너지로 나눈 시설 효율 지표
- **데이터센터 인프라 효율(Data Center infrastructure Efficiency, DCiE)**: '디씨아이이'로 읽으며, IT 에너지를 총 시설 에너지로 나눈 백분율
- **부분 PUE(partial PUE, pPUE)**: '피피유이'로 읽으며, 명시한 구역·모듈의 총에너지를 해당 IT 에너지로 나눈 지표
- **표기 이유**: `PUE = 총 시설 에너지 / IT 장비 에너지`이므로 이상적 하한은 1이며, 1에 가까울수록 비IT 오버헤드가 작음
- **해석 경계**: PUE는 냉각·배전 효율 지표이며 IT 작업 효율·탄소·물 사용량을 직접 나타내지 않음

## Ⅰ. 개요

$$PUE = \frac{\text{데이터센터 총 시설 에너지}}{\text{IT 장비 에너지}}$$

- 정의/개념: 같은 기간의 **총 시설 에너지를 IT 장비 에너지로 나눈 무차원 비율**
- **배경/필요성**: 총전력량만으로는 **냉각·배전·조명 등 비IT 시설 오버헤드를 분리하기 어려운 한계**를 해소하기 위해 필요

### 쉽게 이해하기 (학습용)

- 서버가 100을 쓰고 데이터센터 전체가 150을 쓰면 PUE는 1.5이며, 나머지 50은 냉각·배전 등의 시설 사용량이다.

## Ⅱ. 특징

- 총 시설과 IT 에너지를 **같은 경계·기간에 계측**해야 비교할 수 있다.
- PUE가 1에 가까울수록 **비IT 시설 에너지 오버헤드가 작다**.
- 부하·기후·계측 경계의 영향을 받으므로 **IT 효율·탄소·물 지표와 함께 해석**해야 한다.

### 쉽게 이해하기 (학습용)

- 점수가 낮아도 서버가 일을 효율적으로 하는지는 알 수 없으므로 같은 조건의 시설 손실만 비교해야 한다.

## Ⅲ. 아키텍처 및 구성요소

```text
[총 시설 에너지 계측]
        ├─ [IT 장비 에너지]
        └─ [배전·냉각·조명 오버헤드]
                      ↓
              [PUE 산정·원인 분석]
```

| 설계 요소 | 설명 |
|:---|:---|
| 총 시설 계측 | **경계 내 전체 에너지 측정** |
| IT 장비 계측 | **서버·저장·네트워크 에너지 측정** |
| 경계·기간 명세 | **계측 위치·범주·기간 고정** |
| 오버헤드 분해 | **냉각·배전·조명 손실 분석** |
| 보조 지표 | **IT 효율·탄소·물·신뢰성 보완** |

> 요약: 동일 경계의 총 시설과 IT 에너지를 계측해 비IT 오버헤드를 분석한다.

### 쉽게 이해하기 (학습용)

- 건물 전체와 서버 전력을 같은 시간에 재고 그 차이를 냉각·배전 항목으로 나눈다.

## Ⅳ. 원리 및 절차 흐름도

```text
측정 경계 정의 → 총·IT 동시 계측 → PUE 산정 → 오버헤드 분석 → 개선·신뢰성 검증 → 재측정
```

| 절차 | 설명 |
|:---|:---|
| 측정 경계 정의 | 시설·IT 계측 위치와 기간 고정 |
| 총·IT 동시 계측 | 같은 기간 에너지 수집 |
| PUE 산정 | 총 시설 에너지를 IT 에너지로 나눔 |
| 오버헤드 분석 | 냉각·배전·조명 손실 분해 |
| 개선·신뢰성 검증 | 온도·용량·장애 조건 확인 |
| 재측정 | 동일 경계에서 효과 비교 |

> 요약: 측정 조건을 고정하고 시설 오버헤드를 개선한 뒤 같은 경계에서 다시 계산한다.

### 쉽게 이해하기 (학습용)

- 계절과 서버 부하를 함께 기록해야 냉각 조정이 실제로 시설 전력을 줄였는지 알 수 있다.

## Ⅴ. 종류 및 비교

| 시설 전력 효율 지표 | PUE | pPUE | DCiE |
|:---|:---|:---|:---|
| 적용 기준 | 데이터센터 전체 효율 | 구역·모듈별 병목 진단 | IT 전력 비중 표시 |
| 핵심 특징 | 총 시설 / IT 에너지 | 부분 시설 / 부분 IT | IT / 총 시설 × 100 |
| 한계 | 경계·부하가 다르면 오비교 | 전체 시설로 일반화 불가 | PUE와 같은 정보의 역수 |

> 요약: 전체·부분 경계를 구분하고 PUE와 DCiE의 역수 관계를 이해해야 한다.

### 쉽게 이해하기 (학습용)

- 전체 점수와 특정 구역 점수는 섞어 비교하지 않고, DCiE는 PUE를 반대로 표현한 값으로 본다.

## Ⅵ. 실무 사례

1. **외기 냉방 적용 전후의 연간 PUE 비교**
2. **서버 통합 후 총전력 감소·PUE 상승 동시 확인**

### 쉽게 이해하기 (학습용)

- 계절 전체를 포함해 냉각 전력과 온도 안정성이 실제 개선됐는지 확인한다.
- 서버 통합으로 분모가 더 크게 줄면 PUE가 상승할 수 있으므로 총전력 절감도 함께 본다.

## Ⅶ. 결론

- 시설 에너지 손실을 개선할 때 **동일 경계·기간의 PUE와 총전력·IT 효율·신뢰성을 함께 검증**해야 한다.

### 쉽게 이해하기 (학습용)

- PUE는 시설 지원 효율 지표이므로 데이터센터 전체 친환경 점수로 사용하면 안 된다.
