## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **전력 사용 효과성(Power Usage Effectiveness, PUE)**: 같은 기간의 데이터센터 총 시설 에너지를 IT 장비 에너지로 나눈 시설 효율 지표로 정의된다.
- **시설 오버헤드**: 냉각•배전•조명 등 IT 장비 외 설비가 소비하는 에너지이다.
- **정보기술(Information Technology, IT)**: 데이터를 처리•저장•전송하는 컴퓨팅 기술과 장비을 말한다.

</details>

$$PUE = \frac{\text{데이터센터 총 시설 에너지}}{\text{IT 장비 에너지}}$$

- 정의: 같은 기간 총 시설 에너지를 IT 장비 에너지로 나눈 **PUE**
- 배경/필요성: 총전력량만으로는 IT 소비와 **냉각•배전 시설 오버헤드 구분 곤란**

#### 한줄 요약

- 총 시설 150•IT 100의 **PUE 1.5•시설 오버헤드 50**

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **데이터센터 인프라 효율(Data Center infrastructure Efficiency, DCiE)**: IT 에너지를 총 시설 에너지로 나눈 PUE의 역수 지표을 말한다.
- **해석 경계**: 전력 사용 효과성이 냉각•배전 효율만 나타내며 정보기술 작업 효율•탄소•물 사용량은 직접 나타내지 않는 범위로 정의된다.
- **국제표준화기구(International Organization for Standardization, ISO)**: 국제 표준을 개발•발행하는 비정부 기구을 말한다.
- **국제전기기술위원회(International Electrotechnical Commission, IEC)**: 전기•전자 분야 국제 표준을 개발하는 기구로 정의된다.

</details>

- **ISO/IEC 30134-2:2026** 기반 동일 경계•기간 계측
- **PUE** 1에 가까울수록 비IT 오버헤드 감소•**DCiE** 증가
- 부하•기후 영향을 고려한 IT 효율과 **탄소•물 지표 병행**
#### 한줄 요약

- 동일 조건의 **시설 손실 비교**, IT 작업 효율은 별도 평가

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **총 시설 계측**: 정한 데이터센터 경계 안의 정보기술•배전•냉각•조명 에너지를 모두 측정하는 기능을 의미한다.
- **정보기술 장비 계측**: 서버•저장•네트워크 장비가 실제 사용한 에너지를 같은 기간에 측정하는 기능로 정의된다.

</details>

```text
             [경계•기간 명세]
               /           \
      [총 시설 계측]   [IT 장비 계측]
               \           /
              [오버헤드 분해]
                       |
                   [보조 지표]
```

선의 의미: 같은 경계•기간의 총 시설과 IT 에너지를 측정하고, 차이를 오버헤드와 보조 지표로 분석한다.

총 시설•IT 장비 계측의 **동일 경계•기간 적용**

| 구성요소 | 책임 |
|:---|:---|
| 총 시설 계측 | **경계 내 전체 에너지 측정** |
| IT 장비 계측 | 서버•저장•네트워크의 **에너지 측정** |
| 경계•기간 명세 | 계측 위치•범주와 **측정 기간** 고정 |
| 오버헤드 분해 | 냉각•배전과 **조명 손실** 분석 |
| 보조 지표 | IT 효율•탄소와 **물•신뢰성** 보완 |

#### 한줄 요약

- 동일 기간 총 시설•IT 전력의 **오버헤드 분해**

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **동일 조건 비교**: 계측 경계•기간•IT 부하•외기 온도를 맞춰 개선 전후 PUE를 대조하는 방법을 의미한다.
- **오버헤드 분해**: 총 시설과 IT 에너지의 차이를 냉각•배전•조명 등 원인별로 나누는 분석하는 개념을 의미한다.
- **서비스 수준 목표(Service Level Objective, SLO)**: 효율 개선 중에도 달성해야 할 사용자 중심 품질 목표로 정의된다.

</details>

```text
[운영 조직] ── 측정 경계•기간 ──▶ [에너지 계측]
                                        │ 1. 총•IT 에너지
                                        ▼
                                [PUE 계산•손실 분석]
                                        │ 2. PUE•오버헤드 개선안
                                        ▼
[운영 조직] ◀────── 재측정 결과 ──── [검증 체계]
```

### 동작 원리

1. 총•IT 에너지: 같은 기간의 **두 에너지 값** 제공
2. PUE•오버헤드 개선안: 부하•기후 기반 **냉각•배전 조건** 결정

#### 한줄 요약

- 동일 계절•IT 부하의 **PUE 시설 전력 개선 검증**

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **부분 전력 사용 효과성(partial Power Usage Effectiveness, pPUE)**: 명시한 구역•모듈의 총에너지를 해당 IT 에너지로 나눈 지표을 의미한다.
- **이상적 하한**: 총 시설 에너지가 IT 에너지보다 작을 수 없어 PUE가 이론적으로 가질 수 있는 최솟값 1을 말한다.

</details>

| 시설 전력 효율 지표 | PUE | pPUE | DCiE |
|:---|:---|:---|:---|
| 적용 기준 | 데이터센터 **전체 효율** | 구역•모듈별 **병목 진단** | **IT 전력 비중** 표시 |
| 핵심 특징 | **총 시설 / IT 에너지** | **부분 시설 / 부분 IT** | **IT / 총 시설 × 100** |
| 한계 | 경계•부하 차이에 따른 **비교 왜곡** | 전체 시설로 **일반화 불가** | PUE와 같은 정보의 **역수** |

#### 한줄 요약

- 전체•구역 범위와 **PUE•pPUE•DCiE 해석** 구분

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **부하•계절 영향**: IT 사용률과 외기 온도 차이가 냉각•배전 에너지와 PUE를 바꾸는 효과이다.
- **단독 최적화**: PUE만 낮추면서 총전력•물•탄소•장비 효율•서비스 신뢰성의 악화를 놓치는 접근하는 개념로 정의된다.
- **물 사용 효과성(Water Usage Effectiveness, WUE)**: 데이터센터 물 사용량을 IT 장비 에너지로 나눈 물 집약도로 정의된다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 계측 경계 차이로 **PUE 비교 왜곡** | **계측 위치•포함 설비•기간** 명시 후 동일 조건 비교 | **PUE 동일 경계 비교성** 확보 |
| 부하•계절 차이로 **개선 효과 오판** | **IT 부하•외기 온도** 기록과 연간•부하 구간 분석 | 부하•계절 **효과 오판** 감소 |
| PUE 단독 최적화로 **물•신뢰성 악화** | 총에너지•WUE•IT 효율•온도•**SLO 공동 검증** | 물•탄소•**신뢰성 악화** 방지 |

#### 한줄 요약

- 계측 경계•부하•단독 최적화의 **PUE 해석 위험 통제**

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **동일 경계 비교성**: 포함 설비•계측 위치•기간이 같아 두 PUE 값의 차이를 해석할 수 있는 성질로 정의된다.
- **보조 지표**: PUE가 표현하지 못하는 WUE•탄소•IT 작업 효율•SLO를 함께 판단하는 값이다.

</details>

- 시설 전체는 **PUE**, 구역 병목은 **pPUE**, 물•탄소는 별도 평가

#### 한줄 요약

- **동일 경계•부하•계절**에서 비교하고 WUE•탄소•SLO 병행
