## 미리 알고가기

- **백도어 공격**: 백도어 공격은 특정 트리거가 있을 때만 악성 동작을 일으키도록 모델 내부에 숨은 규칙을 심는 공격임
- **평상시 정확도**: 평상시 정확도가 높게 유지될 수 있어 일반 검증셋으로는 놓치기 쉬움
- **데이터 오염**: 데이터 오염과 모델 가중치 변조가 대표 침투 경로임

## Ⅰ. 개요

- **정의/개념**: 트리거에서만 악성 행동을 유도하는 공격이다
- **배경/필요성**: 정상 정확도에 숨은 조건부 행동을 탐지한다

### 쉽게 이해하기 (학습용)

- 평소에는 정답을 잘 말하다가 비밀 스티커가 붙은 순간 공격자가 정한 오답을 내도록 길들인 AI와 같음

## Ⅱ. 특징

- 데이터·모델 변조는 여러 공급망 경로를 노린다
- 정상 정확도 유지는 일반 성능 검사를 우회하게 한다
- 변형 트리거는 고정 패턴 탐지의 누락을 늘린다
- 제거·재학습은 적응형 공격과 성능 저하를 겪는다
- 변형별 시험은 숨은 행동의 배포 피해를 막는다

### 쉽게 이해하기 (학습용)

- 평소 문제 성적이 높아도 비밀 표시가 붙은 문제만 반복해서 틀릴 수 있고, 그 표시가 위치나 모양을 바꾸면 고정된 검사로 찾기 어려움

## Ⅲ. 아키텍처 및 구성요소

```text
  [주입 채널]
      │
  [손상 모델]
 ┌────┴────┐
[정상]   [트리거]
 └────┬────┘
  [이중 평가셋]
```

| 설계 요소 | 설명 |
|:---|:---|
| 트리거 패턴 | 악성 행동 활성화 조건 |
| 표적 행동 | 유도할 오분류·우회 출력 |
| 주입 채널 | 데이터·모델 변조 경로 |
| 손상 모델 | 트리거 반응 규칙 포함 |
| 이중 평가셋 | 정상 성능·공격 성공률 측정 |

> 요약: 일반·트리거 입력으로 조건부 행동을 구분한다

### 쉽게 이해하기 (학습용)

- 비밀 스위치인 트리거, 스위치가 켜질 때의 명령, 그 규칙을 심는 통로, 숨은 규칙을 가진 모델, 평상시와 발동 시를 나눠 보는 검증지가 필요함

## Ⅳ. 원리 및 절차 흐름도

```text
설계
 ↓
주입
 ↓
생성
 ↓
정상 평가
 ↓
공격 평가
```

| 절차 | 설명 |
|:---|:---|
| 트리거 설계 | 발동 조건과 표적 행동 결정 |
| 백도어 주입 | 트리거·행동 연관성 삽입 |
| 모델 생성 | 조건부 규칙을 가진 모델 생성 |
| 정상 행동 평가 | 일반 입력의 정상 성능 판정 |
| 트리거 행동 평가 | 공격 성공률과 변형 강건성 판정 |

> 요약: 정상 성능과 트리거 성공률로 백도어를 판정한다

### 쉽게 이해하기 (학습용)

- 공격자는 비밀 표시와 오답을 연결해 가르친 뒤 평범한 문제 성적을 확인하고, 표시가 있는 문제에서 원하는 오답이 나올 때까지 주입 방식을 바꿔 반복함

## Ⅴ. 종류 및 비교

| 판단 기준 | 라벨 변조 데이터 백도어 | 라벨 유지 데이터 백도어 | 모델 수준 백도어 |
|:---|:---|:---|:---|
| 핵심 특징 | 샘플·트리거·라벨 변조 | 라벨 유지·특징 변조 | 가중치·구조 직접 변조 |
| 적용 기준 | 라벨·트리거 이상 검사 | 특징 공간 이상 검사 | 계보·내부 행동 검사 |
| 주요 위험 | 오염 흔적 노출 | 정상 라벨로 탐지 회피 | 신뢰 출처에 악성 규칙 은닉 |

> 요약: 데이터·라벨·모델 통제 범위별로 검사를 달리한다

### 쉽게 이해하기 (학습용)

- 라벨 변조 방식은 문제와 정답을 함께 바꾸고, 라벨 유지 방식은 정답은 그대로 둔 채 문제 특징을 속이며, 모델 수준 공격은 학생의 판단 규칙 자체를 바꿈

## Ⅵ. 실무 사례

1. 표지판 모델의 위치·모양별 트리거 성공률을 평가한다
2. 외부 모델의 출처와 트리거 행동을 따로 검증한다

### 쉽게 이해하기 (학습용)

- 표지판 모델은 정상 정확도와 스티커 위치·모양별 표적 오분류율을 함께 평가한다.
- 서명이 맞는 외부 모델도 숨은 규칙이 있을 수 있어 출처와 트리거 행동을 따로 검증한다.

## Ⅶ. 결론

- 모델 계보와 변형별 트리거 성공률로 배포를 결정한다.

### 쉽게 이해하기 (학습용)

- 평소 검증 성적과 비밀 표시가 있는 검증을 모두 통과해야만, 겉으로 멀쩡한 AI를 배포할 근거가 생김
