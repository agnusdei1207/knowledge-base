## 미리 알고가기

- **백도어 공격(Backdoor Attack)**: 특정 트리거에서 공격자가 정한 표적 행동을 내도록 숨은 연관성을 심는 공격
- **트리거(Trigger)**: 백도어의 표적 행동을 활성화하는 패턴·문구·특징·조건
- **정상 정확도(Clean Accuracy)**: 트리거 없는 정상 입력의 정확도로 백도어 모델에서도 높게 유지될 수 있음
- **공격 성공률(Attack Success Rate, ASR)**: '에이에스알'로 읽고 트리거 입력이 표적 행동을 낸 비율을 표시
- **데이터 오염**: 백도어를 학습 데이터에 심는 경로이며 모델 가중치·구조 변조와 구분

## Ⅰ. 개요

- 정의/개념: 트리거 입력에서만 **공격자 지정 행동을 출력하도록 모델에 조건부 규칙을 삽입**
- **배경/필요성**: 정상 평가 정확도만으로 놓치는 **숨은 조건부 행동·공급망 모델 변조 탐지**

### 쉽게 이해하기 (학습용)

- 평소에는 정답을 잘 말하다가 비밀 스티커가 붙은 순간 공격자가 정한 오답을 내도록 길들인 AI와 같음

## Ⅱ. 특징

- **데이터 오염·사전학습 모델·가중치 변조**를 통해 트리거-행동 연관성을 삽입한다.
- **정상 정확도는 유지하고 트리거 ASR만 높여** 일반 성능 평가를 우회한다.
- **출처·무결성·정상 정확도·트리거 변형별 ASR**을 함께 검증한다.

### 쉽게 이해하기 (학습용)

- 평소 문제 성적이 높아도 비밀 표시가 붙은 문제만 반복해서 틀릴 수 있고, 그 표시가 위치나 모양을 바꾸면 고정된 검사로 찾기 어려움

## Ⅲ. 아키텍처 및 구성요소

```text
  [주입 채널]
      │
  [손상 모델]
 ┌────┴────┐
[정상]   [트리거]
 └────┬────┘
  [이중 평가셋]
```

| 설계 요소 | 설명 |
|:---|:---|
| 트리거 패턴 | 악성 행동 활성화 조건 |
| 표적 행동 | 유도할 오분류·우회 출력 |
| 주입 채널 | 데이터·모델 변조 경로 |
| 손상 모델 | 트리거 반응 규칙 포함 |
| 이중 평가셋 | 정상 성능·공격 성공률 측정 |

> 요약: 일반·트리거 입력으로 조건부 행동을 구분한다

### 쉽게 이해하기 (학습용)

- 비밀 스위치인 트리거, 스위치가 켜질 때의 명령, 그 규칙을 심는 통로, 숨은 규칙을 가진 모델, 평상시와 발동 시를 나눠 보는 검증지가 필요함

## Ⅳ. 원리 및 절차 흐름도

```text
트리거 설계
 ↓
백도어 주입
 ↓
모델 생성
 ↓
정상 행동 평가
 ↓
트리거 행동 평가
```

| 절차 | 설명 |
|:---|:---|
| 트리거 설계 | 발동 조건과 표적 행동 결정 |
| 백도어 주입 | 트리거·행동 연관성 삽입 |
| 모델 생성 | 조건부 규칙을 가진 모델 생성 |
| 정상 행동 평가 | 일반 입력의 정상 성능 판정 |
| 트리거 행동 평가 | 공격 성공률과 변형 강건성 판정 |

> 요약: 정상 성능과 트리거 성공률로 백도어를 판정한다

### 쉽게 이해하기 (학습용)

- 공격자는 비밀 표시와 오답을 연결해 가르친 뒤 평범한 문제 성적을 확인하고, 표시가 있는 문제에서 원하는 오답이 나올 때까지 주입 방식을 바꿔 반복함

## Ⅴ. 종류 및 비교

| 백도어 삽입 경로 | 라벨 변조 데이터 | 클린 라벨 데이터 | 모델 수준 변조 |
|:---|:---|:---|:---|
| 적용 기준 | 라벨·트리거 이상 검사 | 특징 공간 이상 검사 | 계보·내부 행동 검사 |
| 핵심 특징 | 트리거·표적 라벨 변조 | 정상 라벨·특징 변조 | 가중치·구조 직접 변조 |
| 한계 | 라벨 이상으로 노출 가능 | 정상 라벨로 탐지 회피 | 신뢰 출처에 규칙 은닉 |

> 요약: 데이터·라벨·모델 통제 범위별로 검사를 달리한다

### 쉽게 이해하기 (학습용)

- 라벨 변조 방식은 문제와 정답을 함께 바꾸고, 라벨 유지 방식은 정답은 그대로 둔 채 문제 특징을 속이며, 모델 수준 공격은 학생의 판단 규칙 자체를 바꿈

## Ⅵ. 실무 사례

1. 표지판 모델의 **위치·모양별 트리거 성공률**을 평가한다

### 쉽게 이해하기 (학습용)

- 정상 정확도가 높아도 특정 표식에서 오분류가 반복되는지 변형별로 확인한다

## Ⅶ. 결론

- 은닉 트리거의 표적 오분류를 탐지하기 위해 **모델 출처·정상 정확도·변형별 ASR·활성 패턴**을 검토하고, 의심 모델은 격리·정제 후 재검증한다

### 쉽게 이해하기 (학습용)

- 평소 검증 성적과 비밀 표시가 있는 검증을 모두 통과해야만, 겉으로 멀쩡한 AI를 배포할 근거가 생김
