## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **백도어 공격**: 특정 트리거에서 공격자가 정한 표적 행동을 내도록 모델에 숨은 연관성을 심는 공격이다.
- **조건부 모델 공격**: 일반 입력에서는 정상 동작하지만 특정 조건에서만 악성 행동이 활성화되는 공격을 의미한다.
- **인공지능(Artificial Intelligence, AI)**: 입력을 바탕으로 예측•생성•의사결정을 수행하는 시스템을 의미한다.

</details>

- 정의/개념: 정상 입력에는 정상 동작하지만 특정 트리거에는 지정 행동을 내도록 주입하는 **백도어 기반 조건부 모델 공격**임.
- 배경/필요성: 정상 정확도만으로는 숨은 **트리거 조건부 행동** 식별하기 어렵음.

#### 한줄 요약

- 평소에는 정상 동작하지만 특정 트리거에서 공격자가 지정한 행동을 내는 AI 공격이다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **트리거**: 백도어의 표적 행동을 활성화하는 패턴•문구•특징 또는 조건로 정의된다.
- **정상 정확도**: 트리거 없는 정상 입력의 정확도로 백도어 모델에서도 높게 유지될 수 있는 방식을 말한다.
- **공격 성공률(Attack Success Rate, ASR)**: 트리거 입력이 공격자가 의도한 표적 행동을 유발한 비율을 말한다.

</details>

- 트리거•행동을 연결하는 **데이터 오염•모델•가중치 변조**가 핵심임.
- 일반 성능 평가를 우회하는 **정상 정확도 유지•ASR 상승**이 핵심임.
- 은닉 행동을 찾는 **출처•무결성•변형별 ASR 검증**이 핵심임.

#### 한줄 요약

- 트리거 패턴이 위치•형태•크기를 변형하면 고정 규칙 기반 탐지로는 식별이 불가능하므로, 트리거 변형에 강건한 다중 검증 기법이 필요하다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **표적 행동**: 트리거가 활성화됐을 때 공격자가 모델에 유도하려는 오분류•우회 출력로 정의된다.
- **트리거 적용**: 패턴•토큰•패치•조건으로 숨은 표적 행동을 활성화하는 방식을 의미한다.
- **주입 채널**: 데이터•가중치•모델 구조에 트리거와 행동의 연관성을 심는 경로이다.
- **손상 모델(Compromised Model)**: 정상 입력에는 정상적으로 보이지만 트리거 입력에는 공격자가 정한 행동을 수행하도록 변조된 모델이다.
- **이중 평가기**: 정상 정확도와 트리거 공격 성공률을 분리해 측정하는 구성요소을 말한다.

</details>

ASR은 트리거 변형별 표적 행동 발생률을 측정하고, 은닉성은 정상 입력 성능으로 평가한다.

```text
[트리거 생성기]---[표적 행동 정의부]
        |                  |
        +----------[주입 채널]
                         |
                    [손상 모델]
                         |
                    [이중 평가기]
```

선의 의미: 트리거 생성기와 표적 행동 정의부가 주입 채널에 결합되고, 손상 모델과 이중 평가기가 조건부 악성 행동 및 정상 성능의 검증 경계를 구성한다.

| 구성요소 | 책임 |
|:---|:---|
| 트리거 생성기 | 악성 행동 활성화 조건 구성 |
| 표적 행동 정의부 | 유도할 오분류•우회 출력 지정 |
| 주입 채널 | 데이터•모델 변조 경로 |
| 손상 모델 | 트리거 반응 규칙 포함 |
| 이중 평가기 | 정상 정확도•공격 성공률 측정 |

#### 한줄 요약

- 비밀 스위치인 트리거, 스위치가 켜질 때의 명령, 그 규칙을 심는 통로, 숨은 규칙을 가진 모델, 평상시와 발동 시를 나눠 보는 검증지가 필요하다는 점이 핵심이다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **트리거 변형**: 위치•모양•크기•문구를 바꿔도 백도어가 활성화되는지 시험하는 입력군을 말한다.
- **은닉성**: 정상 입력의 성능과 동작을 유지해 백도어 존재가 일반 평가에서 드러나지 않는 성질을 말한다.

</details>

```text
트리거•표적 행동 정의부
   │ 1. 트리거 패턴 설계
   │ 2. 표적 행동 지정
   ▼
주입 채널
   │ 3. 트리거•행동 연관성 주입
   ▼
손상 모델
   │ 4. 정상•트리거 추론
   ▼
이중 평가기
   └── 5. 은닉성•변형별 ASR 평가 ──▶ 손상 모델
```

1. **트리거 패턴 설계**: 위치•모양•문구의 발동 조건을 구성함.
2. **표적 행동 지정**: 트리거 입력에서 유도할 결과를 결정함.
3. **트리거•행동 연관성 주입**: 데이터•가중치에 조건부 규칙을 삽입함.
4. **정상•트리거 추론**: 일반 입력과 발동 입력의 행동을 분리함.
5. **은닉성•변형별 ASR 평가**: 정상 정확도와 공격 강건성을 판정함.

#### 한줄 요약

- 공격자는 비밀 표시와 오답을 연결해 가르친 뒤 평범한 문제 성적을 확인하고, 표시가 있는 문제에서 원하는 오답이 나올 때까지 주입 방식을 바꿔 반복하는 것이 핵심이다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **라벨 변조 백도어**: 트리거 표본의 라벨을 공격 목표로 바꿔 조건부 행동을 학습시키는 방식을 의미한다.
- **클린 라벨 백도어**: 정상 라벨을 유지한 채 입력 특징을 조작해 조건부 행동을 학습시키는 방식로 정의된다.
- **모델 수준 변조**: 가중치나 구조를 직접 바꿔 트리거 반응 규칙을 삽입하는 방식이다.

</details>

| 백도어 삽입 경로 | 라벨 변조 데이터 | 클린 라벨 데이터 | 모델 수준 변조 |
|:---|:---|:---|:---|
| 적용 기준 | 라벨•**트리거 이상** 검사 | **특징 공간 이상** 검사 | 계보•**내부 행동** 검사 |
| 핵심 특징 | 트리거•**표적 라벨 변조** | 정상 라벨•**특징 변조** | 가중치•**구조 직접 변조** |
| 한계 | 라벨 이상으로 **노출 가능** | 정상 라벨로 **탐지 회피** | 신뢰 출처에 **규칙 은닉** |

#### 한줄 요약

- 라벨 변조 방식은 문제와 정답을 함께 바꾸고, 라벨 유지 방식은 정답은 그대로 둔 채 문제 특징을 속이며, 모델 수준 공격은 학생의 판단 규칙 자체를 바꿈이 핵심이다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **백도어 은닉**: 높은 정상 정확도 때문에 트리거 조건부 악성 행동이 일반 평가에서 보이지 않는 문제을 말한다.
- **고정 패턴 검사 우회**: 트리거의 위치•모양을 바꿔 단일 패턴 기반 탐지를 피하는 문제이다.
- **규칙 은닉**: 공급 모델의 가중치•구조에 악성 행동이 포함돼 출처만 믿고 배포하면 놓치는 문제로 정의된다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 정상 정확도에 **백도어 은닉** | 정상 정확도와 **ASR 동시 평가** | 조건부 **악성 행동 식별** |
| 트리거의 **위치•모양 변형** | 변형군별 **공격 성공률** 측정 | 고정 패턴 **검사 우회 방지** |
| 공급 모델의 **규칙 은닉** | 모델 계보•활성•**가중치 무결성** 검증 | 변조 모델의 **배포 차단** |

#### 한줄 요약

- 정상 정확도가 높아도 특정 표식에서 오분류가 반복되는지 변형별로 확인한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **모델 계보**: 모델의 원본•학습 데이터•변환•검증•배포 버전을 추적하는 기록을 의미한다.
- **의심 모델 격리**: 백도어 가능성이 있는 모델을 운영 환경과 분리해 변형별 ASR과 무결성을 재검증하는 조치을 말한다.

</details>

- **모델 출처•정상 정확도•변형별 ASR**로 의심 모델을 격리하고 재검증이 핵심임.

#### 한줄 요약

- 정상 입력과 트리거 변형 검증을 모두 통과한 AI만 배포한다.
