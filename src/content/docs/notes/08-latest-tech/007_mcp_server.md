## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **모델 컨텍스트 프로토콜 서버(Model Context Protocol Server, MCP Server)**: 도구•리소스•프롬프트를 표준 기능으로 노출하고 백엔드 접근과 실행을 통제하는 프로그램이다.
- **인공지능(Artificial Intelligence, AI)**: 학습•추론으로 기능을 선택하고 결과를 생성하는 기술이다.

</details>

- 정의/개념: **AI** 호스트에 표준 기능을 노출하고 백엔드 실행을 통제하는 **MCP Server**임.
- 배경/필요성: 맞춤 API마다 기능 발견•권한 방식이 달라 재사용과 일관된 통제가 어렵음.

#### 한줄 요약
- **MCP Server**는 허용된 도구•리소스•프롬프트만 노출한다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **기능 발견**: 클라이언트가 서버의 도구•리소스•프롬프트 목록과 명세를 조회하는 과정을 말한다.
- **검증 축**: 인증•인가•입력 검증으로 서버 실행 경계를 통제하는 관점이다.
- **구조화 결과**: 클라이언트가 후속 처리할 수 있도록 정해진 필드와 형식으로 반환한 실행 결과로 정의된다.

</details>

- **기능 발견**: 목록•명세와 캐시 힌트의 동적을 제공함.
- **검증 축**: 인증•인가•입력 검증 기반 실행 경계를 통제함.
- 결과 축: 구조화 결과•오류 기반 후속 추론을 지원함.

#### 한줄 요약
- 서버는 **검증 축**에 따라 검증하고 **구조화 결과** 또는 오류를 반환한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **도구 제공자**: 입력 스키마와 실행 결과 계약을 공개하고 권한 검증 뒤 백엔드 동작을 수행하는 서버 구성요소을 말한다.
- **프로토콜 처리기**: JSON-RPC 요청•응답•알림•오류를 해석해 해당 기능 처리기로 전달하는 구성요소이다.
- **기능 레지스트리**: 서버의 도구•리소스•프롬프트 명세와 처리기를 등록•조회하는 구성요소을 의미한다.
- **정책 집행기**: 호출 주체•테넌트•권한•입력 범위를 검증해 실행 허용 여부를 결정하는 구성요소로 정의된다.
- **백엔드 어댑터**: 검증된 MCP 요청을 내부 API나 업무 시스템 호출로 변환하는 구성요소을 의미한다.
- **표준 입출력(Standard Input/Output, stdio)**: 로컬 클라이언트와 서버 프로세스가 메시지를 교환하는 전송 방식을 말한다.
- **스트리밍 가능 하이퍼텍스트 전송 프로토콜(Streamable Hypertext Transfer Protocol, Streamable HTTP)**: 원격 MCP 요청을 HTTP POST와 라우팅 헤더로 교환하는 전송 방식을 의미한다.
- **자바스크립트 객체 표기법 원격 절차 호출(JavaScript Object Notation Remote Procedure Call, JSON-RPC)**: MCP 요청•응답•알림•오류를 표현하는 메시지 형식이다.
- **표현 상태 전송 응용 프로그래밍 인터페이스(Representational State Transfer Application Programming Interface, REST API)**: 백엔드 자원을 고정 HTTP 계약으로 호출하는 인터페이스이다.

</details>

- **도구 제공자** 중심 구조는 **stdio** 또는 **Streamable HTTP** 연결을 받아 **JSON-RPC** 메시지로 처리함.

```text
                   [전송 계층]
                        |
                 [프로토콜 처리기]
                        |
                 [기능 레지스트리]
                        |
                   [정책 집행기]
                        |
                  [백엔드 어댑터]
```

선의 의미: 전송 계층과 프로토콜 처리기가 기능 레지스트리를 노출하고, 정책 집행기 경계를 거쳐 백엔드 어댑터와 연결되는 MCP 서버 계층을 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 전송 계층 | **stdio•Streamable HTTP 연결** 수신 |
| 프로토콜 처리기 | **프로토콜 처리기**가 JSON-RPC 요청•응답•오류 처리 |
| 기능 레지스트리 | **기능 레지스트리**가 도구•리소스•프롬프트 명세 관리 |
| 정책 집행기 | **정책 집행기**가 인증•인가•입력•테넌트 검증 |
| 백엔드 어댑터 | **백엔드 어댑터**가 **REST API**•업무 시스템 결과 변환 |

#### 한줄 요약
- **정책 집행기**가 권한을 검증하고 백엔드 호출을 통제한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **요청•응답 상관관계**: JSON-RPC 식별자를 이용해 각 실행 요청과 성공•오류 결과를 연결하는 관계이다.
- **모델 컨텍스트 프로토콜 클라이언트(Model Context Protocol Client, MCP Client)**: 서버의 기능 목록•명세를 발견하고 실행 결과를 교환하는 구성요소을 말한다.
- **버전•메타•기능 목록 요청**: 요청별 프로토콜 버전•클라이언트 식별과 목록 조회를 전달하는 단계을 말한다.
- **기능 명세•캐시 힌트 제공**: 기능 설명•입력 스키마•유지 시간•공유 범위를 반환하는 단계을 의미한다.
- **기능명•구조화 인자 요청**: 선택한 기능과 검증할 인자를 서버에 전달하는 단계이다.
- **권한•입력 검증 후 백엔드 실행**: 허용된 주체와 입력의 작업만 업무 시스템에서 수행하는 단계이다.

</details>

- **MCP Client**와 서버는 **JSON-RPC** 식별자로 요청과 결과를 연결함.

```text
MCP 클라이언트
   │ 1. 버전•메타•기능 목록 요청
   ▼
MCP 서버
   │ 2. 기능 명세•캐시 힌트 제공
   ▼
MCP 클라이언트
   │ 3. 기능명•구조화 인자 요청
   ▼
MCP 서버
   │ 4. 권한•입력 검증 후 백엔드 실행
   ▼
업무 시스템
   │ 백엔드 결과•오류 반환
   ▼
MCP 서버
   │ 서버 변환 결과•오류 반환
   ▼
MCP 클라이언트
```

### 동작 원리

1. **버전•메타•기능 목록 요청**: 요청별 프로토콜 버전•클라이언트 식별을 전달함.
2. **기능 명세•캐시 힌트 제공**: 설명•입력 스키마•TTL•공유 범위를 제공함.
3. **기능명•구조화 인자 요청**: 선택 기능과 검증 인자를 전달함.
4. **권한•입력 검증 후 백엔드 실행**: **요청•응답 상관관계**를 유지하며 허용 작업만 수행함.

#### 한줄 요약
- **권한•입력 검증 후 백엔드 실행** 뒤 결과를 반환한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **Local MCP Server**: 호스트가 시작한 프로세스로 실행되고 stdio를 통해 한 클라이언트와 메시지를 교환하는 서버이다.
- **REST API Server**: 고정된 HTTP 메서드•자원 계약으로 기능을 제공하는 서버을 의미한다.
- **통합 자원 식별자(Uniform Resource Identifier, URI)**: 웹 자원을 식별하는 표준 문자열을 말한다.

</details>

- **Local MCP Server**와 **REST API Server**를 기능 발견 방식과 전송 계약으로 비교함.

| 판단 기준 | MCP Server | REST API 서버 |
|:---|:---|:---|
| 적용 기준 | **MCP Server**는 AI의 동적 기능 선택 | **REST API Server**는 고정 API 계약 기반 기능 제공 |
| 핵심 특징 | 기능 목록•명세 동적 제공 | HTTP 메서드•**URI** 계약 |
| 한계 | 서버의 권한•입력 검증 책임 | 모델용 기능 협상 부재 |

> 요약: **MCP 서버 기반 모델 기능 발견**, **REST API 기반 고정 HTTP 계약**이 핵심이다.

#### 한줄 요약
- 동적 기능 발견은 **MCP**, 고정 웹 자원은 **REST**가 핵심이다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **서버 최소 권한**: MCP Server가 제공 기능에 필요한 백엔드 자원과 작업만 접근하도록 계정•경로•명령을 제한하는 원칙을 의미한다.
- **구조화 오류**: 실패 원인과 재시도 가능 여부를 클라이언트가 판정하도록 코드와 데이터로 표현한 실행 결과로 정의된다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 과도한 공개로 공격 표면 확대 | **서버 최소 권한**과 허용 목록 적용 | 고권한 기능 오용 차단 |
| 테넌트 식별 누락으로 교차 접근 | 인증 주체•백엔드 쿼리에 테넌트 강제 | 데이터 경계 보장 |
| 불명확한 오류로 복구 판단 혼선 | **구조화 오류**로 재시도 가능성 전달 | 안전한 복구 경로 선택 |

#### 한줄 요약
- 사용자별 **테넌트•최소 권한**으로 자료 범위를 제한한다.

<summary>핵심 용어</summary>

</details>

- AI 동적 기능 발견은 **MCP Server**, 고정 HTTP 계약은 **REST API**을 선택함.

#### 한줄 요약
