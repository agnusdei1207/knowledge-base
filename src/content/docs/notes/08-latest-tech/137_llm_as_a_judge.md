## 미리 알고가기

- **LLM-as-a-Judge**: LLM-as-a-Judge는 다른 모델의 답변 품질을 LLM이 채점하도록 만드는 평가 방식임
- **사람 평**: 사람 평가 비용을 줄이면서 대규모 자동 평가를 가능하게 하지만 편향과 일관성 문제가 있음
- **블라인드 평가**: 블라인드 평가와 기준표와 사람 교정이 함께 있어야 신뢰도를 확보할 수 있음


## Ⅰ. 개요

- **정의/개념**: LLM이 응답 점수·선호를 판정
- **배경/필요성**: 열린 응답의 반복 평가 비용 절감

### 쉽게 이해하기 (학습용)

- 글의 정답이 하나가 없을 때 채점 기준표를 받은 다른 AI가 점수와 이유를 내되, 그 결과가 사람 채점과 맞는지 다시 확인하는 방식임

## Ⅱ. 특징

- 기준표·문맥·참조 답안이 판정 범위를 고정한다
- 점수화·쌍대 비교를 모두 지원한다
- 반복 비용은 낮지만 사람 판단의 대리 지표다
- 응답 순서·문체·길이가 판정을 편향시킨다

### 쉽게 이해하기 (학습용)

- 같은 답안도 앞자리에 놓이거나 길게 쓰였다는 이유로 더 좋아 보일 수 있으므로, AI 채점은 빠르지만 채점 습관까지 함께 검사해야 함

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 평가 표본 | 질문·문맥·응답과 참조 답안 |
| 평가 기준표 | 항목별 판정 기준·단계·동점 조건 |
| 블라인드 변환 | 모델 식별자 제거와 응답 순서 변경 |
| 판정 모델 | 기준표에 따라 점수·선호·이유 생성 |
| 사람 교정 | 일치도와 불일치 유형을 확인하는 표본 |

> 요약: 표본·기준표를 가리고 사람 교정으로 편향을 확인한다.

### 쉽게 이해하기 (학습용)

- 검증지에서 이름을 가리고 답안 순서를 섞은 뒤 AI가 기준표로 채점하며, 미리 사람이 채점한 일부 답안으로 AI 채점이 치우쳤는지 확인하는 구조임

## Ⅳ. 원리 및 절차 흐름도

```text
평가 표본·기준표 결합 → 후보 익명화·순서 무작위화
                                  ↓
                         LLM 판정·순서 교환 재판정
                                  ↓
                       사람 교정 집합과 일치?
                  ├─ 예 → 자동 평가 결과 채택
                  └─ 아니요 → 사람 검토·기준표 조정 후 반복
```

| 절차 | 설명 |
|:---|:---|
| 표본 구성 | 대표 응답·실패 유형·고위험 사례 포함 |
| 블라인드 변환 | 모델 식별자 제거 및 후보 순서 무작위화 |
| 반복 판정 | 순서 교환 시 결과 불일치 표시 |
| 사람 교정 | 사람 판정과의 일치도 및 편향 확인 |
| 결과 결정 | 일치 표본은 집계하고 불일치는 사람 검토 |

> 요약: 순서 교환 반복 판정 후 사람 교정과 대조해 최종 결정함

### 쉽게 이해하기 (학습용)

- 두 답안의 자리를 바꿔도 같은 승자를 고르는지 확인하고, 사람 채점과도 맞을 때만 AI 점수를 믿는 순서임

## Ⅴ. 종류 및 비교

| 판단 기준 | 규칙 기반 | LLM 평가자 | 사람 평가 |
|:---|:---|:---|:---|
| 판정 방식 | 규칙 대조 | 점수·선호·이유 생성 | 전문가 직접 판단 |
| 적용 기준 | 정답·형식 확인 | 열린 응답 반복 평가 | 고위험·모호 사례 |
| 주요 위험 | 기계적 오판 | 편향 발생 | 비용·편차 큼 |

> 요약: 규칙·LLM·사람은 정형·개방·고위험 평가에 쓴다.

### 쉽게 이해하기 (학습용)

- 객관식은 정답표로, 서술형 초벌 채점은 AI로, 애매하거나 중요한 답안은 사람이 보는 것처럼 판정 대상과 위험에 따라 평가자를 나눔

## Ⅵ. 실무 사례

1. 고객상담 챗봇은 기존·후보 응답을 블라인드 비교하고, 순서 교환 불일치를 사람에게 보냄
2. 사내 문서 질의응답은 판정 모델과 사람의 근거성 판단이 어긋난 표본으로 기준표를 교정함

### 쉽게 이해하기 (학습용)

- 챗봇 새 버전을 빠르게 초벌 채점하되 답안 자리만 바꿔도 결과가 뒤집히거나 사람이 동의하지 않는 사례는 자동 통과시키지 않는 것임

## Ⅶ. 결론

- 편향·일치도 문제가 크면 사람 판정으로 전환한다

### 쉽게 이해하기 (학습용)

- AI 채점은 빠른 1차 심사로 쓰고, 채점 순서에 흔들리거나 사람 기준과 어긋나면 최종 판단을 사람에게 넘겨야 함
