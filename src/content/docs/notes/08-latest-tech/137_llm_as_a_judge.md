## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **LLM 평가자(Large Language Model as a Judge, LLM-as-a-Judge)**: 기준표와 평가 문맥을 받은 언어 모델이 다른 모델의 응답 점수•선호•판정 이유를 생성하는 평가 방식이다.
- **평가 기준표(Rubric)**: 정확성•충실성•유용성 등 항목별 판정 조건과 점수 단계를 정의한 채점표이다.

</details>

- 정의: 기준표로 다른 모델 응답을 판정하는 **LLM 평가자**이다.
- 배경/필요성: 반복 인간 평가는 **비용 증가•평가자 편차**로 대규모 평가 제약

#### 한줄 요약
- 블라인드 자동 판정을 사람과 보정해 **초벌 평가**에 활용

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **쌍대 비교(Pairwise Comparison)**: 두 후보 응답을 함께 제시하여 더 나은 응답이나 동점을 선택하는 판정 방식이다.
- **판정 편향**: 응답 품질 외의 순서•길이•생성 모델 정보가 평가 결과에 영향을 주는 현상이다.

</details>

- 기준표•문맥•참조 답안 기반 **판정 범위 고정**
- **점수화•쌍대 비교** 기반 대량 의미 평가
- 위치•길이•자기 선호에 따른 **판정 편향**

#### 한줄 요약
- 순서 교환으로 **위치•길이 편향과 판정 일관성** 검증

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **블라인드 평가(Blind Evaluation)**: 모델 이름과 식별 정보를 숨기고 후보 순서를 무작위화하여 판정하는 방식이다.
- **인간 교정 집합**: 자동 평가의 일치도와 편향을 검증하기 위해 사람이 미리 판정한 대표 표본이다.

</details>

```text
[평가 표본] ----- [블라인드 변환기]
                           |
 [평가 기준표] ----- [LLM 판정기] ----- [인간 교정 집합]
```

| 구성요소 | 책임 |
|:---|:---|
| 평가 표본 | 질문•문맥•후보•참조 답의 **판정 입력 보관** |
| 평가 기준표 | 항목•단계•동점의 **평가 조건 정의** |
| 블라인드 변환기 | 모델 식별 제거와 **후보 순서 교환** |
| LLM 판정기 | 기준표 기반 **점수•선호•이유 생성** |
| 인간 교정 집합 | 사람 판정과의 **일치도•편향 검증** |

#### 한줄 요약
- 식별•순서를 가리고 **인간 교정 집합** 및 자동 판정 대조

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **순서 교환 평가**: 후보의 앞뒤 위치를 바꾸어 반복 판정하고 결과의 일관성을 측정하는 절차이다.
- **인간 전환**: 자동 판정의 일치도가 낮거나 위험도가 높은 사례를 사람 평가자에게 넘기는 통제이다.

</details>

```text
평가•결과 책임자
   │ 1. 대표 표본•기준표 구성
   ▼
블라인드 변환기
   │ 2. 식별 제거•후보 순서 교환
   ▼
LLM 판정기
   │ 3. 반복 점수•선호 판정
   ▼
인간 교정자
   │ 4. 사람 판단•편향 대조
   ▼
평가•결과 책임자
   └ 5. 자동 채택•인간 전환 결정
```

### 동작 원리

1. 대표 표본•기준표 구성: 정상•실패•고위험 사례와 **판정 조건** 정의
2. 식별 제거•후보 순서 교환: 모델 이름•위치의 **선입견 요인** 통제
3. 반복 점수•선호 판정: 순서별 반복 평가로 **판정 일관성** 측정
4. 사람 판단•편향 대조: 교정 집합의 **일치도•불일치 유형** 검증
5. 자동 채택•인간 전환 결정: 일치도•위험도별 **최종 평가 주체** 선택

#### 한줄 요약
- 순서 안정성과 사람 일치도로 **자동 채택•인간 전환** 판정

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **규칙 기반 평가**: 정답•형식과 명시적 조건을 기계적으로 대조하는 평가 방식이다.
- **인간 평가**: 전문가가 문맥과 위험을 고려해 응답 품질을 직접 판정하는 평가 방식이다.

</details>

| 구분 | 규칙 기반 평가 | LLM 평가자 | 인간 평가 |
|:---|:---|:---|:---|
| 적용 기준 | **정답**•**형식** 판정 | **개방형 응답** 대량 평가 | **고위험•모호 사례** |
| 핵심 특징 | 결정 규칙의 **자동 대조** | 의미 기반 **점수•선호 생성** | 전문가의 **직접 판단** |
| 한계 | **의미**•**맥락** 판정 한계 | **위치•자기 선호 편향** | **시간•비용•평가자 편차** |

#### 한줄 요약
- 정형•개방형•고위험에 따른 **평가 주체** 선택

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **위치 편향(Position Bias)**: 후보 내용보다 제시된 앞•뒤 순서에 따라 평가 결과가 달라지는 현상이다.
- **자기 선호 편향(Self-Preference Bias)**: 평가 모델이 자신이나 유사한 계열이 만든 응답을 더 높게 판정하는 현상이다.
- **판정 일치도**: 자동 평가와 인간 평가 또는 반복 평가 사이에서 같은 결론이 나온 비율이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 후보 순서의 **위치 편향** | **순서 교환 반복•불일치 인간 전환** | 쌍대 판정 **안정성 확보** |
| 평가 모델의 **자기 선호 편향** | **모델 식별 블라인드•이종 평가자 대조** | 생성 계열 편향 **완화** |
| 사람과 낮은 **판정 일치도** | **기준표 보정•고위험 사례 수동 판정** | 자동 평가 **적용 경계 확정** |

#### 한줄 요약
- 순서•모델 식별을 가리고 **낮은 일치도** 기반 인간 전환

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **순서 안정성**: 후보 배치를 바꾸어도 평가 결과가 일관되게 유지되는 성질이다.
- **적용 경계**: 자동 판정을 허용하고 인간 검토로 전환하는 일치도•위험도 기준이다.

</details>

- **순서 안정성•인간 일치도** 기반 자동 판정과 인간 전환 결정

#### 한줄 요약
- 위치•자기 선호가 낮고 **인간 일치도** 높은 범위만 자동화
