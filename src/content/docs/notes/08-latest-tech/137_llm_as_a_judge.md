## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **LLM 평가자(Large Language Model as a Judge, LLM-as-a-Judge)**: 기준표와 평가 문맥을 받은 언어 모델이 다른 모델의 응답 점수·선호·판정 이유를 생성하는 평가 방식이다.
- **평가 기준표(Rubric)**: 정확성·충실성·유용성 등 항목별 판정 조건과 점수 단계를 정의한 채점표이다.

</details>

- 정의/개념: 거대 언어 모델(Large Language Model, LLM)이 평가 기준표에 따라 다른 모델의 응답 점수·선호·이유를 생성하는 **LLM 평가자 방식**
- 배경/필요성: 개방형 응답의 반복 인간 평가는 **비용·평가자 편차** 증가

#### 한줄 요약
- 이름을 가린 서술형 답안과 채점표를 다른 언어 모델에 주고 사람 채점과 맞는지 확인해 초벌 평가에 사용함

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **쌍대 비교(Pairwise Comparison)**: 두 후보 응답을 함께 제시하여 더 나은 응답이나 동점을 선택하는 판정 방식이다.
- **판정 편향**: 응답 품질 외의 순서·길이·생성 모델 정보가 평가 결과에 영향을 주는 현상이다.

</details>

- 기준표·문맥·참조 답안 기반 **판정 범위 고정**
- **점수화·쌍대 비교** 기반 대량 의미 평가
- 위치·길이·자기 선호에 따른 **판정 편향**

#### 한줄 요약
- 같은 답도 앞자리에 놓이거나 길게 쓰였다는 이유로 점수가 달라질 수 있어 순서를 바꿔 다시 채점함

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **블라인드 평가(Blind Evaluation)**: 모델 이름과 식별 정보를 숨기고 후보 순서를 무작위화하여 판정하는 방식이다.
- **인간 교정 집합**: 자동 평가의 일치도와 편향을 검증하기 위해 사람이 미리 판정한 대표 표본이다.

</details>

```mermaid
block-beta
    columns 3
    S["평가 표본"]
    R["평가 기준표"]
    B["블라인드 변환기"]
    J["LLM 판정기"]
    H["인간 교정 집합"]
    S --- R
    R --- B
    B --- J
    J --- H
```

거대 언어 모델(Large Language Model, LLM) 판정기는 기준표에 따라 점수·선호·이유를 생성한다.

| 구성요소 | 책임 |
|:---|:---|
| 평가 표본 | 질문·문맥·후보·참조 답의 **판정 입력 보관** |
| 평가 기준표 | 항목·단계·동점의 **평가 조건 정의** |
| 블라인드 변환기 | 모델 식별 제거와 **후보 순서 교환** |
| LLM 판정기 | 기준표 기반 **점수·선호·이유 생성** |
| 인간 교정 집합 | 사람 판정과의 **일치도·편향 검증** |

#### 한줄 요약
- 답안 이름과 순서를 가리고 AI가 채점한 결과를 사람이 미리 채점한 표본과 대조함

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **순서 교환 평가**: 후보의 앞뒤 위치를 바꾸어 반복 판정하고 결과의 일관성을 측정하는 절차이다.
- **인간 전환**: 자동 판정의 일치도가 낮거나 위험도가 높은 사례를 사람 평가자에게 넘기는 통제이다.

</details>

```mermaid
sequenceDiagram
    participant O as 평가·결과 책임자
    participant B as 블라인드 변환기
    participant J as LLM 판정기
    participant H as 인간 교정자
    O->>B: 1. 대표 표본·기준표 구성
    B->>J: 2. 식별 제거·후보 순서 교환
    J->>H: 3. 반복 점수·선호 판정
    H->>O: 4. 사람 판단·편향 대조
    O->>O: 5. 자동 채택·인간 전환 결정
```

거대 언어 모델(Large Language Model, LLM) 판정 결과는 순서 교환 결과 및 인간 판정과 대조한다.

1. **대표 표본·기준표 구성**: 정상·실패·고위험 사례와 **판정 조건** 정의
2. **식별 제거·후보 순서 교환**: 모델 이름·위치를 가려 **선입견 요인** 통제
3. **반복 점수·선호 판정**: 같은 표본을 순서별로 평가해 **판정 일관성** 측정
4. **사람 판단·편향 대조**: 인간 교정 집합과 일치도·불일치 유형의 **신뢰도** 검증
5. **자동 채택·인간 전환 결정**: 임계 일치도와 위험도에 따라 **최종 평가 주체** 선택

#### 한줄 요약
- 답안 자리를 바꿔도 같은 결과인지 보고 사람 채점과 어긋나는 중요한 사례는 사람에게 넘김

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **규칙 기반 평가**: 정답·형식과 명시적 조건을 기계적으로 대조하는 평가 방식이다.
- **인간 평가**: 전문가가 문맥과 위험을 고려해 응답 품질을 직접 판정하는 평가 방식이다.

</details>

거대 언어 모델(Large Language Model, LLM) 평가자는 개방형 응답의 대량 초벌 평가에 사용한다.

| 비교 기준 | 규칙 기반 평가 | LLM 평가자 | 인간 평가 |
|:---|:---|:---|:---|
| 적용 기준 | **정답·형식** 판정 | **개방형 응답** 대량 평가 | **고위험·모호 사례** |
| 핵심 특징 | 결정 규칙의 **자동 대조** | 의미 기반 **점수·선호 생성** | 전문가의 **직접 판단** |
| 한계 | **의미·맥락** 판정 한계 | **위치·자기 선호 편향** | **시간·비용·평가자 편차** |

#### 한줄 요약
- 객관식은 규칙, 서술형 초벌은 언어 모델, 애매하고 중요한 답은 사람이 채점함

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **위치 편향(Position Bias)**: 후보 내용보다 제시된 앞·뒤 순서에 따라 평가 결과가 달라지는 현상이다.
- **자기 선호 편향(Self-Preference Bias)**: 평가 모델이 자신이나 유사한 계열이 만든 응답을 더 높게 판정하는 현상이다.
- **판정 일치도**: 자동 평가와 인간 평가 또는 반복 평가 사이에서 같은 결론이 나온 비율이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 후보 순서의 **위치 편향** | **순서 교환 반복·불일치 인간 전환** | 쌍대 판정 **안정성 확보** |
| 평가 모델의 **자기 선호 편향** | **모델 식별 블라인드·이종 평가자 대조** | 생성 계열 편향 **완화** |
| 사람과 낮은 **판정 일치도** | **기준표 보정·고위험 사례 수동 판정** | 자동 평가 **적용 경계 확정** |

#### 한줄 요약
- 답안 순서와 작성 모델 이름을 숨기고 사람과 다른 판정은 자동 통과시키지 않음

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **순서 안정성**: 후보 배치를 바꾸어도 평가 결과가 일관되게 유지되는 성질이다.
- **적용 경계**: 자동 판정을 허용하고 인간 검토로 전환하는 일치도·위험도 기준이다.

</details>

- **순서 안정성·인간 일치도** 기준으로 **자동 판정·인간 전환 경계** 결정

#### 한줄 요약
- 언어 모델 채점이 자리와 모델 이름에 흔들리지 않고 사람과 맞는 범위까지만 자동화함
