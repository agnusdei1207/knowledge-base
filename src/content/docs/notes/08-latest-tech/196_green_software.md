## 미리 알고가기

- **Green Software**: Green Software는 기능과 성능뿐 아니라 에너지 사용과 탄소 배출까지 설계 목표에 포함하는 소프트웨어 접근임
- **핵심 축**: 핵심 축은 energy efficiency와 carbon awareness와 hardware efficiency임
- **측정 체계**: 단순 친환경 선언이 아니라 SCI 같은 지표로 측정하고 개선하는 운영 체계가 필요함


## Ⅰ. 개요

- **정의/개념**: 기능 단위 탄소를 줄이는 소프트웨어 공학
- **배경/필요성**: 연산·장비·실행 시점의 탄소 영향을 최적화

### 쉽게 이해하기 (학습용)

- 서비스 제공 시 계산 전기·장비를 줄이고 청정 전력을 쓸 때 실행하는 개발·운영 방식임

## Ⅱ. 특징

- 탄소 효율이 동일 기능의 배출량을 줄인다.
- 에너지 효율이 컴퓨트·저장 전력을 절감한다.
- 하드웨어 효율이 내재 탄소 배분을 줄인다.
- 탄소 인지 실행이 청정 시간·지역을 활용한다.

### 쉽게 이해하기 (학습용)

- 계산을 가볍게 하고 장비를 놀리지 않으며, 미룰 수 있는 일은 전기가 깨끗할 때 처리해 탄소를 줄임

## Ⅲ. 아키텍처 및 구성요소
```text
[기능 단위 및 측정 경계]
      │
      ├─ 에너지 효율: 코드·데이터
      ├─ 하드웨어 효율: 자원·수명
      └─ 탄소 인지: 시간·지역
      │
    [SCI·총배출·SLO 검증]
```
| 설계 요소 | 설명 |
|:---|:---|
| 측정 경계·기능 단위 | 기능당 탄소 측정 범위를 정의함 |
| 에너지 telemetry | 실행별 에너지 사용량을 수집함 |
| 코드·데이터 효율 | 연산·전송·저장 에너지를 절감함 |
| 자원·하드웨어 효율 | 이용률·수명으로 내재 탄소를 줄임 |
| 탄소 인지·검증 정책 | 시간·지역 이동 후 성과를 검증함 |
> 요약: 기능별 효율과 탄소 인지 후 성과를 검증함
### 쉽게 이해하기 (학습용)
- 원인을 분석해 전력과 장비 낭비를 개선함
## Ⅳ. 원리 및 절차 흐름도

```text
측정경계
  ↓
핫스폿
  ↓
감축조치
  ↓
재측정
  ↓
개선판정
```

| 절차 | 설명 |
|:---|:---|
| 원인 식별 | 원인 식별을 수행하고 결과를 검증함 |
| 감축 조치 | 감축 조치을 수행하고 결과를 검증함 |
| 재측정·운영 | 재측정·운영을 수행하고 결과를 검증함 |

> 요약: 기준선·핫스폿으로 감축 후 효과 재검증

### 쉽게 이해하기 (학습용)

- 같은 기준으로 원인을 찾아 처방하고 실제 수치와 서비스 품질 개선 여부를 확인함

## Ⅴ. 종류 및 비교

| 판단 기준 | Energy Efficiency | Hardware Efficiency | Carbon Awareness |
|:---|:---|:---|:---|
| 핵심 특징 | 기능당 소비 전력량 | 기능에 배분되는 장비 제조·폐기 배출 | 소비 전력의 시간·지역별 탄소 강도 |
| 적용 기준 | 연산·전송·저장·유휴 작업 축소 | 적정 크기·고활용·장비 수명 연장 | 실행 시간·지역을 유연하게 이동 |
| 주요 위험 | 성능 저하·재시도로 에너지가 늘 수 있음 | 과도한 고밀도 운영·조기 교체를 피함 | SLA·데이터 이동·예측 오차를 함께 검증함 |

> 요약: 에너지·장비 배분·탄소 강도를 함께 최적화

### 쉽게 이해하기 (학습용)

- 적은 전기로 계산하고 장비를 충분히 쓰며 더 깨끗한 전력 시간에 작업을 실행함

## Ⅵ. 실무 사례

1. 대상 환경의 도입 조건과 설계를 검증함
2. 운영 위험과 성과 지표를 검증함

### 쉽게 이해하기 (학습용)

- API 팀은 요청 1건을 기능 단위로 정하고 과도한 DB 조회·응답 필드를 줄여 에너지와 인스턴스 수를 낮춘 뒤 같은 부하에서 SCI·총 kWh·p95 지연을 비교함
- ML 플랫폼은 GPU를 right-sizing하고 유휴 종료를 적용한 뒤 deadline 안의 학습만 저탄소 시간대로 이동하며 학습 1회 SCI와 월간 총 CO2e를 함께 확인함

## Ⅶ. 결론

- 기능당 탄소와 시간·지역 유연성으로 실행 배치 결정

### 쉽게 이해하기 (학습용)

- 친환경 수치 보고를 넘어 같은 서비스를 유지하며 전기·장비·시점을 최적화해 배출을 줄여야 함
