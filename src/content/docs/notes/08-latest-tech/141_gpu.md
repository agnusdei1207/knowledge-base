## 미리 알고가기

- **GPU (Graphics Processing Unit, GPU)**: 대량 병렬 연산 프로세서로 현대 AI 학습과 추론의 표준 가속기
- **병렬 코어 구조**: 수천 개 코어와 고대역폭 메모리로 행렬 연산 처리
- **GPU 성능**: 코어 수, VRAM 용량, 대역폭과 통신 구조에 크게 좌우됨



## Ⅰ. 개요

- **정의/개념**: 워프 단위 데이터 병렬 프로세서
- **배경/필요성**: 반복 연산의 처리량·메모리 지연 개선

### 쉽게 이해하기 (학습용)

- 한 명이 복잡한 주문을 차례로 처리하기보다 많은 작업자가 같은 조리법으로 서로 다른 재료를 동시에 다루는 생산 라인과 같음

## Ⅱ. 특징

- 워프가 같은 명령으로 대량 데이터를 병렬 처리한다
- 다른 워프 실행이 메모리 대기 시간을 숨긴다
- 연속 접근·타일링이 메모리 이동을 줄인다
- 분기·과도한 자원 사용은 점유율을 낮춘다

### 쉽게 이해하기 (학습용)

- 같은 줄의 작업자는 같은 지시를 받을 때 빠르지만 서로 다른 길로 갈라지면 차례로 기다리고, 가까운 작업대에 재료를 재사용할수록 창고 왕복이 줄어듦

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 스트리밍 멀티프로세서 | 스레드·워프 배치 및 자원 할당 단위 |
| 워프 스케줄러 | 준비된 워프를 명령 발행하는 제어부 |
| 산술·텐서 유닛 | 정수·부동소수·행렬 연산 병렬 자원 |
| 메모리 계층 | 레지스터·공유 메모리·캐시 온칩 보관 |
| VRAM 제어기 | 외부 메모리 대역폭 경계 대용량 저장 |

> 요약: 워프 실행과 온칩 재사용·VRAM 접근이 성능을 정한다.

### 쉽게 이해하기 (학습용)

- 감독자인 워프 스케줄러가 일할 수 있는 조를 골라 계산대에 보내고, 가까운 선반인 공유 메모리를 잘 쓰면 먼 창고인 VRAM을 기다리는 시간이 줄어듦

## Ⅳ. 원리 및 절차 흐름도

```text
커널구성
   ↓
입력배치
   ↓
블록할당
   ↓
워프실행
   ↓
타일재사용
   ↓
결과반환
```

| 절차 | 설명 |
|:---|:---|
| 커널구성 | 데이터·자원 기반 격자·블록·스레드 결정함 |
| 입력배치 | 호스트 입력을 VRAM으로 이동함 |
| 블록할당 | 자원 요구량 기반 멀티프로세서 블록 할당함 |
| 워프실행 | 워프에 명령 발행 및 분기 경로 순차 처리함 |
| 타일재사용 | 입력 타일을 공유 메모리에 올려 재사용함 |
| 결과반환 | 블록 동기화 후 VRAM·호스트에 결과 전달함 |

> 요약: 블록·워프·메모리를 조정해 VRAM 대기를 줄인다.

### 쉽게 이해하기 (학습용)

- 작업량에 맞는 조 수를 정해 같은 길의 재료를 한꺼번에 가져오고 가까운 선반에서 재사용하며, 갈림길에서는 조가 차례로 움직이는 과정임

## Ⅴ. 종류 및 비교

| 판단 기준 | CPU | GPU | 전용 AI 가속기 |
|:---|:---|:---|:---|
| 실행 구조 | 소수의 복잡한 코어와 독립 제어 흐름 | 다수 스레드의 워프 단위 명령 실행 | 고정·특화된 텐서 데이터 흐름 |
| 적용 기준 | 분기·순차 의존·짧은 단일 작업이 많을 때 | 같은 연산을 큰 데이터 묶음에 반복할 때 | 지원 연산이 고정되고 성능 대비 전력이 우선일 때 |
| 주요 병목 | 코어 수·명령 수준 병렬성 | 메모리 대역폭·워프 분기·호스트 전송 | 연산 지원·컴파일 이식성 |

> 요약: 제어는 CPU, 병렬은 GPU, 고정 연산은 가속기다.

### 쉽게 이해하기 (학습용)

- 다양한 주문을 빠르게 판단하면 CPU, 같은 주문을 대량 처리하면 GPU, 메뉴가 고정된 초대량 생산이면 전용 가속기가 적합함

## Ⅵ. 실무 사례

1. 생성형 AI 추론의 행렬 곱 커널은 입력 타일을 공유 메모리에 올려 여러 워프가 재사용함으로써 VRAM 읽기 횟수를 줄임
2. 열 지향 분석 엔진은 반복 산술이 많은 열 배치만 GPU 커널로 보내고 분기 많은 질의 계획은 CPU에 남김

### 쉽게 이해하기 (학습용)

- 생성형 AI는 자주 쓰는 행렬 조각을 가까운 선반에 두고 반복 사용하며, 데이터 분석은 같은 계산이 많은 부분만 GPU에 맡기고 복잡한 판단은 CPU가 담당함

## Ⅶ. 결론

- 계산 절감이 전송 비용보다 클 때 GPU를 선택한다

### 쉽게 이해하기 (학습용)

- 같은 일을 많이 나눌수록 GPU가 유리하지만 갈림길과 창고 왕복이 많으면 이점이 줄어드므로, 규칙적인 작업만 맡기고 가까운 메모리를 재사용해야 함
