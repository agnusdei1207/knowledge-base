## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **그래픽 처리장치(Graphics Processing Unit, GPU)**: 동일 연산을 대량 데이터에 병렬 적용하는 프로세서이다.
- **단일 명령 다중 스레드(Single Instruction, Multiple Threads, SIMT)**: 스레드 묶음이 같은 명령을 실행하는 GPU 방식이다.
- **중앙처리장치(Central Processing Unit, CPU)**: 복잡한 제어와 순차 작업을 처리하는 범용 프로세서이다.

</details>

- 정의: SIMT로 동일 연산을 대량 데이터에 적용하는 **GPU**
- 배경/필요성: 복잡한 분기 제어와 순차 처리에 최적화된 전통적 CPU는 코어당 독립 제어부(ALU 대비 거대한 캐시 및 Control 유닛) 구조로 인해 수천 개의 동시 연산이 필요한 3D 그래픽 래스터라이제이션과 대규모 딥러닝 텐서(Tensor) 연산 처리 시 심각한 처리량(Throughput) 한계에 직면함에 따라, 수천 개의 가벼운 연산 코어가 단일 명령어를 공유하여 대량의 데이터를 병렬 처리하는 SIMT(Single Instruction, Multiple Threads / Streaming Multiprocessor: SM, Warp Scheduler, Tensor Core, Unified Memory, CUDA Architecture) 아키텍처를 도입하여 **동일 실리콘 면적 내 산술 연산기(ALU/Tensor Core) 집적도 극대화, 수십 개의 워프(Warp)를 초고속 컨텍스트 스위칭하여 메모리 지연을 완벽히 은닉(Latency Hiding), 초광폭 VRAM 대역폭(GDDR/HBM)과 공유 메모리(Shared Memory) 타일링을 통한 대규모 행렬 곱셈 처리량의 수십 배 혁신**을 달성할 필요

#### 한줄 요약

- 대량 스레드가 같은 명령을 실행하는 **SIMT 병렬 구조**

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **워프(Warp)**: 같은 명령을 함께 실행하도록 묶은 GPU 스레드의 기본 스케줄링 단위이다.
- **메모리 지연 은닉**: 한 워프가 데이터를 기다릴 때 다른 준비된 워프를 실행해 연산기 유휴를 줄이는 방식이다.

</details>

- 워프 단위 **SIMT 데이터 병렬 실행**
- 준비된 워프 교대로 **메모리 지연 은닉**
- 병합 접근•타일링으로 **VRAM 전송 감소**

#### 한줄 요약

- 분기 발산은 직렬화, **공유 메모리 재사용** 전송 절감

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **스트리밍 멀티프로세서(Streaming Multiprocessor, SM)**: 워프•연산•온칩 자원을 관리하는 실행 단위이다.
- **워프 스케줄러(Warp Scheduler)**: 같은 명령을 실행할 스레드 묶음인 워프의 준비 상태를 보고 실행 순서를 선택하는 구성요소이다.
- **산술•텐서 유닛**: 스칼라•벡터 산술과 행렬 곱셈•누산을 대량 병렬로 수행하는 연산부이다.
- **메모리 계층**: 레지스터•공유 메모리•캐시•비디오 메모리를 통해 지연과 용량이 다른 데이터 재사용 경로를 제공하는 구성요소이다.
- **비디오 메모리(Video RAM, VRAM)**: GPU가 직접 접근하는 장치 메모리이다.

</details>

```text
[GPU Architecture]
├── [실행 클러스터 계층]
│   └── [스트리밍 멀티프로세서 (SM)]
├── [스케줄링 및 파이프라인]
│   └── [워프 스케줄러 (Warp Scheduler)]
├── [연산 코어 계층]
│   └── [산술·텐서 유닛 (ALU & Tensor Core)]
└── [메모리 서브시스템 계층]
    ├── [메모리 계층 (Register/Shared/Cache)]
    └── [VRAM 제어기 (Memory Controller)]
```

- 선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 스트리밍 멀티프로세서 | **스레드•워프 배치•자원 할당** 단위 |
| 워프 스케줄러 | 준비된 워프의 **명령 발행** 제어 |
| 산술•텐서 유닛 | **정수•부동소수•행렬 연산** 병렬 처리 |
| 메모리 계층 | **레지스터•공유 메모리•캐시** 보관 |
| VRAM 제어기 | **외부 메모리 대역폭•용량** 관리 |

#### 한줄 요약

- 준비된 워프를 발행하고 **메모리 계층** 기반 지연 은닉

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **커널(Kernel)**: CPU가 GPU에 전달해 여러 스레드가 병렬 실행하는 함수이다.
- **블록(Block)**: 같은 SM에 배치되어 공유 메모리와 동기화 기능을 함께 사용하는 스레드 묶음이다.

</details>

CPU 커널 전달과 SM 실행 후 **VRAM 결과 기록** 흐름

```text
CPU 호스트 ── 커널•입력 ──▶ VRAM 제어기
                                 │ 1. 블록•데이터 전달
                                 ▼
┌──────── 워프 실행 완료까지 ────────┐
│ 워프 스케줄러 ── 2. 실행 가능 워프 전달 ──▶ 산술•텐서 유닛
│ 워프 스케줄러 ◀─ 3. 분기•메모리 대기 상태 ─ 산술•텐서 유닛
└────────────────────────────────────┘
VRAM 제어기 ◀─ 4. 연산 결과 저장 ── 산술•텐서 유닛
CPU 호스트 ◀── 연산 결과 ───────── VRAM 제어기
```

### 동작 원리

1. 블록•데이터 전달: SM 자원에 맞는 블록•타일 공급
2. 실행 가능 워프 전달: 준비된 워프의 동일 명령 발행
3. 분기•메모리 대기 상태: 다른 워프로 지연 은닉
4. 연산 결과 저장: 완료 결과를 VRAM에 기록

#### 한줄 요약

- 블록 배치 후 **워프 교대•결과 저장**으로 실행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **주문형 집적회로(Application-Specific Integrated Circuit, ASIC)**: 특정 AI 데이터 흐름을 제조할 때 고정한 전용 칩이다.

</details>

GPU•CPU•AI ASIC의 **최적화 대상** 비교

| 프로세서 | GPU | CPU | AI ASIC |
|:---|:---|:---|:---|
| 적용 기준 | **규칙적 데이터 병렬 연산** | **분기•순차 의존 작업** | **고정 AI 연산•전력 효율** |
| 핵심 특징 | **SIMT•대량 병렬 처리** | **강한 제어•낮은 단일 지연** | **고정 텐서 데이터흐름** |
| 한계 | **분기 발산•메모리 병목** | **대량 연산 처리량 제한** | **연산 지원•이식성 제한** |

> 요약: **CPU**는 제어, **GPU**는 병렬, AI ASIC는 고정 연산 중심

#### 한줄 요약

- 순차 제어는 **CPU**, 데이터 병렬은 **GPU**, 고정 연산은 ASIC

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **분기 발산**: 한 워프의 스레드가 서로 다른 제어 경로를 실행해 경로별로 직렬 처리되는 현상이다.
- **병합 접근**: 인접 스레드의 메모리 요청을 연속 전송으로 묶어 VRAM 대역폭을 효율적으로 쓰는 방법이다.

</details>

**SIMT 효율**과 VRAM 전송량의 공동 관리

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 워프 분기로 **SIMT 직렬화** 발생 | 동일 제어 흐름별 스레드•커널 분리 | 워프 **실행 효율** 향상 |
| 비병합 접근으로 **VRAM 대역폭** 낭비 | 병합 접근•공유 메모리 타일링 | 외부 메모리 **전송량 감소** |

#### 한줄 요약

- 규칙적 연산은 GPU, 복잡한 제어는 **CPU** 기반 역할 분리

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **데이터 병렬 연산**: 같은 연산을 서로 다른 데이터 원소에 동시에 적용하는 계산 방식이다.
- **순차 의존**: 앞선 연산 결과가 나와야 다음 연산을 시작할 수 있는 실행 관계이다.

</details>

- 고성능 범용 컴퓨팅(GPGPU)과 생성형 AI 혁명을 촉발한 **현대 병렬 컴퓨팅 및 딥러닝 가속의 최고 핵심 프로세서 표준(GPU / SIMT Architecture / NVIDIA Hopper & Blackwell SM / Tensor Core & Transformer Engine / Shared Memory Tiling & Coalesced Access / CUDA & Triton Ecosystem)의 확고한 표준**으로 확고히 자리 잡았으며, 트랜스포머 전용 하드웨어 엔진(FP8/FP4) 및 초고속 NVLink 패브릭과 결합되는 가운데, 실무 GPU 기반 시스템 설계 시에는 **워프 분기 발산(Divergence)을 최소화하도록 데이터 구조를 정렬하고, 전역 메모리 병합 접근(Coalesced Access)과 텐서 코어 타일링을 통해 VRAM 대역폭 효율을 극대화하며, 복잡한 비정형 제어는 CPU에, 규칙적 대규모 텐서 연산은 GPU에 위임하는 이기종(Heterogeneous) 협력 파이프라인**을 결합하여 완벽한 연산 처리량과 하드웨어 효율을 완성

#### 한줄 요약

- 분기•VRAM 병목이 낮은 **규칙적 병렬 연산** 대상 GPU 적용
