## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **그래픽 처리장치(Graphics Processing Unit, GPU)**: 동일 연산을 대량 데이터에 병렬 적용하는 프로세서 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **단일 명령 다중 스레드(Single Instruction, Multiple Threads, SIMT)**: 스레드 묶음이 같은 명령을 실행하는 GPU 방식 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **중앙처리장치(Central Processing Unit, CPU)**: 복잡한 제어와 순차 작업을 처리하는 범용 프로세서 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

- 정의: SIMT로 동일 연산을 대량 데이터에 적용하는 **GPU**이다.
- 배경/필요성: CPU의 **규칙적 행렬•벡터 처리량** 한계

#### 한줄 요약

- 대량 스레드가 같은 명령을 실행하는 **SIMT 병렬 구조**

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **워프(Warp)**: 같은 명령을 함께 실행하도록 묶은 GPU 스레드의 기본 스케줄링 단위 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **메모리 지연 은닉**: 한 워프가 데이터를 기다릴 때 다른 준비된 워프를 실행해 연산기 유휴를 줄이는 방식 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

- 워프 단위 **SIMT 데이터 병렬 실행**
- 준비된 워프 교대로 **메모리 지연 은닉**
- 병합 접근•타일링으로 **VRAM 전송 감소**

#### 한줄 요약

- 분기 발산은 직렬화, **공유 메모리 재사용**은 전송 절감

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **스트리밍 멀티프로세서(Streaming Multiprocessor, SM)**: 워프•연산•온칩 자원을 관리하는 실행 단위 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **워프 스케줄러(Warp Scheduler)**: 같은 명령을 실행할 스레드 묶음인 워프의 준비 상태를 보고 실행 순서를 선택하는 구성요소 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **산술•텐서 유닛**: 스칼라•벡터 산술과 행렬 곱셈•누산을 대량 병렬로 수행하는 연산부 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **메모리 계층**: 레지스터•공유 메모리•캐시•비디오 메모리를 통해 지연과 용량이 다른 데이터 재사용 경로를 제공하는 구성요소을  역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **비디오 메모리(Video RAM, VRAM)**: GPU가 직접 접근하는 장치 메모리 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

GPU의 SM은 VRAM에서 받은 데이터를 병렬 처리한다.

```text
             [스트리밍 멀티프로세서]
                        |
                [워프 스케줄러]
                        |
               [산술•텐서 유닛]
                        |
                  [메모리 계층]
                        |
                  [VRAM 제어기]
```

선의 의미: 스트리밍 멀티프로세서 안에서 워프 스케줄러와 산술•텐서 유닛이 실행 자원을 구성하고, 메모리 계층과 VRAM 제어기가 데이터 공급 경계를 형성한다.

| 구성요소 | 책임 |
|:---|:---|
| 스트리밍 멀티프로세서 | **스레드•워프 배치•자원 할당** 단위 |
| 워프 스케줄러 | 준비된 워프의 **명령 발행** 제어 |
| 산술•텐서 유닛 | **정수•부동소수•행렬 연산** 병렬 처리 |
| 메모리 계층 | **레지스터•공유 메모리•캐시** 보관 |
| VRAM 제어기 | **외부 메모리 대역폭•용량** 관리 |

#### 한줄 요약

- 준비된 워프를 발행하고 **메모리 계층**으로 지연 은닉

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **커널(Kernel)**: CPU가 GPU에 전달해 여러 스레드가 병렬 실행하는 함수 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **블록(Block)**: 같은 SM에 배치되어 공유 메모리와 동기화 기능을 함께 사용하는 스레드 묶음을  역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

CPU가 GPU에 커널을 전달하면 SM이 실행하고 VRAM에 결과를 기록한다.

```text
CPU 호스트 ── 커널•입력 ──▶ VRAM 제어기
                                 │ 1. 블록•데이터 전달
                                 ▼
┌──────── 워프 실행 완료까지 ────────┐
│ 워프 스케줄러 ── 2. 실행 가능 워프 전달 ──▶ 산술•텐서 유닛
│ 워프 스케줄러 ◀─ 3. 분기•메모리 대기 상태 ─ 산술•텐서 유닛
└────────────────────────────────────┘
VRAM 제어기 ◀─ 4. 연산 결과 저장 ── 산술•텐서 유닛
CPU 호스트 ◀── 연산 결과 ───────── VRAM 제어기
```

### 동작 원리

1. 블록•데이터 전달: SM 자원에 맞는 블록•타일을 공급함.
2. 실행 가능 워프 전달: 준비된 워프의 동일 명령을 발행함.
3. 분기•메모리 대기 상태 전달: 다른 워프로 지연을 은닉함.
4. 연산 결과 저장: 완료 결과를 VRAM에 기록함.

#### 한줄 요약

- 블록을 배치하고 **워프 교대•결과 저장**으로 실행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **주문형 집적회로(Application-Specific Integrated Circuit, ASIC)**: 특정 AI 데이터 흐름을 제조할 때 고정한 전용 칩 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

GPU, CPU, AI ASIC는 최적화 대상이 다르다.

| 프로세서 | GPU | CPU | AI ASIC |
|:---|:---|:---|:---|
| 적용 기준 | **규칙적 데이터 병렬 연산** | **분기•순차 의존 작업** | **고정 AI 연산•전력 효율** |
| 핵심 특징 | **SIMT•대량 병렬 처리** | **강한 제어•낮은 단일 지연** | **고정 텐서 데이터흐름** |
| 한계 | **분기 발산•메모리 병목** | **대량 연산 처리량 제한** | **연산 지원•이식성 제한** |

> 요약: 중앙처리장치는 **제어**, 그래픽 처리장치는 **병렬**, 인공지능 주문형 집적회로는 **고정 연산** 중심이 핵심이다.

#### 한줄 요약

- 순차 제어는 **CPU**, 데이터 병렬은 **GPU**, 고정 연산은 ASIC

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **분기 발산**: 한 워프의 스레드가 서로 다른 제어 경로를 실행해 경로별로 직렬 처리되는 현상 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **병합 접근**: 인접 스레드의 메모리 요청을 연속 전송으로 묶어 VRAM 대역폭을 효율적으로 쓰는 방법을  역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

SIMT 효율과 VRAM 전송량을 함께 관리한다.

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 워프 분기로 **SIMT 직렬화** 발생 | 동일 제어 흐름별 스레드•커널 분리 | 워프 **실행 효율** 향상 |
| 비병합 접근으로 **VRAM 대역폭** 낭비 | 병합 접근•공유 메모리 타일링 | 외부 메모리 **전송량 감소** |

#### 한줄 요약

- 규칙적 연산은 GPU, 복잡한 제어는 **CPU**로 역할 분리

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **데이터 병렬 연산**: 같은 연산을 서로 다른 데이터 원소에 동시에 적용하는 계산 방식 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **순차 의존**: 앞선 연산 결과가 나와야 다음 연산을 시작할 수 있는 실행 관계 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

- 규칙적 대량 병렬은 **GPU**, 분기•순차 의존은 **CPU** 선택

#### 한줄 요약

- 분기•VRAM 병목이 낮은 **규칙적 병렬 연산**에 GPU 적용
