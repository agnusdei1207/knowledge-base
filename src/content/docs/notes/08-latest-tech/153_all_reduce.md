## 미리 알고가기

- **All-Reduce**: 여러 노드의 값을 축약 연산하여 결과를 모든 노드에 배포하는 집합 통신
- **주요 용도**: 분산 학습에서 기울기(gradient) 동기화 핵심 연산으로 활용
- **성능 영향**: 알고리즘 선택과 네트워크 토폴로지가 통신 시간에 큰 영향을 미침



## Ⅰ. 개요

- **정의/개념**: 값을 축약해 모든 참여자에게 배포
- **배경/필요성**: 중앙 병목 없는 분산 결과 동기화

### 쉽게 이해하기 (학습용)

- 모든 숫자를 더한 합계를 전원에게 나누어 주는 연산

## Ⅱ. 특징

- 모든 순위의 호출 불일치는 작업을 중단시킨다
- 축약·배포 결합이 중앙 집계 병목을 없앤다
- 청크 분할이 여러 링크를 병렬 활용한다
- 순위·물리 링크 배치가 통신 성능을 좌우한다

### 쉽게 이해하기 (학습용)

- 배치 방식(원형/트리)에 따라 전달 횟수와 통로 활용도가 달라짐

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 역할과 설계 기준 |
|:---|:---|
| 참여 순위·통신자 | 참여 순위의 개수·자료형·호출 순서를 맞춤 |
| 축약 연산자 | 축약 연산의 정밀도·오버플로를 검토함 |
| 청크·버킷 | 청크·버킷으로 지연·대역폭을 조절함 |
| 집합 통신 알고리즘 | 크기·참여 수에 맞춰 링·트리를 고름 |
| 토폴로지 매핑 | 링크 대역폭에 맞춰 순위·경계를 배치함 |

```text
링:   [R0] → [R1] → [R2] → [R3] ┐
       ↑                         │
       └─────────────────────────┘

트리:             [R0]
                 /    \
              [R1]    [R2]
                       /
                    [R3]
```

> 요약: 청크·알고리즘·순위와 토폴로지 정합이 성능을 정한다.

### 쉽게 이해하기 (학습용)

- 짐을 나누고 빠른 길에 사람을 세우는 방식에 따라 완료 시간 결정

## Ⅳ. 원리 및 절차 흐름도

조건확인 → 청크분할 → 알고리즘선택 → 축약수행 → 결과배포 → 완료통지

| 절차 | 설명 |
|:---|:---|
| 1. 참여 조건 확인 | 순위별 원소·자료형·연산 일치를 확인함 |
| 2. 청크 분할 | 청크·버킷으로 지연·링크 사용을 조절함 |
| 3. 알고리즘 선택 | 크기·순위·링크에 맞춰 경로를 선택함 |
| 4. 축약 수행 | 링은 순환, 트리는 상향 축약함 |
| 5. 결과 배포 | 링은 순환, 트리는 하향 배포함 |
| 6. 완료 통지 | 순위별 수신 결과가 같으면 완료함 |

> 요약: 링은 큰 메시지에 효율적이나 순위별 단계가 늘어난다.

### 쉽게 이해하기 (학습용)

- 링 방식은 짐을 나눠 한 바퀴 돌며 합치고 분산하여 통로를 계속 활용함

## Ⅴ. 종류 및 비교

| 판단 기준 | 링 | 트리 | 계층형 |
|:---|:---|:---|:---|
| 실행 단계 | 두 단계를 각각 $p-1$회 수행함 | 축약과 배포를 각각 트리 높이에 따라 수행함 | 노드 내부 축약·노드 간 축약·노드 내부 배포로 나눔 |
| 적용 기준 | 큰 메시지에서 모든 링크 대역폭을 지속 활용함 | 작은 메시지에서 단계 지연을 줄임 | 노드 내부와 외부의 링크 속도 차이가 클 때 적용함 |
| 주요 병목 | 순위 증가에 따라 단계 수와 느린 링크 영향이 커짐 | 상위 링크의 집중과 비대칭 토폴로지에 민감함 | 계층 경계와 순위 배치를 잘못 잡으면 전환 비용이 커짐 |

> 요약: 대형은 링, 소형은 트리, 다중 노드는 계층형이다.

### 쉽게 이해하기 (학습용)

- 메시지 크기에 맞춰 링/트리/계층형 중 최적화된 방식을 선택함

## Ⅵ. 실무 사례

### 사례 1. 데이터 병렬 학습의 기울기 버킷 동기화

- **상황**: 역전파 뒤 통신하면 단계 지연이 늘어난다
- **적용**: 버킷 통신을 역전파와 중첩한다
- **검증**: 중첩률·단계 시간으로 병목을 찾는다

### 사례 2. 분산 기울기 전역 노름 계산

- **상황**: 로컬 기울기만으로 전역 노름은 모른다
- **적용**: 제곱합을 축약해 전역 노름을 구한다
- **검증**: 순위별 노름·클리핑 일치를 확인한다

### 쉽게 이해하기 (학습용)

- 큰 기울기는 버킷으로 묶어 효율화하고 작은 통계는 빠른 방식으로 공유함

## Ⅶ. 결론

- **알고리즘**: 구간별 측정을 통해 트리·계층형과 전환 지점을 정함
- **순위 배치**: 느린 링크 반복 통과를 막도록 물리 토폴로지와 매핑
- **수치 일관성**: 부동소수점 덧셈 재현성을 위해 순서 고정
- **결론**: 청크·토폴로지가 통신 효율을 정한다

### 쉽게 이해하기 (학습용)

- 짐 크기와 통로 구조에 맞는 전달 순서와 배치 설계 필요
