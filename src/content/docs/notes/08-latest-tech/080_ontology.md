## 미리 알고가기

- **온톨로지 (Ontology)**: 도메인 개념·관계·제약을 명세함
- **개념 계층 (Concept Hierarchy)**: 상위·하위 개념 관계를 정의함
- **공리 (Axiom)**: 추론 및 모순 판정에 사용하는 논리 규칙임
- **일관성 검사 (Consistency Check)**: 규칙 간 모순을 탐지함



## Ⅰ. 개요

- **정의/개념**: 도메인 개념·관계·제약·공리를 명세
- **배경/필요성**: 시스템 간 용어와 의미 해석의 불일치 해소

### 쉽게 이해하기 (학습용)

- 여러 시스템이 용어와 관계의 뜻을 동일하게 해석하도록 만든 공용 설계도입니다.

## Ⅱ. 특징

- 개념의 상하위 관계와 하위 개념의 속성 상속을 정의한다.
- 관계의 의미·정의역·치역과 제약 조건을 명시한다.
- 사실과 공리로 암묵적 분류와 일관성을 추론한다.
- 표현력이 높을수록 추론과 변경 영향 분석 비용이 커진다.

### 쉽게 이해하기 (학습용)

- 자세한 규칙은 숨은 분류와 모순을 찾지만 잘못된 사실도 추론에 전파됩니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 핵심 키워드 | 직관적 설명 |
|:---|:---|:---|
| 개념 | 범주 분류 | 도메인의 대상을 정의함 |
| 계층 | 포함 관계 | 상·하위 체계임 |
| 관계 | 연결 명세 | 개념 간 허용범위임 |
| 제약 | 자료 제한 | 데이터의 형식 제한임 |
| 공리 | 추론 규칙 | 논리 판단 기준임 |

```text
온톨로지
├─ 개념개체
├─ 개념계층
├─ 속성관계
├─ 허용제약
└─ 추론공리
```

### 쉽게 이해하기 (학습용)

- 개념·계층·관계·제약·공리가 공유 의미 체계를 구성합니다.

## Ⅳ. 원리 및 절차 흐름도

```text
용어합의
↓
구조모형
↓
규칙명세
↓
추론검사
↓
버전확정
```

| 절차 | 설명 |
|:---|:---|
| 용어합의 | 대상 범위를 확정함 |
| 구조모형 | 계층·관계 정의함 |
| 규칙명세 | 제약·공리 명시함 |
| 추론검사 | 모순 여부 확인함 |
| 버전확정 | 데이터 영향 검토함 |

### 쉽게 이해하기 (학습용)

- 용어·관계·공리를 명세하고 추론 결과와 논리적 모순을 검사합니다.

## Ⅴ. 종류 및 비교

| 판단 기준 | 분류체계 | 온톨로지 | 지식그래프 |
|:---|:---|:---|:---|
| 표현 중심 | 상·하위 용어 | 개념·제약·공리 | 실제 개체·사실 |
| 적용 기준 | 분류 계층 필요 | 공유 의미·추론 | 경로 탐색 중심 |
| 주요 위험 | 관계 표현 한계 | 합의·추론 비용 | 정보 연결 오류 |

> 요약: 모델별 표현 중심과 적용 범위의 차이임

### 쉽게 이해하기 (학습용)

- 분류체계·온톨로지·지식그래프는 표현 깊이와 활용 목적이 다릅니다.

## Ⅵ. 실무 사례

- 서버·서비스·조직의 공통 개념으로 자산 의미 통일
- 의무·대상·예외 공리를 명세하고 원문과 대조

### 쉽게 이해하기 (학습용)

- 공통 개념과 관계로 자산 의미를 통일하고 자동 추론은 원문 규정과 대조합니다.

## Ⅶ. 결론

- 공유 의미와 추론 범위에 적용하고 일관성을 관리함

### 쉽게 이해하기 (학습용)

- 과도한 규칙과 잘못된 사실은 유지보수 비용과 추론 오류를 함께 키웁니다.
