## 미리 알고가기

- **데이터 병렬**: 동일 모델을 여러 장치에 복제하고 입력 배치를 분할하여 학습하는 방식
- **특징**: 구현이 단순하고 확장성이 좋아 가장 기본적인 분산 학습 방식으로 활용
- **핵심 과제**: 기울기(gradient) 동기화 비용 최소화와 전역 배치 크기 변화에 따른 최적화
- **ZeRO (Zero Redundancy Optimizer)**: 모델 상태를 단계별로 분할하여 복제본 메모리 사용량을 줄이는 기법



## Ⅰ. 개요

- 정의/개념: 모델 복제·배치 분할 병렬 학습
- **배경/필요성**: 단일 장치만으로 대규모 학습 데이터의 단계 처리량과 학습 시간 요구 충족 곤란

### 쉽게 이해하기 (학습용)

- 문제집과 풀이법을 공유하고 각자 문제를 푼 뒤 풀이 방향을 평균 내어 다 같이 수정하는 방식

## Ⅱ. 특징

- 모델 복제·배치 분할 기반 **표본 병렬 처리**
- All-Reduce 기반 **기울기 전역 동기화**
- 전역 배치·상태 복제 기반 **수렴·메모리 한계**

### 쉽게 이해하기 (학습용)

- 복제본 수를 늘리면 한 번에 보는 전체 데이터가 늘어나 학습 성격이 변화함

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 역할과 설계 기준 |
|:---|:---|
| 모델·최적화 상태 복제본 | 모델·상태가 장치 메모리에 들어가야 함 |
| 분산 데이터 샘플러 | 시드 규칙으로 누락·중복·편향을 막음 |
| 로컬 학습 실행기 | 로컬 순전파·역전파로 기울기를 만듦 |
| 기울기 동기화기 | 기울기를 축약·평균해 갱신값을 만듦 |
| 전역 단계 제어기 | 배치·학습률·체크포인트를 전역 관리함 |

```text
                [전역 배치]
              /      |      \
          [배치 0] [배치 1] [배치 2]
             ↓       ↓       ↓
          [모델 A] [모델 B] [모델 C]
             \       |       /
              [기울기 All-Reduce]
                       ↓
                [동일 파라미터]
```

> 요약: 초기화·입력 분할·집단 통신 순서가 동기화를 좌우한다.

### 쉽게 이해하기 (학습용)

- 복사본이 같은 책으로 시작해도 문제 배분이나 답안 평균이 다르면 결국 다른 책이 됨

## Ⅳ. 원리 및 절차 흐름도

배치결정 → 모델복제/분할 → 로컬계산 → 기울기동기화 → 최적화갱신

| 절차 | 설명 |
|:---|:---|
| 1. 전역 배치 설계 | 전역 배치·학습률·단계 기준을 고정함 |
| 2. 상태 복제 | 같은 체크포인트로 시작 상태를 맞춤 |
| 3. 배치 분할 | 전역 배치를 중복 없는 로컬 배치로 나눔 |
| 4. 로컬 계산 | 로컬 역전파 후 기울기를 누적함 |
| 5. 기울기 동기화 | 기울기를 축약해 전역 평균을 만듦 |
| 6. 파라미터 갱신 | 같은 기울기·상태로 다음 배치를 처리함 |

> 요약: 처리량·배치 확장 실험을 나눠 수렴성을 검증한다.

### 쉽게 이해하기 (학습용)

- 장치 수 증가와 배치 크기 증가를 구분해야 속도 향상과 학습 변화의 원인을 정확히 규명함

## Ⅴ. 분산 학습 병렬화 비교

| 구분 | 데이터 병렬 | 텐서 병렬 | 파이프라인 병렬 |
|:---|:---|:---|:---|
| 분할 대상 | 입력 배치를 나누고 모델을 복제함 | 한 계층의 텐서 연산과 파라미터를 나눔 | 연속된 모델 계층을 단계별로 나눔 |
| 적용 기준 | 모델 복제 가능·배치 큼 | 단일 연산이 장치 초과 | 계층 묶음 분할 가능 |
| 핵심 특징 | 배치 분할·기울기 동기화 | 텐서 축 분할·부분 합산 | 단계 분할·마이크로배치 |
| 한계 | 모델 상태 복제·통신 | 연산마다 빈번한 통신 | 파이프라인 버블·스케줄 |
| 주요 통신 | 단계마다 복제본 간 기울기를 동기화함 | 계층 연산 중 부분 결과를 집합 통신함 | 단계 경계에서 활성값과 기울기를 점대점 전송함 |

> 요약: 데이터·텐서·파이프라인은 분할 축이 다르다.

### 쉽게 이해하기 (학습용)

- 문제를 나누고, 한 계산을 나누며, 풀이 단계를 나누는 병렬화의 차이

## Ⅵ. 실무 사례

### 사례 1. 이미지 분류 학습의 GPU 확장

- **상황**: GPU 증가는 전역 배치·수렴을 바꾼다
- **적용**: 전역 배치를 고정해 확장성을 측정한다
- **검증**: 처리량·손실·정확도를 함께 비교한다

### 사례 2. 모델이 장치에 들어가는 언어 모델 사전학습

- **상황**: 작은 배치는 통신 비중을 높인다
- **적용**: 누적 마지막에만 기울기를 동기화한다
- **검증**: 단계 시간·손실로 성능·수렴을 확인한다

### 쉽게 이해하기 (학습용)

- GPU 수 증가와 데이터 전역 배치 변화에 따른 학습 정확도 영향 관리 필요

## Ⅶ. 결론

- **메모리**: 상태가 크면 다른 병렬화를 결합한다
- **통신**: 버킷화·중첩으로 단계 지연을 줄인다
- **배치**: 전역 배치·갱신 횟수를 다시 계산한다
- **결론**: 처리량과 수렴을 분리 검증한다

### 쉽게 이해하기 (학습용)

- 여러 장치의 빠른 계산과 모든 복제본의 동일한 모델 수렴을 동시에 달성함
