## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **데이터 병렬화(Data Parallelism)**: 동일한 모델을 여러 연산 장치에 복제하고, 분할된 데이터 배치(Batch)를 각 장치가 병렬 처리한 뒤, 계산된 기울기(Gradient)를 전역적으로 동기화하여 학습하는 방식.
- **전역 배치(Global Batch)**: 전체 학습 시스템이 한 번의 파라미터 갱신 단계를 위해 처리하는 전체 데이터 샘플의 총개수.

</details>

- 정의: 모델을 복제하고 배치 분할•기울기 동기화하는 **데이터 병렬화**이다.
- 배경/필요성: 수십 테라바이트 이상의 대규모 데이터셋으로 딥러닝 모델을 학습할 때, 단일 GPU/서버는 한 번에 처리할 수 있는 미니배치(Mini-batch) 크기가 제한되어 전체 에포크(Epoch)를 순회하는 데 수개월 이상의 막대한 학습 시간이 소요되는 치명적인 처리량 한계에 직면함에 따라, 전체 모델 파라미터와 옵티마이저 상태를 각 연산 장치에 복제하고 전체 학습 데이터를 중복 없이 나누어(Shard) 병렬로 순전파/역전파를 수행한 뒤 그래디언트를 동기화하는 데이터 병렬화(Data Parallelism: DDP / Distributed Data Parallel, All-Reduce Gradient Synchronization, Zero Redundancy Optimizer: ZeRO-1/2/3, FSDP: Fully Sharded Data Parallel, Gradient Accumulation) 아키텍처를 도입하여 **학습 연산 시간을 GPU 장치 수에 반비례하여 획기적으로 단축(선형적 처리량 스케일아웃), 역전파 연산과 All-Reduce 통신을 완벽히 오버랩(Overlap)하는 비동기 버케팅 최적화, ZeRO/FSDP를 통한 옵티마이저/그래디언트/파라미터 분할 적재로 단일 GPU 메모리 용량 한계를 극복하는 고효율 분산 메모리 학습**을 달성할 필요

#### 한줄 요약
- 데이터 병렬은 계산 시간을 장치 수로 나누는 대신 반복마다 **기울기 평균** 통신을 새 비용으로 떠안으므로, 장치 증설의 효과는 통신이 계산에 가려지는 지점까지만 유지된다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **로컬 배치(Local Batch)**: 단일 연산 장치가 한 번의 학습 단계에서 처리하는 개별 데이터 샘플 개수.
- **올리듀스(All-Reduce)**: 모든 연산 장치의 기울기를 특정 연산으로 축약하고 그 결과를 모든 장치에 배포하여 동기화하는 집단 통신 방식.

</details>

- 모델 복제•로컬 배치 기반 **표본 병렬 처리**
- All-Reduce 기반 **기울기 전역 평균**
- 장치 증가에 따른 **처리량•전역 배치•통신 증가**

#### 한줄 요약
- 장치를 늘리면 통신량뿐 아니라 **전역 배치**가 함께 커져 학습률과 수렴 특성까지 바뀌므로, 데이터 병렬의 확장 한계는 하드웨어보다 학습 품질이 먼저 정한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **분산 데이터 샘플러(Distributed Data Sampler)**: 여러 장치에 데이터가 중복되거나 누락되지 않도록 전체 데이터를 고유한 인덱스로 나누어 배정하는 모듈.
- **모델/상태 복제본(Model/State Replica)**: 각 장치가 보유하는 동일한 파라미터와 옵티마이저 학습 상태 또는 ZeRO 기법에 의해 분할 보관되는 실행 단위.
- **로컬 학습기(Local Learner)**: 장치별로 할당된 로컬 배치에 대해 순전파(Forward) 및 역전파(Backward)를 수행하여 기울기를 산출하는 연산 엔진.
- **기울기 동기화기(Gradient Synchronizer)**: All-Reduce 등의 집단 통신을 통해 각 장치의 로컬 기울기를 합산하여 전역 평균 기울기를 생성하는 통신 인터페이스.
- **ZeRO(Zero Redundancy Optimizer)**: 복제된 모델 파라미터, 기울기, 옵티마이저 상태를 여러 연산 장치 사이에 분할 저장하여 메모리 중복을 제거하는 최적화 기법.

</details>

```text
[데이터 병렬화 아키텍처]
├── [전역 제어 계층]
│   └── [전역 단계 제어기]
├── [모델 및 데이터 관리]
│   ├── [모델•상태 복제본]
│   └── [분산 데이터 샘플러]
└── [로컬 연산 및 동기화]
    ├── [로컬 학습기]
    └── [기울기 동기화기]
```

- 선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.
| 구성요소 | 책임 |
|:---|:---|
| 모델•상태 복제본 | **상태 복제•ZeRO 분할** 기반 보관 |
| 분산 데이터 샘플러 | 표본의 **중복•누락 없는 배치 분할** |
| 로컬 학습기 | 로컬 배치의 **순전파•역전파 계산** |
| 기울기 동기화기 | 올리듀스 기반 **전역 평균 기울기 생성** |
| 전역 단계 제어기 | 배치•학습률•체크포인트의 **공동 단계 관리** |

#### 한줄 요약
- 표본을 중복 없이 나누고 **전역 평균 기울기** 기반 상태 일치

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **순전파•역전파(Forward•Backward Propagation)**: 입력으로 예측을 계산하고 오차 기울기를 반대 방향으로 전달하는 학습 연산이다.
- **전역 평균 기울기**: 모든 장치의 로컬 기울기를 합산한 뒤 참여 장치 수로 나눈 공동 갱신값을 말한다.

</details>

```text
┌──────────── 학습 종료 조건까지 ────────────┐
│ 전역 모델•단계 제어기 ── 1. 전역 배치•학습률 설정 ──▶ 데이터 샘플러
│ 데이터 샘플러 ── 2. 중복 없는 로컬 배치 분할 ──▶ 로컬 학습기
│ 로컬 학습기 ── 3. 로컬 순전파•역전파 ──▶ 기울기 동기화기
│ 전역 모델•단계 제어기 ◀─ 4. 기울기 축약•전역 평균 ─ 기울기 동기화기
│ 전역 모델•단계 제어기 ── 5. 동일 파라미터 갱신 ──▶ 모델 복제본
└────────────────────────────────────────────┘
```

### 동작 원리

1. 전역 배치•학습률 설정: 장치 수•로컬 배치별 **최적화 조건** 고정
2. 중복 없는 로컬 배치 분할: 표본의 장치별 **독립 입력 조각** 배정
3. 로컬 순전파•역전파: 복제본별 로컬 데이터의 **기울기** 계산
4. 기울기 축약•전역 평균: 모든 장치 기울기의 **공동 갱신값** 생성
5. 동일 파라미터 갱신: 복제본의 동일 상태와 **다음 단계** 준비

#### 한줄 요약
- 로컬 기울기를 평균 내어 **모델 복제본** 동일 갱신

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **텐서 병렬화(Tensor Parallelism)**: 하나의 계층 안에서 텐서 연산과 파라미터를 여러 장치에 나누는 방식이다.
- **파이프라인 병렬화(Pipeline Parallelism)**: 연속 모델 층을 여러 장치 단계에 나누고 중간값을 전달하는 방식을 의미한다.
- **마이크로배치(Microbatch)**: 파이프라인 단계를 겹쳐 실행하도록 하나의 배치를 더 작게 나눈 단위이다.

</details>

| 구분 | 데이터 병렬 | 텐서 병렬 | 파이프라인 병렬 |
|:---|:---|:---|:---|
| 적용 기준 | **모델 복제 가능•큰 배치** | **단일 연산이 장치 초과** | **계층 묶음 분할 가능** |
| 핵심 특징 | 배치 분할•**기울기 동기화** | 텐서 축 분할•**부분 합산** | 단계 분할•**마이크로배치** |
| 한계 | **상태 복제•전역 통신** | **연산별 빈번한 통신** | **파이프라인 버블•불균형** |

#### 한줄 요약
- 세 병렬화는 모두 단일 장치 한계를 나누는 같은 해법이며, 부족한 것이 시간이면 배치를 메모리면 텐서•계층을 가르는 식으로 **분할 대상**이 갈린다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **확장 효율**: 장치 증가에 따른 이상적인 처리량 향상 대비 실제 처리량 향상의 비율을 의미한다.
- **학습률 재조정**: 전역 배치 변화에 맞춰 파라미터 갱신 크기와 스케줄을 다시 설정하는 절차이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 장치 증가의 **전역 배치 과대화** | **배치 고정 시험•학습률 재조정** | 수렴 변화 **분리 검증** |
| 샘플러 오류의 **표본 중복•누락** | **장치•단계별 표본 인덱스** 검증 | 학습 데이터 **정합성 확보** |
| 기울기 동기화의 **단계 시간 병목** | **버킷 통신•역전파 중첩•토폴로지** 배치 | 확장 효율 **향상** |

#### 한줄 요약
- 전역 배치를 통제하고 **샘플러•통신 병목** 분리 검증

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **모델 복제**: 같은 파라미터와 학습 상태를 여러 장치에 각각 적재하는 배치 방식을 말한다.
- **기울기 동기화**: 장치별 계산 결과를 합쳐 모든 모델 복제본을 같은 파라미터로 갱신하는 과정이다.

</details>

- 딥러닝 분산 학습에서 가장 기본적이고 높은 계산 효율(MFU)을 제공하며 수천 개 GPU 클러스터로 확장되는 **분산 AI 훈련의 절대적 기초 및 핵심 스케일아웃 표준(Data Parallelism / PyTorch DDP & FSDP / DeepSpeed ZeRO-Stage 1,2,3 / All-Reduce Gradient Synchronization / Gradient Accumulation & Linear Scaling Rule)의 확고한 표준**으로 확고히 자리 잡았으며, 거대 LLM 학습을 위해 3D 병렬화(TP, PP, DP) 및 FSDP로 융합 발전하는 가운데, 실무 대규모 분산 훈련 설계 시에는 **메모리 절감이 필요한 경우 FSDP(ZeRO-3)를 채택하고, GPU 증가에 따른 전역 배치(Global Batch) 크기 확대 시 선형 학습률 스케일링(Linear LR Warmup)을 적용하며, NCCL 그래디언트 버킷 튜닝을 통해 계산-통신 중첩률을 90% 이상 확보**를 결합하여 완벽한 분산 훈련 수렴 안정성과 최상의 하드웨어 가동률을 완성

#### 한줄 요약
- 데이터 병렬은 메모리가 아니라 시간이 병목일 때의 해법이므로, 전역 배치가 수렴을 해치지 않고 통신이 계산에 가려지는 범위 안에서 **데이터 병렬 확장 규모**를 정한다.
