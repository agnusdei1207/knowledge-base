## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **추적 식별자(Trace Identifier, Trace ID)**: 하나의 전체 분산 요청을 식별하는 값이다.
- **분산 추적(Distributed Tracing)**: Trace ID와 스팬의 부모•자식 관계로 종단 간 호출 경로와 지연을 재구성하는 관측 기법이다.
- **트레이스(Trace)**: 하나의 전체 요청을 구성하는 스팬 집합이다.

</details>

- 정의/개념: Trace ID와 스팬의 부모•자식 관계를 연결하여 분산 요청의 종단 간 인과 경로와 구간별 지연을 재구성하는 **분산 추적 기법**이다.
- 배경/필요성: 서비스별 로그만으로는 **서비스 간 호출 관계•병목 구간** 식별이 어렵다.

#### 한줄 요약

- 하나의 요청 번호로 여러 서비스의 처리 순서와 시간을 연결해 지연•오류 발생 구간을 찾는 방식이다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **스팬 식별자(Span Identifier, Span ID)**: 추적 안의 개별 연산을 식별하는 값이다.
- **스팬 컨텍스트(Span Context)**: 추적 식별자•스팬 식별자•표본화 정보 등 서비스 경계로 전파할 추적 문맥이다.

</details>

- Trace ID•Span ID와 부모 관계 기반 **분산 연산 인과관계**가 핵심이다.
- 동기•비동기 경계의 컨텍스트 전파 기반 **요청 경로 연속성**이 핵심이다.
- 샘플링•배기지 정책 기반 **수집 비용•민감정보 통제**가 핵심이다.
#### 한줄 요약

- 같은 요청 번호를 끊기지 않게 전달하되 기록 비용과 함께 전달할 업무 정보의 보안도 통제한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **스팬(Span)**: 요청 경로에서 개별 연산의 시작•종료•상태•속성을 기록한 단위이다.
- **스팬 생성기**: 개별 연산의 시작•종료•상태•속성을 계측하는 구성요소이다.
- **스팬 컨텍스트 전파**: Trace ID•Span ID•샘플링 상태로 부모•자식 인과관계를 이어 주는 개념이다.
- **문맥 전파기**: 하이퍼텍스트 전송 프로토콜(Hypertext Transfer Protocol, HTTP) 헤더•메시지 속성에 추적 문맥을 주입하고 피호출 측에서 추출하는 구성요소이다.
- **수집기**: 서비스가 내보낸 스팬을 수신•가공하여 추적 처리 경로로 전달하는 구성요소이다.
- **샘플러**: 정책에 따라 보존할 추적을 선별하는 개념이다.
- **추적 백엔드(Trace Backend)**: 스팬을 추적 단위로 조립•저장•검색하고 임계 경로와 오류 구간을 분석하는 개념이다.

</details>

Trace ID와 Span ID를 부모•자식 관계로 보존한다.

```text
                       [스팬 컨텍스트]
                         /          \
                  [스팬 생성기]   [문맥 전파기]
                         \          /
                           [수집기]
                              |
                           [샘플러]
                              |
                       [추적 백엔드]
```
선의 의미: 스팬 컨텍스트는 스팬 생성기와 문맥 전파기가 공유하는 Trace ID•Span ID•표본화 계약이고, 수집기와 샘플러는 이 관계를 보존한 스팬을 추적 백엔드의 경로 재구성 경계에 연결한다.

| 구성요소 | 책임 |
|:---|:---|
| 스팬 생성기 | **연산 시작•종료•상태•속성 계측** |
| 스팬 컨텍스트 | **Trace ID•Span ID•표본화 정보 보존** |
| 문맥 전파기 | 통신 매체의 **컨텍스트 주입•추출** |
| 수집기 | **스팬 수집•가공•전송** |
| 샘플러 | **보존 추적 선별** |
| 추적 백엔드 | 부모 관계 기반 **경로 재구성•지연 분석** |

#### 한줄 요약

- 각 거점이 같은 운송장 문맥으로 기록을 남기면 중앙에서 지연 구간을 찾을 수 있다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **부모•자식 관계**: 호출한 스팬과 피호출 스팬의 인과 순서를 연결하는 관계이다.
- **임계경로**: 전체 요청 완료 시간을 결정하는 가장 긴 의존 연산 경로이다.

</details>

```text
호출 서비스
   │ 1. 스팬 컨텍스트 전달
   ▼
문맥 전파기
   │ 2. 추적 문맥 전달
   ▼
피호출 서비스 ── 3. 자식 스팬 전달 ─┐
호출 서비스 ── 4. 부모 스팬 전달 ───┤
                                      ▼
                                수집기•샘플러
                                      │ 5. 선별 스팬 전달
                                      ▼
                                  추적 백엔드
```

**동작 원리**

- **1. 스팬 컨텍스트 전달**: 호출 연산의 Trace ID•Span ID•표본화 결정을 생성한다.
- **2. 추적 문맥 전달**: HTTP 헤더•메시지 속성 기반 부모 문맥 주입•추출이다.
- **3. 자식 스팬 전달**: 피호출 연산의 부모 관계•시간•상태 계측이다.
- **4. 부모 스팬 전달**: 호출 연산 완료 시 스팬 속성•이벤트 확정이다.
- **5. 선별 스팬 전달**: 샘플링 후 부모•자식 관계와 임계경로 재구성한다.

#### 한줄 요약

- 운송장 번호를 이어 쓰고 각 거점의 시간을 순서대로 연결해 지연 지점을 찾는다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **헤드 샘플링**: 요청이 시작될 때 트레이스 저장 여부를 결정하는 방식이다.
- **테일 샘플링**: 트레이스가 끝난 뒤 오류•고지연 등 전체 결과를 보고 저장 여부를 결정하는 방식이다.

</details>

| 샘플링 방식 | 전량 수집 | 헤드 샘플링 | 테일 샘플링 |
|:---|:---|:---|:---|
| 적용 기준 | **저트래픽•전체 감사** | 시작 시 **저비용 선별** | **오류•고지연 우선 보존** |
| 핵심 특징 | **모든 스팬** 저장 | **요청 시작 시** 결정 | **트레이스 완료 후** 결정 |
| 한계 | **저장•처리 비용** 증가 | **후발 오류 누락**가능 | **버퍼•결정 지연 비용** |

#### 한줄 요약

- 모든 영상을 보관하거나, 촬영 전에 일부만 고르거나, 촬영 뒤 사고 장면을 우선 보관하는 차이다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **배기지(Baggage)**: 서비스 사이에 추적 문맥과 함께 전파하는 업무 정보이다.
- **고카디널리티(High Cardinality)**: 속성값의 종류가 지나치게 많아 저장•색인 비용을 높이는 특성이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **문맥 단절** 미검증 시 비동기•외부 호출의 **부모 관계 유실** | 표준 전파 형식과 경계별 **주입•추출 검사** | **부모-자식 추적 연속성** 확보 |
| **수집 비용** 미검증 시 고트래픽의 **저장•처리량 급증** | 헤드•테일 **샘플링 정책과 보존 등급** | **저장•처리 비용** 제한 |
| **배기지•속성** 미검증 시 민감정보 유출•**고카디널리티** | 허용 목록•크기 제한•**민감정보 제거** | 민감정보 노출•**질의 폭증** 억제 |

#### 한줄 요약

- 요청 경계의 문맥 전파를 검증하고, 오류•고지연 트레이스를 우선 보존하며, 민감한 속성은 수집 전에 제거한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **추적 연속성**: 비동기•외부 호출 경계를 지나도 같은 요청의 부모•자식 관계가 끊기지 않는 성질이다.
- **샘플링 예산**: 비용 한도 안에서 보존할 트레이스의 비율과 우선순위를 정한 기준이다.

</details>

- **추적 연속성•샘플링 예산**을 지키며 오류•고지연 추적 우선 저장이 핵심이다.

#### 한줄 요약

- 요청 번호를 끊김 없이 전달하고 필요한 추적을 비용 범위 안에서 보존해야 한다.
