## 미리 알고가기

- **분산 추적**: 하나의 요청이 여러 서비스를 지나는 경로를 연결해 인과관계와 지연을 관측함
- **trace**: 연관된 span들의 집합으로 하나의 전체 작업 경로를 식별함
- **샘플링**: 비용 절감과 분석 정확도를 고려해 추적할 데이터를 선별함



## Ⅰ. 개요

- **정의/개념**: 요청 경로를 trace와 span으로 연결해 분석
- **배경/필요성**: 분산 호출의 인과관계와 병목을 가시화

### 쉽게 이해하기 (학습용)

- 택배 여정을 운송장으로 묶고 거점별 시간을 기록해 전체 경로를 확인함

## Ⅱ. 특징

- trace ID가 분산된 span의 인과관계를 잇는다.
- 문맥 전파가 서비스 간 하위 span을 연결한다.
- baggage 통제가 업무 문맥 유출을 막는다.
- 표본화가 분석 가치와 저장 비용을 조절한다.

### 쉽게 이해하기 (학습용)

- 운송장 번호가 이어져야 경로가 연결되며, 개인정보 유출 방지와 사고 기록 누락 방지 설계가 필요함

## Ⅲ. 아키텍처 및 구성요소

```text
요청
  ↓
서비스A(생성)
  ↓
서비스B(전파)
  ↓
추적 저장소
```

| 설계 요소 | 설명 |
|:---|:---|
| 계측·span 생성기 | 연산의 상태·속성을 기록함 |
| span context | trace·span ID로 관계 식별함 |
| propagator | carrier로 문맥 전파함 |
| baggage 정책 | 업무 문맥·보안 관리함 |
| 수집기·sampler | span 가공·표본화함 |
| 추적 backend | 저장·지연 분석함 |

> 요약: 계측과 전파로 추적 데이터를 수집해 저장 및 분석함

### 쉽게 이해하기 (학습용)

- 거점마다 기록을 남기고 중앙에서 지연 구간을 찾는 구조임

## Ⅳ. 원리 및 절차 흐름도

```text
추출생성
   ↓
시작계측
   ↓
주입전파
   ↓
수집샘플
   ↓
경로분석
```

| 절차 | 설명 |
|:---|:---|
| 추출생성 | 인바운드에서 문맥 추출 또는 생성함 |
| 시작계측 | 연산 시작·종료 및 속성 기록함 |
| 주입전파 | carrier에 문맥 주입 및 전달함 |
| 수집샘플 | span 전송 및 정책별 선별함 |
| 경로분석 | trace 경로 재구성 및 지연 분석함 |

> 요약: 추적 문맥 전파로 요청 경로와 병목을 재구성함

### 쉽게 이해하기 (학습용)

- 운송장 번호를 이어 쓰고 시간순으로 병목 구간을 확인함

## Ⅴ. 종류 및 비교

| 판단 기준 | 전량 수집 | 헤드 샘플링 | 테일 샘플링 |
|:---|:---|:---|:---|
| 핵심 특징 | 요청 시작 시 | 요청 시작 시 | 요청 완료 후 |
| 적용 기준 | 높음 | 낮음 | 중간 |
| 주요 위험 | 전체 감사 | 일반 성능 | 오류·고지연 |

> 요약: 목적과 트래픽에 맞춰 샘플링 기법을 조합해야 함

### 쉽게 이해하기 (학습용)

- 영상 전량 보관, 일부 선별, 사고 영상 위주 보관 방식임

## Ⅵ. 실무 사례

1. 결제 span을 연결해 전체 응답 중 임계 구간을 식별함
2. 메시지 추적 시 실패 trace를 보존하고 개인정보는 제거함

### 쉽게 이해하기 (학습용)

- 결제 span을 연결해 전체 응답 중 임계 구간을 식별함
- 메시지 추적 시 실패 trace를 보존하고 개인정보는 제거함

## Ⅶ. 결론

- trace 연속성과 표본화 목적에 맞춰 수집 정책 선택

### 쉽게 이해하기 (학습용)

- 기록 연속성 보장과 효율적 샘플링 설계가 중요함
