## 미리 알고가기

- **분산 추적(Distributed Tracing)**: '디스트리뷰티드 트레이싱'으로 읽으며, 요청의 서비스 간 호출 경로와 시간을 연결하는 관측 기법
- **트레이스(Trace)**: 하나의 전체 요청을 구성하는 스팬 집합
- **스팬(Span)**: 요청 경로에서 개별 연산의 시작·종료·상태·속성을 기록한 단위
- **Trace ID·Span ID**: '트레이스 아이디·스팬 아이디'로 읽으며, 전체 요청과 개별 연산을 식별하기 위한 값
- **스팬 컨텍스트(Span Context)**: Trace ID·Span ID·표본화 정보 등 전파할 추적 문맥
- **배기지(Baggage)**: 서비스 간 함께 전파하는 업무 문맥이며, 민감정보와 크기를 통제해야 함

## Ⅰ. 개요

- 정의/개념: Trace ID와 스팬의 부모·자식 관계로 **요청의 종단 간 인과 경로와 지연을 재구성**하는 기법
- **배경/필요성**: 서비스별 로그만으로는 **분산 호출 간 관계와 실제 지연 구간을 연결하기 어려운 한계**를 해소하기 위해 필요

### 쉽게 이해하기 (학습용)

- 하나의 운송장 번호로 여러 거점의 처리 시간과 순서를 연결해 전체 배송 지연 구간을 찾는 방식이다.

## Ⅱ. 특징

- Trace ID·Span ID와 부모 관계로 **분산된 연산의 인과관계를 연결**한다.
- 동기·비동기 경계에서 스팬 컨텍스트를 전파해 **요청 경로의 연속성을 유지**한다.
- 샘플링으로 저장 비용을 통제하고, 배기지의 **민감정보·크기·신뢰 경계를 제한**한다.

### 쉽게 이해하기 (학습용)

- 같은 요청 번호를 끊기지 않게 전달하되 기록 비용과 함께 전달할 업무 정보의 보안도 통제한다.

## Ⅲ. 아키텍처 및 구성요소

```text
[요청] → [서비스 A 스팬] → [서비스 B 스팬]
                ↓ 문맥 전파 ↓
          [수집·표본화] → [추적 백엔드]
```

| 설계 요소 | 설명 |
|:---|:---|
| 스팬 생성기 | **연산 시간·상태·속성 기록** |
| 스팬 컨텍스트 | **Trace ID·부모 관계 보존** |
| 전파기 | **통신 매체에 문맥 주입·추출** |
| 배기지 정책 | **업무 문맥·보안·크기 통제** |
| 수집기·샘플러 | **스팬 수집·선별·전송** |
| 추적 백엔드 | **경로 재구성·지연 분석** |

> 요약: 스팬 문맥을 서비스 간 전파하고 수집해 요청의 전체 경로를 재구성한다.

### 쉽게 이해하기 (학습용)

- 각 거점이 같은 운송장 문맥으로 기록을 남기면 중앙에서 지연 구간을 찾을 수 있다.

## Ⅳ. 원리 및 절차 흐름도

```text
문맥 추출·생성 → 스팬 시작·계측 → 문맥 주입·전파 → 수집·표본화 → 경로 재구성
```

| 절차 | 설명 |
|:---|:---|
| 문맥 추출·생성 | 인바운드 문맥 확인 또는 생성 |
| 스팬 시작·계측 | 연산 시간·상태·속성 기록 |
| 문맥 주입·전파 | 통신 매체에 문맥 전달 |
| 수집·표본화 | 스팬 전송과 정책별 선별 |
| 경로 재구성 | 부모 관계 연결·지연 분석 |

> 요약: 추적 문맥을 전파하고 스팬 관계를 연결해 요청 경로와 병목을 재구성한다.

### 쉽게 이해하기 (학습용)

- 운송장 번호를 이어 쓰고 각 거점의 시간을 순서대로 연결해 지연 지점을 찾는다.

## Ⅴ. 종류 및 비교

| 분산 추적 샘플링 방식 | 전량 수집 | 헤드 샘플링 | 테일 샘플링 |
|:---|:---|:---|:---|
| 적용 기준 | 저트래픽·전체 감사 | 시작 시 저비용 선별 | 오류·고지연 우선 보존 |
| 핵심 특징 | 모든 스팬 저장 | 요청 시작 시 결정 | 트레이스 완료 후 결정 |
| 한계 | 저장·처리 비용 증가 | 후발 오류 누락 가능 | 버퍼·결정 지연 비용 |

> 요약: 보존 목적과 비용에 따라 전량·헤드·테일 샘플링을 선택한다.

### 쉽게 이해하기 (학습용)

- 모든 영상을 보관하거나, 촬영 전에 일부만 고르거나, 촬영 뒤 사고 장면을 우선 보관하는 차이다.

## Ⅵ. 실무 사례

1. **결제 요청의 서비스별 스팬 연결로 지연 구간 식별**

### 쉽게 이해하기 (학습용)

- 결제 요청의 전체 호출 시간을 연결해 가장 오래 걸린 서비스를 찾는다.

## Ⅶ. 결론

- 분산 서비스의 지연과 오류 전파 경로를 식별하기 위해 **Trace 문맥 전파·Span 경계·샘플링·고카디널리티·수집 비용**을 검토하고, 종단 요청의 임계경로 분석에 분산 추적을 활용해야 한다.

### 쉽게 이해하기 (학습용)

- 요청 번호를 끊김 없이 전달하고 필요한 추적을 비용 범위 안에서 보존해야 한다.
