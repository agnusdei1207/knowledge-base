## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **모델 서비스 거부(Model Denial of Service, Model DoS)**: 고비용 모델 작업을 반복해 정상 요청의 가용성을 훼손하는 자원 고갈 공격을 의미한다.
- **자원 고갈**: 토큰•GPU 시간•메모리•도구 호출을 과도하게 소비해 정상 작업을 처리하지 못하는 상태이다.

</details>

- 정의/개념: 고비용 작업을 반복해 정상 가용성을 훼손하는 **모델 자원 고갈 공격**임.
- 배경/필요성: 요청 건수 제한만으로 **토큰•시간•도구 비용**의 자원 고갈을 포착할 수 없음.

#### 한줄 요약

- 적은 요청이라도 고비용 추론 작업을 반복해 GPU 자원을 점유하고 정상 요청의 처리를 지연시키는 공격이 핵심이다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **그래픽 처리장치 자원(Graphics Processing Unit Resource, GPU 자원)**: 모델의 행렬 연산과 캐시를 처리하는 가속기 계산•메모리 용량을 의미한다.
- **대기열 지연**: 고비용 작업이 실행 슬롯을 점유해 정상 요청의 대기 시간이 늘어나는 현상을 의미한다.
- **실행 풀 격리**: 테넌트나 작업 등급별로 처리 용량을 나눠 한 주체의 자원 독점을 제한하는 통제을 말한다.

</details>

- 긴 입력•출력•반복에 따른 **GPU 계산•메모리 소모**가 핵심임.
- 자원 고갈에 따른 **대기열 지연•오류•가용성 저하**가 핵심임.
- 자원 독점을 제한하는 **주체별 예산•실행 풀 격리**가 핵심임.

#### 한줄 요약

- 요청 건수가 적어도 한 요청이 긴 토큰과 연쇄 도구 호출을 반복하면 GPU 시간과 비용을 모두 독점할 수 있다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **작업량 계량기**: 요청의 입력•출력 토큰, 실행 시간과 도구 호출 사용량을 누적하는 구성요소을 의미한다.
- **스케줄러**: 테넌트별 용량과 우선순위에 따라 요청의 실행 순서와 슬롯을 배정하는 구성요소을 의미한다.
- **도구 실행기**: 외부 도구의 권한•호출 횟수•시간을 제한하며 모델 계획을 실행하는 구성요소을 말한다.

</details>

```text
                 [요청 게이트웨이]
                         |
                  [작업량 계량기]
                         |
                [대기열•스케줄러]
                         |
              +----------+----------+
              |                     |
         [추론 실행기]          [도구 실행기]
```

선의 의미: 요청 게이트웨이와 작업량 계량기가 주체별 소비를 통제하고, 대기열•스케줄러가 추론 실행기와 도구 실행기의 격리된 자원 경계를 관리한다.

| 구성요소 | 책임 |
|:---|:---|
| 요청 게이트웨이 | 주체 식별과 한도 적용 |
| 작업량 계량기 | 토큰•시간•도구 호출 누적 |
| 대기열•스케줄러 | 테넌트별 실행 풀 격리 |
| 추론 실행기 | 모델 연산과 캐시 처리 |
| 도구 실행기 | 도구 권한•시간 제한 |

#### 한줄 요약

- 게이트웨이에서 주체를 식별하고 계량기가 토큰•시간 사용량을 누적하며, 스케줄러가 실행 순서를 격리하고 예산 초과 시 추론•도구 실행을 중단하는 구조이다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **분당 요청 수(Requests Per Minute, RPM)**: 사용자나 키별로 1분 동안 허용하는 요청 건수 한도이다.
- **분당 토큰 수(Tokens Per Minute, TPM)**: 사용자나 키별로 1분 동안 허용하는 입력•출력 토큰 수 한도이다.
- **실행 예산**: 요청 하나가 사용할 수 있는 토큰•시간•도구 호출•동시성의 상한이다.

</details>

```text
공격자
   │ 1. 고비용 요청 반복 제출
   ▼
요청 게이트웨이
   │ 2. 분산 계정•동시성 한도 우회
   ▼
대기열•스케줄러
   │ 3. 실행 슬롯•KV 캐시 점유
   ▼
추론•도구 실행기
   │ 4. 긴 생성•도구 연쇄 실행
   └── 5. 자원 고갈•서비스 지연 유발 ──▶ 정상 요청
```

1. **고비용 요청 반복 제출**: 긴 입출력•재귀 계획 작업을 생성함.
2. **분산 계정•동시성 한도 우회**: 요청을 여러 주체로 분산함.
3. **실행 슬롯•KV 캐시 점유**: 추론 계산•메모리 자원을 확보함.
4. **긴 생성•도구 연쇄 실행**: GPU 시간과 외부 호출 비용을 소모함.
5. **자원 고갈•서비스 지연 유발**: 정상 요청 대기•오류•거부를 발생함.

#### 한줄 요약

- 고비용 요청이 추론•도구 자원을 점유해 정상 요청의 처리 지연을 유발하는 것이 핵심이다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **입력 길이 증폭**: 긴 문맥으로 입력 연산과 KV 캐시를 과도하게 점유하는 공격 경로을 말한다.
- **출력 길이 증폭**: 장시간 순차 생성을 유도해 생성 슬롯과 GPU 시간을 점유하는 공격 경로이다.
- **도구•에이전트 반복**: 재귀 계획과 연쇄 도구 호출로 모델 및 외부 서비스 비용을 소모하는 공격 경로로 정의된다.
- **키-값(Key-Value, KV) 캐시**: 이전 토큰의 주의 연산 키와 값을 저장해 후속 생성을 가속하는 메모리이다.

</details>

Model DoS는 입력의 KV 캐시, 출력 생성 시간, 도구 반복 비용을 각각 고갈시킨다.

| 모델 DoS 자원 소모 경로 | 입력 길이 증폭 | 출력 길이 증폭 | 도구•에이전트 반복 |
|:---|:---|:---|:---|
| 적용 기준 | 긴 문맥의 **처리 고갈** | 장시간 **순차 생성 고갈** | 재귀•**연쇄 실행 고갈** |
| 핵심 특징 | 입력 연산•**캐시 소모** | 생성 슬롯•**시간 소모** | 모델•도구의 **반복 호출** |
| 한계 | 입력 상한으로 **출력 미통제** | 출력 상한으로 **입력 미통제** | 외부 서비스로 **피해 전파** |

#### 한줄 요약

- 긴 질문은 읽는 자원, 긴 답은 쓰는 시간, 도구 반복은 다른 시스템까지 호출하는 횟수를 소모하므로 각각 다른 한도가 필요하다는 점이 핵심이다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **긴 토큰 점유**: 적은 요청이 매우 긴 입출력을 사용해 건수 제한만으로는 자원 독점을 막지 못하는 문제을 말한다.
- **무한 반복**: 에이전트와 도구가 종료 조건 없이 재귀 호출해 비용을 계속 소모하는 문제로 정의된다.
- **대기열 독점**: 고비용 요청이 공유 실행 슬롯을 차지해 정상 요청의 처리를 지연시키는 문제을 의미한다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 적은 요청의 **긴 토큰 점유** | 사용자별 **RPM•TPM 동시 제한** | 입력•출력의 **자원 독점 차단** |
| 에이전트•도구의 **무한 반복** | 단계•시간•**도구 호출 예산** 설정 | 연쇄 **비용 고갈 방지** |
| 고비용 요청의 **대기열 독점** | 테넌트별 **실행 풀•동시성** 격리 | 정상 요청의 **가용성 보존** |

#### 한줄 요약

- 한 사용자의 긴 요청이 전체 추론 자원을 고갈시키지 않게 한도를 둔다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **주체별 계량**: 사용자•키•조직•테넌트 단위로 자원 소비를 합산해 제한하는 방식로 정의된다.
- **예산 초과 중단**: 실행 중 누적 사용량이 상한을 넘으면 모델 생성과 도구 호출을 취소하는 통제을 말한다.

</details>

- **토큰•시간•동시성•도구 비용**을 계량해 예산 초과 작업을 격리•중단이 핵심임.

#### 한줄 요약

- 요청 건수만 제한하는 것으로는 부족하므로 주체별 토큰•실행 시간•도구 호출 비용을 함께 계량하고 실행 풀을 격리해야 한다.
