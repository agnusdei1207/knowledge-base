## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **프라이버시 보존 AI(Privacy-Preserving AI)**: 학습•추론 중 개인정보 노출을 줄이는 기술군이다.
- **위협 모델(Threat Model)**: 공격자 능력•관측값•보호 자산의 가정이다.

</details>

- 정의: 데이터•중간값•출력 노출을 줄이는 **프라이버시 보존 AI**이다.
- 배경/필요성: 원본을 한곳에 모아 학습하는 구조는 수집•학습•추론 각 단계에서 **개인정보 노출•재식별 위험** 유발해 사고 시 회복 비용이 데이터 전체에 미치므로, 분산 학습•잡음 추가•암호 연산을 단계별로 끼워 넣어 원본 접근 자체를 없애는 보호 계층을 구성

#### 한줄 요약
- **원본•업데이트•출력** 단계별 노출 경계 보호

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **노출 경계(Exposure Boundary)**: 원본•업데이트•출력을 볼 수 있는 주체 범위이다.
- **다층 방어(Defense in Depth)**: 데이터 비이동•노이즈•암호를 결합한다.
- **효용 손실(Utility Loss)**: 보호 통제로 정확도•지연•처리량이 저하된 정도이다.

</details>

- 원본•업데이트•추론 결과를 나눈 **단계별 노출 경계**
- 데이터 비이동과 업데이트 보호를 결합한 **다층 방어**
- 강한 보호 설정에 따른 **정확도 저하•연산 비용 증가**

#### 한줄 요약
- **노출 경계•다층 방어•효용 손실** 절충

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **신뢰 경계(Trust Boundary)**: 데이터•키•중간값•결과를 취급할 주체 범위이다.
- **보호 계층(Protection Layer)**: 노이즈•암호로 관측 범위를 제한한다.
- **공격•효용 평가**: 공격 성공률과 정확도•비용을 함께 측정한다.

</details>

```text
                         [위협 모델]
                              |
                         [신뢰 경계]
                        /           \
                [분산 학습 계층]  [노이즈•암호 계층]
                        \           /
                      [공격•효용 평가기]
```

| 구성요소 | 책임 |
|:---|:---|
| 위협 모델 | 공격자 능력•관측값•**보호 자산 정의** |
| 신뢰 경계 | 데이터•키•결과의 **처리 주체 구분** |
| 분산 학습 계층 | 원본 비이동 기반 **로컬 업데이트 생성** |
| 노이즈•암호 계층 | 업데이트•입력•출력의 **노출 범위 제한** |
| 공격•효용 평가기 | 공격 성공률•정확도•비용의 **보호 효과 검증** |

#### 한줄 요약
- **위협 모델•신뢰 경계•분산•노이즈•암호•평가** 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **공격 표면(Attack Surface)**: 학습•집계•추론에서 개인정보가 노출되는 접점이다.
- **잔여 노출(Residual Exposure)**: 보호 후에도 공격자가 얻을 수 있는 정보 범위이다.

</details>

```text
보호 책임자
   │ 1. 보호 자산•공격자 능력 정의
   │ 2. 단계별 노출 경로 분석
   ▼
┌──────────── 보호•효용 목표 충족까지 ────────────┐
│ 분산 학습기 ── 3. 분산•노이즈•암호 기술 배치 ──▶ 보호 계층
│ 보호 계층 ── 4. 공격 성공률•효용 측정 ──▶ 공격•효용 평가기
│ 보호 책임자 ◀─ 5. 잔여 노출•비용 재설계 ─ 공격•효용 평가기
└─────────────────────────────────────────────────┘
```

### 동작 원리

1. 보호 자산•공격자 능력 정의: 원본•업데이트•출력의 **관측 주체** 설정
2. 단계별 노출 경로 분석: 학습•집계•추론의 **공격 표면** 식별
3. 분산•노이즈•암호 기술 배치: 노출 경로별 **보호 계층** 적용
4. 공격 성공률•효용 측정: 공격과 정확도•지연의 **실측 결과** 비교
5. 잔여 노출•비용 재설계: 목표 초과 위험•비용의 **기술 조합** 조정

#### 한줄 요약
- **자산•노출 경로•보호 배치•공격•효용•재설계** 수행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **연합학습(Federated Learning)**: 원본을 이동하지 않고 로컬 업데이트를 집계한다.
- **차등 프라이버시(Differential Privacy)**: 개인 포함 여부의 결과 영향을 예산으로 제한한다.
- **동형암호(Homomorphic Encryption)**: 암호문 상태에서 연산한다.
- **보안 집계(Secure Aggregation)**: 개별 업데이트를 숨기고 합계만 공개한다.

</details>

| 구분 | 연합학습 | 차등 프라이버시 | 동형암호•보안 집계 |
|:---|:---|:---|:---|
| 적용 기준 | **원본 데이터 비이동** | **개인 기여도 은닉** | **입력•업데이트 기밀성** |
| 핵심 특징 | 로컬 학습의 **업데이트 집계** | 노이즈 기반 **분포 영향 제한** | 암호 상태의 **연산•합계 공개** |
| 한계 | **업데이트 추론 공격** | **정확도 저하•예산 누적** | **연산•통신 비용•공모 가정** |

#### 한줄 요약
- **원본 비이동•개인 기여 은닉•암호 연산**에 따른 기법 구분

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **업데이트 역추론(Update Inversion)**: 변화량에서 원본 특성을 복원하는 공격이다.
- **프라이버시 예산 소진**: 반복 질의•학습으로 누적 노출 한도를 소진한 문제이다.
- **암호 연산 폭증**: 큰 암호문•복잡 연산으로 계산•통신이 급증한 문제이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 연합 업데이트의 **개인정보 역추론** | 보안 집계•업데이트 크기 제한•차등 프라이버시 적용 | 개별 참여자 정보 **노출 완화** |
| 반복 질의의 **프라이버시 예산 소진** | 예산 회계•질의 상한•노이즈 재조정 | 누적 보호 수준 **통제** |
| 동형암호의 **연산•통신 폭증** | 보호 연산 범위•암호 파라미터•배치 최적화 | 기밀성을 유지하며 **처리 비용 절감** |

#### 한줄 요약
- **역추론•프라이버시 예산•암호 비용•공모 가정** 검증

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **보호 예산(Privacy Budget)**: 허용 정보 노출과 보호 기법 사용량의 한도이다.
- **기술 조합(Technique Composition)**: 위협•효용에 맞춘 분산•노이즈•암호 배치이다.

</details>

- 원본 비이동은 **연합학습**, 개인 기여 은닉은 **차등 프라이버시** 선택
- 업데이트 기밀성은 **보안 집계**, 암호 연산은 **동형암호** 적용

#### 한줄 요약
- **관측 범위•보호 예산•효용 손실**에 따라 보호 기술 조합 결정
