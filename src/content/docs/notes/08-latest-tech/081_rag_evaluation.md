## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **RAG 평가(RAG Evaluation)**: 검색•생성•운영 품질을 분리 측정하는 평가 체계이다.

</details>

- 정의: 검색•생성•운영 품질을 분리 측정하는 **RAG 평가**이다.
- 배경/필요성: 최종 답변 점수 하나로는 **검색 누락·생성 오류 구분 곤란**해 실패마다 전 구간을 다시 실험하는 비용을 치르므로, 검색과 생성 각 단계에 별도 지표 계층을 끼워 넣어 원인 구간을 좁힌 뒤 수정

#### 한줄 요약
- **검색•생성•운영 단계**별 오류 원인 분리

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **문맥 재현율(Context Recall)**: 필요한 근거가 검색 문맥에 포함된 정도이다.
- **문맥 정밀도(Context Precision)**: 검색 문맥 중 관련 근거의 비율이다.
- **충실성(Faithfulness)**: 답변 주장이 검색 문맥으로 뒷받침되는 정도이다.
- **답변 관련성(Answer Relevance)**: 답변이 질의 요구에 대응하는 정도이다.

</details>

- **문맥 재현율•정밀도•Recall@k•MRR** 기반 검색 평가
- 충실성•관련성 기반 **문맥 지지•질의 대응 평가**
- 검색·생성·운영 지표의 **단계별 실패 귀속**

#### 한줄 요약
- **검색 회수•문맥 지지•질의 대응** 분리 측정

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **기준 정답(Ground Truth)**: 검증된 근거 문서와 답변이다.
- **검색 평가기**: 회수율•정밀도•순위로 검색 실패를 진단한다.
- **생성 평가기**: 충실성•정답성•인용 일치로 생성 실패를 진단한다.
- **실패 분석기**: 평가 결과를 검색•생성•운영 원인으로 분류한다.
- **실행 식별자(Run ID)**: 후보•문맥•응답•인용•평가 결과를 연결한다.

</details>

```text
[평가 데이터셋]──[RAG 실행기]──[실행 기록]
                        │
              [검색 평가기]──[생성 평가기]──[실패 분석기]
```

| 구성요소 | 책임 |
|:---|:---|
| 평가 데이터셋 | 질의•근거•**기준 정답** 평가 표본 보관 |
| RAG 실행기 | 검색 후보•문맥•응답•인용의 **실행 기록 생성** |
| 검색 평가기 | **Recall@k•MRR•문맥 정밀도** 계산 |
| 생성 평가기 | 충실성•관련성•정확성의 **답변 품질 계산** |
| 실패 분석기 | 지표•로그를 연결한 **오류 단계 귀속** |

#### 한줄 요약
- **데이터셋•실행 기록•검색•생성•실패 분석** 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **상위 k개 재현율(Recall at k, Recall@k)**: 상위 k개에 정답 근거가 포함된 질의 비율이다.
- **평균 역순위(Mean Reciprocal Rank, MRR)**: 첫 관련 문서 순위 역수의 평균이다.
- **실패 귀속(Failure Attribution)**: 오류 원인을 검색•생성•운영 단계에 연결한다.

</details>

```text
평가 책임자
   │ 1. 품질 목표•기준 표본 정의
   ▼
RAG 실행기
   │ 2. 질의 실행•로그 수집
   ▼
[검색•생성 평가기]
   │ 3. 검색 회수•순위 측정
   │ 4. 충실성•관련성 측정
   │ 5. 실패 단계•회귀 판정
   └── 평가 결과 ──▶ 평가 책임자
```

### 동작 원리

1. 품질 목표•기준 표본 정의: 기준 근거·답과 **합격 임계값** 설정
2. 질의 실행•로그 수집: 후보·문맥·응답·인용을 **실행 ID로 연결**
3. 검색 회수•순위 측정: 포함 여부·첫 순위의 **검색 품질** 계산
4. 충실성•관련성 측정: 문맥 지지·질의 대응의 **생성 품질** 계산
5. 실패 단계•회귀 판정: 지표를 **원인 단계·기준 버전**에 귀속

#### 한줄 요약
- **표본 정의•로그 수집•검색•생성 평가•실패 귀속** 수행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **정답셋•인간•모델 평가**: 자동 비교•전문가 판정•대량 의미 판정 방식이다.

</details>

| 구분 | 정답셋 평가 | 인간 평가 | 모델 평가자 |
|:---|:---|:---|:---|
| 적용 기준 | **반복 회귀 시험** | **고위험·개방형 판정** | **대량 의미 평가** |
| 핵심 특징 | 기준 근거•답과 **자동 비교** | 전문가 지침의 **직접 판정** | 평가 모델•규칙의 **의미 판정** |
| 한계 | **정답셋 구축·갱신 비용** | **시간·비용·평가자 편차** | **모델·프롬프트 편향** |

#### 한줄 요약
- 반복성·전문성·비용·편향에 따라 **평가자 구분**

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **평가자 일치도(Inter-rater Agreement)**: 모델 판정과 인간 합의 표본의 일치 정도이다.
- **신뢰 구간(Confidence Interval)**: 표본 변동을 고려한 실제 품질의 추정 범위이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 기준 근거 누락의 **Recall@k 왜곡** | 질의별 복수 정답 근거•판정 규칙 검수 | 검색 재현율의 **타당성 확보** |
| 검색 실패가 섞인 **충실성 오판** | 검색 성공•실패 표본을 분리해 생성 평가 | 생성 오류의 **독립 진단** |
| 모델 평가자의 **판정 편향** | 인간 합의 표본과 일치도•불일치 유형 측정 | 자동 평가의 **신뢰 구간 확인** |

#### 한줄 요약
- **기준 근거•단계 분리•평가자 일치도** 검증

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **개선 우선순위(Improvement Priority)**: 품질 목표를 가장 크게 저해하는 단계의 순서이다.

</details>

- 검색 회수•문맥 충실성•평가자 신뢰도로 **실패 단계•개선 우선순위** 결정

#### 한줄 요약
- **검색•생성•운영 지표** 기반 우선 개선 단계 결정
