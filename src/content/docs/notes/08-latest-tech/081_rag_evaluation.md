## 미리 알고가기

- **후보 재현율 (Context Recall)**: 필요한 근거가 검색 후보에 포함된 비율
- **문맥 정밀도 (Context Precision)**: 검색 문맥 중 유용한 근거의 비율과 순위
- **충실성 (Faithfulness)**: 답변 주장이 제공된 문맥으로 뒷받침되는 정도
- **답변 관련성 (Answer Relevance)**: 답변이 질의 요구에 직접 대응하는 정도

## Ⅰ. 개요

- **정의/개념**: RAG의 검색·문맥·생성 품질을 단계별 측정
- **배경/필요성**: 최종 오답의 검색·생성 원인을 분리 진단

### 쉽게 이해하기 (학습용)

- 답이 틀린 원인이 검색 누락인지 생성 오류인지 단계별로 검사합니다.

## Ⅱ. 특징

- 후보 재현율은 필요한 근거가 후보에 포함됐는지 측정한다.
- 문맥 정밀도는 검색 문맥의 유용성과 순위를 평가한다.
- 충실성은 답변 주장이 문맥으로 뒷받침되는지 측정한다.
- 답변 관련성은 답변이 질의 요구에 대응하는지 평가한다.

### 쉽게 이해하기 (학습용)

- 필요한 자료의 확보와 잡음 배제 및 답변의 근거성을 따로 평가합니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 평가질의 | 질의·기준 문서·답을 보관함 |
| 실행기록 | 검색 후보·문맥·답을 연결함 |
| 평가지표 | 검색 누락·생성 오류를 측정함 |
| 평가명세 | 평가자·지침·반복을 기록함 |

### 쉽게 이해하기 (학습용)

- 평가 자료·실행 기록·지표·평가자 설정을 함께 보존합니다.

## Ⅳ. 원리 및 절차 흐름도

```text
자료구축
↓
실행수집
↓
검색평가
↓
생성평가
↓
원인분석
```

| 절차 | 설명 |
|:---|:---|
| 자료구축 | 질의·기준 문서·답을 구축함 |
| 실행수집 | 검색 후보·문맥·답을 저장함 |
| 검색평가 | 재현율·정밀도로 누락·잡음 진단함 |
| 생성평가 | 충실성·관련성 판정을 대조함 |
| 원인분석 | 검색·생성 실패 원인을 분리함 |

### 쉽게 이해하기 (학습용)

- 검색과 생성을 따로 평가해 실패 원인과 개선 대상을 구분합니다.

## Ⅴ. 종류 및 비교

| 적용 기준 | 정답셋 평가 | 인간 평가 | 모델 평가자 |
|:---|:---|:---|:---|
| 판정 근거 | 기준 문서·답 | 지침·전문지식 | 모델·평가지침 |
| 적용 환경 | 회귀 테스트 | 고위험·개방형 | 대량 사전 평가 |
| 주요 위험 | 답 누락·편차 | 비용·편차 | 프롬프트 편향 |

> 요약: 판정 근거와 환경에 따라 정답셋·인간·모델로 구분함

### 쉽게 이해하기 (학습용)

- 정답셋·사람·모델 평가자는 판정 근거와 적용 환경이 다릅니다.

## Ⅵ. 실무 사례

- 청크 분할 변경은 재현율·정밀도를 비교해 검색 개선을 확인함
- 모델 평가는 고정 표본으로 사람과 교차 채점하여 검증함

### 쉽게 이해하기 (학습용)

- 청킹이나 자동 평가자를 바꾸면 고정 표본으로 검색과 생성 품질을 다시 검증합니다.

## Ⅶ. 결론

- RAG 평가는 검색·생성 지표와 평가자 편향을 분리한다.

### 쉽게 이해하기 (학습용)

- 실패 단계와 평가자 간 일치도를 확인해 개선 대상을 선택해야 합니다.
