## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **메모리 내 처리(Processing-in-Memory, PIM)**: 메모리 내부 회로에서 연산해 처리기와의 데이터 이동을 줄이는 컴퓨팅 구조 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **폰 노이만 병목(Von Neumann Bottleneck)**: 처리기와 메모리 사이의 반복 전송이 성능과 전력을 제한하는 현상을  역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

- 정의/개념: 메모리 내부에서 연산해 데이터 이동을 줄이는 **PIM**
- 배경/필요성: 처리기•메모리 간 데이터 왕복으로 **지연•에너지 병목**이 발생하는 특징을 가짐.

#### 한줄 요약

- 메모리 내부에서 계산해 **부분 결과**만 처리기로 전달

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **오프로딩(Offloading)**: 호스트가 수행하던 지원 연산을 메모리 내 처리 연산부로 넘겨 실행하는 방식 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **데이터 일관성**: 호스트와 메모리 내 처리 연산부가 같은 데이터의 최신 값을 일치되게 관측하는 성질 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

**PIM**은 지원 명령과 데이터만 메모리 내부 연산부로 오프로딩한다.

- 데이터 위치에서 연산해 **전송량•전력 절감**
- 지원 명령•데이터만 메모리에 **오프로딩**
- 정밀도•일관성•동기화의 **결과 검증**

#### 한줄 요약

- 명령•동기화 비용보다 **데이터 이동 절감량**이 큰 작업 적용

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **실행 배치 계층**: 연산 지원 범위와 이동 이득을 바탕으로 호스트와 PIM 중 실행 위치를 정하는 계층 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **명령 인터페이스**: 연산 대상•명령•동기화 조건을 PIM 연산부에 전달하는 경계 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **메모리 저장 영역**: 연산할 데이터와 부분 결과를 메모리 셀•뱅크 가까이에 보관하는 영역 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **PIM 연산부**: 메모리 반도체 내부에 직접 연산기(Processor)를 통합하여, CPU와 메모리 간의 대규모 데이터 이동을 최소화함으로써 전력 소모를 줄이고 처리 속도를 비약적으로 향상시키는 지능형 메모리 기술
- **결과 검증 계층**: 메모리 내 처리 결과의 정확도•일관성을 확인하고 호스트 기준 결과와의 차이•예외를 처리하는 구성요소을  역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

**PIM 실행 배치 계층**은 연산 지원 범위와 이동 이득을 바탕으로 호스트와 메모리 중 실행 위치를 정한다.

```text
             [실행 배치 계층]
                     |
              [명령 인터페이스]
                     |
       +-------------+-------------+
       |                           |
[메모리 저장 영역]           [PIM 연산부]
       |                           |
       +-------------+-------------+
                     |
              [결과 검증 계층]
```

선의 의미: 실행 배치 계층과 명령 인터페이스가 메모리 저장 영역 및 PIM 연산부의 소유권 경계를 정의하고, 결과 검증 계층이 정확성과 일관성을 확인한다.

| 구성요소 | 책임 |
|:---|:---|
| 실행 배치 계층 | **호스트•PIM 실행 주체** 결정 |
| 명령 인터페이스 | **대상•연산•동기화 명령** 전달 |
| 메모리 저장 영역 | **연산 대상 데이터** 인근 배치 |
| PIM 연산부 | **지원 연산•부분 결과** 처리 |
| 결과 검증 계층 | **데이터 소유권•연산 오차** 확인 |

#### 한줄 요약

- 호스트가 지원 작업을 나누고 명령을 보내면 메모리 근처 연산부가 계산하고 검증부가 결과를 확인하는 특징을 가짐.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **피연산자**: 필터•벡터•누산 연산이 직접 처리하는 입력 데이터 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **소유권 경계**: 호스트와 메모리 내 처리 연산부 중 어느 주체가 데이터를 읽고 갱신할 수 있는지 정한 규칙 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

**PIM 소유권 경계**는 호스트와 메모리 연산부의 읽기•갱신 권한을 구분한다.

```text
실행 배치 계층
   │ 1. 이동량•지원 연산 판정
   ▼
명령 인터페이스
   │ 2. 대상 데이터•동기화 명령
   ▼
메모리 저장 영역
   │ 3. 메모리 인접 피연산자
   ▼
PIM 연산부
   │ 4. 부분 연산 결과
   ▼
결과 검증 계층 ── 정확성•이동 이득 판정 ──▶ 실행 배치 계층
```

### 동작 원리

1. **이동량•지원 연산 판정**: 오프로딩 편익과 명령 지원을 확인함.
2. **대상 데이터•동기화 명령**: 연산 대상과 소유권 경계를 지정함.
3. **메모리 인접 피연산자**: 호스트 왕복 없이 데이터를 공급함.
4. **부분 연산 결과**: 필터•벡터•누산의 지원 연산을 수행함.

#### 한줄 요약

- 이동 이득이 큰 연산만 보내고 **정확성**•**일관성** 검증

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **셀 내부 메모리 내 처리**: 메모리 셀이나 감지 회로에서 직접 단순 연산을 수행하는 구조을  역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **메모리 근접 처리(Processing-Near-Memory, PNM)**: 메모리 옆의 로직에서 연산해 데이터 이동 거리를 줄이는 구조 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

**PIM**과 **PNM**은 연산부가 메모리 셀 내부•로직 계층•인접 위치 중 어디에 배치되는지가 다르다.

| 메모리 연산 구조 | 셀 내부 PIM | 로직 계층 PIM | PNM |
|:---|:---|:---|:---|
| 적용 기준 | **단순 대량 연산•오차 허용** | **제한 명령의 정확 연산** | **유연한 메모리 집약 처리** |
| 핵심 특징 | **셀•감지회로 내 연산** | **메모리 로직 다이 연산** | **메모리 옆 처리기 연산** |
| 한계 | **소자 편차•변환 오차** | **명령•용량•열 제약** | **근거리 데이터 이동 잔존** |

> 요약: **셀 PIM**은 효율, **로직 PIM**은 정확 명령, PNM은 유연성이 핵심이다.

#### 한줄 요약

- 효율•정확 명령•유연성에 따른 **메모리 연산 위치** 선택

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **오프로딩 편익**: 줄어든 데이터 이동 비용에서 명령•동기화•결과 회수 비용을 뺀 실제 이득 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **변환 오차**: 메모리 셀의 아날로그 연산이나 제한 정밀도로 인해 기준 계산과 달라지는 값 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 오프로딩보다 큰 명령 비용 | 연산량 대비 **데이터 이동 절감량** 사전 측정 | 비효율 오프로딩 방지 |
| 셀 연산의 정밀도 오차 | 허용 오차•**결과 검증** 적용 | 계산 정확성 보존 |
| 호스트•PIM 데이터 불일치 | 소유권•동기화 **일관성 규칙** 정의 | 오래된 데이터 사용 방지 |

#### 한줄 요약

- 오프로딩 편익•오차•일관성으로 **PIM 적용 범위** 검증

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **이동 절감량**: PIM 실행으로 처리기와 메모리 사이에서 전송하지 않아도 된 데이터의 양 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.
- **근접 처리**: 데이터가 저장된 위치 가까이에 연산기를 배치해 전송 거리와 에너지를 줄이는 방식 역할을 수행하는 핵심 기술 및 개념하는 특징을 가짐.

</details>

- 단순 대량•이동 절감은 **PIM**, 유연한 근접 처리는 **PNM** 선택

#### 한줄 요약

- 이동 절감이 비용보다 크고 **결과 오차**가 허용될 때 PIM 적용
