## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **메모리 내 처리(Processing-in-Memory, PIM)**: 메모리 내부 회로에서 연산해 처리기와의 데이터 이동을 줄이는 컴퓨팅 구조이다.
- **폰 노이만 병목(Von Neumann Bottleneck)**: 처리기와 메모리 사이의 반복 전송이 성능과 전력을 제한하는 현상이다.

</details>

- 정의: 메모리 내부에서 연산해 데이터 이동을 줄이는 **PIM**
- 배경/필요성: 거대 언어 모델(LLM)의 생성 단계(Token Generation), 대규모 추천 시스템의 임베딩 룩업(Embedding Lookup), 그래프 신경망(GNN) 등 메모리 집약적(Memory-bound) AI 워크로드는 연산 강도(Arithmetic Intensity)가 낮아, CPU/GPU 프로세서와 오프칩 DRAM 사이의 데이터 전송에 전체 시스템 에너지의 60~80% 이상이 낭비되고 메모리 버스 대역폭 한계로 인한 폰 노이만 병목(Von Neumann Bottleneck)에 직면함에 따라, DRAM 뱅크(Bank) 내부 또는 베이스 다이에 연산 유닛(ALU/MAC)을 직접 집적하여 메모리 내부에서 데이터를 제자리 연산(In-situ Computing)하는 PIM(Processing-in-Memory / Samsung HBM-PIM & Aquabolt-XL, SK Hynix AiM, UPMEM DPU, Processing-Near-Memory: PNM) 아키텍처를 도입하여 **호스트-메모리 간 원시 데이터 이동을 최소화하고 최종 축약(Reduction/Aggregation) 결과만을 전송함으로써 데이터 이동 전력 70% 이상 절감, 수천 개 메모리 뱅크의 내부 병렬 대역폭을 동시 활용한 초광폭 메모리 레벨 병렬성(Bank-level Parallelism) 극대화, 기존 호스트 컴파일러 및 메모리 컨트롤러와의 호환성 확보**를 달성할 필요

#### 한줄 요약

- 메모리 내부 연산을 통해 **부분 결과** 한정 처리기로 전송

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **오프로딩(Offloading)**: 호스트가 수행하던 지원 연산을 메모리 내 처리 연산부로 넘겨 실행하는 방식이다.
- **데이터 일관성**: 호스트와 메모리 내 처리 연산부가 같은 데이터의 최신 값을 일치되게 관측하는 성질이다.

</details>

지원 명령과 데이터만 메모리 연산부로 보내는 **PIM 오프로딩**

- 데이터 위치에서 연산해 **전송량•전력 절감**
- 지원 명령•데이터만 메모리에 **오프로딩**
- 정밀도•일관성•동기화의 **결과 검증**

#### 한줄 요약

- 명령•동기화 비용보다 **데이터 이동 절감량** 큰 작업 적용

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **실행 배치 계층**: 연산 지원 범위와 이동 이득을 바탕으로 호스트와 PIM 중 실행 위치를 정하는 계층이다.
- **명령 인터페이스**: 연산 대상•명령•동기화 조건을 PIM 연산부에 전달하는 경계이다.
- **메모리 저장 영역**: 연산할 데이터와 부분 결과를 메모리 셀•뱅크 가까이에 보관하는 영역이다.
- **PIM 연산부**: 메모리 셀•뱅크 가까이에서 지원 연산을 수행해 데이터 왕복을 줄이는 구성요소이다.
- **결과 검증 계층**: 메모리 내 처리 결과의 정확도•일관성을 확인하고 호스트 기준 결과와의 차이•예외를 처리하는 구성요소이다.

</details>

```text
[PIM Architecture]
├── [오케스트레이션 및 인터페이스 계층]
│   ├── [실행 배치 계층 (Workload Placement)]
│   └── [명령 인터페이스 (Command Interface)]
├── [인메모리 컴퓨팅 계층]
│   ├── [메모리 저장 영역 (DRAM Banks)]
│   └── [PIM 연산부 (In-Bank ALU/MAC)]
└── [검증 및 일관성 계층]
    └── [결과 검증 계층 (Coherence & Verification)]
```

- 선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 실행 배치 계층 | **호스트•PIM 실행 주체** 결정 |
| 명령 인터페이스 | **대상•연산•동기화 명령** 전달 |
| 메모리 저장 영역 | **연산 대상 데이터** 인근 배치 |
| PIM 연산부 | **지원 연산•부분 결과** 처리 |
| 결과 검증 계층 | **데이터 소유권•연산 오차** 확인 |

#### 한줄 요약

- 호스트 실행 배치와 **메모리 인접 연산•결과 검증** 구조

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **피연산자**: 필터•벡터•누산 연산이 직접 처리하는 입력 데이터이다.
- **소유권 경계**: 호스트와 메모리 내 처리 연산부 중 어느 주체가 데이터를 읽고 갱신할 수 있는지 정한 규칙이다.

</details>

**PIM 소유권 경계**에 따른 호스트•메모리 연산부의 읽기•갱신 권한 구분

```text
실행 배치 계층
   │ 1. 이동량•지원 연산 판정
   ▼
명령 인터페이스
   │ 2. 대상 데이터•동기화 명령
   ▼
메모리 저장 영역
   │ 3. 메모리 인접 피연산자
   ▼
PIM 연산부
   │ 4. 부분 연산 결과
   ▼
결과 검증 계층 ── 정확성•이동 이득 판정 ──▶ 실행 배치 계층
```

### 동작 원리

1. 이동량•지원 연산 판정: 오프로딩 편익과 명령 지원 확인
2. 대상 데이터•동기화 명령: 연산 대상과 소유권 경계 지정
3. 메모리 인접 피연산자: 호스트 왕복 없이 데이터 공급
4. 부분 연산 결과: 필터•벡터•누산의 지원 연산 수행

#### 한줄 요약

- 이동 이득이 큰 연산만 보내고 **정확성**•**일관성** 검증

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **셀 내부 메모리 내 처리**: 메모리 셀이나 감지 회로에서 직접 단순 연산을 수행하는 구조이다.
- **메모리 근접 처리(Processing-Near-Memory, PNM)**: 메모리 옆의 로직에서 연산해 데이터 이동 거리를 줄이는 구조이다.

</details>

**PIM**•**PNM** 연산부의 셀 내부•로직 계층•인접 위치 비교

| 메모리 연산 구조 | 셀 내부 PIM | 로직 계층 PIM | PNM |
|:---|:---|:---|:---|
| 적용 기준 | **단순 대량 연산•오차 허용** | **제한 명령의 정확 연산** | **유연한 메모리 집약 처리** |
| 핵심 특징 | **셀•감지회로 내 연산** | **메모리 로직 다이 연산** | **메모리 옆 처리기 연산** |
| 한계 | **소자 편차•변환 오차** | **명령•용량•열 제약** | **근거리 데이터 이동 잔존** |

> 요약: **셀 PIM** 효율, **로직 PIM** 정확 명령, PNM은 유연성이 핵심이다.

#### 한줄 요약

- 효율•정확 명령•유연성에 따른 **메모리 연산 위치** 선택

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **오프로딩 편익**: 줄어든 데이터 이동 비용에서 명령•동기화•결과 회수 비용을 뺀 실제 이득이다.
- **변환 오차**: 메모리 셀의 아날로그 연산이나 제한 정밀도로 인해 기준 계산과 달라지는 값이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 오프로딩보다 큰 **명령 비용** | 연산량 대비 **데이터 이동 절감량** 사전 측정 | **비효율 오프로딩** 방지 |
| 셀 연산의 **정밀도 오차** | 허용 오차•**결과 검증** 적용 | **계산 정확성** 보존 |
| 호스트•PIM **데이터 불일치** | 소유권•동기화 **일관성 규칙** 정의 | **오래된 데이터** 사용 방지 |

#### 한줄 요약

- 오프로딩 편익•오차•일관성으로 **PIM 적용 범위** 검증

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **이동 절감량**: PIM 실행으로 처리기와 메모리 사이에서 전송하지 않아도 된 데이터의 양이다.
- **근접 처리**: 데이터가 저장된 위치 가까이에 연산기를 배치해 전송 거리와 에너지를 줄이는 방식이다.

</details>

- 폰 노이만 아키텍처의 물리적 한계를 근본적으로 돌파하여 메모리 벽을 허무는 **차세대 니어 메모리/인메모리 AI 가속 컴퓨팅의 최고 패러다임 표준(Processing-in-Memory: PIM / HBM-PIM, CXL-PNM & LPDDR-PIM / In-situ Arithmetic & Bank-Level Parallelism / Von Neumann Bottleneck Elimination / Memory-Compute Unified Architecture)의 확고한 표준**으로 확고히 자리 잡았으며, CXL 인터페이스 기반의 CXL-PNM 및 온디바이스 저전력 LPDDR-PIM으로 급속히 확장되는 가운데, 실무 PIM 시스템 도입 및 워크로드 최적화 시에는 **연산 집약적 Dense GEMM은 GPU/TPU에 할당하고, 메모리 대역폭 집약적인 LLM 디코딩 어텐션 및 추천 임베딩 연산은 PIM/PNM으로 지능형 분기 오프로딩하며, 호스트-PIM 간 캐시 일관성과 비동기 런타임 드라이버**를 결합하여 완벽한 와트당 성능 극대화와 메모리 병목 없는 초고속 AI 인프라를 완성

#### 한줄 요약

- 이동 절감이 비용보다 크고 **결과 오차** 허용될 때 PIM 적용
