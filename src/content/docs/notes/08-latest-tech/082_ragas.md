## 미리 알고가기

- **RAGAS(Retrieval-Augmented Generation Assessment)**: 질의·검색 문맥·응답·기준 정보를 묶어 RAG 품질을 여러 지표로 자동 평가하는 프레임워크
- **검색 증강 생성(Retrieval-Augmented Generation, RAG)**: 질의와 관련된 외부 문서를 검색하여 생성 답변의 근거로 제공하는 방식
- **충실성(Faithfulness)**: 응답 주장이 검색 문맥으로 뒷받침되는 정도
- **문맥 정밀도(Context Precision)**: 관련 근거가 검색 문맥의 앞순위에 배치된 정도
- **문맥 재현율(Context Recall)**: 기준 답에 필요한 근거가 검색 문맥에 포함된 정도
- **평가 모델(Evaluator Model)**: 자연어의 의미와 지표 규칙을 이용하여 평가 표본을 판정하는 모델
- **임베딩 모델(Embedding Model)**: 문장을 벡터로 바꾸어 의미 유사도를 계산하는 모델
- **평가 스키마(Evaluation Schema)**: 지표 계산에 필요한 질의·응답·문맥·기준 답 필드의 구조

## Ⅰ. 개요

- 정의/개념: **RAGAS**는 구조화 표본과 자동 지표로 RAG 검색·생성 품질을 반복 평가하는 프레임워크
- 배경/필요성: 수작업 RAG 평가는 반복 실험의 **비용·판정 편차** 증가

### 쉽게 이해하기 (학습용)
- 같은 답안지와 채점 조건으로 검색 자료와 생성 답변을 반복 채점하는 자동 평가 도구임

## Ⅱ. 특징

- 질의·응답·문맥·기준 정보의 **평가 스키마 구조화**
- 충실성·문맥 정밀도·재현율의 **목적별 지표 조합**
- 평가 모델·프롬프트·반복 조건의 **재현 가능한 실행 기록**

### 쉽게 이해하기 (학습용)
- 표본 형식과 채점 모델·채점 문장을 함께 고정해야 변경 전후 점수를 비교할 수 있음

## Ⅲ. 구조 및 구성요소

```mermaid
block-beta
    columns 5
    D["평가 데이터셋"]
    M["지표 모음"]
    E["평가 모델"]
    X["평가 실행기"]
    R["결과 저장소"]
```

| 구성요소 | 책임 |
|:---|:---|
| 평가 데이터셋 | 단일 질의·대화 표본의 **평가 스키마 보관** |
| 지표 모음 | 평가 대상·필수 입력·**점수 규칙 정의** |
| 평가 모델 | 언어 모델·임베딩 기반 **의미 판정** |
| 평가 실행기 | 프롬프트·재시도·동시성의 **실행 조건 통제** |
| 결과 저장소 | 표본별 점수·비용·추적의 **평가 결과 보존** |

### 쉽게 이해하기 (학습용)
- 표본과 채점표를 평가 모델에 넣고 실행 조건과 결과를 같은 기록에 남김

## Ⅳ. 흐름도

```mermaid
sequenceDiagram
    participant O as 평가 책임자
    participant D as 평가 데이터셋
    participant M as 지표·평가 모델
    participant X as 평가 실행기
    participant H as 인간 검증자
    O->>D: 1. 평가 목적·표본 스키마 정의
    D->>M: 2. 지표·평가 모델 선택
    M->>X: 3. 프롬프트·버전·재시도 고정
    X->>H: 4. 표본별 점수 실행·집계
    H-->>O: 5. 자동 점수·인간 판단 대조
```

### 동작 원리

1. **평가 목적·표본 스키마 정의**: 검색·생성 목표와 지표별 **필수 필드** 구성
2. **지표·평가 모델 선택**: 평가 질문에 맞는 점수 규칙과 **판정 모델** 지정
3. **프롬프트·버전·재시도 고정**: 변경 전후 비교가 가능한 **실행 조건** 저장
4. **표본별 점수 실행·집계**: 지표별 점수와 비용·오류의 **평가 결과** 생성
5. **자동 점수·인간 판단 대조**: 대표 표본의 불일치로 **자동 평가 신뢰도** 검증

### 쉽게 이해하기 (학습용)
- 채점 목적과 표본 형식을 정하고 같은 채점기로 점수를 낸 뒤 일부 답을 사람이 다시 확인함

## Ⅴ. 종류 및 비교

| 비교 기준 | LLM 기반 지표 | 비LLM 기반 지표 | 인간 평가 |
|:---|:---|:---|:---|
| 적용 기준 | 의미·문맥 판정 | 문자열·통계 판정 | 고위험 최종 판정 |
| 핵심 특징 | 프롬프트 기반 **의미 평가** | 일치·유사도 기반 **결정 평가** | 전문가 지침 기반 **직접 평가** |
| 한계 | 비결정성·모델 편향 | 의미 관계 판정 한계 | 시간·비용·평가자 편차 |

### 쉽게 이해하기 (학습용)
- 다른 모델, 계산 규칙, 사람이 채점할 때 각각 이해 범위와 비용이 달라짐

## Ⅵ. 실무 고려사항 및 대책

| 고려사항 | 대책 | 효과 |
|:---|:---|:---|
| 지표별 **필수 스키마 누락** | 지표 입력 계약에 맞춘 필드 사전 검증 | 계산 실패·무효 점수 **방지** |
| 평가 모델 변경의 **점수 기준 이동** | 모델·프롬프트 버전 고정과 병렬 재평가 | 지표 시계열의 **비교 가능성 확보** |
| 비결정 평가의 **점수 변동** | 반복 실행 분포·인간 일치도 측정 | 자동 점수의 **불확실성 확인** |

### 쉽게 이해하기 (학습용)
- 채점표에 필요한 칸과 채점기 버전을 고정하고 같은 답을 여러 번 채점해 흔들림을 확인함

## Ⅶ. 결론

- 평가 목적·스키마 완전성·판정 일치도를 기준으로 **RAGAS 지표와 평가 모델** 선택

### 쉽게 이해하기 (학습용)
- 필요한 정보를 갖춘 지표와 사람이 납득할 만큼 일관된 채점 모델을 선택함
