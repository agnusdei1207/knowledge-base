## 미리 알고가기

- **RAGAS (Retrieval-Augmented Generation Assessment)**: RAG 품질을 지표별로 평가하는 프레임워크
- **충실성 (Faithfulness)**: 응답 주장이 검색 문맥에 근거한 정도
- **문맥 정밀도 (Context Precision)**: 검색 문맥의 관련성과 순위 품질
- **평가 모델 (Evaluator Model)**: 자연어 의미를 기준으로 표본을 판정하는 모델

## Ⅰ. 개요

- **정의/개념**: RAG의 검색·생성 품질을 지표별 평가
- **배경/필요성**: 검색과 생성 오류를 분리해 개선 대상 식별

### 쉽게 이해하기 (학습용)

- 검색과 생성의 성공 여부를 서로 다른 채점표로 검사합니다.

## Ⅱ. 특징

- 표본은 질의·응답·검색 문맥·기준 답으로 구성한다.
- 품질을 지표별로 나눠 오류가 발생한 단계를 찾는다.
- 평가 목적과 사용 가능한 기준 답에 맞춰 지표를 조합한다.
- 평가 모델·프롬프트·반복 조건에 따라 점수가 달라진다.

### 쉽게 이해하기 (학습용)

- 채점자와 채점표가 바뀌면 점수도 달라지므로 평가 조건을 기록합니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 평가표본 | 질의·응답·문맥·기준 답을 묶음 |
| 지표정의 | 평가 대상과 판정 기준을 구분함 |
| 평가모델 | 의미 기반 판정을 수행함 |
| 평가설정 | 모델·프롬프트·반복을 기록함 |

### 쉽게 이해하기 (학습용)

- 표본·지표·평가 모델·설정이 재현 가능한 평가 체계를 구성합니다.

## Ⅳ. 원리 및 절차 흐름도

```text
목적정의
↓
표본구성
↓
지표선택
↓
설정고정
↓
결과검증
```

| 절차 | 설명 |
|:---|:---|
| 목적정의 | 검색·생성 진단 축을 정함 |
| 표본구성 | 질의·응답·문맥·기준 답 구성함 |
| 지표선택 | 목적·입력에 맞는 지표 선택함 |
| 설정고정 | 평가자·프롬프트 고정함 |
| 결과검증 | 자동 점수와 사람 표본 대조함 |

### 쉽게 이해하기 (학습용)

- 같은 설정으로 자동 평가하고 일부 표본을 사람의 판단과 대조합니다.

## Ⅴ. 종류 및 비교

| 적용 기준 | RAGAS 자동 | 사람 평가 | 문자열 평가 |
|:---|:---|:---|:---|
| 평가 범위 | 문맥·응답 지표 | 맥락·유용성 | 문자열 일치 |
| 재현 조건 | 모델·프롬프트 고정 | 평가자 합의 | 토큰화 고정 |
| 적용 환경 | 반복·오류 분리 | 최종 판단 | 단답형 평가 |

> 요약: 판정 방식에 따라 자동·사람·문자열로 구분함

### 쉽게 이해하기 (학습용)

- RAGAS·사람·문자열 평가는 판정 근거와 비용이 다릅니다.

## Ⅵ. 실무 사례

- 동일 표본과 설정으로 검색 지표 회귀를 탐지함
- 생성 지표의 저점 표본을 사람이 검토함

### 쉽게 이해하기 (학습용)

- 변경 전후를 같은 표본으로 평가하고 낮은 점수의 원인은 사람이 확인합니다.

## Ⅶ. 결론

- RAGAS는 평가 설정 고정과 사람 표본 검증을 병행함

### 쉽게 이해하기 (학습용)

- 자동 점수는 개선 신호이므로 중요한 판단은 사람 평가와 교차 검증해야 합니다.
