## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **그래프 검색 증강 생성(Graph Retrieval-Augmented Generation, GraphRAG)**: 개체•관계와 커뮤니티 요약을 근거로 사용하는 RAG 방식이다.
- **다중 홉 질의**: 답을 찾기 위해 여러 개체 관계를 따라가는 질의이다.

</details>

- 정의/개념: 개체•관계•커뮤니티 요약을 검색하는 **GraphRAG**
- 배경/필요성: 일반 RAG의 청크 검색만으로는 **다중 홉 질의•전체 주제 탐색**에 한계가 있음.

#### 한줄 요약
- **개체•관계•커뮤니티 요약** 기반 근거 탐색

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **지식 그래프**: 개체를 노드, 관계를 간선으로 표현한 지식 구조이다.
- **커뮤니티 요약**: 밀접하게 연결된 개체 집단의 주요 주제와 관계를 압축한 근거로 정의된다.

</details>

- **개체•관계•출처**: 원문 사실과 그래프 근거 연결
- **지역•전역 검색**: 주변 관계와 커뮤니티 요약 탐색
- **추출•갱신 오류**: 정확도 저하와 구축 비용 증가

#### 한줄 요약

- **관계 탐색•추출 오류 전파**를 함께 검증

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **개체명 통합**: 표기가 다른 별칭을 동일 식별자로 연결하는 과정이다.
- **관계 추출**: 원문에서 개체 사이의 의미 관계와 그 근거 문장을 식별하는 과정을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.

</details>

```text
                      [그래프 저장소]
                       /           \
                 [정규화부]       [검색기]
                      |
                   [추출기]
                      |
                [텍스트•출처]
```

선의 의미: 그래프 저장소는 정규화된 개체•관계와 검색 인터페이스를 함께 보유하고, 정규화부는 추출기가 텍스트•출처에서 식별한 개체•관계를 통합한다.

| 구성요소 | 책임 |
|:---|:---|
| 텍스트•출처 | **원문 단위•문서 위치** 보존 |
| 추출기 | **개체•관계•원문 근거** 추출 |
| 정규화부 | **별칭 통합•동명이인 분리** |
| 그래프 저장소 | **관계•근거•커뮤니티 버전** 관리 |
| 검색기 | **개체 이웃•전체 요약 경로** 선택 |


#### 한줄 요약
- **텍스트•추출•정규화•그래프•검색** 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **지역 검색**: 특정 개체 주변의 이웃과 관계에서 세부 근거를 찾는 방식이다.
- **전역 검색**: 그래프 커뮤니티 요약을 사용해 전체 주제와 경향을 찾는 방식을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.

</details>

```text
원문•관계 추출기
   │ 1. 개체•관계 추출•정규화
   ▼
그래프 저장소 ── 2. 커뮤니티 탐지•요약 생성 ──▶ 요약기
      ▲                  커뮤니티 요약                  │
      └─────────────────────────────────────────────────┘
검색기
   │ 3. 지역•전역 경로 선택
   ▼
그래프 저장소
   │ 4. 관계•요약 근거 탐색
   │ 원문 연결 근거
   ▼
생성기
   └ 5. 출처 기반 답변 생성
```

### 동작 원리

1. 개체•관계 추출•정규화: 별칭•동명이인을 구분해 관계를 연결함.
2. 커뮤니티 탐지•요약 생성: 연결 집단별 **전역 주제**를 구성함.
3. 지역•전역 경로 선택: 질의 범위에 맞는 그래프 탐색을 결정함.
4. 관계•요약 근거 탐색: 다중 홉 관계와 커뮤니티 요약을 검색함.
5. 출처 기반 답변 생성: 그래프 근거를 원문과 대조해 답변을 구성함.

#### 한줄 요약
- **그래프 구축•지역•전역 검색•원문 대조** 수행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **벡터 검색 증강 생성(Vector Retrieval-Augmented Generation, 벡터 RAG)**: 질의와 문서 조각의 임베딩 유사도를 기준으로 근거를 검색하는 방식을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.
- **하이브리드 검색 증강 생성(Hybrid Retrieval-Augmented Generation, 하이브리드 RAG)**: 벡터•어휘•그래프 신호를 결합하는 방식이다.

</details>

RAG는 근거 단위에 따라 그래프형•벡터형•하이브리드형으로 구분한다.

| RAG 방식 | GraphRAG | 벡터 RAG | 하이브리드 RAG |
|:---|:---|:---|:---|
| 적용 기준 | **다중 홉•전역 질의** | **독립 사실 질의** | **원문**•**관계** 병행 |
| 핵심 특징 | 관계•**커뮤니티 요약** | 의미 유사 **청크 검색** | 청크•**그래프 문맥** 결합 |
| 한계 | 추출 오류•**구축 비용** | 다중 **관계 누락** | 병합 충돌•**근거 불일치** |

#### 한줄 요약
- **질의 관계성•근거 단위**로 RAG 방식 구분

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **개체 중복**: 같은 대상을 서로 다른 개체로 저장해 관계가 분산되는 문제로 정의된다.
- **관계 추출 오류**: 원문에 없는 관계를 만들거나 실제 관계를 빠뜨리는 문제이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.
- **관계 노후화**: 원문 변경 뒤 그래프 연결과 요약이 갱신되지 않는 문제이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 별칭 분산에 따른 **개체 중복** | **개체명 통합•식별자 분리** | 잘못된 **관계 연결 감소** |
| 관계 추출 오류 | 관계마다 **원문 출처** 연결 | 그래프 **근거 검증** |
| 갱신 누락에 따른 **관계 노후화** | 원문 변경과 **그래프•요약 갱신 연계** | **최신 관계 유지** |

#### 한줄 요약

- **개체 중복•관계 오류•노후화**를 원문으로 검증

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **관계 정확성**: 그래프의 간선이 원문에서 확인되는 실제 관계를 올바르게 나타내는 정도이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.
- **근거 추적성**: 검색 결과의 개체와 관계를 원문 출처까지 역으로 확인할 수 있는 성질을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.

</details>

- 다중 홉•전역 질의는 **GraphRAG**, 독립 사실 질의는 **벡터 RAG** 선택

#### 한줄 요약

- **질의 관계성•전역 범위•구축 비용**으로 RAG 방식 결정
