## 미리 알고가기

- **RAG (Retrieval-Augmented Generation)**: 검색 근거를 문맥에 넣어 답변 생성
- **Graph RAG**: 개체·관계 그래프를 검색 근거로 사용하는 방식
- **다중 홉 질의 (Multi-Hop Query)**: 여러 관계를 차례로 따라가는 질문
- **개체명 통합 (Entity Resolution)**: 별칭을 같은 개체 식별자로 연결



## Ⅰ. 개요

- **정의/개념**: 개체·관계 그래프와 요약을 검색 근거로 활용
- **배경/필요성**: 분산된 관계와 전체 주제를 구조적으로 탐색

### 쉽게 이해하기 (학습용)

- 개체와 사건을 점과 선으로 연결해 주변 관계나 전체 주제 요약을 찾습니다.

## Ⅱ. 특징

- 개체·관계를 추출하고 원문 근거와 연결해 출처를 남긴다.
- 별칭을 통합하고 동명이인을 분리해 연결 오류를 줄인다.
- 커뮤니티별 요약을 만들어 전역 검색 단위로 사용한다.
- 지역 검색은 이웃 관계를, 전역 검색은 요약을 종합한다.
- 추출 오류 전파와 그래프 구축·갱신 비용을 관리한다.

### 쉽게 이해하기 (학습용)

- 관계 지도는 탐색을 돕지만 잘못 추출한 개체나 관계가 오류를 전파할 수 있습니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 텍스트·출처 | 원문 단위와 문서 위치 보존 |
| 추출기 | 개체·관계와 원문 근거 추출 |
| 정규화부 | 별칭 통합 및 동명이인 분리 |
| 그래프 저장소 | 관계·근거·커뮤니티 버전 관리 |
| 검색기 | 개체 이웃·전체 요약 경로 선택 |

```text
원문근거
├─ 관계그래프
│   └─ 지역검색
└─ 집단요약
    └─ 전역검색
```

### 쉽게 이해하기 (학습용)

- 개체 관계와 커뮤니티 요약을 질문 범위에 맞춰 검색합니다.

## Ⅳ. 원리 및 절차 흐름도

```text
문서준비
  ↓
지식추출
  ↓
그래프구축
  ↓
질의검색
  ↓
근거생성
```

| 절차 | 설명 |
|:---|:---|
| 문서준비 | 문서를 나누고 권한·시점·출처 기록함 |
| 지식추출 | 개체·관계와 원문 근거를 추출함 |
| 그래프구축 | 개체 정규화 및 집단 요약 생성 |
| 질의검색 | 지역·전역 검색으로 근거 탐색 |
| 근거생성 | 그래프 근거를 원문과 대조해 답변함 |

### 쉽게 이해하기 (학습용)

- 관계 그래프를 만들고 지역·전역 검색 결과를 원문과 대조합니다.

## Ⅴ. 종류 및 비교

| 판단 기준 | 벡터 RAG | GraphRAG | 하이브리드 RAG |
|:---|:---|:---|:---|
| 검색 단위 | 의미 유사 청크 | 관계·집단 요약 | 청크·그래프 문맥 |
| 적용 기준 | 독립 사실 질의 | 관계·전역 질의 | 원문·관계를 병행 |
| 주요 위험 | 관계 누락 | 추출 오류·비용 | 병합 충돌·불일치 |

> 요약: GraphRAG는 구조적 지식과 계층 요약을 병행함

### 쉽게 이해하기 (학습용)

- 벡터·그래프·하이브리드 RAG는 검색 근거 단위가 다릅니다.

## Ⅵ. 실무 사례

- 개체 경로마다 근거·시점을 연결하고 인과 단정 방지
- 커뮤니티별 답과 근거 범위를 종합해 전역 질의 처리
- 변경된 개체·관계·요약만 갱신하고 버전 검사
- 추출 정확도·근거 충실도·비용을 벡터 RAG와 비교

### 쉽게 이해하기 (학습용)

- 그래프를 갱신할 때 삭제된 관계도 반영하고 모든 연결을 원문과 대조합니다.

## Ⅶ. 결론

- GraphRAG는 추출 오류·최신성·구축 비용을 검증한다.

### 쉽게 이해하기 (학습용)

- 정확한 그래프와 최신 원문의 연결을 유지해야 신뢰할 수 있는 답을 만듭니다.
