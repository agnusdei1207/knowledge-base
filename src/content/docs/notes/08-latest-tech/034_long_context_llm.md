## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **장문맥 대규모 언어 모델(Long Context Large Language Model, Long Context LLM)**: 확장된 컨텍스트 윈도우에서 멀리 떨어진 토큰의 관계와 근거를 함께 처리하는 언어 모델을 말한다.
- **장거리 의존성**: 시퀀스에서 멀리 떨어진 정보들이 의미나 판단에 서로 영향을 주는 관계이다.

</details>

- 정의/개념: 확장된 컨텍스트 윈도우에서 많은 토큰과 장거리 의존성을 한 번에 처리하는 **Long Context LLM**임.
- 배경/필요성: 문서 분할은 여러 구간에 걸친 전역 관계와 중간 근거 연결을 단절시킬 수 있음.

#### 한줄 요약

- 확장 문맥에서 **장거리 의존성•근거**를 연결하는 모델이다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **위치 표현 확장**: 학습한 길이 밖에서도 토큰의 순서와 거리를 해석하도록 위치 규칙을 조정하는 기법로 정의된다.
- **회전 위치 임베딩(Rotary Position Embedding, RoPE)**: Q•K 회전으로 상대적 거리를 반영하는 기법이다.
- **희소 어텐션(Sparse Attention)**: 선택된 토큰 관계만 계산하여 비용을 줄이는 방식을 말한다.
- **윈도우 어텐션(Window Attention)**: 일정 범위 안의 토큰 관계만 계산하는 방식을 의미한다.
- **유효 문맥 길이**: 최대 입력 한도 중 모델이 실제로 근거를 정확히 회수하고 결합할 수 있는 범위로 정의된다.

</details>

![문맥 길이에 따른 어텐션 상호작용 증가 개념도](/study/diagrams/long-context-attention-growth.svg)

> 파란 전체 어텐션 선은 문맥 길이의 제곱으로 증가하지만 붉은 고정 윈도우 선은 선형 증가하며, 정규화한 가정값이지 실측값은 아니다.

- **위치 표현 확장**으로 학습 범위를 넘는 토큰 순서 해석이 핵심임.
- **희소 어텐션**으로 선택 관계만을 계산함.
- **윈도우 어텐션**으로 지역 관계만을 계산함.
- 위치별 근거를 회수•결합하는 **유효 문맥 길이**를 확인함.

#### 한줄 요약

- 최대 길이보다 **유효 문맥 길이•근거 회수율**이 핵심이 핵심이다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **위치 보간(Position Interpolation)**: 긴 위치 인덱스를 학습된 범위 안으로 비례 압축하여 입력 길이를 확장하는 기법을 의미한다.
- **프리필(Prefill)**: 장문 입력의 어텐션 상태를 먼저 계산하는 처리이다.
- **키-값 캐시(Key-Value Cache, KV Cache)**: 계산한 상태를 후속 토큰 생성에서 재사용하는 메모리을 의미한다.

</details>

```text
                       [장문 학습 데이터]
                        /           \
              [위치 표현 계층]   [효율적 어텐션 계층]
                        \           /
                       [프리필•KV Cache]
                              |
                       [장문맥 평가 계층]
```

선의 의미: 장문 학습 데이터는 위치 표현과 효율적 어텐션의 학습 기반이고, 두 계층의 계산 상태는 프리필•KV Cache에 결합되며, 장문맥 평가 계층은 전체 구성의 유효 문맥 품질을 검증한다.

| 구성요소 | 책임 |
|:---|:---|
| 위치 표현 계층 | **위치 보간**•스케일링으로 위치 확장 |
| 효율적 어텐션 계층 | **희소 어텐션**•**윈도우 어텐션** 적용 |
| 장문 학습 데이터 | 멀리 떨어진 근거 연결 과업 제공 |
| 프리필•KV Cache | **프리필**과 **KV Cache**로 상태 재사용 |
| 장문맥 평가 계층 | 위치별 인출•다중 근거•지연 검증 |

#### 한줄 요약

- 위치•어텐션•캐시•평가를 함께 확장한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **컨텍스트 윈도우(Context Window)**: 한 번의 추론에서 모델이 입력과 출력으로 처리할 수 있는 최대 토큰 범위이다.
- **장거리 근거 회수**: 긴 입력의 여러 위치에서 질문과 관련된 정보를 찾아 생성 문맥에 반영하는 과정이다.
- **장문 입력 구성**: 지시•원문•출력 여유를 컨텍스트 윈도우 안에 배치하는 절차이다.
- **장거리 관계 계산**: 전체 또는 희소•윈도우 범위에서 관련 토큰의 정보를 결합하는 절차이다.
- **프리필•KV Cache 생성**: 장문 입력을 병렬 계산하고 후속 생성용 상태를 저장하는 절차을 의미한다.
- **장거리 근거 회수•결합**: 긴 입력의 여러 위치에서 관련 정보를 찾아 하나의 응답 근거로 통합하는 절차을 말한다.

</details>

```text
장문 입력 요청
      │
      ▼
문맥 처리기
      │ 1. 장문 입력 구성
      │ 2. 위치 표현 확장
      │ 확장 위치 입력 전달
      ▼
어텐션•KV Cache
      │ 3. 장거리 관계 계산
      │ 4. 프리필•KV Cache 생성
      │ 문맥 상태 제공
      ▼
모델
      │ 5. 장거리 근거 회수•결합
      │ 근거 기반 응답
      ▼
사용자
```

1. **장문 입력 구성**: 지시•원문•출력 여유를 컨텍스트 윈도우에 배치함.
2. **위치 표현 확장**: **RoPE**와 **위치 보간**으로 학습 길이 밖 관계를 부여함.
3. **장거리 관계 계산**: 전체 또는 희소•윈도우 범위의 관련 토큰을 결합함.
4. **프리필•KV Cache 생성**: 입력 병렬 처리와 생성 단계 상태를 재사용함.
5. **장거리 근거 회수•결합**: 멀리 떨어진 정보의 인출•결합 결과를 검증함.

#### 한줄 요약

- **위치 확장•관계 계산•KV Cache**로 근거 결합이 핵심이다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **직접 장문 입력**: 원문 전체를 하나의 넓은 컨텍스트에 넣어 전역 관계를 모델이 직접 처리하는 방식을 의미한다.
- **검색 증강 생성(Retrieval-Augmented Generation, RAG)**: 질의와 관련된 외부 문서 조각을 검색해 모델 입력에 근거로 제공하는 방식을 의미한다.

</details>

- **Long Context LLM 기반 직접 장문 입력** 및 **RAG** 사이를 전역 관계 분석과 선택 검색 기준으로 구분함.

| 비교 기준 | 직접 장문 입력 | RAG |
|:---|:---|:---|
| 적용 기준 | 전체 문서 전역 관계 분석 | 대규모•갱신 지식 선택 검색 |
| 핵심 특징 | 원문 전체 단일 문맥 처리 | 관련 문서 조각 검색 후 주입 |
| 한계 | 프리필•KV 캐시 비용과 중간 근거 손실 | 검색 누락•문서 관계 단절 |

#### 한줄 요약

- 전역 관계는 **직접 장문 입력**, 선택 근거는 **RAG**가 핵심이다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **건초더미 속 바늘 찾기(Needle in a Haystack, NIAH)**: 긴 문맥의 여러 위치에 숨긴 특정 근거를 얼마나 정확히 회수하는지 확인하는 평가이다.
- **접두사 캐싱(Prefix Caching)**: 여러 요청이 공유하는 입력 앞부분의 프리필 결과를 저장해 재사용하는 기법로 정의된다.
- **동적 배치(Dynamic Batching)**: 도착 시점과 길이가 다른 요청을 실행 중에 묶어 연산 자원 사용률을 높이는 방식을 말한다.
- **민감정보 마스킹(Data Masking)**: 입력의 개인정보나 비밀값을 제거하거나 대체값으로 가려 노출을 줄이는 보호 기법을 말한다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 이차 어텐션 비용 | **희소 어텐션**•**윈도우 어텐션**과 입력 예산 적용 | 연산량•메모리 증가 억제 |
| 중간 정보 회수 저하 | 위치별 **NIAH**•다중 근거 평가 | **유효 문맥 길이** 검증 |
| 프리필 지연•KV Cache 압박 | **접두사 캐싱**•**동적 배치**와 캐시 한도 | 동시 처리량 향상 |
| 접근 권한 혼입 | 권한 필터와 **민감정보 마스킹** | 정보 노출 방지 |

#### 한줄 요약

- 근거 회수율•지연•메모리•권한을 통합 평가한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **장문 처리 방식 선택 기준**: 전역 의존성에는 직접 장문 입력을, 일부 최신 근거에는 RAG를 적용하는 기준로 정의된다.

</details>

- **장문 처리 방식 선택 기준**에 따라 전역 의존성에는 **직접 장문 입력**, 일부 최신 근거에는 **RAG**를 선택함.

#### 한줄 요약

- 전역 의존성 범위에 따라 직접 입력•RAG를 선택한다.
