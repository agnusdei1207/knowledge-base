## 미리 알고가기

- **양자화(Quantization)**: 촘촘한 자의 실숫값을 성긴 정수 눈금에 맞추듯 가중치·활성값을 제한된 저비트 단계로 변환하는 기법
- **스케일(Scale)·영점(Zero-point)**: 실수 눈금 간격과 실수 0에 대응하는 정수 위치를 정하는 양자화 매개변수
- **세분성(Granularity)**: 하나의 양자화 매개변수를 텐서·채널·그룹 중 어느 범위에서 공유할지 정하는 단위
- **보정 데이터(Calibration Data)**: 운영 입력을 대표해 가중치·활성값의 범위를 관측하는 표본
- **양자화 커널(Quantized Kernel)**: 목표 장치에서 저비트 행렬 연산을 실제 수행하는 실행 코드
- **학습 후 양자화(Post-Training Quantization, PTQ)**: 재학습 없이 보정 데이터로 모델을 양자화하는 방식
- **양자화 인지 학습(Quantization-Aware Training, QAT)**: 학습 중 양자화 오차에 적응하도록 훈련하는 방식
- **활성값 인지 가중치 양자화(Activation-aware Weight Quantization, AWQ)**: 중요 활성값 채널을 고려해 가중치 스케일을 조정하는 방식


## Ⅰ. 개요

- 정의/개념: 가중치·활성값을 낮은 비트 표현으로 변환하는 모델 압축 기법
- 배경/필요성: 고정밀 연산의 **메모리 대역폭·전력 비용** 절감 필요

### 쉽게 이해하기 (학습용)
- 정보를 덜 정밀한 눈금으로 바꿔 저장·계산함

## Ⅱ. 특징

![균일 양자화 매핑](/study/diagrams/quantization-mapping.svg)

> 계단선은 연속 실숫값이 같은 정수 눈금으로 묶이고 양끝에서 포화됨을 나타내며, 명시한 양자화 공식으로 계산한 예시 좌표이지 모델 정확도 실측값은 아니다.

- 연속 실숫값을 유한 단계로 매핑하는 **스케일·영점**
- 채널별 분포와 활성 이상치에 따른 **양자화 오차**
- 저비트 저장과 실제 **정수 커널 가속**의 분리 판단

### 쉽게 이해하기 (학습용)
- 가중치만 줄이는 방식과 중간값까지 줄이는 방식의 효율과 위험은 다름

## Ⅲ. 구조 및 구성요소

```mermaid
block-beta
  columns 3
  observer["분포 관측기"]
  parameter["양자 매개변수"]
  value["저비트 표현"]
  restore["복원 연산"]
  kernel["실행 커널"]
  observer --- parameter
  parameter --- value
  value --- restore
  restore --- kernel
```

| 구성요소 | 책임 |
|:---|:---|
| **분포 관측기** | 대표 표본의 **값 범위** 측정 |
| **양자 매개변수** | **스케일·영점·세분성** 결정 |
| **저비트 표현** | 실숫값의 **정수 코드** 저장 |
| **복원 연산** | 정수 코드의 **근사 실숫값** 변환 |
| **실행 커널** | 장비의 **저정밀 연산** 수행 |

### 쉽게 이해하기 (학습용)

- 스케일과 영점을 정해 원래 값을 작은 숫자 범위로 옮긴다

## Ⅳ. 흐름도

```mermaid
sequenceDiagram
  participant E as 평가기
  participant O as 관측기
  participant P as 형식 설계기
  participant Q as 변환기
  participant H as 실행 장치
  E->>O: 1. 품질·자원 기준 설정
  O->>P: 2. 대표 분포 관측
  P->>Q: 3. 형식·매개변수 결정
  Q->>H: 4. 양자화·커널 실행
  H-->>E: 5. 품질·자원 검증
```

1. **품질·자원 기준 설정**: 허용 정확도 손실과 **자원 목표** 확정
2. **대표 분포 관측**: 보정 표본으로 **동적 범위** 측정
3. **형식·매개변수 결정**: 대상·비트·**스케일·영점** 선택
4. **양자화·커널 실행**: 저비트 변환과 **장비 연산** 수행
5. **품질·자원 검증**: 정확도·지연·메모리의 **동시 비교**
### 쉽게 이해하기 (학습용)

- 숫자 범위를 재고 눈금 간격을 정한 뒤 실제 칩이 그 숫자로 계산하는지까지 확인함

## Ⅴ. 종류 및 비교

| 구분 | 가중치 전용 PTQ | 가중치·활성값 PTQ | QAT |
|:---|:---|:---|:---|
| 적용 기준 | 메모리 절감 중심 | 정수 연산 가속 | 정확도 보존 우선 |
| 핵심 특징 | 가중치만 저비트 변환 | 가중치·활성값 변환 | 학습 중 양자화 오차 반영 |
| 한계 | 활성값 연산 비용 유지 | 보정 데이터·이상치 민감 | 재학습 비용 증가 |

> 요약: 대상과 학습 환경에 따라 양자화 방식을 선택함

### 쉽게 이해하기 (학습용)

- 학습 후 변환과 학습 중 적응은 비용과 품질 회복력이 다르다

## Ⅵ. 실무 고려사항 및 대책

| 고려사항 | 대책 | 효과 |
|:---|:---|:---|
| 보정 데이터 불일치 | 운영 분포 표본으로 **계층별 범위** 관측 | 범위 왜곡 감소 |
| 활성 이상치 | 채널별 스케일·**클리핑** 적용 | 오차 집중 완화 |
| 커널 미지원 | 장비의 **연산자·비트 형식** 확인 | 실제 지연 개선 |

### 쉽게 이해하기 (학습용)
- Layer별 분포 차이를 고려해 보정을 세분화함

## Ⅶ. 결론
- **분포 오차·커널 지원**을 기준으로 PTQ·QAT를 선택해 **품질·자원** 균형 결정

### 쉽게 이해하기 (학습용)
- 낮은 비트보다 품질과 장비 효율을 지키는 형식이 중요함
