## 미리 알고가기

- **양자화 (Quantization)**: 가중치·활성값의 표현 비트를 낮춤
- **학습 후 양자화 (Post-Training Quantization, PTQ)**: 재학습 없이 보정 데이터로 변환함
- **양자화 인지 학습 (Quantization-Aware Training, QAT)**: 양자화 오차를 학습 중 반영함
- **활성값 인지 가중치 양자화 (Activation-aware Weight Quantization, AWQ)**: 중요 채널 스케일을 조정함


## Ⅰ. 개요

- **정의/개념**: 값의 정밀도를 낮춰 저장·연산 절감
- **배경/필요성**: 메모리·속도·전력 효율 개선

### 쉽게 이해하기 (학습용)
- 정보를 덜 정밀한 눈금으로 바꿔 저장·계산함

## Ⅱ. 특징

- 가중치 양자화는 저장량·메모리 이동을 줄인다
- 활성값 양자화는 이상치에 더 민감하다
- PTQ는 사후 보정, QAT는 학습 중 오차에 적응한다
- 비트폭·단위·커널이 실제 가속을 결정한다

### 쉽게 이해하기 (학습용)
- 가중치만 줄이는 방식과 중간값까지 줄이는 방식의 효율과 위험은 다름

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| Scale | 실수 범위를 Grid 간격으로 변환함 |
| Zero-point | 실수 0에 대응할 정수 위치를 정함 |
| Granularity | 눈금 공유 단위를 설정함 |
| Observer | 대표 분포로 범위를 측정함 |
| Kernel | 저정밀 행렬 연산을 실행함 |
```text
실수모델
├─ 범위관측
├─ 양자매개
├─ 저정밀값
└─ 실행커널
```

- Scale은 눈금 간격, Zero-point는 0의 정수 위치임

### 쉽게 이해하기 (학습용)

- 스케일과 영점을 정해 원래 값을 작은 숫자 범위로 옮긴다

## Ⅳ. 원리 및 절차 흐름도

```text
목표설정
↓
형식설계
↓
보정변환
↓
성능검증
```

| 절차 | 설명 |
|:---|:---|
| 목표설정 | 품질·자원 목표를 설정함 |
| 형식설계 | 대상·비트·단위를 정함 |
| 보정변환 | 데이터를 범위를 보정함 |
| 성능검증 | 커널의 품질을 검증함 |
### 쉽게 이해하기 (학습용)

- 숫자 범위를 재고 눈금 간격을 정한 뒤 실제 칩이 그 숫자로 계산하는지까지 확인함

## Ⅴ. 종류 및 비교

| 적용 기준 | Weight-only PTQ | Weight-Activation PTQ | QAT |
|:---|:---|:---|:---|
| 변환 대상 | 가중치만 저비트화 | 가중치·활성 저비트화 | 오차를 학습에 반영 |
| 적용 환경 | 가중치 병목 시 | 정수 커널 확보 시 | PTQ 품질 부족 시 |
| 주요 고려 | 복원 비용 | 활성 이상치 대응 | 배포 수치 일치 |

> 요약: 대상과 학습 환경에 따라 양자화 방식을 선택함

### 쉽게 이해하기 (학습용)

- 학습 후 변환과 학습 중 적응은 비용과 품질 회복력이 다르다

## Ⅵ. 실무 사례

- Calibration Data가 부적절하면 품질이 왜곡됨
- 이상치는 채널별 혹은 혼합 정밀도로 대응함
- 고정밀 Fallback 발생 시 변환 비용을 추적함
- 하드웨어별 조합 변경 시 성능을 재검증함

### 쉽게 이해하기 (학습용)
- Layer별 분포 차이를 고려해 보정을 세분화함

## Ⅶ. 결론
- 양자화는 배포 자원에 맞춰 정밀도를 최적화하는 과정임
- 품질·성능·장비 특성을 고려해 방식을 선택해야 함

### 쉽게 이해하기 (학습용)
- 낮은 비트보다 품질과 장비 효율을 지키는 형식이 중요함
