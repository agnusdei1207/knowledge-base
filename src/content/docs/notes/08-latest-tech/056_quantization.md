## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **양자화(Quantization)**: 가중치와 활성값을 제한된 저비트 단계로 변환하여 메모리•연산 비용을 줄이는 기법을 의미한다.
- **저비트 표현(Low-bit Representation)**: 실숫값을 더 적은 비트의 정수나 부동소수점 값으로 근사한 표현을 말한다.

</details>

- 정의/개념: **양자화**는 가중치•활성값을 저비트 표현으로 변환하는 모델 압축 기법임.
- 배경/필요성: 고정밀 연산의 **메모리 대역폭•전력 비용** 증가로 단말 배포에 제약이 따름.

#### 한줄 요약
- **저비트 눈금**으로 가중치•활성값을 저장•계산한다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **스케일(Scale)**: 실수 범위를 정수 눈금 간격으로 변환하는 계수를 뜻한다.
- **영점(Zero Point)**: 실수 0에 대응하도록 정한 정수 위치를 나타낸다.
- **세분성(Granularity)**: 하나의 양자화 매개변수를 텐서•채널•그룹 중 어느 범위에서 공유할지 정하는 단위를 의미한다.
- **활성값 인지 가중치 양자화(Activation-aware Weight Quantization, AWQ)**: 중요 활성값 채널을 고려하여 가중치 스케일을 조정하는 양자화 방식을 의미한다.

</details>

![균일 양자화 매핑](/study/diagrams/quantization-mapping.svg)

> 계단선은 연속 실숫값이 같은 정수 눈금으로 묶이고 양끝에서 포화됨을 나타내며, 명시한 양자화 공식으로 계산한 예시 좌표이지 모델 정확도 실측값은 아님.

- 연속 실숫값을 유한 단계로 매핑하는 **스케일•영점**이 핵심임.
- 채널별 분포와 활성 이상치에 따른 **양자화 오차**가 핵심임.
- 저비트 저장과 실제 **정수 커널 가속**을 분리하여 판단함.

#### 한줄 요약
- **양자화 대상•세분성•커널 지원**이 효과를 결정한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **보정 데이터(Calibration Data)**: 운영 입력을 대표하여 가중치•활성값의 범위를 관측하는 표본을 말한다.
- **복원 연산(Dequantization)**: 정수 코드를 스케일과 영점으로 근사 실숫값에 대응시키는 변환하는 연산을 뜻한다.
- **양자화 커널(Quantization Kernel)**: 목표 장치에서 저비트 행렬 연산을 실제 수행하는 실행 코드를 의미한다.

</details>

```text
[분포 관측기]──[형식 설계기]──[양자화 변환기]
                                    │
                                 [복원기]──[실행 커널]
```

선의 의미: 분포•형식•코드 변환•복원•실행 책임의 정적 연결을 나타냄.

| 구성요소 | 책임 |
|:---|:---|
| 분포 관측기 | 대표 표본의 **값 범위** 측정함 |
| 형식 설계기 | **스케일•영점•세분성** 결정함 |
| 양자화 변환기 | 실숫값을 **정수 코드**로 변환함 |
| 복원기 | 정수 코드의 **근사 실숫값** 변환함 |
| 실행 커널 | 장비의 **저정밀 연산** 수행함 |

#### 한줄 요약
- **분포•스케일•영점•코드•저정밀 커널**을 구성한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **동적 범위(Dynamic Range)**: 보정 표본에서 관측한 가중치•활성값의 최솟값과 최댓값 범위를 말한다.
- **품질•자원 기준(Quality/Resource Criteria)**: 허용 정확도 손실과 목표 지연•메모리•전력을 함께 정한 평가 기준을 뜻한다.

</details>

```text
기준 관리기
    │ 1. 품질•자원 기준 설정
    ▼
분포 관측기
    │ 2. 대표 분포 측정
    ▼
형식 설계기
    │ 3. 형식•매개변수 설계
    ▼
변환기
    │ 4. 저비트 모델 변환
    ▼
실행 장치
    │ 5. 장치 품질•자원 검증
    ▼
기준 관리기
```

**동작 원리**

1. **품질•자원 기준 설정**: 허용 정확도 손실과 **자원 목표**를 확정함.
2. **대표 분포 측정**: 보정 표본으로 **동적 범위**를 산정함.
3. **형식•매개변수 설계**: 대상•비트•**스케일•영점**을 선택함.
4. **저비트 모델 변환**: 실숫값을 정수 코드와 복원 계수로 변환함.
5. **장치 품질•자원 검증**: 정확도•지연•메모리를 **동시에 비교**함.

#### 한줄 요약
- **기준•분포•형식•변환•실기기 검증**을 수행한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **학습 후 양자화(Post-Training Quantization, PTQ)**: 재학습 없이 보정 데이터로 저비트 변환하는 방식을 뜻한다.
- **가중치 전용 PTQ(Weight-only PTQ)**: 가중치만 저비트로 변환하여 메모리를 줄이는 방식을 의미한다.
- **가중치•활성값 PTQ(Weight-Activation PTQ)**: 가중치와 활성값을 변환하여 정수 연산을 가속하는 방식을 말한다.
- **양자화 인지 학습(Quantization-Aware Training, QAT)**: 학습 중 양자화 오차를 반영하여 저비트 변환 후 정확도를 회복하는 방식을 나타낸다.

</details>

- 재학습 제약은 **PTQ**, 정확도 회복 우선은 **QAT**가 핵심임.

| 구분 | 가중치 전용 PTQ | 가중치•활성값 PTQ | QAT |
|:---|:---|:---|:---|
| 적용 기준 | **메모리 절감** 중심 | **정수 연산 가속** | **정확도 보존** 우선 |
| 핵심 특징 | **가중치**만 저비트 변환 | 가중치•**활성값** 변환 | 학습 중 **양자화 오차** 반영 |
| 한계 | **활성값 연산 비용** 유지 | **보정 데이터•이상치** 민감 | **재학습 비용** 증가 |

> 요약: **양자화 대상•재학습 가능성**에 따라 방식을 선택함.

#### 한줄 요약
- 재학습 제약은 **PTQ**, 품질 민감 과업은 **QAT**가 적합하다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **분포 불일치(Distribution Mismatch)**: 보정 표본의 값 범위가 실제 운영 입력과 달라 양자화 오차가 커지는 문제를 뜻한다.
- **활성 이상치(Activation Outlier)**: 일부 채널의 매우 큰 값이 전체 양자화 눈금을 넓혀 대부분 값의 정밀도를 낮추는 현상을 의미한다.
- **커널 미지원(Kernel Unsupported)**: 장치가 선택한 비트 형식이나 연산자를 직접 실행하지 못해 실제 가속이 발생하지 않는 문제를 말한다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **보정 데이터** 불일치 | 운영 분포 표본으로 **계층별 범위** 관측 | 분포 범위의 **왜곡 감소** |
| **활성 이상치** | 채널별 스케일•**클리핑** 적용 | 양자화 오차의 **집중 완화** |
| **커널 미지원** | 장비의 **연산자•비트 형식** 확인 | 실제 추론 지연 **개선** |

#### 한줄 요약
- **운영 분포•이상치•커널 지원**으로 형식 보정이 핵심이다.
