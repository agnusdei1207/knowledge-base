## 미리 알고가기

- **Concept Drift**: 입력 데이터는 동일하나 정답과의 관계가 변화하는 현상
- **탐지**: 실제 라벨 및 결과 피드백이 필요하여 데이터 드리프트보다 탐지 난이도 높음
- **대응**: 재학습을 넘어 라벨 정의 및 비즈니스 규칙 변경까지 검토 필요
- **$P(Y|X)$**: “피 와이 기븐 엑스”로 읽으며 입력 $X$에 따른 정답 $Y$의 조건부 분포

## Ⅰ. 개요

- **정의/개념**: 입력과 정답의 조건부 관계가 시간에 따라 변한다
- **배경/필요성**: 낡은 예측 규칙의 성능·정책 오류를 막는다

### 쉽게 이해하기 (학습용)

- 같은 입력이라도 환경이 바뀌어 정답과의 관계가 달라지면 기존 판단 규칙이 맞지 않게 된다.

## Ⅱ. 특징

- 입력 분포가 같아도 입력·정답 관계는 변할 수 있다
- 정답 지연은 탐지와 성능 확인 시점을 늦춘다
- 부분 집단 변화는 전체 평균 지표에 숨을 수 있다
- 라벨 정의 변화는 재학습 전에 정책 검토가 필요하다
- 관계 확인 뒤 재학습해야 불필요한 교체를 줄인다

### 쉽게 이해하기 (학습용)

- 사용자 행동이나 정책 변화로 예전 판단 규칙이 맞지 않는지 실제 정답을 받아 확인한다.

## Ⅲ. 아키텍처 및 구성요소

| 설계 요소 | 설명 |
|:---|:---|
| 기준 개념 창 | 학습 시점의 입력-정답 및 성능 기준 |
| 예측 로그 | 시각 및 모델 정보를 포함한 예측 기록 |
| 정답 저장소 | 실제 결과 및 라벨 확정 시각 보관 |
| 드리프트 검출기 | 조건부 관계 변화 및 오류 패턴 분석 |
| 적응 정책 | 라벨 검토, 재학습, 재배포 실행 |

> 요약: 예측·지연 정답으로 관계 변화를 찾아 적응한다

### 쉽게 이해하기 (학습용)

- 예측 기록과 뒤늦게 도착한 정답을 연결해 고객군·시간대별 판단 관계가 달라졌는지 찾는다.

## Ⅳ. 원리 및 절차 흐름도

```text
예측 기록 → 정답 도착 판정
                ├─ 미도착 → 상태 유지
                └─ 도착 → 정답 결합 → 관계 변화 판정
                                             ↓
                                      정책 검토 및 재학습
```

| 절차 | 설명 |
|:---|:---|
| 예측 기록 | 시각·모델 정보와 함께 저장 |
| 정답 판정 | 지연 건 처리 및 대기 |
| 정답 결합 | 시각 기준 예측과 라벨 연결 |
| 관계 판정 | 오류 패턴 및 관계 변화 분석 |
| 정책 검토 | 라벨 정의 수정 및 후보 재학습 |

> 요약: 지연 정답으로 관계를 판정해 정책·모델을 갱신한다

### 쉽게 이해하기 (학습용)

- 정답이 도착한 뒤 예측 관계가 실제로 변했는지 확인하고 라벨 정책을 검토한 후 재학습한다.

## Ⅴ. 종류 및 비교

| 판단 기준 | 개념 드리프트 | 데이터 드리프트 | 라벨 드리프트 |
|:---|:---|:---|:---|
| 변화 대상 | 관계 P(Y|X) | 입력 P(X) | 정답 P(Y) |
| 성립 경계 | 관계가 변함 | 구성이 변함 | 비율이 변함 |
| 확인 정보 | 지연 정답 성능 | 운영 입력 | 정답 및 예측 |

> 요약: 입력·정답·관계 변화별로 대응 방식이 다르다

### 쉽게 이해하기 (학습용)

- 입력 구성 변화와 정답 비율 변화 및 입력·정답 관계 변화를 구분해야 알맞은 대응을 선택할 수 있다.

## Ⅵ. 실무 사례
1. 신용평가는 연체 확정 뒤 고객군별 관계를 판정한다
2. 사기 탐지는 이의 결과 뒤 규칙·모델을 갱신한다

### 쉽게 이해하기 (학습용)

- 신용평가는 연체 결과가 확정된 뒤 고객군별 입력과 연체의 관계가 바뀌었는지 확인한다.
- 사기 탐지는 이의 제기 결과로 라벨 정책을 고치고 관계 변화가 확인되면 모델을 재학습한다.

## Ⅶ. 결론
- 지연 정답으로 관계 변화를 확인해 정책·모델을 갱신한다.

### 쉽게 이해하기 (학습용)

- 입력 변화만 보고 재학습하지 않고 지연된 정답으로 판단 관계 변화를 확인한 뒤 필요한 조치만 수행한다.
