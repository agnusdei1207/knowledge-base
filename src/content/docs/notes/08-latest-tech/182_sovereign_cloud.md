## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **소버린 클라우드(Sovereign Cloud)**: 지정 국가·권역이 데이터와 클라우드 운영·기술의 실질적 통제권을 유지하는 모델이다.
- **데이터 주권**: 데이터가 속한 국가의 법률과 통제 요구를 따르는 원칙이다.

</details>

- 정의/개념: **소버린 클라우드(Sovereign Cloud)** 는 지정 권역이 데이터·운영·기술 통제권을 유지하는 모델
- 배경/필요성: 국내 저장만으로는 외국 법률·원격 관리자·공급 중단의 **통제권 상실** 방지 곤란

#### 한줄 요약

- 데이터 위치뿐 아니라 암호화 키·관리자·적용 법률·비상 이전 권한까지 통제한다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **운영 주권**: 지정된 법인·인력·절차가 관리 접근과 서비스 운영을 통제하는 능력이다.
- **기술 주권**: 공급 중단에도 기술을 유지·대체·이전할 수 있는 능력이다.

</details>

- **1. 데이터 주권**: 저장·처리·전송·삭제와 반출 승인 권한을 지정 권역에서 통제
- **2. 운영 주권**: 현지 법인·인력, 고객 통제 키, 다중 승인으로 외부 관리자 접근 제한
- **3. 기술 주권**: 공급망 투명성과 대체·이전·독립 복구 능력으로 서비스 연속성 확보

#### 한줄 요약

- 데이터·운영자·암호화 키·복구 수단을 지정 관할 안에서 관리한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **고객 통제 키**: 클라우드 제공자가 단독으로 사용하지 못하도록 고객이 생성·보관·폐기 권한을 가진 암호화 키이다.
- **다중 승인**: 관리 접근이나 비상 복호화에 둘 이상의 독립된 승인을 요구하는 통제이다.
- **관할·계약 통제**: 데이터와 운영 인력에 적용될 법률·지역·하도급 조건을 계약과 정책으로 제한하는 통제이다.
- **데이터 경계**: 저장·처리·백업·지원 데이터가 허용된 지역과 시스템 밖으로 나가지 않게 하는 범위이다.
- **현지 운영·종료 계획**: 승인된 인력이 운영하고 계약 종료 시 데이터·키·서비스를 검증 가능하게 이전·폐기하는 체계이다.

</details>

```mermaid
block-beta
  columns 3
  N0["관할·계약"]
  N1["데이터 경계"]
  N2["키·접근 통제"]
  N3["현지 운영"]
  N4["공급망·종료"]
  N0 --- N1 --- N2
  N2 --- N3 --- N4
```

| 구성요소 | 책임 |
|:---|:---|
| 관할·계약 | 제공자·하도급자의 **법 적용·외부 요구 대응** 통제 |
| 데이터 경계 | 데이터·메타데이터의 **저장·처리 위치** 제한 |
| 키·접근 통제 | 고객 통제 키·다중 승인 기반 **접근 철회** 집행 |
| 현지 운영 | 권역 내 인력·도구로 배포와 **보안 대응·복구** 수행 |
| 공급망·종료 | 의존성 추적과 대체 공급·반출 및 **이전 가능성** 보장 |

#### 한줄 요약

- 법적 경계 안에서 데이터·키·관리자·공급망·반출 절차를 함께 운영한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **통제 증적**: 데이터 위치·현지 운영·접근 차단·복구 절차가 실제 작동함을 보여 주는 기록이다.
- **종료 전략**: 계약 종료나 공급 중단 시 데이터와 업무를 다른 환경으로 이전·복구하는 계획이다.

</details>

```mermaid
sequenceDiagram
  participant O as 업무 조직
  participant L as 법무·위험
  participant P as 제공자
  participant A as 감사자
  participant E as 종료 체계
  O->>L: 주권 요구 전달
  L->>P: 1. 주권 통제 조건 전달
  P->>A: 2. 구현 증적 전달
  A->>P: 3. 검증 결과 전달
  P->>E: 4. 종료·이전 자료 전달
  E-->>O: 주권 검증·이전 결과
```

**동작 원리**

1. **주권 통제 조건 전달**: 법률·민감도별 데이터와 **운영·기술 조건** 제공
2. **구현 증적 전달**: 위치·현지 운영·접근 차단의 **통제 증거** 제공
3. **검증 결과 전달**: 계약 권리와 실제 통제의 **일치 여부** 제공
4. **종료·이전 자료 전달**: 반출 권리·대체 공급자의 **복구 자료** 제공

#### 한줄 요약

- 각 단계의 판정 결과가 다음 주체의 실행 조건으로 이어지는 흐름이다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **데이터 레지던시(Data Residency)**: 데이터 저장·처리 위치를 특정 지역으로 제한하는 요구이다.
- **규제 준수 리전**: 특정 지역에서 규제 인증·계약 보호조치를 제공하는 클라우드 운영 구역이다.

</details>

| 구분 | 데이터 레지던시 | 규제 준수 리전 | 소버린 클라우드 |
|:---|:---|:---|:---|
| 적용 대상 | **데이터 위치 제한** | 인증·계약 통제가 필요한 **규제 업무** | 국가·산업의 **독립 통제 업무** |
| 핵심 방식 | 지정 위치의 **저장·처리** | 지역 서비스와 **보호조치** 적용 | 법적·데이터·운영·기술 **주권 결합** |
| 주요 한계 | **원격 접근·법적 관할** 통제 부족 | 본사 운영과 **공급망 의존** | **높은 비용·서비스 선택** 제약 |

#### 한줄 요약

- 적용 기준과 핵심 특징 및 한계를 함께 비교해 대안을 선택한다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **관할권 통제**: 제공자·하도급자·지원 인력에 적용되는 법률과 외부 접근 요구를 계약·기술로 제한하는 능력이다.
- **이전성**: 데이터·구성·운영 절차를 개방 형식으로 반출해 대체 환경에서 복구할 수 있는 성질이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **명목상 지역성** 미검증 시 국내 저장이어도 외부 법·관리자 접근 가능 | 법인·하도급·지원 경로 조사와 고객 승인·기록 기반 접근 | **관할권 통제력** 확보 |
| **키 통제 상실** 미검증 시 제공자가 단독으로 복호화해 데이터 주권 약화 | 고객 관리 키, 키 외부 보관, 다중 승인과 비상 접근 감사 | **단독 복호화 가능성** 제거 |
| **공급자 종속** 미검증 시 제재·계약 종료 시 서비스와 데이터 복구 불가 | 개방 형식, 대체 공급자, 반출 권리와 정기 이전·복구 훈련 | 서비스·데이터 **이전성** 확보 |

#### 한줄 요약

- 핵심 운영 위험마다 실행 가능한 대책과 검증 효과를 함께 확인한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **원격 접근 위험**: 권역 밖의 관리자나 법적 요구가 시스템과 데이터에 접근할 가능성이다.
- **공급망 의존**: 특정 사업자의 소프트웨어·장비·인력 중단이 서비스 지속을 제한하는 상태이다.

</details>

- 외국 관할·원격 접근 위험이 크면 **소버린 클라우드**, 위치 제한만 필요하면 **레지던시** 선택

#### 한줄 요약

- 핵심 판단 기준을 먼저 정한 뒤 적용 범위를 결정하는 것이 중요하다.
