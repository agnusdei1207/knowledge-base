## 미리 알고가기

- **사이드카 프록시(Sidecar Proxy)**: 애플리케이션과 같은 배포 단위에서 통신을 대행하는 보조 프록시
- **서비스 메시(Service Mesh)**: '서비스 메시'로 읽으며, 서비스 간 통신 정책을 제어·집행하는 인프라 계층
- **파드(Pod)**: '파드'로 읽으며, 컨테이너가 네트워크와 저장 공간을 공유하는 쿠버네티스 최소 배포 단위
- **상호 전송 계층 보안(Mutual TLS, mTLS)**: '엠티엘에스'로 읽으며, 통신 양쪽이 인증서를 검증하는 방식

## Ⅰ. 개요

- 정의/개념: 애플리케이션과 같은 배포 단위의 프록시가 **인바운드·아웃바운드 통신 정책을 대행**하는 구조
- **배경/필요성**: 앱별 통신 라이브러리의 **언어별 구현 편차와 정책 갱신 결합을 해소**하기 위해 필요

### 쉽게 이해하기 (학습용)

- 앱마다 통신 전담 비서를 두어 업무 코드와 무관하게 라우팅·인증·관측 정책을 적용하는 방식이다.

## Ⅱ. 특징

- 앱과 프록시는 네트워크를 공유하되 **별도 프로세스로 실행**된다.
- 제어 평면이 경로·신원·정책을 배포하고 **데이터 평면 프록시가 집행**한다.
- 코드 독립성을 얻지만 **워크로드별 자원·시작 시간·장애 경로가 증가**한다.

### 쉽게 이해하기 (학습용)

- 앱별 비서가 세밀한 규칙을 공통 적용하지만 비서의 자원 비용과 장애도 함께 관리해야 한다.

## Ⅲ. 아키텍처 및 구성요소

```text
[제어 평면: 정책·인증서]
          ↓
[Pod: 앱 ↔ 사이드카 프록시] → [대상 서비스]
```

| 설계 요소 | 설명 |
|:---|:---|
| 애플리케이션 | **업무 로직과 통신 요청 생성** |
| 사이드카 프록시 | **통신 중계와 정책 집행** |
| 트래픽 우회 | **앱 통신을 프록시 경로로 전환** |
| 제어 평면 | **경로·신원·인증서 정책 배포** |
| 관측 파이프라인 | **지표·로그·추적 수집** |

> 요약: 앱 트래픽을 사이드카 프록시로 우회해 공통 통신 정책을 집행한다.

### 쉽게 이해하기 (학습용)

- 중앙에서 규칙을 내려주면 각 앱 옆 프록시가 통신을 중계하고 결과를 기록한다.

## Ⅳ. 원리 및 절차 흐름도

```text
주입·배포 → 준비 확인 → 트래픽 우회 → 정책·전달 → 측정·갱신
```

| 절차 | 설명 |
|:---|:---|
| 주입·배포 | 앱과 같은 Pod에 프록시 배치 |
| 준비 확인 | 설정·인증서·포트 상태 확인 |
| 트래픽 우회 | 인바운드·아웃바운드 통신 전환 |
| 정책·전달 | 신원·경로·복원력 정책 집행 |
| 측정·갱신 | 신호 수집과 구성 점진 배포 |

> 요약: 프록시 준비 후 트래픽을 우회하고 정책 집행 결과를 측정한다.

### 쉽게 이해하기 (학습용)

- 프록시가 준비된 뒤에만 통신을 맡기고, 적용 결과를 확인하며 규칙을 갱신한다.

## Ⅴ. 종류 및 비교

| 서비스 통신 정책 배치 | 사이드카 프록시 | 노드 공유 프록시 | 내장 통신 라이브러리 |
|:---|:---|:---|:---|
| 적용 기준 | 워크로드별 세밀 정책 | 노드 단위 자원 절감 | 앱의 직접 통신 제어 |
| 핵심 특징 | Pod별 독립 프록시 | 노드별 공유 프록시 | 앱 코드에 기능 포함 |
| 한계 | 자원·시작·장애 경로 증가 | 공유 장애·격리 한계 | 언어 결합·갱신 부담 |

> 요약: 정책 격리 수준, 프록시 자원, 앱 코드 결합도를 기준으로 선택한다.

### 쉽게 이해하기 (학습용)

- 개인 비서, 공용 안내원, 직접 처리 중 필요한 통제 수준과 비용에 맞는 방식을 고른다.

## Ⅵ. 실무 사례

1. **Istio·Envoy 기반 서비스 통신 정책 집행**
2. **구형 앱에 mTLS 인증·인증서 교체 적용**

### 쉽게 이해하기 (학습용)

- Envoy가 앱 코드 밖에서 라우팅·보안 정책을 공통 적용한다.
- 구형 앱도 사이드카를 통해 상호 인증을 적용할 수 있다.

## Ⅶ. 결론

- 사이드카의 핵심은 **코드 독립 통신 정책 집행**이며, 대가는 **워크로드별 프록시 비용**이다.

### 쉽게 이해하기 (학습용)

- 공통 정책의 이득과 프록시 자원·장애 비용을 함께 판단해야 한다.
