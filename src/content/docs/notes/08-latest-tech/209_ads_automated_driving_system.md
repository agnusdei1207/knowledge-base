## 미리 알고가기

- **에이디에스(Automated Driving System, ADS)**: 자동화된 주행 시스템이라는 이름으로, 특정 운행 조건에서 전체 동적 주행 과업을 수행하는 체계
- **오디디(Operational Design Domain, ODD)**: 운행 설계 영역이라는 뜻으로, 도로·날씨·속도 등 ADS가 작동하도록 설계된 조건 범위
- **디디티(Dynamic Driving Task, DDT)**: 동적 주행 과업이라는 뜻으로, 조향·가감속·주변 객체 및 사건 탐지·대응을 포함
- **최소위험기동(Minimal Risk Maneuver, MRM)**: 고장·ODD 이탈 시 위험을 낮추기 위한 제어 동작이며, 그 결과 도달한 안정 상태가 최소위험상태(MRC)



## Ⅰ. 개요

- **정의/개념**: ODD 안에서 전체 동적 주행을 수행하는 시스템
- **배경/필요성**: 운전자 지원과 자율주행의 혼동으로 발생하는 작동 범위·비상 대응 주체의 불명확성을 해소

### 쉽게 이해하기 (학습용)

- 자율주행 등급은 차의 별명이 아니라 지금 켠 기능이 어느 조건에서 보고 운전하는지를 나타냄

## Ⅱ. 특징

- **전체 DDT 수행**: ADS가 조향·가감속·객체 및 사건 대응을 맡는다.
- **ODD 제한**: 도로·날씨·속도 등 정의된 조건에서만 작동한다.
- **Fallback 주체**: L3는 운전자, L4 이상은 시스템이 비상 대응한다.

### 쉽게 이해하기 (학습용)

- ODD에 따라 주행 범위를 정하고, 범위를 벗어나거나 고장 시 누가 운전할지 미리 약속함

## Ⅲ. 아키텍처 및 구성요소

```text
[ODD·System Availability]
          ↓
        [ADS]
        ├─ Normal DDT
        │  └─ [Perception·OEDR → Plan·Control]
        └─ Fallback
           └─ [Safety Monitor → MRM → MRC]
```

| 설계 요소 | 설명 |
|:---|:---|
| ODD·기능 관리자 | 운행 조건과 기능 가용성을 판단함 |
| 인지·OEDR 계층 | 객체·사건을 탐지하고 대응함 |
| 예측·계획·제어 계층 | 경로·행동을 정해 차량을 제어함 |
| DDT fallback 계층 | 고장·영역 이탈 시 MRM을 수행함 |
| 안전·기록·지원 계층 | 상태 감시·증적·원격 지원을 제공함 |

> 요약: 운용 영역과 고장을 감시하고 단계별 안전 대응을 완료함.

### 쉽게 이해하기 (학습용)

- 평소 주행 두뇌 옆에 고장과 운행 조건을 지켜보다 안전 대응을 수행하는 별도 두뇌가 있음

## Ⅳ. 원리 및 절차 흐름도

```text
ODD·상태 확인 → ADS 활성화 → 전체 DDT 수행
                                  ↓
경계·고장 판정 → DDT fallback → MRC·기록
```

| 절차 | 설명 |
|:---|:---|
| ODD·상태 확인 | 도로·날씨·속도와 시스템 가용성을 확인함 |
| ADS 활성화 | 운전자 요청과 진입 조건 충족 시 기능을 시작함 |
| 전체 DDT 수행 | 인지·판단·조향·가감속을 시스템이 수행함 |
| 경계·고장 판정 | ODD 이탈과 기능 고장을 지속 감시함 |
| DDT fallback | 운전자 인계 또는 MRM을 실행함 |
| MRC·기록 | 안전 상태 도달 후 원인과 대응을 기록함 |

> 요약: ODD 내 DDT 수행과 경계·고장 대응을 연결

### 쉽게 이해하기 (학습용)

- 자율주행 중에도 조건을 확인하고 문제가 생기면 사람이나 시스템이 안전하게 마무리함

## Ⅴ. ADS 자동화 수준 비교

| 판단 기준 | SAE L3 | SAE L4 | SAE L5 |
|:---|:---|:---|:---|
| 적용 기준 | 인계 가능한 제한 ODD | 무인 운행 가능한 제한 ODD | ODD 제한 없는 무인 운행 |
| 핵심 특징 | 운전자에게 fallback 요청 | 시스템이 fallback 수행 | 모든 조건에서 시스템 운전 |
| 한계 | 인계 지연·준비 부족 | ODD 밖 운행 불가 | 모든 환경 대응 난도 |

> 요약: L3 사람 인계와 L4·L5 시스템 대응 구분

### 쉽게 이해하기 (학습용)

- L3은 사람이 이어받고 L4 이상은 지정 구역 내에서 차가 끝까지 안전하게 처리함

## Ⅵ. 실무 사례

1. **고속도로 정체 구간 L3 기능**

- **운전자 인계**: ODD 이탈 예고 시 충분한 인계 시간을 제공하고 미응답 시 감속·정차함

2. **지오펜스 L4 로보택시**

- **시스템 대응**: 센서 고장·도로 폐쇄 시 우회하거나 MRM으로 MRC에 도달함

### 쉽게 이해하기 (학습용)

- 고속도로 정체 구간 L3 기능
- 지오펜스 L4 로보택시

## Ⅶ. 결론

- ODD·fallback 주체로 ADS 등급·운행 범위 결정

### 쉽게 이해하기 (학습용)

- 어디까지 달릴지 명확히 하고 문제 발생 시 약속된 주체가 안전하게 마무리함
