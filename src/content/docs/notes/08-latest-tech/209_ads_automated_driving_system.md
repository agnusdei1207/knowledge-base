## 미리 알고가기

- **ADS (Automated Driving System) 기능**: 특정 ODD 안에서 동적 주행 과업을 수행하는 체계
- **DDT (Dynamic Driving Task) 과업**: 실시간 조향·가감속 및 주변 객체 탐지 과업
- **ODD (Operational Design Domain) 운용조건**: 기능 작동을 위해 정의된 환경 및 기술 범위
- **DDT Fallback 대응**: 고장이나 ODD 이탈 발생 시 수행하는 안전 대응
- **MRM (Minimal Risk Maneuver) 동작**: 위험 최소화를 위해 수행하는 제어 동작
- **MRC (Minimal Risk Condition) 상태**: 안전한 정차 등 도달해야 할 안정된 최종 상태



## Ⅰ. 개요

- **정의/개념**: ODD 안에서 전체 동적 주행을 수행하는 시스템
- **배경/필요성**: 자동 주행의 작동 경계와 인수 책임을 명확화

### 쉽게 이해하기 (학습용)

- 자율주행 등급은 차의 별명이 아니라 지금 켠 기능이 어느 조건에서 보고 운전하는지를 나타냄

## Ⅱ. 특징

- DDT가 조향·인지·대응의 수행 범위를 정한다.
- ODD가 도로·날씨·속도 등 작동 조건을 제한한다.
- fallback이 고장·영역 이탈 시 위험을 낮춘다.
- L3 인수와 L4 최소위험 상태가 책임을 구분한다.

### 쉽게 이해하기 (학습용)

- ODD에 따라 주행 범위를 정하고, 범위를 벗어나거나 고장 시 누가 운전할지 미리 약속함

## Ⅲ. 아키텍처 및 구성요소

```text
[ODD·System Availability]
          ↓
        [ADS]
        ├─ Normal DDT
        │  └─ [Perception·OEDR → Plan·Control]
        └─ Fallback
           └─ [Safety Monitor → MRM → MRC]
```

| 설계 요소 | 설명 |
|:---|:---|
| ODD·기능 관리자 | 운행 조건과 기능 가용성을 판단함 |
| 인지·OEDR 계층 | 객체·사건을 탐지하고 대응함 |
| 예측·계획·제어 계층 | 경로·행동을 정해 차량을 제어함 |
| DDT fallback 계층 | 고장·영역 이탈 시 MRM을 수행함 |
| 안전·기록·지원 계층 | 상태 감시·증적·원격 지원을 제공함 |

> 요약: 운용 영역과 고장을 감시하고 단계별 안전 대응을 완료함.

### 쉽게 이해하기 (학습용)

- 평소 주행 두뇌 옆에 고장과 운행 조건을 지켜보다 안전 대응을 수행하는 별도 두뇌가 있음

## Ⅳ. 원리 및 절차 흐름도

```text
[ODD 진입]
      ↓
[전체 DDT 수행]
      ↓
[연속 감시]
      ↓
[이상 대응(인계/MRM)]
      ↓
[MRC 도달]
```

| 절차 | 설명 |
|:---|:---|
| 1. ODD·상태 확인 | 1. ODD·상태 확인을 수행하고 결과를 검증함 |
| 2. ADS 활성화 | 2. ADS 활성화을 수행하고 결과를 검증함 |
| 3. 전체 DDT 수행 | 3. 전체 DDT 수행을 수행하고 결과를 검증함 |
| 4. 경계·고장 판정 | 4. 경계·고장 판정을 수행하고 결과를 검증함 |
| 5. DDT fallback 실행 | 5. DDT fallback 실행을 수행하고 결과를 검증함 |
| 6. 최소위험상태·기록 | 6. 최소위험상태·기록을 수행하고 결과를 검증함 |

> 요약: ODD 내 DDT 수행과 경계·고장 대응을 연결

### 쉽게 이해하기 (학습용)

- 자율주행 중에도 조건을 확인하고 문제가 생기면 사람이나 시스템이 안전하게 마무리함

## Ⅴ. 종류 및 비교

| 판단 기준 | SAE L3 | SAE L4 | SAE L5 |
|:---|:---|:---|:---|
| 핵심 특징 | 전체 DDT 후 사람에게 fallback 요청 | 제한 ODD에서 시스템 fallback | 모든 도로 조건에서 시스템 운전 |
| 적용 기준 | 인계 가능한 제한 ODD | 무인 운행 가능한 제한 ODD | ODD 제한 없는 무인 운행 |
| 주요 위험 | 인계 지연·운전자 준비 부족 | ODD 밖 운행 불가·MRC 실패 | 미해결 환경의 완전 대응 |

> 요약: L3 사람 인계와 L4·L5 시스템 대응 구분

### 쉽게 이해하기 (학습용)

- L3은 사람이 이어받고 L4 이상은 지정 구역 내에서 차가 끝까지 안전하게 처리함

## Ⅵ. 실무 사례

1. **고속도로 정체 구간 L3 기능**

- **상황**: 운영 병목·위험과 영향 범위를 식별함
- **적용**: 주제별 통제·절차를 대상 환경에 적용함
- **검증**: 성능·품질·위험 지표로 효과를 확인함

2. **지오펜스 L4 로보택시**

- **상황**: 운영 병목·위험과 영향 범위를 식별함
- **적용**: 주제별 통제·절차를 대상 환경에 적용함
- **검증**: 성능·품질·위험 지표로 효과를 확인함

### 쉽게 이해하기 (학습용)

- 고속도로 정체 구간 L3 기능
- 지오펜스 L4 로보택시

## Ⅶ. 결론

- ODD·fallback 주체로 ADS 등급·운행 범위 결정

### 쉽게 이해하기 (학습용)

- 어디까지 달릴지 명확히 하고 문제 발생 시 약속된 주체가 안전하게 마무리함
