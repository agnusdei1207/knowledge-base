## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **벡터 데이터베이스(Vector Database)**: 벡터•식별자•메타데이터와 유사도 검색 색인을 함께 관리하는 검색 특화 저장소다.
- **근사 최근접 이웃(Approximate Nearest Neighbor, ANN)**: 일부 정확도를 양보하고 탐색량을 줄이는 이웃 검색 방식이다.

</details>

- 정의/개념: 벡터•원문•메타데이터와 ANN 색인을 관리하는 **벡터 DB 기반 검색 저장소**
- 배경/필요성: 벡터 전수 비교는 데이터 증가에 따라 **검색 시간•연산량** 급증

#### 한줄 요약

- 비슷한 벡터를 빨리 찾는 색인과 메타데이터의 변경 상태를 함께 관리합니다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **회수율(Recall)**: 관련 이웃 중 검색 결과가 실제로 찾아낸 비율이다.
- **탐색 폭(Search Breadth)**: 근사 최근접 이웃(Approximate Nearest Neighbor, ANN)이 후보를 찾을 때 조사하는 색인 범위로, 넓힐수록 회수율과 지연•메모리 사용이 함께 증가한다.

</details>

- 검색 단위별 벡터•원문•메타데이터•권한의 **연결 관리**
- 근사 최근접 이웃(Approximate Nearest Neighbor, ANN)의 **탐색 폭에 따른 회수율•검색 지연•메모리 절충**
- 삽입•수정•삭제를 반영하는 **저장소•색인•복제본 동기화**

#### 한줄 요약

- 근사 색인은 빠르지만 가까운 항목을 놓칠 수 있고 필터와 갱신도 성능을 바꿉니다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **임베딩(Embedding)**: 텍스트•이미지 같은 대상을 의미나 특징을 나타내는 벡터로 변환한 표현이다.
- **벡터 저장소**: 벡터 식별자와 원문•메타데이터•버전을 함께 보존하는 저장 계층이다.
- **근사 최근접 이웃 색인(Approximate Nearest Neighbor Index, ANN Index)**: 전체 벡터를 비교하지 않고 가까운 후보를 빠르게 찾는 검색 구조이다.
- **거리 함수(Distance Function)**: 코사인•내적•유클리드 거리 등으로 벡터 간 유사성을 계산한다.
- **메타데이터 필터**: 권한•시간•문서 유형 같은 조건으로 검색 가능한 후보 범위를 제한한다.
- **변경 관리**: 삽입•삭제•재임베딩과 색인 버전을 원문 변경에 맞춰 동기화하는 기능이다.

</details>

```mermaid
block-beta
  columns 3
  store["벡터 저장소"]
  index["근사 색인"]
  distance["거리 함수"]
  filter["필터부"]
  change["변경 관리"]
  store --- index
  index --- distance
  distance --- filter
  filter --- change
```

| 구성요소 | 책임 |
|:---|:---|
| **벡터 저장소** | 벡터•원문•권한•시점 연결 |
| **근사 색인** | 벡터 후보 탐색 범위 축소 |
| **거리 함수** | 벡터 간 유사도 계산 |
| **필터부** | 메타데이터로 허용 후보 제한 |
| **변경 관리** | 저장•색인•복제본 버전 추적 |


#### 한줄 요약

- 벡터 저장•근사 색인•필터•변경 관리가 역할을 나눕니다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **메타데이터 필터(Metadata Filter)**: 권한•시점•문서 유형 같은 조건으로 검색 가능한 후보를 제한한다.
- **거리 기반 순위**: 질의 벡터와 후보 벡터의 거리•유사도로 이웃 순서를 정한다.

</details>

```mermaid
sequenceDiagram
  participant Q as 질의 처리기
  participant S as 벡터 저장소
  participant I as 근사 색인
  participant F as 메타데이터 필터
  Q->>F: 질의 벡터•필터 조건 전달
  F->>I: 1. 사전 필터 범위 적용
  I->>I: 2. ANN 이웃 탐색
  I-->>F: 3. 거리 기반 후보 순위 산출
  F->>S: 4. 사후 필터•원문 조회
  S-->>Q: 허용 이웃 문서 반환
```

**동작 원리**

1. **사전 필터 범위 적용**: 권한•시점•문서 유형으로 후보 축소
2. **ANN 이웃 탐색**: 근사 색인으로 가까운 벡터 후보 탐색
3. **거리 기반 후보 순위 산출**: 거리 함수로 이웃 순서 결정
4. **사후 필터•원문 조회**: 부적합 후보를 제거하고 원문 결합

#### 한줄 요약

- 벡터를 색인해 후보를 찾고 수정•삭제 반영 상태를 확인합니다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **전용 벡터 데이터베이스(Dedicated Vector Database)**: 벡터 저장과 근사 색인의 독립 확장에 강점이 있다.
- **관계형 데이터베이스 확장(Relational Database Extension)**: 업무 데이터와 벡터의 트랜잭션 일관성에 강점이 있다.
- **검색 엔진 벡터(Vector Search Engine)**: 역색인과 벡터를 결합한 희소•밀집 혼합 검색에 강점이 있다.

</details>

데이터베이스(Database, DB) 통합 범위와 근사 최근접 이웃(Approximate Nearest Neighbor, ANN) 검색 신호에 따라 전용 벡터형, 관계형 확장형, 검색 엔진형을 선택한다.

| 저장 방식 | 전용 벡터 DB | 관계형 DB 확장 | 검색 엔진 벡터 |
|:---|:---|:---|:---|
| **적용 기준** | 대규모 **독립 확장** | 업무 **일관성** 우선 | **혼합 검색** 우선 |
| **핵심 특징** | 분산 **ANN 색인** 중심 | 관계 데이터•**벡터 통합** | 역색인•**벡터 통합** |
| **한계** | 원문•색인 **동기화 부담** | 대규모 **벡터 확장 제약** | 두 색인의 **자원 경합** |

#### 한줄 요약

- 관계형•검색 엔진•전용 벡터 DB는 통합 범위가 다릅니다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **사전 필터(Pre-filter)**: 근사 최근접 이웃(Approximate Nearest Neighbor, ANN) 탐색 전에 허용 후보를 제한하는 방식이다.
- **사후 필터(Post-filter)**: ANN 결과에서 조건에 맞지 않는 항목을 제거하는 방식이다.
- **색인 전환(Index Cutover)**: 새 임베딩 모델의 색인을 별도로 검증한 뒤 읽기 트래픽을 새 버전으로 바꾸는 절차다.

</details>

필터 선택: 근사 최근접 이웃(Approximate Nearest Neighbor, ANN)의 **사전•사후 필터 비교**, 임베딩 모델 변경: **색인 전환 절차 적용**

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| ANN의 **이웃 누락** | 탐색 폭별 **회수율•지연** 측정 | 회수율 목표에 맞는 **탐색 폭 결정** |
| 필터 후 **후보 부족** | **사전•사후 필터** 방식 비교 | 조건 검색의 **회수율 보존** |
| 삭제된 **벡터 잔존** | 저장소•색인•복제본 **동기화** | 오래된 **후보 반환 방지** |

#### 한줄 요약

- 권한 없는 문서는 제외하고 임베딩 모델을 바꾸면 새 색인을 검증한 뒤 전환합니다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **선택 기준(Selection Criteria)**: 회수율•검색 지연•필터 선택도와 변경 동기화 요구사항이다.

</details>

- 선택 지표: **회수율•지연•필터 선택도**, 색인 방식: ANN, 운영 요구사항: **변경 동기화 보장**

#### 한줄 요약

- 검색 속도뿐 아니라 이웃 누락과 메모리 사용 및 수정•삭제 반영을 확인해야 합니다.
