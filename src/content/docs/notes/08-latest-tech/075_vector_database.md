## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **벡터 데이터베이스(Vector Database)**: 벡터•식별자•메타데이터와 유사도 검색 색인을 함께 관리하는 검색 특화 저장소이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.
- **근사 최근접 이웃(Approximate Nearest Neighbor, ANN)**: 일부 정확도를 양보하고 탐색량을 줄이는 이웃 검색 방식을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.

</details>

- 정의/개념: 벡터•원문•메타데이터와 ANN 색인을 관리하는 **벡터 DB**
- 배경/필요성: 벡터 전수 비교의 **검색 시간•연산량 급증**

#### 한줄 요약
- 유사 벡터 색인과 메타데이터 **변경 상태**를 함께 관리한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **회수율(Recall)**: 관련 이웃 중 검색 결과가 실제로 찾아낸 비율을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.
- **탐색 폭(Search Breadth)**: ANN이 후보를 찾을 때 조사하는 색인 범위이다.

</details>

- **연결 관리**: 벡터•원문•메타데이터•권한 결합
- **탐색 폭 절충**: 회수율•지연•메모리 조정
- **변경 동기화**: 저장소•색인•복제본에 삽입•수정•삭제 반영

#### 한줄 요약

- **ANN 회수율•필터•변경 동기화**가 검색 품질 결정

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **임베딩(Embedding)**: 텍스트•이미지를 의미나 특징 벡터로 변환한 표현이다.
- **벡터 저장소**: 벡터 식별자와 원문•메타데이터•버전을 함께 보존하는 저장 계층을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.
- **근사 최근접 이웃 색인(Approximate Nearest Neighbor Index, ANN Index)**: 전체 비교 없이 가까운 후보를 찾는 구조이다.
- **거리 함수(Distance Function)**: 코사인•내적•유클리드 거리 등으로 벡터 간 유사성을 계산하는 함수이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.
- **메타데이터 필터**: 권한•시간•문서 유형으로 후보를 제한하는 구성요소이다.
- **변경 관리**: 삽입•삭제•재임베딩과 색인 버전을 동기화하는 기능이다.

</details>

```text
                   [변경 관리]
                     /     \
          [벡터 저장소] ----- [근사 색인]
                              /       \
                       [거리 함수]   [필터부]
```

선의 의미: 벡터 저장소와 근사 색인은 동일한 벡터•원문•메타데이터 집합을 공유하고, 근사 색인은 거리 함수와 필터부를 검색 경계로 사용하며 변경 관리는 저장소와 색인의 버전 정합성을 함께 통제하는 정적 검색 구조를 뜻한다.

| 구성요소 | 책임 |
|:---|:---|
| 벡터 저장소 | 벡터•원문•권한•시점 연결 |
| 근사 색인 | 벡터 후보 탐색 범위 축소 |
| 거리 함수 | 벡터 간 유사도 계산 |
| 필터부 | 메타데이터로 허용 후보 제한 |
| 변경 관리 | 저장•색인•복제본 버전 추적 |


#### 한줄 요약
- **저장소•근사 색인•거리•필터•변경 관리** 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **메타데이터 필터(Metadata Filter)**: 권한•시점•문서 유형으로 후보를 제한하는 구성요소이다.
- **거리 기반 순위**: 질의 벡터와 후보 벡터의 거리•유사도로 이웃 순서를 정하는 개념을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.

</details>

```text
질의 처리기 ── 질의 벡터•필터 조건 ──▶ 메타데이터 필터
                                          │ 1. 사전 필터 범위 적용
                                          ▼
                                       근사 색인
                                          │ 2. ANN 이웃 탐색
                                          │ 3. 거리 기반 후보 순위 산출
                                          ▼
                                    메타데이터 필터
                                          │ 4. 사후 필터•원문 조회
                                          ▼
                                     벡터 저장소
                                          └── 허용 이웃 문서 ──▶ 질의 처리기
```

### 동작 원리

1. **사전 필터 범위 적용**: 권한•시점•문서 유형으로 후보를 축소함.
2. **ANN 이웃 탐색**: 근사 색인으로 가까운 벡터 후보를 탐색함.
3. **거리 기반 후보 순위 산출**: 거리 함수로 이웃 순서를 결정함.
4. **사후 필터•원문 조회**: 부적합 후보를 제거하고 원문을 결합함.

#### 한줄 요약
- **사전 필터•ANN•거리 순위•원문 조회** 수행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **전용 벡터 데이터베이스(Dedicated Vector Database)**: 벡터 저장과 근사 색인의 독립 확장에 강점이 있는 방식이며, 이는 구조적 완결성을 높이고 차별화된 성능을 제공하는 기술적 기반이 된다.
- **관계형 데이터베이스 확장(Relational Database Extension)**: 업무 데이터와 벡터의 트랜잭션 일관성에 강점이 있는 방식을 말하며, 실무적 관점에서 안정성과 효율성을 보장하는 주요 기전으로 작용한다.
- **검색 엔진 벡터(Vector Search Engine)**: 역색인과 벡터를 결합한 희소•밀집 혼합 검색에 강점이 있는 방식을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.

</details>

데이터베이스(Database, DB) 통합 범위와 근사 최근접 이웃(Approximate Nearest Neighbor, ANN) 검색 신호에 따라 전용 벡터형, 관계형 확장형, 검색 엔진형을 선택한다.

| 저장 방식 | 전용 벡터 DB | 관계형 DB 확장 | 검색 엔진 벡터 |
|:---|:---|:---|:---|
| 적용 기준 | 대규모 **독립 확장** | 업무 **일관성** 우선 | **혼합 검색** 우선 |
| 핵심 특징 | 분산 **ANN 색인** 중심 | 관계 데이터•**벡터 통합** | 역색인•**벡터 통합** |
| 한계 | 원문•색인 **동기화 부담** | 대규모 **벡터 확장 제약** | 두 색인의 **자원 경합** |

#### 한줄 요약
- **독립 확장•업무 일관성•혼합 검색**으로 저장 방식 구분

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **사전 필터(Pre-filter)**: 근사 최근접 이웃(Approximate Nearest Neighbor, ANN) 탐색 전에 허용 후보를 제한하는 방식을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.
- **사후 필터(Post-filter)**: ANN 결과에서 조건에 맞지 않는 항목을 제거하는 방식이다.
- **색인 전환(Index Cutover)**: 새 색인을 검증한 뒤 읽기 트래픽을 전환하는 절차이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| ANN의 **이웃 누락** | 탐색 폭별 **회수율•지연** 측정 | 회수율 목표에 맞는 **탐색 폭 결정** |
| 필터 후 **후보 부족** | **사전•사후 필터** 방식 비교 | 조건 검색의 **회수율 보존** |
| 삭제된 **벡터 잔존** | 저장소•색인•복제본 **동기화** | 오래된 **후보 반환 방지** |

#### 한줄 요약
- **이웃 누락•필터 후보 부족•삭제 벡터 잔존** 통제

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **선택 기준(Selection Criteria)**: 회수율•검색 지연•필터 선택도와 변경 동기화 요구사항을 의미하며, 시스템의 자율적 판단과 실행을 가능하게 하는 핵심 아키텍처 요소이다.

</details>

- 독립 확장은 **전용 벡터 DB**, 업무 일관성은 **관계형 확장**, 혼합 검색은 **검색 엔진** 선택

#### 한줄 요약
- **확장성•일관성•검색 신호**에 따라 저장 방식 결정
