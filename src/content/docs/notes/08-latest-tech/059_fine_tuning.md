## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **파인튜닝(Fine-Tuning)**: 사전학습 모델의 가중치를 목적 데이터로 추가 학습하여 특정 작업•도메인에 적응시키는 기법으로 정의된다.
- **사전학습 모델(Pre-trained Model)**: 대규모 일반 데이터에서 범용 표현과 능력을 먼저 학습한 기반 모델.

</details>

- 정의: 목적 데이터로 사전학습 모델을 적응시키는 **파인튜닝**이다.
- 배경/필요성: 대규모 일반 코퍼스로 사전학습(Pre-training)된 파운데이션 모델을 특정 엔터프라이즈 업무에 적용할 때 인컨텍스트 러닝(In-Context Learning) 및 단순 프롬프트 엔지니어링에만 의존할 경우, 매 요청마다 긴 지시문과 Few-shot 예시를 전송해야 하는 막대한 토큰 비용, 컨텍스트 길이 제한, 도메인 특화 지식 및 정형 출력 포맷 준수의 극심한 불안정성이 발생하는 한계가 존재함에 따라, 목표 도메인의 고품질 입력-정답 데이터셋을 사용하여 사전학습 모델의 매개변수를 직접 추가 학습시키는 파인튜닝(Fine-Tuning: SFT, PEFT, LoRA, QLoRA) 기술을 도입하여 **도메인 특화 태스크에서의 압도적인 성능 및 출력 형식(JSON/SQL 등)의 완벽한 일관성 확보, 프롬프트 길이 축소를 통한 서빙 추론 지연 및 API 비용의 획기적 절감, 기업 고유 데이터의 안전한 모델 내재화를 통한 프라이빗 AI 모델 구축**을 달성할 필요

#### 한줄 요약
- **목적 데이터**로 행동을 가중치에 새기면 요청당 토큰 비용은 사라지지만 지식 갱신마다 재학습 비용이 되살아나므로, 자주 바뀌는 사실은 미세조정이 아니라 검색으로 다룬다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **지도 파인튜닝(Supervised Fine-Tuning, SFT)**: 입력•정답 쌍으로 목표 출력 행동을 학습하는 방식으로 나타낸다.
- **매개변수 효율적 파인튜닝(Parameter-Efficient Fine-Tuning, PEFT)**: 전체 기반 모델을 동결하고 일부 추가•선택 매개변수만 갱신하는 기술군.
- **파멸적 망각(Catastrophic Forgetting)**: 새로운 학습으로 인해 기존의 범용 능력이 저하되는 현상을 칭한다.
- **전체 파인튜닝(Full Fine-Tuning, Full FT)**: 기반 모델의 전체 매개변수를 갱신하는 기법을 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.

</details>

- **SFT 데이터 분포•품질**: 행동•일반화 범위 결정
- **Full FT•PEFT•프롬프트 튜닝**: 갱신 범위•자원 차이
- **기존 능력 회귀•과적합**: 기준 모델 대비 변화 평가

#### 한줄 요약
- **데이터 품질•갱신 범위** 적응 폭과 비용 결정

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **갱신 매개변수(Trainable Parameters)**: 학습 과정에서 실제로 값을 변경할 전체 가중치•어댑터•소프트 프롬프트의 범위를 나타낸다.
- **목적함수(Objective Function)**: 목표 토큰 손실과 정규화 항을 결합하여 가중치 갱신 방향을 정하는 기준.
- **버전 자산(Versioned Asset)**: 모델•토크나이저•데이터•학습 설정•평가 결과를 추적 가능하게 연결한 패키지로 정의된다.

</details>

```text
[기반 모델 저장소]──[데이터 관리기]──[학습기]
                                        │
                                      [평가기]──[버전 저장소]
```

선의 의미: 기반•데이터•학습•평가•버전 책임 간의 정적 연결 구조임.

| 구성요소 | 책임 |
|:---|:---|
| 기반 모델 저장소 | **가중치•토크나이저 기준** 보관 |
| 데이터 관리기 | **학습•평가 데이터** 분리 |
| 학습기 | 갱신 범위와 **목적함수** 적용 |
| 평가기 | **성능•회귀•안전성** 검증 |
| 버전 저장소 | **모델•데이터•설정** 연결 |

#### 한줄 요약
- **기반 모델•데이터•학습•평가•버전** 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **평가 격리(Evaluation Isolation)**: 학습 데이터와 평가 데이터를 분리하여 데이터 누출 없이 일반화 성능을 측정하는 원칙으로 정의된다.
- **기준 모델 평가(Baseline Model Evaluation)**: 학습 전 목표 과업과 기존 능력의 성능을 기록하여 변경 후 결과와 비교하는 절차를 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.

</details>

```text
평가기
   │ 1. 기준 모델 평가
   ▼
데이터 관리기
   │ 2. 학습•평가 데이터 분리
   ▼
학습기
   │ 3. 갱신 범위•목적함수 학습
   ▼
평가기
   │ 4. 목표•회귀•안전 평가
   │ 5. 버전 등록•배포
   ▼
배포 관리기
```

### 동작 원리

1. 기준 모델 평가: 목표 과업·기존 능력의 **기준치 기록**
2. 학습•평가 데이터 분리: 중복·오염 제거와 **평가 격리**
3. 갱신 범위•목적함수 학습: 선택 매개변수의 **손실 최적화**
4. 목표•회귀•안전 평가: 적응 이득과 **기존 능력 변화 비교**
5. 버전 등록•배포: 모델·데이터·설정의 **추적 연결**

#### 한줄 요약
- **기준•격리•학습•회귀 평가•버전 등록** 수행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **전체 파인튜닝(Full Fine-Tuning, Full FT)**: 모델 전체 매개변수를 갱신하여 적응 폭은 크지만 자원 및 망각 부담이 큰 방식.
- **어댑터 기반 PEFT(Adapter-based PEFT)**: 기반 가중치를 동결하고 작은 작업별 모듈만 갱신하는 기법이다.
- **프롬프트 튜닝(Prompt Tuning)**: 모델 가중치 대신 입력에 붙는 학습 가능한 가상 토큰만 갱신하는 기술을 나타낸다.

</details>

| 파인튜닝 갱신 범위 | 전체 파인튜닝 | 어댑터 기반 PEFT | 프롬프트 튜닝 |
|:---|:---|:---|:---|
| 적용 기준 | **모델 전반 적응 필요** | **작업별 경량 모듈 필요** | **가상 토큰 적응 충분** |
| 핵심 특징 | **전체 매개변수 갱신** | **기반 동결•어댑터 갱신** | **소프트 프롬프트 갱신** |
| 한계 | **메모리•저장•망각 부담** | **구조•적재 관리 필요** | **문맥 사용•표현력 제한** |

#### 한줄 요약
- 갱신 범위·운영 비용에 따른 **파인튜닝 방식 구분**

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **과적합(Overfitting)**: 학습 데이터에는 잘 맞지만 새로운 운영 입력에서 성능이 저하되는 현상.
- **기존 능력 회귀셋(General Ability Regression Set)**: 파인튜닝 뒤 범용 능력과 안전성이 유지되는지 확인하는 고정 평가 모음으로 정의된다.
- **데이터 혼합(Data Mixing)**: 새 과업 데이터와 기존 능력 보존용 데이터를 함께 학습하여 망각을 줄이는 방식이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 과적합 | 검증 분리•**조기 종료•정규화** | 목표 분포 **일반화** |
| 파멸적 망각 | 기존 능력 회귀셋•**데이터 혼합** | 범용 능력 **보존** |

#### 한줄 요약
- **목표 성능•기존 능력•안전성** 통합 회귀 평가

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **전체 파인튜닝 선택 기준(Full Fine-Tuning Selection Criterion)**: 모델 전반의 행동을 크게 바꿀 필요가 있고 충분한 자원이 있을 때 선택하는 기준을 뜻하며, 복잡한 문제 해결과 동적 환경 적응에 필수적인 역할을 수행한다.
- **PEFT 및 프롬프트 튜닝 선택 기준(PEFT & Prompt Tuning Selection Criterion)**: 기반 모델을 공유하며 작업별 자원과 배포 자산을 줄여야 할 때 적용하는 가이드라인을 나타낸다.

</details>

- 범용 사전학습 파운데이션 모델을 특정 산업군 및 기업 고유의 전문 비즈니스 시스템으로 최적화하는 **엔터프라이즈 생성형 AI 엔지니어링의 핵심 기술(Model Fine-Tuning / Supervised Fine-Tuning: SFT / Parameter-Efficient Fine-Tuning: PEFT / LoRA & QLoRA / Catastrophic Forgetting Mitigation)의 표준 프레임워크**로 확고히 자리 잡았으며, 다중 도메인 멀티 어댑터 서빙 체계로 고도화되는 가운데, 실무 프로덕션 파인튜닝 파이프라인 구축 시에는 **단순 데이터 양보다 고품질 정제 데이터 선별(Data Quality over Quantity) 우선, 학습 과정에서 모델의 기존 범용 추론 능력이 파괴되는 파멸적 망각(Catastrophic Forgetting)을 방지하기 위한 일반 데이터 혼합(Data Mixing) 및 회귀 테스트셋 구축, 인프라 비용과 서빙 유연성을 고려한 LoRA/QLoRA 기반 어댑터 모듈화 배포**를 결합하여 완벽한 도메인 적응성과 안정적인 모델 라이프사이클을 완성

#### 한줄 요약
- **적응 폭•자원 제약** 대상 따라 파인튜닝 방식 결정
