## 미리 알고가기

- **파인튜닝 (Fine-Tuning)**: 목적 데이터로 모델 가중치를 조정함
- **파멸적 망각 (Catastrophic Forgetting)**: 새 학습으로 기존 능력이 저하되는 현상임
- **지도 미세조정(Supervised Fine-Tuning, SFT)**: '에스에프티'로 읽고 입력·정답 쌍으로 출력 행동을 학습하는 방식을 표시
- **매개변수 효율 미세조정(Parameter-Efficient Fine-Tuning, PEFT)**: '페프트'로 읽고 일부 매개변수만 갱신하는 기술군을 표시


## Ⅰ. 개요

- **정의/개념**: 사전학습 모델의 매개변수를 목적 데이터로 추가 학습해 **작업·도메인에 적응**
- **배경/필요성**: 프롬프트만으로 일관되게 만들기 어려운 **업무 행동·출력 형식의 반복 적용**

### 쉽게 이해하기 (학습용)
- 사전학습 모델에 회사의 답변 형식과 업무 사례를 추가로 훈련합니다.

## Ⅱ. 특징

- **데이터 분포·품질·목적함수**가 학습할 행동과 일반화 범위를 정한다.
- **전체 FT·PEFT·프롬프트 튜닝**은 갱신 대상과 자원·적응 폭이 다르다.
- **기존 능력 회귀·과적합·안전성 변화**를 기준 모델과 비교해야 한다.

### 쉽게 이해하기 (학습용)
- 학습 데이터가 행동을 바꾸며 갱신 범위에 따라 비용과 기존 능력의 변화 폭이 달라집니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 기반 모델 | 사전학습 및 토크나이저 기준 |
| 학습 데이터 | 목표 출력 및 민감 데이터 구분 |
| 갱신 매개변수 | 전체·어댑터·프롬프트 학습 범위 |
| 목적함수 | 목표 토큰 손실·정규화 설정 |
| 버전 저장소 | 성능·회귀·배포 자산 관리 |
```text
기반모델
├─ 학습자료
├─ 갱신범위
├─ 목적함수
└─ 버전평가
```

### 쉽게 이해하기 (학습용)

- 기반 모델·학습 데이터·갱신 범위·목적함수와 결과 버전을 함께 관리합니다.

## Ⅳ. 원리 및 절차 흐름도

```text
기준 평가
↓
자료 분할
↓
방식 학습
↓
회귀 평가
↓
버전 배포
```

| 절차 | 설명 |
|:---|:---|
| 기준 평가 | 작업·기존 능력 기준치 기록 |
| 자료 분할 | 중복·오염 제거 후 분리 |
| 방식 학습 | 갱신 범위·목적함수로 학습 |
| 회귀 평가 | 작업·기존 능력·안전 평가 |
| 버전 배포 | 모델·데이터·설정 연결 배포 |
### 쉽게 이해하기 (학습용)

- 학습 전후의 목표 작업 성능과 기존 능력의 회귀를 함께 비교합니다.

## Ⅴ. 종류 및 비교

| 파인튜닝 갱신 범위 | 전체 파인튜닝 | 어댑터 기반 PEFT | 프롬프트 튜닝 |
|:---|:---|:---|:---|
| 적용 기준 | 모델 전반 적응 필요 | 작업별 경량 모듈 필요 | 가상 토큰 적응 충분 |
| 핵심 특징 | 전체 매개변수 갱신 | 기반 동결·어댑터 갱신 | 소프트 프롬프트 갱신 |
| 한계 | 메모리·저장·망각 부담 | 구조·적재 관리 필요 | 문맥 사용·표현력 제한 |

> 요약: 적응 범위와 운영 자원에 따라 튜닝 방식을 선택함
### 쉽게 이해하기 (학습용)

- 전체·어댑터·프롬프트 튜닝은 갱신하는 매개변수의 범위와 운영 비용이 다릅니다.

## Ⅵ. 실무 사례

1. 고객지원은 **상담 데이터 학습 후 정확도·범용 능력 비교**
2. 파이프라인은 **모델·데이터·설정 버전과 롤백 연결**

### 쉽게 이해하기 (학습용)
- 상담 업무 성능뿐 아니라 기존 범용 능력도 확인하고 회귀가 크면 이전 버전으로 복구합니다.

## Ⅶ. 결론
- 파인튜닝은 **목표 작업 향상과 기존 능력 회귀**를 함께 평가

### 쉽게 이해하기 (학습용)
- 목표 행동을 학습한 뒤 기존 능력과 안전성이 유지되는지 비교해야 배포할 수 있습니다.
