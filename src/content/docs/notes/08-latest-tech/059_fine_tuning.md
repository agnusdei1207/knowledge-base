## 미리 알고가기

- **파인튜닝 (Fine-Tuning)**: 목적 데이터로 모델 가중치를 조정함
- **파멸적 망각 (Catastrophic Forgetting)**: 새 학습으로 기존 능력이 저하되는 현상임
- **지도 미세조정 (Supervised Fine-Tuning, SFT)**: 정답 쌍으로 출력 행동을 학습함
- **매개변수 효율 미세조정 (Parameter-Efficient Fine-Tuning, PEFT)**: 소수 매개변수만 갱신함


## Ⅰ. 개요

- **정의/개념**: 목적 데이터로 모델 매개변수를 조정하는 학습
- **배경/필요성**: 업무 행동·문체를 반복 가능하게 내재화

### 쉽게 이해하기 (학습용)
- 사전학습 모델에 회사의 답변 형식과 업무 사례를 추가로 훈련합니다.

## Ⅱ. 특징

- 학습 데이터의 분포·품질이 새 행동 범위를 정한다.
- 전체 조정은 적응 폭과 자원 요구가 모두 크다.
- PEFT는 기반 가중치를 고정하고 일부만 갱신한다.
- 새 학습은 기존 능력의 파멸적 망각을 일으킬 수 있다.

### 쉽게 이해하기 (학습용)
- 학습 데이터가 행동을 바꾸며 갱신 범위에 따라 비용과 기존 능력의 변화 폭이 달라집니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 기반 모델 | 사전학습 및 토크나이저 기준 |
| 학습 데이터 | 목표 출력 및 민감 데이터 구분 |
| 갱신 매개변수 | 전체·어댑터·프롬프트 학습 범위 |
| 목적함수 | 출력 차이 반영 학습 |
| 버전 저장소 | 성능·회귀·배포 자산 관리 |
```text
기반모델
├─ 학습자료
├─ 갱신범위
├─ 목적함수
└─ 버전평가
```

### 쉽게 이해하기 (학습용)

- 기반 모델·학습 데이터·갱신 범위·목적함수와 결과 버전을 함께 관리합니다.

## Ⅳ. 원리 및 절차 흐름도

```text
기준평가
↓
자료분할
↓
방식학습
↓
회귀평가
↓
버전배포
```

| 절차 | 설명 |
|:---|:---|
| 기준평가 | 작업·능력 기준치 기록 |
| 자료분할 | 오염 제거 후 자료 분할 |
| 방식학습 | 갱신 범위 맞춤 학습 |
| 회귀평가 | 작업·능력·안전성 평가 |
| 버전배포 | 설정과 모델 연결 배포 |
### 쉽게 이해하기 (학습용)

- 학습 전후의 목표 작업 성능과 기존 능력의 회귀를 함께 비교합니다.

## Ⅴ. 종류 및 비교

| 기준 | 전체 파인튜닝 | 어댑터 기반 PEFT | 프롬프트 튜닝 |
|:---|:---|:---|:---|
| 학습 범위 | 전체 매개변수 | 삽입 어댑터 | 프롬프트 벡터 |
| 운영 특성 | 적응 폭·비용 큼 | 기반 모델 공유 | 추가 데이터 소량 |
| 적용 환경 | 모델 전반 변화 시 | 작업별 분리 시 | 행동 유도 시 |

> 요약: 적응 범위와 운영 자원에 따라 튜닝 방식을 선택함
### 쉽게 이해하기 (학습용)

- 전체·어댑터·프롬프트 튜닝은 갱신하는 매개변수의 범위와 운영 비용이 다릅니다.

## Ⅵ. 실무 사례

- 고객지원: 상담 기록으로 어댑터 학습 후 정확도·일반성 비교
- 파이프라인: 모델·데이터 버전 관리 및 회귀 시 롤백 수행

### 쉽게 이해하기 (학습용)
- 상담 업무 성능뿐 아니라 기존 범용 능력도 확인하고 회귀가 크면 이전 버전으로 복구합니다.

## Ⅶ. 결론
- 파인튜닝은 목표 범위와 기존 능력 회귀를 검증한다.

### 쉽게 이해하기 (학습용)
- 목표 행동을 학습한 뒤 기존 능력과 안전성이 유지되는지 비교해야 배포할 수 있습니다.
