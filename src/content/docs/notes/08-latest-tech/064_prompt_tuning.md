## 미리 알고가기

- **프롬프트 튜닝(Prompt Tuning)**: 동결 모델의 입력 앞에 붙는 소프트 프롬프트 임베딩만 학습
- **소프트 프롬프트(Soft Prompt)**: 자연어 토큰이 아닌 학습 가능한 연속 임베딩 벡터
- **하드 프롬프트(Hard Prompt)**: 사람이 읽고 직접 작성·수정할 수 있는 자연어 지시문
- **매개변수 효율 미세조정(Parameter-Efficient Fine-Tuning, PEFT)**: '페프트'로 읽고 일부 매개변수만 학습하는 기술군을 표시


## Ⅰ. 개요

- 정의/개념: 동결한 모델의 입력 임베딩 앞에 붙는 **과제별 가상 토큰 벡터만 학습하는 PEFT**
- **배경/필요성**: 전체·어댑터 학습의 **매개변수 저장·작업별 모델 복제 부담 절감**

### 쉽게 이해하기 (학습용)

- 입력에 가상 토큰을 붙이고 원하는 출력에 맞춰 그 값만 최적화합니다.

## Ⅱ. 특징

- **학습 가능한 연속 임베딩**을 실제 입력 토큰 임베딩 앞에 결합한다.
- **기반 모델은 동결하고 가상 토큰만 갱신**해 과제별 자산을 작게 저장한다.
- **프롬프트 길이·초기화·모델 규모·과제**가 품질과 문맥·연산 비용을 좌우한다.

### 쉽게 이해하기 (학습용)

- 학습은 가볍지만 기반 모델과 과제의 적합성은 따로 검증해야 합니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 소프트 프롬프트 | 학습 가능한 연속 임베딩 벡터 |
| 프롬프트 길이 | 가상 토큰 수·문맥 연산량 |
| 임베딩 결합기 | 가상·실제 토큰 연결 |
| 동결 백본 | 모델 가중치 고정·입력 처리 |
| 과제 손실 | 소프트 프롬프트 갱신 그래디언트 |

```text
가상토큰 ─── 입력결합 ─── 동결모델 ─── 과제출력
실제토큰 ─┘
```

### 쉽게 이해하기 (학습용)

- 가상 토큰과 실제 토큰을 묶고 가상 토큰만 학습합니다.

## Ⅳ. 원리 및 절차 흐름도

```text
토큰 초기화
↓
입력 결합
↓
모델 추론
↓
선택 갱신
↓
과제 배포
```

| 절차 | 설명 |
|:---|:---|
| 토큰 초기화 | 가상 토큰 길이·차원 설정 |
| 입력 결합 | 가상·실제 토큰 임베딩 연결 |
| 모델 추론 | 동결 모델로 과제 출력 생성 |
| 선택 갱신 | 가상 토큰만 그래디언트 갱신 |
| 과제 배포 | 프롬프트 분리 저장·적재 |

### 쉽게 이해하기 (학습용)

- 가상 토큰만 갱신해 과제별로 분리해 저장합니다.

## Ⅴ. 종류 및 비교

| 프롬프트 적응 방식 | 하드 프롬프트 | 프롬프트 튜닝 | 접두어 튜닝 |
|:---|:---|:---|:---|
| 적용 기준 | 즉시 수정 필요 시 | 입력층 조정 시 충분 시 | 계층별 제어 필요 시 |
| 핵심 특징 | 자연어 지시문 직접 작성 | 입력층 가상 토큰 학습 | 계층별 키·값 접두어 학습 |
| 한계 | 표현·작성자 편차 | 문맥 사용·해석 불가 | 계층별 캐시 메모리 증가 |

> 요약: 방식별 조정 대상과 추론 비용 비교

### 쉽게 이해하기 (학습용)

- 하드·소프트·접두어 방식은 조정 위치와 비용이 다릅니다.

## Ⅵ. 실무 사례

1. 과제별 소프트 프롬프트는 **전체 파인튜닝 대비 품질 비교**
2. 배포 전 **가상 토큰 길이·문맥 점유·응답 지연 측정**

### 쉽게 이해하기 (학습용)

- 공용 모델의 과제별 가상 토큰이 문맥을 과도하게 차지하지 않는지 검증합니다.

## Ⅶ. 결론

- 프롬프트 튜닝은 **가상 토큰 품질·문맥 점유·지연**을 평가

### 쉽게 이해하기 (학습용)

- 기반 모델이나 과제가 달라지면 품질과 문맥 비용을 다시 확인해야 합니다.
