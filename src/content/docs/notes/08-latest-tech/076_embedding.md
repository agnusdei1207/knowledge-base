## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **임베딩(Embedding)**: 입력 의미•특징을 연속 벡터로 표현하는 기술이다.

</details>

- 정의: 입력 의미•특징을 고정 길이 벡터로 표현하는 **임베딩**
- 배경/필요성: 비정형 텍스트, 이미지, 음성 등 인간의 자연어 및 멀티모달 데이터는 형태와 길이가 가변적이며 이산적(Discrete) 심볼로 구성되어 있어, 단순 키워드 매칭이나 규칙 기반 방식으로는 데이터에 내재된 깊은 의미론적 유사도와 맥락적 관계를 수학적으로 계산할 수 없는 근본적 한계가 존재함에 따라, 심층 신경망 인코더(BERT, RoBERTa, OpenAI text-embedding-3, BGE 등)를 활용하여 가변 길이 입력을 고차원의 연속 밀집 벡터(Continuous Dense Vector) 공간으로 투영하는 임베딩(Embedding: Contextual Dense Vectors, Pooling, Normalization, Cosine Metric) 기술을 도입하여 **의미론적 유사성을 벡터 공간 상의 기하학적 거리(코사인/유클리드)로 환산하는 정밀한 의미 표현 체계 확립, RAG 시맨틱 검색, 추천 시스템, 텍스트 분류 및 클러스터링의 공통 핵심 입력 기반 제공, 텍스트-이미지 간 크로스모달(Cross-Modal) 의미 정렬 달성**을 달성할 필요

#### 한줄 요약

- **고정 길이 벡터**는 형태가 다른 데이터를 하나의 거리 연산으로 묶는 대신 길이에 담기지 못한 세부를 버리므로, 차원 수는 표현 손실과 저장·검색 비용의 절충점에서 정해진다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **인코더 학습 목표**: 벡터에 보존할 의미•특징을 정하는 기준이다.
- **풀링•고정 차원화**: 가변 입력을 하나의 고정 길이 벡터로 결합한다.
- **표현 공간 일관성**: 모델•차원•정규화•거리 규격을 통일한다.

</details>

![의미가 비슷한 표현의 임베딩 공간 배치](/study/diagrams/embedding-semantic-space.svg)

> 파란 검색 표현과 붉은 보안 표현은 각 주제 안에서 가깝게 모이고 서로 다른 주제 사이는 멀어지며, 실제 모델 출력이 아닌 의미 거리의 개념 좌표다.

- **인코더 학습 목표**: 벡터에 보존할 의미•특징 결정
- **풀링•고정 차원화**: 가변 입력을 검색 벡터로 결합
- **표현 공간 일관성**: 모델•차원•정규화•거리 규격 통일

#### 한줄 요약

- **학습 목표•벡터 규격**과 풀링이 표현 품질 결정

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **인코더(Encoder)**: 입력을 문맥이 반영된 연속 표현으로 변환하는 모델이다.
- **풀링(Pooling)**: 여러 표현을 하나의 고정 길이 벡터로 결합하는 처리이다.
- **벡터 정규화**: 벡터 크기의 영향을 통제하도록 길이를 맞추는 처리이다.
- **벡터 규격**: 모델•차원•거리 함수•정규화를 묶은 호환 계약이다.
- **코사인 유사도**: 두 벡터의 각도로 방향 유사성을 측정하는 지표이다.

</details>

```text
[Embedding System]
├── [변환/풀링 파이프라인]
│   ├── [전처리기]
│   ├── [인코더]
│   └── [풀링기]
└── [규격/연산 관리]
    ├── [벡터 규격 저장소]
    └── [유사도 계산기]
```

- 선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 전처리기 | 입력을 모델 토큰 규격으로 변환 |
| 인코더 | 문맥•특징을 **토큰 벡터**로 변환 |
| 풀링기 | 토큰 벡터를 **고정 길이**로 결합 |
| 벡터 규격 저장소 | 모델•차원•**벡터 정규화**•풀링 관리 |
| 유사도 계산기 | 동일 규격 벡터의 **코사인 유사도** 산출 |

#### 한줄 요약

- **인코더•풀링**과 전처리•규격•유사도 구성

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **동일 규격 유사도 비교**: 모델•차원•정규화가 같은 벡터만 비교한다.

</details>

```text
전처리•인코더
   │ 1. 토큰 규격 전처리
   │ 2. 문맥 토큰 벡터 생성
   ▼
풀링기
   │ 3. 고정 길이 벡터•규격 등록
   ▼
벡터 규격 저장소
   │ 4. 동일 규격 유사도 비교
   ▼
유사도 계산기
   └── 거리•유사도 결과 ──▶ 벡터 규격 저장소
```

### 동작 원리

1. 토큰 규격 전처리: 모델 버전에 맞춘 입력 단위 통일
2. 문맥 토큰 벡터 생성: 입력 특징의 연속 공간 배치
3. 고정 길이 벡터•규격 등록: 풀링 결과와 생성 규격 저장
4. 동일 규격 유사도 비교: 모델•차원•정규화가 같은 벡터 비교

#### 한줄 요약

- **인코딩•풀링** 전후 전처리•동일 규격 비교 수행

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **희소 표현(Sparse Representation)**: 어휘 출현을 고차원 희소 벡터로 표현한다.
- **정적 임베딩(Static Embedding)**: 단어마다 하나의 고정 밀집 벡터를 부여한다.
- **문맥 임베딩(Contextual Embedding)**: 문맥에 따라 토큰•문장 벡터를 생성한다.

</details>

| 구분 | 희소 표현 | 정적 임베딩 | 문맥 임베딩 |
|:---|:---|:---|:---|
| 적용 기준 | **정밀 검색** | **어휘 유사도** | 문맥•**다의어 구분** |
| 핵심 특징 | 단어별 **희소 차원** | 단어별 **고정 밀집 벡터** | 문맥별 **토큰•문장 벡터** |
| 한계 | 표기 변형•**동의어 누락** | 다의어•**문맥 구분 한계** | 생성•저장•**검색 비용 증가** |

#### 한줄 요약

- **정밀 어휘•문맥 구분**과 계산 비용에 따라 표현 방식 구분

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **상위 k개 재현율(Recall at k, Recall@k)**: 관련 정답이 상위 k개에 포함된 비율이다.
- **정규화 할인 누적 이득(nDCG)**: 관련성과 검색 순위를 함께 반영한 품질 지표이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 규격이 다른 **벡터 공간** 혼합 | 버전•전처리•차원•풀링을 함께 등록 | **거리 비교 정합성** 확보 |
| 학습 목적과 **거리 함수** 불일치 | 권장 거리 함수와 **정규화** 고정 | **유사도 순위** 보존 |
| 전문용어•다의어의 **표현력 부족** | **Recall@k•nDCG** 평가 후 미세조정 | **검색 누락률** 감소 |

#### 한줄 요약

- **벡터 규격•거리 함수**와 도메인 표현력 검증

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **표현 품질**: 실제 질의에서 의미 구분과 검색 순위 보존을 평가하는 기준이다.

</details>

- 비정형 자연어 및 멀티모달 데이터를 기계가 수학적으로 연산 가능한 고차원 잠재 공간으로 변환하는 **현대 생성형 AI, 의미 검색(Semantic Search) 및 RAG 인프라의 절대적 근간 기술(Dense Vector Embedding / Contextual Encoders / CLS & Mean Pooling / L2 Normalization / Cosine Similarity Metric / Domain Fine-Tuned Embeddings)의 표준 표현 체계**로 확고히 자리 잡았으며, 다국어 및 멀티모달 통합 임베딩으로 진화하는 가운데, 실무 임베딩 파이프라인 구축 시에는 **동일 벡터 공간 정합성을 보장하기 위해 인코더 모델 버전, 차원 수($d$), 풀링 방식 및 L2 정규화 규격을 엄격히 통일하고, 도메인 특화 용어 및 전문 지식에 대한 검색 품질 저하를 방어하기 위한 임베딩 모델 미세조정(Fine-Tuning) 및 nDCG/MRR 벤치마크 평가**를 결합하여 완벽한 의미 표현력과 견고한 검색 성능을 완성

#### 한줄 요약

- **질의 어휘성•문맥 의존성**에 따라 표현 방식 결정
