## 미리 알고가기

- **에이전틱 RAG (Agentic RAG)**: 에이전트가 도구를 스스로 고르고 여러 번 검증해 답을 만드는 RAG
- **반추 (Reflection)**: 정보의 신뢰도와 추가 검색 필요성을 스스로 평가하는 성찰 단계
- **도구 라우팅 (Tool Routing)**: 질의 문맥에 맞춰 적합한 외부 API 도구를 식별해 호출하는 기법
- **무한 탐색 루프 (Infinite Loop)**: 에이전트 성찰 오작동으로 무의미한 검색을 반복하는 자원 낭비 결함



## Ⅰ. 개요

- 정의/개념: 에이전트가 계획·검색·평가를 반복하는 RAG
- **배경/필요성**: 복합 질의의 동적 탐색과 실패 복구 지원

### 쉽게 이해하기 (학습용)

- 할 일을 나누고 적절한 도구로 확인하며 근거가 부족하면 다시 검색합니다.

## Ⅱ. 특징

- 계획기가 질문을 하위 목표로 나누고 필요한 증거를 기록한다.
- 도구 라우터가 목표와 권한에 맞는 검색·DB·API를 고른다.
- 평가기가 근거의 관련성·충분성을 검사해 재검색을 정한다.
- 반복 탐색은 실패를 복구하지만 루프와 비용을 늘릴 수 있다.
- 최소 권한·호출 예산·최대 단계로 실행을 통제한다.

### 쉽게 이해하기 (학습용)

- 에이전트는 조사 기록으로 다음 행동을 정하므로 반복과 권한 오용을 통제해야 합니다.

## Ⅲ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 계획기 | 목표를 하위 작업과 완료 조건으로 분해하고 순서 제안 |
| 상태·메모리 | 작업 결과, 근거 출처, 오류와 남은 목표를 구조화 저장 |
| 도구 라우터 | 허용 목록과 스키마 확인 뒤 목표에 맞는 도구 호출 |
| 근거 평가기 | 근거의 관련성·충분성·모순과 인용 가능성을 검사 |
| 정책 통제기 | 최대 단계·비용, 도구 권한, 중단·대체 응답 규칙 강제 |

```text
                 [정책 통제기]
              권한·예산·중단 조건
                      │
[계획기] ── [상태·메모리] ── [근거 평가기]
                      │
              [도구 라우터·허용 도구]
```

### 쉽게 이해하기 (학습용)

- 계획·상태·도구·근거 평가와 안전 정책이 함께 반복 탐색을 통제합니다.

## Ⅳ. 원리 및 절차 흐름도

```text
목표수립
  ↓
도구실행
  ↓
상태갱신
  ↓
근거평가
  ↓
종료응답
```

| 절차 | 설명 |
|:---|:---|
| 목표수립 | 질문을 하위 목표로 분해하고 증거·도구·중단 조건 정함 |
| 도구실행 | 목표에 맞는 도구를 선택하고 권한 검증 뒤 호출함 |
| 상태갱신 | 결과·오류·비용과 해결된 목표를 저장함 |
| 근거평가 | 근거의 관련성과 출처 일치를 평가해 추가 탐색 결정 |
| 종료응답 | 근거가 충분하면 답하고, 한계 도달 시 중단 사유 밝힘 |

### 쉽게 이해하기 (학습용)

- 조사 범위와 안전선을 정하고 근거가 충분하거나 한계에 닿으면 멈춥니다.

## Ⅴ. 종류 및 비교

| 판단 기준 | 고정 RAG | 워크플로 RAG | Agentic RAG |
|:---|:---|:---|:---|
| 실행 제어 | 검색·생성 단계를 1회 수행함 | 설계된 분기와 순서에 따라 실행함 | 상태와 평가 결과에 따라 다음 단계 결정 |
| 적용 기준 | 질문과 데이터가 일정할 때 적용함 | 업무 절차와 예외 분기가 명확할 때 적용함 | 복합 목표를 실행 중 반복 탐색해야 할 때 적용함 |
| 주요 위험 | 검색 실패 복구가 어려움 | 정의되지 않은 상황의 분기 누락 | 반복 루프, 지연·비용, 도구 권한 오용 |

> 요약: 에이전틱 RAG는 작업 분해와 반복 검색을 수행한다.

### 쉽게 이해하기 (학습용)

- 고정형·워크플로형·에이전틱형은 다음 검색 단계를 정하는 방식이 다릅니다.

## Ⅵ. 실무 사례

- 재무·문서 자료의 시점과 단위를 맞춰 비교 검증

### 쉽게 이해하기 (학습용)

- 반복 행동과 누적 비용을 감시하고 중요한 시스템 호출에는 사람 승인을 둡니다.

## Ⅶ. 결론

- 복합 질문의 검색 계획과 도구 사용을 자동화하기 위해 **반복 종료 조건·근거 품질·도구 권한·지연·비용**을 검토하고, 단계별 결과를 검증할 수 있는 업무에 에이전틱 RAG를 활용해야 한다.

### 쉽게 이해하기 (학습용)

- 탐색 범위와 실행 권한 및 중단 조건을 명확한 정책으로 제한해야 합니다.
