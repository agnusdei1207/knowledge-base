## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **보안 접근 서비스 엣지(Secure Access Service Edge, SASE)**: 연결과 보안을 사용자 가까운 클라우드 서비스 거점에서 통합하는 아키텍처이다.
- **소프트웨어 정의 광역망(Software-Defined Wide Area Network, SD-WAN)**: 애플리케이션별 광역망 경로와 품질을 소프트웨어 정책으로 제어하는 연결 기술이다.
- **보안 서비스 엣지(Security Service Edge, SSE)**: 접근•웹•데이터 보안 기능을 클라우드에서 통합 제공하는 서비스 계층이다.
- **백홀(Backhaul)**: 지점•원격 사용자의 트래픽을 중앙 데이터센터로 우회해 전달하는 방식이다.

</details>

- 정의/개념: **SASE**는 **SD-WAN** 연결과 **SSE**를 분산 서비스 거점에서 통합하는 아키텍처
- 배경/필요성: 중앙 백홀은 분산 사용자•클라우드 접속의 지연•병목과 **정책 편차** 유발
#### 한줄 요약

- 중앙 보안 장비로 왕복하지 않고 가까운 거점에서 동일한 연결•보안 정책을 적용한다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **제로 트러스트 네트워크 접근(Zero Trust Network Access, ZTNA)**: 신원•장치•맥락을 검증해 애플리케이션 단위 접근을 허용하는 기능이다.
- **서비스 거점(Point of Presence, PoP)**: 사용자 가까이에서 연결•보안 정책을 집행하는 분산 엣지 위치이다.

</details>

- **SD-WAN•SSE** 기반 **연결•보안 정책 통합**
- **ZTNA** 기반 사용자•장치•애플리케이션의 **지속적 접근 판정**
- 인접 **PoP** 기반 **백홀 지연 감소**와 거점 품질 의존
#### 한줄 요약

- 사용자 위치와 관계없이 같은 경로 선택과 보안 규칙이 적용돼야 한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **통합 신원•정책**: 사용자•장치•애플리케이션 맥락을 하나의 정책으로 평가해 모든 서비스 거점에 동일하게 집행한다.

</details>

분산 **PoP**의 **SSE** 접근 검사, **SD-WAN** 경로 제어, **ZTNA** 집행

```text
                 [가입자 접속]
                      |
               [신원•정책 계층]
                      |
              [분산 서비스 거점]
                      |
            +---------+---------+
            |                   |
     [SSE 보안 서비스]   [SD-WAN 연결 서비스]
```

선의 의미: 가입자 접속과 신원•정책 계층이 분산 서비스 거점의 공통 접근 경계를 구성하고, 각 거점은 SSE 보안 서비스와 SD-WAN 연결 서비스를 결합한다.

| 구성요소 | 책임 |
|:---|:---|
| 가입자 접속 | 사용자•장치•지점의 **에이전트•터널 연결** |
| 신원•정책 계층 | 신원•장치•위험 기반 **통합 정책 결정** |
| 분산 서비스 거점 | 인접 위치의 **트래픽 수용•정책 집행** |
| SSE 보안 서비스 | ZTNA•웹 필터와 **방화벽•데이터 보안** 적용 |
| SD-WAN 연결 서비스 | 애플리케이션별 경로•품질과 **장애 우회** 제공 |

#### 한줄 요약

- 인접 PoP의 공통 신원 검사와 목적지•품질 기반 경로 전달

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **위험 맥락**: 사용자 신원•장치 상태•애플리케이션•위협 정보를 결합한 접근 판단 자료이다.
- **경로 품질**: 네트워크 경로의 지연•손실•가용성을 측정한 상태이다.

</details>

```text
[사용자•지점] ── 접속 맥락 ──▶ [서비스 거점]
                                    │ 1. 신원•장치 상태
                                    ▼
                              [신원•정책 계층]
                                    │ 2. 접근•검사 정책
                                    ▼
                              [SSE 보안 서비스]
                                    │ 3. 허용 트래픽
                                    ▼
[사용자•지점] ◀── 서비스 응답 ── [SD-WAN 연결]
                                    │ 4. 경로 품질
                                    └────────▶ [서비스 거점]
```

**동작 원리**

1. **신원•장치 상태 전달**: 사용자•장치•애플리케이션의 **위험 맥락** 제공
2. **접근•검사 정책 전달**: **ZTNA•SSE**의 웹•방화벽 검사 규칙 제공
3. **허용 트래픽 전달**: 정책을 통과한 **목적지별 세션** 제공
4. **경로 품질 전달**: 지연•손실•가용성의 **경로 상태** 제공

#### 한줄 요약

- 사용자•기기•목적지를 확인해 보안 검사와 경로를 결정하고 위험 변화 시 재평가한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **기존 허브 경유 방식**: 지점•사용자 트래픽을 중앙 데이터센터의 보안 장비로 모아 검사하는 구조이다.
- **남북 트래픽**: 조직 내부와 인터넷•외부 서비스 사이를 오가는 통신이다.
- **광역망(Wide Area Network, WAN)**: 먼 거리에 분산된 지점•데이터센터를 연결하는 네트워크이다.

</details>

| 판단 기준 | SASE | SSE | 기존 허브 경유 방식 |
|:---|:---|:---|:---|
| 적용 기준 | 연결•보안 통합이 필요한 **분산 환경** | 기존 **WAN**의 **보안 통합** | **중앙 업무•고정 경계** 중심 |
| 핵심 특징 | **SD-WAN•SSE**의 **엣지 통합** | **클라우드 보안 기능**만 제공 | 중앙 허브의 **트래픽 집중 검사** |
| 한계 | **제공자 종속•거점 품질** 편차 | **연결•보안 정책 분리** 가능 | **백홀 지연•중앙 장애** 집중 |

#### 한줄 요약

- 연결•보안 통합은 SASE, 기존 WAN의 보안 통합은 SSE 선택

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **거점 품질 편차**: 지역별 서비스 거점의 용량•경로•장애 대응 차이로 사용자 경험이 달라지는 현상이다.
- **탈출 계획**: 제공자 변경 시 정책•로그•연동•트래픽을 대체 환경으로 이전하는 절차이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **거점 품질** 미검증 시 지역별 **지연•가용성 편차** | 주요 지역 **PoP**의 **성능•장애 전환 검증** | 지역별 **지연•가용성 편차** 감소 |
| **정책 통합** 미검증 시 연결•보안 규칙의 **충돌•우회** | 단일 정책 모델과 **변경 영향 시험** | 정책 **충돌•우회** 축소 |
| **제공자 의존** 미검증 시 기능•로그•정책의 **이전 제약** | 표준 연동•로그 반출•**탈출 계획** | 정책•로그 **이전성** 확보 |

#### 한줄 요약

- 주요 사용자 지역의 서비스 거점 품질과 장애 전환을 측정하고 연결•보안 정책의 일관성을 검증한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **연결•보안 통합**: 네트워크 경로 선택과 접근•콘텐츠 보안 정책을 하나의 서비스 체계로 운영하는 방식이다.
- **제공자 종속**: 특정 보안 접근 서비스 엣지 사업자의 거점•정책 모델•로그 형식에 의존해 이전이 어려운 상태이다.

</details>

- 분산 사용자•지점은 **SASE**, 보안만 통합할 기존 **WAN**은 **SSE** 선택

#### 한줄 요약

- SASE는 지역별 체감 지연과 통제 효과를 함께 시험해야 한다.
