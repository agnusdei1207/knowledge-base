## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **SIMT(Single Instruction, Multiple Threads)**: 수많은 독립 스레드들을 워프(Warp: 32개 스레드) 단위로 묶어 단일 명령어 스트림으로 동시 병렬 실행하는 GPU 하드웨어 실행 모델.
- **GPU(Graphics Processing Unit)**: 수천 개의 소형 고효율 연산 코어와 초고대역폭 메모리(HBM/GDDR)를 집적하여 대규모 데이터 병렬성을 초고속 처리하는 프로세서.

</details>

- 정의/개념: 독립 스레드들을 32개 단위의 **워프(Warp)**로 묶어 단일 명령어로 동시 실행하면서 스레드별 개별 문맥을 제공하는 **SIMT 아키텍처**
- 배경/필요성: 기존 CPU 직렬 제어 한계로 대규모 **텐서 병렬 연산** 처리량 제한 극복

#### 한줄 요약
- SIMT는 스레드별 독립 제어의 유연성과 SIMD의 대규모 하드웨어 병렬 실행 효율을 동시에 달성하는 GPU 핵심 아키텍처이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **워프(Warp)**: SM 내부에서 단일 명령어로 함께 스케줄링되어 락스텝(Lock-step)으로 동시 실행되는 32개 스레드의 하드웨어 실행 단위.
- **지연시간 은닉(Latency Hiding)**: 한 워프가 DRAM 메모리 접근으로 대기할 때, 연산 준비가 완료된 다른 상주 워프로 즉시 스위칭하여 파이프라인 유휴를 없애는 기법.
- **분기 발산(Branch Divergence)**: 워프 내 스레드들이 조건문(if-else)에 따라 서로 다른 분기 경로를 탈 때, 경로별로 순차 직렬 실행되어 성능이 저하되는 현상.

</details>

- 제어 오버헤드 극소화: 32개 스레드가 단일 디코더를 공유하여 다이 면적당 **연산 코어 집적도** 극대화
- 제로 사이클 문맥 전환: 대용량 레지스터 파일에 워프 문맥을 보관하여 **지연시간 은닉(Latency Hiding)** 실현
- 조건 분기 패널티: 워프 내부 스레드의 조건 불일치 시 액티브 마스크를 통한 **분기 발산(Branch Divergence)** 발생

#### 한줄 요약
- 워프 공유 실행으로 제어 면적을 줄이고, 대용량 레지스터를 통한 지연 은닉으로 메모리 대기를 무력화한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **스트리밍 멀티프로세서(Streaming Multiprocessor, SM)**: 워프 스케줄러, 레지스터 파일, CUDA 코어, 텐서 코어, 공유 메모리를 통합 내장한 GPU의 핵심 독립 연산 유닛.
- **공유 메모리(Shared Memory / L1 Data Cache)**: 동일 스레드 블록 내 스레드들이 프로그래머 제어 하에 1~2사이클로 데이터를 초고속 공유하는 온칩 SRAM.

</details>

```text
[GPU 실리콘 프로세서 다이]
 ├─ 스트리밍 멀티프로세서 어레이 (SM)
 │   ├─ 워프 스케줄러 & 디스패치 유닛
 │   ├─ 온칩 레지스터 파일 (Register File)
 │   ├─ 실행 코어군 (CUDA 코어 / Tensor 코어)
 │   ├─ 특수 기능 유닛 (SFU)
 │   └─ 공유 메모리 / L1 캐시
 ├─ 온칩 크로스바 인터커넥트
 ├─ 공유 L2 캐시 (Shared L2 Cache)
 └─ 고대역폭 메모리 인터페이스 (HBM / GDDR)
```

선의 의미: 가지(`├─`, `└─`)는 하드웨어 소속 및 포함 관계를 나타냄

| 구성요소 | 소속 및 위치 | 핵심 엔지니어링 책임 | 주요 특징 |
|:---|:---|:---|:---|
| SM | GPU 내부 핵심 엔진 | 스레드 블록 수용 및 **워프 스케줄링**, 텐서 병렬 연산 총괄 | 수십~수백 개 집적 |
| 워프 스케줄러 | SM 내부 제어기 | 준비 완료된 워프를 선택하여 **연산 코어**로 디스패치 | 제로 오버헤드 스위칭 |
| 레지스터 파일 | SM 내부 고속 저장소 | 수천 개 상주 스레드의 **실행 문맥** 보관 | 대용량 SRAM 구조 |
| 텐서 코어 | SM 내부 전용 연산기 | 혼합 정밀도 행렬 곱셈 누산(**MMA**) 하드웨어 가속 | AI 딥러닝 텐서 가속 |
| 공유 메모리 | SM 내부 온칩 SRAM | 동일 블록 내 스레드 간 **데이터 교환** 및 타일링 버퍼 | 프로그래머블 캐시 |

#### 한줄 요약
- GPU는 다수의 SM(워프 스케줄러, 레지스터, 코어, 공유 메모리)과 공유 L2 캐시 및 HBM 메모리 인터페이스로 구성된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **액티브 마스크(Active Mask)**: 분기 발산 발생 시 현재 실행 중인 분기 경로에 해당하는 스레드만 1로 인에이블하고 나머지는 일시 비활성화하는 하드웨어 마스크.

</details>

```text
[호스트 CPU 커널 함수 런칭]
         │
         ▼
1. GigaThread 엔진의 스레드 블록 분배 적재
         │
         ▼
2. SM 워프 스케줄러의 32스레드 워프 그룹화
         │
         ▼
3. 실행 준비(Ready) 워프 탐색 및 단일 명령어 코어 동시 발행
         │
         ▼
4. 액티브 마스크 기반 분기 발산(Divergence) 순차 실행 처리
         │
         ▼
5. 메모리 대기 시 타 워프로 제로 사이클 스위칭(지연 은닉)
         │
         ▼
[연산 결과 호스트 메모리 반환]
```

분기 결과: 분기 발산 부재 시 32스레드 100% **동시 실행**, 발산 발생 시 마스크 기반 **순차 실행**으로 분기 처리

#### 한줄 요약
- 1. 블록 분배 적재 ➔ 2. 워프 그룹화 ➔ 3. 단일 명령어 동시 발행 ➔ 4. 분기 발산 순차 실행 ➔ 5. 지연시간 은닉 순으로 동작한다.

## Ⅴ. 종류 및 비교

| 병렬 처리 아키텍처 | SIMT (GPU 아키텍처) | SIMD (CPU 벡터 확장: AVX-512) | MIMD (멀티코어 CPU) |
|:---|:---|:---|:---|
| 프로그래밍 모델 | **스레드 수준 병렬성** | 데이터 벡터 레지스터 병렬성 | 독립 태스크/스레드 병렬성 |
| 명령어 제어 | 32개 독립 스레드가 **단일 명령어** 공유 | 단일 명령어가 단일 벡터 레지스터 구동 | 각 코어가 **독립 명령어** 스트림 실행 |
| 분기 처리 능력 | 하드웨어 **액티브 마스크** 처리 | 벡터 마스크 레지스터 수동 제어 | 각 코어가 독립 분기 예측 및 실행 |
| 연산 병렬 규모 | 수만~수십만 개 **스레드 동시 상주** | 8~16개 데이터 요소 벡터화 | 수십~수백 개 코어 병렬 실행 |
| 주요 적용 분야 | **AI 딥러닝**, 3D 그래픽 렌더링 | 과학 계산, 미디어 인코딩 | 범용 OS, 데이터베이스 서버 |

#### 한줄 요약
- SIMD는 단일 벡터 레지스터에 종속되고 MIMD는 코어 확장이 제한적인 반면, SIMT는 수만 스레드의 대규모 데이터 병렬성을 완벽히 처리한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **메모리 병합(Memory Coalescing)**: 워프 내 32개 스레드의 연속 메모리 접근을 단 1회의 128바이트 DRAM 트랜잭션으로 결합하는 최적화.
- **뱅크 충돌(Bank Conflict)**: 공유 메모리의 동일 뱅크에 서로 다른 주소 접근이 동시 발생하여 접근이 직렬화되는 현상.

</details>

| 문제 상황 | 대책 | 엔지니어링 효과 |
|:---|:---|:---|
| 워프 내 분기 발산으로 연산기 유휴 | 데이터 정렬 및 **워프 특화(Warp-Specialized)** 커널 분할 | 분기 발산 제거 및 **연산 코어 가동률** 극대화 |
| 비연속 메모리 스트라이드로 대역폭 낭비 | 구조체 배열(AoS)을 **배열 구조체(SoA)**로 변환 | **메모리 병합**으로 DRAM 읽기 트랜잭션 절감 |
| 과도한 레지스터 사용으로 점유율 저하 | 컴파일러 launch_bounds 지정 및 **레지스터 수 제한** | SM당 상주 워프 수 확보 및 **지연 은닉** 달성 |
| 공유 메모리 접근 시 뱅크 충돌 발생 | 공유 메모리 2차원 배열 열 **패딩(Padding)** 삽입 | 동시 접근 직렬화 해소 및 **1사이클 접근** 보장 |

#### 한줄 요약
- 실무에서는 메모리 병합(Coalescing), 워프 특화 분기 제거, 공유 메모리 패딩을 통해 GPU 대역폭과 점유율을 극대화한다.

## Ⅶ. 결론

- **대규모 데이터 병렬성** 요구 시 **SIMT 아키텍처**와 메모리 병합 적용

#### 한줄 요약
- SIMT는 현대 AI와 고성능 컴퓨팅의 표준 실행 모델이며, 데이터 레이아웃 최적화와 텐서 코어 활용을 통해 압도적 처리량을 완성한다.
