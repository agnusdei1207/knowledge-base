## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **고속 직렬 인터페이스**: 적은 차동 신호선으로 비트를 순차 고속 전송하는 연결 규격이다.
- **범용 직렬 버스(Universal Serial Bus, USB)**: 데이터 전송과 전력 공급을 지원하는 범용 직렬 인터페이스이다.
- **범용 직렬 버스 타입 C(Universal Serial Bus Type-C, USB-C)**: 상하 구분 없는 형상을 제공하지만 속도•전력•영상 기능 자체를 보장하지 않는 커넥터 규격이다.

</details>

- 정의/개념: **고속 직렬 인터페이스**는 적은 수의 차동 레인으로 데이터를 직렬 전송하고 양단과 케이블의 협상으로 데이터•전력•영상 기능을 정하는 연결 규격이다.
- 배경/필요성: USB-C는 커넥터 형상만 규정하므로 같은 모양의 포트와 케이블이라도 지원 속도, 전력, 영상 및 터널링 기능이 다를 수 있다.

#### 한줄 요약

- **USB-C**는 호스트•장치•케이블이 공통으로 지원하는 기능만 활성화한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **기능 탐색**: 호스트•장치•케이블이 지원 기능을 교환하여 공통 속도•전력•영상 모드를 찾는 절차이다.
- **차동 신호**: 두 선의 전압 차이로 비트를 표현하여 공통 잡음의 영향을 줄이는 방식이다.
- **터널링**: 한 프로토콜의 패킷을 다른 링크의 전송 형식에 실어 전달하는 방식이다.
- **USB 전력 전송(USB Power Delivery, USB PD)**: USB 연결에서 전력 방향•전압•전류를 협상하는 규격이다.
- **고속 주변장치 상호연결(Peripheral Component Interconnect Express, PCIe)**: 처리기와 주변장치를 연결하는 고속 직렬 인터페이스이다.
- **직접 메모리 접근(Direct Memory Access, DMA)**: 장치가 처리기를 거치지 않고 메모리에 직접 접근하는 방식이다.

</details>

- **기능 탐색**과 **USB PD**로 공통 속도•전력•대체 모드를 결정한다.
- **차동 신호**와 레인으로 고속 직렬 전송을 수행한다.
- Thunderbolt의 **PCIe** **터널링**은 고대역 장치 연결과 외부 **DMA** 공격면을 함께 확대한다.

#### 한줄 요약

- **기능 탐색**과 Thunderbolt 외부 DMA 격리가 핵심이다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **호스트 컨트롤러(Host Controller)**: 기능 협상과 데이터•터널 경로를 제어하는 구성이다.
- **USB-C 포트(USB-C Port)**: CC로 연결 방향과 전원 역할 및 기능을 협상하는 구성이다.
- **구성 채널(Configuration Channel, CC)**: 연결 방향과 전원 역할 및 대체 모드를 협상하는 USB-C 신호선이다.
- **전자 마커(Electronic Marker, e-Marker)**: 케이블의 지원 속도•전류•레인 등급을 제공하는 칩이다.
- **장치 컨트롤러(Device Controller)**: 장치 기능을 광고하고 협상된 데이터를 처리하는 구성이다.
- **입출력 메모리 관리 장치(Input-Output Memory Management Unit, IOMMU)**: 외부 장치의 DMA 주소와 메모리 접근 범위를 격리하는 구성이다.

</details>

```text
[IOMMU] -- [호스트 컨트롤러] -- [USB-C 포트]
                                      |
                          [케이블•e-Marker] -- [장치 컨트롤러]
```

선의 의미: 호스트와 장치 컨트롤러를 포트•케이블이 연결하고 IOMMU가 호스트 측 외부 DMA 접근 경계를 제공하는 정적 인터페이스 관계다.

| 구성요소 | 책임 |
|:---|:---|
| 호스트 컨트롤러 | 기능 협상•라우팅 |
| USB-C 포트 | CC 기반 방향•전력 협상 |
| 케이블•e-Marker | 속도•전류 등급 제공 |
| 장치 컨트롤러 | 기능 광고•데이터 처리 |
| IOMMU | 외부 DMA 격리 |

#### 한줄 요약

- **호스트 컨트롤러**, **USB-C 포트**, **전자 마커**, **장치 컨트롤러** 경로와 **IOMMU**의 외부 DMA 격리가 핵심이다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **대체 모드**: USB-C 신호선을 DisplayPort 같은 다른 프로토콜에 배정하는 동작 모드이다.
- **케이블 능력 확인**: 전자 마커에서 케이블의 속도와 전류 한도를 확인하는 단계이다.
- **전력·기능 협상**: 양단의 전력 역할과 데이터 및 대체 모드의 공통 범위를 정하는 단계이다.
- **공통 기능 확정**: 호스트·장치·케이블이 모두 지원하는 링크 구성을 고르는 단계이다.
- **외부 DMA 경계 적용**: 터널링 장치가 접근할 수 있는 메모리 범위를 제한하는 단계이다.
- **데이터·영상 링크 활성화**: 협상한 레인과 보안 정책으로 데이터 또는 영상 경로를 여는 단계이다.

</details>

```text
[USB-C 연결 감지]
        │
        ▼
1. 케이블 능력 확인
        │
        ▼
2. 전력•기능 협상
        │
        ▼
3. 공통 기능 확정
        │
        ▼
4. 외부 DMA 경계 설정
        │
        ▼
5. 데이터•영상 링크 활성화
        │
        ▼
 [협상 기능 제공]
```

### 동작 원리

1. **케이블 능력 확인**: 전자 표식 케이블이면 e-Marker 정보를 읽고, 포트와 케이블이 허용하는 속도•전류 한도를 확인한다.
2. **전력•기능 협상**: 양단이 전력 역할과 USB 데이터, 대체 모드 또는 터널링 기능의 공통 범위를 정한다.
3. **공통 기능 확정**: 호스트•장치•케이블이 모두 지원하는 링크 속도와 영상•전력 구성을 선택한다.
4. **외부 DMA 경계 적용**: PCIe 터널링을 사용하는 외부 장치에는 IOMMU와 사용자 승인 정책으로 접근 가능한 메모리를 제한한다.
5. **데이터•영상 링크 활성화**: 협상한 레인 구성과 보안 정책을 적용한 뒤 데이터 또는 영상 경로를 연다.

#### 한줄 요약

- **공통 기능 확정**과 **외부 DMA 경계 적용**을 마친 뒤 **데이터·영상 링크 활성화**를 수행한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **Thunderbolt**: PCIe•DisplayPort 패킷을 하나의 고속 직렬 링크로 터널링하는 인터페이스이다.

</details>

| 직렬 인터페이스 | USB | Thunderbolt |
|:---|:---|:---|
| 적용 기준 | 범용 장치•충전 | 외장 PCIe•다중 화면 |
| 핵심 특징 | 범용 데이터•전력 전송 | PCIe•DisplayPort 터널링 |
| 한계 | 포트•케이블 기능 불일치 | 외부 장치의 DMA 접근 |

> 요약: 범용 연결은 **USB**, PCIe 터널링은 **Thunderbolt**를 선택한다.

#### 한줄 요약

- 범용 장치•충전은 USB, 외장 PCIe•다중 화면은 Thunderbolt가 적합하다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **다운트레이닝**: 링크가 목표보다 낮은 속도나 레인 수로 설정되는 현상이다.
- **재협상**: 연결 중 전력•속도•기능 조건을 다시 합의하는 절차이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 도킹 스테이션에서 USB-C 형상만 보고 기능을 오판 | 호스트•장치•케이블 기능과 협상값 확인 | 속도•영상•충전 호환 장애 감소 |
| 저등급 케이블로 **다운트레이닝**과 **재협상** 반복 | 인증 케이블•링크 오류•협상 속도 감시 | 지속 전송률 확보 |
| Thunderbolt PCIe 터널이 허용 범위 밖 DMA 접근 | **IOMMU**와 사용자 승인 및 잠금 중 연결 제한 | 메모리 침해 방지 |
| 전력 계약이 케이블•포트 열 한도를 넘어 과열 발생 | 전력 예산•**전자 마커** 등급•포트 온도 감시 | 충전 중단•열 손상 예방 |

#### 한줄 요약

- 업무용 도크는 **호스트 컨트롤러**와 장치 및 케이블이 모두 필요한 화면 수와 해상도 및 충전 전력을 지원하는지 확인한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **도킹 스테이션**: 단일 포트를 전원•화면•네트워크•주변장치 연결로 확장하는 장치이다.
- **직렬 인터페이스 선택 기준**: 범용 데이터·충전과 PCIe 터널링 및 외부 DMA 격리 요구로 연결 규격을 고르는 기준이다.

</details>

- **직렬 인터페이스 선택 기준**에 따라 범용•충전 중심 **도킹 스테이션**은 **USB**, 외장 PCIe•다중 화면은 **Thunderbolt**를 선택한다.

#### 한줄 요약

- 공통 기능과 외부 DMA 요구로 USB 또는 Thunderbolt를 선택한다.
