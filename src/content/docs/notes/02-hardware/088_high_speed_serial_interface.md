## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **유에스비 타입 씨(USB Type-C)**: 위아래 구분이 없어서 꽂기 편한 겉모양 규격일 뿐, 속을 까보면 충전만 되는 쓰레기부터 썬더볼트까지 천차만별인 폼팩터이다.
- **썬더볼트 4/5(Thunderbolt 4/5)**: 인텔과 애플이 멱살 잡고 만든 괴물 규격으로, USB-C 껍데기를 쓰지만 무조건 초고속 속도와 모니터 출력을 강제하는 인증이다.
- **유에스비 파워 딜리버리(USB Power Delivery, USB PD)**: "나 100W 먹을 수 있어!" 하고 기계들끼리 멱살 잡고 전압을 협상해서 노트북까지 고속 충전해 버리는 전력 규칙이다.

</details>

- 정의: 겉모양은 다 똑같이 생겼는데 선 하나로 데이터, 모니터 화면, 240W 깡패 전력까지 싹 다 멀티플렉싱해서 쑤셔 박아주는 **USB & Thunderbolt 고속 직렬 인터페이스** 규격
- 배경: 겉모양만 C타입이고 실제로는 싸구려 충전만 되는지, 모니터가 나오는지 꽂아보기 전엔 모르는 난장판 스펙을 통일하고 외장 그래픽카드(eGPU)까지 연결하기 위함

#### 한줄 요약

- USB-C 껍데기 하나로 데이터 복사, 모니터 화면 출력, 100W 고속 충전까지 짬뽕해서 쏴주는 깡패 기술이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **얼터네이트 모드(Alternate Mode, Alt Mode)**: 원래 데이터나 보내던 USB 선을 뺏어서 모니터 영상 신호(DisplayPort) 전송선으로 둔갑시키는 마법이다.
- **피시에이아이 터널링(PCIe Tunneling)**: 데스크탑 안에 꽂아야 할 그래픽카드나 SSD를, USB 선을 터널처럼 뚫어서 바깥으로 빼내버리는 미친 확장 기술이다.
- **이마커(Electronic Marker, e-Marker)**: 선 꼬다리에 박혀있는 칩셋으로, "나 100W 버티는 고급 케이블이야!" 하고 자기 스펙을 증명하는 전자 신분증이다.

</details>

- USB 선 하나로 모니터 영상 신호(DisplayPort)까지 얹어서 같이 보내버리는 마법의 **얼터네이트 모드**를 지원함.
- 외장 그래픽카드나 초고속 SSD를 USB 선으로 끌어다 쓰는 극한의 속도(**피시에이아이 터널링**)를 얄짤없이 수용함.
- 불타는 싸구려 케이블을 걸러내기 위해, 선 꼬다리에 칩(**이마커**)을 박아넣고 전력 통과 한계(**USB PD**)를 멱살 잡고 협상함.

#### 한줄 요약

- 겉보기엔 똑같은 선이라도 영상 출력(Alt Mode), 그래픽카드 직결(터널링), 고속 충전(PD) 칩이 씹어먹을 듯 작동한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **호스트 컨트롤러(Host Controller)**: USB 데이터, 화면 영상, PCIe 데이터를 한 번에 짬뽕해서 선 하나로 쏴주는 메인 통제 칩셋이다.
- **씨씨 핀(Configuration Channel Pin, CC Pin)**: 선을 뒤집어 꽂았는지 감지하고, "너 충전 몇 와트 필요해?" 하고 물어보는 똑똑한 더듬이 핀이다.
- **아이오엠엠유(Input-Output MMU, IOMMU)**: 노트북 밖에서 들어온 썬더볼트 신호가 시스템 커널 메모리를 쑤시지 못하게 막아버리는 철통 하드웨어 방화벽이다.

</details>

```text
[ 유에스비 고속 직렬 멀티플렉싱 십자포화 프레임워크 ]
[ 방화벽 (IOMMU) ] ── [ 호스트 컨트롤러 (짬뽕 믹서기) ] ── [ USB-C 포트 (더듬이 CC 핀) ]
                                                              │
                     [ 장치 컨트롤러 (수신기) ] ── [ 케이블 (이마커 신분증) ]
```

| 구성요소 | 책임 |
|:---|:---|
| **호스트 컨트롤러** | USB 데이터, 화면 영상, PCIe 데이터를 한 번에 짬뽕해서 터널로 쏴주는 메인 통제 칩셋 |
| **씨씨 핀**(CC Pin) | 케이블 뒤집어 꽂았는지 확인하고, "너 몇 볼트 먹냐?" 하고 전력(**USB PD**)을 멱살 잡고 협상하는 탐지 센서 |
| 케이블•**이마커** | "나 싸구려 아니야! 100W 버텨!" 하고 자기 스펙을 당당하게 까발리는 케이블 내장 칩 |
| **아이오엠엠유** | 노트북 밖에서 들어온 썬더볼트 신호가 시스템 커널 메모리를 쑤시지 못하게 막아버리는 하드웨어 방화벽 |

#### 한줄 요약

- 컨트롤러가 신호를 섞고(터널링), 더듬이(CC)와 케이블 칩(이마커)이 스펙을 맞춘 뒤 방화벽(IOMMU)이 멱살을 잡는다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **유에스비포 썬더볼트 프로토콜 핸드셰이크(USB4 / Thunderbolt Protocol Handshake)**: 꽂자마자 기계 3개(노트북, 선, 모니터)가 모여서 "우리 어디까지 지원하냐?" 하고 눈치 싸움하며 기능을 확정 짓는 합의 과정이다.

</details>

```text
[ 유에스비 썬더볼트 십자포화 협상 및 터널링 뚫기 흐름 ]
                                 │
                                 ▼
   [ 1. 깡통 스펙 털기: 선 꽂히면 케이블 신분증(이마커) 털어서 몇 와트 버티는지 잼 ]
                                 │
                                 ▼
     [ 2. 멱살 합의: 노트북이랑 모니터가 "나 100W 쏠게, 화면 받음?" 하고 협상함 ]
                                 │
                                 ▼
    [ 3. 짬처리 확정: 노트북, 선, 모니터 3놈 다 지원하는 기능(교집합)만 최종 낙점 ]
                                 │
                                 ▼
  [ 4. 방어막 치기: 외부 장비가 메모리 털어갈까 봐 IOMMU 방화벽으로 얄짤없이 컷 ]
                                 │
                                 ▼
     [ 5. 터널 뚫고 쏘기: 협상 끝난 데이터, 화면, 전기 섞어서 빛의 속도로 쏨 ]
```

### 동작 원리

1. 깡통 스펙 털기: **씨씨 핀**이 선 꽂힌 걸 감지하고 **이마커**를 털어서 케이블이 몇 와트까지 버티는지 칼같이 조사함.
2. 전력 및 기능 멱살 협상: 노트북이랑 모니터가 "나 화면 출력됨, 100W 쏠게" 하고 **USB PD**와 영상(**얼터네이트 모드**) 기능을 합의봄.
3. 짬처리 확정: 케이블, 노트북, 모니터 3놈이 교집합으로 지원하는 기능만 최종 낙점함.
4. 방화벽 철통 방어: **피시에이아이 터널링** 뚫을 때 외부 장비가 메모리를 파먹지 못하게 **아이오엠엠유**로 경계를 침.
5. 터널 뚫고 쏘기: 협상 끝난 데이터, 화면, 전기를 한 번에 섞어서 빛의 속도로 쏴버림.

#### 한줄 요약

- 선 꽂으면 칩 털어서 스펙 맞추고, IOMMU로 방어막 친 다음에야 데이터를 통과시킨다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **유에스비 쓰리포인트투 젠 투바이투(USB 3.2 Gen 2x2)**: 속도는 20Gbps로 빠르지만 영상 출력(DP)이나 PCIe 같은 건 꿈도 못 꾸는, 그저 데이터 복사용으로 남은 구식 깡통 규격이다.

</details>

| 비교 항목 | **USB 3.2 Gen 2x2** | **유에스비포** (USB4) | **썬더볼트 4·5** (Thunderbolt 4·5) |
|:---|:---|:---|:---|
| 시스템 적용 최적 기준 | 그냥 폰 충전하고 외장 하드 연결하는 흔해 빠진 저가형 깡통 환경일 시 | 기기빨 엄청 타서 지원되면 화면도 띄우고 eGPU도 연결하는 복불복 C타입 환경일 시 | 모니터 2대 띄우고 eGPU 풀파워로 돌려야 하는 극강의 깐깐한 인증(Intel) 환경일 시 |
| 아키텍처 핵심 구현 특징 | 속도 20Gbps로 데이터 쏘고 충전만 적당히 해주는 평범한 구닥다리 규격 | 속도는 최대 40Gbps인데 제조사가 영상 출력이나 PCIe 기능을 빼버리면 답이 없는 껍데기 통합 | 애플이나 인텔이 멱살 잡고 무조건 40~120Gbps, 영상 출력, PCIe까지 강제 지원하게 만든 풀옵션 규격 |
| 극복해야 할 태생적 한계점 | 외장 그래픽이나 모니터 영상 출력을 뼛속까지 지원하지 않음 | C타입 겉모양만 보고는 영상이 나오는지 터널링이 되는지 꽂아보기 전엔 모르는 극악의 파편화 | 칩셋(인증) 값이 더럽게 비싸서 노트북이나 케이블 가격이 미쳐 날뜀 |

#### 한줄 요약

- USB 3.2는 데이터만, USB4는 제조사 맘대로 짬뽕, 썬더볼트는 비싼 대신 모든 기능을 100% 보장한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **디엠에이 어택(DMA Attack, Thunderspy)**: 화면 안 잠긴 노트북 썬더볼트 구멍에 해킹 칩 꽂고, 0.1초 만에 시스템 메모리를 통째로 털어가 버리는 영화 같은 하드웨어 해킹이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 외부 썬더볼트 포트에 해킹 칩 꽂고 메모리 다이렉트(DMA)로 통째로 털어가는 **썬더스파이** 공격 재앙 | OS 단에서 **아이오엠엠유**(IOMMU) 방화벽 빡세게 켜고 썬더볼트 외부 DMA 메모리 접근을 무자비하게 차단 | 노트북 잠겨있을 때 해킹 툴 꽂아서 비밀번호나 메모리 빼가는 하드웨어 털이 완벽 방어 |
| 100W 먹는 모니터에 길거리 천 원짜리 케이블 꽂았다가 속도 반토막 나고 케이블 불타오름 | **이마커** 칩 없는 쓰레기 케이블은 충전량(20W)과 대역폭을 강제로 억제해 버림 | 규격 미달 케이블 때문에 노트북 메인보드가 용접(용융)되는 화재 대참사 절대 방어 |
| USB-C로 화면 띄우면서 동시에 100W 땡기다가 포트 단자가 미친 듯이 뜨거워져 녹아내림 | **USB PD** 칩이 온도 센서랑 연동해서 뜨거워지면 전류를 멱살 잡고 깎아내림(스로틀링) | 포트 과열로 인한 화재나 칩셋 사망을 원천 차단해 안전한 지속 사용 보장 |

#### 한줄 요약

- 메모리 해킹은 IOMMU로 맞고, 선 타들어 가는 건 이마커(칩) 확인하고 온도 센서(스로틀링)로 강제 차단해라.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **직렬 인터페이스 선택 기준(High-Speed Serial Selection Criteria)**: 그냥 폰 충전용 선인지, 모니터 2대에 그래픽카드까지 박을 미친 선인지 용도 멱살을 잡고 규격을 고르는 잣대이다.

</details>

- **직렬 인터페이스 선택 기준** 원칙에 따라, 깡패급 외장 그래픽/다중 고해상도 독(Dock)은 **썬더볼트**, 범용 충전/데이터 짬처리는 **USB4** 채택 기조 확립함

#### 한줄 요약

- 비싸고 확실하게 다 때려 박으려면 썬더볼트를 쓰고, 복불복 운에 맡길 거면 범용 USB를 써라.
