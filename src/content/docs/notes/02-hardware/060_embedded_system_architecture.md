## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **임베디드 시스템(Embedded System)**: 특정 기계 장치나 전자기기 내부에 내장되어 실시간 센싱, 연산, 제어, 통신을 전담하도록 하드웨어와 전용 펌웨어 소프트웨어가 밀결합된 특수 목적 컴퓨팅 시스템.
- **HW/SW 공동 설계(HW/SW Co-Design)**: 비용, 성능, 전력 제약 조건을 만족하기 위해 기능 요구사항을 하드웨어 ASIC/IP와 소프트웨어 알고리즘으로 최적 분할하여 동시 설계 및 검증하는 방법론.

</details>

- 정의/개념: 자원 제약적 환경에서 특정 제어 목적을 달성하기 위해 **MCU/SoC 하드웨어, 실시간 OS(RTOS), 전용 펌웨어**를 통합한 **임베디드 시스템(Embedded System) 아키텍처**
- 배경/필요성: 범용 PC 구조의 높은 전력 소모, 큰 부피, 비결정적 지연시간으로는 **자동차, 가전, 항공, 산업 제어의 엄격한 실시간 마감시간(Deadline)과 원가/신뢰성 제약 동시 충족 불가**

#### 한줄 요약
- 임베디드 시스템은 제한된 자원 내에서 엄격한 실시간 마감시간과 고신뢰성 제어를 달성하기 위해 HW/SW를 최적화한 특수 목적 시스템이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **결정론적 실시간성(Deterministic Real-Time Property)**: 논리적 연산의 정확성뿐만 아니라 사전에 정의된 마감시간(Deadline) 내에 제어 출력이 100% 보장되어야 하는 특성.
- **자원 제약성(Resource Constraints)**: 수십 KB~수 MB의 제한된 메모리, 배터리 구동 초저전력, 소형 폼팩터, 저비용 BoM(Bill of Materials) 한계.

</details>

- **HW/SW 공동 설계(Co-Design)**: 기능의 복잡도와 속도 요구에 따라 하드웨어 가속기(FPGA/IP)와 소프트웨어(RTOS 태스크) 최적 분할
- **결정론적 실시간성(Real-Time)**: 최악 실행 시간(Worst-Case Execution Time, WCET) 분석을 통해 인터럽트 처리 및 제어 마감시간 보장
- 가혹 환경 고신뢰성: 고온, 진동, 전자파 노이즈(EMI) 환경에서 다운을 방지하기 위한 **워치독 타이머(WDT)** 및 페일 세이프(Fail-Safe) 내장

#### 한줄 요약
- HW/SW 동시 설계, 마감시간을 보장하는 결정론적 실시간성, 가혹 환경을 견디는 고신뢰성이 3대 핵심 특징이다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **워치독 타이머(Watchdog Timer, WDT)**: 소프트웨어가 무한 루프나 정지에 빠졌을 때 주기적 킥(Kick) 신호 부재를 감지하여 하드웨어를 강제 리셋하는 독립 카운터 회로.
- **액추에이터(Actuator)**: 마이크로컨트롤러의 디지털 PWM/DAC 제어 신호를 모터 회전, 밸브 개폐, 유압 등 물리적 운동으로 변환하는 구동 장치.

</details>

```text
[임베디드 시스템 4계층 아키텍처]
 ┌─ [1. 응용 소프트웨어 계층] ──── 실시간 제어 알고리즘 / 상태 머신 (FSM)
 │
 ├─ [2. 시스템 소프트웨어 계층] ── 실시간 운영체제 (RTOS) + 하드웨어 추상화 계층 (HAL) / 드라이버
 │
 ├─ [3. MCU / SoC 하드웨어 계층]
 │   ├─ 프로세서 코어 (ARM Cortex-M / RISC-V 코어)
 │   ├─ 온칩 메모리 (Flash 롬 + SRAM 램)
 │   ├─ 타이머 서브시스템 & [워치독 타이머 (WDT)]
 │   ├─ 아날로그 프론트엔드 (ADC / DAC / PWM 발생기)
 │   └─ 결정론적 통신 인터페이스 (CAN, SPI, I2C, UART)
 │
 └─ [4. 물리 환경 인터페이스] ──── 센서 (온도, 압력, 비전) + [액추에이터 (모터, 밸브, 릴레이)]
```

선의 의미: 가지(`├─`, `└─`)는 하드웨어/소프트웨어 소속 및 계층 관계; 센서 신호가 ADC를 거쳐 MCU로 들어오면 RTOS가 연산 후 PWM으로 액추에이터를 제어함

| 구성요소 | 계층 및 소속 | 핵심 엔지니어링 책임 | 주요 특징 |
|:---|:---|:---|:---|
| **프로세서 코어** | MCU 내부 | 센서 데이터 실시간 연산 및 PID/모터 제어 알고리즘 실행 | ARM Cortex-M / RISC-V |
| **온칩 메모리** | MCU 내부 | 펌웨어 코드 저장(Flash) 및 실시간 스택/변수 버퍼(SRAM) | 수십 KB ~ 수 MB |
| **워치독 타이머 (WDT)**| 하드웨어 감시 회로| 소프트웨어 다운 감지 시 시스템 강제 하드웨어 리셋 | 독립 클록 구동 |
| **ADC / PWM 모듈** | 아날로그 I/O | 아날로그 센서 신호 디지털화 및 **액추에이터 듀티비 제어** | 초고속 12-bit ADC |
| **결정론적 통신 버스**| 인터페이스단 | CAN/SPI/I2C 버스를 통한 센서·ECU 간 무충돌 실시간 통신 | 하드웨어 필터링 |
| **RTOS 커널** | 시스템 소프트웨어 | 선점형 우선순위 기반 태스크 스케줄링 및 인터럽트 중계 | FreeRTOS, Zephyr |

#### 한줄 요약
- 임베디드 시스템은 프로세서 코어, 온칩 메모리, 주변 I/O(ADC/PWM), WDT, 센서/액추에이터 및 RTOS 커널로 구성된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **인터럽트 서비스 루틴(Interrupt Service Routine, ISR)**: 센서 신호 입력이나 타이머 만료 시 CPU가 현재 작업을 중단하고 즉각 분기하여 최우선 처리하는 하드웨어 루틴.

</details>

```text
1. 시스템 전원 인가 ➔ 부트로더가 클록, 레지스터, 인터럽트 벡터 테이블 초기화
                      │
                      ▼
2. RTOS 커널 기동 ➔ 주기적 제어 태스크 및 우선순위 스케줄링 등록
                      │
                      ▼
3. 외부 긴급 센서 이벤트 발생 (ADC 완료 또는 CAN 메시지 수신)
                      │
                      ▼
4. 하드웨어 인터럽트(ISR) 즉각 진입 ➔ 센서 데이터 취득 ➔ 제어 태스크 깨움
                      │
                      ▼
5. 제어 알고리즘 연산이 마감시간(Deadline) 내에 완료되었는가?
   ┌──────────────────┴──────────────────┐
[ 마감시간 내 완료 (Pass) ]           [ 마감시간 초과 / 무한 루프 다운 (Fail) ]
   │                                     │
   ▼                                     ▼
6. 액추에이터로 제어 신호(PWM) 즉시 출력 6. 워치독 타이머(WDT) 킥 실패 ➔ 카운터 만료
   ➔ 워치독 타이머 갱신 (WDT Kick)       │
   │                                     ▼
   │                                  7. 하드웨어 강제 리셋 ➔ 페일 세이프(Fail-Safe) 모드 진입
   └──────────────────┬──────────────────┘
                      │
                      ▼
8. 저전력 대기(Sleep) 모드 진입 ➔ 다음 주기 타이머 인터럽트 대기
```

분기 결과: **마감시간 내에 연산이 끝나면** 정상 제어 출력과 WDT 갱신이 이루어지며, **다운 시에는** WDT에 의해 강제 리셋되어 안전을 확보함

#### 한줄 요약
- 부팅 ➔ RTOS 기동 ➔ ISR 센서 감지 ➔ 마감시간 내 연산 및 PWM 출력 ➔ WDT 갱신 ➔ 대기 모드의 6단계 실시간 루프로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **마이크로컨트롤러(Microcontroller Unit, MCU)**: CPU, ROM/Flash, RAM, I/O 포트를 단일 칩에 집적한 초소형·초저전력 제어 전용 프로세서.
- **마이크로프로세서(Microprocessor Unit, MPU / SoC)**: 외장 DRAM과 고성능 MMU를 기반으로 Linux/Android 등 범용 OS를 구동하는 고성능 프로세서.

</details>

| 제어 컴퓨팅 플랫폼 | MCU (마이크로컨트롤러) | MPU / 임베디드 SoC | 임베디드 DSP | 임베디드 FPGA |
|:---|:---|:---|:---|:---|
| 핵심 프로세서 구조 | **단일 칩 내 Flash/RAM/IO 통합** | 고성능 CPU 코어 + 외장 DDR | 고속 MAC 연산기 특화 코어 | 비트스트림 기반 순수 하드웨어 |
| 운영체제 환경 | **Bare-Metal 또는 RTOS (FreeRTOS)**| **임베디드 Linux, Android** | 경량 신호처리 런타임 | OS 없음 (하드웨어 로직) |
| 전력 소모 수준 | **초저전력 (밀리와트~수십 mW)** | 중간 (수 W ~ 15W) | 낮음~중간 (수백 mW ~ 수 W) | 중간~높음 (수 W ~ 수십 W) |
| 실시간 마감시간 보장| **마이크로초($\mu\text{s}$) 단위 완벽 보장** | 밀리초($\text{ms}$) 단위 (가변적) | 마이크로초 단위 신호 가속 | **나노초(ns) 단위 하드웨어 보장** |
| 주요 적용 분야 | **자동차 ECU, 가전 모터, IoT 센서** | **스마트 TV, 차량용 IVI, 게이트웨이**| 레이더/오디오 필터링, 통신 모뎀 | 초고속 영상 전처리, 산업용 통신 |

#### 한줄 요약
- 실시간성과 초저전력이 최우선인 제어에는 MCU가 쓰이고, 복잡한 네트워크와 대형 UI/멀티미디어에는 MPU/SoC가 쓰인다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **A/B 듀얼 뱅크 OTA(A/B Dual-Bank OTA Update)**: 플래시 메모리를 두 파티션으로 나누어 펌웨어를 B에 기록하고 부팅 검증 후 활성화하는 안전 무선 업데이트 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 원격 무선 펌웨어 업데이트(OTA) 중 전원 단절로 인한 칩셋 벽돌(Brick) | **A/B 듀얼 뱅크 플래시 파티셔닝 및 무결성 서명 검증 롤백** | 통신/전원 장애 시 이전 정상 펌웨어 100% 자동 복구 |
| 소프트웨어 교착 상태(Deadlock)로 인한 제어 불능 | **독립 클록 윈도우 워치독 타이머(Window WDT) 구현** | 오동작 시 밀리초 내 강제 리셋 및 안전 모드 진입 |
| 배터리 구동 엣지 장치의 잦은 방전 | **이벤트 기반 딥슬립(Deep Sleep) 모드 및 인터럽트 웨이크업** | 대기 전류 $1\mu\text{A}$ 이하 억제 및 수년 배터리 수명 확보 |

#### 한줄 요약
- 실무에서는 A/B 듀얼 뱅크 OTA로 복구력을 확보하고, 윈도우 WDT로 안전을 지키며, 딥슬립 모드로 배터리를 연장한다.

## Ⅶ. 결론

- 엄격한 자원 제약과 결정론적 실시간성이 요구되는 산업·자동차 제어 환경을 위해 **ARM Cortex-M/RISC-V 기반의 MCU와 선점형 RTOS 아키텍처를 표준 구축**하고, 시스템 안전성을 위해 **독립 하드웨어 워치독 타이머(WDT) 및 A/B 듀얼 뱅크 무선 업데이트(OTA)**를 적용하며, 복합 지능형 단말로 확장 시 **MCU(실시간 제어)와 SoC(AI/통신)가 협업하는 이종 이중화 구조**를 수립하는 고신뢰 임베디드 시스템 설계 확립

#### 한줄 요약
- 임베디드 시스템은 HW/SW 공동 설계를 바탕으로 실시간 마감시간 준수와 무중단 고신뢰성을 달성하는 특화 엔지니어링이다.
