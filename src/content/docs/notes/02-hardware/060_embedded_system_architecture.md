## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **임베디드 시스템(Embedded System)**: 특정 기계 장치나 전자기기 내부에 내장되어 실시간 센싱, 연산, 제어, 통신을 전담하도록 하드웨어와 전용 펌웨어 소프트웨어가 밀결합된 특수 목적 컴퓨팅 시스템.
- **HW/SW 공동 설계(HW/SW Co-Design)**: 비용, 성능, 전력 제약 조건을 만족하기 위해 기능 요구사항을 하드웨어 ASIC/IP와 소프트웨어 알고리즘으로 최적 분할하여 동시 설계 및 검증하는 방법론.

</details>

- 정의/개념: 자원 제약 환경에서 실시간 제어를 위해 HW와 전용 SW를 밀결합한 **임베디드 시스템 아키텍처**
- 배경/필요성: 제한된 자원(메모리, 전력, 연산능력) 및 가혹한 물리적 환경 속에서의 **엄격한 실시간 마감시간(Deterministic Deadline) 및 신뢰성 보장 한계**

#### 한줄 요약
- 임베디드 시스템은 제한된 자원 내에서 엄격한 실시간 마감시간과 고신뢰성 제어를 달성하기 위해 HW/SW를 최적화한 특수 목적 시스템이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **결정론적 실시간성(Deterministic Real-Time Property)**: 논리적 연산의 정확성뿐만 아니라 사전에 정의된 마감시간(Deadline) 내에 제어 출력이 100% 보장되어야 하는 특성.
- **자원 제약성(Resource Constraints)**: 수십 KB~수 MB의 제한된 메모리, 배터리 구동 초저전력, 소형 폼팩터, 저비용 BoM(Bill of Materials) 한계.
- **워치독 타이머(Watchdog Timer, WDT)**: 소프트웨어가 무한 루프나 정지에 빠졌을 때 주기적 킥(Kick) 신호 부재를 감지하여 하드웨어를 강제 리셋하는 독립 카운터 회로.

</details>

- **HW/SW 공동 설계**: 기능 요구에 따라 하드웨어 가속기와 RTOS 태스크 간 최적 분할
- **결정론적 실시간성**: 최악 실행 시간(WCET) 분석을 통한 인터럽트 처리 및 제어 마감시간 보장
- 가혹 환경 고신뢰성: 노이즈 환경 다운 방지를 위한 **워치독 타이머(WDT)** 및 페일 세이프 메커니즘 내장

#### 한줄 요약
- HW/SW 동시 설계, 마감시간을 보장하는 결정론적 실시간성, 가혹 환경을 견디는 고신뢰성이 3대 핵심 특징이다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **액추에이터(Actuator)**: 마이크로컨트롤러의 디지털 PWM/DAC 제어 신호를 모터 회전, 밸브 개폐, 유압 등 물리적 운동으로 변환하는 구동 장치.

</details>

```text
[임베디드 제어 시스템 계층 구조]
  │
  ├─ [응용 소프트웨어 & RTOS] (FreeRTOS / Zephyr 커널)
  │     ├─ [우선순위 선점 스케줄러] (마감시간 엄수 태스크 분배)
  │     └─ [하드웨어 추상화 계층] (HAL 드라이버 및 ISR 핸들러)
  │
  ├─ [마이크로컨트롤러 하드웨어] (MCU / SoC 단일 칩)
  │     ├─ [프로세서 코어] (ARM Cortex-M / RISC-V 코어)
  │     ├─ [온칩 메모리] (내장 Flash ROM 및 SRAM)
  │     ├─ [워치독 타이머] (WDT, 독립 발진기 기반 리셋)
  │     ├─ [아날로그 인터페이스] (ADC / DAC 고속 변환기)
  │     ├─ [타이머 & PWM 유닛] (초정밀 펄스 모터 구동)
  │     └─ [통신 컨트롤러] (CAN-FD, SPI, UART 엔진)
  │
  └─ [물리 인터페이스단] (센서 및 액추에이터)
        ├─ [물리 센서단] (온도/압력/가속도 아날로그 센싱)
        ├─ [액추에이터 구동단] (모터, 밸브 제어 드라이버)
        └─ [제어 네트워크] (차량 및 산업용 CAN 통신망)
```

선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 프로세서 코어 | 센서 데이터와 PID 제어 연산 |
| 온칩 메모리 | 펌웨어와 실시간 변수 저장 |
| 워치독 타이머 (WDT) | 정지 감지 시 하드웨어 리셋 수행 |
| ADC / PWM 모듈 | 센서 변환과 **액추에이터** 제어 |
| 결정론적 통신 버스 | CAN·SPI 기반 무충돌 통신 |
| RTOS 커널 | 우선순위 기반 태스크 스케줄링 |

#### 한줄 요약
- 메모리와 주변 I/O가 모두 칩 안에 들어와 있어 외부 접근마다 생기던 시간 변동이 사라지고, ADC와 PWM이 물리 신호와 디지털 값 사이의 변환을 전담해 코어에는 제어 연산만 남는다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **인터럽트 서비스 루틴(Interrupt Service Routine, ISR)**: 센서 신호 입력이나 타이머 만료 시 CPU가 현재 작업을 중단하고 즉각 분기하여 최우선 처리하는 하드웨어 루틴.

</details>

```text
[시스템 전원 인가 및 부팅 시퀀스 개시]
                     │
                     ▼
1. 부트로더 하드웨어 초기화 및 RTOS 선점형 태스크 스케줄러 기동
                     │
                     ▼
2. 센서 신호 감지 및 하드웨어 인터럽트 서비스 루틴(ISR) 진입
                     │
                     ▼
3. 제어 알고리즘(PID) 연산 및 실시간 마감시간(Deadline) 검증
    ┌────────────────┴────────────────┐
 [ 마감시간 내 완료 (정상 제어) ]    [ 마감시간 초과 / 락업 (오류) ]
    │                                 │
    ▼                                 ▼
4. PWM 액추에이터 제어 신호 출력     4. WDT 킥(Kick) 신호 누락 발생
    │                                 │
    ▼                                 ▼
5. 워치독 타이머 리프레시 갱신       5. WDT 카운터 만료 및 하드웨어 강제 리셋
    │                                 │
    └────────────────┬────────────────┘
                     │
                     ▼
[다음 샘플링 제어 주기 대기 또는 페일 세이프 모드 진입]
```

- 분기 결과: 정해진 마감시간 내 연산이 끝나면 액추에이터를 구동하고 WDT를 갱신하며, 락업 발생 시 WDT가 시스템을 즉시 강제 리셋하여 페일 세이프를 달성함

**동작 원리**

1. 전원 인가 시 부트로더의 클록 및 온칩 메모리 초기화 후 RTOS 커널 실행 및 우선순위 기반 제어 태스크 큐 등록
2. 외부 물리 센서의 아날로그 입력 발생 시 ADC 변환 인터럽트 트리거 및 CPU의 인터럽트 서비스 루틴(ISR) 즉각 전환
3. 획득 센서 데이터의 최우선순위 제어 태스크 전달을 통한 PID 피드백 알고리즘 연산 및 실시간 마감시간(Deadline) 검증
4. 연산 결과 도출에 따른 PWM 타이머 레지스터 갱신 및 모터 드라이버 구동 펄스 출력
5. 제어 사이클 종료 직전 독립 워치독 타이머(WDT) 킥 신호 인가를 통한 카운터 리셋 및 락업 발생 시 하드웨어 강제 리셋 수행

#### 한줄 요약
- 임베디드 제어 루프는 평균 처리 속도가 아니라 최악 실행 시간이 마감시간 안에 드는지로 설계되므로, 성능 여유를 키우기보다 WDT 리셋 같은 실패 시 안전 경로를 먼저 확보한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **마이크로컨트롤러(Microcontroller Unit, MCU)**: CPU, ROM/Flash, RAM, I/O 포트를 단일 칩에 집적한 초소형·초저전력 제어 전용 프로세서.
- **마이크로프로세서(Microprocessor Unit, MPU / SoC)**: 외장 DRAM과 고성능 MMU를 기반으로 Linux/Android 등 범용 OS를 구동하는 고성능 프로세서.

</details>

| 대상 구분 | MCU (마이크로컨트롤러) | MPU / SoC | 임베디드 DSP | 임베디드 FPGA |
|:---|:---|:---|:---|:---|
| 적용 기준 | 초저전력 및 마이크로초 단위 결정론적 실시간 제어 요구 시 | 풍부한 GUI 및 복잡한 네트워킹/멀티미디어 처리 요구 시 | 실시간 오디오/레이더 필터링 및 고속 신호 가속 요구 시 | 나노초 단위 초저지연 하드웨어 로직 변환 및 통신 가속 시 |
| 핵심 특징 | 단일 칩 내 CPU/메모리/I/O 집적, RTOS/Bare-Metal, mW 단위 초저전력, $\mu\text{s}$ 단위 결정론적 마감시간 보장 | 고성능 CPU 코어 + 외장 DDR, Linux/Android 구동, 수 W~15W 전력, 밀리초 단위 응답 및 풍부한 주변 인터페이스 | MAC 연산기 특화 코어, 경량 신호처리 런타임, 수백 mW~수 W 전력, $\mu\text{s}$ 단위 고속 신호 처리 가속 | 비트스트림 기반 하드웨어 로직 게이트 직접 구성, OS 미사용, 수 W~수십 W, 나노초(ns) 단위 하드웨어 실시간성 보장 |
| 한계 | 제한된 연산 성능 및 메모리 확장 한계로 대용량 데이터 처리 불가 | 비결정론적 OS 인터럽트 지연으로 하드 실시간 보장 한계 및 고전력 소모 | 범용 제어 로직 처리 비효율 및 유연성 부족 | 복잡한 RTL 설계 검증(HDL) 비용 및 고가의 BoM 단가 |

#### 한줄 요약
- 실시간성과 초저전력이 최우선인 제어에는 MCU가 쓰이고, 복잡한 네트워크와 대형 UI/멀티미디어에는 MPU/SoC가 쓰인다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **A/B 듀얼 뱅크 OTA(A/B Dual-Bank OTA Update)**: 플래시 메모리를 두 파티션으로 나누어 펌웨어를 B에 기록하고 부팅 검증 후 활성화하는 안전 무선 업데이트 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| OTA 펌웨어 업데이트 중 단절로 벽돌화 | **A/B 듀얼 뱅크 플래시** 및 무결성 검증 롤백 | 펌웨어 갱신 실패 시 자동 복구 |
| 소프트웨어 교착 상태로 인한 제어 불능 | 독립 클록 기반 **윈도우 워치독 타이머(WDT)** 적용 | 오동작 시 밀리초 내 리셋 및 안전 모드 전환 |
| 배터리 구동 엣지 장치의 빠른 방전 | **딥슬립(Deep Sleep)** 및 인터럽트 웨이크업 | 대기 전류 극소화로 배터리 수명 극대화 |

#### 한줄 요약
- 실무에서는 **A/B 듀얼 뱅크 OTA**로 복구력을 확보하고, 윈도우 WDT로 안전을 지키며, 딥슬립 모드로 배터리를 연장한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **최악 실행 시간(Worst-Case Execution Time, WCET)**: 프로세서 캐시 미스, 인터럽트 지연 등을 감안하여 태스크가 완료되는 데 걸리는 이론적 최대 실행 시간.
- **이종 멀티코어(Heterogeneous Multi-Core)**: 실시간 제어용 저전력 MCU 코어와 고성능 앱 프로세서 코어를 단일 칩에 융합한 SoC 구조.

</details>

- 엄격한 실시간성과 초저전력이 요구되는 제어 도메인은 MCU 기반 RTOS(FreeRTOS, Zephyr), 대규모 미디어/네트워크 처리는 임베디드 Linux 기반 SoC가 확고한 업계 표준으로 정립되었으며, 최근 자율주행 및 로보틱스 분야에서는 둘을 단일 칩에 융합한 이종 멀티코어(Heterogeneous Multi-Core) 및 하이퍼바이저 가상화로 급속 진화 중.
- 임베디드 시스템 설계 시 최악 실행 시간(WCET) 기반 데드라인 준수성 검증과 독립 WDT 리셋 및 A/B 뱅크 OTA 무결성 복구 체계의 동시 확립 필수.

#### 한줄 요약
- 임베디드 시스템은 HW/SW 공동 설계를 바탕으로 실시간 마감시간 준수와 무중단 고신뢰성을 달성하는 특화 엔지니어링이다.
