## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **유시에스아이이(Universal Chiplet Interconnect Express)**: 삼성 칩이든 인텔 칩이든 제조사를 가리지 않고, 서로 다른 회사가 만든 반도체 조각(칩렛)들을 하나의 기판에 꽂아도 찰떡같이 통신할 수 있게 만든 전 세계 칩렛 통일 규격이다.
- **다이 대 다이(Die-to-Die)**: 패키지 지붕 아래 모인 칩렛 조각들끼리 0.1밀리미터도 안 되는 미세 구리선을 통해 찰나의 버벅거림 없이 텐서를 미친 듯이 핑퐁 치는 초저지연 통신 기술이다.
- **공급자 종속(Vendor Lock-In)**: A사 칩을 사면 무조건 A사의 호환 칩만 사야 하고, 다른 회사 칩은 핀이 안 맞아 꽂을 수도 없는 노예 같은 독점 생태계 족쇄이다.

</details>

- 정의: 통신 규격을 물리(PHY), 어댑터, 프로토콜 계층으로 3단 분리하여, 서로 다른 제조사가 깎은 칩렛 간 **다이 대 다이** 핑퐁 연동을 합법적으로 보장하는 **유시에스아이이** 개방형 범용 표준
- 배경: 벤더마다 즈그들만 아는 독자 언어로 통신 선을 깔아버려, 한 번 만든 칩렛을 남의 보드에 꽂을 수 없는 치명적인 칩렛 재사용 불가 및 끔찍한 생태계 파편화 파국을 막기 위함

#### 한줄 요약

- 인텔 두뇌(CPU)와 삼성 수족(I/O)을 하나로 조립해도 에러 없이 쌩쌩 돌아가도록, 반도체 회사들이 통신 규칙을 하나로 통일해 버린 칩렛 시대의 만국 공통어이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **계층 분리(Layer Separation)**: 소프트웨어(프로토콜)와 하드웨어(구리선)를 섞지 않고 3층으로 칼같이 쪼개어, 밑바닥 구리선을 광케이블로 바꿔도 윗단 소프트웨어는 코드를 한 줄도 안 고치게 만드는 마법의 설계이다.
- **플릿(Flit, Flow Control Unit)**: 거대한 텐서 덩어리를 좁은 구리선으로 밀어 넣기 위해, 레고 블록처럼 규격이 딱 정해진 크기로 잘게 썰어놓은 데이터 택배 상자이다.
- **순환 중복 검사(Cyclic Redundancy Check)**: 구리선을 넘어오다 전기 노이즈에 튀겨져 데이터가 썩어버리지 않았는지, 택배 상자 겉면에 바코드를 찍어 가차 없이 불량품을 색출하는 깐깐한 검열관이다.
- **재전송(Retransmission)**: 바코드 검사에서 썩은 데이터가 걸리면, 수신 칩이 "데이터 깨졌어! 10번 상자 다시 쏴!"라고 멱살을 잡아 칩 내부 오염을 틀어막는 좀비 복구 시스템이다.
- **적합성(Compliance)**: 네가 만든 칩이 우리 통일 규격을 100% 지켰는지, 핀 위치 하나 전압 1볼트까지 현미경으로 뜯어보는 악독한 통과 의례 검증이다.
- **상호운용성(Interoperability)**: 테스트 통과한 삼성 칩과 인텔 칩을 실제로 기판에 납땜해 붙였을 때, 서로 욕하지 않고 아름답게 핑퐁 치며 돌아가는 꿈의 협업 상태이다.
- **피시아이익스프레스(PCI Express)**: 컴퓨터 부품이면 무조건 따라야 하는 대국민 표준 톨게이트 버스로, 이 규격 위에서도 똑같이 돌아가게 만들어 범용성을 미친 듯이 뻥튀기한다.

</details>

- 상위 딥러닝 트랜잭션과 하위 아날로그 미세 배선 물리 신호를 섞이지 않게 완벽하게 쪼개놓은 **계층 분리** 모듈형 구조를 채택함.
- 칩 내부로 쓰레기 데이터가 들어오는 걸 100% 차단하기 위해, **플릿** 상자 단위로 **순환 중복 검사**를 돌리고 에러 시 하드웨어 자동 **재전송**을 미친 듯이 수행함.
- 서로 앙숙인 이종 파운드리 칩렛 간 믹스앤매치 조립을 합법적으로 허용하는 엄격한 **적합성** 심사 및 완벽한 **상호운용성**을 보장함.

#### 한줄 요약

- 규격을 3층으로 쪼개서(계층 분리) 유연성을 확보하고, 바코드를 찍어(CRC) 썩은 데이터는 다시 받아내며(재전송), 벤더가 달라도 한 몸처럼 돌아가게(상호운용성) 묶어버린다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **프로토콜 계층(Protocol Layer)**: 칩렛 통신의 꼭대기 층으로, "메모리 1번지 읽어와" 같은 사람 말을 기계어로 번역하여 아래로 던져주는 똑똑한 소프트웨어 대가리이다.
- **다이 대 다이 어댑터(D2D Adapter)**: 대가리가 던진 기계어를 택배 상자(플릿)에 쑤셔 넣고, 바코드(CRC)를 붙인 뒤 에러 나면 멱살 잡고 다시 받아오는 중간 관리자(노가다 십장) 계층이다.
- **물리 계층(Physical Layer)**: 0과 1의 디지털 신호를 미세한 아날로그 전압(차동 신호)으로 바꿔, 구리선을 뚫고 옆 칩으로 전기를 펌핑해 쏘아대는 무식한 육체노동 층이다.
- **패키지 채널(Package Channel)**: 칩과 칩 사이의 바닥을 깔아주는 실리콘 기판(인터포저) 속에 머리카락 1/100 굵기로 촘촘하게 파놓은 물리적 구리선 톨게이트이다.

</details>

```text
[ 유시에스아이이(UCIe) 개방형 표준 3계층 스택 및 칩렛 통신 아키텍처 ]
                   [ 상위 딥러닝 트랜잭션 / 애플리케이션 ]
                                     │
+------------------------------------▼------------------------------------+
| 1. 프로토콜 계층 (PCIe / CXL 등 상위 명령 번역 및 맵핑)                   |
| 2. 다이 대 다이 어댑터 계층 (택배 포장, 에러 바코드 각인 및 멱살 재전송)  |
| 3. 아날로그 물리 계층 (디지털 0/1을 전압으로 펌핑하여 쏘아대는 포병대)    |
+------------------------------------▼------------------------------------+
                                     │
             [ 4. 패키지 채널 (기판 바닥에 깔린 미세 구리선망) ]
```

| 구성요소 | 책임 |
|:---|:---|
| 상위 **프로토콜 계층** | **피시아이익스프레스** 및 컴퓨터 익스프레스 링크(CXL) 등 상위 통신 트랜잭션의 기계어 인코딩 및 맵핑 통제 제어 |
| **다이 대 다이 어댑터** 계층 | 거대 데이터를 **플릿** 상자로 캡슐화 포장, **순환 중복 검사** 에러 바코드 생성, 불량 시 **재전송** 멱살 제어 및 물리단 통제 |
| 아날로그 **물리 계층** | 주대역(고속도로) 및 측대역(국도) 차동 신호 송수신, 아날로그 신호 증폭 펌핑 및 핀 개수 억지로 맞추는 전기적 레인 정렬 |
| 하부 **패키지 채널** | 인터포저 기판 바닥에 깔린 고밀도 미세 구리선 전송선 및 칩을 기판에 붙이는 실리콘 마이크로 범프 물리 통로 제공 |

#### 한줄 요약

- 대가리(프로토콜)가 명령하면 중간 십장(어댑터)이 상자에 담아 바코드를 찍고, 포병대(물리 계층)가 전기 신호로 펌핑해 바닥 구리선(채널)으로 쏴버리는 3단계 공장이다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **주대역(Mainband)**: 텐서나 학습 데이터 같은 어마어마한 용량의 짐 덩어리들을 수백 GB/s 속도로 미친 듯이 쏟아붓는 메인 8차선 고속도로 데이터 채널이다.
- **측대역(Sideband)**: 통신을 시작하기 전 "너 살아있냐? 핀 몇 개냐?" 하고 귓속말을 나누거나, 온도가 높아지면 "잠깐 속도 줄여"라고 통제 신호만 주고받는 1차선 샛길(국도)이다.
- **레인(Lane)**: 메인 8차선 고속도로에 그어진 1차선, 2차선 같은 물리적인 전선 한 가닥으로, 이 레인 수백 개를 묶어야 비로소 무식한 대역폭이 나온다.

</details>

```text
[ 유시에스아이이 3계층 스택 기반 칩렛 패킷 전송 및 멱살잡이 오류 제어 흐름 ]
                               │
                               ▼
  [ 1. 어댑터에서 상위 명령을 택배 상자(플릿)로 썰고 바코드(CRC) 쾅 찍어 포장 ]
                               │
                               ▼
   [ 2. 샛길(측대역)로 인사 끝낸 뒤, 8차선 고속도로(주대역)로 데이터 미친 듯이 펌핑 ]
                               │
                               ▼
       [ 3. 수신 칩 포병대가 신호를 정렬하고 바코드 뜯어보며 불량품 가차 없이 색출 ]
                               │
            +---------------------------------------+
            |        [ 바코드 불량 에러 감지? ]     |
            |        /                      \       |
            |    [ 예 ]                  [ 아니요 ] |
            |      │                         │      |
            | 4. 썩은 패킷 폐기         5. 무결한 패킷만|
            | 및 멱살잡고 재전송 요구   상위 명령 복원  |
            |  (1~3 핑퐁 재수행)       (로직으로 올려줌)|
            +---------------------------------------+
```

### 동작 원리

1. 상위 프로토콜 플릿 인코딩: 딥러닝 트랜잭션을 **다이 대 다이 어댑터**에서 억지로 쪼개어 **플릿** 상자 구조로 변환한 뒤 무결성 바코드를 잔인하게 인코딩함.
2. 주대역 물리 신호 전송: **측대역** 샛길을 통한 칩 초기화 밀당이 끝나면, **주대역** **레인** 고속도로로 데이터를 냅다 고속 펌핑 발사함.
3. 수신 신호 및 플릿 검증: 수신 측 물리 계층이 흔들린 레인 신호를 각 잡고 정렬하며, 어댑터가 패킷 순서 꼬임과 무결성을 현미경처럼 깐깐하게 검증함.
4. 에러 플릿 자동 재전송: 털끝만 한 에러라도 터지면 송신 측으로 **재전송** 요구 멱살을 즉각 인가하고, 오류 플릿을 새것으로 받아내어 핑퐁 복구함.
5. 무결성 상위 요청 복원: 지옥 같은 검문을 통과한 무결한 플릿 상자들만 원래의 상위 프로토콜 명령으로 복원하여 칩렛 두뇌 로직에 안전하게 바침.

#### 한줄 요약

- 상자로 썰어서(플릿) 메인 도로(주대역)로 냅다 쏘면, 받은 놈이 바코드를 뜯어보고 썩은 건 버리고 다시 쏘라고 멱살을 잡아(재전송) 무결점 데이터만 두뇌에 올려보낸다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **독자 다이 대 다이 링크(Proprietary D2D Link)**: "표준? 알게 뭐야, 우리 칩은 우리가 만든 선으로만 통신할 거야" 라며 애플이나 구글이 자기네 칩 덩어리 안에만 깔아놓은 폐쇄적인 커스텀 통신망이다.
- **칩렛 재사용(Chiplet Reuse)**: 인텔이 깎아놓은 싸구려 I/O 칩 조각 하나를 사 와서, 내가 만든 AI 가속기 옆에 찰싹 붙여도 아무 에러 없이 작동하여 개발비 수백억을 아끼는 기적의 짬짜면 조립이다.

</details>

| 비교 항목 | **유시에스아이이** 규격 (UCIe) | **독자 다이 대 다이 링크** (Proprietary) |
|:---|:---|:---|
| 시스템 적용 최적 기준 | 이종 벤더 파운드리의 눈물겨운 **칩렛 재사용** 및 삼성, TSMC, 인텔 칩들의 짬짜면 믹스앤매치 프랑켄슈타인 조립 절대 필요 시 | 단일 회사 내부의 전용 하드웨어 칩 조각들만 극한으로 밀착 최적화하여 0.1나노초의 핑퐁 성능만 영혼까지 쥐어짤 시 |
| 아키텍처 핵심 구현 특징 | 전 세계 반도체 마피아 제조사들이 합의한 3층 개방형 **계층 분리** 범용 통일 표준 프로토콜 스택 규격 철저 준수 | 특정 회사 엔지니어들만 알아먹을 수 있는 폐쇄적이고 이기적인 커스텀 하드웨어 통신 프로토콜 배선 떡칠 |
| 극복해야 할 태생적 한계점 | 이종 제조사 간 **상호운용성** 검증을 통과하기 위한 지옥 같은 난이도 및 억지로 표준을 맞추려 낭비되는 래퍼 회로 기판 면적 오버헤드 낭비 | 칩이 인질로 잡히는 끔찍한 **공급자 종속**(Lock-In) 파국 발생 및 한 번 깎은 칩렛 조각을 남의 시스템에 절대 재사용할 수 없는 돈 낭비 |

#### 한줄 요약

- 남의 회사 칩을 사 와서 레고처럼 조립해 가성비를 뽑으려면 UCIe 통일 규격을 따라야 하고, 호환성 다 포기하고 속도 끝판왕을 보려면 독자 규격을 밀고 나가면 된다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **비트 에러율(Bit Error Rate)**: 10억 개의 비트를 구리선으로 쐈을 때 노이즈를 먹고 1에서 0으로 찌그러진 불량 비트가 몇 개나 나오는지 세는 통신 품질 최악의 성적표이다.
- **신호 눈 마진(Signal Eye Margin)**: 오실로스코프로 전기 신호를 찍었을 때 눈깔(Eye) 모양이 쩍 벌어져 있어야 신호가 뚜렷한 건데, 이 눈이 감겨있으면 노이즈에 잡아먹힌 쓰레기 신호라는 증거이다.
- **오류 주입(Error Injection)**: 칩이 평화롭게 돌아갈 때, 일부러 선을 끊거나 노이즈 전압을 팍 튀겨버려(주입) "너 이래도 안 뻗고 재전송할 수 있어?"라고 테스트하는 하드코어 고문 기법이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 파운드리(삼성/TSMC) 간 칩렛 신호 전압 레벨 차이로 통신이 엇갈려 고속도로(주대역) 칩 기동이 실패하는 참사 발생 | 샛길(**측대역**) 상태 채널로 눈치를 보며 실시간 모니터링 후, 자동 레인 데그라데이션(Degradation)으로 통신 속도 억지 강등 조치 | 칩이 쇼트나서 뻗는 것을 막고 굼벵이 속도라도 최소한의 핑퐁 기동 가용성을 확보하는 100% 방어망 구축 |
| 다이 대 다이 좁아터진 물리 채널의 미세 노이즈 간섭으로 인한 치명적인 **비트 에러율**(BER) 솟구침 떡상 현상 | 아날로그 물리 신호 파형의 **신호 눈 마진** 깐깐한 검증 및 어댑터 단의 하드웨어 좀비 무한 **재전송** 떡칠 루프 가동 | 칩 내부로 쓰레기 데이터 유입 완벽 차단 및 쓸데없는 재전송 핑퐁으로 인한 유효 대역폭 둔화 스로틀링 방어 |
| 개별 칩렛은 합격이나, 막상 인텔과 TSMC 칩을 기판에 붙여놓으면 **상호운용성** 불일치로 시스템 전체가 뻗어버리는 현상 | 비싼 테스트 장비로 하드코어 억지 **오류 주입** 및 이종 파운드리 칩 간 핑퐁 파이프라인 통합 교차 검증 강제 수행 | 삼성, 인텔, TSMC 칩을 내 맘대로 섞어 쓰는 멀티 벤더 칩렛 조립 가용성 확보 및 노예 생태계 탈출 해방 보장 |

#### 한줄 요약

- 속도가 엇갈리면 기어를 낮춰 생존하고(데그라데이션), 노이즈가 끼면 재전송으로 멱살을 잡으며, 칩을 조립한 뒤 억지로 에러를 주입해 맷집을 뜯어봐야 칩이 실전에서 안 죽는다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **D2D 인터페이스 선택 기준(D2D Interface Selection Criteria)**: 구글, 아마존 같은 놈들이 반도체 칩을 엮을 때, 범용 생태계에 올라타서 남의 부품을 재활용할지 즈그들만의 폐쇄적인 끝판왕 성벽을 쌓을지 결정짓는 잔인한 정치적 잣대이다.

</details>

- **D2D 인터페이스 선택 기준**에 따라 남의 칩을 재활용하여 멀티 벤더 칩렛 생태계에 편승할 시 **유시에스아이이**(UCIe), 나 홀로 전용 하드웨어 단일 최적화 끝판왕을 찍을 시 **독자 다이 대 다이 링크** 선택을 단호히 결정함

#### 한줄 요약

- 부품을 레고처럼 싸게 떼다 붙여 가성비 프랑켄슈타인 칩을 만들 거면 무조건 UCIe 규격을 따라야 하고, 독고다이로 괴물 칩을 깎을 거면 즈그들만의 독자 링크를 깔면 된다.
