## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **UCIe(Universal Chiplet Interconnect Express)**: 서로 다른 파운드리(TSMC, Intel, 삼성)와 이종 제조 공정에서 생산된 칩렛(Chiplet) 다이들을 단일 패키지 내부에서 초고속·초저지연·초저전력으로 상호 연결하는 개방형 산업 표준 다이 간(Die-to-Die) 인터페이스 규격.
- **다이 간 인터커넥트(Die-to-Die Interconnect, D2D)**: 단일 패키지 내부에서 개별 실리콘 다이들을 고밀도로 결합하여 단일 칩처럼 동작하게 하는 온패키지 통신 기술.

</details>

- 정의/개념: 이종 칩렛 간 플러그 앤 플레이 상호운용성을 보장하기 위해 프로토콜 계층, D2D 어댑터 계층, 물리 계층(PHY)을 표준화한 **UCIe(Universal Chiplet Interconnect Express) 개방형 D2D 인터페이스 표준**
- 배경/필요성: 칩렛 도입 시 반도체 제조사별 독자 D2D 프로토콜 난립으로 인한 **파운드리 간 이종 칩렛 상호 결합 불가 및 반도체 IP 생태계 파편화 극복**

#### 한줄 요약
- UCIe는 개방형 표준 규격을 통해 서로 다른 제조사의 이종 칩렛을 단일 패키지 안에서 레고 블록처럼 결합할 수 있게 한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **FDI / RDI(Flit-aware D2D Interface / Raw D2D Interface)**: 프로토콜 계층과 D2D 어댑터 간(FDI), D2D 어댑터와 PHY 계층 간(RDI)을 연결하는 표준 내부 인터페이스 규격.
- **CRC 하드웨어 재전송**: 데이터 무결성을 위해 Flit 단위 순환 중복 검사(CRC)를 수행하고 오류 검출 시 하드웨어 레벨에서 1~2사이클 내 즉시 무손실 재전송하는 메커니즘.

</details>

- 3계층 모듈형 표준 아키텍처: **프로토콜 계층(PCIe/CXL), D2D 어댑터 계층, 물리 계층(PHY)**으로 분리하여 각 계층의 독립적 진화 보장
- 이중 패키징 지원: 표준 2D 유기 기판(Standard)과 2.5D/3D 실리콘 인터포저(Advanced) 패키징을 단일 표준 규격으로 모두 지원
- 초고효율 및 무손실 전송: 비트당 0.5pJ 미만의 **초저에너지(pJ/bit)와 Flit 기반 CRC 재전송**을 통해 무손실 고신뢰성 D2D 통신 보장

#### 한줄 요약
- 3계층 모듈형 아키텍처와 Flit 기반 CRC 재전송을 통해 이종 파운드리 칩렛 간 무손실 초고속 연결을 실현한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **플릿(Flow Control Unit, Flit)**: D2D 어댑터와 물리 계층 간에 흐름 제어, 패킷 라우팅 및 CRC 무결성 검증을 수행하는 정형화된 데이터 전송 단위.
- **사이드밴드 채널(Sideband Channel)**: 메인 고속 데이터 레인과 독립적으로 800MHz 저주파 클록으로 동작하여 링크 초기화, 기능 협상, 전력 관리를 수행하는 보조 채널.

</details>

```text
[UCIe 3계층 표준 아키텍처]
 ┌─────────────────────────────────────────────────────────────┐
 │ 1. 프로토콜 계층 (Protocol Layer)                           │
 │    ├─ PCIe 6.0 / CXL 3.0 네이티브 트랜잭션 매핑             │
 │    └─ 사용자 정의 스트리밍 프로토콜 (Streaming Mode)        │
 └──────────────────────────────┬──────────────────────────────┘
                                │ FDI (Flit-aware D2D Interface)
 ┌──────────────────────────────▼──────────────────────────────┐
 │ 2. D2D 어댑터 계층 (D2D Adapter Layer)                      │
 │    ├─ Flit 패킷화 & 흐름 제어 (Credit-Based Flow Control)    │
 │    ├─ CRC 계산 & 하드웨어 링크 레벨 재전송 (Link Retransmit)│
 │    └─ 링크 상태 머신 제어 (LSM: Active, Low Power, Retrain) │
 └──────────────────────────────┬──────────────────────────────┘
                                │ RDI (Raw D2D Interface)
 ┌──────────────────────────────▼──────────────────────────────┐
 │ 3. 물리 계층 (Physical Layer / PHY)                         │
 │    ├─ 메인밴드 레인 어레이 (Mainband: Data, DQS, Clock)      │
 │    ├─ 사이드밴드 채널 (Sideband: 링크 훈련, 협상, 레인 리맵)│
 │    └─ AFE (Analog Front-End / 드라이버 & 수신기)            │
 └──────────────────────────────┬──────────────────────────────┘
                                │ 마이크로 범프 / C4 범프 배선
 ┌──────────────────────────────▼──────────────────────────────┐
 │ 4. 패키지 물리 채널 (Advanced 2.5D 인터포저 / Standard 2D 기판)│
 └─────────────────────────────────────────────────────────────┘
```

선의 의미: 가지(`├─`, `└─`)는 하드웨어 소속 및 포함 관계; FDI와 RDI 표준 버스를 통해 계층 간 완벽한 독립성을 유지함

| 구성요소 | 소속 및 계층 | 핵심 엔지니어링 책임 | 주요 특징 |
|:---|:---|:---|:---|
| **프로토콜 계층** | 최상위 계층 | CXL.mem(메모리), PCIe 6.0(I/O), 독자 스트리밍 패킷 처리 | PCIe/CXL 완벽 호환 |
| **D2D 어댑터 계층** | 중간 관리 계층 | **FDI-RDI 간 Flit 변환, 크레딧 흐름 제어, CRC 재전송** | 무손실 링크 보장 |
| **물리 계층 (PHY)** | 하드웨어 전송단 | 고속 메인 데이터 레인 구동, 클록 정렬, **사이드밴드 협상** | $4\sim 32\text{ Gbps}$ 레인 |
| **FDI / RDI 인터페이스**| 계층 간 표준 버스| 프로토콜-어댑터(FDI), 어댑터-PHY(RDI) 간 독립성 보장 | 표준 내부 인터페이스 |
| **패키지 채널** | 물리 패키징 | 마이크로 범프(Advanced) 또는 C4 범프(Standard) 물리 배선 | 실리콘 인터포저/기판 |

#### 한줄 요약
- UCIe는 프로토콜 계층, D2D 어댑터, PHY 계층 및 물리 채널이 FDI/RDI 표준 버스로 결합된 모듈형 구조이다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **링크 훈련(Link Training)**: 칩 전원 인가 시 사이드밴드를 통해 양 다이 간 전압, 클록, 전송 속도를 협상하고 메인 레인의 스큐를 자동 보정하는 초기화 절차.

</details>

```text
1. 칩렛 패키지 전원 인가 및 하드웨어 리셋 해제
                      │
                      ▼
2. 사이드밴드(Sideband) 초기화 및 다이 간 기능 협상 (Capability Exchange)
   ➔ 지원 프로토콜(PCIe/CXL), 패키지 유형(Advanced/Standard), 전압 조건 교환
                      │
                      ▼
3. 메인밴드 PHY 링크 훈련 (레인 스큐 보정, 클록 위상 동기화, 레인 반전 감지)
                      │
                      ▼
4. D2D 어댑터 상태 전이 (Link Active: 활성 통신 상태 진입)
                      │
                      ▼
5. 프로토콜 패킷을 Flit 단위로 캡슐화 ➔ CRC 검증 코드 부착 ➔ 메인밴드 전송
                      │
                      ▼
6. 수신측 D2D 어댑터의 CRC 무결성 검증
   ┌──────────────────┴──────────────────┐
[ CRC 오류 검출 (Bit Error) ]         [ CRC 정상 통과 (Pass) ]
   │                                     │
   ▼                                     ▼
7. 하드웨어 링크 레벨 즉각 재전송         7. 상위 프로토콜 계층으로 패킷 전달 완료
   (Link Retransmit 수행)                │
   │                                     │
   └──────────────────┬──────────────────┘
                      │
                      ▼
8. 정상 패킷 트랜잭션 연속 처리 (마이크로초 이하 초저지연 유지)
```

분기 결과: **링크 훈련과 CRC 검증을 통해** 전송 오류 발생 시에도 하드웨어 레벨에서 즉시 무손실 복구되어 신뢰성을 보장함

#### 한줄 요약
- 사이드밴드 협상 ➔ 메인밴드 링크 훈련 ➔ Active 상태 전이 ➔ Flit 전송 ➔ CRC 검증 및 오류 시 하드웨어 재전송 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **UCIe Advanced**: 실리콘 인터포저/RDL 브리지를 통해 마이크로 범프(25~55$\mu\text{m}$)로 연결하는 고밀도 첨단 패키징.
- **UCIe Standard**: 일반 유기 기판(Substrate) 상에서 C4 범프(100~130$\mu\text{m}$)로 연결하는 경제적인 표준 패키징.

</details>

| 패키징 유형 | UCIe Advanced (첨단 패키징) | UCIe Standard (표준 패키징) | 독자 D2D 규격 (Proprietary) |
|:---|:---|:---|:---|
| 패키징 기술 | **실리콘 인터포저, 실리콘 브리지 (EMIB/CoWoS)** | 표준 유기 기판 배선 (Standard Substrate) | 제조사별 전용 맞춤형 기판 |
| 범프 피치 (Pitch) | **초미세 피치 ($25\sim 55\mu\text{m}$)** | 표준 피치 ($100\sim 130\mu\text{m}$) | 다양함 |
| 선간 대역폭 밀도 | **최고 ($1300\sim 3200\text{ GB/s/mm}$)** | 중간 ($130\sim 320\text{ GB/s/mm}$) | 독자 규격에 종속 |
| 에너지 효율 (pJ/bit)| **최고 (< 0.25 pJ/bit)** | 우수 (< 0.5 pJ/bit) | 가변적 |
| 생태계 및 호환성 | **글로벌 개방형 표준 (타사 칩렛 결합 가능)** | **글로벌 개방형 표준 (타사 칩렛 결합 가능)** | **타사 칩렛과 상호운용 불가 (Lock-in)** |

#### 한줄 요약
- 초고밀도 대용량 AI 프로세서에는 UCIe Advanced가, 중저가 모바일/임베디드에는 UCIe Standard가 최적의 선택이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **레인 리매핑(Lane Remapping)**: 패키징 조립 후 특정 데이터 라인이 단선되었을 때 사전에 배치된 예비(Spare) 레인으로 물리 연결을 우회 교체하는 결함 복구 기술.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 패키징 후 초미세 범프 단선으로 인한 칩 전체 폐기 위험 | **사이드밴드 기반 자동 레인 리매핑(Lane Remapping)** | 결함 레인 즉각 치환 및 패키징 수율 99% 확보 |
| 이종 파운드리 칩렛 간 공정 산포로 인한 타이밍 스큐 | **AFE 적응형 등화기(Equalization) 및 동적 위상 보정** | 비트 에러율(BER $< 10^{-15}$) 만족 |
| 상이한 클록 도메인으로 인한 버퍼 오버플로/언더플로 | **D2D 어댑터 계층의 엄격한 크레딧 기반 흐름 제어** | 버퍼 넘침 차단 및 꼬리 지연시간 단축 |

#### 한줄 요약
- 실무에서는 레인 리매핑으로 조립 수율을 지키고, 적응형 등화기로 스큐를 잡으며, 크레딧 제어로 무손실을 보장한다.

## Ⅶ. 결론

- 글로벌 반도체 공급망의 파편화를 극복하고 이종 칩렛 생태계를 구축하기 위해 **프로토콜·어댑터·PHY의 3계층 모듈형 아키텍처를 정의한 UCIe(Universal Chiplet Interconnect Express) 표준을 전면 채택**하고, 초고성능 AI 가속기에는 **UCIe Advanced 2.5D 패키징**을 적용하며, 수율 보전을 위해 **하드웨어 레인 리매핑 및 CRC 무손실 재전송 기술**을 필수 구현하는 표준 칩렛 반도체 시스템 설계 확립

#### 한줄 요약
- UCIe는 모듈형 칩렛 반도체 생태계를 완성하는 글로벌 개방형 표준 인터페이스이며, 이종 파운드리 칩렛 통합의 표준이다.
