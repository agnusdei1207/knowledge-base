## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **UCIe(Universal Chiplet Interconnect Express)**: 서로 다른 파운드리(TSMC, Samsung, Intel)와 공정에서 제조된 이종 칩렛 간에 다이 대 다이(D2D) 상호 연결을 지원하는 개방형 산업 표준.
- **D2D(Die-to-Die)**: 단일 패키지 내부에서 인접한 칩렛 간에 테라바이트급 초고대역폭과 피코초 단위 저지연을 제공하는 온패키지 물리 인터페이스.
- **Vendor Lock-in(공급자 종속)**: 특정 제조사의 독자 D2D 프로토콜에 종속되어 타사 칩렛을 혼합 조립할 수 없는 폐쇄성.

</details>

- 정의/개념: 이종 파운드리 및 제조사 간 칩렛(Chiplet) 다이를 패키지 수준에서 상호 연결하기 위해 프로토콜, D2D 어댑터, 물리(PHY) 계층으로 3단 분리 표준화한 개방형 산업 상호 연결 규격
- 배경/필요성: 벤더별 독자 D2D 규격에 따른 공급자 종속(Lock-in)과 칩렛 재사용 불가 한계를 극복하고, **다양한 벤더의 칩렛을 레고 블록처럼 결합하는 개방형 생태계 구축**

#### 한줄 요약

- 3계층 스택 기반으로 **이종 칩렛 간 플러그 앤 플레이 및 초고대역폭 D2D 표준화**

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **3계층 분리 스택**: Protocol Layer(PCIe/CXL), D2D Adapter(Flit/CRC/Replay), Physical Layer(PHY)로 분리되어 상위 호환성을 유지하는 구조.
- **Flit(Flow Control Unit)**: 고정 크기(256B 또는 68B)의 데이터 단위로 헤더, 페이로드, CRC를 포함하여 결정론적 전송을 보장.

</details>

- 상위 트랜잭션과 하위 패키징 기술을 독립적으로 발전시키는 모듈형 **3계층 분리(Protocol-Adapter-PHY) 구조** 채택
- 칩 내부 데이터 오염을 차단하기 위한 **Flit 단위 CRC 검증** 및 하드웨어 자동 **링크 레벨 재전송(Link-Level Replay)** 내장
- 기존 소프트웨어 스택과 100% 호환되는 **PCIe 및 CXL 프로토콜 네이티브 매핑** 지원

#### 한줄 요약

- **3계층 분리 스택·Flit 기반 CRC/하드웨어 재전송·표준 프로토콜(PCIe/CXL) 매핑**

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **Protocol Layer**: PCIe 6.0/7.0, CXL 2.0/3.0 및 사용자 정의 스트리밍 프로토콜을 매핑하는 상위 계층.
- **D2D Adapter**: 링크 상태 관리, Flit 패킹, 흐름 제어, CRC 계산 및 오류 시 재전송(Replay)을 전담하는 중간 계층.
- **Physical Layer(PHY)**: Mainband(고속 데이터 레인)와 Sideband(저속 제어/초기화 링크)로 구성된 아날로그 인터페이스.

</details>

```text
[ UCIe 개방형 표준 3계층 아키텍처 구조도 ]
┌─────────────────────────────────────────────────────────────┐
│ 1. 프로토콜 계층 (Protocol Layer)                           │
│  ├─ PCIe 6.0 / 7.0 프로토콜                                 │
│  ├─ CXL 2.0 / 3.0 (CXL.io, CXL.cache, CXL.mem)              │
│  └─ 사용자 정의 스트리밍 프로토콜 (Streaming Protocol)      │
└──────────────────────────────┬──────────────────────────────┘
                               │ (FDI: Flit-to-Die Interface)
┌──────────────────────────────┴──────────────────────────────┐
│ 2. D2D 어댑터 계층 (Die-to-Die Adapter Layer)               │
│  ├─ Flit 패킹 / 언패킹 및 가상 채널 중재                     │
│  └─ 링크 레벨 오류 관리 (CRC 생성 및 하드웨어 Replay 버퍼)   │
└──────────────────────────────┬──────────────────────────────┘
                               │ (RDI: Raw Die Interface)
┌──────────────────────────────┴──────────────────────────────┐
│ 3. 물리 계층 (Physical Layer : PHY)                         │
│  ├─ Mainband (초고속 차동 데이터 레인 모듈)                  │
│  └─ Sideband (800MHz 초기화 및 링크 훈련 제어 채널)          │
└──────────────────────────────┬──────────────────────────────┘
                               │
┌──────────────────────────────┴──────────────────────────────┐
│ 4. 패키지 채널 (Standard 2D / Advanced 2.5D Interposer 배선) │
└─────────────────────────────────────────────────────────────┘
```

선의 의미: 프로토콜 계층(PCIe/CXL), D2D 어댑터, 물리 계층(PHY) 및 패키지 채널(표준/첨단) 간의 UCIe 스택 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 상위 프로토콜 계층 | **피시아이익스프레스** 및 컴퓨터 익스프레스 링크(CXL) 등 상위 통신 트랜잭션의 기계어 인코딩 및 맵핑 통제 제어 |
| 다이 대 다이 어댑터 계층 | 거대 데이터를 **플릿** 상자로 캡슐화 포장, **순환 중복 검사** 에러 바코드 생성, 불량 시 **재전송** 멱살 제어 및 물리단 통제 |
| 아날로그 물리 계층 | 주대역(고속도로) 및 측대역(국도) 차동 신호 송수신, 아날로그 신호 증폭 펌핑 및 핀 개수 억지로 맞추는 전기적 레인 정렬 |
| 하부 패키지 채널 | 인터포저 기판 바닥에 깔린 고밀도 미세 구리선 전송선 및 칩을 기판에 붙이는 실리콘 마이크로 범프 물리 통로 제공 |

#### 한줄 요약

- **프로토콜 계층(PCIe/CXL)·D2D 어댑터(Flit/CRC)·물리 계층(Mainband/Sideband)·패키지 채널**

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Sideband Link Training**: 800MHz 저속 사이드밴드를 통해 칩렛 간 전압, 클록, 레인 상태를 사전 교섭하고 메인밴드를 활성화하는 절차.

</details>

```text
[ UCIe 패킷 전송 및 오류 제어 흐름 ]
                         │
                         ▼
   [ 1. D2D 어댑터가 상위 PCIe/CXL 요청을 Flit 단위로 패킹 및 CRC 각인 ]
                         │
                         ▼
   [ 2. Sideband 훈련 후 Mainband 고속 레인으로 Flit 물리 전송 ]
                         │
                         ▼
   [ 3. 수신 측 PHY가 신호 디스큐(Deskew) 및 Flit CRC 무결성 검증 ]
                         │
        +─────────────────────────────────────────+
        │             [ CRC 오류 발생? ]          │
        │             /                \          │
        │         [ 예 ]             [ 아니오 ]   │
        │           │                    │        │
        │   4. NAK 전송 및        5. 정상 Flit   │
        │      하드웨어 Replay       프로토콜 복원│
        +─────────────────────────────────────────+
```

**동작 원리**

1. **Flit 생성**: D2D 어댑터가 상위 PCIe/CXL 트랜잭션을 수신하여 Flit으로 쪼개고 CRC 바코드 계산
2. **사이드밴드 훈련 & 메인밴드 전송**: Sideband로 링크 파라미터 교섭 후 Mainband 레인으로 전기 신호 전송
3. **신호 정렬 및 검증**: 수신 측 PHY가 레인 간 스큐(Skew)를 보정하고 어댑터에서 Flit CRC 검증
4. **오류 재전송**: CRC 에러 감지 시 즉시 NAK를 발송하고 Replay 버퍼에서 해당 Flit 재전송
5. **상위 복원**: 검증을 통과한 Flit을 원래 프로토콜 트랜잭션으로 복원하여 수신 칩렛 코어에 전달

#### 한줄 요약

- Flit 패킷 인코딩 $\to$ **Sideband 핸드셰이크 & Mainband 전송 $\to$ CRC 무결성 검증 $\to$ 오류 시 재전송 / 성공 시 상위 전달**

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **UCIe vs 독자 D2D vs PCIe**:
  - UCIe: 개방형 표준, 멀티 벤더 이종 칩렛 믹스앤매치, 초고밀도
  - 독자 D2D: 단일 벤더 폐쇄형, 최적화 극대화, 타사 칩렛 재사용 불가 (Apple UltraFusion)
  - PCIe: 보드 레벨 표준 버스, 긴 전송 거리, 칩렛 내부 적용 불가 (높은 pJ/bit)

</details>

| 비교 항목 | UCIe 표준 규격 | 독자 D2D 링크 (Proprietary) | PCIe 보드 레벨 인터커넥트 |
|:---|:---|:---|:---|
| 표준화 및 생태계 | 산업 표준 개방형 규격 (Intel/TSMC/Samsung/AMD) | 특정 벤더 폐쇄형 커스텀 인터페이스 (Apple UltraFusion) | 산업 표준 보드 레벨 버스 인터페이스 |
| 대역폭 밀도 및 에너지 | 초고밀도 대역폭 ($>1.3\text{TB/s/mm}$), 초저전력 ($<0.5\text{pJ/bit}$) | 최고 수준의 대역폭 및 극단적 온다이 최적화 | 상대적 낮은 대역폭, 높은 전력 소모 ($>5\text{pJ/bit}$) |
| 한계 및 오버헤드 | 프로토콜 래퍼 회로 면적 소모, 상호운용 검증 난제 | 단일 벤더 종속(Lock-in), 타사 칩렛 재사용 불가 | 칩렛 간 연결 불가 (패키지 외부 보드 배선 전용) |

#### 한줄 요약

- 개방형 멀티 벤더 칩렛은 **UCIe**, 단일 벤더 최고 성능은 **독자 D2D**, 보드 확장은 **PCIe**

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Lane Degradation(레인 데그라데이션)**: 특정 물리 레인에 영구 단선이나 결함 발생 시, 전체 링크를 차단하지 않고 가용 레인 수(예: 64레인 $\to$ 32레인)로 대역폭을 축소하여 작동을 지속하는 기능.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 파운드리(삼성/TSMC) 간 칩렛 신호 전압 레벨 차이로 통신이 엇갈려 고속도로(주대역) 칩 기동이 실패하는 참사 발생 | 샛길(**측대역**) 상태 채널로 눈치를 보며 실시간 모니터링 후, 자동 레인 데그라데이션(Degradation)으로 통신 속도 억지 강등 조치 | 칩이 쇼트나서 뻗는 것을 막고 굼벵이 속도라도 최소한의 핑퐁 기동 가용성을 확보하는 100% 방어망 구축 |
| 다이 대 다이 좁아터진 물리 채널의 미세 노이즈 간섭으로 인한 치명적인 **비트 에러율**(BER) 솟구침 떡상 현상 | 아날로그 물리 신호 파형의 **신호 눈 마진** 깐깐한 검증 및 어댑터 단의 하드웨어 좀비 무한 **재전송** 떡칠 루프 가동 | 칩 내부로 쓰레기 데이터 유입 완벽 차단 및 쓸데없는 재전송 핑퐁으로 인한 유효 대역폭 둔화 스로틀링 방어 |
| 개별 칩렛은 합격이나, 막상 인텔과 TSMC 칩을 기판에 붙여놓으면 **상호운용성** 불일치로 시스템 전체가 뻗어버리는 현상 | 비싼 테스트 장비로 하드코어 억지 **오류 주입** 및 이종 파운드리 칩 간 핑퐁 파이프라인 통합 교차 검증 강제 수행 | 삼성, 인텔, TSMC 칩을 내 맘대로 섞어 쓰는 멀티 벤더 칩렛 조립 가용성 확보 및 노예 생태계 탈출 해방 보장 |

#### 한줄 요약

- **Sideband 모니터링 & Lane Degradation·Signal Eye 검증·하드웨어 오류 주입 테스트**

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **UCIe 3D 확장**: 차세대 UCIe 규격은 2.5D 인터포저를 넘어 3D TSV 직접 적층(Direct Bonding)까지 지원하여 테라바이트급 3D 적층 칩렛 구현.

</details>

- 반도체 파운드리 생태계에서 **UCIe 1.1/2.0 기반 이종 칩렛 통합 및 2.5D/3D 고급 패키징 표준 채택**

#### 한줄 요약

- **칩렛 재사용성(Multi-Vendor)과 온패키지 초저지연 전력 효율**을 만족하는 UCIe 표준화
