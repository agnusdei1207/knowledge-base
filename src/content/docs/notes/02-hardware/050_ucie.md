## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **범용 칩렛 상호연결 익스프레스(Universal Chiplet Interconnect Express, UCIe)**: 서로 다른 칩렛을 물리•어댑터•프로토콜 계층에서 연결하는 표준 D2D 인터페이스이다.
- **다이 간 연결(Die-to-Die, D2D)**: 하나의 패키지 안에서 서로 다른 다이를 직접 연결하는 인터페이스이다.
- **공급자 종속(Vendor Lock-in)**: 특정 공급자의 칩렛과 연결 기술에 의존하여 다른 공급자의 부품으로 교체하기 어려운 상태이다.

</details>

- 정의/개념: 패키지 내부 칩렛 연결의 PHY·D2D 어댑터와 상위 프로토콜 수용 방식을 규정하는 **UCIe**이다.
- 배경/필요성: 공급자별 독자 D2D는 칩렛 조합마다 인터페이스를 다시 설계·검증해야 해 통합 비용이 늘고 **공급자 종속**이 커진다.

#### 한줄 요약

- UCIe는 공통 PHY·어댑터·프로토콜 경계를 제공해 멀티벤더 칩렛의 재사용과 조합별 통합 비용 절감을 목표로 한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **계층 분리(Layer Separation)**: 상위 프로토콜과 링크 관리 및 전기 신호 기능을 독립된 계층으로 나누는 설계 원칙이다.
- **플릿(Flit)**: D2D 어댑터가 링크를 통해 전송하는 고정 형식의 흐름 제어 단위이다.
- **순환 중복 검사(Cyclic Redundancy Check, CRC)**: 송수신 플릿의 검사값을 비교하여 전송 비트 오류를 검출하는 기법이다.
- **재전송(Retransmission)**: CRC나 순서 오류가 검출된 플릿만 다시 보내 데이터 무결성을 회복하는 절차이다.
- **적합성(Conformance)**: 구현이 UCIe 규격의 필수 동작과 전기 조건을 따르는지 확인한 상태이다.
- **상호운용성(Interoperability)**: 서로 다른 공급자의 칩렛이 실제 조합에서 올바르게 통신하는 성질이다.
- **피시아이 익스프레스(Peripheral Component Interconnect Express, PCIe)•컴퓨트 익스프레스 링크(Compute Express Link, CXL)**: UCIe가 수용할 수 있는 범용 입출력 및 일관성 프로토콜이다.

</details>

- PCIe•CXL•스트리밍 상위 프로토콜을 수용하는 **계층 분리**가 핵심이다.
- 링크 오류의 데이터 손상을 막는 **플릿 CRC·재전송**이 핵심이다.
- 멀티벤더 결합을 검증하는 **적합성·상호운용성** 시험이 핵심이다.

#### 한줄 요약

- 계층 분리는 상위 프로토콜과 전기 연결을 독립적으로 구성하게 하고, CRC·재시도와 조합 시험은 링크 무결성과 상호운용성을 검증한다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **프로토콜 계층(Protocol Layer)**: 읽기와 쓰기 같은 상위 트랜잭션의 의미와 형식을 제공하는 계층이다.
- **다이 간 연결 어댑터(Die-to-Die Adapter, D2D 어댑터)**: 트랜잭션을 플릿으로 바꾸고 순환 중복 검사(Cyclic Redundancy Check, CRC)와 재시도 및 링크 상태를 관리하는 계층이다.
- **물리 계층(Physical Layer, PHY)**: 패키지 배선으로 전기 신호를 송수신하고 링크의 레인과 타이밍을 맞추는 계층이다.
- **패키지 채널(Package Channel)**: 두 다이의 PHY 사이에서 고속 전기 신호가 이동하는 패키지 내부 배선 경로이다.

</details>

```text
UCIe 계층 경계
└─ [프로토콜 계층]
   └─ [D2D 어댑터]
      └─ [물리 계층]
         └─ [패키지 채널]
```

선의 의미: UCIe 경계 안에서 프로토콜•어댑터•물리 계층이 상하 인터페이스를 이루고 물리 계층이 패키지 채널에 접하는 정적 계층 관계다.

| 구성요소 | 책임 |
|:---|:---|
| 프로토콜 계층 | 상위 트랜잭션 제공 |
| D2D 어댑터 | 플릿화•CRC•재전송 |
| 물리 계층 | 주대역•측대역 신호 송수신 |
| 패키지 채널 | 다이 간 전기 경로 제공 |

#### 한줄 요약

- 프로토콜 요청을 어댑터 플릿과 PHY 신호로 바꿔 패키지 채널에 전달한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **주대역(Mainband)**: 실제 트랜잭션 데이터 플릿을 고속으로 전달하는 기본 데이터 경로이다.
- **측대역(Sideband)**: 링크 초기화와 상태 및 관리 신호를 주대역과 별도로 전달하는 경로이다.
- **레인(Lane)**: 한 방향의 고속 직렬 데이터를 전달하는 차동 신호 경로이다.
- **순환 중복 검사(Cyclic Redundancy Check, CRC)•다이 간 연결(Die-to-Die, D2D)**: 플릿 오류 검출 기법과 어댑터 사이의 패키지 연결 방식이다.
- **물리 계층(Physical Layer, PHY)•범용 칩렛 상호연결 익스프레스(Universal Chiplet Interconnect Express, UCIe)**: 전기 신호 송수신 계층과 칩렛 연결 표준이다.
- **플릿·CRC 부호화**: 상위 요청을 플릿으로 만들고 CRC 검사값을 붙이는 단계이다.
- **주대역 PHY 전송**: 플릿을 레인 신호로 바꿔 패키지 채널로 보내는 단계이다.
- **신호·플릿·순서 검증**: 레인 정렬과 CRC 및 플릿 순서를 확인하는 단계이다.
- **오류 플릿 재전송**: 오류가 난 플릿을 다시 요청해 보내는 단계이다.
- **상위 요청 복원·응답**: 검증된 플릿을 원래 프로토콜 요청으로 되돌려 처리하고 응답하는 단계이다.

</details>

```text
                    [상위 프로토콜 요청]
                              |
                    1. 플릿•CRC 부호화
                              |
                2. 주대역 직렬화•PHY 전송
                              |
                3. 신호 정렬•플릿•순서 검증
                       /             \
                    [성공]           [오류]
                      |                |
               5. 상위 요청 복원  4. 재전송 요청
                      |                |
               [응답 플릿 반환]   [오류 플릿 재전송]
                                      |
                                [1~3단계 재수행]
```

### 동작 원리

1. **플릿·CRC 부호화**: PCIe·CXL·스트리밍 요청을 D2D 어댑터의 전송 플릿으로 만들고 오류 검출값을 추가한다.
2. **주대역 PHY 전송**: **측대역**으로 링크 상태를 관리하면서 플릿을 레인 신호로 변환해 패키지 채널의 상대 PHY로 전달한다.
3. **신호·플릿·순서 검증**: 수신 PHY와 어댑터가 레인 정렬, CRC와 플릿 순서를 확인해 무결성을 판정한다.
4. **오류 플릿 재전송**: CRC·순서 오류가 있으면 해당 플릿의 재전송을 요청하고 1~3단계를 반복한다.
5. **상위 요청 복원·응답**: 검증된 플릿을 원래 프로토콜 요청으로 복원해 대상에서 처리하고 응답 플릿을 반환한다.

#### 한줄 요약

- UCIe는 상위 요청을 CRC 플릿과 PHY 신호로 변환해 전달하고, 오류 플릿은 재전송한 뒤 검증된 요청만 상위 프로토콜에 넘긴다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **독자 D2D 링크(Proprietary D2D Link)**: 특정 공급자가 제품에 맞춰 물리•어댑터•프로토콜 계층을 자체 정의한 연결이다.
- **칩렛 재사용(Chiplet Reuse)**: 검증된 칩렛을 여러 제품과 패키지 조합에서 반복 활용하는 방식이다.
- **전용 최적화(Dedicated Optimization)**: 단일 제품의 성능과 전력 목표에 맞춰 인터페이스를 제한 없이 조정하는 설계이다.

</details>

| D2D 인터페이스 | UCIe | 독자 D2D 링크 |
|:---|:---|:---|
| 적용 기준 | 생태계•칩렛 재사용 우선 | 단일 제품의 전용 성능 우선 |
| 핵심 특징 | **UCIe** 표준 계층 | **독자 D2D 링크**의 전용 계층 |
| 한계 | 조합별 **상호운용성**•신호 품질 검증 | **공급자 종속**•재개발 비용 |

> 요약: **칩렛 재사용**은 **UCIe**, **전용 최적화**는 **독자 D2D 링크**를 선택한다.

#### 한줄 요약

- 멀티벤더 칩렛 재사용과 표준 생태계가 중요하면 UCIe를, 단일 제품의 지연·전력·대역폭만 극대화하면 독자 D2D를 선택한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **비트 오류율(Bit Error Rate, BER)**: 전체 전송 비트 가운데 오류가 발생한 비트의 비율이다.
- **신호 눈 마진(Eye Margin)**: 수신 파형의 판정 시점과 전압이 오류 한계까지 가지는 여유를 나타내는 지표이다.
- **오류 주입(Error Injection)**: 의도적으로 링크 오류를 발생시켜 검출과 재시도 및 복구 동작을 확인하는 시험이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 레인·속도 협상에 실패해 주대역 링크 미기동 | **측대역** 상태 로그를 분석하고 지원 범위 안에서 레인 수·속도 하향 | 공통 동작점 재협상으로 링크 기동 복구 |
| 높은 **비트 오류율**로 재전송이 늘어 유효 대역폭 저하 | 온도별 **BER·신호 눈 마진**과 재전송률 감시 | 물리 채널 열화를 조기에 찾아 신호 품질 개선 |
| 규격 적합 판정을 받은 칩렛끼리도 **상호운용성** 문제로 실제 조합 실패 | 공급사 조합별 **오류 주입**과 프로토콜·전기 시험 | 복구 경로와 경계 조건을 포함한 조합 검증 |
| 패키지의 열·전압 변화로 PHY 타이밍 마진 축소 | 열·전력 무결성 해석과 실사용 부하 링크 시험 | 최악 조건에서도 신호 타이밍 마진 유지 |

> 요약: 실제 칩렛 조합의 **BER**과 재전송률을 측정해 **상호운용성**을 검증한다.

#### 한줄 요약

- 규격 적합 칩렛도 실제 조합에서 BER•재시도율•대역폭•지연을 검증해야 한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **멀티벤더(Multi-vendor)**: 서로 다른 공급자가 만든 칩렛과 도구를 하나의 시스템에서 함께 사용하는 구성이다.
- **생태계(Ecosystem)**: 표준을 중심으로 칩렛•패키지•검증 도구와 공급사가 상호 협력하는 산업 환경이다.
- **전용 성능(Dedicated Performance)**: 특정 제품만을 위해 조정한 인터페이스에서 얻는 지연과 대역폭 및 전력상의 이점이다.
- **D2D 인터페이스 선택 기준**: 멀티벤더·생태계 이득과 전용 성능을 비교해 UCIe와 독자 D2D 링크를 고르는 기준이다.

</details>

- **D2D 인터페이스 선택 기준**에 따라 **멀티벤더·생태계**와 **칩렛 재사용**이 우선이면 **UCIe**, **전용 성능**이 우선이면 **독자 D2D 링크**를 선택한다.

#### 한줄 요약

- 여러 공급자의 칩렛을 재사용하려면 UCIe를, 단일 제품에 한정해 링크 성능을 극대화하려면 독자 D2D를 선택한다.
