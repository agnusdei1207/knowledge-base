## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **UCIe(Universal Chiplet Interconnect Express)**: 패키지 내부의 서로 다른 칩렛 다이들을 표준화된 방식으로 연결하기 위한 개방형 Die-to-Die(D2D) 인터커넥트 표준 규격.
- **D2D(Die-to-Die)**: 동일 패키지 내부에서 서로 다른 실리콘 다이 간에 초고속·초저지연 신호를 주고받는 물리적/논리적 연결.
- **상호운용성(Interoperability)**: 서로 다른 파운드리와 벤더에서 제조된 칩렛들이 동일 표준 규격 위에서 오류 없이 상호 통신할 수 있는 특성.

</details>

- 정의/개념: 프로토콜 계층, D2D 어댑터, 물리(PHY) 계층으로 구성되어 이종 칩렛 간 **개방형 상호운용성** 보장하는 차세대 패키징 인터커넥트 표준
- 배경/필요성: 독자 D2D 규격 난립에 따른 개발 비용 증가 방지 및 멀티 벤더 칩렛 에코시스템 구축 필요

#### 한줄 요약
- 서로 다른 제조사의 칩렛들을 레고 블록처럼 패키지 안에서 자유롭게 결합할 수 있도록 정의한 D2D 표준 고속 인터커넥트다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **프로토콜 계층(Protocol Layer)**: PCIe, CXL 등 상위 트랜잭션 프로토콜 또는 사용자 정의 프로토콜을 처리하는 계층.
- **D2D 어댑터(D2D Adapter)**: 플릿(Flit) 패킷화, 링크 상태 관리, 흐름 제어 및 CRC 오류 검출을 전담하는 중간 계층.
- **물리 계층(Physical Layer, PHY)**: 아날로그 전기 신호 송수신, 클록 분배, 링크 훈련 및 패키지 배선 인터페이스를 담당하는 계층.

</details>

- **3계층 모듈형 아키텍처**(프로토콜·어댑터·PHY)로 표준 상위 프로토콜과 패키지 물리 구현의 독립적 발전 지원
- 표준 패키징(Standard 2D)과 첨단 패키징(Advanced 2.5D/3D)을 모두 지원하는 폭넓은 확장성
- Flit 기반의 엄격한 **CRC 및 재전송 메커니즘** 기반 무손실 고신뢰성 D2D 통신 보장

#### 한줄 요약
- 상위 프로토콜(PCIe/CXL)과 물리 패키징을 계층화하여 이종 파운드리 칩렛 간의 원활한 결합과 신뢰성 있는 통신을 보장한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **플릿(Flit, Flow Control Unit)**: D2D 어댑터와 상위 프로토콜 간 흐름 제어 및 오류 검출을 위해 정형화된 데이터 전송 기본 단위.
- **사이드밴드(Sideband)**: 링크 초기화, 전력 관리, 매개변수 협상 및 디버깅을 위해 메인 데이터 라인과 독립적으로 동작하는 보조 제어 채널.

</details>

```text
┌─────────────────────────────────────────────────────────────┐
│ UCIe 계층형 아키텍처 (Layered Architecture)                 │
│                                                             │
│  [ 프로토콜 계층 (Protocol Layer) ]                          │
│  ├─ PCIe 6.0 / CXL 3.0 / 스트리밍 프로토콜 (User-Defined)   │
│  └──────────────────────────┬────────────────────────────┘  │
│                             │ (FDI: Flit-aware Die-to-Die Interface)
│  [ D2D 어댑터 계층 (Die-to-Die Adapter Layer) ]              │
│  ├─ 플릿(Flit) 형성 / 패킷 무결성(CRC) / 흐름 제어 / 재전송  │
│  └──────────────────────────┬────────────────────────────┘  │
│                             │ (RDI: Raw Die-to-Die Interface)
│  [ 물리 계층 (Physical Layer, PHY) ]                         │
│  ├─ 메인밴드(Mainband) 고속 데이터 레인 (x16 ~ x64)         │
│  ├─ 사이드밴드(Sideband) 링크 훈련 및 파라미터 협상 채널     │
│  └──────────────────────────┬────────────────────────────┘  │
│                             │ (Bump Matrix: Standard / Advanced)
│  [ 패키지 채널 (Package Channel) ]                           │
│  └─ 기판 배선 (Substrate) / 실리콘 인터포저 / RDL 브리지     │
└─────────────────────────────────────────────────────────────┘
```

선의 의미: 상위 프로토콜에서 FDI 인터페이스로 어댑터에 전달되고, RDI를 거쳐 PHY 및 물리 패키지 채널로 이어지는 데이터 흐름도

| 구성요소 | 책임 |
|:---|:---|
| 프로토콜 계층 | 메모리(CXL.mem), I/O(PCIe), 가속기 스트리밍 등 상위 트랜잭션 의미론 처리 |
| D2D 어댑터 | FDI-RDI 간 플릿 변환, 링크 상태 머신(LSM) 관리 및 CRC 기반 오류 복구 |
| 물리 계층 (PHY) | 전기 신호 레인 구동, 클록 포워딩, 레인 반전/보정 및 사이드밴드 통신 |
| 패키지 채널 | 마이크로 범프(Advanced) 또는 C4 범프(Standard)를 통한 칩렛 간 물리 배선 |
| FDI / RDI 인터페이스 | 프로토콜-어댑터(FDI) 및 어댑터-PHY(RDI) 간의 표준화된 내부 버스 규격 |

#### 한줄 요약
- 프로토콜 계층, D2D 어댑터, PHY 계층 및 물리 패키지 채널이 표준 인터페이스(FDI/RDI)로 결합된 구조다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **링크 훈련(Link Training)**: 전원 인가 후 사이드밴드를 통해 레인 스큐를 보정하고 최적 전송 주파수와 채널 파라미터를 협상하는 과정.

</details>

```text
전원 인가 및 리셋 해제
      │
      ▼
1. 사이드밴드 링크 초기화 및 기능 협상 (Capability Exchange)
      │
      ▼
2. 메인밴드 PHY 링크 훈련 (레인 스큐 보정 및 클록 동기화)
      │
      ▼
3. D2D 어댑터 상태 전이 (Link Active: 활성 통신 상태 진입)
      │
      ▼
4. Flit 데이터 송수신 및 CRC 오류 검출 (메인밴드 전이중 스트리밍)
      │
      ▼
5. 전송 오류 발생 시 Link-level Retransmit 또는 보고 후 복구
```

**동작 원리** 1. **사이드밴드 초기화**: 보조 채널을 통해 칩렛 간 프로토콜 지원 범위, 링크 폭, 전압 조건 교환
2. **PHY 링크 훈련**: 메인 데이터 레인의 전기적 신호 정렬 및 최적 전송 속도 보정
3. **어댑터 활성화**: 링크 상태 머신이 활성 상태로 진입하고 상위 프로토콜 트랜잭션 대기
4. **플릿 스트리밍**: 상위 패킷을 정형화된 Flit 단위로 나누어 CRC와 함께 초저지연 전송
5. **오류 복구**: Flit 손상 시 하드웨어 레벨 재전송을 가동하여 무손실 복구 수행

#### 한줄 요약
- 사이드밴드 협상 → PHY 링크 훈련 → 어댑터 활성화 → Flit 전송 및 CRC 검증 → 오류 복구 순으로 동작한다.

## Ⅴ. 종류 및 비교

| 패키징 유형 | UCIe Advanced (첨단 패키징) | UCIe Standard (표준 패키징) | 독자 D2D (Proprietary) |
|:---|:---|:---|:---|
| 적용 기준 | 초고밀도·초대역폭 AI/서버 프로세서 | 중저가·비용 최적화 임베디드/모바일 | 단일 제조사 내부 완제품 최적화 |
| 핵심 특징 | 실리콘 인터포저/RDL 기반 미세 범프 (25~55$\mu m$) | 일반 유기 기판 배선 (100~130$\mu m$ 범프) | 제조사 전용 맞춤형 PHY 및 프로토콜 |
| 대역폭 밀도 | 최대 1300+ GB/s/mm (초고밀도) | 약 200~300 GB/s/mm (표준 밀도) | 제조사 설계에 따라 가변적 |
| 한계 | 첨단 패키징 제조 비용 및 공정 난이도 | 상대적으로 낮은 배선 밀도 및 대역폭 | 타사 칩렛과의 상호운용 불가 (Lock-in) |

#### 한줄 요약
- 초고성능은 첨단 패키징 UCIe, 비용 최적화는 표준 패키징 UCIe, 단일 벤더 특화는 독자 D2D를 쓴다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **레인 리매핑(Lane Remapping)**: 결함이 발생한 특정 데이터 레인을 예비(Spare) 레인으로 대체하여 수율을 방어하는 하드웨어 기술.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 패키징 후 특정 데이터 레인의 물리적 단선 결함 | **레인 리매핑(Lane Remapping)** 및 예비 레인 스위칭 | 패키지 폐기 방지 및 조립 수율 보전 |
| 이종 파운드리 칩렛 간 전압 및 타이밍 미세 불일치 | **사이드밴드 자동 캘리브레이션** 및 적응형 등화기(EQ) 가동 | 신호 무결성 확보 및 비트 에러율(BER) 억제 |
| 프로토콜 간 대역폭 불균형으로 인한 버퍼 오버플로 | D2D 어댑터 계층의 **크레딧 기반 흐름 제어** 엄격 적용 | 패킷 드롭 방지 및 꼬리 지연시간 단축 |
| 전원 차단 상태에서 활성 상태 복귀 시 긴 지연 | 고속 저전력 상태(L1/L2) 진입 및 고속 웨이크업 설계 | 절전 효과 극대화 및 응답 지연 최소화 |

#### 한줄 요약
- 레인 리매핑으로 수율을 지키고, 사이드밴드 보정으로 신호를 맞추며, 크레딧 제어로 버퍼 넘침을 방지한다.

## Ⅶ. 결론

- 멀티 벤더 이종 칩렛 통합 및 개방형 에코시스템 구축을 위해 **UCIe 표준 인터커넥트** 도입 필수

#### 한줄 요약
- 계층화된 D2D 표준과 Flit 기반 무손실 전송을 통해 칩렛 기반 모듈형 반도체 설계를 가속화해야 한다.
