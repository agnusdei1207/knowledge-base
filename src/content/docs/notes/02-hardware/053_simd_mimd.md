## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **SIMD(Single Instruction, Multiple Data)**: 하나의 명령어로 여러 개의 데이터 요소에 동일한 연산을 동시에 수행하는 데이터 병렬 처리 모델.
- **MIMD(Multiple Instruction, Multiple Data)**: 여러 개의 독립적인 프로세서나 코어가 각자의 명령어 흐름에 따라 서로 다른 데이터를 비동기 실행하는 모델.

</details>

- 정의/개념: 단일 명령어로 다중 데이터를 처리하는 **SIMD** 및 독립 코어가 분산 실행하는 **MIMD** 병렬 프로세서 구조
- 배경/필요성: 단일 코어 클록 주파수 증대 한계로 **정형 데이터 및 독립 태스크 병렬 가속 불가**

#### 한줄 요약
- 데이터 병렬성을 위한 SIMD와 태스크 병렬성을 위한 MIMD는 상호 보완적인 병렬 처리 아키텍처다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **벡터 레인(Vector Lane)**: SIMD 연산기 내부에서 하나의 데이터 요소를 독립적으로 계산하는 하드웨어 데이터 경로.
- **스레드 수준 병렬성(TLP)**: MIMD 환경에서 독립된 프로그램 스레드들을 다중 코어에 분산해 처리하는 병렬성.

</details>

- SIMD는 제어 회로를 **벡터 레인** 전체가 공유해 명령어 해독 비용 절감
- MIMD는 코어마다 독립 제어 흐름을 두어 **스레드 수준 병렬성** 및 복잡한 분기 수용
- 현대 프로세서는 멀티코어 내부에 벡터 확장 유닛을 집적하여 계층적 하이브리드 병렬성 구현

#### 한줄 요약
- SIMD는 제어 회로 공유로 연산 밀도를 높이고, MIMD는 독립 코어 복제로 실행 유연성을 확보한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **인터커넥트망(Interconnect Network)**: MIMD 다중 코어 간에 캐시 일관성 메시지와 공유 메모리 접근을 중계하는 온칩 패브릭.

</details>

```text
[SIMD 구조]
|-- 단일 제어부 (명령어 인출·해독 후 브로드캐스트)
`-- 벡터 연산 레인 × N (동일 연산·다중 데이터 병렬 실행)

[MIMD 구조]
|-- 독립 코어 × N (자체 제어부·PC·ALU)
|-- 온칩 인터커넥트망 (캐시 일관성·동기화 메시지 중계)
`-- 공유 LLC 및 시스템 메모리
```

선의 의미: 계층 및 제어 구조

| 구성요소 | 책임 |
|:---|:---|
| SIMD 제어부 | 단일 명령어를 인출·해독하여 모든 벡터 레인에 동기 제어 신호 배포 |
| 벡터 레인 | 동일한 제어 신호에 맞춰 개별 데이터 요소 연산 병렬 수행 |
| MIMD 독립 코어 | 자체 프로그램 카운터(PC)를 통해 독립적인 명령어 스트림 실행 |
| **인터커넥트망** | 코어 간 캐시 일관성 유지, 동기화 및 데이터 교환 중계 |
| 공유 메모리 시스템 | 다중 코어 및 벡터 유닛에 고대역폭 데이터 스트림 공급 |

#### 한줄 요약
- SIMD는 단일 제어부 아래 다중 레인을 두고, MIMD는 독립 코어들을 인터커넥트망으로 결합한 구조다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **자동 벡터화(Auto-Vectorization)**: 컴파일러가 소스 코드의 순차 반복문을 분석하여 자동으로 SIMD 벡터 명령어로 변환하는 최적화.

</details>

```text
병렬 소프트웨어 실행 시작
        │
   구간의 병렬성 성격은 무엇인가?
   ┌────┴─────────┐
독립 태스크        정형 반복문
   │                 │
MIMD 스레드로       컴파일러가 자동 벡터화 가능한가?
코어에 분산          ┌──┴───┐
   │              아니오     예
   │                │        │
   │           내장 함수로  SIMD 명령으로
   │           수동 벡터화   일괄 처리
   └────┬───────────┴────────┘
        │
   배리어·락으로 코어 간 상태 동기화
        │
   부분 결과 합산 후 저장
```

#### 한줄 요약
- 정형 루프는 컴파일러 자동 벡터화를 통해 SIMD로 가속하고, 독립 태스크는 MIMD 스레드로 분산하여 실행한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **SISD(Single Instruction, Single Data)**: 단일 프로세서가 순차적으로 단일 명령과 데이터를 처리하는 전통적 구조.
- **MISD(Multiple Instruction, Single Data)**: 동일 데이터 스트림에 여러 명령어를 중복 실행하는 특수 목적 구조.

</details>

| 병렬 프로세서 구조 | SIMD (벡터 유닛) | MIMD (멀티코어/클러스터) | SISD (단일 CPU) | MISD (특수 파이프라인) |
|:---|:---|:---|:---|:---|
| 적용 기준 | 딥러닝 텐서·영상 처리·그래픽스 | 범용 서버·OS 멀티태스킹·클라우드 | 단순 임베디드 마이크로컨트롤러 | 우주항공 비행 제어 다중 중복 검증 |
| 핵심 특징 | 단일 명령어로 대량 데이터 고효율 일괄 처리 | 독립 코어들의 비동기 스레드 분산 실행 | 단일 제어-단일 연산의 결정적 순차 실행 | 단일 데이터에 다수 알고리즘 중복 적용 |
| 한계 | 조건 분기(if-else) 시 연산 레인 유휴 | 스레드 동기화 락 경합 및 통신 오버헤드 | 처리량 확장 불가 및 전력 장벽 한계 | 상용 소프트웨어 부재 및 구현 비용 과다 |

#### 한줄 요약
- 대규모 동일 연산 가속에는 SIMD가 유리하고, 복합 비동기 워크로드 처리에는 MIMD가 필수적이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **마스킹(Masking)**: SIMD 연산 중 if-else 조건 불일치 레인의 결과를 무효화하여 분기 발산을 해결하는 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 조건 분기로 인한 비활성 벡터 레인 발생 | 분기 제거 알고리즘 작성 및 하드웨어 **마스킹** 적용 | 유효 레인 가동률 향상 및 분기 손실 제거 |
| 스레드 간 부하 불균형으로 배리어 대기 지연 | 작업 훔치기(Work-Stealing) 및 동적 스케줄링 적용 | 코어 유휴 시간 축소 및 전체 처리량 증대 |
| 비정렬 메모리 접근으로 인한 벡터 로드 실패 | 메모리 정렬 보장 및 구조체 배열(SoA) 변환 | 단일 트랜잭션 연속 벡터 로드 달성 |
| 코어 수 증가에 따른 캐시 일관성 트래픽 급증 | 디렉터리 기반 일관성 프로토콜 및 데이터 격리 | 스누핑 대역폭 포화 완화 및 확장성 보장 |

#### 한줄 요약
- SIMD는 마스킹과 데이터 정렬로 레인을 채우고, MIMD는 작업 훔치기와 일관성 최적화로 락 경합을 방지한다.

## Ⅶ. 결론

- 정형 행렬 연산은 **SIMD 벡터 레인**, 독립 제어 태스크는 **MIMD 멀티코어**에 매핑하여 계층적 하이브리드 병렬 시스템으로 최적화

#### 한줄 요약
- 현대 고성능 시스템 설계는 외부의 MIMD 스케일아웃과 내부의 SIMD 벡터 연산을 결합하여 처리량을 극대화한다.
