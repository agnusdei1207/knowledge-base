## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **SIMD(Single Instruction, Multiple Data)**: 하나의 디코딩 인스트럭션을 인가하여 여러 병렬 연산 레인의 데이터를 동시에 가속하는 처리 방식.
- **MIMD(Multiple Instruction, Multiple Data)**: 다수의 독립된 제어 유닛이 각자 독자적인 명령어를 디코딩하여 서로 다른 데이터를 비동기 실행하는 구조.
- **병렬 아키텍처(Parallel Architecture)**: 데이터 병렬성(Data Level Parallelism) 및 작업 병렬성(Task Level Parallelism)을 조합 수용하는 프로세서 설계 체계.

</details>

- 정의/개념: 멀티 코어 간 MIMD 작업 병렬성과 코어 내부 SIMD 벡터 레인의 데이터 병렬성을 복합 결합하는 **SIMD·MIMD 병렬 아키텍처**
- 배경/필요성: 단일 SIMD의 분기 제어 약점 및 단일 MIMD의 대규모 동질 데이터 제어 디코딩 오버헤드를 상호 보완할 필요성

#### 한줄 요약

- 현대 프로세서는 코어 간 MIMD 작업 병렬성과 코어 내부 SIMD 데이터 병렬성을 계층적으로 결합한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **공통 명령(Common Instruction)**: 단일 제어 장치가 브로드캐스팅하여 복수의 데이터 레인에 일괄 인가하는 인스트럭션.
- **독립 명령 흐름(Independent Instruction Flow)**: 코어별로 제어 유닛, PC(Program Counter)를 분리 보유하여 독립 구동하는 실행 파이프라인.
- **계층형 병렬성(Hierarchical Parallelism)**: 상위 계층의 MIMD 멀티스레딩과 하위 계층의 SIMD/SIMT 벡터 연산을 결합하는 구조.

</details>

- 명령 디코드 오버헤드를 줄이는 **공통 명령** 기반 벡터 연산
- 독립 프로그램 파이프라인 수용을 위한 코어별 **독립 명령 흐름** 보유
- 코어 간 MIMD 및 코어 내 SIMD를 일체화한 **계층형 병렬성** 하이브리드 아키텍처

#### 한줄 요약

- 각 코어는 독립 명령 흐름을 실행하고, 규칙적인 반복 구간에서는 하나의 벡터 명령을 여러 연산 레인에 적용한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **작업 큐(Work Queue)**: MIMD 스케줄러가 코어들에 비동기 할당하기 위해 독립 작업 패킷을 대기시키는 큐.
- **MIMD 스케줄러(MIMD Scheduler)**: 작업 큐의 업무를 유휴 코어로 비동기 배분하는 스케줄링 모듈.
- **연산 레인(Execution Lane)**: SIMD 벡터 명령어를 한 번에 병렬 연산 처리하는 ALU 하드웨어 단위.
- **배리어(Barrier)**: 비동기 MIMD 코어 간의 전역 연산 완료 시점을 수평 매칭하는 동기화 메커니즘.

</details>

```text
[작업 큐] -- [MIMD 스케줄러] -- [SIMD 지원 코어군]
                                            |
                               [공유 메모리•동기화기]
```

선의 의미: MIMD 스케줄러가 작업 큐의 독립 업무를 각 코어로 비동기 할당하고, 코어 내부 SIMD 레인을 거쳐 전역 동기화기로 연동되는 구조.

| 구성요소 | 책임 |
|:---|:---|
| 작업 큐 | 독립 Task/Thread 단위 작업 패킷 큐잉 및 대기 제어 |
| MIMD 스케줄러 | 유휴 코어 탐색 및 비동기 작업 디스패칭 수행 |
| SIMD 지원 코어군 | 코어 독립 실행 및 내부 벡터/ALU **연산 레인** 병렬 연산 |
| 공유 메모리•동기화기 | 코어 간 데이터 텐서 공유 및 **배리어** 동기화 래칭 |

#### 한줄 요약

- MIMD 코어가 서로 다른 작업을 맡고 각 코어의 규칙 구간은 SIMD 레인이 처리한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **작업 기술자(Work Descriptor)**: MIMD 스케줄러에 등록되는 함수 포인터, 입력 파라미터 및 범위 정보 객체.
- **벡터 연산(Vector Operation)**: SIMD 레인 상에서 배열 및 텐서 데이터를 일괄 처리하는 연산.
- **동기화 완료(Synchronization Completion)**: 배리어 동기화 지점에 도달하여 전역 텐서 출력을 확정한 상태.

</details>

```text
                       [독립 작업 큐]
                              |
                    1. 독립 작업 회수
                              |
                 2. MIMD 코어별 작업 배치
                              |
             +--------------------------------+
             | 병렬: 독립 코어의 규칙 구간   |
             | 3. SIMD 벡터 연산              |
             +--------------------------------+
                              |
                 4. 코어별 결과 공유 기록
                              |
                    5. 배리어•후속 해제
                              |
                         [작업 완료]
```

### 동작 원리

1. **독립 작업 회수**: **작업 큐**로부터 **작업 기술자** 인출 및 스케줄링 준비.
2. **MIMD 코어별 작업 배치**: **MIMD 스케줄러**가 독립 코어들로 각기 다른 작업 할당 및 비동기 커널 런칭.
3. **SIMD 벡터 연산**: 각 코어 내부에서 반복되는 동일 패턴 데이터에 대해 **SIMD 연산 레인** 기반 벡터 연산 수행.
4. **코어별 결과 공유 기록**: 연산 완결 텐서를 코어 간 공유 메모리에 이송 및 인덱싱.
5. **배리어·후속 해제**: 전역 **배리어** 동기화 확인 후 **동기화 완료** 래치 해제 및 후속 작업 연계.

#### 한줄 요약

- MIMD 코어는 서로 다른 작업을 실행하고 각 코어의 규칙 구간은 SIMD 레인으로 병렬 처리한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **조밀 텐서(Dense Tensor)**: 메모리 연속성이 높고 동일 연산 반복성이 강한 데이터 표현.
- **비정형 분기(Irregular Branch)**: 데이터 조건에 따라 제어 흐름이 불규칙하게 튀어 SIMD 효율을 떨어뜨리는 분기.
- **동기화 비용(Synchronization Cost)**: MIMD 프로세서 간 배리어/락 획득 시 유발되는 지연 오버헤드.

</details>

| 병렬 실행 구조 | SIMD (Vector Processor) | MIMD (Multi-core Processor) |
|:---|:---|:---|
| 적용 기준 | **조밀 텐서**, 행렬 연산 및 영상/음성 처리 시 | 독립 서비스, 비동기 쿼리 및 **비정형 분기** 처리 시 |
| 핵심 특징 | 단일 제어 인스트럭션 기반 데이터 레인 병렬화 | 독립 코어/스레드 기반 비동기 작업 병렬화 |
| 한계 | 분기 발산(Divergence) 시 성능 저하 | 잦은 코어 간 **동기화 비용** 및 스케줄링 오버헤드 |

#### 한줄 요약

- 같은 연산을 연속 데이터에 적용하면 SIMD가 유리하고, 각 작업의 명령·분기·작업량이 다르면 MIMD가 유리하다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **분기 발산(Branch Divergence)**: SIMD 레인 간 조건 분기가 갈라져 일부 레인이 마스킹(Inactivate)되는 병목 현상.
- **활성 마스크(Active Mask)**: 조건 분기 시 참/거짓 레인을 구분하여 실행을 통제하는 비트 마스크.
- **부하 불균형(Load Imbalance)**: MIMD 코어별 작업 완료 시점 차이로 유휴 코어가 발생하는 불균형.
- **동적 스케줄링(Dynamic Scheduling)**: 런타임 작업 완료 상태에 따라 코어 간 Work Stealing을 구동하는 동적 배분.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 조건문 증가에 따른 **분기 발산** 및 레인 유휴 | **활성 마스크** 기반 커널 분리 및 데이터 정렬 | SIMD 하드웨어 레인 활용률 향상 |
| 코어 간 연산량 차이로 인한 **부하 불균형** | Work Stealing 기반 **동적 스케줄링** 도입 | MIMD 전역 동기화 대기 시간 단축 |
| 메모리 불연속 접근으로 인한 SIMD 대역폭 저하 | Memory Coalescing 및 연속 데이터 레이아웃 재배치 | 메모리 버스 트랜잭션 수 감소 |

> 사례: 멀티코어 CPU 상에서 OpenMP(MIMD)와 AVX-512(SIMD)를 결합한 하이브리드 가속

#### 한줄 요약

- 영상 타일은 MIMD 코어에 나누고 각 타일의 연속 픽셀은 SIMD 레인으로 처리한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **병렬 실행 구조 선택 기준(Parallel Architecture Selection Criteria)**: 연산 알고리즘의 데이터 동질성, 제어 흐름 분기율 및 시스템 스케일링에 근거한 결정 기준.

</details>

- 동질 반복은 **SIMD**, 비정형 독립 작업은 **MIMD**, 혼합 부하는 계층 결합

#### 한줄 요약

- 동질 반복은 SIMD, 독립 분기는 MIMD, 혼합 부하는 계층 결합을 선택한다.
