## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **단일 명령 다중 데이터(Single Instruction Multiple Data, SIMD)**: 하나의 명령을 여러 데이터 원소에 동시에 적용하는 병렬 처리 방식이다.
- **다중 명령 다중 데이터(Multiple Instruction Multiple Data, MIMD)**: 여러 독립 명령 흐름이 서로 다른 데이터를 동시에 처리하는 병렬 구조이다.
- **병렬 구조(Parallel Architecture)**: 여러 연산 자원이 명령과 데이터를 나누어 동시에 처리하도록 구성한 하드웨어 구조이다.

</details>

- 정의/개념: 코어 사이에는 독립 명령을, 코어 내부 레인에는 공통 명령을 발행하는 **SIMD·MIMD 병렬 구조**이다.
- 배경/필요성: 단일 SIMD 방식은 복잡한 분기 제어에 취약하고, 순수 MIMD 방식은 대규모 동차 데이터 연산 시 제어 오버헤드가 커진다.

#### 한줄 요약

- 현대 프로세서는 코어 간 MIMD 작업 병렬성과 코어 내부 SIMD 데이터 병렬성을 계층적으로 결합한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **공통 명령(Common Instruction)**: 하나의 제어 장치가 여러 연산 레인에 동시에 발행하는 동일한 연산 지시이다.
- **독립 명령 흐름(Independent Instruction Flow)**: 각 코어가 다른 작업 순서와 분기를 별도로 실행하는 제어 흐름이다.
- **계층형 병렬성(Hierarchical Parallelism)**: 코어 사이의 작업 병렬성과 코어 내부의 데이터 병렬성을 함께 사용하는 구조이다.

</details>

- SIMD의 **공통 명령**으로 여러 데이터 레인의 제어·해석 비용을 줄인다.
- MIMD의 **독립 명령 흐름**으로 서로 다른 작업과 분기를 코어별로 동시에 실행한다.
- **계층형 병렬성**으로 코어 간 작업 병렬성과 코어 내부 데이터 병렬성을 결합한다.

#### 한줄 요약

- 각 코어는 독립 명령 흐름을 실행하고, 규칙적인 반복 구간에서는 하나의 벡터 명령을 여러 연산 레인에 적용한다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **작업 큐(Work Queue)**: 독립적으로 실행할 작업과 입력 범위를 대기 순서대로 보관하여 여러 코어에 배분하는 자료구조이다.
- **MIMD 스케줄러(MIMD Scheduler)**: 독립 작업을 실행 가능한 코어에 할당하는 구성요소이다.
- **연산 레인(Execution Lane)**: SIMD 명령이 담당하는 데이터 원소를 처리하는 연산 통로이다.
- **배리어(Barrier)**: 참여한 모든 작업이 특정 지점에 도달할 때까지 후속 실행을 막는 동기화 기법이다.

</details>

```text
[작업 큐] -- [MIMD 스케줄러] -- [SIMD 지원 코어군]
                                            |
                              [공유 메모리•동기화기]
```

선의 의미: 스케줄러가 작업 큐와 SIMD 지원 코어군을 연결하고 코어군이 공용 데이터•배리어 자원에 접하는 정적 계층형 병렬 구조다.

| 구성요소 | 책임 |
|:---|:---|
| 작업 큐 | 독립 작업•입력 범위 대기 보관 |
| MIMD 스케줄러 | 작업을 코어별로 독립 배치 |
| SIMD 지원 코어군 | 공통 명령의 **연산 레인** 처리 |
| 공유 메모리•동기화기 | 코어 간 데이터 교환•배리어 판정 |

#### 한줄 요약

- MIMD 코어가 서로 다른 작업을 맡고 각 코어의 규칙 구간은 SIMD 레인이 처리한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **작업 기술자(Work Descriptor)**: 실행할 함수와 데이터 범위 및 의존성을 기록하여 코어에 전달하는 정보이다.
- **벡터 연산(Vector Operation)**: 하나의 명령으로 여러 데이터 원소에 같은 계산을 수행하는 연산이다.
- **동기화 완료(Synchronization Completion)**: 모든 참여 코어가 필요한 결과를 기록하고 대기 조건을 충족한 상태이다.
- **계층형 실행(Hierarchical Execution)**: MIMD 작업 안에서 SIMD 벡터 연산을 수행하는 방식이다.
- **독립 작업 회수**: 작업 큐에서 실행할 작업 기술자를 선택하는 단계이다.
- **MIMD 코어 배치**: 독립 작업을 사용 가능한 코어에 할당하는 단계이다.
- **SIMD 벡터 연산**: 각 코어의 규칙 구간에서 한 명령을 여러 데이터 레인에 적용하는 단계이다.
- **코어별 결과 기록**: 각 작업의 결과를 공유 메모리나 후속 입력 버퍼에 반영하는 단계이다.
- **의존성·배리어 해제**: 필요한 결과가 모두 기록되면 대기 조건을 풀고 후속 작업을 허용하는 단계이다.

</details>

```text
                       [독립 작업 큐]
                              |
                    1. 독립 작업 회수
                              |
                 2. MIMD 코어별 작업 배치
                              |
             +--------------------------------+
             | 병렬: 독립 코어의 규칙 구간   |
             | 3. SIMD 벡터 연산              |
             +--------------------------------+
                              |
                 4. 코어별 결과 공유 기록
                              |
                    5. 배리어•후속 해제
                              |
                         [작업 완료]
```

### 동작 원리

1. **독립 작업 회수**: 작업 큐에서 함수·입력 범위·의존성이 다른 작업 기술자를 선택한다.
2. **MIMD 코어 배치**: 독립 작업을 사용 가능한 코어에 할당해 서로 다른 명령 흐름을 실행한다.
3. **SIMD 벡터 연산**: **계층형 실행**에서 각 코어의 규칙적인 구간에 공통 명령을 여러 데이터 레인으로 적용한다.
4. **코어별 결과 기록**: 작업 결과를 공유 메모리나 후속 작업의 입력 버퍼에 반영한다.
5. **의존성·배리어 해제**: 필요한 참여 코어가 결과 기록을 마쳐 **동기화 완료** 상태가 되면 후속 작업을 허용한다.

#### 한줄 요약

- MIMD 코어는 서로 다른 작업을 실행하고 각 코어의 규칙 구간은 SIMD 레인으로 병렬 처리한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **조밀 벡터•행렬(Dense Vector•Matrix)**: 대부분의 원소가 유효하여 같은 연산을 연속 원소에 반복하기 쉬운 데이터이다.
- **비정형 분기(Irregular Branch)**: 입력마다 실행 경로와 작업량이 달라 공통 명령으로 묶기 어려운 제어 흐름이다.
- **동기화 비용(Synchronization Cost)**: 락과 배리어 및 메시지를 기다리느라 실제 연산을 수행하지 못하는 시간이다.

</details>

| 병렬 실행 구조 | SIMD | MIMD |
|:---|:---|:---|
| 적용 기준 | **조밀 벡터·행렬**•영상 | 서비스•그래프•**비정형 분기** |
| 핵심 특징 | 공통 명령의 다중 데이터 처리 | 독립 명령의 다중 작업 처리 |
| 한계 | 분기 발산•비연속 메모리 | **동기화 비용**•통신•부하 불균형 |

> 요약: 규칙 연산에는 **SIMD**, 독립 작업에는 **MIMD**를 선택한다.

#### 한줄 요약

- 같은 연산을 연속 데이터에 적용하면 SIMD가 유리하고, 각 작업의 명령·분기·작업량이 다르면 MIMD가 유리하다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **분기 발산(Branch Divergence)**: 같은 SIMD 묶음이 다른 경로를 선택해 일부 레인이 비활성화되는 현상이다.
- **활성 마스크(Active Mask)**: SIMD 레인 가운데 현재 명령을 실제로 실행할 레인만 표시하는 비트 집합이다.
- **부하 불균형(Load Imbalance)**: 코어별 작업량이 달라 일부 코어가 작업을 끝낸 뒤 다른 코어를 기다리는 상태이다.
- **동적 스케줄링(Dynamic Scheduling)**: 실행 중의 완료와 부하 상태를 보고 남은 작업을 유휴 코어에 다시 배치하는 방식이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| SIMD 묶음의 **분기 발산**으로 비활성 레인 증가 | 같은 경로의 데이터를 묶고 **활성 마스크** 효율 측정 | 유효 연산 레인을 늘려 SIMD 활용률 향상 |
| 벡터 레인이 떨어진 주소를 요청해 메모리 트랜잭션 증가 | 자료 배치와 루프 순서를 연속 주소 접근에 맞게 변경 | 병합·벡터 전송을 늘려 메모리 대역폭 효율 향상 |
| MIMD의 **부하 불균형**으로 동기화 지점에서 유휴 코어 대기 | 작업을 더 작게 나누고 **동적 스케줄링**으로 유휴 코어에 재분배 | 작업 종료 시점을 맞춰 코어 대기 시간 감소 |
| SIMD·MIMD 경계마다 형식을 바꾸거나 복사해 혼합 실행 비용 증가 | SIMD 규칙 구간을 넓히고 경계 데이터 형식·배치 통일 | 변환·복사 횟수를 줄여 경계 오버헤드 완화 |

> 요약: 영상 타일은 **MIMD**, 연속 픽셀은 **SIMD** 병렬을 처리한다.

#### 한줄 요약

- 영상 타일은 MIMD 코어에 나누고 각 타일의 연속 픽셀은 SIMD 레인으로 처리한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **동일 연산(Uniform Operation)**: 여러 데이터 원소에 같은 계산 순서와 제어 흐름을 반복 적용하는 작업이다.
- **독립 제어(Independent Control)**: 각 코어나 작업이 다른 명령 순서와 분기를 별도로 결정하는 실행 방식이다.
- **혼합 실행(Hybrid Execution)**: 비정형 작업은 MIMD, 규칙 구간은 SIMD로 처리하는 방식이다.
- **병렬 실행 구조 선택 기준**: 동일 연산과 독립 제어의 비중으로 SIMD와 MIMD 또는 혼합 실행을 고르는 기준이다.

</details>

- **병렬 실행 구조 선택 기준**에 따라 **동일 연산**에는 **SIMD**, **독립 제어**에는 **MIMD**, 두 특성이 계층적으로 공존하면 **혼합 실행**을 선택한다.

#### 한줄 요약

- 동일 연산은 SIMD, 독립 제어는 MIMD를 적용한다.
