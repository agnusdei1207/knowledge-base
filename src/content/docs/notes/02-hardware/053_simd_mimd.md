## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **SIMD(Single Instruction, Multiple Data)**: 하나의 명령어로 여러 개의 독립된 데이터 요소(벡터 레지스터)에 동일한 산술 논리 연산을 동시에 수행하는 데이터 병렬 처리 모델.
- **MIMD(Multiple Instruction, Multiple Data)**: 다수의 독립된 프로세서 또는 CPU 코어가 각자의 프로그램 카운터(PC)와 명령어 스트림에 따라 서로 다른 데이터를 비동기 실행하는 태스크 병렬 처리 모델.

</details>

- 정의/개념: 단일 명령어로 대량 데이터 벡터를 동시 연산하는 **SIMD**와 독립 코어들이 상이한 태스크를 분산 실행하는 **MIMD 프로세서** 아키텍처
- 배경/필요성: 클록으로 성능을 사는 길이 전력 장벽(Power Wall)에서 막혀 **클록 주파수 확장 한계**에 부딪히자 병렬화가 유일한 확장 축으로 남았으므로, 같은 연산을 대량 데이터에 적용하는 SIMD와 서로 다른 태스크를 독립 실행하는 MIMD로 병렬성의 종류를 나눠 확보

#### 한줄 요약
- SIMD는 동일 연산을 데이터 배열에 대량 적용하는 데이터 병렬 모델이고, MIMD는 독립 코어들이 서로 다른 작업을 비동기 실행하는 태스크 병렬 모델이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **벡터 레인(Vector Lane)**: SIMD 연산기 내부에서 1개의 데이터 요소(32비트/64비트)를 독립적으로 연산하는 하드웨어 산술 논리 경로.
- **스레드 수준 병렬성(Thread-Level Parallelism, TLP)**: MIMD 환경에서 독립된 실행 문맥을 가진 여러 소프트웨어 스레드를 다중 코어에 분산하여 동시 실행하는 병렬성.

</details>

- 제어 회로 효율성 (SIMD): 단일 제어 장치를 다수의 **벡터 레인**이 공유하여 디코딩 오버헤드를 줄이고 연산기 집적도 극대화
- 제어 유연성 및 복잡성 (MIMD): 독립 제어부와 PC를 통해 **스레드 수준 병렬성(TLP)**을 완벽히 수용하나 캐시 일관성 오버헤드 수반
- 계층적 하이브리드 결합: 현대 프로세서는 **MIMD 멀티코어 내부에 SIMD 벡터 유닛**을 집적하여 두 병렬성을 통합 제공

#### 한줄 요약
- SIMD는 제어 공유로 연산 밀도를 높이고, MIMD는 독립 코어로 유연성을 확보하며, 현대 CPU는 둘을 계층적으로 결합한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **온칩 인터커넥트 패브릭(On-Chip Interconnect Fabric)**: MIMD 다중 코어 간에 L3 캐시 공유, 캐시 일관성(MESI) 메시지 및 메모리 트랜잭션을 고속 중계하는 온칩 상호 연결망.

</details>

```text
[SIMD·MIMD 프로세서 구조]
 ├── [SIMD 제어 장치]
 ├── [벡터 레인 어레이]
 ├── [MIMD 독립 코어]
 ├── [온칩 인터커넥트]
 └── [공유 LLC 및 IMC]
```

선의 의미: 가지(`├──`, `└──`)는 병렬 프로세서의 정적 구성 관계

| 구성요소 | 책임 |
|:---|:---|
| SIMD 제어 장치 | **1개 디코더**로 모든 벡터 레인 제어 |
| 벡터 레인 어레이 | 요소별 산술 논리를 다중 **ALU 레인**에서 실행 |
| MIMD 독립 코어 | 독립 PC 기반의 **실행 문맥** 처리 |
| 온칩 인터커넥트 | 코어 간 **캐시 일관성** 메시지 중계 |
| 공유 LLC 및 IMC | 다중 코어에 **DDR5/HBM** 대역폭 공급 |

#### 한줄 요약
- SIMD는 디코더 하나를 모든 레인이 공유해 제어 회로를 복제하지 않는 대신 레인마다 다른 일을 시킬 수 없고, MIMD는 코어마다 실행 문맥을 두는 대가로 코어 간 일관성 메시지를 중계할 온칩 인터커넥트와 공유 LLC 계층을 새로 떠안는다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **자동 벡터화(Auto-Vectorization)**: C/C++ 컴파일러가 소스 코드의 순차 `for` 루프를 분석하여 데이터 의존성이 없을 때 자동으로 SIMD 벡터 명령어로 변환하는 최적화 기법.

</details>

```text
응용 소프트웨어 병렬 연산 요청
                      │
                      ▼
워크로드 병렬성 성격 판정
   ┌──────────────────┴──────────────────┐
[ 비동기 다중 태스크 / 독립 스레드 ]   [ 대규모 정형 데이터 배열 / 행렬 루프 ]
   │                                     │
   ▼                                     ▼
MIMD 스레드로 분할 (OpenMP, Pthreads)   컴파일러 자동 벡터화 가능 여부 판정
   │                                     ┌──────────┴──────────┐
   ▼                                   [ 수동 벡터화 필요 ]   [ 자동 벡터화 성공 ]
OS 스케줄러: 다중 코어 분산 매핑          │                     │
   │                                     ▼                     ▼
   ▼                                   내장 함수 수동 구현     SIMD 벡터 명령 일괄 생성
각 코어에서 독립 명령어 스트림 실행       │                     │
   │                                     └──────────┬──────────┘
   └──────────────────┬─────────────────────────────┘
                      │
                      ▼
          캐시 일관성 유지 및 결과 병합 완료
```

분기 결과: 독립 태스크는 **MIMD 스레드**로 분산 실행되며 정형 데이터 루프는 **SIMD 벡터화**로 가속됨

#### 한줄 요약
- 병렬성 판정 ➔ MIMD 스레드 분할 또는 SIMD 벡터화 ➔ 결과 병합

## Ⅴ. 종류 및 비교

| 비교 항목 | SIMD (벡터 프로세서 / GPU) | MIMD (멀티코어 CPU / 클러스터) |
|:---|:---|:---|
| 제어 장치 (CU) 구조 | 1개 CU를 **다수 연산 레인이 공유** | 코어마다 **독립 CU 및 PC** 내장 |
| 병렬성 추구 수준 | **데이터 수준 병렬성** (DLP) | **스레드 수준 병렬성** (TLP) |
| 하드웨어 집적 효율 | **연산기 집적** 극대화 | 제어 회로 및 캐시 면적 중복 |
| 조건 분기 처리 | 분기 발산 시 **레인 마스킹** 유휴 발생 | 각 코어가 **독립 분기 예측** 및 실행 |
| 통신 및 동기화 | 레지스터 셔플 및 로컬 브로드캐스트 | **온칩 인터커넥트** 캐시 일관성 및 락 동기화 |
| 주요 적용 분야 | **AI 행렬곱**, 영상/신호 처리 | **멀티태스킹 OS**, 가상화 서버, DBMS |

#### 한줄 요약
- 행렬 연산과 대량 데이터 처리에는 SIMD가 압도적이며, 복잡한 비즈니스 로직과 멀티태스킹에는 MIMD가 필수적이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **레인 마스킹(Lane Masking)**: SIMD 연산 시 `if-else` 조건에 부합하지 않는 특정 벡터 레인의 결과 쓰기를 하드웨어적으로 비활성화하는 기법.
- **작업 훔치기(Work-Stealing)**: MIMD 환경에서 유휴 상태가 된 코어가 부하가 많은 다른 코어의 작업 큐에서 태스크를 가져와 처리하는 부하 분산 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| SIMD 연산 중 조건 분기로 인한 벡터 레인 유휴 | **하드웨어 레인 마스킹** 및 분기 제거 적용 | 유효 레인 가동률 90% 이상 유지 |
| MIMD 스레드 간 부하 불균형으로 인한 배리어 대기 지연 | 동적 **작업 훔치기(Work-Stealing)** 스케줄러 적용 | 코어 유휴 시간 축소 및 처리량 대폭 향상 |
| 비정렬 메모리 접근에 따른 SIMD 성능 저하 | **메모리 정렬** 및 구조체 배열(SoA) 변환 | 1사이클 연속 벡터 로드/스토어 달성 |
| MIMD 코어 수 증가에 따른 캐시 일관성 트래픽 포화 | **디렉터리 기반 일관성** 및 스레드 로컬 격리 | 버스 대역폭 병목 해소 및 선형적 확장성 확보 |

#### 한줄 요약
- 실무에서는 레인 마스킹과 메모리 정렬로 SIMD를 극대화하고, 작업 훔치기와 일관성 최적화로 MIMD를 안정화한다.

## Ⅶ. 결론

- 정형 배열 연산은 **SIMD**, 독립 태스크·복잡한 분기는 **MIMD** 선택

#### 한줄 요약
- 현대 컴퓨터 구조는 MIMD의 유연한 제어와 SIMD의 막강한 연산 밀도를 결합하여 최고의 성능을 달성한다.
