## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **파이프라이닝(Pipelining)**: 명령어 처리 과정을 복수의 세부 단계로 분할하고 중첩 실행하여 처리량을 극대화하는 하드웨어 병렬 기법.
- **비파이프라인 구조(Non-Pipelined Architecture)**: 한 명령어의 모든 실행 단계가 완전히 끝날 때까지 다음 명령어 진입을 대기시키는 순차 구조.
- **클록당 명령어 수(Instructions Per Cycle, IPC)**: 프로세서가 단일 클록 주기에 완료하여 출력하는 평균 기계어 명령어 수.

</details>

- 정의/개념: 명령어 처리 과정을 인출(IF), 해독(ID), 실행(EX), 메모리접근(MEM), 결과기록(WB) 등 복수 단계로 분할하여 중첩 병렬 실행하는 CPU 하드웨어 기법
- 배경/필요성: 단일 사이클 비파이프라인 구조의 하드웨어 유휴를 제거하고 **클록당 처리 명령어 수(IPC) 및 프로세서 처리량 극대화**

#### 한줄 요약

- 명령어 처리 단계를 중첩 실행하여 **단위 시간당 명령어 처리량(Throughput)** 극대화

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **단계 중첩(Stage Overlapping)**: 동일 클록 주기에 서로 다른 명령어가 각 단계를 시분할로 점유하여 동시 실행되는 메커니즘.
- **최장 단계 지연(Longest Stage Delay)**: 5단계 중 논리 지연 시간이 가장 길어 전체 시스템 클록 주파수를 제한하는 임계 구간.

</details>

- **단계 중첩** 기법을 통한 정상 상태 진입 시 매 클록당 1개 명령어 완료
- 시스템 최소 클록 주기를 결정하는 **최장 단계 지연(Critical Path)**과 레지스터 오버헤드
- 개별 명령어 **지연시간(Latency)**의 미세 증가 대비 전체 **처리량(Throughput)**의 획기적 향상

#### 한줄 요약

- 개별 지연시간은 미세 증가하나 **단계 중첩을 통한 전체 처리량** 대폭 향상

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **파이프라인 5단계**: IF(Instruction Fetch), ID(Instruction Decode), EX(Execute), MEM(Memory Access), WB(Write Back).
- **파이프라인 레지스터(Pipeline Register)**: IF/ID, ID/EX, EX/MEM, MEM/WB 단계 사이에 위치하여 데이터와 제어 신호를 동기화 전달하는 저장소.

</details>

```text
[ 기본 RISC 파이프라인 5단계 ]
  +------+    +------+    +------+    +------+    +------+
  |  IF  |===>|  ID  |===>|  EX  |===>| MEM  |===>|  WB  |
  +------+    +------+    +------+    +------+    +------+
     ||          ||          ||          ||          ||
  [IF/ID]     [ID/EX]     [EX/MEM]    [MEM/WB] (파이프라인 레지스터)
```

선의 의미: IF, ID, EX, MEM, WB 5단계와 중간 파이프라인 레지스터의 동기화 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 명령어 인출 (IF) | 프로그램 카운터 기반 기계어 인출 및 주소 갱신 |
| 명령어 해독 (ID) | 명령어 해독과 피연산자 및 제어 신호 생성 |
| 실행 (EX) | 산술 논리 연산 수행 및 분기 주소 계산 |
| 메모리 접근 (MEM) | 로드 및 스토어 명령어의 데이터 캐시 접근 |
| 결과 기록 (WB) | 연산 결과 및 로드 데이터의 레지스터 기록 |
| 파이프라인 레지스터 | 단계 간 데이터 및 제어 신호의 동기화 전달 |

#### 한줄 요약

- **5단계(IF-ID-EX-MEM-WB)**와 중간 파이프라인 레지스터의 동기화 제어

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **정상 상태(Steady State)**: 파이프라인의 모든 단계가 유효 명령어로 채워져 매 사이클마다 결과가 산출되는 이상적 동작 상태.

</details>

```text
클록 주기 ──>   CC1   CC2   CC3   CC4   CC5   CC6   CC7
명령어 1:      IF ──> ID ──> EX ──> MEM ──> WB
명령어 2:             IF ──> ID ──> EX  ──> MEM ──> WB
명령어 3:                    IF ──> ID  ──> EX  ──> MEM ──> WB
명령어 4:                           IF  ──> ID  ──> EX  ──> MEM ──> WB
```

**동작 원리**

1. **시동 단계**: 초기 4클록 동안 순차적으로 명령어를 투입하여 파이프라인 레지스터를 채움
2. **정상 상태**: 5번째 클록부터 매 사이클마다 1개의 명령어가 WB 단계를 빠져나와 완료
3. **제어 신호 전달**: 클록 상승 엣지마다 파이프라인 레지스터가 다음 단계로 제어 비트 이동
4. **결과 갱신**: 레지스터 파일에 최종 연산 결과를 기록하며 지속적 연속 처리 완결

#### 한줄 요약

- **시동-정상-종료** 단계를 거치며 정상 상태에서 매 클록 1개 명령어 완결

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **해저드(Hazard)**: 구조적(자원 충돌), 데이터(의존성), 제어(분기) 요인으로 인해 다음 사이클에 명령어가 실행되지 못하는 현상.

</details>

| 비교 항목 | 5단계 파이프라인 구조 | 비파이프라인 구조 |
|:---|:---|:---|
| 적용 기준 | 고성능 범용 CPU, 모바일 AP, 슈퍼스칼라 프로세서 | 초저전력 마이크로컨트롤러, 단순 상태 제어기 |
| 핵심 특징 | 최장 단계 지연 기준 고속 클록, 높은 처리량(IPC≒1) | 전 과정 합산 지연 기준 긴 클록 주기, 낮은 처리량 |
| 한계 및 위험 | 구조적/데이터/제어 해저드 및 파이프라인 스톨/플러시 | 회로 단순성은 높으나 하드웨어 유휴 시간 과다 발생 |

#### 한줄 요약

- 파이프라인은 **고속 클록과 고처리량**, 비파이프라인은 **단순성과 해저드 부재**

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **단계 분할(Stage Splitting)**: 가장 오래 걸리는 단계를 2개 이상의 세부 단계로 쪼개어 시스템 클록 주파수를 높이는 기법(슈퍼파이프라이닝).

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 의존성 데이터 해저드 발생 및 **버블** 주입 | **포워딩** 경로 구성 및 컴파일러 **명령 스케줄링** 적용 | 대기 버블 축소 및 연산 주파수 유지 |
| 조건 분기 타깃 미확정으로 파이프라인 **플러시** 손실 | 버퍼 기반 **분기 예측** 및 조기 판정 회로 내장 | 분기 페널티를 최소화하고 연속성 보장 |
| 특정 논리 지연이 길어 클록 주파수 저하 | 지연 경로를 분할하는 **단계 분할** 및 회로 재배치 | 클록 주파수 상승으로 전체 성능 향상 |
| 단계 깊이 증가에 따른 **단계 사용률** 저하 | 동적 해저드 제어 및 비순차 실행 엔진 연동 | 버블 최소화 및 단위 시간 유효 처리량 극대화 |

#### 한줄 요약

- **포워딩·분기 예측·단계 분할·명령어 재배치**로 해저드 페널티 최소화

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **슈퍼파이프라이닝(Superpipelining)**: 파이프라인을 10~20단계 이상으로 미세 분할하여 초고주파수 클록을 달성하는 고성능 아키텍처 기법.

</details>

- 워크로드 특성 분석 기반 **파이프라인 깊이 최적화 및 하드웨어 해저드 완화 기법 적용**

#### 한줄 요약

- **최장 단계 지연과 해저드 페널티**의 균형을 통한 최적 파이프라인 설계
