## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **버스 스누핑(Bus Snooping)**: 공용 공유 버스의 트랜잭션을 각 사설 캐시 제어기가 도청(Snoop)하여 일관성 상태를 동기화하는 체계.
- **디렉터리 기반 일관성(Directory-Based Coherence)**: 각 메모리 블록별 사본 보유 코어 목록을 디렉터리에 기록하여 필요한 노드에만 점대점으로 메시지를 전송하는 아키텍처.
- **선택적 무효화(Selective Invalidation)**: 전체 브로드캐스트 없이 실제 사본을 가진 코어에만 점대점으로 무효화 패킷을 전송하는 기술.

</details>

- 정의/개념: 공유 버스의 브로드캐스트 신호를 감시하는 버스 스누핑(Bus Snooping)과 주소별 공유자 목록을 추적하여 점대점으로 제어하는 디렉터리 기반(Directory-based) 일관성 아키텍처
- 배경/필요성: 코어 수 증가 시 발생하는 **전역 브로드캐스트 대역폭 포화(스누핑의 한계)를 극복하고 대규모 멀티코어/NUMA 서버 확장성 확보**

#### 한줄 요약

- 소규모는 **브로드캐스트 버스 스누핑**, 대규모는 **점대점 디렉터리 기반 일관성** 활용

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **일관성 순서점(Coherence Ordering Point)**: 동일 메모리 주소에 대한 복수 쓰기 요청의 전역 순서를 확정하는 직렬화 지점.
- **무효화 완료 응답(Invalidation Ack)**: 무효화 메시지를 받은 캐시가 사본 파기를 완료했음을 발신자에게 알리는 패킷.

</details>

- 트랜잭션 전역 순서를 결정짓는 **일관성 순서점** 구성을 통한 쓰기 직렬화 보장
- 타 사본들의 **무효화 완료 응답(Ack)** 수합 완료 후 요청 코어에 **배타적 쓰기 권한** 부여
- 버스 스누핑은 **전체 브로드캐스트 관찰**, 디렉터리는 **공유자 명단 조회 후 점대점 전송**

#### 한줄 요약

- **일관성 순서점(Serialization)**과 무효화 완료 응답(Ack)으로 단일 쓰기 독점권 확정

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **홈 디렉터리(Home Directory)**: 주소 블록의 캐시 공유자 비트맵(Sharer Bitmap)과 상태 메타데이터를 유지하는 중앙/분산 관리 노드.
- **점대점 인터커넥트**: NoC(Network-on-Chip) 또는 크로스바 라우터를 통해 특정 노드로 메시지를 직접 전송하는 통신망.

</details>

```text
[ 버스 스누핑 구조 (Bus Snooping) ]
 +------------+     +------------+     +------------+
 | 코어 0 캐시 |     | 코어 1 캐시 |     | 코어 2 캐시 |
 +------------+     +------------+     +------------+
       │                  │                  │
 ══════╧══════════════════╧══════════════════╧════ [ 공유 버스 브로드캐스트 ]

[ 디렉터리 기반 일관성 구조 (Directory-Based) ]
 +------------------+     +------------------+
 |    코어 0 노드   |     |    코어 1 노드   |
 +------------------+     +------------------+
          │                        │
 ═════════╧════════════════════════╧══════════════ [ 점대점 NoC 패킷 라우터 ]
          │
 +-------------------------------------------+
 | 홈 디렉터리 노드 (공유자 비트맵 보유)    |
 +-------------------------------------------+
```

선의 의미: 공유 버스 기반 스누핑 구조와 홈 디렉터리 및 점대점 인터커넥트 기반 일관성 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 공유 버스 및 버스 중재기 | 일관성 트랜잭션 직렬화 및 전 코어 방송 수행 |
| 스누프 제어기 | 방송 버스 감시를 통한 캐시 상태 갱신 제어 |
| 홈 디렉터리 | 주기억장치 주소별 공유자 및 상태 목록 관리 |
| 점대점 인터커넥트 | 대상 노드 간 일관성 제어 메시지의 단독 라우팅 |

#### 한줄 요약

- **공유 버스 중재기(스누핑)**와 **홈 디렉터리·점대점 네트워크(디렉터리)** 구조 비교

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **홈 노드(Home Node)**: 메모리 주소 번지에 매핑되는 디렉터리 메타데이터와 물리 메모리를 관장하는 전담 노드.

</details>

```text
[ 버스 스누핑 흐름 ]
[코어 0 쓰기 요청] ──> 공유 버스 전역 브로드캐스트 ──> [전체 코어 스누핑 및 무효화] ──> [쓰기 완료]

[ 디렉터리 기반 흐름 ]
[코어 0 쓰기 요청] ──> [홈 노드 디렉터리 조회 (공유자 코어 2 특정)]
                               │
                               ▼
[특정 대상 점대점 무효화 전송 (코어 2)] ──> [코어 2 무효화 완료 응답(Ack)] ──> [쓰기 완료]
```

**동작 원리**

1. **버스 스누핑 동작**: 쓰기 요청을 공유 버스에 브로드캐스트하고, 모든 코어의 스누프 제어기가 주소를 대조하여 사본을 무효화
2. **디렉터리 조회**: 요청을 받은 **홈 노드**가 공유자 비트맵을 조회하여 해당 블록을 가진 특정 코어만 추출
3. **점대점 무효화**: 사본을 보유한 코어에만 점대점 무효화 메시지를 전송하고 타 코어로는 트래픽 미발생
4. **완료 응답 수합**: 대상 코어들로부터 무효화 완료 응답(Ack)을 모두 수신하면 요청 코어에 독점 쓰기 권한 부여

#### 한줄 요약

- 스누핑은 **전체 방송 무효화**, 디렉터리는 **공유자 명단 조회 후 점대점 무효화**

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **확장성(Scalability)**: 코어 수가 8개에서 64개, 128개 이상으로 증가할 때 대역폭과 성능이 선형적으로 유지되는 능력.

</details>

| 일관성 구조 | 버스 스누핑 방식 (Bus Snooping) | 디렉터리 기반 방식 (Directory-based) |
|:---|:---|:---|
| 적용 기준 | 소규모 단일 칩 멀티코어 (4~8코어 데스크톱/모바일) | 대규모 다중 소켓 멀티프로세서 (NUMA, 서버, HPC) |
| 핵심 특징 | 공유 버스 브로드캐스트 감시, 별도 디렉터리 메모리 불필요 | 홈 노드의 공유자 비트맵 관리, 점대점 유니캐스트 메시징 |
| 한계 및 위험 | 코어 수 증가 시 $O(N^2)$ 트래픽 폭증 및 버스 대역폭 포화 | 디렉터리 메타데이터 메모리 오버헤드, 3-Hop 메시지 지연 |

#### 한줄 요약

- 스누핑은 **소규모 저지연 단순성**, 디렉터리는 **대규모 확장성(Scalability)**에 특화

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **희소 디렉터리(Sparse Directory)**: L1/L2 캐시에 적재된 유효 라인만 추적하여 디렉터리 메모리 용량을 80% 이상 절감하는 구조.
- **가상 채널(Virtual Channel)**: 요청(Request), 전달(Forward), 응답(Response) 메시지의 버퍼 큐를 분리하여 프로토콜 데드락을 방지하는 라우터 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 코어 증가에 따른 디렉터리 **메타데이터** 용량 기하급수적 증가 | **희소 디렉터리** 및 **제한 디렉터리** 방식 도입 적용 | 디렉터리 메모리 오버헤드 축소 및 실리콘 면적 절감 |
| 특정 주소 번지 접근 집중 시 단일 홈 노드로 라우팅 핫스팟 발생 | **주소 해싱** 알고리즘 기반 홈 디렉터리 노드 분산 | 시스템 전체 통신 병목 해소 및 점대점 지연시간 균일화 |
| 요청 패킷과 응답 패킷 충돌로 인한 온칩 네트워크 프로토콜 교착 | 라우터 내부 **가상 채널** 분리 및 메시지 종류별 순서 제어 | 일관성 제어 메시지 교착 완벽 차단 및 시스템 활성 유지 |
| 스누핑 방식에서 한계 코어 초과로 인한 **버스 대역폭** 포화 | 상위 레벨 점대점 전환을 융합한 계층형 스누핑 아키텍처 채택 | 로컬 트래픽 국지화 방어 및 전체 외부 대역폭 확보율 극대화 |

#### 한줄 요약

- **희소 디렉터리·주소 해싱 분산·가상 채널(VC)**로 메모리 및 교착상태 방어

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **계층형 일관성(Hierarchical Coherence)**: 칩/소켓 내부에서는 고속 스누핑을 사용하고, 소켓 간/노드 간에는 디렉터리를 결합하는 하이브리드 아키텍처.

</details>

- 시스템 규모 분석 기반 **8코어 이하는 스누핑, 대규모 NUMA/클러스터는 디렉터리 일관성 채택**

#### 한줄 요약

- **코어 확장 규모와 온칩 네트워크 대역폭**을 기준으로 최적 일관성 메커니즘 선정
