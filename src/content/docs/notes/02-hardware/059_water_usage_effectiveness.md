## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **물 사용 효율(Water Usage Effectiveness, WUE)**: The Green Grid에서 제정한 지표로, 데이터센터의 연간 총 용수(물) 사용량을 IT 장비가 소비한 총 전력량으로 나눈 수자원 지속가능성 표준 척도.
- **증발식 냉각(Evaporative Cooling)**: 냉각탑에서 물이 증발할 때 주변의 열을 흡수하는 잠열(Latent Heat)을 활용하여 적은 전력으로 차가운 냉각수를 생산하는 공조 방식.

</details>

- 정의/개념: 연간 총 용수 소비량을 IT 전력량으로 나눈 **WUE(Water Usage Effectiveness) 지표**
- 배경/필요성: PUE 최적화를 위한 **증발식 냉각**탑 과다 가동 시 발생하는 수자원 대량 소비(Water-Energy Tradeoff) 및 **물 부족 규제 대응 한계 극복 및 수자원 지속가능성 관리 체계 확립 필요성 증대**

$$
\text{WUE} = \frac{\text{연간 총 용수 사용량 (Annual Water Usage, Liter)}}{\text{순수 IT 장비 전력 소비량 (IT Equipment Energy, kWh)}} \quad [\text{L/kWh}] \quad (\text{이상적 목표: } 0.0)
$$

#### 한줄 요약
- WUE는 데이터센터가 IT 장비 1kWh를 구동하고 냉각하는 데 소비한 물의 양(L)을 측정하는 수자원 지속가능성 지표다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **이상적 WUE(Ideal WUE = 0.0 L/kWh)**: 냉각탑 증발수나 수자원 소비 없이 100% 무수(Zero-Water) 공랭 또는 완전 밀폐형 드라이 쿨러로 구동되는 상태.
- **농축 배수(Cycles of Concentration, COC)**: 냉각탑 순환수가 증발할 때 잔류 미네랄이 농축되는 비율로, COC가 높을수록 강제 배출(블로우다운)하는 물의 양이 줄어들어 절수됨.

</details>

- 수자원 평가: IT 전력 1kWh당 용수 소비량 측정을 통한 물-전력 상충 관계 정량화
- 수처리 제어: **농축 배수(COC)** 제어 및 중수도 재활용을 통한 상수도 의존도 최소화
- PUE 균형 최적화: 증발 냉각과 건식 방열을 결합한 하이브리드(Adiabatic) 냉각 적용 유도

#### 한줄 요약
- 0.0에 근접할수록 수자원을 아끼는 친환경 센터이며, 농축 배수 제어와 하이브리드 냉각을 통해 용수 낭비를 막는다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **농축 배수 제어기(COC Controller)**: 냉각탑 수질의 전기전도도(TDS)를 측정하여 블로우다운 밸브를 자동으로 개폐하는 지능형 수처리 장비.
- **블로우다운(Blowdown)**: 냉각탑 순환수가 증발하면서 농축된 미네랄과 침전물이 배관을 막지 않도록 강제로 방류하는 농축 퇴수.

</details>

```text
+-------------------------------------------------------------------------------+
|                    데이터센터 WUE 수자원 계측 및 냉각수 처리 계통            |
|                                                                               |
|  [ 상수도/중수도 인입선 ]                                                     |
|           │                                                                   |
|           ▼                                                                   |
|  +-------------------------------------------------------------------------+  |
|  | [계측 지점 A: 총 용수 인입량(분자)] -> 스마트 디지털 초음파 유량계       |  |
|  +-------------------------------------------------------------------------+  |
|           │                                                                   |
|           ▼ 보충수 (Makeup Water)                                             |
|  +-------------------------------------------------------------------------+  |
|  |       개방형/하이브리드 냉각탑 (Evaporative Cooling Tower)              |  |
|  |       [ 대기 증발 잠열 방열 ] <=========> [ 배관 순환수 수온 강하 ]      |  |
|  +-------------------------------------------------------------------------+  |
|           │                                          │                        |
|           ▼ 강제 방류 (블로우다운)                   ▼ 1차 냉각수 공급        |
|  +---------------------------------+   +-----------------------------------+  |
|  | 농축 배수(COC) 자동 제어 밸브   |   | 폐쇄형 판형 열교환기 (HEX)        |  |
|  | (전기전도도 TDS 감시 방류 최소화)|   | (냉각탑수 <-> IT 전산실 2차수 격리)|  |
|  +---------------------------------+   +-----------------------------------+  |
|                                                          │ 2차 밀폐 냉각 루프  |
|                                                          ▼                    |
|                                        +-----------------------------------+  |
|                                        | IT 장비 랙 (Level 3 전력 계측 지점)|  |
|                                        | [계측 지점 B: IT 전력(kWh) 분모]  |  |
|                                        +-----------------------------------+  |
|                                                          │                    |
|  [ 계측 지점 A: 총 용수(L) ] + [ 계측 지점 B: IT 전력(kWh) ] ===> DCIM WUE 엔진 |
+-------------------------------------------------------------------------------+
```

- 신호 및 연결 관계: 상단 인입 유량계(분자)와 하단 IT 랙 전력계(분모)의 시계열 데이터(`===>`)가 DCIM 수자원 관리 모듈로 집계되어 실시간 L/kWh 단위의 WUE를 산출함을 명시함

| 구성요소 | 책임 |
|:---|:---|
| 인입 유량계 | 센터의 총 용수량 계측 |
| 증발식 냉각탑 | 물의 증발 잠열을 이용한 방열 |
| 농축 배수 제어기 | 전도도 기반 블로우다운 방류량 최소화 |
| 폐쇄형 판형 열교환기 | 냉각탑수와 서버 순환수의 물리적 격리 |
| DCIM 수자원 모듈 | 유량·IT 전력 기반 실시간 WUE 산출 |

#### 한줄 요약
- 증발식 냉각탑이 전력 대신 물의 잠열로 열을 버리는 자리를 맡고, 폐쇄형 열교환기가 그 냉각탑수를 서버 순환수와 갈라놓아 방열 효과만 건네받으며, 농축 배수 제어기는 그 대가로 버려야 하는 블로우다운 양을 전도도 기준으로 깎는다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **단열 분무식 하이브리드 공조(Adiabatic Cooling)**: 평상시 물을 쓰지 않는 건식 드라이쿨러로 동작하다가, 한여름 폭염 피크 시에만 공기 흡입구에 미세 물방울을 분무하여 온도를 낮추는 고효율 절수 공조.

</details>

```text
+-------------------------------------------------------------+
|              데이터센터 용수 공급 및 IT 부하 가동           |
+-------------------------------------------------------------+
                               │
                               ▼
+-------------------------------------------------------------+
| 1. 스마트 유량계 및 랙 PDU 전력계 기반 용수량·전력 계측    |
+-------------------------------------------------------------+
                               │
                               ▼
+-------------------------------------------------------------+
| 2. 실시간 WUE 산출 및 냉각탑 증발/비산 손실률 분석          |
+-------------------------------------------------------------+
                               │
                               ▼
+-------------------------------------------------------------+
| 3. 농축 배수(COC) 전기전도도 센싱 기반 블로우다운 최소화    |
+-------------------------------------------------------------+
                               │
                               ▼
+-------------------------------------------------------------+
| 4. 외기 측정 기반 건식 드라이쿨러/단열 분무 하이브리드 전환 |
+-------------------------------------------------------------+
                               │
                               ▼
+-------------------------------------------------------------+
| 5. 목표 WUE(0.2 L/kWh 이하) 달성 및 PUE-WUE 에너지 균형     |
+-------------------------------------------------------------+
```

분기 결과: 외기 건구온도가 낮으면 완전 무수(0.0 L/kWh) 건식 드라이쿨러로 가동하고 극고온 시에만 단열 분무를 가동하여 용수 낭비를 원천 차단함

**동작 원리**

1. **실시간 유량 및 전력 계측**: 인입 배관의 전자식 스마트 유량계와 서버 랙의 IT 전력계를 통해 용수 투입량(L)과 소비 전력량(kWh) 실시간 수집
2. **소비 패턴 분석**: DCIM 수자원 모듈이 데이터를 집계하여 시간대별 WUE 지수를 산출하고 증발식 냉각탑의 물 소비 패턴 분석
3. **농축 배수 자동 제어**: 냉각탑 순환수 내부의 용존 이온 농도를 TDS 센서로 측정하여 농축 배수(COC)를 6~8사이클 이상으로 높여 블로우다운 밸브 개폐 최소화
4. **외기 연동 모드 절환**: 외부 기온이 선선한 계절에는 냉각탑 밸브를 차단하고 물을 전혀 쓰지 않는 건식 드라이 쿨러로 절환하여 WUE 0.0 상태 유지
5. **다차원 에너지 균형 유지**: 혹서기 피크 시간대에는 단열 분무(Adiabatic) 노즐만을 제한적으로 분사하여 PUE 전력 급증과 WUE 용수 낭비 사이의 최적 균형점 유지

#### 한줄 요약
- 무수 냉각은 용수를 아끼는 대신 압축기 전력을 더 쓰므로 WUE 개선이 PUE 악화로 되돌아오며, 두 지표의 균형점은 그 입지에서 전력과 용수 중 무엇이 더 희소한지가 정한다.

## Ⅴ. 종류 및 비교

| 대상 구분 | WUE (물 사용 효율) | PUE (전력 사용 효율성) | CUE (탄소 사용 효율) | ERF (에너지 재사용 비율) |
|:---|:---|:---|:---|:---|
| 적용 기준 | 냉각탑 증발수 및 수자원 소비량 최적화 시 | 공조 및 변전 손실 전력 오버헤드 최소화 시 | 스코프 2 온실가스 배출량 및 ESG 공시 대응 시 | 데이터센터 발생 폐열의 지역난방 재활용 평가 시 |
| 핵심 특징 | $\text{연간 총 용수(L)} / \text{IT 전력(kWh)}$, 냉각탑 수자원 소비 추적, 이상적 목표 $0.0\text{ L/kWh}$ | $\text{총 시설 전력} / \text{IT 전력}$, 이상적 목표 $1.0$, 공조/변전 에너지 효율 지표 | $\text{총 }CO_2\text{ 배출량} / \text{IT 전력(kWh)}$, 이상적 목표 $0.0$, 탄소 발자국 평가 | $\text{재사용 에너지} / \text{총 투입 에너지}$, 이상적 목표 $100\%$, 폐열 회수 지표 |
| 한계 | 전력 소비 절감과의 트레이드오프(물-전력 상충), 무수 냉각 시 PUE 상승 유발 | 수자원 증발 소비 및 탄소 배출 미반영, 저효율 서버 착시 발생 | 전력 공급원의 신재생 발전 믹스 종속, 실시간 계측 복잡성 | 인근 지역난방 배관망 인프라 필수, 하절기 폐열 수요 급감 한계 |

#### 한줄 요약
- WUE는 데이터센터의 수자원 소비를 통제하며, PUE, CUE, ERF와 함께 다차원 그린 데이터센터를 구축하는 4대 지표다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **물 스트레스 지역(Water-Stressed Region)**: 연간 가용 수자원 대비 수요가 40% 이상 초과하여 물 부족과 환경 파괴 리스크가 높은 권역.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **물 스트레스 지역** 내 인허가 규제 | **단열 분무식 하이브리드 공조** 및 완전 폐쇄형 루프 | 상수도 사용량 90% 감축 |
| 냉각탑 농축으로 인한 배관 스케일 형성 | 자동 전도도 기반 **COC 제어** 및 수처리 장치 | 배관 부식 방지 및 열교환 효율 유지 |
| PUE 절감 치중으로 수도 요금 폭증 | **전력-용수 통합 비용 모델** 기반 가변 공조 운전 | PUE와 WUE 간 최적 경제점 확보 |

#### 한줄 요약
- 실무에서는 하이브리드 쿨러로 물 부족 규제를 피하고, 자동 COC 제어로 스케일을 막으며, 통합 비용 모델로 PUE-WUE 균형을 맞춘다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **TDS(Total Dissolved Solids)**: 물속에 용존된 총 고형물질의 양으로, 전기전도도 센서로 측정하여 냉각수 농축 오염도를 판단하는 지표.
- **폐열 회수(Waste Heat Recovery)**: 서버에서 배출되는 30~50°C 온수를 히트펌프로 승온시켜 인근 시설 난방이나 스마트팜에 공급하는 순환 경제 기술.

</details>

- 데이터센터 냉각 수자원 소비를 정량화하는 글로벌 핵심 친환경 지속가능성 지표(이상적 목표: 0.0 L/kWh 무수 냉각)로 정립되었으며, 향후 물 스트레스 지역 인허가 규제 대응과 지속가능성을 위해 완전 밀폐형 드라이 쿨러, 단열 분무식(Adiabatic) 냉각 및 중수도/우수 재활용 시스템과의 연계가 필수 설계 기준으로 확립 진행 중.
- 인프라 엔지니어는 전력 요금과 용수 요금을 통합한 단일 TCO 함수를 도출하여 PUE-WUE 상충 관계를 동적으로 최적화하는 수자원 거버넌스 체계 확립 필수.

#### 한줄 요약
- WUE는 데이터센터 수자원 책임의 핵심 지표이며, 하이브리드 냉각과 PUE 연계 최적화를 통해 완성된다.
