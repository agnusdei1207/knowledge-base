## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **WUE(Water Usage Effectiveness)**: 데이터센터의 연간 현장 용수 사용량을 IT 장비 에너지 사용량으로 나눈 수자원 효율 지표.
- **증발식 냉각(Evaporative Cooling)**: 냉각탑에서 물의 증발 잠열을 이용해 공랭식 대비 전력 소비를 줄이며 냉수를 생산하는 공조 방식.

</details>

- 정의/개념: 데이터센터 냉각 및 운영에 소비된 연간 총 용수량을 순수 IT 장비 소비 전력량으로 나눈 **수자원 지속가능성 평가 지표**
- 배경/필요성: 증발 냉각으로 전력을 줄여도 지역 물 스트레스와 취수·소비 영향은 PUE에 나타나지 않아 별도 계측 필요

$$
\text{WUE} = \frac{\text{연간 총 용수 사용량 (Annual Water Usage, Liter)}}{\text{순수 IT 장비 전력 소비량 (IT Equipment Energy, kWh)}} \quad [\text{L/kWh}]
$$

#### 한줄 요약
- 서버가 쓴 전력(1kWh)당 데이터센터 냉각에 들어간 물의 양(리터)을 측정해 수자원 낭비를 평가하는 지표다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **물-에너지 넥서스(Water-Energy Nexus)**: 전력 효율(PUE)을 높이기 위해 물을 많이 쓰면 WUE가 나빠지고, 물을 안 쓰면 팬 전력 소비로 PUE가 나빠지는 상관관계.
- **블로우다운(Blowdown)**: 냉각탑 순환수가 증발하면서 농축된 미네랄과 침전물을 배출하기 위해 강제로 방류하는 퇴수.

</details>

- The Green Grid 표준 지표로 **0에 근접할수록** 수자원 소비가 없는 친환경 시스템
- 전력 사용 효율(PUE)과의 **상충 관계(Trade-off)** 를 투명하게 정량화
- 하수 재처리수(중수도) 및 빗물 재활용 적용 효과를 직접적으로 평가

#### 한줄 요약
- 수치가 낮을수록 물을 아끼는 친환경 센터이며, PUE 절감을 위해 물을 무분별하게 낭비하는 현상을 감시한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **농축 배수 제어기(COC Controller)**: 냉각탑의 전기전도도를 측정하여 블로우다운 밸브를 자동 제어하는 수처리 장치.
- **드라이쿨러(Dry Cooler)**: 물 증발 없이 외기 공기와 냉매/냉수 간의 열교환만으로 열을 방출하는 무수(Zero-Water) 냉각기.

</details>

```text
┌─────────────────────────────────────────────────────────────┐
│ 데이터센터 수자원 흐름 및 WUE 계측 지점 구조               │
│                                                             │
│  [ 상수도 / 지하수 / 중수도 인입 유량계 ]                   │
│  └──────────────────────────┬───────────────────────────────┘│
│                             ▼                               │
│              ┌──────────────┴──────────────┐                │
│              │ 수처리 및 연수화 설비       │                │
│              └──────┬───────────────┬──────┘                │
│                     │               │                       │
│        (증발 손실)  │               │ (블로우다운 퇴수)     │
│             ▼       ▼               ▼                       │
│        ┌────────────────────┐ ┌───────────────────┐         │
│        │ 증발식 냉각탑      │ │ 수질 모니터링 &   │         │
│        │ (Evaporative Tower)│ │ 배수 유량계       │         │
│        └────────────┬───────┘ └───────────────────┘         │
│                     │                                       │
│                     ▼ (냉각수 순환)                         │
│        ┌──────────────────────────────────────────┐         │
│        │ 전산실 칠러 및 수랭식 열교환기 (CDU)     │         │
│        └──────────────────────────────────────────┘         │
└─────────────────────────────────────────────────────────────┘
```

선의 의미: 인입 유량계에서 측정된 총 용수가 냉각탑 증발 및 블로우다운 배수로 순환하며 IT 발열을 제거

| 구성요소 | 책임 |
|:---|:---|
| 인입 용수 계량기 | 상수도, 중수도, 지하수 등 센터로 유입되는 모든 급수량을 실시간 측정 |
| 증발식 냉각탑 & 칠러 | 물의 증발 잠열을 활용해 고온 냉각수의 열을 대기로 방출 |
| 농축 배수 제어기 (COC) | 수질 전도도 감시 및 적정 농축 배수 유지를 통한 블로우다운 배출수 최소화 |
| 폐쇄형 루프 열교환기 (CDU) | 내부 순환 냉각수를 외부 급수와 물리적으로 격리하여 용수 오염 방지 |
| 통합 BEMS 관제기 | 용수 사용량과 IT 전력 소비량을 동시 집계하여 실시간 WUE 산출 |

#### 한줄 요약
- 급수 유량계, 냉각탑, COC 수처리 장비, 폐쇄형 CDU, BEMS 관제기가 상호 결합된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **하이브리드 공조(Adiabatic Cooling)**: 평상시 건식 드라이쿨러로 동작하다가 한여름 피크 온도시만 단열 분무식으로 물을 분사하는 절수 공조 방식.

</details>

```text
데이터센터 WUE 절감 프로젝트 착수
      │
      ▼
1. 수자원 인벤토리 구축: 인입 급수량, 증발량, 배수량 전수 계측
      │
      ▼
2. 농축 배수 최적화
      │
      ▼
3. 하이브리드 냉각 전환
      │
      ▼
4. 대체 수자원 연계
      │
      ▼
5. PUE-WUE 통합 최적화
```

**동작 원리**

1. **용수 밸런스 측정**: 인입 급수량과 배수량을 실시간 측정하여 미계측 누수 지점 제거
2. **농축 배수 최적화**: 수질·부식·스케일 한계 안에서 COC와 블로우다운 조정
3. **무수 냉각 확대**: 기온이 낮은 계절에는 물을 전혀 쓰지 않는 외기 건식 냉각으로 전환
4. **대체 수자원 연계**: 수질·보건 기준을 충족하는 재이용수·빗물로 상수도 의존 감소
5. **통합 시뮬레이션**: PUE 상승 비용과 용수 비용을 실시간 비교하여 최적 절수 모드 가동

#### 한줄 요약
- 용수 계측 → 농축 배수비 상향 → 하이브리드 단열 냉각 → 대체수 전환 → PUE-WUE 통합 제어 순으로 진행된다.

## Ⅴ. 종류 및 비교

| 친환경 지속가능성 지표 | WUE (용수) | PUE (전력) | CUE (탄소) | ERF (에너지 재사용) |
|:---|:---|:---|:---|:---|
| 적용 기준 | 냉각 용수 소비량 및 물 스트레스 지역 관리 | 총 전력 중 비IT 인프라 손실 비율 평가 | 전력 소비에 따른 온실가스 배출량 관리 | 데이터센터 폐열의 외부 지역난방 재활용 |
| 핵심 특징 | 연간 용수량(L) / IT 전력량(kWh) | 총 시설 전력 / 순수 IT 전력 | 총 온실가스량($\text{CO}_2\text{eq}$) / IT 전력량 | 외부 재사용 에너지 / 총 투입 에너지 |
| 한계 | 전력 사용량과의 트레이드오프 발생 | 물 소비나 탄소 배출량을 반영 못함 | 신재생 에너지 인프라 종속성 높음 | 인근 난방 수요처 확보 및 배관 인프라 필요 |

#### 한줄 요약
- 물은 WUE, 전력은 PUE, 탄소는 CUE, 폐열은 ERF로 평가하여 복합 친환경 데이터센터를 구현한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **물 스트레스 지역(Water-Stressed Region)**: 가용 수자원 대비 수요가 과도하여 가뭄이나 환경 파괴 위험이 극심한 지리적 권역.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 물 스트레스 지역의 **지역사회·인허가 위험** | 건식·하이브리드 냉각과 대체 수원을 지역 수질·기후에 맞춰 적용 | 상수도 소비와 피크 취수 영향 감소 |
| 냉각수 순환 배관 부식 및 스케일 침착으로 인한 **설비 고장** | **자동 수처리 시스템(화학 약품 투입/전기분해)** 및 정밀 수질 센서 연동 | 스케일 방지 및 냉각 열교환 효율 유지 |
| PUE 단일 지표 추구로 인한 **과도한 수자원 낭비(WUE 악화)** | PUE-WUE 통합 비용 지표(TCO/ESG) 수립 및 계절별 복합 운영 | 에너지와 수자원의 다차원 최적화 |
| 재이용수 사용 시 **레지오넬라 등 미생물 위험** | 위험평가에 따른 여과·소독·잔류농도·비산수 관리 | 냉각탑 수질과 작업자·주변 노출 위험 관리 |

#### 한줄 요약
- 단열 하이브리드 쿨러로 갈등을 막고, 자동 수처리로 스케일을 방지하며, UV 살균으로 안전성을 확보한다.

## Ⅶ. 결론

- 물 스트레스가 크면 **WUE와 피크 취수량**을 우선 줄이고, 다른 지역도 PUE·CUE와 함께 냉각 방식 결정

#### 한줄 요약
- 동일 WUE라도 지역·수원별 영향이 다르므로 재이용수 비율과 유역 위험까지 공개해 입지를 판단해야 한다.
