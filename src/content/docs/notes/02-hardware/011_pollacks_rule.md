## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **폴락의 법칙(Pollack's Rule)**: 동일 반도체 공정에서 프로세서 마이크로아키텍처의 트랜지스터 수와 면적을 $n$배로 늘릴 때 단일 스레드 성능 향상은 제곱근인 $\sqrt{n}$배에 그친다는 컴퓨터 아키텍처 경험 법칙.
- **경험 법칙(Empirical Rule)**: 수학적 이론 유도가 아닌 실제 반도체 칩 실측 데이터와 마이크로아키텍처 관측을 통해 정립된 공학적 법칙.
- **하위 선형 반환(Sublinear Return)**: 자원 투입량 $n$배 대비 성능 증가율이 정비례하지 못하고 완만한 제곱근 곡선을 그리며 둔화되는 비선형 성능 특성.
- **수익 체감(Diminishing Returns)**: 코어 면적과 트랜지스터를 추가 투입할수록 단위 자원당 얻어지는 성능 향상 폭이 점차 감소하는 공학적 한계.

</details>

- 정의/개념: 동일 공정에서 면적·트랜지스터 $n$배 증가 시 단일 성능은 $\sqrt{n}$배에 그치는 **경험 법칙**
- 배경/필요성: 단일 코어 대형화의 **하위 선형 반환**과 **수익 체감**으로 멀티코어 패러다임 전환 촉발

#### 한줄 요약

- 코어 면적을 4배 늘려도 성능 향상은 2배($\sqrt{4}$)에 그치는 **하위 선형적 성능 법칙**.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **단일 스레드 성능(Single-Thread Performance)**: 단일 프로세서 코어가 단일 명령어 실행 흐름을 단위 시간당 처리하는 연산 속도.
- **면적당 성능(Performance per Area)**: 실리콘 다이 면적 투입량 대비 달성된 연산 속도로, 면적이 $n$배 늘어날 때 효율이 $1/\sqrt{n}$로 감소하는 핵심 척도.
- **이종 멀티코어(Heterogeneous Multicore)**: 고성능 대형 코어와 고효율 소형 코어를 하나의 다이에 혼합 탑재하여 면적당 성능 효율을 극대화하는 아키텍처.

</details>

![코어 복잡도에 따른 단일 스레드 성능의 제곱근 증가 차트](/study/diagrams/pollacks-rule-growth.svg)

> 다이 면적($C$) 증가 시 단일 성능($P$)은 $\sqrt{C}$배로 완만하게 증가하고 단위 면적당 성능 효율은 $1/\sqrt{C}$로 감소하는 하위 선형 추세.

- 면적 $n$배 투입 시 **단일 스레드 성능**은 $\sqrt{n}$배로 증가 (면적 4배 시 성능 2배)
- 단위 **면적당 성능** 효율은 $1/\sqrt{n}$로 저하 (면적 4배 시 면적당 효율 50%로 반감)
- 단일 코어 대형화의 한계를 극복하기 위한 **이종 멀티코어** 설계 기준 제시

#### 한줄 요약

- 면적 $n$배 시 성능은 $\sqrt{n}$배 증가에 그쳐 **면적당 연산 효율이 $1/\sqrt{n}$로 반감**.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **단일 대형 코어(Monolithic Big Core)**: 넓은 다이 면적에 비순서 실행 엔진과 대용량 윈도우를 집적하여 단일 스레드 지연을 최소화한 고성능 코어.
- **다중 소형 코어(Multiple Small Cores)**: 단순한 파이프라인을 적용한 경량 코어 다수를 동일 면적에 배치하여 전체 병렬 처리량을 극대화한 구조.
- **총 병렬 처리량(Total Parallel Throughput)**: 다수의 독립된 코어가 동시에 작업을 수행하여 시스템 전체에서 단위 시간당 완결하는 총 연산량.
- **공유 최종 단계 캐시(Shared Last-Level Cache, Shared LLC)**: 모든 코어가 공유하며 느린 주기억장치 접근 지연을 완충하는 온칩 대용량 L3 캐시.
- **DRAM 접근 지연(DRAM Access Latency)**: 프로세서가 메인 메모리인 DRAM에 데이터를 요청하여 응답을 받을 때까지 소요되는 지연시간.
- **온칩 인터커넥트(On-Chip Interconnect)**: 다중 코어, 캐시, 메모리 제어기 간에 데이터와 제어 패킷을 고속으로 전달하는 온칩 통신망.
- **고속 패킷 전송(High-Speed Packet Transmission)**: 온칩 인터커넥트 버스나 네트워크를 통해 코어 간 데이터를 낮은 지연으로 교환하는 전송 방식.

</details>

```text
+-------------------------------------------------------------+
| 동일 실리콘 다이 면적 예산 (Area Budget = 4A)              |
|                                                             |
| [전략 A: 단일 대형 코어]          [전략 B: 다중 소형 코어]  |
| +-------------------------+     +------------+------------+ |
| |                         |     |  소형코어1 |  소형코어2 | |
| |      단일 대형 코어     |     +------------+------------+ |
| |    (비순서 실행 엔진)   |     |  소형코어3 |  소형코어4 | |
| |                         |     +------------+------------+ |
| +-------------------------+     |     온칩 인터커넥트     | |
| |        사설 캐시        |     +-------------------------+ |
| +-------------------------+     |        공유 LLC         | |
| (단일 스레드 지연 최소화)       +-------------------------+ |
|                                 (총 병렬 처리량 극대화)     |
+-------------------------------------------------------------+
```

선의 의미: 동일 다이 면적 예산(4A) 내 단일 대형 코어(지연 중심)와 다중 소형 코어(처리량 중심)의 공간 배치 및 공유 자원 구조

| 구성요소 | 책임 |
|:---|:---|
| 단일 대형 코어 | **비순서 실행** 자원 집중으로 단일 스레드 지연 최소화 |
| 다중 소형 코어 | 경량 파이프라인 다중화로 면적당 **총 병렬 처리량** 극대화 |
| 공유 LLC | 코어 간 데이터 공유 및 **DRAM 접근 지연** 완충 |
| 온칩 인터커넥트 | 다중 코어와 캐시 간 **고속 패킷 전송** 및 트래픽 중재 |

#### 한줄 요약

- 동일 실리콘 면적에서 단일 대형 코어는 **지연 단축**, 다중 소형 코어는 **병렬 처리량 2배 달성**.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **암달의 법칙(Amdahl's Law)**: 시스템 가속비가 프로그램 내에 존재하는 불가피한 순차 처리 구간 비율에 의해 제약을 받는다는 성능 법칙.
- **다크 실리콘(Dark Silicon)**: 열 설계 전력(TDP)과 방열 한계로 인해 칩 내의 모든 트랜지스터를 동시에 최대 클록으로 켤 수 없는 실리콘 영역.
- **가속비(Speedup)**: 단일 코어 기준 처리 시간 대비 코어 증설 시 달성되는 상대적 성능 향상 비율.

</details>

```text
워크로드 특성 분석 (순차 비율 s, 병렬 비율 1-s)
                      |
                      v
          1. 단일 코어 확장 한계 분석
        (면적 4A 투입 시 단일 성능 2P 포화)
                      |
                      v
          2. 암달의 법칙 병렬 확장성 평가
     (직렬 구간 s 병목 및 병렬 구간 처리량 산출)
                      |
                      v
          3. 전력 밀도 및 발열 한계 검증
        (다크 실리콘 및 열 설계 전력 TDP 검토)
                      |
                      v
          4. 최적 아키텍처 구성 확정
+---------------------+---------------------+
|                     |                     |
v                     v                     v
순차 위주 워크로드   병렬 위주 워크로드   복합 워크로드
[대형 코어 중심]     [소형 코어 분산]     [이종 멀티코어]
```

### 동작 원리

1. **단일 코어 확장 한계 분석**: 폴락의 법칙으로 코어 대형화 시 면적당 성능 수익 체감 확인
2. **암달의 법칙 병렬 확장성 평가**: 워크로드의 순차·병렬 비율 기반 코어 증설 가속비 산정
3. **전력 밀도 및 발열 한계 검증**: 코어 밀집에 따른 전력 장벽과 다크 실리콘 제약 검토
4. **최적 아키텍처 구성 확정**: 워크로드 요구에 맞춰 대형·소형 또는 이종 코어 구성 결정

#### 한줄 요약

- 폴락의 한계 분석과 **암달의 가속비 평가**를 거쳐 워크로드별 **최적 코어 아키텍처 결정**.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **순차 임계경로(Sequential Critical Path)**: 병렬화가 불가능하여 단일 코어의 연산 속도가 전체 응답 시간을 결정하는 실행 구간.
- **스레드 전환 오버헤드(Thread Migration Overhead)**: 워크로드 부하 변동 시 Big 코어와 LITTLE 코어 간에 스레드를 이전하면서 발생하는 캐시 미스와 스케줄링 비용.
- **전력 밀도(Power Density)**: 단위 면적당 소모되는 전력량으로, 대형 코어에 집적도가 집중될 때 발열 핫스팟을 유발하는 지표.

</details>

| 코어 구성 전략 | 단일 대형 코어 | 다중 소형 코어 | 이종 멀티코어 (big.LITTLE) |
|:---|:---|:---|:---|
| 적용 기준 | **순차 임계경로** 지연 단축 요구 | **병렬 처리량** 극대화 요구 | 순차 지연과 병렬 전력 효율 동시 요구 |
| 핵심 특징 | 면적 4배로 단일 성능 2배 달성하는 **하위 선형 반환** | 동일 면적에 4개 코어로 **병렬 처리량 4배** 달성 | 순차 구간은 대형 코어, 병렬 구간은 소형 코어 분합 |
| 한계 | 면적 대비 성능 효율 저하 및 높은 **전력 밀도** | 순차 처리 구간의 **단일 스레드 지연** 단축 불가 | 코어 간 **스레드 전환 오버헤드** 및 스케줄러 복잡성 |

> 요약: 단일 스레드 지연 단축은 대형 코어, 병렬 처리량 극대화는 소형 코어, 지연과 전력 효율의 동시 달성은 **이종 멀티코어**를 선택.

#### 한줄 요약

- 순차 지연은 대형 코어, 병렬 처리량은 소형 코어, 복합 환경은 **이종 멀티코어로 한계 극복**.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **파워 게이팅(Power Gating)**: 유휴 상태인 코어나 연산 유닛의 전원 공급을 완전히 차단하여 누설 전력 소모를 방지하는 저전력 기술.
- **동적 전압 주파수 조절(Dynamic Voltage and Frequency Scaling, DVFS)**: 워크로드 요구량에 맞추어 프로세서의 동작 전압과 클록 주파수를 동적으로 낮춰 전력과 발열을 제어하는 기술.
- **대역폭 포화(Bandwidth Saturation)**: 다수의 소형 코어가 동시에 메인 메모리를 요청할 때 버스 전송 용량 한계에 도달하여 지연이 급증하는 현상.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 코어 대형화 시 면적당 성능 **수익 체감** 및 전력 낭비 | 대형 코어와 소형 코어를 결합한 **이종 멀티코어** 도입 | 순차 지연 단축과 병렬 에너지 효율 동시 확보 |
| 소형 코어 다수 집적 시 **다크 실리콘** 및 발열 한계 | 미사용 코어 **파워 게이팅** 및 코어별 **동적 전압 주파수 조절(DVFS)** 적용 | 열 설계 전력(TDP) 내 전력 밀도 억제 및 안정성 보장 |
| 다중 코어 동시 메모리 접근으로 인한 **대역폭 포화** | 분산 온칩 네트워크(NoC) 구축 및 대용량 **공유 LLC** 계층화 | 코어 간 버스 경합 완화 및 메모리 지연 단축 |

#### 한줄 요약

- **이종 멀티코어·파워 게이팅**과 **공유 LLC 확충**으로 수익 체감과 발열 병목 해결.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **이종 코어 자원 최적화(Heterogeneous Core Resource Optimization)**: 폴락의 법칙에 따른 단일 코어 한계와 암달의 법칙에 따른 병렬 한계를 동시에 고려하여 실리콘 면적 내에 대형 코어와 소형 코어를 최적 비율로 배분하는 아키텍처 결정.

</details>

- 순차 지연용 대형 코어와 병렬 처리용 소형 코어를 결합하는 **이종 코어 자원 최적화** 채택

#### 한줄 요약

- 폴락의 법칙 한계를 극복하기 위해 대형·소형 코어를 혼합 배치하는 **이종 아키텍처로 진화**.
