## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **폴락의 법칙(Pollack's Rule)**: 동일 반도체 공정에서 프로세서 코어 복잡도(다이 면적 및 트랜지스터 수)를 $n$배 증가시킬 때 단일 스레드 성능 향상은 제곱근인 $\sqrt{n}$배에 그친다는 경험 법칙.
- **하위 선형적 반환(Sublinear Returns)**: 자원을 $n$배 투입해도 성능이 $n$배로 선형 증가하지 않고 대략 제곱근($\approx \sqrt{n}$) 수준으로 둔화되어 반환되는 현상.
- **수익 체감(Diminishing Returns)**: 코어 면적과 트랜지스터를 추가 투입할수록 단위 자원당 얻어지는 성능 향상 폭이 점차 감소하는 현상.
- **제곱근 비례(Square-Root Proportionality)**: 코어 복잡도 비율과 단일 스레드 성능 향상비 간의 제곱근($P \propto \sqrt{C}$) 관계.

</details>

- 정의/개념: 동일 공정에서 코어 복잡도를 $n$배 늘릴 때 단일 스레드 성능은 $\sqrt{n}$배 향상되는 **폴락의 법칙**
- 배경/필요성: 단일 코어 대형화 시 **하위 선형적 반환**에 따른 **수익 체감**으로 멀티코어 전환 필요성 대두

#### 한줄 요약

- 코어 복잡도를 $n$배 늘려도 성능 향상은 $\sqrt{n}$배에 그치는 **하위 선형적 반환** 법칙.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **코어 복잡도(Core Complexity, C)**: 트랜지스터 집적도, 파이프라인 깊이, 비순서 실행 윈도우 등 코어 회로의 물리적 규모와 실리콘 다이 면적.
- **단일 스레드 성능(Single-Thread Performance, P)**: 단일 프로세서 코어가 단일 명령어 실행 흐름을 처리하는 연산 속도.
- **정규화 지표(Normalized Metric)**: 기준 코어의 면적 $C_0$과 성능 $P_0$을 1.0으로 설정해 상대적 변화율을 비교하는 척도.
- **제곱근 관계식(Square-Root Formula)**: 코어 복잡도 비율과 성능 비율 간의 수학적 비례 산식($\frac{P_1}{P_0} \approx \sqrt{\frac{C_1}{C_0}}$).

</details>

![코어 복잡도에 따른 단일 스레드 성능의 제곱근 증가 차트](/study/diagrams/pollacks-rule-growth.svg)

> **제곱근 비례**에 따라 코어 다이 면적을 4배 늘려도 단일 스레드 성능은 약 2배($\sqrt{4}=2$) 향상에 그침.

$$
\frac{P_1}{P_0} \approx \sqrt{\frac{C_1}{C_0}}
$$

| 변수 / 축 | 물리적 의미 및 해석 | 산정 전제 조건 |
|:---|:---|:---|
| $C_1/C_0$ (x축) | 기준 코어 대비 물리적 실리콘 다이 면적 및 복잡도 비율 | 동일 반도체 미세 공정 및 동일 아키텍처 세대 |
| $P_1/P_0$ (y축) | 기준 코어 대비 획득된 단일 스레드 처리 성능 비율 | 동일 벤치마크 워크로드 실측치 |

- 코어 복잡도를 4배 늘릴 때 **단일 스레드 성능** 향상은 약 2배에 그치는 **제곱근 비례** 특성
- 면적 4배 투입 대비 성능은 2배 향상에 그쳐 단위 면적당 성능 효율이 50%로 감소하는 **하위 선형적 반환**
- 단일 대형 코어와 다중 소형 코어 간 면적 대비 성능 트레이드오프 설계 기준 제공

#### 한줄 요약

- 코어 복잡도가 4배 증가할 때 성능은 2배 증가하여 **면적당 성능 효율 반감**.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **워크로드 모델(Workload Model)**: 대상 소프트웨어의 직렬 실행 비율과 응답 지연 요구 조건을 정의한 평가 기준.
- **실리콘 면적 예산(Silicon Area Budget)**: 단일 다이 칩에서 코어 연산 유닛과 캐시 배치에 할당된 총 면적 한도.
- **후보 구성기(Candidate Configurator)**: 면적 예산 내에서 대형 코어와 소형 코어의 수량 조합을 생성하는 설계 모듈.
- **운영 한계 검증기(Operating Envelope Evaluator)**: 열 설계 전력(TDP)과 메모리 대역폭 한계 내 동작 가능성을 검증하는 장치.
- **p99 지연시간(99th Percentile Latency, p99)**: 전체 요청 중 99%가 완료되는 최악 조건 응답 지연 한계 지표.

</details>

```text
프로세서 면적 설계 평가 구조
├─ 입력부: 실리콘 면적 예산 / 워크로드 모델 (p99 지연)
├─ 후보 생성부
│  ├─ 전략 A: 1 대형 코어 (면적=4, 단일 성능=2)
│  └─ 전략 B: 4 소형 코어 (면적=1x4, 병렬 처리량=4)
└─ 평가부: 열 설계 전력(TDP) / 대역폭 / 성능 검증
```

가지의 의미: 고정된 실리콘 면적 예산과 워크로드 요구를 바탕으로 코어 구성 후보를 생성하고 운영 한계를 검증하는 아키텍처 계층도.

| 구성요소 | 책임 |
|:---|:---|
| 워크로드 모델 | 순차 비율과 **p99 지연시간** 등 성능 요구사항 정의 |
| 실리콘 면적 예산 | 코어 및 캐시 배치에 할당된 전체 다이 면적 설정 |
| 후보 구성기 | 대형 코어와 소형 코어의 면적 배분 조합 생성 |
| 운영 한계 검증기 | 열 설계 전력과 메모리 대역폭 한계 내 동작 여부 검증 |

#### 한줄 요약

- 면적 예산 내에서 대형·소형 코어 후보를 구성하고 **운영 한계 검증**.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **후보 생성(Candidate Generation)**: 실리콘 면적 예산 내에서 대형 코어와 소형 코어의 배치 조합을 설계하는 단계.
- **성능 추정(Performance Estimation)**: 폴락의 법칙과 암달의 법칙을 결합해 순차 지연과 병렬 처리량을 산출하는 과정.
- **운영 상한 평가(Operating Limit Evaluation)**: 방열 한계와 온칩 인터커넥트 대역폭 병목을 평가하는 절차.
- **열 설계 전력(Thermal Design Power, TDP)**: 프로세서가 정상 작동 시 방출하는 최대 열량으로 냉각 장치 설계 기준 전력.
- **설계 확정(Design Confirmation)**: 요구 지연시간과 처리량을 동시에 만족하는 최적 코어 구성을 확정하는 단계.

</details>

```text
실리콘 면적 예산 및 워크로드 p99 요구사항 입력
                        │
                        ▼
             1. 후보 생성
          ├─ 전략 A: 대형 코어 1개 집중 (단일 스레드 지연 단축)
          └─ 전략 B: 소형 코어 4개 분산 (병렬 처리량 극대화)
                        │
                        ▼
      2. 성능 추정 (P ∝ √C)
                        │
                        ▼
           3. 운영 상한 평가 (TDP·대역폭)
                        │
       ┌────────────────┴────────────────┐
       ▼                                 ▼
 4. 설계 확정                후보 생성 재진입
```

### 동작 원리

1. **후보 생성**: 면적 예산 내 대형 코어와 소형 코어 배분 조합 수립
2. **성능 추정**: 폴락의 법칙을 적용한 단일 지연 및 병렬 처리량 예측
3. **운영 상한 평가**: 열 설계 전력과 온칩 대역폭 한계 충족 여부 검증
4. **설계 확정**: 지연과 처리량 최적화 조건을 만족하는 최종 코어 구성 결정

#### 한줄 요약

- 폴락의 법칙 기반 성능 추정과 **운영 상한 평가**를 거쳐 코어 구성 확정.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **대형 코어(Big Core)**: 넓은 다이 면적과 복잡한 비순서 실행 엔진을 투입해 단일 스레드 지연을 최소화한 고성능 코어.
- **소형 코어(Small Core)**: 단순한 파이프라인 구조를 적용해 면적 대비 병렬 처리량을 극대화한 고효율 코어.
- **순차 임계경로(Sequential Critical Path)**: 병렬화가 불가능하여 단일 코어의 빠른 연산 속도가 전체 응답시간을 결정하는 실행 구간.
- **병렬 처리량(Parallel Throughput)**: 다수의 소형 코어에 독립 작업을 분산하여 단위 시간당 처리하는 총 연산량.

</details>

| 비교 항목 | 대형 코어 집중 전략 | 소형 코어 분산 전략 |
|:---|:---|:---|
| 적용 기준 | **순차 임계경로** 지연 단축 및 p99 응답시간 최소화 | **병렬 처리량** 극대화 및 면적당 전력 효율 최적화 |
| 핵심 특징 | 면적 4배 투입 시 단일 성능 약 2배 향상되는 **수익 체감** | 동일 면적에 4개 코어 배치로 전체 병렬 처리량 4배 달성 |
| 한계 | 면적 및 전력 소모 대비 단일 성능 향상 효율 저하 | 순차 실행 구간의 응답 지연시간 단축 불가 |

> 요약: 단일 스레드 지연 단축에는 대형 코어를, 대규모 병렬 처리량 확장에는 **소형 코어 분산** 전략을 선택 적용.

#### 한줄 요약

- 순차 지연 단축은 대형 코어, 면적당 처리량 증대는 **소형 코어 분산**이 유리함.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **이종 멀티코어(Heterogeneous Multicore)**: 고성능 대형 코어와 고효율 소형 코어를 하나의 다이에 통합 배치하는 아키텍처.
- **전력 밀도(Power Density)**: 단위 면적당 소비 전력으로 국소 발열 핫스팟과 열 쓰로틀링을 유발하는 지표.
- **동적 전압 주파수 조절(Dynamic Voltage and Frequency Scaling, DVFS)**: 워크로드 부하에 따라 전압과 클록 주파수를 동적으로 제어하는 전력 관리 기술.
- **공정 보정(Process Calibration)**: 미세 공정 전환에 따른 트랜지스터 면적 및 누설 전류 변화를 모델에 재반영하는 보정 기법.
- **지속 가능 성능(Sustainable Performance)**: 발열 쓰로틀링 없이 장시간 안정적으로 유지 가능한 연산 처리 속도.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 단일 코어 대형화로 인한 면적당 **수익 체감** 심화 | 대형 코어와 소형 코어를 결합한 **이종 멀티코어** 설계 | 순차 지연 단축과 병렬 처리량 동시 확보 |
| 소형 코어 증설 시 메모리 대역폭 포화 | 메모리 채널 증설 및 대용량 공유 캐시(LLC) 확충 | 메모리 병목 해소 및 다중 코어 처리량 보장 |
| 대형 코어의 국소적 **전력 밀도** 상승 및 발열 | **동적 전압 주파수 조절(DVFS)** 및 전력 캡핑 제어 | 발열 핫스팟 차단 및 **지속 가능 성능** 유지 |

#### 한줄 요약

- **이종 멀티코어**와 DVFS 전력 제어로 면적당 성능 효율과 발열 제어 달성.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **코어 배분 기준(Core Allocation Criteria)**: 워크로드의 순차 지연 특성과 병렬 처리량 요구에 따라 대형·소형 코어 비율을 결정하는 설계 프레임워크.

</details>

- 단일 스레드 지연이 중요하면 대형 코어, 병렬 처리량이 중요하면 소형 코어를 배분하는 **코어 배분 기준** 확립

#### 한줄 요약

- 지연시간과 처리량 요구 조건에 따라 대형 코어와 소형 코어 간 **최적 배분 결정**.
