## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **폴락의 법칙(Pollack's Rule)**: 코어의 트랜지스터 수와 면적을 늘려도 성능 향상은 제곱근 배수에 그친다는 컴퓨터 아키텍처 경험 법칙이다.
- **경험 법칙(Empirical Rule)**: 수학적 이론 유도가 아닌 실제 칩 실측 데이터와 관측을 통해 정립된 공학적 법칙이다.
- **면적당 성능 효율(Performance per Area Efficiency)**: 실리콘 다이 면적 투입량 대비 달성되는 연산 성능 비율이다.

</details>

- 정의: 프로세서 면적과 트랜지스터를 늘려도 단일 스레드 성능 향상은 면적 증가율의 제곱근에 그치는 **경험 법칙**
- 배경: 단일 코어 대형화에 따른 면적당 성능 효율 저하 한계를 극복하고 멀티코어 패러다임으로 전환하기 위함

#### 한줄 요약

- 코어 면적을 대폭 늘려도 성능 향상폭은 둔화하여 면적당 효율이 반감하는 하드웨어 특성이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **단일 스레드 성능(Single-Thread Performance)**: 프로세서 코어가 단일 명령어 실행 흐름을 단위 시간당 처리하는 연산 속도이다.
- **면적당 성능(Performance per Area)**: 다이 면적 대비 달성된 연산 속도로 면적이 늘어날 때 감소하는 효율 지표이다.
- **이종 멀티코어(Heterogeneous Multicore)**: 고성능 대형 코어와 고효율 소형 코어를 혼합 탑재하여 효율을 극대화하는 아키텍처이다.

</details>

![코어 복잡도에 따른 단일 스레드 성능의 제곱근 증가 차트](/study/diagrams/pollacks-rule-growth.svg)

> 코어 면적 증가 대비 성능 향상 폭이 둔화되어 면적당 효율이 감소하는 추세.

- 면적이 늘어날 때 **단일 스레드 성능**은 면적 증가율의 제곱근 배율로 서서히 상승함.
- 단위 **면적당 성능** 효율은 코어 면적이 늘어날수록 급격히 반감되는 양상을 보임.
- 단일 코어 대형화의 성능 한계를 극복하기 위한 **이종 멀티코어** 설계 기준을 제시함.

#### 한줄 요약

- 코어 면적을 늘려도 성능은 제곱근으로 증가하므로 단위 면적당 연산 효율은 대폭 하락한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **단일 대형 코어(Monolithic Big Core)**: 넓은 면적에 비순서 실행 엔진을 집적하여 단일 스레드 지연을 최소화한 고성능 코어이다.
- **다중 소형 코어(Multiple Small Cores)**: 단순한 파이프라인을 적용한 경량 코어 다수를 배치하여 전체 처리량을 극대화한 구조이다.
- **총 병렬 처리량(Total Parallel Throughput)**: 다수의 독립된 코어가 동시에 작업을 수행하여 완결하는 총 연산량이다.
- **공유 최종 단계 캐시(Shared Last-Level Cache)**: 모든 코어가 공유하며 느린 메모리 접근 지연을 완충하는 대용량 캐시이다.
- **주기억장치 접근 지연(DRAM Access Latency)**: 프로세서가 주기억장치에 데이터를 요청하여 응답을 받을 때까지 소요되는 지연시간이다.
- **온칩 인터커넥트(On-Chip Interconnect)**: 다중 코어와 제어기 간에 데이터와 패킷을 고속으로 전달하는 칩 내부 통신망이다.
- **고속 패킷 전송(High-Speed Packet Transmission)**: 인터커넥트를 통해 코어 간 데이터를 매우 낮은 지연으로 교환하는 전송 방식이다.

</details>

```text
[ 동일 실리콘 면적 내 설계 구조 비교 ]
+-------------------------+     +-------------------------+
| [전략 A: 대형 코어 중심]|     | [전략 B: 소형 코어 분산]|
|                         |     |                         |
|      단일 대형 코어     |     | 소형코어 1 | 소형코어 2 |
|                         |     |------------+------------|
|                         |     | 소형코어 3 | 소형코어 4 |
+-------------------------+     +-------------------------+
|   지연 최소화 사설 캐시 |     |  처리량 극대화 공유 캐시|
+-------------------------+     +-------------------------+
```

| 구성요소 | 책임 |
|:---|:---|
| **단일 대형 코어** | 비순서 실행 자원 집중으로 단일 스레드 지연 시간 최소화 |
| **다중 소형 코어** | 경량 파이프라인 다중화로 면적당 **총 병렬 처리량** 극대화 |
| **공유 최종 단계 캐시** | 코어 간 데이터 공유 및 **주기억장치 접근 지연** 완충 |
| **온칩 인터커넥트** | 다중 코어와 캐시 간 **고속 패킷 전송** 및 데이터 트래픽 중재 |

#### 한줄 요약

- 단일 대형 코어는 실행 지연 단축을 책임지며 다중 소형 코어는 동일 면적 내에서 병렬 처리량을 배가시킨다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **암달의 법칙(Amdahl's Law)**: 시스템 가속비가 프로세스 내의 불가피한 순차 처리 구간 비율에 의해 제약을 받는다는 성능 법칙이다.
- **다크 실리콘(Dark Silicon)**: 열 설계 전력 한계로 인해 칩 내의 모든 트랜지스터를 동시에 가동할 수 없는 비활성 실리콘 영역이다.
- **가속비(Speedup)**: 단일 코어 기준 처리 시간 대비 멀티코어 환경에서 달성되는 상대적 성능 향상 비율이다.

</details>

```text
[ 워크로드 특성 분석 ]
         │
         ▼
[ 1. 단일 코어 확장 한계 분석 ]
         │
         ▼
[ 2. 병렬 확장성 평가 ]
         │
         ▼
[ 3. 발열 한계 및 전력 검증 ]
         │
         ▼
[ 4. 최적 아키텍처 구성 확정 ]
```

### 동작 원리

1. 한계 분석: 법칙을 적용하여 코어 대형화 시 발생하는 면적당 성능 효율 저하를 확인함.
2. 병렬 확장성 평가: 워크로드의 순차 및 병렬 비율을 기반으로 코어 증설에 따른 **가속비**를 산정함.
3. 발열 한계 검증: 코어 밀집 시 발생하는 전력 장벽과 **다크 실리콘** 제약을 검토함.
4. 아키텍처 확정: 시스템의 요구 사항에 맞추어 대형, 소형, 혹은 이종 코어 구성을 결정함.

#### 한줄 요약

- 코어 확장 한계와 병렬성 한계를 평가하고 전력 장벽을 검증하여 대상 시스템의 최적 아키텍처를 도출한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **순차 실행 구간(Serial Portion)**: 병렬화가 불가능한 직렬 코드로 코어 수를 증가시켜도 지연이 단축되지 않아 가속비를 한정하는 구간이다.
- **스레드 전환 오버헤드(Thread Migration Overhead)**: 이종 코어 간에 스레드를 이전하면서 발생하는 캐시 미스 및 운영체제 스케줄링 비용이다.
- **전력 밀도(Power Density)**: 단위 면적당 소모되는 전력량으로 대형 코어 집적 시 발열 문제를 유발하는 지표이다.

</details>

| 비교 항목 | 단일 대형 코어 | 다중 소형 코어 | 이종 멀티코어 |
|:---|:---|:---|:---|
| 적용 목적 | **순차 실행 구간**의 지연 시간 단축 최우선 | 전체 시스템의 병렬 처리량 극대화 최우선 | 순차 지연 단축과 병렬 전력 효율을 동시에 요구 |
| 설계 특징 | 비순서 실행 엔진 확장을 통한 최고 단일 성능 제공 | 단일 코어 성능을 희생하고 동일 면적 내 코어 수 증대 | 처리 요구에 맞춰 대형 및 소형 코어를 유연하게 배분 |
| 주요 한계 | 면적 효율 급감 및 극심한 **전력 밀도** 상승 | 순차 처리 구간에 대한 단일 스레드 지연 단축 불가능 | 이종 구조에 따른 **스레드 전환 오버헤드** 및 스케줄링 난해 |

#### 한줄 요약

- 순차 지연 단축에는 대형 코어, 처리량 극대화에는 소형 코어가 유리하며, 이종 코어는 두 목표를 모두 절충한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **파워 게이팅(Power Gating)**: 유휴 코어의 전원 공급을 완전히 차단하여 대기 전력 소모를 방지하는 저전력 제어 기술이다.
- **동적 전압 주파수 조절(Dynamic Voltage and Frequency Scaling)**: 부하량에 맞추어 동작 전압과 클록 주파수를 동적으로 낮춰 발열을 억제하는 기술이다.
- **대역폭 포화(Bandwidth Saturation)**: 다수의 코어가 메인 메모리에 동시 접근할 때 버스 전송 용량 한계에 도달하여 지연이 급증하는 현상이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 코어 대형화로 면적당 성능 효율이 급감하고 전력 낭비 심화 | 대형 코어와 소형 코어를 결합한 **이종 멀티코어** 아키텍처 도입 | 순차 지연 단축과 병렬 연산 효율을 동시에 달성 |
| 다수 코어 집적 시 극심한 발열과 물리적 전력 한계 돌파 | 유휴 코어 **파워 게이팅** 및 코어별 **동적 전압 주파수 조절** 적용 | 물리적 발열 제약 내에서 전력 밀도 억제 및 안정성 보장 |
| 코어 동시 메모리 접근으로 인한 병목 및 **대역폭 포화** 발생 | 분산 온칩 네트워크 도입 및 대용량 공유 최종 단계 캐시 확충 | 코어 간 데이터 경합을 완화하고 메모리 접근 지연 시간 단축 |

#### 한줄 요약

- 이종 아키텍처 도입, 파워 게이팅 전력 제어, 대용량 공유 캐시 구성을 통해 면적 효율 감소와 발열 병목을 동시에 해결한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **이종 코어 자원 최적화(Heterogeneous Core Resource Optimization)**: 폴락의 법칙 한계와 암달의 법칙 병렬 한계를 동시에 고려하여 대형 소형 코어 비율을 배분하는 아키텍처 설계이다.

</details>

- 단일 코어의 성능 한계와 전력 제약에 대응하기 위해 **이종 코어 자원 최적화** 전략을 적극 도입함

#### 한줄 요약

- 코어 면적과 전력 소모의 한계를 극복하기 위해 대형 소형 코어를 작업 부하에 맞게 배치하는 이종 아키텍처로 진화하고 있다.
