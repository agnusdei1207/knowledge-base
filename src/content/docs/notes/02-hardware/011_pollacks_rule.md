## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **폴락의 법칙(Pollack's Rule)**: 마이크로프로세서의 다이 면적과 트랜지스터 수를 2배 늘려도 성능 향상은 면적 증가율의 제곱근($\sqrt{2} \approx 1.4\text{배}$)에 그친다는 경험 법칙이다.
- **면적당 성능 효율(Performance per Area)**: 실리콘 다이 면적 투입량 대비 달성되는 단일 스레드의 연산 성능 비율이다.

</details>

- 정의/개념: 프로세서 면적과 트랜지스터를 2배 늘려도 단일 스레드 성능 향상은 면적 증가율의 제곱근($\approx 1.4\text{배}$)에 그친다는 경험 법칙
- 배경/필요성: 단일 코어 대형화에 따른 면적당 성능 효율 급감과 전력/발열 장벽을 극복하고 **멀티코어/이종 아키텍처로의 전환 근거 제공**

#### 한줄 요약

- 코어 면적 증가 대비 성능 향상은 **제곱근($\text{Performance} \propto \sqrt{\text{Area}}$)**에 수렴.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **다크 실리콘(Dark Silicon)**: 열 설계 전력(TDP) 한계로 인해 칩 내의 모든 트랜지스터를 동시에 최대 주파수로 가동할 수 없는 미가동 실리콘 영역이다.
- **이종 멀티코어(Heterogeneous Multicore)**: 고성능 빅코어와 고효율 리틀코어를 단일 칩에 혼합 탑재하여 에너지 효율과 성능을 동시에 확보하는 구조이다.

</details>

- 코어 면적 $2\text{배}$ 증가 시 **단일 스레드 성능은 약 $1.4\text{배}(\sqrt{2})$** 향상에 불과
- 코어 대형화 시 단위 면적당 성능 및 전력 효율의 급격한 반감 현상 발생
- 대형 단일 코어 대신 다중 소형 코어 및 **이종 멀티코어(big.LITTLE)** 도입의 이론적 배경

#### 한줄 요약

- 면적 대비 성능 증가 둔화로 **단위 면적당 연산 효율 급감**.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **Big Core vs Small Core**: 넓은 면적에 비순차 실행 엔진을 탑재한 대형 코어와 단순 순차 파이프라인으로 면적을 절약한 소형 코어이다.

</details>

```text
[ 동일 실리콘 면적 내 설계 구조 비교 ]
+-------------------------+     +-------------------------+
| [전략 A: 대형 코어 중심]|     | [전략 B: 소형 코어 분산]|
|                         |     |                         |
|      단일 대형 코어     |     | 소형코어 1 | 소형코어 2 |
|       (성능 1.4배)      |     |------------+------------|
|                         |     | 소형코어 3 | 소형코어 4 |
+-------------------------+     +-------------------------+
|   지연 최소화 사설 캐시 |     |  처리량 극대화 공유 캐시|
+-------------------------+     +-------------------------+
```

선의 의미: 동일한 실리콘 면적 내에서 단일 대형 코어(지연 단축)와 다중 소형 코어(처리량 극대화) 간의 설계 전략 비교.

| 구성요소 | 책임 |
|:---|:---|
| 단일 대형 코어 | 비순서 실행 자원 집중으로 단일 스레드 지연 시간 최소화 |
| 다중 소형 코어 | 경량 파이프라인 다중화로 면적당 **총 병렬 처리량** 극대화 |
| 공유 최종 단계 캐시 | 코어 간 데이터 공유 및 **주기억장치 접근 지연** 완충 |
| 온칩 인터커넥트 | 다중 코어와 캐시 간 **고속 패킷 전송** 및 데이터 트래픽 중재 |

#### 한줄 요약

- **단일 대형 코어(지연 최소화)** vs **다중 소형 코어(처리량 극대화)** 설계 비교.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **암달의 법칙 결합**: 순차 구간은 대형 코어에 할당하고 병렬 구간은 다중 소형 코어에 분산하는 비대칭 멀티코어 가속 모델이다.

</details>

```text
[ 워크로드 특성 분석 (순차 vs 병렬 비율) ]
                   │
                   ▼
[ 1. 단일 코어 확장 한계 분석 (폴락의 법칙 적용) ]
                   │
                   ▼
[ 2. 병렬 확장성 평가 (암달의 법칙 가속비 산정) ]
                   │
                   ▼
[ 3. 열 설계 전력(TDP) 및 다크 실리콘 검증 ]
                   │
                   ▼
[ 4. 최적 아키텍처(대형/소형/이종 코어) 구성 확정 ]
```

**동작 원리**

1. **한계 분석**: 폴락의 법칙을 적용하여 코어 대형화 시 발생하는 면적당 성능 효율 저하 및 전력 밀도 산출
2. **병렬 확장성 평가**: 워크로드의 순차 코드 비율을 분석하여 코어 증설에 따른 최대 가속비 계산
3. **발열 한계 검증**: 코어 밀집 시 발생하는 전력 장벽(Power Wall)과 다크 실리콘 제약 검토
4. **아키텍처 확정**: 워크로드 요구사항에 맞춰 단일 대형, 다중 소형, 또는 이종 멀티코어 비율 결정

#### 한줄 요약

- 워크로드의 순차/병렬 비율과 **폴락·암달 법칙** 기반 최적 코어 구조 도출.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **순차 실행 구간 vs 병렬 실행 구간**: 순차 코드는 대형 코어 클록에 종속되며, 병렬 코드는 다중 소형 코어의 총 스루풋에 종속된다.

</details>

| 아키텍처 분류 | 단일 대형 코어 (Big Core) | 다중 소형 코어 (Many Small Cores) | 이종 멀티코어 (big.LITTLE) |
|:---|:---|:---|:---|
| 적용 기준 | 순차 실행 구간의 극단적 지연시간 단축 요구 시 | 대규모 독립 병렬 작업 및 처리량(Throughput) 극대화 시 | 순차 지연 단축과 병렬 에너지 효율 동시 요구 시 |
| 핵심 특징 | 대규모 비순차 실행 엔진, 넓은 이슈 폭, 최고 IPC | 단순 순차 파이프라인, 작은 면적, 코어 수 극대화 | 빅코어(순차 가속) + 리틀코어(병렬/대기 전력 절감) |
| 한계 및 위험 | 폴락의 법칙에 따른 면적당 성능 효율 및 전력 밀도 악화 | 순차 코드 구간에서 심각한 단일 스레드 지연 발생 | OS 스케줄러 복잡도 및 코어 마이그레이션 오버헤드 |

#### 한줄 요약

- 순차 지연은 **대형 코어**, 처리량은 **소형 코어**, 균형은 **이종 코어** 선택.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **파워 게이팅(Power Gating)**: 유휴 상태의 대형 코어 전원을 완전히 차단하여 대기 누설 전류를 0으로 만드는 전력 절감 기법이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 코어 대형화로 면적당 성능 효율이 급감하고 전력 낭비 심화 | 대형 코어와 소형 코어를 결합한 **이종 멀티코어** 아키텍처 도입 | 순차 지연 단축과 병렬 연산 효율을 동시에 달성 |
| 다수 코어 집적 시 극심한 발열과 물리적 전력 한계 돌파 | 유휴 코어 **파워 게이팅** 및 코어별 **동적 전압 주파수 조절** 적용 | 물리적 발열 제약 내에서 전력 밀도 억제 및 안정성 보장 |
| 코어 동시 메모리 접근으로 인한 병목 및 **대역폭 포화** 발생 | 분산 온칩 네트워크 도입 및 대용량 공유 최종 단계 캐시 확충 | 코어 간 데이터 경합을 완화하고 메모리 접근 지연 시간 단축 |

#### 한줄 요약

- **이종 아키텍처·파워 게이팅·대용량 LLC**로 효율 감소와 전력 장벽 돌파.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **도메인 특화 아키텍처(DSA)**: 범용 코어 대형화의 한계를 극복하기 위해 특정 알고리즘(AI/그래픽)을 직접 하드웨어로 가속하는 NPU/GPU 결합 구조이다.

</details>

- 폴락의 법칙(면적 한계)과 암달의 법칙(병렬 한계)을 결합한 **동적 이종 코어 최적화 설계**

#### 한줄 요약

- **면적과 전력 효율 극대화**를 위한 이종 멀티코어 및 가속기 결합 설계.
