## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **폴락의 법칙(Pollack's Rule)**: 프로세서 코어의 복잡도 또는 면적이 커져도 단일 스레드 성능은 그보다 완만하게 증가한다는 경험적 관찰입니다.
- **면적당 성능(Performance per Area)**: 실리콘 면적을 투입해 얻는 성능의 효율입니다.
- **단일 스레드 성능(Single-Thread Performance)**: 하나의 실행 흐름이 완료하는 작업 속도입니다.

</details>

- 정의/개념: 코어 대형화에 따른 성능 증가가 둔화되는 **면적 효율 관찰**
- 배경/필요성: 대형 코어, 다수 코어, 가속기 간 실리콘 예산 배분 판단

#### 한줄 요약

- 코어를 크게 만들면 빨라지지만, 같은 면적을 쓴 만큼 성능이 비례해 늘지는 않으므로 다른 배분 방법과 비교해야 합니다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **비순차 실행(Out-of-Order Execution)**: 준비된 명령어를 프로그램 순서보다 먼저 실행해 대기를 줄이는 기법입니다.
- **다크 실리콘(Dark Silicon)**: 전력과 열 제약으로 칩의 모든 회로를 동시에 최대 성능으로 켤 수 없는 상태입니다.
- **처리량(Throughput)**: 단위 시간에 완료하는 작업량입니다.

</details>

- 넓은 실행 자원에 따른 **단일 스레드 성능 둔화**
- 대형화와 함께 커지는 **면적·전력·검증 비용**
- 남은 예산을 다수 코어·가속기에 배분하는 **처리량 대안**

#### 한줄 요약

- 코어를 복잡하게 만들수록 기다림을 줄이는 기능은 늘지만, 그 기능 하나를 추가하는 비용은 더 빠르게 커질 수 있습니다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **대형 코어(Big Core)**: 넓은 실행 자원과 캐시로 높은 단일 스레드 성능을 목표로 하는 코어입니다.
- **소형 코어(Small Core)**: 면적과 전력 효율을 우선해 비교적 단순한 실행 자원을 갖는 코어입니다.
- **도메인 특화 가속기(Domain-Specific Accelerator, DSA)**: 특정 연산을 높은 성능과 에너지 효율로 처리하도록 설계한 하드웨어입니다.
- **실리콘 예산(Silicon Budget)**: 칩에서 면적, 전력, 열 한도로 배분할 수 있는 설계 자원입니다.

</details>

```text
[실리콘 예산]
├─ 대형 코어
├─ 소형 코어 군
├─ 공유 캐시·인터커넥트
└─ DSA
```

| 구성요소 | 책임 |
|:---|:---|
| 대형 코어 | 순차 작업의 낮은 지연 제공 |
| 소형 코어 군 | 독립 작업의 높은 처리량 제공 |
| 공유 캐시·인터커넥트 | 데이터 공급과 공유 요청 처리 |
| DSA | 규칙적 특화 연산의 효율적 처리 |

#### 한줄 요약

- 폴락의 법칙은 코어를 크게 만들지 말라는 규칙이 아니라, 한정된 칩 자원을 어떤 실행 방식에 나눌지 묻는 기준입니다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **가속비(Speedup)**: 기준 실행 시간과 개선 후 실행 시간의 비율입니다.
- **열 설계 전력(Thermal Design Power, TDP)**: 냉각 설계가 지속적으로 감당해야 하는 열·전력 수준의 지표입니다.

</details>

```text
[1. 워크로드 측정]
          │
          ▼
[2. 순차·병렬 구간 분석]
          │
          ▼
[3. 면적·전력 예산 설정]
          │
          ▼
[4. 코어·가속기 구성 선택]
```

동작 원리:

1. 워크로드 측정: 단일 지연, 병렬 비율, 데이터 대기 확인
2. 순차·병렬 구간 분석: 대형 코어와 다수 코어의 가속비 비교
3. 면적·전력 예산 설정: TDP와 메모리 공급 제약 반영
4. 코어·가속기 구성 선택: 성능·에너지 효율이 높은 자원 조합 확정

#### 한줄 요약

- 먼저 프로그램이 혼자 순서대로 하는 일과 여럿이 나눌 수 있는 일을 재고, 그 결과에 맞춰 비싼 대형 코어와 효율적인 병렬 자원을 나눕니다.

## Ⅴ. 종류 및 비교

| 설계 방식 | 대형 코어 중심 | 소형 코어 중심 | DSA 중심 |
|:---|:---|:---|:---|
| 적용 기준 | 순차 지연이 핵심 병목 | 독립 작업의 처리량 우선 | 반복적·규칙적 연산 우세 |
| 핵심 특징 | 넓은 발행과 큰 캐시 | 높은 코어 수와 에너지 효율 | 알고리즘 특화 데이터 경로 |
| 한계 | 면적·전력·설계 복잡도 증가 | 직렬 구간과 메모리 병목 | 범용성·개발·데이터 이동 제약 |

#### 한줄 요약

- 하나의 일이 느리면 대형 코어, 많은 독립 일이 있으면 소형 코어, 같은 계산이 반복되면 가속기를 선택하는 방향입니다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **파워 게이팅(Power Gating)**: 유휴 회로의 전원 공급을 줄이거나 차단해 누설 전력을 낮추는 기법입니다.
- **동적 전압·주파수 조절(Dynamic Voltage and Frequency Scaling, DVFS)**: 부하와 온도에 맞춰 전압과 주파수를 조절하는 전력 관리 기법입니다.
- **온칩 네트워크(Network on Chip, NoC)**: 칩 내부 구성요소 사이에 데이터와 요청을 전달하는 통신 구조입니다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 대형 코어 확대가 면적·전력 예산 초과 | 소형 코어·DSA와 성능당 전력 비교 | 작업별 자원 배분 효율 향상 |
| 동시 활성 회로 증가로 과열 발생 | 파워 게이팅과 DVFS 정책 적용 | 누설 전력과 열 위험 감소 |
| 다수 코어의 메모리 요청 집중 | 캐시·NoC·메모리 채널 병목 측정 | 데이터 공급 경합 완화 |
| 이종 자원에 맞지 않는 작업 배치 | 지연·처리량·에너지 기준 스케줄링 | 마이그레이션과 유휴 자원 감소 |

#### 한줄 요약

- 실리콘 예산을 잘 나눠도 전력과 데이터 이동이 받쳐 주지 않으면 성능이 나오지 않으므로, 실제 작업 기준의 측정과 전력 제어가 필요합니다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **에너지 효율(Energy Efficiency)**: 일정한 에너지로 처리할 수 있는 작업량 또는 작업당 에너지 소비의 효율입니다.

</details>

- 단일 스레드 지연 이득이 **면적당 성능**·**에너지 효율** 저하보다 크면 대형 코어를 확대하고, 그렇지 않으면 병렬 코어·DSA로 실리콘 예산 재배분

#### 한줄 요약

- 폴락의 법칙은 코어 대형화의 수익성을 따져 보고, 같은 칩 면적을 더 많은 코어 또는 특화 하드웨어에 쓸지 결정하게 하는 설계 기준입니다.
