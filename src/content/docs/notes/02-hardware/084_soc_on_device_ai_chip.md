## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **온디바이스 AI(On-Device AI)**: 클라우드 서버와의 통신 없이 스마트폰, 로봇, 차량 등 단말기 자체 하드웨어에서 딥러닝 추론을 독립 실행하는 기술.
- **NPU(Neural Processing Unit)**: 딥러닝 인공신경망의 다차원 텐서 행렬 곱셈(MAC)과 활성화 함수 처리에 특화된 전용 하드웨어 가속기.

</details>

- 정의/개념: 단말 내부에서 클라우드 통신 없이 딥러닝 추론을 독자 실행하기 위해 CPU, GPU, **전용 NPU 코어와 온칩 SRAM**을 집적한 저전력 임베디드 AI 가속 반도체
- 배경/필요성: 클라우드 서버 통신에 따른 **네트워크 전송 지연, 통신 비용 급증 및 민감 개인정보 유출 위험** 직면

#### 한줄 요약
- 스마트폰이나 자동차 안에서 인터넷 연결 없이도 인공지능을 초고속·저전력으로 구동하는 전용 온칩 반도체다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **에너지 효율(TOPS/Watt)**: 1와트(W)의 전력 소모당 초당 처리 가능한 테라(1조 회) 연산 횟수로, 모바일 NPU 성능의 핵심 지표.
- **DVFS(Dynamic Voltage and Frequency Scaling)**: 부하량과 칩셋 발열 상태에 따라 전압과 클록 주파수를 실시간 조절해 배터리를 아끼는 제어 기술.

</details>

- 인터넷 단절 환경에서도 즉각 작동하며 외부 데이터 유출을 원천 차단하는 **프라이버시 보장**
- INT8/INT4 정수 연산 및 2D 시스톨릭 어레이 기반의 **압도적 에너지 효율(TOPS/W)**
- 팬리스(Fanless) 모바일 발열 제약(TDP)을 충족하기 위한 **DVFS 기반 지속 성능 관리**

#### 한줄 요약
- 보안과 초저지연을 보장하고, 저전력 양자화 연산과 전력 제어로 스마트폰 배터리 소모를 극소화한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **시스톨릭 어레이(Systolic Array)**: 데이터가 2차원 연산기 격자를 심장 박동처럼 규칙적으로 흘러가며 메모리 재접근 없이 행렬 곱을 누적하는 전용 아키텍처.
- **온칩 시스템 캐시(System-Level Cache, SLC)**: 외부 LPDDR DRAM 접근 시 발생하는 막대한 전력 소모를 줄이기 위해 칩 내부에 상주시키는 대용량 SRAM 버퍼.

</details>

```text
┌─────────────────────────────────────────────────────────────┐
│ 온디바이스 AI SoC 하드웨어 아키텍처 및 데이터 흐름         │
│                                                             │
│  [ 호스트 제어 프로세서 (Multi-Core CPU / GPU) ]            │
│  └──────────────────────────┬───────────────────────────────┘│
│                             │ (온칩 NoC 고속 버스)          │
│  ┌──────────────────────────▼───────────────────────────────┐│
│  │ 대용량 공유 온칩 버퍼 (Shared System Cache: 8MB~32MB)     ││
│  └──────────────────────────┬───────────────────────────────┘│
│                             │ (타일 단위 가중치/피쳐맵 스트리밍)
│  ┌──────────────────────────▼───────────────────────────────┐│
│  │ 전용 NPU 가속기 코어 (Neural Processing Unit)            ││
│  │  ├─ 2D 시스톨릭 MAC 어레이 (Tensor Engine)               ││
│  │  ├─ 벡터 활성화 & 풀링 유닛 (Activation / Pooling)       ││
│  │  └─ 전력·발열 관리 제어기 (DVFS / Thermal Throttling)    ││
│  └──────────────────────────────────────────────────────────┘│
└─────────────────────────────────────────────────────────────┘
```

선의 의미: 호스트 CPU가 작업을 스케줄링하면 온칩 공유 캐시에서 NPU 시스톨릭 어레이로 데이터를 스트리밍하여 행렬 가속

| 구성요소 | 책임 |
|:---|:---|
| 호스트 CPU/GPU | 전체 AI 파이프라인 총괄 및 NPU 미지원 특수 연산자(Non-standard Layer) 대리 실행 |
| 전용 NPU 코어 | 2D 시스톨릭 어레이를 통해 대규모 합성곱(Conv) 및 Transformer 행렬 곱셈 전담 |
| 공유 온칩 시스템 캐시 | 외부 DRAM 접근 횟수를 80% 이상 줄여 메모리 병목 해소 및 전력 절감 |
| 벡터 활성화 엔진 | ReLU, GELU, Softmax 등 비선형 활성화 함수 및 정규화(LayerNorm) 고속 처리 |
| DVFS 전력/열 제어기 | 온칩 온도 센서와 연동하여 칩셋이 허용 TDP를 초과하지 않도록 주파수 동적 조절 |

#### 한줄 요약
- 호스트 CPU/GPU, 전용 NPU 코어, 온칩 대용량 캐시, 벡터 엔진, DVFS 모듈이 저전력 고효율 SoC를 완성한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **그래프 융합(Graph Fusion)**: Conv + BatchNorm + ReLU 등 연속된 복수 연산자를 단일 융합 연산자로 합쳐 메모리 왕복을 없애는 컴파일러 최적화.

</details>

```text
딥러닝 모델 배포 요청 (ONNX / TensorFlow Lite)
      │
      ▼
1. 모델 컴파일: INT8/INT4 정수 양자화 및 연산자 그래프 융합(Graph Fusion)
      │
      ▼
2. 텐서 타일링: 거대 가중치를 온칩 SRAM 용량에 맞게 타일(Tile) 단위로 분할 적재
      │
      ▼
3. 연산자 분기 실행: 표준 행렬 연산은 NPU로, 미지원 특수 연산자는 CPU/GPU(Fallback)로 디스패치
      │
      ▼
4. 시스톨릭 가속: NPU 2D MAC 격자에서 클록당 수천 회의 행렬 곱셈 누적 실행
      │
      ▼
5. DVFS 발열 제어 및 최종 추론 결과 호스트 앱 반환
```

**동작 원리**

1. **사전 컴파일**: 훈련된 부동소수점(FP32) 모델을 양자화하고 메모리 접근을 줄이도록 연산자 융합
2. **타일 적재**: 온칩 캐시 용량 한계에 맞춰 가중치와 피쳐맵을 작은 타일 블록으로 쪼개어 SRAM에 로드
3. **지능형 분기**: NPU가 직접 가속 가능한 레이어와 그렇지 않은 레이어를 판별해 최적의 이종 코어로 분배
4. **고속 행렬 연산**: NPU 내부 PE들이 데이터를 옆으로 넘겨주며 DRAM 접근 없이 행렬 연산 완수
5. **결과 반환**: 발열 한계선 내에서 안정적인 지속 처리량(Sustained TOPS)을 유지하며 추론값 출력

#### 한줄 요약
- 양자화 컴파일 → 텐서 타일링 → 연산자 분기 → 시스톨릭 가속 → 발열 제어 및 결과 반환 순으로 동작한다.

## Ⅴ. 종류 및 비교

| AI 연산 플랫폼 | 온디바이스 AI SoC (NPU) | 클라우드 서버 GPU | 엣지 전용 DSP/MCU | 온디바이스 FPGA |
|:---|:---|:---|:---|:---|
| 적용 기준 | 스마트폰, 태블릿, 자율주행 ADAS | 데이터센터 초거대 생성형 LLM 학습/추론 | 스마트 워치, 초소형 초저전력 IoT 센서 | 실시간 산업용 비전 및 통신 프로토콜 가속 |
| 핵심 특징 | 저전력 INT8/4 행렬 특화 (수 W, 45+ TOPS) | 초대용량 HBM 및 FP16/FP8 범용 연산 (수백 W) | 초저전력(mW 단위) 및 단순 신호 처리 | 로직 재구성 가능성 및 결정론적 지연 |
| 한계 | 메모리 용량 제약(수B 소형 모델에 국한) | 막대한 서버 인프라 비용 및 통신 지연 | 복잡한 딥러닝 트랜스포머 모델 연산 불가 | 높은 칩 단가 및 복잡한 RTL 설계 난이도 |

#### 한줄 요약
- 모바일 단말은 온디바이스 SoC, 초거대 LLM은 클라우드 GPU, 초저전력 센서는 MCU, 특수 산업용은 FPGA를 쓴다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **폴백(Fallback)**: NPU 하드웨어가 지원하지 않는 최신 커스텀 레이어를 만났을 때 시스템 크래시 없이 CPU/GPU가 대신 연산하는 안전 메커니즘.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 최신 AI 모델의 미지원 연산자로 인한 **NPU 런타임 크래시 오류** | 컴파일러 레벨의 **CPU/GPU 자동 폴백(Fallback) 파이프라인** 구축 | 모델 호환성 100% 보장 및 무중단 실행 |
| 외부 LPDDR DRAM 병목으로 인한 **NPU 연산 코어 유휴(Starvation)** | **가중치 정밀도 양자화(INT8/INT4)** 및 텐서 타일링(Tiling) 기법 적용 | 메모리 대역폭 요구량 75% 절감 |
| 지속 연산 시 급격한 온도 상승으로 인한 **열 스로틀링(Throttling) 성능 급감** | **지능형 DVFS 제어** 및 이종 코어 간 워크로드 동적 분산 | 지속 실효 성능(Sustained TOPS) 안정적 유지 |
| 대규모 온디바이스 LLM 구동 시 **단말기 RAM 용량 부족** | **활성화 메모리 압축(Activation Compression)** 및 KV 캐시 양자화 | 소형 모델(3B~7B) 온디바이스 상용화 실현 |

#### 한줄 요약
- CPU 폴백으로 호환성을 살리고, 양자화/타일링으로 메모리 병목을 뚫으며, DVFS로 지속 발열을 통제한다.

## Ⅶ. 결론

- 생성형 AI 온디바이스 확산을 위해 **NPU 45+ TOPS 탑재(Copilot+ PC, 온디바이스 폰)** 와 **소형 LLM(SLM) 경량화 툴체인 구축** 필수

#### 한줄 요약
- 전력 효율(TOPS/W)과 메모리 대역폭 한계를 극복하는 전용 NPU 아키텍처를 통해 진정한 엣지 인텔리전스를 구현해야 한다.
