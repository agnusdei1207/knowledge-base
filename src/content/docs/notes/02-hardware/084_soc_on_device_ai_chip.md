## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **온디바이스 에이아이(On-Device AI)**: 클라우드(서버)에 연결 안 하고, 스마트폰이나 자동차 안에서 자체적으로 인공지능을 돌려버리는 독고다이 기술이다.
- **신경망 처리 장치(Neural Processing Unit, NPU)**: CPU나 GPU가 쩔쩔매는 딥러닝 행렬 곱셈만 밥 먹듯이 미친 속도로 갈겨버리는 인공지능 전용 깡패 칩이다.
- **시스템 온 칩(System on Chip, SoC)**: CPU, GPU, NPU에 램까지 손톱만 한 실리콘 한 조각에 몽땅 때려 박은 잡탕 반도체이다.

</details>

- 정의: 스마트폰 같은 단말기 안에서 클라우드 통신 없이 딥러닝 추론을 독고다이로 돌려버리기 위해, CPU/GPU와 전용 인공지능 가속기(**NPU**)를 실리콘 칩 하나에 다 때려 박은 **SoC AI 온디바이스 칩** 아키텍처
- 배경: 챗GPT처럼 클라우드 서버로 데이터를 보내서 처리하면 인터넷 끊길 때 기계가 먹통이 되고, 내 개인정보가 남의 서버로 넘어가는 끔찍한 사생활 침해를 멱살 잡고 차단하기 위함

#### 한줄 요약

- 폰 안에 인공지능 전용 칩(NPU)을 박아서, 인터넷 없이도 빠르고 안전하게 AI를 돌리는 기술이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **톱스(Tera Operations Per Second, TOPS)**: 칩이 1초에 계산을 무려 1조 번이나 때려 박는지 재는 무식한 전투력 측정기이다.
- **동적 전압 주파수 스케일링(Dynamic Voltage Frequency Scaling, DVFS)**: 스마트폰이 불타오르는 걸 막기 위해, 기계가 빡세게 일할 땐 전기를 쏟아붓고 쉴 땐 확 줄여서 멱살 잡고 컨트롤하는 전력 쥐어짜기 기술이다.
- **열 설계 전력(Thermal Design Power, TDP)**: 칩이 타들어 가기 직전까지 뿜어낼 수 있는 열의 최대 한계선이다.

</details>

- 인터넷이 끊겨도 작동하고, 서버로 데이터를 1바이트도 안 보내서 지연과 프라이버시 침해를 원천 차단하는 **온디바이스 에이아이** 기술의 정수임.
- 칩이 초당 연산을 몇 조 번이나 갈겨버리는지 나타내는 무식한 지표인 **톱스**(**TOPS**)로 NPU의 전투력을 과시함.
- 스마트폰 배터리가 광탈하거나 타오르는 걸 막기 위해, 연산량에 맞춰 전압과 클록을 멱살 잡고 쥐어짜는 **동적 전압 주파수 스케일링**(**DVFS**)을 혹사시킴.

#### 한줄 요약

- 인터넷 지연과 해킹을 막고, 제한된 배터리와 온도(TDP) 안에서 NPU 연산력(TOPS)을 극한으로 쥐어짠다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **시스톨릭 어레이(Systolic Array)**: 심장이 피를 뿜어내듯, 데이터를 컨베이어 벨트처럼 쫙 깔아놓고 행렬 곱셈만 무식하게 밀어붙이는 NPU 전용 노가다 아키텍처이다.
- **공유 온칩 버퍼(SRAM/SRAM Buffer)**: 칩 밖에 있는 느린 램(DDR)에 다녀오면 배터리가 박살 나니까, 데이터를 칩 내부에 꽁꽁 숨겨두고 재탕하는 초고속 캐시 창고이다.

</details>

```text
[ 오프라인 인공지능 십자포화 SoC 프레임워크 ]
 [ CPU/GPU 호스트 (잔심부름 지휘관) ] ── [ 공유 온칩 버퍼 (데이터 짱박기 창고) ] ── [ NPU 가속기 (행렬 노가다 깡패) ]
                                                            │
                                             [ 전력•열 제어기 (온도 멱살 잡기) ]
```

| 구성요소 | 책임 |
|:---|:---|
| CPU/GPU 호스트 | NPU가 멍청하게 못 돌리는 괴상한 인공지능 수식(레이어)을 대신 짬처리하고 잔심부름을 도맡는 메인 지휘관 |
| NPU 가속기 | 심장 박동처럼 데이터를 밀어내는 **시스톨릭 어레이**로 딥러닝 행렬 곱셈만 미친 듯이 갈겨버리는 단순 무식한 괴물 연산기 |
| **공유 온칩 버퍼** | 칩 밖에 있는 느린 램(DDR)까지 다녀오면 배터리가 박살 나니까, 데이터(가중치)를 칩 내부에 꽁꽁 숨겨두고 재탕하는 초고속 캐시 창고 |
| 전력·열 제어 | NPU가 폭주해서 스마트폰이 녹아내리지 않게 멱살을 잡고 전압과 온도 한계선(**TDP**)을 억제하는 안전장치 |

#### 한줄 요약

- CPU가 지휘하고, NPU가 노가다 뛰며, 버퍼에 데이터를 숨겨두고, 전력 제어기가 온도를 잡는 한 칩(SoC) 구조이다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **양자화(Quantization)**: 폰에 안 들어가는 무거운 AI 모델을, 소수점을 다 정수로 쳐내서 반의반 토막으로 뼈를 깎는 다이어트 기술이다.
- **그래프 융합(Graph Fusion)**: 수식 A 하고 B 하는 걸, 아예 "AB 해라" 하고 하나로 합쳐서 쓸데없는 메모리 낭비를 줄이는 꼼수이다.

</details>

```text
[ 오프라인 딥러닝 추론 십자포화 분산 및 발열 억제 흐름 ]
                                 │
                                 ▼
          [ 1. 딥러닝 다이어트: 양자화와 수식 융합으로 모델 크기 뼈 깎음 ]
                                 │
                                 ▼
             [ 2. 데이터 짱박기: 외부 램 안 거치게 온칩 버퍼에 욱여넣음 ]
                                 │
                                 ▼
         [ 3. 이기종 짬처리: 행렬은 NPU가, 듣보잡 수식은 CPU가 분산해서 계산 ]
                                 │
                 ┌───────────────┴───────────────┐
            ( NPU 담당 )                    ( CPU/GPU 짬처리 )
                 ▼                               ▼
       [ NPU 행렬 곱셈 폭격 ]             [ 폴백(Fallback) 예외 처리 ]
                 │                               │
                 └───────────────┬───────────────┘
                                 ▼
           [ 4. 온도 멱살 제어: 폰 타들어 가기 전에 클록 강제로 깎아내림 ]
```

### 동작 원리

1. 딥러닝 다이어트: 무거운 AI 모델을 스마트폰에 우겨넣기 위해 소수점을 정수로 쳐내는 **양자화**와 수식을 합치는 **그래프 융합**으로 뼈를 깎음.
2. 데이터 짱박기 계획: 외부 램(DDR)에 안 가도록 온칩 버퍼에 데이터를 어떻게 쑤셔 박을지(Tiling) 머리를 쥐어짬.
3. 이기종 노가다 분배: 행렬 곱셈은 닥치고 NPU한테 던지고, NPU가 모르는 듣보잡 수식(미지원 레이어)은 CPU나 GPU한테 짬처리 시킴.
4. 온도 멱살 제어: 연산하다가 스마트폰 온도가 폭발하기 직전이면 강제로 클록을 낮춰버려서 기계가 타들어 가는 걸 막음.

#### 한줄 요약

- 양자화로 모델을 압축하고 버퍼에 밀어 넣은 뒤, NPU와 CPU가 분담해서 계산하고 온도를 감시한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **클라우드 에이아이(Cloud AI)**: 인터넷 연결해서 저 멀리 데이터센터에 있는 수만 대의 슈퍼컴퓨터(GPU)가 대신 뇌를 굴려주는 챗GPT 같은 방식이다.

</details>

| 비교 항목 | **온디바이스 에이아이** (SoC NPU) | **클라우드 에이아이** (Data-Center GPU) |
|:---|:---|:---|
| 시스템 적용 최적 기준 | 자율주행차나 스마트폰 지문인식처럼 인터넷 끊어져도 무조건 0.1초 만에 답이 나와야 할 시 | 챗GPT처럼 파라미터가 수천억 개라 스마트폰 따위는 1초 만에 불타버리는 초거대 모델 돌릴 시 |
| 아키텍처 핵심 구현 특징 | 배터리와 발열 제한 안에서 쥐어짜 내기 위해 소형 칩(SoC) 하나에 NPU를 쑤셔 박고 뼈를 깎는 최적화 시전 | 발전소 하나를 통째로 돌리는 무식한 전력(메가와트)과 서버용 GPU 수만 대를 데이터센터에 쏟아부음 |
| 극복해야 할 태생적 한계점 | 칩이 쪼만해서 모델 크기가 10기가를 넘어가면 램이 부족해서 실행 자체가 뻗어버림 | 인터넷 끊기면 바보 되고, 내 일기장 데이터까지 통째로 서버로 날아가서 개인정보 털릴 위험 폭발 |

#### 한줄 요약

- 인터넷 끊겨도 나 혼자 굴리는 게 온디바이스고, 폰으로 감당 안 되는 초거대 모델을 원격으로 돌리는 게 클라우드다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **폴백(Fallback)**: NPU가 자기가 모르는 최신 수식을 보고 "나 안 해!" 하고 뻗으려고 할 때, 재빨리 CPU가 "내가 할게" 하고 대신 계산해 주는 구명조끼 기술이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 최신 AI 논문 수식을 NPU가 못 알아처먹어서 칩 전체가 에러 뿜고 뻗어버리는 치명적 호환성 붕괴 | NPU가 뱉어낸 찌꺼기 연산을 CPU나 GPU가 멱살 잡고 대신 계산해 주는 **폴백**(Fallback) 구명조끼 장착 | 모델이 뻗지 않고 끝까지 돌아가게 살려내는 극강의 추론 예외 처리 사수 |
| NPU 코어는 팽팽 도는데 외부 램(DDR)에서 데이터 가져오는 속도가 개판이라 NPU가 하루 종일 노는 병목 지옥 | **양자화**로 데이터 크기 반토막 내고 온칩 버퍼(SRAM)에 데이터를 꽁꽁 싸매두는 타일링(Tiling) 떡칠 | 램 대역폭 병목을 씹어먹고 NPU 연산 효율(TOPS)을 한계점까지 멱살 잡고 끌어올림 |
| AI 모델 10분 돌렸더니 스마트폰이 불타오르면서 강제로 성능을 반토막 내는 열 스로틀링(Throttling) 발동 | **DVFS**로 전압을 미친 듯이 쪼개서 조절하고 작업량을 칩 여러 개로 갈기갈기 찢어서 부하 분산 | 칩이 녹아내리지 않고 최고 성능 대신 무난한 속도로 지속 처리량을 무한 방어 |

#### 한줄 요약

- NPU가 모르는 건 폴백으로 커버하고, 양자화로 램 병목을 없애며, DVFS로 폰 타는 걸 막아라.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **온디바이스 AI 선택 기준(On-Device AI Selection Criteria)**: 이 폰이 얼마나 멍청한 모델까지 커버할 수 있는지, 배터리가 1시간 버틸지 연산력(TOPS)과 전력 밸런스를 따져보는 기준표이다.

</details>

- **온디바이스 AI 선택 기준** 원칙에 따라, 딜레이 없고 사생활 털리기 싫은 건 **온디바이스**, 폰이 뻗을 만큼 덩치가 큰 괴물 모델은 **클라우드** 채택 기조 확립함

#### 한줄 요약

- 빠르고 프라이버시가 중요하면 폰에서 돌리고, 폰이 감당 못 할 사이즈면 닥치고 클라우드에 떠넘겨라.
