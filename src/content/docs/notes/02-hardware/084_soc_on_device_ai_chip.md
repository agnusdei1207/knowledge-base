## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **On-Device AI(온디바이스 AI)**: 외부 클라우드 서버와의 데이터 송수신 없이 단말 장치(스마트폰, 차량, 로봇) 자체 하드웨어에서 인공지능 모델을 구동하는 기술.
- **NPU(Neural Processing Unit, 신경망 처리 장치)**: 심층 신경망(DNN)의 다차원 텐서(Tensor) 행렬 곱셈 및 활성화 함수 연산에 특화된 하드웨어 가속 코어.
- **SoC(System on Chip)**: CPU, GPU, NPU, ISP, DSP, 온칩 메모리 및 버스를 단일 실리콘 다이에 통합한 지능형 반도체.

</details>

- 정의/개념: 스마트폰, 모빌리티, IoT 등 엣지 단말 디바이스 내부에서 클라우드 서버와의 통신 없이 딥러닝 추론(Inference)을 독자 실행하기 위해 CPU, GPU, 전용 신경망 처리 장치(NPU) 및 온칩 SRAM을 단일 실리콘에 집적한 하드웨어 가속 SoC 아키텍처
- 배경/필요성: 클라우드 전송 지연(Latency), 네트워크 단절 위험, 통신 대역폭 비용 및 개인정보(Privacy) 유출 문제를 해결하고 **실시간 엣지 인공지능 서비스 상용화 달성**

#### 한줄 요약

- 단말 내부에서 클라우드 없이 딥러닝을 고속 처리하는 **저전력 고효율 SoC AI 온디바이스 칩 아키텍처**

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **TOPS/Watt**: 1와트(W)의 전력당 초당 수행 가능한 테라(1조 회) 연산 수량으로 엣지 NPU의 에너지 효율 척도.
- **DVFS(Dynamic Voltage and Frequency Scaling)**: NPU 연산 부하량에 따라 전압과 동작 주파수를 동적으로 조절하여 배터리 소모와 발열을 제어하는 기술.
- **Thermal Design Power(TDP)**: 모바일 단말에서 팬(Fan) 없이 섀시 방열로 감당 가능한 지속 전력 상한(보통 수 W 이내).

</details>

- 인터넷 연결 단절 시에도 오프라인으로 100% 정상 작동하며 개인 데이터를 기기 외부에 유출하지 않는 **데이터 프라이버시 보장**
- INT8/INT4 정수 연산 특화 및 대규모 병렬 MAC(Multiply-Accumulate) 유닛을 통한 **압도적인 에너지 효율(TOPS/W)**
- 모바일 배터리 한계와 팬리스(Fanless) 방열 제약 하에서 지속 성능을 유지하기 위한 **DVFS 및 열 스로틀링 통제**

#### 한줄 요약

- **초저지연·프라이버시 보장·TOPS/Watt 고효율 NPU·DVFS/TDP 기반 지속 전력 관리**

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **Systolic Array(시스톨릭 어레이)**: 데이터가 인접한 2D PE(Processing Element) 격자를 통해 리드미컬하게 흐르며 메모리 접근 없이 행렬 곱을 누적하는 전용 연산 구조.
- **On-chip SRAM Buffer**: 외부 LPDDR DRAM 접근 시 발생하는 전력 소모를 억제하기 위해 가중치(Weight)와 활성화 맵을 칩 내부에 상주시키는 고속 버퍼.

</details>

```text
[ 온디바이스 AI SoC 하드웨어 아키텍처 및 데이터 흐름 ]
┌─────────────────────────────────────────────────────────────┐
│ 1. 메인 호스트 제어 계층 (CPU 코어 + GPU 코어)              │
└──────────────────────────────┬──────────────────────────────┘
                               │ [ 고속 온칩 NoC 버스 ]
┌──────────────────────────────┴──────────────────────────────┐
│ 2. 공유 온칩 SRAM 버퍼 (Shared System Cache : 수 MB~수십 MB)│
└──────────────────────────────┬──────────────────────────────┘
                               │ [ 피쳐맵 / 가중치 타일 스트리밍 ]
┌──────────────────────────────┴──────────────────────────────┐
│ 3. NPU 코어 가속기 (Neural Processing Unit Core)             │
│  ├─ 시스톨릭 MAC 어레이 (2D Systolic Array / Tensor Engine)  │
│  ├─ 벡터 활성화 유닛 (Activation & Pooling Engine)           │
│  └─ 4. DVFS 전력 및 온도 센서 관리 모듈                     │
└─────────────────────────────────────────────────────────────┘
```

선의 의미: 호스트 프로세서(CPU/GPU), 공유 온칩 SRAM 버퍼, NPU 시스톨릭 어레이 및 DVFS 전력/열 제어기 간의 On-Device AI SoC 구조도.

| 구성요소 | 책임 |
|:---|:---|
| CPU/GPU 호스트 | NPU가 멍청하게 못 돌리는 괴상한 인공지능 수식(레이어)을 대신 짬처리하고 잔심부름을 도맡는 메인 지휘관 |
| NPU 가속기 | 심장 박동처럼 데이터를 밀어내는 **시스톨릭 어레이**로 딥러닝 행렬 곱셈만 미친 듯이 갈겨버리는 단순 무식한 괴물 연산기 |
| 공유 온칩 버퍼 | 칩 밖에 있는 느린 램(DDR)까지 다녀오면 배터리가 박살 나니까, 데이터(가중치)를 칩 내부에 꽁꽁 숨겨두고 재탕하는 초고속 캐시 창고 |
| 전력·열 제어 | NPU가 폭주해서 스마트폰이 녹아내리지 않게 멱살을 잡고 전압과 온도 한계선(**TDP**)을 억제하는 안전장치 |

#### 한줄 요약

- **호스트 제어부(CPU/GPU)·NPU 가속기(Systolic Array)·공유 온칩 SRAM 버퍼·전력/열 관리 모듈(DVFS)**

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Quantization(양자화)**: 32비트 부동소수점(FP32) 가중치를 8비트/4비트 정수(INT8/INT4)로 변환하여 메모리 대역폭과 연산량을 절감하는 경량화 기법.
- **Layer Tiling(타일링)**: 거대한 텐서 행렬을 온칩 SRAM 크기에 맞춰 작은 블록(Tile) 단위로 쪼개어 반복 연산하는 스케줄링.

</details>

```text
[ 온디바이스 AI 추론 및 이기종 연산 파이프라인 흐름 ]
                         │
                         ▼
   [ 1. 모델 경량화 및 컴파일 (INT8 양자화, 레이어 융합: Conv+BN+ReLU) ]
                         │
                         ▼
   [ 2. 온칩 SRAM 버퍼에 가중치 및 입력 텐서 타일링(Tiling) 적재 ]
                         │
                         ▼
   [ 3. 연산자 분기 및 이기종 스케줄링 ]
        /                                               \
   [ NPU 지원 표준 연산자 ]                          [ NPU 미지원 특수 연산자 ]
        │                                               │
   [ NPU 시스톨릭 어레이 가속 ]                     [ CPU / GPU 로 Fallback 실행 ]
        │                                               │
        └───────────────────────┬───────────────────────┘
                                │
                                ▼
   [ 4. DVFS 열 스로틀링 억제 및 최종 추론 결과물 호스트 반환 ]
```

**동작 원리**

1. **컴파일 및 양자화**: FP32 모델을 INT8/INT4로 양자화하고 연속된 연산자를 Graph Fusion으로 병합
2. **타일링 적재**: 컴파일러가 외부 DRAM 트래픽을 최소화하도록 타일 단위로 가중치를 온칩 SRAM에 사전 적재
3. **NPU 가속 실행**: 2D 시스톨릭 어레이가 클록당 수천 개의 정수 곱셈 누적(MAC)을 병렬 수행
4. **Fallback 예외 처리**: NPU 하드웨어가 지원하지 않는 최신 연산자는 CPU/GPU 코어로 안전하게 전달하여 실행
5. **열 제어 및 완료**: 칩 온도가 임계치에 도달하지 않도록 주파수를 제어하며 밀리초 단위로 최종 추론값 반환

#### 한줄 요약

- 모델 경량화(INT8/INT4) 및 그래프 융합 $\to$ **타일링(Tiling) 온칩 버퍼 적재 $\to$ NPU 행렬 가속 (미지원 레이어 CPU Fallback) $\to$ 열 스로틀링 억제 $\to$ 실시간 추론 완료**

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **On-Device AI vs Cloud AI**:
  - On-Device AI: 단말 내부 SoC NPU, 오프라인 독립, 제로 지연/프라이버시, 경량 모델(수B)
  - Cloud AI: 데이터센터 초거대 GPU 클러스터, 네트워크 의존, 높은 서버 비용, 초거대 LLM(수백B)

</details>

| 비교 항목 | 온디바이스 AI (SoC NPU / Edge AI) | 클라우드 AI (Data-Center GPU / Cloud) |
|:---|:---|:---|
| 네트워크 의존성 및 프라이버시 | 오프라인 완전 독립 실행, 원천적 데이터 프라이버시 보장 | 지속적 인터넷 연결 필수, 서버로 사용자 데이터 전송 |
| 지연시간(Latency) 및 비용 | 수 밀리초($\text{ms}$) 단위 초저지연, 통신/서버 비용 0 | 네트워크 RTT 지연 발생, 지속적인 클라우드 API/서버 비용 |
| 모델 크기 및 연산 한계 | 수억~수십억 파라미터 경량 모델 (INT8/4), 메모리 한계 | 수천억 파라미터 초거대 LLM (FP16/FP8), 무제한 스케일 |

#### 한줄 요약

- 초저지연·보안은 **온디바이스 AI(NPU)**, 대규모 초거대 모델은 **클라우드 AI(GPU 클러스터)**

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Fallback(폴백)**: NPU 연산 지원 범위를 벗어난 복잡한 커스텀 레이어를 만났을 때 크래시 없이 CPU/GPU가 대신 연산하는 예외 처리 아키텍처.
- **Sustained TOPS**: 초기 피크 연산 성능이 아닌 열 스로틀링(Throttling) 상태에서도 장시간 유지 가능한 실효 NPU 연산 성능.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 최신 AI 논문 수식을 NPU가 못 알아처먹어서 칩 전체가 에러 뿜고 뻗어버리는 치명적 호환성 붕괴 | NPU가 뱉어낸 찌꺼기 연산을 CPU나 GPU가 멱살 잡고 대신 계산해 주는 **폴백**(Fallback) 구명조끼 장착 | 모델이 뻗지 않고 끝까지 돌아가게 살려내는 극강의 추론 예외 처리 사수 |
| NPU 코어는 팽팽 도는데 외부 램(DDR)에서 데이터 가져오는 속도가 개판이라 NPU가 하루 종일 노는 병목 지옥 | **양자화**로 데이터 크기 반토막 내고 온칩 버퍼(SRAM)에 데이터를 꽁꽁 싸매두는 타일링(Tiling) 떡칠 | 램 대역폭 병목을 씹어먹고 NPU 연산 효율(TOPS)을 한계점까지 멱살 잡고 끌어올림 |
| AI 모델 10분 돌렸더니 스마트폰이 불타오르면서 강제로 성능을 반토막 내는 열 스로틀링(Throttling) 발동 | **DVFS**로 전압을 미친 듯이 쪼개서 조절하고 작업량을 칩 여러 개로 갈기갈기 찢어서 부하 분산 | 칩이 녹아내리지 않고 최고 성능 대신 무난한 속도로 지속 처리량을 무한 방어 |

#### 한줄 요약

- **컴파일러 단 CPU/GPU Fallback 예외 처리·INT8/INT4 양자화 및 온칩 SRAM 타일링·DVFS 기반 지속 성능(Sustained TOPS) 확보**

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **모바일 SLM(Small Language Model) 구동 추세**: 단말기 내에서 3B~7B 크기의 소형 거대언어모델(Phi-3, LLaMA-3-8B)을 30+ tokens/s 속도로 직접 구동하는 방향으로 발전.

</details>

- 온디바이스 생성형 AI(On-Device LLM/LMM) 시대를 맞아 **NPU 45+ TOPS 탑재(Copilot+ PC, 온디바이스 폰) 및 칩렛 기반 이종 SoC 표준 채택**

#### 한줄 요약

- **전력 효율(TOPS/W)과 메모리 대역폭 한계**를 극복하는 온디바이스 NPU SoC 최적화
