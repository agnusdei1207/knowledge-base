## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **메모리 계층 구조(Memory Hierarchy)**: 접근 지연시간, 용량, 비트당 비용 격차를 완화하기 위해 레지스터, 캐시, 메인 메모리, 보조기억장치를 피라미드 형태로 단계 배치한 저장 아키텍처이다.
- **지역성(Locality of Reference)**: 프로그램 실행 중 특정 시점에 인근 주소를 집중하여 반복적으로 참조하는 메모리 억세스 특성이다.

</details>

- 정의: 데이터 참조 **지역성**을 기반으로 접근 속도, 용량, 비용에 따라 메모리를 피라미드 형태로 단계화한 구조
- 배경: 단일 고속 메모리 구성 시 발생하는 막대한 비용 증가와 대용량 구현의 하드웨어적 제약을 극복하기 위함

#### 한줄 요약

- 참조 지역성을 기반으로 고속/소용량 상위 계층과 저속/대용량 하위 계층을 조합하여 평균 메모리 접근 시간을 최소화하는 아키텍처이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **시간 지역성(Temporal Locality)**: 최근 접근된 메모리 번지가 가까운 미래에 다시 반복적으로 접근될 확률이 높은 특성이다.
- **공간 지역성(Spatial Locality)**: 특정 메모리 번지가 접근되면 그 인접 번지들이 연속적으로 접근될 확률이 높은 특성이다.
- **적중률(Hit Rate)**: 메모리 참조 요청 시 상위 계층 저장장치에서 즉시 발견하여 반환된 횟수 비율이다.
- **미스율(Miss Rate)**: 상위 계층에 데이터가 없어 하위 계층으로 요청을 넘기는 비율이다.
- **평균 메모리 접근 시간(Average Memory Access Time)**: 계층 구조 상에서 1회 메모리 참조 시 평균적으로 소요되는 지연시간 지표이다.
- **미스 페널티(Miss Penalty)**: 미스 발생 시 하위 계층으로부터 데이터를 인출해올 때 추가로 소비되는 사이클 페널티이다.
- **비트당 비용(Cost Per Bit)**: 단위 데이터를 저장 회로로 물리적으로 구현하는 데 소요되는 실리콘 하드웨어 제조 단가이다.

</details>

- 상위 계층일수록 접근 속도는 극도로 빠르나 용량이 작고 **비트당 비용**이 높음.
- **시간 지역성**과 **공간 지역성**을 극대화하여 최상위 계층의 **적중률**을 95% 이상으로 유지함.
- 상위 계층 적중 시간과 하위 계층 **미스 페널티**가 시스템의 **평균 메모리 접근 시간**을 결정함.

#### 한줄 요약

- 지역성을 활용하여 상위 계층 적중률을 극대화함으로써 시스템 전체의 체감 접근 속도를 최상위 계층 수준으로 수렴시킨다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **레지스터(Register)**: 프로세서 코어 내부에서 피연산자와 상태를 보관하는 초고속 최상위 저장 소자이다.
- **정적 램(Static RAM)**: 캐시 메모리로 주로 사용되며 전원 공급 중 리프레시 없이 저지연을 제공하는 고속 반도체이다.
- **동적 램(Dynamic RAM)**: 주기억장치로 사용되며 주기적 리프레시가 필요하나 고밀도 대용량을 제공하는 반도체이다.
- **보조기억장치(Secondary Storage)**: 비휘발성 플래시 메모리나 자기 디스크로 구성되며 영구 데이터를 보관하는 하위 계층이다.

</details>

```text
[ 메모리 계층 피라미드 아키텍처 ]
          ▲ 고속도 / 고비용 / 소용량
   ┌──────┴──────┐
   │  레지스터   │ (프로세서 내부)
   ├─────────────┤
   │ 캐시 메모리 │ (L1, L2, L3)
   ├─────────────┤
   │ 주기억장치  │ (동적 램)
   ├─────────────┤
   │보조기억장치 │ (스토리지)
   └─────────────┘
          ▼ 저속도 / 저비용 / 대용량
```

| 구성요소 | 책임 |
|:---|:---|
| 레지스터 | 프로세서 코어 내부에서 피연산자와 연산 상태 즉각 보관 |
| 캐시 메모리 | 최근 사용된 블록의 초저지연 재사용 및 주기억장치 접근 은닉 |
| 주기억장치 | 실행 중인 응용 프로그램 데이터 및 코드의 대용량 저장 제공 |
| 보조기억장치 | 비상주 페이지 데이터 및 파일 시스템의 영구적 비휘발성 보관 |

#### 한줄 요약

- 레지스터, 캐시, 주기억장치, 보조기억장치의 4단계 계층이 용량과 속도의 상호 보완적인 구조를 형성한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **캐시 블록(Cache Block)**: 하위 메모리에서 상위 캐시 메모리로 한 번에 묶어 전송하고 교체하는 라인 단위의 데이터 블록이다.
- **비상주 페이지(Non-Resident Page)**: 가상 주소 상에는 존재하지만 주기억장치에 적재되지 않아 보조기억장치로부터 인출해야 하는 페이지이다.

</details>

```text
[ 메모리 접근 트랜잭션 요청 발생 ]
                │
                ▼
      [ 1. 최상위 캐시 조회 ]
      ├─ 적중 ──> [ 데이터 즉시 반환 ]
      │
      └─ 미스 ──> [ 2. 하위 캐시 연쇄 탐색 ]
                        ├─ 적중 ──> [ 상위 계층 적재 및 반환 ]
                        │
                        └─ 미스 ──> [ 3. 주기억장치 인출 시도 ]
                                          ├─ 상주 시 ──> [ 캐시 적재 및 반환 ]
                                          │
                                          └─ 비상주 시 ──> [ 4. 보조기억장치 적재 ]
```

### 동작 원리

1. 최상위 캐시 조회: 접근 시 가장 먼저 최상위 캐시를 탐색하고 적중 시 즉각 데이터를 반환함.
2. 하위 캐시 탐색: 미스 발생 시 하위 레벨 캐시를 순차 탐색하여 **캐시 블록**을 상위로 보충함.
3. 주기억장치 인출: 모든 캐시 탐색에 실패하면 주기억장치에서 데이터를 블록 단위로 인출함.
4. 보조기억장치 적재: 주기억장치에도 없는 **비상주 페이지**이면 예외 처리 후 보조기억장치에서 메모리로 적재함.

#### 한줄 요약

- 상위 계층 미스 시 순차적으로 하위 계층으로 접근이 전파되며, 인출된 데이터는 캐시 블록 단위로 상위 계층에 채워진다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **작업 집합(Working Set)**: 프로그램이 특정 구동 구간에서 시간 및 공간 지역성에 의해 집중적으로 반복 참조하는 페이지 집합이다.
- **반복 교체(Thrashing)**: 작업 집합 크기가 상위 캐시 용량을 초과하여 인출된 블록이 재사용되기도 전에 축출되는 슬래싱 현상이다.

</details>

| 비교 항목 | 상위 계층 (레지스터, 캐시 메모리) | 하위 계층 (주기억장치, 보조기억장치) |
|:---|:---|:---|
| 물리적 위치 | 프로세서 칩 내부에 집적되는 온칩 형태 | 메인보드 외곽 및 전용 인터페이스로 연결됨 |
| 접근 속도 특성 | 서브 나노초 수준으로 지연이 극도로 짧음 | 수십 나노초에서 밀리초 단위로 상대적 느림 |
| 비트당 제조 비용 | 단위 용량당 실리콘 하드웨어 가격이 매우 높음 | 대용량을 저가로 경제성 있게 구축 가능함 |
| 데이터 유지 전략 | 지역성 기반의 **작업 집합** 집중 보관에 유리함 | 전체 응용 프로그램 데이터 및 **비상주 페이지** 보존 |
| 용량 부족 한계 시 | 캐시 오염 및 빈번한 블록 **반복 교체** 유발 | 가상 메모리 스왑 및 막대한 파일 입출력 지연 발생 |

#### 한줄 요약

- 상위 계층은 극도의 속도로 빈번한 데이터 재사용에 집중하고, 하위 계층은 막대한 데이터를 경제적으로 장기 보존한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **캐시 블로킹(Cache Blocking)**: 대용량 행렬 연산 시 캐시 용량에 맞는 소형 타일 단위로 루프를 쪼개어 접근 지역성을 극대화하는 소프트웨어 최적화이다.
- **선인출(Hardware Prefetching)**: 주소 접근 패턴을 미리 하드웨어적으로 예측하여 다음 읽을 캐시 블록을 주기억장치에서 선제적으로 당겨오는 기법이다.
- **캐시 오염(Cache Pollution)**: 일회성 대용량 전수 스트리밍 데이터가 들어와 유용한 작업 집합을 밀어내버려 캐시 적중률이 하락하는 부작용이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 대용량 행렬 및 텐서 연산 시 캐시 한계 초과로 인한 **반복 교체** 급증 | 프로그램 반복문 재구성을 통한 **캐시 블로킹** 알고리즘 튜닝 적용 | 물리적 캐시 적중률 대폭 향상 및 총 접근 지연 감소 |
| 스트리밍 데이터의 무작위 연속 적재로 인한 치명적인 **캐시 오염** 발생 | 비지역성 메모리 쓰기 명령어 인가 및 하드웨어 **선인출** 강도 제어 | 유용한 작업 집합의 억울한 퇴출 방지 및 오염 차단 |
| 하위 주기억장치의 본질적인 접근 지연(60ns)으로 인한 파이프라인 정지 | 지능형 접근 패턴 분석 기반의 **선인출** 하드웨어 논리 회로 활성화 | 주기억장치 읽기 지연시간을 파이프라인 뒤로 완벽 은닉 |
| 대용량 데이터 셋의 계층 간 이동 시 핀 병목에 따른 전송 대역폭 한계 | 인터포저 기반의 고대역폭 메모리(HBM) 및 3D 적층 기술 적극 도입 | 칩 간 물리적 데이터 이동 병목 해소 및 대역폭 수십 배 확충 |

#### 한줄 요약

- 캐시 블로킹과 비지역성 명령어로 캐시 오염을 막고 하드웨어 선인출 및 고대역폭 메모리 적층으로 지연을 적극 은닉한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **계층 최적화 기준(Hierarchy Optimization Criteria)**: 워크로드의 스레드 특성, 병렬 입출력 요구, 평균 적중률 목표를 수립하여 각 계층의 용량 배분과 전송 대역폭을 정형화하는 설계 지표이다.

</details>

- 접근 지역성이 뚜렷하면 캐시 용량을 증설하고, 스트리밍 대역폭 병목이 크면 선인출과 적층 메모리를 확충함

#### 한줄 요약

- 애플리케이션의 메모리 참조 특성과 평균 접근 시간 요인을 종합 평가하여 계층별 최적 용량과 이동 정책을 결정해야 한다.
