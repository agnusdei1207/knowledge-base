## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **메모리 계층**: 지연•용량•비트당 비용이 다른 저장장치를 단계적으로 조합하는 구조이다.
- **지역성**: 최근 사용한 데이터나 그 주변 주소를 가까운 미래에 다시 접근하는 성질이다.

</details>

- 정의/개념: 지역성에 따라 지연•용량•비용을 절충한 **메모리 계층**이다.
- 배경/필요성: 저지연 저장장치만으로 대용량•저비용 시스템을 구성하기 어렵다.

#### 한줄 요약

- 빠른 저장장치는 작고 비싸므로, 메모리 계층은 속도•용량•비용이 다른 장치를 조합한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **시간 지역성**: 방금 사용한 데이터를 가까운 미래에 다시 접근하는 성질이다.
- **공간 지역성**: 사용한 데이터의 인접 주소를 가까운 미래에 접근하는 성질이다.
- **적중률**: 요청 데이터를 현재 계층에서 찾은 접근의 비율이다.
- **미스율**: 요청 데이터를 현재 계층에서 찾지 못한 접근의 비율이다.
- **평균 메모리 접근 시간(Average Memory Access Time, AMAT)**: 적중 시간에 미스율과 미스 페널티의 곱을 더한 평균 접근 시간이다.
- **미스 페널티**: 현재 계층의 미스 뒤 하위 계층에서 데이터 블록을 가져오는 추가 지연이다.
- **적중 시간**: 요청 데이터를 현재 계층에서 찾아 반환하는 데 걸리는 시간이다.
- **비트당 비용**: 저장 용량 한 비트를 구현하는 데 드는 하드웨어 비용이다.

</details>

- 상위 계층일수록 짧은 지연·작은 용량·**높은 비트당 비용**이 핵심이다.
- **시간·공간 지역성**이 상위 계층의 데이터 재사용과 적중률을 좌우한다.
- **적중 시간+미스율×미스 페널티**로 평균 메모리 접근 시간을 결정한다.

$$
AMAT = Hit\ Time + Miss\ Rate \times Miss\ Penalty
$$

> 다음 계층의 AMAT는 미스 페널티에 포함

#### 한줄 요약

- 시간•공간 지역성이 적중률을 만들지만, 평균 지연은 적중 시간과 미스 페널티까지 함께 봐야 한다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **레지스터(Register)**: CPU 내부에서 현재 명령의 피연산자를 보관하는 저장 공간이다.
- **SRAM**: Static Random-Access Memory, 캐시 블록을 보관하는 고속 메모리이다.
- **동적 임의 접근 메모리(Dynamic Random-Access Memory, DRAM) 주기억장치**: 실행 중인 코드와 데이터를 큰 용량으로 제공하는 휘발성 메모리이다.
- **솔리드 스테이트 드라이브(Solid-State Drive, SSD) 보조기억장치**: 비상주 페이지와 영구 데이터를 보관하는 비휘발성 저장장치이다.
- **중앙 처리 장치(Central Processing Unit, CPU)**: 명령을 실행하고 레지스터와 캐시 계층을 가장 가까이 사용하는 연산 장치이다.

</details>

```text
[레지스터] -- [캐시 계층] -- [주기억장치] -- [보조기억장치]
```

선의 의미: CPU에 가까운 고속 계층부터 큰 하위 저장 계층까지 인접 계층끼리 결합된 정적 메모리 계층이다.

| 구성요소 | 책임 |
|:---|:---|
| 레지스터 | 현재 명령의 피연산자 제공 |
| 캐시 계층 | 재사용 **SRAM 블록** 보관 |
| 주기억장치 | 실행 중 코드•데이터 제공 |
| 보조기억장치 | 비상주•영구 데이터 보관 |

#### 한줄 요약

- 접근 빈도가 높은 데이터일수록 CPU와 가까운 저장 계층에 배치한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **캐시 블록**: 하위 계층에서 상위 계층으로 한 번에 전송하고 교체하는 연속 데이터 단위이다.
- **비상주 페이지**: 주소 공간에는 존재하지만 현재 주기억장치에 올라와 있지 않은 페이지이다.
- **페이지 상주 확인**: 요청한 가상 페이지가 주기억장치에 있는지 확인하는 단계이다.
- **비상주 페이지 적재**: 보조기억장치의 페이지를 주기억장치로 읽어 오는 단계이다.
- **캐시 계층 조회**: 상위 캐시부터 주소 태그를 비교해 요청 블록을 찾는 단계이다.
- **주기억장치 블록 공급**: 캐시 미스 때 DRAM 블록을 읽어 캐시에 채우는 단계이다.

</details>

```text
                  [CPU 가상 주소 요청]
                           |
                 1. 페이지 상주 확인
                    /             \
                 [상주]          [비상주]
                   |                |
                   |       2. 보조기억장치에서 페이지 적재
                   +-------+--------+
                           |
                  3. 캐시 계층 조회
                     /           \
                  [적중]         [미스]
                    |              |
               [데이터 반환]  4. 주기억장치 블록 읽기·캐시 채움
                                   |
                              [데이터 반환]
```

### 동작 원리

1. **페이지 상주 확인**: MMU가 요청한 가상 페이지의 주기억장치 상주 여부와 접근 권한을 확인한다.
2. **비상주 페이지 적재**: 페이지 폴트가 발생하면 SSD 보조기억장치의 페이지를 주기억장치에 적재한다.
3. **캐시 계층 조회**: 주소 태그를 상위 캐시부터 확인해 요청 블록의 적중 여부를 판정한다.
4. **주기억장치 블록 공급**: 모든 캐시에서 미스가 발생하면 DRAM에서 **캐시 블록**을 읽어 채운 뒤 요청 데이터를 반환한다.

#### 한줄 요약

- 상위 계층 미스가 인접 하위 계층으로 차례로 전파되므로, 더 아래까지 내려갈수록 접근 지연이 누적된다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **작업 집합**: 프로그램이 현재 집중적으로 반복 접근하는 코드와 데이터의 묶음이다.
- **반복 교체**: 작업 집합이 계층 용량보다 커서 가져온 블록이 재사용 전에 계속 밀려나는 현상이다.

</details>

| 계층 배치 위치 | 상위 계층 | 하위 계층 |
|:---|:---|:---|
| 적용 기준 | **작업 집합**이 계층 용량 안에 들어갈 때 | 접근 빈도는 낮지만 저장할 데이터 총량이 클 때 |
| 핵심 특징 | 짧은 지연•작은 용량•**높은 비트당 비용** | 긴 지연•큰 용량•**낮은 비트당 비용** |
| 한계 | 용량 초과 시 **반복 교체** 손실 | 접근 시 **미스 페널티** 직격 |

> 요약: 상위 계층 배치는 반복 사용하는 **작업 집합**이 해당 계층 용량 안에 들어갈 때 효과적이다.

#### 한줄 요약

- 작업 집합이 상위 계층 용량을 넘으면 재사용 전에 블록이 축출되어 반복 교체와 하위 계층 접근이 증가한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **캐시 블로킹**: 큰 계산을 캐시에 들어가는 조각으로 나눠 조각 안에서 데이터를 반복 재사용하는 최적화이다.
- **선인출**: 사용할 것으로 예상한 데이터를 요청 전에 미리 가져오는 기법이다.
- **캐시 오염**: 잘못 가져온 데이터가 유용한 캐시 블록을 밀어내는 현상이다.
- **데이터 온도**: 최근 접근 빈도로 데이터를 뜨거움과 차가움으로 구분하는 계층 배치 기준이다.
- **선인출 정확도**: 미리 가져온 블록 중 사용된 비율이다.
- **오염률**: 선인출 데이터가 유용한 캐시 블록을 밀어낸 비율이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 작업 집합이 캐시 용량보다 커서 **반복 교체** 발생 | 계층별 미스율을 측정하고 **캐시 블로킹**으로 계산 단위 축소 | 캐시 안의 재사용 증가로 용량 미스 감소 |
| 낮은 미스율에도 긴 **미스 페널티**가 평균 지연 지배 | **AMAT**를 측정해 병목 계층의 적중 시간·미스율 개선 | 영향도가 큰 항목 개선으로 평균 접근 지연 단축 |
| 부정확한 선인출이 유용한 블록을 밀어내 **캐시 오염** | **선인출 정확도·오염률**에 따라 거리와 강도 조정 | 불필요한 전송 감소로 캐시·대역폭 낭비 완화 |
| 느린 확장 메모리에 빈번히 접근해 응답 지연 변동 증가 | 접근 빈도인 **데이터 온도**에 따라 계층 배치·이동 기준 설정 | 뜨거운 데이터의 상위 배치로 평균 지연 증가 제한 |

#### 한줄 요약

- 캐시 블로킹으로 작업을 캐시 용량에 맞게 나누면 블록의 재사용 거리가 줄어 반복 교체를 완화할 수 있다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **재사용 데이터**: 가까운 시간 안에 같은 값이나 블록을 다시 접근할 가능성이 높은 데이터이다.
- **일회성 데이터**: 한 번 순차적으로 읽은 뒤 다시 사용할 가능성이 낮은 데이터이다.
- **계층 배치 기준**: 데이터의 재사용 빈도와 전체 용량으로 저장 계층을 고르는 기준이다.

</details>

- **계층 배치 기준**에 따라 **재사용 데이터**는 상위 계층에, **일회성 데이터**는 하위 계층에 배치한다.

#### 한줄 요약

- 재사용 빈도가 높은 데이터는 지연이 짧은 상위 계층에, 일회성·대용량 데이터는 용량이 큰 하위 계층에 배치한다.
