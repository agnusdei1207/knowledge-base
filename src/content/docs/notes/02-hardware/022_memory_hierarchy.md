## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **메모리 계층 구조(Memory Hierarchy)**: 레지스터, 캐시(L1~L3), 메인 메모리(DRAM), 보조기억장치(SSD/HDD)를 속도, 용량, 비트당 비용에 따라 피라미드형으로 배치하여 참조 지역성을 기반으로 평균 접근 지연시간(AMAT)을 최소화하는 컴퓨터 시스템 구조.
- **참조 지역성(Locality of Reference)**: 프로그램 실행 중 특정 메모리 주소나 인접 주소가 짧은 시간 간격 내에 반복 참조되는 통계적 특성.
- **평균 메모리 접근 시간(Average Memory Access Time, AMAT)**: $AMAT = T_{hit} + (Miss\,Rate \times Miss\,Penalty)$로 산출되는 전체 메모리 계층의 유효 접근 시간.

</details>

- 정의/개념: 접근 속도·용량·비트당 비용이 다른 기억장치들을 **참조 지역성(시간적·공간적)**에 따라 계층적으로 배치하여 고속 대용량 메모리를 가상으로 구현하는 **메모리 계층 구조 아키텍처**
- 배경/필요성: CPU 연산 속도와 메인 메모리 접근 속도 간의 심각한 성능 격차인 **메모리 벽(Memory Wall) 극복 및 비용 효율적 메모리 용량 확보**

#### 한줄 요약
- 메모리 계층 구조는 참조 지역성을 활용하여 레지스터의 초고속 속도와 SSD/HDD의 대용량을 동시에 실현하는 설계 체계이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **시간 지역성(Temporal Locality)**: 최근 참조된 메모리 주소가 가까운 미래에 다시 참조될 확률이 높은 특성(반복문, 스택 데이터 등).
- **공간 지역성(Spatial Locality)**: 특정 메모리 주소가 참조될 때 그 인접한 주소들이 연속적으로 참조될 확률이 높은 특성(배열 순회, 순차 코드 실행 등).
- **미스 패널티(Miss Penalty)**: 상위 계층 미스 시 하위 계층에서 데이터를 인출하여 상위 계층을 리필하는 데 소요되는 추가 지연시간.

</details>

- 피라미드형 계층 구성: 상위 계층으로 갈수록 초고속·소용량·고비용(레지스터, SRAM), 하위 계층으로 갈수록 대용량·저비용·고지연(DRAM, Flash) 배치
- 지역성 기반 최적화: **시간 지역성**을 활용해 최근 블록을 상위 캐시에 유지하고, **공간 지역성**을 활용해 64B 라인 단위로 일괄 반입하여 적중률 극대화
- AMAT 최소화: 90~95% 이상의 높은 캐시 적중률을 통해 CPU가 체감하는 **평균 메모리 접근 시간(AMAT)**을 1~수 사이클 수준으로 단축

#### 한줄 요약
- 상위 계층은 속도를, 하위 계층은 용량을 담당하며, 참조 지역성을 통해 AMAT를 최소화한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **레지스터(Register)**: CPU 코어 내부 실행 유닛과 직결되어 0~1클록 내에 데이터를 공급하는 플립플롭 기반 초고속 저장소.
- **온칩 캐시(L1/L2/L3 Cache)**: 프로세서 다이 내부에 SRAM으로 집적되어 DRAM 접근 트래픽을 완충하는 계층형 캐시.
- **주기억장치(DRAM)**: 실행 중인 프로그램과 데이터를 보관하는 시스템 메인 메모리.
- **보조기억장치(SSD/HDD)**: 비휘발성 대용량 파일 시스템 및 가상 메모리 스왑 영역을 제공하는 2차 저장장치.

</details>

```text
[CPU 코어 내부]
 └─ 레지스터 (Registers: < 1ns, 수십~수백 Bytes)
      │
[온칩 SRAM 캐시 계층]
 ├─ L1 캐시 (L1 I/D Cache: ~1ns, 수십 KB, 코어 전용)
 ├─ L2 캐시 (L2 Cache: 3~5ns, 수백 KB~수 MB, 코어 전용/공유)
 └─ L3 캐시 (LLC: 10~20ns, 수십~수백 MB, 전체 코어 공유)
      │
[오프칩 시스템 메모리 계층]
 └─ 메인 메모리 (DDR / HBM DRAM: 50~100ns, 수십 GB~수 TB)
      │
[비휘발성 스토리지 계층]
 ├─ 고속 NVMe SSD (Flash Storage: 수십 μs, 수 TB)
 └─ 대용량 HDD / 클라우드 스토리지 (Magnetic Storage: 수 ms, 수십 TB+)
```

선의 의미: 위에서 아래로 갈수록 용량 증가 및 접근 지연시간 급증; 상위 계층 적중 시 하위 계층 접근 생략

| 계층 | 사용 소자 | 전형적 용량 | 전형적 접근 지연 | 핵심 책임 |
|:---|:---|:---|:---|:---|
| **레지스터** | 플립플롭 회로 | 수백 Bytes | **< 1 사이클 (< 0.5ns)** | 실행 유닛 피연산자 즉시 공급 |
| **L1 캐시** | 고속 6T SRAM | 32KB ~ 64KB | **1 ~ 4 사이클 (~ 1ns)** | 1클록 명령어/데이터 공급 |
| **L2 캐시** | 고밀도 6T SRAM | 512KB ~ 2MB | **10 ~ 15 사이클 (~ 4ns)** | L1 미스 트래픽 완충 |
| **L3 캐시 (LLC)**| 고밀도 SRAM | 16MB ~ 256MB | **30 ~ 50 사이클 (~ 15ns)**| 코어 간 데이터 공유 및 DRAM 차단 |
| **주기억장치** | DDR/HBM DRAM | 16GB ~ 1TB+ | **50 ~ 100ns** | 실행 코드/데이터 전역 보관 |
| **보조기억장치** | NAND 플래시 (NVMe) | 1TB ~ 100TB+ | **10 ~ 100 $\mu$s** | 파일 시스템 및 스왑 영역 영구 보존 |

#### 한줄 요약
- 메모리 계층은 레지스터(피연산자) ➔ L1~L3 캐시(완충) ➔ DRAM(주기억) ➔ SSD/HDD(영구저장)의 4대 계층으로 피라미드를 형성한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **캐시 라인 리필(Cache Line Refill)**: 캐시 미스 발생 시 하위 메모리로부터 64B 블록 전체를 인출하여 상위 캐시에 적재하는 동작.

</details>

```text
1. CPU 코어의 메모리 읽기/쓰기 요청 발행
                      │
                      ▼
2. L1 캐시 조회 (1클록)
   ┌──────────────────┴──────────────────┐
[ L1 적중 (Hit) ]                     [ L1 미스 (Miss) ]
   │                                     │
   ▼                                     ▼
데이터 즉시 반환                      3. L2 / L3 캐시 순차 조회
(1~4 사이클 완료)                        ┌──────────┴──────────┐
                                   [ L2/L3 적중 ]          [ L3 미스 ]
                                         │                     │
                                         ▼                     ▼
                                   데이터 반환 및      4. DRAM 메인 메모리 접근 (50~100ns)
                                   L1 리필                 ┌──────────┴──────────┐
                                                     [ DRAM 상주 ]         [ 비상주 (Page Fault) ]
                                                           │                     │
                                                           ▼                     ▼
                                                     데이터 반환 및       5. OS 페이지 폴트: SSD 스왑 인
                                                     L1~L3 리필                │
                                                                               ▼
                                                                          DRAM 적재 ➔ 캐시 리필 ➔ 데이터 반환
```

분기 결과: **상위 캐시 적중은** 수 나노초 내에 끝나나, **DRAM 미스는** 수십 마이크로초의 디스크 I/O를 유발하므로 상위 계층 적중률 유지가 절대적임

#### 한줄 요약
- 요청 발생 시 L1 ➔ L2 ➔ L3 ➔ DRAM ➔ SSD 순으로 계층을 순차 탐색하며, 미스 발생 시 하위 계층에서 상위 계층으로 라인 리필을 수행한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **포함 캐시(Inclusive Cache)**: 상위 캐시(L1)의 모든 데이터 블록이 하위 캐시(L2/L3)에도 반드시 중복 보관되는 정책.
- **배타적 캐시(Exclusive Cache)**: 동일한 데이터 블록이 L1, L2, L3 중 오직 단 하나의 계층에만 존재하는 정책(전체 유효 용량 극대화).

</details>

| 비교 항목 | L1 / L2 사설 캐시 (Private Cache) | L3 공유 캐시 (Shared LLC) | 메인 메모리 (Main Memory DRAM) |
|:---|:---|:---|:---|
| 배치 위치 | **각 CPU 코어 내부 직결** | **온칩 인터커넥트에 연결된 공통 블록** | 프로세서 외부 마더보드/인터포저 실장 |
| 최적화 목표 | **초저지연 (최소 클록 접근)** | **대용량 및 코어 간 일관성 중계** | **최대 용량 및 대역폭 확장** |
| 관리 주체 | 하드웨어 캐시 제어기 | 하드웨어 캐시 제어기 및 디렉터리 | OS 가상 메모리 관리자 및 메모리 컨트롤러 |
| 전송 단위 | 워드(Word) / 64B 캐시 라인 | 64B 캐시 라인 | 64B 캐시 라인 / 4KB 페이지 프레임 |

#### 한줄 요약
- 사설 캐시는 코어의 초저지연을 보장하고, 공유 LLC는 코어 간 공유와 메모리 완충을 담당하며, DRAM은 시스템 전체의 대용량을 제공한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **캐시 블로킹(Cache Blocking)**: 대규모 데이터 행렬 연산 시 캐시 용량 크기에 맞추어 타일(Tile) 단위로 데이터를 분할 처리하는 알고리즘 최적화 기법.
- **하드웨어 프리페처(Hardware Prefetcher)**: 순차 및 스트라이드 접근 패턴을 감지하여 CPU 요청 전에 메모리 블록을 미리 캐시로 가져오는 유닛.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 대규모 행렬 연산 시 캐시 용량 초과로 인한 반복 미스 | **캐시 블로킹(Cache Blocking / Tiling) 알고리즘** 적용 | 시간적/공간적 지역성 극대화 및 DRAM 접근 90% 절감 |
| 비순차적 메모리 접근으로 인한 **캐시 미스 페널티** 증가 | **하드웨어 프리페처(Stream/Stride Prefetcher)** 활성화 | 미스 지연시간 은닉 및 연산 파이프라인 연속성 보장 |
| AI 가속 및 고성능 컴퓨팅에서 DRAM 대역폭 병목(메모리 벽) | **HBM(고대역폭 메모리) 또는 CXL 확장 메모리** 도입 | 초당 수 테라바이트급 메모리 전송 대역폭 확보 |

#### 한줄 요약
- 실무 성능 최적화는 캐시 블로킹 알고리즘, 하드웨어 프리페칭, HBM 초고대역폭 메모리 도입을 통해 메모리 벽을 극복한다.

## Ⅶ. 결론

- CPU와 메모리 간의 속도 및 대역폭 격차를 극복하기 위해 **레지스터 ➔ 다단계 온칩 캐시(L1~L3) ➔ DRAM ➔ NVMe 스토리지로 이어지는 메모리 계층 구조를 필수 구축**하고, 소프트웨어 계층에서는 **캐시 블로킹과 데이터 지역성 최적화**를 수행하며, 대규모 AI 연산 환경에서는 **HBM 및 CXL 메모리 계층 기술**을 융합하는 고성능 메모리 아키텍처 확립

#### 한줄 요약
- 메모리 계층 구조는 참조 지역성을 기반으로 성능과 비용의 최적 균형을 달성하는 핵심 설계이며, HBM과 CXL로 확장 진화하고 있다.
