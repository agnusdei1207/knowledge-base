## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **메모리 계층 구조(Memory Hierarchy)**: 속도, 용량, 비용이 다른 저장 장치를 계층으로 배치해 평균 접근 비용을 줄이는 구조입니다.
- **참조 지역성(Locality of Reference)**: 프로그램이 일정 시간 동안 일부 주소를 집중적으로 참조하는 성질입니다.
- **평균 메모리 접근 시간(Average Memory Access Time, AMAT)**: 여러 계층의 적중 시간과 미스 비용을 반영한 평균 접근 시간입니다.

</details>

- 정의/개념: 지역성을 이용해 저장 장치를 계층화하는 **평균 접근 비용 최적화 구조**
- 배경/필요성: 단일 고속·대용량 메모리의 비용과 물리적 한계 절충

#### 한줄 요약

- 자주 쓰는 데이터는 빠른 작은 저장소에 두고, 덜 쓰는 데이터는 느리지만 큰 저장소에 두어 전체 비용을 낮추는 구조입니다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **시간 지역성(Temporal Locality)**: 최근 사용한 데이터가 가까운 미래에 다시 사용되는 성질입니다.
- **공간 지역성(Spatial Locality)**: 한 주소를 사용하면 인접 주소도 곧 사용되는 성질입니다.
- **미스 패널티(Miss Penalty)**: 상위 계층에 데이터가 없어 하위 계층에서 가져오는 추가 시간입니다.

</details>

- 시간 지역성에 따른 **최근 데이터 재사용**
- 공간 지역성에 따른 **인접 블록 반입**
- 계층별 적중률과 **미스 패널티**의 AMAT 결정

#### 한줄 요약

- 프로그램의 반복과 순차 접근을 이용하면 빠른 계층에 모든 데이터를 담지 않아도 평균적으로 빠르게 동작할 수 있습니다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **레지스터(Register)**: CPU 내부에서 피연산자와 실행 상태를 가장 빠르게 보관하는 저장소입니다.
- **캐시(Cache)**: 최근 데이터와 명령어를 프로세서 가까이에 보관하는 저장소입니다.
- **주기억장치(Main Memory)**: 실행 중인 프로그램과 데이터를 보관하는 대용량 휘발성 메모리입니다.
- **보조기억장치(Secondary Storage)**: 전원이 꺼져도 파일과 비상주 데이터를 보존하는 저장 장치입니다.

</details>

```text
[메모리 계층]
├─ 레지스터
├─ 캐시
├─ 주기억장치
└─ 보조기억장치
```

| 구성요소 | 책임 |
|:---|:---|
| 레지스터 | 현재 연산의 피연산자와 상태 보관 |
| 캐시 | 반복 참조 블록의 저지연 제공 |
| 주기억장치 | 실행 중인 코드와 데이터 보관 |
| 보조기억장치 | 대용량 파일과 비상주 데이터 보존 |

#### 한줄 요약

- 위로 갈수록 빠르고 비싸며 작고, 아래로 갈수록 느리지만 싸고 큰 저장소가 배치됩니다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **캐시 라인 리필(Cache Line Refill)**: 하위 계층에서 일정 크기의 데이터 블록을 가져와 캐시에 채우는 처리입니다.
- **캐시 적중(Cache Hit)**: 현재 계층에서 요청 데이터를 찾은 상태입니다.

</details>

```text
[1. 상위 계층 조회]
          │
          ├─ 적중 → [3. 데이터 반환]
          │
          └─ 미스 → [2. 하위 계층 조회]
                         │
                         ▼
                    [캐시 라인 리필]
                         │
                         ▼
                    [3. 데이터 반환]
```

동작 원리:

1. 상위 계층 조회: 가장 빠른 저장소에서 요청 데이터 확인
2. 하위 계층 조회: 미스면 다음 계층을 차례로 검색하고 필요한 블록 반입
3. 데이터 반환: 요청자에게 값을 주고 상위 계층 상태 갱신

#### 한줄 요약

- 가까운 저장소에서 찾으면 즉시 끝나고, 없으면 아래 계층에서 데이터를 가져와 다음 접근을 빠르게 만들며 돌아옵니다.

## Ⅴ. 종류 및 비교

| 메모리 계층 | 상위 계층 | 하위 계층 |
|:---|:---|:---|
| 적용 기준 | 반복 참조와 낮은 지연 우선 | 대용량과 낮은 저장 비용 우선 |
| 핵심 특징 | 레지스터·캐시의 빠른 접근 | DRAM·SSD의 큰 용량 |
| 한계 | 높은 비트당 비용과 작은 용량 | 접근 지연과 대역폭 변동 |

#### 한줄 요약

- 상위 계층은 시간을 아끼고 하위 계층은 공간과 비용을 아끼므로, 둘을 함께 써야 현실적인 시스템이 됩니다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **캐시 블로킹(Cache Blocking)**: 큰 데이터를 캐시에 맞는 작은 블록으로 나누어 재사용을 높이는 소프트웨어 최적화입니다.
- **프리페치(Prefetch)**: 앞으로 사용할 데이터를 미리 상위 계층으로 가져오는 기법입니다.
- **캐시 오염(Cache Pollution)**: 유용한 데이터가 불필요한 반입 데이터로 캐시에서 밀려나는 현상입니다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 행렬·텐서 데이터가 캐시보다 커 반복 교체 | 캐시 블로킹으로 작업 타일 구성 | 데이터 재사용과 적중률 향상 |
| 순차 데이터가 유용한 라인을 축출 | 프리페치 거리와 비지역성 접근 조정 | 캐시 오염과 대역폭 낭비 감소 |
| DRAM 지연으로 실행 유닛 대기 | 접근 순서 최적화와 메모리 병렬성 활용 | 하위 계층 대기 은닉 |
| 대역폭이 필요한 가속 작업에 부족 | 고대역폭 메모리와 계층 배치 검토 | 데이터 공급 병목 완화 |

#### 한줄 요약

- 메모리 계층 성능은 하드웨어 크기만의 문제가 아니며, 데이터 접근 순서와 반입 정책을 함께 조정해야 개선됩니다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **대역폭(Bandwidth)**: 단위 시간에 저장 장치와 프로세서 사이에서 전송할 수 있는 데이터 양입니다.

</details>

- 반복 접근은 캐시 블로킹으로 **AMAT**를 낮추고, 대역폭 중심 작업은 하위 계층의 **대역폭**과 저장 비용을 기준으로 메모리 계층을 결정

#### 한줄 요약

- 메모리 계층은 빠른 저장소를 무작정 키우는 설계가 아니라, 프로그램의 지역성과 필요한 데이터 전송량에 맞춰 비용을 나누는 설계입니다.
