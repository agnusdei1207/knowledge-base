## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **플린의 분류(Flynn's Taxonomy)**: 마이클 플린(Michael J. Flynn)이 제안한 컴퓨터 아키텍처 분류 체계로, CPU의 명령어 스트림(Instruction Stream)과 데이터 스트림(Data Stream)의 단일(Single)·다중(Multiple) 조합에 따라 시스템을 4가지 기본 범주로 분류.
- **명령어 스트림(Instruction Stream, IS)**: 프로세서의 제어 장치(Control Unit, CU)에 의해 메모리에서 순차적으로 인출·해독되는 기계어 명령어의 흐름.
- **데이터 스트림(Data Stream, DS)**: 처리 장치(Processing Unit, PU / ALU)에 입력되어 명령어에 의해 조작되는 피연산자 데이터의 흐름.

</details>

- 정의/개념: 컴퓨터 시스템의 병렬성 구조를 **명령어 스트림(IS)과 데이터 스트림(DS)**의 단일(Single)/다중(Multiple) 수량을 기준으로 4대 기본 아키텍처로 분류한 **플린의 분류(Flynn's Taxonomy) 체계**
- 배경/필요성: 단순한 코어 개수나 클록 주파수 집계만으로는 **제어 흐름의 공유 여부와 데이터 병렬성 메커니즘의 아키텍처적 차이 식별 불가**

#### 한줄 요약
- 플린의 분류는 명령어와 데이터의 흐름 수를 2×2 매트릭스로 조합하여 SISD, SIMD, MISD, MIMD로 병렬성을 규정하는 고전 표준 체계이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **데이터 병렬성(Data Parallelism)**: 단일 연산 명령어를 대규모 배열이나 행렬의 개별 데이터 요소들에 동시에 적용하는 병렬 처리 형태.
- **태스크 병렬성(Task Parallelism)**: 서로 다른 독립된 명령어 코드와 제어 흐름(스레드/프로세스)을 다수의 코어에서 동시에 비동기 실행하는 형태.

</details>

- 직관적인 2×2 매트릭스 분류: **SISD, SIMD, MISD, MIMD**의 4개 상호 배타적 영역으로 컴퓨터 시스템의 하드웨어 제어 경계 정의
- 병렬성 유형의 명확화: 단일 명령어로 대량 데이터를 다루는 **데이터 병렬성(SIMD)**과 독립 코어가 협업하는 **태스크 병렬성(MIMD)**의 본질적 차이 규명
- 계층적 하이브리드 확장성: 현대 슈퍼컴퓨터 및 GPU 서버의 **노드 간 MIMD + 노드 내 SIMT/SIMD** 복합 아키텍처 분석의 이론적 토대 제공

#### 한줄 요약
- 2×2 매트릭스로 제어와 데이터의 병렬 구조를 명확히 정의하며, 현대 하이브리드 시스템 분석의 기반이 된다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **제어 장치(Control Unit, CU)**: 메모리로부터 명령어를 인출(Fetch)하고 해독(Decode)하여 처리 장치에 제어 신호를 인가하는 하드웨어 유닛.
- **처리 장치(Processing Unit, PU)**: 제어 장치의 지시에 따라 산술 논리 연산(ALU)을 직접 실행하는 하드웨어 연산 레인.

</details>

```text
[플린의 분류 2×2 매트릭스 아키텍처]
 ┌──────────────────────┬─────────────────────────────────────────────────────────────┐
 │                      │                     데이터 스트림 (Data Stream)             │
 │                      ├──────────────────────────────┬──────────────────────────────┤
 │                      │ 단일 데이터 스트림 (Single)   │ 다중 데이터 스트림 (Multiple)│
 ├──────────┬───────────┼──────────────────────────────┼──────────────────────────────┤
 │          │ 단일 (SI) │ **SISD (Single Inst, Single)**│ **SIMD (Single Inst, Multi)**│
 │  명령어  │           │ ┌────┐     ┌────┐            │ ┌────┐     ┌────┐ ┌────┐     │
 │  스트림  │           │ │ CU │ ──► │ PU │ ──► DS      │ │ CU │ ──► │ PU0│ │ PU1│     │
 │  (IS)    │           │ └────┘     └────┘            │ └────┘     └────┘ └────┘     │
 │          ├───────────┼──────────────────────────────┼──────────────────────────────┤
 │          │ 다중 (MI) │ **MISD (Multi Inst, Single)** │ **MIMD (Multi Inst, Multi)** │
 │          │           │ ┌────┐     ┌────┐            │ ┌────┐┌────┐ ┌────┐┌────┐    │
 │          │           │ │ CU0│ ──► │ PU0│ ──┐ DS     │ │ CU0││ CU1│ │ PU0││ PU1│    │
 │          │           │ ├────┤     ├────┤   ├──►     │ └────┘└────┘ └────┘└────┘    │
 │          │           │ │ CU1│ ──► │ PU1│ ──┘        │ (멀티코어 CPU, 분산 클러스터)│
 └──────────┴───────────┴──────────────────────────────┴──────────────────────────────┘
```

선의 의미: CU(제어 장치)와 PU(처리 장치) 간의 명령어 신호 분배 및 데이터 스트림(DS)의 유입 경로를 나타냄

| 아키텍처 범주 | 하드웨어 구성 (CU 및 PU) | 핵심 엔지니어링 책임 | 대표 하드웨어 구현 |
|:---|:---|:---|:---|
| **SISD** | 1개 CU + 1개 PU | 단일 명령어 스트림으로 단일 데이터 순차 처리 | 고전 단일 코어 폰 노이만 CPU |
| **SIMD** | 1개 CU + 다중 PU 레인 | 단일 명령어를 다수의 PU 레인에 브로드캐스트하여 동시 연산 | Intel AVX-512, ARM Neon, GPU |
| **MISD** | 다중 CU + 다중 PU | 동일한 단일 데이터 스트림에 여러 명령어를 중복 적용 | 우주항공 비행 제어 다중 검증 시스템 |
| **MIMD** | 다중 CU + 다중 PU | 각 코어가 독립된 프로그램 카운터(PC)로 독립 데이터 실행 | 최신 멀티코어 CPU, 분산 서버 클러스터 |

#### 한줄 요약
- 플린의 분류는 SISD(단일 제어-단일 연산), SIMD(단일 제어-다중 연산), MISD(다중 제어-단일 연산), MIMD(다중 제어-다중 연산)로 구성된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **분석 관점(Observation Boundary)**: 코어 레벨, 프로세서 칩 레벨, 랙 클러스터 레벨 등 병렬성을 판정하는 시스템의 관찰 계층 기준.

</details>

```text
1. 분석 대상 하드웨어 계층 경계 설정 (코어 내부, 칩 전체, 클러스터)
                      │
                      ▼
2. 독립된 프로그램 카운터(PC)와 제어 장치(CU)가 몇 개인가?
   ┌──────────────────┴──────────────────┐
[ 1개의 제어 장치 (Single IS) ]       [ 복수의 독립 제어 장치 (Multiple IS) ]
   │                                     │
   ▼                                     ▼
3. 1개 명령어가 처리하는 데이터 수는?    3. 각 제어 흐름이 다루는 데이터는?
   ┌──────────┴──────────┐               ┌──────────┴──────────┐
 [ 1개 데이터 ] [ 다중 데이터 ]         [ 동일 데이터 중복 ] [ 독립 데이터 분산 ]
   │              │                       │                    │
   ▼              ▼                       ▼                    ▼
4. **SISD 판정** 4. **SIMD 판정**        4. **MISD 판정**     4. **MIMD 판정**
   │              │                       │                    │
   └──────────────┴───────────────┬───────┴────────────────────┘
                                  │
                                  ▼
5. 현대 시스템 분석: 노드 간 MIMD(클러스터) + 노드 내 SIMT/SIMD 하이브리드 계층 도출
```

분기 결과: **제어 장치 수와 데이터 레인 수를 판정하여** 4대 기본 영역으로 분류하고, 현대 시스템은 이들의 계층적 조합으로 분석함

#### 한줄 요약
- 제어 장치 수 판정 ➔ 데이터 처리 수 판정 ➔ 4대 영역 분류 ➔ 하이브리드 계층 구조 도출의 흐름으로 진행된다.

## Ⅴ. 종류 및 비교

| 분류 항목 | SISD | SIMD | MISD | MIMD |
|:---|:---|:---|:---|:---|
| 제어 복잡도 | **최저 (단일 파이프라인)** | 낮음 (단일 디코더 공유) | 높음 (다중 제어 동기화) | **최고 (코어별 독립 제어)** |
| 하드웨어 효율성 | 낮음 (병렬성 부재) | **최고 (다이 면적당 연산기 극대화)**| 낮음 (중복 연산 오버헤드) | 중간 (제어 회로 중복 면적 소요) |
| 프로그래밍 난이도 | **가장 쉬움 (순차 코드)** | 중간 (데이터 벡터화 필요) | 높음 (특수 알고리즘) | **높음 (동기화, 데드락, 락 경합)**|
| 주력 워크로드 | 단순 순차 로직, 임베디드 제어 | **행렬 곱셈, 영상 처리, 딥러닝** | 우주항공 결함 감지 및 허용 | **웹 서버, 가상화 클라우드, DBMS** |

#### 한줄 요약
- 정형 대량 데이터 연산에는 SIMD가, 독립 멀티태스킹과 분산 환경에는 MIMD가 최적의 아키텍처이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **SIMT(Single Instruction, Multiple Threads)**: SIMD의 데이터 레인 구조 위에 스레드 단위의 프로그래밍 추상화와 하드웨어 워프 스케줄링을 결합한 확장 모델.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 시스템 관찰 계층(코어 vs 칩) 혼동으로 인한 아키텍처 분석 오류 | **계층적 분석(SoC 수준 MIMD + 코어 내부 SIMD) 체계 적용** | 시스템 병렬 구조의 정확한 파악 및 최적화 |
| SIMD/SIMT 구조에서 if-else 조건문으로 인한 성능 급락 | **데이터 정렬 및 브랜치 프리(Branch-Free) 마스킹 알고리즘** | 연산 레인 유휴 제거 및 처리량 극대화 |
| MIMD 환경에서 코어 수 증가에 따른 캐시 일관성 및 락 병목 | **디렉터리 기반 일관성 프로토콜 및 락-프리(Lock-Free) 큐 적용** | 코어 확장 시 선형적 처리 성능 사수 |

#### 한줄 요약
- 실무에서는 계층적 하이브리드 관점으로 시스템을 분석하고, SIMD의 분기 발산과 MIMD의 락 경합을 방지해야 한다.

## Ⅶ. 결론

- 고성능 컴퓨팅 및 대규모 AI 시스템의 병렬성 최적화를 위해 **플린의 분류(Flynn's Taxonomy) 이론에 따라 정형 데이터 병렬 구간에는 SIMD/SIMT를, 비동기 태스크 병렬 구간에는 MIMD를 분리 매핑**하고, 현대 인프라에서는 **노드 간 MIMD 분산 클러스터와 노드 내 SIMD 가속기를 융합한 계층적 하이브리드 아키텍처**를 구축하는 고효율 시스템 엔지니어링 확립

#### 한줄 요약
- 플린의 분류는 컴퓨터 병렬성을 규정하는 영원한 나침반이며, 현대 시스템은 MIMD와 SIMD의 계층적 융합으로 진화했다.
