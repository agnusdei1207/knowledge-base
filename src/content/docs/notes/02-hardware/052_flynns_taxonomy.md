## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **플린 분류(Flynn's Taxonomy)**: 명령 스트림과 데이터 스트림의 수를 단일·다중으로 조합해 컴퓨터 구조를 네 가지로 나누는 분류 체계이다.
- **명령 스트림(Instruction Stream)**: 독립된 제어 장치가 순서대로 해석하고 발행하는 명령의 흐름이다.
- **데이터 스트림(Data Stream)**: 동일한 시점에 독립적으로 연산되는 데이터 값들의 흐름이다.

</details>

- 정의/개념: 명령 스트림과 데이터 스트림의 수를 각각 단일•다중으로 조합해 컴퓨터 구조를 네 유형으로 나누는 **플린 분류** 기반 **병렬 구조 분류 체계**
- 배경/필요성: 처리기 수만으로는 실행 흐름의 **병렬성 구분 불가**

#### 한줄 요약

- 동시에 쓰는 레시피와 재료 묶음 수로 주방을 네 갈래로 나눈다

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **독립 명령 스트림(Independent Instruction Stream)**: 다른 제어 흐름과 별도로 명령 순서와 분기를 결정할 수 있는 실행 흐름이다.
- **독립 데이터 스트림(Independent Data Stream)**: 다른 데이터와 별도의 연산 입력으로 동시에 처리되는 데이터 흐름이다.
- **분석 경계(Analysis Boundary)**: 명령과 데이터 스트림을 셀 때 기준으로 삼는 코어·칩·노드 등의 범위이다.

</details>

- **독립 명령 스트림 수** 로 제어 흐름 구분
- **독립 데이터 스트림 수** 로 동시 처리 범위 구분
- **분석 경계 고정** 으로 코어·칩·노드 분류 혼선 방지

#### 한줄 요약

- 조리대가 많아도 같은 레시피를 따르면 명령 흐름은 하나로 센다

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **코어(Core)**: 독립적인 명령 흐름을 실행할 수 있는 프로세서 내부의 연산 단위이다.
- **칩(Chip)**: 하나 이상의 코어와 캐시 및 인터페이스를 하나의 반도체 다이에 통합한 장치이다.
- **노드(Node)**: 프로세서와 메모리 및 운영체제를 갖추고 네트워크에 연결된 한 대의 컴퓨터이다.
- **2×2 분류 행렬(2×2 Classification Matrix)**: 명령과 데이터 스트림의 단일·다중 조합으로 네 구조를 결정하는 표이다.

</details>

| 구성요소 | 책임 |
|:---|:---|
| 분석 경계 | 코어·칩·노드 **범위 고정** |
| 명령 스트림 수 | 독립 **제어 흐름 판정** |
| 데이터 스트림 수 | 동시 **데이터 흐름 판정** |
| 2×2 분류 행렬 | 네 병렬 **구조 결정** |

#### 한줄 요약

- 분석 범위를 정한 뒤 명령과 데이터 흐름 수를 조합해 네 구조로 분류한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **스트림 계수(Stream Counting)**: 정한 분석 경계 안에서 독립 명령과 데이터 흐름이 각각 몇 개인지 판단하는 과정이다.
- **분류 일관성(Classification Consistency)**: 비교하는 모든 구조에 동일한 분석 경계와 판정 기준을 적용하는 성질이다.
- **계층별 분류(Hierarchical Classification)**: 코어·칩·노드처럼 서로 다른 계층을 분리하여 각각 플린 유형을 판정하는 방식이다.

</details>

- **분석 경계** 안의 **명령·데이터 스트림 수** 조합으로 유형 판정

#### 한줄 요약

- 어느 주방을 볼지 정한 뒤 레시피와 재료 묶음 수를 조합표에 넣는다

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **단일 명령 단일 데이터(Single Instruction Single Data, SISD)**: 하나의 명령 스트림이 하나의 데이터 스트림을 처리하는 순차 구조이다.
- **단일 명령 다중 데이터(Single Instruction Multiple Data, SIMD)**: 하나의 명령 스트림이 여러 데이터 스트림에 같은 연산을 동시에 적용하는 구조이다.
- **다중 명령 단일 데이터(Multiple Instruction Single Data, MISD)**: 여러 명령 스트림이 하나의 데이터 흐름을 처리하는 구조이다.
- **다중 명령 다중 데이터(Multiple Instruction Multiple Data, MIMD)**: 여러 명령 스트림이 서로 다른 데이터를 독립적으로 처리하는 구조이다.

</details>

| Flynn 분류 | SISD | SIMD | MISD | MIMD |
|:---|:---|:---|:---|:---|
| 적용 기준 | 순차 스칼라 | 동일 연산·다중 데이터 | 동일 입력·다중 처리 | 독립 작업·데이터 |
| 핵심 특징 | 단일 명령·**단일 데이터** | 단일 명령·**다중 데이터** | 다중 명령·**단일 데이터** | 다중 명령·**다중 데이터** |
| 한계 | 병렬 처리량 부족 | 분기·레인 미활용 | 적용 사례 제한 | 동기화·통신 비용 |

> 요약: 동일 연산에는 **SIMD**, 독립 작업에는 **MIMD** 선택

#### 한줄 요약

- 레시피 하나로 여러 재료를 다루면 SIMD, 각자 주문을 맡으면 MIMD이다

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **단일 명령 다중 스레드(Single Instruction Multiple Threads, SIMT)**: 하나의 명령을 워프의 여러 스레드 상태에 공통 발행하되 각 스레드가 독립 상태를 유지하는 실행 모델이다.
- **단일 명령 다중 데이터(Single Instruction Multiple Data, SIMD)**: 하나의 명령으로 여러 데이터 레인을 동시에 처리하는 실행 구조이다.
- **다중 명령 다중 데이터(Multiple Instruction Multiple Data, MIMD)**: 여러 실행 단위가 서로 다른 명령과 데이터를 독립적으로 처리하는 구조이다.
- **명령 발행 단위(Instruction Issue Unit)**: 하나의 명령이 동시에 적용되는 하드웨어 레인이나 스레드의 묶음이다.
- **혼합 병렬성(Hybrid Parallelism)**: 하나의 시스템이 계층에 따라 데이터 병렬성과 작업 병렬성을 함께 사용하는 구조이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 코어·칩·노드 경계를 섞어 분류 | 비교 대상마다 **분석 경계** 선지정 | **분류 일관성** 확보 |
| 그래픽 처리장치(Graphics Processing Unit, GPU)의 SIMT를 하드웨어 SIMD와 동일시 | **명령 발행 단위·스레드 상태** 구분 | **실행 모델** 오분류 방지 |
| 이기종 시스템 전체를 단일 범주로 단순화 | **중앙처리장치(Central Processing Unit, CPU)·GPU·노드** 계층별 분리 분류 | **혼합 병렬성** 표현 |

> 요약: GPU 워프는 **SIMD**, 여러 GPU·노드는 **MIMD** 관점 분류

#### 한줄 요약

- 한 조리대는 같은 레시피를 따르지만 여러 주방은 각자 다른 주문을 처리한다

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **데이터 병렬성(Data Parallelism)**: 같은 연산을 서로 다른 데이터 원소들에 동시에 적용하는 병렬 방식이다.
- **작업 병렬성(Task Parallelism)**: 서로 다른 명령과 작업을 독립적인 실행 자원에서 동시에 처리하는 방식이다.
- **실행 모델(Execution Model)**: 명령이 실행 단위에 발행되고 데이터가 처리되는 규칙을 정의한 체계이다.

</details>

- 동일 연산•다중 데이터는 **단일 명령 다중 데이터(Single Instruction Multiple Data, SIMD)**, 독립 작업은 **다중 명령 다중 데이터(Multiple Instruction Multiple Data, MIMD)** 분류

#### 한줄 요약

- 어느 주방을 볼지 먼저 정하고 같은 레시피면 SIMD, 각자 주문이면 MIMD로 나눈다
