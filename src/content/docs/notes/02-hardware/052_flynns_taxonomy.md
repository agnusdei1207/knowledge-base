## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **플린 분류(Flynn's Taxonomy)**: 명령 스트림과 데이터 스트림의 수를 단일•다중으로 조합해 컴퓨터 구조를 네 가지로 나누는 분류 체계이다.
- **명령 스트림(Instruction Stream)**: 독립된 제어 장치가 순서대로 해석하고 발행하는 명령의 흐름이다.
- **데이터 스트림(Data Stream)**: 동일한 시점에 독립적으로 연산되는 데이터 값들의 흐름이다.

</details>

- 정의/개념: 분석 경계 안의 독립 명령 스트림과 데이터 스트림 수를 단일·다중으로 조합하는 **플린 분류**이다.
- 배경/필요성: 처리기 개수만으로는 같은 명령을 여러 데이터에 적용하는지 독립 작업을 실행하는지 병렬 실행 방식을 구분하기 어렵다.

#### 한줄 요약

- 플린 분류는 독립 명령·데이터 스트림 수를 각각 단일·다중으로 판정해 SISD·SIMD·MISD·MIMD로 구분한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **독립 명령 스트림(Independent Instruction Stream)**: 다른 제어 흐름과 별도로 명령 순서와 분기를 결정할 수 있는 실행 흐름이다.
- **독립 데이터 스트림(Independent Data Stream)**: 다른 데이터와 별도의 연산 입력으로 동시에 처리되는 데이터 흐름이다.
- **분석 경계(Analysis Boundary)**: 명령과 데이터 스트림을 셀 때 기준으로 삼는 코어•칩•노드 등의 범위이다.

</details>

- **독립 명령 스트림**의 수로 제어 흐름을 구분한다.
- **독립 데이터 스트림**의 수로 동시 처리 범위를 구분한다.
- **분석 경계**를 고정해 코어•칩•노드 분류 혼선을 방지한다.

#### 한줄 요약

- 처리기 수가 아니라 고정한 분석 경계 안의 독립 제어 흐름과 동시 데이터 흐름 수로 병렬 구조를 판정한다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **코어(Core)**: 독립적인 명령 흐름을 실행할 수 있는 프로세서 내부의 연산 단위이다.
- **칩(Chip)**: 하나 이상의 코어와 캐시 및 인터페이스를 하나의 반도체 다이에 통합한 장치이다.
- **노드(Node)**: 프로세서와 메모리 및 운영체제를 갖추고 네트워크에 연결된 한 대의 컴퓨터이다.
- **2×2 분류 행렬(2×2 Classification Matrix)**: 명령과 데이터 스트림의 단일•다중 조합으로 네 구조를 결정하는 표이다.

</details>

| 구성요소 | 책임 |
|:---|:---|
| 분석 경계 | 코어•칩•노드 범위 고정 |
| 명령 스트림 수 | 독립 제어 흐름 판정 |
| 데이터 스트림 수 | 동시 데이터 흐름 판정 |
| 2×2 분류 행렬 | 네 병렬 구조 결정 |

#### 한줄 요약

- 분석 범위를 정한 뒤 명령과 데이터 흐름 수를 조합해 네 구조로 분류한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **스트림 계수(Stream Counting)**: 정한 분석 경계 안에서 독립 명령과 데이터 흐름이 각각 몇 개인지 판단하는 과정이다.
- **분류 일관성(Classification Consistency)**: 비교하는 모든 구조에 동일한 분석 경계와 판정 기준을 적용하는 성질이다.
- **계층별 분류(Hierarchical Classification)**: 코어•칩•노드처럼 서로 다른 계층을 분리하여 각각 플린 유형을 판정하는 방식이다.
- **분석 경계 설정**: 독립 스트림을 셀 코어·칩·노드 범위를 고정하는 단계이다.
- **명령 스트림 판정**: 경계 안의 독립 제어 흐름 수가 단일인지 다중인지 확인하는 단계이다.
- **데이터 스트림 판정**: 동시에 연산되는 독립 데이터 흐름 수가 단일인지 다중인지 확인하는 단계이다.
- **분류 행렬 매핑**: 두 스트림 수의 조합을 2×2 분류 행렬의 유형에 대응하는 단계이다.

</details>

```text
1. 분석 경계 설정
        |
2. 명령 스트림 수 판정
   ├─ 단일
   └─ 다중
        |
3. 데이터 스트림 수 판정
   ├─ 단일
   └─ 다중
        |
4. 2×2 행렬에 매핑
   ├─ 단일·단일: SISD
   ├─ 단일·다중: SIMD
   ├─ 다중·단일: MISD
   └─ 다중·다중: MIMD
```

### 동작 원리

1. **분석 경계 설정**: **스트림 계수**를 수행할 코어·칩·노드 범위를 먼저 고정하고 필요하면 **계층별 분류**로 나눈다.
2. **명령 스트림 판정**: 경계 안에서 독립적으로 명령 순서와 분기를 결정하는 제어 흐름의 수를 확인한다.
3. **데이터 스트림 판정**: 같은 시점에 독립적으로 연산되는 데이터 흐름의 수를 확인한다.
4. **분류 행렬 매핑**: **분류 일관성**을 유지하도록 같은 기준으로 명령·데이터의 단일·다중 조합을 SISD·SIMD·MISD·MIMD에 대응한다.

#### 한줄 요약

- 코어·칩·노드 중 분석 경계를 고정한 뒤 독립 명령·데이터 스트림 수를 2×2 행렬에 대응한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **단일 명령 단일 데이터(Single Instruction Single Data, SISD)**: 하나의 명령 스트림이 하나의 데이터 스트림을 처리하는 순차 구조이다.
- **단일 명령 다중 데이터(Single Instruction Multiple Data, SIMD)**: 하나의 명령 스트림이 여러 데이터 스트림에 같은 연산을 동시에 적용하는 구조이다.
- **다중 명령 단일 데이터(Multiple Instruction Single Data, MISD)**: 여러 명령 스트림이 하나의 데이터 흐름을 처리하는 구조이다.
- **다중 명령 다중 데이터(Multiple Instruction Multiple Data, MIMD)**: 여러 명령 스트림이 서로 다른 데이터를 독립적으로 처리하는 구조이다.

</details>

| Flynn 분류 | 명령 스트림 | 데이터 스트림 | 대표 형태 |
|:---|:---|:---|:---|
| **SISD** | 단일 명령 | 단일 데이터 | 순차 스칼라 처리 |
| **SIMD** | 단일 명령 | 다중 데이터 | 같은 연산의 벡터•행렬 처리 |
| **MISD** | 다중 명령 | 단일 데이터 | 동일 입력의 고장 허용 중복 처리 |
| **MIMD** | 다중 명령 | 다중 데이터 | 독립 작업의 멀티코어•분산 처리 |

> 요약: 명령•데이터 스트림 수로 **SISD**, **SIMD**, **MISD**, **MIMD**를 분류한다.

#### 한줄 요약

- 하나의 명령을 여러 데이터에 적용하면 SIMD, 여러 독립 명령이 서로 다른 데이터를 처리하면 MIMD로 분류한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **단일 명령 다중 스레드(Single Instruction Multiple Threads, SIMT)**: 하나의 명령을 워프의 여러 스레드 상태에 공통 발행하되 각 스레드가 독립 상태를 유지하는 실행 모델이다.
- **명령 발행 단위(Instruction Issue Unit)**: 하나의 명령이 동시에 적용되는 하드웨어 레인이나 스레드의 묶음이다.
- **혼합 병렬성(Hybrid Parallelism)**: 하나의 시스템이 계층에 따라 데이터 병렬성과 작업 병렬성을 함께 사용하는 구조이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 코어·칩·노드 경계를 섞어 스트림 수 판정 불일치 | 모든 비교 대상에 같은 분석 경계 선지정 | 동일 기준 적용으로 **분류 일관성** 확보 |
| GPU의 SIMT 프로그래밍 모델을 하드웨어 SIMD와 완전히 같은 개념으로 오인 | **명령 발행 단위**의 공통 명령과 스레드별 상태·활성 마스크를 구분 | 하드웨어 실행과 프로그래밍 모델의 개념 혼동 방지 |
| CPU·GPU·다중 노드의 이기종 시스템을 하나의 플린 유형으로 단순화 | CPU 코어·GPU 워프·노드를 계층별로 분리해 분류 | SIMD와 MIMD가 공존하는 **혼합 병렬성** 표현 |

> 요약: GPU 워프는 플린 관점에서 SIMD형 명령 발행이지만 스레드별 상태를 가진 SIMT 모델이며, 여러 GPU·노드는 MIMD로 분류한다.

#### 한줄 요약

- GPU 워프는 SIMD형 공통 명령 발행과 SIMT 스레드 상태를 함께 구분하고, 여러 GPU·노드는 독립 명령 흐름을 가진 MIMD 관점으로 분류한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **데이터 병렬성(Data Parallelism)**: 같은 연산을 서로 다른 데이터 원소들에 동시에 적용하는 병렬 방식이다.
- **작업 병렬성(Task Parallelism)**: 서로 다른 명령과 작업을 독립적인 실행 자원에서 동시에 처리하는 방식이다.
- **실행 모델(Execution Model)**: 명령이 실행 단위에 발행되고 데이터가 처리되는 규칙을 정의한 체계이다.
- **플린 유형 판정 기준**: 실행 모델의 명령·데이터 스트림 수와 병렬성 형태로 SIMD와 MIMD 등을 구분하는 기준이다.

</details>

- **플린 유형 판정 기준**에 따라 **실행 모델**이 같은 연산을 여러 데이터에 적용하는 **데이터 병렬성**이면 **SIMD**, 독립 명령과 작업을 수행하는 **작업 병렬성**이면 **MIMD**로 분류한다.

#### 한줄 요약

- 분석 경계를 먼저 고정하고 공통 명령의 데이터 병렬성은 SIMD, 독립 명령의 작업 병렬성은 MIMD로 분류한다.
