## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **플린 분류(Flynn's Taxonomy)**: 컴퓨터가 일을 할 때 뇌(명령)가 몇 개고, 먹어 치우는 밥(데이터)이 몇 개냐를 기준으로, 세상의 모든 컴퓨터 족보를 딱 4가지로 쪼개버린 반도체 학계의 절대적인 분류표이다.
- **명령 스트림(Instruction Stream)**: 컴퓨터의 뇌(제어 유닛)가 "더해라! 곱해라!" 하고 내려보내는 지시사항의 줄기 수로, 뇌가 하나면 스트림이 하나고 머리가 여러 개면 스트림도 여러 개다.
- **데이터 스트림(Data Stream)**: 뇌의 지시를 받아 연산기가 씹어먹기 위해 파이프라인으로 빨아들이는 데이터의 줄기 수로, 숟가락이 한 개냐 여러 개냐를 의미한다.

</details>

- 정의: 컴퓨터 아키텍처 분석 경계 내 **명령 스트림**과 **데이터 스트림** 수의 단일/다중 조합으로 병렬 컴퓨터 구조를 4가지로 쪼개버리는 **플린 분류** 체계
- 배경: 옛날처럼 단순히 연산기가 몇 개 달렸냐로 컴퓨터를 멍청하게 분류하던 방식의 한계를 박살 내고, 제어 흐름과 데이터 병렬화 방식을 뼛속까지 명확히 구분할 절대적 체계가 필요했기 때문

#### 한줄 요약

- 컴퓨터가 멍청한지 똑똑한지 판별하기 위해, 대가리(명령)가 한 개인지 여러 개인지, 숟가락(데이터)이 한 개인지 여러 개인지를 따져서 4가지 족보로 낙인찍는 평가표이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **독립 명령 스트림(Independent Instruction Stream)**: 남의 눈치를 보지 않고 자기 맘대로 "이거 해!"라고 독자적으로 분기하고 명령을 내릴 수 있는 진짜 뇌(제어 유닛)의 개수이다.
- **독립 데이터 스트림(Independent Data Stream)**: 뇌가 명령을 내렸을 때, 여러 개의 연산기가 각자 다른 데이터를 입에 물고 동시에 우적우적 씹어먹을 수 있는 동시 데이터 파이프라인의 수이다.
- **분석 경계(Analysis Boundary)**: 이 분류법을 들이댈 때 "코어 하나만 볼 거냐, 칩 전체를 볼 거냐, 아니면 컴퓨터 10대를 묶어서 볼 거냐"를 정하는, 말싸움을 막기 위한 평가 잣대의 범위이다.

</details>

- 제어 주체 유닛(뇌)이 1개인지 여러 개인지를 판정하는 **독립 명령 스트림** 기준 분류를 철저히 고수함.
- 동시 연산 처리 대역폭(식사량)을 결정하는 **독립 데이터 스트림** 조합을 매트릭스로 교차 평가함.
- 이게 코어 기준인지 칩 기준인지 헷갈려 치고받고 싸우는 촌극을 막기 위해, 관점의 혼선을 방지하는 **분석 경계** 지정을 강제함.

#### 한줄 요약

- 말싸움을 막기 위해 평가 범위를 딱 정해놓고, 그 안에서 진짜 뇌(명령)가 몇 개고 입(데이터)이 몇 개인지를 세어 칩의 본질을 까발린다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **2곱하기2 분류 행렬(2x2 Classification Matrix)**: 명령이 1개냐 여러 개냐, 데이터가 1개냐 여러 개냐의 두 가지 질문을 엮어서 만든 4칸짜리 무자비한 심판의 도마(표)이다.
- **코어 칩 노드 계층(Core/Chip/Node Layer)**: 현미경 렌즈 배율을 정하듯, 칩 안의 쪼그만 코어 하나를 볼지, 칩 전체를 뭉뚱그려 볼지 잣대의 크기를 정하는 계층이다.

</details>

```text
[ 플린 분류 기반 컴퓨터 아키텍처 스트림 식별 및 매핑 프레임워크 ]
       [ 인공지능 가속기 / 멀티코어 프로세서 타깃 시스템 ]
                               │
            [ 1. 싸움 방지용 분석 경계 렌즈 장착 ]
                 /                        \
 [ 2. 명령 스트림(머리 개수) 판독 ]  [ 3. 데이터 스트림(숟가락 개수) 판독 ]
                 \                        /
                  ▼                      ▼
+---------------------------------------------------------+
|                  2곱하기2(2x2) 분류 행렬                |
|               | Data: 단일 (S)    | Data: 다중 (M)      |
|---------------+-------------------+---------------------|
| Inst: 단일 (S)| SISD (고전 칩)    | SIMD (그래픽 카드)  |
| Inst: 다중 (M)| MISD (우주선 칩)  | MIMD (슈퍼 컴퓨터)  |
+---------------------------------------------------------+
```

| 구성요소 | 책임 |
|:---|:---|
| **분석 경계** 지정 | 논쟁을 막기 위해 칩, 코어, 멀티 노드 등 플린 분류를 들이댈 시스템 평가 관점 레이어를 얄짤없이 확정 |
| **명령 스트림** 수 판정 | 확정된 시스템 내에서 대가리(제어 유닛)가 하나(Single)인지 여러 개(Multiple)인지 냉혹하게 카운팅 |
| **데이터 스트림** 수 판정 | 한 번에 빨아들이는 데이터 파이프라인(숟가락)이 한 줄(Single)인지 여러 줄(Multiple)인지 무자비하게 카운팅 |
| **2곱하기2 분류 행렬** 매핑 | 카운팅 된 두 가지 잣대의 4가지 조합에 따라 최종적으로 해당 컴퓨터의 족보를 심판의 도마 위에 낙인찍음 |

#### 한줄 요약

- 어디까지 볼 건지(분석 경계) 현미경 배율을 맞추고, 뇌와 입의 개수를 세어 4칸짜리 행렬에 냅다 꽂아 칩의 정체를 폭로한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **스트림 계수(Stream Counting)**: 타깃 아키텍처 내부를 까뒤집어 제어 신호가 뿜어져 나오는 구멍과 데이터를 빨아들이는 구멍의 숫자를 현미경처럼 세어내는 작업이다.
- **분류 일관성(Classification Consistency)**: 어제는 칩 전체를 MIMD라고 부르고 오늘은 코어 하나만 떼서 SIMD라고 부르며 말을 바꾸지 않도록, 평가 레이어를 뼛속까지 고정하는 굳은 심지이다.

</details>

```text
[ 플린 분류 기반 병렬 컴퓨터 아키텍처 식별 판정 심판 흐름 ]
                               │
                               ▼
     [ 1. 엉뚱한 잣대 방지용 분석 대상 경계 확정 (코어 렌즈 장착) ]
                               │
                               ▼
 [ 2. 확정된 바운더리 안에서 통제권을 쥔 명령 스트림 수(단일/다중) 세아림 ]
                               │
                               ▼
     [ 3. 한 방에 밀어 넣는 데이터 스트림(숟가락) 수(단일/다중) 카운팅 ]
                               │
                               ▼
        [ 4. 2x2 도마 위에 뇌와 숟가락 개수 조합을 올려놓고 교차 맵핑 ]
                               │
                               ▼
      [ 5. SISD, SIMD, MISD, MIMD 중 하나의 족보로 칩의 운명 최종 낙인 ]
```

### 동작 원리

1. 분석 대상 경계 확정: 엉뚱한 해석으로 치고받는 걸 막기 위해 **스트림 계수**를 세기 위한 잣대가 코어 단위인지 칩 단위인지 기준 계층을 박아버림.
2. 명령 스트림 수 판정: 콱 박아둔 경계 내에서 독자 분기 제어(명령)를 뿜어내는 **명령 스트림**의 개수가 단일(Single)인지 다중(Multiple)인지 세아림.
3. 데이터 스트림 수 판정: 제어 유닛의 지시에 따라 동일 시점에 연산기로 인가되어 빨려 들어가는 **데이터 스트림** 파이프라인 수를 카운팅함.
4. 2곱하기2 행렬 교차 매핑: 도출된 두 가지 판정 결과를 **2곱하기2 분류 행렬** 도마 위에 가차 없이 올려놓고 4개의 칸 중 어디에 속하는지 교차 매핑함.
5. 최종 아키텍처 분류 낙인: 매핑 결과에 따라 SISD, SIMD, MISD, MIMD 중 하나의 클래스로 해당 칩의 족보 운명을 최종 선고함.

#### 한줄 요약

- 배율을 렌즈에 고정하고(경계), 뇌(명령)가 몇 개고 입(데이터)이 몇 개인지를 센 뒤, 4칸짜리 족보표에 대입해 칩의 정체를 단호하게 까발린다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **단일 명령 단일 데이터(SISD)**: 뇌가 한 개, 숟가락도 한 개인 가장 불쌍하고 단순한 컴퓨터로, 한 번에 밥 한 톨씩만 먹고 처리하는 30년 전 고전 칩이다.
- **단일 명령 다중 데이터(SIMD)**: 뇌는 하나인데 입이 100개 달린 괴물로, 대가리가 "먹어!" 하면 100개의 입이 100개의 데이터를 융단폭격으로 동시에 씹어버리는 AI 텐서 코어이다.
- **다중 명령 단일 데이터(MISD)**: 숟가락은 하나인데 잔소리하는 뇌가 여러 개인 강박증 컴퓨터로, 밥 한 톨을 두고 뇌 여러 개가 중복 감시를 하며 에러가 나면 사람이 죽는 우주선에 쓰인다.
- **다중 명령 다중 데이터(MIMD)**: 뇌도 수백 개, 숟가락도 수백 개인 완전 각자도생 칩으로, 각자 자기 할 일을 미친 듯이 따로따로 처리하는 최신 데이터센터 슈퍼컴퓨터이다.

</details>

| 2곱하기2 분류 | 명령 스트림 | 데이터 스트림 | 아키텍처 특성 | 적용 예시 칩 모델 |
|:---|:---|:---|:---|:---|
| **단일 명령 단일 데이터** (SISD) | 오직 1개 (S) | 오직 1개 (S) | 하나의 대가리가 하나의 데이터만 순차적으로 갉아먹는 클래식하고 처참히 느린 고전 방식 | 구석기 시대의 펜티엄이나 극도로 단순한 파이프라인 스칼라 CPU 코어 1개 |
| **단일 명령 다중 데이터** (SIMD) | 오직 1개 (S) | 여러 개 (M) | 대가리는 하난데 입이 여러 개라, 데이터 레인을 미친 듯이 융단폭격으로 동시에 쳐내는 효율의 끝판왕 | 인텔 에이브이엑스(AVX) 벡터 확장명령어 레인 및 딥러닝 텐서(행렬) 코어 덩어리 |
| **다중 명령 단일 데이터** (MISD) | 여러 개 (M) | 오직 1개 (S) | 데이터 하나를 두고 여러 대가리가 중복해서 물어뜯으며 교차 검증하는 강박증 편집증 구조 | 단 한 번의 에러로 칩이 뻗으면 사람 목숨이 날아가는 우주 항공용 결함 허용(Fault-tolerant) 칩 |
| **다중 명령 다중 데이터** (MIMD) | 여러 개 (M) | 여러 개 (M) | 대가리도 여러 개고 데이터 파이프도 여러 개라 각자도생으로 미친 듯이 비동기로 연산하는 난장판 방식 | 최신 인텔/AMD 멀티코어 프로세서 및 클러스터로 묶인 거대 분산 슈퍼컴퓨터 노드 |

#### 한줄 요약

- 뇌 1 데이터 1은 옛날 컴퓨터, 뇌 1 데이터 100개 융단폭격은 딥러닝 GPU, 뇌 3 데이터 1 감시망은 우주선 칩, 뇌 100 데이터 100 난장판은 최신 데이터센터 서버이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **단일 명령 다중 스레드(Single Instruction Multiple Threads)**: 엔비디아가 자기네 GPU를 홍보하려고 만든 소프트웨어 용어로, 하드웨어 뼈대인 SIMD와 헷갈리게 섞어 써서 사람들을 미치게 만드는 낚시성 실행 모델이다.
- **혼합 병렬성(Hybrid Parallelism)**: 요즘 칩들이 하도 짬뽕이라, 칩 껍데기를 보면 MIMD인데 코어 안쪽 현미경을 들이대면 SIMD 코어가 돌아가고 있는 이중인격 구조이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 렌즈를 들이댈 코어 관점인지 칩 관점인지 분석 레이어를 멋대로 뇌피셜로 해석하여 칩 분류가 엉망진창으로 꼬이는 혼선 | **분석 경계**를 평가 전 멱살 잡고 서면으로 강제 명시하며, 계층별 수용 범위를 엄격하게 고정 타격 | **분류 일관성**을 100% 사수하고 학술적 논쟁과 쓸데없는 말싸움을 완벽 박멸하는 객관성 확보 |
| 그래픽 카드의 소프트웨어 **단일 명령 다중 스레드**(SIMT) 모델을 플린의 뼈대 하드웨어 SIMD와 동일시하는 치명적 멍청한 오인 | 붕어빵 틀(소프트웨어 스레드 제어)과 붕어빵 기계(물리 연산 레인)의 계층을 단호히 쪼개서 분리 명시 통제 | 마케팅 용어에 낚이지 않고 칩의 뼛속 하드웨어 아키텍처 관점에서의 족보를 헷갈리지 않고 정확히 식별 |
| 최신 인공지능 멀티코어 칩은 한 계층에 다중 코어와 벡터 코어가 지독하게 짬뽕되어 단순 단일 클래스로 욱여넣을 수 없음 | 시스템 계층 렌즈 배율에 따라 코어 밖은 MIMD, 코어 안은 SIMD로 부르는 **혼합 병렬성** 하이브리드 이중 표기 적용 | 복합 분산 아키텍처의 다중 계층 짬뽕 특성을 완벽히 수용하고 낡은 플린 분류의 평가 한계 박살 돌파 |

#### 한줄 요약

- 말싸움을 막기 위해 분석 범위를 칼같이 적고, 엔비디아의 마케팅(SIMT)에 속지 않으며, 요즘 칩은 겉과 속이 다른 짬뽕(하이브리드)이니 이중 잣대를 들이대야 정확하다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **플린 유형 판정 기준(Flynn's Classification Criteria)**: 수천만 원짜리 인공지능 칩을 샀을 때, 이 칩이 진짜 병렬 연산 괴물인지 아니면 속 빈 강정인지 뇌(명령)와 입(데이터)의 개수를 뜯어보고 낙인찍는 잔인한 평가 지표이다.

</details>

- **플린 유형 판정 기준**에 따라 명령 스트림과 데이터 스트림의 단일/다중 조합으로 칩의 운명을 **SISD·SIMD·MISD·MIMD** 4가지 중 하나로 가차 없이 판정함

#### 한줄 요약

- 현미경 배율(분석 경계)을 고정한 상태에서, 뇌(명령)와 입(데이터)의 조합을 까발려 칩의 정체를 단호하게 4가지 중 하나로 쑤셔 박는다.
