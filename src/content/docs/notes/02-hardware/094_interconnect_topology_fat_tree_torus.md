## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **인터커넥트 토폴로지**: 연산 노드•스위치•링크의 물리•논리 연결 형태이다.
- **팻트리**: 상위 계층으로 갈수록 링크 용량이나 수를 늘린 계층형 스위치 망이다.
- **토러스**: 각 차원의 끝단을 연결하여 순환 경로를 만든 격자형 노드 망이다.

</details>

- 정의/개념: **인터커넥트 토폴로지**는 연산 노드와 스위치•라우터 및 링크의 연결 형태로 패킷 경로, 망 지름과 양분 대역폭을 결정하는 네트워크 구조이다.
- 배경/필요성: 전역 집단 통신과 최근접 이웃 통신은 트래픽 행렬이 달라 같은 연결 구조에서도 서로 다른 링크에 대역폭•지연 병목이 생긴다.

#### 한줄 요약

- 전역 집단 통신과 최근접 이웃 통신 패턴에 따라 **팻트리** 또는 **토러스**를 결정한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **양분 대역폭**: 망을 같은 크기의 두 노드 집합으로 나눌 때 그 사이를 잇는 최소 총 링크 용량이다.
- **오버서브스크립션**: 하향 포트의 총대역폭이 상향 포트의 총대역폭을 초과하는 상태이다.
- **망 지름**: 망에서 가장 먼 두 노드 사이의 최소 홉 수이다.
- **동일 비용 다중 경로(Equal-Cost Multi-Path, ECMP)**: 비용이 같은 여러 경로에 흐름을 해시로 분산하는 방식이다.

</details>

- 높은 노드 차수는 배선 비용을 늘리고, 큰 **망 지름**은 최대 홉 수를 늘린다.
- 팻트리는 높은 **양분 대역폭**과 **ECMP**로 전체 축약을 지원한다.
- 토러스는 순환 최근접 연결로 인접 통신 비용을 줄인다.

#### 한줄 요약

- **양분 대역폭**과 **망 지름** 및 배선 비용 사이에는 상충 관계가 있다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **연산 노드(Compute Node)**: 목적지와 데이터를 담은 패킷을 생성•수신하는 구성이다.
- **리프 스위치(Leaf Switch)**: 연산 노드를 수용하고 스파인 상향 경로를 제공하는 구성이다.
- **스파인 스위치(Spine Switch)**: 모든 리프 사이의 전역 다중 경로를 제공하는 구성이다.
- **토러스 라우터(Torus Router)**: 목적 좌표와 혼잡 상태로 이웃 방향을 선택하는 구성이다.
- **순환 링크(Wraparound Link)**: 각 차원의 끝단을 연결하여 대체 경로를 제공하는 구성이다.

</details>

```text
                 [연산 노드]
                  /       \
       [리프 스위치]     [토러스 라우터]
              |                 |
       [스파인 스위치]      [순환 링크]
```

선의 의미: 왼쪽 가지는 팻트리의 노드•리프•스파인 계층이고, 오른쪽 가지는 토러스의 노드•라우터•순환 링크 연결 구조를 뜻한다.

| 구성요소 | 책임 |
|:---|:---|
| 연산 노드 | 패킷 생성•수신 |
| 리프 스위치 | 종단 수용•상향 전달 |
| 스파인 스위치 | 전역 다중 경로 제공 |
| 토러스 라우터 | 좌표 기반 전달 |
| 순환 링크 | 끝단•대체 경로 연결 |

#### 한줄 요약

- **리프 스위치**와 **스파인 스위치**의 계층 경로 및 **토러스 라우터**와 **순환 링크**의 순환 경로 구조이다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **패킷 주입**: 연산 노드가 목적지와 데이터를 담은 패킷을 로컬 네트워크 장비에 넣는 동작이다.
- **적응 라우팅**: 링크의 혼잡•장애 상태에 따라 패킷의 전송 경로를 바꾸는 방식이다.
- **교착**: 패킷들이 서로 점유한 자원을 기다리며 모두 진행하지 못하는 상태이다.
- **리프 패킷 주입**: 출발 노드가 목적 주소와 데이터를 가까운 리프 스위치에 전달하는 단계이다.
- **ECMP 상향 경로 선택**: 동일 비용의 스파인 경로 중 하나를 고르는 단계이다.
- **목적 리프 하향 전달**: 스파인에서 목적 노드가 연결된 리프로 패킷을 전달하는 단계이다.
- **목적 좌표 방향 선택**: 토러스의 현재 좌표에서 다음 이동 차원을 고르는 단계이다.
- **이웃 홉 전달**: 순환 링크로 이웃 라우터에 보내 목적 좌표까지 반복하는 단계이다.

</details>

```text
팻트리 경로
[출발 노드]
     │
     ▼ 1. 리프 패킷 주입
[리프 스위치]
     │
     ▼ 2. ECMP 상향 경로 선택
[스파인 스위치]
     │
     ▼ 3. 목적 리프 하향 전달
[목적 노드]

토러스 경로
[출발 노드]
     │
     ▼ 4. 목적 좌표 방향 선택
[토러스 라우터]
     │
     ▼ 5. 이웃 홉 전달
[목적 좌표 도달?]
     ├─ 아니오: 4단계로 반복
     └─ 예: [목적 노드]
```

### 동작 원리

1. **리프 패킷 주입**: 팻트리에서는 출발 노드가 목적 주소와 데이터를 가까운 리프 스위치에 전달한다.
2. **ECMP 상향 경로 선택**: 리프 스위치가 동일 비용의 스파인 경로 가운데 하나를 해시나 혼잡 정책으로 선택한다.
3. **목적 리프 하향 전달**: 스파인 스위치가 목적 노드가 연결된 리프로 패킷을 내려보내고 해당 리프가 목적 노드에 전달한다.
4. **목적 좌표 방향 선택**: 토러스에서는 현재 좌표와 목적 좌표의 차이 및 허용된 혼잡 정책으로 다음 이동 차원을 고른다.
5. **이웃 홉 전달**: 선택한 순환 링크로 이웃 라우터에 전달하고 목적 좌표에 도달할 때까지 4~5단계를 반복한다.

#### 한줄 요약

- 팻트리는 **ECMP 상향 경로 선택**과 **목적 리프 하향 전달**, 토러스는 **목적 좌표 방향 선택**과 **이웃 홉 전달**로 패킷을 전달한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **집단 통신**: 여러 프로세스가 방송•수집•축약 같은 공동 데이터 교환에 참여하는 통신이다.
- **최근접 이웃 통신**: 각 노드가 토폴로지에서 인접한 소수 노드와 반복적으로 데이터를 교환하는 패턴이다.

</details>

| 망 토폴로지 | 팻트리 | 토러스 |
|:---|:---|:---|
| 적용 기준 | 전역 집단 통신 중심 작업 | 최근접 이웃 통신 중심 작업 |
| 핵심 특징 | 리프•스파인 계층의 다중 경로 | 차원별 이웃의 순환 경로 |
| 한계 | 상위 스위치•포트•케이블 비용 | 먼 노드의 홉•혼잡 증가 |

> 요약: 전역 집단 통신은 **팻트리**, 최근접 이웃 통신은 **토러스**를 선택한다.

#### 한줄 요약

- 높은 양분 대역폭이 필요한 **집단 통신**에는 팻트리, **최근접 이웃 통신**이 반복되는 작업에는 토러스가 유리하다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **통신 행렬**: 출발•목적 노드 쌍별 통신량을 나타낸 표이다.
- **꼬리 지연**: 지연 분포의 상위 백분위에 해당하는 느린 패킷의 지연이다.
- **장애 주입(Fault Injection)**: 링크나 스위치 장애를 의도적으로 발생시키는 시험이다.
- **경로 재수렴(Path Reconvergence)**: 장애 후 라우팅이 새 정상 경로로 안정되는 과정이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 평균 대역폭만 보면 집단 통신 혼잡 누락 | **통신 행렬**로 **양분 대역폭**과 **꼬리 지연** 시험 | 토폴로지 적합성 검증 |
| 팻트리 **오버서브스크립션**으로 상위 링크 병목 | 트래픽 배치•상향 용량과 **ECMP** 조정 | 전역 통신 처리량 확보 |
| 토러스 장거리 흐름이 다수 홉을 점유해 **교착**•혼잡 유발 | 교착 회피 경로와 **적응 라우팅** | 홉•혼잡 감소 |
| 링크•스위치 장애로 우회 경로 편중 | **장애 주입**과 **경로 재수렴** 및 축소 대역폭 감시 | 장애 성능 예측성 향상 |

#### 한줄 요약

- 전체 축약에는 높은 **양분 대역폭**과 **ECMP** 다중 경로를 확보한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **토폴로지 인지 배치**: 통신량이 큰 작업을 서로 가까운 노드에 배치하는 기법이다.
- **전체 축약(All-Reduce)**: 모든 노드의 값을 축약한 결과를 다시 모든 노드에 배포하는 집단 통신이다.
- **토폴로지 선택 기준**: 통신 행렬의 전역·인접 비중과 대역폭 및 비용 제약에 따라 망 구조를 고르는 기준이다.

</details>

- **토폴로지 선택 기준**에 따라 **전체 축약** 같은 전역 집단 통신은 **팻트리**, **토폴로지 인지 배치**가 가능한 최근접 이웃 통신은 **토러스**를 선택한다.

#### 한줄 요약

- **통신 행렬**의 전역•최근접 비중과 비용 제약을 측정하여 팻트리 또는 토러스를 선택한다.
