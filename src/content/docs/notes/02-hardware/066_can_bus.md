## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **CAN(Controller Area Network)**: 차량 및 산업용 기기 내에서 마이크로컨트롤러(ECU) 간에 호스트 컴퓨터 없이 직접 통신을 가능하게 하는 표준 직렬 버스 네트워크.
- **메시지 식별자(CAN ID)**: 노드의 물리 주소가 아닌 데이터의 종류와 송신 우선순위를 나타내는 11비트(표준) 또는 29비트(확장) 헤더.

</details>

- 정의/개념: **메시지 식별자(CAN ID)** 기반 우선순위 중재와 에러 결함 격리를 지원하는 2선식 차동 직렬 통신 **CAN** 버스
- 배경/필요성: 기존 점대점 일대일 배선 구조로는 **제어기 증가에 따른 와이어링 하네스 중량 폭증 및 노이즈 극복 불가**

#### 한줄 요약
- CAN은 노드 주소 대신 메시지 ID 기반 우선순위로 버스를 중재하고 차동 꼬임선으로 노이즈를 상쇄하는 차량용 표준 네트워크다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **비파괴 비트 단위 중재(Non-Destructive Bitwise Arbitration)**: 여러 노드가 동시 송신할 때 우성(Dominant, 0) 비트를 보낸 노드가 버스를 계속 차지하고 열성(Recessive, 1) 노드는 즉시 수신으로 전환되어 충돌 손실이 없는 방식.
- **버스 오프(Bus-Off)**: 특정 노드의 전송 에러 카운터(TEC)가 255를 초과하면 버스 전체의 마비를 막기 위해 해당 노드를 버스에서 강제 격리하는 안전 기능.

</details>

- 물리 주소 없이 메시지 식별자로 방송(Broadcast)하고 수신 측이 하드웨어 필터링
- 동시 송신 시에도 **비파괴 비트 단위 중재** 기반으로 충돌 지연 없는 우선순위 통신 보장
- 에러 카운터 기반 3단계 결함 상태 전이를 거쳐 최종적으로 **버스 오프** 결함 노드 분리

#### 한줄 요약
- 비파괴 중재로 데이터 충돌 손실을 방지하고, 에러 카운터 기반 버스 오프 기능으로 결함 노드를 자동 격리한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **CAN 컨트롤러**: 메시지 프레임 생성, 비트 스터핑, CRC 계산, 에러 카운팅을 수행하는 디지털 로직.
- **CAN 트랜시버**: 로직 레벨(0/1) 신호를 CAN_H, CAN_L 차동 전압 신호로 변환하는 아날로그 PHY 칩.

</details>

```text
[CAN 노드 및 버스 토폴로지]
|-- CAN 노드 (ECU)
|   |-- 마이크로컨트롤러 (호스트 CPU)
|   |-- CAN 컨트롤러 (프레임화·비트 스터핑·CRC·중재 로직)
|   |-- 하드웨어 수신 필터 (관심 CAN ID 선별 수신)
|   `-- CAN 트랜시버 (TxD/RxD 로직 <-> CAN_H/CAN_L 차동 전압)
`-- 차동 꼬임선 버스 (Twisted Pair)
    |-- CAN_H (우성 시 3.5V / 열성 시 2.5V)
    |-- CAN_L (우성 시 1.5V / 열성 시 2.5V)
    `-- 120Ω 종단 저항 (양 끝단 반사파 흡수)
```

선의 의미: 계층 및 물리 신호 구조

| 구성요소 | 책임 |
|:---|:---|
| **CAN 컨트롤러** | 프레임 생성, 비트 단위 중재, 비트 스터핑, CRC 계산 및 결함 상태 관리 |
| **CAN 트랜시버** | 로직 전압을 CAN_H/CAN_L 차동 전압으로 변환하여 물리선 구동 |
| 차동 꼬임선 버스 | 동상 노이즈(Common Mode Noise)를 상쇄하여 전자파 내성 확보 |
| 120Ω 종단 저항 | 버스 양 끝단에서 전송 신호 반사파를 흡수하여 파형 왜곡 방지 |
| 수신 메시지 필터 | 호스트 인터럽트 없이 관심 ID 프레임만 선별 수용 |

#### 한줄 요약
- CAN 컨트롤러, 트랜시버, 차동 꼬임선 및 120Ω 종단 저항이 결합되어 고신뢰성 제어망을 구성한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **우성(Dominant 0) vs 열성(Recessive 1)**: 두 노드가 동시에 0과 1을 보내면 버스에는 전압차가 발생하여 물리적으로 '0'이 승리하는 원리.

</details>

```text
버스 유휴(Idle) 감지 → 대기 노드들이 동시에 송신 시작
        │
   CAN ID 비트를 한 클록씩 송출하며 버스 실제 값과 비교
        │
   내가 보낸 비트와 버스 모니터링 값이 일치하는가?
   ┌────┴─────┐
  예           아니오 (열성 1 송출 중 우성 0 감지)
   │             │
다음 비트 계속   즉시 송신 중단 및 수신 모드로 전환 (중재 패배)
   │             (데이터 손상 없음)
   │
중재 승리 → 데이터 필드 및 CRC 송출 완료
        │
   수신 노드가 ACK 슬롯에 우성(0) 비트를 응답했는가?
   ┌────┴─────┐
  예           아니오 (ACK 에러)
   │             │
전송 성공      에러 카운터(TEC) 증가 후 재전송 시도
```

#### 한줄 요약
- 비트 단위 전압 비교로 식별자 숫자가 낮은(우성 비트가 많은) 고순위 메시지가 지연 없이 버스를 차지한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **CAN FD(Flexible Data-rate)**: 페이로드를 최대 64바이트로 확장하고 데이터 구간 전송 속도를 최대 5~8Mbps로 가변 가속하는 표준.
- **LIN(Local Interconnect Network)**: 1선식 UART 기반의 초저가 서브네트워크로 도어, 시트, 와이퍼 등 비핵심 전장 제어에 사용.

</details>

| 차량용 네트워크 프로토콜 | Classical CAN 2.0 | CAN FD | LIN | Automotive Ethernet |
|:---|:---|:---|:---|:---|
| 적용 기준 | 엔진/변속기/바디 기본 제어 네트워크 | 대용량 센서/ADAS 제어 데이터 전송 | 도어/시트/창문 등 초저가 서브네트워크 | 자율주행 라이다/카메라/도메인 제어기 |
| 핵심 특징 | 명목 1Mbps 이하와 8바이트 페이로드 | 데이터 구간 가변 속도와 64바이트 페이로드 | 1선식 UART 기반 스케줄 통신 | 스위치 기반 고속 IP 통신 |
| 한계 | 대역폭 부족으로 대규모 데이터 전송 불가 | 트랜시버 교체 필요 및 배선 토폴로지 민감 | 극저속 및 마스터 단일 제어로 응답성 한계 | 높은 케이블/트랜시버 단가 및 전력 소비 |

#### 한줄 요약
- 기본 제어는 CAN, 대용량 실시간 전송은 CAN FD, 단순 편의 장치는 LIN, 자율주행 백본은 차량용 이더넷을 적용한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **비트 스터핑(Bit Stuffing)**: 동일한 비트가 5개 연속되면 동기 유지를 위해 반대 극성의 비트 1개를 강제로 삽입하는 규칙.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 결함 노드가 에러 프레임을 반복 송출해 버스 마비 | 에러 카운터 기반 3단계(Active/Passive/Bus-Off) 격리 | 불량 노드 자동 차단 및 네트워크 무중단 보장 |
| 종단 저항 미부착에 따른 신호 반사파 왜곡 | 버스 양단에 120Ω 금속피막 저항 정확한 실장 | 신호 무결성(SI) 확보 및 에러 프레임 제거 |
| 브로드캐스트 특성으로 인한 메시지 스푸핑 위협 | SecOC(Secure Onboard Communication) 암호화 MAC | 패킷 위변조 및 재전송 공격 차단 |
| 버스 부하율 70% 초과 시 저순위 메시지 기아 | 버스 분할(Sub-bus) 및 CAN FD 전환 대역폭 확장 | 최악 응답 시간(WCRT) 마감시간 이내 보장 |

#### 한줄 요약
- 버스 오프 안전 메커니즘, 종단 저항 실장, SecOC 암호 인증, CAN FD 전환을 통해 신뢰성과 대역폭을 확보한다.

## Ⅶ. 결론

- 차량 섀시·파워트레인 제어는 **CAN/CAN FD 버스**를 구축하고, 보안성 강화를 위해 **SecOC 메시지 인증** 및 게이트웨이 침입 탐지 시스템(IDS) 연계

#### 한줄 요약
- CAN 버스는 비파괴 중재와 하드웨어 결함 격리를 통해 40년간 검증된 자동차 전장 네트워크의 핵심 표준이다.
