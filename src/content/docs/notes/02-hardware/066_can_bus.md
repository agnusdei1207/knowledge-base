## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **CAN(Controller Area Network, ISO 11898)**: 차량 및 산업용 분산 제어 환경에서 마이크로컨트롤러(ECU) 간에 호스트 컴퓨터 없이 2선식 차동 버스를 통해 고신뢰성 통신을 지원하는 표준 직렬 통신 네트워크.
- **메시지 식별자(CAN ID)**: 노드의 물리적 하드웨어 주소가 아닌 전송 데이터의 의미(엔진 RPM, 차속 등)와 우선순위를 나타내는 11비트(표준) 또는 29비트(확장) 헤더.

</details>

- 정의/개념: **메시지 식별자(CAN ID)** 기반의 비파괴 비트 중재와 하드웨어 결함 격리(Bus-Off)를 지원하는 2선식 차동 직렬 통신 **CAN(Controller Area Network) 아키텍처**
- 배경/필요성: 제어기 증가에 따른 일대일 점대점 배선의 **와이어링 하네스 중량 및 원가 폭증과 차량 내부 극심한 전자파 노이즈(EMI) 극복**

#### 한줄 요약
- CAN은 노드 주소 대신 메시지 ID 우선순위로 버스를 중재하고 차동 꼬임선으로 노이즈를 상쇄하는 차량용 표준 네트워크 기술이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **비파괴 비트 단위 중재(Non-Destructive Bitwise Arbitration)**: 복수 노드가 동시 송신할 때 우성(Dominant 0) 비트를 전송한 노드가 버스를 계속 점유하고 열성(Recessive 1) 노드는 즉시 수신으로 전환되어 데이터 충돌 손실이 없는 메커니즘.
- **버스 오프(Bus-Off)**: 전송 에러 카운터(TEC)가 255를 초과한 결함 노드를 버스 선로에서 물리적으로 강제 격리하여 네트워크 전체 마비를 차단하는 안전 기능.

</details>

- 방송(Broadcast) 및 하드웨어 필터링: 모든 노드가 버스 프레임을 수신하되, **수신 필터(Acceptance Filter)**를 통해 관심 ID만 인터럽트 수신
- 무손실 우선순위 보장: **비파괴 비트 단위 중재**를 통해 충돌에 따른 백오프 재전송 지연 없이 고우선순위 메시지의 100% 즉시 전송 보장
- 자동 결함 격리: 에러 카운터 기반 3단계 전이(Error-Active ➔ Error-Passive ➔ **Bus-Off**)를 통해 결함 노드를 자동 분리

#### 한줄 요약
- 비파괴 중재로 충돌 지연을 없애고, 에러 카운터 기반 버스 오프로 결함 노드를 자동 격리하여 신뢰성을 확보한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **CAN 컨트롤러(CAN Controller)**: 프레임 패킷화, 비트 스터핑, CRC 검증, 비트 중재 및 에러 카운팅을 하드웨어로 수행하는 디지털 로직.
- **CAN 트랜시버(CAN Transceiver)**: 디지털 로직 레벨(TxD/RxD 0/1) 신호를 CAN_H, CAN_L 차동 전압 레벨로 상호 변환하는 아날로그 물리 계층(PHY) 칩.
- **차동 꼬임선(Twisted Pair)**: 두 전선을 꼬아 외부 동상 노이즈(Common-Mode Noise)가 두 선에 동일하게 유입되도록 하여 수신단 차동 증폭기로 노이즈를 100% 상쇄하는 배선.

</details>

```text
[CAN 노드 및 차동 버스 토폴로지]
 ┌─ [CAN 노드 (ECU 0)]                 ┌─ [CAN 노드 (ECU 1)]                 ┌─ [CAN 노드 (ECU N)]
 │   ├─ 호스트 MCU (마이크로컨트롤러)   │   ├─ 호스트 MCU (마이크로컨트롤러)   │   ├─ 호스트 MCU (마이크로컨트롤러)
 │   ├─ [CAN 컨트롤러 (중재 / CRC)]    │   ├─ [CAN 컨트롤러]                 │   ├─ [CAN 컨트롤러]
 │   └─ [CAN 트랜시버 (TxD/RxD PHY)]   │   └─ [CAN 트랜시버]                 │   └─ [CAN 트랜시버]
 └─────────────┬───────────────────────┘─────────────┬───────────────────────┘─────────────┬───────────────────────┘
               │ (CAN_H / CAN_L)                     │ (CAN_H / CAN_L)                     │ (CAN_H / CAN_L)
 ══════════════╪═════════════════════════════════════╪═════════════════════════════════════╪══════════════════════
 [120Ω 종단저항]─────────────────────────────────────────────────────────────────────────────[120Ω 종단저항]
                              공통 차동 꼬임선 버스 (CAN_H: 3.5V, CAN_L: 1.5V / Dominant)
```

선의 의미: 가지(`├─`, `└─`)는 하드웨어 소속 및 포함 관계; 양 끝단의 120Ω 종단 저항이 반사파를 흡수하고 차동 신호가 버스를 공유함

| 구성요소 | 소속 및 위치 | 핵심 엔지니어링 책임 | 주요 특징 |
|:---|:---|:---|:---|
| **호스트 MCU** | ECU 두뇌 | 센싱 데이터 처리 및 CAN 전송 메시지 버퍼 큐잉 | 32-bit 전장용 코어 |
| **CAN 컨트롤러** | MCU 내부/외장 | **프레임화, 비트 중재, 비트 스터핑, CRC 검증, TEC/REC 에러 관리** | 하드웨어 로직 |
| **CAN 트랜시버** | ECU 물리단 | 로직 신호와 **CAN_H / CAN_L 차동 전압 상호 변환** | 고전압 보호 회로 |
| **차동 꼬임선** | 차량 하네스 | 외부 전자기 간섭(EMI) 노이즈 상쇄 및 2선식 멀티드롭 버스 제공 | Twisted Pair 배선 |
| **120Ω 종단 저항** | 버스 양 끝단 | 고주파 신호 전송 시 선로 끝에서 발생하는 **신호 반사파 흡수** | 신호 무결성(SI) 확보 |

#### 한줄 요약
- CAN 시스템은 호스트 MCU, CAN 컨트롤러, CAN 트랜시버, 차동 꼬임선 및 양단 120Ω 종단 저항으로 구성된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **우성(Dominant 0) vs 열성(Recessive 1)**: 두 노드가 동시에 0과 1을 송출하면 버스 라인은 2.0V 차동 전압이 발생하여 물리적으로 우성인 '0' 상태가 승리하는 와이어드-AND(Wired-AND) 논리.

</details>

```text
1. 버스 유휴(Bus Idle: 연속 11비트 열성 1) 감지 ➔ 복수 노드가 SOF(Start of Frame) 송출
                      │
                      ▼
2. CAN ID(11비트)를 MSB부터 1비트씩 버스로 송출함과 동시에 버스 실제 전압 모니터링
                      │
                      ▼
3. 내가 송출한 비트와 버스 모니터링 전압 레벨이 일치하는가?
   ┌──────────────────┴──────────────────┐
[ 일치 (우성 0 전송 중 우성 0 감지) ]  [ 불일치 (열성 1 전송 중 우성 0 감지) ]
   │                                     │
   ▼                                     ▼
4. 다음 식별자 비트 계속 송출            4. 즉각 송신 중단 ➔ 수신 모드로 자동 전환 (중재 패배!)
   │                                     │ (데이터 충돌 손상 0화, 전송 지연 없음)
   ▼                                     │
5. 중재 승리 ➔ 데이터(8B) 및 CRC 송출 완료 │
   │                                     │
   ▼                                     │
6. 수신 노드가 ACK 슬롯에 우성(0) 응답   │
   ┌──────────────────┴──────────────────┤
[ ACK 수신 성공 ]                     [ ACK 실패 / CRC 에러 ]
   │                                     │
   ▼                                     ▼
7. 전송 성공 ➔ 다음 메시지 처리          7. 전송 에러 카운터(TEC) 증가 ➔ 자동 재전송 시도
```

분기 결과: **식별자 숫자가 낮을수록(우성 0이 많을수록)** 중재에서 승리하여 지연 없이 전송되며, **패배한 노드는** 손실 없이 즉시 수신으로 전환됨

#### 한줄 요약
- 버스 감지 ➔ ID 비트 송출 및 비교 ➔ 중재 승리 시 데이터 전송 / 패배 시 수신 전환 ➔ ACK 확인 및 에러 카운팅 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **CAN FD(Flexible Data-rate)**: 데이터 필드 전송 속도를 최대 5~8Mbps로 가변 가속하고 페이로드를 최대 64바이트로 확장한 차세대 CAN 표준.
- **LIN(Local Interconnect Network)**: 단일 마스터-다중 슬레이브 구조의 1선식 UART 기반 초저가 차량용 서브네트워크.

</details>

| 차량용 통신 프로토콜 | Classical CAN 2.0A/B | CAN FD (Flexible Data-rate) | LIN (Local Interconnect) | 차량용 이더넷 (Automotive) |
|:---|:---|:---|:---|:---|
| 전송 속도 (대역폭) | **최대 1 Mbps** | **최대 5 ~ 8 Mbps (가변 가속)**| 최대 20 kbps (저속) | **100 Mbps ~ 10 Gbps (초고속)**|
| 최대 페이로드 크기 | **8 바이트 (Bytes)** | **64 바이트 (Bytes)** | 8 바이트 | 1500 바이트 (표준 프레임) |
| 버스 토폴로지 | 2선식 멀티드롭 차동 버스 | 2선식 멀티드롭 차동 버스 | 1선식 단일 버스 (Single Wire)| 스위치 기반 점대점 스타형 |
| 주요 적용 분야 | **엔진, 변속기, ABS 기본 제어** | **ADAS 센서, 차량 섀시 통합 제어**| **도어 록, 시트 조절, 창문, 미러** | **자율주행 라이다/카메라, 도메인 제어** |

#### 한줄 요약
- 기본 제어에는 CAN 2.0, 대용량 실시간 제어에는 CAN FD, 단순 편의 장치에는 LIN, 대용량 센서/백본에는 차량용 이더넷이 쓰인다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **SecOC(Secure Onboard Communication)**: AUTOSAR 표준 보안 프로토콜로, CAN 메시지에 메시지 인증 코드(MAC)와 신선도 값(Freshness Value)을 부착하여 스푸핑 및 재전송 공격을 차단하는 기술.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 결함 노드가 에러 프레임을 폭주 송출하여 버스 마비 | **에러 카운터 기반 3단계(Active ➔ Passive ➔ Bus-Off) 자동 격리** | 불량 노드 100% 격리 및 네트워크 무중단 사수 |
| 종단 저항 미부착 또는 파손으로 인한 신호 반사파 왜곡 | **버스 양단 끝단에 $120\Omega$ 금속 피막 저항 정밀 실장** | 신호 무결성(SI) 확보 및 비트 에러 0화 |
| 브로드캐스트 특성으로 인한 메시지 위변조/스푸핑 위협 | **AUTOSAR SecOC(Secure Onboard Communication) MAC 인증** | 패킷 위변조 및 재생(Replay) 공격 원천 차단 |

#### 한줄 요약
- 실무에서는 Bus-Off로 결함을 격리하고, 120Ω 종단 저항으로 반사파를 막으며, SecOC로 보안 위변조를 차단한다.

## Ⅶ. 결론

- 차량 섀시 및 파워트레인의 실시간 결정론적 제어를 위해 **비파괴 중재와 하드웨어 결함 격리를 제공하는 CAN 및 CAN FD 버스를 표준 채택**하고, 전자기 노이즈 내성을 위해 **120Ω 종단 저항과 차동 꼬임선 물리 계층**을 구축하며, 커넥티드 카 보안을 위해 **AUTOSAR SecOC 암호 인증 체계**를 필수 연동하는 고신뢰 전장 통신 아키텍처 확립

#### 한줄 요약
- CAN 버스는 비파괴 중재와 Bus-Off 결함 격리를 통해 40년간 검증된 자동차 전장 네트워크의 핵심 표준이다.
