## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **암바(Advanced Microcontroller Bus Architecture, AMBA)**: 스마트폰 칩(SoC) 안에 들어가는 수십 개의 칩셋 부품들이 서로 치고받지 않고 우아하게 데이터를 주고받게 만든 Arm 사의 절대 표준 도로교통법 규격이다.
- **시스템 온 칩(System on Chip, SoC)**: CPU, 그래픽카드, 메모리 핀 아웃 등 컴퓨터 한 대 분량의 부품을 손톱만 한 칩 한 개에 전부 다 쑤셔 박아버린 통합 칩이다.
- **거래(Transaction)**: 버스 고속도로 위에서 "야, 이 주소에 데이터 좀 써라!" 하고 명령을 날리고 "알았어" 하고 답을 받는 한 사이클의 데이터 택배 배송 과정이다.

</details>

- 정의: SoC 기능 블록 간 통신 신호와 **거래** 프로토콜을 계층별로 칼같이 규정해 놓은 Arm 사의 뼈대 설계도인 **암바**
- 배경: 칩 안에 CPU, 램, USB 부품(IP)을 우겨넣을 때 제조사마다 선 꽂는 방식이 달라서 땜질하다 칩이 박살 나는 참사를 막고 칩 통합 설계의 멱살을 잡고 하드캐리하기 위함

#### 한줄 요약

- 칩 하나에 쑤셔 넣은 온갖 부품들이 싸우지 않고 데이터를 주고받게 만드는 Arm 사의 절대적인 도로망 표준 설계도이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **에이엑스아이(Advanced eXtensible Interface, AXI)**: 8차선 고속도로를 뚫어놓고 대답 듣기도 전에 다음 택배를 미친 듯이 쏴버리는(미완료 거래) 최고성능 온칩 버스 규격이다.
- **에이에이치비(Advanced High-Performance Bus, AHB)**: 주소를 쏘고 나서 숨도 안 쉬고 데이터를 겹쳐 쏘는 파이프라인 방식으로 욱여넣는 가성비 시스템 버스 규격이다.
- **에이피비(Advanced Peripheral Bus, APB)**: 타이머나 키보드 같은 느려 터진 부품들을 연결하는 골목길 버스로, 그냥 껐다 켰다 하는 수준의 초저전력 규격이다.
- **미완료 거래(Outstanding Transaction)**: "이전 택배 잘 받았냐?" 대답 듣기도 전에 일단 다음 택배부터 냅다 갈겨버려서 파이프라인을 100% 쥐어짜는 상남자식 전송 기법이다.

</details>

- 칩 안의 고속도로인 **에이엑스아이**는 5개의 전용 차선을 뚫어놓고 묻지마 버스트(**미완료 거래**)를 갈겨버리는 최고성능 규격임.
- 중간급 국도인 **에이에이치비**는 주소와 데이터를 겹쳐서 파이프라인으로 밀어붙이는 시스템 버스 규격임.
- 동네 골목길인 **에이피비**는 2단계로만 껐다 켰다 하는, 속도는 느리지만 전기를 극단적으로 아끼는 주변장치 제어용 버스 규격임.

#### 한줄 요약

- 속도 무제한 고속도로(AXI), 적당히 빠른 국도(AHB), 느리지만 전기를 아끼는 골목길(APB)로 칩 내부 도로망을 계층화한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **관리자 블록(Manager Block)**: "거기 메모리! 당장 데이터 내놔!" 라며 능동적으로 거래를 던지며 버스를 호령하는 갑질 블록(CPU, DMA 등)이다.
- **대상 블록(Subordinate/Target Block)**: 관리자한테 명령을 받아먹고 묵묵히 데이터를 뱉어내거나 스위치를 켜는 불쌍한 을의 블록(메모리, 센서 등)이다.
- **프로토콜 브리지(Protocol Bridge)**: AXI 고속도로에서 날아온 초고속 명령을, 멍청하고 느린 골목길 부품(APB)이 알아들을 수 있게 통역하고 속도를 늦춰주는 중간 브로커이다.

</details>

```text
[ 스마트폰 칩 내부 도로망 및 통역 브리지 프레임워크 ]
 [ 관리자 블록 (갑질 지시) ] ─── [ AXI 고속 상호 연결망 (8차선 고속도로) ] ─── [ 대상 블록 (메모리 등) ]
                                                │
                                  [ 프로토콜 브리지 (속도 조절 통역사) ]
                                                │
                                    [ 느린 대상 블록 (센서, 타이머 등) ]
```

| 구성요소 | 책임 |
|:---|:---|
| **관리자(Manager)** | "거기 메모리 값 좀 가져와!" 하고 주소와 제어 신호 트랜잭션을 능동적으로 무자비하게 쏴대는 갑질 블록(CPU, DMA) |
| 고속 상호 연결망 | 관리자가 쏜 AXI 신호를 5개 채널로 쪼개서 길을 찾아주고(라우팅) 교통정리(중재) 해주는 메인 고속도로 |
| **프로토콜 브리지** | 고속 AXI 신호를 멍청하고 느린 **에이피비** 장치들이 알아들을 수 있게 속도를 늦춰주고 통역해 주는 브로커 |
| **대상(Target)** | UART나 타이머처럼 브리지에서 넘어온 지시를 받고 묵묵히 껐다 켰다 명령만 수행하는 을의 블록 |

#### 한줄 요약

- CPU(관리자)가 고속도로(AXI)로 명령을 쏘면, 중간 브리지가 속도를 조절해서 느린 센서(대상 블록)들에게 번역해 준다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **밸리드 레디 핸드셰이크(VALID/READY Handshake)**: 보내는 놈이 "보낸다(VALID)!" 하고, 받는 놈이 "받을 준비 됨(READY)!" 하고 동시에 외쳐야만 데이터가 꽂히는 깐깐한 규칙이다.
- **피셀 피이네이블(PSEL/PENABLE)**: 느린 동네 버스(APB)에서 "너 선택됨(PSEL)", "이제 진짜 준다(PENABLE)" 하고 멍청하게 2단계로 나눠서 악수하는 원시적인 신호이다.

</details>

```text
[ 암바 버스 십자포화 요청 릴레이 및 껍데기 변환 흐름 ]
                                 │
                                 ▼
   [ 1. 갑의 요청 투척: 관리자가 냅다 주소를 쏘고 상호 연결망이 교통정리 ]
                                 │
           ┌─────────────────────┴─────────────────────┐
           ▼                                           ▼
[ 2. 고속 악수: AXI에서 (VALID/READY)       [ 3. 멍청이 번역: 브리지가 APB용으로
  치면서 병렬로 데이터 냅다 꽂아버림 ]         (PSEL/PENABLE) 2단계 속도 늦춤 ]
           │                                           │
           └─────────────────────┬─────────────────────┘
                                 ▼
[ 4. 응답 배달: 작업 끝난 놈들이 뱉은 응답 찌끄러기를 잘 모아서 관리자에게 반환 ]
```

### 동작 원리

1. 갑의 요청 투척: 관리자가 냅다 주소를 던지면 상호 연결망이 멱살 잡고 디코딩 및 교통정리(중재)를 갈김.
2. AXI 고속 악수: AXI 고속도로에서 "보낸다(VALID) / 준비됨(READY)" 하고 **밸리드 레디 핸드셰이크**를 치며 병렬로 데이터를 꽂아버림.
3. 멍청이 번역(브리지): 느린 장치로 갈 때는 브리지가 끼어들어 "준비해라(**PSEL**)", "받아라(**PENABLE**)" 하고 2단계로 멍청하게 통역함.
4. 응답 배달: 작업 끝난 놈들이 뱉어낸 응답 찌끄러기를 잘 모아서 꼬이지 않게 순서 맞춰서 관리자에게 반환함.

#### 한줄 요약

- CPU가 쏜 명령이 AXI로 빠르게 가거나, 브리지를 거쳐 APB로 느리게 전달된 후, 응답을 잘 모아서 CPU에 돌려준다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **독립 채널(Independent Channel)**: AXI 버스가 주소, 데이터 읽기, 쓰기 등을 각각 다른 차선(선로)으로 찢어놔서 차가 전혀 막히지 않는 개사기 구조이다.

</details>

| 비교 항목 | **AXI** (Advanced eXtensible Interface) | **AHB** (Advanced High-performance) | **APB** (Advanced Peripheral Bus) |
|:---|:---|:---|:---|
| 시스템 적용 최적 기준 | CPU, GPU, NPU처럼 데이터를 미친 듯이 퍼먹어야 하는 괴물 블록들을 연결할 시 | 온칩 SRAM이나 DMA처럼 굳이 5차선 고속도로까진 필요 없는 적당한 뼈대 블록 연결 시 | 키보드, 타이머 등 한 세월 걸려도 상관없는 멍청하고 느린 주변장치 찌끄러기 연결 시 |
| 아키텍처 핵심 구현 특징 | 주소 주고받기, 데이터 쓰고 읽기를 5개의 **독립 채널**로 찢어서 무식하게 병렬로 쏟아붓는 상남자 전송 | 하나의 버스에 주소 쏘고 바로 데이터 쏘는 식으로 앞뒤를 겹쳐서(파이프라이닝) 욱여넣는 가성비 전송 | 그냥 선 딱 연결해서 켜고 끄는(2-Phase) 원시적이고 단순한 악수(Handshake) 전송 |
| 극복해야 할 태생적 한계점 | 채널이 5개나 돼서 칩 내부에 선을 까는 면적(로직)이 살인적으로 커지고 복잡도 폭발함 | 여러 놈이 동시에 쓰려고 달려들면 버스 쟁탈전(중재)이 벌어져서 속도 반토막 남 | 속도가 너무 끔찍하게 느려서 고속 버스(AXI)랑 묶어 놓으면 전체 시스템이 같이 뻗어버리는 목덜미 잡기 |

#### 한줄 요약

- 최고성능 괴물들은 무거운 AXI를 달고, 중간급은 AHB로 욱여넣고, 자잘한 부품은 가벼운 APB로 연결한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **클럭 도메인 교차(Clock Domain Crossing, CDC)**: 1GHz로 미친 듯이 도는 버스랑 10MHz로 굼벵이처럼 도는 버스가 만날 때, 신호가 박살 나지 않게 중간에 완충 지대(Async FIFO)를 깔아주는 안전장치이다.
- **프로토콜 체커(Protocol Checker)**: 칩 만들기 전 시뮬레이터에서 버스 규칙을 어기고 새치기하는 미친 블록이 없는지 멱살 잡고 감시하는 스나이퍼 모듈이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| AXI가 순서 무시(Out-of-Order)하고 데이터를 쏴댔더니 ID가 꼬여버려 시스템 전체가 데드락에 빠지는 재앙 | 시뮬레이션 단계에서 규약 위반을 멱살 잡고 찾아내는 **프로토콜 체커** 지뢰밭 강력 설치 | 미친 듯이 쏟아지는 트랜잭션 사이클 꼬임을 실시간 탐지해 칩이 뻗어버리는 사태 원천 차단 |
| 1GHz짜리 CPU 버스랑 10MHz짜리 느린 버스가 그냥 부딪혀 신호가 찌그러져버리는 준안정성(Metastability) 폭발 | 도메인 사이에 클록 완충 지대(**CDC** Async FIFO)를 박아넣어 신호 박자를 강제로 쪼개고 뼈 깎듯 맞춤 | 클록 속도가 다른 블록끼리 데이터를 주고받아도 신호가 깨지지 않고 완벽한 데이터 정합성 사수 |
| 느려 터진 APB 장치가 대답을 안 해서 브리지 버퍼가 터져나가고, 결국 AXI 고속도로까지 꽉 막혀버리는 연쇄 마비 | 브리지 버퍼 용량을 쥐어짜 튜닝하고 대답 안 하면 얄짤없이 타임아웃(에러) 내버리는 독재 타이머 장착 | 멍청한 주변장치 하나 때문에 최고급 AXI 버스가 뻗어버리는 연쇄 병목(목덜미 잡기) 절대 방어 |

#### 한줄 요약

- 규약 위반은 체커로 잡아내고, 속도 다른 구역은 CDC 완충 지대를 깔고, 대답 없는 장치는 타임아웃으로 칼같이 잘라내라.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **AMBA 선택 기준(AMBA Selection Criteria)**: 이 부품이 데이터를 얼마나 무식하게 퍼먹는지 견적을 낸 뒤, 비싼 AXI를 깔아줄지 구린 APB를 줄지 급을 나누는 계급장이다.

</details>

- **AMBA 선택 기준** 원칙에 따라, 고속 컴퓨팅 부품은 **AXI** 5채널로 꽂고, 중간 뼈대는 **AHB** 파이프라인으로 엮으며, 단순 제어 레지스터는 **APB**로 분리하는 계층 설계 기조 확립함

#### 한줄 요약

- 속도와 면적 견적을 내서 괴물급 부품에는 AXI, 중간급에는 AHB, 조무래기 부품에는 APB를 박아 계급을 철저히 나눠라.
