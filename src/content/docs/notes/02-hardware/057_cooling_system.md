## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **데이터센터 냉각 시스템(Cooling System)**: IT 장비에서 발생하는 열을 포집·수송·방출하여 허용 온도 범위 내에서 정상 작동하도록 유지하는 열 관리 설비 체계.
- **열 부하(Heat Load)**: 서버, 전원 공급기, 네트워크 장비가 소비한 전력이 열 에너지로 변환되어 외부로 배출해야 하는 총 열량.
- **열 쓰로틀링(Thermal Throttling)**: 부품 온도가 임계치에 도달했을 때 소자 손상을 방지하기 위해 클록 주파수와 전압을 강제로 낮추는 하드웨어 보호 메커니즘.

</details>

- 정의/개념: 공기·물·유전체 유체를 매개로 **열 부하(Heat Load)**를 포집해 외기로 내보내는 **데이터센터 냉각 시스템(Cooling System)**
- 배경/필요성: 가속기 랙의 열 밀도가 공기로 실어 낼 수 있는 한계를 넘어서면 온도가 아니라 **열 쓰로틀링(Thermal Throttling)**으로 성능이 먼저 깎임

#### 한줄 요약
- 냉각은 고장을 막는 설비가 아니라 성능을 사는 설비이며, 식히지 못한 만큼 칩이 스스로 속도를 낮춰 투자한 연산력을 되돌려 준다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **CDU(Cooling Distribution Unit)**: 시설 냉각수 루프와 서버 내부 루프 간에 열을 교환하고 냉각수 유량과 압력을 정밀 제어하는 장치.
- **콜드 플레이트(Cold Plate)**: 발열 소자(CPU/GPU) 위에 직접 밀착되어 내부로 흐르는 냉각수를 통해 열을 직접 흡수하는 금속판.
- **액침 냉각(Immersion Cooling)**: 서버 본체를 비전도성 특수 유전체 용액에 완전히 담가 비등 또는 대류로 냉각하는 차세대 기술.

</details>

- 랙 열밀도와 장비 호환성에 따라 공랭·직접 액체 냉각·**액침 냉각(Immersion Cooling)**을 단독 또는 혼합 적용
- 액체의 높은 체적 열용량을 이용해 **콜드 플레이트(Cold Plate)** 수준에서 열을 잡아 고밀도 랙 대응
- 외기 조건이 맞으면 압축기 없이 외기만으로 냉각해 운전 전력 절감

#### 한줄 요약
- 액체 냉각으로 바꿔도 전원부와 메모리의 잔여 발열은 여전히 공기로 처리해야 하므로, 전환은 대체가 아니라 두 계통을 동시에 운영하는 일이 된다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **차폐 통로(Aisle Containment)**: 서버의 차가운 유입 공기(Cold Aisle)와 뜨거운 배기 공기(Hot Aisle)가 섞이지 않도록 차단막으로 격리하는 구조.
- **QDC(Quick Disconnect Coupling)**: 서버 유지보수 시 냉각수 누수 없이 원터치로 호스를 탈부착할 수 있는 전용 밸브.

</details>

```text
[냉각 방식별 열 경로]
├─ 공랭 차폐
│  └─ 냉기 공급 → 차폐 통로 → 서버 랙 → 온기 회수 → 공조기·칠러
├─ 직접 액체 냉각 (DLC)
│  └─ 시설 냉각수 → CDU 열교환 → 랙 매니폴드·QDC → 콜드 플레이트
└─ 액침 냉각
   └─ 외부 칠러 → 열교환기 → 유전체 탱크 (서버 침적)
```

선의 의미: 가지(`├─`)는 방식 구분이며, 아래로 갈수록 열을 잡는 지점이 방 전체에서 칩 표면 쪽으로 가까워짐

| 구성요소 | 책임 |
|:---|:---|
| **CDU(Cooling Distribution Unit)** | 시설 루프와 랙 루프를 분리 열교환하고 유량·압력 제어 |
| 콜드 플레이트 | 발열 소자에 밀착해 마이크로 채널로 열을 직접 흡수 |
| 랙 매니폴드·**QDC(Quick Disconnect Coupling)** | 서버별 냉각수 분배와 무누수 착탈 지원 |
| 액침 냉각 탱크 | 서버 전체를 비전도성 유체에 담가 대류 또는 비등으로 냉각 |
| 외부 방열 설비 | 냉각탑·드라이쿨러로 최종 열을 대기에 방출 |

#### 한줄 요약
- **차폐 통로(Aisle Containment)**부터 액침 탱크까지 모든 구성이 결국 같은 일을 하는데, 차이는 뜨거운 공기와 찬 공기를 어디서 갈라놓느냐 하나뿐이다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **프리쿨링(Free Cooling)**: 동절기나 환절기에 압축기(칠러)를 가동하지 않고 차가운 외기만으로 냉각수를 식혀 전력을 아끼는 운전 모드.

</details>

```text
서버 가속기 발열 발생
        │
   랙 열밀도가 공기 처리 한계 안인가?
   ┌────┴─────┐
  예           아니오
   │             │
차폐 통로로     콜드 플레이트가 칩 열을 냉각수에 전달
냉온기 분리       │
   │        매니폴드·QDC를 지나 CDU로 이송
   │             │
   │        CDU 열교환기에서 시설수로 열 전달
   └────┬────────┘
        │
   외기 온도가 충분히 낮은가?
   ┌────┴─────┐
  예           아니오
   │             │
압축기 없이     칠러 가동 후 대기 방출
외기만으로 방열     │
   └────┬────────┘
        │
   냉각된 유체 재순환
```

분기 결과: 앞 갈림길은 열을 어디서 잡을지, 뒤 갈림길은 어떻게 버릴지를 정하며, **프리쿨링(Free Cooling)** 가능 시간은 설비가 아니라 입지의 기후가 결정

#### 한줄 요약
- 냉각 전력의 대부분은 열을 옮기는 데가 아니라 마지막에 버리는 데 쓰이므로, 효율 개선의 여지도 서버 쪽이 아니라 외기 방열 쪽에 크게 남아 있다.

## Ⅴ. 종류 및 비교

| 냉각 방식 | 공랭 차폐 (Air Cooling) | 직접 액체 냉각 (DLC / D2C) | 단상 액침 냉각 (1-Phase) | 2상 액침 냉각 (2-Phase) |
|:---|:---|:---|:---|:---|
| 적용 기준 | 공기 유량으로 처리 가능한 표준 랙 | 칩 열밀도가 높은 AI·HPC 랙 | 서버 전체 열 포집과 팬 제거 요구 | 비등 열전달이 필요한 고열밀도 장비 |
| 핵심 특징 | 냉복도/온복도 차폐 및 팬 순환 | 발열체에 콜드 플레이트 직결 수랭 | 비전도성 합성유에 서버 완전 침적 | 저비점 불소계 냉매의 증발-응축 순환 |
| 시설 영향 | 팬·공조 전력 증가 | CDU·배관과 잔여 공랭 필요 | 탱크·유체·정비 절차 변경 | 냉매·응축기와 환경 규제 검토 |
| 한계 | 고밀도 랙 발열 해소 불가 | 랙 내 배관 누수(Leak) 위험 | 유지보수 시 오일 드립 및 무거움 | 고가의 불소계 냉매 및 환경 규제(PFAS) |

#### 한줄 요약
- 오른쪽으로 갈수록 냉각 성능은 오르지만 정비 절차와 장비 보증이 통째로 바뀌므로, 방식 전환은 설비 교체가 아니라 운영 체계 교체에 가깝다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **누수 감지 시스템(Leak Detection System)**: 냉각수 배관 및 서버 바닥에 센서 로프를 설치하여 액체 누출 시 밸브를 즉각 차단하는 안전 설비.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 배관 파손 시 전기 설비에 냉각수 누출 | 음압 계통과 **누수 감지 시스템(Leak Detection System)** 연동 | 누출 조기 탐지와 영향 구역 격리 |
| 미생물 번식과 스케일로 마이크로 채널 막힘 | 부식 억제제(Inhibitor) 투입 및 정밀 필터링(50$\mu m$) 수질 관리 | 열교환 효율 유지 및 마이크로 채널 막힘 방지 |
| 유전체 유체가 케이블 피복·광부품을 침식 | 유체 호환 인증 부품 선정과 밀봉 커넥터 적용 | 재질 변형과 화학 반응 장애 차단 |
| 외기 온습도 변화로 배관 표면 결로 발생 | 공급수 온도를 노점보다 높게 유지하고 단열 적용 | 결로와 수분 접촉 위험 완화 |

#### 한줄 요약
- 네 문제 모두 냉각 성능이 아니라 액체를 전기 설비 옆에 두었다는 사실에서 나오므로, 액체 냉각 도입 판단의 핵심은 냉각 능력이 아니라 누수를 감당할 수 있느냐다.

## Ⅶ. 결론

- 공랭 용량을 넘는 칩 직접 열부하는 직접 액체 냉각으로 처리하고, 장비 전체 열 포집과 정비 절차 전환이 가능한 경우에만 액침 냉각을 검토

#### 한줄 요약
- 냉각 방식 결정에서 자주 빠지는 항목은 효율 수치가 아니라 장비 보증과 정비 인력의 숙련도이며, 이 둘이 안 맞으면 좋은 설비도 운영 단계에서 무력해진다.
