## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **냉각 시스템(Cooling System)**: 서버 및 고발열 반도체 칩에서 발생하는 열을 공기, 냉각수, 또는 비전도성 절연유를 통해 흡수하여 대기 중으로 방출하는 인프라.
- **Heat Load(열 부하)**: 랙 내부의 연산 칩, 메모리, PSU가 전력을 소모하면서 발생하는 총 열에너지(kW/BTU).
- **Thermal Throttling(열 스로틀링)**: 반도체 칩의 접합부 온도(Tj)가 임계값($\sim 100^\circ\text{C}$)에 도달했을 때 칩 파손을 막기 위해 클록 주파수와 전압을 강제로 낮추는 하드웨어 보호 메커니즘.

</details>

- 정의/개념: 서버 고집적화 및 AI 가속기 구동 시 발생하는 열 부하(Heat Load)를 공기(Air), 액체(Liquid), 또는 비전도성 유체(Immersion Fluid)를 통해 포집, 이송, 방출하여 칩 동작 온도를 안정적으로 유지하는 열 관리 인프라 체계
- 배경/필요성: AI/HPC 랙 전력 밀도가 40~100+ kW/Rack으로 급증함에 따라, **기존 공랭식 한계를 돌파하고 열 스로틀링(Throttling) 방어 및 냉각 PUE 효율 극대화**

#### 한줄 요약

- 랙 전력 밀도에 맞춘 **공랭·직접 수랭(DLC)·액침냉각으로 고발열 AI 칩 열 스로틀링 방지**

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **Closed-Loop(폐쇄 순환 루프)**: 냉각수가 외부 공기와 접촉하여 오염되거나 증발하지 않도록 밀폐된 배관과 열교환기를 통해 지속 순환하는 구조.
- **CDU(Cooling Distribution Unit)**: 1차 냉수 루프와 2차 서버 루프 사이에서 열을 교환하고 냉각수 유량과 압력을 정밀 제어하는 냉각 분배 장치.
- **Thermal Interface Material(TIM)**: 칩 다이와 방열판/콜드플레이트 사이의 미세 공기 틈새를 메워 열 저항을 극소화하는 써멀 그리스/패드.

</details>

- 칩셋 접합부부터 데이터센터 외부 쿨링타워까지 밀폐 순환을 유지하는 **폐쇄형 열전달 경로(Closed-Loop Path)** 구축
- 최대 연산 부하 시 발생하는 피크 발열량을 여유 있게 방출할 수 있는 **냉각 용량(Cooling Capacity) 오버프로비저닝**
- 콜드플레이트 미세 채널 설계 및 고열전도도 TIM을 통한 **계면 열 저항(Thermal Resistance) 극소화**

#### 한줄 요약

- **폐쇄형 열전달 경로(Closed-Loop)·피크 열부하 냉각 용량 마진·열 저항(TIM/Cold Plate) 극소화**

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **Cold Plate(콜드플레이트)**: 구리/알루미늄 블록 내부에 마이크로 채널을 파서 냉각수를 통과시켜 칩 표면의 열을 직접 흡수하는 접촉판.
- **Dry Cooler / Chiller**: 외부 대기와 열을 교환하여 뜨거워진 1차 루프 냉각수를 다시 식혀주는 대형 냉각 설비.

</details>

```text
[ 데이터센터 냉각 3단계 아키텍처 및 CDU 루프 구조도 ]
┌─────────────────────────────────────────────────────────────┐
│ 1. 열 수집부 (Heat Collection) : 서버 내부 콜드플레이트 / 방열판│
└──────────────────────────────┬──────────────────────────────┘
                               │ [ 2차 루프 : 정제된 부식방지 냉각수 ]
┌──────────────────────────────┴──────────────────────────────┐
│ 2. 열 전달부 (Heat Transport) : CDU (냉각 분배 장치 & N+1 펌프)│
└──────────────────────────────┬──────────────────────────────┘
                               │ [ 1차 루프 : 시설 공업 냉수 ]
┌──────────────────────────────┴──────────────────────────────┐
│ 3. 열 방출부 (Heat Rejection) : Chiller / Dry Cooler / 쿨링타워│
└──────────────────────────────┬──────────────────────────────┘
                               │
┌──────────────────────────────┴──────────────────────────────┐
│ 4. 감시 제어부 : 센서 텔레메트리 (온도/유압/누수 감지) + PLC/BMS│
└─────────────────────────────────────────────────────────────┘
```

선의 의미: 열 수집부(Cold Plate), 열 전달부(CDU/펌프), 열 방출부(Chiller/쿨링타워) 및 감시 제어부 간의 데이터센터 냉각 아키텍처 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 열 수집부 | 불타오르는 CPU와 GPU에 뾰족한 방열판(히트싱크)이나 물이 흐르는 쇳덩이(콜드플레이트)를 냅다 비벼서 열을 빨아들임 |
| 열 전달부 | 비행기 엔진 같은 송풍 팬과 펌프를 미친 듯이 돌려 열을 머금은 공기나 물(냉매)을 밖으로 펌핑해서 실어 나름 |
| 열 방출부 | 땀 흘리며 실어 온 끔찍한 열을 외부의 거대한 쿨링타워나 칠러를 통해 옥상 밖 대기 중으로 가차 없이 내다 버림 |
| 감시 제어부 | 온도와 유압 센서를 째려보다가 서버가 열받는 기미가 보이면 펌프와 팬을 비명 지르듯 최대로 돌리며 악독하게 통제함 |

#### 한줄 요약

- **열 수집부(콜드플레이트)·열 전달부(CDU/펌프/배관)·열 방출부(쿨링타워/칠러)·감시 제어부(PLC/BMS)**

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **QDC(Quick Disconnect Coupling)**: 배관 분리 시 밸브가 자동으로 차단되어 액체가 외부로 누출되지 않는 드립리스 원터치 유압 커넥터.

</details>

```text
[ 냉각 루프 모니터링 및 자동 장애 조치 흐름 ]
                         │
                         ▼
   [ 1. 센서가 칩 접합부 온도(Tj), 냉각수 유량, 압력 실시간 계측 ]
                         │
                         ▼
   [ 2. 칩 부하 증가 시 CDU 펌프 RPM 및 인버터 주파수 상향 제어 ]
                         │
                         ▼
   [ 3. 콜드플레이트에서 열 포집 ──> CDU 열교환 ──> 대기 방출 ]
                         │
        +─────────────────────────────────────────+
        │             [ 펌프 고장 또는 누수 발생? ]│
        │             /                         \ │
        │         [ 아니오 ]                  [ 예 ]│
        │             │                         │ │
        │         정상 순환           4. N+1 예비 펌프 즉시 절체
        │                              5. 누수 구역 솔레노이드 차단
        +─────────────────────────────────────────+
```

**동작 원리**

1. **상태 감시**: 서버 BMC 및 CDU 센서가 냉각수 공급/환수 온도, 차압, 유량을 실시간 수집
2. **동적 제어**: 열 부하 증가 시 CDU 인버터 펌프 속도를 올려 유량을 늘리고 냉각 효율 극대화
3. **열 교환/방출**: 칩 열을 흡수한 2차 루프 냉각수가 CDU 판형 열교환기에서 1차 루프로 열을 넘겨 대기로 방출
4. **N+1 펌프 절체**: 가동 중인 펌프 압력 저하 시 대기 중인 N+1 예비 펌프가 0초 내 자동 기동
5. **누수 구역 격리**: 누수 감지선(Rope Sensor) 반응 시 해당 랙 공급 밸브를 즉각 폐쇄하여 장비 침수 방지

#### 한줄 요약

- 온도/유압 감시 $\to$ **CDU 펌프 RPM 제어 $\to$ 2차 루프 열교환 및 대기 방출 $\to$ 펌프 고장 시 N+1 예비 절체 $\to$ 누수 밸브 격리**

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **공랭 vs 직접 수랭(DLC) vs 액침냉각(Immersion)**:
  - 공랭: 10~20kW/Rack 이하, CRAC/CRAH 풍량 냉각, 소음 및 팬 전력 큼
  - 직접 수랭(DLC): 40~100kW/Rack, 칩 직접 냉각수 순환, 고효율 PUE (<1.15)
  - 액침냉각: 100~200+kW/Rack, 비전도성 절연유 침전, 극초저 PUE (<1.05)

</details>

| 비교 항목 | 공랭식 (Air Cooling) | 직접 수랭식 (Direct Liquid Cooling, DLC) | 액침 냉각 (Immersion Cooling) |
|:---|:---|:---|:---|
| 냉각 매체 및 구조 | 공기 순환 (CRAC/CRAH + 차폐 컨테인먼트) | 칩셋 콜드플레이트 + 냉각수 배관 (CDU 연동) | 비전도성 절연유(유전체 유체) 탱크 직접 침전 |
| 수용 가능 랙 전력 밀도 | 랙당 10~20 kW 이하 (팬 소음 및 풍량 한계) | 랙당 40~100 kW (GPU TDP 700~1,000W 수용) | 랙당 100~200+ kW (초고밀도 AI 클러스터) |
| 한계 및 위험 | 높은 팬 전력 소모 및 국소 핫스폿 위험 | 배관 누수(Leak) 시 하드웨어 부식/쇼트 위험 | 무거운 탱크 무게, 서버 유지보수(기름 세척) 난제 |

#### 한줄 요약

- 일반 서버는 **공랭**, 고발열 AI GPU는 **직접 수랭(DLC)**, 초고밀도 극한은 **액침냉각**

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Aisle Containment(복도 차폐)**: 냉복도(Cold Aisle) 또는 열복도(Hot Aisle)를 물리적 차폐벽으로 밀폐하여 공기 혼합을 방지하는 설계.
- **Fluid Compatibility(유체 호환성)**: 절연유나 냉각수가 고무 오링(O-Ring), 케이블 피복, 솔더링 접합부를 용해하거나 부식시키지 않는 안정성.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 메인 수랭 펌프가 뻗어 물이 안 돌면 서버가 순식간에 불타버리는 쿨링 루프 마비 대참사 발생 | 메인 펌프 옆에 놀고먹는 예비 펌프를 억지로 달아두는 **엔 플러스 일 펌프 구성** 떡칠 강제 | 펌프 하나 죽었다고 100억짜리 AI 서버가 줄초상 치르는 치명적 사태(SPOF)를 완벽 차단 방어 |
| 수랭 호스를 뺐다 낄 때 냉각수가 뚝뚝 떨어져 비싼 전자 기판을 태워 먹는 누수 쇼트 위험 | 호스를 뽑는 순간 밸브가 기계적으로 착 닫혀 물 한 방울 안 흘리는 **드립리스 커넥터** 강제 체결 | 작업자의 손떨림이나 실수로 서버에 물을 엎질러 칩이 파산하는 인재 사고 원천 봉쇄 |
| 찬 바람과 더운 바람이 섞여 특정 서버만 열을 못 식히고 쪄죽는 기형적인 **핫스폿** 존 발생 | 뜨거운 복도와 차가운 복도를 유리문으로 완전히 차폐(Containment)하여 공기 믹싱을 물리적 단절 | 비싼 에어컨 바람을 낭비 없이 서버 입에만 정확히 쑤셔 넣어 쿨링 전기세 효율 극대화 달성 |
| 서버를 식용유 같은 액침 절연유에 담갔더니 기름이 고무 패킹과 케이블을 녹여버리는 호환성 부식 참사 | 서버를 푹 담그기 전에 부품이 기름에 안 녹는지 뼛속까지 검증하는 악독한 사전 **재료 호환성** 테스트 수행 | 기름에 서버가 녹아내리는 기괴한 사태를 막고 하드웨어 기판 수명을 보장하는 안전장치 |

#### 한줄 요약

- **CDU N+1 펌프 이중화·드립리스 퀵 디스커넥트(QDC)·차폐 컨테인먼트·절연유 재료 호환성 검증**

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **Direct-to-Chip Liquid Cooling 수렴**: 차세대 TDP 1,000W+ 고발열 가속기(NVIDIA Blackwell B200 등) 도입으로 데이터센터 냉각의 대세가 공랭에서 DLC로 급속 전환 중.

</details>

- 차세대 AI 데이터센터(NVIDIA H100/B200 NVL72)에서 **CDU 기반 직접 수랭(DLC) 표준 채택 및 차세대 초밀집 노드에 2-Phase 액침냉각 도입**

#### 한줄 요약

- **랙당 발열량(kW/Rack)과 유지보수 복잡도, TCO**에 맞춘 냉각 아키텍처 선정
