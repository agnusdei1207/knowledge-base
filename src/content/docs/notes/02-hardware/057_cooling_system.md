## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **데이터센터 냉각 시스템(Cooling System)**: 서버 CPU, GPU 가속기 및 스토리지에서 발생하는 열 부하를 포집하여 외부 대기로 방출함으로써 전산실 내부 온습도를 적정 수준으로 제어하는 열 관리 인프라.
- **열 스로틀링(Thermal Throttling)**: 반도체 칩셋 접합 온도가 임계치($100^\circ\text{C}$ 이상)에 도달했을 때 소자 파괴를 막기 위해 클록 주파수와 전압을 강제로 떨어뜨리는 보호 메커니즘.

</details>

- 정의/개념: IT 장비의 열 부하를 유체 매개체로 포집·방출하는 **데이터센터 냉각 시스템**
- 배경/필요성: AI 고집적 랙(40~100kW+ per Rack) 등장에 따른 공랭 방식의 방열 한계 도달 및 **열 스로틀링(Thermal Throttling) 위험 방어 한계 극복 및 고효율 액체 냉각 인프라 도입 필요성 증대**

#### 한줄 요약
- 데이터센터 냉각 시스템은 공랭 차폐에서 직접 액체 냉각(DLC) 및 액침 냉각으로 진화하여 고밀도 AI 서버의 발열을 직접 해소한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **쿨런트 분배 장치(Cooling Distribution Unit, CDU)**: 시설 1차 냉각수 루프와 서버 내부 2차 루프 간에 판형 열교환기를 통해 열을 교환하고, 유량·온도·압력을 정밀 제어하는 핵심 장치.
- **직접 액체 냉각(Direct Liquid Cooling, DLC / D2C)**: 발열 소자(CPU/GPU) 표면에 구리 마이크로 채널 콜드 플레이트를 밀착시켜 냉각수를 순환시켜 열을 직접 흡수하는 방식.
- **액침 냉각(Immersion Cooling)**: 서버 본체를 비전도성 특수 유전체(Dielectric Fluid) 탱크에 완전히 담가 팬 없이 자연 대류 또는 비등 기화로 냉각하는 기술.
- **외기 프리쿨링(Free Cooling)**: 동절기 및 환절기에 외부 기온이 충분히 낮을 때, 냉동기(Chiller) 압축기를 정지시키고 외기와의 자연 열교환만으로 냉각수를 식히는 에너지 절감 운전 모드.

</details>

- 고열용량 매체: 공기 대비 열용량이 큰 냉각수 기반 **직접 액체 냉각(DLC)**을 통한 랙당 100kW+ 초고밀도 발열 해소
- 에너지 효율 극대화: 외기 온도를 활용하는 **프리쿨링(Free Cooling)** 연계를 통한 PUE 1.1 이하 달성
- 팬 전력 제거: **액침 냉각(Immersion Cooling)** 도입 시 서버 팬 제거를 통한 자체 소비 전력 절감

#### 한줄 요약
- 높은 열용량을 가진 액체 매체와 **CDU**를 활용하여 40kW 이상 고밀도 랙의 발열을 해소하고 외기 프리쿨링으로 PUE를 극대화한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **콜드 플레이트(Cold Plate)**: 수백 마이크로미터 폭의 미세 채널이 가공된 구리 블록으로, CPU/GPU 칩셋 상단에 장착되어 냉각수와 직접 열교환하는 부품.
- **무누수 퀵 디스커넥트(Quick Disconnect Coupling, QDC)**: 냉각수가 흐르는 배관을 서버 탈부착 시 단 한 방울의 누수 없이 원터치로 연결/분리하는 전용 밸브.

</details>

```text
+-------------------------------------------------------------------------------+
|                 데이터센터 직접 액체 냉각(DLC) 및 열순환 아키텍처             |
|                                                                               |
|  [ 전산실 내부 2차 루프 (IT 장비 순환) ]       [ 건물 외부 1차 루프 (방열 설비)]|
|                                                                               |
|  +-------------------------------------+       +---------------------------+  |
|  |       AI 가속 서버 섀시 (랙 실장)   |       |    외기 방열 설비         |  |
|  |  +-------------------------------+  |       |  [ 외기 드라이 쿨러 ]     |  |
|  |  | 고발열 칩셋 (GPU/CPU)         |  |       |  - 외기 < 25도 (프리쿨링) |  |
|  |  | [구리 마이크로 채널 콜드플레이트]|       |  [ 냉동기 (Chiller) ]     |  |
|  |  +-------------------------------+  |       |  - 고온 외기 시 압축 가동|  |
|  |                 │ 2차 냉각수 환류   |       +---------------------------+  |
|  |                 ▼ ($45^\circ\text{C}$)|                     ▲               |
|  |  +-------------------------------+  |                     │ 1차 냉각수 환류 |
|  |  | QDC 무누수 밸브 & 랙 매니폴드 |  |                     │ ($32^\circ\text{C}$)
|  |  +-------------------------------+  |                     │               |
|  +-------------------------------------+                     │               |
|                      │                                       ▼               |
|                      │ 2차 공급/환류           +---------------------------+ |
|                      ▼                         | 판형 열교환기 (HEX)       | |
|  +-----------------------------------------+   | - 1차수/2차수 물리적 분리 | |
|  |     쿨런트 분배 장치 (CDU)              |<=>| - 정밀 온도/유량/압력 제어| |
|  |     [ 2차 순환 펌프 및 $50\mu$m 필터 ]  |   +---------------------------+ |
|  +-----------------------------------------+                                 |
+-------------------------------------------------------------------------------+
```

- 신호 및 연결 관계: 좌측 서버 내부의 2차 순환수($35^\circ\text{C}\leftrightarrow 45^\circ\text{C}$)는 QDC 밸브를 통해 CDU로 집결되며, CDU 판형 열교환기(`<=>`)를 매개로 우측 건물의 1차 시설수 및 외기 드라이 쿨러로 격리 열교환됨을 명시함

| 구성요소 | 책임 |
|:---|:---|
| 콜드 플레이트 | 칩 표면 열을 마이크로 채널 냉각수로 흡수 |
| QDC 밸브 | 서버 교체 시 드립-프리 무누수 착탈 |
| 랙 매니폴드 | 냉각수를 랙 내 서버에 균등 분배 |
| CDU | 판형 열교환기로 시설수와 서버수의 열 교환 |
| 드라이 쿨러 | 외기로 프리쿨링 수행 |

#### 한줄 요약
- 콜드 플레이트가 칩 표면에 직접 붙어 공기를 매개로 하던 방열을 액체 열교환으로 대신하고, CDU가 시설수와 서버수를 갈라놓아 서버 내부 배관이 외부 수질 조건까지 떠안지 않게 한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **드라이 쿨러(Dry Cooler)**: 물 증발 없이 폐쇄 루프 코일에 팬으로 외부 공기를 불어넣어 냉각수를 냉각하는 수자원 소비 제로 방열 장치.

</details>

```text
+-------------------------------------------------------------+
|         AI 서버 GPU 고부하 연산 및 칩셋 발열 발생           |
+-------------------------------------------------------------+
                               │
                               ▼
+-------------------------------------------------------------+
| 1. 콜드 플레이트 2차 순환수의 마이크로 채널 열 흡수 전도    |
+-------------------------------------------------------------+
                               │
                               ▼
+-------------------------------------------------------------+
| 2. QDC 무누수 커플링 및 랙 매니폴드를 통한 고온수 CDU 집결  |
+-------------------------------------------------------------+
                               │
                               ▼
+-------------------------------------------------------------+
| 3. CDU 판형 열교환기 기반 1차 시설 냉각수 루프로 열 교환    |
+-------------------------------------------------------------+
                               │
                               ▼
               +-------------------------------+
               | 4. 외기 온습도 센서 측정 판정 |
               +-------------------------------+
                      |                 |
     [ 외기 $< 25^\circ\text{C}$ ]      | [ 외기 $\ge 25^\circ\text{C}$ ]
                      |                 v
                      | +-------------------------------+
                      | | 냉동기(Chiller) 압축기 가동   |
                      | +-------------------------------+
                      v                 |
+-----------------------+               |
| 드라이 쿨러 팬 가동   |               |
| (외기 프리쿨링 수행)  |               |
+-----------------------+               |
                      |                 |
                      +--------+--------+
                               v
+-------------------------------------------------------------+
| 5. 감온 냉각수 랙 매니폴드 재공급 및 순환 사이클 지속       |
+-------------------------------------------------------------+
```

분기 결과: 외기 온도가 낮을 때는 칠러 압축기 없이 **드라이 쿨러**만으로 방열하여 전력을 극소화하며 고온 시에만 칠러를 기동함

**동작 원리**

1. **마이크로 채널 열 전도**: 연산 중인 GPU 다이 표면의 고밀도 열이 써멀 인터페이스를 거쳐 콜드 플레이트 내부 수백 마이크로미터 미세 핀 사이를 흐르는 2차 냉각수로 전도
2. **QDC 무누수 집결**: 가열된 냉각수가 무누수 QDC 밸브를 통해 랙 수직 매니폴드로 모인 후 CDU 내부의 순환 펌프에 의해 고속 흡입
3. **격리 판형 열교환**: CDU 내부 판형 열교환기(HEX)에서 2차 순환수의 열이 외부 시설 1차 냉각수로 전달되며, 양측 유체는 오염 방지를 위해 완전 분리 순환
4. **외기 모드 판정 및 방열**: 시설 제어 시스템이 외부 대기 온도를 실시간 측정하여 프리쿨링이 가능한 경우 냉동기 압축기를 바이패스하고 드라이 쿨러 팬만 가동
5. **감온 유체 재공급**: $35^\circ\text{C}$로 냉각된 유체가 다시 서버 랙의 공급 매니폴드로 고압 분배되어 열 스로틀링 없는 안정적 연산 사이클 유지

#### 한줄 요약
- 액체 냉각은 열용량이 큰 유체를 발열원까지 끌어들여 고밀도 열을 빼내는 대신 누수 위험과 CDU·배관 투자를 떠안으므로, 랙 전력 밀도가 공랭 상한을 넘는 구간에서만 비용이 회수된다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **단상 액침 냉각(1-Phase Immersion)**: 비전도성 탄화수소계 오일에 서버를 담가 오일의 온도 상승과 펌프 순환 대류로 냉각하는 방식.
- **2상 액침 냉각(2-Phase Immersion)**: 끓는점이 낮은 불소계 유전체 액체가 칩 열에 의해 비등 기화하고 상단 응축기에서 액화 환류하는 방식.

</details>

| 대상 구분 | 공랭 차폐 (Air Containment) | 직접 액체 냉각 (DLC / D2C) | 단상 액침 냉각 (1-Phase Immersion) | 2상 액침 냉각 (2-Phase Immersion) |
|:---|:---|:---|:---|:---|
| 적용 기준 | 랙당 20kW 이하 범용 웹/DB 서버 환경 구성 시 | 랙당 40~100kW 고밀도 GPU AI 가속기 클러스터 구축 시 | 랙당 100kW 이상 초고밀도 HPC 및 무소음 전산실 구축 시 | 랙당 150kW 극초고밀도 및 극한 PUE 달성 특수 환경 구성 시 |
| 핵심 특징 | 냉복도/온복도 물리 격리, 기존 공조 인프라 활용, 팬 풍량 제어 | 칩셋 표면 **구리 마이크로 채널 콜드 플레이트 직결**, CDU 기반 분리 열교환, 외기 프리쿨링 연계 | 비전도성 합성 오일에 서버 완전 침적, 팬 완전 제거, 자연 대류 및 펌프 순환 | 저비점 불소계 유전체 액체 비등·기화 잠열 흡수, 응축 환류 루프, 최저 PUE(1.02) |
| 한계 | 공기의 낮은 비열로 인해 랙당 30kW 이상 발열 해소 불가, 팬 전력 과다 | 배관 연결부 누수(Leak) 위험, CDU 및 배관망 초기 설비비 부담 | 유지보수 시 오일 드립 및 작업성 저하, 바닥 하중 보강 및 특수 섀시 필요 | 고가 유전체 증발 손실 보충 비용, 환경 규제(PFAS/GWP) 및 유지보수 난이도 극상 |

#### 한줄 요약
- 현재 상용 AI 가속기 인프라는 직접 액체 냉각(DLC)이 사실상 표준이며, 초고밀도 센터를 위해 **단상 액침 냉각**이 확대되고 있다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **누수 감지 시스템(Leak Detection System)**: 냉각수 배관 이음매와 서버 섀시 바닥에 센서 로프를 배치하여 액체 누출 시 0.1초 내 밸브를 자동 차단하는 안전 설비.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 배관 파손 및 결합 불량으로 냉각수 누수 | **음압(Negative Pressure) 배관** 및 누수 감지 센서 | 누수 시 외기 유입으로 유체 유출 방지 |
| 불순물 축적으로 콜드 플레이트 유로 막힘 | 부식 억제제 투입 및 $50\mu\text{m}$ **정밀 수질 필터링** | 마이크로 채널 유량 및 열전달 효율 유지 |
| 고온 다습 환경에서 배관 표면 결로 발생 | 공급수 온도를 전산실 **이슬점(Dew Point)** 이상 제어 | 배관 결로 억제 및 전기 단락 사고 예방 |

#### 한줄 요약
- 실무에서는 음압 배관 및 누수 감지로 안전을 담보하고, 정밀 수질 관리로 채널 막힘을 방지하며, 이슬점 제어로 결로를 차단한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **음압 배관(Negative Pressure Piping)**: 배관 내부 압력을 대기압보다 낮게 유지하여 미세 균열 발생 시 냉각수가 외부로 새지 않고 외부 공기가 배관 내부로 흡입되도록 하는 누수 방지 배관 기술.
- **PUE(Power Usage Effectiveness)**: 데이터센터 총 투입 전력을 순수 IT 장비 소비 전력으로 나눈 수치로, 1.0에 가까울수록 냉각 등 부대 인프라 에너지 낭비가 적음을 의미.

</details>

- 초거대 AI 가속기 클러스터의 열폭주를 억제하기 위한 지배적 냉각 표준은 직접 액체 냉각(DLC)과 CDU 연동 체계(PUE 1.1 달성)로 정착되었으며, 향후 100kW+ 초고밀도 랙 및 칩렛 발열 심화에 대응하여 단상 액침 냉각(Immersion Cooling) 및 외기 무수 프리쿨링과의 통합 가속화 진행 중.
- 인프라 엔지니어는 음압 배관 누수 방지 설계와 이슬점 온도 제어를 철저히 수립하고 냉각수 수질 관리 지침을 체계화하는 열 관리 거버넌스 확립 필수.

#### 한줄 요약
