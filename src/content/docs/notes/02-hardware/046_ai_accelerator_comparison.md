## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **AI 가속기(AI Accelerator)**: 딥러닝 신경망의 행렬 곱셈, 컨볼루션 및 텐서 연산을 고속·저전력으로 가속하는 전용 하드웨어 시스템.
- **워크로드 적합성(Workload Fit)**: 특정 AI 모델의 연산 복잡도와 정밀도 요구사항이 대상 하드웨어 아키텍처와 최적으로 부합하는 정도.

</details>

- 정의/개념: 인공지능 워크로드 특성에 따라 **연산 병렬성·유연성·에너지 효율성**을 최적화하여 가속하는 하드웨어 프로세서 체계
- 배경/필요성: AI 모델 파라미터 급증에 따른 **연산 복잡도 폭증** 및 범용 CPU의 순차 처리 한계 직면

#### 한줄 요약
- 유연성과 에너지 효율, 개발 비용을 고려해 CPU, GPU, NPU, FPGA, ASIC 중 최적의 가속기를 선택한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **유연성-효율성 상충(Flexibility-Efficiency Tradeoff)**: 소프트웨어 프로그래밍 유연성이 높을수록 전력 효율이 낮아지고, 하드웨어 전용성이 높을수록 전력 효율이 극대화되는 공학적 관계.
- **NRE(Non-Recurring Engineering)**: ASIC 설계 및 포토마스크 제작 시 발생하는 초기 일회성 고정 개발 비용.

</details>

- 범용 프로그래밍 **유연성(Flexibility)** 과 전용 하드웨어 **전력 효율성(TOPS/W)** 의 상충 관계
- 런타임 컴파일러 생태계 및 프레임워크(CUDA, OpenVINO, XLA) 지원 수준에 따른 성능 격차
- 생산 수량(Volume)과 초기 고정 개발비(NRE)에 따른 경제성 분기점 존재

#### 한줄 요약
- 범용 유연성을 중시하면 GPU, 저전력 추론은 NPU, 회로 재구성은 FPGA, 대량 양산 효율은 ASIC이 유리하다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **도메인 특화 아키텍처(DSA)**: 특정 문제 영역(행렬 연산)에만 하드웨어 자원을 집중하여 범용 제어 오버헤드를 없앤 아키텍처.

</details>

```text
┌─────────────────────────────────────────────────────────────┐
│ AI 가속기 스펙트럼 (범용 유연성 ◄──────────────► 전용 고효율) │
│                                                             │
│  [ CPU ]       [ GPU ]       [ FPGA ]      [ NPU/ASIC ]     │
│  ┌──────┐      ┌──────┐      ┌──────┐      ┌──────────┐     │
│  │ ALUs │      │ SIMT │      │ LUTs │      │ Systolic │     │
│  │ (소수)│     │(수천)│      │ DSPs │      │ MAC Array│     │
│  └──────┘      └──────┘      └──────┘      └──────────┘     │
│     │             │             │               │           │
│  (직렬 제어)   (데이터병렬)  (회로재구성)    (텐서전용고정) │
│     │             │             │               │           │
│  ▼ 높은 유연성 ───────────────────────────▼ 높은 전력효율   │
└─────────────────────────────────────────────────────────────┘
```

선의 의미: 좌측 범용 제어 중심(CPU)에서 우측 전용 텐서 가속(ASIC/NPU)으로 갈수록 전력 효율과 처리율이 극대화됨

| 구성요소 | 책임 |
|:---|:---|
| 범용 프로세서 (CPU) | 복잡한 제어 분기, I/O 중계, 데이터 전처리 및 미지원 연산자 폴백 처리 |
| 그래픽스 가속기 (GPU) | SIMT 대규모 병렬 코어로 초대형 모델 분산 학습 및 유연한 추론 가속 |
| 신경망 처리 장치 (NPU) | 온칩 SRAM과 2D MAC 어레이로 모바일·엣지 저전력 AI 추론 전담 |
| 프로그래머블 반도체 (FPGA) | 비트스트림 기반 회로 재구성으로 맞춤형 파이프라인 및 결정적 지연 보장 |
| 주문형 반도체 (ASIC) | 전용 시스톨릭 회로 고정 집적으로 최고 처리량과 극저전력 대량 생산 실현 |

#### 한줄 요약
- 제어 중심의 CPU부터 대규모 병렬 GPU, 재구성 FPGA, 텐서 전용 NPU/ASIC이 연속 스펙트럼을 형성한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **벤치마크(Benchmark)**: 목표 하드웨어에서 실제 AI 모델을 구동하여 지연시간, 처리량, 전력 소모를 실측 평가하는 절차.

</details>

```text
AI 서비스 목표 및 모델 아키텍처 확정
      │
      ▼
1. 요구조건 분석: 연산 유형(학습/추론), 지연시간, 전력 예산 정의
      │
      ▼
2. 아키텍처 후보 선별: 개발 기간, 생산 물량(Volume), NRE 예산 검토
      │
      ▼
3. 타깃 벤치마크 실측: TOPS 실효 처리율, 메모리 대역폭, 컴파일러 검증
      │
      ▼
4. TCO 종합 평가: 칩 단가, 전력 비용, 유지보수 소프트웨어 생태계 비교
      │
      ▼
5. 최종 가속기 선정 및 이기종 시스템(Host+Accelerator) 배포
```

**동작 원리**

1. **요구조건 정의**: 모델의 연산 정밀도(FP32/FP16/INT8), 목표 지연시간, 전력 한도 확정
2. **후보군 필터링**: 개발 일정 및 양산 수량에 따라 ASIC/FPGA/GPU/NPU 후보군 압축
3. **실측 벤치마킹**: 타깃 컴파일러(TensorRT, TVM 등)로 모델을 컴파일하여 실효 성능 측정
4. **TCO 산출**: 초기 개발비(NRE)와 전력 소비, 인프라 운영 비용을 통합한 총소유비용 비교
5. **이기종 배포**: 호스트 CPU와 최적 AI 가속기를 버스로 연결하고 드라이버 배포 완료

#### 한줄 요약
- 요구조건 분석 → 후보 선별 → 벤치마크 실측 → TCO 종합 평가 → 최종 가속기 배포 순으로 진행된다.

## Ⅴ. 종류 및 비교

| AI 가속 프로세서 | CPU | GPU | NPU | FPGA | ASIC |
|:---|:---|:---|:---|:---|:---|
| 적용 기준 | 복잡한 제어 및 가벼운 범용 AI 모델 | 대규모 LLM 분산 학습 및 범용 HPC | 스마트폰·모빌리티 초저전력 엣지 추론 | 실시간 저지연 통신 및 알고리즘 잦은 변경 | 고정된 대량 생산 텐서 워크로드 |
| 핵심 특징 | 높은 프로그래밍 유연성·대용량 캐시 | 거대한 SIMT 병렬 코어 및 CUDA 생태계 | 온칩 SRAM 집적 및 INT8 고효율 연산 | 하드웨어 로직 재구성(Look-Up Table) | 전용 시스톨릭 어레이 및 최고 TOPS/W |
| 한계 | 행렬 병렬 연산 처리 속도 극히 느림 | 높은 소비 전력 및 대규모 쿨링 비용 | 지원 연산자 제한 및 온칩 용량 한계 | 높은 칩 단가 및 복잡한 HDL 개발 난이도 | 막대한 초기 NRE 비용 및 설계 수정 불가 |

#### 한줄 요약
- 유연성은 CPU/GPU, 저전력 추론은 NPU, 적응성은 FPGA, 대량 고효율은 ASIC이 최적이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **실효 처리율(Effective Utilization)**: 하드웨어 이론상 최대 연산 성능(Peak TOPS) 대비 실제 워크로드에서 달성한 성능 비율.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 스펙상 이론 Peak TOPS 대비 실제 처리율 저하 | 모델 메모리 접근 패턴 최적화 및 연산자 융합(Fusion) 적용 | 메모리 병목 해소 및 실효 가속비 달성 |
| NPU/ASIC 미지원 연산자로 인한 호스트 폴백 지연 | AI 모델 레이어를 가속기 호환 표준 연산자로 사전 치환 | 가속기 단독 100% 실행 및 버스 트래픽 차단 |
| 소량 생산 환경에서 ASIC 도입 시 과도한 NRE 발생 | 초기 검증 단계에서 GPU/FPGA 활용 후 양산 시 ASIC 전환 | 개발 리스크 최소화 및 초기 투자 비용 절감 |
| 엣지 디바이스 연속 추론 시 발열로 인한 스로틀링 | **동적 전압·주파수 조절(DVFS)** 및 INT4/INT8 경량화 모델 적용 | 배터리 수명 보호 및 일정한 추론 프레임 유지 |

#### 한줄 요약
- 연산자 융합으로 실효 성능을 높이고, 호환 연산자로 폴백을 막으며, 생산 규모에 맞게 칩을 선택한다.

## Ⅶ. 결론

- 대규모 분산 학습은 **GPU/TPU**, 배터리 기반 실시간 추론은 **NPU/Edge TPU**, 대량 양산은 **ASIC** 선택

#### 한줄 요약
- 워크로드의 연산 병렬성, 소프트웨어 생태계, 전력 예산 및 총소유비용(TCO)을 종합 고려하여 최적의 가속기를 결정해야 한다.
