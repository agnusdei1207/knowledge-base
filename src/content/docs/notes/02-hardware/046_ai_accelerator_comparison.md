## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **AI 가속기(AI Accelerator)**: 인공신경망의 대규모 행렬 곱셈 및 텐서 연산을 고속·저전력으로 가속하기 위해 특화된 전용 하드웨어.
- **워크로드 적합성(Workload Suitability)**: 신경망 구조(CNN, Transformer, RNN 등)와 연산 특성이 타깃 가속기의 데이터 경로와 부합하는 정도.

</details>

- 정의/개념: 인공지능 모델의 연산·메모리 특성에 맞춰 유연성과 연산 효율 간 균형을 최적화하는 **AI 가속기** 선정 체계
- 배경/필요성: 기존 단일 지표 중심 사양 평가로는 **모델별 워크로드 적합성 편차 및 메모리 병목 예측 불가**

#### 한줄 요약
- AI 가속기 선정은 단순 칩 스펙 비교가 아니라 모델의 연산 복잡도, 양산 규모, 전력 예산, 알고리즘 변경 주기를 종합 고려하는 의사결정 체계다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **유연성-효율성 상충(Flexibility-Efficiency Tradeoff)**: 범용 제어 로직을 제거하고 전용 데이터 경로를 확장할수록 연산 효율은 상승하나 알고리즘 변경 대응력은 감소하는 설계 관계.
- **비반복 엔지니어링 비용(Non-Recurring Engineering, NRE)**: 집적회로 설계, 논리 검증 및 포토마스크 제작 과정에서 발생하는 일회성 초기 고정 개발 비용.

</details>

- **유연성-효율성 상충**에 따른 하드웨어 아키텍처 결정
- 전용 컴파일러 및 프레임워크 생태계 성숙도에 따른 실효 가속 성능 편차
- 대규모 양산 시 **NRE** 분산에 따른 경제성 역전

#### 한줄 요약
- 제어 로직을 제거하여 하드웨어를 고정할수록 전력 효율과 연산 밀도는 상승하지만 알고리즘 변경에 대한 유연성은 감소한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **도메인 특화 아키텍처(Domain-Specific Architecture, DSA)**: 딥러닝 텐서 연산 등 특정 도메인의 데이터 흐름에 맞춰 하드웨어 자원을 집중 배치한 맞춤형 구조.
- **ASIC(Application-Specific Integrated Circuit)**: 특정 목적의 연산 회로만을 고정 설계하여 전력 효율과 연산 처리량을 극대화한 맞춤형 반도체.

</details>

```text
[AI 가속기 스펙트럼] (상단 = 유연성 우위 / 하단 = 효율 우위)
|-- CPU : 소수 코어·직렬 분기 제어 및 캐시 계층
|-- GPU : 수천 개 SIMT 코어·대규모 데이터 병렬 처리
|-- FPGA : LUT·DSP 블록 기반 하드웨어 회로 재구성
`-- NPU/ASIC : 시스톨릭 MAC 어레이·텐서 전용 고정 회로
```

선의 의미: 계층 및 스펙트럼 순서

| 구성요소 | 책임 |
|:---|:---|
| CPU | 복잡한 제어 분기·입출력 중계·전처리와 미지원 연산자 폴백 처리 |
| GPU | **SIMT** 대규모 병렬 코어로 초대형 모델 분산 학습 및 유연한 추론 가속 |
| NPU | 온칩 SRAM과 전용 MAC 어레이로 엣지 저전력 실시간 추론 전담 |
| FPGA | 룩업 테이블 재구성으로 맞춤형 파이프라인 및 확정적 저지연 보장 |
| ASIC | **도메인 특화 아키텍처** 기반 고정 연산 효율 및 와트당 성능 극대화 |

#### 한줄 요약
- AI 가속기들은 유연성과 효율성 축 위에 위치하며, 시스템 요구사항에 맞춰 최적의 위치를 선택해야 한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **벤치마크(Benchmark)**: 목표 하드웨어 및 전용 컴파일러 환경에서 실제 모델을 구동하여 지연 시간, 처리량, 전력 소모를 정량 실측하는 절차.

</details>

```text
AI 서비스 목표·모델 아키텍처 확정
        │
   정밀도·목표 지연·전력 한도 정의
        │
   모델과 양산 규모가 확정됐는가?
   ┌────┴─────┐
아니오          예
   │             │
GPU·FPGA로     ASIC·NPU 포함 후보군 구성
후보 한정         │
   └────┬────────┘
        │
   타깃 컴파일러로 실측 벤치마크
        │
   실측 성능이 목표를 만족하는가?
   ┌────┴─────┐
아니오          예
   │             │
모델·연산자     NRE·전력·운영비 합산해 총소유비용 산출
재구성 후 재측정   │
   │        호스트와 가속기 이기종 배포
   └────┬────────┘
        │
   (다시 벤치마크)
```

#### 한줄 요약
- 가속기 선정은 모델 확정 여부와 실측 벤치마크를 기반으로 진행되며, NRE와 운영비를 포함한 총소유비용(TCO)으로 최종 결정한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **SIMT(Single Instruction, Multiple Threads)**: 수많은 독립 스레드를 묶어 동일 명령어로 동시 처리하는 대규모 병렬 모델.
- **LUT(Look-Up Table)**: FPGA 내부에서 논리 함수를 구현하기 위해 사용하는 진리표 기반 프로그래머블 소자.

</details>

| AI 가속 프로세서 | CPU | GPU | NPU | FPGA | ASIC |
|:---|:---|:---|:---|:---|:---|
| 적용 기준 | 복잡한 제어 및 가벼운 범용 AI 모델 | 대규모 LLM 분산 학습 및 범용 HPC | 스마트폰·모빌리티 초저전력 엣지 추론 | 실시간 저지연 통신 및 알고리즘 잦은 변경 | 고정된 대량 생산 텐서 워크로드 |
| 핵심 특징 | 높은 프로그래밍 유연성·대용량 캐시 | 거대한 SIMT 병렬 코어 및 CUDA 생태계 | 온칩 SRAM 집적 및 INT8 고효율 연산 | 하드웨어 로직 재구성(**LUT**) | 전용 시스톨릭 어레이 및 최고 TOPS/W |
| 한계 | 행렬 병렬 연산 처리 속도 극히 느림 | 높은 소비 전력 및 대규모 쿨링 비용 | 지원 연산자 제한 및 온칩 용량 한계 | 높은 칩 단가 및 복잡한 HDL 개발 난이도 | 막대한 초기 **NRE** 비용 및 설계 수정 불가 |

#### 한줄 요약
- 각 가속기는 고유한 한계점을 가지므로, 시스템 제약 조건에 맞춰 감당 가능한 한계를 선택하는 것이 실무 의사결정의 핵심이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **실효 처리율(Effective Utilization)**: 하드웨어 이론상 최대 연산 성능 대비 실제 모델 연산에서 실측된 유효 처리 성능 비율.
- **서브그래프 분할(Subgraph Partitioning)**: 전체 신경망 연산 그래프에서 가속기 지원 연산자와 미지원 연산자를 분리하여 이기종 프로세서에 분배하는 최적화 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 이론 성능 대비 **실효 처리율** 저조 | 메모리 접근 패턴 최적화 및 연산자 융합 적용 | 메모리 대역폭 병목 해소 및 실효 가속비 극대화 |
| 미지원 연산자로 인한 호스트 폴백 지연 | 지원 연산자 치환 및 **서브그래프 분할** 경계 최소화 | 호스트-가속기 간 왕복 복사 및 동기화 지연 축소 |
| 소량 생산 환경에서 과도한 NRE 발생 | 초기 검증 단계 GPU·FPGA 활용 후 양산 시 ASIC 전환 | 초기 투자 리스크 완화 및 총소유비용 절감 |
| 엣지 장치 연속 추론 시 열 포화 및 스로틀링 | 동적 전압·주파수 조절(DVFS) 및 모델 경량화 적용 | 배터리 수명 보호 및 목표 추론 프레임 유지 |

#### 한줄 요약
- 실무 도입 시 이론 스펙보다 실제 컴파일러 최적화 후의 실효 처리율을 검증하고 서브그래프 폴백을 최소화해야 한다.

## Ⅶ. 결론

- 모델 탐색 및 분산 학습은 **GPU**, 단말 저전력 추론은 **NPU**, 프로토콜 연동 초저지연은 **FPGA**, 대량 양산 고정 워크로드는 **ASIC**을 선정하여 총소유비용(TCO) 최적화

#### 한줄 요약
- AI 가속기 선정은 알고리즘의 진화 속도와 양산 수량을 저울질하여 유연성과 효율성 사이의 최적 균형점을 도출하는 작업이다.
