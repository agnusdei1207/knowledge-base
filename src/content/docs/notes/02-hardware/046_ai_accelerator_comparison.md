## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **AI 가속기(AI Accelerator)**: 심층 신경망(DNN)의 다차원 행렬 곱셈 및 비선형 텐서 연산을 고속 처리하기 위해 특화된 전용 하드웨어(GPU, NPU, TPU, FPGA, ASIC).
- **DSA(Domain-Specific Architecture)**: 특정 응용 영역(AI 텐서 연산 등)의 데이터 흐름에 하드웨어 구조를 일치시켜 에너지 효율과 처리량을 극대화한 아키텍처.

</details>

- 정의/개념: 인공지능 워크로드의 특성(학습/추론)과 지연시간, 전력, 생산 수량 및 총소유비용(TCO) 제약에 따라 GPU, NPU, TPU, FPGA, ASIC 중 최적의 아키텍처를 선정하는 **반도체 비교 및 평가 공학 체계**
- 배경/필요성: AI 모델의 파라미터 크기 폭증과 온디바이스부터 하이퍼스케일러까지의 상이한 하드웨어 요구 조건 분화로 인해 **단일 범용 프로세서의 전력·지연시간·비용 한계**를 극복하기 위해 도입

#### 한줄 요약
- AI 가속기 비교는 유연성(CPU/GPU), 재구성성(FPGA), 극저전력·고효율(NPU/TPU/ASIC) 간의 상충 관계를 분석하여 최적의 아키텍처를 도출하는 엔지니어링 방법론이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **유연성-효율성 트레이드오프(Flexibility-Efficiency Tradeoff)**: 하드웨어를 특정 알고리즘에 고정할수록 에너지 효율(TOPS/W)은 극대화되나, 신규 모델 수용 유연성은 감소하는 반도체 설계 원리.
- **NRE 비용(Non-Recurring Engineering Cost)**: ASIC/반도체 칩 개발 시 마스크 제작, 회로 검증 등에 1회성으로 투입되는 초기 고정 개발 비용.

</details>

- 범용 CPU(유연성 최고)에서 GPU, FPGA를 거쳐 NPU/ASIC(효율성 최고)으로 이어지는 **유연성-효율성(Flexibility-Efficiency) 상충 스펙트럼** 형성
- 하드웨어 물리 연산 능력 외에 전용 컴파일러(CUDA, XLA, TVM) 및 프레임워크 최적화 생태계가 실효 모델 연산 효율(MFU) 결정
- 소량 다품종 환경에서는 초기 비용이 없는 GPU/FPGA가 유리하나, 수백만 대 이상 대량 양산 시 **NRE 마스크 비용 분산 효과**로 전용 ASIC의 칩당 원가 및 TCO 우위 확보

#### 한줄 요약
- 하드웨어를 고정할수록 TOPS/W는 비약적으로 상승하지만 알고리즘 변경 유연성은 줄어들며, 양산 수량에 따라 경제성이 갈린다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **도메인 특화 아키텍처(Domain-Specific Architecture, DSA)**: 딥러닝 텐서 연산 등 특정 응용 도메인의 데이터 흐름에 맞추어 하드웨어 연산기와 메모리 계층을 최적 배치한 맞춤형 반도체 구조.

</details>

```text
+-------------------------------------------------------------+
|             AI 가속기 스펙트럼 및 시스템 계층 비교          |
|                                                             |
|  [ 유연성 최고 / 소프트웨어 프로그래밍 ]                    |
|  +-------------------------------------------------------+  |
|  | 범용 연산 계층: 멀티코어 CPU (복잡한 제어 및 폴백)    |  |
|  +-------------------------------------------------------+  |
|         |                                                   |
|         v                                                   |
|  +-------------------------------------------------------+  |
|  | 범용 가속 계층: GPGPU (SIMT 파이프라인 + 텐서 코어)   |  |
|  +-------------------------------------------------------+  |
|         |                                                   |
|         v                                                   |
|  +-------------------------------------------------------+  |
|  | 회로 재구성 계층: FPGA (CLB + DSP 슬라이스 + BRAM)    |  |
|  +-------------------------------------------------------+  |
|         |                                                   |
|         v                                                   |
|  +-------------------------------------------------------+  |
|  | 도메인 특화 계층: 온디바이스 NPU (저전력 정수 MAC)     |  |
|  +-------------------------------------------------------+  |
|         |                                                   |
|         v                                                   |
|  +-------------------------------------------------------+  |
|  | 고정 전용 계층: 클라우드 ASIC / TPU (2D 시스톨릭 MXU) |  |
|  +-------------------------------------------------------+  |
|  [ 에너지 효율 최고 / 하드웨어 고정 데이터패스 ]            |

```

선의 의미: 실선 화살표는 범용 프로그래밍 유연성 중심의 상위 계층에서 알고리즘을 하드웨어 실리콘에 물리적으로 고정하여 에너지 효율을 극대화하는 하위 전용 계층으로의 스펙트럼 전이를 나타냄

| 구성요소 | 책임 |
|:---|:---|
| **범용 CPU** | 복잡한 제어 흐름, 데이터 전처리 및 **가속기 미지원 연산자의 폴백 실행** |
| **범용 GPU** | CUDA 플랫폼 기반으로 **초대규모 LLM 분산 학습 및 가변 모델 범용 가속** |
| **재구성 FPGA** | 비트스트림 재적재를 통해 **단일 배치(Batch=1) 결정론적 초저지연 보장** |
| **온디바이스 NPU** | 밀착 온칩 SRAM과 정수 양자화를 통해 **밀리와트급 모바일 실시간 추론** |
| **전용 ASIC/TPU** | 2차원 시스톨릭 어레이를 통해 **대규모 양산 환경의 최고 TOPS/W 및 최저 TCO** |

#### 한줄 요약
- 계층이 내려갈수록 명령어를 해석하던 회로가 고정 배선된 데이터 경로로 대체되어 같은 면적에 연산기를 더 채우게 되지만, 배선에 없는 연산자를 만나면 다시 위층 CPU 폴백 경로에 기대야 한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **실효 처리율(Model FLOPs Utilization, MFU)**: 하드웨어의 이론적 피크 연산 성능 대비 실제 딥러닝 훈련/추론에서 실측된 유효 연산 처리량 비율.

</details>

```text
+-------------------------------------------------------------+
|        AI 서비스 요구사양 및 제약조건 수립 (학습/추론)       |
+-------------------------------------------------------------+
                               |
                               v
               +-------------------------------+
               |     1. 모델 알고리즘 가변성   |
               +-------------------------------+
                      |                 |
             [수시 변경 / 연구 단계]    | [고정 표준 모델 확정]
                      |                 v
                      | +-------------------------------+
                      | | 2. 양산 볼륨 및 전력 제약 판정|
                      | +-------------------------------+
                      |                 |
                      |       [소량/저지연]  [수백만 대/초저전력]
                      |             |                |
                      v             v                v
+-----------------------+ +-----------+ +-----------------------+
|  GPU 가속기 선정     | | FPGA 선정 | |  NPU / ASIC 선정      |
+-----------------------+ +-----------+ +-----------------------+
                      |             |                |
                      +------+------+----------------+
                             v
+-------------------------------------------------------------+
|       3. 벤치마크 기반 실효 모델 연산 효율(MFU) 계측         |
+-------------------------------------------------------------+
                               |
                               v
+-------------------------------------------------------------+
|       4. 초기 NRE 비용 및 3개년 인프라 총소유비용(TCO) 산출   |
+-------------------------------------------------------------+
                               |
                               v
+-------------------------------------------------------------+
|       5. 최종 타깃 가속기 확정 및 이종 협력 파이프라인 배포  |
+-------------------------------------------------------------+
```

분기 결과: 모델 진화 속도가 빠르면 **GPU/FPGA**를 선정하여 재설계 위험을 회피하나, 모델 규격이 고정되고 대량 양산 및 엣지 배포가 확정되면 **NPU/ASIC**을 도입하여 에너지와 단가를 극소화함

**동작 원리**

1. **알고리즘 가변성 평가**: 모델 아키텍처의 변경 주기와 연산자 지원 여부를 평가하여 범용성과 전용성 요구 수준을 판별함
2. **배포 환경 제약 조건 분석**: 배터리 기반 온디바이스(밀리와트급)인지, 실시간 통신(수 마이크로초 지연)인지, 데이터센터 대규모 분산 서빙인지 환경을 분류함
3. **실효 MFU 및 지연시간 실측**: 대상 후보 하드웨어에서 실제 텐서플로우/파이토치 커널을 실행하여 피크 성능 대비 실효 모델 연산 효율(MFU)을 계측함
4. **NRE 및 운영 TCO 경제성 분석**: 초기 포토마스크/설계 비용(NRE)과 수율, 칩당 양산 단가, 데이터센터 전력 요금을 종합하여 손익분기점(BEP) 수량을 도출함
5. **이종 협력 파이프라인 배포**: 분석 결과를 토대로 호스트 CPU의 전처리와 전용 가속기의 텐서 추론을 결합한 최적의 하드웨어-소프트웨어 런타임을 배포함

#### 한줄 요약
- 모델이 계속 바뀌는 구간에서는 유연성 값을 치르고 GPU/FPGA를 쓰는 편이 싸고, 워크로드가 고정된 뒤에야 NRE를 선불한 NPU/ASIC의 전력·단가 이득이 TCO에서 회수된다.

## Ⅴ. 종류 및 비교

| AI 가속 하드웨어 | 범용 GPU | 온디바이스 NPU | 프로그래머블 FPGA | 전용 ASIC (TPU) |
|:---|:---|:---|:---|:---|
| 적용 기준 | 초대형 파운데이션 모델 학습 및 다양한 알고리즘 탐색 시 | 모바일·IoT 기기의 배터리 제약 실시간 상시 추론 시 | 통신 인터페이스 직결 및 배치=1 결정론적 초저지연 시 | 정형화된 대규모 AI 모델의 하이퍼스케일 서빙 시 |
| 핵심 특징 | **CUDA/cuDNN 생태계** 및 압도적인 소프트웨어 유연성 | 밀착 결합 온칩 SRAM 및 **INT8 저전력 정수 가속** | 하드웨어 비트스트림을 통한 **맞춤형 파이프라인 재구성** | 고정 2D 시스톨릭 어레이 기반 **압도적인 TOPS/W 효율** |
| 한계 | 수백 와트급 높은 소비 전력 및 대규모 칩 구매 비용 | 고정된 지원 연산자 외에는 **CPU/GPU 폴백 지연 수반** | 높은 칩당 단가와 전문 하드웨어 설계(RTL/HLS) 난도 | 수백억 원의 **초기 NRE 마스크 비용** 및 변경 불가 |

#### 한줄 요약
- 초대형 훈련에는 GPU, 모바일 단말 추론에는 NPU, 프로토콜 직결 초저지연에는 FPGA, 초대규모 데이터센터 서빙에는 ASIC이 최적이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **서브그래프 분할(Subgraph Partitioning)**: 신경망 연산 그래프에서 가속기 지원 연산자는 NPU/ASIC으로, 미지원 연산자는 CPU/GPU로 분할 매핑하는 최적화.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 이론 대비 실효 처리율(MFU) 저하 | 컴파일러 기반 **메모리 타일링** 및 연산자 인라인 융합 | 외부 메모리 왕복 제거로 실효 처리량 3배 향상 |
| 미지원 연산자로 인한 호스트 폴백 발생 | 모델 설계 단계에서 **표준 지원 연산자 치환** 및 정렬 | 텐서 복사 오버헤드 원천 제거 및 레이턴시 단축 |
| 성급한 전용 ASIC 개발 시 NRE 매몰 위험 | **GPU/FPGA 사전 검증** 후 양산 수량 기준 전환 | 투자 위험 분산 및 3개년 누적 TCO 최적화 달성 |

#### 한줄 요약
- 실무에서는 메모리 타일링으로 MFU를 높이고, 연산자 치환으로 폴백을 없애며, 양산 수량에 맞춰 ASIC 전환 시점을 결정한다.

## Ⅶ. 결론

- AI 가속기 시장은 초대규모 범용 학습을 전담하는 GPU(CUDA 생태계), 클라우드 대규모 고정 서빙을 담당하는 ASIC/TPU, 모바일·엣지 저전력 추론의 NPU, 실시간 통신 및 특수 제어의 FPGA로 명확히 역할이 분화되었으며, 차세대 아키텍처에서는 CXL 3.0 및 UCIe 표준 인터커넥트 기반의 칩렛 이종 집적(Heterogeneous Computing)과 오픈 표준 컴파일러(OpenXLA, TVM) 융합으로 진화하고 있다. 따라서 시스템 아키텍트는 모델의 생애주기 성숙도와 생산 볼륨을 면밀히 분석하여 유연성과 에너지 효율 사이의 공학적 손익분기점을 기반으로 가속기 포트폴리오를 결정해야 한다.

#### 한줄 요약
- AI 가속기 선정은 알고리즘의 안정성과 양산 수량을 저울질하여 유연성과 효율성 사이의 최적 균형점을 도출하는 전략이다.
