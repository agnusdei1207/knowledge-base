## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **인공지능 가속기(Artificial Intelligence Accelerator, AI 가속기)**: 신경망의 반복적인 행렬•벡터 연산을 범용 중앙 처리 장치(Central Processing Unit, CPU)보다 효율적으로 처리하는 장치이다.
- **워크로드 특성(Workload Characteristics)**: 연산 종류와 병렬성, 메모리 이동, 변경 주기 및 배포 물량을 포함한 작업의 성질이다.
- **장치 선택 체계(Device-selection Framework)**: 목표 성능과 전력 및 비용 조건을 기준으로 후보 가속기를 비교하는 절차이다.

</details>

- 정의/개념: 모델의 제어·병렬성·변경 주기와 시스템의 전력·지연·물량을 기준으로 실행 장치를 고르는 **장치 선택 체계**이다.
- 배경/필요성: 하나의 장치가 유연성·처리량·전력 효율·개발비를 모두 최적화할 수 없어 워크로드별 선택이 필요하다.

#### 한줄 요약

- AI 가속기는 모델의 **워크로드 특성**과 변경 주기, 전력·지연 한도, 배포 물량을 함께 비교해 선택한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **실모델 적합성(Workload Fit)**: 실제 모델의 연산자와 정밀도 및 메모리 이동이 후보 장치에서 직접 실행되는 정도이다.
- **실효 성능(Effective Performance)**: 지원 연산과 메모리 병목 및 장치 전환을 포함한 실제 작업에서 측정한 성능이다.
- **수명주기 비용(Lifecycle Cost)**: 설계와 구매부터 전력•운영•교체까지 전체 사용 기간에 드는 비용이다.

</details>

- **실모델 적합성**이 지원 연산과 메모리 병목을 반영한다.
- 목표 부하의 지연·처리량·전력을 **실효 성능**으로 비교한다.
- 개발비·운영비·물량을 **수명주기 비용**으로 비교한다.

#### 한줄 요약

- 이론 정점 성능보다 지원 연산, 메모리·전송 병목, 폴백을 포함한 실효 성능과 수명주기 비용을 비교한다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **컴파일러(Compiler)**: 모델의 연산 그래프를 후보 가속기의 장치 코드로 변환하는 소프트웨어이다.
- **런타임(Runtime)**: 실행 순서와 버퍼 및 장치 전환을 관리하는 소프트웨어이다.
- **호스트 중앙 처리 장치(Host Central Processing Unit, 호스트 CPU)**: 동적 분기와 전후처리 및 가속기가 지원하지 않는 연산을 실행하는 프로세서이다.
- **인터커넥트(Interconnect)**: CPU와 가속기 및 메모리 사이에서 텐서와 제어 신호를 전달하는 연결이다.
- **그래픽 처리 장치(Graphics Processing Unit, GPU)•신경망 처리 장치(Neural Processing Unit, NPU)•필드 프로그래머블 게이트 배열(Field-Programmable Gate Array, FPGA)•주문형 반도체(Application-Specific Integrated Circuit, ASIC)**: 병렬•전용•재구성•고정 회로 연산을 담당하는 가속기이다.

</details>

```text
       [호스트 CPU]
             |
             |
[컴파일러•런타임] -- [GPU•NPU•FPGA•ASIC] -- [인터커넥트•가속기 메모리]
```

선의 의미: 컴파일러•런타임이 호스트와 가속기를 함께 관리하고, 가속기가 인터커넥트•메모리에 결합된 정적 이기종 시스템 구조다.

| 구성요소 | 책임 |
|:---|:---|
| 컴파일러•런타임 | 연산•버퍼•장치 경계 배치 |
| 호스트 CPU | 분기•전후처리•폴백 실행 |
| GPU•NPU•FPGA•ASIC | 병렬•전용•재구성 연산 |
| 인터커넥트•가속기 메모리 | 텐서 전송•공급 |

#### 한줄 요약

- 런타임이 지원 연산은 가속기에, 동적•비지원 연산은 CPU에 배치한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **모델 변경 주기(Model Change Cycle)**: 연산 구조와 커널 요구가 바뀌는 시간 간격이다.
- **결정적 지연(Deterministic Latency)**: 최악 조건에서도 실행 시간이 정해진 상한을 넘지 않는 특성이다.
- **배포 물량(Deployment Volume)**: 동일한 가속기 설계를 적용할 제품이나 장치의 수이다.
- **실모델 특성 측정**: 연산자·정밀도 지원률과 제어·병렬성·메모리 이동량을 확인하는 단계이다.
- **제어·병렬성 판정**: 제어 중심 작업과 대규모 데이터 병렬 작업을 구분하는 단계이다.
- **모델 변경 주기 판정**: 커널과 모델의 변경 빈도로 범용·재구성·전용 후보를 좁히는 단계이다.
- **전력·지연·물량 판정**: 시스템 한도와 배포 물량으로 NPU·FPGA·ASIC 후보를 구분하는 단계이다.
- **종단 성능·비용 검증**: 동일 조건에서 실효 성능과 수명주기 비용을 측정해 장치를 확정하는 단계이다.

</details>

```text
 [AI 워크로드•제약]
          |
 1. 실모델 특성 측정
          |
 2. 제어•병렬성 판정
    ├─ 제어•소규모
    │  └─ [CPU 후보]
    └─ 대규모 병렬
       └─ 3. 모델 변경 주기 판정
          ├─ 잦음
          │  └─ [GPU 후보]
          └─ 낮음
             └─ 4. 전력•지연•물량 판정
                ├─ 저전력  ─ [NPU 후보]
                ├─ 결정적  ─ [FPGA 후보]
                └─ 고정 대량 ─ [ASIC 후보]

 [CPU•GPU•NPU•FPGA•ASIC 후보]
          |
 5. 종단 성능•수명주기 비용 검증
          |
     [가속기 확정]
```

### 동작 원리

1. **실모델 특성 측정**: 연산자·정밀도 지원률, 제어 분기, 병렬성, 메모리 이동량과 데이터 재사용률을 확인한다.
2. **제어·병렬성 판정**: 제어 중심 소규모 작업은 CPU를, 대규모 데이터 병렬 작업은 가속기 후보로 분류한다.
3. **모델 변경 주기 판정**: 커널·모델 변경이 잦으면 GPU를, 변경이 주기적이거나 낮으면 전용·재구성 후보를 검토한다.
4. **전력·지연·물량 판정**: 저전력 단말은 NPU, **결정적 지연**과 회로 변경은 FPGA, 큰 **배포 물량**의 고정 모델은 ASIC 후보로 분류한다.
5. **종단 성능·비용 검증**: 동일 모델·정확도·배치 조건에서 지연·처리량·전력과 전체 수명주기 비용을 측정해 확정한다.

#### 한줄 요약

- 제어 복잡도, 병렬성, 변경 주기, 전력·지연 한도와 물량으로 후보를 좁힌 뒤 동일 조건의 종단 성능과 비용으로 확정한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **중앙 처리 장치(Central Processing Unit, CPU)•그래픽 처리 장치(Graphics Processing Unit, GPU)**: 인공지능(Artificial Intelligence, AI) 작업에서 복잡한 제어에 강한 범용 프로세서와 대규모 데이터 병렬 연산에 강한 가속기이다.
- **신경망 처리 장치(Neural Processing Unit, NPU)•필드 프로그래머블 게이트 배열(Field-Programmable Gate Array, FPGA)**: 저전력 신경망 전용 배열과 제조 후 논리•배선을 재구성할 수 있는 반도체이다.
- **주문형 반도체(Application-Specific Integrated Circuit, ASIC)**: 안정된 특정 연산의 데이터 경로를 고정하여 높은 전력 효율을 얻는 전용 반도체이다.
- **단일 명령 다중 스레드(Single Instruction, Multiple Threads, SIMT)•비반복 엔지니어링(Non-Recurring Engineering, NRE)**: GPU 실행 모델과 ASIC 초기 설계•마스크 제작 비용이다.
- **재설계 비용(Redesign Cost)**: 고정된 ASIC 기능을 바꾸기 위해 설계•검증•제조를 다시 수행하는 비용이다.

</details>

| AI 가속기 | CPU | GPU | NPU | FPGA | ASIC |
|:---|:---|:---|:---|:---|:---|
| 적용 기준 | 제어•분기•소규모 부하 | 학습•대규모 병렬 | 저전력 단말 추론 | 회로 변경•결정적 지연 | 안정된 부하•대량 배포 |
| 핵심 특징 | **CPU** 범용 제어 | **GPU·SIMT** | **NPU** 전용 배열 | **FPGA** 재구성 회로 | **ASIC** 고정 회로 |
| 한계 | 낮은 병렬 처리량 | 메모리 대역폭•전력 | 지원 연산•폴백 | 자원•주파수•합성 시간 | 개발 기간•**NRE·재설계 비용** |

#### 한줄 요약

- 제어·소규모 부하는 CPU, 가변 대규모 병렬 부하는 GPU, 저전력 단말 추론은 NPU, 재구성과 지연 변동 제한은 FPGA, 고정 대량 배포는 ASIC이 적합하다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **정점 성능(Peak Performance)**: 모든 연산 자원을 이상적으로 활용할 때 가능한 이론상의 최대 처리량이다.
- **연산자•정밀도 지원 범위(Operator•Precision Coverage)**: 모델의 연산 종류와 수치 형식 가운데 장치가 직접 실행할 수 있는 범위이다.
- **재사용률(Data Reuse Ratio)**: 한 번 전송한 입력이나 가중치를 연산기 가까이에서 반복 사용하는 정도이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **정점 성능**만 비교해 실제 모델의 폴백·메모리 병목 누락 | 동일 정확도·배치 조건에서 **실효 성능** 측정 | 같은 작업 기준의 후보 비교 |
| 연산자·정밀도 지원 부족으로 CPU·GPU 폴백 증가 | 전체 그래프의 **연산자·정밀도 지원 범위** 검증 | 실제 장치 실행 비율 확인 |
| 텐서 이동량이 링크·메모리 대역폭을 넘어 연산기 유휴 | 계층별 전송량·대역폭과 **재사용률** 측정 | 데이터 이동 병목 확인 |
| 도구 비용·NRE·운영 전력·공급자 종속성을 빼서 장기 비용 과소평가 | 개발부터 교체까지 **수명주기 비용** 산정 | 초기 가격과 운영비 반영 |

> 모델 복제•배치 분할로 데이터 병렬 처리량 향상

#### 한줄 요약

- 같은 모델•정확도•배치•전력에서 종단 지연과 수명주기 비용을 측정해 가속기를 선택한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **가변 병렬 학습(Variable Parallel Training)**: 모델과 커널이 바뀌면서도 많은 데이터를 병렬 처리해야 하는 학습 작업이다.
- **저전력 추론(Low-power Inference)**: 제한된 배터리와 열 한도 안에서 모델 예측을 수행하는 실행 조건이다.
- **대량 고정 배포(Fixed High-volume Deployment)**: 기능 변경이 드문 동일 설계를 많은 수량으로 배포하는 조건이다.
- **AI 가속기 선택 기준**: 모델 변경성·전력·지연·배포 물량으로 CPU·GPU·NPU·FPGA·ASIC을 고르는 기준이다.

</details>

- **AI 가속기 선택 기준**에 따라 **가변 병렬 학습**은 **GPU**, **저전력 추론**은 **NPU**, **대량 고정 배포**는 **ASIC**을 선택한다.

#### 한줄 요약

- 모델 변경성, 전력·지연 한도와 배포 물량을 비교하고, 동일 조건의 종단 성능과 수명주기 비용으로 최종 장치를 결정한다.
