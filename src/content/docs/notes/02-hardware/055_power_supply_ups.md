## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **전원 공급 장치(Power Supply Unit, PSU)**: 한전 상용 교류(AC 220V/380V) 전원을 서버 메인보드 및 부품이 사용하는 안정된 직류(DC 12V/48V)로 변환하는 전력 변환기.
- **무정전 전원 공급 장치(Uninterruptible Power Supply, UPS)**: 상용 전원 정전, 전압 강하(Sag), 서지(Surge) 발생 시 배터리 에너지를 즉각 인버팅하여 0ms 무순단으로 전력을 공급하는 비상 백업 전원 시스템.

</details>

- 정의/개념: 상용 교류 전원을 고효율 직류로 변환하는 서버 **PSU**와 정전 시 배터리를 통해 무순단 전력을 공급하는 온라인 **UPS 기반 전원 인프라 아키텍처**
- 배경/필요성: 상용 전력 계통의 정전, 전압 강하(Sag), 서지(Surge) 등 전원 품질 이상으로 인한 데이터센터 서버 불시 다운타임 및 **데이터 손실 위험 방어 한계 극복 및 0ms 무순단 전력 보장 체계 확립 필요성 증대**

#### 한줄 요약
- 전원 인프라는 온라인 이중 변환 UPS와 이중화 서버 PSU를 결합하여 0ms 무순단 전력 공급과 24/7 데이터 정합성을 보장한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **온라인 이중 변환(Online Double Conversion)**: 입력 AC를 DC로 1차 정류한 후, DC 버스에서 배터리를 충전함과 동시에 인버터를 통해 순수 정현파 AC로 2차 역변환하여 부하에 공급하는 방식.
- **절체 시간(Transfer Time)**: 상용 전원 이상 발생 시 배터리 전원 공급으로 경로가 전환되는 데 소요되는 지연시간(온라인 방식은 0ms).

</details>

- 0ms 무순단 전력 공급: **온라인 이중 변환** 방식을 통해 정전 시에도 **절체 시간(0ms)** 없이 배터리 버스에서 즉각 전력 공급
- 완전한 전원 품질 정형: 전압 서지, 노이즈, 주파수 변동을 차단하고 왜곡 없는 순수 정현파 AC 출력
- 계통 이중화(A/B Feed): 수전 설비부터 UPS, PDU, 서버 섀시 내부 이중화 CRPS **PSU**까지 2N 완전 중복화

#### 한줄 요약
- 온라인 이중 변환으로 0ms 무순단 전력을 보장하고, A/B 이중화 계통과 CRPS로 단일 장애점(SPOF)을 원천 차단한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **정류기 / 컨버터(Rectifier / Converter)**: 상용 AC 전원을 직류(DC)로 변환하여 배터리를 충전하고 인버터로 DC 전력을 전달하는 전력 전자 소자.
- **인버터(Inverter)**: DC 버스의 직류 전원을 안정된 정격 주파수/전압의 순수 정현파 AC 전원으로 역변환하는 핵심 유닛.
- **정적 바이패스(Static Bypass)**: 인버터 고장, 과부하 또는 정비 시 상용 전원을 부하로 마이크로초 단위로 즉각 직결 우회하는 반도체 스위치(SCR).

</details>

```text
[데이터센터 전원 및 무정전 공급 체계]
  │
  ├─ [인입 및 비상 발전 계층] (ATS 기반 1차 절체)
  │     ├─ [한전 상용 AC 수전] (주 전력 공급원)
  │     ├─ [비상 발전기] (장기 정전 시 자동 기동 백업)
  │     └─ [자동 절체 스위치] (ATS, 기계적 전원 절체)
  │
  ├─ [온라인 이중 변환 UPS] (0ms 무순단 품질 정형)
  │     ├─ [정류기/컨버터] (AC -> DC 변환 및 충전 제어)
  │     ├─ [배터리 뱅크] (리튬이온/납축전지 DC 버스)
  │     ├─ [인버터 유닛] (DC -> 정현파 AC 역변환)
  │     └─ [정적 바이패스] (SCR 스위치, 과부하 즉시 직결)
  │
  └─ [랙 분전 및 서버 수전 계층] (2N 완전 이중화)
        ├─ [랙 분전반] (PDU, A-Feed / B-Feed 분리 배전)
        └─ [서버 이중화 PSU] (CRPS 1+1 리던던트 전원 모듈)
```

선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 정류기 (Rectifier) | IGBT 스위칭으로 AC 변환과 충전 전류 제어 |
| 인버터 (Inverter) | DC를 순수 정현파 AC로 변환해 노이즈 차단 |
| 배터리 뱅크 | 정전 시 백업 전력을 인버터에 공급 |
| 정적 바이패스 | 고장·과부하 시 SCR 스위치로 상용 전원 우회 |
| 서버 CRPS PSU | A/B 피드를 DC로 변환하는 1+1 이중화 |

#### 한줄 요약
- 정류기와 인버터가 상용 전원과 부하 사이에 상시 끼어들어 입력 변동을 차단하고 절체 시간 자체를 없애는 대신 이 변환 경로가 새로운 단일 고장점이 되므로, 정적 바이패스가 상용 전원으로 직결되는 우회로를 따로 남겨 둔다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **안전 셧다운(Graceful Shutdown)**: 정전 장기화로 배터리 고갈이 임박했을 때, OS와 DBMS에 신호를 보내 캐시 데이터를 디스크로 플러시하고 정상 종료하는 절차.

</details>

```text
+-------------------------------------------------------------+
|    한전 상용 전원 정상 공급 (정류기 ➔ 인버터 상시 가동)     |
+-------------------------------------------------------------+
                               │
                               ▼
+-------------------------------------------------------------+
| 1. 상용 전력 이상(정전 또는 Sag/Surge) 감지                 |
+-------------------------------------------------------------+
                               │
                               ▼
+-------------------------------------------------------------+
| 2. 배터리 버스 0ms 방전: 절체 지연 없이 인버터로 DC 공급    |
+-------------------------------------------------------------+
                               │
                               ▼
               +-------------------------------+
               | 3. 비상 발전기 기동 판정      |
               +-------------------------------+
                      |                 |
             [발전기 기동 성공]         | [발전기 기동 실패]
                      |                 v
                      | +-------------------------------+
                      | | 4. BMS 배터리 고갈 임계치 감지|
                      | +-------------------------------+
                      |                 |
                      |                 v
                      | +-------------------------------+
                      | | 5. OS 및 DBMS 안전 셧다운     |
                      | +-------------------------------+
                      v                 |
+-----------------------+               |
| 4. ATS 발전기 라인 절체|               |
|    및 배터리 재충전   |               |
+-----------------------+               |
                      |                 |
                      +--------+--------+
                               v
+-------------------------------------------------------------+
| 상용 전원 복전 시 서지 필터링 후 정상 계통 복귀             |
+-------------------------------------------------------------+
```

분기 결과: 발전기 기동 성공 시 전력이 무중단 복구되고 발전기 실패 시 배터리 고갈 전 **안전 셧다운**을 실행함

**동작 원리**

1. **상시 이중 변환 공급**: 평상시 한전 상용 전원이 정류기를 통해 DC로 변환되어 배터리를 부동 충전함과 동시에 인버터를 통해 깨끗한 정현파 AC로 서버에 상시 공급
2. **0ms 무순단 배터리 방전**: 상용 입력 정전이나 급격한 전압 강하 발생 시 정류기 입력만 차단되고, 인버터는 동일 DC 버스에 연결된 배터리 전력을 지연시간(0ms) 없이 즉각 변환하여 방출
3. **비상 발전기 기동 감시**: 정전 신호와 동시에 비상 발전기 시동 모터가 가동되며 10~30초 이내에 정격 전압 및 주파수 도달 여부를 ATS 컨트롤러가 감시
4. **계통 절체 및 전력 인계**: 발전기 정상 기동 시 ATS가 발전기 전원으로 절체하여 부하 공급을 인계하고 배터리를 재충전하며, 기동 실패 시 배터리 방전 카운트다운 개시
5. **안전 셧다운 명령 전파**: 배터리 잔량이 위험 임계치(10~15분)에 도달하면 UPS SNMP 네트워크 카드가 서버 BMC 및 OS에 안전 셧다운 명령을 브로드캐스트하여 시스템 안전 종료

#### 한줄 요약
- 배터리는 발전기 기동까지의 수십 초를 사는 완충 계층이므로, 배터리 용량은 발전기 기동 판정과 안전 셧다운에 필요한 시간만 감당하도록 설계하면 충분하다.

## Ⅴ. 종류 및 비교

| 대상 구분 | 온라인 이중 변환 UPS | 라인 인터랙티브 UPS | 오프라인(스탠바이) UPS |
|:---|:---|:---|:---|
| 적용 기준 | 0ms 무순단 절체와 정밀 전압 제어가 필수적인 미션 크리티컬 데이터센터 구축 시 | 2~4ms 미세 절체 허용 가능한 지사 및 중소형 서버실 구축 시 | 저비용 단순 백업을 요하는 일반 사무용 PC 및 데스크톱 환경 구성 시 |
| 핵심 특징 | 상시 AC-DC-AC 이중 변환, **완전 무순단(0ms 절체)**, 정적 바이패스 내장, 완벽한 순수 정현파 출력 | 양방향 인버터 및 AVR(자동 전압 조정기) 탑재, $2\sim 4\text{ ms}$ 절체, 높은 상시 효율(98%) | 상용 전원 직결 공급, 정전 시 인버터 기동($4\sim 10\text{ ms}$ 지연), 단순 서지 필터링 |
| 한계 | 상시 이중 변환에 따른 전력 손실(효율 94~97%), 발열량 증가 및 고가 도입 비용 | 절체 순간 미세 전압 왜곡 수반, 정밀 서버/의료 기기 전원 민감성 대응 한계 | 전원 품질 정형 불가(순간 단전), 구형파/계단파 출력으로 고역률 정밀 파워서플라이 비호환 |

#### 한줄 요약
- 데이터센터와 핵심 서버실에는 0ms 무순단의 온라인 이중 변환 UPS가 필수적이며, 일반 사무실에는 라인 인터랙티브 방식이 쓰인다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **돌입 전류(Inrush Current)**: 전원 복전이나 다수의 서버 동시 기동 시 전원 공급기 내부 커패시터 충전으로 인해 순간적으로 발생하는 정격의 수배 이상 대전류.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 배터리 셀 노후화로 인한 정전 백업 시간 급감 | **셀 단위 BMS 모니터링** 및 주기적 방전 시험 | 불량 셀 사전 교체 및 백업 신뢰성 100% 확보 |
| 복전 시 동시 부팅에 따른 **돌입 전류** 차단기 트립 | PDU 포트별 **순차 전원 투입(Power Sequencing)** | 피크 돌입 전류 분산 및 분전반 트립 차단 |
| 단일 전원선 장애로 인한 서버 전원 상실 위험 | **독립 A/B 피드** 및 **Titanium급 이중화 CRPS** 구성 | 단일 전원선 단선 시 100% 무중단 가동 보장 |

#### 한줄 요약
- 실무에서는 BMS 부하 시험으로 배터리를 관리하고, 순차 전원 투입으로 돌입 전류를 막으며, A/B 피드로 가용성을 보장한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **BBU(Battery Backup Unit)**: 중앙 집중식 대형 UPS 대신 서버 랙 내부 또는 개별 섀시에 직접 실장되는 분산형 소형 배터리 백업 팩.
- **CRPS(Common Redundant Power Supply)**: 인텔 및 업계 표준 규격의 슬림형 고효율 핫스왑 서버 전원 공급 장치 모듈.

</details>

- 미션 크리티컬 데이터센터의 전력 무결성을 위한 온라인 이중 변환(Double Conversion) UPS와 2N A/B 피드 기반 Titanium급 서버 PSU는 고가용성 인프라의 표준으로 확립되었으며, 향후 부피와 수명을 개선한 리튬이온(LFP) 배터리 뱅크 및 OCP 기반 48V DC 중앙 배전/BBU 랙 아키텍처로 진화 중.
- 전기 및 인프라 엔지니어는 돌입 전류 억제 전원 시퀀싱과 비상 셧다운 자동화 소프트웨어 연동 체계를 사전 모의 훈련을 통해 철저히 검증하는 무중단 전원 운용 지침 수립 필수.

#### 한줄 요약
- 전원 인프라는 0ms 온라인 이중 변환 UPS, A/B 피드 이중화, 발전기 연동 및 안전 셧다운의 유기적 결합으로 완성된다.
