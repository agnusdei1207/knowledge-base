## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **PSU(Power Supply Unit)**: 상용 교류(AC) 전원을 서버 메인보드 및 부품이 사용하는 직�- 정의/개념: 상용 교류를 서버용 직류로 바꾸는 **PSU** 및 정전 구간을 배터리로 잇는 **UPS**를 기반으로 이루어진 전원 인프라
- 배경/필요성: 정전과 순간 전압 이상은 서버를 멈추는 데 그치지 않고 진행 중이던 쓰기를 훼손해 복구 불가능한 손상을 남김

#### 한줄 요약
- 전원 설계가 보호하는 것은 가동 시간이 아니라 데이터 정합성이며, 그래서 배터리 용량보다 안전하게 멈출 시간을 확보했는지가 먼저다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **온라인 이중 변환(Online Double Conversion)**: 입력 AC를 DC로 변환한 뒤 다시 안정된 AC로 재변환하여 전원 노이즈를 완전 차단하는 방식.
- **절체 시간(Transfer Time)**: 상용 전원에서 배터리 전원으로 전원 경로가 전환되는 데 걸리는 지연 시간.

</details>

- **온라인 이중 변환은** 배터리가 DC 버스에 상시 연결돼 **절체 시간** 자체가 발생하지 않음
- 서버 내부 이중 PSU와 독립 A·B 전원 경로로 단일 장애가 미치는 범위 축소
- 배터리 관리 시스템 연동으로 셀 상태를 감시하고 소진 전에 안전 종료 유도

#### 한줄 요약
- 상시 변환은 절체 지연을 없애는 대신 평상시에도 변환 손실을 계속 지불하므로, 무정전은 성능이 아니라 전기 요금으로 값을 치른다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **정류기(Rectifier)**: 교류(AC) 전원을 직류(DC)로 변환하여 배터리를 충전하고 인버터로 전달하는 전력 전자 소자.
- **인버터(Inverter)**: 배터리나 정류기의 직류(DC) 전원을 고품질 정현파 교류(AC) 전원으로 변환해 부하에 공급하는 장치.
- **정적 바이패스(Static Bypass)**: UPS 내부 고장이나 과부하 시 상용 전원을 부하로 즉시 직결하는 고속 반도체 스위치.

</details>

```text
[데이터센터 전원 계통]
├─ 입력 전원
│  ├─ 상용 전원
│  └─ 비상 발전기
├─ 자동 절체 스위치 (입력 전원 선택)
├─ UPS
│  ├─ 정류기 (AC → DC·배터리 충전)
│  ├─ 배터리 뱅크·BMS (DC 버스 상시 연결)
│  ├─ 인버터 (DC → 정현파 AC)
│  └─ 정적 바이패스 (고장·과부하 시 직결)
└─ 부하 측
   ├─ 랙 전원 분배기 (A·B 이중 경로)
   └─ 서버 이중 PSU
```

선의 의미: 가지(`├─`)는 소유 관계이며, 정적 바이패스만이 UPS 내부 변환 경로를 건너뛰어 부하로 직결

| 구성요소 | 책임 |
|:---|:---|
| 자동 절체 스위치 | 상용 전원 상실 시 비상 발전기로 입력 자동 전환 |
| **정류기** | 입력 교류를 직류로 변환해 배터리 충전과 인버터 공급 |
| 배터리 뱅크·BMS | 정전 구간 방전과 셀 전압·온도 감시 |
| **인버터** | 직류를 정현파 교류로 변환해 부하에 공급 |
| 랙 PDU·이중 PSU | 랙 단위 분배와 이중 경로로 단일 선로 고장 흡수 |

#### 한줄 요약
- **정적 바이패스의** 존재가 말해 주듯 UPS 자체도 고장 대상이므로, 전원 설계는 보호 장치가 실패하는 경우까지 포함해야 완성된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **안전 셧다운(Graceful Shutdown)**: 배터리 소진 전 운영체제와 데이터베이스에 신호를 보내 데이터를 디스크에 안전하게 플러시하고 정상 종료하는 절차.

</details>

```text
상용 전원 정상 공급
        │
    입력 전원이 유지되는가?
    ┌────┴─────┐
  예           아니오 (정전)
   │             │
이중 변환으로   DC 버스의 배터리가 즉시 방전
부하 공급         │
   │        비상 발전기가 정격에 도달했는가?
   │        ┌────┴─────┐
   │      아니오          예
   │        │             │
   │   배터리 잔량이     발전기로 절체 후
   │   임계 이하인가?     배터리 재충전
   │   ┌──┴───┐          │
   │  예     아니오       │
   │   │       │          │
   │ 안전     대기 유지    │
   │ 셧다운      │        │
   └───┴────┬───┴────────┘
             │
    복전 시 서지 필터링 후 순차 기동
```

분기 결과: 배터리는 발전기가 뜨는 수십 초를 메우는 다리일 뿐이므로, 발전기 기동에 실패하면 남은 선택지는 시간 안에 안전하게 멈추는 것뿐

#### 한줄 요약
- **안전 셧다운이** 흐름의 종착점 중 하나로 설계돼 있다는 사실이 중요하며, 무정전 설비의 목표는 영원한 가동이 아니라 통제된 정지다.

## Ⅴ. 종류 및 비교

| 무정전 전원 공급 장치 | 온라인 이중 변환 UPS | 라인 인터랙티브 UPS | 오프라인(스탠바이) UPS | 플라이휠 UPS |
|:---|:---|:---|:---|:---|
| 적용 기준 | 미션 크리티컬 데이터센터·서버실 | 지사 네트워크 장비 및 중소형 서버 | 개인용 PC 및 단순 사무기기 | 친환경 단시간 발전기 연계 센터 |
| 핵심 특징 | 절체 시간 0ms 및 완전한 파형 정형 | AVR 내장 및 2~4ms 짧은 절체 시간 | 평상시 바이패스·정전 시 4~10ms 절체 | 기계적 회전 에너지 저장·친환경 |
| 한계 | 상시 변환에 따른 전력 손실(효율 90~95%) | 전압 서지 정밀 필터링 한계 | 절체 시 순간 전압 강하 위험 | 방전 유지 시간(15~30초) 극히 짧음 |

#### 한줄 요약
- 네 방식은 절체 시간과 상시 손실을 맞바꾼 눈금이며, 부하가 몇 밀리초의 공백을 견디느냐가 등급을 자동으로 결정한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **돌입 전류(Inrush Current)**: 전원 복전이나 장비 기동 시 커패시터 충전 등으로 인해 순간적으로 발생하는 고전류.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 배터리 노후화로 실제 백업 시간 급감 | 상태 감시와 정기 방전 부하 시험 실시 | 수명 사전 예지와 적기 교체 |
| 동시 부팅 시 **돌입 전류**로 인한 차단기 동작 | 분배기 포트별 순차 전원 투입 적용 | 피크 부하 분산과 차단 사고 예방 |
| 단일 전원선 분배 실패로 서버 전원 상실 | 용량을 검증한 독립 A/B 피드와 이중 PSU 연결 | 한 경로 장애 시 남은 경로로 부하 유지 |
| UPS 자체 고장으로 전체 전원 중단 | 모듈형 구조와 예비 용량 구성 적용 | 무중단 모듈 교체와 서비스 연속성 확보 |

#### 한줄 요약
- 네 문제 가운데 셋이 평상시가 아니라 전환 순간에 발생하므로, 전원 설비의 위험은 정전 자체보다 정전에서 벗어나는 과정에 몰려 있다.

## Ⅶ. 결론

- 절체 공백을 허용할 수 없는 핵심 부하는 온라인 이중 변환 방식을 쓰고, 짧은 공백이 허용되는 부하는 하위 방식으로 낮추되, A·B 경로와 예비 용량은 실제 부하 시험으로 검증

#### 한줄 요약
- UPS를 발전기의 대체재로 이해하면 용량 산정이 처음부터 어긋나며, 이 장치가 사는 것은 전력이 아니라 시간이다. 신호를 보내 데이터를 디스크에 안전하게 플러시하고 정상 종료하는 절차.

</details>

```text
상용 전원 정상 공급
        │
   입력 전원이 유지되는가?
   ┌────┴─────┐
  예           아니오 (정전)
   │             │
이중 변환으로   DC 버스의 배터리가 즉시 방전
부하 공급         │
   │        비상 발전기가 정격에 도달했는가?
   │        ┌────┴─────┐
   │      아니오          예
   │        │             │
   │   배터리 잔량이     발전기로 절체 후
   │   임계 이하인가?     배터리 재충전
   │   ┌──┴───┐          │
   │  예     아니오       │
   │   │       │          │
   │ 안전     대기 유지    │
   │ 셧다운      │        │
   └───┴────┬───┴────────┘
             │
    복전 시 서지 필터링 후 순차 기동
```

#### 한줄 요약
- **안전 셧다운** 흐름의 종착점 중 하나로 설계돼 있다는 사실이 중요하며, 무정전 설비의 목표는 영원한 가동이 아니라 통제된 정지다.
