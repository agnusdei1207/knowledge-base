## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **PSU(Power Supply Unit)**: 상용 교류(AC) 전원을 서버 부품이 사용하는 직류(DC 12V/48V)로 변환하는 전원 공급 장치.
- **UPS(Uninterruptible Power Supply)**: 상용 전원 정전이나 전압 이상 시 배터리를 통해 무단절 전력을 즉각 공급하는 무정전 전원 공급 장치.

</details>

- 정의/개념: 상용 교류를 직류로 변환하는 **PSU** 및 정전 시 배터리로 무순단 전력을 공급하는 **UPS** 기반 전원 인프라
- 배경/필요성: 상용 전원의 정전·순간전압강하 발생 시 **서버 다운 및 진행 중 쓰기 데이터 손상 방지 불가**

#### 한줄 요약
- 전원 인프라는 무정전 전력 공급을 통해 데이터센터 서버의 가동 시간과 스토리지 데이터 정합성을 보호한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **온라인 이중 변환(Online Double Conversion)**: 입력 AC를 DC로 변환한 뒤 다시 안정된 AC로 재변환하여 전원 노이즈를 완전 차단하는 방식.
- **절체 시간(Transfer Time)**: 상용 전원에서 배터리 전원으로 전원 경로가 전환되는 데 걸리는 지연 시간.

</details>

- **온라인 이중 변환** 적용 시 배터리가 DC 버스에 상시 연결되어 **절체 시간** 0ms 달성
- 서버 내부 이중 PSU와 독립 A·B 전원 경로로 단일 장애점(SPOF) 원천 배제
- 배터리 관리 시스템(BMS) 연동으로 셀 상태를 실시간 감시하고 잔량 부족 시 안전 종료(Graceful Shutdown) 유도

#### 한줄 요약
- 온라인 이중 변환으로 0ms 무순단 전력을 보장하고 A/B 이중 경로 구성을 통해 가용성을 극대화한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **정류기(Rectifier)**: 교류(AC) 전원을 직류(DC)로 변환하여 배터리를 충전하고 인버터로 전달하는 전력 전자 소자.
- **인버터(Inverter)**: 배터리나 정류기의 직류(DC) 전원을 고품질 정현파 교류(AC) 전원으로 변환해 부하에 공급하는 장치.
- **정적 바이패스(Static Bypass)**: UPS 내부 고장이나 과부하 시 상용 전원을 부하로 즉시 직결하는 고속 반도체 스위치.

</details>

```text
[데이터센터 전원 계통]
|-- 상용 전원 (한국전력 AC 수전)
|-- 비상 발전기 (ATS 연동 디젤 발전기)
|-- 온라인 UPS 시스템
|   |-- 정류기 (AC -> DC 변환)
|   |-- 배터리 뱅크 (리튬이온/납축전지 DC 버스)
|   |-- 인버터 (DC -> 안정 정현파 AC 변환)
|   `-- 정적 바이패스 스위치
|-- PDU / RPP (전원 분전반)
`-- 서버 섀시 이중화 CRPS (A/B 피드 PSU)
```

선의 의미: 계층 및 전력 흐름

| 구성요소 | 책임 |
|:---|:---|
| **정류기(컨버터)** | 상용 AC를 정제된 DC로 변환하여 배터리 충전 및 인버터 구동 |
| **인버터** | DC 전원을 순수 정현파 AC로 역변환하여 IT 부하에 왜곡 없는 전력 공급 |
| 배터리 뱅크 | 정전 발생 시 인버터에 즉시 DC 에너지를 방전하여 0ms 백업 제공 |
| **정적 바이패스** | UPS 인버터 고장 또는 과전류 시 상용 전원으로 0ms 즉각 우회 |
| 서버 이중 PSU | A/B 독립 전원 경로를 수전하여 1+1 또는 N+1 중복 전력 공급 |

#### 한줄 요약
- 정류기, 배터리, 인버터, 바이패스 스위치 및 서버 이중 PSU가 결합되어 무중단 전원 계통을 구성한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **안전 셧다운(Graceful Shutdown)**: 배터리 소진 전 운영체제와 데이터베이스에 신호를 보내 데이터를 디스크에 안전하게 플러시하고 정상 종료하는 절차.

</details>

```text
상용 전원 정상 공급
        │
   입력 전원이 유지되는가?
   ┌────┴─────┐
  예           아니오 (정전)
   │             │
이중 변환으로   DC 버스의 배터리가 즉시 방전 (0ms 절체)
부하 공급         │
   │        비상 발전기가 정격 전압에 도달했는가?
   │        ┌────┴─────┐
   │      아니오          예
   │        │             │
   │   배터리 잔량이     발전기로 절체(ATS) 후
   │   임계 이하인가?     배터리 재충전
   │   ┌──┴───┐          │
   │  예     아니오       │
   │   │       │          │
   │ 안전     대기 유지    │
   │ 셧다운      │        │
   └───┴────┬───┴────────┘
             │
    복전 시 서지 필터링 후 정상 복귀
```

#### 한줄 요약
- 정전 시 배터리가 0ms로 즉시 방전하며, 발전기 기동 실패 시 배터리 소진 전 안전 셧다운을 실행하여 데이터를 보호한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **라인 인터랙티브 UPS**: 자동 전압 조절기(AVR)를 내장하여 평상시 전압을 보정하다가 정전 시 2~4ms 내에 배터리로 절체하는 방식.
- **오프라인 UPS**: 평상시 상용 전원을 그대로 바이패스 공급하다가 정전 시 인버터로 4~10ms 절체하는 방식.

</details>

| 무정전 전원 공급 장치 | 온라인 이중 변환 UPS | 라인 인터랙티브 UPS | 오프라인(스탠바이) UPS | 플라이휠 UPS |
|:---|:---|:---|:---|:---|
| 적용 기준 | 미션 크리티컬 데이터센터·서버실 | 지사 네트워크 장비 및 중소형 서버 | 개인용 PC 및 단순 사무기기 | 친환경 단시간 발전기 연계 센터 |
| 핵심 특징 | 절체 시간 0ms 및 완전한 파형 정형 | AVR 내장 및 2~4ms 짧은 절체 시간 | 평상시 바이패스·정전 시 4~10ms 절체 | 기계적 회전 에너지 저장·친환경 |
| 한계 | 상시 변환에 따른 전력 손실(효율 90~95%) | 전압 서지 정밀 필터링 한계 | 절체 시 순간 전압 강하 위험 | 방전 유지 시간(15~30초) 극히 짧음 |

#### 한줄 요약
- 핵심 데이터센터에는 0ms 무순단의 온라인 이중 변환 UPS가 필수적이며, 일반 기기에는 경제적인 라인 인터랙티브 방식을 쓴다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **돌입 전류(Inrush Current)**: 전원 복전이나 장비 동시 기동 시 커패시터 충전 등으로 인해 순간적으로 발생하는 대전류.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 배터리 노후화로 인한 실제 백업 시간 급감 | 셀 단위 BMS 모니터링 및 정기 방전 부하 시험 | 배터리 수명 사전 예측 및 조기 불량 교체 |
| 동시 부팅 시 **돌입 전류**로 인한 차단기 트립 | 분전반(PDU) 포트별 순차 전원 투입(Power Sequencing) | 피크 부하 분산 및 차단기 오작동 방지 |
| 단일 전원선 분배 실패로 서버 전원 상실 | 독립 A/B 전원 피드 구성 및 이중화 CRPS PSU 연결 | 단일 회선 고장 시 무단절 연속 가동 보장 |
| UPS 자체 고장으로 인한 전체 계통 중단 | 모듈형 N+1 UPS 아키텍처 및 정적 바이패스 연동 | 핫스왑 무중단 유지보수 및 계통 가용성 확보 |

#### 한줄 요약
- BMS 기반 사전 예방 관리, 순차 기동을 통한 돌입 전류 제어, A/B 피드 이중화를 통해 전원 신뢰성을 완성한다.

## Ⅶ. 결론

- 무순단 전력 공급이 필수적인 핵심 서버 인프라는 **온라인 이중 변환 UPS** 및 **A/B 이중화 피드**를 구축하고, 정기 부하 시험으로 신뢰성 검증

#### 한줄 요약
- 데이터센터 전원 설계는 0ms 절체와 이중화 계통을 기반으로 정전 시 발전기 연계 및 안전 셧다운 타임라인을 완벽히 확보해야 한다.
