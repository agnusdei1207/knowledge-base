## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **PSU(Power Supply Unit)**: 상용 교류(AC) 전원을 서버 메인보드 및 부품이 사용하는 직류(DC) 전압으로 변환해 공급하는 장치.
- **UPS(Uninterruptible Power Supply)**: 상용 전원 정전이나 전압 이상 발생 시 배터리를 통해 서버에 무단절 전력을 공급하는 전원 백업 장치.

</details>

- 정의/개념: 서버에 안정적인 전력을 공급하기 위해 **교류-직류 변환(PSU)** 과 정전 시 **무정전 백업(UPS)** 을 수행하는 전원 관리 인프라 기술
- 배경/필요성: 상용 전원의 정전 및 전압 급변(Surge/Sag) 발생 시 서버 다운타임 방지 및 무단절 전력 가용성 보장 필요

#### 한줄 요약
- 상용 전기를 서버용 직류로 바꾸고(PSU), 정전 시 배터리로 끊김 없이 전력을 유지(UPS)하는 인프라다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **온라인 이중 변환(Online Double Conversion)**: 입력 AC를 DC로 변환한 뒤 다시 안정된 AC로 재변환하여 전원 노이즈를 완전 차단하는 방식.
- **절체 시간(Transfer Time)**: 상용 전원에서 배터리 전원으로 전원 경로가 전환되는 데 걸리는 지연 시간.

</details>

- **온라인 이중 변환** 기반 무순단 절체(절체 시간 0ms)로 정전 시 무중단 보장
- 서버 내부 **핫스왑 N+1 / 2N 이중화 PSU**를 통한 단일 장애점(SPOF) 제거
- **BMS(배터리 관리 시스템)** 연동을 통한 실시간 배터리 수명(SOH) 감시 및 안전 셧다운

#### 한줄 요약
- 절체 시간 0ms의 이중 변환 방식과 서버 내부 핫스왑 이중화 전원 공급으로 최고 수준의 전력 가용성을 확보한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **정류기(Rectifier)**: 교류(AC) 전원을 직류(DC)로 변환하여 배터리를 충전하고 인버터로 전달하는 전력 전자 소자.
- **인버터(Inverter)**: 배터리나 정류기의 직류(DC) 전원을 고품질 정현파 교류(AC) 전원으로 변환해 부하에 공급하는 장치.
- **정적 바이패스(Static Bypass)**: UPS 내부 고장이나 과부하 시 상용 전원을 부하로 즉시 직결하는 고속 반도체 스위치.

</details>

```text
┌─────────────────────────────────────────────────────────────┐
│ 무정전 전원 공급(UPS) 및 서버 전원 분배 구조                │
│                                                             │
│  [ 한전 상용 전원 ] ───┐                                   │
│                        │ (ATS 절체)                         │
│  [ 비상 디젤 발전기 ] ─┴──> [ 정적 바이패스 스위치 ] ──┐    │
│                                │                        │    │
│                     ┌──────────▼──────────┐             │    │
│                     │ 정류기 (AC ──► DC)  │             │    │
│                     └────┬───────────┬────┘             │    │
│                          │           │                  │    │
│  [ 배터리 뱅크 (BMS) ] ──┘           ▼                  │    │
│  (리튬이온 / 납축전지)       │ 인버터 (DC ──► AC)  │    │
│                              └───────────┬────────┘     │    │
│                                          │              │    │
│  ┌───────────────────────────────────────┴──────────────┴──┐│
│  │ 랙 전원 분배기 (Rack PDU A / B 이중화 경로)             ││
│  └───────────────────┬──────────────────────┬──────────────┘│
│                      │                      │               │
│               ┌──────▼──────┐        ┌──────▼──────┐        │
│               │ 서버 PSU A  │        │ 서버 PSU B  │        │
│               └─────────────┴────────┴─────────────┘        │
└─────────────────────────────────────────────────────────────┘
```

선의 의미: 상용 전원이 정류기-인버터를 거쳐 PDU와 서버 이중화 PSU로 전달되며 정전 시 배터리가 인버터에 즉각 전력 공급

| 구성요소 | 책임 |
|:---|:---|
| 자동 절체 스위치 (ATS) | 한전 전원 정전 시 비상 디젤 발전기로 주 전원 입력을 자동 절체 |
| 정류기 및 충전기 (Rectifier) | 입력 AC를 DC로 변환하여 배터리를 상시 충전하고 인버터에 정격 직류 공급 |
| 배터리 뱅크 & BMS | 정전 시 방전하여 수 분~수십 분간 인버터를 구동하고 셀 전압·온도 감시 |
| 인버터 (Inverter) | 배터리 DC를 정밀 정현파 AC로 변환하여 전압 변동 없는 고품질 전력 출력 |
| 랙 PDU & 서버 이중화 PSU | 랙 단위 전력 분배 및 1+1 리던던시 구성으로 단일 전원선 고장 시에도 무중단 유지 |

#### 한줄 요약
- ATS, 정류기, 배터리 뱅크, 인버터, 바이패스, 랙 PDU, 이중화 PSU가 단계별 전력 안전망을 구축한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **안전 셧다운(Graceful Shutdown)**: 배터리 소진 전 운영체제와 데이터베이스에 신호를 보내 데이터를 디스크에 안전하게 플러시하고 정상 종료하는 절차.

</details>

```text
정상 상용 전력 인가 (한전 AC)
      │
      ▼
1. 정상 모드: 정류기(AC-DC) 거쳐 배터리 충전 및 인버터(DC-AC) 부하 공급
      │
      ▼
2. 정전 발생: 0ms 지연으로 배터리 뱅크 방전 전력이 인버터 구동
      │
      ▼
3. 발전기 기동: 1분 내 디젤 발전기 정격 출력 도달 시 ATS가 발전기로 절체
      │
      ▼
4. 장기 정전 및 배터리 임계치 도달 시: SNMP 에이전트가 서버 안전 셧다운(Graceful Shutdown) 트리거
      │
      ▼
5. 복전 시: 상용 전원 정상화 후 인버터 재가동 및 서버 순차 자동 부팅
```

**동작 원리**

1. **상시 이중 변환**: 입력 전원을 DC로 정류해 노이즈를 제거하고 다시 깨끗한 교류로 재생성
2. **무단절 배터리 공급**: 정전 감지 즉시 DC 버스에 연결된 배터리가 전력을 방출하여 인버터 연속 동작
3. **비상 발전기 백업**: 발전기가 가동되어 정격 주파수에 도달하면 ATS가 전원을 전환해 배터리 보호
4. **소프트웨어 연동 종료**: 발전기 실패 시 UPS가 네트워크로 서버 OS에 셧다운 명령을 내려 데이터 손실 방지
5. **정상 전원 복귀**: 상용 전력 복전 시 서지 전압을 필터링한 후 서버를 순차 기동(Staggered Spin-up)

#### 한줄 요약
- 상시 이중 변환 → 무단절 배터리 방전 → 발전기 연동 → 임계 시 안전 셧다운 → 복전 후 순차 기동 순으로 동작한다.

## Ⅴ. 종류 및 비교

| 무정전 전원 공급 장치 | 온라인 이중 변환 UPS | 라인 인터랙티브 UPS | 오프라인(스탠바이) UPS | 플라이휠 UPS |
|:---|:---|:---|:---|:---|
| 적용 기준 | 미션 크리티컬 데이터센터·서버실 | 지사 네트워크 장비 및 중소형 서버 | 개인용 PC 및 단순 사무기기 | 친환경 단시간 발전기 연계 센터 |
| 핵심 특징 | 절체 시간 0ms 및 완전한 파형 정형 | AVR 내장 및 2~4ms 짧은 절체 시간 | 평상시 바이패스·정전 시 4~10ms 절체 | 기계적 회전 에너지 저장·친환경 |
| 한계 | 상시 변환에 따른 전력 손실(효율 90~95%) | 전압 서지 정밀 필터링 한계 | 절체 시 순간 전압 강하 위험 | 방전 유지 시간(15~30초) 극히 짧음 |

#### 한줄 요약
- 데이터센터는 온라인 이중 변환, 일반 서버는 라인 인터랙티브, PC는 오프라인, 친환경 연계는 플라이휠을 쓴다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **돌입 전류(Inrush Current)**: 전원 복전이나 장비 기동 시 커패시터 충전 등으로 인해 순간적으로 발생하는 고전류.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 배터리 노후화로 인한 **정전 시 백업 시간(Runtime) 급감** | **BMS 실시간 모니터링** 및 정기 방전 부하 테스트(Load Bank) 실시 | 배터리 수명 사전 예지 및 적기 교체 |
| 대규모 서버 동시 부팅 시 **돌입 전류로 인한 차단기 트립** | PDU 포트별 **순차 전원 투입(Power Sequencing)** 적용 | 피크 부하 분산 및 전원 차단 사고 예방 |
| 단일 전원선 분배 실패로 인한 **서버 전원 다운** | **2N 완전 분리 A/B 피드** 및 서버 이중화 PSU 독립 연결 | 단일 경로 장애 시에도 100% 가용성 유지 |
| UPS 내부 고장 시 **전체 전원 중단 사고** | **모듈형 핫스왑 UPS** 구조 적용 및 N+1 리던던시 구성 | 무중단 모듈 교체 및 서비스 연속성 확보 |

#### 한줄 요약
- BMS로 배터리를 감시하고, 순차 부팅으로 돌입 전류를 막으며, 2N 독립 전원 경로로 무중단을 달성한다.

## Ⅶ. 결론

- 엔터프라이즈 데이터센터 및 핵심 인프라는 **온라인 이중 변환 UPS + 2N 이중화 PSU**, 지사 소규모 랙은 **라인 인터랙티브 UPS** 선택

#### 한줄 요약
- 무순단 전력 공급과 발전기 연동, 서버 OS 안전 셧다운 체계를 통합 구축하여 전원 장애로부터 시스템을 완벽히 보호해야 한다.
