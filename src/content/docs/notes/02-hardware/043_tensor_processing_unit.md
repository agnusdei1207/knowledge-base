## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **TPU(Tensor Processing Unit)**: 구글이 신경망의 텐서 및 행렬 곱 연산을 전용 처리하도록 개발한 커스텀 ASIC 가속기.
- **텐서(Tensor)**: 다차원 수치 배열로 인공지능 모델의 입력, 가중치, 중간 상태를 나타내는 데이터 표현 단위.
- **행렬 연산 전용 가속(Matrix-Specialized Acceleration)**: 2D 시스톨릭 배열 하드웨어를 통해 행렬 연산 데이터 재사용성을 극대화하는 방식.

</details>

- 정의/개념: 시스톨릭 행렬 연산 아키텍처와 전용 **XLA** 컴파일러 기반 신경망 텐서 연산을 특화 처리하는 **TPU**
- 배경/필요성: 범용 프로세서(CPU/GPU) 대비 인프라 차원의 딥러닝 행렬 연산 전력 효율 및 처리량 극대화 요구

#### 한줄 요약

- TPU는 시스톨릭 배열에서 피연산자와 부분합을 인접 처리 요소로 전달해 대규모 행렬 곱의 처리량과 전력 효율을 높인다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **XLA(Accelerated Linear Algebra)**: 연산 그래프 융합, 타일링, 샤딩을 통해 TPU 맞춤형 머신 코드를 생성하는 전용 도메인 컴파일러.
- **시스톨릭 배열(Systolic Array)**: 데이터가 2D 펄스 형태로 인접 PE를 통과하며 곱셈과 부분합 누적을 동시 처리하는 구조.
- **HBM(High Bandwidth Memory)**: 3D 수직 적층으로 대용량 텐서 데이터를 초고속 공급하는 고대역폭 메모리.
- **ICI(Inter-Chip Interconnect)**: TPU 칩 간 2D/3D 토러스 링 망으로 집단 통신을 지원하는 전용 고속 칩 간 연결망.
- **MXU(Matrix Multiply Unit)**: TPU 내부의 시스톨릭 배열 기반 행렬 곱셈 연산 유닛.

</details>

- 연산 그래프 융합, 타일링, 샤딩을 자동 수행하는 **XLA** 컴파일 도구 체계
- **시스톨릭 배열** 기반 **MXU** 하드웨어 전용 2D 행렬 곱 처리
- 칩 단위 데이터 공급을 보장하는 **HBM** 및 칩 간 고속 확장 **ICI**

#### 한줄 요약

- 행렬 연산 배열의 활용률이 높아도 HBM 공급 대역폭이나 칩 간 통신이 병목이면 전체 성능이 제한된다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **벡터 유닛(Vector Unit)**: Activation(Softmax, ReLU), Normalization, Element-wise 연산을 전담하는 하드웨어 유닛.
- **TPU 런타임(TPU Runtime)**: 컴파일된 그래프 텐서 작업을 TPU 칩으로 런칭하고 DMA 제어를 총괄하는 실행 라이브러리.

</details>

```text
[XLA 컴파일러] -- [TPU 호스트•런타임] -- [MXU•벡터 유닛] -- [HBM•ICI 데이터 경로]
```

선의 의미: XLA 컴파일 파이프라인에서 생성된 실행 계획이 TPU 런타임 제어 하에 MXU 연산 및 HBM/ICI 통신 계층으로 전달되는 시스템 구조.

| 구성요소 | 책임 |
|:---|:---|
| XLA 컴파일러 | 그래프 연산 융합, 텐서 타일링, Multi-chip 샤딩 최적화 |
| TPU 호스트•런타임 | 호스트 통신, 커널 런칭 및 장치 상태 메트릭 모니터링 |
| MXU•벡터 유닛 | MXU의 2D 행렬 곱 연산 및 벡터 유닛의 비선형 연산 수행 |
| HBM•ICI 데이터 경로 | HBM 텐서 고속 공급 및 ICI 기반 칩 간 All-Reduce 통신 |

#### 한줄 요약

- XLA가 작업을 나누고 HBM과 ICI가 MXU•벡터 유닛에 데이터를 공급한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **연산 그래프(Computation Graph)**: 딥러닝 모델 연산자와 텐서 흐름의 방향성 있는 그래프 표현(DAG).
- **타일링(Tiling)**: 거대한 텐서를 온칩 자원 한계 크기에 맞춰 나눈 조각 블록.
- **집단 통신(Collective Communication)**: 분산 칩 간 All-Reduce, All-To-All 등 텐서 동기화 통신 패턴.

</details>

```text
                  [연산 그래프•텐서 모양]
                              |
              1. XLA 융합•타일링•샤딩 컴파일
                              |
                 2. 입력•가중치 HBM 배치
                              |
             +--------------------------------+
             | 반복: 컴파일된 텐서 타일      |
             | 3. HBM 피연산자 타일 공급     |
             | 4. MXU•벡터 연산•결과 저장 |
             +--------------------------------+
                              |
                    [다중 칩 실행인가?]
                       /             \
                    [아니요]          [예]
                       |               |
                       |       5. ICI 집단 통신
                       |               |
                       +-------+-------+
                               |
                         [결과 텐서 반환]
```

### 동작 원리

1. **XLA 융합·타일링·샤딩 컴파일**: 연산 그래프 수용, 융합 커널 생성 및 **타일링** 기반 **XLA** 컴파일.
2. **입력·가중치 HBM 배치**: 컴파일 텐서 파라미터의 **HBM** 온칩 보관 및 메모리 배치.
3. **HBM 피연산자 타일 공급**: HBM으로부터 **MXU** 피연산자 타일 데이터 스트리밍 공급.
4. **MXU·벡터 연산·결과 저장**: MXU 2D 시스톨릭 배열 기반 행렬 곱 및 벡터 유닛 비선형 연산 수행.
5. **ICI 집단 통신**: TPU Pod 구성 시 **ICI** 토러스 망을 활용한 칩 간 **집단 통신** 동기화.

#### 한줄 요약

- XLA가 연산 그래프를 타일·샤드로 나누면 HBM이 MXU에 피연산자를 공급하고, 다중 칩 실행에서는 ICI가 부분 결과를 교환한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **TPU Pod**: 수백~수천 개의 TPU 칩을 전용 2D/3D Torus ICI 통신망으로 묶은 초거대 텐서 컴퓨팅 클러스터.
- **GPU(Graphics Processing Unit)**: 범용 데이터 병렬 스레드 기반 멀티 캘큘레이션 가속기.
- **NPU(Neural Processing Unit)**: Edge 장치용 저전력 딥러닝 추론 전용 칩.

</details>

| AI 가속기 | TPU | GPU | NPU |
|:---|:---|:---|:---|
| 적용 기준 | 초거대 모델 데이터센터 **TPU Pod** 분산 학습 시 | 다양한 알고리즘 갱신 및 범용 병렬 가속 시 | 모바일/Embedded 단말 저전력 추론 시 |
| 핵심 특징 | **TPU** 시스톨릭 배열 및 **XLA** 컴파일러 | **GPU**의 SIMT 스레드 병렬성 | **NPU** 전용 저전력 MAC 로직 |
| 한계 | 특정 프레임워크 종속 및 **XLA** 재컴파일 오버헤드 | 높은 전력 소모 및 전역 메모리 병목 | 연산자 지원 제어 및 도구 생태계 한계 |

> 요약: 초거대 모델 학습은 TPU Pod, 범용 가속은 GPU, 온디바이스는 NPU 적용.

#### 한줄 요약

- 대규모 행렬과 텐서 처리 장치 포드 학습에는 TPU, 가변적인 범용 병렬 커널에는 GPU, 전력 제한이 큰 단말 추론에는 NPU가 적합하다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **모양 버킷화(Shape Bucketing)**: 가변 입력 텐서 셰이프를 정해진 버킷으로 고정 패딩하여 XLA 재컴파일을 방지하는 기법.
- **컴파일 캐시(Compilation Cache)**: 이미 컴파일 완료된 그래프 버킷 핑거프린트를 저장하여 재사용하는 캐시.
- **폴백(Fallback)**: TPU 미지원 연산자를 CPU로 회회하여 연산하도록 우회 처리하는 백업 방식.
- **샤딩(Sharding)**: 거대 모델 파라미터를 복수 TPU 칩으로 분할 배치하는 분산 텐서 병렬화.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 입력 텐서 셰이프 가변으로 **XLA** 재컴파일 폭주 | **모양 버킷화** 패딩 및 **컴파일 캐시** 적용 | 런타임 런칭 지연시간 제거 |
| TPU 지원 불가능 연산자 포함에 따른 **폴백** 발생 | 커널 그래프 리팩토링 및 대체 연산자 전환 | CPU-TPU 간 불필요한 데이터 이송 차단 |
| HBM 대역폭 포화로 인한 MXU 가동률 저하 | **XLA** 연산자 융합(Op Fusion) 및 타일 크기 재조정 | 온칩 텐서 재사용성 증대 |
| TPU Pod 다중 칩 간 통신 병목 현상 | **샤딩** 패턴 최적화 및 **계산·통신 중첩** 구현 | Scalability 확장 효율 증대 |

> 사례: **모양 버킷화** 기법을 통한 Dynamic Shape 입력의 XLA 재컴파일 방지

#### 한줄 요약

- 입력 모양을 버킷화하고 컴파일 결과를 재사용해 XLA 재컴파일 지연을 줄인다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **가속기 선택 기준(Accelerator Selection Criteria)**: 연산 텐서 구조, 분산 학습 규모, 프레임워크 생태계에 기반한 프로세서선택 체계.

</details>

- **가속기 선택 기준**에 따라 초거대 행렬 및 Pod 병렬 학습은 **TPU**, 범용 모델 가속은 **GPU** 선택

#### 한줄 요약

- XLA 컴파일과 ICI 통신 비용을 상쇄할 만큼 대규모 행렬 연산이 반복될 때 TPU 적용 원칙 준수.
