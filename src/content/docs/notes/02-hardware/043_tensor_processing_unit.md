## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **텐서 처리 장치(Tensor Processing Unit, TPU)**: Google이 대규모 AI 딥러닝 텐서 연산 및 행렬 곱셈을 가속하기 위해 자체 개발한 맞춤형 도메인 특화 ASIC.
- **행렬 곱셈 유닛(Matrix Multiply Unit, MXU)**: 2차원 시스톨릭 어레이 구조로 수천 개의 MAC 셀이 레지스터 접근 없이 행렬 곱셈을 1사이클 스트리밍하는 핵심 연산기.
- **XLA(Accelerated Linear Algebra)**: 텐서 연산 그래프를 분석하여 연산자를 융합(Fusion)하고 전용 기계어로 자동 컴파일하는 도메인 특화 가속 컴파일러.

</details>

- 정의/개념: 대규모 행렬 곱셈 전용 **MXU(시스톨릭 어레이)**와 HBM 메모리, 칩 간 전용망(ICI)을 단일 아키텍처로 통합한 **Google TPU(Tensor Processing Unit) ASIC**
- 배경/필요성: 범용 프로세서(CPU/GPU)의 범용 명령어 오버헤드와 호스트 경유 네트워크 방식으로는 **초거대 LLM 분산 학습 시 통신 및 메모리 병목 극복 불가**

#### 한줄 요약
- TPU는 2차원 시스톨릭 행렬 연산기(MXU)와 광학 칩 간 전용망(ICI)을 결합하여 초대규모 분산 딥러닝을 가속하는 전용 ASIC이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **칩 간 인터커넥트(Inter-Chip Interconnect, ICI)**: 호스트 CPU나 네트워크 스위치를 거치지 않고 TPU 칩들끼리 직접 2D/3D 토러스 망으로 데이터를 초고속 교환하는 전용 인터페이스.
- **bfloat16**: FP32와 동일한 8비트 지수부를 유지하여 오버플로를 방지하면서 가수부를 7비트로 줄여 16비트로 행렬 곱셈을 가속하는 Google 전용 부동소수점 포맷.

</details>

- 시스톨릭 데이터 재사용: **MXU** 내부에서 셀 간에 데이터를 직접 전달하여 레지스터 및 외부 HBM 메모리 접근 트래픽 90% 이상 절감
- 컴파일러 기반 연산자 융합: **XLA 컴파일러**가 딥러닝 연산 그래프를 분석하여 다중 연산자를 단일 기계어 커널로 융합
- 선형적 분산 확장성: **ICI(Inter-Chip Interconnect)** 전용 링크를 기반으로 수천 개 칩을 3D 토러스(Torus) 망으로 묶어 단일 슈퍼컴퓨터(TPU Pod)처럼 운용

#### 한줄 요약
- MXU 시스톨릭 어레이와 XLA 컴파일러 융합, ICI 전용 토러스 네트워크를 통해 수천 칩의 선형적 확장을 보장한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **벡터 처리 유닛(Vector Processing Unit, VPU)**: 활성화 함수(GELU, ReLU), 레이어 정규화(LayerNorm), 소프트맥스 등 벡터 연산을 전담하는 SIMD 유닛.
- **TPU Pod**: 수천 개의 TPU 칩을 ICI 초고속 광학 토러스 망으로 결합하여 엑사플롭스(ExaFLOPS)급 연산력을 제공하는 대규모 클러스터 시스템.

</details>

```text
[Google TPU 코어 실리콘 아키텍처]
 ├─ [고대역폭 메모리 (HBM3 / HBM3E)] ── 초당 수 TB/s 가중치 공급
 │
 ├─ [전용 연산 유닛 계층]
 │   ├─ 2D 시스톨릭 행렬 곱셈기 (MXU: $128\times 128$ / $256\times 256$ bfloat16 MAC)
 │   ├─ 벡터 처리 유닛 (VPU: 활성화 함수, 정규화, 소프트맥스)
 │   └─ 스칼라 연산기 (주소 계산, 루프 제어, DMA 디스패치)
 │
 ├─ [벡터/가중치 메모리 버퍼 (VMem / WMem)] ── 온칩 SRAM 버퍼
 │
 └─ [칩 간 인터커넥트 라우터 (ICI Router)] ──► [TPU Pod (3D Torus 광통신망)]
```

선의 의미: 가지(`├─`, `└─`)는 하드웨어 소속 및 포함 관계; ICI 라우터가 칩 간 텐서 교환을 전담하여 호스트 CPU 개입을 원천 배제함

| 구성요소 | 소속 및 위치 | 핵심 엔지니어링 책임 | 주요 특징 |
|:---|:---|:---|:---|
| **MXU (Matrix Multiply Unit)**| 코어 중심 연산기 | 2차원 시스톨릭 어레이 기반 **bfloat16 행렬 곱셈 누산** | $128\times 128$ MAC 셀 |
| **VPU (Vector Processing Unit)**| 코어 벡터 연산기 | 활성화(GELU), 정규화(LayerNorm), 소프트맥스 등 비선형 연산 | 초광폭 SIMD 파이프라인 |
| **스칼라 유닛** | 코어 제어기 | 메모리 주소 계산, 제어 흐름 분기 및 파이프라인 동기화 | 경량 RISC 코어 |
| **ICI 라우터** | 칩 경계 통신망 | 호스트 경유 없는 **칩 간 3D 토러스 고속 텐서 전송** | 초저지연 패킷 라우터 |
| **HBM 인터페이스** | 메모리 인터페이스 | 초대형 모델 가중치와 활성화 텐서에 광폭 대역폭 공급 | 다채널 HBM 서브시스템 |

#### 한줄 요약
- TPU는 MXU(행렬곱), VPU(벡터), 스칼라 제어기, HBM 및 칩 간 전용 통신망 ICI 라우터로 구성된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **연산자 융합(Operator Fusion)**: 여러 개의 개별 연산(MatMul + Bias + GELU)을 하나의 통합 하드웨어 루프로 결합하여 HBM 메모리 접근을 없애는 최적화.

</details>

```text
1. JAX / TensorFlow AI 모델 그래프 정의
                      │
                      ▼
2. XLA 컴파일러: 연산 그래프 분석 및 연산자 융합(Operator Fusion) 수행
                      │
                      ▼
3. HBM에서 가중치 텐서를 인출하여 온칩 버퍼 및 MXU 셀에 적재
                      │
                      ▼
4. MXU 2D 시스톨릭 어레이로 입력 텐서 시차 주입 ➔ 1사이클 스트리밍 행렬곱 수행
                      │
                      ▼
5. 누산 결과를 VPU로 즉시 전달 ➔ 비선형 활성화(GELU) 및 레이어 정규화 적용
                      │
                      ▼
6. 분산 학습 동기화 분기
   ┌──────────────────┴──────────────────┐
[ 단일 칩 실행 ]                      [ 대규모 TPU Pod 분산 학습 ]
   │                                     │
   ▼                                     ▼
7. 최종 출력 텐서 도출                8. ICI 라우터를 통해 All-Reduce 그래디언트 초고속 교환
   │                                     │
   └──────────────────┬──────────────────┘
                      │
                      ▼
9. 다음 트레이닝 스텝 즉시 개시 (호스트 개입 없는 고속 루프)
```

분기 결과: **TPU Pod 환경에서는** ICI 토러스망을 통해 칩 간 텐서 동기화가 하드웨어적으로 즉시 완료되어 대규모 선형 확장이 유지됨

#### 한줄 요약
- XLA 그래프 분석 ➔ 연산자 융합 ➔ MXU 시스톨릭 행렬곱 ➔ VPU 정규화 ➔ ICI All-Reduce 동기화의 흐름으로 동작한다.

## Ⅴ. 종류 및 비교

| 비교 항목 | Google TPU (v4 / v5p) | NVIDIA GPU (H100 / B200) | 온디바이스 NPU | 범용 CPU |
|:---|:---|:---|:---|:---|
| 핵심 연산 구조 | **대규모 시스톨릭 어레이 (MXU)** | SIMT 스트리밍 멀티프로세서 | 저전력 정수 MAC 어레이 | 범용 OoO 실행 파이프라인 |
| 다중 칩 상호연결 | **ICI 전용 3D 토러스 광학 링크** | NVLink / NVSwitch + InfiniBand | 칩 내부 버스 (단일 칩) | QPI / UPI 소켓 인터커넥트 |
| 소프트웨어 스택 | **XLA (JAX, TensorFlow 최적화)** | CUDA, cuDNN, TensorRT, PyTorch | TFLite, ONNX Runtime | 표준 C/C++, OpenMP |
| 전력 및 집적도 | **매우 높음 (AI 전용 설계로 고효율)** | 높음 (범용 연산기 병행 집적) | **초저전력 (밀리와트~수 와트)**| 보통 |
| 주요 적용 분야 | **Google Cloud 초대형 LLM 학습/추론** | **전 세계 AI 연구 및 범용 훈련/추론**| 스마트폰, IoT 실시간 추론 | 범용 비즈니스 컴퓨팅 |

#### 한줄 요약
- 구글 클라우드 기반 초대규모 분산 학습에는 TPU가 최강의 가성비를 내며, 범용 생태계와 다양한 연구에는 GPU가 표준이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **형상 버킷팅(Shape Bucketing)**: 가변 길이 텍스트 입력을 사전에 정의된 몇 개의 고정 크기(128, 512, 2048 등)로 패딩하여 XLA 컴파일러의 잦은 재컴파일을 방지하는 기술.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 가변 입력 길이에 따른 XLA 컴파일러의 잦은 재컴파일 지연 | **형상 버킷팅(Shape Bucketing) 및 고정 텐서 패딩** 적용 | 정적 그래프 재사용 및 컴파일 오버헤드 100% 제거 |
| 대규모 클러스터 분산 학습 시 칩 간 통신 병목 | **ICI 토러스 토폴로지 맞춤형 텐서/파이프라인 병렬화(SPMD)** | 통신-연산 중첩 및 팟 확장 효율 95% 유지 |
| 단정밀도(FP32) 연산으로 인한 HBM 대역폭 낭비 | **bfloat16 혼합 정밀도 및 손실 스케일링** 적용 | 메모리 대역폭 2배 확보 및 연산 속도 2배 가속 |

#### 한줄 요약
- 실무에서는 형상 버킷팅으로 재컴파일을 막고, ICI 맞춤 병렬화로 통신 병목을 없애며, bfloat16으로 대역폭을 최적화한다.

## Ⅶ. 결론

- 초대형 언어 모델(LLM)의 훈련 및 대규모 추론 인프라를 구축하기 위해 **대규모 시스톨릭 MXU와 ICI 3D 토러스 통신망을 통합한 Google TPU Pod 아키텍처를 도입**하고, 소프트웨어 계층에서는 **XLA 컴파일러의 연산자 융합과 bfloat16 혼합 정밀도 기술**을 표준 적용하며, 가변 입력 처리를 위해 **형상 버킷팅(Shape Bucketing)**을 구축하는 고효율 AI 전용 슈퍼컴퓨팅 플랫폼 확립

#### 한줄 요약
- TPU는 시스톨릭 어레이와 ICI 전용망을 결합한 클라우드 AI 슈퍼컴퓨팅의 핵심이며, XLA 최적화를 통해 엑사플롭스급 성능을 달성한다.
