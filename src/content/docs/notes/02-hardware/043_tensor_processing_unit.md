## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **TPU(Tensor Processing Unit)**: 구글이 텐서플로(TensorFlow)/JAX 프레임워크 및 대규모 딥러닝 연산에 최적화하여 독자 개발한 AI 도메인 특화 가속 프로세서(DSA ASIC).
- **시스톨릭 어레이(Systolic Array)**: 데이터가 프로세서 내부 격자형 연산 셀들을 심장 박동(Systole)처럼 주기적으로 흘러가며 레지스터 접근 없이 연산을 누산하는 하드웨어 구조.

</details>

- 정의/개념: 구글이 딥러닝 텐서 연산(행렬 곱셈 및 누산)을 초고속으로 처리하기 위해 개발한 **도메인 특화 ASIC 프로세서**
- 배경/필요성: 범용 구조는 행렬 곱셈의 중간 부분합을 연산마다 레지스터·메모리에 반복 저장해 연산보다 데이터 이동 비용이 커지며 **행렬 연산 처리 효율**을 떨어뜨리므로, 연산기를 격자로 배열해 부분합을 인접 셀로 흘려보내는 전용 데이터 경로로 이동 자체를 없앨 필요

#### 한줄 요약
- TPU는 2D 시스톨릭 행렬곱 연산기(MXU)와 대용량 SRAM 버퍼를 결합하여 행렬 연산 처리량과 전력 효율을 극대화한 구글의 AI 전용 칩이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **MXU(Matrix Multiply Unit)**: TPU의 핵심 연산 엔진으로, 수만 개의 곱셈 누산기(MAC)가 2차원 격자로 배열되어 bfloat16 행렬 곱을 1클록에 처리하는 시스톨릭 어레이.
- **bfloat16 (Brain Floating Point)**: FP32와 동일한 지수부(8비트)를 유지하고 가수부를 7비트로 축소하여 FP32의 동적 범위를 보존하면서 대역폭을 절반으로 줄인 16비트 포맷.
- **ICI(Inter-Chip Interconnect)**: 호스트 CPU나 외부 네트워크 스위치를 거치지 않고 TPU 칩 간을 직접 고속 연결하는 구글 전용 광학/전기 인터커넥트.

</details>

- 시스톨릭 데이터 재사용: **MXU** 내부에서 셀 간에 데이터를 직접 전달하여 레지스터 및 외부 HBM 메모리 접근 트래픽 90% 이상 절감
- 컴파일러 기반 연산자 융합: **XLA 컴파일러**가 딥러닝 연산 그래프를 분석하여 다중 연산자를 단일 기계어 커널로 융합
- 선형적 분산 확장성: **ICI(Inter-Chip Interconnect)** 전용 링크를 기반으로 수천 개 칩을 3D 토러스(Torus) 망으로 묶어 단일 슈퍼컴퓨터(TPU Pod)처럼 운용

#### 한줄 요약
- MXU 시스톨릭 어레이와 XLA 컴파일러 융합, ICI 전용 토러스 네트워크를 통해 수천 칩의 선형적 확장을 보장한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **벡터 처리 유닛(Vector Processing Unit, VPU)**: 활성화 함수(GELU, ReLU), 레이어 정규화(LayerNorm), 소프트맥스 등 벡터 연산을 전담하는 SIMD 유닛.
- **TPU Pod**: 수천 개의 TPU 칩을 ICI 초고속 광학 토러스 망으로 결합하여 엑사플롭스(ExaFLOPS)급 연산력을 제공하는 대규모 클러스터 시스템.

</details>

```text
[Google TPU 코어 실리콘 아키텍처]
 ├─ 고대역폭 메모리 인터페이스 (HBM3 / HBM3E)
 ├─ 전용 연산 유닛 계층
 │   ├─ 2D 시스톨릭 행렬 곱셈기 (MXU: 128x128 / 256x256 MAC)
 │   ├─ 벡터 처리 유닛 (VPU: 활성화, 정규화, 소프트맥스)
 │   └─ 스칼라 연산기 (주소 계산, 루프 제어, DMA 제어)
 ├─ 벡터 및 가중치 온칩 메모리 버퍼 (VMem / WMem SRAM)
 └─ 칩 간 인터커넥트 라우터 (ICI Router: 3D Torus 광통신망)
```

선의 의미: 가지(`├─`, `└─`)는 하드웨어 소속 및 포함 관계를 나타냄

| 구성요소 | 소속 및 위치 | 핵심 엔지니어링 책임 | 주요 특징 |
|:---|:---|:---|:---|
| MXU (Matrix Multiply Unit) | 코어 중심 연산기 | 2차원 시스톨릭 어레이 기반 **bfloat16 행렬 곱셈 누산** | 128x128 MAC 셀 |
| VPU (Vector Processing Unit) | 코어 벡터 연산기 | 활성화(GELU), 정규화(LayerNorm), 소프트맥스 등 **비선형 연산** | 초광폭 SIMD 파이프라인 |
| 스칼라 유닛 | 코어 제어기 | 메모리 주소 계산, 제어 흐름 분기 및 **파이프라인 동기화** | 경량 RISC 코어 |
| ICI 라우터 | 칩 경계 통신망 | 호스트 경유 없는 **칩 간 3D 토러스 고속 텐서 전송** | 초저지연 패킷 라우터 |
| HBM 인터페이스 | 메모리 인터페이스 | 초대형 모델 가중치와 활성화 텐서에 **초광폭 대역폭 공급** | 다채널 HBM 서브시스템 |

#### 한줄 요약
- MXU가 시스톨릭 셀 사이로 데이터를 흘려 곱셈마다 되풀이되던 메모리 재접근을 없애고, 활성화·정규화 같은 비선형 연산은 VPU가, 주소 계산과 분기는 경량 스칼라 유닛이 떼어 맡아 MXU를 행렬곱 전용으로 비워 둔다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **연산자 융합(Operator Fusion)**: 여러 개의 개별 연산(MatMul + Bias + GELU)을 하나의 통합 하드웨어 루프로 결합하여 HBM 메모리 접근을 없애는 최적화.

</details>

```text
[AI 모델 그래프 정의 및 입력]
         │
         ▼
1. XLA 컴파일러의 연산 그래프 분석 및 연산자 융합
         │
         ▼
2. 가중치 텐서 온칩 버퍼 및 MXU 셀 적재
         │
         ▼
3. MXU 2D 시스톨릭 어레이 기반 스트리밍 행렬곱 연산
         │
         ▼
4. VPU 비선형 활성화 및 레이어 정규화 적용
         │
         ▼
5. ICI 라우터 기반 분산 그래디언트 동기화
         │
         ▼
[최종 출력 텐서 반환]
```

분기 결과: TPU Pod 환경에서는 ICI 토러스망을 통해 칩 간 텐서 동기화가 하드웨어적으로 즉시 완료되어 **대규모 선형 확장** 유지

#### 한줄 요약
- 연산자 융합은 레이어마다 반복되던 HBM 왕복을 온칩 루프 하나로 접고, 칩 간 그래디언트 동기화는 ICI가 대신 맡아 규모를 키워도 통신이 확장의 상한이 되지 않게 한다.

## Ⅴ. 종류 및 비교

| 비교 항목 | Google TPU (v4 / v5p) | NVIDIA GPU (H100 / B200) | 온디바이스 NPU | 범용 CPU |
|:---|:---|:---|:---|:---|
| 핵심 연산 구조 | 대규모 **시스톨릭 어레이(MXU)** | SIMT 스트리밍 멀티프로세서 | 저전력 정수 MAC 어레이 | 범용 OoO 실행 파이프라인 |
| 다중 칩 상호연결 | **ICI 전용 3D 토러스 링크** | NVLink / NVSwitch + InfiniBand | 칩 내부 버스 (단일 칩) | QPI / UPI 소켓 인터커넥트 |
| 소프트웨어 스택 | **XLA (JAX, TensorFlow 최적화)** | CUDA, cuDNN, TensorRT, PyTorch | TFLite, ONNX Runtime | 표준 C/C++, OpenMP |
| 전력 및 집적도 | **매우 높음 (AI 전용 고효율)** | 높음 (범용 연산기 병행 집적) | **초저전력 (밀리와트~수 와트)** | 보통 |
| 주요 적용 분야 | **초대형 LLM 학습/추론 서빙** | **전 세계 AI 연구 및 범용 가속** | 스마트폰, IoT 실시간 추론 | 범용 비즈니스 컴퓨팅 |

#### 한줄 요약
- 구글 클라우드 기반 초대규모 분산 학습에는 TPU가 최강의 가성비를 내며, 범용 생태계와 다양한 연구에는 GPU가 표준이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **형상 버킷팅(Shape Bucketing)**: 가변 길이 텍스트 입력을 사전에 정의된 몇 개의 고정 크기(128, 512, 2048 등)로 패딩하여 XLA 컴파일러의 잦은 재컴파일을 방지하는 기술.

</details>

| 문제 상황 | 대책 | 엔지니어링 효과 |
|:---|:---|:---|
| 가변 입력 길이에 따른 XLA 잦은 재컴파일 | **형상 버킷팅(Shape Bucketing)** 및 고정 패딩 | 컴파일 오버헤드 **완전 제거** |
| 대규모 분산 학습 시 칩 간 통신 병목 | **ICI 토러스 토폴로지 맞춤형 SPMD** 병렬화 | 팟 확장 효율 **95% 유지** |
| 단정밀도(FP32) 연산으로 인한 HBM 대역폭 낭비 | **bfloat16 혼합 정밀도** 및 손실 스케일링 | 메모리 대역폭 **2배 확보** |

#### 한줄 요약
- 실무에서는 형상 버킷팅으로 재컴파일을 막고, ICI 맞춤 병렬화로 통신 병목을 없애며, bfloat16으로 대역폭을 최적화한다.

## Ⅶ. 결론

- **초대규모 분산 학습** 요구 시 **시스톨릭 MXU**와 ICI 기반 인프라 구축

#### 한줄 요약
- TPU는 시스톨릭 어레이와 ICI 전용망을 결합한 클라우드 AI 슈퍼컴퓨팅의 핵심이며, XLA 최적화를 통해 엑사플롭스급 성능을 달성한다.
