## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **3D 적층 메모리(3D Stacked Memory)**: 여러 장의 메모리 다이(DRAM/NAND)를 수직으로 쌓아 올리고 수직 인터커넥트로 결합하여 초광폭 버스와 고집적도를 달성하는 3차원 반도체 기술.
- **TSV(Through-Silicon Via)**: 실리콘 웨이퍼 다이를 수직으로 완전히 관통하는 미세 구리 기둥 전극을 형성하여 상하 칩 간 신호와 전력을 최단 거리로 연결하는 기술.

</details>

- 정의/개념: 여러 메모리 다이를 수직으로 쌓고 **TSV(Through-Silicon Via)** 기반 관통 연결해 용량과 버스 폭을 함께 늘린 **3D 적층 메모리(3D Stacked Memory)**
- 배경/필요성: 평면 패키징에서는 칩 가장자리에 낼 수 있는 핀 수가 물리적으로 제한돼, 대역폭을 늘리려면 배선을 옆이 아니라 위로 내야 함

#### 한줄 요약
- 이 기술이 푼 문제는 메모리 속도가 아니라 배선을 낼 자리이며, 그래서 해법이 소자 개선이 아니라 3차원 배치에서 나왔다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **초광폭 I/O(Wide I/O)**: 기존 DDR 메모리의 64비트 버스 대비 16배 넓은 1024비트~2048비트 버스를 사용하여 클록 주파수를 낮추면서도 테라바이트급($\text{TB/s}$) 대역폭을 달성하는 구조.
- **KGD(Known Good Die)**: 적층 조립 전 규정된 다이 테스트를 통과한 양품 후보 다이.

</details>

- **초광폭 I/O(Wide I/O)** 기반 클록을 낮추면서도 대역폭을 확보
- 인터포저 위에서 연산 다이와 메모리를 최단 거리로 직결
- 적층 수율 확보를 위한 **KGD(Known Good Die)** 선별과 리던던시 수리

#### 한줄 요약
- 넓고 느린 버스가 좁고 빠른 버스보다 에너지 효율이 좋다는 점이 설계의 근거이며, 대역폭을 클록이 아니라 폭으로 산 결과다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **실리콘 인터포저(Silicon Interposer)**: PCB 기판 상에서 구현 불가능한 수천 가닥의 초미세 금속 배선을 연결하기 위해 GPU와 HBM 하단에 배치되는 2.5D 중계 기판.
- **베이스 로직 다이(Base Logic Die)**: HBM 스택 맨 아래 위치하여 호스트 컨트롤러 인터페이스, BIST 테스트 및 오류 정정(ECC)을 전담하는 제어 다이.

</details>

```text
[3D 적층 메모리 패키지]
├─ 연산 다이 (GPU·가속기)
│  └─ 호스트 메모리 컨트롤러
├─ 메모리 스택
│  ├─ DRAM 코어 다이 × N (수직 적층)
│  ├─ TSV 관통 전극 (층 간 신호·전력 전달)
│  └─ 베이스 로직 다이 (인터페이스·테스트·오류 정정)
├─ 실리콘 인터포저 (연산 다이와 스택 간 광폭 배선)
└─ 패키지 기판
```

선의 의미: 가지(`├─`)는 소유 관계이며, 인터포저가 수평 배선을 TSV가 수직 배선을 각각 담당

| 구성요소 | 책임 |
|:---|:---|
| 호스트 메모리 컨트롤러 | 채널 단위로 명령·주소를 병렬 발행 |
| **실리콘 인터포저(Silicon Interposer)** | 기판에 낼 수 없는 초미세 배선망 제공 |
| **베이스 로직 다이(Base Logic Die)** | 호스트 인터페이스·테스트·오류 정정 담당 |
| TSV 관통 전극 | 층 사이로 신호와 전력을 최단 거리로 전달 |
| DRAM 코어 다이 스택 | 다층 적층으로 용량 확보와 광폭 데이터 방출 |

#### 한줄 요약
- 인터포저와 TSV 어느 하나만 없어도 성립하지 않으므로 이 기술의 진입 장벽은 메모리 설계가 아니라 첨단 패키징 공정 접근권에 있다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **슈도 채널(Pseudo-Channel)**: 1024비트 물리 버스를 2~4개의 독립된 채널(예: 128비트 단위)로 가상 분할하여 개별 뱅크에 동시 병렬 접근하도록 하는 기술.

</details>

```text
호스트가 메모리 읽기 요청 발행
        │
   주소를 채널·뱅크·행·열로 분해
        │
   요청이 여러 채널에 고르게 나뉘는가?
   ┌────┴─────┐
  예           아니오
   │             │
채널별 병렬     한 채널로 직렬화되어
동시 진행       광폭 버스가 남아돎
   └────┬────────┘
        │
   인터포저 배선으로 명령·주소 전달
        │
   TSV가 해당 층 다이까지 수직 분배
        │
   뱅크 행 활성화 후 광폭 레인으로 병렬 반환
```

분기 결과: 물리 대역폭은 항상 같지만 요청이 한 채널에 몰리면 나머지 레인이 놀게 되므로, 실효 성능은 배선 폭이 아니라 주소 분산 방식이 결정

#### 한줄 요약
- **슈도 채널(Pseudo-Channel)**을 기반으로 버스를 잘게 나누는 이유가 여기에 있으며, 한 번에 많이 옮기는 것보다 여러 요청을 겹치는 편이 실제로 더 빠르다.

## Ⅴ. 종류 및 비교

| 메모리 적층 및 구조 기술 | 3D HBM (DRAM 적층) | 3D V-NAND (플래시) | 2D DDR5 DIMM | CXL 메모리 익스팬더 |
|:---|:---|:---|:---|:---|
| 적용 기준 | AI 가속기 및 슈퍼컴퓨터 초고대역폭 | SSD 및 모바일 대용량 비휘발 저장 | PC 및 범용 서버 메인 메모리 | 데이터센터 메모리 풀링 및 확장 |
| 핵심 특징 | TSV 기반 광폭 버스와 근접 패키징 | 메모리 셀·게이트의 수직 적층 | DIMM 채널과 표준 서버 메모리 생태계 | CXL 기반 캐시 일관성·메모리 확장 |
| 한계 | 고비용 및 첨단 패키징 제조 난이도 | 블록 단위 소거 및 느린 I/O 속도($\mu s$) | 핀 수 한계로 인한 대역폭 병목 | PCIe 인터페이스 경유로 인한 지연 증가 |

#### 한줄 요약
- 네 기술은 대역폭·용량·확장성 중 무엇을 포기했는지로 갈리며, 적층 메모리는 사후 증설 가능성을 통째로 내주고 대역폭을 샀다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **더미 TSV(Dummy TSV)**: 신호 전달 목적이 아닌 적층 다이 내부의 열을 패키지 외부 방열판으로 신속 배출하기 위한 열 전도 전용 금속 기둥.
- **하이브리드 본딩(Hybrid Bonding, Cu-Cu)**: 마이크로 범프를 없애고 구리와 절연막을 원자 단위로 직접 접합하여 피치를 $1\mu\text{m}$ 이하로 줄이고 열 저항을 낮추는 차세대 공정.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 고단 적층으로 열 밀도와 층별 온도 편차 증가 | **더미 TSV(Dummy TSV)** 및 열 해석 기반 냉각 설계 | 접합 온도와 층 간 열 불균형 완화 |
| 적층 후 다이 하나의 결함이 스택 전체를 폐기 | 사전 선별·리던던시 셀·조립 후 시험 범위 확대 | 완성 단계 폐기 위험 감소 |
| 수많은 신호의 동시 스위칭으로 전압 강하와 노이즈 | 전력 전달 경로 최적화와 온다이 디커플링 집적 | 전원 안정성 확보와 신호 왜곡 방지 |
| 접합 피치 한계로 I/O 밀도와 저항이 정체 | 성숙도에 따라 **하이브리드 본딩(Hybrid Bonding, Cu-Cu)** 검토 | 미세 피치·저저항과 공정 난이도의 절충 |

#### 한줄 요약
- 네 문제 모두 다이를 쌓았기 때문에 생기므로, 적층으로 얻은 대역폭의 상당 부분은 열과 수율과 전원 관리 비용으로 되돌려 준다.

## Ⅶ. 결론

- 대역폭당 전력이 병목인 연산에는 적층 메모리를, 용량과 교체 가능성·원가가 중요한 영역에는 표준 모듈이나 확장 메모리를 배치해 계층화하고, 채택 판단은 대역폭 실측과 패키지 수율·열·용량 비용 종합 계산 및 고려

#### 한줄 요약
- 대역폭이 늘어도 연산이 데이터를 재사용하지 못하면 병목은 그대로 남으므로, 이 메모리의 값어치는 하드웨어가 아니라 그 위에 올릴 알고리즘이 증명한다.
