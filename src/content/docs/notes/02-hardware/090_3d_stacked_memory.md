## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **3D 적층 메모리(3D Stacked Memory)**: 여러 장의 DRAM 또는 NAND 플래시 메모리 다이를 수직으로 쌓아 올리고 실리콘 관통 전극(TSV)으로 상하를 직접 연결하여 초광폭 버스와 고집적도를 달성하는 3차원 반도체 패키징 기술.
- **실리콘 관통 전극(Through-Silicon Via, TSV)**: 실리콘 다이 웨이퍼를 수직으로 완전히 관통하는 미세 구리 기둥 전극을 형성하여 상하 다이 간 신호와 전력을 최단 거리로 직결하는 인터커넥트 기술.

</details>

- 정의/개념: 복수의 메모리 다이를 수직으로 적층하고 **TSV(Through-Silicon Via) 및 2.5D 실리콘 인터포저**를 통해 연산 프로세서와 초근접 연결하는 **3D 적층 메모리(HBM / 3D V-NAND) 아키텍처**
- 배경/필요성: 기존 2D 평면 패키징의 제한된 PCB 핀 수(64-bit)와 긴 배선 길이로 인한 **심각한 메모리 벽(Memory Wall) 대역폭 병목 극복**

#### 한줄 요약
- TSV 관통 전극과 2.5D 인터포저를 활용해 테라바이트급 초고대역폭(TB/s)과 고밀도 집적을 실현한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **초광폭 I/O 버스(Wide I/O)**: 기존 DDR 메모리의 64비트 버스 대비 16배 이상 넓은 1024비트~2048비트 병렬 버스를 사용하여 클록을 무리하게 높이지 않고도 초당 수 테라바이트(TB/s)의 대역폭을 달성하는 구조.
- **양품 선별 다이(Known Good Die, KGD)**: 수직 적층 패키징 조립 전에 엄격한 전수 웨이퍼 테스트를 통과하여 100% 무결성이 검증된 단일 다이.

</details>

- 테라바이트급 초고대역폭: **1024비트~2048비트 초광폭 I/O 버스**를 통해 1.2TB/s~2.0TB/s 이상의 데이터 처리 속도 달성
- 초저지연 및 고효율 에너지: 2.5D 실리콘 인터포저 상에서 GPU와 HBM을 마이크로미터 단위로 초근접 배치하여 I/O 구동 에너지(pJ/bit) 극소화
- 고단 수직 집적: DRAM 다이를 8단, 12단, 16단(16H)으로 적층하고 **KGD 선별**과 베이스 로직 다이 내 리던던시 회로로 수율 확보

#### 한줄 요약
- 넓은 버스 폭(1024비트+)과 수직 TSV 연결을 통해 저전력으로 극한의 메모리 대역폭을 공급한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **실리콘 인터포저(Silicon Interposer)**: PCB 기판 상에서 구현 불가능한 수천 가닥의 초미세 서브미크론 병렬 금속 배선을 연결하기 위해 GPU와 HBM 하단에 배치되는 2.5D 중계 기판.
- **베이스 로직 다이(Base Logic Die)**: HBM 스택 최하단에 위치하여 호스트 컨트롤러 인터페이스 PHY, 채널 라우팅, 자체 테스트(BIST) 및 온다이 ECC를 전담하는 제어 다이.

</details>

```text
[3D 적층 HBM 및 2.5D 인터포저 시스템 아키텍처]
 ┌─ [연산 프로세서 다이] ────────────── GPU / NPU 호스트 메모리 컨트롤러
 │                                           │ (1024비트 초광폭 버스)
 ├─ [2.5D 실리콘 인터포저 (Interposer)] ────┴──────────────────────────────────────────────┐
 │   (초미세 서브미크론 병렬 금속 배선망 + 실리콘 딥 트렌치 커패시터 DTC)                   │
 │                                                                                          │
 └─ [3D HBM3e 메모리 스택] ─────────────────────────────────────────────────────────────────┘
     ├─ DRAM 코어 다이 (8~16층 수직 적층) ── 고밀도 DRAM 메모리 셀 어레이
     ├─ [TSV 관통 전극 어레이] ────────────── 실리콘 관통 수천 개 구리 기둥 (신호/전력 직결)
     └─ [베이스 로직 다이 (Base Die)] ────── PHY 인터페이스 + BIST 엔진 + [온다이 ECC]
```

선의 의미: 가지(`├─`, `└─`)는 하드웨어 소속 및 3D 수직/수평 패키징 구조; GPU와 HBM이 인터포저를 통해 수평 연결되고 HBM 내부는 TSV로 수직 직결됨

| 구성요소 | 계층 및 위치 | 핵심 엔지니어링 책임 | 주요 특징 |
|:---|:---|:---|:---|
| **호스트 컨트롤러** | GPU 실리콘단 | 1024비트 초광폭 채널로 대용량 메모리 읽기/쓰기 명령 병렬 발행 | 광폭 PHY 제어 |
| **DRAM 코어 다이 스택**| HBM 수직 스택단 | 고밀도 DRAM 셀 어레이를 8~16단 수직 적층하여 고용량(24~48GB) 공급 | 16H 고단 적층 |
| **TSV 관통 전극** | 적층 다이 내부 | 실리콘 웨이퍼를 관통하는 수천 개의 구리 기둥으로 **상하 다이를 최단거리 직결** | 수직 인터커넥트 |
| **베이스 로직 다이** | HBM 최하단 | 호스트 인터페이스 PHY, BIST 자체 테스트 및 **온다이 ECC 오류 정정** 전담 | 로직 제어 다이 |
| **2.5D 실리콘 인터포저**| 패키지 중계단 | GPU와 HBM 간 수천 개의 마이크로 범프 배선을 **초미세 금속선으로 고밀도 연결** | 서브미크론 배선 |

#### 한줄 요약
- 3D 적층 메모리는 DRAM 코어 스택, TSV 전극, 베이스 로직 다이, 2.5D 실리콘 인터포저 및 GPU 호스트로 구성된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **슈도 채널(Pseudo-Channel)**: 1024비트 물리 버스를 복수의 독립적인 세부 채널(예: 128비트 채널 8개)로 가상 분할하여 동시 병렬 접근을 지원하는 기술.

</details>

```text
1. 호스트 GPU: 1024비트 초광폭 HBM 대용량 메모리 읽기 요청 발행
                      │
                      ▼
2. GPU 메모리 컨트롤러: 주소를 슈도 채널(Pseudo-Channel) 및 타깃 뱅크 번호로 디코딩
                      │
                      ▼
3. 2.5D 실리콘 인터포저의 초미세 병렬 배선을 통해 HBM 베이스 로직 다이로 전송
                      │
                      ▼
4. 베이스 로직 다이 ➔ TSV 수직 관통 전극을 통해 목표 층 DRAM 코어 다이로 신호 분배
                      │
                      ▼
5. DRAM 코어 셀 어레이: 행 활성화(Row Active) 및 온다이 ECC 무결성 검증 수행
                      │
                      ▼
6. 1024비트 병렬 데이터 레인을 통해 실리콘 인터포저를 거쳐 GPU로 TB/s 데이터 반환
```

분기 결과: **TSV 수직 직결과 초광폭 인터포저를 통해** 나노초 단위의 지연시간과 단일 스택당 1.2TB/s 이상의 압도적 대역폭을 달성함

#### 한줄 요약
- GPU 요청 ➔ 슈도 채널 디코딩 ➔ 인터포저 전달 ➔ TSV 수직 분배 ➔ 광폭 병렬 반환 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **3D V-NAND**: 평면 플래시 셀 간의 간섭 한계를 극복하기 위해 메모리 게이트를 수직으로 200~300단 이상 쌓아 올리는 비휘발성 저장 기술.

</details>

| 메모리 적층 및 구조 방식 | 3D HBM (DRAM 수직 적층) | 3D V-NAND (플래시 적층) | 2D DDR5 DIMM | CXL 메모리 익스팬더 |
|:---|:---|:---|:---|:---|
| 핵심 적층 메커니즘 | **다이 단위 TSV 수직 관통 적층** | **모놀리식 게이트 200단+ 수직 적층**| 적층 없음 (평면 PCB 실장) | PCIe 버스 기반 외장 모듈 |
| 데이터 버스 폭 | **1024 ~ 2048 비트 (초광폭)** | 블록/페이지 단위 직렬 | 64 비트 (채널당 32비트 듀얼) | x8 / x16 직렬 PCIe 레인 |
| 실효 전송 대역폭 | **1.2 ~ 2.0 TB/s (극초고대역)**| 수 GB/s | 38.4 ~ 64 GB/s | 64 ~ 128 GB/s |
| 주요 적용 분야 | **AI 가속기 (H100, B200), HPC** | 초고용량 NVMe SSD, 스마트폰 | 범용 PC, 표준 서버 메인 메모리| **데이터센터 메모리 풀링 및 확장** |

#### 한줄 요약
- 초고대역폭 AI 가속에는 3D HBM이, 대용량 영구 저장에는 3D V-NAND가, 표준 확장은 DDR5/CXL이 쓰인다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **더미 TSV(Dummy TSV)**: 전기 신호 전달 목적이 아닌 적층 다이 내부의 집중된 열을 외부 방열판으로 신속히 배출하기 위한 열전도 전용 구리 기둥.
- **하이브리드 본딩(Hybrid Bonding, Cu-Cu)**: 마이크로 범프 없이 구리 전극과 절연막을 원자 단위로 직접 접합하여 피치를 $1\mu\text{m}$ 이하로 줄이고 열 저항을 낮추는 공정.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 16단(16H) 고단 적층으로 인한 칩 내부 열 집중 및 스로틀링 | **더미 TSV(Dummy TSV) 방열 기둥 배치 및 직접 액체 냉각(DLC)** | 내부 접합 온도 15도 저하 및 고클록 대역폭 유지 |
| 수천 개 신호 동시 스위칭으로 인한 급격한 전압 강하(IR Drop) | **실리콘 인터포저 내 딥 트렌치 커패시터(DTC) 고밀도 내장** | 전원 무결성(PI) 확보 및 스위칭 노이즈 억제 |
| 마이크로 범프 접합 피치 한계로 인한 두께 증가 및 신호 저항 | **차세대 범프리스 하이브리드 본딩(Cu-Cu 접합) 공정 도입** | I/O 밀도 10배 증대 및 층간 높이 30% 축소 |

#### 한줄 요약
- 실무에서는 더미 TSV와 DLC로 열을 식히고, DTC로 전압을 안정화하며, 하이브리드 본딩으로 고밀도를 실현한다.

## Ⅶ. 결론

- 초거대 AI 가속기 및 슈퍼컴퓨터의 메모리 벽을 돌파하기 위해 **1024비트 광폭 버스와 TSV를 결합한 3D HBM3e/HBM4 적층 메모리를 표준 채택**하고, 열 집중 및 배선 한계를 극복하기 위해 **하이브리드 본딩(Cu-Cu) 및 직접 액체 냉각(DLC)**을 적용하며, 대규모 용량 확장을 위해 **CXL 메모리 풀링과 연계**하는 차세대 3차원 메모리 아키텍처 확립

#### 한줄 요약
- 3D 적층 메모리는 반도체 미세화의 물리적 한계를 3차원 패키징 혁신으로 극복한 AI 하드웨어의 핵심 엔진이다.
