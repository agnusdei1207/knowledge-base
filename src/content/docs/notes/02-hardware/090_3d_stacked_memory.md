## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **3D Stacked Memory(3D 적층 메모리)**: 복수의 메모리 실리콘 다이를 수직으로 적층하고 수직 전기 통로로 상호 결합하여 초광폭 버스와 고밀도를 달성하는 3차원 패키징 메모리.
- **TSV(Through-Silicon Via, 실리콘 관통 전극)**: 실리콘 웨이퍼 다이를 수직으로 완전히 관통하는 미세 구리 기둥을 형성하여 신호와 전력을 최단 거리로 연결하는 전극.
- **Base Die(Logic/Buffer Die)**: 적층 메모리 최하단에 위치하여 호스트 컨트롤러 인터페이스, 테스트(BIST), 물리 계층 신호 분배 및 오류 정정(ECC)을 담당하는 로직 다이.

</details>

- 정의/개념: 다수의 메모리 다이(DRAM/NAND)를 수직으로 적층하고, 실리콘 관통 전극(TSV: Through-Silicon Via) 및 마이크로 범프(Microbump)로 상호 연결하여 1024비트 이상의 초광폭(Wide I/O) 버스를 구현한 고밀도·초고대역폭 3차원 적층 메모리 반도체 아키텍처
- 배경/필요성: AI 딥러닝 및 대규모 HPC 연산에서 프로세서 연산 속도 대비 폰 노이만 메모리 대역폭 병목(Memory Wall)을 해소하고, **서브스트레이트 면적 절감 및 단위 전력당 대역폭(GB/s/W) 극대화 필수**

#### 한줄 요약

- TSV 수직 배선 기반으로 **초광폭(1024-bit) 버스와 테라바이트급 초고대역폭을 달성하는 3D 적층 메모리(HBM)**

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **Wide I/O**: 기존 DDR의 64비트 버스 폭 대신 1024비트~2048비트의 초광폭 데이터 핀을 배치하여 상대적으로 낮은 클록 주파수에서도 테라바이트급 대역폭을 구현하는 구조.
- **Microbump**: 수십 마이크로미터($\mu\text{m}$) 피치를 갖는 미세 땜납 돌기로 상하 DRAM 다이 간의 TSV를 물리적/전기적으로 결합하는 접합점.
- **KGD(Known Good Die)**: 다이를 수직 적층하기 전에 개별 웨이퍼 레벨에서 엄격한 번인(Burn-in) 및 기능 테스트를 완벽히 통과하여 100% 정상 동작이 검증된 다이.

</details>

- 64비트 공유 버스의 한계를 넘어 1024비트 병렬 전송 라인을 제공하는 **초광폭 I/O(Wide I/O) 고대역폭 구조**
- 다단 적층 시 단일 결함 다이로 인한 전체 스택 폐기를 방지하기 위한 **KGD(Known Good Die) 선별 및 리던던시 수리**
- 수직 집적으로 인한 단위 체적당 발열 증가를 제어하기 위한 **열 밀도(Thermal Density) 방열 설계 필수**

#### 한줄 요약

- **1024비트 초광폭 버스(Wide I/O)·KGD(Known Good Die) 선별 수율 관리·수직 적층 열 밀도(Thermal Density) 제어**

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **Silicon Interposer**: 유기물 PCB 메인보드 상에서 구현 불가능한 수천 가닥의 미세 서브미크론 배선을 지원하기 위해 GPU와 HBM 하단에 배치되는 2.5D 실리콘 중계 기판.
- **DRAM Core Stack**: TSV와 마이크로 범프로 4층, 8층, 12층, 16층 등으로 수직 적층된 실제 DRAM 셀 어레이 다이들의 집합.

</details>

```text
[ 3D HBM 적층 메모리 및 2.5D 인터포저 아키텍처 ]
 
 [ GPU / AI 가속기 다이 ]         [ 3D HBM 적층 메모리 스택 ]
┌────────────────────────┐       ┌────────────────────────┐
│ GPU 연산 코어 및       │       │ DRAM 다이 4 (Core Die) │
│ HBM 메모리 컨트롤러    │       ├────────────────────────┤
│                        │       │ DRAM 다이 3 (Core Die) │ ◄─ [ TSV 수직 관통 전극 ]
│                        │       ├────────────────────────┤
│                        │       │ DRAM 다이 2 (Core Die) │ ◄─ [ Microbump 접합 ]
│                        │       ├────────────────────────┤
│                        │       │ DRAM 다이 1 (Core Die) │
│                        │       ├────────────────────────┤
│                        │       │ 베이스 로직 다이 (Base)│
└───────────┬────────────┘       └───────────┬────────────┘
            │ [ 1024-bit 초미세 배선 ]       │
┌───────────┴────────────────────────────────┴────────────┐
│ 2.5D 실리콘 인터포저 (Silicon Interposer Substrate)      │
├─────────────────────────────────────────────────────────┤
│ 패키지 기판 (Package BGA Substrate)                      │
└─────────────────────────────────────────────────────────┘
```

선의 의미: GPU/호스트 프로세서, 2.5D 실리콘 인터포저, 1층 로직 베이스 다이, TSV/마이크로 범프 및 3D 적층 DRAM 코어 다이 간의 HBM 아키텍처 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 메모리 제어기 | GPU나 CPU 안에서 "데이터 당장 내놔!" 하고 1024개 차선으로 명령을 쏴버리는 악덕 지휘관 |
| 실리콘 인터포저 | 메인보드 선으로는 감당 안 되는 1024가닥 미세 배선을 깔아주기 위해 GPU와 메모리 밑에 깔아둔 마법의 실리콘 도마 |
| 베이스 다이 | 아파트(메모리) 1층에 입주해서, GPU가 내리는 명령을 위층으로 배달하고 에러를 고쳐주는 똑똑한 로직 경비원 |
| TSV • 마이크로 범프 | 아파트 위아래 층을 수직으로 뚫어버린 엘리베이터(TSV)와 층과 층 사이를 붙여주는 극미세 땜납(마이크로 범프) |
| 디램 코어 스택 | 4층, 8층, 12층으로 겹겹이 쌓여서 데이터를 무식하게 짱박아두는 깡통 메모리 집합소 |

#### 한줄 요약

- **메모리 제어기(Host Controller)·2.5D 실리콘 인터포저·로직 베이스 다이(Base Die)·TSV/마이크로 범프·DRAM 코어 스택**

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Pseudo-Channel**: 1024비트 버스를 2개~4개의 독립된 채널(예: 128비트 단위)로 가상 분할하여 개별 뱅크에 동시 접근하도록 하는 병렬화 기술.

</details>

```text
[ 3D 적층 메모리 데이터 요청 및 수직 전송 시퀀스 ]
                         │
                         ▼
   [ 1. GPU 메모리 컨트롤러가 Pseudo-Channel 명령 및 주소 발행 ]
                         │
                         ▼
   [ 2. 2.5D 실리콘 인터포저의 1024비트 미세 배선을 통해 신호 전달 ]
                         │
                         ▼
   [ 3. 베이스 로직 다이(Base Die)가 명령 디코딩 및 타깃 스택 층수 판별 ]
                         │
                         ▼
   [ 4. TSV 구리 기둥을 통해 타깃 DRAM 다이(예: 3층)로 수직 신호 라우팅 ]
                         │
                         ▼
   [ 5. 해당 층 DRAM 뱅크 활성화 ──> 1024비트 광폭 버스로 데이터 동시 방출 ]
```

**동작 원리**

1. **명령 발행**: 호스트 프로세서가 특정 메모리 주소에 대한 읽기 요청을 Pseudo-Channel 단위로 생성
2. **인터포저 전송**: 수천 개의 마이크로 범프를 거쳐 2.5D 실리콘 인터포저의 초미세 금속 배선을 통해 HBM으로 이동
3. **베이스 다이 디코딩**: 최하단 로직 다이가 주소를 분석하여 몇 번째 DRAM 층(Layer)의 어느 뱅크인지 판정
4. **TSV 수직 구동**: 실리콘 관통 전극(TSV)을 통해 지정된 층까지 전기 신호가 왜곡 없이 수직 상승
5. **초광폭 데이터 반환**: DRAM 셀에서 인출된 데이터를 1024비트 버스 폭으로 쏟아내어 GPU 수신 버퍼로 고속 전송

#### 한줄 요약

- 호스트 메모리 요청 $\to$ **Pseudo-Channel 분할 $\to$ 2.5D 인터포저 배선 $\to$ 베이스 다이 디코딩 $\to$ TSV 수직 관통 $\to$ 목표 DRAM 층 뱅크 활성화 및 1024-bit 광폭 전송 완료**

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **HBM vs 3D V-NAND vs 2D DDR5**:
  - HBM: TSV 수직 적층 DRAM, 1024-bit 광폭 버스, 수 TB/s 초고대역폭, AI/HPC 전용
  - 3D V-NAND: 셀 수백 층 수직 적층 플래시, 대용량 비휘발성 저장, 수 GB/s, SSD
  - 2D DDR5: PCB 수평 실장, 64-bit 공유 버스, 수십 GB/s, 범용 PC/서버

</details>

| 비교 항목 | 고대역폭 메모리 (HBM3e / HBM4) | 3D V-NAND 플래시 (NAND Flash) | 평면 메모리 (2D DDR5 DIMM) |
|:---|:---|:---|:---|
| 집적 방식 및 버스 폭 | TSV 기반 8~16층 DRAM 수직 적층, 1024~2048-bit | 수백 층 수직 적층 게이트(Charge Trap), 8/16-bit | PCB 기판 상 수평 2D 평면 실장, 64-bit 버스 |
| 대역폭 및 지연시간 | 초당 수 TB/s (초고대역폭), 수십 $\text{ns}$ | 초당 수 GB/s (대용량 스토리지), 수십 $\mu\text{s}$ | 초당 수십 GB/s (범용 시스템 메모리), 수십 $\text{ns}$ |
| 한계 및 주 적용 분야 | 고비용 및 패키징 난이도 (AI 가속기, 슈퍼컴퓨터) | 블록 단위 삭제 및 수명 제한 (SSD, 모바일 UFS) | 핀 수 한계로 인한 대역폭 병목 (PC, 범용 서버) |

#### 한줄 요약

- AI 초고대역폭은 **HBM(3D DRAM)**, 대용량 비휘발성은 **3D V-NAND**, 범용 확장은 **평면 DDR5**

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Dummy TSV(더미 TSV)**: 전기적 신호 전달 대신 적층 칩 내부의 열을 패키지 외부로 방출하기 위한 열 전도 전용 구리 기둥 통로.
- **Hybrid Bonding(하이브리드 본딩, Cu-Cu)**: 마이크로 범프 없이 구리와 절연막을 원자 단위로 직접 접합하여 피치를 수 $\mu\text{m}$ 이하로 줄이고 열 저항을 낮추는 차세대 적층 기술.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 12층으로 겹쳐놓은 메모리 한가운데서 열이 폭발해서 칩이 타버리기 직전(**열 스로틀링**) 참사 발발 | 열 빼내는 전용 더미 TSV 구멍을 송송 뚫고 액체 냉각(Liquid Cooling)으로 멱살 잡고 열을 식힘 | 열받아서 기계가 뻗고 성능이 반토막 나는 대참사를 막고 최고 속도 사수 |
| 10층짜리 아파트 다 지어놨는데 3층 불량 나서 비싼 HBM 통째로 쓰레기통에 처박는 수율 지옥 | 쌓기 전에 **노운 굿 다이(KGD)**로 정상 칩만 칼같이 거르고 여분 셀로 고장 난 비트 강제 수리 | 쓰레기통에 처박히는 칩을 살려내서 공정 마진 흑자 전환과 피눈물 나는 단가 방어 달성 |
| 1024가닥 선이 동시에 깜빡일 때마다 전압이 출렁거리고 노이즈가 폭발해 데이터가 박살 나는 재앙 | 칩 구석구석 디커플링 커패시터 떡칠하고 **전력 전달 네트워크(PDN)** 튜닝으로 전기를 꽉 잡아줌 | 전압 출렁임을 씹어먹고 1024가닥 데이터가 0.001초의 오차 없이 깔끔하게 날아가는 신뢰성 확보 |

#### 한줄 요약

- **더미 TSV 방열 통로 및 액체 냉각(Liquid Cooling)·KGD 사전 선별 및 여분(Redundant) 셀 수리·PDN 디커플링 커패시터 전압 안정화**

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **HBM4 및 3D 하이브리드 본딩 진화**: HBM4부터 2048비트 인터페이스를 도입하고 베이스 다이를 최첨단 파운드리 공정(4nm/3nm)으로 제조하여 GPU와 직접 3D 적층하는 방향으로 발전.

</details>

- 생성형 AI 및 LLM 가속 인프라에서 **HBM3e/HBM4 및 3D 다이 투 다이(Die-to-Die) 직접 하이브리드 본딩 표준 채택**

#### 한줄 요약

- **TSV 미세 배선과 인터포저 패키징**을 통한 3D 적층 메모리 대역폭 장벽 돌파
