## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **3D 적층 메모리(3D Stacked Memory)**: 여러 장의 메모리 다이(DRAM/NAND)를 수직으로 쌓아 올리고 수직 인터커넥트로 결합하여 초광폭 버스와 고집적도를 달성하는 3차원 반도체 기술.
- **TSV(Through-Silicon Via)**: 실리콘 웨이퍼 다이를 수직으로 완전히 관통하는 미세 구리 기둥 전극을 형성하여 상하 칩 간 신호와 전력을 최단 거리로 연결하는 기술.

</details>

- 정의/개념: 복수 메모리 다이를 수직 적층하고 **TSV·마이크로 범프**로 연결해 용량·I/O 폭을 높이는 3차원 메모리 기술
- 배경/필요성: AI 초거대 모델 연산 시 2D 평면 패키징의 핀 수 제약에 따른 메모리 벽(Memory Wall) 대역폭 병목 극복 필요

#### 한줄 요약
- 메모리 칩을 아파트처럼 수직으로 쌓고 실리콘 기둥(TSV)으로 뚫어 1024개 차선으로 데이터를 쏟아붓는 초고대역폭 메모리다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **초광폭 I/O(Wide I/O)**: 기존 DDR 메모리의 64비트 버스 대비 16배 넓은 1024비트~2048비트 버스를 사용하여 클록 주파수를 낮추면서도 테라바이트급($\text{TB/s}$) 대역폭을 달성하는 구조.
- **KGD(Known Good Die)**: 적층 조립 전 규정된 다이 테스트를 통과한 양품 후보 다이.

</details>

- 1024비트 병렬 전송 라인을 통한 **초광폭 I/O(Wide I/O) 테라바이트급 대역폭**
- 2.5D 실리콘 인터포저 기반으로 GPU와 메모리를 초단거리 직결하는 **고밀도 패키징**
- 다단 적층 수율 저하를 방지하기 위한 **KGD(Known Good Die) 선별 및 리던던시 수리**

#### 한줄 요약
- 1024비트 광폭 통로로 테라바이트 대역폭을 뚫어주고, KGD 사전 검사로 적층 수율을 방어한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **실리콘 인터포저(Silicon Interposer)**: PCB 기판 상에서 구현 불가능한 수천 가닥의 초미세 금속 배선을 연결하기 위해 GPU와 HBM 하단에 배치되는 2.5D 중계 기판.
- **베이스 로직 다이(Base Logic Die)**: HBM 스택 맨 아래 위치하여 호스트 컨트롤러 인터페이스, BIST 테스트 및 오류 정정(ECC)을 전담하는 제어 다이.

</details>

```text
┌─────────────────────────────────────────────────────────────┐
│ 3D HBM 적층 메모리 및 2.5D 실리콘 인터포저 구조            │
│                                                             │
│  [ GPU / AI 가속기 다이 ]         [ 3D HBM 적층 메모리 스택 ]│
│ ┌────────────────────────┐       ┌────────────────────────┐ │
│ │ GPU 연산 코어 및       │       │ DRAM 다이 4 (Core Die) │ │
│ │ HBM 메모리 컨트롤러    │       ├────────────────────────┤ │
│ │                        │       │ DRAM 다이 3 (Core Die) │ ◄─ [ TSV 관통 전극 ]
│ │                        │       ├────────────────────────┤ │
│ │                        │       │ DRAM 다이 2 (Core Die) │ ◄─ [ Microbump 접합 ]
│ │                        │       ├────────────────────────┤ │
│ │                        │       │ DRAM 다이 1 (Core Die) │ │
│ │                        │       ├────────────────────────┤ │
│ │                        │       │ 베이스 로직 다이 (Base)│ │
│ └───────────┬────────────┘       └───────────┬────────────┘ │
│             │ (1024-bit 초미세 배선)          │              │
│ ┌───────────┴─────────────────────────────────┴───────────┐ │
│ │ 2.5D 실리콘 인터포저 (Silicon Interposer Substrate)      │ │
│ ├─────────────────────────────────────────────────────────┤ │
│ │ 패키지 BGA 기판 (Package Substrate)                     │ │
│ └─────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────┘
```

선의 의미: GPU와 3D 적층 HBM이 2.5D 실리콘 인터포저의 1024비트 미세 배선과 TSV 관통 전극을 통해 수평/수직 초고속 연결

| 구성요소 | 책임 |
|:---|:---|
| 호스트 메모리 컨트롤러 | GPU/NPU 내부에서 1024비트 Pseudo-Channel 명령 및 주소를 병렬 발행 |
| 2.5D 실리콘 인터포저 | GPU와 HBM 간 수천 가닥의 초미세 서브미크론 인터커넥트 배선망 제공 |
| 베이스 다이 (Base Die) | 호스트 인터페이스와 테스트·신호 분배 등 스택 하부 기능 수행 |
| TSV 수직 관통 전극 | 칩 내부를 수직 관통하여 신호 및 전력을 지연과 왜곡 없이 상층 다이로 전달 |
| DRAM 코어 다이 스택 | 4~16개 층으로 수직 적층되어 대용량 데이터를 저장하고 1024비트로 일괄 방출 |

#### 한줄 요약
- 호스트 컨트롤러, 2.5D 실리콘 인터포저, 베이스 로직 다이, TSV 수직 전극, DRAM 코어 스택이 HBM을 완성한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **슈도 채널(Pseudo-Channel)**: 1024비트 물리 버스를 2~4개의 독립된 채널(예: 128비트 단위)로 가상 분할하여 개별 뱅크에 동시 병렬 접근하도록 하는 기술.

</details>

```text
호스트 GPU 메모리 읽기 요청 (Pseudo-Channel 명령)
      │
      ▼
1. 명령·채널 디코딩
      │
      ▼
2. 인터포저 전송
      │
      ▼
3. TSV 신호 분배
      │
      ▼
4. 뱅크 활성화
      │
      ▼
5. 광폭 데이터 반환
```

**동작 원리**

1. **명령·채널 디코딩**: 메모리 컨트롤러가 주소를 채널·뱅크·행·열로 분해
2. **인터포저 전송**: 명령·주소가 미세 배선을 거쳐 HBM 인터페이스에 도달
3. **TSV 신호 분배**: TSV가 적층 다이에 명령·주소·데이터·전원을 수직 전달
4. **뱅크 활성화**: 선택된 DRAM 뱅크의 행을 활성화하고 열 데이터 감지
5. **광폭 데이터 반환**: 다수 I/O 레인으로 데이터를 컨트롤러에 병렬 반환

#### 한줄 요약
- 명령 분할 → 인터포저 전달 → 베이스 다이 디코딩 → TSV 수직 상승 → 1024비트 광폭 반환 순으로 동작한다.

## Ⅴ. 종류 및 비교

| 메모리 적층 및 구조 기술 | 3D HBM (DRAM 적층) | 3D V-NAND (플래시) | 2D DDR5 DIMM | CXL 메모리 익스팬더 |
|:---|:---|:---|:---|:---|
| 적용 기준 | AI 가속기 및 슈퍼컴퓨터 초고대역폭 | SSD 및 모바일 대용량 비휘발 저장 | PC 및 범용 서버 메인 메모리 | 데이터센터 메모리 풀링 및 확장 |
| 핵심 특징 | TSV 기반 광폭 버스와 근접 패키징 | 메모리 셀·게이트의 수직 적층 | DIMM 채널과 표준 서버 메모리 생태계 | CXL 기반 캐시 일관성·메모리 확장 |
| 한계 | 고비용 및 첨단 패키징 제조 난이도 | 블록 단위 소거 및 느린 I/O 속도($\mu s$) | 핀 수 한계로 인한 대역폭 병목 | PCIe 인터페이스 경유로 인한 지연 증가 |

#### 한줄 요약
- AI 초고대역폭은 3D HBM, 대용량 저장은 3D V-NAND, 범용 확장은 DDR5, 풀링 확장은 CXL을 쓴다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **더미 TSV(Dummy TSV)**: 신호 전달 목적이 아닌 적층 다이 내부의 열을 패키지 외부 방열판으로 신속 배출하기 위한 열 전도 전용 금속 기둥.
- **하이브리드 본딩(Hybrid Bonding, Cu-Cu)**: 마이크로 범프를 없애고 구리와 절연막을 원자 단위로 직접 접합하여 피치를 $1\mu\text{m}$ 이하로 줄이고 열 저항을 낮추는 차세대 공정.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 고단 적층에 따른 **열 밀도·온도 구배** | 열 TSV·히트스프레더·패키지 열 해석 후 냉각 방식 결정 | 접합 온도와 층별 열 불균형 완화 |
| 적층 후 단일 다이 결함에 따른 **스택 수율 저하** | KGD 선별·리던던시 셀·조립 후 테스트 커버리지 확대 | 고가 적층 완료 후 폐기 위험 감소 |
| 1024개 신호 동시 스위칭(SSN) 시 발생하는 **전압 강하(IR Drop) 및 노이즈** | **전력 전달 네트워크(PDN) 최적화** 및 온다이 디커플링 커패시터 집적 | 전원 무결성(PI) 확보 및 신호 왜곡 방지 |
| 마이크로 범프 피치에 따른 **I/O 밀도·저항 한계** | 제품 성숙도에 따라 Cu-Cu 하이브리드 본딩 검토 | 미세 피치·낮은 접속 저항과 공정 난이도 절충 |

#### 한줄 요약
- 더미 TSV로 열을 빼고, KGD로 수율을 살리며, PDN 튜닝과 하이브리드 본딩으로 전원과 대역폭을 극대화한다.

## Ⅶ. 결론

- 대역폭당 전력이 병목인 AI·HPC는 **HBM**, 용량·교체성·원가는 DDR·CXL 메모리와 계층화
- HBM도 연산 재사용이 낮으면 병목이 남으므로 대역폭 실측과 패키지 수율·열·용량 비용으로 판단

#### 한줄 요약
- 수직 실리콘 관통 배선과 초광폭 버스 아키텍처를 통해 차세대 인공지능 프로세서의 연산 성능을 완벽히 뒷받침해야 한다.
