## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **멀티코어 프로세서(Multicore Processor)**: 단일 반도체 내부에 2개 이상의 독립적인 중앙처리장치 코어를 집적하여 다중 소프트웨어 스레드를 동시에 처리하는 시스템이다.
- **스레드 수준 병렬성(Thread-Level Parallelism)**: 독립적인 스레드를 물리적으로 서로 다른 코어에서 병렬로 구동하는 방식이다.
- **전력 한계(Power Wall)**: 클록 주파수 및 전압 증가에 따른 동적 전력 소모가 반도체의 허용 전력을 초과하는 기술적 장벽이다.
- **발열 한계(Thermal Wall)**: 단위 면적당 전력 밀도 증가로 인한 발열을 물리적 냉각 장치가 감당하지 못하는 한계이다.

</details>

- 정의: 단일 반도체 칩에 복수의 연산 코어를 집적하여 **스레드 수준 병렬성**을 실현하는 **멀티코어 프로세서** 구조
- 배경: 단일 코어의 성능 확장이 **전력 한계**와 **발열 한계**로 제약됨에 따라 코어 병렬화로 처리량을 향상시키기 위함

#### 한줄 요약

- 단일 코어의 전력과 발열 장벽을 넘어 다중 스레드 병렬성으로 시스템 전체의 처리량을 극대화한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **암달의 법칙(Amdahl's Law)**: 코어를 무한히 증설하더라도 프로그램 내의 직렬 처리 비율에 의해 전체 가속비 상한이 한정됨을 나타내는 성능 법칙이다.
- **가속비(Speedup)**: 단일 코어 환경의 처리 시간 대비 멀티코어 병렬 처리 환경에서 달성된 상대적 성능 향상 비율이다.
- **동기화(Synchronization)**: 다중 스레드가 메모리 내 공유 자원에 동시 접근할 때 데이터 일관성을 유지하기 위한 제어 동작이다.
- **처리량(Throughput)**: 멀티코어 시스템 전체가 단위 시간당 처리하여 완결하는 작업의 총 수량이다.
- **고성능 및 고효율 코어(Performance Core & Efficient Core)**: 고부하 작업은 고성능 코어에 할당하고 배경 작업은 고효율 코어에 배분하여 전력 대비 성능을 극대화하는 코어 구조이다.

</details>

- 단일 스레드의 지연시간 단축보다는 다중 스레드 기반의 전체 **처리량** 확장을 목적으로 설계됨.
- 소프트웨어가 **스레드 수준 병렬성** 구조로 분할 설계된 경우에 연산 병렬화 성능 향상 효과를 발휘함.
- 코어가 증가할수록 직렬 구간 병목을 설명하는 **암달의 법칙**과 코어 간 **동기화** 오버헤드가 전체 **가속비**를 한정함.

#### 한줄 요약

- 다중 스레드 병렬성으로 시스템 전체 처리량을 높이지만 암달의 법칙에 의해 가속비가 제한된다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **사설 캐시(Private Cache)**: 각 물리 코어 내부에 독점 배치되어 저지연 접근을 제공하는 고속 데이터 캐시이다.
- **최종 단계 캐시(Last-Level Cache)**: 모든 코어가 인터커넥트를 통해 칩 수준에서 공유하는 대용량 캐시이다.
- **일관성 인터커넥트(Coherence Interconnect)**: 사설 캐시 간의 복제 데이터를 최신으로 유지하도록 일관성 프로토콜 신호를 중계하는 통신망이다.
- **코어 클러스터(Core Cluster)**: 복수의 코어와 캐시를 효율적인 배선 구조로 그룹화한 단위 연산 파티션이다.
- **메모리 제어기(Memory Controller)**: 코어들로부터 유입되는 주기억장치 접근 요청을 중재하고 대역폭을 최적 할당하는 모듈이다.

</details>

| 구성요소 | 책임 |
|:---|:---|
| 코어 클러스터 | 스레드별 독립 연산 명령 실행 수행 |
| 사설 캐시 | 코어별 저지연 명령어와 데이터 제공 |
| 일관성 인터커넥트 | 캐시 일관성 프로토콜 패킷 전달 및 중재 |
| 최종 단계 캐시 | 코어 간 공유 데이터 및 메모리 요청 완충 보관 |
| 메모리 제어기 | 다중 코어의 주기억장치 채널 접근 중재 |

#### 한줄 요약

- 코어 클러스터와 사설 캐시 계층 위에 일관성 인터커넥트를 통해 공유 캐시와 메모리를 통합 연결한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **캐시 일관성(Cache Coherence)**: 여러 코어의 사설 캐시에 복제된 데이터가 갱신되었을 때 모든 코어가 동일한 최신 값을 읽도록 보장하는 체계이다.
- **쓰기 소유권(Write Ownership)**: 특정 코어가 캐시 라인을 변경하기 전 독점 권한을 취득하는 동작이다.
- **무효화(Invalidation)**: 타 코어가 가진 동일 캐시 복사본의 상태를 무효로 변경하여 구버전 읽기를 차단하는 통신 패킷이다.
- **스케줄러(OS Scheduler)**: 실행 대기 큐의 스레드들을 최적의 물리 코어에 할당하는 운영체제 제어 모듈이다.
- **캐시 라인(Cache Line)**: 캐시 일관성 제어 및 데이터 이동의 기본 구성 블록 단위이다.

</details>

```text
[ 코어 스레드 배정 ]
        │
        ▼
[ 사설 캐시 주소 조회 ]
        │
        ▼
[ 일관성 인터커넥트 접근 및 쓰기 소유권 획득 ]
        │
        ▼
[ 타 코어 사본 무효화 신호 전송 ]
        │
        ▼
[ 캐시 라인 데이터 수정 및 갱신 상태 보존 ]
```

### 동작 원리

1. 스레드 할당: **스케줄러**가 코어의 부하와 데이터 지역성을 고려하여 스레드를 배정함.
2. 캐시 라인 조회: 코어가 자체 **사설 캐시**에서 대상 메모리 주소를 확인하고 갱신을 준비함.
3. 쓰기 소유권 요청: **일관성 인터커넥트**로 메시지를 전송하여 캐시 라인의 독점 **쓰기 소유권**을 획득함.
4. 사본 무효화: 다른 코어에 존재하는 동일 **캐시 라인**의 사본을 모두 **무효화**함.
5. 수정 상태 유지: 연산을 수행한 코어가 최신값을 보존하고 갱신 상태를 유지함.

#### 한줄 요약

- 스케줄러의 코어 배정 후 사설 캐시 접근 시 쓰기 소유권 획득과 사본 무효화를 통해 데이터의 최신값을 유지한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **동시 멀티스레딩(Simultaneous Multithreading)**: 단일 물리 코어 내부에서 디코더와 연산 자원을 공유하며 복수의 논리 스레드를 동시 발행하는 기법이다.
- **동종 멀티코어(Homogeneous Multicore)**: 모든 코어가 동일한 연산 처리 특성과 성능 사양을 가진 구조이다.
- **이종 멀티코어(Heterogeneous Multicore)**: 고성능 코어와 저전력 고효율 코어를 하나의 칩에 복합적으로 탑재한 아키텍처이다.
- **유휴 누설전력(Idle Leakage Power)**: 연산 작업이 없이 대기 중인 코어에서도 미세 트랜지스터를 통해 계속 소비되는 전력이다.
- **코어 이동 비용(Core Migration Overhead)**: 이종 코어 간에 스레드가 이동할 때 캐시 지역성 저하와 컨텍스트 스위칭으로 발생하는 성능 저하 비용이다.

</details>

| 비교 항목 | 멀티코어 프로세서 | 동시 멀티스레딩 |
|:---|:---|:---|
| 하드웨어 구조 | 칩 내에 독립된 복수의 물리 코어 탑재 | 단일 코어 내부의 논리적 상태 레지스터 다중화 |
| 자원 독립성 | 코어별 연산 유닛 및 **사설 캐시** 분리 | 파이프라인 및 연산 자원 동시 공유 |
| 성능 확장성 | 독립 코어로 병렬성 확장 유리 | 공유 자원 병목으로 인한 성능 향상 한계 |

| 코어 형태 | 동종 멀티코어 | 이종 멀티코어 |
|:---|:---|:---|
| 코어 구성 | 모든 코어가 동일한 사양 및 아키텍처 적용 | **고성능 및 고효율 코어**의 복합 탑재 구성 |
| 적용 환경 | 작업 부하가 균일한 고성능 서버 및 데이터센터 | 전력 제한과 변동 부하가 잦은 모바일 및 엣지 기기 |
| 주요 한계 | 대기 상태 시 전체 단말의 높은 **유휴 누설전력** 유발 | 스레드 스케줄링 오배정 시 발생하는 **코어 이동 비용** |

#### 한줄 요약

- 다중 코어는 물리적 분리와 공유로 동시 멀티스레딩과 구분되며 코어 형태에 따라 동종과 이종 모델로 나뉜다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **거짓 공유(False Sharing)**: 독립 변수들이 동일한 캐시 라인 내에 배치되어 한 코어의 갱신이 타 코어 캐시를 잦게 무효화시키는 병목 현상이다.
- **캐시 라인 패딩(Cache Line Padding)**: 거짓 공유 방지를 위해 구조체 변수 사이에 공백 바이트를 삽입하여 별도 라인으로 물리 격리하는 최적화이다.
- **작업 훔치기(Work Stealing)**: 유휴 작업 코어가 부하가 집중된 코어의 대기 큐에서 직접 태스크를 가져오는 부하분산 기술이다.
- **비균일 메모리 접근 인지 배치(NUMA-Aware Placement)**: 다중 코어 환경에서 스레드가 사용할 메모리를 해당 코어와 가장 가까운 로컬 뱅크에 할당하는 기법이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 독립 변수 갱신으로 타 코어 무효화가 반복되는 **거짓 공유** 병목 | 변수 선언 시 메모리 간격 **캐시 라인 패딩** 적용 | 물리적 캐시 라인 격리로 무의미한 일관성 패킷 통신 절감 |
| 특정 코어에만 연산이 집중되고 다수 코어는 유휴 상태 체류 | 코어 간 부하를 동적으로 분배하는 **작업 훔치기** 스케줄러 도입 | 물리 코어 활용 부하 평형 달성 및 병렬 지연 단축 |
| 코어 수 증가 시 통합 메모리 버스 대역폭 포화 및 지연 | 스레드와 메모리를 매핑하는 **비균일 메모리 접근 인지 배치** | 원격 메모리 접근 최소화 및 메모리 대역폭 경합 완화 |
| **이종 멀티코어** 환경에서 작업 특성과 맞지 않는 오배정 발생 | 부하 힌트 및 운영체제 기반의 이종 코어 인지 스케줄링 | 지연 민감 작업과 배경 작업의 최적 배치로 전력 대 성능 극대화 |

#### 한줄 요약

- 캐시 라인 패딩, 작업 훔치기 스케줄링, 비균일 메모리 접근 매핑으로 멀티코어의 통신 병목과 대기 유휴 자원을 해소한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **메모리 대역폭(Memory Bandwidth)**: 프로세서 코어 집합이 초당 주기억장치와 송수신할 수 있는 최대 데이터 전송량이다.
- **일관성 트래픽(Coherence Traffic)**: 사설 캐시 간 상태 동기화를 위해 인터커넥트에 유입되는 제어 패킷의 양이다.
- **코어 확장 기준(Core Scaling Criteria)**: 스레드의 직렬 비율, 메모리 대역폭, 일관성 트래픽 한계를 종합적으로 평가하여 코어 수를 선택하는 체계이다.

</details>

- **코어 확장 기준**을 분석하여 병렬성 여유가 크면 코어 확장을 진행하고, 일관성 병목 시 지역성 최적화를 우선 적용함

#### 한줄 요약

- 직렬 처리 비율과 메모리 대역폭 병목의 상관관계를 종합적으로 측정하여 코어 증설 규모와 배치 전략을 결정해야 한다.
