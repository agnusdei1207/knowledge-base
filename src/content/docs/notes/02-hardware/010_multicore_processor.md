## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **멀티코어 프로세서** 는 하나의 칩에 여러 실행 코어를 통합하여 복수 스레드를 동시에 처리하는 프로세서 구조이다.
- **스레드 수준 병렬성(Thread-Level Parallelism, TLP)**: 독립적인 여러 스레드를 동시에 실행하는 병렬성
- **전력 한계**: 주파수와 전압 상승에 따른 소비 전력 제약
- **발열 한계**: 소비 전력 증가로 발생한 열을 방출하는 능력의 제약

</details>

- 정의/개념: **멀티코어 프로세서** 는 하나의 칩에 여러 실행 코어를 통합해 독립 스레드를 병렬 실행하는 **프로세서 구조**
- 배경/필요성: 주파수 상승의 **전력•발열 한계** 보완

#### 한줄 요약
- 멀티코어는 주파수 상승의 전력•발열 한계를 여러 스레드의 병렬 실행으로 보완한다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **암달의 법칙** 은 프로그램의 직렬 실행 비율이 코어 수를 늘려 얻을 수 있는 전체 가속의 상한을 결정한다.
- **동기화** 는 여러 스레드가 공유 데이터와 실행 순서를 맞추어 결과를 안전하게 결합하도록 제어한다.
- **처리량** 은 단위 시간에 완료하는 작업 수로 멀티코어가 직접 확장하려는 성능 지표이다.
- **스레드 수준 병렬성** 은 서로 독립적인 여러 스레드를 동시에 실행할 수 있는 정도이다.

</details>

- 코어 추가로 단일 지연이 아닌 **처리량** 확장
- **스레드 수준 병렬성** 이 있어야 성립하는 성능 이득
- **암달의 법칙**대로 직렬 비율이 가속 상한 확정

#### 한줄 요약
- 코어 수를 늘려도 직렬 구간과 동기화 비율이 전체 가속의 상한을 결정한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **사설 캐시** 는 각 코어가 독립적으로 사용하며 같은 데이터의 사본이 생기므로 일관성 관리가 필요하다.
- **공유 최종 단계 캐시(Shared Last-Level Cache, 공유 LLC)**: 여러 코어가 용량과 대역폭을 함께 쓰는 최종 캐시
- **일관성 인터커넥트** 는 코어•캐시•메모리 제어기 사이에서 요청과 캐시 상태 정보를 전달한다.
- **코어 클러스터** 는 여러 실행 코어를 묶어 스레드를 병렬 처리하도록 구성한 단위이다.
- **메모리 제어기** 는 여러 코어의 주기억장치 요청 순서와 사용할 대역폭을 조정한다.

</details>

```text
[코어 클러스터] -- [일관성 인터커넥트] -- [공유 LLC] -- [메모리 제어기]
```

선의 의미: 여러 코어와 공유 캐시•메모리 제어기를 일관성 요청 및 데이터 경로로 잇는 칩 내부 정적 연결 관계다.

| 구성요소 | 책임 |
|:---|:---|
| 코어 클러스터 | 복수 스레드 **병렬 실행** |
| 일관성 인터커넥트 | 캐시 사본 상태와 **요청 전달** |
| 공유 LLC | 코어 공용 **캐시 용량•대역폭** 제공 |
| 메모리 제어기 | 주기억장치 **접근 순서•대역폭** 배분 |

#### 한줄 요약
- 코어가 스레드를 실행하고 인터커넥트•LLC•메모리 제어기가 공유 데이터와 대역폭을 조정한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **캐시 일관성** 은 여러 사설 캐시에 복제된 같은 캐시 줄이 서로 다른 값을 갖지 않도록 보장하는 성질이다.
- **쓰기 소유권** 은 코어가 캐시 줄을 수정하기 전에 다른 사본을 무효화하고 확보하는 독점 쓰기 권한이다.
- **무효화** 는 다른 코어의 동일 캐시 줄 사본을 더 이상 사용할 수 없는 상태로 바꾸는 일관성 동작이다.
- **스케줄러** 는 실행할 스레드를 코어에 배치하고 완료 상태를 관리하는 운영체제 구성요소이다.
- **캐시 줄** 은 캐시와 메모리 사이에서 한 번에 이동하고 일관성 상태를 공유하는 고정 크기 데이터 블록이다.
- **공유 계층** 은 여러 코어가 함께 사용하는 LLC와 메모리 경로로 용량과 대역폭을 중재한다.

</details>

```text
                    [병렬 작업 집합]
                           |
                 1. 독립 스레드 배치
                           |
              +------------+------------+
              |                         |
       [코어 A•사설 캐시]       [코어 B•사설 캐시]
              |                         |
              +---- 2. 병렬 실행•접근 --+
                           |
              [일관성 인터커넥트•공유 LLC]
                           |
             3. 공유 대역폭•요청 중재
                           |
                   [동일 캐시 줄 쓰기?]
                      /             \
                   [아니요]          [예]
                      |               |
               [독립 접근 지속]  4. 무효화•소유권 부여
                      |               |
                      +-------+-------+
                              |
                        [병렬 실행 지속]
                              |
                         [결과 집계]
```

**동작 원리**

- **1. 독립 스레드 배치**: 코어별 실행 흐름 할당
- **2. 병렬 실행•접근**: 사설 캐시 경로로 데이터 요청
- **3. 공유 대역폭•요청 중재**: LLC•메모리 접근 조정
- **4. 무효화•소유권 부여**: 동일 캐시 줄 쓰기 직렬화

#### 한줄 요약
- 코어 병렬 실행과 **일관성•공유 대역폭** 중재

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **동시 멀티스레딩(Simultaneous Multithreading, SMT)**: 한 물리 코어에서 여러 논리 스레드를 함께 발행하는 방식
- **동종 멀티코어**: 같은 특성의 코어를 반복 배치한 구조
- **이종 멀티코어**: 성능 코어와 절전 코어를 조합한 구조
- **물리 코어**: 독립적으로 명령어를 실행하는 하드웨어 코어
- **논리 스레드**: SMT가 하나의 물리 코어 안에서 제공하는 실행 문맥
- **거짓 공유** 는 서로 다른 변수가 같은 캐시 줄에 있어 독립 쓰기에도 불필요한 일관성 통신이 생기는 현상이다.
- **유휴 누설전력** 은 코어가 작업하지 않을 때에도 트랜지스터 누설로 소비되는 전력이다.
- **코어 이동 비용** 은 스레드를 다른 종류의 코어로 옮기며 캐시•실행 상태를 다시 준비하는 데 드는 지연이다.

</details>

| 병렬 실행 방식 | 멀티코어 | SMT |
|:---|:---|:---|
| 적용 기준 | 독립 스레드가 코어 수만큼 있을 때 | 단일 스레드가 **실행 회로** 를 다 못 채울 때 |
| 핵심 특징 | 복수 **물리 코어** 의 독립 실행 | 한 코어를 나눈 **논리 스레드** 중첩 |
| 한계 | **거짓 공유**•공유 대역폭 경합 | 실행 유닛•**사설 캐시** 분점 |

> 요약: 일감이 많으면 **물리 코어**, 회로가 놀면 **논리 스레드**

| 멀티코어 구성 | 동종 멀티코어 | 이종 멀티코어 |
|:---|:---|:---|
| 적용 기준 | 작업 성격이 균일할 때 | 지연•전력 요구가 갈릴 때 |
| 핵심 특징 | 동일 코어 반복 배치로 **부하 분산** | **성능 코어•절전 코어** 혼합 배치 |
| 한계 | 경부하 구간의 **유휴 누설전력** | 오배정 시 **코어 이동** 비용 |

> 요약: 작업별 성능•전력 요구로 동종•이종 선택

#### 한줄 요약
- 멀티코어•SMT는 하드웨어 병렬성을, 동종•이종 구성은 코어 특성의 조합을 결정한다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **비균일 메모리 접근(Non-Uniform Memory Access, NUMA)**: 코어와 메모리 위치에 따라 접근 지연이 달라지는 구조
- **작업 훔치기** 는 유휴 코어가 다른 코어의 작업 큐에서 대기 작업을 가져와 부하 불균형을 줄이는 기법이다.
- **패딩**: 독립 변수 사이에 여백을 넣어 캐시 줄을 분리하는 방법
- **메모리 배치**: 독립 변수를 서로 다른 캐시 줄에 놓는 방법
- **NUMA 인지 배치**: 스레드와 데이터를 가까운 메모리 노드에 두는 전략
- **메모리 지역성**: 연산 주체와 가까운 메모리를 반복 접근하는 성질
- **이종 코어 스케줄링** 은 작업의 성능•전력 특성에 맞춰 성능 코어나 절전 코어에 배정하는 방식이다.
- **공용 큐 경합** 은 여러 코어가 하나의 작업 큐에 동시에 접근하며 잠금과 캐시 줄을 놓고 경쟁하는 현상이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 코어 추가에도 **처리 시간 정체** | **직렬•동기화 비율** 측정과 재분할 | **암달 상한** 완화 |
| 독립 변수 갱신에도 **캐시 줄 왕복** | 패딩•배치로 **거짓 공유** 제거 | **일관성 트래픽** 감소 |
| 다수 코어의 **메모리 대역폭 포화** | **NUMA 인지 배치•지역성** 개선 | **메모리 병목** 완화 |
| **이종 코어 오배정** | 작업 특성 기반 **스케줄링** | **지연•전력** 최적화 |
| 웹 서버의 **공용 큐 경합** | 코어별 **작업 큐•작업 훔치기** | **경합 완화•부하 균형** |

#### 한줄 요약
- 직렬 비율, 일관성 트래픽, 메모리 대역폭을 함께 측정해 유효한 코어 수를 정한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **메모리 대역폭** 은 단위 시간에 주기억장치와 전송할 수 있는 데이터 양이며 모든 코어가 공유하는 확장 한도이다.
- **직렬 비율** 은 전체 실행 시간 중 여러 코어로 나눌 수 없는 구간의 비율로 병렬 가속의 상한을 정한다.
- **일관성 트래픽** 은 캐시 사본의 상태를 맞추기 위해 코어 사이에서 오가는 조회•무효화•소유권 메시지이다.

</details>

- **직렬 비율•대역폭** 과 일관성 트래픽 기준 코어 수 결정

#### 한줄 요약
- 병렬 가능 비율과 작업의 지연•전력 요구를 기준으로 코어 수와 구성을 선택한다.
