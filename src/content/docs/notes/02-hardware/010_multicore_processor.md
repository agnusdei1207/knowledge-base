## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **멀티코어 프로세서(Multicore Processor)**: 하나의 칩에 여러 실행 코어를 통합하여 복수 스레드를 동시에 처리하는 프로세서 구조.
- **스레드 수준 병렬성(Thread-Level Parallelism, TLP)**: 독립적인 여러 스레드를 동시에 실행하여 얻는 병렬성.
- **전력 한계(Power Wall)**: 주파수와 전압 상승에 따라 소비 전력이 허용치를 초과하는 제약.
- **발열 한계(Thermal Wall)**: 소비 전력 증가로 발생한 열을 칩 냉각 능력 안에서 방출할 수 없는 제약.

</details>

- 정의/개념: **멀티코어 프로세서**는 한 칩의 여러 코어로 **TLP**를 구현하는 프로세서 구조
- 배경/필요성: 주파수를 계속 높이면 **전력 한계**와 **발열 한계**에 이르므로 여러 코어의 병렬 실행으로 단위 전력당 처리량 향상

#### 한줄 요약
- 멀티코어는 주파수 상승의 전력•발열 한계를 여러 스레드의 병렬 실행으로 보완한다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **암달의 법칙(Amdahl's Law)**: 직렬 비율의 역수가 코어 추가 시 전체 가속비(Speedup)의 상한이 되는 법칙.
- **동기화(Synchronization)**: 여러 스레드가 공유 데이터와 실행 순서를 일치시켜 정합성을 유지하는 제어 동작.
- **처리량(Throughput)**: 단위 시간에 완료하는 작업 수. 멀티코어가 확장하는 핵심 성능 지표.
- **스레드 수준 병렬성(TLP)**: 서로 독립적인 여러 스레드를 동시에 실행할 수 있는 정도.

</details>

- 코어 추가로 단일 스레드 지연보다 다중 작업 **처리량** 확장이 핵심
- **스레드 수준 병렬성**이 있을 때만 코어 추가의 성능 이득 발생
- **암달의 법칙**에 따라 직렬 비율이 가속 상한을 결정하며 **동기화** 비용도 함께 고려

#### 한줄 요약
- 코어 수를 늘려도 직렬 구간과 동기화 비율이 전체 가속의 상한을 결정한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **사설 캐시(Private Cache)**: 각 코어가 독점적으로 사용하는 캐시. 공유 데이터 사본이 여러 코어에 존재하면 일관성 관리가 필요.
- **최종 단계 캐시(Last-Level Cache, LLC)**: 여러 코어가 용량과 대역폭을 공유하는 최하위 온칩 캐시.
- **일관성 인터커넥트(Coherence Interconnect)**: 코어·캐시·메모리 제어기 사이에서 요청과 캐시 상태 정보를 전달하는 연결망.
- **코어 클러스터(Core Cluster)**: 여러 실행 코어를 묶어 스레드를 병렬 처리하도록 구성한 단위.
- **메모리 제어기(Memory Controller)**: 여러 코어의 주기억장치 접근 요청을 중재하고 대역폭을 배분하는 장치.

</details>

```text
멀티코어 프로세서
├─ 코어 클러스터
│  └─ 코어별 사설 캐시(Private Cache)
├─ 일관성 인터커넥트
├─ 공유 LLC(Last-Level Cache)
└─ 메모리 제어기
```

가지의 의미: 병렬 실행과 공유 메모리 접근의 정적 책임 구성.

| 구성요소 | 책임 |
|:---|:---|
| **코어 클러스터** | 복수 스레드 병렬 실행 |
| **사설 캐시** | 코어에 가까운 데이터 사본 제공 |
| **일관성 인터커넥트** | 캐시 사본 상태와 요청 전달 |
| **공유 LLC** | 전체 코어 대상 캐시 용량•대역폭 제공 |
| **메모리 제어기** | 주기억장치 접근 순서•대역폭 배분 |

#### 한줄 요약
- 코어가 스레드를 실행하고 인터커넥트•LLC•메모리 제어기가 공유 데이터와 대역폭을 조정한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **캐시 일관성(Cache Coherence)**: 여러 사설 캐시에 복제된 같은 캐시 라인의 값을 모든 코어가 일관되게 관찰하도록 보장하는 성질.
- **쓰기 소유권(Write Ownership)**: 코어가 캐시 라인을 수정하기 전에 다른 사본을 무효화하고 확보하는 독점 권한.
- **무효화(Invalidation)**: 다른 코어의 동일 캐시 라인 사본을 더 이상 유효하지 않은 상태로 전환하는 일관성 동작.
- **스케줄러(Scheduler)**: 실행 가능한 스레드를 코어에 배치하고 완료 상태를 관리하는 운영체제 구성요소.
- **캐시 라인(Cache Line)**: 캐시와 메모리 사이에서 한 번에 전송되는 고정 크기 데이터 블록. 일관성 제어의 최소 단위.
- **공유 계층(Shared Hierarchy)**: 여러 코어가 함께 사용하는 LLC와 메모리 경로. 용량과 대역폭을 중재.

</details>

```text
1. 독립 스레드 전달
          ├─ 코어 A•사설 캐시
          └─ 코어 B•사설 캐시
                    │
                    ▼
          2. 데이터 접근 요청
                    │
                    ▼
          동일 캐시 라인 쓰기 판정
          ├─ 아니오: 독립 캐시 라인 병렬 접근
          └─ 예
             └─ 3. 쓰기 소유권 요청
                └─ 4. 무효화 요청 전달
                   └─ 쓰기 소유권 부여
                    │
                    ▼
              스레드 완료 반환
```

### 동작 원리

1. **독립 스레드 전달**: **스케줄러**가 실행 가능한 스레드를 서로 다른 코어에 배치.
2. **데이터 접근 요청**: 각 코어가 주소를 사설 캐시 경로에 전달.
3. **쓰기 소유권 요청**: **공유 계층**을 통해 해당 캐시 라인의 독점 권한 요청.
4. **무효화 요청 전달**: 다른 코어의 동일 사본을 무효 상태로 전환.

#### 한줄 요약
- 코어별 사설 캐시의 사본은 일관성 인터커넥트가 상태를 조정하고, LLC와 메모리 제어기는 모든 코어가 공유하는 용량•대역폭을 중재한다.
- 이 과정이 사설 캐시의 **캐시 일관성**을 유지한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **동시 멀티스레딩(Simultaneous Multithreading, SMT)**: 한 물리 코어에서 여러 논리 스레드를 동시에 발행하는 방식.
- **동종 멀티코어(Homogeneous Multicore)**: 같은 특성의 코어를 반복 배치한 구조.
- **이종 멀티코어(Heterogeneous Multicore)**: 성능 코어(P-core)와 절전 코어(E-core)를 조합한 구조.
- **물리 코어(Physical Core)**: 독립적으로 명령어를 실행하는 하드웨어 코어.
- **논리 스레드(Logical Thread)**: SMT가 하나의 물리 코어 안에서 제공하는 독립 실행 문맥.
- **유휴 누설전력(Idle Leakage Power)**: 코어가 작업하지 않을 때에도 트랜지스터 누설로 소비되는 전력.
- **코어 이동 비용(Core Migration Cost)**: 스레드를 다른 종류의 코어로 옮기며 캐시•실행 상태를 다시 준비하는 데 드는 지연.

</details>

| 병렬 실행 방식 | 멀티코어 | SMT |
|:---|:---|:---|
| 적용 기준 | 독립 스레드가 물리 코어 수만큼 있을 때 | 스레드별 정체로 실행 슬롯이 남을 때 |
| 핵심 특징 | 복수 **물리 코어**의 독립 실행 | 한 코어에서 여러 **논리 스레드** 중첩 |
| 한계 | 코어 간 일관성•메모리 대역폭 경합 | 실행 유닛•사설 캐시 용량 공유 |

> 요약: 일감이 많으면 **물리 코어**, 회로가 놀면 **논리 스레드**가 핵심이다.

| 멀티코어 구성 | 동종 멀티코어 | 이종 멀티코어 |
|:---|:---|:---|
| 적용 기준 | 작업 성격이 균일할 때 | 지연•전력 요구가 갈릴 때 |
| 핵심 특징 | 동일 코어 반복 배치로 부하 분산 | 성능 코어•절전 코어 혼합 배치 |
| 한계 | 경부하 구간의 **유휴 누설전력** | 오배정 시 **코어 이동 비용** |

> 요약: 작업별 성능•전력 요구로 동종•이종을 선택한다.

#### 한줄 요약
- 멀티코어•SMT는 하드웨어 병렬성을, 동종•이종 구성은 코어 특성의 조합을 결정한다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **비균일 메모리 접근(Non-Uniform Memory Access, NUMA)**: 코어와 메모리의 물리적 위치에 따라 접근 지연이 달라지는 구조.
- **작업 훔치기(Work Stealing)**: 유휴 코어가 다른 코어의 작업 큐에서 대기 작업을 가져와 부하 불균형을 줄이는 기법.
- **패딩(Padding)**: 독립 변수 사이에 여백을 삽입하여 서로 다른 캐시 라인에 배치하는 방법.
- **NUMA 인지 배치(NUMA-Aware Placement)**: 스레드와 데이터를 물리적으로 가까운 메모리 노드에 배치하는 전략.
- **메모리 지역성(Memory Locality)**: 연산 주체와 가까운 메모리를 반복 접근하여 원격 접근을 줄이는 성질.
- **이종 코어 스케줄링(Heterogeneous Scheduling)**: 작업의 성능•전력 특성에 맞춰 적합한 코어 유형에 배정하는 방식.
- **공용 큐 경합(Shared Queue Contention)**: 여러 코어가 하나의 작업 큐에 동시에 접근하며 잠금과 캐시 라인을 놓고 경쟁하는 현상.
- **거짓 공유(False Sharing)**: 서로 다른 변수가 같은 캐시 라인에 위치하여, 독립 쓰기에도 불필요한 일관성 트래픽이 발생하는 현상.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 코어 추가에도 처리 시간 정체 | 직렬•동기화 구간 측정과 작업 재분할 | 병렬 실행 비율 증가 |
| 독립 변수 갱신에도 캐시 라인 왕복 | **패딩**으로 **거짓 공유** 제거 | 무효화 트래픽 감소 |
| 다수 코어에서 메모리 대역폭 포화 | **NUMA 인지 배치**•**메모리 지역성** 개선 | 원격 접근 감소 |
| 지연 민감 작업이 절전 코어에 오배정 | **이종 코어 스케줄링** | 코어 유형 재배정 |
| 웹 서버의 **공용 큐 경합** | 코어별 작업 큐•**작업 훔치기** | 잠금 경쟁•부하 편차 완화 |

#### 한줄 요약
- 직렬 비율, 일관성 트래픽, 메모리 대역폭을 함께 측정해 유효한 코어 수를 정한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **메모리 대역폭(Memory Bandwidth)**: 단위 시간에 주기억장치와 전송할 수 있는 데이터 양. 모든 코어가 공유하는 확장 한도.
- **직렬 비율(Serial Fraction)**: 전체 실행 시간 중 여러 코어로 나눌 수 없는 구간의 비율. 병렬 가속의 상한을 결정.
- **일관성 트래픽(Coherence Traffic)**: 캐시 사본의 상태를 맞추기 위해 코어 사이에서 오가는 조회•무효화•소유권 메시지.
- **코어 확장 기준**: 직렬 비율•메모리 대역폭•일관성 트래픽이 코어 추가 이득을 상쇄하는지 판단하는 기준.

</details>

- **코어 확장 기준**에 따라 코어 추가 이득이 **직렬 비율**•**메모리 대역폭**•**일관성 트래픽** 비용보다 클 때까지 코어 수 확대

#### 한줄 요약
- 병렬 가능 비율과 작업의 지연•전력 요구를 기준으로 코어 수와 구성을 선택한다.
