## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **멀티코어 프로세서(Multicore Processor)**: 단일 반도체 칩(Die) 내에 둘 이상의 독립적인 실행 코어를 집적하여 스레드 수준 병렬성(TLP)을 처리하는 마이크로프로세서.
- **스레드 수준 병렬성(Thread-Level Parallelism, TLP)**: 복수의 독립적인 소프트웨어 실행 흐름(Thread)을 다중 코어에 분산 배치하여 동시에 병렬 실행하는 기법.
- **전력 장벽(Power Wall)**: 주파수·전압 상승에 따른 전력과 발열 증가로 단일 코어 성능 확장이 제한되는 현상.

</details>

- 정의/개념: 단일 반도체 다이에 독립적인 둘 이상의 연산 코어와 온칩 캐시를 집적하여 **스레드 수준 병렬성**을 통해 전체 처리량을 확장하는 병렬 프로세서 구조
- 배경/필요성: 단일 코어 클록 주파수 증대에 따른 소비 전력 및 발열의 급격한 상승(**전력 장벽**)으로 단일 스레드 성능 향상이 물리적 한계에 봉착하므로, 주파수 대신 코어 수를 늘려 동일 전력 예산 내 처리량 확장

#### 한줄 요약
- 멀티코어는 단일 코어의 주파수 증대 한계를 극복하기 위해 코어를 복제하여 병렬 처리량을 확장하는 아키텍처이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **암달의 법칙(Amdahl's Law)**: 병렬 프로세서 코어 수를 무한히 늘려도 프로그램 내 직렬(Sequential) 실행 구간의 비율에 의해 전체 시스템 가속비(Speedup) 상한이 제한된다는 법칙.
- **캐시 일관성(Cache Coherence)**: 동일 주소의 캐시 사본에 대한 쓰기 순서와 최신값 관찰을 통제하는 하드웨어 규약.
- **온칩 인터커넥트(On-Chip Interconnect)**: 다중 코어, 사설 캐시, 공유 LLC, 통합 메모리 제어기 간에 데이터와 일관성 메시지를 고속 중계하는 내부 통신 네트워크(Ring, Mesh 등).

</details>

- 처리량 확장: 다중 코어에 독립 스레드를 분산 배치하여 클록 주파수 상승 없이도 총 연산 처리량 대폭 증대
- 가속비의 한계: 프로그램 내 병렬화 불가능한 직렬 구간 비율에 따라 **암달의 법칙**에 의해 성능 가속비 상한 제약
- 공유 자원 정합성: 다중 코어가 동일 주소를 갱신할 때 발생하는 데이터 불일치를 방지하기 위해 하드웨어 **캐시 일관성** 프로토콜(MESI/MOESI) 필수
- 인터커넥트 병목: 코어 수가 증가함에 따라 **온칩 인터커넥트** 및 메모리 제어기 대역폭이 시스템 확장의 핵심 병목으로 부상

#### 한줄 요약
- 멀티코어 성능은 암달의 법칙에 의한 직렬 구간 비율과 캐시 일관성 인터커넥트 대역폭에 의해 결정된다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **사설 캐시(Private Cache)**: 개별 코어에 전용으로 배치되어 해당 코어의 접근 지연을 줄이는 L1 또는 L2 캐시.
- **최종 단계 캐시(Last-Level Cache, LLC)**: 주기억장치 직전의 마지막 온칩 캐시로, 구현에 따라 코어들이 공유하는 캐시 계층.
- **통합 메모리 제어기(Integrated Memory Controller, IMC)**: 프로세서 다이에 내장되어 다중 DDR 메모리 채널과의 통신을 직접 제어하는 고속 컨트롤러.

</details>

```text
+-----------------------------------------------------------------------+
| 멀티코어 프로세서 하드웨어 아키텍처                                   |
|  +---------------------------+     +---------------------------+      |
|  | 코어 0 (Core 0)           |     | 코어 1 (Core 1)           |      |
|  |  - 실행 파이프라인 (ALU/FPU)|  - 실행 파이프라인 (ALU/FPU)|      |
|  |  - 사설 캐시 (L1 I/D, L2) |     |  - 사설 캐시 (L1 I/D, L2) |      |
|  +-------------+-------------+     +-------------+-------------+      |
|                |                                 |                    |
|  +-------------v---------------------------------v-------------+      |
|  | 온칩 고속 인터커넥트 (On-Chip Crossbar / Ring / 2D Mesh)     |      |
|  |  - 스누핑/디렉터리 기반 캐시 일관성(Cache Coherence) 제어   |      |
|  +-----------------------------+-------------------------------+      |
|                                |                                      |
|  +-----------------------------v-------------------------------+      |
|  | 공유 최종 단계 캐시 (Shared Last-Level Cache, LLC / L3)     |      |
|  +-----------------------------+-------------------------------+      |
|                                |                                      |
|  +-----------------------------v-------------------------------+      |
|  | 통합 메모리 제어기 (IMC) -> 다중 채널 DDR/LPDDR 인터페이스  |      |
+--+-------------------------------------------------------------+------+
```

선의 의미: `+---+`는 코어 및 온칩 서브시스템 경계, `->`는 온칩 인터커넥트를 통한 데이터 및 일관성 패킷 이동 흐름

| 구성요소 | 책임 |
|:---|:---|
| 개별 CPU 코어 | 독립 명령어 인출, 해독 및 실행을 통한 소프트웨어 스레드 병렬 처리 |
| 사설 캐시(L1/L2) | 코어 전용 고속 캐싱으로 주파수 병목 완화 및 **접근 지연시간 단축** |
| 온칩 인터커넥트 | 코어 간 데이터 전송 중계 및 **캐시 일관성 패킷** 고속 라우팅 |
| 공유 LLC(L3) | 다중 코어 간 공유 데이터 보관 및 메인 메모리 트래픽 완충 |
| 통합 메모리 제어기 | 외부 DRAM 채널 명령 스케줄링 및 **메모리 버스 대역폭** 중재 |

#### 한줄 요약
- 멀티코어는 코어별 사설 캐시 ➔ 온칩 인터커넥트 ➔ 공유 LLC ➔ 통합 메모리 제어기의 4단계 계층 구조로 집적된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **스누핑(Snooping)**: 공유 버스를 통해 모든 캐시 컨트롤러가 브로드캐스트되는 메모리 트랜잭션을 감시하여 일관성을 유지하는 방식.
- **무효화(Invalidation)**: 한 코어가 데이터를 쓸 때 타 코어의 사설 캐시에 있는 동일 라인을 무효 상태로 바꾸는 일관성 동작.

</details>

```text
[스레드 실행 요청 발생]
          │
          ▼
1. 코어별 독립 병렬 실행
          │
          ▼
2. 사설 캐시(L1/L2) 계층 조회
   ┌──────┴──────┐
(캐시 적중)   (캐시 미스)
   │             │
   │             ▼
   │      3. 온칩 인터커넥트 중재 및 일관성 검사
   │             │ (스누핑/디렉터리 무효화)
   │             ▼
   │      4. 공유 LLC 및 DRAM 접근
   │             │
   └──────┬──────┘
          │
          ▼
[코어에 유효 데이터 반환 및 연산 완료]
```

분기 결과: 사설 캐시 적중이면 코어 안에서 끝나지만, 미스는 **온칩 인터커넥트** 중재와 **스누핑**·**무효화** 메시지를 거쳐 LLC·DRAM까지 내려가 지연이 계층 수만큼 늘어남

**동작 원리**

1. **코어별 독립 병렬 실행**: 운영체제 스케줄러가 분산 할당한 스레드를 복수의 코어가 독립 파이프라인에서 동시 실행함
2. **사설 캐시 계층 조회**: 메모리 읽기/쓰기 발생 시 코어 내부의 L1/L2 사설 캐시를 먼저 조회하여 적중 시 무지연 완료함
3. **온칩 인터커넥트 중재 및 일관성 검사**: 사설 캐시 미스 발생 시 인터커넥트 중재를 거쳐 캐시 일관성 프로토콜(MESI) 메시지를 브로드캐스트 또는 디렉터리로 송출함
4. **공유 LLC 및 DRAM 접근**: 공유 L3(LLC)에서 데이터를 인출하거나 부재 시 통합 메모리 제어기(IMC)를 통해 외부 DRAM에서 블록을 적재함

#### 한줄 요약
- 멀티코어에서 데이터 갱신 시 캐시 일관성 프로토콜이 인터커넥트를 통해 타 코어의 사본을 무효화한 후 안전하게 쓰기를 완료한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **대칭 다중 처리(SMP)**: 동일한 성능의 코어들이 단일 메모리를 균등하게 공유하는 구조.
- **이종 멀티코어(Heterogeneous)**: 고성능 빅 코어와 저전력 리틀 코어를 결합한 구조(ARM big.LITTLE).
- **동시 멀티스레딩(SMT)**: 단일 코어 내부에서 하드웨어 스레드 문맥을 복수 유지하는 기술.

</details>

| 멀티코어 아키텍처 | 대칭 멀티코어 (SMP) | 이종 멀티코어 (big.LITTLE) | 동시 멀티스레딩 (SMT) |
|:---|:---|:---|:---|
| 적용 기준 | **균등한 연산 부하** 및 서버 환경 | **가변 부하** 및 모바일 전력 절감 요구 | **I/O 대기 은닉** 및 파이프라인 활용 요구 |
| 핵심 특징 | 동일 마이크로아키텍처 코어 집적으로 **균등 부하 분산** 용이 | 빅·리틀 코어 혼합 배치로 **전력 대 성능비 최적화** | 단일 코어 내 복수 하드웨어 스레드 문맥으로 유휴 유닛 활용 |
| 한계 | 저부하 시 유휴 코어의 전력 낭비 발생 | 코어 간 태스크 마이그레이션 오버헤드 | 스레드 간 실행 유닛 및 캐시 간섭 충돌 |

#### 한줄 요약
- 일관된 연산 성능에는 대칭 다중 처리가 적합하고, 모바일 에너지 효율에는 이종 멀티코어가, 단일 코어 활용 극대화에는 동시 멀티스레딩이 적합하다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **거짓 공유(False Sharing)**: 서로 다른 코어가 독립된 변수를 갱신하지만, 동일한 물리 캐시 라인(64B)에 속해 있어 불필요한 무효화가 반복되는 성능 저하 현상.
- **캐시 라인 패딩(Cache-Line Padding)**: 독립 변수 사이에 더미 바이트를 채워 서로 다른 캐시 라인에 위치시키는 기법.
- **비균일 메모리 접근(NUMA)**: 소켓별로 로컬 메모리를 분할 배치하여 메모리 접근 지연이 불균일한 구조.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 독립 변수 갱신인데 캐시 라인이 겹쳐 거짓 공유 발생 | 64바이트 단위 **캐시 라인 패딩** 적용 | 불필요한 캐시 무효화 버스 트래픽 원천 차단 |
| 코어 수 증가로 인한 단일 공유 버스 대역폭 포화 | 2D Mesh 인터커넥트 및 **디렉터리 일관성** 채택 | 브로드캐스트 트래픽 분산 및 수십 코어 확장성 확보 |
| 다중 소켓 환경에서 원격 노드 메모리 접근 지연 급증 | **NUMA** 인식 메모리 할당 및 스레드 바인딩 | 원격 메모리 버스 참조 최소화 및 로컬 DRAM 대역폭 극대화 |

#### 한줄 요약
- 멀티코어 실무에서는 거짓 공유를 패딩으로 방어하고, 코어 확장에 맞춘 Mesh 인터커넥트와 NUMA 인식 배치를 통해 병목을 통제한다.

## Ⅶ. 결론

- 현대 컴퓨팅 전 영역의 표준 아키텍처로 확립되었으며, 수십~수백 코어 매니코어 시대에 대응하기 위해 칩렛 모듈화·3D 적층 패키징 및 CXL 기반 이기종 메모리 풀링 구조로 진화하고 있어, 직렬화 병목(암달의 법칙)과 캐시 일관성 트래픽 오버헤드를 고려한 적정 코어 수·인터커넥트 토폴로지 설계

#### 한줄 요약
- 멀티코어는 현대 컴퓨팅의 기본 구조이며, 캐시 일관성과 인터커넥트, NUMA 메모리 배치의 최적화가 시스템 확장성을 결정한다.
