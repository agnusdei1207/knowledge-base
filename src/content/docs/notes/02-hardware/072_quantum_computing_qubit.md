## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **Qubit(Quantum Bit, 큐비트)**: 양자역학의 중첩(Superposition)과 얽힘(Entanglement) 현상을 이용하여 정보를 처리하는 양자 컴퓨터의 기본 연산 단위.
- **Computational Basis(계산 기저)**: 양자 상태를 측정했을 때 붕괴되어 나타나는 직교하는 두 고전 상태 $|0\rangle$과 $|1\rangle$.
- **State Vector(상태 벡터)**: 블로흐 구면(Bloch Sphere) 상에서 큐비트의 중첩 상태를 나타내는 복소 확률 진폭 벡터.

</details>

- 정의/개념: 고전적 0 또는 1의 이진 상태가 아닌, 양자역학적 중첩(Superposition)과 얽힘(Entanglement) 원리를 이용해 두 상태의 복소수 선형 결합($\alpha|0\rangle + \beta|1\rangle$)으로 정보를 표현하는 양자 컴퓨팅의 기본 정보 단위
- 배경/필요성: 고전 폰 노이만 컴퓨터로 해결이 불가능한 **NP-난해 복잡도 문제(소인수분해, 신약 분자 시뮬레이션, 대규모 조합 최적화)에 대한 양자 초월성(Quantum Advantage) 달성**

#### 한줄 요약

- 중첩과 얽힘의 복소 진폭 기반으로 **$2^n$개 상태를 동시 표현하는 양자 컴퓨팅 정보 기본 단위**

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **Superposition(양자 중첩)**: 큐비트가 관측되기 전까지 $|0\rangle$과 $|1\rangle$ 상태를 확률적 진폭으로 동시에 유지하는 양자적 성질.
- **Entanglement(양자 얽힘)**: 둘 이상의 큐비트가 공간적으로 분리되어 있어도 하나의 상태가 결정되면 다른 큐비트의 상태가 즉각 결정되는 강한 비고전적 상관관계.
- **Wavefunction Collapse(파동함수 수축)**: 중첩 상태의 큐비트를 측정(Measurement)하는 순간 확률에 따라 단 하나의 고전 상태($0$ 또는 $1$)로 결정되는 현상.

</details>

- 0과 1 상태를 복소 확률 진폭으로 동시에 표현하는 **양자 중첩(Superposition) 기반 병렬성**
- 다중 큐비트 간의 비고전적 상관관계를 통해 $N$개 큐비트로 $2^N$개의 상태를 동시에 연산하는 **양자 얽힘(Entanglement)**
- 연산 중에는 가역적인 유니터리 변환을 유지하다가 관측 시 확정적인 고전 비트로 붕괴하는 **투사 측정(Projection Measurement)**

$$
|\psi\rangle = \alpha|0\rangle + \beta|1\rangle,\qquad
|\alpha|^2 + |\beta|^2 = 1
$$

#### 한줄 요약

- **중첩(Superposition) 상태 공간·얽힘(Entanglement) 상관관계·측정(Measurement) 시 파동함수 수축**

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **Transmon Qubit**: 조셉슨 접합(Josephson Junction) 기반의 비선형 인덕턴스를 이용해 준위를 분리한 초전도 회로 소자.
- **Tunable Coupler**: 인접한 두 큐비트 사이의 상호작용을 외부 자속(Flux)으로 제어하여 2큐비트 얽힘 게이트(CZ, CNOT)를 켜고 끄는 소자.
- **AWG(Arbitrary Waveform Generator)**: 극저온 큐비트에 수 $\text{GHz}$ 대역의 RF 마이크로파 펄스를 인가하여 양자 상태 회전을 제어하는 장비.

</details>

```text
[ 양자 큐비트 제어 및 판독 하드웨어 계층 아키텍처 ]
┌─────────────────────────────────────────────────────────────┐
│ 1. 극저온 제어 계층 : AWG 마이크로파 펄스 발생기 (xy/z 제어)│
└──────────────────────────────┬──────────────────────────────┘
                               │ [ 동축 케이블 감쇠기(Attenuator) ]
┌──────────────────────────────┴──────────────────────────────┐
│ 2. 양자 프로세서 다이 (10mK Dilution Refrigerator 내부)     │
│  ├─ 물리 큐비트 소자 (Transmon / Trapped-Ion)               │
│  └─ 가변 결합기 (Tunable Coupler : 2큐비트 얽힘 게이트)     │
└──────────────────────────────┬──────────────────────────────┘
                               │ [ 공진기 주파수 편이 Readout ]
┌──────────────────────────────┴──────────────────────────────┐
│ 3. 판독 측정 계층 : HEMT 극저온 증폭기 ──> FPGA 디지털 복조 │
└─────────────────────────────────────────────────────────────┘
```

선의 의미: 물리 큐비트 소자(초전도/이온트랩), 가변 결합기(Coupler), 마이크로파/레이저 제어 계층 및 판독 측정 계층 간의 양자 프로세서 아키텍처 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 큐비트 소자 | 절대영도(-273도)의 초전도체나 레이저에 갇힌 이온 같은 걸로 만들어져 진짜 양자 마법을 품고 있는 하드웨어 심장 |
| 결합 구조 | "너랑 나랑 운명 공동체야"라며 큐비트끼리 멱살을 잡고 **얽힘**(Entanglement) 게이트를 강제로 만들어내는 연결 고리 |
| 제어 계층 | 마이크로파나 레이저 펄스를 쏴서 큐비트를 팽이처럼 빙글빙글 돌리며 입맛대로 연산(단일 게이트)을 먹이는 조종사 |
| 측정 계층 | "너 0이야 1이야?" 하고 빛을 쏴서 파동으로 요동치던 양자 상태를 0과 1의 고전 비트로 억지로 찍어 누르는 깐깐한 판독기 |

#### 한줄 요약

- **물리 큐비트 소자·가변 결합기(Coupler)·마이크로파 제어 계층(AWG)·판독 측정 계층(Readout)**

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Shot(샷)**: 양자 측정은 확률적이므로 동일한 양자 회로를 수천~수만 번 반복 실행하여 결과의 확률 분포를 수집하는 단일 실행 단위.

</details>

```text
[ 양자 회로 컴파일 및 샷(Shot) 기반 측정 시퀀스 ]
                         │
                         ▼
   [ 1. 양자 알고리즘을 물리 게이트(H, X, CNOT) 펄스로 트랜스파일링 ]
                         │
        +─────────────────────────────────────────+
        │        ( 샷(Shot) N회 반복 루프 )       │
        │                  │                      │
        │                  ▼                      │
        │   [ 2. 큐비트 영점 상태($|0\rangle$) 초기화 ]     │
        │                  │                      │
        │                  ▼                      │
        │   [ 3. 마이크로파 펄스 인가 (중첩/얽힘 유니터리 연산) ]│
        │                  │                      │
        │                  ▼                      │
        │   [ 4. 투사 측정(Projection)에 의한 고전 비트 판독 ]│
        +──────────────────┬──────────────────────+
                           │
                           ▼
   [ 5. N회 샷 결과의 확률 분포 집계 및 최종 최적해 도출 ]
```

**동작 원리**

1. **회로 트랜스파일링**: OpenQASM 코드를 대상 큐비트 토폴로지에 맞춘 물리 마이크로파 파형으로 변환
2. **상태 초기화**: 결맞음 완화를 통해 모든 큐비트를 바닥 상태 $|00\dots 0\rangle$으로 리셋
3. **게이트 펄스 연산**: 단일 큐비트 회전($R_x, R_y$) 및 2큐비트 얽힘(CZ) 펄스를 순차 인가하여 유니터리 연산 전개
4. **투사 측정**: 공진기의 위상 변화를 감지하여 파동함수를 0 또는 1로 수축
5. **통계적 해 도출**: 수천 번의 샷을 반복하여 획득한 비트열 히스토그램에서 최다 빈도 상태를 최종 정답으로 채택

#### 한줄 요약

- 알고리즘 펄스 트랜스파일 $\to$ **$|0\rangle$ 상태 초기화 $\to$ 단일/2큐비트 유니터리 게이트 펄스 인가 $\to$ 투사 측정(Projection) $\to$ 샷(Shot) 반복 통계 도출**

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **Qubit vs Classical Bit**:
  - Qubit: 복소 진폭 중첩($2^N$ 상태), 유니터리 가역 게이트, 노이즈 및 결맞음 손실 취약
  - Classical Bit: 0 또는 1 확정 상태, 비가역 불리언 게이트, 높은 노이즈 마진

</details>

| 비교 항목 | 양자 큐비트 (Qubit) | 고전 비트 (Classical Bit) |
|:---|:---|:---|
| 정보 표현 및 상태 공간 | 0과 1의 중첩 ($\alpha|0\rangle + \beta|1\rangle$, $N$개 시 $2^N$개 동시 표현) | 확정적인 0 또는 1 (단일 1비트 상태) |
| 연산 원리 및 게이트 | 유니터리 가역 변환 (Hadamard, CNOT, Phase Shift) | 비가역 불 대수 게이트 (AND, OR, NOT, NAND) |
| 한계 및 노이즈 취약성 | 환경 노이즈에 극도로 취약, 결맞음 손실(Decoherence) | 전압 마진 기반 극도의 노이즈 내성 및 오류율 $10^{-15}$ |

#### 한줄 요약

- 다차원 중첩 병렬은 **큐비트(Qubit)**, 결정론적 고신뢰 연산은 **고전 비트(Bit)**

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Coherence Time($T_1, T_2$)**:
  - $T_1$ (에너지 이완 시간): 들뜬 상태 $|1\rangle$에서 바닥 상태 $|0\rangle$으로 붕괴하는 시간.
  - $T_2$ (위상 결맞음 시간): 중첩 상태의 위상 관계가 노이즈로 파괴되는 시간 ($T_2 \le 2T_1$).
- **Crosstalk(크로스토크)**: 특정 큐비트 구동 펄스가 인접한 큐비트에 전자기적으로 누설되어 원치 않는 위상 오차를 유발하는 현상.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 외부 노이즈나 미세한 온도 변화에도 양자 상태가 깨져버리는 끔찍한 **결맞음 손실** 발발 | 칩을 절대영도 진공 냉장고에 처박고 전자파를 뼛속까지 차폐하여 **결맞음 시간**(T1/T2)을 한계치까지 연장 | 양자 연산 마법이 깨지기 전까지 계산을 끝마칠 수 있는 가용 유지시간을 멱살 잡고 확보 |
| 마이크로파 펄스를 쏠 때마다 오차가 누적되어 최종 정답이 쓰레기가 되는 **게이트 오류** 누적 폭발 | 큐비트 1개를 표현하기 위해 보조 큐비트 수십 개를 엮어 에러를 깎아내는 **양자 오류 정정**(QEC) 강제 수용 | 물리적 찌그러짐을 논리적으로 보정해 논리 오류율을 억제하고 신뢰성 있는 연산 100% 보장 |
| 옆에 있는 큐비트를 돌렸더니 내 큐비트까지 같이 요동치는 빡치는 Cross-talk 간섭 현상 | 큐비트 간 거리를 벌리고 평소엔 끊어놨다가 필요할 때만 이어주는 가변 **결합기** 투입 | 원치 않는 유령 간섭을 차단하여 2-Qubit Gate 연산의 충실도(Fidelity)를 극적으로 향상시킴 |

#### 한줄 요약

- **극저온 희석 냉동기(10mK) 결맞음 시간($T_1, T_2$) 확보·QEC(양자 오류 정정) 표면 코드·Tunable Coupler 크로스토크 차단**

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **FTQC(Fault-Tolerant Quantum Computing)**: 노이즈가 있는 물리 큐비트 수천 개를 오류 정정 코드로 묶어 오류율이 $10^{-10}$ 이하인 무결점 논리 큐비트를 구현하는 궁극의 양자 컴퓨팅 단계.

</details>

- 차세대 컴퓨팅 연구에서 **Shor/Grover 알고리즘 기반 특정 워크로드에 대한 양자 이득(Quantum Advantage) 실증 및 오류 억제 FTQC 표준 채택**

#### 한줄 요약

- **결맞음 시간 연장과 QEC 기반 논리 큐비트**를 통한 양자 컴퓨팅 실용화 달성
