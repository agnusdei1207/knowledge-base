## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **큐비트(Qubit/Quantum Bit)**: 0과 1의 고전 비트 상태 외에 중첩(Superposition) 및 얽힘(Entanglement) 상태를 표현하는 양자 컴퓨팅의 기본 정보 단위.
- **계산 기저(Computational Basis)**: 큐비트를 관측(Measurement) 시 수축 투영되는 고전 상태 기저벡터 ($|0\rangle, |1\rangle$).
- **상태 벡터(State Vector)**: 복소 확률 진폭(Complex Probability Amplitude) $\alpha, \beta$를 인자로 가지는 큐비트 상태 표현식 ($|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$).

</details>

- 정의/개념: 중첩·얽힘과 복소 진폭으로 상태를 표현하는 양자 정보 단위인 **큐비트**
- 배경/필요성: 특정 양자 시뮬레이션·인수분해는 **고전 계산량이 빠르게 증가**

#### 한줄 요약

- 큐비트는 0과 1 계산 기저의 복소 진폭을 상태 벡터로 표현하는 양자 정보 단위이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **확률 진폭(Probability Amplitude)**: 복소수 절댓값의 제곱이 각 계산 기저 수축 확률($|\alpha|^2, |\beta|^2$)을 결정하는 계수.
- **중첩(Superposition)**: 단일 큐비트가 0과 1의 상태를 기하학적 블로흐 구(Bloch Sphere) 상에서 동시 보유하는 속성.
- **얽힘(Entanglement)**: 둘 이상의 큐비트 상태가 상호 강력하게 바인딩되어 단일 큐비트 독립 관측이 불가능한 상태 ($|\Phi^+\rangle = \frac{|00\rangle + |11\rangle}{\sqrt{2}}$).

</details>

- 0과 1의 기저를 복소 **확률 진폭**으로 동시 표현하는 **중첩** 특성
- 개별 상태로 분리해 표현할 수 없는 큐비트 간 상관인 **얽힘**
- 관측 전까지 다중 병렬 상태를 보유하다가 측정 시 단일 기저로 수축(Collapse)하는 거동

$$
|\psi\rangle = \alpha|0\rangle + \beta|1\rangle,\qquad
|\alpha|^2 + |\beta|^2 = 1
$$

#### 한줄 요약

- 확률 진폭과 상대 위상 및 얽힘을 변환해 목표 측정 확률을 높인다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **큐비트 소자(Qubit Device)**: 초전도(Josephson Junction), 이온 트랩, 광자, 반도체 퀀텀닷 등 큐비트를 구현하는 물리 칩셋.
- **결합 구조(Coupler)**: 큐비트 간 교환 상호작용(Exchange Interaction)을 제어하여 2-큐비트(CNOT, CZ) 얽힘 게이트를 형성하는 결합기.
- **제어 계층(Control Layer)**: 마이크로파(RF) 또는 레이저 펄스를 인가하여 큐비트 블로흐 구 상의 회전 연산(Single-Qubit Gate)을 가하는 모듈.
- **측정 계층(Measurement Layer)**: 공진기(Resonator) 주파수 변이 또는 형광 검출을 통해 큐비트 상태를 0/1 고전 비트로 읽어내는 아키텍처.

</details>

```text
[제어 계층] -- [큐비트 소자] -- [결합 구조]
      |               |
[보정 계층] ----- [측정 계층]
```

선의 의미: 제어 계층 및 보정 계층이 큐비트 소자/결합 구조를 정밀 구동하고 측정 계층을 통하여 고전 결과를 획득하는 양자 하드웨어 구성.

| 구성요소 | 책임 |
|:---|:---|
| 큐비트 소자 | 물리 상태(초전도 회로, 이온 포획 등) 상의 양자 정보 보유 |
| 결합 구조 | **2-Qubit Gate**(CNOT, CZ) 구현을 위한 큐비트 간 **얽힘** 커플링 제어 |
| 제어 계층 | RF/마이크로파 펄스 성형 및 **단일 큐비트 게이트** 회전 제어 |
| 측정 계층 | 양자 상태의 0/1 수축 전압 변이 및 고전 Readout 판독 |

#### 한줄 요약

- 제어 계층·결합 구조·측정 계층·보정 계층을 결합해 큐비트 소자를 처리한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **양자 게이트(Quantum Gate)**: 상태 벡터를 가역적으로 회전 변환하는 유니타리 행렬(Unitary Matrix) 연산자.
- **샷(Shot)**: 확률적 양자 회로 결과를 통계 수집하기 위해 동일 회로를 초기화 및 측정을 반복 집계하는 단위.

</details>

```text
[양자 알고리즘•논리 회로]
             │
             ▼
1. 물리 게이트 매핑
             │
             ▼
┌──────────── 샷 반복 ────────────┐
│ 2. 큐비트 초기화                │
│             │                    │
│             ▼                    │
│ 3. 양자 게이트 실행             │
│             │                    │
│             ▼                    │
│ 4. 측정•고전 비트 변환          │
└─────────────┬───────────────────┘
              ▼
5. 반복 통계•고전 후처리
              │
              ▼
       [문제 해답 추정]
```

### 동작 원리

1. 물리 게이트 매핑: 논리 양자 알고리즘을 하드웨어 토폴로지에 맞춘 물리 **양자 게이트** 트랜스파일링.
2. 큐비트 초기화: **샷** 개시 시 큐비트를 $|0\rangle$ 기저 상태로 리셋.
3. 양자 게이트 실행: 마이크로파 펄스를 인가하여 **중첩** 및 **얽힘** 양자 연산 전개.
4. 측정·고전 비트 변환: 파동함수를 측정하여 0 또는 1의 고전 비트 정보로 래칭.
5. 반복 통계·고전 후처리: 반복 샷의 측정 분포를 집계해 문제 해답 추정.

#### 한줄 요약

- 장치에 맞춘 물리 게이트 매핑과 반복 샷 통계로 양자 회로의 결과를 추정한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **결맞음 손실(Decoherence)**: 외부 환경 열/전자기 노이즈로 인해 큐비트의 양자 위상 정보가 붕괴되는 현상.
- **양자 이득(Quantum Advantage)**: 특정 계산에서 양자 방식이 비교 가능한 고전 방식보다 우수함을 입증한 상태.

</details>

| 비교 항목 | 큐비트 (Qubit) | 고전 비트 (Classical Bit) |
|:---|:---|:---|
| 적용 기준 | 검증된 양자 알고리즘과 종단 이득 후보가 있을 때 | 일반 범용 연산, 데이터베이스, 웹 서비스 처리 시 |
| 정보 표현 | N큐비트 상태의 $2^N$개 복소 진폭 | N비트가 한 시점에 하나의 확정 상태 표현 |
| 핵심 한계 | **결맞음 손실** 및 짧은 T1/T2 유지시간 | 조합 폭발 문제(NP-Hard) 상의 계산 시간 극증 |

#### 한줄 요약

- 큐비트는 진폭•위상을 변환하고 확률적으로 측정하지만, 고전 비트는 확정된 값에 논리 연산을 수행한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **결맞음 시간(Coherence Time, T1/T2)**: T1(에너지 완화 시간), T2(위상 상쇄 시간) 기반 큐비트 유지 한계 시간.
- **QEC(Quantum Error Correction)**: 여러 물리 큐비트에 논리 정보를 부호화해 논리 오류율을 낮추는 기술.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 환경 노이즈로 인한 **결맞음 손실** 발생 | 소자 방식에 맞춘 냉각·진공·차폐와 T1/T2 개선 | 양자 연산 가용 유지시간 확보 |
| 펄스 변동에 의한 **게이트 오류** 누적 | 임계값 이하 물리 오류와 **QEC** 부호 적용 | 논리 오류율 억제 가능성 확보 |
| 큐비트 간 Cross-talk 간섭 | 물리적 거리 확보 및 가변 **결합기** 수용 | 2-Qubit Gate 충실도(Fidelity) 향상 |

> 사례: 표면 코드 크기 증가에 따른 물리·논리 오류율 변화 검증

#### 한줄 요약

- 장치 대기와 보정·회로 깊이·샷·후처리를 모두 포함한 종단 시간으로 양자 이득을 검증해야 한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **양자 컴퓨팅 선택 기준(Quantum Computing Selection Criteria)**: 대상 문제의 양자 알고리즘 존재 여부, 회로 깊이 및 양자 이득 달성 가능성에 기초한 체계.

</details>

- 검증된 알고리즘과 **종단 양자 이득**이 있으면 양자, 그 외는 고전 컴퓨터 선택

#### 한줄 요약

- 알고리즘·오류·종단 시간을 포함해 양자 이득이 입증될 때만 양자 방식을 선택한다.
