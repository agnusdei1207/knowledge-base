## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **큐비트(Qubit/Quantum Bit)**: 0도 아니고 1도 아닌, 그 두 상태가 유령처럼 겹쳐있는 기묘한 상태를 이용해 슈퍼컴퓨터가 1만 년 걸릴 계산을 몇 초 만에 끝내버리는 양자 컴퓨터의 뼛속 단위이다.
- **계산 기저(Computational Basis)**: 큐비트가 아무리 파동처럼 요동치고 있어도, 막상 사람이 눈으로 쳐다보는(측정하는) 순간 얄짤없이 0 아니면 1로 굳어버리는 도착 지점이다.
- **상태 벡터(State Vector)**: 큐비트가 0이 될 확률과 1이 될 확률이 얼마나 섞여 있는지 나타내는 복잡한 수학 공식(복소 확률 진폭)이다.

</details>

- 정의: 중첩·얽힘과 복소 진폭으로 0과 1이 섞여 있는 기묘한 상태를 표현하는 양자 컴퓨팅의 절대 정보 단위인 **큐비트**
- 배경: 분자 구조 시뮬레이션이나 암호 박살내기(소인수분해) 같은 문제는 일반 컴퓨터로 돌리면 시간이 우주 나이만큼 걸려서 **고전 계산량이 끔찍하게 터져나가기 때문**

#### 한줄 요약

- 0과 1 중 하나만 기억하는 일반 비트와 달리, 0과 1을 동시에 겹쳐서 기억하며 미친 속도로 병렬 계산을 해치우는 양자 세계의 정보 단위이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **확률 진폭(Probability Amplitude)**: 큐비트를 열어봤을 때 0이 나올지 1이 나올지를 결정짓는 확률의 씨앗 값으로, 마이크로파를 쏴서 이 값을 요리조리 조작하는 게 양자 연산이다.
- **중첩(Superposition)**: 동전이 앞면도 아니고 뒷면도 아닌, 빙글빙글 돌고 있어서 두 상태를 동시에 가진 살아있는 고양이와 죽은 고양이가 겹쳐있는 듯한 기괴한 상태이다.
- **얽힘(Entanglement)**: 서울에 있는 큐비트와 뉴욕에 있는 큐비트가 영혼이 묶여서, 서울 놈을 0으로 찌르면 뉴욕 놈도 빛보다 빨리 반응하는, 아인슈타인도 기겁한 유령 같은 텔레파시 현상이다.

</details>

- 0도 아니고 1도 아닌 상태를 복소 **확률 진폭**으로 동시 표현하며, 살아있는 고양이와 죽은 고양이가 겹쳐있는 듯한 기괴한 **중첩** 특성을 지님.
- 한 놈을 찌르면 반대쪽 놈이 빛보다 빨리 반응하는, 아인슈타인도 기겁한 큐비트 간 유령 같은 상관관계인 **얽힘** 현상을 부림.
- 계산 전까지는 무한한 우주처럼 다중 병렬 상태를 유지하다가, 눈으로 관측(측정)하는 순간 단 하나의 0이나 1의 고전 기저로 무자비하게 수축(Collapse)해버리는 거동을 보임.

$$
|\psi\rangle = \alpha|0\rangle + \beta|1\rangle,\qquad
|\alpha|^2 + |\beta|^2 = 1
$$

#### 한줄 요약

- 큐비트는 0과 1이 섞여 있는 중첩과, 서로 텔레파시가 통하는 얽힘을 이용해 계산하다가, 보는 순간 0이나 1로 굳어버린다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **큐비트 소자(Qubit Device)**: 절대영도(-273도)의 초전도체나 레이저에 갇힌 이온 같은 걸로 만들어져 진짜 양자 마법을 품고 있는 하드웨어 심장이다.
- **결합 구조(Coupler)**: 큐비트끼리 "너랑 나랑 운명 공동체야"라며 멱살을 잡고 서로의 파동을 엮어서 얽힘(Entanglement) 마법을 강제로 만들어내는 연결 고리이다.
- **제어 계층(Control Layer)**: 큐비트한테 마이크로파나 레이저를 쏴서 팽이처럼 빙글빙글 돌리며 입맛대로 연산(게이트)을 먹이는 조종사이다.
- **측정 계층(Measurement Layer)**: 연산 끝난 큐비트한테 "너 0이야 1이야?" 하고 빛을 쏴서, 파동으로 요동치던 놈을 0과 1의 고전 비트로 억지로 찍어 누르는 판독기이다.

</details>

```text
[ 양자 마법 제어 및 관측 붕괴 하드웨어 프레임워크 ]
       [ 제어 계층 (마이크로파 쏘는 조종사) ]
                         │
[ 큐비트 소자 (양자 심장) ] ─── [ 결합 구조 (얽힘 연결 고리) ]
                         │
       [ 측정 계층 (0/1로 억지로 찍어 누르는 판독기) ]
```

| 구성요소 | 책임 |
|:---|:---|
| **큐비트 소자** | 절대영도(-273도)의 초전도체나 레이저에 갇힌 이온 같은 걸로 만들어져 진짜 양자 마법을 품고 있는 하드웨어 심장 |
| **결합 구조** | "너랑 나랑 운명 공동체야"라며 큐비트끼리 멱살을 잡고 **얽힘**(Entanglement) 게이트를 강제로 만들어내는 연결 고리 |
| **제어 계층** | 마이크로파나 레이저 펄스를 쏴서 큐비트를 팽이처럼 빙글빙글 돌리며 입맛대로 연산(단일 게이트)을 먹이는 조종사 |
| **측정 계층** | "너 0이야 1이야?" 하고 빛을 쏴서 파동으로 요동치던 양자 상태를 0과 1의 고전 비트로 억지로 찍어 누르는 깐깐한 판독기 |

#### 한줄 요약

- 조종사(제어 계층)가 마이크로파를 쏴서 큐비트를 요리조리 돌리고 얽히게 만든 다음, 판독기(측정 계층)로 결과를 0이나 1로 읽어낸다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **양자 게이트(Quantum Gate)**: 고전 컴퓨터의 AND/OR 게이트처럼, 큐비트한테 마이크로파를 쏴서 0 확률을 줄이고 1 확률을 높이는 식으로 파동을 조작하는 마법 주문이다.
- **샷(Shot)**: 큐비트는 한 번 까보면 값이 확률로 튀기 때문에, 똑같은 계산을 수만 번 돌려보고 "1이 70% 나왔으니 답은 1이네" 하고 통계를 내는 반복 측정 단위이다.

</details>

```text
[ 논리 양자 회로 맵핑 및 샷 반복 측정 십자포화 통계 흐름 ]
                               │
                               ▼
   [ 1. 칠판 수학 번역: 양자 알고리즘을 기계가 알아듣는 물리 양자 게이트 펄스로 맵핑 ]
                               │
            ┌──────────────────┴──────────────────┐
            │          ( 무한 반복: 샷 )          │
            │                  ▼                  │
            │   [ 2. 초기화: 큐비트 영점 조준 ]   │
            │                  │                  │
            │                  ▼                  │
            │   [ 3. 펄스 난사: 중첩/얽힘 연산 ]  │
            │                  │                  │
            │                  ▼                  │
            │   [ 4. 파동 수축: 0/1로 확정 측정 ] │
            └──────────────────┬──────────────────┘
                               ▼
   [ 5. 통계 심판: 수만 번 돌린 결과 분포를 까보고 가장 많이 나온 값으로 진짜 해답 추정 ]
```

### 동작 원리

1. 물리 게이트 매핑: 칠판에 적은 양자 수학(알고리즘)을 실제 기계가 알아들을 수 있는 물리 **양자 게이트** 펄스로 트랜스파일링함.
2. 큐비트 초기화: **샷**을 때리기 직전에 모든 큐비트를 영점($|0\rangle$)으로 멱살 잡고 깨끗하게 초기화함.
3. 펄스 난사 및 연산: 마이크로파 펄스를 미친 듯이 난사하여 **중첩**시키고 **얽힘** 연산을 전개함.
4. 파동함수 수축 측정: 양자 상태를 눈으로 까봐서(관측), 파동으로 요동치던 값을 0 아니면 1로 무자비하게 확정(수축)시킴.
5. 무한 반복(샷) 통계: 양자는 한 번 보면 확률로 값이 튀니까, 똑같은 짓을 수만 번(샷 반복) 돌려서 나온 통계(가장 많이 나온 값)로 진짜 해답을 추정함.

#### 한줄 요약

- 알고리즘을 펄스로 바꾸고, 큐비트를 요리조리 볶은 다음 눈으로 확인하는 짓(샷)을 수만 번 반복해서 정답을 때려 맞춘다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **결맞음 손실(Decoherence)**: 온도나 미세한 노이즈만 껴도 큐비트의 파동(마법)이 산산조각 나서 0과 1의 평범한 찌끄레기로 전락해 버리는 개복치 같은 현상이다.
- **양자 이득(Quantum Advantage)**: 슈퍼컴퓨터가 1만 년 걸릴 계산을 양자 컴퓨터로 1초 만에 박살 냈을 때, "우리가 고전 컴퓨터를 이겼다!" 하고 선언하는 승리 판정이다.

</details>

| 비교 항목 | **큐비트** (Qubit) | **고전 비트** (Classical Bit) |
|:---|:---|:---|
| 시스템 적용 최적 기준 | 분자 구조 시뮬레이션이나 초거대 암호 털기처럼 억 단위 컴퓨터 1만 대를 돌려도 답이 없는 미친 문제 | 유튜브 시청, 카카오톡, 데이터베이스 관리처럼 우리가 흔히 아는 모든 일반적이고 평범한 연산 시 |
| 아키텍처 핵심 구현 특징 | $N$개의 큐비트가 모이면 $2^N$개의 우주(복소 진폭)를 동시에 품고 굴러가는 미친 병렬 연산력 폭발 | 아무리 칩이 좋아도 한 번에 딱 한 가지 상태(0 아니면 1)만 충실하게 표현하는 답답한 확정 상태 |
| 극복해야 할 태생적 한계점 | 주변 온도나 미세한 노이즈만 껴도 파동이 붕괴되어 0/1로 박살 나는 **결맞음 손실**의 치명적 약복숭아 체력 | 경우의 수가 조금만 늘어나도(NP-Hard) 연산 시간이 우주 나이보다 길어지는 끔찍한 조합 폭발의 한계 |

#### 한줄 요약

- 고전 비트는 동전이 앞 아니면 뒤로 딱 누워있지만, 큐비트는 수백 개의 동전이 빙글빙글 도는 상태로 계산을 해치우는 대신 바람만 불어도 쓰러진다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **결맞음 시간(Coherence Time, T1/T2)**: 큐비트가 마법 상태(파동)를 유지할 수 있는 쥐꼬리만 한 시간으로, 이 시간이 끝나기 전에 빨리 계산을 마쳐야 한다.
- **양자 오류 정정(Quantum Error Correction, QEC)**: 큐비트 하나가 노이즈 쳐맞고 뻗을까 봐, 보조 큐비트 수십 개를 방패막이로 세워서 에러를 고쳐내는 억지 맷집 기술이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 외부 노이즈나 미세한 온도 변화에도 양자 상태가 깨져버리는 끔찍한 **결맞음 손실** 발발 | 칩을 절대영도 진공 냉장고에 처박고 전자파를 뼛속까지 차폐하여 **결맞음 시간**(T1/T2)을 한계치까지 연장 | 양자 연산 마법이 깨지기 전까지 계산을 끝마칠 수 있는 가용 유지시간을 멱살 잡고 확보 |
| 마이크로파 펄스를 쏠 때마다 오차가 누적되어 최종 정답이 쓰레기가 되는 **게이트 오류** 누적 폭발 | 큐비트 1개를 표현하기 위해 보조 큐비트 수십 개를 엮어 에러를 깎아내는 **양자 오류 정정**(QEC) 강제 수용 | 물리적 찌그러짐을 논리적으로 보정해 논리 오류율을 억제하고 신뢰성 있는 연산 100% 보장 |
| 옆에 있는 큐비트를 돌렸더니 내 큐비트까지 같이 요동치는 빡치는 Cross-talk 간섭 현상 | 큐비트 간 거리를 벌리고 평소엔 끊어놨다가 필요할 때만 이어주는 가변 **결합기** 투입 | 원치 않는 유령 간섭을 차단하여 2-Qubit Gate 연산의 충실도(Fidelity)를 극적으로 향상시킴 |

#### 한줄 요약

- 칩을 절대영도로 얼려서 유지 시간을 벌고(결맞음 연장), 노이즈로 생기는 에러는 보조 큐비트 수십 개를 갈아 넣어서 억지로 고쳐야(QEC) 쓸만해진다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **양자 컴퓨팅 선택 기준(Quantum Computing Selection Criteria)**: 이 문제가 양자 컴퓨터로 풀었을 때 슈퍼컴퓨터를 쳐바를 수 있는지(양자 이득) 견적을 내어 기계를 고르는 잣대이다.

</details>

- **양자 컴퓨팅 선택 기준** 원칙에 따라, 슈퍼컴퓨터를 쳐바르는 **양자 이득**(Quantum Advantage)이 증명된 미친 문제에만 양자 컴퓨터를 선택함

#### 한줄 요약

- 아무 문제나 양자 컴퓨터에 넣는 게 아니라, 슈퍼컴퓨터로 수만 년 걸리는 암호 해독 같은 문제(양자 이득)에만 써먹어라.
