## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **큐비트(Qubit, Quantum Bit)**: 고전 컴퓨터의 0 또는 1 비트와 달리, 양자역학적 원리를 이용해 0과 1의 상태를 동시에 가질 수 있는 양자 정보의 기본 단위.
- **블로흐 구면(Bloch Sphere)**: 단일 큐비트의 순수 양자 상태를 3차원 단위 구 표면 위의 한 점으로 시각화한 기하학적 모델.

</details>

- 정의/개념: $|0\rangle$과 $|1\rangle$의 기저 상태를 복소수 확률 진폭으로 선형 결합하여 **양자 중첩과 얽힘 현상**을 정보 처리에 활용하는 양자 컴퓨팅 기본 단위
- 배경/필요성: 고전 컴퓨터의 비트(0/1) 표현 한계 및 **특정 복잡 난제(소인수분해/분자시뮬레이션) 연산 시간 폭증** 직면

$$
|\psi\rangle = \alpha|0\rangle + \beta|1\rangle \quad (단, |\alpha|^2 + |\beta|^2 = 1)
$$

#### 한줄 요약
- 0과 1을 동시에 품는 양자 중첩과 얽힘을 이용해 $N$개 큐비트로 $2^N$개의 계산을 한 번에 처리하는 차세대 정보 단위다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **양자 중첩(Superposition)**: 단일 큐비트가 $|0\rangle$과 $|1\rangle$ 두 기저 상태의 선형 결합으로 존재하여 동시에 확률적으로 두 상태를 모두 가지는 성질.
- **양자 얽힘(Entanglement)**: 두 개 이상의 큐비트가 강하게 결합되어 한 큐비트의 상태를 측정하는 즉시 다른 큐비트의 상태가 비국소적으로 결정되는 현상.

</details>

- **양자 중첩(Superposition)**을 통해 $N$개 큐비트로 $2^N$개의 정보를 동시 표현
- **양자 얽힘(Entanglement)**을 활용한 초병렬 다체 상관관계 연산 지원
- **양자 간섭(Interference)**을 이용해 오답 경로는 상쇄하고 정답 확률 진폭만 증폭

#### 한줄 요약
- 중첩으로 방대한 경우의 수를 동시에 펼쳐놓고, 얽힘과 간섭을 이용해 정답만 솟아오르게 만든 뒤 관측한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **유니터리 게이트(Unitary Gate)**: 큐비트의 상태 확률 총합(노름, Norm)을 1로 보존하며 가역적으로 회전 변환을 수행하는 양자 논리 게이트.
- **판독 회로(Readout Circuitry)**: 큐비트의 양자 상태를 고전 전기 신호(0 또는 1)로 변환 측정하는 초고감도 판독기.

</details>

```text
┌─────────────────────────────────────────────────────────────┐
│ 큐비트 블로흐 구면(Bloch Sphere) 및 양자 연산 시스템 구조   │
│                                                             │
│                |0> (Z축 북극)                               │
│                 ▲                                           │
│                 │      ● |ψ> = α|0> + β|1>                  │
│                 │     /                                     │
│                 │ θ  /                                      │
│                 │   /                                       │
│                 │  /   φ                                    │
│                 └──┼──────► Y축                             │
│                /   │                                        │
│               /    │                                        │
│              ▼     ▼                                        │
│            X축    |1> (Z축 남극)                            │
│                                                             │
│  [ 양자 제어 펄스 (Microwave/Laser) ] ──► [ 유니터리 게이트 ]│
│                                                   │         │
│  [ 양자 측정 및 상태 붕괴 ] ◄─────────────────────┘         │
└─────────────────────────────────────────────────────────────┘
```

선의 의미: 제어 펄스가 블로흐 구면 상에서 큐비트 벡터를 회전시키고(유니터리 게이트), 측정 시 Z축(|0> 또는 |1>)으로 붕괴

| 구성요소 | 책임 |
|:---|:---|
| 물리 큐비트 (Physical Qubit) | 초전도 조셉슨 접합, 이온 트랩, 광자 등 물리적 소자로 양자 준위 구현 |
| 단일 큐비트 게이트 (X, Y, Z, H) | 블로흐 구면 상에서 단일 큐비트의 위상 및 기저 상태를 정밀 회전 변환 |
| 다중 큐비트 게이트 (CNOT, CZ) | 2개 이상의 큐비트를 상호작용시켜 양자 얽힘(Entanglement) 상태 생성 |
| 양자 판독 회로 (Readout) | 공진기(Resonator) 주파수 천이를 감지해 양자 상태를 고전 디지털 비트로 측정 |
| 극저온 칠러 (Dilution Fridge) | 열잡음으로 인한 결맞음 손실(Decoherence)을 막기 위해 10mK 극저온 환경 유지 |

#### 한줄 요약
- 물리 큐비트, 단일/다중 양자 게이트, 극저온 냉각 챔버, 초고감도 판독 회로가 하나의 양자 프로세서를 구성한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **결맞음 시간(Coherence Time, $T_1/T_2$)**: 큐비트가 외부 환경 노이즈에 의해 양자적 특성을 잃어버리기 전까지 중첩과 위상을 유지하는 수명.

</details>

```text
양자 알고리즘 회로 작성 (Qiskit/Cirq)
      │
      ▼
1. 큐비트 초기화: 모든 큐비트를 바닥 기저 상태(|0...0>)로 정렬
      │
      ▼
2. 아다마르(H) 게이트 인가: 균등한 확률 진폭을 갖는 양자 중첩 상태($|+\rangle$) 생성
      │
      ▼
3. 얽힘 및 오라클 연산: CNOT 게이트로 얽힘 형성 후 문제 함수(Oracle) 병렬 연산
      │
      ▼
4. 양자 간섭 증폭: 진폭 증폭(Grover Diffusion)으로 정답 상태의 관측 확률 극대화
      │
      ▼
5. 기저 측정: 파동함수 붕괴를 통해 고전 비트열(0101...) 획득 및 샷(Shot) 통계 집계
```

**동작 원리**

1. **상태 초기화**: 레이저 펄스나 마이크로파로 모든 물리 큐비트를 순수 $|0\rangle$ 상태로 리셋
2. **중첩 전개**: 아다마르(Hadamard) 게이트를 적용해 $2^N$개의 모든 상태가 동시에 공존하도록 전개
3. **병렬 연산**: 대상 함수를 유니터리 행렬로 통과시켜 모든 상태에 대해 단 1회의 사이클로 동시 계산
4. **간섭 제어**: 보강 간섭(Constructive)과 상쇄 간섭(Destructive)을 유도해 정답 진폭만 집중 증폭
5. **투영 측정**: 양자 상태를 측정하여 확률적으로 가장 높은 정답 비트열을 고전 컴퓨터로 회수

#### 한줄 요약
- 초기화(|0>) → 중첩 전개(H) → 얽힘 및 오라클 연산 → 진폭 증폭(간섭) → 측정 및 고전 변환 순으로 진행된다.

## Ⅴ. 종류 및 비교

| 정보 표현 단위 및 컴퓨팅 모델 | 양자 큐비트 (Qubit) | 고전 비트 (Bit) | 확률적 비트 (p-bit) | 양자 어닐링 큐비트 |
|:---|:---|:---|:---|:---|
| 적용 기준 | 범용 양자 컴퓨팅(쇼어/그로버 알고리즘) | 범용 디지털 컴퓨터 및 스마트폰 | 에너지 기반 확률적 최적화 연산 | 특정 조합 최적화 난제 전용 연산 |
| 핵심 특징 | 복소 진폭 기반 양자 중첩·얽힘·간섭 | 0 또는 1의 확정적 불리언(Boolean) 값 | 열잡음을 이용해 0과 1 사이를 요동 | 터널링 기반 전역 최적점(Ground State) 탐색 |
| 한계 | 짧은 결맞음 시간 및 높은 양자 에러율 | $2^N$ 규모 지수적 복잡도 난제 해결 불가 | 복소 위상 간섭 불가(위상 정보 부재) | 범용 양자 게이트 연산 알고리즘 실행 불가 |

#### 한줄 요약
- 범용 양자 연산은 큐비트, 고전 디지털은 비트, 확률 모델은 p-bit, 조합 최적화는 어닐링 큐비트를 쓴다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **결맞음 손실(Decoherence)**: 미세한 온도 변화나 전자기 노이즈로 인해 큐비트의 양자 중첩 상태가 고전적 무작위 상태로 붕괴되는 현상.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 열잡음으로 인한 **결맞음 손실(Decoherence) 및 연산 에러** | **희석 냉동기(Dilution Refrigerator)**로 10mK 극저온 유지 및 차폐 챔버 장착 | 큐비트 결맞음 수명($T_1, T_2$) 획기적 연장 |
| 물리 큐비트의 **높은 게이트 에러율(0.1~1%)** | **양자 오류 정정(QEC, 표면 코드)**을 통해 논리 큐비트 합성 | 오류율 $10^{-10}$ 이하 무결점 양자 연산 실현 |
| 다중 큐비트 확장 시 발생하는 **신호 간섭(Crosstalk 노이즈)** | 플럭서블 동축 케이블 라우팅 및 펄스 캘리브레이션 알고리즘 적용 | 인접 큐비트 간 전자기 간섭 최소화 |
| 양자 측정 결과의 **확률적 오차 및 노이즈** | **다중 샷(Shots) 반복 측정** 및 제로 노이즈 외삽(ZNE) 오류 완화 기법 적용 | 통계적 신뢰도 99% 이상 확보 |

#### 한줄 요약
- 10mK 극저온으로 결맞음을 지키고, 표면 코드로 오류를 잡으며, ZNE 완화 기법으로 측정 신뢰도를 높인다.

## Ⅶ. 결론

- 양자 우위(Quantum Advantage) 실현을 위해 **물리 큐비트 고집적화**와 **오류 정정 기반 논리 큐비트(Fault-Tolerant Qubit) 전환** 필수

#### 한줄 요약
- 중첩, 얽힘, 간섭의 양자역학적 원리를 정밀 제어하여 고전 컴퓨터로 불가능한 지수적 복잡도의 계산 난제를 해결해야 한다.
