## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **데이터센터 티어(Data Center Tier)**: Uptime Institute가 전력·냉각 등 사이트 인프라의 유지보수성과 결함 허용성을 평가하는 4단계 인증 체계.
- **TIA-942 Rated**: 통신산업협회(TIA)가 통신, 건축, 전기, 기계 4개 분야를 포괄하여 데이터센터 신뢰성을 평가하는 등급 체계.

</details>

- 정의/개념: 데이터센터 인프라 가용성을 보장하기 위해 **동시 유지보수성·결함 허용성**을 기준으로 전력과 냉각 경로를 평가하는 표준 분류 체계
- 배경/필요성: 장비 수량만 중복해도 공유 배관·배전 경로나 유지보수 절차가 남으면 계획·비계획 정지 발생

#### 한줄 요약
- 정전이나 장비 고장, 정기 점검 중에도 서버가 멈추지 않도록 데이터센터의 전력과 냉각 안정성을 4단계로 나눈 표준이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **동시 유지보수성(Concurrent Maintainability)**: 핵심 설비의 계획된 정기 점검 및 수리 중에도 IT 부하에 전원과 냉각을 무중단 공급할 수 있는 능력(Tier III).
- **결함 허용성(Fault Tolerance)**: 단일 고장이 IT 부하에 미치는 영향을 격리해 전력·냉각 공급을 유지하는 능력(Tier IV).

</details>

- Tier I 기본 용량부터 Tier IV 결함 허용까지 **성과 기반 요구사항** 단계화
- **Tier III 동시 유지보수성**으로 계획 정비 시 IT 부하 공급 유지
- **Tier IV 결함 허용성**으로 단일 설비·배전 경로 고장의 영향 격리

#### 한줄 요약
- Tier I·II는 단일 배전 경로, Tier III는 동시 유지보수, Tier IV는 단일 고장 허용을 목표로 한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **N / N+1 / 2N**: 기본 필요 용량(N), 예비 장비 1개 추가(N+1), 완전히 독립된 2개의 독립 전원/냉각 시스템 구축(2N).

</details>

```text
┌─────────────────────────────────────────────────────────────┐
│ Uptime Tier I ~ IV 인프라 경로 토폴로지 비교                │
│                                                             │
│  [ Tier I : Basic ]         [ Tier II : Redundant ]         │
│  상용전원 ──► UPS ──► 서버  상용전원 ──► [UPS N+1] ──► 서버 │
│  (단일 경로, N 용량)        (단일 경로, N+1 모듈 중복)      │
│                                                             │
│  [ Tier III : Concurrently Maintainable ]                   │
│  상용전원 A ──► UPS A ──► PDU A ──┐                         │
│                                   ├──► [서버 이중화 PSU]    │
│  상용전원 B ──► Bypass/UPS B ─────┘                         │
│  (1 Active + 1 Alternate 경로, 무중단 설비 유지보수 가능)   │
│                                                             │
│  [ Tier IV : Fault Tolerant ]                               │
│  시스템 A : 상용전원 A ──► UPS A ──► PDU A ──┐ (2N 독립 경로)│
│                                              ├──► [서버]    │
│  시스템 B : 상용전원 B ──► UPS B ──► PDU B ──┘ (물리적 격리)│
└─────────────────────────────────────────────────────────────┘
```

선의 의미: 등급별 전원 경로 개념 예시이며 실제 인증은 전체 전력·냉각 성과와 고장 시나리오로 판정

| 구성요소 | 책임 |
|:---|:---|
| Tier I (기본 인프라) | 단일 비중복 배전 경로와 기본 용량 구성 |
| Tier II (용량 잉여) | 단일 배전 경로에 용량 구성요소 예비분 추가 |
| Tier III (동시 유지보수) | 모든 용량·배전 구성요소를 계획 정비해도 IT 부하 공급 유지 |
| Tier IV (결함 허용) | 단일 고장 발생 시에도 IT 부하 공급을 유지하도록 영향 격리 |
| 냉각 및 전력 패브릭 | CRAC, 칠러, 배전선로를 등급 요구사항에 맞춰 이중화하여 지속 가동 지원 |

#### 한줄 요약
- Tier I(N), Tier II(N+1), Tier III(다중 경로/무중단 정비), Tier IV(2N/완전 결함 허용)로 구성된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **커미셔닝(Commissioning)**: 데이터센터 준공 전 설계된 Tier 등급에 맞게 정전 및 장비 고장 시나리오를 가상 부하로 실측 검증하는 절차.

</details>

```text
데이터센터 가용성 목표 수립 (RTO/RPO)
      │
      ▼
1. 비즈니스 분석
      │
      ▼
2. 이중화 토폴로지 설계
      │
      ▼
3. 가상 부하 검증
      │
      ▼
4. 인증 심사
      │
      ▼
5. 표준 운영 절차 준수
```

**동작 원리**

1. **비즈니스 분석**: 금융/클라우드 등 미션 크리티컬 워크로드의 가용성 요구사항 산정
2. **이중화 토폴로지 설계**: 전기실 물리 분리, 듀얼 한전 인입, N+1/2N UPS 및 배관 배치
3. **가상 부하 검증**: 발열 히터와 더미 로드를 투입해 상용 전원 차단 시 무순단 전환 실측
4. **글로벌 인증 심사**: Uptime Institute 심사관의 현장 실사를 통해 Tier 인증서 획득
5. **표준 운영 절차 준수**: 예방 정비 시 동시 유지보수성 절차를 준수하여 인적 오류 방지

#### 한줄 요약
- 목표 수립 → 이중화 설계 → 가상 부하 커미셔닝 → Tier 인증 심사 → 무중단 운영 관리 순으로 진행된다.

## Ⅴ. 종류 및 비교

| 데이터센터 등급 | Tier I (Basic) | Tier II (Redundant) | Tier III (Concurrently Maint.) | Tier IV (Fault Tolerant) |
|:---|:---|:---|:---|:---|
| 적용 기준 | 단순 업무용 내부 전산실 | 일반 기업 웹 서버 및 비핵심 IT | 글로벌 클라우드 및 금융 결제 인프라 | 국가 핵심 망·최고 등급 금융 코어 |
| 핵심 특징 | 단일 비중복 배전 경로 | 단일 경로와 예비 용량 구성요소 | 동시 유지보수 가능한 용량·배전 구성 | 단일 고장을 허용하는 인프라 구성 |
| 한계 | 정기 점검 및 부품 고장 시 전면 중단 | 선로 차단기 고장 시 서비스 다운 | 동시 복수 고장(2개 이상 장애) 시 취약 | 막대한 초기 건축 비용 및 높은 운영 TCO |

#### 한줄 요약
- 단순 전산실은 Tier I/II, 무중단 비즈니스는 Tier III, 최고 수준 금융·국가망은 Tier IV를 구축한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **공통 원인 고장(Common Cause Failure)**: 서로 다른 이중화 선로가 동일한 배전반, 제어 소프트웨어, 또는 물리적 공간을 공유하여 동시에 마비되는 사고.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| A/B 전원 선로의 **물리적 동일 경로 배치로 동시 파손** | 배선 트레이 및 전기실 물리 구획 분리(Fire Compartment) | 화재·누수 시 단일 선로 보호 및 가용성 유지 |
| 설비 정기 점검 중 인적 조작 실수로 인한 **전원 트립** | 승인된 절차·교차 확인과 **LOTO** 적용 | 오조작과 위험 에너지 노출 감소 |
| 단일 파워 서버 도입으로 인한 **Tier III 인프라 무력화** | 랙 단위 **자동 절체 스위치(STS)** 설치로 듀얼 피드 공급 | 레거시 단일 전원 장비의 무중단 수용 |
| 디젤 발전기 비상 기동 실패 사고 | 정기 **로드 뱅크 시험**과 연료·시동 계통 관리 | 실제 부하 조건의 기동·용량 결함 조기 발견 |

#### 한줄 요약
- 물리적 구획 분리로 공통 고장을 막고, LOTO로 인적 실수를 방지하며, STS와 실부하 시험으로 신뢰성을 검증한다.

## Ⅶ. 결론

- 계획 정비 중단을 허용할 수 없으면 **Tier III**, 단일 고장도 격리해야 하면 Tier IV 목표
- 서비스 아키텍처의 이중화와 비용을 함께 평가해 과도한 시설 등급 투자 방지

#### 한줄 요약
- 단순 장비 중복을 넘어 전력과 냉각의 완전 분리 다중 경로와 표준 운영 절차를 확립하여 데이터센터 가용성을 달성해야 한다.
