## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **데이터센터 티어(Data Center Tier)**: 전력, 냉각, 통신 설비 인프라가 정비 및 장애를 견디는 가용성(Availability) 수준을 Tier I부터 Tier IV까지 4단계로 규정한 Uptime Institute의 글로벌 인증 표준.
- **TIA-942 Rated**: 통신(Telecommunications), 건축(Architectural), 전기(Electrical), 기계/냉각(Mechanical)의 4대 영역을 종합 평가하여 데이터센터 신뢰성을 등급화한 미국 통신산업협회 표준.

</details>

- 정의/개념: 데이터센터 전력 및 냉각 인프라의 가용성과 이중화 수준을 규정한 **Uptime Institute 티어 표준 체계**
- 배경/필요성: 데이터센터 전력·냉각 인프라의 단일 장애점(SPOF)으로 인한 대규모 서비스 중단 및 **정비 시 시스템 셧다운 위험 방어 한계 극복 및 고가용성 인프라 구축 기준 정립 필요성 증대**

#### 한줄 요약
- **데이터센터 티어**는 전력과 냉각 경로의 물리적 다중화 수준을 바탕으로 Tier I(기본)부터 Tier IV(결함 허용)까지 시설 가용성을 평가하는 표준이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **동시 유지보수성(Concurrent Maintainability)**: 핵심 전력/냉각 설비(UPS, 변압기, 칠러 등)의 계획된 정기 점검, 수리 및 교체 중에도 IT 부하에 100% 무단절 전력과 냉각을 공급하는 능력(Tier III).
- **결함 허용성(Fault Tolerance)**: 예기치 못한 단일 전기/기계 장애(차단기 트립, 배관 파열 등)가 발생해도 자동 격리 및 대체 경로를 통해 IT 운영에 일체 영향이 없는 능력(Tier IV).

</details>

- 4단계 계층화: Tier I부터 Tier III(동시 정비성) 및 **Tier IV(결함 허용성)**까지 4단계 가용률 체계화
- 무중단 정비 실현: 다중 배전·냉각 경로 확보를 통한 운영 중 **동시 유지보수성** 보장
- 완전 물리 격리: 2N 독립 계통의 방화 구획 분리를 통한 단일 장애 국소화 및 결함 허용 달성

#### 한줄 요약
- 계획된 정비를 무중단으로 수용하는 Tier III와 예고 없는 돌발 고장까지 완전 격리하는 Tier IV로 고가용성 인프라를 구분한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **N / N+1 / 2N 이중화 구조**: IT 부하 구동에 필요한 기본 용량(N), 예비 장비 1대 추가(N+1), 완전히 독립된 2개의 시스템을 100% 중복 구축(2N).

</details>

```text
+-------------------------------------------------------------------------------+
|                       데이터센터 티어(Tier I ~ IV) 아키텍처 비교              |
|                                                                               |
|  [ Tier I: 단일 경로 (N) ]              [ Tier II: 단일 경로 + 예비 모듈 (N+1)]|
|  +---------------------------------+   +------------------------------------+ |
|  | 수전 -> 변압기 -> UPS -> PDU    |   | 수전 -> 변압기 -> [UPS A / UPS B]  | |
|  | (단일 경로: 정비 시 셧다운)     |   | (모듈 이중화, 경로는 단일 선로)    | |
|  +---------------------------------+   +------------------------------------+ |
|                                                                               |
|  [ Tier III: 다중 경로 동시 정비 (N+1)] [ Tier IV: 완전 물리 분리 결함허용 (2N)]|
|  +---------------------------------+   +------------------------------------+ |
|  | 주 전력 경로 A (Active) =======>|   | 독립 수전 A -> 변압기 A -> UPS A   | |
|  | 예비 경로 B (Standby) ========> |   | [방화구획 A] ===(2N Dual Active)== | |
|  | (1 Active + 1 Standby 무중단정비)|   | [방화구획 B] ===(완전 물리 격리)== | |
|  |                                 |   | 독립 수전 B -> 변압기 B -> UPS B   | |
|  +---------------------------------+   +------------------------------------+ |
+-------------------------------------------------------------------------------+
```

- 신호 및 연결 관계: Tier I/II는 단일 경로(`->`)로 인해 선로 정비 시 정전이 불가피하며, Tier III는 주/예비 다중 선로(`=======>`)로 동시 정비성을 보장하고, Tier IV는 완전 격리된 2N 듀얼 액티브 경로로 단일 설비 파열 시에도 무영향 결함 허용을 달성함을 명시함

| 구성요소 | 책임 |
|:---|:---|
| Tier I | 단일 경로·용량 $N$의 기본 인프라 제공 |
| Tier II | 단일 경로에 예비 모듈 $N+1$ 구성 |
| Tier III | 다중 경로로 **동시 유지보수성** 확보 |
| Tier IV | 2N 물리 격리로 **결함 허용성** 확보 |

#### 한줄 요약
- Tier I/II의 단일 경로에서 Tier III의 동시 유지보수 다중 경로, Tier IV의 2N 완전 물리 격리 결함 허용 구조로 진화한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **커미셔닝(Commissioning)**: 데이터센터 준공 전 설계된 Tier 등급에 맞게 정전, 배관 단선, 차단기 트립 시나리오를 가상 열부하 뱅크로 실측 검증하는 절차.

</details>

```text
+-------------------------------------------------------------+
|     비즈니스 가용성 요구사항 및 연간 허용 다운타임 분석     |
+-------------------------------------------------------------+
                               │
                               ▼
               +-------------------------------+
               | 1. 운영 중 무중단 정비 요구?  |
               +-------------------------------+
                      |                 |
             [아니오 (정기 셧다운)]     | [예 (24/7 무중단 정비)]
                      |                 v
                      | +-------------------------------+
                      | | 2. 단일 장애 결함 허용 요구?  |
                      | +-------------------------------+
                      |                 |
                      |       [아니오]  |  [예]
                      |          |      |   |
                      v          v      |   v
+-----------------------+ +-----------+ | +---------------------+
| Tier I (N) / Tier II  | | Tier III  | | | Tier IV (2N)        |
| 단일 경로 기본 설계   | | 다중 경로 | | | 완전 물리 분리 격리 |
+-----------------------+ +-----------+ | +---------------------+
                      |          |      |   |
                      +----------+------+---+
                               │
                               ▼
+-------------------------------------------------------------+
| 3. 가상 열부하 뱅크 투입 기반 커미셔닝(Commissioning) 검증   |
+-------------------------------------------------------------+
                               │
                               ▼
+-------------------------------------------------------------+
| 4. Uptime Institute 공식 티어 인증 획득 및 인프라 가동       |
+-------------------------------------------------------------+
```

분기 결과: 정기 점검 시 셧다운 허용 여부로 Tier II와 III가 갈리며, 예기치 못한 돌발 단일 장애 격리 요구 시 Tier IV 2N 구조로 확정됨

**동작 원리**

1. **가용성 요건 분석**: 기업 서비스의 비즈니스 영향도와 SLA 요구 가용률(99.671%~99.995%) 및 다운타임 허용 범위 분석
2. **동시 유지보수성 판정**: 장비 점검이나 교체 시 계획된 서비스 셧다운이 가능한지 검토하여 불가능할 경우 다중 전력/냉각 경로를 필수 요건으로 채택
3. **결함 허용성 판정**: 설비의 예상치 못한 단일 고장(차단기 단선, 냉각관 누수) 발생 시 인간의 수동 개입 없이 시스템이 100% 자동 생존해야 하는지 판정
4. **경로 토폴로지 설계**: Tier III는 1개 활성 경로와 1개 대기 경로의 다중 배선으로 동시 유지보수성을 구성하고, Tier IV는 완전 물리 구획 분리된 2N 듀얼 액티브 배선으로 결함 허용 구조 설계
5. **커미셔닝 실측 검증**: 설계 준공 후 실하중 가상 로드뱅크를 가동하여 상용 전원 차단 및 냉각 밸브 차단 시나리오를 실측하는 커미셔닝을 거쳐 가용성 최종 공인

#### 한줄 요약
- 티어 상승은 경로를 이중화해 정비·고장 중에도 가동을 유지하는 대가로 설비 투자와 상면을 함께 치르므로, 요구 가용 시간과 구축 예산이 교차하는 지점에서 등급이 정해진다.

## Ⅴ. 종류 및 비교

| 대상 구분 | Tier I (기본 인프라) | Tier II (이중화 부품) | Tier III (동시 정비성) | Tier IV (결함 허용성) |
|:---|:---|:---|:---|:---|
| 적용 기준 | 정기 점검 시 비업무 시간 셧다운 허용 연구/개발실 구축 시 | 단시간 정비 셧다운 허용 일반 중소기업 전산실 구축 시 | 24/7 서비스 무중단 유지보수가 필수적인 상용 클라우드/금융 포털 구축 시 | 단일 부품 고장 시 자동 격리 결함 허용 필수인 국가 기간망/금융 원장 구축 시 |
| 핵심 특징 | 단일 전력/냉각 경로(N), 가용률 99.671%(연간 다운타임 28.8시간), 최저 CAPEX | 단일 경로 + 주요 부품 이중화(N+1), 가용률 99.741%(연간 22.0시간) | 다중 배선 경로(1 Act + 1 Alt), **무중단 동시 유지보수성(N+1)**, 가용률 99.982%(연간 1.6시간) | 독립 2N 완전 물리 분리, **결함 허용성(Fault Tolerance)**, 자동 격리, 가용률 99.995%(연간 0.4시간) |
| 한계 | 설비 점검 및 고장 시 전면 셧다운 불가피, SPOF 다수 존재 | 배전선로 및 냉각 배관 단일 경로로 선로 정비 시 중단 발생 | 돌발적인 중대 결함 시 수동 우회 개입 필요 가능성 잔존 | CAPEX/OPEX 극대화(Tier I 대비 3배 이상), 방화 구획 부지 상면 부담 가중 |

#### 한줄 요약
- 일반 클라우드 및 금융 서비스에는 Tier III가 표준이며, 국가 안보 및 핵심 금융 시스템에는 Tier IV가 필수적이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **공통 원인 고장(Common Cause Failure)**: 서로 다른 이중화 선로가 동일한 케이블 트레이, 배전반, 또는 물리적 공간을 공유하여 단일 사고(화재, 누수)로 동시에 마비되는 현상.
- **정적 절체 스위치(Static Transfer Switch, STS)**: 단일 전원 입력 장비(Single Corded)에 대해 2개 독립 전원 경로를 4ms 이내로 무순단 절체 공급하는 스위치.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 전원선 공유로 인한 **공통 원인 고장** | 전기실·배선 트레이 및 냉각 배관 **방화 구획 분리** | 화재·침수 시 단일 계통 100% 생존 보장 |
| 단일 전원선 장비 도입 시 이중화 무력화 | 랙 단위 **정적 절체 스위치(Rack STS)** 적용 | 단일 전원 장비 대상 무순단 절체 구현 |
| 정기 점검 시 엔지니어 차단기 오조작 | **표준 작업 절차서(MOP)** 및 LOTO 의무화 | 인적 오류(Human Error)로 인한 셧다운 방지 |

#### 한줄 요약
- 실무에서는 물리적 방화 구획 분리로 공통 고장을 막고, Rack STS로 단일 전원 장비를 수용하며, MOP/LOTO로 인적 실수를 차단한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **Multi-AZ(Multi-Availability Zone)**: 단일 데이터센터 재난에 대비하여 지리적으로 수십 km 이상 격리된 복수의 데이터센터에 워크로드를 분산 배치하는 클라우드 아키텍처.
- **LOTO(Lockout-Tagout)**: 전기 설비 정비 시 차단기를 물리적 자물쇠로 잠그고 경고 태그를 부착하여 타 작업자의 오인가를 방지하는 산업 안전 절차.

</details>

- 상용 클라우드 및 엔터프라이즈 데이터센터의 글로벌 표준은 동시 유지보수성을 보장하는 Tier III(가용률 99.982%)이며, 국가 기간망 및 핵심 금융 원장의 경우 완전 결함 허용(Fault Tolerance) 2N 구조의 Tier IV 구축이 필수적이므로 아키텍트는 물리 설비의 티어 등급 충족뿐만 아니라 클라우드 멀티 가용영역(Multi-AZ) 분산 설계를 결합하여 설비와 소프트웨어 전 계층의 가용성을 총체적으로 보장하는 복원력(Resilience) 체계 확립 필수.

#### 한줄 요약
- 데이터센터 티어는 하드웨어 경로 이중화의 표준 잣대이며, Tier III/IV 설계와 멀티 AZ 분산 배치의 결합으로 완성된다.
