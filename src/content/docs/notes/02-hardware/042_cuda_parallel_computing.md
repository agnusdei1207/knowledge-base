## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **CUDA(Compute Unified Device Architecture)**: NVIDIA가 개발한 GPU 병렬 컴퓨팅 플랫폼 및 C/C++ 기반 프로그래밍 모델.
- **GPGPU(General-Purpose computing on GPUs)**: 그래픽 렌더링에만 국한되던 GPU 연산 파이프라인을 범용 과학 계산 및 AI 딥러닝 연산에 활용하는 기술.

</details>

- 정의/개념: C/C++ 확장으로 GPU를 제어하는 **CUDA 병렬 프로그래밍 모델**
- 배경/필요성: GPU 하드웨어가 있어도 그래픽스 API를 우회 수단으로 삼으면 범용 연산을 표현하는 데 변환 비용이 들어 **대규모 데이터 병렬 처리량**을 살리지 못하므로, C/C++ 확장으로 스레드 계층과 메모리 계층을 직접 기술하게 하는 프로그래밍 계층의 필요

#### 한줄 요약
- CUDA는 개발자가 친숙한 C/C++ 언어로 수천 개의 GPU 연산 코어를 직접 제어할 수 있게 해주는 GPGPU 표준 플랫폼이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **그리드-블록-스레드(Grid-Block-Thread)**: CUDA 프로그래밍의 3단계 계층 구조로, 알고리즘을 하드웨어 SM 및 워프에 직관적으로 매핑하는 가상화 단위.
- **CUDA 스트림(CUDA Stream)**: 호스트가 GPU에 발행하는 명령어(메모리 전송, 커널 실행)들의 순차적 실행 대기열로, 다중 스트림 간 비동기 중첩 지원.
- **고정 메모리(Pinned Memory)**: OS 가상 메모리 페이징에 의해 스왑 아웃되지 않고 물리 메모리에 고정되어 GPU DMA가 고속 직접 접근하는 호스트 메모리.

</details>

- 계층적 병렬 추상화: **그리드-블록-스레드** 3단계 계층을 통해 알고리즘을 하드웨어 SM 및 워프에 직관적 매핑
- 프로그래머블 메모리 계층: 레지스터, 온칩 **공유 메모리(Shared Memory)**, L1/L2 캐시, 글로벌 메모리를 직접 통제
- 비동기 스트림 파이프라이닝: **CUDA 스트림**을 활용하여 데이터 전송 지연시간을 커널 연산 시간 뒤로 완전 은닉

#### 한줄 요약
- 계층적 스레드 구조와 프로그래머블 메모리, 비동기 스트림을 통해 GPU 연산 성능을 극대화한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **커널 함수(Kernel Function)**: `__global__` 한정자로 선언되어 호스트가 런칭하고 GPU의 수많은 스레드에서 병렬 실행되는 C/C++ 함수.
- **공유 메모리(Shared Memory)**: `__shared__` 한정자로 선언되어 동일 스레드 블록 내 스레드들이 초고속으로 공유하는 온칩 SRAM.

</details>

```text
[CUDA 소프트웨어-하드웨어 매핑 계층]
 ├─ 호스트 (Host: CPU & 시스템 DRAM)
 │   └─ 고정 메모리 (Pinned Host Memory)
 ├─ 인터커넥트 버스 (PCIe / NVLink)
 └─ 디바이스 (Device: GPU & 글로벌 메모리)
     ├─ 그리드 (Grid: 소프트웨어 커널 인스턴스)
     ├─ 스레드 블록 (Thread Block: SM 매핑 단위)
     ├─ 워프 (Warp: 32개 스레드 실행 단위)
     └─ 온칩 메모리 계층 (레지스터 & 공유 메모리)
```

선의 의미: 가지(`├─`, `└─`)는 하드웨어 소속 및 매핑 계층 관계를 나타냄

| 구성요소 | 책임 |
|:---|:---|
| 호스트·디바이스 | CPU 제어와 GPU **병렬 연산** 분담 |
| 그리드 | 커널의 **스레드 블록 배열** 구성 |
| 스레드 블록 | SM 자원을 공유하며 **협력 실행** |
| 워프 | 32개 스레드의 **SIMT 실행** |
| 공유 메모리 | 블록 내 **데이터 공유**와 타일링 지원 |

#### 한줄 요약
- CUDA는 호스트 제어 하에 그리드, 스레드 블록, 워프, 공유 메모리 계층을 하드웨어 SM과 매핑하여 동작한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **cudaMemcpyAsync**: 비동기 메모리 복사 함수로 호스트 CPU가 블로킹되지 않고 다음 명령어를 즉시 발행 가능.
- **스트림 동기화(Stream Synchronization)**: 비동기로 발행된 커널 연산 및 데이터 전송 작업이 모두 끝날 때까지 대기하는 제어 기법.

</details>

```text
[호스트 CPU 메모리 할당 및 데이터 준비]
         │
         ▼
1. 스트림·고정 메모리 준비
         │
         ▼
2. HtoD 복사·커널 디스패치
         │
         ▼
3. 연산·전송 중첩
         │
         ▼
4. DtoH 비동기 복사
         │
         ▼
5. 스트림 동기화
         │
         ▼
[호스트 메모리로 최종 결과 수합]
```

분기 결과: **다중 스트림 적용 시** 데이터 전송 지연시간과 커널 연산 시간이 완전 중첩(Overlap)되어 전체 실행 시간 대폭 단축

**동작 원리**

1. **스트림·고정 메모리 준비**: DMA 가능한 호스트 버퍼와 큐 구성
2. **HtoD 복사·커널 디스패치**: 데이터와 연산을 비동기 제출
3. **연산·전송 중첩**: 독립 스트림의 복사와 커널 실행 병렬화
4. **DtoH 비동기 복사**: 완료 결과를 호스트로 전송
5. **스트림 동기화**: 모든 비동기 작업 완료 확인

#### 한줄 요약
- 고정 메모리 확보와 스트림 동기화라는 관리 비용을 지불하는 대가로, 직렬로 드러나던 호스트-디바이스 전송 지연을 다른 스트림의 커널 실행 뒤로 숨긴다.

## Ⅴ. 종류 및 비교

| 병렬 프로그래밍 모델 | CUDA | SYCL·DPC++ | OpenCL |
|:---|:---|:---|:---|
| 적용 기준 | NVIDIA 성능·생태계 우선 | 이기종 단일 소스·휴대성 | 저수준 다중 벤더 지원 |
| 핵심 특징 | **C/C++ 확장·cuDNN** | **모던 C++·oneAPI** | **C API·런타임 컴파일** |
| 한계 | NVIDIA 종속 | 구현별 기능·성능 편차 | 복잡한 저수준 API |

#### 한줄 요약
- 범용 이종 플랫폼에는 SYCL/OpenCL이 쓰이나, 최첨단 AI 및 고성능 컴퓨팅(HPC) 영역에서는 CUDA가 독보적 표준이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **고정 메모리(Pinned/Page-Locked Memory)**: OS 페이징에 의해 스왑 아웃되지 않도록 물리 메모리에 상주시켜 DMA가 즉시 고속 접근할 수 있는 호스트 메모리.
- **커널 퓨전(Kernel Fusion)**: 연속된 여러 개의 소규모 커널을 하나의 커널로 결합하여 글로벌 메모리 읽기/쓰기를 온칩 레지스터/공유 메모리로 대체하는 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| PCIe 버스 대역폭 한계로 호스트 전송 병목 | **고정 메모리** 및 다중 스트림 비동기 파이프라이닝 | 데이터 전송 지연시간 **100% 은닉** |
| 소규모 커널 연속 호출에 따른 런칭 오버헤드 | **커널 퓨전(Kernel Fusion)** 및 CUDA Graphs 적용 | 드라이버 런칭 오버헤드 **대폭 절감** |
| 비연속 메모리 접근으로 인한 대역폭 낭비 | 공유 메모리 **타일링(Tiling)** 및 SoA 변환 | **메모리 병합** 달성 및 처리량 향상 |

#### 한줄 요약
- 실무에서는 고정 메모리와 다중 스트림으로 전송 지연을 은닉하고, 커널 퓨전과 공유 메모리 타일링으로 연산 효율을 극대화한다.

## Ⅶ. 결론

- NVIDIA 최적화가 우선이면 **CUDA**, 이기종 휴대성이 우선이면 SYCL 선택

#### 한줄 요약
- CUDA는 GPGPU 병렬 컴퓨팅의 글로벌 표준이며, 공유 메모리 타일링과 비동기 스트림 중첩을 통해 GPU 잠재력을 100% 실현한다.
