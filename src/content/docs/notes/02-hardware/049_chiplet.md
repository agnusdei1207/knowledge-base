## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **칩렛(Chiplet)**: 하나의 대규모 SoC를 기능 블록(연산, I/O, 메모리 등)별 개별 다이로 나누어 제작한 후 단일 패키지로 통합하는 기술.
- **이종 집적(Heterogeneous Integration)**: 서로 다른 반도체 공정(예: 3nm 연산 다이 + 14nm I/O 다이)으로 생산된 다이를 하나의 패키지로 조립하는 기술.

</details>

- 정의/개념: 대규모 SoC를 기능별 소형 다이(Die)로 분할 제조하여 **2.5D/3D 첨단 패키징**과 D2D 인터페이스로 결합하는 반도체 집적 기술
- 배경/필요성: 단일 모놀리식 다이의 면적 한계에 따른 **수율 저하 및 초미세 공정 비용 폭증** 직면

#### 한줄 요약
- 하나의 거대한 칩 대신 기능별로 작게 쪼개어 만든 칩 조각들을 첨단 패키징으로 이어 붙여 수율과 비용을 혁신한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **KGD(Known Good Die)**: 패키징 조립 전에 웨이퍼 레벨 테스트를 완벽히 통과하여 동작 신뢰성이 검증된 양품 다이.
- **D2D(Die-to-Die) 인터페이스**: 동일 패키지 내 다이 간에 초고밀도·초저지연 데이터 통신을 제공하는 표준 물리 계층 인터페이스(UCIe 등).

</details>

- 기능별 맞춤형 **이종 공정(Heterogeneous Process)** 적용으로 제조 원가 최적화
- 다이 크기 축소를 통한 **웨이퍼 수율(Yield)** 대폭 개선 및 결함 손실 최소화
- **KGD(Known Good Die) 선별**과 표준 **UCIe** 인터페이스로 모듈식 IP 재사용

#### 한줄 요약
- 연산은 초미세 선단 공정, I/O는 성숙 공정으로 따로 만들어 결합함으로써 칩 개발비와 결함 위험을 크게 낮춘다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **실리콘 인터포저(Silicon Interposer)**: 칩렛 다이들과 패키지 기판 사이에 고밀도 미세 범프 배선을 제공하는 중간 연결 기판.
- **재배선층(RDL, Redistribution Layer)**: 다이의 I/O 패드 위치를 패키징에 적합하도록 재배치하는 초미세 배선층.

</details>

```text
┌─────────────────────────────────────────────────────────────┐
│ 2.5D 칩렛 패키지 아키텍처 (UCIe D2D Interconnect)          │
│                                                             │
│  ┌──────────┐  UCIe D2D  ┌──────────┐  UCIe D2D  ┌──────────┐│
│  │ 연산 다이│◄──────────►│ I/O 다이 │◄──────────►│ HBM3 스택││
│  │ (3nm CPU)│   (100GB/s)│ (14nm I/O│   (TB/s)   │ (DRAM)   ││
│  └────┬─────┘            └────┬─────┘            └────┬─────┘│
│       │ (Micro Bumps)         │                       │      │
│  ┌────┴───────────────────────┴───────────────────────┴────┐│
│  │ 실리콘 인터포저 / RDL 초미세 배선층                      ││
│  └────────────────────────────┬────────────────────────────┘│
│                               │ (C4 Bumps)                   │
│  ┌────────────────────────────┴────────────────────────────┐│
│  │ 유기 패키지 기판 (Package Substrate) & 솔더볼 (BGA)       ││
│  └─────────────────────────────────────────────────────────┘│
└─────────────────────────────────────────────────────────────┘
```

선의 의미: 서로 다른 공정의 기능 칩렛들이 실리콘 인터포저와 마이크로 범프를 통해 단일 칩 수준의 초저지연 통신 수행

| 구성요소 | 책임 |
|:---|:---|
| 연산 칩렛 (Compute Die) | 최선단 미세 공정(3nm/2nm)을 적용해 CPU, GPU 등 고성능 핵심 연산 수행 |
| I/O 칩렛 (I/O Die) | 성숙 공정(12nm/14nm)으로 PCIe, 메모리 컨트롤러 등 인터페이스 전담 |
| HBM 칩렛 (Memory Die) | DRAM 다이를 수직 적층하여 초고대역폭 메모리 공간을 패키지 내 직접 공급 |
| 실리콘 인터포저 / RDL | 수 마이크로미터 피치의 초미세 배선으로 칩렛 간 고밀도 D2D 연결 제공 |
| D2D 인터페이스 (UCIe) | 칩렛 간 패킷 송수신, 무손실 흐름 제어 및 플릿(Flit) 계층 프로토콜 처리 |

#### 한줄 요약
- 연산 칩렛, I/O 칩렛, HBM, 실리콘 인터포저, UCIe D2D 버스가 단일 첨단 패키지로 통합되어 있다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **UCIe(Universal Chiplet Interconnect Express)**: 서로 다른 파운드리와 벤더의 칩렛을 호환 결합하기 위해 정의된 산업 표준 D2D 프로토콜.

</details>

```text
기능별 칩렛 웨이퍼 개별 제조 완료
      │
      ▼
1. KGD 선별: 프로빙 및 번인(Burn-in) 테스트로 100% 양품 다이 검증
      │
      ▼
2. 2.5D/3D 패키징: 인터포저 상에 마이크로 범프로 칩렛 정밀 실장
      │
      ▼
3. D2D 링크 훈련: UCIe 컨트롤러가 레인 정렬 및 신호 무결성 보정
      │
      ▼
4. 온패키지 패브릭: Flit 단위로 칩렛 간 초저지연 데이터 스트리밍
      │
      ▼
5. 최종 패키지 검사 후 단일 monolithic SoC처럼 동작 보장
```

**동작 원리**

1. **양품 선별**: 개별 웨이퍼에서 생산된 칩렛을 고속 테스트하여 KGD(Known Good Die)만 추출
2. **첨단 실장**: 실리콘 인터포저 또는 RDL 브리지 위에 마이크로 범프로 칩렛 다이들을 정밀 본딩
3. **링크 캘리브레이션**: 전원 인가 시 UCIe PHY 계층이 채널 스큐를 보정하고 최적 전송 속도 협상
4. **패브릭 통신**: CPU 칩렛과 I/O·메모리 칩렛이 Flit 패킷 기반으로 나노초 단위 데이터 교환
5. **투명한 실행**: 운영체제와 소프트웨어 입장에서는 단일 모놀리식 다이와 완전히 동일하게 인식

#### 한줄 요약
- KGD 선별 → 첨단 패키지 본딩 → UCIe 링크 정렬 → D2D Flit 통신 → 단일 칩 동작 순으로 진행된다.

## Ⅴ. 종류 및 비교

| 반도체 집적 구조 | 칩렛 (2.5D/3D) | 모놀리식 SoC | PCB 멀티칩 모듈(MCM) | 전통 개별 패키징 |
|:---|:---|:---|:---|:---|
| 적용 기준 | 초대형 고성능 AI/서버 프로세서 | 단일 공정 소형 모바일 SoC | 중저가 다중 칩 통합 모듈 | 범용 단일 목적 상용 반도체 |
| 핵심 특징 | 이종 공정 분리 및 실리콘 인터포저 결합 | 최단 배선 지연 및 단일 다이 집적 | 표준 기판 배선 기반 다이 실장 | 완성 칩을 PCB 기판에 개별 납땜 |
| 한계 | 고가의 첨단 패키징 공정 및 열 분산 난이도 | 다이 면적 증가 시 수율 급락 및 고비용 | 칩 간 배선 지연 및 낮은 대역폭 | 넓은 폼팩터 면적 및 긴 신호 지연 |

#### 한줄 요약
- 고성능 대형 칩은 칩렛, 소형 모바일은 모놀리식 SoC, 중저가 통합은 MCM, 범용 보드는 개별 패키징을 쓴다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **열 핫스팟(Thermal Hotspot)**: 고발열 연산 다이가 밀집되어 국소적으로 온도가 급상승하는 현상.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 불량 다이 혼입 시 **전체 패키지 폐기 손실(수율 저하)** | **KGD(Known Good Die)** 고정밀 선별 및 웨이퍼 번인 강화 | 조립 완성 수율 99% 이상 확보 |
| D2D 인터페이스의 **신호 무결성(Signal Integrity) 저하** | **UCIe 표준 PHY** 채택 및 패키지 내 차동 신호 라우팅 최적화 | 전송 비트 에러율(BER) 극소화 |
| 고밀도 다이 집적에 따른 **국소 열 핫스팟(Hotspot) 발생** | 방열 구조 최적화 및 TIM(Thermal Interface Material) 개선 | 열 저항 감소 및 안정적 클록 주파수 유지 |
| 이종 칩렛 간 **전원 공급망(PDN) 노이즈 및 전압 강하** | 온패키지 디커플링 커패시터(DCC) 및 독립 전력 도메인 분리 | 공급 전압 안정화 및 크로스토크 방지 |

#### 한줄 요약
- KGD로 조립 수율을 지키고, UCIe로 신호를 잡으며, TIM과 DCC로 발열과 전원을 다스린다.

## Ⅶ. 결론

- 대규모 초대형 고성능 프로세서 및 AI 반도체는 **칩렛(2.5D/3D)**, 소형 모바일은 **모놀리식 SoC** 선택

#### 한줄 요약
- 이종 공정 분리와 KGD 선별, 표준 UCIe D2D 인터페이스를 통해 무어의 법칙 한계를 넘는 반도체 집적 효율을 실현해야 한다.
