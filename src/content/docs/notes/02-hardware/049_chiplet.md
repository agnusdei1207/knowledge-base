## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **칩렛(Chiplet)**: 특정 기능을 맡는 작은 다이들을 하나의 패키지에서 연결하여 시스템을 구성하는 단위이다.
- **다이 간 연결(Die-to-Die, D2D)**: 같은 패키지의 칩렛 사이에서 데이터와 제어 및 클록 신호를 전달하는 인터페이스이다.
- **수율(Yield)**: 제조한 다이나 패키지 가운데 요구 기능과 품질 기준을 통과한 비율이다.

</details>

- 정의/개념: 기능별로 제작한 소형 다이를 패키지 내부 D2D 인터페이스로 연결하는 **다중 다이 시스템 구성 방식**이다.
- 배경/필요성: 대형 단일 다이는 결함을 포함할 확률과 전체 다이 폐기 비용이 커져 **수율·제조비 악화**가 발생한다.

#### 한줄 요약

- 칩렛은 기능을 소형 다이로 분할해 다이 수율과 설계 재사용성을 높이고, 기능마다 적합한 제조 공정을 적용한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **정상 다이(Known Good Die, KGD)**: 패키지 조립 전에 전기적 기능 검사를 통과하여 정상임을 확인한 다이다.
- **이종 집적(Heterogeneous Integration)**: 기능에 맞게 서로 다른 제조 공정으로 만든 다이를 하나의 패키지에 결합하는 방식이다.
- **패키지 조립 수율(Package Assembly Yield)**: 칩렛과 배선 및 기판을 조립한 전체 패키지 가운데 정상 동작하는 제품의 비율이다.
- **다이 간 연결 비용(Die-to-Die Interconnect Cost, D2D 연결 비용)**: 다이 간 데이터 전달에서 발생하는 지연과 전력 및 패키지 배선 비용이다.

</details>

- 수율•불량 폐기 비용을 개선하는 **소형 KGD 조합**이 핵심이다.
- 기능별 공정을 최적화하는 **이종 공정 혼용**이 핵심이다.
- 지연•전력 증가를 만드는 **D2D 연결** 및 수율 위험을 만드는 **패키지 조립**이 핵심이다.

#### 한줄 요약

- KGD 조합과 이종 공정은 수율·재사용 이득을 제공하지만 D2D 지연·전력과 패키지 조립 비용을 추가한다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **연산 칩렛(Compute Chiplet)**: 중앙 처리 장치(Central Processing Unit, CPU)나 그래픽 처리 장치(Graphics Processing Unit, GPU) 코어를 포함하여 범용 또는 병렬 연산을 수행하는 다이다.
- **입출력•캐시 칩렛(Input/Output•Cache Chiplet, I/O•캐시 칩렛)**: 메모리와 외부 장치 인터페이스 및 공유 캐시를 담당하는 다이다.
- **인터포저(Interposer)**: 여러 칩렛을 미세 배선으로 연결하고 패키지 기판에 결합하는 중간 기판이다.
- **전력망(Power Delivery Network)**: 패키지와 다이의 각 회로에 안정적인 전압과 전류를 공급하는 배선 구조이다.

</details>

```text
[연산 칩렛]       [I/O•캐시 칩렛]
       \             /
        [D2D 인터커넥트]
                 |
        [인터포저•패키지]
```

선의 의미: 두 기능 칩렛이 공용 D2D 인터커넥트에 접속하고 인터포저•패키지가 연결 배선과 전력•방열 기반을 제공하는 정적 패키지 구조다.

| 구성요소 | 책임 |
|:---|:---|
| 연산 칩렛 | CPU•GPU **연산 수행** |
| I/O•캐시 칩렛 | 메모리•I/O **제어•캐시** |
| D2D 인터커넥트 | 다이 간 **트랜잭션 전달** |
| 인터포저•패키지 | 배선•전력•**방열 제공** |

#### 한줄 요약

- 기능별 칩렛을 D2D와 패키지 배선으로 연결해 하나의 시스템처럼 동작시킨다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **칩렛 트랜잭션(Chiplet Transaction)**: 한 칩렛이 다른 칩렛의 기능이나 데이터에 접근하기 위해 보내는 요청과 응답이다.
- **순환 중복 검사(Cyclic Redundancy Check, CRC)**: 송수신 데이터에서 계산한 검사값을 비교하여 전송 비트 오류를 검출하는 기법이다.
- **재전송(Retransmission)**: 오류가 검출된 패킷을 송신 측이 다시 보내어 링크 신뢰성을 확보하는 절차이다.
- **입출력(Input/Output, I/O)**: 메모리와 외부 장치 사이에서 데이터와 제어 신호를 전달하는 기능이다.

</details>

```text
 [연산 칩렛 원격 요청]
          |
 1. 트랜잭션 패킷•CRC 생성
          |
 2. D2D 링크 전송
          |
 3. CRC•순서 검증
    ├─ 실패
    │  └─ 4. 재전송 요청
    │     └─ [1~3단계 재수행]
    └─ 성공
       └─ 5. 대상 처리·응답 전송
          └─ [트랜잭션 완료]
```

**동작 원리**

1. **요청 패킷·CRC 생성**: 원격 주소·명령·데이터를 D2D 패킷으로 만들고 링크가 지원하면 오류 검출값을 추가한다.
2. **D2D 링크 전송**: 송신 엔드포인트가 인터포저·패키지 배선을 통해 대상 칩렛으로 패킷을 전달한다.
3. **오류·순서 검증**: 수신 엔드포인트가 CRC와 패킷 순서를 확인해 요청의 처리 가능 여부를 판정한다.
4. **오류 패킷 재전송**: 재전송을 지원하는 링크에서 실패한 패킷을 요청해 1~3단계를 반복한다.
5. **대상 처리·응답 전송**: 검증된 요청을 대상 칩렛에서 실행하고 결과 패킷을 역방향 경로로 반환한다.

#### 한줄 요약

- D2D 엔드포인트는 칩렛 요청을 패킷으로 전달하고, 오류 검출·재전송을 지원하는 링크는 CRC 실패 패킷을 다시 보낸다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **단일 시스템온칩(Single System on Chip, Single SoC)**: 프로세서와 메모리 제어 및 입출력 기능을 하나의 다이에 통합한 칩이다.
- **온다이 지연(On-die Latency)**: 동일한 다이 내부의 회로 사이에서 신호가 이동하고 응답하는 데 걸리는 시간이다.
- **레티클 한계(Reticle Limit)**: 한 번의 노광으로 웨이퍼에 전사할 수 있는 최대 다이 면적이다.

</details>

| 반도체 통합 방식 | 칩렛 | 단일 SoC |
|:---|:---|:---|
| 적용 기준 | 이종 공정•**재사용•수율** | 온다이 지연•**단일 설계** |
| 핵심 특징 | 검증 다이의 **패키지 연결** | 기능의 **단일 다이 통합** |
| 한계 | D2D 지연•**패키지 수율** | 대형 다이 **수율•재설계** |

> 요약: 칩렛은 수율•재사용 대신 연결 비용이 증가한다.

#### 한줄 요약

- 이종 공정·설계 재사용·대형 다이 수율 개선이 중요하면 칩렛을, 가장 짧은 온다이 지연과 단일 설계가 중요하면 단일 SoC를 선택한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **번인 시험(Burn-in Test)**: 고온이나 높은 전압에서 일정 시간 동작시켜 초기 잠복 결함을 조기에 드러내는 시험한다.
- **링크 오류율(Link Error Rate)**: 전체 다이 간 연결(Die-to-Die, D2D) 전송 가운데 오류가 검출된 데이터나 패킷의 비율이다.
- **열 배치(Thermal Placement)**: 발열이 큰 칩렛의 위치와 냉각 경로를 조정하여 온도 집중을 줄이는 설계한다.
- **D2D 프로파일(D2D Profile)**: 링크 속도와 레인 및 지원 기능처럼 상호 연결에 필요한 공통 설정 집합이다.
- **정상 다이(Known Good Die, KGD)**: 패키지 조립 전 기능 검사를 통과한 다이다.
- **중앙 처리 장치(Central Processing Unit, CPU)•입출력(Input/Output, I/O) 다이**: 연산 코어와 외부 연결•공유 캐시 기능을 담당하는 칩렛이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 다이 단독 KGD 시험이 조립 조건의 **접합·열 잠복 결함 누락** | 다이 단독 검사, 조립 후 검사와 **번인 시험** 결합 | 패키지 출하 전 **잠복 불량 검출률 향상** |
| D2D 전송 오류·직렬화 지연이 **온다이 분할 이점 상쇄** | 링크 오류율·대역폭·왕복 지연 검증과 지원 링크의 **재전송 적용** | 오류 복구와 성능 한도 확인으로 **연결 신뢰성 확보** |
| 조립 불량과 칩렛 발열 집중으로 **패키지 수율·지속 성능 저하** | 패키지 공정 수율 추적과 **열 배치·전력망 공동 설계** | 결함·열 집중 완화로 **제조비 절감·성능 유지** |
| 공급사·세대별 D2D 설정 차이로 **인터페이스 호환 실패** | 표준 **D2D 프로파일·버전 협상**과 공급망 조합 검증 | 검증 칩렛의 **재사용·교체 가능성 향상** |

> 코어 칩렛 수 조절•I/O 다이 재사용으로 **제품군•수율** 관리

#### 한줄 요약

- 서버 CPU는 검증한 코어 칩렛 수를 제품별로 조절하고 공통 I/O 다이를 재사용한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **재사용 이득(Reuse Benefit)**: 검증한 칩렛을 여러 제품에서 반복 사용하여 설계 기간과 비용을 줄이는 효과이다.
- **폐기 비용(Scrap Cost)**: 제조 결함 때문에 다이나 조립된 패키지를 사용할 수 없어 발생하는 손실이다.
- **패키지 비용(Packaging Cost)**: 칩렛 조립과 미세 배선, 전력 공급 및 냉각 구조를 구현하는 데 드는 비용이다.

</details>

- D2D•패키지 비용보다 큰 **수율•재사용 이득** 확보 시 **칩렛 선택**이 핵심이다.

#### 한줄 요약

- 다이 수율·설계 재사용·이종 공정 이득이 D2D 지연·전력과 패키지 비용보다 클 때 칩렛 구성을 선택한다.
