## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **칩렛(Chiplet)**: 칩을 피자 한 판처럼 통째로 구워내다 실패해서 버리는 짓을 멈추고, 조각 피자처럼 작은 반도체 다이들을 따로따로 만들어 하나의 기판 위에 레고 블록처럼 이어 붙인 초고밀도 패키징 칩이다.
- **다이 대 다이(Die-to-Die)**: 한 지붕(패키지) 아래 모인 조각 칩(다이)들이 찰나의 버벅거림도 없이 서로 데이터를 미친 듯이 핑퐁 하며 주고받을 수 있게 만든 초고속 미세 구리선 인터페이스이다.
- **수율(Yield)**: 웨이퍼 한 장에서 쓰레기(불량)를 빼고 정상 작동하는 칩을 몇 개나 건졌는지 보여주는 비율로, 칩 크기가 커질수록 쓰레기가 될 확률이 기하급수적으로 폭증하는 반도체 회사의 목숨줄이다.

</details>

- 정의: 기능 단위로 조각조각 분할 제조된 소형 다이들을 하나의 패키지 내에서 초고밀도 **다이 대 다이** 인터페이스로 꽉 묶어 결합하는 **칩렛** 패키징 기술
- 배경: 첨단 미세공정으로 칩 면적을 대형화하려다, 웨이퍼 면적 당 결함(먼지 한 톨) 비율이 폭증하여 칩을 통째로 내다 버려야 하는 치명적인 **수율** 급락 및 파산 문제를 해소하기 위함

#### 한줄 요약

- 커다란 칩 하나를 통째로 굽다가 망치지 말고, 잘게 쪼개서 멀쩡한 조각들만 모아 조립함으로써 수율을 올리고 원가를 후려치는 반도체 업계의 생존 전략이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **양품 다이(Known Good Die)**: 다른 조각 칩들과 합체(패키징)하기 전에, 바늘구멍 같은 테스트를 통과하여 "나는 절대 불량이 아니다"라고 도장을 쾅 찍은, 100% 정상 작동이 보장된 엘리트 조각 칩이다.
- **이종 집적(Heterogeneous Integration)**: 대가리(CPU 연산)는 비싼 최신 3나노 공정으로 찍고, 엉덩이(I/O 입출력)는 싼 14나노 공정으로 따로 찍은 뒤, 이종교배하듯 하나로 합쳐 가성비를 극대화하는 마법이다.
- **패키지 조립 수율(Package Assembly Yield)**: 엘리트 조각 칩들을 모아놨어도 조립하다가 핀 하나 엇나가면 전체 칩이 쓰레기통행이 되기 때문에, 결합 공정이 끝난 후 최종적으로 합격판정을 받는 피 말리는 확률이다.
- **다이 대 다이 연결 오버헤드(D2D Interconnect Overhead)**: 조각을 나눠놨으니 통신하려면 좁은 톨게이트를 지나야 하고, 이때 발생하는 눈곱만 한 데이터 전송 지연과 전기세 낭비라는 피할 수 없는 부작용이다.

</details>

- 철저하게 사전 검증된 모듈 칩렛들만의 물리적 결합을 통해, **양품 다이** 기반의 칩 조립 쓰레기화를 막고 최종 패키지 수율을 극대화함.
- 중요한 핵심 연산 로직과 덜 중요한 입출력 및 메모리를 각기 급이 다른 최적 공정으로 제작하여 결합하는 극강의 가성비 **이종 집적**을 지원함.
- 통짜(단일) 온칩 구조 대비 **다이 대 다이 연결 오버헤드** 발생이라는 부작용을 안고 가야 하며, 조립 과정의 끔찍한 실수를 막기 위한 엄격한 **패키지 조립 수율** 제어가 요구됨.

#### 한줄 요약

- 불량 없는 조각만 모으고(KGD), 싼 공정과 비싼 공정을 섞어 쓰며(이종 집적) 수율의 한계를 돌파하지만, 조각을 이어 붙이느라 생기는 통신 딜레이(오버헤드)는 감수해야 한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **연산 칩렛(Compute Chiplet)**: 반도체 회사의 영혼을 갈아 넣은 3나노, 2나노 최첨단 공정으로 찍어내어 수치 계산을 미친 듯이 쳐내는 CPU나 GPU의 핵심 두뇌 다이이다.
- **입출력 칩렛(I/O Chiplet)**: 메모리와 통신하는 단순 노가다를 굳이 비싼 공정으로 뺄 필요가 없어, 옛날 사골 공정(14나노 등)으로 저렴하게 찍어낸 뒤 연산 칩렛 옆에 붙여주는 수족 다이이다.
- **인터포저(Interposer)**: 조각 칩들을 맨바닥에 붙일 순 없으니, 칩과 칩 사이를 머리카락보다 얇은 미세 구리선으로 연결해 주는 고가의 실리콘 깔개(기판)이다.
- **전력 전달 망(Power Delivery Network)**: 조각 칩들마다 밥 먹는 양(전압/전류)이 다르니, 옆집에 노이즈를 주지 않고 정확한 전기를 깔끔하게 꽂아주는 배전반 구조이다.

</details>

```text
[ 칩렛 기반 이종 집적 2.5D / 3D 패키징 하드웨어 결합 아키텍처 ]
     [ 연산 칩렛 (3나노 최신 공정) ]      [ 입출력 칩렛 (14나노 사골 공정) ]
                  │                                  │
                  ▼                                  ▼
      [ 마이크로 범프 (칩과 기판을 잇는 초미세 납땜 볼) ]
                  │                                  │
+-----------------▼----------------------------------▼------------------+
| 실리콘 인터포저 (칩 간 고속도로 기판)                                 |
|                                                                       |
|      [ 다이 대 다이(D2D) 인터커넥트 초고속 미세 구리선 통신망 ]       |
+-----------------------------------------------------------------------+
```

| 구성요소 | 책임 |
|:---|:---|
| **연산 칩렛** | 피 말리는 최첨단 공정으로 빚어낸 중앙 처리 장치(CPU) 및 그래픽(GPU) 고속 텐서 산술 연산 로직 전담 수행 |
| **입출력 칩렛** 및 캐시 다이 | 구형 레거시 공정 기반으로 싸게 찍어낸 메모리 컨트롤러, 거대 공유 캐시 및 시스템 바깥과의 입출력 제어 |
| **다이 대 다이** 인터커넥트 | 떨어져 있는 분할된 칩렛 상호 간의 통신 병목을 찢어버리는 초저지연 및 초고대역폭 물리적 신호 인라인 핑퐁 전송 |
| **인터포저** 패키지 및 **전력 전달 망** | 초미세 재배선층(RDL) 기반의 물리 조립을 버티고, 칩렛마다 독립적 **전력 전달 망** 인가 및 타오르는 열 방출 경로 제공 |

#### 한줄 요약

- 비싼 두뇌(연산)와 싼 수족(I/O)을 따로 찍은 뒤, 실리콘 깔개(인터포저) 위에 올려놓고 미세 구리선(D2D)으로 꿰매어 한 몸으로 동작하게 만드는 프랑켄슈타인 구조이다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **칩렛 트랜잭션(Chiplet Transaction)**: 연산 칩렛이 계산을 하다 멍청한 입출력 칩렛에게 "메모리에서 데이터 좀 가져와"라고 좁은 다리(D2D)를 건너 쏘아대는 명령 패킷이다.
- **순환 중복 검사(Cyclic Redundancy Check)**: 좁은 다리를 건너가는 텐서 데이터가 전압 노이즈 때문에 비트가 찌그러지진 않았는지 확인하는 가차 없는 바코드 검사이다.
- **재전송(Retransmission)**: 바코드 검사(CRC)에서 에러가 터지면 수신 칩이 "데이터 썩었어! 다시 보내!"라고 멱살을 잡고 즉시 재요청하여 핑퐁 복구하는 에러 차단 프로토콜이다.

</details>

```text
[ 칩렛 간 다이 대 다이(D2D) 인터페이스 패킷 전송 및 눈물겨운 오류 복구 흐름 ]
                               │
                               ▼
 [ 1. 연산 칩렛의 트랜잭션 요청 패킷 생성 및 무결성 바코드(CRC) 인코딩 각인 ]
                               │
                               ▼
     [ 2. 인터포저 기판의 다이 대 다이(D2D) 미세 물리 링크를 통한 패킷 발사 ]
                               │
                               ▼
      [ 3. 수신 칩렛(I/O)의 패킷 순서 정렬 및 바코드(CRC) 데이터 무결성 검증 ]
                               │
            +---------------------------------------+
            |        [ 검증 실패 에러 감지? ]       |
            |        /                      \       |
            |    [ 예 ]                  [ 아니요 ] |
            |      │                         │      |
            | 4. 쓰레기 패킷 버림       5. 무결한 대상  |
            | 및 즉시 재전송 요구       요청 로직 처리  |
            |  (1~3 핑퐁 재수행)        (결과물 반환)   |
            +---------------------------------------+
```

### 동작 원리

1. 트랜잭션 요청 및 검사 인코딩: **연산 칩렛**에서 메모리를 털어오라는 **칩렛 트랜잭션** 수송을 위해 패킷을 포장하고 겉면에 **순환 중복 검사**(CRC) 인코딩 바코드를 쾅 찍음.
2. 다이 대 다이 물리 링크 전송: 인터포저 깔개에 파놓은 미세 배선(Micro-bump)을 통해 칩 간 물리적 전기 통신 신호를 상대 칩렛으로 이송 발사함.
3. 수신 무결성 및 순서 검증: 수신 측 다이가 쏟아지는 패킷 순서를 맞추고 **순환 중복 검사** 데이터 무결성을 엄격하게 뜯어보며 불량품을 색출함.
4. 에러 감지 패킷 복구: 노이즈 에러 감지 시 얄짤없이 썩은 데이터를 버리고 **재전송** 프로토콜을 즉각 수행하여 칩 내부 데이터 오염을 완벽 차단함.
5. 대상 요청 로직 처리: 바코드 검사를 무사히 통과한 수신 칩렛 내부 로직이 요청 명령과 데이터를 최종 처리해 결과를 건너편으로 반환함.

#### 한줄 요약

- 칩 조각들끼리 신호를 쏠 때 바코드(CRC)를 찍어 보내고, 받아서 에러가 있으면 무조건 다시 쏘라고(재전송) 멱살을 잡아 칩 내부 통신의 신뢰성을 100% 지켜낸다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **단일 시스템 온 칩(Single System on Chip)**: 연산, I/O, 메모리를 쪼개지 않고 무식하게 커다란 실리콘 도화지(웨이퍼) 한 장에 통째로 쑤셔 그려 넣는 전통적이고 무식한 칩 제조 방식이다.
- **온다이 지연(On-Die Latency)**: 칩을 쪼개지 않았기 때문에 톨게이트를 거칠 필요가 없어, 칩 내부 배선만 타고 빛의 속도로 전송되는 넘사벽 초저지연 시간이다.
- **레티클 한계(Reticle Limit)**: 반도체 장비(노광기)가 웨이퍼에 한 번에 레이저로 찍어낼 수 있는 물리적인 최대 칩 크기 면적 제한으로, 이 크기를 넘어가면 칩을 만들 수 없다.

</details>

| 비교 항목 | **칩렛** 패키징 (Chiplet) | **단일 시스템 온 칩** (Monolithic SoC) |
|:---|:---|:---|
| 시스템 적용 최적 기준 | 코어 개수를 무식하게 늘리고 싶고 싼 공정과 비싼 공정을 섞는 **이종 집적**으로 반도체 수율의 극한 개선이 절실히 필요할 시 | 칩 면적이 작아서 한 판에 그릴 수 있고, 통신 핑퐁 딜레이를 단 0.1초도 용납 못 하는 최고의 칩 내부 통신 성능 요구 시 |
| 아키텍처 핵심 구현 특징 | 블록놀이 하듯 기능별로 쪼갠 다이를 초미세 인터커넥트 깔개로 꿰매어 수평/수직(2.5D/3D)으로 포개버리는 프랑켄슈타인 통합 구조 | 모든 시스템 블록과 배선을 한 판의 실리콘 다이 위에 몽땅 그려 넣고 한 번에 구워내는 전통적이고 깔끔한 일체형 구성 |
| 극복해야 할 태생적 한계점 | 다이 간 톨게이트(인터페이스) 지연 오버헤드 감수 및 조립하다 핀 엇나가면 다 죽는 치명적 불량 방지용 **패키지 조립 수율** 제어 피말림 | 노광 장비 면적인 **레티클 한계** 절대 초과 불가 및, 칩 덩치가 커질수록 쓰레기 불량품이 속출하는 기하급수적인 **수율** 폭락의 파산 위험 |

#### 한줄 요약

- 수율을 잡고 비싼 공정비를 아끼려면 조각내서 이어 붙이는 칩렛으로 가야 하고, 지연시간 0초의 완벽한 일체형을 원하면 단일 SoC로 구워내야 한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **번인 시험(Burn-In Test)**: 멀쩡해 보이는 조각 칩들을 용광로(고온/고전압)에 집어넣고 지져버려서, 패키징 조립 전에 약해 빠진 불량 칩들을 솎아내어 쓰레기통에 처박는 잔인한 고문 공정이다.
- **링크 오류율(Link Error Rate)**: 인터포저 구리선을 타고 넘어가는 전기 신호가 노이즈를 먹고 비트가 뒤집어지는 확률로, 이 확률이 높으면 재전송 핑퐁 때문에 칩 전체가 굼벵이가 된다.
- **열 분산 배치(Thermal Placement)**: 불타오르는 고성능 연산 칩 두 개를 바짝 붙여놨다가 칩이 녹아내리지 않도록, 의도적으로 간격을 띄우고(열 분산) 수직으로 열을 빼내는 방열 설계 꼼수이다.
- **다이 대 다이 프로파일(D2D Profile)**: 삼성 칩과 인텔 칩을 한 기판에 붙였을 때 서로 말이 안 통해 뻗어버리지 않도록, 전 세계가 억지로 맞춘 칩렛 간 통신 표준 규약(UCIe)이다.

</details>

#### 한줄 요약

- 조립 전 불량 칩을 고문해서(번인) 걸러내고, 에러 나면 재전송하며, 불타지 않게 거리를 띄우고(열 분산), 통신 표준(UCIe)을 맞춰야 프랑켄슈타인 칩이 살아 움직인다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **재사용 이득(Reuse Benefit)**: 14나노 입출력(I/O) 칩 조각 하나를 잘 파놓은 뒤, 서버 칩 만들 때도 붙여 먹고 데스크톱 칩 만들 때도 우려먹어 개발비를 0원으로 수렴시키는 궁극의 단가 후려치기 꼼수이다.
- **칩렛 선택 기준(Chiplet Adoption Criteria)**: 웨이퍼 하나에서 통짜 칩을 구울 때 버리는 돈(수율)과 칩 조각을 이어 붙일 때 드는 핀셋 조립 비용(패키징)을 피도 눈물도 없이 계산하여 칩의 제조 방식을 결정하는 잣대이다.

</details>

- **칩렛 선택 기준**에 따라 조각조각 내서 버는 **수율** 개선 돈과 칩 조각 **재사용 이득**이 다이 대 다이(D2D) 조립 인건비를 확실히 씹어 먹을 시 지체 없이 **칩렛** 구조 선택을 단호히 결정함

#### 한줄 요약

- 통짜 칩을 굽다 불량이 나서 수백억 원을 날릴 바엔, 조립비(패키징 비용)를 더 내고 통신이 조금 느려지더라도 수율과 원가를 잡을 수 있는 칩렛으로 갈아타는 것이 현대 반도체의 생존법칙이다.
