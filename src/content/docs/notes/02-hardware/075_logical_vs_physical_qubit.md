## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **물리 큐비트(Physical Qubit)**: 실제 소자로 구현하여 제어하고 측정할 수 있는 잡음이 있는 양자 상태이다.
- **논리 큐비트(Logical Qubit)**: 여러 물리 큐비트에 정보를 부호화하고 오류 정정으로 보호한 계산 단위이다.
- **양자 오류 정정(Quantum Error Correction, QEC)**: 물리 오류를 검출하고 보정하여 논리 양자 정보를 보호하는 기술이다.

</details>

- 정의/개념: 여러 **물리 큐비트**에 정보를 부호화하고 반복적인 **양자 오류 정정**으로 보호한 **논리 큐비트**이다.
- 배경/필요성: 잡음이 있는 물리 큐비트를 직접 실행하면 긴 회로에서 오류가 누적되므로 계산 규모에 맞는 논리 오류 억제가 필요하다.

#### 한줄 요약

- 다수 물리 큐비트와 오류 정정으로 구성한 **논리 큐비트**가 핵심이다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **안정자 측정(Stabilizer Measurement)**: 논리 정보를 직접 읽지 않고 물리 큐비트 사이의 패리티 관계를 측정하는 방식이다.
- **복호(Decoding)**: 증후군 이력에서 가능한 물리 오류 경로를 추정하여 논리 보정 상태를 결정하는 처리이다.
- **코드 거리(Code Distance)**: 검출되지 않은 채 논리 상태를 바꿀 수 있는 최소 물리 오류 경로의 길이다.
- **파울리 프레임(Pauli Frame)**: 추정한 논리 보정 상태를 즉시 물리 게이트로 적용하지 않고 고전 정보로 기록하는 방식이다.

</details>

- **안정자 측정**은 논리 정보를 직접 읽지 않고 물리 오류의 증후군을 검출한다.
- **복호·파울리 프레임**은 추정한 오류를 후속 연산 해석에 반영하여 논리 오류의 전파를 억제한다.
- **코드 거리**는 필요한 물리 자원과 달성 가능한 논리 오류율을 결정한다.

#### 한줄 요약

- **코드 거리**가 증가하면 논리 오류율은 감소하고 자원은 증가한다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **데이터 큐비트(Data Qubit)**: 논리 정보를 여러 소자에 분산 저장하는 물리 큐비트이다.
- **보조 큐비트(Ancilla Qubit)**: 안정자 패리티를 측정해 오류 증후군을 생성하는 물리 큐비트이다.
- **복호기(Decoder)**: 증후군 이력에서 물리 오류 경로와 논리 보정 상태를 추정하는 구성이다.
- **논리 큐비트(Logical Qubit)**: 데이터•보조 큐비트와 복호 규칙으로 보호한 계산 단위이다.
- **논리 회로(Logical Circuit)**: 오류 확산을 제한하는 내결함 논리 게이트들로 구성한 양자 회로이다.

</details>

```text
                     [논리 회로]
                          |
                     [논리 큐비트]
                     /     |     \
        [데이터 큐비트] [보조 큐비트] [복호기]
```

선의 의미: 세로선은 논리 회로가 논리 큐비트를 계산 단위로 포함하는 관계이고, 아래 가지는 논리 큐비트가 데이터•보조 큐비트와 복호기에 의존하는 보호 구조를 뜻한다.

| 구성요소 | 책임 |
|:---|:---|
| 데이터 큐비트 | 논리 정보 분산 저장 |
| 보조 큐비트 | 오류 증후군 추출 |
| 복호기 | 오류 위치 추정 |
| 논리 큐비트 | 보호 계산 단위 제공 |
| 논리 회로 | 내결함 게이트 실행 |

#### 한줄 요약

- **데이터 큐비트·보조 큐비트·복호기**로 **논리 큐비트**를 구성해 **논리 회로**를 실행한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **실패 예산(Failure Budget)**: 전체 계산에 허용하는 실패 확률을 논리 큐비트와 연산별로 배분한 한도이다.
- **코드 패치(Code Patch)**: 하나의 논리 큐비트를 구성하는 표면 코드 격자의 물리 영역이다.
- **내결함 일정(Fault-tolerant Schedule)**: 단일 물리 오류가 논리 오류로 확산되지 않도록 게이트와 측정 순서를 정한 계획이다.
- **실패 예산·코드 거리 산정**: 목표 성공 확률을 논리 연산별 실패 한도로 나누고 코드 거리를 정하는 단계이다.
- **내결함 논리 일정 생성**: 논리 연산을 오류 확산을 제한하는 물리 게이트와 측정 순서로 바꾸는 단계이다.
- **물리 게이트·안정자 측정**: 코드 패치를 조작하면서 오류 증후군을 추출하는 단계이다.
- **증후군 복호·프레임 갱신**: 오류 경로를 추정해 파울리 프레임에 반영하는 단계이다.

</details>

```text
[알고리즘•목표 성공 확률]
            │
            ▼
1. 실패 예산•코드 거리 산정
            │
            ▼
2. 내결함 논리 일정 생성
            │
            ▼
┌──────── 논리 연산 반복 ────────┐
│ 3. 물리 게이트•안정자 측정     │
│            │                    │
│            ▼                    │
│ 4. 증후군 복호•프레임 갱신     │
└────────────┬───────────────────┘
             ▼
      [논리 연산 결과]
```

### 동작 원리

1. **실패 예산•코드 거리 산정**: 알고리즘의 목표 성공 확률을 논리 연산별 실패 예산으로 나누고 필요한 코드 거리를 정한다.
2. **내결함 논리 일정 생성**: 각 논리 연산의 **내결함 일정**을 오류 확산을 제한하는 물리 게이트와 측정 순서로 변환한다.
3. **물리 게이트•안정자 측정**: 코드 패치를 조작하면서 안정자를 반복 측정하여 오류 증후군을 추출한다.
4. **증후군 복호•프레임 갱신**: 추정한 오류 경로를 파울리 프레임에 기록하여 후속 논리 연산에 반영한다.

#### 한줄 요약

- **논리 회로**는 내결함 물리 게이트와 안정자 측정 및 고전 복호 일정으로 변환되어 실행된다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **물리 오류율(Physical Error Rate)**: 실제 게이트와 측정 및 유휴 상태가 실패하는 비율이다.
- **논리 오류율(Logical Error Rate)**: 오류 정정 후에도 하나의 논리 연산이나 주기가 실패하는 비율이다.
- **결맞음 손실(Decoherence)**: 환경과의 상호작용으로 물리 큐비트의 위상과 양자 상태가 훼손되는 현상이다.

</details>

| 큐비트 계층 | 역할 | 성능 판단 기준 |
|:---|:---|:---|
| **물리 큐비트** | 직접 제어•측정하는 실제 소자 | 게이트•판독 **물리 오류율** |
| **논리 큐비트** | 여러 물리 큐비트를 묶은 오류 정정 계산 단위 | 오류 정정 후 **논리 오류율** |

물리 큐비트는 잡음과 **결맞음 손실**의 영향을 직접 받으며, 논리 큐비트는 오류 정정으로 이를 억제하는 대신 다수의 물리 자원을 사용한다.

#### 한줄 요약

- 장치의 **물리 큐비트** 수와 오류 정정 후 실제 계산에 사용할 수 있는 **논리 큐비트** 수를 구분해야 한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **오류 임계값(Error Threshold)**: 물리 오류율이 이 값 아래일 때 코드 거리를 늘리면 논리 오류율이 감소하는 경계이다.
- **오류 지도(Error Map)**: 큐비트와 연결별 오류율을 물리 위치에 대응하여 기록한 자료이다.
- **시공간 부담(Space-time Overhead)**: 논리 연산이 점유하는 물리 큐비트 수와 실행 시간의 결합 비용이다.
- **마법 상태 증류(Magic-state Distillation)**: 여러 잡음 특수 상태를 소비하여 정확한 비클리퍼드 게이트용 상태를 만드는 절차이다.
- **격자 수술(Lattice Surgery)**: 표면 코드 패치를 병합·분할하여 논리 연산을 수행하는 방식이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 물리 오류율이 **오류 임계값** 이상이면 거리 증가 효과 상실 | 큐비트 보정•소자 선별 | 임계값 이하 오류율 확보 |
| 큐비트•연결별 편차를 평균 오류율이 은폐 | 연결별 **오류 지도** 관리 | 취약 경로 병목 식별 |
| 회로 깊이와 허용 실패율 누락으로 거리 과소 산정 | 회로 깊이•실패 예산 반영 | 목표 성공 확률 확보 |
| 논리 게이트의 **시공간 부담** 누락으로 자원 과소 산정 | 게이트 시간•패치 면적 반영 | 현실적 자원 계획 수립 |
| 비클리퍼드 게이트의 상태 정제 비용 누락 | **마법 상태 증류** 자원 포함 | 범용 계산 자원 현실화 |
| 패치 간 연산의 병합•분할 시간과 공간 누락 | **격자 수술** 일정•공간 반영 | 논리 연산 비용 산정 |

#### 한줄 요약

- 논리 작업량을 코드 패치, 물리 큐비트, 복호기와 실행 시간을 포함한 시공간 부담으로 환산해야 한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **목표 논리 오류율(Target Logical Error Rate)**: 알고리즘의 전체 성공 확률을 만족하도록 각 논리 연산에 요구하는 최대 실패율이다.
- **물리 자원 산정(Physical Resource Estimation)**: 코드 거리와 회로 사양을 물리 큐비트 수 및 제어•복호 자원으로 환산하는 작업이다.
- **유효 계산량(Useful Computation)**: 오류 정정 비용을 제외하고 실제 알고리즘에 제공할 수 있는 논리 연산 규모이다.
- **논리 큐비트 자원 평가 기준**: 목표 논리 오류율을 만족하는 물리 자원과 유효 계산량을 함께 평가하는 기준이다.

</details>

- **논리 큐비트 자원 평가 기준**에 따라 **목표 논리 오류율**을 만족하는 코드 거리를 정하고 **물리 자원 산정** 뒤 **유효 계산량**을 평가한다.

#### 한줄 요약

- 장치는 총 물리 큐비트 수보다 오류 정정 후 유효 계산량을 우선 평가해야 한다.
