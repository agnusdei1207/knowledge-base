## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **물리 큐비트(Physical Qubit)**: 초전도 회로, 이온 트랩 등 실제 하드웨어 칩 상에 결합된 노이즈 수용 전자기적 큐비트 단원.
- **논리 큐비트(Logical Qubit)**: 여러 물리 큐비트에 논리 정보를 부호화해 오류율을 억제하는 계산 단위.
- **QEC(Quantum Error Correction)**: 물리 큐비트 상의 비트/위상 반전 에러를 보조 큐비트 안정자 측정을 통해 실시간 감지/정정하는 부호화 기술.

</details>

- 정의/개념: 잡음이 있는 **물리 큐비트**에 **QEC**를 부호화해 논리 오류율을 낮추는 **논리 큐비트**
- 배경/필요성: 물리 오류가 누적되면 **깊은 양자 회로의 성공 확률 급감**

#### 한줄 요약

- 다수 물리 큐비트와 오류 정정으로 구성한 **논리 큐비트**가 핵심이다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **코드 거리(Code Distance, d)**: 논리 연산자를 형성하는 최소 물리 오류 사슬의 길이.
- **파울리 프레임(Pauli Frame)**: 물리 펄스 대신 소프트웨어 계층 상에서 파울리($X, Y, Z$) 에러 트래킹을 수용하는 런타임 프레임워크.

</details>

- 임계값 아래에서 코드 거리 증가에 따른 논리 오류율 감소
- **코드 거리** 증가에 따른 표면 코드 패치 면적과 측정 자원 증가
- 고전 복호기와 결합해 오류 추정을 추적하는 **파울리 프레임** 구조

#### 한줄 요약

- **코드 거리**가 증가하면 논리 오류율은 감소하고 자원은 증가한다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **데이터 큐비트(Data Qubit)**: 실제 양자 연산 파동함수 정보 코드를 수용하는 물리 큐비트.
- **앤실라 큐비트(Ancilla Qubit)**: 주변 데이터 큐비트의 패리티(X/Z) 오류를 측정(Stabilizer)하는 보조 큐비트.
- **고전 복호기(Classical Decoder)**: 시공간 3D 에러 증후군 데이터로부터 물리 에러 경로를 추정하는 실시간 알고리즘 엔진 (MWPM 등).

</details>

```text
                     [논리 회로]
                          |
                     [논리 큐비트]
                     /     |     \
        [데이터 큐비트] [보조 큐비트] [복호기]
```

선의 의미: 논리 회로가 논리 큐비트를 대상으로 수행되며, 논리 큐비트는 데이터 큐비트, 앤실라(보조) 큐비트 및 고전 복호기에 의해 유지되는 구조.

| 구성요소 | 책임 |
|:---|:---|
| 데이터 큐비트 | 표면 코드 격자 상에서 실제 양자 파동함수 텐서 수용 |
| 보조(앤실라) 큐비트 | 데이터 큐비트와 결합 후 X/Z 패리티 **안정자 측정** 수행 |
| 고전 복호기 | 실시간 3D 에러 증후군 그래프에서 **MWPM** 최적 복호 에지 추출 |
| 논리 큐비트 | QEC 부호화로 목표 논리 오류율을 지향하는 계산 단위 |

#### 한줄 요약

- **데이터 큐비트·보조 큐비트·복호기**로 **논리 큐비트**를 구성해 **논리 회로**를 실행한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **내결함 일정(Fault-Tolerant Schedule)**: 오류 발생 시에도 전역 논리 에러로 확산되지 않도록 큐비트를 제어하는 QEC 스케줄링.
- **실패 예산(Failure Budget)**: 타깃 알고리즘 성공률(예: 99%)을 달성하기 위해 허용되는 연산당 최대 논리 에러 한도.

</details>

```text
[알고리즘•목표 성공 확률]
            │
            ▼
1. 실패 예산•코드 거리 산정
            │
            ▼
2. 내결함 논리 일정 생성
            │
            ▼
┌──────── 논리 연산 반복 ────────┐
│ 3. 물리 게이트•안정자 측정     │
│            │                    │
│            ▼                    │
│ 4. 증후군 복호•프레임 갱신     │
└────────────┬───────────────────┘
             ▼
      [논리 연산 결과]
```

### 동작 원리

1. **실패 예산·코드 거리 산정**: 알고리즘 **실패 예산** 산출 및 필요한 **코드 거리(d)** 도출.
2. **내결함 논리 일정 생성**: 물리 게이트에 대한 **내결함 일정** 트랜스파일링.
3. **물리 게이트·안정자 측정**: **데이터/보조 큐비트** 파이프라인에서 물리 게이트 인가 및 패리티 수용.
4. **증후군 복호·프레임 갱신**: **고전 복호기**가 실시간 에러 정정 후 **파울리 프레임** 갱신.

#### 한줄 요약

- **논리 회로**는 내결함 물리 게이트와 안정자 측정 및 고전 복호 일정으로 변환되어 실행된다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **QEC Threshold**: 코드 거리를 늘릴 때 논리 오류율이 감소하기 위한 물리 오류율 경계.

</details>

| 비교 항목 | 물리 큐비트 (Physical Qubit) | 논리 큐비트 (Logical Qubit) |
|:---|:---|:---|
| 적용 기준 | 하드웨어 칩 상의 개별 물리적 소자 제어 시 | FTQC 내결함 기반 대규모 유효 양자 연산 시 |
| 오류율 | 장치·게이트·측정 환경에 따라 변동 | 물리 오류·코드 거리·복호기에 따라 변동 |
| 자원 관계 | 실제 소자·제어·측정 채널 단위 | 다수 물리 큐비트와 복호 자원으로 구성 |
| 주요 과제 | 칩 Scale-up, 충실도 향상, 노이즈 억제 | 하드웨어 **QEC** 디코더 지연 해소, 물리 자원 인프라 확장 |

#### 한줄 요약

- 장치의 **물리 큐비트** 수와 오류 정정 후 계산에 사용할 수 있는 **논리 큐비트** 수를 구분해야 한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **Magic-State Distillation**: Non-Clifford 게이트(T-gate)를 논리 큐비트 상에 적용하기 위해 고품질 마법 상태를 정제하는 기술.
- **Lattice Surgery**: 표면 코드 패치(Patch)들을 병합(Merge) 및 분할(Split)하여 논리 CNOT 게이트를 수행하는 2D 큐비트 연산 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| T-Gate 연산 시 대량의 물리 큐비트 추가 소모 | **Magic-State Distillation** 팩토리 배치 | Non-Clifford 논리 연산 내결함 수행 |
| 2D 격자 상에서 2-Qubit 논리 게이트 구현 난제 | **Lattice Surgery** 패치 병합/분할 연산 기법 인가 | 평면 상에서 물리적 SWAP 최소화 |
| 물리 오류율이 임계값을 넘으면 거리 증가 효과 상실 | 물리 오류를 임계값 아래로 낮춘 뒤 **QEC** 적용 | 코드 거리 증가에 따른 논리 오류 억제 |

> 사례: 코드 거리 증가 전후의 물리 자원과 논리 오류율 비교

#### 한줄 요약

- 논리 작업량을 코드 패치, 물리 큐비트, 복호기와 실행 시간을 포함한 시공간 부담으로 환산해야 한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **물리 자원 산정(Physical Resource Estimation)**: 실효 양자 알고리즘 구동에 요구되는 물리 큐비트 총량 및 디코더 성능을 설계 산출하는 프로세스.

</details>

- 내결함 장시간 계산은 **논리 큐비트**, 장치 보정·얕은 실험은 **물리 큐비트** 사용

#### 한줄 요약

- 목표 논리 오류율에서 코드 거리·물리 큐비트·복호기·실행시간을 함께 산정한다.
