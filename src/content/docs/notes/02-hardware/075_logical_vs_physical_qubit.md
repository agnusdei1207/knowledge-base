## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **물리 큐비트(Physical Qubit)**: 실제 초전도 소자나 이온 트랩 챔버에 하드웨어로 제작된 개별 큐비트 소자로, 외부 노이즈와 결맞음 손실에 직접 노출됨.
- **논리 큐비트(Logical Qubit)**: 여러 물리 큐비트를 양자 오류 정정(QEC) 알고리즘으로 묶어 노이즈 없는 이상적 큐비트처럼 동작하도록 만든 가상 연산 단위.

</details>

- 정의/개념: 노이즈에 취약한 다수의 물리 큐비트(Physical Qubit)를 양자 오류 정정 부호(QEC)로 결합하여 **오류율 $10^{-10}$ 이하의 신뢰성**을 보장하는 추상화된 논리 큐비트(Logical Qubit) 연산 체계
- 배경/필요성: 단일 물리 큐비트의 높은 노이즈와 결맞음 손실 한계 극복 및 결함 허용 대규모 양자 알고리즘 실행 필요

#### 한줄 요약
- 깨지기 쉬운 수백~수천 개의 물리 큐비트를 하나로 똘똘 뭉쳐 절대 깨지지 않는 단 하나의 완벽한 논리 큐비트를 만든다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **결함 허용 양자 컴퓨팅(FTQC, Fault-Tolerant Quantum Computing)**: 논리 큐비트를 기반으로 하드웨어 오류가 발생해도 연산 전체가 붕괴되지 않고 자가 치유되는 완벽한 양자 연산 체계.
- **매직 상태 증류(Magic State Distillation)**: 범용 양자 연산에 필수적인 $T$-게이트를 결함 허용 방식으로 실행하기 위해 고순도 보조 양자 상태를 정제하는 프로세스.

</details>

- 물리적 오류율($10^{-3}$)을 **논리적 오류율($10^{-10}$ 이하)** 로 획기적 억제
- 코드 거리($d$)에 따라 **논리 큐비트 1개당 수백~수천 개의 물리 큐비트 오버헤드** 발생
- **매직 상태 증류(Magic State Distillation)** 를 통한 범용 비클리포드($T$) 게이트 실행 보장

#### 한줄 요약
- 오류율을 100만 배 이상 낮춰 주지만, 논리 큐비트 1개를 만들기 위해 방대한 양의 물리 큐비트가 희생된다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **오버헤드 비율(Overhead Ratio)**: 하나의 논리 큐비트를 보호하기 위해 요구되는 데이터 큐비트 및 신드롬 측정 보조 큐비트의 총 물리적 수량.

</details>

```text
┌─────────────────────────────────────────────────────────────┐
│ 물리 큐비트 어레이에서 논리 큐비트 합성 계층 구조          │
│                                                             │
│  [ 양자 소프트웨어 / 알고리즘 계층 ]                        │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ 논리 큐비트 연산 (Logical Qubit L0, L1, L2..)       │  │
│  └──────────────────────────┬────────────────────────────┘  │
│                             ▼ (Lattice Surgery 논리 게이트) │
│  [ 양자 오류 정정(QEC) 미들웨어 계층 ]                      │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ 표면 코드 패치 (Surface Code Patch: Distance d)       │  │
│  │  ├─ 신드롬 패리티 측정 (X/Z Stabilizer)               │  │
│  │  └─ 실시간 고전 복호기 & 파울리 프레임 가상 보정      │  │
│  └──────────────────────────┬────────────────────────────┘  │
│                             ▼ (물리적 펄스 디스패치)        │
│  [ 물리 하드웨어 계층 (Physical Hardware) ]                 │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ 물리 큐비트 어레이 (수천 개 Transmon / Trapped-Ion)   │  │
│  │  ●-●-●-●-●-●-●-●-●-●-●-●-●-●-●-●-●-●-●-●-●-●-●-●-●-●-● │  │
│  └───────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

선의 의미: 수천 개의 물리 큐비트가 QEC 표면 코드 패치로 묶여 상위 애플리케이션에 1개의 완전한 논리 큐비트로 추상화됨

| 구성요소 | 책임 |
|:---|:---|
| 물리 데이터 큐비트 | 실제 칩 상에서 0/1 중첩 상태를 분산 보관하는 하드웨어 소자 |
| 물리 보조 큐비트 | 주기적으로 데이터 큐비트의 패리티를 측정하여 에러 신드롬 추출 |
| QEC 표면 코드 엔진 | 코드 거리 $d$에 따라 $2d^2-1$개의 물리 큐비트를 1개 논리 패치로 바인딩 |
| 매직 상태 팩토리 | 결함 허용 $T$-게이트 연산에 투입할 고순도 매직 상태 자원을 대량 정제 공급 |
| 논리 게이트 실행기 | 격자 수술(Lattice Surgery) 기법으로 패치 간 병합/분할을 수행하여 얽힘 구현 |

#### 한줄 요약
- 물리 큐비트 어레이, QEC 표면 코드 엔진, 매직 상태 팩토리, 논리 게이트 실행기가 모여 무결점 시스템을 구성한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **격자 수술(Lattice Surgery)**: 인접한 표면 코드 패치들의 경계 안정자를 함께 측정하여 물리적 이동 없이 두 논리 큐비트 간 CNOT 연산을 수행하는 기법.

</details>

```text
양자 알고리즘 컴파일 (논리 회로 정의)
      │
      ▼
1. 물리 자원 할당: 논리 큐비트당 $d \times d$ 물리 큐비트 격자 블록 매핑
      │
      ▼
2. QEC 신드롬 측정 사이클: 매 100ns마다 X/Z 안정자 패리티 연속 측정
      │
      ▼
3. 실시간 에러 정정: 고전 FPGA 디코더가 물리적 에러를 소프트웨어 프레임에 반영
      │
      ▼
4. 논리 게이트 실행: 격자 수술(Lattice Surgery) 및 매직 상태 주입으로 연산 수행
      │
      ▼
5. 논리 상태 최종 판독: 전체 패치 데이터 큐비트를 일괄 측정하여 다수결 확정
```

**동작 원리**

1. **패치 매핑**: 알고리즘 요구사항에 맞춰 물리 칩셋 상에 1개의 논리 큐비트용 2D 격자 영역 할당
2. **에러 감시**: 연산이 진행되는 도중에도 보조 큐비트들이 쉼 없이 패리티를 읽어 노이즈를 감시
3. **가상 치유**: 물리적 결맞음 손실이 발생하면 고전 복호기가 파울리 프레임을 갱신해 에러 무력화
4. **결함 허용 연산**: 논리 패치 간의 경계를 붙였다 떼는 격자 수술로 완벽한 논리 CNOT 게이트 수행
5. **무오류 결과 회수**: 알고리즘 종료 후 모든 물리 큐비트를 측정하고 패리티 복호를 거쳐 최종 정답 도출

#### 한줄 요약
- 물리 격자 매핑 → QEC 상시 감시 → 실시간 에러 가상 치유 → 격자 수술 논리 연산 → 무오류 판독 순으로 진행된다.

## Ⅴ. 종류 및 비교

| 양자 정보 연산 계층 | 논리 큐비트 (Logical) | 물리 큐비트 (Physical) | 보조 큐비트 (Ancilla) | 매직 상태 큐비트 (Magic State) |
|:---|:---|:---|:---|:---|
| 적용 기준 | 결함 허용 대규모 범용 양자 알고리즘 | 하드웨어 칩 상의 개별 물리 소자 | QEC 에러 신드롬 패리티 추출 | 결함 허용 $T$-게이트 비선형 연산 주입 |
| 핵심 특징 | 오류율 $10^{-10}$ 이하 무결점 추상화 | 오류율 $10^{-3}$ 및 짧은 결맞음 수명 | 데이터 비파괴 간접 측정 전용 | 증류(Distillation)를 통해 정제된 자원 |
| 한계 | 수천 배의 물리 자원 오버헤드 소모 | 단독으로는 수십 게이트 이상 연산 불가 | 주기적 측정/리셋 회로 복잡도 | 정제 과정에서 막대한 물리 큐비트 소모 |

#### 한줄 요약
- 완벽한 계산은 논리 큐비트, 칩의 원자재는 물리 큐비트, 에러 탐지는 보조 큐비트, $T$-게이트는 매직 상태를 쓴다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **쇼어 알고리즘(Shor's Algorithm)**: RSA 2048비트 암호를 수 시간 내에 해독할 수 있는 양자 소인수분해 알고리즘으로, 약 4,000개의 논리 큐비트와 수백만 개의 물리 큐비트가 필요.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| RSA 2048 해독에 필요한 **물리 큐비트 수백만 개 요구(하드웨어 벽)** | **양자 LDPC(qLDPC) 부호** 도입을 통한 오버헤드 비율 1/10 감축 | 필요 물리 큐비트 수 90% 이상 절감 |
| 매직 상태 증류 과정에서 발생하는 **극심한 공간/시간 낭비** | **자가 정제(Auto-distillation) 프로토콜** 및 회로 $T$-깊이 최적화 | 상태 정제 오버헤드 획기적 축소 |
| 물리 큐비트 간 간섭으로 인한 **상관 오류(Correlated Error) 발생** | 펄스 셰이핑(Pulse Shaping) 및 무작위 컴파일(Randomized Compiling) | 비상관 파울리 노이즈로 정규화 |
| 논리 큐비트 간 통신을 위한 **장거리 SWAP 게이트 지연 누적** | **양자 네트워크 인터커넥트(Quantum Interconnect)** 기반 모듈형 연결 | 칩 간 장거리 얽힘 즉각 생성 |

#### 한줄 요약
- qLDPC로 물리 큐비트를 절약하고, $T$-깊이를 줄여 매직 상태를 아끼며, 양자 인터커넥트로 칩을 확장한다.

## Ⅶ. 결론

- 양자 컴퓨터의 상용화 척도는 '물리 큐비트 개수'가 아닌 **'동작 가능한 논리 큐비트(Logical Qubit)의 수와 신뢰도'**로 평가 필수

#### 한줄 요약
- 물리 큐비트의 물리적 한계를 양자 오류 정정(QEC)으로 극복하여 수천 개의 논리 큐비트를 합성하는 것이 양자 컴퓨팅의 최종 목표다.
