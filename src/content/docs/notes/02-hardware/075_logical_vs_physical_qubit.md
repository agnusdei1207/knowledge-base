## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **물리 큐비트(Physical Qubit)**: 반도체 칩이나 진공 트랩 상에 물리적으로 존재하는, 결맞음 시간이 짧고 환경 잡음에 취약한 개별 하드웨어 양자 소자.
- **논리 큐비트(Logical Qubit)**: 다수의 물리 큐비트를 양자 오류 정정(QEC) 부호로 묶고 실시간 신드롬 복호를 수행하여, 오류율을 $10^{-12}$ 이하로 낮춘 무결한 가상 연산 단위.

</details>

- 정의/개념: 높은 오류율($10^{-3}$)을 갖는 다수의 **물리 큐비트**를 QEC 부호로 결합하여 결함 허용 연산을 보장하는 가상 추상화 단위인 **논리 큐비트(Logical Qubit) 아키텍처**
- 배경/필요성: 단일 물리 큐비트의 짧은 결맞음 수명과 노이즈로는 **수백만 게이트 깊이(Depth)를 갖는 쇼어(Shor) 암호 해독이나 양자 화학 시뮬레이션 알고리즘 완수 불가**

$$
P_{\text{Logical}} \propto \left( \frac{P_{\text{Physical}}}{P_{\text{Threshold}}} \right)^{\frac{d+1}{2}} \quad (\text{단, } d\text{는 코드 거리})
$$

#### 한줄 요약
- 논리 큐비트는 수백~수천 개의 불안정한 물리 큐비트를 양자 오류 정정(QEC)으로 결합하여 신뢰성 있는 연산을 수행하는 핵심 단위다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **결함 허용 양자 컴퓨팅(Fault-Tolerant Quantum Computing, FTQC)**: 물리 부품에 오류가 지속 발생하더라도 연산·측정·복호 과정에서 오류가 통제되어 최종 논리 결과가 보장되는 체계.
- **매직 상태 증류(Magic State Distillation)**: 결함 허용 표면 코드에서 직접 수행할 수 없는 비클리포드($T$) 게이트를 실행하기 위해 고순도 보조 상태($|T\rangle$)를 정제하는 팩토리 프로세스.

</details>

- 지수적 오류 억제: 물리 오류율이 임계치 이하일 때, **코드 거리($d$)**를 증가시킴에 따라 논리 오류율이 지수적으로 감소
- 막대한 물리적 오버헤드: 단 1개의 무결한 논리 큐비트를 구현하기 위해 **수백~수천 개의 물리 큐비트와 보조 큐비트 자원 소모**
- 비클리포드 게이트 주입: 범용 연산 완성을 위해 **매직 상태 증류 팩토리**를 통해 고순도 $|T\rangle$ 상태를 결함 허용 방식으로 공급

#### 한줄 요약
- 오류 정정 부호와 매직 상태 증류를 통해 물리적 잡음을 극복하고 완벽한 결함 허용 양자 연산을 실현한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **격자 수술(Lattice Surgery)**: 인접한 표면 코드 패치들의 경계 안정자를 함께 측정하여 물리적 이동 없이 두 논리 큐비트 간 CNOT 연산을 수행하는 기법.
- **오버헤드 비율(Overhead Ratio)**: 하나의 논리 큐비트를 보호하기 위해 요구되는 데이터 큐비트 및 보조 큐비트의 총 물리적 수량($\approx 2d^2$).

</details>

```text
[논리 큐비트 4계층 가상화 아키텍처]
 ┌─ [1. 양자 애플리케이션 및 알고리즘 계층] ── 쇼어 소인수분해 / 그로버 탐색 (논리 회로)
 │
 ├─ [2. 결함 허용 논리 게이트 계층 (FTQC)]
 │   ├─ [논리 게이트 실행기] ──────────────── 격자 수술 (Lattice Surgery) 기반 논리 CNOT
 │   └─ [매직 상태 팩토리 (Distillation)] ─── T-게이트 주입용 순수 $|T\rangle$ 상태 증류
 │
 ├─ [3. 양자 오류 정정(QEC) 미들웨어 계층]
 │   ├─ 실시간 신드롬 복호기 (Decoder) ────── FPGA 기반 MWPM / Union-Find 에러 매칭
 │   └─ 파울리 프레임 추적기 (Pauli Frame) ── 소프트웨어 에러 테이블 실시간 갱신
 │
 └─ [4. QPU 물리 하드웨어 계층]
     ├─ [물리 데이터 큐비트 (Data Qubit)] ─── 양자 정보 분산 보관 소자
     └─ [물리 보조 큐비트 (Ancilla Qubit)] ── 주기적 패리티 신드롬 측정 소자
```

선의 의미: 가지(`├─`, `└─`)는 하드웨어 소속 및 추상화 계층; 물리 큐비트 어레이 위에 QEC 미들웨어와 매직 상태 팩토리가 얹혀져 단일 논리 큐비트를 구현함

| 구성요소 | 계층 및 위치 | 핵심 엔지니어링 책임 | 주요 특징 |
|:---|:---|:---|:---|
| **물리 데이터 큐비트** | QPU 실리콘 칩 | 표면 코드 격자 상에서 단일 논리 양자 정보를 분산 부호화 | $d^2$ 개 소자 |
| **물리 보조 큐비트** | QPU 실리콘 칩 | 주기적 CNOT 얽힘을 통해 데이터 큐비트의 X/Z 에러 신드롬 추출 | $d^2 - 1$ 개 소자 |
| **QEC 미들웨어** | 고전 FPGA 컨트롤러 | 신드롬 데이터를 초고속 복호하여 파울리 에러를 실시간 추적/보정 | 실시간 복호 엔진 |
| **매직 상태 팩토리** | 논리 자원단 | 범용 양자 연산에 필수적인 고순도 $|T\rangle$ 상태를 증류하여 주입 | T-게이트 공급기 |
| **격자 수술 (Surgery)**| 논리 인터커넥트 | 물리적 소자 이동 없이 **패치 경계 병합/분할로 논리 얽힘 생성** | 2D 평면 논리 게이트 |

#### 한줄 요약
- 논리 큐비트는 물리 데이터/보조 큐비트, QEC 미들웨어, 매직 상태 팩토리 및 격자 수술 인터커넥트로 구성된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **파울리 프레임(Pauli Frame)**: 오류가 발생했을 때 하드웨어 펄스를 직접 인가하지 않고, 고전 컴퓨터 메모리의 위상 테이블만 갱신하여 런타임 지연을 없애는 소프트웨어 추적 기법.

</details>

```text
1. 양자 알고리즘 컴파일 ➔ 논리 큐비트 회로 및 타깃 오류율($10^{-12}$) 정의
                      │
                      ▼
2. 필요 코드 거리($d$) 산출 ➔ QPU 상에 물리 데이터/보조 큐비트 패치($\approx 2d^2$) 할당
                      │
                      ▼
3. 물리 보조 큐비트: 마이크로초 단위로 패리티 신드롬 측정 ➔ FPGA 복호기 전송
                      │
                      ▼
4. 실행할 논리 게이트 종류 판정
   ┌──────────────────┴──────────────────┐
[ 클리포드 게이트 (H, CNOT, S) ]       [ 비클리포드 게이트 (T-게이트) ]
   │                                     │
   ▼                                     ▼
5. 격자 수술(Lattice Surgery)로          5. 매직 상태 팩토리에서 증류된 $|T\rangle$ 상태 주입
   패치 경계 결합 및 측정                │
   │                                     │
   └──────────────────┬──────────────────┘
                      │
                      ▼
6. 신드롬 복호 결과를 고전 파울리 프레임에 누적 갱신
                      │
                      ▼
7. 최종 논리 측정값을 신드롬과 결합 복호 ➔ 100% 무결한 고전 비트 출력
```

분기 결과: **클리포드 게이트는 격자 수술로, T-게이트는 매직 상태 주입으로 처리하며** 파울리 프레임을 통해 무오류 결과를 보장함

#### 한줄 요약
- 코드 거리 산정 ➔ 물리 패치 할당 ➔ 신드롬 측정 ➔ 격자 수술/매직 상태 주입 ➔ 파울리 프레임 갱신 ➔ 무오류 논리 비트 출력 순으로 동작한다.

## Ⅴ. 종류 및 비교

| 비교 항목 | 논리 큐비트 (Logical Qubit) | 물리 큐비트 (Physical Qubit) |
|:---|:---|:---|
| 구현 형태 | **가상 추상화 단위 (다수 물리 큐비트 + QEC)**| 실리콘/진공 상의 개별 물리 소자 (조셉슨/이온) |
| 오류율 수준 | **극저오류 ($10^{-12} \sim 10^{-15}$ 이하)** | **고오류 ($10^{-2} \sim 10^{-3}$ 수준)** |
| 연산 가능 깊이 (Depth)| **수백만 ~ 수십억 게이트 이상 (FTQC)** | 수십 ~ 수백 게이트 이하 (NISQ 한계) |
| 수명 (결맞음 시간) | **QEC 능동 복호로 이론상 무한 연장** | 물리 소자 고유의 $T_1 / T_2$ (수십 $\mu\text{s} \sim$ 수 초) |
| 필요 자원 규모 | 단일 논리 큐비트당 $10^3 \sim 10^4$개 물리 소자 소모 | $1:1$ 개별 소자 |

#### 한줄 요약
- 물리 큐비트는 잡음에 노출된 하드웨어 소자이며, 논리 큐비트는 QEC를 통해 오류를 극복한 진정한 범용 연산 단위다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **쇼어(Shor) 알고리즘 자원 산정**: RSA-2048 비트를 해독하기 위해 약 4,000개 이상의 무결한 논리 큐비트와 수백만 개 이상의 물리 큐비트가 필요하다는 양자 하드웨어 요구 분석.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **쇼어 알고리즘** 실행 시 수백만 개 이상의 물리 큐비트 오버헤드 | **물리 게이트 충실도 개선($99.9\% \to 99.99\%$) 및 저오버헤드 부호(LDPC) 연구** | 필요 물리 큐비트 소모량 90% 감축 |
| 매직 상태 증류(Distillation)로 인한 물리 칩 면적 과다 점유 | **블록 증류 프로토콜 및 컴파일러 레벨 T-게이트 개수 최소화** | 증류 팩토리 오버헤드 70% 이상 절감 |
| 칩 간 장거리 논리 큐비트 통신 시 발생하는 얽힘 유실 | **양자 인터커넥트(Qlink) 및 광학 얽힘 분배 네트워크 구축** | 멀티 칩 모듈형 FTQC 분산 확장성 확보 |

#### 한줄 요약
- 실무에서는 물리 충실도 개선, 매직 상태 최적화, 양자 인터커넥트를 통해 오버헤드를 극복하고 대규모 확장을 실현한다.

## Ⅶ. 결론

- 실용적 결함 허용 양자 컴퓨터(FTQC) 개발을 위해 **단순 물리 큐비트 수량 경쟁을 넘어 표면 코드 기반의 논리 큐비트(Logical Qubit) 생성 효율을 핵심 지표로 설정**하고, 비선형 연산을 위해 **매직 상태 증류(Distillation) 팩토리**를 연동하며, 대규모 확장을 위해 **양자 인터커넥트(Qlink) 기반 모듈형 분산 아키텍처**를 구축하는 차세대 결함 허용 양자 컴퓨팅 체계 확립

#### 한줄 요약
- 양자 컴퓨팅의 실용화는 노이즈가 있는 물리 큐비트에서 오류 없는 논리 큐비트로의 패러다임 전환에 달려 있다.
