## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **Physical Qubit(물리 큐비트)**: 초전도 조셉슨 접합, 포획 이온 등 실제 하드웨어 칩에 구현된 물리적 양자 소자로 환경 노이즈와 결맞음 손실에 직접 노출되는 단위.
- **Logical Qubit(논리 큐비트)**: 다수의 물리 큐비트를 양자 오류 정정(QEC) 코드로 묶어 오류율을 $10^{-10}$ 이하로 극도로 억제한 이상적인 가상 연산 단위.
- **QEC Overhead(오류 정정 오버헤드)**: 단 1개의 무결점 논리 큐비트를 생성하고 유지하기 위해 투입되는 수백~수천 개의 물리 큐비트 및 제어 회로 비율.

</details>

- 정의/개념: 노이즈와 결맞음 손실에 직접 노출되는 개별 하드웨어 물리 큐비트(Physical Qubit)와, 복수의 물리 큐비트를 양자 오류 정정(QEC) 코드로 묶어 오류율을 $10^{-10}$ 이하로 억제한 이상적 가상 계산 단위인 논리 큐비트(Logical Qubit)의 비교 체계
- 배경/필요성: 물리 큐비트의 높은 노이즈 오류율($10^{-3}$)로 인해 회로 깊이가 제한되는 NISQ 한계를 극복하고, **수백만 개의 게이트를 신뢰성 있게 실행하는 오류 허용 양자 컴퓨팅(FTQC) 실현 필수**

#### 한줄 요약

- 노이즈에 노출된 하드웨어 소자(물리 큐비트)와 **QEC 부호화로 오류를 극복한 이상적 가상 연산 단위(논리 큐비트)**

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **Code Distance(코드 거리, d)**: 논리 큐비트 1개를 구성하는 2D 표면 코드 격자의 크기로 거리가 증가할수록 정정 가능한 물리 오류 개수($t = \lfloor(d-1)/2\rfloor$) 증가.
- **Pauli Frame Tracking**: 논리 연산 중 발생한 비트/위상 반전 오류를 물리적으로 되돌리지 않고 소프트웨어 레지스터 테이블에서 추적하여 누적 오차를 방지하는 기법.

</details>

- 물리 큐비트 오류율($10^{-3}$) 대비 논리 큐비트 오류율을 $10^{-10}$ 이하로 지수적 억제
- 코드 거리 $d$에 비례하여 1개의 논리 큐비트를 지탱하기 위한 물리 큐비트 수($\sim 2d^2$)가 급증하는 **물리 자원 오버헤드**
- 물리 소자를 직접 조작하지 않고 고전 복호기와 연동하여 가상 프레임을 보정하는 **파울리 프레임(Pauli Frame) 연계 체계**

#### 한줄 요약

- **물리 오류율($10^{-3}$) 대비 논리 오류율($10^{-10}$) 억제·코드 거리($d$) 비례 자원 오버헤드·파울리 프레임(Pauli Frame) 연동**

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **Data Qubit Array**: 논리 큐비트의 양자 중첩 정보를 분산 저장하는 물리 큐비트 군단.
- **Ancilla Qubit Array**: 데이터 큐비트 간 패리티를 측정하여 오류 증후군을 수집하는 보조 물리 큐비트 군단.
- **MWPM Decoder**: 증후군 비트열을 분석하여 최소 가중치 매칭으로 오류 발생 위치를 실시간 판정하는 고전 프로세서.

</details>

```text
[ 물리 큐비트 어레이 기반 1개 논리 큐비트 형성 아키텍처 ]
┌─────────────────────────────────────────────────────────────┐
│ 1. 최상위 논리 큐비트 인터페이스 (|0_L>, |1_L> 양자 상태)   │
└──────────────────────────────┬──────────────────────────────┘
                               │ [ 표면 코드 QEC 인코딩/디코딩 ]
┌──────────────────────────────┴──────────────────────────────┐
│ 2. 2D 평면 물리 큐비트 어레이 ($d \times d$ 격자, 수백 개) │
│  ├─ 데이터 큐비트군 (Data Qubits : 정보 분산 저장)          │
│  └─ 앤실라 큐비트군 (Ancilla Qubits : X/Z 패리티 측정)      │
└──────────────────────────────┬──────────────────────────────┘
                               │ [ 증후군 비트 스트림 ]
┌──────────────────────────────┴──────────────────────────────┐
│ 3. 고전 복호기 (FPGA MWPM) ──> 4. 소프트웨어 파울리 프레임   │
└─────────────────────────────────────────────────────────────┘
```

선의 의미: 데이터 큐비트군, 앤실라 큐비트군, 고전 복호기(MWPM), 소프트웨어 파울리 프레임 및 최상위 논리 큐비트 인터페이스 간의 논리 큐비트 아키텍처 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 데이터 큐비트 | 1개의 논리 큐비트를 지탱하기 위해 표면 코드 격자판에 넓게 깔려 희생하는 수백 개의 하드웨어 큐비트 부품 |
| 보조(앤실라) 큐비트 | 데이터 큐비트들 사이에서 "에러 났냐?" 하고 X/Z 패리티만 몰래 훔쳐보고 나오는 끄나풀 큐비트 |
| 고전 복호기 | 끄나풀들이 던져준 에러 지도를 보고, 가장 확률이 높은 에러 경로를 찾아내는 명탐정 알고리즘 |
| 논리 큐비트 | 끄나풀과 명탐정의 피눈물 나는 서포트를 받아 완성된, 개발자가 믿고 쓰는 단 1개의 절대 무적 양자 계산 단위 |

#### 한줄 요약

- **데이터 큐비트군·앤실라 큐비트군·고전 복호기(MWPM)·소프트웨어 파울리 프레임·논리 큐비트**

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Failure Budget(실패 예산)**: 수십억 회의 양자 게이트 연산 중 전체 알고리즘 성공률(예: 99%)을 달성하기 위해 허용되는 최대 논리 오류 확률.

</details>

```text
[ 논리 큐비트 자원 산정 및 내결함 연산 흐름 ]
                         │
                         ▼
   [ 1. 양자 알고리즘 요구 회로 깊이 분석 및 총 실패 예산(Failure Budget) 수립 ]
                         │
                         ▼
   [ 2. 목표 논리 오류율 달성을 위한 필요 코드 거리($d$) 및 물리 큐비트 수 산정 ]
                         │
        +────────────────┴────────────────────────+
        │        ( 내결함성 양자 연산 루프 )      │
        │                        │                │
        │                        ▼                │
        │   [ 3. 물리 게이트 펄스 인가 및 앤실라 증후군 측정 ]
        │                        │                │
        │                        ▼                │
        │   [ 4. FPGA 복호기 오류 판정 및 파울리 프레임 갱신 ]
        +────────────────────────┬────────────────+
                                 │
                                 ▼
   [ 5. 오류 누적 없는 최종 논리 양자 연산 결과 도출 ]
```

**동작 원리**

1. **실패 예산 수립**: Shor 알고리즘 등 목표 알고리즘의 총 게이트 수(예: $10^9$)에 맞춰 허용 논리 오류율($10^{-11}$) 산정
2. **코드 거리 산정**: 물리 오류율($10^{-3}$)과 표면 코드 공식을 통해 필요 코드 거리($d=27$) 및 물리 큐비트 수(약 1,500개/논리 큐비트) 도출
3. **물리 게이트 구동**: 수천 개의 물리 큐비트에 펄스를 인가하고 매 코드 주기마다 앤실라 안정자 측정
4. **실시간 복호**: FPGA 복호기가 증후군을 처리하여 파울리 프레임을 갱신
5. **무결점 연산 완료**: 논리 게이트 연산을 완주하고 최종 투사 측정을 통해 정확한 해답 도출

#### 한줄 요약

- 알고리즘 실패 예산 수립 $\to$ **필요 코드 거리($d$) 산정 $\to$ 내결함성 물리 게이트 펄스 인가 $\to$ 앤실라 증후군 수집 $\to$ 파울리 프레임 갱신 $\to$ 무결점 논리 연산 완료**

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **Physical vs Logical Qubit 비교**:
  - Physical Qubit: 하드웨어 소자, 오류율 $10^{-3}$, $T_1/T_2$ 내 얕은 회로만 가능 (NISQ)
  - Logical Qubit: QEC 부호화된 가상 단위, 오류율 $<10^{-10}$, 임의의 깊은 회로 무제한 실행 (FTQC)

</details>

| 비교 항목 | 물리 큐비트 (Physical Qubit) | 논리 큐비트 (Logical Qubit) |
|:---|:---|:---|
| 물리적 실체 및 오류율 | 하드웨어 소자 자체 (조셉슨 접합, 포획 이온), 오류율 $10^{-3}\sim 10^{-4}$ | 수십~수천 개 물리 큐비트의 QEC 부호화, 오류율 $<10^{-10}$ |
| 연산 지속성 및 회로 깊이 | 결맞음 시간($T_1, T_2$) 내 얕은 회로만 실행 가능 ($<100$ 게이트) | 실시간 QEC 복호로 임의의 깊은 회로 무제한 실행 가능 |
| 한계 및 자원 요구량 | 스케일링 시 노이즈 누적으로 결과 신뢰성 급락 | 1개 논리 큐비트당 수백~수천 개 물리 큐비트 오버헤드 소모 |

#### 한줄 요약

- 하드웨어 소자는 **물리 큐비트(NISQ)**, 오류 없는 가상 연산 단위는 **논리 큐비트(FTQC)**

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Magic-State Distillation(매직 상태 정제)**: 범용 양자 연산을 위한 비클리포드(T-Gate) 게이트를 내결함성 있게 구현하기 위해 고품질 마법 상태를 별도 정제하는 팩토리 기술.
- **Lattice Surgery(격자 수술)**: 2D 평면 표면 코드 패치 간의 경계를 병합(Merge) 및 분할(Split)하여 장거리 2큐비트 논리 게이트(CNOT)를 구현하는 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 논리 큐비트한테 삐딱한 고급 연산(T-Gate)을 먹이려면 수십 배의 물리 큐비트가 무식하게 증발해버리는 참사 | 공장 한쪽에 **매직 상태 정제** 전용 공장을 따로 지어 고품질 양자 상태(마법 가루)를 깎아낸 뒤 본진에 주입시킴 | 무식하게 큐비트를 낭비하지 않고도 복잡한 논리 연산을 깔끔하고 완벽하게(내결함성 보장) 해치움 |
| 바둑판(2D 표면 코드) 모양이라 저 멀리 있는 논리 큐비트랑 얽히게 만들려면 선을 이을 방법이 없어서 뻗어버림 | 논리 큐비트 패치(구역)들을 수술하듯 잘랐다 붙였다 하는 **격자 수술**(Lattice Surgery) 기법 전격 도입 | 멀리 있는 놈팽이들과 얽힐 때 물리적인 자리 이동(SWAP 낭비) 없이 평면 상에서 우아하게 연결 완료 |
| 칩 자체가 너무 썩어서 물리 에러율이 임계값을 넘어버리면, 바둑판(코드 거리)을 키울수록 에러가 더 폭발해버리는 자폭 사태 | 하드웨어를 뼈 깎듯 갈고닦아 어떻게든 물리 오류를 임계값 아래로 멱살 잡고 내린 뒤에야 **QEC** 적용 허가 | 임계값만 넘어서면 물리 큐비트를 들이부을 때마다 논리 에러가 0에 수렴해버리는 궁극의 방패 완성 |

#### 한줄 요약

- **매직 상태 정제(Magic-State Distillation) 팩토리·Lattice Surgery 격리 얽힘·QEC 오류 임계값 확보**

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **FTQC 스케일링 로드맵**: 2030년대 RSA-2048 해독을 위해 약 4,000개의 논리 큐비트와 이를 지탱하는 수백만 개의 초전도/이온트랩 물리 큐비트 집적 목표.

</details>

- 오류 허용 양자 컴퓨터 구축 시 **Shor 알고리즘 기준 약 4,000 논리 큐비트 구현을 위해 수백만 개의 물리 큐비트 집적 및 QEC 아키텍처 표준 채택**

#### 한줄 요약

- **물리 큐비트 집적도와 QEC 부호화 효율**을 통한 논리 큐비트 대규모 양산
