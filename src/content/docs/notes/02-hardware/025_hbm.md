## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **고대역폭 메모리(High Bandwidth Memory, HBM)**: 다수 DRAM 다이를 TSV로 수직 적층하고 실리콘 인터포저의 광폭 버스로 프로세서와 연결하여 초고속 전송 대역폭을 제공하는 패키지 메모리.
- **메모리 벽(Memory Wall)**: 프로세서의 연산 처리 속도 향상에 비해 메모리 데이터 전송 대역폭 발전이 뒤처져 전체 시스템 성능이 병목되는 현상.
- **실리콘 인터포저(Silicon Interposer)**: 로직 다이와 HBM 스택 사이에 미세 피치 마이크로범프 배선을 형성하여 광폭 병렬 신호 경로를 제공하는 중간 기판.

</details>

- 정의/개념: DRAM 다이를 수직 적층하고 **실리콘 인터포저** 기반 가속기와 직결한 **HBM**
- 배경/필요성: 기존 2D 평면 패키징만으로는 **메모리 벽(Memory Wall)에 따른 대역폭 병목 극복 불가**

#### 한줄 요약
- HBM이 푸는 문제는 메모리가 느리다는 것이 아니라 배선을 낼 자리가 없다는 것이며, 그래서 해법이 소자가 아니라 패키징에서 나왔다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **실리콘 관통 전극(Through-Silicon Via, TSV)**: 실리콘 칩을 수직으로 관통하는 미세 전극을 형성하여 상하 적층된 다이 간에 최단 전기 신호 경로를 제공하는 3차원 패키징 배선 기술.
- **광폭 인터페이스(Wide Interface)**: 1024비트 이상의 다수 데이터 버스를 병렬로 연결하여 핀당 동작 클록을 낮추면서도 총 전송 대역폭을 극대화하는 인터페이스 구조.
- **채널 인터리빙(Channel Interleaving)**: 메모리 주소 요청을 복수의 독립 채널에 분산 접근시켜 동시 병렬 전송 효율을 극대화하는 기법.

</details>

- **TSV** 수직 적층으로 다이 간 배선 길이를 단축하여 신호 지연 및 에너지 소모 절감
- **광폭 인터페이스** 기반 핀당 속도를 낮추면서 전체 메모리 대역폭 확대
- **채널 인터리빙** 통한 요청 병렬 분산으로 유효 대역폭 극대화

#### 한줄 요약
- 핀당 속도를 낮추고 선 수를 늘린 선택이 신호 무결성과 전력 문제를 동시에 완화하므로, 넓고 느린 쪽이 좁고 빠른 쪽보다 에너지 효율에서 앞선다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **베이스 다이(Base Die)**: HBM 적층 스택의 최하단에 위치하여 상단 DRAM 코어 다이들과 외부 호스트 로직 간의 신호 라우팅 및 테스트 제어를 총괄하는 인터페이스 로직 다이.
- **마이크로범프(Microbump)**: 다이와 인터포저 또는 다이 간의 전기적·기계적 접속을 위해 형성된 마이크로미터 단위의 초미세 솔더 볼 접합부.
- **DRAM 코어 다이(DRAM Core Die)**: 실제 데이터를 저장하는 메모리 셀 어레이와 수직 연결용 TSV 전극을 포함하는 상부 적층 메모리 칩.

</details>

```text
[가속기 패키지]
AI·GPU 로직 다이 ─ 마이크로범프 ─ 실리콘 인터포저 ─ 마이크로범프 ─ HBM 스택
                                                                     ├─ DRAM 코어 다이 × N
                                                                     │     ↕ TSV
                                                                     └─ 베이스 다이
```

선의 의미: `─`는 로직 다이와 HBM의 광폭 수평 연결, `↕`는 적층 다이 사이의 TSV 수직 연결

| 구성요소 | 책임 |
|:---|:---|
| 로직 다이 | 메모리 요청 발생과 가속 연산 수행 |
| **실리콘 인터포저** | **마이크로범프**를 통한 로직·HBM 간 광폭 배선 제공 |
| **DRAM 코어 다이** | 적층 단수만큼의 대용량 데이터 저장 |
| **TSV** | 적층 다이 간 수직 고밀도 신호 전달 |
| **베이스 다이** | 외부 인터페이스 수신과 **채널 인터리빙** 분산 |

#### 한줄 요약
- 모든 구성요소가 한 패키지에 봉인되므로 한 다이의 결함이 패키지 전체를 폐기시키며, HBM 원가의 상당 부분이 성능이 아니라 이 수율 위험에서 나온다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **메모리 컨트롤러(Memory Controller)**: 호스트의 메모리 접근 요청을 해석하여 HBM의 독립 채널 및 내부 뱅크로 주소를 스케줄링하고 명령을 전달하는 제어 장치.
- **버스트 전송(Burst Transfer)**: 단일 읽기/쓰기 명령에 대해 연속된 데이터 블록을 클록 사이클마다 고속으로 연속 입출력하는 전송 방식.

</details>

```text
가속기 메모리 요청
      │
      ▼
메모리 컨트롤러: 주소 분산 후 채널·뱅크 병렬 요청 생성
      │
      ▼
광폭 명령·주소 전달: 인터포저 경유 베이스 다이 도달
      │
      ▼
TSV 수직 전송: DRAM 코어 다이 접근 후 버스트 전송 반환
      │
      ▼
가속기 연산 유닛으로 데이터 공급
```

분기 결과: 요청이 여러 채널에 고르게 흩어지면 **버스트 전송이** 겹쳐 대역폭이 그대로 나오지만, 한 채널로 몰리면 광폭 배선이 있어도 그 채널 속도 이상은 나오지 않음

#### 한줄 요약
- 광폭 인터페이스의 대역폭은 요청이 흩어져 있을 때만 실현되는 잠재값이라, 데이터 배치가 나쁘면 비싼 패키징이 그대로 낭비된다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **그래픽 DDR(Graphics Double Data Rate, GDDR)**: 그래픽 및 가속 연산 처리를 위해 핀당 고속 클록 주파수를 적용하여 단일 기판에서 높은 대역폭을 구현한 고속 메모리 규격.
- **DDR SDRAM(Double Data Rate Synchronous Dynamic Random-Access Memory, DDR)**: 클록 신호의 상승 에지와 하강 에지에서 모두 데이터를 전송하는 표준 범용 메모리 규격.
- **DIMM(Dual In-line Memory Module)**: 여러 개의 DRAM 칩을 기판 양면에 실장하여 메인보드 슬롯에 탈착할 수 있게 만든 표준 메모리 모듈.

</details>

| 메모리 유형 | HBM | GDDR | DDR |
|:---|:---|:---|:---|
| 적용 기준 | 가속기·HPC에서 대역폭이 최우선 | 그래픽에서 대역폭과 비용의 균형 | 범용 시스템의 용량·확장성 우선 |
| 핵심 특징 | 적층 DRAM·**광폭 인터페이스**·낮은 핀 전력 | 협폭 고속 인터페이스·GDDR 세대 향상 | DIMM 기반 범용 확장성 |
| 한계 | 패키징·열·비용 부담 | 신호 전력·공간 제약 | 가속기 대역폭 병목 가능 |

#### 한줄 요약
- 세 메모리는 성능 등급이 아니라 용량을 늘리는 방식이 갈리며, HBM만은 패키지에 봉인돼 나중에 증설할 수 없다는 점이 결정적 제약이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **양품 다이(Known Good Die, KGD)**: 적층 패키징 공정 전 웨이퍼 레벨 테스트를 완벽히 통과하여 정상 동작 신뢰성이 100% 보증된 베어 다이.
- **직접 칩 냉각(Direct-to-Chip Liquid Cooling)**: 고발열 반도체 패키지 표면에 냉각 플레이트를 직접 밀착시켜 냉각수를 순환시키는 고효율 수랭식 냉각 기술.
- **오류 정정 코드(Error-Correcting Code, ECC)**: 데이터 저장 및 전송 중 발생하는 비트 반전 오류를 자체적으로 검출하고 단일 비트 오류를 정정하는 메커니즘.
- **메모리 RAS(Reliability, Availability, Serviceability)**: 시스템 무중단 신뢰성 보장을 위해 오류 검출·격리·복구 및 셀 재배치를 수행하는 통합 하드웨어 신뢰성 메커니즘.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 적층 다이 결함으로 패키지 수율 저하 | **KGD** 선별·적층 전후 시험 | 결함 조기 검출·수율 향상 |
| 가속기+HBM 집중 발열 | 패키지 열 설계·**직접 칩 냉각** 검토 | 열 제한·성능 저하 완화 |
| 특정 채널 요청 쏠림 | **채널 인터리빙**·주소 배치 조정 | 유효 대역폭 향상 |
| 적층 연결부·셀 오류로 무결성 저하 | **ECC** 및 **메모리 RAS** 기능 보장 범위 검증 | 검출·정정 가능 오류 범위 확정 |

#### 한줄 요약
- 네 문제 중 셋이 다이를 쌓았기 때문에 생기므로, 적층이 만든 대역폭 이득은 수율·발열·검증 비용으로 상당 부분 되돌려 준다.

## Ⅶ. 결론

- 초고대역폭은 **HBM**, 비용 대비 대역폭은 **GDDR**, 대용량 확장은 **DDR** 선택

#### 한줄 요약
- HBM 채택 판단의 실제 기준은 대역폭 수치가 아니라 그 대역폭을 다 쓰는 워크로드가 있느냐이며, 못 쓰면 GDDR 대비 지불한 값이 전부 손실이다.
