## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **고대역폭 메모리(High Bandwidth Memory, HBM)**: 복수의 DRAM 다이(Die)를 수직 적층(3D Stacking)하고 실리콘 인터포저(Silicon Interposer) 기반의 1024-bit 이상 광폭 I/O(Wide I/O) 버스를 통해 GPU/NPU AI 가속기와 2.5D 패키징 결합되는 초고속 메모리 아키텍처.
- **DRAM (Dynamic Random-Access Memory)**: 1T1C 커패시터 전하 저장 기반의 초고밀도 휘발성 반도체.
- **메모리 장벽(Memory Wall)**: 프로세서(GPU/NPU) 연산 속도의 폭증 대비 메인 메모리의 데이터 전송 대역폭 확장이 뒤처져, 연산 유닛이 데이터 입력을 받지 못하고 멈춰 서는(Stall) 병목 현상.

</details>

- 정의/개념: TSV(Through-Silicon Via) 미세 수직 배선 기술을 활용하여 다수의 DRAM 다이를 적층하고 실리콘 인터포저 기반 1024-bit 초광폭 I/O 경로로 가속기와 결합하는 초고속 **고대역폭 메모리**.
- 배경/필요성: LLM(거대언어모델) AI 딥러닝 훈련 시 GPU 연산력 대비 기존 GDDR/DDR 메모리의 핀 수 및 전송 대역폭 한계로 심각한 **메모리 장벽**이 발생함에 따라 초당 테라바이트(TB/s) 급 전송 대역폭이 필수화됨.

#### 한줄 요약
- TSV 수직 적층 및 1024-bit 초광폭 인터포저 패키징을 기반으로 테라바이트(TB/s) 급 초고대역폭을 제공하여 AI 메모리 장벽을 해소하는 가속기 전용 메모리.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **실리콘 관통 전극(Through-Silicon Via, TSV)**: DRAM 칩 다이를 수직으로 수천 개 관통하는 초미세 구리 단자를 형성하여 층간 신호와 전력을 직통 연결하는 미세 3D 적층 배선 기술.
- **채널 수(Channel Count)**: HBM 스택이 제공하는 독립 메모리 인터페이스 전송 경로 수.
- **채널 폭(Channel Width)**: 한 채널이 병렬 전송하는 데이터 비트 수.
- **핀 전송률(Pin Transfer Rate, $R_{pin}$)**: HBM 핀 1개가 초당 쏘아 보내는 데이터 수치 (Gbps / Gb/s).
- **I/O 전력(I/O Power)**: 초고속 신호 구동 시 발생되는 패키징 신호선 전력 소모량으로, HBM은 배선 길이가 극도로 짧아 GDDR 대비 I/O 전력 효율(PJ/bit)이 대폭 우수함.

</details>

- **TSV(Through-Silicon Via)** 적층을 적용하여 신호 배선 거리를 수 밀리미터(mm) 수준으로 단축함으로써 신호 감쇄를 줄이고 **I/O 전력(I/O Power)** 소모량 최소화.
- 1024-bit 광폭 물리 인터페이스를 채택하여 핀당 클록 주파수를 과도하게 올리지 않고도 초당 1~2 TB/s 이상의 **실효 대역폭** 달성.
- **채널 수**, **채널 폭** 및 **핀 전송률($R_{pin}$)**의 곱으로 이론 총 대역폭을 수치화.

$$
Bandwidth_{theoretical} = \frac{N_{channel} \times W_{channel} \times R_{pin}}{8}
$$

#### 한줄 요약
- TSV 3D 적층 및 1024-bit 광폭 인터포저 연결을 통해 전력 소모를 절감하면서 초당 1~2 TB/s 이상의 초고대역폭을 실현함.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **DRAM 다이 스택(DRAM Die Stack)**: 4층, 8층, 12층, 16층 수직으로 쌓아 올린 3D DRAM Core 칩 모듈.
- **베이스 다이(Base Die / Logic Die)**: HBM 스택 가장 하단에 배치되어 TSV 수직 신호를 수집 및 제어하고 온디바이스 테스트/ECC 회로를 내장한 마이크로 로직 다이.
- **실리콘 인터포저(Silicon Interposer)**: 2.5D 패키징 기반 하에서 GPU/NPU 칩과 HBM 스택 사이에 1024개 이상의 초미세 물리 배선(Sub-micron Trace)을 형성해 주는 고정밀 반도체 서브스트레이트 기판.
- **마이크로범프(Microbump) / MR-MUF**: DRAM 다이 및 베이스 다이 간의 전기적 물리 접합을 매개하는 정밀 땜납 범프 및 성형 소재 기술.

</details>

```text
[ 2.5D System-in-Package (SiP) Architecture ]
 ┌─────────────────────────────────────────────────────────────┐
 │  GPU / NPU AI Accelerator   │  HBM3e DRAM Stack (4~16 Core) │
 │  (Logic ASIC Compute Die)   │  ├─ Core DRAM Die 3 (TSV)     │
 │                             │  ├─ Core DRAM Die 2 (TSV)     │
 │                             │  ├─ Core DRAM Die 1 (TSV)     │
 │                             │  └─ Base Logic Die (Buffer)   │
 ├─────────────────────────────┴───────────────────────────────┤
 │ Silicon Interposer Substrate (1024-bit Sub-micron Traces)   │
 ├─────────────────────────────────────────────────────────────┤
 │ Package Substrate & BGA Balls                               │
 └─────────────────────────────────────────────────────────────┘
```

| 구성요소 | 책임 |
|:---|:---|
| DRAM 다이 스택 | **TSV 기반 용량 적층** 제공 |
| 베이스 다이 | **신호 라우팅•PHY•테스트** 제어 |
| 실리콘 인터포저 | 가속기•HBM 간 **광폭 배선** 제공 |
| TSV•접합 소재 | 다이 간 **수직 신호•전력•기계 접합** 제공 |

#### 한줄 요약
- DRAM Die Stack(TSV), Base Logic Die, Silicon Interposer 2.5D substrate 및 MR-MUF 방열 소재가 결합함.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **HBM 컨트롤러(HBM Controller)**: ASIC/GPU 내부에 배치되어 16개 독립 HBM 채널로 주소를 분산하고 Command/Address 버스트 전송을 스케줄링하는 유닛.
- **광폭 I/O(Wide I/O PHY)**: 인터포저 상의 1024개 물리 데이터 라인을 타고 고속으로 데이터를 주고받는 반도체 물리 계층.

</details>

```text
[ GPU / NPU AI Tensor Compute Core Request ]
                      │
                      ▼
        [ 1. 주소 인터리빙 ]
        └─ 16개 독립 채널(Channel 0 ~ 15)로 주소 분산 스케줄링
                      │
                      ▼
        [ 2. 광폭 I/O 전송 ]
                      │
                      ▼
        [ 3. 베이스 다이 라우팅 ]
                      │
                      ▼
        [ 4. TSV•DRAM 뱅크 접근 ]
                      │
                      ▼
        [ 5. 버스트 데이터 반환 ]
```

### 동작 원리

1. 주소 인터리빙: 요청을 독립 채널•뱅크로 분산함.
2. 광폭 I/O 전송: PHY•인터포저를 거쳐 베이스 다이로 전달함.
3. 베이스 다이 라우팅: 요청을 목표 TSV 경로로 연결함.
4. TSV•뱅크 접근: 목표 DRAM 다이의 뱅크에서 데이터를 읽음.
5. 버스트 데이터 반환: 광폭 경로로 가속기에 데이터를 반환함.

#### 한줄 요약
- 16-Channel Interleaving -> 1024-bit Interposer PHY -> Base Die -> TSV -> DRAM Bank Read 및 Burst Return 순으로 작동함.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **GDDR (Graphics DDR)**: 개별 칩 패키징 형태로 PCB 보드 위에 배치되며 32-bit 데이터 핀의 동작 주파수(20+ Gbps)를 극도로 올리는 그래픽 전용 메모리.
- **적층 수율(Stack Yield)**: N개의 DRAM 다이를 쌓아 올릴 때 단 1개 층의 미세 결합 오차만 발생해도 스택 전체를 폐기해야 하는 제조 수율 리스크.
- **신호 무결성(Signal Integrity)**: 고주파 전송 시 핀 신호 상호 간섭(Crosstalk) 및 반사파로 인한 데이터 왜곡 성질.

</details>

| 비교 항목 | HBM (HBM3 / HBM3e) | GDDR (GDDR6X / GDDR7) |
|:---|:---|:---|
| 패키징 아키텍처 | 3D TSV 적층 + 2.5D **실리콘 인터포저** | PCB 보드 상에 2D Surface Mount 개별 칩 배치 |
| 인터페이스 폭 | **1024-bit** (초광폭 Bus) | 32-bit per Chip (협폭 Bus) |
| 핀당 동작 속도 | 상대적 낮음 (6.4 ~ 9.6 Gbps) | 극도로 높음 (20 ~ 32+ Gbps) |
| 전송 대역폭 | **1.2 TB/s ~ 1.5 TB/s+ per Stack** | 80 ~ 128 GB/s per Chip |
| I/O 전력 효율 | **매우 뛰어남** (낮은 Clock, 짧은 배선) | 상대적 취약 (고주파 구동 전력 대폭 소모) |
| 제조/패키징 단가 | 매우 비쌈 (**적층 수율** 및 인터포저 비용) | 비교적 저렴함 (표준 PCB 탑재 가능) |

#### 한줄 요약
- HBM은 1024-bit 광폭 2.5D 적층 구조로 TB/s 급 대역폭 및 우수한 전력 효율을 제공하고, GDDR은 32-bit 협폭 2D 보드 배치 구조로 고주파 핀 속도를 제공함.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **양품 다이(Known Good Die, KGD)**: 적층 전 각 DRAM 웨이퍼 다이가 100% 정상 작동하는지 사전 정밀 검사하는 선별 절차.
- **액체 냉각(Liquid Cooling / Direct-to-Chip)**: GPU와 HBM이 2.5D 밀집 패키징되어 발생하는 핫스팟 발열을 워터블록 서큘레이터로 직접 식혀주는 고성능 수랭 시스템.
- **오류 격리(Error Isolation / Pseudo-Channel)**: 특정 HBM 채널이나 라인에 물리 결함 발생 시 독립된 수리 배선(Redundancy Bus)으로 스위칭하거나 해당 채널만 격리하는 기술.

</details>

| 문제 및 병목 원인 | 실무적 대책 및 해결 방안 | 기대 효과 |
|:---|:---|:---|
| N층 적층 중 한 다이 결함으로 스택 수율 저하 | **양품 다이** 선별 및 **예비 경로** 내장 | 적층 전 결함 차단과 연결 수율 향상 |
| GPU 코어와 HBM 2.5D 패키지 밀집으로 인한 초고밀도 발열 스로틀링 | **MR-MUF** 방열 소재 패키징 및 **Direct-to-Chip 액체 냉각** 연동 | 열 스로틀링(Throttling) 차단 및 100% 지속 연산 성능 확보 |
| 특정 HBM 채널 주소 쏠림으로 인한 **채널 포화** | HBM 컨트롤러 **주소 인터리빙** 최적화 | 16개 채널 균등 억세스 및 실효 대역폭 95% 달성 |
| 수천 개 TSV 미세 단자 연결 손상에 따른 비트 오류 | Base Die 내장 **Pseudo-Channel On-Die ECC** 및 **오류 격리** | 데이터 무결성 보장 및 시스템 다운 차단 |

#### 한줄 요약
- KGD 사전 선별 및 Redundant TSV, Direct-to-Chip 수랭 냉각, Address Interleaving 및 On-Die ECC 기술을 적용함.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **HBM 아키텍처 선택 기준(HBM Selection Criteria)**: LLM AI 모델 파라미터 용량, 가속기 FLOPs 연산 속도, 패키징 제조 단가 및 수랭 쿨링 인프라 구축 가능성을 평가하여 HBM3e/HBM4 규격을 선택하는 프레임워크.

</details>

- 대역폭•용량이 패키징 비용보다 중요하면 **HBM**, 비용•교체성이 우선이면 **GDDR** 선택.

#### 한줄 요약
- 대역폭 요구와 열•수율 비용을 기준으로 HBM 채택과 적층 수를 결정함.
