## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **고대역폭 메모리(High Bandwidth Memory, HBM)**: 복수의 DRAM 코어 다이를 TSV(실리콘 관통 전극)로 수직 적층하고 실리콘 인터포저의 1024비트 이상 초광폭 버스로 GPU/AI 프로세서와 직결하여 초고속 대역폭을 제공하는 3D 스택 메모리.
- **메모리 벽(Memory Wall)**: 프로세서 연산 처리 속도의 발전 속도에 비해 외부 메모리 전송 대역폭이 따라가지 못해 전체 컴퓨팅 성능이 메모리에서 병목되는 현상.
- **실리콘 인터포저(Silicon Interposer)**: 로직 다이(GPU/NPU)와 HBM 스택 사이에 미세 피치 마이크로범프 배선을 형성하여 초광폭 병렬 신호 경로를 제공하는 2.5D 패키징 기판.

</details>

- 정의/개념: DRAM을 TSV로 적층하고 **인터포저**로 연결한 **HBM**
- 배경/필요성: 기존 PCB 평면 실장(GDDR/DDR)의 핀 수 제약 및 신호 손실 한계로 인해 AI·고성능 컴퓨팅(HPC)의 대규모 데이터 처리 요구에 대응하는 **초고대역폭(TB/s급) 메모리 구현 불가**

#### 한줄 요약
- HBM은 DRAM을 수직 적층(TSV)하고 인터포저로 GPU와 직결하여 수 테라바이트급 초고대역폭을 구현하는 3D 메모리 패키징 기술이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **실리콘 관통 전극(Through-Silicon Via, TSV)**: 실리콘 다이를 수직으로 관통하는 마이크로미터 단위 전극을 형성하여 상하 적층 다이 간 최단 전기적 신호 경로를 제공하는 배선 기술.
- **광폭 인터페이스(Wide Interface)**: 1024비트 이상의 다수 데이터 핀을 병렬 연결하여 개별 핀의 동작 주파수를 낮추면서도 시스템 총 대역폭을 비약적으로 확장하는 인터페이스.
- **채널 인터리빙(Channel Interleaving)**: 메모리 주소를 여러 독립 채널에 분산 매핑하여 동시 병렬 전송 효율을 극대화하는 기법.

</details>

- **TSV**의 짧은 수직 배선으로 전송 에너지 절감
- 1024비트 이상 **광폭 인터페이스**로 TB/s급 대역폭
- **3D 적층**으로 평면 실장 대비 패키지 면적 축소

#### 한줄 요약
- TSV 수직 적층과 1024비트 광폭 버스를 결합하여 전력 소모를 줄이면서 초당 테라바이트급 대역폭을 구현한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **베이스 다이(Base/Logic Die)**: HBM 스택 최하단에 위치하여 상단 DRAM 코어 다이들과 외부 호스트 간의 물리 계층(PHY), BIST 테스트, 채널 라우팅을 총괄하는 로직 칩.
- **마이크로범프(Microbump)**: 다이와 인터포저 또는 다이 간을 물리적·전기적으로 접합하는 초미세 솔더 볼.
- **DRAM 코어 다이(DRAM Core Die)**: 데이터 저장 셀 어레이와 TSV 전극을 포함하는 상부 수직 적층 메모리 다이 (4단, 8단, 12단, 16단 적층).

</details>

```text
HBM 2.5D 이종 집적 아키텍처
├── GPU/AI 로직 다이: 대규모 병렬 연산 코어 및 다채널 호스트 메모리 컨트롤러
├── 실리콘 인터포저: 마이크로범프 기반 1024비트+ 초광폭 미세 배선 경로 제공
├── 베이스 로직 다이: HBM 최하단 위치, TSV 라우팅, PHY 인터페이스, BIST 제어
└── DRAM 코어 다이 스택: TSV 관통 전극으로 직결된 4~16단 수직 적층 1T1C 셀 어레이
```

선의 의미: 가지(`├──`, `└──`)는 단일 2.5D 패키지 내부에 집적된 로직 다이, 인터포저, HBM 스택 구성요소의 포함 관계를 나타냄

| 구성요소 | 책임 |
|:---|:---|
| GPU·AI 로직 다이 | HBM 채널별 **메모리 요청** 발행 |
| 실리콘 인터포저 | **마이크로범프** 기반 광폭 신호선 제공 |
| 베이스 다이 | TSV 라우팅과 **PHY·BIST** 제어 |
| TSV 수직 전극 | 적층 다이 간 데이터·제어 신호 연결 |
| DRAM 코어 다이 | 적층 **1T1C 어레이**에 데이터 저장 |

#### 한줄 요약
- HBM은 로직 다이, 실리콘 인터포저, 베이스 다이, 수직 적층 DRAM(TSV)이 단일 2.5D 패키지 안에서 결합된 고집적 시스템이다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **HBM 채널(HBM Channel)**: HBM 스택 내부에서 독립적으로 주소 지정 및 데이터 전송이 가능한 병렬 서브 인터페이스(HBM3 기준 16개 의사 채널).

</details>

```text
GPU/AI 코어의 대규모 텐서 데이터 메모리 접근 요청 발행
                      │
                      ▼
1. 호스트 메모리 제어기의 주소 채널 분산 스케줄링 (16개 의사 채널)
                      │
                      ▼
2. 실리콘 인터포저 경유 1024비트 초광폭 병렬 신호 전송
                      │
                      ▼
3. HBM 베이스 다이의 목적 채널 및 뱅크 주소 디코딩
                      │
                      ▼
4. TSV 관통 전극을 통한 수직 적층 DRAM 코어 다이 셀 접근
                      │
                      ▼
1024비트 광폭 버스로 데이터 일괄 인출 후 인터포저를 거쳐 GPU로 초고속 반환 (TB/s+)
```

분기 결과: 요청이 **16개 채널에 균등 분산**되면 최대 대역폭이 실현되며, **단일 채널 집중** 시 병렬 전송 효율이 저하됨

**동작 원리**

1. **주소 채널 분산 스케줄링**: 주소를 의사 채널에 분산
2. **초광폭 병렬 신호 전송**: 인터포저로 요청 전달
3. **목적 채널 및 뱅크 주소 디코딩**: 접근 뱅크 선택
4. **수직 적층 DRAM 코어 다이 셀 접근**: TSV로 셀 데이터 인출

#### 한줄 요약
- 요청이 메모리 제어기에서 16개 채널로 분산되어 인터포저와 TSV를 거쳐 DRAM에 도달하고, 광폭 버스로 GPU에 초고속 반환된다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **GDDR(Graphics DDR)**: 32비트 협폭 버스에 초고주파 클록을 인가하여 기판 레벨에서 대역폭을 구현한 그래픽 메모리.
- **표준 DDR5**: 탈착식 DIMM 모듈 기반으로 대용량 확장에 최적화된 표준 시스템 메모리.

</details>

| 그래픽·시스템 메모리 | HBM | GDDR | DDR5 |
|:---|:---|:---|:---|
| 적용 기준 | 대역폭·전력 효율 최우선 | 비용과 그래픽 대역폭 절충 | 대용량·증설성 우선 |
| 핵심 특징 | **2.5D 적층·광폭 버스** | PCB 실장·**고속 핀** | DIMM 기반 **모듈 확장** |
| 한계 | 패키징 비용과 용량 고정 | 고주파 구동 전력 증가 | 상대적으로 낮은 대역폭 |

#### 한줄 요약
- 초고대역폭과 에너지 효율이 최우선이면 HBM, 비용과 대역폭의 절충에는 GDDR, 대용량 확장성에는 표준 DDR5가 선택 기준이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **양품 다이(Known Good Die, KGD)**: 적층 패키징 전에 100% 정상 동작이 검증된 베어 다이(Die).
- **직접 칩 냉각(Direct-to-Chip Liquid Cooling)**: 고발열 2.5D 패키지 표면에 수랭식 콜드 플레이트를 밀착시켜 냉각하는 기술.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 적층 다이 불량 시 패키지 전체 폐기 위험 | **KGD 선별 시험** 및 리던던시 TSV 배치 | 적층 패키징 수율 90% 이상 확보 |
| 고밀도 2.5D 집적으로 인한 패키지 열 집중 | **MR-MUF 공정** 및 직접 수랭 냉각 적용 | 열 저항 40% 감소 및 스로틀링 방지 |
| 고정 패키지 용량 한계로 인한 초대형 모델 적재 부족 | **CXL 확장 메모리** 연계 계층화 | 고대역폭과 대용량 하이브리드 구축 |

#### 한줄 요약
- 실무에서는 KGD 검사와 리던던시 TSV로 수율을 방어하고, MR-MUF 공정과 수랭식 쿨링으로 발열을 제어하며, CXL로 용량을 확장한다.

## Ⅶ. 결론

- 생성형 AI 및 초대규모 언어 모델(LLM) 가속기(GPU/NPU)의 **핵심 표준 메모리(HBM3E/HBM4)**로 자리 잡았으며, 향후 **커스텀 베이스 다이(파운드리 공정 결합), 16단/20단 극미세 하이브리드 본딩 및 PIM 연산 융합 구조**로 기술 진화 가속화

#### 한줄 요약
- HBM은 AI 반도체 성능을 결정하는 초고대역폭 핵심 메모리이며, 첨단 3D 패키징과 방열 기술의 융합이 상용화의 핵심이다.
