## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **고대역폭 메모리(High Bandwidth Memory, HBM)**: 복수의 DRAM 코어 다이를 TSV(실리콘 관통 전극)로 수직 적층하고 실리콘 인터포저의 1024비트 이상 초광폭 버스로 GPU/AI 프로세서와 직결하여 초고속 대역폭을 제공하는 3D 스택 메모리.
- **메모리 벽(Memory Wall)**: 프로세서 연산 처리 속도의 발전 속도에 비해 외부 메모리 전송 대역폭이 따라가지 못해 전체 컴퓨팅 성능이 메모리에서 병목되는 현상.
- **실리콘 인터포저(Silicon Interposer)**: 로직 다이(GPU/NPU)와 HBM 스택 사이에 미세 피치 마이크로범프 배선을 형성하여 초광폭 병렬 신호 경로를 제공하는 2.5D 패키징 기판.

</details>

- 정의/개념: DRAM 다이를 TSV로 수직 적층하고 **실리콘 인터포저(2.5D)**를 통해 프로세서와 초광폭(1024비트+) 버스로 직결한 **고대역폭 메모리(HBM) 아키텍처**
- 배경/필요성: 기존 PCB 2D 평면 패키징 방식(GDDR/DDR)의 핀 수 한계로 인한 **메모리 벽(Memory Wall) 및 대규모 AI 학습/추론 연산 병목 극복**

#### 한줄 요약
- HBM은 DRAM을 수직 적층(TSV)하고 인터포저로 GPU와 직결하여 수 테라바이트급 초고대역폭을 구현하는 3D 메모리 패키징 기술이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **실리콘 관통 전극(Through-Silicon Via, TSV)**: 실리콘 다이를 수직으로 관통하는 마이크로미터 단위 전극을 형성하여 상하 적층 다이 간 최단 전기적 신호 경로를 제공하는 배선 기술.
- **광폭 인터페이스(Wide Interface)**: 1024비트 이상의 다수 데이터 핀을 병렬 연결하여 개별 핀의 동작 주파수를 낮추면서도 시스템 총 대역폭을 비약적으로 확장하는 인터페이스.
- **채널 인터리빙(Channel Interleaving)**: 메모리 주소를 여러 독립 채널에 분산 매핑하여 동시 병렬 전송 효율을 극대화하는 기법.

</details>

- 초고대역폭 및 저전력: **TSV** 수직 배선으로 연결 길이를 밀리미터 단위에서 마이크로미터 단위로 단축하여 기생 정전용량 감소 및 데이터 전송당 에너지(pJ/bit) 대폭 절감
- 초광폭 병렬 버스: 1024비트 이상의 **광폭 인터페이스(Wide Interface)**를 채택하여 낮은 핀 클록에서도 초당 수 테라바이트(TB/s)의 전송 대역폭 달성
- 폼팩터 소형화: 수직 3D 적층을 통해 2D 평면 실장 대비 메인보드 및 패키지 점유 면적(Footprint) 70% 이상 절감

#### 한줄 요약
- TSV 수직 적층과 1024비트 광폭 버스를 결합하여 전력 소모를 줄이면서 초당 테라바이트급 대역폭을 구현한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **베이스 다이(Base/Logic Die)**: HBM 스택 최하단에 위치하여 상단 DRAM 코어 다이들과 외부 호스트 간의 물리 계층(PHY), BIST 테스트, 채널 라우팅을 총괄하는 로직 칩.
- **마이크로범프(Microbump)**: 다이와 인터포저 또는 다이 간을 물리적·전기적으로 접합하는 초미세 솔더 볼.
- **DRAM 코어 다이(DRAM Core Die)**: 데이터 저장 셀 어레이와 TSV 전극을 포함하는 상부 수직 적층 메모리 다이 (4단, 8단, 12단, 16단 적층).

</details>

```text
[2.5D 이종 패키지 (SiP: System-in-Package)]
 ┌──────────────────────────┐               ┌──────────────────────────────────────────────┐
 │ [AI / GPU 로직 프로세서]  │               │ [HBM3 / HBM3E 스택 (3D Stack)]               │
 │ (연산 코어 + 메모리 컨트롤러)│               │  ├─ DRAM 코어 다이 #N (셀 어레이 + TSV)      │
 └─────────────┬────────────┘               │  ├─ DRAM 코어 다이 #1 (셀 어레이 + TSV)      │
               │ 마이크로범프                 │  └─ [베이스 로직 다이 (Base/Logic Die)]      │
 ┌─────────────┴────────────────────────────┴──────────────────────────────────────────────┐
 │ [실리콘 인터포저 (Silicon Interposer: 1024-bit+ 초광폭 미세 금속 배선)]                  │
 └──────────────────────────────────────────┬──────────────────────────────────────────────┘
                                            │ 패키지 기판 BGA
                                            ▼
                               [메인 PCB 시스템 보드]
```

선의 의미: 가지(`├─`, `└─`)는 하드웨어 소속 및 포함 관계; 실리콘 인터포저가 로직 칩과 HBM 스택 사이를 1024비트 광폭 배선으로 직결함

| 구성요소 | 소속 및 위치 | 핵심 엔지니어링 책임 | 주요 특징 |
|:---|:---|:---|:---|
| **GPU/AI 로직 다이** | 2.5D 패키지 상단 | 가속 연산 수행 및 HBM 채널별 메모리 트래픽 요청 | 대규모 병렬 연산 코어 집적 |
| **실리콘 인터포저** | 로직과 HBM 하단 | **마이크로범프**를 매개로 1024비트 초광폭 고밀도 신호선 제공 | 2.5D 미세 피치 배선 기판 |
| **베이스 다이** | HBM 스택 최하단 | 상단 DRAM 다이 TSV 라우팅, PHY 인터페이스, BIST 테스트 | 로직 제어 전담 다이 |
| **TSV 수직 전극** | DRAM 다이 관통 | 수직 적층된 다이 간의 고속 데이터/제어 신호선 직결 | 수천 개의 마이크로 관통로 |
| **DRAM 코어 다이** | HBM 스택 상부 | 4~16단 수직 적층으로 고집적 대용량 데이터 저장 | 1T1C 고속 DRAM 어레이 |

#### 한줄 요약
- HBM은 로직 다이, 실리콘 인터포저, 베이스 다이, 수직 적층 DRAM(TSV)이 단일 2.5D 패키지 안에서 결합된 고집적 시스템이다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **HBM 채널(HBM Channel)**: HBM 스택 내부에서 독립적으로 주소 지정 및 데이터 전송이 가능한 병렬 서브 인터페이스(HBM3 기준 16개 의사 채널).

</details>

```text
1. GPU/AI 코어의 대규모 텐서 데이터 읽기/쓰기 요청
                      │
                      ▼
2. 호스트 메모리 컨트롤러: 주소를 16개 독립 채널로 분산 스케줄링
                      │
                      ▼
3. 실리콘 인터포저를 통해 1024비트 광폭 병렬 명령/주소 신호 전송
                      │
                      ▼
4. HBM 베이스 다이 도달 ➔ 목적 채널 및 뱅크 어드레스 디코딩
                      │
                      ▼
5. TSV 수직 관통 전극을 통해 해당 DRAM 코어 다이로 데이터 접근
                      │
                      ▼
6. 1024비트 광폭 버스로 데이터 일괄 인출 ➔ 인터포저 경유 ➔ GPU 코어로 초고속 공급 (1TB/s+)
```

분기 결과: **요청이 16개 채널에 고르게 분산되면** 모든 채널이 동시 동작하여 최대 대역폭이 실현되며, **단일 채널 집중 시** 병렬 전송 효율이 저하됨

#### 한줄 요약
- 요청이 메모리 컨트롤러에서 16개 채널로 분산되어 인터포저와 TSV를 거쳐 DRAM에 도달하고, 광폭 버스로 GPU에 초고속 반환된다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **GDDR(Graphics DDR)**: 32비트 협폭 버스에 초고주파 클록을 인가하여 기판 레벨에서 대역폭을 구현한 그래픽 메모리.
- **표준 DDR5**: 탈착식 DIMM 모듈 기반으로 대용량 확장에 최적화된 표준 시스템 메모리.

</details>

| 비교 항목 | HBM (HBM3 / HBM3E) | GDDR (GDDR6 / GDDR7) | 표준 DDR (DDR5) |
|:---|:---|:---|:---|
| 패키징 방식 | **2.5D 실리콘 인터포저 수직 3D 적층** | 표준 PCB 평면 실장 (2D 패키징) | 표준 DIMM 슬롯 모듈 (2D) |
| 버스 폭 (Bus Width)| **1024-bit (초광폭 버스)** | 32-bit (협폭 버스) | 64-bit (채널당 32-bit $\times 2$) |
| 핀당 전송 속도 | 상대적 낮음 ($6.4\sim 9.6\text{ Gbps}$) | **매우 높음 ($24\sim 32\text{ Gbps}$)** | 중간 ($4.8\sim 8.4\text{ Gbps}$) |
| 스택/칩당 대역폭 | **$819\text{ GB/s} \sim 1.2\text{ TB/s}$ (초고대역폭)** | $96\sim 128\text{ GB/s}$ | $38.4\sim 67.2\text{ GB/s}$ |
| 전력 효율 (pJ/bit) | **매우 우수 (최저 에너지 소모)** | 높음 (고주파 구동 전력 증가) | 보통 |
| 제조 비용 및 확장성 | **고비용, 패키지 봉인 (사후 증설 불가)** | 중간, 고정 용량 | **저비용, 자유로운 용량 증설** |

#### 한줄 요약
- 초고대역폭과 에너지 효율이 최우선이면 HBM, 비용과 대역폭의 절충에는 GDDR, 대용량 확장성에는 표준 DDR5가 선택 기준이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **양품 다이(Known Good Die, KGD)**: 적층 패키징 전에 100% 정상 동작이 검증된 베어 다이(Die).
- **직접 칩 냉각(Direct-to-Chip Liquid Cooling)**: 고발열 2.5D 패키지 표면에 수랭식 콜드 플레이트를 밀착시켜 냉각하는 기술.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 적층 다이 중 1개 불량 시 패키지 전체가 폐기되는 수율 위험 | **KGD(Known Good Die) 선별 시험 및 베이스 다이 내 리던던시 TSV** 배치 | 적층 패키징 수율 90% 이상 확보 |
| 로직 칩과 다층 HBM 스택의 고밀도 집적으로 인한 열 집중 | **MR-MUF(액체 에폭시 몰딩) 공정 및 직접 칩 수랭 냉각** 적용 | 열 저항 40% 감소 및 발열 스로틀링 방지 |
| 고정 패키지 용량 한계로 인한 초대형 LLM 모델 적재 부족 | **CXL 기반 확장 메모리(CXL Memory Expander)** 하이브리드 연계 | HBM(고대역폭) + CXL(대용량) 계층화 메모리 구축 |

#### 한줄 요약
- 실무에서는 KGD 검사와 리던던시 TSV로 수율을 방어하고, MR-MUF 공정과 수랭식 쿨링으로 발열을 제어하며, CXL로 용량을 확장한다.

## Ⅶ. 결론

- AI 대규모 언어 모델(LLM) 및 고성능 슈퍼컴퓨팅의 메모리 벽을 극복하기 위해 **TSV 수직 적층과 2.5D 인터포저 기반의 HBM3/HBM3E를 가속기 패키지에 표준 적용**하고, 패키징 수율과 발열 문제를 통제하기 위해 **KGD 검증 체계와 첨단 방열 패키징(MR-MUF) 기술**을 채택하며, 용량 한계는 **CXL 메모리 계층과 융합**하는 고성능 컴퓨팅 아키텍처 확립

#### 한줄 요약
- HBM은 AI 반도체 성능을 결정하는 초고대역폭 핵심 메모리이며, 첨단 3D 패키징과 방열 기술의 융합이 상용화의 핵심이다.
