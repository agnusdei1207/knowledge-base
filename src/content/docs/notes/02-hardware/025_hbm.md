## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **고대역폭 메모리(High Bandwidth Memory, HBM)**: TSV(Through-Silicon Via)를 이용해 DRAM 다이를 수직 적층하고 실리콘 인터포저를 통해 GPU와 결합하는 2.5D 패키징 메모리.
- **메모리 벽(Memory Wall)**: 프로세서 연산 속도 증가율에 비해 메모리 대역폭 증가율이 뒤처져 전체 시스템 성능이 정체되는 병목 현상.
- **2.5D SiP(System-in-Package)**: 실리콘 인터포저 기판 위에 로직 다이(GPU)와 HBM 스택을 나란히 배치하여 초미세 배선으로 연결하는 첨단 패키징.

</details>

- 정의/개념: TSV(Through-Silicon Via) 기반으로 DRAM 다이를 수직 적층하고 실리콘 인터포저를 통해 1024비트 이상의 광폭 버스로 GPU/NPU와 2.5D 패키징 결합하는 고대역폭 메모리
- 배경/필요성: 거대언어모델(LLM) 및 AI 연산 폭증에 따른 **폰 노이만 메모리 벽(Memory Wall)을 타파하고 TB/s급 초고대역폭 및 저전력 전송 확보**

#### 한줄 요약

- **TSV 3D 수직 적층과 1024비트 인터포저 광폭 버스**로 TB/s급 대역폭 실현

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **TSV(Through-Silicon Via)**: 실리콘 웨이퍼를 수천 개의 미세 구멍으로 관통하여 상하 다이 간 전기적 신호를 직결하는 수직 배선 기술.
- **초광폭 인터페이스(1024-bit Wide I/O)**: 32비트/64비트 일반 메모리와 달리 1024개의 데이터 핀을 동시에 병렬 구동하는 인터페이스.

</details>

- **실리콘 관통 전극(TSV)** 적용을 통한 신호 배선 거리 극단적 단축 및 **I/O 구동 전력(pJ/bit)** 대폭 절감
- 1024비트 광폭 물리 인터페이스를 채택하여 핀당 주파수 부담 없이 스택당 1TB/s 이상의 초고대역폭 달성
- 복수의 독립 채널(16채널) 구성과 의사 채널(Pseudo Channel) 분할을 통한 뱅크 병렬성 극대화

#### 한줄 요약

- 1024비트 광폭 인터페이스와 TSV 수직 배선으로 **저전력 초고대역폭(TB/s)** 달성

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **베이스 다이(Base/Logic Die)**: HBM 스택 최하단에 위치하여 DRAM 코어 다이들의 신호 라우팅, BIST(내장 자체 시험), DFI 인터페이스를 총괄하는 로직 칩.
- **실리콘 인터포저(Silicon Interposer)**: 서브스트레이트 위에 올려져 GPU와 HBM 간에 수만 개의 초미세 배선을 형성하는 고밀도 연결 기판.

</details>

```text
[ 2.5D 시스템 인 패키지 (CoWoS / I-Cube) 아키텍처 ]
┌───────────────────────────┬─────────────────────────────────┐
│     인공지능 가속기       │     HBM 다이 스택 (4~16층)      │
│     (GPU / NPU Logic)     │  ├─ DRAM 코어 다이 3 (TSV 관통) │
│                           │  ├─ DRAM 코어 다이 2 (TSV 관통) │
│                           │  ├─ DRAM 코어 다이 1 (TSV 관통) │
│                           │  └─ 베이스 다이 (Base Logic)    │
└─────────────┬─────────────┴────────────────┬────────────────┘
              │ [마이크로범프]               │ [마이크로범프]
══════════════╧══════════════════════════════╧═════════════════ (실리콘 인터포저: 1024-bit)
              │ [C4 범프]
─────────────────────────────────────────────────────────────── (패키지 기판 서브스트레이트)
              │ [BGA Ball]
                      메인보드 PCB
```

선의 의미: GPU 연산 다이, 실리콘 인터포저, 베이스 다이 및 TSV 적층 DRAM 코어로 구성된 2.5D SiP 아키텍처.

| 구성요소 | 책임 |
|:---|:---|
| 다이 스택 (DRAM Layers) | 실리콘 관통 전극(TSV) 기반의 수직 대용량 메모리 저장 공간 |
| 베이스 다이 (Base Die) | 신호 라우팅, 온다이 ECC, 인터포저 인터페이스 물리 계층 제어 |
| 실리콘 인터포저 | GPU와 HBM 베이스 다이 간의 광폭 1024비트 초미세 배선 제공 |
| 마이크로범프 | 상하 다이 및 인터포저 간의 수직 전기적 접합 및 기계적 체결 |

#### 한줄 요약

- **다이 스택(Core DRAM)·베이스 다이(Logic)·실리콘 인터포저(1024bit)** 통합

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **채널 인터리빙(Channel Interleaving)**: 연속된 메모리 주소를 여러 HBM 독립 채널에 분산하여 동시 병렬 읽기/쓰기를 유도하는 스케줄링.

</details>

```text
[ GPU 텐서 코어 메모리 읽기 요청 ]
                │
                ▼
[ 1. 메모리 컨트롤러 채널 인터리빙 분산 ]
                │ (독립 16개 채널 매핑)
                ▼
[ 2. 인터포저 1024-bit 광폭 병렬 전송 ]
                │
                ▼
[ 3. HBM 베이스 다이 디코딩 및 TSV 라우팅 ]
                │
                ▼
[ 4. 목표 층(Layer) DRAM 뱅크 데이터 활성화 ]
                │
                ▼
[ 5. TSV 수직 경로 및 인터포저 경유 GPU 버스트 반환 ]
```

**동작 원리**

1. **주소 분산**: GPU 메모리 컨트롤러가 트랜잭션을 16개 독립 채널 및 뱅크 그룹으로 인터리빙
2. **광폭 전송**: 1024개 인터포저 배선을 통해 낮은 클록 주파수로 동시 다량 데이터 송신
3. **수직 인출**: 베이스 다이가 수직 TSV 채널을 구동하여 지정된 적층 층수의 DRAM 셀에서 데이터 인출
4. **버스트 반환**: 인출된 고용량 데이터가 지연 없이 GPU 텐서 코어로 초고속 반환 완료

#### 한줄 요약

- 채널 인터리빙 후 **인터포저와 TSV 수직 전극을 통한 1024bit 광폭 동시 전송**

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **HBM vs GDDR vs DDR**:
  - HBM: 1024-bit, 3D/2.5D 적층, 최고 대역폭(TB/s), 최고가
  - GDDR: 32-bit, 고주파수(20+ Gbps), 고대역폭(100+ GB/s), 고발열
  - DDR: 64-bit, 대용량 DIMM 소켓, 범용 시스템 메모리

</details>

| 비교 항목 | 고대역폭 메모리 (HBM3/HBM3E) | 그래픽스 메모리 (GDDR6/GDDR7) | 메인 메모리 (DDR5) |
|:---|:---|:---|:---|
| 물리 아키텍처 | 3D TSV 수직 적층 + 2.5D 실리콘 인터포저 SiP | PCB 표면 실장 2D 평면 패키징 (BGA) | 마더보드 DIMM 슬롯 2D 평면 소켓 실장 |
| 버스 폭 및 대역폭 | 1024-bit 초광폭 버스 (스택당 1~1.2TB/s) | 32-bit 협폭 고주파수 버스 (칩당 80~128GB/s) | 64-bit 채널 (모듈당 38~51GB/s) |
| 한계 및 위험 | 높은 제조 단가, 2.5D 패키징 수율(KGD), 발열 집중 | 핀당 고주파수로 인한 전력 소모 및 신호 무결성 한계 | 낮은 대역폭으로 AI/가속기 연산 처리 불가 |

#### 한줄 요약

- HBM은 **초광폭 초고대역폭(AI/GPU)**, GDDR은 **협폭 고주파수(그래픽)**, DDR은 **대용량 확장**

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **KGD(Known Good Die)**: 적층 전 개별 다이 상태에서 완벽한 테스트를 통과한 양품 칩만을 선별하여 적층 수율을 방어하는 공정.
- **직접 액체 냉각(Direct-to-Chip Liquid Cooling)**: HBM과 GPU의 고밀도 집적 핫스팟을 식히기 위해 냉각판(Cold Plate)을 칩에 직접 부착하는 냉각 체계.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 단일 층의 미세 결함만으로도 칩 전체를 버려야 하는 **적층 수율** 저하 | 사전에 엄격한 **양품 다이** 선별 보장 및 예비 경로 여분 내장 | 결함 조기 차단 및 최종 스택 패키징 제조 수율 극대화 |
| 가속기와 메모리 근접 밀집 패키징으로 인한 국부 핫스팟 초고밀도 발열 | 특수 방열 소재 적용 및 고성능 **액체 냉각** 시스템 직결 연동 | 치명적 열 스로틀링 파동 차단 및 100% 지속 연산 성능 확보 |
| 특정 채널로의 인공지능 메모리 주소 쏠림으로 인한 실효 대역폭 포화 | 메모리 컨트롤러 내부의 다중 채널 주소 인터리빙 최적화 분산 적용 | 다중 채널 균등 병렬 접근 보장 및 총 실효 대역폭 최고점 달성 |
| 수천 개 관통 단자 연결 손상 시 칩 폐기로 직결되는 치명적 비트 오류 | 온다이 오류 정정 코드 하드웨어 내장 및 물리적 **오류 격리** 우회 | 데이터 무결성 상시 보장 및 시스템 다운으로 인한 훈련 정지 방지 |

#### 한줄 요약

- **KGD 선별·직접 수랭(Liquid Cooling)·채널 인터리빙·On-die ECC**로 수율/발열 극복

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **HBM4 진화**: 베이스 다이를 4nm/3nm 파운드리 첨단 로직 공정으로 제작하고, 2048비트 인터페이스를 도입하여 GPU와 직접 3D 적층(Direct Bonding)으로 진화.

</details>

- AI 가속기 및 HPC 시스템의 메모리 벽 타파를 위한 **HBM3E/HBM4 및 3D 직접 적층(CoWoS) 표준 채택**

#### 한줄 요약

- **대역폭·전력 효율·패키징 수율**을 절충한 AI 인프라 핵심 메모리 아키텍처
