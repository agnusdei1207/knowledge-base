## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **고대역폭 메모리(High Bandwidth Memory, HBM)**: DRAM 다이를 수직으로 쌓고 넓은 인터페이스로 로직과 연결한 메모리입니다.
- **메모리 벽(Memory Wall)**: 프로세서 연산 속도에 비해 메모리 데이터 공급이 느려 성능이 제한되는 현상입니다.
- **실리콘 인터포저(Silicon Interposer)**: 로직 다이와 HBM 스택 사이에 고밀도 배선을 제공하는 패키지 기판입니다.

</details>

- 정의/개념: 적층 DRAM과 광폭 인터페이스를 결합한 **고대역폭 메모리 구조**
- 배경/필요성: AI·HPC 가속기의 메모리 벽과 데이터 공급 병목 완화

#### 한줄 요약

- HBM은 메모리 칩을 높이 쌓고 가속기 가까이에 넓은 데이터 길을 놓아, 많은 데이터를 한 번에 전달하는 구조입니다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **실리콘 관통 전극(Through-Silicon Via, TSV)**: 다이를 수직으로 관통해 상하 칩의 전기 신호를 연결하는 배선입니다.
- **광폭 인터페이스(Wide Interface)**: 많은 데이터 선을 병렬로 사용해 핀당 속도 부담을 낮추는 인터페이스입니다.
- **채널 인터리빙(Channel Interleaving)**: 요청을 여러 독립 채널에 분산해 병렬 전송을 유도하는 방식입니다.

</details>

- TSV 기반 **수직 적층**
- 광폭 인터페이스 기반 **전송 대역폭 확대**
- 채널 인터리빙 기반 **병렬 메모리 접근**

#### 한줄 요약

- HBM은 한 선을 극도로 빠르게 달리는 대신 여러 선을 동시에 사용하고, 여러 채널에 요청을 분산해 대역폭을 높입니다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **베이스 다이(Base Die)**: HBM 스택 하단에서 DRAM 다이와 외부 로직 사이의 신호·명령 연결을 담당하는 다이입니다.
- **마이크로범프(Microbump)**: 다이와 인터포저를 전기적·기계적으로 연결하는 미세 접합부입니다.
- **DRAM 코어 다이(DRAM Core Die)**: 실제 메모리 셀 배열을 포함하는 HBM 적층 다이입니다.

</details>

```text
[가속기 패키지]
├─ AI·GPU 로직 다이
├─ 실리콘 인터포저
└─ HBM 스택
   ├─ DRAM 코어 다이
   ├─ TSV
   └─ 베이스 다이
```

| 구성요소 | 책임 |
|:---|:---|
| 로직 다이 | 메모리 요청과 가속 연산 수행 |
| 실리콘 인터포저 | 로직·HBM 사이 광폭 배선 제공 |
| DRAM 코어 다이 | 대용량 데이터 저장 |
| TSV | 적층 다이 사이 수직 신호 전달 |
| 베이스 다이 | 외부 인터페이스와 적층 다이 연결 |

#### 한줄 요약

- HBM은 가속기와 인터포저, 베이스 다이, 여러 DRAM 다이가 하나의 고밀도 패키지에서 협력하는 구조입니다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **메모리 컨트롤러(Memory Controller)**: 가속기 메모리 요청을 채널과 뱅크에 배치하는 제어기입니다.
- **버스트 전송(Burst Transfer)**: 연속 데이터를 한 요청으로 묶어 전송하는 방식입니다.

</details>

```text
[1. 가속기 메모리 요청]
          │
          ▼
[2. 채널·뱅크 인터리빙]
          │
          ▼
[3. 인터포저·TSV 병렬 전송]
          │
          ▼
[4. DRAM 데이터 버스트 반환]
```

동작 원리:

1. 가속기 메모리 요청: 연산 유닛이 필요한 데이터 요청
2. 채널·뱅크 인터리빙: 주소를 병렬 채널과 뱅크에 분산
3. 인터포저·TSV 병렬 전송: 넓은 연결망으로 데이터 이동
4. DRAM 데이터 버스트 반환: 적층 DRAM에서 연속 데이터를 반환

#### 한줄 요약

- 요청을 여러 채널에 나누고 넓은 배선과 수직 연결로 동시에 옮기므로, 대규모 가속 연산의 데이터 공급이 빨라집니다.

## Ⅴ. 종류 및 비교

| 메모리 유형 | HBM | GDDR | DDR |
|:---|:---|:---|:---|
| 적용 기준 | 가속기·HPC의 대역폭 우선 | 그래픽의 대역폭·비용 균형 | 범용 시스템의 용량·확장성 |
| 핵심 특징 | 적층 DRAM과 광폭 인터페이스 | 협폭 고속 인터페이스 | DIMM 기반 범용 메모리 |
| 한계 | 패키징·열·비용 부담 | 신호·전력 부담 | 가속기 대역폭 병목 가능성 |

#### 한줄 요약

- 가속기 가까이에서 대역폭이 가장 중요하면 HBM, 범용 확장성과 비용이 중요하면 DDR, 그래픽 균형은 GDDR을 선택합니다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **양품 다이(Known Good Die, KGD)**: 적층 전에 시험을 통과해 정상 동작이 확인된 다이입니다.
- **직접 칩 냉각(Direct-to-Chip Liquid Cooling)**: 냉각판과 냉각 유체로 고밀도 패키지의 열을 직접 제거하는 방식입니다.
- **메모리 신뢰성·가용성·서비스성(Reliability, Availability, Serviceability, RAS)**: 오류 검출, 격리, 복구를 포함하는 시스템 신뢰성 설계입니다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 적층 다이 결함으로 패키지 수율 저하 | KGD 선별과 적층 전후 시험 적용 | 결함 조기 검출과 수율 향상 |
| 가속기와 HBM 집중 발열 | 패키지 열 설계와 직접 칩 냉각 검토 | 열 제한과 성능 저하 완화 |
| 특정 채널 요청 쏠림 | 채널 인터리빙과 주소 배치 조정 | 유효 대역폭 향상 |
| 적층 연결·메모리 오류 발생 | ECC와 RAS 기능의 보장 범위 검증 | 검출·정정 가능한 오류의 신뢰성 확보 |

#### 한줄 요약

- HBM의 대역폭만 보는 것이 아니라 적층 수율, 열 제거, 채널 균형, 오류 처리까지 제품 수준에서 함께 확인해야 합니다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **메모리 대역폭 요구량(Memory Bandwidth Demand)**: 가속 작업이 단위 시간에 필요로 하는 데이터 전송량입니다.

</details>

- **메모리 대역폭 요구량**이 병목이고 패키징·열 비용을 감당할 수 있으면 HBM을 선택하며, 용량 확장과 비용이 우선이면 DDR·GDDR을 비교해 결정

#### 한줄 요약

- HBM은 무조건 빠른 메모리가 아니라, 가속기가 실제로 요구하는 대역폭이 패키지와 냉각 비용을 정당화할 때 선택하는 메모리입니다.
