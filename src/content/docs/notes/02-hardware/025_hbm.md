## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **고대역폭 메모리(High Bandwidth Memory)**: 다이들을 수직 적층하고 실리콘 인터포저 기반의 광폭 버스를 통해 가속기와 결합되는 초고속 메모리 아키텍처이다.
- **동적 램(Dynamic Random-Access Memory)**: 커패시터 전하 저장 기반의 초고밀도 휘발성 반도체이다.
- **메모리 장벽(Memory Wall)**: 연산 속도 폭증 대비 데이터 전송 대역폭 확장이 뒤처져 가속기가 멈춰 서는 병목 현상이다.

</details>

- 정의: 실리콘 관통 전극을 활용하여 동적 램을 적층하고 광폭 입출력 경로로 가속기와 결합하는 초고속 **고대역폭 메모리**
- 배경: 인공지능 훈련 시 발생하는 극심한 **메모리 장벽**을 해소하기 위해 테라바이트급 초고대역폭이 필수적이기 때문임

#### 한줄 요약

- 수직 적층 및 초광폭 인터포저 패키징을 기반으로 가속기와 최단 거리로 결합하여 대역폭 한계를 돌파하는 인공지능 전용 메모리이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **실리콘 관통 전극(Through-Silicon Via)**: 다이를 수직으로 수천 개 관통하는 초미세 구리 단자를 형성하여 층간 신호를 연결하는 배선 기술이다.
- **채널 수(Channel Count)**: 스택 내부에 구성된 독립적인 메모리 인터페이스 전송 경로의 총 개수이다.
- **채널 폭(Channel Width)**: 한 채널이 한 번에 병렬 전송하는 데이터 비트 수이다.
- **핀 전송률(Pin Transfer Rate)**: 입출력 핀 1개가 초당 쏘아 보내는 데이터 전송 수치이다.
- **입출력 전력(I/O Power)**: 초고속 신호 구동 시 패키징 신호선에서 소모되는 전력으로, 배선이 짧아질수록 극적으로 감소한다.

</details>

- **실리콘 관통 전극**을 적용하여 신호 배선 거리를 단축함으로써 신호 감쇄를 줄이고 **입출력 전력** 소모량을 최소화함.
- 1024비트 광폭 물리 인터페이스를 채택하여 핀당 주파수를 과도하게 올리지 않고도 초당 수 테라바이트급 대역폭을 달성함.
- **채널 수**, **채널 폭** 및 **핀 전송률**의 곱셈 연산으로 이론적인 전체 전송 대역폭 크기가 결정됨.

#### 한줄 요약

- 수직 배선 기술과 초광폭 패키징을 결합하여 핀 전송률 한계를 우회하며, 저전력으로 수 테라바이트급 대역폭을 실현한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **다이 스택(Die Stack)**: 4층, 8층, 12층 등으로 수직으로 겹겹이 쌓아 올린 동적 램 코어 모듈 덩어리이다.
- **베이스 다이(Base Die)**: 스택 가장 하단에 배치되어 수직 신호를 수집 및 제어하고 온다이 오류 회로를 내장한 마이크로 로직 기판이다.
- **실리콘 인터포저(Silicon Interposer)**: 가속기 칩과 메모리 스택 사이에 초미세 배선을 형성해 주는 고정밀 서브스트레이트 매개 기판이다.
- **마이크로범프(Microbump)**: 다이 및 베이스 다이 간의 전기적 물리 접합을 매개하는 정밀 땜납 범프 기술이다.

</details>

```text
[ 2.5D 시스템 인 패키지 아키텍처 ]
+-------------------------------------------------------------+
| [ 인공지능 가속기 ]       | [ 다이 스택 (4~16 코어 층) ]    |
| (논리 연산 코어 다이)     |  ├─ 코어 다이 3 (수직 전극)     |
|                           |  ├─ 코어 다이 2 (수직 전극)     |
|                           |  ├─ 코어 다이 1 (수직 전극)     |
|                           |  └─ 베이스 다이 (로직 버퍼)     |
+---------------------------+---------------------------------+
|             [ 실리콘 인터포저 기판 (1024비트) ]             |
+-------------------------------------------------------------+
|             [ 메인 패키지 기판 및 BGA 볼 ]                  |
+-------------------------------------------------------------+
```

| 구성요소 | 책임 |
|:---|:---|
| **다이 스택** | 실리콘 관통 전극 기반의 수직 대용량 메모리 적층 공간 제공 |
| **베이스 다이** | 신호 라우팅 및 테스트, 인터포저 연결을 위한 물리 계층 제어 |
| **실리콘 인터포저** | 가속기와 메모리 베이스 간의 광폭 1024비트 초미세 배선 제공 |
| **마이크로범프** | 다이 상호 간의 수직 전기적 신호 연결 및 기계적 물리 접합 제공 |

#### 한줄 요약

- 코어 다이 스택, 베이스 다이, 그리고 실리콘 인터포저가 수직 전극과 범프로 긴밀히 결합하여 단일 패키지를 형성한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **메모리 컨트롤러(Memory Controller)**: 가속기 내부에 배치되어 채널로 주소를 분산하고 버스트 전송을 스케줄링하는 유닛이다.
- **광폭 입출력(Wide I/O PHY)**: 인터포저 상의 1024개 물리 데이터 라인을 타고 초고속으로 데이터를 송수신하는 반도체 물리 계층이다.

</details>

```text
[ 텐서 연산 코어 데이터 접근 요청 ]
                │
                ▼
      [ 1. 채널 주소 인터리빙 ]
                │ (독립 채널로 분산)
                ▼
    [ 2. 인터포저 광폭 전송 대기열 ]
                │
                ▼
        [ 3. 베이스 다이 라우팅 ]
                │
                ▼
 [ 4. 수직 전극 매개 메모리 뱅크 접근 ]
                │
                ▼
       [ 5. 광폭 버스트 데이터 반환 ]
```

### 동작 원리

1. 주소 인터리빙: 컨트롤러가 요청을 독립 채널과 뱅크 단위로 스케줄링 분산함.
2. 광폭 전송: **광폭 입출력**을 거쳐 인터포저를 타고 베이스 다이로 전달함.
3. 라우팅 및 접근: 베이스 다이에서 목표 수직 경로로 연결하여 데이터를 읽음.
4. 데이터 반환: 인출된 데이터가 1024비트 광폭 경로를 통해 가속기에 즉시 반환됨.

#### 한줄 요약

- 채널 인터리빙을 거쳐 광폭 인터포저를 통과한 요청이 베이스 다이와 수직 전극을 타고 뱅크에 도달한 뒤 데이터를 폭포수처럼 반환한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **그래픽스 더블 데이터 레이트(Graphics DDR)**: 인쇄 회로 기판 상에 배치되며 협폭 핀의 주파수를 극도로 올려 속도를 내는 전통적 그래픽 메모리이다.
- **적층 수율(Stack Yield)**: 다이를 쌓아 올릴 때 단 하나의 층 결함만 있어도 스택 전체를 폐기해야 하는 치명적인 제조 수율 리스크이다.
- **신호 무결성(Signal Integrity)**: 고주파 전송 시 핀 신호 상호 간섭 및 반사파로 인해 발생할 수 있는 데이터 신호 왜곡 성질이다.

</details>

| 비교 항목 | 고대역폭 메모리 (HBM) | 그래픽스 메모리 (GDDR) |
|:---|:---|:---|
| 패키징 아키텍처 | 3D 수직 적층 및 2.5D **실리콘 인터포저** 초근접 결합 | 인쇄 회로 기판 보드 표면 상에 2D 개별 칩 분산 배치 |
| 물리적 버스 폭 | 초당 1024비트를 동시에 전송하는 초광폭 버스 인터페이스 | 칩당 32비트씩만 전송하는 전통적인 협폭 버스 인터페이스 |
| 핀당 동작 속도 | 클록 주파수가 수 기가비트 수준으로 상대적으로 낮음 | 핀당 주파수를 수십 기가비트로 극도로 높여 한계를 보완함 |
| 패키지당 대역폭 | 스택 1개당 초당 수 테라바이트급의 막강한 초고대역폭 제공 | 칩 1개당 수십 기가바이트 수준의 일반적인 대역폭 제공 |
| 전력 효율 및 단가 | 전력 효율이 매우 뛰어나나 **적층 수율** 한계로 단가 고가 | 상대적으로 전력 소모가 크나 제조 패키징 단가는 저렴함 |

#### 한줄 요약

- 고대역폭 메모리는 제조 단가가 높지만 초광폭 패키징으로 대역폭을 평정했으며, 그래픽스 메모리는 저비용 대량 양산에 유리하다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **양품 다이(Known Good Die)**: 수직 적층 이전에 각 웨이퍼 다이가 정상 작동하는지 사전 정밀 검사하여 양품만 선별하는 절차이다.
- **액체 냉각(Liquid Cooling)**: 가속기와 메모리 패키지에 워터블록을 장착하여 고열을 식혀주는 직접 방식의 고성능 냉각 시스템이다.
- **오류 격리(Error Isolation)**: 특정 채널이나 배선에 결함 발생 시 예비 배선으로 전환하거나 해당 채널만 안전하게 차단하는 기술이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 단일 층의 미세 결함만으로도 칩 전체를 버려야 하는 **적층 수율** 저하 | 사전에 엄격한 **양품 다이** 선별 보장 및 예비 경로 여분 내장 | 결함 조기 차단 및 최종 스택 패키징 제조 수율 극대화 |
| 가속기와 메모리 근접 밀집 패키징으로 인한 국부 핫스팟 초고밀도 발열 | 특수 방열 소재 적용 및 고성능 **액체 냉각** 시스템 직결 연동 | 치명적 열 스로틀링 파동 차단 및 100% 지속 연산 성능 확보 |
| 특정 채널로의 인공지능 메모리 주소 쏠림으로 인한 실효 대역폭 포화 | 메모리 컨트롤러 내부의 다중 채널 주소 인터리빙 최적화 분산 적용 | 다중 채널 균등 병렬 접근 보장 및 총 실효 대역폭 최고점 달성 |
| 수천 개 관통 단자 연결 손상 시 칩 폐기로 직결되는 치명적 비트 오류 | 온다이 오류 정정 코드 하드웨어 내장 및 물리적 **오류 격리** 우회 | 데이터 무결성 상시 보장 및 시스템 다운으로 인한 훈련 정지 방지 |

#### 한줄 요약

- 선별적 양품 적층과 예비 경로로 수율을 잡고, 인터리빙 분산과 강력한 직접 냉각을 통해 초고대역폭의 안정성을 사수한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **메모리 아키텍처 선택 기준(Memory Architecture Selection Criteria)**: 언어모델 훈련 파라미터 용량, 연산 속도 요구, 패키징 예산을 종합 평가하여 칩 탑재 규격을 선택하는 프레임워크이다.

</details>

- 대규모 인공지능 훈련에는 **고대역폭 메모리**, 비용 효율 및 그래픽 처리에는 **그래픽스 메모리**를 선택함

#### 한줄 요약

- 연산 장벽 해소를 위해 필수불가결한 수직 적층 메모리 기술의 열 및 비용 단점을 면밀히 분석하고 도입을 최적화해야 한다.
