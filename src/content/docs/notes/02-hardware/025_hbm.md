## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **고대역폭 메모리(High Bandwidth Memory, HBM)**: DRAM 다이를 적층하고 광폭 인터페이스로 연결한 메모리.
- **DRAM(Dynamic Random-Access Memory)**: 전하 셀을 사용하는 동적 메모리.
- **메모리 장벽(Memory Wall)**: 연산 성능보다 데이터 공급 속도가 느려 연산 유닛이 대기하는 병목.

</details>

- 정의/개념: 여러 DRAM 다이를 수직 적층하고 가속기와 광폭 인터페이스로 연결하는 **HBM**
- 배경/필요성: AI 및 고성능 연산 장치의 전송 요구량 대비 기존 DDR 패키징의 핀 수와 신호 대역폭 확장 한계로 **메모리 장벽** 발생

#### 한줄 요약

- HBM은 가속기 가까이에 적층 DRAM과 광폭 인터페이스를 배치해 연산 유닛에 공급하는 데이터 대역폭을 높인다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **채널 병렬성(Channel-Level Parallelism)**: 독립 전송 경로에 요청을 분산해 동시에 처리하는 성질.
- **뱅크 병렬성(Bank-Level Parallelism)**: 독립 셀 배열에 요청을 분산해 동시에 처리하는 성질.
- **핀 전송률(Pin Transfer Rate)**: 신호 핀 하나가 초당 전송하는 데이터량.
- **실효 대역폭(Effective Bandwidth)**: 주소 편향과 프로토콜 오버헤드를 반영해 워크로드가 얻는 전송량.
- **실리콘 관통 전극(Through-Silicon Via, TSV)**: 적층 다이를 수직으로 관통해 신호와 전력을 전달하는 미세 배선.
- **I/O 전력(I/O Power)**: 메모리 인터페이스 신호 구동과 수신에 소비되는 전력.
- **채널 수(Channel Count)**: 독립적으로 명령과 데이터를 처리할 수 있는 메모리 전송 경로의 개수.
- **채널 폭(Channel Width)**: 채널이 한 데이터 전송 시점에 병렬로 전달하는 비트 수.
- **주소 분산(Address Interleaving)**: 연속 요청이 특정 채널과 뱅크에 몰리지 않도록 주소를 여러 경로에 배정하는 방법.

</details>

- **채널 수**·**채널 폭**·**핀 전송률**의 곱으로 이론 총대역폭 결정
- 짧은 신호 거리와 낮은 **I/O 전력**을 만드는 **TSV** 적층 구조
- 요청의 **주소 분산**으로 **채널 병렬성**•**뱅크 병렬성**과 **실효 대역폭** 확보

$$
Bandwidth_{theoretical} = \frac{N_{channel} \times W_{channel} \times R_{pin}}{8}
$$

> 채널 폭을 비트 단위로 넣으면 8로 나눈 결과는 초당 바이트 단위의 이론 대역폭

#### 한줄 요약

- 이론 대역폭이 높아도 요청이 일부 경로에 몰리면 채널·뱅크 병렬성이 떨어지므로 주소 분산이 실효 대역폭을 좌우한다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **DRAM 다이 스택(DRAM Die Stack)**: 여러 DRAM 다이를 수직 적층해 용량과 병렬 채널을 제공하는 구조.
- **베이스 다이(Base Die)**: TSV 신호를 외부 메모리 채널로 중계하는 하단 다이.
- **실리콘 인터포저(Silicon Interposer)**: HBM 스택과 가속기를 짧고 넓은 배선으로 연결하는 기판.

</details>

```text
       [DRAM 다이 스택]
               |
       [TSV•다이 접합]
               |
          [베이스 다이]
               |
       [실리콘 인터포저] -- [가속기]
```

선의 의미: DRAM 적층부에서 베이스 다이와 패키지 인터포저까지 수직•수평 배선 계층이 결합된 정적 패키지 구조.

| 구성요소 | 책임 |
|:---|:---|
| DRAM 다이 스택 | 수직 적층 저장 공간 제공 |
| TSV•다이 접합 | 층간 신호•전력 경로 제공 |
| 베이스 다이 | 채널 신호 중계•분배 |
| 실리콘 인터포저 | 가속기•스택 광폭 연결 |

#### 한줄 요약

- TSV는 적층 다이를 연결하고 인터포저는 HBM 스택과 가속기를 광폭으로 연결한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **HBM 컨트롤러(HBM Controller)**: 주소를 채널•뱅크로 나누고 병렬 명령을 스케줄링하는 회로.
- **버스트 데이터(Burst Data)**: 한 메모리 명령으로 연속해서 반환되는 데이터 묶음.
- **광폭 I/O(Wide I/O)**: 많은 배선을 병렬 사용해 대역폭을 높이는 인터페이스.
- **물리 계층(Physical Layer, PHY)**: 디지털 데이터를 패키지 배선의 전기 신호로 변환하는 회로.

</details>

```text
                    [가속기 메모리 요청]
                              |
                   1. 채널•뱅크 매핑
                              |
                   2. 병렬 채널 명령 분배
                       /              \
                  [채널 0]          [채널 N]
                       \              /
                    [인터포저•광폭 PHY]
                              |
                   3. 베이스 다이•TSV 분배
                              |
                    [DRAM 다이•뱅크]
                              |
                   4. 뱅크 판독•버스트 전송
                              |
                    [가속기 데이터 반환]
```

### 동작 원리

1. **채널·뱅크 매핑**: 요청 주소를 병렬 처리할 HBM 채널과 뱅크에 배정.
2. **병렬 명령 분배**: **HBM 컨트롤러**가 독립 채널의 **광폭** PHY 경로로 명령 전달.
3. **다이·뱅크 선택**: **베이스 다이**와 **TSV**가 적층된 DRAM 다이의 대상 뱅크로 신호 분배.
4. **판독·버스트 반환**: 선택한 뱅크에서 **버스트 데이터**를 읽어 인터포저의 광폭 경로로 가속기에 반환.

#### 한줄 요약

- HBM 컨트롤러는 요청을 채널·뱅크에 분산하고, TSV와 인터포저의 광폭 경로로 판독 데이터를 가속기에 반환한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **GDDR(Graphics Double Data Rate Memory)**: 보드의 개별 메모리 칩에서 높은 핀 전송률로 대역폭을 확보하는 그래픽 메모리.
- **적층 수율(Stack Yield)**: 쌓은 모든 다이와 접합이 정상 동작해 완제품으로 사용할 수 있는 비율.
- **신호 무결성(Signal Integrity)**: 잡음과 반사 속에서도 신호가 올바른 전압과 타이밍을 유지하는 성질.
- **메모리 대역폭(Memory Bandwidth)**: 메모리와 가속기 사이에서 단위 시간에 전송할 수 있는 데이터량.

</details>

| 가속기 메모리 | HBM | GDDR |
|:---|:---|:---|
| 적용 기준 | 제한된 전력·패키지 면적에서 **메모리 대역폭** 극대화 시 | 용량 대비 비용과 보드 구성 유연성 중요 시 |
| 핵심 특징 | 적층·**광폭 I/O** 기반 다채널 병렬 전송 | 개별 칩의 고속 핀 전송과 칩 수 확장 |
| 한계 | 패키지•발열 비용을 높이는 **적층 수율** 부담 | 핀 속도 상승 시 **신호 무결성** 유지 부담 |

> 요약: HBM은 패키지, GDDR은 신호 부담.

#### 한줄 요약

- HBM은 광폭 패키지의 적층·수율 비용을 부담하고, GDDR은 높은 핀 전송률에 따른 전력·신호 무결성 비용을 부담한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **채널 포화(Channel Saturation)**: 주소 요청이 일부 채널에 몰려 다른 채널이 놀고 전체 대역폭이 제한되는 상태.
- **열 스로틀링(Thermal Throttling)**: 온도 한계를 지키려고 메모리나 가속기의 동작 속도를 낮추는 제어 동작.
- **양품 다이(Known Good Die, KGD)**: 적층 전에 정상 동작을 확인한 메모리 다이.
- **예비 경로(Redundant Path)**: 결함 배선을 우회하도록 마련한 여분 신호 경로.
- **오류 정정 코드(Error-Correcting Code, ECC)**: 추가 검사 비트로 전송 오류를 검출•정정하는 기법.
- **액체 냉각(Liquid Cooling)**: 냉각수를 열원 가까이 순환시켜 적층 메모리의 집중 발열을 제거하는 방식.
- **오류 격리(Error Isolation)**: 반복 오류가 발생한 채널이나 페이지를 사용 대상에서 제외하는 조치.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 주소가 일부 채널에 몰려 **채널 포화** | 데이터 배치에 **주소 분산** 적용 | 유휴 채널 감소로 실효 대역폭 향상 |
| 적층 다이 내부에 발열이 누적되어 **열 스로틀링** 발생 | 온도 감시와 방열 구조·**액체 냉각** 적용 | 동작 속도 저하 방지로 지속 처리량 유지 |
| 적층 다이 또는 접합 결함으로 패키지 수율 저하 | 적층 전 **양품 다이** 선별·**예비 경로** 적용 | 결함 다이·배선 배제로 완제품 수율 개선 |
| 메모리 채널 오류가 연산 결과로 전파 | **ECC** 정정과 반복 오류의 **오류 격리** | 오류 데이터 사용 차단으로 연산 신뢰성 확보 |

#### 한줄 요약

- AI 학습처럼 메모리 대역폭이 병목인 작업은 채널 분산과 냉각을 함께 확보해야 HBM의 광폭 경로를 지속적으로 활용할 수 있다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **대역폭 집약 워크로드(Bandwidth-Intensive Workload)**: 연산량보다 메모리 데이터 이동량이 성능을 제한하는 작업.
- **패키지 비용(Package Cost)**: 적층 메모리 조립에 추가되는 제조 비용.
- **냉각 비용(Cooling Cost)**: 집중 발열을 처리하기 위해 추가되는 운영 비용.
- **HBM 선택 기준**: 실효 대역폭 이득과 적층 패키지·냉각 비용을 비교해 HBM 적용 여부를 정하는 기준.

</details>

- **HBM 선택 기준**에 따라 **대역폭 집약 워크로드**의 이득이 **패키지 비용**·**냉각 비용**을 넘으면 **HBM** 적용

#### 한줄 요약

- 실효 처리량 이득이 적층•냉각 비용을 넘는 대역폭 집약 워크로드에 HBM을 적용한다.
