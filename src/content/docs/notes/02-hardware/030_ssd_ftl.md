## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **플래시 변환 계층(Flash Translation Layer)**: 장치 컨트롤러 내부에 탑재되어 파일 시스템의 논리 주소를 물리 낸드 플래시 주소로 동적 매핑하고 수명 관리를 총괄하는 핵심 펌웨어 소프트웨어이다.
- **비제자리 갱신(Out-of-Place Update)**: 덮어쓰기가 불가능한 하드웨어 특성상 기존 데이터를 직접 지우지 않고 비어있는 새 페이지에 데이터를 기록한 후 기존 페이지를 무효화하는 저장 방식이다.
- **낸드 플래시(NAND Flash)**: 읽기와 쓰기는 페이지 단위로 수행하고 데이터의 삭제는 더 큰 블록 단위로만 수행하는 고밀도 비휘발성 저장 반도체이다.

</details>

- 정의: 호스트의 논리적 덮어쓰기 요청을 물리적인 **비제자리 갱신** 방식으로 수습하고 주소를 동적 변환하는 핵심 펌웨어 계층
- 배경: 쓰기 전 블록 단위 삭제 필수 원칙과 입출력 단위 불일치라는 치명적인 하드웨어 제약을 운영체제 파일 시스템으로부터 완벽히 은닉하기 위함

#### 한줄 요약

- 하드웨어의 쓰기 제약과 수명 한계를 투명하게 덮어주고, 일반 블록 저장장치처럼 논리 주소 매핑을 제공하는 지능형 펌웨어 시스템이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **가비지 컬렉션(Garbage Collection)**: 무효화된 페이지가 누적된 희생 블록에서 유효한 데이터만 새 클린 블록으로 옮겨 적은 뒤 해당 희생 블록 전체를 소거하여 여유 공간으로 재활용하는 필수 유지보수 과정이다.
- **마모도 평준화(Wear Leveling)**: 소거 횟수 수명 한계를 지닌 낸드 블록들이 특정 영역만 집중적으로 마모되는 것을 막기 위해 모든 블록의 소거 빈도를 균등하게 분산하는 펌웨어 기술이다.
- **쓰기 증폭(Write Amplification Factor)**: 호스트가 요청한 쓰기 데이터량 대비 가비지 컬렉션의 유효 페이지 이동 등으로 실제 낸드 플래시에 물리적으로 기록된 데이터량의 배수 비율이다.

</details>

- **비제자리 갱신** 방식을 적용하여 새 빈 페이지에 데이터를 즉각 기록하고 기존 페이지는 무효 상태로 표시함.
- **가비지 컬렉션**을 비동기적으로 백그라운드에서 수행하여 무효 페이지가 가득 찬 희생 블록을 소거하고 재사용 공간으로 회수함.
- 가비지 컬렉션 과정에서 유효 데이터가 함께 이동하는 오버헤드로 인해 **쓰기 증폭** 수치가 1.0 이상으로 상승하는 물리적 상충 관계가 발생함.

#### 한줄 요약

- 비제자리 갱신으로 쓰기 제약을 우회하지만, 이로 인해 파생되는 가비지 컬렉션과 쓰기 증폭을 관리하고 마모도를 평준화하는 책임을 진다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **논리 물리 매핑 테이블(LPN-PPA Mapping Table)**: 호스트 논리 페이지 번호를 실제 낸드 물리 페이지 주소로 대조 변환해 주는 장치 메모리 상의 룩업 표이다.
- **전력 차단 보호기(Power-Loss Protection)**: 갑작스러운 정전 발생 시 내부 보조 전력을 활용하여 휘발성 메모리의 매핑 데이터와 기록 중인 캐시를 낸드로 안전하게 백업하는 회로이다.
- **마모도 평준화기(Wear Leveling Engine)**: 동적 및 정적 마모도 분산 알고리즘을 가동하여 칩 전체의 소거 횟수를 실시간으로 대조하고 조율하는 제어 유닛이다.

</details>

```text
[ 장치 컨트롤러 내부 플래시 변환 계층 아키텍처 ]
+-------------------------------------------------------------+
| 호스트 인터페이스 (프로토콜 커맨드 해독기)                  |
+-------------------------------------------------------------+
                              │
+-------------------------------------------------------------+
| 플래시 변환 계층 (펌웨어)                                   |
|  ├─ 논리 물리 매핑 엔진                                     |
|  ├─ 가비지 컬렉터 (희생 블록 선택 및 유효 페이지 복사)      |
|  ├─ 마모도 평준화기 (동적 및 정적 소거 분산 제어)           |
|  └─ 전력 차단 보호기 (매핑 저널 영구 복구 관리)             |
+-------------------------------------------------------------+
                              │
+-------------------------------------------------------------+
| 칩 내부 임시 메모리 (매핑 테이블 및 데이터 캐시 버퍼)       |
+-------------------------------------------------------------+
                              │
+-------------------------------------------------------------+
| 낸드 플래시 물리 제어기 (다중 채널 병렬 낸드 입출력)        |
+-------------------------------------------------------------+
```

| 구성요소 | 책임 |
|:---|:---|
| **논리 물리 매핑 엔진** | 논리 페이지 번호와 실제 물리 페이지 주소 간의 고속 매핑 관리 |
| 가비지 컬렉터 | 낭비된 희생 블록 선택, 유효 페이지 이주 및 물리적 소거 수행 |
| **마모도 평준화기** | 낸드 블록 전체의 소거 횟수 균등 분산 스케줄링 관리 |
| **전력 차단 보호기** | 예기치 않은 정전 시 기록 데이터 및 매핑 메타데이터 안전 보존 |

#### 한줄 요약

- 호스트와 물리 낸드 사이에서 매핑 엔진, 가비지 컬렉터, 평준화기, 전력 보호기가 펌웨어 형태로 통합 구동되어 안정성을 확보한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **희생 블록(Victim Block)**: 가비지 컬렉션 실행 시 무효화된 페이지 비율이 가장 높아 유효 데이터 이동 오버헤드가 적은 최적의 소거 대상 물리 블록이다.
- **매핑 저널(Mapping Journal)**: 주소 변경 이력을 낸드 플래시 전용 저널링 구역에 로그 형태로 영구 적재하여 불의의 사고 시 복구를 지원하는 기법이다.

</details>

```text
[ 호스트 논리 페이지 쓰기 요청 도달 ]
                 │
                 ▼
     [ 1. 물리 낸드 신규 페이지 기록 ]
                 │
                 ▼
     [ 2. 매핑 테이블 및 저널 갱신 ]
                 │
                 ▼
     [ 3. 기존 PPA 페이지 무효화 처리 ]
                 │
      [ 여유 블록 개수 임계치 미달 여부 검사 ]
                 │
      ┌──────────┴──────────┐
      ▼                     ▼
 [ 정상 종료 ]         [ 여유 공간 부족 ]
                            │
                            ▼
                  [ 4. 백그라운드 가비지 컬렉션 ]
                  - 무효 비율 최대 희생 블록 선정
                  - 유효 페이지 신규 블록 복사 이주
                  - 희생 블록 물리적 소거 및 재활용
```

### 동작 원리

1. 신규 페이지 기록: 비어있는 물리 페이지를 할당하고 새 데이터를 낸드에 기록함.
2. 매핑 및 저널 갱신: 신규 물리 주소 매핑을 테이블에 적용하고 **매핑 저널**을 저장함.
3. 기존 페이지 무효화: 논리 주소에 묶여있던 기존 물리 페이지를 무효 상태로 갱신함.
4. 가비지 컬렉션: 여유 블록이 임계치 미만이면 **희생 블록**에서 유효 페이지를 이주시키고 해당 블록을 소거함.

#### 한줄 요약

- 항상 새 페이지에 기록 후 기존 매핑을 무효화하며, 찌꺼기 데이터가 누적되어 여유 공간이 고갈될 조짐이 보이면 가비지 컬렉션을 가동한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **페이지 매핑(Page-Level Mapping)**: 논리 4KB 단위마다 독립적인 물리 4KB를 1:1로 매핑하는 방식으로, 성능은 극상이나 매핑 테이블 용량이 방대해지는 방식이다.
- **블록 매핑(Block-Level Mapping)**: 수 MB의 블록 단위로만 매핑을 관리하여 메모리 소모는 극도로 적으나, 작은 쓰기 발생 시 블록 전체 병합 오버헤드로 성능이 폭락하는 방식이다.
- **하이브리드 매핑(Hybrid Mapping)**: 기본은 블록 매핑을 유지하되 잦은 쓰기 구역에는 임시로 페이지 매핑을 적용하는 절충형 기법이다.

</details>

| 비교 항목 | 페이지 매핑 기법 | 블록 매핑 기법 | 하이브리드 매핑 기법 |
|:---|:---|:---|:---|
| 논리 물리 매핑 굵기 단위 | 4KB 페이지 단위의 극히 세밀한 개별 매핑 | 수 MB 블록 단위의 굵직한 매핑 통제 | 블록 단위 기본 골격에 로그 영역만 페이지 매핑 혼합 |
| 시스템 메모리 사용량 | 방대한 페이지 수에 비례하여 칩 메모리 대량 소모 | 블록 수에 비례하므로 제어 메모리 소모 극히 미미함 | 두 방식의 절충으로 중간 수준의 메모리 용량 요구 |
| 4KB 무작위 임의 쓰기 성능 | 낸드 쓰기 증폭이 억제되어 최고 성능 보장 | 잦은 블록 읽기 쓰기 병합 오버헤드로 최악의 성능 수반 | 로그 영역 포화 시 급격한 성능 병목으로 중간 수준 |
| 대표적 채택 기기 분야 | 엔터프라이즈 서버 및 최신 소비자용 고성능 저장장치 | 메모리 용량이 희박한 과거 구형 카드 및 초저가 플래시 | 페이지 매핑 적용이 부담스럽던 초기 저장장치 모델 |

#### 한줄 요약

- 고성능 시스템은 풍부한 램을 바탕으로 압도적인 임의 쓰기 성능을 발휘하는 페이지 매핑을 표준으로 채택하고 있다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **초과 예비 공간(Over-Provisioning)**: 전체 물리 용량 중 호스트 유저에게 노출하지 않고 가비지 컬렉션 및 수명 관리를 위해 숨겨둔 고정 낸드 예비 공간이다.
- **트림 명령(TRIM Command)**: 운영체제가 파일 삭제 시 해당 논리 주소가 더 이상 유효하지 않음을 명시적으로 펌웨어에 통지하여 사전 무효화 처리를 유도하는 제어 명령이다.
- **정적 마모도 평준화(Static Wear Leveling)**: 갱신이 없는 차가운 데이터를 강제로 다른 블록으로 옮기고 덜 닳은 블록을 무거운 쓰기 작업에 투입하는 능동적 수명 관리 기법이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 호스트 쓰기 폭주 시 즉각적인 전경 가비지 컬렉션 발동으로 인한 지연 상승 | 워크로드 특성에 맞춘 **초과 예비 공간** 넉넉한 확보 및 운영체제 **트림 명령** 연동 | 펌웨어 여유 블록 조기 확보 및 지연을 유발하는 전경 수집 빈도 강력 억제 |
| 소규모 무작위 쓰기 지속 시 심각한 쓰기 증폭 폭증으로 낸드 수명 단축 | 계층 내 데이터 쓰기 버퍼 능동 집계 및 정밀한 페이지 매핑 기술 상시 구동 | 무의미한 낸드 쓰기 증폭 원천 억제 및 물리적 소거 수명 연장 |
| 특정 읽기 전용 데이터 적재 구역의 마모율 불균형에 따른 셀 조기 불량 | **정적 마모도 평준화** 가동을 통한 차가운 정지 데이터의 정기적 강제 이주 | 전체 낸드 칩 단위의 물리적 블록 지우기 횟수 수명 완벽 균등화 |
| 불시 정전 시 임시 메모리 상의 매핑 테이블 유실 및 치명적인 데이터 파손 | 기판 전용 방전 커패시터 탑재 및 영구 플래시 구역의 매핑 저널 즉각 회복 가동 | 불시 정전 후 재부팅 시 주소 매핑 테이블 무결성 100% 복구 보장 |

#### 한줄 요약

- 초과 예비 공간과 트림 명령으로 성능 저하를 방어하고, 정적 평준화로 수명을 연장하며, 전력 차단 보호 설계로 극한의 신뢰성을 보장한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **펌웨어 최적화 기준(Firmware Optimization Criteria)**: 저장장치 도입 시 워크로드의 임의 쓰기 강도, 필요한 여유 공간 할당량, 수명 보증 요구사항을 분석하여 펌웨어 파라미터를 결정하는 가이드라인이다.

</details>

- 임의 쓰기가 과도하면 **페이지 매핑과 여유 공간** 확보, 전력 위험이 치명적이면 **하드웨어 전력 보호** 장착 모델을 선택함

#### 한줄 요약

- 쓰기 증폭, 꼬리 지연시간, 소모 수명, 정전 위험 요소를 복합적으로 고려하여 펌웨어 매핑과 가비지 컬렉션 정책을 최적화해야 한다.
