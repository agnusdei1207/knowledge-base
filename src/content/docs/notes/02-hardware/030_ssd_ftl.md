## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **플래시 변환 계층(Flash Translation Layer, FTL)**: 논리 주소를 NAND 물리 위치로 변환하는 계층이다.
- **낸드(Not AND, NAND)**: 페이지 기록과 블록 삭제를 사용하는 플래시 메모리이다.
- **솔리드 스테이트 드라이브(Solid-State Drive, SSD)**: NAND와 컨트롤러로 구성한 저장장치이다.

</details>

- 정의/개념: 호스트 논리 페이지를 NAND의 최신 물리 페이지에 매핑하는 **FTL**이다.
- 배경/필요성: NAND는 빈 페이지에 기록하고 블록 단위로만 삭제할 수 있어 기존 페이지를 제자리에서 갱신할 수 없다.

#### 한줄 요약

- FTL은 새 물리 페이지에 데이터를 기록하고 논리 매핑을 전환해 NAND의 제자리 갱신 제약을 숨긴다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **비제자리 갱신**: 새 물리 페이지에 데이터를 기록한 뒤 기존 페이지를 무효화하는 방식이다.
- **마모도 평준화**: 프로그램•삭제 횟수를 여러 NAND 블록에 분산하는 기법이다.
- **가비지 컬렉션(Garbage Collection, GC)**: 유효 페이지 이주와 블록 삭제로 공간을 회수하는 작업이다.

</details>

- 기존 페이지 덮어쓰기를 피하는 **비제자리 갱신**이 핵심이다.
- 무효 페이지 블록을 회수하는 **가비지 컬렉션**이 핵심이다.
- 프로그램•삭제 횟수를 분산하는 **마모도 평준화**가 핵심이다.

$$
Write\ Amplification = \frac{NAND\ Physical\ Write\ Amount}{Host\ Logical\ Write\ Amount}
$$

> GC•메타데이터 쓰기도 물리 쓰기에 포함

#### 한줄 요약

- FTL은 비제자리 갱신과 주소 매핑으로 페이지 기록·블록 삭제 단위 차이를 흡수하고, GC로 빈 블록을 회수한다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **논리 페이지 번호(Logical Page Number, LPN)**: 호스트가 지정하는 페이지 번호이다.
- **물리 페이지 주소(Physical Page Address, PPA)**: NAND 내부의 최신 페이지 주소이다.
- **LPN-PPA 매핑**: 논리 페이지를 최신 물리 페이지 위치에 연결하는 정보이다.
- **가비지 컬렉터**: 유효 페이지 이주와 블록 삭제를 실행해 여유 공간을 만드는 구성요소이다.
- **메타데이터 복구기**: 체크포인트와 저널을 이용해 정전 후 주소 매핑을 복원하는 구성요소이다.
- **마모도 평준화기**: 블록별 프로그램•삭제 횟수를 분산해 NAND 수명을 고르게 사용하는 구성요소이다.

</details>

```text
FTL 펌웨어 경계
|
+-- [LPN-PPA 매핑 테이블]
+-- [가비지 컬렉터]
+-- [마모도 평준화기]
`-- [메타데이터 복구기]
```

선의 의미: 네 구성요소가 동일한 FTL 펌웨어 경계에 포함되어 주소 변환•공간 회수•마모 분산•복구 책임을 나누는 정적 포함 관계다.

| 구성요소 | 책임 |
|:---|:---|
| LPN-PPA 매핑 테이블 | 논리 페이지의 최신 물리 위치 제공 |
| 가비지 컬렉터 | 유효 페이지 이주와 블록 회수 |
| 마모도 평준화기 | 블록별 삭제 부하 분산 |
| 메타데이터 복구기 | 저널 기반 매핑 복원 |

#### 한줄 요약

- 매핑 테이블이 최신 물리 위치를 제공하고, 가비지 컬렉터·마모도 평준화기·복구기가 각각 공간·수명·정전 복구를 관리한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **페이지 프로그램**: 빈 NAND 페이지에 데이터를 기록하는 동작이다.
- **블록 삭제**: NAND 블록 전체를 초기화하는 동작이다.
- **매핑 저널**: 새 물리 위치를 활성화하기 전에 주소 변경 기록을 영구 저장하는 로그이다.
- **희생 블록**: 유효 페이지를 옮긴 뒤 삭제해 여유 공간으로 회수할 NAND 블록이다.
- **빈 페이지 할당**: 쓰기 가능한 NAND 블록에서 새 물리 페이지를 확보하는 단계이다.
- **새 페이지 프로그램**: 기존 페이지 대신 새 물리 페이지에 호스트 데이터를 기록하는 단계이다.
- **매핑 저널 보존**: 새 LPN-PPA 대응 기록을 영구 저장해 정전 복구에 대비하는 단계이다.
- **매핑 전환·기존 페이지 무효화**: 새 PPA를 최신 위치로 바꾸고 이전 페이지를 무효 상태로 만드는 단계이다.
- **유효 페이지 이주·블록 삭제**: 희생 블록의 유효 데이터를 옮긴 뒤 블록을 지워 공간을 회수하는 단계이다.

</details>

```text
                      [논리 쓰기 요청]
                               |
                       1. 빈 페이지 할당
                               |
                       2. 새 페이지 프로그램
                               |
                       3. 매핑 저널 보존
                               |
                 4. 새 매핑 활성화•기존 무효화
                               |
                          [쓰기 완료]
                               |
                    [여유 블록 임계치 미만?]
                        /              \
                     [아니요]           [예]
                        |                |
                     [종료]   +--------------------------------+
                              | 반복: 희생 블록의 유효 페이지 |
                              | 5. 유효 페이지 이주•블록 삭제 |
                              +--------------------------------+
                                           |
                                    [공간 회수]
```

### 동작 원리

1. **빈 페이지 할당**: 쓰기 가능한 NAND 블록에서 새 물리 페이지 주소를 확보한다.
2. **새 페이지 프로그램**: 기존 페이지를 덮어쓰지 않고 새 물리 페이지에 호스트 데이터를 기록한다.
3. **매핑 저널 보존**: 정전 후 변경을 재현할 수 있도록 새 LPN-PPA 대응 기록을 확정한다.
4. **매핑 전환·기존 페이지 무효화**: 새 PPA를 최신 위치로 활성화하고 이전 물리 페이지를 무효 상태로 변경한다.
5. **유효 페이지 이주·블록 삭제**: 여유 블록이 부족하면 희생 블록의 유효 페이지를 옮긴 뒤 블록 전체를 삭제한다.

#### 한줄 요약

- FTL은 새 데이터와 매핑 저널을 확정한 뒤 최신 물리 위치를 전환하고, 여유 공간이 부족하면 GC로 블록을 회수한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **페이지 매핑 FTL**: 논리 페이지마다 물리 페이지를 직접 연결해 임의 쓰기 지연을 줄이는 방식이다.
- **블록 매핑 FTL**: 논리 블록과 물리 블록을 연결해 매핑 메모리를 줄이는 방식이다.
- **하이브리드 FTL**: 데이터 블록과 로그 블록 매핑을 결합해 지연과 메타데이터 크기를 절충하는 방식이다.
- **임의 쓰기 지연**: 떨어진 논리 주소를 갱신하는 요청이 완료될 때까지 걸리는 시간이다.
- **매핑 메모리**: SSD 컨트롤러가 논리•물리 주소 대응을 보관하는 메모리이다.
- **혼합 쓰기**: 임의 쓰기와 순차 쓰기가 함께 나타나는 작업 패턴이다.
- **쓰기 증폭**: 호스트 논리 쓰기량 대비 NAND 물리 쓰기량의 비율이다.

</details>

| FTL 방식 | 페이지 매핑 FTL | 블록 매핑 FTL | 하이브리드 FTL |
|:---|:---|:---|:---|
| 적용 기준 | **임의 쓰기 지연**을 줄이는 것이 중요할 때 | 순차 쓰기 중심이며 **매핑 메모리** 절감이 중요할 때 | 임의·순차 **혼합 쓰기**를 절충할 때 |
| 핵심 특징 | 논리 페이지별 직접 매핑 | 논리•물리 블록 단위 매핑 | 데이터•로그 블록 매핑 결합 |
| 한계 | 큰 **매핑 메모리** | 블록 병합의 **쓰기 증폭** | 병합•메타데이터 복잡도 |

> 요약: 쓰기 패턴과 **매핑 메모리 규모** 기준 **FTL 방식**을 선택한다.

#### 한줄 요약

- 임의 쓰기는 페이지 매핑, 순차 쓰기는 블록 매핑, 두 패턴이 섞이면 하이브리드 매핑으로 지연과 메타데이터 크기를 절충한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **초과 예비 공간**: 호스트에 노출하지 않고 GC에 사용하는 여유 블록이다.
- **TRIM**: Trim, 사용하지 않는 논리 주소를 SSD에 알리는 명령이다.
- **체크포인트**: 복구 기준이 되는 매핑 상태를 기록한 메타데이터이다.
- **저널**: 체크포인트 이후 매핑 변경을 기록한 로그이다.
- **동적 마모도 평준화**: 새 쓰기를 삭제 횟수가 적은 빈 블록에 배치하는 기법이다.
- **정적 마모도 평준화**: 오래 고정된 데이터도 옮겨 모든 블록의 삭제 횟수를 분산하는 기법이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 여유 블록이 고갈되어 호스트 쓰기 중 전경 GC 발생 | **초과 예비 공간·TRIM**으로 무효 페이지를 미리 식별 | 쓰기 경로의 GC 감소로 꼬리 지연 완화 |
| 작은 임의 쓰기로 희생 블록의 유효 페이지 이주 증가 | 작은 쓰기를 병합·순차화하고 GC 시작 임계치 조정 | 추가 물리 쓰기 감소로 **쓰기 증폭** 완화 |
| 일부 블록에 프로그램·삭제가 집중되어 수명 편차 증가 | **동적 마모도 평준화·정적 마모도 평준화**와 블록별 삭제 횟수 감시 | 삭제 부하 분산으로 NAND 수명 균등화 |
| 매핑 전환 중 전원이 끊겨 최신 물리 주소 손실 | **체크포인트·저널**을 보존하고 장애 주입으로 복구 순서 검증 | 정전 후 최신 매핑 복원으로 주소 일관성 확보 |

> 사례: 여유 공간•TRIM으로 GC 지연 완화

#### 한줄 요약

- 예비 공간과 TRIM으로 미리 회수할 블록을 확보하면 호스트 쓰기 경로의 전경 GC와 꼬리 지연을 줄일 수 있다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **임의 쓰기**: 떨어진 논리 주소를 갱신하는 쓰기 패턴이다.
- **순차 쓰기**: 연속 논리 주소를 차례로 기록하는 쓰기 패턴이다.
- **FTL 선택 기준**: 쓰기 패턴과 매핑 메모리 크기로 페이지·블록·하이브리드 FTL을 고르는 기준이다.

</details>

- **FTL 선택 기준**에 따라 **임의 쓰기**에는 **페이지 매핑 FTL**, **순차 쓰기**에는 **블록 매핑 FTL**, 혼합 쓰기에는 **하이브리드 FTL**을 선택한다.

#### 한줄 요약

- 임의 쓰기는 페이지 매핑, 순차 쓰기는 블록 매핑, 혼합 쓰기는 하이브리드 FTL이 적합하다.
