## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **Edge TPU**: 구글이 엣지 및 IoT 단말기에서 TensorFlow Lite 모델을 초저전력(2W 이하)으로 가속 추론하도록 개발한 소형 전용 ASIC.
- **Coral**: Google Edge TPU를 탑재한 개발 보드, 모듈(SoM), USB 가속기, M.2/PCIe 확장 카드를 아우르는 구글의 하드웨어 브랜드.

</details>

- 정의/개념: 저전력 엣지 디바이스 및 임베디드 기기에서 TensorFlow Lite 모델 추론을 고속 수행하도록 설계된 **초소형 도메인 특화 가속 ASIC**
- 배경/필요성: 엣지·IoT 디바이스 환경에서 클라우드 서버 의존 시 발생하는 **네트워크 대역폭 비용, 통신 지연시간 및 프라이버시 침해 문제**를 해소하고 현장 실시간 추론을 보장할 필요성 대두

#### 한줄 요약
- Edge TPU는 2와트 이하의 극저전력으로 초당 4조 회의 정수 연산(4 TOPS)을 수행하는 엣지 비전·음성 AI 전용 가속기이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **완전 정수 양자화(Full INT8 Quantization)**: 모델의 모든 가중치와 활성화 텐서를 8비트 정수로 변환하여 부동소수점 연산기 없이 순수 정수 연산기만으로 구동하는 기법.
- **Edge TPU 컴파일러**: 사전 학습된 TFLite 모델 그래프를 분석하여 Edge TPU 전용 바이너리로 변환하고 미지원 연산자를 CPU로 분할하는 전용 툴.

</details>

- INT8 정수 연산 극대화: 부동소수점 유닛을 배제하고 **INT8 전용 시스톨릭 MAC 어레이**로 하드웨어를 단순화하여 실리콘 면적과 전력 극소화
- 도메인 특화 컴파일러: **Edge TPU 컴파일러**를 통해 가속 가능 서브그래프를 자동 분할하고 단일 실행 바이너리로 패키징
- 높은 전력 대비 성능: 2W 전력 소모에서 **4 TOPS(초당 4조 회 연산)** 처리량을 달성하여 초당 30~60프레임의 실시간 비전 AI 구동

#### 한줄 요약
- INT8 정수 연산에만 특화하여 부동소수점 회로를 제거함으로써 2W에서 4 TOPS의 극저전력 고성능을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **TFLite Delegate**: TFLite 런타임이 그래프 내 특정 연산자들을 Edge TPU 하드웨어 드라이버로 위임(Delegate)하여 가속 실행하도록 중계하는 프레임워크 인터페이스.
- **온칩 SRAM 버퍼(On-Chip SRAM Buffer)**: 가중치와 중간 피처맵 텐서를 상주시켜 USB/PCIe 호스트 버스 트래픽을 차단하는 내부 메모리.

</details>

```text
[Google Coral Edge TPU 모듈 (M.2 / PCIe / USB)]
 ├─ 호스트 인터페이스 (PCIe Gen2 x1 / USB 3.0 Type-C)
 ├─ 온칩 SRAM 버퍼 (초저지연 가중치/피처맵 내부 메모리)
 ├─ 전용 정수 신경망 연산 엔진
 │   ├─ 시스톨릭 INT8 MAC 어레이 (64x64 정수 곱셈 누산기)
 │   └─ 활성화 및 양자화 스케일러 (ReLU, Hardswish, INT32->INT8)
 └─ 시퀀서 및 텐서 DMA 제어기 (전용 바이너리 해석 및 스트리밍)
```

선의 의미: 가지(`├─`, `└─`)는 하드웨어 소속 및 포함 관계를 나타냄

| 구성요소 | 책임 |
|:---|:---|
| 시스톨릭 INT8 MAC 어레이 | **INT8 행렬곱·합성곱** 스트리밍 |
| 온칩 SRAM 버퍼 | 텐서 상주로 **호스트 전송 절감** |
| 활성화·양자화 유닛 | 활성화와 **INT8 재스케일링** |
| 시퀀서 제어기 | 전용 바이너리 해석과 **파이프라인 제어** |
| TFLite Delegate | 지원 서브그래프의 **하드웨어 위임** |

#### 한줄 요약
- TFLite Delegate가 호스트 런타임과 가속기 사이에서 지원되는 서브그래프만 골라 넘기고, 그 안쪽은 시퀀서가 전용 바이너리를 직접 해석해 연산마다 호스트 CPU가 명령을 내리던 개입을 대신한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **대표 데이터셋(Representative Dataset)**: 모델 양자화 캘리브레이션 시 실제 엣지 입력 데이터의 동적 범위(Dynamic Range)를 모사하기 위해 사용하는 표본 데이터셋.
- **경계 텐서(Boundary Tensor)**: 서브그래프 분할로 인해 가속기(Edge TPU)와 호스트 CPU 간에 I/O 버스를 통해 교환되는 중간 데이터.

</details>

```text
[AI 모델 학습 완료 및 입력]
         │
         ▼
1. 완전 정수 양자화
         │
         ▼
2. 그래프 분석·연산자 매핑
         │
         ▼
3. 지원 연산 판정·바이너리 빌드
         │
         ▼
4. 온칩 적재·MAC 추론
         │
         ▼
5. 서브그래프 분할·CPU 폴백
         │
         ▼
[실시간 AI 추론 결과 반환]
```

분기 결과: 모든 연산자가 Edge TPU에서 지원되면 단일 바이너리로 컴파일되어 100% 하드웨어 가속이 이루어지며, 미지원 연산자 존재 시 **CPU 폴백** 발생

**동작 원리**

1. 완전 정수 양자화
2. 그래프 분석·연산자 매핑
3. 지원 연산 판정·바이너리 빌드
4. 온칩 적재·MAC 추론
5. 서브그래프 분할·CPU 폴백

#### 한줄 요약
- 완전 정수 양자화는 정밀도를 내주고 온칩 가속을 사는 선택이며, 분할된 서브그래프의 경계 텐서가 늘어날수록 호스트 CPU와의 I/O 왕복이 그 가속 이득을 되돌려 받아 간다.

## Ⅴ. 종류 및 비교

| 엣지 AI 가속기 | Google Edge TPU (Coral) | 온디바이스 NPU (스마트폰 SoC) | 엣지 GPU (NVIDIA Jetson) | 엣지 CPU (ARM Cortex-A) |
|:---|:---|:---|:---|:---|
| 전력 소비 수준 | **초저전력 (0.5W ~ 2W)** | 초저전력 (1W ~ 3W) | 중간~높음 (5W ~ 30W) | 낮음 (1W ~ 5W) |
| 지원 연산 포맷 | **INT8 완전 정수 전용** | INT8, INT4, FP16 | **FP32, FP16, INT8, FP8** | FP32, FP64, INT32 |
| 하드웨어 폼팩터 | **모듈형 (USB, M.2, PCIe 카드)** | 모바일 SoC 내부 실리콘 집적 | 독립 임베디드 보드 (SoM) | 메인 프로세서 내장 |
| 소프트웨어 스택 | **TensorFlow Lite 전용** | 벤더 전용 SDK (SNPE, QNN 등) | **CUDA, TensorRT, PyTorch** | ONNX Runtime, TFLite |
| 주요 적용 분야 | **스마트 팩토리 비전, IoT 카메라** | 스마트폰 온디바이스 AI 기능 | **자율주행 로봇, 복합 다채널 영상** | 초경량 센서 제어 및 단순 추론 |

#### 한줄 요약
- USB/M.2 모듈형으로 기존 임베디드 기기에 간편하게 저전력 INT8 추론을 추가할 때는 Edge TPU가 최적이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **양자화 인식 훈련(Quantization-Aware Training, QAT)**: 양자화로 인한 가중치 절삭 오차를 학습 과정에 반영하여 INT8 변환 후에도 정확도를 100% 수준으로 보존하는 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 완전 정수 변환 시 예측 정확도 하락 | **양자화 인식 훈련(QAT)** 및 대표 데이터셋 보정 | 원본 대비 **정확도 99% 보존** |
| 비표준 연산자로 인한 CPU 폴백 발생 | **TFLite 표준 연산자** 치환 및 모델 재설계 | **100% 칩 내부 가속** 달성 |
| 밀폐형 산업용 섀시 장착 시 발열 발생 | **방열 블록 밀착** 및 듀티 사이클 제어 | 연속 24시간 **안정 동작 보장** |

#### 한줄 요약
- 실무에서는 QAT로 INT8 정확도를 확보하고, TFLite 표준 연산자로 모델을 재설계하여 CPU 폴백을 방지한다.

## Ⅶ. 결론

- TensorFlow Lite 기반 **완전 정수(Full INT8) 경량 신경망 추론에 최적화된 대표적 초저전력(2W 이하) 엣지 모듈 솔루션**으로 정착되었으며, 향후 **스마트 팩토리, 비전 AI 카메라 및 로보틱스 엣지 디바이스**를 중심으로 온디바이스 NPU 및 엣지 임베디드 플랫폼과의 융합 가속화

#### 한줄 요약
- Edge TPU는 INT8 완전 정수 특화를 통해 엣지 단말의 실시간 AI 추론을 가장 효율적으로 구현하는 맞춤형 가속 솔루션이다.
