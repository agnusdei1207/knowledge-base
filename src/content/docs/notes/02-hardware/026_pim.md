## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **메모리 내 처리(Processing-in-Memory, PIM)**: 메모리 내부에 연산기를 배치해 원본 데이터의 외부 이동을 줄이는 처리 구조이다.
- **데이터 이동 병목**: 계산보다 데이터를 옮기는 시간과 에너지가 더 크게 성능을 제한하는 상태이다.
- **연산 이관**: 작업 일부를 데이터가 있는 메모리 쪽 연산기에 넘기는 동작이다.

</details>

- 정의/개념: 메모리 셀 또는 인접 로직에 연산기를 배치해 저장 위치에서 데이터를 처리하는 **PIM** 구조이다.
- 배경/필요성: 호스트 중심 처리는 대량 원본을 프로세서와 메모리 사이에서 왕복시켜 전송 지연과 에너지를 증가시킨다.

#### 한줄 요약

- PIM은 데이터가 저장된 메모리 내부나 인접 로직으로 **연산 이관**하고 축약 결과만 반환해 외부 전송량과 에너지를 줄인다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **내부 대역폭**: 메모리 뱅크와 다이 내부 연산기 사이에서 외부 핀보다 넓게 제공되는 전송량이다.
- **메모리 내 컴퓨팅(In-Memory Computing, IMC)**: 메모리 셀의 물리 동작으로 연산하는 방식이다.
- **메모리 근접 처리(Processing-Near-Memory, PNM)**: 메모리 셀 가까운 로직 계층에서 처리하는 방식이다.
- **축약**: 많은 입력을 합계•최댓값•조건 통과 행처럼 작은 결과로 줄이는 연산이다.
- **입출력(Input/Output, I/O)**: 메모리와 외부 호스트 사이에서 원본과 결과를 전송하는 경로이다.
- **지원 연산 범위**: 메모리 공정의 회로 밀도와 열 한도 안에서 PIM이 실행할 수 있는 연산의 종류이다.
- **구현 방식 스펙트럼**: 셀의 물리 동작을 쓰는 IMC부터 인접 로직을 쓰는 PNM까지의 구현 범위이다.

</details>

- 뱅크 **내부 대역폭** 활용으로 외부 I/O 지연과 전송 에너지 절감이 핵심이다.
- 메모리 공정의 회로 밀도와 열 한계가 제한하는 **지원 연산 범위**가 핵심이다.
- 메모리 셀 연산 IMC부터 인접 로직 연산 PNM까지 이어지는 **구현 방식 스펙트럼**이 핵심이다.

#### 한줄 요약

- PIM은 넓은 내부 대역폭을 활용하지만 메모리 공정과 발열 제약 때문에 단순·반복·고축약 연산에 적합하다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **연산 이관 인터페이스**: 호스트와 PIM 사이에서 연산 종류•주소•버퍼•완료 정보를 전달하는 접점이다.
- **곱셈 누산(Multiply-Accumulate, MAC)**: 입력값을 곱한 뒤 누적 합계에 더하는 연산이다.
- **메모리 내 연산 유닛**: 뱅크 가까이에서 MAC•스캔•필터•축약을 병렬 실행하는 회로이다.
- **메모리 뱅크 배열**: 원본 데이터를 저장하고 내부 병렬 접근을 제공하는 셀 배열이다.

</details>

```text
[명령•이관 인터페이스] -- [메모리 내 연산 유닛] -- [메모리 뱅크 배열]
```

선의 의미: 외부 명령 접점, 메모리 내부 연산 회로, 저장 뱅크가 하나의 PIM 장치 안에서 결합된 정적 구조다.

| 구성요소 | 책임 |
|:---|:---|
| 명령•이관 인터페이스 | 명령 수신•결과 반환 |
| 메모리 내 연산 유닛 | **MAC•축약**의 병렬 실행 |
| 메모리 뱅크 배열 | 원본에 대한 **내부 대역폭** 제공 |

#### 한줄 요약

- 이관 인터페이스가 작업을 받고 연산 유닛이 메모리 뱅크의 데이터를 내부에서 처리한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **호스트**: PIM에 연산과 주소 범위를 지정하고 결과를 처리하는 실행 장치이다.
- **부분 결과**: 여러 뱅크가 독립적으로 계산한 뒤 최종 축약에 합쳐지는 중간값이다.
- **이관 적합성 판정**: 축약률·분기 복잡도·데이터 재사용률로 PIM 실행의 손익을 판단하는 단계이다.
- **연산·주소 범위 이관**: 지원 연산과 처리할 메모리 범위를 PIM 인터페이스에 전달하는 단계이다.
- **뱅크 내부 병렬 연산**: 여러 메모리 뱅크가 할당된 원본 데이터를 동시에 처리하는 단계이다.
- **부분 결과 축약·반환**: 뱅크별 중간값을 작은 결과로 합쳐 호스트에 돌려주는 단계이다.

</details>

```text
                     [후보 연산•데이터]
                              |
                1. 축약률•분기•재사용 판정
                         /            \
                    [PIM 부적합]     [PIM 적합]
                         |               |
                   [호스트 실행]  2. 연산 종류•주소 이관
                                         |
                       +-----------------------------+
                       | 반복: 할당된 메모리 뱅크   |
                       | 3. 뱅크 내부 병렬 연산     |
                       +-----------------------------+
                                         |
                              4. 부분 결과 축약
                                         |
                               [결과•완료 반환]
```

### 동작 원리

1. **이관 적합성 판정**: 축약률·분기 복잡도·호스트 데이터 재사용률로 PIM 이관의 예상 손익을 계산한다.
2. **연산·주소 범위 이관**: 호스트가 지원 연산과 처리할 메모리 범위를 **연산 이관 인터페이스**에 전달한다.
3. **뱅크 내부 병렬 연산**: 할당된 뱅크의 원본 데이터를 외부로 내보내지 않고 병렬 처리한다.
4. **부분 결과 축약·반환**: 뱅크별 중간값을 작은 결과로 합쳐 완료 상태와 함께 호스트에 반환한다.

#### 한줄 요약

- 호스트는 적합한 연산과 주소 범위를 이관하고, PIM은 원본을 내부에서 병렬 처리해 축약 결과만 반환한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **축약 비율**: 읽은 원본 데이터 양에 비해 호스트로 반환하는 결과가 얼마나 작아졌는지 나타내는 비율이다.
- **데이터 재사용**: 호스트 캐시나 레지스터에 올린 값을 여러 번 연산에 사용하는 특성이다.
- **범용 연산**: 복잡한 분기와 다양한 명령을 호스트에서 유연하게 처리하는 연산이다.
- **캐시 일관성**: 호스트 캐시와 PIM 메모리가 같은 주소의 최신값을 일치시키는 성질이다.

</details>

| 연산 수행 위치 | PIM | 호스트 중심 처리 |
|:---|:---|:---|
| 적용 기준 | 읽는 양 대비 높은 **축약 비율** | 분기가 많고 큰 **데이터 재사용 효과** |
| 핵심 특징 | 원본을 옮기지 않는 **뱅크 내부 병렬 연산** | 코어로 적재 후 **범용 연산** |
| 한계 | 지원 연산 제약과 **캐시 일관성** 관리 | 원본 이동에 드는 대역폭•전송 에너지 |

> 요약: PIM은 원본 이동을 줄이지만 **지원 연산 범위**가 제한된다.

#### 한줄 요약

- 단순 연산으로 반환 데이터를 크게 줄일 수 있으면 PIM이 유리하고, 복잡한 분기나 캐시 데이터 재사용이 많으면 호스트 처리가 유리하다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **비캐시 버퍼**: PIM과 공유하는 데이터를 호스트 캐시에 담지 않아 오래된 사본을 막는 메모리 영역이다.
- **캐시 플러시**: 호스트 캐시의 수정 사본을 메모리에 반영하는 처리이다.
- **동기화**: 호스트와 PIM의 메모리 접근 순서를 맞추는 처리이다.
- **뱅크 포화**: 주소가 일부 뱅크에 몰려 다른 뱅크의 병렬성이 활용되지 않는 상태이다.
- **이관 지연**: 호스트가 PIM 명령과 주소를 설정하고 완료를 기다리는 데 드는 시간이다.
- **뱅크 접근 분산**: 요청 주소와 데이터를 여러 메모리 뱅크에 고르게 배치하는 방법이다.
- **고축약 연산**: 대량 입력을 처리한 뒤 호스트로 돌려보낼 결과가 매우 작아지는 연산이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 명령 설정·완료 대기 비용이 데이터 이동 절감량 초과 | **축약 비율·이관 지연**을 함께 계산해 실행 위치 선택 | 손익이 없는 비효율 이관 방지 |
| 호스트 캐시와 PIM 메모리에 수정본 불일치 | 공유 영역에 **비캐시 버퍼·캐시 플러시·동기화** 적용 | PIM 실행 전후 데이터 정합성 유지 |
| 데이터 주소가 일부 뱅크에 몰려 **뱅크 포화** | 주소 매핑과 데이터 배치로 **뱅크 접근 분산** | 유휴 뱅크 감소로 내부 병렬성 향상 |
| 복잡한 연산 회로가 면적·발열을 늘려 동작 한계 도달 | 단순 **고축약 연산** 선별과 온도 기반 속도 제어 | 열 한도 안에서 지속 처리량 확보 |

#### 한줄 요약

- 조건을 만족하는 행이 적은 질의는 PIM에서 필터링해 반환 데이터를 줄이되, 이관 지연과 캐시 정합성 비용을 함께 검증한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **분기 연산**: 복잡한 제어 흐름으로 호스트 실행이 유리한 연산이다.
- **재사용 연산**: 캐시 데이터를 반복 사용해 호스트 실행이 유리한 연산이다.
- **실행 위치 선택 기준**: 축약 비율·분기 복잡도·데이터 재사용으로 PIM과 호스트 실행을 고르는 기준이다.

</details>

- **실행 위치 선택 기준**에 따라 **고축약 연산**은 **PIM**, **분기 연산·재사용 연산**은 **호스트**에서 실행한다.

#### 한줄 요약

- 반환 데이터가 충분히 작고 연산이 단순할 때 PIM 이관 효과가 크다.
