## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **메모리 관리 장치(Memory Management Unit)**: 프로세서와 메모리 사이에 위치하여 주소 변환과 권한 검사, 캐시 속성을 하드웨어적으로 강제 제어하는 내장 모듈이다.
- **접근 격리(Access Isolation)**: 하드웨어적 변환 경계를 구축하여 특정 프로세스가 타 프로세스나 커널의 영역을 침범하지 못하도록 차단하는 보안 성질이다.
- **하드웨어 보호 경계(Hardware Protection Boundary)**: 소프트웨어적 우회가 불가능하도록 접근 트랜잭션을 실시간으로 필터링하는 물리적 게이트이다.

</details>

- 정의: 가상 주소를 물리 주소로 동적 변환하고 **하드웨어 보호 경계**에서 권한 검사와 캐시 속성을 통제하는 **메모리 관리 장치**
- 배경: 소프트웨어 검사만으로는 메모리 주소 격리와 권한 보호를 우회 불가능하게 강제하기 어렵기 때문임

#### 한줄 요약

- 모든 메모리 트랜잭션을 하드웨어 레벨에서 가로채어 주소 변환과 권한 검사를 수행하는 핵심 제어 아키텍처이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **가상 주소(Virtual Address)**: 프로세스가 0번지부터 독립적으로 사용하는 논리적 주소 공간이다.
- **물리 주소(Physical Address)**: 실제 주기억장치 하드웨어에 할당된 핀 버스 접근 주소이다.
- **페이지 권한(Page Permission)**: 기술자에 기록된 사용자/관리자 모드 허용 및 읽기, 쓰기, 실행 제어 보안 비트이다.
- **변환 색인 버퍼(Translation Lookaside Buffer)**: 장치 내부에 탑재되어 최근 변환 결과를 1주기 이내로 출력하는 전용 캐시이다.
- **물리 프레임(Physical Frame)**: 물리 메모리 상의 분할 단위 프레임 번호이다.

</details>

- **가상 주소**를 **물리 프레임**으로 변환하여 비연속적인 물리 메모리 적재를 실현함.
- 메모리 접근 시마다 사용자 권한 및 **페이지 권한**을 실시간으로 하드웨어 검사함.
- 내부 **변환 색인 버퍼**가 적중하면 다단계 탐색을 생략하여 지연을 단축함.

#### 한줄 요약

- 동적 주소 변환과 고속 캐시 기반 가속, 실시간 접근 권한 통제 기능을 단일 모듈 내에서 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **페이지 테이블 순회기(Page Table Walker)**: 버퍼 미스 발생 시 파이프라인을 멈추고 다단계 페이지 테이블을 자동 탐색하는 제어 로직이다.

</details>

```text
[ 메모리 관리 장치 내부 아키텍처 ]
+---------------------------------------------------+
| 프로세서 가상 주소 입력 (가상 번호 + 오프셋)      |
+---------------------------------------------------+
                          │
                          ▼
            [ 변환 색인 버퍼 (TLB) 조회 ]
            ├─ 적중 시 ──> 물리 번호 및 권한 인출
            │
            └─ 미스 시 ──> [ 페이지 테이블 순회기 가동 ]
                                  │
                                  ▼
                    [ 권한 및 캐시 속성 검사기 ]
                                  │
                    ┌─────────────┴─────────────┐
                    ▼                           ▼
          [ 예외 제어기 트랩 ]        [ 물리 주소 확정 출력 ]
```

| 구성요소 | 책임 |
|:---|:---|
| **변환 색인 버퍼** | 최근 주소 변환 매핑 결과와 권한 비트 고속 보관 |
| **페이지 테이블 순회기** | 버퍼 미스 시 메모리의 다단계 페이지 테이블 탐색 수행 |
| 권한 및 속성 검사기 | 읽기/쓰기/실행 보호 권한과 메모리 캐시 속성 대조 |
| 예외 제어기 | 무효 매핑이나 권한 위반에 대한 즉각적인 예외 신호 생성 |

#### 한줄 요약

- 캐시 버퍼, 순회기, 보호 검사기, 예외 제어기가 통합되어 파이프라인 지연 없이 변환을 수행한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **가상 페이지 번호(Virtual Page Number)**: 변환 버퍼 및 테이블 인덱싱에 사용되는 가상 주소의 상위 필드이다.
- **페이지 오프셋(Page Offset)**: 변환 없이 하위로 그대로 복사되는 페이지 내부 바이트 위치이다.
- **페이지 폴트(Page Fault)**: 비상주 접근이나 권한 위반 시 제어를 운영체제로 넘기는 예외 트랩이다.

</details>

```text
[ 가상 주소 접근 요청 ]
          │
          ▼
   [ 1. 버퍼 및 테이블 탐색 ]
   ├─ 적중 ──> 권한 인출
   └─ 미스 ──> 다단계 순회 및 갱신 (예외 시 폴트)
          │
          ▼
   [ 2. 권한 및 속성 검사 ]
   ├─ 위반 ──> 보호 예외 트랩
   └─ 정상 ──> 통과
          │
          ▼
   [ 3. 물리 주소 결합 확정 ]
```

### 동작 원리

1. 버퍼 및 테이블 탐색: **가상 페이지 번호** 조회 후 미스 시 테이블에서 물리 번호와 권한을 인출함.
2. 권한 및 속성 검사: 실행 모드와 접근 종류를 인출된 **페이지 권한**과 대조함.
3. 물리 주소 확정: 물리 번호와 **페이지 오프셋**을 결합 후 메모리 계층으로 주소를 전달함.

#### 한줄 요약

- 주소 탐색과 권한 대조를 선행하고, 모든 보안 검사를 통과한 요청에 한해서만 물리 주소를 결합하여 출력한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **메모리 보호 장치(Memory Protection Unit)**: 주소 변환 기능 없이, 물리 주소 공간의 고정 영역에 대해서만 접근 권한을 검사하는 저가형 하드웨어이다.
- **실시간 예측성(Real-Time Predictability)**: 탐색 지연 변동 없이 확정된 시간 내에 억세스를 완료하는 성질이다.
- **요구 페이징(Demand Paging)**: 가상 메모리를 통해 참조 시점에만 페이지를 물리 메모리에 로드하는 기법이다.

</details>

| 비교 항목 | 메모리 관리 장치 (MMU) | 메모리 보호 장치 (MPU) |
|:---|:---|:---|
| 주소 변환 지원 여부 | 가상 주소 변환 및 **요구 페이징** 적극 지원 | 물리 주소 기반으로 주소 변환 아예 미지원 |
| 권한 보호 단위 | 페이지 크기 단위의 세밀한 매핑 및 권한 제어 | 구현에 따라 한정된 고정 물리 영역 단위 제어 |
| 접근 지연 확정성 | 페이지 테이블 탐색으로 접근 지연 변동 발생 | 주소 변환 과정이 없어 뛰어난 **실시간 예측성** 보장 |
| 하드웨어 구현 면적 | 캐시 및 순회 로직이 필요하여 크고 복잡함 | 단순한 구간 비교기만 탑재하여 면적이 작고 가벼움 |
| 주요 실무 적용 분야 | 고성능 프로세서, 범용 운영체제 및 가상화 시스템 | 하드 실시간 운영체제 및 임베디드 소형 마이크로컨트롤러 |

#### 한줄 요약

- 관리 장치(MMU)는 가상 주소 변환과 요구 페이징을 지원하며, 보호 장치(MPU)는 변환 없이 고정 영역 보호와 실시간 확정성을 제공한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **TLB 슛다운(TLB Shootdown)**: 멀티코어 환경에서 한 코어가 매핑을 수정할 때 타 코어들의 캐시를 무효화하는 동기화 작업이다.
- **중첩 페이징(Nested Paging)**: 하이퍼바이저 환경에서 게스트에서 호스트로 이어지는 2단계 주소 변환을 수행하는 하드웨어 가상화 기술이다.
- **메모리 고정(Memory Pinning)**: 실시간 제어가 중요한 페이지를 물리 메모리에 상주하도록 강제하여 폴트 지연을 차단하는 기법이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 다단계 테이블 순회로 인한 극심한 주소 변환 지연 병목 | 대형 페이지 적용 및 내부 **페이지 순회 캐시** 활성화 | 메모리 순회 빈도 감소 및 최종 접근 지연시간 단축 |
| 다중 코어 간 매핑 수정 시 발생하는 **TLB 슛다운** 통신 폭증 | 무효화 전파 범위를 최소화하는 커널 국지적 동기화 적용 | 코어 간 통신 지연 감소 및 인터럽트 오버헤드 삭감 |
| 하이퍼바이저 가상화 환경에서의 **중첩 페이징** 변환 지연 | 결합형 캐시 버퍼 탑재 및 호스트 중첩 대형 페이지 활용 | 순회 빈도 억제 및 2단계 이중 변환 지연 시간 은닉 |
| 초저지연 실시간 제어에서 폴트에 의한 응답 예측성 파괴 | 운영체제 차원의 **메모리 고정** 연동 및 전용 보호 장치 전환 | 물리적 지연 요인 배제 및 접근 지연의 완벽한 확정성 보장 |

#### 한줄 요약

- 대형 페이지 및 순회 캐시로 변환 지연을 은닉하고, 국지적 슛다운과 메모리 고정을 통해 동기화 병목과 예측 불가능성을 차단한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **MMU 설계 판단 기준(MMU Architecture Decision Criteria)**: 대상 시스템의 운영체제 유형, 가상화 요구, 지연 확정성을 종합 평가하여 장치 채택 여부를 결정하는 기준이다.

</details>

- 범용 가상 메모리와 가상화가 필요하면 **관리 장치**, 확정된 지연과 보호가 필요하면 **보호 장치**를 선택함

#### 한줄 요약

- 시스템의 주소 공간 유연성 요구와 실시간 응답 예측성을 기준으로 가상 메모리 관리와 물리 메모리 보호를 결정해야 한다.
