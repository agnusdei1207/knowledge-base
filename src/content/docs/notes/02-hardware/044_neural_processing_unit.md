## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **신경망 처리 장치(Neural Processing Unit)**: 스마트폰이나 가전제품 안에서 배터리를 갉아먹지 않으면서도, 얼굴 인식이나 음성 분석 같은 인공신경망 추론을 빛의 속도로 끝내버리는 모바일 인공지능 전용 가속 반도체이다.
- **전용 연산 배열(Dedicated Compute Array)**: 쓸데없는 기능은 다 빼버리고 오직 곱하기와 더하기만 미친 듯이 잘하는 연산기들을 바둑판처럼 촘촘히 깔아놓은 하드웨어 연산 공장이다.
- **근접 메모리(Near-Compute Memory)**: 데이터를 저 멀리 바깥 메모리에서 끌고 오며 전기를 낭비하지 않도록, 연산기 바로 코앞에 개인 사물함처럼 착 붙여놓은 초고속 메모리 영역이다.
- **인공지능(Artificial Intelligence)**: 인간의 뇌신경망을 모방하여 수많은 데이터의 패턴을 학습하고, 이를 통해 찰나의 순간에 사진을 인식하거나 언어를 이해하는 데이터 처리 기술이다.
- **중앙 처리 장치(Central Processing Unit)**: 수많은 가속기를 지휘하고, 예외 상황이 발생하면 직접 나서서 복잡한 로직을 해결해 주는 기기의 총사령관 프로세서이다.
- **그래픽 처리 장치(Graphics Processing Unit)**: 전기세 걱정 없는 환경에서 어마어마한 스레드를 동시에 굴리며 대규모 행렬 연산을 무식하게 쳐내는 범용 병렬 가속기이다.

</details>

- 정의: 클라우드 접속 없이 단말 기기 내부(온디바이스)에서, 인공지능의 텐서 연산을 **전용 연산 배열** 및 근접 메모리 기반으로 쥐어짜듯 전용 처리하는 **신경망 처리 장치** 반도체
- 배경: 범용 프로세서(CPU, GPU)를 쓰다간 스마트폰 배터리가 순식간에 녹아내리고 손난로처럼 불타오르는 발열 한계를 극복하며 실시간 응답 지연을 잡기 위함

#### 한줄 요약

- 그래픽 카드를 스마트폰에 넣을 순 없으니, 전기를 잡아먹는 기능은 모조리 걷어내고 오직 인공지능의 단순 계산(곱하기/더하기)만 초저전력으로 쳐내는 족집게 반도체이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **곱셈 누산 연산 배열(Multiply-Accumulate Array)**: 소수점의 미세한 정확도를 포기하는 대신 정수(INT8)로 데이터를 뭉개버려, 좁은 공간에 수천 개의 연산기를 구겨 넣은 2차원 병렬 연산의 심장부이다.
- **온칩 정적 임의 접근 메모리(On-Chip SRAM)**: 전기를 가장 많이 잡아먹는 주범인 바깥 메모리(DRAM) 나들이를 끊어버리기 위해, 칩 안쪽에 가중치 데이터를 꽉꽉 눌러 담고 단물이 빠질 때까지 재활용하는 고속 창고이다.
- **테라 연산 처리량(Tera Operations Per Second)**: 이 칩이 1초에 무려 1조 번의 연산을 쳐낼 수 있다는, 마케팅 부서가 자랑하기 좋아하는 칩의 이론적 최대 성능 스펙 뻥튀기 지표이다.
- **종단 지연(End-to-End Latency)**: 이론적 수치 따위가 아니라, 사용자가 카메라를 들이밀었을 때부터 칩이 멈추거나 튕겨서 버벅거리는 시간까지 전부 포함해 결과가 화면에 뜨는 진짜 체감 시간이다.

</details>

- 저정밀 텐서 연산을 극저전력으로 고속 병렬 처리하는 거대한 2차원 **곱셈 누산 연산 배열** 하드웨어를 칩 한가운데 박아 넣음.
- 전기를 무지막지하게 갉아먹는 외부 동적 임의 접근 메모리(DRAM) 이동 횟수를 극적으로 낮추는 **온칩 정적 임의 접근 메모리** 기반 데이터 가두기 및 재사용 구조를 달성함.
- 스펙 시트용 이론적인 **테라 연산 처리량** 수치보다, 칩이 못 풀어서 중앙 처리 장치로 던져버릴 때 발생하는 폴백 오버헤드까지 몽땅 포함된 실제 체감 **종단 지연** 최적화에 설계 목숨을 검.

#### 한줄 요약

- 정밀도를 낮춰 연산기를 때려 박고, 데이터를 칩 안에 가둬 전기를 아끼며, 칩이 버벅거리는 핑퐁 시간(종단 지연)을 없애는 것이 핵심 설계 철학이다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **모델 컴파일러(Model Compiler)**: 거대한 신경망 지도를 분석해서, 어떤 연산은 칩에 넣고 어떤 연산은 칩이 모르니 쳐낼지 결정한 뒤 텐서를 칩 사이즈에 맞게 난도질하는 무자비한 최적화 소프트웨어이다.
- **신경망 처리 장치 런타임(NPU Runtime)**: 칩이 쉴 틈 없이 돌아가게끔 컴파일된 작업 조각들을 차례차례 칩의 입에 넣어주고 메모리를 치워주는 스마트폰 속 매니저이다.
- **호스트 폴백 경로(Host Fallback Path)**: 칩이 태어나서 처음 보는 희한한 최신 딥러닝 연산자를 만나면 뻗어버리는데, 이때 포기하지 않고 중앙 처리 장치로 데이터를 쓱 밀어 넘겨 대신 풀게 하는 굴욕적인 비상 탈출구이다.
- **곱셈 누산 연산(Multiply-Accumulate)**: 인공지능이 무언가를 판단할 때 숨 쉬듯 반복하는, 두 숫자를 곱하고 기존 값에 계속 더해나가는 가장 원초적인 신경망 기초 연산이다.

</details>

```text
[ 모바일 신경망 처리 장치 하드웨어 및 구동 런타임 융합 아키텍처 ]
                        [ 오프라인 딥러닝 모델 컴파일러 ]
                                         │ (최적화 텐서 맵핑 및 분할)
                                         ▼
+-------------------------------------------------------------------------------+
| 단말 기기 시스템 내부 망                                                      |
|                                                                               |
|                   [ 신경망 처리 장치(NPU) 구동 매니저 런타임 ]                |
|                    /                                         \                |
|                  ▼                                             ▼              |
| [ 칩 내장 온칩 메모리 + 곱셈 누산 연산 배열 ]   ←(데이터 교환)→  [ 호스트 중앙 처리 장치 폴백 구역 ] |
+-------------------------------------------------------------------------------+
```

| 구성요소 | 책임 |
|:---|:---|
| **모델 컴파일러** | 방대한 신경망 그래프 분석, 연산자 최적화 결합, 저정밀 양자화 다이어트 및 호환성을 위한 서브그래프 물리적 쪼개기(분할) |
| **신경망 처리 장치 런타임** | 컴파일된 작업 조각의 커널 디스패치 런칭, 칩 내부 온칩 메모리의 동기화 제어 및 실시간 텐서 파이프라인 흐름 관장 |
| **곱셈 누산 연산 배열** 및 온칩 메모리 | 배터리를 소모하지 않는 초저전력 저정밀 텐서 병렬 연산 및 칩 안에서 텐서를 계속 돌려쓰기 위한 피딩 버퍼 보관 |
| **호스트 폴백 경로** | 칩이 지원하지 않는 최신 돌연변이 연산자 조우 시 중앙 처리 장치(CPU) 등으로 우회 전송하여 계산을 땜빵하는 예외 처리 실행 |

#### 한줄 요약

- 컴파일러가 모델을 칩 입맛에 맞게 자르고, 런타임이 칩에 먹여주며, 칩이 못 씹는 질긴 연산(폴백)은 뱉어서 CPU가 대신 씹게 하는 끈끈한 협업 구조이다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **서브그래프 분할(Subgraph Partitioning)**: 전체 신경망 도면을 쫙 펼쳐놓고, "여기부터 여기까지는 NPU가 계산하고, 저기 꼬인 부분은 CPU가 계산해"라고 선을 긋고 토막 내는 컴파일 절차이다.
- **직접 메모리 접근(Direct Memory Access)**: 연산기가 계산하느라 바쁜데 짐까지 나를 순 없으니, 바깥 메모리에 있는 텐서 타일을 칩 내부 창고로 몰래몰래 퍼다 나르는 하드웨어 전담 지게차이다.
- **경계 텐서(Boundary Tensor)**: 서브그래프가 쪼개지는 절단면에서 발생하는 데이터로, NPU가 계산하다 막혀서 CPU로 넘겨줄 때 어쩔 수 없이 좁은 버스를 타고 건너가야 하는 아까운 전송 데이터 덩어리이다.

</details>

```text
[ 신경망 처리 장치 온디바이스 추론 실행 및 굴욕의 폴백 처리 제어 흐름 ]
                               │
                               ▼
    [ 1. 컴파일된 모델 실행 계획 등록 및 서브그래프 분할 순서 확정 ]
                               │
                               ▼
   [ 2. 직접 메모리 접근 지게차를 통한 입력 텐서 타일의 온칩 창고 배치 ]
                               │
            +---------------------------------------+
            | 쪼개진 서브그래프 조각 루프 순회      |
            |              [ NPU 지원? ]            |
            |             /             \           |
            |         [ 예 ]          [ 아니요 ]    |
            |           │                 │         |
            |  3. 칩 전용 고속 실행   4. 폴백 경로  |
            |  (곱셈 누산 배열 가동)  (CPU로 넘김)  |
            |           \                 /         |
            |     5. 결과물 융합 및 다음 조각 대기  |
            +---------------------------------------+
                               │
                               ▼
         [ 최종 온디바이스 추론 결과 사용자 화면 출력 및 반환 ]
```

### 동작 원리

1. 컴파일 실행 계획 등록: 칩 안으로 들어온 **서브그래프 분할** 결과를 면밀히 분석하고, 누구 먼저 실행할지 순서를 확정하며 빈 버퍼 창고를 할당함.
2. 타일 텐서 데이터 배치: **직접 메모리 접근** 제어기 지게차를 조종하여 느린 외부 메모리의 텐서를 칩 안쪽 근접 메모리로 차곡차곡 선제 배치함.
3. 칩 전용 저정밀 실행: 하드웨어가 완벽히 지원하는 꿀 같은 레이어들을 대상으로, 거대한 곱셈 누산 배열 기반의 맹렬한 고속 연산을 초저전력으로 쳐냄.
4. 예외 폴백 경로 구동: 칩이 모르는 최신 미지원 레이어 조우 시, 중간 결과물인 **경계 텐서**를 호스트로 뱉어내고 **호스트 폴백 경로**를 강제 구동함.
5. 결과 융합 및 반환: NPU와 CPU가 엎치락뒤치락 연산한 모든 서브그래프 결과를 하나로 통합하여 다음 레이어로 넘기고 최종 딥러닝 결과를 반환함.

#### 한줄 요약

- 지원하는 연산은 칩 안에서 초고속으로 갈아버리고, 칩이 모르는 연산이 나오면 뱉어서(폴백) CPU가 처리하게 한 뒤 다시 칩으로 넣어주는 치열한 릴레이이다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **온디바이스 추론(On-Device Inference)**: 인터넷이 끊기거나 비행기 모드에서도 스마트폰 칩셋 혼자서 인공지능을 돌려, 내 사진과 음성 데이터가 서버로 새어나가지 않는 극한의 프라이버시 보호 연산이다.
- **단일 명령 다중 스레드(Single Instruction Multiple Threads)**: 전력을 미친 듯이 빨아먹더라도 그래픽 처리 장치(GPU) 안에서 수만 개의 스레드를 굴려 무지막지한 텐서 대역폭을 뽑아내는 서버용 병렬 구조이다.
- **동적 분기(Dynamic Branching)**: 데이터에 따라 실행 경로가 이리저리 튀는 조건문 제어 흐름으로, 똑같은 덧셈만 죽어라 반복하는 NPU가 가장 극혐하고 기절해버리는 취약점이다.

</details>

| 비교 항목 | **신경망 처리 장치** (NPU) | **그래픽 처리 장치** (GPU) | **중앙 처리 장치** (CPU) |
|:---|:---|:---|:---|
| 시스템 적용 최적 기준 | 스마트폰이나 무선 카메라 등 배터리가 목숨인 환경의 초저전력 **온디바이스 추론** 가속 시 | 전기세 펑펑 쓰는 클라우드 서버의 대용량 데이터 범용 병렬 가속 및 거대 신경망 훈련 학습 시 | 신경망 전후의 복잡하게 꼬인 제어 흐름, **동적 분기** 중심의 텐서 가공 및 기기 운영체제 뼈대 구동 시 |
| 아키텍처 핵심 특징 | 배터리 소모를 극소화하기 위해 오직 딥러닝만 할 줄 아는 깡통 전용 곱셈 누산 배열 하드웨어 최적화 | **단일 명령 다중 스레드** 기반의 멈추지 않는 수만 개 스레드를 통한 고대역폭 무자비한 병렬 연산 달성 | 똑똑한 코어 몇 개가 복잡한 텐서의 전후처리를 매끄럽게 통제하고 칩 전체를 조율하는 범용 제어 파이프라인 |
| 극복해야 할 태생적 한계점 | 연산자 지원 폭이 좁아 칩 밖으로 데이터가 튀어나가는 치명적인 폴백 지연 오버헤드가 호환성을 갉아먹음 | 모바일 단말에 우겨넣기에는 감당할 수 없는 너무 높은 소비 전력 및 케이스를 녹일 듯한 극심한 열 발열 문제 | 대규모 텐서 병렬 연산을 코어 몇 개로 감당하기엔 턱없이 부족하고 비루한 산술 연산 처리량 바닥 |

#### 한줄 요약

- 배터리를 아껴야 하는 스마트폰 속에선 NPU가 왕이고, 전기가 펑펑 남는 서버에선 GPU가 깡패이며, 복잡한 판단과 마무리는 CPU가 도맡는 철저한 분업 생태계이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **양자화(Quantization)**: 메모리를 엄청 잡아먹고 뚱뚱한 소수점 데이터를 가차 없이 1바이트 정수형(INT8)으로 뭉개버려, 칩 안의 메모리 여유를 확보하고 연산 속도를 폭발시키는 극한의 다이어트 기법이다.
- **보정(Calibration)**: 데이터를 뭉갤(양자화) 때 값의 범위가 찌그러져 엉뚱한 결과(예: 개를 고양이로 인식)가 나오지 않도록, 샘플 데이터를 미리 돌려보고 최적의 축소 비율을 정교하게 깎아내는 영점 조절 작업이다.
- **연산자 지원 범위(Operator Coverage)**: 딥러닝 논문에서 쏟아지는 수백 가지 최신 수학 공식 중, 이 반도체 칩이 하드웨어 적으로 튕겨내지 않고 소화할 수 있는 연산의 스펙트럼이다.
- **연산자 결합(Operator Fusion)**: 덧셈 따로, 곱셈 따로 하며 칩 안에서 불필요하게 메모리를 오가는 낭비를 막고자, 연산 세 개를 한 덩어리로 짬뽕 결합하여 칩이 한 방에 쳐내도록 만드는 컴파일러의 꼼수이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| NPU가 좋아하는 저정밀 **양자화** 다이어트 변환에 따른 신경망 모델의 치명적인 추론 정확도 붕괴 하락 | 적절한 **보정** 데이터셋 샘플 활용 및 모델 학습 때부터 양자화를 인지시키는 QAT 인식 학습 사전 강제 적용 | 무겁고 전력을 퍼먹는 부동소수점 대비 체감할 수 없는 동등한 수준의 극한 모델 방어 달성 |
| 최신 모델을 지원하지 못하는 좁아터진 **연산자 지원 범위**로 인한 칩 이탈(폴백) 오버헤드 핑퐁 지연 현상 | 컴파일러 단의 **연산자 결합** 마법 및 타겟 칩이 호환할 수 있는 구형 하위 연산자로의 코드 뼈대 리팩토링 | 칩 밖(CPU)으로 나가는 굴욕적인 데이터 복사를 원천 차단하여 온디바이스 처리 속도 결사 수호 |
| 온칩 메모리가 작아 대역폭 한계로 연산기들이 밥을 굶고 노는 기아 현상 및 값비싼 연산 가동률 하락 | 거대 텐서를 코딱지만 한 공간적 텐서 타일링으로 쪼개고, 짐 나르기(통신)와 씹기(연산)의 완벽한 겹침 파이프라이닝 구축 | 곱셈 연산 유휴 시간을 완전히 박멸하고 한정된 공간 안에서의 칩 하드웨어 효율 극대화 100% 달성 |
| 발열을 못 버틴 모바일 단말의 전력 및 섭씨 발열 한도 초과에 따른 칩 뻗음(강제 성능 스로틀링) 참사 | 모바일 운영체제 연동 동적 전압 주파수 스케일링(DVFS) 적용 및 데이터 칩 외부 유출 완전 봉쇄 | 미친 발열로 인한 클록 강제 저하를 막고, 사용자 화면이 버벅대지 않는 종단 지연 성능의 안정적 무한 유지 |

#### 한줄 요약

- 다이어트(양자화)로 칩 크기를 줄이고, 핑퐁 지연(폴백)을 막기 위해 코드를 칩 입맛에 맞게 개조하며, 짐을 쪼개서 쉴 틈 없이 밀어 넣어 발열 없이 칩을 쥐어짜는 최적화가 필수이다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **지원률(Support Coverage)**: 딥러닝 모델 안에 있는 100개의 연산 블록 중, 칩이 CPU 도움 없이 스스로 온전히 소화해 낼 수 있는 연산의 백분율 비율로 폴백 지연을 결정짓는 핵심 지표이다.
- **추론 장치 선택 기준(Inference Hardware Selection Criteria)**: 이 기기의 배터리 용량이 얼마인지, 사용자가 허락하는 대기 시간이 몇 초인지, 모델이 칩에서 얼마나 돌아갈지(지원률)를 싸그리 계산하여 NPU를 박을지 말지 결정하는 판단 체계이다.

</details>

- **추론 장치 선택 기준**에 따라 특정 모델의 압도적인 칩 **지원률**과, 스마트폰처럼 극한의 초저전력 환경 요구 시 지체 없이 **신경망 처리 장치** 적용을 결단함

#### 한줄 요약

- 스마트폰 배터리를 아끼면서, 돌리려는 인공지능 모델의 연산 대부분을 칩이 튕겨내지 않고 스스로 소화할 수 있을 때만 비싼 돈을 주고 NPU를 탑재해야 한다.
