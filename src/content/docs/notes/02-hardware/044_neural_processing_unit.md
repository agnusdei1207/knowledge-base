## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **NPU(Neural Processing Unit)**: 모바일 및 에지 기기에서 딥러닝 신경망 추론을 초저전력(수 와트 미만)으로 고속 처리하는 전용 가속기.
- **2D MAC 어레이**: 곱셈(Multiply)과 누산(Accumulate) 연산기를 2차원 격자로 배치하여 행렬 연산을 전용 처리하는 하드웨어 블록.
- **온디바이스 AI(On-Device AI)**: 클라우드 서버 통신 없이 단말 기기 자체 칩셋에서 실시간 신경망 추론을 완수하는 컴퓨팅 패러다임.

</details>

- 정의/개념: 모바일 및 에지 디바이스에서 인공신경망 텐서 연산을 초저전력(TOPS/W)으로 가속하기 위해, 2D MAC 어레이와 온칩 SRAM 중심 근접 메모리를 집적한 도메인 특화 프로세서
- 배경/필요성: 모바일/IoT 단말에서 GPU/CPU 구동 시 발생하는 **배터리 급방전 및 발열(Thermal Throttling)을 방지하고 실시간 온디바이스(On-Device) AI 추론 처리 보장**

#### 한줄 요약

- 2D MAC 연산 어레이와 온칩 SRAM으로 **모바일 온디바이스 AI를 초저전력 가속하는 전용 NPU**

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **INT8 / INT4 저정밀 연산**: FP32 부동소수점 대신 8비트/4비트 정수로 모델을 양자화하여 연산기 면적과 전력 소모를 1/4 이하로 축소하는 기법.
- **End-to-End Latency**: 순수 칩 연산 시간뿐 아니라 전처리, DMA 전송, 호스트 CPU 폴백 오버헤드를 모두 포함한 최종 사용자 체감 응답 시간.

</details>

- 저정밀(INT8, INT4, FP16) 텐서 연산에 특화된 고집적 2차원 **2D MAC 연산 어레이** 하드웨어 내장
- 외부 DRAM 이동 에너지를 최소화하기 위한 대용량 **온칩 SRAM** 기반 가중치/피처맵 가두기 및 재사용 극대화
- 단순 이론 피크 스펙(TOPS)보다 CPU-NPU 간 전환 오버헤드를 줄이는 실제 **End-to-End 지연시간 최적화**

#### 한줄 요약

- **저정밀(INT8/INT4) 2D MAC 어레이·온칩 SRAM 데이터 재사용·End-to-End 지연 최적화**

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **모델 컴파일러**: ONNX, TensorFlow Lite 모델을 분석하여 NPU 전용 명령어 바이너리로 변환하고 양자화/타일링을 수행하는 오프라인 도구.
- **Host Fallback Path**: NPU 하드웨어가 지원하지 않는 복잡하거나 새로운 연산자를 만났을 때 CPU/GPU로 데이터를 우회시켜 처리하는 경로.

</details>

```text
[ 모바일 NPU 하드웨어 및 런타임 아키텍처 ]
┌─────────────────────────────────────────────────────────────┐
│ 딥러닝 모델 컴파일러 (양자화, 타일링, 서브그래프 분할)      │
└──────────────────────────────┬──────────────────────────────┘
                               │ (NPU 바이너리 생성)
┌──────────────────────────────┴──────────────────────────────┐
│ 온디바이스 NPU 런타임 매니저 (Kernel Dispatch & Scheduling) │
│  ├─ NPU 실행 경로 ───────────┐                              │
│  │                           ▼                              │
│  │  ┌────────────────────────────────────────────────────┐  │
│  │  │ NPU 하드웨어 코어                                  │  │
│  │  │  ├─ 대용량 온칩 SRAM 버퍼 (수 MB)                  │  │
│  │  │  ├─ 2D 저정밀 MAC 연산 배열 (INT8/INT4/FP16)       │  │
│  │  │  └─ 활성화/정규화 전용 하드웨어 가속기             │  │
│  │  └────────────────────────────────────────────────────┘  │
│  │                           │                              │
│  └─ 미지원 연산자 우회 ───────┴─> [ Host CPU 폴백 경로 ]    │
└─────────────────────────────────────────────────────────────┘
```

선의 의미: 모델 컴파일러, NPU 런타임, 온칩 SRAM + MAC 연산 배열 및 호스트 CPU 폴백 경로 간의 NPU 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 모델 컴파일러 | 방대한 신경망 그래프 분석, 연산자 최적화 결합, 저정밀 양자화 다이어트 및 호환성을 위한 서브그래프 물리적 쪼개기(분할) |
| 신경망 처리 장치 런타임 | 컴파일된 작업 조각의 커널 디스패치 런칭, 칩 내부 온칩 메모리의 동기화 제어 및 실시간 텐서 파이프라인 흐름 관장 |
| 곱셈 누산 연산 배열 및 온칩 메모리 | 배터리를 소모하지 않는 초저전력 저정밀 텐서 병렬 연산 및 칩 안에서 텐서를 계속 돌려쓰기 위한 피딩 버퍼 보관 |
| 호스트 폴백 경로 | 칩이 지원하지 않는 최신 돌연변이 연산자 조우 시 중앙 처리 장치(CPU) 등으로 우회 전송하여 계산을 땜빵하는 예외 처리 실행 |

#### 한줄 요약

- **모델 컴파일러·NPU 런타임·온칩 SRAM & MAC 어레이·CPU 폴백 경로**

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **서브그래프 분할(Subgraph Partitioning)**: 신경망 그래프 중 NPU가 실행할 수 있는 영역과 미지원으로 CPU가 실행해야 하는 영역을 컴파일 시점에 분할하는 기법.

</details>

```text
[ 온디바이스 NPU 추론 실행 및 폴백 처리 흐름 ]
                         │
                         ▼
   [ 1. 컴파일된 서브그래프 실행 계획 및 메모리 버퍼 할당 ]
                         │
                         ▼
   [ 2. DMA 컨트롤러를 통한 입력 텐서 타일 온칩 SRAM 적재 ]
                         │
        +────────────────────────────────────────+
        │ 서브그래프 루프 순회                   │
        │             [ NPU 지원 연산자? ]       │
        │             /               \          │
        │         [ 예 ]            [ 아니오 ]   │
        │           │                   │        │
        │   3. NPU MAC 배열 실행   4. CPU 폴백   │
        │   (초저전력 고속 가속)   (우회 연산)   │
        │           \                   /        │
        │         5. 경계 텐서 동기화 및 융합    │
        +────────────────────────────────────────+
                         │
                         ▼
   [ 6. 최종 추론 결과물 생성 및 사용자 앱으로 반환 ]
```

**동작 원리**

1. **실행 계획 로드**: 런타임이 모델 컴파일러의 서브그래프 분할 계획을 로드하고 온칩 버퍼 할당
2. **타일 적재**: DMA 엔진이 외부 DRAM에서 입력 피처맵 타일을 온칩 SRAM으로 고속 복사
3. **NPU 가속**: NPU 지원 레이어는 저정밀 2D MAC 어레이에서 초저전력 행렬 연산 수행
4. **CPU 폴백**: NPU 미지원 특수 레이어 조우 시 경계 텐서를 Host CPU로 넘겨 소프트웨어 연산 수행
5. **결과 융합**: CPU와 NPU의 중간 결과를 온칩 버퍼에서 융합하여 최종 추론 완료 후 반환

#### 한줄 요약

- 모델 컴파일 $\to$ **DMA 온칩 텐서 배치 $\to$ NPU 지원 레이어 가속 $\to$ 미지원 레이어 CPU 폴백 $\to$ 결과 융합**

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **NPU vs GPU vs CPU**:
  - NPU: 저정밀 전용 하드웨어, 초저전력(1~5W), 온디바이스 에지 추론 특화
  - GPU: 고대역폭 범용 SIMT, 고전력(50~700W), 대규모 학습 및 고성능 추론
  - CPU: 범용 직렬 코어, 복잡한 분기 제어, 전처리/후처리 및 폴백 전담

</details>

| 비교 항목 | 신경망 처리 장치 (NPU) | 그래픽 처리 장치 (GPU) | 중앙 처리 장치 (CPU) |
|:---|:---|:---|:---|
| 타깃 워크로드 및 정밀도 | 온디바이스 AI 추론 특화 (INT8, INT4, FP16) | 대규모 병렬 훈련 및 추론 (FP32, FP16, BF16) | 범용 제어, 복잡한 분기 및 직렬 알고리즘 |
| 전력 효율 및 발열 | 최고 수준의 에너지 효율 (5~15 TOPS/W, 1~5W) | 고전력 소모 (50~700W, 발열 제어 필수) | 중간 전력 소모 (15~150W, 범용 파이프라인) |
| 한계 및 호환성 | 미지원 연산자 발생 시 CPU 폴백 오버헤드 | 모바일 배터리 환경 탑재 불가 (높은 전력) | 대규모 텐서 연산 처리량의 심각한 한계 |

#### 한줄 요약

- 모바일 저전력 추론은 **NPU**, 대규모 학습/서버는 **GPU**, 범용 제어는 **CPU**

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **QAT(Quantization-Aware Training)**: 학습 과정에서 양자화 오차를 시뮬레이션하여 INT8/INT4 변환 시에도 FP32 수준의 정확도를 보존하는 기술.
- **Operator Fusion**: 인접한 Conv-BatchNorm-ReLU 연산자를 하나의 커널로 결합하여 온칩 메모리 왕복을 제거하는 최적화.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| NPU가 좋아하는 저정밀 **양자화** 다이어트 변환에 따른 신경망 모델의 치명적인 추론 정확도 붕괴 하락 | 적절한 **보정** 데이터셋 샘플 활용 및 모델 학습 때부터 양자화를 인지시키는 QAT 인식 학습 사전 강제 적용 | 무겁고 전력을 퍼먹는 부동소수점 대비 체감할 수 없는 동등한 수준의 극한 모델 방어 달성 |
| 최신 모델을 지원하지 못하는 좁아터진 **연산자 지원 범위**로 인한 칩 이탈(폴백) 오버헤드 핑퐁 지연 현상 | 컴파일러 단의 **연산자 결합** 마법 및 타겟 칩이 호환할 수 있는 구형 하위 연산자로의 코드 뼈대 리팩토링 | 칩 밖(CPU)으로 나가는 굴욕적인 데이터 복사를 원천 차단하여 온디바이스 처리 속도 결사 수호 |
| 온칩 메모리가 작아 대역폭 한계로 연산기들이 밥을 굶고 노는 기아 현상 및 값비싼 연산 가동률 하락 | 거대 텐서를 코딱지만 한 공간적 텐서 타일링으로 쪼개고, 짐 나르기(통신)와 씹기(연산)의 완벽한 겹침 파이프라이닝 구축 | 곱셈 연산 유휴 시간을 완전히 박멸하고 한정된 공간 안에서의 칩 하드웨어 효율 극대화 100% 달성 |
| 발열을 못 버틴 모바일 단말의 전력 및 섭씨 발열 한도 초과에 따른 칩 뻗음(강제 성능 스로틀링) 참사 | 모바일 운영체제 연동 동적 전압 주파수 스케일링(DVFS) 적용 및 데이터 칩 외부 유출 완전 봉쇄 | 미친 발열로 인한 클록 강제 저하를 막고, 사용자 화면이 버벅대지 않는 종단 지연 성능의 안정적 무한 유지 |

#### 한줄 요약

- **QAT/PTQ 양자화 보정·연산자 결합(Operator Fusion)·공간 타일링·DVFS 발열 억제**

#### 한줄 요약

- **연산자 커버리지(Coverage)와 전력 예산(Power Budget)**을 절충한 NPU 아키텍처 설계
