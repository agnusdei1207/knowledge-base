## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **신경망 처리 장치(Neural Processing Unit, NPU)**: 딥러닝 인공신경망의 행렬 곱셈 및 컨볼루션 연산을 저전력으로 처리하기 위해 설계된 특화 가속 프로세서.
- **온디바이스 AI(On-device AI)**: 클라우드 서버를 거치지 않고 스마트폰, 자율주행차 등 단말 기기 내부에서 직접 AI 추론을 실행하는 기술.

</details>

- 정의/개념: 인공신경망 추론을 저전력으로 가속하기 위해 **2D MAC 어레이**와 온칩 SRAM을 집적한 도메인 특화 프로세서
- 배경/필요성: 모바일·엣지 환경에서 GPU의 높은 **소비 전력·발열** 및 클라우드 통신 지연·보안 한계 발생

#### 한줄 요약
- 스마트폰이나 임베디드 기기에서 배터리를 적게 쓰면서 AI 계산을 빠르게 끝내도록 만든 전용 두뇌 칩이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **양자화(Quantization)**: 32비트 부동소수점 데이터를 INT8/INT4 정수형으로 변환해 연산 속도를 높이고 메모리 용량을 줄이는 기법.
- **희소성(Sparsity)**: 신경망 내 0에 가까운 무의미한 가중치 계산을 생략하여 연산 효율과 대역폭을 극대화하는 기술.

</details>

- **초저전력 고효율(TOPS/W)**로 배터리 기반 모바일 기기 최적화
- 저비트 양자화(INT8/INT4) 및 희소성(Sparsity) 가속 지원
- 대용량 온칩 SRAM 버퍼를 통한 DRAM 접근 전력 최소화

#### 한줄 요약
- 8비트 정수 연산과 0값 건너뛰기, 대용량 온칩 메모리로 전력 소모를 획기적으로 줄인다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **MAC(Multiply-Accumulate) 어레이**: 곱셈과 덧셈을 한 사이클에 동시에 수행하는 핵심 연산기 집합.
- **타이트 결합 온칩 SRAM(Tightly-Coupled SRAM)**: 외부 DRAM으로 나가지 않고 연산기 바로 옆에서 가중치와 활성화를 공급하는 고속 캐시.

</details>

```text
┌─────────────────────────────────────────────────────────────┐
│ NPU 코어 내부 아키텍처                                      │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ 호스트 SoC 버스 인터페이스 & 텐서 DMA 제어기           │  │
│  └──────────────────────────┬────────────────────────────┘  │
│                             │ (데이터 고속 이동)            │
│  ┌──────────────────────────┴────────────────────────────┐  │
│  │ 대용량 온칩 가중치 & 활성화 SRAM 버퍼 (Unified SRAM)   │  │
│  └───────────┬───────────────────────────┬───────────────┘  │
│              │ (가중치 공급)             │ (입력 피처맵)    │
│              ▼                           ▼                  │
│  ┌───────────────────────┐   ┌───────────────────────┐      │
│  │ 2D MAC 연산기 어레이  │──>│ 벡터 / 활성화 유닛    │      │
│  │ (Matrix / Conv Engine)│   │ (ReLU/GELU/Quantize)  │      │
│  └───────────────────────┘   └───────────┬───────────┘      │
│                                          │                  │
│  ┌───────────────────────────────────────┴───────────────┐  │
│  │ 양자화 스케일러 및 출력 후처리 엔진                   │  │
│  └───────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

선의 의미: 텐서 DMA가 SRAM으로 데이터를 올리면 MAC 어레이와 벡터 유닛이 연산 후 양자화 스케일러를 거쳐 출력

| 구성요소 | 책임 |
|:---|:---|
| MAC 연산기 어레이 | 2차원 격자 구조로 INT8/FP16 행렬 곱셈 및 2D 컨볼루션 연산 고속 수행 |
| 벡터 / 활성화 유닛 | ReLU, Sigmoid, LayerNorm 등 비선형 활성화 함수 및 풀링 전담 |
| 온칩 SRAM 버퍼 | 대규모 가중치와 피처맵을 보관하여 DRAM 접근 전력 소모 원천 차단 |
| 텐서 DMA 제어기 | 시스템 LPDDR 메모리와 온칩 SRAM 간 고속 블록 데이터 자동 전송 |
| 양자화/압축 엔진 | 모델 가중치 압축 해제 및 연산 결과의 INT8 스케일링 복원 |

#### 한줄 요약
- MAC 연산기 어레이, 온칩 SRAM, 벡터 유닛, 텐서 DMA가 하나의 저전력 칩 안에 집적되어 있다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **서브그래프 분할(Subgraph Partitioning)**: NPU가 지원하는 연산자와 미지원 연산자를 분류해 NPU와 CPU/GPU로 각각 분배 실행하는 작업.

</details>

```text
딥러닝 모델 개발 완료 (ONNX / TensorFlow Lite)
      │
      ▼
1. 모델 컴파일러: INT8/INT4 양자화 및 NPU 전용 서브그래프 분할
      │
      ▼
2. 텐서 DMA: 가중치 및 입력 텐서를 NPU 온칩 SRAM에 적재
      │
      ▼
3. 2D MAC 어레이: 행렬 곱셈 및 컨볼루션 연산 병렬 수행
      │
      ▼
4. 벡터 유닛: 활성화 함수 적용 및 양자화 스케일링 변환
      │
      ▼
5. 미지원 연산자 발생 시 CPU/GPU 폴백 처리 후 최종 결과 반환
```

**동작 원리**

1. **모델 컴파일**: 모델을 INT8로 양자화하고 NPU 가속 가능 영역을 분할하여 전용 바이너리 생성
2. **온칩 버퍼 적재**: 텐서 DMA가 입력 영상 및 모델 가중치를 온칩 SRAM에 직접 로드
3. **MAC 어레이 연산**: 수백~수천 개의 MAC 셀이 데이터를 공유하며 행렬 곱셈과 누산 동시 수행
4. **활성화 및 스케일링**: 벡터 유닛이 활성화 함수를 적용하고 정수 결과를 지정된 스케일로 보정
5. **결과 반환 및 폴백**: 연산 완료 결과를 호스트에 전달하고, 미지원 연산은 CPU/GPU와 협업해 완성

#### 한줄 요약
- 모델 컴파일 → SRAM 적재 → MAC 어레이 연산 → 활성화 및 양자화 보정 → 결과 반환 순으로 진행된다.

## Ⅴ. 종류 및 비교

| AI 추론 프로세서 | 온디바이스 NPU | 모바일 GPU | 모바일 CPU | 서버급 TPU |
|:---|:---|:---|:---|:---|
| 적용 기준 | 스마트폰·IoT 초저전력 실시간 추론 | 모바일 그래픽 및 복합 AI 연산 | 범용 제어 및 소규모 경량 추론 | 대규모 데이터센터 모델 학습/추론 |
| 핵심 특징 | 극저전력 MAC 어레이 및 온칩 SRAM 집적 | 범용 병렬 셰이더 기반 유연한 가속 | 직렬 명령어 고속 처리 및 높은 범용성 | 초대규모 시스톨릭 어레이 및 광통신망 |
| 한계 | 지원 연산자 제한·온칩 메모리 용량 한계 | NPU 대비 높은 소비 전력 및 발열 | 딥러닝 행렬 연산 처리 속도 극히 느림 | 고비용·막대한 전력 소모 및 이동성 불가 |

#### 한줄 요약
- 스마트폰 실시간 AI는 NPU, 유연한 병렬 가속은 GPU, 범용 처리는 CPU, 초대형 서버는 TPU를 쓴다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **QAT(Quantization-Aware Training)**: 학습 단계에서 양자화 손실을 미리 반영해 모델 정확도 하락을 방어하는 학습 기법.
- **폴백 오버헤드(Fallback Overhead)**: NPU 미지원 연산자를 CPU로 넘길 때 발생하는 메모리 복사 및 동기화 지연.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| INT8 양자화 시 모델 예측 **정확도 저하** | **QAT(양자화 인식 학습)** 및 민감 레이어 FP16 혼합 정밀도 적용 | 정확도 복원 및 추론 속도 유지 |
| NPU 미지원 연산자로 인한 **CPU 폴백 지연** | 모델 컴파일러 최적화 및 연산자 융합(Operator Fusion) 대체 | 칩 간 데이터 복사 오버헤드 원천 차단 |
| 대용량 모델 구동 시 온칩 SRAM 용량 부족 | 텐서 타일링(Tiling) 및 가중치 무손실 압축 기법 적용 | DRAM 트래픽 억제 및 전력 소모 최소화 |
| 장시간 AI 연속 구동 시 열 발생 및 쓰로틀링 | NPU 전용 **DVFS** 및 동적 파워 게이팅 제어 연동 | 배터리 수명 보호 및 일정한 성능 유지 |

#### 한줄 요약
- QAT로 정확도를 잡고, 연산자 융합으로 CPU 폴백을 없애며, 타일링과 DVFS로 발열과 전력을 다스린다.

## Ⅶ. 결론

- 초저전력 배터리 기반 온디바이스 AI 추론은 **NPU**, 가변적인 고성능 복합 연산은 **GPU** 선택

#### 한줄 요약
- 양자화 최적화와 연산자 융합, 온칩 SRAM 타일링을 통해 온디바이스 NPU의 와트당 처리 효율을 극대화해야 한다.
