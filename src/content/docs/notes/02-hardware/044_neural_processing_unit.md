## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **NPU(Neural Processing Unit)**: 딥러닝 인공신경망 추론을 저전력·고효율로 전용 가속 처리하도록 설계된 하드웨어 프로세서.
- **전용 연산 배열(Dedicated Compute Array)**: 신경망의 곱셈·누산(MAC) 연산을 2D 공간 구조 상에서 고속 병렬 처리하는 회로.
- **근접 메모리(Near-Compute Memory)**: 연산기 근처에 정적 임의 접근 메모리(SRAM)를 구획하여 메모리 이송 소모 전력을 최소화하는 구조.
- **AI(Artificial Intelligence)**: 학습된 신경망 모델 기반 가시/음성/텍스트 등을 추론하고 인식하는 지능형 기술.
- **CPU(Central Processing Unit)**: 제어 로직과 범용 명령 처리에 최적화된 프로세서.
- **GPU(Graphics Processing Unit)**: 수많은 코어 기반 스레드 병렬 처리를 통해 대용량 수치 계산을 가속하는 프로세서.

</details>

- 정의/개념: 온디바이스 **AI**의 저정밀 텐서 연산을 **전용 연산 배열** 및 근접 메모리 기반으로 전용 처리하는 **NPU**
- 배경/필요성: 범용 CPU·GPU의 단말 디바이스 배터리 및 발열 한계 내 지속적 추론 연산 시 전력 및 실시간 응답 지연 문제 극복

#### 한줄 요약

- NPU는 저정밀 MAC 배열과 근접 SRAM 재사용으로 외부 데이터 이동을 줄여 단말 추론의 전력과 지연을 낮춘다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **MAC 배열(Multiply-Accumulate Array)**: 다수의 저정밀(INT8/INT4) 곱셈과 누산 연산기를 2D 그리드로 배치한 하드웨어 로직.
- **온칩 SRAM(On-Chip SRAM)**: 가중치 및 피연산자 타일을 칩 내부에서 재사용하도록 지원하는 고속 메모리.
- **TOPS(Tera Operations Per Second)**: 1초당 수행 가능한 조(Tera) 단위의 최대 연산 처리량 지표.
- **종단 지연(End-to-End Latency)**: 입력 수용부터 NPU 연산 및 호스트 폴백 처리를 거쳐 최종 출력이 완료될 때까지의 총 소요 시간.

</details>

- 저정밀 텐서 연산을 고속 병렬 처리하는 **MAC 배열** 탑재
- 외부 DRAM 이동 전력을 극적으로 낮추는 **온칩 SRAM** 기반 데이터 재사용
- 단순히 이론적 **TOPS** 수치보다 폴백 오버헤드가 포함된 **종단 지연** 최적화 중점

#### 한줄 요약

- 명목 TOPS 수치보다 모델 연산자의 하드웨어 직접 지원률, CPU·GPU 폴백 오버헤드, 전후처리를 합산한 종단 지연이 성능을 결정한다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **모델 컴파일러(Model Compiler)**: 신경망 그래프 분석, 양자화, 하드웨어 연산자 매핑 및 코드 생성을 전담하는 소프트웨어 도구.
- **NPU 런타임(NPU Runtime)**: 컴파일된 그래프 텐서 작업을 하드웨어에 디스패치하고 메모리를 관리하는 실행 라이브러리.
- **호스트 폴백 경로(Host Fallback Path)**: NPU 미지원 연산자를 CPU 또는 GPU로 우회 전송하여 실행하는 예외 처리 경로.
- **MAC(Multiply-Accumulate)**: 신경망 행렬 연산의 기본 단위인 곱셈-누산 연산.

</details>

```text
                     [모델 컴파일러]
                            |
                            |
[MAC 배열•온칩 메모리] -- [NPU 런타임] -- [호스트 폴백 경로]
```

선의 의미: NPU 런타임을 구심점으로 컴파일된 신경망 텐서 코드, NPU 하드웨어 자원, 호스트 백업 실행 경로 간의 정적 인터페이스 관계.

| 구성요소 | 책임 |
|:---|:---|
| 모델 컴파일러 | 그래프 최적화, 저정밀 양자화, 서브그래프 분할 |
| NPU 런타임 | 커널 디스패치, 온칩 메모리 동기화 및 텐서 제어 |
| MAC 배열•온칩 메모리 | 저정밀 텐서 MAC 병렬 처리 및 온칩 텐서 보관 |
| 호스트 폴백 경로 | NPU 미지원 연산자 대상 CPU/GPU 대치 실행 |

#### 한줄 요약

- 컴파일러가 작업을 나누고 런타임이 NPU 실행과 호스트 폴백을 연결한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **서브그래프 분할(Subgraph Partitioning)**: 전체 딥러닝 연산 그래프를 NPU 가속 영역과 CPU/GPU 폴백 영역으로 분류하는 절차.
- **DMA(Direct Memory Access)**: 텐서 타일을 외부 DRAM에서 NPU 온칩 SRAM으로 고속 이송하는 제어기.
- **경계 텐서(Boundary Tensor)**: NPU와 호스트 폴백 장치 간에 교환되는 중간 연산 레이어 텐서 데이터.

</details>

```text
                    [컴파일된 추론 계획•입력]
                                |
                    1. 실행 계획•입력 등록
                                |
                    2. DMA 입력 타일 배치
                                |
              +-----------------------------------+
              | 반복: 실행 계획의 서브그래프     |
              |           [NPU 지원?]             |
              |          /          \             |
              |        [예]         [아니요]       |
              |         |              |           |
              | 3. NPU 저정밀 실행  4. 경계 텐서•폴백 |
              |          \            /           |
              |       5. 결과 통합•다음 구간     |
              +-----------------------------------+
                                |
                          [추론 결과 반환]
```

### 동작 원리

1. **실행 계획·입력 등록**: **서브그래프 분할** 결과 확인 및 실행 순서, 텐서 버퍼 할당.
2. **입력 타일 배치**: **DMA** 제어기를 통해 외부 메모리의 텐서 타일을 온칩 SRAM으로 배치.
3. **NPU 저정밀 실행**: NPU 지원 레이어 대상 **MAC 배열** 및 근접 메모리 기반 고속 처리.
4. **경계 텐서·폴백 실행**: NPU 미지원 레이어 발생 시 **경계 텐서**를 CPU/GPU로 이송 후 **호스트 폴백 경로** 구동.
5. **결과 통합·후속 실행**: 각 서브그래프 실행 결과를 통합하여 다음 레이어 전달 및 추론 완료.

#### 한줄 요약

- 런타임은 지원 서브그래프를 NPU에서 실행하고, 비지원 연산은 경계 텐서를 CPU·GPU로 전송해 처리한 뒤 결과를 다시 연결한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **온디바이스 추론(On-Device Inference)**: 네트워크 연결 없이 모바일, 가전, 자동차 단말 내부에서 직접 AI 모델을 구동하는 처리 방식.
- **SIMT(Single Instruction, Multiple Threads)**: GPU에서 사용하는 스레드 병렬 실행 모델.
- **동적 분기(Dynamic Branching)**: 런타임 조건에 따라 실행 경로가 크게 유동적으로 변경되는 제어 흐름.

</details>

| 신경망 실행 장치 | NPU | GPU | CPU |
|:---|:---|:---|:---|
| 적용 기준 | 모바일/Embedded 저전력 **온디바이스 추론** 시 | 서버/가전 대용량 데이터 병렬 및 학습 시 | 복잡한 제어 및 **동적 분기** 중심 전후처리 시 |
| 핵심 특징 | **NPU** 저정밀 **MAC 배열** 전용 아키텍처 | **GPU**의 **SIMT** 기반 고대역폭 병렬 처리 | **CPU** 범용 복잡 제어 파이프라인 |
| 한계 | 연산자 지원 제한 및 **호스트 폴백 경로** 발생 | 높은 소비 전력 및 발열 문제 | 텐서 병렬 연산 처리량의 한계 |

> 요약: 저전력 추론은 NPU, 범용 병렬은 GPU, 복잡 제어는 CPU 선정.

#### 한줄 요약

- 저전력 온디바이스 추론은 NPU, 가변 모델·범용 병렬 연산은 GPU, 동적 분기와 전후처리는 CPU가 적합하다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **양자화(Quantization)**: FP32 수치 표현을 INT8/INT4 등으로 변환하여 연산량 및 데이터 크기를 감소시키는 변환 기법.
- **보정(Calibration)**: Representative Dataset을 활용하여 양자화 시의 스케일 팩터를 산출하는 최적화 단계.
- **연산자 지원 범위(Operator Coverage)**: NPU 하드웨어 및 컴파일러가 매핑을 직접 지원하는 레이어 비율.
- **연산자 결합(Operator Fusion)**: Conv-ReLU-BN 등 연속 레이어를 단일 통합 커널로 합성하여 텐서 전송을 단축하는 최적화.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 저정밀 **양자화** 전환에 따른 모델 추론 정확도 하락 | **보정** 데이터셋 활용 및 QAT(Quantization-Aware Training) 적용 | FP32 대비 동등 수준 모델 정확도 보유 |
| 파편화된 **연산자 지원 범위**로 인한 폴백 오버헤드 | **연산자 결합** 및 칩 호환 레이어 기반 모델 리팩토링 | CPU-NPU 간 경계 텐서 메모리 복사 최소화 |
| 메모리 대역폭 한계로 인한 MAC 연산기 스타베이션 | 텐서 타일링 및 DMA 스트리밍-연산 겹침 처리 | 연산 유휴 시간 차단 |
| 모바일 전력/발열 한도 초과에 따른 Throttling | 동적 DVFS 적용 및 온칩 SRAM 재사용율 극대화 | 지속 종단 지연 성능의 안정적 유지 |

> 사례: Conv+BN+ReLU 레이어의 **연산자 결합**을 통한 NPU 단일 커널 매핑

#### 한줄 요약

- 지원 연산을 결합해 NPU 서브그래프를 넓히면 CPU•GPU 폴백의 복사•동기화가 줄어든다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **지원률(Support Coverage)**: Target 신경망 모델 전체 연산 중 NPU에서 하드웨어로 직접 구동 가능한 비율.
- **추론 장치 선택 기준(Inference Hardware Selection Criteria)**: 전력 한도, 실시간 지연시간 목표 및 모델 연산자 지원률에 기반한 하드웨어 결정 체계.

</details>

- **추론 장치 선택 기준**에 따라 높은 **지원률**과 저전력 환경 요구 시 **NPU** 적용

#### 한줄 요약

- 모델 지원률이 높고 폴백 전송 비용이 작아 종단 전력·지연이 개선될 때 단말 NPU를 적용한다.
