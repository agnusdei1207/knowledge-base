## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **세그멘테이션(Segmentation)**: 주소 공간을 코드•데이터•스택 같은 가변 길이 논리 영역으로 나눠 변환•보호하는 메모리 관리 방식이다.
- **논리 권한 경계**: 프로그램의 영역별로 서로 다른 범위와 읽기•쓰기•실행 권한을 적용하는 구분이다.
- **평면 주소 공간**: 코드•데이터•스택을 별도 논리 영역으로 구분하지 않고 하나의 연속 주소 범위로 다루는 구조이다.

</details>

- 정의/개념: 주소 공간을 가변 길이 논리 영역으로 나누고 기준·한계·권한으로 변환하는 **메모리 관리 방식**이다.
- 배경/필요성: 평면 주소 공간만으로는 코드·데이터·스택의 **영역별 경계와 권한 표현하기 어렵다**.

#### 한줄 요약

- 세그멘테이션은 세그먼트별 기준 주소·한계·접근 권한으로 논리 영역의 주소 변환과 보호를 수행한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **2차원 주소**: 세그먼트 번호와 그 영역 내부 오프셋으로 구성한 논리 주소이다.
- **기준 주소**: 세그먼트가 시작하는 물리 메모리 위치이다.
- **한계**: 세그먼트에서 허용하는 최대 오프셋 범위이다.
- **독립 성장**: 코드•데이터•스택 영역이 서로의 크기와 무관하게 확장되는 성질이다.
- **단일 단계 변환**: 기술자에서 기준 주소를 찾고 오프셋을 더해 한 번에 물리 주소를 만드는 변환 방식이다.

</details>

- **2차원 주소**로 논리 영역과 영역 내부 위치를 분리한다.
- 영역별 **한계·권한** 부여로 독립적인 크기와 보호 정책을 지원한다.
- 기준 주소 덧셈으로 끝나는 **단일 단계 변환**이 핵심이다.

#### 한줄 요약

- 세그먼트 번호와 오프셋을 분리하고 기술자의 기준 주소를 더해 영역별 주소 변환과 보호를 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **세그먼트 기술자**: 한 영역의 기준 주소•한계•존재 여부•접근 권한을 담은 항목이다.
- **보호 검사기**: 세그먼트 존재•범위•접근 권한을 확인하는 회로이다.
- **주소 생성기**: 검사를 통과한 기준 주소에 오프셋을 더해 물리 주소를 만드는 회로이다.
- **세그먼트 테이블**: 세그먼트 번호를 색인으로 각 논리 영역의 기술자를 저장하는 표이다.

</details>

```text
세그멘테이션 변환 구조
├─ 세그먼트 테이블
├─ 보호 검사기
└─ 주소 생성기
```

가지의 의미: 기술자 조회•보호 검사•주소 생성의 정적 책임 구성이다.

| 구성요소 | 책임 |
|:---|:---|
| 세그먼트 테이블 | **기준•한계•권한** 제공 |
| 보호 검사기 | 존재•범위•**권한 위반** 판정 |
| 주소 생성기 | 검증 주소의 **물리 주소** 산출 |

#### 한줄 요약
- 세그먼트 테이블이 영역 정보를 제공하고 보호 검사기를 통과한 주소만 생성기가 물리 위치로 바꾼다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **세그먼트 번호**: 변환할 논리 영역을 선택하는 주소 필드이다.
- **오프셋**: 선택한 세그먼트 안의 바이트 위치이다.
- **보호 예외**: 영역 부재•범위 초과•권한 위반 시 메모리 접근을 중단하는 예외이다.
- **중앙 처리 장치(Central Processing Unit, CPU)**: 메모리 접근 명령을 실행하는 장치이다.
- **접근 유형**: CPU가 요청한 읽기•쓰기•실행 동작의 종류이다.
- **보호•주소 변환기**: 기술자의 존재•한계•권한을 검사하고 기준 주소와 오프셋을 합산하는 하드웨어이다.

</details>

```text
세그먼트 번호•오프셋•접근 유형
              │
              ▼
    1. 세그먼트 기술자 조회
              │
              ▼
       2. 존재 여부 검사
              ├─ 부재: 보호 예외
              └─ 존재
                 └─ 3. 한계•권한 검사
                    ├─ 실패: 보호 예외
                    └─ 통과
                       └─ 4. 기준 주소•오프셋 합산
                          └─ 5. 물리 메모리 접근
                             └─ 데이터•완료 반환
```

**동작 원리**

1. **세그먼트 기술자 조회**: 세그먼트 번호로 기준 주소·한계·접근 권한을 확보한다.
2. **존재 여부 검사**: 선택한 세그먼트가 현재 사용할 수 있는 유효 영역인지를 판정한다.
3. **한계·권한 검사**: 오프셋이 한계 안에 있고 요청한 접근 유형이 허용되는지를 확인한다.
4. **물리 주소 산출**: 검사를 통과한 기준 주소와 오프셋을 더해 물리 주소를 생성한다.
5. **물리 메모리 접근**: 검증된 물리 주소로 데이터를 읽거나 쓰고 완료 결과를 반환한다.

#### 한줄 요약

- 보호 검사기는 세그먼트의 존재·범위·권한을 확인하고, 검사를 통과한 주소만 물리 주소로 변환한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **외부 단편화**: 가변 크기 영역 사이에 빈틈이 흩어져 충분한 총공간에도 연속 자리를 확보하지 못하는 현상이다.
- **페이징**: 주소 공간을 고정 크기로 나눠 비연속 물리 프레임에 배치하는 방식이다.
- **내부 단편화**: 고정 크기 페이지의 마지막 자투리가 사용되지 않아 생기는 낭비이다.
- **결합 방식**: 세그먼트로 논리 영역과 권한을 나누고 각 영역 내부를 페이지로 다시 나누는 세그먼트-페이징 구조이다.

</details>

| 주소 변환 방식 | 세그멘테이션 | 페이징 |
|:---|:---|:---|
| 적용 기준 | 논리 영역마다 **경계와 접근 권한**을 구분할 때 | 고정 크기 단위로 물리 프레임을 **비연속 배치**할 때 |
| 핵심 특징 | 가변 논리 영역의 **기준•한계** 변환 | 고정 페이지의 **비연속 프레임** 배치 |
| 한계 | 연속 자리를 요구하는 **외부 단편화** | 자투리가 남는 **내부 단편화** |

> 요약: 세그멘테이션은 논리 경계를 표현하고, 페이징은 연속 물리 공간 요구를 제거한다.

#### 한줄 요약

- 세그멘테이션은 논리 영역별 보호에 유리하지만 외부 단편화가 발생하고, 페이징은 비연속 배치가 가능하지만 내부 단편화를 부담한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **세그먼트-페이징**: 논리 영역으로 권한을 나눈 뒤 내부를 고정 페이지로 잘라 비연속 배치하는 결합 방식이다.
- **가드 영역**: 스택•힙 경계에 둔 접근 불가 구간으로 범위 침범을 예외로 탐지하는 영역이다.
- **TLB 지역성**: 반복 사용하는 주소 변환이 TLB에 남아 결합 변환의 조회 지연을 줄이는 성질이다.
- **변환 색인 버퍼(Translation Lookaside Buffer, TLB)**: 최근 주소 변환을 저장하는 캐시이다.
- **최소 권한**: 세그먼트에 필요한 접근 권한만 부여하는 원칙이다.
- **경계값 시험**: 한계 직전•직후 주소의 허용과 예외 처리를 검증하는 방법이다.
- **표 지역성**: 가까운 주소의 세그먼트•페이지 표 항목을 반복 조회해 캐시에 남을 가능성이 높은 성질이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 가변 세그먼트의 연속 배치로 **외부 단편화 발생** | **세그먼트 내부 페이징**으로 물리 프레임 분산 배치 | 큰 **연속 물리 공간 요구 완화** |
| 스택·힙이 서로를 향해 성장하여 **영역 충돌** | 성장 한계와 **가드 영역** 설정 | 경계 접근을 예외로 전환해 **침범 조기 탐지** |
| 세그먼트 기술자의 **권한·한계 설정 오류** | **최소 권한 적용·경계값 시험** | 허용 범위 밖 접근 차단으로 **메모리 보호 강화** |
| 세그먼트와 페이지 표를 모두 조회해 **변환 지연 증가** | **TLB와 표 지역성**을 활용해 변환 정보 재사용 | 메타데이터 조회 감소로 **주소 변환 지연 단축** |

#### 한줄 요약

- 세그먼트-페이징은 세그먼트의 논리 권한 경계와 페이징의 비연속 물리 배치를 결합한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **연속 공간 요구**: 세그먼트 전체를 물리 메모리의 이어진 한 구간에 배치해야 하는 제약이다.
- **비연속 배치**: 세그먼트 내부 페이지를 떨어진 물리 프레임에 나누어 놓는 방식이다.

</details>

- 권한 경계와 외부 단편화 공존 시 **세그먼트-페이징**을 적용한다.

#### 한줄 요약

- 논리 영역의 경계와 권한은 세그먼트로 구분하고, 각 영역의 물리 배치는 페이지로 분리한다.
