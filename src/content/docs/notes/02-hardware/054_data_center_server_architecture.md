## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **데이터센터 서버 구조(Data Center Server Architecture)**: 대규모 클라우드 가상화, 빅데이터 및 AI 워크로드를 초고효율·초고집적으로 처리하기 위해 연산(CPU/GPU), 메모리(DDR5/CXL), 스토리지(NVMe), 통신(DPU), 전력(CRPS) 및 냉각(DLC)을 최적화한 랙 실장형 서버 하드웨어 체계.
- **모듈러 섀시(Modular Chassis)**: 표준 19인치/21인치 랙(1U~4U) 내에서 컴퓨트 노드, 전원 공급기, 팬 모듈, 가속기 카드를 무중단 핫스왑 방식으로 독립 교체 및 확장할 수 있는 랙 마운트 프레임.

</details>

- 정의/개념: 고밀도 가상화 및 AI 워크로드를 위해 다중 소켓 CPU, GPU 가속기, DPU 스마트 NIC, 직접 액체 냉각(DLC)을 융합한 **데이터센터 서버 아키텍처**
- 배경/필요성: 클라우드 가상화 및 AI 워크로드 급증에 따른 랙당 전력 밀도 폭증, CPU 인프라 오버헤드(Tax) 및 **공랭 냉각 한계 극복 및 고집적 고효율 서버 하드웨어 아키텍처 구축 필요성 증대**

#### 한줄 요약
- 현대 데이터센터 서버는 고밀도 연산 코어, 이기종 가속기, DPU 스마트 NIC 및 직접 액체 냉각을 결합하여 고효율 클라우드 인프라를 지탱한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **NUMA(Non-Uniform Memory Access)**: 멀티 소켓 서버 환경에서 각 CPU가 자체 로컬 메모리를 가지며, 원격 메모리 접근 시 UPI/인터커넥트를 경유하는 비균일 메모리 접근 구조.
- **대역외 관리(Out-of-Band Management, OOB)**: 주 운영체제(OS)나 업무용 네트워크와 완전히 분리된 전용 물리 포트를 통해 서버의 전원 제어, 원격 콘솔, 하드웨어 진단을 수행하는 독립 관리 방식.

</details>

- 이종 컴퓨팅 집적: 범용 멀티코어 CPU, AI 가속용 GPU/NPU, 인프라 가속용 DPU가 결합된 이기종 아키텍처 구현
- 초고속 메모리/I/O 패브릭: **NUMA** 토폴로지 및 PCIe Gen5/CXL 버스를 기반으로 광대역폭 및 저지연 I/O 달성
- 24/7 무중단 원격 제어: BMC 컨트롤러와 Redfish 표준 API를 통한 무중단 대역외(**OOB**) 관리

#### 한줄 요약
- 이기종 컴퓨팅 집적, NUMA 및 CXL 고속 패브릭, BMC 대역외 관리를 통해 최고의 성능과 24/7 가용성을 달성한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **BMC(Baseboard Management Controller)**: 메인보드에 독립 실장되어 호스트 CPU/OS와 무관하게 전원, 온도 센서, 쿨링 팬, 펌웨어를 24시간 원격 감시/제어하는 전용 마이크로컨트롤러(ASPEED 칩셋 등).
- **데이터 처리 장치(Data Processing Unit, DPU)**: 가상 스위칭(OVS), 스토리지 가상화(NVMe-oF), IPSec/TLS 암호화 등 인프라 서비스를 CPU로부터 100% 오프로드하는 프로그래머블 SoC.

</details>

```text
[데이터센터 서버 아키텍처]
  │
  ├─ [냉각 인프라 계층] (DLC 및 공랭 하이브리드)
  │     └─ [직접 액체 냉각] (콜드 플레이트 매니폴드, 초고열 분산)
  │
  ├─ [이종 연산 서브시스템] (Compute Subsystem)
  │     ├─ [다중 소켓 CPU] (NUMA 도메인 0/1, DDR5 채널)
  │     └─ [GPU 가속 클러스터] (NVLink 풀메시 패브릭 직결)
  │
  ├─ [인프라 가속 & I/O 계층] (Infra & Memory Fabric)
  │     ├─ [DPU / SmartNIC] (가상화/스위칭/보안 100% 오프로드)
  │     ├─ [CXL 메모리 풀] (PCIe/CXL 캐시 일관성 확장)
  │     └─ [NVMe 스토리지] (E1.S 고밀도 고속 플래시 어레이)
  │
  └─ [대역외 관리 서브시스템] (OOB Management)
        └─ [BMC 컨트롤러] (ASPEED, Redfish/KVM 물리적 격리 제어)
```

선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 다중 소켓 CPU | 범용 OS·가상화·비즈니스 로직의 x86/ARM 연산 |
| GPU 가속 클러스터 | NVLink 풀메시 기반 AI 행렬 연산 가속 |
| DPU / SmartNIC | 네트워크 가상화·스토리지·보안 오프로드 |
| CXL 메모리 풀 | 캐시 일관성 기반 저지연 메모리 풀링 |
| 직접 액체 냉각 (DLC) | 콜드 플레이트로 CPU·GPU 열 직접 흡수 |
| BMC 컨트롤러 | Redfish/IPMI 기반 원격 전원·센서 관리 |

#### 한줄 요약
- DPU가 CPU 코어에서 돌던 네트워크·스토리지 처리를 NIC 계층으로 내려 범용 연산에 쓸 코어를 되돌려주고, CXL 메모리 풀은 소켓에 직접 물려야 했던 용량 증설을 패브릭 너머로 옮기며, BMC는 OS가 멈춘 뒤에도 남는 별도 관리 계층을 맡는다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **코어 친화도(Core Affinity / NUMA Binding)**: 특정 프로세스나 I/O 인터럽트 핸들러를 물리적으로 가장 가까운 NUMA 노드의 CPU 코어에 고정 실행하여 메모리 지연을 최소화하는 기법.

</details>

```text
+-------------------------------------------------------------+
|         ToR 스위치로부터 초고속 네트워크 패킷 인입          |
+-------------------------------------------------------------+
                               │
                               ▼
+-------------------------------------------------------------+
| 1. DPU 하드웨어 오프로드: 패킷 헤더 파싱 및 Zero-Copy DMA    |
+-------------------------------------------------------------+
                               │
                               ▼
+-------------------------------------------------------------+
| 2. OS 스케줄러의 NUMA 친화도(Core Affinity) 기반 코어 배정  |
+-------------------------------------------------------------+
                               │
                               ▼
               +-------------------------------+
               |     소켓 메모리 참조 판정     |
               +-------------------------------+
                      |                 |
             [로컬 NUMA 메모리]        | [원격 NUMA 소켓]
                      |                 v
                      | +-------------------------------+
                      | | UPI/CXL 인터커넥트 경유 지연  |
                      | +-------------------------------+
                      v                 |
+---------------------------------------+
| 3. CPU 및 GPU 가속 연산 즉시 실행                           |
+-------------------------------------------------------------+
                               │
                               ▼
+-------------------------------------------------------------+
| 4. CXL 풀 및 NVMe 스토리지 트랜잭션 완료 및 데이터 커밋     |
+-------------------------------------------------------------+
                               │
                               ▼
+-------------------------------------------------------------+
| 5. BMC 텔레메트리 센서 수집 및 동적 쿨링/전력 캐핑 제어     |
+-------------------------------------------------------------+
```

분기 결과: 로컬 **NUMA** 노드에 바인딩 시 지연시간을 최소화하며 **BMC** 상시 감시를 통해 열 폭주를 차단함

**동작 원리**

1. **패킷 수신 및 DPU 오프로드**: ToR 스위치로부터 들어온 초고속 이더넷 패킷을 DPU가 수신하여 가상 스위칭과 암호 해독을 하드웨어에서 오프로드 처리한 뒤 호스트 메모리로 제로 카피 DMA 전송
2. **NUMA 친화도 코어 배정**: 운영체제 커널이 프로세스의 메모리 페이지가 위치한 NUMA 소켓과 동일한 물리 코어에 태스크 바인딩(NUMA Binding)하여 인터커넥트 지연 억제
3. **가속 연산 병렬 실행**: 로컬 메모리 참조가 확인되면 CPU 코어 및 연동된 GPU 가속기가 고속 메모리 버스를 통해 병렬 연산 즉시 수행
4. **저지연 스토리지 커밋**: 연산 결과 데이터가 저지연 CXL 확장 메모리 버퍼 또는 PCIe Gen5 NVMe 스토리지로 트랜잭션 안전성을 보장하며 일괄 기록
5. **BMC 텔레메트리 동적 제어**: 연산 중 메인보드 전역의 온도 및 전류 센서를 BMC가 실시간 폴링하여 CDU 액체 유량과 팬 속도를 최적화하고 임계 초과 시 하드웨어 클록 자동 캐핑

#### 한줄 요약
- DPU 오프로드와 NUMA 친화 배치는 모두 데이터가 지나는 경로를 짧게 만드는 조치이며, 원격 노드 접근은 UPI를 한 번 더 경유해 로컬보다 큰 지연을 물기에 코어 배정이 곧 성능이 된다.

## Ⅴ. 종류 및 비교

| 대상 구분 | 범용 연산 랙 서버 (1U/2U) | 고밀도 AI 가속 서버 (4U/8U) | OCP 모듈러 블레이드 서버 | 엣지 마이크로 서버 |
|:---|:---|:---|:---|:---|
| 적용 기준 | 표준 웹/WAS 및 기업용 관계형 DB 호스팅 시 | 초거대 LLM 분산 훈련 및 고밀도 HPC 가속 시 | 하이퍼스케일 클라우드 대규모 가상화 집적 시 | 원격 기지국 및 산업 자동화 현장 엣지 분산 처리 시 |
| 핵심 특징 | 다중 코어 CPU + DDR5 메모리, 표준 19인치 공랭 섀시, 범용 PCIe 확장 슬롯 | 8개 이상 GPU 클러스터 탑재, **NVLink 풀메시 패브릭**, 직접 액체 냉각(DLC) 기반 40kW+ 발열 제어 | 섀시 공유 전원(CRPS) 및 팬 블록, **무중단 핫플러그 노드 실장**, 오픈 하드웨어 표준 | 초소형 폼팩터, 저전력 SoC/NPU 탑재, **무팬(Fanless) 방열 설계**, 열악한 산업 환경 내구성 |
| 한계 | 고밀도 가속기 장착 제한, 공랭 방식의 열 수용 한계(20kW 미만), AI 훈련 비효율 | 초고전력 소모(랙당 40~100kW), 액체 냉각 배관 인프라 구축 필수, 도입 비용 극고가 | 표준 데이터센터 전용 랙 규격(21인치) 종속, 기존 19인치 인프라 호환성 제약 | 연산 및 메모리 확장성 극제약, 대규모 모델 구동 불가, 소형 단독 워크로드 국한 |

#### 한줄 요약
- 일반 클라우드에는 범용 랙 서버가, 초거대 AI 모델에는 DLC 액체 냉각 기반 AI 가속 서버가 표준으로 적용된다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **파워 캐핑(Power Capping)**: 랙 전체 전력 공급 한도를 초과하지 않도록 BMC가 CPU/GPU 클록 주파수를 동적으로 제어하는 전력 통제 기술.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 소켓 간 원격 메모리 접근으로 인한 NUMA 지연 급증 | **로컬 메모리 바인딩** 및 인터럽트 **코어 친화도** 설정 | 메모리 지연 단축 및 트랜잭션 처리량 30% 향상 |
| 랙당 전력 밀도 40kW 초과로 인한 공랭 냉각 한계 | **직접 액체 냉각(DLC)** 및 CDU 연동 체계 구축 | PUE 1.1 미만 달성 및 열 스로틀링 원천 차단 |
| 네트워크 패킷 처리 및 암호화로 인한 CPU 낭비 | **DPU 기반 인프라 가속** 및 하드웨어 오프로드 | 순수 비즈니스 로직용 CPU 코어 100% 확보 |
| 원격 침해로 인한 BMC 펌웨어 변조 위험 | **하드웨어 RoT** 칩 실장 및 암호화 서명 부팅 | 공급망 펌웨어 공격 차단 및 안전한 복구 보장 |

#### 한줄 요약
- 실무에서는 NUMA 바인딩으로 지연을 잡고, DLC 수랭으로 초고밀도 발열을 해소하며, DPU와 RoT로 성능과 보안을 확보한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **냉각 분배 장치(Cooling Distribution Unit, CDU)**: 고밀도 서버 랙 내부로 냉각수를 정밀 순환시키고 유량과 온도를 제어하여 외부 시설 루프와 열을 교환하는 액체 냉각 장비.
- **신뢰의 닻/하드웨어 신뢰점(Root of Trust, RoT)**: 위변조가 불가능한 보안 하드웨어를 기반으로 부팅 초기 단계부터 시스템 펌웨어의 암호화 무결성을 검증하는 보안 기준점.

</details>

- **모듈러 패브릭 및 액체 냉각 진화**: DPU 인프라 오프로드와 냉각 분배 장치(Cooling Distribution Unit, CDU) 기반 직접 액체 냉각(DLC)을 축으로, CXL 메모리 풀링 및 개방형 컴퓨트 프로젝트(Open Compute Project, OCP) 랙 표준 중심의 고도화 추세.
- **실무 열 밀도 통제 및 보안 무결성 통찰**: 랙당 수십 kW 전력 밀도 급증에 대응하여 공랭-수랭 전환 임계치를 엄밀히 산정하고, 신뢰의 닻/하드웨어 신뢰점(Root of Trust, RoT) 기반의 원격 침해 및 펌웨어 변조 방어 아키텍처 구축 필수.

#### 한줄 요약
- CDU 기반 직접 액체 냉각과 OCP 모듈러 랙 구조로 진화하고 있으며, 열 밀도에 따른 냉각 방식 절환과 하드웨어 RoT 보안 체계 확립이 인프라 설계의 핵심이다.
