## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **제이태그(Joint Test Action Group, JTAG)**: 칩 핀이 안 보여서 테스터기로 찍어볼 수 없을 때, 단 4개의 선만 꽂아서 칩 내부를 훔쳐보고 조종하는 기가 막힌 해킹 겸 테스트 인터페이스이다.
- **탭(Test Access Port, TAP)**: JTAG 통신을 위해 칩 외부에 뚫어놓은 개구멍으로, 이 구멍에 4가닥 선(클럭, 모드, 인, 아웃)을 꽂아 칩을 노예처럼 부린다.
- **경계 스캔(Boundary Scan)**: 칩 내부의 진짜 뇌(코어)는 잠재워두고, 껍데기 핀들에만 첩자를 심어서 전기가 제대로 통하는지 억지로 검사하는 기술이다.

</details>

- 정의: 탭(TAP) 상태 머신 및 경계 스캔 셀 체인을 통해 기판 물리 핀 납땜 및 배선 단락을 비침습 방식으로 검사하는 **제이태그**
- 배경: 칩 발이 밑바닥에 숨어있는 고밀도 패키지(BGA) 시대가 오면서, 납땜이 잘됐는지 핀에 뾰족한 탐침을 찔러넣는 게 불가능해져 비접촉 자동화 검사가 절실했기 때문

#### 한줄 요약

- 칩 발이 안 보여서 테스터기를 못 댈 때, 선 4개만 꽂으면 칩 껍데기에 심어둔 첩자(경계 스캔 셀)들이 알아서 납땜 불량을 찾아내고 펌웨어도 쑤셔 넣는 마법의 포트이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **직렬 스캔 체인(Serial Scan Chain)**: 칩 100개가 기판에 붙어있어도, 1번 칩 입구로 쑤셔 넣은 데이터가 100번 칩 엉덩이로 빠져나오게 뱀처럼 엮어버린 기가 막힌 구조이다.
- **경계 스캔 셀(Boundary-Scan Cell)**: 칩의 핀 하나하나에 기생충처럼 딱 달라붙어 있는 하드웨어 회로로, 평소엔 숨어있다가 JTAG가 명령하면 핀을 지 맘대로 껐다 켰다 조종한다.

</details>

- 수많은 칩의 핀 검사를 단 4개의 포트로 통합 수용하는 기가 막힌 **직렬 스캔 체인** 구조를 가짐.
- 칩 안의 진짜 뇌(코어)는 잠시 분리해 두고, 껍데기 핀들만 따로 조종하는 **경계 스캔 셀**을 구동함.
- 기판 납땜 불량 검사를 넘어, 프로세서 내부 레지스터 조작, 펌웨어 굽기, CPU 정지(브레이크포인트)까지 무자비하게 수용함.

#### 한줄 요약

- 칩들을 뱀처럼 한 줄로 엮고(스캔 체인), 핀마다 심어둔 첩자(경계 스캔 셀)를 조종해서 납땜 불량도 잡고 칩 해킹(디버깅)도 한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **탭 제어기(TAP Controller)**: JTAG 포트로 들어오는 모드(TMS) 신호를 보고 "명령어 받을까? 데이터 뺄까?"를 16단계 상태로 휙휙 바꾸는 칩 안의 지휘관이다.
- **명령 레지스터(Instruction Register, IR)**: "지금부터 핀을 강제로 켤 테니 엎드려!" 같은 JTAG의 무자비한 작전 지시서를 받아 적는 공간이다.
- **데이터 레지스터(Data Register, DR)**: 명령에 따라 칩 핀의 상태(BSR)나 칩 아이디(ID)를 기차에 싣고 밖으로 실어 나르는 데이터 통로이다.
- **티디아이 티디오(TDI/TDO)**: 데이터 기차가 칩 안으로 들어가는 터널 입구(TDI)와, 칩을 다 돌고 밖으로 튀어나오는 출구(TDO) 핀이다.

</details>

```text
[ 제이태그 칩 내부 스파이 조종 및 데이터 빼돌리기 아키텍처 ]
                        [ 명령 레지스터 (작전 지시서) ]
                               │
[ 탭 제어기 (지휘관) ] ────────┴──────── [ 데이터 기차 선로 (DR) ]
  (TMS, TCK 신호 밭음)                            │
                                         [ 핀 기생충 (경계 스캔 셀) ]
```

| 구성요소 | 책임 |
|:---|:---|
| **탭 제어기** | TMS 신호를 받아 16단계 상태 머신(FSM)을 미친 듯이 휙휙 돌리며 칩을 조종하는 지휘관 |
| **명령 레지스터** | 핀을 강제 구동할지(EXTEST), 구경만 할지(SAMPLE) 명령어를 받아 적는 작전 지시서 |
| **데이터 레지스터** | 핀 껍데기 상태 데이터(BSR)나 칩 고유 아이디(IDCODE)를 싣고 나르는 데이터 기차 |
| 경계 스캔 셀 | 칩 핀에 딱 달라붙어서 핀의 상태를 훔쳐보거나(Capture) 억지로 전기를 쑤셔 넣는(Update) 첩자 |

#### 한줄 요약

- 지휘관(TAP 제어기)이 작전(명령 레지스터)을 내리면, 핀에 붙은 첩자(경계 셀)가 움직이고 그 결과를 기차(데이터 레지스터)에 실어 빼낸다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **외부 테스트(External Test, EXTEST)**: "코어는 냅두고 핀들끼리 합선(쇼트) 났는지 테스트해!"라며 칩 껍데기에 전기를 억지로 뿜어내는 가장 잔인한 JTAG 명령이다.
- **시험 패턴(Test Pattern)**: 합선 불량을 잡기 위해 핀들에 쑤셔 넣는 '010101' 같은 미끼 비트열이다. 1을 넣었는데 건너편에서 0이 나오면 불량이다.

</details>

```text
[ 제이태그 핀 쇼트(합선) 불량 색출 직렬 비트열 밀어내기 잔혹 흐름 ]
                               │
                               ▼
   [ 1. 작전 하달: 탭 제어기를 돌려 핀을 강제 조종하는 외부 테스트(EXTEST) 명령 인가 ]
                               │
                               ▼
     [ 2. 선로 변경: 칩 아이디 통로를 끊고, 경계 스캔 셀(BSR) 쪽으로 기차 선로 전환 ]
                               │
                               ▼
     [ 3. 시한폭탄 장전: TDI 핀으로 시험 패턴 비트 기차를 밀어 넣어 셀마다 장전(Shift) ]
                               │
                               ▼
        [ 4. 강제 조작: 장전된 폭탄을 터뜨리듯(Update), 핀 밖으로 전기를 억지로 뿜어냄 ]
                               │
                               ▼
   [ 5. 스파이 관측: 건너편 핀의 전기를 훔쳐보고(Capture) 밖으로 빼내어 합선 여부 심판 ]
```

### 동작 원리

1. 작전 명령 인가: 탭 제어기를 돌려 명령 레지스터(IR)에 핀을 강제로 조종하겠다는 **외부 테스트**(EXTEST) 작전을 얄짤없이 하달함.
2. 데이터 기차 선로 변경: 칩 아이디 확인용 선로를 끊고, 경계 스캔 셀들이 엮인 선로(BSR)로 기차 길을 바꿈.
3. 폭발물 시한폭탄 장전: TDI 핀으로 0과 1로 된 **시험 패턴** 비트열 기차를 밀어 넣어 핀 셀마다 장전(Shift-DR)시킴.
4. 핀 상태 강제 조작: 장전된 폭탄을 터뜨리듯(Update-DR), 칩의 바깥쪽 물리 핀으로 전기를 억지로 뿜어냄.
5. 스파이 관측 및 회수: 건너편 칩의 핀에서 날아온 전기를 훔쳐보고(Capture-DR), TDO 핀으로 비트열을 빼내 쇼트(합선) 불량을 색출함.

#### 한줄 요약

- EXTEST 명령을 내리고 미끼 비트를 장전한 뒤, 전기를 강제로 뿜어내고 건너편에서 제대로 받았는지 훔쳐봐서 납땜 불량을 잡아낸다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **에스더블유디(Serial Wire Debug, SWD)**: 핀 4~5개를 쓰는 JTAG가 뚱뚱하다고, 단 2가닥 핀만으로 Arm 코어의 뇌를 뼛속까지 파고드는 가성비 극강의 디버깅 포트이다.
- **유아트(Universal Asynchronous Receiver-Transmitter, UART)**: 코드 멈추고 메모리 뒤지는 고급 기능은 없고, 그냥 터미널 창에 "부팅 성공" 같은 텍스트 로그만 띄워주는 가장 만만한 통신이다.

</details>

| 디버그 인터페이스 | **제이태그** (JTAG / IEEE 1149.1) | **에스더블유디** (Serial Wire Debug) | **유아트** (UART 콘솔) |
|:---|:---|:---|:---|
| 시스템 적용 최적 기준 | 공장에서 기판(PCB) 핀 납땜 삑사리를 잡거나 수십 개의 칩을 줄줄이 엮어 검사할 시 | 핀 수가 모자란 쥐꼬리만 한 Arm 칩을 뼛속까지 파고들어 펌웨어 디버깅을 할 시 | 프로그램이 살아서 잘 도는지 터미널 화면에 글씨(로그)만 띄워볼 시 |
| 아키텍처 핵심 구현 특징 | 4~5가닥의 핀으로 칩들의 껍데기(경계 셀)를 사슬처럼 엮어 기판 불량을 기가 막히게 잡아냄 | 단 2가닥의 핀(클럭, 데이터)만으로 Arm 코어와 메모리를 직접 쑤시고 다니는 극강의 가성비 달성 | 가장 만만하고 오래된 비동기 직렬 텍스트 통신으로, 단순히 터미널 창에 텍스트만 찍어냄 |
| 극복해야 할 태생적 한계점 | 핀을 5개나 처먹고, 출하 후 퓨즈를 안 막으면 해커가 펌웨어를 통째로 뽑아가는 보안 대형 참사 유발 | Arm 칩 전용이라 딴 동네에선 못 쓰고, 기판 핀 납땜 불량(Boundary Scan)은 물리적으로 잡아낼 수 없음 | 디버그 브레이크포인트(코드 멈추기)나 칩 핀 하드웨어 검사는 아예 불가능한 깡통 로그 기능 한계 |

#### 한줄 요약

- 기판 납땜 불량 검사는 JTAG, 핀 아끼며 칩 내부 버그 잡는 건 SWD, 그냥 글자만 띄워보는 건 UART를 쓴다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **디버그 퓨즈 잠금(Debug Fuse Lock)**: 칩 안에 있는 전자 퓨즈를 레이저나 고전압으로 지져서 영원히 끊어버려, 해커가 JTAG 포트를 꽂아도 칩이 아무 반응 안 하게 만드는 최후의 보안 방패이다.
- **우회 패스(BYPASS)**: 스캔 체인 중간에 있는 칩이 뻗어버리면, "너는 데이터 건드리지 말고 그냥 1비트만 딜레이시켜서 바로 패스해라"라고 명령해 나머지 체인을 살리는 꼼수이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 공장 출하 후 **제이태그** 포트를 열어뒀더니 해커가 꽂아서 펌웨어와 암호 키를 싹 다 뽑아가는 끔찍한 보안 대참사 발발 | 출하 직전에 칩 내부의 eFuse를 레이저로 태워 끊어버리는 얄짤없는 **디버그 퓨즈 잠금** 인가 및 JTAG 비활성화 | 칩이 뼛속까지 박살 나지 않는 한 그 누구도 펌웨어에 접근할 수 없는 하드웨어 원천 차단 100% 달성 |
| 줄줄이 엮인 스캔 체인 상에서 중간에 있는 칩 하나가 뻗어버려 전체 테스트 라인이 통째로 셧다운되는 마비 사태 | 뻗어버린 칩에 **우회 패스**(BYPASS) 명령을 내려 데이터를 1비트만 거치게 하고 그냥 점프시켜 버림 | 한 놈이 죽어 자빠져도 나머지 멀쩡한 체인의 테스트 가용성을 멱살 잡고 강제로 유지시켜 줌 |
| 핀 강제 구동 테스트(EXTEST) 도중 합선(Short)된 핀에 전기를 잘못 뿜어내 보드와 칩이 아예 타버리는 끔찍한 파손 위험 | 전원 핀이나 민감한 핀은 건드리지 못하게 사전에 안전 핀 마스크를 씌워 구동을 원천 통제 | 핀 강제 조작으로 애먼 칩 껍데기를 태워 먹는 물리적 전기 파손 참사를 완벽하게 예방함 |

#### 한줄 요약

- 테스트 끝난 JTAG는 eFuse를 지져서 해커가 펌웨어를 못 빼가게 잠그고, 중간 칩이 죽으면 BYPASS로 패스시키며, 위험한 핀은 안 건드리게 조심해라.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **제이태그 운영(JTAG Operation)**: 공장에서는 핀 불량을 잡고 펌웨어를 굽는 효자지만, 출하 후에는 보안을 뚫어버리는 악마가 되므로 생애주기에 따라 철저히 관리하는 룰이다.

</details>

- **제이태그 운영** 원칙에 따라 양산 라인에선 기판 불량 색출용 **외부 테스트**(EXTEST)를 허용하되, 고객 출하 시엔 **디버그 퓨즈 잠금**으로 포트를 영구 파괴함

#### 한줄 요약

- 공장에서 테스트할 때는 JTAG로 칩을 마음껏 유린하고, 시장에 팔 때는 해커가 못 쓰게 퓨즈를 끊어버려라.
