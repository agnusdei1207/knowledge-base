## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **JTAG(Joint Test Action Group, IEEE 1149.1)**: 집적회로(IC)의 물리적 핀 납땜 결선 테스트(경계 스캔)와 플래시 펌웨어 다운로드 및 CPU 온칩 디버깅을 지원하는 4/5선 표준 하드웨어 직렬 인터페이스.
- **경계 스캔(Boundary Scan)**: IC 내부 핵심 로직과 외부 I/O 패드 사이에 경계 스캔 셀(Boundary Scan Cell)을 배치하여, 물리적 탐침(Probe) 접촉 없이 직렬 신호만으로 핀의 전압 레벨을 읽고 쓰는 검사 기술.

</details>

- 정의/개념: IC 내부 로직과 I/O 핀 사이에 배치된 **경계 스캔(Boundary Scan)** 셀을 직렬 제어하여 PCB 배선 검사와 온칩 디버깅을 수행하는 **JTAG(IEEE 1149.1) 표준 인터페이스**
- 배경/필요성: 고밀도 다층 BGA(Ball Grid Array) 패키징의 확산으로 물리적 오실로스코프 탐침 접촉이 불가능해짐에 따른 **PCB 납땜 결함(단선/단락)의 비파괴 전기적 검사 및 온칩 디버깅 필요**

#### 한줄 요약
- JTAG은 경계 스캔 셀을 직렬 데이지 체인으로 연결하여 PCB 납땜 결함을 비파괴 검사하고 온칩 디버깅을 수행하는 표준 규격이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **TAP(Test Access Port) 컨트롤러**: TMS(Test Mode Select)와 TCK(Test Clock) 신호의 변화에 따라 동작하는 16개 상태를 가진 하드웨어 유한 상태 머신(16-State FSM).
- **BSDL(Boundary Scan Description Language)**: 특정 IC의 JTAG 아키텍처, 핀 구성, 지원 명령어 및 경계 스캔 셀 순서를 기술한 표준 VHDL 기반 설명 파일.

</details>

- 소수 핀 직렬 인터페이스: 4개 필수 신호선(**TCK, TMS, TDI, TDO**)과 선택적 리셋선(**TRST**)만으로 복잡한 칩 내부 및 핀 제어
- 16-상태 FSM 제어: **TAP 컨트롤러** 상태 머신을 기반으로 명령어 레지스터(IR)와 데이터 레지스터(DR)의 캡처(Capture), 시프트(Shift), 갱신(Update) 통제
- 직렬 데이지 체인(Daisy Chain): 복수의 IC 칩을 단일 TDI-TDO 직렬 체인으로 묶어 단 하나의 커넥터 헤더로 메인보드 전체 검사

#### 한줄 요약
- 4개 전용 핀으로 16상태 TAP FSM을 구동하여 칩 내부 로직과 외부 배선을 완전히 분리 검사하며 데이지 체인으로 확장된다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **명령어 레지스터(Instruction Register, IR)**: 실행할 테스트 모드 명령어(EXTEST, SAMPLE/PRELOAD, BYPASS 등)를 시프트 저장하고 디코딩하는 레지스터.
- **경계 스캔 레지스터(Boundary Scan Register, BSR)**: 칩의 모든 I/O 핀과 내부 로직 사이에 직렬 연결되어 실제 핀의 입출력 신호를 래치하는 스캔 셀 집합.
- **바이패스 레지스터(Bypass Register)**: 비검사 칩을 지날 때 직렬 경로를 1비트로 단축하여 스캔 지연을 최소화하는 1비트 레지스터.

</details>

```text
[JTAG TAP 하드웨어 아키텍처]
 ┌─ [TAP 인터페이스 신호선] ──────── TCK (클록) / TMS (모드 제어) / TRST (비동기 리셋)
 │
 ├─ [TAP 컨트롤러 (16-State FSM)] ── TMS/TCK에 따라 Capture, Shift, Update 신호 발생
 │
 ├─ [명령어 레지스터 (IR)] ───────── TDI ──► [IR 시프트 레지스터] ──► TDO (EXTEST/SAMPLE/BYPASS)
 │
 └─ [데이터 레지스터 (DR 그룹)]
     ├─ [경계 스캔 레지스터 (BSR)] ── TDI ──► [스캔 셀 0 ~ 스캔 셀 N (I/O 핀 직결)] ──► TDO
     ├─ [디바이스 ID 레지스터 (IDCODE)] TDI ──► [32비트 제조사/파트 식별자] ──────────► TDO
     └─ [바이패스 레지스터 (BYPASS)] ── TDI ──► [1비트 단축 시프트 레지스터] ────────► TDO
```

선의 의미: 가지(`├─`, `└─`)는 하드웨어 소속 및 포함 관계; TAP 컨트롤러가 IR과 DR 레지스터의 시프트 경로를 선택하여 TDO로 출력함

| 구성요소 | 소속 및 위치 | 핵심 엔지니어링 책임 | 주요 특징 |
|:---|:---|:---|:---|
| **TAP 컨트롤러** | 칩 내부 제어부 | TMS 신호에 따라 16개 FSM 상태를 전이하며 IR/DR 시프트 통제 | 하드웨어 16-State FSM |
| **명령어 레지스터 (IR)**| 칩 내부 제어단 | EXTEST(외부 배선 검사), SAMPLE(신호 캡처), BYPASS 명령어 디코딩 | 직렬 시프트 레지스터 |
| **경계 스캔 레지스터 (BSR)**| I/O 핀 패드 경계 | 각 물리 핀의 신호를 구동하거나 수신 신호를 캡처하여 직렬 전송 | I/O 핀 수만큼 셀 구성 |
| **바이패스 레지스터** | 칩 내부 바이패스단| 현재 검사하지 않는 칩의 데이터 경로를 **단 1비트로 단축** | 데이지 체인 오버헤드 축소 |
| **IDCODE 레지스터** | 칩 내부 식별단 | 칩 제조사, 파트 번호, 버전 정보를 담은 32비트 식별 코드 제공 | 32-bit 고유 ID |

#### 한줄 요약
- JTAG 시스템은 TAP 컨트롤러, 명령어 레지스터(IR), 경계 스캔 레지스터(BSR), 바이패스 레지스터 및 4개 신호선으로 구성된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **EXTEST 명령어**: 칩 내부 코어 로직을 핀과 전기적으로 분리하고, 경계 스캔 셀을 통해 칩 외부 PCB 패턴의 단선(Open) 및 단락(Short) 결함을 검사하는 표준 명령어.

</details>

```text
1. JTAG 테스트 장비 연결 ➔ TMS=1을 5클록 이상 인가하여 모든 칩 TAP 리셋 (Test-Logic-Reset)
                      │
                      ▼
2. IR(명령어 레지스터) 시프트 경로 선택 ➔ 외부 결선 검사 명령어(EXTEST) 직렬 적재
   (비검사 대상 칩들은 BYPASS 명령어 적재)
                      │
                      ▼
3. DR(데이터 레지스터) 시프트 경로 선택 ➔ 송신 칩의 BSR로 테스트 패턴 비트열 직렬 주입
                      │
                      ▼
4. Update-DR 상태 전이 ➔ 송신 칩 I/O 핀을 통해 PCB 배선으로 전압 신호 일제히 출력
                      │
                      ▼
5. Capture-DR 상태 전이 ➔ 수신 칩 I/O 핀의 경계 스캔 셀이 PCB 배선 전압을 1클록에 캡처
                      │
                      ▼
6. Shift-DR 상태 전이 ➔ 캡처된 비트열을 TDO 신호선으로 직렬 인출
                      │
                      ▼
7. 테스트 장비: 인출된 비트열과 원본 넷리스트(Netlist) 정합성 비교
   ┌──────────────────┴──────────────────┐
[ 넷리스트 일치 (Pass) ]              [ 불일치 감지 (Fail) ]
   │                                     │
   ▼                                     ▼
8. PCB 납땜 및 배선 정상 판정         8. 결함 발생 핀 번호 및 단선/단락 위치 즉각 특정
```

분기 결과: **EXTEST 명령어를 통해** 물리적 탐침 없이 직렬 시프트만으로 BGA 핀의 납땜 불량(냉납, 브리지) 위치를 100% 특정함

#### 한줄 요약
- TAP 리셋 ➔ EXTEST 명령어 로드 ➔ 패턴 시프트 주입 ➔ 핀 전압 구동 및 캡처 ➔ TDO 인출 비교 검증 순으로 동작한다.

## Ⅴ. 종류 및 비교

| 하드웨어 디버그/테스트 인터페이스 | JTAG (IEEE 1149.1) | SWD (Serial Wire Debug) | UART 디버깅 | 인서킷 에뮬레이터 (ICE) |
|:---|:---|:---|:---|:---|
| 필수 물리 신호선 수 | **4~5선 (TCK, TMS, TDI, TDO, TRST)**| **2선 (SWCLK, SWDIO)** | 2선 (TX, RX) | 수십~수백 개 전용 소켓 핀 |
| 경계 스캔 (배선 검사)| **완벽 지원 (BSR 기반 PCB 결선 검사)**| **미지원 (온칩 디버깅 전용)** | 미지원 | 미지원 |
| 다중 칩 데이지 체인 | **지원 (단일 헤더로 복수 칩 연결)** | 미지원 (점대점 직결) | 멀티드롭 제한적 | 미지원 |
| 주요 적용 분야 | **PCB 제조 양산 테스트, 대형 SoC/FPGA**| **초소형 MCU (ARM Cortex-M 디버깅)**| 단순 콘솔 로그 출력, 펌웨어 CLI | 레거시 CPU 하드웨어 전용 분석 |

#### 한줄 요약
- 보드 제조 납땜 검사와 복수 칩 검사에는 JTAG이 표준이며, 핀 수가 부족한 초소형 MCU 디버깅에는 SWD가 쓰인다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **JTAG 보안 퓨즈(JTAG Security eFuse / Lock)**: 제품 양산 출하 시 반도체 내부의 eFuse를 전기적으로 끊어 JTAG 디버그 포트를 통한 펌웨어 덤프 및 역공학을 물리적으로 차단하는 기술.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 상용 제품 출하 후 JTAG 포트를 통한 펌웨어 탈취 및 변조 | **하드웨어 JTAG eFuse 단선 및 암호화 인증 디버깅(Secure Debug)** | 물리적 역공학 차단 및 기밀 IP 보호 |
| 데이지 체인 내 단일 칩 고장으로 체인 전체 검사 마비 | **체인 분할 설계 및 바이패스 멀티플렉서(Scan Bridge) 실장** | 불량 칩 신속 격리 및 검사 연속성 사수 |
| 다층 고밀도 BGA 패키지의 간헐적 냉납 및 솔더 크랙 | **BSDL 기반 자동화 테스트 벡터 생성 및 X-ray 검사 연계** | 제조 결함 검출률 99.9% 달성 |

#### 한줄 요약
- 실무에서는 JTAG eFuse 잠금으로 역공학을 막고, 스캔 브리지로 체인을 보호하며, BSDL 자동화로 BGA 결함을 검출한다.

## Ⅶ. 결론

- 고밀도 BGA 패키징 및 다층 PCB 보드의 제조 품질을 검증하기 위해 **경계 스캔(Boundary Scan)을 지원하는 JTAG(IEEE 1149.1) 인터페이스를 하드웨어에 표준 실장**하고, 초소형 MCU 환경에서는 **2선 기반 SWD 디버깅**을 병행하며, 양산 출하 단계에서는 **하드웨어 eFuse 보안 잠금(Secure Debug)**을 적용하는 고신뢰 전자 시스템 테스트 및 보안 아키텍처 확립

#### 한줄 요약
- JTAG은 초미세 반도체 패키징 시대의 필수 제조 검사 및 디버깅 표준이며, 양산 후 eFuse 잠금과의 결합으로 보안을 완성한다.
