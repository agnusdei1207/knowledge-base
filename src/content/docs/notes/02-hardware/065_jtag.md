## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **JTAG(Joint Test Action Group, IEEE 1149.1)**: 집적회로(IC)의 물리적 핀 납땜 결선 테스트(경계 스캔)와 플래시 펌웨어 다운로드 및 CPU 온칩 디버깅을 지원하는 4/5선 표준 하드웨어 직렬 인터페이스.
- **경계 스캔(Boundary Scan)**: IC 내부 핵심 로직과 외부 I/O 패드 사이에 경계 스캔 셀(Boundary Scan Cell)을 배치하여, 물리적 탐침(Probe) 접촉 없이 직렬 신호만으로 핀의 전압 레벨을 읽고 쓰는 검사 기술.

</details>

- 정의/개념: IC 내부 로직과 I/O 핀 사이에 배치된 **경계 스캔(Boundary Scan)** 셀을 직렬 제어하여 PCB 배선 검사와 온칩 디버깅을 수행하는 **JTAG(IEEE 1149.1)** 표준 인터페이스
- 배경/필요성: 초미세 고밀도 패키징(BGA, CSP) 확산에 따른 물리적 테스트 탐침(Probe) 접근 불가 한계와 **PCB 결선 납땜 불량 비파괴 검출 및 온칩 디버깅 표준화** 필요

#### 한줄 요약
- JTAG은 경계 스캔 셀을 직렬 데이지 체인으로 연결하여 PCB 납땜 결함을 비파괴 검사하고 온칩 디버깅을 수행하는 표준 규격이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **TAP(Test Access Port) 컨트롤러**: TMS(Test Mode Select)와 TCK(Test Clock) 신호의 변화에 따라 동작하는 16개 상태를 가진 하드웨어 유한 상태 머신(16-State FSM).
- **BSDL(Boundary Scan Description Language)**: 특정 IC의 JTAG 아키텍처, 핀 구성, 지원 명령어 및 경계 스캔 셀 순서를 기술한 표준 VHDL 기반 설명 파일.

</details>

- 소수 핀 직렬 인터페이스: 4개 필수 신호선(**TCK, TMS, TDI, TDO**)과 선택적 리셋선(TRST)만으로 복잡한 칩 내부 및 핀 제어
- 16-상태 FSM 제어: **TAP 컨트롤러** 상태 머신을 기반으로 명령어 레지스터(IR)와 데이터 레지스터(DR)의 캡처, 시프트, 갱신 통제
- 직렬 데이지 체인: 복수의 IC 칩을 단일 TDI-TDO 직렬 체인으로 연결하여 **단일 커넥터**로 보드 전체 검사

#### 한줄 요약
- 4개 전용 핀으로 TAP FSM을 구동하고 데이지 체인으로 복수 칩을 검사한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **명령어 레지스터(Instruction Register, IR)**: 실행할 테스트 모드 명령어(EXTEST, SAMPLE/PRELOAD, BYPASS 등)를 시프트 저장하고 디코딩하는 레지스터.
- **경계 스캔 레지스터(Boundary Scan Register, BSR)**: 칩의 모든 I/O 핀과 내부 로직 사이에 직렬 연결되어 실제 핀의 입출력 신호를 래치하는 스캔 셀 집합.
- **바이패스 레지스터(Bypass Register)**: 비검사 칩을 지날 때 직렬 경로를 1비트로 단축하여 스캔 지연을 최소화하는 1비트 레지스터.

</details>

```text
[JTAG TAP 하드웨어 아키텍처]
 ├─ TAP 인터페이스 신호선 ──── TCK, TMS, TDI, TDO, TRST
 ├─ TAP 컨트롤러 (16-State FSM) ── TMS/TCK 기반 FSM 상태 전이 제어
 ├─ 명령어 레지스터 (IR) ────── EXTEST, SAMPLE, BYPASS 디코딩
 └─ 데이터 레지스터 (DR 그룹)
     ├─ 경계 스캔 레지스터 (BSR) ── I/O 핀 신호 구동 및 캡처
     ├─ 디바이스 ID 레지스터 ───── 32비트 제조사 식별자
     └─ 바이패스 레지스터 ──────── 1비트 직렬 바이패스 경로
```

선의 의미: 가지(`├─`, `└─`)는 하드웨어 소속 및 포함 관계; TAP 컨트롤러가 IR과 DR 레지스터의 시프트 경로를 선택하여 TDO로 출력함

| 구성요소 | 책임 |
|:---|:---|
| TAP 컨트롤러 | **TMS**에 따른 IR·DR 시프트 상태 통제 |
| 명령어 레지스터 | **EXTEST·SAMPLE·BYPASS** 명령 해석 |
| 경계 스캔 레지스터 | I/O 핀 신호 구동·캡처와 직렬 전송 |
| 바이패스 레지스터 | 비검사 칩의 경로를 **1비트**로 단축 |
| IDCODE 레지스터 | 제조사·부품·버전 식별 정보 제공 |

#### 한줄 요약
- 경계 스캔 레지스터가 I/O 핀과 내부 로직 사이에 끼어들어 물리 탐침 접촉을 대신하므로 핀이 가려진 패키지도 검사 대상이 되고, 바이패스 레지스터는 비검사 칩의 시프트 길이를 1비트로 줄여 체인 전체를 훑던 비용을 덜어낸다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **EXTEST 명령어**: 칩 내부 코어 로직을 핀과 전기적으로 분리하고, 경계 스캔 셀을 통해 칩 외부 PCB 패턴의 단선(Open) 및 단락(Short) 결함을 검사하는 표준 명령어.

</details>

```text
테스트 장비 연결
  │
  ▼
1. TAP 리셋
  │
  ▼
2. EXTEST 적재
  │
  ▼
3. 패턴 주입
  │
  ▼
4. 핀 구동·캡처
  │
  ▼
5. 넷리스트 비교
   ┌──────────────────┴──────────────────┐
[ 넷리스트 일치 (Pass) ]              [ 불일치 감지 (Fail) ]
   │                                     │
   ▼                                     ▼
PCB 납땜 및 배선 정상 판정            결함 핀 및 단선/단락 위치 특정
```

동작 원리:

1. TAP 리셋: TAP 상태를 Test-Logic-Reset으로 초기화
2. EXTEST 적재: IR에 외부 배선 검사 명령 입력
3. 패턴 주입: DR에 테스트 비트열 입력
4. 핀 구동·캡처: 출력 구동 후 입력값 수집
5. 넷리스트 비교: TDO 결과로 단선·단락 판정

#### 한줄 요약
- 경계 스캔은 탐침 없이 검사 접근성을 얻는 대가로 핀마다 스캔 셀 면적과 지연을 상시 부담하며, 양산 후에도 남는 그 통로가 곧 공격 경로가 되어 잠금 정책과 함께 다뤄진다.

## Ⅴ. 종류 및 비교

| 하드웨어 디버그/테스트 인터페이스 | JTAG (IEEE 1149.1) | SWD (Serial Wire Debug) | UART 디버깅 | 인서킷 에뮬레이터 (ICE) |
|:---|:---|:---|:---|:---|
| 필수 물리 신호선 수 | **4~5선**(TCK, TMS, TDI, TDO) | **2선**(SWCLK, SWDIO) | 2선 (TX, RX) | 수십~수백 개 전용 소켓 핀 |
| 경계 스캔 (배선 검사) | **지원**(BSR 기반 배선 검사) | **미지원**(온칩 디버깅 전용) | 미지원 | 미지원 |
| 다중 칩 데이지 체인 | **지원**(단일 헤더 복수 칩 연결) | 미지원 (점대점 직결) | 멀티드롭 제한적 | 미지원 |
| 주요 적용 분야 | **PCB 제조 양산 테스트**, SoC/FPGA | **초소형 MCU 디버깅** | 단순 콘솔 로그 출력 | 레거시 CPU 하드웨어 전용 분석 |

#### 한줄 요약
- 보드 제조 납땜 검사와 복수 칩 검사에는 JTAG이 표준이며, 핀 수가 부족한 초소형 MCU 디버깅에는 SWD가 쓰인다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **JTAG 보안 퓨즈(JTAG Security eFuse / Lock)**: 제품 양산 출하 시 반도체 내부의 eFuse를 전기적으로 끊어 JTAG 디버그 포트를 통한 펌웨어 덤프 및 역공학을 물리적으로 차단하는 기술.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 양산 후 JTAG을 통한 펌웨어 탈취 위험 | **하드웨어 JTAG eFuse 단선** 및 보안 디버그 적용 | 물리적 역공학 차단 및 기밀 IP 보호 |
| 데이지 체인 내 단일 칩 고장으로 검사 마비 | **스캔 브리지(Scan Bridge)** 기반 체인 분할 설계 | 불량 칩 신속 격리 및 검사 연속성 사수 |
| BGA 패키지의 간헐적 냉납 및 솔더 크랙 | **BSDL 기반 자동 테스트** 벡터 생성 | 제조 결함의 반복 검사 지원 |

#### 한줄 요약
- 실무에서는 JTAG eFuse 잠금으로 역공학을 막고, 스캔 브리지로 체인을 보호하며, BSDL 자동화로 BGA 결함을 검출한다.

## Ⅶ. 결론

- 반도체 제조 결선 검사(Boundary Scan) 및 프로세서 온칩 디버깅/플래싱의 **글로벌 하드웨어 표준(IEEE 1149.1/1149.7)**으로 자리잡았으며, 양산 완제품 환경에서는 역공학 및 펌웨어 탈취를 방지하기 위한 **보안 eFuse 단선(Locking) 및 암호화 인증 기반 보안 디버그(Secure Debug)** 적용이 필수적 엔지니어링 원칙

#### 한줄 요약
- JTAG은 초미세 반도체 패키징 시대의 필수 제조 검사 및 디버깅 표준이며, 양산 후 eFuse 잠금과의 결합으로 보안을 완성한다.
