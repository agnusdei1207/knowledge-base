## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **3-상태 버퍼(Tri-State Buffer)**: 논리 0(Low), 논리 1(High) 외에 선로와 전기적으로 분리되는 고임피던스(High-Z) 상태를 가질 수 있는 디지털 스위칭 소자.
- **고임피던스(High-Z / High Impedance)**: 내부 트랜지스터가 모두 차단되어 출력 임피던스가 수 메가옴 이상으로 상승하여 선로와 물리적으로 분리된 무구동 상태.
- **버스 경합(Bus Contention)**: 둘 이상의 드라이버가 동일 버스 라인을 서로 다른 논리 레벨(0과 1)로 동시 구동하여 발생하는 단락 전류 및 신호 왜곡 현상.

</details>

- 정의/개념: 논리 0(Low)과 1(High) 외에 선로와 전기적으로 분리되는 고임피던스(High-Z) 상태를 제어하여 복수의 출력이 단일 공유 버스를 시분할 공유할 수 있도록 지원하는 **디지털 스위칭 소자**
- 배경/필요성: 복수 디지털 출력 소자의 공통 신호선 공유 시 상호 반대 전압 구동에 따른 단락 과전류(Bus Contention) 방지 및 소자 파괴 예방

#### 한줄 요약
- 3-상태 버퍼는 High-Z 상태를 통해 비선택 장치를 버스에서 전기적으로 분리하여 공통 버스 공유를 실현하는 디지털 논리 소자이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **출력 인에이블(Output Enable, OE)**: 버퍼의 출력을 유효 구동 상태(0/1)로 활성화할지 High-Z 절연 상태로 둘지를 제어하는 게이트 제어 신호.
- **플로팅(Floating)**: 모든 드라이버가 High-Z 상태일 때 선로의 전압이 확정되지 않고 중간 전압으로 부유하여 노이즈에 취약해지는 상태.

</details>

- **출력 인에이블(Output Enable, OE)** 제어 신호에 따라 1클록 내에 정상 논리 구동과 고임피던스(High-Z) 전기적 절연 절체
- 복수 소자의 출력을 단일 물리 배선에 병렬 연결하는 와이어드 버스 구성을 통해 **칩 핀 수와 PCB 배선 면적 극소화**
- 모든 버퍼가 비활성화될 때 발생하는 **선로 플로팅(Floating) 현상**을 억제하기 위해 풀업 저항 또는 버스 홀더 회로 연동

#### 한줄 요약
- OE 절연은 장치마다 전용 배선을 깔던 비용을 하나의 공유 선로로 압축하는 대신, 아무도 구동하지 않는 구간의 전압 확정 책임을 풀업 저항이라는 별도 소자에 떠넘긴다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **풀업 PMOS(Pull-Up PMOS)**: 입력이 1일 때 도통하여 출력 라인을 $V_{dd}$(논리 1)로 드라이빙하는 상단 트랜지스터.
- **풀다운 NMOS(Pull-Down NMOS)**: 입력이 0일 때 도통하여 출력 라인을 GND(논리 0)로 드라이빙하는 하단 트랜지스터.

</details>

```text
[3-상태 버퍼 서브시스템]
  │
  ├─ [입력 제어 신호군] (데이터 입력 A & 인에이블 OE)
  │
  ├─ [내부 CMOS 제어 로직] (상하단 트랜지스터 독립 제어)
  │     ├─ [풀업 제어 게이트] (OE/A 기반 PMOS 게이트 구동)
  │     └─ [풀다운 제어 게이트] (OE/A 기반 NMOS 게이트 구동)
  │
  ├─ [출력 구동단 소자] (3가지 상태 생성 드라이버)
  │     ├─ [풀업 PMOS 소자] (도통 시 Vdd 논리 1 구동)
  │     ├─ [풀다운 NMOS 소자] (도통 시 GND 논리 0 구동)
  │     └─ [High-Z 차단 상태] (동시 턴오프 전기적 절연)
  │
  └─ [단일 공유 버스 선로] (와이어드 라인)
        └─ [풀업 저항 / 버스 홀더] (플로팅 방지 전압 안정화)
```

선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 제어 논리 게이트 | 데이터(A)와 출력 인에이블(OE)을 조합하여 **상하단 트랜지스터 구동 전압 생성** |
| 풀업 PMOS | OE=1이고 A=1일 때 도통되어 **출력 라인을 $V_{dd}$(논리 1)로 충전** |
| 풀다운 NMOS | OE=1이고 A=0일 때 도통되어 **출력 라인을 접지(논리 0)로 고속 방전** |
| 풀업 저항 / 버스 홀더 | 모든 버퍼가 High-Z일 때 **선로 전압 부유 방지 및 논리 레벨 유지** |

#### 한줄 요약
- 제어 논리 게이트가 데이터와 OE를 조합해 풀업 PMOS와 풀다운 NMOS를 동시에 차단하는 경로를 만들어내므로, 출력단이 언제나 Vdd나 GND 중 하나에 묶여 있던 2상태 구동 회로가 스스로 버스에서 빠질 수 있는 소자로 바뀐다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Break-Before-Make**: 새 버퍼를 활성화하기 전에 이전 활성 버퍼를 완전히 High-Z로 차단하여 버스 경합을 방지하는 타이밍 제어 규칙.

</details>

```text
[입력 데이터(A) 및 출력 인에이블(OE) 신호 인가]
       │
       ▼
 1. 출력 인에이블(OE) 판정
   ├─ [OE = 0 (비활성)] ──> 2. 트랜지스터 차단 및 High-Z 절연
   └─ [OE = 1 (활성 상태)]
       │
       ├─ 3. Break-Before-Make 비중첩 절체
       └─ 4. 데이터(A) 레벨별 CMOS 스위칭 구동
       │
       ▼
 5. 공유 버스 라인 전압 확정 (0, 1 또는 High-Z)
```

분기 결과: **OE=0**이면 출력단이 High-Z로 차단되어 타 장치가 버스를 자유롭게 구동하나, **OE=1**이면 내부 트랜지스터가 도통되어 버스 선로를 논리 0 또는 1로 구동함

**동작 원리**

1. **출력 인에이블(OE) 판정**: 회로에 인가된 인에이블 신호(OE)를 수신하여 현재 버퍼가 버스 구동 권한을 갖는지 판단
2. **트랜지스터 차단 및 High-Z 절연**: OE=0일 때 풀업 PMOS와 풀다운 NMOS를 동시에 턴오프하여 출력단을 고임피던스로 완전 격리
3. **Break-Before-Make 비중첩 절체**: 이전 구동 장치의 차단 시점과 새 장치의 활성화 시점 사이에 비중첩 마진을 두어 두 소자가 동시 도통되는 단락 방지
4. **데이터(A) 레벨별 CMOS 스위칭 구동**: OE=1일 때 입력 데이터 A가 1이면 풀업 PMOS를 턴온하여 $V_{dd}$를 출력하고, A가 0이면 풀다운 NMOS를 턴온하여 GND로 출력
5. **버스 전압 확정 및 무결성 유지**: 버스 선로 전압이 확정되며, 전체 High-Z 유휴 구간에서는 외부 풀업 저항 또는 버스 홀더가 중간 전압 표류 노이즈 방지

#### 한줄 요약
- 절체 구간에서 어느 버퍼도 버스를 구동하지 않는 공백을 감수하는 대가로, 두 출력이 겹쳐 발생하는 버스 경합을 차단한다.

## Ⅴ. 종류 및 비교

| 버퍼 및 드라이버 구조 | 액티브 하이 3-상태 버퍼 | 액티브 로우 3-상태 버퍼 (/OE) | 오픈 드레인 (Open-Drain) | 일반 푸시풀 버퍼 (Push-Pull) |
|:---|:---|:---|:---|:---|
| 적용 기준 | 공통 마이크로프로세서 고속 데이터 버스 시분할 공유 | 메모리 칩 제어 버스 (/CE, /OE) 인터페이스 연결 | I2C, SMBus 등 양방향 유선 AND 라인 | 점대점 고속 클록 배선 및 전용 단방향 신호선 |
| 핵심 특징 | OE=1 시 능동 구동, OE=0 시 **High-Z 무구동 절연** | /OE=0 시 능동 구동, /OE=1 시 **High-Z 무구동 절연** | NMOS로 접지(0) 구동, 1은 **외부 풀업 저항에 의존** | PMOS/NMOS 상보 구동으로 **상시 논리 0 또는 1 출력** |
| 한계 | 절체 타이밍 불일치 시 버스 경합 및 **플로팅 발생** | 모든 드라이버 High-Z 구간에서 **풀업 저항 필수** | 외부 풀업 저항 $RC$ 시정수로 인한 **고속 전송 한계** | 복수 출력 병렬 연결 시 **단락 과전류로 소자 파괴** |

#### 한줄 요약
- 고속 공유 시스템 버스에는 3-상태 버퍼가 쓰이고, 유선 AND 통신에는 오픈 드레인이, 점대점 전용선에는 푸시풀 버퍼가 쓰인다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **버스 홀더(Bus Holder Circuit)**: 버스가 High-Z가 되었을 때 마지막 논리 상태를 약한 피드백으로 유지하여 중간 전압 누설을 방지하는 회로.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 절체 순간 두 버퍼의 동시 도통으로 인한 버스 경합 | **Break-Before-Make 비중첩 클록** 제어 | 단락 과전류 차단 및 소자 파손 방지 |
| 모든 버퍼 High-Z 시 버스 선로 플로팅 누설 전류 | **풀업 저항** 또는 **능동 버스 홀더** 실장 | 중간 전압 부유 억제 및 대기 전력 소모 방지 |
| 고속 버스 스위칭 시 신호 반사 및 언더슛 노이즈 | 버퍼 출력단 **직렬 댐핑 저항** 실장 | 전송선로 임피던스 정합 및 신호 무결성 확보 |

#### 한줄 요약
- 실무에서는 Break-Before-Make로 동시 충돌을 방지하고, 버스 홀더로 플로팅 누설을 잡으며, 댐핑 저항으로 신호 반사를 억제한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **양방향 송수신기(Bidirectional Transceiver)**: 3-상태 버퍼 2개를 역병렬로 배치하고 방향 신호(DIR)와 인에이블(/OE)로 데이터 송수신을 전환하는 칩셋 소자.
- **슈미트 트리거(Schmitt Trigger)**: High-Z 이후 복귀 시 노이즈로 인해 흔들리는 입력 신호에 히스테리시스 특성을 부여하여 깨끗한 구형파로 정형하는 입력 버퍼 회로.

</details>

- **초고속 직렬화 및 인터페이스 진화**: 현대 시스템이 점대점 직렬 패브릭으로 전환되는 추세 속에서도, DDRx 메모리 데이터 버스 및 복합 양방향 송수신기(Bidirectional Transceiver) 기반 시분할 I/O 블록의 핵심 소자로 지속 진화 추세.
- **신호 무결성 및 내결함 설계 확립**: 버스 경합 단락 방지를 위한 Break-Before-Make 스위칭 지연 설계와 더불어, 플로팅 노이즈 제거를 위한 슈미트 트리거(Schmitt Trigger) 및 종단 저항 배치 기반의 신호 무결성(SI) 확보 필수.

#### 한줄 요약
- DDR 메모리 및 양방향 송수신 인터페이스의 핵심 소자로 기능하며, Break-Before-Make 타이밍 정합과 슈미트 트리거 노이즈 정형을 결합한 신호 무결성 설계가 핵심이다.
