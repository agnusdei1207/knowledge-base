## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **3-상태 버퍼**: 활성화에 따라 논리 0•1 또는 고임피던스를 출력해 공유선 충돌을 막는 회로이다.
- **버스 경합**: 둘 이상의 출력이 같은 선을 서로 다른 값으로 동시에 구동해 전류와 논리가 충돌하는 상태이다.

</details>

- 정의/개념: 출력 활성화 신호에 따라 논리 0·1 또는 고임피던스를 출력하는 **공유선 구동 회로**이다.
- 배경/필요성: 여러 출력단이 같은 선을 반대 값으로 구동하면 큰 전류와 논리 충돌이 발생하므로 **비선택 출력 분리를 필요로 한다**.

#### 한줄 요약

- 3-상태 버퍼는 선택된 출력만 0 또는 1을 구동하고 나머지는 고임피던스로 분리해 공유선 경합을 방지한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **고임피던스(Z)**: 출력 구동을 끊어 공유선에 전기적으로 영향을 주지 않는 상태이다.
- **출력 활성화(Output Enable, OE)**: 출력단의 구동 여부를 제어하는 신호이다.
- **OE 상호 배타**: 여러 출력 활성화 신호 가운데 동시에 참인 신호가 최대 하나인 조건이다.
- **부동**: 어느 출력도 선을 구동하지 않아 전압과 논리값이 정해지지 않은 상태이다.

</details>

- **OE·고임피던스(Z)** 제어로 비선택 출력단을 공유선에서 전기적으로 분리한다.
- 두 출력의 동시 구동을 막는 **OE 상호 배타·비중첩 전환**이 핵심이다.
- 모든 출력이 꺼진 구간에는 **부동 입력 방지용 바이어스·버스 홀드** 필요가 핵심이다.

#### 한줄 요약

- OE 상호 배타와 비중첩 전환은 출력 경합을 막고, 풀업·풀다운·버스 홀드는 무구동 구간의 부동을 막는다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **데이터 입력**: 선택된 출력단이 공유 버스에 전달할 논리 0 또는 1이다.
- **공유 버스**: 한 시점에 하나의 출력단만 구동해야 하는 공용 신호선이다.

</details>

```text
                     [데이터 입력]
                           |
[출력 활성화] ----- [3-상태 출력단] ----- [공유 버스]
```

선의 의미: 선은 3-상태 출력단을 중심으로 데이터, 출력 활성화와 공유 버스가 결합되는 정적 신호 경계를 뜻한다.

| 구성요소 | 책임 |
|:---|:---|
| 데이터 입력 | 외부 전송 **논리 0•1** 제공 |
| 출력 활성화 | 구동•**고임피던스** 선택 |
| 3-상태 출력단 | 데이터•OE 기반 **0•1•Z** 출력 |
| 공유 버스 | 단일 구동자의 **신호 전달** |

#### 한줄 요약

- 출력 활성화 신호가 한 출력단만 공유 버스를 구동하도록 제어한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **데이터 입출력(Data Input/Output, DQ)**: 메모리 읽기•쓰기 데이터를 전달하는 신호이다.
- **DQ 버스**: 메모리와 제어기 사이의 양방향 데이터선이다.
- **비중첩 전환**: 현재 출력단을 끈 뒤 다음 출력단을 켜 동시 구동을 막는 전환한다.
- **턴어라운드**: 양방향 버스의 구동 주체가 바뀔 때 두 출력이 모두 꺼져 있는 시간이다.

</details>

```text
                      [DQ 쓰기 구간]
                            |
                   1. 제어기 OE 활성
                            |
                   2. 쓰기 데이터 구동
                            |
                  3. 제어기 OE 비활성
                            |
                 [DQ 버스 고임피던스]
                            |
                       [턴어라운드]
                            |
              4. 메모리 OE 활성•읽기 구동
                            |
                    [제어기에 반환]
```

**동작 원리**

1. **제어기 OE 활성**: 쓰기 구간에 제어기 출력단만 활성화해 DQ 버스 구동 권한을 부여한다.
2. **쓰기 데이터 구동**: 제어기가 논리 0·1의 쓰기 데이터를 DQ 버스로 전달한다.
3. **제어기 OE 비활성**: 읽기 전환 전에 제어기 출력을 고임피던스로 바꾸고 턴어라운드 시간을 확보한다.
4. **메모리 OE 활성·읽기 구동**: 제어기 출력이 완전히 꺼진 뒤 메모리 출력단을 활성화해 읽기 데이터를 반환한다.

#### 한줄 요약

- 쓰기 출력이 고임피던스로 전환된 뒤 읽기 출력을 활성화해야 양방향 DQ 버스의 순간 단락과 논리 충돌을 막을 수 있다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **오픈드레인**: 0 또는 고임피던스만 출력하고 외부 풀업 저항으로 1을 만드는 공유선 방식이다.
- **풀업 저항**: 구동자가 없을 때 신호선을 높은 전압으로 끌어올리는 저항이다.
- **멀티플렉서(Multiplexer, MUX)**: 여러 입력 중 하나를 출력으로 연결하는 회로이다.

</details>

| 공유 경로 구성 | 3-상태 버퍼 | 멀티플렉서 | 오픈드레인 |
|:---|:---|:---|:---|
| 적용 기준 | 외부 **양방향 데이터 버스** | 내부 **선택 경로** | 다중 장치 **공유 제어선** |
| 핵심 특징 | OE 기반 **0•1•Z 출력** | 선택 입력의 **단일 출력 연결** | 0•Z 출력과 **외부 풀업** |
| 한계 | 경합 전류•**무구동 부동** | 선택 지연•**배선 증가** | 풀업 지연•**High 직접 구동 불가** |

> 요약: 외부 버스는 3-상태, 내부 경로는 MUX가 적합하다.

#### 한줄 요약

- 외부 양방향 버스에는 3-상태 버퍼가, 칩 내부의 단일 선택 경로에는 멀티플렉서가 적합하다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **버스 홀드**: 모든 출력이 고임피던스일 때 약한 되먹임으로 마지막 논리값을 유지하는 회로이다.
- **논리 합성**: 하드웨어 설명을 실제 게이트와 멀티플렉서 연결로 변환하는 과정이다.
- **순간 단락**: 방향 전환 중 두 출력단이 반대 값을 함께 구동해 큰 전류가 흐르는 현상이다.
- **현장 프로그래머블 게이트 배열(Field-Programmable Gate Array, FPGA)**: 재구성 가능한 논리 장치이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 둘 이상의 출력이 활성화되어 **반대 논리 동시 구동** | **OE 상호 배타 속성 검증**과 경합 전류 감시 | 다중 구동 차단으로 **전기적 충돌 방지** |
| 방향 전환 때 두 출력의 구동 시간이 겹쳐 **순간 단락** | **비중첩 제어와 턴어라운드 시간** 검증 | 이전 출력이 꺼진 뒤 다음 출력을 켜 **단락 전류 방지** |
| 모든 출력이 고임피던스인 동안 **버스 전압 부동** | **풀업·풀다운·버스 홀드** 적용 | 무구동 구간의 **입력 논리값 안정화** |
| FPGA 내부 3-상태 회로가 MUX로 변환되어 **예상 경로와 불일치** | 칩 내부는 **MUX**, 외부 I/O 핀만 3-상태 버퍼 사용 | 구현 의도를 합성 구조와 맞춰 **타이밍 예측성 향상** |

> 사례: **읽기•쓰기 전환 구간**에 턴어라운드를 확보하는 메모리 DQ 버스

#### 한줄 요약

- OE 상호 배타와 충분한 턴어라운드 시간으로 양방향 버스 전환 중 순간 단락을 방지한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **외부 양방향 버스**: 같은 물리 핀을 시간에 따라 입력과 출력으로 번갈아 사용하는 경로이다.
- **내부 선택 경로**: 칩 내부에서 여러 신호 중 하나를 논리적으로 골라 전달하는 배선이다.

</details>

- 외부 양방향은 **3-상태**, 내부 선택은 **MUX**을 적용한다.

#### 한줄 요약

- 외부 양방향 공유선은 3-상태 버퍼로 구동하고, 칩 내부의 신호 선택 경로는 MUX로 구현한다.
