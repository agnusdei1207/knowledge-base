## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **3-상태 버퍼(Tri-State Buffer)**: 전기적 출력을 일반적인 2진 논리 상태인 '0'과 '1' 이외에, 물리적으로 신호선과의 연결을 완전히 끊어버리는 고임피던스 상태까지 포함하여 총 3가지 상태로 제어할 수 있는 특수한 디지털 논리 게이트이다.
- **고임피던스(High-Impedance)**: 출력단이 비활성화되어 공유선에 어떠한 전압도 가하지 않고 전기를 통하지 않는, 마치 스위치가 열린 것과 같은 완벽한 전기적 절연 상태이다.
- **버스 경합(Bus Contention)**: 두 개 이상의 칩이 동일한 버스 신호선에 '0'과 '1'을 동시에 출력하려 들면서 끔찍한 단락 전류가 흐르고 결국 반도체가 물리적으로 타버리는 치명적 파손 현상이다.

</details>

- 정의: 출력 활성화 신호 제어를 통해 논리 영, 논리 일 및 전기적 절연 상태인 **고임피던스** 3가지 상태를 선택 출력하는 **3-상태 버퍼** 회로
- 배경: 다수의 칩이 하나의 물리적 버스 선에 병렬로 엮인 공유 버스 아키텍처에서, 말할 차례가 아닌 칩들의 입을 막아 **버스 경합**과 칩의 화재(단락)를 방지하기 위함

#### 한줄 요약

- 0과 1의 신호뿐만 아니라, 자신을 투명 인간으로 만들어 전기를 완전히 끊어버리는 세 번째 상태를 지원하여 여러 칩이 하나의 선을 안전하게 돌려쓰게 해주는 마법의 문지기이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **출력 활성화 신호(Output Enable)**: 버퍼의 문을 열어서 0 또는 1 신호를 버스로 쏘아 보낼지, 아니면 문을 굳게 닫고 고임피던스 상태로 숨죽일지를 결정하는 1비트 제어 핀이다.
- **출력 활성화 상호 배타(OE Mutual Exclusion)**: 공유 버스에 꽂힌 수많은 버퍼 중에서 반드시 단 1개의 칩만이 활성화 신호를 가져야 한다는, 신호등과 같은 절대적인 설계 통제 규칙이다.
- **부동 현상(Floating State)**: 버스에 물린 모든 칩이 고임피던스 상태로 숨어버려, 버스 선의 전압이 0볼트도 아니고 5볼트도 아닌 귀신 같은 공중 전위 상태로 노이즈에 극히 취약해지는 현상이다.
- **버스 전환 시간(Bus Turnaround Time)**: 앞선 칩이 쓰기를 멈추고 고임피던스로 완전히 물러난 뒤, 다음 칩이 읽기를 시작하기 전까지 반드시 지켜야 하는 아주 짧은 안전 대기 시간이다.

</details>

- 비선택 장치의 구동기를 **고임피던스** 상태로 강제 전환시켜 공유 버스 선상에서 전기적으로 완전하게 떼어내는 절연을 달성함.
- 칩이 타버리는 버스 경합을 막기 위하여 컨트롤러 단에서 엄격한 **출력 활성화 상호 배타** 조건 및 겹치지 않는 충분한 **버스 전환 시간** 보장이 필수적임.
- 버스 상의 모든 출력이 절연 상태가 될 때 발생하는 **부동 현상** 시의 노이즈 취약점을 방어하기 위해 풀업 또는 풀다운 바이어스 저항을 결합함.

#### 한줄 요약

- 자신이 말할 때만 문을 열고(상호 배타), 말이 끝나면 흔적도 없이 사라지며(고임피던스), 틈새 시간에는 저항이 버스를 붙잡아 주는(부동 방지) 특성을 지닌다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **전달 트랜지스터(Pass Transistor)**: 버퍼의 최종 출력을 밀고 당기는 반도체 소자로, 활성화 신호가 꺼지면 위아래 스위치가 모두 열려 완벽한 고임피던스 벽을 형성하는 CMOS 회로이다.
- **바이어스 저항(Bias Resistor)**: 버스를 아무도 구동하지 않는 붕 뜬 상태일 때 전압을 끌어올리거나 내려서 안전한 기본 논리 상태로 묶어두는 전자 부품이다.
- **버스 유지 회로(Bus Hold Cell)**: 버스 핀에 달린 아주 약한 피드백 회로로, 모두가 침묵하는 상태에서도 직전에 버스가 가졌던 마지막 논리 전압을 그대로 유지시켜 전력 소모를 억제한다.

</details>

```text
[ 3-상태 버퍼 반도체 논리 게이트 및 공유 버스 물리 연결 아키텍처 ]
               전원 전압 (VCC)
                 │
             ┌───┴───┐
      데이터 ─┤ P-MOS │ (출력 비활성화 시 완전 차단)
             └───┬───┐
                 ├───┼─── 출력 ──> [ 공유 물리 버스 전송선 ] ──┐
             ┌───┴───┐                                         │
      데이터 ─┤ N-MOS │ (출력 비활성화 시 완전 차단)           │
             └───┬───┘                             ┌─────────┴─────────┐
                 │                                 │ 풀업 바이어스 저항│
                접지                               └─────────┬─────────┘
                                                             │
                                                          전원 전압 (부동 차단)
```

| 구성요소 | 책임 |
|:---|:---|
| 출력 활성화 핀 | 데이터를 보낼 구동 상태와 전기를 끊을 고임피던스 절연 상태 선택 통제 |
| 상보성 금속 산화막 반도체 출력단 | 핀이 활성화되었을 때 논리 영과 일의 강력한 물리적 전압 쏘아내기 구동 |
| **바이어스 저항** | 버스가 무구동 절연 상태일 때 부동하지 않도록 안전한 기본 논리 상태 고정 |
| **버스 유지 회로** | 약한 피드백을 통해 직전 버스가 가졌던 마지막 논리 상태 지속 유지 및 노이즈 차단 |

#### 한줄 요약

- 트랜지스터 두 개로 전기를 뿜어내거나 아예 끊어버리며, 그 끊어진 빈틈을 풀업 저항이나 유지 회로가 메워주어 버스의 평화를 지킨다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **순간 단락(Pass-Through Short)**: 앞선 칩이 미처 고임피던스로 빠져나오기도 전에 다음 칩이 성급하게 켜져버려, 순간적으로 전원과 접지가 직통으로 연결되면서 불꽃이 튀는 과도 단락 현상이다.

</details>

```text
[ 공유 메모리 데이터 버스의 쓰기 및 읽기 방향 전환 하드웨어 흐름 ]
                          │
                          ▼
        [ 1. 호스트 컨트롤러의 쓰기 출력 활성화 핀 켜기 ]
                          │
            [ 호스트가 공유 버스에 데이터 강하게 구동 ]
                          │
                          ▼
        [ 2. 쓰기 완결 및 즉각적인 출력 끄기 (고임피던스 전환) ]
                          │
                          ▼
        [ 3. 안전 확보를 위한 버스 전환 시간 무구동 대기 ]
                          │
                          ▼
        [ 4. 대상 메모리 칩의 읽기 출력 활성화 핀 켜기 ]
                          │
             [ 메모리가 공유 버스에 읽기 데이터 구동 ]
```

### 동작 원리

1. 쓰기 구동: 호스트 컨트롤러가 쓰기 출력을 활성화하여 공유 데이터 버스 상에 데이터를 강하게 구동함.
2. 절연 전환: 쓰기 완결 시 호스트는 지체 없이 즉시 자신의 출력을 끄고 **고임피던스** 상태로 전환하여 물러남.
3. 전환 대기: 두 칩이 겹쳐 타버리는 **순간 단락** 방지를 위해, 지정된 **버스 전환 시간** 동안 버스를 무구동 상태로 철저히 비워둠.
4. 읽기 구동: 충분한 대기 후 메모리 칩이 안전하게 자신의 읽기 출력을 활성화하여 읽기 데이터를 호스트로 반환함.

#### 한줄 요약

- 호스트가 문을 열고 데이터를 쓴 뒤 즉시 문을 닫아버리고, 찰나의 침묵(전환 시간)을 거친 후 메모리가 문을 열어 응답하는 릴레이 구조이다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **멀티플렉서(Multiplexer)**: 3-상태 버퍼의 절연 마법을 쓰지 않고, 여러 입력 중 단 1개만 통과하도록 앤드와 오어 논리 게이트들을 복잡하게 엮어 만든 안전한 내부 전용 선택기이다.
- **오픈 드레인(Open-Drain)**: 논리 1을 뿜어내는 능력을 아예 거세하여 0만 바닥으로 끌어내리게 만들고, 여러 선을 그냥 묶어도 타버리지 않게 만든 통신망 핀 구조이다.

</details>

| 비교 항목 | **3-상태 버퍼** | **멀티플렉서** | **오픈 드레인** |
|:---|:---|:---|:---|
| 물리적 출력 가능 상태 | 논리 영, 일, 전기적 절연 고임피던스 | 논리 영, 논리 일 (단 2개) | 논리 영, 절연 고임피던스 |
| 주력 설계 적용 영역 | 칩 밖으로 나가는 외부 양방향 공유 버스 | 칩 내부 시스템 온 칩 코어 간 신호 선택망 | 칩 간의 공유 제어선 및 다중 인터럽트 라인 |
| 하드웨어 구현 구조적 특징 | 하나의 핀으로 주고받아 전체 핀 수 대폭 절감 | 내부에 앤드와 오어 논리 게이트 면적 낭비 수반 | 외부 풀업 저항 장착이 무조건 필수적임 |
| 칩 파손 신호 충돌 위험도 | 제어 신호가 겹치는 순간 물리적 단락 파손 발생 | 선택기 오류가 나도 논리적 오동작에만 그침 | 모두가 당겨도 합선이 안 되는 전기적 허용 구조 |
| 물리적 억세스 구동 속도 | 직접 전압을 밀고 당겨 양방향 초고속 전송 달성 | 내부 전기 신호라 칩 속도만큼 매우 빠름 | 저항을 타고 올라가는 지연 탓에 상대적으로 느림 |

#### 한줄 요약

- 3-상태 버퍼는 칩 밖에서 핀을 아끼는 양날의 검이고, 멀티플렉서는 칩 안에서 안전하게 길을 고르는 교차로이며, 오픈 드레인은 안전하게 다수결을 묻는 구조이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **논리 합성(Logic Synthesis)**: 사람이 작성한 하드웨어 코드를 실제 실리콘 게이트 회로로 변환하는 도구로, 현대 설계에서는 칩 내부의 3-상태 버퍼를 금지하고 모두 멀티플렉서로 강제 변환시켜 버린다.
- **온 다이 터미네이션(On-Die Termination)**: 초고속 양방향 버스에서 신호가 끝에 부딪혀 반사되는 찌그러짐을 막고자, 칩 내부에 동적 저항을 달아 임피던스를 깔끔하게 맞춰주는 고급 신호 무결성 기술이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 제어 신호가 미세하게 어긋나 두 구동기가 동시에 켜지며 불꽃이 튀는 **순간 단락** 파손 | 칩 레벨의 엄격한 **출력 활성화 상호 배타** 디코더 삽입 및 비중첩 전환 간격 강제 할당 | 칩을 태워버리는 과도 전류 방지 및 출력단 충돌 파손 원천 예방 |
| 공유 버스 상의 모든 출력이 절연으로 빠질 때 노이즈가 폭포수처럼 유입되는 **부동 현상** | 물리적 버스 핀에 풀업 저항 달기 또는 **버스 유지 회로** 하드웨어 셀 내부 탑재 | 부동 상태의 노이즈 완벽 차단 및 요동치는 스위칭 전력 소모 극적 절감 |
| 칩 내부 설계 코드에서 버퍼 선언 시 반도체 합성 오류 및 테스트 불가 늪에 빠짐 | **논리 합성** 단계에서 칩 내부 배선은 안전한 **멀티플렉서** 구조로 설계 도구 강제 전환 | 생산 후 칩 불량 테스트 검증성 확보 및 내부 신호 단락 위험 100% 무결성 보장 |
| 초고속 양방향 버스 구동 시 선 끝단 반사파로 인한 심각한 데이터 왜곡 및 오인식 | **온 다이 터미네이션** 기술을 칩 내부에 심어 양방향 전환 시마다 동적 임피던스 매칭 자동 적용 | 고주파 핀 신호의 찌그러짐을 펴서 무결성을 보장하고 초고속 안정적 데이터 전송 달성 |

#### 한줄 요약

- 단락을 막기 위해 틈새 시간을 두고, 부동을 막기 위해 저항을 달며, 칩 내부는 멀티플렉서로 대체하고 칩 외부는 터미네이션으로 찌그러짐을 편다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **공유 회로 아키텍처 선택 기준(Shared Circuit Decision Criteria)**: 대상 버스의 물리적 위치(칩 내부냐 외부냐), 전송 방향성, 가용 핀 수 제약 및 요구 속도를 종합적으로 가늠하여 3-상태 버퍼, 멀티플렉서, 오픈 드레인 중 최적의 무기를 채택하는 프레임워크이다.

</details>

- 외부로 나가는 병렬 양방향 핀 버스는 **3-상태 버퍼**, 칩 내부의 안전한 데이터 선택 경로는 무조건 **멀티플렉서** 적용

#### 한줄 요약

- 칩 내부는 합선 위험이 없는 멀티플렉서로 안전하게 짜고, 칩 외부는 핀 개수를 획기적으로 줄여주는 3-상태 버퍼로 공간의 한계를 극복해야 한다.
