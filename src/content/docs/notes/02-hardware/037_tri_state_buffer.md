## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **3-상태 버퍼(Tri-State Buffer)**: 출력으로 논리 0, 논리 1, 고임피던스(High-Z)의 세 가지 상태를 가질 수 있는 디지털 논리 소자.
- **고임피던스(High-Z)**: 출력이 선로와 전기적으로 분리되어 입력도 출력도 구동하지 않는 무구동 상태.
- **버스 경합(Bus Contention)**: 둘 이상의 출력이 동일 선로를 동시에 구동하여 논리 충돌 및 과전류가 흐르는 상태.

</details>

- 정의/개념: 논리 0, 1 외에 출력 인에이블 신호로 **고임피던스(High-Z)** 상태를 형성하는 버스 공유용 논리 게이트 소자
- 배경/필요성: 공통 버스에 다수 장치 직접 연결 시 **신호 충돌(Contention)** 및 과전류 소자 파손 위험 발생

#### 한줄 요약
- 쓰지 않을 때는 회선에서 아예 손을 떼는 고임피던스 상태를 만들어 여러 장치가 선을 공유하게 돕는다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **출력 인에이블(Output Enable, OE)**: 버퍼의 출력을 활성화할지 High-Z로 차단할지 제어하는 입력 신호.
- **플로팅(Floating)**: 아무런 구동 소자도 연결되지 않아 선로의 전압이 불안정하게 흔들리는 상태.

</details>

- **인에이블(Enable) 제어**로 출력 구동과 High-Z 분리 상태 전환
- **양방향 버스 공유**로 핀 수 및 하드웨어 배선 면적 최소화
- 풀업/풀다운 저항과 결합해 버스 선로의 플로팅 노이즈 억제

#### 한줄 요약
- 인에이블 신호로 켜고 끄며, 꺼졌을 때는 회로를 분리해 다른 장치의 버스 통신을 방해하지 않는다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **풀업 트랜지스터(Pull-up PMOS)**: 출력 라인을 전원 전압(Vdd, 논리 1)으로 끌어올리는 스위칭 소자.
- **풀다운 트랜지스터(Pull-down NMOS)**: 출력 라인을 접지 전압(GND, 논리 0)으로 끌어내리는 스위칭 소자.

</details>

```text
       데이터 입력 (A) ───────┐
                              ▼
                       ┌──────────────┐
  출력 인에이블 (OE) ──>│ 제어 논리 게이트│
                       └──────┬───────┘
                              │
             ┌────────────────┴────────────────┐
             ▼ (PMOS 게이트)                   ▼ (NMOS 게이트)
       ┌───────────┐                     ┌───────────┐
Vdd ───┤ 풀업 PMOS ├───┐             ┌───┤ 풀다운 NMOS├─── GND
       └───────────┘   │             │   └───────────┘
                       ▼             ▼
                 ══════╧═════════════╧══════ 공통 버스 라인 (출력 Y)
```

선의 의미: 상단은 입력 신호와 제어 논리; 하단은 두 트랜지스터의 출력단이 공통 버스에 병렬 결합된 구조

| 구성요소 | 책임 |
|:---|:---|
| 데이터 입력단 (A) | 버퍼를 통해 전달할 원본 디지털 논리값 입력 |
| 출력 인에이블단 (OE) | 출력 활성화(0/1 구동) 또는 High-Z 분리 여부 결정 |
| 풀업 PMOS 트랜지스터 | 입력이 1일 때 도통하여 출력 라인을 Vdd로 구동 |
| 풀다운 NMOS 트랜지스터 | 입력이 0일 때 도통하여 출력 라인을 GND로 구동 |
| 풀업/풀다운 저항 | 모든 버퍼가 High-Z일 때 버스 라인의 전압 레벨 안정화 |

#### 한줄 요약
- 제어 신호에 따라 상하 트랜지스터를 모두 끄면 버스와 완전히 분리되는 High-Z 상태가 된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Break-Before-Make**: 새 드라이버가 버스를 켜기 전에 이전 드라이버가 완전히 꺼지도록 보장하는 타이밍 규칙.

</details>

```text
제어 신호 (OE) 및 데이터 (A) 입력
      │
      ├─ OE = 비활성 (0) → 1. 상하 트랜지스터 동시 차단 (Off)
      │                          │
      │                    2. 고임피던스 (High-Z) 출력 유지 (버스 분리)
      │
      └─ OE = 활성 (1) ──> 3. 입력 데이터 (A) 판별
                                 │
                           ├─ A = 1 → 풀업 PMOS On → 논리 1 출력
                           │
                           └─ A = 0 → 풀다운 NMOS On → 논리 0 출력
```

**동작 원리**

1. **인에이블 비활성화**: OE가 0이면 풀업 PMOS와 풀다운 NMOS를 모두 차단
2. **High-Z 상태 형성**: 출력이 전기적으로 절연되어 버스에 아무런 전압도 인가하지 않음
3. **인에이블 활성화**: OE가 1이면 입력 A에 따라 하나의 트랜지스터만 도통
4. **논리값 출력 구동**: A가 1이면 High(Vdd), A가 0이면 Low(GND)로 버스를 강하게 구동

#### 한줄 요약
- 인에이블이 꺼지면 상하 소자를 모두 잠가 버스에서 떨어지고, 켜지면 입력대로 0이나 1을 출력한다.

## Ⅴ. 종류 및 비교

| 버퍼 및 출력 구조 | 액티브 하이 3-상태 버퍼 | 액티브 로우 3-상태 버퍼 | 오픈 드레인 (Open-Drain) | 일반 푸시풀 버퍼 (Push-Pull) |
|:---|:---|:---|:---|:---|
| 적용 기준 | 일반 디지털 로직 버스 제어 | 저전력 액티브 로우 인터페이스 | I2C 등 유선 AND(Wired-AND) 버스 | 단일 드라이버 전용 점대점 선로 |
| 핵심 특징 | OE=1일 때 활성화, OE=0일 때 High-Z | /OE=0일 때 활성화, /OE=1일 때 High-Z | 0(Low)만 능동 구동, 1은 저항 풀업 | 0과 1만 항상 능동 구동 (High-Z 없음) |
| 한계 | 풀다운 저항 미배치 시 플로팅 노이즈 | 극성 혼동 시 버스 단락 위험 | 풀업 저항에 따른 상승 시간 지연 | 복수 연결 시 충돌 및 단락 파괴 |

#### 한줄 요약
- 양방향 공유는 3-상태 버퍼, 다중 신호 결합은 오픈 드레인, 단순 1:1 전송은 푸시풀 버퍼를 쓴다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **버스 홀더(Bus Holder)**: 버스가 High-Z가 되었을 때 마지막 논리 레벨을 약하게 유지해 플로팅 전력 낭비를 막는 회로.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 드라이버 전환 순간 동시 턴온으로 **버스 경합** | **Break-Before-Make** 타이밍 딜레이 적용 | 단락 전류 방지 및 칩 신뢰성 확보 |
| 모든 버퍼 Off 시 버스 선로 **플로팅 노이즈** | 버스에 풀업/풀다운 저항 또는 **버스 홀더** 배치 | 중간 전압에 따른 누설 전류 차단 |
| 고속 버스 스위칭 시 신호 반사 및 링잉 | 버퍼 출력단에 직렬 종단 저항(Damping Resistor) 연결 | 신호 무결성 개선 및 왜곡 억제 |
| 정전기 방전(ESD)으로 인한 버퍼 파괴 | I/O 패드에 전용 ESD 보호 다이오드 집적 | 외부 충격 전압 방어 및 내구성 유지 |

#### 한줄 요약
- 전환 타이밍 딜레이로 충돌을 막고, 풀업 저항과 버스 홀더로 플로팅 누설을 방지한다.

## Ⅶ. 결론

- 공통 버스 다중화는 **3-상태 버퍼**, 유선 결합 제어는 **오픈 드레인** 선택

#### 한줄 요약
- 인에이블 타이밍과 버스 풀업 설계를 철저히 검증하여 버스 충돌과 플로팅 노이즈를 완벽히 통제해야 한다.
