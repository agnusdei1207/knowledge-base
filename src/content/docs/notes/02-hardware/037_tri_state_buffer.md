## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **3-상태 버퍼(Tri-State Buffer)**: 출력으로 논리 0, 논리 1, 고임피던스(High-Z)의 세 가지 상태를 가질 수 있는 디지털 논리 소자.
- **고임피던스(High-Z)**: 출력이 선로와 전기적으로 분리되어 입력도 출력도 구동하지 않는 무구동 상태.
- **버스 경합(Bus Contention)**: 둘 이상의 출력이 동일 선로를 동시에 구동하여 논리 충돌 및 과전류가 흐르는 상태.

</details>

- 정의/개념: 논리 0·1 외에 **고임피던스**라는 무구동 상태를 가져 여러 출력이 한 선로를 공유하게 하는 **3-상태 버퍼**
- 배경/필요성: 여러 출력이 같은 선로를 동시에 구동하면 **버스 경합**으로 인해 논리값이 깨지고 전원과 접지가 직결되어 소자가 손상됨

#### 한줄 요약
- 세 번째 상태의 값어치는 0도 1도 아니라는 데 있지 않고 아무 값도 주장하지 않는다는 데 있으며, 이 침묵이 공유 버스를 가능하게 한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **출력 인에이블(Output Enable, OE)**: 버퍼의 출력을 활성화할지 High-Z로 차단할지 제어하는 입력 신호.
- **플로팅(Floating)**: 아무런 구동 소자도 연결되지 않아 선로의 전압이 불안정하게 흔들리는 상태.

</details>

- **출력 인에이블** 신호로 구동과 High-Z 분리를 전환
- 비선택 출력을 전기적으로 떼어 내 공유 버스의 배선·핀 중복 감소
- 풀업·풀다운 저항과 결합해 모든 버퍼가 꺼진 구간의 **플로팅** 억제

#### 한줄 요약
- 아무도 구동하지 않는 순간이 생긴다는 점이 High-Z의 대가이며, 그래서 3-상태 버스는 반드시 기본 전압을 잡아 주는 회로를 함께 요구한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **풀업 트랜지스터(Pull-up PMOS)**: 출력 라인을 전원 전압(Vdd, 논리 1)으로 끌어올리는 스위칭 소자.
- **풀다운 트랜지스터(Pull-down NMOS)**: 출력 라인을 접지 전압(GND, 논리 0)으로 끌어내리는 스위칭 소자.

</details>

```text
[3-상태 버퍼]
├─ 데이터 입력 A
├─ 출력 인에이블 OE
├─ 제어 논리 게이트 (A와 OE로 두 게이트 구동 신호 생성)
├─ 출력단
│  ├─ 풀업 PMOS (Vdd 방향 구동)
│  └─ 풀다운 NMOS (GND 방향 구동)
└─ 공통 버스 라인 Y
   └─ 풀업·풀다운 저항 (전 버퍼 High-Z 시 전압 유지)
```

선의 의미: 가지(`├─`)는 소유 관계이며, 두 트랜지스터가 동시에 꺼진 상태가 곧 High-Z

| 구성요소 | 책임 |
|:---|:---|
| 데이터 입력 A | 버퍼가 전달할 원본 논리값 입력 |
| **출력 인에이블** | 구동과 High-Z 분리 중 어느 쪽인지 결정 |
| **풀업 트랜지스터** | 입력이 1일 때 도통해 출력을 Vdd로 구동 |
| **풀다운 트랜지스터** | 입력이 0일 때 도통해 출력을 GND로 구동 |
| 풀업/풀다운 저항 | 모든 버퍼가 High-Z일 때 버스 라인의 전압 레벨 안정화 |

#### 한줄 요약
- 두 트랜지스터를 모두 끄는 것과 모두 켜는 것은 회로상 한 신호 차이일 뿐이라, 제어 논리의 사소한 결함이 곧바로 관통 전류로 이어진다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Break-Before-Make**: 새 드라이버가 버스를 켜기 전에 이전 드라이버가 완전히 꺼지도록 보장하는 타이밍 규칙.

</details>

```text
OE·A 입력 도달
        │
   OE가 활성인가?
   ┌────┴─────┐
아니오          예
   │             │
두 트랜지스터    입력 A는 무엇인가?
동시 차단        ┌──┴──┐
   │            1      0
High-Z 유지      │      │
버스에서 분리   풀업 On  풀다운 On
   │          논리 1   논리 0
   │            └──┬───┘
   └────┬──────────┘
        │
   다음 드라이버 전환 시 이전 드라이버 완전 차단 확인
```

분기 결과: High-Z와 구동 상태의 전환 사이에 겹치는 구간이 생기면 두 드라이버가 동시에 선로를 잡아 단락이 발생하므로, 갈래를 나누는 것보다 갈래가 바뀌는 순간의 타이밍이 결정적

#### 한줄 요약
- 논리 동작 자체는 단순하지만 실제 고장은 전부 상태 전환 경계에서 나므로, 3-상태 설계의 검증 대상은 정적 진리표가 아니라 타이밍이다.

## Ⅴ. 종류 및 비교

| 버퍼 및 출력 구조 | 액티브 하이 3-상태 버퍼 | 액티브 로우 3-상태 버퍼 | 오픈 드레인 (Open-Drain) | 일반 푸시풀 버퍼 (Push-Pull) |
|:---|:---|:---|:---|:---|
| 적용 기준 | 활성 High 제어 신호와 공유 버스 | 활성 Low 제어 신호와 공유 버스 | I2C 등 유선 AND(Wired-AND) 버스 | 단일 드라이버 전용 점대점 선로 |
| 핵심 특징 | OE=1일 때 활성화, OE=0일 때 High-Z | /OE=0일 때 활성화, /OE=1일 때 High-Z | 0(Low)만 능동 구동, 1은 저항 풀업 | 0과 1만 항상 능동 구동 (High-Z 없음) |
| 한계 | 기본 상태 회로가 없으면 플로팅 | 극성 혼동 시 잘못된 출력 활성 | 풀업 저항에 따른 상승 시간 지연 | 복수 연결 시 충돌·단락 전류 |

#### 한줄 요약
- 오픈 드레인은 충돌을 막는 대신 논리 1을 저항으로 만들어 속도를 내주므로, 공유의 대가를 3-상태는 타이밍으로 오픈 드레인은 대역폭으로 지불한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **버스 홀더(Bus Holder)**: 버스가 High-Z가 되었을 때 마지막 논리 레벨을 약하게 유지해 플로팅 전력 낭비를 막는 회로.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 드라이버 전환 순간 동시 턴온으로 **버스 경합** | **Break-Before-Make** 비중첩 제어 적용 | 단락 전류·출력 충돌 방지 |
| 모든 버퍼가 꺼진 구간에서 버스 선로 **플로팅** | 버스에 풀업/풀다운 저항 또는 **버스 홀더** 배치 | 중간 전압에 따른 누설 전류 차단 |
| 고속 버스 스위칭 시 신호 반사 및 링잉 | 버퍼 출력단에 직렬 종단 저항(Damping Resistor) 연결 | 신호 무결성 개선 및 왜곡 억제 |

#### 한줄 요약
- **버스 홀더가** 필요한 이유는 CMOS 입력이 중간 전압에서 두 트랜지스터를 동시에 열어 버리기 때문이며, 플로팅은 논리 오류가 아니라 전력 문제로 먼저 나타난다.

## Ⅶ. 결론

- 외부 공통 버스는 3-상태 버퍼, 유선 AND 결합은 오픈 드레인을 선택하고, 내부 FPGA·SoC 배선은 High-Z 공유 대신 합성 가능한 멀티플렉서 구조를 우선 적용

#### 한줄 요약
- 칩 내부에서 3-상태가 밀려난 이유는 성능이 아니라 검증 가능성이며, 멀티플렉서는 타이밍 위반이 논리 오류로 드러나지만 High-Z는 소자 손상으로 드러난다.
