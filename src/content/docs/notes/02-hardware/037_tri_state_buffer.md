## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **3-상태 버퍼(Tri-State Buffer)**: 논리 0(Low), 논리 1(High) 외에 선로와 전기적으로 분리되는 고임피던스(High-Z) 상태를 가질 수 있는 디지털 스위칭 소자.
- **고임피던스(High-Z / High Impedance)**: 내부 트랜지스터가 모두 차단되어 출력 임피던스가 수 메가옴 이상으로 상승하여 선로와 물리적으로 분리된 무구동 상태.
- **버스 경합(Bus Contention)**: 둘 이상의 드라이버가 동일 버스 라인을 서로 다른 논리 레벨(0과 1)로 동시 구동하여 발생하는 단락 전류 및 신호 왜곡 현상.

</details>

- 정의/개념: 논리 0(Low)과 1(High) 외에 선로와 전기적으로 분리되는 고임피던스(High-Z) 상태를 제어하여 복수의 출력이 단일 공유 버스를 시분할 공유할 수 있도록 지원하는 **디지털 스위칭 소자**
- 배경/필요성: 복수의 디지털 출력 핀이 단일 공통 신호선을 공유할 때 상호 반대 전압 구동으로 인한 **단락 과전류(Bus Contention) 및 소자 파괴 위험**을 방지하기 위해 도입

#### 한줄 요약
- 3-상태 버퍼는 High-Z 상태를 통해 비선택 장치를 버스에서 전기적으로 분리하여 공통 버스 공유를 실현하는 디지털 논리 소자이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **출력 인에이블(Output Enable, OE)**: 버퍼의 출력을 유효 구동 상태(0/1)로 활성화할지 High-Z 절연 상태로 둘지를 제어하는 게이트 제어 신호.
- **플로팅(Floating)**: 모든 드라이버가 High-Z 상태일 때 선로의 전압이 확정되지 않고 중간 전압으로 부유하여 노이즈에 취약해지는 상태.

</details>

- **출력 인에이블(Output Enable, OE)** 제어 신호에 따라 1클록 내에 정상 논리 구동과 고임피던스(High-Z) 전기적 절연 절체
- 복수 소자의 출력을 단일 물리 배선에 병렬 연결하는 와이어드 버스 구성을 통해 **칩 핀 수와 PCB 배선 면적 극소화**
- 모든 버퍼가 비활성화될 때 발생하는 **선로 플로팅(Floating) 현상**을 억제하기 위해 풀업 저항 또는 버스 홀더 회로 연동

#### 한줄 요약
- OE 절연은 장치마다 전용 배선을 깔던 비용을 하나의 공유 선로로 압축하는 대신, 아무도 구동하지 않는 구간의 전압 확정 책임을 풀업 저항이라는 별도 소자에 떠넘긴다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **풀업 PMOS(Pull-Up PMOS)**: 입력이 1일 때 도통하여 출력 라인을 $V_{dd}$(논리 1)로 드라이빙하는 상단 트랜지스터.
- **풀다운 NMOS(Pull-Down NMOS)**: 입력이 0일 때 도통하여 출력 라인을 GND(논리 0)로 드라이빙하는 하단 트랜지스터.

</details>

```text
+-------------------------------------------------------------+
|             데이터 입력 신호 (A) & 출력 인에이블 (OE)        |
+-------------------------------------------------------------+
                               |
                               v
+-------------------------------------------------------------+
|               3-상태 버퍼 내부 CMOS 제어 로직               |
|  +-------------------------------------------------------+  |
|  | 풀업 제어 논리 (NAND)     | 풀다운 제어 논리 (NOR)     |  |
|  +-------------------------------------------------------+  |
|              |                               |              |
|              v                               v              |
|  +-----------------------+       +-----------------------+  |
|  | 풀업 PMOS 트랜지스터  |       | 풀다운 NMOS 트랜지스터|  |
|  | (Vdd 구동: 논리 1)    |       | (GND 구동: 논리 0)    |  |
|  +-----------------------+       +-----------------------+  |
+-------------------------------------------------------------+
                               |
                               v
+-------------------------------------------------------------+
|               단일 공유 시스템 버스 라인 (Shared Bus)        |
|  +-------------------------------------------------------+  |
|  | 풀업 저항 (Pull-up R) 또는 능동 버스 홀더 (Bus Holder) |  |
|  +-------------------------------------------------------+  |
+-------------------------------------------------------------+
```

선의 의미: 실선 화살표는 데이터 및 OE 제어 신호가 내부 CMOS 로직을 거쳐 풀업/풀다운 소자를 구동하거나 양쪽 모두를 턴오프하여 버스를 High-Z로 절연시키는 흐름을 나타냄

| 구성요소 | 책임 |
|:---|:---|
| **제어 논리 게이트** | 데이터(A)와 출력 인에이블(OE)을 조합하여 **상하단 트랜지스터 구동 전압 생성** |
| **풀업 PMOS** | OE=1이고 A=1일 때 도통되어 **출력 라인을 $V_{dd}$(논리 1)로 충전** |
| **풀다운 NMOS** | OE=1이고 A=0일 때 도통되어 **출력 라인을 접지(논리 0)로 고속 방전** |
| **풀업 저항 / 버스 홀더** | 모든 버퍼가 High-Z일 때 **선로 전압 부유 방지 및 논리 레벨 유지** |

#### 한줄 요약
- 제어 논리 게이트가 데이터와 OE를 조합해 풀업 PMOS와 풀다운 NMOS를 동시에 차단하는 경로를 만들어내므로, 출력단이 언제나 Vdd나 GND 중 하나에 묶여 있던 2상태 구동 회로가 스스로 버스에서 빠질 수 있는 소자로 바뀐다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Break-Before-Make**: 새 버퍼를 활성화하기 전에 이전 활성 버퍼를 완전히 High-Z로 차단하여 버스 경합을 방지하는 타이밍 제어 규칙.

</details>

```text
+-------------------------------------------------------------+
|          데이터 입력(A) 및 출력 인에이블(OE) 신호 인가       |
+-------------------------------------------------------------+
                               |
                               v
               +-------------------------------+
               |     1. 출력 인에이블(OE) 판정 |
               +-------------------------------+
                      |                 |
             [OE = 0 (비활성)]          | [OE = 1 (활성 상태)]
                      |                 v
                      | +-------------------------------+
                      | | 2. Break-Before-Make 절체     |
                      | +-------------------------------+
                      |                 |
                      |                 v
                      | +-------------------------------+
                      | | 3. 데이터(A) 레벨에 따른 구동 |
                      | |    (풀업 도통 or 풀다운 도통) |
                      | +-------------------------------+
                      v                 |
+-----------------------+               |
| 상하단 트랜지스터 차단|               |
| 고임피던스(High-Z) 절연|              |
+-----------------------+               |
                      |                 |
                      +--------+--------+
                               v
+-------------------------------------------------------------+
|       4. 공유 버스 라인 전압 확정 (0, 1 또는 High-Z)         |
+-------------------------------------------------------------+
                               |
                               v
+-------------------------------------------------------------+
|       5. 풀업 저항/버스 홀더에 의한 유휴 구간 무결성 유지    |
+-------------------------------------------------------------+
```

분기 결과: **OE=0**이면 출력단이 High-Z로 차단되어 타 장치가 버스를 자유롭게 구동하나, **OE=1**이면 내부 트랜지스터가 도통되어 버스 선로를 논리 0 또는 1로 강력하게 구동함

**동작 원리**

1. **제어 신호 입력 및 디코딩**: 회로에 인가된 인에이블 신호(OE)를 수신하여 현재 버퍼가 버스 구동 권한을 갖는지 판단함
2. **Break-Before-Make 비중첩 절체**: 이전 구동 장치의 차단 시점과 새 장치의 활성화 시점 사이에 비중첩 마진을 두어 두 소자가 동시 도통되는 단락을 방지함
3. **상보적 CMOS 스위칭 구동**: OE=1일 때 입력 데이터 A가 1이면 풀업 PMOS를 턴온하여 $V_{dd}$를 출력하고, A가 0이면 풀다운 NMOS를 턴온하여 GND로 전압을 클램핑함
4. **고임피던스(High-Z) 완전 절연**: OE=0일 때 풀업 PMOS와 풀다운 NMOS를 동시에 턴오프하여 출력 저항을 수 메가옴 이상으로 격리함
5. **유휴 플로팅 억제**: 모든 드라이버가 High-Z인 유휴 구간에서는 외부 풀업 저항 또는 버스 홀더 회로가 미세 전류를 공급하여 선로가 중간 전압으로 표류하는 노이즈를 방지함

#### 한줄 요약
- 절체 구간에서 어느 버퍼도 버스를 구동하지 않는 공백을 감수하는 대가로, 두 출력이 겹쳐 발생하는 버스 경합을 차단한다.

## Ⅴ. 종류 및 비교

| 버퍼 및 드라이버 구조 | 액티브 하이 3-상태 버퍼 | 액티브 로우 3-상태 버퍼 (/OE) | 오픈 드레인 (Open-Drain) | 일반 푸시풀 버퍼 (Push-Pull) |
|:---|:---|:---|:---|:---|
| 적용 기준 | 공통 마이크로프로세서 데이터 버스 | 메모리 칩 제어 버스 (/CE, /OE) | 양방향 유선 AND 라인 (I2C) | 점대점 고속 클록 및 전용 신호선 |
| 활성화 조건 | OE = 1 (**High 레벨**) | /OE = 0 (**Low 레벨**) | 입력 논리에 따라 0 구동 | 상시 능동 활성화 |
| 비활성 상태 | **High-Z** (무구동 절연) | **High-Z** (무구동 절연) | High-Z (외부 저항 풀업 의존) | 해당 없음 (상시 0 또는 1) |
| 버스 공유 여부 | 가능 (**시분할 버스 공유**) | 가능 (**시분할 버스 공유**) | 가능 (**유선 AND 와이어드 OR**) | 불가 (**단락 소자 파괴 발생**) |
| 전송 속도 | 능동 구동 (**고속**) | 능동 구동 (**고속**) | 풀업 시정수 지연 (느림) | 점대점 구동 (**최고속**) |

#### 한줄 요약
- 고속 공유 시스템 버스에는 3-상태 버퍼가 쓰이고, 유선 AND 통신에는 오픈 드레인이, 점대점 전용선에는 푸시풀 버퍼가 쓰인다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **버스 홀더(Bus Holder Circuit)**: 버스가 High-Z가 되었을 때 마지막 논리 상태를 약한 피드백으로 유지하여 중간 전압 누설을 방지하는 회로.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 절체 순간 두 버퍼의 동시 도통으로 인한 버스 경합 | **Break-Before-Make 비중첩 클록** 제어 | 단락 과전류 차단 및 소자 파손 방지 |
| 모든 버퍼 High-Z 시 버스 선로 플로팅 누설 전류 | **풀업 저항** 또는 **능동 버스 홀더** 실장 | 중간 전압 부유 억제 및 대기 전력 소모 방지 |
| 고속 버스 스위칭 시 신호 반사 및 언더슛 노이즈 | 버퍼 출력단 **직렬 댐핑 저항** 실장 | 전송선로 임피던스 정합 및 신호 무결성 확보 |

#### 한줄 요약
- 실무에서는 Break-Before-Make로 동시 충돌을 방지하고, 버스 홀더로 플로팅 누설을 잡으며, 댐핑 저항으로 신호 반사를 억제한다.

- 

#### 한줄 요약
- 3-상태 버퍼는 디지털 시스템 버스 공유의 기본 소자이며, Break-Before-Make 타이밍과 버스 홀더의 결합으로 완성된다.
