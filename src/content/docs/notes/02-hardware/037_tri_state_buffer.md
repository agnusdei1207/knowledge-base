## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **3-상태 버퍼(Tri-State Buffer)**: 활성화 신호에 따라 논리 0·1 또는 고임피던스(High-Z)를 출력하는 회로.
- **버스 경합(Bus Contention)**: 둘 이상의 출력이 공용 라인을 서로 다른 값으로 동시 구동하여 신호 충돌이 발생하는 상태.

</details>

- 정의/개념: 출력 활성화 신호에 따라 논리 0·1 또는 고임피던스(High-Z) 상태를 출력하는 **3-상태 버퍼**
- 배경/필요성: 공유 버스에 연결된 복수 드라이버의 동시 출력 시 숏트 전류 소손 및 논리 신호 왜곡 발생 방지

#### 한줄 요약

- 3-상태 버퍼는 선택된 출력만 0 또는 1을 구동하고 나머지는 고임피던스로 분리해 공유선 경합을 방지한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **고임피던스(High-Z)**: 출력단이 전기적으로 절연되어 공유선에 영향을 주지 않는 상태.
- **OE(Output Enable)**: 출력단의 데이터 구동 여부를 제어하는 활성화 신호.
- **OE 상호 배타(OE Mutual Exclusion)**: 다수 출력 활성화 신호 중 동시 참(True) 상태를 최대 1개로 제한하는 조건.
- **부동(Floating)**: 어느 드라이버도 선을 구동하지 않아 전압 레벨이 불확정 상태로 방치되는 현상.
- **비중첩 전환(Non-Overlapping Transition)**: 기존 출력을 끈 후 다음 출력을 키는 시간차 전환 기법.
- **바이어스(Bias)**: 무구동 신호선의 기준 전압 유지를 위한 풀업/풀다운 회로 구성.
- **버스 홀드(Bus Hold)**: 부동 상태 시 약한 피드백으로 직전 논리 전압 상태를 유지하는 회로.

</details>

- **OE** 및 **고임피던스** 제어를 통한 비선택 드라이버의 전기적 분리
- 동시 구동에 의한 단락 방지 목적의 **OE 상호 배타** 및 **비중첩 전환**
- 무구동 구간의 **부동** 방지를 위한 **바이어스** 및 **버스 홀드** 적용

#### 한줄 요약

- OE 상호 배타와 비중첩 전환은 출력 경합을 막고, 풀업·풀다운·버스 홀드는 무구동 구간의 부동을 막는다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **데이터 입력(Data Input)**: 3-상태 버퍼를 통해 공유 버스로 전달되는 입력 논리 신호.
- **공유 버스(Shared Bus)**: 단일 시점에 하나의 드라이버만 구동 가능한 공용 신호 배선.

</details>

```text
                     [데이터 입력]
                            |
[출력 활성화] ----- [3-상태 출력단] ----- [공유 버스]
```

선의 의미: 3-상태 출력단을 중심으로 데이터, 출력 활성화 및 공유 버스가 결합되는 정적 신호 제어 경계.

| 구성요소 | 책임 |
|:---|:---|
| 데이터 입력 | 외부 전달 대상 논리 0 또는 1 제공 |
| 출력 활성화 | 출력 구동 및 고임피던스 상태 선택 제어 |
| 3-상태 출력단 | OE 제어에 따른 0·1·High-Z 출력 생성 |
| 공유 버스 | 단일 선택 드라이버의 신호 전달 경로 |

#### 한줄 요약

- 출력 활성화 신호가 한 출력단만 공유 버스를 구동하도록 제어한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **DQ(Data Input/Output)**: 메모리와 컨트롤러 간 데이터를 전송하는 양방향 신호선.
- **턴어라운드(Turnaround Time)**: 양방향 버스의 데이터 전송 방향 전환 시 발생하는 상호 비구동 시간.

</details>

```text
                       [DQ 쓰기 구간]
                             |
                    1. 제어기 OE 활성
                             |
                    2. 쓰기 데이터 구동
                             |
                   3. 제어기 OE 비활성
                             |
                  [DQ 버스 고임피던스]
                             |
                        [턴어라운드]
                             |
               4. 메모리 OE 활성•읽기 구동
                             |
                     [제어기에 반환]
```

### 동작 원리

1. **제어기 OE 활성**: 쓰기 구간 중 컨트롤러 출력단 활성화 및 **DQ** 버스 구동.
2. **쓰기 데이터 구동**: 컨트롤러가 0·1 쓰기 데이터를 DQ 버스로 출력.
3. **제어기 OE 비활성**: 읽기 전환 전 컨트롤러 출력을 **고임피던스**로 변경하여 **턴어라운드** 시간 확보.
4. **메모리 OE 활성·읽기 구동**: 컨트롤러 출력 완전 차단 확인 후 메모리 OE 활성화 및 읽기 데이터 반환.

#### 한줄 요약

- 쓰기 출력이 고임피던스로 전환된 뒤 읽기 출력을 활성화해야 양방향 DQ 버스의 순간 단락과 논리 충돌을 막을 수 있다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **오픈드레인(Open-Drain)**: 논리 0 또는 High-Z만 출력하고 외부 풀업으로 논리 1을 형성하는 회로.
- **풀업 저항(Pull-Up Resistor)**: 무구동 시 신호선을 높은 전압(VCC)으로 유전하는 저항.
- **MUX(Multiplexer)**: 제어 신호에 따라 다수 입력 중 하나를 단일 출력으로 선택하는 조합 논리 회로.

</details>

| 공유 경로 구성 | 3-상태 버퍼 | MUX | 오픈드레인 |
|:---|:---|:---|:---|
| 적용 기준 | 외부 양방향 데이터 버스 | 칩 내부 단일 선택 경로 | 다중 장치 공유 제어선 |
| 핵심 특징 | **3-상태 버퍼** 기반 양방향 제어 | **MUX** 조합 논리 신호 선택 | **오픈드레인** 와이어드 AND 연결 |
| 한계 | 경합 전류 및 **부동** 상태 발생 | 내부 면적 증가 및 배선 복잡 | 풀업 저항 지연 및 직접 High 구동 불가 |

> 요약: 외부 버스는 3-상태, 내부 경로는 MUX 적용.

#### 한줄 요약

- 외부 양방향 버스에는 3-상태 버퍼가, 칩 내부의 단일 선택 경로에는 멀티플렉서가 적합하다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **논리 합성(Logic Synthesis)**: RTL 설계를 게이트 레벨의 논리 회로 체계로 자동 변환하는 과정.
- **순간 단락(Pass-Through Short)**: 전환 타이밍 겹침으로 두 드라이버가 반대 논리를 동시 구동하는 현상.
- **FPGA(Field-Programmable Gate Array)**: 프로그램 가능한 반도체 논리 소자.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 다수 드라이버 동시 활성화로 인한 논리 충돌 | **OE 상호 배타** 조건 검증 및 로직 설계 | 전기적 신호 충돌 방지 |
| 방향 전환 시 구동 시간 중첩에 따른 **순간 단락** | **비중첩 전환** 및 충분한 **턴어라운드** 확보 | 과도한 대전류 유입 차단 |
| 모든 출력 차단 시 버스 **부동** 현상 | 풀업/풀다운 **바이어스** 및 **버스 홀드** 적용 | 무구동 시 신호 전압 안점화 |
| **FPGA** 칩 내부 3-상태 회로 사용 시 MUX 변환 | 내부 신호는 **MUX**, 외부 핀에만 3-상태 버퍼 할당 | 논리 합성 구조 최적화 |

> 사례: 양방향 메모리 DQ 버스의 **턴어라운드** 타임 설정

#### 한줄 요약

- OE 상호 배타와 충분한 턴어라운드 시간으로 양방향 버스 전환 중 순간 단락을 방지한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **공유 경로 선택 기준(Shared Path Selection Criteria)**: 칩 내부/외부 버스 환경 및 양방향성 여부에 따른 최적 버스 구동 회로 선택 기준.

</details>

- **공유 경로 선택 기준**에 따라 외부 양방향 버스는 **3-상태 버퍼**, 칩 내부 선택 경로는 **MUX** 선택

#### 한줄 요약

- 외부 양방향 공유선은 3-상태 버퍼로 구동하고, 칩 내부의 신호 선택 경로는 MUX로 구현한다.
