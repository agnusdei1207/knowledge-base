## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **3-상태 버퍼**: 활성화에 따라 논리 0•1 또는 고임피던스를 출력해 공유선 충돌을 막는 회로
- **버스 경합**: 둘 이상의 출력이 같은 선을 서로 다른 값으로 동시에 구동해 전류와 논리가 충돌하는 상태

</details>

- 정의/개념: 활성화 신호에 따라 **논리 0•1 또는 고임피던스** 를 출력해 공유선 충돌을 막는 회로
- 배경/필요성: 다중 출력의 **경합 전류•논리 충돌** 방지

#### 한줄 요약

- OE로 **0•1•Z** 를 선택해 공유선 경합 방지

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **고임피던스(Z)**: 출력 구동을 끊어 공유선에 전기적으로 영향을 주지 않는 상태
- **OE**: Output Enable, 출력단의 구동 여부를 제어하는 신호
- **OE 원-핫**: 여러 OE 신호 중 정확히 하나만 참이 되는 조건
- **부동**: 어느 출력도 선을 구동하지 않아 전압과 논리값이 정해지지 않은 상태

</details>

- **OE•고임피던스(Z)** 기반 비선택 출력의 공유선 분리
- 동시 구동 경합을 막는 **원-핫•비중첩 제어**
- 무구동 구간은 **부동 입력** 방지를 위한 바이어스•홀드 필요

#### 한줄 요약

- **원-핫•비중첩** 은 경합, 바이어스는 부동 방지

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **데이터 입력**: 선택된 출력단이 공유 버스에 전달할 논리 0 또는 1
- **공유 버스**: 한 시점에 하나의 출력단만 구동해야 하는 공용 신호선

</details>

```text
                     [데이터 입력]
                           |
[출력 활성화] ----- [3-상태 출력단] ----- [공유 버스]
```

선의 의미: 선은 3-상태 출력단을 중심으로 데이터, 출력 활성화와 공유 버스가 결합되는 정적 신호 경계를 뜻한다.

| 구성요소 | 책임 |
|:---|:---|
| 데이터 입력 | 외부 전송 **논리 0•1** 제공 |
| 출력 활성화 | 구동•**고임피던스** 선택 |
| 3-상태 출력단 | 데이터•OE 기반 **0•1•Z** 출력 |
| 공유 버스 | 단일 구동자의 **신호 전달** |

#### 한줄 요약

- 출력 활성화 신호가 한 출력단만 공유 버스를 구동하도록 제어한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **DQ**: Data Input/Output, 메모리 읽기•쓰기 데이터를 전달하는 신호
- **DQ 버스**: 메모리와 제어기 사이의 양방향 데이터선
- **비중첩 전환**: 현재 출력단을 끈 뒤 다음 출력단을 켜 동시 구동을 막는 전환
- **턴어라운드**: 양방향 버스의 구동 주체가 바뀔 때 두 출력이 모두 꺼져 있는 시간

</details>

```text
                      [DQ 쓰기 구간]
                            |
                   1. 제어기 OE 활성
                            |
                   2. 쓰기 데이터 구동
                            |
                  3. 제어기 OE 비활성
                            |
                 [DQ 버스 고임피던스]
                            |
                       [턴어라운드]
                            |
                   4. 메모리 OE 활성
                            |
                    [읽기 데이터 구동]
                            |
                    [제어기에 반환]
```

**동작 원리**

- **1. 제어기 OE 활성**: 쓰기 출력단의 버스 구동 허용
- **2. 쓰기 데이터 구동**: 제어기에서 DQ 버스로 전달
- **3. 제어기 OE 비활성**: 턴어라운드 전에 공유선 해제
- **4. 메모리 OE 활성**: 읽기 출력단에 구동 권한 이전

#### 한줄 요약

- 쓰기 출력이 Z로 물러난 뒤 읽기 출력이 켜져야 공유 DQ 버스의 경합을 막는다

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **멀티플렉서**: 선택 신호로 여러 입력 중 하나만 내부 출력 경로에 연결하는 조합 회로
- **오픈드레인**: 0 또는 고임피던스만 출력하고 외부 풀업 저항으로 1을 만드는 공유선 방식
- **풀업 저항**: 구동자가 없을 때 신호선을 높은 전압으로 끌어올리는 저항
- **MUX**: Multiplexer, 여러 입력 중 하나를 출력으로 연결하는 회로

</details>

| 공유 경로 구성 | 3-상태 버퍼 | 멀티플렉서 | 오픈드레인 |
|:---|:---|:---|:---|
| 적용 기준 | 외부 **양방향 데이터 버스** | 내부 **선택 경로** | 다중 장치 **공유 제어선** |
| 핵심 특징 | OE 기반 **0•1•Z 출력** | 선택 입력의 **단일 출력 연결** | 0•Z 출력과 **외부 풀업** |
| 한계 | 경합 전류•**무구동 부동** | 선택 지연•**배선 증가** | 풀업 지연•**High 직접 구동 불가** |

> 요약: 외부 버스는 3-상태, 내부 경로는 MUX가 적합하다

#### 한줄 요약

- 외부 양방향은 **3-상태**, 내부 선택은 MUX

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **버스 홀드**: 모든 출력이 고임피던스일 때 약한 되먹임으로 마지막 논리값을 유지하는 회로
- **논리 합성**: 하드웨어 설명을 실제 게이트와 멀티플렉서 연결로 변환하는 과정
- **순간 단락**: 방향 전환 중 두 출력단이 반대 값을 함께 구동해 큰 전류가 흐르는 현상
- **FPGA**: Field-Programmable Gate Array, 재구성 가능한 논리 장치

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 둘 이상의 출력이 동시에 활성화 | **OE 원-핫** 속성과 경합 전류 감시 | **전기적 충돌** 방지 |
| 방향 전환 시 구동 시간이 겹침 | **비중첩•턴어라운드** 시간 검증 | 순간 단락 방지 |
| 모든 출력이 Z인 동안 버스 부동 | **풀업•풀다운•버스 홀드** 적용 | **입력값** 안정화 |
| FPGA 내부 3상 버퍼가 MUX로 합성 | 내부 경로는 **MUX**, 핀에서만 3상 사용 | **합성 결과** 예측성 향상 |

> 사례: **읽기•쓰기 전환 구간** 에 턴어라운드를 확보하는 메모리 DQ 버스

#### 한줄 요약

- **턴어라운드•OE 원-핫** 으로 순간 단락 방지

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **외부 양방향 버스**: 같은 물리 핀을 시간에 따라 입력과 출력으로 번갈아 사용하는 경로
- **내부 선택 경로**: 칩 내부에서 여러 신호 중 하나를 논리적으로 골라 전달하는 배선

</details>

- 외부 양방향은 **3-상태**, 내부 선택은 **MUX** 적용

#### 한줄 요약

- 외부 공유선은 3-상태, 내부 신호는 **MUX** 적용
