## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **현장 프로그램 가능 게이트 어레이(Field-Programmable Gate Array)**: 제조가 끝난 후에도 설계자가 원하는 대로 내부 논리 회로와 배선을 찰흙처럼 뗐다 붙이며 재구성할 수 있는 놀라운 유연성을 가진 반도체이다.
- **재구성 회로(Reconfigurable Circuit)**: 소프트웨어 코드를 실행하는 방식이 아니라, 하드웨어 회로망 자체를 비트스트림이라는 설계도로 덮어씌워 완전히 다른 칩처럼 동작하게 만드는 물리적 변신 회로이다.
- **지연 상한(Latency Bound)**: 자율주행이나 산업 제어처럼 아무리 최악의 상황이라도 입력이 들어오면 반드시 정해진 찰나의 시간 안에 결과를 토해내야 하는 엄격한 마감 시간이다.
- **인공지능(Artificial Intelligence)**: 인간의 뇌신경망을 모방한 방대한 행렬 곱셈을 통해 기계가 스스로 학습하고 추론하게 만드는 데이터 처리 기술이다.
- **주문형 반도체(Application-Specific Integrated Circuit)**: 오직 붕어빵만 굽기 위해 무쇠 뼈대로 쾅 찍어 만든 틀처럼, 특정 기능 하나만 미친 듯이 잘하지만 절대 용도를 바꿀 수 없는 고정형 반도체이다.
- **그래픽 처리 장치(Graphics Processing Unit)**: 수천 개의 미니 코어를 때려 박아 수만 개의 스레드를 동시에 돌리는 소프트웨어 기반의 무식하고 강력한 병렬 연산 가속기이다.

</details>

- 정의: 인공지능 모델 알고리즘에 맞추어 칩 내부의 논리 회로와 데이터 이동 경로를 비트스트림으로 유연하게 뜯어고쳐 하드웨어 레벨에서 밀착 지원하는 **현장 프로그램 가능 게이트 어레이** 기반 가속 방식
- 배경: 기능이 고정된 **주문형 반도체**가 가지는 알고리즘 변경 불가 한계와 **그래픽 처리 장치**가 가진 소프트웨어 탓에 들쭉날쭉한 응답 지연 문제를 한 번에 극복하기 위함

#### 한줄 요약

- 알고리즘이 바뀔 때마다 하드웨어 회로망을 다시 엮어 소프트웨어의 느린 실행 지연을 없애고, 최악의 순간에도 정해진 시간 안에 일정한 속도로 인공지능 추론을 완수하는 변신 로봇 같은 칩이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **공간 병렬 파이프라인(Spatial Parallel Pipeline)**: 시간을 쪼개 쓰는 방식이 아니라, 공장의 컨베이어 벨트처럼 칩의 물리적 공간에 연산 단계들을 주르륵 배치하여 물 흐르듯 데이터를 연속 처리하는 하드웨어 특화 구조이다.
- **개시 간격(Initiation Interval)**: 컨베이어 벨트에서 바로 앞 제품과 다음 제품 사이의 간격처럼, 파이프라인이 새로운 데이터를 삼키는 데 걸리는 클록 주기의 틱 차이이다.
- **비트스트림(Bitstream)**: 칩 내부의 수만 개 논리 게이트와 배선 스위치들을 어떻게 켤지 정의해 둔 기계어 설계도 파일로, 이 파일을 칩에 부으면 하드웨어 회로가 새롭게 탄생한다.
- **온칩 메모리 재사용(On-Chip Memory Reuse)**: 칩 밖의 느려터진 메모리에 다녀오는 시간을 없애고자, 가중치와 중간 계산 값을 칩 내부의 초고속 버퍼에 꽉꽉 우겨넣고 닳도록 재활용하는 극한의 최적화 기법이다.

</details>

- 응답 시간이 들쭉날쭉한 소프트웨어 스레드를 버리고, 물리적으로 구성된 **공간 병렬 파이프라인**을 뚫어 **개시 간격**을 최소화함으로써 한 치의 오차도 없는 결정적 처리 속도를 보장함.
- 매일 쏟아지는 새로운 인공지능 알고리즘의 진화 속도에 뒤처지지 않도록, 하드웨어를 유연하게 재구성하는 **비트스트림** 매핑을 제공함.
- 바깥 메모리를 오가며 생기는 심각한 전송 병목을 극복하기 위해, 칩 내부의 자원을 영혼까지 끌어모으는 **온칩 메모리 재사용** 중심의 최적화된 데이터 흐름 설계를 채택함.

#### 한줄 요약

- 소프트웨어의 변덕을 버리고 물리적 컨베이어 벨트(공간 파이프라인)를 깔아 지연시간을 꽉 잡으며, 칩 안의 메모리만으로 끈질기게 버티면서 새로운 알고리즘이 나올 때마다 회로를 뜯어고친다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **룩업 테이블(Look-Up Table)**: 진리표를 내부에 저장해 두고 입력이 들어오면 답을 툭 뱉어내는, 모든 논리 게이트를 흉내 낼 수 있는 카멜레온 같은 기초 조각이다.
- **디에스피 슬라이스(DSP Slice)**: 인공지능 연산의 꽃인 덧셈과 곱셈을 빛의 속도로 쳐내기 위해 칩 내부에 하드웨어로 박아넣은 단단하고 강력한 고속 연산 전용 블록이다.
- **블록 램(Block RAM)**: 칩 내부 곳곳에 점조직처럼 흩뿌려져 있어, 연산기 바로 옆에서 가중치 데이터를 1나노초 만에 찔러 넣어주는 초고속 임시 저장소이다.
- **직접 메모리 접근(Direct Memory Access)**: 칩이 컴퓨터의 메인 메모리에 직접 빨대를 꽂아, 중앙처리장치 몰래 엄청난 양의 영상 데이터를 칩 안으로 폭포수처럼 끌어오는 하드웨어 펌프이다.
- **플립플롭(Flip-Flop)**: 심장 박동(클록)이 뛸 때마다 데이터를 받아 다음 단계로 넘겨주며 파이프라인의 마디마디를 끊어주는 레지스터 소자이다.
- **곱셈 누산 연산(Multiply-Accumulate)**: 인공지능이 데이터를 판단할 때 수도 없이 반복하는 '곱하고 더하는' 핵심 수학 연산이다.

</details>

```text
[ 현장 프로그램 가능 게이트 어레이 인공지능 가속기 아키텍처 ]
+-------------------------------------------------------------+
| 인공지능 가속 칩 내부 경계                                  |
|                                                             |
|  [ 비트스트림 수신 및 하드웨어 구성 제어부 ]                |
|               │ (회로망 재조립)                             |
|               ▼                                             |
|  [ 직접 메모리 접근 및 데이터 스트림 인터페이스 통신망 ]    |
|               │ (텐서 데이터 유입)                          |
|               ▼                                             |
|  [ 블록 램 및 울트라 램 초고속 온칩 임시 버퍼망 ]           |
|               │ (가중치 및 데이터 융단폭격 공급)            |
|               ▼                                             |
|  [ 룩업 테이블, 플립플롭, 디에스피 슬라이스 융합 파이프라인]|
+-------------------------------------------------------------+
```

| 구성요소 | 책임 |
|:---|:---|
| **비트스트림** 및 구성 제어기 | 외부에서 설계도를 다운받아 칩 내부의 논리 배선과 **디에스피 슬라이스**의 동작 모드를 찰흙처럼 재구성 |
| **직접 메모리 접근** 및 인터페이스 | 중앙처리장치 개입 없이 외부 호스트 메모리에서 방대한 텐서 데이터를 초고속 스트리밍으로 칩 내부로 직접 펌핑 |
| **블록 램** 및 온칩 버퍼 | 인공지능 신경망의 무거운 가중치, 특징 맵, 계산 중간 찌꺼기들을 연산기 바로 옆에 임시로 꽉꽉 눌러 담음 |
| **룩업 테이블**, **플립플롭**, **디에스피 슬라이스** | 재구성된 제어 논리를 바탕으로, 끝없이 밀려오는 **곱셈 누산 연산**을 컨베이어 벨트 위에서 병렬로 무자비하게 쳐냄 |

#### 한줄 요약

- 설계도를 다운받아 회로망을 재조립한 뒤, 펌프로 외부 데이터를 빨아들여 버퍼에 채우고, 강력한 전용 연산기들로 쉴 틈 없이 데이터를 갈아버린다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **구성 제어기(Configuration Controller)**: 전원이 켜지거나 모델이 바뀔 때 비트스트림 파일을 읽어 들여, 이 파일이 오염되지 않았는지 서명을 검사하고 칩의 배선을 촤르륵 재정렬하는 내부 십장이다.
- **타일(Tile)**: 수십 메가바이트에 달하는 텐서 데이터를 칩 내부의 코딱지만 한 메모리 크기에 맞게 바둑판처럼 잘게 썰어놓은 데이터 조각이다.
- **이중 버퍼링(Double Buffering)**: A 통통배가 연산기에 데이터를 붓고 있는 동안, B 통통배는 밖에서 다음 데이터를 몰래 실어 와서 연산기가 단 1초도 쉬지 않게 만드는 핑퐁 보급 전술이다.

</details>

```text
[ 인공지능 모델 적용 및 공간 파이프라인 가속 실행 흐름 ]
                      │
                      ▼
 [ 1. 인공지능 알고리즘 분석 및 온칩 데이터 흐름 맵 짜기 ]
                      │
                      ▼
 [ 2. 구성 제어기를 통한 비트스트림 무결성 검증 및 칩 재조립 ]
                      │
                      ▼
 [ 3. 직접 메모리 접근을 통한 핑퐁 이중 버퍼 타일 데이터 폭격 ]
                      │
                      ▼
 [ 4. 완성된 물리적 컨베이어 파이프라인의 무자비한 연산 쳐내기 ]
```

### 동작 원리

1. 매핑 설계: 소프트웨어 알고리즘을 잘근잘근 씹어 분석하고, 칩 내부 버퍼와 **디에스피 슬라이스**의 효율적인 물리 공간 배치를 결정함.
2. 비트스트림 구성: **구성 제어기**가 서명 검증을 거친 설계도를 칩에 붓고, 스위치들을 조작하여 새 인공지능에 맞는 하드웨어를 탄생시킴.
3. 핑퐁 데이터 공급: 칩이 깨어나면 **직접 메모리 접근** 엔진이 **이중 버퍼링** 구조를 통해 연산이 멈추지 않도록 **타일** 조각을 끊임없이 먹여줌.
4. 파이프라인 연산: 구축된 거대한 물리적 파이프라인을 통하여 연속으로 밀려오는 **곱셈 누산 연산**을 흔들림 없는 속도로 완수하고 결과를 뱉어냄.

#### 한줄 요약

- 모델을 분석해 회로도를 그리고(매핑), 칩을 변신시킨 뒤(구성), 핑퐁 전술로 데이터를 밀어 넣으면(버퍼링), 톱니바퀴 맞물리듯 정확한 시간에 계산이 끝난다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **배치 처리량(Batch Throughput)**: 지연시간은 좀 늦더라도 여러 장의 사진을 묶어서 한 번에 공장식으로 처리할 때 1초당 뿜어내는 압도적인 데이터 마릿수이다.
- **타이밍 클로저(Timing Closure)**: 칩 안의 전기 신호가 정해진 클록 박동 시간 안에 꼬불꼬불한 배선을 무사히 통과하도록 물리적 배치를 깎고 다듬는 피 말리는 노가다 작업이다.
- **대량 생산(Mass Production)**: 한 번 설계도를 쾅 찍어 붕어빵 틀을 만들면 수정은 불가능하지만, 수백만 개를 싸고 전력 소모 적게 찍어내어 돈을 쓸어 담는 상업 생태계이다.

</details>

| 비교 항목 | **현장 프로그램 가능 게이트 어레이** | **그래픽 처리 장치** | **주문형 반도체** |
|:---|:---|:---|:---|
| 시스템 적용 최적 기준 | 알고리즘이 자주 바뀌면서도 목숨이 걸린 엄격한 **지연 상한** 준수 요구 시 | 잦은 알고리즘 갱신과 압도적인 통뼈 **배치 처리량**이 필요한 클라우드 서버 시 | 알고리즘이 완벽히 굳어버렸고 가격과 전력이 중요한 **대량 생산** 출하 중심 환경 시 |
| 아키텍처 핵심 구현 구조 | 물리적인 **공간 병렬 파이프라인**을 마음대로 뜯어고치는 재구성 하드웨어 | 수천 개 미니 코어를 무식하게 박아 넣은 소프트웨어 스레드 병렬성 극대화 칩 | 특정 목적 단 하나를 위해 뼛속까지 굳어버린 완벽히 고정 설계된 극강 효율 하드웨어 |
| 극복해야 할 태생적 한계 | 남는 논리 게이트들의 낭비 오버헤드와 전기 신호를 맞추는 **타이밍 클로저** 달성의 지독한 어려움 | 전기 먹는 하마급 전력 소모와 운영체제 개입으로 인한 튀는 지연시간 변동성 | 수백억이 깨지는 막대한 초기 개발 비용 발생 및 한 번 구우면 절대 고칠 수 없는 기능 |

#### 한줄 요약

- 속도와 지연시간을 꽉 잡아야 하면서도 로직을 뜯어고치고 싶으면 FPGA, 무조건 많이만 쳐내면 되면 GPU, 한 우물만 파서 대박 칠 거면 ASIC을 택한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **양자화(Quantization)**: 메모리를 엄청나게 잡아먹는 무거운 소수점(FP32) 데이터를 앙증맞은 정수(INT8)로 뭉개버려, 연산 속도를 폭발시키고 칩 내부 메모리 한계를 극복하는 마법이다.
- **부분 재구성(Partial Reconfiguration)**: 카메라 시스템 전체를 끄지 않고도, 칩 한구석의 필터 로직 영역만 실시간으로 몰래 다른 회로로 바꿔치기하는 극한의 무중단 변신 기술이다.
- **롤백 이미지(Rollback Image)**: 인터넷으로 칩 설계도를 업데이트받다가 랜선이 뽑히면 벽돌이 되는 걸 막기 위해, 칩 안쪽에 고이 모셔둔 '돌아가기'용 옛날 정상 설계도 복사본이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 로직 최적화 실패로 전기 신호가 제때 도착하지 못하는 **타이밍 클로저** 위반 및 칩 먹통 사태 | 중간중간 파이프라인 레지스터를 징검다리처럼 추가하고 클록 도메인을 논리적으로 완전히 분리 독립 | 넉넉한 전기적 타이밍 마진 확보 및 마이크로아키텍처 회로의 흔들림 없는 작동 안정화 |
| 바깥 동적 메모리의 허접한 대역폭 때문에 연산기가 밥을 못 먹고 놀고먹는 치명적 지연 병목 | 텐서 데이터 **양자화**로 다이어트, 버퍼 타일링 쪼개기 및 핑퐁 **이중 버퍼링** 하드웨어 무한 가동 | 느린 외부 메모리 바운드의 족쇄 완화 및 온칩 연산기의 곱셈 효율 100% 한계 돌파 |
| 코딱지만 한 칩 내부 자원 한계로 덩치가 산만 한 최신 딥러닝 대형 모델이 안 들어가는 참사 | 레이어별로 시간을 쪼개 쓰는 시분할 구조 채택 및 핵심 구역 대상 동적 **부분 재구성** 꼼수 할당 | 비싼 큰 칩을 안 사고도 한정된 하드웨어 자원을 영혼까지 쥐어짜 내어 대형 모델 억지 수용 |
| 공장에 설치된 칩을 원격 업데이트하다가 인터넷이 끊기거나 해커가 오염된 파일로 칩을 부수려는 위협 | 검증된 구버전 **롤백 이미지** 탑재 강제화 및 업데이트 파일의 비트스트림 암호화 서명 철저 검증 | 재구성 폭파 실패 시 불사조처럼 자동 복구 발동 및 무인 공장 시스템 가용성 24시간 완벽 유지 |

#### 한줄 요약

- 레지스터로 징검다리를 놔서 신호 지연을 막고, 데이터 다이어트(양자화)와 핑퐁 버퍼링으로 굶주림을 해결하며, 부위별 변신(부분 재구성)으로 좁은 칩의 한계를 뚫어낸다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **가속기 아키텍처 선택 기준(Accelerator Architecture Decision Criteria)**: 개발 중인 기기의 알고리즘 변동 주기, 최악의 순간에도 응답해야 하는 지연 상한선, 투자 가능한 개발 비용을 냉정하게 따져 반도체의 운명을 가르는 결정 프레임워크이다.

</details>

- **가속기 아키텍처 선택 기준**에 따라, 로봇 제어처럼 알고리즘 갱신과 1밀리초의 엄격한 **지연 상한**이 결합된 환경은 **현장 프로그램 가능 게이트 어레이**, 빅데이터 클라우드 병렬처리는 **그래픽 처리 장치**, 스마트폰 등 대량 살포 기기는 **주문형 반도체**를 단호히 선정함

#### 한줄 요약

- 알고리즘이 바뀌어도 지연시간만큼은 절대 양보할 수 없는 현장 제어 시스템이라면 유연하고 빠릿빠릿한 찰흙 반도체(FPGA)가 유일한 구원자이다.
