## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **FPGA(Field-Programmable Gate Array)**: 하드웨어 논리 회로와 배선 연결 구조를 재구성할 수 있는 프로그래머블 반도체.
- **재구성 회로(Reconfigurable Circuit)**: 비트스트림을 변경하여 연산 논리 및 데이터 경로를 재설정 가능한 하드웨어 회로.
- **지연 상한(Latency Bound)**: 실시간 제어 환경에서 응답 완결에 대한 최악 조건 허용 시간 한계.
- **AI(Artificial Intelligence)**: 학습 알고리즘 기반 지능형 데이터 처리 및 연산 기술.
- **ASIC(Application-Specific Integrated Circuit)**: 특정 응용 목적에 맞게 기능이 고정 제작되는 주문형 반도체.
- **GPU(Graphics Processing Unit)**: 대규모 코어 기반 스레드 병렬 처리 중심 소프트웨어 프로그래밍 가능한 가속기.

</details>

- 정의/개념: AI 모델 알고리즘에 맞게 회로 논리 및 데이터 경로를 **비트스트림**으로 유연하게 재매핑하는 **FPGA AI 가속** 방식
- 배경/필요성: 고정 ASIC의 신규 AI 모델 적용 불가 한계 극복 및 GPU 대비 실시간 지연시간(Latency) 결정성 보장

#### 한줄 요약

- FPGA는 모델 변경 시 회로를 다시 구성하고 공간 파이프라인의 단계와 데이터 공급을 고정해 추론 지연 변동을 줄인다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **공간 병렬 파이프라인(Spatial Parallel Pipeline)**: 연산 단계를 물리적으로 나눈 하드웨어 레지스터에 분치하여 데이터를 연속 흐름 방식으로 처리하는 구조.
- **II(Initiation Interval)**: 파이프라인이 다음 새 입력을 받기까지 소요되는 클록 주기 간격.
- **비트스트림(Bitstream)**: FPGA 내부 LUT, 배선 및 블록 RAM 설정을 정의한 바이너리 구성 파일.
- **온칩 메모리 재사용(On-Chip Memory Reuse)**: 외부 DRAM 전송을 최소화하기 위해 내부 BRAM에 가중치 및 부분합을 보관 및 재활용하는 방식.

</details>

- 지연시간 유동성 없는 결정적 처리율을 보장하는 **공간 병렬 파이프라인** 및 **II** 최소화
- AI 알고리즘 변화에 맞춰 하드웨어를 재구성하는 **비트스트림** 매핑
- 외부 메모리 병목을 극복하는 **온칩 메모리 재사용** 중심 설계

#### 한줄 요약

- 공간 파이프라인은 단계마다 연산을 겹쳐 실행하며, 개시 간격이 작을수록 새 입력을 더 자주 받아 처리량을 높인다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **LUT(Look-Up Table)**: 조합 논리 회로 진리표를 저장하여 임의 논리 함수를 구현하는 FPGA 기본 구성 소자.
- **DSP 슬라이스(DSP Slice)**: 고속 곱셈과 누산(MAC) 연산을 수행하도록 하드웨어로 고정 제작된 연산 블록.
- **BRAM/URAM(Block RAM / UltraRAM)**: 가중치 및 중간 텐서 데이터를 고속 저장하는 FPGA 온칩 메모리.
- **DMA(Direct Memory Access)**: CPU 개입 없이 외부 호스트 메모리 데이터를 온칩 버퍼로 전송하는 장치.
- **FF(Flip-Flop)**: 동기 클록에 맞춰 논리 레벨 상태를 제어 및 보관하는 순차 논리 소자.
- **MAC(Multiply-Accumulate)**: 딥러닝 핵심 연산 단위인 곱셈 후 누산 처리 동작.

</details>

```text
FPGA AI 가속기
|
+-- [비트스트림•구성 메모리]
+-- [DMA•스트림 인터페이스]
+-- [BRAM•URAM 버퍼]
`-- [LUT•FF•DSP 파이프라인]
```

선의 의미: 4개의 하드웨어 자원이 FPGA AI 가속기 경계 내부에서 정적 포함 및 전송/연산 분담 연결 관계 형성.

| 구성요소 | 책임 |
|:---|:---|
| 비트스트림•구성 메모리 | 논리 라우팅 및 DSP 동작 모드 재구성 정보 제공 |
| DMA•스트림 인터페이스 | 호스트 간 고속 텐서 스트리밍 데이터 이송 |
| BRAM•URAM 버퍼 | 가중치, 특징 맵 및 부분합의 온칩 임시 보관 |
| LUT•FF•DSP 파이프라인 | 파이프라인 제어 논리 및 MAC 병렬 연산 수행 |

#### 한줄 요약

- 비트스트림이 전송•버퍼•연산 회로를 구성해 모델별 파이프라인을 만든다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **구성 제어기(Configuration Controller)**: 비트스트림 인가 및 무결성 검증을 통해 FPGA 자원을 초기화하는 칩 내부 컨트롤러.
- **타일(Tile)**: 대용량 텐서를 온칩 BRAM 크기에 맞춰 분할한 데이터 단위 블록.
- **이중 버퍼링(Double Buffering)**: 핑퐁 버퍼 구조로 타일 연산과 다음 타일 데이터 DMA 전송을 동시 수행하는 기법.

</details>

```text
                    [AI 모델•지연 상한]
                             |
                1. 연산•데이터 흐름 매핑
                             |
                  2. 비트스트림 검증•구성
                             |
                [LUT•FF•DSP 공간 파이프라인]
                             |
             +--------------------------------+
             | 반복: 입력•가중치 타일       |
             | 3. DMA•이중 버퍼 공급        |
             | 4. 타일 파이프라인 연산       |
             +--------------------------------+
                             |
                    [결과 기록•완료 통지]
```

### 동작 원리

1. **연산·데이터 흐름 매핑**: AI 알고리즘 분석 및 온칩 **BRAM** 및 **DSP 슬라이스** 배치 결정.
2. **비트스트림 검증·구성**: **구성 제어기**를 통한 서명 검증 및 FPGA 하드웨어 갱신.
3. **타일 DMA·이중 버퍼 공급**: **이중 버퍼링** 구조 기반 연산 수행과 동시에 **DMA** 데이터 파이프라이닝.
4. **공간 파이프라인 연산**: **LUT/DSP** 파이프라인을 통해 연속 데이터 타일의 MAC 연산 및 결과 반환.

#### 한줄 요약

- 비트스트림으로 연산 경로를 구성한 뒤 DMA와 이중 버퍼가 타일을 끊김 없이 공급하면 공간 파이프라인이 여러 입력을 겹쳐 처리한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **배치 처리량(Batch Throughput)**: 다수의 입력을 묶어 처리할 때 단위 시간당 처리 가능한 데이터 개수.
- **타이밍 클로저(Timing Closure)**: 합성 및 배치·배선 후 최악 지연 경로가 목표 클록 주기를 만족하도록 맞추는 과정.
- **대량 생산(Mass Production)**: 고정된 반도체 칩 설계로 대량의 유닛을 지속 제작하는 상업 생산 형태.

</details>

| AI 가속기 | FPGA | GPU | ASIC |
|:---|:---|:---|:---|
| 적용 기준 | 주기적 모델 변경 및 **지연 상한** 준수 시 | 잦은 소프트웨어 갱신 및 높은 **배치 처리량** 필요 시 | 모델 고정 및 대량 출하 중심 환경 |
| 핵심 특징 | **공간 병렬 파이프라인** 및 재구성 회로 | **GPU** 소프트웨어 스레드 병렬성 | **ASIC** 하드웨어 로직 고정 |
| 한계 | 회로 면적 대비 저속 및 **타이밍 클로저** 어려움 | 높 전력 소모 및 지연시간 가변성 | 초기 개발비(NRE) 유입 및 기능 변경 불가 |

> 요약: 지연 결정성은 FPGA, 처리량은 GPU, 단가/전력은 ASIC 선택.

#### 한줄 요약

- 모델 변경이 주기적이고 지연 변동을 제한해야 하면 FPGA, 변경이 잦고 배치 처리량이 중요하면 GPU, 모델이 고정된 대량 생산이면 ASIC을 선택한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **양자화(Quantization)**: FP32 데이터를 INT8/INT4 등 낮은 정밀도로 변환하여 메모리 및 연산량을 절감하는 기법.
- **부분 재구성(Partial Reconfiguration)**: 시스템 전체 정지 없이 특정 FPGA 로직 구역만 실시간 재설정하는 기술.
- **롤백 이미지(Rollback Image)**: 비트스트림 업데이트 실패 시 이전 정상 구성 상태로 자동 복구하기 위해 보유하는 미러 바이너리.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 로직 최적화 실패로 인한 **타이밍 클로저** 위반 | 파이프라인 레지스터 추가 및 클록 도메인 분리 | 타이밍 마진 확보 및 마이크로아키텍처 회로 안정화 |
| DRAM 인터페이스 대역폭 부족으로 인한 연산 지연 | **양자화** 적용, **BRAM** 텐서 타일링 및 **이중 버퍼링** 구현 | 메모리 바운드 완화 및 온칩 연산 효율성 극대화 |
| 칩 자원(DSP, BRAM, LUT) 제한으로 대형 모델 미탑재 | 시분할 구조 및 핵심 레이어 대상 **부분 재구성** 할당 | 한정된 FPGA 하드웨어 자원 활용도 극대화 |
| 비트스트림 갱신 중 네트워크 끊김 또는 오염 오류 발생 | **롤백 이미지** 저장 및 비트스트림 암호화 서명 검증 | 재구성 실패 시 자동 복구 및 시스템 가용성 유지 |

> 사례: 스마트 팩토리 비전 검사 시스템에 FPGA 기반 **지연 상한** 파이프라인 구축

#### 한줄 요약

- 산업 비전처럼 지연 상한이 중요한 추론은 온칩 버퍼와 이중 버퍼로 데이터 공급 중단을 줄이고 고정 단계 파이프라인의 최악 지연을 검증한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **엄격한 지연 상한(Strict Latency Bound)**: 최악의 워크로드 조건에서도 정해진 한계 시간을 절대로 초과하지 않는 실시간 조건.
- **AI 가속기 선택 기준(AI Accelerator Selection Criteria)**: 알고리즘 변동 주기, 지연 결정성, 개발 예산에 기반한 반도체 선택 체계.

</details>

- **AI 가속기 선택 기준**에 따라 알고리즘 갱신과 **엄격한 지연 상한** 시 **FPGA**, 대규모 병렬처리는 **GPU**, 대량 생산 시 **ASIC** 선정

#### 한줄 요약

- 모델 변경이 주기적이며 지연 변동을 제한해야 하면 FPGA, 변경이 잦으면 GPU, 기능이 고정된 대량 생산이면 ASIC이 적합하다.
