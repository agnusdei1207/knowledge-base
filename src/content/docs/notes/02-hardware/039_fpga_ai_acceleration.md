## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **FPGA(Field-Programmable Gate Array)**: 제조 후에도 비트스트림(Bitstream)을 통해 내부 논리 블록(LUT)과 상호 연결 배선을 하드웨어 수준에서 프로그래밍할 수 있는 반도체.
- **재구성 가능 회로(Reconfigurable Logic)**: 알고리즘 변경 시 소프트웨어 재컴파일 대신 하드웨어 회로망 자체를 재배선하여 맞춤형 데이터 경로를 구성하는 기술.
- **결정론적 지연시간(Deterministic Latency)**: OS 스케줄링 간섭이나 캐시 미스 요동 없이 일정한 클록 사이클 내에 연산을 완료하는 특성.

</details>

- 정의/개념: LUT(Look-Up Table), DSP 블록, 온칩 BRAM을 활용하여 AI 딥러닝 모델에 최적화된 맞춤형 파이프라인 및 데이터 경로를 하드웨어 수준에서 유연하게 재구성(Reconfigurable)하는 가속 아키텍처
- 배경/필요성: ASIC의 긴 개발 기간(NRE 비용)과 GPU의 높은 전력 소모 및 비결정론적 지연시간(Tail Latency)을 극복하고, **빠르게 변화하는 AI 알고리즘의 유연한 수용과 결정론적 초저지연(Sub-ms) 확보**

#### 한줄 요약

- 비트스트림 기반 **하드웨어 재구성(Reconfigurable)과 결정론적 초저지연 AI 추론** 달성

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **공간 병렬 파이프라인(Spatial Parallel Pipeline)**: 시간 분할(Time-Multiplexing) 방식 대신 칩 내부 물리 공간에 연산 단계를 직렬 배치하여 단일 클록마다 새 입력을 처리하는 구조.
- **Initiation Interval(II)**: 파이프라인이 다음 새로운 입력 데이터를 받아들이는 데 필요한 클록 주기 간격 ($\text{II}=1$이 이상적).

</details>

- 하드웨어 **공간 병렬 파이프라인** 구성을 통한 **개시 간격(II=1)** 달성 및 지연시간 편차 없는 결정론적 추론 보장
- 급변하는 딥러닝 모델 구조(CNN, Transformer, RNN)에 맞춰 하드웨어 데이터 경로를 유연하게 갱신하는 **비트스트림(Bitstream)** 재구성
- 외부 DRAM 병목을 최소화하기 위한 온칩 **BRAM / URAM** 기반 타일링 및 가중치/피처맵 집중 재사용

#### 한줄 요약

- **공간 병렬 파이프라인·온칩 BRAM 재사용·비트스트림 동적 재구성(PR)** 지원

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **LUT(Look-Up Table)**: 임의의 부울 논리 함수를 구현하는 SRAM 기반 논리 소자.
- **DSP Slice**: 고속 곱셈기(Multiplier)와 누산기(Accumulator)를 하드와이어드로 내장한 전용 산술 연산 블록.
- **BRAM / URAM**: FPGA 다이 내부에 분산 배치된 수십~수백 MB 용량의 초저지연 온칩 메모리 블록.

</details>

```text
[ FPGA 기반 인공지능 가속기 아키텍처 ]
┌─────────────────────────────────────────────────────────────┐
│ FPGA 칩 내부 물리 리소스                                    │
│                                                             │
│  [ 비트스트림 수신 및 구성 제어기 (ICAP / PCAP) ]            │
│               │ (하드웨어 회로망 재배선)                    │
│               ▼                                             │
│  [ AXI-Stream DMA 컨트롤러 (PCIe Host I/F) ]                │
│               │ (대용량 텐서 데이터 유입)                   │
│               ▼                                             │
│  [ 온칩 BRAM / URAM 분산 버퍼망 (Double Buffering) ]         │
│               │ (가중치 및 피처맵 초광폭 공급)              │
│               ▼                                             │
│  [ LUT / Flip-Flop 제어 로직 + DSP MAC 공간 파이프라인 어레이]│
└─────────────────────────────────────────────────────────────┘
```

선의 의미: 비트스트림 구성 제어기, DMA 스트리밍 I/F, 온칩 BRAM/URAM 버퍼 및 LUT/DSP 연산 파이프라인 간의 FPGA 아키텍처 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 비트스트림 및 구성 제어기 | 외부에서 설계도를 다운받아 칩 내부의 논리 배선과 **디에스피 슬라이스**의 동작 모드를 찰흙처럼 재구성 |
| 직접 메모리 접근 및 인터페이스 | 중앙처리장치 개입 없이 외부 호스트 메모리에서 방대한 텐서 데이터를 초고속 스트리밍으로 칩 내부로 직접 펌핑 |
| 블록 램 및 온칩 버퍼 | 인공지능 신경망의 무거운 가중치, 특징 맵, 계산 중간 찌꺼기들을 연산기 바로 옆에 임시로 꽉꽉 눌러 담음 |
| 룩업 테이블, 플립플롭, 디에스피 슬라이스 | 재구성된 제어 논리를 바탕으로, 끝없이 밀려오는 **곱셈 누산 연산**을 컨베이어 벨트 위에서 병렬로 무자비하게 쳐냄 |

#### 한줄 요약

- **구성 제어기(비트스트림)·DMA 스트리머·BRAM/URAM 버퍼·DSP MAC 파이프라인**

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **HLS(High-Level Synthesis)**: C/C++ 또는 PyTorch 모델 코드를 하드웨어 기술 언어(Verilog/VHDL) 및 RTL 회로로 자동 변환해 주는 설계 자동화 도구.

</details>

```text
[ AI 모델 개발부터 FPGA 하드웨어 실행 흐름 ]
                      │
                      ▼
[ 1. AI 모델 양자화(INT8) 및 HLS 기반 공간 파이프라인 C++ 설계 ]
                      │
                      ▼
[ 2. 비트스트림 합성/배치배선(P&R) 및 FPGA 플래시 프로그래밍 ]
                      │
                      ▼
[ 3. 호스트 PCIe DMA를 통한 온칩 BRAM 이중 버퍼링 데이터 공급 ]
                      │
                      ▼
[ 4. DSP MAC 어레이 공간 파이프라인 연산 실행 및 II=1 결과 출력 ]
```

**동작 원리**

1. **HLS 설계**: C/C++ 기반으로 레이어별 최적 파이프라인 지시어(`#pragma HLS pipeline II=1`)를 적용하여 회로 합성
2. **비트스트림 주입**: 생성된 비트스트림을 FPGA 구성 메모리에 로드하여 전용 AI 추론 엔진 구축
3. **이중 버퍼링**: DMA 엔진이 A 버퍼에서 연산하는 동안 B 버퍼에 다음 타일 데이터를 백그라운드 프리페치
4. **파이프라인 실행**: 클록 사이클마다 지연 없이 행렬 곱셈을 누산하고 즉시 최종 텐서 결과 반환

#### 한줄 요약

- 모델 분석 및 HLS 합성 $\to$ **비트스트림 주입 $\to$ DMA 이중 버퍼링 $\to$ 공간 파이프라인 실행**

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **FPGA vs GPU vs ASIC**:
  - FPGA: 공간 재구성, 서브 밀리초 결정론적 지연, 우수한 전력 효율
  - GPU: 소프트웨어 SIMT, 대규모 배치 처리량(Throughput), 고전력
  - ASIC: 고정 논리 회로, 최고 전력 효율, 최고 개발비(NRE), 수정 불가

</details>

| 비교 항목 | FPGA 가속기 | GPU 가속기 | ASIC / NPU 가속기 |
|:---|:---|:---|:---|
| 아키텍처 및 유연성 | 공간적 하드웨어 재구성 (LUT/DSP 맞춤 회로) | 시간적 SIMT/SIMD 소프트웨어 스레드 병렬 실행 | 하드와이어드 전용 고정 논리 회로 (재구성 불가) |
| 지연 결정론 및 효율 | 결정론적 초저지연(Sub-ms), 우수한 전력 효율 | 높은 배치 처리량(Throughput), 높은 전력 소모 | 최고 수준의 에너지 효율(TOPS/W) 및 면적 최적화 |
| 한계 및 개발 비용 | 회로 배치/배선(P&R) 난제, 상대적 낮은 클록 주파수 | 스케줄링 오버헤드로 인한 꼬리 지연시간 변동성 | 막대한 초기 개발 비용(NRE) 및 알고리즘 변경 불가 |

#### 한줄 요약

- FPGA는 **재구성 유연성과 초저지연(에지/통신)**, GPU는 **대규모 처리량**, ASIC은 **대량 양산 효율**

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Dynamic Partial Reconfiguration(DPR)**: FPGA 전체 시스템을 리셋하지 않고 특정 연산 영역의 비트스트림만 런타임에 동적으로 교체하는 고급 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 로직 최적화 실패로 전기 신호가 제때 도착하지 못하는 **타이밍 클로저** 위반 및 칩 먹통 사태 | 중간중간 파이프라인 레지스터를 징검다리처럼 추가하고 클록 도메인을 논리적으로 완전히 분리 독립 | 넉넉한 전기적 타이밍 마진 확보 및 마이크로아키텍처 회로의 흔들림 없는 작동 안정화 |
| 바깥 동적 메모리의 허접한 대역폭 때문에 연산기가 밥을 못 먹고 놀고먹는 치명적 지연 병목 | 텐서 데이터 **양자화**로 다이어트, 버퍼 타일링 쪼개기 및 핑퐁 **이중 버퍼링** 하드웨어 무한 가동 | 느린 외부 메모리 바운드의 족쇄 완화 및 온칩 연산기의 곱셈 효율 100% 한계 돌파 |
| 코딱지만 한 칩 내부 자원 한계로 덩치가 산만 한 최신 딥러닝 대형 모델이 안 들어가는 참사 | 레이어별로 시간을 쪼개 쓰는 시분할 구조 채택 및 핵심 구역 대상 동적 **부분 재구성** 꼼수 할당 | 비싼 큰 칩을 안 사고도 한정된 하드웨어 자원을 영혼까지 쥐어짜 내어 대형 모델 억지 수용 |
| 공장에 설치된 칩을 원격 업데이트하다가 인터넷이 끊기거나 해커가 오염된 파일로 칩을 부수려는 위협 | 검증된 구버전 **롤백 이미지** 탑재 강제화 및 업데이트 파일의 비트스트림 암호화 서명 철저 검증 | 재구성 폭파 실패 시 불사조처럼 자동 복구 발동 및 무인 공장 시스템 가용성 24시간 완벽 유지 |

#### 한줄 요약

- **양자화(INT8/INT4)·더블 버퍼링·부분 재구성(Partial Reconfig)·비트스트림 서명**

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **Adaptive SoC (Xilinx Versal)**: 스칼라 CPU, DSP 엔진, AI 엔진 어레이(AIE) 및 프로그래머블 로직(PL)을 이종 결합한 최신 적응형 가속 컴퓨팅 플랫폼.

</details>

- 통신 인프라(vRAN/O-RAN), 자율주행, 금융 초단타 매매 등 **알고리즘 적응성과 결정론적 지연시간이 공존하는 영역에서 FPGA 가속 표준 채택**

#### 한줄 요약

- **알고리즘 변화 주기와 지연 결정론(Determinism)**에 기반한 FPGA 가속기 선정
