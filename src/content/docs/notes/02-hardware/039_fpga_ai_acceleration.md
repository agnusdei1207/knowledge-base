## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **필드 프로그래머블 게이트 배열(Field-Programmable Gate Array, FPGA)**: 제조 후에도 논리 기능과 내부 배선을 다시 구성할 수 있는 반도체이다.
- **재구성 회로(Reconfigurable Circuit)**: 설정 데이터를 바꾸어 동일한 하드웨어 자원을 다른 연산 구조로 재편할 수 있는 회로이다.
- **지연 상한(Latency Bound)**: 입력부터 결과까지 걸리는 시간이 넘지 않아야 하는 최대 허용 한계이다.
- **인공지능(Artificial Intelligence, AI)**: 학습 모델 기반 지능형 처리 기술이다.
- **주문형 반도체(Application-Specific Integrated Circuit, ASIC)**: 기능이 고정된 전용 반도체이다.
- **그래픽 처리 장치(Graphics Processing Unit, GPU)**: 프로그램식 병렬 처리 장치이다.

</details>

- 정의/개념: AI 모델의 연산·데이터 흐름을 제조 후 다시 구성할 수 있는 논리 자원에 매핑하는 **하드웨어 가속 방식**이다.
- 배경/필요성: ASIC은 기능 변경이 어렵고 GPU는 공유 자원과 프로그램 실행으로 지연 변동이 있어 **변경 가능·예측 가능한 파이프라인을 필요로 한다**.

#### 한줄 요약

- FPGA는 모델 변경 시 회로를 다시 구성하고 공간 파이프라인의 단계와 데이터 공급을 고정해 추론 지연 변동을 줄인다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **공간 병렬 파이프라인(Spatial Parallel Pipeline)**: 연산 단계를 물리적으로 나눈 회로에 배치해 여러 입력을 겹쳐 처리하는 구조이다.
- **개시 간격(Initiation Interval, II)**: 파이프라인이 연속된 새 입력을 받아들이는 사이의 클록 간격이다.
- **비트스트림(Bitstream)**: FPGA의 논리 기능과 배선 연결 및 메모리 구성을 담은 설정 파일이다.
- **온칩 메모리 재사용(On-chip Memory Reuse)**: 외부 전송을 반복하지 않도록 데이터를 칩 내부 메모리에 유지하며 여러 연산에 사용하는 방식이다.

</details>

- 일정한 지연•처리율을 확보하는 **공간 병렬 파이프라인•II**가 핵심이다.
- 모델 변경에 회로를 재매핑하는 **비트스트림 재구성**이 핵심이다.
- 외부 전송량을 줄이는 **온칩 메모리 재사용**이 핵심이다.

#### 한줄 요약

- 공간 파이프라인은 단계마다 연산을 겹쳐 실행하며, 개시 간격이 작을수록 새 입력을 더 자주 받아 처리량을 높인다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **룩업 테이블(Look-Up Table, LUT)**: 진리표를 저장하여 사용자 정의 조합 논리를 구현하는 필드 프로그래머블 게이트 배열(Field-Programmable Gate Array, FPGA)의 기본 블록이다.
- **디지털 신호 처리 슬라이스(Digital Signal Processing Slice, DSP Slice)**: 곱셈과 누산 같은 수치 연산을 전용으로 수행하는 FPGA 블록이다.
- **블록 램•울트라램(Block RAM•UltraRAM, BRAM•URAM)**: 가중치와 특징맵 및 부분합을 저장하는 FPGA의 온칩 메모리 자원이다.
- **직접 메모리 접근(Direct Memory Access, DMA)**: 프로세서가 직접 복사하지 않고 장치와 메모리 사이에서 데이터를 전송하는 방식이다.
- **플립플롭(Flip-Flop, FF)•곱셈 누산(Multiply-Accumulate, MAC)**: 상태를 저장하는 순차 논리와 곱셈 결과를 누적하는 연산이다.

</details>

```text
FPGA AI 가속기
|
+-- [비트스트림•구성 메모리]
+-- [DMA•스트림 인터페이스]
+-- [BRAM•URAM 버퍼]
`-- [LUT•FF•DSP 파이프라인]
```

선의 의미: 네 구성요소가 같은 FPGA 가속기 경계에 포함되어 설정•전송•저장•연산 책임을 나누는 정적 구조다.

| 구성요소 | 책임 |
|:---|:---|
| 비트스트림•구성 메모리 | 논리•배선•**DSP 모드 설정** |
| DMA•스트림 인터페이스 | 외부•가속기 **데이터 전송** |
| BRAM•URAM 버퍼 | 타일•부분합 **온칩 보관** |
| LUT•FF•DSP 파이프라인 | 제어•MAC **병렬 실행** |

#### 한줄 요약

- 비트스트림이 전송•버퍼•연산 회로를 구성해 모델별 파이프라인을 만든다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **구성 제어기(Configuration Controller)**: 비트스트림을 검증하고 적재하여 필드 프로그래머블 게이트 배열(Field-Programmable Gate Array, FPGA) 자원의 동작을 설정하는 회로이다.
- **타일(Tile)**: 큰 텐서를 온칩 메모리 용량과 연산기 크기에 맞게 나눈 데이터 블록이다.
- **이중 버퍼(Double Buffering)**: 한 버퍼로 연산하는 동안 다른 버퍼에 다음 데이터를 전송해 계산과 이동을 겹치는 기법이다.
- **직접 메모리 접근(Direct Memory Access, DMA)•블록 램(Block RAM, BRAM)•울트라램(UltraRAM, URAM)**: 타일을 전송하고 온칩에 저장하는 데이터 경로와 메모리 자원이다.
- **룩업 테이블(Look-Up Table, LUT)•플립플롭(Flip-Flop, FF)•디지털 신호 처리(Digital Signal Processing, DSP)**: 제어와 파이프라인 및 수치 연산을 구현하는 FPGA 자원이다.

</details>

```text
                    [AI 모델•지연 상한]
                             |
                1. 연산•데이터 흐름 매핑
                             |
                  2. 비트스트림 검증•구성
                             |
                [LUT•FF•DSP 공간 파이프라인]
                             |
             +--------------------------------+
             | 반복: 입력•가중치 타일       |
             | 3. DMA•이중 버퍼 공급        |
             | 4. 타일 파이프라인 연산       |
             +--------------------------------+
                             |
                    [결과 기록•완료 통지]
```

**동작 원리**

1. **연산·데이터 흐름 매핑**: 모델 연산을 LUT·DSP에 배치하고 온칩 메모리 크기와 파이프라인 단계를 결정한다.
2. **비트스트림 검증·구성**: 서명과 대상 장치를 확인한 뒤 논리·배선·메모리·스트림 경로를 설정한다.
3. **타일 DMA·이중 버퍼 공급**: 현재 타일을 연산하는 동안 다음 입력·가중치 타일을 다른 버퍼에 전송한다.
4. **공간 파이프라인 연산**: 구성된 단계가 타일 연산을 겹쳐 실행하고 결과를 외부 메모리에 기록한다.

#### 한줄 요약

- 비트스트림으로 연산 경로를 구성한 뒤 DMA와 이중 버퍼가 타일을 끊김 없이 공급하면 공간 파이프라인이 여러 입력을 겹쳐 처리한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **그래픽 처리 장치(Graphics Processing Unit, GPU)**: 프로그램 가능한 다수의 코어로 대규모 병렬 연산을 수행하는 프로세서이다.
- **주문형 반도체(Application-Specific Integrated Circuit, ASIC)**: 특정 기능과 데이터 경로를 제조 시점에 고정하여 구현한 전용 반도체이다.
- **배치 처리량(Batch Throughput)**: 여러 입력을 묶어 처리할 때 단위 시간당 완료하는 입력의 수이다.

</details>

| AI 가속기 | FPGA | GPU | ASIC |
|:---|:---|:---|:---|
| 적용 기준 | 주기적 변경•**엄격한 지연 상한** | 잦은 변경•**대규모 배치** | 안정된 모델•**대량 생산** |
| 핵심 특징 | 재구성 **공간 파이프라인** | 프로그램식 **병렬 코어** | 고정 **전용 회로** |
| 한계 | 자원•대역폭•**타이밍 클로저** | 전력•메모리•**지연 변동** | 개발비•제조 기간•**기능 고정** |

> 요약: 변경 주기•지연 상한•물량으로 가속기를 선택한다.

#### 한줄 요약

- 모델 변경이 주기적이고 지연 변동을 제한해야 하면 FPGA, 변경이 잦고 배치 처리량이 중요하면 GPU, 모델이 고정된 대량 생산이면 ASIC을 선택한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **타이밍 클로저(Timing Closure)**: 합성•배치•배선 후 모든 신호 경로가 목표 클록 주기를 만족하는 상태이다.
- **양자화(Quantization)**: 가중치와 활성값의 수치 비트 수를 줄여 연산량과 메모리 사용량을 낮추는 변환한다.
- **부분 재구성(Partial Reconfiguration)**: FPGA 전체를 정지하지 않고 지정한 일부 영역의 회로 구성만 교체하는 기능이다.
- **롤백 이미지(Rollback Image)**: 새 비트스트림의 검증이나 기동에 실패했을 때 복구할 수 있도록 보관한 정상 구성이다.
- **룩업 테이블(Look-Up Table, LUT)•디지털 신호 처리(Digital Signal Processing, DSP)•블록 램(Block RAM, BRAM)**: 논리•수치 연산•온칩 저장을 담당하는 FPGA 자원이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 배치·배선 후 최장 신호 경로가 목표 주기를 넘어 **클록 타이밍 위반** | **파이프라인 단계 추가**와 제약·최악 경로 검증 | 조합 경로 단축으로 **타이밍 클로저 확보** |
| 외부 메모리 전송이 늦어 연산 단계에 **데이터 공급 중단** | **타일링·이중 버퍼**로 연산과 다음 타일 전송 중첩 | 유휴 주기 감소로 **파이프라인 가동률 향상** |
| 모델 매핑이 사용 가능한 LUT·DSP·BRAM **자원 용량 초과** | **양자화·연산 자원 공유**와 정확도·자원 탐색 | 자원 사용량을 한도 안으로 줄여 **구현 가능성 확보** |
| 변조·오류 비트스트림 또는 재구성 실패로 **서비스 중단** | 서명 검증과 **롤백 이미지·부분 재구성** 적용 | 정상 구성 복구와 영향 범위 제한으로 **무결성·가용성 향상** |

> 양자화•공간 파이프라인으로 **추론 지연 상한** 준수

#### 한줄 요약

- 산업 비전처럼 지연 상한이 중요한 추론은 온칩 버퍼와 이중 버퍼로 데이터 공급 중단을 줄이고 고정 단계 파이프라인의 최악 지연을 검증한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **모델 변경 주기(Model Change Cycle)**: 배포한 인공지능 모델의 구조나 연산 요구를 갱신하는 시간 간격이다.
- **엄격한 지연 상한(Strict Latency Bound)**: 최악 조건에서도 응답 시간이 정해진 제한을 초과하지 않아야 하는 요구사항이다.
- **고정 대량 생산(Fixed High-volume Production)**: 기능 변경이 드물고 동일한 설계를 많은 수량으로 제조하는 생산 조건이다.

</details>

- 주기 변경은 **FPGA**, 잦은 변경은 **GPU**, 고정 대량은 ASIC을 선택한다.

#### 한줄 요약

- 모델 변경이 주기적이며 지연 변동을 제한해야 하면 FPGA, 변경이 잦으면 GPU, 기능이 고정된 대량 생산이면 ASIC이 적합하다.
