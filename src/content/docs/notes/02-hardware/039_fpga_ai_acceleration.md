## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **FPGA(Field-Programmable Gate Array)**: 제조 후에도 비트스트림(Bitstream) 다운로드를 통해 내부 논리 블록(CLB)과 라우팅 연결망을 소프트웨어적으로 자유롭게 재구성할 수 있는 프로그래머블 반도체.
- **비트스트림(Bitstream)**: FPGA의 내부 SRAM 구성 셀에 적재되어 논리 게이트, 배선 스위치, I/O 핀의 연결 상태를 결정하는 바이너리 하드웨어 설정 파일.

</details>

- 정의/개념: 딥러닝 신경망 모델에 최적화된 연산 파이프라인과 커스텀 데이터 경로를 비트스트림으로 프로그래밍하여 실시간 추론을 가속하는 **프로그래머블 반도체 아키텍처**
- 배경/필요성: 고정형 ASIC의 고비용 재설계 한계와 GPU의 대규모 배치 대기에 따른 가변 지연(Non-deterministic Latency) 극복 및 단일 배치 실시간 결정론적 추론 실현

#### 한줄 요약
- FPGA는 하드웨어 회로를 재구성하여 신경망 모델별 맞춤형 파이프라인과 결정적 초저지연을 실현하는 AI 가속기이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **고수준 합성(High-Level Synthesis, HLS)**: C/C++ 또는 OpenCL과 같은 고수준 언어 코드를 하드웨어 기술 언어(Verilog/VHDL RTL)로 자동 변환하는 반도체 설계 도구 기술.
- **결정론적 지연시간(Deterministic Latency)**: OS 문맥 전환이나 캐시 미스에 따른 편차 없이 하드웨어 파이프라인 클록에 따라 100% 일정하게 보장되는 I/O 응답 시간.

</details>

- 칩 제조 후에도 비트스트림 재적재를 통해 신경망 구조별 전용 하드웨어 파이프라인으로 즉각 전환 가능한 **하드웨어 재구성 유연성** 제공
- 표준 부동소수점 외에 **FP8, INT4, 바이너리(BNN)** 등 비표준 임의 정밀도 양자화 연산기를 유연하게 구성하여 면적 및 전력 효율 극대화
- 복잡한 OS 스케줄링 및 명령어 디코딩 오버헤드 없이 스트리밍 파이프라인을 구동하여 단일 배치(Batch=1) 환경의 **결정론적 초저지연(Deterministic Low-Latency)** 보장

#### 한줄 요약
- 회로 재구성 유연성과 비표준 비트폭 지원을 통해 지연시간 변동 없는 결정론적 실시간 AI 추론을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **프로그래머블 논리 블록(Configurable Logic Block, CLB)**: 룩업 테이블(LUT)과 플립플롭(FF), 멀티플렉서로 구성되어 임의의 조합 논리와 순차 논리를 구현하는 FPGA의 기본 단위.
- **DSP 슬라이스(DSP Slice)**: 고속 곱셈-누산(MAC) 연산을 전담하도록 실리콘에 하드웨어로 미리 내장된 연산 블록.

</details>

```text
+-------------------------------------------------------------+
|                 FPGA AI 가속 칩 내부 아키텍처                |
|  +-------------------------------------------------------+  |
|  |           프로그래머블 논리 블록 어레이 (CLB Array)   |  |
|  |   [ LUT: 임의 비트폭 활성화 ]  [ FF: 파이프라인 래치 ] |  |
|  +-------------------------------------------------------+  |
|                              ^                              |
|                              | 프로그래머블 스위치 매트릭스 |
|                              v                              |
|  +-------------------------------------------------------+  |
|  |               하드와이어드 DSP 슬라이스 어레이        |  |
|  |          (초고속 INT8 / FP16 곱셈-누산기, MAC)        |  |
|  +-------------------------------------------------------+  |
|                              ^                              |
|                              | 전용 로컬 인터커넥트         |
|                              v                              |
|  +-------------------------------------------------------+  |
|  |     온칩 초저지연 분산 메모리 (BRAM / UltraRAM 텐서 버퍼) |  |
|  +-------------------------------------------------------+  |
|  +-------------------------------------------------------+  |
|  | 외부 인터페이스: PCIe Gen5 / CXL 컨트롤러 & HBM 인터페이스|  |
|  +-------------------------------------------------------+  |
+-------------------------------------------------------------+
```

선의 의미: 실선 화살표는 스위치 매트릭스를 통해 프로그래머블 논리 블록(CLB), 전용 DSP 슬라이스, 온칩 BRAM 메모리 간에 형성되는 맞춤형 AI 데이터패스 경로를 나타냄

| 구성요소 | 책임 |
|:---|:---|
| CLB (LUT + 플립플롭) | 임의 정밀도 양자화 활성화 함수 및 **파이프라인 제어 회로 구성** |
| DSP 슬라이스 | 딥러닝 핵심 행렬 곱셈을 위한 **초고속 병렬 곱셈 누산(MAC) 연산 전담** |
| BRAM / UltraRAM | 외부 메모리 접근 지연을 제거하는 **초고속 온칩 가중치 및 활성화 텐서 버퍼** |
| 스위치 매트릭스 | SRAM 기반으로 각 기능 블록 간의 **커스텀 스트리밍 연결망 동적 구성** |

#### 한줄 요약
- FPGA는 CLB, DSP 슬라이스, BRAM 온칩 메모리 및 프로그래머블 스위치 매트릭스가 고정 I/O IP와 결합된 구조이다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **양자화 및 프루닝(Quantization & Pruning)**: 신경망 파라미터의 비트 수를 줄이고 불필요한 가중치를 제거하여 하드웨어 자원 점유율을 줄이는 경량화 기법.

</details>

```text
+-------------------------------------------------------------+
|        신경망 모델 정의 및 양자화(INT8/FP8)·프루닝 경량화   |
+-------------------------------------------------------------+
                               |
                               v
+-------------------------------------------------------------+
|       1. HLS/RTL 기반 맞춤형 데이터패스 파이프라인 기술     |
+-------------------------------------------------------------+
                               |
                               v
+-------------------------------------------------------------+
|       2. EDA 도구를 통한 논리 합성 및 P&R 물리 배치·배선     |
+-------------------------------------------------------------+
                               |
                               v
               +-------------------------------+
               |     3. 정적 타이밍 분석(STA)  |
               +-------------------------------+
                      |                 |
             [주파수 타이밍 미달]       | [타이밍 클로저 달성]
                      |                 v
                      | +-------------------------------+
                      | | 4. 바이너리 비트스트림 생성   |
                      | +-------------------------------+
                      |                 |
                      |                 v
                      | +-------------------------------+
                      | | 5. FPGA SRAM 구성 셀 적재 및  |
                      | |    실시간 결정론적 추론 실행  |
                      | +-------------------------------+
                      v                 |
+-----------------------+               |
| 파이프라인 레지스터 추가|              |
| 및 플로어플래닝 재튜닝|               |
+-----------------------+               |
                      |                 |
                      +--------+--------+
                               v
+-------------------------------------------------------------+
|            실시간 결정론적 AI 스트리밍 추론 완료             |
+-------------------------------------------------------------+
```

분기 결과: **정적 타이밍 분석(STA) 달성** 시 즉시 비트스트림을 생성하여 하드웨어를 재구성하나, **타이밍 위반** 시 파이프라인 레지스터 삽입 및 플로어플래닝을 조정하여 클록 주파수를 최적화함

**동작 원리**

1. **맞춤형 파이프라인 설계**: C/C++ 기반 고수준 합성(HLS) 또는 Verilog RTL을 통해 AI 신경망 레이어 구조에 1:1 대응하는 완전 파이프라인 데이터패스 코딩
2. **논리 합성 및 P&R 최적화**: EDA 합성 툴이 RTL 코드를 FPGA 기본 단위인 LUT, FF, DSP 블록으로 매핑하고 칩 다이 상에 최적 배치 및 배선 수행
3. **정적 타이밍 분석(STA)**: 배선 지연을 포함한 신호 경로를 검증하여 목표 클록 주파수(수백 MHz)에서의 셋업/홀드 타임 위반 여부 판별
4. **비트스트림 바이너리 생성**: 물리 설계 검증이 완료된 네트리스트를 FPGA 구성 메모리(SRAM Cell)에 기록될 직렬 비트스트림 파일로 변환
5. **온칩 재구성 및 스트리밍 추론**: 생성된 비트스트림을 FPGA로 다운로드하여 하드웨어 스위치 매트릭스를 물리 연결한 후 단일 배치 입력에 대해 결정론적 초저지연 스트리밍 추론 개시

#### 한줄 요약
- 신경망 모델을 HLS/RTL로 기술하고 논리 합성과 타이밍 클로저를 거쳐 생성된 비트스트림을 적재함으로써 전용 하드웨어 스트리밍 추론을 수행한다.

## Ⅴ. 종류 및 비교

| AI 가속기 플랫폼 | FPGA (Field-Programmable) | GPU (General Purpose GPU) | ASIC (Application-Specific) | 범용 CPU (General CPU) |
|:---|:---|:---|:---|:---|
| 적용 기준 | 알고리즘 변동 대응 및 배치=1 결정론적 초저지연 요구 시 | 초대규모 모델 병렬 학습 및 배치 단위 고대역폭 처리 환경 | 알고리즘 고정 초대규모 양산 및 최고 전력 효율 추구 시 | 복잡한 제어 흐름 및 비정형 비즈니스 로직 처리 환경 |
| 핵심 특징 | **비트스트림 회로 재구성** 및 맞춤형 임의 비트폭 파이프라인 | 수천 개 SIMT 코어 기반 **소프트웨어 커널 대규모 병렬 연산** | 목표 알고리즘에만 특화된 물리 회로로 **최고 연산 밀도 달성** | 다계층 캐시와 분기 예측 기반 **범용 명령어 순차 처리** |
| 한계 | 프로그래머블 배선 오버헤드로 인한 **동작 클록 주파수 한계** | 배치 큐잉에 따른 **가변 지연** 및 고주파 구동 전력 소모 | 회로 완전 고정으로 **변경 불가** 및 초기 NRE 비용 천문학적 | 순차 처리 구조로 인한 **대규모 텐서 병렬 연산 처리량 한계** |

#### 한줄 요약
- 결정론적 초저지연과 회로 재구성이 필수적인 엣지/특수 통신에는 FPGA가, 초대규모 AI 학습에는 GPU가, 고정 양산에는 ASIC이 최적이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **타이밍 클로저(Timing Closure)**: FPGA 내부 신호 지연이 목표 클록 주파수 조건을 만족하도록 배치와 배선을 최적화하는 과정.
- **부분 재구성(Partial Reconfiguration, PR)**: 시스템 가동 중에 FPGA의 특정 영역만 실시간으로 회로를 동적 교체하는 고급 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 대규모 신경망 수용 시 온칩 BRAM/UltraRAM 용량 한계 | 외부 **HBM 직결 패키징** 및 텐서 타일링 기법 적용 | 테라바이트급 메모리 대역폭 확보 및 온칩 메모리 병목 극복 |
| 복잡한 라우팅 혼잡으로 인한 목표 주파수 타이밍 클로저 실패 | **파이프라인 레지스터 분할** 및 물리적 플로어플래닝 격리 | 동작 주파수 500MHz 이상 확보 및 타이밍 수렴 |
| AI 모델 업데이트 시 시스템 재부팅 및 칩 전체 재구성 지연 | **동적 부분 재구성(PR)** 기술 적용 | 가동 중단 없는 실시간 타깃 신경망 모듈 핫스왑 지원 |

#### 한줄 요약
- 실무에서는 HBM 연동으로 온칩 용량을 극복하고, 플로어플래닝으로 타이밍을 수렴하며, 부분 재구성(PR)으로 무중단 모델 변경을 지원한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **적응형 컴퓨팅 가속 플랫폼(ACAP)**: 스칼라 코어, 적응형 하드웨어(FPGA), 지능형 AI 엔진을 단일 다이에 융합한 차세대 이종 가속 아키텍처.
- **eFPGA(Embedded FPGA)**: SoC/ASIC 다이 내부에 프로그래머블 논리 블록을 IP 코어 형태로 내장하여 사후 알고리즘 변경을 지원하는 기술.

</details>

하드웨어 수준의 재구성 유연성과 결정론적 초저지연을 결합하여 통신, 방산, 자율주행 엣지 추론을 주도하는 반도체 기술이며, 향후 ACAP 및 eFPGA를 통한 이종 SoC 결합으로의 진화.

#### 한줄 요약
- FPGA는 하드웨어 수준의 재구성 유연성과 결정론적 초저지연을 결합하여 자율주행과 금융 등 특수 AI 가속 분야의 표준으로 자리 잡았다.
