## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **FPGA(Field-Programmable Gate Array)**: 제조 후 비트스트림을 다운로드하여 논리 회로와 연결을 자유롭게 재구성할 수 있는 반도체 소자.
- **비트스트림(Bitstream)**: FPGA의 내부 SRAM에 적재되어 하드웨어 회로망을 형성하는 설정 바이너리 파일.

</details>

- 정의/개념: 비트스트림을 다운로드하여 **LUT와 DSP 블록**을 재구성함으로써 신경망 추론 파이프라인을 최적화하는 반도체 구조
- 배경/필요성: 빠른 AI 알고리즘 변화 대비 ASIC 개발 비용 부담 및 GPU의 높은 **소비 전력·지연 변동** 발생

#### 한줄 요약
- 회로 자체를 프로그램하듯 바꿀 수 있어, 최신 AI 알고리즘에 맞춘 전용 가속 회로를 즉시 만들 수 있다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **HLS(High-Level Synthesis)**: C/C++ 같은 고수준 프로그래밍 언어를 하드웨어 기술 언어(Verilog/VHDL)로 자동 변환하는 합성 기술.
- **결정적 지연(Deterministic Latency)**: 캐시 미스나 스케줄링 변동 없이 하드웨어 파이프라인에 따라 일정하게 보장되는 응답 시간.

</details>

- **재구성 가능성(Reconfigurability)**으로 비트스트림 기반 회로 변경 지원
- **커스텀 데이터 타입(FP8/INT4)** 및 맞춤형 연산기 직접 구현
- 파이프라인 병렬성 기반 결정적 저지연(Deterministic Latency) 실현

#### 한줄 요약
- 비트 단위로 원하는 크기의 계산기를 만들고 파이프라인으로 연결해 일정한 초저지연 성능을 낸다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **CLB(Configurable Logic Block)**: LUT와 플립플롭으로 구성되어 임의의 조합 논리와 순차 논리를 구현하는 기본 단위.
- **DSP 슬라이스**: 고속 곱셈 및 누산(MAC)을 전담하도록 하드웨어로 미리 내장된 연산 블록.

</details>

```text
┌─────────────────────────────────────────────────────────────┐
│ FPGA 칩 내부 아키텍처                                       │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐       │
│  │ 논리 블록(CLB)│  │ DSP 슬라이스 │  │ 온칩 램(BRAM)│       │
│  │ (LUT + FF)   │  │ (고속 MAC)   │  │ (가중치 버퍼)│       │
│  └──────┬───────┘  └──────┬───────┘  └──────┬───────┘       │
│         │                 │                 │               │
│  ═══════╪═════════════════╪═════════════════╪═══════        │
│         │     프로그래머블 스위치 매트릭스  │ (온칩 배선망) │
│  ┌──────┴───────┐  ┌──────┴───────┐  ┌──────┴───────┐       │
│  │ PCIe 컨트롤러│  │ HBM 인터페이스│  │ 고속 SerDes  │       │
│  └──────────────┘  └──────────────┘  └──────────────┘       │
└─────────────────────────────────────────────────────────────┘
```

선의 의미: 스위치 매트릭스를 통해 CLB 논리, DSP 연산기, BRAM 메모리가 AI 파이프라인 형태로 상호 결선

| 구성요소 | 책임 |
|:---|:---|
| 설정 가능 논리 블록 (CLB) | 활성화 함수, 제어 로직 및 임의 비트 폭 연산기 구현 |
| DSP 슬라이스 | 합성곱 및 행렬 곱셈을 위한 고정소수점·부동소수점 고속 MAC 연산 |
| 온칩 블록 램 (BRAM/URAM) | AI 모델 가중치와 활성화 텐서를 연산기 바로 옆에 캐싱 |
| 프로그래머블 인터커넥트 | 연산 유닛 간 점대점 스트리밍 데이터 패스 형성 |
| 고속 I/O 트랜시버 | PCIe 및 네트워크 패킷의 제로 카피 다이렉트 수신 |

#### 한줄 요약
- 논리 블록(CLB), 곱셈기(DSP), 메모리(BRAM)가 촘촘한 스위치망으로 연결되어 맞춤형 회로를 만든다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **양자화(Quantization)**: 32비트 실수를 8비트·4비트 정수로 축소하여 정확도 손실을 최소화하면서 연산량을 줄이는 기법.

</details>

```text
AI 모델 정의 (PyTorch / ONNX)
      │
      ▼
1. AI 모델 가지치기 및 저비트 양자화 (INT8 / INT4)
      │
      ▼
2. 고위 언어 합성 (HLS)을 통한 RTL 회로 생성
      │
      ▼
3. 배치 및 배선 (P&R)과 타이밍 클로저 검증
      │
      ▼
4. 비트스트림 생성 및 FPGA 내부 메모리 적재
      │
      ▼
5. 데이터 스트리밍 및 초저지연 AI 추론 수행
```

**동작 원리**

1. **모델 최적화**: 딥러닝 모델의 가중치를 FPGA 연산에 최적화된 저비트 정수로 양자화
2. **HLS 회로 합성**: C/C++ 기반 HLS 도구로 최적의 파이프라인 하드웨어 기술(RTL) 코드 생성
3. **배치 및 배선**: 칩 내 실제 CLB와 DSP 위치를 지정하고 배선 지연을 맞추는 P&R 수행
4. **비트스트림 적재**: 생성된 바이너리를 FPGA의 SRAM에 다운로드하여 하드웨어 가속기 회로 실체화
5. **실시간 추론**: 네트워크나 PCIe에서 들어오는 데이터를 메모리 경유 없이 스트리밍으로 즉시 계산

#### 한줄 요약
- 모델 양자화 → HLS 회로 생성 → P&R 배치배선 → 비트스트림 적재 → 스트리밍 추론으로 이어진다.

## Ⅴ. 종류 및 비교

| AI 연산 프로세서 | FPGA | GPU | ASIC (TPU/NPU) | CPU |
|:---|:---|:---|:---|:---|
| 적용 기준 | 초저지연 실시간 제어·알고리즘 가변 | 대규모 일괄(Batch) 학습 및 범용 가속 | 대규모 고정 모델 초고효율 양산 | 범용 제어 및 복잡한 분기 처리 |
| 핵심 특징 | 비트스트림 기반 하드웨어 회로 재구성 | 수천 개 코어 기반 대규모 데이터 병렬 | 전용 시스톨릭 어레이 고집적 고효율 | 복잡한 명령어 세트 및 유연한 실행 |
| 한계 | 개발 난이도 높음·상대적 클록 주파수 낮음 | 높은 전력 소모 및 지연시간 변동 | 설계 변경 불가·초기 개발 비용(NRE) 막대 | 병렬 연산 처리 대역폭 한계 |

#### 한줄 요약
- 알고리즘 변경과 저지연은 FPGA, 대규모 학습은 GPU, 대량 생산 고효율은 ASIC을 쓴다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **타이밍 클로저(Timing Closure)**: 칩 내부 신호 전달 시간이 목표 클록 주기 내에 들어오도록 설계를 최적화하는 과정.
- **부분 재구성(Partial Reconfiguration)**: 시스템을 중단하지 않고 FPGA의 일부 영역만 실시간으로 회로를 바꾸는 기능.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 복잡한 AI 모델 수용 시 온칩 BRAM 용량 부족 | 외부 **HBM** 연동 및 텐서 타일링(Tiling) 스트리밍 적용 | 대용량 모델 구동 및 메모리 병목 해소 |
| 라우팅 혼잡으로 인한 **타이밍 클로저** 실패 | 파이프라인 레지스터 추가 및 계층적 배치(Floorplanning) | 목표 클록 주파수 달성 및 안정성 확보 |
| 모델 변경 시 전체 칩 재부팅 지연 | **부분 재구성(Partial Reconfiguration)** 기술 적용 | 무중단 런타임 모델 동적 스위칭 |
| 비트스트림 추출 및 하드웨어 복제 위협 | 비트스트림 AES 암호화 및 하드웨어 서명 검증 | IP 보호 및 펌웨어 위변조 원천 방지 |

#### 한줄 요약
- HBM 연동으로 용량을 늘리고, 계층 배치로 타이밍을 맞추며, 부분 재구성으로 무중단 교체를 실현한다.

## Ⅶ. 결론

- 알고리즘 변경 대응과 초저지연 처리는 **FPGA**, 대규모 병렬 학습은 **GPU** 선택

#### 한줄 요약
- 개발 유연성과 결정적 지연, 전력 효율을 종합 비교해 FPGA 기반 엣지 및 인프라 AI 가속기를 구축해야 한다.
