## 미리 알고가기

- **필드 프로그래머블 게이트 배열(Field-Programmable Gate Array, FPGA)**: 제조 후에도 논리와 배선을 재구성할 수 있는 반도체
- **비트스트림(Bitstream)**: FPGA 논리·배선 구성을 담은 설정 파일
- **룩업 테이블(Look-Up Table, LUT)**: 진리표 기반으로 사용자 정의 조합 논리를 구현하는 FPGA의 기본 블록
- **플립플롭(Flip-Flop, FF)**: 파이프라인과 상태 값을 저장하는 FPGA의 순차 논리 소자
- **디지털 신호 처리(Digital Signal Processing, DSP) 슬라이스**: 곱셈·누산 전용 연산 블록
- **블록 램·울트라램(Block RAM·UltraRAM, BRAM·URAM)**: 가중치·특징맵용 온칩 메모리
- **직접 메모리 접근(Direct Memory Access, DMA)**: 프로세서의 데이터 복사 없이 장치와 메모리 사이에서 직접 전송하는 방식
- **개시 간격(Initiation Interval, II)**: 파이프라인이 연속된 새 입력을 받아들이는 사이의 클록 간격
- **타이밍 클로저(Timing Closure)**: 모든 배치·배선 경로가 목표 클록 주기를 만족한 상태
- **양자화(Quantization)**: 가중치·활성값의 수치 정밀도를 낮추는 변환
- **그래픽 처리장치(Graphics Processing Unit, GPU)**: 프로그램으로 병렬 연산을 수행하는 프로세서
- **주문형 반도체(Application-Specific Integrated Circuit, ASIC)**: 특정 기능으로 고정 제작한 전용 반도체
- **인공지능(Artificial Intelligence, AI)**: 학습한 모델로 분류·예측하며 FPGA가 해당 연산 그래프를 회로로 가속하는 기술
- **파이프라인(Pipeline)**: 연산을 여러 단계로 나눠 서로 다른 입력을 겹쳐 처리하는 회로 구조
- **텐서(Tensor)**: 신경망 입력·가중치·활성값을 다차원 배열로 나타낸 데이터
- **타일(Tile)**: 큰 텐서를 온칩 메모리와 연산기에 맞게 나눈 작은 블록
- **부분합(Partial Sum)**: 행렬 곱의 일부 곱셈 결과를 누적 중인 중간값
- **스트림 인터페이스(Stream Interface)**: 주소를 매번 지정하지 않고 순서대로 이어지는 데이터 흐름을 전달하는 연결
- **합성·배치·배선(Synthesis·Placement·Routing)**: 논리 설명을 회로로 바꾸고 칩 자원 위치와 연결 경로를 정하는 구현 단계
- **연산 그래프(Computation Graph)**: 모델의 연산자와 텐서 의존 관계를 노드·간선으로 나타낸 구조
- **추론(Inference)**: 학습된 모델에 새 입력을 넣어 예측 결과를 계산하는 과정
- **커널(Kernel)**: GPU 같은 가속기에서 여러 코어가 병렬 실행하는 연산 함수
- **배치 처리량(Batch Throughput)**: 여러 입력을 묶어 처리할 때 단위 시간당 완료하는 입력 수
- **산업 비전(Industrial Vision)**: 카메라와 영상 모델로 제품의 위치·치수·결함을 자동 판정하는 시스템
- **구성 제어기(Configuration Controller)**: 비트스트림을 검증·적재해 FPGA의 LUT·배선·메모리·DSP 동작을 설정하는 회로
- **이중 버퍼(Double Buffering)**: 한 버퍼를 연산하는 동안 다른 버퍼에 다음 데이터를 전송해 계산과 이동을 겹치는 기법
- **부분 재구성(Partial Reconfiguration)**: FPGA 전체를 멈추지 않고 지정된 일부 영역의 비트스트림만 교체하는 기능
- **롤백 이미지(Rollback Image)**: 새 비트스트림의 검증·기동에 실패했을 때 되돌아갈 수 있도록 보관한 정상 구성

## Ⅰ. 개요

- 정의/개념: AI 연산을 **재구성 병렬 회로**에 매핑하는 가속 방식
- 기존 한계: 고정 회로는 **모델 변경 대응**, GPU는 지연 예측에 제약

### 쉽게 이해하기 (학습용)

- 제품이 바뀔 때 배선을 다시 짤 수 있는 전용 생산 라인에서 처리하는 것과 같다

## Ⅱ. 특징

- **공간 병렬 파이프라인**으로 일정한 처리 지연 확보
- **비트스트림 재구성**으로 모델 변경에 회로 재매핑
- **온칩 메모리 재사용**으로 외부 전송량 절감

### 쉽게 이해하기 (학습용)

- 여러 작업대를 한 줄에 배치해 각 작업이 동시에 다른 제품을 처리한다

## Ⅲ. 아키텍처 및 구성요소

### 도표안 A. FPGA AI 가속 정적 구조

```mermaid
flowchart LR
    CFG[비트스트림·구성 메모리]
    DMA[DMA·스트림 인터페이스]
    BUF[BRAM·URAM 버퍼]
    PE[LUT·FF·DSP 파이프라인]
    CFG -->|전송 경로 구성| DMA
    CFG -->|버퍼 모드 구성| BUF
    CFG -->|연산 경로 구성| PE
    DMA -->|입력 타일| BUF
    BUF -->|연산 데이터| PE
    PE -->|결과 타일| BUF
    BUF -->|결과 스트림| DMA
```

| 설계 요소 | 입력·상태 | 역할 |
|:---|:---|:---|
| 비트스트림·구성 메모리 | 회로 구성 데이터 | 논리·배선·메모리·DSP 모드 설정 |
| DMA·스트림 인터페이스 | 텐서 주소·스트림 상태 | 외부–가속기 데이터 전송 |
| BRAM·URAM 버퍼 | 입력·가중치·부분합 타일 | 온칩 재사용 데이터 저장 |
| LUT·FF·DSP 파이프라인 | 연산 데이터·II | 제어·곱셈·누산 동시 실행 |

> 요약: 비트스트림이 전송·버퍼·연산 경로를 구성

### 도표안 B. 비트스트림 구성·타일 추론 시퀀스

```mermaid
sequenceDiagram
    participant H as 호스트 런타임
    participant C as 구성 제어기
    participant D as DMA·스트림 인터페이스
    participant M as 외부 메모리
    participant B as BRAM·URAM 버퍼
    participant P as LUT·FF·DSP 파이프라인

    H->>C: ① 서명된 비트스트림 적재 요청
    C->>P: ② 연산·배선·파이프라인 구성
    C->>D: ③ DMA·스트림 경로 구성
    H->>D: ④ 텐서 주소·추론 시작 전달
    loop 입력·가중치 타일
        D->>M: ⑤ 다음 타일 읽기 요청
        M-->>D: ⑥ 타일 데이터 반환
        D->>B: ⑦ 온칩 버퍼에 타일 적재
        B->>P: ⑧ 파이프라인 입력 데이터 공급
        P-->>B: ⑨ 결과·부분합 타일 반환
        B-->>D: ⑩ 결과 스트림 전달
    end
    D->>M: ⑪ 최종 결과 텐서 기록
    D-->>H: ⑫ 추론 완료 통지
```

### 동작 원리

1. **① 서명된 비트스트림 적재 요청**: 호스트 런타임은 대상 모델의 연산 그래프와 정밀도에 맞는 비트스트림을 구성 제어기에 제출한다.
2. **② 연산·배선·파이프라인 구성**: 구성 제어기는 무결성을 확인한 비트스트림으로 LUT·FF·DSP 연결과 연산 파이프라인 단계를 설정한다.
3. **③ DMA·스트림 경로 구성**: 같은 비트스트림은 외부 메모리, 온칩 버퍼와 연산 파이프라인 사이의 전송 폭과 스트림 연결도 설정한다.
4. **④ 텐서 주소·추론 시작 전달**: 호스트는 입력·가중치·출력 텐서 주소와 타일 크기를 DMA에 쓰고 추론을 시작한다.
5. **⑤ 다음 타일 읽기 요청**: DMA는 연산 중인 버퍼와 겹치지 않는 다른 버퍼에 채울 다음 입력·가중치 타일을 외부 메모리에 요청한다.
6. **⑥ 타일 데이터 반환**: 외부 메모리는 요청한 연속 데이터 블록을 DMA 인터페이스에 반환한다.
7. **⑦ 온칩 버퍼에 타일 적재**: DMA는 반환 데이터를 BRAM·URAM에 배치해 외부 왕복 없이 여러 연산에서 재사용하게 한다.
8. **⑧ 파이프라인 입력 데이터 공급**: 온칩 버퍼는 개시 간격에 맞춰 LUT·FF·DSP 파이프라인에 매 클록 필요한 데이터를 공급한다.
9. **⑨ 결과·부분합 타일 반환**: 공간 병렬 파이프라인은 곱셈·누산 결과를 온칩 버퍼에 저장하거나 다음 연산 단계로 넘긴다.
10. **⑩ 결과 스트림 전달**: 완성된 결과 타일은 버퍼에서 DMA의 출력 스트림으로 전달된다.
11. **⑪ 최종 결과 텐서 기록**: DMA는 모든 결과 타일을 외부 메모리의 출력 주소에 기록한다.
12. **⑫ 추론 완료 통지**: 전체 타일 처리가 끝나면 DMA는 호스트 런타임에 완료 상태를 알린다.

### 쉽게 이해하기 (학습용)

- 설계도로 운반대와 작업대, 가까운 부품함의 연결을 바꾼다

## Ⅳ. 종류 및 비교

| AI 가속기 | FPGA | GPU | ASIC |
|:---|:---|:---|:---|
| 적용 기준 | 주기적 변경·**엄격한 지연 상한** | 잦은 변경·**대규모 배치** | 안정된 모델·**대량 생산** |
| 핵심 특징 | 재구성 **공간 파이프라인** | 프로그램식 **병렬 코어** | 고정 **전용 회로** |
| 한계 | 자원·대역폭·**타이밍 클로저** | 전력·메모리·**지연 변동** | 개발비·제조 기간·**기능 고정** |

> 요약: 변경 주기·지연 상한·물량으로 가속기 선택

### 쉽게 이해하기 (학습용)

- FPGA는 설비를 다시 배선하고 GPU는 작업표를 바꾸며 ASIC은 공장을 새로 짓는다

## Ⅴ. 실무 고려사항 및 대응 방안

| 운영 위험 | 대응 | 기대 효과 |
|:---|:---|:---|
| 배치·배선 경로가 목표 클록을 위반 | 파이프라인 단계 추가와 제약·최악 경로 검증 | 타이밍 클로저 확보 |
| 외부 메모리 대역폭이 연산기를 굶김 | 타일링·이중 버퍼와 연산·전송 중첩 | 파이프라인 가동률 향상 |
| LUT·DSP·BRAM 자원 초과 | 양자화·연산 공유와 자원·정확도 탐색 | 구현 가능성 확보 |
| 잘못된 비트스트림·재구성 중 서비스 중단 | 서명 검증·롤백 이미지와 부분 재구성 적용 | 무결성·가용성 향상 |

> 산업 비전은 양자화한 모델을 고정 길이 공간 파이프라인으로 구성해 부품별 추론 지연 상한을 맞춘다.

### 쉽게 이해하기 (학습용)

- 가까운 부품함에서 데이터를 되풀이 공급해 여러 작업대가 쉬지 않고 계산한다.
- 검사 부품이 도착할 때마다 전용 라인이 일정한 시간 안에 판정을 끝낸다

## Ⅵ. 결론

- 재구성 가속을 위해 지연·자원을 검토하여 **FPGA** 활용

### 쉽게 이해하기 (학습용)

- 가끔 바꾸는 전용 라인은 FPGA, 잦으면 GPU, 고정이면 ASIC이다
