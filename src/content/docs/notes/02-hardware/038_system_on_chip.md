## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **시스템온칩(System on Chip, SoC)**: CPU, GPU, 메모리 제어기, 통신 모듈 등 시스템의 모든 핵심 기능을 하나의 반도체 다이에 집적한 칩.
- **IP 블록(Intellectual Property Block)**: 검증을 거쳐 재사용 가능하도록 모듈화된 반도체 기능 회로 블록.

</details>

- 정의/개념: CPU·GPU·메모리 제어기·I/O 등 시스템 전체 구성요소를 **단일 실리콘 다이**에 집적한 초고집적 반도체 아키텍처
- 배경/필요성: 개별 칩 분리 배치 시 발생하는 PCB 배선 지연 및 폼팩터 면적·전력 소모 제약 극복 필요

#### 한줄 요약
- 여러 칩으로 나뉘어 있던 컴퓨터의 핵심 부품들을 손톱만 한 하나의 실리콘 칩 안에 모두 합친 기술이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **네트워크온칩(Network on Chip, NoC)**: 수많은 온칩 IP 블록 간 패킷 통신을 라우터 기반으로 중계하는 온칩 상호 연결망.
- **하드웨어/소프트웨어 통합 설계(HW/SW Co-Design)**: 칩 제작 전 가상 플랫폼에서 소프트웨어와 하드웨어를 동시에 검증하는 개발 기법.

</details>

- **IP 블록 재사용**을 통한 설계 기간 단축 및 검증 신뢰성 확보
- 온칩 인터커넥트(NoC/AMBA) 기반 초고속 저전력 통신 지원
- 면적 절감 및 폼팩터 소형화로 모바일·임베디드 최적화

#### 한줄 요약
- 검증된 부품 블록을 레고처럼 조립해 개발 기간을 줄이고, 칩 내부에서 초고속으로 통신한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **전력 관리 유닛(PMU)**: 각 IP 블록의 동작 상태에 따라 전압과 주파수를 동적으로 조절하는 전력 제어 회로.

</details>

```text
┌─────────────────────────────────────────────────────────────┐
│ 단일 실리콘 다이 (SoC Die)                                  │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐       │
│  │ CPU 코어 클러스터 │  │ GPU / NPU 가속기 │  │ 보안 암호화 엔진 │       │
│  └──────┬───────┘  └──────┬───────┘  └──────┬───────┘       │
│         │                 │                 │               │
│  ═══════╪═════════════════╪═════════════════╪═══════ NoC 버스 │
│         │                 │                 │ (온칩 연결망)  │
│  ┌──────┴───────┐  ┌──────┴───────┐  ┌──────┴───────┐       │
│  │ LPDDR 메모리 제어기 │  │ 디스플레이/카메라 IP│  │ 고속 I/O (PCIe/USB)│  │
│  └──────────────┘  └──────────────┘  └──────────────┘       │
└─────────────────────────────────────────────────────────────┘
```

선의 의미: 중앙의 NoC 버스를 통해 상하단의 다양한 연산, 메모리, I/O IP 블록들이 고속 패킷으로 통신

| 구성요소 | 책임 |
|:---|:---|
| 프로세서 코어 클러스터 | 범용 OS 구동 및 고성능 직렬 제어 연산 수행 |
| 하드웨어 가속기 (NPU/GPU) | AI 딥러닝 추론 및 고성능 그래픽 병렬 연산 전담 |
| 온칩 인터커넥트 (NoC/AMBA) | 다중 IP 블록 간 고대역폭·저지연 패킷 라우팅 및 중재 |
| 메모리 제어기 및 주변장치 IP | 외부 LPDDR DRAM 연동 및 디스플레이·통신 인터페이스 제공 |
| 전력 관리 유닛 (PMU) | DVFS 및 전력 도메인 게이팅을 통한 칩 전체 에너지 최적화 |

#### 한줄 요약
- CPU, AI 가속기, 메모리 컨트롤러, I/O 장치들이 NoC라는 초고속 내부 도로망으로 묶여 있다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **테이프아웃(Tape-Out)**: 칩의 최종 레이아웃 설계 데이터를 파운드리 공장으로 넘겨 생산을 의뢰하는 단계.

</details>

```text
시스템 요구사항 분석
      │
      ▼
1. 시스템 아키텍처 정의 및 핵심 IP 블록 선정
      │
      ▼
2. NoC/AMBA 온칩 버스 설계 및 IP 블록 통합
      │
      ▼
3. HW/SW 통합 시뮬레이션 및 가상 플랫폼 검증
      │
      ▼
4. 물리적 배치/배선 (P&R) 및 테이프아웃
      │
      ▼
5. 단일 실리콘 다이 반도체 공정 제조
```

**동작 원리**

1. **아키텍처 정의 및 IP 선정**: 처리 성능과 전력 목표에 맞춰 CPU, GPU 등 검증된 IP 블록 라이브러리 선택
2. **온칩 버스 통합**: NoC 또는 AMBA 프로토콜을 기반으로 IP 간 대역폭과 주소 공간 매핑 설계
3. **통합 검증**: 가상 플랫폼(Virtual Platform)을 통해 실제 칩 제작 전 소프트웨어와 하드웨어 기능 동시 검증
4. **물리 설계 및 테이프아웃**: 배치 및 배선(P&R), 타이밍 검증을 완료하고 마스크 데이터를 파운드리에 전달
5. **단일 다이 제조**: 첨단 미세 공정을 통해 단일 실리콘 기판 위에 완제품 SoC 칩 생산

#### 한줄 요약
- 부품 IP 선정 → NoC 버스 통합 → 가상 검증 → 물리 설계 후 파운드리에서 한 번에 찍어낸다.

## Ⅴ. 종류 및 비교

| 시스템 집적 구조 | 단일 다이 SoC | SiP (System in Package) | 칩렛 (Chiplet) | 개별 칩 기판 (PCB) |
|:---|:---|:---|:---|:---|
| 적용 기준 | 초소형·초저전력 모바일/스마트폰 | 이종 공정 칩 혼합·단기 출시 필요 | 고성능 대면적 서버/AI 가속기 | 저비용 소량 생산 일반 전자기기 |
| 핵심 특징 | 단일 실리콘에 전 시스템 완전 집적 | 여러 개별 다이를 단일 패키지에 결합 | 기능별 최적 공정 다이를 인터포저로 연결 | 개별 패키지 칩을 PCB 기판에 납땜 |
| 한계 | 다이 면적 증가 시 수율 급감·비용 상승 | 패키징 두께 증가 및 열 방출 분산 필요 | 인터포저 패키징 비용 및 신호 무결성 | 부피 큼·배선 지연 길고 전력 소모 큼 |

#### 한줄 요약
- 최고 집적도는 SoC, 빠른 결합은 SiP, 대규모 고성능은 칩렛, 일반 전자제품은 PCB 구조를 쓴다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **DVFS(Dynamic Voltage and Frequency Scaling)**: 부하에 따라 전압과 클록 주파수를 실시간 조절하는 절전 기법.
- **파워 게이팅(Power Gating)**: 사용하지 않는 IP 블록의 전원을 스위치로 완전히 차단해 누설 전류를 없애는 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 다이 면적 증가로 인한 공정 수율 저하 | 모듈형 설계 및 다이 분할(칩렛 구조 전환) 검토 | 웨이퍼 수율 방어 및 제조 단가 절감 |
| 고밀도 집적에 따른 국소적 핫스팟 및 열 집중 | 칩 내 온도 센서 분산 배치 및 동적 열 쓰로틀링 | 칩 과열 방지 및 동작 수명 연장 |
| 유휴 IP 블록의 대기 전력 및 누설 전류 | **파워 게이팅** 및 다중 전력 도메인 **DVFS** 적용 | 모바일 배터리 지속 시간 극대화 |
| 디지털 고속 클록 노이즈의 아날로그 RF 간섭 | 기판 가드링(Guard Ring) 및 물리적 격리 배치 | 신호 무결성(SI/PI) 확보 및 오동작 방지 |

#### 한줄 요약
- 파워 게이팅으로 전력을 아끼고, 온도 센서로 과열을 막으며, 가드링으로 신호 간섭을 차단한다.

## Ⅶ. 결론

- 초소형·초저전력 시스템은 **단일 다이 SoC**, 대규모 고성능 연산은 **칩렛/SiP** 선택

#### 한줄 요약
- 양산 수율과 전력, 폼팩터 요구사항을 종합 분석해 SoC 집적 수준과 패키징 방식을 결정해야 한다.
