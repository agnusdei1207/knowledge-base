## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **SoC(System on Chip)**: 연산(CPU/GPU/NPU), 메모리 제어, 입출력 통신, 보안 엔진 등 시스템 구동에 필요한 제반 기능을 단일 실리콘 다이에 집적한 반도체.
- **모놀리식 다이(Monolithic Die)**: 하나의 단일 실리콘 웨이퍼 조각 위에 모든 회로를 일체형으로 제조하는 방식.
- **I/O 전력 소모(I/O Power)**: 칩 외부 PCB 구리 배선 및 핀을 구동할 때 소비되는 막대한 기생 커패시턴스 전력.

</details>

- 정의/개념: CPU, GPU, NPU, 메모리 컨트롤러, 보안 엔진, I/O 인터페이스 등 시스템 구동에 필요한 제반 기능 블록(IP)을 단일 실리콘 다이(Single-Die)에 통합 집적한 반도체
- 배경/필요성: 개별 칩 분리 구성 시의 PCB 면적 낭비, 신호 전파 지연 및 **I/O 핀 구동에 따른 과도한 전력 소모(pJ/bit) 절감 및 극단적 소형화 달성**

#### 한줄 요약

- 시스템 전체 기능을 **단일 실리콘 다이에 집적하여 초소형·초저전력·고성능** 달성

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **NoC(Network-on-Chip)**: 수십 개의 온칩 IP 블록 간에 라우터와 가상 채널을 통해 패킷 기반으로 데이터를 고속 전송하는 온칩 상호 연결망.
- **전력 도메인(Power Domain)**: 블록별로 전압과 클록 공급을 독립 제어하여 미사용 시 전원을 완전히 차단(Power Gating)하는 구획.
- **IP(Intellectual Property) 블록**: 특정 기능을 수행하도록 미리 설계·검증되어 재사용 가능한 하드웨어 회로 블록(ARM CPU, Mali GPU 등).

</details>

- 온칩 초단거리 배선을 통한 신호 지연 제거 및 외부 버스 구동 전력의 획기적 절감
- 칩 내부의 수많은 이종 연산 블록(CPU, GPU, NPU, ISP) 간 고대역폭 패킷 통신을 중재하는 **NoC(Network-on-Chip)** 내장
- 각 블록별 독립적인 **전력 도메인(Power Domain)** 구성과 **DVFS / Power Gating**을 통한 정적·동적 전력 극소화

#### 한줄 요약

- **NoC(Network-on-Chip) 인터커넥트·독립 전력 도메인(DVFS)·IP 재사용** 기반 설계

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **PMU / CRU(Power & Clock Reset Unit)**: 시스템 상태에 따라 각 IP 블록의 전원 스위치, PLL 클록 주파수 및 리셋 신호를 시퀀싱하는 제어 블록.
- **MMIO(Memory-Mapped I/O)**: CPU가 전용 명령어 없이 일반 메모리 주소 읽기/쓰기로 주변 장치 레지스터를 제어하는 방식.

</details>

```text
[ 시스템 온 칩 (SoC) 내부 아키텍처 구조도 ]
┌─────────────────────────────────────────────────────────────┐
│ 전력 / 클록 / 리셋 관리 유닛 (PMU / CRU Controller)        │
└──────────────┬───────────────────────────────┬──────────────┘
               │                               │
┌──────────────┴──────────────┐ ┌──────────────┴──────────────┐
│ 이종 연산 IP 블록군         │ │ 메모리 서브시스템           │
│  ├─ Multi-Core CPU          │ │  ├─ 온칩 시스템 캐시 (SLC)   │
│  ├─ High-Perf GPU           │ │  ├─ 내부 고속 SRAM         │
│  ├─ Neural Engine (NPU)     │ │  └─ LPDDR5/DDR5 컨트롤러     │
│  └─ Image Signal Proc (ISP) │ └──────────────┬──────────────┘
└──────────────┬──────────────┘                │
               │                               │
═══════════════╧═══════════════════════════════╧═══════════════ (NoC 온칩 패킷 스위칭 네트워크)
               │                               │
┌──────────────┴──────────────┐ ┌──────────────┴──────────────┐
│ 보안 서브시스템             │ │ 외부 I/O 서브시스템         │
│  └─ Crypto Engine / HSM     │ │  └─ PCIe, USB, UFS, MIPI    │
└─────────────────────────────┘ └─────────────────────────────┘
```

선의 의미: 연산 IP 블록, NoC 인터커넥트, 메모리 서브시스템 및 전력/클록/리셋 관리자 간의 SoC 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 연산 및 기능 지적 재산 블록 | 실제 데이터 가공 처리, 특수 연산 가속 및 최상위 시스템 제어 기능 직접 수행 |
| 네트워크 온 칩 인터커넥트 | 온칩 주소 기반 목적지 라우팅, 병목 트래픽 중재 및 **서비스 품질** 보장 정책 엄격 적용 |
| 메모리 서브시스템 | 온칩 고속 캐시 데이터 보관 및 외부 **동적 임의 접근 메모리**와의 복잡한 타이밍 인터페이스 통제 |
| 입출력 서브시스템 | 외부 통신 장치 **메모리 맵 입출력** 매핑 처리 및 외부 주변 장치와의 물리적 신호 통신 제어 |
| 전력, 클록 및 리셋 관리기 | 수백 개 블록별 독립 **전력 도메인**의 세밀한 전원 인가, 주파수 분할 및 안전한 순차 초기화 제어 |

#### 한줄 요약

- **이종 연산 IP(CPU/GPU/NPU)·NoC 버스·메모리 컨트롤러·PMU/CRU** 통합

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Power Gating / Clock Gating**: 미사용 블록의 공급 전원 자체를 스위치 차단(Power Gating)하거나 클록 토글을 중단(Clock Gating)하는 절전 동작.

</details>

```text
[ SoC 응용 프로그램 작업 요청에 따른 동작 흐름 ]
                         │
                         ▼
   [ 1. PMU가 대상 가속기 전력 도메인 On 및 클록 인가 ]
                         │
                         ▼
   [ 2. CPU가 MMIO 제어 레지스터에 작업 파라미터 기록 ]
                         │
                         ▼
   [ 3. NoC가 주소 디코딩 후 패킷 라우팅 및 대역폭(QoS) 중재 ]
                         │
                         ▼
   [ 4. 가속기(NPU/GPU)가 메모리 직접 인출 및 고속 연산 수행 ]
                         │
        [ 작업 완료 및 유휴 타이머 만료 판정 ]
                         │
                         ▼
   [ 5. PMU가 Clock Gating 및 Power Gating 발동하여 절전 진입 ]
```

**동작 원리**

1. **도메인 활성화**: PMU가 잠자던 가속기(NPU)의 전력 스위치를 켜고 PLL 클록과 리셋 신호를 순차 해제
2. **작업 할당**: CPU가 NoC를 통해 가속기 MMIO 레지스터에 텐서 메모리 주소와 연산 명령 기록
3. **NoC 중재**: 온칩 네트워크가 QoS 우선순위에 따라 가속기와 메모리 컨트롤러 간 패킷 트래픽 라우팅
4. **가속 실행**: 가속기 IP가 시스템 캐시(SLC) 및 외부 DRAM에서 데이터를 인출하여 병렬 연산 완료
5. **절전 진입**: 작업 완료 인터럽트 발송 후 유휴 상태가 되면 클록 및 전원 스위치를 내려 누설 전류 차단

#### 한줄 요약

- 전력 도메인 활성화 $\to$ **MMIO 레지스터 설정 $\to$ NoC 패킷 라우팅 및 IP 실행 $\to$ 유휴 시 Clock/Power Gating**

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **SoC vs SiP vs MPU Board**:
  - SoC: 단일 실리콘 다이 일체형 집적 (최고 전력 효율, 최고 집적도)
  - SiP: 이종 다이들을 단일 패키지 내부 결합 (이종 공정 통합, 적층)
  - MPU Board: PCB 기판 상에 개별 칩 실장 (가장 큼, 고전력)

</details>

| 비교 항목 | 시스템 온 칩 (SoC) | 시스템 인 패키지 (SiP) | 마이크로프로세서 보드 (MPU Board) |
|:---|:---|:---|:---|
| 집적 방식 및 수준 | 단일 실리콘 다이에 모든 기능 집적 (Monolithic) | 개별 다이들을 단일 패키지 내부 적층/병합 | 개별 칩들을 PCB 기판 표면에 솔더링 실장 |
| 성능 및 전력 효율 | 온칩 배선으로 신호 지연 및 I/O 전력 극소화 | 인터포저/본딩와이어로 준우수한 지연 및 전력 | PCB 배선 구동으로 가장 높은 전력 소모 및 지연 |
| 한계 및 제조 비용 | 다이 크기 증가 시 수율(Yield) 급감, 고액의 NRE | 고급 패키징 공정 비용 및 패키지 불량 검증 난제 | 물리적 폼팩터 크기 및 조립 보드 면적 낭비 |

#### 한줄 요약

- 대량 양산/모바일은 **SoC**, 이종 공정/적층은 **SiP/Chiplet**, 범용/소량은 **MPU 보드**

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **DVFS(Dynamic Voltage and Frequency Scaling)**: 실시간 워크로드 부하에 따라 CPU/GPU 전압과 동작 주파수를 동적으로 조절하여 소비 전력을 $P \propto V^2 f$ 비율로 절감하는 기술.
- **칩렛(Chiplet)**: 대면적 모놀리식 다이의 수율 한계를 극복하기 위해 기능별(Core, I/O, Memory)로 작은 다이로 쪼개어 UCIe 표준으로 결합하는 기술.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 이기종 가속기 간 데이터 이동 폭발로 온칩 네트워크망 붕괴 및 심각한 전송 지연 병목 사태 | **서비스 품질** 강제 차등 정책 수립 및 물리 링크 내 **가상 채널** 분리 다중화 기술 적용 | 우선순위가 높은 실시간 트래픽의 대역폭 확보 및 지연시간 상한을 완벽하게 보장 |
| 깊은 절전인 **전력 게이팅**에서 깨어날 때 복구 시간 지연에 따른 칩 전반의 굼뜬 응답성 저하 | 타이머 유휴 임계치 미세 조정 및 절전 전 상태를 보존해두는 특수 상태 유지 레지스터 활용 | 누설 전력은 잡으면서도 사용자 명령에 즉시 응답하는 전원 복구 응답성 간의 최적 균형 확보 |
| 외부에서 사 온 각기 다른 블록 간 통신 인터페이스 규격 불일치 및 캐시 메모리 정합성 훼손 | 설계 단계에서의 엄격한 칩 레벨 **통합 검증** 및 호환성을 맞춰주는 프로토콜 변환 래퍼 체계 강제 결합 | 주소 라우팅 미아 오류 방지 및 다중 코어 환경의 절대적인 **캐시 일관성** 무효화 실패 원천 차단 |
| 수많은 기능을 집어넣느라 단일 칩 면적이 너무 커져 치명적인 **수율** 저하 및 국소 부위 용광로 핫스팟 발열 | 기능별로 **칩렛** 구조로 잘게 분할 생산 후 이어 붙이기 및 온도를 감시하는 동적 전압 주파수 스케일링 연동 제어 | 작게 잘라 만들어 칩 전체 생산 수율 극대화 향상 및 임계 발열 한도 내에서의 시스템 다운 없는 작동 유지 |

#### 한줄 요약

- **NoC QoS/가상 채널(VC)·DVFS/Power Gating·칩렛(Chiplet) 분할·DFT 검증**

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **모듈러 칩렛 SoC(Modular Chiplet SoC)**: 3nm 최선단 연산 코어 칩렛과 6nm/12nm 레거시 I/O 칩렛을 UCIe/2.5D 인터포저로 통합하여 수율과 비용을 극대화하는 차세대 SoC 패러다임.

</details>

- 모바일/에지 디바이스는 **Monolithic SoC**, 대면적 서버/AI 프로세서는 **칩렛(Chiplet) 기반 모듈형 SoC 표준 채택**

#### 한줄 요약

- **수율 한계와 공정 최적화**를 위해 단일 SoC에서 첨단 칩렛(Chiplet)으로 진화
