## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **시스템온칩(System on Chip, SoC)**: CPU·가속기·메모리 제어기·I/O 등 시스템의 주요 기능을 하나의 반도체 다이에 집적한 칩.
- **IP 블록(Intellectual Property Block)**: 검증을 거쳐 재사용 가능하도록 모듈화된 반도체 기능 회로 블록.

</details>

- 정의/개념: CPU·가속기·메모리 제어기·I/O를 검증된 **IP 블록** 단위로 모아 하나의 다이에 올린 **시스템온칩**
- 배경/필요성: 칩 사이를 PCB로 잇는 순간 배선 길이만큼 I/O 전력과 지연이 붙어, 모바일 기기의 전력 예산 안에 들어올 수 없음

#### 한줄 요약
- SoC가 절약하는 것은 면적보다 다이 사이를 건너는 신호의 전력이며, 모바일에서 SoC가 필수가 된 이유도 성능이 아니라 이 전력이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **네트워크온칩(Network on Chip, NoC)**: 수많은 온칩 IP 블록 간 패킷 통신을 라우터 기반으로 중계하는 온칩 상호 연결망.
- **하드웨어/소프트웨어 통합 설계(HW/SW Co-Design)**: 칩 제작 전 가상 플랫폼에서 소프트웨어와 하드웨어를 동시에 검증하는 개발 기법.

</details>

- IP 블록 재사용으로 기능 회로의 재설계·재검증 범위 축소
- **네트워크온칩** 기반 인터커넥트로 IP별 주소·대역폭·우선순위 배분
- 단일 다이 통합으로 패키지 간 I/O 배선과 보드 면적 감소

#### 한줄 요약
- IP 재사용이 줄이는 것은 설계 시간이 아니라 검증 시간이며, SoC 개발 일정의 대부분이 검증에 쓰인다는 점에서 이 절감이 결정적이다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **전력 관리 유닛(PMU)**: 각 IP 블록의 동작 상태에 따라 전압과 주파수를 동적으로 조절하는 전력 제어 회로.

</details>

```text
[SoC 다이]
├─ 연산 IP
│  ├─ CPU 코어 클러스터
│  ├─ GPU·NPU 가속기
│  └─ 보안 암호 엔진
├─ 온칩 인터커넥트 (NoC·AMBA)
├─ 메모리·주변 IP
│  ├─ LPDDR 메모리 제어기
│  ├─ 디스플레이·카메라 IP
│  └─ 고속 I/O (PCIe·USB)
└─ 전력 관리 유닛 (PMU)
```

선의 의미: 가지(`├─`)는 소유 관계이며, 온칩 인터커넥트만이 연산 IP와 메모리·주변 IP 양쪽에 동시에 닿음

| 구성요소 | 책임 |
|:---|:---|
| 프로세서 코어 클러스터 | 범용 OS 구동 및 고성능 직렬 제어 연산 수행 |
| 하드웨어 가속기 (NPU/GPU) | AI 딥러닝 추론 및 고성능 그래픽 병렬 연산 전담 |
| 온칩 인터커넥트 | 다중 IP 간 고대역폭·저지연 패킷 라우팅과 중재 |
| 메모리 제어기 및 주변장치 IP | 외부 LPDDR DRAM 연동 및 디스플레이·통신 인터페이스 제공 |
| **전력 관리 유닛** | 전압·주파수 조절과 도메인 차단으로 칩 전체 에너지 관리 |

#### 한줄 요약
- IP는 벤더가 달라도 인터커넥트 규약만 맞으면 붙으므로, SoC 설계의 실제 난제는 회로가 아니라 서로 다른 출처의 IP를 한 규약 아래 세우는 통합이다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **테이프아웃(Tape-Out)**: 칩의 최종 레이아웃 설계 데이터를 파운드리 공장으로 넘겨 생산을 의뢰하는 단계.

</details>

```text
시스템 요구사항 분석 → 핵심 IP 블록 선정
        │
   온칩 버스 설계 후 IP 통합
        │
   HW/SW 통합 검증 통과?
   ┌────┴─────┐
아니오          예
   │             │
IP 구성·버스     배치·배선 후 타이밍 검증
정책 재조정        │
   │        타이밍 수렴하는가?
   │         ┌──┴───┐
   │       아니오     예
   │         │        │
   └────┬────┘   테이프아웃 후 제조
        │
   (다시 통합 검증)
```

분기 결과: **하드웨어/소프트웨어 통합 설계** 기반 검증과 타이밍 수렴이라는 두 되돌림 지점이 SoC 일정의 전부이며, **테이프아웃을** 지나면 되돌릴 수 없어 그 이전 검증 밀도가 곧 재작업 비용을 결정

#### 한줄 요약
- 소프트웨어 검증을 칩 제작 전으로 끌어온 이유는 개발 병행이 아니라 되돌릴 수 없는 시점 이후에 발견되는 결함의 비용이 자릿수 단위로 크기 때문이다.

## Ⅴ. 종류 및 비교

| 시스템 집적 구조 | 단일 다이 SoC | SiP (System in Package) | 칩렛 (Chiplet) | 개별 칩 기판 (PCB) |
|:---|:---|:---|:---|:---|
| 적용 기준 | 최소 폼팩터·낮은 다이 간 I/O 전력 | 이종 다이의 단일 패키지 결합 | 대형 다이 수율·공정 최적화 필요 | 기능 변경·소량 생산 유연성 우선 |
| 핵심 특징 | 주요 시스템 기능의 단일 다이 집적 | 여러 개별 다이를 단일 패키지에 결합 | 기능별 공정 다이를 고밀도 연결 | 개별 패키지 칩을 PCB에서 연결 |
| 한계 | 다이 면적 증가 시 수율 급감·비용 상승 | 패키징 두께 증가 및 열 방출 분산 필요 | 인터포저 패키징 비용 및 신호 무결성 | 부피 큼·배선 지연 길고 전력 소모 큼 |

#### 한줄 요약
- 네 방식은 통합 수준의 눈금이며, 왼쪽일수록 전력과 지연이 유리하지만 다이가 커져 수율이 급격히 나빠지는 지점에서 오른쪽으로 밀린다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **DVFS(Dynamic Voltage and Frequency Scaling)**: 부하에 따라 전압과 클록 주파수를 실시간 조절하는 절전 기법.
- **파워 게이팅(Power Gating)**: 사용하지 않는 IP 블록의 전원을 스위치로 완전히 차단해 누설 전류를 없애는 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 다이 면적 증가로 공정 결함 노출·수율 저하 | 모듈형 설계·칩렛 전환 검토 | 결함 영향 면적 감소·양품 조합 가능 |
| 고밀도 집적으로 국소 핫스팟 발생 | 온도 센서·동적 열 쓰로틀링 | 접합 온도 제한 내 동작 유지 |
| 유휴 IP 블록의 대기 전력·누설 전류 | **파워 게이팅**·다중 전력 도메인 **DVFS** 적용 | 유휴 전력 감소·부하별 성능 유지 |
| 디지털 고속 클록 노이즈의 아날로그 RF 간섭 | 기판 가드링(Guard Ring) 및 물리적 격리 배치 | 신호 무결성(SI/PI) 확보 및 오동작 방지 |

#### 한줄 요약
- 집적이 만들어 낸 이득과 문제가 같은 뿌리에서 나오므로, **파워 게이팅** 및 열·간섭 대책 적용은 SoC의 부가 기능이 아니라 성립 조건이다.

## Ⅶ. 결론

- 낮은 I/O 전력과 최소 폼팩터가 우선이면 단일 다이 SoC를 유지하고, 다이 면적·이종 공정·수율 비용이 임계점을 넘는 고성능 시스템은 칩렛·SiP로 분할 구성

#### 한줄 요약
- 집적을 어디서 멈출지는 기술이 아니라 수율 곡선이 정하며, 다이가 커질수록 결함 하나가 버리는 면적도 함께 커진다는 사실이 그 한계선을 그린다.
