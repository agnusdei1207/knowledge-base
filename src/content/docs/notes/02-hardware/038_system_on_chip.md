## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **시스템 온 칩(System on Chip, SoC)**: 연산•메모리•I/O를 단일 다이에 통합한 시스템이다.
- **입출력(Input/Output, I/O)**: 칩과 외부 장치 사이의 데이터를 전달하는 체계이다.
- **다이(Die)**: 웨이퍼에서 절단하여 패키지에 넣는 하나의 반도체 회로 조각이다.
- **I/O 전력**: 칩 사이 신호를 송수신할 때 소비되는 전력이다.

</details>

- 정의/개념: 프로세서·가속기·메모리 제어기·I/O 기능을 단일 다이에 통합한 **SoC**이다.
- 배경/필요성: 기능을 개별 칩으로 연결하면 보드 면적과 칩 간 통신 지연·I/O 전력이 증가한다.

#### 한줄 요약

- SoC는 주요 시스템 기능을 단일 다이에 통합해 보드 면적과 칩 간 통신 지연·I/O 전력을 줄인다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **칩 내 네트워크(Network on Chip, NoC)**: 칩 내부 IP 사이의 트랜잭션 연결망이다.
- **지식재산 블록(Intellectual Property Block, IP 블록)**: 재사용 가능한 설계 블록이다.
- **전력 도메인(Power Domain)**: 전원을 다른 영역과 독립적으로 공급하거나 차단할 수 있도록 구분한 회로 영역이다.
- **클록 게이팅(Clock Gating)**: 유휴 블록에 공급되는 클록을 차단하여 불필요한 동적 전력을 줄이는 기법이다.
- **단일 다이 통합**: 연산·메모리·I/O 기능을 하나의 반도체 다이에 구현하는 방식이다.

</details>

- 보드 면적•I/O 전력을 줄이는 **단일 다이 통합**이 핵심이다.
- 이기종 IP의 주소•대역폭을 중재하는 **NoC**가 핵심이다.
- 블록별 전원•클록을 제어하는 **전력 도메인**이 핵심이다.

#### 한줄 요약

- NoC는 이종 IP의 주소·대역폭을 중재하고, 전력 도메인과 클록 게이팅은 유휴 블록의 동적·누설 전력을 줄인다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **메모리 서브시스템(Memory Subsystem)**: 캐시와 메모리 제어기를 통해 연산 블록에 명령과 데이터를 공급하는 구성이다.
- **리셋 관리기(Reset Manager)**: 전원과 클록의 준비 순서에 맞춰 각 블록의 초기화와 해제를 제어하는 회로이다.
- **서비스 품질(Quality of Service, QoS)**: 트래픽별 대역폭•지연 목표를 적용하는 정책이다.
- **동적 임의 접근 메모리(Dynamic Random-Access Memory, DRAM)**: 동적 주기억장치이다.
- **메모리 매핑 입출력(Memory-Mapped Input/Output, MMIO)**: 메모리 주소로 장치 레지스터에 접근하는 방식이다.

</details>

```text
            [전력•클록•리셋 관리기]
                  /           \
     [연산•기능 IP] ----- [NoC•인터커넥트] ----- [메모리 서브시스템]
                                  |
                           [I/O 서브시스템]
```

선의 의미: 가로•세로선은 NoC에 결합된 연산•메모리•I/O 경계이고, 사선은 관리기가 연산 IP와 NoC의 전력•클록•리셋 경계에 함께 연결됨을 뜻한다.

| 구성요소 | 책임 |
|:---|:---|
| 연산•기능 IP | 명령 기반 연산•제어 수행 |
| NoC•인터커넥트 | 주소 라우팅•중재•**QoS 적용** |
| 메모리 서브시스템 | 캐시•DRAM 데이터 공급 |
| I/O 서브시스템 | MMIO•외부 데이터 이동 |
| 전력•클록•리셋 관리기 | 전원•주파수•초기화 제어 |

#### 한줄 요약

- NoC가 연산•메모리•I/O 블록을 연결하고 관리기가 각 블록의 전력 상태를 제어한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **전력 게이팅(Power Gating)**: 사용하지 않는 회로 블록의 전원을 차단하여 누설 전력을 줄이는 기법이다.
- **중앙 처리 장치(Central Processing Unit, CPU)**: 범용 명령을 실행하는 처리 장치이다.
- **신경망 처리 장치(Neural Processing Unit, NPU)**: 신경망 연산 전용 처리 장치이다.
- **전력·클록·리셋 활성화**: 대상 IP의 전원과 클록을 켜고 리셋을 해제하는 단계이다.
- **MMIO 작업 설정**: CPU가 연산 종류와 데이터 주소를 IP 레지스터에 기록하는 단계이다.
- **NoC 라우팅·QoS 중재**: 목적 주소로 경로를 정하고 트래픽별 대역폭과 우선순위를 배정하는 단계이다.
- **연산 IP 데이터 처리**: 대상 IP가 메모리·I/O 데이터를 받아 작업을 실행하는 단계이다.
- **전력·클록 게이팅**: 작업 완료 뒤 유휴 IP의 클록이나 전원을 차단하는 단계이다.

</details>

```text
                     [소프트웨어 작업 요청]
                              |
                  1. 전력•클록•리셋 활성화
                              |
                     2. MMIO 작업 설정
                              |
                       [NoC•인터커넥트]
                              |
                   3. 주소 라우팅•QoS 중재
                              |
             +---------------------------------+
             | 반복: 작업 데이터•타일        |
             | 4. 연산 IP•데이터 처리        |
             +---------------------------------+
                              |
                     [완료•결과 상태 전달]
                              |
                     [유휴 임계치 도달?]
                        /           \
                     [아니요]        [예]
                        |             |
                  [다음 작업 대기] 5. 전력•클록 게이팅
```

### 동작 원리

1. **전력·클록·리셋 활성화**: 대상 IP의 전원을 켜고 클록 안정화와 리셋 해제로 실행 상태를 준비한다.
2. **MMIO 작업 설정**: CPU가 연산 종류, 데이터 주소, 크기와 완료 통지 정보를 IP 레지스터에 기록한다.
3. **NoC 라우팅·QoS 중재**: 목적 주소로 요청 경로를 선택하고 트래픽 등급에 따라 대역폭·우선순위를 배정한다.
4. **연산 IP 데이터 처리**: 대상 IP가 NoC로 메모리·I/O 데이터를 받아 작업을 실행하고 결과 상태를 기록한다.
5. **전력·클록 게이팅**: 완료 후 유휴 시간이 임계치를 넘으면 클록 또는 전원을 차단해 동적·누설 전력을 절감한다.

#### 한줄 요약

- CPU가 대상 가속기의 전력 상태와 작업을 설정하면 NoC가 데이터를 전달하고, 완료 후 전력 관리기가 유휴 시간에 따라 클록·전원을 차단한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **패키지 내 시스템(System in Package, SiP)**: 서로 다른 기능이나 공정의 여러 다이를 하나의 패키지 안에서 연결한 시스템이다.
- **마이크로프로세서 기반 보드(MPU-based Board, MPU 기반 보드)**: 독립 프로세서와 메모리 및 주변 칩을 인쇄회로기판 배선으로 결합한 시스템이다.
- **칩렛(Chiplet)**: 기능별로 나눈 작은 다이를 패키지 안에서 연결하여 하나의 시스템처럼 사용하는 구성 단위이다.
- **인쇄회로기판(Printed Circuit Board, PCB)**: 독립 칩을 배선으로 연결하는 기판이다.
- **수율(Yield)**: 제조한 전체 다이 가운데 요구 기능과 품질 기준을 통과한 다이의 비율이다.

</details>

| 시스템 통합 방식 | SoC | SiP | MPU 기반 보드 |
|:---|:---|:---|:---|
| 적용 기준 | 기능이 고정된 대량 제품에서 소형·저전력이 중요할 때 | 서로 다른 공정의 다이·칩렛 결합이 필요할 때 | 소량 제품에서 잦은 사양 변경에 대응할 때 |
| 핵심 특징 | **SoC**의 단일 다이 | **SiP**의 복수 다이 | **MPU 기반 보드**의 독립 칩·**PCB** 연결 |
| 한계 | 대형 다이 **수율**과 검증 | 패키지 **수율**과 발열 | 보드 면적과 **I/O 전력** |

> 요약: 통합 범위와 변경 주기로 구현 방식을 선택한다.

#### 한줄 요약

- 기능이 고정된 대량 제품은 SoC, 이종 공정·칩렛 결합은 SiP, 사양 변경이 잦은 소량 제품은 MPU 기반 보드가 적합하다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **가상 채널(Virtual Channel)**: 하나의 물리 링크를 여러 논리 흐름으로 분리하여 혼잡과 선두 차단을 줄이는 전송 자원이다.
- **캐시 일관성(Cache Coherence)**: 여러 연산 주체가 가진 공유 데이터의 캐시 복사본을 동일하게 유지하는 규칙이다.
- **동적 전압•주파수 조절(Dynamic Voltage and Frequency Scaling, DVFS)**: 부하와 전력•열 한도에 맞춰 동작 전압과 주파수를 조절하는 기법이다.
- **지식재산(Intellectual Property, IP)•이미지 신호 처리기(Image Signal Processor, ISP)•신경망 처리 장치(Neural Processing Unit, NPU)**: 재사용 설계 블록과 영상•신경망 전용 가속 블록이다.
- **유휴 임계치**: 블록의 클록이나 전원을 차단하기 전에 기다리는 유휴 시간 기준이다.
- **IP 통합 검증**: IP 블록 사이의 주소·프로토콜·동시성 규칙을 함께 시험하는 절차이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 이기종 IP 요청이 같은 NoC 링크에 몰려 혼잡·지연 증가 | 흐름별 대역폭·지연을 측정해 **QoS·가상 채널** 설정 | 우선 트래픽의 대역폭 확보 |
| 전력 게이팅 해제 시간이 길어 작업 시작 지연 | 사용 예측에 따라 **유휴 임계치**와 상태 유지 수준 조정 | 전력과 응답성 절충 |
| IP마다 주소 맵과 **캐시 일관성** 규칙이 달라 데이터 오류 발생 | **IP 통합 검증**으로 인터페이스 규칙 확인 | 잘못된 라우팅과 오래된 사본 사용 방지 |
| 대형 단일 다이에서 결함·발열이 집중되어 수율·지속 성능 저하 | 기능별 **칩렛** 분할과 **DVFS**·온도 감시 적용 | 결함 영향과 열 분산 |

> 사례: 스마트폰 SoC는 ISP•NPU 대역폭을 **NoC**에 예약

#### 한줄 요약

- NoC QoS로 우선 트래픽의 지연을 제한하고, 전력 게이팅의 유휴 임계치로 소비 전력과 기동 지연을 절충한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **이종 공정(Heterogeneous Process)**: 기능별 블록을 서로 다른 제조 공정으로 구현하여 비용과 성능을 최적화하는 방식이다.
- **통합 범위(Integration Scope)**: 한 다이•한 패키지•한 보드 중 시스템 기능을 묶어 구현하는 물리적 경계이다.
- **사양 변경 주기(Specification Change Cycle)**: 제품 기능이나 인터페이스 요구가 갱신되어 설계를 수정해야 하는 시간 간격이다.
- **통합 방식 선택 기준**: 통합 범위·이종 공정·사양 변경 주기로 SoC·SiP·보드를 고르는 기준이다.

</details>

- **통합 방식 선택 기준**에 따라 고정 기능의 대량 제품은 **SoC**, **이종 공정**은 **SiP**, **사양 변경 주기**가 짧으면 **MPU 기반 보드**로 구성한다.

#### 한줄 요약

- 고정 기능의 대량 제품은 단일 다이 SoC, 이종 공정은 복수 다이 SiP, 사양 변경이 잦은 소량 제품은 MPU 기반 보드로 구현한다.
