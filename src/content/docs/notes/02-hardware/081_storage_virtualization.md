## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **스토리지 가상화(Storage Virtualization)**: 다수의 물리적 저장장치(All-Flash NVMe, SAS HDD, 이기종 SAN 어레이)를 논리적으로 통합 추상화하여, 호스트 서버에 물리 하드웨어 종속성이 없는 단일 가상 스토리지 풀(Pool)과 가상 볼륨(Virtual LUN)으로 제공하는 기술.
- **논리-물리 주소 매핑(LBA Mapping)**: 호스트가 접근하는 가상 블록 주소(Virtual LBA)와 백엔드 실제 물리 디스크의 블록 주소(Physical Extent)를 실시간으로 상호 변환하는 추상화 계층.

</details>

- 정의/개념: 이기종 물리 스토리지를 단일 풀로 추상화하고 논리-물리 매핑을 통해 씬 프로비저닝과 무중단 마이그레이션을 제공하는 **스토리지 가상화**(Storage Virtualization) 아키텍처
- 배경/필요성: 이기종 물리 스토리지 간 사일로 현상으로 인한 자원 활용률 저하 및 장비 증설·교체 시의 서비스 다운타임 한계

#### 한줄 요약
- 스토리지 가상화는 물리 스토리지의 복잡성을 은닉하고 논리-물리 매핑을 통해 동적 용량 관리와 무중단 마이그레이션을 실현한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **씬 프로비저닝(Thin Provisioning)**: 호스트에는 대용량 가상 볼륨(예: 10TB)을 즉시 할당하되, 실제 물리 디스크 공간은 데이터가 실제로 쓰이는 시점에만 블록 단위로 동적 할당하는 기술.
- **온라인 데이터 마이그레이션(Online Migration)**: 서비스 운영 중단 없이 백그라운드에서 데이터를 구형 스토리지에서 신형 스토리지로 실시간 이관하는 무중단 재배치 기능.

</details>

- 물리 디스크와의 디커플링: 논리-물리 매핑 분리를 통해 호스트 설정 변경 없이 백엔드 물리 스토리지 증설 및 교체
- 자원 활용률 극대화: **씬 프로비저닝**(Thin Provisioning) 및 중복제거 기술을 결합하여 물리 디스크 활용률 극대화
- 무중단 고가용성: 서비스 다운타임을 제거하는 **온라인 데이터 마이그레이션** 및 스토리지 풀 간 실시간 미러링 보장

#### 한줄 요약
- 주소 매핑 분리로 씬 프로비저닝과 다운타임 없는 온라인 데이터 재배치를 실현한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **가상 LUN(Virtual LUN)**: 물리 디스크의 실제 위치 및 RAID 구성과 무관하게 호스트 서버에 표준 블록 디바이스로 노출되는 가상 볼륨.
- **스토리지 풀(Storage Pool)**: 이기종 물리 디스크들의 가용 공간을 하나의 거대한 자원 저장소로 집적하여 가상 볼륨에 물리 익스텐트(Extent)를 동적 배분하는 엔진.

</details>

```text
[스토리지 가상화 3계층 아키텍처]
├── 호스트 서버 계층 (Host Layer)
│   └── 가상 볼륨 (Virtual LUN)
├── 가상화 매핑 엔진 계층 (SDS Engine)
│   ├── 가상화 매핑 엔진 (Virtual LBA - Physical Extent 매핑)
│   ├── 매핑 메타데이터 (인메모리 주소 변환 테이블)
│   └── 씬 프로비저닝 할당기 (동적 익스텐트 할당)
└── 물리 백엔드 계층 (Physical Layer)
    └── 이기종 스토리지 풀 (All-Flash NVMe, SAS HDD, SAN 어레이)
```

선의 의미: 가지(`├──`, `└──`)는 가상화 계층별 소속 및 포함 관계; 가상화 매핑 엔진이 호스트 요청을 해석하여 물리 **스토리지 풀**의 익스텐트로 변환함

| 구성요소 | 책임 |
|:---|:---|
| **가상 LUN** | 호스트에 단일 블록 디바이스 제공 |
| 가상화 매핑 엔진 | 가상 LBA와 익스텐트의 실시간 주소 변환 |
| 매핑 메타데이터 | 주소 대응표의 인메모리 원자 관리 |
| 씬 프로비저닝 할당기 | 쓰기 시 동적 익스텐트 할당 |
| 이기종 스토리지 풀 | 물리 용량을 단일 풀로 통합 |

#### 한줄 요약
- 매핑 엔진이 호스트의 가상 LBA와 물리 익스텐트 사이에 끼어들어 데이터를 옮겨도 호스트가 알 필요가 없게 만들고, 그 대가로 모든 I/O에 붙게 된 주소 변환 조회는 메타데이터를 메모리에 상주시켜 감춘다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **익스텐트 동적 할당(Extent Allocation)**: 씬 프로비저닝 환경에서 호스트가 미할당 가상 LBA에 데이터를 처음 기록할 때, 스토리지 풀에서 실제 물리 블록을 떼어 매핑하는 절차.

</details>

```text
호스트 서버: 가상 LUN의 특정 가상 블록(Virtual LBA) 쓰기 요청
      │
      ▼
인메모리 매핑 메타데이터 테이블 조회
      │
      ▼
가상 LBA 대상 물리 익스텐트(Extent) 할당 여부 판정
   ├── [할당 완료] ── 매핑된 물리 디스크 주소로 데이터 직접 기록
   └── [미할당 상태] ─ 스토리지 풀에서 신규 물리 익스텐트 동적 할당
                               │
                               ▼
                        매핑 메타데이터 테이블에 주소 매핑 갱신
      │
      ▼
호스트 서버로 I/O 쓰기 완료(ACK) 응답 반환
```

분기 결과: **씬 프로비저닝**을 통해 실제 쓰기 시점에만 물리 용량을 소비하여 스토리지 낭비 방지

#### 한줄 요약
- 매 쓰기마다 매핑 테이블을 거치는 메타데이터 조회 비용을 지불하는 대신, 물리 용량은 실제 기록 시점에만 소비되어 선할당 낭비가 사라진다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **호스트 기반 가상화(Host-Based)**: LVM(논리 볼륨 관리자)이나 vSAN처럼 호스트 OS 커널 레벨에서 스토리지를 가상화하는 방식.
- **네트워크 기반 가상화(Network-Based)**: SAN 스위치 패브릭 또는 전용 SDS 가상화 어플라이언스에서 이기종 스토리지를 통합하는 방식.
- **배열 기반 가상화(Array-Based)**: 특정 메인 스토리지 컨트롤러 펌웨어가 하위 외장 스토리지를 가상화하여 수용하는 방식.

</details>

| 가상화 방식 | 호스트 기반 (Host-Based) | 네트워크 기반 (Network-Based) | 스토리지 배열 기반 (Array-Based) |
|:---|:---|:---|:---|
| 가상화 구현 계층 | 호스트 OS 커널 / 하이퍼바이저 | SAN 스위치 / 전용 어플라이언스 | 스토리지 컨트롤러 펌웨어 |
| 이기종 스토리지 수용력 | 단일 호스트 내부 장치로 한정 | 이기종 스토리지 전체 통합 | 벤더 전용 하위 장비 |
| 호스트 CPU 부하 | 연산 부하 발생 | 호스트 오프로드 | 호스트 오프로드 |
| 주요 적용 분야 | HCI 환경 | 엔터프라이즈 이기종 SAN | 고성능 전용 어레이 |

#### 한줄 요약
- 클라우드 HCI에는 호스트 기반, 대규모 이기종 통합에는 네트워크 기반, 고성능 전용망에는 **배열 기반 가상화**를 채택한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **변경 블록 추적(Changed Block Tracking, CBT)**: 무중단 온라인 데이터 이관 중 초기 전체 복제 이후 새롭게 발생한 실시간 변경 블록만 비트맵으로 추적하여 최종 차분 동기화하는 기술.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 씬 프로비저닝 오버커밋으로 인한 물리 스토리지 풀 공간 고갈 | **임계치 모니터링** 및 자동 용량 확장 | Out-of-Space 쓰기 오류 사전 방지 |
| 스토리지 가상화 컨트롤러 장애 시 전체 가상 볼륨 마비 | **액티브-액티브** 이중화 및 메타데이터 미러링 | 단일 장애점 제거 및 고가용성 보장 |
| 무중단 온라인 마이그레이션 중 실시간 쓰기 불일치 | **변경 블록 추적**(CBT) 기반 차분 동기화 | 무중단 데이터 정합성 보장 |
| 다중 가상 볼륨 간의 I/O 경합으로 인한 성능 간섭 | 가상 LUN별 **QoS 정책** 적용 | 핵심 워크로드 I/O 성능 보장 |

#### 한줄 요약
- 실무에서는 임계치 모니터링으로 용량을 지키고, 듀얼 컨트롤러로 HA를 보장하며, CBT로 무중단 이관을 완성한다.

## Ⅶ. 결론

- 하드웨어 종속성을 탈피하고 자원 활용률을 극대화하는 소프트웨어 정의 스토리지(SDS) 및 클라우드 가상화의 핵심 인프라 기술로 자리잡았으며, 최근에는 HCI(vSAN, Nutanix) 호스트 가상화와 CXL/NVMe-oF 기반 분산 컴포저블 스토리지(Composable Disaggregated Storage)로 고도화

#### 한줄 요약
- 스토리지 가상화는 벤더 종속성을 탈피하고 자원 활용률을 극대화하는 클라우드 인프라의 핵심 저장 기술이다.
