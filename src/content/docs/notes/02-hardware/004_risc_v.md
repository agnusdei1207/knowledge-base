## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **RISC-V**: 기본 정수 명령어 세트와 표준/사용자 정의 확장을 조합하는 로열티 없는 개방형 표준 ISA.
- **개방형 ISA 규격(Open ISA Specification)**: 특정 기업의 라이선스 종속 없이 하드웨어 코어를 구현하거나 명령어를 확장할 수 있도록 사양이 공개된 규격.
- **사용자 정의 확장(Custom Extension)**: 도메인 특화 연산을 위해 예약된 커스텀 인코딩 영역에 독자 명령어를 추가하는 하드웨어 확장 체계.

</details>

- 정의/개념: 기본 정수 명령어 세트(RV32I/RV64I)에 표준 및 사용자 정의 확장을 모듈식으로 조합하는 로열티 없는 개방형 표준 ISA
- 배경/필요성: 독점 아키텍처(x86, ARM)의 높은 라이선스 비용과 명령어 수정 제약을 해소하고 **도메인 특화 가속 코어의 독자 개발 지원**

#### 한줄 요약

- 로열티 없는 개방형 표준과 **모듈식 확장**으로 특화 프로세서 자율 구현

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **기본 ISA(Base ISA)**: RISC-V 호환 코어가 의무적으로 구현해야 하는 최소 단위의 정수 연산 명령어 집합.
- **표준 확장(Standard Extension)**: M(곱셈/나눗셈), A(원자적 연산), F/D(부동소수점), C(압축), V(벡터) 등 공식 표준화된 모듈 확장 세트.

</details>

- 라이선스 및 로열티 비용 없는 **개방형 ISA 규격**을 통한 독자적 반도체 칩 설계 허용
- **기본 ISA**에 **표준 확장** 및 특화 연산용 **사용자 정의 확장**의 모듈식 블록 조합
- 명령어 사양과 칩 내부 **마이크로아키텍처** 분리를 통한 다양한 성능/전력 구현체 생성

#### 한줄 요약

- **기본 ISA + 표준/사용자 확장** 조합으로 목적별 파이프라인 구현

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **ISA 프로파일(ISA Profile)**: RVA22 등 범용 운영체제 구동과 생태계 호환성을 위해 필수 확장 세트를 묶은 표준 사양.
- **권한 아키텍처(Privileged Architecture)**: M-Mode(머신), S-Mode(슈퍼바이저), U-Mode(사용자)로 계층화된 하드웨어 보안 및 예외 처리 규격.

</details>

```text
[ RISC-V 아키텍처 계층 구조 ]
┌───────────────────────────────────────────────────────────┐
│  ISA Profile (예: RVA22: RV64GC + Vector Extensions)      │
├───────────────────────────────┬───────────────────────────┤
│  Base ISA (RV32I / RV64I)     │  Extensions (M, A, F, D)  │
├───────────────────────────────┴───────────────────────────┤
│  Privileged Architecture (M-Mode / S-Mode / U-Mode CSRs)  │
└───────────────────────────────────────────────────────────┘
```

선의 의미: 기본 정수 ISA와 표준 확장, 특권 아키텍처 및 표준 프로파일로 구성된 RISC-V 계층 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 기본 ISA | **XLEN** 정수 연산의 공통 실행 계약을 규정 |
| 확장 집합 | 산술, 벡터 및 **사용자 정의 확장** 명령 선택 |
| 권한 아키텍처 | 동작 모드 제어, **제어 및 상태 레지스터**와 예외 규정 |
| ISA 프로파일 | 필수 확장 조합을 통해 호환 대상 고정 |

#### 한줄 요약

- **기본 ISA·확장·특권 모드(M/S/U)**를 표준 프로파일(RVA)로 통합

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **적합성 시험(Compliance Test)**: 구현된 코어가 공식 명령어 사양과 특권 레지스터 동작을 정확히 만족하는지 검증하는 테스트 스위트.

</details>

```text
1. [ 목표 프로파일 및 확장 세트 선정 ]
                 │
                 ▼
2. [ 코어 RTL 하드웨어 논리 설계 ]
                 │
                 ▼
3. [ 인코딩 계약 기반 검증 코드 생성 ]
                 │
                 ▼
4. [ 적합성 시험 및 차등 테스트 ] ──> 불일치: RTL 수정 / 통과: 툴체인 배포
```

**동작 원리**

1. **목표 선정**: 시스템 성능 및 전력 목표에 맞추어 기본 ISA(RV64I)와 필요 확장(M, A, F, D, V) 정의
2. **RTL 구현**: 선정된 사양서에 의거하여 파이프라인 및 제어 논리 회로 설계
3. **테스트 생성**: 표준 인코딩 계약에 따른 코너 케이스 및 예외 처리 검증 코드 생성
4. **적합성 검증**: 시뮬레이터와 실제 RTL 동작을 비교하는 차등 테스트(Differential Testing)로 규격 검증 완료

#### 한줄 요약

- 프로파일 선정, RTL 구현, **적합성 시험 및 차등 테스트**로 코어 완결

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **생태계 파편화(Fragmentation)**: 각 기업이 독자 확장을 무분별하게 추가하여 소프트웨어 바이너리 호환성이 깨지는 현상.

</details>

| 비교 항목 | 개방형 ISA (RISC-V) | 상용 독점 ISA (Arm) |
|:---|:---|:---|
| 적용 기준 | 도메인 특화 가속기(AI/NPU), 커스텀 SoC, 학술 연구 | 모바일 AP, 검증된 자동차/서버 상용 칩셋, 빠른 시장 출시 |
| 핵심 특징 | 로열티 무료, 사용자 정의 확장 무제한 허용, 오픈소스 | 고가의 라이선스 비용, 엄격히 통제된 표준 명령어 세트 |
| 한계 및 위험 | 제조사별 확장에 따른 소프트웨어 생태계 파편화 위험 | 코어 수정 불가(명령어 확장 제약) 및 벤더 종속성 심화 |

#### 한줄 요약

- RISC-V는 **확장 자율성과 비용 절감**, Arm은 **검증된 생태계와 성숙도** 강점

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **차등 테스트(Differential Testing)**: 골든 모델 시뮬레이터(Spike 등)와 개발 중인 하드웨어 코어의 레지스터 상태를 명령어 단위로 비교 검증하는 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 모듈 확장 난립에 따른 소프트웨어 **확장 파편화** | **응용 프로그램 이진 인터페이스** 고정 및 런타임 **기능 탐지** 적용 | 멀티코어 칩간 소프트웨어 바이너리 호환성 유지 |
| 커스텀 명령어와 표준 **예약 인코딩**의 공간 충돌 | 커스텀 전용 오퍼코드 영역 활용 | 표준 업데이트 시에도 확장 회로의 안전성 확보 |
| 기계어 처리 오작동 및 예외 누수 검증 한계 | 시뮬레이터 기반 **차등 테스트** 및 공식 **적합성 시험** 통과 | 물리적 제작 전 논리 오류 전수 발굴 및 비용 절감 |
| 최신 확장에 대한 컴파일러 툴체인 **성숙도** 부족 | 공식 업스트림 반영 모니터링 및 자체 백엔드 유지보수 | 개발 코드 빌드 실패 사전 차단 |

#### 한줄 요약

- **표준 ABI 준수·차등 테스트·커스텀 오퍼코드 격리**로 파편화 방지

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **반도체 주권과 자율성**: 특정 국가나 상용 벤더의 수출 통제 및 라이선스 정책에 구애받지 않고 독자 칩을 개발할 수 있는 역량.

</details>

- 특화 명령어 및 반도체 주권 확보는 **RISC-V**, 기검증된 생태계와 빠른 출시는 **Arm IP** 선택

#### 한줄 요약

- **특화 연산 자율성(RISC-V)**과 **생태계 성숙도(Arm)** 간의 전략적 선택
