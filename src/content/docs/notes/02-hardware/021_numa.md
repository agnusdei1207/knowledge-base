## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **비균일 메모리 접근(Non-Uniform Memory Access, NUMA)**: 프로세서와 메모리 노드의 상대 위치에 따라 접근 지연이 다른 공유 메모리 구조이다.
- **NUMA 노드**: CPU 코어와 로컬 메모리를 묶은 운영체제의 지역성 도메인이다.
- **메모리 경합**: 여러 CPU의 요청이 같은 메모리 경로나 제어기에 몰려 대기 시간이 늘어나는 현상이다.

</details>

- 정의/개념: 프로세서와 메모리를 여러 노드로 분산해 접근 위치에 따라 지연이 달라지는 **NUMA** 구조이다.
- 배경/필요성: 다중 소켓 고성능 서버에서 단일 공유 버스 메모리 접근 방식을 적용하면 대역폭 병목과 메모리 버스 경합이 지수적으로 커진다.

#### 한줄 요약

- NUMA는 노드마다 로컬 메모리와 채널을 두어 전체 메모리 용량과 대역폭을 확장한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **CPU**: Central Processing Unit, 프로그램 명령을 실행하는 중앙 처리 장치이다.
- **로컬 메모리**: 실행 CPU와 같은 NUMA 노드에 연결된 메모리이다.
- **원격 메모리**: 실행 CPU와 다른 NUMA 노드에 연결된 메모리이다.
- **ccNUMA**: Cache-Coherent NUMA, 공유 주소 공간의 캐시 일관성을 유지하는 구조이다.
- **노드 간 인터커넥트**: 원격 메모리 요청과 응답을 노드 사이에서 운반하는 연결망이다.
- **캐시 일관성**: 여러 노드의 캐시가 같은 메모리 블록에 대해 최신값과 단일 쓰기 권한을 유지하는 성질이다.

</details>

- 노드별 **로컬 메모리**와 채널 추가에 따른 용량과 대역폭 확장이 핵심이다.
- **원격 메모리** 접근에 따라 인터커넥트 경합과 응답 지연이 증가한다.
- **ccNUMA** 공유 주소 공간의 캐시 일관성을 유지한다.

#### 한줄 요약

- 로컬 메모리보다 원격 메모리의 접근 지연이 크므로 스레드와 페이지의 노드 배치가 성능을 좌우한다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **메모리 제어기**: 메모리 주소와 명령 타이밍을 관리하는 구성요소이다.
- **메모리 채널**: 메모리 제어기와 DRAM 사이에서 데이터를 전송하는 경로이다.
- **NUMA 인지 운영체제**: 스레드 실행 위치와 물리 페이지 배치를 함께 관리하는 운영체제이다.
- **페이지 마이그레이션**: 자주 접근하는 CPU에 가까운 노드로 물리 페이지를 옮기는 동작이다.
- **DRAM**: Dynamic Random Access Memory, 주기적 재충전이 필요한 주기억장치이다.

</details>

```text
                 [NUMA 인지 운영체제]
                    /             \
[노드 0: CPU·캐시·제어기] --- [노드 간 인터커넥트] --- [노드 1: CPU·캐시·제어기]
            |                                             |
      [로컬 메모리 0]                               [로컬 메모리 1]
```

선의 의미: NUMA 노드가 로컬 메모리와 노드 간 연결망에 결합되고, 운영체제가 노드의 배치 정책을 관리하는 정적 구조다.

| 구성요소 | 책임 |
|:---|:---|
| NUMA 노드 | 지역 연산•캐시 제공 |
| 로컬 메모리 | 노드별 **DRAM**•채널 제공 |
| 노드 간 인터커넥트 | 원격 요청•응답 전달 |
| NUMA 인지 운영체제 | 스레드 배치•**페이지 마이그레이션** |

#### 한줄 요약
- 운영체제가 스레드와 페이지를 같은 노드에 배치하고 원격 접근만 인터커넥트로 전달한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **CPU 친화도**: 스레드가 실행할 코어 또는 NUMA 노드를 제한하는 정책이다.
- **홈 노드**: 특정 물리 주소의 메모리를 실제로 보유하고 요청을 처리하는 노드이다.
- **원격 메모리 요청**: 로컬 노드에 없는 페이지를 인터커넥트로 다른 노드에서 읽는 접근이다.
- **실행 노드 지정값**: CPU 친화도 정책에 따라 스레드가 실행할 코어나 NUMA 노드를 나타내는 정보이다.
- **스레드·페이지 배치**: 실행 스레드와 그 작업 페이지를 같은 NUMA 노드에 두는 단계이다.
- **홈 노드 판정**: 물리 주소의 홈 노드가 실행 CPU의 로컬 노드인지 확인하는 단계이다.
- **로컬 DRAM 접근**: 실행 CPU와 같은 노드의 메모리 제어기와 채널로 처리하는 접근이다.
- **원격 DRAM 접근**: 노드 간 인터커넥트를 거쳐 다른 노드의 DRAM에서 처리하는 접근이다.
- **스레드·페이지 재배치**: 원격 접근을 줄이도록 실행 스레드나 물리 페이지의 노드를 바꾸는 단계이다.

</details>

```text
                   [스레드•작업 페이지]
                            |
                  1. 스레드•페이지 배치
                            |
                    [CPU 메모리 접근]
                            |
                    2. 홈 노드 판정
                       /          \
                    [로컬]        [원격]
                      |             |
              3. 로컬 DRAM 접근  4. 인터커넥트•홈 DRAM 접근
                      |             |
                      +------+------+
                             |
                       [데이터 반환]
                             |
                    [원격 접근률 과다?]
                       /          \
                    [아니요]       [예]
                       |            |
                 [배치 유지]  5. 스레드•페이지 재배치
                                    |
                               [지역성 회복]
```

### 동작 원리

1. **스레드·페이지 배치**: CPU 친화도의 **실행 노드 지정값**과 물리 페이지 위치를 같은 NUMA 노드에 정렬한다.
2. **홈 노드 판정**: 물리 주소를 보유한 홈 노드가 실행 CPU의 로컬 노드인지를 확인한다.
3. **로컬 DRAM 접근**: 홈 노드가 같으면 로컬 메모리 제어기와 채널로 요청을 처리한다.
4. **원격 DRAM 접근**: 홈 노드가 다르면 **원격 메모리 요청**을 인터커넥트를 거쳐 다른 노드의 메모리 제어기로 전달한다.
5. **스레드·페이지 재배치**: 원격 접근이 지속되면 실행 스레드나 페이지를 이동해 지역성을 회복한다.

#### 한줄 요약

- NUMA는 로컬 메모리에 직접 접근하고, 원격 메모리는 노드 간 인터커넥트를 거쳐 접근한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **UMA**: Uniform Memory Access, 모든 프로세서의 공유 메모리 접근 지연이 같은 구조이다.
- **다중 소켓**: 둘 이상의 프로세서 패키지와 각 소켓의 로컬 메모리를 노드로 구성한 시스템이다.
- **배치 민감도**: 스레드와 페이지 위치에 따라 성능이 크게 달라지는 NUMA의 특성이다.
- **확장 한계**: 공유 메모리 경로의 대역폭과 중재 능력 때문에 프로세서 수를 늘려도 성능이 더 증가하지 않는 지점이다.
- **용량 확장**: 노드를 추가해 전체 메모리 용량을 늘리는 효과이다.
- **대역폭 확장**: 노드를 추가해 독립 메모리 채널의 처리량을 늘리는 효과이다.
- **분산 대역폭**: 각 NUMA 노드의 독립 메모리 채널이 병렬로 제공하는 합산 처리량이다.

</details>

| 메모리 구조 | NUMA | UMA |
|:---|:---|:---|
| 적용 기준 | 다중 소켓에서 **용량 확장·대역폭 확장**이 필요할 때 | 소규모 프로세서에서 일관된 접근 지연이 중요할 때 |
| 핵심 특징 | 노드별 메모리 채널을 통한 **분산 대역폭** | 모든 프로세서가 공유하는 균일 접근 경로 |
| 한계 | 원격 접근 지연과 **배치 민감도** | 공유 경로 경합에 따른 **프로세서 확장 한계** |

> 요약: 확장은 NUMA, 단순 관리는 UMA가 핵심이다.

#### 한줄 요약

- 다중 소켓의 용량·대역폭 확장에는 NUMA가 유리하고, 소규모 구성의 균일 지연과 단순한 배치에는 UMA가 유리하다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **최초 접근 정책**: 페이지를 처음 접근한 CPU의 NUMA 노드에 물리 메모리를 배치하는 정책이다.
- **자동 NUMA 균형**: 접근 패턴을 관찰해 스레드나 페이지를 가까운 노드로 자동 재배치하는 기능이다.
- **워커 지역화**: 질의 실행 스레드를 담당 데이터와 같은 노드에 두는 배치 방법이다.
- **버퍼 풀 지역화**: 자주 쓰는 데이터 페이지를 처리 노드에 두는 배치 방법이다.
- **병렬 초기화**: 실제 처리 스레드들이 각자 사용할 페이지를 처음 접근해 여러 NUMA 노드에 고르게 배치하는 방법이다.
- **마이그레이션 임계치**: 페이지 이동을 시작할 원격 접근량 기준이다.
- **마이그레이션 주기**: 페이지 접근 패턴을 다시 평가하는 시간 간격이다.
- **재배치 진동**: 접근 패턴 변화나 낮은 임계치 때문에 페이지가 노드 사이를 반복 이동하는 현상이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 스레드와 페이지가 다른 노드에 있어 원격 접근률 상승 | **CPU 친화도**와 페이지 위치를 함께 측정·정렬 | 로컬 메모리 사용 증가로 접근 지연 감소 |
| 단일 스레드의 **최초 접근 정책**으로 페이지 배치 편향 | 실제 처리 스레드가 담당 페이지를 **병렬 초기화** | 노드별 사용량에 따른 페이지 균등 분산 |
| **자동 NUMA 균형**의 낮은 이동 기준으로 **재배치 진동** | 접근 지속성에 맞게 **마이그레이션 임계치**와 **마이그레이션 주기** 조정 | 불필요한 복사와 재배치 오버헤드 감소 |
| 원격 요청이 집중되어 노드 간 인터커넥트 포화 | **워커 지역화·버퍼 풀 지역화**와 읽기 데이터 노드별 복제 | 원격 트래픽 분산으로 대역폭 경합 완화 |

> 사례: 워커•버퍼 풀을 같은 노드에 배치

#### 한줄 요약

- 이동 비용과 접근 지속성을 확인하고 데이터베이스 워커와 버퍼 풀을 같은 노드에 배치한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **일관 지연**: 어느 프로세서에서 접근해도 메모리 응답 시간이 같은 특성이다.
- **메모리 구조 선택 기준**: 용량·대역폭 확장성과 접근 지연의 균일성으로 NUMA와 UMA를 고르는 기준이다.

</details>

- **메모리 구조 선택 기준**에 따라 다중 소켓의 용량·대역폭 확장은 **NUMA**, 소규모의 **일관 지연**은 **UMA**를 선택한다.

#### 한줄 요약

- NUMA를 선택한 뒤에는 스레드와 자주 접근하는 페이지를 같은 노드에 배치해 로컬 메모리 지역성을 유지한다.
