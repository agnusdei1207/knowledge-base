## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **광 인터커넥트**: 전기 데이터를 빛으로 변환하여 광섬유로 전달하는 연결 기술이다.
- **광전 변환**: 전기 신호를 광 신호로 바꾸고 수신단에서 다시 전기 신호로 복원하는 과정이다.

</details>

- 정의/개념: 전기 비트열을 변조된 광 신호로 바꾸어 광섬유로 전송한 뒤 수신부에서 다시 전기 데이터로 복원하는 인터커넥트 기술이다.
- 배경/필요성: 구리 채널은 거리와 속도가 증가할수록 감쇠•누화와 등화 전력이 커지므로 장거리 고대역 전송의 에너지 효율이 낮아진다.

#### 한줄 요약

- **E/O 변환•광섬유 전송•O/E 복원** 기반을 연결한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **전자기 간섭(Electromagnetic Interference, EMI)**: 전자기장이 전기 신호에 유발하는 간섭이다.
- **파장 분할 다중화(Wavelength Division Multiplexing, WDM)**: 서로 다른 파장의 광 채널을 한 광섬유로 동시에 전송하는 기술이다.
- **주문형 집적회로(Application-Specific Integrated Circuit, ASIC)**: 특정 용도의 기능을 구현하도록 설계한 집적회로이다.
- **공동 패키지 광학(Co-Packaged Optics, CPO)**: ASIC과 광 엔진을 같은 패키지 가까이에 배치해 전기 경로를 줄이는 구조이다.
- **밀리와트 기준 데시벨(Decibels relative to One Milliwatt, dBm)**: 1mW를 기준으로 절대 전력을 나타내는 로그 단위이다.
- **데시벨(Decibel, dB)**: 두 전력의 비율을 나타내는 로그 단위이다.

</details>

- **광섬유•EMI 내성**으로 장거리 감쇠•간섭 감소한다.
- **WDM 병렬 채널**로 대역폭을 확대한다.
- **CPO**로 ASIC•광 엔진의 전기 경로 단축이 핵심이다.

광 링크의 수신 전력과 여유는 다음과 같다.

$$
P_{\mathrm{rx}} = P_{\mathrm{tx}}-L_{\mathrm{total}},\qquad
M = P_{\mathrm{rx}}-P_{\mathrm{sens}}
$$

- 송신•수신•최소 감도 전력은 **dBm**, 총 경로 손실•링크 여유는 **dB**을 적용한다.
- 동일 파장•전송률에서 노화•오염•온도 손실을 포함한 **링크 버짓**을 산정한다.

#### 한줄 요약

- **광섬유•WDM 이득**과 광전 변환 전력•비용 사이에는 상충 관계가 있다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **직렬화•역직렬화기(Serializer/Deserializer, SerDes)**: 병렬 데이터를 직렬 신호로 변환하고 수신 시 다시 병렬 데이터로 복원하는 회로이다.
- **전기-광 변환(Electrical-to-Optical Conversion, E/O)**: 전기 데이터를 변조된 광 신호로 바꾸는 과정이다.
- **광-전기 변환(Optical-to-Electrical Conversion, O/E)**: 수신 광 신호를 전기 데이터로 복원하는 과정이다.
- **광 송신부(Optical Transmitter)**: 전기 데이터를 레이저와 변조기로 광 신호로 바꾸는 구성이다.
- **WDM 결합•분리기(WDM Multiplexer•Demultiplexer)**: 여러 파장을 한 광섬유에 결합하고 수신단에서 분리하는 구성이다.
- **광섬유 경로(Optical-fiber Path)**: 다중 파장 광 신호를 낮은 손실로 전달하는 구성이다.
- **광 수신부(Optical Receiver)**: 들어온 빛을 전기 신호로 검출하고 클록•데이터를 복원하는 구성이다.

</details>

```text
[SerDes] -- [광 송신부] -- [WDM 결합•분리기]
                                      |
                           [광섬유 경로] -- [광 수신부]
```

선의 의미: 직렬 전기 인터페이스와 광 송신부, 파장 결합부, 광섬유, 광 수신부 사이의 정적 광전 링크 연결 관계다.

| 구성요소 | 책임 |
|:---|:---|
| SerDes | **직렬화•역직렬화** |
| 광 송신부 | **E/O 변환•변조** |
| WDM 결합•분리기 | **파장 다중화•분리** |
| 광섬유 경로 | **광 신호 전달** |
| 광 수신부 | **O/E 변환•클록 복원** |

#### 한줄 요약

- **SerDes•광전 변환•WDM•광섬유**의 종단 링크 구조이다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **링크 버짓**: 송신 광출력에서 경로 손실과 수신 감도를 반영해 계산한 수신 전력 여유이다.
- **파장 드리프트**: 온도 변화 등으로 레이저•변조기의 중심 파장이 이동하는 현상이다.

</details>

```text
[병렬 전기 데이터]
        │
        ▼
1. 직렬화•E/O 변조
        │
        ▼
2. WDM 파장 결합
        │
        ▼
3. 광섬유 전송
        │
        ▼
4. 파장 분리•O/E 복원
        │
        ▼
[병렬 수신 데이터]
```

**동작 원리**

1. **직렬화•E/O 변조**: 병렬 전기 데이터를 직렬화하고 레이저의 세기나 위상에 실어 광 신호로 변환한다.
2. **WDM 파장 결합**: 서로 다른 파장에 실린 여러 광 채널을 하나의 광섬유에 다중화한다.
3. **광섬유 전송**: 송신 광세기에서 커넥터•결합•섬유 손실을 제외한 신호를 수신부까지 전달한다.
4. **파장 분리•O/E 복원**: 수신부가 파장을 분리하고 광 신호를 전기 비트열과 병렬 데이터로 복원한다.

#### 한줄 요약

- 전기 데이터를 광 신호로 변환하고 WDM으로 전송한 뒤 **광 신호를 다시 전기 데이터로 복원**한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **광섬유**: 빛을 낮은 손실로 안내하여 장거리 전송하는 매체이다.
- **전기 인터커넥트**: 구리 배선의 전압•전류 신호로 데이터를 직접 전달하는 연결 방식이다.

</details>

| 인터커넥트 매체 | 광 인터커넥트 | 전기 인터커넥트 |
|:---|:---|:---|
| 적용 기준 | 전기 채널 한도 초과•**비트당 에너지 이득** | 전기 채널 한도 충족•**광전 변환 이득 없음** |
| 핵심 특징 | **광섬유•WDM** 장거리 전송 | **구리 배선•전압 신호** 직접 연결 |
| 한계 | **광전 변환•정렬•열 제어** | **감쇠•누화•등화 전력** |

> 요약: 전기 채널 한도 초과•종단 에너지 이득 구간만 **광 전환**이 핵심이다.

#### 한줄 요약

- 구리 채널이 거리•속도 한계에 이르고 광전 변환을 포함한 **종단 비트당 에너지**가 더 낮을 때 광 연결로 전환한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **삽입 손실**: 커넥터•결합기•광섬유를 통과하며 광출력이 감소하는 양이다.
- **비트당 에너지**: 한 비트를 종단까지 전달하는 데 소비되는 에너지이다.
- **곡률 반경**: 광섬유가 과도한 굽힘 손실 없이 유지해야 하는 최소 굽힘 크기이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 오염•굽힘•접속 손실로 **링크 버짓 부족** | **설치 전후 광세기 측정•청소•곡률 관리** | **다운트레이닝•링크 단절** 예방 |
| 온도 변화로 레이저•변조기 **파장 드리프트** | **온도 제어•파장•출력 감시** | **WDM 채널 분리** 유지 |
| 광 모듈 장애로 **고대역 경로 중단** | **이중 경로•교체 절차•예비 모듈** 운영 | **광 링크 복구 시간** 단축 |
| 광전 변환 전력이 거리 절감분을 넘어 **에너지 이득 소멸** | **종단 비트당 에너지•냉각•거리 비교** | **광 전환 거리** 결정 |

#### 한줄 요약

- **송수신 광세기•삽입 손실** 측정과 링크 버짓 보정이 핵심이다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **광 전환 거리**: 광전 변환 비용보다 전기 채널의 손실•등화 비용 절감이 커지는 거리이다.
- **등화**: 전기 채널의 주파수별 손실을 보상해 수신 신호를 복원하는 처리이다.

</details>

- 전기 손실 한도 초과•에너지 이득 시 **광 인터커넥트**를 적용한다.

#### 한줄 요약

- **광 전환 거리•비트당 에너지**를 만족하는 구간만을 적용한다.
