## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **광 인터커넥트(Optical Interconnect)**: 느려 터진 구리선을 다 뽑아버리고, 전기를 레이저 빛으로 바꿔서 광섬유로 쏴버리는 초고속 통신 마법이다.
- **전기광•광전 변환(E/O & O/E Conversion)**: 전기를 주면 불이 번쩍 켜지고(E/O), 빛을 쏘면 전기가 찌릿 흐르게(O/E) 만드는 상호 변환 기술이다.
- **동반 패키지 광학(Co-Packaged Optics, CPO)**: 광 변환기를 저 멀리 포트에 안 달고, 아예 메인 칩(ASIC) 바로 옆에 껌딱지처럼 딱 붙여서 전력 손실을 씹어먹는 패키징 꼼수이다.

</details>

- 정의: 무겁고 열 뿜어대는 구리선을 뜯어내고, 전기 데이터를 레이저 빛으로 바꿔서 광섬유로 쏴버리는 초고속 **광 인터커넥트** 기술
- 배경: 수만 대의 AI GPU가 미친 듯이 데이터를 주고받는데 구리선으로는 전파가 다 깎여먹고 발열 때문에 케이블이 다 타버려서, 아예 빛의 속도로 뚫어버리기 위함

#### 한줄 요약

- 발열과 속도 한계에 부딪힌 구리선 대신 전기 신호를 빛으로 바꿔서 광섬유로 쏘는 기술이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **파장 분할 다중화(Wavelength Division Multiplexing, WDM)**: 광섬유 한 가닥에 빨간불, 파란불, 노란불을 섞어 쏴서 데이터를 수십 배로 뻥튀기하는 무지개 통신 마법이다.
- **링크 버짓(Link Budget)**: 빛을 쐈을 때 중간에 유리가루에 부딪혀 깎여나가는 손실을 빼고도 "도착할 때 이 정도 빛은 남아있어야 해!" 하고 빡세게 잡아둔 생존 마지노선이다.
- **전자파 간섭(Electromagnetic Interference, EMI) 내성**: 옆에 발전기가 돌아가든 자석이 굴러다니든, 빛이라서 전자파 노이즈 따위는 1도 안 먹고 무시해버리는 깡패 특성이다.

</details>

- 구리선 특유의 데이터 깨짐과 전자파 노이즈(**전자파 간섭**)를 빛의 직진성으로 완벽하게 씹어먹음.
- 광섬유 가닥 하나에 여러 색깔의 레이저를 겹쳐 쏴서(**파장 분할 다중화**) 대역폭을 수십 배로 뻥튀기함.
- 빛을 쏠 때 중간에 깎여먹는 손실을 계산해서 도착할 때까지 신호가 살아남는지(**링크 버짓**) 빡세게 마진을 잡음.

#### 한줄 요약

- 노이즈도 없고(EMI 내성) 여러 빛을 섞어 쏠 수 있지만(WDM), 가는 동안 빛이 깎이는 손실(링크 버짓)을 관리해야 한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **서디스(Serializer/Deserializer, SerDes)**: 넓게 퍼진 데이터를 한 줄로 쫙 세워서 레이저 쏘기 좋게 밀어 넣고, 받을 땐 다시 넓게 풀어버리는 교통정리 칩이다.
- **실리콘 포토닉스 광 변조기(Silicon Photonics Modulator)**: 전기 신호가 찌릿 들어오면 "번쩍번쩍" 빛을 깜빡거리게 조작하는 반도체 광학 마술사이다.
- **결합•분리기(Mux/Demux)**: 쏠 때는 여러 빛깔을 억지로 하나로 합쳐서 쏘고(Mux), 받을 때는 프리즘처럼 다시 색깔별로 갈기갈기 찢어내는(Demux) 렌즈 장비이다.

</details>

```text
[ 광 인터커넥트 십자포화 변환 프레임워크 ]
       [ 광 송신부 ]                       [ 광 수신부 ]
[ 서디스 ] ── [ 실리콘 포토닉스 (E/O) ] ── [ Mux (빛 뭉치기) ] ── (광섬유) ── [ Demux (빛 찢기) ] ── [ 광 센서 (O/E) ] ── [ 서디스 ]
(전기 압축)         (전기를 빛으로)                                                    (빛을 전기로)       (전기 풀기)
```

| 구성요소 | 책임 |
|:---|:---|
| **서디스(SerDes)** | 넓게 퍼진 전기 데이터를 한 줄로 쫙 압축해서 레이저 쏘기 좋게 밀어 넣는 직렬화 칩 |
| **실리콘 포토닉스** | 전기가 들어오면 빛을 깜빡거리게 조작해서 전기 신호를 광 신호(E/O)로 갈아버리는 변환기 |
| **결합•분리기** | 쏠 때는 여러 빛깔을 하나로 합치고(**Mux**), 받을 때는 프리즘처럼 다시 색깔별로 찢어내는(**Demux**) 광학 필터 |
| 광 수신부(O/E) | 눈먼 빛을 카메라 센서(PD)로 찍어내서 다시 원래 전기 신호로 되돌려놓는 복원기 |

#### 한줄 요약

- 서디스로 압축한 전기를 실리콘 포토닉스로 빛으로 바꾸고(E/O), 뭉쳐서(Mux) 쏜 다음, 찢어서(Demux) 다시 전기로(O/E) 돌린다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **팸포 광 변조(Pulse Amplitude Modulation 4, PAM4)**: 그냥 껐다 켰다(0과 1) 하는 게 아니라, 빛의 밝기를 4단계(아주 밝음, 밝음, 어두움, 꺼짐)로 쪼개서 한 번에 데이터를 2배로 쑤셔 박는 꼼수이다.

</details>

```text
[ 광전 변환 및 파장 다중화 십자포화 송수신 흐름 ]
                                 │
                                 ▼
       [ 1. 전기 압축 및 변조: 전기를 한 줄로 세우고 빛을 4단계(PAM4)로 깜빡임 ]
                                 │
                                 ▼
      [ 2. 파장 짬뽕(Mux): 빨주노초파남보 여러 레이저를 하나로 무자비하게 합침 ]
                                 │
                                 ▼
         [ 3. 빛 전송: 깎이는 빛 손실(링크 버짓) 버티며 광섬유로 냅다 쏴버림 ]
                                 │
                                 ▼
  [ 4. 파장 찢기 및 복원(Demux): 도착한 짬뽕 빛을 다시 찢고, 광 센서로 읽어서 전기로 원상복구 ]
```

### 동작 원리

1. 전기 압축 및 변조: **서디스**가 데이터를 일렬로 세우고, **팸포** 변조기로 빛을 4단계 밝기로 깜빡거리게 만듦.
2. 파장 짬뽕(결합): 여러 색깔의 레이저를 **Mux**로 렌즈에 쑤셔 넣어서 하나로 뭉쳐버림.
3. 빛 전송: 깎여나가는 손실(**링크 버짓**)을 버티면서 광섬유를 타고 저 멀리 빛을 쏴버림.
4. 색깔 찢기 및 복원: 도착한 빛을 **Demux**로 다시 찢고, 광 센서로 읽어서 찌그러진 전기 신호를 완벽하게 복구함.

#### 한줄 요약

- 밝기 조절(PAM4)로 전기를 빛으로 바꾸고 섞어서 쏜 다음, 도착하면 찢어서 다시 전기로 복원한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **플러거블 광 모듈(Pluggable Transceiver)**: 10기가 이상 인터넷 뽑을 때, 서버 껍데기에 USB 메모리처럼 띡 꽂고 광케이블을 연결하는 쇳덩어리 모듈이다.

</details>

| 비교 항목 | **플러거블 광 모듈** (Pluggable Transceiver) | **동반 패키지 광학** (Co-Packaged Optics, CPO) |
|:---|:---|:---|
| 시스템 적용 최적 기준 | 서버 겉면에 USB 꽂듯이 뺐다 꼈다 하면서 장거리 통신망을 깔아야 할 시 | 엔비디아 AI 칩처럼 속도가 미쳐 날뛰어서 기판(보드) 안에서부터 빛으로 쏴야 할 시 |
| 아키텍처 핵심 구현 특징 | 스위치 껍데기에 구멍 뚫어놓고 광 모듈을 손으로 직접 꽂아 쓰는 고전적이고 편한 방식 | 칩이랑 광 변환기를 아예 메인보드에 찰싹 붙여서 용접해 버리는 극한의 밀착형 패키징 |
| 극복해야 할 태생적 한계점 | 칩에서 모듈까지 가는 구리선 구간에서 전기를 너무 많이 깎아먹고 열이 뻗침 | 칩 하나 고장 나면 용접된 보드를 통째로 뜯어내야 해서 유지보수가 지옥 그 자체 |

#### 한줄 요약

- 포트에 꽂아 쓰는 플러거블은 편하지만 구리선 손실이 있고, 메인보드에 용접하는 CPO는 빠르지만 고장 나면 지옥이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **파장 드리프트(Wavelength Drift)**: 기계가 열받으면 레이저 색깔이 빨간색에서 미세하게 주황색으로 틀어져서, 받을 때 에러가 터져버리는 짜증 나는 현상이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 광 변환기가 불타오르면서 레이저 색깔이 미세하게 틀어지는(**파장 드리프트**) 치명적 통신 붕괴 | 열받는 레이저 쏘는 놈(ELS)만 모듈 밖으로 시원하게 빼버리고 온도 조절기(TEC) 떡칠 | 온도가 튀어도 파장이 0.1nm도 안 흔들리는 극한의 광학 신뢰성 방어 |
| 메인보드 칩 옆에 광 모듈을 붙여버린 **CPO**에서 레이저가 고장 났을 때 기판 전체를 버려야 하는 참사 | 레이저 광원(ELS)만 따로 빼서 교체형으로 만들고 칩에는 빛만 밀어 넣게 개조 | 기판 뜯어내는 대공사 없이 레이저만 똑딱 갈아 끼우는 미친 유지보수성 확보 |
| 구멍만 한 광섬유 코어(10마이크로미터)에 빛을 쑤셔 넣다가 각도 틀어져서 빛이 다 새어버리는 대참사 | 렌즈 깎는 노인처럼 초정밀 능동 정렬(Active Alignment)로 빔 각도를 1도 단위로 멱살 잡고 꺾음 | 삽입 손실을 씹어먹고 **링크 버짓** 턱밑까지 빛을 100% 욱여넣는 광 효율 달성 |

#### 한줄 요약

- 레이저가 열받아 색깔이 틀어지는 건 밖으로 빼서 식히고, 빛이 새는 건 정밀하게 렌즈를 깎아서 막아라.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **광 인터커넥트 선택 기준(Optical Interconnect Selection Criteria)**: 속도가 얼마나 미쳐 날뛰는지, 기판을 통째로 갈아치울 용기가 있는지 따져보고 CPO를 박을지 말지 정하는 기준표이다.

</details>

- **광 인터커넥트 선택 기준** 원칙에 따라, 뺐다 꼈다 할 거면 **플러거블**, 칩 단에서부터 극한의 전력 다이어트가 필요하면 **CPO** 채택 기조 확립함

#### 한줄 요약

- 편하게 관리하려면 밖에서 꽂고, 칩의 미친 속도와 열을 감당하려면 보드에 박아버려라.
