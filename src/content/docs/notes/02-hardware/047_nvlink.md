## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **엔브이링크(NVLink)**: 메인보드의 좁아터진 기본 도로(PCIe)를 버리고, 엔비디아 그래픽 카드들끼리만 수백 기가바이트의 데이터를 빛의 속도로 쏟아부으며 집단으로 텐서를 공유할 수 있게 만든 그들만의 전용 아우토반이다.
- **인터커넥트(Interconnect)**: 칩과 칩, 메모리와 메모리가 서로 고립되지 않고 방대한 데이터를 서로 퍼 나를 수 있도록 거미줄처럼 엮어놓은 물리적 구리선과 광케이블 신호망이다.
- **홉(Hop)**: 데이터 택배가 출발지에서 목적지까지 갈 때 징검다리처럼 거쳐야 하는 정거장의 개수로, 이 개수가 많아질수록 속도는 처참하게 떨어지고 병목 현상이 폭발한다.

</details>

- 정의: 다중 그래픽 처리 장치 환경에서 굼뜬 호스트 중앙 처리 장치(CPU)를 거치지 않고, 그래픽 카드들끼리 피어 투 피어(P2P)로 텐서를 융단폭격하듯 쏘아대는 집단 통신을 가능케 하는 **엔브이링크** 전용 인터커넥트
- 배경: 컴퓨터의 기본 버스인 피시아이이(PCIe)의 처참한 대역폭 한계와, 데이터를 보낼 때마다 CPU를 거쳐야 해서 발생하는 무의미한 **홉** 증가 및 통신 병목을 박살 내기 위함

#### 한줄 요약

- CPU라는 좁은 톨게이트를 무시하고, 그래픽 카드들끼리 직접 전용 고속도로를 깔아 초거대 인공지능 모델 학습에 필요한 기가바이트급 텐서를 빛의 속도로 주고받는 엔비디아의 독점 규격이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **링크 결합(Link Aggregation)**: 두 그래픽 카드 사이에 전선 한 가닥만 연결하는 게 아니라, 6가닥 12가닥을 통째로 묶어 파이프를 무식하게 키워버림으로써 대역폭을 수백 GB/s로 뻥튀기하는 기술이다.
- **엔브이스위치(NVSwitch)**: 8개, 16개의 그래픽 카드가 서로 엉키지 않고 누구와 통신하든 차단 없이(Non-blocking) 텐서를 집어던질 수 있게 해주는 거대한 중앙 교환기 칩이다.
- **토폴로지(Topology)**: 그래픽 카드들을 원형으로 연결할지(링), 그물처럼 연결할지(메시) 등 선을 어떻게 배선하느냐에 따라 통신 효율이 극단적으로 달라지는 물리적 연결 지도이다.
- **집단 통신(Collective Communication)**: 수백 대의 그래픽 카드가 각자 계산한 텐서 조각들을 "하나, 둘, 셋" 하고 동시에 교환하여 하나의 거대한 정답 텐서로 뭉쳐내는 분산 학습의 꽃이다.

</details>

- 두 장치 간의 데이터 파이프를 무식하게 묶어 대역폭을 멀티플렉싱 확장하는 **링크 결합** 기술을 완벽히 지원함.
- 수십 대의 그래픽 장치 노드가 엉키지 않고 완전 무결한 다대다 통신을 보장하는 거대 칩인 **엔브이스위치** 라우팅을 제공함.
- 초거대 모델의 **집단 통신** 성능 극대화를 위해 선 낭비 없는 최적의 **토폴로지** 및 전송 패턴을 강제 적용함.

#### 한줄 요약

- 선을 여러 개 묶어 파이프를 키우고(링크 결합), 중간에 거대 스위치를 박아(NVSwitch) 수백 대의 칩이 병목 없이 동시에 데이터를 주고받게 만드는 통신 괴물이다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **엔비디아 집단 통신 라이브러리(NVIDIA Collective Communications Library)**: 수백 개의 칩이 엉키지 않고 텐서를 교환할 수 있도록, 기가 막힌 링(Ring) 알고리즘을 짜서 데이터 배달 순서를 완벽히 통제하는 엔비디아의 사기적인 통신 소프트웨어이다.
- **엔드포인트(Endpoint)**: 굵은 구리선과 광케이블이 그래픽 칩 안으로 꽂혀 들어오는 종착지이자, 데이터를 쏘고 받는 하드웨어 톨게이트이다.
- **패브릭(Fabric)**: 수많은 엔드포인트와 거대 스위치들이 씨줄과 날줄처럼 얽혀, 어디서 어디로 텐서를 쏘든 막힘없이 뚫려있는 거대한 네트워크 공간이다.

</details>

```text
[ 다중 그래픽 처리 장치 간 통신 소프트웨어 및 하드웨어 결합 아키텍처 ]
                   [ 딥러닝 프레임워크 (PyTorch 분산 학습 등) ]
                                         │
                                         ▼
      [ 엔비디아 집단 통신 라이브러리 (최적화 링 라우팅 알고리즘 통제) ]
                                         │ (전송 지시)
+----------------------------------------▼----------------------------------------+
| 서버 내부 및 외부 물리적 네트워크 계층                                          |
|                                                                                 |
| [ 그래픽 칩 1 엔드포인트 ]   <──(엔브이링크 초고속 구리선)──>   [ 그래픽 칩 2 엔드포인트 ] |
|            │                                                          │         |
|            └────────────────> [ 엔브이스위치 패브릭 망 ] <──────────────┘         |
+---------------------------------------------------------------------------------+
```

| 구성요소 | 책임 |
|:---|:---|
| **엔비디아 집단 통신 라이브러리** | 칩들이 어떻게 꽂혀있는지 물리망 지도를 파악하고, 최적의 링 알고리즘 작전을 수립하여 거대 텐서의 집단 통신 전개 |
| 그래픽 장치 **엔드포인트** 집합 | 거대 텐서 데이터 패킷의 물리적인 송수신 타격 및 칩 안의 하드웨어 피어 투 피어(P2P) 버퍼 제어 |
| **엔브이링크** 물리 전송 링크 | 다중 레인 묶음 기술을 적용한 초고속 차동 신호 송수신 물리 전송 구리선 및 광케이블 제공 |
| **엔브이스위치** 라우팅 **패브릭** | 차단 병목 없는 다대다 통신 라우팅, 거대 크로스바 스위칭 및 다중 노드 패킷의 초고속 융합 펌핑 |

#### 한줄 요약

- 똑똑한 통신 라이브러리(NCCL)가 작전을 짜면, 칩(엔드포인트)이 전용 고속도로(NVLink)와 거대 교차로(NVSwitch)를 통해 텐서를 미친 듯이 핑퐁 하는 구조이다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **올 리듀스(All-Reduce)**: 분산 학습의 핵심으로, 100대의 그래픽 카드가 각자 계산한 가중치 조각들을 한곳에 모아 합친(Reduce) 뒤, 완성된 결과물을 다시 100대에게 몽땅 뿌려주는(All) 극한의 집단 통신 연산이다.
- **리듀스 스캐터(Reduce-Scatter)**: 거대한 텐서를 쪼개서, A 칩은 앞부분만 합치고 B 칩은 뒷부분만 합치게끔 일을 흩뿌리는(Scatter) 전반전 통신 작업이다.
- **올 개더(All-Gather)**: 각자 합쳐놓은 조각들을 "자, 이제 하나로 합치자!" 하고 우르르 돌려가며 수집(Gather)하여 완전체를 만드는 후반전 통신 작업이다.
- **통신 조각(Communication Chunk)**: 수 기가바이트의 텐서를 한 번에 던지면 길이 막히니, 우편물 크기로 잘게 잘라 링을 따라 끊임없이 돌려대는 데이터 패킷이다.

</details>

```text
[ 엔비디아 집단 통신 라이브러리 기반 텐서 올 리듀스 집단 분산 통신 흐름 ]
                               │
                               ▼
        [ 1. 통신망 지형지물 파악 및 텐서 조각화 파이프라인 작전 수립 ]
                               │
                               ▼
        [ 2. 링 네트워크를 빙빙 돌며 부분합을 더하는 리듀스 스캐터 전개 ]
                               │
            +---------------------------------------+
            | N-1 단계의 피 피 말리는 핑퐁 전송 루프|
            |     3. 텐서 조각을 옆 칩으로 토스     |
            |     (동시에 내 연산기에서 덧셈 융합)  |
            +---------------------------------------+
                               │
                               ▼
       [ 4. 완성된 조각들을 다시 링으로 돌려 줍줍하는 올 개더 통신 교환 ]
                               │
                               ▼
            [ 5. 모든 칩이 완벽히 동일한 최종 텐서를 보유하고 훈련 속행 ]
```

### 동작 원리

1. 통신망 토폴로지 계획 수립: 통신 라이브러리가 물리망을 싹 파악하여 링 알고리즘 작전 및 **통신 조각** 분할 계획을 칼같이 수립함.
2. 리듀스 스캐터 실행 전개: 링 파이프라인을 따라 노드 개수만큼 **리듀스 스캐터** 핑퐁을 수행하며 거대 텐서 부분합을 분산 축소함.
3. 텐서 조각 피어 전송: 축소된 조각을 옆 노드로 끊임없이 던지는 와중에 로컬 연산기에서 덧셈을 동시에 겹쳐 실행하는 야바위를 부림.
4. 올 개더 통신 실행: 퍼즐이 맞춰진 합산 조각 텐서를 링 경로 상으로 다시 전파하여 모두가 줍줍하는 **올 개더** 교환을 맹렬히 전개함.
5. 전체 텐서 축소 완료: 링을 한 바퀴 다 돌면 모든 장치가 동일한 완전체 텐서를 보유하게 되며 멈춤 없이 다음 훈련 단계를 속행함.

#### 한줄 요약

- 통신 라이브러리가 텐서를 잘게 썰고, 칩들이 둥글게 앉아 조각을 옆으로 돌리며 합친 뒤(리듀스 스캐터), 완성본을 다시 돌려가며 나눠 갖는(올 개더) 숨 가쁜 군무이다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **직접 엔브이링크(Direct NVLink)**: 스위치 같은 거추장스러운 장비 없이, 그래픽 카드끼리 다이렉트로 전선을 꽂아버려(점대점) 초저지연으로 통신하는 낭만적이지만 확장이 불가능한 방식이다.
- **엔브이스위치 패브릭(NVSwitch Fabric)**: 수십 대의 칩을 직결하는 건 물리적으로 불가능하니, 중간에 엄청나게 비싼 거대 스위치 칩을 매개로 하여 그물을 짜놓은 확장성 끝판왕 통신망이다.
- **피시아이익스프레스(PCI Express)**: 컴퓨터 부품이면 무조건 호환되는 만국 공통의 톨게이트 버스지만, 대역폭이 좁아터져 인공지능 텐서를 옮기다간 속 터져 죽는 시스템 버스이다.

</details>

| 비교 항목 | **직접 엔브이링크** (Direct NVLink) | **엔브이스위치 패브릭** (NVSwitch) | **피시아이익스프레스** (PCIe) |
|:---|:---|:---|:---|
| 시스템 적용 최적 기준 | 서버 1대 안에 들어가는 8대 이하 소규모 장치의 강력한 직결 피어 투 피어(P2P) 연결 시 | 돈을 쏟아부어 수백 대 서버를 엮는 전대역폭 무차단 다대다 연결망 요구 시 | 인공지능 칩과 네트워크 카드, 저장장치 등 이기종 범용 장치들을 한 보드에 연결 시 |
| 아키텍처 핵심 구현 특징 | 스위치 없는 점대점 물리적 링 또는 메시 토폴로지로 선을 무식하게 꽂아버리는 직결 방식 | 보드 중간에 거대 전용 스위치 칩을 여러 개 박아놓은 중앙 집중형 초고속 네트워크 라우팅 | 컴퓨터 시스템 메인보드에 뿌리내린 범용 표준의 트리 구조 톨게이트 버스 라우팅 |
| 극복해야 할 태생적 한계점 | 칩 옆구리에 뚫린 포트 개수만큼만 선을 꽂을 수 있어 대규모 노드로의 토폴로지 확장 절대 불가 | 시스템 보드 단가 폭증 및 공랭식으론 열을 식힐 수 없어 수냉을 돌려야 하는 끔찍한 전력 소모 | 인공지능 모델을 돌리기엔 처참한 대역폭 한계 및 무조건 CPU를 거쳐야 하는 심각한 **홉** 지연 병목 |

#### 한줄 요약

- 소규모로 묶을 땐 직결(Direct NVLink)이 최고고, 수백 대를 묶어 슈퍼컴퓨터를 만들 땐 돈을 털어 스위치(NVSwitch)를 박아야 하며, 그 외의 찌끄레기 장비들은 굼뜬 PCIe 버스에 물린다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **프로세스 샤드 배치(Process Shard Placement)**: 통신을 미친 듯이 주고받아야 하는 두 인공지능 프로세스를, 멍청하게 먼 칩에 배정하지 않고 물리적 전선이 가장 굵게 연결된 바로 옆 칩에다 짝지어주는 소프트웨어 최적화 기법이다.
- **꼬리 지연(Tail Latency)**: 100대의 칩 중 단 1대의 칩이나 케이블이 맛이 가서 굼벵이 짓을 하면, 나머지 99대가 통신을 끝내고도 이 1대를 기다리느라 전체 훈련이 멈춰버리는 끔찍한 연대책임 지연 현상이다.
- **통신 연산 중첩(Communication-Computation Overlap)**: 텐서를 칩 밖으로 택배 보내는 시간(통신) 동안 연산 코어를 놀리지 않고, 다음 텐서를 미리 당겨와 곱셈(연산)을 시킴으로써 통신 지연 시간을 장부에서 지워버리는 사기 기법이다.
- **링크 감시(Link Monitoring)**: 수만 가닥의 구리선 중 열을 받아 끊어지거나 에러를 뿜는 놈이 없는지 1초 단위로 감시하고, 문제 발생 시 즉각 그 선을 잘라내 통신 마비를 막는 관제 시스템이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 멍청한 프로세스 배치로 멀리 돌아가는 홉 통신 오버헤드 유발 및 전체 클러스터가 멈추는 치명적 **꼬리 지연** | 통신 라이브러리가 토폴로지를 인지하여, 짝꿍끼리 선이 굵은 포트에 붙여주는 **프로세스 샤드 배치** 알고리즘 최적화 | 쓸데없는 홉 톨게이트 경유를 최소화하고, 특정 선만 불타오르는 통신 대역폭 부하 쏠림 균형 완벽 확보 |
| 통신망으로 텐서를 핑퐁 하느라 수만 개의 값비싼 연산 코어가 손가락을 빨며 멈춰버리는 유휴 참사 | 칩 안에서 비동기 스트림 기술을 영혼까지 끌어모은 **통신 연산 중첩** 꼼수 기법 적극 적용 | 치명적인 데이터 전송 지연시간을 칩 내부 코어 연산 시간 뒤로 완벽하게 은닉(가림) 달성 |
| 물리적 구리선 커넥터 불량 또는 극한 발열 결함으로 인해 특정 케이블의 통신 대역폭이 급감하는 둔화 | 실시간 텔레메트리 **링크 감시** 가동 및 에러 뿜는 비정상 죽은 레인을 런타임에 강제 격리 조치 | 구리선 몇 개 끊어져도 대규모 훈련 클러스터 패브릭 전송망이 마비되지 않는 100% 안정성 보장 |

#### 한줄 요약

- 통신이 잦은 놈끼리 묶어주고(샤드 배치), 통신할 때 연산도 같이 돌려 지연을 가리며(연산 중첩), 선이 끊어졌는지 매초 감시해야(링크 감시) 천문학적인 돈이 들어간 서버가 안 멈춘다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **GPU 연결 선택 기준(GPU Interconnect Selection Criteria)**: 칩을 몇 대나 엮을 건지, 텐서 교환 대역폭이 얼마나 미친 듯이 필요한지, 그리고 예산(TCO)이 얼마인지를 들이대어 직결할지 스위치를 살지 결정하는 잔인한 견적서이다.

</details>

- **GPU 연결 선택 기준**에 따라 8대 이하 소규모 노드는 저렴한 **직접 엔브이링크**, 거대 학습용 수백 대 노드는 억 소리 나는 **엔브이스위치** 적용을 단호히 결정함

#### 한줄 요약

- 서버 한 대 안에서 그래픽 카드 몇 장 엮을 땐 선만 꽂으면(직접 NVLink) 충분하지만, 데이터센터 규모로 엮어 딥러닝 끝판왕을 보려면 스위치(NVSwitch)에 전 재산을 털어 넣어야 한다.
