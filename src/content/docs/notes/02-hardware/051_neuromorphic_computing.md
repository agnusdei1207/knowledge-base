## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **뉴로모픽 컴퓨팅(Neuromorphic Computing)**: 0과 1로 계산하는 차가운 컴퓨터 로직을 버리고, 인간 뇌의 뉴런과 시냅스가 전기를 찌릿찌릿 튕기며 신호를 주고받는 생물학적 메커니즘을 반도체로 징그럽게 흉내 낸 두뇌 모방 칩이다.
- **스파이크(Spike)**: 뉴런들이 대화할 때 쓰는 신호로, 특정 임계치를 넘을 때만 "찌릿!" 하고 전압 펄스를 한 번 튕기는 극도로 이기적이고 효율적인 비동기 이벤트이다.
- **이벤트 기반 처리(Event-Driven Processing)**: 컴퓨터처럼 무식하게 1초에 수십억 번씩 심장(클록)을 뛰게 하며 전기를 낭비하지 않고, 밖에서 입력(이벤트)이 들어온 그 찰나의 순간에만 번쩍 눈을 떠서 연산하는 궁극의 게으른(저전력) 방식이다.

</details>

- 정의: 생물학적 뇌 신경망의 뉴런과 시냅스 활동 전위 동작을 하드웨어 반도체 로직으로 흉내 내어 구현한 **뉴로모픽 컴퓨팅**
- 배경: 기존 폰 노이만 구조의 클록 기반 주기적 연산으로 인한 무의미한 전력 낭비 및 메모리 벽(Memory Wall) 병목의 한계를 근본적으로 타파하기 위함

#### 한줄 요약

- CPU처럼 멍청하게 계속 전기를 먹으며 헛돌지 않고, 입력에 변화가 생겨 뉴런이 '찌릿'할 때만 연산 스위치를 켜서 배터리를 극한으로 아끼는 뇌 모방 인공지능 칩이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **스파이킹 신경망(Spiking Neural Network)**: 숫자를 곱하는 기존 딥러닝을 혐오하며, 전압 펄스가 언제 튀었는지(타이밍)와 얼마나 자주 튀었는지(빈도)만으로 정보를 인코딩하는 3세대 인공신경망이다.
- **희소 이벤트(Sparse Event)**: CCTV 화면에서 아무 일도 없을 땐 침묵하다가, 도둑이 지나가서 픽셀이 변하는 그 찰나의 희귀한 순간에만 스파이크가 튀어 오르는 지독하게 짜임새 있는 특성이다.
- **근접 메모리 연산(Near-Memory Computing)**: 뇌가 생각(연산)과 기억(메모리)을 한곳에서 하듯, 칩 내부의 연산기 바로 옆에 메모리를 딱 붙여놔서 데이터를 멀리 퍼 나르느라 버려지는 전기세를 원천 봉쇄하는 구조이다.

</details>

- 시간과 전압 펄스 신호의 빈도로 정보를 인코딩하는 생물학적 **스파이킹 신경망** 알고리즘을 강제 적용함.
- 입력 데이터 변화가 없는 구간에서는 하드웨어 전원 스위치를 내려 전력 소모를 차단하는 **희소 이벤트** 구동을 구현함.
- 무거운 시냅스 가중치 파라미터를 인출하느라 낭비되는 전력을 극소화하기 위해 연산기 옆에 메모리를 박아 넣은 **근접 메모리 연산**을 수행함.

#### 한줄 요약

- 전압 펄스(스파이크)로 통신하고(SNN), 변화가 없으면 칩을 재우며(희소 이벤트), 기억과 연산을 한곳에서 뭉쳐(근접 연산) 극초저전력을 실현한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **스파이크 인코더(Spike Encoder)**: 카메라나 마이크에서 들어오는 평범한 아날로그 신호를 뇌가 알아먹을 수 있는 "찌릿" 하는 펄스 이벤트 패킷으로 썰어서 번역해 주는 관문 회로이다.
- **이벤트 라우터(Event Router)**: 인코더가 만든 펄스 패킷을 칩 안의 수백만 개 뉴런 중 정확히 목적지 뉴런 코어로 길을 잃지 않고 배달해 주는 온칩 네트워크(NoC) 우체부이다.
- **시냅스 메모리(Synaptic Memory)**: 뉴런과 뉴런 사이의 연결 강도(가중치)를 기억하고 있다가, 펄스가 도착하면 그 강도만큼 전압을 증폭시키거나 줄여서 넘겨주는 두뇌의 기억 저장소이다.
- **뉴런 코어(Neuron Core)**: 옆 뉴런들에서 날아온 전압 펄스들을 모금함(막전위)에 계속 적립하다가, 꽉 차서 임계치를 넘는 순간 쾅! 하고 새로운 스파이크를 방출하는 핵심 연산 세포이다.

</details>

```text
[ 뉴로모픽 생물학적 뇌 모방 비동기 스파이크 연산 하드웨어 아키텍처 ]
     [ 카메라 / 오디오 센서의 아날로그 및 디지털 혼합 입력 스트림 ]
                               │
                               ▼
      [ 스파이크 인코더 (일반 데이터를 뇌의 찌릿 펄스로 인코딩 번역) ]
                               │
+------------------------------▼------------------------------+
| 뉴로모픽 칩 내부 이벤트 네트워크                            |
|                                                             |
|           [ 이벤트 라우터 (온칩 네트워킹 우체부) ]          |
|                   /                        \                |
|                  ▼                          ▼               |
|      [ 뉴런 코어 및 껌딱지처럼 붙어있는 시냅스 메모리 묶음 ]|
+-------------------------------------------------------------+
```

| 구성요소 | 책임 |
|:---|:---|
| **스파이크 인코더** | 아날로그 센서 입력 신호를 시간 및 주소 기반의 이산 펄스 **스파이크** 데이터로 인코딩 번역 변환 |
| **이벤트 라우터** | 발생된 펄스 패킷을 칩 내부 네트워크망을 통해 목적지 타깃 뉴런 코어로 저지연 라우팅 핑퐁 전송 |
| **시냅스 메모리** 및 인프라 | 뉴런 간의 결합 가중치 파라미터 보관 및 칩의 전기세를 아끼기 위한 초저전력 **근접 메모리 연산** 물리적 수용 |
| **뉴런 코어** 연산 로직 | 전압 게이지(막전위) 누적 및 폭발(발화 임계값) 제어를 통한 새로운 **스파이크** 방출 연산 수행 |

#### 한줄 요약

- 인코더가 신호를 스파이크로 썰면, 우체부(라우터)가 목적지로 배달하고, 뉴런 코어가 시냅스 메모리를 참조해 전압을 쌓다가 터뜨리는 뇌 시뮬레이터 칩이다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **주소 이벤트 표현(Address-Event Representation)**: 스파이크 패킷이 길을 잃지 않도록, 이 펄스가 '언제', '어느 뉴런'에서 발생했는지 주소를 꼬리표처럼 달아놓은 비동기 디지털 통신 포맷이다.
- **막전위(Membrane Potential)**: 뉴런 코어 내부에 존재하는 물통 같은 것으로, 스파이크가 도착할 때마다 수위(전압)가 찰랑찰랑 올라가는 누적 상태값이다.
- **발화 임계값(Firing Threshold)**: 막전위 물통의 높이로, 이 선을 넘치게 되면 뉴런이 더 이상 참지 못하고 새로운 스파이크를 토해내는 트리거 기준 전압이다.

</details>

```text
[ 뉴로모픽 코어 스파이크 이벤트 연산 및 발화 폭발 제어 흐름 ]
                               │
                               ▼
    [ 1. 센서 이벤트 감지 시 주소 이벤트 표현(AER) 포맷 스파이크 생성 ]
                               │
                               ▼
  [ 2. 이벤트 라우터를 통한 목적지 뉴런 탐색 및 시냅스 가중치 전압 조회 ]
                               │
                               ▼
        [ 3. 뉴런 코어로 시냅스 가중치가 곱해진 펄스 전류 신호 인가 ]
                               │
                               ▼
   [ 4. 물통(막전위)에 전압을 누적하고 폭발 한계선(발화 임계값) 도달 판정 ]
                               │
            +---------------------------------------+
            |      [ 전압이 임계값을 넘었는가? ]    |
            |      /                        \       |
            |   [ 예 ]                   [ 아니요 ] |
            |     │                          │      |
            | 5. 쾅! 스파이크 방출       물통 전압 보존 |
            | 및 물통 0으로 리셋        (다음 펄스 대기)|
            +---------------------------------------+
```

### 동작 원리

1. 센서 이벤트 감지 인코딩: 입력 센서의 유의미한 픽셀 데이터 변화 감지 시 **주소 이벤트 표현**(AER) 포맷 기반의 스파이크 이벤트를 생성함.
2. 목적지 펄스 라우팅 전송: **이벤트 라우터**를 통해 목적지 뉴런 코어를 탐색하고 해당 펄스를 정밀하게 라우팅함.
3. 시냅스 가중치 펄스 인가: 뉴런 코어에 도달 시 껌딱지 **시냅스 메모리** 가중치가 반영된 펄스 전류 신호를 칩에 인가함.
4. 막전위 누적 임계값 판정: 뉴런의 누수 적분 발화 모델(LIF) 기반으로 **막전위** 물통에 전압을 누적하고 뇌의 **발화 임계값**과 엄격히 비교함.
5. 신규 스파이크 발화 방출: 임계값 도달 시 뇌가 스파크를 튀기듯 새로운 스파이크를 다음 뉴런으로 방출하고 즉시 막전위를 초기화함.

#### 한줄 요약

- 스파이크가 도착할 때마다 뉴런의 물통(막전위)에 물을 채우고, 찰랑이다가 물이 넘치는 순간(임계값 도달) 다음 뉴런으로 스파이크를 토해내는 반복 작업이다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **폰 노이만 인공지능 가속기(Von Neumann AI Architecture)**: 심장병 걸린 듯 1초에 수십억 번 강제로 뛰는 클록에 맞춰, 끊임없이 메모리에서 데이터를 퍼 나르며 행렬을 갈아버리는 피곤한 GPU/NPU 구조이다.
- **조밀 텐서(Dense Tensor)**: 행렬 안에 빈칸(0) 없이 쓸데없는 숫자들까지 꽉꽉 들어차 있어, 칩이 하나하나 계산하느라 전기세를 미친 듯이 빨아먹는 딥러닝 텐서의 고질적 형태이다.
- **비동기 연산(Asynchronous Computing)**: 전체 칩을 통제하는 꼰대 같은 중앙 클록 시계열 없이, 각 뉴런이 입력이 들어올 때만 알아서 일하고 다시 자는 눈치 게임식 실행 형태이다.

</details>

| 비교 항목 | **뉴로모픽 컴퓨팅** (Event-Driven) | 기존 **폰 노이만 인공지능 가속기** (Clock-Driven) |
|:---|:---|:---|
| 시스템 적용 최적 기준 | 드론이나 센서의 **희소 이벤트** 감지 및 좁쌀 배터리로 수년을 버텨야 하는 극단적인 초저전력 상시 추론 환경 시 | **조밀 텐서** 기반 초거대 언어 모델(LLM)의 무자비한 대규모 병렬 연산 및 99% 이상의 완벽한 정확도 요구 시 |
| 아키텍처 핵심 구현 특징 | 생물학적 뇌 구조 모방의 **스파이킹 신경망**(SNN) 알고리즘 및 클록 없는 100% **비동기 연산** 하드웨어 | 중앙 클록 동기화 타이밍에 맞춰 행렬을 미친 듯이 갉아먹는 조밀 텐서 연산 코어 융단폭격 배열 구조 |
| 극복해야 할 태생적 한계점 | 기존 딥러닝을 스파이킹 신경망으로 억지 변환 시 발생하는 치명적 정확도 붕괴 저하 및 학습 알고리즘의 끔찍한 미성숙 | 폰 노이만 메모리 벽(Memory Wall) 병목 구조로 인한 처참한 지연 및 연산기가 쉴 때도 타오르는 상시 전력 누수 낭비 |

#### 한줄 요약

- 배터리로 버티며 아주 드물게 일어나는 사건(이벤트)만 감지할 땐 뉴로모픽이 최고지만, 거대한 언어 모델을 돌리거나 0.1% 정확도에 목숨을 걸 땐 기존 폰 노이만 가속기(GPU/NPU)를 써야 한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **이벤트율(Event Rate)**: 조용하던 환경이 갑자기 미쳐 날뛰어서(예: 나뭇잎이 미친 듯이 흔들림) 센서가 감당 못 할 스파이크를 초당 수백만 개씩 뿜어내는 끔찍한 유입 빈도이다.
- **타임스탬프(Timestamp)**: 클록이 없는 자유분방한 칩 안에서 스파이크들이 도착 순서가 꼬여 뇌가 바보가 되는 걸 막기 위해, 패킷에 "몇 시 몇 분 발생"이라고 찍어놓는 출생증명서이다.
- **이벤트 카메라(Event-Based Camera)**: 동영상을 초당 60장씩 멍청하게 계속 찍지 않고, 화면에서 픽셀이 움직인 그 지점만 찰나의 순간에 펄스로 쏘아 보내는 뉴로모픽 전용 괴물 센서(DVS)이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 입력 데이터가 미친 듯이 급변하여 폭증한 **이벤트율**에 의한 온칩 라우터 병목 및 패킷 붕괴 | 물통 폭발 기준을 빡세게 높이는 동적 임계값 제어 및 펄스 버퍼 큐 확장 최적화 조치 | 쓸데없는 스파이크 폭주 발화를 막고 칩 내부 라우팅 패킷 손실 및 지연을 원천 방지 달성 |

#### 한줄 요약

- 스파이크 폭주를 막기 위해 임계값을 쥐어짜고, 순서 꼬임을 막기 위해 타임스탬프를 찍으며, 전력 낭비를 막기 위해 프레임 카메라 대신 이벤트 카메라를 붙여야 진정한 뉴로모픽이 완성된다.
