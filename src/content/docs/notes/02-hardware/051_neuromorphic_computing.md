## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **뉴로모픽 컴퓨팅(Neuromorphic Computing)**: 인간 두뇌의 생물학적 신경망 구조와 뉴런·시냅스의 스파이크 신호 전달 방식을 모방한 비 폰 노이만 아키텍처.
- **SNN(Spiking Neural Network)**: 연속적인 실수 값 대신 시간에 따른 스파이크(전기 펄스)의 발생 타이밍으로 정보를 표현하고 처리하는 3세대 신경망.

</details>

- 정의/개념: **SNN(Spiking Neural Network)**의 스파이크 신호와 이벤트 구동 처리를 하드웨어로 구현해 저전력 연산을 노리는 **뉴로모픽 컴퓨팅(Neuromorphic Computing)**
- 배경/필요성: 상시 센서를 주기적으로 샘플링하면 아무 변화가 없는 구간에도 메모리 접근과 전력 소모가 그대로 유지됨

#### 한줄 요약
- 이 방식의 이득은 연산 효율이 아니라 아무 일도 하지 않을 수 있다는 데 있으므로, 입력이 늘 변하는 환경에서는 이점이 사라진다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **이벤트 구동(Event-Driven)**: 고정된 클록마다 모든 연산기를 구동하는 대신, 입력 변화나 스파이크가 발생한 순간에만 회로를 활성화하는 처리 방식.
- **인메모리 연산(In-Memory Computing)**: 별도의 연산기(ALU) 없이 가중치가 저장된 메모리 셀 어레이 내부에서 아날로그 또는 디지털 연산을 직접 완료하는 기술.

</details>

- SNN 기반으로 값의 크기가 아니라 발생 시점에 정보를 실어 시계열 처리
- 변화가 있을 때만 반응하는 **이벤트 구동(Event-Driven)** 비동기 처리
- **인메모리 연산(In-Memory Computing)**으로 시냅스 가중치를 저장한 자리에서 곧바로 계산

#### 한줄 요약
- 세 특징이 모두 폰 노이만 구조의 전제를 하나씩 버린 결과이며, 그래서 기존 소프트웨어 자산을 거의 그대로 쓸 수 없다는 대가가 따른다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **AER(Address-Event Representation)**: 스파이크를 발생시킨 뉴런의 2차원 주소와 발생 시간(Timestamp)을 패킷으로 묶어 전송하는 프로토콜.
- **LIF(Leaky Integrate-and-Fire)**: 입력 스파이크를 누산하다가 막전위(Membrane Potential)가 임계값을 넘으면 스파이크를 발화(Fire)하고 감쇄(Leak)하는 뉴런 모델.

</details>

```text
[뉴로모픽 시스템]
├─ 이벤트 기반 센서 (변화 픽셀만 스파이크 출력)
├─ AER 비동기 라우터 (글로벌 클록 없는 핸드셰이크 중계)
└─ 뉴로모픽 코어 × N
   ├─ 시냅스 메모리 어레이 (가중치 저장·RRAM·SRAM)
   └─ LIF 뉴런 연산 유닛 (막전위 적분·발화·리셋)
```

선의 의미: 가지(`├─`)는 소유 관계이며, 전 구간에 공통 클록이 없어 스파이크가 도착할 때만 각 단계가 깨어남

| 구성요소 | 책임 |
|:---|:---|
| 이벤트 기반 센서 | 변화가 있는 픽셀만 마이크로초 단위 스파이크로 출력 |
| **AER(Address-Event Representation)** 라우터 | 공통 클록 없이 뉴런 주소·시각 패킷 중계 |
| 시냅스 어레이 (Synapse) | 뉴런 간 연결 가중치를 저장하고 입력 스파이크에 가중치 반영 |
| **LIF(Leaky Integrate-and-Fire)** 뉴런 회로 | 막전위 적분과 임계 도달 시 발화·리셋 |

#### 한줄 요약
- 시냅스 어레이가 메모리이면서 연산기라는 점이 구조의 핵심이며, 저장과 계산의 경계를 없앤 대가로 정밀도를 소자 특성에 맡기게 된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **STDP(Spike-Timing-Dependent Plasticity)**: 시냅스 전 뉴런과 시냅스 후 뉴런의 스파이크 발화 시간 차이에 따라 시냅스 연결 강도를 강화하거나 약화시키는 학습 규칙.

</details>

```text
외부 환경 변화 발생 (빛·소리 등)
        │
   변화가 센서 임계를 넘는가?
   ┌────┴─────┐
아니오          예
   │             │
회로 유휴 유지   AER 패킷화 후 라우터 전송
(전력 소모 없음)  │
   │        시냅스 가중치를 입력에 반영
   │             │
   │        LIF 막전위가 임계를 넘는가?
   │        ┌────┴─────┐
   │      아니오          예
   │        │             │
   │     누설 감쇄 후    스파이크 발화 후 리셋
   │     다음 입력 대기    │
   │        │        온라인 학습 시 STDP로 가중치 갱신
   └────┬───┴─────────────┘
        │
   다음 이벤트 대기
```

분기 결과: 두 임계가 연달아 걸러 내므로 대부분의 시간에는 회로가 아예 깨어나지 않으며, 전력 소모가 입력량이 아니라 변화량에 비례하게 됨

#### 한줄 요약
- **STDP(Spike-Timing-Dependent Plasticity)**가 발화 흐름 안에 들어 있어 학습과 추론이 분리되지 않으며, 이 점이 온라인 적응의 근거이자 정확도 보증을 어렵게 만드는 원인이다.

## Ⅴ. 종류 및 비교

| 신경망 컴퓨팅 아키텍처 | 뉴로모픽 (SNN) | 심층신경망 (ANN/NPU) | 양자 컴퓨팅 | 전통 폰 노이만 (CPU) |
|:---|:---|:---|:---|:---|
| 적용 기준 | 초저전력 상시 감시 엣지·음성/생체 센서 | 대규모 고정밀 비전/LLM 학습 및 추론 | 조합 최적화 및 양자 암호·시뮬레이션 | 복잡한 범용 제어 및 순차 프로그램 |
| 핵심 특징 | 스파이크 이벤트 구동과 분산 상태 저장 | 연속값 텐서의 행렬 곱셈 가속 | 큐비트 중첩·얽힘 기반 연산 | 범용 명령 실행과 다단계 캐시 |
| 한계 | 학습·도구·정확도 평가 생태계 미성숙 | 메모리 이동과 대기 전력 부담 | 오류 교정과 하드웨어 규모 제약 | 대규모 행렬 연산의 전력 효율 제약 |

#### 한줄 요약
- 네 구조 중 뉴로모픽만 정확도를 최우선으로 두지 않으므로, 비교 기준을 정확도로 잡는 순간 이 기술의 존재 이유가 지워진다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **ANN-to-SNN 변환**: 학습이 용이한 표준 심층신경망(CNN 등)을 먼저 학습시킨 후 뉴로모픽용 SNN으로 변환 배포하는 소프트웨어 기술.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 스파이크가 불연속이라 기울기 계산 불가 | 대리 기울기 기법과 **ANN-to-SNN 변환** 적용 | 기존 딥러닝 모델을 SNN으로 이식 |
| 스파이크 폭증 시 라우터 병목 | 계층형 라우팅과 이벤트 필터·발생률 제한 적용 | 혼잡과 스파이크 손실 위험 완화 |
| 아날로그 소자 산포로 가중치 값이 흔들림 | 디지털·아날로그 하이브리드 시냅스와 노이즈 인식 학습 | 추론 정확도 신뢰성과 수율 확보 |
| 기존 딥러닝 프레임워크(PyTorch 등)와의 호환성 부족 | Lava, SpikingJelly 등 오픈소스 SNN 전용 미들웨어 연동 | 개발 진입 장벽 완화 및 배포 단축 |

#### 한줄 요약
- 네 문제 중 셋이 하드웨어가 아니라 학습·도구 쪽에 있으며, 이 기술이 오래 상용화 문턱을 넘지 못한 이유도 칩이 아니라 그 주변에 있다.

## Ⅶ. 결론

- 입력이 희소하고 상시 감시 전력이 핵심 제약이면 **뉴로모픽 컴퓨팅(Neuromorphic Computing)**을 검토하고, 고정밀 밀집 텐서 연산은 NPU·GPU로 보낸 뒤 실제 이벤트 발생률로 재판단

#### 한줄 요약
- 도입 판단의 실제 변수는 칩 성능이 아니라 입력이 얼마나 자주 변하느냐이며, 이 값이 낮을 때만 이 구조가 다른 모든 약점을 상쇄한다.
