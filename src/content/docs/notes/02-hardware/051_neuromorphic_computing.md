## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **뉴로모픽 컴퓨팅(Neuromorphic Computing)**: 인간 두뇌의 생물학적 신경망 구조와 뉴런·시냅스의 스파이크 신호 전달 방식을 모방한 비 폰 노이만 아키텍처.
- **SNN(Spiking Neural Network)**: 연속적인 실수 값 대신 시간에 따른 스파이크(전기 펄스)의 발생 타이밍으로 정보를 표현하고 처리하는 3세대 신경망.

</details>

- 정의/개념: 인간 뇌의 뉴런과 시냅스 동작을 모방하여 **스파이크 신호(SNN)** 기반 이벤트 구동 방식으로 초저전력 연산을 수행하는 뇌신경 모방 반도체 기술
- 배경/필요성: 폰 노이만 구조의 **메모리-연산기 간 데이터 이동 병목** 및 막대한 소비 전력 한계 직면

#### 한줄 요약
- 뇌의 뉴런이 전기 신호를 쏠 때만 일하듯, 이벤트가 일어날 때만 계산해 소비 전력을 획기적으로 줄인 반도체다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **이벤트 구동(Event-Driven)**: 고정된 클록마다 모든 연산기를 구동하는 대신, 입력 변화나 스파이크가 발생한 순간에만 회로를 활성화하는 처리 방식.
- **인메모리 연산(In-Memory Computing)**: 별도의 연산기(ALU) 없이 가중치가 저장된 메모리 셀 어레이 내부에서 아날로그 또는 디지털 연산을 직접 완료하는 기술.

</details>

- **스파이킹 신경망(SNN)** 기반 시간 축 정보를 활용한 시계열 이벤트 처리
- 변화가 있을 때만 반응하는 **이벤트 구동(Event-Driven)** 비동기 처리
- 연산기와 메모리가 물리적으로 융합된 **인메모리(In-Memory)** 구조로 버스 병목 원천 차단

#### 한줄 요약
- 스파이크 신호가 들어올 때만 뉴런 내부 메모리에서 즉시 계산하여 마이크로와트($\mu W$) 수준의 전력으로 작동한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **AER(Address-Event Representation)**: 스파이크를 발생시킨 뉴런의 2차원 주소와 발생 시간(Timestamp)을 패킷으로 묶어 전송하는 프로토콜.
- **LIF(Leaky Integrate-and-Fire)**: 입력 스파이크를 누산하다가 막전위(Membrane Potential)가 임계값을 넘으면 스파이크를 발화(Fire)하고 감쇄(Leak)하는 뉴런 모델.

</details>

```text
┌─────────────────────────────────────────────────────────────┐
│ 뉴로모픽 코어 및 비동기 NoC 상호 연결 구조                 │
│                                                             │
│  [ 이벤트 센서 (DVS) ]                                      │
│         │ (AER 비동기 스파이크 패킷)                        │
│  ┌──────▼────────────────────────────────────────────────┐  │
│  │ 비동기 패킷 라우터 (Asynchronous AER Router)           │  │
│  └──────┬────────────────────────┬───────────────────────┘  │
│         ▼                        ▼                          │
│  ┌───────────────────────┐┌───────────────────────┐         │
│  │ 뉴로모픽 코어 A       ││ 뉴로모픽 코어 B       │         │
│  │ ┌───────────────────┐ ││ ┌───────────────────┐ │         │
│  │ │ 시냅스 메모리 어레이│ ││ │ 시냅스 메모리 어레이│ │         │
│  │ │ (가중치 저장소)   │ ││ │ (RRAM / SRAM)    │ │         │
│  │ └─────────┬─────────┘ ││ └─────────┬─────────┘ │         │
│  │           ▼           ││           ▼           │         │
│  │ ┌───────────────────┐ ││ ┌───────────────────┐ │         │
│  │ │ LIF 뉴런 연산 유닛│ ││ │ LIF 뉴런 연산 유닛│ │         │
│  │ └───────────────────┘ ││ └───────────────────┘ │         │
│  └───────────────────────┘└───────────────────────┘         │
└─────────────────────────────────────────────────────────────┘
```

선의 의미: DVS 센서에서 생성된 스파이크가 AER 라우터를 거쳐 뉴런 코어로 전달되며, 시냅스 가중치와 결합해 LIF 발화 수행

| 구성요소 | 책임 |
|:---|:---|
| 이벤트 기반 센서 (DVS) | 조도 변화가 있는 픽셀만 마이크로초 단위 비동기 스파이크로 출력 |
| AER 비동기 라우터 | 글로벌 클록 없이 핸드셰이크 방식으로 송수신 뉴런 주소 패킷을 중계 |
| 시냅스 어레이 (Synapse) | 뉴런 간 연결 강도(Weight)를 저장하고 신호 입력 시 아날로그 컨덕턴스 가중치 부여 |
| LIF 뉴런 회로 (Neuron) | 입력 신호를 막전위로 적분하고 임계값 도달 시 출력 스파이크 발화 및 리셋 |
| 가소성 학습기 (STDP) | 프리/포스트 스파이크 도착 시간차에 따라 시냅스 연결 가중치를 자율 갱신 |

#### 한줄 요약
- DVS 센서, AER 패킷 라우터, 시냅스 가중치 어레이, LIF 뉴런 회로, STDP 학습 모듈이 뇌 구조를 재현한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **STDP(Spike-Timing-Dependent Plasticity)**: 시냅스 전 뉴런과 시냅스 후 뉴런의 스파이크 발화 시간 차이에 따라 시냅스 연결 강도를 강화하거나 약화시키는 학습 규칙.

</details>

```text
외부 물리적 환경 변화 발생 (빛, 소리 등)
      │
      ▼
1. 이벤트 센서: 화소별 변화 감지 즉시 비동기 스파이크 생성
      │
      ▼
2. AER 라우팅: 발화 뉴런 주소를 패킷화하여 대상 뉴로모픽 코어로 전송
      │
      ▼
3. 시냅스 가중치 곱: 수신된 스파이크에 시냅스 연결 가중치(Conductance) 반영
      │
      ▼
4. LIF 뉴런 적분: 막전위(Membrane Potential) 누산 및 임계치 초과 여부 판별
      │
      ▼
5. 스파이크 발화 및 STDP 자율 학습: 후속 뉴런으로 스파이크 전파 및 가중치 보정
```

**동작 원리**

1. **이벤트 감지**: DVS 카메라 등 전용 센서가 픽셀의 밝기 변화를 감지해 마이크로초 단위 펄스 발생
2. **AER 패킷화**: 발화된 뉴런의 2차원 좌표와 시간 정보를 비동기 패킷으로 변환해 NoC로 송신
3. **가중치 인가**: 수신 코어의 시냅스 크로스바에서 가중치 저항값과 전류를 곱해 뉴런으로 전달
4. **LIF 막전위 누산**: 뉴런이 누설 감쇄를 적용하며 전하를 충전하고, 임계치를 넘으면 스파이크 발화
5. **학습 및 전파**: 출력 스파이크를 다음 계층으로 즉각 브로드캐스트하고 STDP 규칙으로 시냅스 갱신

#### 한줄 요약
- 센서 이벤트 감지 → AER 패킷 전송 → 시냅스 가중치 반영 → LIF 막전위 적분 → 스파이크 발화 순으로 진행된다.

## Ⅴ. 종류 및 비교

| 신경망 컴퓨팅 아키텍처 | 뉴로모픽 (SNN) | 심층신경망 (ANN/NPU) | 양자 컴퓨팅 | 전통 폰 노이만 (CPU) |
|:---|:---|:---|:---|:---|
| 적용 기준 | 초저전력 상시 감시 엣지·음성/생체 센서 | 대규모 고정밀 비전/LLM 학습 및 추론 | 조합 최적화 및 양자 암호·시뮬레이션 | 복잡한 범용 제어 및 순차 프로그램 |
| 핵심 특징 | 스파이크 이벤트 구동 및 아날로그 인메모리 | 부동소수점 다차원 텐서 행렬 곱셈 가속 | 큐비트 중첩 및 얽힘 기반 초병렬 연산 | 직렬 명령어 파이프라인 및 다단계 캐시 |
| 한계 | 역전파 학습 알고리즘 부재·낮은 모델 호환성 | 높은 대기 전력 소모 및 메모리 벽 병목 | 극저온 냉각 인프라 필요 및 높은 에러율 | 행렬 병렬 연산 효율 극히 낮음 |

#### 한줄 요약
- 초저전력 센서 융합은 뉴로모픽, 고정밀 거대 AI는 NPU/GPU, 특정 난제는 양자, 범용 처리는 CPU를 쓴다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **ANN-to-SNN 변환**: 학습이 용이한 표준 심층신경망(CNN 등)을 먼저 학습시킨 후 뉴로모픽용 SNN으로 변환 배포하는 소프트웨어 기술.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 비연속 스파이크 신호로 인한 **역전파(Backprop) 미분 불가** | **대리 기울기(Surrogate Gradient)** 기법 및 ANN-to-SNN 변환 적용 | 높은 정확도의 딥러닝 모델 SNN 이식 |
| 연속 스파이크 폭증(Event Burst) 시 **AER 라우터 패킷 병목** | 국소 클러스터링 기반 계층형 라우팅 및 스파이크 레이트 제한 | 패킷 유실 방지 및 지연시간 안정화 |
| 아날로그 멤리스터(RRAM) 공정 미세화 시 **소자 산포 노이즈** | 디지털-아날로그 하이브리드 시냅스 및 노이즈 인식 훈련(NAT) | 추론 정확도 신뢰성 및 수율 확보 |
| 기존 딥러닝 프레임워크(PyTorch 등)와의 호환성 부족 | Lava, SpikingJelly 등 오픈소스 SNN 전용 미들웨어 연동 | 개발 진입 장벽 완화 및 배포 단축 |

#### 한줄 요약
- 대리 기울기로 학습 난제를 풀고, 계층형 라우터로 패킷 폭증을 막으며, 전용 미들웨어로 호환성을 확보한다.

## Ⅶ. 결론

- 마이크로와트($\mu W$) 수준의 상시 감시 배터리 기반 온디바이스 센서 융합은 **뉴로모픽**, 대형 LLM 추론은 **NPU/GPU** 선택

#### 한줄 요약
- SNN 이벤트 구동 방식과 인메모리 시냅스 아키텍처를 결합하여 차세대 초저전력 뇌모방 지능형 반도체를 구현해야 한다.
