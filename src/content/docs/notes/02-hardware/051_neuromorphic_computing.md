## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **뉴로모픽 컴퓨팅(Neuromorphic Computing)**: 인간 두뇌의 생물학적 신경망 구조와 뉴런·시냅스의 스파이크(Spike) 전기 신호 전달 메커니즘을 모방하여 비동기·초저전력으로 연산하는 비 폰 노이만 반도체 아키텍처.
- **스파이킹 신경망(Spiking Neural Network, SNN)**: 연속적인 실수 텐서 값 대신 시간에 따른 스파이크 펄스의 발생 유무와 발화 시점(Timing)으로 정보를 부호화하여 처리하는 3세대 인공신경망 모델.

</details>

- 정의/개념: 생물학적 뉴런의 스파이크 신호와 이벤트 구동 메커니즘을 모방하여 인메모리 비동기 연산을 수행하는 **뉴로모픽 컴퓨팅** 아키텍처
- 배경/필요성: 폰 노이만 구조의 메모리 벽(Memory Wall) 병목과 상시 동기식 클록 구동으로 인한 심각한 전력 소모 및 데이터 이동 한계

#### 한줄 요약
- 뉴로모픽 컴퓨팅은 뇌의 시냅스 연결과 스파이크 신호를 모방하여 입력 변화 시에만 비동기로 동작하는 극저전력 비 폰 노이만 반도체 기술이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **이벤트 구동(Event-Driven)**: 글로벌 클록에 따라 상시 동작하는 대신, 외부 입력의 변화나 스파이크 펄스가 도착했을 때에만 해당 회로가 비동기적으로 활성화되는 동작 방식.
- **인메모리 연산(In-Memory Computing)**: 가중치가 저장된 비휘발성 메모리(RRAM, MRAM) 또는 SRAM 셀 어레이 내부에서 아날로그 물리 법칙을 이용해 곱셈-누산을 직접 수행하는 기술.

</details>

- 시계열 정보의 스파이크 부호화: **SNN** 기반 스파이크 빈도 및 발생 시점에 정보를 실어 초저전력 연산 수행
- 제로 대기 전력: 입력 신호 부재 시 완전 유휴 상태를 유지하는 **이벤트 구동** 방식 기반 $\mu\text{W}$급 초저전력 달성
- 폰 노이만 병목 해소: 시냅스 가중치 소자 내부에서 직접 연산하는 **인메모리 연산** 적용으로 데이터 이동 에너지 극소화

#### 한줄 요약
- 스파이크 부호화, 이벤트 구동 제로 대기 전력, 인메모리 연산을 통해 폰 노이만 병목을 극복한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **AER(Address-Event Representation)**: 스파이크가 발생한 뉴런의 2차원/3차원 좌표 주소와 타임스탬프를 디지털 패킷으로 변환하여 비동기 버스로 전송하는 통신 프로토콜.
- **LIF 뉴런 모델(Leaky Integrate-and-Fire)**: 시냅스로부터 유입된 전류를 막전위에 누적(적분)하다가 시간이 지남에 따라 일부 누설(Leaky)되며, 임계 전압 도달 시 스파이크를 발화하는 뉴런 회로.
- **막전위(Membrane Potential)**: 뉴런 내부와 외부의 전위차로, 시냅스 입력 전류가 누적됨에 따라 상승하는 아날로그 전압 값.

</details>

```text
[뉴로모픽 컴퓨팅 아키텍처]
 ├── 이벤트 센서단 (DVS 카메라, 촉각 센서)
 ├── 비동기 라우팅 패브릭 (AER 프로토콜, NoC 라우터)
 ├── 시냅스 크로스바 어레이 (RRAM / MRAM / SRAM 가중치 셀)
 └── LIF 뉴런 연산 코어
     ├── 아날로그 적분 회로 (막전위 전압 축적)
     ├── 비교기 / 임계치 판정기 (Spike 발화 트리거)
     └── 가소성 제어기 (STDP 학습 가중치 갱신)
```

선의 의미: 트리는 뉴로모픽 시스템의 계층적 하드웨어 구성요소 및 연산 코어 내부 모듈 포함 관계를 나타냄

| 구성요소 | 책임 |
|:---|:---|
| DVS 이벤트 센서 | 밝기 변화 시 비동기 스파이크 생성 |
| AER 라우터 | **주소 이벤트(AER)** 패킷의 비동기 중계 |
| 시냅스 크로스바 | **인메모리 연산** 기반 곱셈-누산 병렬 처리 |
| **LIF 뉴런 모델** 회로 | 전류를 **막전위**에 적분하고 임계 초과 시 발화 |
| STDP 학습 제어기 | 스파이크 시차에 따른 시냅스 가중치 조정 |

#### 한줄 요약
- DVS 센서가 화면 전체를 주기적으로 읽던 자리를 밝기가 변한 시점만 내보내는 계층으로 대신하고, AER 라우터도 발생한 스파이크만 주소로 실어 나르므로 변화가 없는 구간에는 옮길 데이터 자체가 생기지 않는다.

## Ⅳ. 흐름도

```text
외부 환경 물리적 변화 감지
                      │
                      ▼
1. DVS 이벤트 센서: 픽셀 밝기 변화 감지 ➔ 비동기 스파이크 생성
                      │
                      ▼
2. AER 비동기 라우터: 발화 뉴런 좌표 및 타임스탬프 패킷 브로드캐스트
                      │
                      ▼
3. 시냅스 크로스바 통과: 가중치 인메모리 전류 인출
                      │
                      ▼
4. LIF 뉴런 회로 적분: 입력 전류를 막전위($V_{mem}$)에 누적
                      │
                      ▼
5. 막전위 임계 판정: $V_{mem} \ge V_{th}$ 여부 검사
   ┌──────────────────┴──────────────────┐
[ $V_{mem} < V_{th}$ ]                 [ $V_{mem} \ge V_{th}$ ]
   │                                     │
   ▼                                     ▼
누설 감쇄 후 대기                     스파이크 발화 ➔ STDP 가중치 갱신
                                         │
                                         ▼
                                다음 계층 뉴런으로 스파이크 전파
```

분기 결과: 막전위가 임계를 넘을 때만 스파이크 발화가 일어나 후속 계층으로 전파되므로 극단적인 에너지 절감이 달성됨

#### 한줄 요약
- 밝기 변화라는 이벤트가 있을 때만 스파이크가 생기고 막전위가 임계를 넘을 때만 다음 계층으로 전파되므로, 연산량이 입력 크기가 아니라 변화량에 비례하는 것이 뉴로모픽 저전력의 근원이다.

## Ⅴ. 종류 및 비교

| 컴퓨팅 아키텍처 | 뉴로모픽 컴퓨팅 (Intel Loihi) | 딥러닝 가속기 (NPU/GPU) | 양자 컴퓨팅 (Quantum) | 전통 폰 노이만 CPU |
|:---|:---|:---|:---|:---|
| 데이터 표현 방식 | 시간 축 스파이크 펄스 | 다차원 연속 실수 텐서 | 큐비트 중첩 및 얽힘 | 이진 비트 워드 |
| 클록 및 구동 메커니즘 | 비동기 **이벤트 구동** | 고속 동기식 클록 구동 | 극저온 마이크로파 펄스 | 고주파 글로벌 동기 클록 |
| 메모리-연산 구조 | 인메모리 완전 분산 | 연산기와 메모리 분리 | 큐비트 레지스터 일체형 | 계층적 캐시 분리 |
| 전력 소모 수준 | 초저전력 ($\mu\text{W} \sim \text{mW}$) | 중간~높음 (수 W ~ 수백 W) | 극저온 냉각 전력 소모 큼 | 중간 (수십 W ~ 수백 W) |
| 주요 적용 분야 | 상시 감시 IoT, 로보틱스 센싱 | 대규모 LLM 학습, 비전 추론 | 조합 최적화, 시뮬레이션 | 범용 OS 및 비즈니스 컴퓨팅 |

#### 한줄 요약
- 상시 대기형 극저전력 엣지 센싱에는 뉴로모픽이 독보적이며, 대규모 고정밀 행렬 연산에는 NPU/GPU가 표준이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **ANN-to-SNN 변환(ANN-to-SNN Conversion)**: 기존 역전파로 사전 학습된 심층신경망(ANN)의 활성화 값을 스파이크 발화율(Rate-Coding)로 변환하여 SNN 하드웨어에 탑재하는 기술.
- **대리 기울기(Surrogate Gradient)**: 미분 불가능한 스파이크 발화 함수의 역전파 구간에서 시그모이드 같은 매끄러운 근사 함수의 미분값을 대신 사용하여 SNN을 경사하강법으로 학습시키는 기법.
- **NoC(Network-on-Chip)**: 칩 내부 코어·메모리 블록을 라우터와 링크의 패킷 교환망으로 연결하여 공유 버스의 병목 없이 다수 블록이 동시에 통신하게 하는 온칩 상호연결 구조.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 스파이크 함수의 불연속 미분 불가로 인한 역전파 학습 난제 | **대리 기울기** 기법 및 **ANN-to-SNN 변환** 적용 | 기존 딥러닝 수준의 높은 분류 정확도 달성 |
| 대규모 스파이크 폭증 시 AER 비동기 라우터의 패킷 정체 | 계층형 **NoC** 토폴로지 및 발화율 제한 적용 | 패킷 손실 0화 및 전송 지연시간 안정화 |
| 차세대 아날로그 멤리스터 소자의 공정 산포 오차 | 소자 노이즈 인식 학습 모델 적용 | 하드웨어 비이상성에 따른 추론 정확도 저하 방어 |

#### 한줄 요약
- 실무에서는 ANN-to-SNN 변환으로 학습 문제를 해결하고, 계층형 NoC로 스파이크 정체를 제어하며, 노이즈 인식 훈련으로 소자 오차를 극복한다.

## Ⅶ. 결론

- 스파이킹 신경망(SNN)과 이벤트 구동(Event-Driven) 기반의 비 폰 노이만 차세대 인메모리 AI 반도체 핵심 연구 분야(Intel Loihi 2, SynSense 등)로 자리잡았으며, 향후 DVS(이벤트 카메라) 기반 엣지 센싱, BCI(뇌-컴퓨터 인터페이스) 및 초저전력(마이크로와트급) 상시 가동(Always-On) IoT 영역으로 응용 확장 전망

#### 한줄 요약
- 뉴로모픽 컴퓨팅은 폰 노이만 병목을 극복하는 차세대 생체 모방 반도체이며, 이벤트 구동 센서와의 결합을 통해 마이크로와트 AI를 실현한다.
