## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **뉴로모픽 컴퓨팅(Neuromorphic Computing)**: 인간 두뇌의 생물학적 신경망 구조와 뉴런·시냅스의 스파이크 신호 전달 방식을 모방한 비 폰 노이만 아키텍처.
- **스파이킹 신경망(Spiking Neural Network, SNN)**: 연속적인 실수 값 대신 시간에 따른 스파이크(전기 펄스)의 발생 타이밍으로 정보를 표현하고 처리하는 3세대 신경망 모델.

</details>

- 정의/개념: **SNN** 스파이크 신호와 이벤트 구동 메커니즘을 하드웨어로 구현한 **뉴로모픽 컴퓨팅**
- 배경/필요성: 기존 폰 노이만 구조의 지속적 메모리 왕복과 상시 대기 전력으로는 **생체 모방 초저전력 연산 불가**

#### 한줄 요약
- 뇌 신경망의 시냅스 연결과 스파이크 신호를 모방하여 입력 변화 시에만 비동기로 동작하는 극저전력 비 폰 노이만 반도체다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **이벤트 구동(Event-Driven)**: 고정된 클록 주기마다 회로를 동작시키는 대신, 외부 입력 변화나 스파이크 신호가 발생한 시점에만 비동기적으로 회로를 활성화하는 처리 방식.
- **인메모리 연산(In-Memory Computing)**: 별도의 연산기(ALU) 없이 가중치가 저장된 메모리 셀 어레이 내부에서 아날로그 또는 디지털 연산을 직접 수행하여 메모리 병목을 제거하는 기술.

</details>

- 스파이크 펄스 발생 시점에 시계열 정보를 실어 처리하는 **SNN 모델** 기반
- 신호 입력 시에만 비동기로 활성화되는 **이벤트 구동** 방식
- 시냅스 저장 소자 내에서 곱셈·누산을 직접 수행하는 **인메모리 연산**

#### 한줄 요약
- 클록 없이 이벤트가 발생할 때만 동작하고 메모리 내부에서 연산을 직접 처리하여 전력 소모를 마이크로와트 단위로 절감한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **주소-이벤트 표현(Address-Event Representation, AER)**: 스파이크를 발화한 뉴런의 2차원 좌표 주소와 발생 시간을 패킷화하여 비동기 라우터로 중계하는 통신 프로토콜.
- **누설-적분-발화 모델(Leaky Integrate-and-Fire, LIF)**: 시냅스 입력 스파이크를 막전위에 누적하다가 임계 전압 도달 시 스파이크를 발화하고 리셋하는 생물학적 뉴런 모사 회로.

</details>

```text
[뉴로모픽 시스템]
|-- 이벤트 기반 센서 (변화 픽셀만 스파이크 출력)
|-- AER 비동기 라우터 (글로벌 클록 없는 핸드셰이크 중계)
`-- 뉴로모픽 코어 × N
    |-- 시냅스 메모리 어레이 (가중치 저장·RRAM·SRAM)
    `-- LIF 뉴런 연산 유닛 (막전위 적분·발화·리셋)
```

선의 의미: 계층 및 신호 전달 구조

| 구성요소 | 책임 |
|:---|:---|
| 이벤트 기반 센서 | 밝기·신호 변화가 감지된 픽셀만 마이크로초 단위 스파이크로 출력 |
| **AER 라우터** | 글로벌 클록 없이 비동기 핸드셰이크로 뉴런 좌표 패킷 중계 |
| 시냅스 메모리 어레이 | 뉴런 간 연결 가중치 저장 및 입력 스파이크에 가중치 반영 |
| **LIF 뉴런 회로** | 막전위 시간 적분 및 임계 전압 도달 시 출력 스파이크 발화 |

#### 한줄 요약
- DVS 센서, AER 비동기 라우터, 시냅스 어레이, LIF 뉴런 회로가 비동기적으로 상호작용하여 정보를 처리한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **스파이크 타이밍 의존 가소성(Spike-Timing-Dependent Plasticity, STDP)**: 시냅스 전 뉴런과 후 뉴런의 스파이크 발화 시간 차이에 따라 시냅스 연결 강도를 강화하거나 약화시키는 생물학적 학습 규칙.

</details>

```text
외부 환경 변화 발생 (빛·소리 등)
        │
   변화가 센서 임계를 넘는가?
   ┌────┴─────┐
아니오          예
   │             │
회로 유휴 유지   AER 패킷화 후 라우터 전송
(전력 소모 없음)  │
   │        시냅스 가중치를 입력에 반영
   │             │
   │        LIF 막전위가 임계를 넘는가?
   │        ┌────┴─────┐
   │      아니오          예
   │        │             │
   │     누설 감쇄 후    스파이크 발화 후 리셋
   │     다음 입력 대기    │
   │        │        온라인 학습 시 STDP로 가중치 갱신
   └────┬───┴─────────────┘
        │
   다음 이벤트 대기
```

#### 한줄 요약
- 입력 임계와 막전위 임계를 순차 검증하여 발화 조건을 충족할 때만 스파이크를 발생시키고 STDP 가소성으로 가중치를 갱신한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **심층신경망(ANN/NPU)**: 연속적인 실수 행렬 곱셈을 기반으로 역전파 학습을 수행하는 기존 2세대 인공신경망 가속 구조.
- **양자 컴퓨팅(Quantum Computing)**: 큐비트의 중첩과 얽힘 현상을 활용하여 특정 복잡 연산을 지수적으로 가속하는 비고전 컴퓨팅.

</details>

| 신경망 컴퓨팅 아키텍처 | 뉴로모픽 (SNN) | 심층신경망 (ANN/NPU) | 양자 컴퓨팅 | 전통 폰 노이만 (CPU) |
|:---|:---|:---|:---|:---|
| 적용 기준 | 초저전력 상시 감시 엣지·음성/생체 센서 | 대규모 고정밀 비전/LLM 학습 및 추론 | 조합 최적화 및 양자 암호·시뮬레이션 | 복잡한 범용 제어 및 순차 프로그램 |
| 핵심 특징 | 스파이크 이벤트 구동과 분산 상태 저장 | 연속값 텐서의 행렬 곱셈 가속 | 큐비트 중첩·얽힘 기반 연산 | 범용 명령 실행과 다단계 캐시 |
| 한계 | 학습·도구·정확도 평가 생태계 미성숙 | 메모리 이동과 대기 전력 부담 | 오류 교정과 하드웨어 규모 제약 | 대규모 행렬 연산의 전력 효율 제약 |

#### 한줄 요약
- 상시 감시 및 극저전력 엣지 센싱에는 뉴로모픽이 적합하며, 대규모 고정밀 딥러닝에는 NPU/GPU가 적합하다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **ANN-to-SNN 변환**: 역전파 학습이 용이한 표준 심층신경망을 먼저 학습시킨 후 활성화 함수를 스파이크 발화율로 매핑하여 SNN으로 변환하는 소프트웨어 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 불연속 스파이크로 인한 기울기 역전파 불가 | 대리 기울기(Surrogate Gradient) 기법 및 **ANN-to-SNN 변환** 적용 | 기존 딥러닝 모델의 SNN 이식 및 학습 수렴 |
| 스파이크 폭증 시 라우터 패킷 병목 | 계층형 라우팅 및 스파이크 발생률(Rate Limit) 제어 | 라우터 혼잡 제어 및 스파이크 유실 방지 |
| 아날로그 메모리 소자 산포로 인한 오차 | 노이즈 인식 학습 및 하이브리드 시냅스 소자 적용 | 하드웨어 비이상성 극복 및 추론 정확도 확보 |
| 표준 프레임워크 호환성 부족 | Lava, SpikingJelly 등 전용 미들웨어 연동 | 개발 진입 장벽 완화 및 파이프라인 단축 |

#### 한줄 요약
- ANN-to-SNN 변환 기법으로 학습 한계를 극복하고 계층형 비동기 라우팅으로 스파이크 패킷 폭증을 제어한다.

## Ⅶ. 결론

- 희소 시계열 신호 기반 초저전력 상시 감시는 **뉴로모픽**, 대규모 고정밀 행렬 연산은 **NPU/GPU** 선정 및 적용

#### 한줄 요약
- 뉴로모픽은 데이터 변화 빈도가 낮은 상시 대기형 스마트 센서 및 엣지 환경에서 극단적인 에너지 효율을 발휘한다.
