## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **뉴로모픽 컴퓨팅(Neuromorphic Computing)**: 인간 두뇌의 생물학적 신경망 구조와 뉴런·시냅스의 스파이크(Spike) 전기 신호 전달 메커니즘을 모방하여 비동기·초저전력으로 연산하는 비 폰 노이만 반도체 아키텍처.
- **스파이킹 신경망(Spiking Neural Network, SNN)**: 연속적인 실수 텐서 값 대신 시간에 따른 스파이크 펄스의 발생 유무와 발화 시점(Timing)으로 정보를 부호화하여 처리하는 3세대 인공신경망 모델.

</details>

- 정의/개념: 생물학적 뉴런의 스파이크 신호와 이벤트 구동 메커니즘을 모방하여 인메모리 비동기 연산을 수행하는 **뉴로모픽 컴퓨팅 아키텍처**
- 배경/필요성: 폰 노이만 구조의 메모리 벽(Memory Wall) 병목과 상시 동기식 클록 구동으로 인한 **심각한 전력 소모 및 데이터 이동 에너지 한계 극복 및 마이크로와트급 생체 모방 비동기 연산 실현 요구 증대**

#### 한줄 요약
- 뉴로모픽 컴퓨팅은 뇌의 시냅스 연결과 스파이크 신호를 모방하여 입력 변화 시에만 비동기로 동작하는 극저전력 비 폰 노이만 반도체 기술이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **이벤트 구동(Event-Driven)**: 글로벌 클록에 따라 상시 동작하는 대신, 외부 입력의 변화나 스파이크 펄스가 도착했을 때에만 해당 회로가 비동기적으로 활성화되는 동작 방식.
- **인메모리 연산(In-Memory Computing)**: 가중치가 저장된 비휘발성 메모리(RRAM, MRAM) 또는 SRAM 셀 어레이 내부에서 아날로그 물리 법칙을 이용해 곱셈-누산을 직접 수행하는 기술.

</details>

- 시계열 정보의 스파이크 부호화: **SNN** 기반 스파이크 빈도 및 발생 시점에 정보를 실어 초저전력 연산 수행
- 제로 대기 전력: 입력 신호 부재 시 완전 유휴 상태를 유지하는 **이벤트 구동** 방식 기반 $\mu\text{W}$급 초저전력 달성
- 폰 노이만 병목 해소: 시냅스 가중치 소자 내부에서 직접 연산하는 **인메모리 연산** 적용으로 데이터 이동 에너지 극소화

#### 한줄 요약
- 스파이크 부호화, 이벤트 구동 제로 대기 전력, 인메모리 연산을 통해 폰 노이만 병목을 극복한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **AER(Address-Event Representation)**: 스파이크가 발생한 뉴런의 2차원/3차원 좌표 주소와 타임스탬프를 디지털 패킷으로 변환하여 비동기 버스로 전송하는 통신 프로토콜.
- **LIF 뉴런 모델(Leaky Integrate-and-Fire)**: 시냅스로부터 유입된 전류를 막전위에 누적(적분)하다가 시간이 지남에 따라 일부 누설(Leaky)되며, 임계 전압 도달 시 스파이크를 발화하는 뉴런 회로.
- **막전위(Membrane Potential)**: 뉴런 내부와 외부의 전위차로, 시냅스 입력 전류가 누적됨에 따라 상승하는 아날로그 전압 값.

</details>

```text
+-------------------------------------------------------------------------------+
|                       뉴로모픽 컴퓨팅 하드웨어 아키텍처                       |
|                                                                               |
|  +-------------------------------------------------------------------------+  |
|  |       이벤트 센서단 (DVS 카메라, 동적 음향 센서: 밝기/신호 변화 감지)   |  |
|  +-------------------------------------------------------------------------+  |
|                                    │ 비동기 이벤트 펄스                       |
|                                    ▼                                          |
|  +-------------------------------------------------------------------------+  |
|  |       비동기 라우팅 패브릭 (AER 프로토콜 / NoC 2D-Mesh 패킷 라우터)      |  |
|  +-------------------------------------------------------------------------+  |
|                                    │ 스파이크 이벤트 좌표 패킷 전송           |
|                                    ▼                                          |
|  +-------------------------------------------------------------------------+  |
|  |     시냅스 크로스바 어레이 (RRAM / MRAM / SRAM 인메모리 가중치 소자)    |  |
|  |     - 옴의 법칙(I=V/R)과 키르히호프 전류 법칙(KCL) 기반 아날로그 MAC   |  |
|  +-------------------------------------------------------------------------+  |
|                                    │ 시냅스 가중치 합산 전류 ($I_{syn}$)     |
|                                    ▼                                          |
|  +-------------------------------------------------------------------------+  |
|  |                   LIF (Leaky Integrate-and-Fire) 뉴런 코어              |  |
|  |   [아날로그 적분기]  -->  [막전위($V_{mem}$) 누적/누설]  -->  [비교 판정]   |  |
|  |   [STDP 가소성 모듈] <--  [스파이크 발화(Spike Output)] <---+              |  |
|  +-------------------------------------------------------------------------+  |
+-------------------------------------------------------------------------------+
```

- 신호 및 연결 관계: 하향 화살표(`▼`)는 외부 물리 변화에서 발생한 스파이크 펄스가 라우터와 시냅스 크로스바를 거쳐 LIF 뉴런으로 유입되는 비동기 이벤트 흐름을 나타내며, 하단 화살표(`-->`, `<--`)는 막전위 임계 초과 시 스파이크 발화 및 STDP 피드백 갱신 루프를 명시함

| 구성요소 | 책임 |
|:---|:---|
| DVS 이벤트 센서 | 밝기 변화 시 비동기 스파이크 생성 |
| AER 라우터 | **주소 이벤트(AER)** 패킷의 비동기 중계 |
| 시냅스 크로스바 | **인메모리 연산** 기반 곱셈-누산 병렬 처리 |
| LIF 뉴런 모델 회로 | 전류를 **막전위**에 적분하고 임계 초과 시 발화 |
| STDP 학습 제어기 | 스파이크 시차에 따른 시냅스 가중치 조정 |

#### 한줄 요약
- DVS 센서가 화면 전체를 주기적으로 읽던 자리를 밝기가 변한 시점만 내보내는 계층으로 대신하고, AER 라우터도 발생한 스파이크만 주소로 실어 나르므로 변화가 없는 구간에는 옮길 데이터 자체가 생기지 않는다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **STDP(Spike-Timing-Dependent Plasticity)**: 시냅스 전 뉴런과 후 뉴런의 스파이크 발화 시간 차이에 따라 시냅스 연결 강도(가중치)를 강화하거나 약화시키는 생물학적 학습 규칙.

</details>

```text
+-------------------------------------------------------------+
|                 외부 환경 물리적 변화 감지                  |
+-------------------------------------------------------------+
                               |
                               v
+-------------------------------------------------------------+
| 1. DVS 이벤트 센서의 픽셀 밝기 변화 감지 및 비동기 펄스 생성|
+-------------------------------------------------------------+
                               |
                               v
+-------------------------------------------------------------+
| 2. AER 비동기 라우터의 발화 뉴런 좌표 및 타임스탬프 라우팅  |
+-------------------------------------------------------------+
                               |
                               v
+-------------------------------------------------------------+
| 3. 시냅스 크로스바 통과 및 옴/키르히호프 법칙 인메모리 연산 |
+-------------------------------------------------------------+
                               |
                               v
+-------------------------------------------------------------+
| 4. LIF 뉴런 회로의 유입 전류 막전위 누적 및 시간 경과 누설  |
+-------------------------------------------------------------+
                               |
                               v
               +-------------------------------+
               | 5. 막전위 임계치($V_{mem} \ge V_{th}$) 판정  |
               +-------------------------------+
                      |                 |
             [ $V_{mem} < V_{th}$ ]    | [ $V_{mem} \ge V_{th}$ ]
                      |                 v
                      | +-------------------------------+
                      | | 스파이크 발화 및 STDP 갱신    |
                      | +-------------------------------+
                      v                 |
+-----------------------+               v
| 누설 감쇄 후 대기 유지| +-------------------------------+
+-----------------------+ | 다음 계층 뉴런으로 전파     |
                          +-------------------------------+
```

분기 결과: 막전위가 임계를 넘을 때만 스파이크 발화가 일어나 후속 계층으로 전파되므로 극단적인 에너지 절감이 달성됨

**동작 원리**

1. **비동기 스파이크 생성**: DVS 센서의 각 픽셀이 외부 조도 변화를 감지하는 즉시 클록 없이 독립적인 스파이크 전기 펄스 생성
2. **AER 주소 이벤트 라우팅**: AER 비동기 라우터가 스파이크를 발생시킨 센서 픽셀의 2D 좌표와 타임스탬프를 패킷화하여 대상 시냅스 코어로 전송
3. **인메모리 아날로그 연산**: 수신된 스파이크 전압 펄스가 시냅스 크로스바 어레이를 통과하면서 각 저항 소자의 컨덕턴스에 비례하는 아날로그 전류를 키르히호프 법칙에 따라 즉각 합산 인출
4. **LIF 막전위 적분 및 누설**: LIF 뉴런 회로가 시냅스 전류를 커패시터에 충전하여 막전위($V_{mem}$)를 상승시키며, 입력 부재 시 저항을 통해 자연 누설(Leak) 감쇄
5. **임계 판정 및 발화 전파**: 막전위가 기설정된 임계 전압($V_{th}$)을 초과하면 비교기가 동작하여 스파이크를 후단으로 발화하고 STDP 회로가 시냅스 가중치 동적 갱신

#### 한줄 요약
- 밝기 변화라는 이벤트가 있을 때만 스파이크가 생기고 막전위가 임계를 넘을 때만 다음 계층으로 전파되므로, 연산량이 입력 크기가 아니라 변화량에 비례하는 것이 뉴로모픽 저전력의 근원이다.

## Ⅴ. 종류 및 비교

| 대상 구분 | 뉴로모픽 컴퓨팅 (Intel Loihi) | 딥러닝 가속기 (NPU/GPU) | 양자 컴퓨팅 (Quantum) | 전통 폰 노이만 CPU |
|:---|:---|:---|:---|:---|
| 적용 기준 | 초저전력 상시 감시 IoT 및 실시간 생체 신호 모니터링 요구 시 | 대규모 심층 신경망(LLM/비전) 고정밀 행렬 연산 처리 시 | 특수 암호 해독 및 대규모 분자 구조 시뮬레이션 요구 시 | 범용 OS 제어 및 직렬 비즈니스 로직 연산 처리 시 |
| 핵심 특징 | 시간 축 스파이크 펄스(SNN), **비동기 이벤트 구동**, 시냅스 크로스바 기반 인메모리 연산 | 다차원 연속 실수 텐서, **고속 동기식 클록 기반 대규모 SIMT/MAC**, 분리형 고대역 HBM | 큐비트 중첩 및 얽힘 상태 활용, 극저온 마이크로파 펄스 제어, 양자 병렬 연산 | 이진 비트 워드, 슈퍼스칼라 비순차 파이프라인, 계층적 캐시 메모리 구조 |
| 한계 | 표준 역전파 훈련 부재(대리 기울기 필요), 범용 소프트웨어 생태계 협소, 아날로그 공정 산포 | 고전력 소모(수십~수백 와트), 상시 클록 구동 발열, 폰 노이만 메모리 벽 병목 잔존 | 극저온(-273°C) 유지 인프라 필수, 양자 결맞음 시간(Coherence) 한계, 에러 수정 난제 | 대규모 병렬 행렬 연산 시 대역폭 부족, 연산 단위당 높은 전력 소모 |

#### 한줄 요약
- 상시 대기형 극저전력 엣지 센싱에는 뉴로모픽이 독보적이며, 대규모 고정밀 행렬 연산에는 NPU/GPU가 표준이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **ANN-to-SNN 변환(ANN-to-SNN Conversion)**: 기존 역전파로 사전 학습된 심층신경망(ANN)의 활성화 값을 스파이크 발화율(Rate-Coding)로 변환하여 SNN 하드웨어에 탑재하는 기술.
- **대리 기울기(Surrogate Gradient)**: 미분 불가능한 스파이크 발화 함수의 역전파 구간에서 시그모이드 같은 매끄러운 근사 함수의 미분값을 대신 사용하여 SNN을 경사하강법으로 학습시키는 기법.
- **NoC(Network-on-Chip)**: 칩 내부 코어·메모리 블록을 라우터와 링크의 패킷 교환망으로 연결하여 공유 버스의 병목 없이 다수 블록이 동시에 통신하게 하는 온칩 상호연결 구조.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 스파이크 함수의 불연속 미분 불가로 인한 역전파 학습 난제 | **대리 기울기** 기법 및 **ANN-to-SNN 변환** 적용 | 기존 딥러닝 수준의 높은 분류 정확도 달성 |
| 대규모 스파이크 폭증 시 AER 비동기 라우터의 패킷 정체 | 계층형 **NoC** 토폴로지 및 발화율 제한 적용 | 패킷 손실 0화 및 전송 지연시간 안정화 |
| 차세대 아날로그 멤리스터 소자의 공정 산포 오차 | 소자 노이즈 인식 학습 모델 적용 | 하드웨어 비이상성에 따른 추론 정확도 저하 방어 |

#### 한줄 요약
- 실무에서는 ANN-to-SNN 변환으로 학습 문제를 해결하고, 계층형 NoC로 스파이크 정체를 제어하며, 노이즈 인식 훈련으로 소자 오차를 극복한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **DVS(Dynamic Vision Sensor)**: 전통적인 프레임 단위 영상 획득 대신 개별 픽셀의 밝기 변화 이벤트만을 비동기 스파이크로 출력하는 차세대 초저전력 이벤트 카메라.
- **BCI(Brain-Computer Interface)**: 두뇌의 신경 신호를 컴퓨터가 해석하여 외부 기기를 제어하거나 반대로 뇌에 전기 자극을 전달하는 인터페이스 기술.

</details>

- 스파이킹 신경망(SNN)과 이벤트 구동(Event-Driven) 기반의 비 폰 노이만 인메모리 반도체 핵심 기술(Intel Loihi 2 등)로 발전하고 있으며, 향후 DVS 이벤트 카메라와 결합된 극저전력 초소형 웨어러블 및 BCI(뇌-컴퓨터 인터페이스) 생태계로 확산 진행 중.
- 하드웨어 아키텍트는 대리 기울기 학습 프레임워크와 아날로그 멤리스터 공정 신뢰성을 종합 평가하여 마이크로와트급 지능형 센서 노드 상용화 체계 확립 필수.

#### 한줄 요약
- 뉴로모픽 컴퓨팅은 폰 노이만 병목을 극복하는 차세대 생체 모방 반도체이며, 이벤트 구동 센서와의 결합을 통해 마이크로와트 AI를 실현한다.
