## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **뉴로모픽 컴퓨팅(Neuromorphic Computing)**: 생물학적 뇌의 신경세포(Neuron)와 시냅스(Synapse) 구조를 모방하여 비동기 스파이크 신호 기반으로 초저전력 정보 처리를 수행하는 반도체.
- **Spike(스파이크)**: 신경세포가 특정 전압 임계치를 초과할 때 방출하는 짧은 전압 펄스(활동 전위).
- **Event-Driven(이벤트 기반 구동)**: 전역 클록 없이 입력 신호(스파이크)가 발생하는 순간에만 연산기가 활성화되는 비동기 방식.

</details>

- 정의/개념: 인간 뇌의 생물학적 뉴런(Neuron)과 시냅스(Synapse)의 동작 원리를 모방하여, 비동기 스파이크(Spike) 이벤트 기반으로 초저전력(mW 단위) 정보 처리를 수행하는 뇌 모방 컴퓨팅 아키텍처
- 배경/필요성: 기존 폰 노이만 구조의 클록 기반 주기적 연산으로 인한 **메모리 벽(Memory Wall) 병목과 상시 전력 소모(Static Power)를 극복하고 초저전력 상시 감시(Always-On) AI 실현**

#### 한줄 요약

- 뇌의 신경망을 모방한 **비동기 스파이크(SNN) 및 인메모리 연산으로 초저전력(mW) 달성**

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **SNN(Spiking Neural Network)**: 스파이크 펄스의 발생 시점(타이밍)과 빈도로 정보를 인코딩하는 3세대 인공신경망.
- **Sparsity(희소성)**: 시간 및 공간적으로 대부분의 뉴런이 침묵(유휴)하고 극소수 뉴런만 발화하여 전력 소모를 극소화하는 특성.
- **In-Memory Computing**: 연산 유닛 내부에 시냅스 가중치 메모리를 통합하여 폰 노이만 데이터 이동 에너지를 제거하는 구조.

</details>

- 스파이크 발생 타이밍과 빈도에 정보를 인코딩하는 생물학적 **스파이킹 신경망(SNN)** 모델 적용
- 입력 신호 변화가 없는 유휴 상태에서 정적 전력 소모를 0에 가깝게 유지하는 **희소 이벤트(Sparse Event) 구동**
- 시냅스 가중치 메모리와 뉴런 연산기를 동일 공간에 집적하는 **인메모리 근접 연산(Near-Memory Computing)**

#### 한줄 요약

- **SNN 스파이킹 신경망·이벤트 기반 비동기 구동(Event-Driven)·인메모리 근접 연산**

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **Spike Encoder**: 센서의 아날로그/디지털 신호를 AER(Address-Event Representation) 스파이크 패킷으로 변환하는 모듈.
- **Neuron Core (LIF)**: 수신된 스파이크 전류를 막전위(Membrane Potential)에 누적하다가 임계값 초과 시 발화하는 Leaky Integrate-and-Fire 연산기.

</details>

```text
[ 뉴로모픽 칩 비동기 이벤트 연산 아키텍처 ]
┌─────────────────────────────────────────────────────────────┐
│ 이벤트 기반 센서 (DVS 카메라, 실시간 오디오 센서)          │
└──────────────────────────────┬──────────────────────────────┘
                               │ (이벤트 신호)
┌──────────────────────────────┴──────────────────────────────┐
│ 스파이크 인코더 (AER: Address-Event Representation 변환)    │
└──────────────────────────────┬──────────────────────────────┘
                               │ (스파이크 패킷)
┌──────────────────────────────┴──────────────────────────────┐
│ 온칩 비동기 이벤트 라우터 (NoC Packet Router)                │
│  ├─ 타깃 뉴런 코어 주소 디코딩 및 멀티캐스트                │
│  └─ 타임스탬프 기반 순서 정렬 및 큐잉                        │
└──────────────────────────────┬──────────────────────────────┘
                               │
┌──────────────────────────────┴──────────────────────────────┐
│ 뉴런 코어 & 시냅스 메모리 어레이                            │
│  ├─ 시냅스 SRAM (연결 가중치 W_ij 인메모리 보관)             │
│  └─ LIF 뉴런 연산기 (막전위 V_m 적분 ──> 임계값 비교 ──> 발화)│
└─────────────────────────────────────────────────────────────┘
```

선의 의미: 아날로그 센서 입력, 스파이크 인코더, 온칩 이벤트 라우터 및 뉴런 코어/시냅스 메모리 간의 뉴로모픽 아키텍처 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 스파이크 인코더 | 아날로그 센서 입력 신호를 시간 및 주소 기반의 이산 펄스 **스파이크** 데이터로 인코딩 번역 변환 |
| 이벤트 라우터 | 발생된 펄스 패킷을 칩 내부 네트워크망을 통해 목적지 타깃 뉴런 코어로 저지연 라우팅 핑퐁 전송 |
| 시냅스 메모리 및 인프라 | 뉴런 간의 결합 가중치 파라미터 보관 및 칩의 전기세를 아끼기 위한 초저전력 **근접 메모리 연산** 물리적 수용 |
| 뉴런 코어 연산 로직 | 전압 게이지(막전위) 누적 및 폭발(발화 임계값) 제어를 통한 새로운 **스파이크** 방출 연산 수행 |

#### 한줄 요약

- **스파이크 인코더(AER)·온칩 이벤트 라우터·뉴런 코어(LIF)·시냅스 메모리(가중치)**

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **LIF (Leaky Integrate-and-Fire)**: 스파이크가 들어오면 전압을 더하고, 들어오지 않으면 서서히 방전(Leak)되다가 임계값 도달 시 발화하는 뉴런 수학 모델.

</details>

```text
[ 뉴로모픽 스파이크 연산 및 발화 흐름 ]
                         │
                         ▼
   [ 1. 센서 이벤트 감지 시 AER 포맷 스파이크 패킷 생성 ]
                         │
                         ▼
   [ 2. 온칩 라우터가 패킷 수신 및 목적지 뉴런 코어로 전달 ]
                         │
                         ▼
   [ 3. 시냅스 메모리에서 가중치($W_{ij}$)를 읽어 전류 신호 인가 ]
                         │
                         ▼
   [ 4. LIF 뉴런 모델 기반 막전위($V_m$) 누적 및 누수 연산 ]
                         │
        +─────────────────────────────────────────+
        │        [ 막전위 $V_m \ge V_{th}$ 임계값 초과? ]  │
        │        /                               \        │
        │    [ 예 ]                            [ 아니오 ] │
        │      │                                   │      │
        │ 5. 스파이크 발화 방출            막전위 유지/누수│
        │    및 막전위 리셋($V_m=0$)        (다음 펄스 대기)│
        +─────────────────────────────────────────+
```

**동작 원리**

1. **AER 인코딩**: 센서 데이터 변화 시 발생 시간과 소스 주소가 담긴 AER 스파이크 생성
2. **이벤트 라우팅**: 온칩 NoC 라우터가 스파이크를 목적지 시냅스/뉴런 코어로 라우팅
3. **가중치 인가**: 시냅스 SRAM에 저장된 가중치 $W_{ij}$를 반영하여 뉴런에 펄스 전류 주입
4. **막전위 적분**: LIF 뉴런이 $V_m(t) = V_m(t-1) \cdot \alpha + I(t)$ 수식으로 막전위 갱신
5. **스파이크 발화**: $V_m \ge V_{th}$ 도달 시 새로운 스파이크를 방출하고 $V_m$을 0으로 리셋

#### 한줄 요약

- AER 스파이크 생성 $\to$ **이벤트 라우팅 $\to$ 시냅스 가중치 인가 $\to$ 막전위(LIF) 누적 $\to$ 임계값 초과 시 발화**

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **Neuromorphic vs Von Neumann AI 가속기**:
  - Neuromorphic: 비동기 이벤트 구동, SNN 기반, mW 단위 초저전력, 상시 감시
  - Von Neumann AI: 동기 클록 구동, ANN/Dense 텐서, 높은 처리량, 고전력

</details>

| 비교 항목 | 뉴로모픽 컴퓨팅 (Event-Driven) | 기존 폰 노이만 인공지능 가속기 (Clock-Driven) |
|:---|:---|:---|
| 구동 방식 및 네트워크 | 비동기 이벤트 구동, SNN(스파이킹 신경망) | 글로벌 클록 동기 구동, ANN/CNN/Transformer |
| 연산 및 전력 효율 | 희소성(Sparsity) 기반 초저전력 (mW 단위, 인메모리) | 조밀 텐서(Dense) 고처리량, 고전력 (W~수백W) |
| 한계 및 학습 난제 | SNN 학습 알고리즘 미성숙, ANN 대비 정확도 손실 | 폰 노이만 메모리 벽(Memory Wall) 및 대기 전력 누수 |

#### 한줄 요약

- 희소 이벤트/상시 감시는 **뉴로모픽**, 대규모 조밀 AI 학습/추론은 **폰 노이만(GPU/NPU)**

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **STDP(Spike-Timing-Dependent Plasticity)**: 시냅스 전후 뉴런의 스파이크 발화 시차에 따라 가중치를 스스로 강화하거나 약화시키는 뇌 모방 비지도 학습 규칙.
- **Event-Based Camera (DVS)**: 프레임 단위가 아닌 픽셀별 밝기 변화 시에만 비동기 스파이크를 100만분의 1초 단위로 출력하는 센서.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 입력 데이터가 미친 듯이 급변하여 폭증한 **이벤트율**에 의한 온칩 라우터 병목 및 패킷 붕괴 | 물통 폭발 기준을 빡세게 높이는 동적 임계값 제어 및 펄스 버퍼 큐 확장 최적화 조치 | 쓸데없는 스파이크 폭주 발화를 막고 칩 내부 라우팅 패킷 손실 및 지연을 원천 방지 달성 |
| 중앙 클록이 없는 비동기 전송 지연으로 인해 스파이크 펄스가 뒤죽박죽 도착하는 순서 꼬임 참사 | 각 펄스에 **타임스탬프** 꼬리표를 붙여 칩 내부에서 시간순으로 줄 세우는 정렬 버퍼 로직 강제 적용 | 뇌 신경망의 생명인 시공간 데이터 인과관계 순서 손상을 차단하고 추론 정확도 방어 유지 |
| 기존 딥러닝(ANN)을 뇌 모델(SNN)로 억지로 욱여넣다 발생하는 심각한 추론 성능 정확도 하락 | 스파이크 타이밍 의존성 가소성(STDP) 알고리즘 기반의 뇌 모방 다이렉트 SNN 훈련 학습 개조 | 복잡한 타깃 인공지능 상용 응용 분야에서도 비즈니스 투입이 가능한 품질 마진 100% 확보 |
| 화면 전체가 빼곡한 조밀 데이터를 입력하면 시도 때도 없이 발화하여 초저전력의 칩 존재 이유가 상실됨 | 픽셀이 변할 때만 신호를 쏘는 **이벤트 카메라**(DVS) 등 희소성 데이터 전용 찰떡궁합 센서 조합 구성 | 좁쌀 배터리 하나로 1년을 버티는 극초저전력 무인 오프라인 상시 모니터링 시스템 구축 달성 |

#### 한줄 요약

- **동적 발화 임계값 제어·타임스탬프 정렬 버퍼·STDP 직접 학습·이벤트 카메라(DVS) 연동**

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **Intel Loihi 2 / SynSense DYNAPs**: 대표적인 상용 뉴로모픽 프로세서로, 100만 개 이상의 뉴런을 집적하고 초저전력 제스처 인식, 바이오 신호 분석에 활용.

</details>

- 드론, 웨어러블, 스마트 센서 등 **초저전력 상시 감시(Always-On) 에지 환경에서 Intel Loihi / SynSense 뉴로모픽 표준 채택**

#### 한줄 요약

- **데이터 희소성(Sparsity)과 초저전력 상시 감시 요구**에 맞춘 뉴로모픽 칩 적용
