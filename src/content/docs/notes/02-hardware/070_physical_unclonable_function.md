## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **PUF(Physical Unclonable Function)**: 반도체 제조 공정의 불가피한 미세 물리적 편차를 활용해 칩마다 고유한 무작위 난수 비트를 출력하는 하드웨어 지문 소자.
- **온디맨드 키 생성(Key Generation On-Demand)**: 암호 키를 불휘발성 메모리(NVM)에 영구 저장하지 않고, 필요할 때만 PUF 회로에서 즉석 생성해 사용 후 파기하는 방식.

</details>

- 정의/개념: 반도체 제조 미세 공정 편차를 기반으로 칩 고유의 암호 키를 즉석 생성하는 **PUF** 기술
- 배경/필요성: 불휘발성 메모리(NVM) 내 암호 키 저장 시 **물리적 프로빙 및 역공학 공격 노출 불가피**

#### 한줄 요약
- PUF는 반도체 제조 시 발생하는 나노 스케일 미세 편차를 이용해 칩마다 유일한 고유 암호 키를 온디맨드로 생성한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **고유성(Uniqueness)**: 동일한 마스크로 제조된 서로 다른 칩들 간의 PUF 출력 비트가 통계적으로 50%의 해밍 거리를 가지며 서로 완벽히 구분되는 특성.
- **신뢰성(Reliability)**: 동일한 칩에서 온도, 전압, 경년 변화 등 외부 환경이 바뀌어도 항상 동일한 기준 키를 재현해내는 안정성.

</details>

- 하드웨어 회로 자체를 물리적으로 복제하는 것이 불가능한 비복제성(Unclonability)
- 전원 차단 시 키가 소멸하여 메모리 덤프 및 물리적 디캡(Decap) 공격 원천 방어
- 칩 간 식별을 위한 **고유성(해밍 거리 50%)**과 환경 변화를 견디는 **신뢰성(재현율 100%)** 확보

#### 한줄 요약
- 키를 메모리에 저장하지 않고 필요 시점에만 칩의 물리 지문으로부터 재현하여 완벽한 보안성을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **퍼지 추출기(Fuzzy Extractor)**: 노이즈가 섞인 PUF 원시 응답(Raw Response)에서 BCH/리드솔로몬 에러 정정 부호와 헬퍼 데이터를 이용해 순수 암호키를 추출하는 모듈.
- **헬퍼 데이터(Helper Data)**: 키 등록(Enrollment) 시 생성되어 외부에 공개 저장되는 비민감 보조 데이터로, 키 재현 시 에러 비트 보정에 사용.

</details>

```text
[PUF 암호 키 생성 경로]
|-- PUF 원시 코어 (SRAM 전원 인가 셀 / 링 발진기 어레이)
|-- 퍼지 추출기 (Fuzzy Extractor)
|   |-- 에러 정정 디코더 (BCH / Reed-Solomon 에러 보정)
|   `-- 헬퍼 데이터 (Helper Data - 공개 보조 데이터 연동)
|-- 엔트로피 압축기 (해시 함수 및 KDF 기반 균등 비트열 변환)
`-- 암호화 엔진 (생성된 대칭키를 NVM 경유 없이 메모리 버스 직결)
```

선의 의미: 계층 및 신호 처리 파이프라인

| 구성요소 | 책임 |
|:---|:---|
| PUF 원시 코어 | 트랜지스터 문턱전압 편차를 기반으로 원시 챌린지-응답(CRP) 비트 생성 |
| 등록 엔진 | 초기 양산 시 기준 응답을 측정하여 공개 보조 정보인 **헬퍼 데이터** 생성 |
| **퍼지 추출기** | 온도·전압 변동으로 뒤집힌 잡음 비트를 에러 정정 부호로 100% 복원 |
| KDF / 해시 엔진 | 복원된 비트열의 편향을 제거하고 암호학적으로 균등한 128/256비트 키 유도 |
| 암호 엔진 | 생성된 키를 즉시 AES 암복호화에 사용하고 사용 직후 레지스터 제로화 |

#### 한줄 요약
- PUF 원시 코어, 퍼지 추출기, 헬퍼 데이터, KDF 엔진이 결합되어 100% 재현 가능한 암호 키를 생성한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **챌린지-응답(CRP, Challenge-Response Pair)**: 특정 입력 자극(Challenge)에 대해 PUF 회로가 고유하게 내놓는 출력값(Response)의 쌍.

</details>

```text
키 생성 요청 → PUF 코어에 챌린지(Challenge) 인가 및 원시 응답 측정
        │
   헬퍼 데이터(Helper Data)를 읽어와 에러 정정 디코딩 수행
        │
   비트 에러 개수가 ECC 허용 한계 이내인가?
   ┌────┴─────┐
  예           아니오
   │             │
기준 응답 복원   키 재현 실패 및 보안 리셋
   │
키 유도 함수(KDF)로 256비트 대칭키 생성
        │
   온칩 암호 하드웨어에서 암호 연산 수행
        │
   키 버퍼 및 레지스터 즉시 제로화(Zeroization)
```

#### 한줄 요약
- 챌린지 인가 → 원시 응답 생성 → 헬퍼 데이터 기반 ECC 복원 → KDF 키 생성 및 연산 후 즉시 소멸 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **SRAM PUF**: 전원 인가 시 SRAM 셀의 0 또는 1 초기 안정 상태 편차를 활용하는 방식.
- **Ring Oscillator PUF**: 동일 인버터 체인의 미세 지연 차이로 인한 발진 주파수를 비교하는 방식.

</details>

| 하드웨어 보안 키 생성 기술 | SRAM PUF | Ring Oscillator PUF | eFuse OTP 저장 | TRNG (난수발생기) |
|:---|:---|:---|:---|:---|
| 적용 기준 | 상용 MCU 온칩 SRAM 활용 초저비용 | FPGA 로직 셀 기반 PUF 구현 | 전통적인 제조사 고정 키 주입 | 실시간 일회용 세션키/난수 생성 |
| 핵심 특징 | 전원 인가 시 SRAM 셀의 초기 불안정 상태 활용 | 인버터 체인의 지연시간 차이로 주파수 비교 | 전기적 퓨즈를 영구 단선시켜 0/1 저장 | 열잡음/양자잡음 기반 예측불가 난수 |
| 한계 | 고온 장기 사용 시 셀 노화(Aging) 에러 증가 | 면적 및 전력 소모가 SRAM 대비 큼 | 물리적 레이저 프로빙/현미경 공격에 노출 | 매번 다른 난수가 나와 고정 키로 사용 불가 |

#### 한줄 요약
- 저비용 IoT에는 SRAM PUF가, FPGA에는 RO PUF가 적합하며, 영구 저장 방식(eFuse)의 물리 취약점을 극복한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **머신러닝 모델링 공격(ML Modeling Attack)**: 공격자가 대량의 챌린지-응답 쌍(CRP)을 수집하여 인공지능 신경망으로 PUF의 하드웨어 물리 특성을 수학적으로 복제하는 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 온도·전압 변동으로 인한 키 비트 에러 발생 | BCH 다항식 기반 ECC 설계 및 불안정 비트 사전 마스킹 | $-40\sim 125^\circ\text{C}$ 극한 환경에서도 키 재현율 100% 보장 |
| CRP 대량 질의를 통한 **머신러닝 모델링 공격** | Controlled PUF 구조(해시 전처리 및 입력 인터페이스 차단) | 챌린지-응답 수집 원천 차단 및 수학적 복제 무력화 |
| 장기 사용에 따른 반도체 소자 노화(Aging) | 헬퍼 데이터 무결성 검증 및 번인(Burn-in) 사전 선별 | 10년 이상 동작 수명 기간 동안 신뢰성 유지 |
| 공개된 헬퍼 데이터 조작을 통한 키 복원 교란 | 헬퍼 데이터 전자서명 부착 및 인증 체계 연동 | 보조 데이터 변조를 통한 키 생성 장애 방어 |

#### 한줄 요약
- BCH 정밀 ECC 적용, Controlled PUF 입력 차단, 헬퍼 데이터 무결성 보증으로 환경 변동과 AI 공격을 방어한다.

## Ⅶ. 결론

- IoT 및 차량용 보안 반도체는 **SRAM/RO PUF 기반 온디맨드 키 생성**을 구현하고, **Controlled PUF 및 ECC**를 연동하여 절대 복제 불가능한 RoT 확립

#### 한줄 요약
- PUF는 반도체 제조 편차를 디지털 지문으로 변환하여 물리적 역공학 공격을 원천 차단하는 차세대 하드웨어 보안 소자다.
