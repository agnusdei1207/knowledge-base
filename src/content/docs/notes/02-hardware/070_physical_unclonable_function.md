## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **PUF(Physical Unclonable Function)**: 반도체 제조 공정에서 발생하는 나노미터 단위의 불가피한 물리적 미세 편차를 기반으로, 칩마다 고유하고 예측 불가능한 암호학적 지문(디지털 지문)을 생성하는 보안 하드웨어 회로.
- **온디맨드 키 생성(Key Generation On-Demand)**: 암호 키를 불휘발성 메모리(Flash, eFuse)에 영구 저장하지 않고, 암호 연산이 필요한 순간에만 PUF 회로로부터 즉석 생성하여 사용한 뒤 레지스터에서 즉시 소멸시키는 기술.

</details>

- 정의/개념: 반도체 실리콘의 미세 공정 편차를 고유한 물리적 지문으로 변환하여 **비복제성(Unclonability)과 온디맨드 암호 키 생성**을 제공하는 **PUF(Physical Unclonable Function) 하드웨어 보안 기술**
- 배경/필요성: 기존 플래시나 eFuse에 암호 키를 영구 저장하는 방식의 **물리적 레이저 프로빙, 현미경 디캡(Decapsulation) 및 부채널 분석을 통한 키 탈취 취약점 극복**

#### 한줄 요약
- PUF는 반도체 제조 시 발생하는 나노 스케일 미세 편차를 이용해 칩마다 유일한 고유 암호 키를 온디맨드로 생성하는 하드웨어 지문 소자이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **고유성(Uniqueness)**: 동일한 마스크로 제조된 서로 다른 칩들 간의 PUF 출력 비트열이 통계적으로 이상적인 50%의 해밍 거리(Hamming Distance)를 가지며 완벽히 구별되는 특성.
- **신뢰성(Reliability)**: 동일한 칩에서 온도($-40\sim 125^\circ\text{C}$), 전압 변동, 경년 열화(Aging) 등 가혹한 환경 변화가 발생해도 100% 동일한 암호 키를 항상 재현해내는 안정성.

</details>

- 물리적 복제 불가능성: 반도체 공정의 양자역학적/물리적 무작위성에 기반하므로 동일한 제조사나 파운드리도 **물리적으로 복제 칩 제작 불가**
- 키 저장소 부재(Zero Storage): 평상시 전원이 차단되면 키가 메모리에 전혀 남아있지 않아 **물리적 메모리 덤프 공격 원천 무력화**
- **고유성(해밍 거리 50%)** 및 **신뢰성(재현율 100%)**: 퍼지 추출기(Fuzzy Extractor)와 결합하여 환경 잡음을 극복하고 완벽한 키 재현성 달성

#### 한줄 요약
- 키를 메모리에 저장하지 않고 필요할 때만 물리 지문으로부터 100% 재현하여 메모리 탈취 및 복제 공격을 차단한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **퍼지 추출기(Fuzzy Extractor)**: 노이즈가 섞인 PUF 원시 출력값(Raw Response)에서 BCH/리드솔로몬 에러 정정 부호(ECC)와 공개 헬퍼 데이터(Helper Data)를 이용해 100% 동일한 순수 암호 키를 복원하는 모듈.
- **헬퍼 데이터(Helper Data)**: 초기 키 등록(Enrollment) 시 생성되어 비보안 외장 플래시에 공개 저장되는 보조 데이터로, 비밀 키 정보를 전혀 노출하지 않으면서 런타임 노이즈 비트를 보정함.

</details>

```text
[PUF 온디맨드 암호 키 생성 아키텍처]
 ┌─ [1. PUF 원시 하드웨어 코어] ──── SRAM 셀 초기 불안정 상태 / 링 발진기(RO) 주파수 편차
 │                                                    │
 │                                                    ▼ (원시 비트열: 잡음 포함)
 ├─ [2. 퍼지 추출기 (Fuzzy Extractor)] ◄─── [공개 헬퍼 데이터 (Helper Data / BCH ECC)]
 │   └─ 에러 정정 디코더 (온도/전압으로 뒤집힌 비트 100% 오류 정정 복원)
 │                                                    │
 │                                                    ▼ (안정된 기준 비트열)
 ├─ [3. 엔트로피 압축 및 KDF 엔진] ───────── SHA-256 해시 기반 256비트 대칭키 유도
 │                                                    │
 └─ [4. 온칩 암호 가속 엔진] ─────────────── [AES-256 / RSA 연산 직결 후 즉각 레지스터 제로화]
```

선의 의미: 가지(`├─`, `└─`)는 하드웨어 소속 및 키 생성 파이프라인; PUF 코어의 원시 비트가 퍼지 추출기를 거쳐 암호 엔진으로 직결되고 사용 후 즉시 소멸됨

| 구성요소 | 소속 및 위치 | 핵심 엔지니어링 책임 | 주요 특징 |
|:---|:---|:---|:---|
| **PUF 원시 코어** | 실리콘 물리단 | 트랜지스터 문턱전압 편차를 기반으로 고유한 원시 챌린지-응답(CRP) 비트 생성 | SRAM / RO 어레이 |
| **등록 엔진 (Enrollment)**| 양산 테스트단 | 칩 제조 시 기준 응답을 측정하여 공개 보조 정보인 **헬퍼 데이터** 생성 | 1회성 등록 |
| **퍼지 추출기 (Fuzzy Extractor)**| 보안 컨트롤러 | BCH/Reed-Solomon 에러 정정 부호로 환경 변화에 따른 **잡음 비트 100% 복원** | 에러 정정 디코더 |
| **KDF / 해시 엔진** | 키 유도 계층 | 복원된 비트열의 편향을 제거하고 균등한 암호학적 엔트로피(128/256-bit) 추출 | SHA-256 기반 |
| **암호 연산 엔진** | 하드웨어 가속기 | 메모리 버스를 거치지 않고 **온칩 레지스터 직결로 암복호화 수행 후 즉시 소멸** | AES / ECC 가속기 |

#### 한줄 요약
- PUF 시스템은 원시 코어, 퍼지 추출기(헬퍼 데이터 연동), KDF 키 유도 엔진 및 암호 가속기로 구성된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **챌린지-응답 쌍(Challenge-Response Pair, CRP)**: PUF 회로에 특정 입력 자극(Challenge)을 인가했을 때 내부 물리적 지문에 의해 고유하게 출력되는 응답값(Response).

</details>

```text
1. 시스템 암호 연산 요청 (예: 부팅 서명 검증 또는 TLS 세션 연결)
                      │
                      ▼
2. PUF 코어에 전원 인가 및 챌린지(Challenge) 인가 ➔ 원시 응답(Raw Response) 생성
                      │
                      ▼
3. 외장 플래시에서 공개 헬퍼 데이터(Helper Data) 인출 ➔ 퍼지 추출기(Fuzzy Extractor) 입력
                      │
                      ▼
4. BCH 에러 정정 디코딩: 온도/전압 변동으로 반전된 비트 보정 수행
   ┌──────────────────┴──────────────────┐
[ 에러 개수가 ECC 정정 한계 이내 ]    [ 에러 한계 초과 (소자 파손/공격) ]
   │                                     │
   ▼                                     ▼
5. 100% 동일한 기준 응답 비트열 복원   5. 키 재현 실패 ➔ 시스템 보안 리셋 (Tamper Action)
   │
   ▼
6. 키 유도 함수(KDF) 실행 ➔ 256비트 AES 대칭 암호 키 온디맨드 유도
   │
   ▼
7. 하드웨어 암호 엔진에서 암복호화 연산 수행 (DRAM/플래시 저장 0화)
   │
   ▼
8. 연산 완료 즉시 내부 키 레지스터 완전 소거 (Zeroization)
```

분기 결과: **헬퍼 데이터 기반 ECC 복원을 통해** 외부 환경 변화에도 100% 동일한 키가 즉석 생성되며, **연산 후 즉시 파기됨**

#### 한줄 요약
- 챌린지 인가 ➔ 원시 응답 생성 ➔ 헬퍼 데이터 ECC 복원 ➔ KDF 키 유도 ➔ 암호 연산 ➔ 레지스터 제로화 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **SRAM PUF**: 전원 인가 순간 SRAM 셀의 양쪽 인버터 간 문턱전압 미세 불균형에 의해 0 또는 1로 결정되는 초기 상태 편차를 활용하는 방식.
- **Ring Oscillator PUF(RO PUF)**: 복수의 링 발진기 인버터 체인의 배선 및 지연시간 편차로 인한 발진 주파수 차이를 비교하는 방식.

</details>

| 하드웨어 키 생성/저장 기술 | SRAM PUF | Ring Oscillator PUF (RO PUF) | eFuse OTP 영구 저장 | TRNG (진성 난수발생기) |
|:---|:---|:---|:---|:---|
| 키 저장 및 생성 형태 | **미저장 (전원 인가 시 온디맨드 재현)**| **미저장 (주파수 비교 온디맨드 재현)**| 불휘발성 퓨즈에 영구 물리 저장 | 매 순간 무작위 일회용 난수 생성 |
| 물리적 복제 가능성 | **불가능 (나노 스케일 실리콘 편차)** | **불가능 (실리콘 지연 편차)** | 복제 가능 (키 값 추출 시 위조 칩 주입)| 해당 없음 (키 고정 불가) |
| 물리적 해킹 공격 저항성| **최고 (디캡/현미경 공격 시 키 파괴)**| **최고 (프로빙 시 기생 커패시턴스 변동)**| 취약 (레이저 전압 프로빙에 노출) | 높음 |
| 하드웨어 오버헤드 | **최소 (상용 MCU 내장 SRAM 재활용)**| 중간 (인버터 체인 및 카운터 면적) | 작음 (퓨즈 셀 어레이) | 작음 (아날로그 노이즈 소스) |
| 주요 적용 분야 | **초저가 IoT 단말, 스마트카드, MCU** | **FPGA 보안, 서버용 보안 SoC** | 레거시 장치 고정 비밀키 주입 | 실시간 세션 키, 암호 넌스(Nonce) |

#### 한줄 요약
- 저비용 IoT에는 SRAM PUF가, FPGA에는 RO PUF가 적합하며, 영구 저장 방식(eFuse)의 물리적 탈취 취약점을 완벽히 해결한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **머신러닝 모델링 공격(ML Modeling Attack)**: 공격자가 PUF의 입력(Challenge)과 출력(Response) 쌍을 대량 수집한 후 딥러닝 인공신경망을 학습시켜 PUF의 물리 동작을 소프트웨어로 수학적 복제하는 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 극한 온도($-40\sim 125^\circ\text{C}$) 변화로 인한 키 비트 오류 급증 | **BCH 다항식 기반 다단계 ECC 설계 및 노이즈 비트 사전 마스킹** | 전 온도 범위에서 암호 키 재현율 100% 달성 |
| 대량의 CRP 질의를 통한 **머신러닝 모델링 공격(ML Modeling Attack)** | **Controlled PUF 구조 (해시 함수 전처리 및 외부 직결 차단)** | 챌린지-응답 수집 원천 차단 및 수학적 복제 무력화 |
| 장기 사용에 따른 반도체 경년 열화(Aging) 및 셀 피로 현상 | **번인(Burn-in) 사전 선별 및 안티 에이징 차동 셀 레이아웃 적용** | 10년 이상 차량용 수명 주기 내 안정성 보장 |

#### 한줄 요약
- 실무에서는 다단계 BCH ECC로 온도를 극복하고, Controlled PUF로 AI 모델링 공격을 막으며, 안티 에이징 설계로 수명을 보장한다.

## Ⅶ. 결론

- 사물인터넷(IoT) 및 차량용 전장 반도체의 물리적 복제와 키 탈취 공격을 원천 차단하기 위해 **실리콘 공정 편차 기반의 SRAM/RO PUF 온디맨드 키 생성 기술을 하드웨어 신뢰 뿌리(RoT)로 표준 채택**하고, 환경 노이즈를 극복하기 위해 **BCH 기반 퍼지 추출기(Fuzzy Extractor)**를 연동하며, 수학적 모델링 공격을 방어하기 위해 **Controlled PUF 구조**를 필수 적용하는 차세대 무저장 하드웨어 보안 아키텍처 확립

#### 한줄 요약
- PUF는 반도체 제조 편차를 복제 불가능한 디지털 지문으로 변환하여 물리적 키 저장을 배제하는 차세대 하드웨어 보안의 정점이다.
