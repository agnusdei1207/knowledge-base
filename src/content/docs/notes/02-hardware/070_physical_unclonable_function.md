## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **PUF(Physical Unclonable Function)**: 반도체 제조 공정 중 발생하는 불가피한 미세 나노 물리적 편차(Manufacturing Variation)를 기반으로 고유 암호 키 및 반도체 지문을 생성하는 보안 기술.
- **제조 편차(Manufacturing Variation)**: 칩 제조 시 실리콘 다이 간 게이트 지연, 에칭 차이 등으로 생기는 불가피한 물리적 산란 현상.
- **고정 비밀 저장(Stored Secret)**: EEPROM, Flash 메모리 상에 비밀 암호 키를 0/1 수치 비트로 직접 저장하는 전통적 방식.

</details>

- 정의/개념: 칩별 **제조 편차**를 장치 고유 응답이나 키 재료로 변환하는 **PUF**
- 배경/필요성: **고정 비밀 저장**은 메모리 프로빙 시 키 비트가 직접 노출

#### 한줄 요약

- PUF는 반도체 **제조 편차**를 장치 고유 응답으로 활용한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **고유성(Uniqueness)**: 서로 다른 칩 간 생성되는 PUF 응답 비트열이 상호 명확히 구분되는 확률적 차별성 (Ideal 50% Inter-HD).
- **신뢰성(Reliability)**: 동일 칩 상에서 온도, 전압, 노화 변동에도 매번 동일한 PUF 키 응답을 재현해내는 안정성 (Ideal 0% Intra-HD).
- **엔트로피(Entropy)**: PUF 출력 응답의 무작위성 및 예측 불가능성 정도.
- **퍼지 추출기(Fuzzy Extractor)**: 잡음이 섞인 PUF 응답을 보조 데이터와 오류 정정 코드로 안정된 키로 변환하는 모듈.

</details>

- 칩 고유의 물리 신분증 역할을 담당하는 **고유성** 및 **엔트로피**
- 온도·전압 변동에서 응답 재현성을 측정하는 **신뢰성** 평가
- 잡음 응답을 안정된 암호 키로 변환하는 **퍼지 추출기** 연동

$$
\mathrm{RER}(\%) = \frac{d_H(R_{\mathrm{enroll}}, R_{\mathrm{retest}})}{n} \times 100
$$

#### 한줄 요약

- PUF 품질은 장치 간 **고유성**, 동일 장치의 신뢰성, 응답 엔트로피를 함께 측정해 평가한다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **PUF 회로(PUF Circuit)**: SRAM 셀 초기화 상태, Ring Oscillator 발진 주파수 차이 등을 활용하여 0/1 고유 응답 비트를 생성하는 회로.
- **보조 데이터 저장소(Helper-Data Store)**: 키 복원 시 오류 정정을 위해 헬퍼 데이터(BCH/Reed-Solomon 코딩)를 보관하는 저장 영역.
- **암호 서비스(Cryptographic Service)**: 재생된 PUF 전용 디바이스 고유 키(Device Unique Key)를 기반으로 대칭키/비대칭키 암호 연산을 수행하는 모듈.

</details>

```text
       [PUF 회로]
            |
[퍼지 추출기] -- [보조 데이터 저장소]
            |
       [암호 서비스]
```

선의 의미: PUF 회로 신호가 퍼지 추출기로 인가되고 보조 데이터 저장소의 오류 정정 정보와 결합되어 암호 서비스 키로 제공되는 구조.

| 구성요소 | 책임 |
|:---|:---|
| PUF 회로 | SRAM/RO 기반 물리 미세 **제조 편차** 응답 신호 방출 |
| 퍼지 추출기 | ECC 오류 정정과 잡음 응답 기반 안정된 키 유도 |
| 보조 데이터 저장소 | 키 복원용 **보조 데이터**의 무결성과 접근 통제 |
| 암호 서비스 | 런타임 **키 삭제(Zeroization)** 및 암호 연산 수행 |

#### 한줄 요약

- **PUF 회로**의 응답과 **보조 데이터 저장소**의 정보를 결합하고 **암호 서비스**에서 장치 키를 사용한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **등록(Enrollment)**: 파운드리 칩 생산 단계에서 PUF 기준 응답을 수집하고 헬퍼 데이터를 생성/저장하는 최초 등록 단계.
- **재생(Reconstruction)**: 디바이스 현장 구동 시 헬퍼 데이터와 PUF 실시간 응답을 결합하여 메모리 상에 키를 임시 복원하는 런타임 단계.
- **RER(Response Error Rate)**: 노화, 온도 변화 시 발생하는 PUF 비트의 에러율.

</details>

```text
┌──────────── 등록 단계 ────────────┐
│ [통제 환경•등록 질의]             │
│          │                         │
│          ▼ 1. 기준 응답 측정       │
│      [PUF 회로]                    │
│          │                         │
│          ▼ 2. 보조 데이터 생성     │
│    [보조 데이터 저장소]            │
└───────────────────────────────────┘

┌──────────── 재생 단계 ────────────┐
│ [현장 환경•동일 질의]             │
│          │                         │
│          ▼ 3. 현장 응답 측정       │
│      [PUF 회로]                    │
│          │                         │
│          ▼ 4. 오류 보정•키 복원    │
│ [퍼지 추출기 + 보조 데이터]        │
│          │                         │
│          ▼                         │
│       [복원 키]                    │
└───────────────────────────────────┘
```

### 동작 원리

1. **기준 응답 측정**: 파운드리 검사 공정 상에서 **PUF 회로**의 기준 챌린지-응답 파이프라인 수집.
2. **보조 데이터 생성**: **퍼지 추출기** 인코딩을 거쳐 키 복원용 **보조 데이터**를 영구 칩에 기록.
3. **현장 응답 측정**: 디바이스 부팅 및 키 요구 발생 시 실시간 PUF **현장 응답 측정**.
4. **오류 보정·키 복원**: **보조 데이터**와 실시간 응답을 결합해 RER 범위 안의 오류를 정정하고 키 재생.

#### 한줄 요약

- 등록 시 만든 **보조 데이터**로 현장의 잡음 응답을 보정하여 동일한 키를 재생한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **약한 PUF(Weak PUF)**: 소수의 fixed 챌린지-응답을 통해 칩 내부 고유 암호 키(DUK)를 생성하는 온칩 PUF (예: SRAM PUF).
- **강한 PUF(Strong PUF)**: 수많은 챌린지-응답 쌍(CRP)을 형성하여 디바이스 상호 인증에 직접 활용하는 외부 방출용 PUF (예: Arbiter PUF).
- **TRNG(True Random Number Generator)**: 물리적 아날로그 무작위 노이즈를 통해 매번 고유한 비트열을 생성하는 진난수 생성기.

</details>

| 구분 | 약한 PUF (Weak PUF) | 강한 PUF (Strong PUF) | TRNG (Random Generator) |
|:---|:---|:---|:---|
| 적용 기준 | 칩 내부 고유 암호 키(DUK/Root Key) 재생 시 | 챌린지-응답 기반 디바이스 상호 인증 시 | 일회성 암호화 세션 키 및 난수 시드 생성 시 |
| 핵심 특징 | **SRAM/RO** 기반 소수 응답, 칩 내부 사용 | 대량의 **CRP** 형성, 외부 인증 활용 | 매번 무작위 비트열 생성 (Non-repeatable) |
| 한계 | 외부 인증용 대량 CRP 형성 불가 | ML 기반 **모델링 공격** 타깃 노출 위험 | 동일 키 재생 불가능 (키 저장 불가) |

#### 한줄 요약

- **PUF는 키 재생**, TRNG는 새 난수 생성, OTP 메모리는 고정값 저장에 사용한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **안정 비트(Stable Bit)**: 환경 변화에서도 값의 뒤집힘 확률이 낮은 PUF 셀 비트.
- **모델링 공격(Modeling Attack)**: 머신러닝(ML) 알고리즘을 통해 강한 PUF의 대량 CRP 입력-출력 패턴을 학습하여 암호키를 추정해내는 기법.
- **키 삭제(Key Zeroization)**: 암호 연산 완료 후 SRAM 상에 복원된 임시 키를 0x00으로 깨끗이 파기하는 보안 처리.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 경년 변화 및 극온 조건에서 **RER** 증가 | **안정 비트** 선별과 오류 정정 여유 설계 | 허용 환경에서 키 재생 실패율 감소 |
| ML 머신러닝 기반 **모델링 공격**으로 CRP 유출 | CRP 응답 출력 제어 및 비선형 믹싱 어댑터 수용 | 인증 키 예측 불가능성 확보 |
| 런타임 복원 키의 SRAM 상 노출 위험 | 암호 연산 완결 즉시 **키 삭제** 수행 | 메모리 프로빙 및 덤프 공격 차단 |

> 사례: **SRAM PUF**와 **퍼지 추출기**의 환경별 키 재생 실패율 검증

#### 한줄 요약

- 필요할 때만 PUF에서 **키를 재생**하고 암호 연산 직후 메모리에서 삭제하여 노출 시간을 줄인다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **PUF 유형 선택 기준(PUF Type Selection Criteria)**: 암호 키 온칩 생성용인지, 외부 장치 상호 인증용인지에 따른 칩셋 선택 지표.

</details>

- **PUF 유형 선택 기준**에 따라 칩 내부 전용 루트 키 생성은 **약한 PUF**, 인증용 대량 CRP 형성은 **강한 PUF** 선정

#### 한줄 요약

- 온칩 키 재생은 약한 PUF, 외부 인증은 모델링 저항을 검증한 강한 PUF를 선택한다.
