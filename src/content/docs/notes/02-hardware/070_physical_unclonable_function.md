## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **물리적 복제 불가 함수(Physical Unclonable Function, PUF)**: 쌍둥이도 지문이 다르듯, 칩을 똑같이 찍어내도 공정상의 미세한 흠집(오차) 때문에 칩마다 전기가 미세하게 다르게 흐르는 현상을 이용해 절대 못 베끼는 '하드웨어 지문'을 만드는 기술이다.
- **제조 편차(Manufacturing Variation)**: 반도체 공장에서 칩을 구울 때 완벽하게 똑같이 못 굽고 두께나 선 굵기가 0.0001mm라도 달라져버리는, 사람으로 치면 고유한 흉터나 지문 같은 것이다.
- **고정 비밀 저장(Stored Secret)**: 예전에는 암호 키를 메모리에 '1234'라고 대놓고 적어놨는데, 해커가 칩 껍데기를 까서 현미경으로 들여다보면 다 털리는 멍청한 방식이다.

</details>

- 정의: 칩별 **제조 편차**를 장치 고유 응답이나 암호 키 재료로 변환하는 **물리적 복제 불가 함수**
- 배경: 칩 안에 암호 키를 대놓고 적어두는 전통적인 **고정 비밀 저장** 방식은, 해커가 칩을 뜯고 현미경으로 메모리를 들여다보면(프로빙) 키 비트가 그대로 노출되어 털리기 때문

#### 한줄 요약

- 암호 키를 메모리에 저장해두면 해커가 훔쳐가니까, 아예 저장하지 않고 칩의 미세한 흠집(제조 편차)을 이용해 필요할 때마다 고유 지문을 뽑아내는 마법의 기술이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **고유성(Uniqueness)**: 내 칩 지문이랑 네 칩 지문이 완전히 다르게 나와야 한다는 특성으로, 지문이 겹치면 다 털리니까 50% 확률로 무조건 다르게 나와야 한다.
- **신뢰성(Reliability)**: 내 칩 지문을 어제 뽑고 오늘 다시 뽑아도, 혹은 영하 20도에서 뽑아도 똑같은 지문이 나와야 비밀번호(키)로 쓸 수 있는 강인한 재현성이다.
- **엔트로피(Entropy)**: 지문이 얼마나 꼬불꼬불하고 엉망진창인지 나타내는 수치로, 패턴이 너무 뻔하면 해커가 때려 맞추니까 무조건 난장판이어야 한다.
- **퍼지 추출기(Fuzzy Extractor)**: 날씨나 노화 때문에 칩 지문이 살짝 찌그러져서 나와도, 보정 안경을 씌워서 원래 지문(암호 키)으로 똑같이 복원해 내는 기가 막힌 알고리즘이다.

</details>

- 칩 고유의 물리 신분증 역할을 담당하는 **고유성** 및 아무도 예측할 수 없는 **엔트로피**를 가짐.
- 온도나 전압이 미쳐 날뛰는 상황에서도 항상 똑같은 암호 키를 만들어내는지 측정하는 **신뢰성** 평가가 핵심임.
- 칩에서 나오는 삐뚤빼뚤한 잡음 응답을 오류 없이 완벽하고 안정된 암호 키로 깎아내는 **퍼지 추출기** 연동이 필수적임.

$$
\mathrm{RER}(\%) = \frac{d_H(R_{\mathrm{enroll}}, R_{\mathrm{retest}})}{n} \times 100
$$

#### 한줄 요약

- PUF의 품질은 남들과 얼마나 다른지(고유성), 내가 다시 뽑아도 똑같은지(신뢰성), 패턴이 얼마나 미쳤는지(엔트로피)로 평가한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **퍼프 회로(PUF Circuit)**: 칩이 켜질 때 전기가 왼쪽으로 먼저 가는지 오른쪽으로 먼저 가는지 레이스를 시켜서, 그 미세한 속도 차이로 0과 1의 지문을 뽑아내는 하드웨어 공장이다.
- **보조 데이터 저장소(Helper-Data Store)**: 퍼지 추출기가 찌그러진 지문을 펴서 원래 암호 키로 복원할 때, 커닝 페이퍼처럼 참고하는 힌트(보조 데이터)를 모아둔 금고이다.
- **암호 서비스(Cryptographic Service)**: 방금 만든 지문(암호 키)으로 금고 문을 열거나 데이터를 암호화하고, 해커가 못 훔쳐가게 곧바로 키를 삭제해버리는 보안 요원이다.

</details>

```text
[ 하드웨어 지문 추출 및 찌그러짐 복원 암호 키 연성 프레임워크 ]
                        [ 퍼프 회로 (하드웨어 지문 공장) ]
                                      │
[ 보조 데이터 저장소 (커닝 페이퍼) ] ─── [ 퍼지 추출기 (오류 정정 마법사) ]
                                      │
                         [ 암호 서비스 (키 사용 및 파기) ]
```

| 구성요소 | 책임 |
|:---|:---|
| **퍼프 회로** | 공장에서 칩 구울 때 생긴 미세한 불량(제조 편차)을 이용해 0과 1의 고유 지문 신호를 방출하는 하드웨어 공장 |
| **퍼지 추출기** | 퍼프 회로에서 나온 삐뚤빼뚤한 지문 신호를 오류 정정(ECC)으로 깎고 다듬어서 완벽한 암호 키로 연성하는 마법사 |
| **보조 데이터 저장소** | 퍼지 추출기가 암호 키를 복원할 때 참고하는 힌트(보조 데이터)를 보관하는 무결성 금고 |
| **암호 서비스** | 만들어진 암호 키로 데이터를 암호화하고, 일이 끝나면 램(SRAM)에서 키를 흔적도 없이 0으로 덮어써 지워버리는 살수 |

#### 한줄 요약

- 퍼프 회로가 찌그러진 지문을 던져주면, 퍼지 추출기가 힌트(보조 데이터)를 보고 반듯한 암호 키로 깎아서 암호 서비스에 넘긴다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **등록(Enrollment)**: 공장에서 칩 팔기 전에 딱 한 번, 에어컨 빵빵한 환경에서 완벽한 오리지널 지문을 뽑아보고 힌트(보조 데이터)를 만들어 칩에 적어두는 입학식이다.
- **재생(Reconstruction)**: 나중에 고객이 한겨울에 칩을 켤 때, 찌그러져 나오는 지문을 공장에서 적어둔 힌트를 보고 오리지널 키로 다시 살려내는 부활 작업이다.
- **응답 오류율(Response Error Rate, RER)**: 온도나 칩 노화 때문에 어제 뽑은 지문이랑 오늘 뽑은 지문이 얼마나 틀려 먹었는지 나타내는 불량률이다.

</details>

```text
[ 칩 지문 기반 암호 키 등록 및 런타임 재생 십자포화 흐름 ]

┌──────────── 공장 등록 단계 (입학식) ────────────┐
│ 1. 쾌적한 공장에서 칩을 켜고 기준 지문(응답) 측정 │
│                         │                         │
│                         ▼                         │
│ 2. 찌그러짐 복원용 힌트(보조 데이터) 만들어 칩에 저장 │
└───────────────────────────────────────────────────┘
                          │
┌──────────── 현장 재생 단계 (부활 작업) ──────────┐
│ 3. 한겨울에 고객이 칩을 켜서 현장 지문 실시간 측정│
│                         │                         │
│                         ▼                         │
│ 4. 방금 뽑은 찌그러진 지문 + 공장의 힌트(보조 데이터) │
│                         │                         │
│                         ▼                         │
│ 5. 오류 정정 후 오리지널 완벽 암호 키 100% 재생 완료 │
└───────────────────────────────────────────────────┘
```

### 동작 원리

1. 기준 지문 측정: 공장에서 칩을 찍어낼 때 **퍼프 회로**에 전기를 먹여 기준 챌린지-응답 지문을 수집함.
2. 보조 힌트 생성: **퍼지 추출기**를 굴려서, 나중에 현장에서 지문이 약간 찌그러져도 복원할 수 있는 힌트(보조 데이터)를 칩에 영구 기록함.
3. 현장 지문 측정: 기계가 켜지고 암호 키가 필요해지면, 실시간으로 퍼프 회로를 돌려 **현장 응답 측정**을 수행함.
4. 오류 보정 및 키 복원: 공장에서 심어둔 보조 데이터와 방금 뽑은 지문을 섞어서, 노화나 온도로 인한 찌그러짐(RER)을 펴고 완벽한 키를 재생함.

#### 한줄 요약

- 공장에서 완벽한 지문을 뽑아 힌트를 만들어두고, 나중에 현장에서 찌그러진 지문이 나와도 힌트를 써서 완벽한 키로 살려낸다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **약한 퍼프(Weak PUF)**: 메모리(SRAM) 초기값 찌꺼기를 이용해서 지문을 만드는데, 지문 종류가 딱 하나밖에 안 나와서 남한테는 안 보여주고 칩 내부 암호로만 쓰는 쫄보 퍼프이다.
- **강한 퍼프(Strong PUF)**: 질문(챌린지)을 던질 때마다 서로 다른 지문(응답)이 수억 개씩 쏟아져 나와서, 서버랑 기기가 "너 진짜야?"라며 서로 인증할 때 대놓고 쓰는 깡패 퍼프이다.
- **진난수 생성기(True Random Number Generator, TRNG)**: 전기 노이즈를 갈아 넣어서 매번 절대 똑같은 값이 안 나오는 미친 주사위로, 임시 비밀번호 만들 때 쓴다.

</details>

| 구분 | **약한 퍼프** (Weak PUF) | **강한 퍼프** (Strong PUF) | **진난수 생성기** (TRNG) |
|:---|:---|:---|:---|
| 시스템 적용 최적 기준 | 칩 내부에서만 몰래 쓰는 하나뿐인 절대 암호 키(Root Key)를 뼛속에서 재생할 시 | 외부 장비와 서로가 진짜인지 챌린지-응답을 미친 듯이 주고받으며 빡세게 상호 인증할 시 | 세션 키나 씨앗(Seed)처럼 한 번 쓰고 버릴 무작위 난수를 쉴 새 없이 뽑아낼 시 |
| 아키텍처 핵심 구현 특징 | 지문 종류가 몇 개 없어서 칩 밖으로 유출 안 하고 내부용으로만 철저히 락다운시킴 | 지문 패턴 종류(CRP)가 수억 개라 밖으로 뿌려대며 외부 서버 인증용으로 찰지게 활용함 | 물리적 노이즈를 갈아 넣어서 매번 절대 똑같이 안 나오는 미친 무작위 비트열 생성 |
| 극복해야 할 태생적 한계점 | 지문 개수가 딸려서 외부 기기와 상호 인증용으로 돌려쓰기엔 불가능한 태생적 한계 | 수억 개의 질의응답 패턴을 딥러닝(머신러닝)으로 학습해서 키를 통째로 추정해버리는 해킹(모델링 공격) 타깃 노출 | 매번 값이 바뀌므로 PUF처럼 똑같은 암호 키를 다시 복원해서 쓰는 것은 원천 불가능함 |

#### 한줄 요약

- 내 칩 안에서만 쓰는 키는 약한 퍼프, 남이랑 통신하며 인증할 때는 강한 퍼프, 한 번 쓰고 버릴 비밀번호는 진난수 생성기를 쓴다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **안정 비트(Stable Bit)**: 지문 비트 수만 개 중에서, 영하 20도가 되든 칩이 10년 늙든 절대 0에서 1로 안 뒤집히고 꿋꿋하게 버티는 강철 같은 비트만 골라내는 기술이다.
- **모델링 공격(Modeling Attack)**: 강한 퍼프가 질문 1번엔 답 1번, 질문 2번엔 답 2번을 주는 걸 해커가 딥러닝으로 학습시켜서, "질문 3만 번 던지면 답 3만 번 나오겠네?" 하고 통째로 예측해버리는 끔찍한 인공지능 공격이다.
- **키 삭제(Key Zeroization)**: 힘들게 복원한 암호 키를 쓰고 나서 램(SRAM)에 그냥 두면 해커가 빼가니까, 다 쓴 즉시 0으로 덮어써서 흔적도 없이 태워버리는 보안 기본 소양이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 칩이 늙거나 한겨울에 얼어붙으면 지문이 심하게 찌그러져(RER 폭발) 암호 키 복원이 실패하는 벽돌 셧다운 사태 | 지문 중에서 환경이 변해도 값이 잘 안 뒤집히는 **안정 비트**만 골라 쓰고 오류 정정 맷집을 한계치까지 펌핑 | 극한 환경에서도 암호 키 재생 실패율을 쥐어짜 낮춰 시스템 무중단 생존 100% 보장 |
| 해커가 딥러닝(ML) 알고리즘으로 강한 PUF의 입출력 패턴을 미친 듯이 학습시켜 암호키를 추정해내는 **모델링 공격** 발발 | 입력값과 출력값을 함부로 못 맞추게 뒤섞어버리는 비선형 믹싱 어댑터를 박아 딥러닝 패턴 예측을 완전히 뭉개버림 | 해커의 딥러닝 기반 인증 키 예측을 원천 불가능하게 만들어 하드웨어 지문 탈취 방어 |
| 힘들게 복원한 암호 키를 램(SRAM)에 놔뒀더니 해커가 메모리를 뒤져서(프로빙) 홀라당 털어가는 끔찍한 위험 | 암호화 연산이 끝나는 즉시 램에 있는 임시 키를 0으로 덮어써서 흔적도 없이 날려버리는 얄짤없는 **키 삭제** 수행 | 해커가 메모리를 얼리거나 까뒤집는 덤프 공격을 들이밀어도 가져갈 키가 없게 원천 차단 |

#### 한줄 요약

- 잘 안 변하는 지문(안정 비트)만 골라 쓰고, 해커가 딥러닝으로 지문 패턴 못 읽게 뒤섞어버리며, 다 쓴 암호 키는 즉시 메모리에서 삭제해라.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **퍼프 유형 선택 기준(PUF Type Selection Criteria)**: 내가 칩 안에 암호 키를 몰래 숨겨둘 건지(약한 놈), 서버랑 대놓고 핑퐁치며 인증할 건지(강한 놈) 견적 내어 퍼프 종류를 고르는 잣대이다.

</details>

- **퍼프 유형 선택 기준** 원칙에 따라 칩 내부 전용 루트 키 생성은 **약한 퍼프**(Weak PUF), 디바이스 상호 인증용 대량 패턴 형성은 **강한 퍼프**(Strong PUF) 적용 기조 확립함

#### 한줄 요약

- 칩 안에서 나 혼자 쓸 키는 약한 퍼프로 만들고, 서버랑 수만 번 인증할 때는 모델링 방어가 된 강한 퍼프를 선택해라.
