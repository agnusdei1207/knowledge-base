## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **PUF(Physical Unclonable Function)**: 반도체 제조 공정에서 발생하는 나노미터 단위의 불가피한 물리적 미세 편차를 기반으로, 칩마다 고유하고 예측 불가능한 암호학적 지문(디지털 지문)을 생성하는 보안 하드웨어 회로.
- **온디맨드 키 생성(Key Generation On-Demand)**: 암호 키를 불휘발성 메모리(Flash, eFuse)에 영구 저장하지 않고, 암호 연산이 필요한 순간에만 PUF 회로로부터 즉석 생성하여 사용한 뒤 레지스터에서 즉시 소멸시키는 기술.

</details>

- 정의/개념: 반도체 실리콘의 미세 공정 편차를 고유한 물리적 지문으로 변환하여 비복제성 및 온디맨드 암호 키 생성을 제공하는 **PUF 보안 기술**
- 배경/필요성: 비휘발성 메모리(eFuse, Flash)에 암호 키 영구 저장 시 발생하는 물리적 디캡, 마이크로프로빙 및 **부채널 공격을 통한 루트 키 유출 위험 방어 한계**

#### 한줄 요약
- PUF는 반도체 제조 시 발생하는 나노 스케일 미세 편차를 이용해 칩마다 유일한 고유 암호 키를 온디맨드로 생성하는 하드웨어 지문 소자이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **고유성(Uniqueness)**: 칩 간 응답의 해밍 거리가 이상값 50%에 가까운 특성.
- **신뢰성(Reliability)**: 환경 변화에도 동일 칩의 응답을 안정적으로 재현하는 특성.

</details>

- 복제 저항성: 반도체 공정 편차에 기반한 칩별 고유 응답 생성
- 키 저장소 부재(Zero Storage): 평상시 키가 메모리에 존재하지 않아 물리적 메모리 덤프 공격 무력화
- **고유성**·**신뢰성**: 퍼지 추출기로 환경 잡음을 보정해 키 재현

#### 한줄 요약
- 키를 메모리에 저장하지 않고 필요할 때만 물리 지문으로부터 100% 재현하여 메모리 탈취 및 복제 공격을 차단한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **퍼지 추출기(Fuzzy Extractor)**: ECC와 헬퍼 데이터로 PUF 응답 잡음을 보정해 키를 복원하는 모듈.
- **헬퍼 데이터(Helper Data)**: 초기 키 등록(Enrollment) 시 생성되어 비보안 외장 플래시에 공개 저장되는 보조 데이터로, 비밀 키 정보를 전혀 노출하지 않으면서 런타임 노이즈 비트를 보정함.

</details>

```text
[PUF 온디맨드 키 생성 아키텍처]
  │
  ├─ [물리 실리콘 소자 계층] (고유 물리 지문)
  │     ├─ [SRAM 셀 어레이] (파워온 비트 상태 편차)
  │     └─ [링 발진기 (RO)] (인버터 지연시간 주파수 편차)
  │
  ├─ [신호 정제 및 키 유도 계층] (잡음 보정 및 압축)
  │     ├─ [퍼지 추출기] (헬퍼 데이터 및 BCH/ECC 보정)
  │     └─ [KDF / 해시 엔진] (엔트로피 압축 및 AES 키 생성)
  │
  └─ [온칩 암호 실행 계층] (Zero Storage 보호)
        ├─ [온칩 암호 가속기] (AES/ECC 암·복호화 연산)
        └─ [소멸 메커니즘] (연산 직후 레지스터 제로화)
```

- 선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| PUF 원시 코어 | 공정 편차 기반 챌린지·응답 생성 |
| 등록 엔진 | 기준 응답에서 **헬퍼 데이터** 생성 |
| 퍼지 추출기 | ECC로 환경 잡음 비트 보정 |
| KDF·해시 엔진 | 응답 편향 제거와 암호 키 유도 |
| 암호 연산 엔진 | 온칩 키 사용 후 레지스터 소거 |

#### 한줄 요약
- 저장 매체에 남는 것이 키가 아니라 노출돼도 무방한 헬퍼 데이터뿐이라 탈취 대상이 되던 키 저장 계층 자체가 없어지고, 유도된 키는 온칩 암호 연산 엔진 안에서만 쓰인 뒤 소거돼 칩 밖으로 나가는 경로를 두지 않는다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **챌린지-응답 쌍(Challenge-Response Pair, CRP)**: PUF 회로에 특정 입력 자극(Challenge)을 인가했을 때 내부 물리적 지문에 의해 고유하게 출력되는 응답값(Response).

</details>

```text
[시스템 런타임 암호 연산 또는 기기 인증 요청]
                     │
                     ▼
1. PUF 아날로그 회로에 챌린지(Challenge) 자극 인가 및 원시 응답 생성
                     │
                     ▼
2. 외장 플래시로부터 공개된 헬퍼 데이터(Helper Data) 로드
                     │
                     ▼
3. 퍼지 추출기(Fuzzy Extractor)의 BCH/ECC 에러 정정 알고리즘 구동
    ┌────────────────┴────────────────┐
 [ 에러 비트가 ECC 정정 한계 이내 ]  [ 에러 비트 한계 초과 (공격/소자 파손) ]
    │                                 │
    ▼                                 ▼
4. KDF 기반 고정밀 루트 대칭키 유도  4. 키 복원 실패 처리 및 보안 리셋 트리거
    │
    ▼
5. 온칩 암호 엔진에서 즉각 연산 수행 및 키 레지스터 제로화(Zeroization) 소멸
```

- 분기 결과: 노이즈가 ECC 한계 내이면 암호 키를 100% 동일하게 재현하여 연산 후 즉시 소멸시키며, 물리 공격 등으로 에러 한계 초과 시 즉각 보안 리셋됨

**동작 원리**

1. CPU나 보안 엔진의 암호 키 요구 시 PUF 회로 전원 인가 및 챌린지 주소 전달을 통한 고유 미세 편차 원시 비트열 출력
2. 반도체 제조 시 안전 공개 저장된 헬퍼 데이터 로드 및 현재 원시 비트열과의 XOR 연산 수행
3. 퍼지 추출기 에러 정정(ECC) 회로 구동을 통한 온도·전압 잡음 비트 실시간 보정 및 원본 기준 비트 복원
4. 정제 비트 스트림의 KDF 해시 함수 압축을 통한 암호학적 엔트로피 보강 및 256비트 대칭 마스터 키 도출
5. 외부 핀 노출 없는 온칩 암호 가속기 직접 전달 연산 수행 및 사용 직후 레지스터 제로화(Zeroization) 파기

#### 한줄 요약
- PUF는 키를 저장하지 않아 탈취 표면 자체를 없애지만 응답이 온도·전압에 따라 흔들리므로, ECC와 헬퍼 데이터라는 보정 비용을 대가로 재현성을 사는 구조가 된다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **정적 램 물리적 복제 방지 기능(Static Random Access Memory Physical Unclonable Function, SRAM PUF)**: 전원 인가 순간 SRAM 셀의 양쪽 인버터 간 문턱전압 미세 불균형에 의해 0 또는 1로 결정되는 초기 상태 편차를 활용하는 방식.
- **링 발진기 물리적 복제 방지 기능(Ring Oscillator Physical Unclonable Function, RO PUF)**: 복수의 링 발진기 인버터 체인의 배선 및 지연시간 편차로 인한 발진 주파수 차이를 비교하는 방식.

</details>

| 대상 구분 | SRAM PUF | Ring Oscillator PUF (RO PUF) | eFuse OTP 영구 저장 | TRNG (진성 난수발생기) |
|:---|:---|:---|:---|:---|
| 적용 기준 | 추가 면적 없이 표준 내장 SRAM 활용 초저가 IoT 단말 보안 키 생성 시 | FPGA 기반 재구성 로직 및 발진기 지연 비교 보안 환경 시 | 고정 키 물리 주입이 가능하고 제조 라인이 확립된 레거시 기기 시 | 예측 불가능한 일회용 세션 키 및 암호 넌스(Nonce) 생성 시 |
| 핵심 특징 | 전원 인가 순간 SRAM 초기 상태 편차 활용, 온디맨드 키 재현, 제로 스토리지(Zero Storage) | 링 발진기 인버터 체인 주파수 차이 비교, FPGA 로직 적합, 고유성 우수 | 불휘발성 퓨즈 영구 단선 물리 저장, 고정 키 유지, 검증된 신뢰성 | 물리적 열잡음/양자 요동 기반 엔트로피원 활용, 매 순간 무작위 일회용 난수 생성 |
| 한계 | 온도·전압 변동에 따른 노이즈 비트 발생으로 퍼지 추출기(ECC) 오버헤드 수반 | 다수의 링 발진기 배치에 따른 실리콘 면적 및 소비 전력 오버헤드 | 칩 디캡 및 전자현미경 프로빙 등 물리적 역공학 공격 시 키 탈취 위험 노출 | 키 고정이 불가능하여 기기 고유 식별자나 루트 키로 단독 사용 불가 |

#### 한줄 요약
- 저비용 IoT에는 **SRAM PUF**가, FPGA에는 **RO PUF**가 적합하며, 영구 저장 방식(eFuse)의 물리적 탈취 취약점을 완벽히 해결한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **머신러닝 모델링 공격(ML Modeling Attack)**: 공격자가 PUF의 입력(Challenge)과 출력(Response) 쌍을 대량 수집한 후 딥러닝 인공신경망을 학습시켜 PUF의 물리 동작을 소프트웨어로 수학적 복제하는 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 극한 온도 변화로 인한 키 비트 오류 증가 | **다단계 ECC 설계**와 잡음 비트 마스킹 | 운용 범위에서 키 재현율 개선 |
| 대량의 **CRP** 질의를 통한 **머신러닝 모델링 공격** | **Controlled PUF 구조 (해시 전처리 및 외부 직결 차단)** | 챌린지-응답 수집 차단 및 수학적 복제 무력화 |
| 장기 사용에 따른 반도체 경년 열화 및 셀 피로 현상 | **번인(Burn-in) 사전 선별** 및 안티 에이징 차동 셀 레이아웃 적용 | 10년 이상 차량용 수명 주기 내 안정성 보장 |

#### 한줄 요약
- 실무에서는 다단계 ECC로 환경 잡음을 잡고, Controlled PUF로 머신러닝 복제를 막으며, 번인 선별로 경년 열화를 방어한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **통제된 물리적 복제 불가 기능(Controlled PUF)**: 외부에서 챌린지와 응답 신호선에 직접 접근하지 못하도록 암호 해시 함수나 제어 로직으로 감싸 머신러닝 모델링 공격을 원천 차단하는 하드웨어 구조.
- **양자 내성 암호(Post-Quantum Cryptography, PQC)**: 양자 컴퓨터의 쇼어 알고리즘으로도 해독되지 않도록 격자 기반 등 수학적 난제에 기반하여 설계된 차세대 암호 체계.

</details>

- 실리콘 메모리에 키를 영구 저장하지 않는 제로 스토리지 기반 하드웨어 신뢰 뿌리(RoT) 기술의 확립과 함께, 양자 내성 암호(PQC) 키 생성 및 머신러닝 모델링 공격 방어를 위한 Controlled PUF 아키텍처로의 진화 추세.
- 가혹한 온도·전압 변동 환경에서도 100% 키 재현성을 보장하는 다단계 퍼지 추출기 설계와 반도체 경년 열화를 억제하는 번인 선별 체계 확보 필요.

#### 한줄 요약
- 제로 스토리지 기반의 온디맨드 키 복원력과 Controlled PUF 보호 구조를 결합하여 차세대 PQC 시대의 물리적 불변 보안을 달성해야 한다.
