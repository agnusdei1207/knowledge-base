## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **PUF(Physical Unclonable Function)**: 동일한 공정으로 제작된 반도체 간에도 존재하는 미세한 물리적 공정 편차를 이용하여 칩 고유의 디지털 지문(암호 키)을 생성하는 기술.
- **Manufacturing Variation(공정 편차)**: 반도체 리소그래피, 도핑 농도, 배선 지연 등에서 발생하는 제어 불가능한 미세 물리적 차이.
- **Key Storage Free(비저장형 키 생성)**: 암호 키를 플래시/EEPROM 메모리에 영구 저장하지 않고 전원 인가 시 실시간 재생(Reconstruction) 후 사용 즉시 파기하는 방식.

</details>

- 정의/개념: 반도체 제조 공정 중 발생하는 불가피한 미세 물리적 편차(Manufacturing Variation)를 고유한 챌린지-응답(CRP) 및 하드웨어 디지털 지문(암호 키)으로 변환하는 하드웨어 보안 기술
- 배경/필요성: 비휘발성 메모리(EEPROM/Flash)에 비밀키를 평문 저장하는 기존 방식의 **침습적/비침습적 물리 공격(Probing, DPA) 취약점을 극복하고 비저장형 하드웨어 Root of Trust(RoT) 구현**

#### 한줄 요약

- 반도체 제조 편차를 이용해 **비휘발성 메모리 저장 없이 온디맨드로 고유 암호키를 생성하는 하드웨어 지문**

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **Uniqueness(고유성)**: 서로 다른 칩 간의 PUF 응답 비트 차이를 나타내는 척도로 이상적인 해밍 거리(HD)는 50%.
- **Reliability(신뢰성)**: 동일한 칩에서 온도, 전압, 노화 변동에도 항상 동일한 키를 재생하는 척도로 이상적인 응답 오류율(RER)은 0%.
- **Fuzzy Extractor(퍼지 추출기)**: 노이즈가 섞인 PUF 원시 출력에서 Helper Data를 활용해 오류를 정정(ECC)하고 완전한 균일 비밀키를 추출하는 알고리즘.

</details>

- 물리적 복제가 수학적·물리적으로 불가능하여 칩 위조 및 복제를 원천 방어하는 **고유성(Uniqueness)**
- 극단적인 온도($-40\sim 125^\circ\text{C}$) 및 공급 전압 변동 하에서도 동일 키를 도출하는 **신뢰성(Reliability)**
- 노이즈가 포함된 하드웨어 응답을 완전 무결한 암호학적 대칭키로 변환하는 **퍼지 추출기(Fuzzy Extractor)** 연동 필수

$$
\mathrm{RER}(\%) = \frac{d_H(R_{\mathrm{enroll}}, R_{\mathrm{retest}})}{n} \times 100
$$

#### 한줄 요약

- **물리적 복제 불가능성(Unclonability)·고유성(50% HD) 및 신뢰성(0% RER)·Fuzzy Extractor 오류 정정**

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **PUF Core Circuit**: SRAM 초기 기동 상태(Power-up State), 링 오실레이터(RO) 주파수 차이, 아비터(Arbiter) 배선 지연 차이를 측정하는 물리 회로.
- **Helper Data**: 퍼지 추출기가 키를 복원할 때 사용하는 오류 정정 보조 데이터로, 공개되어도 원본 비밀키가 유출되지 않는 정보.

</details>

```text
[ PUF 하드웨어 키 재생 및 퍼지 추출기 아키텍처 ]
┌─────────────────────────────────────────────────────────────┐
│ 1. PUF 코어 회로 (SRAM 셀 어레이 / Ring Oscillator)        │
└──────────────────────────────┬──────────────────────────────┘
                               │ [ 노이즈가 포함된 원시 응답 R' ]
┌──────────────────────────────┴──────────────────────────────┐
│ 2. 퍼지 추출기 (Fuzzy Extractor : BCH/Reed-Solomon 디코더) │
│  ├─ Helper Data 입력 (eFuse/Flash 보조 데이터)              │
│  └─ 엔트로피 압축 (해시 함수를 통한 무작위 암호키 추출)     │
└──────────────────────────────┬──────────────────────────────┘
                               │ [ 완전 무결한 대칭 암호키 K ]
┌──────────────────────────────┴──────────────────────────────┐
│ 3. 암호 서비스 모듈 (AES/ECC 하드웨어 가속기) ──> 사용 후 Zeroize│
└─────────────────────────────────────────────────────────────┘
```

선의 의미: PUF 회로(SRAM/Arbiter), Helper Data 저장소, Fuzzy Extractor(BCH/Repetition) 및 암호 서비스 모듈 간의 PUF 키 재생 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 퍼프 회로 | 공장에서 칩 구울 때 생긴 미세한 불량(제조 편차)을 이용해 0과 1의 고유 지문 신호를 방출하는 하드웨어 공장 |
| 퍼지 추출기 | 퍼프 회로에서 나온 삐뚤빼뚤한 지문 신호를 오류 정정(ECC)으로 깎고 다듬어서 완벽한 암호 키로 연성하는 마법사 |
| 보조 데이터 저장소 | 퍼지 추출기가 암호 키를 복원할 때 참고하는 힌트(보조 데이터)를 보관하는 무결성 금고 |
| 암호 서비스 | 만들어진 암호 키로 데이터를 암호화하고, 일이 끝나면 램(SRAM)에서 키를 흔적도 없이 0으로 덮어써 지워버리는 살수 |

#### 한줄 요약

- **PUF 코어 회로(SRAM/RO/Arbiter)·Fuzzy Extractor(ECC)·보조 데이터(Helper Data)·암호화 서비스**

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Enrollment(등록 단계)**: 칩 생산 시 제어된 환경에서 기준 응답($R$)을 추출하고 Helper Data($W$)를 생성하여 비휘발성 메모리에 저장하는 단계.
- **Reconstruction(재생 단계)**: 런타임에 칩에서 노이즈 섞인 응답($R'$)을 측정하고 Helper Data($W$)와 결합하여 원래 키($K$)를 복원하는 단계.

</details>

```text
[ PUF 등록(Enrollment) 및 현장 키 재생(Reconstruction) 시퀀스 ]
 
 [ 1. 공장 등록 단계 (Enrollment) ]
   [ PUF 코어 기준 응답(R) 측정 ] ──> [ Helper Data 생성 알고리즘 ] ──> [ Helper Data(W) 플래시 저장 ]
 
 [ 2. 현장 키 재생 단계 (Reconstruction) ]
   [ 전원 인가 시 PUF 회로 기동 ]
                 │
                 ▼
   [ 노이즈 포함된 현장 응답(R') 측정 ]
                 │
                 ▼
   [ Fuzzy Extractor 에 R' 및 Helper Data(W) 입력 ]
                 │
                 ▼
   [ 오류 정정(ECC) 디코딩을 통한 기준 응답(R) 복원 ]
                 │
                 ▼
   [ 해시 함수(SHA-256)를 거쳐 완전 무결한 암호키 K 도출 ]
```

**동작 원리**

1. **공장 등록**: 제조 라인에서 PUF 회로의 기준 응답 $R$을 측정하고, 퍼지 추출기 Gen 함수로 Helper Data $W$ 생성 및 칩 저장
2. **현장 기동**: 현장에서 장치에 전원이 공급되면 PUF 코어가 환경 노이즈가 섞인 $R'$ 출력
3. **오류 정정 디코딩**: 퍼지 추출기 Rep 함수가 $R'$와 $W$를 결합하여 비트 에러(RER)를 정정하고 $R$ 복원
4. **암호키 도출**: 복원된 비트열을 암호학적 해시 함수에 통과시켜 균일한 엔트로피를 갖는 비밀키 $K$ 도출
5. **키 사용 및 제로화**: AES 하드웨어 엔진에서 인증/암호화에 사용 후 RAM에서 즉시 제로화(Zeroization)

#### 한줄 요약

- 공장 등록(Enrollment: 기준 응답 및 Helper Data 생성) $\to$ **현장 구동 시 챌린지 입력 $\to$ 노이즈 응답 획득 $\to$ Fuzzy Extractor 재생(Key Reconstruction) $\to$ 무결성 키 도출**

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **Weak PUF vs Strong PUF vs TRNG**:
  - Weak PUF: 소수 CRP(1개), 칩 내부 루트 키(RoT) 생성, SRAM/RO
  - Strong PUF: 지수적 다수 CRP($2^n$), 서버-디바이스 상호 인증, Arbiter
  - TRNG: 챌린지 없음, 일회용 세션 키/난수 생성, 동일 키 복원 불가

</details>

| 비교 항목 | Weak PUF (약한 PUF : SRAM PUF) | Strong PUF (강한 PUF : Arbiter PUF) | TRNG (진난수 생성기) |
|:---|:---|:---|:---|
| 챌린지-응답 쌍(CRP) 수 | 1개 또는 극소수 (주소 고정) | 지수적 다수 ($2^n$개 이상) | 응답 없음 (연속적 무작위 비트열) |
| 주 용도 및 메커니즘 | 칩 내부 불변 루트 키(RoT) 생성 | 외부 서버와의 무인증 Challenge-Response | 세션 키 및 일회용 난수(Nonce) 생성 |
| 한계 및 보안 위협 | 외부 노출 시 보안 위험 (온칩 격리 필수) | 머신러닝 모델링 공격(Modeling Attack) 노출 | 매번 값이 달라져 동일 키 재생 불가 |

#### 한줄 요약

- 고정 비밀키는 **Weak PUF**, 외부 인증은 **Strong PUF**, 일회용 난수는 **TRNG**

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Stable Bit Masking**: 온도/전압 변화에도 값이 뒤집히지 않는 상위 10~20%의 극안정 셀만 선별하여 키 재료로 사용하는 기법.
- **Modeling Attack(머신러닝 모델링 공격)**: 해커가 Strong PUF의 공개된 다량의 CRP를 수집하여 딥러닝/SVM 모델로 PUF 회로 지연을 학습 및 복제하는 공격.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 칩이 늙거나 한겨울에 얼어붙으면 지문이 심하게 찌그러져(RER 폭발) 암호 키 복원이 실패하는 벽돌 셧다운 사태 | 지문 중에서 환경이 변해도 값이 잘 안 뒤집히는 **안정 비트**만 골라 쓰고 오류 정정 맷집을 한계치까지 펌핑 | 극한 환경에서도 암호 키 재생 실패율을 쥐어짜 낮춰 시스템 무중단 생존 100% 보장 |
| 해커가 딥러닝(ML) 알고리즘으로 강한 PUF의 입출력 패턴을 미친 듯이 학습시켜 암호키를 추정해내는 **모델링 공격** 발발 | 입력값과 출력값을 함부로 못 맞추게 뒤섞어버리는 비선형 믹싱 어댑터를 박아 딥러닝 패턴 예측을 완전히 뭉개버림 | 해커의 딥러닝 기반 인증 키 예측을 원천 불가능하게 만들어 하드웨어 지문 탈취 방어 |
| 힘들게 복원한 암호 키를 램(SRAM)에 놔뒀더니 해커가 메모리를 뒤져서(프로빙) 홀라당 털어가는 끔찍한 위험 | 암호화 연산이 끝나는 즉시 램에 있는 임시 키를 0으로 덮어써서 흔적도 없이 날려버리는 얄짤없는 **키 삭제** 수행 | 해커가 메모리를 얼리거나 까뒤집는 덤프 공격을 들이밀어도 가져갈 키가 없게 원천 차단 |

#### 한줄 요약

- **안정 비트 마스킹(Stable Bit Masking)·비선형 믹싱/XOR 모델링 방어·온디맨드 키 생성 후 제로화(Zeroization)**

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **차세대 PUF 트렌드**: 2nm 이하 첨단 공정 및 3D 패키징 환경에서 Quantum PUF 및 안티 탬퍼링(Anti-Tamper) 센서와 결합된 차세대 하드웨어 보안 앵커로 진화.

</details>

- IoT 보안 칩 및 고신뢰 하드웨어 RoT 구현 시 **SRAM 기반 Weak PUF와 퍼지 추출기(Fuzzy Extractor) 표준 채택**

#### 한줄 요약

- **온칩 키 재생(Weak PUF)과 머신러닝 방어(Strong PUF)**를 통한 물리적 복제 방지
