## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **PUF(Physical Unclonable Function)**: 반도체 제조 공정에서 발생하는 나노미터 단위의 불가피한 물리적 미세 편차를 기반으로, 칩마다 고유하고 예측 불가능한 암호학적 지문(디지털 지문)을 생성하는 보안 하드웨어 회로.
- **온디맨드 키 생성(Key Generation On-Demand)**: 암호 키를 불휘발성 메모리(Flash, eFuse)에 영구 저장하지 않고, 암호 연산이 필요한 순간에만 PUF 회로로부터 즉석 생성하여 사용한 뒤 레지스터에서 즉시 소멸시키는 기술.

</details>

- 정의/개념: 반도체 실리콘의 미세 공정 편차를 고유한 물리적 지문으로 변환하여 **비복제성 및 온디맨드 암호 키 생성**을 제공하는 **PUF 보안 기술**
- 배경/필요성: 메모리 키 영구 저장 방식의 **레이저 프로빙 및 부채널 분석을 통한 키 탈취 취약점** 극복

#### 한줄 요약
- PUF는 반도체 제조 시 발생하는 나노 스케일 미세 편차를 이용해 칩마다 유일한 고유 암호 키를 온디맨드로 생성하는 하드웨어 지문 소자이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **고유성(Uniqueness)**: 칩 간 응답의 해밍 거리가 이상값 50%에 가까운 특성.
- **신뢰성(Reliability)**: 환경 변화에도 동일 칩의 응답을 안정적으로 재현하는 특성.

</details>

- 복제 저항성: 반도체 공정 편차에 기반한 **칩별 고유 응답** 생성
- 키 저장소 부재(Zero Storage): 평상시 키가 메모리에 존재하지 않아 **물리적 메모리 덤프 공격 무력화**
- **고유성·신뢰성**: 퍼지 추출기로 환경 잡음을 보정해 키 재현

#### 한줄 요약
- 키를 메모리에 저장하지 않고 필요할 때만 물리 지문으로부터 100% 재현하여 메모리 탈취 및 복제 공격을 차단한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **퍼지 추출기(Fuzzy Extractor)**: ECC와 헬퍼 데이터로 PUF 응답 잡음을 보정해 키를 복원하는 모듈.
- **헬퍼 데이터(Helper Data)**: 초기 키 등록(Enrollment) 시 생성되어 비보안 외장 플래시에 공개 저장되는 보조 데이터로, 비밀 키 정보를 전혀 노출하지 않으면서 런타임 노이즈 비트를 보정함.

</details>

```text
[PUF 키 생성 하드웨어]
 ├─ PUF 원시 코어
 ├─ 등록 엔진
 ├─ 퍼지 추출기
 │   └─ 헬퍼 데이터·ECC
 ├─ KDF·해시 엔진
 └─ 온칩 암호 엔진
```

선의 의미: 가지(`├─`, `└─`)는 하드웨어 소속 및 키 생성 파이프라인; PUF 코어의 원시 비트가 퍼지 추출기를 거쳐 암호 엔진으로 직결되고 사용 후 즉시 소멸됨

| 구성요소 | 책임 |
|:---|:---|
| PUF 원시 코어 | 공정 편차 기반 **챌린지·응답** 생성 |
| 등록 엔진 | 기준 응답에서 **헬퍼 데이터** 생성 |
| 퍼지 추출기 | ECC로 환경 잡음 비트 보정 |
| KDF·해시 엔진 | 응답 편향 제거와 암호 키 유도 |
| 암호 연산 엔진 | 온칩 키 사용 후 레지스터 소거 |

#### 한줄 요약
- PUF 시스템은 원시 코어, 퍼지 추출기(헬퍼 데이터 연동), KDF 키 유도 엔진 및 암호 가속기로 구성된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **챌린지-응답 쌍(Challenge-Response Pair, CRP)**: PUF 회로에 특정 입력 자극(Challenge)을 인가했을 때 내부 물리적 지문에 의해 고유하게 출력되는 응답값(Response).

</details>

```text
시스템 암호 연산 요청
                      │
                      ▼
1. 원시 응답 생성
                      │
                      ▼
2. 헬퍼 데이터 입력
                      │
                      ▼
3. 응답 오류 보정
   ┌──────────────────┴──────────────────┐
[ 에러 개수가 ECC 정정 한계 이내 ]    [ 에러 한계 초과 (소자 파손/공격) ]
   │                                     │
   ▼                                     ▼
4. 암호 키 유도                       키 재현 실패·보안 리셋
   │
   ▼
5. 키 사용·소거
   │
   ▼
   │
   ▼
연산 결과 반환
```

동작 원리:

1. 원시 응답 생성: PUF에 챌린지 인가
2. 헬퍼 데이터 입력: 등록 보조 정보 조회
3. 응답 오류 보정: ECC 한계 이내 잡음 정정
4. 암호 키 유도: KDF로 용도별 키 생성
5. 키 사용·소거: 온칩 연산 후 레지스터 정화

#### 한줄 요약
- 챌린지 인가 ➔ 원시 응답 생성 ➔ 헬퍼 데이터 ECC 복원 ➔ KDF 키 유도 ➔ 암호 연산 ➔ 레지스터 제로화 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **SRAM PUF**: 전원 인가 순간 SRAM 셀의 양쪽 인버터 간 문턱전압 미세 불균형에 의해 0 또는 1로 결정되는 초기 상태 편차를 활용하는 방식.
- **Ring Oscillator PUF(RO PUF)**: 복수의 링 발진기 인버터 체인의 배선 및 지연시간 편차로 인한 발진 주파수 차이를 비교하는 방식.

</details>

| 하드웨어 키 생성/저장 기술 | SRAM PUF | Ring Oscillator PUF (RO PUF) | eFuse OTP 영구 저장 | TRNG (진성 난수발생기) |
|:---|:---|:---|:---|:---|
| 키 저장 및 생성 형태 | **미저장 (온디맨드 재현)** | **미저장 (주파수 비교 재현)** | 불휘발성 퓨즈에 영구 물리 저장 | 매 순간 무작위 일회용 난수 생성 |
| 물리적 복제 가능성 | **복제 곤란**(실리콘 편차) | **복제 곤란**(지연 편차) | 키 추출 시 복제 위험 | 해당 없음 (키 고정 불가) |
| 물리적 해킹 저항성 | 높음 (디캡 시 응답 변화) | 높음 (프로빙 시 지연 변화) | 프로빙에 키 노출 위험 | 높음 |
| 하드웨어 오버헤드 | 낮음 (내장 SRAM 재활용) | 중간 (인버터 체인 면적) | 낮음 (퓨즈 셀 어레이) | 낮음 (아날로그 잡음원) |
| 주요 적용 분야 | **초저가 IoT 단말, MCU** | **FPGA 보안, 서버용 SoC** | 레거시 장치 고정 비밀키 주입 | 실시간 세션 키, 암호 넌스 |

#### 한줄 요약
- 저비용 IoT에는 SRAM PUF가, FPGA에는 RO PUF가 적합하며, 영구 저장 방식(eFuse)의 물리적 탈취 취약점을 완벽히 해결한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **머신러닝 모델링 공격(ML Modeling Attack)**: 공격자가 PUF의 입력(Challenge)과 출력(Response) 쌍을 대량 수집한 후 딥러닝 인공신경망을 학습시켜 PUF의 물리 동작을 소프트웨어로 수학적 복제하는 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 극한 온도 변화로 인한 키 비트 오류 증가 | **다단계 ECC 설계**와 잡음 비트 마스킹 | 운용 범위에서 키 재현율 개선 |
| 대량의 CRP 질의를 통한 머신러닝 모델링 공격 | **Controlled PUF 구조 (해시 전처리 및 외부 직결 차단)** | 챌린지-응답 수집 차단 및 수학적 복제 무력화 |
| 장기 사용에 따른 반도체 경년 열화 및 셀 피로 현상 | **번인(Burn-in) 사전 선별** 및 안티 에이징 차동 셀 레이아웃 적용 | 10년 이상 차량용 수명 주기 내 안정성 보장 |

#### 한줄 요약
- 실무에서는 다단계 ECC로 환경 잡음을 잡고, Controlled PUF로 머신러닝 복제를 막으며, 번인 선별로 경년 열화를 방어한다.

## Ⅶ. 결론

- MCU 키 유도는 **SRAM PUF**, FPGA는 **RO PUF** 선택

#### 한줄 요약
- PUF는 반도체 고유 지문을 활용한 궁극의 하드웨어 보안 기술이며, 온디맨드 키 생성과 퍼지 추출기의 결합으로 완성된다.
