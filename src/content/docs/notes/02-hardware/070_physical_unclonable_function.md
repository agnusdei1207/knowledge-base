## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **PUF(Physical Unclonable Function)**: 반도체 제조 공정의 불가피한 미세 물리적 편차를 활용해 칩마다 고유한 무작위 난수 비트를 출력하는 하드웨어 지문 소자.
- **온디맨드 키 생성(Key Generation On-Demand)**: 암호 키를 불휘발성 메모리(NVM)에 영구 저장하지 않고, 필요할 때만 PUF 회로에서 즉석 생성해 사용 후 파기하는 방식.

</details>

- 정의/개념: 반도체 제조 공정에서 발생하는 미세 편차를 이용해 칩마다 고유하고 복제 불가능한 **하드웨어 지문(Digital Fingerprint) 암호 키**를 생성하는 보안 반도체 기술
- 배경/필요성: 플래시 메모리나 eFuse 내 비밀키 저장 시 발생하는 물리적 칩 해킹(프로빙/역공학) 및 복제 위협 극복 필요

#### 한줄 요약
- 칩을 만들 때 생기는 사람의 지문 같은 미세한 공정 차이를 이용해, 칩 자체에서 절대 복제되지 않는 비밀 암호키를 만들어낸다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **고유성(Uniqueness)**: 동일한 마스크로 제조된 서로 다른 칩들 간의 PUF 출력 비트가 통계적으로 50%의 해밍 거리를 가지며 서로 완벽히 구분되는 특성.
- **신뢰성(Reliability)**: 동일한 칩에서 온도, 전압, 경년 변화 등 외부 환경이 바뀌어도 항상 동일한 기준 키를 재현해내는 안정성.

</details>

- 제조사조차 똑같이 복제할 수 없는 **물리적 복제 불가능성(Unclonability)**
- 키를 메모리에 영구 저장하지 않아 전원이 꺼지면 흔적이 사라지는 **비저장 보안성**
- 잡음(Noise)을 보정하여 항상 100% 동일한 키를 복원하는 **퍼지 추출기(Fuzzy Extractor)**

#### 한줄 요약
- 메모리에 키를 남기지 않아 칩을 뜯어 분석해도 키를 훔칠 수 없으며, 환경 변화에도 퍼지 추출기로 정확한 키를 복원한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **퍼지 추출기(Fuzzy Extractor)**: 노이즈가 섞인 PUF 원시 응답(Raw Response)에서 BCH/리드솔로몬 에러 정정 부호와 헬퍼 데이터를 이용해 순수 암호키를 추출하는 모듈.
- **헬퍼 데이터(Helper Data)**: 키 등록(Enrollment) 시 생성되어 외부에 공개 저장되는 비민감 보조 데이터로, 키 재현 시 에러 비트 보정에 사용.

</details>

```text
┌─────────────────────────────────────────────────────────────┐
│ PUF 키 생성 및 에러 정정(Fuzzy Extractor) 아키텍처         │
│                                                             │
│  [ PUF 코어 회로 (SRAM 셀 어레이 / 링 발진기) ]             │
│  └──────────────────────────┬───────────────────────────────┘│
│                             ▼ (노이즈 포함 원시 응답 R')    │
│  ┌─────────────────────────────────────────────────────────┐│
│  │ 퍼지 추출기 (Fuzzy Extractor)                           ││
│  │  ┌───────────────────────┐   ┌───────────────────────┐  ││
│  │  │ 에러 정정 디코더 (ECC)│◄──│ 헬퍼 데이터 (Helper)  │  ││
│  │  │ (BCH / Reed-Solomon)  │   │ (공개 플래시 저장)    │  ││
│  │  └───────────┬───────────┘   └───────────────────────┘  ││
│  │              ▼ (무오류 기준 응답 R 복원)                 ││
│  │  ┌───────────────────────┐                              ││
│  │  │ 암호학적 해시 압축기  │                              ││
│  │  │ (SHA-256 / KDF)       │                              ││
│  │  └───────────┬───────────┘                              ││
│  └──────────────┼──────────────────────────────────────────┘│
│                 ▼                                           │
│  [ 256-bit 디바이스 마스터 암호 키 (K) ] ──► [AES 엔진 사용]│
└─────────────────────────────────────────────────────────────┘
```

선의 의미: PUF 원시 응답이 헬퍼 데이터와 결합하여 에러를 정정하고 해시 함수를 통해 순수 256비트 암호키로 변환

| 구성요소 | 책임 |
|:---|:---|
| PUF 코어 (SRAM/RO) | 칩 전원 투입 시 셀 간 트랜지스터 임계전압 차이를 무작위 0/1 비트열로 출력 |
| 등록 엔진 (Enrollment) | 공장 출하 시 최초 PUF 응답을 측정하여 헬퍼 데이터(W)를 생성 및 플래시에 기록 |
| 에러 정정 모듈 (ECC) | 온도/전압 변화로 발생한 플립 비트(Bit Flip)를 헬퍼 데이터를 이용해 복구 |
| 해시/KDF 압축기 | 에러 정정된 균일하지 않은 비트열을 SHA-256으로 압축해 균등 엔트로피 키 생성 |
| 보안 암호화 엔진 | 생성된 마스터 키를 메모리 노출 없이 AES/ECC 암호화 하드웨어에 직결 공급 |

#### 한줄 요약
- PUF 코어, 에러 정정 디코더, 헬퍼 데이터, 해시 압축기가 결합되어 잡음 없는 암호키를 완성한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **챌린지-응답(CRP, Challenge-Response Pair)**: 특정 입력 자극(Challenge)에 대해 PUF 회로가 고유하게 내놓는 출력값(Response)의 쌍.

</details>

```text
디바이스 전원 인가 및 보안 키 생성 요청
      │
      ▼
1. PUF 원시 응답 인출: SRAM 어레이 초기 전원 상태 또는 링 발진기 주파수 차이 측정
      │
      ▼
2. 헬퍼 데이터 로드: 플래시 메모리에서 공장 출하 시 저장된 헬퍼 데이터(W) 인입
      │
      ▼
3. ECC 에러 정정: BCH 디코더가 온도·전압 변동으로 뒤집힌 비트(Bit-flip) 정정
      │
      ▼
4. 해시 추출: 정정된 비트열을 SHA-256 해시 함수에 통과시켜 완벽한 대칭키(K) 추출
      │
      ▼
5. 암호 연산 수행 후 즉각 RAM 레지스터 클리어(Zeroization)
```

**동작 원리**

1. **원시 비트 추출**: 전원이 켜지는 순간 SRAM 셀들이 고유 미세 구조에 따라 0 또는 1로 수렴
2. **보조 데이터 결합**: 외부 플래시에서 공개 헬퍼 데이터를 가져와 에러 정정 로직에 입력
3. **노이즈 완벽 복원**: 환경 변화로 약 5~10% 발생한 에러 비트를 ECC 알고리즘으로 100% 정정
4. **마스터 키 유도**: 엔트로피를 최대로 끌어올리기 위해 해시 알고리즘(KDF)을 거쳐 256비트 키 생성
5. **사용 후 증발**: 암호 연산이 끝나면 즉시 메모리를 0으로 덮어써 흔적을 완전히 소거

#### 한줄 요약
- 원시 응답 측정 → 헬퍼 데이터 결합 → ECC 에러 정정 → SHA-256 키 유도 → 사용 후 즉각 파기 순으로 동작한다.

## Ⅴ. 종류 및 비교

| 하드웨어 보안 키 생성 기술 | SRAM PUF | Ring Oscillator PUF | eFuse OTP 저장 | TRNG (난수발생기) |
|:---|:---|:---|:---|:---|
| 적용 기준 | 상용 MCU 온칩 SRAM 활용 초저비용 | FPGA 로직 셀 기반 PUF 구현 | 전통적인 제조사 고정 키 주입 | 실시간 일회용 세션키/난수 생성 |
| 핵심 특징 | 전원 인가 시 SRAM 셀의 초기 불안정 상태 활용 | 인버터 체인의 지연시간 차이로 주파수 비교 | 전기적 퓨즈를 영구 단선시켜 0/1 저장 | 열잡음/양자잡음 기반 예측불가 난수 |
| 한계 | 고온 장기 사용 시 셀 노화(Aging) 에러 증가 | 면적 및 전력 소모가 SRAM 대비 큼 | 물리적 레이저 프로빙/현미경 공격에 노출 | 매번 다른 난수가 나와 고정 키로 사용 불가 |

#### 한줄 요약
- 범용 가성비는 SRAM PUF, FPGA는 RO PUF, 전통 방식은 eFuse, 일회용 난수는 TRNG를 쓴다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **머신러닝 모델링 공격(ML Modeling Attack)**: 공격자가 대량의 챌린지-응답 쌍(CRP)을 수집하여 인공지능 신경망으로 PUF의 하드웨어 물리 특성을 수학적으로 복제하는 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 극한의 고온/저온 환경에서 **에러율(BER) 급증으로 키 복원 실패** | **고성능 BCH/LDPC 에러 정정 부호** 및 온도 보상 회로 설계 | $-40^\circ\text{C}\sim125^\circ\text{C}$ 전 구간 100% 키 복원 보장 |
| 대량의 CRP 노출로 인한 **머신러닝(ML) 모델링 복제 공격** | 챌린지 입력단에 **암호화 해시 차단막(Controlled PUF)** 적용 | 외부 직접 CRP 수집 원천 차단 |
| 반도체 장기 사용에 따른 **NBTI 노화(Aging)로 인한 PUF 특성 변질** | 안티 에이징(Anti-Aging) 인버전 구동 및 주기적 재등록 체계 구축 | 10년 이상 차량용 신뢰성 수명 유지 |
| 헬퍼 데이터 변조를 통한 **부채널 오류 주입 공격** | 헬퍼 데이터에 **HMAC 무결성 전자서명** 결합 검증 | 헬퍼 데이터 위변조 시도 즉각 탐지 |

#### 한줄 요약
- BCH 부호로 극한 온도를 버티고, Controlled PUF로 AI 복제를 막으며, HMAC으로 헬퍼 데이터를 보호한다.

## Ⅶ. 결론

- 사물인터넷(IoT) 및 차량용 반도체의 물리적 복제 방지 및 하드웨어 보안 뿌리(RoT) 구축을 위해 **SRAM PUF + 퍼지 추출기** 필수 적용

#### 한줄 요약
- 반도체 공정 미세 편차를 활용하여 키를 저장하지 않고 즉석에서 생성함으로써 최고 수준의 물리적 보안을 달성해야 한다.
