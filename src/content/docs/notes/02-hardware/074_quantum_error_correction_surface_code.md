## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **양자 오류 정정(QEC, Quantum Error Correction)**: 양자 상태를 직접 관측하지 않고 보조 큐비트의 패리티 측정을 통해 비트 반전(X)과 위상 반전(Z) 오류를 검출·복원하는 기술.
- **표면 코드(Surface Code)**: 물리 큐비트들을 2차원 격자 평면에 배치하여 인접한 큐비트 간의 국소적 상호작용만으로 오류를 정정하는 대표적인 위상 양자 부호.

</details>

- 정의/개념: 양자 상태 복제 불가(No-Cloning) 제약을 극복하기 위해 다수 물리 큐비트를 2차원 격자로 배치하고 **안정자(Stabilizer) 신드롬 측정**으로 오류를 정정하는 대표적 양자 부호 기술
- 배경/필요성: 환경 노이즈로 인한 **비트 플립(X) 및 위상 플립(Z) 결맞음 손실 오류 누적** 직면

#### 한줄 요약
- 양자 상태를 깨뜨리지 않고 바둑판 모양의 보조 큐비트로 에러 신드롬만 읽어내 실시간으로 고치는 오류 정정 기술이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **오류 임계치(Threshold)**: 물리 큐비트의 오류율이 이 기준값(약 1%) 이하일 때, 코드 거리($d$)를 늘릴수록 논리 오류율이 지수적으로 감소하는 한계선.
- **코드 거리(Code Distance, $d$)**: 하나의 논리 큐비트 오류를 유발하기 위해 필요한 최소 물리적 오류 개수(최대 $\lfloor(d-1)/2\rfloor$개 정정 가능).

</details>

- 인접 큐비트 간 **2D 국소 연결성(Nearest-Neighbor)** 만으로 구현 가능해 반도체 칩 실장에 최적
- 물리적 오류율 약 **1%의 높은 오류 허용 임계치(Threshold)** 제공
- 데이터 큐비트와 보조(Ancilla) 큐비트를 번갈아 배치하는 **X 및 Z 안정자 패리티 측정**

#### 한줄 요약
- 2차원 평면 배선만으로 구현 가능하고 오류 허용치가 1%로 매우 높아 실제 양자 하드웨어 구현의 표준으로 쓰인다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **데이터 큐비트(Data Qubit)**: 실제 양자 알고리즘 연산 데이터 상태를 분산 저장하는 물리 큐비트.
- **보조 큐비트(Ancilla Qubit)**: 데이터 큐비트와 얽힌 후 측정되어 X-타입(위상) 또는 Z-타입(비트) 에러 신드롬을 추출하는 측정 전용 큐비트.

</details>

```text
┌─────────────────────────────────────────────────────────────┐
│ 표면 코드 2차원 격자 (Surface Code Patch) 구조              │
│                                                             │
│       (D) ───── [ Z ] ───── (D)                             │
│        │                     │                              │
│       [ X ] ─── (D) ─── [ X ]│     (D) : 데이터 큐비트       │
│        │         │           │     [Z] : Z-안정자 (비트 에러)│
│       (D) ───── [ Z ] ───── (D)    [X] : X-안정자 (위상 에러)│
│                                                             │
│  [ 안정자 측정 회로 (4회 CNOT + 측정) ]                      │
│                 │ (신드롬 비트 스트림)                      │
│  ┌──────────────▼────────────────────────────────────────┐  │
│  │ 고전 고속 복호기 (MWPM / Union-Find 디코더)            │  │
│  │ ──► [ 파울리 프레임(Pauli Frame) 소프트웨어 추적 보정 ] │  │
│  └───────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

선의 의미: 데이터 큐비트(D)의 상태가 보조 큐비트(X/Z)로 얽혀 측정되고, 신드롬 결과가 고전 복호기로 전달되어 에러 추적

| 구성요소 | 책임 |
|:---|:---|
| 데이터 큐비트 (Data Qubit) | 2차원 격자 상에서 하나의 논리 큐비트 상태를 중복 분산 저장 |
| X-안정자 (X-Stabilizer) | 4개의 인접 데이터 큐비트의 Z(위상 반전) 오류를 감지하는 보조 큐비트 |
| Z-안정자 (Z-Stabilizer) | 4개의 인접 데이터 큐비트의 X(비트 반전) 오류를 감지하는 보조 큐비트 |
| 고전 복호기 (Decoder) | 최소 가중치 완벽 매칭(MWPM) 알고리즘으로 에러 사슬(Error Chain) 추론 |
| 파울리 프레임 (Pauli Frame) | 물리 큐비트를 직접 건드리지 않고 소프트웨어 레벨에서 위상/비트 반전 가상 보정 |

#### 한줄 요약
- 데이터 큐비트, X/Z 안정자 보조 큐비트, 고전 복호기, 파울리 프레임 추적기가 완벽한 논리 큐비트를 만든다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **MWPM(Minimum Weight Perfect Matching)**: 측정된 에러 신드롬 그래프에서 가장 확률이 높은 에러 발생 경로 쌍을 찾아내는 그래프 최적화 복호 알고리즘.

</details>

```text
논리 양자 상태 부호화 완료 (Distance d 패치)
      │
      ▼
1. 안정자 연산: 보조 큐비트와 인접 4개 데이터 큐비트 간 CNOT 게이트 인가
      │
      ▼
2. 신드롬 측정: 보조 큐비트를 고전 측정하여 0/1 에러 발생 신드롬 추출
      │
      ▼
3. 신드롬 그래프 생성: 시간에 따른 신드롬 변화(Defect)를 시공간 3D 그래프로 구성
      │
      ▼
4. 고전 실시간 복호(MWPM): 고속 디코더가 최단 에러 사슬 매칭 계산
      │
      ▼
5. 파울리 프레임 갱신: 후속 양자 게이트 및 최종 판독 시 에러 보정값 소프트웨어 반영
```

**동작 원리**

1. **패리티 얽힘**: 데이터 큐비트의 정보를 건드리지 않고 보조 큐비트와 4방향 CNOT을 걸어 패리티 복사
2. **신드롬 측정**: 보조 큐비트를 측정하여 이전 주기와 결과가 달라진 결함(Defect) 지점 발견
3. **에러 추론**: 결함 위치를 기반으로 비트 플립인지 위상 플립인지 발생 큐비트 위치를 MWPM으로 탐색
4. **가상 보정**: 물리 게이트를 추가 인가하지 않고 파울리 프레임 소프트웨어 테이블에 보정값 기록
5. **무결점 연산**: 모든 양자 연산이 끝난 후 최종 측정값에 파울리 프레임을 역적용해 100% 무결점 정답 도출

#### 한줄 요약
- 안정자 CNOT → 신드롬 측정 → 결함 그래프 생성 → MWPM 복호 → 파울리 프레임 가상 보정 순으로 동작한다.

## Ⅴ. 종류 및 비교

| 양자 오류 제어 기술 | 표면 코드 (Surface Code) | 양자 오류 완화 (QEM) | 고전 해밍/리드솔로몬 부호 | 쇼어 9-큐비트 코드 |
|:---|:---|:---|:---|:---|
| 적용 기준 | 결함 허용 대규모 양자 컴퓨터(FTQC) | 현재 NISQ 시대 얕은 양자 회로 | 고전 디지털 메모리 및 통신 네트워크 | 최초의 이론적 양자 오류 정정 개념 |
| 핵심 특징 | 2D 격자 국소 연결 및 1% 높은 임계치 | 통계적 외삽(ZNE)으로 노이즈 편향 제거 | 비트를 단순 복제하여 다수결 패리티 검사 | 1개 논리 큐비트에 9개 물리 큐비트 사용 |
| 한계 | 1개 논리 큐비트당 수천 개 물리 큐비트 소모 | 회로 깊이가 깊어지면 측정 횟수 지수적 폭증 | 양자 복제 불가 정리로 양자 시스템 적용 불가 | 인접 2D 평면 배선 불가능 및 낮은 임계치 |

#### 한줄 요약
- 진정한 무오류 양자 연산은 표면 코드, 현재 칩의 오차 보정은 오류 완화(QEM), 고전 통신은 해밍 코드를 쓴다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **복호 지연(Decoding Latency)**: 신드롬 측정 주기가 마이크로초 단위인데 고전 복호기 연산이 느리면 에러가 누적되어 전체 시스템이 지연되는 병목 현상.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 1개 논리 큐비트당 **수천 개 물리 큐비트 소모(오버헤드 폭증)** | 물리 큐비트 오류율을 0.1% 이하로 낮추어 **코드 거리($d$) 축소** | 필요 물리 큐비트 수 10배 이상 절감 |
| 고전 복호기 연산 지연으로 인한 **실시간 제어 병목(Decoding Backlog)** | **FPGA / ASIC 하드웨어 가속기 기반 Union-Find 복호기** 도입 | 마이크로초 이내 실시간 스트리밍 복호 실현 |
| 다중 큐비트 동시 측정 시 **측정 큐비트 자체의 측정 오류(Measurement Error)** | 신드롬 측정을 시간 축으로 **$d$회 연속 반복 측정(시공간 복호)** | 보조 큐비트 자체의 측정 오류 완벽 필터링 |
| 인접하지 않은 논리 큐비트 간 연산 시 **격자 변형 오버헤드** | **격자 수술(Lattice Surgery)** 기법을 통한 패치 간 병합 및 분할 | 2차원 평면 내 효율적 논리 게이트 구현 |

#### 한줄 요약
- 물리 오류를 낮춰 큐비트를 아끼고, FPGA로 초고속 복호를 돌리며, 격자 수술로 2D 연산을 구현한다.

## Ⅶ. 결론

- 진정한 오류 허용 범용 양자 컴퓨팅(FTQC) 구축을 위해 **2D 표면 코드(Surface Code)와 FPGA 실시간 복호기** 결합 필수

#### 한줄 요약
- 안정자 측정과 고속 복호 알고리즘을 통해 물리 큐비트의 불가피한 노이즈를 극복하고 무결점 논리 큐비트를 실현해야 한다.
