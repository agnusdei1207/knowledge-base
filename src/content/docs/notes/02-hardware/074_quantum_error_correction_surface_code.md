## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **양자 오류 정정(QEC, Quantum Error Correction)**: 양자 상태를 직접 관측하지 않고 보조 큐비트의 패리티 측정을 통해 비트 반전(X)과 위상 반전(Z) 오류를 검출·복원하는 기술.
- **표면 코드(Surface Code)**: 물리 큐비트들을 2차원 격자 평면에 배치하여 인접한 큐비트 간의 국소적 상호작용만으로 오류를 정정하는 대표적인 위상 양자 부호.

</details>

- 정의/개념: 논리 상태를 여러 물리 큐비트에 나눠 담고 상태 자체가 아닌 패리티만 반복 측정해 오류를 추론하는 **표면 코드(Surface Code)**
- 배경/필요성: 양자 상태는 복제할 수 없고 측정하면 붕괴하므로, 고전 부호처럼 값을 읽어 비교하는 방식으로는 오류를 잡을 수 없음

#### 한줄 요약
- 정보를 보지 않고 오류만 보는 것이 이 부호의 핵심 발상이며, 측정이 상태를 파괴한다는 제약을 우회하는 유일한 길이기도 하다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **오류 임계치(Threshold)**: 물리 큐비트의 오류율이 이 기준값(약 1%) 이하일 때, 코드 거리($d$)를 늘릴수록 논리 오류율이 지수적으로 감소하는 한계선.
- **코드 거리(Code Distance, $d$)**: 하나의 논리 큐비트 오류를 유발하기 위해 필요한 최소 물리적 오류 개수(최대 $\lfloor(d-1)/2\rfloor$개 정정 가능).

</details>

- 인접 큐비트만 연결하면 되므로 평면 하드웨어에 그대로 구현 가능
- 물리 오류가 **오류 임계치(Threshold)** 아래이면 **코드 거리(Code Distance, $d$)**를 늘려 논리 오류를 지수적으로 억제
- 데이터 큐비트와 보조 큐비트를 번갈아 배치해 두 종류 오류를 각각 감지

#### 한줄 요약
- 임계치 아래에서만 정정이 이득이 되므로, 이 부호는 하드웨어 품질이 일정 수준을 넘긴 뒤에야 의미를 갖는 조건부 기술이다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **데이터 큐비트(Data Qubit)**: 실제 양자 알고리즘 연산 데이터 상태를 분산 저장하는 물리 큐비트.
- **보조 큐비트(Ancilla Qubit)**: 데이터 큐비트와 얽힌 후 측정되어 X-타입(위상) 또는 Z-타입(비트) 에러 신드롬을 추출하는 측정 전용 큐비트.

</details>

```text
[표면 코드 구성]
├─ 2차원 격자 패치
│  ├─ 데이터 큐비트 (논리 상태를 분산 저장)
│  ├─ X 안정자 보조 큐비트 (위상 오류 감지)
│  └─ Z 안정자 보조 큐비트 (비트 오류 감지)
├─ 안정자 측정 회로 (인접 4개 데이터 큐비트와 얽힘 후 측정)
└─ 고전 처리 계층
   ├─ 복호기 (신드롬에서 오류 사슬 추론)
   └─ 파울리 프레임 (물리 보정 없이 소프트웨어로 추적)
```

선의 의미: 가지(`├─`)는 소유 관계이며, 양자 영역에서 나온 신드롬 비트만이 고전 처리 계층으로 넘어감

| 구성요소 | 책임 |
|:---|:---|
| **데이터 큐비트(Data Qubit)** | 격자 위에 논리 상태를 중복 분산 저장 |
| X 안정자 | 인접 데이터 큐비트의 위상 반전 오류 감지 |
| Z 안정자 | 인접 데이터 큐비트의 비트 반전 오류 감지 |
| 고전 복호기 | 신드롬 그래프에서 가장 가능성 높은 오류 사슬 추론 |
| 파울리 프레임 | 물리 조작 없이 이후 해석에 보정 상태 반영 |

#### 한줄 요약
- **보조 큐비트(Ancilla Qubit)**가 데이터와 같은 칩에 있어야 한다는 제약 때문에 유효 큐비트 수가 절반 이하로 줄며, 정정의 대가는 곧 면적으로 지불된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **MWPM(Minimum Weight Perfect Matching)**: 측정된 에러 신드롬 그래프에서 가장 확률이 높은 에러 발생 경로 쌍을 찾아내는 그래프 최적화 복호 알고리즘.

</details>

```text
논리 상태 부호화 완료
        │
   보조 큐비트를 인접 데이터 큐비트와 얽어 패리티 복사
        │
   보조 큐비트 측정값이 이전 주기와 달라졌는가?
   ┌────┴─────┐
아니오          예 (결함 발생)
   │             │
다음 주기로     시공간 결함 그래프에 지점 추가
계속             │
   │        복호기가 오류 사슬 추론
   │             │
   │        추론된 오류가 코드 거리 안인가?
   │        ┌────┴─────┐
   │      예            아니오
   │        │             │
   │   파울리 프레임    논리 오류 발생
   │   갱신으로 흡수     (정정 불가)
   └────┬───┴─────────────┘
        │
   다음 신드롬 측정 주기
```

분기 결과: 오류가 코드 거리의 절반을 넘는 순간 정정이 아니라 잘못된 정정이 되어 논리 오류로 바뀌므로, 거리 설정이 곧 허용 가능한 실패 확률을 정함

#### 한줄 요약
- **MWPM(Minimum Weight Perfect Matching)** 같은 복호가 실시간으로 끝나야 다음 주기가 진행되므로, 양자 컴퓨터의 속도는 고전 계산 성능에도 함께 묶인다.

## Ⅴ. 종류 및 비교

| 양자 오류 제어 기술 | 표면 코드 (Surface Code) | 양자 오류 완화 (QEM) | 고전 해밍/리드솔로몬 부호 | 쇼어 9-큐비트 코드 |
|:---|:---|:---|:---|:---|
| 적용 기준 | 결함 허용 대규모 양자 컴퓨터(FTQC) | 현재 NISQ 시대 얕은 양자 회로 | 고전 디지털 메모리 및 통신 네트워크 | 최초의 이론적 양자 오류 정정 개념 |
| 핵심 특징 | 2D 국소 안정자와 반복 신드롬 측정 | 추가 샷·잡음 모델로 기대값 편향 완화 | 중복·패리티로 비트·심볼 오류 정정 | 9개 물리 큐비트의 비트·위상 오류 부호화 |
| 한계 | 1개 논리 큐비트당 수천 개 물리 큐비트 소모 | 회로 깊이가 깊어지면 측정 횟수 지수적 폭증 | 양자 복제 불가 정리로 양자 시스템 적용 불가 | 인접 2D 평면 배선 불가능 및 낮은 임계치 |

#### 한줄 요약
- 완화 기법은 오류를 없애지 않고 결과의 편향만 줄이므로 회로가 깊어지면 무너지며, 정정과 완화는 대체재가 아니라 시대가 다른 선택지다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **복호 지연(Decoding Latency)**: 신드롬 측정 주기가 마이크로초 단위인데 고전 복호기 연산이 느리면 에러가 누적되어 전체 시스템이 지연되는 병목 현상.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 논리 오류 목표를 맞추려면 물리 큐비트가 급증 | 물리 오류율과 회로 깊이를 낮춰 필요한 코드 거리 축소 | 목표 실패 확률을 만족하는 최소 패치 크기 확보 |
| **복호 지연(Decoding Latency)**이 측정 주기를 따라가지 못함 | 전용 하드웨어 가속 복호기 도입 | 측정 주기 안에서 스트리밍 복호 실현 |
| 보조 큐비트 자체의 측정 오류 | 충분한 라운드 반복 측정과 시공간 복호 적용 | 데이터 오류와 측정 오류를 시간 축에서 구분 |
| 떨어진 논리 큐비트 간 연산 비용 증가 | 패치 경계를 병합·분할하는 격자 수술 기법 적용 | 평면 구조 안에서 논리 게이트 구현 |

#### 한줄 요약
- 네 문제 중 둘이 고전 컴퓨터 쪽에서 발생하듯, 결함 허용 양자 컴퓨터는 양자 장치 하나가 아니라 양자와 고전이 실시간으로 맞물린 복합 시스템이다.

## Ⅶ. 결론

- 평면 국소 연결과 높은 임계치가 유리하면 표면 코드를, 연결성이나 잡음 편향이 다르면 대안 부호를 비교하되, 논리 오류 목표는 물리 오류율만이 아니라 신드롬 대역폭·복호 지연·논리 연산 비용까지 함께 설계해야 달성

#### 한줄 요약
- 오류 정정은 잡음을 없애는 기술이 아니라 잡음을 자원으로 환산하는 기술이며, 그래서 논의의 결론은 언제나 몇 개의 물리 큐비트를 살 것인가로 돌아온다.
