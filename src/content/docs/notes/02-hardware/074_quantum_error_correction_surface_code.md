## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **QEC(Quantum Error Correction, 양자 오류 정정)**: 양자 상태를 파괴하지 않고 환경 노이즈로 인해 발생하는 비트 뒤집힘($X$) 및 위상 뒤집힘($Z$) 오류를 감지하고 복구하는 기술.
- **Surface Code(표면 코드)**: 2D 평면 격자 위에 데이터 큐비트와 앤실라 큐비트를 배치하여 인접 큐비트 간의 국소적 상호작용만으로 오류를 정정하는 대표적인 위상적(Topological) QEC 코드.
- **Logical Qubit(논리 큐비트)**: 다수의 물리 큐비트를 오류 정정 코드로 묶어 오류율이 극도로 낮은 단일 가상 큐비트를 구현한 단위.

</details>

- 정의/개념: 양자역학적 복제 불가능 정리(No-Cloning Theorem) 및 측정 붕괴 제약 하에서, 2D 평면 격자 상의 데이터 큐비트와 앤실라(Ancilla) 큐비트 간 국소 안정자(Stabilizer) 패리티 측정을 통해 양자 상태 파괴 없이 비트/위상 오류를 정정하는 대표적 양자 오류 정정(QEC) 기법
- 배경/필요성: 물리 큐비트의 높은 노이즈 오류율($10^{-3}$)을 극복하고, **임의의 깊은 양자 회로를 오류 없이 실행 가능한 오류 허용 양자 컴퓨터(FTQC) 실현 필수**

#### 한줄 요약

- 2D 국소 안정자 측정(Stabilizer) 기반으로 **상태 파괴 없이 비트/위상 오류를 정정하는 2D 격자 표면 코드(Surface Code)**

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **Stabilizer Measurement(안정자 측정)**: 데이터 큐비트 자체를 직접 관측하지 않고, 인접한 4개 데이터 큐비트의 결합 패리티($XXXX$ 또는 $ZZZZ$)를 보조 앤실라 큐비트로 측정하여 오류 위치를 식별하는 기법.
- **Syndrome(오류 증후군)**: 안정자 측정 결과로 도출되는 2진 비트열로, 오류가 발생한 시공간적 위치를 가리키는 지문 데이터.
- **Fault-Tolerant Threshold(오류 임계값)**: 물리 큐비트 오류율이 이 임계치(표면 코드의 경우 약 $1\%$) 이하일 때만 코드 거리를 늘릴수록 논리 오류율이 감소하는 한계선.
- **Code Distance(코드 거리, $d$)**: 논리적 오류를 유발하는 데 필요한 최소 물리적 오류 개수로, 바둑판 격자의 크기에 해당하며 $t = \lfloor(d-1)/2\rfloor$개의 오류 정정 가능.

</details>

![표면 코드 거리에 따른 정정 가능 오류 수 차트](/study/diagrams/surface-code-distance.svg)

- 원본 양자 상태를 직접 관측하지 않고 패리티만 측정하여 파동함수 붕괴를 방지하는 **비파괴 안정자 측정(Stabilizer Measurement)**
- 2D 평면 격자에서 인접한(Nearest Neighbor) 큐비트 간 결합만 요구하며 높은 **오류 임계값($\sim 1\%$)** 보유
- 물리 오류율이 임계치 이하일 때 코드 거리($d$)를 증가시킴에 따라 **논리 오류율이 지수적으로 감소($P_L \propto (P_{phys}/P_{th})^{(d+1)/2}$)**

$$
t = \left\lfloor \frac{d-1}{2} \right\rfloor
$$

#### 한줄 요약

- **비파괴 안정자 측정(Stabilizer)·높은 오류 임계값($\sim 1\%$)·코드 거리 $d$ 비례 오류 지수적 억제**

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **Data Qubit**: 표면 코드 격자 상에서 실제 양자 정보를 분산 저장하는 물리 큐비트.
- **Ancilla Qubit(보조 큐비트)**: 데이터 큐비트의 $X$ 패리티(위상 오류 감지) 및 $Z$ 패리티(비트 오류 감지)를 측정하기 위해 교차 배치된 측정 전용 큐비트.
- **Classical Decoder(고전 복호기)**: 증후군 시계열 그래프를 분석하여 최단 오류 사슬을 찾아내는 알고리즘(MWPM: Minimum-Weight Perfect Matching, Union-Find).
- **Pauli Frame**: 물리 큐비트에 직접 반대 게이트를 가하지 않고 소프트웨어적으로 위상/비트 반전을 추적하여 누적 오차를 방지하는 가상 프레임.

</details>

```text
[ 표면 코드 2D 격자 및 실시간 QEC 복호 아키텍처 ]
┌─────────────────────────────────────────────────────────────┐
│ 1. 2D 평면 큐비트 격자 : [데이터 큐비트] ── [앤실라 큐비트] │
│  ├─ X-안정자 (Z-오류 감지: 위상 뒤집힘)                     │
│  └─ Z-안정자 (X-오류 감지: 비트 뒤집힘)                     │
└──────────────────────────────┬──────────────────────────────┘
                               │ [ 증후군 비트열 측정 (Syndrome) ]
┌──────────────────────────────┴──────────────────────────────┐
│ 2. 증후군 수집 및 3D 시공간 그래프 생성기                   │
└──────────────────────────────┬──────────────────────────────┘
                               │
┌──────────────────────────────┴──────────────────────────────┐
│ 3. 고전 복호기 (MWPM / Union-Find Decoder : FPGA 가속)      │
│  └─ 4. 소프트웨어 파울리 프레임 (Pauli Frame Tracker) 갱신  │
└─────────────────────────────────────────────────────────────┘
```

선의 의미: 2D 격자 데이터 큐비트, 앤실라 큐비트(X/Z 안정자), 증후군 추출기, 고전 복호기(MWPM/Union-Find) 및 파울리 프레임 간의 표면 코드 아키텍처 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 데이터 큐비트 | 표면 코드 바둑판 위에서 진짜 양자 정보를 쪼개서 품고 있는 핵심 생존자들 |
| 앤실라 큐비트 | 데이터 큐비트들 사이에 껴서 "너 에러 났어?" 하고 상태만 훔쳐보고 뱉어내는 끄나풀(보조) 큐비트 |
| 증후군 수집기 | 앤실라들이 뱉어낸 0과 1의 찌꺼기(에러 신호)를 모아서 시공간 3D **오류 증후군** 지도를 그리는 수집상 |
| 고전 복호기 | 지도를 보고 "아, 이 선 따라 에러가 번졌네!" 하고 최단 거리(MWPM)로 범인을 잡아내는 일반 컴퓨터 명탐정 |
| 파울리 프레임 | 에러 난 큐비트를 쑤셔서 물리적으로 뜯어고치지 않고, 소프트웨어 장부에 "얘 에러 남" 하고 적어만 두는 회계 장부 |

#### 한줄 요약

- **데이터 큐비트·앤실라 큐비트(X/Z 패리티)·증후군 수집기·고전 복호기(MWPM)·파울리 프레임(Pauli Frame)**

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Code Cycle(코드 주기)**: 앤실라 큐비트와 데이터 큐비트 간 얽힘 게이트 인가부터 앤실라 측정 및 리셋까지 완료되는 1회 반복 QEC 루프(초전도 기준 약 $1\,\mu\text{s}$).

</details>

```text
[ 표면 코드 QEC 증후군 측정 및 복호 루프 ]
                         │
        +────────────────┴────────────────────────+
        │         ( 매 코드 주기(Code Cycle) 반복 )│
        │                        │                │
        │                        ▼                │
        │   [ 1. 앤실라-데이터 큐비트 간 CNOT/CZ 인가 ] │
        │                        │                │
        │                        ▼                │
        │   [ 2. 앤실라 큐비트 투사 측정 및 리셋 ]│
        │                        │                │
        │                        ▼                │
        │   [ 3. 시간적 변화 감지 ──> 증후군 비트 추출 ]│
        +────────────────────────┬────────────────+
                                 │
                                 ▼
   [ 4. FPGA 복호기가 3D 시공간 매칭 그래프에서 최단 오류 사슬 탐색 ]
                                 │
                                 ▼
   [ 5. 파울리 프레임(Pauli Frame) 소프트웨어 레지스터 갱신 ]
```

**동작 원리**

1. **안정자 회로 구동**: 앤실라 큐비트와 주변 4개 데이터 큐비트 간에 4단계 CNOT 게이트 순차 인가
2. **증후군 측정**: 앤실라 큐비트를 측정하여 패리티 비트($0$ 또는 $1$)를 읽어내고 다음 주기를 위해 바닥 상태로 리셋
3. **증후군 결함 추출**: 이전 주기 측정값과 현재 측정값의 XOR을 통해 오류가 발생한 시공간 좌표(Defect) 추출
4. **고전 매칭 복호**: MWPM 알고리즘이 결함 쌍들을 연결하는 가중치 최소 경로를 계산하여 물리 오류 위치 추정
5. **소프트웨어 보정**: 물리 게이트를 추가하지 않고 고전 제어기의 파울리 프레임 테이블을 갱신하여 사후 연산에 반영

#### 한줄 요약

- 안정자 CNOT 회로 구동 $\to$ **앤실라 패리티 측정 $\to$ 오류 증후군(Syndrome) 추출 $\to$ MWPM 최단 오류 사슬 복호 $\to$ 파울리 프레임 소프트웨어 갱신**

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **Surface Code FTQC vs Error Mitigation vs Classical ECC**:
  - Surface Code: 물리 큐비트 수백~수천 개로 논리 큐비트 생성, 임의의 회로 깊이 지원
  - Error Mitigation: 추가 큐비트 없이 샷 수 증가로 통계적 오차 상쇄 (NISQ 전용)
  - Classical ECC: 비트 복제 기반 패리티 검사, 연속적인 양자 위상 오류 정정 불가

</details>

| 비교 항목 | 표면 코드 기반 FTQC (Fault-Tolerant) | NISQ 기반 오류 완화 (Error Mitigation) | 고전 ECC (Reed-Solomon / LDPC) |
|:---|:---|:---|:---|
| 오류 정정 메커니즘 | 물리 큐비트 잉여 부호화 및 실시간 증후군 측정 | 사후 통계적 외삽 (ZNE, Readout Calibration) | 데이터 비트 단순 복제 및 다수결/패리티 검사 |
| 필요 자원 및 오버헤드 | 논리 큐비트당 수백~수천 개 물리 큐비트 소모 | 추가 물리 큐비트 0개 (반복 측정 샷 수 증가) | 데이터 비트 대비 $10\sim 50\%$ 수준의 패리티 비트 |
| 한계 및 적합 분야 | 막대한 하드웨어 오버헤드 (범용 대규모 FTQC) | 회로 깊이 증가 시 완화 불가 (단기 NISQ 알고리즘) | 양자 상태의 연속 위상 오류 정정 불가 |

#### 한줄 요약

- 장기 대규모 연산은 **표면 코드 FTQC**, 단기 얕은 회로는 **오류 완화**, 디지털 데이터는 **고전 ECC**

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Streaming Decoder(스트리밍 복호기)**: 큐비트 측정 데이터가 쏟아지는 속도($\sim 1\,\mu\text{s}$)에 맞춰 지연(Latency) 없이 실시간으로 오류를 추론하는 FPGA/ASIC 하드웨어.
- **Resource Overhead**: $d=3$일 때 17개, $d=5$일 때 49개, $d=27$(RSA 해독 수준)일 때 논리 큐비트 1개당 약 1,500개의 물리 큐비트가 필요한 자원 부담.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 큐비트는 미친 듯이 에러를 뱉는데 고전 복호기(명탐정) 연산이 늦어서 증후군이 산더미처럼 쌓여 터지는 셧다운 사태 | 반도체 칩(FPGA)을 떡칠해서 에러가 나오는 즉시 빛의 속도로 추리해 버리는 **스트리밍 복호기** 구축 | 런타임 지연으로 양자 컴퓨터가 뻗어버리는 참사를 막고 **파울리 프레임**을 실시간 갱신 100% 보장 |
| 에러 한 번 고치겠다고 쓸데없이 큐비트 수만 개를 낭비해서 컴퓨터 크기만 커지는 살인적인 **자원 오버헤드** 폭발 | 목표로 하는 에러율에 딱 맞춰서 바둑판 크기(코드 거리)를 다이어트하고 패치 배치를 뼈 깎듯 최적화 | 쓸모없이 버려지는 잉여 물리 큐비트 소모를 쥐어짜 줄여 양자 컴퓨터의 가성비 및 확장성 타개 |
| 바둑판 위에 큐비트를 촘촘히 박았더니 옆에 놈한테 전자파가 튀어서 다 같이 에러가 터지는 **교차 간섭** 연쇄 재앙 | 가변 결합기로 큐비트 사이를 물리적으로 격리하고 상관 오류를 빡세게 잡아내 펄스 튜닝 깎음 | 큐비트 간 유령 간섭을 차단해 물리 오류율을 궁극의 **오류 임계값**(Threshold) 아래로 억제해 냄 |

#### 한줄 요약

- **FPGA 기반 초저지연 스트리밍 복호기(Streaming Decoder)·코드 거리(d) 최적화·Tunable Coupler 크로스토크 차단**

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **차세대 qLDPC(Quantum Low-Density Parity-Check)**: 2D 표면 코드의 평면 제약을 넘어 장거리 결합을 활용하여 물리/논리 큐비트 오버헤드를 10배 이상 절감하는 차세대 QEC 코드.

</details>

- 차세대 양자 컴퓨터 상용화 로드맵에서 **물리 오류율 0.1% 이하 달성 및 표면 코드 기반 1,000+ 논리 큐비트 시스템 구축 표준 채택**

#### 한줄 요약

- **오류 임계값($\sim 1\%$) 극복과 실시간 하드웨어 복호기**를 통한 내결함 양자 컴퓨팅 완성
