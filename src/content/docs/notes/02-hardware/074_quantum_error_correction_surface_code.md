## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **양자 오류 정정(Quantum Error Correction, QEC)**: 여러 물리 큐비트에 논리 정보를 부호화하여 오류를 검출하고 보정하는 기술이다.
- **표면 코드(Surface Code)**: 2차원 큐비트 격자에서 국소 안정자를 반복 측정하여 논리 정보를 보호하는 오류 정정 코드이다.
- **논리 큐비트(Logical Qubit)**: 여러 물리 큐비트와 오류 정정 규칙으로 보호한 하나의 양자 계산 단위이다.

</details>

- 정의/개념: 여러 물리 큐비트에 정보를 부호화하고 안정자를 반복 측정해 **논리 큐비트**를 보호하는 **양자 오류 정정**이며, 2차원 격자를 사용하는 대표 방식이 **표면 코드**이다.
- 배경/필요성: 잡음이 있는 물리 큐비트만 직접 사용하면 회로가 길어질수록 오류가 누적되어 논리 상태를 신뢰성 있게 유지할 수 없다.

#### 한줄 요약

- 양자 오류 정정은 논리 상태를 직접 노출하지 않는 안정자 반복 측정으로 오류 증후군을 얻는다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **안정자(Stabilizer)**: 논리 상태 자체를 읽지 않고 주변 큐비트의 비트•위상 패리티를 검사하는 연산자이다.
- **오류 증후군(Error Syndrome)**: 안정자 측정값의 변화에서 얻는 물리 오류의 위치와 유형에 관한 단서이다.
- **오류 임계값(Error Threshold)**: 물리 오류율이 이 값 아래일 때 코드 거리를 늘리면 논리 오류율이 감소하는 경계이다.
- **오류 사슬(Error Chain)**: 시공간 격자에서 여러 검출 사건을 이어 물리 오류의 가능한 경로로 표현한 것이다.

</details>

![표면 코드 거리에 따른 정정 가능 오류 수 차트](/study/diagrams/surface-code-distance.svg)

> 코드 거리 3→11에서 정정 오류 수 1→5 증가

- **안정자** 측정으로 비트•위상 오류의 **오류 증후군**을 생성한다.
- 시간축을 포함한 증후군 변화로 **오류 사슬**을 추정한다.
- **오류 임계값** 아래에서는 코드 거리를 늘릴수록 논리 오류율이 감소한다.

#### 한줄 요약

- 코드 거리가 증가하면 정정 능력과 자원 오버헤드가 함께 증가한다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **데이터 큐비트(Data Qubit)**: 논리 양자 정보를 여러 소자에 분산하여 저장하는 물리 큐비트이다.
- **보조 큐비트(Ancilla Qubit)**: 데이터 큐비트의 안정자 값을 측정해 오류 증후군을 만드는 큐비트이다.
- **증후군 수집기(Syndrome Collector)**: 안정자 결과의 시간 변화를 검출 사건 이력으로 구성하는 처리기이다.
- **고전 복호기(Classical Decoder)**: 증후군 시공간 이력에서 가장 가능성 높은 오류 사슬을 추정하는 처리기이다.
- **파울리 프레임(Pauli Frame)**: 즉시 물리 게이트로 보정하지 않고 논리 보정 상태를 고전 정보로 기록하는 방식이다.

</details>

```text
[데이터 큐비트] -- [보조 큐비트] -- [증후군 수집기]
                                            |
                              [고전 복호기] -- [파울리 프레임]
```

선의 의미: 데이터•보조 큐비트의 안정자 관계와 증후군 수집기•고전 복호기•파울리 프레임의 정적 오류 정정 인터페이스다.

| 구성요소 | 책임 |
|:---|:---|
| 데이터 큐비트 | 논리 정보 분산 저장 |
| 보조 큐비트 | 안정자 패리티 측정 |
| 증후군 수집기 | 검출 사건 이력 생성 |
| 고전 복호기 | 오류 사슬 추정 |
| 파울리 프레임 | 논리 보정 상태 기록 |

#### 한줄 요약

- **증후군 수집기**와 **고전 복호기**가 오류 사슬을 추정해 **파울리 프레임**을 갱신한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **코드 주기(Code Cycle)**: 모든 필요한 안정자를 한 차례 측정하고 증후군을 수집하는 반복 시간 단위이다.
- **검출 사건(Detection Event)**: 연속한 코드 주기 사이에서 안정자 측정값이 변하여 오류 가능성을 나타내는 지점이다.
- **코드 거리(Code Distance)**: 검출되지 않은 채 논리 상태를 바꿀 수 있는 최소 물리 오류 경로의 길이다.
- **안정자 측정**: 보조 큐비트로 데이터 큐비트의 X·Z 패리티를 읽는 단계이다.
- **증후군 비트 생성**: 논리 상태를 직접 읽지 않고 안정자 결과를 수집하는 단계이다.
- **검출 사건 이력 구성**: 연속 코드 주기의 측정값 변화를 시공간 이력으로 기록하는 단계이다.
- **오류 사슬 복호**: 검출 사건을 설명할 가능성이 높은 물리 오류 경로를 추정하는 단계이다.
- **파울리 프레임 갱신**: 추정한 보정 상태를 고전 정보로 기록하는 단계이다.

</details>

```text
┌──────────── 코드 주기 반복 ────────────┐
│ 1. 안정자 측정                         │
│          │                              │
│          ▼                              │
│ 2. 증후군 비트 생성                    │
│          │                              │
│          ▼                              │
│ 3. 검출 사건 이력 구성                 │
│          │                              │
│          ▼                              │
│ 4. 오류 사슬 복호                      │
│          │                              │
│          ▼                              │
│ 5. 파울리 프레임 갱신                  │
│          │                              │
│          └── 후속 게이트•측정 해석 반영 │
└─────────────────────────────────────────┘
```

코드 거리가 \(d\)인 코드는 이상적 조건에서 다음 개수까지의 물리 오류를 정정할 수 있다.

$$
t = \left\lfloor \frac{d-1}{2} \right\rfloor
$$

> 요약: 코드 거리 d에서 최대 ⌊(d-1)/2⌋개 오류를 정정할 수 있다.

### 동작 원리

1. **안정자 측정**: 보조 큐비트와 데이터 큐비트를 상호작용시켜 X•Z 패리티를 측정한다.
2. **증후군 비트 생성**: 논리 상태 자체를 읽지 않고 각 안정자의 측정 결과를 수집한다.
3. **검출 사건 이력 구성**: 연속한 코드 주기의 측정값 변화를 시공간 검출 사건으로 기록한다.
4. **오류 사슬 복호**: 고전 복호기가 검출 사건을 설명할 가능성이 가장 높은 물리 오류 경로를 추정한다.
5. **파울리 프레임 갱신**: 추정한 보정을 고전 상태로 기록하고 후속 게이트와 최종 측정 해석에 반영한다.

#### 한줄 요약

- 시공간 **검출 사건**에서 **오류 사슬**을 복호한 뒤 그 결과를 파울리 프레임에 반영한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **내결함 양자 계산(Fault-tolerant Quantum Computing)**: 일부 물리 오류가 전체 논리 오류로 확산되지 않도록 연산과 측정을 구성하는 방식이다.
- **오류 완화(Error Mitigation)**: 논리 부호화 없이 반복 측정과 후처리로 짧은 회로의 잡음 영향을 줄이는 방식이다.
- **자원 오버헤드(Resource Overhead)**: 논리 큐비트 보호를 위해 추가되는 물리 큐비트와 측정 및 복호 계산량이다.

</details>

| 실행 방식 | 표면 코드 논리 실행 | 물리 큐비트 직접 실행 |
|:---|:---|:---|
| 적용 기준 | 장시간 **내결함 양자 계산** | 짧은 회로•**오류 완화** 실험 |
| 핵심 특징 | 안정자 반복 측정 | 물리 게이트 즉시 실행 |
| 한계 | 큰 **자원 오버헤드** | 오류 누적•확장 한계 |

#### 한줄 요약

- 장시간 **내결함 양자 계산**에는 논리 부호화가 필요하며, 짧은 물리 회로 실험에는 **오류 완화**를 사용할 수 있다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **스트리밍 복호(Streaming Decoding)**: 증후군을 수신하는 즉시 오류를 연속 추정하여 복호 지연을 줄이는 방식이다.
- **누설 오류(Leakage Error)**: 큐비트가 0과 1 계산 기저 밖의 물리 상태로 벗어나는 오류이다.
- **상관 오류(Correlated Error)**: 공통 원인으로 여러 큐비트에 함께 발생하여 독립 오류 가정을 깨는 오류이다.
- **코드 패치(Code Patch)**: 하나의 논리 큐비트를 구성하는 표면 코드 격자의 물리 영역이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 복호 지연이 코드 주기보다 길어 프레임 반영 지연 | **스트리밍 복호**와 병렬 처리 | 실시간 프레임 갱신 유지 |
| **누설 오류·상관 오류**가 독립 오류 모델을 위반 | 누설 제거 회로와 상관 오류 모델 적용 | 논리 오류율 평가 정확도 향상 |
| 측정 오류와 데이터 오류가 같은 증후군으로 혼동 | 시공간 증후군 분석 | 오류 사슬 위치 정확도 향상 |
| 과도한 코드 거리로 물리 큐비트•복호 자원 급증 | 목표별 코드 거리와 **코드 패치** 산정 | 자원 과잉 배치 방지 |

#### 한줄 요약

- 목표 논리 오류율과 물리 오류 모델에 맞춰 코드 거리와 패치 자원 및 복호 성능을 함께 산정한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **물리 오류율(Physical Error Rate)**: 게이트와 측정 및 유휴 상태가 실패하는 비율이다.
- **논리 오류율(Logical Error Rate)**: 오류 정정 후에도 하나의 논리 주기나 연산이 실패하는 비율이다.
- **복호 지연(Decoding Latency)**: 증후군 수집부터 파울리 프레임 갱신 결과가 나오기까지 걸리는 시간이다.
- **표면 코드 매개변수 선택 기준**: 물리 오류율에서 목표 논리 오류율과 복호 지연을 만족하는 코드 거리를 정하는 기준이다.

</details>

- **표면 코드 매개변수 선택 기준**에 따라 **물리 오류율**이 임계값 아래일 때 목표 **논리 오류율**과 **복호 지연**을 만족하는 **코드 거리**를 선택한다.

#### 한줄 요약

- 물리 오류율이 임계값 아래이고 복호 지연을 감당할 수 있을 때 코드 거리를 늘려 논리 오류율을 낮춘다.
