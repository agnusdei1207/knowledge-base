## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **QEC(Quantum Error Correction)**: 환경 잡음으로 인한 큐비트 파동함수의 비트 반전(Bit Flip) 및 위상 반전(Phase Flip) 오류를 복수의 물리 큐비트로 부호화하여 정정하는 내결함 기술.
- **표면 코드(Surface Code)**: 2D 평면 격자 상에 데이터 큐비트와 앤실라(Ancilla) 큐비트를 교대로 배열하여 인접 큐비트 패리티만 측정(Stabilizer Measurement)하는 대표적 QEC 코드.
- **논리 큐비트(Logical Qubit)**: 여러 물리 큐비트에 논리 정보를 부호화해 오류 억제를 적용하는 큐비트.

</details>

- 정의/개념: 복수의 물리 큐비트 상에서 앤실라 패리티 측정을 수행하여 **논리 큐비트**의 비트/위상 오류를 복호화 정정하는 **QEC** 및 2D 격자 아키텍처인 **표면 코드**
- 배경/필요성: 복제 불가능 정리(No-Cloning Theorem) 및 관측 수축 문제로 인한 일반 고전 비트 복사 방식 적용 불가 한계 극복 요구

#### 한줄 요약

- 양자 오류 정정은 논리 상태를 직접 노출하지 않는 안정자 반복 측정으로 오류 증후군을 얻는다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **안정자(Stabilizer Measurement)**: 큐비트 본래 양자 상태($|\psi\rangle$)를 붕괴시키지 않고, X/Z 패리티 텐서 연산자($X_1 X_2 X_3 X_4$, $Z_1 Z_2 Z_3 Z_4$)를 통해 오류 신호만 관측하는 기법.
- **오류 증후군(Syndrome)**: 앤실라 큐비트 패리티 측정 결과로 얻어지는 0/1 오류 신호 패턴 데이터.
- **오류 임계값(Fault-Tolerant Threshold)**: 코드 거리를 늘릴 때 논리 오류율이 감소하기 위한 물리 오류율 경계.
- **코드 거리(Code Distance, d)**: 논리 상태 비트를 역전시키기 위해 필요한 최소 물리 에러의 개수 ($t = \lfloor(d-1)/2\rfloor$개 정정 가능).

</details>

![표면 코드 거리에 따른 정정 가능 오류 수 차트](/study/diagrams/surface-code-distance.svg)

- 본래 양자 정보를 유지한 채 비트/위상 반전만 감지하는 **안정자 측정** 메커니즘
- 물리 오류 모델·회로·복호기에 따라 달라지는 **오류 임계값**
- 임계값 아래에서 **코드 거리** 확장에 따른 논리 오류율 감소와 자원 증가

$$
t = \left\lfloor \frac{d-1}{2} \right\rfloor
$$

#### 한줄 요약

- 코드 거리가 증가하면 정정 능력과 자원 오버헤드가 함께 증가한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **데이터 큐비트(Data Qubit)**: 실제 논리 양자 상태 정보의 파동함수를 분산 보유하는 2D 격자 큐비트.
- **앤실라 큐비트(Ancilla/Measure Qubit)**: 인접한 4개 데이터 큐비트의 X/Z 패리티를 얽힘 측정하여 덤프받는 보조 큐비트.
- **고전 복호기(Classical Decoder/MWPM)**: 앤실라 증후군 시공간 매핑 데이터로부터 최적 오류 경로를 실시간 추정하는 알고리즘 (MWPM, Union-Find).
- **파울리 프레임(Pauli Frame)**: 추정된 파울리 에러($X, Y, Z$)를 물리 펄스로 직접 수정하지 않고 소프트웨어 상에서 포인터 갱신하는 후처리 기법.

</details>

```text
[데이터 큐비트] -- [보조 큐비트] -- [증후군 수집기]
                                            |
                              [고전 복호기] -- [파울리 프레임]
```

선의 의미: 데이터/앤실라 물리 큐비트 레이어에서 측정된 증후군이 고전 복호기를 통해 파울리 프레임 계층으로 처리되는 신호 아키텍처.

| 구성요소 | 책임 |
|:---|:---|
| 데이터 큐비트 | 표면 코드 격자 상에서 실제 양자 정보를 분산 수용 |
| 앤실라 큐비트 | 인접 데이터 큐비트와 CNOT 연산 후 X/Z 패리티 증후군 추출 |
| 증후군 수집기 | 앤실라 readout 결과로부터 시공간 3D **오류 증후군** 그래프 형성 |
| 고전 복호기 | MWPM(Minimum Weight Perfect Matching) 기반 최단 오류 에지 추정 |
| 파울리 프레임 | 물리 펄스 대신 소프트웨어 상에서 파울리 변환 상태(**Pauli Frame**) 관리 |

#### 한줄 요약

- 증후군 수집기와 고전 복호기가 오류 사슬을 추정해 파울리 프레임을 갱신한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **코드 주기(Code Cycle)**: 표면 코드 상에서 1회 X/Z 패리티 안정자 측정을 완성하는 단위 시간.

</details>

```text
┌──────────── 코드 주기 반복 ────────────┐
│ 1. 안정자 측정                         │
│          │                              │
│          ▼                              │
│ 2. 증후군 비트 생성                    │
│          │                              │
│          ▼                              │
│ 3. 검출 사건 이력 구성                 │
│          │                              │
│          ▼                              │
│ 4. 오류 사슬 복호                      │
│          │                              │
│          ▼                              │
│ 5. 파울리 프레임 갱신                  │
│          │                              │
│          └── 후속 게이트•측정 해석 반영 │
└─────────────────────────────────────────┘
```

### 동작 원리

1. **안정자 측정**: **앤실라 큐비트**와 인접 **데이터 큐비트**를 결합해 X/Z 패리티 측정.
2. **증후군 비트 생성**: 앤실라 관측 결과 기반 비트 덤프 및 **오류 증후군** 수치 추출.
3. **검출 사건 이력 구성**: 연속적인 **코드 주기(Code Cycle)** 집계 데이터를 통한 시공간 에러 그래핑.
4. **오류 사슬 복호**: **고전 복호기(MWPM)** 알고리즘 기반 물리 에러 매칭 추정.
5. **파울리 프레임 갱신**: 추정 결과를 소프트웨어 **파울리 프레임**에 매핑 갱신.

#### 한줄 요약

- 시공간 검출 사건에서 오류 사슬을 복호한 뒤 그 결과를 파울리 프레임에 반영한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **내결함 양자 컴퓨팅(FTQC/Fault-Tolerant Quantum Computing)**: 오류가 전파되지 않도록 논리 연산과 오류 정정을 함께 설계한 양자 컴퓨팅.
- **오류 완화(Error Mitigation)**: NISQ(Noisy Intermediate-Scale Quantum) 시대에 오류 정정 없이 통계적 억제를 가하는 기술 (Zero-Noise Extrapolation 등).

</details>

| 비교 항목 | 표면 코드 기반 내결함 방식 (FTQC) | NISQ 기반 오류 완화 방식 (Mitigation) |
|:---|:---|:---|
| 적용 기준 | 목표 논리 오류율과 오류 정정 자원을 확보할 때 | 오류 정정 자원이 부족한 얕은 회로 실험 시 |
| 핵심 특징 | **논리 큐비트** 부호화와 반복 **안정자 측정** | 물리 큐비트 직접 구동과 **통계 후처리** |
| 한계 | 수백~수천 개의 물리 큐비트 오버헤드 소모 | 회로 깊이 증가 시 통계적 오차 한계 봉착 |

#### 한줄 요약

- 장시간 내결함 양자 계산에는 논리 부호화가 필요하며, 짧은 물리 회로 실험에는 오류 완화를 사용할 수 있다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **스트리밍 복호(Streaming Decoding)**: 증후군 생성 속도를 따라가며 연속적으로 오류를 추정하는 실시간 복호 기술.
- **자원 오버헤드(Resource Overhead)**: 논리 큐비트와 논리 연산에 필요한 물리 큐비트·측정·복호 자원.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 고전 복호기 처리 지연으로 인한 **증후군 적체(Decoders Bottleneck)** | FPGA/ASIC 기반 **스트리밍 복호기** 구축 | 런타임 지연 차단 및 파울리 프레임 실시간 갱신 |
| 높은 **자원 오버헤드**로 인한 물리 큐비트 부족 | 목표 논리 오류율별 코드 거리와 패치 배치 최적화 | 불필요한 물리 큐비트 소모 감소 |
| 물리 큐비트 간 **교차 간섭**이 임계값 초과 | 결합기·펄스·배치 조정과 상관 오류 측정 | 물리 오류율을 **오류 임계값** 아래로 억제 |

> 사례: **표면 코드(Surface Code)** 적용을 통한 거리 $d=3, 5$ 논리 큐비트 오류 정정 실증

#### 한줄 요약

- 목표 논리 오류율과 물리 오류 모델에 맞춰 코드 거리와 패치 자원 및 복호 성능을 함께 산정한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **QEC 채택 기준(QEC Adoption Criteria)**: 물리 게이트 오류율, 복호기 런타임 처리량 및 큐비트 오버헤드 수용성에 기초한 내결함 체계.

</details>

- 물리 오류가 **임계값 아래**이고 자원·복호 지연을 감당할 때 **표면 코드** 도입

#### 한줄 요약

- 임계값·목표 논리 오류율·자원·복호 지연을 함께 만족할 때 표면 코드를 선택한다.
