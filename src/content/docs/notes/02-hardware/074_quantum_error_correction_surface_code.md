## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **양자 오류 정정(Quantum Error Correction, QEC)**: 양자 상태를 직접 측정하여 붕괴시키지 않고, 보조 큐비트와의 얽힘을 통한 패리티(안정자) 측정으로 비트 반전(X) 및 위상 반전(Z) 오류를 실시간 복원하는 기술.
- **표면 코드(Surface Code)**: 물리 큐비트들을 2차원 평면 격자에 배치하여 인접한 큐비트 간의 국소적 상호작용만으로 오류를 정정하는 대표적인 2D 토폴로지컬 양자 부호.

</details>

- 정의/개념: 단일 논리 양자 정보를 다수의 물리 큐비트에 분산 부호화하고, 보조 큐비트로 **안정자(Stabilizer) 패리티 신드롬**을 반복 측정하여 양자 오류를 실시간 정정하는 **표면 코드(Surface Code) QEC 아키텍처**
- 배경/필요성: 양자역학의 복제 불가 정리(No-Cloning Theorem)와 측정 시 상태 붕괴 특성으로 인해 **고전적인 단순 비트 복사 및 다수결 투표 방식의 오류 정정 적용 불가**

#### 한줄 요약
- 표면 코드는 양자 상태를 붕괴시키지 않고 보조 큐비트의 신드롬 측정을 통해 비트(X)와 위상(Z) 오류를 동시에 정정하는 표준 QEC 기술이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **오류 임계치(Fault-Tolerance Threshold)**: 물리 게이트의 오류율이 이 기준값(표면 코드의 경우 약 1%) 이하일 때, 코드 거리($d$)를 늘릴수록 논리 오류율이 지수적으로 0에 수렴하는 한계선.
- **코드 거리(Code Distance, $d$)**: 단일 논리 큐비트의 상태를 반전시키는 데 필요한 최소 물리적 오류의 개수(최대 $\lfloor(d-1)/2\rfloor$개의 물리 오류 동시 정정 가능).

</details>

- 2D 평면 국소 연결성: 2차원 평면 격자에서 **최근접(Nearest-Neighbor) 상호작용**만으로 안정자 측정이 가능하여 초전도 반도체 QPU 구현에 최적
- 높은 결함 허용 **오류 임계치(약 1%)**: 타 양자 부호 대비 압도적으로 높은 물리 오류 허용 임계치 보유
- 비트(X)와 위상(Z)의 독립적 검출: 데이터 큐비트와 X/Z 보조 큐비트의 체커보드 교차 배치를 통해 두 축의 오류를 완벽히 분리 정정

#### 한줄 요약
- 2D 평면 최근접 연결성과 1%의 높은 오류 임계치를 바탕으로 초전도 QPU에서 가장 유력한 결함 허용(FTQC) 부호로 채택된다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **데이터 큐비트(Data Qubit)**: 실제 양자 알고리즘 연산에 사용되는 논리 양자 정보의 확률 진폭을 분산 보관하는 물리 소자.
- **보조 큐비트(Ancilla / Syndrome Qubit)**: 데이터 큐비트와 CNOT 게이트로 얽힌 후 측정되어 X-타입(위상) 또는 Z-타입(비트) 에러 신드롬을 추출하는 측정 전용 소자.

</details>

```text
[표면 코드 2D 격자 패치 및 신드롬 복호 아키텍처]
 ┌─ [QPU 실리콘 2D 격자 계층 ($d \times d$ 물리 패치)]
 │   ├─ [데이터 큐비트 (● Data Qubit)] ── 양자 정보 분산 부호화 소자
 │   ├─ [X 보조 큐비트 (■ Measure-X)] ── 인접 4개 데이터 큐비트의 위상 반전(Z) 감지
 │   └─ [Z 보조 큐비트 (▲ Measure-Z)] ── 인접 4개 데이터 큐비트의 비트 반전(X) 감지
 │
 └─ [고전 실시간 제어 및 고속 복호 계층]
     ├─ 마이크로파 판독 ADC ──────────── 1 마이크로초($\mu\text{s}$) 단위 신드롬 비트 스트리밍
     ├─ [실시간 고속 복호기 (Decoder)] ── FPGA / ASIC 기반 MWPM / Union-Find 에러 매칭
     └─ [파울리 프레임 (Pauli Frame)] ── 소프트웨어 테이블 갱신으로 실시간 에러 오프셋 추적
```

선의 의미: 가지(`├─`, `└─`)는 하드웨어 소속 및 양자-고전 연동 관계; 보조 큐비트 측정 신드롬이 FPGA 복호기로 전달되어 파울리 프레임을 갱신함

| 구성요소 | 소속 및 위치 | 핵심 엔지니어링 책임 | 주요 특징 |
|:---|:---|:---|:---|
| **데이터 큐비트** | 2D 격자 정점 | 단일 논리 큐비트의 양자 상태를 다수의 물리 큐비트에 분산 부호화 | $d^2$ 개 소자 |
| **X 보조 큐비트** | 2D 격자 면/변 | 인접 데이터 큐비트들과 CNOT 연산 후 **위상 반전(Z) 에러 신드롬 측정** | 위상 오류 감지 |
| **Z 보조 큐비트** | 2D 격자 면/변 | 인접 데이터 큐비트들과 CNOT 연산 후 **비트 반전(X) 에러 신드롬 측정** | 비트 오류 감지 |
| **실시간 고속 복호기**| 고전 FPGA/ASIC | 시공간 결함 그래프를 분석하여 **최소 가중치 완전 매칭(MWPM) 복호** 수행 | $1\mu\text{s}$ 이내 처리 |
| **파울리 프레임** | 제어 소프트웨어단 | 물리 게이트를 인가하지 않고 소프트웨어 위상 테이블만 갱신하여 에러 흡수 | 무지연 에러 추적 |

#### 한줄 요약
- 표면 코드는 데이터 큐비트, X/Z 보조 큐비트, 고속 FPGA 복호기 및 파울리 프레임 추적기로 구성된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **최소 가중치 완전 매칭(Minimum Weight Perfect Matching, MWPM)**: 2D/3D 신드롬 결함 그래프에서 에러가 발생했을 확률이 가장 높은 큐비트 쌍을 찾아내는 그래프 최적화 복호 알고리즘.

</details>

```text
1. 논리 큐비트 부호화 및 양자 게이트 연산 진행
                      │
                      ▼
2. 보조 큐비트: 인접 4개 데이터 큐비트와 CNOT 얽힘 후 패리티 신드롬 측정 (1회 라운드)
                      │
                      ▼
3. 측정 결과에서 신드롬 값의 반전(Defect)이 감지되었는가?
   ┌──────────────────┴──────────────────┐
[ 반전 없음 (에러 0) ]                [ 신드롬 반전 감지 (결함 발생) ]
   │                                     │
   ▼                                     ▼
4. 정상 양자 상태 유지                   4. FPGA 복호기: 시공간 3D 결함 그래프(Defect Graph) 생성
   │                                     │
   │                                     ▼
   │                                  5. MWPM / Union-Find 알고리즘으로 최단 에러 사슬 매칭
   │                                     │
   │                                     ▼
   │                                  6. 물리적 에러 개수가 정정 한계($\lfloor(d-1)/2\rfloor$) 이내인가?
   │                                     ┌──────────┴──────────┐
   │                                   [ 한계 이내 (정정 성공) ] [ 한계 초과 (정정 실패) ]
   │                                     │                     │
   │                                     ▼                     ▼
   │                                  7. 파울리 프레임         7. 논리 에러 발생 ➔ 연산 실패
   │                                     소프트웨어 갱신
   │                                     │
   └──────────────────┬──────────────────┘
                      │
                      ▼
8. 다음 신드롬 측정 라운드 반복 (마이크로초 단위 루프 지속)
```

분기 결과: **신드롬 측정을 통해** 데이터 큐비트 붕괴 없이 에러 위치를 찾아 파울리 프레임을 갱신하므로 무결한 논리 연산이 유지됨

#### 한줄 요약
- 패리티 신드롬 측정 ➔ 결함 감지 ➔ 3D 결함 그래프 생성 ➔ MWPM 복호 ➔ 파울리 프레임 갱신 ➔ 주기적 반복 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **양자 오류 완화(Quantum Error Mitigation, QEM)**: 큐비트 증설 없이 잡음 외삽(ZNE)을 통해 통계적 기대값 편향만 보정하는 NISQ 시대 기법.

</details>

| 오류 제어 방식 | 표면 코드 (Surface Code QEC) | 양자 오류 완화 (QEM) | 고전 해밍 부호 (ECC) |
|:---|:---|:---|:---|
| 핵심 적용 패러다임 | **결함 허용 양자 컴퓨팅 (FTQC)** | 현재 노이즈 양자 컴퓨팅 (NISQ) | 고전 디지털 메모리 및 통신망 |
| 오류 정정 메커니즘 | **보조 큐비트 안정자 측정 및 실시간 복호**| 통계적 노이즈 외삽 및 사후 확률 보정 | 단순 패리티 비트 연산 및 다수결 |
| 물리 자원 오버헤드 | **매우 큼 (논리 1개당 수백~수천 개 소자)** | **추가 큐비트 소모 없음 (측정 샷 증가)**| 작음 (수 비트 추가) |
| 정정 가능 오류 | **비트 반전(X) + 위상 반전(Z) 동시 정정** | 통계적 기대값 오차 축소 | 비트 반전(0/1) 단일 오류 정정 |

#### 한줄 요약
- 단기 얕은 양자 회로에는 오류 완화(QEM)가 쓰이며, 장기 대규모 범용 양자 연산에는 표면 코드 기반 오류 정정(QEC)이 필수적이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **복호 지연(Decoding Latency)**: 신드롬 측정 주기가 $1\mu\text{s}$인데 고전 복호기의 연산이 지연될 경우 신드롬 백로그가 누적되어 전체 양자 연산이 멈추는 병목 현상.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **복호 지연(Decoding Latency)**으로 인한 신드롬 백로그 누적 | **FPGA/ASIC 기반 Union-Find 하드웨어 가속 복호기 실장** | $1\mu\text{s}$ 이내 실시간 스트리밍 복호 완수 |
| 보조 큐비트 자체의 판독 측정 오류로 인한 오판정 | **시공간 3차원($d$ 라운드 시간축) 반복 측정 및 신드롬 필터링** | 보조 큐비트 측정 결함과 데이터 큐비트 결함 완벽 분리 |
| 논리 큐비트 1개당 요구되는 물리 큐비트($10^3$) 과다 소모 | **물리 게이트 충실도 개선($99.9\% \to 99.99\%$) 및 코드 거리 축소** | 필요 물리 큐비트 오버헤드 80% 이상 절감 |

#### 한줄 요약
- 실무에서는 FPGA 가속 복호기로 지연을 막고, 3차원 반복 측정으로 신뢰성을 확보하며, 물리 충실도 개선으로 오버헤드를 줄인다.

## Ⅶ. 결론

- 범용 결함 허용 양자 컴퓨터(FTQC)를 실현하기 위해 **2D 평면 최근접 연결성을 갖춘 표면 코드(Surface Code) QEC를 표준 채택**하고, 복호 지연을 극복하기 위해 **FPGA/ASIC 기반 초저지연 하드웨어 복호기(Union-Find/MWPM)**를 연동하며, 양자 게이트 충실도를 $99.9\%$ 이상으로 고도화하는 실시간 양자 오류 정정 아키텍처 확립

#### 한줄 요약
- 표면 코드는 높은 임계치와 2D 평면 구현성으로 결함 허용 양자 컴퓨팅을 현실화하는 핵심 표준 부호다.
