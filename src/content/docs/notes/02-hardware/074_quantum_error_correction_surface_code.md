## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **양자 오류 정정(QEC, Quantum Error Correction)**: 데이터 상태를 직접 측정해 붕괴시키지 않고, 보조 큐비트와의 패리티(안정자) 측정으로 비트·위상 오류를 복원하는 기술.
- **표면 코드(Surface Code)**: 물리 큐비트들을 2차원 격자 평면에 배치하여 인접한 큐비트 간의 국소적 상호작용만으로 오류를 정정하는 대표적인 위상 양자 부호.

</details>

- 정의/개념: 논리 상태를 다수 물리 큐비트에 분산하고 패리티(안정자)만 반복 측정해 오류를 실시간 복원하는 **표면 코드(Surface Code)**
- 배경/필요성: 양자 복제 불가 정리 및 측정 시 상태 붕괴로 인해 **고전적인 단순 복사·비교 방식 오류 정정 불가**

#### 한줄 요약
- 양자 상태를 붕괴시키지 않고 보조 큐비트의 신드롬 측정을 통해 비트 반전(X) 및 위상 반전(Z) 오류를 정정한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **오류 임계치(Threshold)**: 물리 큐비트의 오류율이 이 기준값(약 1%) 이하일 때, 코드 거리($d$)를 늘릴수록 논리 오류율이 지수적으로 감소하는 한계선.
- **코드 거리(Code Distance, $d$)**: 하나의 논리 큐비트 오류를 유발하기 위해 필요한 최소 물리적 오류 개수(최대 $\lfloor(d-1)/2\rfloor$개 정정 가능).

</details>

- 2D 평면 격자에서 최근접(Nearest-Neighbor) 상호작용만으로 안정자 측정 구현
- 물리 오류율이 **오류 임계치(약 1%)** 이하일 때 **코드 거리($d$)** 확장에 따라 논리 오류 지수적 억제
- 비트 반전(X)과 위상 반전(Z)을 독립적으로 검출하는 데이터-보조 큐비트 2차원 교차 배치

#### 한줄 요약
- 높은 오류 임계치와 2D 평면 국소 연결성을 가져 초전도 QPU 등에서 가장 유력한 결함 허용(FTQC) 부호다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **데이터 큐비트(Data Qubit)**: 실제 양자 알고리즘 연산 데이터 상태를 분산 저장하는 물리 큐비트.
- **보조 큐비트(Ancilla Qubit)**: 데이터 큐비트와 얽힌 후 측정되어 X-타입(위상) 또는 Z-타입(비트) 에러 신드롬을 추출하는 측정 전용 큐비트.

</details>

```text
[표면 코드 2D 격자 패치 구조]
|-- 물리 큐비트 어레이 ($d \times d$ 패치)
|   |-- 데이터 큐비트 (Data Qubit - 양자 정보 분산 부호화)
|   |-- X 안정자 보조 큐비트 (Measure-X: 위상 반전 에러 감지)
|   `-- Z 안정자 보조 큐비트 (Measure-Z: 비트 반전 에러 감지)
|-- 신드롬 측정 회로 (인접 4개 데이터 큐비트와 CNOT 얽힘)
`-- 고전 실시간 제어 및 복호 계층
    |-- 고속 복호기 (MWPM / Union-Find 알고리즘)
    `-- 파울리 프레임 (Pauli Frame - 소프트웨어적 에러 추적)
```

선의 의미: 계층 및 양자-고전 연동 구조

| 구성요소 | 책임 |
|:---|:---|
| **데이터 큐비트** | 2D 평면 격자 상에서 단일 논리 큐비트의 양자 상태를 중복 분산 저장 |
| X 보조 큐비트 | 인접 데이터 큐비트들과의 CNOT 연산으로 위상 반전(Z) 에러 신드롬 측정 |
| Z 보조 큐비트 | 인접 데이터 큐비트들과의 CNOT 연산으로 비트 반전(X) 에러 신드롬 측정 |
| **고전 복호기** | 측정된 신드롬 결함 그래프를 바탕으로 가장 가능성 높은 에러 사슬 추론 |
| 파울리 프레임 | 물리적 반전 게이트 인가 대신 소프트웨어 테이블 갱신으로 실시간 에러 흡수 |

#### 한줄 요약
- 데이터 큐비트, X/Z 보조 큐비트, 고전 신드롬 복호기가 실시간으로 맞물려 양자 상태를 보호한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **MWPM(Minimum Weight Perfect Matching)**: 측정된 에러 신드롬 그래프에서 가장 확률이 높은 에러 발생 경로 쌍을 찾아내는 그래프 최적화 복호 알고리즘.

</details>

```text
논리 큐비트 부호화 및 양자 연산 진행
        │
   보조 큐비트를 인접 데이터 큐비트와 얽은 후 패리티 신드롬 측정
        │
   보조 큐비트 측정 결과에서 신드롬 반전(결함)이 발생했는가?
   ┌────┴─────┐
아니오          예
   │             │
정상 유지      시공간 결함 그래프(Defect Graph) 생성
다음 사이클       │
   │        고전 복호기(MWPM)가 최소 가중치 에러 사슬 매칭
   │             │
   │        발생한 물리 에러 개수가 정정 한계($\lfloor(d-1)/2\rfloor$) 이내인가?
   │        ┌────┴─────┐
   │      예            아니오
   │        │             │
   │   파울리 프레임     논리적 에러 발생 (Logical Error)
   │   소프트웨어 갱신     연산 실패
   └────┬───┴─────────────┘
        │
   다음 신드롬 측정 라운드 반복 (마이크로초 단위)
```

#### 한줄 요약
- 보조 큐비트 신드롬 측정 → 결함 그래프 생성 → MWPM 복호 → 파울리 프레임 보정 순으로 반복된다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **양자 오류 완화(Quantum Error Mitigation, QEM)**: 큐비트 추가 없이 통계적 잡음 외삽(ZNE) 등을 통해 기대값의 오차를 보정하는 NISQ 기법.

</details>

| 양자 오류 제어 기술 | 표면 코드 (Surface Code) | 양자 오류 완화 (QEM) | 고전 해밍/리드솔로몬 부호 | 쇼어 9-큐비트 코드 |
|:---|:---|:---|:---|:---|
| 적용 기준 | 결함 허용 대규모 양자 컴퓨터(FTQC) | 현재 NISQ 시대 얕은 양자 회로 | 고전 디지털 메모리 및 통신 네트워크 | 최초의 이론적 양자 오류 정정 개념 |
| 핵심 특징 | 2D 국소 안정자와 반복 신드롬 측정 | 추가 샷·잡음 모델로 기대값 편향 완화 | 중복·패리티로 비트·심볼 오류 정정 | 9개 물리 큐비트의 비트·위상 오류 부호화 |
| 한계 | 1개 논리 큐비트당 수천 개 물리 큐비트 소모 | 회로 깊이가 깊어지면 측정 횟수 지수적 폭증 | 양자 복제 불가 정리로 양자 시스템 적용 불가 | 인접 2D 평면 배선 불가능 및 낮은 임계치 |

#### 한줄 요약
- 단기적 얕은 회로에는 오류 완화(QEM)를, 장기 대규모 범용 양자 연산에는 표면 코드 기반 오류 정정(QEC)을 적용한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **복호 지연(Decoding Latency)**: 신드롬 측정 주기가 마이크로초 단위인데 고전 복호기 연산이 느리면 에러가 누적되어 전체 시스템이 지연되는 병목 현상.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 논리 큐비트 1개당 물리 큐비트 오버헤드($10^3\sim 10^4$) 극심 | 물리 게이트 오류율 개선($10^{-3} \to 10^{-4}$) 및 코드 거리 축소 | 필요 물리 큐비트 수 자릿수 절감 |
| **복호 지연**으로 인한 신드롬 데이터 백로그 누적 | FPGA/ASIC 기반 하드웨어 전용 복호기(Union-Find 가속) | $1\mu s$ 이내 실시간 스트리밍 복호 완수 |
| 보조 큐비트 자체의 측정 신뢰성 저하 | $d$ 라운드 시공간(3D) 반복 측정 및 신드롬 필터링 | 보조 큐비트 측정 오류와 데이터 큐비트 오류 완벽 분리 |
| 떨어진 논리 큐비트 간 게이트 연산 오버헤드 | 패치 경계를 병합/분할하는 격자 수술(Lattice Surgery) | 2D 평면 제약 내에서 범용 논리 게이트 구현 |

#### 한줄 요약
- 물리 에러율 개선, FPGA 복호 가속기 도입, 시공간 3D 반복 측정 및 격자 수술 기법으로 실용적 FTQC를 구현한다.

## Ⅶ. 결론

- 범용 결함 허용 양자 컴퓨터(FTQC) 실현을 위해 **표면 코드 기반 양자 오류 정정**을 필수 구축하고, **실시간 하드웨어 복호기**와 결합하여 논리 큐비트 신뢰성 달성

#### 한줄 요약
- 표면 코드는 높은 임계치와 2D 평면 구현성으로 결함 허용 양자 컴퓨팅을 현실화하는 핵심 표준 부호다.
