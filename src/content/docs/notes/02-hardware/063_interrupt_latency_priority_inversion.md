## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **인터럽트 요청(Interrupt Request, IRQ)**: 키보드나 센서 같은 외부 장치가 "급해 죽겠으니까 하던 거 멈추고 내 말 좀 들어!"라며 CPU의 멱살을 잡고 흔드는 비상벨 신호이다.
- **인터럽트 서비스 루틴(Interrupt Service Routine, ISR)**: 비상벨이 울리면 CPU가 모든 걸 내팽개치고 가장 먼저 튀어 나가 불을 끄는 0순위 특수부대 코드이다.
- **인터럽트 레이턴시(Interrupt Latency)**: 센서가 비상벨을 누른 시점부터, 특수부대(ISR)가 현장에 도착해 첫 총알을 쏘기까지 걸리는 답답한 물리적 준비 시간이다.
- **우선순위 역전(Priority Inversion)**: 별 볼 일 없는 하사관(저순위)이 화장실(메모리) 문을 잠그고 안 나오는 바람에, 급한 장군(고순위)이 밖에서 발을 동동 구르며 대기하는 기가 막힌 하극상이다.

</details>

- 정의: 센서의 **인터럽트 요청**(IRQ) 시작 지연과 메모리 잠금에 의한 **우선순위 역전**을 분리하여 뼛속까지 분석하는 실시간 지연 통제
- 배경: 인터럽트가 막히거나 하급자가 메모리를 물고 안 놔줄 때, 실시간 마감시간(Deadline) 위반 및 끔찍한 시스템 락업 참사가 유발되기 때문

#### 한줄 요약

- 실시간 시스템이 늦게 반응하는 원인은 크게 두 가지인데, 비상벨을 늦게 듣는 물리적 지연(인터럽트 레이턴시)과 엉뚱한 놈이 새치기하는 소프트웨어 지연(우선순위 역전)이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **인터럽트 마스킹(Interrupt Masking)**: CPU가 중요한 계산을 할 때 "나 지금 바쁘니까 비상벨 울려도 안 들을 거야!"라며 아예 귀를 닫아버리는 무식한 차단 구간이다.
- **중순위 선점(Medium-Priority Preemption)**: 하사관이 화장실에 있는데, 엉뚱한 중위(중순위)가 나타나 하사관을 걷어차고 볼일을 보느라 장군(고순위)의 대기 시간이 더 길어지는 미친 새치기 상황이다.

</details>

- 하드웨어가 "나 지금 바쁘니까 말 걸지 마!"라며 귀를 닫아버리는 **인터럽트 마스킹** 및 뇌 상태(Context) 저장 시간에 따른 물리적 지연을 유발함.
- 소프트웨어 자원 경합 시 엉뚱한 놈이 새치기하는 기가 막힌 **우선순위 역전** 및 **중순위 선점** 방지가 절대적으로 요구됨.
- 마감시간 안에 끝내기 위해, 두 개의 지연 구간을 쪼개서 최악 응답시간(WCRT) 상한을 무자비하게 수학적으로 산정함.

#### 한줄 요약

- CPU 귀 막는 시간(마스킹)과 엉뚱한 놈의 새치기(중순위 선점) 때문에 딜레이가 발생하므로, 이 두 시간을 철저히 분리해서 최악의 딜레이 한계선을 계산해야 한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **인터럽트 컨트롤러(Interrupt Controller)**: 여러 센서가 동시에 비명을 지를 때, 덜 중요한 비명은 씹고 제일 중요한 비명만 골라 CPU 멱살을 잡는 하드웨어 문지기이다.
- **예외 진입(Exception Entry)**: CPU가 비상벨을 듣고 하던 계산 결과(레지스터)를 서랍(스택)에 냅다 던져버리고 특수부대 위치로 달려가는 기계적 반사 신경이다.
- **임계 구역(Critical Section)**: 두 태스크가 동시에 건드리면 데이터가 박살 나는 살벌한 구역으로, 여기 들어갈 때는 무조건 뮤텍스(자물쇠)로 문을 걸어 잠가야 한다.

</details>

```text
[ 실시간 지연 원인 제공자 및 통제 프레임워크 ]
       (물리적 지연 원인)                     (소프트웨어 지연 원인)
[ 인터럽트 컨트롤러 (하드웨어 문지기) ]     [ 실시간 스케줄러 (재판관) ]
               │                                      │
               ▼                                      ▼
     [ 예외 진입 및 특수부대(ISR) ]         [ 임계 구역 및 뮤텍스 (자물쇠) ]
```

| 구성요소 | 책임 |
|:---|:---|
| **인터럽트 컨트롤러** | 센서 핀에 불이 들어오면 우선순위를 따져보고 CPU 멱살을 잡아채는 하드웨어 문지기 |
| **예외 진입** 및 ISR | 하던 일의 뇌 상태(레지스터)를 스택에 냅다 던져버리고 특수부대(ISR)를 투입하는 하드웨어 래칭 |
| 실시간 스케줄러 | 어떤 놈이 우선순위 새치기를 당하는지 째려보다가 권력을 휘둘러 순서를 바로잡는 재판관 |
| **임계 구역** 뮤텍스 락 | 두 놈이 동시에 건드리면 데이터가 박살 나는 **임계 구역**을 방어하기 위해 문을 걸어 잠그는 자물쇠 |

#### 한줄 요약

- 딜레이는 하드웨어가 문을 열고 특수부대(ISR)를 부르는 과정과, 커널 스케줄러가 자물쇠(뮤텍스)를 쥔 놈들을 통제하는 과정에서 각각 발생한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **인터럽트 벡터(Interrupt Vector)**: 비상벨이 울렸을 때, 불을 끄려면 몇 번지로 가고 도둑을 잡으려면 몇 번지로 가야 하는지 주소가 적혀있는 비상 연락망이다.
- **우선순위 상속(Priority Inheritance)**: 장군이 밖에서 기다리다 빡치면, 화장실 안의 하사관에게 임시 장군 계급장을 달아줘서 감히 중위(중순위)가 새치기 못 하게 막는 꼼수이다.

</details>

```text
[ 인터럽트 레이턴시 및 최악의 하극상(우선순위 역전) 해결 무자비한 흐름 ]

┌──────── 1. 물리적 지연: 인터럽트 레이턴시 ────────┐
│ [센서 비명] -> (귀 막는 시간) -> [CPU가 비명 인지]    │
│      │                                                  │
│      ▼ (하던 일 내팽개치고 뇌 덤프)                     │
│ [인터럽트 벡터 점프] -> [특수부대(ISR) 첫 총알 발사]    │
└─────────────────────────────────────────────────┘

┌──────── 2. 소프트웨어 지연: 우선순위 하극상 해결 ─┐
│ [장군이 화장실(자물쇠) 문 두드림]                       │
│      │                                                  │
│      ▼ (하사관이 문 잠그고 있음)                      │
│ [하사관에게 임시로 장군 계급장 줌 (우선순위 상속)]    │
│      │  (감히 중위 따위가 새치기 불가!)                 │
│      ▼ (하사관이 쫄아서 빛의 속도로 볼일 보고 나옴)   │
│ [장군이 화장실 차지하고 쾌변]                           │
└─────────────────────────────────────────────────┘
```

### 동작 원리

1. 1차 물리적 딜레이(인터럽트 마스킹): 외부 장치가 비명을 질러도 CPU가 귀를 막고 있으면 이 시간이 고스란히 딜레이로 쌓임.
2. 뇌 덤프 및 특수부대 투입: CPU가 하던 일을 스택에 냅다 던지고 **인터럽트 벡터**를 찾아 ISR 첫 줄을 실행할 때까지의 시간이 인터럽트 레이턴시임.
3. 락 소유자 식별(하극상 발생): 장군(고순위)이 메모리를 쓰려는데 하사관(저순위)이 문을 잠그고 안에서 뻗어버리는 기가 막힌 상황 식별.
4. 권력 남용(우선순위 상속): 장군이 빡쳐서 하사관에게 임시 장군 계급장(**우선순위 상속**)을 달아줘서 딴 놈들이 새치기 못 하게 막음.
5. 자원 뱉고 원상 복귀: 하사관이 놀라서 빨리 일을 끝내고 열쇠를 뱉으면, 장군이 즉시 메모리를 차지하고 연산을 찢어버림.

#### 한줄 요약

- CPU 귀 막는 시간을 지나 특수부대가 출동할 때까지가 레이턴시이고, 장군이 대기 탈 때 하사관에게 임시 계급장을 달아줘 새치기를 막는 게 상속이다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **최악 응답 시간(Worst-Case Response Time, WCRT)**: 억까란 억까는 다 당해서, 비상벨 소리도 늦게 듣고 새치기까지 당했을 때 나오는 최악의 지각 시간이다.

</details>

| 지연 경로 | 인터럽트 레이턴시 (하드웨어 레벨 지연) | 우선순위 역전 (소프트웨어 커널 레벨 지연) |
|:---|:---|:---|
| 관측 구간 | 외부 센서 비명 소리부터 특수부대(ISR)가 현장에 도착해 첫 총알을 쏘기 전까지의 물리적 준비 시간 | 장군(고순위)이 자물쇠를 못 열어 밖에서 오들오들 떨며 대기하는 굴욕적인 소프트웨어 지연 시간 |
| 지연 발생 원인 | CPU가 귀를 닫는 **인터럽트 마스킹** 구간 및 현재 뇌 상태를 서랍에 백업(Context Save)하느라 버리는 시간 | 하사관이 자물쇠를 쥐고 있는데 엉뚱한 중위(중순위)가 나타나 하사관을 걷어차고 새치기하는 환장할 방해 공작 |
| 해결 대책 | CPU가 귀 닫는 시간을 극도로 짧게 줄이고, 복잡한 일은 나중으로 냅다 미루는 지연 처리(Deferred Processing) 기법 적용 | 하사관에게 억지로 장군 계급장을 달아줘서 감히 중위가 새치기 못 하게 막아버리는 **우선순위 상속**(PI) 프로토콜 |

#### 한줄 요약

- 하드웨어 딜레이(레이턴시)는 마스킹 시간을 쥐어짜서 해결하고, 소프트웨어 딜레이(역전)는 억지 계급장 부여(우선순위 상속)로 해결한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **지연 처리(Deferred Processing)**: 불 끄러 간 특수부대(ISR)가 거기서 보고서까지 쓰면 다음 비상벨을 못 들으니, 깃발만 꽂아두고 보고서 작성은 일반 태스크로 넘기는 꼼수이다.
- **인터럽트 기아(IRQ Starvation)**: 센서 하나가 고장 나서 1초에 1만 번씩 쓸데없는 비상벨을 울리는 바람에, 진짜 중요한 에어백 센서가 씹혀버리는 대형 참사이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| CPU 귀를 너무 오래 닫아둬서(마스킹) 그사이 발생한 에어백 센서 비명을 놓치고 운전자가 뒈지는 대형 참사 | ISR에서는 깃발(플래그)만 꽂고 진짜 빡센 계산은 나중으로 냅다 미루는 **지연 처리**(Bottom-half) 적용 | 어떻게든 **인터럽트 레이턴시**를 극한으로 쥐어짜 줄여서 다음 센서를 절대 놓치지 않고 수용 |
| 메모리를 두고 엉뚱한 놈팽이(중순위)가 새치기하여 장군이 무한 대기 타는 **우선순위 역전** 셧다운 마비 | **우선순위 상속** 프로토콜(PIP) 커널 강제 적용으로 하사관을 미친 듯이 쪼아서 빨리 나가게 만듦 | 억울한 새치기(**중순위 선점**)에 의한 무한 대기 셧다운 사태를 원천 차단하고 통제권 회복 |
| 불필요한 센서가 1초에 수만 번씩 비명을 질러 정작 중요한 태스크가 굶어 죽는 **인터럽트 기아** | 타이머로 인터럽트 빈도에 족쇄(Throttling)를 채우거나, 단순 데이터는 CPU 대신 DMA 칩에 짬 때려버림 | 미친 듯이 튀는 CPU 부하율을 진정시키고 비명 소리에 묻혀 시스템이 마비되는 현상 선제 방어 |

#### 한줄 요약

- 특수부대는 불만 끄고 빠지며(지연 처리), 하극상은 계급장 상속으로 누르고, 쓸데없는 비상벨은 타이머로 족쇄를 채워야 시스템이 안 죽는다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **지연 완화(Latency Mitigation)**: 기계 탓(HW)이든 프로그램 탓(SW)이든 핑계 대지 말고, 데드라인을 맞추기 위해 모든 수단과 방법을 동원해 딜레이를 박살 내는 전략이다.

</details>

- **지연 완화** 원칙에 따라 IRQ 지연은 **ISR 최소화와 지연 처리 이관**으로, 잠금 차단 하극상은 **우선순위 상속** 적용으로 단호히 통제함

#### 한줄 요약

- 하드웨어 딜레이는 뇌 비우기(지연 처리)로 막고, 소프트웨어 딜레이는 계급장 빌려주기(우선순위 상속)로 막아 최악의 응답 시간을 사수해라.
