## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **인터럽트 요청(Interrupt Request, IRQ)**: 장치가 CPU에 비동기 처리를 요구하는 신호이다.
- **인터럽트 서비스 루틴(Interrupt Service Routine, ISR)**: 인터럽트 사건을 처리하는 루틴이다.
- **인터럽트 레이턴시(Interrupt Latency)**: IRQ 인가부터 ISR 첫 명령 시작까지의 지연이다.
- **우선순위 역전(Priority Inversion)**: 높은 우선순위 태스크가 낮은 우선순위 태스크가 보유한 잠금을 기다리는 현상이다.
- **실시간 지연 분석(Real-time Latency Analysis)**: 이벤트 처리 경로의 각 대기 원인과 최악 상한을 분리하여 계산하는 과정이다.

</details>

- 정의/개념: **IRQ** 발생부터 **ISR** 시작까지의 전달 지연과 고순위 태스크의 저순위 잠금 대기를 구분하는 **실시간 지연 분석**이다.
- 배경/필요성: 종단 응답시간만 측정하면 인터럽트 마스킹·상위 ISR과 공유 자원 잠금 중 직접 지연 원인을 판별하기 어렵다.

#### 한줄 요약

- 인터럽트 레이턴시는 IRQ부터 ISR 첫 명령까지, 우선순위 역전은 고순위 태스크의 잠금 대기 구간으로 분리해 분석한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **인터럽트 마스킹(Interrupt Masking)**: 프로세서가 특정 IRQ 처리를 일정 시간 억제하는 동작이다.
- **상위 ISR 중첩**: 더 높은 우선순위 인터럽트가 현재 ISR을 선점하는 현상이다.
- **중순위 선점(Medium-priority Preemption)**: 잠금을 가진 저순위 태스크가 중순위 태스크에 선점되어 고순위 태스크의 대기가 길어지는 현상이다.

</details>

- 인터럽트 시작 지연의 직접 원인은 **인터럽트 마스킹**과 **상위 ISR 중첩** 대기이다.
- 저순위 잠금 보유는 고순위 태스크의 실행을 차단한다.
- **중순위 선점**은 우선순위 역전 시간을 늘린다.

#### 한줄 요약

- 인터럽트 레이턴시는 마스킹·상위 ISR·예외 진입을, 우선순위 역전은 저순위 잠금 보유와 중순위 선점을 포함해 각각 상한을 측정한다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **인터럽트 컨트롤러(Interrupt Controller)**: 여러 장치의 인터럽트 요청(Interrupt Request, IRQ)을 보류하고 우선순위를 정해 프로세서에 전달하는 하드웨어이다.
- **예외 진입(Exception Entry)**: 현재 상태를 저장하고 인터럽트 벡터를 조회한 뒤 인터럽트 서비스 루틴(Interrupt Service Routine, ISR) 문맥으로 전환하는 절차이다.
- **뮤텍스(Mutex)**: 한 시점에 하나의 태스크만 공유 자원에 접근하도록 보장하는 잠금이다.
- **임계 구역(Critical Section)**: 공유 자원을 배타적으로 읽거나 변경하기 위해 잠금을 보유하는 코드 구간이다.

</details>

IRQ 전달 경로: **인터럽트 컨트롤러•예외 진입**, ISR 이후 배타 접근: **뮤텍스•임계 구역**

```text
[IRQ 제어기] -- [예외 진입•ISR] -- [스케줄러] -- [뮤텍스] -- [공유 자원]
```

선의 의미: 인터럽트 처리 영역과 태스크 스케줄링•잠금 영역이 맞닿은 정적 실시간 제어 구조다.

| 구성요소 | 책임 |
|:---|:---|
| IRQ 제어기 | 요청•우선순위 관리 |
| 예외 진입•ISR | 긴급 원인 처리 |
| 스케줄러 | 태스크 실행 결정 |
| 뮤텍스 | 배타 접근 관리 |
| 공유 자원 | 공통 상태 제공 |

#### 한줄 요약

- IRQ 제어기·예외 진입 경로와 스케줄러·뮤텍스 경로를 분리해 인터럽트 시작 지연과 태스크 잠금 차단 원인을 추적한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **인터럽트 벡터(Interrupt Vector)**: 인터럽트 요청(Interrupt Request, IRQ) 종류에 해당하는 인터럽트 서비스 루틴(Interrupt Service Routine, ISR) 시작 주소를 찾기 위한 식별자나 주소표 항목이다.
- **후속 태스크(Deferred Task)**: ISR에서 긴 처리를 넘겨받아 일반 태스크 문맥에서 실행하는 작업이다.
- **락 소유자(Lock Owner)**: 현재 뮤텍스를 획득하여 공유 자원의 임계 구역을 실행 중인 태스크이다.
- **우선순위 상속(Priority Inheritance)**: 락 소유자가 대기 중인 고순위 태스크의 우선순위를 임시로 받아 임계 구역을 빨리 끝내는 기법이다.
- **IRQ 우선순위 판정**: 마스크와 실행 우선순위로 처리할 인터럽트 벡터를 고르는 단계이다.
- **예외 진입·ISR 시작**: 현재 문맥을 저장하고 선택한 벡터의 ISR 첫 명령을 실행하는 단계이다.
- **락 소유자 식별**: 고순위 태스크가 기다리는 뮤텍스를 보유한 태스크를 찾는 단계이다.
- **우선순위 상속**: 락 소유자에게 대기 태스크의 높은 우선순위를 임시로 부여하는 단계이다.
- **공유 자원 반환**: 임계 구역 완료 뒤 잠금을 풀고 원래 우선순위로 복귀하는 단계이다.

</details>

IRQ는 벡터와 우선순위에 따라 ISR로 진입하고 긴 작업은 후속 태스크로 넘긴다.

```text
┌──────── 인터럽트 레이턴시 경로 ────────┐
│ [IRQ 발생]                              │
│      │                                  │
│      ▼ 1. IRQ 우선순위 판정             │
│ [IRQ 제어기]                            │
│      │                                  │
│      ▼ 2. 예외 진입•ISR 시작            │
│ [후속 태스크 이관]                      │
└─────────────────────────────────────────┘

┌──────── 우선순위 역전 완화 경로 ───────┐
│ [고순위 태스크의 잠금 요청]             │
│      │                                  │
│      ▼ 3. 락 소유자 식별                │
│ [저순위 태스크]                         │
│      │                                  │
│      ▼ 4. 우선순위 상속                 │
│ [임계 구역 실행]                        │
│      │                                  │
│      ▼ 5. 공유 자원 반환                │
│ [고순위 태스크 실행]                    │
└─────────────────────────────────────────┘
```

### 동작 원리

1. **IRQ 우선순위 판정**: 마스크 상태와 현재 실행 우선순위를 비교해 처리할 **인터럽트 벡터**와 선점 순서를 결정한다.
2. **예외 진입·ISR 시작**: 현재 문맥 저장과 벡터 조회를 마친 뒤 ISR 첫 명령을 실행한다.
3. **락 소유자 식별**: 고순위 태스크가 요청한 뮤텍스를 보유한 저순위 태스크를 확인한다.
4. **우선순위 상속**: 락 소유자에게 대기 태스크의 높은 우선순위를 임시 부여해 중순위 선점을 방지한다.
5. **공유 자원 반환**: 저순위 소유자가 임계 구역을 끝내고 잠금을 해제하면 원래 우선순위로 복귀하고 고순위 태스크를 실행한다.

#### 한줄 요약

- 마스킹·상위 ISR 시간을 줄이면 인터럽트 시작 지연이 감소하고, 우선순위 상속은 잠금 보유자의 중순위 선점을 막아 역전 시간을 제한한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **최악 응답시간(Worst-case Response Time)**: 이벤트나 작업 요청부터 모든 대기와 실행을 거쳐 완료까지 걸리는 최대 시간이다.

</details>

IRQ부터 ISR 시작까지의 경로와 잠금 대기 경로를 분리해 비교한다.
두 경로를 포함한 전체 대기•실행 상한: 이벤트 요청부터 처리 완료까지의 **최악 응답시간**

| 지연 경로 | 관측 구간 | 지연을 만드는 직접 원인 |
|:---|:---|:---|
| **인터럽트 레이턴시** | IRQ 발생부터 ISR 시작까지 | 마스킹•예외 진입•상위 ISR 실행 |
| **우선순위 역전** | 고순위 태스크의 잠금 대기 구간 | 저순위 소유자의 잠금과 중순위 선점 |

#### 한줄 요약

- IRQ 발생부터 ISR 시작까지는 인터럽트 레이턴시로, 고순위 태스크의 잠금 대기는 우선순위 역전으로 별도 측정한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **후속 처리 이관(Deferred-processing Offload)**: ISR의 긴 작업을 준비 큐의 태스크로 넘겨 인터럽트 실행 시간을 줄이는 방식이다.
- **인터럽트 요청 기아(Interrupt Request Starvation, IRQ 기아)**: 높은 우선순위 요청이 계속 발생하여 낮은 우선순위 IRQ가 장시간 처리되지 못하는 현상이다.
- **잠금 순서(Lock Ordering)**: 여러 잠금을 획득할 때 모든 태스크가 지키도록 정한 일관된 순서이다.
- **최대 보유시간(Maximum Hold Time)**: 태스크가 하나의 잠금을 획득한 뒤 해제할 때까지 허용되는 최장 시간이다.

</details>

IRQ 지연을 줄이려면 ISR을 짧게 유지하고 잠금 보유시간을 제한해야 한다.

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 긴 인터럽트 마스킹과 상위 ISR 실행으로 IRQ 시작 지연 증가 | 임계 구역을 줄이고 **후속 처리 이관** 적용 | 마스킹·중첩 점유 시간을 줄여 IRQ 지연 상한 단축 |
| 상위 IRQ가 계속 중첩되어 **IRQ 기아** 발생 | 중첩 깊이 제한과 장치별 인터럽트 병합·처리 예산 적용 | 상위 요청 점유를 제한해 하위 IRQ 처리 기회 확보 |
| 여러 잠금을 다른 순서로 획득해 교착·차단 시간 증가 | 모든 태스크의 **잠금 순서**와 **최대 보유시간** 지정 | 순환 대기를 제거하고 교착·차단 상한 통제 |
| 우선순위 상속 누락·복원 오류로 고순위 태스크 응답 지연 | 중·저·고 우선순위가 경합하는 상속·해제 시나리오 시험 | 실제 락 차단을 반영한 고순위 응답시간 상한 검증 |

#### 한줄 요약

- IRQ 전달 지연과 락 보유·차단 시간을 따로 측정하고 각각의 최악 상한을 WCRT 분석에 반영한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **인터럽트 요청 지연 상한(Interrupt Request Latency Bound, IRQ 지연 상한)**: 최악 조건에서 인터럽트 요청부터 인터럽트 서비스 루틴(Interrupt Service Routine, ISR) 시작까지 허용하는 최대 시간이다.
- **락 차단 상한(Lock-blocking Bound)**: 공유 자원 대기로 고순위 태스크가 차단될 수 있는 최대 시간이다.
- **데드라인(Deadline)**: 인터럽트 후속 처리와 태스크 결과를 반드시 완료해야 하는 시각이다.
- **지연 완화 선택 기준**: IRQ 지연 상한과 락 차단 상한 중 어느 경로가 데드라인을 위반하는지에 따라 완화책을 고르는 기준이다.

</details>

- **지연 완화 선택 기준**에 따라 **IRQ 지연 상한** 초과에는 마스킹·ISR 단축, **락 차단 상한** 초과에는 **우선순위 상속**을 적용해 **데드라인**을 지킨다.

#### 한줄 요약

- IRQ 전달과 자원 대기 경로별 상한 통제로 데드라인을 준수한다.
