## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **IRQ(Interrupt Request)**: 외부 장치가 프로세서에 비동기적 처리를 요청하는 신호
- **ISR(Interrupt Service Routine)**: IRQ 발생 시 커널이 최우선 구동하는 지연 최소화 루틴
- **인터럽트 레이턴시(Interrupt Latency)**: IRQ 인가 시점부터 ISR 최초 명령어 수행까지의 시간적 지연
- **우선순위 역전(Priority Inversion)**: 고순위 태스크가 저순위 태스크의 자원 잠금(Lock)으로 인해 대기하는 동안, 중순위 태스크가 코어를 점유하는 선점 현상

</details>

- 정의/개념: **IRQ** 시작 지연과 잠금에 의한 **우선순위 역전**을 분리 분석하는 실시간 지연 통제
- 배경/필요성: 인터럽트 마스킹 지연 및 락 공유에 따른 태스크 블로킹 발생 시 실시간 마감시간(Deadline) 위반 및 시스템 락업 유발

#### 한줄 요약

- 인터럽트 레이턴시는 IRQ부터 ISR 첫 명령까지, 우선순위 역전은 고순위 태스크의 잠금 대기 구간으로 분리해 분석한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **인터럽트 마스킹(Interrupt Masking)**: 임계 구역 진입 시 CPU의 IRQ 수용을 비활성화하는 구간
- **중순위 선점(Medium-Priority Preemption)**: 잠금을 보유한 저순위 태스크가 무관한 중순위 태스크에 의해 선점되어 고순위 태스크의 대기 시간이 증가하는 현상

</details>

- 하드웨어적 IRQ 억제 구간인 **인터럽트 마스킹** 및 Context Save 시간에 따른 지연
- 소프트웨어 자원 경합 시 발생하는 **우선순위 역전** 및 **중순위 선점** 방지 요구성
- 최악 응답시간(WCRT) 분석을 위한 개별 지연 구간의 수치화와 상한 산정

#### 한줄 요약

- 인터럽트 레이턴시는 마스킹·상위 ISR·예외 진입을, 우선순위 역전은 저순위 잠금 보유와 중순위 선점을 포함해 각각 상한을 측정한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **인터럽트 컨트롤러(Interrupt Controller/NVIC)**: 하드웨어 IRQ 핀 신호를 수집하여 우선순위를 마스킹/판정 후 CPU 코어로 전달하는 하드웨어.
- **예외 진입(Exception Entry)**: 코어가 현재 실행 상태 레지스터를 Stack에 Push하고 IVT 주소로 점프하는 하드웨어 래칭.
- **임계 구역(Critical Section)**: 공유 데이터 조작을 위해 **뮤텍스** 락을 점유하는 상호 배타 코드 블록.

</details>

```text
[IRQ 제어기] -- [예외 진입•ISR] -- [스케줄러] -- [뮤텍스] -- [공유 자원]
```

선의 의미: 하드웨어 인터럽트 수용 계층과 커널 스케줄러/뮤텍스 자원 동기화 계층 간의 연동 관계.

| 구성요소 | 책임 |
|:---|:---|
| IRQ 제어기 | 외부 **IRQ** 선점 처리, 마스킹 및 물리 인터럽트 디스패치 |
| 예외 진입•ISR | 레지스터 자동 Stack 덤프 및 핵심 **ISR** 하드웨어 서비스 |
| 스케줄러 | 태스크 Context Switch 및 **우선순위 상속** 프로토콜 집행 |
| 뮤텍스 | 배타 자원 보호 및 락 점유 태스크 관리 |

#### 한줄 요약

- IRQ 제어기·예외 진입 경로와 스케줄러·뮤텍스 경로를 분리해 인터럽트 시작 지연과 태스크 잠금 차단 원인을 추적한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **인터럽트 벡터(Interrupt Vector)**: 각 IRQ 번호별 ISR 시작 주소가 저장된 메모리 포인터 테이블.
- **우선순위 상속(Priority Inheritance)**: 락을 쥔 낮은 태스크의 우선순위를 대기 중인 높은 태스크의 레벨로 일시 상향하여 중순위 선점을 차단하는 기법.

</details>

```text
┌──────── 인터럽트 레이턴시 경로 ────────┐
│ [IRQ 발생]                              │
│      │                                  │
│      ▼ 1. IRQ 우선순위 판정             │
│ [IRQ 제어기]                            │
│      │                                  │
│      ▼ 2. 예외 진입•ISR 시작            │
│ [후속 태스크 이관]                      │
└─────────────────────────────────────────┘

┌──────── 우선순위 역전 완화 경로 ───────┐
│ [고순위 태스크의 잠금 요청]             │
│      │                                  │
│      ▼ 3. 락 소유자 식별                │
│ [저순위 태스크]                         │
│      │                                  │
│      ▼ 4. 우선순위 상속                 │
│ [임계 구역 실행]                        │
│      │                                  │
│      ▼ 5. 공유 자원 반환                │
│ [고순위 태스크 실행]                    │
└─────────────────────────────────────────┘
```

### 동작 원리

1. IRQ 우선순위 판정: 외부 장치 **IRQ** 인가 시 **인터럽트 컨트롤러**가 마스킹 여부 파악 후 우선순위 판정.
2. 예외 진입·ISR 시작: CPU 코어의 레지스터 **예외 진입** 덤프 및 **인터럽트 벡터** 점프 후 **ISR** 실행 (인터럽트 레이턴시 구간 완료).
3. 락 소유자 식별: 고순위 태스크가 뮤텍스 획득 시도 시 이미 락을 가진 저순위 태스크 식별.
4. 우선순위 상속: 저순위 태스크에 고순위 태스크의 우선순위를 즉각 할당하여 **중순위 선점** 차단.
5. 공유 자원 반환: 임계 구역 탈출 시 락 해제 및 원래 우선순위 복귀 후 고순위 태스크 코어 할당.

#### 한줄 요약

- 마스킹·상위 ISR 시간을 줄이면 인터럽트 시작 지연이 감소하고, 우선순위 상속은 잠금 보유자의 중순위 선점을 막아 역전 시간을 제한한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **WCRT(Worst-Case Response Time)**: 이벤트 발생 시점부터 시스템 전체 처리가 완결될 때까지의 총 시간.

</details>

| 지연 경로 | 인터럽트 레이턴시 (HW Layer) | 우선순위 역전 (SW/Kernel Layer) |
|:---|:---|:---|
| 관측 구간 | 외부 **IRQ** 발생부터 **ISR** 첫 명령 시작까지 | 고순위 태스크의 **뮤텍스** 잠금 대기 구간 |
| 지연 발생 원인 | **인터럽트 마스킹** 구간, Context Save, IVT 점프 | 저순위 태스크의 락 보유 및 **중순위 선점** 방해 |
| 해결 대책 | 마스킹 최단화, Deferred Processing, 하드웨어 덤프 | **우선순위 상속**(PI), Priority Ceiling(PCP) 프로토콜 |

#### 한줄 요약

- IRQ 발생부터 ISR 시작까지는 인터럽트 레이턴시로, 고순위 태스크의 잠금 대기는 우선순위 역전으로 별도 측정한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Deferred Processing**: ISR 내부에서는 최소 신호만 수용하고 본 연산 처리는 일반 태스크로 지연 전송하는 기술.
- **IRQ 기아(IRQ Starvation)**: 높은 우선순위 IRQ의 연속 발생으로 낮은 IRQ가 서비싱되지 못하는 현상.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 과도한 **인터럽트 마스킹**으로 인한 HW 지연 | **Deferred Processing**(Bottom-half) 적용 | **인터럽트 레이턴시** 최소화 |
| 뮤텍스 배타 제어 시 발생되는 **우선순위 역전** | **우선순위 상속** 프로토콜(PIP) 커널 적용 | **중순위 선점**에 의한 무한 대기 차단 |
| 고빈도 IRQ 유입에 따른 저순위 **IRQ 기아** | Interrupt Throttling 및 DMA 처리 이관 | CPU 부하율 안정화 |

> 사례: Mars Pathfinder 탐사선 사태 해결을 위한 **우선순위 상속** 패치 적용

#### 한줄 요약

- IRQ 전달 지연과 락 보유·차단 시간을 따로 측정하고 각각의 최악 상한을 WCRT 분석에 반영한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **지연 완화(Latency Mitigation)**: HW 반응 지연 및 SW 자원 차단 지연을 개별 측정하여 수립하는 실시간 대책 체계

</details>

- IRQ 지연은 **ISR 최소화·후속 처리 이관**, 잠금 차단은 **우선순위 상속** 적용

#### 한줄 요약

- IRQ 지연은 ISR 최소화, 잠금 차단은 우선순위 상속으로 제한한다.
