## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **캐시 매핑**: 주기억장치 블록을 캐시의 어느 라인에 배치하고 조회할 태그 범위를 정하는 규칙
- **캐시 라인**: 캐시와 하위 메모리 사이에서 한 번에 전송하고 관리하는 고정 크기 데이터 블록
- **태그 비교**: 주소의 태그와 후보 캐시 라인에 저장된 태그를 대조해 요청 블록의 존재 여부를 판정하는 동작

</details>

- 정의/개념: 캐시의 **블록 배치•탐색 범위** 규칙
- 배경/필요성: 전체 캐시 탐색은 **태그 비교 지연•면적** 증가

#### 한줄 요약

- 캐시 매핑은 인덱스로 후보 집합을 제한하고 태그로 요청 블록의 적중 여부를 판정한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **연관도**: 메모리 블록 하나가 배치될 수 있는 후보 캐시 라인의 수
- **AMAT**: Average Memory Access Time, 적중 시간과 미스 비용을 결합한 평균 접근 시간
- **충돌 미스**: 빈 라인이 있어도 지정 후보가 모두 차 있어 발생하는 캐시 미스
- **웨이**: 하나의 캐시 집합 안에서 블록이 배치될 수 있는 개별 캐시 라인 자리
- **적중 시간**: 캐시 적중 데이터를 반환하는 데 걸리는 시간
- **미스율**: 전체 메모리 접근 중 캐시 미스가 발생한 비율
- **미스 페널티**: 캐시 미스 한 번으로 추가되는 접근 지연

</details>

- 블록이 들어갈 **후보 웨이 수** 가 곧 연관도
- **적중 시간•미스율**•미스 페널티로 **AMAT** 결정
- 집합별 **충돌 집중도** 가 높을수록 커지는 연관도 증가 효과

$$
AMAT = Hit\ Time + Miss\ Rate \times Miss\ Penalty
$$

> 단일 캐시 단계의 평균 접근 시간 기본식

#### 한줄 요약

- 연관도를 높이면 충돌 미스는 줄지만 태그 비교 시간•면적•전력이 증가할 수 있다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **태그**: 요청 블록과 캐시 라인의 일치 여부를 판별하는 주소 필드
- **인덱스**: 요청 블록이 속한 캐시 집합을 선택하는 주소 필드
- **오프셋**: 캐시 라인 안에서 요청 바이트를 선택하는 주소 필드
- **유효 비트**: 캐시 라인에 의미 있는 데이터가 들어 있는지를 표시하는 상태 비트
- **교체 정책**: 후보 웨이가 모두 찼을 때 축출할 라인을 고르는 규칙
- **태그 탐색부**: 선택한 집합의 태그와 요청 태그를 비교해 일치 웨이를 찾는 회로
- **데이터 배열**: 캐시 라인의 실제 데이터 블록을 저장하고 선택된 웨이의 값을 반환하는 저장부
- **교체 제어부**: 미스 시 축출할 웨이를 정하고 리필 과정의 태그•상태 갱신을 관리하는 회로

</details>

```mermaid
block-beta
    columns 2
    A["주소 분해기"] --- T["태그 탐색부"] --- D["데이터 배열"]
    T --- R["교체 제어부"]
    R --- D
```

| 구성요소 | 책임 |
|:---|:---|
| 주소 분해기 | 주소의 **태그•인덱스•오프셋** 분리 |
| 태그 탐색부 | 집합과 **일치 웨이** 판정 |
| 데이터 배열 | 선택 웨이의 **요청 데이터** 반환 |
| 교체 제어부 | 미스 시 **축출•리필 상태** 갱신 |

#### 한줄 요약
- 주소 분해기가 후보를 정하고 태그 탐색부와 데이터 배열이 적중을 처리하며 교체 제어부가 미스를 채운다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **캐시 적중**: 요청 데이터가 캐시에 있어 즉시 반환할 수 있는 상태
- **캐시 미스**: 요청 데이터를 하위 계층에서 가져와야 하는 상태
- **축출**: 교체 대상으로 선택한 기존 캐시 라인을 내보내는 동작
- **리필**: 하위 계층에서 받은 블록을 캐시 라인에 채우는 동작
- **하위 메모리 계층**: 현재 캐시 미스 시 요청을 전달하는 다음 단계 캐시나 주기억장치
- **일치 웨이**: 요청 태그와 저장 태그가 일치한 캐시 라인

</details>

```mermaid
sequenceDiagram
    participant C as 프로세서 코어
    participant L as 주소•태그 탐색부
    participant D as 데이터 배열
    participant R as 교체 제어부
    participant M as 하위 메모리 계층

    C->>L: 주소 요청
    L->>L: 1. 인덱스•태그 탐색
    alt 캐시 적중
        L->>D: 2. 적중 데이터 선택
        D-->>C: 요청 데이터 반환
    else 캐시 미스
        L->>R: 3. 교체 웨이 선택
        R->>M: 4. 하위 블록 리필
        M-->>R: 캐시 라인 반환
        R->>L: 5. 태그•유효 비트 갱신
        R->>D: 선택 웨이에 블록 저장
        D-->>C: 요청 데이터 반환
    end
```

**동작 원리**

- **1. 인덱스•태그 탐색**: 매핑 위치와 저장 태그 비교
- **2. 적중 데이터 선택**: 일치 웨이에서 오프셋 데이터 선택
- **3. 교체 웨이 선택**: 미스 후보 상태로 축출 대상 결정
- **4. 하위 블록 리필**: 요청 블록을 하위 계층에서 조회
- **5. 태그•유효 비트 갱신**: 새 캐시 라인의 식별 정보 기록

#### 한줄 요약

- 인덱스가 집합을 고르고 태그가 웨이를 식별하며 오프셋이 라인 안의 요청 바이트를 선택한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **직접 매핑**: 각 메모리 블록을 하나의 캐시 라인에만 배치하는 방식
- **완전 연관 매핑**: 블록을 모든 라인에 배치할 수 있는 대신 전체 태그를 비교하는 방식
- **집합 연관 매핑**: 인덱스로 집합을 고른 뒤 그 안의 여러 웨이를 비교하는 절충 방식
- **적중 지연**: 주소를 해석하고 태그를 비교해 캐시 데이터를 반환하기까지 걸리는 시간
- **웨이 선택**: 집합 안에서 적중 라인이나 교체 라인을 결정하는 동작

</details>

| 캐시 매핑 방식 | 직접 매핑 | 완전 연관 매핑 | 집합 연관 매핑 |
|:---|:---|:---|:---|
| 적용 기준 | **적중 지연** 을 최소로 눌러야 할 때 | 라인 수가 적은 소형 캐시일 때 | 미스율과 지연을 함께 봐야 할 때 |
| 핵심 특징 | 인덱스가 지정한 **단일 라인** 배치 | 전체 라인이 **단일 집합**인 배치 | 지정 집합의 **여러 웨이** 배치 |
| 한계 | 빈자리가 있어도 나는 **충돌 미스** | 전체 **태그 비교** 의 면적•전력 폭증 | 웨이 선택•**교체 정책** 회로 부담 |

> 요약: 연관도 증가 시 **충돌 미스 감소•태그 비교 비용 증가**

#### 한줄 요약

- 집합 연관 매핑은 직접 매핑의 충돌과 완전 연관 매핑의 전체 태그 비교 비용을 절충한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **비차단 캐시**: 미스 처리를 기다리는 동안 다른 독립 요청을 계속 처리하는 구조
- **프리페치**: 곧 사용할 것으로 예상되는 블록을 요청 전에 미리 가져오는 기법
- **LRU 근사**: Least Recently Used 근사, 최소 최근 사용 라인을 낮은 비용으로 추정하는 방법
- **주소 배치**: 자주 함께 쓰는 데이터가 같은 캐시 집합에 몰리지 않도록 메모리 주소 위치를 조정하는 방법
- **병렬 태그 비교**: 한 집합의 여러 웨이 태그를 동시에 대조해 적중 웨이를 찾는 방식
- **L2 캐시**: Level 2 Cache, 1차 캐시 미스를 흡수하는 2차 캐시 계층
- **랜덤 교체 정책**: 미스 시 후보 웨이 가운데 하나를 무작위로 골라 축출하는 단순 정책
- **MCU**: Microcontroller Unit, 프로세서•메모리•주변장치 통합 제어 장치

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 특정 주소의 **충돌 미스 반복** | **연관도 확대•주소 배치** 조정 | **동일 집합 집중** 완화 |
| 연관도 증가 후 **지연•전력 상승** | **웨이 수•병렬 태그 비교** 조정 | 목표 **AMAT** 내 전력 증가 제한 |
| **미스 페널티** 가 지연 지배 | **L2 캐시•프리페치** 와 **비차단 캐시** | **미스 대기** 완화 |
| 작업 집합의 **반복 축출** | **LRU 근사•랜덤 정책** 비교 | **불필요한 축출** 감소 |
| 소형 **MCU 면적•지연** 제약 | **직접 매핑** 적용 가능성 검증 | **단순 회로•짧은 적중 시간** |

#### 한줄 요약

- 적중 시간•미스율•미스 페널티를 합친 AMAT와 전력을 함께 비교해야 한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **태그 비교 비용**: 후보 라인의 태그를 병렬 확인하는 데 드는 면적•전력•시간

</details>

- 최소 지연은 **직접**, 소형은 **완전 연관**, 절충은 집합 연관 선택

#### 한줄 요약

- 연관도는 충돌 미스 감소 효과가 태그 비교 시간•전력 비용보다 큰 범위에서 선택한다.
