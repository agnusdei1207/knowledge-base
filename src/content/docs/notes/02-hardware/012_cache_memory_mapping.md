## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **캐시 매핑(Cache Mapping)**: 메인 메모리(DRAM)의 블록을 고속 캐시 메모리(SRAM)의 특정 라인 위치에 배치하고 태그 비교를 통해 적중 여부를 판정하는 주소 사상(address mapping) 기법으로, 메모리 계층 간 블록 위치 규칙을 정의하는 하드웨어 설계 기준.
- **메모리 벽(Memory Wall)**: CPU 연산 속도 대비 메모리 접근 속도의 상대적 지연 격차가 프로세서 성능 활용을 제한하는 구조적 병목으로, 캐시 계층 도입의 핵심 배경.
- **태그 비교(Tag Comparison)**: CPU 요청 주소의 태그 필드와 캐시 집합 내 W개 Way의 태그를 병렬 대조하여 일치 Way 존재 시 Cache Hit, 부재 시 Cache Miss를 판정하는 하드웨어 탐색 동작.
- **충돌 미스(Conflict Miss)**: 서로 다른 메인 메모리 블록이 동일한 캐시 집합(Set)으로 매핑되어 기존 라인을 Eviction하고 새 블록이 적재될 때 발생하는 캐시 미스로, 연관도(Associativity) 부족 또는 핫 데이터 쏠림 시 발생하는 성능 저하 원인.

</details>

- 정의/개념: **캐시 매핑** — DRAM 블록을 SRAM 라인에 배치하고 태그 비교로 적중 여부를 판정하는 주소 사상 기법
- 배경/필요성: CPU-메모리 속도 격차(**메모리 벽**) 완화 및 동일 인덱스 쏠림에 의한 **충돌 미스** 최소화

#### 한줄 요약

- 인덱스 기반 캐시 집합(Set) 선택 및 태그 비교(Tag Match) 기반 적중 판정 사상 체계.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **연관도(Associativity)**: 하나의 집합(Set) 안에서 메모리 블록이 선택할 수 있는 캐시 Way의 수로, 집합 연관 매핑의 W 값에 해당하며 직접 매핑(W=1)부터 완전 연관 매핑(집합 1개·Way=전체 라인 수)까지 확장되는 배치 유연성 지표.
- **AMAT(Average Memory Access Time)**: 적중 시간(Hit Time)과 미스율(Miss Rate) × 미스 페널티(Miss Penalty)의 합으로 산출되는 메모리 계층 전체의 평균 참조 지연시간으로, 캐시 계층 설계 시 트레이드오프 평가의 핵심 지표.

</details>

- **연관도** 증가 시 지정 집합 내 분산 배치로 **충돌 미스** 대폭 감소
- 연관도 상향 시 태그 비교기 증가로 **적중 시간** 트레이드오프 발생
- 적중 시간·미스율·미스 페널티로 전체 **AMAT** 산출

$$
AMAT = T_{hit} + (Miss\ Rate \times Miss\ Penalty)
$$

#### 한줄 요약

- 연관도 상향 기반 충돌 미스 억제 및 AMAT 수식 기준 최적화.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **태그(Tag)**: 메모리 주소의 상위 비트 영역으로, 캐시 라인에 적재된 데이터 블록의 출처 메인 메모리 주소 일부를 보관하여 태그 비교 시 동일 블록 여부를 판별하는 식별 비트 집합.
- **인덱스(Index)**: 메모리 주소의 중간 비트 영역으로, 캐시 메모리 내에서 어떤 집합(Set)에 접근할지 선택하기 위해 집합 디코더에 전달되는 주소 비트 집합.
- **오프셋(Offset)**: 메모리 주소의 하위 비트 영역으로, 64바이트 캐시 라인 내부에서 요청된 바이트 단위 데이터를 정확히 추출하기 위해 데이터 배열 멀티플렉서로 전달되는 주소 비트.

</details>

```text
[캐시 매핑 구조 예시: 32비트 주소·64바이트 라인·64개 집합]
 ├─ 주소 분해기
 │  ├─ Tag (20비트)
 │  ├─ Set Index (6비트)
 │  └─ Block Offset (6비트)
 ├─ 집합 선택기
 ├─ 태그·유효 비트 배열 (W개 Way)
 ├─ 데이터 배열 (W개 Way)
 └─ 교체 제어부 (집합 연관의 교체 메타데이터)
```

선의 의미: 주소 분해기와 캐시 배열·교체 제어부의 정적 포함 관계. 주소 비트 예시는 설명을 위한 조건이며, 실제 비트 수는 캐시 용량·라인 크기·집합 수에 따라 달라짐.

| 구성요소 | 책임 |
|:---|:---|
| 주소 분해기 | CPU 주소를 **태그**·인덱스·오프셋 비트로 분해 |
| 집합 선택기 | 인덱스로 접근할 **캐시 집합** 선택 |
| 태그·유효 비트 배열 | 선택 집합의 Way별 **캐시 적중** 여부 판정 |
| 데이터 배열 | 적중 Way의 **오프셋** 위치 데이터 반환 |
| 교체 제어부 | 집합 연관에서 교체 Way 선택, 직접 매핑은 고정 라인 사용 |

#### 한줄 요약

- 태그(일치 검증)·인덱스(집합 선택)·오프셋(데이터 추출)의 3단 주소 분해 구조 적용.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **리필(Refill)**: 캐시 미스 발생 시 DRAM 메인 메모리에서 해당 64바이트 블록을 인출하여 캐시 집합 내 LRU 정책으로 선정된 희생 Way에 적재하는 회전 동작으로, Miss Penalty의 핵심 구간.
- **LRU(Least Recently Used)**: 집합 내에서 가장 오래 사용되지 않은 Way를 희생 라인으로 선택하는 교체 정책.

</details>

```text
 CPU Memory Request
        │
        ▼
┌──────────────────────────────────┐
│ Index 비트로 캐시 집합(Set) 디코딩│
└──────────────┬───────────────────┘
               ▼
┌──────────────────────────────────┐
│ W-Way 병렬 태그(Tag) 비교        │
└──────┬───────────────┬───────────┘
 [Hit] │               │ [Miss]
       ▼               ▼
┌────────────┐ ┌───────────────────┐
│ Offset 참조│ │ 교체 Way 선택     │
│ Data 반환  │ │ 축출 및 DRAM Refill│
└────────────┘ └───────────────────┘
```

**동작 원리**

1. **집합 인덱싱**: 주소의 **인덱스** 비트를 디코딩하여 특정 캐시 집합(Set) 선택
2. **태그 비교**: 선택된 집합 내 모든 Way의 **유효 비트**와 **태그**를 병렬로 비교
3. **적중 처리**: 일치하는 태그 존재 시(**캐시 적중**) 데이터 배열에서 **오프셋** 위치의 데이터를 즉시 반환
4. **미스 처리**: 일치 태그 부재 시(**캐시 미스**) 직접 매핑은 고정 라인을, 집합 연관은 **LRU** 등 교체 정책으로 희생 Way를 정해 새 블록 리필

#### 한줄 요약

- 인덱스 기반 집합 선택 후 W-Way 태그 비교 및 매핑별 교체 처리.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **직접 매핑(Direct-Mapped Cache)**: 메인 메모리 블록이 인덱스에 의해 캐시의 단 하나의 라인에만 고정 배치되는 방식으로, 태그 비교기가 1개여서 하드웨어가 단순하나 동일 인덱스 충돌 시 Thrashing 발생.
- **완전 연관 매핑(Fully-Associative Cache)**: 인덱스 비트 없이 메모리 블록을 캐시 내 임의의 빈 슬롯에 자유 배치하는 방식으로, 충돌 미스가 없는 대신 전체 태그 병렬 비교로 비교기 회로 면적·전력 과다 소모.
- **집합 연관 매핑(Set-Associative Cache)**: 캐시를 S개의 Set으로 나누고 각 Set에 W개의 Way를 두어, 인덱스로 Set을 고른 뒤 W개 후보를 병렬 비교하는 방식.

</details>

| 매핑 방식 | 직접 매핑 (Direct Mapped) | 완전 연관 매핑 (Fully Associative) | 집합 연관 매핑 (Set-Associative) |
|:---|:---|:---|:---|
| 적용 기준 | 초고속 L1 명령어 캐시, 저비용 마이크로컨트롤러 | 소규모 엔트리 고속 변환 버퍼 (TLB, Branch Target) | 현대 고성능 프로세서 L1/L2/L3 캐시 표준 규격 |
| 핵심 특징 | 1개 Index당 1개 Line 고정 배치, 단일 태그 비교 | Index 없이 임의 슬롯 적재, 전체 태그 병렬 비교 | 전체 캐시를 Set으로 나누고 Set 내 W-Way 병렬 비교 |
| 한계 | 동일 Index 쏠림 시 심각한 충돌 미스(Thrashing) 발생 | 비교기 회로 면적 과다 소모, 전력 및 탐색 지연 증가 | 연관도(W) 증가에 따른 적중 시간(Hit Time) 미세 증가 |

#### 한줄 요약

- 직접 매핑 속도와 완전 연관 매핑 유연성 절충 기반 W-Way 집합 연관 매핑 선택.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **비차단 캐시(Non-Blocking Cache)**: 이전 미스에 의한 메모리 리필이 백그라운드에서 진행되는 동안에도 후속 캐시 적중 요청을 중단(stall) 없이 계속 처리하는 Miss Status Handling Register(MSHR) 기반의 비순차 메모리 응답 구조로, 캐시 스루풋과 파이프라인 활용률을 동시에 향상시키는 구조.
- **Pseudo-LRU**: 정확한 LRU보다 적은 상태 비트로 최근 사용 순서를 근사하여 집합 연관 캐시의 교체 Way를 선택하는 정책.
- **Way 예측기(Way Predictor)**: 직전 접근 등의 정보를 이용해 적중 가능성이 높은 Way를 먼저 선택하여 태그 비교와 데이터 선택 비용을 줄이는 회로.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 특정 집합 쏠림에 따른 **충돌 미스** | **집합 연관 매핑** 확장•주소 배치 최적화 | 집합별 충돌 미스 감소 |
| 높은 연관도로 비교·교체 비용 증가 | **Way 예측기**로 비교 수를 줄이고 **Pseudo-LRU**로 교체 메타데이터 단순화 | 적중 경로 전력 및 교체 제어 비용 절감 |
| 미스 발생 시 파이프라인 정지 | **비차단 캐시**•하드웨어 **프리페치** | 메모리 접근 지연 은닉 |

#### 한줄 요약

- 집합 연관도 확장·Pseudo-LRU·비차단 캐시·하드웨어 프리페치 기반 AMAT 단축.

## Ⅶ. 결론

- 계층별 AMAT 분석 기반 **L1의 낮은 연관도와 하위 캐시의 높은 연관도 사이 설계**

#### 한줄 요약

- 적중 시간과 미스율의 AMAT 트레이드오프에 맞춘 계층별 캐시 연관도 결정.
