## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **캐시 매핑(Cache Mapping)**: 메인 메모리(DRAM)의 블록을 고속 캐시 메모리(SRAM)의 특정 라인 위치에 배치하고 적중 여부를 판단하는 주소 변환 체계이다.
- **태그 비교(Tag Comparison)**: CPU가 요청한 메모 주소의 Tag 필드와 캐시 라인 태그를 비교기로 대조하여 Cache Hit/Miss를 판정하는 동작이다.
- **충돌 미스(Conflict Miss)**: 서로 다른 메모리 블록이 동일한 캐시 집합(Index)으로 동시에 매핑되어 기존 유효 라인을 축출하며 발생하는 미스이다.

</details>

- 정의/개념: 메인 메모리(DRAM) 블록을 고속 캐시 메모리(SRAM)의 특정 라인 위치에 배치하고 태그 비교를 통해 적중(Hit) 여부를 판정하는 주소 사상 기법
- 배경/필요성: 프로세서와 메모리 간 속도 격차인 **메모리 벽(Memory Wall) 완화 및 동일 인덱스 쏠림에 의한 충돌 미스(Conflict Miss) 최소화**

#### 한줄 요약

- 인덱스로 캐시 집합(Set)을 선택하고 **태그 비교(Tag Match)**로 적중을 판정하는 사상 체계이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **연관도(Associativity)**: 하나의 메인 메모리 블록이 적재될 수 있는 후보 캐시 라인(Set 내의 Way)의 개수이다.
- **AMAT(Average Memory Access Time)**: 적중 시간과 미스율, 미스 페널티의 곱으로 계산되는 전체 메모리 참조 평균 지연시간이다.

</details>

- **연관도** 증가 시 지정 집합 내 분산 배치로 **충돌 미스** 대폭 감소
- 연관도 상향 시 태그 비교기 증가로 **적중 시간** 트레이드오프 발생
- **적중 시간**•**미스율**•**미스 페널티**로 전체 **AMAT** 산출

$$
AMAT = T_{hit} + (Miss\ Rate \times Miss\ Penalty)
$$

#### 한줄 요약

- **연관도 상향**으로 충돌 미스를 억제하며, **AMAT 수식** 기준으로 최적화한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **태그(Tag)**: 메모리 주소 상위 비트로, 캐시 라인 데이터가 어떤 메인 메모리 블록에서 온 것인지 검증하는 식별자이다.
- **인덱스(Index)**: 메모리 주소 중간 비트로, 접근할 캐시 집합(Set) 번호를 선택하는 인덱스 비트이다.
- **오프셋(Offset)**: 메모리 주소 하위 비트로, 64바이트 캐시 라인 내부에서 특정 바이트 위치를 지시하는 포인터이다.

</details>

```text
+--------------------------------------------------------------+
|              Physical Memory Address                         |
| +------------------+----------------+------------------+     |
| |  Tag (20-bit)    | Index (6-bit)  |  Offset (6-bit)  |     |
| +------------------+----------------+------------------+     |
+--------------------------------------------------------------+
          │                  │                  │
          │     +------------+------------+     │
          │     | Set Decoder              |     │
          │     +---+----+----+----+------+     │
          │         │    │    │    │             │
          │     +---+----+----+----+------+     │
          │     | N-Way Tag Comparators   |     │
          │     +------------------------+     │
          │                                    │
          │     +------------------------+     │
          │     | Data Array MUX         |-----+
          │     +------------------------+
          │
+-------------------+
| Valid Bit Storage |
+-------------------+
```

선의 의미: 물리 주소의 태그, 인덱스, 오프셋 분해와 N-Way 태그 비교기 및 데이터 배열 MUX의 동작 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 주소 분해기 | CPU 주소를 **태그**•인덱스•오프셋 비트로 파싱 |
| 태그 탐색부 | N-Way 병렬 비교기로 **캐시 적중** 여부 판정 |
| 데이터 배열 | 적중한 Way의 **오프셋** 위치 데이터 반환 |
| 교체 제어부 | 집합 포화 시 **LRU** 기반 기존 라인 축출 |

#### 한줄 요약

- **태그(일치 검증)·인덱스(집합 선택)·오프셋(데이터 추출)**의 3단 주소 분해를 거친다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **리필(Refill)**: 캐시 미스 발생 시 DRAM 메인 메모리에서 64바이트 블록을 인출하여 캐시 라인에 적재하는 동작이다.

</details>

```text
 CPU Memory Request
        │
        ▼
┌──────────────────────────────────┐
│ Index 비트로 캐시 집합(Set) 디코딩│
└──────────────┬───────────────────┘
               ▼
┌──────────────────────────────────┐
│ N-Way 병렬 태그(Tag) 비교        │
└──────┬───────────────┬───────────┘
 [Hit] │               │ [Miss]
       ▼               ▼
┌────────────┐ ┌───────────────────┐
│ Offset 참조│ │ LRU 희생 라인     │
│ Data 반환  │ │ 축출 및 DRAM Refill│
└────────────┘ └───────────────────┘
```

**동작 원리**

1. **집합 인덱싱**: 주소의 **인덱스** 비트를 디코딩하여 특정 캐시 집합(Set) 선택
2. **태그 비교**: 선택된 집합 내 모든 Way의 **유효 비트**와 **태그**를 병렬로 비교
3. **적중 처리**: 일치하는 태그 존재 시(**캐시 적중**) 데이터 배열에서 **오프셋** 위치의 데이터를 즉시 반환
4. **미스 처리**: 일치 태그 부재 시(**캐시 미스**) **LRU** 정책으로 기존 라인을 축출하고 메인 메모리에서 새 블록 리필

#### 한줄 요약

- 인덱스로 집합 선택 후 **N-Way 병렬 태그 비교를 통한 즉시 반환 및 LRU 축출**을 수행한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **직접 vs 완전 연관 vs 집합 연관**:
  - 직접 매핑: 1 Index당 1 Way로 고정한다.
  - 완전 연관 매핑: Index 없이 임의로 배치한다 (N Way).
  - 집합 연관 매핑: Set 단위로 N Way 분할 배치한다.

</details>

| 매핑 방식 | 직접 매핑 (Direct Mapped) | 완전 연관 매핑 (Fully Associative) | 집합 연관 매핑 (Set-Associative) |
|:---|:---|:---|:---|
| 적용 기준 | 초고속 L1 명령어 캐시, 저비용 마이크로컨트롤러 | 소규모 엔트리 고속 변환 버퍼 (TLB, Branch Target) | 현대 고성능 프로세서 L1/L2/L3 캐시 표준 규격 |
| 핵심 특징 | 1개 Index당 1개 Line 고정 배치, 단일 태그 비교 | Index 없이 임의 슬롯 적재, 전체 태그 병렬 비교 | 전체 캐시를 Set으로 나누고 Set 내 N-Way 병렬 비교 |
| 한계 및 위험 | 동일 Index 쏠림 시 심각한 충돌 미스(Thrashing) 발생 | 비교기 회로 면적 과다 소모, 전력 및 탐색 지연 증가 | 연관도(N) 증가에 따른 적중 시간(Hit Time) 미세 증가 |

#### 한줄 요약

- 직접 매핑의 속도와 완전 연관 매핑의 유연성을 절충한 **N-Way 집합 연관 매핑을 표준으로 채택한다.**

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **비차단 캐시(Non-Blocking Cache)**: 이전 미스에 대한 메모리 리필이 진행되는 동안에도 후속 적중 요청을 중단 없이 계속 처리하는 MSHR 기반 구조이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 특정 집합 쏠림에 따른 **충돌 미스** | **집합 연관 매핑** 확장•주소 배치 최적화 | 메모리 블록 쏠림 완화 |
| 연관도 증가로 태그 탐색 전력 폭증 | **Pseudo-LRU**•**Way 예측기** 도입 | 탐색 지연 및 전력 감소 |
| 미스 발생 시 파이프라인 정지 | **비차단 캐시**•하드웨어 **프리페치** | 메모리 접근 지연 은닉 |

#### 한줄 요약

- **집합 연관도 확장·Pseudo-LRU·비차단 캐시·하드웨어 프리페치**로 AMAT를 단축한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **계층별 최적화 전략**: L1은 빠른 Hit Time(저연관도), L2/L3는 Miss Rate 최소화(고연관도)를 적용하는 다계층 캐시 설계 원칙이다.

</details>

- 계층별 AMAT 분석 기반 **L1 캐시의 저연관도 고속화 및 L2/L3 캐시의 고연관도 충돌 억제 설계**

#### 한줄 요약

- **적중 시간과 미스율의 AMAT 트레이드오프**에 맞춰 계층별 캐시 연관도를 결정한다.
