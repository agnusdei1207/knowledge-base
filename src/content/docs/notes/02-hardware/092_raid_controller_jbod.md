## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **독립 디스크 중복 배열(Redundant Array of Independent Disks, RAID)**: 여러 디스크에 데이터를 분산•중복하여 장애를 견디는 저장 기술이다.
- **RAID 컨트롤러**: RAID 구성과 캐시를 관리하여 하나의 논리 볼륨으로 제공하는 장치이다.
- **디스크 묶음(Just a Bunch of Disks, JBOD)**: 하드웨어 RAID 없이 개별 디스크를 상위 소프트웨어에 직접 노출하는 방식이다.
- **입출력(Input/Output, I/O)**: 호스트와 저장장치 사이에서 데이터를 읽거나 쓰는 작업이다.

</details>

- 정의/개념: RAID 컨트롤러는 여러 디스크를 중복된 논리 볼륨으로 제공하고, JBOD는 각 디스크를 상위 소프트웨어가 직접 관리하도록 개별 장치로 제공한다.
- 배경/필요성: 컨트롤러 RAID와 분산 스토리지가 동시에 중복도를 관리하면 용량과 쓰기 비용이 낭비되고 장애•복구 책임도 불분명해진다.

#### 한줄 요약

- **보호•복구 책임 계층**에 따른 RAID 또는 JBOD을 선택한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **전원 보호 쓰기 캐시**: 정전이 발생해도 디스크에 반영되지 않은 쓰기 데이터를 보존하는 캐시이다.
- **라이트백**: 데이터를 보호 캐시에 기록한 뒤 완료를 알리고 디스크에는 나중에 반영하는 방식이다.
- **패스스루**: 디스크 명령과 상태를 상위 계층에 그대로 전달하는 방식이다.
- **소프트웨어 정의 스토리지(Software-Defined Storage, SDS)**: 범용 서버 소프트웨어가 데이터 배치•복제•복구 정책을 담당하는 구조이다.

</details>

- **보호 캐시**를 통한 라이트백 응답 지연 단축이 핵심이다.
- **단일 컨트롤러 장애**에 따른 배열 전체 중단 위험이 핵심이다.
- **JBOD 상태 노출**을 활용한 SDS 배치•격리를 결정한다.

#### 한줄 요약

- **보호 캐시•컨트롤러 장애**와 JBOD 상태 노출 사이에는 상충 관계가 있다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **호스트(Host)**: 논리 볼륨 또는 개별 디스크에 블록 I/O를 발행하는 구성이다.
- **보호 쓰기 캐시(Protected Write Cache)**: 정전 중 미반영 쓰기를 보존하고 안전한 라이트백을 제공하는 구성이다.
- **RAID 엔진(RAID Engine)**: 스트라이핑•미러링•패리티와 재구성을 관리하는 구성이다.
- **패스스루 컨트롤러(Pass-through Controller)**: 개별 디스크와 상태를 상위 소프트웨어에 노출하는 구성이다.
- **물리 디스크(Physical Disk)**: 블록 데이터와 장치 건강 상태를 제공하는 구성이다.

</details>

```text
                 [호스트]
                /       \
     [보호 쓰기 캐시]   [패스스루 컨트롤러]
              |               |
         [RAID 엔진]           |
                \             /
                 [물리 디스크]
```

선의 의미: 위 가지는 보호 캐시와 RAID 엔진을 포함한 논리 볼륨 경계이고, 아래 가지는 호스트와 물리 디스크를 직접 잇는 패스스루 경계를 뜻한다.

| 구성요소 | 책임 |
|:---|:---|
| 호스트 | **논리•개별 I/O 요청** |
| 보호 쓰기 캐시 | **안전한 라이트백 제공** |
| RAID 엔진 | **스트라이핑•패리티 관리** |
| 패스스루 컨트롤러 | **개별 디스크 노출** |
| 물리 디스크 | **블록•상태 제공** |

#### 한줄 요약

- **RAID 보호 경로•JBOD 패스스루 경로**의 책임을 분리한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **RAID 재구성**: 생존 데이터와 패리티를 읽어 교체 디스크에 손실된 내용을 복원하는 과정이다.
- **재복제**: 생존 사본을 다른 디스크나 노드에 복사해 목표 중복도를 회복하는 과정이다.

</details>

```text
[호스트 블록 쓰기]
        │
        ▼
1. 보호•복구 책임 판정
   ┌────┴──────────────┐
   │ RAID 컨트롤러     │ JBOD•SDS
   ▼                   ▼
2. 보호 캐시 기록   4. 개별 디스크 매핑
   │                   │
   ▼                   ▼
3. 데이터•패리티 배치 5. 소프트웨어 사본 배치
   │                   │
   └─────────┬─────────┘
             ▼
      [쓰기 완료 반환]
```

**동작 원리**

1. **보호•복구 책임 판정**: 중복도와 장애 복구를 RAID 컨트롤러 또는 SDS 중 어느 한 계층이 담당할지 정한다.
2. **보호 캐시 기록**: RAID 경로에서는 전원 장애에도 보존되는 캐시에 쓰기를 기록한 경우에만 호스트에 조기 완료를 반환한다.
3. **데이터•패리티 배치**: RAID 컨트롤러가 선택한 레벨에 따라 데이터와 미러 또는 패리티를 구성 디스크에 기록한다.
4. **개별 디스크 매핑**: JBOD 경로에서는 각 패스스루 디스크의 고유 식별자와 실제 건강 상태를 SDS에 노출한다.
5. **소프트웨어 사본 배치**: SDS가 장애 영역 정책에 따라 서로 다른 디스크나 노드에 사본 또는 코딩 조각을 배치한다.

#### 한줄 요약

- RAID 경로는 컨트롤러의 **보호 캐시•중복 배치**, JBOD 경로는 SDS의 디스크 식별•사본 배치를 사용한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **논리 볼륨**: 여러 물리 디스크의 용량을 묶어 호스트에 하나의 블록 장치로 제공하는 공간이다.

</details>

| 저장 구성 | RAID 컨트롤러 | JBOD 패스스루 |
|:---|:---|:---|
| 적용 기준 | **단일 서버 내부 볼륨** 보호 | **분산 스토리지 사본** 관리 |
| 핵심 특징 | **논리 볼륨 중복•재구성** 관리 | 개별 디스크를 **SDS에 노출** |
| 한계 | **컨트롤러 장애•재구성 부하** | **복제 정책 오류•상태 관리** |

> 요약: 단일 서버 보호는 **RAID**, 분산 복제는 **JBOD•SDS**을 선택한다.

#### 한줄 요약

- RAID는 컨트롤러가 디스크를 재구성하고, JBOD 기반 SDS는 분산 계층이 사본을 재복제하여 중복도를 회복한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **단일 장애점**: 하나의 구성요소 고장만으로 전체 서비스가 중단되는 지점이다.
- **취약 시간**: 재구성•재복제가 끝날 때까지 추가 장애를 견디기 어려운 저하 상태의 지속 시간이다.
- **RAID 메타데이터**: RAID 레벨•구성원•배치•재구성 상태를 기록하는 제어 정보이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 보호되지 않은 라이트백 캐시로 **정전 손실** 발생 | 보호 상태 감시 후 **라이트스루 전환** | **승인된 쓰기** 보존 |
| **재구성•재복제**가 정상 I/O를 압박 | 우선순위 제한과 **취약 시간 감시** | 정상 I/O 지연•**취약 시간** 목표 준수 |
| 하드웨어 RAID와 SDS의 **중복 보호** | **보호•복구 책임**을 한 계층에 명시 | **용량 낭비•판단 혼선** 방지 |
| 컨트롤러•RAID 메타데이터 종속으로 **교체 복구 실패** | **호환 예비품•구성 백업**과 복구 훈련 | **배열 복구 가능성** 확보 |

#### 한줄 요약

- 부트 볼륨의 **미러링•전원 보호 캐시**를 적용한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **부트 볼륨**: 운영체제와 부팅 파일을 저장하여 서버 시작에 사용하는 논리 저장장치이다.
- **라이트스루**: 디스크에 실제 기록이 끝난 뒤 호스트에 쓰기 완료를 알리는 방식이다.

</details>

- 단일 서버 보호는 **RAID**, 분산 복제는 **JBOD•SDS**을 선택한다.

#### 한줄 요약

- **복구 책임**을 단일 서버 컨트롤러가 지면 RAID, 분산 스토리지 계층이 지면 JBOD 패스스루를 선택한다.
