## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **ASIC(Application-Specific Integrated Circuit)**: 특정 용도와 연산 알고리즘에 맞게 회로 논리를 완전히 고정하여 맞춤 제작하는 전용 반도체.
- **전용 데이터 경로(Dedicated Data Path)**: 특정 연산의 데이터 이동 및 처리를 위해 하드웨어 배선을 고정 설계한 실행 경로.
- **오프칩 데이터 이동(Off-Chip Data Movement)**: 가속기와 외부 DRAM 간 데이터를 송수신하며 소비되는 전송 동작.
- **AI(Artificial Intelligence)**: 학습된 신경망 모델 기반 추론 및 연산 기술.

</details>

- 정의/개념: 특정 AI 알고리즘·연산 정밀도·데이터 흐름 전용 회로를 하드웨어 제조 시점에 완전 고정한 **ASIC** 가속기
- 배경/필요성: 범용 프로세서(CPU/GPU)의 불필요한 명령 디코딩 오버헤드 및 외부 메모리 액세스 소모 전력 최소화 요구

#### 한줄 요약

- ASIC AI 가속기는 전용 데이터 경로와 온칩 재사용으로 명령 처리와 외부 데이터 이동 오버헤드를 줄인다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **고정형 데이터플로우(Stationary Dataflow)**: 가중치, 활성값, 부분합 중 하나를 PE 내부 버퍼에 고정 유지하여 피연산자 이동을 최소화하는 방식.
- **NRE(Non-Recurring Engineering)**: 반도체 칩 설계, 마스크 제작, 시제품 검증 등에 소요되는 일회성 초기 개발 비용.
- **손익분기 수량(Break-Even Volume)**: ASIC 초기 NRE 비용을 칩당 생산 단가 절감액으로 회수할 수 있는 최소 생산 수량.
- **온칩 재사용(On-Chip Reuse)**: 데이터를 칩 내부 SRAM에 유지 및 재활용하여 외부 DRAM 접근 횟수를 줄이는 방식.

</details>

- 불필요한 명령 처리 오버헤드를 제거한 **전용 데이터 경로** 확보
- 외부 메모리 전송을 극적으로 단축시키는 **고정형 데이터플로우** 및 **온칩 재사용**
- 칩당 생산 단가 절감으로 초기 **NRE** 비용을 회수할 **손익분기 수량** 확보 필요

$$
BreakEven\ Volume = \frac{NRE}{UnitCost_{alternative} - UnitCost_{ASIC}}
$$

> 대안보다 ASIC의 칩당 비용이 낮을 때 초기 개발비를 칩당 절감액으로 나누어 손익분기 수량 산정

#### 한줄 요약

- 전용 데이터 경로는 성능·전력 효율을 높이지만 초기 NRE와 모델 변경 시 재설계 비용을 증가시킨다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **PE(Processing Element)**: 행렬 및 텐서 연산을 병렬 실행하는 ASIC 내부의 최단위 연산 블록.
- **MAC(Multiply-Accumulate)**: 두 피연산자를 곱한 값을 기존 부분합에 누적하는 신경망 기본 연산.
- **SRAM(Static Random-Access Memory)**: 가중치 및 부분합을 고속 온칩 재사용하도록 지원하는 휘발성 메모리.
- **NoC(Network on Chip)**: PE 배열 간 데이터 및 부분합을 멀티캐스트로 분배·전송하는 온칩 네트워킹 라우터.
- **DMA(Direct Memory Access)**: CPU 개입 없이 온칩 SRAM과 외부 DRAM 간 텐서를 전송하는 제어기.

</details>

```text
ASIC AI 가속기
|
+-- [호스트•DMA 인터페이스]
+-- [온칩 SRAM•출력 버퍼]
+-- [NoC•멀티캐스트]
`-- [PE•MAC 배열]
```

선의 의미: 4개의 구성요소가 ASIC 가속기 물리 경계 내부에서 데이터 수송, 저장, 병렬 연산을 분담하는 정적 계층 관계.

| 구성요소 | 책임 |
|:---|:---|
| 호스트•DMA 인터페이스 | 호스트 명령 수령 및 외부 DRAM 타일 데이터 획득 |
| 온칩 SRAM•출력 버퍼 | 텐서 데이터의 온칩 보관 및 부분합 재사용 |
| NoC•멀티캐스트 | PE 배열 간 피연산자 고속 멀티캐스팅 및 라우팅 |
| PE•MAC 배열 | 2D/3D 배열 기반 병렬 곱셈-누산 연산 수행 |

#### 한줄 요약

- DMA가 타일을 SRAM에 놓고 NoC가 재사용 데이터를 PE 배열에 분배한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **타일(Tile)**: 대용량 텐서를 온칩 SRAM 크기 및 PE 배열 구조에 맞춰 절편한 데이터 블록.
- **멀티캐스트(Multicast)**: 동일한 데이터(가중치/활성값)를 복수의 PE로 일괄 분배 전송하는 방식.
- **부분합(Partial Sum)**: 행렬 곱 연산 중간 단계에서 누적 생성 중인 중간 연산 결과값.

</details>

```text
                  [고정 AI 작업•데이터플로우]
                                |
              +----------------------------------+
              | 반복: 입력•가중치 타일         |
              | 1. DMA 외부 타일 회수           |
              | 2. 온칩 SRAM 배치•재사용       |
              | 3. NoC 멀티캐스트 분배          |
              | 4. PE MAC•부분합 누적          |
              +----------------------------------+
                                |
                      [최종 결과 기록•완료]
```

### 동작 원리

1. **외부 타일 전송**: **DMA**를 이용하여 입력 및 가중치 **타일**을 온칩 SRAM으로 인출.
2. **온칩 배치·재사용**: **고정형 데이터플로우** 기법 기반 온칩 SRAM에 텐서 데이터 배치 및 재사용 극대화.
3. **NoC 멀티캐스트 분배**: **NoC** 네트워크를 통해 다수의 **PE**로 활성화 데이터 동시 전달.
4. **MAC·부분합 누적**: PE 2D 배열이 병렬 **MAC** 연산을 수행하고 최종 결과값을 출력 버퍼로 반환.

#### 한줄 요약

- DMA가 타일을 온칩 SRAM에 배치하면 NoC가 재사용 데이터를 PE 배열에 분배하고 부분합을 가까이 유지해 외부 메모리 접근을 줄인다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **FPGA(Field-Programmable Gate Array)**: 비트스트림을 통해 논리 회로 및 배선을 재구성할 수 있는 가속기.
- **GPU(Graphics Processing Unit)**: 다수 전용 코어 기반 소프트웨어 프로그래밍 가능한 범용 병렬 가속기.
- **재설계 비용(Redesign Cost)**: 회로 변경 필요 시 마스크 제작 및 NRE가 재발생하는 비용 오버헤드.

</details>

| AI 가속기 | ASIC | FPGA | GPU |
|:---|:---|:---|:---|
| 적용 기준 | 알고리즘 고정 및 **손익분기 수량** 이상 대량 출하 시 | 주기적 회로 갱신 및 결정적 지연 요구 시 | 알고리즘 갱신 빈번 및 높은 범용성 요구 시 |
| 핵심 특징 | **ASIC** 전용 하드웨어 로직 고정 | **FPGA** 회로 재구성 가능 | **GPU** SIMT 스레드 병렬성 |
| 한계 | 높은 **NRE**와 회로 변경 시 재설계 비용 | 재구성 자원•합성•타이밍 오버헤드 | 높은 전력 소비와 메모리 이동 병목 |

> 요약: 성능/전력 극대화는 ASIC, 회로 변경은 FPGA, 범용성은 GPU 선택.

#### 한줄 요약

- 모델이 안정적이고 수요가 많으면 ASIC, 회로 수준 변경이 필요하면 FPGA, 모델·연산 변경이 잦으면 GPU가 적합하다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **프로그래머블 제어(Programmable Control)**: 하드웨어 기본 데이터 경로는 유지하면서 제어 명령 순서를 변경 가능케 하는 회로 설계 방식.
- **연산기 가동률(Compute Utilization)**: 유휴 시간 대비 실제 의미 있는 연산을 수행하는 PE의 가동 비율.
- **에뮬레이션(Emulation)**: ASIC 칩 제작 전 FPGA 대규모 클러스터에서 칩의 동작을 미리 검증하는 절차.
- **실리콘 검증(Silicon Validation)**: 제작 완료된 시제품 칩(Tape-out 이후)의 기능, 전력, 타이밍 마진을 물리적으로 검증하는 단계.
- **TPU(Tensor Processing Unit)**: 행렬 연산 가속을 위해 구글이 개발한 대표적 신경망 전용 ASIC 프로세서.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 소량 생산 시 막대한 **NRE** 비용으로 인한 사업성 상실 | **손익분기 수량** 분석 및 양산 수량 확보 검증 | 비효율적 반도체 개설 투자 방지 |
| 알고리즘 갱신 시 고정 회로의 조기 노후화 | **프로그래머블 제어** 인스트럭션 셋 유연성 확보 | 소프트웨어 수준의 모델 업데이트 수용 |
| SRAM 전송 지연으로 인한 PE 유휴 발생 | **고정형 데이터플로우** 및 메모리 핑퐁 이중 버퍼링 구축 | **연산기 가동률** 극대화 |
| Tape-out 후 마스크 오류로 인한 재제조 실패 | 양산 전 **에뮬레이션** 및 **실리콘 검증** 절차 엄격 적용 | 시제품 오류 차단 및 리비전 비용 절감 |

> 사례: **TPU**의 경우 2D 시스톨릭 아레이 기반 행렬 연산 전용 ASIC 구조 적용

#### 한줄 요약

- 반복 행렬 연산은 데이터를 온칩에서 재사용해 전송 전력과 PE 대기를 줄인다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **모델 안정성(Model Stability)**: 신경망 구조 및 연산 타입이 오랜 기간 변경되지 않고 유지되는 특성.
- **ASIC 선택 기준(ASIC Selection Criteria)**: 생산 수량, 전력 효율 및 서비스 수명을 종합 평가하여 ASIC 제작 여부를 판정하는 기준.

</details>

- **ASIC 선택 기준**에 따라 **모델 안정성** 및 **손익분기 수량** 확보 시 **ASIC** 적용

#### 한줄 요약

- 모델과 핵심 연산이 제품 수명 동안 안정적이고 예상 생산량이 손익분기 수량을 넘을 때 ASIC 적용 원칙 준수.
