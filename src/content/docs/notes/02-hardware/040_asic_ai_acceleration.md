## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **주문형 반도체(Application-Specific Integrated Circuit, ASIC)**: 특정 응용 목적(AI 딥러닝 텐서 연산)만을 전담하여 최고 속도와 전력 효율을 달성하도록 실리콘 회로를 고정 설계한 맞춤형 반도체(Google TPU, Groq LPU 등).
- **초기 개발 비용(Non-Recurring Engineering, NRE)**: 반도체 칩 설계, 검증 및 포토마스크 제작 시 1회성으로 투입되는 수백억 원 규모의 고정 연구개발 비용.

</details>

- 정의/개념: AI 딥러닝의 핵심 연산인 대규모 행렬 곱셈(GEMM)과 텐서 데이터 경로만을 하드웨어 실리콘에 직접 고정하여 최고 속도와 에너지 효율을 달성하는 **주문형 전용 반도체 아키텍처**
- 배경/필요성: 범용 프로세서의 복잡한 제어 논리 오버헤드 제거를 통한 전력 효율(TOPS/W) 극대화 및 데이터 이동 병목 해소

#### 한줄 요약
- ASIC은 AI 전용 고정 회로(시스톨릭 어레이)를 통해 불필요한 제어 오버헤드를 없애고 최고의 전력 효율과 성능을 달성하는 전용 반도체이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **시스톨릭 어레이(Systolic Array)**: 2차원 연산기 셀 격자망에서 데이터가 심장 박동처럼 인접 셀로 직접 흘러가며 누적 연산되어 레지스터 파일이나 메모리 접근을 최소화하는 2D 하드웨어 구조.
- **TOPS/W(Tera Operations Per Second Per Watt)**: 소비 전력 1와트(Watt)당 처리할 수 있는 테라(1조 회) 연산량으로, AI 가속기의 핵심 에너지 효율 척도.

</details>

- 명령어 디코딩과 비순차 실행 로직을 제거하고 실리콘 면적을 **순수 곱셈-누산(MAC) 연산기와 온칩 SRAM**으로 극대화
- 2차원 격자 구조의 **시스톨릭 어레이(Systolic Array)**를 통해 인접 연산 셀 간에 데이터를 직접 전파하여 DRAM 접근 트래픽 최소화
- 범용 프로세서 대비 5~10배 이상 우수한 **에너지 효율(TOPS/W)**과 단위 면적당 압도적인 연산 처리량 실현

#### 한줄 요약
- 불필요한 제어 회로를 없애고 시스톨릭 어레이로 데이터를 재사용하여 최고의 TOPS/W와 처리량을 실현한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **텐서 연산 유닛(Matrix Multiply Unit, MXU / TPU Core)**: 수천 개의 곱셈-누산(MAC) 셀이 2차원 격자로 배열되어 행렬 곱셈을 1사이클 스트리밍으로 처리하는 코어.
- **벡터 및 활성화 유닛(Vector / Activation Unit)**: 행렬 연산 결과에 대해 ReLU, GELU, Softmax, 정규화(LayerNorm) 등 비선형 함수를 병렬 처리하는 SIMD 유닛.

</details>

```text
[ASIC AI 가속 아키텍처]
  │
  ├─ [온칩 SRAM 버퍼 서브시스템] (SRAM Buffer)
  │     ├─ [가중치 버퍼] (정적 모델 파라미터 캐싱)
  │     └─ [활성화 텐서 버퍼] (중간 활성화 데이터 대피)
  │
  ├─ [2D 시스톨릭 어레이] (MXU 행렬 곱셈 엔진)
  │     ├─ [2D 격자 MAC 셀 어레이] (인접 셀 간 직접 전파 연산)
  │     ├─ [가중치 고정 레지스터] (Weight-Stationary 구조)
  │     └─ [부분합 누적 레지스터] (수직 스트리밍 누산기)
  │
  ├─ [벡터 및 활성화 유닛] (SIMD Vector Unit)
  │     ├─ [비선형 활성화 가속기] (GELU, ReLU 함수 하드웨어화)
  │     └─ [텐서 정규화기] (LayerNorm / Softmax 벡터 연산)
  │
  └─ [초고속 메모리 인터페이스] (PHY & I/O)
        ├─ [전용 DMA 컨트롤러] (호스트 간섭 없는 텐서 전송)
        └─ [초고대역폭 HBM PHY] (오프칩 초고속 인터커넥트)
```

선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 2D 시스톨릭 어레이 (MXU) | 2차원 MAC 셀 격자망을 통해 **행렬 곱셈(GEMM) 연산을 1사이클 스트리밍 가속** |
| 대용량 온칩 SRAM | 모델 가중치 및 활성화 텐서를 온칩에 상주시켜 **외부 DRAM 트래픽 차단** |
| 벡터 활성화 유닛 | 행렬 곱셈 결과에 대해 **비선형 활성화(GELU 등) 및 정규화 SIMD 연산 수행** |
| 전용 DMA 컨트롤러 | 호스트 CPU 간섭 없이 **HBM과 온칩 SRAM 간 초고속 텐서 블록 전송** |

#### 한줄 요약
- ASIC은 2D 시스톨릭 어레이(행렬곱), 대용량 온칩 SRAM, 벡터 활성화 유닛 및 HBM 메모리 인터페이스가 결합된 구조이다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **가중치 고정(Weight-Stationary)**: 딥러닝 가중치를 시스톨릭 셀 내부에 고정해 두고, 활성화 입력 데이터를 가로로 흘려보내며 곱셈 누산 결과를 출력하는 데이터 흐름 기법.

</details>

```text
+-------------------------------------------------------------+
|              호스트의 AI 텐서 추론 실행 명령 수신            |
+-------------------------------------------------------------+
                               |
                               v
               +-------------------------------+
               |     1. 가중치 SRAM 상주 검사  |
               +-------------------------------+
                      |                 |
             [SRAM 상주 (Hit)]          | [비상주 (Miss)]
                      |                 v
                      | +-------------------------------+
                      | | 2. 전용 DMA로 HBM 가중치 로드 |
                      | +-------------------------------+
                      v                 |
+---------------------------------------+
|       3. 시스톨릭 어레이 MAC 셀에 가중치 고정(Preload)       |
+-------------------------------------------------------------+
                               |
                               v
+-------------------------------------------------------------+
|       4. 시차(Skewed) 입력 주입 및 2D 셀 간 부분 합 전파     |
+-------------------------------------------------------------+
                               |
                               v
+-------------------------------------------------------------+
|       5. 벡터 유닛의 비선형 활성화 처리 및 최종 텐서 출력    |
+-------------------------------------------------------------+
```

분기 결과: 가중치가 **온칩 SRAM에 상주**하면 외부 메모리 접근 지연 없이 1클록 내 연산 파이프라인으로 직행하나, **비상주** 시에는 HBM으로부터 수십 마이크로초의 DMA 블록 적재 지연이 선행됨

**동작 원리**

1. **온칩 SRAM 상주 판별**: 추론 요청된 레이어의 가중치 텐서가 이미 온칩 SRAM 버퍼에 캐싱되어 있는지 여부를 태그 비교로 즉각 검사
2. **HBM 고속 가중치 프리패치**: SRAM 미스 발생 시 전용 DMA 엔진이 HBM 채널을 직접 구동하여 초당 수 테라바이트 속도로 가중치 블록을 온칩 메모리에 일괄 로드
3. **가중치 고정(Weight-Stationary)**: 2D 시스톨릭 어레이의 각 MAC 셀 내부 로컬 레지스터에 해당 위치의 가중치 파라미터를 1회 기록 및 고정
4. **시차 입력 주입 및 수직/수평 전파**: 활성화 입력 텐서를 클록 주기마다 한 단계씩 시차를 두고 가로축으로 주입하면, MAC 셀이 곱셈 후 부분 합을 세로축 아래 셀로 누적 전파
5. **벡터 활성화 및 결과 출력**: 시스톨릭 어레이 최하단에서 출력된 누적 행렬 데이터에 대해 SIMD 벡터 유닛이 GELU/LayerNorm 비선형 연산을 인라인으로 적용하여 최종 결과 도출

#### 한줄 요약
- 가중치를 온칩에 상주시켜 시스톨릭 어레이에 고정하고, 시차를 두고 주입된 입력을 2D 셀망으로 누적 전파하여 비선형 활성화 후 출력한다.

## Ⅴ. 종류 및 비교

| AI 가속 하드웨어 | ASIC (TPU, Trainium, LPU) | GPU (NVIDIA H100) | FPGA (Xilinx Versal) | 범용 CPU (x86_64) |
|:---|:---|:---|:---|:---|
| 적용 기준 | 알고리즘 고정 대규모 AI 모델 양산 및 최고 TCO 요구 시 | LLM 연구 개발, 초거대 분산 학습 및 범용 가속 환경 | 알고리즘 변동 대응 및 배치=1 결정론적 초저지연 요구 시 | 비정형 제어 흐름, 데이터 전처리 및 범용 비즈니스 로직 시 |
| 핵심 특징 | 시스톨릭 어레이 기반 **완전 고정 맞춤 회로 및 최고 TOPS/W** | 수천 개 SIMT 코어 기반 **소프트웨어 커널 대규모 병렬 연산** | 비트스트림 기반 **회로 재구성 및 비표준 비트폭 파이프라인** | 다계층 캐시와 분기 예측 기반 **범용 비순차 명령어 실행** |
| 한계 | 회로 고정으로 **변경 불가** 및 수백억 원 규모 초기 NRE 비용 | 높은 전력 소모 및 배치 단위 큐잉에 따른 **가변 지연** | 프로그래머블 배선 오버헤드로 인한 **동작 클록 주파수 한계** | 순차 처리 구조로 인한 **대규모 텐서 연산 처리량 한계** |

#### 한줄 요약
- 연산 구조가 고정되고 대량 양산이 가능한 환경에서는 ASIC이 최강의 효율을 내며, 연구 개발과 범용 학습에는 GPU가 표준이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **전용 컴파일러(AI Compiler / XLA)**: PyTorch/TensorFlow 코드를 ASIC 전용 ISA 명령어로 최적화 변환하는 소프트웨어 툴체인.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 막대한 초기 NRE 마스크 비용과 수요 변동 리스크 | **공용 베이스 다이 및 칩렛(Chiplet)** 모듈 재사용 | 개발 비용 분산 및 실리콘 수율 극대화 |
| 고정 하드웨어 설계로 인한 신규 신경망 연산자 지원 불가 | **프로그래머블 VLIW 벡터 연산기** 결합 설계 | 최신 활성화 함수 및 어텐션 알고리즘 유연 수용 |
| 전용 하드웨어에 대한 컴파일러 및 프레임워크 부재 | **OpenXLA 및 TVM** 오픈 컴파일러 생태계 지원 | PyTorch/TensorFlow 모델의 무수정 자동 변환 |

#### 한줄 요약
- 실무에서는 칩렛 활용으로 NRE를 낮추고, 프로그래머블 벡터 코어로 알고리즘 변화를 수용하며, OpenXLA로 소프트웨어 생태계를 완성한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **LPU(Language Processing Unit)**: 대규모 온칩 SRAM과 초고속 데이터패스를 결합하여 LLM 토큰 생성 지연을 극소화한 언어 모델 전용 ASIC.
- **도메인 특화 아키텍처(Domain-Specific Architecture, DSA)**: 범용성을 배제하고 특정 연산 도메인(행렬곱 등)에 물리 회로를 전용화하여 전력과 처리량 효율을 극대화하는 설계 철학.

</details>

정형화된 대규모 AI 모델에서 압도적인 전력 효율(TOPS/W)과 TCO 절감을 달성하는 도메인 특화 아키텍처(DSA)의 정점이며, 컴파일러 자동 최적화 및 칩렛 모듈화와의 융합을 통한 진화.

#### 한줄 요약
- ASIC은 정형화된 대규모 AI 모델에서 압도적인 전력 효율과 가성비를 달성하는 최종 솔루션이며, 컴파일러 생태계와의 결합이 성공의 열쇠이다.
