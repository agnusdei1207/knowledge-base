## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **주문형 반도체(Application-Specific Integrated Circuit)**: 오로지 특정 딥러닝 알고리즘이나 전용 워크로드 단 하나만을 빛의 속도로 쳐내기 위해, 하드웨어 논리 회로를 뼛속까지 고정하여 맞춤 제작한 독단적인 전용 가속기이다.
- **전용 데이터 경로(Dedicated Data Path)**: 소프트웨어의 지시를 기다리지 않고, 정해진 연산만을 숨 막히게 빠르게 처리할 수 있도록 칩 내부의 고속도로 배선을 콘크리트처럼 굳혀버린 하드웨어 실행 경로이다.
- **오프칩 데이터 이동(Off-Chip Data Movement)**: 칩 내부 연산기가 바깥에 있는 느려터진 메인 메모리에서 데이터를 퍼 오거나 쓰는 동작으로, 칩 전체 전력의 대부분을 갉아먹는 최악의 전력 낭비 주범이다.
- **인공지능(Artificial Intelligence)**: 인간의 뇌신경망을 모방한 방대한 행렬 곱셈을 통해 기계가 스스로 학습하고 추론하게 만드는 데이터 처리 기술이다.

</details>

- 정의: 특정 인공지능 알고리즘, 연산 정밀도 및 데이터 흐름 전용 회로를 하드웨어 제조 시점에 완전하게 고정한 **주문형 반도체** 가속기
- 배경: 범용 프로세서의 불필요한 명령어 해독 오버헤드를 걷어내고, 전기를 빨아먹는 외부 메모리 접근으로 인한 막대한 전력 소모를 원천 봉쇄하기 위함

#### 한줄 요약

- 오직 인공지능 연산 하나만을 위해 불필요한 모든 기능을 거세하고, 칩 내부의 데이터 경로를 시멘트처럼 굳혀버려 압도적인 전력 효율과 속도를 달성하는 칩이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **고정형 데이터플로우(Stationary Dataflow)**: 가중치나 부분합 같은 중요한 데이터를 칩 밖으로 빼지 않고 연산기 내부 버퍼에 끈질기게 가둬두어, 데이터가 칩 안에서만 맴돌게 만드는 지독한 최적화 기법이다.
- **일회성 비반복 엔지니어링 비용(Non-Recurring Engineering)**: 반도체 칩 설계도 그리기, 붕어빵 틀(마스크) 파기, 시제품 테스트 등에 갈아 넣어야 하는 수백억 원 단위의 매몰 초기 개발 비용이다.
- **손익분기 수량(Break-Even Volume)**: 저 무시무시한 초기 개발비를 칩 하나당 떨어지는 생산 단가 절감액으로 퉁쳐서 본전을 뽑아낼 수 있는, 최소한으로 팔아치워야 하는 칩의 개수이다.
- **온칩 재사용(On-Chip Reuse)**: 데이터를 한 번 바깥 메모리에서 퍼 왔으면 칩 내부의 고속 버퍼에 꽉꽉 쟁여놓고 단물이 빠질 때까지 재활용하여 밖으로 나가는 발걸음을 끊어버리는 방식이다.

</details>

- 불필요한 범용 명령어 처리 및 해독 오버헤드를 완전히 쳐낸 하드웨어 **전용 데이터 경로**를 칩 내부에 확고하게 구축함.
- 전력을 잡아먹는 외부 메모리 전송 병목을 극적으로 단축시키는 **고정형 데이터플로우** 아키텍처 및 극한의 **온칩 재사용**을 달성함.
- 막대한 초기 **일회성 비반복 엔지니어링 비용**을 칩당 생산 단가 절감액으로 회수할 수 있는 거대한 **손익분기 수량** 확보가 무조건 필수적임.

#### 한줄 요약

- 데이터가 칩 밖으로 나가지 못하게 막아 전력과 속도를 극대화하지만, 붕어빵 틀을 파는 데 수백억이 들기 때문에 반드시 수백만 개를 팔아치워야만 본전을 건진다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **처리 요소(Processing Element)**: 곱하기와 더하기만 미친 듯이 잘하는 아주 작은 일개미 연산 블록으로, 이 개미 수만 마리가 칩 안에 바둑판처럼 깔려 행렬 연산을 처리한다.
- **곱셈 누산 연산(Multiply-Accumulate)**: 두 숫자를 곱한 뒤 기존 값에 더하는 동작으로, 딥러닝 신경망이 데이터를 추론할 때 수조 번 반복하는 숨쉬기 같은 기초 연산이다.
- **정적 임의 접근 메모리(Static Random-Access Memory)**: 데이터를 칩 내부에 가둬두고 전광석화처럼 재활용할 수 있게 해주는, 비싸고 용량은 작지만 엄청나게 빠른 온칩 캐시 메모리이다.
- **네트워크 온 칩(Network on Chip)**: 수만 마리의 일개미 연산기들에게 밥(데이터)을 골고루 동시에 뿌려주기 위해 칩 내부에 깔아놓은 초고속 거미줄 배달 네트워크이다.
- **직접 메모리 접근(Direct Memory Access)**: 칩이 중앙처리장치의 허락을 기다리지 않고 바깥 메인 메모리에 직접 빨대를 꽂아 거대한 텐서 데이터를 칩 안으로 폭포수처럼 들이붓는 하드웨어 펌프이다.

</details>

```text
[ 주문형 인공지능 반도체 가속기 칩 내부 아키텍처 ]
+-------------------------------------------------------------+
| 주문형 반도체 칩 내부 물리적 경계                           |
|                                                             |
|  [ 호스트 명령 수신 및 직접 메모리 접근 통신 인터페이스 ]   |
|               │ (외부 텐서 데이터 무자비한 펌핑 유입)       |
|               ▼                                             |
|  [ 온칩 정적 임의 접근 메모리 버퍼 및 최종 출력 버퍼망 ]    |
|               │ (데이터 온칩 가두기 및 재사용 극대화)       |
|               ▼                                             |
|  [ 네트워크 온 칩 멀티캐스트 및 데이터 고속 라우팅망 ]      |
|               │ (수만 개 연산기에 융단폭격 분배)            |
|               ▼                                             |
|  [ 처리 요소 일개미 배열 및 병렬 곱셈 누산 연산 심장부 ]    |
+-------------------------------------------------------------+
```

| 구성요소 | 책임 |
|:---|:---|
| 호스트 및 **직접 메모리 접근** 인터페이스 | 컴퓨터 주인의 명령을 하달받고 바깥 메모리로부터 방대한 타일 데이터를 칩 안으로 쉴 새 없이 펌핑 인출 |
| 온칩 **정적 임의 접근 메모리** 및 출력 버퍼 | 칩 안으로 들어온 텐서 데이터를 절대 내보내지 않고 보관하며 연산 찌꺼기(부분합)의 즉각적인 재사용 밀착 지원 |
| **네트워크 온 칩** 멀티캐스트 | **처리 요소** 바둑판 배열 사이사이에 피연산자 데이터를 고속 멀티캐스팅으로 뿌려주고 병목 없이 라우팅 |
| **처리 요소** 및 **곱셈 누산 연산** 배열 | 2차원 시스톨릭 배열 기반으로 뭉친 연산기들이 무자비하고 압도적인 병렬 **곱셈 누산 연산**만 하루 종일 집중 수행 |

#### 한줄 요약

- 외부에서 데이터를 퍼 와서 칩 안쪽 창고에 가두고, 내부 거미줄 망을 통해 수만 개의 일개미 연산기들에게 뿌려주어 쉴 새 없이 곱하고 더하게 만든다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **타일(Tile)**: 기가바이트 단위의 거대한 인공지능 텐서 데이터를 칩 안의 조그만 창고 크기와 연산기 배열 구조에 딱 맞게 깍두기처럼 썰어놓은 데이터 조각이다.
- **멀티캐스트(Multicast)**: 똑같은 가중치 데이터를 연산기 수만 개에 일일이 배달하지 않고, 방송국에서 전파를 쏘듯 한 번에 확 뿌려버려 대역폭 낭비를 없애는 전송 기법이다.
- **부분합(Partial Sum)**: 행렬 곱셈을 한 번에 끝낼 수 없어 여러 번에 나누어 더해가는 과정에서 발생하는, 아직 완성되지 않은 임시 중간 계산 결과값이다.

</details>

```text
[ 주문형 반도체 고정형 인공지능 작업 및 데이터플로우 가속 제어 흐름 ]
                                │
                                ▼
         [ 1. 직접 메모리 접근을 통한 외부 타일 펌핑 인출 ]
                                │
                                ▼
         [ 2. 고정형 데이터플로우 기반 온칩 텐서 전략적 배치 및 재사용 ]
                                │
                                ▼
         [ 3. 네트워크 온 칩을 통한 활성화 데이터 멀티캐스트 융단폭격 분배 ]
                                │
                                ▼
         [ 4. 처리 요소 배열의 병렬 곱셈 누산 연산 및 부분합 누적 쳐내기 ]
                                │
                 [ 타일 소진 시까지 1~4 과정 무한 반복 ]
                                │
                                ▼
                 [ 최종 추론 결과물 기록 및 호스트에 완료 알람 통보 ]
```

### 동작 원리

1. 외부 타일 펌핑 전송: **직접 메모리 접근** 펌프를 맹렬히 가동하여 방대한 입력 및 가중치 **타일** 데이터를 온칩 임시 버퍼로 고속 인출함.
2. 온칩 텐서 배치 및 재사용: **고정형 데이터플로우** 기법을 뼈대로 삼아 온칩 버퍼에 텐서 데이터를 전략적으로 가둬 배치하고 닳도록 재사용을 극대화함.
3. 네트워크 온 칩 분배: 내부 온칩 네트워크 도로망을 통해 다수의 **처리 요소** 연산기들로 활성화 데이터를 **멀티캐스트**로 한 번에 동시 전달함.
4. 병렬 곱셈 누산 및 누적: 처리 요소 바둑판 배열이 병렬 연산을 쉼 없이 쳐내고, 계산된 **부분합** 찌꺼기를 버리지 않고 칩 내부 출력 버퍼로 신속히 반환하여 또 더함.

#### 한줄 요약

- 깍두기(타일)를 퍼 와서 안쪽 창고에 박아두고, 네트워크로 모든 연산기에 확 뿌려버린 다음, 수만 개의 연산기가 달라붙어 미친 듯이 곱하고 더해 결과를 짜낸다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **현장 프로그램 가능 게이트 어레이(Field-Programmable Gate Array)**: 알고리즘이 바뀔 때마다 하드웨어 회로 배선을 찰흙처럼 뗐다 붙이며 새로 구성할 수 있는 변신 로봇 같은 유연한 반도체이다.
- **그래픽 처리 장치(Graphics Processing Unit)**: 수천 개의 미니 코어를 때려 박아 수만 개의 소프트웨어 스레드를 동시에 돌리는, 전기 먹는 하마지만 범용성은 끝내주는 병렬 연산 가속기이다.
- **재설계 비용(Redesign Cost)**: 주문형 반도체를 구워냈는데 알고리즘 유행이 지나버려, 다시 설계도를 그리고 수백억짜리 붕어빵 틀(마스크)을 새로 파야 할 때 피눈물 나게 깨지는 비용 오버헤드이다.

</details>

| 비교 항목 | **주문형 반도체** | **현장 프로그램 가능 게이트 어레이** | **그래픽 처리 장치** |
|:---|:---|:---|:---|
| 시스템 적용 최적 기준 | 인공지능 알고리즘이 완전히 고정되고 **손익분기 수량** 이상의 엄청난 대량 출하가 보장된 환경 시 | 주기적인 칩 내부 회로 갱신이 필요하고 1밀리초의 결정적인 지연시간 준수가 목숨처럼 요구될 시 | 모델 알고리즘 갱신이 하루가 다르게 빈번하고 높은 소프트웨어적 범용성이 무조건 요구될 시 |
| 아키텍처 핵심 구현 구조 | 특정 목적 단 하나를 위해 전용 하드웨어 로직을 뼛속까지 시멘트처럼 고정하여 극한의 효율성만 추구 | 하드웨어 비트스트림 재구성 마법을 통하여 유연하게 논리 회로망 변신을 달성하는 구조 | 다수의 쪼가리 전용 코어를 기반으로 멈추지 않는 소프트웨어 스레드 병렬성을 극대화한 구조 |
| 극복해야 할 태생적 한계점 | 막대한 초기 개발 비용이 깨지며, 회로 변경 시 천문학적 **재설계 비용**과 시간이 증발하는 치명적 약점 | 쓰지 않고 버려지는 재구성 자원 낭비 및 물리적 타이밍 클로저 달성에 피 말리는 오버헤드 존재 | 극도로 거대한 칩 전력 소비 및 끊임없는 외부 메모리 이동 병목으로 인한 지연시간 변동성 발생 |

#### 한줄 요약

- 수백만 개를 찍어내 전기세를 극단적으로 아낄 거면 무조건 ASIC, 지연시간을 꽉 잡고 회로를 뜯어고칠 거면 FPGA, 일단 이것저것 다 돌려봐야 하면 GPU가 정답이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **프로그래머블 제어(Programmable Control)**: 하드웨어를 통째로 굳혀버리면 깡통이 될까 봐, 기본 데이터 길목은 내버려 두되 제어 명령 순서 정도는 소프트웨어로 바꿀 수 있게 숨통을 트여놓는 설계 꼼수이다.
- **연산기 가동률(Compute Utilization)**: 칩 안에 수만 개의 연산기를 박아놨는데 데이터가 늦게 도착해서 멍때리고 노는 시간을 뺀, 땀 흘리며 100% 진짜 연산만 하고 있는 기계의 가동 비율이다.
- **에뮬레이션(Emulation)**: 수백억을 들여 진짜 칩으로 굽기 전에, 거대한 FPGA 클러스터 장비에 설계도를 올려놓고 칩이 제대로 도는지 시뮬레이션으로 수개월간 굴려보는 모의고사 절차이다.
- **실리콘 검증(Silicon Validation)**: 테이프 아웃(설계 완료) 후 공장에서 막 튀어나온 따끈따끈한 시제품 칩에 전기를 꽂아, 설계대로 스피드가 나오는지 발열은 안 터지는지 물리적으로 확인하는 살떨리는 단계이다.
- **텐서 처리 장치(Tensor Processing Unit)**: 딥러닝 행렬 곱셈 하나만을 미친 듯이 가속하기 위해 구글이 천문학적인 돈을 들여 뼈대를 굳혀 만든 구글 전용 주문형 반도체(ASIC)의 대명사이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 어설프게 소량 생산했다가 막대한 초기 개발 비용을 건지지 못해 회사가 망하는 프로젝트 사업성 상실 위험 | 개발 착수 전 면밀한 **손익분기 수량** 엑셀 분석 및 고객사 양산 수량 개런티 확보 사전 검증 철저 수행 | 수백억이 증발하는 비효율적인 반도체 개설 투자 원천 방지 및 명확한 재무적 사업성 확보 |
| 칩을 굽고 나니 인공지능 알고리즘 트렌드가 확 바뀌어버려, 굳어버린 칩이 조기 노후화되고 고철이 될 위협 | 마이크로코드 기반 **프로그래머블 제어** 명령어 셋을 칩 내부에 심어 제어 유연성 탈출구 전략 사전 확보 | 최신 논문에서 쏟아지는 소프트웨어 수준의 모델 업데이트 꾸역꾸역 수용 및 칩 생명 연장 |
| 칩 안쪽 창고(버퍼)에서 연산기로 데이터 배달이 늦어져 비싼 연산기들이 손가락 빨며 심각한 유휴 상태 발생 | 데이터 가두기 **고정형 데이터플로우** 채택 및 데이터 핑퐁 이중 버퍼링 아키텍처로 쉴 틈 없이 밀어 넣기 구축 | 칩 내부 **연산기 가동률**을 90% 이상으로 극대화하고 때려 박은 하드웨어 자원 효율 100% 달성 |
| 수백억 주고 공장에 테이프 아웃 넘겼는데, 설계 오류가 뒤늦게 발견되어 치명적인 칩 재제조(리비전) 실패 참사 | 공장에 넘기기 전 양산 전 대규모 **에뮬레이션** 및 칩이 나오자마자 가혹한 물리적 **실리콘 검증** 절차 엄격 적용 | 시제품의 어처구니없는 논리 오류를 차단하고 수백억 원의 리비전 마스크 비용 절감 및 파산 방지 |

#### 한줄 요약

- 손익분기점으로 파산을 막고, 소프트웨어 숨통(프로그래머블)을 틔워 수명을 늘리며, 핑퐁 버퍼링으로 연산기를 쥐어짜고, 칩을 굽기 전 모의고사(에뮬레이션)로 설계 오류를 박멸한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **주문형 반도체 선택 기준(ASIC Selection Criteria)**: 이 모델이 5년 뒤에도 안 바뀔지(모델 안정성), 수십억 원의 설계비를 뽑고도 남을 만큼 수백만 개를 팔아치울 수 있을지(생산 수량), 전기를 얼마나 아껴야 할지를 냉혹하게 종합 평가하여 ASIC 제작 결단 버튼을 누르는 결정 프레임워크이다.

</details>

- **주문형 반도체 선택 기준**에 따라 알고리즘이 굳어버린 **모델 안정성** 및 대박 칠 확신이 선 **손익분기 수량** 확보 시 단호하게 **주문형 반도체** 적용을 결단함

#### 한줄 요약

- 모델과 핵심 연산이 제품이 단종될 때까지 안 바뀔 거라는 확신이 들고, 팔아치울 개수가 손익분기 수량을 아득히 넘어설 때만 거액을 들여 붕어빵 틀(ASIC)을 파야 한다.
