## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **주문형 반도체(Application-Specific Integrated Circuit, ASIC)**: 특정 응용 목적(AI 딥러닝 텐서 연산)만을 전담하여 최고 속도와 전력 효율을 달성하도록 실리콘 회로를 고정 설계한 맞춤형 반도체(Google TPU, Groq LPU 등).
- **초기 개발 비용(Non-Recurring Engineering, NRE)**: 반도체 칩 설계, 검증 및 포토마스크 제작 시 1회성으로 투입되는 수백억 원 규모의 고정 연구개발 비용.

</details>

- 정의/개념: AI 딥러닝의 핵심 연산인 대규모 행렬 곱셈(GEMM)과 텐서 데이터 경로만을 하드웨어 실리콘에 영구 고정한 **ASIC(주문형 반도체) AI 가속 아키텍처**
- 배경/필요성: 범용 GPU/CPU의 복잡한 제어 로직 오버헤드로 인한 **전력 효율(TOPS/W) 저하 및 연산 파이프라인 병목 한계**

#### 한줄 요약
- ASIC은 AI 전용 고정 회로(시스톨릭 어레이)를 통해 불필요한 제어 오버헤드를 없애고 최고의 전력 효율과 성능을 달성하는 전용 반도체이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **시스톨릭 어레이(Systolic Array)**: 2차원 연산기 셀 격자망에서 데이터가 심장 박동처럼 인접 셀로 직접 흘러가며 누적 연산되어 레지스터 파일이나 메모리 접근을 최소화하는 2D 하드웨어 구조.
- **TOPS/W(Tera Operations Per Second Per Watt)**: 소비 전력 1와트(Watt)당 처리할 수 있는 테라(1조 회) 연산량으로, AI 가속기의 핵심 에너지 효율 척도.

</details>

- 제어 오버헤드 0화: 명령어 인출, 디코딩, 비순차 실행 로직을 배제하고 칩 다이 면적의 대다수를 **순수 연산기(MAC)**와 온칩 SRAM 버퍼로 채움
- 데이터 재사용 극대화: **시스톨릭 어레이(Systolic Array)**를 통해 입력 데이터와 가중치를 셀 간에 직접 전파하여 DRAM 접근 소모 최소화
- 압도적인 에너지 효율: 범용 프로세서 대비 우수한 **TOPS/W(전력 대비 연산 성능)** 달성

#### 한줄 요약
- 불필요한 제어 회로를 없애고 시스톨릭 어레이로 데이터를 재사용하여 최고의 TOPS/W와 처리량을 실현한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **텐서 연산 유닛(Matrix Multiply Unit, MXU / TPU Core)**: 수천 개의 곱셈-누산(MAC) 셀이 2차원 격자로 배열되어 행렬 곱셈을 1사이클 스트리밍으로 처리하는 코어.
- **벡터 및 활성화 유닛(Vector / Activation Unit)**: 행렬 연산 결과에 대해 ReLU, GELU, Softmax, 정규화(LayerNorm) 등 비선형 함수를 병렬 처리하는 SIMD 유닛.

</details>

```text
ASIC AI 가속 시스템 구조
├── 2D 시스톨릭 어레이 (행렬 곱셈 MAC 격자 연산 코어)
├── 대용량 온칩 SRAM (가중치 및 활성화 텐서 버퍼)
├── 벡터 활성화 유닛 (GELU, LayerNorm 비선형 연산기)
├── 전용 DMA 컨트롤러 (호스트 무간섭 텐서 전송)
└── HBM3 메모리 PHY (초대형 모델 가중치 고속 공급)
```

선의 의미: 가지(`├──`, `└──`)는 ASIC 실리콘 칩 내 하드웨어 구성요소 소속 관계를 나타냄

| 구성요소 | 책임 |
|:---|:---|
| 2D 시스톨릭 어레이 | GEMM의 **MAC 셀 격자 연산** 가속 |
| 대용량 온칩 SRAM | 가중치·활성화 상주로 **DRAM 트래픽** 차단 |
| 벡터 활성화 유닛 | 비선형 활성화·정규화의 **SIMD 연산** |
| 전용 DMA 컨트롤러 | PCIe·CXL을 통한 **호스트 무간섭 전송** |
| HBM3 메모리 PHY | 초대형 모델 가중치의 **고대역폭 공급** |

#### 한줄 요약
- ASIC은 2D 시스톨릭 어레이(행렬곱), 대용량 온칩 SRAM, 벡터 활성화 유닛 및 HBM 메모리 인터페이스가 결합된 구조이다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **가중치 고정(Weight-Stationary)**: 딥러닝 가중치를 시스톨릭 셀 내부에 고정해 두고, 활성화 입력 데이터를 가로로 흘려보내며 곱셈 누산 결과를 출력하는 데이터 흐름 기법.

</details>

```text
[외부 명령] 호스트의 AI 추론 명령 수신
                      │
                      ▼
1. 가중치 온칩 SRAM 상주 여부 검사
   ┌──────────────────┴──────────────────┐
[ SRAM 상주 (Hit) ]                   [ 비상주 (Miss) ]
   │                                     │
   │                                     ▼
   │                                  2. 외부 HBM 가중치 온칩 DMA 로드
   └──────────────────┬──────────────────┘
                      │
                      ▼
3. 시스톨릭 어레이 MAC 셀 가중치 고정
                      │
                      ▼
4. 시차 입력 주입 및 2D 셀 간 연산 전파
                      │
                      ▼
5. 벡터 유닛 비선형 활성화 함수 적용
                      │
                      ▼
[결과 반환] 최종 추론 텐서 출력
```

분기 결과: 가중치가 온칩 SRAM에 상주하면 외부 HBM 왕복 없이 **3. 시스톨릭 어레이 MAC 셀 가중치 고정**과 **4. 시차 입력 주입 및 2D 셀 간 연산 전파**로 곧장 진입하나, 비상주 시에는 DMA 로드 지연이 추론마다 선행되어 온칩 용량이 실효 처리량을 결정함

#### 한줄 요약
- 1. 가중치 온칩 SRAM 상주 여부 검사
- 2. 외부 HBM 가중치 온칩 DMA 로드
- 3. 시스톨릭 어레이 MAC 셀 가중치 고정
- 4. 시차 입력 주입 및 2D 셀 간 연산 전파
- 5. 벡터 유닛 비선형 활성화 함수 적용

## Ⅴ. 종류 및 비교

| 비교 항목 | ASIC (Google TPU, Groq LPU) | GPU (NVIDIA H100) | FPGA (Xilinx Versal) | 범용 CPU |
|:---|:---|:---|:---|:---|
| 하드웨어 구현 | **완전 고정 맞춤형 회로** | SIMT 코어 프로그래머블 | 비트스트림 회로 재구성 | 범용 비순차 코어 |
| 전력 효율 (TOPS/W) | 최고 (**$5\sim 10\times$ GPU**) | 보통 | 우수 | 낮음 |
| 알고리즘 유연성 | 낮음 (신규 연산자 제약) | **소프트웨어 갱신** (최고) | 회로 재구성 (우수) | 범용 명령어 실행 |
| 칩당 제조 단가 | **대량 양산 시 최저** | 고가 (독점 마진) | 중간 | 저가~중간 |
| 초기 개발비 (NRE) | **수백억 원 소요** (최대) | 칩 구매 (개발비 없음) | 중간 | 개발비 없음 |
| 주요 적용 분야 | **대규모 고정 모델 추론** | **LLM 연구 및 범용 학습** | 자율주행, 프로토타이핑 | 범용 비즈니스 로직 |

#### 한줄 요약
- 연산 구조가 고정되고 대량 양산이 가능한 환경에서는 ASIC이 최강의 효율을 내며, 연구 개발과 범용 학습에는 GPU가 표준이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **전용 컴파일러(AI Compiler / XLA)**: PyTorch/TensorFlow 코드를 ASIC 전용 ISA 명령어로 최적화 변환하는 소프트웨어 툴체인.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 초기 막대한 NRE 비용과 수요 예측 실패 위험 | **양산 수량 검증** 및 **칩렛 IP 재사용** | 투자 손익분기점 조기 달성 및 리스크 헤징 |
| 신규 신경망 구조 등장 시 고정 하드웨어 무용화 | **프로그래머블 VLIW 벡터 코어** 결합 | 신규 활성화 및 어텐션 연산자 수용 |
| 전용 하드웨어에 대한 컴파일러 생태계 부족 | **OpenXLA 및 TVM** 오픈 표준 컴파일러 지원 | 소프트웨어 개발 생산성 및 모델 이식성 확보 |

#### 한줄 요약
- 실무에서는 칩렛 활용으로 NRE를 낮추고, 프로그래머블 벡터 코어로 알고리즘 변화를 수용하며, OpenXLA로 소프트웨어 생태계를 완성한다.

## Ⅶ. 결론

- 대규모 정형화된 AI 모델(LLM 추론/학습)에서 **최고의 전력 효율(TOPS/W)과 가격 경쟁력(TCO)**을 제공하는 핵심 가속기(Google TPU, AWS Trainium/Inferentia 등)로 입지를 굳혔으며, 최근에는 알고리즘 변화에 대응하기 위해 **프로그래머블 텐서/벡터 엔진 결합 및 오픈 컴파일러(OpenXLA, TVM) 생태계**를 통한 유연성 확보가 핵심 과제

#### 한줄 요약
- ASIC은 정형화된 대규모 AI 모델에서 압도적인 전력 효율과 가성비를 달성하는 최종 솔루션이며, 컴파일러 생태계와의 결합이 성공의 열쇠이다.
