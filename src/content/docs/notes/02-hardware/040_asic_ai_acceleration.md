## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **ASIC(Application-Specific Integrated Circuit)**: 특정 AI 알고리즘이나 전용 워크로드 처리를 위해 하드웨어 회로망을 맞춤형으로 고정 제작한 주문형 반도체.
- **전용 데이터 경로(Dedicated Data Path)**: 범용 명령어 인출/해독 단계를 생략하고 텐서 연산만을 최단 경로로 직결 처리하는 고정 하드웨어 파이프라인.
- **오프칩 메모리 트랜잭션(Off-Chip Access)**: 칩 외부 DRAM에서 데이터를 읽고 쓰는 동작으로, 온칩 SRAM 접근 대비 수백 배의 전력(pJ/bit)을 소모하는 병목.

</details>

- 정의/개념: 특정 AI 딥러닝 워크로드(행렬 곱셈, 컨볼루션)에 특화하여 연산 정밀도(INT8/FP8)와 하드웨어 데이터 경로를 전용 실리콘 회로로 고정 제작한 주문형 반도체(ASIC)
- 배경/필요성: 범용 프로세서(CPU/GPU)의 불필요한 명령어 인출/해독 오버헤드를 제거하고, **오프칩 메모리 접근(pJ/bit)을 최소화하여 압도적인 전력 효율(TOPS/W)과 대량 양산 경제성 확보**

#### 한줄 요약

- 특정 AI 연산에 특화된 하드와이어드 회로로 **최고 수준의 전력 효율(TOPS/W)과 처리 성능** 달성

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **Stationary Dataflow**: 가중치(Weight), 입력(Input), 또는 부분합(Output)을 온칩 PE 레지스터에 고정시켜 외부 메모리 접근을 최소화하는 텐서 데이터플로우 기법.
- **NRE(Non-Recurring Engineering) 비용**: 칩 마스크 제작, IP 라이선스, 물리적 설계 검증 등에 소요되는 일회성 고정 초기 개발비(수백억 원).
- **손익분기 생산량(Break-Even Volume, BEV)**: 절감된 단위당 칩 제조 단가로 초기 NRE 비용을 전액 회수할 수 있는 최소 생산 수량.

</details>

- 불필요한 범용 제어 로직을 배제하고 행렬 곱셈(GEMM)에 특화된 하드웨어 **전용 데이터 경로** 구축
- 외부 DRAM 이동을 극적으로 차단하는 **고정형 데이터플로우(Weight/Output Stationary)** 및 온칩 SRAM 재사용 극대화
- 막대한 초기 **NRE 비용(설계/마스크 비용)**을 상쇄하기 위한 대규모 **손익분기 생산 수량(BEV)** 확보 필수

#### 한줄 요약

- **전용 데이터 경로·고정형 데이터플로우(Dataflow)·NRE 회수(손익분기)** 특성

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **PE(Processing Element)**: MAC(Multiply-Accumulate) 연산기와 로컬 레지스터로 구성된 시스톨릭 2차원 연산 배열의 기본 단위 셀.
- **시스톨릭 어레이(Systolic Array)**: 데이터가 인접 PE들 사이를 심장 박동(Systole)처럼 일정한 클록 주기로 전달되며 곱셈과 누산을 연속 수행하는 2D 격자 구조.

</details>

```text
[ AI 전용 ASIC (TPU / NPU) 내부 아키텍처 ]
┌─────────────────────────────────────────────────────────────┐
│ ASIC 칩 내부 물리적 경계                                    │
│                                                             │
│  [ PCIe Gen5 Host I/F & DMA 스트리밍 엔진 ]                 │
│               │ (대용량 텐서 타일 데이터 고속 인출)          │
│               ▼                                             │
│  [ 온칩 대용량 SRAM 버퍼 (Unified Buffer: 수십~수백 MB) ]   │
│               │ (가중치/활성화 텐서 온칩 가두기 및 재사용)   │
│               ▼                                             │
│  [ NoC 멀티캐스트 및 데이터 분배 네트워크 ]                 │
│               │ (입력 텐서 융단폭격 공급)                    │
│               ▼                                             │
│  [ 2D 시스톨릭 PE 어레이 (수만 개 MAC 연산기 매트릭스) ]     │
│               │ (Weight-Stationary 행렬 곱셈 가속)          │
│               ▼                                             │
│  [ 벡터 연산 유닛 (VPU : ReLU, GeLU, Softmax 후처리 엔진) ]  │
└─────────────────────────────────────────────────────────────┘
```

선의 의미: 호스트 DMA 인터페이스, 온칩 SRAM 버퍼, NoC 멀티캐스트망 및 2D 시스톨릭 PE 어레이 간의 ASIC 아키텍처 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 호스트 및 직접 메모리 접근 인터페이스 | 컴퓨터 주인의 명령을 하달받고 바깥 메모리로부터 방대한 타일 데이터를 칩 안으로 쉴 새 없이 펌핑 인출 |
| 온칩 정적 임의 접근 메모리 및 출력 버퍼 | 칩 안으로 들어온 텐서 데이터를 절대 내보내지 않고 보관하며 연산 찌꺼기(부분합)의 즉각적인 재사용 밀착 지원 |
| 네트워크 온 칩 멀티캐스트 | **처리 요소** 바둑판 배열 사이사이에 피연산자 데이터를 고속 멀티캐스팅으로 뿌려주고 병목 없이 라우팅 |
| 처리 요소 및 곱셈 누산 연산 배열 | 2차원 시스톨릭 배열 기반으로 뭉친 연산기들이 무자비하고 압도적인 병렬 **곱셈 누산 연산**만 하루 종일 집중 수행 |

#### 한줄 요약

- **호스트 DMA·대용량 온칩 SRAM·NoC 멀티캐스트·2D 시스톨릭 PE 어레이**

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Weight-Stationary**: 가중치 매트릭스를 PE 레지스터에 미리 적재해 고정하고, 입력 피처맵을 시스톨릭 방향으로 흘려보내며 부분합을 누적하는 데이터플로우.

</details>

```text
[ ASIC AI 가속 실행 및 데이터플로우 흐름 ]
                         │
                         ▼
   [ 1. 호스트 DMA가 외부 DRAM에서 가중치/입력 타일 인출 ]
                         │
                         ▼
   [ 2. 온칩 SRAM 버퍼에 가중치 텐서 로드 및 고정 (Weight Stationary) ]
                         │
                         ▼
   [ 3. NoC 멀티캐스트를 통해 활성화 입력 데이터를 PE 배열로 주입 ]
                         │
                         ▼
   [ 4. 2D 시스톨릭 PE 어레이에서 클록마다 곱셈 누산(MAC) 연속 실행 ]
                         │
                         ▼
   [ 5. 활성화 함수(VPU) 후처리 후 온칩 버퍼 저장 및 호스트 인터럽트 통보 ]
```

**동작 원리**

1. **타일 인출**: 호스트 DMA가 외부 메모리에서 현재 레이어의 가중치 및 활성화 타일 데이터를 온칩 SRAM으로 인출
2. **가중치 고정**: 시스톨릭 PE 어레이의 각 셀 레지스터에 가중치 값을 고정(Weight-Stationary) 적재
3. **입력 주입**: 온칩 NoC를 통해 입력 피처맵 데이터를 행/열 방향으로 시차를 두고 연속 주입
4. **시스톨릭 연산**: 데이터가 인접 PE를 통과하면서 곱셈과 덧셈을 수행하고 부분합(Partial Sum)을 누적
5. **결과 출력**: VPU(Vector Processing Unit)에서 활성화 함수(GeLU 등)를 거쳐 최종 텐서 결과를 호스트에 반환

#### 한줄 요약

- DMA 타일 인출 $\to$ **온칩 가중치 고정(Weight Stationary) $\to$ NoC 멀티캐스트 $\to$ PE 시스톨릭 연산**

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **ASIC vs FPGA vs GPU**:
  - ASIC: 최고 에너지 효율(TOPS/W), 최소 다이 면적, NRE 높음, 기능 수정 불가
  - FPGA: 하드웨어 재구성 가능, 결정론적 저지연, 중간 NRE
  - GPU: 최고 소프트웨어 범용성(CUDA), 고전력, 기성품 즉시 도입

</details>

| 비교 항목 | 주문형 반도체 (ASIC / TPU) | 현장 프로그램 가능 반도체 (FPGA) | 그래픽 처리 장치 (GPU) |
|:---|:---|:---|:---|
| 아키텍처 및 유연성 | 고정된 하드와이어드 전용 회로 (기능 수정 불가) | 비트스트림 기반 공간적 하드웨어 재구성 | SIMT 기반 소프트웨어 다중 스레드 병렬 실행 |
| 전력 효율 및 성능 | 최고 수준의 TOPS/W 및 최소 면적 비용 | 우수한 에너지 효율 및 결정론적 초저지연 | 높은 배치 처리량, 높은 전력 소모(300~700W) |
| 경제성 및 개발 비용 | 막대한 초기 NRE 비용(수백억 원), 대량 양산 시 단가 최소 | 중간 수준 칩 단가, 빠른 출시(Time-to-Market) | 기성품 구매 가능, 범용 소프트웨어 생태계(CUDA) |

#### 한줄 요약

- 대규모 양산/초저전력은 **ASIC(TPU/NPU)**, 알고리즘 변경/저지연은 **FPGA**, 범용성은 **GPU**

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **VLIW/마이크로코드 제어기**: 하드웨어 배선은 고정하되, 명령어 디스패치 순서와 텐서 이동 순서를 소프트웨어로 프로그래밍할 수 있게 하여 알고리즘 변화에 유연성을 부여하는 기법.
- **Pre-Silicon Emulation (하드웨어 에뮬레이션)**: 대규모 FPGA 팜(Farm) 장비에서 ASIC 설계 RTL을 테이프아웃 전에 100% 검증하여 수백억 원의 마스크 리비전 실패를 방지하는 절차.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 어설프게 소량 생산했다가 막대한 초기 개발 비용을 건지지 못해 회사가 망하는 프로젝트 사업성 상실 위험 | 개발 착수 전 면밀한 **손익분기 수량** 엑셀 분석 및 고객사 양산 수량 개런티 확보 사전 검증 철저 수행 | 수백억이 증발하는 비효율적인 반도체 개설 투자 원천 방지 및 명확한 재무적 사업성 확보 |
| 칩을 굽고 나니 인공지능 알고리즘 트렌드가 확 바뀌어버려, 굳어버린 칩이 조기 노후화되고 고철이 될 위협 | 마이크로코드 기반 **프로그래머블 제어** 명령어 셋을 칩 내부에 심어 제어 유연성 탈출구 전략 사전 확보 | 최신 논문에서 쏟아지는 소프트웨어 수준의 모델 업데이트 꾸역꾸역 수용 및 칩 생명 연장 |
| 칩 안쪽 창고(버퍼)에서 연산기로 데이터 배달이 늦어져 비싼 연산기들이 손가락 빨며 심각한 유휴 상태 발생 | 데이터 가두기 **고정형 데이터플로우** 채택 및 데이터 핑퐁 이중 버퍼링 아키텍처로 쉴 틈 없이 밀어 넣기 구축 | 칩 내부 **연산기 가동률**을 90% 이상으로 극대화하고 때려 박은 하드웨어 자원 효율 100% 달성 |
| 수백억 주고 공장에 테이프 아웃 넘겼는데, 설계 오류가 뒤늦게 발견되어 치명적인 칩 재제조(리비전) 실패 참사 | 공장에 넘기기 전 양산 전 대규모 **에뮬레이션** 및 칩이 나오자마자 가혹한 물리적 **실리콘 검증** 절차 엄격 적용 | 시제품의 어처구니없는 논리 오류를 차단하고 수백억 원의 리비전 마스크 비용 절감 및 파산 방지 |

#### 한줄 요약

- **손익분기 분석(Break-Even)·VLIW/마이크로코드 제어·이중 버퍼링·에뮬레이션(Pre-Silicon)**

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **도메인 특화 아키텍처(Domain-Specific Architecture, DSA)**: 튜링상 수상자 헤네시와 패터슨이 제시한 포스트 무어의 법칙 시대의 핵심 패러다임으로, 범용성을 버리고 특정 소프트웨어 도메인에 100% 최적화된 하드웨어 가속기(ASIC) 구축을 의미.

</details>

- 모델 아키텍처가 검증된 대규모 서비스(데이터센터 추론, 온디바이스 AI)에서 **NPU/TPU 형태의 도메인 특화 ASIC 표준 채택**

#### 한줄 요약

- **알고리즘 안정성과 손익분기 생산 수량(BEV)**에 기반한 AI ASIC 개발 의사결정
