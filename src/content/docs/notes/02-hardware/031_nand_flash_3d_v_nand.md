## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **3D NAND**: 평면 미세화 한계를 완화하기 위해 메모리 셀을 수직(Z축)으로 적층한 낸드 플래시 구조.
- **V-NAND(Vertical NAND)**: Samsung이 사용하는 3D NAND 계열의 상표·기술 명칭.
- **2D Planar NAND**: 실리콘 기판 평면(X-Y축) 상에서 회로 선폭을 좁혀가며 집적도를 높이던 2차원 플래시 메모리.
- **CTF(Charge Trap Flash)**: 도체 부유 게이트(Floating Gate) 대신 부도체 질화막(SiN)에 전하를 트랩하여 누설 전류와 셀 간 간섭을 차단하는 기술.

</details>

- 정의/개념: 2D 평면 미세화의 한계를 완화하기 위해 낸드 셀을 수직으로 적층하는 플래시 메모리 구조. 전하 트랩·부유 게이트·주변 회로 배치는 제조사와 세대별로 다르다.
- 배경/필요성: 10nm 이하 2D 평면 낸드의 **셀 간 간섭(Cross-talk), 산화막 누설 전류 및 미세 노광 비용 한계 극복**

#### 한줄 요약

- 평면 미세화 한계를 **3차원 수직 적층(Z축)과 CTF 전하 트랩 셀**로 극복

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **HARC(High Aspect Ratio Contact) 식각**: 수백 층의 박막을 수직으로 한 번에 균일하게 뚫어내는 고난도 반도체 식각 공정.
- **COP(Cell on Peri) / PUC**: 주변부 구동 로직 회로(Peri)를 셀 하단으로 배치하여 칩 면적 효율성을 극대화하는 설계.

</details>

- CTF 등 전하 저장 구조로 전하 보존·간섭 특성을 관리하며, 효과는 셀 설계와 공정에 따라 달라짐
- 평면 면적의 과도한 축소 대신 **수직 적층 층수(Layer)**를 늘려 비트 밀도 확대
- **고종횡비 식각(HARC)**과 다중 스택 등 공정으로 고층 수직 적층의 제조 난이도 관리

#### 한줄 요약

- **CTF 셀 구조·수직 적층 층수 확장·HARC 식각**을 통한 고집적/고신뢰성 확보

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **수직 채널 스트링(Vertical Channel String)**: 수직으로 적층된 셀들을 관통하여 비트라인과 소스라인 사이를 잇는 실리콘 기둥 전류 통로.
- **Wordline Gate Stack**: 각 층마다 텅스텐(W) 금속 게이트를 형성하여 해당 높이 셀의 온/오프 및 프로그래밍을 제어하는 층.

</details>

```text
[ 3D V-NAND 수직 적층 및 COP 아키텍처 ]
┌─────────────────────────────────────────────────────────────┐
│ 비트라인 (Bitline: 수직 채널 기둥 최상단과 연결)            │
├─────────────────────────────────────────────────────────────┤
│ 층 N   : Wordline (N) ── [ CTF 전하 트랩 셀 ] ──┐            │
│ ...    : Wordline ... ── [ CTF 전하 트랩 셀 ] ──┼── Vertical │
│ 층 2   : Wordline (2) ── [ CTF 전하 트랩 셀 ] ──│   Channel  │
│ 층 1   : Wordline (1) ── [ CTF 전하 트랩 셀 ] ──┘   (Hole)   │
├─────────────────────────────────────────────────────────────┤
│ 공통 소스 라인 (Common Source Line, CSL)                     │
├─────────────────────────────────────────────────────────────┤
│ COP / PUC (주변 제어 로직 회로가 위치한 기판 최하단부)      │
└─────────────────────────────────────────────────────────────┘
```

선의 의미: 수직 채널 홀(Ch), CTF 셀, 워드라인 적층(WL) 및 하단 COP(Cell on Peri) 제어 로직 간의 3D V-NAND 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 전하 트랩 플래시 셀 | 질화막 등에 전하를 포획해 문턱 전압 상태로 데이터를 표현 |
| 수직 채널 스트링 | 적층된 수백 개의 셀을 직렬로 꿰뚫고 지나가는 물리적 수직 전류 경로 제공 |
| 워드라인 적층 | 수직 층별로 위치한 개별 셀의 프로그래밍 및 판독 동작 전압 정밀 제어 |
| 셀 언더 페리 (COP) | 주변 제어 회로를 메모리 셀 수직 기둥 하단에 배치하여 칩 면적 효율성 개선 |

#### 한줄 요약

- **CTF 셀·수직 채널 스트링·워드라인 적층 게이트·COP(Cell on Peri)** 통합

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **ISPP(Incremental Step Pulse Programming)**: 펄스 전압을 미세하게 단계별로 높이며 셀의 문턱 전압(Vth)을 정밀 제어하는 프로그램 기법.

</details>

```text
[ 3D V-NAND 제조 및 동작 파이프라인 ]
                      │
                      ▼
        [ 1. 기판 최하단 COP 제어 로직 형성 ]
                      │
                      ▼
      [ 2. 절연막(SiO2) 및 질화막(SiN) 교대 수백 층 적층 ]
                      │
                      ▼
      [ 3. HARC 고종횡비 수직 채널 홀 식각 ]
                      │
                      ▼
      [ 4. CTF 트랩막, 산화막 및 실리콘 채널 증착 ]
                      │
                      ▼
      [ 5. 질화막 제거 후 텅스텐(W) 워드라인 대체 (Gate Replacement) ]
                      │
                      ▼
      [ 6. ISPP 전압 인가를 통한 셀 프로그래밍 및 데이터 판독 ]
```

**동작 원리**

1. **COP 형성**: 실리콘 기판 상에 감지 증폭기, 디코더 등 주변 회로를 먼저 제작
2. **박막 적층**: 절연막과 질화막을 목표 층수만큼 교대로 균일하게 증착
3. **HARC 홀 식각**: 초미세 수직 구멍을 수백 층 깊이로 단번에 식각
4. **CTF 증착**: 홀 내부 표면에 전하 트랩막과 실리콘 채널을 형성
5. **ISPP 동작**: ISPP 계단식 전압 펄스를 인가하여 전자를 질화막에 주입하고 데이터 기록

#### 한줄 요약

- COP 하단 로직 형성 $\to$ **수백 층 박막 적층 $\to$ HARC 홀 식각 $\to$ ISPP 전압 기록**

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **3D NAND vs 2D Planar NAND**: 3D NAND는 수직 적층으로 밀도를 높이고, 2D NAND는 평면 미세화에 의존한다. 전하 저장 방식·내구성·간섭 수준은 셀 설계와 비트 수(TLC/QLC 등)에 따라 달라진다.

</details>

| 분류(종류) | 적용 기준 | 핵심 특징 | 제약 사항(한계) |
|:---|:---|:---|:---|
| 3D NAND | 고밀도·대용량 스토리지 | Z축 수직 적층, 공정별 전하 저장 구조 | HARC 식각·적층 정렬·수율 관리 난이도 |
| 2D Planar NAND | 기존 평면형 플래시 | X-Y 평면 미세화, 공정별 부유 게이트·CTF 적용 | 미세화에 따른 간섭·누설·리소그래피 비용 증가 |

#### 한줄 요약

- 3D V-NAND는 **수직 적층과 CTF 기반 고신뢰성**, 2D NAND는 **물리적 미세화 한계 봉착**

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **LDPC(Low-Density Parity-Check)**: TLC/QLC의 좁은 문턱 전압 산포 중첩으로 발생하는 비트 오류를 정정하는 고성능 에러 정정 알고리즘.
- **Read Retry**: 전하 누설로 셀 전압이 이동했을 때, 읽기 기준 전압을 오프셋 이동시켜 정확한 비트를 읽어내는 펌웨어 기술.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 단일 식각 깊이 한계로 인한 수직 채널 홀의 심각한 휘어짐 및 불량 | 100단 이하의 스택 단위 층을 상하로 접합하는 **다중 스택** 분할 공정 가동 | 깊은 홀 식각 결함 원천 방지 및 수백 단 초고층 양산 수율 확보 |
| 다중 레벨 셀의 미세한 전압 산포 중첩으로 인한 **원시 비트 에러율** 폭증 | 정밀 펄스 제어 및 고강도 저밀도 패리티 검사(LDPC) 오류 정정 코드 적용 | 중첩으로 인한 비트 에러 정정 및 고밀도 쿼드 레벨 데이터 정합성 보장 |
| 오랜 시간 경과 및 고온에 따른 미세 전하 유실 및 판독 불량 에러 발생 | 오프셋 전압을 변경하여 최적 전압을 탐색하는 **읽기 재시도** 펌웨어 구동 | 손상 데이터의 원형 복구 및 플래시 저장 매체의 물리적 장기 보존성 유지 |
| 수직 낸드 플래시의 쓰기 버퍼 고갈 시 전체 쓰기 속도가 급락하는 성능 저하 | 워크로드에 따라 크기가 변하는 가변 용량 싱글 레벨 셀(SLC) 동적 캐시 적용 | 쓰기 성능 편차 감소 및 쿼드 레벨 기반 대용량 파일 전송 대역폭 유지 |

#### 한줄 요약

- 고단 적층의 식각 난이도는 Multi-Stack 분할로 완화하고, 비트 오류는 LDPC 에러 정정과 Read Retry로 잡으며, 쓰기 성능은 SLC 동적 캐싱으로 유지한다.

## Ⅶ. 결론

- 대용량 스토리지에서는 3D NAND의 밀도 이점을 활용하되, 요구 내구성·지연·쓰기 패턴을 기준으로 TLC/QLC 선택, ECC 능력, 적층 세대와 컨트롤러 설계를 함께 평가한다.

#### 한줄 요약

- **수직 적층 수 확장과 LDPC 오류 정정**을 결합한 페타바이트급 스토리지 구축
