## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **3차원 수직 낸드(Three-Dimensional Vertical NAND, 3D V-NAND)**: 워드라인과 채널을 수직 적층한 구조이다.
- **2차원 낸드(Two-Dimensional NAND, 2D NAND)**: 기판 평면에서 셀 간격을 줄인 구조이다.
- **낸드(Not AND, NAND)**: 페이지 기록과 블록 삭제를 사용하는 플래시 메모리이다.

</details>

- 정의/개념: 워드라인 층을 쌓고 수직 채널로 셀을 연결해 면적당 용량을 높인 **3차원 NAND 구조**이다.
- 배경/필요성: 2D NAND의 셀 간격 축소가 간섭과 전하 누설을 키워 **평면 미세화 한계가 발생한다**.

#### 한줄 요약

- 3D V-NAND는 평면 셀 간격을 계속 줄이는 대신 워드라인 층과 수직 채널을 쌓아 집적도를 높인다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **수직 층수**: 평면 미세화 대신 위로 쌓아 집적도를 높이는 워드라인 적층 수이다.
- **셀 간섭**: 인접 셀의 전기장으로 임계 전압이 흔들리는 현상이다.
- **전하 누설**: 저장 전하가 빠져나가 셀 임계 전압이 변하는 현상이다.
- **고종횡비 식각**: 깊고 좁은 수직 채널 구멍을 여러 적층에 균일하게 뚫는 공정이다.

</details>

- 평면 미세화를 대신하는 **수직 층수 확대**가 핵심이다.
- 큰 셀 치수 기반 **셀 간섭•전하 누설 완화**가 핵심이다.
- 층수 증가에 따른 **고종횡비 식각•균일도 부담**이 핵심이다.

#### 한줄 요약

- 수직 층수 확장은 평면 셀 간격 축소 부담을 줄이지만 깊은 채널 식각과 층별 전기 특성 균일도 확보가 필요하다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **워드라인 적층**: 같은 높이의 셀 게이트를 선택하도록 층별로 배치한 배선이다.
- **전하 트랩 셀**: 절연막에 전자를 가두고 임계 전압 구간으로 비트를 표현하는 셀이다.
- **수직 채널 스트링**: 여러 적층 셀을 직렬로 연결해 비트라인으로 이어 주는 수직 통로이다.

</details>

```text
3D NAND 셀 배열 경계
|
+-- [워드라인 적층] -- [전하 저장 셀]
|                           |
`-- [페이지•블록 배열] -- [수직 채널 스트링]
```

선의 의미: 셀 배열 경계 안에서 워드라인과 수직 채널이 전하 저장 셀을 선택하고 페이지•블록 배열이 이 셀 집합을 묶는 정적 연결•포함 관계다.

| 구성요소 | 책임 |
|:---|:---|
| 워드라인 적층 | 같은 높이의 **셀 선택** |
| 전하 저장 셀 | 임계 전압으로 **비트 저장** |
| 수직 채널 스트링 | 선택 셀•**비트라인 연결** |
| 페이지•블록 배열 | 페이지 입출력•**블록 삭제** |

#### 한줄 요약

- 워드라인 층과 수직 채널이 적층 셀을 선택하고 페이지•블록 단위로 읽고 지운다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **수평 미세화**: 셀 간격과 배선 폭을 줄여 평면 집적도를 높이는 방식이다.
- **수직 적층**: 워드라인 층을 위로 쌓아 면적당 셀 수를 높이는 방식이다.
- **층수 확장**: 평면 면적을 늘리지 않고 적층 워드라인 수를 늘리는 방식이다.

</details>

```text
1. NAND 집적도 확대 목표
├─ 2D NAND
│  └─ 2. 셀 간격·배선 폭 축소
│     └─ 3. 평면 면적당 셀 증가
│        └─ 4. 셀 간섭·전하 누설 증가
└─ 3D V-NAND
   └─ 2. 워드라인 수직 적층
      └─ 3. 수직 채널로 층별 셀 연결
         └─ 4. 고종횡비 식각·층 균일도 부담
```

**동작 원리**

1. **집적도 확대 목표 설정**: 같은 평면 면적에 더 많은 NAND 셀을 배치할 확장 방식을 선택한다.
2. **확장 방향 결정**: 2D NAND는 셀 간격을 수평 축소하고 3D V-NAND는 워드라인을 수직을 적층한다.
3. **면적당 셀 수 증가**: 2D는 평면 셀 밀도를, 3D는 층수와 수직 채널의 셀 수를 확대한다.
4. **공정 한계 관리**: 2D는 셀 간섭·누설을, 3D는 깊은 채널 식각·층별 특성 편차를 제어한다.

#### 한줄 요약

- 2D NAND는 셀 간격 축소로, 3D V-NAND는 워드라인 층수 확대로 면적당 저장 용량을 높인다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **평면 미세화**: 셀 간격과 배선 폭을 줄여 2차원 면적당 용량을 높이는 방식이다.
- **층 균일도**: 적층 높이와 위치가 달라도 셀과 채널의 전기 특성이 일정한 정도이다.
- **면적당 용량**: 칩의 평면 면적 하나에 저장할 수 있는 총 데이터 양이다.

</details>

| NAND 구조 | 3D V-NAND | 2D NAND |
|:---|:---|:---|
| 적용 기준 | **고용량•고집적 SSD** | 저용량•**성숙 평면 공정** |
| 핵심 특징 | 워드라인 **수직 적층•수직 스트링** | 셀 간격 축소의 **평면 미세화** |
| 한계 | **고종횡비 식각•층 균일도** | 미세화에 따른 **셀 간섭•누설** |

> 요약: **3D 수직 적층**, **2D 평면 미세화**가 핵심이다.

#### 한줄 요약

- 고집적 SSD에는 수직 층수를 늘리는 3D V-NAND가 유리하고, 낮은 집적도의 성숙 공정에는 2D NAND가 적합하다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **원시 비트 오류**: 감지 회로가 읽은 오류 정정 코드 적용 전 비트 오류이다.
- **프로그램 간섭**: 인접 워드라인의 쓰기 전압이 다른 셀 임계 전압을 변화시키는 현상이다.
- **오류 정정 코드(Error-Correcting Code, ECC)**: 추가 검사 비트로 오류를 검출•정정하는 기법이다.
- **증분 스텝 펄스 프로그래밍(Incremental Step Pulse Programming, ISPP)**: 전압을 단계적으로 높여 목표 임계 전압에 기록하는 방식이다.
- **단일 레벨 셀 캐시(Single-Level Cell Cache, SLC 캐시)**: 셀당 1비트로 동작해 쓰기 속도를 높이는 영역이다.
- **삼중 레벨 셀(Triple-Level Cell, TLC)**: 한 셀에 3비트를 저장하는 플래시 셀 방식이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 층수가 늘어 채널 식각과 **셀 특성 편차 확대** | **층·블록별 읽기 보정값**과 불량 블록 관리 | 판독 기준 보정으로 **층별 오류 편차 감소** |
| 보존 시간과 마모 증가로 **원시 비트 오류 상승** | ECC 여유 확보, **읽기 재시도·수명 지표 감시** | 허용 오류 범위 안에서 **데이터 복구율 유지** |
| 인접 워드라인의 쓰기 전압으로 **프로그램 간섭 발생** | **ISPP 전압 단계·프로그램 순서** 조정 | 셀 상태 간 **임계 전압 분포 겹침 감소** |
| SLC 캐시를 모두 사용한 뒤 **지속 쓰기 처리량 급락** | **캐시 용량·회수 속도와 캐시 외 성능**을 분리 측정 | 장시간 부하의 **실제 지속 쓰기 성능 산정** |

> 사례: 3D TLC•ECC로 내구성 확보

#### 한줄 요약

- 데이터센터 SSD는 층·블록별 오류 편차와 SLC 캐시 외 성능을 측정하고, ECC 여유와 셀당 비트 수로 용량·내구성을 절충한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **고집적 SSD**: 제한된 칩 면적에 많은 NAND 용량을 제공하는 저장장치이다.
- **성숙 평면 공정**: 제조 경험과 수율이 안정된 2차원 NAND 생산 기술이다.

</details>

- 고집적은 **3D V-NAND**, 성숙 저용량은 **2D NAND**을 선택한다.

#### 한줄 요약

- 같은 면적의 용량은 층수로 늘리고 오류 여유는 셀당 비트 수와 ECC로 지킨다.
