## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **3D NAND**: 평면 미세화 한계를 완화하기 위해 메모리 셀을 수직(Z축)으로 적층한 낸드 플래시 구조.
- **V-NAND(Vertical NAND)**: Samsung이 사용하는 3D NAND 계열의 상표·기술 명칭.
- **2D Planar NAND**: 실리콘 기판 평면(X-Y축) 상에서 회로 선폭을 좁혀가며 집적도를 높이던 2차원 플래시 메모리.
- **CTF(Charge Trap Flash)**: 도체 부유 게이트(Floating Gate) 대신 부도체 질화막(SiN)에 전하를 트랩하여 누설 전류와 셀 간 간섭을 차단하는 기술.

</details>

- 정의/개념: 평면 미세화 한계를 극복하기 위해 메모리 셀을 **수직(Z축)으로 적층**하고 **CTF 전하 트랩**을 적용한 플래시 메모리 구조
- 배경/필요성: 2D 평면 미세화가 진행될수록 셀 간격이 줄어 **간섭·전하 누설** 증가

#### 한줄 요약

- 3D NAND는 평면 선폭을 계속 줄이는 대신 셀을 수직으로 쌓아 비트 밀도를 높인다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **HARC(High Aspect Ratio Contact) 식각**: 수백 층의 박막을 수직으로 한 번에 균일하게 뚫어내는 고난도 반도체 식각 공정.
- **COP(Cell on Peri) / PUC**: 주변부 구동 로직 회로(Peri)를 셀 하단으로 배치하여 칩 면적 효율성을 극대화하는 설계.

</details>

- **CTF 전하 트랩 셀**로 전하 누설 및 인접 셀 간 간섭 억제
- 평면 면적의 과도한 축소 대신 **수직 적층 층수(Layer)** 를 늘려 비트 밀도 확대
- 적층 수가 늘수록 **고종횡비 식각(HARC)** 과 수직 채널 균일도 관리 난이도 증가

#### 한줄 요약

- 전하 트랩 셀은 층별 워드라인과 수직 채널을 공유하며, 적층 수가 늘수록 식각 균일도 관리가 중요해진다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **수직 채널 스트링(Vertical Channel String)**: 수직으로 적층된 셀들을 관통하여 비트라인과 소스라인 사이를 잇는 실리콘 기둥 전류 통로.
- **Wordline Gate Stack**: 각 층마다 텅스텐(W) 금속 게이트를 형성하여 해당 높이 셀의 온/오프 및 프로그래밍을 제어하는 층.

</details>

```text
[ 3D V-NAND 수직 적층 및 COP 아키텍처 ]
┌─────────────────────────────────────────────────────────────┐
│ 비트라인 (Bitline: 수직 채널 기둥 최상단과 연결)            │
├─────────────────────────────────────────────────────────────┤
│ 층 N   : Wordline (N) ── [ CTF 전하 트랩 셀 ] ──┐            │
│..    : Wordline.. ── [ CTF 전하 트랩 셀 ] ──┼── Vertical │
│ 층 2   : Wordline (2) ── [ CTF 전하 트랩 셀 ] ──│   Channel  │
│ 층 1   : Wordline (1) ── [ CTF 전하 트랩 셀 ] ──┘   (Hole)   │
├─────────────────────────────────────────────────────────────┤
│ 공통 소스 라인 (Common Source Line, CSL)                     │
├─────────────────────────────────────────────────────────────┤
│ COP / PUC (주변 제어 로직 회로가 위치한 기판 최하단부)      │
└─────────────────────────────────────────────────────────────┘
```

선의 의미: 수직 채널 홀(Ch), CTF 셀, 워드라인 적층(WL) 및 하단 COP(Cell on Peri) 제어 로직 간의 3D V-NAND 구조도.

| 구성요소 | 책임 |
|:---|:---|
| 전하 트랩 플래시 셀 | 질화막 등에 전하를 포획해 문턱 전압 상태로 데이터를 표현 |
| 수직 채널 스트링 | 적층된 수백 개의 셀을 직렬로 꿰뚫고 지나가는 물리적 수직 전류 경로 제공 |
| 워드라인 적층 | 수직 층별로 위치한 개별 셀의 프로그래밍 및 판독 동작 전압 정밀 제어 |
| 셀 언더 페리 (COP) | 주변 제어 회로를 메모리 셀 수직 기둥 하단에 배치하여 칩 면적 효율성 개선 |

#### 한줄 요약

- 수직 채널이 여러 층의 전하 트랩 셀을 직렬 연결하고, COP 구조는 주변 회로를 셀 배열 아래에 배치한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **다중 스택(Multi-Stack)**: 전체 적층을 여러 구간으로 나눠 식각·접합해 단일 고종횡비 식각 부담을 줄이는 공정.

</details>

```text
[ 3D V-NAND 제조 및 동작 파이프라인 ]
                      │
                      ▼
        [ 1. 주변 회로 및 박막 적층 ]
                      │
                      ▼
        [ 2. HARC 수직 채널 홀 식각 ]
                      │
                      ▼
        [ 3. 전하 트랩막 및 채널 형성 ]
                      │
                      ▼
        [ 4. 워드라인 게이트 형성·스택 접합 ]
```

**동작 원리**

1. **주변 회로 및 박막 적층**: 주변 로직과 워드라인용 절연막·희생막 구조 형성
2. **HARC 수직 채널 홀 식각**: 적층막을 관통하는 고종횡비 채널 홀 형성
3. **전하 트랩막 및 채널 형성**: 홀 내부에 전하 저장막과 수직 채널 증착
4. **워드라인 게이트 형성·스택 접합**: 희생막을 게이트로 치환하고 다중 스택 구간 연결

#### 한줄 요약

- 적층막을 수직으로 식각해 채널과 전하 트랩막을 형성하고, 층별 워드라인을 연결해 셀 스트링을 완성한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **3D NAND vs 2D Planar NAND**: 3D NAND는 수직 적층으로 밀도를 높이고, 2D NAND는 평면 미세화에 의존한다. 전하 저장 방식·내구성·간섭 수준은 셀 설계와 비트 수(TLC/QLC 등)에 따라 달라진다.

</details>

| 구조 유형 | 3D NAND | 2D Planar NAND |
|:---|:---|:---|
| 적용 기준 | 고밀도·대용량 엔터프라이즈 스토리지 | 저용량 레거시 임베디드 장치 |
| 핵심 특징 | Z축 수직 적층 및 **CTF 전하 트랩** 적용 | X-Y 평면 미세화 및 부유 게이트 적용 |
| 한계 | **HARC 식각** 및 다중 스택 수율 관리 난이도 | 셀 간 간섭 및 물리적 미세화 한계 |

#### 한줄 요약

- 3D NAND는 수직 적층으로 밀도를 확장하고, 2D NAND는 평면 미세화에 따른 셀 간섭 한계가 크다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **LDPC(Low-Density Parity-Check)**: TLC/QLC의 좁은 문턱 전압 산포 중첩으로 발생하는 비트 오류를 정정하는 고성능 에러 정정 알고리즘.
- **Read Retry**: 전하 누설로 셀 전압이 이동했을 때, 읽기 기준 전압을 오프셋 이동시켜 정확한 비트를 읽어내는 펌웨어 기술.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 적층 증가로 수직 채널 식각 편차·불량 증가 | **다중 스택** 분할 식각·접합 정렬 | 단일 식각 종횡비 완화·수율 개선 |
| 다중 레벨 셀의 문턱 전압 분포 중첩 | 정밀 프로그램 제어·**LDPC** 적용 | 비트 오류 정정 범위 확대 |
| 시간·고온에 따른 전하 손실로 판독 실패 | 기준 전압을 조정하는 **Read Retry** 적용 | 이동한 문턱 전압의 판독 가능성 회복 |

#### 한줄 요약

- 다중 스택은 식각 부담을 나누고, LDPC와 Read Retry는 적층·다중 비트 셀에서 증가하는 판독 오류를 보완한다.

## Ⅶ. 결론

- 고밀도 낸드는 **3D NAND**를 기본으로 하되 적층 수 자체보다 HARC 수율·채널 편차·판독 오류를 함께 검증하고, **2D NAND**는 성숙 공정이 필요한 저밀도·레거시 용도에 한정

#### 한줄 요약

- 3D NAND의 경쟁력은 층수만이 아니라 적층 수율과 오류 정정 이후의 지연·내구성을 함께 만족하는 데 있다.
