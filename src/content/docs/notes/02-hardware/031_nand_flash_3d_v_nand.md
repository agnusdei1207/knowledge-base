## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **3D NAND**: 평면 미세화 한계를 완화하기 위해 메모리 셀을 수직(Z축)으로 적층한 낸드 플래시 구조.
- **V-NAND(Vertical NAND)**: Samsung이 사용하는 3D NAND 계열의 상표·기술 명칭.
- **2D Planar NAND**: 실리콘 기판 평면(X-Y축) 상에서 회로 선폭을 좁혀가며 집적도를 높이던 2차원 플래시 메모리.
- **CTF(Charge Trap Flash)**: 도체 부유 게이트(Floating Gate) 대신 부도체 질화막(SiN)에 전하를 트랩하여 누설 전류와 셀 간 간섭을 차단하는 기술.

</details>

- 정의/개념: 평면 미세화 한계를 우회하려 셀을 수직으로 쌓고 **CTF(Charge Trap Flash)**로 전하를 가둔 **3D NAND** 구조
- 배경/필요성: **2D Planar NAND**는 선폭을 줄일수록 셀 간격이 좁아져 간섭과 전하 누설이 함께 늘어 밀도 향상이 멈춤

#### 한줄 요약
- 수직 적층은 미세화의 연장이 아니라 포기이며, 선폭을 오히려 되돌려 여유를 확보한 뒤 높이로 밀도를 되찾는 방향 전환이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **HARC(High Aspect Ratio Contact) 식각**: 수백 층의 박막을 수직으로 한 번에 균일하게 뚫어내는 고난도 반도체 식각 공정.
- **COP(Cell on Peri) / PUC**: 주변부 구동 로직 회로(Peri)를 셀 하단으로 배치하여 칩 면적 효율성을 극대화하는 설계.

</details>

- CTF 셀이 부도체 질화막에 전하를 가두어 누설과 인접 셀 간섭을 억제
- 평면 축소 대신 적층 층수를 늘려 같은 면적에서 비트 밀도 확대
- 적층 수가 늘수록 **HARC(High Aspect Ratio Contact) 식각**과 수직 채널 균일도 관리 난이도 급증

#### 한줄 요약
- 밀도 경쟁의 무대가 노광 해상도에서 식각 균일도로 옮겨 갔으며, 그래서 3D NAND의 경쟁력은 설계보다 공정 능력에서 갈린다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **수직 채널 스트링(Vertical Channel String)**: 수직으로 적층된 셀들을 관통하여 비트라인과 소스라인 사이를 잇는 실리콘 기둥 전류 통로.
- **Wordline Gate Stack**: 각 층마다 텅스텐(W) 금속 게이트를 형성하여 해당 높이 셀의 온/오프 및 프로그래밍을 제어하는 층.

</details>

```text
[3D V-NAND 셀 구조]
├─ 비트라인 (수직 채널 최상단 연결)
├─ 워드라인 적층
│  ├─ 층 N ─ CTF 셀
│  ├─ ⋮
│  └─ 층 1 ─ CTF 셀
├─ 수직 채널 스트링 (전 층을 관통하는 실리콘 기둥)
├─ 공통 소스 라인 (CSL)
└─ COP·PUC (셀 하단 주변 제어 로직)
```

선의 의미: 가지(`├─`)는 소유 관계이며, 수직 채널 스트링만이 모든 워드라인 층을 세로로 가로지름

| 구성요소 | 책임 |
|:---|:---|
| CTF 셀 | 질화막에 전하를 포획해 문턱 전압으로 데이터 표현 |
| **수직 채널 스트링(Vertical Channel String)** | 적층된 셀 전체를 직렬로 잇는 수직 전류 경로 제공 |
| **Wordline Gate Stack** | 층별 게이트 전압으로 해당 높이 셀의 프로그램·판독 제어 |
| **COP(Cell on Peri) / PUC** | 주변 제어 회로를 셀 하단에 배치해 칩 면적 효율 개선 |

#### 한줄 요약
- 셀이 하나의 기둥에 직렬로 꿰여 있으므로 한 층의 결함이 그 스트링 전체를 못 쓰게 만들며, 적층 수가 늘수록 결함 하나의 파급 범위도 함께 커진다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **다중 스택(Multi-Stack)**: 전체 적층을 여러 구간으로 나눠 식각·접합해 단일 고종횡비 식각 부담을 줄이는 공정.

</details>

```text
주변 회로 형성 후 절연막·희생막 적층
        │
   목표 층수를 한 번에 뚫을 수 있는가?
   ┌────┴─────┐
  예           아니오
   │             │
단일 HARC 식각   다중 스택으로 구간 분할
   │             │
   │        구간별 식각 후 접합 정렬
   └────┬────────┘
        │
  홀 내부에 전하 트랩막·수직 채널 증착
        │
  희생막을 금속 게이트로 치환해 워드라인 형성
```

분기 결과: 단일 식각은 공정이 단순하지만 종횡비가 임계를 넘으면 상하 구멍 지름이 어긋나고, **다중 스택(Multi-Stack)**은 그 부담을 나누는 대신 구간 접합 정렬이라는 새로운 불량 요인을 도입

#### 한줄 요약
- 적층 수를 늘리는 일은 공정 단계를 더하는 것이 아니라 실패 지점을 바꾸는 일이며, 세대마다 병목이 식각에서 접합으로 옮겨 다닌다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **비트 밀도 확장 방식(Bit Density Scaling)**: 밀도를 높이는 방향을 평면 축소로 잡을지 수직 적층으로 잡을지 가르는 기준으로, 3D NAND는 수직 적층으로 밀도를 높이고, 2D NAND는 평면 미세화에 의존한다. 전하 저장 방식·내구성·간섭 수준은 셀 설계와 비트 수(TLC/QLC 등)에 따라 달라진다.

</details>

| **비트 밀도 확장 방식** | 3D NAND | 2D Planar NAND |
|:---|:---|:---|
| 적용 기준 | 고밀도·대용량 엔터프라이즈 스토리지 | 저용량 레거시 임베디드 장치 |
| 핵심 특징 | Z축 수직 적층과 CTF 전하 트랩 적용 | X-Y 평면 미세화와 부유 게이트 적용 |
| 한계 | HARC 식각과 다중 스택 수율 관리 난이도 | 셀 간 간섭과 물리적 미세화 한계 |

#### 한줄 요약
- 2D가 남아 있는 이유는 성능이 아니라 성숙한 공정의 낮은 불량률이며, 소용량 임베디드에서는 밀도보다 이 예측 가능성이 값지다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **LDPC(Low-Density Parity-Check)**: TLC/QLC의 좁은 문턱 전압 산포 중첩으로 발생하는 비트 오류를 정정하는 고성능 에러 정정 알고리즘.
- **Read Retry**: 전하 누설로 셀 전압이 이동했을 때, 읽기 기준 전압을 오프셋 이동시켜 정확한 비트를 읽어내는 펌웨어 기술.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 적층 증가로 수직 채널 식각 편차·불량 증가 | **다중 스택** 분할 식각·접합 정렬 | 단일 식각 종횡비 완화·수율 개선 |
| 다중 레벨 셀의 문턱 전압 분포 중첩 | 정밀 프로그램 제어·**LDPC** 적용 | 비트 오류 정정 범위 확대 |
| 시간·고온에 따른 전하 손실로 판독 실패 | 기준 전압을 조정하는 **Read Retry** 적용 | 이동한 문턱 전압의 판독 가능성 회복 |

#### 한줄 요약
- **LDPC(Low-Density Parity-Check)**와 **Read Retry**가 필수가 됐다는 사실은 낸드가 이미 오류를 전제로 설계된다는 뜻이며, 정정 능력이 곧 저장 밀도의 상한을 정한다.

## Ⅶ. 결론

- 고밀도 낸드는 **3D NAND**·**V-NAND(Vertical NAND)** 계열을 기본으로 하되 층수보다 식각 수율·채널 편차·판독 오류를 함께 검증하고, 2D 평면 구조는 성숙 공정이 필요한 저밀도·레거시 용도로 한정

#### 한줄 요약
- 층수는 마케팅 수치이고 실제 원가를 정하는 것은 수율이므로, 층수 경쟁의 승패는 공정 안정화 속도에서 갈린다.
