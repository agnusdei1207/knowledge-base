## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **동적 램(Dynamic Random Access Memory, DRAM)**: 트랜지스터 1개+커패시터 1개(1T1C) 셀로 비트를 저장하고 주기적 리프레시가 필요한 휘발성 메모리.
- **정적 램(Static Random Access Memory, SRAM)**: 6개 트랜지스터(6T) 래치 셀로 전원 공급 중 데이터를 안정 유지하는 휘발성 메모리.
- **휘발성 메모리(Volatile Memory)**: 전원이 끊기면 저장 데이터가 사라지는 메모리.

</details>

- 정의/개념: 커패시터의 **전하 충전(1T1C)** 또는 플립플롭의 **래치 회로(6T)**로 비트를 저장하는 휘발성 반도체 기억소자
- 배경/필요성: 단일 기억소자로는 **접근 속도(SRAM)**와 **고집적 대용량(DRAM)**의 물리적 동시 달성 불가

#### 한줄 요약
- DRAM은 작은 셀로 대용량을 담고 SRAM은 큰 회로로 빠르게 읽으므로, 보통 DRAM은 주기억장치에 SRAM은 캐시에 배치된다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **1T1C 셀(One Transistor-One Capacitor Cell)**: DRAM 비트를 트랜지스터 1개와 커패시터 1개로 구성하는 최소 셀; 고집적 가능.
- **6T 셀(Six-Transistor Cell)**: SRAM 래치와 접근 경로를 6개 트랜지스터로 구성하는 셀; 래치 안정성 우수.
- **리프레시(Refresh)**: DRAM 커패시터의 누설 전하를 주기적으로 재충전해 데이터를 보존하는 동작; 접근 지연 원인.

</details>

- **1T1C 셀**로 고집적 대용량 구현 및 주기적 리프레시 수행
- **6T 래치 셀**로 비파괴 판독 및 초고속 접근 지원
- 동일 공정에서 DRAM은 비트당 면적·비용 낮고, SRAM은 비트당 지연 낮음

#### 한줄 요약
- DRAM은 저장 셀이 작아 용량을 키우기 쉽지만 주기적으로 되살려야 하고, SRAM은 전원 중 래치 상태를 바로 읽을 수 있다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **커패시터(Capacitor)**: 전하를 저장해 DRAM 셀의 논리 상태를 표현하는 소자.
- **감지 증폭기(Sense Amplifier)**: 비트라인의 작은 전압 차이를 논리 1·0으로 증폭하고 DRAM 판독 후 복원하는 회로.
- **교차 결합 인버터(Cross-Coupled Inverter)**: SRAM 내부에서 두 인버터의 출력을 서로의 입력으로 연결해 두 안정 상태를 유지하는 회로.

</details>

```text
[메모리 셀 구조]
├─ DRAM (1T1C)
│  ├─ 접근 트랜지스터 (워드라인 제어)
│  ├─ 커패시터  (전하 저장)
│  └─ 감지 증폭기  (전압 차이 증폭·복원)
└─ SRAM (6T)
   ├─ 교차 결합 인버터  (래치 상태 유지)
   └─ 접근 트랜지스터 (워드라인 제어)
```

선의 의미: 가지(`├─`)는 소유·구성 관계; DRAM과 SRAM은 대안 셀 구조

| 구성요소 | 책임 |
|:---|:---|
| DRAM **커패시터** | 전하 저장으로 비트 상태 표현 |
| DRAM **감지 증폭기** | 전하 차이 증폭·**파괴적 판독** 후 복원 |
| SRAM 교차 결합 인버터 | 전원 공급 중 래치 상태 유지·**비파괴 판독** |
| 접근 트랜지스터 | 워드라인 신호로 읽기·쓰기 연결 |

#### 한줄 요약
- DRAM은 전하의 양을 읽고 복원하는 셀이고, SRAM은 인버터의 두 안정 상태를 직접 읽는 셀이다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **파괴적 판독(Destructive Read)**: DRAM 읽기 과정에서 셀 전하가 변해 판독 후 원래 전하를 복원해야 하는 방식.
- **비파괴적 판독(Non-Destructive Read)**: SRAM 읽기에서 래치 상태가 변하지 않아 복원 불필요한 방식.
- **프리차지(Precharge)**: 다음 DRAM 행 접근 전 비트라인 전압을 기준값(Vdd/2)으로 초기화하는 동작.

</details>

```text
워드라인 활성화
      │
      ├─ 1. DRAM 판독 및 재충전
      │      │
      │  커패시터 전하 공유 → 감지 증폭기 판정 → 셀 전하 복원 → 프리차지
      │
      └─ 2. SRAM 비파괴 판독
             │
         교차 결합 인버터 차동값 감지 → 데이터 즉시 반환 (복원 불필요)
```

**동작 원리**

1. **DRAM 판독 및 재충전**: 비트라인 전하 공유 후 증폭 판정, 파괴적 판독 보상
2. **SRAM 비파괴 판독**: 워드라인 활성화 후 교체 결합 래치 차동값 판정

#### 한줄 요약
- DRAM은 읽은 전하를 다시 채우는 절차가 필요하지만 SRAM은 래치 상태를 그대로 읽으므로 읽기 경로가 단순하다.

## Ⅴ. 종류 및 비교

| 메모리 유형 | DRAM | SRAM |
|:---|:---|:---|
| 적용 기준 | 대용량 주기억장치·메모리 채널 | 저지연 캐시·고속 레지스터 버퍼 |
| 핵심 특징 | **1T1C** 고집적·**리프레시** 필요 | **6T** 래치·**비파괴 판독** |
| 한계 | 리프레시·복원 지연·제어 회로 비용 | 셀 면적·누설 전력·낮은 집적도 |

#### 한줄 요약
- 많은 데이터를 낮은 비용으로 저장하면 DRAM, 프로세서 가까이에서 빠르게 반복 접근하면 SRAM이 적합하다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **행 적중(Row Hit)**: 이미 활성화된 DRAM 행에서 필요한 열에 접근해 행 활성화 비용을 줄이는 상황.
- **Row Hammer**: 특정 DRAM 행을 반복 활성화해 인접 행의 커패시터 전하에 간섭해 오류 가능성을 높이는 현상.
- **오류 정정 코드(Error Correcting Code, ECC)**: 저장·전송 데이터의 오류를 검출·정정하는 코드.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **리프레시**로 유효 대역폭 손실 | 리프레시 스케줄·뱅크 분산 조정 | 유효 대역폭 손실 완화 |
| 반복 행 전환으로 활성화 비용 증가 | **행 적중** 중심 요청 스케줄링 | 행 전환 지연 감소 |
| **Row Hammer**로 인접 셀 오류 가능 | 완화 정책(PARA·TRR)·**ECC** 적용 | 오류 검출·정정 |
| SRAM 캐시의 면적·누설 전력 증가 | 캐시 용량·전력 차단 단위 최적화 | 지연·면적·전력 균형 |

#### 한줄 요약
- DRAM은 리프레시와 행 배치를, SRAM은 셀 면적과 누설 전력을 관리해야 각자의 장점을 유지할 수 있다.

## Ⅶ. 결론

- 저지연 반복 접근은 **SRAM 캐시**, 대용량 집적은 **DRAM 주기억장치** 선택

#### 한줄 요약
- DRAM과 SRAM의 선택은 우열이 아니라, 저장 용량을 확보할지 접근 시간을 줄일지에 따라 계층별 역할을 나누는 결정이다.
