## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **DRAM(Dynamic RAM)**: 1개의 트랜지스터와 1개의 커패시터(1T1C)로 구성되어 높은 집적도를 가지나 주기적 리프레시가 필요한 휘발성 메모리.
- **SRAM(Static RAM)**: 6개의 트랜지스터(6T) 래치 회로로 구성되어 리프레시 없이 전원 공급 중 데이터를 유지하는 초고속 캐시 메모리.
- **휘발성(Volatility)**: 전원 공급이 차단되면 저장된 데이터가 즉시 소멸되는 특성.

</details>

- 정의/개념: 커패시터 전하 기반의 고밀도·대용량 DRAM(1T1C)과 플립플롭 래치 기반의 초고속·저지연 SRAM(6T)의 물리 구조 및 동작 특성을 비교하는 반도체 메모리 분류
- 배경/필요성: 단일 반도체로는 초고속 접근과 대용량 집적도를 동시에 만족할 수 없어 **캐시(SRAM)와 메인 메모리(DRAM)의 계층적 역할 분담 필수**

#### 한줄 요약

- 1T1C 커패시터 기반 **DRAM(대용량 주기억)**과 6T 래치 기반 **SRAM(초고속 캐시)** 비교

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **파괴적 판독(Destructive Read)**: DRAM 셀의 전하를 비트라인으로 방출해 읽는 순간 데이터가 파괴되어 센스 앰프를 통한 재충전(Restore)이 필수인 특성.
- **비파괴 판독(Non-Destructive Read)**: SRAM 래치의 차동 전압 상태를 그대로 읽어내어 셀 데이터가 보존되는 특성.

</details>

- **1T1C 셀** 구조의 DRAM은 집적도가 월등히 높아 작은 다이 면적에 대용량 주기억장치 구현 가능
- **6T 래치** 구조의 SRAM은 **비파괴 판독**과 상태 유지를 통해 1~10ns 수준의 초저지연 캐시 접근 지원
- DRAM은 커패시터 누설 전류 보충을 위해 **복원(Restore)** 및 주기적인 **리프레시(Refresh)** 동작 필수

#### 한줄 요약

- DRAM은 **파괴적 판독과 리프레시(1T1C)**, SRAM은 **비파괴 판독과 초저지연(6T)**

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **감지 증폭기(Sense Amplifier)**: DRAM 비트라인의 미세한 전하 변화를 감지하여 0/1 논리 전압으로 증폭하고 셀로 다시 복원하는 회로.
- **교차 결합 인버터(Cross-coupled Inverters)**: SRAM 셀 내부에서 2개의 인버터가 상호 피드백을 형성하여 쌍안정 상태를 유지하는 회로.

</details>

```text
[ 메모리 셀 구조 비교 ]
+------------------------------------+     +------------------------------------+
| DRAM (1T1C 셀 구조)                |     | SRAM (6T 래치 구조)                |
|                                    |     |                                    |
| [ 워드라인 (Wordline) ]            |     | [ 워드라인 (Wordline) ]            |
|       │                            |     |       │                            |
|       ▼                            |     |       ▼                            |
| [ Access Transistor ] ── [커패시터]|     | [ Access Transistor 쌍 ]           |
|       │                            |     |       │                            |
| [ 비트라인 (Bitline) ]             |     | [ 교차 결합 인버터 래치 회로 (4T) ] |
+------------------------------------+     +------------------------------------+
```

선의 의미: 1T1C 셀 기반 DRAM(워드라인/비트라인/감지증폭기)과 6T 래치 기반 SRAM의 내부 회로 구조 비교.

| 구성요소 | 책임 |
|:---|:---|
| DRAM 커패시터 | 전하 저장(충전/방전)을 통해 1비트 데이터 표현 |
| DRAM 감지 증폭기 | 미세 전하 감지, 0/1 전압 증폭 및 데이터 원상 복원 |
| SRAM 6T 래치 | 쌍안정 인버터 루프로 전원 유지 시 데이터 영구 보존 |
| 비트라인 / 워드라인 | 행 선택 게이트 활성화 및 열 데이터 읽기/쓰기 전송 |

#### 한줄 요약

- **DRAM 1T1C(커패시터 충방전)** vs **SRAM 6T(인버터 교차 래치)** 회로 비교

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Precharge (프리차지)**: 다음 행(Row)을 활성화하기 위해 비트라인 전압을 $V_{DD}/2$ 레벨로 균등화하는 초기화 단계.

</details>

```text
[ 메모리 셀 읽기 동작 흐름 ]
+-------------------------------------------------------------------------+
| 1. DRAM 읽기 : Row Active ──> Sense & Restore ──> Column Read ──> Precharge |
+-------------------------------------------------------------------------+
                                     │
                                     ▼
+-------------------------------------------------------------------------+
| 2. SRAM 읽기 : Wordline Active ──> Bitline 차동 전압 감지 ──> 즉시 반환 |
+-------------------------------------------------------------------------+
```

**동작 원리**

1. **DRAM 읽기**: Row Active로 커패시터 전하 방출 $\to$ 감지 증폭기로 증폭 및 커패시터 재충전 $\to$ Column 읽기 $\to$ 다음 접근을 위한 Precharge 수행
2. **SRAM 읽기**: Wordline을 켜는 즉시 래치의 $Q, \bar{Q}$ 신호가 Bitline 차동 전압으로 방출되어 수 사이클 내 즉시 데이터 반환 (복원/프리차지 불필요)

#### 한줄 요약

- DRAM은 **Row Active $\to$ Sense/Restore $\to$ Precharge**, SRAM은 **Wordline 인출**

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **DDR/LPDDR vs L1/L2 Cache**:
  - DRAM: 주기억장치(DDR5), 모바일(LPDDR5), 고대역폭(HBM)
  - SRAM: CPU 레지스터, L1/L2/L3 온칩 캐시

</details>

| 비교 항목 | DRAM (Dynamic RAM) | SRAM (Static RAM) |
|:---|:---|:---|
| 적용 기준 | 대용량 메인 메모리, 모바일 시스템, 그래픽 버퍼 (DDR/HBM) | 극초저지연 L1/L2/L3 온칩 캐시, CPU 레지스터, 고속 라우터 버퍼 |
| 핵심 특징 | 1T1C 구조로 초고집적도 달성, 커패시터 전하 기반 데이터 저장 | 6T 래치 구조로 나노초 수준 접근 속도 제공, 비파괴 판독 수행 |
| 한계 | 전하 누설로 인한 주기적 리프레시 필수, 파괴적 판독으로 복원 지연 발생 | 넓은 다이 면적 차지로 대용량 집적 불가, 지속적인 정적 누설 전력 발생 |

#### 한줄 요약

- DRAM은 **대용량 메인 메모리(DDR/HBM)**, SRAM은 **초고속 온칩 캐시(L1/L2/L3)** 적용

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Row Hammer**: DRAM의 특정 행을 반복 활성화하여 인접 행의 커패시터 전하 누설을 유발하는 하드웨어 취약점(TRR 기술로 방어).

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 전체 뱅크 **리프레시** 구동 시 중앙처리장치의 메모리 접근 일시 정지 | 뱅크 분산 리프레시 및 온도 가변 기반의 지능적 재충전율 적용 | 리프레시 정체 지연 오버헤드 삭감 및 메모리 유효 대역폭 확보 |
| 잦은 메모리 행 변경으로 인한 프리차지 동작 오버헤드 및 성능 지연 | 제어기의 **행 적중** 기반 명령 인터리빙 스케줄링 기법 채택 | 동일 행 연속 접근 시 오버헤드 은닉 및 데이터 전송률 획기적 향상 |
| 미세 공정 정적 램 캐시 모듈의 대기 상태 **정적 누설 전력** 폭증 현상 | 슬립 모드 전환을 유도하는 블록 단위의 **전력 차단** 회로 동적 연동 | 미사용 캐시 모듈의 전력 소모 차단 및 배터리 시스템 효율 개선 |
| 셀 소형화 및 입자 충돌에 의한 방사선 데이터 비트 반전 소프트 오류 | 고신뢰성을 요구하는 칩 내부 **오류 정정 코드** 인코딩 내장 | 하드웨어 데이터 정합성 보장 및 1비트 소프트 오류 완벽 자동 정정 |

#### 한줄 요약

- **분산 리프레시·Row Hit 인터리빙·Power Gating·On-die ECC**로 병목 극복

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **메모리 월과 융합**: 프로세서와 DRAM 간 속도 격차를 줄이기 위해 3D HBM 적층과 PIM(Processing-In-Memory) 연산 융합 메모리로 발전.

</details>

- 극초저지연 온칩 캐싱에는 **SRAM**, 대용량 고대역폭 메인 메모리에는 **DRAM(DDR5/LPDDR5/HBM) 채택**

#### 한줄 요약

- **지연시간, 집적도, 비트당 단가**에 맞춘 SRAM/DRAM 계층 최적 배치
