## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **임의 접근 기억장치(Random Access Memory, RAM)**: 물리적 저장 위치와 무관하게 동일한 접근 시간으로 데이터 읽기·쓰기가 가능한 주기억·캐시 계층의 핵심 반도체 휘발성 메모리.
- **동적 램(Dynamic Random Access Memory, DRAM)**: 1개의 트랜지스터와 1개의 커패시터(1T1C)로 전하를 충·방전하여 비트를 저장하며 유전체 누설 방지를 위해 주기적 재충전이 요구되는 고집적 메모리.
- **정적 램(Static Random Access Memory, SRAM)**: 상호 결합된 인버터 래치 회로(6T)의 전압 상태로 비트를 저장하여 전원 공급 중 리프레시 없이 서브 나노초 판독을 보장하는 초고속 캐시 메모리.
- **래치 기반(Latch-based)**: 데이터를 커패시터 전하로 담아두는 DRAM과 달리, 인버터 회로의 전압 레벨(High/Low) 상태를 지속 유지(Latch)하여 리프레시 없이 즉각적인 비파괴 판독을 지원하는 회로 구조.

</details>

- 정의/개념: 저장 위치와 무관하게 동일 접근 시간을 제공하는 **임의 접근 기억장치(RAM)** 환경에서, 1T1C 커패시터 전하로 고집적을 달성하는 **DRAM**과 6T 인버터 래치 회로로 초저지연을 보장하는 **SRAM**으로 구성된 **반도체 휘발성 메모리**
- 배경/필요성: 6T SRAM의 대형 셀 면적에 따른 고비용 한계와 1T1C DRAM의 파괴 판독 및 재충전 지연을 상호 절충하기 위한 온칩 캐시·메인 메모리 역할 분담 체계 확립

#### 한줄 요약
- 고집적 대용량의 DRAM과 초고속 온칩 캐시인 SRAM이 상호보완하여 메모리 계층 구조를 형성한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **1T1C 소형 셀**: 트랜지스터 1개와 커패시터 1개 구조로 실리콘 다이 면적을 최소화하여 대용량 비트 집적을 지원하는 DRAM 단위 소자.
- **6T 래치 셀**: 4개의 인버터 트랜지스터와 2개의 접근 트랜지스터로 구성되어 전하 복원 지연 없이 1클록 판독을 제공하는 SRAM 단위 소자.
- **리프레시(Refresh)**: 커패시터 유전체의 자연 방전으로 인한 데이터 소실을 방지하기 위해 주기적으로 전체 행을 읽어 재충전하는 동작.

</details>

- DRAM은 **1T1C 소형 셀** 구조로 실리콘 다이 면적을 최소화하여 시스템 주기억장치에 필요한 저장 밀도 극대화
- SRAM은 **6T 래치 셀**의 상호 피드백 전압 유지를 통해 전하 복원 과정 없는 1사이클 비파괴 고속 판독 보장
- 커패시터 자연 방전에 따른 **주기적 리프레시** 필수성과 전원 인가 중 무리프레시 쌍안정 전압 유지의 특성 대비

#### 한줄 요약
- DRAM은 면적이 작아 대용량 구축에 유리하고, SRAM은 복원 지연이 없어 1클록 온칩 캐시에 유리하다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **스토리지 커패시터(Storage Capacitor)**: 절연 유전체 사이에 전하($Q=CV$)를 축적하여 1비트의 논리 전압 레벨을 물리적으로 보관하는 DRAM 셀의 저장 소자.
- **열 감지 증폭기(Column Sense Amplifier)**: 비트라인 열에 공유 배치되어 셀 판독 시 미세 차동 전압을 감지 증폭하고 파괴된 커패시터 전하를 재충전하는 복원 회로.
- **교차 결합 인버터(Cross-Coupled Inverter)**: 2개의 CMOS 인버터가 서로의 입출력을 교차 연결하여 전원 공급 중 High/Low 전압을 유지하는 SRAM의 쌍안정 래치 회로.
- **접근 트랜지스터(Access Transistor)**: 워드라인(WL) 전압 제어로 온칩 래치 또는 커패시터를 외부 비트라인(BL)에 전기적으로 연결하는 스위칭 소자.

</details>

```text
[DRAM vs SRAM 셀 아키텍처]
  │
  ├─ [DRAM 셀 구조 (1T1C)]
  │     ├─ [스토리지 커패시터] (1C 전하 축적 Q=CV)
  │     ├─ [접근 트랜지스터] (1T 워드라인 게이팅)
  │     └─ [열 감지 증폭기] (비트라인 증폭·재충전)
  │
  └─ [SRAM 셀 구조 (6T)]
        ├─ [교차 결합 인버터] (4T 쌍안정 래치 유지)
        └─ [접근 트랜지스터 쌍] (2T 차동 BL·/BL 구동)
```

선의 의미: DRAM(1T1C 커패시터 기반)과 SRAM(6T 래치 기반) 셀 내부 회로의 계층 구조를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 스토리지 커패시터 (DRAM 1C) | 유전체 내 미세 전하 축적($Q=CV$)을 통해 최소 면적으로 1비트 저장 |
| 열 감지 증폭기 (Sense Amp) | 셀 방전 시 비트라인 미세 차동 전압 감지 및 파괴된 전하 재충전 |
| 교차 결합 인버터 (SRAM 4T) | 4개 CMOS 트랜지스터의 상호 피드백으로 전원 공급 중 쌍안정 논리 유지 |
| 접근 트랜지스터 쌍 (SRAM 2T) | 워드라인 신호에 동기화되어 차동 비트라인(BL, /BL)으로 논리 전압 출력 |

#### 한줄 요약
- DRAM은 1T1C 커패시터와 감지 증폭기로 집적도를 극대화하고, SRAM은 6T 인버터 래치로 초저지연을 달성한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **차동 비트라인 쌍(BL, /BL)**: 서로 반전된 상보 논리 전압을 동시에 전달하여 잡음을 상쇄하고 고속 감지를 가능하게 하는 SRAM의 신호선 쌍.
- **비트라인 프리차지(Bitline Precharge)**: 다음 읽기 접근을 위해 비트라인 전압을 기준 전압 레벨($V_{DD}/2$ 또는 $V_{DD}$)로 초기화하는 동작.

</details>

```text
+-------------------------------------------------------------+
|                 워드라인(WL) 활성화 판독 요청                |
+-------------------------------------------------------------+
                              |
              +---------------+---------------+
              |                               |
              v                               v
+-----------------------------+ +-----------------------------+
|      [ DRAM 판독 사이클 ]   | |      [ SRAM 판독 사이클 ]   |
+-----------------------------+ +-----------------------------+
| 1. 전하 공유: 커패시터와    | | 1. 래치 신호 전달: 4T 래치  |
|    비트라인 간 미세 전하 분배| |    상태가 2T 트랜지스터 통과|
| 2. 감지 및 복원: Sense Amp  | | 2. 차동 방전: BL 및 /BL 선에|
|    전압 증폭 및 전하 재충전 | |    상보적 차동 전압 형성    |
| 3. 프리차지: 다음 접근을    | | 3. 비파괴 판독: 래치 상태   |
|    위해 비트라인 전압 초기화 | |    유지하며 1사이클 내 완료 |
+-----------------------------+ +-----------------------------+
```

분기 결과: **DRAM**은 파괴적 판독으로 인해 감지 증폭기의 전하 복원 및 **비트라인 프리차지**가 필수적이므로 수십 ns의 사이클 지연이 발생하나, **SRAM**은 **차동 비트라인 쌍**을 감지하는 비파괴 판독이므로 래치 상태를 보존하며 1사이클 내에 완료됨

**동작 원리**

1. **DRAM 워드라인 구동 및 전하 공유**: 워드라인이 턴온되면 1T 스위치를 통해 커패시터에 저장된 미세 전하가 사전 충전된 비트라인으로 방출되어 수십 mV의 전압 변위가 발생함
2. **DRAM 열 감지 증폭 및 전하 복원**: 감지 증폭기가 비트라인 전압과 기준 전압의 차이를 최대 전원 전압($V_{DD}$)으로 고속 증폭하고, 파괴된 셀 커패시터에 원래 전하를 다시 밀어 넣어 완전 복원함
3. **DRAM 비트라인 프리차지**: 다음 행 접근을 준비하기 위해 비트라인 전압을 $V_{DD}/2$ 레벨로 초기화하여 읽기 오차를 방지함
4. **SRAM 차동 비트라인 방전**: 워드라인이 인가되면 상호 결합 인버터의 출력 노드가 2개의 접근 트랜지스터를 통해 비트라인(BL)과 반전 비트라인(/BL) 중 한쪽을 접지로 고속 방전시킴
5. **SRAM 비파괴 고속 데이터 검출**: 인버터 내부 전압이 파괴되지 않고 유지되므로 별도의 복원 사이클 없이 차동 감지 증폭기가 신호차를 검출하여 1클록 내에 데이터를 즉시 CPU로 전달함

#### 한줄 요약
- DRAM은 판독 시 전하가 소실되어 복원과 프리차지가 필수이나, SRAM은 비파괴 판독으로 1클록 내 즉시 출력한다.

## Ⅴ. 종류 및 비교

| 휘발성 반도체 메모리 | DRAM (Dynamic RAM) | SRAM (Static RAM) |
|:---|:---|:---|
| 적용 기준 | 테라바이트급 시스템 주기억장치 및 대용량 버퍼 요구 시 | 1사이클 서브 나노초 CPU L1~L3 온칩 캐시 요구 시 |
| 핵심 특징 | **1T1C 소형 셀** 기반 고집적 및 주기적 리프레시 동작 | **6T 래치 셀** 기반 서브 나노초 비파괴 고속 판독 |
| 한계 | 파괴적 판독 복원 지연 및 **리프레시** 컨트롤러 오버헤드 | 대형 셀 면적으로 인한 집적도 한계 및 고비용 구조 |

#### 한줄 요약
- 대용량 시스템 메모리는 저비용 고집적 DRAM이 전담하고, CPU 코어 캐시는 리프레시 없는 고속 SRAM이 전담한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Row Hammer**: DRAM의 특정 워드라인을 단시간에 반복 활성화할 때 인접 셀의 누설 전하가 가속되어 비트가 반전되는 취약점.
- **전원 게이팅(Power Gating)**: 미사용 SRAM 캐시 블록에 공급되는 전원을 절체 스위치로 차단하여 대기 누설 전류를 억제하는 저전력 설계 기법.
- **소프트 에러(Soft Error Rate, SER)**: 우주선 기원의 중성자나 패키징 물질의 알파 입자 충돌로 메모리 셀의 저장 전하/전압 상태가 일시 반전되는 비영구적 결함.
- **TRR(Targeted Row Refresh)**: 메모리 제어기 또는 DRAM 내부 카운터가 단시간에 과다 활성화된 공격 행을 추적하고, 그 인접 희생 행을 정규 리프레시 주기와 별도로 선제 재충전하여 Row Hammer 비트 반전을 차단하는 DRAM 방어 기법.
- **SEC-DED ECC(Single Error Correction, Double Error Detection)**: 데이터 워드에 해밍 부호 기반 검사 비트를 덧붙여 저장하고 판독 시 신드롬을 계산하여 1비트 오류는 위치를 찾아 정정하고 2비트 오류는 검출만 하는 오류 정정 부호.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| DRAM 미세 공정화에 따른 셀 간 간섭 및 **Row Hammer** 결함 | **TRR**(Targeted Row Refresh) 회로 적용 | 과도 활성화 행 인접 희생 행을 선제 리프레시하여 비트 반전 차단 |
| 초미세 공정 SRAM의 서브스레숄드 누설 전류 및 대기 전력 급증 | **전원 게이팅**(Power Gating) 기법 적용 | 유휴 캐시 슬라이스 누설 차단 및 온칩 전력 효율 극대화 |
| 고에너지 입자 충돌에 의한 일시적 **소프트 에러**(SER) 발생 | **SEC-DED ECC** 회로 적용 | 단일 비트 오류 실시간 정정 및 2비트 오류 검출 |

#### 한줄 요약
- DRAM 대책은 전하 저장 셀이 치르는 인접 행 간섭과 방전을 보강하는 데, SRAM 대책은 트랜지스터 6개의 대가인 누설 전력을 억누르는 데 모이므로, 각 셀 구조가 포기한 것이 곧 실무 대책의 표적이다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **HBM(High Bandwidth Memory)**: 복수의 DRAM 다이를 TSV 실리콘 관통 전극으로 수직 적층하여 광대역 통신을 지원하는 3D 메모리.

</details>

- 고집적 대용량 주기억장치로서의 **DRAM**과 초고속 온칩 캐시로서의 **SRAM**은 상호 보완적 메모리 계층으로 확고히 자리 잡았으며, 차세대 컴퓨팅에서는 TSV 기반 3D 적층 고대역폭 메모리(**HBM**) 및 임베디드 SRAM 최적화 구조로 진화하고 있어, 워크로드의 데이터 처리량과 접근 레이턴시 요구를 분석한 온칩 SRAM 캐시 용량·오프칩 DRAM 인터페이스 설계

#### 한줄 요약
- SRAM의 초고속성과 DRAM의 고집적성은 상호 보완 관계이며, 두 메모리의 계층적 결합이 현대 컴퓨팅의 기반이다.
