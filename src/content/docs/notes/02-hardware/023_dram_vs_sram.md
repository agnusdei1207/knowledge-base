## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **동적 램(Dynamic Random Access Memory, DRAM)**: 커패시터 전하로 비트를 저장해 주기적인 리프레시가 필요한 메모리입니다.
- **정적 램(Static Random Access Memory, SRAM)**: 래치 회로로 전원 공급 중 데이터를 유지하는 메모리입니다.
- **휘발성 메모리(Volatile Memory)**: 전원이 끊기면 저장 데이터가 사라지는 메모리입니다.

</details>

- 정의/개념: 전하 저장 셀과 래치 셀을 비교하는 **휘발성 메모리 분류**
- 배경/필요성: 접근 지연과 집적도 요구에 따른 캐시·주기억장치 역할 분담

#### 한줄 요약

- DRAM은 작은 셀로 많은 데이터를 담고 SRAM은 큰 회로로 빠르게 읽으므로, 보통 DRAM은 주기억장치에 SRAM은 캐시에 배치됩니다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **1T1C 셀(One Transistor-One Capacitor Cell)**: 트랜지스터 하나와 커패시터 하나로 DRAM 비트를 구성하는 셀입니다.
- **6T 셀(Six-Transistor Cell)**: 여섯 트랜지스터로 SRAM 래치와 접근 경로를 구성하는 대표 셀입니다.
- **리프레시(Refresh)**: 누설된 DRAM 커패시터 전하를 주기적으로 다시 보충하는 동작입니다.

</details>

- DRAM: 1T1C 기반 **고집적 저장**
- SRAM: 6T 기반 **저지연 접근**
- DRAM: 전하 누설에 따른 **리프레시 필요**

#### 한줄 요약

- DRAM은 저장 셀이 작아 용량을 키우기 쉽지만 주기적으로 되살려야 하고, SRAM은 전원을 유지하는 동안 바로 상태를 읽을 수 있습니다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **커패시터(Capacitor)**: 전하를 저장해 DRAM 셀의 논리 상태를 표현하는 소자입니다.
- **감지 증폭기(Sense Amplifier)**: 비트라인의 작은 전압 차이를 논리값으로 증폭하는 회로입니다.
- **교차 결합 인버터(Cross-Coupled Inverter)**: SRAM 내부에서 서로의 출력을 입력으로 연결해 두 안정 상태를 유지하는 회로입니다.

</details>

```text
[메모리 셀]
├─ DRAM
│  ├─ 접근 트랜지스터
│  ├─ 커패시터
│  └─ 감지 증폭기
└─ SRAM
   ├─ 교차 결합 인버터
   └─ 접근 트랜지스터
```

| 구성요소 | 책임 |
|:---|:---|
| DRAM 커패시터 | 전하 저장으로 비트 상태 표현 |
| DRAM 감지 증폭기 | 전하 차이 증폭과 읽기 후 복원 |
| SRAM 교차 결합 인버터 | 전원 공급 중 래치 상태 유지 |
| 접근 트랜지스터 | 워드라인에 따른 읽기·쓰기 연결 |

#### 한줄 요약

- DRAM은 전하의 양을 읽고 복원하는 셀이고, SRAM은 인버터의 두 안정 상태를 유지하는 셀입니다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **파괴적 판독(Destructive Read)**: 읽는 과정에서 DRAM 셀 전하가 변해 읽은 뒤 데이터를 복원해야 하는 방식입니다.
- **비파괴적 판독(Non-Destructive Read)**: 읽어도 SRAM 래치 상태가 유지되는 방식입니다.
- **프리차지(Precharge)**: 다음 DRAM 행 접근 전에 비트라인 전압을 기준 상태로 맞추는 동작입니다.

</details>

```text
[1. 행 선택]
          │
          ├─ DRAM → [2. 전하 감지·복원·프리차지]
          │
          └─ SRAM → [2. 래치 차동값 감지]
                         │
                         ▼
                    [3. 데이터 반환]
```

동작 원리:

1. 행 선택: 워드라인으로 대상 셀 활성화
2. 전하 감지·복원·프리차지 또는 래치 차동값 감지: 셀 유형별 판독
3. 데이터 반환: 감지된 논리값을 요청 회로에 제공

#### 한줄 요약

- DRAM은 읽은 전하를 다시 채우는 절차가 필요하지만 SRAM은 래치 상태를 그대로 읽으므로 읽기 경로가 단순합니다.

## Ⅴ. 종류 및 비교

| 메모리 유형 | DRAM | SRAM |
|:---|:---|:---|
| 적용 기준 | 대용량 주기억장치와 메모리 채널 | 저지연 캐시와 고속 버퍼 |
| 핵심 특징 | 1T1C 고집적과 리프레시 | 6T 래치와 비파괴 판독 |
| 한계 | 리프레시·복원 지연과 제어 비용 | 셀 면적·누설 전력과 낮은 집적도 |

#### 한줄 요약

- 많은 데이터를 낮은 비용으로 저장하면 DRAM, 프로세서 가까이에서 빠르게 반복 접근하면 SRAM이 적합합니다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **행 적중(Row Hit)**: 열린 DRAM 행에서 필요한 열을 다시 접근해 행 활성화 비용을 줄이는 상황입니다.
- **Row Hammer**: 특정 DRAM 행을 반복 활성화해 인접 행의 데이터 오류 가능성을 높이는 현상입니다.
- **오류 정정 코드(Error Correcting Code, ECC)**: 저장·전송 데이터의 오류를 검출하고 일부 오류를 정정하는 코드입니다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| DRAM 리프레시가 접근을 지연 | 리프레시 스케줄과 뱅크 분산 조정 | 유효 대역폭 손실 완화 |
| 반복 행 전환으로 활성화 비용 증가 | 행 적중 중심 요청 스케줄링 | 행 전환 지연 감소 |
| Row Hammer로 인접 셀 오류 가능 | 메모리 세대별 완화 정책과 ECC 적용 | 오류 영향 검출·정정 |
| SRAM 캐시의 면적·누설 전력 증가 | 캐시 용량과 전력 차단 단위 최적화 | 지연·면적·전력 균형 |

#### 한줄 요약

- DRAM은 리프레시와 행 배치를, SRAM은 셀 면적과 누설 전력을 관리해야 각자의 장점을 유지할 수 있습니다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **메모리 계층 구조(Memory Hierarchy)**: 지연·용량·비용이 다른 저장 장치를 함께 사용해 평균 접근 비용을 낮추는 구조입니다.

</details>

- 저지연과 반복 접근이 우선이면 **SRAM**을 캐시에 배치하고, 용량·집적도와 **메모리 계층 구조**가 우선이면 DRAM을 주기억장치로 선택

#### 한줄 요약

- DRAM과 SRAM의 선택은 우열이 아니라, 저장 용량을 확보할지 접근 시간을 줄일지에 따라 계층별 역할을 나누는 결정입니다.
