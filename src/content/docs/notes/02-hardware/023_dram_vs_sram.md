## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **동적 램(Dynamic Random Access Memory, DRAM)**: 1개의 트랜지스터와 1개의 커패시터(1T1C)로 단일 비트를 전하 형태로 저장하며, 누설 전하 보충을 위한 주기적 리프레시(Refresh)가 요구되는 고집적 휘발성 메모리.
- **정적 램(Static Random Access Memory, SRAM)**: 4개 또는 6개의 트랜지스터(6T)로 구성된 쌍안정 플립플롭 래치 구조로 데이터를 저장하여 전원 공급 중에는 리프레시 없이 초고속 접근을 유지하는 휘발성 메모리.
- **휘발성 메모리(Volatile Memory)**: 전원 공급이 중단되면 저장된 데이터가 소멸하는 특성을 가진 반도체 기억장치.

</details>

- 정의/개념: 커패시터 전하로 비트를 담는 **동적 램(DRAM)** 및 래치 상태로 담는 **정적 램(SRAM)**으로 갈리는 **휘발성 메모리**
- 배경/필요성: 단일 메모리 소자만으로는 **초고속 저지연과 고집적 대용량 동시 만족 불가**

#### 한줄 요약
- 둘의 차이는 제조 기술이 아니라 비트 하나를 무엇으로 기억하느냐이며, 전하는 새어 나가고 래치는 유지된다는 물리적 사실이 나머지 모든 차이를 낳는다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **1T1C 셀(One Transistor-One Capacitor Cell)**: 트랜지스터 1개와 커패시터 1개로 구성되어 실리콘 면적당 집적도를 극대화할 수 있는 DRAM의 최소 저장 셀 단위.
- **6T 셀(Six-Transistor Cell)**: 2개의 교차 결합 인버터와 2개의 접근 트랜지스터로 구성되어 판독 시 셀 상태를 파괴하지 않고 최고속 동작을 보장하는 SRAM의 단위 셀.
- **리프레시(Refresh)**: 커패시터의 유전체 누설 전류로 인해 소실되는 전하를 방지하기 위해 주기적으로 전체 행을 읽어 재충전하는 동작.

</details>

- **1T1C 셀** 기반 고집적 대용량을 얻는 대신 주기적 **리프레시** 부담
- **6T 셀은** 래치로 복원 없는 판독과 초고속 접근 지원
- 동일 공정에서 DRAM은 비트당 면적·비용 낮고, SRAM은 비트당 지연 낮음

#### 한줄 요약
- 셀 하나에 쓰는 트랜지스터 수 1개와 6개의 차이가 곧 집적도 차이이고, 그 집적도 차이가 다시 용량과 지연의 역할 분담을 강제한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **커패시터(Capacitor)**: 전하를 충전하거나 방전하여 논리 1과 0의 2진 데이터를 전압 차이로 표현하는 DRAM의 저장 소자.
- **감지 증폭기(Sense Amplifier)**: 비트라인의 미세한 전하 이동에 따른 전압 변화를 감지하여 전식 논리 전압 레벨(0 또는 Vdd)로 증폭하고, 파괴적 판독 후 셀 데이터를 원래대로 복원하는 회로.
- **교차 결합 인버터(Cross-Coupled Inverter)**: 두 개의 CMOS 인버터가 상호 입력-출력으로 연결되어 양방향 피드백을 통해 2개의 안정된 논리 상태를 지속 유지하는 SRAM의 래치 회로.

</details>

```text
[비트 저장·판독 구조]
├─ DRAM 배열
│  ├─ 1T1C 셀
│  │  ├─ 접근 트랜지스터
│  │  └─ 커패시터
│  └─ 주변 감지 증폭기 (여러 셀이 공유)
└─ SRAM 6T 셀
   ├─ 교차 결합 인버터
   └─ 접근 트랜지스터
```

선의 의미: 가지(`├─`)는 소유·구성 관계; DRAM과 SRAM은 대안 셀 구조

| 구성요소 | 책임 |
|:---|:---|
| DRAM **커패시터** | 전하 저장으로 비트 상태 표현 |
| DRAM **감지 증폭기** | 전하 차이 증폭·**파괴적 판독** 후 복원 |
| SRAM **교차 결합 인버터** | 전원 공급 중 래치 상태 유지와 **비파괴적 판독** |
| 접근 트랜지스터 | 워드라인 신호로 읽기·쓰기 연결 |

#### 한줄 요약
- **감지 증폭기가** 여러 셀에 공유된다는 점이 DRAM 집적도의 실제 근거이며, 셀을 작게 만든 대가를 주변 회로가 대신 치르는 구조다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **파괴적 판독(Destructive Read)**: 커패시터의 전하가 비트라인과 공유되면서 셀 내부의 원래 데이터가 소실되어, 판독 직후 감지 증폭기를 통한 재충전(복원)이 필수적인 읽기 동작.
- **비파괴적 판독(Non-Destructive Read)**: 래치 회로의 상태를 직접 반전시키지 않고 비트라인의 차동 전압만을 감지하여 데이터 손실 없이 즉시 읽기를 완료하는 동작.
- **프리차지(Precharge)**: 다음 행(Row) 접근을 위해 비트라인 쌍의 전압을 기준 레벨(일반적으로 Vdd/2)로 균등하게 충전하여 초기화하는 동작.

</details>

```text
워드라인 활성화
      │
      ├─ 1. DRAM 판독 및 재충전
      │      │
      │  커패시터 전하 공유 → 감지 증폭기 판정 → 셀 전하 복원 → 프리차지
      │
      └─ 2. SRAM 비파괴 판독
             │
         교차 결합 인버터 차동값 감지 → 데이터 즉시 반환 (복원 불필요)
```

분기 결과: DRAM은 읽는 행위 자체가 상태를 무너뜨려 복원과 **프리차지가** 반드시 뒤따르지만, SRAM은 읽어도 상태가 그대로라 읽기 경로가 한 단계로 끝남

#### 한줄 요약
- **파괴적 판독은** 결함이 아니라 셀을 최소로 줄인 대가이며, DRAM 타이밍 규격이 유독 복잡한 이유도 전부 이 복원 절차에서 파생된다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **DRAM(Dynamic RAM)**: 1T1C 셀 구조로 집적도가 높아 대용량 주기억장치에 적합한 메모리.
- **SRAM(Static RAM)**: 6T 래치 구조로 리프레시 없이 초고속 동작하여 캐시에 적합한 메모리.

</details>

| 메모리 유형 | DRAM | SRAM |
|:---|:---|:---|
| 적용 기준 | 대용량 주기억장치·메모리 채널 | 저지연 캐시·고속 레지스터 버퍼 |
| 핵심 특징 | **1T1C 셀** 고집적 구조에 리프레시 필요 | **6T 셀** 래치로 복원 없는 판독 |
| 한계 | 리프레시·복원 지연·제어 회로 비용 | 셀 면적·누설 전력·낮은 집적도 |

#### 한줄 요약
- 두 메모리가 한 칩 안에서 공존하는 이유는 어느 쪽도 상대의 영역을 감당할 수 없어서이며, 통합 시도가 반복해 실패해 온 지점이기도 하다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **행 적중(Row Hit)**: DRAM 접근 시 요청된 주소가 이미 행 버퍼(Sense Amplifier)에 활성화(Open)되어 있어 추가적인 행 활성화 및 프리차지 지연 없이 즉시 열 접근이 가능한 상태.
- **Row Hammer**: 특정 DRAM 행을 극도로 빈번하게 반복 활성화(Activating)함으로써 인접한 희생 행의 커패시터 전하 누설을 가속하여 비트 플립(Bit Flip) 오류를 유발하는 물리적 하드웨어 취약점.
- **오류 정정 코드(Error Correcting Code, ECC)**: 메모리 저장 또는 전송 데이터에 패리티 비트를 추가하여 싱글 비트 오류를 자체 정정(SEC)하고 더블 비트 오류를 검출(DED)하는 신뢰성 보장 메커니즘.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **리프레시** 기반 유효 대역폭 손실 | 리프레시 스케줄·뱅크 분산 조정 | 유효 대역폭 손실 완화 |
| 반복 행 전환으로 활성화 비용 증가 | **행 적중** 중심 요청 스케줄링 | 행 전환 지연 감소 |
| **Row Hammer** 기반 인접 셀 오류 가능 | 완화 정책(PARA·TRR)·**ECC** 적용 | 오류 검출·정정 |
| SRAM 캐시의 면적·누설 전력 증가 | 캐시 용량·전력 차단 단위 최적화 | 지연·면적·전력 균형 |

#### 한줄 요약
- **Row Hammer는** 집적도를 계속 높인 결과 인접 셀 간섭이 임계를 넘어선 사례이며, 미세화의 이득이 신뢰성 비용으로 되돌아오는 전형을 보여 준다.

## Ⅶ. 결론

- 초고속 캐시는 **SRAM**, 대용량 주기억장치는 **DRAM** 선택

#### 한줄 요약
- 선택이라는 표현이 무색할 만큼 두 메모리의 역할은 물리 특성이 이미 정해 두었고, 설계자가 실제로 정하는 것은 각 계층의 용량 비율뿐이다.
