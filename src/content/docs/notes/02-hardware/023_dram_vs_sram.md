## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **동적 임의 접근 메모리(Dynamic Random-Access Memory, DRAM)**: 전하 셀로 고밀도를 얻는 휘발성 메모리.
- **정적 임의 접근 메모리(Static Random-Access Memory, SRAM)**: 래치 셀로 짧은 지연을 얻는 휘발성 메모리.
- **휘발성(Volatility)**: 전원이 끊기면 저장한 값이 사라지는 성질.

</details>

- 정의/개념: 전하 셀로 고밀도를 제공하는 **DRAM**과 래치 셀로 저지연을 제공하는 **SRAM**
- 배경/필요성: 단일 셀 구조로는 집적도와 접근 속도를 동시에 만족할 수 없어 메모리 계층 배치 분리

#### 한줄 요약

- DRAM은 용량을, SRAM은 접근 속도를 담당하여 메모리 계층의 서로 다른 위치에 배치된다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **1T1C 셀(1T1C Cell)**: 트랜지스터 하나와 커패시터 하나로 DRAM 1비트를 저장하는 구조.
- **6T 래치(6T Latch)**: 교차 결합 인버터와 접근 트랜지스터로 SRAM 상태를 유지하는 구조.
- **비파괴 판독(Non-Destructive Read)**: 읽어도 저장 상태가 무너지지 않아 복원이 필요 없는 SRAM의 판독 특성.

</details>

- DRAM의 **1T1C 셀** 기반 고밀도와 낮은 비트 단가
- SRAM의 **6T 래치** 기반 **비파괴 판독**과 짧은 지연
- 전원 차단 시 값이 사라지는 공통 **휘발성**

#### 한줄 요약

- DRAM은 판독 후 셀 전하를 복원해야 하지만, SRAM은 래치 상태를 유지한 채 비파괴 판독한다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **워드라인(Wordline)**: 메모리 셀의 행을 선택하는 배선.
- **비트라인(Bitline)**: 메모리 셀의 읽기•쓰기 신호를 전달하는 배선.
- **감지 증폭기(Sense Amplifier)**: DRAM 셀의 미세한 비트라인 전압 차를 논리값으로 증폭하는 회로.
- **복원(Restore)**: 파괴적 판독 후 감지한 값을 DRAM 셀에 다시 기록하는 동작.

</details>

```text
DRAM 구조: [DRAM 1T1C 셀 배열] -- [DRAM 감지•복원 회로]

SRAM 구조: [SRAM 6T 셀 배열] -- [SRAM 읽기•쓰기 회로]
```

선의 의미: 각 선은 셀 배열과 해당 주변 회로의 정적 결합이며, DRAM과 SRAM 두 구조 사이의 직접 연결은 없음.

| 구성요소 | 책임 |
|:---|:---|
| DRAM 1T1C 셀 배열 | 고밀도 전하 비트 보관 |
| DRAM 감지•복원 회로 | 전압 증폭•전하 재기록 |
| SRAM 6T 셀 배열 | 비파괴 래치 상태 유지 |
| SRAM 읽기•쓰기 회로 | 워드•비트라인 입출력 |

#### 한줄 요약

- DRAM은 전하를 복원하고 SRAM은 래치 상태를 유지하도록 회로가 나뉜다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **행 활성(Row Activation)**: 선택한 DRAM 행의 셀을 비트라인과 연결하는 동작.
- **열 선택(Column Selection)**: 활성화한 행에서 입출력할 데이터 위치를 고르는 동작.
- **프리차지(Precharge)**: 다음 행을 열기 전에 비트라인 전압을 기준 상태로 되돌리는 준비 동작.

</details>

```text
1. 메모리 읽기 요청
├─ DRAM
│  └─ 2. 행 활성
│     └─ 3. 전하 감지·복원
│        └─ 4. 열 선택·출력·프리차지
└─ SRAM
   └─ 2. 워드라인 선택
      └─ 3. 래치 상태 비파괴 판독
         └─ 4. 데이터 출력
```

### 동작 원리

1. **읽기 요청 입력**: 주소와 읽기 명령을 DRAM 또는 SRAM의 주변 회로에 전달.
2. **저장 행 선택**: DRAM은 **행 활성**, SRAM은 **워드라인**으로 래치 셀 선택.
3. **저장값 판독**: DRAM은 **감지 증폭기**로 전하를 읽은 뒤 파괴된 값 **복원**, SRAM은 래치 상태 비파괴 판독.
4. **데이터 출력·종료**: 선택한 데이터 출력, DRAM은 다음 행 접근을 위해 **프리차지**.

#### 한줄 요약

- DRAM은 판독이 셀 전하를 훼손하므로 감지한 값을 즉시 복원하지만, SRAM은 래치 상태가 유지된다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **리프레시(Refresh)**: 누설되는 DRAM 셀 전하를 보충하려고 모든 행을 주기적으로 복원하는 동작.
- **비트 단가(Cost Per Bit)**: 저장 용량 한 비트를 구현하는 데 드는 칩 면적과 제조 비용.
- **접근 지연(Access Latency)**: 메모리 요청 후 데이터를 읽거나 쓰기까지 걸리는 시간.

</details>

| 휘발성 메모리 | DRAM | SRAM |
|:---|:---|:---|
| 적용 기준 | 기가바이트급 용량과 낮은 **비트 단가** 우선 시 | 나노초급 **접근 지연** 우선 시 |
| 핵심 특징 | **1T1C 셀**의 고밀도와 낮은 비트 단가 | **6T 래치**의 비파괴·저지연 판독 |
| 한계 | 접근 간격을 묶는 **복원**•**리프레시** | 셀 면적에 따른 높은 **비트 단가** |

> 요약: 용량 선택 시 복원 지연 부담, 지연 선택 시 단가 부담.

#### 한줄 요약

- 필요한 용량과 허용 접근 시간을 기준으로 DRAM과 SRAM의 배치 위치를 정한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **행 적중(Row Hit)**: 이미 열린 DRAM 행에서 열만 선택해 프리차지와 재활성화를 피하는 접근.
- **누설 전력(Leakage Power)**: 회로가 전환하지 않을 때도 트랜지스터를 통해 소비되는 전력.
- **오류 정정 코드(Error-Correcting Code, ECC)**: 추가 검사 비트로 메모리 비트 오류를 검출하고 정정하는 기법.
- **전력 차단(Power Gating)**: 사용하지 않는 SRAM 영역의 전원을 끊어 누설 전력을 줄이는 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| DRAM **리프레시**가 메모리 요청을 막아 응답 지연 급증 | 리프레시를 뱅크별로 분산하고 온도에 따라 주기 조정 | 요청 중단 시간 분산으로 최대 지연 완화 |
| 잦은 행 전환으로 프리차지·활성 비용 증가 | 주소 매핑과 스케줄링으로 **행 적중** 우선 | 행 재사용 증가로 유효 대역폭 향상 |
| 큰 SRAM이 칩 면적과 **누설 전력** 증가 | 목표 적중률에 맞춰 용량·연관도와 **전력 차단** 조정 | 성능 목표 안에서 면적·대기 전력 제한 |
| 메모리 셀 비트 오류로 데이터 손상 | **ECC** 적용과 오류율·온도 감시 | 단일 비트 오류 정정과 다중 오류 검출 |

#### 한줄 요약

- 대용량 주기억장치는 DRAM 채널로 구성하고, CPU 인접 저지연 캐시는 SRAM으로 구성한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **캐시 메모리(Cache Memory)**: CPU 가까이에서 재사용 데이터를 짧은 지연으로 제공하는 소용량 SRAM 계층.
- **주기억장치(Main Memory)**: 실행 중인 대량의 코드와 데이터를 보관하는 고밀도 DRAM 계층.

</details>

- **캐시 메모리**는 **SRAM**, 대용량 **주기억장치**는 **DRAM**으로 구성

#### 한줄 요약

- 나노초급 응답이 필요한 캐시는 SRAM, 대용량 주기억장치는 DRAM으로 구성한다.
