## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **동적 임의 접근 메모리(Dynamic Random-Access Memory, DRAM)**: 1개의 트랜지스터와 1개의 커패시터 구조로 높은 집적도를 제공하지만, 주기적 리프레시가 필수적인 메모리 반도체이다.
- **정적 임의 접근 메모리(Static Random-Access Memory, SRAM)**: 6개의 트랜지스터 래치 구조를 기반으로 리프레시 없이 초고속 접근 지연을 제공하는 휘발성 반도체이다.
- **휘발성(Volatility)**: 전원 공급이 중단되면 저장되어 있던 논리 데이터가 즉각 소멸되는 반도체 전하 성질이다.

</details>

- 정의: 커패시터 기반의 고밀도 **동적 임의 접근 메모리**와 래치 기반의 초고속 **정적 임의 접근 메모리**를 비교하는 **휘발성** 반도체 규격
- 배경: 단일 반도체 소자로는 초고속 접근 속도와 대용량 고밀도 집적성을 동시에 만족시킬 수 없어 계층적 활용이 필요하기 때문임

#### 한줄 요약

- 대용량 동적 램과 초고속 정적 램의 구조적 차이와 스펙을 비교하여 최적의 메모리 계층 구성을 지원하는 하드웨어 원리이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **1T1C 셀(1T1C Cell)**: 1개의 트랜지스터와 1개의 커패시터로 구성되어 전하를 충방전하며 비트를 구별하는 동적 램 셀이다.
- **6T 래치(6T Latch)**: 인버터 트랜지스터 쌍으로 구성되어 쌍안정 논리 상태를 지속적으로 유지하는 정적 램 셀이다.
- **비파괴 판독(Non-Destructive Read)**: 읽기 연산 시 셀 내부 래치 상태가 훼손되지 않아 복원 과정이 필요 없는 독출 특성이다.
- **파괴적 판독(Destructive Read)**: 워드라인 활성 시 커패시터 전하가 유출되어 읽기 순간 데이터가 파괴되므로 즉시 재충전해야 하는 특성이다.

</details>

- **1T1C 셀** 구조의 동적 램은 집적도가 월등히 높아 작은 다이 면적에 대용량 주기억장치 구현이 가능함.
- **6T 래치** 구조의 정적 램은 **비파괴 판독**과 상태 유지를 통해 초저지연 캐시 접근을 지원함.
- 동적 램은 **파괴적 판독**과 누설 전류를 보충하기 위해 복원 및 주기적인 리프레시 동작이 필수적임.

#### 한줄 요약

- 동적 램은 파괴적 판독과 재충전을 감수하여 고밀도를 달성하고, 정적 램은 래치 회로를 통해 리프레시 없는 초저지연을 달성한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **워드라인(Wordline)**: 메모리 셀 행을 선택하여 트랜지스터 게이트를 활성화시키는 행 제어선이다.
- **비트라인(Bitline)**: 선택된 셀의 데이터 전하 신호를 감지 증폭기로 전달하거나 쓰기 전압을 싣는 열 데이터선이다.
- **감지 증폭기(Sense Amplifier)**: 파괴적 판독 시 발생하는 미세 전하 변위를 논리 신호로 증폭하고 원래 상태로 복원하는 핵심 회로이다.
- **복원(Restore)**: 동적 램 독출 직후 감지 증폭기가 파괴된 커패시터 전하를 원상태로 재충전하는 하드웨어 연산이다.

</details>

```text
[ 메모리 셀 구조 비교 ]
+------------------------------------+     +------------------------------------+
| 동적 램 (DRAM) 1T1C 셀 구조        |     | 정적 램 (SRAM) 6T 래치 구조        |
|                                    |     |                                    |
| [ 워드라인 ]                       |     | [ 워드라인 ]                       |
|       │                            |     |       │                            |
|       ▼                            |     |       ▼                            |
| [ 접근 트랜지스터 ] ── [ 커패시터 ]|     | [ 접근 트랜지스터 쌍 ]             |
|       │                            |     |       │                            |
| [ 비트라인 ]                       |     | [ 인버터 교차 결합 래치 회로 ]     |
+------------------------------------+     +------------------------------------+
```

| 비교 항목 | 동적 임의 접근 메모리 (DRAM) | 정적 임의 접근 메모리 (SRAM) |
|:---|:---|:---|
| 핵심 구동 회로 | 트랜지스터와 커패시터 결합 기반의 1T1C 셀 | 교차 결합된 6개의 트랜지스터 논리 래치 셀 |
| 판독 메커니즘 | **파괴적 판독** 발생 및 **감지 증폭기** 복원 필수 | **비파괴 판독**으로 래치 전압 상태 영구 직접 유지 |
| 리프레시 필요성 | 커패시터 누설 전하를 보충하는 주기적 재충전 필수 | 전원 공급 중에는 상태가 유지되어 재충전 불필요 |
| 면적 및 단가 | 작은 면적으로 집적도가 매우 높고 제조 단가 저렴 | 다수의 트랜지스터로 집적도가 낮고 제조 단가 고가 |

#### 한줄 요약

- 동적 램은 1T1C 구조와 감지 증폭기 기반으로 고밀도를 구현하고, 정적 램은 복잡한 트랜지스터 래치 기반으로 고속화를 구현한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **행 활성(Row Activation)**: 메모리 주소의 행을 선택하여 셀 전하를 비트라인으로 방출하고 증폭하는 1단계 작업이다.
- **열 선택(Column Selection)**: 래칭된 행 데이터 중 접근하고자 하는 열 비트를 선택하여 인출하는 2단계 작업이다.
- **프리차지(Precharge)**: 다음 행 접근을 위해 비트라인 전압을 기준 레벨로 다시 균등화하는 초기화 연산이다.

</details>

```text
[ 메모리 셀 읽기 동작 흐름 ]
+----------------------------+
| 1. 동적 램 (DRAM) 동작     |
+----------------------------+
  행 활성 ──> 감지 및 복원 ──> 열 선택 인출 ──> 프리차지
                 │
                 ▼
+----------------------------+
| 2. 정적 램 (SRAM) 동작     |
+----------------------------+
  워드라인 활성 ──> 차동 래치 판독 ──> 즉시 데이터 반환
```

### 동작 원리

1. 행 활성: 동적 램에서 행을 활성화하여 전하를 감지하고 즉각 **복원**함.
2. 열 선택: 감지된 데이터 중 **열 선택**으로 출력하고 **프리차지**로 회로를 초기화함.
3. 워드라인 활성: 정적 램에서 워드라인을 켜고 차동 래치 신호를 직접 판독함.
4. 즉시 반환: 별도의 복원이나 프리차지 없이 즉각 데이터를 반환함.

#### 한줄 요약

- 동적 램은 전하 복원과 프리차지라는 복잡한 동적 절차를 거치며, 정적 램은 래치 신호를 워드라인을 통해 단번에 읽어낸다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **리프레시(Refresh)**: 누설 전류로 데이터가 변질되는 현상을 방지하기 위해 정해진 주기마다 메모리의 모든 행을 읽어 재충전하는 동작이다.
- **접근 지연(Access Latency)**: 프로세서가 읽기 명령을 발생시킨 후 실제 메모리가 유효 데이터를 버스 상에 적재하기까지 걸리는 클록 시간이다.

</details>

| 성능 지표 | 동적 임의 접근 메모리 (DRAM) | 정적 임의 접근 메모리 (SRAM) |
|:---|:---|:---|
| 시스템 핵심 용도 | 대용량 시스템 주기억장치 및 그래픽 비디오 메모리 | 프로세서 온칩 레벨 1/2/3 캐시 및 레지스터 파일 |
| 집적 물리 밀도 | 단위 면적당 수십억 비트를 담는 초고밀도에 적합 | 동일 면적당 밀도가 십분의 일 수준으로 매우 저조 |
| 전력 소모 요인 | 주기적 **리프레시** 및 커패시터 충방전 동적 전력 유발 | 다수 트랜지스터에 의한 대기 상태 누설 정적 전력 유발 |
| **접근 지연** 한계 | 충방전과 감지 복원 오버헤드로 수십 나노초 지연 수반 | 트랜지스터 논리 지연만 존재하여 나노초 미만 지연 제공 |

#### 한줄 요약

- 동적 램은 대용량 메인 메모리 인프라 구축에 최적화되었으며, 정적 램은 표준 로직 공정을 활용한 온칩 고속 캐시에 적용된다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **행 적중(Row Hit)**: 이전에 활성화된 동적 램 행을 프리차지 없이 연속적으로 열 인출만 수행하여 지연을 대폭 절감하는 기술이다.
- **오류 정정 코드(Error-Correcting Code)**: 미세 공정화에 따른 입자 충돌로 발생하는 비트 반전을 감지하고 정정하는 정밀 회로이다.
- **전력 차단(Power Gating)**: 사용하지 않는 대형 정적 램 캐시 블록의 전원을 차단하여 정적 누설 전력을 억제하는 기술이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 전체 뱅크 **리프레시** 구동 시 중앙처리장치의 메모리 접근 일시 정지 | 뱅크 분산 리프레시 및 온도 가변 기반의 지능적 재충전율 적용 | 리프레시 정체 지연 오버헤드 삭감 및 메모리 유효 대역폭 확보 |
| 잦은 메모리 행 변경으로 인한 프리차지 동작 오버헤드 및 성능 지연 | 제어기의 **행 적중** 기반 명령 인터리빙 스케줄링 기법 채택 | 동일 행 연속 접근 시 오버헤드 은닉 및 데이터 전송률 획기적 향상 |
| 미세 공정 정적 램 캐시 모듈의 대기 상태 **정적 누설 전력** 폭증 현상 | 슬립 모드 전환을 유도하는 블록 단위의 **전력 차단** 회로 동적 연동 | 미사용 캐시 모듈의 전력 소모 차단 및 배터리 시스템 효율 개선 |
| 셀 소형화 및 입자 충돌에 의한 방사선 데이터 비트 반전 소프트 오류 | 고신뢰성을 요구하는 칩 내부 **오류 정정 코드** 인코딩 내장 | 하드웨어 데이터 정합성 보장 및 1비트 소프트 오류 완벽 자동 정정 |

#### 한줄 요약

- 분산 리프레시와 행 적중 최적화로 동적 램 한계를 극복하고, 전력 차단과 오류 정정으로 정적 램 효율을 제고한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **메모리 소자 선택 기준(Memory Device Selection Criteria)**: 대상 시스템의 목표 대역폭, 단위 용량당 제조 단가, 평균 접근 지연 목표를 분석하여 최적 반도체를 배치하는 프레임워크이다.

</details>

- 저지연 온칩 캐싱에는 **정적 램**, 대용량 오프칩 주기억에는 **동적 램**을 선택함

#### 한줄 요약

- 접근 지연 한계와 단위 집적 밀도, 경제적 비용을 종합 평가하여 시스템 계층별로 동적 램과 정적 램을 최적 배치해야 한다.
