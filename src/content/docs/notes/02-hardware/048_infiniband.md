## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **인피니밴드(InfiniBand)**: 컴퓨터끼리 인터넷 선(이더넷)으로 핑퐁 치는 느려터진 짓을 때려치우고, 수만 대의 슈퍼컴퓨터가 마치 한 대의 컴퓨터처럼 서로의 메모리를 빛의 속도로 쑤셔댈 수 있게 만든 무자비한 고속 통신망이다.
- **원격 직접 메모리 접근(Remote Direct Memory Access)**: A 컴퓨터가 B 컴퓨터의 메모리에 데이터를 쓸 때, B 컴퓨터의 중앙 처리 장치(CPU)를 귀찮게 깨우지 않고 몰래 잽싸게 쓰고 빠지는 사기적인 직거래 기술이다.
- **커널 우회(Kernel Bypass)**: 네트워크 칩이 운영체제(OS)의 길고 복잡한 검열소(TCP/IP 스택)를 뻔뻔하게 무시하고(우회), 곧바로 응용 프로그램 메모리로 텐서를 꽂아버리는 프리패스 기술이다.
- **중앙 처리 장치(Central Processing Unit)**: 일반 네트워크에서는 택배(패킷)가 올 때마다 하던 일을 멈추고 박스를 뜯어 메모리에 옮겨 담느라 정작 자기 일을 못 하고 과로사하는 불쌍한 칩이다.

</details>

- 정의: 호스트 채널 어댑터(HCA), 거대 전용 스위치 및 **원격 직접 메모리 접근** 하드웨어 전송 기법을 엮어, 수만 대 노드의 메모리를 딜레이 없이 한 몸처럼 고속 연결하는 **인피니밴드** 네트워크 패브릭
- 배경: 옛날 소켓 기반 커널 전송 제어 프로토콜(TCP/IP) 인터넷 망이 가진 끔찍한 데이터 복사 삽질, 커널 문맥 전환 지연, 그리고 미친 듯이 솟구치는 **중앙 처리 장치** 과부하 점유율을 모조리 극복하기 위함

#### 한줄 요약

- CPU와 운영체제를 철저히 왕따시키고, 랜카드끼리 직접 남의 컴퓨터 메모리에 데이터를 꽂아버려 데이터센터 전체를 하나의 거대 뇌로 묶는 극초저지연 통신망이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **메모리 등록(Memory Registration)**: 램(RAM)의 특정 구역에 대못을 박아(Pinning) 운영체제가 하드디스크로 쫓아내지 못하게 고정하고, 남의 컴퓨터 랜카드가 합법적으로 쳐들어올 수 있도록 현관문 비밀번호(접근 키)를 파주는 사전 작업이다.
- **호스트 채널 어댑터(Host Channel Adapter)**: 겉보기엔 평범한 랜카드 같지만, CPU가 할 네트워크 짐을 몽땅 떠안고 인피니밴드 망과 컴퓨터의 좁은 골목(PCIe) 사이를 쉴 새 없이 펌핑하는 전담 하드웨어이다.
- **크레딧 기반 흐름 제어(Credit-Based Flow Control)**: 받을 쪽 창고(수신 버퍼)에 자리가 몇 개 남았는지 쿠폰(크레딧)을 미리 받아내어, 쿠폰 개수만큼만 정확히 쏴버려 단 한 톨의 패킷도 바닥에 떨어뜨리지 않는 무결점 제어이다.
- **집단 통신(Collective Communication)**: 수백 대의 노드가 텐서를 주고받을 때, 바보같이 한 명씩 통화하지 않고 링을 만들어 다 같이 핑퐁 치며 텐서를 합치는 딥러닝 분산 학습의 생명줄이다.

</details>

- 운영체제의 간섭을 없애기 위해 물리적 **메모리 등록** 기반의 원격 메모리 직결 및 **커널 우회**를 칩 수준에서 하드웨어로 완벽 구현함.
- 수신 버퍼 오버플로우로 데이터가 날아가 망이 마비되는 치명적인 참사를 원천 방지하는 **크레딧 기반 흐름 제어** 알고리즘을 맹신함.
- 고성능 컴퓨팅(HPC) 및 초거대 인공지능 분산 클러스터링의 생명선인 거대 텐서 **집단 통신** 대역폭을 한계까지 쥐어짬.

#### 한줄 요약

- 메모리에 대못을 박아 운영체제를 따돌리고, 쿠폰(크레딧)만큼만 쏴서 패킷 손실을 0으로 만들며, 집단 통신을 폭발시켜 수만 대의 GPU를 하나처럼 돌리게 한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **큐 쌍(Queue Pair)**: 칩과 프로그램 사이의 소통 창구로, "이거 보내줘"라고 우겨넣는 송신함(SQ)과 "이거 받았음" 하고 쌓이는 수신함(RQ)이 찰떡같이 묶인 쌍둥이 통신 종단점이다.
- **완료 큐(Completion Queue)**: 큐 쌍에 던져둔 택배 발송이 진짜로 무사히 배달되었는지, 칩이 프로그램에게 "일 다 했어!"라고 영수증을 비동기로 던져주는 알림판 창구이다.
- **서브넷 관리자(Subnet Manager)**: 인피니밴드 패브릭 구석구석을 돌아다니며 주소표(라우팅 테이블)를 나눠주고, 사고가 나면 우회로를 뚫어주는 네트워크 망의 절대 권력자 소프트웨어이다.

</details>

```text
[ 인피니밴드 무손실 통신 아키텍처 및 원격 직접 메모리 접근 프레임워크 ]
       [ 분산 클러스터 노드 1 ]                         [ 분산 클러스터 노드 2 ]
                   │                                              │
    [ 큐 쌍(QP) 및 완료 큐(CQ) 관리 ]              [ 큐 쌍(QP) 및 완료 큐(CQ) 관리 ]
                   │                                              │
         [ 호스트 채널 어댑터 ]                         [ 호스트 채널 어댑터 ]
                   │               (광케이블 직결)                │
                   └─────────> [ 인피니밴드 스위치 망 ] <─────────┘
                                         │
                                [ 서브넷 관리자 (SM) ]
```

| 구성요소 | 책임 |
|:---|:---|
| 호스트 채널 어댑터 및 **큐 쌍**, **완료 큐** 종단점 | 응용 프로그램의 **원격 직접 메모리 접근** 명령을 가로채어, 하드웨어 전용 칩으로 직접 펌핑 전송하고 **완료 큐**에 영수증을 꽂아주는 말단 노가다 반장 |
| **인피니밴드** 거대 스위치 패브릭 망 | 패킷이 바닥에 떨어지지 않는 100% 무손실 핑퐁을 보장하는 **크레딧 기반 흐름 제어** 및 수천 개 포트의 미친 크로스바 스위칭 책임 |
| 소프트웨어 **서브넷 관리자** | 얽히고설킨 수만 가닥의 광케이블 망 지형을 파악하고, 각 노드에 논리적 주소(LID)를 할당하며 차단 없는 최적의 경로를 뚫는 교통경찰 |

#### 한줄 요약

- 프로그램이 큐 쌍에 일을 던지면 칩(HCA)이 알아서 스위치 망을 통해 데이터를 남의 집에 꽂아버리고 완료 큐에 보고하며, 이 모든 길은 서브넷 관리자가 뚫는다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **작업 요청(Work Request)**: 프로그램이 칩(HCA)에게 "B 컴퓨터 100번지 메모리에 이 텐서를 꽂아버려라"라고 적어 제출하는 무자비한 청부 살인(Write) 명령서이다.
- **등록 키(Registration Key)**: 남의 컴퓨터 메모리에 함부로 들어갔다간 해킹으로 간주되어 튕겨나가니, 합법적 침입을 증명하기 위해 패킷 이마에 붙이고 다니는 마스터키(rkey)이다.
- **직접 메모리 접근(Direct Memory Access)**: 칩이 CPU한테 결재받지 않고, 메인보드 버스를 타고 메모리 창고에 몰래 들어가 데이터를 수레로 털어오는 도둑질(그러나 합법적인) 기술이다.

</details>

```text
[ 인피니밴드 원격 직접 메모리 접근 쓰기(Write) 전송 하드웨어 핑퐁 제어 흐름 ]
                               │
                               ▼
  [ 1. 프로그램의 쓰기 작업 요청 및 송신 HCA의 로컬 데이터 직접 메모리 접근 인출 ]
                               │
                               ▼
        [ 2. 큐 쌍(QP) 및 크레딧 검증 통과 후 인피니밴드 스위치 망으로 패킷 발사 ]
                               │
                               ▼
    [ 3. 수신 HCA가 날아온 패킷의 원격 등록 키(rkey) 멱살을 잡고 메모리 접근 권한 검열 ]
                               │
                               ▼
     [ 4. 검문 통과 시 CPU 모르게 수신 측 등록 메모리에 다이렉트로 데이터 강제 꽂기 ]
                               │
                               ▼
          [ 5. 양쪽 노드 완료 큐(CQ)에 전송 완료 영수증 비동기 통지 및 세션 종료 ]
```

### 동작 원리

1. 송신 버퍼 직접 메모리 읽기: 애플리케이션의 무자비한 쓰기 **작업 요청** 인가 시, 송신 호스트 채널 어댑터가 CPU를 기절시키고 **직접 메모리 접근**으로 로컬 데이터를 털어 인출함.
2. 큐 쌍 패킷 패브릭 전달: **큐 쌍** 규칙과 받을 쪽의 크레딧 쿠폰이 남았는지 깐깐하게 하드웨어 검증을 마친 후 **인피니밴드** 패브릭으로 패킷을 미친 듯이 쏘아댐.
3. 수신 노드 권한 검증: 수신 노드 칩이 패킷 이마에 붙은 원격 **등록 키**를 낚아채어, 남의 메모리 가상 주소를 파고들 권한이 있는지 철저한 보안 검열을 시행함.
4. 원격 메모리 직접 쓰기: 검문을 통과하면 수신 호스트 어댑터가 등록 메모리에 직접 쓰기를 강제 수행하여 데이터를 꽂아버리고 이벤트를 기록함.
5. 전송 확인 응답 통지: 송신자와 수신자 양쪽 모두에게 전송 완료를 비동기식으로 통보하여 영수증을 발급하고 세션을 우아하게 종료함.

#### 한줄 요약

- CPU를 따돌리고 내 메모리를 턴 다음(DMA), 스위치 망에 던져서 남의 칩에 도달하면 열쇠(rkey)를 검사받고 남의 메모리에 직접 꽂아버리는 직거래 시스템이다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **이더넷 기반 원격 직접 메모리 접근(RDMA over Converged Ethernet)**: 비싸고 낯선 인피니밴드 선을 깔기 싫어서, 흔해 빠진 회사 랜선(이더넷) 위에 억지로 억지로 RDMA 기술을 포장해서 얹어놓은 끔찍한 혼종 기술이다.
- **원격 직접 메모리 접근 버브(RDMA Verbs)**: C 언어로 짠 프로그램이 인피니밴드든 이더넷이든 신경 쓰지 않고 하드웨어 칩에게 직접 명령을 내릴 수 있게 만든 표준 API 만능열쇠이다.
- **전송 제어 프로토콜(Transmission Control Protocol)**: 인터넷 세상의 절대 표준이지만, 느려터진 운영체제 커널을 거치며 확인 도장 100번을 찍느라 초거대 인공지능 통신에는 도저히 써먹을 수 없는 범용 통신 규약이다.

</details>

| 비교 항목 | **인피니밴드** (InfiniBand) | **이더넷 기반 원격 직접 메모리 접근** (RoCE) | 범용 **전송 제어 프로토콜** 망 (TCP/IP) |
|:---|:---|:---|:---|
| 시스템 적용 최적 기준 | 단 1ms의 핑퐁 오차도 허용하지 않는 미션크리티컬 고성능 컴퓨팅 및 인공지능 초고속 **집단 통신** 클러스터 환경 시 | 이미 깔려있는 낡은 이더넷 기반 데이터센터 망을 다 갈아엎지 않고 꼼수로 저비용 원격 메모리 접근을 구축할 시 | 돈이 없어 싼값으로 범용 서버 간의 웹 서비스, 데이터베이스 등 일반적인 인프라 통신을 짤짤이로 구축할 시 |
| 아키텍처 핵심 구현 특징 | 전용의 값비싼 광케이블 패브릭 스위치 및 전용 하드웨어 칩을 도배하여 태생부터 무손실 통신을 보장하는 완벽한 통제 | 잃어버리는 게 일상인 이더넷 스위치에 '잠깐 멈춰!' 기능(PFC)을 억지로 우겨넣어 무손실을 흉내 내는 이종 혼합 꼼수 네트워크 | 전 세계 모든 운영체제 커널 뼛속에 기본 내장된 범용 프로토콜 스택 기반의 미련하고 느려터진 소프트웨어 전송 |
| 극복해야 할 태생적 한계점 | 전용 장비 도입에 따른 천문학적인 단가 폭증 덤탱이 및 단일 벤더(엔비디아) 종속에 따른 눈물겨운 관리 복잡성 | 이더넷 네트워크 튜닝의 극악한 난이도 및, 스위치에 멈춤 신호가 꼬이면 전체 데이터센터 망이 뻗어버리는 쇄도 동결(Pause Flood) 참사 위험 | 운영체제 커널의 잦은 훼방 개입에 따른 끔찍한 메모리 복사 지연 및 실시간성을 보장할 수 없는 치명적으로 높은 대기 핑(Ping) |

#### 한줄 요약

- 돈 발라서 완벽한 무손실망을 깔려면 인피니밴드, 돈 아끼려고 기존 랜선에 마법을 부리려면 RoCE, 인공지능이 아니라 웹서버나 굴릴 거면 TCP/IP를 쓴다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **키 폐기(Key Revocation)**: 통신이 끝났는데도 남의 메모리에 들어갈 수 있는 마스터키(rkey)를 살려두면 해커가 들어와서 헤집어 놓으니, 전송 즉시 비밀번호를 파기해 버리는 단호한 보안 조치이다.
- **큐 쌍 오류 상태(Queue Pair Error State)**: 선이 살짝 씹히거나 해커가 엉뚱한 주소로 찌르면, 칩이 스스로 통신 멱살을 잡고 문을 잠가버려(Error State) 해당 통신 세션이 완전히 뻗어버리는 예외 상황이다.
- **지피유 직접 원격 메모리 접근(GPU Direct RDMA)**: 그래픽 카드(GPU)의 VRAM 데이터를 시스템 램(RAM)으로 퍼 옮긴 뒤 랜카드(HCA)로 보내는 멍청한 짓을 막고, GPU에서 랜카드로 피시아이이 고속도로를 타고 바로 쏴버리는 궁극의 야바위 기술이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 허공에 노출된 낡은 **등록 키**를 악용한 해커의 원격 서버 램 무단 침범 및 인공지능 텐서 데이터 탈취 보안 참사 위험 | RDMA 전송 작업 완료 직후 얄짤없는 즉각적 **키 폐기** 및 할당된 메모리 영역 강제 락업(Pinning) 해제 조치 시스템화 | 승인되지 않은 비인가 메모리 경계 오염 및 세그먼트 오류(Segfault) 크래시 원천 방지 및 데이터 보안망 구축 |
| 광케이블 순간 패킷 에러 또는 스위치 재부팅에 의한 **큐 쌍 오류 상태** 강제 전환 및 클러스터 전체 통신 세션 연쇄 마비 현상 | 하드웨어 수준의 에러 복구 핸들러 펌웨어 구축 및 인공지능 학습이 멈추지 않게 자동 큐 쌍 리셋 재연결 알고리즘 떡칠 탑재 | 찰나의 네트워크 단절이나 펄스 에러에도 학습 훈련 세션이 날아가지 않는 시스템 가용성 100% 방어 확보 |
| 특정 스위치 링크로 트래픽이 미친 듯이 쏠려 패킷이 버려지고 클러스터 전체가 버벅대는 극심한 네트워크 병목 혼잡 붕괴 | 트래픽 핫스폿을 요리조리 피하는 스위치 하드웨어 적응형 라우팅 및 런타임 동적 다중 경로 부하 분산 강제 적용 | 특정 노드 연결선의 혼잡 붕괴(Congestion Collapse) 현상 원천 방지 및 전체 초거대 클러스터 대역폭 균등화 수호 |
| 가속기(GPU) 데이터가 굳이 호스트 시스템 메모리(RAM)를 거쳐가야 하는 굴욕적인 데이터 핑퐁 복사 지연 오버헤드 병목 | **지피유 직접 원격 메모리 접근** 기술을 켜서 중앙 처리 장치를 기절시키고 그래픽 램과 네트워크 랜카드 직결 펌핑 야바위 구현 | 중앙 처리 장치 낭비를 막고, 서버 간 그래픽 카드 칩 간 통신 지연시간(Latency)을 마이크로초 단위의 0에 가깝게 극한 최소화 달성 |

#### 한줄 요약

- 해킹 막으려면 열쇠를 즉각 부수고(키 폐기), 끊기면 자동 재시작하며, 선이 막히면 우회로를 타고, GPU끼린 CPU 거치지 않고 다이렉트로 쏴야(GPU Direct) 클러스터가 살 수 있다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **패브릭 선택 기준(Fabric Selection Criteria)**: 돈지랄을 해서라도 1밀리초의 지연도 용납 못 할 초거대 딥러닝 훈련장인지, 아니면 기존 스위치를 재활용해 가성비로 묶어볼 건지를 냉혹하게 저울질하여 네트워크망의 운명을 결정하는 잣대이다.

</details>

- **패브릭 선택 기준**에 따라 최고 성능의 에러 없는 무손실 초저지연망이 절대 필요 시 **인피니밴드**, 예산이 없어 기존 이더넷 인프라를 쥐어짜 재활용할 시 **이더넷 기반 원격 직접 메모리 접근** 적용을 단호히 결정함

#### 한줄 요약

- 수백억 원짜리 AI 훈련장(클러스터)의 핑퐁 속도에 목숨을 건다면 무조건 인피니밴드로 도배하고, 속도 좀 까먹어도 가성비로 버틸 거면 기존 랜선(RoCE)을 써야 한다.
