## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **인피니밴드(InfiniBand)**: 고성능 컴퓨팅(HPC) 및 AI 클러스터 데이터센터에서 서버 노드 간, 그리고 서버-스토리지 간에 초고속·초저지연 무손실 패브릭 통신을 제공하는 점대점 스위치형 네트워크 표준.
- **원격 직접 메모리 접근(Remote Direct Memory Access, RDMA)**: 송수신 양측의 OS 커널 개입과 메모리 복사 없이 네트워크 어댑터(HCA)가 원격 호스트의 메모리에 데이터를 직접 읽고 쓰는 기술.

</details>

- 정의/개념: 하드웨어 기반 **RDMA(Remote Direct Memory Access)**와 크레딧 기반 무손실 흐름 제어를 결합하여 마이크로초($\mu\text{s}$) 단위의 초저지연을 실현하는 **인피니밴드(InfiniBand) 네트워크 아키텍처**
- 배경/필요성: 기존 표준 TCP/IP 이더넷의 OS 커널 인터럽트 오버헤드, 다단계 소켓 버퍼 복사 및 패킷 유실(Drop) 재전송 지연으로 인한 **대규모 AI/HPC 분산 클러스터 확장 한계 극복**

#### 한줄 요약
- 인피니밴드는 커널 우회와 제로 카피를 하드웨어로 구현하여 패킷 손실 없는 초저지연·초고대역폭을 제공하는 고성능 패브릭 기술이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **커널 우회(Kernel Bypass)**: 사용자 공간(User Space) 응용 프로그램이 OS 커널의 시스템 콜(Syscall)을 거치지 않고 HCA 하드웨어와 직접 통신하여 지연시간을 대폭 단축하는 기법.
- **제로 카피(Zero-Copy)**: 중간 소켓 커널 버퍼 복사 단계를 완전히 제거하고 사용자 애플리케이션 메모리 버퍼에서 네트워크 인터페이스로 데이터를 직접 전송하는 기술.

</details>

- CPU 부하 0화: **커널 우회(Kernel Bypass)**와 **제로 카피(Zero-Copy)**를 통해 네트워크 전송 중 호스트 CPU 사용률과 메모리 버스 트래픽 극소화
- 무손실(Lossless) 전송 보장: 링크 레벨의 엄격한 크레딧 기반 흐름 제어(Credit-Based Flow Control)를 통해 **네트워크 버퍼 넘침에 따른 패킷 드롭 원천 차단**
- 중앙화된 고속 라우팅: **서브넷 관리자(Subnet Manager)**가 전체 토폴로지를 사전에 탐색하여 컷스루(Cut-through) 스위칭 경로를 최적화

#### 한줄 요약
- 커널 우회와 제로 카피로 CPU 부하를 없애고, 크레딧 기반 흐름 제어로 무손실 고신뢰성 초저지연 통신을 보장한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **호스트 채널 어댑터(Host Channel Adapter, HCA)**: 서버의 PCIe 버스에 장착되어 RDMA 프로토콜 엔진과 주소 변환을 하드웨어로 고속 처리하는 전용 네트워크 카드.
- **큐 페어(Queue Pair, QP)**: RDMA 비동기 통신을 위해 송신 큐(Send Queue)와 수신 큐(Receive Queue)로 쌍을 이루는 엔드포인트 작업 큐.
- **완료 큐(Completion Queue, CQ)**: HCA가 처리를 완료한 송수신 작업의 결과(Work Completion)를 모아 응용 프로그램에 통지하는 큐.
- **서브넷 관리자(Subnet Manager, SM)**: 네트워크 토폴로지를 탐색하고 노드별 로컬 식별자(LID) 할당 및 최적 라우팅 경로를 일괄 설정하는 마스터 제어 엔진.

</details>

```text
[InfiniBand 클러스터 네트워크 패브릭]
 ┌─ [서버 노드 엔드포인트 A]                     ┌─ [서버 노드 엔드포인트 B]
 │   ├─ 사용자 공간 메모리 버퍼 (Registered Memory)│   ├─ 사용자 공간 메모리 버퍼 (Registered Memory)
 │   └─ [호스트 채널 어댑터 (HCA)]                 │   └─ [호스트 채널 어댑터 (HCA)]
 │       ├─ 큐 페어 (QP: Send Queue / Recv Queue)  │       ├─ 큐 페어 (QP)
 │       └─ 완료 큐 (CQ: Completion Queue)         │       └─ 완료 큐 (CQ)
 └──────────────────────┬──────────────────────────┘──────────────────────┬──────────────────────────┘
                        │ (400G / 800G NDR/XDR IB Links)                  │
 ┌──────────────────────▼─────────────────────────────────────────────────▼──────────────────────────┐
 │ [인피니밴드 스위치 패브릭 (InfiniBand Switch Fabric: Cut-Through 하드웨어 스위칭)]               │
 │  └─ [서브넷 관리자 (Subnet Manager: LID 할당 및 컷스루 라우팅 경로 제어)]                        │
 └──────────────────────────────────────────────────────────────────────────────────────────────────┘
```

선의 의미: 가지(`├─`, `└─`)는 하드웨어 소속 및 포함 관계; HCA 간 통신은 스위치 패브릭을 통해 컷스루 방식으로 직접 메모리 간 교환됨

| 구성요소 | 소속 및 위치 | 핵심 엔지니어링 책임 | 주요 특징 |
|:---|:---|:---|:---|
| **HCA (Host Channel Adapter)**| 서버 PCIe 슬롯 | RDMA 패킷화, 가상 주소 변환, 하드웨어 DMA 전송 엔진 총괄 | ConnectX HCA 칩셋 |
| **큐 페어 (QP)** | HCA 내부 메모리 | 송신(SQ) 및 수신(RQ) 비동기 전송 작업 디스크립터(WQE) 관리 | 락-프리 큐 구조 |
| **완료 큐 (CQ)** | HCA 내부 메모리 | 전송 완료된 작업(CQE)을 수집하여 사용자 프로그램에 통지 | 폴링/이벤트 지원 |
| **인피니밴드 스위치** | 네트워크 랙 장비 | 서브넷 관리자 경로에 따라 패킷을 나노초 단위로 **컷스루(Cut-Through) 중계** | 초저지연 스위칭 ASIC |
| **서브넷 관리자 (SM)**| 스위치 또는 전용 노드 | 토폴로지 탐색, **LID 할당, 포트 설정 및 라우팅 테이블 전역 배포** | 중앙 집중 제어 |

#### 한줄 요약
- 인피니밴드는 서버의 HCA(QP/CQ), 컷스루 스위치 패브릭 및 중앙 서브넷 관리자로 구성된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **메모리 등록(Memory Registration)**: RDMA 송수신에 사용할 가상 메모리 영역을 OS가 스왑 아웃하지 못하도록 물리 메모리에 고정(Pinning)하고 가상-물리 주소 변환표와 보호 키(L_Key / R_Key)를 발급받는 절차.

</details>

```text
1. RDMA 통신 초기화: 통신 버퍼 메모리 등록 (Memory Registration)
   ➔ 페이지 고정(Pinning) 및 하드웨어 보호 키(L_Key, R_Key) 발급
                      │
                      ▼
2. 송신 애플리케이션: HCA 송신 큐(Send Queue)에 작업 요청(WQE) 등록 (커널 우회!)
                      │
                      ▼
3. 송신 HCA: WQE 인출 ➔ 호스트 메모리에서 DMA로 데이터 직접 읽기 ➔ IB 패킷 캡슐화
                      │
                      ▼
4. 인피니밴드 스위치 패브릭 전송 (크레딧 기반 무손실 컷스루 라우팅)
                      │
                      ▼
5. 수신 HCA 도달 ➔ 보호 키(R_Key) 및 가상 주소 범위 하드웨어 검증
   ┌──────────────────┴──────────────────┐
[ 검증 실패 (보안 위반) ]             [ 검증 성공 (정상) ]
   │                                     │
   ▼                                     ▼
오류 패킷 폐기 및 에러 통지           6. 수신측 호스트 메모리로 DMA 직접 기록 (Zero-Copy)
   │                                     │
   └──────────────────┬──────────────────┘
                      │
                      ▼
7. 완료 큐(CQ)에 완료 이벤트(CQE) 기록 ➔ 애플리케이션이 폴링으로 완료 확인
```

분기 결과: **보호 키 검증이 통과하면** 수신측 CPU 개입 없이 원격 메모리에 직접 데이터가 기록(Zero-Copy)되어 마이크로초 내에 전송 완료됨

#### 한줄 요약
- 메모리 등록 ➔ 송신 큐 WQE 등록 ➔ HCA DMA 인출 ➔ 무손실 스위칭 ➔ R_Key 검증 ➔ 수신 메모리 직접 기록 ➔ CQ 완료 통지 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **RoCE v2(RDMA over Converged Ethernet v2)**: 표준 이더넷 인프라 위에서 UDP/IP 캡슐화를 통해 RDMA를 구현하는 기술.
- **iWARP**: 표준 TCP/IP 프로토콜 위에서 하드웨어 오프로딩을 통해 RDMA 통신을 제공하는 표준.

</details>

| 고성능 네트워킹 기술 | InfiniBand (NDR / XDR) | RoCE v2 (Ethernet) | iWARP (TCP/IP) | 표준 TCP/IP 이더넷 |
|:---|:---|:---|:---|:---|
| 물리 네트워크 계층 | **전용 인피니밴드 케이블/스위치** | 표준 이더넷 (PFC/ECN 스위치) | 표준 이더넷 스위치 | 표준 이더넷 케이블/스위치 |
| 통신 프로토콜 | **네이티브 InfiniBand 패브릭** | UDP/IP 캡슐화 RDMA | TCP/IP 캡슐화 RDMA | 표준 TCP/IP 소켓 스택 |
| 무손실 흐름 제어 | **하드웨어 크레딧 기반 (완벽 무손실)**| 소프트웨어 PFC/ECN 기반 (복잡) | TCP 윈도우 기반 (손실 복구) | 패킷 드롭 후 TCP 재전송 |
| 지연시간 (Latency)| **초저지연 ($< 1\mu\text{s}$)** | 저지연 ($1\sim 3\mu\text{s}$) | 중간 ($5\sim 10\mu\text{s}$) | 높음 ($20\sim 50\mu\text{s}$) |
| 인프라 구축 비용 | 고가 (전용 스위치 및 HCA) | 중간 (이더넷 스위치 재활용) | 중간 | **가장 저렴** |
| 주요 적용 분야 | **초대규모 LLM 분산 훈련, HPC** | 엔터프라이즈 AI 클러스터 | 광역망(WAN) 스토리지 복제 | 일반 웹 서비스, 파일 전송 |

#### 한줄 요약
- 초거대 AI 분산 훈련과 HPC에는 무손실이 완벽 보장되는 InfiniBand가 최적이며, 이더넷 재활용 환경에는 RoCE v2가 대안이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **GPUDirect RDMA**: CPU 메인 메모리를 거치지 않고 네트워크 HCA가 GPU VRAM(HBM)에 직접 P2P 전송을 수행하는 기술.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| GPU 간 분산 학습 시 CPU 시스템 메모리 경유로 인한 지연 | **GPUDirect RDMA 기반 HCA와 GPU VRAM 간 P2P 직결** | 호스트 복사 오버헤드 제거 및 통신 지연 50% 단축 |
| 대규모 클러스터에서 특정 링크 트래픽 쏠림 및 혼잡 발생 | **적응형 라우팅(Adaptive Routing) 및 하드웨어 ECN** 적용 | 패킷 경로 실시간 동적 분산 및 꼬리 지연시간 단축 |
| 서브넷 관리자(SM) 단일 장애로 인한 네트워크 전체 마비 | **서브넷 관리자 이중화(Master-Standby SM) 구성** | 결함 발생 시 무중단 페일오버 및 토폴로지 가용성 보장 |

#### 한줄 요약
- 실무에서는 GPUDirect RDMA로 GPU 직결 전송을 수행하고, 적응형 라우팅으로 혼잡을 해소하며, 서브넷 관리자 이중화로 신뢰성을 확보한다.

## Ⅶ. 결론

- 초대규모 생성형 AI 모델의 분산 훈련 및 고성능 슈퍼컴퓨팅 인프라를 구축하기 위해 **무손실 크레딧 흐름 제어와 초저지연 컷스루 스위칭을 제공하는 InfiniBand 패브릭을 표준 채택**하고, GPU 간 동기화 병목을 제거하기 위해 **GPUDirect RDMA 기술**을 적용하며, 클러스터 신뢰성을 위해 **서브넷 관리자 이중화 및 적응형 라우팅(Adaptive Routing)**을 필수 구현하는 고신뢰 고성능 AI 네트워크 아키텍처 확립

#### 한줄 요약
- 인피니밴드는 대규모 AI 클러스터의 스케일아웃 성능을 결정하는 핵심 패브릭이며, GPUDirect RDMA와의 결합을 통해 완성된다.
