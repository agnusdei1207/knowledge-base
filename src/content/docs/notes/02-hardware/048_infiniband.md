## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **인피니밴드(InfiniBand)**: 고성능 컴퓨팅(HPC) 및 대규모 AI 클러스터에서 서버와 스토리지 간 초고대역폭(최대 800Gbps NDR/XDR)과 마이크로초 미만 초저지연 통신을 제공하는 스위치 패브릭 네트워크 표준.
- **RDMA(Remote Direct Memory Access)**: OS 커널이나 CPU 개입 없이 네트워크 어댑터가 원격 노드의 메모리에 직접 데이터를 읽고 쓰는 기술.

</details>

- 정의/개념: 고성능 컴퓨팅(HPC) 및 AI 데이터센터에서 서버 노드 간 대규모 데이터를 초고속으로 전송하기 위한 커널 우회·초저지연 **스위치 패브릭 통신 표준 기술**
- 배경/필요성: 기존 TCP/IP 이더넷의 소프트웨어 프로토콜 스택 오버헤드로 인한 높은 지연시간과 패킷 손실 시 재전송으로 인한 **분산 학습 병렬 확장성 병목 한계 극복 및 하드웨어 무손실 초저지연 패브릭 구축 필요성 증대**

#### 한줄 요약
- **인피니밴드**는 RDMA 기반 커널 우회와 무손실 컷스루 스위칭을 통해 대규모 분산 AI 훈련 클러스터의 스케일아웃 네트워크를 완성하는 표준 기술이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **커널 우회(Kernel Bypass)**: 사용자 공간(User Space) 애플리케이션이 OS 커널 시스템 콜 없이 HCA 하드웨어와 직접 통신하여 CPU 오버헤드와 컨텍스트 스위칭을 제거하는 기법.
- **크레딧 기반 흐름 제어(Credit-Based Flow Control)**: 수신 버퍼에 여유 공간(크레딧)이 있을 때만 패킷을 전송하여 버퍼 오버플로로 인한 패킷 드롭 및 재전송을 원천 방지하는 하드웨어 메커니즘.

</details>

- **커널 우회** RDMA: OS 커널 및 TCP/IP 소프트웨어 스택을 완전히 우회하여 원격 노드 메모리에 직접 읽기/쓰기(Zero-Copy) 수행
- 하드웨어 무손실 전송: **크레딧 기반 흐름 제어(Credit-Based Flow Control)**를 통해 패킷 드롭 및 재전송 오버헤드를 하드웨어적으로 원천 차단
- 컷스루 스위칭: 패킷 전체를 수신하기 전에 헤더의 목적지 주소(LID)만 확인하고 즉시 포워딩하여 나노초 단위 스위칭 지연 실현

#### 한줄 요약
- 커널 우회 Zero-Copy RDMA, 크레딧 기반 완벽 무손실 흐름 제어, 컷스루 스위칭으로 마이크로초 미만의 초저지연을 실현한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **HCA(Host Channel Adapter)**: 인피니밴드 프로토콜 및 RDMA 엔진을 하드웨어로 처리하여 호스트 CPU 부하를 제로화하는 고성능 네트워크 인터페이스 카드.
- **큐 페어(Queue Pair, QP)**: RDMA 통신을 위해 생성되는 송신 큐(Send Queue)와 수신 큐(Receive Queue)의 쌍으로, 통신 종단점 역할을 수행.
- **서브넷 관리자(Subnet Manager, SM)**: 인피니밴드 서브넷 내의 모든 노드에 로컬 식별자(LID)를 부여하고 최적 라우팅 경로를 계산·배포하는 중앙 제어기.

</details>

```text
[인피니밴드 패브릭 아키텍처]
  │
  ├─ [중앙 서브넷 관리자] (SM, Subnet Manager)
  │     ├─ [LID 동적 할당기] (노드별 로컬 식별자 부여)
  │     └─ [전역 포워딩 테이블] (LFT 계산 및 스위치 배포)
  │
  ├─ [인피니밴드 스위치 패브릭] (무손실 패브릭)
  │     ├─ [컷스루 스위칭 엔진] (초저지연 목적지 LID 포워딩)
  │     └─ [크레딧 기반 흐름 제어] (버퍼 오버플로/패킷 드롭 차단)
  │
  └─ [노드 엔드포인트 계층] (송수신 HCA 어댑터)
        ├─ [호스트 채널 어댑터] (HCA ASIC, 하드웨어 RDMA)
        ├─ [큐 페어 & 완료 큐] (QP SQ/RQ 및 CQ 비동기 통신)
        ├─ [보안 키 검증기] (L_Key / R_Key 원격 메모리 보호)
        └─ [사용자 공간 고정 메모리] (Pinned DRAM, 커널 우회 직결)
```

선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| HCA | RDMA 패킷화와 DMA 전송 |
| 큐 페어 | 송수신 비동기 작업 관리 |
| 완료 큐 | 완료 작업 수집과 애플리케이션 통지 |
| 인피니밴드 스위치 | 컷스루 패킷 중계 |
| 서브넷 관리자 | LID·라우팅 경로 배포 |

#### 한줄 요약
- 큐 페어와 완료 큐가 응용 쪽에 그대로 노출돼 송수신마다 커널을 거치던 계층을 대신하고, 경로 결정은 노드마다 따로 계산하는 대신 서브넷 관리자가 LID와 경로를 일괄 배포하는 중앙 계층으로 옮겨 놓는다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **메모리 등록(Memory Registration)**: RDMA 송수신에 사용할 가상 메모리 영역을 OS가 스왑 아웃하지 못하도록 물리 메모리에 고정(Pinning)하고 가상-물리 주소 변환표와 보호 키(L_Key / R_Key)를 발급받는 절차.

</details>

```text
[InfiniBand 원격 직접 메모리 접근(RDMA) 흐름]
▼
1. 가상 메모리 등록(MR) 및 보호키 발급
├─ 물리 메모리 고정(Pinning) : OS 가상 메모리 스왑 아웃 방지
└─ 하드웨어 키 발급          : 송신자용 L_Key 및 원격 접근용 R_Key 생성
▼
2. 커널 우회 작업 요청 등록 (Kernel Bypass)
├─ 표준 TCP/IP : 소켓 API 호출 -> OS 커널 컨텍스트 스위칭 지연 발생
└─ RDMA        : 사용자 영역에서 HCA 송신 큐(SQ)로 작업 요청(WQE) 직접 투입
▼
3. Zero-Copy DMA 인출 및 패킷화
├─ 송신 HCA가 시스템 버스 제어하여 호스트 메모리 직접 DMA 인출
└─ CPU 복사 오버헤드 없이 IB 프로토콜 헤더 붙여 고속 패킷 조립
▼
4. 인피니밴드 스위치 패브릭 무손실 컷스루 전송
├─ 크레딧 기반 흐름 제어 : 버퍼 공간 사전 확보 후 전송 (패킷 드롭 방지)
└─ 목적지 LID 컷스루 포워딩 : 전체 패킷 수신 대기 없이 헤더 확인 즉시 전달
▼
5. 수신측 R_Key 검증 및 원격 메모리 직결 DMA 기록
├─ [R_Key 불일치] ─> 하드웨어 보안 위반 즉시 감지 및 연결 차단
└─ [R_Key 일치]   ─> 수신 CPU 무개입 타깃 RAM 직결 DMA 기록 및 CQE 통지
```

분기 결과: 보호 키 검증이 통과하면 수신측 CPU 개입 없이 원격 메모리에 직접 데이터가 기록되어 마이크로초 내 고속 전송 완료

**동작 원리**

1. **가상 메모리 등록 및 키 발급**: 애플리케이션이 전송 대상 가상 메모리를 물리 RAM에 페이징 고정(Pinning) 등록하고, HCA로부터 보안 접근용 L_Key와 원격 노드용 R_Key를 선제 발급
2. **커널 우회 작업 요청 등록**: 사용자 공간 애플리케이션이 OS 시스템 콜 없이 HCA의 전용 송신 큐(SQ)에 전송 작업 요청서(WQE)를 다이렉트로 투입
3. **Zero-Copy DMA 인출 및 패킷화**: 송신 HCA가 시스템 버스를 제어하여 호스트 메모리로부터 데이터를 제로 카피 DMA 방식으로 직접 읽어 들인 후 InfiniBand 프로토콜 패킷으로 조립
4. **크레딧 기반 컷스루 포워딩**: 패킷이 중간 스위치 패브릭을 통과하며, 크레딧 기반 흐름 제어에 따라 버퍼 오버플로 없이 목적지 LID 기반 컷스루 방식으로 나노초 단위 전송
5. **원격 메모리 직결 DMA 기록**: 수신측 HCA가 패킷의 R_Key를 하드웨어 검증한 후 수신 노드 CPU 개입 없이 타깃 HBM/DRAM 주소에 DMA로 직접 기록하고 완료 큐(CQ)에 이벤트 통지

#### 한줄 요약
- **메모리 등록**으로 페이지 고정과 보호 키 발급이라는 준비 비용을 한 번 선불하는 대신, 전송마다 반복되던 커널 진입과 수신측 CPU 복사를 통째로 없앤다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **RoCE v2(RDMA over Converged Ethernet v2)**: 표준 이더넷 인프라 위에서 UDP/IP 캡슐화를 통해 RDMA를 구현하는 기술.
- **iWARP**: 표준 TCP/IP 프로토콜 위에서 하드웨어 오프로딩을 통해 RDMA 통신을 제공하는 표준.

</details>

| 대상 구분 | InfiniBand (NDR / XDR) | RoCE v2 (Ethernet) | iWARP (TCP/IP) | 표준 TCP/IP 이더넷 |
|:---|:---|:---|:---|:---|
| 적용 기준 | 절대적 무손실과 마이크로초 미만 초저지연 HPC/초거대 AI 학습 클러스터 구축 시 | 기존 이더넷 스위치 인프라 재활용하며 RDMA 가속 구현 시 | 손실률 높은 광역망(WAN) 또는 복잡한 서브넷 환경에서 RDMA 전송 시 | 범용 웹 서비스 및 표준 서버 간 일반 데이터 통신 구축 시 |
| 핵심 특징 | 하드웨어 기반 크레딧 흐름 제어, **네이티브 무손실 컷스루 RDMA**, 서브넷 관리자 중앙 제어 | 표준 L3 IP 라우팅 지원, **PFC/ECN 기반 무손실 모사**, 기존 이더넷 장비 활용 | **TCP 계층 상위 RDMA 구현**, 손실 패킷의 하드웨어 재전송 처리 | 소켓 인터페이스, 광범위한 호환성 및 개방형 인프라 생태계 |
| 한계 | 인피니밴드 전용 스위치/HCA 도입 비용 고가, 단일 서브넷 관리 복잡성 | 버퍼 데드락(PFC 폭풍) 위험, 대규모 패브릭 설정 복잡성 및 튜닝 난도 | TCP 오프로드 엔진 복잡성, 높은 지연시간, 상용 벤더 생태계 축소 | OS 커널 메모리 복사(Double Copy), CPU 점유율 과다 및 수십 마이크로초 지연 |

#### 한줄 요약
- 초거대 AI 분산 훈련과 HPC에는 무손실이 완벽 보장되는 InfiniBand가 최적이며, 이더넷 재활용 환경에는 **RoCE v2**가 대안이며, TCP 기반 **iWARP**는 지연 증가로 대안에서 밀려났다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **GPUDirect RDMA**: CPU 메인 메모리를 거치지 않고 네트워크 HCA가 GPU VRAM(HBM)에 직접 P2P 전송을 수행하는 기술.
- **적응형 라우팅(Adaptive Routing)**: 스위치가 출력 포트별 큐 점유 상태를 보고 같은 목적지로 향하는 패킷을 홉마다 혼잡이 적은 경로로 동적으로 분산하는 InfiniBand 스위치 라우팅 방식.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 시스템 메모리 경유로 통신 지연 | **GPUDirect RDMA** 기반 GPU 메모리 P2P 직결 | 복사 오버헤드 제거 및 지연 50% 단축 |
| 특정 링크 트래픽 쏠림 및 혼잡 | **적응형 라우팅(Adaptive Routing)** 및 ECN | 패킷 동적 분산 및 꼬리 지연 단축 |
| 서브넷 관리자 장애 시 패브릭 마비 | **서브넷 관리자** 이중화(Master-Standby) | 무중단 페일오버 및 네트워크 가용성 보장 |

#### 한줄 요약
- 실무에서는 GPUDirect RDMA로 GPU 직결 전송을 수행하고, 적응형 라우팅으로 혼잡을 해소하며, 서브넷 관리자 이중화로 신뢰성을 확보한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **울트라 이더넷 컨소시엄(Ultra Ethernet Consortium, UEC)**: 초대규모 AI 워크로드 처리를 위해 패킷 비순서 전송 및 첨단 혼잡 제어를 표준화하는 개방형 초고속 패브릭 연합체.
- **선형 전달 테이블(Linear Forwarding Table, LFT)**: 서브넷 관리자가 로컬 식별자(LID) 기반 경로를 사전에 계산하여 인피니밴드 스위치에 주입하는 하드웨어 포워딩 테이블.

</details>

- **초고속 규격 및 패브릭 지능화 진화**: 하드웨어 기반 무손실 전송을 바탕으로 차세대(NDR 400G / XDR 800G) 스케일아웃 표준을 주도하는 가운데, 울트라 이더넷 컨소시엄(Ultra Ethernet Consortium, UEC)과의 상호 경쟁을 통한 개방형 초저지연 패브릭 고도화 추세.
- **실무 토폴로지 및 무손실 운영 통찰**: 초대규모 클러스터 배포 시 서브넷 관리자(SM)의 무중단 이중화와 선형 전달 테이블(Linear Forwarding Table, LFT) 정밀 튜닝을 선행하고, 패킷 정체를 방어하는 Fat-Tree 기반 내결함성 토폴로지 수립 필수.

#### 한줄 요약
- NDR/XDR 규격으로 초고속화되며 UEC와 경쟁·진화하고 있으며, 서브넷 관리자 이중화와 Fat-Tree 토폴로지 기반의 무손실 경로 설계가 핵심이다.
