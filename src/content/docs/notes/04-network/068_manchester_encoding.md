## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **맨체스터 인코딩(Manchester Encoding)**: 전송하고자 하는 디지털 이진 비트(0, 1)의 매 비트 구간 중앙에서 반드시 전압 준위 천이(Transition)가 발생하도록 비트와 클럭 신호를 XOR 결합하는 자가 동기화(Self-Clocking) 회선 부호화(Line Coding) 기술.
- **NRZ(Non-Return to Zero)**: 비트 구간 동안 일정한 전압 레벨(High/Low)을 유지하는 단순 부호화 방식으로, 동일 비트가 연속 수신될 때 클럭 동기화 손실(Clock Drift) 및 직류 바이어스(DC Wander)가 발생하는 한계 보유.

</details>

- 정의/개념: 매 비트 주기의 중앙 시점에서 강제적인 전압 상승(Low $\rightarrow$ High) 또는 하강(High $\rightarrow$ Low) 천이를 유발하여, 별도의 클럭 라인 없이 수신단에서 **클럭 신호 복구(Clock Recovery)** 와 데이터 복조를 동시에 달성하는 **물리 계층 2진 회선 부호화 기술**
- 배경/필요성: 초기 이더넷(IEEE 802.3 10BASE-T) 및 산업용 통신망에서 연속된 0 또는 1 전송 시 발생하는 송수신 클럭 비동기화 및 트랜스포머 직류 왜곡을 방지할 요구

#### 한줄 요약
- 비트 중앙의 전압 천이를 통해 클럭을 자가 복구하고 직류 성분을 제거하는 회선 부호화 기술이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **자가 동기화(Self-Clocking)**: 데이터 신호 자체에 클럭 정보(중앙 천이)가 내장되어 수신기의 위상 고정 루프(PLL)가 전송 데이터 스트림으로부터 클럭 펄스를 완벽히 추출해내는 특성.
- **직류 편향(DC Wander) 제거**: 매 비트 구간마다 양(+)의 전압과 음(-)의 전압이 정확히 50%의 듀티비(Duty Cycle)로 반분되므로 신호의 평균 전압(DC 성분)이 0V로 수렴.

</details>

- **완벽한 클럭 자가 복구**: 긴 연속 0 또는 1 패턴 유입 시에도 비트 중간 천이가 상시 보장되어 수신단 PLL 동기화 손실 원천 방지
- **직류 성분 제거(Zero DC Baseline)**: 전송 선로 상의 결합 변압기(Transformer Coupling) 포화를 방지하고 신호 왜곡 억제
- **대역폭 효율성 저하(Baud Rate 배가)**: 1비트 정보를 전송하기 위해 2개의 신호 심볼(2 보드)을 소모하므로 NRZ 대비 2배의 주파수 대역폭(20MHz for 10Mbps) 요구

#### 한줄 요약
- 자가 동기화와 직류 왜곡 제거를 달성하지만, 2배의 주파수 대역폭을 요구하는 트레이드오프가 존재한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **위상 고정 루프(Phase Locked Loop, PLL)**: 수신된 신호의 전압 천이(에지) 시점과 수신 내부 발진기 위상을 지속적으로 비교·보정하여 송신 클럭 주파수를 완벽히 추종하는 동기 회로.
- **에지 검출기(Edge Detector)**: 수신 파형의 상승 에지(Rising Edge) 및 하강 에지(Falling Edge) 시점을 정밀 검출하여 펄스를 생성하는 하드웨어 회로.

</details>

```text
[ 송신단 맨체스터 부호화 파이프라인 ]
 [ 데이터 비트 스트림 ] ──┬──▶ [ XOR 게이트 ] ──▶ [ 라인 드라이버 ] ──▶ 물리 전송 선로 (UTP)
 [ 송신 클럭 신호 (Clock) ] ──┘     (맨체스터 변환)      (차동 전압 송출)
                                                                            │
                                                                            ▼ (신호 감쇠 및 지터 발생)
[ 수신단 클럭 및 데이터 복원 파이프라인 ]                                   │
 [ 복원 데이터 ] ◀── [ 비트 디코더 ] ◀── [ 에지 검출기 ] ◀── [ 수신 등화기 ] ◀── UTP 수신 신호
                           ▲                    │
                           └─ [ 수신 PLL (클럭 복원) ] ◀┘
```

선의 의미: 데이터와 클럭이 XOR되어 전송된 후, 수신단에서 에지 검출 및 PLL을 통해 수신 클럭을 복원하고 원본 데이터를 복조하는 구조

| 구성요소 | 책임 및 역할 | 비고 |
|:---|:---|:---|
| **XOR 결합 부호기** | 원본 데이터 비트와 클럭 신호를 배타적 논리합(XOR)하여 중앙 천이 파형 생성 | 송신단 로직 |
| **물리 전송 선로** | UTP Cat3/Cat5 트위스티드 페어 케이블을 통해 차동 신호 전송 | 10BASE-T |
| **에지 검출기** | 수신 신호의 중간 전압 천이 시점을 캡처하여 타이밍 기준 펄스 생성 | 수신단 하드웨어 |
| **수신 PLL 모듈** | 추출된 천이 펄스를 기반으로 수신 샘플링 클럭을 잠금(Locking) 및 위상 보정 | Clock Recovery |
| **데이터 판정기** | 복원된 클럭 타이밍에 맞춰 중앙 천이 방향(하강=0, 상승=1)을 식별하여 비트 복원 | IEEE 802.3 표준 |

#### 한줄 요약
- XOR 부호기, 전송 선로, 에지 검출기, PLL 클럭 복구기, 비트 판정기가 결합하여 동작한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **IEEE 802.3 맨체스터 규격**: 비트 값 '0'은 High $\rightarrow$ Low(하강 천이), 비트 값 '1'은 Low $\rightarrow$ High(상승 천이)로 정의 (Thomas 규격은 반대로 정의).

</details>

```text
1. 송신기가 데이터 비트와 동기 클럭을 XOR 연산하여 비트 중앙 전압 천이 신호 생성
            │
            ▼
2. 차동 신호 형태로 구리 연선(UTP) 케이블을 통해 물리 신호 송출
            │
            ▼
3. 수신기의 에지 검출기가 매 비트 주기 중앙의 전압 변위(Rising/Falling Edge)를 포착
            │
            ▼
4. 수신 PLL 회로가 에지 타이밍을 추종하여 송신기와 완전히 동기화된 내부 수신 클럭 재생
            │
            ▼
5. 재생된 클럭의 샘플링 윈도우에서 전압 천이 극성을 판정 ➔ 원본 이진 비트(0 또는 1) 복원
```

**동작 원리**

1. **중앙 천이 생성**: 데이터 0은 전반부 High/후반부 Low, 데이터 1은 전반부 Low/후반부 High로 변환
2. **선로 전송**: 10Mbps 전송 시 최대 10MHz의 구형파 펄스가 전송 선로를 통과
3. **타이밍 추출**: 수신기가 매 비트 간격($T_b$)의 $T_b/2$ 지점에서 발생하는 에지 신호를 캡처
4. **위상 잠금**: 에지 신호를 PLL의 위상 비교기 입력으로 주입하여 주파수 오차 제로화
5. **극성 복조**: 중앙 천이의 기울기 부호($\Delta V / \Delta t$)를 판정하여 원본 데이터 스트림 출력

#### 한줄 요약
- XOR 파형 생성, 선로 송출, 중앙 에지 캡처, PLL 클럭 동기화, 극성 판정 비트 복원 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **차분 맨체스터 인코딩(Differential Manchester)**: 비트 중앙의 천이는 순수 클럭 동기화용으로만 사용하고, 비트 구간 시작점(Boundary)에서의 전압 천이 유무(천이 있음: 0, 천이 없음: 1)로 데이터를 판정하는 방식.

</details>

| 비교 항목 | 표준 맨체스터 (IEEE 802.3) | 차분 맨체스터 (Token Ring) | 비복귀 영점 (NRZ-L) |
|:---|:---|:---|:---|
| **비트 판정 기준** | **비트 중앙 천이의 방향 (상승=1, 하강=0)** | **비트 시작점의 천이 유무 (천이=0, 무천이=1)**| **비트 구간의 전압 절대 레벨 (H=1, L=0)** |
| **자가 동기화 능력** | **매우 우수 (매 비트 중앙 천이)** | **매우 우수 (매 비트 중앙 천이)** | **취약 (연속 비트 시 동기 손실)** |
| **선로 극성 반전 내성**| **취약 (UTP 결선 반전 시 0/1 반전 오류)**| **완전 면역 (상대적 천이 유무만 판정)** | 취약 (전압 레벨 반전 오류 발생) |
| **대역폭 소모 (보드율)**| **2 Baud/bit (대역폭 2배 소모)** | **2 Baud/bit (대역폭 2배 소모)** | **1 Baud/bit (대역폭 효율적)** |
| **대표 적용 표준** | 10BASE-T 이더넷 (IEEE 802.3) | IEEE 802.5 토큰링, 산업용 필드버스 | 고속 시리얼, 광통신, 8B/10B 기반망 |

#### 한줄 요약
- 표준 맨체스터는 극성 반전에 취약하며, 차분 맨체스터는 극성에 면역이고, NRZ는 대역폭 효율적이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **8B/10B 인코딩**: 8비트 데이터를 10비트 심볼로 매핑하여 최대 연속 동일 비트 길이를 5개 이하로 제한함으로써 직류 균형(DC Balance)과 클럭 동기화를 유지하는 고속 회선 부호화 기술.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| UTP 케이블 결선 실수(Tx+/Tx- 반전) 시 데이터 비트가 반전되어 통신 붕괴 | **차분 맨체스터(Differential Manchester)** 또는 **Auto-MDIX/극성 자동 보정** 적용 | 선로 결선 극성 오류 시에도 무중단 정상 비트 복조 |
| 기가비트(Gbps) 고속화 시 맨체스터의 2배 대역폭 오버헤드로 인한 전송 한계 | 고속망에서 맨체스터를 배제하고 **8B/10B, PAM4, 4B5B 고효율 부호화** 채택 | 주파수 대역폭 낭비 제거 및 1Gbps~100Gbps 초고속 회선 전송 실현 |
| 케이블 장거리 포설 시 고주파 신호 감쇠 및 에지 지터 누적으로 PLL 락 해제 | **저지터(Low-Jitter) PLL IC** 탑재 및 전송 선로 중간 **액티브 리피터** 배치 | 신호 파형 정형을 통한 에지 지터 제거 및 비트 오류율(BER) 억제 |

#### 한줄 요약
- 차분 맨체스터로 극성 반전을 극복하고, 고속망은 8B/10B로 전환하며, 저지터 PLL로 동기를 유지한다.

## Ⅶ. 결론

- 초기 10BASE-T 이더넷 및 고신뢰 임베디드 통신에서 **맨체스터 인코딩**은 완벽한 자가 동기화와 직류 바이어스 제거를 달성하는 핵심 물리 계층 기술이었으나, 전송 속도가 고속화(Gbps 이상)됨에 따라 주파수 대역폭 효율 한계를 극복하기 위해 현대 초고속 네트워크는 **8B/10B, 64B/66B 및 PAM4 다치 변조 체계**로 진화

#### 한줄 요약
- 맨체스터 인코딩의 자가 동기화 원리를 바탕으로 현대 고속망은 8B/10B 및 PAM4로 고도화되었다.
