## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **VPN (Virtual Private Network)**: 공용 인터넷망 상에 암호화 가상 터널을 형성하여 사설 전용선처럼 안전하게 통신하는 기술.
- **Split Tunneling (분할 터널링)**: 사내 업무 트래픽만 VPN 터널로 보내고 일반 인터넷 트래픽은 로컬 게이트웨이로 직접 분기하는 라우팅 기법.

</details>

- 정의/개념: 공용망 위에 **터널링 캡슐화, 암호화(ESP), 상호 인증(IKE)을 적용하여 기밀성과 무결성이 보장된 가상 사설 통신로를 구축하는 기술**
- 배경/필요성: 지사 연결 및 재택근무 시 물리적 전용회선의 **천문학적 회선 비용 발생 및 공용 인터넷 경유 시 패킷 도청·변조 위협**

#### 한줄 요약
- 터널링과 암호화를 통해 공용 인터넷 상에서 안전하고 경제적인 가상 전용망을 구축한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **PFS (Perfect Forward Secrecy, 전방향 안전성)**: 장기 개인키가 유출되더라도 과거 세션마다 독립적으로 생성된 임시 키들은 역산할 수 없도록 보장하는 암호학적 특성.
- **ESP (Encapsulating Security Payload)**: IPsec에서 데이터 암호화(AES-GCM), 무결성 검증, 안티 리플레이를 제공하는 프로토콜 (IP 프로토콜 50).

</details>

- **기밀성·무결성 보호**: 암호화와 인증 태그로 도청·변조 대응
- **계층별 적용 유연성**: Site-to-Site 백본망(L3 IPsec), 재택근무자 웹 포털(L7 SSL VPN), 저지연 모바일(L3 WireGuard) 지원
- **동적 키 교환 및 재키잉(Rekeying)**: IKEv2 및 Noise 프로토콜 기반 **주기적 세션 키 갱신을 통한 전방향 안전성(PFS) 보증**

#### 한줄 요약
- 기밀성/무결성 보장, 계층별 터널링 유연성, PFS 기반 주기적 재키잉을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **SA (Security Association)**: 암호 알고리즘, 세션 키, 모드(Transport/Tunnel), 수명을 정의한 종단 간 단방향 논리적 연결 계약.
- **IKEv2 (RFC 7296)**: Diffie-Hellman 키 교환을 통해 보안 연관(SA)을 자동 협상하고 수명주기를 관리하는 표준 프로토콜.

</details>

```text
[VPN 체계]
|-- VPN 클라이언트·지사 라우터
|-- 공용 인터넷
`-- VPN 게이트웨이
    |-- IKE·SA 엔진
    |-- ESP 처리기
    |-- 접근 제어기
    `-- 분할 터널 라우터
```

선의 의미: 원본 IP 패킷이 클라이언트에서 암호화 및 캡슐화되어 공용망을 통과한 후 게이트웨이에서 복호화되어 내부망에 전달되는 구조

| 구성요소 | 책임 |
|:---|:---|
| **VPN 게이트웨이** | 터널 종단과 내부망 접근 제어 |
| **IKE·SA 엔진** | 키 교환·인증·SA 수명 관리 |
| **ESP 처리기** | 암호화·무결성·재전송 방지 처리 |
| **분할 터널 라우터** | 목적지별 터널·로컬 경로 선택 |

#### 한줄 요약
- VPN 게이트웨이, IKE 키 협상기, ESP 암호 모듈, 분할 터널 라우터가 결합된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **IPsec Tunnel Mode**: 원본 IP 헤더 전체를 암호화하고 새로운 공용 IP 헤더(Outer IP)를 덧씌워 전송하는 망간 연동 표준 모드.

</details>

```text
IPsec IKEv2 핸드셰이크 및 데이터 전송 파이프라인
        │
   1. [IKE_SA_INIT] 클라이언트가 게이트웨이와 DH 키 교환을 수행하여 보안 제어 채널 수립
        │
   2. [IKE_AUTH] X.509 인증서 또는 사전 공유 키(PSK)로 상호 신원 인증 및 사용자 자격 검증
        │
   3. [Child SA 생성] 데이터 전송용 ESP SA가 생성되고 대칭 암호화 키 및 SPI 바인딩 완료
        │
   4. [ESP 캡슐화 송출] 원본 IP 패킷 전체를 AES-256-GCM으로 암호화 후 Outer IP를 붙여 터널 전송
        │
   ▼
5. [게이트웨이 복호화 전달] 수신 게이트웨이가 외부 헤더 제거 및 ESP 복호화 후 내부 사설망 전달
```

- 1. IKE_SA_INIT: DH 교환과 제어 SA 생성
- 2. IKE_AUTH: 피어 신원과 자격 검증
- 3. Child SA 생성: ESP 키와 SPI 설정
- 4. ESP 캡슐화 송출: 보호된 패킷 전송
- 5. 게이트웨이 복호화 전달: 검증 후 내부망 전달

#### 한줄 요약
- IKE SA 수립 → 상호 인증 → Child SA 생성 → ESP 캡슐화 전송 → 게이트웨이 복호화 전달 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **IPsec (L3 망 연동)** vs **SSL VPN (L7 웹 접속)** vs **WireGuard (모던 초경량 L3)**.

</details>

| 비교 항목 | IPsec VPN (IETF RFC 4301) | SSL/TLS VPN (OpenVPN / AnyConnect) | WireGuard (최신 커널 기반) |
|:---|:---|:---|:---|
| 동작 범위 | IP 패킷 터널 | 웹·응용 또는 전용 클라이언트 | IP 패킷 터널 |
| 암호 체계 | IKEv2·ESP | TLS | Noise·ChaCha20-Poly1305 |
| 클라이언트 | OS 내장·전용 소프트웨어 | 브라우저·전용 소프트웨어 | WireGuard 에이전트 |
| NAT 통과 | **NAT-T** 사용 | TLS 전송 경로 활용 | UDP 엔드포인트 로밍 |
| 적용 영역 | 지사·VPC 사이 터널 | 사용자 원격 접속 | 경량 호스트·클러스터 터널 |

#### 한줄 요약
- IPsec은 본사-지사 백본망, SSL VPN은 재택근무 웹 접속, WireGuard는 고속 모바일 및 클라우드 연동에 쓰인다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **MSS Clamping**: VPN 암호화 오버헤드로 인한 패킷 단편화(Fragmentation)를 막기 위해 TCP SYN의 MSS 크기를 1360~1400B로 강제 축소 보정하는 설정.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| VPN 암호화 오버헤드로 인한 MTU 초과 시 패킷 단편화 및 성능 저하 | **`TCP MSS Clamping (1360~1400B)` 및 PMTU Discovery 적용** | 패킷 단편화 제거 및 대용량 파일 전송 처리율 40% 향상 |
| 재택 단말 분할 터널링 시 감염 PC를 통한 내부망 침해 횡적 확산 | **`엔드포인트 EDR/ZTNA 검증` 및 사내 접근 허용 `최소 라우팅(Least Route)`** | VPN 터널 경유 악성코드 전파 차단 및 제로 트러스트 달성 |
| 장시간 동일 암호화 키 사용으로 인한 수학적 키 유출 및 세션 탈취 | **`PFS (Perfect Forward Secrecy)` 활성화 및 주기적 재키잉(Rekeying)** | 세션 키 주기적 갱신 및 과거 캡처 패킷 사후 복호화 차단 |
| 이동 근무자 IP 변경 시 VPN 세션 단절 및 재인증 지연 | **`WireGuard Roaming` 또는 IKEv2 MOBIKE (RFC 4555) 활성화** | Wi-Fi/LTE 망 전환 시에도 무단절 세션 유지 |

#### 한줄 요약
- MSS Clamping으로 MTU 병목을 제거하고, ZTNA 검증으로 분할 터널을 통제하며, PFS 재키잉으로 전방향 안전성을 확보한다.

## Ⅶ. 결론

- 지사 간은 **IPsec**, 웹 원격 접속은 SSL VPN 선택

#### 한줄 요약
- VPN은 터널링과 암호화를 통해 공용망 위에서 가상 전용선을 제공하며, IPsec, SSL, WireGuard의 맞춤형 결합으로 신뢰성을 확보한다.
