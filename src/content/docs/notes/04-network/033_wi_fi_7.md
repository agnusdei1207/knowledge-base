## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **Wi-Fi 7 (IEEE 802.11be EHT)**: 유선 기가 인터넷을 쌉발라버리는(최대 46Gbps) 초고속, 초저지연 괴물 무선 표준 규격이다. 극고처리량(EHT, Extremely High Throughput)이라고 불린다.
- **MLO(Multi-Link Operation)**: 2.4G와 5G 중 하나만 골라 쓰던 옛날과 달리, 주파수 3개(2.4/5/6GHz)를 동시에 다발로 묶어서 다운받는 사기 스킬이다.

</details>

- 정의: 다중 링크 동작(MLO), 320MHz 채널 폭, 4096-QAM을 갈아 넣어 **최대 46Gbps 전송 속도를 뽑아내는 차세대 무선 LAN 표준 규격**
- 배경: 단일 주파수 링크만으로는 AR/VR 메타버스나 8K 스트리밍이 요구하는 **극단적인 저지연성과 초고속 대역폭을 감당할 수 없었기 때문**

#### 한줄 요약

- 랜선 3개(2.4/5/6GHz)를 허공에 동시에 꽂아버리는 MLO 기술로 유선 인터넷 속도를 뛰어넘은 괴물 와이파이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **채널 천공(Preamble Puncturing)**: 도로(채널) 한가운데 공사 중(간섭)이면 옛날엔 도로 전체를 폐쇄했는데, 이젠 공사 구간만 쏙 빼고(천공) 나머지 도로로 차를 씽씽 달리게 하는 알뜰 기술이다.
- **Multi-RU (Multi-Resource Unit)**: 화물칸(RU) 하나만 쓰던 와이파이 6과 달리, 비어있는 화물칸 여러 개를 한 놈한테 몰아줘서 잉여 자원을 영혼까지 끌어모아 쓰는 할당 방식이다.

</details>

- **MLO 기반 다중 대역 결합**: 2.4/5/6GHz 대역을 짬뽕해서 한 번에 쏘거나, 간섭 생기면 딜레이 1ms도 없이 다른 채널로 휙 스위칭함.
- **320MHz 광대역 및 4096-QAM**: 차선을 160MHz에서 320MHz로 두 배 늘리고, 전파 파도 한 번에 데이터를 12비트(4096-QAM)씩 꽉꽉 구겨 넣음.
- **주파수 효율화 극대화**: 간섭 난 곳만 도려내는 **채널 천공**과 잉여 자원을 긁어모으는 **Multi-RU**로 버려지는 전파를 0으로 만듦.

#### 한줄 요약

- 3배로 묶어 쓰고(MLO), 2배로 넓히고(320MHz), 구겨 넣고(4096-QAM), 빈틈은 꿰매 쓰는(채널 천공) 극한의 튜닝이다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **MLD(Multi-Link Device)**: 와이파이 칩셋 안에 무선 랜카드를 여러 개 박아넣고, 겉으로는 랜카드 1개인 척 속여서 다중 통신을 통제하는 기계다.
- **MLO 스케줄러**: "5G는 막히니까 6G로 쏴라", "둘 다 뻥 뚫렸으니 둘 다 쏴라" 하고 트래픽 핑퐁을 실시간으로 지휘하는 뇌(두뇌)다.

</details>

```text
[ Wi-Fi 7 MLO 팩트 폭행 구조 ]

[ MLO 스케줄러 (트래픽 분배 두뇌) ]
         │
         ▼
[ AP MLD (Wi-Fi 7 공유기) ]
   │        │        │
(2.4G)   (5G)     (6G)  ◀── (이 3개 채널을 동시에 묶어서 쏨)
   │        │        │
   ▼        ▼        ▼
[ 단말 MLD (Wi-Fi 7 폰) ]
```

| 구성요소 | 팩트 폭행 책임 | 비고 |
|:---|:---|:---|
| **MLO 스케줄러** | 주파수 상태 실시간 눈치 보며 트래픽 쪼개주는 **브레인** | 분배/제어 |
| **AP MLD** | 주파수 3개를 한 번에 묶어서 쏴주는 **와이파이 7 공유기** | 기지국 |
| **단말 MLD** | 폰 하나로 2.4/5/6GHz 전파 3개를 동시에 다 받아먹는 **괴물 단말** | 스마트폰/PC |
| **무선 링크 집합** | 물리적으로 쪼개져 있지만 논리적으론 한 파이프처럼 쓰는 **3차선 고속도로** | 채널 묶음 |

#### 한줄 요약

- MLO 스케줄러가 대가리를 굴려서 2.4/5/6GHz 전파 3개를 하나의 단말에 융단폭격하듯 쏴버린다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **STR(Simultaneous Transmit and Receive)**: 2.4G로 다운받으면서 동시에 6G로 업로드하는 짓이 상호 간섭 없이 부드럽게 되는 미친 묘기다.
- **동적 링크 스위칭**: 5G로 게임 중 핑이 튀면, 0.1초 만에 6G 채널로 휙 옮겨버려 렉을 아예 못 느끼게 하는 사기 스킬이다.

</details>

```text
[ Wi-Fi 7 MLO 동작 십자포화 흐름 ]

┌──────────────────────────────┐
│ 1. [MLD 역량 협상]           │
│ (너 채널 3개 동시 지원하냐?) │
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 2. [멀티 링크 결합]          │
│ (ㅇㅇ 2.4/5/6GHz 싹 다 연결!)│
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 3. [채널 상태 실시간 눈치게임]
│ (어디가 쾌적한지 간보기)     │
└──────────────┬───────────────┘
      ┌────────┴────────┐
(어느 한 곳 핑 튐)   (채널 2개가 다 뻥 뚫림)
      │                 │
      ▼                 ▼
┌────────────────┐┌──────────────────────────────┐
│ 4a. 링크 스위칭││ 4b. STR 동시 전송            │
│ (안 튀는 쪽으로││ (2개 채널에 데이터 쪼개서    │
│  데이터 휙 넘김││  동시에 폭격함)              │
└────────────────┘└──────────────────────────────┘
```

### 동작 원리

1. 역량 협상: 단말이 AP한테 "나 주파수 3개 동시 수신(STR) 가능함" 하고 스펙 자랑.
2. 링크 결합: 교환된 스펙 바탕으로 2.4/5/6GHz 링크를 한 큐에 다 뚫음.
3. 실시간 모니터링: 스케줄러가 각 주파수마다 간섭 쩌는지 핑(퍼포먼스) 실시간 측정.
4. 스위칭 및 폭격: 막히면 안 막히는 채널로 휙 넘기고(스위칭), 다 뚫려있으면 쪼개서 한 번에 쏨(STR).

#### 한줄 요약

- 주파수 3개 다 연결해 놓고 핑 튀면 요리조리 옮겨 타거나 3개 다 써서 한 번에 쏟아붓는다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **Wi-Fi 6E**: Wi-Fi 6 스펙 그대로 6GHz라는 신규 청정 도로만 뚫어준 반쪽짜리 과도기 세대다.
- **QAM**: 전파의 파도(진폭/위상) 모양을 꺾어서 한 파도에 비트(0과 1)를 몇 개나 구겨 넣을지 결정하는 변조 스킬이다. (4096-QAM은 12비트를 한 번에 전송)

</details>

| 비교 항목 | **Wi-Fi 6 / 6E (ax)** | **Wi-Fi 7 (be)** |
|:---|:---|:---|
| 개발 목표 | HE (High Efficiency) - 사람 미어터진 곳에서 **생존** | **EHT** (Extremely High Throughput) - 극강의 **초고속** |
| 최대 속도 | 9.6 Gbps | **46 Gbps** (유선 랜 쌉발라버림) |
| 변조 기법 | 1024-QAM (10비트) | **4096-QAM** (12비트, 데이터 구겨 넣기 끝판왕) |
| 채널 대역폭 | 160MHz | **320MHz** (6GHz 한정, 초대형 광폭 도로) |
| 다중 링크 | Single Link (채널 1개만 택일) | **MLO** (3개 채널 동시 묶음) |

#### 한줄 요약

- Wi-Fi 6가 꽉 막힌 도로 차선 정리라면, Wi-Fi 7은 차선 2배 늘리고 고가도로까지 파서 트럭 3대 동시에 모는 거다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **mGig (Multi-Gigabit)**: 무선 속도가 40Gbps인데 유선 랜선이 1Gbps면 병목이 터지니까, 유선도 2.5G, 5G, 10G로 빵빵하게 뚫어주는 멀티 기가비트 이더넷 스위치다.

</details>

| 장애/위험 요소 | 원인 분석 | 실무 대책 및 해결방안 | 기대 효과 |
|:---|:---|:---|:---|
| 320MHz 초광폭 뚫었더니 **옆집 공유기랑 간섭 터져 다 뻗음** | 너무 넓은 채널 폭에 의한 인접 AP 간 무지성 중첩 | **채널 천공(Preamble Puncturing)** 켜서 겹치는 차선만 핀포인트 컷 | 간섭 씹어 먹고 광대역 실효 처리량 떡상 |
| 4096-QAM 켰는데 **속도 안 나오고 핑만 존나 튐** | 신호가 구려서(SNR 낮음) 12비트 변조 뻑나고 재전송 늪 빠짐 | 공유기 커버리지 축소 및 **고밀도 AP 떡칠 배치**, 송신 출력 튜닝 | 최고 속도 변조(4096-QAM) 100% 유지 보장 |
| Wi-Fi 7 AP 달았는데 **구형 폰(똥차)이 채널 쳐먹어서 다 느림** | MLO 단말과 레거시 단말이 자원 경쟁 | MLO 전용 **SSID 분리** 및 똥차 5G/2.4G 강제 유배(Band Steering) | MLO 단말 극저지연 및 EHT 성능 100% 보장 |
| 와이파이 속도는 10기가인데 **실제 인터넷은 1기가밖에 안 나옴** | 천장에 꽂힌 **유선 백본 스위치(1Gbps)** 가 어이없게 병목임 | AP 스위치를 **10GbE mGig** 및 mPoE++ 로 싹 다 갈아엎음 | 유/무선 대역폭 언밸런스 병목 대참사 해결 |

#### 한줄 요약

- 비싼 Wi-Fi 7 달아놓고 유선 랜선 1기가짜리 꽂으면 개그니까, 무조건 유선 스위치 10Gbps로 싹 갈아엎어라.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- (상단 참조)

</details>

- 무지성으로 Wi-Fi 7 AP만 달면 유선 백본 병목으로 폭망하므로, **10GbE mGig 백본 승급**과 MLO 전용 SSID 분리, 그리고 **채널 천공** 기반 간섭 제어가 동반되는 엔터프라이즈 무선 아키텍처 기조 확립함

#### 한줄 요약

- Wi-Fi 7의 본체는 무선 기기가 아니라, 쏟아지는 무선 트래픽 46Gbps를 받아낼 수 있는 10기가 유선 백본 설계에 있다.
