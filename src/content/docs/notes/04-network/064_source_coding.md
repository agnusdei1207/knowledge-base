## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **Source Coding (소스 부호화)**: 정보원에 존재하는 통계적 중복성(Redundancy)을 제거하여 데이터 표현 비트 수를 압축하는 기술.
- **Shannon Entropy ($H(X)$)**: 무손실 압축이 도달할 수 있는 이론적 최소 평균 부호 길이 ($H(X) = -\sum P(x_i) \log_2 P(x_i)$).

</details>

- 정의/개념: 심볼 발생 확률의 차이를 이용하여 자주 등장하는 심볼에 짧은 비트를 할당함으로써 평균 부호 길이를 엔트로피 한계에 수렴시키는 무손실 압축 기술
- 배경/필요성: 문자, 음성, 영상 등의 디지털 정보원(Source)은 특정 심볼이나 패턴이 빈번하게 반복되는 심각한 통계적 중복성(Redundancy)을 내포하고 있으며, 모든 심볼에 고정된 길이(Fixed-Length)의 비트를 일률적으로 할당할 경우 대규모 네트워크 전송 대역폭 낭비와 스토리지 저장 비용 폭증을 초래하는 한계를 극복하기 위해, 심볼의 출현 확률 $P(x_i)$에 반비례하여 자주 등장하는 심볼에는 짧은 비트를, 드물게 등장하는 심볼에는 긴 비트를 할당하는 가변 길이 접두 부호(Prefix Code: 허프만 부호, 산술 부호) 기반의 **소스 부호화**(Source Coding**)를 도입하여 **통계적 중복성 90% 이상 제거, 섀넌 엔트로피 한계($H(X)$)로의 무손실 데이터 압축 및 전송 효율 극대화를 달성할 필요

#### 한줄 요약
- 가변 길이 부호화와 엔트로피 최소화를 통해 데이터 전송 대역폭과 저장 공간을 절감한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **Prefix Code (접두 부호)**: 어떤 부호어도 다른 부호어의 앞부분(Prefix)이 되지 않도록 설계하여 쉼표 없이 즉시 디코딩할 수 있는 특성.
- **Kraft Inequality (크라프트 부등식)**: 유일하게 복호 가능한 접두 부호가 존재하기 위한 부호 길이 조건 ($\sum 2^{-l_i} \le 1$).

</details>

- 가변 길이 부호화(VLC): 발생 확률 $P(x_i)$에 반비례하여 부호 길이 $l_i = \lceil -\log_2 P(x_i) \rceil$ 비트를 가변 할당
- 순시 복호성(Instantaneous Decodability): 접두 부호(**Prefix Code**) 조건을 만족하여 구분자 없이 실시간 연속 디코딩
- 무손실 데이터 가역성(Lossless): 코드북 및 확률 모델을 통해 원본 데이터를 100% 비트 단위로 완전 복원

#### 한줄 요약
- 가변 길이 부호화, 접두 부호 기반 순시 복호성, 엔트로피 한계 기반 무손실 압축을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **Codebook (코드북)**: 원본 심볼과 가변 길이 이진 부호어를 1:1 매핑한 변환 참조 테이블.
- **CABAC (Context-based Adaptive Binary Arithmetic Coding)**: 이전 비트 패턴의 문맥을 학습하여 산술 부호화 확률을 실시간 갱신하는 비디오 압축 기술.

</details>

```text
[소스 부호화 체계]
  ├── [분석 계층] ───────── [확률 모델러]
  │                           │
  ├── [압축 계층] ───────── [소스 부호기 / 코드북]
  │                           │
  └── [복원 계층] ───────── [소스 복호기]
```

- 선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 확률 모델러 | 심볼의 **정적·동적 확률 분포 산출** |
| 소스 부호기 | 허프만·산술 기반 **압축 비트열 생성** |
| **코드북** | 심볼과 **가변 길이 부호 매핑** |
| 소스 복호기 | 비트열의 **원본 심볼 복원** |

#### 한줄 요약
- 확률 모델러가 부호기 앞에서 심볼별 비트 길이를 결정하고 코드북이 그 결과를 송수신 양단의 공유 사본으로 남기므로, 복호기는 별도 부가 정보 없이 원본을 복원한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Huffman Tree Builder**: 가장 발생 빈도가 낮은 2개 심볼을 묶어 상향식(Bottom-Up)으로 이진 트리를 구성하는 알고리즘.

</details>

```text
허프만 부호화 압축 및 순시 복호 파이프라인
        │
   [심볼 빈도수 계산] 원본 데이터를 스캔하여 심볼별 출현 확률 $P(x_i)$ 도출
        │
   [허프만 트리 구축] 최소 확률 노드 2개를 결합하며 이진 트리 구성 (0/1 간선 할당)
        │
   [접두 부호어 확정] 루트부터 리프 노드까지 경로를 추적하여 가변 길이 부호어 생성
        │
   [비트 치환 및 전송] 원본 데이터를 비트로 압축 치환하고 코드북 헤더와 함께 송출
        │
   ▼
[순시 트리 디코딩] 수신 복호기가 비트 스트림을 트리에 대조하여 리프 노드 도달 즉시 원본 복원
```

#### 한줄 요약
- 접두 부호 특성상 복호는 구분자 탐색 없이 비트 스트림을 그대로 소비하므로, 압축률의 대가는 전송·복호가 아니라 송신단의 빈도 계측과 트리 구성 연산에 몰린다.

## Ⅴ. 종류 및 비교


| 비교 항목 | 허프만 부호화 (Huffman Coding) | 산술 부호화 (Arithmetic Coding) |
|:---|:---|:---|
| 비트 할당 단위 | 정수 비트 단위 (최소 1 bit/symbol) | 비정수 실수 비트 단위 ($<1$ bit/symbol 가능)|
| 압축 효율성 | 엔트로피 한계와 소폭 오차 존재 ($H \le L < H+1$) | 섀넌 엔트로피 한계에 거의 100% 완전 근접 |
| 연산 복잡도 | 낮음 (이진 트리 탐색으로 초고속 처리) | 높음 (고정밀 부동소수점 누적 연산 요구) |
| 알고리즘 구현 | 표준 공개 알고리즘 (구현 용이) | 연산 정밀도 및 하드웨어 가속기 요구 |
| 주요 활용 분야 | ZIP, GZIP, MP3, JPEG 허프만 테이블 | H.264/AVC, H.265/HEVC (CABAC), JPEG-2000 |

#### 한줄 요약
- 허프만은 정수 비트 단위의 경량·고속 압축에 적합하고, 산술 부호화는 고화질 비디오의 극한 압축에 최적화된다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Error Propagation (오류 전파)**: 가변 길이 부호(VLC) 스트림 전송 중 1비트 에러가 발생하면 이후 모든 부호어 경계가 어긋나 전체가 붕괴되는 현상.
- **Restart Marker**: 압축 비트열 중간에 고정 동기 패턴을 삽입하여 오류 발생 시 다음 마커부터 정상 복구를 재개시키는 기술.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 가변 길이 부호 전송 중 1비트 반전 시 후속 전체 디코딩 붕괴 | 압축 스트림 내 주기적 재시작 마커(**Restart Marker**) 삽입 | 비트 오류 전파 범위를 마커 구간 내로 국소 격리 |
| 소용량 단문 압축 시 코드북 헤더 오버헤드로 인한 역압축 | 크기 임계치 검사 및 표준 사전 정의 코드북(Static Table) 활용 | 단문 메시지 압축 오버헤드 방지 및 대역폭 절감 |
| 실시간 4K/8K 스트리밍 시 산술 부호화(CABAC) 복호 연산 병목 | 전용 하드웨어 비디오 디코더(ASIC/VPU) 및 파이프라인 가속 | 고해상도 영상의 실시간 60fps 무지연 복호 처리 |
| 무선 채널 전송 시 압축 비트열의 높은 비트 에러 민감도 | 소스 코딩 후단에 강력한 채널 코딩(FEC/LDPC) 필수 결합 | 물리 계층 비트 오류 복원 및 무손실 압축 해제 보장 |

#### 한줄 요약
- Restart Marker로 **오류 전파**를 차단하고, Static Table로 역압축을 방지하며, ASIC 가속과 FEC를 결합한다.

## Ⅶ. 결론

- 현대 디지털 멀티미디어(H.264/H.265 CABAC, JPEG), 웹 데이터 압축(GZIP, Brotli, Zstandard) 및 대규모 언어 모델(LLM) 토크나이저에 이르기까지 모든 디지털 정보 처리와 네트워크 전송의 가장 기초가 되는 핵심 정보 이론 기반 압축 기술로 자리잡았으며, 실무 시스템 구현 시에는 가변 길이 부호(VLC) 특성상 1비트 에러가 전체로 번지는 오류 전파(Error Propagation)를 차단하기 위한 재시작 마커(Restart Marker) 삽입, 실시간 고화질 영상 처리를 위한 하드웨어 VPU 가속기 적용, 무선 전송 시 물리 계층 채널 코딩(FEC/LDPC)과의 필수적 융합을 결합하여 완벽한 압축률과 전송 안정성을 완성

#### 한줄 요약
- 소스 부호화는 통계적 중복성을 제거하여 엔트로피 한계의 압축을 달성하는 핵심 데이터 압축 기술이다.
