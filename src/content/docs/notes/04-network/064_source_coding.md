## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **소스 코딩(Source Coding / Source Encoding)**: 아날로그 원시 신호 또는 디지털 텍스트/미디어 데이터에 존재하는 통계적 중복성(Redundancy)을 제거하여, 정보 손실 없이 또는 최소의 왜곡으로 데이터 표현 비트 수를 압축하는 기술.
- **섀넌 엔트로피(Shannon Entropy, $H(X)$)**: 정보원(Source)이 생성하는 심볼들의 평균 정보량을 나타내며, 무손실 압축이 달성할 수 있는 이론적 최소 평균 부호 길이(비트/심볼)의 하한선 ($H(X) = -\sum P(x_i) \log_2 P(x_i)$).

</details>

- 정의/개념: 심볼 발생 확률의 불균일성을 이용하여 자주 등장하는 심볼에는 짧은 비트열을, 드물게 등장하는 심볼에는 긴 비트열을 할당함으로써 **평균 부호 길이를 엔트로피 한계($H(X)$)에 수렴시키는 무손실 데이터 압축 기술**
- 배경/필요성: 고용량 멀티미디어(4K/8K 비디오, 무손실 오디오) 및 대규모 네트워크 트래픽을 제한된 전송 대역폭과 스토리지 인프라에서 효율적으로 수용할 요구

#### 한줄 요약
- 통계적 중복성을 제거하여 평균 비트 길이를 섀넌 엔트로피 한계에 근접시키는 데이터 압축 기술이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **가변 길이 부호(Variable Length Code, VLC)**: 모든 심볼에 동일한 비트 길이를 부여하는 고정 길이 부호(FLC)와 달리, 심볼별 발생 확률의 역수에 비례하여 가변적인 비트 길이를 부여하는 부호화 방식.
- **접두 부호(Prefix-Free Code / Prefix Code)**: 어떤 부호어도 다른 유효한 부호어의 앞부분(접두사)과 일치하지 않도록 설계하여, 비트 스트림 사이에 별도의 구분자(Delimiter) 없이도 수신단에서 즉각 유일 복호(Unique Decodability)가 가능한 부호 체계.

</details>

- **확률 기반 가변 비트 할당**: 심볼 발생 확률 $P(x)$에 반비례하여 비트 길이 $L(x) \approx \log_2(1/P(x))$를 할당하여 전체 데이터 전송량 최소화
- **순시 복호성(Instantaneous Decodability)**: **접두 부호(Prefix Code)** 조건을 만족하여 비트 수신 즉시 역방향 탐색 없이 순차적 토큰 분리 가능
- **무손실 데이터 가역성(Lossless Reversibility)**: 코드북(Codebook) 및 확률 모델 매핑을 통해 원본 데이터를 100% 비트 단위로 완벽 복원

#### 한줄 요약
- 가변 길이 부호화, 접두 부호 기반 순시 복호성, 엔트로피 한계 기반 무손실 압축을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **코드북(Codebook)**: 원본 심볼과 이에 대응하는 가변 길이 이진 부호어(Bit Sequence)를 1:1 매핑한 변환 참조 테이블.
- **문맥 모델링(Context Modeling)**: 이전 심볼들의 패턴을 기반으로 현재 심볼의 발생 확률을 동적으로 추정하여 압축 효율을 극대화하는 통계 엔진 (CABAC 등).

</details>

```text
[ 송신단 소스 부호화 파이프라인 ]
 [ 입력 원본 심볼 스트림 ] ──▶ [ 확률 통계 모델러 ] ──▶ [ 소스 부호기 (Encoder) ] ──▶ 압축 비트열 송출
                                   (심볼별 발생 확률 추정)       (허프만 / 산술 부호화)
                                                                                         │
                                                                                         ▼ (네트워크 전송)
[ 수신단 소스 복호화 파이프라인 ]                                                         │
 [ 복원 원본 심볼 스트림 ] ◀── [ 소스 복호기 (Decoder) ] ◀── [ 코드북 / 확률 모델 파싱 ] ◀── 압축 비트열 수신
```

선의 의미: 원본 데이터가 확률 모델러를 거쳐 최적 비트로 압축되고, 수신단에서 코드북과 복호기를 통해 손실 없이 원본 심볼로 복원되는 파이프라인

| 구성요소 | 책임 및 역할 | 비고 |
|:---|:---|:---|
| **확률 모델러 (Modeler)** | 소스 데이터 내 심볼 빈도수를 계측하여 정적/동적 확률 분포 산출 | Static / Adaptive |
| **소스 부호기 (Encoder)** | 허프만 트리 구성 또는 산술 구간 분할을 통해 이진 압축 비트열 생성 | VLC / CABAC |
| **코드북 (Codebook)** | 압축 해제에 필요한 이진 트리 구조 및 심볼-부호 매핑 정보 제공 | 헤더 오버헤드 |
| **소스 복호기 (Decoder)** | 수신된 비트열을 접두 부호 트리를 따라 1비트씩 파싱하여 원본 복원 | 유일 복호화 |

#### 한줄 요약
- 확률 모델러, 소스 부호기, 코드북, 소스 복호기가 결합하여 무손실 압축 및 복원을 수행한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **허프만 트리 구성 알고리즘**: 모든 심볼을 발생 빈도순으로 정렬한 후, 가장 확률이 낮은 두 노드를 반복적으로 병합하여 상향식(Bottom-Up) 이진 트리를 완성하는 절차.

</details>

```text
1. 원본 데이터 소스 전체를 스캔하여 각 심볼의 출현 빈도수 및 확률 $P(x_i)$ 계산
            │
            ▼
2. 최소 확률 노드 2개를 결합하며 이진 트리 구성 (좌측 간선 '0', 우측 간선 '1' 할당)
            │
            ▼
3. 루트 노드부터 리프 노드까지의 경로를 추적하여 심볼별 최적 가변 접두 부호어 확정
            │
            ▼
4. 원본 심볼을 해당 부호어로 치환하고, 코드북 메타데이터 및 재시작 마커(Restart Marker)와 함께 전송
            │
            ▼
5. 수신 복호기가 비트 스트림을 트리에 대조하며 리프 노드 도달 시 원본 심볼을 즉시 출력 복원
```

**동작 원리**

1. **통계 추출**: 원본 데이터 내 문자/픽셀 빈도를 계측하여 우선순위 큐(Priority Queue) 구성
2. **트리 빌드**: 빈도가 낮은 심볼부터 결합하여 확률이 높은 심볼이 루트 인접(짧은 경로)에 위치하도록 트리 생성
3. **인코딩**: 각 심볼을 생성된 이진 코드로 변환하여 비트 패킹
4. **순시 디코딩**: 수신단은 비트 단위로 트리의 간선을 탐색하며 리프(Leaf) 노드를 만날 때마다 심볼을 1:1 디코딩

#### 한줄 요약
- 심볼 빈도 계측, 허프만 트리 구성, 접두 부호 생성, 비트 패킹 전송, 순시 디코딩 순으로 처리된다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **허프만 부호화 vs 산술 부호화**: 심볼마다 최소 1비트 이상의 정수 비트를 할당하는 방식과, 전체 메시지를 $[0, 1)$ 사이의 단일 실수 소수점 구간으로 매핑하여 비정수(Fractional) 비트 압축을 달성하는 방식.

</details>

| 비교 항목 | 허프만 부호화 (Huffman Coding) | 산술 부호화 (Arithmetic Coding) |
|:---|:---|:---|
| **비트 할당 단위** | **정수 비트 단위 (최소 1 bit/symbol)** | **비정수 실수 비트 단위 ($<1$ bit/symbol 가능)** |
| **압축 효율성** | 엔트로피 한계와 소폭 오차 존재 ($H \le L < H+1$) | **섀넌 엔트로피 한계에 거의 100% 완전 근접** |
| **연산 복잡도** | **낮음 (이진 트리 탐색으로 초고속 처리)** | 높음 (고정밀 부동소수점 누적 곱셈/나눗셈 요구) |
| **특허 및 구현** | 표준 공개 알고리즘 (구현 용이) | 특허 이슈 및 하드웨어 연산기 최적화 요구 |
| **주요 활용 분야** | **ZIP, GZIP, MP3, JPEG 허프만 테이블** | **H.264/AVC, H.265/HEVC (CABAC), JPEG-2000** |

#### 한줄 요약
- 허프만은 정수 비트 단위의 경량·고속 압축에 적합하고, 산술 부호화는 고화질 비디오의 극한 압축에 최적화된다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **오류 전파(Error Propagation)**: 가변 길이 부호(VLC) 스트림 전송 중 1비트의 오류가 발생하면 이후 모든 부호어의 경계 판정이 어긋나 전체 데이터가 왜곡되는 취약성.
- **재시작 마커(Restart Marker)**: 압축 비트열 중간에 고유한 고정 비트 패턴을 삽입하여, 오류 발생 시 다음 마커 위치부터 디코딩을 정상 재개할 수 있도록 분할 격리하는 동기화 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 가변 길이 부호 전송 중 1비트 반전 시 후속 전체 데이터 디코딩 붕괴 (오류 전파) | 압축 스트림 내 주기적 **재시작 마커(Restart Marker / Sync Byte)** 삽입 | 비트 오류 전파 범위를 마커 구간 내로 국소화 및 디코딩 복원 |
| 초소형 데이터 압축 시 코드북(헤더) 오버헤드로 인한 역압축(데이터 용량 증가) | 데이터 크기 임계치 검사 및 표준 **사전 정의 코드북(Static Table)** 활용 | 단문 메시지 압축 오버헤드 방지 및 대역폭 낭비 차단 |
| 실시간 4K/8K 스트리밍 시 산술 부호화(CABAC) 복호 연산 부하로 인한 버퍼링 | **전용 하드웨어 비디오 디코더(ASIC/VPU)** 및 파이프라인 병렬화 적용 | 고해상도 영상의 실시간 60fps 무지연 복호 처리 달성 |

#### 한줄 요약
- Restart Marker로 오류 전파를 차단하고, Static Codebook으로 역압축을 방지하며, 전용 하드웨어 ASIC으로 산술 연산을 가속한다.

## Ⅶ. 결론

- 대용량 데이터 전송 효율을 극대화하기 위해 텍스트 및 일반 파일 시스템에는 경량 **허프만 부호화**, 고효율 비디오 코덱에는 엔트로피 한계에 도달하는 **산술 부호화(CABAC)** 를 표준으로 채택하되, 무선 전송 시 발생하는 비트 오류 전파 취약성을 방어하기 위해 **채널 코딩(FEC)** 및 **재시작 동기 마커**를 결합하여 압축 효율성과 전송 복원력을 동시에 확보

#### 한줄 요약
- 허프만/산술 부호화의 엔트로피 압축과 채널 코딩의 신뢰성 보장을 결합하여 전송 인프라를 최적화한다.
