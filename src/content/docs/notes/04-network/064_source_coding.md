## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **소스 코딩(Source Coding)**: 원천 데이터(Source Data)의 통계적 중복성(Redundancy)을 제거하여 표현 비트 길이를 최소화하는 무손실/유손실 압축 부호화 기술.
- **엔트로피(Entropy)**: 정보 이론에서 심벌 발생 확률 분포에 따른 심벌당 표현 최저 평균 비트 수의 이론적 한계치($H(X) = -\sum P(x) \log_2 P(x)$).

</details>

- 정의/개념: **소스 코딩**은 통계적 중복이나 지각적 비중을 이용해 원천 데이터의 표현 비트 수를 줄이는 무손실·유손실 부호화 기술.
- 배경/필요성: 원시 텍스트, 이미지, 비디오 데이터를 원형 전송 시 대역폭 과다 점유 및 저장 비용 상승이 발생하므로 전송 효율성 극대화를 위한 데이터 압축 처리 필수.

#### 한줄 요약

- 정보 발생 확률에 따른 엔트로피 기반 비트 가중치 배정으로 전송 대역폭을 최적화하는 소스 코딩 기술 적용.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **심벌(Symbol)**: 데이터 소스를 구성하는 문자, 알파벳, 화소 값, 양자화 토큰 등의 최소 부호화 단위.
- **접두 부호(Prefix Code / Prefix-free Code)**: 어떠한 부호어(Codeword)도 타 부호어의 접두어(Prefix)와 일치하지 않아 구분자 없이 즉시 복호 가능한 비트 부호.
- **확률 모델(Probability Model)**: 각 심벌의 출현 빈도 및 문맥 의존성을 분석하여 부호기와 복호기에 동일 제공하는 통계 모델.

</details>

- 출현 빈도가 높은 **심벌**에는 짧은 부호어를, 희귀 심벌에는 긴 부호어를 가변 할당(Variable Length Coding).
- 딜리미터(Delimiter) 없이 비트 스트림을 실시간 해석 가능한 **접두 부호** 특성을 보장하여 복호 모호성 차단.
- 수발신 시스템 간 공유된 **확률 모델** 기반으로 엔트로피 한계치에 도달하는 압축 이득 실현.

#### 한줄 요약

- 가변 길이 접두 부호와 엔트로피 한계 설계를 통해 데이터 통계적 잉여성을 원천 차단하는 부호화 원칙 준수.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **코드북(Codebook)**: 심벌과 가변 비트 부호어(Codeword) 간 매핑 구조를 저장한 룩업 테이블 또는 트리(Tree) 구조.
- **문맥 모델(Context Model)**: 직전 심벌 출력 패턴에 기반하여 현재 심벌의 동적 출현 확률을 예측하는 통계 모델.
- **고정 정밀도 연산(Fixed-precision Arithmetic)**: 부동소수점 오차로 인한 부호기-복호기 상태 불일치를 방지하고자 정수 비트 연산 기반으로 확률 구간을 분할하는 연산 방식.
- **순환 중복 검사(Cyclic Redundancy Check, CRC)**: 압축 비트열 훼손 유무를 검증하여 완전한 무손실 원본 복원 여부를 점검하는 검증 다항식.

</details>

- **코드북**을 통해 심벌-비트 간 1:1 치환을 수행하고, **문맥 모델**을 연동하여 조건부 확률 기반 압축률 극대화.
- 부호기·복호기의 **고정 정밀도 연산** 일치와 **순환 중복 검사**를 통한 전송 오류 검출.

```text
소스 코딩 구성요소
├─ 확률 모델(Probability Model)
├─ 소스 부호기(Source Encoder)
├─ 코드북 및 룩업 테이블(Codebook)
├─ 소스 복호기(Source Decoder)
└─ CRC 검사기(CRC Verification)
```

| 구성요소 | 역할 및 핵심 기능 |
|:---|:---|
| 확률 모델 | 심벌 발생 빈도 및 N-Gram 문맥 확률을 실시간 수집 및 동적 갱신 |
| 소스 부호기 | 확률 분포 기반 이진 트리 구축 또는 누적 확률 구간 분할을 통해 압축 비트 생성 |
| 코드북 및 룩업 테이블 | 심벌-부호어 변환 매핑 테이블을 헤더에 동봉하거나 동적 파싱 |
| 소스 복호기 | 동일 확률 모델과 접두 부호 규칙을 적용하여 비트 스트림을 심벌로 역변환 |
| CRC 검사기(CRC Verification) | 전달된 검사값으로 압축 블록의 오류 검출 |

#### 한줄 요약

- 확률 기반 이진 트리 산출, 고정 정밀도 연산 및 CRC 완전성 검사가 통합 연계된 엔드투엔드 소스 코딩 구조 적용.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **재시작 지점(Restart Point)**: 비트 손실 시 이후 모든 심벌 복구가 파손되는 현상을 방지하기 위해 일정 주기로 복호 상태를 초기화하는 마커.
- **심벌 통계 전달(Symbol Statistics Delivery)**: 원문 스트림에서 각 알파벳 및 토큰의 빈도수를 측정하여 확률 엔진으로 주입하는 단계.
- **확률 모델 제공(Probability Model Provision)**: 수집된 통계를 바탕으로 확률 분포표 및 이진 부호 트리를 부호기에 설정하는 단계.
- **압축 블록 생성(Compressed Block Generation)**: 부호 비트 스트림 전면에 재시작 마커와 CRC 체크섬을 인코딩하는 단계.
- **블록·모델 버전 전달(Block & Model Delivery)**: 압축 비구조 데이터와 함께 헤더에 확률 메타데이터를 전송하는 단계.
- **무손실 심벌 복원(Lossless Symbol Reconstruction)**: 동일한 트리를 탐색하며 100% 동일한 원본 데이터를 회복하는 단계.

</details>

```text
원시 데이터 입력
      │
      ▼
1. 심벌 통계 전달
      │
      ▼
2. 확률 모델 제공
      │
      ▼
3. 압축 블록 생성
      │
      ▼
4. 블록·모델 버전 전달
      │
      ▼
5. 무손실 심벌 복원
```

### 동작 원리

1. 심벌 통계 전달: 입력 심벌을 스캔하여 발생 빈도 및 문맥 조건부 확률 측정.
2. 확률 모델 제공: 확률이 높은 심벌에는 짧은 비트열이 할당되도록 부호 트리를 완성하여 부호기에 제공.
3. 압축 블록 생성: 원문을 비트 스트림으로 인코딩하면서 **재시작 지점** 및 **순환 중복 검사** 메타데이터 삽입.
4. 블록·모델 버전 전달: 압축 해제에 필요한 헤더 정보와 압축 비트열을 수신 측 전달.
5. 무손실 심벌 복원: 수신 측에서 동일 트리를 탐색하여 **무손실 심벌 복원**을 완료하고 CRC로 완전성 검증.

#### 한줄 요약

- 통계 측정 기반 부호 트리 구축과 압축 비트스트림 인코딩, CRC 무손실 복원 프로세스 준수.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **허프만 부호화(Huffman Coding)**: 심벌 발생 확률에 따라 이진 트리를 구성하고 정수 비트(Integer Bit) 단위의 접두 부호를 할당하는 그리디 무손실 압축 알고리즘.
- **산술 부호화(Arithmetic Coding)**: 심벌열을 누적 확률 구간으로 표현하여 평균 비트 수를 엔트로피에 근접시키는 알고리즘.

</details>

- **허프만 부호화**는 심벌당 최소 1비트 이상을 소모하는 정수 단위 부호화로 구조가 단순하고 복호 속도가 신속.
- **산술 부호화**는 심벌당 비트 수 제약 없이 소수점 단위 비트 압축이 가능하여 엔트로피 극한값에 근접하지만 연산 복잡도가 높음.

| 비교 항목 | 허프만 부호화 (Huffman Coding) | 산술 부호화 (Arithmetic Coding) |
|:---|:---|:---|
| 부호화 단위 | 심벌별 정수 비트(Integer Bit) 단위 할당 | 심벌열 전체를 단일 확률 구간(Fractional Bit)으로 변환 |
| 엔트로피 도달성 | 2의 거듭제곱 확률에서 엔트로피 일치 | 긴 심벌열에서 엔트로피 한계에 근접 |
| 연산 복잡도 | 룩업 테이블/이진 트리를 이용한 경량·고속 복호 연산 | 확률 구간 하한/상한 재귀 계산으로 정밀 정수 연산 오버헤드 존재 |
| 오류 전파 리스크 | 부호어 간 접두 특성으로 1비트 손실 시 일부만 영향 | 구간 붕괴로 인해 1비트 오류 발생 시 이후 전 데이터 파손 |
| 주요 활용 분야 | GZIP, PKZIP, JPEG, MP3 인코딩 기본 계층 | H.264/CABAC, HEVC, JPEG-2000 고효율 압축 계층 |

> 요약: 단순 구현 및 빠른 복호화 요구 시 **허프만**, 고압축률 요구 차세대 비디오 코덱에는 **산술 부호화** 적용.

#### 한줄 요약

- 정수 비트 할당 기반 허프만과 소수점 확률 구간 분할 기반 산술 부호화의 압축률 및 연산 성능 비교 모델 수용.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **오류 전파(Error Propagation)**: 압축 스트림 내 1비트 손상 시 가변 길이 부호 동기화 파손으로 이후 심벌이 연속 훼손되는 현상.
- **모델 불일치(Model Mismatch)**: 압축 시 적용한 확률 모델과 실제 입력 데이터 빈도가 달라 압축 후 데이터 크기가 더 커지는 현상.

</details>

| 실무 문제점 | 발생 원인 | 해결 대책 | 기대 효과 |
|:---|:---|:---|:---|
| 오류 전파 붕괴 | 가변 길이 부호 특성상 1비트 전달 오류 시 복호 파손 | 일정 심벌 주기마다 **재시작 지점** 및 CRC 주입 | 오류 격리 구역 확보로 피해 최소화 |
| 역압축 발생 | 사전 정의 모델과 실제 입력 간 **모델 불일치** 발생 | 적응형 확률 모델(Adaptive Model) 기반 동적 코드북 갱신 연동 | 예외 트래픽에 대한 압축 손실 예방 및 높은 압축비 유지 |
| 실시간 지연 상승 | 산술 부호화의 미세 구간 정수 나눗셈 연산 오버헤드 과다 | 하드웨어 전용 CABAC 파이프라인 연산기 구축 및 정밀도 축소 | 4K/8K 고화질 실시간 스트리밍 복호 지연 단축 |
| 메타데이터 오버헤드 | 짧은 텍스트 압축 시 헤더 내 코드북 크기가 원문보다 커짐 | 글로벌 사전 정의 고정 테이블 사용 또는 무압축 통과 처리 | 소용량 메시지에 대한 부적절한 인코딩 방지 |

#### 한줄 요약

- 재시작 마커를 이용한 오류 전파 차단, 동적 확률 모델 적용 및 메타데이터 최소화를 통한 소스 코딩 가동성 확보 체계 구축.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **무손실 복원(Lossless Reconstruction)**: 압축 해제 후 원본 파일과 단 1비트 오차도 없이 동일하게 복구하는 기술.
- **엔트로피 한계(Entropy Bound / Shannon Entropy Limit)**: 데이터 손실 없이 최대로 축소할 수 있는 물리적 최저 평균 비트 수.

</details>

- 빠른 복호는 **허프만**, 높은 압축 효율은 **산술 부호화** 선택.

#### 한줄 요약

- 엔트로피 한계 도달 이득과 복호 연산 수용성을 종합 평가하여 시스템에 최적화된 소스 코딩 체계 구현 필수.
