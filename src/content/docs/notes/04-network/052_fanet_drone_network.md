## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **FANET (드론 애드혹 네트워크, Flying Ad-Hoc Network)**: 산불이나 지진으로 땅에 있는 기지국이 싹 다 타버렸을 때, 드론 수십 대가 하늘로 날아올라 자기들끼리 전파를 쏴서 공중에 허공 기지국(그물망)을 임시로 만들어버리는 마법이다.
- **UAV (무인항공기, Unmanned Aerial Vehicle)**: 사람 안 타고 카메라랑 무전기만 달고 날아다니는 드론이다.

</details>

- 정의: 드론(UAV) 여러 대가 지상 기지국 도움 없이 3차원 공중에서 자기들끼리 알아서 무선망(토폴로지)을 짜고, 데이터를 릴레이(멀티홉)로 전달하는 비행 무선 네트워크 기술이다.
- 배경: 산골짜기나 전쟁터처럼 지상 기지국이 아예 없거나 다 박살 난 상황에서도, 군집 드론들이 하늘에서 안 끊기고 통신하면서 정찰이나 구조 임무를 수행하려고 만들었다.

#### 한줄 요약

- 기지국 다 터진 재난 현장에서, 드론들이 하늘 위로 날아올라 서로 전파를 토스하며 '임시 하늘 기지국'을 만드는 기술이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **LET (링크 예상 수명, Link Expiration Time)**: 드론 A랑 드론 B가 서로 쌩쌩 날아다니는데, 속도랑 방향(벡터)을 짱구 굴려 계산해 보니 "우리 3초 뒤엔 멀어져서 통신 끊긴다!" 하고 미리 단절 시점을 예측하는 눈치채기 기술이다.

</details>

- **미친 3차원 변동성 (토폴로지 수시 변경)**: 땅바닥(2D)이 아니라 하늘 위 3D 공간을 위아래 양옆 막 날아다니니까, 전파가 1초 만에 연결됐다가 끊어졌다 하는 대환장 파티가 열림.
- **눈치 빠른 경로 수정 (LET 라우팅)**: 통신 끊어지기 직전에 LET 계산을 때려서, "어 끊긴다! 데이터 날아가기 전에 딴 드론한테 넘겨!" 하고 선제적으로 릴레이 셔틀 선수를 교체해 버림.
- **가혹한 배터리 쥐어짜기**: 드론은 프로펠러 돌리는 데 배터리를 다 써서 무전 칠 전기가 모자라니까, 배터리 많은 드론한테만 통신 중계(노가다)를 몰아주는 얍삽한 라우팅 룰을 쓴다.

#### 한줄 요약

- 하늘에서 휙휙 날아다녀서 전파가 맨날 끊어지니까, 끊기기 1초 전에 눈치껏 딴 드론한테 패스하고 배터리도 아껴 쓰는 극한 생존 통신망이다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **Relay UAV (중계 드론)**: 자기가 수집한 데이터는 없고, 그냥 남의 데이터 받아서 옆 드론한테 패스만 셔틀해 주는 하늘의 와이파이 공유기다.
- **Gateway UAV (게이트웨이 드론)**: 하늘에서 모은 데이터를 땅에 있는 지상 관제소나 우주에 있는 위성으로 쏴주는 하늘망의 마지막 톨게이트 대장 드론이다.

</details>

```text
[ 공중 드론 네트워크 팩트 폭행 구조 ]

[ 임무 드론 (열화상 카메라) ] ─▶ [ 중계 드론 (하늘 공유기) ] ─▶ [ 중계 드론 ]
                                                                   │ (데이터 릴레이)
                                                                   ▼
                            [ 지상 관제소 (지휘통제실) ] ◀── [ 게이트웨이 드론 (톨게이트) ]
```

| 구성요소 | 팩트 폭행 책임 | 비고 |
|:---|:---|:---|
| **임무 드론 (Mission UAV)** | 산불 현장 사진 찍고 **자기 위치랑 배터리 상태 동네방네 떠드는 놈** | 센서 노드 |
| **중계 드론 (Relay UAV)** | 임무 드론 데이터 받아서 **옆 드론한테 셔틀 패스하는 하늘 공유기** | 릴레이 노드 |
| **게이트웨이 드론 (Gateway)**| 하늘에서 모인 데이터를 **땅(관제소)으로 쏴주는 마지막 톨게이트 대장** | 백홀 노드 |
| **지상 관제소 (GCS)** | 드론들 쫙 띄워놓고 모니터 보면서 **드론 조종하고 영상 받아보는 지휘통제실** | Ground |
| **3D 라우팅 엔진** | 배터리, 속도, 거리 계산해서 **누구한테 데이터 패스할지 짱구 굴리는 뇌** | 알고리즘 |

#### 한줄 요약

- 사진 찍는 놈(임무), 옆으로 토스하는 놈(중계), 땅으로 꽂아버리는 놈(게이트웨이) 세 명이서 짜고 치는 하늘 고스톱이다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- (상단 참조)

</details>

```text
[ 하늘 릴레이(멀티홉) 패스 십자포화 흐름 ]

┌──────────────────────────────┐
│ 1. [이웃 드론 팩트 체크]     │
│ (나 1번 드론인데 배터리 50%고 북쪽 감)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 2. [LET (링크 수명) 계산]    │
│ (2번 드론이랑은 3초 뒤에 전파 끊어지겠네)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 3. [최적의 셔틀(중계) 선택]  │
│ (배터리 빵빵한 3번 드론한테 넘기자)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 4. [게이트웨이로 릴레이 슛]  │
│ (1번 $\to$ 3번 $\to$ 5번 $\to$ 게이트웨이(땅) 골인)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 5. [선제적 경로 꺾기]        │
│ (3번 드론 배터리 방전 직전! 빨리 4번으로 바꿔)
└──────────────────────────────┘
```

### 동작 원리

1. 이웃 드론 팩트 체크: 하늘에 뜬 드론들이 서로 자기 고도, 날아가는 방향, 배터리 잔량을 브로드캐스팅(자랑)함.
2. LET(링크 수명) 계산: 정보 받아서 계산기 두들기고 "쟤는 나랑 반대 방향으로 날아가니 곧 통신 끊기겠다" 하고 예측함.
3. 중계 셔틀 선택: 통신 안 끊기고 배터리도 많이 남은 만만한 드론을 다음 패스 대상으로 찝음.
4. 패킷 릴레이 전송: 데이터가 드론 징검다리를 거쳐서 마지막 대장(게이트웨이)을 통해 땅으로 내려감.
5. 경로 재설정(Proactive): 셔틀 드론이 멀어지거나 배터리 방전되기 1초 전에 미리 다른 셔틀로 경로를 휙 꺾어버림.

#### 한줄 요약

- 배터리 많고 오래 붙어있을 드론 골라서 징검다리 넘듯이 데이터를 패스하다가, 끊길 거 같으면 재빨리 딴 놈으로 갈아타는 흐름이다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **MANET**: 사람이나 스마트폰이 땅(2D)에서 걸어 다니며 만드는 느긋한 무선망.
- **VANET**: 자동차가 도로(2D)에서 쌩쌩 달리며 만드는 빠른 무선망.

</details>

| 비교 항목 | **FANET (드론 애드혹)** | **VANET (자동차 애드혹)** | **MANET (스마트폰/사람 애드혹)** |
|:---|:---|:---|:---|
| 팩트 폭행 비유 | 허공을 지 맘대로 나는 **전투기들** | 차선 맞춰서 쌩쌩 달리는 **레이싱카들** | 땅바닥 어슬렁 걷는 **동네 사람들** |
| 공간 및 이동성 | **3차원 (제일 빠르고 위아래 양옆 노빠꾸)** | 2차원 (차선이랑 도로 따라 얌전히 다님) | 2차원 (사람 걷는 속도라 느려 터짐) |
| 통신 단절 빈도 | **제일 심함 (1초 단위로 휙휙 끊어짐)** | 높음 (차 빨라서 자주 끊김) | 보통 (느려서 잘 안 끊김) |
| 배터리 에너지 | **최악 (통신할 전기도 날개 돌리는 데 다 씀)** | 무제한 (차 엔진 발전기가 빵빵하게 밀어줌) | 높음 (폰 배터리 떨어지면 끝) |

#### 한줄 요약

- 셋 다 기지국 없이 폰끼리 뭉치는 건 똑같은데, 드론(FANET)은 3D로 막 날아다녀서 제일 통신 맞추기 빡세고 배터리도 조루다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- (상단 참조)

</details>

| 장애/위험 요소 | 원인 분석 | 실무 대책 및 해결방안 | 기대 효과 |
|:---|:---|:---|:---|
| 고속 비행하다 휙 꺾으니 **전파 끊기고 데이터 증발함** | 드론의 미친 3D 급선회로 안테나 전파 각도가 확 벗어남 | **LET(링크 수명)** 계산해서 끊기기 1초 전에 다른 드론한테 **선제적 패스(Proactive)** | 전파 단절 나기 전에 경로 꺾어서 데이터 증발 완벽 방어 |
| 중계 셔틀 드론 하나만 **배터리 방전돼서 하늘에서 추락함** | 만만한 핫스팟 드론한테만 데이터 중계 노가다를 짬 때려서 터짐 | **배터리 잔량(Energy-aware)** 계산해서 셔틀 임무 뺑뺑이 돌림 (로드밸런싱) | 특정 드론 혹사 추락 방지 및 군집 전체 비행 시간 연장 |
| 게이트웨이 드론 뻗으니까 **땅(관제소)이랑 통신 싹 다 죽음** | 하늘 톨게이트를 1대만 띄워놔서 발생하는 뼈아픈 단일 장애점(SPOF) | 게이트웨이 대장 드론을 2~3대 띄워서 **페일오버(이중화) 백홀망 구축** | 대장 드론 격추돼도 관제소 통신 안 끊기고 생존 |
| 지상 기지국 전파가 **하늘로 올라와서 전파 간섭 오짐** | 공중에 떠 있어서 지상 5G/LTE 전파를 장애물 없이 직빵으로 다 쳐맞음 | 빔포밍 안테나 달고 전파 비어있는 곳 피해서 쏘는 **주파수 도약(AFH) 적용** | 지상 전파 간섭 뚫고 깨끗한 3D 무선 신호(SNR) 확보 |

#### 한줄 요약

- 끊기기 전에 패스하고(LET), 배터리 노가다 돌려 막기(Energy) 하고, 대장 드론 2대 띄워서 추락 대참사를 막아라.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- (상단 참조)

</details>

- 지상 기지국 인프라 마비 상황과 3차원 고속 비행의 전파 단절 한계를 극복하기 위해, **LET 예측 라우팅**과 **Energy-aware 멀티홉** 중계를 결합한 FANET 자율 통신 생태계 기조 확립함

#### 한줄 요약

- FANET은 기지국이 박살 난 재난 현장에서도 군집 드론들이 하늘의 별자리처럼 스스로 무선망을 짜서 생명선을 잇는 궁극의 무선 기술이다.
