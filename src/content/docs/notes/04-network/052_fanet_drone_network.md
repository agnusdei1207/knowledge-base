## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **비행 애드혹 네트워크(Flying Ad Hoc Network, FANET)**: 3차원으로 이동하는 무인항공기가 중계 경로를 자율 구성하는 멀티홉 애드혹 네트워크이다.

</details>

- 정의/개념: 3차원 이동 **무인항공기(Unmanned Aerial Vehicle, UAV)** 가 중계 경로를 자율 구성하는 **비행 애드혹 네트워크(Flying Ad Hoc Network, FANET)**
- 배경/필요성: 지상 관제소 직접 링크만으로는 장애물•원거리 드론의 **연결 유지 불가**

#### 한줄 요약

- 드론들이 서로 패킷을 중계해 지상 관제소와 연결되는 범위를 넓힌다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **링크 수명**: 두 무인항공기가 이동하면서 직접 무선 연결을 유지할 것으로 예상되는 시간이다.
- **토폴로지**: 무인항공기 노드와 노드 사이 통신 링크의 연결 구조이다.

</details>

- 고속 3차원 이동으로 **토폴로지 변화•링크 단절** 빈발
- **위성항법시스템(Global Positioning System, GPS)** 위치•비행 계획을 이용한 **링크 수명•경로 예측**
- 중계 부하가 집중될수록 **배터리 소진•임무 시간 단축**

#### 한줄 요약

- 현재 신호만 보지 않고 드론 이동 방향으로 연결 유지 시간을 예측해 중계자를 정한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **중계 무인항공기**: 다른 무인항공기의 임무 데이터를 선택된 멀티홉 경로의 다음 노드로 전달하는 드론이다.
- **게이트웨이 무인항공기**: 비행 애드혹 네트워크의 공중 경로를 지상 관제소 또는 외부 백홀과 연결하는 드론이다.

</details>

**무인항공기(Unmanned Aerial Vehicle, UAV)** 노드가 멀티홉 경로를 구성하고 게이트웨이가 **비행 애드혹 네트워크(Flying Ad Hoc Network, FANET)** 를 지상망과 연결한다.

```mermaid
block-beta
    columns 3
    A["UAV 노드"]
    B["애드혹 라우팅"]
    C["중계 UAV"]
    D["게이트웨이 UAV"]
    E["지상 관제소"]
    A --- B
    B --- C
    C --- D
    D --- E
```

| 구성요소 | 책임 |
|:---|:---|
| UAV 노드 | **센서 데이터** 생성과 이웃 상태 제공 |
| 애드혹 라우팅 | 이동•에너지를 반영한 **멀티홉 경로** 선택 |
| 중계 UAV | 선택된 경로의 **임무 데이터** 중계 |
| 게이트웨이 UAV | FANET과 지상 **백홀** 연결 |
| 지상 관제소 | 임무 데이터 수신과 **드론 임무** 관리 |

#### 한줄 요약

- 각 드론은 비행하면서 데이터를 만들고 다른 드론의 패킷도 다음 드론으로 전달한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **이웃 상태**: 인접 무인항공기의 위치•속도•링크 품질•잔여 에너지를 묶은 경로 선택 정보이다.
- **멀티홉**: 송신 무인항공기의 데이터를 하나 이상의 중간 무인항공기가 차례로 중계하는 전달 방식이다.

</details>

```mermaid
sequenceDiagram
    participant UAV노드
    participant 라우팅제어
    participant 중계UAV
    participant 게이트웨이
    participant 지상관제소
    UAV노드->>라우팅제어: 1. 이웃 상태
    라우팅제어->>중계UAV: 2. 중계 경로
    UAV노드->>중계UAV: 3. 임무 데이터
    중계UAV->>게이트웨이: 4. 중계 데이터
    게이트웨이->>지상관제소: 5. 관제 데이터
```

**동작 원리**

1. **이웃 상태**: 위치•속도•링크 품질•에너지 제공
2. **중계 경로**: 예상 링크 수명과 잔여 에너지로 **중계 무인항공기(Unmanned Aerial Vehicle, UAV)** 선택
3. **임무 데이터**: 제어•안전 우선순위에 따라 데이터 전송
4. **중계 데이터**: 선택된 멀티홉 경로로 게이트웨이까지 전달
5. **관제 데이터**: 백홀을 통해 지상 관제소에 임무 데이터 제공

#### 한줄 요약

- 중계 드론이 통신 범위를 벗어나기 전에 다음 경로를 준비해야 패킷 손실을 줄일 수 있다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **이동 애드혹 네트워크•차량 애드혹 네트워크(MANET•VANET)**: 일반 이동 단말의 임시망과 도로 이동 차량에 특화된 애드혹망이다.
- **비행 애드혹 네트워크(FANET)**: 공중에서 고속•3차원으로 이동하는 드론 군집에 특화된 애드혹망이다.

</details>

| 애드혹 이동망 | 비행 애드혹 네트워크(Flying Ad Hoc Network, FANET) | 이동 애드혹 네트워크(Mobile Ad Hoc Network, MANET) | 차량 애드혹 네트워크(Vehicular Ad Hoc Network, VANET) |
|:---|:---|:---|:---|
| 적용 환경 | 공중 **드론 군집 임무** | 일반 단말 **임시 지상망** | 도로 기반 **차량 통신망** |
| 이동 특성 | 고속 **3차원 자유 이동** | 자유로운 **지상 단말 이동** | 도로 제약의 **고속 이동** |
| 경로 제약 | 짧은 링크 수명과 **배터리 제약** | 불규칙 이동에 따른 **경로 유지 곤란** | 밀집•음영 구간의 **연결 변동** |

> 요약: 3차원 이동성으로 중계 경로 선택

#### 한줄 요약

- 자동차는 도로를 따라가지만 드론은 높이와 방향까지 바뀌므로 다음 연결을 예측하기 더 어렵다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **중계 부하**: 특정 무인항공기가 다른 노드의 패킷을 전달하느라 사용하는 통신•연산•배터리 자원이다.
- **백홀 연속성**: 게이트웨이 장애가 발생해도 비행 애드혹 네트워크와 지상망 사이 전달 경로가 유지되는 성질이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 현재 신호만 보면 이동 중 링크 단절 | 속도•방향으로 **링크 수명** 예측 | 단절 전 경로 전환으로 **전송 연속성** 확보 |
| 특정 **중계 무인항공기(Unmanned Aerial Vehicle, UAV)** 에 부하가 집중되면 배터리 소진 | 잔여 에너지•임무 중요도로 **중계 부하** 분산 | 군집의 **임무 지속시간** 연장 |
| 단일 게이트웨이 장애로 지상 연결 상실 | 복수 게이트웨이와 **임시 지상 경로** 구성 | 장애 중에도 **백홀 연속성** 유지 |

#### 한줄 요약

- 수색 드론이 멀어지기 전에 배터리가 남은 드론으로 중계 경로를 바꾼다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **비행 애드혹 네트워크 중계 경로**: 예상 링크 수명과 잔여 에너지로 선택한 무인항공기들의 멀티홉 전달 경로이다.

</details>

- 예상 링크 수명•잔여 에너지가 임무 기준을 충족하는 경로만 **비행 애드혹 네트워크(Flying Ad Hoc Network, FANET) 중계 경로** 로 선택

#### 한줄 요약

- 가장 짧은 길보다 오래 연결되고 배터리를 감당할 중계 경로를 선택해야 한다.
