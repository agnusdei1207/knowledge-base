## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **양자 키 분배(Quantum Key Distribution, QKD)**: 양자 상태의 측정 교란을 이용해 두 종단이 키 후보를 만들고 오류율로 안전한 키 생성 여부를 판정하는 기술이다.
- **BB84**: Bennett와 Brassard가 1984년에 제안해 이름에 두 성의 첫 글자와 연도를 썼으며, 두 기저로 양자 비트를 보내 일치한 측정만 키 후보로 쓰는 규약이다.
- **양자 측정 교란**: 알 수 없는 양자 상태를 측정하면 상태가 변해 도청 흔적이 오류율로 나타나는 성질이다.
- **양자 공격 취약성**: 충분한 규모의 양자컴퓨터가 기존 공개키 암호의 수학 문제를 효율적으로 풀 수 있는 위험이다.

</details>

- 정의/개념: **양자 측정 교란**을 이용한 비밀키 분배이다.
- 배경/필요성: 공개키 암호의 **양자 공격 취약성**이 발생한다.

#### 한줄 요약

- 아주 약한 빛으로 키 재료를 보내 도청자가 측정하면 흔적이 남는 성질을 이용해 쓸 수 있는 키인지 판단한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **양자 비트 오류율(Quantum Bit Error Rate, QBER)**: 선별한 양자 비트 중 송수신 결과가 다른 비율로서 잡음•도청 가능성의 판단 지표이다.
- **기저(Basis)**: 양자 상태를 준비하거나 측정할 때 선택하며 송수신이 같아야 결과를 키 후보로 쓰는 기준이다.
- **오류 정정**: 송수신 키 후보의 다른 비트를 고전 채널에서 맞추되 실제 키 값을 노출하지 않도록 처리하는 단계이다.
- **비밀성 증폭(Privacy Amplification)**: 공격자가 일부 정보를 알 가능성을 줄이기 위해 정정된 키를 더 짧은 최종 키로 압축하는 단계이다.
- **QBER 임계값**: 측정 오류율이 안전한 키 생성 허용 범위 안인지 판정하는 기준이다.
- **키 정제**: 선별 키에 오류 정정과 비밀성 증폭을 적용해 최종 비밀키를 생성하는 처리이다.

</details>

![이상적 BB84에서 QBER 증가에 따라 감소하는 점근 비밀키 비율](/study/diagrams/bb84-qber-secret-fraction.svg)

> 파란 선은 이상적 BB84와 단방향 후처리를 가정한 `1-2h₂(Q)` 하한으로 QBER 약 11%에서 비밀키 비율이 소진되며, 실제 임계값은 장비•프로토콜•보안 증명에 따라 달라진다.

- **BB84**: **기저** 불일치와 측정 교란으로 도청 흔적을 검출한다.
- **QBER 임계값**: 키 정제 진행•폐기 판단이다.
- **키 정제**: **오류 정정**과 **비밀성 증폭**으로 최종 키를 생성한다.

#### 한줄 요약

- 양자 채널이 키를 직접 안전하게 보장하는 것이 아니라 오류가 너무 크면 버리고 통과한 키로 별도 암호를 사용한다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **양자 송신기**: 임의 비트•기저로 양자 상태를 만드는 장치이다.
- **양자 채널**: 광자의 양자 상태를 송신기에서 수신기로 전달하는 경로이다.
- **양자 수신기**: 임의 기저로 양자 상태를 측정하는 장치이다.
- **인증 고전 채널**: 기저•오류 정정 정보를 변조 없이 교환하도록 상대를 확인한 채널이다.
- **키 관리기**: 최종 키의 저장•공급•수명•폐기를 관리하는 구성요소이다.

</details>

```text
QKD 이중 채널 구조
├─ 양자 송신기
├─ 양자 채널
├─ 양자 수신기
├─ 인증 고전 채널
└─ 키 관리기
```

가지의 의미: 양자 전송•고전 인증•키 관리 책임을 분리한 정적 구조이다.

| 구성요소 | 책임 |
|:---|:---|
| 양자 송신기 | **양자 송신기**가 임의 비트•기저로 양자 상태 생성 |
| 양자 채널 | **양자 채널**이 광자로 키 후보 양자 상태 전달 |
| 양자 수신기 | **양자 수신기**가 임의 기저로 상태 측정 |
| 인증 고전 채널 | **인증 고전 채널**이 기저 선별•오류 정정 정보 교환 |
| 키 관리기 | **키 관리기**가 최종 키 저장•공급•폐기 수행 |

#### 한줄 요약

- 양자 채널에서 측정값을 만들고 인증된 일반 채널에서 기저와 오류를 확인한 뒤 양쪽 키 관리기에 같은 최종 키를 넣는다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **중간자 공격(Man-in-the-Middle Attack)**: 공격자가 두 통신자 사이에서 각각 상대인 것처럼 가장해 메시지를 엿보거나 바꾸는 공격이다.
- **양자 상태 전송**: 송신기가 임의 비트와 기저로 준비한 양자 상태를 수신기에 보내는 단계이다.
- **측정 기저 정보 전달**: 수신기가 측정에 사용한 기저 정보를 인증 고전 채널로 제공하는 단계이다.
- **준비 기저 정보 전달**: 송신기가 상태 준비에 사용한 기저 정보를 인증 고전 채널로 제공하는 단계이다.
- **일치 비트•QBER 표본 전달**: 같은 기저의 비트를 선별하고 일부 표본의 오류율을 비교하는 단계이다.
- **최종 키 전달**: 오류 정정과 비밀성 증폭을 마친 대칭키를 키 관리기에 제공하는 단계이다.

</details>

```text
고전 채널 상호 인증
        │
        ▼
1. 양자 상태 전송
        │
        ▼
2. 측정 기저 정보 전달
        │
        ▼
3. 준비 기저 정보 전달
        │
        ▼
4. 일치 비트•QBER 표본 전달
        ├─ 임계값 초과: 후보 키 폐기
        └─ 임계값 이하: 오류 정정•비밀성 증폭
                              │
                              ▼
                      5. 최종 키 전달
```

### 동작 원리

1. **양자 상태 전송**: 임의 비트•기저의 광자를 **양자 상태 전송**으로 보낸다.
2. **측정 기저 정보 전달**: 수신 측정에 사용한 기저를 **측정 기저 정보 전달**로 제공한다.
3. **준비 기저 정보 전달**: **중간자 공격**을 막는 인증 고전 채널에서 **준비 기저 정보 전달**을 수행한다.
4. **일치 비트•QBER 표본 전달**: 후보 비트와 QBER 표본을 **일치 비트•QBER 표본 전달**로 제공한다.
5. **최종 키 전달**: 정정•증폭을 마친 대칭키를 **최종 키 전달**로 제공한다.
#### 한줄 요약

- 서로 같은 측정 기준을 쓴 비트만 남기고 일부 오류율이 높으면 전부 버리며 통과하면 더 짧고 안전한 키로 정제한다.

## Ⅴ. 종류 및 비교

<details><summary>핵심 용어</summary>

- **신뢰 중계 노드(Trusted Relay Node)**: 장거리 양자 키 분배 구간을 이어 주며 중간에서 키를 복원하므로 운영자를 신뢰해야 하는 장비이다.
- **양자내성암호(Post-Quantum Cryptography, PQC)**: 양자컴퓨터 공격에도 안전할 것으로 평가된 수학 문제를 이용하는 소프트웨어 암호이다.
- **기존 공개키 암호**: 소인수분해 및 이산로그 문제의 높은 계산 복잡도에 보안 안전성을 의존하는 비대칭 키 교환·서명 방식이다.

</details>

| 양자 위협 대응 | **QKD** | **양자내성암호** | **기존 공개키 암호** |
|:---|:---|:---|:---|
| 적용 기준 | 전용 광 구간•고가치 키 | 기존망•응용 양자 전환 | 현재 호환성•운영 검증 |
| 핵심 특징 | 측정 교란 기반 키 분배 | 양자내성 키•서명 | 기존 수학 기반 키•서명 |
| 한계 | 거리•장비•인증 채널과 **신뢰 중계 노드** 의존 | 성능•구현 검증 부담 | 양자 공격•장기 기밀 노출 |

#### 한줄 요약

- 전용 광 구간은 QKD, 기존 인터넷과 소프트웨어는 양자내성암호가 현실적이며 기존 방식은 기밀 수명을 따져 단계 전환한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **키 생성률**: QBER을 반영해 단위 시간에 공급할 수 있는 안전한 키의 양이다.
- **키 수명 관리**: 키의 생성•사용•교체•폐기 시점을 통제하는 절차이다.
- **상호운용성**: 서로 다른 장비와 계층이 같은 규격으로 연동되는 성질이다.
- **ITU-T Y.3800**: 국제전기통신연합 전기통신표준화부문(International Telecommunication Union Telecommunication Standardization Sector, ITU-T)의 QKD 네트워크 구조 권고이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 거리 증가의 **키 생성률** 저하 | 손실•**QBER** 사전 실측 | 응용에 공급할 키 용량 산정 |
| 고전 채널 **중간자 공격** | 상호 인증과 **키 수명 관리** | 키 교환 무결성 확보 |
| 장비•망 간 **상호운용성** 한계 | **ITU-T Y.3800** 구조 적용 | 계층별 상호운용 확보 |

#### 한줄 요약

- 전용 광 구간의 손실과 오류율을 실측하고 인증된 고전 채널과 키 수명 정책을 함께 운영해야 한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **양자 위협 대응 선택**: 전용 광 인프라•키 생성률•범용망 호환성에 따라 QKD와 PQC를 배정하는 판단이다.

</details>

- **키 생성률**•**상호운용성**을 검증한 뒤 고가치 전용 광은 **QKD**, 범용망은 **PQC**로 전환하는 **양자 위협 대응 선택**이 필요하다.

#### 한줄 요약

- QKD는 양자라는 이름보다 실제 거리에서 필요한 키가 나오는지와 고전 채널 인증부터 폐기까지 안전한지를 확인해야 한다.
