## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **QKD (Quantum Key Distribution)**: 단일 광자의 양자 상태를 전송하고 기저를 대조하여 물리 법칙 기반의 무조건적 안전성을 갖는 비밀키를 공유하는 기술.
- **No-Cloning Theorem (복제 불가 정리)**: 미지의 양자 상태는 복제할 수 없으며, 도청자가 측정을 시도하면 상태가 붕괴되어 에러(QBER)가 발생하므로 도청이 100% 발각되는 물리 법칙.

</details>

- 정의/개념: 단일 광자의 양자 상태에 키를 인코딩하고 **복제 불가 정리와 QBER 평가를 통해 도청을 100% 탐지하여 무조건적 안전성을 보장하는 암호키 분배 기술**
- 배경/필요성: 양자컴퓨터의 쇼어(Shor) 알고리즘으로 인한 **기존 RSA/ECC 공개키 암호 체계의 완전 무력화 위협 및 '선 수집 후 사후 해독(SNDL)' 공격 방어 불가**

#### 한줄 요약
- 양자 복제 불가 원리와 단일 광자 편광 측정을 통해 도청 시도를 100% 탐지하는 절대 안전 키 분배를 실현한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **QBER (Quantum Bit Error Rate, 양자 비트 오류율)**: 수신된 비트 중 오류가 발생한 비율로, 11%를 초과할 경우 도청 시도로 판정하여 키를 전량 폐기하는 안전 임계치.
- **Privacy Amplification (비밀성 증폭)**: 오류 정정 후 해시 함수 압축을 통해 도청자 Eve가 가질 수 있는 키의 잔여 정보량을 수학적 0으로 축소하는 과정.

</details>

- **물리 법칙 기반의 무조건적 안전성(Unconditional Security)**: 계산 복잡도가 아닌 **양자역학 물리 법칙에 기반하여 도청 시도 100% 발각**
- **양자 채널과 고전 채널의 듀얼 아키텍처**: 단일 광자를 전송하는 **양자 채널(Dark Fiber)과 기저 대조용 공용 IP 채널 분리 운영**
- **QBER 기반 도청 실시간 감지 및 키 폐기**: 오류율이 **임계치(11%)를 초과하면 즉시 도청으로 판정하고 생성 키 전량 폐기**

#### 한줄 요약
- 무조건적 물리 안전성, 양자/고전 듀얼 채널 분리, QBER 기반 도청 탐지 및 비밀성 증폭을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **Alice vs Bob**: 단일 광자 레이저와 QRNG로 양자 상태를 송신하는 Alice와 단일 광자 검출기(SPAD)로 기저를 측정하는 Bob.

</details>

```text
[BB84 프로토콜 기반 QKD 시스템 토폴로지]
|-- Alice: 양자 송신기 (Single-Photon Laser, QRNG 난수 생성, 기저 변조기: +, x)
`-- Quantum Channel (전용 암전 광섬유: Dark Fiber 1550nm 단일 광자 스트림)
`-- Bob: 양자 수신기 (Beam Splitter, SPAD 광다이오드 단일 광자 검출)
`-- Authenticated Classical Channel (인증된 공용 IP 네트워크)
    |-- Sifting (기저 일치 여부 대조: + / x 일치분만 추출)
    |-- Error Correction & Privacy Amplification (Cascade 오류 정정 & 비밀성 증폭)
    `-- Key Management System (ITU-T Y.3800 KMS: IPsec/MACsec 암호화 장비로 대칭키 공급)
```

선의 의미: Alice와 Bob이 양자 채널을 통해 광자를 교환하고 일반 고전 채널로 기저 정보와 오류 정정을 거쳐 최종 암호키를 KMS에 적재하는 구조

| 구성요소 | 핵심 엔지니어링 책임 | 주요 특징 |
|:---|:---|:---|
| **양자 송신기 (Alice)**| QRNG 기반 비트 생성 및 **단일 광자 기저(편광/위상) 변조 송출** | Single-Photon Laser |
| **양자 채널 (Dark Fiber)**| 단일 광자 신호가 **광학적 손실 없이 전파되는 전용 암전 광섬유 매체** | 1550nm 광케이블 |
| **양자 수신기 (Bob)** | 무작위 기저를 선택하여 **단일 광자 검출기(SPAD)로 양자 상태 측정·기록**| SPAD Detector |
| **인증된 고전 채널** | Alice와 Bob 간의 **기저 일치 확인, 에러 정정, 비밀성 증폭을 수행하는 IP 망** | Classical Network |
| **키 관리 시스템 (KMS)**| 정제된 대칭 비밀키를 저장·관리하고 **상위 VPN 암호화 장비로 안전 분배** | ITU-T Y.3800 KMS |

#### 한줄 요약
- 양자 송신기(Alice), 양자 채널, 양자 수신기(Bob), 인증 고전 채널, KMS 키 관리기가 결합된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Sifted Key Generation (기저 체질)**: Alice와 Bob이 고전 채널로 서로 사용한 측정 기저의 종류만을 공개 대조하여 일치한 비트만 1차 원시 키로 추출하는 과정.

</details>

```text
BB84 단일 광자 송출, 기저 체질, QBER 검증 및 최종 키 생성 파이프라인
        │
   1. [양자 상태 송출] Alice가 QRNG 난수로 편광 상태($0^\circ, 90^\circ, +45^\circ, -45^\circ$) 중 하나로 광자 전송
        │
   2. [단일 광자 수신] Bob이 무작위로 수평/수직($+$) 또는 대각($\times$) 기저를 선택하여 광자 측정
        │
   3. [기저 체질 대조] 고전 채널을 통해 사용한 '기저 목록'만 상호 대조하여 일치한 비트만 추출(Sifting)
        │
   4. [QBER 도청 판정] 표본 비트를 공개 비교하여 오류율 산출 ➔ 임계치(11%) 초과 시 즉각 전량 폐기
        │
   ▼
5. [비밀성 증폭 및 키 완성] 에러 정정(Cascade) 및 해시 압축 후 최종 대칭키를 완성하여 KMS에 저장
```

#### 한줄 요약
- 단일 광자 전송 → 임의 기저 측정 → 기저 체질 대조 → QBER 도청 판정 → 비밀성 증폭 및 키 완성 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **QKD (하드웨어 물리 보안)** vs **PQC (소프트웨어 수학적 난제)** vs **RSA/ECC (레거시 공개키)**.

</details>

| 비교 항목 | 양자 키 분배 (QKD / Hardware) | 양자내성암호 (PQC / Software) | 기존 공개키 암호 (RSA / ECC) |
|:---|:---|:---|:---|
| **보안 근거** | **양자역학 물리 법칙 (무조건적 안전성)**| **격자/다변량 기반 수학적 복잡도 난제** | 소인수분해, 이산대수 난제 |
| **인프라 요구사항** | **전용 단일 광자 광케이블 및 전용 장비**| **기존 인터넷 망 및 소프트웨어 패치만 요구**| 기존 인터넷 인프라 100% 활용 |
| **전송 거리 제약** | 광섬유 감쇠로 인해 **~100km 한계 (중계 필요)**| **거리 제약 전무 (전 지구적 적용 가능)** | 거리 제약 전무 |
| **양자 공격 안전성**| **영구적 절대 안전 (수학적 진보와 무관)**| **우수 (알려진 양자 알고리즘에 안전)**| **양자컴퓨터 출현 시 완전 무력화 (Shor)**|
| **표준화 및 상용화**| ITU-T Y.3800, 국가 백본망 구축 | **NIST 표준화 완료 (ML-KEM, ML-DSA)** | 범용 표준 기배포 |

#### 한줄 요약
- QKD는 물리 법칙 기반 절대 보안을 제공하나 거리 제약이 있고, PQC는 범용 인터넷에 즉시 적용 가능한 수학적 대안이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Trusted Node (신뢰 중계 노드)**: 광섬유 감쇠로 인한 100km 전송 한계를 극복하기 위해 중간 지점에서 키를 일시 복호화/재암호화하여 전달하는 물리적 보안 거점.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 광섬유 광자 감쇠로 인한 전송 거리 한계(~100km) 및 광역망 구축 제약 | **`물리적 방호 신뢰 중계 노드(Trusted Node)` 및 다중 경로 릴레이** | 국가 백본망 규모의 장거리 광역 QKD 네트워크 확장 |
| 기저 교환용 고전 채널에 대한 중간자 공격(MITM) 위협 | **`사전 공유 키 기반 일회용 패드(OTP)` 또는 PQC 전자서명 상호 인증** | 고전 채널 변조 차단 및 기저 교환 프로토콜 무결성 보장 |
| 이종 QKD 제조사 간 키 관리 인터페이스 불일치로 상호운용성 단절 | **`ITU-T Y.3800 계층 표준 및 ETSI GS QKD 014 REST API` 준수** | 멀티 벤더 QKD 장비와 상용 VPN 암호 장비 간 상호운용성 확보 |
| 신뢰 중계 노드 내부자 물리적 침해 시 평문 키 유출 위험 | **`양자 얽힘 기반 측정 기기 무관 QKD(MDI-QKD)`** 기술 도입 | 중계 노드 해킹 시에도 키 기밀성 수학적 보증 |

#### 한줄 요약
- 신뢰 중계 노드로 거리를 극복하고, 고전 채널 상호 인증으로 MITM을 방어하며, ITU-T 표준으로 상호운용성을 보장한다.

## Ⅶ. 결론

- 양자 컴퓨팅 시대의 'Store Now, Decrypt Later' 위협으로부터 국가 핵심 기반 시설 및 금융 전산망을 영구적으로 방어하기 위해 **물리 법칙 기반의 QKD 인프라를 필수 도입**하되, 실무 구현의 제약을 극복하기 위해 **신뢰 중계 노드 기반 광역 백본망 구축, ITU-T Y.3800 표준 KMS 연동, 단기적으로는 PQC(양자내성암호)와의 하이브리드 결합 모델(QKD+PQC)**을 적용하여 양자 안전 암호 통신망 완성

#### 한줄 요약
- QKD 물리 보안과 PQC 암호화를 하이브리드로 결합하여 양자 컴퓨팅 위협에 대응하는 완벽한 보안망을 구축한다.
