## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **QKD (Quantum Key Distribution)**: 단일 광자의 양자 상태를 전송하고 기저를 대조하여 물리 법칙 기반의 무조건적 안전성을 갖는 비밀키를 공유하는 기술.
- **No-Cloning Theorem (복제 불가 정리)**: 미지의 양자 상태는 복제할 수 없으며, 도청자가 측정을 시도하면 상태가 붕괴되어 에러(QBER)가 발생하므로 도청이 100% 발각되는 물리 법칙.

</details>

- 정의/개념: 양자 상태의 측정 교란을 이용한 **암호키 분배 기술**
- 배경/필요성: 양자 컴퓨터의 발전으로 인해 소인수분해 및 이산대수 문제에 기반한 전통적인 공개키 암호 체계(RSA, ECC)가 쇼어(Shor) 알고리즘에 의해 무력화될 위험에 직면하고, 공격자가 현재 암호화된 트래픽을 미리 수집한 뒤 미래에 양자 컴퓨터로 사후 해독하는 '지금 저장하고 나중에 해독(Harvest Now, Decrypt Later)' 공격 위협이 현실화됨에 따라, 수학적 계산 복잡성이 아닌 양자역학의 기본 물리 법칙(양자 중첩, 복제 불가 정리, 불확정성 원리)을 활용하여 도청 시도 시 상태 교란(QBER)으로 도청 사실을 100% 탐지하는 양자 키 분배(QKD) 기술을 도입하여 **도청이 물리적으로 불가능한 무조건적 정보이론적 안전성(Information-Theoretic Security) 확보, 국가 안보 및 금융 핵심 백본망의 양자 안전 암호키 분배**를 달성할 필요

#### 한줄 요약
- 양자 복제 불가 원리와 단일 광자 편광 측정을 통해 도청 시도를 100% 탐지하는 절대 안전 키 분배를 실현한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **QBER (Quantum Bit Error Rate, 양자 비트 오류율)**: 수신된 비트 중 오류가 발생한 비율로, 11%를 초과할 경우 도청 시도로 판정하여 키를 전량 폐기하는 안전 임계치.
- **Privacy Amplification (비밀성 증폭)**: 오류 정정 후 해시 함수 압축을 통해 도청자 Eve가 가질 수 있는 키의 잔여 정보량을 수학적 0으로 축소하는 과정.

</details>

- **무조건적 안전성**: 양자 측정 교란으로 **도청 탐지**
- **이중 채널**: 광자용 **양자 채널**과 인증 고전 채널 분리
- **QBER 판정**: 오류율 임계치 초과 시 **키 전량 폐기**

#### 한줄 요약
- 무조건적 물리 안전성, 양자/고전 듀얼 채널 분리, QBER 기반 도청 탐지 및 비밀성 증폭을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **Alice vs Bob**: 단일 광자 레이저와 QRNG로 양자 상태를 송신하는 Alice와 단일 광자 검출기(SPAD)로 기저를 측정하는 Bob.

</details>

```text
[BB84 QKD 체계]
|-- 양자 송신기      : 난수·광자 상태 생성
|-- 양자 채널        : 단일 광자 전송
|-- 양자 수신기      : 무작위 기저 측정
|-- 인증 고전 채널   : 기저 대조·오류 정정
`-- 키 관리 시스템   : 정제 키 저장·분배
```

선의 의미: Alice와 Bob이 양자 채널을 통해 광자를 교환하고 일반 고전 채널로 기저 정보와 오류 정정을 거쳐 최종 암호키를 KMS에 적재하는 구조

| 구성요소 | 책임 |
|:---|:---|
| 양자 송신기 | QRNG와 **광자 상태 생성** |
| 양자 채널 | 단일 광자 전송 |
| 양자 수신기 | 무작위 기저로 **광자 측정** |
| 인증 고전 채널 | **기저 대조·오류 정정·비밀성 증폭** |
| 키 관리 시스템 | 정제 키의 **저장·분배** |

#### 한줄 요약
- 양자 채널은 키 재료 전달만 맡고 인증된 고전 채널이 기저 대조와 정제를 담당하므로, 물리적 안전성과 상대 인증이 서로 다른 경로에서 확보된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Sifted Key Generation (기저 체질)**: Alice와 Bob이 고전 채널로 서로 사용한 측정 기저의 종류만을 공개 대조하여 일치한 비트만 1차 원시 키로 추출하는 과정.

</details>

```text
Alice
  |
1. 양자 상태 송출
  |
2. 광자 기저 측정
  |
3. 기저 체질 대조
  |
4. QBER 도청 판정
  +-- 초과: 키 폐기
  `-- 허용: 5. 비밀성 증폭·키 완성
                         |
                        KMS
```

동작 원리

1. 양자 상태 송출
2. 광자 기저 측정
3. 기저 체질 대조
4. QBER 도청 판정
5. 비밀성 증폭·키 완성

#### 한줄 요약
- QBER 임계에서 키 채택과 전량 폐기로 갈리며, 도청 흔적을 확실히 걸러내는 대가로 최종 키 생성률이 크게 줄어든다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **QKD (하드웨어 물리 보안)** vs **PQC (소프트웨어 수학적 난제)** vs **RSA/ECC (레거시 공개키)**.

</details>

| 비교 항목 | 양자 키 분배 (QKD / Hardware) | 양자내성암호 (PQC / Software) | 기존 공개키 암호 (RSA / ECC) |
|:---|:---|:---|:---|
| 보안 근거 | **양자역학 물리 법칙** | **수학적 난제** | 소인수분해·이산대수 |
| 인프라 요구사항 | 전용 광채널·장비 | 기존 망·소프트웨어 | 기존 인터넷 인프라 |
| 전송 거리 제약 | 감쇠로 **중계 필요** | 거리 제약 없음 | 거리 제약 없음 |
| 양자 공격 안전성 | **무조건적 안전성** | 알려진 양자 공격에 안전 | Shor 알고리즘에 취약 |
| 표준화·상용화 | ITU-T Y.3800 | **ML-KEM·ML-DSA** | 범용 배포 |

#### 한줄 요약
- QKD는 물리 법칙 기반 절대 보안을 제공하나 거리 제약이 있고, PQC는 범용 인터넷에 즉시 적용 가능한 수학적 대안이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Trusted Node (신뢰 중계 노드)**: 광섬유 감쇠로 인한 100km 전송 한계를 극복하기 위해 중간 지점에서 키를 일시 복호화/재암호화하여 전달하는 물리적 보안 거점.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 광자 감쇠로 **전송 거리 제한** | **신뢰 중계 노드·다중 경로** | 광역 QKD 확장 |
| 고전 채널의 **MITM 위협** | 사전 공유 키나 **PQC 서명 인증** | 기저 교환 무결성 보장 |
| 제조사별 **KMS 상호운용 단절** | **Y.3800·QKD 014 API** 준수 | 멀티벤더 연동 확보 |
| 중계 노드 침해로 **평문 키 유출** | **MDI-QKD** 도입 | 측정 장치 공격 저항성 확보 |

#### 한줄 요약
- 신뢰 중계 노드로 거리를 극복하고, 고전 채널 상호 인증으로 MITM을 방어하며, ITU-T 표준으로 상호운용성을 보장한다.

## Ⅶ. 결론

- 수학적 알고리즘 난이도에 의존하는 보안을 넘어 자연계 물리 법칙에 기반하여 도청을 원천 차단하는 **양자 시대 국가 기밀, 국방 및 금융 기간망의 궁극적인 하드웨어 물리 보안 표준 기술(ITU-T Y.3800)**로 확립되었으며, 범용 소프트웨어 암호인 양자내성암호(PQC) 및 양자 인터넷(Quantum Internet)과의 융합으로 진화하는 가운데, 실무 QKD 인프라 구축 시에는 **광섬유 감쇠로 인한 전송 거리 한계(약 100km)를 극복하기 위한 물리적 신뢰 중계 노드(Trusted Node) 및 다중 경로 링망 설계, 고전 채널 중간자 공격(MITM)을 차단하는 PQC 기반 상호 인증, 멀티벤더 이기종 장비 간 상호운용성을 보장하는 ETSI GS QKD 014 표준 키 전달 API 연동**을 결합하여 완벽한 양자 암호 통신 무결성을 완성

#### 한줄 요약
- QKD 물리 보안과 PQC 암호화를 하이브리드로 결합하여 양자 컴퓨팅 위협에 대응하는 완벽한 보안망을 구축한다.
