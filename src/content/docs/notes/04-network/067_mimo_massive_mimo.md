## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **MIMO (다중입출력)**: 안테나를 여러 개 달아서 데이터를 쪼개 보내거나(속도업), 똑같은 걸 여러 번 쏴서(신뢰성) 통신 품질을 뻥튀기하는 무선 기술이다.
- **대규모 MIMO (Massive MIMO)**: 5G 기지국에 안테나를 64개, 128개씩 무식하게 촘촘히 박아서, 스마트폰 하나하나마다 전파 빔을 1:1로 꽂아주는 끝판왕 공간 분할 기술이다.

</details>

- 정의: **MIMO** 및 **대규모 MIMO** 기반 안테나를 복수로 배치하여, 주파수 추가 할당 없이도 데이터를 여러 층으로 겹쳐 쏘거나 특정 단말에 전파를 몰아주는 무선 물리계층 핵심 기술이다.
- 배경: 주파수(도로) 대역폭을 더 늘릴 돈이나 자원이 없으니까, **안테나 수를 늘려서 허공(공간)을 차선처럼 쪼개 써먹으려고 도입했다.**

#### 한줄 요약

- 안테나를 수십, 수백 개 달아서 허공을 여러 차선으로 쪼개고, 전파를 사방에 버리지 않고 내 폰에만 레이저처럼 쏴주는 마법이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **공간 스트림 (Spatial Stream)**: 허공을 투명한 차선 여러 개로 쪼개서, 똑같은 주파수에서 서로 다른 데이터를 동시에 날려 속도를 대폭 향상시키는 기술이다.
- **빔포밍 (Beamforming)**: 전파를 사방팔방으로 낭비하지 않고, 안테나 각도를 조절해서 타겟 폰에만 레이저처럼 쏴주는 저격 기술이다.
- **다이버시티 (Diversity)**: 비바람 불 때 똑같은 데이터를 안테나 여러 개로 동시에 쏴서, 하나라도 살아남아라 하고 융단 폭격을 때리는 신뢰성 올인 기술이다.

</details>

- **차선 쪼개기 (공간 다중화)**: 주파수는 1갠데 안테나가 4개면, 데이터를 4개 덩어리로 쪼개서 허공으로 동시에 던져 속도를 4배로 뻥튀기한다.
- **전파 레이저 (3D 빔포밍)**: 안테나 수백 개를 쓰면 전파가 퍼지지 않고 폰마다 1:1 빔을 꽂아줄 수 있어 배터리 소모도 줄이고 옆 폰과의 간섭도 원천 차단한다.
- **안전빵 복사 전송 (공간 다이버시티)**: 신호가 구리면 속도를 포기하고, 여러 안테나로 똑같은 파형을 중복 송출해서 수신율(신뢰성)을 무조건 살려낸다.

#### 한줄 요약

- 속도 고플 땐 쪼개서 쏘고(다중화), 특정 폰만 노릴 땐 레이저로 쏘고(빔포밍), 날씨 구릴 땐 복사해서 쏜다(다이버시티).

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **채널 행렬 (Channel Matrix)**: 송신 안테나와 수신 안테나 사이의 전파 경로가 튕기고 반사되면서 얼마나 얽히고설켰는지 수학적으로 계산한 복소수 족보다.
- **프리코더 (Precoder)**: 여러 안테나에서 나가는 전파가 허공에서 서로 꼬이지 않게, 쏘기 직전에 각도와 세기를 미리 계산해서 튜닝해 주는 지휘관이다.

</details>

```text
[ 다중 안테나 직관적 비교 구조 ]

[ 1. 채널 추정기 ] ── (스마트폰이 쏜 테스트 전파 보고 공간 상태 싹 스캔함)
      │
      ▼
[ 2. 스케줄러 & 프리코더 ] ── (야 넌 1번 빔 쏘고, 넌 2번 빔 파워 올려! 튜닝 완료)
      │
      ▼ (안테나 수백 개에서 전파 레이저 발사)
[ 3. 무선 공간 (채널 행렬 H) ] ── (전파가 허공에서 건물에 반사되고 섞이면서 난리 부르스 춤)
      │
      ▼
[ 4. MIMO 검출기 ] ── (단말에 짬뽕돼서 들어온 전파를 수학(MMSE)으로 분리해 냄)
```

| 구성요소 | 책임 | 비고 |
|:---|:---|:---|
| **채널 추정기** | 테스트 신호(파일럿) 보고 **허공에 전파 차선이 몇 개 나오나 견적 뽑음** | Estimator |
| **스케줄러** | 누구한테 몇 차선(스트림) 열어줄지 **눈치껏 배분하는 교통순경** | Scheduler |
| **프리코더** | 안테나에서 나갈 전파가 안 꼬이게 **미리 각도랑 세기 조율하는 지휘관** | Precoder |
| **안테나 배열** | 64개, 128개씩 빽빽하게 박혀서 **실제로 빔을 쏘는 거대한 직사각형 대포** | Antenna Array |
| **MIMO 검출기** | 수신 단말에서 **섞여서 들어온 짬뽕 전파를 수학으로 분리해 내는 해독기** | Detector |

#### 한줄 요약

- 견적 뽑고(추정기) $\to$ 쏠 각도 계산하고(프리코더) $\to$ 수백 개 대포로 쏘면 $\to$ 스마트폰이 짬뽕된 전파를 분리해 낸다(검출기).

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **CSI (채널 상태 정보)**: 폰이 허공 전파 상태를 싹 스캔해서 기지국한테 "지금 각도 15도로 쏘세요" 하고 꼰지르는 실시간 날씨/공간 정보다.
- **파일럿 오염 (Pilot Contamination)**: 기지국 빔 맞추려고 쏘는 테스트 신호(파일럿)가 옆 동네 기지국 거랑 섞여서, 빔이 엉뚱한 데로 꽂히는 대규모 네트워크 장애다.

</details>

```text
[ 안테나 빔 저격 십자포화 흐름 ]

┌──────────────────────────────┐
│ 1. [테스트 신호(파일럿) 교환]│
│ (기지국&폰: 야, 전파 잘 가냐? 서로 찔러봄)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 2. [CSI(채널 상태) 및 Rank 꼰지르기]
│ (폰: 지금 건물 반사돼서 2차선 뚫렸고 각도는 이렇습니다!)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 3. [공간 차선 및 빔 타겟팅 할당]
│ (기지국: ㅇㅋ 넌 VIP니까 1번 빔 전용으로 맞고 속도 올리자)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 4. [프리코딩 가중치 튜닝]    │
│ (기지국: 빔 쏠 각도랑 파워 안테나 수백 개에 싹 다 입력함)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 5. [전파 레이저 발사 및 해독]│
│ (기지국 빔 발사 ➡️ 폰 수신 후 짬뽕 전파 분리해서 데이터 쫙 뽑음)
└──────────────────────────────┘
```

### 동작 원리

1. 파일럿 교환: 송수신 간 테스트 신호를 쏴서 무선 채널이 얼마나 꼬여있는지 파악함.
2. CSI 피드백: 폰이 채널 상태(CSI)와 뚫어줄 수 있는 최대 차선 개수(Rank)를 기지국에 알림.
3. 스케줄링: 기지국이 동시 접속한 단말들(MU-MIMO)을 분석해서 빔과 차선을 최적으로 배분함.
4. 프리코딩: 안테나 소자 128개에 넣을 위상(각도)과 진폭(파워) 가중치를 수학적으로 연산함.
5. 빔 발사: 정밀하게 조율된 전파가 보강간섭을 일으키며 폰에만 레이저(빔)처럼 꽂힘.

#### 한줄 요약

- 테스트 쏴보고 $\to$ 폰이 꼰지르고 $\to$ 기지국이 빔 각도 계산해서 $\to$ 안테나 수백 개로 레이저 쏘는 흐름이다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- (상단 참조)

</details>

| 구분 | **SISO (구석기 방식)** | **MIMO (국민 방식)** | **대규모 MIMO (5G/6G 끝판왕)** |
|:---|:---|:---|:---|
| 핵심 특징 | **외길 수순 1차선 흙길** | 2차선, 4차선 뚫은 **다차선 도로** | 허공에 128차선 뚫어버리는 **공중 부양** |
| 안테나 수 (Tx $\times$ Rx) | 딱 1개 (공유기 안테나 1개짜리) | 2개~8개 (LTE, 일반 Wi-Fi) | **64개~수백 개 이상** (5G 기지국) |
| 공간 제어 기술 | 없음. 그냥 사방으로 전파 퍼짐 | 2D 빔포밍, 공간 다중화 분리 | **3D 정밀 빔포밍, 수십 명 1:1 전담 타겟팅** |
| 연산 및 복잡도 | 짱구 안 굴려도 됨 | 수학 계산 쪼끔 빡셈 | **수백 개 빔 각도 맞추느라 CPU 터짐** |
| 주력 활용 분야 | 싸구려 구형 공유기, 초소형 센서 | LTE 스마트폰, Wi-Fi 5/6 | **5G/6G 기지국, 스타링크 위성 통신** |

#### 한줄 요약

- 싸구려 센서는 SISO, 흔한 스마트폰은 일반 MIMO, 기지국에서 쏴주는 건 무조건 Massive MIMO다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **하이브리드 빔포밍 (Hybrid Beamforming)**: 안테나 수백 개마다 비싼 앰프(RF 칩)를 다 달면 파산하니까, 앰프는 적당히 달고 아날로그 위상 천이기랑 섞어 써서 가성비 챙기는 타협 기술이다.

</details>

| 장애/위험 요소 | 원인 분석 | 실무 대책 및 해결방안 | 기대 효과 |
|:---|:---|:---|:---|
| 옆 동네 신호 섞여서 **빔이 엉뚱한 놈한테 꽂힘 (파일럿 오염)** | 테스트 신호(파일럿) 패턴을 다 똑같은 거 써서 기지국이 타겟을 헷갈림 | 테스트 신호에 **동네별로 다른 암호(직교 코드) 걸어둠** | 빔 삽질 방지하고 찐 타겟한테만 전파 꽂음 |
| KTX 탔더니 **빔이 못 따라오고 자꾸 끊김 (CSI 지연 붕괴)** | 기지국이 빔 쏠 준비 다 했는데, 그 사이 단말기가 벌써 저 멀리 도망감 | 단순 피드백 믿지 말고 **AI 예측기로 단말기 1초 뒤 위치 예상해서 빔을 쏨** | 시속 300km에서도 빔 안 끊기고 다운로드 유지 |
| 안테나 128개 달았더니 **기지국 부품값만 수억 깨짐** | 안테나 소자마다 비싼 RF 체인(디지털 부품)을 1:1로 무식하게 다 박으려 함 | 앰프 개수 줄이고 섞어 쓰는 **아날로그/디지털 하이브리드 빔포밍 설계 적용** | 기지국 구축 비용 줄이고 전기세 발열 컷트 |

#### 한줄 요약

- 파일럿 섞이는 거 암호 걸어서 막고, 폰 빨리 움직이면 예측해서 쏘고, 앰프값 비싸니까 하이브리드 꼼수 써라.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- (상단 참조)

</details>

- 주파수 대역폭 확장의 물리적 한계를 공간 차원으로 돌파하기 위해, 수십~수백 개의 배열 안테나를 이용해 **공간 다중화** 및 **3D 빔포밍** 실현하는 대규모 MIMO 기조 확립함

#### 한줄 요약

- 대규모 MIMO는 허공이라는 투명한 공간을 무한의 데이터 고속도로로 개조해버리는 5G/6G 통신의 근본 마법이다.
