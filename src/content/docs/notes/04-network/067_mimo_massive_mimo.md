## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **다중입출력(Multiple-Input Multiple-Output, MIMO)**: 여러 송수신 안테나로 공간 다중화•빔 형성•다이버시티를 수행하는 기술이다.
- **대규모 MIMO(Massive MIMO)**: 많은 안테나 소자로 여러 사용자 빔을 동시에 형성하는 MIMO 구조이다.
- **단일입출력(Single-Input Single-Output, SISO)**: 송신과 수신에 각각 안테나 하나를 사용하는 무선 구조이다.

</details>

- 정의/개념: **MIMO**와 **대규모 MIMO**는 여러 안테나로 공간 차원을 활용하는 무선 전송 기술이다.
- 배경/필요성: **SISO**는 같은 대역에서 공간 다중화나 다이버시티로 용량•신뢰도를 확장할 수 없다.

#### 한줄 요약

- 여러 안테나가 같은 주파수에서 데이터를 분할•보강 송신하는 것이 핵심이다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **공간 스트림(Spatial Stream)**: 같은 시간•주파수 자원에서 독립적으로 전송하는 데이터 흐름이다.
- **빔(Beam)**: 안테나 신호가 목표 지점에서 결합하는 공간 방향이다.
- **다이버시티(Diversity)**: 같은 정보를 서로 다른 공간 경로로 보내 결합해 오류 확률을 낮추는 방식이다.
- **신호대잡음비(Signal-to-Noise Ratio, SNR)**: 수신 신호 전력과 잡음 전력의 비율이다.

</details>

- **빔**은 목표 방향에서 신호를 결합해 **SNR**을 높인다.
- **공간 스트림**은 같은 시간•주파수 자원에서 독립 데이터를 전송한다.
- **다이버시티**는 독립 경로의 같은 정보를 결합해 오류 확률을 낮춘다.

#### 한줄 요약

- 안테나 수가 많아도 채널 경로가 비슷하면 독립 스트림 수는 늘지 않아 채널 순위가 중요하다는 점이 핵심이다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **채널 행렬(Channel Matrix)**: 각 송신 안테나에서 각 수신 안테나로 전달되는 신호의 크기와 위상을 행렬로 나타낸 값이다.
- **채널 순위(Channel Rank)**: 채널 행렬에서 분리 가능한 독립 공간 경로의 수이다.
- **채널 상태 정보(Channel State Information, CSI)**: 안테나 간 진폭•위상•품질을 나타내 프리코딩과 스트림 수 결정에 쓰이는 측정값이다.

</details>

- **채널 행렬**은 안테나 사이의 크기•위상을 나타내고 **채널 순위**는 분리 가능한 독립 경로 수를 정하며 **CSI**는 프리코딩과 스트림 선택의 입력이 된다.

```text
MIMO 송수신 구조
├─ 채널 추정기
├─ 스케줄러•순위 선택기
├─ 프리코더
├─ 송수신 안테나 배열
└─ MIMO 검출기
```

선의 의미: 각 선은 CSI•채널 순위, 사용자•공간 스트림 할당, 안테나별 복소 가중치, 공간 신호와 수신 혼합 신호의 스트림•간섭 분리 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| 채널 추정기 | 파일럿 기반 안테나 간 CSI 산출 |
| 스케줄러•순위 선택기 | 사용자•자원•공간 스트림 결정 |
| 프리코더 | 복소 가중치•전력 계산 |
| 송수신 안테나 배열 | 공간 신호 방사•수신 |
| MIMO 검출기 | 스트림•간섭 분리 |

#### 한줄 요약

- 프리코더는 안테나별 크기•위상을 조절해 목적 방향에서 신호를 합치고 다른 방향의 간섭을 줄인다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **파일럿(Pilot)**: 송수신기가 채널을 추정하도록 알려진 값으로 보내는 참조 신호이다.
- **프리코딩(Precoding)**: CSI에 따른 복소 가중치로 빔과 스트림을 형성하는 처리이다.
- **스케줄러(Scheduler)**: 사용자•시간•주파수•공간 스트림 자원을 배정하는 제어기이다.
- **파일럿 전송**: 알려진 참조 신호를 송신해 안테나 사이 채널을 측정하게 하는 단계이다.
- **CSI•채널 순위 보고**: 측정한 채널 상태와 독립 공간 경로 수를 스케줄러에 제공하는 단계이다.
- **사용자•스트림 배정**: 채널 조건에 따라 사용자와 공간 스트림 자원을 정하는 단계이다.
- **가중 신호 전달**: 프리코더가 계산한 안테나별 복소 가중치와 전력을 송신부에 적용하는 단계이다.
- **빔•공간 스트림 전송**: 안테나 배열이 같은 자원에서 방향성 신호와 독립 데이터를 보내는 단계이다.

</details>

```text
1. 파일럿 전송
      │
      ▼
2. CSI•채널 순위 보고
      │
      ▼
3. 사용자•스트림 배정
      │
      ▼
4. 가중 신호 전달
      │
      ▼
5. 빔•공간 스트림 전송
      │
      └─ 채널 변화 시 1단계부터 갱신
```

### 동작 원리

1. **파일럿 전송**: **파일럿 전송** 단계에서 **파일럿**을 안테나로 송신한다.
2. **CSI•채널 순위 보고**: **CSI•채널 순위 보고** 단계에서 채널 진폭•위상과 독립 경로 수를 제공한다.
3. **사용자•스트림 배정**: **사용자•스트림 배정** 단계에서 **스케줄러**가 분리 가능한 사용자와 스트림을 결정한다.
4. **가중 신호 전달**: **가중 신호 전달** 단계에서 **프리코딩**으로 안테나별 복소 가중치•전력을 적용한다.
5. **빔•공간 스트림 전송**: **빔•공간 스트림 전송** 단계에서 같은 자원으로 독립 데이터를 송신한다.

#### 한줄 요약

- 사용자가 이동하면 CSI 측정과 전송의 시차가 길수록 빔 이탈과 오류가 늘어난다.

## Ⅴ. 종류 및 비교

| 판단 기준 | MIMO | 대규모 MIMO | SISO |
|:---|:---|:---|:---|
| 적용 기준 | **MIMO**는 채널 순위가 높은 링크 | **대규모 MIMO**는 사용자를 공간적으로 분리할 수 있는 셀 | **SISO**는 단순•저비용 단일 링크 |
| 핵심 특징 | 복수 안테나•스트림 | 대형 배열•다중 사용자 빔 | 단일 송수신 안테나 |
| 한계 | 검출•CSI 복잡도 | 파일럿 오염•연산•전력 | 공간 다중화 이득 없음 |

> 요약: 채널 순위와 사용자 분리가 공간 이득을 정한다.

#### 한줄 요약

- 대규모 MIMO는 한 사용자의 스트림을 무한히 늘리기보다 여러 사용자를 다른 빔으로 함께 서비스하는 데 강점이 있다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **파일럿 오염(Pilot Contamination)**: 여러 셀이 같은 파일럿을 재사용해 채널 추정값에 다른 사용자의 신호가 섞이는 현상이다.
- **안테나 보정(Antenna Calibration)**: 배열 소자별 위상•이득 편차를 측정해 보상하는 작업이다.
- **간섭(Interference)**: 다른 송신 신호가 원하는 신호의 판정을 방해하는 현상이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 이동 중 오래된 **CSI**로 빔 이탈 | 이동 속도별 파일럿 갱신 | 빔 이탈 감소 |
| 셀 간 **파일럿 오염** | 자원 조정•공간 필터 적용 | **간섭** 억제 |
| 배열 소자별 위상•이득 편차 | **안테나 보정** 정기 수행 | 빔 형성 정확성 향상 |

#### 한줄 요약

- 안테나 수가 많아도 CSI로 확인한 독립 경로가 둘이면 해당 단말에는 공간 스트림을 둘까지만 배정한다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **복소 가중치(Complex Weight)**: 안테나별 신호의 크기와 위상을 조절하는 계수이다.
- **공간 이득의 조건**: MIMO 이득은 채널 순위와 CSI 정확도에 제한되는 원칙이다.

</details>

- **공간 이득의 조건**은 정확한 CSI와 채널 순위이며, **복소 가중치**로 빔을 형성해 단일 저비용은 **SISO**, 고순위 링크는 **MIMO**, 사용자 분리는 **대규모 MIMO**를 선택한다.

#### 한줄 요약

- 안테나 수보다 각 단말 채널을 정확히 알고 같은 방향으로 신호를 모으는 것이 중요하다.
