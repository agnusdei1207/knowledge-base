## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **망분리(Network Separation / Isolation)**: 외부 인터넷망을 통한 악성코드 유입 및 내부 핵심 정보(고객 정보, 소스코드, 금융 데이터)의 외부 유출을 원천 방지하기 위해, 업무용 내부망(Intranet)과 외부 인터넷망(Internet)을 물리적 또는 논리적으로 완벽히 격리하는 보안 통제 정책.
- **망연계 시스템(Network Bridge / Data Diode)**: 분리된 업무망과 인터넷망 간에 안전한 데이터 송수신을 지원하기 위해, 전용 스토리지(공유 메모리/IEEE 1394) 또는 단방향 링크를 매개로 백신 검사 및 승인 결재를 거쳐 자료를 중계하는 보안 관문.

</details>

- 정의/개념: 업무망(Trusted Zone)과 인터넷망(Untrusted Zone) 간의 직접적인 IP 라우팅을 **물리적 분리(2-PC/물리 스위치)** 또는 **논리적 가상화(VDI/CBC)** 로 차단하고, 승인된 전용 **망연계 솔루션(자료/스트림 연계)** 과 **CDR(콘텐츠 무해화)** 을 통해서만 통신을 허용하는 **경계 보안 아키텍처**
- 배경/필요성: 단일 네트워크 환경에서 발생하는 엔드포인트 PC 악성코드 감염에 따른 내부망 횡적 이동(Lateral Movement) 및 APT 기반 대규모 전산망 마비 사고를 원천 방어할 법적/기술적 요구 (전자금융감독규정, 개인정보보호법)

#### 한줄 요약
- 업무망과 인터넷망을 물리적/논리적으로 격리하고 전용 망연계 관문으로 침해 확산 및 데이터 유출을 방어한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **기본 차단(Default Deny)**: 분리된 망 간의 모든 인바운드/아웃바운드 네트워크 패킷 흐름을 기본적으로 전면 차단하고, 명시적으로 승인된 특정 트래픽만 예외 허용하는 제로 트러스트 보안 원칙.
- **콘텐츠 악성코드 무해화(Content Disarm & Reconstruction, CDR)**: 외부에서 반입되는 문서 파일(HWP, PDF, MS Office)을 분석하여 악성 매크로, 자바스크립트, 실행 코드를 원천 제거하고 순수 정적 데이터만으로 안전하게 문서를 재조립하는 기술.

</details>

- **망 간 직접 라우팅 차단 (Air-Gap / Isolation)**: 인터넷망과 내부 업무망 간의 L3/L4 직접 통신 경로를 전면 제거하여 공격자의 C&C 통신 및 내부 확산 차단
- **승인 기반의 통제된 자료 반출입**: 망연계 관문에서 결재 라인 승인, 멀티 안티바이러스 검사, CDR 무해화 처리를 거친 파일만 제한적 이동 허용
- **특권 접근 통제 및 감사 추적 (PAM)**: 서버 및 DB 관리자 세션에 대해 MFA 인증, 명령어 통제 및 작업 화면 100% 동영상 녹화 감사 수행

#### 한줄 요약
- 기본 차단(Default Deny), 통제된 망연계 관문, CDR 무해화 및 관리자 PAM 감사를 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **VDI(가상 데스크탑 인프라)**: 중앙 서버 팜(Server Farm)의 하이퍼바이저 상에서 가상 머신(VM)으로 OS를 구동하고 사용자 단말에는 화면(픽셀)만을 스트리밍(RDP/PCoIP/ICA)하는 서버 기반 논리적 망분리 기술.
- **단방향 보안 게이트웨이(Data Diode)**: 물리적인 단일 광섬유(Tx-Rx 단선) 송수신기를 사용하여 물리적으로 역방향 전송이 불가능한 100% 단방향 데이터 송신 링크.

</details>

```text
[ 외부 인터넷망 (Untrusted Zone) ] ── (인터넷 웹서핑, 외부 이메일용 VDI / PC)
                 │
                 ▼
[ 비무장지대 (DMZ: External Services) ] ── (대외 연계 웹서버, 메일 릴레이)
                 │
   ══════════════╪═════════════════════════════════════════════════════════════
                 ▼ (물리적 / 논리적 격리 경계)
[ 망연계 시스템 (Network Bridge / Data Diode) ]
 ├─ 자료 연계: 결재 승인 ➔ 멀티 백신 ➔ CDR 무해화 ➔ 스토리지 중계
 └─ 스트림 연계: 전용 보안 프록시 기반 실시간 소켓 중계 (Non-IP 변환)
   ══════════════╪═════════════════════════════════════════════════════════════
                 │
                 ▼
[ 내부 업무망 (Trusted Zone) ] ──────── (업무용 PC, 사내 그룹웨어, 인트라넷)
                 │
                 ▼ (PAM 특권 접근 관리 / MFA 통제)
[ 핵심 서버망 (Core Zone) ] ────────── (고객 정보 DB, 코어 뱅킹, 결제 서버)
```

선의 의미: 인터넷망과 내부망이 분리된 상태에서 오직 망연계 시스템(자료/스트림 연계)을 통해서만 엄격한 보안 검증 후 트래픽이 통과하는 계층 아키텍처

| 구성요소 | 책임 및 역할 | 비고 |
|:---|:---|:---|
| **인터넷망 (Untrusted)** | 웹서핑, 외부 이메일 수신을 수행하는 격리 환경 | 물리 PC 또는 VDI |
| **업무망 (Trusted)** | 내부 문서 작성, ERP, 그룹웨어 등 사내 비즈니스 전용 인트라넷 | 내부 전용 단말 |
| **망연계 시스템 (Bridge)** | 망 간 파일 전송(자료연계) 및 서비스 연계(스트림연계) 중계 | 이중화 스토리지 / Non-IP |
| **CDR 무해화 엔진** | 문서 파일 내 실행 가능한 매크로/스크립트 제거 후 안전한 재조립 | Zero-Day 차단 |
| **PAM (특권 접근 관리)** | 핵심 서버망(Core Zone) 접속 시 2FA 인증, 접근 승인, 세션 녹화 | 관리자 통제 |

#### 한줄 요약
- 인터넷망, DMZ, 망연계 관문, 업무망, 핵심 서버망(PAM)이 계층적으로 결합한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **자료 연계 vs 스트림 연계**: 비실시간 파일 전송을 위한 스토리지 기반 중계 방식과 실시간 데이터 스트리밍(중계 DB, 웹 소켓)을 위한 전용 프록시 기반 프로토콜 변환 방식.

</details>

```text
1. 사용자가 인터넷망 단말에서 다운로드한 외부 문서를 내부 업무망으로 반입 요청
            │
            ▼
2. 망연계 시스템이 사용자 직급/역할 및 부서장 사전 승인 결재 여부 검증
            │
            ▼
3. 파일 페이로드를 격리된 샌드박스에서 멀티 백신 검사 및 CDR(콘텐츠 무해화) 실행
            │
            ├─ [악성코드/매크로 탐지] ➔ 반입 즉시 차단 및 보안관제팀 이벤트 전송
            ▼
4. [무해화 완료] ➔ 물리적 공유 스토리지 또는 단방향 링크를 통해 내부망으로 파일 전달
            │
            ▼
5. 내부망 수신자가 파일 수신 ➔ 망연계 감사 로그에 송수신자, 해시값, 결재 이력 영구 기록
```

**동작 원리**

1. **반입 신청**: 웹 인터페이스를 통해 파일명, 목적, 승인자를 지정하여 반입 큐 등록
2. **사전 결재**: 정책 기반 워크플로우 엔진이 지정된 결재권자의 전자결재 확인
3. **심층 검사**: 시그니처 백신과 더불어 정적 분석(CDR)으로 오피스 문서 내 실행 코드 추출 및 파괴
4. **망간 전송**: 인터넷망 서버가 공유 스토리지에 파일을 쓰고, 내부망 서버가 이를 읽어가는 비-IP 방식 중계
5. **감사 추적**: SHA-256 파일 해시와 타임스탬프를 보존하여 사후 유출 사고 조사 시 무결성 증명

#### 한줄 요약
- 반입 신청, 결재 승인, CDR 무해화 검사, 비-IP 망간 중계, 감사 로그 기록 순으로 처리된다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **물리적 망분리 vs 서버 기반 VDI vs 클라이언트 기반 CBC**: 하드웨어 완전 이중화, 서버 가상화 화면 전송, 단말 OS 영역 분리 기술의 비교.

</details>

| 비교 항목 | 물리적 망분리 (Dual PC) | 서버 기반 논리적 망분리 (SBC / VDI) | 클라이언트 기반 논리적 망분리 (CBC) |
|:---|:---|:---|:---|
| **격리 구현 방식** | **물리적 PC 2대 및 스위치/배선 분리** | **단일 PC에서 서버 가상화(VDI) 화면 수신** | **단일 PC OS 상에서 컨테이너/VM 격리** |
| **보안 격리성** | **최고 수준 (물리적 전송 매체 차단)**| **우수 (데이터는 서버 저장, 화면만 전송)** | 중간 (단말 OS 취약점 공격 시 침해 위험) |
| **사용자 편의성** | 낮음 (책상 공간 협소, 2대 조작) | **우수 (단일 단말, 어디서든 접속 가능)** | 보통 (로컬 단말 리소스 점유 및 속도 저하) |
| **구축 비용 (CapEx)**| **매우 높음 (PC/스위치/케이블 이중화)** | 높음 (VDI 서버 팜, 고성능 스토리지) | **낮음 (별도 서버 인프라 없이 SW 라이선스)**|
| **주요 적용 기관** | 국방, 원자력, 국가 1급 보안 시설 | **금융권, 대기업, 공공기관 (스마트워크)** | 중소기업, 개발망 격리 |

#### 한줄 요약
- 물리적 망분리는 최고 수준의 물리 보안, VDI는 스마트워크 편의성, CBC는 저비용 구축에 적합하다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **망 혼용(Cross-Network Contamination)**: 무선 랜(Wi-Fi), 테더링, 비인가 USB 연결 등으로 인해 인터넷망과 업무망이 비인가로 연결되어 망분리가 무력화되는 현상.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 인터넷망 문서 반입 시 신종 제로데이 악성 매크로의 내부 업무망 침투 및 감염 | 망연계 관문에 **CDR(콘텐츠 무해화 및 재조립)** 엔진 연동 의무화 | 문서 내 액티브 콘텐츠 100% 제거 및 제로데이 APT 위협 차단 |
| 유지보수 인력 또는 외주 직원의 서버망 비인가 접속 및 핵심 DB 데이터 유출 | **PAM(특권 접근 관리) 솔루션** 기반 MFA 인증 및 **전체 세션 동영상 녹화** | 관리자 계정 오남용 차단 및 사후 완벽한 법적 감사 증적 확보 |
| 무선 테더링 또는 듀얼 NIC 장착으로 인한 내부망-인터넷망 **망 혼용 발생** | **엔드포인트 매체 제어(DLP/NAC)** 로 Wi-Fi/LTE 모뎀 비인가 활성화 강제 차단 | 물리/논리적 망분리 우회 통로 원천 차단 및 정책 준수율 100% 달성 |

#### 한줄 요약
- CDR로 문서 악성코드를 제거하고, PAM으로 서버 접근을 통제하며, DLP/NAC로 망 혼용을 방지한다.

## Ⅶ. 결론

- 내부 핵심 자산 보호와 랜섬웨어 횡적 확산 방지를 위해 **물리적 망분리 또는 VDI 기반 논리적 망분리 아키텍처**를 필수 구축하되, 업무 연속성을 담보하기 위해 **CDR 결합 망연계 시스템**, **특권 접근 관리(PAM)**, **엔드포인트 매체 통제**를 통합 연계하여 안전하고 생산성 높은 제로 트러스트 업무 환경을 완성

#### 한줄 요약
- 망분리와 CDR 결합 망연계 및 PAM 통제를 통해 고신뢰 엔터프라이즈 보안을 실현한다.
