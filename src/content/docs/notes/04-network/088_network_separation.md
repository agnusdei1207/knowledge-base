## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **Network Separation (망분리)**: 업무용 내부망(Intranet)과 외부 인터넷망(Internet)을 물리적/논리적으로 격리하는 보안 통제 정책.
- **망연계 시스템 (Network Bridge)**: 분리된 망 간에 비-IP 스토리지나 보안 프록시를 통해 결재 승인 및 백신 검사 후 데이터를 안전하게 중계하는 관문.

</details>

- 정의/개념: 업무망(Trusted)과 인터넷망(Untrusted) 간의 IP 라우팅을 **물리적 분리 또는 가상화(VDI)로 차단하고 망연계 및 CDR 무해화로 데이터를 중계하는 보안 격리 기술**
- 배경/필요성: 공공기관, 금융권, 국가 기반 시설 등 핵심 정보 자산을 다루는 환경에서 인터넷망과 내부 업무망을 단일 네트워크로 혼용 운영할 경우, 이메일 악성코드(APT), 피싱 및 랜섬웨어가 엔드포인트 단말 하나를 감염시킨 후 내부 L3/L4 라우팅 경로를 타고 사내 핵심 데이터베이스(DB)와 운영 서버로 횡적 이동(Lateral Movement)하여 대규모 기밀 유출과 시스템 마비를 초래함에 따라, 업무망(Trusted)과 인터넷망(Untrusted) 간의 직접적인 IP 라우팅을 물리적 분리(Dual PC) 또는 가상화(VDI/CBC)로 원천 차단하고 비-IP 망연계 시스템 및 CDR(콘텐츠 무해화)을 도입하여 **외부 사이버 위협의 내부 유입 경로 원천 차단, 내부 핵심 데이터의 무단 반출 방지 및 법적 컴플라이언스(전자금융감독규정/개인정보보호법) 완벽 준수**를 달성할 필요

#### 한줄 요약
- 물리적·논리적 망 격리와 CDR 기반 망연계를 통해 외부 위협 유입과 내부 데이터 유출을 원천 차단한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **CDR (Content Disarm and Reconstruction)**: 문서 파일(PDF, MS Office) 내에 숨겨진 악성 매크로, 자바스크립트를 제거(무해화)하고 안전한 텍스트/이미지만 재조립하는 기술.
- **Lateral Movement (횡적 이동)**: 단일 PC가 감염되었을 때 동일 네트워크 내부의 핵심 DB나 서버망으로 공격자가 권한을 상승하며 침투하는 공격 단계.

</details>

- **직접적인 IP 통신 경로 원천 차단**: 업무망과 인터넷망 간의 L3/L4 라우팅 패킷 전송을 물리적/논리적으로 단절
- **승인 기반 망연계 및 CDR 무해화**: 망 간 파일 전송 시 **결재 워크플로우, 멀티 백신, 악성 매크로 무해화(CDR) 강제**
- **내부 횡적 이동(Lateral Movement) 억제**: 외부 침해 사고 발생 시 피해 범위를 인터넷망 영역으로 국소 격리

#### 한줄 요약
- 직접 IP 경로 차단, 승인 기반 망연계/CDR 무해화, 횡적 이동 차단을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **Data Diode (단방향 보안 게이트웨이)**: 물리적 단일 광섬유 송수신기를 사용하여 역방향 전송이 물리적으로 불가능한 100% 단방향 송신 링크.

</details>

```text
[엔터프라이즈 망분리 체계]
  ├── [외부 환경] ───────── [인터넷망 (외부 웹/메일)]
  │                           │
  ├── [격리 및 중계] ─────── [망연계 시스템 / CDR 엔진]
  │                           │
  └── [신뢰 영역] ───────── [내부 업무망 / 핵심 서버망(PAM)]
```

- 선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| **인터넷망** | 외부 웹·메일 이용 환경 제공 |
| **업무망** | 내부 업무 응용과 데이터 처리 |
| **망연계 시스템** | 승인된 자료·서비스 중계 |
| **CDR 엔진** | 문서의 활성 콘텐츠 제거와 재조립 |
| **PAM** | 핵심 서버의 특권 접근 승인·기록 |

#### 한줄 요약
- 망연계 관문이 두 망 사이의 유일한 통과 지점을 독점하므로, 승인된 파일만 IP 세션 없이 옮겨지고 침해 경로는 관문 앞에서 끊긴다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Data Bridge vs Stream Bridge**: 파일 단위의 비실시간 스토리지 중계(자료연계)와 DB/웹 소켓 실시간 프록시 중계(스트림연계).

</details>

```text
망연계 파일 반입 및 CDR 무해화 처리 파이프라인
        │
   1. [반입 신청] 사용자가 인터넷망 단말에서 다운로드한 외부 문서의 업무망 반입 요청
        │
   2. [결재 승인 검증] 망연계 시스템이 사용자 권한 및 부서장 사전 승인 결재 여부 확인
        │
   3. [멀티 백신 및 CDR 무해화] 샌드박스에서 악성코드 검사 및 문서 내 매크로/스크립트 제거
        │
   ├─ [악성코드 탐지 시] ➔ 반입 즉각 차단 및 보안관제팀 이벤트 전송
    ▼
4. [비-IP 스토리지 망간 전달] 무해화 완료 파일을 공유 스토리지 또는 단방향 링크로 업무망 전송
        │
    ▼
5. [업무망 수신 및 감사 로깅] 내부 수신자에게 파일 전달 및 SHA-256 해시/이력 영구 감사 기록
```

- 1. 반입 신청: 외부 문서의 업무망 반입 요청
- 2. 결재 승인 검증: 사용자 권한과 승인 확인
- 3. 멀티 백신 및 CDR 무해화: 검사·활성 콘텐츠 제거
- 4. 비-IP 스토리지 망간 전달: 승인 파일 중계
- 5. 업무망 수신 및 감사 로깅: 해시와 이력 기록

#### 한줄 요약
- CDR 무해화 단계에서 반입 허용과 차단이 갈리며, 문서의 능동 요소를 제거하는 대가로 원본 기능 일부 손실을 감수한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **Dual PC (물리적)** vs **VDI (서버 가상화)** vs **CBC (클라이언트 가상화)**.

</details>

| 비교 항목 | 물리적 망분리 (Dual PC) | 서버 기반 논리적 망분리 (VDI) | 클라이언트 기반 논리적 망분리 (CBC) |
|:---|:---|:---|:---|
| 격리 방식 | 장비·배선 물리 분리 | 서버 VDI 화면 전송 | 단말 VM·컨테이너 격리 |
| 격리 강도 | 물리 경계 중심 | 서버·접속 정책 중심 | 단말 하이퍼바이저 중심 |
| 사용자 경험 | 두 환경 전환 필요 | 원격 데스크톱 이용 | 단말 내 환경 전환 |
| 구축 부담 | 장비·배선 이중화 | 서버·스토리지 운영 | 단말 자원·보안 관리 |
| 적용 판단 | 높은 물리 격리 요구 | 중앙 데이터 통제 요구 | 단말 중심 유연성 요구 |

#### 한줄 요약
- 물리적 망분리는 최고 수준의 물리 보안, VDI는 스마트워크 편의성, CBC는 저비용 구축에 적합하다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Cross-Network Contamination (망 혼용)**: 무선 테더링, 비인가 Wi-Fi, 듀얼 NIC 장착으로 인해 망분리가 우회되어 악성코드가 유입되는 현상.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 인터넷망 문서 반입 시 신종 제로데이 악성 매크로의 업무망 침투 | 망연계 관문에 **`CDR (콘텐츠 무해화 및 재조립)` 엔진 연동 의무화** | 문서 내 액티브 콘텐츠 100% 제거 및 APT 위협 차단 |
| 유지보수/외주 인력의 서버망 비인가 접속 및 핵심 DB 유출 | **`PAM (특권 접근 관리) 솔루션` 기반 MFA 및 세션 동영상 녹화** | 관리자 계정 오남용 차단 및 완벽한 법적 감사 증적 확보 |
| 무선 테더링 또는 듀얼 NIC 장착으로 인한 내부망-인터넷망 **망 혼용 발생** | **`엔드포인트 매체 제어 (DLP/NAC)`로 비인가 무선 모뎀 강제 비활성화** | 망분리 우회 통로 원천 차단 및 정책 준수율 100% 달성 |
| 대용량 파일 반입 시 망연계 스토리지 I/O 병목으로 업무 지연 | **`인메모리 기반 비-IP 버퍼링` 및 다중 백신 병렬 스캔 파이프라인** | 파일 검사 지연 70% 단축 및 업무 연속성 확보 |

#### 한줄 요약
- CDR로 문서 악성코드를 제거하고, PAM으로 서버 접근을 통제하며, DLP/NAC로 망 혼용을 방지한다.

## Ⅶ. 결론

- 외부 침해 위협을 인터넷 영역으로 국소 격리하고 내부 핵심 자산을 철저히 보호하는 **국내 공공·금융 및 국가 기반 시설 보안 규제의 가장 강력하고 핵심적인 경계 보안 표준**으로 확립되었으며, 클라우드 SaaS 도입 및 생성형 AI 활용 요구에 맞추어 일률적 망분리에서 데이터 중요도에 따른 다층 보안 체계(MLS) 및 제로 트러스트(ZTNA)로 진화하는 가운데, 실무 망분리 인프라 구축 시에는 **문서 내 제로데이 악성 매크로를 제거하는 망연계 CDR(무해화 및 재조립) 엔진 의무화, 내부 특권 계정 탈취를 방지하는 PAM 기반 MFA 및 세션 감사 로깅, 무선 테더링/듀얼 NIC에 의한 망 혼용을 차단하는 NAC/DLP 매체 제어**를 결합하여 완벽한 망 격리 무결성을 완성

#### 한줄 요약
- 망분리는 물리적·논리적 격리와 CDR 망연계 및 PAM 통제를 결합하여 기업 핵심 자산을 보호하는 표준 보안 인프라다.
