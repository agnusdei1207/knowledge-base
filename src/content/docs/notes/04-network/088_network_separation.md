## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **망분리**: 신뢰 수준이 다른 네트워크를 격리하고 승인된 통로만 허용해 침해 확산을 제한하는 보안 통제이다.

</details>

- 정의/개념: 신뢰 수준이 다른 네트워크를 **격리하고 승인된 통로만 허용**해 침해 확산을 제한하는 **보안 통제**이다.
- 배경/필요성: 단일 망의 **침해 횡적 확산•정보 유출**이 발생한다.

#### 한줄 요약

- 중요한 업무망을 별도 방으로 나누고 파일과 관리자 접속은 검사받는 문으로만 오가게 한다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **기본 차단**: 명시적으로 허용하지 않은 모든 교차망 통신을 거부하는 정책이다.
- **통제 관문**: 분리 영역 사이의 자료와 관리자 세션을 검사하고 승인된 흐름만 중계하는 구성요소이다.

</details>

- **격리 강도**: 공유 자원•우회 경로로 실제 분리 수준을 결정한다.
- **기본 차단**: 업무에 필요한 통신만 예외 승인한다.
- **관문 통제**: 자료 전송과 관리자 세션을 별도 검사이다.

#### 한줄 요약

- 선을 나누는 것만으로 끝나지 않고 파일 반입과 원격 관리처럼 실제로 남겨 둔 통로를 더 엄격히 관리해야 한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **비무장지대(Demilitarized Zone, DMZ)**: 외부 공개 서버를 내부 업무망과 분리해 중계하는 보안 영역이다.
- **자료•관리 관문**: 자료 관문은 파일 반입•반출을 검사하고 관리 관문은 특권 세션을 인증•기록한다.

</details>

```text
망분리 구조
├─ 신뢰 영역
│  ├─ 비무장지대
│  ├─ 업무 영역
│  └─ 핵심 영역
└─ 업무•핵심 간 통제 관문
   ├─ 자료 전송 관문
   └─ 관리 접속 관문
```

선의 의미: 비무장지대•업무 영역•핵심 영역이 신뢰 수준별로 분리되고, 업무 영역과 핵심 영역 사이는 자료 전송 관문과 관리 접속 관문이라는 전용 통제 경계로만 연결되는 정적 구조이다.

| 구성요소 | 책임 |
|:---|:---|
| 비무장지대 | **공개 서비스 중계•내부 격리** |
| 업무 영역 | **일반 업무 단말•서버** 수용 |
| 핵심 영역 | **중요 자료•제어 시스템** 격리 |
| 자료 전송 관문 | **파일 검사•무해화•반출 승인** |
| 관리 접속 관문 | **관리자 인증•승인•세션 기록** |

#### 한줄 요약

- 인터넷•일반 업무•핵심 업무를 나누고 파일과 관리자 접속은 각각 전용 관문에서 검사한 뒤 통과시킨다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **접근 맥락**: 교차망 요청을 한 사용자•단말•권한•업무 목적을 묶은 판단 정보이다.
- **최소 흐름**: 업무 수행에 필요한 주소•포트•시간 범위만 허용한 네트워크 통신이다.

</details>

```text
교차망 통신 요청
      │
      ▼
1. 접근 맥락 검증
      ├─ 불일치: 요청 차단•감사 기록
      └─ 일치
          │
          ▼
2. 최소 흐름 판정
          ├─ 불필요 흐름: 차단
          └─ 필요 흐름
              │
              ▼
3. 자료•세션 검사
              ├─ 위험 탐지: 차단•격리
              └─ 통과: 4. 승인 통신 중계
                           │
                           ▼
                      감사 기록•업무 결과 반환
```

**동작 원리**

1. **접근 맥락 검증**: 사용자•단말•권한•업무를 대조한다.
2. **최소 흐름 판정**: 필요한 주소•포트•시간만을 허용한다.
3. **자료•세션 검사**: 악성 내용•관리 명령을 확인한다.
4. **승인 통신 중계**: 직접 연결 없이 관문이 대행한다.

#### 한줄 요약

- 다른 망으로 가려는 요청은 사용자와 업무 목적을 확인하고 필요한 범위만 관문이 대신 연결하며 모든 행위를 남긴다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **물리적•논리적 망분리**: 물리 분리는 장비•회선을 별도로 구성하고 논리 분리는 공유 장비 안에서 가상화•정책으로 영역을 나눈다.
- **혼합 망분리**: 핵심 영역은 물리적으로, 일반 영역은 논리적으로 분리해 비용과 격리 수준을 조절하는 방식이다.

</details>

| 망분리 방식 | 물리적 망분리 | 논리적 망분리 | 혼합 망분리 |
|:---|:---|:---|:---|
| 적용 기준 | 최고 격리•**규제 요구** | 잦은 변화•**자원 효율 우선** | 중요도별 **비용•격리 균형** |
| 핵심 특징 | 장비•회선의 **완전 별도 구성** | 공유 장비의 **가상화•정책 분리** | 핵심 물리•**일반 논리 분리** |
| 한계 | 높은 비용•**자료 이동 불편** | 설정 오류•**공유 계층 취약점** | 경계 복잡•**정책 불일치** |

> 요약: 자산 중요도•공유 위험•비용으로 방식을 선택한다.

#### 한줄 요약

- 아주 중요한 망은 물리적으로 나누고 변화가 잦은 망은 논리적으로 나누며 중요도가 섞이면 두 방식을 조합한다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **콘텐츠 무해화(Content Disarm and Reconstruction, CDR)**: 문서의 실행 코드와 위험 요소를 제거하고 안전한 내용으로 재구성하는 기술이다.
- **특권 접근 관리(Privileged Access Management, PAM)**: 관리자 권한•승인•세션•명령 기록을 통제해 특권 접근을 관리하는 체계이다.
- **가상 근거리 통신망(Virtual LAN, VLAN)**: 공유 장비에서 논리적인 링크 영역을 분리하는 기술이다.
- **가상 라우팅 및 포워딩(Virtual Routing and Forwarding, VRF)**: 장비 안에서 라우팅 테이블을 분리하는 기술이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 외부 문서의 **실행 코드 반입** | 관문에서 **CDR•악성 검사** 적용 | 업무망의 **감염 경로 차단** |
| 관리자 통로의 **우회 접속** | PAM 기반 **승인•세션 기록** | 특권 행위의 **추적성 확보** |
| 논리 분리의 **정책 불일치** | VLAN•VRF•방화벽 **교차 검증** | 우회 경로와 **오설정 감소** |

#### 한줄 요약

- 망연계 구간에서 외부 문서의 매크로•실행 코드를 제거하고 승인된 내용만 재구성해 내부 업무망으로 전달한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **격리 수준**: 공유 자원•우회 경로•관문 통제를 고려해 실제 침해 확산을 차단하는 정도이다.

</details>

- 최고 격리는 **물리 분리**, 변화•효율은 **논리 분리**, 중요도 혼재는 **혼합**이 핵심이다.

#### 한줄 요약

- 망분리는 물리와 논리 중 하나를 고르는 데서 끝나지 않고 실제 자료와 관리 경로를 어떤 관문으로 통제할지 정해야 한다.
