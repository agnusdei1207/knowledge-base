## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **망분리 (Network Separation)**: 해커가 인터넷망을 뚫고 들어와도, 중요한 회사 데이터가 있는 내부망으로 넘어오지 못하게 인터넷용 통신망과 업무용 통신망을 아예 찢어놓는 강력한 보안 정책이다.

</details>

- 정의: **망분리** 기반 보안 신뢰 수준이 다른 네트워크(인터넷망, 내부 업무망 등)를 물리적/논리적으로 격리하고, 엄격하게 승인된 통로(망연계)만 허용해 침해 확산을 막는 네트워크 보안 통제다.
- 배경: 단일망을 쓰면 말단 직원의 PC 하나만 랜섬웨어에 걸려도 회사 전체 DB 서버까지 하이패스로 침해당하니까, **해커가 횡적(Lateral)으로 이동하지 못하게 망 자체를 두 동강 내버렸다.** #### 한줄 요약

- 해커가 판치는 인터넷망과 중요한 사내 업무망을 찢어놔서, 인터넷 PC가 털려도 회사 데이터는 안전하게 지키는 방어막이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **기본 차단 (Default Deny)**: "일단 두 망 사이의 통신은 다 막고, 서류 결재받은 아주 필수적인 것만 열어준다"는 망분리의 0순위 화이트리스트 철칙이다.
- **통제 관문 (망연계 시스템)**: 망이 갈라져 있어도 파일은 주고받아야 하니까, 악성코드 검사를 빡세게 거치고 결재를 받아야만 파일을 통과시켜 주는 '사이버 세관'이다.

</details>

- **일단 다 막기 (기본 차단)**: 외부 인터넷망과 내부 업무망 사이의 직접 연결은 100% 차단하며, 업무상 꼭 필요한 통신만 예외적으로 승인한다.
- **개구멍 통제 (망연계 관문)**: 망분리를 해도 이메일이나 엑셀 파일 전송을 위한 통로(망연계)는 뚫어 놔야 하므로, 이 구간의 악성코드 유입과 중요 정보 유출을 빡세게 감시한다.

#### 한줄 요약

- 두 네트워크를 완전히 끊어버리고, 파일을 넘길 때는 세관(망연계)에서 빡세게 바이러스 검사를 하고 넘겨준다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **DMZ (비무장지대)**: 웹서버처럼 외부 인터넷이랑 꼭 통신해야 하는 서버들을 내부망과 격리해서 몰아넣은, 털릴 거 각오하고 만든 완충 지대다.
- **자료/관리 관문**: 망 간 파일 전송을 검사하는 자료 연계 관문과, 서버망 접근 권한을 체크하는 관리 연계 관문이다.

</details>

```text
[ 망분리 및 통제 관문 직관적 비교 구조 ]

[ 1. 인터넷 영역 (해커 득실득실) ] ── (웹서핑, 외부 이메일용 PC가 여기 있음)
      │
      ▼ (외부 서비스용 서버 대기실)
[ 2. 비무장지대 (DMZ) ] ── (털릴 거 각오하고 웹서버 세워둔 곳. 여기서 내부망 직접 못 감)
      │
======▼=============================== (망연계 시스템 / 통제 관문)
      │ (팀장 결재받은 파일만 백신/CDR 검사하고 문 열어줌)
[ 3. 업무 영역 (내부망) ] ── (인터넷 안 되는 쾌적한 사내망. 문서 작업용 PC)
      │
======▼=============================== (접근 제어 시스템 / PAM)
      │ (관리자만 2FA 인증하고 접근 가능, 작업 화면 100% 녹화함)
[ 4. 핵심 영역 (서버망) ] ── (고객 DB, 소스코드 저장된 심장부)
```

| 구성요소 | 책임 | 비고 |
|:---|:---|:---|
| **인터넷망 / DMZ** | 털릴 거 각오하고 **인터넷 서핑하고 외부 서비스 돌리는 격리 구역** | Untrusted Zone |
| **업무망 (내부망)** | 해커 못 들어오게 **인터넷 선 뽑아버린 쾌적한 사내망** | Trusted Zone |
| **핵심망 (서버망)** | 내부 직원도 함부로 못 들어가는 **고객 DB 저장된 최심부** | Core Zone |
| **자료 전송 관문** | 인터넷망에서 내부망으로 파일 가져올 때 **악성코드 체크하는 세관** | 망연계 시스템 |
| **관리 접속 관문** | 서버망 접근할 때 **관리자 신분증(MFA) 빡세게 검사하는 초소** | 접근 제어 (PAM) |

#### 한줄 요약

- 인터넷 지대, 사내 업무 지대, 서버 지대를 나누고 각 지대를 넘어갈 땐 세관에서 검사받아야 한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **접근 맥락 / 최소 흐름**: 인터넷망에서 내부망으로 통신할 때 "누가, 왜" 쏘는지(맥락) 확인하고, 딱 필요한 포트랑 출발지/목적지 IP 하나만(최소 흐름) 구멍을 뚫어주는 깐깐한 정책이다.

</details>

```text
[ 망연계 (교차망) 통신 통제 십자포화 흐름 ]

┌──────────────────────────────┐
│ 1. [교차망 통신 요청 및 접근 맥락 검증]
│ (직원: 인터넷망 PC에서 내부망으로 제안서 파일 좀 넘길게)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 2. [최소 흐름 판정 및 팀장 결재]
│ (관문: 업무 목적 맞음? 팀장 결재 났음? 체크 완료)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 3. [자료/세션 검사 (백신/CDR)]
│ (망연계: 파일 내놔 봐. 매크로 바이러스 묻었네? 차단!)
│ (정상 파일일 경우만 통과)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 4. [승인 통신 중계 및 감사 기록]
│ (관문: 내부망으로 파일 넘겨줌. 누가 무슨 파일 넘겼는지 로그 박제)
└──────────────────────────────┘
```

### 동작 원리

1. 통신/반입 요청: 직원이 외부 인터넷망에서 다운받은 파일을 사내망으로 넘기겠다고 망연계 시스템에 결재를 올림.
2. 정책 검증 및 승인: 보안 정책에 위반되지 않는 확장자인지 체크하고 부서장 결재를 받음.
3. 악성코드 검사: 승인된 파일을 멀티 백신과 APT 방어 장비(CDR)로 지독하게 검사함.
4. 파일 전송 및 감사 기록: 검사 통과한 파일만 내부망으로 쏴주고, 언제 누가 넘겼는지 로그를 평생 박제함.

#### 한줄 요약

- 결재 올리기 $\to$ 파일 빡세게 세탁하기 $\to$ 내부망 전송 $\to$ 꼬투리 잡히게 로그 남기기의 4단계다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **물리적 망분리**: 책상 위에 PC 2대(인터넷용 1대, 업무용 1대) 올려두고 랜선도 2가닥 깔아버리는 무식하지만 가장 확실한 방법이다.
- **논리적 망분리 (VDI / CBC)**: PC는 1대인데, 서버 기반 가상화(VDI)를 써서 인터넷 화면만 스트리밍받거나, PC 안에서 OS를 가상으로 쪼개서(CBC) 싸게 때우는 방법이다.

</details>

| 망분리 방식 비교 | **물리적 망분리 (PC 2대)** | **논리적 망분리 - VDI (가상 데스크탑)** | **논리적 망분리 - CBC (OS 쪼개기)** |
|:---|:---|:---|:---|
| 핵심 특징 | **집 두 채 짓고 따로 살기** | **서버에 원격 접속해서 화면만 보기** | **PC 한 대에 윈도우 2개 깔아서 스왑하기** |
| 작동 원리 | 진짜로 PC 2대, 망 스위치 2개 깔아서 **하드웨어적으로 100% 찢어버림** | 인터넷망이나 내부망 중 하나를 **서버의 가상 PC(VM)로 할당받아 스트리밍함** | PC 1대에서 **하이퍼바이저로 격리된 가상 OS 영역 2개를 돌림** |
| 최고 장점 | 해킹이 불가능에 가까운 **완벽한 보안성 (망혼용 제로)** | PC 1대라 책상 깔끔하고, **서버에 데이터 저장돼서 통제 쉽고 스마트워크 가능** | VDI처럼 비싼 서버 안 사도 돼서 **구축 비용이 제일 쌈** |
| 치명적 한계 | 구축 비용이 **급격히 비싸고**, 책상 좁고 전기세 많이 나옴 | VDI 서버 인프라 구축 **초기 비용이 무지막지하게 깨지고, 서버 발생하면 다 뒈짐** | PC 사양 타서 버벅거리고, OS 취약점 침해당하면 **망분리 한 방에 뚫림** |

#### 한줄 요약

- 돈 많고 침해당하면 큰일 나는 곳은 물리적 망분리, 스마트워크 해야 하면 VDI 망분리를 쓴다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **CDR (콘텐츠 무해화)**: 외부에서 들어오는 엑셀 파일에 숨겨진 악성 매크로 찌꺼기를 다 뜯어내고 순수 데이터만 외부 캡슐화 래퍼 안에 다시 조립해서 내부망으로 들여보내는 무적의 세탁 기술이다.
- **PAM (특권 접근 관리)**: 관리자 계정 하나 침해당하면 끝장나니까, 서버망 들어갈 때 다중 인증(MFA) 거치고 작업 화면을 100% 동영상으로 녹화 박제하는 솔루션이다.
- **VLAN / VRF**: 스위치나 라우터 하나 안에서 가상으로 네트워크를 쪼개버리는 논리적 망분리의 근간 기술이다.

</details>

| 장애/위험 요소 | 원인 분석 | 실무 대책 및 해결방안 | 기대 효과 |
|:---|:---|:---|:---|
| 인터넷망 문서 열었는데 **내부망에 랜섬웨어 다 퍼짐** | 망연계 시스템의 구형 백신이 신종(제로데이) 악성 매크로를 못 걸러냄 | 망연계 관문에 **CDR(무해화) 장비 도입해서 문서 안의 매크로/스크립트 싹 다 뜯어버림** | 문서 기반 타겟형 해킹(APT) 및 신종 랜섬웨어 원천 차단 |
| 망분리 빡세게 해놨는데 **유지보수 외주 직원이 서버 다 털어감** | 서버망 접근할 때 비밀번호 하나만 치고 무지성으로 통과시킴 | **PAM(특권 접근 관리) 시스템 달아서 2FA 인증하고, 작업 화면 100% 녹화 박제함** | 내부자 소행 추적 및 루트(Root) 권한 오남용 완벽 차단 |
| 논리적 망분리 썼는데 **VLAN 점프 뛰어서 해킹당함** | 방화벽이나 스위치 라우팅 설정 삐끗해서 인터넷망에서 내부망으로 가는 구멍이 뚫림 | **VLAN, VRF** 설정 주기적으로 교차 검증하고 망 간 통신은 무조건 망연계 관문으로 몰아넣음 | 논리적 분리의 치명적 약점인 네트워크 설정 오류 방어 |

#### 한줄 요약

- 망연계 구멍으로 들어오는 악성코드는 CDR로 세탁하고, 내부 서버 접속하는 놈들은 PAM으로 녹화해서 감시해라.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- (상단 참조)

</details>

- 단일망의 횡적 확산 취약점을 제거하기 위해, 기업 환경에 맞는 **물리/논리적 망분리** 및 **망연계 시스템(자료/스트림 연계)**, **CDR 및 PAM 통제** 활용 결합한 최고 수준의 망분리 기조 확립함

#### 한줄 요약

- 망분리는 선만 뚝 끊는다고 끝나는 게 아니라, 남겨둔 개구멍(망연계)으로 쥐가 못 들어오게 덫을 놓는 게 진짜 핵심이다.
