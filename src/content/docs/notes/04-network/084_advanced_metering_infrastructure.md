## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **AMI (지능형 검침 인프라)**: 아줌마가 집에 와서 전기 계량기 숫자 적어가던 걸 없애고, 양방향 통신으로 실시간 요금 계산부터 "전기 끊어라!" 하는 원격 제어까지 다 해먹는 스마트 전력망의 핵심 인프라다.
- **AMR (자동 원격 검침)**: AMI의 조상님 격으로, 원격 제어는 못 하고 그냥 전기 사용량만 단방향으로 띡띡 보내주던 반쪽짜리 검침 방식이다.

</details>

- 정의: **AMI**는 집집마다 달린 스마트 미터(계량기)와 한전 서버를 양방향 통신으로 묶어서, 실시간 사용량 수집과 원격 제어(단전/복전)를 때리는 **양방향 지능형 검침 인프라**다.
- 배경: 아줌마가 일일이 돌아다니는 건 인건비가 터지고(현장 검침), 데이터만 받는(AMR) 걸론 요금 미납자 전기를 원격으로 못 끊으니까, **양방향으로 통신하고 제어까지 하려고 AMI를 깔았다.**

#### 한줄 요약

- 사람이 직접 계량기 보러 가는 짓을 없애고, 본사에서 마우스 클릭으로 요금 계산하고 전기까지 끊어버리는 기술이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **VEE (검증•추정•편집)**: 통신 에러로 계량값이 "99999"로 미쳐 날뛰거나 값이 비어있을 때, 한전이 과거 데이터를 보고 "이 집은 평균 300 쓰니까 300으로 퉁치자" 하고 체크하고 보정하는 작업이다.
- **양방향 제어**: 전력사가 돈 안 내는 집 전기를 원격으로 끊거나(차단), 돈 내면 다시 붙여주는(복전) 갑질의 핵심 기능이다.

</details>

- **원격 갑질 (양방향 제어)**: 전기 요금 안 내면 사람 안 보내고 서버에서 클릭 한 번으로 전기를 똑 끊어버리고(차단), 돈 내면 다시 붙여준다.
- **데이터 체크 (VEE)**: 계량기가 벼락 맞아서 한 달에 1억 원어치 썼다고 헛소리 보내면, 그대로 청구하지 않고 컷트한 뒤 과거 데이터를 바탕으로 보정(VEE)한다.
- **수요 반응 (DR)**: 한여름에 전력망 터질 것 같을 때, 스마트 미터에 "지금 전기 아끼면 요금 깎아줌" 하고 정보를 쏴서 사용량을 줄이게 유도한다.

#### 한줄 요약

- 단순히 전기 쓴 양만 읽어오는 게 아니라 이상한 값은 고쳐 쓰고(VEE), 말 안 들으면 원격으로 전기를 끊어버린다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **HES (헤드엔드 시스템)**: 수백만 대의 스마트 미터랑 통신을 맺고 끊으면서 데이터를 쭉쭉 빨아들이고 제어 명령을 쏴주는 최전방 통신 서버다.
- **MDMS (계량 데이터 관리 시스템)**: HES가 빨아들인 쓰레기 포함 로우 데이터를 모아서, VEE 체크를 빡세게 돌리고 요금소(빌링)로 넘겨주는 데이터 뇌다.

</details>

```text
[ 스마트 미터 AMI 직관적 비교 구조 ]

[ 1. 전력 업무 시스템 (빌링/ERP) ] ── (요금 고지서 찍어내고 단전 명령 내리는 본사)
      │
      ▼ (요금 계산용 데이터 넘김)
[ 2. MDMS (계량 데이터 관리 시스템) ] ── (데이터 모아서 에러 난 거 고치고(VEE) 체크함)
      │
      ▼ (원시 데이터 수집)
[ 3. HES (헤드엔드 시스템) ] ── (수백만 대 계량기랑 통신 터널 뚫고 멱살 잡는 최전방 서버)
      │
      ▼ (LTE, Wi-SUN 등 무선/유선 통신망)
[ 4. 스마트 미터 (Smart Meter) ] ── (전봇대나 집집마다 달려있는 똑똑한 계량기)
```

| 구성요소 | 직관적 비교 책임 | 비고 |
|:---|:---|:---|
| **스마트 미터** | 전력 사용량 측정하고 **단전/복전 명령받아서 릴레이 스위치 내리는 말단 기기** | Smart Meter |
| **HES (헤드엔드)** | 수백만 개 미터기랑 **통신 뚫고 데이터 빨아들이는 최전방 수집/명령 서버** | Head-End System |
| **MDMS (데이터 관리)**| 수집된 쓰레기 데이터 **체크(VEE)하고 쓸만하게 가공해 주는 뇌** | Meter Data Mgt |
| **전력 업무 시스템** | 최종 데이터 받아서 **요금 고지서 때리고 수요 반응(DR) 통제하는 본사** | Billing / ERP |

#### 한줄 요약

- 미터기가 측정하면 $\to$ HES가 수집하고 $\to$ MDMS가 에러 고치고 $\to$ 본사가 요금 고지서를 날린다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **품질 플래그 (Quality Flag)**: VEE로 값을 맘대로 수정했을 때, "이건 진짜 잰 게 아니라 우리가 짐작해서 적은 거다"라고 꼬리표를 달아놔서 나중에 고객이 요금 따질 때 체크용으로 쓰는 마크다.

</details>

```text
[ AMI 데이터 수집 및 원격 단전 십자포화 흐름 ]

┌──────────────────────────────┐
│ 1. [계량 자료 전송 및 누락 보완]
│ (미터기: 오늘 10kW 썼음 쏨. HES: 어제 거 비었네? 다시 쏴봐)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 2. [VEE 데이터 체크 (MDMS)]
│ (MDMS: 하루 만에 10만kW? 에러네. 과거 데이터로 추정(보정) 때려)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 3. [원격 제어 승인 및 명령 하달]
│ (본사: 이 집 요금 석 달 밀림. 전기 끊어라!)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 4. [인증 명령 실행 (단전/복전)]
│ (미터기: 해커 아니네 체크. 전기 차단 스위치 틱!)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 5. [결과 보고 및 요금 청구]  │
│ (HES: 단전 완료 보고. MDMS: 남은 요금 청구서 발행함)
└──────────────────────────────┘
```

### 동작 원리

1. 계량 자료 전송: 스마트 미터가 HES로 시간대별 사용량을 쏘고, 통신 끊겨서 누락된 건 나중에 다시 채워 넣음.
2. VEE 데이터 보정: MDMS가 수집된 데이터를 보고 미친 값이면 과거 데이터 기반으로 수정하고 꼬리표(플래그)를 닮.
3. 원격 명령 하달: 본사에서 요금 미납, 혹은 이사 간 집에 대해 원격으로 단전/복전 명령을 내림.
4. 인증 명령 실행: 미터기가 이게 찐 명령인지 검증(PKI)한 뒤 릴레이 스위치를 떨어뜨림.
5. 결과 보고/과금: 명령 성공 여부를 본사에 보고하고 정제된 데이터로 과금을 때림.

#### 한줄 요약

- 데이터 올려서 불량품 걸러내고(VEE), 돈 안 내면 얄짤없이 원격으로 끊어버리는 냉혹한 사이클이다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **현장 검침**: 노가다로 아줌마가 공책 들고 돌아다니는 구시대 방식이다.
- **AMR (단방향)**: 계량기가 데이터만 보내고 위에서 명령은 못 내리는 반쪽짜리다.

</details>

| 검침 방식 비교 | **현장 검침 (노가다)** | **AMR (반쪽짜리 자동화)** | **AMI (스마트 미터 끝판왕)** |
|:---|:---|:---|:---|
| 비유 및 핵심 특징 | **검침원 아줌마가 공책 들고 집집마다 감** | **미터기가 알아서 데이터만 위로 쏨** | **위아래 다 통신하고 본사에서 원격 차단까지 함** |
| 통신 방식 | 통신망 없음 (사람 눈) | 단방향 (미터기 $\to$ 본사) | 양방향 (미터기 $\leftrightarrow$ 본사) |
| 장점 | 해킹당할 일이 없음 | 인건비 줄고 요금 청구 자동화 | 원격 단전/복전, 실시간 수요 반응(DR) 싹 다 됨 |
| 치명적 한계 | 개가 물거나, 문 안 열어주면 검침 빵꾸남 | 미납자 전기 끊으려면 결국 사람 보내야 됨 | 서버 해킹당하면 **도시 전체 전기 다 끊겨서 지옥 됨** |

#### 한줄 요약

- 요금만 편하게 걷을 거면 AMR로 충분하지만, 전기를 원격으로 인형 뽑기처럼 통제하려면 무조건 AMI를 깔아야 한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **PKI (공개키 기반구조)**: 해커가 가짜 차단 명령 내리는 걸 막기 위해, 미터기랑 HES 서버가 서로 인증서로 빡세게 신분증 검사하는 보안 체계다.
- **이중 승인**: 마우스 한 번 잘못 클릭해서 공장 전기 끊기면 수백억 날아가니까, 차단 명령 내릴 땐 무조건 관리자 2명이 승인하게 락(Lock)을 거는 거다.

</details>

| 장애/위험 요소 | 원인 분석 | 실무 대책 및 해결방안 | 기대 효과 |
|:---|:---|:---|:---|
| 미터기 에러 났는데 **요금 1억 원 청구돼서 뉴스 남** | 미터기 고장으로 튄 값을 HES가 빌링 시스템에 무지성으로 넘겨버림 | MDMS에서 **VEE(검증/추정) 돌려서 체크하고 품질 플래그(꼬리표) 달아놓음** | 말도 안 되는 요금 폭탄 막고 고객 클레임 방어 |
| 해커가 서버 뚫고 **강남구 전체 전기를 다 끊어버림** | 해커가 쏜 가짜 단전 명령을 미터기가 바보같이 믿고 스위치 다 내림 | 미터기에 **PKI 인증서 박아넣고, 단전 명령은 관리자 '이중 승인' 빡세게 거침** | 대규모 블랙아웃 테러 막고 원격 제어 보안 확보 |
| 수백만 대 미터기 **인증서 만료돼서 통신 싹 죽음** | 보안성 높이려고 PKI 인증서 유효기간 짧게 줬는데, 수동으로 갱신하다가 빵꾸남 | 사람이 직접 안 하고 **HES가 원격(OTA)으로 인증서 자동 갱신하게 스크립트 짬** | 인증서 만료로 전국 계량기 통신 마비되는 뻘짓 방지 |

#### 한줄 요약

- 미친 값 올라오면 VEE로 거르고, 원격 단전할 땐 무조건 이중 승인 박아서 대참사를 막아야 한다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- (상단 참조)

</details>

- 단순 검침 인건비 절감을 넘어 실시간 수요 반응과 양방향 제어를 위해, **MDMS의 VEE 품질 관리**와 **HES-미터 간 PKI 보안**, **이중 승인**을 결합한 스마트 미터링 기조 확립함

#### 한줄 요약

- AMI는 아줌마 발품을 통신망으로 대체한 걸 넘어, 전국 전기 요금과 스위치를 쥐고 흔드는 전력망의 핵심 뇌다.
