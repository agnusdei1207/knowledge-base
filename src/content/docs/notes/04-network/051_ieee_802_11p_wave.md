## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **WAVE (IEEE 802.11p)**: 집에서 쓰는 와이파이(Wi-Fi)를 시속 100km로 달리는 자동차에서도 안 끊기고 쓸 수 있게 마개조한 '자동차 전용 와이파이'다.
- **OCB (Outside the Context of BSS)**: 카페 와이파이 잡을 때 뜨는 비밀번호 입력이나 IP 할당 대기 시간을 싹 다 무시하고, 그냥 전파 닿자마자 바로 데이터를 쏴버리는 프리패스 모드다.

</details>

- 정의: **IEEE 802.11p WAVE** 기반 5.9GHz 주파수 대역에서 복잡한 와이파이 연결 절차 없이(OCB 모드), 고속으로 달리는 차량끼리(V2V) 충돌 경고 메시지(WSMP)를 0.001초 만에 쏴버리는 단거리 통신 규격이다.
- 배경: 100km/h로 달리는 차가 일반 와이파이처럼 "비밀번호가 뭔가요?" 하고 핸드셰이크하는 몇 초 동안 차는 이미 100미터를 굴러가서 사고가 나니까, **묻지도 따지지도 않고 바로 통신부터 박아버리려고 만들었다.**

#### 한줄 요약

- 귀찮은 와이파이 연결 절차 싹 다 씹고(OCB), 자동차끼리 마주치자마자 0.001초 만에 급정거 메시지를 쏴버리는 자동차 전용 와이파이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **10MHz 반채널 (Half-clocked)**: 일반 와이파이는 20MHz로 뚱뚱하게 데이터를 쏘는데, 자동차는 너무 빨라서 전파가 찌그러지니까(도플러 효과), 대역폭을 반(10MHz)으로 줄여서 전파를 단단하고 질기게 만든 거다.

</details>

- **묻지마 직통 발사 (OCB 모드 적용)**: 통신사 가입이나 와이파이 비밀번호 입력 따위 다 생략하고, 전파 사정거리(300m) 안에 차가 들어오면 무조건 메시지부터 꽂아버림.
- **전파 찌그러짐 방어 (10MHz 반채널)**: 차가 너무 빨리 달려서 생기는 전파 왜곡(도플러 시프트)을 막으려고, 속도를 절반 포기한 대신 전파 생존력을 떡상시킴.
- **자동차 전용 스택 (IEEE 1609 결합)**: 밑바닥 무선 전파는 802.11p(와이파이)가 깔아주고, 그 위에서 노는 보안, 채널 쪼개기, 퀵서비스 배달은 IEEE 1609 형님들이 다 통제함.

#### 한줄 요약

- 연결 대기 시간 0초(OCB), 전파 안 깨지게 다이어트(10MHz), 자동차 전용 상위 스택(1609)으로 무장한 생존 특화 통신이다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **WSMP (WAVE Short Message Protocol)**: 복잡한 인터넷 주소(IP) 같은 거 다 떼어버리고, "앞차 급브레이크!" 같은 긴급 메시지만 초스피드로 나르는 자동차 전용 퀵서비스 라우팅이다.
- **CCH / SCH (제어/서비스 채널)**: 무전기 채널을 0.05초(50ms) 단위로 쪼개서, 0.05초는 생명과 직결된 긴급 방송(CCH)만 하고, 다음 0.05초는 MP3 다운로드 같은 잡다한 통신(SCH)을 번갈아 가면서 하는 거다.

</details>

```text
[ WAVE 규격 직관적 비교 구조 ]

[ 자동차 안전 앱 (BSM/CAM 긴급 메시지) ]
      │
[ IEEE 1609.2 (보안/해커 방어) ] ─▶ [ IEEE 1609.3 (WSMP 퀵서비스 라우팅) ]
      │
[ IEEE 1609.4 (0.05초마다 CCH/SCH 채널 와리가리 스위칭) ]
      │
[ IEEE 802.11p (5.9GHz 무선 전파, 묻지마 OCB 빔 발사) ]
```

| 구성요소 | 직관적 비교 책임 | 비고 |
|:---|:---|:---|
| **IEEE 1609.2 (보안)** | 해커가 구라핑 못 치게 **가명 인증서로 전자서명 빡세게 박는 놈** | 보안 계층 |
| **IEEE 1609.3 (네트워크)**| 무거운 IP 주소 버리고 **WSMP로 0.001초 만에 퀵 배달 뛰는 놈** | 네트워크 계층 |
| **IEEE 1609.4 (채널 운용)**| 0.05초마다 긴급 채널(CCH)이랑 잡다한 채널(SCH) **스위칭해 주는 놈** | 채널 제어 |
| **IEEE 802.11p (MAC/PHY)**| BSS(가입) 쌩까고 **5.9GHz로 전파 무지성 발사하는 밑바닥 노가다** | 무선 물리 계층 |

#### 한줄 요약

- 1609.2가 도장(보안) 찍고, 1609.3이 퀵서비스(WSMP) 부르고, 1609.4가 차선(채널) 뚫어주면, 802.11p가 무지성 발사(OCB)한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- (상단 참조)

</details>

```text
[ WAVE 초저지연 메시지 발사 십자포화 흐름 ]

┌──────────────────────────────┐
│ 1. [긴급 안전 메시지 생성]   │
│ (앱: 앞차랑 충돌 1초 전 떴다 쏴라!)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 2. [1609.2 가명 인증서 서명] │
│ (보안: 나 해커 아니고 진짜 앞차 맞음 도장 쾅)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 3. [1609.3 WSMP 퀵서비스 짐 싸기]
│ (네트워크: IP 주소 무거우니까 버리고 짐 압축함)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 4. [1609.4 긴급 채널(CCH) 탑승]
│ (채널: 지금 0.05초 긴급 타임임 얼른 타라)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 5. [802.11p OCB 전파 발사]  │
│ (물리: 가입 절차 쌩까고 5.9GHz로 무지성 발사)
└──────────────────────────────┘
```

### 동작 원리

1. 메시지 생성: 차량 센서가 사고를 감지하고 0.001초 단위의 BSM(기본 안전 메시지)을 뱉어냄.
2. 1609.2 보안 서명: 내 차가 유령 해커가 아니라는 걸 증명하기 위해 가명 인증서로 전자 서명을 꽝 찍음.
3. 1609.3 WSMP 캡슐화: 거추장스러운 TCP/IP 스택을 다 던져버리고 초경량 WSMP 봉투에 메시지를 담음.
4. 1609.4 CCH 타임슬롯 진입: 0.05초마다 열리는 긴급 제어 채널(CCH) 타이밍에 맞춰 무선 모듈을 장전함.
5. 802.11p OCB 발사: 와이파이 연결(핸드셰이크)을 과감히 생략하고 CSMA/CA 경합 뚫자마자 허공에 쏴버림.

#### 한줄 요약

- 보안 도장 찍고 $\to$ 짐 가볍게 줄여서 $\to$ 긴급 차선(CCH) 올라탄 뒤 $\to$ 톨게이트(BSS) 다 부수고 프리패스 발사함.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- (상단 참조)

</details>

| 구분 | **IEEE 802.11p (자동차 와이파이)** | **IEEE 802.11a/g/n (집/카페 와이파이)** |
|:---|:---|:---|
| 비유 및 핵심 특징 | 하이패스로 톨게이트 **그냥 뚫고 가는 놈** | 톨게이트 멈춰서 **동전 내고 영수증 받는 놈** |
| 접속 모드 | **OCB 모드** (비번이고 뭐고 묻지마 직통 발사) | **BSS 모드** (비번 치고 IP 할당받는 수초 대기) |
| 채널 대역폭 | **10MHz 반채널** (속도 포기하고 전파 생존력 떡상)| 20/40/80MHz (속도는 빠르지만 흔들리면 죽음) |
| 네트워킹 (짐싸기)| **WSMP 전용 프로토콜** (무겁고 복잡한 IP 다 뺌) | 무거운 TCP/IPv4, IPv6 다 달고 다님 |
| 무선 이동성 | **100km/h로 쌩쌩 달리는 고속도로 자율주행** | 사람 걷는 속도나 방구석 넷플릭스 머신 |

#### 한줄 요약

- 일반 와이파이가 방구석에서 넷플릭스 보려고 덩치를 키운 놈이라면, 802.11p는 고속도로에서 살아남으려고 군살을 다 뺀 놈이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **듀얼 라디오(Dual-Radio)**: 0.05초마다 채널을 껐다 켰다(CCH/SCH 스위칭) 하면 찰나의 순간에 긴급 메시지를 놓칠 수 있으니, 아예 안테나를 2개 달아서 두 채널을 동시에 듣는 돈지랄 장비다.
- **EDCA (우선순위 큐)**: 앰뷸런스가 오면 모세의 기적처럼 차들이 비켜주듯이, 5.9GHz 무선 채널 안에서도 생명과 직결된 브레이크 메시지는 남들 다 무시하고 프리패스로 쏘게 해주는 새치기 기술이다.

</details>

| 장애/위험 요소 | 원인 분석 | 실무 대책 및 해결방안 | 기대 효과 |
|:---|:---|:---|:---|
| 0.05초마다 채널(CCH) 바꾸다 **긴급 메시지 놓치고 사고 남** | 안테나 1개로 와리가리 털다가(스위칭) 무선 사각지대가 생김 | OBU에 안테나 2개 박아서 상시 청취하는 **Dual-radio 장비 떡칠함** | 스위칭 딜레이 삭제 및 무조건 생존 수신 |
| 강남역 차 막히니까 **와이파이(CSMA/CA) 충돌 나서 뻗음** | 수백 대가 서로 떠들겠다고 눈치 게임 하다가 주파수 터짐 | 급정거 메시지에 무조건 새치기 권한 주는 **EDCA (우선순위 큐) 적용** | 아무리 차 막혀도 급정거 핑은 무조건 살림 |
| 전자서명(보안) 풀다가 **시간 다 가서 이미 앞차 박음** | 보안 칩(CPU) 깡성능이 후져서 ECDSA 암호 푸는 데 한참 걸림 | 무전기(OBU) 안에 **하드웨어 암호 가속기(HSM) 칩셋을 발라서 박아버림** | 0.01초 만에 서명 체크 끝내고 브레이크 밟음 |

#### 한줄 요약

- 채널 바꾸다 죽기 싫으면 안테나 2개 달고(Dual-radio), 차 막히면 새치기 룰(EDCA) 쓰고, 암호 풀다 죽기 싫으면 비싼 칩(HSM) 써라.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- (상단 참조)

</details>

- BSS 접속 지연과 도플러 효과를 극복하기 위해, **OCB 모드** 및 **10MHz 반채널** 적용하고 **IEEE 1609 WSMP** 프로토콜을 결합한 802.11p WAVE 단거리 무선 통신 기조 확립함

#### 한줄 요약

- WAVE 802.11p는 비록 C-V2X에게 패권을 내주고 있지만, 'OCB 묻지마 통신'이라는 자동차 무선망의 근본을 세운 위대한 기술이다.
