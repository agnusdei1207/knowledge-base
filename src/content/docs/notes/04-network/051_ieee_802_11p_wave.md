## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **IEEE 802.11p (WAVE)**: 고속 주행 환경에 맞춰 5.9GHz 대역에서 BSS 연결 절차 없이 즉시 통신하는 차량 전용 Wi-Fi 물리/MAC 계층 표준.
- **OCB (Outside the Context of BSS)**: AP 접속 핸드셰이크나 인증 절차를 생략하고 수신된 프레임을 즉시 복조 처리하는 무선 통신 모드.

</details>

- 정의/개념: 차량 주행 환경(5.9GHz)에서 BSS 결합 절차를 생략하는 **OCB** 모드와 경량 WSMP 프로토콜을 통해 10ms 내에 안전 메시지를 전송하는 차량 무선 통신 표준
- 배경/필요성: 일반 상용 Wi-Fi(802.11a/g/n)는 통신 개시 전 BSS(Basic Service Set) 탐색, 인증, 결합(Association) 및 DHCP IP 할당에 수 초 이상의 긴 핸드셰이크 지연이 소요되고, 20MHz 광대역 채널 구조가 100km/h 이상의 고속 이동 시 심각한 도플러 편이(Doppler Shift)와 다중 경로 지연 확산(Delay Spread)에 취약하여 차량 간 충돌 방지 안전 메시지를 즉각 교환하지 못하는 한계를 극복하기 위해, 5.9GHz ITS 전용 대역에서 BSS 결합 절차 없이 즉시 무선 프레임을 송수신하는 OCB(Outside the Context of BSS) 모드, 심볼 길이를 2배로 확장한 10MHz 반채널(Half-Clocked), 무거운 TCP/IP를 우회하는 경량 WSMP(IEEE 1609.3)를 집대성한 **IEEE 802.11p** WAVE 표준을 도입하여 고속 주행 환경에서의 10ms 이하 결정론적 초저지연 안전 메시지 전송과 도플러 내성을 달성할 필요

#### 한줄 요약
- OCB 모드, 10MHz 반채널, WSMP 경량 스택을 통해 고속 주행 환경에서 10ms 이내 통신을 실현한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **10MHz Half-Clocked Channel**: 기존 20MHz 채널을 10MHz로 축소하여 심볼 길이를 2배 늘림으로써 다중 경로 지연 확산(Delay Spread)과 ISI를 방어하는 기법.
- **WSMP (WAVE Short Message Protocol)**: 복잡한 TCP/IP 헤더를 제거하고 안전 페이로드만을 초경량으로 전달하는 IEEE 1609.3 차량 전용 프로토콜.

</details>

- 접속 지연 시간 제로(OCB 모드): 사전 비컨 탐색 및 인증 핸드셰이크 없이 패킷을 즉시 방송 송수신
- 10MHz 반채널(Half-Clocked) 적용: 심볼 시간을 2배(8.0㎲)로 확장하여 고속 주행 시 다중 경로 지연 확산 및 도플러 내성 확보
- 차량 전용 IEEE 1609 상위 스택 결합: 보안(1609.2), **WSMP** 네트워킹(1609.3), 멀티채널 제어(1609.4) 완비

#### 한줄 요약
- 접속 지연 0초(OCB), 10MHz 반채널 지연 확산 방어, IEEE 1609 상위 스택 결합을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **CCH vs SCH (제어/서비스 채널)**: 50ms 주기로 시분할 스위칭하여 50ms는 긴급 안전 방송(CCH)을, 50ms는 일반 데이터 서비스(SCH)를 수행하는 채널 구조.

</details>

```text
[IEEE 802.11p WAVE 스택 구조]
  │
  ├─ [응용 계층] ── Application Layer
  │     ├─ BSM 기본 안전 메시지 (위치/속도/방향 브로드캐스트)
  │     └─ CAM / DENM (돌발 상황 긴급 경보 메시지)
  │
  ├─ [WAVE 상위 규격] ── IEEE 1609 Protocol Family
  │     ├─ IEEE 1609.2 보안 (ECDSA 가명 인증서 전자서명)
  │     ├─ IEEE 1609.3 네트워킹 (초경량 WSMP 라우팅)
  │     └─ IEEE 1609.4 다중채널 (50ms CCH/SCH 스위칭)
  │
  └─ [무선 물리·MAC] ── IEEE 802.11p
        ├─ MAC 계층 (OCB 모드, EDCA 차등 매체 접속)
        └─ PHY 계층 (5.9GHz 대역, 10MHz 반채널 OFDM)
```

- 선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| IEEE 1609.2 (보안) | ECDSA 타원곡선 전자서명 및 **가명 인증서 위변조 차단** |
| IEEE 1609.3 (네트워크) | 복잡한 TCP/IP를 우회하는 **초경량 WSMP 1ms 라우팅** |
| IEEE 1609.4 (채널 제어) | 50ms 단위 **긴급 제어(CCH) 및 서비스(SCH) 시분할 스위칭** |
| IEEE 802.11p (PHY/MAC) | BSS 결합 생략 **OCB 모드 및 10MHz 반채널 OFDM 송출** |

#### 한줄 요약
- 1609.3의 WSMP가 TCP/IP 헤더와 그 연결 수립 절차를 걷어내고 802.11p의 OCB가 BSS 결합 자체를 생략하므로, 스쳐 지나가는 차량은 접속 협상에 쓸 시간 없이 곧바로 안전 메시지를 뿌린다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **WSMP 캡슐화 5단계**: 긴급 안전 메시지 생성 $\to$ 1609.2 가명 서명 $\to$ 1609.3 WSMP 캡슐화 $\to$ 1609.4 CCH 타임슬롯 할당 $\to$ 802.11p OCB 즉시 송출.

</details>

```text
WAVE 초저지연 안전 메시지 전송 파이프라인
        │
   1. [긴급 안전 메시지 생성] 차량 센서가 급제동을 감지하고 BSM 메시지 생성 (100ms 주기)
        │
   2. [1609.2 가명 서명] HSM 칩셋을 통해 ECDSA 가명 전자서명 생성 및 패킷 결합
        │
   3. [1609.3 WSMP 캡슐화] TCP/IP 헤더를 생략하고 초경량 WSMP 헤더로 패킷 조립
        │
   4. [1609.4 CCH 타임슬롯 할당] 50ms 제어 채널 동기화 타이밍에 맞춰 무선 버퍼 인입
        │
   ▼
5. [802.11p OCB 즉시 송출] BSS 핸드셰이크 없이 5.9GHz 10MHz 대역으로 즉각 무선 방사
```

#### 한줄 요약
- TCP/IP 헤더와 BSS 결합을 걷어낸 만큼 첫 메시지가 즉시 나가지만, 연결로 확보하던 신뢰 근거가 사라져 1609.2 서명 검증이 메시지마다 붙는다.

## Ⅴ. 종류 및 비교


| 비교 항목 | IEEE 802.11p (WAVE 차량용) | IEEE 802.11a/g/n (상용 Wi-Fi) |
|:---|:---|:---|
| 접속 모드 | OCB 모드 (사전 결합 절차 없이 즉각 송출) | BSS 모드 (비밀번호 인증 및 IP 할당 대기) |
| 채널 대역폭 | 10 MHz (심볼 주기 2배 확장을 통한 내성 확보)| 20 / 40 / 80 MHz (광대역 고속 전송 지향) |
| 심볼 지속 시간 | 8.0 ㎲ (지연 확산 및 도플러 내성 극대화) | 4.0 ㎲ (고속 이동 시 간섭 왜곡 발생) |
| 전송 계층 프로토콜 | WSMP 전용 경량 프로토콜 (오버헤드 최소화) | 일반 TCP/IPv4, IPv6 무거운 스택 |
| 지원 이동 속도 | 최대 200 km/h 고속 이동 환경 지원 | 보행 및 정지 환경 (고속 이동 시 세션 단절) |

#### 한줄 요약
- 802.11p는 OCB 모드와 10MHz 반채널 설계를 통해 고속 주행 환경에 최적화된 통신을 제공한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Dual-Radio (이중 무선 트랜시버)**: 50ms 채널 스위칭(CCH/SCH)으로 인한 안전 메시지 수신 공백을 원천 제거하기 위해 2개의 RF 체인을 탑재하여 동시 청취하는 구성.
- **EDCA (Enhanced Distributed Channel Access)**: 4개 접근 범주(AC_VO, AC_VI, AC_BE, AC_BK)를 통해 긴급 제동 메시지에 최우선 매체 접근 권한을 부여하는 QoS 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 50ms CCH/SCH 스위칭 중 발생하는 **긴급 안전 메시지 수신 공백** | OBU 내 Dual-Radio (2개 무선 RF 트랜시버) 상시 청취 탑재 | 채널 전환 공백 제거 및 긴급 안전 메시지 100% 수신 |
| 교차로 차량 밀집 시 CSMA/CA 백오프 충돌로 패킷 폐기 급증 | 긴급 안전 패킷에 최우선 권한을 부여하는 **EDCA (QoS 큐잉) 적용** | 고우선순위 BSM 메시지 최단 지연 전송 보증 |
| 차량 고속 이동 시 ECDSA 서명 검증 지연으로 인한 제동 지연 | OBU 내 하드웨어 보안 모듈(HSM / Crypto Accelerator) 탑재 | 초당 수천 개 서명 1ms 내 고속 검증 |
| 다중 경로 페이딩으로 인한 터널 및 도심 협곡 수신율 저하 | 다이버시티 안테나(Rx Diversity) 및 채널 등화기 최적화 | 다중 경로 간섭 완화 및 패킷 수신 성공률 향상 |

#### 한줄 요약
- **Dual-Radio** 상시 청취, EDCA 우선순위 큐, HSM 암호 가속기, 다이버시티 안테나로 운영한다.

## Ⅶ. 결론

- C-ITS 초기 시범 사업 및 북미/유럽의 단거리 차량 안전 인프라 구축을 주도하며 1세대 V2X 통신 기술의 성숙도와 신뢰성을 검증한 핵심 무선 표준으로 기여하였으며, 향후 고용량 센서 셰어링을 지향하는 802.11bd 및 C-V2X와의 융합으로 발전해 나가는 가운데, 실무 장비 구축 시에는 50ms CCH/SCH 스위칭 수신 공백을 원천 제거하는 Dual-Radio 상시 청취 구조 적용, 긴급 제동 메시지 우선권을 보장하는 EDCA QoS 스케줄링, 패킷 검증 지연을 최소화하는 HSM 하드웨어 암호화 가속기를 결합하여 완벽한 노변·차량 간 안전 통신 링크를 완성

#### 한줄 요약
- IEEE 802.11p WAVE는 OCB 모드와 10MHz 반채널을 통해 고속 주행 시 초저지연 안전 통신을 구현하는 단거리 차량 통신 표준이다.
