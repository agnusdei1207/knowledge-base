## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **C-V2X (Cellular V2X)**: 스마트폰 통신망(LTE/5G) 기술을 자동차에 쑤셔 넣은 거다. 기지국도 쓰고 다이렉트 통신도 다 지원하는 최신식 셀룰러 V2X 통신이다.
- **DSRC / WAVE (단거리 전용 통신)**: 집에서 쓰는 와이파이(Wi-Fi) 기술을 자동차용으로 개조한 거다. 기지국 없이 차끼리 직접 무전 치는 데 특화된 1세대 통신이다.

</details>

- 정의: 자율주행차끼리 대화할 때 쓰는 양대 통신 규격이다. 3GPP가 주도하는 통신사 기반의 **C-V2X**와 IEEE가 주도하는 와이파이 기반의 **DSRC(WAVE)** 가 맞짱을 뜨는 기술 구도다.
- 배경: 지능형 교통 체계(C-ITS)를 깔아야 하는데, 옛날부터 쓰던 싸고 검증된 와이파이(DSRC)를 깔지, 아니면 비싸지만 5G로 진화할 수 있는 최신 기술(C-V2X)을 깔지 국가마다 피 터지게 싸우다가 팩트 정리가 필요해서 나왔다.

#### 한줄 요약

- 자동차 통신망(V2X)의 표준을 놓고, '최신 스마트폰 칩(C-V2X)'과 '전통의 와이파이 칩(DSRC)'이 서로 밥그릇 싸움하는 거다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **CSMA/CA (경합 방식)**: DSRC의 와이파이식 통신이다. 누가 말하고 있으면 눈치 보다가 조용해질 때 내가 말하는 '눈치 게임' 방식이라, 차가 많아지면 서로 말하려고 난리 치다 통신이 뻗는다.
- **자원 스케줄링 (Resource Scheduling)**: C-V2X의 통신사식 통신이다. 기지국이나 알고리즘이 "너는 1번 채널, 너는 2번 채널 써" 하고 번호표를 뽑아줘서 차가 엄청 몰려도 깔끔하게 통신한다.

</details>

- **DSRC (단순 무식 와이파이)**: 눈치 게임(CSMA/CA) 방식이라 한산한 도로에선 싸고 빠르지만, 강남역처럼 차가 꽉 막히면 지들끼리 전파가 꼬여서 메시지가 다 날아가는 맹점이 있음.
- **C-V2X (스마트 셀룰러)**: 주파수 채널을 쪼개서 번호표(스케줄링)를 나눠주니까, 차가 수백 대 몰려도 전파 충돌이 안 나고 수신 성공률(PDR)이 떡상함.
- **진화의 한계 (미래 전망)**: DSRC는 와이파이 태생적 한계로 100~300m 단거리 직통만 되지만, C-V2X는 통신사 5G 망을 껴서 수십 km 밖 광역 사고 정보까지 다이렉트로 끌어올 수 있음.

#### 한줄 요약

- DSRC는 차가 많아지면 전파가 엉켜서 죽지만, C-V2X는 번호표(스케줄링)를 나눠줘서 쾌적하고 5G 기지국까지 쓸 수 있다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **OBU (차량 단말기, On-Board Unit)**: 자동차 트렁크에 다는 무전기다. DSRC는 와이파이 칩을 달고, C-V2X는 스마트폰 모뎀 칩(LTE/5G)을 단다.
- **RSU (노변 장치, Roadside Unit)**: 신호등에 매달아 놓는 중계 안테나다. DSRC 전용 RSU랑 C-V2X 전용 RSU는 서로 쓰는 말이 달라서 소통이 안 된다.

</details>

```text
[ V2X 통신 규격 팩트 폭행 구조 ]

[ C-V2X 진영 (최신식 5G 모뎀 파) ]
  ├─ 코어 기술: 3GPP 통신사 표준 (PC5 / Uu)
  ├─ 통신 방식: 주파수 쪼개서 번호표 배분 (자원 스케줄링)
  └─ 진화 방향: 5G-V2X $\to$ 6G-V2X (완전 자율주행)

VS

[ DSRC 진영 (전통의 와이파이 파) ]
  ├─ 코어 기술: IEEE 802.11p (WAVE) 와이파이 개조
  ├─ 통신 방식: 눈치 보다가 아무나 지르기 (CSMA/CA 경합)
  └─ 진화 방향: 802.11bd (근데 투자 다 끊기고 망해가는 중)
```

| 구성요소 | C-V2X (최신 스마트폰 칩) | DSRC (전통 와이파이 칩) |
|:---|:---|:---|
| **OBU / RSU 칩셋** | 비싸지만 성능 짱짱한 **셀룰러(LTE/5G) 모뎀** | 싸고 구조가 단순한 **와이파이(802.11p) 모뎀** |
| **통신 룰 (접근 제어)**| 차례대로 번호표 뽑아서 말하는 **스케줄링 제어** | 눈치 보다가 사람 없을 때 지르는 **경합(CSMA/CA)** |
| **네트워크 커버리지** | 기지국(Uu) 껴서 **광역망 + 직접망 짬짜면 지원** | 무조건 차끼리 직접 무전 치는 **근거리 한우물** |
| **글로벌 대세** | 중국, 미국, 한국이 **전부 이쪽으로 갈아탐 (승리자)** | 20년 동안 팠는데 **최근에 버려지는 중 (패배자)** |

#### 한줄 요약

- C-V2X는 3GPP 통신사 규격으로 스케줄링 룰을 쓰고, DSRC는 IEEE 와이파이 규격으로 눈치 게임 룰을 쓴다.

### 동작 원리

1. 주파수 할당 논의: 국가별로 5.9GHz V2X 주파수 대역을 어느 기술에 줄지 밥그릇 싸움 시작.
2. 장단점 격돌: DSRC는 성숙도와 싼 가격을 무기로, C-V2X는 스케줄링과 5G 진화성을 무기로 격돌함.
3. 고밀도 성능 팩트 체크: 차량이 몰리는 교차로에서 테스트해 보니 DSRC는 패킷이 씹히고 C-V2X가 승리함.
4. 기술 단일화: 미국 FCC에 이어 한국 과기부도 2023년 C-V2X 단일 표준 채택을 선언하며 게임이 끝남.

#### 한줄 요약

- 옛날엔 싼 맛에 DSRC를 깔았는데, 차가 꽉 막히면 통신이 터지는 문제 때문에 결국 C-V2X로 글로벌 대세가 넘어왔다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- (상단 참조)

</details>

| 비교 항목 | **C-V2X (승리자)** | **DSRC / WAVE (패배자)** |
|:---|:---|:---|
| 팩트 폭행 비유 | 번호표 뽑고 질서 지키는 **스마트폰 통신** | 마이크 하나 두고 눈치싸움 하는 **무전기 통신** |
| 무선 표준 기술 | **3GPP (통신사 연합 표준)** | **IEEE 802.11p (와이파이 연합 표준)** |
| 채널 접속 방식 | **OFDMA / 스케줄링 (질서 정연함)** | **CSMA/CA (눈치 게임, 툭하면 충돌)** |
| 통신 커버리지 | **최대 1km 직통 + 기지국(5G) 광역 통신** | **300m 이내 (딱 눈에 보이는 곳만 직통)** |
| 고밀도(강남역) 성능| 채널 쪼개서 할당하니까 **전파 빵빵하고 쾌적함** | 차가 100대만 넘어가도 **서로 씹혀서 먹통 됨** |
| 현재 상황 | **미국, 중국, 한국 모두 단일 표준 확정** | **유럽도 손절각 재면서 역사 속으로 사라지는 중** |

#### 한줄 요약

- 기술력, 커버리지, 진화 가능성 등 모든 면에서 5G 모뎀을 단 C-V2X가 와이파이 베이스인 DSRC를 압살했다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **듀얼 모드(Dual Mode)**: DSRC로 이미 깔아놓은 옛날 기계들이 버티고 있으니까, 기계 하나에 C-V2X랑 DSRC 칩을 둘 다 박아놓고 과도기를 버티는 꼼수다.

</details>

| 장애/위험 요소 | 원인 분석 | 실무 대책 및 해결방안 | 기대 효과 |
|:---|:---|:---|:---|
| 교차로에 차가 꽉 차면 **DSRC 무전이 다 씹히고 뻗음** | CSMA/CA 특성상 눈치 게임 하다 차가 많아지면 **주파수 충돌 폭발함** | 스케줄링으로 질서 잡아주는 **C-V2X 단일 표준으로 완전 이관** | 강남역 한복판에서도 V2X 핑 안 튀고 생존율 떡상 |
| 길바닥에 이미 깔아둔 **옛날 DSRC 장비들은 어떡함?** | 정부가 10년 전부터 시범 사업한다고 DSRC를 도로에 너무 많이 깔아둠 | 당분간 RSU 장비에 칩 2개 다 박는 **듀얼 모드(Dual Mode) 꼼수 운영** | 매몰 비용 낭비 막고 자연스러운 세대 교체 달성 |
| C-V2X 칩 가격이 **와이파이(DSRC) 칩보다 오지게 비쌈** | 통신사 LTE/5G 모뎀 특허비랑 칩셋 단가가 자비가 없음 | **차량 인포테인먼트(5G 내비) 모뎀이랑 V2X를 원칩(SoC)으로 통합** | 부품 단가 후려치고 자동차 통신 모듈 보급률 떡상 |

#### 한줄 요약

- 뻗어버리는 DSRC는 버리고 C-V2X로 갈아타되, 옛날에 깔아둔 장비는 듀얼 모드로 짬 처리하고 원칩으로 단가를 깎아라.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- (상단 참조)

</details>

- WAVE(DSRC)의 고밀도 통신 패킷 충돌 한계와 확장성 문제를 극복하기 위해, 글로벌 무선 기술의 패권이 **CSMA/CA** 기반에서 **3GPP 스케줄링** 기반의 **C-V2X**로 완전 단일화되는 기조 확립함

#### 한줄 요약

- DSRC는 20년 동안 자율주행의 기틀을 닦았으나, 결국 시대의 흐름을 이기지 못하고 5G 기반의 C-V2X에게 왕좌를 물려주었다.
