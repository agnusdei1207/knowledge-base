## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **C-V2X(Cellular Vehicle-to-Everything)**: 3GPP 이동통신 표준 기반으로 차량 간(V2V), 차량-인프라 간(V2I), 차량-보행자 간(V2P) 직접 통신(PC5 사이드링크)과 기지국 네트워크 통신(Uu)을 모두 지원하는 차량 통신 기술.
- **단거리 전용 통신(DSRC / IEEE 802.11p WAVE)**: Wi-Fi(IEEE 802.11a) 기술을 차량 고속 이동 환경(5.9GHz 대역)에 맞게 개량하여 기지국 없이 차량과 노변 장치(RSU) 간 단거리 애드혹 통신을 수행하는 1세대 V2X 표준.

</details>

- 정의/개념: 자율주행 및 지능형 교통 체계(C-ITS) 구현을 위해 경쟁해 온 **3GPP 셀룰러 기반 C-V2X** 와 **IEEE 와이파이 기반 DSRC(WAVE)** 통신 표준
- 배경/필요성: 고밀도 도심 교차로 환경에서 패킷 충돌 없이 10ms 이하 저지연 신뢰성 통신을 보장하고, 단거리 안전 경고를 넘어 완전 자율주행(센서 공유, 군집주행)으로의 확장성을 확보할 요구

#### 한줄 요약
- 3GPP 셀룰러 기반 C-V2X와 IEEE Wi-Fi 기반 DSRC가 C-ITS 표준 주도권을 경합한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **반송파 감지 다중 접속(CSMA/CA)**: 무선 채널이 사용 중인지 감청(Listen-before-talk)한 후 유휴 상태일 때 난수 백오프를 거쳐 전송하는 경합형 매체 접속 제어 방식.
- **사이드링크 자원 스케줄링(Sidelink Resource Scheduling)**: C-V2X에서 기지국 제어 하에 자원을 할당(Mode 3/Mode 1)하거나 차량 자율 센싱 기반으로 충돌 확률이 가장 낮은 서브채널을 선택(Mode 4/Mode 2)하는 결정론적 스케줄링 방식.

</details>

- **DSRC의 경합 기반 단순성**: 기지국 인프라가 불필요하며 구조가 단순하지만, 차량 밀집도가 증가하면 **CSMA/CA 충돌 확률이 급증** 하여 패킷 전달률(PDR) 저하
- **C-V2X의 고밀도 신뢰성**: SC-FDMA/OFDMA 기반 자원 블록(RB) 분할 및 **자율 센싱 스케줄링(Mode 4)** 을 적용하여 고밀도 교차로에서도 안정적 전송 보장
- **통신 범위 및 서비스 확장성**: DSRC가 300m 이내 가시거리(LOS) 단거리에 국한되는 반면, C-V2X는 **PC5(직접 통신 1km)** 와 **Uu(기지국 광역망)** 를 결합하여 광역 교통 관제 연동 가능

#### 한줄 요약
- DSRC는 단순 경합 통신을, C-V2X는 결정론적 자원 스케줄링과 광역 셀룰러 연동을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **차량 탑재 단말(On-Board Unit, OBU)**: 차량 내부에 장착되어 센서 데이터를 수집하고 V2X 메시지(BSM/CAM/DENM)를 송수신하는 차량 통신 장치.
- **노변 기지국 장치(Roadside Unit, RSU)**: 교차로 신호등이나 도로변 인프라에 설치되어 신호 정보(SPaT)와 위험 정보를 브로드캐스트하는 V2X 통신 노드.

</details>

```text
[ C-V2X 통신 아키텍처 (이중 인터페이스) ]
 ┌──────────────────────┐   PC5 사이드링크 (직접 통신, 10ms 초저지연)   ┌──────────────────────┐
 │ 차량 OBU (C-V2X 모뎀)│ ◀────────────────────────────────────────▶ │ 주변 차량 / 노변 RSU │
 └──────────┬───────────┘                                               └──────────────────────┘
            │
            ▼ Uu 인터페이스 (LTE / 5G 기지국 광역망 통신)
 [ 5G gNB 기지국 ] ──▶ [ 5G 코어망 (5GC) / C-ITS 관제 센터 ]

[ DSRC / WAVE 아키텍처 (단일 애드혹 통신) ]
 ┌──────────────────────┐   IEEE 802.11p (CSMA/CA 단거리 애드혹 통신) ┌──────────────────────┐
 │ 차량 OBU (WAVE 모뎀) │ ◀────────────────────────────────────────▶ │ 주변 차량 / 노변 RSU │
 └──────────────────────┘                                               └──────────────────────┘
```

선의 의미: C-V2X는 직접 통신(PC5)과 광역 기지국 통신(Uu)을 이중 지원하며, DSRC는 순수 직접 애드혹 통신만을 지원하는 구조

| 비교 요소 | C-V2X (Cellular V2X) | DSRC / WAVE (802.11p) |
|:---|:---|:---|
| **물리/MAC 표준** | **3GPP Rel-14/15/16 (LTE-V2X, 5G-V2X)** | **IEEE 802.11p / IEEE 1609 (WAVE)** |
| **채널 다중화 방식** | **SC-FDMA / OFDMA 기반 스케줄링** | **OFDM 기반 CSMA/CA (경합 방식)** |
| **통신 인터페이스** | **PC5 (사이드링크 직접) + Uu (셀룰러 광역)** | **802.11p (단일 직접 통신 링크)** |
| **최대 통신 거리** | **최대 1,000 m (직접 통신 기준)** | **최대 300 m 이내** |
| **자원 할당 방식** | 자율 센싱 기반 준지속 스케줄링 (SPS, Mode 4) | 비인프라 난수 백오프 CSMA/CA |

#### 한줄 요약
- C-V2X는 PC5/Uu 이중 인터페이스와 OFDMA 스케줄링을, DSRC는 802.11p 단일 링크와 CSMA/CA를 채택한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **준지속 스케줄링(Semi-Persistent Scheduling, SPS)**: C-V2X Mode 4에서 각 차량이 주변 무선 채널의 신호 세기(RSSI)를 센싱하여 가장 비어있는 자원 블록을 선점하고 일정 주기 동안 반복 사용하는 자원 예약 기법.

</details>

```text
[ C-V2X Mode 4 자율 자원 할당 절차 ]
 1. 차량 OBU가 최근 1,000ms 동안의 서브채널 RSRP/RSSI를 지속 센싱
 2. 간섭이 적은 하위 20%의 최적 후보 자원 블록(Candidate RB) 선별
 3. 무작위 선택 후 SPS 예약 타이머 설정 ➔ 충돌 없는 주기적 BSM 안전 메시지 송출

[ DSRC 802.11p 매체 접근 절차 ]
 1. 차량 OBU가 채널 상태를 반송파 감지(Clear Channel Assessment)
 2. 채널 사용 중 시 DIFS 대기 및 무작위 백오프(Contention Window) 수행
 3. 타이머 만료 시 즉시 브로드캐스트 송출 (동시 송출 시 충돌 발생 및 재전송 불가)
```

**동작 원리**

1. **채널 상태 인지**: C-V2X는 센싱 기반 통계적 자원 예약을, DSRC는 순간적 캐리어 센싱을 수행
2. **트래픽 밀집 시 동작**: C-V2X는 예약된 타임-주파수 슬롯에서 패킷을 전송하여 충돌을 회피하나, DSRC는 동시 백오프 만료로 패킷 충돌 및 유실 발생
3. **진화 경로 연동**: C-V2X는 5G-NR V2X로 진화하여 센서 융합 데이터 공유를 지원

#### 한줄 요약
- C-V2X SPS 자원 예약과 DSRC CSMA/CA 백오프 절차를 거쳐 안전 메시지를 송수신한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **기본 안전 메시지(Basic Safety Message, BSM)**: 차량의 실시간 위치, 속도, 조향각, 가속도 정보를 100ms 주기로 주변에 브로드캐스트하는 핵심 V2X 페이로드.

</details>

| 비교 항목 | C-V2X (Cellular V2X) | DSRC / WAVE (IEEE 802.11p) |
|:---|:---|:---|
| **주관 표준화 기구** | **3GPP, 5GAA (통신·자동차 연합)** | **IEEE, ISO (전통 무선랜 진영)** |
| **고밀도 환경 성능** | **우수 (자원 예약 스케줄링으로 패킷 충돌 억제)** | **취약 (차량 증가 시 충돌 급증 및 PDR 급감)** |
| **최대 이동 속도** | **최대 250 ~ 500 km/h (고속 도플러 보정 지원)** | **최대 200 km/h 내외** |
| **차세대 진화 로드맵** | **5G-NR V2X, 6G-V2X (군집주행, 원격 제어)** | IEEE 802.11bd (표준 개발 지연 및 투자 축소) |
| **국가별 정책 채택** | **한국, 미국, 중국 단일 표준 공식 채택** | 초기 시범 사업 도입 후 C-V2X로 전환 추세 |

#### 한줄 요약
- C-V2X는 고밀도 안정성, 5G 진화성, 글로벌 표준 채택 면에서 DSRC 대비 기술적 우위를 확보했다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **이중 모드 RSU(Dual-Mode RSU)**: 기존에 구축된 DSRC 기반 노변 인프라와 신규 C-V2X 차량 단말을 동시에 수용하기 위해 양대 무선 트랜시버를 모두 탑재한 하이브리드 RSU.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 기존 기구축된 DSRC 기반 RSU 인프라와 신규 C-V2X 단말 간 비호환성 | **이중 모드(Dual-Mode RSU/OBU)** 장비 도입 및 단계적 마이그레이션 | 기존 인프라 매몰 비용 방지 및 원활한 표준 전환 |
| 5.9GHz V2X 전용 주파수 대역 내 비인가 무선랜(Wi-Fi 6E) 간섭 위협 | V2X 대역(5.850~5.925GHz) 전용 보호 대역 지정 및 **RF 대역통과 필터** 적용 | 인접 Wi-Fi 전파 간섭 차단 및 통신 신뢰성 확보 |
| C-V2X 모뎀 및 5G 텔레매틱스 모듈 분리 탑재 시 차량 원가 상승 | **5G 텔레매틱스 + C-V2X 통합 SoC(원칩) 솔루션** 적용 | 부품 단가 절감, 차량 내부 배선 간소화 및 보급 촉진 |

#### 한줄 요약
- Dual-Mode 장비로 인프라를 전환하고, RF 대역 필터로 간섭을 방지하며, 통합 SoC로 원가를 절감한다.

## Ⅶ. 결론

- 글로벌 자율주행 및 지능형 교통 체계(C-ITS) 표준은 고밀도 환경 신뢰성과 5G 진화성이 우수한 **3GPP C-V2X** 로 수렴 확정되었으므로, 기존 DSRC 인프라와의 연동을 위해 **이중 모드 RSU** 를 활용한 과도기 전환 전략을 추진하고, 향후 완전 자율주행(레벨 4/5)을 위해 **5G-NR V2X 기반 협력 주행 인프라** 를 조기 구축

#### 한줄 요약
- C-V2X 단일 표준 기조 하에 이중 모드 인프라를 거쳐 5G-NR 협력 자율주행망으로 진화한다.
