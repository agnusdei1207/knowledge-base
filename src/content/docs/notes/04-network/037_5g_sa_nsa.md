## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **NSA(비독립형, Non-Standalone)**: 머리(제어)와 심장(코어망)은 기존 LTE 장비에 얹혀살면서, 데이터 다운받을 때만 5G 안테나를 빌려 쓰는 꼼수 방식(반쪽짜리 5G)이다.
- **SA(독립형, Standalone)**: 뇌부터 심장, 손발까지 전부 다 5G 전용 장비(5GC)로 싹 갈아엎어서 독자 생존하는 '진짜 5G'다.
- **5GC(5G Core)**: 기존 4G의 낡은 장비를 버리고, 모든 걸 소프트웨어(클라우드)로 굴리는 5G 전용 최신 두뇌(코어망)다.

</details>

- 정의: 5G 망 구축을 할 때, 기존 LTE 두뇌(EPC)에 얹혀살 건지(**NSA**), 아니면 5G 전용 두뇌(**5GC**)를 새로 깔아서 완전히 독립할 건지(**SA**) 나누는 아키텍처 방식
- 배경: 처음엔 5G 망 전체를 깔려면 돈이 너무 많이 드니까 꼼수(NSA)로 속도만 올리다, 이제 슬라이싱 같은 진짜 5G 기술을 쓰려고 SA로 진화하는 중임

#### 한줄 요약

- LTE에 기생해서 폰 속도만 올리는 게 NSA(꼼수 5G)이고, 코어망부터 싹 갈아엎어 자율주행까지 돌리는 게 SA(진짜 5G)다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **EPC(Evolved Packet Core)**: 4G LTE 시대에 쓰던 심장(코어망). 튼튼하지만 너무 옛날 거라 5G의 1ms 극저지연 같은 묘기를 부리지 못한다.
- **VoNR(Voice over NR)**: LTE망 빌리지 않고 5G 망만으로 음성 통화를 깨끗하게 뽑아내는 '진짜 5G 통화'다.

</details>

- **NSA (EN-DC 이중 연결)**: 전화 걸거나 망에 접속하는 빡센 제어는 LTE 기지국이 담당하고, 유튜브 같은 무거운 데이터만 5G 기지국이 나눠서 짬 처리함.
- **SA (5GC 기반 완전 독립)**: 접속 제어부터 데이터 전송까지 싹 다 5G 전용망이 독식해서 처리. 간섭이나 딜레이 없이 완전한 5G 100% 성능이 나옴.
- **기능 제공 차별성**: 꼼수(NSA)는 단순히 스마트폰 속도만 올리지만, 찐(SA)은 코어망을 칼로 찢어버리는 슬라이싱이나 자율주행급 1ms 초저지연을 보장함.

#### 한줄 요약

- NSA는 LTE에 기생해서 데이터 속도 원툴로 가고, SA는 5G 전용 두뇌로 초저지연과 슬라이싱까지 다 씹어 먹는다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **EN-DC(E-UTRA NR Dual Connectivity)**: 폰 하나에 LTE 안테나랑 5G 안테나 두 개를 동시에 물려서 양쪽 데이터를 다 빨아먹는 이중 연결 스킬이다.

</details>

```text
[ 5G 망 직관적 비교 아키텍처 ]

[ NSA 꼼수 5G ]                       [ SA 찐 5G ]

(폰: EN-DC 듀얼)                       (폰: 단독 연결)
   │       │                              │
(LTE)    (5G 망)                        (5G 망)
   │       │                              │
   ▼       ▼                              ▼
[ LTE 코어 (EPC) ]                [ 5G 전용 코어 (5GC) ]
(머리)     (데이터만)             (슬라이싱, 초저지연 풀가동)
```

| 구성요소 | 직관적 비교 책임 | 비고 |
|:---|:---|:---|
| **이중 연결(EN-DC)** | 기지국 두 개(LTE+5G)에 **동시 접속해서 양쪽 데이터 다 빨아먹는 꼼수 기술** | NSA 전용 |
| **LTE 코어 (EPC)** | NSA 환경에서 접속 관리, 과금 등 **귀찮은 머리 쓰는 일 짬 처리하는 구형 코어** | 4G Core |
| **5G NR 기지국 (gNB)** | 폰에다가 진짜 5G 전파 쏴주는 최신 안테나 | RAN |
| **5G 전용 코어 (5GC)** | 슬라이싱, 클라우드 등 **진짜 5G의 모든 묘기를 부릴 수 있는 100% 소프트웨어 뇌** | 5G Core |

#### 한줄 요약

- NSA는 LTE 뇌(EPC)에 5G 팔다리만 하나 더 붙인 거고, SA는 뇌(5GC)부터 팔다리(NR)까지 싹 다 5G 전용으로 갈아치운 거다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- (상단 참조)

</details>

```text
[ 통신사 5G 구축 십자포화 흐름 ]

┌──────────────────────────────┐
│ 1. [구축 전략 체크]     │
│ (돈 아낄래? 찐 5G 할래?)     │
└──────────────┬───────────────┘
      ┌────────┴────────┐
(돈 아끼고 일단 론칭) (자율주행, 슬라이싱 풀가동)
      │                 │
      ▼                 ▼
┌────────────────┐┌──────────────────────────────┐
│ 2a. NSA 방식   ││ 2b. SA 방식                  │
│ (폰이 LTE 기지국││ (폰이 5G 기지국한테만 말 걺) │
│ 한테 제어 받음) ││ (5G 코어에서 슬라이싱 쫙 찢음)│
│ (데이터만 5G 씀)││ (완벽한 E2E 저지연 타임어택) │
└────────────────┘└──────────────────────────────┘
```

### 동작 원리

1. 방향 판정: 통신사가 LTE 자산을 울궈먹을지, 돈 붓고 찐 5G로 갈지 결정.
2. NSA: LTE한테 제어(컨트롤) 허락받고 5G로 데이터만 시원하게 다운.
3. SA: LTE 쌩까고 5G가 직접 단말 인증부터 초저지연, 슬라이싱 썰기까지 풀코스 뜀.

#### 한줄 요약

- 돈 덜 들이고 속도 올리려고 NSA로 간 보다가, 나중에 B2B 특화 서비스 하려고 SA로 넘어가는 흐름이다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **EPS Fallback**: SA(찐 5G) 폰으로 통화 걸었는데 음성(VoNR)이 아직 뻑나서 안 터지면, 재빨리 4G(VoLTE)망으로 런 쳐서 통화 끊기는 걸 막는 비상 탈출 꼼수다.

</details>

| 비교 항목 | **NSA (반쪽 5G)** | **SA (찐 5G)** |
|:---|:---|:---|
| 직관적 비교 목표 | 통신사 돈 아끼면서 **폰 체감 속도만 뻥튀기** 하기 | 코어망 싹 갈아엎고 **자율주행, 공장 로봇, 슬라이싱** 굴리기 |
| 뇌(Core) / 수족(RAN)| 뇌는 **구형(LTE EPC)** / 팔다리만 **최신(5G NR)** | 뇌(**5GC**)부터 팔다리(**5G NR**)까지 싹 다 최신 |
| 연결 방식 | 폰에 LTE랑 5G 안테나 **동시에 켜짐 (EN-DC)** | 폰에 5G만 쿨하게 단독으로 켜짐 |
| 5G 킬러 서비스 | 속도만 빠름 (eMBB 원툴) | **초저지연(URLLC), 네트워크 슬라이싱 완벽 지원** |
| 음성 통화 (Voice)| 기존 VoLTE 씀 | **VoNR (5G 음성)** 쓰거나 안 터지면 **LTE로 런침(EPS Fallback)** |

#### 한줄 요약

- 스마트폰 가입자 꼬실 땐 NSA로 꿀 빨고, 공장이나 기업망 뚫을 땐 SA로 찐 성능을 뽑아낸다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **과금 기록(CDR, Charging Data Record)**: 얘가 데이터를 얼마나 썼나 기록하는 통신사 영수증이다. NSA는 LTE랑 5G 양쪽에서 영수증이 날아와 꼬일 위험이 있다.

</details>

| 장애/위험 요소 | 원인 분석 | 실무 대책 및 해결방안 | 기대 효과 |
|:---|:---|:---|:---|
| 찐 5G(SA) 폰 개통했는데 **전화만 걸면 뚝뚝 끊기고 뻗음** | 초기 SA망은 음성 통화(VoNR) 커버리지가 개판임 | 통화 걸 때만 강제로 LTE망으로 런 치게 만듦 **(EPS Fallback)** | 통화 연속성 억지 보장 및 폰 먹통 방지 |
| NSA 폰 쓰는데 아무것도 안 해도 **배터리 광탈함** | LTE랑 5G 신호 두 개를 급격히 동시에 탐색함 (EN-DC) | 화면 끄거나 데이터 안 쓸 땐 **5G 연결 끊고 LTE만 물려놓음** | 폰 배터리 타임 극한의 방어 (최적화) |
| 데이터 요금 정산하는데 **청구서 영수증 다 꼬여버림** | NSA는 LTE(EPC)랑 5G 장비가 서로 다른 영수증(CDR) 찍어댐 | **과금 중계 시스템(CHF)** 넣어서 두 개 짬뽕된 영수증 체크함 | 통신사 요금 분쟁 및 정산 오차 컷 |

#### 한줄 요약

- SA 초기엔 통화 뻑나니까 LTE로 도망갈 구멍(EPS Fallback) 파놓고, NSA는 배터리 광탈 막으려고 대기 모드 튜닝을 빡세게 해라.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- (상단 참조)

</details>

- 초기 커버리지 뻥튀기는 **NSA**로 꿀 빨고, B2B 특화망(자율주행, 슬라이싱)을 위해서는 반드시 5GC 기반의 **SA**로 전환하며, 과도기 음성 뻑남은 **EPS Fallback**으로 방어하는 5G 진화 아키텍처 기조 확립함

#### 한줄 요약

- NSA는 5G 시대를 여는 '급행열차'였고, SA는 5G의 진짜 잠재력을 터뜨리는 '완성형 생태계'다.
