## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **WDM (파장 분할 다중화)**: 광케이블 한 가닥 안에 빨강, 파랑, 초록 등 색깔(파장)이 다른 레이저빔을 여러 개 쏴서, 도로를 안 넓히고도 차선을 늘리는 마법의 광통신 다중화 기술이다.
- **CWDM / DWDM**: CWDM은 색깔을 듬성듬성 나눠 쏘는 가성비 단거리 용이고, DWDM은 색깔을 무식하게 촘촘히 쪼개 쏴서 장거리 대용량을 뽑는 백본 코어 전용 기술이다.
- **Flex-Grid (유연 격자)**: 고속버스(400G 트래픽)가 들어오면 차선 2개를 터주고, 경차(10G)가 오면 반 개만 내주는 지능형 주파수 슬롯 가변 기술이다.

</details>

- 정의: **WDM**은 라우터에서 나온 데이터를 서로 다른 색깔(파장)의 빛으로 바꾼 뒤, 단일 광케이블 코어 하나에 몽땅 쑤셔 넣고 쏘는 광 백본 코어 네트워킹 기술이다. (밀도에 따라 CWDM, DWDM, Flex-Grid로 진화함)
- 배경: 유튜브, 넷플릭스 때문에 트래픽이 폭발하는데 전국에 광케이블을 새로 까려면 땅 파는 토목 공사비가 수조 원 깨지니까, **깔려 있는 선은 놔두고 빛깔만 쪼개서 용량을 뻥튀기하려고 빡세게 도입했다.**

#### 한줄 요약

- 단일 광섬유 안에 여러 색깔의 광파장을 욱여넣어, 광케이블 추가 굴착 없이 백본 용량을 마법처럼 늘리는 기술이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **인접 채널 간섭 (Adjacent Channel Interference)**: 촘촘한 DWDM에서 파랑 빔이랑 남색 빔을 너무 바짝 붙여 쏘면, 광케이블 안에서 색깔이 섞여 짬뽕(FWM 비선형 왜곡)이 돼버리는 무서운 현상이다.
- **OSNR (광 신호대잡음비)**: 빔이 날아갈 때 광증폭기(EDFA)가 빔을 강제로 키워주는데, 그때마다 빛 쓰레기(ASE 노이즈)가 껴서 신호가 얼마나 탁해졌는지 재는 마진 수치다.

</details>

- **선로 굴착 0원, 용량 무한 떡상**: 포크레인 불러서 땅을 파지 않고 양쪽 국사에 장비만 꽂아주면, 단일 광선로의 전송 용량이 10배, 100배로 떡상한다.
- **색깔 섞임 주의 (인접 채널 간섭)**: 100기가짜리 빛을 너무 촘촘하게 박아 넣으면(DWDM), 케이블 안에서 빛끼리 비비다가 색깔이 뭉개지는 비선형 왜곡(FWM)과 색분산이 터진다.
- **광증폭기 딜레마 (OSNR 하락)**: 전기 변환 없이 빛을 증폭(EDFA)시켜서 장거리를 쏘면 편하긴 한데, 증폭할 때마다 찌꺼기 잡음이 누적돼 나중엔 수신 OSNR이 쓰레기가 되는 임계 한계가 있다.

#### 한줄 요약

- 땅 파는 돈 아끼면서 용량은 늘리되, 빛깔 섞이는 비선형 간섭과 앰프 찌꺼기 노이즈(OSNR) 관리가 생명인 기술이다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **트랜스폰더 (Transponder)**: 맹탕인 일반 데이터를 받아서 WDM 규격에 맞는 '정밀 컬러 레이저빔'으로 변환해 주는 빔 발사기다.
- **EDFA (에르븀 첨가 광섬유 증폭기)**: 희토류(에르븀) 이온 특성을 이용해, 빛 신호를 전기로 바꾸는 뻘짓 없이 빛 상태 그대로 파워만 빵빵하게 튀겨주는 개사기 광 앰프다.
- **ROADM (재구성 광 분기결합기)**: 직원이 출장 가서 광점퍼코드를 뺐다 꼈다 안 해도, 중앙 통제실 마우스 클릭 딸깍으로 광주파수 길(경로)을 요리조리 바꿔주는 톨게이트 스위치 노드다.
- **OCM (광 채널 모니터)**: 날아가는 빛을 살짝 빼서 색깔이 섞였는지, 파워가 죽었는지 실시간으로 CCTV처럼 감시하는 장비다.

</details>

```text
[ WDM 광망 팩트 폭행 구조 ]

[ 1. OEO 트랜스폰더 ] ── (투명한 데이터에 색깔 입히고 컬러 빔으로 쏨)
      │
      ▼
[ 2. MUX 다중화기 ] ── (무지개색 빔 80개를 묶어 광케이블 한 가닥에 쑤셔 넣음)
      │
      ▼ (광케이블 타고 슝~)
[ 3. EDFA 광증폭기 ] ── (가다가 빛 약해지면 전기로 안 바꾸고 에르븀 뽕 맞혀 뻥튀기함)
      │
      ▼
[ 4. ROADM 스위치 노드 ] ── (WSS 톨게이트로 빨간색 빔은 서울, 파란색 빔은 부산으로 갈라줌)
```

| 구성요소 | 팩트 폭행 책임 | 비고 |
|:---|:---|:---|
| **OEO 트랜스폰더** | 투명한 일반 회선을 받아서 **규격 컬러(파장) 광선으로 염색해서 쏘는 놈** | Transponder |
| **MUX / DEMUX** | 색깔 다른 광선들을 **한 가닥에 뭉치고(MUX), 나중에 프리즘처럼 쪼개줌(DEMUX)** | Multiplexer |
| **EDFA 증폭기** | 전기 변환 뻘짓 없이 **빛 상태 그대로 에르븀 뽕 맞혀서 뻥튀기시킴** | Amplifier |
| **ROADM 톨게이트** | 원격 딸깍으로 **원하는 색깔만 쏙 빼고 새 색깔 얹어주는 스마트 스위치** | WSS Node |
| **OCM (모니터)** | 빛 흘러가는 거 몰래 빼보고 **에러 났는지 색깔 섞였는지 CCTV로 감시함** | Monitor |

#### 한줄 요약

- 트랜스폰더로 쏘고 $\to$ 뭉쳐서 광케이블 태우고 $\to$ EDFA로 뻥튀기하며 날아가다 $\to$ ROADM에서 목적지 찾아 스위칭한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **파장 연속성 (Wavelength Continuity)**: 서울에서 부산 갈 때 '빨간색 파장'을 탔으면, 대전이나 대구 중간 노드를 지날 때도 빨간색이 무조건 비어 있어야 직통으로 뚫어주는 개빡센 광 경로 제약 룰이다.
- **RWA 알고리즘**: 내비게이션처럼 "어떤 경로(라우팅)로 가서 무슨 색깔(파장)을 타야 빈자리가 있을까?" 계산해 주는 라우팅 대가리다.

</details>

```text
[ 광 경로(Lightpath) 개통 십자포화 흐름 ]

┌──────────────────────────────┐
│ 1. [경로 및 빈 슬롯(파장) 탐색]
│ (RWA: 서울 $\to$ 부산 가야 하는데 빨간색 파장 비어있냐?)
└──────────────┬───────────────┘
               ▼ (연속 파장 없으면 플렉스그리드로 재배치 꼼수 씀)
┌──────────────────────────────┐
│ 2. [광 자원 찜하기 (할당)]   │
│ (시스템: 오케이 빨간색 비었다. 내가 찜함!)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 3. [파장 발사 (트랜스폰더)]  │
│ (트랜스폰더: 100G 코히어런트 켜고 빨간색 빔 빵 쏜다!)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 4. [광 터널 길 뚫기 (ROADM)] │
│ (ROADM 스위치: WSS 톨게이트 열어서 빨간색 빔 무사 통과시켜 줌)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 5. [품질 팩트 체크 및 개통]  │
│ (OCM: 빔 도착했다. 잡음(OSNR) 없고 맑네. 개통 완료!)
└──────────────────────────────┘
```

### 동작 원리

1. 파장 탐색: RWA 알고리즘이 내비게이션을 돌려 **파장 연속성**을 깨지 않는 빈 파장(빈 차선)을 찾음.
2. 할당 및 찜하기: 충돌(경합)을 막기 위해 쓸 파장을 시스템에 시그널링해서 독점 예약함.
3. 컬러 빔 송출: 트랜스폰더가 Coherent 100G 변조기를 돌려 정밀하게 지정된 파장을 발사함.
4. ROADM 터널 세팅: 노드 스위치(WSS)를 셋업해서 빛이 막히지 않고 쭉 뚫고 나가는 물리적 터널(Lightpath) 구성.
5. OSNR 검증: OCM이 수신 측에 도착한 빔의 찌꺼기(OSNR 마진)를 재보고 통과면 바로 서비스 개통함.

#### 한줄 요약

- RWA로 빈 파장 찾고 $\to$ 트랜스폰더로 쏘고 $\to$ ROADM이 길 뚫어주고 $\to$ OCM이 잡음 확인 후 개통하는 흐름이다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **스펙트럼 단편화 (Spectrum Fragmentation)**: Flex-Grid 쓰다 보면 트래픽을 뺐다 꼈다 하면서 주파수 여기저기에 테트리스 빵꾸난 것처럼 쪼가리 빈 공간이 남아서 대용량을 못 꽂는 빡치는 상황이다.

</details>

| 비교 항목 | **CWDM (가성비 단거리망)** | **DWDM (촘촘한 전국망)** | **Flex-Grid (가변 고무줄망)** |
|:---|:---|:---|:---|
| 팩트 폭행 비유 | 파장 간격 널널해서 싼 **마을버스** | 빽빽하게 꽉꽉 채운 **광속 KTX** | 손님 덩치에 맞게 좌석 터주는 **우주선** |
| 채널 간격 (도로 폭) | 20 nm (개넓음. 대충 쏴도 됨) | 0.8 nm / 0.4 nm (오차 나면 섞여서 뒤짐) | **12.5 GHz 단위**로 슬롯 넣었다 뺐다 함 |
| 광 증폭기 (EDFA) | 간격 넓어서 **증폭기 잘 안 먹힘** | C/L 대역 딱 맞아서 **EDFA 증폭 찰떡임** | 광 대역폭 자체를 넓혀서 연동함 |
| 장비 가격 및 용도 | 싸구려 부품 씀. **단거리 메트로망** | 비싼 정밀 레이저 씀. **전국 백본망** | 테트리스 빡셈. **400G 이상 코어 전송망** |
| 치명적 한계 | 용량 확장 좆망, 장거리 증폭 불가 | 400G 대용량 못 넣고 대역 효율 개판 남 | **스펙트럼 단편화** 터져서 쪼가리 관리 빡셈 |

#### 한줄 요약

- 단거리엔 가성비 CWDM, 전국망 백본엔 무조건 DWDM, 400G 이상 초거대 트래픽엔 고무줄 12.5G Flex-Grid를 쓴다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **색분산 (Chromatic Dispersion)**: 무지개빛이 프리즘 통과할 때 색깔별로 속도가 달라서 빔이 퍼지듯이, 100Gbps로 쏘면 빛 알갱이들 도착 시간이 미세하게 틀어져서 파형이 뭉개지는 대참사다.

</details>

| 장애/위험 요소 | 원인 분석 | 실무 대책 및 해결방안 | 기대 효과 |
|:---|:---|:---|:---|
| 중간 국사에서 파장이 차서 **직통 개통 거부 당함 (연속성 붕괴)** | 서울~부산 갈 때 전 구간을 똑같은 색깔만 타야 하는 '파장 연속성' 제약 때문 | ROADM 중간 노드에 **파장 변환기(Wavelength Converter) 꽂아서 환승시켜 줌** | 파장 충돌(경합) 뚫어버리고 광 경로 개통률 떡상 |
| EDFA 앰프 10번 거쳤더니 **빛이 찌꺼기에 쩔어서 에러 남** | 증폭할 때마다 찌꺼기 잡음(ASE)이 누적돼서 나중엔 OSNR이 쓰레기 수준 됨 | 코히어런트 수신기로 복원력 올리고, 노이즈 덜 낀 **라만(Raman) 하이브리드 증폭기 씀** | 노이즈 뚫고 무재생으로 대륙 횡단 장거리 전송 |
| Flex-Grid 썼더니 **테트리스 빵꾸 나서(단편화) 400G 못 꽂음** | 자잘한 트래픽 뺐다 꼈다 하면서 주파수 대역 사이에 찌꺼기 빈 공간이 낭비됨 | 쪼가리 공간 모아주는 **Defragmentation(디프래그) 알고리즘 돌려서 슬롯 싹 재배치함** | 낭비되는 주파수 쪼가리들 모아서 대용량 채널 뚫어줌 |
| 100G 쐈더니 **빛이 퍼지고 찌그러짐 (색분산/비선형 왜곡)** | 속도가 빠르면 파장별로 도착 속도가 달라지고, 좁은 데서 빔끼리 비비면서 찌그러짐 | 멍청한 보상 케이블 빼다 버리고, **코히어런트 DSP 칩(디지털 신호 처리)으로 수학적 멱살 잡음** | 찌그러진 빛 파형을 DSP 연산으로 펴서 초고속 보장 |

#### 한줄 요약

- 파장 충돌 나면 변환기로 환승시키고, 색분산 나서 빛 찌그러지면 DSP 칩 수학 연산으로 빳빳하게 펴라.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- (상단 참조)

</details>

- 토목 공사(광섬유 포설) 없이 폭발하는 백본 트래픽을 감당하기 위해, **OEO 파장 변환**과 전기 변환 없는 **EDFA 증폭**, 클릭 한 번에 톨게이트 여는 **ROADM 스위칭**을 결합한 초광대역 코어 DWDM 기조 확립함

#### 한줄 요약

- WDM 기술은 거대한 광케이블 하나를 무한대의 무지개 차선으로 쪼개서 통신망의 토목 공사비를 아껴주는 1등 공신이다.
