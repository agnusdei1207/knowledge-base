## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **사이버 위협 인텔리전스(Cyber Threat Intelligence, CTI)**: 공격자•기법•대상•흔적을 근거와 맥락으로 분석해 방어 판단에 쓰는 정보이다.
- **구조화된 위협 정보 표현(Structured Threat Information eXpression, STIX)**: 위협 개체와 관계를 기계가 읽을 수 있게 표현하는 표준 자료 모델이다.
- **신뢰 가능한 위협 정보 자동 교환(Trusted Automated eXchange of Intelligence Information, TAXII)**: STIX 자료를 조직과 도구 사이에서 조회•게시하는 표준 전송 규약이다.
- **CTI 표준 체계**: 위협 정보의 개체•관계를 표준 형식으로 표현하고 권한에 따라 자동 교환하는 체계이다.
- **비정형 위협 정보 자동 연계 한계**: 문서마다 다른 형식과 용어 때문에 보안 도구가 위협 정보를 자동 해석•집행하지 못하는 문제이다.

</details>

- 정의/개념: **CTI**를 STIX로 표현하고 TAXII로 교환하는 **CTI 표준 체계**이다.
- 배경/필요성: 비정형 문서에는 **비정형 위협 정보 자동 연계 한계**가 있다.

#### 한줄 요약

- STIX가 공격 정보의 공통 양식과 관계를 정하고 TAXII가 그 정보를 조직과 보안 도구 사이에 배달한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **위협 지표(Indicator)**: 악성 주소•파일값처럼 특정 공격 활동을 탐지할 수 있는 조건과 유효 기간을 가진 정보이다.
- **관측 자료(Observed Data)**: 네트워크나 시스템에서 실제로 발견한 주소•파일•행위와 관측 시각을 기록한 사실이다.
- **신뢰도•유효 기간**: 정보 출처를 믿을 정도와 탐지•차단에 사용할 수 있는 기간이다.
- **트래픽 라이트 프로토콜(Traffic Light Protocol, TLP)**: 위협 정보의 재공유 범위를 색상 등급으로 표시하는 규약이다.
- **STIX 객체•관계**: 공격자•공격 기법•위협 지표•관측 자료를 개체와 연결 관계로 표현한 정보 구조이다.
- **TAXII 컬렉션**: 접근 권한과 공유 목적에 따라 STIX 객체를 묶어 게시•조회하는 저장 단위이다.
- **집행 통제**: 위협 정보의 신뢰도•유효 기간•공유 범위를 확인해 탐지와 차단 적용 여부를 결정하는 통제이다.

</details>

- **STIX 객체•관계**: 공격자•기법•**위협 지표**•**관측 자료**의 위협 맥락을 표현한다.
- **TAXII 컬렉션**: 조직•도구 간 위협 정보 자동 교환한다.
- **집행 통제**: **신뢰도•유효 기간**과 **TLP**를 기준으로 적용한다.

#### 한줄 요약

- 악성 주소 하나만 보내지 않고 왜 위험한지와 언제까지 누구에게 쓸 수 있는지를 함께 전달해야 한다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **STIX 객체 저장소**: 위협 개체•관계•공유 표시를 보존하는 저장소이다.
- **위협 검증•보강기**: 출처•신뢰도•수명•관계를 확인하고 위협 맥락을 추가하는 구성요소이다.
- **TAXII 교환 서버**: 컬렉션별 조회•게시•접근 권한을 제공하는 서버이다.
- **보안 도구 소비자**: STIX 객체를 내부 탐지•차단 형식으로 변환하는 도구이다.
- **품질 환류기**: 소비자의 적중•오탐 결과를 객체 갱신•폐기에 반영하는 구성요소이다.

</details>

```text
CTI 교환 구조
├─ 위협 검증•보강기
├─ STIX 객체 저장소
├─ TAXII 교환 서버
├─ 보안 도구 소비자
└─ 품질 환류기
```

선의 의미: 가로선은 검증•보강 기능, STIX 객체 저장소, TAXII 교환 서버와 보안 도구 소비자의 정적 정보 연계이고, 아래 가지는 소비자의 적중•오탐 결과를 검증•보강 기준에 연결하는 품질 환류 관계를 뜻한다.

| 구성요소 | 책임 |
|:---|:---|
| 위협 검증•보강기 | **위협 검증•보강기**가 출처•신뢰도•수명•관계 확인 |
| STIX 객체 저장소 | **STIX 객체 저장소**가 개체•관계•공유 표시 보존 |
| TAXII 교환 서버 | **TAXII 교환 서버**가 컬렉션별 조회•게시•권한 제공 |
| 보안 도구 소비자 | **보안 도구 소비자**가 내부 형식 변환•탐지•차단 |
| 품질 환류기 | **품질 환류기**가 적중•오탐 기반 갱신•폐기 |

> 요약: 검증된 STIX를 TAXII로 배포•회수가 핵심이다.

#### 한줄 요약

- 여러 출처의 위협을 검증해 STIX로 저장하고 TAXII가 권한별로 나눠 주면 보안 도구의 결과가 다시 품질 개선에 쓰인다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **증분 동기화**: 마지막 수신 뒤 추가•변경된 객체만 교환하는 방식이다.
- **스키마 검증•매핑**: 표준 객체를 내부 형식으로 정확히 변환했는지 확인하는 절차이다.
- **위협 검증•보강**: 출처•신뢰도•수명•관계를 확인하고 맥락을 추가하는 처리이다.
- **위협 근거 전달**: 출처•시각•관측 사실을 위협 정보 생산자에게 제공하는 단계이다.
- **STIX 객체 등록**: 지표•기법•공격자 맥락을 STIX 개체와 관계로 저장하는 단계이다.
- **컬렉션 객체 제공**: TLP와 조직 범위에 맞는 객체를 TAXII 컬렉션으로 게시하는 단계이다.
- **증분 객체 요청**: 마지막 수신 뒤 추가•변경된 객체만 조회하는 단계이다.
- **품질 결과 환류**: 적중•오탐•만료 결과로 객체의 신뢰도를 갱신하거나 폐기하는 단계이다.

</details>

```text
반복 범위: 위협 정보 갱신 주기마다 1~5단계

1. 위협 근거 전달
      │
      ▼
2. STIX 객체 등록
      │
      ▼
3. 컬렉션 객체 제공
      │
      ▼
4. 증분 객체 요청
      │
      ▼
변경 객체 검증•집행
      │
      ▼
5. 품질 결과 환류
      ├─ 적중: 신뢰도 갱신
      └─ 오탐•만료: 객체 폐기•회수
```

### 동작 원리

1. **위협 근거 전달**: **위협 검증•보강**을 거친 출처•시각•관측 사실을 **위협 근거 전달**로 제공한다.
2. **STIX 객체 등록**: 지표•기법•공격자 맥락을 연결해 **STIX 객체 등록**을 수행한다.
3. **컬렉션 객체 제공**: TLP와 조직 범위로 제한한 **컬렉션 객체 제공**을 수행한다.
4. **증분 객체 요청**: **증분 동기화**로 변경분만 **증분 객체 요청**한다.
5. **품질 결과 환류**: **스키마 검증•매핑** 결과와 적중•오탐•만료를 **품질 결과 환류**에 반영한다.
> 요약: 검증•구조화•배포•집행•회수의 순환이 핵심이다.

#### 한줄 요약

- 출처를 확인한 위협을 공통 양식으로 만들고 권한 있는 도구에 새 내용만 보내며 잘못되거나 낡으면 빠르게 거둔다.

## Ⅴ. 종류 및 비교

| 표준 | 역할 | 연계 결과 |
|:---|:---|:---|
| **STIX** | 위협 객체•관계•수명 표현 | 도구가 해석할 공통 위협 정보 데이터 생성 |
| **TAXII** | 컬렉션 기반 조회•게시 | 권한이 적용된 STIX 객체 전송 |

> 요약: STIX로 위협 정보를 표현하고 TAXII로 권한에 맞게 교환이 핵심이다.

#### 한줄 요약

- 공격 정보를 어떤 항목과 관계로 쓸지는 STIX, 그 묶음을 어디에 누구에게 전달할지는 TAXII가 맡는다.

## Ⅵ. 실무 고려사항 및 대책

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 오래된 지표의 오차단 | **신뢰도•유효 기간** 기반 자동 만료 | 불필요한 차단 감소 |
| 공유 범위 초과 | **TLP**와 **TAXII 컬렉션**별 권한 통제 | 정보 유출 방지 |
| 내부 형식 변환 손실 | **스키마 검증•매핑** 시험 | 탐지 의미 보존 |

#### 한줄 요약

- 지표의 수명과 공유 권한을 통제하고 변환 결과를 검증해야 자동 배포로 인한 오차단을 줄일 수 있다.

## Ⅶ. 결론

<details><summary>핵심 용어</summary>

- **구조화 정보 표준화 기구(Organization for the Advancement of Structured Information Standards, OASIS)**: 정보 교환 표준을 개발하는 국제 비영리 기구이다.
- **OASIS STIX 2.1**: STIX 위협 개체와 관계를 규정한 표준이다.
- **OASIS TAXII 2.1**: TAXII 컬렉션 교환 인터페이스를 규정한 표준이다.
- **STIX•TAXII 역할 구분**: 위협 의미와 관계는 STIX, 권한별 전송은 TAXII에 배정하는 표준 적용 판단이다.

</details>

- **OASIS**의 **OASIS STIX 2.1**로 위협 의미를 표현하고 **OASIS TAXII 2.1**로 권한별 교환을 수행하는 **STIX•TAXII 역할 구분**과 만료•오탐의 즉시 회수가 핵심이다.

#### 한줄 요약

- 위협 정보는 많이 자동 배포하는 것보다 근거와 유효 기간을 확인해 필요한 방어에 쓰고 틀리면 즉시 회수해야 한다.
