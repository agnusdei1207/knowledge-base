## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **시간 민감 네트워킹(Time-Sensitive Networking, TSN)**: IEEE 802 이더넷에 시간 동기•트래픽 조정•신뢰성 기능을 적용해 지연 상한을 보장하는 결정형 네트워크 표준군이다.
- **전기전자공학자협회 802(Institute of Electrical and Electronics Engineers 802, IEEE 802)**: 근거리•도시권 네트워크의 물리•데이터링크 기술을 규정하는 표준 계열이다.

</details>

- 정의/개념: **TSN**은 **IEEE 802** 이더넷에 시간 동기•트래픽 조정•신뢰성을 적용한 결정형 네트워크 표준군이다.
- 배경/필요성: 최선형 이더넷은 혼잡 시 제어 트래픽의 지연 상한을 보장할 수 없다.

#### 한줄 요약

- 중요한 제어 메시지가 일반 데이터에 밀리지 않도록 스위치들이 공통 시각 동기와 GCL로 전송 순서를 지킨다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **결정형 네트워크**: 정해진 조건에서 패킷의 최악 도착 시간을 계산하고 제한할 수 있는 네트워크이다.
- **전기전자공학자협회 802.1AS(Institute of Electrical and Electronics Engineers 802.1AS, IEEE 802.1AS)**: TSN 참여 장비의 시각과 주파수를 공통 기준에 맞추는 시간 동기 표준이다.
- **게이트 제어 목록(Gate Control List, GCL)**: 큐별 전송 게이트의 개폐 시각을 정의한 시간표이다.
- **중앙 네트워크 구성기(Centralized Network Configuration, CNC)**: 스트림 경로•대역폭•GCL을 계산하는 중앙 기능이다.

</details>

- **결정형 네트워크**는 예약 조건으로 최악 도착 시간을 계산한다.
- **IEEE 802.1AS**의 공통 시각으로 **GCL** 실행을 정렬한다.
- **CNC**는 스트림 요구와 토폴로지로 경로•GCL을 계산한다.

#### 한줄 요약

- 한 장비만 시간을 지켜서는 부족하고 송신자부터 모든 스위치와 수신자까지 같은 규칙을 실행해야 한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **스트림**: 송신자에서 수신자까지 동일한 주기•지연•손실 요구로 전달되는 연속 프레임 흐름이다.
- **TSN 브리지(TSN Bridge)**: 결정형 큐•게이트•선점 제어를 실행하는 스위치이다.

</details>

- **스트림**은 같은 주기•지연•손실 요구를 가지며 **TSN 브리지**가 큐•게이트•선점 정책으로 전달한다.

```text
TSN
├─ 스트림 경로
│  ├─ 송신자
│  ├─ TSN 브리지
│  └─ 수신자
├─ 시간 동기 도메인
└─ CNC
```

선의 의미: 송신자•TSN 브리지•수신자는 하나의 스트림 경로 관계이고 공통 시간 동기 도메인을 공유하며, CNC는 TSN 브리지의 경로•대역폭•GCL 구성 관계이다.

| 구성요소 | 책임 |
|:---|:---|
| 송신자 | 주기•크기 기반 스트림 생성 |
| TSN 브리지 | 큐•게이트•선점 전송 통제 |
| 수신자 | 스트림 지연•손실 확인 |
| 시간 동기 도메인 | 모든 장비의 공통 시각 제공 |
| CNC | 경로•대역폭•GCL 계산•배포 |

#### 한줄 요약

- CNC가 계산한 GCL을 공통 시각 동기에 맞춰 브리지들이 실행해 스트림을 지연 상한 안에 전달한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **수용 제어**: 새 스트림을 추가해도 기존 스트림의 지연•대역 요구를 지킬 수 있는지 판정하는 기능이다.
- **스트림 요구 등록**: 새 흐름의 주기•크기•지연•손실 한계를 구성기에 전달하는 단계이다.
- **경로 기능 확인**: 후보 경로 장비의 시간 동기•트래픽 조정•선점 지원을 검사하는 단계이다.
- **경로•GCL 배포**: 수용된 스트림의 경로•대역폭•게이트 시각을 브리지에 설정하는 단계이다.
- **예약 스트림 전송**: 공통 시각과 큐 정책에 따라 예약 프레임을 목적지로 보내는 단계이다.
- **종단 성능 검증**: 혼잡•장애 조건에서 실제 지연과 손실이 요구 한계를 지키는지 확인하는 단계이다.

</details>

```text
1. 스트림 요구 등록
      │
      ▼
2. 경로 기능 확인
      │
      ▼
수용 가능 여부
      ├─ 불가: 요청 거절•대체 경로 탐색
      └─ 가능
          │
          ▼
3. 경로•GCL 배포
          │
          ▼
4. 예약 스트림 전송
          │
          ▼
5. 종단 성능 검증
          ├─ 마감 위반: 스케줄 재계산
          └─ 마감 충족: 운영 유지
```

### 동작 원리

1. **스트림 요구 등록**: **스트림 요구 등록** 단계에서 주기•크기•지연•손실 한계를 전달한다.
2. **경로 기능 확인**: **경로 기능 확인** 단계에서 장비별 동기•조정•선점 지원을 검사한다.
3. **경로•GCL 배포**: **경로•GCL 배포** 전에 **수용 제어**를 통과한 대역폭과 게이트 시각을 설정한다.
4. **예약 스트림 전송**: **예약 스트림 전송** 단계에서 공통 시각과 큐 정책으로 전달한다.
5. **종단 성능 검증**: **종단 성능 검증** 단계에서 혼잡•장애 조건의 지연 상한을 확인한다.

#### 한줄 요약

- 메시지의 주기와 마감시간을 등록하면 CNC가 경로의 전송 시간을 정하고 최악 조건에서도 지키는지 확인한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **시간 인식 조정기(Time-Aware Shaper, TAS)**: 공통 시간표로 큐 게이트를 제어하는 방식이다.
- **비동기 트래픽 조정기(Asynchronous Traffic Shaper, ATS)**: 시간 동기 없이 흐름별 전송률을 조정하는 방식이다.
- **프레임 선점**: 긴 일반 프레임을 일시 중단하고 긴급 프레임을 먼저 전송해 차단 시간을 줄이는 기능이다.
- **전기전자공학자협회 802.1Qbv(Institute of Electrical and Electronics Engineers 802.1Qbv, IEEE 802.1Qbv)**: 시간 인식 조정기의 게이트 제어를 규정하는 표준이다.

</details>

| TSN 트래픽 제어 | 시간 인식 조정 | 비동기 트래픽 조정 | 프레임 선점 |
|:---|:---|:---|:---|
| 적용 기준 | **TAS**는 고정 주기•마감 예약 트래픽 | **ATS**는 비주기 버스트 트래픽 | **프레임 선점**은 긴 프레임의 차단 시간 축소 |
| 핵심 특징 | **IEEE 802.1Qbv**의 GCL 개폐 | 흐름별 비동기 전송 조정 | 일반 프레임 일시 중단 |
| 한계 | 시계 오차•스케줄 충돌 | 매개변수별 지연 누적 | 양단 지원•분할 오버헤드 |

#### 한줄 요약

- 주기 제어는 TAS의 GCL, 갑작스러운 밀집은 비동기 트래픽 조정, 긴 일반 프레임이 막을 때는 선점을 사용한다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **동기 오차 예산•가드 밴드**: 허용 시계 편차의 장비별 배분과 예약 게이트 전 보호 시간을 묶은 설계 기준이다.
- **프레임 복제 및 중복 제거(Frame Replication and Elimination for Reliability, FRER)**: 서로 다른 경로로 프레임을 복제하고 수신부에서 중복을 제거해 재전송 없이 신뢰성을 높이는 기능이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 시계 편차의 게이트 오정렬 | **동기 오차 예산•가드 밴드** 적용 | 충돌과 마감 위반 감소 |
| 동시 스트림의 GCL 충돌 | 종단 스케줄 분석과 **수용 제어** | 최악 지연의 사전 보장 |
| 경로 장애의 결정성 상실 | 이중 경로와 **FRER** 적용 | 무재전송 복구와 저손실 |

#### 한줄 요약

- 공장 로봇 제어는 모든 경로의 시계 오차와 큐 점유를 계산해 전용 게이트가 열리는 시간을 예약한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **마감시간**: 스트림 프레임이 목적지에 도착해야 하는 최종 시각으로 트래픽 조정 방식 선택의 기준이다.

</details>

- **마감시간**을 기준으로 고정 주기 흐름은 **TAS**, 비주기 버스트는 **ATS**, 차단 축소는 **프레임 선점**이 핵심이다.

#### 한줄 요약

- 평균 속도보다 최악 지연 원인을 먼저 찾고 TAS•비동기 조정•선점을 필요한 구간에 조합한다.
