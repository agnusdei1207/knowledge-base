## 미리 알고가기

- **시간 민감 네트워킹(Time-Sensitive Networking, TSN)**: IEEE 802 이더넷에 시간 동기·트래픽 조정·신뢰성을 더해 지연 상한을 제공하는 표준군
- **결정형 네트워크(Deterministic Network)**: 정해진 조건에서 패킷의 최악 도착 시간을 계산하고 제한할 수 있는 네트워크
- **스트림(Stream)**: 송신자에서 수신자까지 동일한 서비스 요구로 전달되는 연속 프레임 흐름
- **시간 동기(Timing and Synchronization)**: 참여 장비의 시계를 공통 기준에 맞춰 같은 전송 시간표를 실행하는 기능
- **시간 인식 조정기(Time-Aware Shaper, TAS)**: IEEE 802.1Qbv 시간표로 큐 게이트를 열고 닫는 트래픽 조정기
- **비동기 트래픽 조정기(Asynchronous Traffic Shaper, ATS)**: IEEE 802.1Qcr 방식으로 시간 동기 없이 흐름별 전송을 조정하는 기능
- **프레임 선점(Frame Preemption)**: 긴 일반 프레임을 중단하고 긴급 프레임을 먼저 전송해 차단 시간을 줄이는 기능
- **중앙 집중형 네트워크 구성(Centralized Network Configuration, CNC)**: 스트림 요구와 토폴로지로 경로·대역폭·스케줄을 계산하는 구성 기능
- **프레임 복제 및 제거(Frame Replication and Elimination for Reliability, FRER)**: 중복 경로 프레임을 복제하고 수신부에서 중복을 제거하는 신뢰성 기능
- **게이트 제어 목록(Gate Control List, GCL)**: 큐별 전송 게이트의 개폐 시각을 정의한 주기 시간표
- **IEEE 802 TSN 표준군**: 결정적 이더넷을 위한 시간 동기·트래픽 조정·신뢰성 표준 집합

## Ⅰ. 개요

- 정의: **IEEE 802 TSN** 기반 **결정적 이더넷 표준군**
- 필요성: 제어·일반 트래픽의 **결정적 통합 수용**

### 쉽게 이해하기 (학습용)

- 중요한 제어 메시지가 일반 데이터에 밀리지 않도록 스위치들이 같은 시계와 시간표로 전송 순서를 지킨다.

## Ⅱ. 특징

- 예약 조건 기반 **최악 지연 상한** 산정
- 표준 이더넷의 **실시간·일반 트래픽 통합**
- **IEEE 802.1AS**의 **종단 시간 동기** 요구

### 쉽게 이해하기 (학습용)

- 한 장비만 시간을 지켜서는 부족하고 송신자부터 모든 스위치와 수신자까지 같은 규칙을 실행해야 한다.

## Ⅲ. 구조 및 구성요소

```mermaid
block-beta
    columns 1
    TALKER["송신자"]
    BRIDGE["TSN 브리지"]
    LISTENER["수신자"]
    TIME["시간 동기 도메인"]
    CNC["CNC"]
```

| 구성요소 | 책임 |
|:---|:---|
| **송신자** | 주기·크기 요구에 맞춘 스트림 생성 |
| **TSN 브리지** | 큐·게이트·선점으로 전송 통제 |
| **수신자** | 스트림 수신과 지연·손실 확인 |
| **시간 동기 도메인** | 모든 장비에 공통 시각 제공 |
| **CNC** | 경로·대역폭·GCL 계산·배포 |

### 쉽게 이해하기 (학습용)

- CNC가 계산한 시간표를 공통 시계에 맞춘 브리지들이 실행해 스트림을 약속된 시간 안에 전달한다.

## Ⅳ. 흐름도

```mermaid
sequenceDiagram
    participant T as 송신자
    participant C as CNC
    participant B as TSN 브리지
    participant L as 수신자
    T->>C: 1. 스트림 요구 등록
    C->>B: 2. 경로 기능 확인
    B-->>C: 동기·큐·대역폭 상태
    C->>B: 3. 경로·GCL 배포
    T->>L: 4. 예약 스트림 전송
    L-->>C: 5. 종단 성능 검증
```

1. **스트림 요구 등록**: 주기·크기·지연·손실 한계 전달
2. **경로 기능 확인**: 장비별 동기·조정·선점 지원 검사
3. **경로·GCL 배포**: 대역폭과 게이트 시각을 일괄 설정
4. **예약 스트림 전송**: 공통 시각과 큐 정책으로 전달
5. **종단 성능 검증**: 혼잡·장애 조건의 지연 상한 확인

### 쉽게 이해하기 (학습용)

- 메시지의 주기와 마감시간을 등록하면 CNC가 경로의 전송 시간을 정하고 최악 조건에서도 지키는지 확인한다.

## Ⅴ. 종류 및 비교

| TSN 트래픽 제어 | 시간 인식 조정 | 비동기 트래픽 조정 | 프레임 선점 |
|:---|:---|:---|:---|
| 적용 기준 | 고정 주기·마감의 **예약 트래픽** | 비주기 **버스트 트래픽** | 긴 프레임의 **차단 시간** 축소 |
| 핵심 특징 | **IEEE 802.1Qbv** **GCL 개폐** | 흐름별 **비동기 전송 조정** | 일반 프레임의 **일시 중단** |
| 한계 | 시계 오차·**스케줄 충돌** | 매개변수별 **지연 누적** | 양단 지원·**분할 오버헤드** |

### 쉽게 이해하기 (학습용)

- 주기 제어는 시간표, 갑작스러운 밀집은 비동기 조정, 긴 일반 프레임이 막을 때는 선점을 사용한다.

## Ⅵ. 실무 고려사항 및 대책

| 고려사항 | 대책 | 효과 |
|:---|:---|:---|
| 시계 편차의 **게이트 오정렬** | 동기 오차 예산과 **가드 밴드** 적용 | 충돌과 **마감 위반 감소** |
| 동시 스트림의 **GCL 충돌** | 종단 스케줄 분석과 **수용 제어** | 최악 지연의 **사전 보장** |
| 경로 장애의 **결정성 상실** | 이중 경로와 **FRER** 적용 | 무재전송 복구와 **저손실** |

### 쉽게 이해하기 (학습용)

- 공장 로봇 제어는 모든 경로의 시계 오차와 큐 점유를 계산해 전용 게이트가 열리는 시간을 예약한다.

## Ⅶ. 결론

- **주기성·버스트·차단 시간**으로 TSN 기능 조합

### 쉽게 이해하기 (학습용)

- 평균 속도보다 최악 지연 원인을 먼저 찾고 시간표·비동기 조정·선점을 필요한 구간에 조합한다.
