## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **DDoS 방어 체계 (Distributed Denial-of-Service Mitigation)**: 수십만 대의 좀비 PC(봇넷)가 인터넷 회선이나 서버 메모리를 꽉 채워서 마비시키는 공격(DDoS)을 앞단에서 몸빵으로 흡수하고 쓰레기 트래픽만 걸러내는(정화) 최전방 방어 시스템이다.

</details>

- 정의: **DDoS 방어 체계**는 다수의 공격자가 대량의 트래픽을 쏴서 회선, 세션, 응용 자원을 고갈시키는 공격을 앞단에서 탐지•흡수•정화해 찐 고객들이 접속할 수 있게 서비스 가용성을 유지하는 철저한 방어선이다.
- 배경: 내 서버 앞마당(방화벽)에서 아무리 컷트해 봐야 이미 건물로 들어오는 통신 회선(파이프)이 꽉 차버리면 인터넷 자체가 끊기니까, **우리 회사까지 오기 전의 상위망에서 먼저 공격을 걸러내야만 살 수 있었다.**

#### 한줄 요약

- 덤프트럭 수천 대가 우리 가게 앞 도로를 꽉 막는 공격을, 고속도로 입구에서 검문해서 찐 고객만 보내주는 방어 체계다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **다단 완화 (Multi-Layer Mitigation)**: 공격을 내 방화벽 한 군데서 막다가 터지지 않게, 통신사(ISP) 입구 $\to$ CDN 엣지 $\to$ 사내 방화벽 순으로 여러 단계에 걸쳐 트래픽을 깎아내는 방어 전술이다.
- **오탐 (False Positive)**: 쫄아서 방어 룰을 너무 빡세게 걸면, 진짜로 물건 사러 온 정상 고객(VIP)까지 해커로 오해해서 입구 컷트해버리는 치명적 병크다.

</details>

- **앞단 컷트 (다단 완화)**: 내 서버까지 공격이 도달하기 전에 전 세계에 깔린 거대한 **CDN망**과 상위 통신사(ISP) 망에서 쓰레기 트래픽을 나눠서 몸빵으로 흡수해 버린다.
- **체크의 딜레마 (오탐)**: 방어막을 무식하게 올리면 해커뿐 아니라 찐 사용자(정상 트래픽)까지 차단(오탐)되어 버리므로, 정교한 체크 분리 수거가 생명이다.

#### 한줄 요약

- 한 방에 100Gbps를 다 막는 게 아니라 여러 망에서 나눠서 막고, 진짜 손님은 안 쫓아내는 게 핵심 기술이다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **정화 센터 (Scrubbing Center)**: 트래픽이 폭주할 때, 평소 가던 길을 막고 거대한 세탁소(정화 센터)로 돌려서 악성 패킷만 싹 걸러낸 뒤 정상 트래픽만 원본 서버로 보내는 사이버 대피소다.
- **기준선 (Baseline)**: 평소 우리 사이트에 접속자가 몇 명이고 핑이 얼마나 나오는지 기록해 둔 '정상 상태 수치'다. 이 선을 넘어가면 공격으로 간주한다.

</details>

```text
[ DDoS 다단 완화 및 세탁소 직관적 비교 구조 ]

[ 좀비 PC / 해커 (봇넷) ] ── (가짜 트래픽 100Gbps 쏨)
      │
      ▼ (트래픽 폭주 감지)
[ 1. DDoS 탐지기 ] ── (어? 기준선 넘었네? BGP 경로 틀어서 세탁소로 보내라!)
      │
      ▼ (트래픽 우회)
[ 2. 상위 통신사업자 (ISP) / CDN 엣지망 ] ── (넓은 대역폭으로 몸빵 1차 흡수)
      │
      ▼
[ 3. 정화 센터 (Scrubbing Center) ] ── (더러운 패킷 싹 거르고 정상 고객만 통과시킴)
      │
      ▼ (세탁 완료, 깨끗한 1Gbps만 남음)
[ 4. 원본 서비스 (Origin Server) ] ── (살았다! 찐 고객만 받아서 정상적으로 장사함)
```

| 구성요소 | 직관적 비교 책임 | 비고 |
|:---|:---|:---|
| **DDoS 탐지기** | 평소 **기준선(Baseline) 넘는 미친 트래픽 들어오면 사이렌 울리는 놈** | Detector |
| **상위 통신사 / CDN** | 넓디넓은 대역폭으로 **미친 트래픽을 제일 먼저 몸빵해 주는 거대한 방패** | ISP / CDN |
| **정화 센터** | 우회된 트래픽 받아서 **악성 패킷만 세탁기로 싹 걸러내는 사이버 대피소** | Scrubbing Center |
| **원본 서비스** | 해커한테 IP 숨기고 **세탁소에서 넘어온 깨끗한 찐 고객만 받아서 장사하는 서버** | Origin |

#### 한줄 요약

- 탐지기가 비상벨 누르면 $\to$ 길을 막아서 통신사 세탁소로 트래픽 돌리고 $\to$ 찐 고객만 내 서버로 쏙 넣어준다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **상위 정화 우회 (Upstream Scrubbing Diversion)**: 라우터의 내비게이션(BGP)을 조작해서, 우리 회사로 오던 길을 끊고 통신사 쪽에 있는 거대한 정화 센터로 트래픽 방향을 강제로 틀어버리는 스킬이다.
- **복구 검증**: 막았다고 끝이 아니라 트래픽 양이 기준선으로 돌아왔는지 체크하고, 괜찮으면 다시 원래 길로 복구시키는 작업이다.

</details>

```text
[ DDoS 자원 고갈 탐지 및 우회 세탁 십자포화 흐름 ]

┌──────────────────────────────┐
│ 1. [공격 이상 탐지]     │
│ (탐지기: 평소보다 트래픽 100배 뛰었음. DDoS 공격이다!)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 2. [고갈 자원 부위 체크]│
│ (망 회선 포화인가? 메모리(상태) 고갈인가? 웹서버/DB 뻗었나?)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 3. [부위별 완화 정책 가동]   │
│ (회선 터짐 $\to$ BGP 틀어서 정화 센터로 우회시킴!)
│ (세션 메모리 고갈 $\to$ SYN 쿠키 켜서 껍데기 세션 다 버림!)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 4. [정화 및 정상 트래픽 전달]│
│ (정화 센터/장비: 쓰레기 다 걸러내고 찐 고객만 원본 서버로 보냄)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 5. [서비스 복구 철저한 검증]   │
│ (트래픽 정상화(기준선 복귀) 체크되면 우회 풀고 원상복구)
└──────────────────────────────┘
```

### 동작 원리

1. 공격 이상 탐지: 네트워크 모니터링이 평소 기준선(Baseline)을 초과하는 트래픽 튐을 포착함.
2. 고갈 자원 판정: 어디를 때리는지 파악함 (회선 대역폭 L3/L4 인가, 방화벽 메모리인가, 웹서버 L7 인가).
3. 완화 정책 적용: 회선 꽉 차면 BGP 라우팅 틀어서 세탁소로 보내고, 메모리 꽉 차면 SYN 쿠키 등으로 방어함.
4. 정상 트래픽 전달: 세탁소나 방어 장비가 악성 패킷을 휴지통에 처박고, 살려낸 정상 트래픽만 원본 서버에 꽂아줌.
5. 서비스 복구 검증: 공격 멈춘 거 확인되면 걸어놨던 우회 경로랑 임시 락(Lock)을 다 풀어서 정상화함.

#### 한줄 요약

- 공격 부위 확인 $\to$ 부위에 맞는 방어막 치기 $\to$ 쓰레기 거르고 찐 고객 구출 $\to$ 끝나면 원상 복구.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **대역폭 공격 (Volumetric)**: 묻지마 쓰레기 트래픽을 몇백 기가씩 쏟아부어서 통신 회선(파이프) 자체를 찢어버리는 무식한 공격이다. (DNS 증폭 등)
- **상태 소진 (State-Exhaustion)**: 대역폭은 안 쓰는데, 방화벽이나 서버에 가짜 연결 요청만 무한대로 보내서 세션 기억력(상태표 메모리)을 다 써버리게 만드는 공격이다.
- **응용 계층 공격 (L7 Application)**: 일반 정상 고객인 척 접속해서, DB 무거운 검색 버튼만 매크로로 1초에 100번 눌러 웹서버랑 DB를 뻗게 만드는 정밀 타격이다.

</details>

| DDoS 공격 유형 | **대역폭 (Volumetric)** | **상태 소진 (TCP/Protocol)** | **응용 계층 (L7 Application)** |
|:---|:---|:---|:---|
| 비유 및 핵심 특징 | **가게 문 앞 도로를 덤프트럭으로 꽉 막음** | **가게 알바생한테 계속 말 걸어서 일 못하게 함** | **가게 들어와서 메뉴판 100번 읽고 아무것도 안 삼** |
| 고갈 타겟 | 인터넷 연결 **회선 대역폭 (파이프 자체를 찢음)** | 방화벽/서버의 **TCP 세션 메모리 (상태표 꽉 채움)** | 웹 서버의 **CPU, 메모리, DB 커넥션 풀** |
| 대표 공격 기법 | UDP/DNS 증폭 공격, ICMP 플러딩 | **SYN 플러드(Flood)**, 슬로리스(Slowloris) | HTTP GET/POST 플러딩 |
| 치명적 한계 | 내 방화벽 앞단에서 차단해 봐야 **이미 들어오는 회선이 터져서 의미 없음** | 정상적으로 세션 맺으려는 **착한 고객 연결도 다 같이 튕겨버림** | 정상 요청이랑 똑같이 생겨서 **오탐(찐 고객 컷트) 오지게 남** |

#### 한줄 요약

- 도로를 막으면(대역폭), 전화를 계속 걸면(상태 소진), 가게 와서 진상 짓 하면(응용 L7) 각각 막는 법이 다 다르다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **SYN 플러드 (SYN Flood)**: "안녕(SYN)?" 하고 인사만 한 뒤 내가 "어, 안녕(SYN-ACK)" 대답하면 쌩까버려서, 서버가 "얘 대답 언제 오지?" 하고 기억력(반개방 상태)을 다 쓰다 뻗게 만드는 악질 공격이다.
- **SYN 쿠키 (SYN Cookie)**: 해커가 인사했을 때 서버 메모리에 적어두지 않고, 쿠키(암호화된 수학 계산 값)를 던져서 "네가 진짜면 이 쿠키값 다시 계산해서 줘봐" 하고 검증하는 똑똑한 메모리 철저한 방어법이다.
- **비용 기반 제한 (Cost-Based Rate Limiting)**: 응용 계층(L7)에서, 한 놈이 서버 CPU 겁나 파먹는 무거운 검색(고비용)만 1초에 10번 누르면 "이 새끼 매크로네" 하고 컷트해버리는 WAF 방어술이다.

</details>

| 장애/위험 요소 | 원인 분석 | 실무 대책 및 해결방안 | 기대 효과 |
|:---|:---|:---|:---|
| DNS 증폭 맞고 **인터넷 회선 전체가 터져버림** | 남의 봇넷이 100Gbps 쓰레기를 쏴서 내 1Gbps 파이프가 찢어짐 | BGP 라우팅 틀어서 **상위 정화 센터로 '우회'시켜 대역폭 몸빵으로 막아냄** | 내 앞마당 터지기 전에 거대한 세탁소에서 먼저 걸러내 생존함 |
| SYN 플러드 맞고 **방화벽 세션 테이블 뻗어서 멈춤** | 가짜 IP로 연결 요청(SYN)만 쏴서 서버가 메모리(상태표) 다 쓰고 뻗음 | 서버에 기록 안 하고 **암호화된 쿠키값 쏴서 응답 오는 놈만 통과시키는 SYN 쿠키 켬** | 찐 신규 고객은 통과시키고 봇넷의 가짜 껍데기 요청만 버림 |
| 무지성 새로고침 매크로 맞고 **웹서버 CPU 터짐 (L7)** | 일반 고객인 척 들어와서 서버 CPU 제일 많이 파먹는 무거운 요청만 무한 반복함 | L7 방어 장비로 **사용자별 IP/세션당 '비용 기반 제한(Rate Limiting)' 빡세게 걺** | 진짜 고객은 냅두고 매크로 봇이나 7계층 좀비 PC만 정밀 타격함 |

#### 한줄 요약

- 회선 터지면 우회하고, 세션 꽉 차면 SYN 쿠키 굽고, 매크로 돌리면 L7 임계치(Rate Limit) 빡세게 걸어라.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **완화 위치 (Mitigation Point)**: 공격이 내 회선을 조지는지, 방화벽을 조지는지, 웹서버를 조지는지(고갈 자원) 파악하고 그 앞단에서 막을 방어 지점을 정하는 기준이다.

</details>

- 인터넷 전체를 마비시키는 묻지마 트래픽 포격을 막기 위해, **BGP 우회 상위 정화**, **SYN 쿠키 기반 상태 보호**, **비용 기반 L7 컷트**를 결합한 계층별 다단 완화 방어 기조 확립함

#### 한줄 요약

- DDoS 방어는 성벽 튼튼하게 짓는 걸 넘어서, 쳐들어오는 적군을 길목마다 분산시키고 늪에 빠트려 지치게 만드는 전략이다.
