## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **Network Forensics**: 네트워크 상의 원시 패킷(PCAP), 플로우 통계, 로그를 수집·보전·분석하여 침해 경로와 유출 데이터를 규명하는 분야.
- **Chain of Custody (연계보관성, CoC)**: 증거 수집부터 법정 제출까지 취급자, 일시, 목적, 해시 일치 여부를 문서화하여 증거 능력을 입증하는 절차.

</details>

- 정의/개념: 트래픽 증거를 수집·보존·분석하는 **과학수사 기술**
- 배경/필요성: 사이버 침해 사고 및 데이터 유출 발생 시 호스트 기반 안티포렌식(로그 삭제, 디스크 포맷)으로 인해 엔드포인트 증거가 훼손되거나 휘발되는 경우가 빈번하며, 네트워크 패킷은 전송 즉시 소멸하는 휘발성(Volatility)을 지녀 사후 조사 시 침해 경로, C&C 통신 및 실제 유출 데이터를 객관적으로 입증할 수 없는 한계를 극복하기 위해, 비침습적 네트워크 TAP/SPAN을 통해 원시 트래픽(FPC/PCAP)과 플로우(NetFlow)를 수집하고 ISO/IEC 27037 표준에 따른 연계보관성(Chain of Custody)과 WORM 불변 스토리지를 적용하는 네트워크 포렌식 체계를 도입하여 **침해 사고의 정확한 인과관계 규명, 유출 데이터의 완벽한 실체 복원 및 법정 제출 가능한 무결한 디지털 증거력(Evidence Integrity)**을 달성할 필요

#### 한줄 요약
- 비침습적 패킷 수집, WORM 불변 저장, ISO/IEC 27037 연계보관성을 통해 법적 증거력을 보장한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **ISO/IEC 27037 5대 원칙**: 정당성(Legality), 신뢰성(Reliability), 무결성(Integrity), 원본성(Authenticity), 연계보관성(Chain of Custody).
- **WORM (Write Once Read Many)**: 데이터를 한 번 기록하면 수정이나 삭제가 물리적/논리적으로 불가능하여 원본성을 보장하는 불변 스토리지.

</details>

- **법적 증거력**: ISO/IEC 27037과 **CoC** 확립
- **원본 무결성**: TAP 수집 후 **SHA-256·WORM 봉인**
- **L7 페이로드 복원**: TCP 재조립으로 **유출 파일 복원**

#### 한줄 요약
- ISO/IEC 27037 법적 증거력 확보, WORM 무결성 봉인, L7 세션 및 페이로드 복원을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **FPC (Full Packet Capture)**: 네트워크 인터페이스를 통과하는 모든 프레임의 헤더와 페이로드를 누락 없이 100% 캡처하는 장비.

</details>

```text
[네트워크 포렌식 체계]
|-- TAP/SPAN        : 패킷 복제
|-- FPC 캡처기      : 원시 PCAP 수집
|-- WORM 봉인기     : 해시·원본 보존
|-- 로그 결합기     : 시간·주소 문맥 연결
`-- CoC 관리대장    : 취급 이력 기록
```

선의 의미: 네트워크 길목에서 TAP으로 복제된 원본 트래픽이 해시 생성 후 WORM 스토리지에 봉인되고 분석관은 사본으로만 분석을 수행하는 구조

| 구성요소 | 책임 |
|:---|:---|
| TAP/SPAN | 회선 패킷의 **비침습적 복제** |
| FPC 캡처기 | 원시 **PCAP 무손실 수집** |
| WORM 봉인기 | **SHA-256** 해시와 원본 보존 |
| 로그 결합기 | **NetFlow·DHCP·NAT** 문맥 연결 |
| CoC 관리대장 | 취급 이력과 **해시 검증 기록** |

#### 한줄 요약
- TAP이 운영 경로를 건드리지 않고 사본을 떠내고 WORM 저장소가 그 사본의 변경 가능성을 차단하므로, 수집 행위 자체가 증거 능력을 훼손하지 않는다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Bit-stream Verified Copy**: 원본 데이터를 1:1로 완전 복제하고 SHA-256 해시 일치를 입증하여 원본 훼손 없이 분석에 사용하는 사본.

</details>

```text
네트워크 회선
      |
 1. 트래픽 캡처
      |
 2. 해시 생성·원본 봉인
      |
 3. 검증 사본·CoC 등록
      |
 4. TCP·L7 복원
      |
 5. 주소 문맥 결합·감정
      |
   감정 보고서
```

동작 원리

1. 트래픽 캡처
2. 해시 생성·원본 봉인
3. 검증 사본·CoC 등록
4. TCP·L7 복원
5. 주소 문맥 결합·감정

#### 한줄 요약
- 원본 해시 봉인 이후 모든 분석은 검증 사본에서만 수행되므로, 중복 저장 용량을 대가로 원본 무결성과 분석 재현성을 함께 확보한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **FPC (전체 패킷)** vs **NetFlow (통계 메타데이터)** vs **장비 로그 (이벤트 결과)**.

</details>

| 비교 항목 | 전체 패킷 캡처 (FPC / PCAP) | 플로우 통계 (NetFlow / IPFIX) | 네트워크 장비 로그 (Firewall/DNS) |
|:---|:---|:---|:---|
| 수집 데이터 범위 | **L2~L7 패킷** | **5-Tuple 통계** | 허용·차단·DNS 이벤트 |
| 포렌식 증명력 | 원본·악성코드 **복원** | 이동 경로 **추적** | 정책 집행 결과 증명 |
| 저장공간 요구량 | **매우 높음** | 낮음 | 낮음 |
| TLS 영향 | 페이로드 복호화 키 필요 | 세션 궤적 분석 가능 | 도메인·IP 확인 가능 |
| 주요 활용 목적 | 유출 실체·Exploit 분석 | APT 이동·C&C 식별 | 위반·침투 시점 식별 |

#### 한줄 요약
- FPC는 데이터 실체 복원, NetFlow는 장기 횡적 이동 추적, 장비 로그는 정책 위반 결과 증명에 쓰인다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **NAT 역추적 매핑**: 수천 대의 내부 사설 IP가 단일 공인 IP로 통신할 때 침해 시점의 NAT 변환 로그(Session Table)와 DHCP 임대 이력을 대조하여 내부 단말을 식별하는 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 변조 주장으로 **증거 능력 상실** | **WORM·SHA-256·CoC** 적용 | 무결성과 법적 효력 확보 |
| 시계 오차로 **타임라인 붕괴** | **NTP 동기화·시각 보정** | 사건 인과관계 입증 |
| NAT로 **내부 단말 식별 불가** | **NAT·DHCP 로그 교차 매핑** | 실제 침해 단말 특정 |
| TLS로 **페이로드 분석 불가** | **복호화 TAP·TLS 키 로깅** | 평문 페이로드 복원 |

#### 한줄 요약
- CoC 절차로 법적 증거력을 확보하고, NTP로 타임라인을 정렬하며, NAT/DHCP 로그로 내부 발신자를 특정한다.

## Ⅶ. 결론

- 사후 침해 조사, 랜섬웨어 유출 증명 및 법적 분쟁 시 객관적 사실을 증명하는 **사이버 보안 인시던트 대응 및 디지털 과학수사의 핵심적인 최종 증거 보존 인프라**로 정립되었으며, 암호화 트래픽(TLS 1.3) 증가에 대응하는 메타데이터/플로우 기반 머신러닝 분석 및 클라우드 VPC 패킷 미러링과의 결합으로 진화하는 가운데, 실무 네트워크 포렌식 인프라 구축 시에는 **수집 즉시 무결성을 봉인하는 SHA-256 해시 생성 및 WORM(Write Once Read Many) 스토리지 저장, 법적 증거 능력을 보장하는 ISO/IEC 27037 기반 연계보관성(Chain of Custody) 엄격 준수, 내부 사설 IP 식별을 위한 NAT 세션 로그와 DHCP 임대 이력 교차 매핑 파이프라인**을 결합하여 완벽한 디지털 증거 신뢰성을 완성

#### 한줄 요약
- FPC/NetFlow 수집과 CoC 연계보관성 및 WORM 봉인을 통해 고신뢰 네트워크 포렌식을 구현한다.
