## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **네트워크 포렌식(Network Forensics)**: 사이버 침해 사고 발생 시 네트워크 인프라 상을 통과하는 원시 패킷(PCAP), 플로우 통계(NetFlow), 장비 로그(Firewall, DNS, DHCP)를 합법적으로 수집·보전·분석하여 공격자의 침입 경로, 공격 기법, 유출 데이터의 범위를 규명하는 디지털 포렌식 분야.
- **증거 연계보관성(Chain of Custody, CoC)**: 수집된 디지털 증거가 법정에서 증거 능력을 인정받기 위해 증거의 식별, 수집, 이송, 보관, 분석, 폐기 전 과정에서 누가, 언제, 어떤 목적으로 증거를 취급했는지와 원본 해시값 일치 여부를 문서로 증명하는 절차.

</details>

- 정의/개념: 네트워크 트래픽을 비침습적(Non-intrusive) 방식으로 수집하여 **ISO/IEC 27037 표준 원칙(무결성, 신뢰성, 정당성, 연계보관성)** 에 따라 암호학적 해시(SHA-256)를 생성·보존하고, 침해 사고의 타임라인을 재구성하는 **네트워크 디지털 증거 분석 체계**
- 배경/필요성: 공격자가 호스트 OS의 시스템 로그를 고의로 삭제·변조하는 안티 포렌식(Anti-Forensics) 기법에 대응하여, 변조가 불가능한 네트워크 전송 계층의 통신 패킷을 통해 객관적 공격 증적을 확보할 요구

#### 한줄 요약
- 네트워크 패킷과 플로우를 무결하게 보전하고 연계보관성(CoC)을 확립하여 침해 사고 타임라인을 재구성한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **전체 패킷 캡처(Full Packet Capture, FPC)**: L2 이더넷 헤더부터 L7 애플리케이션 페이로드까지 전송된 모든 바이트를 누락 없이 원본 그대로 저장하여 데이터 유출 내용과 악성코드를 완전 복원 가능하게 하는 수집 방식.
- **WORM(Write Once, Read Many) 스토리지**: 한 번 기록된 데이터는 물리적/논리적으로 수정이나 삭제가 불가능하여 법적 증거의 위변조 방지를 완벽히 보장하는 저장 매체.

</details>

- **휘발성 네트워크 데이터의 영구 증적화**: 전송 즉시 소멸하는 메모리/선로 상의 패킷을 고속 TAP/SPAN 미러링을 통해 WORM 매체에 영구 박제
- **다계층 교차 검증을 통한 신뢰성 확보**: 전체 패킷(FPC), 세션 메타데이터(NetFlow), 방화벽 인입 로그, DHCP/NAT 주소 변환 기록의 상호 대조
- **법적 증거 능력(Admissibility) 충족**: 원본 해시(SHA-256) 생성, 검증 사본(Verified Copy) 기반 분석 및 CoC 이력 문서화를 통한 무결성 입증

#### 한줄 요약
- FPC 기반 페이로드 복원, NetFlow 장기 궤적 분석, WORM 무결성 보존 및 CoC 법적 증거성을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **네트워크 TAP(Test Access Point)**: 물리 케이블 사이에 인라인으로 장착되어 광 신호나 전기 신호를 패킷 손실(Packet Drop) 없이 수동 복제하여 모니터링 포트로 전달하는 하드웨어 장치.

</details>

```text
[ 코어 스위치 / 관문 라우터 ] ──── (Network TAP / SPAN 미러링: 무손실 복제)
                 │
                 ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 포렌식 수집 및 불변 보존 계층 ]                                       │
│  ├─ 1. 고속 패킷 캡처 엔진 (FPC: 10Gbps+ Line-Rate 무손실 버퍼링)         │
│  ├─ 2. 무결성 해시 생성기 (Capture 즉시 SHA-256 / Ed25519 전자서명 생성) │
│  └─ 3. WORM 불변 스토리지 ── (원본 증거 봉인: 수정 및 삭제 원천 불가)   │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │ (Bit-stream 검증 사본 생성 및 CoC 인계)
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 포렌식 정밀 분석 계층 (Forensics Workstation) ]                        │
│  ├─ 패킷 재조립 및 L7 세션 복원 (TCP Stream Reassembly: Wireshark/Zeek) │
│  ├─ 맥락 로그 결합 (NTP 정밀 타임라인 + DHCP IP 할당 + NAT 변환 매핑)   │
│  └─ 법정 제출용 침해 사고 분석 보고서 (Expert Witness Report)            │
└─────────────────────────────────────────────────────────────────────────┘
```

선의 의미: 네트워크 길목에서 TAP으로 복제된 원본 트래픽이 해시 생성 후 WORM 스토리지에 봉인되고, 분석관은 비트스트림 사본으로만 분석을 수행하는 포렌식 아키텍처

| 구성요소 | 핵심 책임 및 역할 | 비고 |
|:---|:---|:---|
| **네트워크 TAP / SPAN** | 스위치 CPU 부하 없이 물리 회선의 패킷을 100% 무손실 복제 송출 | Passive TAP |
| **FPC 캡처 어플라이언스** | 고속 링 버퍼(Ring Buffer)를 활용하여 초당 수십 기가비트 원시 패킷 저장 | PCAP Capture |
| **무결성 봉인기 (WORM)** | 수집 완료 즉시 타임스탬프 토큰 발급 및 SHA-256 해시를 결합하여 봉인 | ISO/IEC 27037 |
| **로그 상관 결합기** | NTP 동기화된 시간 기준으로 NetFlow, DHCP, NAT 로그를 매핑하여 실제 사용자 특정 | Context Binding |
| **연계보관성 관리대장** | 증거 수집자, 보관 장소, 사본 반출 이력, 해시 검증 결과를 기록한 법적 문서 | CoC Ledger |

#### 한줄 요약
- 네트워크 TAP, FPC 캡처기, WORM 불변 저장소, 로그 결합기, CoC 관리대장이 결합한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **비트스트림 검증 사본(Bit-stream Verified Copy)**: 원본 데이터의 물리적 섹터/바이트를 1:1로 완전 복제한 후, 사본의 SHA-256 해시값이 원본과 일치함을 입증하여 원본 훼손 없이 분석에 사용하는 사본.

</details>

```text
1. 관제 센터의 침해 의심 통보 접수 ➔ 네트워크 TAP 및 센서에서 대상 시간대 트래픽 식별
            │
            ▼
2. FPC 어플라이언스에서 원시 패킷(PCAP) 덤프 ➔ 즉시 SHA-256 해시값 생성 및 WORM 매체 원본 봉인
            │
            ▼
3. 비트스트림 검증 사본을 생성하고 해시 일치 검증 ➔ 연계보관성(CoC) 대장에 반출 이력 공식 등록
            │
            ▼
4. 포렌식 워크스테이션에서 사본 패킷 분석 (TCP 스트림 재조립 + 악성코드 페이로드 추출)
            │
            ▼
5. DHCP/NAT 로그 매핑을 통해 내부 발신 호스트 특정 ➔ 법적 효력을 갖춘 포렌식 최종 감정서 작성
```

**동작 원리**

1. **증거 식별 및 수집**: 침해 사고 시간대의 통신 데이터를 누락 없이 캡처 파일로 추출
2. **원본 무결성 고정**: 수집 즉시 해시를 산출하여 보관 금고에 적재함으로써 사후 변조 시비 원천 차단
3. **사본 기반 분석**: 원본 파일에 대한 일체의 쓰기 접근을 금지하고 오직 검증된 사본만 마운트
4. **프로토콜 복원**: 단편화된 패킷들을 TCP 시퀀스 순서로 재조립하여 공격자가 전송한 원본 파일 복원
5. **사건 타임라인 확정**: 방화벽 로그의 차단 시간과 패킷 발생 시각을 1밀리초 오차 없이 대조 확정

#### 한줄 요약
- 트래픽 식별, 원본 해시 생성 및 WORM 봉인, 검증 사본 생성 및 CoC 등록, L7 세션 복원, 감정서 작성 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **전체 패킷 캡처(FPC) vs 플로우 데이터(NetFlow) vs 네트워크 장비 로그**: 심층 분석용 원시 데이터, 장기 추적용 통계 메타데이터, 이벤트 발생 결과 로그의 비교.

</details>

| 비교 항목 | 전체 패킷 캡처 (FPC / PCAP) | 플로우 통계 (NetFlow / IPFIX) | 네트워크 장비 로그 (Firewall/DNS) |
|:---|:---|:---|:---|
| **수집 데이터 범위** | **L2~L7 전체 헤더 및 페이로드 100%** | **5-Tuple 세션 통계, 바이트 수, 지속 시간** | **접속 허용/차단 이벤트, DNS 질의어** |
| **포렌식 증명력** | **최고 (유출된 문서 원본/악성코드 복원)**| 중간 (공격자의 네트워크 이동 궤적 추적) | 보통 (특정 시점의 정책 집행 결과 증명)|
| **스토리지 요구량** | **매우 높음 (수일~수주일 보관 한계)** | **낮음 (수개월~수개년 장기 보관 가능)** | 낮음 (텍스트 기반 장기 보관) |
| **암호화(TLS) 영향** | 페이로드 암호화 시 복호화 키 필요 | **암호화 무관하게 세션 궤적 완벽 분석** | 암호화 무관하게 도메인/IP 접속 확인 |
| **주요 활용 목적** | 유출 데이터 실체 규명, Exploit 분석 | **장기 APT 횡적 이동 경로 추적, C&C 식별**| 정책 위반 증명, 최초 침투 시점 식별 |

#### 한줄 요약
- FPC는 데이터 실체 복원, NetFlow는 장기 횡적 이동 추적, 장비 로그는 정책 위반 결과 증명에 쓰인다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **NAT 환경 발신자 특정 한계**: 다수의 내부 사설 IP가 단일 공인 IP로 변환되어 통신할 때, 외부 패킷 캡처만으로는 내부의 실제 침해 단말(Private IP/MAC)을 식별할 수 없는 한계.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 법정 공방 시 원본 패킷 증거의 조작·변조 주장으로 인한 **증거 능력(Admissibility) 상실** | **ISO/IEC 27037 기반 WORM 저장, SHA-256 해시 증명 및 CoC 대장** 관리 | 법정 무결성 시비 원천 차단 및 100% 법적 증거 효력 확보 |
| 사내 전사 인프라 간 시스템 시계 오차로 인한 포렌식 공격 타임라인 인과성 붕괴 | 전 네트워크 및 서버에 **RFC 5905 NTP 계층 동기화 및 타임스탬프 보정** | 밀리초 단위 정밀 사건 재구성 및 공격 인과 관계 입증 |
| 공인 IP 변환(NAT)으로 인한 실제 내부 침해 공격 단말 식별 불가 및 특정 실패 | 패킷 캡처 타임스탬프와 **당시 NAT 변환 테이블 및 DHCP 임대 로그의 교차 매핑** | 수천 대 내부 단말 중 실제 악성 패킷 발신 엔드포인트 핀포인트 특정 |

#### 한줄 요약
- CoC 절차로 법적 증거력을 확보하고, NTP로 타임라인을 정렬하며, NAT/DHCP 로그로 내부 발신자를 특정한다.

## Ⅶ. 결론

- 지능형 사이버 침해 사고에 대한 객관적 증거 확보와 사법 처리를 지원하기 위해 **네트워크 포렌식 증거 수집 체계**를 필수 구축하되, 증거의 법적 신뢰성과 분석력을 담보하기 위해 **ISO/IEC 27037 기반 연계보관성(CoC) 확립**, **WORM 불변 스토리지 봉인**, **FPC와 NetFlow의 계층적 하이브리드 보존**, **NTP 기반 다계층 로그 교차 분석**을 통합 구현하여 완결성 높은 디지털 과학수사 환경을 완성

#### 한줄 요약
- FPC/NetFlow 수집과 CoC 연계보관성 및 WORM 봉인을 통해 고신뢰 네트워크 포렌식을 구현한다.
