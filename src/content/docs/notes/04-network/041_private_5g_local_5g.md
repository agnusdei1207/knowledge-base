## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **5세대 이동통신(Fifth Generation, 5G)**: 초고속•초저지연•초연결을 지원하는 이동통신 세대이다.
- **5G 특화망(Private 5G)**: 한정 구역에서 전용 설비•정책으로 산업 서비스를 제공하는 비공중망이다.

</details>

- 정의/개념: 한정 구역에서 산업 서비스를 제공하는 **전용 주파수•정책 기반 비공중망**이다.
- 배경/필요성: 공중망 장애•외부 전송 의존으로 **현장 제어 연속성** 제약이 발생한다.

#### 한줄 요약

- 공장 안에 전용 5G 기지국과 데이터 길을 두어 외부 통신망이 끊겨도 현장 설비를 제어한다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **무선 접속망(Radio Access Network, RAN)**: 산업 단말을 전용 주파수로 5GC에 연결하는 기지국 체계이다.
- **서비스 품질(Quality of Service, QoS)**: 트래픽별 지연•손실•대역폭을 차등 제어하는 품질 정책이다.
- **사용자면 기능(User Plane Function, UPF)**: 사용자 데이터를 현장 데이터망으로 직접 전달하는 코어망 기능이다.
- **가입자 식별 모듈(Subscriber Identity Module, SIM)**: 단말의 가입자 식별자와 인증 정보를 저장하는 모듈이다.

</details>

- **전용 RAN 기반 무선 자원 직접 통제**가 핵심이다.
- **로컬 UPF 기반 현장 데이터 경로 유지**가 핵심이다.
- **SIM** 인증•**QoS** 정책으로 단말 접근과 트래픽 등급을 통제한다.

#### 한줄 요약

- 독립형은 제어권과 장애 독립성이 크지만 코어망까지 직접 운영해야 한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **5세대 코어(5G Core, 5GC)**: 가입자 인증•이동성•정책•세션을 제어하는 5G 핵심망이다.
- **로컬 사용자면 기능(Local User Plane Function, Local UPF)**: 사용자 데이터를 외부 중앙망 대신 현장 데이터망으로 직접 전달하는 사용자면 기능이다.
- **다중접속 에지 컴퓨팅(Multi-access Edge Computing, MEC)**: 현장 가까이에서 응용을 처리하는 컴퓨팅 환경이다.
- **운영 기술(Operational Technology, OT)**: 생산 설비를 감시하고 제어하는 기술 체계이다.
- **비공중망(Non-Public Network, NPN)**: 특정 조직이나 구역을 위해 전용으로 구축한 이동통신망이다.

</details>

```text
5G 특화망
├─ RAN
├─ 5GC
├─ 로컬 UPF
└─ MEC•OT 연계
```

가지의 의미: 비공중망 경계에 속한 무선•코어•현장 처리 기능을 뜻한다.

| 구성요소 | 책임 |
|:---|:---|
| RAN | 전용 주파수로 산업 단말 **무선 접속** 제공 |
| 5GC | 가입자 인증•세션•**QoS 정책** 제어 |
| 로컬 UPF | **사용자 데이터의 현장 데이터망 직접 전달** |
| MEC•OT 연계 | **현장 응용** 처리와 설비 제어 연결 |

#### 한줄 요약

- 5G 코어가 출입과 데이터 길을 정하고 로컬 UPF가 공장 밖을 거치지 않고 설비로 보낸다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **프로토콜 데이터 단위 세션(Protocol Data Unit Session, PDU Session)**: 단말과 데이터망 사이에서 사용자 데이터를 전달하도록 설정한 논리 경로이다.

</details>

RAN, 5GC, UPF, MEC, OT가 인증부터 현장 전달까지 연결한다.

```text
산업 단말 접속 요청
        │
        ▼
1. 가입자 인증 요청
        ├─ 실패: 접속 거절
        └─ 성공
            │
            ▼
2. PDU 세션 규칙
            │
            ▼
3. QoS 정책
            │
            ▼
4. 현장 데이터
            │
            ▼
MEC•OT 처리 결과 반환
```

**동작 원리**

1. **가입자 인증 요청**: **SIM** 정보로 특화망 접속 권한을 판정한다.
2. **PDU 세션 규칙**: 로컬 UPF를 데이터 경로로 지정하는 **5GC을 제어**한다.
3. **QoS 정책**: 트래픽 등급별 **지연•대역폭** 한도를 적용한다.
4. **현장 데이터**: **UPF 기반 MEC•OT을 전달**한다.

#### 한줄 요약

- 단말 신원을 확인한 뒤 업무별 통신 품질을 적용해 데이터를 현장 설비로 보낸다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **독립형 비공중망(Standalone Non-Public Network, SNPN)**: 공중망에 의존하지 않고 전용 기지국과 5GC를 운영하는 비공중망이다.
- **공중망 통합 비공중망(Public Network Integrated Non-Public Network, PNI-NPN)**: 공중망의 가입자•코어 기능을 공유해 운영을 위탁하는 비공중망이다.

</details>

5G 특화망은 SNPN 또는 PNI-NPN으로 구성할 수 있다.

| 현장 무선망 방식 | 5G 특화망 | 기업 Wi-Fi | 공중망 슬라이스 |
|:---|:---|:---|:---|
| 적용 기준 | 이동성•QoS•현장 통제가 필요할 때 | 저비용 근거리 접속이 필요할 때 | 광역 이동과 운영 위탁이 필요할 때 |
| 핵심 특징 | **전용 주파수•정책** 직접 통제 | 비면허 **Wi-Fi** 무선 접속 | 공중망 **네트워크 슬라이싱** |
| 한계 | **5G 코어 운영 역량 필요** | 비면허 간섭•**로밍** 제약 | **공중망 장애 종속성** |

> 요약: 이동성•제어권•운영 역량으로 망을 선택한다.

#### 한줄 요약

- 현장이 주파수와 데이터 경로까지 통제해야 하면 특화망, 운영을 맡기려면 공중망 슬라이스를 선택한다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **무선 음영**: 설비나 구조물의 차폐로 전파 수신 세기가 접속 가능한 수준 아래로 떨어지는 구역이다.
- **경로 정책**: 사용자 트래픽이 로컬 UPF와 현장 데이터망을 통과하도록 고정하는 전달 규칙이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 설비 차폐로 **무선 음영** 발생 | 설비 배치 기반 **커버리지 실측** | 산업 단말 **접속 단절** 감소 |
| 외부망 경유로 지연•**데이터 노출** 증가 | 로컬 **UPF•경로 정책** 고정 | 전송 지연•외부 노출 감소 |
| **5G 코어** 운영 역량 부족 | 관리형 코어와 **장애 훈련** 도입 | 장애 복구 시간 단축 |

#### 한줄 요약

- 공장 제어 데이터가 외부망을 돌지 않고 현장 설비에 바로 도착한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **데이터 주권**: 조직이 데이터의 저장 위치와 처리•전송 경로를 직접 통제하는 능력이다.

</details>

- 공중망 독립•데이터 주권이 핵심이면 **SNPN**, 운영 위탁이면 **PNI-NPN**을 선택한다.

#### 한줄 요약

- 외부망 없이 운영할 범위와 코어망 관리 역량을 확인해 독립형 여부를 정해야 한다.
