## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **경계 게이트웨이 프로토콜(BGP, Border Gateway Protocol)**: 전 세계 통신사(SKT, KT)와 대기업 인터넷망을 하나로 묶어서 글로벌 인터넷을 만들어주는 끝판왕 라우팅 프로토콜이다.
- **자율 시스템(AS, Autonomous System)**: "여기서부턴 내 땅이니까 내가 룰 정함" 하고 고유 번호(ASN)를 부여받아 굴러가는 거대한 인터넷 왕국(ISP 등)이다.
- **네트워크 계층 도달 가능성 정보(NLRI)**: BGP 라우터끼리 주고받는 주소 뭉치로, "이 IP 대역은 우리 왕국으로 오면 됨" 하고 광고하는 정보다.
- **내부 게이트웨이 프로토콜(IGP)**: OSPF처럼 우리 왕국(AS) 내부에서만 제일 빠른 길을 찾는 동네 길잡이다.

</details>

- 정의: 자율 시스템(AS) 간에 IP 도달성과 트래픽 정책 경로를 교환하는 **외부 라우팅(EGP) 끝판왕 프로토콜**
- 배경: 동네 길잡이(IGP)의 최단 경로 논리만으로는 국가나 통신사 간의 복잡한 **비즈니스 정책(돈, 보안) 통제가 불가능했기 때문**

#### 한줄 요약

- 통신사나 대기업 같은 거대 인터넷 왕국(AS)끼리 서로 길을 뚫어주는 글로벌 네비게이션이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **자율 시스템 경로(AS_PATH)**: 여권에 찍힌 출입국 스탬프처럼, "이 패킷은 AS100 $\to$ AS200 $\to$ AS300을 거쳐왔다"라고 족적을 남겨 빙빙 도는(루프) 걸 막아주는 속성이다.
- **증분 갱신(Incremental Update)**: 전 세계 수백만 개의 라우팅 지도를 매번 통째로 보내면 망이 터지니까, 처음에만 다 주고 나중엔 바뀐 거(추가/삭제)만 찔끔찔끔 보내는 효율적인 방식이다.

</details>

- 확실한 배달을 위해 UDP 대신 **TCP 프로토콜(Port 179)** 기반으로 1:1 세션(Peer) 연결 수립.
- 여권 스탬프 같은 **자율 시스템 경로(AS_PATH)** 를 뒤져서 자기 번호가 찍혀 있으면 칼같이 버려버림(라우팅 루프 방지).
- **증분 갱신** 및 Keepalive 패킷을 사용하여 대규모 인터넷 라우팅 테이블 전송 시 대역폭 낭비 극소화.

#### 한줄 요약

- TCP로 확실하게 연결하고, 스탬프(AS_PATH)로 빙빙 도는 걸 막으며, 바뀐 것만 찔끔 전송한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **BGP 피어(BGP Peer)**: "우리 남이지만 인터넷 좀 이어보자" 하고 TCP 179번 포트로 1:1 동맹을 맺은 이웃 왕국 라우터이다.
- **업데이트 메시지(UPDATE Message)**: 동맹국한테 "새로운 길 뚫렸다(NLRI)" 혹은 "저 길 막혔다(Withdraw)"라고 알려주는 BGP 핵심 전보이다.
- **최선 경로(Best Path)**: 여러 동맹국이 알려준 길 중에서 돈(Local_Pref)과 거리(AS_PATH) 등을 빡세게 따져서 하나만 픽하는 1등 경로이다.

</details>

```text
[ BGP 정책 기반 팩트 폭행 라우팅 구조 ]

[ BGP Peer A (AS 100) ] <── TCP 179 동맹 ──> [ BGP Peer B (AS 200) ]
           │
           ├─ 1. 수신 정책 (거를 건 거르고 속성 덧칠함)
           │
           ├─ 2. BGP 장부 (동맹들이 준 길 다 모아놓음)
           │
           ├─ 3. 1등 경로 선발 (Weight > LOCAL_PREF > AS_PATH 등 따짐)
           │
           ├─ 4. 광고 정책 (남한테 이 1등 길을 알려줄지 말지 통제)
           │
           ▼
[ 라우터 칩(FIB)에 1등 경로 때려박음 ]
```

| 구성요소 | 팩트 폭행 책임 | 비고 |
|:---|:---|:---|
| **BGP 피어 (Neighbor)** | TCP 179번 열고 패킷 날리면서 찐친(Established) 상태 유지함 | 끊기면 헬게이트 |
| **경로 속성 (Attributes)** | "이 길은 국산이냐, 스탬프 몇 개 찍혔냐" 하고 1등을 가리는 채점표 | Weight, LOCAL_PREF 등 |
| **수신 정책 (Inbound)** | 남이 준 길 중에 이상한 짭 주소 컷팅하고, 맘에 드는 길 점수 올려줌 | 유입 트래픽 통제 |
| **1등 경로 선발대** | 10개가 넘는 빡센 룰베이스를 거쳐서 오직 단 하나의 최적 경로만 선발 | Best Path Algorithm |
| **광고 정책 (Outbound)** | "이 1등 길을 다른 동맹국한테 소문 낼까 말까" 결정하는 나가는 문지기 | 유출 트래픽 통제 |

#### 한줄 요약

- 남이 준 길을 내 입맛대로 검열하고 조작해서, 오직 1등 길만 뽑아내 내 입맛대로 다시 소문낸다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **수신 정책 검증(Inbound Policy Verification)**: 동맹국이 준 길 중에 쓰레기 주소가 없는지 검사하고 입맛에 맞게 점수를 조작하는 단계이다.
- **최선 경로 선택(Best Path Selection)**: "돈 많이 주는 길 $\to$ 가까운 길" 순서의 절대 규칙으로 1등 길을 뽑아내는 과정이다.
- **광고 정책 검증(Outbound Policy Verification)**: "이 길을 쟤한테 알려주면 우리 회사 망이 털릴까?" 따져보고 안전한 길만 광고하는 단계이다.

</details>

```text
[ BGP UPDATE 패킷 심사 십자포화 흐름 ]
┌──────────────────────────────┐
│ 0. UPDATE 패킷 도착          │
│ ("새로운 길 뚫렸다!")        │
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 1. [수신 정책] 컷팅 및 조작  │
│ (이상한 주소 버리고 점수 줌) │
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 2. [BGP 장부] 후보 등록      │
│ (살아남은 길들 리스트업)     │
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 3. [1등 선발] 오디션         │
│ (Weight>LOCAL_PREF>AS_PATH)  │
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 4. [광고 정책] 소문내기      │
│ (1등 길을 남한테 퍼뜨림)     │
└──────────────────────────────┘
```

### 동작 원리

1. 수신 정책 검증: 프리픽스를 필터링하고 찐인지(RPKI) 컷팅함.
2. 후보 경로 등록: 살아남은 허용 경로와 속성을 BGP 메모리(Table)에 적재함.
3. 최선 경로 선택: 정책 속성 서열(LOCAL_PREF 등)에 따라 단일 1등 경로를 선발함.
4. 광고 정책 검증: 허락된 1등 경로만 이웃 동맹국(eBGP/iBGP)에 조심스레 전파함.

#### 한줄 요약

- 수신 검열로 쓰레기를 걸러내고, 철저한 서열로 1등만 뽑아서 남한테 허락된 것만 소문낸다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **eBGP(External BGP)**: "KT $\leftrightarrow$ SKT"처럼 아예 다른 왕국(AS)끼리 만나서 국경을 넘나드는 글로벌 BGP 동맹이다.
- **iBGP(Internal BGP)**: 외부에서 얻어온 꿀정보를 자기 왕국(AS) 내부 라우터들끼리 "KT가 저 길 뚫었대" 하고 퍼나르는 사내 통신이다.
- **경로 반사기(RR, Route Reflector)**: iBGP 라우터 수백 대가 서로 떠들면 망이 터지니까, 반장(RR) 하나 뽑아서 걔가 싹 다 모아서 방송(반사)해 주는 기술이다.

</details>

| 비교 항목 | **eBGP (국경선 동맹)** | **iBGP (사내 메신저)** |
|:---|:---|:---|
| AS 세션 범위 | 서로 **다른** 왕국(AS 번호 다름) 라우터끼리 연결 | 서로 **같은** 왕국(AS 번호 같음) 내부 라우터끼리 연결 |
| 스탬프 갱신 | 나갈 때 **자기 AS 번호를 여권(AS_PATH)에 쾅 찍음** | 내 식구끼리 도는 거라 스탬프 **안 찍고 그대로 던짐** |
| 루프 방지 룰 | 여권(AS_PATH)에 내 번호 있으면 바로 찢어버림 | 친구(iBGP)한테 들은 얘긴 딴 친구한테 **절대 전달 안 함** |
| 연결 확장성 | eBGP 멀티홉(Multihop) 옵션으로 이음 | 다 연결하기 빡세니까 **경로 반사기(RR)** 반장 세움 |

#### 한줄 요약

- 밖에 나갈 땐 eBGP로 스탬프 찍고 나가고, 안에서 돌릴 땐 iBGP 반장(RR) 통해서 소문낸다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **RPKI(Resource Public Key Infrastructure)**: 해커가 "네이버 IP 내 거임!" 하고 뻥치는(하이재킹) 걸 막으려고, 암호화된 국세청 증명서(ROA)를 까보는 철통 검증 기술이다.
- **프리픽스 필터(Prefix Filter)**: `192.168.x.x` 같은 짭 사설 주소가 바깥 인터넷으로 기어 나가지 않게 문지기 필터를 씌우는 거다.
- **LOCAL_PREF(로컬 선호도)**: 우리 회사에서 밖으로 나갈 때 "비싼 전용선 탈래, 싼 인터넷 탈래?" 하고 나가는 문(아웃바운드)을 강제하는 대빵 속성이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 해커가 가짜 경로 뿌려서 내 트래픽 훔쳐가는 **BGP 하이재킹** | 암호화 증명서 대조하는 **RPKI(ROA 검증)** 빡세게 도입 | 가짜 BGP 경로 사기 극극 방어 및 수용 원천 차단 |
| 내가 남의 회사 패킷까지 공짜로 날라주느라 **회선 터짐** | 딴 데서 받은 경로 안 흘리게 **커뮤니티 필터** 아웃바운드 설정 | 비의도적 패킷 셔틀(Route Leak / Transit) 호구 짓 차단 |
| 외부망 회선 두 개 뚫어놨는데 트래픽이 **한쪽으로만 몰림** | 내가 밀어주고 싶은 회선에 **LOCAL_PREF** 점수 팍팍 줌 | 내부 $\to$ 외부 아웃바운드 회선 대역폭 최적 분산 통제 |

#### 한줄 요약

- RPKI로 사기꾼 잡고, 필터 씌워서 호구 짓 막고, LOCAL_PREF로 트래픽 흐름을 지배해라.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **경로 정책 결정(Routing Policy Selection)**: 아웃바운드는 내 맘대로(LOCAL_PREF) 꽂고, 인바운드는 여권 도장(AS_PATH)을 길게 늘여서 우회하게 만드는 살벌한 튜닝 전략이다.

</details>

- **경로 정책 결정** 원칙에 따라, 수신은 **RPKI**로 가짜를 쳐내고, 송신은 **프리픽스 필터**로 호구 짓을 막아 인터넷 라우팅 무결성을 사수하는 기조 확립함

#### 한줄 요약

- BGP는 들어오는 놈은 의심하고 나가는 정보는 철저히 감춰서 내 비즈니스(정책)를 지키는 게임이다.
