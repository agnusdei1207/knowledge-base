## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **NB-IoT (협대역 사물인터넷, Narrowband IoT)**: 속도랑 이동을 싹 다 포기하고, 배터리를 10년 쓰면서 지하 맨홀 구석까지 전파를 밀어 넣는 데 올인한 짠돌이 고정형 통신망이다.
- **LTE-M (기계형 LTE, Cat-M1)**: NB-IoT보단 전기를 더 먹지만, 적당히 속도도 나오고 자동차처럼 이동하면서도 기지국이 안 끊기는 '적당히 타협한' 기계 전용 LTE망이다.

</details>

- 정의: **NB-IoT** 및 **LTE-M** 통신사 주파수(면허 대역)를 빌려 쓰면서 전기는 쥐꼬리만큼 먹고 전파는 짱짱하게 멀리 쏘는 3GPP 셀룰러 저전력 광역망(LPWAN)의 2대 통신 표준이다.
- 배경: 10원짜리 데이터 쏘는 수도 계량기에 10만 원짜리 스마트폰 LTE 모뎀을 달면 배터리가 하루 만에 털리고 단가가 안 맞으니까, **전기 덜 먹고 단가 후려친 사물 전용 통신망을 만들었다.**

#### 한줄 요약

- 싼 맛에 전기 아끼며 고정해 놓고 쓰는 'NB-IoT'와 굴러다니면서 적당히 빠른 맛에 쓰는 'LTE-M'의 대결이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **PSM (절전 모드, Power Saving Mode)**: 통신사랑 "나 10시간 잘 거니까 깨우지 마!" 하고 합의한 뒤, 진짜 무전기를 아예 꺼버려서 배터리 소모를 0으로 만드는 딥슬립 겨울잠 모드다.
- **eDRX (확장 수신 대기)**: 통신사가 언제 호출할지 모르니까, 눈을 뜨고 1초 대기하다가 10초 자고 다시 눈 뜨는 걸 반복하는 얕은 수면(쪽잠) 모드다.

</details>

- **NB-IoT (고정형 극한의 짠돌이)**: 전파 도로를 180kHz짜리 좁은 실핏줄만 써서 배터리를 아끼고, 전파가 안 터지는 지하는 똑같은 데이터를 수십 번 쏴서 억지로 뚫어버림 (반복 전송 기술).
- **LTE-M (이동형 적당충)**: 도로 폭을 1.4MHz로 좀 더 넓게 쓰고 기지국 간 핸드오버도 지원해서, 택배 트럭처럼 이동하는 물건 추적할 때 통신이 안 찢어짐.
- **극강의 배터리 쥐어짜기**: **PSM**(겨울잠)과 **eDRX**(쪽잠)를 상황에 맞게 스까 써서 AA 배터리 2개로 센서를 10년 동안 살려두는 기적을 보여줌.

#### 한줄 요약

- 속도 포기하고 지하 벙커까지 전파 뚫는 NB-IoT와 이동하면서도 안 끊기는 LTE-M이 PSM(겨울잠)을 무기로 배터리를 10년 연장함.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **코어망 (EPC / 5GC / MME)**: 단말기한테 "너 몇 시간 잘 거임?" 하고 물어보고 PSM 타이머를 세팅해 주는 통신사 중앙 두뇌 서버다.
- **NB-IoT 배치 (In-band / Guard-band / Standalone)**: 기존 LTE 도로 안쪽(In-band)에 빌붙거나, 도로 갓길(Guard-band)에 몰래 깔거나, 아예 시골 흙길(Standalone)을 독자적으로 파서 까는 3가지 주파수 꼼수 옵션이다.

</details>

```text
[ 셀룰러 LPWAN 직관적 비교 구조 ]

[ 1. IoT 단말 (지하 수도 계량기) ] 
      │ (쪽잠 자다 깨서 1바이트 쏨)
      ▼
[ 2. 무선 기지국 (통신사 기지국 철탑) ]
      │ (180kHz 갓길로 전파 받아줌)
      ▼
[ 3. 셀룰러 코어망 (MME / 중앙 서버) ]
      │ (얘 10시간 잔다고 타이머 메모함)
      ▼
[ 4. IoT 서비스 플랫폼 (한전, 수도국 서버) ]
```

| 구성요소 | 직관적 비교 책임 | 비고 |
|:---|:---|:---|
| **IoT 단말 (USIM 탑재)** | 한 달에 한 번 깨서 **검침 데이터 달랑 쏘고 다시 겨울잠(PSM) 자는 놈** | Device |
| **무선 기지국 (eNB/gNB)** | 데이터 안 터지면 터질 때까지 **수십 번 반복 전송(CE) 받아주는 노가다 꾼** | RAN |
| **코어망 (MME/SCEF)** | 단말이랑 타협해서 **"너 몇 시간 잘 건지" 타이머(PSM) 설정하고 통제하는 두뇌** | Core |
| **IoT 플랫폼 (앱 서버)** | 통신사 망 뚫고 올라온 **먼지 같은 데이터들 싹 다 긁어모아 분석하는 주인님** | Platform |

#### 한줄 요약

- 단말기가 깨어나서 기지국에 데이터 쏘고, 코어망한테 "나 이제 잔다" 허락 맡은 뒤, 서버가 데이터 수집하는 기본 구조다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **수신 창(Paging Window / Active Time)**: PSM이나 eDRX로 기절해 있다가 잠깐 눈 떠서, "서버가 나 불렀나?" 하고 통신사 삐삐(Paging)를 기다리는 짧은 시간이다.

</details>

```text
[ IoT 단말 데이터 전송 및 겨울잠 십자포화 흐름 ]

┌──────────────────────────────┐
│ 1. [통신망 스펙 선택]        │
│ (지하 수도 계량기네? $\to$ NB-IoT로 가자)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 2. [기지국 망 붙임 (Attach)] │
│ (단말: 나 10시간(PSM) 딥슬립 할 거임 허락 좀)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 3. [센서 데이터 발사 (업링크)]
│ (단말: 이번 달 수도 요금 데이터 여깄다 빵!)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 4. [수신 창 대기 (Active Time)]
│ (서버에서 답장 올까 봐 10초간 눈뜨고 대기함)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 5. [PSM 진입 (기절)]         │
│ (응 안 오네. 10시간 겨울잠 간다 수고!)
└──────────────────────────────┘
```

### 동작 원리

1. 통신망 선택: 단말이 고정형인지 이동형인지 체크하고 NB-IoT나 LTE-M 모뎀을 킨다.
2. 망 등록(Attach) 및 타이머 협상: 기지국에 붙으면서 코어망(MME)과 PSM/eDRX 수면 타이머를 합의함.
3. 데이터 전송: 모은 데이터를 확 쏴버림 (안 닿으면 CE 반복 전송으로 뇌절해서 쏨).
4. 수신 창(Active Time) 대기: 서버가 "펌프 좀 꺼라" 하고 명령 내릴까 봐 잠깐 눈뜨고 삐삐(Paging) 기다림.
5. PSM 진입: 아무 일 없으면 무선 모뎀 전원을 아예 뽑아버리고 타겟 시간까지 겨울잠에 들어감.

#### 한줄 요약

- 10시간 자고 $\to$ 1초 눈 떠서 데이터 쏘고 $\to$ 10초 답장 기다리다가 $\to$ 다시 10시간 기절하는 좀비 같은 흐름이다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **핸드오버(Handover)**: 자동차가 기지국 사이를 넘어갈 때, 와이파이 끊기듯 안 끊기고 전파를 부드럽게 토스해 주는 이동성 기술이다.

</details>

| 구분 | **NB-IoT (고정형 짠돌이)** | **LTE-M (이동형 적당충)** |
|:---|:---|:---|
| 비유 및 핵심 특징 | 맨홀 밑에서 **10년 버티는 짠돌이 좀비** | 택배 트럭 타고 다니며 **전화도 하는 인싸** |
| 주파수 대역폭 | **180kHz** (머리카락 굵기 초협대역 실핏줄) | **1.4MHz** (그래도 나름 넓직한 도로) |
| 기지국 핸드오버 | **미지원** (이동하면 통신 다 찢어지고 끊어짐) | **지원** (100km/h로 고속도로 달려도 안 끊어짐) |
| 음성 통화 (VoLTE) | **절대 불가** (텍스트 쏘기도 벅참) | **지원 가능** (응급 호출기나 키즈 워치에서 씀) |
| 주력 사용처 | **지하 수도검침, 고정형 주차장 꿀자리 센서** | **물류 트럭 화물 추적, 미아 방지 펫 트래커** |
| 커버리지 (침투력)| **164 dB** (지하 3층 벙커 콘크리트 쌉가능) | **155.7 dB** (건물 안쪽 정도만 파고듦) |

#### 한줄 요약

- 안 움직이고 지하에 처박힌 놈은 무조건 NB-IoT 달고, 돌아다니면서 음성 통화도 찔끔 해야 하면 LTE-M 다는 게 국룰이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **반복 전송 (Repetition/CE)**: 지하 깊은 곳에 전파가 닿을 랑 말 랑 할 때, 기지국이 알아먹을 때까지 똑같은 패킷을 수십, 수백 번 뇌절해서 쏴버리는 무식하지만 확실한 커버리지 확장법이다.

</details>

| 장애/위험 요소 | 원인 분석 | 실무 대책 및 해결방안 | 기대 효과 |
|:---|:---|:---|:---|
| 배터리 10년 간다더니 **6개월 만에 다 터져서 죽음** | 지하 너무 깊어서 단말기가 뚫릴 때까지 **수십 번 반복 전송(CE)** 하느라 배터리 살살 녹음 | 안테나를 밖으로 빼거나, 기지국 안테나 각도 틀어서 **반복 횟수(Repetition) 강제로 줄임** | 불필요한 노가다 전송 막고 배터리 10년 수명 사수 |
| 서버에서 원격 조명 끄라 했는데 **단말기가 대답이 없음** | 단말기가 **겨울잠(PSM)** 자느라 서버의 하향 호출(Paging)을 완전히 씹고 무시함 | 제어가 자주 필요한 단말은 PSM 아예 끄고 **쪽잠(eDRX) 주기를 팍 줄여버림** | 서버 명령 수초 이내에 깍듯하게 수신 완료 |
| 전동 킥보드에 NB-IoT 달았더니 **옆 동네 넘어가자마자 뻗음** | NB-IoT는 킥보드가 달릴 때 **기지국 이관(핸드오버)** 을 못 해줘서 망이 그대로 찢어짐 | 고정형 NB-IoT 버리고 이동성 짱짱하게 지원하는 **LTE-M 모뎀으로 즉각 교체함** | 시속 100km 트럭에 달아도 세션 안 끊김 |

#### 한줄 요약

- 반복 전송 뇌절하다 배터리 터지지 않게 안테나 빼주고, 응답 빨라야 하면 겨울잠(PSM) 재우지 말고, 굴러다니면 얌전히 LTE-M 달아라.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- (상단 참조)

</details>

- 센서 데이터 통신에 고비용/고전력 스마트폰 LTE 모뎀을 쓰는 낭비를 막기 위해, 고정형 짠돌이 **NB-IoT** 및 이동형 범용 **LTE-M** 양대 축으로 하는 셀룰러 LPWAN 기조 확립함

#### 한줄 요약

- 스마트폰 중심의 통신망에서 소외됐던 '사물'들을 면허 대역으로 강력히 끌어올린 NB-IoT와 LTE-M은 진정한 IoT 대중화를 연 일등 공신이다.
