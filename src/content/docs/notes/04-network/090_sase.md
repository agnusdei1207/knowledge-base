## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **SASE(Secure Access Service Edge)**: Gartner가 제안한 클라우드 보안 아키텍처로, 광역 소프트웨어 정의 네트워크(SD-WAN) 기능과 클라우드 네이티브 보안 서비스(SSE: CASB, SWG, ZTNA, FWaaS)를 글로벌 분산 엣지 PoP(Point of Presence) 상에서 단일 서비스로 융합하여 제공하는 프레임워크.
- **SSE(Security Service Edge)**: SASE 프레임워크에서 네트워크 인프라(SD-WAN) 계층을 분리하고, 클라우드 보안 핵심 요소인 CASB, SWG, ZTNA, FWaaS 기능에 집중한 통합 보안 서비스 스택.

</details>

- 정의/개념: 엔터프라이즈의 WAN 엣지 연결성 제어(**SD-WAN**)와 제로 트러스트 보안 통제(**SSE: CASB, SWG, ZTNA**)를 지리적으로 분산된 **글로벌 클라우드 엣지 PoP** 에 통합하여, 위치에 구애받지 않고 일관된 보안 정책과 저지연 고성능 접속을 제공하는 **클라우드 네이티브 네트워크 보안 융합 아키텍처**
- 배경/필요성: SaaS 도입 확산과 원격/재택근무의 일상화로 인해 모든 트래픽을 본사 데이터센터로 집중시켜 검사하는 전통적 트래픽 헤어피닝(Hairpinning / Tromboning)의 병목 및 지연 문제를 해결할 요구

#### 한줄 요약
- SD-WAN 네트워크와 SSE 보안 기능을 글로벌 클라우드 엣지 PoP에 융합하여 제로 트러스트 통합 접근 통제를 실현한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **트래픽 헤어피닝(Hairpinning)**: 지사나 재택 사용자가 외부 클라우드 SaaS(예: Office 365, AWS)에 접속할 때 보안 검사를 위해 트래픽이 본사 데이터센터로 우회했다가 다시 외부로 나가는 비효율적 경로 굴절 현상.
- **단일 통제 평면(Single Control Plane)**: 네트워크 라우팅 정책(QoS, 경로 선택)과 보안 접근 정책(DLP, 인증, 인가)을 단일 클라우드 콘솔에서 통합 정의하고 전 세계 PoP로 실시간 배포하는 중앙 집중 관리 체계.

</details>

- **클라우드 엣지 기반 저지연 처리**: 전 세계 수백 개 분산 PoP에서 트래픽을 인입 즉시 단일 패스(Single-Pass Parallel Processing)로 검사하여 지연 시간 최소화
- **완전한 제로 트러스트(ZTNA) 구현**: 네트워크 레벨의 광범위한 IP 접근을 차단하고 신원(Identity)과 단말 상태(Context) 기반의 L7 마이크로 세그멘테이션 집행
- **통합 정책 및 단일 에이전트(Single Agent)**: 엔드포인트에 단 하나의 경량 에이전트를 설치하여 VPN, DLP, SWG, ZTNA 기능을 통합 제어

#### 한줄 요약
- 클라우드 엣지 단일 패스 검사, ZTNA 기반 L7 세분화 통제, 통합 관리 평면을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **CASB(Cloud Access Security Broker)**: 사용자와 클라우드 서비스 사이에서 데이터 접근 통제, DLP(데이터 유출 방지), 섀도우 IT(Shadow IT) 탐지 및 암호화를 수행하는 보안 게이트웨이.
- **SWG(Secure Web Gateway)**: URL 필터링, 악성코드 검사, SSL/TLS 가시성 확보(SSL 복호화)를 통해 사용자의 외부 웹 서핑을 보호하는 프록시.
- **ZTNA(Zero Trust Network Access)**: 사내 프라이빗 애플리케이션 접속 시 네트워크를 은폐(Dark Cloud)하고, 인증된 사용자 및 기기에만 해당 앱으로의 암호화 터널을 일대일 연결하는 제로 트러스트 솔루션.

</details>

```text
[ 사용자 / 재택 단말 / 지사 Branch ]
 ├─ 단일 통합 에이전트 (Single Agent)
 └─ SD-WAN 엣지 라우터 ──▶ (최적 지연 시간 기준 글로벌 근접 PoP 자동 선택)
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ [ 글로벌 분산 SASE 엣지 PoP (Point of Presence) ]                        │
│  ├─ [ 네트워크 계층 (SD-WAN) ] ── (동적 경로 최적화, QoS, 멀티클라우드 연동)│
│  └─ [ 보안 서비스 계층 (SSE) ]                                         │
│       ├─ SWG (Secure Web Gateway): 악성 URL/파일 검사, SSL 복호화        │
│       ├─ CASB: SaaS 앱 가시성 확보, Shadow IT 차단, 클라우드 DLP       │
│       ├─ ZTNA: 신원 기반 사내 애플리케이션 일대일 마이크로 터널링       │
│       └─ FWaaS: L3~L7 클라우드 차세대 방화벽 및 침입 방지 (IPS)         │
└───────────────────────────────────┬─────────────────────────────────────┘
                                    │
        ┌───────────────────────────┴───────────────────────────┐
        ▼                                                       ▼
[ 외부 SaaS / 퍼블릭 클라우드 ]                         [ 엔터프라이즈 사내 인프라 ]
 (M365, Salesforce, AWS VPC)                             (On-Premise DC, 프라이빗 앱)
```

선의 의미: 사용자가 근접 SASE PoP로 접속하여 SD-WAN 경로 최적화와 SSE 보안 검사를 단일 패스로 통과한 후 대상 리소스로 안전하게 분기되는 구조

| 구성요소 | 핵심 책임 및 역할 | 비고 |
|:---|:---|:---|
| **SD-WAN** | 인터넷, MPLS, 5G 회선을 가상화하여 앱 품질 기반 최적 경로 라우팅 | Network as a Service |
| **SWG** | 웹 트래픽 암복호화 검사, 악성 사이트 차단 및 웹 바이러스 필터링 | L7 Web Security |
| **CASB** | 인가/비인가 SaaS 모니터링, API 연동 데이터 감사, 클라우드 DLP 통제 | Cloud Security |
| **ZTNA** | SDP(소프트웨어 정의 경계) 기반 인프라 은폐 및 앱 단위 세분화 접근 제어 | Zero Trust Edge |
| **FWaaS** | 클라우드 상에서 구동되는 탄력적 L7 차세대 방화벽 및 IPS 침입 방지 | Firewall as a Service |

#### 한줄 요약
- SD-WAN, SWG, CASB, ZTNA, FWaaS가 글로벌 PoP 상에서 단일 패스 구조로 결합한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **지속적 적응형 위험 평가(CARTA / Continuous Assessment)**: 접속 인가 시점뿐만 아니라 세션이 유지되는 동안에도 사용자의 이상 행동(대용량 다운로드, 위치 급변)을 실시간 재평가하여 권한을 동적 회수하는 메커니즘.

</details>

```text
1. 사용자가 단일 에이전트를 통해 네트워크 트래픽 발생 ➔ SD-WAN이 초저지연 근접 PoP으로 연결
            │
            ▼
2. PoP 내 IdP(신원 제공자) 연동 MFA 인증 및 엔드포인트 단말 보안 상태(OS 패치, EDR) 동시 검증
            │
            ▼
3. 목적지 트래픽 유형에 따라 단일 패스(Single-Pass) 보안 파이프라인 집행
            ├─ [일반 웹 트래픽] ➔ SWG 경유 악성 URL 검사 및 파일 샌드박싱
            ├─ [SaaS 클라우드] ➔ CASB 경유 인가 여부(Sanctioned) 및 DLP 검사
            └─ [사내 프라이빗 앱] ➔ ZTNA 컨트롤러를 통한 일대일 세션 중계 (인프라 은폐)
            │
            ▼
4. 세션 진행 중 비정상 행위(CARTA) 모니터링 ➔ 이상 징후 감지 시 세션 즉각 차단 및 격리
```

**동작 원리**

1. **근접 PoP 인입**: 애니캐스트(Anycast) 라우팅을 통해 물리적으로 가장 가까운 SASE 데이터센터 연결
2. **신원 및 맥락 평가**: 사용자 역할, 접속 위치, 단말 컴플라이언스(보안 패치 여부) 다차원 평가
3. **단일 패스 병렬 검사**: 트래픽을 여러 번 복호화하지 않고 단 1회 복호화하여 SWG, CASB, IPS 엔진 동시 적용
4. **목적지 직접 송출**: 보안 검사를 마친 패킷을 퍼블릭 백본 또는 전용 백본망을 통해 목적지로 직결
5. **동적 세션 관리**: 위험 점수(Risk Score) 상승 시 즉시 스텝업(Step-up) 2차 인증 요구 또는 강제 로그아웃

#### 한줄 요약
- 근접 PoP 인입, 신원/맥락 인증, 단일 패스 보안 검사, 목적지 직결, 실시간 위험 재평가 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **레거시 VPN vs SSE vs SASE**: 본사 중앙 집중형 헤어핀 방식, 보안 기능 중심 클라우드화, 네트워크와 보안의 완전한 클라우드 네이티브 융합 비교.

</details>

| 비교 항목 | 전통적 본사 중심 보안 (레거시 VPN) | 보안 서비스 엣지 (SSE) | 보안 액세스 서비스 엣지 (SASE) |
|:---|:---|:---|:---|
| **트래픽 경로** | 본사 데이터센터 우회 (헤어피닝) | 사용자 $\rightarrow$ 클라우드 보안 PoP | **사용자 $\rightarrow$ SD-WAN 최적화 PoP $\rightarrow$ 목적지** |
| **통합 범위** | 온프레미스 하드웨어 방화벽 개별 운영| **보안 서비스(SWG/CASB/ZTNA) 통합** | **네트워크(SD-WAN) + 보안(SSE) 완전 통합** |
| **접근 제어 모델** | 서브넷/VLAN 기반 광범위 네트워크 접속 | **신원 및 앱 기반 제로 트러스트(ZTNA)**| **신원, 단말, 네트워크 경로 통합 제어** |
| **성능 및 지연** | 원격 접속자 증가 시 본사 회선 병목 | 클라우드 직결로 인터넷 지연 개선 | **SD-WAN 동적 경로 제어로 최상의 QoS 보장** |
| **도입 및 관리** | 고비용 하드웨어 구축 및 분산 관리 | 보안 스택 클라우드 전환에 최적 | **전사 디지털 전환(DX)의 최종 지향점** |

#### 한줄 요약
- 레거시는 본사 병목 유발, SSE는 보안 기능 클라우드화, SASE는 네트워크와 보안의 완전한 통합 완성형이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **PoP 장애 및 SLA 저하**: SASE 벤더의 특정 지역 데이터센터(PoP) 장애 시 해당 지역 지사 및 사용자의 전사 인터넷 연결이 전면 마비되는 단일 실패점(SPOF) 리스크.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 특정 지역 SASE PoP 장애 시 해당 권역 지사 및 사용자의 전사 네트워크 단절 | SD-WAN 기반 **인접 다중 PoP 자동 헬스체크 및 무중단 서브초 페일오버** | PoP 단일 장애점(SPOF) 제거 및 99.999% 글로벌 가용성 보장 |
| 네트워크 팀(SD-WAN)과 보안 팀(SSE) 간의 정책 불일치로 인한 오차단 발생 | SASE **단일 콘솔(Single Pane of Glass) 기반 통합 정책 거버넌스** 수립 | 정책 충돌 제거, 관리 오버헤드 50% 절감 및 신속한 룰 배포 |
| 레거시 온프레미스 VPN 허용으로 인한 감염 단말의 사내망 횡적 확산 위협 | VPN 전면 폐기 및 **ZTNA 기반 앱 단위 마이크로 세그멘테이션** 전환 | 감염 PC의 타 사내 시스템 접근 원천 차단 및 공격 표면 90% 축소 |

#### 한줄 요약
- 다중 PoP 페일오버로 가용성을 확보하고, 단일 콘솔로 정책 충돌을 방지하며, ZTNA로 횡적 확산을 차단한다.

## Ⅶ. 결론

- 멀티클라우드와 하이브리드 워크 환경의 확산에 대응하여 엔터프라이즈 인프라를 보호하기 위해 **SD-WAN과 SSE를 결합한 SASE 표준 아키텍처**를 전면 도입하되, 글로벌 운영의 안정성을 보장하기 위해 **다중 PoP 이중화**, **단일 콘솔 기반 통합 정책 운영**, **ZTNA 연속 신원 검증**을 통합 구축하여 안전하고 민첩한 제로 트러스트 클라우드 네트워크를 완성

#### 한줄 요약
- SD-WAN과 SSE를 통합한 SASE 아키텍처를 통해 제로 트러스트 기반 클라우드 네이티브 네트워크를 구현한다.
