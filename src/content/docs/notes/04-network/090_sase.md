## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **보안 액세스 서비스 에지(Secure Access Service Edge, SASE)**: SD-WAN 연결과 SSE 보안을 PoP에서 통합 제공하는 구조이다.
- **소프트웨어 정의 광역망(Software-Defined Wide Area Network, SD-WAN)**: 응용•회선 품질에 따라 광역 경로를 선택하는 기술이다.
- **보안 서비스 에지(Security Service Edge, SSE)**: 웹•클라우드•사설 응용 보안을 클라우드에서 제공하는 구조이다.
- **접속 거점(Point of Presence, PoP)**: 사용자와 가까운 위치에서 연결•보안을 처리하는 사업자 거점이다.

</details>

- 정의/개념: **SASE**는 **SD-WAN** 연결과 **SSE** 보안을 **PoP**에서 결합한 구조이다.
- 배경/필요성: 본사 우회 구조는 지연•회선 병목•정책 편차를 유발한다.

#### 한줄 요약

- 사용자가 어디에 있든 가까운 거점으로 연결해 빠른 경로와 같은 보안 규칙을 한 번에 적용한다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **통합 정책**: 신원•단말•응용 맥락을 바탕으로 경로 선택과 접근•자료 보안을 함께 결정하는 규칙이다.

</details>

- **통합 정책**은 신원•단말•응용 맥락으로 경로 선택과 접근•자료 보안을 함께 결정한다.

#### 한줄 요약

- 지사마다 장비를 따로 관리하지 않아도 되지만 가까운 거점의 용량과 장애 대비가 사용자 품질을 좌우한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **클라우드 접근 보안 중개(Cloud Access Security Broker, CASB)**: 클라우드 사용과 자료 보안을 통제하는 기능이다.
- **보안 웹 게이트웨이(Secure Web Gateway, SWG)**: 웹 요청과 콘텐츠를 검사하는 보안 기능이다.
- **제로 트러스트 네트워크 액세스(Zero Trust Network Access, ZTNA)**: 신원•단말 맥락으로 허용한 응용만 연결하는 방식이다.

</details>

- PoP에서 **CASB**, **SWG**, **ZTNA** 정책을 실행해 클라우드•웹•사설 응용 접근을 통제한다.

```text
SASE
├─ 사용자•지사 엣지
├─ SD-WAN 연결부
├─ PoP•SSE 보안부
├─ 통합 정책 제어기
└─ 인터넷•클라우드•사설 응용
```

선의 의미: 사용자•지사 엣지에서 목적 응용까지 SD-WAN과 PoP•SSE가 연결•보안 경계를 구성하고, 통합 정책 제어기가 두 집행부에 공통 정책을 제공하는 정적 SASE 구조이다.

| 구성요소 | 책임 |
|:---|:---|
| 사용자•지사 엣지 | 신원•단말•회선•응용 정보 수집 |
| SD-WAN 연결부 | 품질•응용 정책 기반 경로 선택 |
| PoP•SSE 보안부 | SWG•CASB•ZTNA 정책 실행 |
| 통합 정책 제어기 | 연결•보안 규칙 일관 배포 |
| 인터넷•클라우드•사설 응용 | 정책 통과 사용자의 목적 자원 |

#### 한줄 요약

- 엣지가 가까운 거점을 골라 트래픽을 보내면 그곳에서 웹과 클라우드, 사설 앱 정책을 검사한 뒤 목적지로 전달한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **품질 기반 PoP 선택**: 지연•손실•용량으로 사용자 트래픽을 처리할 거점을 선택하는 과정이다.
- **세션 위험 재평가**: 접속 중 행위와 맥락 변화를 반영해 기존 허용 수준을 다시 판단하는 절차이다.
- **품질 기반 PoP 접속**: 측정 품질이 가장 적합한 거점으로 사용자 세션을 연결하는 단계이다.
- **통합 정책 조회**: 경로•접근•자료 규칙을 신원•단말•응용 맥락과 대조하는 단계이다.
- **허용 응용 연결**: 보안 검사를 통과한 사용자에게 허용한 개별 응용만 연결하는 단계이다.
- **세션 행위 전달**: 접속 중 응용 이용 행위와 맥락 변화를 거점에 계속 제공하는 단계이다.
- **세션 위험 재평가 요청**: 새 행위와 맥락으로 기존 권한의 유지•축소•차단을 다시 판단하는 단계이다.

</details>

```text
접속 요청
      │
      ▼
1. 품질 기반 PoP 접속
      │
      ▼
2. 통합 정책 조회
      │
      ▼
신원•단말•응용 맥락 허용 여부
      ├─ 거부: 접속 차단
      └─ 허용: 3. 허용 응용 연결
                         │
                         ▼
반복 범위: 세션 유지 중 4~5단계
                         │
                         ▼
4. 세션 행위 전달
                         │
                         ▼
5. 세션 위험 재평가 요청
                         ├─ 위험 증가: 권한 축소•차단
                         └─ 위험 유지: 세션 지속
```

### 동작 원리

1. **품질 기반 PoP 접속**: **품질 기반 PoP 접속** 단계에서 **품질 기반 PoP 선택**으로 거점을 정한다.
2. **통합 정책 조회**: **통합 정책 조회** 단계에서 경로•접근•자료 규칙을 결합한다.
3. **허용 응용 연결**: **허용 응용 연결** 단계에서 ZTNA•SWG•CASB 검사 뒤 응용에 전달한다.
4. **세션 행위 전달**: **세션 행위 전달** 단계에서 응용 이용 행위를 지속 제공한다.
5. **세션 위험 재평가 요청**: **세션 위험 재평가 요청** 단계에서 **세션 위험 재평가**를 실행한다.

#### 한줄 요약

- 사용자와 단말을 확인해 가장 좋은 거점으로 보내고 같은 곳에서 보안 검사를 마친 뒤 허용된 응용에만 연결한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **본사 중심 보안**: 지사•원격 트래픽을 보안 검사를 위해 본사 데이터센터까지 우회시키는 구조이다.
- **광역망(Wide Area Network, WAN)**: 넓은 지역의 지점과 데이터센터를 연결하는 네트워크이다.

</details>

| 접속 보안 구조 | SASE | SSE | 본사 중심 보안 |
|:---|:---|:---|:---|
| 적용 기준 | **SASE**는 지사•원격의 연결•보안 통합 | **SSE**는 기존 **WAN** 유지•보안만 전환 | **본사 중심 보안**은 소수 지점•본사 중심 서비스 |
| 핵심 특징 | SD-WAN•SSE 단일 정책 | 클라우드 보안 기능 통합 | 본사 장비 우회 검사 |
| 한계 | 사업자•PoP 품질 의존 | 연결•보안 정책 분리 | 우회 지연•본사 회선 병목 |

> 요약: 연결 통합 범위•PoP 의존성으로 방식을 선택한다.

#### 한줄 요약

- 연결과 보안을 함께 바꾸면 SASE, 보안만 클라우드화하면 SSE, 본사 중심 업무가 작으면 기존 우회 방식을 고려한다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **자동 경로 전환**: 현재 PoP 장애나 품질 저하를 감지해 다른 거점으로 접속 경로를 바꾸는 기능이다.
- **응용 단위 권한**: 내부 네트워크 전체가 아니라 검증된 사용자에게 허용한 개별 응용만 연결하는 권한이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| PoP 장애의 접속 품질 급락 | 다중 PoP와 **자동 경로 전환** | 지연과 서비스 중단 감소 |
| 연결•보안의 정책 불일치 | 단일 정책 모델•배포 검증 | 우회 허용과 운영 편차 축소 |
| 원격 사용자의 과도한 망 접근 | ZTNA 기반 **응용 단위 권한** 적용 | 횡적 이동과 노출 범위 감소 |

#### 한줄 요약

- 원격 개발자가 SASE PoP에서 신원과 단말 보안 상태를 검증받은 뒤 사내망 전체가 아닌 소스 저장소에만 접속하게 한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **전환 범위**: WAN 연결•보안을 SASE로 바꿀지 SSE만 도입할지 정하는 범위이다.

</details>

- **전환 범위**에서 연결•보안 동시 전환은 **SASE**, WAN 유지•보안 전환은 **SSE**를 선택한다.

#### 한줄 요약

- SASE는 기능 목록보다 사용자가 거치는 거점의 품질과 그곳에서 연결•보안 정책이 함께 적용되는지를 검증해야 한다.
