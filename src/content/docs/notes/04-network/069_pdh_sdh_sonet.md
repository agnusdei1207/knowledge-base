## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **PDH (Plesiochronous Digital Hierarchy)**: 개별 노드가 독립 클럭을 사용하여 주파수 편차를 비트 채움(Bit Stuffing)으로 보정하는 준동기식 다중화 계위.
- **SDH/SONET**: 망 전체가 단일 1차 참조 원자시계(PRC)에 동기화되어 포인터(Pointer)로 직접 분기결합(Direct Add-Drop)을 수행하는 동기식 광전송 표준.

</details>

- 정의/개념: 음성 및 저속 데이터를 광선로로 고속 전송하기 위해 **준동기식 비트 채움(PDH)에서 전사 동기화 기반 바이트 포인터 다중화(SDH/SONET)로 진화한 광전송 계위**
- 배경/필요성: PDH의 독립 클럭 편차 및 비트 채움 한계로 인한 **특정 채널 인출 시 전체 다단 역다중화 필수, OAM 오버헤드 부재 및 50ms 선로 보호절체 불가**

#### 한줄 요약
- 바이트 단위 직접 분기결합(ADM), 포인터 위상 동기화, K1/K2 기반 50ms 자동 보호 절체(APS)를 제공한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **Direct Add-Drop (직접 분기결합)**: 고속 STM-1/OC-3 프레임을 역다중화하여 해체하지 않고 포인터가 지시하는 바이트 위치에서 특정 저속 채널(E1/DS1)을 즉시 인출·삽입하는 기술.
- **APS (Automatic Protection Switching)**: 광케이블 단선 시 K1/K2 오버헤드 바이트를 교환하여 50ms 이내에 예비 링 경로로 자동 우회 절체하는 생존성 기법.

</details>

- **포인터(Pointer) 기반 직접 분기결합(ADM)**: 다단 역다중화 없이 **원하는 저속 신호(E1/DS3)를 즉각 인출 및 삽입**
- **강력한 유지보수 관리(OAM) 오버헤드**: 프레임 내 풍부한 오버헤드(SOH/POH)를 배치하여 종단간 회선 품질 실시간 감시
- **50ms 캐리어급 자동 보호 절체(APS)**: 광케이블 절단 시 **50ms 이내에 예비 링 경로로 무중단 트래픽 절체**

#### 한줄 요약
- 바이트 포인터 직접 분기결합, 풍부한 OAM 감시 오버헤드, 50ms 자동 보호 절체를 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **STM-1 Frame (155.52 Mbps)**: 125$\mu\text{s}$ 주기, 9행 270열(총 2,430바이트) 구조로 9열의 구간 오버헤드(SOH)와 261열의 페이로드(VC-4)로 구성.
- **ADM (Add-Drop Multiplexer)**: 광 링 토폴로지 중간에서 프레임을 해체하지 않고 특정 채널을 분기/결합하는 전송 장비.

</details>

```text
[SDH STM-1 프레임 구조 (125$\mu\text{s}$ 주기, 270열 × 9행 = 2,430 바이트)]
|-- Overhead Section (1~9열)
|   |-- RSOH (1~3행: 재생구간 오버헤드 - 프레임 정렬 A1/A2, 선로 감시 B1)
|   |-- AU-4 Pointer (4행: VC-4 가상 컨테이너 시작 바이트 오프셋 지시)
|   `-- MSOH (5~9행: 다중화구간 오버헤드 - 패리티 B2, 50ms APS 절체 바이트 K1/K2)
`-- Payload Section (10~270열, 261열 × 9행 = 2,349 바이트)
    `-- Virtual Container (VC-4: POH 경로 오버헤드 + 저속 매핑 데이터 E1 / DS3)
```

선의 의미: 125$\mu\text{s}$ 주기의 9행 구조 내에서 SOH 오버헤드와 포인터가 프레임 선두에 위치하여 가상 컨테이너(VC)를 정확히 동기 제어하는 구조

| 구성요소 | 핵심 엔지니어링 책임 | 주요 특징 |
|:---|:---|:---|
| **가상 컨테이너 (VC/SPE)** | 다양한 저속 신호(E1, DS3)를 표준 크기로 매핑하고 **종단간 품질(POH) 감시** | VC-12, VC-4 |
| **관리 단위 포인터 (AU)** | VC의 시작 위치 오프셋을 지시하여 **망 노드 간 클럭 위상 편차 흡수 보정** | AU-4 Pointer |
| **구간 오버헤드 (SOH)** | 프레임 정렬(A1/A2), **선로 오류 감시(B1/B2), 50ms 보호 절체(K1/K2) 수행** | RSOH, MSOH |
| **분기결합 다중화기 (ADM)**| 광선로 중간에서 **프레임 해체 없이 트래픽 Add/Drop 및 APS 절체 실행** | 링 토폴로지 핵심 |
| **디지털 교차연결기 (DXC)** | 대규모 중앙 국사에서 **다중화된 고속 VC 채널 간 상호 교차 스위칭** | 채널 라우팅 |

#### 한줄 요약
- VC 컨테이너, AU 포인터, SOH 오버헤드, ADM/DXC 장비가 결합된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Pointer Justification**: 송수신 클럭 위상 차이 발생 시 포인터 값을 1씩 가감하여 슬립(Slip) 없이 데이터를 수용하는 메커니즘.

</details>

```text
SDH 동기식 프레임 생성 및 APS 보호 절체 파이프라인
        │
   1. [가상 컨테이너 매핑] 저속 데이터(E1)에 POH를 결합하여 표준 VC-4 컨테이너 생성
        │
   2. [AU-4 포인터 정합] STM-1 프레임 내 VC-4의 시작 바이트 오프셋 위치를 포인터에 기록
        │
   3. [STM-1 프레임 송출] SOH(RSOH/MSOH) 오버헤드를 조립하여 155.52Mbps 광신호 방사
        │
   4. [중간 ADM 분기결합] 중간 국사 ADM이 포인터를 참조하여 특정 채널만 즉시 Add/Drop
        │
   ▼
5. [선로 단선 시 50ms APS] 광선로 절단 감지 시 K1/K2 바이트 기반 50ms 내 예비 링 경로 우회
```

#### 한줄 요약
- 컨테이너 매핑 → 포인터 정합 → STM 프레임 송출 → ADM 분기결합 → APS 50ms 절체 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **PDH (준동기식)** vs **SDH (동기식 글로벌 표준)** vs **SONET (동기식 북미 표준)**.

</details>

| 비교 항목 | PDH (준동기식 계위) | SDH (동기식 디지털 계위) | SONET (동기식 광통신망) |
|:---|:---|:---|:---|
| **망 동기화 방식** | **준동기식 (개별 노드 독립 클럭)** | **완전 동기식 (단일 1차 참조 원자시계)** | **완전 동기식 (단일 1차 참조 원자시계)** |
| **클럭 편차 흡수** | **비트 채움 (Bit Stuffing)** | **바이트 포인터 (Pointer Justification)**| **바이트 포인터 (Pointer Justification)**|
| **채널 인출 방식** | **전체 다단 역다중화 필수 (비효율)**| **포인터 기반 직접 분기결합 (Add-Drop)**| **포인터 기반 직접 분기결합 (Add-Drop)**|
| **기본 전송 속도** | T1(1.544M) / E1(2.048M) 파편화 | **STM-1 (155.52 Mbps, 4배수 확장)** | **STS-1 / OC-1 (51.84 Mbps, 정수배 확장)**|
| **보호 절체 (APS)**| 미지원 또는 수 초 소요 | **K1/K2 바이트 기반 50ms 이내 절체** | **K1/K2 바이트 기반 50ms 이내 절체** |
| **표준화 기구** | ITU-T (권고 G.702) | ITU-T (권고 G.707) | ANSI (T1.105) |

#### 한줄 요약
- PDH는 비트 채움과 다단 역다중화를 사용하고, SDH/SONET은 바이트 포인터와 직접 분기결합을 사용한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **BLSR (Bidirectional Line Switched Ring)**: 2선/4선 광 링 토폴로지에서 선로 단선 시 50ms 이내에 반대편 광심선으로 트래픽을 자동 루프백 우회하는 보호 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 링 토폴로지 주 광케이블 단선 시 백본망 대규모 트래픽 마비 | **`2선/4선 양방향 라인 절체 링(BLSR)` 광 링 토폴로지 구축** | 선로 단선 시 50ms 이내 예비 링 자동 절체 및 무중단 유지 |
| 빈번한 포인터 가감(Justification) 연산으로 인한 역다중화 지터 누적 | 최상위 **`원자시계(PRC) 기반 망 동기망(BITS)` 및 디지터 버퍼** | 클럭 편차 원천 억제 및 ITU-T G.823 지터 한계 충족 |
| 북미 SONET(OC-3)과 글로벌 SDH(STM-1) 해저 광망 연동 시 불일치 | **상호 연동 게이트웨이(`AU-3/AU-4 변환 매퍼`) 전송 장비 구축** | 이종 광전송 계위 간 무손실 페이로드 인터워킹 보증 |
| 비동기 IP 패킷 전송 시 고정 TDM 타임슬롯 대역폭 낭비 | **차세대 패킷 광전송망(`OTN / MPLS-TP`)으로 단계적 고도화** | 가변 대역폭 효율적 수용 및 100G/400G 패킷 전송 실현 |

#### 한줄 요약
- BLSR로 50ms 보호 절체를 보장하고, BITS 동기망으로 포인터 지터를 방지하며, OTN으로 패킷망을 고도화한다.

## Ⅶ. 결론

- 국가 기간 통신망의 초고속·고신뢰 광전송을 달성하기 위해 **완전 동기식 SDH/SONET 아키텍처와 포인터 기반 직접 분기결합(ADM) 기술을 확립**하였으며, 폭증하는 데이터 트래픽 수용을 위해 현대 백본망은 SDH 프레임을 파장 단위로 다중화하는 **WDM/DWDM 및 패킷 전달망인 OTN(광수송망)**으로 고도화 완성

#### 한줄 요약
- SDH/SONET은 바이트 포인터 직접 분기결합과 50ms 보호 절체를 통해 고신뢰 동기식 광전송망을 실현한 핵심 기반 기술이다.
