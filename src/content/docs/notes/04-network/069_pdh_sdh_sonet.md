## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **PDH(Plesiochronous Digital Hierarchy)**: 개별 망 노드가 독립된 로컬 클럭 발진기를 사용하여 주파수 편차가 존재하며, 클럭 차이를 보정하기 위해 비트 채움(Bit Stuffing) 방식을 적용하는 준동기식 디지털 다중화 계위.
- **SDH(Synchronous Digital Hierarchy) 및 SONET(Synchronous Optical Network)**: 망 전체가 단일 1차 참조 클럭(PRC, 원자시계)에 동기화되어, 포인터(Pointer) 기법을 통해 다단 역다중화 없이 직접 분기결합(Direct Add-Drop)을 수행하는 ITU-T/ANSI 표준 동기식 광전송 기술.

</details>

- 정의/개념: 음성(DS0/E1) 및 저속 데이터 채널들을 단계별로 결합하여 광선로를 통해 고속 전송하기 위한 시분할 다중화(TDM) 표준으로, **준동기식 비트 채움(PDH)** 에서 **망 동기화 기반 바이트 포인터 다중화(SDH/SONET)** 로 진화한 기간망 전송 체계
- 배경/필요성: PDH에서 특정 저속 채널을 추출하기 위해 전체 고속 프레임을 최하위 계위까지 단계별로 역다중화해야 하는 구조적 비효율을 극복하고, OAM 관리 기능과 50ms 이내 자동 선로 절체(APS)를 실현할 요구

#### 한줄 요약
- 준동기식 PDH의 비트 채움 한계를 극복하고, 완전 동기화 및 포인터 기법으로 직접 분기결합(Add-Drop)을 실현한 광전송 계위이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **포인터(Pointer) 메커니즘**: 가상 컨테이너(VC)의 시작 위치가 동기식 전송 모듈(STM) 프레임 페이로드 내에서 이동할 때, 프레임 전체를 재구성하지 않고 포인터 바이트의 주소값(오프셋)만을 가감(Positive/Negative Justification)하여 위상 차를 흡수하는 기술.
- **직접 분기결합(Direct Add-Drop)**: 고속 동기식 프레임(STM-N)을 하위 신호로 전면 해체하지 않고, 포인터 주소를 직접 참조하여 특정 VC(Virtual Container) 트래픽만을 즉각 인출(Drop)하거나 삽입(Add)하는 기능.

</details>

- **직접 바이트 다중화(Byte Interleaving)**: 고속 다중화 시 비트 단위가 아닌 8비트 바이트 단위로 인터리빙하여 프레임 구조의 투명성 확보
- **강력한 운영 및 유지보수(OAM) 오버헤드**: 프레임 내에 구간 오버헤드(SOH) 및 경로 오버헤드(POH)를 배정하여 실시간 선로 성능(BIP-8) 감시
- **50ms 무중단 자동 보호 절체(APS)**: 광케이블 단선 등 물리 장애 발생 시 링 토폴로지 상에서 50ms 이내에 예비 광경로(Protection Line)로 트래픽을 자동 우회

#### 한줄 요약
- 포인터 기반 직접 분기결합, 바이트 다중화, 50ms 자동 보호 절체(APS) 및 OAM 가시성을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **가상 컨테이너(Virtual Container, VC)**: 비동기 저속 신호(T1/E1)에 경로 오버헤드(POH)를 부착하여 표준 규격의 컨테이너로 패키징한 논리적 전송 단위.
- **분기결합 다중화기(Add-Drop Multiplexer, ADM)**: 광 링 네트워크의 중간 국사에 위치하여 고속 신호의 흐름을 방해하지 않고 특정 채널의 트래픽만을 추출 및 삽입하는 광전송 장비.

</details>

```text
[ SDH STM-1 프레임 구조 (125μs 주기, 270열 × 9행 = 2,430 바이트) ]
┌─────────────────┬────────────────────────────────────────────────────────┐
│ 1~9열 (오버헤드) │ 10~270열 (STM-1 페이로드 영역: 261열 × 9행 = 2,349B)    │
├─────────────────┼────────────────────────────────────────────────────────┤
│ RSOH (재생구간) │                                                        │
├─────────────────┤  가상 컨테이너 (VC-4: POH + 실제 사용자 데이터)       │
│ AU-4 Pointer    │  - 포인터 바이트가 VC-4의 시작 바이트 위치를 지시     │
├─────────────────┤                                                        │
│ MSOH (다중화구간)│                                                       │
└─────────────────┴────────────────────────────────────────────────────────┘
```

선의 의미: 125μs 주기의 9행 구조 내에서 SOH 오버헤드와 포인터가 프레임 선두에 위치하여 페이로드 내부의 가상 컨테이너(VC)를 정확히 동기 제어하는 프레임 배치

| 구성요소 | 책임 및 역할 | 비고 |
|:---|:---|:---|
| **가상 컨테이너 (VC/SPE)** | 다양한 저속 신호(E1, DS3)를 표준화된 크기로 매핑하고 E2E 품질(POH) 감시 | VC-12, VC-3, VC-4 |
| **관리 단위 포인터 (AU Pointer)**| VC의 시작 위치 오프셋을 지시하여 망 노드 간 클럭 위상 편차 흡수 | AU-4, AU-3 Pointer |
| **구간 오버헤드 (SOH)** | 프레임 정렬(A1, A2), 선로 오류 감시(B1, B2), 보호 절체(K1, K2) 수행 | RSOH, MSOH |
| **분기결합 다중화기 (ADM)**| 광선로 중간에서 프레임 해체 없이 트래픽 Add/Drop 및 APS 절체 실행 | 링 토폴로지 핵심 장비 |
| **디지털 교차연결기 (DXC)** | 대규모 중앙 국사에서 다중화된 고속 VC 채널 간 상호 교차 연결(라우팅) | 교차 스위칭 |

#### 한줄 요약
- VC 컨테이너, AU 포인터, SOH 오버헤드, ADM/DXC 장비가 결합하여 동기식 광전송망을 구성한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **자동 보호 절체(Automatic Protection Switching, APS)**: 광 수신단에서 신호 손실(LOS)이나 프레임 손실(LOF)을 감지했을 때 K1/K2 오버헤드 바이트를 교환하여 50ms 이내에 예비 링크로 절체하는 장애 복구 메커니즘.

</details>

```text
1. 하위 계위 데이터(E1/DS1) 인입 ➔ POH(경로 오버헤드)를 부착하여 규격 가상 컨테이너(VC) 생성
            │
            ▼
2. AU-4 포인터를 생성하여 STM-1 프레임 내 VC-4의 시작 바이트 위치(오프셋) 기록
            │
            ▼
3. 구간 오버헤드(RSOH/MSOH)를 결합하여 155.52Mbps STM-1 동기식 광 프레임 송출
            │
            ▼
4. 중간 국사 ADM 장비가 프레임 헤더를 실시간 파싱하며 특정 채널만 무중단 분기(Drop)/결합(Add)
            │
            ├─ [정상 전송] ➔ 목적지 수신 국사에서 포인터 참조 후 원본 데이터 복원
            ▼
5. [선로 단선 감지] ➔ K1/K2 바이트 기반 50ms 이내 단방향/양방향 링 보호 절체(APS) 수행
```

**동작 원리**

1. **컨테이너 매핑**: 저속 신호에 경로 오버헤드(POH)를 결합하여 VC-4 생성
2. **포인터 정합**: 망 발진기 클럭 차이로 인한 위상 이동을 AU 포인터 값 증감(Justification)으로 보정
3. **오버헤드 다중화**: 프레임 정렬 워드(A1/A2) 및 BIP-8 패리티를 부가하여 STM-1 프레임 조립
4. **선로 감시 및 분기**: 전송 중 ADM이 광신호를 통과시키며 포인터가 지시하는 채널만 즉각 인출
5. **무중단 절체**: 광선로 단선 시 하드웨어 레벨 인터럽트를 트리거하여 50ms 내 반대편 링으로 우회

#### 한줄 요약
- 컨테이너 매핑, 포인터 정합, STM 프레임 송출, ADM 분기결합, APS 50ms 절체 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **SDH(ITU-T 유럽/글로벌 표준) vs SONET(ANSI 북미 표준)**: 기본 전송 단위(SDH: STM-1 155.52Mbps, SONET: STS-1/OC-1 51.84Mbps)와 오버헤드 바이트 정의에서 미세한 차이를 갖는 동기식 전송 규격.

</details>

| 비교 항목 | PDH (준동기식 계위) | SDH (동기식 디지털 계위) | SONET (동기식 광통신망) |
|:---|:---|:---|:---|
| **망 동기화 방식** | **준동기식 (개별 노드 독립 클럭)** | **완전 동기식 (단일 1차 참조 원자시계)** | **완전 동기식 (단일 1차 참조 원자시계)** |
| **클럭 편차 흡수** | **비트 채움 (Bit Stuffing)** | **바이트 포인터 (Pointer Justification)** | **바이트 포인터 (Pointer Justification)** |
| **채널 인출 방식** | **전체 다단 역다중화 필수 (비효율)**| **포인터 기반 직접 분기결합 (Direct Add-Drop)** | **포인터 기반 직접 분기결합 (Direct Add-Drop)** |
| **기본 전송 속도** | T1(1.544M) / E1(2.048M) 파편화 | **STM-1 (155.52 Mbps, 4배수 확장)** | **STS-1 / OC-1 (51.84 Mbps, 정수배 확장)** |
| **보호 절체 (APS)** | 미지원 또는 수초 소요 | **K1/K2 바이트 기반 50ms 이내 절체** | **K1/K2 바이트 기반 50ms 이내 절체** |
| **표준화 기구** | ITU-T (권고 G.702) | ITU-T (권고 G.707) | ANSI (T1.105) |

#### 한줄 요약
- PDH는 비트 채움과 다단 역다중화를 사용하고, SDH/SONET은 바이트 포인터와 직접 분기결합을 사용한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **포인터 조정 지터(Pointer Justification Jitter)**: 망 노드 간 주파수 드리프트로 인해 포인터 바이트 값이 빈번하게 가감될 때 역다중화 출력 신호에 발생하는 고유한 위상 지터.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 링 토폴로지 주 광케이블 물리적 절단 사고 시 통신 백본 대규모 장애 | **2선/4선 양방향 라인 절체 링(BLSR/MS-SPRing)** 구축 | 선로 단선 시 50ms 이내 예비 링 자동 절체 및 무중단 유지 |
| 빈번한 포인터 가감(Justification) 연산으로 인한 역다중화 출력 신호 지터 누적 | 최상위 **원자시계(PRC) 기반 망 동기망(BITS)** 및 디지터(De-jitter) 버퍼 구축 | 클럭 편차 원천 억제 및 ITU-T G.823 규격 지터 한계 만족 |
| 북미 SONET(OC-3)과 글로벌 SDH(STM-1) 해저 광망 연동 시 프레임 불일치 | **상호 연동 게이트웨이(AU-3/AU-4 변환 매퍼)** 전송 장비 구축 | 이종 광전송 계위 간 무손실 페이로드 인터워킹 보증 |

#### 한줄 요약
- BLSR로 50ms 보호 절체를 보장하고, BITS 동기망으로 포인터 지터를 방지하며, 게이트웨이 매퍼로 SONET/SDH를 연동한다.

## Ⅶ. 결론

- 국가 기간 통신망의 초고속·고신뢰 광전송을 달성하기 위해 **완전 동기식 SDH/SONET 아키텍처**와 **포인터 기반 직접 분기결합(ADM)** 기술을 확립하였으며, 폭증하는 데이터 트래픽 수용을 위해 현대 백본망은 SDH 프레임을 파장 단위로 다중화하는 **WDM/DWDM** 및 패킷 전달망인 **MPLS-TP/OTN(광수송망)** 으로 고도화 완료

#### 한줄 요약
- SDH/SONET 동기 계위와 50ms 보호 절체를 바탕으로 고신뢰 광전송 인프라를 완성한다.
