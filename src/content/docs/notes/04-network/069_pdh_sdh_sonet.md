## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **PDH (준동기식)**: 옛날 통신망에서 장비마다 시계(클럭)가 약간씩 달라서, 시간 안 맞을 때마다 땜빵용 쓰레기 비트(비트 채움)를 쑤셔 넣어서 억지로 박자를 맞추던 1세대 다중화 기술이다.
- **SDH / SONET (동기식 광통신)**: 국가 전체 기지국과 통신망을 원자시계로 100% 똑같이 핀트(동기화)를 맞추고, 중간에서 데이터를 마트료시카처럼 안 까고 쏙쏙 빼쓸 수 있게 만든 현대 광통신의 뼈대다. (SDH는 글로벌, SONET은 북미형)

</details>

- 정의: **PDH, SDH, SONET**은 느린 저속 데이터 여러 개를 묶어서 개빠른 광케이블 한 가닥에 태워 보내는 디지털 시분할 다중화(TDM Hierarchy) 광전송 표준 규격들이다.
- 배경: 1세대 **PDH**는 10GB 속도망에서 10MB짜리 데이터 하나 빼서 쓰려고 전체를 마트료시카처럼 다 뜯어고쳐야 하는 미친 뻘짓(다단 역다중화)이 필요해서, **중간에서 필요한 것만 쏙쏙 뺄 수 있는 절대 동기 기반의 SDH/SONET이 구원투수로 등장했다.**

#### 한줄 요약

- 자잘한 통신 데이터를 싹 모아서 거대한 광케이블에 실어 나르고, 필요한 중간 기지국에서 짐만 쏙 빼고 넣는 광통신 물류 시스템이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **비트 채움 (Bit Stuffing)**: PDH에서 서로 장비 간 박자가 안 맞아서 데이터 공간이 남으면, 멍청하게 쓸데없는 쓰레기 깡통 비트를 쑤셔 넣어서 억지로 박자를 맞추는 땜빵 기술이다.
- **포인터 (Pointer)**: SDH/SONET에서 "네 데이터는 100번째 칸부터 시작해!" 하고 쪽지(포인터)만 딱 남겨서, 박자가 틀어져도 쪽지 주소만 수정하면 전체 프레임을 해체 안 해도 되게 만든 핵심 치트키다.

</details>

- **다단 다중화의 저주 (PDH)**: 클럭이 안 맞아서 쓰레기 비트를 쑤셔 넣다 보니, 중간 국사에서 데이터 하나 빼려면 끝까지 역으로 다 해체해야 하는 비효율의 극치를 보여준다.
- **쪽지 기법 (SDH/SONET 포인터)**: 망 전체 시계를 똑같이 맞춘 상태에서 포인터(시작 주소)만 찝어주기 때문에, 다 해체할 필요 없이 1-Step으로 필요한 트래픽만 톨게이트에서 쏙 빼고 넣는다 (Direct Add-Drop).
- **유지보수(OAM) 끝판왕**: 관리용 오버헤드(헤더) 바이트를 낭낭하게 배정해서, 포크레인이 광케이블 끊어먹으면 0.05초(50ms) 만에 예비 회선으로 싹 돌려버리는 미친 생존력을 가졌다.

#### 한줄 요약

- 포인터 치트키 써서 필요한 짐만 달리는 트럭에서 쏙 빼고 넣으며, 선 끊어지면 50ms 만에 우회하는 광통신 표준이다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **VC (가상 컨테이너)**: 하위 데이터(E1 쪼가리 등)가 광망 트럭에 올라탈 때 포장되는 '규격화된 물류 컨테이너 박스'다.
- **ADM (분기결합 다중화기)**: 광케이블 링(Ring)을 도는 데이터 트럭에서, 짐을 다 안 내리고 멈추지도 않은 채로 필요한 컨테이너만 쏙 빼고(Drop) 새 짐을 쑤셔 넣는(Add) 기적의 톨게이트 장비다.

</details>

```text
[ 광통신 절대 동기 직관적 비교 구조 ]

[ 1. 가상 컨테이너 (VC/SPE) ] ── (자잘한 구형 데이터들을 규격 컨테이너 박스에 쑤셔 넣음)
      │
      ▼
[ 2. 포인터 (Pointer) ] ── (이 박스가 프레임 몇 번째 칸에 실렸는지 송장 붙임)
      │
      ▼
[ 3. 오버헤드 (SOH/POH) ] ── (파손/장애 대비해서 50ms 절체용 관리 헤더 잔뜩 붙임)
      │
      ▼
[ 4. ADM / DXC 전송 장비 ] ── (광케이블 돌면서 톨게이트에서 짐 쏙 빼고, 교차로에서 섞음)
```

| 구성요소 | 직관적 비교 책임 | 비고 |
|:---|:---|:---|
| **가상 컨테이너 (VC)** | 온갖 규격 다른 옛날 데이터들을 **똑같은 규격 박스로 통일해서 포장해버림** | Container |
| **포인터** | 마트료시카 뻘짓 안 하게 **박스 위치 주소만 딱 찍어주는 치트키** | Pointer |
| **구간 오버헤드 (SOH)** | 동기화 핀트 맞추고 **케이블 끊어지면 바로 우회 절체(APS)시키는 관리 헤더** | Overhead |
| **분기결합 장비 (ADM)**| 고속도로 안 막히게 **달리는 트럭에서 필요한 짐만 쏙 빼고 넣는 톨게이트** | Add-Drop |
| **디지털 교차기 (DXC)**| 대규모 국사에서 **트럭들 짐을 목적지에 맞게 싹 교차 분류해 주는 물류 허브** | Cross-Connect |

#### 한줄 요약

- 컨테이너에 담고(VC) $\to$ 송장 붙이고(포인터) $\to$ 헤더 달아서(SOH) $\to$ ADM 톨게이트 거치면서 짐을 나르는 물류 구조다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **보호 절체 (APS, Automatic Protection Switching)**: 포크레인이 메인 광케이블을 끊어먹었을 때, 오버헤드 통신으로 눈치채고 0.05초(50ms) 만에 링 반대편 예비 선로로 길을 돌려버리는 생명보험 기술이다.

</details>

```text
[ 다중화 물류 및 광전송 십자포화 흐름 ]

┌──────────────────────────────┐
│ 1. [컨테이너(VC) 패킹 및 포장]
│ (하위 데이터들을 VC 컨테이너 박스에 꽉꽉 쑤셔 넣음)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 2. [포인터(위치 주소) 및 송장 세팅]
│ (타이밍 좀 엇나가면 포인터 주소만 위아래로 수정함)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 3. [동기 프레임(STM/OC) 전송]
│ (관리 헤더 낭낭하게 달아서 거대 광케이블망으로 쏴버림)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 4. [오류/품질 감시 및 상태 체크]
│ (ADM 장비가 오버헤드 까보면서 광케이블 멀쩡한지 계속 잼)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 5. [짐 내리기(Drop) 또는 우회 절체(APS)]
│ (멀쩡하면 짐 빼고, 선 끊겼으면 50ms 만에 예비 선로로 우회 뚫음)
└──────────────────────────────┘
```

### 동작 원리

1. 패킹(매핑): 구식 데이터나 이더넷 트래픽을 가져와 경로 오버헤드(POH)와 함께 규격 컨테이너(VC/SPE)에 매핑함.
2. 포인터 보정: 망 원자시계와의 미세한 핀트 편차를 쓰레기 비트 대신 **포인터** 주소 숫자(증/감)로 쿨하게 보정함.
3. 광 프레임 전송: 구간 오버헤드(SOH)를 달아서 155Mbps(STM-1) 이상의 거대한 동기식 광파형으로 송출함.
4. 라인 감시: ADM/DXC 장비가 지나가는 프레임의 헤더(BIP-8)를 까보면서 에러나 단선 여부를 실시간 진단함.
5. 분기 및 절체: 평소엔 특정 짐만 쏙 빼고(Add-Drop), 포크레인 출몰 시 50ms 이내에 예비망으로 **보호 절체(APS)** 를 때림.

#### 한줄 요약

- 박스 포장 $\to$ 광케이블 쏘기 $\to$ ADM 장비가 헤더 감시하다가, 필요하면 짐 내리고 선 끊기면 우회하는 흐름이다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- (상단 참조)

</details>

| 비교 항목 | **PDH (구석기 1세대)** | **SDH (유럽/국제 표준)** | **SONET (북미 전용 룰)** |
|:---|:---|:---|:---|
| 비유 및 핵심 특징 | 마트료시카 뜯다 날 새는 **노가다망** | 절대 시간 맞춘 **글로벌 광전송 표준** | SDH랑 원리는 똑같은데 **미국 놈들 룰** |
| 동기화 (클럭) | 지 멋대로 돌고 **쓰레기 비트로 땜빵함** | 국가 전체가 **동일한 원자시계로 박자 맞춤** | 북미 기준 **동일한 시계로 박자 맞춤** |
| 데이터 인출 (Drop)| **전체 짐 다 해체해야** 중간 거 하나 뺄 수 있음 | **포인터** 치트키로 **원하는 짐만 쏙 뺌 (Add/Drop)** | **포인터** 치트키로 **원하는 짐만 쏙 뺌 (Add/Drop)** |
| 기본 전송 속도 | T1(1.5M), E1(2M) 등 근본 없이 쪼개짐 | **STM-1 (155Mbps)** 부터 4배수로 깔끔하게 시작 | **OC-1 (51.84Mbps)** 부터 배수로 시작 |
| 주력 활용 | 2G/3G 구형 전화망 백본 | **전 세계 통신사 광 백본망 뼈대** | 북미 광 백본망 뼈대 |

#### 한줄 요약

- PDH는 짐 하나 빼려고 마트료시카 다 까야 하는 노가다 망이고, SDH/SONET은 포인터로 쏙 빼는 스마트 광망이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **지터 (Jitter)**: 타이밍 핀트가 수전증처럼 미세하게 흔들리는 현상이다. 포인터 주소를 너무 자주 수정하면 지터가 튀어서 통신 에러율이 떡상한다.
- **이종 연동 (Interworking)**: 한국(SDH 규격)이랑 미국(SONET 규격)이랑 해저 케이블로 연결할 때, 서로 규격이 달라서 중간에 통역기(Gateway 매퍼)를 달아주는 번거로운 작업이다.

</details>

| 장애/위험 요소 | 원인 분석 | 실무 대책 및 해결방안 | 기대 효과 |
|:---|:---|:---|:---|
| 포크레인이 긁어서 **전국 광망 뻗고 카톡 먹통 됨** | 링(Ring) 토폴로지 상에서 메인 광선로 케이블이 물리적으로 끊김 | 헤더(SOH)로 단선 눈치채고 50ms 이내에 **예비 선로로 싹 돌림 (APS 절체 가동)** | 장애 터져도 체감 없이 0.05초 만에 무단절 방어 |
| 타이밍 엇나가서 **에러 튀고(지터) 통신 품질 개판 남** | 통신사 기지국 장비들끼리 시계(클럭)가 틀어져서 포인터 주소 뻘짓이 잦아짐 | 최상위 원자시계(PRC)로 **망 동기화 빡세게 맞추고 지터 억제 버퍼 박음** | 타이밍 수전증 잡고 10Gbps 이상 고속망 에러율 컷트 |
| 미국망이랑 한국망 **연결했더니 호환 안 돼서 터짐** | 북미 SONET(OC-3)이랑 국제 SDH(STM-1) 컨테이너(페이로드) 규격이 미묘하게 다름 | 상호 연동(Interworking) 100% 보장하는 **국제 게이트웨이 매퍼(통역기) 설치함** | 대륙 간 해저 광케이블 통신 호환성 및 국사 연결 확보 |

#### 한줄 요약

- 포크레인 사고는 APS 절체로 막고, 타이밍 에러는 원자시계로 잡고, 미국망 연동은 게이트웨이 매퍼 달아서 해결하라.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- (상단 참조)

</details>

- 느리고 뻘짓 많던 PDH 다단 다중화의 한계를 부수고, **절대 동기화**와 **포인터 기반 1-Step 분기결합**, **50ms 우회 절체**를 장착한 SDH/SONET 광 백본 기조 확립함

#### 한줄 요약

- SDH/SONET은 아날로그식 비효율을 끝장내고 현대 광통신 네트워크를 고속도로처럼 뻥 뚫어준 혁명적 인프라 표준이다.
