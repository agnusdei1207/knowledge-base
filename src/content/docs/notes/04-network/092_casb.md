## Ⅰ. 개요

<details><summary>핵심 용어</summary>

- **클라우드 접근 보안 중개(Cloud Access Security Broker, CASB)**: 클라우드 사용•위험•자료 이동을 가시화하고 정책을 집행하는 보안 체계이다.
- **섀도 IT(Shadow IT)**: 조직의 승인과 관리 없이 사용자가 업무 자료를 처리하는 클라우드 서비스나 기술이다.
- **서비스형 소프트웨어(Software as a Service, SaaS)**: 네트워크를 통해 응용 기능을 구독 형태로 제공하는 서비스이다.

</details>

- 정의/개념: 클라우드 사용•자료 이동을 통제하는 **CASB 보안 중개 체계**이다.
- 배경/필요성: 미승인 SaaS의 **계정•자료 유출 비가시성**이 발생한다.

#### 한줄 요약

- 직원이 어떤 클라우드에 어떤 자료를 올리고 공유하는지 찾아 조직 규칙에 맞게 허용•차단•회수한다.

## Ⅱ. 특징

<details><summary>핵심 용어</summary>

- **데이터 유출 방지(Data Loss Prevention, DLP)**: 자료의 내용과 등급을 식별해 허가되지 않은 전송•공유를 차단하는 기술이다.
- **순방향 프록시**: 사용자에서 클라우드로 나가는 통신을 중계해 접속과 업로드를 실시간 검사하는 방식이다.
- **응용 프로그래밍 인터페이스(Application Programming Interface, API)**: CASB가 저장 자료•공유 설정•계정 상태를 검사하는 호출 통로이다.

</details>

- **행위별 정책**: 사용자•단말•서비스•자료 맥락 결합한다.
- **프록시 연동**: 클라우드 세션의 실시간을 통제한다.
- **API 연동**: 저장 자료•공유 설정의 사후 점검이다.

#### 한줄 요약

- 같은 클라우드라도 회사 단말의 일반 문서는 허용하고 개인 단말의 중요 자료 내려받기는 막을 수 있다.

## Ⅲ. 구조 및 구성요소

<details><summary>핵심 용어</summary>

- **접근 중개기**: 프록시와 API로 세션•저장 자료를 검사하는 구성요소다.
- **CASB 정책 엔진**: 신원•단말•자료•서비스 위험으로 조치를 결정하는 구성요소이다.
- **클라우드 위험 카탈로그**: 서비스별 보안 기능, 법적 위치와 사고 이력 등을 평가해 승인 판단에 쓰는 목록이다.

</details>

```text
CASB
├─ 사용자•단말
├─ 접근 중개기
├─ CASB 정책 엔진
├─ 신원•자료•위험 저장소
└─ 클라우드 서비스
```

선의 의미: 접근 중개기가 사용자•단말과 클라우드 서비스 사이의 통제 경계를 이루고, CASB 정책 엔진이 신원•자료•위험 저장소의 근거로 중개 정책을 결정하는 정적 구조이다.

| 구성요소 | 책임 |
|:---|:---|
| 사용자•단말 | **클라우드 접속•자료 행위** 생성 |
| 접근 중개기 | **프록시•API 세션•저장물** 검사 |
| 신원•자료•위험 저장소 | **계정•등급•서비스 위험** 제공 |
| CASB 정책 엔진 | **허용•차단•격리•회수** 결정 |
| 클라우드 서비스 | **응용•저장•공유 기능** 제공 |

#### 한줄 요약

- 중개기가 클라우드 사용을 관찰하면 정책 엔진이 사용자와 단말, 자료 등급과 서비스 위험을 함께 보고 조치한다.

## Ⅳ. 흐름도

<details><summary>핵심 용어</summary>

- **격리•공유 회수**: 위험 자료를 분리하거나 기존 외부 공유 권한을 제거하는 조치다.
- **역방향 프록시**: 클라우드 서비스로 들어가는 세션 앞에서 접속을 중계해 관리•비관리 단말의 행위를 통제하는 방식이다.

</details>

```text
클라우드 접속•저장물 점검 요청
      │
      ▼
1. SaaS 사용 증거 전달
      │
      ▼
2. 서비스 위험 분류
      │
      ▼
3. 자료•행위 맥락 전달
      │
      ▼
4. 정책 조치 결정
      ├─ 허용: 제한 조건으로 접근
      ├─ 차단: 세션 거부
      └─ 위험 자료: 격리•공유 회수
                    │
                    ▼
5. 세션•저장물 집행
                    │
                    ▼
접근•조치 결과 반환
```

**동작 원리**

1. **SaaS 사용 증거 전달**: 로그•트래픽•API로 사용 정보를 수집한다.
2. **서비스 위험 분류**: 승인 여부•보안 기능•위치를 평가한다.
3. **자료•행위 맥락 전달**: 신원•단말•등급별 이동 정보를 제공한다.
4. **정책 조치 결정**: 허용•차단•격리•공유 회수를 선택한다.
5. **세션•저장물 집행**: 실시간 중계와 사후 API을 조치한다.

#### 한줄 요약

- 사용하는 클라우드를 찾고 서비스와 사용자, 자료의 위험을 차례로 확인해 접속을 막거나 저장된 공유를 회수한다.

## Ⅴ. 종류 및 비교

| CASB 연동 방식 | 순방향 프록시 | 역방향 프록시 | API 연동 |
|:---|:---|:---|:---|
| 적용 기준 | 관리 단말의 **업로드•웹 통제** | 비관리 단말의 **제한 접속** | 기존 저장물•**외부 공유 점검** |
| 핵심 특징 | 발신 세션의 **실시간 중계** | SaaS 로그인 뒤 **세션 중계** | 저장 자료•설정의 **사후 점검** |
| 한계 | 경로 우회•**복호화 병목** | 지원 SaaS•**인증 연계 제한** | API 지연•**실시간 차단 불가** |

> 요약: 세션 방향•실시간성•저장물로 방식을 선택한다.

#### 한줄 요약

- 회사 단말의 나가는 통신은 순방향, 외부 단말의 로그인은 역방향, 이미 저장된 자료는 API 방식으로 점검한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>핵심 용어</summary>

- **관리 단말**: 조직이 보안 상태와 통신 경로를 통제하는 업무 기기다.
- **비관리 단말**: 조직의 직접 관리 밖에서 클라우드에 접속하는 기기다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 개인 SaaS의 **중요 자료 업로드** | 순방향 프록시와 **DLP** 적용 | 이동 중 **자료 유출 차단** |
| 기존 공유의 **사후 노출** | API 기반 **공유•권한 회수** | 저장 자료의 **노출 시간 감소** |
| 비관리 단말의 **과도한 다운로드** | 역방향 프록시로 **행위 제한** | 단말 위험별 **접근 범위 축소** |

#### 한줄 요약

- CASB가 프록시 구간에서 문서의 중요 정보와 사용자 계정을 검사해 업무 문서가 개인 클라우드로 업로드되는 것을 차단한다.

## Ⅶ. 결론

- 관리 단말 실시간은 **순방향**, 비관리 접속은 **역방향**, 저장물은 **API**을 적용한다.

#### 한줄 요약

- CASB는 클라우드 목록만 보여 주는 도구가 아니라 이동 중 자료와 이미 저장된 공유를 각각 맞는 방식으로 바꿔야 한다.
