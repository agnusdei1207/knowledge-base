## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **엣지 컴퓨팅(Edge Computing)**: 스마트폰, 자율주행 센서, 공장 PLC 등 데이터가 생성되는 말단 디바이스(Data Producer) 자체 또는 직결된 1차 장치에서 즉시 연산을 수행하는 극초단 분산 컴퓨팅.
- **포그 컴퓨팅(Fog Computing)**: 말단 엣지 노드와 중앙 클라우드 사이에 위치하는 로컬 네트워크 인프라(스위치, 라우터, 산업용 게이트웨이)에 가상화 노드를 구성하여 데이터 집계, 상호 연계 및 국소 제어를 수행하는 다계층 확장 아키텍처 (OpenFog/IEEE 1934 표준).

</details>

- 정의/개념: 데이터 발생원(장치) 내부에서 1ms 이하 초저지연 연산을 수행하는 **엣지 컴퓨팅** 과, 근거리 로컬 네트워크 계층에서 다수 엣지 노드의 데이터를 수집·요약·중계하는 **포그 컴퓨팅**
- 배경/필요성: 수십억 대의 IoT 단말에서 발생하는 방대한 원시 데이터를 중앙 데이터센터로 일괄 전송할 때 발생하는 백홀 네트워크 대역폭 고갈과 전송 지연을 완화하고, 로컬 사이트의 자율 운영성을 확보할 요구

#### 한줄 요약
- 말단 장치 즉시 제어(Edge)와 로컬 네트워크 다계층 집계·중계(Fog)로 분산 컴퓨팅을 계층화한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **장애 독립성(Fault Autonomy)**: 상위 백홀 네트워크 단선이나 중앙 클라우드 장애 발생 시에도 로컬 엣지/포그 계층 내에서 필수 제어 루프를 독립적으로 유지하는 자율 복원력.
- **계층적 데이터 정제(Data Filtering & Aggregation)**: 말단에서 초당 수천 건 발생하는 원시 센서 데이터를 포그 노드에서 1차 통계·요약하여 의미 있는 메타데이터만 상위 클라우드로 전송하는 대역폭 최적화 기술.

</details>

- **엣지 컴퓨팅의 극초저지연 결정론성**: 데이터 수집 지점에서 1~5ms 내 즉각적 추론 및 액추에이터 구동 제어 수행
- **포그 컴퓨팅의 계층적 클러스터링**: 이기종 통신 프로토콜(CAN, Modbus, BLE, Wi-Fi)을 수용하여 표준 IP 기반으로 프로토콜 변환 및 로컬 분산 저장
- **백본 대역폭 및 클라우드 부하 절감**: 원시 데이터를 현장 정제하여 중앙망 전송 트래픽을 대폭 축소하고 데이터 상주성(Data Sovereignty) 준수

#### 한줄 요약
- 말단 즉시 제어, 포그 계층의 프로토콜 변환 및 데이터 정제, 계층 간 자율 운영성을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **OpenFog 레퍼런스 아키텍처**: IEEE 1934로 표준화된 계층형 포그 아키텍처로, SCALE 원칙(보안 Security, 인지 Cognition, 민첩성 Agility, 지연 Latency, 효율 Efficiency)을 정의.

</details>

```text
[ 중앙 집중형 클라우드 (Central Cloud) ] ──▶ (전역 빅데이터 분석, 장기 AI 모델 학습)
               ▲
               │ (정제된 요약 통계 및 메타데이터 전송 / NGN 백홀)
[ 포그 계층 (Fog Nodes: 스위치, 게이트웨이) ] ─▶ (로컬 분석, 프로토콜 변환, 데이터 집계)
               ▲
               │ (로컬 통신: Ethernet, Wi-Fi, TSN)
[ 엣지 계층 (Edge Devices: 센서, PLC, 카메라) ] ─▶ (실시간 센싱, 1ms 즉시 액추에이터 제어)
```

선의 의미: 데이터는 하위 엣지에서 상위 클라우드로 정제·집계되어 올라가고, 제어 정책 및 AI 가중치 모델은 상위에서 하위로 배포되는 계층적 양방향 구조

| 계층 | 주요 구성요소 | 핵심 책임 | 전형적 응답 지연 |
|:---|:---|:---|:---|
| **엣지 (Edge)** | 스마트 센서, 임베디드 MCU, 스마트 카메라 | 원시 신호 수집, 긴급 장애 차단, 실시간 추론 | 1 ~ 5 ms |
| **포그 (Fog)** | 산업용 IoT 게이트웨이, L3 스위치, 마이크로 서버 | 이종 프로토콜 통합, 데이터 필터링/요약, 로컬 제어 | 10 ~ 50 ms |
| **클라우드 (Cloud)** | 글로벌 리전 데이터센터, 대규모 서버 팜 | 전역 데이터 웨어하우스, 대규모 LLM/AI 학습, 장기 정책 | 100 ms 이상 |

#### 한줄 요약
- 말단 엣지(1~5ms), 중간 포그 게이트웨이(10~50ms), 중앙 클라우드(100ms 이상)가 계층적으로 결합한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **동적 연산 오프로딩(Computation Offloading)**: 엣지 디바이스의 CPU/배터리 자원이 부족할 때 연산 태스크를 인접한 포그 노드나 상위 클라우드로 전송하여 위임 처리하는 기법.

</details>

```text
1. 엣지 센서 노드에서 실시간 원시 데이터(Raw Data) 고주파 계측
            │
            ▼
2. 엣지 디바이스가 임계치 초과 긴급 이벤트 감지 시 액추에이터 즉각 제어 (1ms)
            │
            ▼
3. 일반 시계열 데이터를 근거리 포그 노드로 전송 ➔ 포그 노드가 노이즈 제거 및 요약 통계 산출
            │
            ▼
4. 정제된 메타데이터만 중앙 클라우드로 전송 ➔ 클라우드에서 전역 AI 모델 재학습 후 가중치 하향 배포
```

**동작 원리**

1. **현장 즉시 대응**: 엣지 노드가 센싱과 동시에 내장 가베지 필터링 및 비상 차단 로직 실행
2. **로컬 집계 및 동기화**: 포그 노드가 주변 수십~수백 개 엣지 데이터를 취합하여 시간축 정렬(TSN/PTP) 및 이상 징후 분석
3. **요약 전송**: 데이터 크기를 90% 이상 축소한 요약 벡터를 광대역망을 통해 클라우드로 전송
4. **전역 최적화 피드백**: 클라우드가 축적된 빅데이터를 바탕으로 제어 임계치를 재계산하여 포그/엣지로 갱신 배포

#### 한줄 요약
- 엣지 즉시 제어, 포그 노이즈 필터링 및 집계, 클라우드 요약 전송 및 AI 재학습 피드백 순으로 처리된다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **데이터 상주성(Data Residency)**: 법률적 규제 또는 보안상의 이유로 특정 국가나 사업장 물리적 경계 내에 데이터가 물리적으로 머물러야 하는 보안 조건.

</details>

| 비교 항목 | 엣지 컴퓨팅 (Edge Computing) | 포그 컴퓨팅 (Fog Computing) | 중앙 클라우드 (Central Cloud) |
|:---|:---|:---|:---|
| **물리적 배치 위치** | **데이터 발생 장치 자체 (센서/단말)** | **로컬 LAN 세그먼트 (스위치/게이트웨이)** | **대규모 원격 데이터센터 (IDC)** |
| **네트워크 범위** | 노드 내부 버스 또는 직결 링크 | 근거리 로컬 네트워크 (LAN / PAN) | 광역 인터넷 / 공용 백본망 (WAN) |
| **연산 자원 규모** | 극소형 임베디드 자원 (MCU, NPU) | 중소형 가상화 노드 (x86/ARM 서버) | 무제한에 가까운 대규모 서버 풀 |
| **주요 처리 목적** | **1ms 이하 초저지연 결정론적 제어** | **다중 엣지 데이터 집계 및 프로토콜 변환** | **전역 빅데이터 분석 및 대규모 훈련** |
| **오프라인 동작** | **독립적 완전 자율 운영 가능** | LAN 내 자율 운영 가능 (WAN 단절 무관) | 네트워크 단절 시 서비스 전면 중단 |

#### 한줄 요약
- 엣지는 장치 내 극초저지연 제어를, 포그는 로컬 네트워크 데이터 중계를, 클라우드는 전역 연산을 전담한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **상호 전송 계층 보안(mTLS, mutual TLS)**: 클라이언트와 서버 양측이 공인 X.509 인증서를 상호 교환하여 신원을 양방향 검증하고 통신을 암호화하는 제로 트러스트 보안 프로토콜.
- **정밀 시각 동기화(IEEE 1588 PTP)**: 분산된 센서와 포그 노드 간의 내부 클록 오차를 마이크로초(㎲) 이하로 정밀 동기화하는 네트워크 시각 표준.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 엣지 디바이스 연산 자원 고갈로 인한 처리 지연 및 패킷 드롭 | 태스크 복잡도 기반 **포그 계층 동적 연산 오프로딩(Offloading)** 구성 | 엣지 과부하 방지 및 전체 서비스 SLA 유지 |
| 상위 포그 노드 단선 시 하위 엣지 디바이스의 연쇄 장애(SPOF) 발생 | 엣지 노드 내 **로컬 캐시 및 상태 머신 기반 장애 독립성(Fault Autonomy)** 구현 | 상위망 장애 시에도 현장 공정 셧다운 방지 |
| 분산 엣지/포그 노드 간 시간 불일치로 인한 시계열 분석 데이터 왜곡 | L2/L3 네트워크 전반에 **IEEE 1588 PTP / TSN 정밀 시각 동기화** 적용 | 마이크로초 단위 시계열 데이터 정합성 보장 |
| 분산 배치된 물리 포그 노드에 대한 비인가 기기 접속 및 도청 위험 | 노드 간 통신에 **mTLS 상호 인증 및 하드웨어 TPM 암호화 키 격리** 적용 | 중간자 공격 차단 및 제로 트러스트 엣지 보안 구현 |

#### 한줄 요약
- 동적 오프로딩으로 부하를 분산하고, 장애 독립성으로 가용성을 보장하며, PTP 시각 동기화와 mTLS로 정합성과 보안을 확보한다.

## Ⅶ. 결론

- IoT 및 스마트 인프라의 대규모 데이터 폭증과 실시간 제어 요구를 충족하기 위해, 단말 종단의 **엣지 컴퓨팅** 과 로컬 중계망의 **포그 컴퓨팅**, 중앙의 **클라우드** 를 유기적으로 연계하는 **다계층 분산 아키텍처(IEEE 1934 OpenFog)** 를 구축하고, 계층 간 **동적 오프로딩** 과 **mTLS 제로 트러스트 보안** 을 적용하여 고효율·고가용성 지능형 네트워크를 완성

#### 한줄 요약
- 엣지-포그-클라우드 다계층 연계를 통해 초저지연과 전역 분석을 동시에 최적화한다.
