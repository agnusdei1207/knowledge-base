## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **Edge Computing (엣지 컴퓨팅)**: 데이터가 생성되는 말단 디바이스(센서, PLC, 카메라) 자체에서 즉시 연산·제어하는 극초단 분산 컴퓨팅.
- **Fog Computing (포그 컴퓨팅)**: 엣지 장치와 중앙 클라우드 사이의 로컬 네트워크 장비(게이트웨이, 스위치)에서 데이터 집계와 프로토콜 변환을 수행하는 다계층 확장 아키텍처 (IEEE 1934).

</details>

- 정의/개념: 데이터 발생원 말단에서 1ms 이하 초저지연 연산을 수행하는 **엣지 컴퓨팅**과 근거리 로컬 네트워크에서 다수 엣지 데이터를 수집·요약하는 **포그 컴퓨팅**
- 배경/필요성: 수십억 대 IoT 단말의 원시 데이터를 중앙 클라우드로 일괄 전송 시 발생하는 **백홀 대역폭 고갈, 전송 지연(100ms) 및 로컬 사이트 자율 운영 불가**

#### 한줄 요약
- 엣지는 말단 즉시 제어를, 포그는 로컬 네트워크 집계·중계를, 클라우드는 전역 분석을 분담한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **OpenFog SCALE Principles**: Security(보안), Cognition(인지), Agility(민첩성), Latency(지연), Efficiency(효율성)의 5대 핵심 설계 원칙.
- **Autonomous Operation (장애 독립성)**: 상위 백홀망이 단선되어도 엣지/포그 계층이 로컬 캐시와 제어 로직으로 무중단 단독 가동되는 능력.

</details>

- **엣지 컴퓨팅의 극초저지연 결정론성**: 데이터 수집 지점에서 1~5ms 내 즉각적 추론 및 액추에이터 제어
- **포그 컴퓨팅의 계층적 클러스터링**: 이종 통신 프로토콜(Modbus, BLE, CAN)을 수용하여 표준 IP로 변환 및 로컬 분산 저장
- **백본 대역폭 및 클라우드 부하 절감**: 원시 데이터를 현장에서 정제하여 중앙망 전송 트래픽 90% 이상 축소

#### 한줄 요약
- 말단 즉시 제어, 포그 계층의 프로토콜 변환 및 데이터 정제, 계층 간 자율 운영성을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **IEEE 1934 OpenFog Reference Architecture**: 엣지 디바이스부터 포그 노드, 클라우드 데이터센터에 이르는 분산 계층을 표준화한 레퍼런스 모델.

</details>

```text
[다계층 분산 컴퓨팅(Edge - Fog - Cloud) 참조 아키텍처]
|-- Central Cloud Layer (글로벌 리전 IDC: 대규모 LLM 학습, 전역 빅데이터 분석, 장기 정책, >100ms)
|   `-- NGN WAN Backhaul (정제된 요약 메타데이터 전송)
`-- Fog Computing Layer (IEEE 1934 포그 노드: 산업용 게이트웨이, L3 스위치, 10~50ms)
|   |-- Protocol Converter (CAN, Modbus, BLE -> 표준 IP 변환)
|   |-- Data Aggregator & Noise Filter (시계열 노이즈 제거, 요약 벡터 생성)
|   `-- Local Clustering & Storage (로컬 분산 캐시 및 서브넷 제어)
`-- Edge Device Layer (말단 센서, PLC, 머신비전 카메라, 자율주행 NPU, 1~5ms)
    `-- Real-time Sensor & Actuator (1ms 초저지연 결정론적 즉각 제어)
```

선의 의미: 계층 및 데이터는 하위 엣지에서 상위 클라우드로 정제·집계되어 올라가고 제어 정책과 AI 모델은 상위에서 하위로 배포되는 구조

| 계층 | 주요 구성요소 | 핵심 엔지니어링 책임 | 전형적 응답 지연 |
|:---|:---|:---|:---|
| **엣지 (Edge)** | 스마트 센서, 임베디드 MCU, 스마트 카메라 | **원시 신호 고주파 수집, 긴급 장애 차단, 1ms 실시간 추론** | **1 ~ 5 ms** |
| **포그 (Fog)** | 산업용 IoT 게이트웨이, L3 스위치, 마이크로 서버| **이종 프로토콜 통합 변환, 데이터 필터링/요약, 로컬 제어** | **10 ~ 50 ms** |
| **클라우드 (Cloud)**| 글로벌 리전 데이터센터, 대규모 서버 팜 | **전역 데이터 레이크, 대규모 AI 모델 학습, 장기 정책 수립** | **100 ms 이상** |

#### 한줄 요약
- 말단 엣지(1~5ms), 중간 포그 게이트웨이(10~50ms), 중앙 클라우드(100ms 이상)가 결합된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Computation Offloading (동적 연산 오프로딩)**: 엣지 디바이스의 CPU/배터리 자원이 부족할 때 연산 작업을 인접 포그 노드로 위임 처리하는 기법.

</details>

```text
다계층 데이터 수집·정제 및 제어 파이프라인
        │
   1. [엣지 센싱 및 즉시 대응] 엣지 센서가 고주파 계측 후 이상 시 1ms 내 액추에이터 제어
        │
   2. [포그 노드 전송] 일반 시계열 데이터를 근거리 포그 게이트웨이로 전달
        │
   3. [포그 노이즈 필터링 및 집계] 포그 노드가 프로토콜 변환 및 90% 이상 데이터 요약
        │
   4. [클라우드 요약 전송] 정제된 메타데이터만 중앙 클라우드로 백홀 전송
        │
   ▼
5. [전역 AI 재학습 및 피드백] 클라우드가 AI 모델을 재학습하여 가중치를 포그/엣지로 하향 배포
```

#### 한줄 요약
- 엣지 즉시 제어 → 포그 노이즈 필터링/집계 → 클라우드 요약 전송 → AI 재학습 피드백 순으로 처리된다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **Data Residency (데이터 상주성)**: 국가 규제나 보안상의 이유로 데이터가 사업장 물리적 경계 내에 상주해야 하는 보안 요건.

</details>

| 비교 항목 | 엣지 컴퓨팅 (Edge Computing) | 포그 컴퓨팅 (Fog Computing) | 중앙 클라우드 (Central Cloud) |
|:---|:---|:---|:---|
| **물리적 배치 위치** | **데이터 발생 장치 자체 (센서/단말)** | **로컬 LAN 세그먼트 (스위치/게이트웨이)**| **대규모 원격 데이터센터 (IDC)** |
| **네트워크 범위** | 노드 내부 버스 또는 직결 링크 | 근거리 로컬 네트워크 (LAN / PAN) | 광역 인터넷 / 공용 백본망 (WAN) |
| **연산 자원 규모** | 극소형 임베디드 자원 (MCU, NPU) | 중소형 가상화 노드 (x86/ARM 서버) | 무제한에 가까운 대규모 서버 풀 |
| **주요 처리 목적** | **1ms 이하 초저지연 결정론적 제어** | **다중 엣지 데이터 집계 및 프로토콜 변환**| **전역 빅데이터 분석 및 대규모 훈련** |
| **오프라인 동작** | **독립적 완전 자율 운영 가능** | LAN 내 자율 운영 가능 (WAN 단절 무관) | 네트워크 단절 시 서비스 전면 중단 |

#### 한줄 요약
- 엣지는 장치 내 극초저지연 제어를, 포그는 로컬 네트워크 데이터 중계를, 클라우드는 전역 연산을 전담한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **IEEE 1588 PTP (Precision Time Protocol)**: 분산된 센서와 포그 노드 간의 내부 클록 오차를 마이크로초(㎲) 이하로 정밀 동기화하는 네트워크 시각 표준.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 엣지 디바이스 연산 자원 고갈로 인한 지연 및 패킷 드롭 | 태스크 복잡도 기반 **`포그 계층 동적 연산 오프로딩(Offloading)`** | 엣지 과부하 방지 및 전체 서비스 SLA 유지 |
| 상위 포그 노드 단선 시 하위 엣지 디바이스의 연쇄 장애(SPOF) | 엣지 노드 내 **`로컬 캐시 및 상태 머신 기반 장애 독립성` 구현** | 상위망 단선 시에도 현장 공정 무중단 유지 |
| 분산 노드 간 시간 불일치로 인한 시계열 분석 데이터 왜곡 | L2/L3 네트워크 전반에 **`IEEE 1588 PTP / TSN 정밀 시각 동기화`** | 마이크로초 단위 시계열 데이터 정합성 보장 |
| 분산 배치된 포그 게이트웨이에 대한 비인가 기기 침해 위협 | 노드 간 통신에 **`mTLS 상호 인증 및 하드웨어 TPM 키 격리`** | 중간자 공격 차단 및 제로 트러스트 보안 달성 |

#### 한줄 요약
- 동적 오프로딩, 장애 독립성, PTP 시각 동기화, mTLS/TPM 보안으로 운영한다.

## Ⅶ. 결론

- IoT 및 산업용 스마트 인프라의 대규모 데이터 폭증과 실시간 제어 요구를 충족하기 위해 **단말 종단의 엣지 컴퓨팅과 로컬 중계망의 포그 컴퓨팅, 중앙의 클라우드를 유기적으로 연계하는 다계층 분산 아키텍처(IEEE 1934 OpenFog)를 구축**하고, **동적 연산 오프로딩과 IEEE 1588 PTP 시각 동기화 및 mTLS 제로 트러스트 보안**을 결합하여 고효율·고가용성 분산 네트워크 완성

#### 한줄 요약
- 엣지-포그-클라우드 다계층 연계를 통해 초저지연과 전역 빅데이터 분석을 동시에 최적화하는 분산 아키텍처다.
