## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **OSPF(Open Shortest Path First)**: 사내망(AS 내부)에서 가장 널리 쓰이는 표준 라우팅 프로토콜로, 자기 주변의 도로(링크) 상태를 동네방네 퍼뜨려서 전체 지도를 그리는 방식이다.
- **내부 게이트웨이 프로토콜(IGP)**: 우리 조직 안에서만 길을 찾기 위해 라우터끼리 쑥덕거리는 내부용 라우팅 프로토콜이다.
- **링크 상태 광고(LSA)**: 라우터가 "나 1번 포트 살아있고, 속도 1기가임!" 하고 전단지를 돌리는 상태 알림 패킷이다.
- **링크 상태 데이터베이스(LSDB)**: 동네방네서 주워 모은 LSA 전단지를 다 합쳐서 만든, 완벽하게 똑같은 전체 네트워크 지도(DB)이다.
- **SPF 알고리즘(Shortest Path First)**: 지도(LSDB)를 펴놓고 다익스트라 공식을 돌려서, 나를 중심으로 제일 빠른 길을 계산해 내는 알고리즘이다.

</details>

- 정의: 링크 상태 전단지(LSA)를 돌려 지도를 만들고 최단 경로(SPF)를 계산하는 **IGP 대표 프로토콜**
- 배경: 구식 RIP는 15홉 넘어가면 통신이 끊기고 느려터져서 **복잡하고 큰 규모의 망에선 쓸 수 없었기 때문**

#### 한줄 요약

- 서로 전단지(LSA)를 뿌려 똑같은 지도를 만들고, 수학 공식(SPF)으로 제일 빠른 길을 찾아낸다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **영역(Area)**: 지도가 너무 커지면 CPU가 터지니까, 전국 지도를 "서울(Area 1), 부산(Area 2)"처럼 논리적으로 쪼개놓은 구역이다.
- **플러딩(Flooding)**: 동네 랜선 하나가 끊어지면 "야 여기 끊겼다!" 하고 들어온 구멍 빼고 모든 곳으로 전단지(LSA)를 무식하게 쏴버리는 고속 전파 방식이다.

</details>

- 전체 지도를 **영역(Area)** 단위로 쪼개서, 대규모 망에서도 SPF 연산 부하가 라우터 CPU를 터트리지 않게 최소화.
- 링크가 죽거나 살아나면 해당 LSA를 즉시 **플러딩**하여, 수 초 안에 모든 라우터가 새 지도를 그리는 미친 수렴 속도 달성.
- 단순히 몇 다리 건너는지(Hop) 안 따지고, 도로의 진짜 비용($10^8 / 대역폭$)을 계산해서 가장 뻥 뚫린 길 선택.

#### 한줄 요약

- 구역을 쪼개서 라우터 머리 터지는 걸 막고, 선 끊어지면 바로 동네방네 소문내서 빛의 속도로 우회한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **헬로 패킷(Hello Packet)**: 라우터끼리 처음 만나면 "너 OSPF 써? 비밀번호 뭐야? 나랑 친구 할래?" 하고 찔러보는 인사 패킷이다.
- **인접 관계(Adjacency)**: 헬로 패킷으로 간을 다 보고, "ㅇㅋ 너 통과" 해서 서로 전단지(LSA)를 교환할 수 있게 된 찐친 상태이다.
- **영역 경계 라우터(ABR)**: "나는 지사(Area 1)에도 발 담그고 본사(Area 0)에도 발 담근다" 하고 영역을 이어주는 양다리 중계 라우터이다.
- **경로 요약(Route Summarization)**: ABR이 밑에 구역의 자잘한 길 100개를 다 올리면 대장이 뻗으니까, "이 동네 길은 이거 하나로 퉁쳐!" 하고 줄여서 보고하는 기술이다.

</details>

```text
[ OSPF 멀티 에어리어 직관적 비교 아키텍처 ]

[ 지사 (Area 1) ]             [ 본사 뼈대 (Area 0) ]           [ 지사 (Area 2) ]
┌────────────────┐         ┌────────────────────┐         ┌────────────────┐
│ 라우터 A, B    │         │ 코어 라우터 C, D   │         │ 라우터 E, F    │
└────────────────┘         └────────────────────┘         └────────────────┘
          ＼                     /                               /
            ＼                  /                               /
        ┌─────────────────────────────────────────┐
        │  ABR (양다리 라우터): 구역 연결 & 경로 퉁치기(요약)   │
        └─────────────────────────────────────────┘
```

| 구성요소 | 직관적 비교 책임 | 비고 |
|:---|:---|:---|
| **OSPF Adjacency** | **헬로 패킷** 던져서 비번 똑같은지 확인하고 찐친(Full State) 맺기 | 2-Way $\to$ Full 전이 |
| **LSA (전단지)** | 라우터 상태(Type1), 퉁친 경로(Type3) 등 종류별 전단지 유포 | 영역별로 분리 전파 |
| **LSDB (지도DB)** | 동네 라우터들이 전단지를 모아 100% 똑같이 공유하는 완벽한 맵 | 메모리 점유 |
| **ABR (영역 경계)** | 뼈대(Area 0)와 말단을 잇고, 쓸데없는 전단지 걸러내서 **경로 요약** 해주는 놈 | Area 0 연동 필수 |
| **ASBR (외부 경계)**| BGP나 정적 라우팅 같은 외부 길을 우리 동네로 긁어오는 수입 브로커 | 외부 경로(Type5) 주입 |

#### 한줄 요약

- Area 0라는 거대한 척추에 ABR들이 양다리 걸치고 붙어서 지사(Area)들을 묶어주는 구조다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **데이터베이스 동기화(Database Synchronization)**: 찐친 맺은 라우터끼리 "내가 가진 지도랑 네 지도랑 똑같냐?" 하고 맞춰보는 과정이다.
- **DBD(Database Description)**: "나 이런 전단지들 갖고 있다" 하고 내용물 쏙 빼고 목차(헤더)만 줘서 간 보는 패킷이다.
- **LSR(Link State Request)**: 목차를 봤더니 "어? 나 이 전단지 없네. 혹은 구버전이네. 원본 좀 줘" 하고 요구하는 패킷이다.
- **LSU(Link State Update)**: "ㅇㅋ 여기 최신 원본 전단지 받아라" 하고 진짜 디테일한 정보를 쏴주는 패킷이다.

</details>

```text
[ OSPF 이웃 맺고 지도 그리는 십자포화 흐름 ]
┌──────────────────────────────┐
│ 0. Hello 교환                │
│ (비번 맞냐? 친구 하자)       │
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 1. [DBD] 목차 교환           │
│ (나 이런 전단지들 갖고 있음) │
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 2. [LSR] 상세 정보 요청      │
│ (어? 나 그거 없는데 좀 주라) │
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 3. [LSU] 최신 전단지 쏴줌    │
│ (ㅇㅋ 여기 원본 받아라)      │
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 4. [SPF 연산 & FIB 설치]     │
│ (지도 다 맞췄으니 최단길 굽자)│
└──────────────────────────────┘
```

### 동작 원리

1. DBD 교환: 보유 LSA의 헤더(목차) 목록만 가볍게 교환함.
2. LSR 전송: 목차를 대조해 보고 누락되거나 구버전인 LSA 원본을 요청함.
3. LSU 수신: 상세 LSA 전단지를 쏴줘서 상대방 LSDB(지도)를 완벽하게 갱신시킴.
4. SPF 연산: 똑같아진 지도를 펴놓고 내 기준으로 가장 싼 최단 경로를 계산함.
5. 최선 경로 설치: 계산 끝난 1등 경로를 포워딩 테이블에 집중 배치.

#### 한줄 요약

- 목차 주고받고(DBD) $\to$ 없는 거 달라고 조르고(LSR) $\to$ 원본 쏴주고(LSU) $\to$ 지도 다 그리면 제일 빠른 길 찾는다(SPF).

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **OSPFv2**: IPv4 시절에 만들어져서 전단지(LSA) 안에 IP 정보랑 라우터 연결 정보가 한 덩어리로 엉켜있는 구식 버전이다.
- **OSPFv3**: IPv6를 돌리려고 싹 뜯어고쳐서, 라우터 연결 정보 따로, IP 주소 따로 떼어놔서 유연성이 미친 신식 버전이다.

</details>

| 비교 항목 | **OSPFv2 (기존 구형)** | **OSPFv3 (신형 유연킹)** |
|:---|:---|:---|
| 주소 체계 | **IPv4** 전용 (32비트) | **IPv6** 기본에 IPv4(Multi-AF)도 다 수용함 |
| LSA 덩어리 | IP 주소랑 라우터 토폴로지가 **한 몸으로 엉켜서 날아감** | 지도(토폴로지)랑 주소(Prefix)를 **완벽히 찢어서 유포함** |
| 이웃 찾는 법 | IPv4 출발지 주소 보고 "너구낭!" 함 | IPv6 **링크-로컬 주소(`fe80::`)** 기반으로 쿨하게 통신함 |
| 보안 인증 | 자체적으로 비번 치고 MD5 암호화 돌림 | 쿨하게 자체 인증 버리고 IPv6 찐 인증인 **IPsec**에 짬 때림 |

#### 한줄 요약

- v2는 IPv4 전용이고, v3는 IPv6를 위해 뼈대와 주소를 완벽히 분리해서 다재다능해졌다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **영역 0(Area 0 / Backbone Area)**: OSPF의 심장으로, 모든 지사 Area는 무조건 Area 0에 발을 걸치고 있어야 통신이 되는 절대 구역이다.
- **지정 라우터(DR) / 백업 지정 라우터(BDR)**: 스위치 하나에 라우터 10대가 물려있으면 지들끼리 1:1로 떠들다 망이 터지니까, 반장(DR) 하나 뽑아서 걔한테만 보고하게 만드는 룰이다.
- **MTU 불일치(MTU Mismatch)**: A라우터는 1500바이트씩 던지는데 B는 1400바이트밖에 못 받으면, 목차(DBD) 주고받다가 목구멍에 걸려서 뻗어버리는 장애이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 백본(Area 0)이 쪼개지거나 말단이 백본에 안 붙어서 **통신 두절됨** | 가짜 랜선을 깔아버리는 **Virtual-Link(가상 링크)** 뚫어줌 | 백본 척추를 강제로 이어붙여서 전 구역 정상화 |
| 라우터끼리 DBD 교환(ExStart)하다가 **멈춰서 영원히 찐친을 못 맺음** | 양쪽 포트 **MTU 사이즈(1500) 똑같이 맞추거나** 무시 옵션 줌 | DBD 패킷 목구멍에 걸리는 거 뚫어버림 |
| 스위치 하나에 수십 대 물리니까 **전단지(LSA) 폭풍 불어서 뻗음** | 반장(**DR**)과 부반장(**BDR**)을 뽑아서 얘네랑만 전단지 거래하게 조율 | 수다 떠는 세션 수 획기적으로 줄여서 안정화 |

#### 한줄 요약

- Area 0는 무조건 이어붙이고, MTU 사이즈는 똑같이 맞추고, 떼거지로 모여있을 땐 반장(DR)을 뽑아라.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **영역 결정(Area Boundary Selection)**: 네트워크 덩치가 커졌을 때 어디를 척추(Area 0)로 잡고, 어디를 ABR로 둬서 경로를 퉁칠(요약할) 건지 각을 잡는 설계 작업이다.

</details>

- **영역 결정** 원칙에 따라, 대규모 망은 무조건 **Area 0을 중심으로 계층화**하고, ABR에서 경로를 요약하여 라우터의 부하를 획기적으로 줄이는 기조 확립함

#### 한줄 요약

- 규모가 커지면 무조건 Area를 쪼개고, ABR에서 경로를 퉁쳐서 라우터 숨통을 트이게 만들어야 한다.
