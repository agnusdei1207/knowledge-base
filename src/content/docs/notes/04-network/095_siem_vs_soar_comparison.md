## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **SIEM(Security Information and Event Management)**: 전사 이종 인프라의 로그를 중앙 집중 수집·정규화하고, 시간축 상관 분석(Correlation) 및 머신러닝으로 잠재적 보안 침해를 실시간 탐지(Detection)하는 관제 플랫폼.
- **SOAR(Security Orchestration, Automation, and Response)**: SIEM 등에서 생성된 보안 인시던트를 수신하여 위협 정보를 자동 보강(Enrichment)하고, 사전 정의된 플레이북(Playbook)에 따라 이종 보안 솔루션의 API를 호출하여 조사·차단 대응(Response)을 자동 집행하는 운영 플랫폼.

</details>

- 정의/개념: 보안 위협의 가시성 확보 및 상관 분석 탐지를 담당하는 **SIEM** 과, 탐지된 위협에 대한 오케스트레이션 기반 자동 격리 및 사고 대응을 담당하는 **SOAR** 를 유기적으로 연계하여 **탐지-조사-대응-피드백의 폐루프 보안관제(Closed-Loop SOC)** 를 구축하는 융합 아키텍처
- 배경/필요성: SIEM 단독 운영 시 발생하는 과도한 경보로 인한 분석가 피로도(Alert Fatigue) 및 수동 대응 지연 문제를 해결하고, SOAR 단독으로는 불가능한 전사 빅데이터 상관 분석 기반의 고도화된 침해 탐지를 상호보완할 요구

#### 한줄 요약
- SIEM의 지능형 위협 탐지와 SOAR의 플레이북 기반 자동 대응을 결합하여 폐루프 보안 관제를 실현한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **폐루프 보안관제(Closed-Loop Security Operation)**: `로그 수집/분석(SIEM) ➔ 인시던트 티켓 전달 ➔ 자동 조사/격리(SOAR) ➔ 대응 결과 피드백 및 룰 고도화(Feedback Loop)`로 이어지는 연속적 자율 개선 사이클.
- **경보 계약(Alert Contract)**: SIEM과 SOAR 간의 안정적 연동을 위해 인시던트 ID, 타임스탬프, 발신지 IP, 공격 유형, 신뢰도 점수(Confidence Score), 근거 원시 로그를 표준 JSON 스키마로 정의한 인터페이스 명세.

</details>

- **역할 분담의 상호보완성**: SIEM은 전사 데이터 분석과 위협 탐지(Detection)에 집중하고, SOAR는 API 오케스트레이션과 신속한 조치(Response)에 집중
- **사고 대응 주기(MTTR)의 극적 단축**: SIEM 경보 수신 즉시 SOAR가 위협 인텔리전스(TI) 조회 및 격리 플레이북을 가동하여 대응 시간을 수 시간에서 수초로 단축
- **결과 환류(Feedback Loop)를 통한 오탐 정제**: SOAR의 실제 대응 성공/실패 여부 및 분석가 최종 판정 결과를 SIEM으로 환류하여 상관 룰 임계치 자동 최적화

#### 한줄 요약
- 탐지-대응 역할 분담, MTTR 단축, 결과 환류를 통한 룰 최적화 및 폐루프 관제를 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **위협 인텔리전스(TI) 보강**: SOAR가 인입된 IP, 도메인, URL의 악성 여부를 VirusTotal, AlienVault 등 외부 평판 DB에서 자동 질의하여 케이스에 첨부하는 전처리 단계.

</details>

```text
[ 전사 인프라 (Firewall, IPS, EDR, Server, Cloud) ]
                       │ (1. 대용량 로그 스트리밍)
                       ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ [ SIEM 계층 (탐지 및 가시성: Detection & Intelligence) ]                │
│  ├─ 로그 수집 및 정규화 (Normalization: CEF/ECS)                        │
│  ├─ 시계열 상관 분석 (Correlation Rule Engine) & UEBA 이상 탐지          │
│  └─ 고위험 인시던트(Incident) 생성                                      │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │ (2. 경보 계약 기반 표준 Webhook 전달)
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ [ SOAR 계층 (오케스트레이션 및 대응: Orchestration & Automation) ]       │
│  ├─ 위협 정보(TI) 자동 보강 (Threat Enrichment)                          │
│  ├─ 표준 대응 절차 워크플로우 (Playbook Engine)                         │
│  ├─ 승인 관문 (Human-in-the-Loop: 고위험 조치 관리자 승인)               │
│  └─ REST API 오케스트레이션 (방화벽 IP 차단, EDR 엔드포인트 격리)        │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │ (3. 조치 결과 및 오탐 판정 피드백 환류)
                                     └────────────────────────────────────▶ [ SIEM 상관 룰 튜닝 ]
```

선의 의미: 인프라 로그가 SIEM에서 상관 분석되어 생성된 인시던트가 SOAR로 전달되고, 플레이북 조치 후 그 결과가 다시 SIEM 룰 튜닝으로 환류되는 폐루프 아키텍처

| 구성요소 | 핵심 책임 및 역할 | 비고 |
|:---|:---|:---|
| **SIEM 탐지 엔진** | 전사 로그 수집, 표준 스키마 정규화, 다차원 상관 분석 및 침해 인시던트 발행 | Detection Platform |
| **경보 연동 인터페이스** | 사건 메타데이터, 위험도, 공격 증적을 표준 JSON 포맷으로 패키징하여 전달 | Webhook / REST API |
| **SOAR 플레이북 엔진** | 위협 맥락 보강, 의사결정 분기, 다중 장비 API 호출 및 자동 조치 집행 | Workflow Engine |
| **보안 통제 장비 (Actuators)**| 방화벽, IPS, EDR, AD, 이메일 게이트웨이 등 실제 차단을 집행하는 보안 솔루션 | Control Points |
| **결과 환류 모듈 (Feedback)**| 실제 대응 성공 여부 및 분석가 판정 결과를 SIEM으로 전송하여 탐지 룰 보정 | Tuning Pipeline |

#### 한줄 요약
- SIEM 탐지 엔진, 경보 연동 인터페이스, SOAR 플레이북 엔진, 보안 통제 장비, 결과 환류 모듈이 결합한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **상태 재조회(State Verification)**: SOAR가 방화벽에 IP 차단 REST API를 호출한 후, 방화벽 정책 테이블을 재조회(GET)하여 차단 규칙이 실제로 정상 적재되었는지 검증하는 프로세스.

</details>

```text
1. 사내 방화벽 및 윈도우 AD에서 발생한 이상 로그가 SIEM 수집기로 실시간 인입
            │
            ▼
2. SIEM이 로그를 정규화하고 상관 분석 룰을 실행하여 '다단계 무차별 대입 후 C&C 접속' 인시던트 발행
            │
            ▼
3. 표준화된 경보 계약(Alert Contract) 스키마를 통해 SOAR 플랫폼으로 인시던트 티켓 자동 전달
            │
            ▼
4. SOAR가 TI 평판을 자동 조회한 후 플레이북을 실행하여 방화벽 IP 차단 및 감염 PC 네트워크 격리 API 집행
            │
            ▼
5. 대상 장비 상태 재조회 검증 ➔ 조치 완료 이력 및 오탐 분석 결과를 SIEM으로 환류하여 룰 튜닝 반영
```

**동작 원리**

1. **상관 분석 탐지**: SIEM이 개별 로그의 연관성을 추적하여 단일 공격 시나리오로 확정
2. **티켓 표준 전달**: 인시던트의 심각도(Severity)와 공격자 아티팩트를 JSON으로 SOAR에 인가
3. **자동화 워크플로우**: SOAR가 사전 정의된 SOP에 따라 위협 지표를 심층 검증
4. **오케스트레이션 조치**: 다수의 보안 장비에 병렬로 REST API 명령을 전달하여 즉각 격리
5. **폐루프 환류**: 최종 처리 결과를 기록하고, 오탐으로 판정된 경우 SIEM의 탐지 임계치를 상향 조정

#### 한줄 요약
- SIEM 상관 탐지, 표준 티켓 전달, SOAR 플레이북 실행, 다중 API 조치, 상태 검증 및 룰 환류 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **SIEM vs SOAR 핵심 차이점**: 분석 및 가시성 중심(SIEM)과 오케스트레이션 및 대응 자동화 중심(SOAR)의 아키텍처 비교.

</details>

| 비교 항목 | SIEM (보안 정보 및 이벤트 관리) | SOAR (보안 오케스트레이션/자동화/대응) |
|:---|:---|:---|
| **핵심 목적** | **전사 보안 가시성 확보 및 위협 탐지 (Detection)** | **사고 대응 프로세스 자동화 및 조치 (Response)** |
| **주요 입력 데이터** | **전사 원시 로그 (Syslog, Event Log, Flow, Audit)** | **SIEM/EDR이 정제하여 발행한 보안 경보 (Alert)** |
| **핵심 기술 메커니즘**| **로그 정규화, 시계열 상관 분석, UEBA 머신러닝** | **API 오케스트레이션, 플레이북(BPMN), 멱등성** |
| **결과물 (Output)** | **위협 인시던트(Incident) 경보, 대시보드, 감사 로그**| **방화벽 차단, PC 격리, 티켓 자동 종결, 감사 보고서**|
| **단독 운영 한계** | 탐지 후 조치가 수동으로 이루어져 대응 지연 발생 | 광범위한 원시 로그 상관 분석 및 저장 능력 부재 |

#### 한줄 요약
- SIEM은 빅데이터 상관 분석을 통한 탐지 플랫폼이며, SOAR는 API 오케스트레이션을 통한 자동 대응 플랫폼이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **권한 집중 위험(Concentration of Privilege)**: SOAR가 사내 모든 방화벽, 스위치, AD, EDR의 관리자 권한(API Key)을 집중 보유함에 따라, SOAR 플랫폼 침해 시 전사 인프라 제어권이 탈취될 수 있는 위험.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| SIEM의 오탐 경보가 SOAR 완전 자동화와 연계되어 정상 비즈니스 트래픽을 오차단 | 경보 연동 시 **신뢰도 점수(Confidence $\ge 90$) 필터링** 및 **고영향 조치 HITL 승인** 강제 | 정상 서비스 가용성 보호 및 오탐으로 인한 서비스 중단 원천 차단 |
| SOAR 조치 API 호출 후 방화벽 통신 장애로 인한 차단 미반영 및 보안 사각지대 | 플레이북 내 **조치 후 대상 상태 재조회(State Verification) 검증** 로직 필수화 | 차단 룰 적재 성공률 100% 검증 및 미조치 보안 구멍 방어 |
| SOAR 플랫폼 마스터 계정 탈취로 인한 전사 보안 통제권 상실 및 악의적 시스템 마비 | SOAR 서비스 계정의 **최소 권한(Least Privilege) 적용 및 API Key HSM 보관/MFA** | 권한 집중 리스크 해소 및 SOAR 플랫폼 자체의 침해 저항성 확보 |

#### 한줄 요약
- 신뢰도 필터링으로 오차단을 방지하고, 상태 재조회로 조치 성공을 검증하며, 최소 권한으로 SOAR 계정을 보호한다.

## Ⅶ. 결론

- 차세대 지능형 보안관제센터(SOC)의 효율성과 신뢰성을 극대화하기 위해 **SIEM의 빅데이터 상관 분석 탐지 능력**과 **SOAR의 오케스트레이션 기반 자동 대응 능력**을 결합한 통합 폐루프 아키텍처를 표준 모델로 도입하되, 운영 안정성을 확보하기 위해 **표준 경보 계약 체결**, **HITL 승인 관문 분기**, **상태 재조회 및 룰 피드백 환류 체계**를 통합 구축하여 지능형 자율 사이버 방어 인프라를 완성

#### 한줄 요약
- SIEM의 탐지와 SOAR의 자동 대응을 폐루프로 결합하여 고신뢰 차세대 보안관제를 실현한다.
