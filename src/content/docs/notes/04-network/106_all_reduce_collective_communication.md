## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **전체 축소(All-Reduce)**: 모든 통신 순위의 값을 하나의 연산으로 축소하고 그 동일한 결과를 다시 모든 순위에 배포하는 집합 통신이다.
- **그래픽처리장치(Graphics Processing Unit, GPU)**: 병렬 연산을 대량 처리하는 가속기이다.
- **축소 후 동일 결과로 전체 배포**: 모든 순위의 값을 하나로 집계하고 같은 결과를 참여 순위 전체에 전달하는 동작이다.
- **대규모 기울기 집계 병목**: 중앙 서버 하나에 모든 GPU의 기울기 전송과 합산이 집중되는 성능 한계이다.

</details>

- 정의/개념: 모든 순위의 값을 **축소 후 동일 결과로 전체 배포**하는 집합 통신이다.
- 배경/필요성: 중앙 서버에 모든 **GPU** 기울기가 모여 **대규모 기울기 집계 병목** 발생한다.

#### 한줄 요약

- 각 GPU가 계산한 기울기를 모두 합치고 똑같은 합계를 다시 나눠 줘 다음 학습 단계를 같은 값으로 시작하게 한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **지연 순위**: 계산이나 통신 완료가 가장 늦어 모든 GPU의 다음 단계를 기다리게 하는 순위이다.
- **축소 분산(Reduce-Scatter)**: 입력을 조각별로 축소해 각 순위가 서로 다른 완성 조각 하나씩을 보유하게 하는 연산이다.
- **전체 수집(All-Gather)**: 각 순위가 보유한 조각을 서로 교환해 모든 순위가 전체 결과를 갖게 하는 연산이다.
- **집계 연산 계약**: 모든 순위의 형상•자료형•연산•호출 순서를 맞추는 규칙이다.

</details>

- **축소 분산**•**전체 수집** 기반 집계•배포가 핵심이다.
- 자료 크기•토폴로지에 따라 링•트리•계층형을 선택한다.
- **지연 순위** 및 **집계 연산 계약** 불일치가 전체 완료를 지연•중단시킨다.

#### 한줄 요약

- 한 GPU가 늦거나 다른 순서로 통신을 호출하면 나머지 GPU도 다음 계산을 시작하지 못한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **순위 통신 그룹**: 집합 통신에 참여하는 프로세스•GPU 범위이다.
- **집합 통신 엔진**: 링•트리•계층 알고리즘을 실행하는 구성요소이다.
- **토폴로지 경로**: NVLink•RDMA 링크로 구성된 전송 경로이다.
- **순위(Rank)**: 통신 그룹 안에서 각 프로세스나 GPU를 구분하는 번호이다.
- **원격 직접 메모리 접근(Remote Direct Memory Access, RDMA)**: 호스트 간 등록 메모리를 직접 연결하는 전송 기술이다.

</details>

```text
All-Reduce 통신 구조
├─ 순위 통신 그룹
├─ 집계 연산 계약
├─ 버킷 스케줄러
├─ 집합 통신 엔진
└─ 토폴로지 경로
```

가지의 의미: 참여•계약•묶음•집계•전송 책임을 분리한 정적 구조이다.

| 구성요소 | 책임 |
|:---|:---|
| 순위 통신 그룹 | **순위 통신 그룹** 각 **순위** 참여 프로세스•GPU 범위 정의 |
| 집계 연산 계약 | **집계 연산 계약** 형상•자료형•연산 일치 규정 |
| 버킷 스케줄러 | **버킷 스케줄러** 텐서 묶음•계산 통신 중첩 |
| 집합 통신 엔진 | **집합 통신 엔진** 링•트리•계층 알고리즘 실행 |
| 토폴로지 경로 | **토폴로지 경로** NVLink•**RDMA** 링크 제공 |

#### 한줄 요약

- 같은 그룹의 GPU가 동일한 자료 형식과 연산을 약속하면 스케줄러가 텐서를 묶고 통신 엔진이 링크에 맞는 경로를 선택한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **호출 계약 확인**: 모든 순위의 그룹•형상•자료형•연산•호출 순서가 같은지 확인하는 단계이다.
- **텐서 버킷 구성**: 작은 텐서를 경로 특성과 크기에 맞는 전송 묶음으로 만드는 단계이다.
- **축소 분산 교환**: 조각별 값을 축소해 각 순위가 서로 다른 완성 조각을 갖게 하는 단계이다.
- **전체 수집 교환**: 각 순위의 완성 조각을 교환해 모든 순위가 전체 결과를 갖게 하는 단계이다.

</details>

```text
All-Reduce 호출
        │
        ▼
1. 호출 계약 확인
        ├─ 불일치: 통신 중단
        └─ 일치
             │
             ▼
2. 텐서 버킷 구성
        │
        ▼
3. 축소 분산 교환
        └── 모든 조각 축소까지 반복
                    │
                    ▼
4. 전체 수집 교환
        └── 모든 조각 수집까지 반복
                    │
                    └── 동일 집계 결과 반환
```

### 동작 원리

1. 호출 계약 확인: 그룹•형상•자료형•연산의 **호출 계약 확인** 수행한다.
2. 텐서 버킷 구성: 자료를 경로•크기에 맞게 묶는 **텐서 버킷 구성** 수행한다.
3. 축소 분산 교환: 조각별 축소 결과를 나눠 갖는 **축소 분산 교환** 수행한다.
4. 전체 수집 교환: 집계 조각의 **전체 수집 교환** 기반 모든 순위가 결과를 얻는다.
#### 한줄 요약

- 큰 배열을 조각내 서로 더한 뒤 각자 완성한 조각을 다시 모두 교환해 모든 GPU가 같은 전체 결과를 갖는다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **계층형 All-Reduce**: 서버 내부의 빠른 링크로 먼저 집계한 뒤 서버별 결과만 느린 외부망에서 교환하는 방식이다.
- **링 All-Reduce(Ring All-Reduce)**: 순위를 고리로 연결해 조각을 이웃에 순환 전송하며 링크 대역폭을 고르게 사용하는 방식이다.
- **트리 All-Reduce(Tree All-Reduce)**: 트리의 상향 경로로 값을 축소하고 하향 경로로 결과를 배포하는 방식이다.

</details>

| All-Reduce 알고리즘 | **링 All-Reduce** | **트리 All-Reduce** | **계층형 All-Reduce** |
|:---|:---|:---|:---|
| 적용 기준 | 큰 텐서•균일 링크의 대역폭 우선 | 작은 텐서•다수 순위의 지연 우선 | 내부•외부 링크의 성능 차이가 큰 환경 |
| 핵심 특징 | 이웃 순환•대역폭 균등 | 상향 집계•하향 배포 | 내부 집계 후 외부 교환 |
| 한계 | 느린 링크의 전체 링 제한 | 상위 링크 집중•트리 불균형 | 계층 경계•순위 배치 오류 |

#### 한줄 요약

- 큰 자료는 링, 짧은 응답 단계는 트리, 서버 안과 밖의 링크 차이가 크면 계층형을 사용한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **호출 순서•형상 불일치**: GPU 순위별 집합 연산 계약이 달라 대기나 결과 오류를 만드는 문제이다.
- **교착(Deadlock)**: 순위별 호출 순서가 달라 서로 다른 집합 연산 완료를 무한히 기다리는 상태이다.
- **계층형 축소(Hierarchical Reduction)**: 서버 내부에서 먼저 축소한 뒤 서버별 결과만 외부망에서 교환해 저속 구간의 통신량을 줄이는 방식이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| **지연 순위** 전체 지연 | 순위별 완료시간•링크 감시 | 병목 순위 식별 |
| 내부•외부 링크 성능 차이 | **계층형 축소**•외부 교환 | 저속망 통신량 감소 |
| 호출 순서•형상 불일치 | **집계 연산 계약** 사전 검증 | **교착**•결과 오류 방지 |

#### 한줄 요약

- 서버 내부는 NVLink로 먼저 집계하고 서버별 결과만 RDMA망에서 교환해 느린 외부 링크의 통신량을 줄인다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **최느린 순위 병목(Straggler Bottleneck)**: 가장 늦은 순위의 완료 시간이 동기식 집합 통신 전체 완료 시간을 결정하는 현상이다.
- **All-Reduce 알고리즘 선택**: 텐서 크기•순위 수•내부와 외부 링크 차이에 따라 링•트리•계층형을 결정하는 판단이다.

</details>

- 큰 텐서는 링, 저지연은 트리, 링크 차이는 계층형 **알고리즘 선택**이다.

#### 한줄 요약

- 전체 축소는 단일 링크 속도보다 가장 느린 순위와 내부•외부 경로를 함께 보고 전체 완료 시간을 줄여야 한다.
