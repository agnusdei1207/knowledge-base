## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **촉각 인터넷(Tactile Internet)**: 사람의 조작과 원격 장치의 힘•촉감 반응을 짧고 예측 가능한 지연으로 왕복 전달하는 폐루프 통신 체계이다.

</details>

- 정의/개념: **촉각 인터넷**은 원격 조작과 촉각 반응을 짧고 예측 가능한 지연으로 왕복 전달한다.
- 배경/필요성: 불규칙한 지연과 지터는 제어 오차와 진동을 유발한다.

#### 한줄 요약

- 멀리 있는 로봇을 움직일 때 손의 명령과 로봇이 느낀 힘을 즉시 주고받아 현장에서 만지는 것처럼 제어한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **왕복 지연•지터(Round-Trip Delay/Jitter)**: 왕복 지연은 명령과 반응이 오가는 시간이고 지터는 패킷마다 도착 시간이 달라지는 정도이다.
- **로컬 안전 제어(Local Safety Control)**: 통신이 끊기거나 지연 한계를 넘을 때 원격 장치가 자체 한계•정지 규칙을 실행하는 기능이다.

</details>

- **왕복 지연•지터**의 상한으로 제어 안정성을 판단한다.
- 통신 실패 시 **로컬 안전 제어**로 힘•위치 한계와 정지를 적용한다.

#### 한줄 요약

- 평소 빠른 것보다 순간적으로 늦어질 때 로봇이 흔들리지 않고 스스로 멈출 수 있는지가 더 중요하다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **햅틱 조작기(Haptic Controller)**: 사용자의 위치•힘 명령을 감지하고 원격 장치의 촉각 반응을 재현하는 장치이다.
- **엣지 제어기(Edge Controller)**: 사용자와 원격 장치 가까이에서 지연 예측•보간•상태 동기화를 수행하는 장치이다.

</details>

- **햅틱 조작기**가 위치•힘 명령과 촉각을 변환하고 **엣지 제어기**가 지연 예측•보간•상태 동기화를 수행한다.

```text
촉각 인터넷
├─ 햅틱 조작기
├─ 초저지연 전송망
├─ 엣지 제어기
├─ 원격 로봇
└─ 로컬 안전 제어기
```

선의 의미: 주 구조는 위치•힘 명령과 촉각 피드백의 폐루프 통신 관계이고, 원격 로봇은 통신 실패에도 힘•위치 한계와 정지를 적용하는 로컬 안전 제어기와 결속된다.

| 구성요소 | 책임 |
|:---|:---|
| 햅틱 조작기 | 위치•힘 명령•촉각 재현 |
| 초저지연 전송망 | 명령•피드백 지연•지터 제한 |
| 엣지 제어기 | 지연 예측•보간•상태 동기화 |
| 원격 로봇 | 명령 실행•힘•위치 상태 반환 |
| 로컬 안전 제어기 | 통신 실패 한계•정지 적용 |

#### 한줄 요약

- 조작기와 로봇이 명령과 힘을 주고받고 엣지가 늦은 값을 보정하며 로컬 제어기가 통신 실패 시 로봇을 정지한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **표본화(Sampling)**: 연속적인 위치•힘 신호를 일정 주기의 디지털 값으로 변환하는 처리이다.
- **촉각 상태 피드백(Haptic State Feedback)**: 원격 장치의 실행 결과와 접촉 힘을 사용자 조작기로 되돌려 주는 정보이다.
- **조작 명령 표본화**: 손의 연속 위치•힘 명령을 주기적인 디지털 제어값으로 바꾸는 단계이다.
- **예측 명령 전달**: 지연 상태를 추정해 보정한 제어값을 원격 장치에 보내는 단계이다.
- **동작 한계 검사**: 명령의 힘•위치가 현장 안전 범위 안인지 확인하는 단계이다.
- **촉각 상태 피드백 단계**: 실행 결과와 접촉 힘을 사용자 조작기로 되돌리는 단계이다.

</details>

```text
반복 범위: 촉각 제어 주기마다 1~4단계

1. 조작 명령 표본화
      │
      ▼
2. 예측 명령 전달
      │
      ▼
3. 동작 한계 검사
      ├─ 한계 초과: 로컬 안전 정지
      └─ 허용
          │
          ▼
4. 촉각 상태 피드백 단계
          ├─ 지연•통신 한계 초과: 안전 정지
          └─ 정상: 촉각 재현 후 1단계 반복
```

### 동작 원리

1. **조작 명령 표본화**: **조작 명령 표본화** 단계에서 **표본화**로 손의 위치•힘을 변환한다.
2. **예측 명령 전달**: **예측 명령 전달** 단계에서 지연 상태를 추정해 제어값을 보정한다.
3. **동작 한계 검사**: **동작 한계 검사** 단계에서 힘•위치의 안전 범위를 확인한다.
4. **촉각 상태 피드백 단계**: **촉각 상태 피드백 단계**에서 **촉각 상태 피드백**을 조작기로 반환한다.

#### 한줄 요약

- 손의 움직임을 로봇에 보내고 접촉한 힘을 돌려받되 값이 늦으면 엣지가 보정하고 위험하면 로봇이 스스로 멈춘다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **원격•엣지•로컬 제어(Remote/Edge/Local Control)**: 사람이 직접 명령하거나 엣지가 예측을 보완하거나 현장 장치가 자체 판단하는 제어 위치 분류이다.
- **폐루프 제어(Closed-Loop Control)**: 명령 실행 결과를 다시 입력으로 받아 다음 명령을 계속 보정하는 제어 방식이다.

</details>

| 제어 위치 | 양방향 원격 제어 | 엣지 예측 제어 | 로컬 자율 제어 |
|:---|:---|:---|:---|
| 적용 기준 | **원격•엣지•로컬 제어** 중 짧고 예측 가능한 망 지연 | 코어망 지연 변동 보완 | 통신 단절 중 작업 지속 |
| 핵심 특징 | **폐루프 제어**로 명령•촉각 직접 왕복 | 엣지 지연 상태 예측 | 현장 상태 자체 판단 |
| 한계 | 지연 기반 진동•오조작 | 예측 오차 누적 | 사람 의도•자율 판단 충돌 |

> 요약: 지연 변동•자율성 요구로 제어 위치를 선택한다.

#### 한줄 요약

- 망이 충분히 빠르면 사람이 직접 제어하고 변동이 있으면 엣지가 보정하며 단절을 견뎌야 하면 로봇의 자율성을 높인다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **적응형 보간(Adaptive Interpolation)**: 지연•손실 상태에 따라 늦거나 빠진 표본의 추정 방법과 계수를 바꾸는 처리이다.
- **안전 자세(Safe Pose)**: 통신•제어 실패 시 물리 피해를 줄이도록 미리 정한 로봇 위치와 상태이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 지터 급증의 제어 진동 | 지연 예측과 **적응형 보간** 적용 | 폐루프 안정성 유지 |
| 피드백 손실의 힘 오판 | 로컬 힘•위치 안전 한계 적용 | 물리 피해와 오조작 방지 |
| 회선 단절의 원격 제어 상실 | **안전 자세**로 현장 자동 정지 | 통신 실패의 영향 격리 |

#### 한줄 요약

- 촉각 피드백이 지연되거나 끊겨도 수술 로봇이 힘과 위치 한계를 넘지 않고 안전 자세로 정지하도록 로컬 제어를 둔다.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- **제어 안정성(Control Stability)**: 지연•손실•통신 단절이 있어도 제어 출력이 발산하거나 진동하지 않고 안전 범위를 유지하는 성질이다.

</details>

- **제어 안정성**을 기준으로 안정 초저지연은 원격 제어, 지연 변동은 엣지 예측, 단절은 로컬 자율을 선택한다.

#### 한줄 요약

- 촉각 인터넷은 최고 속도보다 최악의 왕복 지연과 통신 실패 때 어느 위치에서 보정하고 멈출지를 먼저 설계해야 한다.
