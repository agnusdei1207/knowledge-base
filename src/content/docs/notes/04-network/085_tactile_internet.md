## 미리 알고가기

- **촉각 인터넷(Tactile Internet)**: 사람의 조작과 원격 장치의 힘·촉감 반응을 매우 짧고 예측 가능한 지연으로 왕복 전달하는 통신 체계다.
- **햅틱(Haptic)**: 힘, 진동과 촉감 정보를 감지하거나 사용자에게 되돌려 주는 상호작용 기술이다.
- **폐루프 제어**: 명령을 실행한 결과를 다시 입력으로 받아 다음 명령을 계속 보정하는 제어 방식이다.
- **왕복 지연(Round-Trip Time)**: 명령이 원격 장치에 도착하고 그 반응이 사용자에게 돌아오기까지 걸린 시간이다.
- **지터(Jitter)**: 패킷마다 도착 시간이 달라지는 정도이며 제어 주기를 흔들 수 있다.
- **엣지 제어기**: 사용자와 원격 장치 가까이에서 예측·보간과 빠른 제어를 수행해 먼 서버 왕복을 줄이는 장치다.
- **보간**: 늦거나 빠진 표본 사이의 값을 주변 표본으로 추정해 제어 입력을 이어 주는 처리다.
- **로컬 안전 제어**: 통신이 끊기거나 지연 한계를 넘을 때 원격 장치가 자체 한계·정지 규칙을 실행하는 기능이다.

## Ⅰ. 개요

- **정의/개념**: 원격 조작·촉각 반응의 초저지연 폐루프
- **배경/필요성**: 지연·지터가 원격 제어 오차와 진동 유발

### 쉽게 이해하기 (학습용)

- 멀리 있는 로봇을 움직일 때 손의 명령과 로봇이 느낀 힘을 즉시 주고받아 현장에서 만지는 것처럼 제어한다.

## Ⅱ. 특징

- 명령·힘 피드백이 양방향 제어 루프를 형성한다.
- 최악 지연·지터가 제어 안정성을 좌우한다.
- 늦은 촉각 정보가 제어 오동작 위험을 높인다.
- 로컬 안전 제어가 통신 실패 영향을 제한한다.

### 쉽게 이해하기 (학습용)

- 평소 빠른 것보다 순간적으로 늦어질 때 로봇이 흔들리지 않고 스스로 멈출 수 있는지가 더 중요하다.

## Ⅲ. 아키텍처 및 구성요소

```mermaid
flowchart LR
    subgraph T[촉각 제어 경계]
        A["햅틱 조작기"] <-->|명령·촉각| B["초저지연 전송망"]
        B <-->|예측·보간| C["엣지 제어기"]
        C <-->|제어·상태| D["원격 로봇"]
        E["로컬 안전 제어기"] -->|한계·정지| D
    end
```

| 설계 요소 | 설명 |
|:---|:---|
| 햅틱 조작기 | 위치·힘 명령 생성과 촉각 재현 |
| 초저지연 전송망 | 명령·피드백의 지연·지터 제한 |
| 엣지 제어기 | 지연 예측·누락 보간·상태 동기화 |
| 원격 로봇 | 명령 실행과 힘·위치 상태 반환 |
| 로컬 안전 제어기 | 통신 실패 시 한계 적용·정지 |

> 요약: 종단 제어 루프와 로컬 안전 제어 분리

### 쉽게 이해하기 (학습용)

- 조작기와 로봇이 명령과 힘을 주고받고 엣지가 늦은 값을 보정하며 로컬 제어기가 통신 실패 시 로봇을 정지한다.

## Ⅳ. 원리 및 절차 흐름도

```mermaid
sequenceDiagram
    participant 조작기
    participant 엣지
    participant 로봇
    participant 안전제어기
    조작기->>엣지: 조작 명령 표본화
    엣지->>로봇: 지연 예측·명령 전달
    로봇->>로봇: 힘·위치 한계 검사
    로봇-->>엣지: 상태·촉각 피드백
    엣지-->>조작기: 누락 보간·촉각 재현
    alt 지연·통신 한계 초과
        안전제어기->>로봇: 로컬 안전 정지
    end
```

| 절차 | 설명 |
|:---|:---|
| 조작 명령 표본화 | 손의 위치·힘을 주기적으로 변환 |
| 지연 예측·명령 전달 | 예상 상태로 늦은 명령을 보정 |
| 힘·위치 한계 검사 | 위험 범위를 넘는 동작을 제한 |
| 상태·촉각 피드백 | 실행 결과와 접촉 힘을 반환 |
| 누락 보간·촉각 재현 | 빠진 값을 채워 사용자에게 출력 |
| 로컬 안전 정지 | 통신 한계 초과 시 자체 정지 |

> 요약: 명령·촉각 폐루프를 예측하고 실패 시 정지

### 쉽게 이해하기 (학습용)

- 손의 움직임을 로봇에 보내고 접촉한 힘을 돌려받되 값이 늦으면 엣지가 보정하고 위험하면 로봇이 스스로 멈춘다.

## Ⅴ. 종류 및 비교

| 판단 기준 | 양방향 원격 제어 | 엣지 예측 제어 | 로컬 자율 제어 |
|:---|:---|:---|:---|
| 핵심 특징 | 사람 명령과 촉각을 직접 왕복 | 가까운 엣지가 늦은 상태를 예측 | 로봇이 현장 상태로 자체 판단 |
| 적용 기준 | 망 지연이 매우 짧고 예측 가능 | 코어망 지연 변동을 보완 | 통신 단절에도 작업 지속 필요 |
| 주요 위험 | 지연으로 진동·오조작 | 예측 오차 누적 | 사람 의도와 자율 판단 충돌 |

> 요약: 지연 변동·자율성 요구로 제어 위치 선택

### 쉽게 이해하기 (학습용)

- 망이 충분히 빠르면 사람이 직접 제어하고 변동이 있으면 엣지가 보정하며 단절을 견뎌야 하면 로봇의 자율성을 높인다.

## Ⅵ. 실무 사례

1. 원격 수술 로봇에 힘 한계·안전 정지 적용
2. 위험 설비 로봇에 엣지 촉각 보간 적용

### 쉽게 이해하기 (학습용)

- 원격 수술은 통신이 늦어져도 로봇이 정해진 힘과 위치를 넘지 않고 안전 자세로 멈추게 한다.
- 위험 설비를 다루는 로봇은 순간적으로 빠진 촉각 값을 가까운 엣지에서 보간해 조작의 끊김을 줄인다.

## Ⅶ. 결론

- 최악 지연·지터·안전 한계로 제어 위치 결정

### 쉽게 이해하기 (학습용)

- 촉각 인터넷은 최고 속도보다 최악의 왕복 지연과 통신 실패 때 어느 위치에서 보정하고 멈출지를 먼저 설계해야 한다.
