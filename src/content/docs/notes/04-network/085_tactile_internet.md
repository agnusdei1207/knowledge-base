## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **촉각 인터넷 (Tactile Internet)**: 단순히 화면만 보고 로봇을 원격 조종하는 걸 넘어서, 원격 로봇이 물건을 집을 때 느끼는 압력이나 저항감(촉각)을 사람 손에 1ms 안에 전달해서 진짜 눈앞에서 직접 만지는 것처럼 해주는 극한의 초저지연 통신망이다.

</details>

- 정의: **촉각 인터넷**은 원격 장치를 조작할 때 발생하는 힘과 촉감(Haptic) 반응을 사람이 이질감을 못 느끼는 극한의 초저지연(1ms 이하)으로 왕복 전달하는 **폐루프(Closed-loop) 제어 통신 체계**다.
- 배경: 원격 수술이나 폭발물 제거를 할 때, 화면(시각)만 보고 로봇 팔을 움직이면 힘 조절이 안 돼서 환자 장기가 터지거나 폭탄이 터지니까, **직접 만지는 느낌(촉각)을 실시간으로 쏴주는 기술이 팩트로 필요했다.**

#### 한줄 요약

- 지구 반대편에 있는 수술 로봇을 조종할 때, 로봇이 만지는 살의 부드러움을 내 손끝에 실시간으로 전달해 주는 마법이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **왕복 지연/지터 (RTT/Jitter)**: 내 명령이 가고 로봇의 촉각이 돌아오는 시간(왕복 지연)이 1ms를 넘기거나, 도착 시간이 들쭉날쭉(지터)하면 사람이 멀미를 느끼고 뇌 정지가 와서 조작을 망친다.
- **로컬 안전 제어 (Local Safety Control)**: "어? 통신 끊겼네? 나 혼자 멈춰야지" 하고, 핑이 튀거나 통신이 죽었을 때 로봇이 스스로 위험을 감지하고 그 자리에 얼어붙는 생명줄이다.

</details>

- **1ms 왕복 지연의 팩트**: 인간의 뇌는 1ms 이상 늦게 촉각이 오면 멀미(사이버 멀미)를 느끼거나 조작 실수를 하므로, 5G 급 이상의 초저지연망이 절대적으로 필요하다.
- **로컬 우선 안전망**: 통신이 1초만 렉 걸려도 환자 배를 찌를 수 있기 때문에, 문제 발생 시 로봇이 자체적으로 힘(Force)과 위치 한계를 락(Lock) 거는 안전 제어가 필수다.

#### 한줄 요약

- 평소엔 빛의 속도로 촉각을 전달하다가, 인터넷이 조금이라도 끊기면 로봇이 스스로 멈춰서 사고를 막는다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **햅틱 조작기 (Haptic Controller)**: 의사가 손에 끼고 움직이면 그 힘을 센서로 읽고, 반대로 로봇이 살을 쨀 때 느끼는 저항감을 모터로 사람 손에 때려주는 장갑이나 조이스틱 장비다.
- **엣지 제어기 (Edge Controller)**: 클라우드까지 갔다 오면 늦으니까 공장/병원 현장 근처에서 딜레이를 예측하고 보정해 주는 초고속 두뇌다.

</details>

```text
[ 촉각 인터넷 폐루프 팩트 폭행 구조 ]

[ 1. 햅틱 조작기 (Master) ] ── (의사가 힘 줘서 조이스틱 밀고, 저항감(촉각) 팩트로 느낌)
      │▲
  명령││촉각 피드백 (1ms 이내 왕복)
      ▼│
[ 2. 엣지 제어기 / 초저지연 전송망 ] ── (5G/TSN 타고 딜레이 없이 빛의 속도로 쏨)
      │▲
  명령││촉각 피드백
      ▼│
[ 3. 원격 로봇 (Slave) ] ── (명령대로 환자 살 째고, 딱딱한 뼈 닿으면 촉각 데이터 쏨)
      │
[ 4. 로컬 안전 제어기 ] ── (통신 끊기면 로봇 팔 환자 안 찌르게 즉시 얼음!)
```

| 구성요소 | 팩트 폭행 책임 | 비고 |
|:---|:---|:---|
| **햅틱 조작기** | 내 움직임을 쏴주고, **로봇이 느낀 촉감을 내 손에 모터로 재현해 주는 놈** | Master Domain |
| **전송망 / 엣지 제어기**| 1ms 딜레이 지키면서, **조금 늦으면 알아서 값 땜빵(보간)해 주는 중간 다리** | Network / Edge |
| **원격 로봇** | 명령대로 썰고 찌르며 **현장의 단단함, 저항 등 촉각 데이터 뽑아내는 노가다꾼** | Slave Domain |
| **로컬 안전 제어기** | 통신 뻗었을 때 **로봇이 헛발질 안 하게 강제로 멈추는 비상 브레이크** | Safety Controller |

#### 한줄 요약

- 사람이 햅틱으로 조종 $\to$ 5G 망으로 전달 $\to$ 로봇이 찌르고 촉각 보냄 $\to$ 늦으면 엣지가 보완하고 끊기면 로컬 제어가 멈춘다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **폐루프 제어 (Closed-loop Control)**: 일방적으로 명령만 쏘고 마는 게 아니라(개루프), "명령 $\to$ 실행 $\to$ 촉각 피드백 수신 $\to$ 다시 명령 조절"로 빙글빙글 도는 빡센 실시간 상호작용이다.

</details>

```text
[ 1ms 초저지연 폐루프 촉각 제어 십자포화 흐름 ]

┌──────────────────────────────┐
│ 1. [조작 명령 표본화]        │
│ (의사: 조이스틱을 3cm 밀어 넣음. $\to$ 디지털로 변환해서 쏨)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 2. [예측 명령 전달 및 엣지 보정]
│ (엣지: 핑 살짝 튀네? 예측 보정해서 로봇한테 명령 릴레이)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 3. [동작 한계 팩트 체크 및 실행]
│ (로봇: 3cm면 뼈 안 찌르네? OK! 메스 들어감)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 4. [촉각 피드백 및 로컬 브레이크]
│ (로봇: 딱딱한 뼈에 닿음! 저항값(촉각)을 의사 손으로 바로 쏴줌)
│ (통신 끊기면: 즉시 로컬 안전 정지 가동)
└──────────────────────────────┘
```

### 동작 원리

1. 조작 명령 표본화: 사람 손의 연속적인 아날로그 움직임을 쪼개서 디지털 명령으로 변환함.
2. 예측 명령 전달: 전송망 핑이 살짝 튈 거 같으면 엣지가 눈치껏 값을 보정해서 원격 로봇에 보냄.
3. 동작 한계 검사: 로봇이 명령받자마자 "이거 실행하면 환자 다치나?" 팩트 체크 후 실행함.
4. 촉각 상태 피드백: 로봇이 칼끝으로 느낀 압력을 1ms 만에 의사 손의 햅틱 조이스틱으로 쏴줌. 통신 끊기면 로봇은 즉시 멈춤.

#### 한줄 요약

- 내가 누름 $\to$ 로봇이 찌름 $\to$ 로봇이 저항을 느낌 $\to$ 내 손에 저항이 전해짐 이 과정을 1ms 안에 끝낸다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **원격 / 엣지 / 로컬 자율 제어**: 통신이 쾌적하면 사람이 100% 원격으로 조종하고, 살짝 지연되면 엣지가 땜빵하며, 아예 끊어지면 로봇 혼자 판단(로컬)하는 3단계 비상대책이다.

</details>

| 제어 위치 비교 | **양방향 원격 제어 (사람 100%)** | **엣지 예측 제어 (반자동 보조)** | **로컬 자율 제어 (기계 100%)** |
|:---|:---|:---|:---|
| 팩트 폭행 비유 | **내가 아바타 100% 조종함** | **핑 튀면 엣지가 대충 눈치껏 때움** | **통신 뚝 끊기면 로봇이 알아서 생존함** |
| 적용 기준 | 왕복 지연 1ms 보장될 때 (망 쾌적함) | 코어망 지연이나 핑(Jitter)이 살짝 튈 때 | 통신이 완전 끊겨버렸을 때 (재난 상황) |
| 핵심 특징 | 명령과 촉각이 **빛의 속도로 1:1 직접 왕복함** | 엣지 서버가 **과거 데이터로 지연된 명령을 땜빵함** | 본사 지시 무시하고 **로봇이 자체 센서로 알아서 멈춤** |
| 치명적 한계 | 통신 지연 튀면 **로봇 덜덜 떨리면서 발작함** | 예측 실패하면 **의도랑 다르게 움직여서 대형사고 남** | 사람의 섬세한 의도(수술 등)를 100% 대체 불가 |

#### 한줄 요약

- 핑 좋으면 내가 직접 다 하고, 핑 튀면 엣지가 도와주고, 랜선 뽑히면 로봇이 비상 브레이크 밟는 구조다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **적응형 보간 (Adaptive Interpolation)**: 네트워크에 렉이 걸려서 데이터가 듬성듬성 올 때, 엣지가 눈치껏 빈칸을 부드럽게 채워 넣어서(보간) 로봇이 덜덜 떨지 않게 부드럽게 움직이게 해주는 그래픽 기술 같은 거다.
- **안전 자세 (Safe Pose)**: 수술 중에 통신이 끊겼을 때, 메스를 환자 몸에 박은 채로 굳는 게 아니라, 환자를 찌르지 않게 살짝 칼을 빼고 멈추는 비상 대피 행동 규격이다.

</details>

| 장애/위험 요소 | 원인 분석 | 실무 대책 및 해결방안 | 기대 효과 |
|:---|:---|:---|:---|
| 핑(Jitter) 튀어서 **수술 로봇이 덜덜 떨며 발작함** | 네트워크 지연이 들쭉날쭉해서 늦게 온 데이터를 갑자기 확 반영해버림 | 엣지 제어기가 **적응형 보간(Interpolation) 돌려서 빈 데이터 부드럽게 채워 넣음** | 핑 튀어도 움직임이 부드럽게 유지됨 (폐루프 제어 안정화) |
| 피드백 늦게 와서 **로봇이 계란을 쥐어짜서 터트림** | 압력 데이터(촉각)가 늦게 전달돼서, 사람이 저항감을 못 느끼고 힘을 꽉 줘버림 | 로봇 자체에 **로컬 힘/위치 한계선(Threshold) 세팅해서 과도한 명령은 기계가 씹어버림** | 촉각 지연으로 인한 물리적 파손 및 인명 피해 원천 차단 |
| 통신 뚝 끊겼는데 **칼 들고 그 자리에서 굳어버림** | 인터넷이 끊겼을 때 어떻게 행동해야 할지 비상 대책(Fail-Safe)이 없음 | 회선 단절 감지 시, **환자 안 찌르게 메스 빼는 '안전 자세(Safe Pose)'로 자동 복귀시킴** | 통신 실패가 치명적인 물리적 피해로 번지는 대참사 컷트 |

#### 한줄 요약

- 렉 걸리면 엣지가 땜빵 쳐주고, 렉 때문에 힘 조절 실패할 거 같으면 로봇이 스스로 힘 빼게 만들고, 끊기면 칼 빼고 멈춰라.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- (상단 참조)

</details>

- 1ms의 극한 초저지연을 통해 시각 중심 원격 제어의 물리적 이질감을 없애기 위해, **햅틱 폐루프 통신**과 **초저지연 5G/TSN 망**, **단절 대비 로컬 안전 제어** 기조 확립함

#### 한줄 요약

- 촉각 인터넷은 화면만 보던 답답한 원격 조종을 넘어서, 지구 반대편의 물건을 내 손으로 직접 만지고 비트는 수준의 마법이다.
