## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **Tactile Internet (촉각 인터넷)**: 시각·청각을 넘어 촉각(Kinesthetic/Tactile) 정보를 인간 인지 한계인 1ms 이하의 초저지연과 99.999% 초고신뢰성으로 양방향 전송하는 기술 (ITU-T).
- **Haptic Feedback (햅틱 피드백)**: 원격 로봇이 감지한 표면 질감(Tactile) 및 저항력·위치(Kinesthetic) 데이터를 조작자의 햅틱 장치에 역각으로 재현하는 기술.

</details>

- 정의/개념: 인간의 촉각 반응 시간(1ms)을 충족하기 위해 **URLLC 5G/6G망과 엣지 컴퓨팅을 결합하여 실시간 햅틱 피드백을 전달하는 초저지연 폐루프 통신 기술**
- 배경/필요성: 기존 인터넷의 수십~수백 ms 왕복 지연(RTT) 및 지터로 인한 **원격 수술·정밀 로봇 제어 시 조작 렉, 햅틱 폐루프 불안정성(발산) 및 안전사고 위험**

#### 한줄 요약
- 1ms 초저지연, 99.999% 초고신뢰성, 햅틱 압축 코덱을 통해 원격 촉각 제어 폐루프를 구현한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **1ms E2E Latency**: 센싱부터 네트워크 전송, 액추에이션, 촉각 피드백 수신까지의 전 구간 왕복 지연(RTT)을 1ms 이내로 제한하는 요건.
- **Haptic Codec (IEEE 1918.1)**: 1kHz 이상의 고주파수로 발생하는 햅틱 샘플링 데이터를 인간의 지각 임계치(Weber-Fechner 법칙) 기반으로 압축하는 표준 코덱.

</details>

- **1ms 종단 간 초저지연(URLLC)**: 인간의 촉각 인지 및 근육 반사 시간 한계($\le 1\text{ms}$)를 만족하여 **조작 이질감 완벽 제거**
- **초고신뢰성($99.999\%$) 및 결정론적 전송**: 패킷 손실로 인한 원격 장비의 위치 발산을 막기 위해 **TSN 및 다중 경로 전송 보증**
- **인간 지각 기반 햅틱 압축**: IEEE 1918.1 표준 기반으로 **초당 1,000회의 햅틱 스트림을 대역폭 효율적으로 압축**

#### 한줄 요약
- 1ms 초저지연, 99.999% 초고신뢰성, IEEE 1918.1 햅틱 데이터 압축을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **Master Domain vs Slave Domain**: 인간 조작자 및 햅틱 디바이스가 위치한 마스터 도메인과 실제 작업을 수행하는 원격 로봇/액추에이터 슬레이브 도메인.

</details>

```text
[IEEE 1918.1 촉각 인터넷 폐루프 참조 아키텍처]
|-- Master Domain (인간 조작자 -> 햅틱 장치: 위치/속도 조작 명령 1kHz 샘플링 송출)
`-- Network Domain (5G URLLC / TSN 결정론적 광역망: E2E RTT $\le 1\text{ms}$)
    `-- Edge Intelligence (MEC 서버: 햅틱 예측 보정, 적응형 보간, Dead-band 압축)
`-- Slave Domain (원격 정밀 로봇 / 텔레오퍼레이션 머신)
    |-- Force / Tactile Sensors (접촉 압력, 표면 마찰력 실시간 계측)
    `-- Local Safety Controller (통신 단절 시 Safe Pose 자동 복귀 비상 브레이크)
```

선의 의미: 마스터에서 송출된 조작 명령이 초저지연 네트워크를 거쳐 슬레이브 로봇을 구동하고 반력 데이터가 1ms 내에 역방향 피드백되는 구조

| 구성요소 | 핵심 엔지니어링 책임 | 주요 특징 |
|:---|:---|:---|
| **햅틱 마스터 장비** | 조작자의 위치/속도 궤적을 계측하고 **원격 반력을 햅틱 모터로 역재현** | Master Domain |
| **초저지연 전송망** | 5G URLLC 및 IEEE TSN을 결합하여 **1ms 지연 및 무손실 결정론 전송** | Network Domain |
| **엣지 예측 엔진 (MEC)**| 지터 발생 시 **AI 기반 궤적 예측 및 적응형 보간으로 폐루프 안정성 유지**| Edge Computing |
| **원격 슬레이브 로봇** | 제어 명령에 따라 물리 공정을 수행하고 **센서 접촉력 데이터를 상향 송출** | Slave Domain |
| **로컬 안전 제어기** | 네트워크 단절(Timeout) 감지 시 **로봇을 즉각 안전 자세(Safe Pose)로 격리** | Safety Controller |

#### 한줄 요약
- 햅틱 마스터, 초저지연 전송망, 엣지 예측 엔진, 슬레이브 로봇, 로컬 안전 제어기가 결합된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Dead-Band Control (데드밴드 제어)**: 인간이 감지할 수 없는 미세한 힘/위치 변화량(지각 임계치 미만)은 전송하지 않고 필터링하여 통신 트래픽을 90% 절감하는 기법.

</details>

```text
촉각 인터넷 1ms 폐루프 제어 파이프라인
        │
   1. [조작 명령 표본화] 조작자의 햅틱 인터페이스 움직임을 1kHz 주기로 디지털 변환 송출
        │
   2. [엣지 지연 예측 보정] 네트워크 지터 발생 시 MEC 서버가 궤적을 예측 보정하여 슬레이브로 릴레이
        │
   3. [동작 한계 검증 및 실행] 원격 로봇이 명령을 수신하여 안전 작업 영역(Envelope) 확인 후 구동
        │
   4. [촉각 반력 센싱] 로봇 선단 센서가 물체 접촉 압력과 저항값을 측정하여 햅틱 데이터 패킷 생성
        │
   ▼
5. [1ms 역방향 피드백] 1ms 내에 마스터 장치로 전달되어 조작자 손에 물리적 반력 재현 완결
```

#### 한줄 요약
- 조작 표본화 → 엣지 예측 보정 → 안전 영역 검증 구동 → 반력 센싱 → 1ms 역방향 피드백 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **Full Teleoperation vs Edge Assisted vs Local Autonomous**: 완전 원격 직결, 엣지 예측 보조, 통신 단절 시 로컬 자율 제어의 3단계 운영 모델.

</details>

| 제어 위치 모델 | 양방향 원격 제어 (Full Teleoperation) | 엣지 예측 제어 (Edge Assisted) | 로컬 자율 제어 (Local Autonomous) |
|:---|:---|:---|:---|
| **적용 네트워크 조건** | **왕복 지연 $\le 1\text{ms}$ 보장 (초저지연망)** | 코어망 지연 또는 지터 발생 (1~10ms) | **통신망 완전 단절 발생 (재난 상황)** |
| **제어 책임 주체** | **인간 조작자 100% 직접 조종** | 인간 조작자 + 엣지 AI 예측 보조 | **원격 로봇 탑재 로컬 안전 제어기** |
| **데이터 전송 경로** | 마스터 $\leftrightarrow$ 슬레이브 직접 왕복 | 엣지 서버가 지연 구간 데이터 보간 | 로컬 센서 피드백 기반 독립 루프 |
| **제어 지연 민감도** | 극도로 민감 (지터 시 시스템 불안정) | 중간 (AI 예측 모델로 지연 상쇄) | 지연 영향 없음 (독립 완결) |
| **대표 적용 분야** | **원격 미세 수술, 정밀 로봇 조립** | **원격 중장비 굴삭, 자율주행 원격 제동**| **비상 정지, Safe Pose 대피 모드** |

#### 한줄 요약
- 양방향 원격 제어는 초정밀 수술용, 엣지 예측형은 원격 중장비용, 로컬 자율형은 비상 안전 정지용이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Passivity Control (수동성 제어)**: 전송 지연으로 인해 폐루프 제어계에 에너지가 누적되어 로봇이 발산 진동하는 현상을 감쇠기(Damper) 알고리즘으로 상쇄하여 안정성을 유지하는 제어 이론.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 네트워크 지터로 인한 햅틱 폐루프 불안정성 및 로봇 기계적 발산 진동 | **`수동성 제어기(Passivity Controller)` 및 적응형 보간(Interpolation)** | 제어계 에너지 발산 억제 및 부드러운 모션 유지 |
| 촉각 피드백 지연으로 인한 조작자의 과도한 압력 인가 및 물체 파손 | 로봇에 **`로컬 힘/위치 상한선(Safety Envelope Threshold)` 설정** | 촉각 지연 시에도 물리적 파손 및 의료 사고 차단 |
| 통신 회선 완전 단절 시 로봇이 공정 중간에 멈춰 2차 사고 유발 | **단절 즉시 `사전 정의된 안전 자세(Safe Pose)` 자동 복귀 페일세이프** | 통신 단절 시 환자/설비 안전 무조건 보증 |
| 1kHz 고주파 햅틱 데이터 전송으로 인한 무선 대역폭 과점 | **인간 지각 임계치 기반 `데드밴드(Dead-Band) 압축` 알고리즘** | 햅틱 데이터 전송량 85% 절감 및 인지 품질 유지 |

#### 한줄 요약
- 수동성 제어로 발산을 막고, Safety Envelope로 파손을 방지하며, Safe Pose로 통신 단절을 방어한다.

## Ⅶ. 결론

- 원격 수술, 재난 구조, 스마트 제조에서 인간의 물리적 공간 한계를 극복하기 위해 **촉각 인터넷 아키텍처를 도입**하되, 시스템 안정성과 작업자 안전을 보장하기 위해 **5G URLLC/TSN 1ms 초저지연망, IEEE 1918.1 햅틱 압축 코덱, 수동성 제어(Passivity Control) 및 Fail-Safe 안전 자세 복귀 로직**을 통합 구축하여 고신뢰 인간-기계 협업 인프라 완성

#### 한줄 요약
- 촉각 인터넷은 1ms 초저지연과 햅틱 피드백을 결합하여 시공간을 초월한 실시간 물리 상호작용을 실현하는 차세대 통신 패러다임이다.
