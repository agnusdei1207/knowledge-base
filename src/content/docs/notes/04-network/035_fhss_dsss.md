## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **대역 확산(Spread Spectrum)**: 원래 필요한 주파수 넓이보다 수십 배 넓게 쫙 퍼뜨려서 쏘는 무선 통신 기법. 방해 전파(Jamming) 피하고 도청 막는 데 쓴다.
- **FHSS(주파수 도약 대역 확산)**: 주파수(채널)를 메뚜기처럼 초당 수백 번씩 랜덤하게 계속 바꿔가며 쏘는 방식이다. 블루투스에서 쓴다.
- **DSSS(직접 서열 대역 확산)**: 원본 데이터에 졸라 빠른 가짜 암호(PN 코드)를 섞어서 전파를 대역 전체에 넓게 흩뿌려버리는 방식이다. 구형 와이파이나 GPS에서 쓴다.

</details>

- 정의: 송신 신호 전력을 좁은 대역이 아닌 **광대역 분산 송신 통신 기술** 기반, 주파수를 이리저리 뛰게 하는 **FHSS** 및 암호를 섞어 흩뿌리는 **DSSS** 기반 나뉨
- 배경: 전쟁터나 혼잡한 곳에서 적의 방해 전파(Jamming)나 특정 주파수 간섭을 피하고, 엿듣는 놈들(도청)을 막아 **무전 보안성과 강인함을 확보하기 위해 군사 목적으로 처음 등장함**

#### 한줄 요약

- 적군이 주파수를 방해하거나 엿듣지 못하게, 주파수를 메뚜기처럼 뛰게 하거나 암호를 섞어 흩뿌리는 기술이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **의사잡음 코드(PN Code, Pseudo-Noise)**: 잡음(Noise)처럼 생겼지만 송수신기가 서로 약속해서 갖고 있는 난수표 암호 키다. 이걸 섞으면 신호가 넓게 퍼지고, 다시 섞으면 원래 데이터로 돌아온다.
- **역확산(Despreading)**: 넓게 퍼진 잡음 같은 수신 전파에 똑같은 PN 코드를 다시 곱해서 좁고 뾰족한 원본 데이터로 모아주는(복원) 해독 과정이다.

</details>

- **협대역 간섭 및 재밍(Jamming) 방어**: 신호를 넓게 퍼뜨려 쏘기 때문에, 특정 좁은 주파수에 방해 전파를 강하게 쏴도 원본 훼손 없이 끄떡없음.
- **저전력 밀도 및 도청 차단**: 전력을 넓게 퍼뜨려서 쏘니까 바닥에 깔린 환경 잡음(Noise Floor)처럼 보여서, 암호 키(PN) 없이는 신호 존재 자체를 몰라 도청이 불가능함.
- **역확산을 통한 원신호 복원**: 수신 측에서 동일한 **PN 코드나 도약 패턴(Hopping Pattern)** 을 정확한 타이밍(박자)에 들이대야만 원본 데이터가 튀어나옴.

#### 한줄 요약

- 넓게 흩뿌려서 잡음처럼 보이게 쏜 다음, 약속된 암호 코드로 다시 모아(역확산) 간섭과 도청을 원천 차단한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **확산 규칙 생성기**: 메뚜기처럼 뛸 주파수 순서(FHSS)나 섞어버릴 암호 키 서열(DSSS)을 찍어내는 놈이다.
- **동기 검출기**: 수신기가 송신기의 암호 키 타이밍(박자)을 완벽하게 맞추려고 급격히 추적하는 놈이다. 박자 어긋나면 해독 실패다.

</details>

```text
[ 대역 확산 직관적 비교 구조 ]

[ 송신부 ]
  (원본 데이터) ──(+)──▶ [ 광대역 무선 채널 쏘기 ]
               │
[ 확산 생성기 (PN 암호 / 도약 패턴) ]
               │
               ▼ (무선 채널 전송: 잡음처럼 보임)
               │
[ 수신부 ]
 (동기 검출기: 박자 맞춤)
               │
(도착한 전파) ──(+)──▶ (원본 데이터 복원: 역확산)
               │
[ 확산 생성기 (송신부랑 똑같은 암호/패턴) ]
```

| 구성요소 | 직관적 비교 책임 | 비고 |
|:---|:---|:---|
| **확산 규칙 생성기**| 주파수 점프 순서(FHSS)나 암호 키 서열(PN 코드)을 **미리 약속한 대로 찍어냄** | 알고리즘 |
| **확산 변조기** | 원본 신호를 암호 키로 섞어서 **존나 넓은 노이즈(잡음)처럼 흩뿌려서 발사함** | Spreading |
| **동기 검출기** | 수신부에서 송신부가 섞은 **암호 키 박자(타이밍)를 완벽하게 똑같이 맞춤** | Synchronization |
| **역확산 복조기** | 흩뿌려진 전파에 같은 암호 키를 한 번 더 곱해서 **원본 신호로 다시 뭉침(복원)** | Despreading |

#### 한줄 요약

- 송신부가 암호 키로 섞어 흩뿌려 쏘면, 수신부가 완벽한 타이밍에 같은 암호 키로 다시 뭉쳐 복원한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **적응형 주파수 도약(AFH)**: 랜덤으로 메뚜기 뛰다가 와이파이(간섭) 있는 주파수는 빼고 안 막힌 곳으로만 똑똑하게 뛰는 블루투스의 꼼수 기술이다.

</details>

```text
[ 대역 확산 송수신 십자포화 흐름 ]

┌──────────────────────────────┐
│ 1. [원신호 확산]             │
│ (PN 코드 섞거나 주파수 점프) │
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 2. [광대역 전파 발사]        │
│ (잡음처럼 깔려서 날아감)     │
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 3. [동기 체크]          │
│ (수신부에서 박자 완벽히 맞춤)│
└──────────────┬───────────────┘
      ┌────────┴────────┐
(박자 어긋남)       (박자 완벽함)
      │                 │
      ▼                 ▼
┌────────────────┐┌──────────────────────────────┐
│ 재동기화 시도  ││ 4. 동일 코드로 역확산        │
│ (못 찾으면 팅김)││ (암호 풀어서 원본 체크) │
└────────────────┘└──────────────────────────────┘
```

### 동작 원리

1. 신호 확산(Spread): 송신자가 데이터를 암호 코드(DSSS)나 점프 패턴(FHSS)으로 흩뿌림.
2. 채널 전송: 잡음과 섞인 형태로 무선 채널을 날아감.
3. 동기 추적(Sync): 수신자가 전파를 잡고 송신자의 암호 박자를 1밀리초 오차 없이 맞춤.
4. 신호 역확산(Despread): 박자를 맞춘 상태로 똑같은 암호/패턴을 먹여 원본 데이터를 쏙 빼냄.

#### 한줄 요약

- 암호 섞어 쏘고, 박자 맞추고, 다시 암호 풀어서 원래 데이터를 발라먹는 과정이다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **처리 이득(Processing Gain)**: 신호를 얼마나 넓게 흩뿌렸느냐를 나타내는 수치. 넓게 흩뿌릴수록(이득이 높을수록) 나중에 모았을 때 잡음을 뚫고 나오는 파워(화질/음질)가 좋아진다.

</details>

| 구분 | **FHSS (메뚜기 도약형)** | **DSSS (암호 흩뿌림형)** |
|:---|:---|:---|
| 직관적 비교 원리 | 주파수 채널을 **수백 번씩 이리저리 랜덤 점프하면서 쏨** | 좁은 신호를 PN 코드로 섞어서 **넓은 대역에 쫙 깔아버림** |
| 채널 점유 방식 | 좁은 채널 1개를 순식간에 썼다 빠졌다 함 | 존나 넓은 대역폭을 통째로 점유함 |
| 처리 이득(PG) | 상대적으로 낮음 (점프할 수 있는 채널 갯수에 한계 있음) | **개높음** (대역폭 찢어버릴수록 노이즈 뚫고 잘 나옴) |
| 실무 대표 적용 | 블루투스(Bluetooth), 군사용 무전기 | 구형 와이파이(802.11b), GPS, CDMA |

#### 한줄 요약

- FHSS는 채널을 휙휙 옮겨 타서 간섭을 피하는 놈이고, DSSS는 아예 채널 전체에 전파를 연막탄 치듯 깔아버리는 놈이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **근원거리 문제(Near-Far Problem)**: 수신기(기지국) 바로 옆에 있는 단말기가 쏜 전파(고함) 때문에 멀리 있는 단말기 전파(개미 소리)가 묻혀버리는 DSSS(CDMA)의 치명적 고질병이다.
- **송신 전력 제어(TPC, Transmit Power Control)**: 기지국에 도착할 때 가까운 놈은 개미 소리로 쏘고 먼 놈은 고함 쳐서 도착하는 소리 크기를 똑같이 맞추는 기술이다.

</details>

| 장애/위험 요소 | 원인 분석 | 실무 대책 및 해결방안 | 기대 효과 |
|:---|:---|:---|:---|
| 폰 가까이 있는 블루투스가 **와이파이 켜면 자꾸 끊김** | 와이파이(1~13)랑 블루투스(FHSS)의 2.4GHz 주파수 충돌 | 블루투스에 **적응형 주파수 도약(AFH)** 적용해 와이파이 대역 컷 | 이종 기기 간 전파 간섭(Interference) 씹어 먹음 |
| 멀리 있는 기기 데이터가 **가까운 기기 전파에 묻혀 다 뻗음** | DSSS의 치명적 단점인 **근원거리 문제(Near-Far Problem)** | 기지국이 초당 수백 번씩 **동적 송신 전력 제어(TPC)** 를 빡세게 함 | 근거리/원거리 기기 간 수신 전력 공정성 확보 |
| 수신기가 며칠째 **원래 데이터를 복원 못 하고 헤맴** | 송신기랑 PN 코드(암호) 박자가 1밀리초라도 어긋남 (동기화 실패) | 초기 **탐색(Acquisition)** 및 세밀한 **추적(Tracking)** 회로 투입 | 뼈저린 동기 이탈 방지 및 지속적인 복원 성공 |
| 적군이 좁은 대역에 방해전파 쏴서 **통신 아예 다 끊어버림** | 광대역을 커버할 만큼 **처리 이득(Processing Gain)** 이 부족함 | 칩 레이트(Chip Rate) 확 올려서 대역 확산비(Spreading Factor) 증대 | 재밍(Jamming) 무시하고 강인한 S/N 비 방어 |

#### 한줄 요약

- 블루투스(FHSS)는 와이파이 피해서 메뚜기 뛰게 만들고, DSSS는 멀리 있든 가까이 있든 똑같은 크기로 들리게 전력 제어(TPC)를 빡세게 해라.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- (상단 참조)

</details>

- 보안과 간섭 회피가 중요한 무전기 및 블루투스 환경은 **FHSS** 기술을, 다중 접속(CDMA)과 안정적 고속 전송이 필요한 환경은 빡센 전력 제어(TPC)를 동반한 **DSSS** 활용 적용하는 무선 아키텍처 기조 확립함

#### 한줄 요약

- 대역 확산은 전파를 낭비하는 것처럼 보이지만, 사실은 지옥 같은 무선 환경에서 살아남기 위한 가장 똑똑한 생존 기술이다.
