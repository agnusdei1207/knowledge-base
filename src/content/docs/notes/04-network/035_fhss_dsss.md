## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **대역 확산**: 원신호의 에너지를 더 넓은 주파수 대역에 분산하고 수신 측이 같은 규칙으로 복원하는 전송 방식이다.
- **FHSS(Frequency-hopping Spread Spectrum)**: 반송 주파수를 정해진 순서로 바꿔 신호를 분산하는 방식이다.
- **DSSS(Direct-sequence Spread Spectrum)**: 원신호에 확산 코드를 결합해 넓은 대역에 분산하는 방식이다.

</details>

- 정의/개념: **대역 확산**은 **FHSS**의 주파수 도약이나 **DSSS**의 코드 결합으로 신호를 분산한다.
- 배경/필요성: 협대역 전송은 간섭과 재밍 에너지 집중에 취약하다.

#### 한줄 요약

- 신호를 옮기거나 펼쳐 간섭을 분산한다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **의사잡음 코드(Pseudo-Noise Code, PN 코드)**: DSSS 송수신기가 신호의 확산과 역확산에 함께 사용하는 결정적 코드열이다.
- **동기화**: 송수신기가 도약 순서 또는 확산 코드의 규칙과 시작 시점을 일치시키는 과정이다.

</details>

- **FHSS**는 도약 순서로 간섭 주파수를 회피한다.
- **DSSS**는 **PN 코드**로 신호 대역을 확산한다.
- **동기화**가 맞아야 수신 측에서 역확산할 수 있다.

#### 한줄 요약

- 넓게 퍼뜨린 뒤 같은 열쇠로 다시 모은다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **확산 변조기**: 반송 주파수를 도약시키거나 원신호에 확산 코드를 결합해 광대역 신호를 만드는 장치이다.
- **역확산 복조기**: 같은 확산 규칙을 적용해 수신한 광대역 신호에서 원신호를 복원하는 장치이다.

</details>

```text
대역 확산 송수신 구조
├─ 송신 경계
│  ├─ 확산 규칙 생성기
│  └─ 확산 변조기
├─ 전달 경계
│  └─ 광대역 무선 채널
└─ 수신 경계
   ├─ 동기 검출기
   └─ 역확산 복조기
```

가지의 의미: 송신•전달•수신 책임 경계와 각 구성요소의 소속을 뜻한다.

| 구성요소 | 책임 |
|:---|:---|
| 확산 규칙 생성기 | 도약 순서•**PN 코드** 생성 |
| 확산 변조기 | **확산 변조기**가 반송파 도약 또는 코드 결합 |
| 광대역 무선 채널 | 확산 신호와 간섭 전달 |
| 동기 검출기 | 규칙•시작 시점 **동기화** |
| 역확산 복조기 | **역확산 복조기**가 원신호 복원 |

#### 한줄 요약

- 같은 규칙과 시작 시점이 있어야 복원된다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **확산 규칙**: FHSS의 도약 순서나 DSSS의 코드열처럼 송수신기가 공유하는 신호 분산 기준이다.

</details>

```text
원신호 입력
    │
    ▼
확산 방식 선택
    ├─ FHSS: 도약 순서에 따라 반송 주파수 변경
    └─ DSSS: PN 코드의 칩과 원신호 결합
    │
    ▼
광대역 신호 전송
    │
    ▼
규칙•시점 동기
    ├─ 실패: 재동기
    └─ 성공: 역확산
                 │
                 ▼
             원신호 복원
```

#### 한줄 요약

- 수신기는 **확산 규칙**과 같은 순서와 박자를 찾아야 한다.

## Ⅴ. 종류 및 비교

| 대역 확산 방식 | **FHSS** | **DSSS** |
|:---|:---|:---|
| 적용 기준 | 협대역 간섭 회피 | 코드 구분•확산 효과 |
| 핵심 특징 | 반송 주파수 연속 도약 | **PN 코드**로 신호 확산 |
| 한계 | **동기화** 이탈 | 코드 동기•근원거리 문제 |

> 요약: FHSS는 주파수, DSSS는 코드 확산이 핵심이다.

#### 한줄 요약

- FHSS는 옮기고 DSSS는 펼친다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **근원거리 문제**: 가까운 송신기의 강한 신호가 먼 송신기의 약한 신호를 덮어 코드 분리를 어렵게 하는 현상이다.
- **처리 이득**: 확산 대역폭을 원 데이터 대역폭으로 나눈 값으로 역확산 뒤의 간섭 내성을 나타내는 지표이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 도약•코드 동기 실패 | 획득•추적 구간과 재동기 설계 | 역확산 성공률 향상 |
| **근원거리 문제** | 전력 제어•**처리 이득** 산정 | 수신 포화 방지 |
| **확산 규칙** 노출 | 보안 키와 확산 코드를 분리 | 기밀성 오판 방지 |
| 규제 대역 위반 | 도약 채널•출력•점유율 검증 | 전파 규정 준수 |

#### 한줄 요약

- 좁은 대역 간섭이 잦으면 주파수를 옮기는 FHSS를, 확산 이득이 필요하면 DSSS를 선택한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **협대역 간섭**: 전체 확산 대역 중 일부의 좁은 주파수 구간에 에너지가 집중되는 방해 신호이다.

</details>

- **협대역 간섭** 회피는 **FHSS**, **처리 이득** 확보는 **DSSS**를 선택한다.

#### 한줄 요약

- 신호를 넓게 퍼뜨려 간섭을 분산하고 수신 측은 같은 규칙으로 원신호를 복원한다.
