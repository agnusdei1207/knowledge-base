## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **WAF (Web Application Firewall)**: L7 HTTP/HTTPS 요청 및 응답 페이로드를 심층 분석하여 웹 취약점 공격을 탐지·차단하는 특화 보안 솔루션.
- **OWASP Top 10**: 인젝션, XSS, SSRF 등 웹 애플리케이션에서 가장 치명적인 10대 보안 취약점을 정리한 국제 표준 목록.

</details>

- 정의/개념: HTTP 페이로드를 검사하는 **L7 웹 보안 시스템**
- 배경/필요성: 전통적인 L3/L4 네트워크 방화벽은 IP 주소와 포트(80/443) 단위의 접근 제어만 수행하므로 정상 포트로 유입되는 HTTP/HTTPS 페이로드 내부의 악성 웹 공격(SQL Injection, XSS, Command Injection 등)을 탐지할 수 없고, 소스코드 수정(시큐어 코딩)을 통한 조치는 취약점 발견 후 패치 배포까지 상당한 시간과 비용이 소요되어 제로데이 공격에 무방비로 노출되는 한계를 극복하기 위해, 웹 서버 전단에서 L7 프로토콜을 복호화 및 정규화(Normalization)하여 OWASP Top 10 공격을 실시간 탐지·차단하는 웹 애플리케이션 방화벽(WAF)을 도입하여 **웹 취약점 공격의 1차 방어선 구축, 소스코드 수정 없는 가상 패치(Virtual Patching) 기반 제로데이 즉각 대응 및 개인정보 유출 방지(DLP)**를 달성할 필요

#### 한줄 요약
- L7 심층 검사, 공격 난독화 정규화 해제, 취약점 가상 패치를 통해 웹 애플리케이션을 보호한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **Virtual Patching (가상 패치)**: 소스코드 수정이나 서버 재배포 없이 WAF 룰셋을 즉각 적용하여 알려진 취약점 공격 경로를 선제 차단하는 기술.
- **Normalization (정규화)**: URL 인코딩, Hex, Base64, 유니코드 등으로 난독화된 공격 문자열을 단일 표준 텍스트로 디코딩하는 전처리 과정.

</details>

- **L7 심층 검사**: HTTP 헤더·쿠키·본문의 **공격 차단**
- **정규화**: 난독화 문자열을 복원해 **시그니처 매칭**
- **가상 패치**: 코드 수정 전에 **긴급 룰**로 공격 방어

#### 한줄 요약
- L7 페이로드 심층 검사, 난독화 정규화 해제, 가상 패치를 통한 제로데이 긴급 방어를 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **SSL Offloading**: 암호화된 HTTPS 트래픽을 WAF 단에서 복호화하여 백엔드 서버의 연산 부담을 줄이고 페이로드 가시성을 확보하는 기능.

</details>

```text
[웹 애플리케이션 방화벽(WAF)]
  ├── [암호 종단] ───────── [TLS 종단기 (복호화)]
  │                           │
  ├── [입력 전처리] ─────── [정규화 엔진 (인코딩 해제)]
  │                           │
  ├── [정책 집행] ───────── [정책 엔진 (OWASP 검사)]
  │                           │
  └── [출력/감사] ───────── [DLP 모듈 / 감사 로그]
```

- 선의 의미: 계층 구조 및 상하위 포함 관계를 나타낸다.

| 구성요소 | 책임 |
|:---|:---|
| TLS 종단기 | HTTPS **복호화·가속** |
| 정규화 엔진 | 우회 인코딩을 **표준 평문**으로 변환 |
| 정책 엔진 | **OWASP Top 10** 규칙 검사 |
| DLP 모듈 | 응답의 **민감정보 마스킹** |
| 감사 로그 | **오탐 분석**과 규칙 튜닝 |

#### 한줄 요약
- SSL 종단기가 암호문을 먼저 풀어야 정규화와 룰 검사가 성립하므로, WAF는 암호화 경계를 자신에게 끌어오는 대가로 L7 가시성을 얻는다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Positive vs Negative Security Model**: 허용된 정상 요청 패턴만 인가하는 화이트리스트 모델과 알려진 공격 시그니처를 차단하는 블랙리스트 모델.

</details>

```text
클라이언트 요청
       |
  1. TLS 세션 복호화
       |
  2. 난독화 정규화
       |
  3. 복합 정책 검사
       +-- 공격: 차단·기록
       `-- 정상: 4. 응답 정보 마스킹
                       |
                  클라이언트 응답
```

동작 원리

1. TLS 세션 복호화
2. 난독화 정규화
3. 복합 정책 검사
4. 응답 정보 마스킹

#### 한줄 요약
- 정책 검사에서 통과와 차단이 갈리며, 룰을 조일수록 제로데이 차단률과 정상 요청 오탐이 함께 올라간다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **네트워크 방화벽 (L3/L4)** vs **웹 방화벽 (WAF / L7)** vs **시큐어 코딩 (Secure Coding)**.

</details>

| 비교 항목 | 네트워크 방화벽 (L3/L4) | 웹 방화벽 (WAF / L7) | 시큐어 코딩 (Secure Coding) |
|:---|:---|:---|:---|
| 통제 계층 | **L3/L4** | **L7** | 애플리케이션 **소스코드** |
| 검사 대상 | IP·포트·TCP 플래그 | **URI·헤더·쿠키·본문** | 입력값·로직·메모리 |
| 방어 대상 공격 | 스푸핑·스캔·SYN Flood | **SQL 삽입·XSS·웹셸** | 권한 상승·로직 우회 |
| 한계점 | 웹 페이로드 식별 불가 | 비즈니스 로직 탐지 곤란 | 개발 역량과 수정 비용 의존 |
| 주요 역할 | 경계 **접근 통제** | 웹 공격 방어와 **가상 패치** | 취약점 **근본 제거** |

#### 한줄 요약
- 네트워크 방화벽은 경계 L3/L4 통제, WAF는 L7 공격 실시간 방어, 시큐어 코딩은 소프트웨어 결함 원천 제거를 담당한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **Detection Only Mode (감사 모드)**: 신규 룰 배포 시 오탐으로 인한 서비스 중단을 막기 위해 차단 없이 로그만 기록하며 룰을 검증하는 운영 단계.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 신규 규칙의 **오탐**으로 정상 요청 차단 | **감사 모드**와 허용 목록 튜닝 | 서비스 가용성과 탐지 정확도 확보 |
| 소스 패치 전 **제로데이 방어 공백** | **가상 패치** 긴급 규칙 배포 | 패치 전 공격 차단 |
| TLS 복호화로 **CPU 부하·지연** | **SSL 오프로딩** 또는 SaaS WAF | 처리 지연과 부하 완화 |
| 정규식 기반 **API 구조 검증 한계** | **JSON Schema·OpenAPI** 허용 규칙 | 비정상 매개변수 탐지 |

#### 한줄 요약
- 감사 모드 튜닝으로 오탐을 방지하고, 가상 패치로 제로데이에 대응하며, SSL Offloading으로 부하를 최적화한다.

## Ⅶ. 결론

- 인터넷 대고객 서비스와 클라우드 웹 인프라를 지키는 **가장 필수적이고 보편적인 L7 애플리케이션 보안 통제 솔루션**으로 확고히 정립되었으며, 단순 시그니처 매칭의 한계를 넘어 API 보안(WAAP: Web Application & API Protection), 머신러닝 기반 봇(Bot) 탐지 및 RASP(Runtime Application Self-Protection)와의 결합으로 진화하는 가운데, 실무 WAF 운영 시에는 **신규 룰 배포 시 오탐(False Positive)으로 인한 서비스 중단을 방지하는 탐지 모드(Detection Only) 검증 및 예외 튜닝, 소스코드 긴급 수정을 대신하는 가상 패치(Virtual Patch) 즉시 적용, REST API 트래픽 보호를 위한 OpenAPI/JSON 스키마 검증 연동, TLS 복호화 연산 부하를 해소하는 하드웨어 SSL 오프로딩**을 결합하여 완벽한 웹 보안 신뢰성을 완성

#### 한줄 요약
- WAF는 L7 심층 검사와 가상 패치 및 정규화를 통해 웹 애플리케이션을 안전하게 보호하는 핵심 방어 인프라다.
