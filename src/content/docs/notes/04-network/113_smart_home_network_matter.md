## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **Matter 표준(Matter Standard)**: 인터넷 프로토콜(Internet Protocol, IP)망에서 서로 다른 제조사의 스마트 홈 기기 모델•명령•가입 보안을 통일하는 응용 계층 표준이다.
- **모델•명령•가입 보안**: 기기 기능 표현•제어 명령•신뢰 자격 설치를 함께 규정하는 상호운용 범위이다.
- **응용 계층 표준**: 전송망 위에서 기기 기능•명령•가입•권한의 공통 의미를 규정하는 표준이다.
- **명령•가입•권한 상호운용 한계**: 제조사별 데이터 모델과 신뢰 절차가 달라 생태계 사이 제어가 어려운 문제이다.

</details>

- 정의/개념: IP망에서 제조사별 **모델•명령•가입 보안**을 통일하는 **응용 계층 표준**이다.
- 배경/필요성: 제조사별 **명령•가입•권한 상호운용 한계**가 발생한다.

#### 한줄 요약

- 제조사가 달라도 같은 방식으로 기기를 제어한다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **공통 데이터 모델**: 제조사와 전송망이 달라도 기기의 기능•속성•명령 의미를 동일하게 표현하는 규격이다.
- **다중 관리자**: 여러 생태계의 관리자가 하나의 Matter 기기를 각 패브릭에서 제어하는 기능이다.
- **무선 근거리망(Wireless Fidelity, Wi-Fi)**: Matter 기기에 고대역 IP 연결을 제공하는 무선망이다.
- **스레드(Thread)**: 저전력 기기에 IPv6 메시 연결을 제공하는 무선 네트워크 기술이다.
- **기기 증명•운영 인증서**: 제품 진위를 확인하고 패브릭의 운영 자격과 권한을 부여하는 인증 수단이다.
- **패브릭**: Matter 기기와 관리자가 운영 인증서•키•권한을 공유하는 신뢰 영역이다.

</details>

- **공통 데이터 모델**을 통한 기능•속성•명령 통일이 핵심이다.
- IP 기반 **Wi-Fi**•유선망•**Thread** 연결이 핵심이다.
- **기기 증명•운영 인증서** 기반 안전한 가입•다중 관리자를 제공한다.
- 하나의 **패브릭**에 여러 생태계를 연결하는 **다중 관리자**를 지원한다.

#### 한줄 요약

- 연결과 명령, 가입 보안을 하나의 규칙으로 묶는다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **가입 제어기**: 새 기기의 진위를 확인하고 패브릭 운영 자격을 설치하는 구성요소이다.
- **패브릭 제어기**: 패브릭의 인증서•키•접근 권한과 기기 상태를 관리하는 구성요소이다.
- **IP 연결 계층**: 주소 기반으로 제어기와 Matter 기기의 통신 경로를 제공하는 계층이다.
- **Matter 기기**: 공통 데이터 모델에 따른 기능•속성•명령을 제공하는 기기이다.
- **Thread 경계 라우터(Thread Border Router)**: Thread와 외부 IP망을 연결하는 라우터이다.
- **기기 브리지(Device Bridge)**: 비 Matter 기기의 기능과 명령을 Matter 모델로 변환하는 장치이다.

</details>

```text
Matter 스마트 홈 구조
├─ 가입 제어기
├─ 패브릭 제어기
├─ Matter 기기
├─ IP 연결 계층
├─ Thread 경계 라우터
└─ 기기 브리지
```

가지의 의미: 가입•운영•기기•연결•변환 책임을 분리한 정적 구조이다.

| 구성요소 | 책임 |
|:---|:---|
| 가입 제어기 | **가입 제어기**가 기기 증명•운영 자격 설치 |
| 패브릭 제어기 | **패브릭 제어기**가 인증서•키•권한 관리 |
| Matter 기기 | **Matter 기기**가 공통 기능•속성•명령 제공 |
| IP 연결 계층 | **IP 연결 계층**이 주소 기반 연결 제공 |
| Thread 경계 라우터 | **Thread 경계 라우터**가 Thread•외부 IP망 라우팅 |
| 기기 브리지 | **기기 브리지**가 비 Matter 기기 모델 변환 |

#### 한줄 요약

- 제어기는 패브릭 인증서와 권한으로 기기를 가입시키고 IP 경로에서 공통 명령을 수행한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **커미셔닝**: 새 기기의 진위를 확인하고 패브릭 운영 자격과 접근 권한을 설치하는 가입 절차이다.
- **신뢰 저장소**: 제조사 인증기관 정보를 보관해 기기 증명서의 신뢰 체인을 검증하는 저장소이다.
- **저전력 블루투스(Bluetooth Low Energy, BLE)**: 초기 기기 발견과 가입에 사용하는 저전력 무선 기술이다.
- **IP 운영 통신**: 가입 뒤 패브릭의 기기 제어와 상태 교환에 사용하는 연결이다.
- **기기 증명 요청**: 제어기가 새 기기에 제품 인증 정보 제출을 요구하는 단계이다.
- **증명 정보 전달**: 기기가 제품 인증서와 증명값을 제어기에 제공하는 단계이다.
- **신뢰 체인 검증**: 제조사 인증기관과 제품 인증 정보의 연결을 확인하는 단계이다.
- **운영 자격 설치**: 패브릭 인증서와 접근 권한을 기기에 등록하는 단계이다.

</details>

```text
BLE•IP 가입 요청
        │
        ▼
1. 기기 증명 요청
        │
        ▼
2. 증명 정보 전달
        │
        ▼
3. 신뢰 체인 검증
        ├─ 실패: 가입 거부
        └─ 성공
             │
             ▼
     4. 운영 자격 설치
             │
             └── 커미셔닝 완료
```

### 동작 원리

1. **기기 증명 요청**: **BLE**•IP에서 **기기 증명 요청**을 수행한다.
2. **증명 정보 전달**: 기기가 **증명 정보 전달**로 인증서와 증명값을 제공한다.
3. **신뢰 체인 검증**: **신뢰 저장소**로 **신뢰 체인 검증**을 수행한다.
4. **운영 자격 설치**: **커미셔닝**의 **운영 자격 설치** 후 **IP 운영 통신**을 시작한다.

#### 한줄 요약

- 제품 확인과 사용자 권한 부여를 나눠 수행한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **인터넷 프로토콜 버전 6(Internet Protocol version 6, IPv6)**: 128비트 주소 체계를 사용하는 IP 버전이다.
- **Thread 연결**: 저전력 IPv6 메시 경로를 Matter 기기에 제공하는 방식이다.
- **Wi-Fi 연결**: 고대역 IP 직접 연결을 Matter 기기에 제공하는 방식이다.
- **브리지 연결**: 기존 비 Matter 기기의 기능과 명령을 Matter 모델로 변환하는 방식이다.

</details>

| Matter 연결 방식 | **Thread 연결** | **Wi-Fi 연결**•유선망 | **브리지 연결** |
|:---|:---|:---|:---|
| 적용 기준 | 센서•스위치 | 카메라•허브 | 기존 비 Matter 기기 |
| 핵심 특징 | 저전력 **IPv6** 메시 | 고속 IP 직접 연결 | 비 Matter 모델 변환 |
| 한계 | 경계 라우터 의존 | 무선 혼잡•망 노출 | 기능 손실•권한 검증 누락 |

> 요약: 전력•대역폭과 기존 자산을 기준으로 연결 방식을 선택한다.

#### 한줄 요약

- 저전력 기기는 Thread, 고속 전송 기기는 Wi-Fi가 적합하다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **서명 무선 갱신(Signed Over-the-Air Update, 서명 OTA)**: 디지털 서명으로 출처와 무결성을 검증한 소프트웨어만 기기에 원격 설치하는 갱신 방식이다.
- **기기 발견 트래픽**: 제어기가 같은 IP망에서 Matter 기기와 서비스를 찾기 위해 교환하는 탐색 메시지이다.
- **연결 표준 연합(Connectivity Standards Alliance, CSA)**: Matter 규격과 인증 프로그램을 관리하는 표준화 조직이다.
- **전기전자공학자협회(Institute of Electrical and Electronics Engineers, IEEE)**: 통신•컴퓨팅 기술 표준을 개발하는 전문 조직이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 제조사별 명령•가입 불일치 | **CSA** Matter 1.6 준수 시험 | 생태계 상호운용 확보 |
| Thread 저전력망 품질 저하 | **IEEE** 802.15.4 채널 설계 | 간섭•손실 완화 |
| 업무망과 기기망의 과도한 연결 | 필요한 **기기 발견 트래픽**만 허용 | 공격면 최소화 |
| 기기 취약점의 장기 잔존 | **서명 OTA**•롤백 검증 | 위변조 갱신 차단 |

#### 한줄 요약

- 기기망은 업무망과 격리하고 표준 상호운용 시험과 저전력 채널 측정 뒤 필요한 발견 경로만 허용한다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **연결 방식 선택**: 기기의 전력•대역폭•기존 자산 호환성을 비교해 Thread•Wi-Fi•브리지를 결정하는 과정이다.
- **Wi-Fi 적용 조건**: 고대역폭과 전원 공급이 가능한 Matter 기기에 적용하는 조건이다.

</details>

- 저전력은 **Thread 연결**, **Wi-Fi 적용 조건**을 만족하는 고대역 기기는 **Wi-Fi 연결**, 기존 비 Matter 기기는 **브리지 연결**을 택하는 **연결 방식 선택**이 필요하다.

#### 한줄 요약

- 같은 망보다 같은 의미와 신뢰 절차가 핵심이다.
