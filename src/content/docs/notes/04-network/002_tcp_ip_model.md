## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **TCP/IP 4-Layer Model**: 인터넷 통신 기능을 응용(L4), 전송(L3), 인터넷(L2), 네트워크 인터페이스(L1)의 4개 계층으로 모듈화한 사실상(De facto) 표준 프로토콜 스택.
- **Thin-Waist (모래시계 모델)**: 상위의 다양한 응용/전송 프로토콜과 하위의 다양한 물리망 사이에서 유일한 공통 분모로 IP 계층이 중심을 이루는 아키텍처.

</details>

- 정의/개념: 이기종 네트워크를 상호 연결하기 위해 IP 프로토콜을 중심(Thin-Waist)으로 **응용, 전송, 인터넷, 네트워크 인터페이스 4단계로 구조화한 인터넷 표준 프로토콜 스택**
- 배경/필요성: 초기 이기종 통신망 난립으로 인한 **상호 연결 단절 및 각 통신망 간 1:1 변환 게이트웨이 구축 비용의 기하급수적 증가 한계**

#### 한줄 요약
- IP 중심의 모래시계(Thin-Waist) 구조와 종단 간 원칙(End-to-End)을 통해 글로벌 인터넷을 실현한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **End-to-End Principle (종단 간 원칙)**: 네트워크 코어(라우터)는 단순 패킷 전달만 수행하고, 신뢰성 제어와 오류 복구는 종단 호스트(L4 TCP)가 전담한다는 원칙.
- **Best-Effort Delivery (최선 노력 전달)**: IP 계층이 패킷 전달의 성공을 100% 보장하지 않고 최선의 노력으로만 포워딩하는 비연결형 전송 방식.

</details>

- 복잡한 네트워크 제어를 배제하고 종단 호스트가 신뢰성을 제어하는 **종단 간 원칙(End-to-End)**
- IP 프로토콜 하나로 상위 응용과 하위 물리망을 모두 수용하는 **모래시계(Thin-Waist) 아키텍처**
- 신뢰성이 필요한 연결형(TCP)과 초저지연 비연결형(UDP)을 선택하는 **유연한 전송 계층 제공**

#### 한줄 요약
- 종단 간 원칙, Thin-Waist 구조, TCP/UDP 전송 계층 분리를 통해 높은 확장성과 유연성을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **TCP/IP 4계층 PDU 매핑**: Application(Data), Transport(Segment/Datagram), Internet(Packet), Network Interface(Frame).

</details>

```text
[TCP/IP 프로토콜 스택]
|-- 응용 계층 | HTTP·DNS·TLS
|-- 전송 계층 | TCP·UDP
|-- 인터넷 계층 | IPv4·IPv6·ICMP
`-- 네트워크 접근 계층 | Ethernet·Wi-Fi
```

선의 의미: TCP/IP 계층과 프로토콜의 정적 포함 관계

| 구성요소 | 책임 |
|:---|:---|
| 응용 계층 | 응용 프로토콜과 데이터 표현 제공 |
| 전송 계층 | 포트 기반 종단 간 전달과 신뢰성 제어 |
| 인터넷 계층 | IP 주소 기반 패킷 포워딩 |
| 네트워크 접근 계층 | 인접 링크의 프레임과 신호 전송 |

#### 한줄 요약
- 인터넷 계층이 상위 응용·전송과 하위 링크 사이에 끼어들어, 망 조합마다 따로 만들던 변환 규칙을 IP 주소 기반 포워딩 하나로 대신한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **TCP/IP 패킷 포워딩 5단계**: 송신단 응용 데이터 생성 $\to$ L4 TCP 포트 세그먼트화 $\to$ L3 IP 패킷 캡슐화 $\to$ 라우터 넥스트홉 포워딩 $\to$ 수신단 역캡슐화.

</details>

```text
[응용 데이터]
      |
1. 세그먼트 생성
      |
2. IP 패킷 생성
      |
3. 링크 프레임 생성
      |
4. 넥스트홉 포워딩
      |
5. 역캡슐화
      |
[응용 데이터 전달]
```

- 1. 세그먼트 생성: 포트와 전송 헤더 부착
- 2. IP 패킷 생성: 출발지·목적지 IP 부착
- 3. 링크 프레임 생성: 링크별 MAC 헤더 부착
- 4. 넥스트홉 포워딩: 라우팅 테이블로 경로 선택
- 5. 역캡슐화: 수신 계층별 헤더 제거

#### 한줄 요약
- 라우터는 L3 헤더까지만 열고 되돌려 보내므로 코어의 비용은 홉당 IP 조회 한 번에 고정되고, 재전송·순서 복원 같은 비싼 상태 관리는 종단에서만 발생한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **TCP/IP 4계층 vs OSI 7계층**: 실용적 구현 표준(TCP/IP 4계층)과 학술적 이론 참조 모델(OSI 7계층).

</details>

| 비교 항목 | TCP/IP 4계층 모델 | OSI 7계층 참조 모델 |
|:---|:---|:---|
| 모델 성격 및 위상 | 실제 인터넷 구현 기반 사실상 표준 (De facto) | 통신 시스템 표준 설계를 위한 참조 모델 (De jure) |
| 계층 수 및 구조 | 4개 계층 (단순하고 실용적인 통합 구조) | 7개 계층 (엄격하게 분리된 세분화 구조) |
| 세션 및 표현 계층 | 응용 계층(L4) 내 소프트웨어 라이브러리로 통합 | 세션(L5), 표현(L6) 독립 계층 분리 |
| 데이터링크 및 물리 | 네트워크 접근 계층(L1)으로 통합 | 데이터링크(L2), 물리(L1) 독립 분리 |
| 신뢰성 제어 책임 | 종단 호스트(L4 TCP)에 집중 위임 | 각 계층별 분산 오류 제어 지향 |

#### 한줄 요약
- TCP/IP는 구현 중심의 실용적 4계층 구조이며, OSI는 개념적 참조를 위한 엄격한 7계층 구조이다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **MSS Clamping**: 터널링(IPsec/VXLAN) 오버헤드로 인한 MTU 초과 단편화를 막기 위해 TCP SYN 패킷의 MSS 값을 강제로 축소 조정하는 기법.
- **QUIC**: UDP 위에 TLS 1.3 핸드셰이크와 스트림 다중화를 통합해 1-RTT(재접속 시 0-RTT)로 연결을 수립하고, 스트림별로 독립 재전송하여 한 스트림의 손실이 다른 스트림을 막지 않게 하는 전송 프로토콜(HTTP/3의 기반).
- **상향식 계층 진단 (Bottom-Up Troubleshooting)**: 물리 링크 상태, ARP 테이블, IP Ping, 포트 접속 순으로 하위 계층부터 정상 여부를 확인하며 올라가, 처음 실패한 계층으로 장애 원인을 격리하는 진단 절차.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| VPN 터널링 오버헤드로 인한 MTU 초과 및 IP 단편화 지연 | 경로 MTU 탐색(PMTUD) 및 라우터 **MSS Clamping** 적용 | 패킷 분할 오버헤드 방지 및 전송 처리량 극대화 |
| 실시간 스트리밍 시 TCP 재전송 지연으로 인한 버퍼링 장애 | 실시간 트래픽에 UDP 기반 **QUIC**(HTTP/3) 도입 | 연결 설정 지연 제거 및 Head-of-Line Blocking 해소 |
| 네트워크 전면 장애 발생 시 원인 계층 식별 지연 | L1(물리링크) $\to$ L2(ARP) $\to$ L3(IP) $\to$ L4(Port) 순 **상향식 계층 진단** | 문제 식별 시간 단축 및 MTTR 극소화 |
| IP 단편화(Fragmentation)를 악용한 방화벽 우회 해킹 공격 | 보안 게이트웨이에서 비정상 조각 패킷(Teardrop/Overlap) 드롭 강제 | 네트워크 계층 침해 공격 원천 차단 |

#### 한줄 요약
- IP 계층을 얇게 유지해 얻은 확장성은 MTU·신뢰성·보안을 종단과 경계 장비가 대신 맡는 비용으로 돌아오므로, 대책은 그 비용을 어느 종단·경계에서 흡수할지 정하는 일이다.

## Ⅶ. 결론

- 단순성(Simplicity)과 종단 간 원칙(End-to-End)을 바탕으로 전 세계 인터넷 통신의 사실상 표준(De facto Standard)으로 확립되었으며, 현대 클라우드 네이티브 및 초저지연 멀티미디어 환경에서는 **TCP의 HoL 블로킹을 극복하는 UDP 기반 QUIC(HTTP/3) 프로토콜로의 진화, VXLAN/IPsec 터널링 시 MTU 단편화를 방지하는 MSS Clamping 적용, L1부터 L4까지의 상향식(Bottom-Up) 계층별 진단 체계**를 결합하여 차세대 고성능 분산 인프라를 완성

#### 한줄 요약
- TCP/IP 4계층 모델은 IP 중심의 모래시계 아키텍처와 종단 간 원칙을 통해 오늘날 글로벌 인터넷의 표준 프로토콜 스택을 제공하는 핵심 네트워크 모델이다.
