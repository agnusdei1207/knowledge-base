## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **V2X (Vehicle-to-Everything)**: 차량이 타 차량(V2V), 도로 인프라(V2I), 보행자(V2P), 네트워크(V2N)와 주행 정보를 교환하는 협력 주행 통신.
- **PC5 vs Uu**: 기지국 경유 없이 단말 간 직접 통신하는 사이드링크(PC5)와 5G 기지국 및 코어망을 경유하는 광역 셀룰러 인터페이스(Uu).

</details>

- 정의/개념: 차량이 타 차량, 노변 기지국, 보행자와 **PC5(사이드링크) 및 Uu(셀룰러) 인터페이스를 통해 주행 안전 정보를 실시간 교환하는 협력형 무선 통신(V2X)**
- 배경/필요성: 차량 내 센서(카메라/라이다)의 물리적 한계로 인한 **악천후 시 시야 미확보, 건물 모퉁이 사각지대(NLOS) 돌발 위험 사전 인지 불가**

#### 한줄 요약
- PC5 직접 무선과 Uu 셀룰러망을 결합하여 사각지대 비가시선(NLOS) 위험을 사전에 방어한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **SCMS (Security Credential Management System)**: 차량의 프라이버시 보호를 위해 5~10분 주기로 익명 가명 인증서(Pseudonym Certificate)를 발급·폐기하는 PKI 보안 인프라.
- **BSM / CAM (기본 안전 메시지)**: 차량의 위치, 속도, 조향각, 가속도 정보를 초당 10회 주기(10Hz)로 브로드캐스트하는 표준 안전 메시지.

</details>

- 비가시선(NLOS) 상황에서도 10ms 이내에 위험을 전파하는 **초저지연 직접 통신(PC5)**
- 차량의 실제 ID 대신 단기 가명 인증서를 사용하는 **프라이버시 익명성 보호(SCMS)**
- 수신된 전파 좌표와 자체 ADAS 센서(카메라/라이다)를 대조하는 **물리적 개연성(Plausibility) 교차 검증**

#### 한줄 요약
- 초저지연 사이드링크, SCMS 가명 인증, 센서 교차 검증을 통해 자율주행 안전성을 보장한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **OBU (On-Board Unit)**: 차량 내부에 탑재되어 센서 데이터 송출 및 타 차량 경보를 수신하는 V2X 통신 단말 모뎀.
- **RSU (Roadside Unit)**: 신호등, 가로등 등 도로변에 설치되어 신호 주기(SPaT) 및 보행자 돌발 정보를 브로드캐스트하는 인프라 노드.

</details>

```text
[V2X 협력형 주행 통신 토폴로지 및 이중 무선 인터페이스]
|-- Security Infrastructure (SCMS: 주기적 가명 인증서 Pseudonym Cert 발급)
`-- Wide-Area Network (Uu Interface: 5G gNB -> C-ITS 관제 서버 -> 10km 전방 도로 정체/사고 전송)
`-- Local Direct Network (PC5 Sidelink: 5.9GHz V2X 전용 대역 직접 무전, 10ms 초저지연)
    |-- OBU 1 (선두 차량: 급제동 BSM 브로드캐스트 송출)
    |-- OBU 2 (후속 차량: BSM 수신 -> SCMS 검증 -> ADAS 긴급 제동 작동)
    |-- RSU (교차로 노변 기지국: 신호등 잔여 시간 SPaT, 보행자 검지 전송)
    `-- VRU (보행자 스마트폰 / 자전거 센서 V2P 직접 연동)
```

선의 의미: 계층 및 단말 간 직접 PC5 사이드링크와 광역 Uu 셀룰러 인터페이스가 결합하여 C-ITS 협력 주행을 실현하는 구조

| 구성요소 | 핵심 엔지니어링 책임 | 주요 특징 |
|:---|:---|:---|
| **OBU (차량 단말)** | 내 차의 위치·속도·제동 상태를 **초당 10회(10Hz) BSM/CAM 메시지로 브로드캐스트** | Vehicle |
| **RSU (노변 기지국)** | 교차로 신호등 잔여 시간(SPaT) 및 **돌발 낙하물/보행자 정보를 주변 차량에 전파** | Infrastructure |
| **C-ITS 서버 / 5GC** | 5G Uu 인터페이스로 연동되어 **원거리 도로 기상, 정체, 대형 사고 정보를 광역 배포** | Network |
| **SCMS (보안 인프라)** | 차량 추적 스토킹을 차단하기 위해 **5분 주기로 단기 가명 인증서를 자동 발급·순환** | Security PKI |

#### 한줄 요약
- OBU 차량 단말, RSU 노변 장치, C-ITS 관제 서버, SCMS 보안 인프라가 결합된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Plausibility Check (개연성 검증)**: 수신된 무선 안전 메시지의 GPS 좌표가 자체 탑재된 카메라/라이다 센서의 물리적 관측 결과와 일치하는지 대조하는 이상 탐지.

</details>

```text
V2X 안전 메시지 수신 및 긴급 제동 제어 파이프라인
        │
   1. [PC5 안전 메시지 수신] 선두 차량의 급제동 BSM 메시지 수신 (10ms)
        │
   2. [SCMS 서명 검증] 가명 인증서 유효성 및 CRL 폐기 목록 대조
        │
   3. [최신성 타임스탬프 확인] 재전송(Replay) 공격 방지를 위해 100ms 초과 패킷 폐기
        │
   4. [센서 개연성 교차 검증] 카메라/라이다의 거리 측정값과 무선 좌표 간 물리적 정합성 검증
        │
   ▼
5. [ADAS 긴급 제동 개입] 4단계 검증 통과 시 차량 전자제어장치(ECU)를 통해 브레이크 자동 작동
```

#### 한줄 요약
- BSM 수신 → SCMS 서명 검증 → 타임스탬프 최신성 확인 → 센서 개연성 검증 → ADAS 제동 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **PC5 (Direct Sidelink)** vs **Uu (Cellular)**: 기지국 비의존 10ms 초저지연 직접 통신(PC5)과 전국 단위 광역 통신(Uu).

</details>

| 비교 항목 | 직접 사이드링크 통신 (PC5) | 기지국 경유 셀룰러 통신 (Uu) |
|:---|:---|:---|
| **통신 메커니즘** | **기지국 없이 차량 간(V2V/V2I) 직접 1:1, 1:N 송수신**| **5G 기지국(gNB) 및 코어망(UPF)을 경유하여 전송** |
| **전송 지연 (RTT)** | **10 ms 이내 (초저지연 결정론적 통신)** | 30 ~ 100 ms (기지국 및 백홀 전송 지연 발생) |
| **유효 커버리지** | **근거리 통신 (차량 반경 100 ~ 300m)** | **광역 통신 (수 km ~ 전국망 단위)** |
| **기지국 장애 시** | **통신망 장애와 무관하게 음영/터널 통신 보장** | 5G 기지국 단선 시 통신 전면 불능 |
| **핵심 적용 분야** | **충돌 회피, 군집 주행(Platooning), 교차로 위험 경보**| **실시간 동적 지도(HD Map) 다운로드, 광역 교통 관제**|

#### 한줄 요약
- PC5는 충돌 방지용 근거리 초저지연 통신에 적합하고, Uu는 광역 교통 관제 및 HD 맵 갱신에 적합하다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **DCC (Decentralized Congestion Control)**: 교차로 등 차량 밀집 지역에서 전파 충돌로 인한 패킷 드롭을 방지하기 위해 채널 점유율(CBR)에 따라 전송 주기를 자율 조절하는 알고리즘.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 허위 GPS 좌표를 주입하여 급제동을 유발하는 **스푸핑/고스트 공격** | **무선 통신 좌표와 내장 센서(카메라/라이다) 간 `개연성 검증`** | 비정상 허위 패킷 차단 및 오제동 방지 |
| 도심 교차로 내 수백 대 차량 밀집 시 전파 간섭으로 패킷 폐기 | **`분산 혼잡 제어(DCC: 채널 점유율 기반 전송률 조절)` 의무화** | 무선 채널 포화 방지 및 고우선순위 패킷 통과 |
| 차량 고유 인증서 지속 송출로 인한 운전자 이동 경로 추적 스토킹 | **`5분 / 10km 단위 가명 인증서(Pseudonym) 동적 교체`** | 차량 익명성 보장 및 개인정보 유출 원천 차단 |
| 과거 정상 패킷을 녹음 후 재전송하여 혼란을 유발하는 **Replay 공격** | 메시지 헤더 내 **`UTC 타임스탬프 및 100ms 유효 시간 검증`** | 지연된 비정상 과거 패킷 즉각 폐기 |

#### 한줄 요약
- 센서 개연성 검증, DCC 혼잡 제어, 가명 인증서 교체, 타임스탬프 검증으로 운영한다.

## Ⅶ. 결론

- 센서 기반 자율주행의 사각지대와 비가시선(NLOS) 위험을 극복하기 위해 **PC5 초저지연 사이드링크와 Uu 광역 셀룰러를 결합한 하이브리드 V2X 아키텍처를 표준 구축**하고, **SCMS 가명 인증 체계, DCC 분산 혼잡 제어, 센서 개연성 교차 검증 알고리즘**을 결합하여 완전 자율주행(Level 4+)의 안전성과 신뢰성을 완성

#### 한줄 요약
- V2X는 PC5 직접 통신과 Uu 셀룰러망을 융합하여 사각지대 위험을 전파로 극복하는 자율주행 핵심 통신 기술이다.
