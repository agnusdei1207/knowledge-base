## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **V2X(차량사물통신, Vehicle-to-Everything)**: 자동차가 스마트폰처럼 통신 모듈을 달고 주변 자동차, 신호등, 보행자와 0.001초 단위로 쉴 새 없이 상태를 주고받으며 사고를 막는 자율주행 필수 통신이다.
- **PC5 / Uu**: 기지국 쌩까고 차끼리 다이렉트로 무전 치는 초근거리 통신이 PC5고, 5G 기지국을 거쳐서 서울 서버까지 갔다 오는 광역 통신이 Uu다.

</details>

- 정의: 차량이 다른 차량(V2V), 도로 인프라(V2I), 네트워크망(V2N)과 유무선 통신 인터페이스(PC5/Uu)를 이용하여 **주행 상태와 도로 위험 정보를 실시간 교환하는 자율주행 협력 통신 체계다.**
- 배경: 카메라랑 센서에만 의존하면 비 오거나 모퉁이 돌 때 안 보여서 사고가 나니까, **눈에 안 보이는 놈들끼리도 전파로 대화해서 미리 피하려고 만들었다.**

#### 한줄 요약

- 자율주행차가 카메라(눈)에만 의존하지 않고, 주변 차와 신호등이랑 텔레파시(전파)를 주고받아 사각지대 사고를 막는 기술이다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **개연성 검증(Plausibility Check)**: 무전기로 "나 앞차인데 속도 0km야!"라고 구라 핑을 찍어도, 내 차 카메라로 봤을 때 앞차가 100km로 달리고 있으면 씹어버리는 팩트 체크 기술이다.
- **SCMS PKI (가명 인증서)**: 통신할 때 내 차 번호판(진짜 신분)을 까면 해커한테 스토킹 당하니까, 5분마다 닉네임을 바꾸는 일회용 인증서(가명)로 암호화해서 통신하는 보안 룰이다.

</details>

- **이중 통신망 (PC5/Uu 하이브리드)**: 10ms 안에 브레이크 밟아야 하는 긴급 무전은 차끼리 직접 치고(PC5), 앞 동네 교통체증 정보는 5G 망(Uu)으로 여유 있게 받는다.
- **가명 닉네임 프라이버시 보호**: 일회용 가명 인증서로 전자서명을 해서, 차가 어디로 가는지 통신사도 해커도 절대 동선을 추적할 수 없게 막음.
- **센서 + 통신 교차 팩트 체크 (Plausibility)**: 전파로 날아온 앞차 위치랑 내 차 센서(라이다)가 측정한 물리적 거리를 교차 검증해서, 해커가 보낸 가짜 유령 차를 걸러냄.

#### 한줄 요약

- 급할 땐 다이렉트(PC5), 안 급하면 5G(Uu)를 쓰고, 5분마다 신분 세탁(가명 인증서)하며 팩트 체크(개연성)까지 하는 치밀한 구조다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **OBU(차량 탑재 장치, On-Board Unit)**: 자동차 트렁크나 룸미러 뒤에 달아놓는 V2X 무전기(모뎀). 내 차 속도를 주변에 쏘고 남의 경고를 수신하는 놈이다.
- **RSU(노변 장치, Roadside Unit)**: 신호등이나 가로등에 매달려 있는 동네 인프라 무전기. 교차로 신호등이 언제 빨간불로 바뀔지 차들한테 동네방네 떠드는 놈이다.

</details>

```text
[ V2X 통신 팩트 폭행 구조 ]

[ 가명 인증서(SCMS) ] ──▶ (5분마다 일회용 신분증 발급)
         │
[ 5G 기지국(gNB) 및 V2X 서버 ] ◀── [ Uu 통신 ] ──┐
         │ (광역 연결)                         │ (5G 망 경유)
[ RSU (신호등 무전기) ]                        │
         │                                   │
         ▼ (PC5 직접 무전: 10ms 즉각 반응)      │
[ OBU (내 차 무전기) ] ◀── [ PC5 ] ──▶ [ OBU (앞차 무전기) ]
```

| 구성요소 | 팩트 폭행 책임 | 비고 |
|:---|:---|:---|
| **OBU (차량 단말)** | 내 차 속도와 엑셀 상태를 **1초에 10번씩 주변에 난사하는 무전기** | Vehicle |
| **RSU (인프라 단말)**| 교차로에 매달려서 **보행자 튀어나온다고 동네방네 쏘는 무전기** | Infrastructure |
| **V2X 서버 (C-ITS)** | 5G 기지국(Uu)으로 접속해서 **10km 앞 고속도로 사고 났다고 쏴주는 서버** | Network |
| **SCMS (보안 인증서)**| 해커 구라 핑 방어용으로 **OBU한테 5분짜리 일회용 신분증 발급해 주는 곳** | Security |

#### 한줄 요약

- 룸미러 무전기(OBU)랑 신호등 무전기(RSU)가 다이렉트(PC5)로 떠들고, 5G 기지국(Uu)이 광역 정보 뿌려주는 3각 편대다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **최신성(Anti-Replay)**: 해커가 어제 녹음해 둔 "사고 났음!" 메시지를 오늘 다시 틀어서 차를 급정거시키려는 짓(재전송 공격)을 막으려고, 0.1초라도 지난 메시지는 싹 다 버리는 컷 기능이다.

</details>

```text
[ V2X 메시지 검증 및 급브레이크 십자포화 흐름 ]

┌──────────────────────────────┐
│ 1. [PC5 무전기 수신 (BSM)]   │
│ (앞차: 나 급브레이크 밟았어!)│
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 2. [가명 인증서 팩트 체크]   │
│ (이거 해커 폰 아니고 진짜 차 맞네)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 3. [최신성(Replay) 검사]     │
│ (녹음기 틀은 거 아님, 0.01초 전 메시지 통과)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 4. [센서 개연성 크로스 체크] │
│ (카메라 보니 진짜 앞차 거리 좁혀짐)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 5. [ADAS 급제동 엑셀 컷]    │
│ (시스템: 풀브레이크 때림 꽉 잡아)
└──────────────────────────────┘
```

### 동작 원리

1. 안전 메시지 수신: 주변 OBU(앞차)가 쏜 급정거 메시지(BSM)를 PC5 무선으로 즉시 받음.
2. PKI 서명 검증: 메시지가 찐 차에서 온 건지 가명 인증서를 까서 해커 위조 여부 확인함.
3. 최신성(Replay) 검사: 타임스탬프 까보고 0.1초 지났으면 해커가 녹음기 튼 걸로 간주하고 씹어버림.
4. 개연성(Plausibility) 교차 검증: 전파 좌표랑 내 차 카메라 거리가 물리적으로 일치하는지 최종 팩트 체크함.
5. ADAS 제어 꽂기: 4단계를 완벽히 통과해야만 차 브레이크(ECU)를 진짜로 밟음.

#### 한줄 요약

- 무전 오자마자 바로 브레이크 밟는 게 아니라, 인증서 확인 $\to$ 최신성 확인 $\to$ 눈으로 확인(센서) 한 다음에 제동을 건다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- (상단 참조)

</details>

| 비교 항목 | **PC5 (Direct / Sidelink)** | **Uu (Cellular)** |
|:---|:---|:---|
| 팩트 폭행 비유 | 앞차랑 창문 내리고 하는 **다이렉트 육성 무전** | 통신사 기지국 껴서 하는 **카톡 단톡방** |
| 무선 전달 경로 | 기지국 완전 무시하고 **차끼리 1:1, 1:N 직접 쏨** | **5G 기지국이랑 코어망** 싹 다 거쳐서 쏨 |
| 핑 (반응 속도) | 10ms 이내 **(앞차 서면 0.01초 만에 나도 섬)** | 30ms ~ 100ms 이상 **(급정거용으론 뒤짐)** |
| 통신 커버리지 | 차 주변 **100~300m 이내 (근거리 깡패)** | 기지국이 닿는 **수 km ~ 전국 (광역 깡패)** |
| 기지국 터지면? | 기지국 뻗든 말든 터널 안이든 **무조건 터짐** | 통신사 5G 망 먹통 되면 **장님 됨** |

#### 한줄 요약

- 급브레이크용 직통 라인이 PC5고, 막히는 길 우회하려고 기지국 껴서 네비게이션 찍는 게 Uu다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **분산 혼잡 제어(DCC, Decentralized Congestion Control)**: 강남역 사거리에 차가 1,000대 모여서 서로 "나 여깄어!" 하고 무전을 난사하면 전파가 엉켜서 터지니까, 폰(OBU)이 알아서 눈치껏 전송 횟수를 줄이는 매너 기능이다.

</details>

| 장애/위험 요소 | 원인 분석 | 실무 대책 및 해결방안 | 기대 효과 |
|:---|:---|:---|:---|
| 사거리 마비시키려고 **해커가 가짜 좌표(구라 핑)를 쏨** | GPS 스푸핑으로 없는 유령 차를 만들어냄 | 통신 좌표랑 내 차 센서(카메라/라이다) 대조하는 **개연성 검증 빡세게 굴림** | 눈에 안 보이는 유령 차 컷 및 급정거 대참사 방지 |
| 강남역에 차 몰리니까 **무전 채널(PC5)이 꽉 차서 뻗음** | 수백 대가 1초에 10번씩 쏴대니까 주파수가 터짐 | 차량 밀도 높아지면 알아서 전송 횟수 줄이는 **DCC (혼잡 제어) 매너 모드 적용** | 전파 폭주 막고 진짜 위급한 급정거 메시지만 살림 |
| 내 차가 언제 어디 가는지 **동선이 실시간으로 털림** | 통신할 때 진짜 고정 신분증(인증서)을 까서 발생 | **5분, 10km 주기로 가명 인증서 휙휙 돌려치기(교체)** | 해커가 특정 차 번호판 찍어서 스토킹하는 거 원천 차단 |
| 어제 난 사고 메시지를 **해커가 도청했다가 오늘 또 틈** | 옛날 패킷을 그대로 다시 쏘는 **Replay 공격** | 타임스탬프 까보고 **100ms 지난 옛날 패킷은 싹 다 버림** | 철 지난 구라 핑으로 고속도로 교통 체증 유발하는 짓 컷 |

#### 한줄 요약

- 유령 차는 센서 교차 검증으로 거르고, 강남역 폭주는 DCC로 달래고, 스토킹은 5분마다 닉네임(가명) 바꿔서 막아라.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- (상단 참조)

</details>

- 센서 기반 자율주행의 인지 한계와 사각지대를 극복하기 위해, **PC5(초저지연)** 와 **Uu(광역)** 를 결합하고 SCMS 기반 **개연성(Plausibility)** 검증을 통해 완전 자율주행(Level 4+)을 달성하는 V2X 기조 확립함

#### 한줄 요약

- V2X는 카메라가 못 보는 벽 너머의 사고까지 전파로 꿰뚫어 보게 만들어, 자율주행차를 완벽한 '투시 능력자'로 만드는 핵심 무기다.
