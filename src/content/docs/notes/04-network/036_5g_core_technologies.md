## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **eMBB(Enhanced Mobile Broadband, 초고속 대용량 통신)**: 최대 20Gbps 다운로드 전송률과 광대역 주파수(mmWave)를 활용하여 대용량 미디어 및 몰입형 실감 콘텐츠를 제공하는 5G 서비스.
- **URLLC(Ultra-Reliable and Low Latency Communications, 초고신뢰 저지연 통신)**: 무선 구간 1ms 이하의 전송 지연과 99.999%(Five-Nines) 이상의 전송 성공률을 보장하여 미션 크리티컬 제어를 지원하는 5G 서비스.
- **mMTC(Massive Machine Type Communications, 대규모 사물 통신)**: $1\text{km}^2$ 당 100만 개 이상의 저전력·저용량 IoT 단말을 동시 수용하고 10년 이상의 배터리 수명을 지원하는 사물 통신 서비스.

</details>

- 정의/개념: ITU-R(IMT-2020)에서 정의한 5G 이동통신의 3대 대표 서비스 시나리오로, **초고속(eMBB), 초저지연·초고신뢰(URLLC), 대규모 접속(mMTC)** 의 상이한 성능 지표(KPI)를 단일 물리망에서 분할 지원하는 서비스 분류 체계
- 배경/필요성: 단일 획일화된 무선 통신 구조로는 대용량 스트리밍(속도 중심), 자율주행·원격제어(지연 중심), 스마트 시티 센서(밀도/배터리 중심)의 상충하는 요구조건을 동시에 수용할 수 없는 한계 극복

#### 한줄 요약
- 단일 물리망에서 초고속(eMBB), 초저지연(URLLC), 대규모 사물접속(mMTC)의 상충하는 요구를 분할 수용한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **네트워크 슬라이싱(Network Slicing)**: 단일 물리적 5G 네트워크 인프라를 가상화(NFV/SDN)하여 서비스 요구사항별(eMBB, URLLC, mMTC)로 독립적인 논리 망(Slice)을 생성·격리하는 기술.
- **5G QoS 식별자(5QI)**: 5G 패킷의 우선순위 레벨, 패킷 지연 예산(Packet Delay Budget), 패킷 손실률(Packet Error Rate)을 표준화하여 보장하는 QoS 파라미터.

</details>

- **eMBB**: 밀리미터파(mmWave), 대규모 다중 안테나(Massive MIMO) 및 빔포밍을 통한 초고속 대역폭 제공
- **URLLC**: 짧은 슬롯 주기(Mini-slot), 선점형(Preemptive) 스케줄링 및 엣지 컴퓨팅(MEC) 전진 배치를 통한 1ms 초저지연 달성
- **mMTC**: 협대역 전송(NB-IoT/Cat-M1), 긴 수면 주기(PSM/eDRX) 및 커널 제어 평면 경량화를 통한 저전력 대규모 단말 수용

#### 한줄 요약
- eMBB는 대역폭을, URLLC는 1ms 지연과 신뢰성을, mMTC는 저전력 다중 접속을 지향하며 네트워크 슬라이싱으로 격리한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **사용자 평면 기능(User Plane Function, UPF)**: 5G 코어에서 실제 사용자 데이터 패킷의 라우팅 및 포워딩, 패킷 검사, QoS 집행을 전담하는 데이터 플레인 노드.
- **모바일 엣지 컴퓨팅(Mobile Edge Computing, MEC)**: 코어망까지의 물리적 왕복 지연을 단축하기 위해 기지국(gNB) 인접 위치에 클라우드 컴퓨팅 자원과 로컬 UPF를 배치하는 아키텍처.

</details>

```text
[ 5G 이기종 단말 (스마트폰 / 자율주행차 / 센서) ]
                        │
                        ▼ (무선 접속망: gNB)
 ┌───────────────────────────────────────────────────────────┐
 │ 5G RAN (무선 자원 슬라이싱 / 가변 뉴머롤로지 SCS 분할)      │
 └──────────────┬──────────────┬──────────────┬──────────────┘
                │ (eMBB 슬라이스)│ (URLLC 슬라이스) (mMTC 슬라이스)
                ▼              ▼              ▼
 ┌───────────────────────────────────────────────────────────┐
 │ 5G Core (서비스별 가상화 코어 네트워크)                    │
 │ ├─ [ 중앙 UPF / 인터넷 ] ──▶ eMBB (대용량 콘텐츠 서버 연동)│
 │ ├─ [ 로컬 UPF / MEC ] ─────▶ URLLC (1ms 초저지연 로컬 처리)│
 │ └─ [ C-Plane 최적화 UPF ] ─▶ mMTC (대규모 시그널링 경량화) │
 └───────────────────────────────────────────────────────────┘
```

선의 의미: 단말 요구에 따라 RAN에서 가변 뉴머롤로지로 분할되고 코어망에서 중앙 UPF, 로컬 MEC, 경량화 코어로 분기되는 서비스 슬라이스 구조

| 구성요소 | 책임 | 대응 서비스 |
|:---|:---|:---|
| **gNB 가변 뉴머롤로지 (RAN)** | 부반송파 간격(SCS 15~120kHz)과 슬롯 길이를 가변 적용하여 무선 프레임 최적화 | eMBB/URLLC/mMTC |
| **로컬 UPF / MEC (Edge)** | 기지국 인접 지점에서 로컬 트래픽 브레이크아웃(LBO)을 수행하여 왕복 지연 1ms 보장 | **URLLC 특화** |
| **중앙 집중형 UPF (Core)** | 인터넷 백본과 직접 연동하여 대용량 트래픽의 기가비트 라우팅 및 과금 처리 | **eMBB 특화** |
| **제어 평면(AMF/SMF/NEF)** | 대규모 센서 단말의 간헐적 접속 시그널링 부하를 흡수하고 인증·세션 경량 관리 | **mMTC 특화** |

#### 한줄 요약
- 가변 뉴머롤로지 RAN, 로컬 MEC/UPF, 중앙 UPF, 제어 평면 최적화 모듈이 결합하여 3대 서비스를 완결한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **미니 슬롯(Mini-slot / Non-slot based scheduling)**: 표준 슬롯(14 심볼) 단위 전송을 대기하지 않고, 2~7 심볼 단위로 즉시 무선 자원을 선점하여 전송하는 URLLC 전용 초저지연 스케줄링.

</details>

```text
1. 단말 접속 및 서비스 특성 식별 (S-NSSAI 및 5QI 파라미터 매핑)
            │
            ├─ [eMBB 요청] ──▶ 2a. 광대역 mmWave 채널 및 Massive MIMO 빔포밍 자원 할당
            ├─ [URLLC 요청] ─▶ 2b. Mini-slot 선점형 스케줄링 및 로컬 MEC 경로 라우팅
            └─ [mMTC 요청] ──▶ 2c. 협대역(NB-IoT) 채널 및 절전 모드(PSM/eDRX) 파라미터 구성
                    │
                    ▼
3. 종단 간(E2E) 네트워크 슬라이스 경로 확립 및 데이터 전송
```

**동작 원리**

1. **서비스 프로파일링**: 단말의 가입자 정보와 요청 트래픽의 S-NSSAI(단일 네트워크 슬라이스 선택 지원 정보) 식별
2. **무선 자원 할당**: eMBB는 광대역 부반송파를, URLLC는 즉각 전송이 가능한 미니 슬롯을, mMTC는 협대역 채널 할당
3. **사용자 평면 경로 분기**: URLLC는 기지국 직결 MEC의 로컬 UPF로 경로를 수립하고, eMBB는 코어 데이터센터로 연결
4. **QoS 모니터링**: 5QI 기반으로 패킷 지연 예산(PDB)과 손실률을 지속 계측하여 서비스 SLA 보증

#### 한줄 요약
- 단말 서비스 식별, 무선 자원 가변 분할, 사용자 평면 경로 분기(MEC vs Core), 5QI SLA 모니터링 순으로 처리된다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **절전 모드(Power Saving Mode, PSM)**: 단말이 데이터 송수신 후 수신 회로를 차단하고 극저전력 수면 상태로 진입하여 배터리를 수년간 유지하는 기법.

</details>

| 비교 항목 | 초고속 통신 (eMBB) | 초저지연 통신 (URLLC) | 대규모 사물 통신 (mMTC) |
|:---|:---|:---|:---|
| **핵심 성능 목표** | **최대 20Gbps (체감 100Mbps)** | **무선 1ms (E2E 5ms 이하), 99.999%** | **$10^6 \text{ devices}/\text{km}^2$, 배터리 10년** |
| **주요 무선 기술** | mmWave (28GHz), Massive MIMO | **Mini-slot, Preemption, 가변 SCS** | **NB-IoT, eMTC, PSM, eDRX** |
| **코어망 아키텍처** | 대용량 고속 패킷 스위칭 (중앙 UPF) | **MEC (모바일 엣지 컴퓨팅) 전진 배치** | 제어 평면 시그널링 최적화 코어 |
| **주요 적용 분야** | 4K/8K 실시간 중계, AR/VR, 홀로그램 | 자율주행(V2X), 원격 수술, 스마트 팩토리 | 원격 검침, 환경 모니터링, 스마트 물류 |

#### 한줄 요약
- eMBB는 대역폭(20Gbps)을, URLLC는 저지연(1ms)과 신뢰성을, mMTC는 대규모 밀도($10^6/\text{km}^2$)를 목표로 한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **선점형 스케줄링(Preemption)**: URLLC 긴급 패킷이 발생했을 때, 이미 진행 중인 eMBB 전송 자원을 강제로 중단하고 URLLC 패킷을 우선 전송하는 무선 인터페이스 기술.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 대용량 eMBB 트래픽 버스트로 인한 URLLC 트래픽 지연 및 간섭 | **선점형 스케줄링(Preemption)** 및 **물리적 무선 자원 격리(Hard Slicing)** | eMBB 간섭 차단 및 URLLC 1ms 지연 시간 SLA 보장 |
| 코어망 원거리 전송 지연으로 인한 URLLC 5ms 종단 지연 초과 | 기지국 인접 **MEC(Mobile Edge Computing) 및 분산 로컬 UPF** 구축 | 물리적 전송 거리 단축 및 E2E 지연 한도 충족 |
| 수백만 mMTC 단말의 동시 재접속 시 제어 평면(AMF/SMF) 시그널링 폭증 | **접속 시도 백오프(Back-off) 제어** 및 비접속(Connectionless) 전송 | 제어 평면 과부하 방지 및 코어망 안정성 유지 |

#### 한줄 요약
- 선점형 스케줄링으로 eMBB/URLLC 간섭을 방지하고, MEC 배치로 지연을 단축하며, 접속 제어로 mMTC 시그널링 폭증을 방어한다.

## Ⅶ. 결론

- 5G 인프라 구축 시 단일 네트워크 위에서 3대 상충 요구사항을 충족하기 위해 **E2E 네트워크 슬라이싱**을 표준 아키텍처로 채택하고, 산업용/자율주행 환경에는 **MEC 기반 로컬 UPF**를 배치하며, 스마트 시티/센서 인프라에는 **경량화 코어 제어 평면**을 결합하여 서비스별 최적의 SLA를 보장

#### 한줄 요약
- E2E 네트워크 슬라이싱과 MEC 엣지 컴퓨팅을 결합하여 5G 3대 서비스 시나리오를 완성한다.
