## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **Zigbee(지그비)**: 인터넷 연결(IP) 없이 자기들끼리만 통신하는 1세대 스마트홈 기술이다. 꼭 전용 게이트웨이(허브)가 있어야만 스마트폰이랑 통신할 수 있다.
- **Thread(스레드)**: IP 주소를 못 쓰던 지그비의 단점을 고쳐서, 전구 하나하나에 진짜 인터넷 주소(IPv6)를 부여해 주는 2세대 저전력 통신망이다.
- **Matter(매터)**: "삼성 전구는 애플 홈킷에 안 붙어요!" 하던 대환장 파티를 끝내려고, 구글, 애플, 삼성이 모여 대통합을 이룬 3세대 스마트홈 공통 언어(앱 표준)다.

</details>

- 정의: 스마트홈을 굴리는 3대장 기술로, 밑바닥 통신망인 **지그비(비-IP)** 와 **스레드(IPv6)** 위에, 모든 회사의 기기를 하나로 묶어주는 **매터(공통 언어)** 가 얹혀진 구조다.
- 배경: 옛날엔 회사마다 자기네 전용 허브를 안 사면 기기가 호환 안 돼서 소비자들이 개빡쳤는데, **이걸 해결하려고 글로벌 대기업(CSA)들이 강력히 단합해서 매터 표준을 만들었다.**

#### 한줄 요약

- 통신망은 IP 주소 달린 스레드(Thread)로 깔고, 그 위에서 말하는 언어는 매터(Matter)로 통일해서 스마트홈의 대통합을 이룬 거다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **IPv6 (Internet Protocol version 6)**: 전구, 센서같이 조그만 기기 하나하나에까지 부여할 수 있는 무한대의 인터넷 주소다.
- **6LoWPAN**: 쥐꼬리만 한 배터리로 돌아가는 기계에서 무거운 IPv6 주소를 가볍게 압축해서 쓸 수 있게 해주는 마법의 기술이다.

</details>

- **Zigbee (과거의 영광, 비-IP)**: 전용 허브(게이트웨이)가 없으면 인터넷 밖으로 나가지도 못하는 폐쇄적인 우물 안 개구리망(비-IP)이다.
- **Thread (인터넷 직결망)**: 6LoWPAN 기술로 쪼만한 센서에도 글로벌 IP(IPv6)를 박아줘서, 전용 허브 족쇄 없이 스마트폰이랑 다이렉트로 통신한다.
- **Matter (우주 대통합 언어)**: 와이파이든 이더넷이든 스레드든 밑바닥 통신망이 뭐든 간에, 애플 홈킷이나 삼성 스마트싱스 앱 하나로 전 세계 모든 인증 기기를 조작하게 통일시킴.

#### 한줄 요약

- 지그비는 전용 허브가 필수고, 스레드는 전구에 IP 주소를 달아줬으며, 매터는 그 전구들을 모든 앱에서 조종하게 해준 거다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **Thread Border Router (스레드 경계 라우터)**: 스레드 망이랑 집 와이파이를 연결해 주는 통역사다. 애플TV나 스마트 스피커에 그냥 내장돼 있어서 지그비 시절의 '전용 허브 강매'를 없앴다.
- **Matter Bridge (매터 브리지)**: 옛날에 산 비싼 지그비 기기들을 버릴 순 없으니까, 매터 언어로 통역해서 요즘 시스템에 억지로 붙여주는 심폐소생기(어댑터)다.

</details>

```text
[ 매터(Matter) 스마트홈 직관적 비교 구조 ]

[ 스마트폰 (애플 홈 / 스마트싱스 앱) ]
      │ (Matter 공통 언어 명령)
      ▼
[ 집 와이파이 (Wi-Fi 공유기) ] ──▶ [ Matter 브리지 ] ──▶ [ 옛날 지그비 전구 ] (구형)
      │
      ▼
[ Thread 경계 라우터 (애플TV, 구글 홈팟) ]
      │ (IPv6 통역)
      ▼
[ Thread 기반 매터 전구 ] ──▶ [ Thread 센서 ] (신형)
```

| 구성요소 | 직관적 비교 책임 | 비고 |
|:---|:---|:---|
| **Matter 앱 (스마트폰)** | 애플이든 삼성이든 상관없이 **명령 하나로 싹 다 조종하는 만능 리모컨** | Application |
| **Thread 경계 라우터** | 스레드 전파랑 집 와이파이를 연결해 주는 **통역사 (보통 스피커에 내장됨)** | Border Router |
| **Thread Matter 기기** | 무선망은 스레드 쓰고 언어는 매터 쓰는 **제일 잘 나가는 최신형 스마트 기기** | End Device |
| **Matter 브리지** | 매터 말귀 못 알아먹는 **옛날 지그비 기기들을 억지로 통역해 주는 어댑터** | Bridge |
| **Zigbee 기기** | 매터 나오기 전에 산 **구형 비-IP 기기 (브리지 없으면 바보 됨)** | Legacy Device |

#### 한줄 요약

- 폰에서 매터로 명령하면 $\to$ 와이파이 타고 $\to$ 경계 라우터가 스레드 신호로 바꿔서 $\to$ 신형 전구를 켜고 끄는 구조다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **커미셔닝(Commissioning)**: 사 온 전구를 처음 스마트폰 앱에 등록할 때, "너 중국산 해킹 전구 아니지?" 하고 체크하고 우리 집 와이파이 비밀번호를 넘겨주는 신고식 절차다.

</details>

```text
[ 매터 기기 커미셔닝(신고식) 십자포화 흐름 ]

┌──────────────────────────────┐
│ 1. [블루투스 + QR 코드 스캔] │
│ (폰: 박스 QR 찍어서 새 전구 발견함)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 2. [PASE 보안 채널 연결]     │
│ (폰이랑 전구랑 암호화 귓속말 시작)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 3. [DAC (제조사 체크)]  │
│ (폰: 중국산 짭 아님? 정식 출생증명서 까봐 $\to$ 통과)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 4. [와이파이/스레드 비번 전송]│
│ (폰: 자, 우리 집 공유기 비번 이거다)
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 5. [매터 네트워크 가입 완료] │
│ (전구: 이제 폰으로 불 끄고 켤 수 있음 꿀)
└──────────────────────────────┘
```

### 동작 원리

1. BLE 기기 탐색: 전구 박스에 있는 QR 코드를 폰으로 찍어서 블루투스로 연결을 맺음.
2. 암호화 세션(PASE) 수립: 해커가 와이파이 비밀번호 훔쳐보지 못하게 둘만의 암호화된 터널을 뚫음.
3. 기기 증명서(DAC) 검증: 폰이 기기한테 "너 매터 공식 인증 받은 놈 맞냐?" 하고 기기 안에 심어진 증명서를 검사함.
4. 자격 증명 전송: 찐 기기인 게 확인되면 스마트폰이 스레드나 와이파이 접속 비밀번호를 던져줌.
5. 패브릭 가입: 기기가 무선망에 접속하고, 스마트폰 앱(애플 홈/스마트싱스) 화면에 딱 뜨면서 제어 가능해짐.

#### 한줄 요약

- QR코드 찍고 $\to$ 짭 기기인지 체크하고 $\to$ 와이파이 비번 알려줘서 $\to$ 우리 집 앱에 등록시키는 거다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- (상단 참조)

</details>

| 구분 | **Zigbee (과거망)** | **Thread (현재 전송망)** | **Matter (미래 앱 표준)** |
|:---|:---|:---|:---|
| 비유 및 핵심 특징 | 집 밖을 못 나가는 **동네 찐따망** | 전구도 인터넷에 직결된 **스마트망** | 전 세계 모든 회사가 쓰는 **만국 공통어** |
| OSI 계층 | 밑바닥부터 앱까지 **지 혼자 다 해 먹음** | 물리망(PHY)부터 네트워크(IPv6)까지만 담당 | 최상위 **애플리케이션(앱) 계층만 담당** |
| IP (인터넷) 지원 | **미지원 (비-IP)**, 전용 허브 무조건 필수 | **IPv6 지원 (6LoWPAN)**, 전용 허브 필요 없음 | 와이파이, 이더넷, 스레드 **아무거나 다 됨** |
| 기기 호환성 | 같은 지그비라도 **제조사 다르면 안 붙음** | 껍데기는 IP망인데 **앱이 다르면 안 붙음** | 제조사가 달라도 **매터 인증 받으면 싹 다 붙음** |
| 밀어주는 단체 | CSA (옛날 이름 지그비 얼라이언스) | Thread Group (구글 주도) | CSA + 애플 + 구글 + 삼성 (지구 방위대) |

#### 한줄 요약

- 지그비는 허브 없으면 고철이고, 스레드는 길은 잘 뚫었지만 말이 안 통했는데, 매터가 나와서 다 같이 말(언어)을 통일한 거다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **DAC (기기 증명서, Device Attestation Certificate)**: 공장에서 전구 만들 때 "나 매터 정식 인증 받은 찐 기기요!" 하고 심어놓은 칩셋 단위의 출생증명서(위조 불가)다.

</details>

| 장애/위험 요소 | 원인 분석 | 실무 대책 및 해결방안 | 기대 효과 |
|:---|:---|:---|:---|
| 옛날에 산 비싼 **지그비 기기들 다 버려야 됨?** | 지그비는 IP 통신도 안 되고 매터 언어도 못 알아먹음 | **Matter Bridge (매터 브리지)** 사서 통역기 달아버림 (1:1 명령 매핑) | 기기 새로 안 사고 기존 인프라 살려서 꿀 빰 |
| 중국산 짭 전구가 **우리 집 네트워크를 해킹함** | 매터 인증 안 받은 깡통 기기가 커미셔닝(가입) 시도함 | 커미셔닝 시 **DAC(기기 출생증명서)** 까보라고 하고, 없으면 밴(차단) 때림 | 해킹 기기 원천 차단 및 스마트홈 보안 떡상 |
| 스피커(경계 라우터) 꺼지니까 **집안 전구가 다 먹통 됨** | 스레드망을 이어주는 다리가 스피커 1개뿐임 (SPOF 발생) | 애플TV, 홈팟 등 **경계 라우터 역할을 하는 기기를 집안에 여러 대 둠** | 하나 꺼져도 딴 스피커가 길 뚫어줘서 끊김 없음 |

#### 한줄 요약

- 지그비는 브리지(통역기) 달아 살려 쓰고, 짭 기기는 증명서(DAC) 까서 밴 때리고, 공유기 터질 거 대비해 스피커 여러 대 놔라.

## Ⅶ. 결론

<details><summary>용어 설명</summary>

- (상단 참조)

</details>

- 제조사 전용 프로토콜의 파편화로 찢어진 스마트홈 생태계를 대통합하기 위해, 하부 전송망은 **IPv6 기반 Thread** 기반 교체하고 최상위 응용단은 **Matter** 기반 단일화하는 아키텍처 기조 확립함

#### 한줄 요약

- '매터 오버 스레드(Matter over Thread)'는 "삼성 전구는 애플에서 안 켜져요" 하던 지긋지긋한 시대의 종말을 알리는 혁명이다.
