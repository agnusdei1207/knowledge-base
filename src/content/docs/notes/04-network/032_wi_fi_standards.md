## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **전기전자공학자협회 802.11(Institute of Electrical and Electronics Engineers 802.11, IEEE 802.11)**: Wi-Fi의 물리 전송과 무선 매체 접근 방식을 정의해 장비 간 상호운용을 보장하는 표준 계열이다.
- **접근점(Access Point, AP)**: 무선 단말을 유선 분배 시스템과 외부 네트워크에 연결하는 장치이다.

</details>

- 정의/개념: **IEEE 802.11**은 Wi-Fi의 물리 전송과 매체 접근을 규정한다.
- 배경/필요성: 제조사별 독자 규격만으로는 단말과 **AP**가 상호운용하며 전파를 공유할 수 없다.

#### 한줄 요약

- 같은 교통 규칙을 배운 단말과 AP가 한 도로의 차례를 나누듯 IEEE 802.11 규칙으로 전파를 공유한다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **하위 호환**: 새 세대 장비가 이전 세대 장비와 공통 기능을 협상해 통신할 수 있는 성질이다.
- **실효 처리량**: 규격상 최고속도에서 간섭•경합•제어 오버헤드를 제외하고 실제 전달되는 데이터 전송량이다.
- **기가헤르츠(Gigahertz, GHz)**: 무선 주파수의 초당 진동 횟수를 10억 단위로 나타내는 단위이다.

</details>

- **하위 호환**으로 세대 간 공통 기능을 협상한다.
- **GHz** 대역별로 도달 거리와 채널 용량이 다르다.
- 규제•간섭•단말 역량이 **실효 처리량**을 제한한다.

#### 한줄 요약

- 자동차 최고 속도가 도로 폭•교통량•차량 성능에 막히듯 Wi-Fi 실효 속도는 대역•간섭•단말 역량에 따라 달라진다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **분배 시스템**: 여러 AP와 유선망 사이에서 무선 프레임을 전달하는 논리 구성이다.

</details>

```text
무선 단말
│
무선 매체
│
접근점(AP)
│
분배 시스템
```

선의 의미: 무선 단말과 접근점이 무선 매체를 공유하고, 접근점이 분배 시스템을 통해 외부 네트워크 경계와 연결되는 정적 무선랜 토폴로지이다.

| 구성요소 | 책임 |
|:---|:---|
| 무선 단말 | AP 탐색•인증•무선 프레임 송수신 |
| 무선 매체 | 채널•주파수 대역 공유 |
| 접근점(AP) | **AP**가 무선 접속과 전송 기회 배정 |
| 분배 시스템 | **분배 시스템**이 AP와 외부 네트워크 연결 |

#### 한줄 요약

- 교차로인 AP가 공유 도로인 무선 매체의 차례를 단말에 나누고 뒤쪽 분배 시스템이 외부망으로 이어 준다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **비콘**: AP가 SSID•지원 기능•동기화 정보를 주기적으로 알리는 관리 프레임이다.
- **서비스 세트 식별자(Service Set Identifier, SSID)**: 사용자가 무선 네트워크를 구별하도록 AP가 광고하는 이름이다.
- **인증 요청**: 단말이 지원 인증 방식으로 접속 신원을 제시하는 절차이다.
- **인증 응답**: AP가 인증 결과와 후속 연결 조건을 회신하는 절차이다.
- **연결 요청**: 단말이 대역•속도•보안 지원 기능을 제안하는 절차이다.
- **연결 응답**: AP가 공통 기능과 연결 식별자를 확정해 회신하는 절차이다.

</details>

```text
접근점: 1. 비콘
      |
      v
무선 단말: 2. 인증 요청
      |
      v
접근점: 3. 인증 응답
      |
      +-- 인증 실패 ---- 접속 종료
      |
      `-- 인증 성공
             |
             v
무선 단말: 4. 연결 요청
             |
             v
접근점: 5. 연결 응답
             |
             `-- 공통 기능•연결 식별자 확정
```

### 동작 원리

1. **비콘**: AP가 **SSID**•지원 기능과 동기화 정보를 광고한다.
2. **인증 요청**: 단말이 지원 인증 방식으로 접속 신원을 제시한다.
3. **인증 응답**: AP가 인증 결과와 후속 연결 조건을 회신한다.
4. **연결 요청**: 단말이 대역•속도•보안 지원 기능을 제안한다.
5. **연결 응답**: 공통 기능과 연결 식별자를 확정한다.

#### 한줄 요약

- 단말이 비콘으로 AP의 기능과 보안 조건을 확인하고 인증•연결 파라미터를 교환한 뒤 협상된 공통 기능으로 접속한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **Wi-Fi 5**: 5GHz 대역과 다중 사용자 MIMO를 지원하는 IEEE 802.11ac 세대이다.
- **Wi-Fi 6**: 고밀도 단말의 자원 효율을 높인 IEEE 802.11ax 세대이다.
- **Wi-Fi 6E**: Wi-Fi 6 기능을 6GHz 대역까지 확장한 세대이다.
- **직교 주파수 분할 다중 접속(Orthogonal Frequency Division Multiple Access, OFDMA)**: 부반송파를 사용자별로 나누는 다중 접속 방식이다.
- **목표 기상 시간(Target Wake Time, TWT)**: 단말별 송수신 시간을 예약해 전력과 경합을 줄이는 기능이다.
- **Wi-Fi 7**: 320MHz 채널과 다중 링크로 처리량과 지연을 개선한 IEEE 802.11be 세대이다.
- **다중 링크 동작(Multi-Link Operation, MLO)**: 여러 주파수 대역의 무선 링크를 결합하거나 전환하는 기능이다.
- **다중 입력 다중 출력(Multiple-Input Multiple-Output, MIMO)**: 여러 안테나의 공간 스트림을 이용해 처리량과 사용자 동시 전송을 높이는 기술이다.
- **메가헤르츠(Megahertz, MHz)**: 채널 폭과 주파수를 초당 백만 진동 단위로 나타내는 단위이다.

</details>

| Wi-Fi 세대 | **Wi-Fi 5** | **Wi-Fi 6**•**Wi-Fi 6E** | **Wi-Fi 7** |
|:---|:---|:---|:---|
| 적용 기준 | 일반 5GHz 단말 환경 | 고밀도 단말•6GHz 확장 | 저지연•다중 링크 요구 |
| 핵심 특징 | 5GHz의 **MIMO** | **OFDMA**•**TWT** 기반 자원 효율 | **MLO**•320 **MHz** 채널 |
| 한계 | 혼잡 환경의 단말 경합 | 6GHz의 짧은 도달 범위 | 기능 조합별 단말 호환성 |

> 요약: 단말 지원과 전파 환경으로 세대를 선택한다.

#### 한줄 요약

- 최신 세대 기능은 AP와 단말이 동일 표준의 해당 기능을 모두 지원할 때만 동작한다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **공간 재사용**: 서로 간섭하지 않는 AP가 같은 채널을 동시에 사용하도록 출력과 채널 접근 조건을 조정하는 기법이다.
- **Wi-Fi 보호 접속 3(Wi-Fi Protected Access 3, WPA3)**: 강한 인증과 암호화로 Wi-Fi 접속을 보호하는 무선 보안 규격이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 표준 최고속도로만 무선 용량 산정 | 단말•공간•동시 사용자별 **실효 처리량** 측정 | 혼잡 시간의 용량 오차 감소 |
| 넓은 채널이 겹쳐 인접 AP 간섭 증가 | 채널 폭•출력•**공간 재사용** 계획 | 동일 대역의 전파 충돌 감소 |
| 구형 단말이 낮은 속도로 전송 시간 점유 | 대역•SSID•최저 속도 분리 | 고속 단말의 전송 기회 확보 |
| WPA2•WPA3 혼재로 보안 수준 하향 | **WPA3** 우선•전환 구간 격리 | 취약 인증 방식의 접속 범위 축소 |

#### 한줄 요약

- AP 밀도가 높을수록 채널 폭과 송신 출력을 줄여 인접 셀 간섭을 억제하고 공간 재사용 효율을 높인다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **Wi-Fi 세대 선택**: 단말 밀도•지원 기능•주파수 환경•지연 요구로 적용 세대를 정하는 판단이다.

</details>

- **Wi-Fi 세대 선택**은 다단말 혼잡에 **Wi-Fi 6**•**Wi-Fi 6E**, 저지연•다중 링크에 **Wi-Fi 7**을 적용하는 판단이다.

#### 한줄 요약

- 붐비는 교실에는 Wi-Fi 6•6E의 좌석 배분을 쓰고 여러 도로를 함께 써야 하는 저지연 환경에는 Wi-Fi 7을 고른다.
