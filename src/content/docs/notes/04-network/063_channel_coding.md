## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **채널 코딩(Channel Coding / Channel Encoding)**: 무선 채널의 잡음(Noise), 페이딩(Fading), 간섭(Interference)으로 인해 발생하는 수신 비트 오류를 극복하기 위해, 송신 데이터에 체계적인 잉여 비트(Redundancy / Parity)를 부가하는 신호 처리 기술.
- **순방향 오류 정정(Forward Error Correction, FEC)**: 수신 측에서 재전송 요구(ARQ) 없이 수신된 잉여 비트를 연산하여 자체적으로 전송 오류를 검출하고 정정하는 방식.

</details>

- 정의/개념: 무선 채널의 열악한 전파 환경에서 송신 정보 비트($k$)에 패리티 비트($n-k$)를 결합하여 **부호어(Codeword, $n$)** 를 생성하고, 수신단에서 **FEC 알고리즘** 을 통해 섀넌 한계(Shannon Limit)에 근접한 오류 정정 성능을 달성하는 **물리 계층 오류 제어 기술**
- 배경/필요성: 고속 무선 통신(5G/6G, 위성 통신)에서 재전송(ARQ) 왕복 지연을 방지하고, 낮은 신호 대 잡음비(SNR) 환경에서도 비트 오류율(BER)을 최소화할 요구

#### 한줄 요약
- 잉여 패리티 비트를 부가하여 수신단에서 재전송 없이 스스로 오류를 검출 및 정정(FEC)한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **부호율(Code Rate, $R = k/n$)**: 전체 전송 부호어 비트 수($n$) 대비 실제 순수 정보 비트 수($k$)의 비율로, 대역폭 효율성과 오류 정정 성능 간의 트레이드오프 지표.
- **인터리빙(Interleaving)**: 연속된 데이터 비트의 전송 순서를 재배치하여 채널 페이딩으로 발생하는 연쇄적 버스트 오류(Burst Error)를 복호기 기준의 독립적 랜덤 오류(Random Error)로 분산시키는 기법.

</details>

- **순방향 자체 오류 정정(FEC)**: 재전송 핸드셰이크 지연을 제거하여 실시간 통신(URLLC, 스트리밍)의 지연 시간 단축
- **버스트 오류 분산(Interleaving)**: 무선 페이딩에 의한 연속 비트 손상을 시간/주파수 축으로 확산하여 복호 성능 극대화
- **적응형 변조 및 부호화(AMC)**: 무선 채널 품질(CQI)에 따라 부호율($R$)을 동적 적응 조절(좋은 채널: 고부호율 고속 전송, 열악한 채널: 저부호율 강력 정정)

#### 한줄 요약
- FEC 자체 복원, 인터리빙을 통한 버스트 오류 분산, AMC 기반 동적 부호율 제어를 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **신드롬(Syndrome)**: 수신된 부호어 벡터와 패리티 검사 행렬($H^T$)을 곱하여 오류의 발생 여부 및 오류 위치 벡터를 산출하는 대수적 검증 지표.
- **연판정 복호(Soft-Decision Decoding)**: 수신 신호를 0 또는 1의 이진수로 단순 경판정(Hard Decision)하지 않고, 대수적 로그 우도비(LLR, Log-Likelihood Ratio) 확률값을 보존하여 복호 성능 이득(약 2~3dB)을 얻는 기법.

</details>

```text
[ 송신단 (Transmitter) ]
 [ 정보 비트 (k bits) ] ──▶ [ 채널 부호기 (FEC) ] ──▶ [ 인터리버 (Interleaver) ] ──▶ 변조 및 RF 송출
                                (n-k 패리티 부가)           (비트 순서 분산)
                                                                                   │
                                                                                   ▼ (AWGN / 페이딩 채널)
[ 수신단 (Receiver) ]                                                              │
 [ 복원 비트 (k bits) ] ◀── [ 채널 복호기 (LLR 연산) ] ◀── [ 역인터리버 (De-interleaver) ] ◀── RF 복조
```

선의 의미: 송신단에서 패리티 부가 및 인터리빙을 거친 신호가 무선 채널을 통과한 후, 수신단에서 역인터리빙과 LLR 복호 과정을 거쳐 원본 비트로 복원되는 파이프라인

| 구성요소 | 책임 및 역할 | 비고 |
|:---|:---|:---|
| **채널 부호기 (Encoder)** | 생성 행렬($G$)을 통해 정보 비트에 $n-k$ 비트의 패리티를 결합하여 부호어 생성 | 체계적 부호화 |
| **인터리버 (Interleaver)** | 버스트 오류를 방지하기 위해 매트릭스 전치 또는 의사난수 패턴으로 비트 재배열 | 시간/주파수 인터리빙 |
| **무선 채널 (Channel)** | 열잡음(AWGN), 다중 경로 페이딩, 도플러 확산으로 신호 감쇠 및 비트 반전 유발 | 물리 매체 |
| **역인터리버** | 수신된 비트 스트림의 순서를 원래의 시퀀스로 재정렬하여 버스트 오류를 랜덤화 | 복호 전처리 |
| **채널 복호기 (Decoder)** | 신드롬($S$) 또는 LLR 반복 연산(BCJR/Belief Propagation)을 통해 오류 정정 | Hard/Soft Decision |

#### 한줄 요약
- 부호기, 인터리버, 무선 채널, 역인터리버, 복호기가 유기적으로 결합하여 전송 신뢰성을 보장한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **하이브리드 ARQ(HARQ)**: FEC의 오류 정정과 ARQ의 재전송을 결합하여, 복호 실패 시 이전 수신 신호를 버리지 않고 재전송된 신호와 소프트 컴바이닝(Soft Combining: Chase Combining / Incremental Redundancy)하여 복호 성공률을 비약적으로 높이는 기법.

</details>

```text
1. 송신 측에서 정보 비트($k$)에 패리티를 부가하여 부호어($n$) 생성 후 인터리빙 송출
            │
            ▼
2. 무선 채널 통과 중 잡음 및 다중 경로 페이딩으로 인해 비트 왜곡 발생
            │
            ▼
3. 수신 측 역인터리빙 수행 ➔ 채널 복호기가 LLR 연산 및 신드롬 기반 오류 위치 탐색
            │
            ▼
4. 복호기가 반복 복호 알고리즘을 통해 왜곡된 비트 값을 원본 정보 비트로 정정 복원
            │
            ├─ [CRC 검증 성공] ➔ 상위 계층으로 정상 데이터 전달
            ▼
5. [CRC 검증 실패] ➔ LLR 버퍼 보존 후 HARQ NACK 발송 ➔ 재전송 패킷과 컴바이닝 복호
```

**동작 원리**

1. **부호화 및 확산**: 정보 비트에 구조적 패리티를 부착하고 인터리빙으로 버스트 에러 방어
2. **신호 수신**: 복조기가 실수(Real) 값 형태의 신호 진폭을 수신하여 LLR(Log-Likelihood Ratio) 생성
3. **반복 복호**: 터보/LDPC 복호기가 내부 성분 복호기 간 외부 정보(Extrinsic Information)를 반복 교환
4. **CRC 검증 및 HARQ**: 패리티를 통한 오류 복구 완료 후 CRC로 무결성을 최종 확인하고 실패 시 소프트 결합 재전송 요청

#### 한줄 요약
- 부호화/인터리빙, 채널 전송, 역인터리빙, LLR 반복 복호, CRC 검증 및 HARQ 연계 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **해밍 부호 / 리드-솔로몬 / 터보 부호 / LDPC / 폴라 부호**: 블록 단위 단일 비트 정정(해밍), 심볼 단위 버스트 정정(RS), 섀넌 한계 근접 반복 복호(터보/LDPC), 채널 분극 기반 5G 제어 채널 표준(폴라).

</details>

| 부호 종류 | 핵심 수학적 원리 | 주요 오류 정정 특성 | 대표 적용 표준 |
|:---|:---|:---|:---|
| **해밍 부호 (Hamming)** | 패리티 검사 행렬($H$), 해밍 거리 $d_{min}=3$ | **단일 비트 오류 정정(SEC), 2비트 검출(DED)** | 서버 ECC RAM 메모리, L1 캐시 |
| **리드-솔로몬 (RS Code)** | 갈루아 필드($GF(2^m)$) 기반 비이진 다항식 | **연속된 심볼 버스트 오류(Burst Error) 정정에 탁월** | 광디스크(CD/DVD), QR코드, DVB-T |
| **터보 부호 (Turbo Code)** | 두 개의 합성곱 부호기와 인터리버 병렬 결합 | **반복 연판정 복호로 섀넌 한계 0.5dB 근접** | 3G WCDMA, 4G LTE 데이터 채널 |
| **LDPC 부호 (Low-Density)**| 희소 패리티 검사 행렬($H$), 팩터 그래프 | **병렬 고속 복호 가능, 대용량 초고속 처리에 최적** | 5G NR 데이터 채널, Wi-Fi 6/7 |
| **폴라 부호 (Polar Code)** | 채널 분극(Channel Polarization) 현상 활용 | **이론상 섀넌 용량을 완전 달성하는 유일한 부호** | 5G NR 제어 채널(eMBB C-Plane) |

#### 한줄 요약
- 해밍(단일 비트), RS(버스트 오류), 터보(4G 데이터), LDPC(5G/Wi-Fi 고속 데이터), 폴라(5G 제어 채널)가 사용된다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **블록 오류율(Block Error Rate, BLER)**: 전송된 전체 전송 블록(TB) 중 수신단 CRC 검증을 통과하지 못한 오류 블록의 비율 (통상 타겟: 10%).

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 무선 채널 페이딩 심화 시 고정 부호율 적용으로 인한 BLER 급증 및 링크 단절 | CQI 피드백 기반 **적응형 변조 및 부호화(AMC)** 동적 적용 | 채널 상태에 따른 부호율 최적화 및 10% 타겟 BLER 유지 |
| 복호기 반복 연산 횟수(Iteration) 과다로 인한 처리 지연 및 URLLC SLA 위반 | **조기 중단 조건(Early Stopping: 신드롬 체크)** 및 하드웨어 LDPC 적용 | 불필요한 반복 복호 차단 및 복호 지연 시간 50% 단축 |
| 연판정 LLR 고정밀 연산으로 인한 단말기 모뎀 칩셋 전력 소모 및 발열 증가 | 고정 소수점 양자화(Fixed-Point LLR) 및 **전용 ASIC 하드웨어 가속기** 탑재 | 모뎀 전력 소모 최소화 및 기가비트급 라인 레이트 복호 달성 |

#### 한줄 요약
- AMC로 BLER을 제어하고, Early Stopping으로 복호 지연을 줄이며, 전용 ASIC 가속으로 전력을 최적화한다.

## Ⅶ. 결론

- 초고속 무선 통신의 신뢰성과 전송 효율을 극대화하기 위해 데이터 채널에는 고병렬 처리가 가능한 **LDPC 부호**, 제어 채널에는 **폴라(Polar) 부호**를 채택하는 5G/6G 표준 채널 코딩 체계를 구축하고, 무선 채널 변동성에 대응하기 위해 **AMC** 및 **HARQ Incremental Redundancy** 기술을 통합 적용하여 섀넌 한계에 근접한 통신 성능을 완성

#### 한줄 요약
- LDPC 및 폴라 부호와 AMC/HARQ 결합을 통해 무선 채널의 전송 신뢰성을 극대화한다.
