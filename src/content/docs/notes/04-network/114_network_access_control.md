## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **NAC (Network Access Control)**: 사용자 신원 인증과 단말의 보안 상태(포스처)를 검증하여 정상 단말만 업무망에 접속시키는 보안 체계.
- **Posture Assessment (포스처 점검)**: 단말의 OS 패치, 백신 실시간 감시, 디스크 암호화 여부 등을 스캔하여 사내 보안 규정 준수 여부를 평가하는 절차.

</details>

- 정의/개념: 사용자 신원과 단말의 무결성(포스처)을 검증하여 **정책 준수 단말에만 업무망을 허용하고 취약 단말은 동적 격리·치료하는 접근 통제 보안 기술**
- 배경/필요성: 비인가 단말 및 패치 누락 취약 PC의 무단 접속으로 인한 **사내망 랜섬웨어 전파, 악성코드 횡적 이동(Lateral Movement) 및 데이터 유출 방어 불가**

#### 한줄 요약
- 사전 포스처 검증, 동적 격리망 할당, 사후 지속 모니터링을 통해 엔드포인트 무결성을 보장한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **Pre-Admission vs Post-Admission**: 네트워크 접속 전 단말의 보안 규정 준수를 검증하는 사전 통제와 접속 후 악성 행위 발생 시 즉각 격리하는 사후 통제.
- **Dynamic VLAN & dACL**: RADIUS 서버가 스위치 포트에 전달하는 파라미터에 따라 단말의 소속 VLAN과 L4 방화벽 ACL을 동적으로 변경하는 기술.

</details>

- **사전 무결성 검증(Pre-Admission Posture)**: 네트워크 접속 전 **OS 패치, 백신 구동 여부를 정밀 스캔하여 불합격 단말 즉시 격리**
- **동적 네트워크 권한 격리(Dynamic VLAN / dACL)**: 802.1X/RADIUS 연동을 통해 **사용자 역할 및 단말 상태별 업무망/격리망 동적 배정**
- **접속 후 지속적 이상 행위 감시(Post-Admission)**: 세션 연결 후에도 **백신 프로세스 종료 등 보안 위반 감지 시 1초 내 포트 차단**

#### 한줄 요약
- 사전 포스처 검증, 동적 VLAN/dACL 격리, 접속 후 지속적 감시를 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **NAS (Network Access Server)**: L2 스위치, 무선 AP 등 단말의 물리적 접속 지점에서 트래픽을 차단/개방하는 네트워크 장비.

</details>

```text
[NAC 접근 제어 및 동적 격리 아키텍처]
|-- Endpoint Devices (Supplicant: 유선 PC, 노트북, 모바일, 비관리 IoT 단말)
`-- Network Access Server (NAS: L2/L3 스위치, 무선 AP 컨트롤러)
    |-- IEEE 802.1X / MAC Auth Bypass (포트 블로킹 및 EAP 중계)
    `-- Dynamic Port Reprogramming (VLAN 10 업무망 또는 VLAN 99 격리망 동적 주입)
`-- NAC Policy & AAA Server (Policy Server, RADIUS Engine)
    |-- Identity Authentication (Active Directory / LDAP / MDM 연동)
    |-- Posture Assessment Engine (컴플라이언스 룰셋 판정: Pass / Fail)
    `-- Remediation Server (VLAN 99 격리 단말에 백신 업데이트 및 패치 다운로드 제공)
```

선의 의미: 단말의 접속 요청이 스위치를 통해 NAC 정책 서버로 전달되어 포스처 평가를 거치고 결과에 따라 정상 업무망 또는 격리 치료망이 스위치 포트에 주입되는 구조

| 구성요소 | 핵심 엔지니어링 책임 | 주요 특징 |
|:---|:---|:---|
| **엔드포인트 단말** | 802.1X 인증 정보 제시, **에이전트를 통한 레지스트리/프로세스 보안 상태 수집** | Supplicant |
| **접근 집행점 (NAS)** | 스위치 포트 차단/개방, **RADIUS 응답에 따른 동적 VLAN 전환 및 dACL 적용** | Switch / AP |
| **NAC 정책 서버** | **신원 인증(AAA), 단말 프로파일링, 포스처 적합성 판정 및 정책 하달** | Policy Server |
| **디렉터리/MDM 연동기**| Active Directory 계정 권한 및 **MDM 단말 관리 상태(루팅/탈옥 여부) 질의** | External DB |
| **치료 서버 (Remediation)**| 격리된 비준수 단말에 **OS 보안 패치 파일 및 백신 업데이트 다운로드 제공** | Patch Portal |

#### 한줄 요약
- 단말 서플리컨트, 스위치 NAS, NAC 정책 서버, 디렉터리 연동기, 치료 서버가 결합된다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **Quarantine VLAN (격리망)**: 포스처 점검에 불합격한 단말이 배치되는 네트워크로, 오직 사내 패치 서버 및 백신 다운로드 서버로의 접속만 허용됨.

</details>

```text
NAC 단말 감지, 포스처 평가, 동적 격리 및 치료 파이프라인
        │
   1. [물리 링크 감지] 직원이 노트북을 사내 랜에 연결 시 스위치 포트가 차단 상태에서 MAC 감지
        │
   2. [포스처 무결성 수집] NAC 에이전트가 단말 내 OS 패치 버전 및 백신 실시간 감시 상태를 수집
        │
   3. [정책 서버 적합성 대조] NAC 정책 서버가 AD 사용자 인증 및 컴플라이언스 룰셋 대조
        │
   ├─ [포스처 불합격: 백신 미구동] ➔ RADIUS 응답으로 'VLAN 99(격리망)' 및 치료 dACL 전송
   │     │
   │     ▼
   │   스위치가 포트를 격리망으로 이동 ➔ 백신 다운로드 페이지만 허용 ➔ 자가 치료 완료 후 재인증
   ▼
4. [포스처 합격] ➔ RADIUS 응답으로 'VLAN 10(업무망)' 및 정규 접근 권한 전송
        │
   ▼
5. [스위치 포트 개방] 정상 업무 수행 (사후 백신 프로세스 종료 감지 시 즉시 격리망으로 강등)
```

#### 한줄 요약
- 링크 연결 → 포스처 무결성 수집 → 정책 서버 판정 → 동적 VLAN/dACL 할당 → 사후 지속 감시 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **Agent-based** vs **Agentless** vs **802.1X EAP**.

</details>

| 비교 항목 | 에이전트 기반 NAC (Agent-based) | 에이전트리스 NAC (Agentless) | 표준 802.1X EAP 기반 NAC |
|:---|:---|:---|:---|
| **검증 깊이** | **매우 깊음 (프로세스, 레지스트리, 파일)**| 중간 (포트 스캔, 배너 그래빙) | **강력한 신원 인증 (인증서, ID/PW)**|
| **단말 지원 범위** | 사내 표준 PC(Windows, macOS) | **IP 전화기, 프린터, IoT 센서, 게스트**| 802.1X 지원 표준 단말 |
| **구축/배포 용이성**| 에이전트 사전 배포 부담 존재 | **매우 용이 (네트워크 장비 설정만 요구)**| 인증서 배포 및 인프라 설정 고도화 |
| **사후 지속 감시** | **완벽 지원 (백신 프로세스 종료 즉시 감지)**| 주기적 네트워크 폴링 스캔 한계 | 세션 유지 중심 (상태 변화 감지 제한)|
| **주요 적용 영역** | **임직원 핵심 업무용 노트북/PC** | **스마트 빌딩 IoT 장치, 방문객 네트워크**| **전사 유무선 통일 엔터프라이즈 보안** |

#### 한줄 요약
- 임직원 PC는 심층 에이전트 기반, 비관리 IoT/게스트는 에이전트리스 및 802.1X를 하이브리드 적용한다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **MAC Spoofing Bypass**: 공격자가 인가된 프린터의 MAC 주소를 복제하여 단순 MAC 기반 NAC 통제를 우회 침투하는 공격.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 인가된 IoT 기기의 MAC을 도용한 비인가 단말의 **MAC 스푸핑 우회 침투** | MAC 인증 외에 **`다차원 DHCP/HTTP 핑거프린팅 프로파일링 및 802.1X MAB 연동`** | MAC 위조 단말 100% 탐지 및 비인가 접속 원천 차단 |
| NAC 도입 초기 과도한 차단으로 인한 **대규모 정상 업무 마비** | 단계적 구축: **`모니터링(Audit Mode) -> 경고/유예 -> 완전 강제 차단`** | 정책 오분류 예외 사전 정제 및 업무 연속성 완벽 보장 |
| NAC 정책 서버 및 RADIUS 장애 시 전사 유무선 네트워크 **전면 통신 불통** | 스위치에 **`RADIUS 다운 시 이전 VLAN 유지(Critical VLAN / Fail-Open)`** 구성 | NAC 플랫폼 장애 시에도 가용성 100% 확보 |
| 신규 제로데이 취약점 발생 시 단말의 컴플라이언스 갱신 지연 | **`EDR / SIEM 연동 기반 실시간 위협 격리 API 트리거`** 구축 | 신종 악성 행위 발생 즉시 1초 내 네트워크 격리 |

#### 한줄 요약
- 다차원 프로파일링으로 MAC 스푸핑을 막고, 단계적 모드로 오차단을 방지하며, Fail-Open으로 가용성을 보장한다.

## Ⅶ. 결론

- 제로 트러스트(Zero Trust) 보안 모델의 제1원칙인 '신뢰하지 않고 항상 검증하라'를 엔드포인트 네트워크 계층에서 구현하기 위해 **NAC 아키텍처를 전사 보안 거버넌스의 핵심 기반으로 구축**하되, 실무 적용 시 **에이전트와 에이전트리스의 하이브리드 프로파일링, 동적 VLAN/dACL 기반 격리망 운영, EDR/SIEM/SOAR 솔루션과의 API 연동 폐루프 통제**를 구현하여 무결점 엔터프라이즈 접근 제어 환경 완성

#### 한줄 요약
- NAC는 사전 포스처 검증과 동적 VLAN 격리 및 사후 지속 감시를 결합하여 제로 트러스트 엔드포인트 접근 제어를 완성하는 필수 보안 인프라다.
