## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **사물인터넷(Internet of Things, IoT)**: 유무선 네트워크로 상호 연결된 사물(센서, 액추에이터, 임베디드 디바이스)이 사람의 직접적인 개입 없이 환경 데이터를 수집·가공하고, 클라우드/엣지 인텔리전스를 통해 물리 세계를 자동 제어하는 초연결 네트워크 시스템.
- **IoT 참조 아키텍처(IoT Reference Architecture)**: 이기종 단말 수용, 저전력 무선 통신 변환, 엣지 실시간 처리, 클라우드 플랫폼 데이터 분석 및 디바이스 생애주기 관리(LCM)를 계층별로 정의한 표준 청사진 (ITU-T Y.2060 / ISO/IEC 30141).

</details>

- 정의/개념: 현장의 물리 센서/액추에이터 단말(**Device 계층**), 비-IP 프로토콜 변환을 수행하는 **Gateway 계층**, 초저지연 로컬 자율 제어를 수행하는 **Edge 계층**, 대규모 시계열 분석 및 디바이스 제어를 총괄하는 **Cloud Platform 계층** 으로 구성된 **엔드투엔드 사물인터넷 시스템 아키텍처**
- 배경/필요성: 수백만 대의 저전력·저사양 이종 IoT 디바이스가 생성하는 방대한 텔레메트리 트래픽을 효율적으로 수용하고, 클라우드 연결 단절 시에도 현장 시스템의 무중단 안전 제어를 보장할 요구

#### 한줄 요약
- Device, Gateway, Edge, Cloud 4계층 구조를 통해 이종 센서 데이터 수집과 실시간 제어 및 생애주기를 관리한다.

## Ⅱ. 특징

<details><summary>용어 설명</summary>

- **디바이스 수명주기 관리(Device Lifecycle Management, LCM)**: 디바이스 제조 및 온보딩(Provisioning/Auth), 구성 관리, 무선 펌웨어 갱신(FOTA/OTA), 상태 모니터링, 수명 종료 시 보안 인증서 폐기(Decommissioning)의 전 생애주기 프로세스.
- **클라우드-엣지 협업 제어(Cloud-Edge Continuum)**: 고성능 빅데이터 AI 모델 학습 및 전역 정책은 클라우드에서 수행하고, 추론 모델 실행 및 밀리초 단위 세이프티 차단은 현장 엣지에서 전담하는 분업 구조.

</details>

- **4단계 계층화 분업**: 현장 측정(Device) $\rightarrow$ 프로토콜 변환(Gateway) $\rightarrow$ 로컬 저지연 추론(Edge) $\rightarrow$ 전역 관리(Cloud)
- **전주기 보안 및 기기 거버넌스(LCM)**: 하드웨어 보안 모듈(TPM/eSE) 기반 기기 고유 신원 인증 및 OTA 롤백 기반 안전한 펌웨어 패치
- **양방향 제어 파이프라인**: 센서 텔레메트리 상향 전송(MQTT/CoAP)과 클라우드/엣지의 하향 제어 명령(Actuation)을 비동기 이벤트 기반으로 실시간 처리

#### 한줄 요약
- 4계층 분업, 전주기 기기 관리(LCM), 양방향 텔레메트리-제어 파이프라인을 제공한다.

## Ⅲ. 구조 및 구성요소

<details><summary>용어 설명</summary>

- **IoT 게이트웨이(IoT Gateway)**: 비-IP 무선 통신(BLE, Zigbee, Modbus, CAN)을 IP 기반 표준 프로토콜(TCP/UDP, MQTT, HTTPS)로 상호 변환하고 로컬 보안 터널링을 제공하는 경계 장치.
- **IoT 플랫폼(Cloud Platform)**: 디바이스 레지스트리(Registry), 디지털 트윈(Digital Twin / Device Shadow), 시계열 데이터 파이프라인, 규칙 엔진(Rule Engine)을 제공하는 클라우드 PaaS/SaaS.

</details>

```text
[ 4. 클라우드 플랫폼 계층 (AWS IoT / Azure IoT Hub) ]
 ├─ 디바이스 레지스트리 (X.509 신원 인증) ── 규칙 엔진 / 디지털 트윈 ── 시계열 빅데이터 AI
 └─ 전역 OTA 펌웨어 배포 파이프라인
                            │ (WAN: MQTT over TLS, HTTPS, AMQP)
                            ▼
[ 3. 엣지 컴퓨팅 계층 (Edge Server / Micro-K8s) ] ── (실시간 AI 추론, 로컬 세이프티 루프)
                            │
                            ▼ (LAN / Fieldbus: OPC UA, Modbus TCP)
[ 2. IoT 게이트웨이 계층 (Protocol Gateway) ] ────── (비-IP 프로토콜 ➔ IP 패킷 변환)
                            │
                            ▼ (PAN / 무선: BLE, Zigbee, LoRaWAN, RS-485)
[ 1. 디바이스 계층 (Sensors & Actuators) ] ──────── (온도/진동 센서, 모터 인버터, 솔레노이드 밸브)
```

선의 의미: 말단 센서 데이터가 게이트웨이와 엣지를 거쳐 클라우드로 취합되고, 제어 명령이 역방향으로 하향 전달되는 E2E 아키텍처

| 계층 | 주요 구성요소 | 핵심 책임 및 역할 | 비고 |
|:---|:---|:---|:---|
| **클라우드 계층 (Cloud)** | 디바이스 섀도우, 룰 엔진, 시계열 DB | 전역 디바이스 상태 동기화, 빅데이터 분석, OTA 배포 총괄 | SaaS / PaaS |
| **엣지 계층 (Edge)** | 경량 런타임 (K3s, EdgeX Foundry) | 10ms 이내 초저지연 로컬 분석, 클라우드 단절 시 자율 운영 | Edge Gateway |
| **게이트웨이 (Gateway)**| 프로토콜 변환 엔진, 로컬 캐시 | BLE/Zigbee/CAN을 MQTT/IP로 번역 및 패킷 필터링 | L2~L7 변환 |
| **디바이스 계층 (Device)** | MCU, 온습도/압력 센서, 액추에이터 | 물리 환경 상태 측정, 전기 신호 변환, 기계식 구동 집행 | MCU, RTOS |

#### 한줄 요약
- Device, Gateway, Edge, Cloud 4계층이 결합하여 이종 환경의 센싱과 자율 제어를 수행한다.

## Ⅳ. 흐름도

<details><summary>용어 설명</summary>

- **디바이스 섀도우(Device Shadow / Digital Twin)**: 단말의 전원 오프나 통신 두절 시에도 클라우드 상에서 마지막 정상 상태(Reported State)와 목표 설정 상태(Desired State)를 보관하여 비동기 제어를 가능케 하는 가상 복제본.

</details>

```text
1. 디바이스가 하드웨어 X.509 인증서 및 TPM 토큰으로 클라우드/게이트웨이에 보안 상호 인증
            │
            ▼
2. 센서가 계측한 텔레메트리 데이터를 게이트웨이에서 MQTT/Protobuf로 변환하여 엣지/클라우드로 전송
            │
            ▼
3. 엣지 분석 엔진이 실시간 임계치를 평가하여 긴급 이상 징후 감지 시 즉각 로컬 액추에이터 차단
            │
            ▼
4. 클라우드 플랫폼이 시계열 데이터를 집계하고 AI 이상 감지 모델 실행 ➔ 최적화 제어 파라미터 산출
            │
            ▼
5. 디바이스 섀도우(Device Shadow)를 갱신하여 목표 상태(Desired)를 단말로 하향 주입 ➔ OTA 패치 집행
```

**동작 원리**

1. **상호 인증(Mutual TLS)**: 디바이스가 네트워크 진입 시 CA 서명 인증서로 진위 여부 증명
2. **경량 텔레메트리 전송**: MQTT 토픽 기반의 Pub/Sub 모델로 페이로드를 압축하여 상향 스트리밍
3. **엣지 로컬 폴백**: WAN 회선 장애 발생 시 엣지가 즉각 로컬 제어권을 인수하여 설비 안전 정지
4. **비동기 상태 동기화**: 클라우드가 디바이스 섀도우의 `Desired` 속성을 변경하면 단말이 온라인 시 자동 수렴
5. **무선 펌웨어 배포**: A/B 듀얼 파티션 기반 OTA를 실행하여 다운로드 및 검증 후 안전 재부팅

#### 한줄 요약
- 상호 인증, 텔레메트리 전송, 엣지 저지연 판단, 클라우드 분석, 디바이스 섀도우 제어 및 OTA 순으로 동작한다.

## Ⅴ. 종류 및 비교

<details><summary>용어 설명</summary>

- **게이트웨이 중계형 vs 엣지 컴퓨팅형 vs 직접 셀룰러 연결형**: 비-IP 저전력 노드 수용형, 현장 자율 컴퓨팅형, 초고속 5G 모듈 직결형의 아키텍처 비교.

</details>

| 비교 항목 | 게이트웨이 중계형 (Gateway-Centric) | 엣지 컴퓨팅형 (Edge-Centric) | 직접 연결형 (Direct Cellular/Wi-Fi) |
|:---|:---|:---|:---|
| **통신 인프라** | BLE, Zigbee, LoRa $\rightarrow$ 게이트웨이 | TSN, Industrial Ethernet, 5G 프라이빗 | 5G NR, LTE-M, NB-IoT 직결 |
| **제어 지연 시간** | 중간 (100ms ~ 수초) | **초저지연 ($\le 10\text{ms}$ 현장 완결)** | 네트워크 왕복 지연 (50~200ms) |
| **단말 자원 요구량** | **초경량 MCU (코인 배터리 수년 구동)** | 경량 RTOS 및 센서 노드 | 고성능 AP 및 대용량 배터리 필수 |
| **오프라인 자율성** | 낮음 (게이트웨이 캐싱 의존) | **매우 높음 (로컬 엣지 독립 제어)** | 전무 (기지국 단선 시 제어 마비) |
| **주요 적용 분야** | 스마트홈, 원격 검침(AMI), 스마트팜 | **스마트팩토리, 로봇 제어, 자율주행** | 커넥티드 카, 스마트 워치, 자산 트래커 |

#### 한줄 요약
- 게이트웨이형은 저전력 센서망, 엣지형은 미션 크리티컬 산업망, 직접 연결형은 모바일 자산 트래킹에 쓰인다.

## Ⅵ. 실무 고려사항 및 대책

<details><summary>용어 설명</summary>

- **기기 벽돌화(Device Bricking)**: OTA 펌웨어 업데이트 중 전원 차단이나 이미지 무결성 손상으로 부트로더가 훼손되어 원격 복구가 불가능해지는 물리적 고장 상태.
- **A/B 듀얼 뱅크 펌웨어 업데이트(A/B Dual Partitioning)**: 플래시 메모리를 A구역과 B구역으로 분할하여 신규 펌웨어를 비활성 구역에 설치 및 무결성 검증 후 부팅 플래그만 전환하며, 실패 시 이전 구역으로 즉각 자동 롤백하는 무결성 보호 기법.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| WAN 클라우드 백홀 회선 단절 시 설비 모니터링 및 긴급 비상 제어 마비 | **현장 엣지(Edge Gateway) 자율 페일오버 및 로컬 룰 엔진** 구축 | 네트워크 단절 시에도 100% 현장 설비 연속성 및 안전 정지 보장 |
| 광역 네트워크 불안정 상태에서 OTA 펌웨어 전송 중단 시 단말 벽돌화(Bricking) | **A/B 듀얼 뱅크 플래시 파티셔닝** 및 부팅 실패 시 자동 하드웨어 롤백 | 펌웨어 손상으로 인한 현장 물리 방문 제거 및 100% 무중단 복구 |
| 네트워크 복구 시 대규모 단말 데이터가 일시 집중 유입되며 타임스탬프 왜곡 발생 | 단말 내부 **로컬 버퍼링 타임스탬프 보존** 및 메시지 브로커 **멱등성(Idempotency)** 처리 | 중복 데이터 삽입 방지 및 시계열 분석 정합성 100% 유지 |

#### 한줄 요약
- 엣지 자율 제어로 단절에 대비하고, A/B 듀얼 뱅크로 벽돌화를 방지하며, 타임스탬프 보존으로 데이터 정합성을 유지한다.

## Ⅶ. 결론

- 대규모 분산 디바이스의 지능형 제어와 비즈니스 통찰을 확보하기 위해 **Device-Gateway-Edge-Cloud 4계층 IoT 아키텍처**를 표준 모델로 도입하되, 현장 운영의 신뢰성과 보안성을 담보하기 위해 **A/B 듀얼 뱅크 기반 안전한 OTA 체계**, **엣지 자율 분산 제어**, **하드웨어 RoT(Root of Trust) 기반 엔드투엔드 보안**을 통합 구축하여 고가용성 스마트 IoT 생태계를 완성

#### 한줄 요약
- 4계층 IoT 아키텍처와 엣지 자율 제어 및 A/B OTA 기술을 결합하여 고신뢰 IoT 시스템을 구현한다.
