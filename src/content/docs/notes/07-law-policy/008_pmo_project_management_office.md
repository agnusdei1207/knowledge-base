## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **PMO**: 프로젝트의 방법·자원·성과·의사결정을 통합 지원·통제하는 조직.
- **EVM**: 계획 가치·획득 가치·실제 원가로 일정·비용 성과를 측정하는 기법.

</details>

- 정의/개념: 발주자를 지원해 복합 사업을 통합 관리하는 **전문 사업관리 조직**
- 배경/필요성: 다중 사업자의 개별 진도 보고는 **공정 지연·책임 공백 은폐**

#### 한줄 요약
- PMO는 발주자를 지원해 범위·일정·비용·품질·위험을 통합 관리한다.

## Ⅱ. 특징

- 템플릿·교육을 제공하는 **지원형 PMO**
- 방법론 준수를 감독하는 **통제형 PMO**
- PM·자원을 직접 관리하는 **지시형 PMO**
- PV·EV·AC 기반의 **EVM 정량 관리**
- 다중 사업자 사이의 **인터페이스·책임 조정**
- 발주자 판단을 돕는 **통합 의사결정 지원**

#### 한줄 요약
- 권한별 유형, EVM, 다중 벤더 조정, 의사결정 지원이 핵심이다.

## Ⅲ. 구조 및 구성요소

```text
┌────────────── PMO 거버넌스 ──────────────┐
│                                         │
│              [발주기관]                 │
│                  └── [PMO]              │
│                      ├── [주사업자]      │
│                      ├── [협력사업자]    │
│                      └── [공급자]        │
└─────────────────────────────────────────┘
```

| 구성요소 | 책임 |
|:---|:---|
| **발주기관** | 목표·예산·주요 변경의 최종 결정 |
| **PMO** | 범위·일정·비용·품질·위험 통합 관리 |
| **주사업자** | 통합 실행과 산출물·성과 책임 |
| **협력사업자·공급자** | 담당 영역 실행과 인터페이스 준수 |

#### 한줄 요약
- 발주기관, PMO, 주사업자, 협력사업자·공급자로 구성된다.

## Ⅳ. 흐름도

```text
[사업자 실적·위험]
     │
     └──────── 관리 데이터 제출
                 │
                 ▼
              [PMO]
                 │ 1. 통합 관리 기준 수립
                 │ 2. 공정·비용·품질 측정
                 │ 3. 편차·원인·대안 분석
                 ▼
            [발주기관]
                 │ 4. 조치안 의사결정
                 ▼
              [PMO]
                 │ 5. 실행 지시·효과 추적
                 └──────── 관리 결과 반환
```

**동작 원리**

1. **통합 관리 기준 수립**: WBS·보고·변경·위험·품질 기준 확정
2. **공정·비용·품질 측정**: EVM과 산출물·텔레메트리로 실적 확인
3. **편차·원인·대안 분석**: 주공정선과 인터페이스 병목 진단
4. **조치안 의사결정**: 범위·자원·일정 대안의 영향 승인
5. **실행 지시·효과 추적**: 담당·기한을 지정하고 회복 여부 재측정

#### 한줄 요약
- 기준, 측정, 분석, 발주자 결정, 실행 추적 순으로 관리한다.

## Ⅴ. 종류 및 비교

| 비교 항목 | PMO | PM | 정보시스템 감리 |
|:---|:---|:---|:---|
| 입장 | 발주자 **관리 지원** | 수행사의 실행 책임자 | 독립 제3자 검증자 |
| 핵심 역할 | 통합 일정·비용·위험 조정 | 팀·과업·산출물 실행 | 준거·계약·품질 적합성 평가 |
| 수행 주기 | 전 기간 지속 관리 | 전 기간 일상 실행 | 단계·마일스톤별 점검 |
| 의사결정 | 대안 분석·권고·위임 범위 통제 | 수행 조직 내 업무 지시 | 지적·시정조치 요구 |
| 주요 산출물 | 통합 공정·위험·의사결정 자료 | 실행 계획·완료 산출물 | 감리·시정조치 확인보고서 |

#### 한줄 요약
- PMO는 통합 관리, PM은 실행, 감리는 독립 적합성 검증을 담당한다.

## Ⅵ. 실무 고려사항 및 대책

| 문제 | 대책 |
|:---|:---|
| PMO와 수행사 PM의 지시권 충돌 | RACI 기반 **권한·책임 경계** 확정 |
| 보고서 중심으로 실제 품질 은폐 | 빌드·결함·EVM의 **자동 데이터 연계** |
| 사업 위험과 PMO 통제력 불일치 | 위험·복잡도 기반 **PMO 유형 선정** |
| 진도율만 높이고 핵심 경로 지연 | 주공정선·완료 기준 **실적 검증** |
| PMO가 독립 감리 역할까지 수행 | 관리와 감리의 **역할 분리** |

#### 한줄 요약
- 역할 경계, 자동 데이터, 유형 선정, 실적 검증, 감리 분리를 적용한다.

## Ⅶ. 결론

- 사업 복잡도와 발주자 역량을 기준으로 **PMO 유형·통제 권한** 결정

#### 한줄 요약
- 복합도와 관리 역량에 맞는 PMO를 두고 EVM으로 편차를 조기 통제한다.
