## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **EU CSRD**: 대상 기업의 지속가능성 정보를 표준에 따라 공시하게 하는 EU 지침.
- **이중 중대성**: 사람·환경 영향과 기업의 재무 위험·기회를 함께 판단하는 원칙.
- **ESRS**: 지속가능성 공시 항목과 작성 기준을 제공하는 유럽 표준.

</details>

- 정의/개념: 이중 중대성에 따라 ESRS 공시를 요구하는 **지속가능성 보고 지침**
- 배경/필요성: 기존 비재무 보고는 기업마다 항목과 범위가 달라 **정보 비교·검증 일관성**이 서지 않아 투자자가 기업마다 개별 확인 비용을 치르므로, 이중 중대성 판단과 공시 항목을 표준으로 고정한 보고 계층을 자율 공시 위에 두어 서술형 홍보를 검증 가능한 공통 양식으로 대체할 필요

#### 한줄 요약
- CSRD는 이중 중대성으로 중요한 지속가능성 정보를 ESRS에 따라 공시한다.

## Ⅱ. 특징

- 사람·환경 영향을 보는 **영향 중대성**
- 기업가치 위험·기회를 보는 **재무 중대성**
- 가치사슬 정책·행동·목표·지표의 **ESRS 공시**
- 원천·산식·승인·변경의 **공시 내부통제**
- 독립 검증을 받는 **외부 확신**
- 기계 판독을 지원하는 **디지털 태깅**

#### 한줄 요약
- 이중 중대성, ESRS, 내부통제, 외부 확신, 디지털 태깅이 핵심이다.

## Ⅲ. 구조 및 구성요소

```text
┌──────────── CSRD 공시 책임 체계 ────────────┐
│                                           │
│              [경영기구]                   │
│                  └── [공시기업]           │
│                      ├── [가치사슬]       │
│                      ├── [내부통제]       │
│                      └── [외부 검증인]    │
│              [공시 이용자]                │
└───────────────────────────────────────────┘
```

| 구성요소 | 책임 |
|:---|:---|
| **경영기구** | 공시 정책·책임·내부통제 승인 |
| **가치사슬·IRO** | 영향·위험·기회와 기초 자료 제공 |
| **이중 중대성 평가** | 공시할 중요 주제와 경계 판정 |
| **ESRS·내부통제** | 표준 보고와 데이터 증거 관리 |
| **외부 검증인** | 중대성·데이터·통제의 독립 검증 |

#### 한줄 요약
- 이중 중대성 평가가 가치사슬 자료와 ESRS 공시 사이에 끼어들어 무엇을 공시할지의 경계를 먼저 판정하므로 전 항목 보고 부담이 줄고, 내부통제와 외부 검증인이 그 판정과 데이터를 검증해 이용자가 공시를 개별 확인하던 비용을 대신한다.

## Ⅳ. 흐름도

```text
[가치사슬]
     │
     └──────── IRO·원천자료 제공
                 │
                 ▼
            [공시기업]
                 │ 1. 적용 범위·가치사슬 경계 확정
                 │ 2. IRO 식별·이중 중대성 평가
                 │ 3. ESRS 보고·내부통제 증거 작성
                 ▼
            [외부 검증인]
                 │ 4. 공시·통제 독립 검증
                 ▼
            [경영기구]
                 │ 5. 태깅·공시 범위 최종 승인
                 └──────── 공시 결과 반환
```

**동작 원리**

1. **적용 범위·가치사슬 경계 확정**: 대상 기업·연결·상하류 범위 결정
2. **IRO 식별·이중 중대성 평가**: 영향과 재무 관점의 중요도 판정
3. **ESRS 보고·내부통제 증거 작성**: 정책·행동·목표·지표 문서화
4. **공시·통제 독립 검증**: 원천·산식·승인·표본의 외부 확인
5. **태깅·공시 범위 최종 승인**: 검증 결과와 책임을 반영해 공개

#### 한줄 요약
- 중대성 판정과 ESRS 작성은 기업이 스스로 하지만 외부 검증인을 거친 뒤에야 경영기구 승인으로 넘어가므로, 원천 자료와 산식을 검증 가능한 형태로 남겨 두지 않은 항목은 공시 직전에 그 근거를 다시 만들어야 한다.

## Ⅴ. 종류 및 비교

| 비교 항목 | 지속가능성 보고 | 재무보고 |
|:---|:---|:---|
| 핵심 관점 | **영향·재무 이중 중대성** | 재무상태·성과·현금흐름 |
| 주요 범위 | 기업과 상하류 가치사슬 | 보고기업·연결재무 범위 |
| 정보 유형 | 정책·행동·목표·ESG 지표 | 자산·부채·수익·비용 |
| 검증 과제 | IRO·추정·비재무 데이터 | 인식·측정·회계 추정 |
| 주요 위험 | 그린워싱·경계·산식 왜곡 | 회계 오류·추정·누락 |

#### 한줄 요약
- 지속가능성 보고는 사람·환경 영향과 재무 위험을 함께 공시한다.

## Ⅵ. 실무 고려사항 및 대책

| 문제 | 대책 |
|:---|:---|
| 적용 대상·시점의 규정 변화 | 기준일별 **범위·일정 판정 기록** |
| 가치사슬 자료의 출처·산식 불명 | IRO별 **데이터 계보·승인 통제** |
| 중요 주제 누락·과도한 공시 | 이해관계자 증거 기반 **중대성 판정** |
| 정성 주장 중심의 그린워싱 | 목표·기준선·실적의 **검증 지표** |
| 디지털 태그와 본문 불일치 | 보고서·태그의 **자동 대조 검증** |

#### 한줄 요약
- 범위 기록, 데이터 계보, 중대성 증거, 지표, 태그 대조를 적용한다.

## Ⅶ. 결론

- 적용 범위와 이중 중대성을 판정해 **중요 IRO만 ESRS로 검증·공시**

#### 한줄 요약
- 사람·환경과 재무에 중요한 주제를 증거로 선별해 일관되게 공시한다.
