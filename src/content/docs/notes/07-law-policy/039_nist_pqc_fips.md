## Ⅰ. 개요

- 정의/개념: 양자내성 키 설정·서명을 규정한 **FIPS 203·204·205**
- 배경/필요성: 쇼어(Shor) 알고리즘을 구동하는 대규모 양자컴퓨터(Q-Day)의 출현이 가시화되면서, 현재 전 세계 인터넷 보안의 근간인 RSA, ECC, Diffie-Hellman 등 공개키 암호체계가 완전히 무력화될 위기에 직면하고, 공격자가 현재 암호화된 트래픽을 미리 수집한 뒤 미래 양자컴퓨터로 일괄 해독하는 'HNDL(Harvest Now, Decrypt Later)' 위협이 실재함에 따라, 미국 국립표준기술연구소(NIST)가 양자내성암호(PQC) 표준(FIPS 203 ML-KEM, FIPS 204 ML-DSA, FIPS 205 SLH-DSA)을 최종 확정·공식 발표하여 **양자컴퓨팅 공격에 내성을 지닌 차세대 공개키 암호 인프라 확립, 기존 프로토콜(TLS, SSH, IPsec)과의 하이브리드(Hybrid) 병행 적용 및 암호 민첩성(Crypto Agility) 기반의 체계적 국가·기업 PQC 전환 로드맵 구축**을 달성할 필요

#### 한줄 요약
- 장기 데이터와 인증 체계를 NIST PQC 표준으로 전환한다.

## Ⅱ. 특징

- ML-KEM과 대칭 암호의 **용도 분리성**
- 격자·해시 기반을 제공하는 **서명 다변성**
- 알고리즘·매개변수를 교체하는 **암호 민첩성**
- 표준 매개변수별 성능·보안의 **선택 가능성**

#### 한줄 요약
- 키 설정과 서명을 용도별 PQC 알고리즘으로 전환한다.

## Ⅲ. 구조 및 구성요소

```text
┌───────────── NIST PQC 표준 ─────────────┐
│ [FIPS 203]                              │
│ └── ML-KEM | 공유 비밀 설정             │
│ [FIPS 204]                              │
│ └── ML-DSA | 모듈 격자 기반 서명         │
│ [FIPS 205]                              │
│ └── SLH-DSA | 무상태 해시 기반 서명      │
└─────────────────────────────────────────┘
```

| 구성요소 | 책임 |
|:---|:---|
| FIPS 203 | **ML-KEM** 기반 공유 비밀 설정 |
| FIPS 204 | **ML-DSA** 기반 모듈 격자 서명 |
| FIPS 205 | **SLH-DSA** 기반 무상태 해시 서명 |

#### 한줄 요약
- ML-KEM은 키 설정, ML-DSA와 SLH-DSA는 서명을 담당한다.

## Ⅳ. 흐름도

```text
[암호 책임자]
     │ 1. 암호 자산·데이터 수명 확정
     │ 2. HNDL 위험·교체 우선순위 결정
     │ 3. 알고리즘·매개변수 선택
     │ 4. 하이브리드 구성·키 발급 지시
     ▼
[대상 시스템]
     │ 5. 키·인증서 전환 배포
     └──────── 배포 결과 반환
```

**동작 원리**

1. **암호 자산·데이터 수명 확정**: 알고리즘·키·인증서·보호기간 목록화
2. **HNDL 위험·교체 우선순위 결정**: 노출 영향과 의존성 비교
3. **알고리즘·매개변수 선택**: 크기·지연·상호운용성 검증
4. **하이브리드 구성·키 발급 지시**: 병행 적용과 롤백 조건 확정
5. **키·인증서 전환 배포**: 운영 오류를 감시하며 신뢰체계 교체

#### 한줄 요약
- HNDL 위험과 데이터 수명으로 PQC 전환 순서를 정한다.

## Ⅴ. 종류 및 비교

| NIST PQC 표준 | ML-KEM | ML-DSA | SLH-DSA |
|:---|:---|:---|:---|
| 적용 기준 | **ML-KEM** 통신•저장용 공유 비밀 | **ML-DSA** 기반 인증서•코드•문서 서명 | **SLH-DSA** 기반 격자와 다른 보안 근거의 서명 |
| 핵심 특징 | **FIPS 203** 모듈 격자 기반 키 설정 | **FIPS 204** 모듈 격자 기반 서명 | **FIPS 205** 무상태 해시 기반 서명 |
| 한계 | 키•암호문 구현 부담 | 키•서명 구현 부담 | 큰 서명과 처리량 부담 |

#### 한줄 요약
- 키 설정은 ML-KEM, 서명은 ML-DSA 또는 SLH-DSA를 적용한다.

## Ⅵ. 실무 고려사항 및 대책

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 장기 데이터의 HNDL 위험 | 데이터 수명별 **전환 우선순위** | 고위험 자산 선제 보호 |
| 키·서명 크기의 성능 부담 | 분할·지연·처리량 **성능 시험** | 운영 영향 사전 검증 |
| 기존 장비·프로토콜 비호환 | 하이브리드 기반 **상호운용성 검증** | 전환 장애 예방 |
| 교체 실패와 공급자 종속 | 암호 민첩성·하이브리드·**롤백** 설계 | 복구 가능한 전환 보장 |

#### 한줄 요약
- 하이브리드 구성의 지연·호환성을 검증한 뒤 전환한다.

## Ⅶ. 결론

- 양자컴퓨터의 공개키 암호 해독 위협(Q-Day)에 대응하여 전 세계 디지털 통신과 데이터 보안의 암호학적 패러다임을 전면 교체하는 **공식 양자내성암호 국제 표준(NIST PQC Standards: FIPS 203 ML-KEM, FIPS 204 ML-DSA, FIPS 205 SLH-DSA / Module Lattice & Stateless Hash / Crypto Agility & Hybrid PQC)의 절대적 암호 기준선**으로 확고히 자리 잡았으며, TLS 1.3, PKI 인증서, 하드웨어 보안 모듈(HSM) 및 각국 정부 전환 정책(NSM-10, K-PQC)과 결합되어 전면 상용화되는 가운데, 실무 엔터프라이즈 PQC 마이그레이션 추진 시에는 **조직 내 모든 암호 자산(알고리즘, 키 길이, 인증서)을 목록화하는 암호 자재명세서(CBOM) 구축 및 HNDL 취약 장기 보관 데이터의 전환 우선순위화, 전환 과도기 호환성을 위한 고전 암호(RSA/ECC)와 PQC(ML-KEM/ML-DSA) 간 하이브리드 키 교환·서명 적용, 프로토콜 계층 분리를 통한 암호 알고리즘 교체 용이성(Crypto Agility) 확보**를 결합하여 완벽한 양자 저항성과 비즈니스 연속성을 완성

#### 한줄 요약
- HNDL 위험과 시험 결과를 기준으로 복구 가능한 PQC 전환을 결정한다.
