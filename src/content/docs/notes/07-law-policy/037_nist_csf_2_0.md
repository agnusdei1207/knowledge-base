## Ⅰ. 개요

<details><summary>용어 설명</summary>

- **NIST CSF 2.0**: 사이버보안 성과를 기능·범주·하위범주로 표현하는 위험관리 프레임워크.
- **구현 등급**: 조직 위험관리 관행의 정형화·반복·적응 수준.

</details>

- 정의/개념: 사이버보안 성과를 경영 위험과 연결하는 **성과 기반 프레임워크**
- 배경/필요성: 전통적인 체크리스트 중심의 보안 통제 방식이 급변하는 랜섬웨어, 클라우드 위협, 공급망 공격에 수동적으로 대응하는 데 그치고, 기술적 보안 활동과 최고 경영진의 비즈니스 리스크 의사결정 간의 단절로 최적의 보안 예산 투자 우선순위를 도출하지 못하는 한계가 발생함에 따라, 미국 국립표준기술연구소(NIST)의 사이버보안 프레임워크 2.0(NIST CSF 2.0)에 기반하여 기존 5대 핵심 기능(Identify, Protect, Detect, Respond, Recover)에 전사적 위험관리 거버넌스를 총괄하는 최고위 기능인 '거버넌스(Govern)'를 신설(6대 기능)하고 공급망 사이버 위험(C-SCRM)을 대폭 강화하여 **경영진 중심의 사이버 위험 거버넌스 확립, 현재 프로파일과 목표 프로파일 간 갭(Gap) 분석 기반의 정밀한 보안 투자 최적화 및 모든 산업·규모에 적용 가능한 성과 기반 보안 생태계 구축**을 달성할 필요

#### 한줄 요약
- CSF 2.0은 경영 위험을 보안 성과·프로파일·개선 투자와 연결한다.

## Ⅱ. 특징

- 전략·책임·정책을 통합하는 **Govern 중심성**
- 기능·범주·하위범주의 **성과 계층성**
- 현재·목표 상태를 비교하는 **프로파일**
- 위험관리 성숙 관행을 보는 **구현 등급**
- 목표 격차를 투자로 바꾸는 **위험 기반 우선순위**
- 공급망 위험을 포함하는 **전사 범위**

#### 한줄 요약
- Govern, 성과 계층, 프로파일, 구현 등급, 위험 우선순위가 핵심이다.

## Ⅲ. 구조 및 구성요소

```text
┌────────────── NIST CSF 2.0 ──────────────┐
│                                         │
│              [Govern]                   │
│     ├── [Identify]                      │
│     ├── [Protect]                       │
│     ├── [Detect]                        │
│     ├── [Respond]                       │
│     └── [Recover]                       │
└─────────────────────────────────────────┘
```

| 구성요소 | 책임 |
|:---|:---|
| **Govern** | 맥락·전략·책임·정책·공급망 방향 설정 |
| **Identify** | 자산·업무·위험·개선 필요 파악 |
| **Protect** | 신원·데이터·플랫폼의 예방 통제 |
| **Detect** | 이상·침해 징후의 관찰·분석 |
| **Respond** | 사고 분석·억제·완화·소통 |
| **Recover** | 자산·서비스 복원과 개선 |

#### 한줄 요약
- Govern이 Identify·Protect·Detect·Respond·Recover를 조정한다.

## Ⅳ. 흐름도

```text
[경영진]
     │
     │ 1. 범위·위험 허용수준 확정
     ▼
[위험관리 조직]
     │ 2. 현재 프로파일·증거 작성
     │ 3. 목표 프로파일·성과 격차 분석
     │ 4. 위험·비용·의존성 우선순위화
     ▼
[경영진]
     │ 5. 목표·투자 승인과 실행 지시
     └──────── 실행 결과 반환
```

**동작 원리**

1. **범위·위험 허용수준 확정**: 임무·이해관계자·위험 한계 정의
2. **현재 프로파일·증거 작성**: 하위범주별 현재 성과 측정
3. **목표 프로파일·성과 격차 분석**: 필요한 추가 성과 식별
4. **위험·비용·의존성 우선순위화**: 개선 효과와 실행 순서 비교
5. **목표·투자 승인과 실행 지시**: 책임·기한·성과 기준 확정

#### 한줄 요약
- 위험 한도, 현재 상태, 목표 격차, 우선순위, 투자 승인으로 적용한다.

## Ⅴ. 종류 및 비교

| 비교 항목 | CSF 1.1 | CSF 2.0 |
|:---|:---|:---|
| 핵심 기능 | Identify·Protect·Detect·Respond·Recover | **Govern 포함 6개 기능** |
| 거버넌스 | 기능 밖의 연결이 상대적으로 약함 | 전략·책임·정책을 핵심 기능화 |
| 공급망 | 일부 범주 중심 | **전사 공급망 위험 강화** |
| 적용 범위 | 중요 인프라 중심 활용 | 모든 조직을 고려한 범용 지침 |
| 전환 판단 | 기존 프로파일 유지·매핑 | Govern과 목표 프로파일 재정렬 |

#### 한줄 요약
- CSF 2.0은 Govern을 추가해 경영·공급망 책임을 강화했다.

## Ⅵ. 실무 고려사항 및 대책

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 설치 여부만 확인하는 통제 목록 오용 | 임무 기반 **목표 하위범주** 선정 | 성과 중심 보안 체계 전환 |
| 현재 프로파일의 객관적 근거 부족 | 지표·기록·책임자의 **성과 증적** | 갭 분석 정확성 향상 |
| 개선 과제 간 예산·순서 충돌 | 위험 감소·비용·의존성 **우선순위** | 투자 효율 극대화 |
| 구현 등급을 목표 성과로 오해 | 등급과 프로파일의 **용도 분리** | 성숙도·성과 혼동 방지 |
| 공급망 목표의 책임자 부재 | 계약·소유자·성과의 **공급망 매핑** | C-SCRM 실행력 확보 |

#### 한줄 요약
- 목표 성과, 증적, 우선순위, 등급 분리, 공급망 책임을 적용한다.

## Ⅶ. 결론

- 사이버보안을 단순 IT 기술 부서의 운영 업무에서 최고 경영진과 이사회가 주도하는 전사 비즈니스 위험관리 거버넌스로 승격시킨 **글로벌 사이버보안 프레임워크 표준(NIST CSF 2.0 / 6 Core Functions: Govern·Identify·Protect·Detect·Respond·Recover / Profile Gap Analysis & Tiers / C-SCRM)의 최고 프레임워크**로 확고히 자리 잡았으며, ISO 27001, CIS Controls, NIST SP 800-53과의 완벽한 크로스 매핑을 제공하는 가운데, 실무 NIST CSF 2.0 적용 및 보안 체계 고도화 시에는 **조직의 위험 수용 한도(Risk Tolerance)에 맞춘 'Govern' 중심의 전사 보안 정책 및 공급망 위험 관리(C-SCRM) 역할 정의, 하위 범주(Subcategories)별 현재 상태(Current Profile)와 목표 상태(Target Profile) 간 성과 격차(Gap) 정량화, 비용 대비 위험 감소 효과에 기반한 액션 플랜 우선순위화 및 정례 구현 등급(Implementation Tiers) 진단**을 결합하여 완벽한 사이버 회복 탄력성과 투자 효율성을 완성

#### 한줄 요약
- Govern 아래 현재와 목표 성과를 비교해 위험 감소 투자를 승인한다.
