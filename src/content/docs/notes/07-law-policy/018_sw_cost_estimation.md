## Ⅰ. 개요

<details>
<summary>핵심 용어</summary>

- **소프트웨어 대가**: 사업 규모•작업량•단가•보정에 따른 적정 비용이다.
- **원가 추정 체계**: 규모•작업량과 단가•보정으로 비용을 계산한다.

</details>

- 정의/개념: **SW 대가 산정** — 규모•작업량과 단가로 적정 비용을 계산하는 **원가 추정 체계**이다.
- 배경/필요성: 투입 인원만으로는 **기능 규모•변경 가치 산정하기 어렵다**.

#### 한줄 요약

- **기능 규모•작업량**과 **단가**로 적정 예산을 산정한다.

## Ⅱ. 특징

<details>
<summary>핵심 용어</summary>

- **기능점수(FP)**: 데이터•입력•출력•조회 기능의 규모 단위이다.
- **인공지능 사업**: 데이터•학습•검증•배포•맞춤화 사업이다.
- **추적 가능성**: 기능 기준선과 규모•기간•대가 증감의 관계를 연결해 추적한다.

</details>

- **규모 기반성**: 개발 사업은 사용자가 인식하는 데이터•트랜잭션 기능을 기능점수로 측정한다.
- **추적 가능성**: 기능 기준선을 통해 요구사항 변경 전후의 규모와 대가 증감을 연결한다.
- **유형 적합성**: 기획•개발•유지관리•데이터•인공지능•클라우드의 작업 특성에 맞는 산정 방식을 선택한다.

#### 한줄 요약

- **사용자 기능 규모**와 **보정 요소**를 반영한 대가를 산정한다.

## Ⅲ. 구조 및 구성요소

<details>
<summary>핵심 용어</summary>

- **기능 규모**: 데이터•입력•출력•조회 기능의 계수 규모이다.
- **내부 논리 파일(ILF)**: 대상 시스템이 관리하는 논리 데이터이다.
- **외부 연계 파일(EIF)**: 외부 시스템이 관리하고 대상이 참조하는 데이터이다.
- **외부 입력(EI)**: 내부 데이터•상태를 변경하는 입력 기능이다.
- **외부 출력(EO)**: 계산•가공 결과를 외부에 제공하는 기능이다.
- **외부 조회(EQ)**: 내부 변경 없이 조건에 맞는 정보를 반환한다.
- **조정 계수(AF)**: 특성•복잡도를 규모•단가에 반영하는 계수이다.
</details>

```text
SW 대가
├── 사업범위
├── 기능 규모
├── 단가보정
├── 비용항목
└── 변경기준
```

| 구성요소 | 책임 |
|:---|:---|
| 사업범위 | 기획•개발•**인공지능 사업 유형** 정의 |
| 기능 규모 | 데이터•입력•출력•조회 **기능점수** 측정 |
| 단가보정 | 엔지니어 단가와 **조정 계수** 적용 |
| 비용항목 | 인건비•제경비•**기술료•이윤** 합산 |
| 변경기준 | 요구 변경의 **추가 대가** 산출 |

#### 한줄 요약

- **사업 유형•기능 규모**와 **단가 보정**의 대가를 구성한다.

## Ⅳ. 흐름도

<details>
<summary>핵심 용어</summary>

- **투입공수**: 과업을 수행하는 데 필요한 인력 수와 투입 기간을 결합한 작업량이다.
- **기능 기준선**: 승인된 기능•규모의 대가•기간 조정 기준이다.

</details>

```text
발주기관
   │ 1. 사업 유형•범위 정의
   ▼
수행기관
   │ 2. 기능 규모•작업량 산정
   │ 3. 단가•보정 기준 적용
   ▼
발주기관
   │ 4. 비용 항목 검증
   +---------------------+
   | 기능 기준선 변경 시 |
   +----------+----------+
              |
              v
   │ 5. 변경 규모•대가 검증
   ▼
수행기관
   │ 조정 대가 합의 반환
   ▼
발주기관
```

**동작 원리**

1. **사업 유형•범위 정의**: 개발•운영•데이터•인공지능의 **산정 대상•책임 범위**를 확정한다.
2. **기능 규모•작업량 산정**: **기능점수•과업별 투입공수**를 근거로 측정한다.
3. **단가•보정 기준 적용**: **단가•복잡도•품질 보정 요소**를 반영한다.
4. **비용 항목 검증**: **직접비•제경비•기술료 산식**을 확인한다.
5. **변경 규모•대가 검증**: 기준선 대비 **추가•삭제 기능**으로 대가를 조정한다.

#### 한줄 요약

- **범위•규모 측정**부터 **단가 보정•변경 검증**까지 수행한다.

## Ⅴ. 종류 및 비교

<details>
<summary>핵심 용어</summary>

- **투입공수 방식**: 직무•등급•투입 기간을 인월로 산정한다.
- **혼합 산정**: 기능은 FP, 데이터•모델 작업은 투입공수를 적용한다.

</details>

| 산정 접근 | 투입공수 방식 | 기능점수 방식 |
|:---|:---|:---|
| 적용 범위 | 연구•유지관리처럼 **기능 규모 측정이 어려운 작업** | 데이터•트랜잭션 기능이 식별되는 **개발•재구축** |
| 산정 근거 | **M/M•직무별 단가** | **FP•보정계수•단가** |
| 한계 | 인력별 **생산성 차이•투입 적정성** 검증 부담 | 시스템 경계와 **기능 식별 편차** |

- 인공지능 사업의 기능 식별 범위는 **기능점수 방식**, 데이터•모델 작업은 **투입공수 방식** 기반 **혼합 산정**이 핵심이다.

#### 한줄 요약

- **기능 규모•작업량**을 구분한 **AI 혼합 산정**이 핵심이다.

## Ⅵ. 실무 고려사항 및 대책

<details>
<summary>핵심 용어</summary>

- **주관적 식별**: 경계•기능 판정 근거 부족에 따른 FP 편차이다.
- **오차 범위**: 실제 비용이 추정값에서 벗어날 상•하한이다.

</details>

| 문제 | 대책 | 효과 |
|:---|:---|:---|
| 요구 불명확 상태의 **조기 확정 견적** | 사전•상세 산정을 구분하고 **오차 범위** 명시 | 예산 과소•과대 **산정 위험 감소** |
| 기능점수의 **주관적 식별** | 경계•기능의 판정 근거 기록과 **독립 검토** | 규모 측정의 **일관성•재현성 향상** |
| 추가 과업의 **무상 수행** | 기능 기준선과 **규모•기간•대가** 동시 조정 | 정당한 보상•**일정•품질 보호** |

#### 한줄 요약

- **산정 기준•FP 단가**에 따른 **개발비 근거** 명확화가 핵심이다.

## Ⅶ. 결론

<details>
<summary>핵심 용어</summary>

- **변경 범위**: 기준선에서 추가•삭제된 기능을 식별한 조정 대상이다.

</details>

- **기능 규모•변경 범위**로 SW 대가를 조정한다.

#### 한줄 요약

- **기능 규모•변경 범위**에 맞춰 대가•기간 동시를 조정한다.
