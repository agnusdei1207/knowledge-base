# 최신 기술 확장 1,000

## 목적

- 2024~2026 기출과 차기 출제 가능성이 높은 최신 기술군을 별도 관리
- 전통 과목 암기와 분리해 `갱신 빈도 높은 영역`만 빠르게 회독

## 우선 영역

| 영역 | 핵심 주제 |
|:---|:---|
| AI/에이전트 | LLM(Large Language Model), RAG(Retrieval-Augmented Generation), MCP(Model Context Protocol), Agentic AI |
| 클라우드 | 소버린 클라우드, 플랫폼 엔지니어링, 쿠버네티스 운영, 서비스 메시 |
| 보안 | 제로 트러스트(Zero Trust), SBOM(Software Bill of Materials), CTEM(Continuous Threat Exposure Management), AI 보안 |
| 네트워크 | 5G/6G, MEC(Multi-access Edge Computing), O-RAN(Open Radio Access Network), SRv6 |
| 데이터 | 레이크하우스, 데이터 메시, 실시간 스트리밍, 벡터 데이터베이스 |
| DevOps/SRE | GitOps, OpenTelemetry, 관측성, 지속적 배포(Continuous Deployment) |

## 사용 원칙

1. 코어 2,000개를 완전히 대체하지 않습니다.
2. 차기 회차 서술형 선택 추천 후보를 만드는 용도입니다.
3. 최신 기술은 정의보다 `도입 배경-구조-장단점-실무 적용` 순서로 봅니다.
