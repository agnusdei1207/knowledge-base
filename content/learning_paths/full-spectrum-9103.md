# 전 범위 학습 9,103

## 목적

- 16과목 전체를 장기적으로 체계화하는 지식 포털
- 컴퓨터시스템응용기술사뿐 아니라 정보통신기술사, 확장 교양, 융합 주제까지 포괄
- 전자기학·통신·블록체인·빅데이터·감리·EA까지 넓게 커버

## 판단

- **장점**: 누락 없는 백과형 축적
- **한계**: 실전 시험 직전 학습 범위로는 과도
- **결론**: 전 범위는 유지하되, 시험 직결 학습은 별도 트랙으로 분리

```text
[전 범위 9,103]
   ├─ 기초 원리
   ├─ 제도/관리
   ├─ 통신/융합
   └─ 최신 기술 확장
```

## 권장 사용법

1. 과목 전체 구조를 파악할 때 사용
2. 모르는 개념의 상위/하위 맥락을 찾을 때 사용
3. 시험 직전 암기용이 아니라 장기 회독용으로 사용
