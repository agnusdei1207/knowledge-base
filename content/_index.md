# Study Hub

개인 CS 공부 자료와 컴퓨터시스템응용기술사(CSPE) 시험 준비 자료를 분리해 관리합니다.

```text
[개인 CS 공부]
   └─ CS 16과목 학습 노트 (개인 회독용 9,103 키워드)

[CSPE 시험 준비]
   ├─ CSPE 키워드 노트 (공식 8대영역·암기용+답안용)
   ├─ 실전 문서 (전략·기출·빈도)
   └─ 답안 템플릿 (Ⅰ~Ⅴ·문제유형 전환)
```

## 바로가기

| 구분 | 용도 | 링크 |
|:---|:---|:---|
| 개인 CS 공부 | CS 16과목 9,103 키워드 보관 | [CS 16과목 학습 노트](studynote/) |
| CSPE 키워드 공부 | 공식 8대영역별 암기용+답안용 노트 | [CSPE 키워드 노트](cspe/) |
| CSPE 실전 문서 | 전략·기출·빈도·모범답안·템플릿 | [실전 문서](exam/cs/) |
| 통합 학습 전략 | 기출 분석·회독 순서·타임라인 | [통합 학습 전략](exam/cs/integrated-strategy/) |
| 답안 템플릿 | Ⅰ~Ⅴ 정본 골격, 문제 유형별 치환 | [모범답안 템플릿](exam/cs/model-answer/) |

## 운영 원칙

1. `studynote/`는 개인 CS 16과목 회독 자료입니다.
2. `cspe/`는 컴퓨터시스템응용기술사 공식 8대영역 키워드 답안 노트입니다.
3. `exam/cs/`는 CSPE 전략·기출·빈도·답안 작성법만 둡니다.
4. CSPE 답안은 추상 표현 없이 수치·표준·기술명으로 작성합니다.
