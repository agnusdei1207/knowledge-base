# 컴퓨터시스템응용기술사 준비 허브

컴퓨터시스템응용기술사(CSPE) 합격에 필요한 전략·기출·답안 템플릿·핵심 키워드를 한곳에 모았습니다.

```text
[CSPE 준비]
   ├─ 통합 학습 전략 (기출 분석·과목 교차·타임라인)
   ├─ 답안 템플릿 (Ⅰ~Ⅴ·추상표현 금지·문제유형 전환)
   ├─ 기출 분석 (120~138회·빈도)
   └─ 핵심 키워드 (과목별 압축)
```

## 바로가기

| 구분 | 용도 | 링크 |
|:---|:---|:---|
| 통합 학습 전략 | 기출 분석·과목 교차·1000 키워드 기준·타임라인 | [통합 학습 전략](exam/cs/integrated-strategy/) |
| 시험 준비 전체 | 전략·기출·빈도·모범답안·템플릿 | [시험 준비](exam/) |
| 답안 템플릿 | Ⅰ~Ⅴ 정본 골격, 문제 유형별 치환 | [모범답안 템플릿](exam/cs/model-answer/) |
| 핵심 키워드 | 과목별 압축 키워드 세트 | [핵심 키워드](exam/cs/keyword_list/) |

## 운영 원칙

1. 이 사이트는 **컴퓨터시스템응용기술사 합격**에 집중합니다. (정보통신기술사는 약 3년 후 별도 준비)
2. 답안은 추상 표현 없이 수치·표준·기술명으로 작성합니다.
3. 키워드는 암기용(개념 완전 이해) + 답안용(시험 템플릿) 2블록으로 관리합니다.
4. CS 기초 학습 노트(`studynote/`)는 재작성 작업 중 임시 보관(숨김) 상태입니다.
