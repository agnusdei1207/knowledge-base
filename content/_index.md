# 컴퓨터시스템응용기술사 준비 허브

컴퓨터시스템응용기술사(CSPE) 합격에 필요한 전략·기출·답안 템플릿·핵심 키워드를 한곳에 모았습니다.

```text
[CSPE 준비]
   ├─ 키워드 노트 (공식 8대영역·암기용+답안용)
   ├─ CS 16과목 학습 노트 (개인 회독용 9,103 키워드)
   ├─ 통합 학습 전략 (기출 분석·회독 순서·타임라인)
   ├─ 답안 템플릿 (Ⅰ~Ⅴ·추상표현 금지·문제유형 전환)
   └─ 기출 분석 (120~138회·빈도)
```

## 바로가기

| 구분 | 용도 | 링크 |
|:---|:---|:---|
| 키워드 공부 본편 | 공식 8대영역별 암기용+답안용 노트 | [CSPE 키워드 노트](cspe/) |
| 개인 회독 자료 | CS 16과목 9,103 키워드 보관 | [CS 16과목 학습 노트](studynote/) |
| 실전 문서 | 전략·기출·빈도·모범답안·템플릿 | [실전 문서](exam/cs/) |
| 통합 학습 전략 | 기출 분석·회독 순서·타임라인 | [통합 학습 전략](exam/cs/integrated-strategy/) |
| 답안 템플릿 | Ⅰ~Ⅴ 정본 골격, 문제 유형별 치환 | [모범답안 템플릿](exam/cs/model-answer/) |

## 운영 원칙

1. 이 사이트는 **컴퓨터시스템응용기술사 합격**에 집중합니다.
2. 답안은 추상 표현 없이 수치·표준·기술명으로 작성합니다.
3. 키워드는 암기용(개념 완전 이해) + 답안용(시험 템플릿) 2블록으로 관리합니다.
4. 키워드 노트(`cspe/`)는 공식 8개 대영역 기준으로 출제 동향에서 추출해 작성합니다.
