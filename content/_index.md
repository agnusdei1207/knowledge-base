# 기술사 학습 허브

9,103개 전체 학습 노트와 실전 시험용 핵심 트랙을 분리해 관리합니다.

```text
[Study Hub]
   ├─ [전 범위 학습 9,103]
   ├─ [컴퓨터시스템응용기술사 핵심 트랙]
   └─ [시험 답안/기출 분석]
```

## 바로가기

| 구분 | 용도 | 링크 |
|:---|:---|:---|
| 전 범위 학습 | 16과목 전체 지식 체계 탐색 | [Study Note 전체 인덱스](studynote/) |
| 핵심 트랙 | 컴퓨터시스템응용기술사 중심 3천개 내외 압축 학습 | [학습 경로 허브](learning_paths/) |
| 시험 실전 | 기출, 빈도, 모범답안, 전략 | [시험 준비](exam/) |

## 운영 원칙

1. `studynote/`는 전 범위 지식 저장소로 유지합니다.
2. `learning_paths/`는 시험 합격용 압축 경로만 다룹니다.
3. `exam/`은 교시별 답안과 기출 분석에 집중합니다.
