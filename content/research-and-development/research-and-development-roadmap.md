## Q3 우선 검증

### 1. 검색 품질 베이스라인 수립

- 목표: 현재 문서 100건 기준 기본 검색 성능 측정
- 항목:
  - 키워드 검색 정확도
  - 링크 기반 탐색성
  - 문서 최신성 반영 여부
- 산출물:
  - 질의셋 20개
  - 베이스라인 리포트

### 2. AI 문서 요약 파이프라인

- 목표: 긴 회의록을 `inbox` 스타일의 짧은 구조 문서로 자동 전환
- 항목:
  - 섹션 분리
  - 액션 아이템 추출
  - 관련 문서 자동 링크 제안
- 산출물:
  - 요약 프롬프트 초안
  - 사람 검수 기준

### 3. 링크 자동 생성 보조

- 목표: 새 문서를 쓸 때 기존 문서와 연결 후보를 제안
- 항목:
  - 제목 기반 후보
  - 본문 유사도 기반 후보
  - 태그/주제 기반 후보
- 산출물:
  - 후보 추천 규칙
  - 실험 로그 문서

## Q4 확장 검토

### 1. 부서별 문서 템플릿

- 사업 템플릿
- 기술 검토 템플릿
- 운영 회고 템플릿

### 2. 문서 승인 흐름

- AI 초안 작성
- 담당자 검토
- 메인 문서 반영

### 3. 검색 로그 기반 개선

- 어떤 문서를 자주 찾는지
- 검색 실패가 어디서 나는지
- 누락된 허브 문서가 무엇인지 분석

## 성공 기준

- 문서를 찾는 시간이 줄어든다
- 새 문서가 기존 문서와 자연스럽게 연결된다
- AI가 만든 초안의 수정 비용이 줄어든다
- 사업 문서와 기술 문서가 분리되지 않고 이어진다
