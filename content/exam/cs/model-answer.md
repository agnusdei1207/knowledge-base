## 사용 원칙

- 첫 줄 1문장 정의
- 5초 안에 구조가 보이도록 `정의 → 구조/원리 → 비교/절차 → 결론`
- 1교시는 6~8줄, 2~4교시는 `Ⅰ~Ⅴ` 고정
- 약어는 최초 1회 풀네임 병기

---

## 1교시 단답형 템플릿

````markdown
### [키워드]

- **정의**: [개념의 본질 1문장]
- **핵심 1**: [구성요소/원리]
- **핵심 2**: [장점/효과]
- **핵심 3**: [한계/유의점/비교 포인트]

```text
[입력/요구]
   ↓
[핵심 메커니즘]
   ↓
[효과/결과]
```

- **적용/출제 포인트**: [실무 또는 비교 대상]
````

### 1교시 빠른 변형 규칙

| 유형 | 답안 포인트 |
|:---|:---|
| 정의형 | 정의 1줄 + 특징 3개 |
| 비교형 | 공통점 1개 + 차이점 3개 |
| 구조형 | 구성요소 3개 + 흐름도 |
| 장단점형 | 장점 2개 + 단점 1개 + 적용처 |

## 2~4교시 서술형 템플릿

````markdown
## [문제명]

### Ⅰ. 개요
- **정의**: [핵심 개념 1문장]
- **필요성**: [배경 2~3개]

### Ⅱ. 구조 및 동작 원리
```text
[입력/사용자]
   ↓
[핵심 구성 A] → [핵심 구성 B] → [핵심 구성 C]
   ↓
[통제/모니터링]
```
- 구성요소 1
- 구성요소 2
- 구성요소 3

### Ⅲ. 핵심 특징
| 구분 | 내용 | 판단 포인트 |
|:---|:---|:---|
| 구조 |  |  |
| 장점 |  |  |
| 한계 |  |  |

### Ⅳ. 비교/적용/대응 방안
- 방안 1
- 방안 2
- 방안 3

### Ⅴ. 결론
- 실무 적용 시사점
- 향후 발전 방향
````

### 서술형 문항 유형별 치환 규칙

| 문제 표현 | Ⅲ에서 강조 | Ⅳ에서 강조 |
|:---|:---|:---|
| 설명하시오 | 구성요소, 원리 | 적용 사례 |
| 비교하시오 | 표 중심 차이점 | 선택 기준 |
| 방안을 제시하시오 | 문제 원인 | 단계별 개선안 |
| 설계하시오 | 아키텍처 | 구성 기준, 운영 절차 |
| 문제점과 대책 | 리스크 | 원인-대책 매핑 |

## 2~4교시 필수 확장 체크

| 항목 | 확인 기준 |
|:---|:---|
| Ⅰ 개요 | 1교시 정의가 첫 줄에 들어갔는가 |
| Ⅱ 구조 | 구성도 또는 흐름도가 있는가 |
| Ⅲ 비교 | 비교표/특징표가 있는가 |
| Ⅳ 적용 | 단계별 방안 또는 리스크 대응이 있는가 |
| Ⅴ 결론 | 조건별 선택 기준으로 끝나는가 |

---

## 답안 압축 체크리스트

- 정의가 첫 줄에 있는가
- 도해가 1개 이상 있는가
- 서술형은 표가 1개 이상 있는가
- 비교 문제는 선택 기준이 있는가
- 결론이 기술사적 판단으로 끝나는가
