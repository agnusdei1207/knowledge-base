## 사용 원칙

- 첫 줄 1문장 정의
- 5초 안에 구조가 보이도록 `정의 → 구조/원리 → 비교/절차 → 결론`
- 1교시는 `정의 + 핵심 3포인트 + 미니 도식 + 적용 1줄` 기준으로 `2/3~1쪽`, 2~4교시는 `Ⅰ~Ⅴ` 고정
- 2~4교시는 1교시 답안을 따로 붙이는 것이 아니라, Ⅰ·Ⅱ 안에 1교시 요소를 포함한 확장형으로 작성
- 약어는 최초 1회 풀네임 병기

---

## 1교시 단답형 템플릿

````markdown
### [키워드]

- **정의**: [개념의 본질 1문장]
- **핵심 1**: [구성요소/원리]
- **핵심 2**: [장점/효과]
- **핵심 3**: [한계/유의점/비교 포인트]
- **미니 구조**: [입력/요구] → [핵심 메커니즘] → [효과/결과]

- **적용/출제 포인트**: [실무 또는 비교 대상]
````

### 1교시 빠른 변형 규칙

| 유형 | 답안 포인트 | 미니 도식 |
|:---|:---|:---|
| 정의형 | 정의 1줄 + 특징 3개 | `입력 → 처리 → 효과` 3칸 |
| 비교형 | 공통점 1개 + 차이점 3개 | `A vs B` 2칸 비교 |
| 구조형 | 구성요소 3개 + 흐름도 | `구성 A → 구성 B → 구성 C` |
| 장단점형 | 장점 2개 + 단점 1개 + 적용처 | `장점 / 한계 / 적용` 3칸 |

---

## 2~4교시 서술형 템플릿

2~4교시 템플릿은 1교시 템플릿의 확장형이다. Ⅰ. 개요에서 정의와 필요성을 제시하고, Ⅱ. 구성요소에서 1교시 핵심 요소 3개를 역할·원리·검증 기준까지 확장한다.
구조도는 `Ⅰ. 개요` 직후 바로 뼈대를 잡고, 손답안에서는 **박스 3~5개 + 화살표** 수준으로 10~15초 안에 먼저 그린 뒤 세부 문장을 채운다.

````markdown
## [문제명]

### Ⅰ. 개요
- **정의**: [핵심 개념 1문장]
- **필요성**: [배경 2~3개]
- **1교시 포함 요소**: [정의, 핵심요소, 장점·한계, 적용 포인트]

### Ⅱ. 구조·동작원리
| 단계 | 구성요소 | 역할 | 산출물 | 검증 기준 |
|:---:|:---|:---|:---|:---|
| 1 | 입력/요구 |  |  |  |
| 2 | 핵심 구성 A |  |  |  |
| 3 | 핵심 구성 B |  |  |  |
| 4 | 통제/모니터링 |  |  |  |

### Ⅲ. 핵심특징·비교
| 구분 | 내용 | 판단 포인트 |
|:---|:---|:---|
| 구조 |  |  |
| 장점 |  |  |
| 한계 |  |  |

### Ⅳ. 적용방안·리스크
1. 단기: [현황 진단, PoC, 표준 수립]
2. 중기: [아키텍처 전환, 자동화, 거버넌스]
3. 장기: [운영 고도화, 지표 관리, 지속 개선]

| 리스크 | 원인 | 대응 | 기대효과 |
|:---|:---|:---|:---|
|  |  |  |  |
|  |  |  |  |

### Ⅴ. 결론
- 기술사적 판단: [조건별 선택 기준]
- 기술사 제언: [실무 적용 시사점 1줄]
- 향후 발전 방향
````

### 서술형 문항 유형별 치환 규칙

| 문제 표현 | Ⅲ에서 강조 | Ⅳ에서 강조 |
|:---|:---|:---|
| 설명하시오 | 구성요소, 원리 | 적용 사례 |
| 비교하시오 | 표 중심 차이점 | 선택 기준 |
| 방안을 제시하시오 | 문제 원인 | 단계별 개선안 |
| 설계하시오 | 아키텍처 | 구성 기준, 운영 절차 |
| 문제점과 대책 | 리스크 | 원인-대책 매핑 |

## 구조도 예시

다음 형태를 손으로 먼저 그린 뒤, 각 박스 아래에 핵심 키워드 1~2개만 덧붙인다.

```text
┌──────────┐   ┌──────────┐   ┌──────────┐
│ 입력/요구 │──▶│ 핵심 처리 │──▶│ 효과/성과 │
└──────────┘   └──────────┘   └──────────┘
```

16과목별 확장 포인트는 [컴퓨터시스템응용기술사 2~4교시 통합 답안 템플릿](@/exam/cs/master-template.md)의 `Ⅲ. 16과목 적용 포인트`를 따른다.

## 2~4교시 필수 확장 체크

| 항목 | 확인 기준 |
|:---|:---|
| Ⅰ 개요 | 1교시 정의가 첫 줄에 들어갔는가 |
| Ⅱ 구조 | 구성도 또는 흐름도가 있는가 |
| Ⅲ 비교 | 비교표/특징표가 있는가 |
| Ⅳ 적용 | 단계별 방안 또는 리스크 대응이 있는가 |
| Ⅴ 결론 | 조건별 선택 기준으로 끝나는가 |

---

## 답안 압축 체크리스트

- 정의가 첫 줄에 있는가
- 도해가 1개 이상 있는가
- 서술형은 표가 1개 이상 있는가
- 비교 문제는 선택 기준이 있는가
- 결론에 기술사 제언 또는 본인 의견 한 줄이 있는가
- 결론이 기술사적 판단으로 끝나는가
