## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 네트워크는 계층별 연결성·신뢰성·보안을 동시에 설계하는 통합 과목으로, 제어 평면(Control Plane)과 데이터 평면(Data Plane) 분리 시각이 핵심이다.
> 2. **가치**: 라우팅·전송 제어·QoS·보안·데이터센터를 묶어 설명할 수 있어야 대형 서술형 6중4 문제 대응력이 생긴다.
> 3. **판단 포인트**: TCP vs UDP, IPv4 vs IPv6, SDN/NFV, 제로 트러스트(Zero Trust), 5세대 이동통신(5G) 이후 구조를 연결하는 비교형 시각이 채점에 직결된다.

## Ⅰ. 과목 개요

- 총 노트 수: `1120`
- 추천 핵심 키워드 목표 수: `300개` (마스터 템플릿 배분 기준)
- 우선 학습 챕터: `06_network_layer_ip`, `07_network_layer_routing`, `08_transport_layer`, `13_network_security_basics`, `14_network_security_threats`, `16_data_center_cloud`, `17_sdn_nfv`, `20_performance_evaluation_advanced`
- 출제 경향: 프로토콜 단순 암기보다 **계층 위치 → 동작 원리 → 장애/위협 → 설계 대안 → 적용 사례** 순서로 풀어야 고득점. 클라우드·데이터센터·이동통신과 연계 출제가 쉽다.

## Ⅱ. 1교시 단답형 핵심 (앞단위)

> 1교시: 13중10 각 10점, 문항당 ~10분. **정의 1문장 + 핵심 3포인트 + 도해/미니표** 고정. 약어는 최초 1회 풀네임 병기.

| 키워드 | 한줄 정의 | 핵심 3포인트 |
|:---|:---|:---|
| OSI 7계층 / TCP/IP 4계층 | 통신 기능을 계층화한 표준 참조 모델 | ① 캡슐화·역다중화 ② OSI=개념/표준, TCP/IP=구현 ③ 계층별 PDU(비트·프레임·패킷·세그먼트) |
| TCP (Transmission Control Protocol) | 연결지향·신뢰성·스트림 기반 전송 프로토콜 | ① 3-Way Handshake/4-Way 종료 ② 흐름·혼잡 제어(슬라이딩 윈도우) ③ 순서보장·재전송 |
| UDP (User Datagram Protocol) | 비연결·비신뢰·메시지 기반 고속 전송 | ① 8바이트 헤더 최소 오버헤드 ② 브로드캐스트/멀티캐스트 가능 ③ VoIP·DNS·스트리밍 |
| 3-Way Handshake | TCP 연결 설정 3단계 절차 | ① SYN→SYN/ACK→ACK ② ISN 무작위(보안) ③ SYN Flooding 취약 |
| 혼잡 제어 (Congestion Control) | 망 과부하를 막는 송신측 윈도우 조절 | ① 슬로우 스타트(지수)→혼잡 회피(AIMD) ② 빠른 재전송/회복(3 Dup-ACK) ③ CUBIC·BBR |
| 서브네팅 / CIDR | IP 주소를 가변 길이로 분할·요약하는 기법 | ① VLSM 가변 마스크 ② 슈퍼네팅=경로 요약 ③ 주소 고갈 완화 |
| NAT (Network Address Translation) | 사설↔공인 IP 변환 기술 | ① Static/Dynamic/PAT(1:N) ② IPv4 고갈 대응 ③ STUN/TURN로 NAT 횡단 |
| IPv6 | 128비트 차세대 인터넷 프로토콜 | ① 40바이트 고정 헤더(체크섬·단편화 제거) ② SLAAC 자동설정·NDP ③ 듀얼스택/터널/NAT64 전환 |
| ARP (Address Resolution Protocol) | IP(논리)→MAC(물리) 주소 변환 | ① 요청=브로드캐스트, 응답=유니캐스트 ② ARP 캐시 ③ ARP 스푸핑 위협 |
| OSPF (Open Shortest Path First) | 링크 상태 기반 IGP 라우팅 프로토콜 | ① 다익스트라 SPF ② Area 계층·DR/BDR ③ 빠른 수렴·VLSM 지원 |
| BGP (Border Gateway Protocol) | AS 간 경로 벡터 인터넷 백본 라우팅 | ① AS_PATH·LOCAL_PREF·MED 속성 ② iBGP/eBGP ③ Route Reflector |
| MPLS (Multiprotocol Label Switching) | 20비트 라벨 기반 고속 스위칭 | ① LER/LSR, LDP ② IP 조회 없이 라벨 교환 ③ L3 VPN·TE |
| VLAN / 802.1Q | 스위치를 논리적으로 분할하는 가상 LAN | ① 브로드캐스트 도메인 분리 ② 4바이트 태그(VID) ③ Access/Trunk 포트 |
| STP (Spanning Tree Protocol) | L2 루프·브로드캐스트 스톰 방지 | ① 루트 브리지/RP/DP ② BPDU 교환 ③ RSTP(802.1w) 1~2초 수렴 |
| QUIC | UDP 기반 멀티플렉싱 전송 프로토콜 | ① TLS 1.3 내장·0-RTT ② HOL 블로킹 해소 ③ 연결 마이그레이션(HTTP/3) |
| SDN (Software Defined Networking) | 제어/데이터 평면 분리 네트워크 구조 | ① 중앙 컨트롤러·OpenFlow ② 프로그래머블 ③ NFV와 결합 |
| QoS (Quality of Service) | 트래픽 품질 차등 보장 기술 | ① IntServ(RSVP) vs DiffServ(DSCP) ② 큐잉·쉐이핑/폴리싱 ③ 지연·지터·손실 관리 |
| IPSec (IP Security) | IP 계층 보안 프레임워크 | ① AH(무결성)·ESP(기밀성) ② IKE/SA 키교환 ③ 터널/트랜스포트 모드 |

```text
[1교시 답안 공식] 정의(1문장) → 핵심 3포인트 → ASCII 도해 3줄 → 미니표(목적/강점/한계 3행) → 적용·비교 1줄
```

## Ⅲ. 2~4교시 서술형 확장 (심화)

> 2~4교시: 각 교시 6중4, 각 25점, 문항당 ~22~24분, 3~3.5쪽. 구조: **Ⅰ개요 → Ⅱ구조/원리 → Ⅲ특징/비교 → Ⅳ적용/방안 → Ⅴ결론**

### 1) TCP vs UDP 전송 제어 (신뢰성 vs 실시간성)

- **정의**: TCP는 연결지향 신뢰성 스트림 전송, UDP는 비연결 비신뢰 고속 메시지 전송 프로토콜.
- **Ⅰ개요**: 종단 간(End-to-End) 오류·흐름·혼잡 제어와 다중화 요구 → 두 모델 등장 배경.
- **Ⅱ구조/원리**: TCP 세그먼트(20~60B) 헤더, 3-Way Handshake, 슬라이딩 윈도우, 혼잡 제어(슬로우 스타트→AIMD).
- **Ⅲ특징/비교**: 아래 비교표.
- **Ⅳ적용/방안**: 금융·파일전송=TCP, 실시간 영상/게임=UDP+RTP, 혼합 요구=QUIC.
- **Ⅴ결론**: 신뢰성·지연 트레이드오프를 서비스 SLA 기준으로 선택.

```text
[응용 데이터]
   ↓ 세그먼트화
[TCP: SYN→SYN/ACK→ACK | UDP: 즉시 전송]
   ↓
[IP 패킷] → [네트워크]
```

| 구분 | TCP | UDP |
|:---|:---|:---|
| 연결 방식 | 연결지향(핸드셰이크) | 비연결 |
| 신뢰성 | 순서보장·재전송·ACK | 보장 없음 |
| 제어 | 흐름·혼잡 제어 | 없음 |
| 헤더 | 20~60바이트 | 8바이트 |
| 전송 형태 | 스트림(1:1) | 메시지(1:1/1:N) |
| 적용 | HTTP·메일·파일 | VoIP·DNS·스트리밍 |

### 2) IPv4 vs IPv6 전환 전략

- **정의**: IPv6는 IPv4 주소 고갈·헤더 비효율을 해소한 128비트 차세대 프로토콜.
- **Ⅰ개요**: 32비트(약 43억) 고갈, NAT 한계, 자동설정·보안 내장 요구.
- **Ⅱ구조/원리**: 40바이트 고정 헤더, Flow Label, SLAAC/NDP, 애니캐스트.
- **Ⅲ특징/비교**: 비교표.
- **Ⅳ적용/방안**: 듀얼 스택(권장)→터널링(6to4/ISATAP)→주소 변환(NAT64/DNS64) 단계적 전환.
- **Ⅴ결론**: 단순 주소 확장이 아닌 운영·보안 정책 동반 전환.

| 구분 | IPv4 | IPv6 |
|:---|:---|:---|
| 주소 길이 | 32비트 | 128비트 |
| 헤더 | 20~60바이트 가변 | 40바이트 고정 |
| 체크섬/단편화 | 헤더 포함 | 제거(상위/송신측) |
| 주소 자동설정 | DHCP | SLAAC+NDP |
| 보안 | 선택(IPSec) | 설계 내장 |
| 주소 유형 | 유니/멀티/브로드캐스트 | 유니/멀티/애니캐스트 |

### 3) SDN / NFV 기반 네트워크 가상화

- **정의**: SDN은 제어/데이터 평면을 분리해 중앙 제어하는 구조, NFV는 네트워크 기능을 소프트웨어(VNF)로 가상화하는 기술.
- **Ⅰ개요**: 하드웨어 종속·수동 운영 한계, 클라우드·데이터센터 자동화 요구.
- **Ⅱ구조/원리**: 애플리케이션 계층(노스바운드 API)–제어 계층(컨트롤러/OpenFlow)–인프라 계층(스위치).
- **Ⅲ특징/비교**: 아래 비교표.
- **Ⅳ적용/방안**: 데이터센터 EVPN-VXLAN, 통신사 NFV 코어, SD-WAN, 의도 기반 네트워킹(IBN).
- **Ⅴ결론**: SDN+NFV는 5G·클라우드 네이티브 인프라의 자동화·탄력성 기반.

```text
┌──────────────────────────────┐
│  애플리케이션 (오케스트레이션)  │  ← 노스바운드 API
├──────────────────────────────┤
│  제어 평면 (SDN 컨트롤러)       │  ← OpenFlow(사우스바운드)
├──────────────────────────────┤
│  인프라 평면 (스위치/VNF)       │
└──────────────────────────────┘
```

| 구분 | SDN | NFV |
|:---|:---|:---|
| 핵심 | 제어/데이터 평면 분리 | 네트워크 기능 SW화 |
| 표준 | ONF·OpenFlow | ETSI NFV |
| 대상 | 트래픽 경로 제어 | 방화벽·LB·라우터 등 기능 |
| 위치 | 컨트롤러 중심 | 범용 서버(VNF/CNF) |
| 효과 | 프로그래머블·중앙제어 | CapEx 절감·탄력 확장 |

### 4) 라우팅 프로토콜 (거리 벡터 vs 링크 상태 vs 경로 벡터)

- **정의**: 동적 라우팅은 라우터 간 정보 교환으로 최적 경로(Best Path)를 자동 산출하는 기술.
- **Ⅰ개요**: 망 규모 확대·장애 우회 자동화 요구, AS 내부(IGP)·외부(EGP) 구분.
- **Ⅱ구조/원리**: RIP(벨만-포드), OSPF(다익스트라 SPF), BGP(AS_PATH 경로 벡터).
- **Ⅲ특징/비교**: 비교표.
- **Ⅳ적용/방안**: 소규모=RIP, 엔터프라이즈 IGP=OSPF/EIGRP, 통신사 백본=IS-IS, AS 간=BGP.
- **Ⅴ결론**: 수렴 속도·확장성·정책 제어 요구에 따라 계층적으로 조합.

| 구분 | 거리 벡터(RIP) | 링크 상태(OSPF) | 경로 벡터(BGP) |
|:---|:---|:---|:---|
| 알고리즘 | 벨만-포드 | 다익스트라 SPF | 정책·AS_PATH |
| 메트릭 | 홉 카운트(≤15) | 비용(대역폭) | 속성 기반 |
| 수렴 | 느림(루핑 위험) | 빠름 | 느리나 안정 |
| 범위 | 소규모 IGP | 중대형 IGP | AS 간 EGP |
| 루프 방지 | 스플릿 호라이즌 | SPF 트리 | AS_PATH 검사 |

### 5) 제로 트러스트 / 네트워크 보안 (IPSec·VPN·SASE)

- **정의**: 제로 트러스트는 "절대 신뢰하지 않고 항상 검증"하는 보안 모델, IPSec/VPN은 구간 암호화 터널 기술.
- **Ⅰ개요**: 경계 보안 한계, 원격근무·클라우드 확산 → 신원 기반 통제 필요.
- **Ⅱ구조/원리**: IPSec(AH 무결성/ESP 기밀성/IKE 키교환), ZTNA 정책 엔진(PEP/PDP), 마이크로세그멘테이션.
- **Ⅲ특징/비교**: 경계 보안 vs 제로 트러스트.
- **Ⅳ적용/방안**: SASE(보안 서비스 에지)로 SD-WAN+ZTNA+SWG+CASB 통합, 최소권한·지속검증.
- **Ⅴ결론**: 네트워크·신원·데이터 통제를 통합하는 클라우드 시대 표준 보안 아키텍처.

| 구분 | 경계 보안(전통) | 제로 트러스트 |
|:---|:---|:---|
| 신뢰 전제 | 내부=신뢰 | 항상 검증 |
| 통제 단위 | 네트워크 경계 | 신원·세션·자원 |
| 분할 | VLAN/방화벽 | 마이크로세그멘테이션 |
| 접근 | VPN 광범위 허용 | ZTNA 최소권한 |
| 한계 | 횡적 이동 취약 | 구현 복잡·정책 부담 |

## Ⅳ. 출제 포인트 & 함정

| 출제유형 | 1교시 단답 포인트 | 2~4교시 서술 포인트 |
|:---|:---|:---|
| 전송 제어 | TCP 3-Way, 혼잡 제어 단계, UDP 특징 | TCP vs UDP 비교 + 혼잡 제어(슬로우 스타트→AIMD→빠른 회복) 전개 |
| IP/주소 | 서브넷 마스크 계산, NAT 유형, IPv6 헤더 | IPv4→IPv6 전환(듀얼스택/터널/NAT64) 단계 방안 |
| 라우팅 | OSPF/BGP 메트릭·속성, AD 우선순위 | IGP vs EGP, 거리벡터 vs 링크상태 비교 설계 |
| L2 스위칭 | VLAN 태그, STP 포트 역할, RSTP 수렴 | VLAN+STP+LACP 데이터센터 L2 설계 |
| 보안 | IPSec AH/ESP, ZTNA, ARP 스푸핑 | 제로 트러스트/SASE 구조 + 위협-대응표 |
| 신기술 | SDN 평면 분리, QUIC, MPLS 라벨 | SDN/NFV·5G·EVPN-VXLAN 데이터센터 자동화 |

**자주 틀리는 함정**

- TCP **흐름 제어(수신측 버퍼)** 와 **혼잡 제어(망 관점)** 혼동 → 별개 메커니즘으로 구분.
- IPv6는 헤더 **체크섬·단편화를 제거**(상위 계층/송신측 PMTU 처리). "체크섬 강화"로 쓰면 오답.
- NAT는 보안 기능이 아니라 **주소 변환**; 보안은 방화벽·ZTNA가 담당.
- STP 수렴(802.1D 30~50초) vs RSTP(802.1w 1~2초) 수치 혼동 주의.
- SDN(평면 분리)과 NFV(기능 가상화)는 **다른 개념** — 묶어서 뭉뚱그리면 감점.
- QUIC는 **UDP 상위**에서 동작(TCP 아님), TLS 1.3 내장 — "TCP 개선"으로 쓰면 오답.

## Ⅴ. 최신 기술 동향 + 공부 노트 연결

- **보안**: 제로 트러스트 네트워크 액세스(ZTNA), 보안 서비스 에지(SASE), 마이크로세그멘테이션, 양자내성암호(PQC) 전환
- **데이터센터**: 이더넷 가상 사설망(EVPN-VXLAN), 스파인-리프(Spine-Leaf), 스마트NIC/DPU, eBPF 패킷 가시화
- **운영 자동화**: 의도 기반 네트워킹(IBN), 스트리밍 텔레메트리, SD-WAN, 네트워크 디지털 트윈
- **차세대 통신**: 5G/6G, O-RAN, 시간 민감형 네트워킹(TSN), 양자 키 분배(QKD), 테라헤르츠(THz) 대역
- **전송/웹**: QUIC·HTTP/3, MPTCP, BBR 혼잡 제어, gRPC·서비스 메시
