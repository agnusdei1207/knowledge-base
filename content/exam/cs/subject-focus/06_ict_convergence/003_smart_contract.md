## Ⅰ. 정의
> 블록체인 위에서 사전 정의된 조건이 충족되면 중개자 없이 자동 실행·집행되는 프로그램 코드 형태의 계약으로, "Code is Law"를 구현한다.

## Ⅱ. 구성요소 / 원리
- 계약 코드: Solidity 등으로 작성, 조건-실행 로직 정의
- EVM(Ethereum Virtual Machine): 분산 실행 환경, 결정론적 연산
- 가스(Gas): 연산 자원 비용으로 무한루프·남용 방지
- 트리거: 트랜잭션/오라클 외부 데이터로 실행 조건 충족
- 상태 저장: 실행 결과를 블록체인 상태(State)에 기록

## Ⅲ. 흐름도 / 구조
```text
[계약 배포] → [블록체인 주소 부여]
[조건 입력(Tx/Oracle)] → [EVM 실행·검증]
   → [상태 변경·자산 이전] → [원장 기록(불변)]
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 중개자 없는 신뢰 기반 계약 자동 집행 |
| 장점 | 자동화, 위·변조 불가, 거래비용 절감 |
| 한계 | 코드 버그=취약점, 오라클 문제, 수정 불가 |

## Ⅴ. 기술사적 적용
- DeFi(탈중앙금융), NFT 발행, DAO 거버넌스 핵심 엔진
- 오라클(체인링크)로 실세계 데이터 연동
- 재진입 공격 등 보안감사(Audit)·정형검증 필수
