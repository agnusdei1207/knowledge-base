## Ⅰ. 정의
> 거래 내역을 블록 단위로 묶어 해시 체인으로 연결하고, P2P 네트워크의 모든 노드가 동일 원장을 분산 보관·합의하는 분산원장기술(DLT, Distributed Ledger Technology)이다.

## Ⅱ. 구성요소 / 원리
- 블록: 헤더(이전 블록 해시·머클루트·논스·타임스탬프) + 트랜잭션 본문
- 해시 체인: 이전 블록 해시를 포함해 위·변조 시 연쇄 단절로 탐지
- P2P 분산 네트워크: 중앙 서버 없이 노드 간 직접 원장 복제
- 합의 메커니즘: PoW/PoS 등으로 단일 진실 상태 동기화
- 공개키 암호·전자서명: 소유권 증명 및 거래 무결성 보장

## Ⅲ. 흐름도 / 구조
```text
[거래 발생]→[브로드캐스트]→[블록 생성·검증(합의)]
   → [체인 연결] → [모든 노드 원장 동기화]
  Block N-1 ──hash──▶ Block N ──hash──▶ Block N+1
   (Prev Hash + Merkle Root + Nonce)
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 신뢰기관 없는 탈중앙 거래 무결성·투명성 확보 |
| 장점 | 위·변조 불가, 투명성, 단일 장애점(SPOF) 제거 |
| 한계 | 낮은 처리량(TPS)·확장성, 합의 지연, 저장 중복 |

## Ⅴ. 기술사적 적용
- 퍼블릭(비트코인)·프라이빗(하이퍼레저)·컨소시엄으로 유형 구분
- 공급망 추적, 무역금융, 전자투표, CBDC 인프라에 활용
- 트릴레마(확장성·탈중앙·보안) 해결을 위해 L2·샤딩과 연계
