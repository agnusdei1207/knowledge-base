## Ⅰ. 정의
> 다수 트랜잭션을 해시 쌍으로 반복 결합해 하나의 루트 해시(Merkle Root)로 요약하는 이진 해시 트리로, 대량 데이터의 무결성을 효율적으로 검증한다.

## Ⅱ. 구성요소 / 원리
- 리프 노드: 개별 트랜잭션의 해시값
- 중간 노드: 하위 두 해시를 연결·재해시한 값
- 머클 루트: 최상위 단일 해시, 블록 헤더에 저장
- 머클 경로(Proof): 특정 거래 검증에 필요한 형제 해시 집합
- SPV(Simplified Payment Verification): 전체 블록 없이 경로만으로 포함 증명

## Ⅲ. 흐름도 / 구조
```text
          Root Hash
         /         \
     H(AB)         H(CD)
     /   \         /   \
   H(A)  H(B)   H(C)  H(D)
   Tx A  Tx B   Tx C  Tx D
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 대량 거래의 무결성·포함 여부 효율 검증 |
| 장점 | O(log n) 검증, 경량 노드 지원, 변조 즉시 탐지 |
| 한계 | 트리 재구성 비용, 데이터 자체는 미저장(해시만) |

## Ⅴ. 기술사적 적용
- 비트코인 블록 헤더의 머클루트로 거래 무결성 보장
- SPV 라이트 클라이언트(모바일 지갑) 검증 기반
- Git, IPFS, 분산 DB 동기화에도 동일 원리 적용
