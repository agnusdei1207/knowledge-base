## 핵심 인사이트 (3줄 요약)

> 1. **본질**: ICT 융합은 물리(Physical) 공정·도시·차량을 사이버(Cyber)로 끌어와 실시간 동기화·예측·자율제어하는 흐름이다 — 키워드 단건이 아니라 *데이터-연결-지능-보안*의 연결고리로 외운다.
> 2. **출제 양상**: 컴시응에서는 **선별 편입 과목**. 단답은 정의가 까다로운 개념(CPS, 네트워크 슬라이싱, V2X 등), 서술은 *디지털 트윈·스마트팩토리·자율주행·융합보안*처럼 산업 적용 구조가 변별력을 만든다.
> 3. **판단 포인트**: 답안은 항상 "①물리/가상 구조 → ②데이터 흐름 → ③지능(AI)·실시간 → ④보안·운영 이슈" 4박자로 마무리해야 기술사 점수가 나온다.

---

## Ⅰ. 과목 개요

- **정의**: ICT 융합 = 5G·IoT·AI·클라우드 등 기반 ICT를 제조·교통·도시·에너지 등 타 산업 도메인과 결합해 디지털 전환(DX)을 일으키는 응용 영역.
- **시험 비중**: 단독 출제보다 **서술형 마무리·융합 사례 근거**로 더 자주 쓰인다 (예: "MSA로 스마트팩토리 플랫폼 설계", "엣지+AI로 자율주행 인지").
- **1교시**: 정의가 헷갈리는 개념(CPS vs 디지털트윈, 엣지 vs 포그, SAE 레벨)이 단답으로 출제 → 1문장 정의 + 도해로 구분.
- **2~4교시**: "산업 적용 구조 + 데이터 흐름 + 보안 이슈 + 운영 효과"를 묻는 설계·방안형이 주류.
- 약어는 최초 1회 풀네임 병기 (예: CPS(Cyber-Physical System)).

## Ⅱ. 1교시 단답형 핵심 (앞단위)

> 진짜 핵심 12개만. 정의 1문장 + 핵심 3포인트로 압축.

| 키워드 | 한줄 정의 | 핵심 3포인트 |
|:---|:---|:---|
| **디지털 트윈** (Digital Twin) | 물리 객체·시스템·도시를 가상에 1:1 복제해 실시간 동기화·시뮬레이션·예측하는 기술 | ① 3요소: 물리·가상·실시간 데이터연결 ② 모니터링→예측→최적화 단계 ③ CPS·시뮬레이션 결합, 예지정비(PdM) |
| **IoT** (Internet of Things) | 사물에 센서·통신을 내장해 인터넷으로 연결·제어하는 기술 | ① 3구성: 디바이스(센서/액추에이터)·네트워크·플랫폼 ② 경량 프로토콜 MQTT/CoAP ③ 위협: 봇넷(Mirai)·디폴트 PW |
| **엣지 컴퓨팅** (Edge Computing) | 데이터를 클라우드로 보내지 않고 디바이스 주변에서 실시간 처리 | ① 지연(Latency)·대역폭 절감 ② 포그(Fog)는 게이트웨이 중간 계층 ③ 엣지 AI로 온디바이스 추론 |
| **CPS** (Cyber-Physical System) | 컴퓨팅 체계가 물리 공정을 실시간 제어·피드백하는 가상물리시스템 | ① 스마트팩토리의 '두뇌' ② 센싱→연산→액추에이션 폐루프 ③ 디지털 트윈과 결합(트윈=가상모델, CPS=제어체계) |
| **스마트 팩토리** (Smart Factory) | ICT로 설계·생산·물류 전 공정을 자동화·지능화한 공장 | ① CPS+IoT+빅데이터+AI 결합 ② OPC UA·TSN 산업통신 ③ 예지정비·디지털 트윈 기반 최적화 |
| **자율주행** (Autonomous Vehicle) | 차량이 스스로 인지·판단·제어하는 기술 (SAE 0~5단계) | ① Lv3 조건부(시스템 제어)/Lv4 고도(개입 불필요) ② 센서퓨전: 카메라·LiDAR·Radar ③ V2X·SDV로 진화 |
| **V2X** (Vehicle to Everything) | 차량과 차량(V2V)·인프라(V2I)·보행자(V2P)·망(V2N) 간 무선통신 | ① C-V2X(3GPP/5G)가 대세, WAVE(802.11p)는 과거 ② uRLLC 초저지연 필요 ③ 군집주행(Platooning) 기반 |
| **5G 네트워크 슬라이싱** (Network Slicing) | 물리 통신망 1개를 논리적으로 분할해 서비스별 맞춤 보장 | ① 5G 3특성 eMBB/uRLLC/mMTC ② 자율주행=uRLLC, IoT=mMTC 슬라이스 ③ 5G SA(5GC)·SBA 구조 전제 |
| **메타버스/XR** (Metaverse/eXtended Reality) | VR·AR·MR을 아우르는 3D 가상융합 세계·공간 컴퓨팅 | ① 공간 컴퓨팅(3D 스캔·상호작용) ② SLAM·6DoF 트래킹 ③ 디지털 트윈+메타버스로 산업 시뮬레이션 |
| **스마트 시티** (Smart City) | 도시 인프라에 ICT를 접목해 데이터 기반으로 운영·관리하는 도시 | ① 센싱→플랫폼→서비스 계층 ② 디지털 트윈·C-ITS·MaaS 결합 ③ 데이터 거버넌스·프라이버시 이슈 |
| **UAM** (Urban Air Mobility) | eVTOL 기반 도심 3차원 항공 교통 체계 | ① 회랑(Corridor)·UTM 관제 ② K-UAM 그랜드챌린지 ③ C-V2X·5G 통신 의존 |
| **융합보안** (Convergence/OT Security) | IT-OT(운영기술) 결합 환경의 물리·사이버 통합 보안 | ① ICS/SCADA·산업제어 보호 ② IT/OT 망분리·이상탐지 ③ 스마트팩토리·자율주행 안전성 직결 |

**1교시 답안 공식**: `정의 1문장 → 핵심 특징 3개 → ASCII 도해 3줄(입력→메커니즘→효과) → 미니 표(목적·강점·한계) → 적용/비교 1줄` (약어 최초 1회 풀네임).

## Ⅲ. 2~4교시 서술형 확장 (심화)

> 1교시 키워드에서 자라난 4개 주제. 각 주제는 정의 + Ⅰ~Ⅴ 전개 가이드 + 권장 도해/표.

### 1. 디지털 트윈 (Digital Twin)

- **정의**: 물리 자산을 가상에 1:1 복제·실시간 동기화하여 모니터링·시뮬레이션·예측·최적화하는 기술.
- **Ⅰ. 개요**: 정의 + 등장배경(센서·5G·AI 성숙으로 실시간 가상화 현실화).
- **Ⅱ. 구조/원리**: 물리공간 → (IoT 센서/5G) → 가상모델(시뮬레이션 엔진) → AI 분석 → 물리공간 피드백, **폐루프 도해** 필수.
- **Ⅲ. 특징/비교**: 성숙도 단계(모니터링→분석→예측→자율) 표, CAE 시뮬레이션과의 차이(실시간 동기화 유무).
- **Ⅳ. 적용/방안**: 제조 예지정비, 스마트시티 교통, 에너지 그리드 / 도입 시 데이터 정합성·표준·보안 고려.
- **Ⅴ. 결론**: CPS·메타버스와 융합해 산업 AI의 핵심 인프라로 확대.
- **권장 도해/표**: 폐루프 구조도 + 성숙도 단계표.

### 2. 스마트 팩토리 & CPS (Smart Factory & Cyber-Physical System)

- **정의**: CPS·IoT·빅데이터·AI를 결합해 생산 전 공정을 실시간 제어·최적화하는 지능형 공장.
- **Ⅰ. 개요**: 정의 + 필요성(다품종 유연생산·인력감소·품질).
- **Ⅱ. 구조/원리**: 5계층(설비/IoT → 제어(PLC/CPS) → 운영(MES) → 기업(ERP) → 분석/AI), 산업통신 OPC UA·TSN.
- **Ⅲ. 특징/비교**: 성숙도(기초→고도화→지능화) 표, 기존 자동화 공장 vs 스마트팩토리 비교.
- **Ⅳ. 적용/방안**: 예지정비·디지털 트윈·프라이빗 5G(이음5G) / 도입 단계화·IT-OT 융합보안.
- **Ⅴ. 결론**: CPS=실시간 제어 뇌, 디지털 트윈=가상 검증 — 두 축의 결합이 핵심.
- **권장 도해/표**: 5계층 아키텍처 구성도 + 성숙도 표.

### 3. 자율주행 & V2X (Autonomous Vehicle & V2X)

- **정의**: 차량이 센서로 환경을 인지하고 스스로 판단·제어하는 기술과, 이를 보조하는 차량 외부 통신(V2X).
- **Ⅰ. 개요**: 정의 + SAE J3016 0~5단계 위치.
- **Ⅱ. 구조/원리**: 인지(센서퓨전: 카메라·LiDAR·Radar) → 판단(AI/경로계획) → 제어 → V2X 통신 보조, 흐름도.
- **Ⅲ. 특징/비교**: Lv2~Lv4 단계 비교표, C-V2X vs WAVE(802.11p) 비교표.
- **Ⅳ. 적용/방안**: 로보택시·군집주행(Platooning)·SDV / 안전성(Fail-safe)·사이버보안·윤리(트롤리) 이슈.
- **Ⅴ. 결론**: 5G uRLLC·엣지AI·정밀지도와 결합해 Lv4 상용화로 진행.
- **권장 도해/표**: 인지-판단-제어 흐름도 + **C-V2X vs WAVE 비교표** + SAE 단계표.

### 4. 융합보안 (OT/ICS Security)

- **정의**: IT와 OT(운영기술)가 결합된 환경에서 물리·사이버 위협을 통합 방어하는 보안 체계.
- **Ⅰ. 개요**: 정의 + 배경(스마트팩토리·자율주행·스마트시티로 OT가 인터넷에 노출).
- **Ⅱ. 구조/원리**: Purdue 모델 계층(Lv0 현장기기 ~ Lv5 기업망), IT/OT 경계 DMZ·일방향 게이트웨이.
- **Ⅲ. 특징/비교**: **IT 보안 vs OT 보안 비교표**(우선순위 C-I-A vs A-I-C, 패치 주기, 가용성 중시).
- **Ⅳ. 적용/방안**: 망분리·이상탐지(Anomaly)·자산 가시성·제로트러스트 / IEC 62443 표준.
- **Ⅴ. 결론**: 안전(Safety)과 보안(Security)의 동시 달성이 융합보안의 본질.
- **권장 도해/표**: Purdue 계층 구성도 + IT vs OT 보안 비교표.

> **비교표 예시 — IT 보안 vs OT 보안**

| 구분 | IT 보안 | OT 보안 |
|:---|:---|:---|
| 최우선 가치 | 기밀성(C) > I > A | 가용성(A) > I > C |
| 패치/업데이트 | 즉시·빈번 | 가동 중단 부담, 제한적 |
| 수명주기 | 3~5년 | 10~20년(레거시) |
| 핵심 위협 | 정보 유출 | 공정 중단·물리 피해 |
| 대표 표준 | ISO 27001 | IEC 62443 |

## Ⅳ. 출제 포인트 & 함정

| 출제유형 | 1교시 단답 포인트 | 2~4교시 서술 포인트 |
|:---|:---|:---|
| 개념 구분형 | CPS vs 디지털트윈, 엣지 vs 포그 정확히 구분 | 물리/가상 구조 + 데이터 흐름 폐루프 도해 |
| 통신 융합형 | 5G 3특성(eMBB/uRLLC/mMTC), 네트워크 슬라이싱, C-V2X | 슬라이싱으로 서비스별 보장 설계, V2X 비교표 |
| 산업 적용형 | 스마트팩토리 5계층, OPC UA/TSN, 이음5G | 성숙도 단계 + 도입 방안 + IT/OT 보안 |
| 자율주행형 | SAE 레벨, 센서퓨전, LiDAR | 인지-판단-제어 흐름 + 안전·보안 이슈 |
| 보안 융합형 | 융합보안, OT/ICS, IEC 62443 | IT vs OT 비교 + Purdue 계층 방어 |

**흔한 감점/함정**:
- 디지털 트윈을 "단순 3D 모델/시뮬레이션"으로 정의 → **실시간 동기화** 요소를 빠뜨리면 감점.
- CPS와 디지털 트윈을 혼용 → CPS=제어 체계, 트윈=가상 모델로 구분해야 함.
- V2X에서 WAVE(802.11p)를 현행 표준으로 서술 → 현재는 **C-V2X(5G)** 대세.
- 자율주행 Lv3/Lv4 책임 주체 혼동 → Lv3=비상 시 운전자 개입, Lv4=개입 불필요.
- 키워드만 나열하고 **데이터 흐름·보안·운영 효과**로 닫지 않으면 융합 문제에서 변별력 상실.
- 약어 풀네임 미병기, 도해/표 없는 글만 답안.

## Ⅴ. 결론 및 회독 포인트

- ICT 융합은 **개념 암기가 아니라 "물리→데이터→지능→보안" 연결 사고**로 푼다. 단답은 헷갈리는 정의를 도해로 구분하고, 서술은 항상 산업 적용 구조 + 보안·운영 이슈로 마무리한다.
- 우선순위: ① 디지털 트윈·CPS·스마트팩토리(서술 단골) → ② 자율주행·V2X·5G 슬라이싱(통신 융합) → ③ 융합보안·스마트시티·UAM(확장).
- 기술사 관점에서는 정의보다 **적용 조건·트레이드오프(실시간성 vs 비용, 가용성 vs 보안)**를 함께 제시해야 고득점.
