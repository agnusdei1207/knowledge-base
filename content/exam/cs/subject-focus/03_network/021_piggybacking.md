## Ⅰ. 정의
> 전이중 통신에서 수신 확인 응답(ACK)을 별도 프레임 대신 역방향 데이터 프레임에 실어 함께 전송하는 효율화 기법.

## Ⅱ. 구성요소 / 원리
- 데이터 프레임의 제어 필드에 ACK 번호 포함
- 양방향 데이터가 흐를 때 ACK를 편승(piggyback)
- ACK 대기 타이머로 일정 시간 데이터 없으면 단독 ACK 전송
- 슬라이딩 윈도우의 시퀀스·확인 번호 체계와 결합

## Ⅲ. 흐름도 / 구조
```text
A ──[Data0 + AckB]──▶ B
A ◀──[Data0 + AckA]── B   (B의 데이터에 A프레임 ACK 편승)
   데이터 없으면? 타이머 만료 → 단독 ACK 전송
   별도 ACK 프레임 수 감소 → 대역폭 절약
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 별도 ACK 프레임 제거로 대역폭·처리 오버헤드 절감 |
| 장점 | 회선 이용률 향상, 프레임 수 감소 |
| 한계 | 역방향 데이터 없을 시 ACK 지연 발생(지연 트레이드오프) |

## Ⅴ. 기술사적 적용
- HDLC I-프레임의 N(R)/N(S) 필드로 데이터+ACK 동시 전달
- TCP 헤더의 ACK 플래그·확인번호로 양방향 통신에 적용
- 지연 ACK(Delayed ACK)와 결합 시 타이머 과다 설정 주의
