## Ⅰ. 정의
> OSI(Open Systems Interconnection) 7계층은 통신 기능을 7단계로 표준화한 참조모델이며, TCP/IP는 인터넷 실구현 기반의 4계층 모델로 각 계층이 독립 역할을 수행한다.

## Ⅱ. 구성요소 / 원리
- 응용/표현/세션(L7-5): 데이터 표현·암호화·세션 관리(TCP/IP의 응용계층)
- 전송(L4): TCP/UDP 종단 간 신뢰성·흐름제어, PDU=세그먼트
- 네트워크(L3): IP 라우팅·논리주소, PDU=패킷, 장비=라우터
- 데이터링크(L2): MAC 프레임·오류제어, PDU=프레임, 장비=스위치
- 물리(L1): 비트 전기/광 신호 전송, 장비=허브/리피터

## Ⅲ. 흐름도 / 구조
```text
OSI 7         TCP/IP 4        PDU       장비
L7 응용 ┐
L6 표현 ├-> 응용계층        데이터    GW/L7스위치
L5 세션 ┘
L4 전송 --> 전송계층        세그먼트  (L4 부하분산)
L3 네트워크-> 인터넷계층     패킷      라우터
L2 링크 ┐-> 네트워크접근    프레임/   스위치/
L1 물리 ┘    계층           비트      허브
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 통신 기능 계층 분리로 표준화·상호운용·모듈화 |
| 장점 | 계층별 독립 개발·디버깅 용이, 이기종 연동 |
| 한계 | OSI는 참조용 이상화, 실제는 TCP/IP가 사실상 표준 |

## Ⅴ. 기술사적 적용
- OSI vs TCP/IP: 7계층 이론 모델 vs 4계층 구현 모델, 계층 매핑 비교
- 계층별 장비·프로토콜 매핑으로 장애 구간 진단(L1~L7 트러블슈팅)
- 캡슐화/역캡슐화 원리로 종단 간 데이터 전달 설계 근거 제공
