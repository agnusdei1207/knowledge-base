## Ⅰ. 정의
> 송신 시 각 계층이 상위 데이터에 헤더(필요 시 트레일러)를 추가하는 캡슐화와, 수신 시 하위 계층부터 헤더를 제거하는 역캡슐화로, 계층 간 데이터 전달을 구현하는 과정이다.

## Ⅱ. 구성요소 / 원리
- 계층별 헤더 추가: 전송(포트)·네트워크(IP)·링크(MAC) 정보를 단계적 부착
- PDU 변화: 데이터→세그먼트(L4)→패킷(L3)→프레임(L2)→비트(L1)
- 트레일러: 데이터링크 계층 FCS(오류검출) 등 후미 정보 추가
- 역캡슐화: 수신 측이 L1→L7 순으로 헤더 해석·제거 후 상위 전달
- 동등계층 통신: 송수신 동일 계층이 헤더 정보로 논리적 통신

## Ⅲ. 흐름도 / 구조
```text
송신(캡슐화)              수신(역캡슐화)
응용 [Data]                  [Data] 응용
전송 [TCP|Data] 세그먼트     [Data] 전송
네트워크 [IP|TCP|Data] 패킷   [TCP|Data] 네트워크
링크 [MAC|IP|..|FCS] 프레임   [IP|..] 링크
물리 1010... 비트 ====전송====> 1010... 물리
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 계층 독립성 유지하며 종단 간 데이터 신뢰 전달 |
| 장점 | 모듈화로 계층별 변경 용이, 표준 상호운용 |
| 한계 | 계층마다 헤더 오버헤드 누적, MTU 초과 시 단편화 |

## Ⅴ. 기술사적 적용
- 패킷 분석(Wireshark)에서 계층별 헤더 디캡슐화로 장애 진단
- 터널링/VPN은 추가 캡슐화(이중 헤더)로 오버레이 전송 구현
- 헤더 오버헤드·MTU 고려한 MSS·Jumbo Frame 등 성능 설계
