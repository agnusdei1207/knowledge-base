## Ⅰ. 1교시 핵심 답안

> DNS는 사람이 사용하는 도메인 이름을 IP 주소로 변환하는 계층형 분산 네임 해석 시스템이다.

- **계층 구조**: `Root -> TLD -> Authoritative`
- **질의 방식**: Recursive, Iterative
- **주요 레코드**: `A/AAAA`, `CNAME`, `MX`, `NS`
- **출제 포인트**: 분산 구조와 캐싱 메커니즘

## Ⅱ. 구조 및 동작 원리

```text
Client
 -> Resolver
 -> Root
 -> TLD
 -> Authoritative Server
 <- IP Address

응답은 TTL 기반 캐시 가능
```

- **Resolver**: 사용자 대신 질의 수행
- **Recursive Query**: 최종 응답까지 대신 추적
- **Iterative Query**: 다음 질의 대상만 안내
- **TTL Cache**: 반복 질의 감소와 응답 지연 단축

## Ⅲ. 비교표

| 구분 | Recursive | Iterative |
|:---|:---|:---|
| 처리 주체 | Resolver | 질의자 |
| 응답 형태 | 최종 결과 반환 | 다음 서버 정보 반환 |
| 장점 | 사용자 단순화 | 상위 서버 부담 분산 |
| 시험 포인트 | 로컬 DNS 역할 | 계층형 위임 구조 |

## Ⅳ. 기술사 답안 포인트

- **장점**: 계층형 분산 구조로 인터넷 규모 확장 가능
- **운영 포인트**: TTL, Zone 관리, Authoritative/Cache 분리
- **보안 포인트**: Cache Poisoning, DNS Spoofing, `DNSSEC`
- **확장 주제**: DoH/DoT, GSLB, CDN, Anycast DNS

## Ⅴ. 결론

DNS의 핵심은 단순 주소 변환이 아니라 `계층적 위임과 캐시 기반 확장성`이다.  
따라서 답안은 `Root-TLD-권한서버-TTL` 흐름을 중심으로 정리하는 것이 효과적이다.
