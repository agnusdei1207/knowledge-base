## Ⅰ. 정의
> 기존 클래스(A/B/C) 기반 주소 체계의 비효율을 극복하기 위해 가변 길이 프리픽스(/n)로 네트워크 경계를 자유롭게 지정하는 클래스리스 주소 할당·라우팅 방식이다.

## Ⅱ. 구성요소 / 원리
- 프리픽스 표기(CIDR Notation): IP주소/프리픽스길이 형식(예: 203.0.113.0/22)
- 프리픽스 길이가 네트워크 비트 수를 지정, 클래스 경계(8/16/24) 무시
- 라우트 집약(Route Aggregation/Supernetting): 연속된 다수 네트워크를 하나의 프리픽스로 광고
- 슈퍼네팅으로 라우팅 테이블 엔트리 수 감소
- 최장 프리픽스 매칭(Longest Prefix Match)으로 경로 결정

## Ⅲ. 흐름도 / 구조
```text
클래스풀: C클래스 4개 = 4개 라우트 광고
  192.168.0.0/24
  192.168.1.0/24   →  집약(Supernet)
  192.168.2.0/24       192.168.0.0/22
  192.168.3.0/24   →  1개 라우트로 광고
라우터: Longest Prefix Match로 최적 선택
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | IPv4 주소 고갈 완화 및 글로벌 라우팅 테이블 폭증 억제 |
| 장점 | 주소 할당 유연성, 라우트 집약으로 테이블 축소·수렴 개선 |
| 한계 | 주소 계획 복잡, 비연속 주소는 집약 불가, IPv4 근본 고갈은 미해결 |

## Ⅴ. 기술사적 적용
- ISP(Internet Service Provider) 주소 할당 및 BGP(Border Gateway Protocol) 경로 집약에 표준 적용
- VLSM과 결합하여 조직 내부 계층적 주소 설계 수행
- IPv4 고갈의 근본 해법인 IPv6 전환의 과도기 효율화 수단
