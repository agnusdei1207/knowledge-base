## Ⅰ. 정의
> 충돌 도메인은 프레임 충돌이 전파되는 범위이고, 브로드캐스트 도메인은 브로드캐스트 프레임이 도달하는 범위로, 네트워크 장비에 따라 경계가 결정된다.

## Ⅱ. 구성요소 / 원리
- 허브(Hub): 모든 포트가 하나의 충돌·브로드캐스트 도메인
- 스위치(Switch): 포트마다 충돌 도메인 분리, 브로드캐스트 도메인은 공유
- 라우터(Router): 인터페이스마다 브로드캐스트 도메인 분리
- VLAN(Virtual LAN): 스위치에서 브로드캐스트 도메인 논리 분할
- 도메인 축소로 충돌·브로드캐스트 트래픽 감소

## Ⅲ. 흐름도 / 구조
```text
허브  : [─ 1 충돌 / 1 브로드캐스트 도메인 ─]
스위치: 포트별 충돌도메인 분리 | 브로드캐스트 1개
라우터: ─┤BD1├─(R)─┤BD2├─  브로드캐스트 차단
        충돌도메인  ↓ 분할     브로드캐스트도메인 ↓ 분할
        스위치/브리지          라우터/VLAN
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 충돌·브로드캐스트 범위 제어로 성능·확장성 확보 |
| 장점 | 도메인 분할 시 대역폭 효율·보안·격리 향상 |
| 한계 | 과도 분할 시 라우팅 비용·관리 복잡도 증가 |

## Ⅴ. 기술사적 적용
- 계층적 설계: 액세스(스위치)→분배(L3)→코어로 도메인 단계 분리
- VLAN+L3 스위치로 브로드캐스트 도메인을 논리적으로 분할
- 브로드캐스트 스톰 방지를 위한 STP·스톰컨트롤과 연계
