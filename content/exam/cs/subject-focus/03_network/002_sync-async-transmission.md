## Ⅰ. 정의
> 송수신측 비트 타이밍을 일치시키는 방식으로, 문자 단위로 스타트/스톱 비트를 붙이는 비동기 전송(Asynchronous)과, 클럭을 공유하여 블록(프레임) 단위로 연속 전송하는 동기 전송(Synchronous)으로 구분한다.

## Ⅱ. 구성요소 / 원리
- 비동기: 각 문자 앞 1 스타트 비트, 뒤 1~2 스톱 비트로 프레임 경계 식별, 문자 간 휴지(idle) 허용
- 동기: 프리앰블/SYN 문자·플래그로 프레임 동기 확보, 별도 클럭 또는 자기동기(Manchester) 인코딩 사용
- 비동기는 수신측이 스타트 비트 하강에서 클럭 재동기, 저속·간헐 전송에 적합
- 동기는 대량 데이터를 연속 비트열로 전송, 헤더·CRC를 포함한 프레임 구조 사용
- 오버헤드: 비동기는 문자마다 2~3비트(약 20~30%), 동기는 프레임당 헤더만 부담해 효율 높음

## Ⅲ. 흐름도 / 구조
```text
비동기: [Start][D0..D7][Parity][Stop]  idle  [Start]...
        문자마다 동기, 휴지 허용
동기  : [Flag/Preamble][ Header | Data ........ | CRC ][Flag]
        클럭 공유, 블록 연속 전송(휴지 없음)
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 송수신 비트 타이밍 동기화로 정확한 데이터 복원 |
| 장점 | 비동기는 단순·저비용, 동기는 오버헤드 적고 고속 대량 전송에 유리 |
| 한계 | 비동기는 문자당 오버헤드로 효율 저하, 동기는 클럭 동기 회로로 구현 복잡 |

## Ⅴ. 기술사적 적용
- RS-232 UART 직렬통신은 비동기(스타트/스톱) 방식의 대표 사례
- HDLC·이더넷·SONET 등 고속 WAN/LAN은 프레임 기반 동기 전송 채택
- 효율 산정 시 비동기는 (데이터비트/전체비트)로 전송효율을 계산해 비교
