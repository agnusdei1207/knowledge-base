## Ⅰ. 정의
> 벨만-포드(Bellman-Ford) 알고리즘은 단일 출발점에서 모든 노드까지의 최단 경로를 구하는 알고리즘으로, 음수 가중치 간선을 허용하며 거리벡터 라우팅의 이론적 기반이 된다.

## Ⅱ. 구성요소 / 원리
- 모든 간선에 대해 거리 완화(Relaxation)를 (정점수 V-1)회 반복 수행
- 완화: dist[v] > dist[u] + w(u,v)이면 dist[v] 갱신
- V-1회 반복으로 최단 경로 수렴 보장
- 추가 1회 반복에서 갱신 발생 시 음수 사이클(Negative Cycle) 검출
- 시간 복잡도 O(V·E)로 다익스트라보다 느리나 음수 간선 처리 가능

## Ⅲ. 흐름도 / 구조
```text
초기: dist[출발]=0, 나머지=∞
반복 (V-1)회:
  for 모든 간선(u,v,w):
    if dist[u]+w < dist[v]: dist[v]=dist[u]+w (완화)
1회 추가 반복:
  여전히 갱신되면 → 음수 사이클 존재
결과: 출발→전 노드 최단거리
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 음수 가중치를 포함한 그래프의 단일 출발점 최단 경로 계산 |
| 장점 | 음수 간선 허용, 음수 사이클 탐지 가능, 구현 단순 |
| 한계 | O(VE)로 다익스트라(O(E log V)) 대비 느림, 분산 적용 시 카운트 투 인피니티 |

## Ⅴ. 기술사적 적용
- RIP 등 거리벡터 라우팅 프로토콜의 경로 계산 이론 토대
- 음수 간선이 없는 망에서는 다익스트라(OSPF SPF)가 더 효율적
- 분산 벨만-포드의 느린 수렴 문제를 Split Horizon·Poison Reverse로 보완
