## Ⅰ. 정의
> MAC 주소를 학습해 프레임을 목적지 포트로만 전달하는 데이터링크 계층(L2) 장비로, 포트별 충돌 도메인을 분리한다.

## Ⅱ. 구성요소 / 원리
- 학습(Learning): 수신 프레임의 출발지 MAC을 포트와 매핑해 테이블 등록
- 플러딩(Flooding): 목적지 미지/브로드캐스트 시 전 포트로 전송
- 포워딩(Forwarding): 테이블에 있으면 해당 포트로만 전달
- 필터링(Filtering): 동일 포트 향 프레임 차단
- 에이징(Aging): 일정 시간 미사용 항목 자동 삭제

## Ⅲ. 흐름도 / 구조
```text
프레임 수신 → 출발지 MAC 학습(포트 기록)
           → 목적지 MAC 조회
              ├ 미등록/브로드캐스트 → 플러딩(전 포트)
              ├ 등록(다른포트) → 포워딩(해당 포트)
              └ 등록(동일포트) → 필터링(폐기)
 MAC 테이블: [MAC | Port | Age]
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | MAC 기반 지능적 프레임 전달로 LAN 성능 향상 |
| 장점 | 포트별 충돌도메인 분리, 전이중·라인레이트 전송 |
| 한계 | 브로드캐스트 도메인 공유, MAC 테이블 오버플로 공격 취약 |

## Ⅴ. 기술사적 적용
- VLAN·STP·LACP 등 L2 기능의 기반 플랫폼
- L3 스위치는 라우팅 통합으로 도메인 간 고속 전달
- 포트 보안·DHCP 스누핑으로 MAC 플러딩 공격 방어
