## Ⅰ. 정의
> 공중망(Public Network) 위에 터널링과 암호화로 논리적 전용망을 구성하여, 안전하고 사설망과 동등한 통신을 제공하는 기술이다.

## Ⅱ. 구성요소 / 원리
- 터널링: 패킷 캡슐화로 공중망 위 가상 전용 경로 형성
- 암호화·인증: 기밀성·무결성·송신자 인증 보장
- 사이트투사이트(Site-to-Site): 게이트웨이 간 연결로 거점망 통합
- 원격접속(Remote Access): 개별 사용자가 사내망에 안전 접속
- VPN 게이트웨이/클라이언트: 터널 종단·정책 적용 주체

## Ⅲ. 흐름도 / 구조
```text
[지사 LAN]-GW===암호화 터널===GW-[본사 LAN]  (Site-to-Site)
[원격 PC]--VPN Client===터널===VPN GW-[사내망]  (Remote Access)
        인증 -> 터널수립 -> 암호화전송 -> 복호화
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 공중망에서 전용선 수준의 보안·연결성 저비용 제공 |
| 장점 | 전용선 대비 경제적, 확장 용이, 원격근무 지원 |
| 한계 | 공중망 품질 의존, 암호화 오버헤드·지연, 종단 보안 필요 |

## Ⅴ. 기술사적 적용
- IPsec VPN(L3, 전 트래픽) vs SSL VPN(L4-7, 브라우저 기반 응용 접근)
- 제로트러스트(ZTNA)로 진화: 경계형 VPN의 과신뢰 한계 보완
- SD-WAN과 결합해 다중 회선·정책 기반 안전 WAN 구성
