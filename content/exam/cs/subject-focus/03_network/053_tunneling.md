## Ⅰ. 정의
> 한 프로토콜의 패킷을 다른 프로토콜 패킷으로 캡슐화(Encapsulation)하여 중간 네트워크를 가상 통로처럼 통과시키는 오버레이(Overlay) 전송 기법이다.

## Ⅱ. 구성요소 / 원리
- 캡슐화: 원본 패킷을 페이로드로 새 헤더로 감싸 전송, 종단에서 역캡슐화
- 터널 종단점(Tunnel Endpoint): 캡슐화/복원을 수행하는 시작·종료 노드
- GRE(Generic Routing Encapsulation): 다양한 L3 프로토콜을 IP로 캡슐화(비암호)
- L2TP(Layer 2 Tunneling Protocol): L2 프레임(PPP) 터널링, 주로 IPsec와 결합
- 오버레이: 물리망 위 논리 가상망 구성(VXLAN 등도 동일 원리)

## Ⅲ. 흐름도 / 구조
```text
[원본패킷] --(터널 진입)--> +새 터널헤더| 원본패킷 |
                              캡슐화
   언더레이 IP망 통과 ===========================>
                              역캡슐화
              <--(터널 종료)-- +원본패킷 복원-> [목적지]
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 이기종/비호환 망 연동, 프라이빗 경로·논리망 구성 |
| 장점 | 토폴로지 추상화, 멀티프로토콜 수용, 사이트 연결 용이 |
| 한계 | 헤더 오버헤드·MTU 단편화, GRE 단독은 암호화 미제공 |

## Ⅴ. 기술사적 적용
- IPsec 터널모드와 결합해 VPN의 보안 전송 채널 구현(L2TP/IPsec)
- 데이터센터·클라우드 오버레이(VXLAN/GRE)로 멀티테넌시 분리
- IPv6 전환 시 6to4/Teredo 등 터널링으로 점진적 마이그레이션
