## Ⅰ. 정의
> 하나의 주소 블록 안에서 서브넷마다 서로 다른 길이의 서브넷마스크를 적용하여, 실제 호스트 수요에 맞게 IP 주소를 가변적으로 분할하는 계층적 서브네팅 기법이다.

## Ⅱ. 구성요소 / 원리
- 서브넷별로 필요한 호스트 수에 따라 마스크 길이 차등 적용
- 큰 블록부터 할당(Top-down) 후 잔여 주소를 재귀적 서브네팅
- 가변 마스크 → 주소 낭비 최소화 및 효율적 IP 분할
- 라우팅 프로토콜은 클래스리스(RIPv2, OSPF, EIGRP)여야 마스크 정보 전달 가능
- 계층 구조로 라우트 집약(Summarization) 용이

## Ⅲ. 흐름도 / 구조
```text
192.168.1.0/24 블록을 수요별 분할
  본사 100호스트 → /25 (.0/25, 126H)
  지사 50호스트  → /26 (.128/26, 62H)
  소규모 20호스트→ /27 (.192/27, 30H)
  WAN 링크 2호스트→ /30 (.224/30, 2H)
  잔여 주소 추가 분할 가능
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 서브넷별 호스트 수요 차이를 반영한 IP 주소 효율 극대화 |
| 장점 | 주소 낭비 최소, 계층적 설계로 집약 가능, 확장성 우수 |
| 한계 | 설계·관리 복잡도 증가, 클래스풀 프로토콜(RIPv1)에서는 미지원 |

## Ⅲ-보충 비교
- 고정길이 서브네팅: 모든 서브넷 동일 마스크 → WAN 링크 등에서 주소 낭비

## Ⅴ. 기술사적 적용
- WAN 점대점 링크에 /30(또는 /31) 적용으로 주소 절감
- CIDR 라우트 집약과 결합한 계층적 주소 아키텍처 설계
- 대규모 캠퍼스/엔터프라이즈 망의 주소 계획 표준 기법
