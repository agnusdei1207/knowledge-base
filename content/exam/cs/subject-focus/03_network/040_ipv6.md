## Ⅰ. 1교시 핵심 답안

> IPv6는 IPv4 주소 고갈 문제를 해결하기 위해 128비트 주소 체계와 단순화된 헤더를 도입한 차세대 인터넷 프로토콜이다.

- **주소 길이**: 32비트 -> 128비트
- **헤더 특징**: 고정 40바이트, 옵션은 확장 헤더 처리
- **주소 유형**: Unicast, Anycast, Multicast
- **출제 포인트**: 주소 확장뿐 아니라 자동구성과 단순화

## Ⅱ. 구조 및 동작 원리

```text
Host -> RS -> Router
Host <- RA <- Router
Prefix + Interface ID
-> SLAAC 주소 생성
-> DAD 수행
```

- **SLAAC**: 라우터 광고 정보를 이용한 무상태 자동 주소 설정
- **NDP**: ARP, 라우터 발견, DAD 기능 통합
- **브로드캐스트 제거**: 멀티캐스트 기반 구조
- **헤더 간소화**: 중간 라우터 처리 효율 향상

## Ⅲ. 비교표

| 구분 | IPv4 | IPv6 |
|:---|:---|:---|
| 주소 길이 | 32비트 | 128비트 |
| 주소 부족 대응 | NAT 의존 | 대규모 직접 주소화 |
| 브로드캐스트 | 존재 | 없음 |
| 자동 구성 | DHCP 중심 | SLAAC/NDP 지원 |

## Ⅳ. 기술사 답안 포인트

- **도입 배경**: 주소 고갈, NAT 의존 증가, 종단간 통신 제약
- **전환 기술**: Dual Stack, Tunneling, NAT64
- **적용 확장**: IoT, 모바일, 대규모 엔드포인트 수용
- **비교 포인트**: `IPv4 vs IPv6`, `NAT 의존 vs End-to-End 회복`

## Ⅴ. 결론

IPv6의 본질은 단순한 주소 확장이 아니라 `직접 주소화`, `자동 구성`, `프로토콜 단순화`에 있다.  
따라서 서술형에서는 주소 공간만 강조하지 말고 `SLAAC/NDP/전환전략`까지 연결해야 완성도가 높다.
