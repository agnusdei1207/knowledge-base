## Ⅰ. 정의
> 방화벽·라우터·로드밸런서 등 전용 하드웨어로 제공되던 네트워크 기능을 범용 서버상의 소프트웨어(VNF)로 가상화하는 기술이다.

## Ⅱ. 구성요소 / 원리
- VNF(Virtualized Network Function): 가상화된 개별 네트워크 기능 소프트웨어
- NFVI(NFV Infrastructure): VNF가 동작하는 범용 서버·가상화 자원
- MANO(Management and Orchestration): VNF 수명주기·자원 오케스트레이션
- 범용 서버: 전용 어플라이언스 대신 표준 x86 하드웨어 사용
- 서비스 체이닝: VNF를 연결해 트래픽 처리 경로 구성

## Ⅲ. 흐름도 / 구조
```text
 ┌ MANO ┐  (오케스트레이션/관리)
 │ VNF1 │ VNF2 │ VNF3 │  (방화벽/LB/라우터)
 ├──────────────────────┤
 │   NFVI (범용 x86 서버) │
 └──────────────────────┘
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 전용 장비 가상화로 비용·유연성 개선 |
| 장점 | CAPEX/OPEX 절감, 신속 배포·탄력적 확장 |
| 한계 | 성능 오버헤드, MANO 복잡성·표준화 미흡 |

## Ⅴ. 기술사적 적용
- SDN이 트래픽 경로 제어, NFV가 기능 제공으로 상호 보완
- 5G 코어(SA)·엣지 컴퓨팅의 가상화 네트워크 기반
- 클라우드 네이티브 전환으로 CNF(Containerized NF)로 진화
