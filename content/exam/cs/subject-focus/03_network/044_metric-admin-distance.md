## Ⅰ. 정의
> 관리거리(AD, Administrative Distance)는 서로 다른 라우팅 정보원(프로토콜) 간 신뢰도 우선순위를 나타내는 값이며, 메트릭(Metric)은 동일 프로토콜 내 경로들 중 최적 경로를 선택하는 비용 척도이다.

## Ⅱ. 구성요소 / 원리
- AD: 값이 낮을수록 신뢰도 높음(Connected 0, Static 1, EIGRP 90, OSPF 110, RIP 120)
- 동일 목적지에 복수 프로토콜 경로 존재 시 AD 낮은 경로 테이블 등재
- 메트릭: 프로토콜별 산정 기준 상이(RIP=홉 수, OSPF=대역폭 비용, EIGRP=대역폭+지연)
- 선택 절차: ① AD로 프로토콜 우선 결정 → ② 메트릭으로 동일 프로토콜 내 최적 선택
- 메트릭 동일 시 부하분산(ECMP, Equal-Cost Multi-Path) 가능

## Ⅲ. 흐름도 / 구조
```text
목적지 10.0.0.0/24에 복수 경로 학습
  OSPF 경로(AD 110)  vs  RIP 경로(AD 120)
        │ ① AD 비교(낮은 값 우선)
        ▼
  OSPF 경로 채택 → 테이블 등재
        │ ② 동일 프로토콜 내 메트릭 비교
        ▼  최소 비용 경로 = 최적 경로
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 다중 정보원·다중 경로 환경에서 일관된 최적 경로 선정 |
| 장점 | AD로 프로토콜 신뢰 서열화, 메트릭으로 정량적 경로 최적화 |
| 한계 | 메트릭 기준이 프로토콜마다 달라 상호 비교 불가, 부적절한 AD 조정 시 루프 위험 |

## Ⅴ. 기술사적 적용
- 백업 경로 설계 시 Floating Static Route(AD 상향)로 주경로 장애 시 자동 전환
- 멀티프로토콜(Redistribution) 환경에서 AD/메트릭 재설정으로 경로 제어
- 부하분산 요구 시 동일 메트릭 다중경로(ECMP) 구성으로 대역폭 활용
