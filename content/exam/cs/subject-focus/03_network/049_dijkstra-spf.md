## Ⅰ. 정의
> 단일 출발지에서 모든 노드까지의 최소비용 경로를 구하는 그리디(Greedy) 기반 SPF(Shortest Path First) 알고리즘으로, 음수 가중치가 없는 그래프에서 최단경로트리를 산출한다.

## Ⅱ. 구성요소 / 원리
- 거리배열 D: 출발지로부터 각 노드까지의 잠정 최소비용 저장
- 확정집합 S: 최단거리가 확정된 노드 집합, 매 단계 1개씩 추가
- 그리디 선택: 미확정 노드 중 D값 최소 노드를 확정
- 완화(Relaxation): 확정 노드 기준 인접 노드 D값을 갱신(D[v]=min(D[v], D[u]+w))
- 우선순위 큐(최소힙)로 최소노드 추출 가속

## Ⅲ. 흐름도 / 구조
```text
[출발 A:0] -> PQ에서 최소 추출 -> S에 확정
   |              |
   v              v
인접노드 완화  ->  D값 갱신(D[u]+w < D[v]?)
   |
   +--> 모든 노드 확정 시 종료 -> 최단경로트리(SPT)
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 음수 없는 그래프의 단일출발지 최소비용 경로/트리 산출 |
| 장점 | 그리디로 단순·정확, 최소힙 사용 시 O(E+V log V) 효율 |
| 한계 | 음수 가중치 처리 불가(→ Bellman-Ford 필요), 전역 토폴로지 필요 |

## Ⅴ. 기술사적 적용
- OSPF(Open Shortest Path First) 링크상태 라우팅이 LSDB 기반 SPF로 다익스트라 채택
- IS-IS 등 링크상태 프로토콜의 최단경로 계산 엔진으로 활용
- 음수·동적 비용 환경에서는 Bellman-Ford(거리벡터)·A* 와 비교 선택
