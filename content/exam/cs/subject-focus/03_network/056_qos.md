## Ⅰ. 정의
> 한정된 네트워크 자원에서 트래픽 유형별로 대역폭·지연·지터·손실을 차등 제어하여 서비스 품질을 보장하는 기술이다.

## Ⅱ. 구성요소 / 원리
- 분류(Classification)·마킹(Marking): 트래픽 식별 후 DSCP/CoS 표시
- 큐잉(Queuing): PQ·WFQ·CBWFQ 등으로 우선순위 스케줄링
- 셰이핑/폴리싱: 전송률 평탄화 또는 초과 트래픽 제한
- 혼잡회피: WRED 등으로 큐 포화 전 선제 폐기
- 모델: IntServ(RSVP 흐름별 예약), DiffServ(DSCP 클래스별 처리), Best-effort(무보장)

## Ⅲ. 흐름도 / 구조
```text
[유입트래픽] -> 분류 -> 마킹(DSCP) -> 큐 배치
                                        |
            폴리싱/셰이핑 <- 스케줄러(PQ/WFQ)
                                        v
                       혼잡회피(WRED) -> 송출
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 실시간/중요 트래픽의 지연·손실 최소화, SLA 보장 |
| 장점 | 자원 효율 배분, 음성·영상 품질 보장, 차등 서비스 |
| 한계 | 종단 간 일관 정책 필요, 설정 복잡, 과대역에선 효과 한정 |

## Ⅴ. 기술사적 적용
- IntServ(RSVP)는 흐름별 예약·확장성 한계, DiffServ는 확장성 우수로 백본 표준
- VoIP·영상회의에 EF(Expedited Forwarding) 클래스 적용해 저지연 보장
- MPLS-TE·SD-WAN과 연계해 경로별 QoS 차등 정책 구현
