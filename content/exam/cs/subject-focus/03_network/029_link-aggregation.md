## Ⅰ. 정의
> 다수의 물리 링크를 하나의 논리 링크로 묶어 대역폭을 증대하고 이중화를 제공하는 기술(IEEE 802.3ad/802.1AX).

## Ⅱ. 구성요소 / 원리
- LACP(Link Aggregation Control Protocol): 동적 그룹 협상·관리
- 논리 채널(Port-Channel/Bond): 묶인 물리 포트의 단일 논리 인터페이스
- 해시 분산: 출발/목적지 MAC·IP·포트 기반으로 트래픽 분배
- 액티브/스탠바이 또는 액티브/액티브 이중화
- 링크 장애 시 잔여 링크로 자동 재분산

## Ⅲ. 흐름도 / 구조
```text
스위치A ═══ Link1 ═══ 스위치B
        ═══ Link2 ═══         → 1개 논리채널(Port-Channel)
        ═══ Link3 ═══
 흐름 해시(SA/DA·IP·포트) → 링크 선택(흐름 단위 분산)
 Link2 장애 → Link1/3로 자동 재분산(무중단)
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 대역폭 집성과 링크 이중화로 가용성·성능 향상 |
| 장점 | 무중단 장애 복구, 점진적 대역폭 확장, STP 차단 회피 |
| 한계 | 단일 흐름은 1링크로 제한(해시 편중), 양단 동일 설정 필요 |

## Ⅴ. 기술사적 적용
- 정적(Static) vs 동적(LACP) 구성 비교, LACP 권장(장애 감지)
- MLAG/vPC로 서로 다른 스위치 간 이중화 집성 구현
- 서버 NIC 티밍·코어 업링크 대역폭 확장에 적용
