## Ⅰ. 정의
> 하나의 큰 IP(Internet Protocol) 네트워크를 서브넷마스크의 호스트 비트를 빌려 여러 개의 작은 논리적 네트워크로 분할하는 기법으로, IP 주소 활용 효율과 브로드캐스트 도메인 분리를 달성한다.

## Ⅱ. 구성요소 / 원리
- 서브넷마스크(Subnet Mask): 네트워크 비트(1)와 호스트 비트(0)를 구분
- IP 주소와 서브넷마스크의 비트 AND 연산으로 네트워크 주소 산출
- 호스트 비트를 n개 차용 → 서브넷 수 2^n, 서브넷당 호스트 수 2^(잔여비트)-2
- 각 서브넷의 첫 주소(네트워크), 마지막 주소(브로드캐스트)는 호스트 할당 불가
- 분할 단위는 비트 경계(2의 거듭제곱) 기준

## Ⅲ. 흐름도 / 구조
```text
원본: 192.168.1.0/24 (호스트 254)
  마스크 /26 (255.255.255.192)로 2비트 차용
  → 4개 서브넷 (2^2)
  .0/26 | .64/26 | .128/26 | .192/26
  각 서브넷: 네트워크+62호스트+브로드캐스트
  IP AND Mask = 네트워크 주소
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | IP 주소 낭비 최소화 및 브로드캐스트 도메인 축소를 통한 트래픽 격리 |
| 장점 | 보안 분리, 관리 단순화, 라우팅 효율 향상 |
| 한계 | 서브넷당 2개 주소(네트워크·브로드캐스트) 손실, 균등 분할 시 비효율 발생 |

## Ⅴ. 기술사적 적용
- 부서·계층별 망 분리 설계 시 VLAN(Virtual LAN)과 결합하여 적용
- 불균등 요구 시 VLSM(Variable Length Subnet Mask)으로 가변 분할 확장
- CIDR(Classless Inter-Domain Routing) 표기(/n)와 연계하여 클래스리스 주소 설계
