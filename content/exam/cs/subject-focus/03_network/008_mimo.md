## Ⅰ. 정의
> 송신·수신단에 다수의 안테나를 배치하여 동일 시간·주파수 자원에서 여러 데이터 스트림을 공간적으로 전송함으로써 용량과 신뢰성을 높이는 무선 기술이다.

## Ⅱ. 구성요소 / 원리
- 공간다중화(Spatial Multiplexing): 독립 스트림을 병렬 전송하여 용량을 안테나 수에 비례해 증대
- 다이버시티(Diversity): 동일 신호를 다중 경로로 전송, 페이딩 극복·신뢰성 향상
- 빔포밍 결합: 안테나 가중치로 신호 방향성 부여, 간섭 억제
- SU-MIMO(Single-User): 단일 사용자에 다중 스트림, MU-MIMO(Multi-User): 다수 사용자 동시 서비스
- 채널추정(CSI)·프리코딩(Precoding)으로 스트림 간 간섭을 분리

## Ⅲ. 흐름도 / 구조
```text
        Tx 안테나        무선채널 H        Rx 안테나
 데이터→[프리코딩]→ ▒▒▒(공간 경로)▒▒▒ →[검출]→ 데이터
   Tx1 ───────────╲╱─────────── Rx1
   Tx2 ───────────╱╲─────────── Rx2   (H 행렬로 스트림 분리)
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 추가 대역폭 없이 공간 차원을 활용해 용량·신뢰성 동시 향상 |
| 장점 | 안테나 수에 비례한 용량 증대(공간다중화), 페이딩 극복(다이버시티) |
| 한계 | 정확한 CSI 필요, 안테나 간 상관·산란 부족 시 이득 저하, 복잡도·전력 증가 |

## Ⅴ. 기술사적 적용
- 5G NR은 Massive MIMO(64T64R 이상)와 MU-MIMO로 셀 용량 대폭 확대
- Wi-Fi 5/6는 MU-MIMO로 다수 단말 동시 전송 효율 향상
- 빔포밍과 결합해 mmWave 대역의 경로손실을 보상하고 커버리지 확보
