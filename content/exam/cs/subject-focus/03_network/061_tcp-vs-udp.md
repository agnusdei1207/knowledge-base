## Ⅰ. 정의
> TCP는 연결지향·신뢰성 전송계층 프로토콜이고, UDP는 비연결·비신뢰의 경량 전송계층 프로토콜로, 신뢰성과 속도의 트레이드오프에 따라 선택된다.

## Ⅱ. 구성요소 / 원리
- 연결성: TCP는 3-way 핸드셰이크로 연결 수립, UDP는 연결 없이 즉시 전송
- 신뢰성: TCP는 ACK·재전송·순서보장, UDP는 보장 없음(손실·순서 무보장)
- 제어: TCP는 흐름제어(슬라이딩 윈도우)·혼잡제어, UDP는 없음
- 헤더: TCP 20바이트(가변), UDP 8바이트 고정(경량)
- 전송단위: TCP 바이트스트림, UDP 메시지(데이터그램) 단위

## Ⅲ. 흐름도 / 구조
```text
TCP: [Syn->SynAck->Ack] -> 데이터(순서/ACK/재전송) -> [Fin 종료]
       신뢰성O, 오버헤드 큼
UDP: [송신] -> 데이터그램 즉시 전송(ACK 없음) -> [수신]
       신뢰성X, 지연 작음, 헤더 8B
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | TCP=신뢰성 보장, UDP=저지연·저오버헤드 전송 |
| 장점 | TCP=무손실·순서보장 / UDP=경량·실시간·브로드캐스트 |
| 한계 | TCP=오버헤드·지연 / UDP=손실·순서·혼잡제어 부재 |

## Ⅴ. 기술사적 적용
- TCP: HTTP/웹·파일전송·메일 등 정확성 중시 응용에 적용
- UDP: VoIP·스트리밍·DNS·게임 등 실시간성 중시 응용에 적용
- QUIC/HTTP3는 UDP 기반에 신뢰성·암호화를 응용계층에서 구현(혼합형)
