## Ⅰ. 정의
> 라우팅은 패킷 전달 경로를 결정하는 과정으로, 관리자가 경로를 수동 설정하는 정적 라우팅과 라우팅 프로토콜로 경로를 자동 학습·갱신하는 동적 라우팅으로 구분된다.

## Ⅱ. 구성요소 / 원리
- 정적 라우팅: 관리자가 목적지 네트워크와 next-hop을 수동 등록
- 동적 라우팅: 프로토콜(RIP/OSPF/BGP)이 이웃과 정보 교환해 자동 경로 계산
- 라우팅 테이블: 목적지 네트워크·next-hop·메트릭·인터페이스 정보 저장
- 디폴트 라우트(0.0.0.0/0): 테이블에 일치 항목 없을 때 사용하는 마지막 경로
- 동적은 토폴로지 변화 감지 시 자동 재수렴(Convergence)

## Ⅲ. 흐름도 / 구조
```text
[정적]  관리자 ── 수동 입력 ──→ 라우팅 테이블 (고정)
[동적]  R1 ⇄ R2 ⇄ R3  프로토콜 광고 교환
          ↓ 메트릭 계산
        라우팅 테이블 자동 갱신
   장애 발생 → 재수렴 → 대체 경로 자동 반영
패킷: 목적지 Longest Prefix Match → next-hop
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 패킷의 목적지까지 최적 경로 결정 및 망 변화 대응 |
| 장점 | 정적=단순·예측가능·저부하 / 동적=확장성·자동복구·관리효율 |
| 한계 | 정적=대규모·변동망 부적합 / 동적=프로토콜 오버헤드·수렴지연·보안 고려 |

## Ⅴ. 기술사적 적용
- 소규모·스텁(Stub) 망, 보안 경계는 정적 라우팅+디폴트 라우트 적용
- 대규모·다중경로 망은 OSPF/BGP 등 동적 라우팅 채택
- 하이브리드: 핵심망은 동적, 종단은 정적으로 혼용 설계
