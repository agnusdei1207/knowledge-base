## Ⅰ. 1교시 핵심 답안

> NAT는 사설 주소와 공인 주소 간의 변환 기술이며, PAT는 포트 번호까지 활용해 다수 사설 호스트를 하나의 공인 IP로 다중화하는 방식이다.

- **목적**: IPv4 주소 절감, 내부망 은닉
- **유형**: Static NAT, Dynamic NAT, PAT
- **핵심 구조**: 주소/포트 변환 테이블
- **출제 포인트**: 주소 절감과 종단간 투명성 저하의 상충

## Ⅱ. 구조 및 동작 원리

```text
내부 호스트            NAT/PAT 장비                외부 서버
10.0.0.10:3000  -> 203.0.113.5:40001 -> 8.8.8.8:80
10.0.0.11:3000  -> 203.0.113.5:40002 -> 8.8.8.8:80
```

- **Static NAT**: 1:1 고정 변환
- **Dynamic NAT**: 주소 풀 내 동적 1:1 변환
- **PAT**: 공인 IP 1개에 포트 번호를 매핑하여 다중 사용자 수용
- **동작 핵심**: 변환 테이블 기반으로 왕복 세션 유지

## Ⅲ. 비교표

| 구분 | Static NAT | Dynamic NAT | PAT |
|:---|:---|:---|:---|
| 변환 형태 | 1:1 고정 | 1:1 동적 | N:1 |
| 주소 절감 효과 | 낮음 | 중간 | 높음 |
| 대표 용도 | 서버 공개 | 주소 풀 운영 | 인터넷 공유 |
| 한계 | 주소 낭비 | 풀 소진 가능 | 응용 호환성 문제 |

## Ⅳ. 기술사 답안 포인트

- **장점**: IPv4 공인주소 절감, 내부 주소 은닉
- **한계**: `End-to-End` 투명성 저하, P2P/VoIP/IPsec 제약
- **보완**: 포트포워딩, ALG, STUN/TURN/ICE, NAT-T
- **확장 논점**: IPv6 보급과 함께 NAT 의존도 감소, NAT64는 전환 기술

## Ⅴ. 결론

NAT·PAT는 IPv4 시대의 현실적 해법이지만, 본질적으로는 주소 부족을 우회한 기술이다.  
따라서 답안에서는 `주소절감 효과`와 함께 `종단간 구조 훼손`이라는 한계를 같이 적는 것이 핵심이다.
