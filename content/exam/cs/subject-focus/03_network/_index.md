# 03. 네트워크 주제 정리

본 폴더는 `1교시 핵심 답안`을 먼저 제시하고, 같은 페이지에서 `2~4교시 확장 논점`까지 바로 이어 쓸 수 있도록 정리한다.

## 활용 기준

| 구분 | 답안 운용 방식 |
|:---|:---|
| 1교시 | 정의 1문장 + 핵심어 3~4개 + 비교 1개 |
| 2~4교시 | 구조/동작 원리 + 비교표 + 설계/운영 판단 |
| 빈출 관점 | 계층 구분, 주소 체계, 경로 제어, 전송 품질, 소프트웨어화 |

## 작성 패턴

각 페이지는 다음 흐름을 고정한다.

1. `Ⅰ. 1교시 핵심 답안`에서 단답형 베이스 확보
2. `Ⅱ. 구조 및 동작 원리`에서 메커니즘 전개
3. `Ⅲ. 비교표`에서 서술형 확장 포인트 정리
4. `Ⅳ. 기술사 답안 포인트`에서 설계·운영·장애 대응 논리 정리
5. `Ⅴ. 결론`에서 적용 기준과 방향성 정리
