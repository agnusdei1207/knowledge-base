## Ⅰ. 1교시 핵심 답안

> STP는 L2 이중화 환경에서 브리지 루프를 방지하기 위해 논리적으로 트리 구조를 형성하는 프로토콜이며, RSTP는 수렴 속도를 개선한 고속 버전이다.

- **핵심 메시지**: 물리 루프는 허용, 논리 루프는 차단
- **주요 요소**: `BPDU`, `Root Bridge`, `Root Port`, `Designated Port`
- **RSTP 특징**: 빠른 포트 전이, 대체 포트 활용
- **출제 포인트**: 루프 방지와 수렴 시간 비교

## Ⅱ. 구조 및 동작 원리

```text
SW1 ---- SW2
 |        |
 |        |
SW3 ---- SW4

1) Root Bridge 선출
2) 최적 경로 포트 선정
3) 루프 유발 포트 차단
4) 장애 시 대체 경로 활성화
```

- **STP**: BPDU 교환 후 일부 포트를 차단하여 트리 형성
- **RSTP**: Alternate/Backup Port를 활용해 빠른 우회 전환
- **목적**: 브로드캐스트 스톰, MAC Flapping, 중복 프레임 방지

## Ⅲ. 비교표

| 구분 | STP | RSTP |
|:---|:---|:---|
| 표준 | 802.1D | 802.1w |
| 수렴 속도 | 상대적으로 느림 | 빠름 |
| 포트 상태 전이 | 단계 많음 | 단순화 |
| 운영 적합성 | 구형 환경 | 현대 캠퍼스 스위칭 |

## Ⅳ. 기술사 답안 포인트

- **장애 대응**: 링크 장애 시 차단 포트 활성화로 우회 경로 확보
- **운영 한계**: 일부 링크가 대기 상태라 대역폭 활용 비효율
- **비교 확장**: `STP-RSTP-MSTP`, `STP vs EVPN/VXLAN`
- **연계 주제**: VLAN Trunk, 이중화, 루프 방지 설계

## Ⅴ. 결론

STP 계열의 핵심은 `루프 제거`와 `수렴 특성`이다.  
STP는 물리적 이중화 링크 중 일부를 논리적으로 차단해 브로드캐스트 스톰과 MAC Flapping을 방지하고, RSTP는 대체 포트와 빠른 상태 전이를 통해 장애 후 수렴 시간을 단축한다.
