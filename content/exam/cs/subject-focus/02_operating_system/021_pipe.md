## Ⅰ. 정의
> 한 프로세스의 출력을 다른 프로세스의 입력으로 연결하는 단방향 바이트 스트림 기반 IPC(프로세스 간 통신) 메커니즘.

## Ⅱ. 구성요소 / 원리
- 익명 파이프(Anonymous): 부모-자식 등 혈연 프로세스 간 사용
- 명명 파이프(Named Pipe, FIFO): 파일시스템 경로로 무관 프로세스도 연결
- 단방향: 읽기단(read end)·쓰기단(write end) 분리
- 커널 버퍼: FIFO 큐로 바이트 순서 보존
- 흐름제어: 버퍼 가득 시 블로킹, 빈 버퍼 read 블로킹

## Ⅲ. 흐름도 / 구조
```text
 익명파이프:  Writer ─write()─> [Kernel Buffer(FIFO)] ─read()─> Reader
                                (단방향 byte stream)

 명명파이프:  ProcA ──> /tmp/myfifo ──> ProcB
              (mkfifo 경로로 무관 프로세스 연결)
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 간단·고속의 단방향 프로세스 간 데이터 전달 |
| 장점 | 사용 간편, 셸 파이프라인 자연 지원, 흐름제어 내장 |
| 한계 | 단방향·바이트스트림(메시지 경계 없음), 양방향 시 2개 필요 |

## Ⅴ. 기술사적 적용
- 셸 파이프라인(cmd1 | cmd2): 익명 파이프로 표준출력→표준입력 연결
- FIFO로 데몬-클라이언트 비동기 알림 채널 구성
- 양방향 통신은 소켓·메시지큐가 더 적합(파이프는 2개 필요)
