## Ⅰ. 정의
> 페이지테이블(Page Table)은 페이지번호를 프레임번호로 사상하는 자료구조로, 거대한 테이블 크기 문제를 해결하기 위해 다단계·역페이지테이블 등으로 구성한다.

## Ⅱ. 구성요소 / 원리
- 단일 페이지테이블: 페이지 수만큼 항목, 주소공간이 크면 테이블도 거대화
- 다단계(Multi-level): 페이지테이블을 페이지화하여 계층 구성, 미사용 영역 미할당으로 절감
- 역페이지테이블(Inverted): 프레임 단위로 1개 테이블만 유지, 물리메모리 크기에 비례
- 해시·TLB로 역페이지테이블 탐색 시간 보완

## Ⅲ. 흐름도 / 구조
```text
[다단계]  p1 → [외부PT] → p2 → [내부PT] → f → 물리주소
[역PT]    (pid, p) ─해시─▶ [역페이지테이블] 항목i → 프레임 i
          항목 수 = 물리 프레임 수 (논리주소공간 무관)
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 페이지테이블 메모리 사용량 절감 및 대용량 주소공간 지원 |
| 장점 | 다단계는 희소공간 절약, 역PT는 물리크기 비례 고정 |
| 한계 | 다단계는 변환 단계 증가, 역PT는 탐색·공유 어려움 |

## Ⅴ. 기술사적 적용
- 64비트 주소공간은 다단계(4단계 등) 페이지테이블이 표준
- 역페이지테이블은 메모리 절감에 유리하나 해시·TLB 결합 필수
