## Ⅰ. 정의
> 스와핑(Swapping)은 메모리에 있는 프로세스를 일시적으로 백업저장소(Backing Store, 디스크)로 내보내고(Swap-out), 필요 시 다시 메모리로 들여오는(Swap-in) 메모리 관리 기법이다.

## Ⅱ. 구성요소 / 원리
- Swap-out: 우선순위가 낮거나 대기 중인 프로세스를 디스크 스왑 영역으로 이동
- Swap-in: 실행 대상 프로세스를 메모리로 재적재
- 백업저장소: 빠른 접근이 가능한 전용 디스크 스왑 영역 사용
- 문맥교환(Context Switch) 시간 = 스왑 전송시간이 지배적, 전송량 최소화가 관건

## Ⅲ. 흐름도 / 구조
```text
[메인메모리]                 [백업저장소(디스크)]
  P1(실행)  ──── Swap-out ───▶  P2 (대기)
  P2(적재)  ◀─── Swap-in ─────  P3
  ▲ 메모리 부족 시 LRU/우선순위 기반 교체
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 물리 메모리보다 큰 다중프로그래밍 정도(Degree) 확보 |
| 장점 | 메모리 부족 환경에서 다수 프로세스 동시 실행 |
| 한계 | 디스크 입출력 비용 큼, 잦은 스왑 시 성능 저하 |

## Ⅴ. 기술사적 적용
- 실행시간 바인딩 시 스왑-인 위치 변경 가능, MMU 재배치와 연계
- 현대 OS는 프로세스 전체 대신 페이지 단위 스와핑(Paging)으로 효율화, 가상메모리 기반
