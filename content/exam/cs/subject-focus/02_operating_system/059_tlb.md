## Ⅰ. 정의
> TLB(Translation Lookaside Buffer)는 페이지번호→프레임번호 변환 정보를 저장하는 고속 연관 캐시로, 페이지테이블 접근 지연을 줄여 주소변환을 가속한다.

## Ⅱ. 구성요소 / 원리
- 연관 메모리(Associative Memory): 페이지번호 키로 병렬 검색
- TLB Hit: 변환 정보 적중 시 즉시 프레임 획득, TLB Miss: 페이지테이블 접근 후 TLB 갱신
- 유효접근시간(EAT, Effective Access Time) = 적중률 기반 평균 접근시간 계산
- 문맥교환 시 ASID(Address Space ID) 또는 Flush로 일관성 유지

## Ⅲ. 흐름도 / 구조
```text
논리주소[p|d] → [TLB 검색]
                 ├ Hit  → f 획득 → 물리주소
                 └ Miss → 페이지테이블 → f → TLB 갱신 → 물리주소
EAT = Hit율×(TLB+메모리) + Miss율×(TLB+메모리+메모리)
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 페이지테이블 이중 접근을 캐시로 단축 |
| 장점 | 높은 적중률 시 변환 시간 대폭 감소 |
| 한계 | 용량 제한, 문맥교환 시 Flush/관리 오버헤드 |

## Ⅴ. 기술사적 적용
- 페이징의 변환 성능을 결정하는 핵심 요소, EAT로 정량 평가
- ASID 도입으로 문맥교환 Flush 최소화, 다단계 페이지테이블의 지연 보완
