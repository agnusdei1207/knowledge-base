## Ⅰ. 정의
> 준비 큐(Ready Queue)에 도착한 순서대로 CPU(Central Processing Unit)를 할당하는 가장 단순한 비선점(Non-preemptive) 스케줄링 알고리즘이다.

## Ⅱ. 구성요소 / 원리
- 선입선출(FIFO, First-In First-Out) 큐 기반으로 도착 순서대로 처리
- 비선점: 한 번 CPU를 받으면 종료 또는 I/O 전환까지 점유
- 구현 단순, 도착 시각 기준 공정하나 실행시간 무시
- 긴 작업이 앞서면 뒤의 짧은 작업들이 장시간 대기 → 호위효과(Convoy Effect)
- 평균 대기시간이 작업 도착 순서에 크게 좌우됨

## Ⅲ. 흐름도 / 구조
```text
도착순:  P1(24) -> P2(3) -> P3(3)
[Ready FIFO 큐]  P1 | P2 | P3
타임라인: |--- P1(0~24) ---|P2(24~27)|P3(27~30)|
대기시간: P1=0, P2=24, P3=27  -> 평균 17 (호위효과)
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 도착 순서 기반의 단순·공정한 CPU 할당 |
| 장점 | 구현 용이, 기아(Starvation) 없음, 오버헤드 최소 |
| 한계 | 호위효과로 평균 대기시간 증가, 응답시간 예측 곤란 |

## Ⅴ. 기술사적 적용
- 대화형보다 배치 시스템에 적합, 단독 사용보다 보조 정책으로 활용
- 호위효과 완화 위해 SJF·RR 등과 결합·대체 검토
- MLFQ(다단계 피드백 큐)의 최하위 큐 등에서 기본 정책으로 채택
