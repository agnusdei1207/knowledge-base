## Ⅰ. 정의
> CPU(Central Processing Unit) 스케줄링 알고리즘의 우열을 평가·비교하기 위한 정량적 성능 척도로, 시스템 관점과 사용자 관점 지표로 구분된다.

## Ⅱ. 구성요소 / 원리
- CPU 이용률(Utilization): 단위시간 중 CPU가 일하는 비율, 높을수록 좋음
- 처리량(Throughput): 단위시간당 완료된 프로세스 수, 높을수록 좋음
- 반환시간(Turnaround Time): 제출~완료 총 소요시간(대기+실행+I/O), 짧을수록 좋음
- 대기시간(Waiting Time): 준비 큐(Ready Queue)에서 기다린 총 시간, 짧을수록 좋음
- 응답시간(Response Time): 요청 후 첫 반응까지 시간, 대화형에서 핵심

## Ⅲ. 흐름도 / 구조
```text
제출 --대기--> [Ready] --실행--> 첫 응답 ----...---- 완료
 |<-------- 반환시간(Turnaround) ----------------->|
 |<-- 대기시간 -->|        |<-응답시간(첫 반응)->|
시스템 지표: CPU 이용률 / 처리량   사용자 지표: 반환·대기·응답
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 알고리즘 성능을 객관적·정량적으로 비교 평가 |
| 장점 | 워크로드 특성별 최적 알고리즘 선택의 판단 근거 제공 |
| 한계 | 지표 간 상충(처리량↑ vs 응답시간↓) 동시 최적화 곤란 |

## Ⅴ. 기술사적 적용
- 배치 시스템은 처리량·이용률, 대화형은 응답시간 우선 설계
- SJF는 평균 대기시간 최소, RR은 응답시간 우수로 목적별 선택
- 평균값뿐 아니라 분산(예측 가능성)도 실시간 시스템에서 고려
