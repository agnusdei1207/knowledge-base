## Ⅰ. 정의
> 작업의 마감시간(Deadline) 준수를 최우선으로 하는 스케줄링으로, 주기적 태스크에 정적 우선순위를 주는 RM과 마감 임박순으로 동적 배정하는 EDF가 대표적이다.

## Ⅱ. 구성요소 / 원리
- RM(Rate Monotonic): 주기가 짧을수록(주파수 높을수록) 높은 정적 우선순위 부여
- EDF(Earliest Deadline First): 마감시간이 가장 가까운 작업에 동적 우선순위 부여
- 경성(Hard) 실시간은 마감 위반 시 치명적, 연성(Soft)은 성능 저하
- 스케줄 가능성(Schedulability): RM은 이용률 한계, EDF는 ≤100% 이용률 보장
- 둘 다 선점형, 마감 기반 우선순위 결정

## Ⅲ. 흐름도 / 구조
```text
[주기 태스크 집합 (주기 T, 실행 C, 마감 D)]
   |                                |
 RM: 주기↓ -> 우선순위↑ (정적, 고정)
 EDF: 마감 임박 -> 우선순위↑ (동적, 매 시점 재평가)
   |                                |
 선점형 실행 -> 마감 준수 검증(이용률 테스트)
```

## Ⅳ. 핵심 특징 (RM vs EDF 비교)
| 구분 | 내용 |
|:---|:---|
| 목적 | 마감시간 보장으로 실시간 응답성·결정성 확보 |
| 장점 | RM=구현 단순·예측 용이(정적), EDF=이용률 100%·최적(동적) |
| 한계 | RM=이용률 한계(n→∞ 시 약 69%), EDF=과부하 시 도미노 붕괴 |

## Ⅴ. 기술사적 적용
- RM 스케줄 가능 조건: ΣC_i/T_i ≤ n(2^(1/n)−1) (Liu & Layland)
- EDF는 단일 처리기에서 이용률 ≤ 1이면 항상 스케줄 가능(최적)
- 항공·자동차 등 경성 실시간은 RM(정적 분석 용이), 유연 환경은 EDF
