## Ⅰ. 정의
> 인터럽트(Interrupt)는 CPU의 정상 실행 흐름을 중단시키고 즉각적인 처리가 필요한 이벤트를 알리는 신호로, 인터럽트 서비스 루틴(ISR, Interrupt Service Routine)을 수행한 후 원래 흐름으로 복귀하는 비동기·동기 이벤트 처리 메커니즘이다.

## Ⅱ. 구성요소 / 원리
- **하드웨어 인터럽트(HW Interrupt)**: 외부 장치(I/O, 타이머)가 발생시키는 비동기 신호
- **소프트웨어 인터럽트(Trap)**: 명령어(시스템콜)에 의한 의도적·동기적 인터럽트
- **예외(Exception)**: 0으로 나누기·페이지 폴트 등 명령 실행 중 오류
- **인터럽트 벡터(Interrupt Vector)**: 인터럽트 번호별 ISR 주소를 담은 테이블
- **ISR(Interrupt Service Routine)**: 인터럽트 종류에 따라 실행되는 처리 루틴

## Ⅲ. 흐름도 / 구조
```text
[정상 실행] CPU 명령 수행
      │ 인터럽트 신호 발생
      ▼
현재 상태(PC/레지스터) 저장 → 인터럽트 벡터 조회
      │
      ▼
ISR(인터럽트 서비스 루틴) 수행
      │ 처리 완료
      ▼
저장 상태 복원 → 중단 지점부터 실행 재개
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 폴링(Polling) 없이 이벤트를 즉시 처리하여 CPU 효율 향상 |
| 장점 | 비동기 처리, 응답성 확보, 다중 장치 동시 대응 |
| 한계 | 중첩·우선순위 관리 복잡, 컨텍스트 저장/복원 오버헤드 |

### 인터럽트 비교표
| 구분 | 하드웨어 인터럽트 | 소프트웨어 인터럽트(Trap) | 예외(Exception) |
|:---|:---|:---|:---|
| 발생원인 | 외부 장치 신호 | 명령어(시스템콜) | 명령 실행 오류 |
| 동기성 | 비동기 | 동기 | 동기 |
| 예시 | 타이머, 키보드, I/O | `int 0x80`, syscall | 0 나누기, 페이지 폴트 |

## Ⅴ. 기술사적 적용
- 시스템콜(Trap)·문맥교환·선점 스케줄링의 트리거로 동작
- DMA·인터럽트 결합(Interrupt Coalescing)으로 고성능 I/O 처리
- 인터럽트 우선순위(IRQ)·마스킹으로 실시간(RTOS) 응답성 보장
