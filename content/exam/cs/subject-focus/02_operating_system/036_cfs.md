## Ⅰ. 정의
> 리눅스 커널 2.6.23부터 도입된 기본 CPU(Central Processing Unit) 스케줄러로, 가상 실행시간(vruntime)을 기준으로 모든 프로세스에 공정한 CPU 시간을 배분한다.

## Ⅱ. 구성요소 / 원리
- 가상 실행시간(vruntime): 프로세스가 실제 사용한 CPU 시간을 가중치로 정규화한 값
- 레드블랙 트리(Red-Black Tree): vruntime을 키로 하는 자가균형 이진탐색트리, O(log n)
- 항상 vruntime이 가장 작은(가장 적게 실행된) 프로세스를 다음에 선택
- nice 값 기반 가중치로 우선순위 반영(낮은 nice = 큰 가중치 = vruntime 천천히 증가)
- 목표 지연(Target Latency) 내 모든 태스크가 1회 실행되도록 시간 분배

## Ⅲ. 흐름도 / 구조
```text
[Red-Black Tree] 키=vruntime, 최좌측=최소 vruntime
        선택: 최좌측 노드(가장 적게 실행) -> 실행
        실행 후: vruntime += 실행시간/가중치
        -> 트리 재삽입(재균형, O(log n))
가중치: nice 낮음 -> vruntime 느리게 증가 -> 더 자주 선택
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 이상적 멀티태스킹의 완전 공정한 CPU 시간 배분 근사 |
| 장점 | O(log n) 효율, 우선순위 자연 반영, 기아 없음, 대화형 우수 |
| 한계 | 트리 연산 오버헤드, 실시간 보장 부재(별도 RT 클래스 필요) |

## Ⅴ. 기술사적 적용
- 기존 O(1) 스케줄러를 대체하며 휴리스틱 없이 공정성 모델 구현
- 경성 실시간은 SCHED_FIFO·SCHED_RR 등 별도 정책 클래스로 처리
- 후속 EEVDF(Earliest Eligible Virtual Deadline First) 스케줄러로 진화
