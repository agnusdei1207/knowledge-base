## Ⅰ. 정의
> 요구페이징(Demand Paging)은 프로세스 전체를 미리 적재하지 않고 실제 참조되는 페이지만 필요 시점에 메모리로 적재하는 지연 적재(Lazy Loading) 방식의 가상메모리 기법이다.

## Ⅱ. 구성요소 / 원리
- 유효/무효 비트(Valid/Invalid Bit): 페이지가 메모리에 있는지 표시
- 무효 비트 접근 시 페이지부재(Page Fault) 발생 → 백업저장소에서 적재
- 지연 적재로 초기 적재 비용·메모리 사용량 절감
- 요구페이징 + 순수요구페이징(Pure Demand Paging): 처음엔 무적재로 시작

## Ⅲ. 흐름도 / 구조
```text
페이지 참조 ──▶ [페이지테이블 유효비트 확인]
                 ├ Valid   → 메모리 접근
                 └ Invalid → 페이지부재(Trap)
                              → 디스크에서 프레임 적재
                              → 유효비트 갱신 → 재시작
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 필요한 페이지만 적재해 메모리 효율 극대화 |
| 장점 | 빠른 프로세스 시작, 물리메모리 초과 프로그램 실행 |
| 한계 | 페이지부재 처리 지연, 부재율 높으면 성능 저하 |

## Ⅴ. 기술사적 적용
- 페이지부재 처리 흐름·페이지교체 알고리즘과 직접 연계
- 워킹셋·PFF(Page Fault Frequency)로 부재율을 관리해 스래싱 방지
