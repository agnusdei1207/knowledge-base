## Ⅰ. 정의
> 여러 우선순위 큐를 두고 프로세스의 실행 행태에 따라 큐 간 이동을 허용하는 적응형 스케줄링 알고리즘으로, 사전 정보 없이 작업 특성을 학습한다.

## Ⅱ. 구성요소 / 원리
- 다단계 큐(Multilevel Queue): 우선순위별 복수 준비 큐, 각 큐는 자체 정책(RR 등)
- 피드백(Feedback): 실행 행태에 따라 프로세스를 상·하위 큐로 동적 이동
- 강등: 퀀텀(Time Quantum)을 모두 소진한 CPU 집중 작업은 하위 큐로 이동
- 승격: 입출력(I/O) 빈번·대화형 작업은 상위 큐 유지·승격
- 에이징(Aging)·주기적 재배치로 기아(Starvation) 방지

## Ⅲ. 흐름도 / 구조
```text
Q0 (퀀텀 8, 최고)  -- 퀀텀 소진 --> 강등
Q1 (퀀텀 16)       -- 퀀텀 소진 --> 강등
Q2 (FCFS, 최저)    <-- 주기적 승격(에이징) --
선택: 상위 큐 우선, 비면 하위 큐. I/O 작업=상위 유지
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 작업 특성 사전 정보 없이 응답성과 처리량 동시 최적화 |
| 장점 | 짧은·대화형 작업 우대, 긴 작업도 점진 처리, 적응적 |
| 한계 | 파라미터(큐 수·퀀텀·강등 기준) 설정 복잡, 튜닝 의존 |

## Ⅴ. 기술사적 적용
- 다단계 큐(고정 배치) 대비 큐 간 이동 허용이 핵심 차별점
- SJF의 효과를 예측 없이 근사 실현(짧은 작업 우대)
- 전통 유닉스·윈도우 스케줄러의 설계 기반으로 광범위 채택
