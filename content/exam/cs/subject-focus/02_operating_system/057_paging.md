## Ⅰ. 정의
> 페이징(Paging)은 논리메모리를 고정 크기의 페이지(Page)로, 물리메모리를 동일 크기의 프레임(Frame)으로 나누어 비연속 할당하는 메모리 관리 기법이다.

## Ⅱ. 구성요소 / 원리
- 페이지/프레임: 동일한 고정 크기 단위, 논리=페이지, 물리=프레임
- 페이지테이블(Page Table): 페이지번호→프레임번호 사상 정보 저장
- 논리주소 = 페이지번호(p) + 오프셋(d), 물리주소 = 프레임번호(f) + 오프셋(d)
- 비연속 할당으로 외부단편화 해소, 마지막 페이지에 내부단편화 잔존

## Ⅲ. 흐름도 / 구조
```text
논리주소 [ p | d ]
           │
           ▼
   [페이지테이블] p → f
           │
           ▼
물리주소 [ f | d ] → 메모리(프레임)
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 비연속 할당으로 외부단편화 제거, 가상메모리 기반 제공 |
| 장점 | 외부단편화 없음, 페이지 공유·보호 용이 |
| 한계 | 페이지테이블 메모리 오버헤드, 내부단편화 발생 |

## Ⅴ. 기술사적 적용
- 페이징은 요구페이징(Demand Paging)·가상메모리 구현의 토대
- 페이지테이블 접근 지연은 TLB(Translation Lookaside Buffer)로 보완
