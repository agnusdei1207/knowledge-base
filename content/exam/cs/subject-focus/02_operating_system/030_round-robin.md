## Ⅰ. 정의
> 각 프로세스에 동일한 시간 할당량(Time Quantum)을 부여하고 만료 시 선점하여 순환 처리하는 시분할(Time-sharing) 기반 선점형 스케줄링 알고리즘이다.

## Ⅱ. 구성요소 / 원리
- 타임 퀀텀(Time Quantum): 각 프로세스에 부여되는 고정 CPU(Central Processing Unit) 점유 시간
- 퀀텀 만료 시 타이머 인터럽트로 선점, 준비 큐(Ready Queue) 맨 뒤로 이동
- 순환 큐(Circular Queue)를 통한 라운드(순번) 방식의 공정 분배
- 퀀텀이 작으면 응답성↑·문맥교환 오버헤드↑, 크면 FCFS에 수렴
- 일반적으로 퀀텀은 80% CPU 버스트가 끝나도록 설정 권장

## Ⅲ. 흐름도 / 구조
```text
[Ready 순환 큐] P1 -> P2 -> P3 -> (P1) ...
실행: |P1 q|P2 q|P3 q|P1 q|...  (q=퀀텀)
퀀텀 만료 -> 선점 -> 큐 맨 뒤로
퀀텀↓: 응답↑/오버헤드↑    퀀텀↑: FCFS화/응답↓
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 시분할 환경에서 모든 프로세스에 공정한 응답성 보장 |
| 장점 | 기아 없음, 응답시간 우수, 대화형 시스템에 적합 |
| 한계 | 문맥교환 오버헤드, 퀀텀 크기 설정의 트레이드오프 |

## Ⅴ. 기술사적 적용
- 시분할·대화형 운영체제의 기본 스케줄링 정책으로 채택
- 우선순위 RR, MLFQ 등 다단계 큐의 각 레벨 정책으로 확장
- 퀀텀 동적 조정으로 워크로드 변화에 적응적 대응
