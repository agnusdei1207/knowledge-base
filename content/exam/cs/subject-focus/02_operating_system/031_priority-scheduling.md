## Ⅰ. 정의
> 각 프로세스에 우선순위(Priority)를 부여하고 가장 높은 우선순위 프로세스에게 CPU(Central Processing Unit)를 할당하는 스케줄링 알고리즘이다.

## Ⅱ. 구성요소 / 원리
- 우선순위 결정: 내부(시간제한·메모리·버스트) 또는 외부(중요도·요금) 요인
- 선점형: 더 높은 우선순위 도착 시 실행 프로세스 선점
- 비선점형: 준비 큐(Ready Queue) 맨 앞에 배치, 현재 작업 종료 후 적용
- 기아(Starvation): 낮은 우선순위 프로세스가 무한정 대기하는 문제
- 에이징(Aging): 대기시간에 비례해 우선순위를 점진적으로 상향 조정

## Ⅲ. 흐름도 / 구조
```text
[Ready] 우선순위별 정렬  P_high -> ... -> P_low
            |
   최고 우선순위 선택 -> 실행 (선점형: 높은 것 도착 시 선점)
            |
낮은 순위 장기 대기 -> 기아 -> [에이징] 시간↑마다 순위↑ -> 해소
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 중요도 기반 차등 자원 배분으로 핵심 작업 우선 처리 |
| 장점 | 긴급·중요 작업 신속 처리, 정책 유연성 우수 |
| 한계 | 기아 발생, 우선순위 역전(Priority Inversion) 위험 |

## Ⅴ. 기술사적 적용
- 기아는 에이징으로, 우선순위 역전은 우선순위 상속 프로토콜로 해결
- 실시간 시스템의 RM(Rate Monotonic)·EDF 등 핵심 기반
- MLFQ는 우선순위 스케줄링에 큐 간 동적 이동을 결합한 형태
