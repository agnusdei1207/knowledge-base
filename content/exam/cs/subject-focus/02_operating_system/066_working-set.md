## Ⅰ. 정의
> 워킹셋(Working Set)은 일정 시간 윈도우(Δ) 동안 프로세스가 실제로 참조한 페이지의 집합으로, 지역성(Locality)에 기반해 프로세스가 필요로 하는 프레임 수를 추정하는 모델이다.

## Ⅱ. 구성요소 / 원리
- 워킹셋 윈도우(Δ, Delta): 최근 참조를 관찰하는 시간 구간 크기
- 워킹셋 크기(WSS): 윈도우 내 참조된 서로 다른 페이지 수
- 총 수요 D = Σ WSS, D가 가용 프레임 초과 시 스래싱 발생 → 프로세스 일시 중단
- Δ가 너무 작으면 지역성 누락, 너무 크면 여러 지역성 중첩

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 지역성 기반 필요 프레임 추정으로 스래싱 방지 |
| 장점 | 프로세스별 적정 프레임 할당, 다중 정도 조절 |
| 한계 | 윈도우 Δ 설정·워킹셋 추적 오버헤드 |

## Ⅴ. 기술사적 적용
- 스래싱 방지 핵심 모델, PFF(Page Fault Frequency)와 상호 보완
- 지역성 원리에 근거하여 요구페이징의 프레임 할당 정책 결정
