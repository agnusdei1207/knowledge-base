## Ⅰ. 정의
> 사용자 스레드(User Thread)를 커널 스레드(Kernel Thread)에 대응시키는 방식으로, 매핑 비율에 따라 1:1·N:1·N:M(다대다) 모델로 구분.

## Ⅱ. 구성요소 / 원리
- 사용자 스레드: 사용자 라이브러리(예: pthread)가 관리
- 커널 스레드: 커널이 스케줄링하는 실제 실행 단위
- 1:1(일대일): 사용자 1 ↔ 커널 1, 진정한 병렬·블로킹 독립
- N:1(다대일): 사용자 N ↔ 커널 1, 빠른 전환·병렬 불가
- N:M(다대다): 사용자 N ↔ 커널 M, 균형형(스레드 풀)

## Ⅲ. 흐름도 / 구조
```text
 1:1            N:1                N:M
 U  U  U        U U U              U U U U
 |  |  |         \|/                \ | /
 K  K  K          K               K   K  (M<N)
(병렬 O)      (병렬 X)           (병렬 O, 균형)
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 병렬성·전환비용·확장성의 최적 절충 |
| 장점 | 1:1 병렬성, N:1 경량성, N:M 양자 균형 |
| 한계 | 1:1 커널부담↑, N:1 단일블로킹 전체정지, N:M 구현복잡 |

## Ⅴ. 기술사적 적용
- Linux·Windows: 1:1 모델 채택(멀티코어 병렬 활용)
- N:M: 스케줄러 활성화(Scheduler Activation)로 블로킹 통지 구현
- 다수 동시연결 서버는 N:M·경량 코루틴(고루틴) 모델 검토
