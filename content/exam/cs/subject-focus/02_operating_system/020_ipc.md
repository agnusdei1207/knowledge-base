## Ⅰ. 정의
> 프로세스 간 통신(Inter-Process Communication). 독립된 주소공간을 가진 프로세스들이 데이터를 교환·동기화하기 위한 운영체제 제공 메커니즘.

## Ⅱ. 구성요소 / 원리
- 공유 메모리(Shared Memory): 공통 메모리 영역 매핑, 직접 접근
- 메시지 전달(Message Passing): send/receive 시스템콜로 교환
- 동기화 수단: 세마포어·뮤텍스로 경쟁조건 방지
- 직접/간접 통신: 상대 명시 vs 메일박스(포트) 경유
- 동기/비동기(blocking/non-blocking) 송수신 방식

## Ⅲ. 흐름도 / 구조
```text
[공유메모리]  ProcA ─write─> [Shared Mem] <─read─ ProcB
                          (세마포어로 동기화)

[메시지전달]  ProcA ─send()─> [커널 큐/메일박스] ─receive()─> ProcB
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 분리된 프로세스 간 데이터 공유·협력 |
| 장점 | 공유메모리 고속, 메시지전달 동기화 내장·구현 용이 |
| 한계 | 공유메모리 동기화 부담, 메시지전달 복사·커널개입 비용 |

## Ⅴ. 기술사적 적용
| 구분 | 공유 메모리 | 메시지 전달 |
|:---|:---|:---|
| 속도 | 빠름(복사 없음) | 상대적 느림(커널 경유) |
| 동기화 | 별도 필요 | 내장(블로킹) |
| 적합 | 대용량·고빈도 | 분산·소량 메시지 |
