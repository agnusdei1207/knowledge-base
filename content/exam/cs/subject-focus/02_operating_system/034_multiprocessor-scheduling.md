## Ⅰ. 정의
> 복수의 CPU(Central Processing Unit)·코어 환경에서 프로세스를 각 처리기에 배분하는 스케줄링으로, 부하균등과 프로세서 친화성의 균형이 핵심 과제이다.

## Ⅱ. 구성요소 / 원리
- 대칭형 다중처리(SMP, Symmetric Multiprocessing): 각 처리기가 독립 스케줄링
- 비대칭형: 하나의 마스터 처리기가 스케줄링 전담
- 부하균등(Load Balancing): 처리기 간 작업량 균등화(Push/Pull 마이그레이션)
- 프로세서 친화성(Affinity): 프로세스를 동일 처리기에 묶어 캐시 재사용
- 공유 준비 큐(전역) vs 처리기별 큐(지역) 설계 트레이드오프

## Ⅲ. 흐름도 / 구조
```text
        [작업 집합]
       /     |      \
   CPU0    CPU1    CPU2   (각자 Ready 큐 또는 공유 큐)
     |       |       |
 부하 불균형 감지 -> Push/Pull 마이그레이션 -> 균등화
 친화성: 캐시 데이터 보존 위해 동일 CPU 유지(균등화와 상충)
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 다중 처리기 자원의 효율적 활용과 처리량 극대화 |
| 장점 | 병렬 처리로 성능 향상, 확장성, 장애 격리 |
| 한계 | 부하균등 vs 친화성 상충, 캐시 일관성·동기화 비용 |

## Ⅴ. 기술사적 적용
- 부하균등은 처리량↑, 친화성은 캐시 적중률↑ → 워크로드별 절충
- NUMA(Non-Uniform Memory Access) 환경은 메모리 지역성까지 고려
- 리눅스 CFS는 처리기별 런큐와 주기적 부하균등을 병행 적용
