## Ⅰ. 정의
> 5명의 철학자가 원탁에서 좌우 젓가락 2개를 모두 잡아야 식사할 수 있는 모델로, 교착(Deadlock)과 기아(Starvation)를 설명하는 고전적 동기화 문제.

## Ⅱ. 구성요소 / 원리
- 자원: 젓가락 5개(각 철학자 좌우 공유)
- 동작: 생각 → 좌측 젓가락 → 우측 젓가락 → 식사 → 반납
- 교착 조건: 모두 동시에 왼쪽을 잡으면 순환대기(Circular Wait) 성립
- 각 젓가락을 세마포어(이진)로 모델링
- 기아: 양쪽 이웃이 계속 점유 시 특정 철학자 굶음

## Ⅲ. 흐름도 / 구조
```text
        P0
   c0 /    \ c4
   P1        P4
   c1 \      / c3
      P2 -- P3
        c2
모두 좌측 동시 점유 → 우측 대기 → 순환대기(교착)
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 다중자원 점유 시 교착·기아 현상 시연 |
| 장점 | 동기화 해법 검증용 표준 벤치마크 |
| 한계 | 단순 세마포어 해법은 교착·기아 모두 노출 |

## Ⅴ. 기술사적 적용
- 해법1: 자원 순서화(Resource Ordering) — 젓가락 번호 오름차순 획득
- 해법2: 비대칭 — 짝수는 좌측, 홀수는 우측 먼저
- 해법3: 동시 식사 인원 N-1 제한, 또는 Monitor로 두 젓가락 원자 획득
