## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 운영체제는 CPU·메모리·저장장치를 추상화·보호하며 자원 경쟁을 조정하는 자원 관리자다.
> 2. **가치**: 프로세스·스케줄링·동기화·메모리·파일시스템이 한 축으로 연결되어 응용 서비스의 성능과 안정성을 결정한다.
> 3. **판단 포인트**: 단답은 정의·상태 전이·조건 암기, 서술은 성능과 안정성의 트레이드오프 설계로 갈린다.

## Ⅱ. 1교시 단답형 핵심 (앞단위)

| 키워드 | 한줄 정의 | 핵심 3포인트 |
|:---|:---|:---|
| 문맥 교환(Context Switch) | 실행 프로세스 전환 시 CPU 상태(레지스터·PC)를 PCB에 저장·복원하는 동작 | ① PCB/TCB 저장 ② 순수 오버헤드 ③ TLB·캐시 플러시 동반 |
| 시스템 호출(System Call) | 사용자 모드가 커널 서비스를 요청하는 인터페이스 | ① 모드 비트 전환 ② POSIX 표준 ③ 트랩 기반 진입 |
| 프로세스 제어 블록(PCB) | 프로세스 상태·자원을 담은 커널 자료구조 | ① PID·상태·PC ② 레지스터·스케줄링 정보 ③ 메모리·I/O 정보 |
| 스레드(Thread) | 코드·데이터·힙을 공유하는 경량 실행 단위 | ① 스택·레지스터만 독립 ② 응답성·경제성 ③ 사용자/커널 수준 |
| 쓰기 시 복사(Copy-on-Write) | fork() 후 쓰기 시점에만 페이지를 복제하는 최적화 | ① 즉시 복사 회피 ② 메모리 절약 ③ 쓰기 시 페이지 폴트 |
| 좀비/고아 프로세스 | 종료 후 미회수(좀비)·부모 선종료(고아) 상태 | ① wait() 미호출 ② init 입양 ③ 자원 누수 위험 |
| 라운드 로빈(Round Robin) | 시간 할당량 기반 선점형 시분할 스케줄링 | ① Time Quantum ② 공정성 ③ 퀀텀↔문맥교환 절충 |
| 다단계 피드백 큐(MLFQ) | 큐 간 승급·강등을 허용하는 적응형 스케줄링 | ① 다중 우선순위 큐 ② 동적 이동 ③ 노화로 기아 방지 |
| 세마포어(Semaphore) | wait(P)/signal(V) 원자 연산 기반 동기화 정수 | ① 이진·카운팅 ② 자원 풀 관리 ③ 블로킹(Sleep&Wakeup) |
| 뮤텍스 락(Mutex) | 소유권 기반 상호 배제 락 | ① acquire/release ② 소유 스레드만 해제 ③ 우선순위 역전 주의 |
| 모니터(Monitor) | 상호 배제를 자동 보장하는 고수준 동기화 구조 | ① 조건 변수 ② Signal&Wait/Continue ③ 언어 차원 지원 |
| 교착상태(Deadlock) | 자원을 점유한 채 서로 무한 대기하는 상태 | ① 4조건 동시 성립 ② 자원할당그래프 사이클 ③ 예방/회피/탐지 |
| 은행원 알고리즘(Banker's) | 안전 상태 검사로 교착을 회피하는 기법 | ① Available·Max·Allocation·Need ② 안전 순서 ③ 사전 최대수요 필요 |
| 페이지 부재(Page Fault) | 미적재 페이지 접근 시 발생하는 트랩 | ① 유효-무효 비트 ② 마이너/메이저 ③ EAT 성능 좌우 |
| LRU 교체 | 가장 오래 미사용 페이지를 교체하는 알고리즘 | ① 시간 지역성 활용 ② 타임스탬프/스택 ③ 클록(2차 기회)로 근사 |
| 스래싱(Thrashing) | 실행보다 페이징에 더 많은 시간을 쓰는 현상 | ① 프레임 부족 ② 워킹셋 모델 ③ PFF로 동적 조절 |
| TLB(Translation Look-aside Buffer) | 주소 변환 캐시 하드웨어 | ① Hit/Miss ② EAT 단축 ③ ASID로 플러시 최소화 |
| 디스크 스케줄링(SCAN/C-SCAN) | 탐색 시간 최소화를 위한 헤드 이동 정책 | ① 엘리베이터 ② C-SCAN 균등화 ③ LOOK 최적화 |
| RAID | 다중 디스크로 성능·신뢰성을 확보하는 구성 | ① 0 스트라이핑 ② 1 미러링 ③ 5 분산 패리티 |
| 저널링 파일시스템(Journaling) | 크래시 시 로그로 일관성을 복구하는 FS | ① 메타/데이터 저널 ② 로그→커밋→반영 ③ ext4·NTFS |
| 컨테이너(Container) | 네임스페이스·cgroups 기반 OS 수준 가상화 | ① 자원 격리 ② 자원 제어 ③ 경량·고밀도 |
| eBPF(Extended Berkeley Packet Filter) | 커널 내 안전 샌드박스 프로그램 실행 기술 | ① 관측 가능성 ② 네트워킹·보안 ③ 커널 무수정 확장 |

> **1교시 답안 공식**: 정의 1문장 → 핵심 3포인트(원리/효과/한계) → ASCII 도해 3줄 + 미니표 2~3행 → 적용·비교 1줄.

## Ⅲ. 2~4교시 서술형 확장 (심화)

### 1) CPU 스케줄링 비교·설계
- **정의**: 준비 큐의 프로세스 중 CPU를 할당할 대상을 선택하는 단기 스케줄링 정책.
- **전개 가이드**: Ⅰ개요(반환·대기·응답시간 기준) → Ⅱ구조(준비큐·디스패처·디스패치 지연) → Ⅲ알고리즘 특징(FCFS 호위효과·SJF/SRTF·RR·MLFQ·CFS) → Ⅳ적용(서버 처리량 vs 데스크톱 응답성, PREEMPT_RT) → Ⅴ결론(워크로드별 선택 기준).
- **권장 비교표**: 아래 스케줄링 비교표 / **도해**: 준비큐→디스패처→실행→타이머 인터럽트 흐름도.

| 알고리즘 | 선점 | 기준 | 장점 | 한계 |
|:---|:---:|:---|:---|:---|
| FCFS | 비선점 | 도착 순서 | 단순·공정 | 호위 효과 |
| SJF/SRTF | 선택 | 버스트 길이 | 최소 평균 대기 | 기아·예측 필요 |
| RR | 선점 | 시간 할당량 | 응답성·공정 | 퀀텀↔문맥교환 절충 |
| MLFQ | 선점 | 동적 우선순위 | 적응형 | 파라미터 튜닝 |
| CFS | 선점 | vruntime | 공정·확장성 | RT 보장 약함 |

### 2) 병행성·동기화 메커니즘
- **정의**: 임계 구역의 상호 배제·진행·한정 대기를 보장해 경쟁 조건을 제거하는 기법.
- **전개 가이드**: Ⅰ개요(Race Condition·임계구역 3조건) → Ⅱ원리(하드웨어 Test-and-Set/CAS, 스핀락·세마포어·모니터) → Ⅲ비교(바쁜 대기 vs 블로킹, 락 vs Lock-free·RCU) → Ⅳ적용(우선순위 역전→상속/올림, TOCTOU 방어) → Ⅴ결론(경합도 기반 선택).
- **권장 비교표**: 동기화 기법 비교표 / **도해**: 진입→임계구역→퇴출→잔여 구역 폐루프.

| 기법 | 대기 방식 | 소유권 | 적합 상황 |
|:---|:---|:---:|:---|
| 스핀락 | 바쁜 대기 | 무 | 짧은 임계구역·멀티코어 |
| 뮤텍스 | 블로킹 | 유 | 일반 상호 배제 |
| 세마포어 | 블로킹 | 무 | 자원 풀·순서 제어 |
| 모니터 | 조건 변수 | 유 | 고수준 언어 동기화 |
| RCU | 락 프리 읽기 | 무 | 읽기 다수·쓰기 소수 |

### 3) 교착상태 처리
- **정의**: 대기 중인 프로세스들이 점유한 자원을 서로 기다려 영원히 진행하지 못하는 상태.
- **전개 가이드**: Ⅰ개요(4 필요조건) → Ⅱ구조(자원할당그래프·대기 그래프) → Ⅲ처리 비교(예방·회피·탐지/복구·무시) → Ⅳ적용(은행원 알고리즘, 락 순서화·Lockdep, 타임아웃) → Ⅴ결론(현실적 절충=타조+탐지).
- **권장 비교표**: 예방/회피/탐지 비교표 / **도해**: P→R 요청·할당 간선 사이클.

| 처리 전략 | 원리 | 장점 | 한계 |
|:---|:---|:---|:---|
| 예방 | 4조건 중 하나 부정 | 발생 원천 차단 | 자원 효율 저하 |
| 회피 | 안전 상태 유지(은행원) | 동적 허용 | 최대수요 사전 필요·오버헤드 |
| 탐지/복구 | 주기 점검 후 해소 | 자원 활용 높음 | 탐지 비용·롤백 |
| 무시(타조) | 무대응 | 단순·저비용 | 드물게 치명적 |

### 4) 가상 메모리·페이지 교체 튜닝
- **정의**: 물리 메모리보다 큰 주소 공간을 요구 페이징으로 지원하는 메모리 추상화.
- **전개 가이드**: Ⅰ개요(요구 페이징·지역성) → Ⅱ원리(페이지 폴트 6단계, 프레임 할당) → Ⅲ교체 알고리즘(OPT·FIFO/Belady·LRU·클록·LFU) → Ⅳ적용(워킹셋·PFF로 스래싱 제어, Huge Page·ZRAM, NUMA) → Ⅴ결론(EAT·부재율 기반 최적화).
- **권장 비교표**: 페이지 교체 비교표 / **도해**: 참조→유효비트 검사→폴트→교체→매핑.

| 알고리즘 | 기준 | 장점 | 한계 |
|:---|:---|:---|:---|
| OPT | 미래 최장 미사용 | 최적·비교 기준 | 구현 불가 |
| FIFO | 적재 순서 | 단순 | Belady 모순 |
| LRU | 최근 미사용 | 지역성 반영 | 하드웨어 비용 |
| 클록(2차 기회) | 참조 비트 | LRU 근사·저비용 | 정밀도 낮음 |

### 5) 저장장치·파일시스템 신뢰성
- **정의**: 파일을 논리적으로 추상화하고 디스크/SSD 블록에 할당·보호하는 계층.
- **전개 가이드**: Ⅰ개요(VFS·inode) → Ⅱ구조(할당: 연속·연결·색인·익스텐트, 빈공간 비트맵) → Ⅲ신뢰성(저널링·LFS·COW 스냅샷, RAID) → Ⅳ적용(SSD FTL·웨어레벨링·TRIM, NVMe, 분산 FS) → Ⅴ결론(성능·일관성·내구성 균형).
- **권장 비교표**: RAID 레벨 비교표 / **도해**: VFS→파일객체→inode→블록 매핑.

## Ⅳ. 출제 포인트 & 함정

| 출제유형 | 1교시 단답 포인트 | 2~4교시 서술 포인트 |
|:---|:---|:---|
| 스케줄링 | RR·MLFQ·CFS 정의, Time Quantum | 워크로드별 알고리즘 선택 기준·CFS vruntime 설계 |
| 동기화 | 세마포어·뮤텍스·모니터 차이 | 락 경합 해소·RCU/Lock-free·우선순위 역전 대책 |
| 교착상태 | 4조건·은행원 자료구조 | 예방/회피/탐지 절충·복구 희생자 선택 |
| 가상 메모리 | 페이지 폴트·LRU·스래싱 | 워킹셋/PFF 튜닝·Huge Page·NUMA 배치 |
| 저장/파일 | RAID·저널링·TRIM | SSD FTL·COW 스냅샷·분산 FS 일관성 |

**자주 빠지는 함정**
- 뮤텍스(소유권 有) vs 이진 세마포어(소유권 無) 혼동.
- 다중 인스턴스 자원에서 그래프 사이클을 곧 교착으로 단정(필요조건일 뿐).
- Belady 모순을 모든 알고리즘에 적용(스택 알고리즘 LRU는 무관).
- 스핀락을 단일 코어·긴 임계구역에 사용(바쁜 대기 낭비).
- 약어 풀네임 미표기(eBPF, COW, MLFQ 등 최초 1회 병기 필수).

## Ⅴ. 최신 기술 동향 + 공부 노트 연결

- **커널 관측 가능성**: 확장 버클리 패킷 필터(eBPF) 기반 트레이싱·보안 정책, perf/ftrace.
- **클라우드 네이티브**: 컨테이너 런타임, 네임스페이스·컨트롤 그룹(cgroups), io_uring 비동기 I/O.
- **메모리·보안 격리**: 커널 페이지 테이블 격리(KPTI), Meltdown/Spectre 대응, 메모리 암호화(Intel SGX, AMD SEV).
- **경량 가상화**: 마이크로 가상머신(MicroVM), 유니커널(Unikernel), 하드웨어 보조 가상화(Intel VT-x/AMD-V).
- **실시간·전력**: PREEMPT_RT, 에너지 인지 스케줄링(EAS), 틱리스 커널.
