## Ⅰ. 정의
> 세그멘테이션(Segmentation)은 프로그램을 코드·데이터·스택 등 논리적 단위(세그먼트)로 나누어 가변 크기로 메모리에 할당하는 사용자 관점의 메모리 관리 기법이다.

## Ⅱ. 구성요소 / 원리
- 세그먼트: 논리적 의미 단위(함수, 배열, 스택 등), 가변 길이
- 세그먼트테이블: 각 세그먼트의 기준(Base)과 한계(Limit) 저장
- 논리주소 = 세그먼트번호(s) + 오프셋(d), d < limit 검사로 보호
- 가변 크기 할당으로 외부단편화 발생, 페이징과 결합(세그먼트 페이징) 가능

## Ⅲ. 흐름도 / 구조
```text
논리주소 [ s | d ]
           │
   [세그먼트테이블] s → (base, limit)
           │  d < limit ?  NO→Trap
           ▼  YES
물리주소 = base + d → 메모리
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 논리 단위별 관리로 공유·보호를 자연스럽게 지원 |
| 장점 | 사용자 관점 일치, 세그먼트 단위 공유·보호 용이 |
| 한계 | 가변 크기로 외부단편화 발생 |

## Ⅴ. 기술사적 적용
- 페이징(고정·물리관점) 대비 세그멘테이션은 가변·논리관점, 결합 시 장점 통합
- 세그먼트 페이징(Paged Segmentation)으로 외부단편화 제거 + 논리 단위 보존
