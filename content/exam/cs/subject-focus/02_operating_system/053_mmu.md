## Ⅰ. 정의
> MMU(Memory Management Unit)는 CPU가 생성한 논리주소를 물리주소로 실시간 변환하는 하드웨어 장치로, 재배치 레지스터를 이용해 메모리 보호와 동적 재배치를 수행한다.

## Ⅱ. 구성요소 / 원리
- 재배치 레지스터(Relocation/Base Register): 프로세스의 물리 시작주소를 논리주소에 가산
- 한계 레지스터(Limit Register): 논리주소 범위를 검사하여 메모리 보호(불법 접근 차단)
- 주소변환 회로: 논리주소 + 재배치값 = 물리주소 계산
- 페이징/세그멘테이션 환경에서는 페이지테이블·TLB(Translation Lookaside Buffer)와 결합

## Ⅲ. 흐름도 / 구조
```text
CPU ──논리주소(d)──▶ [한계레지스터 비교]
                         │ d < limit ? 
                  NO ◀───┴───▶ YES
              (Trap:주소오류)   │
                          [재배치레지스터(+base)]
                                 │
                                 ▼
                            물리주소 → 메모리
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 논리→물리 주소변환 및 프로세스 간 메모리 보호 |
| 장점 | 하드웨어 변환으로 고속, 동적 재배치·스와핑 지원 |
| 한계 | 추가 HW 필요, 단순 구조는 외부단편화 미해결 |

## Ⅴ. 기술사적 적용
- MMU는 가상메모리 구현의 핵심 HW로 페이징·세그멘테이션의 주소변환을 담당
- TLB와 결합해 변환 지연을 줄이고, 한계 레지스터로 메모리 격리(Isolation) 보장
