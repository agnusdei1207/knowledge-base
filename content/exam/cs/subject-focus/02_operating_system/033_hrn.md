## Ⅰ. 정의
> 대기시간과 서비스시간을 함께 고려한 응답률(Response Ratio)이 가장 높은 프로세스를 선택하는 비선점 스케줄링으로, SJF의 기아(Starvation) 문제를 보완한다.

## Ⅱ. 구성요소 / 원리
- 응답률 = (대기시간 + 서비스시간) / 서비스시간
- 서비스시간이 짧을수록 응답률↑ → SJF처럼 짧은 작업 우대
- 대기시간이 길수록 응답률↑ → 긴 작업도 시간 경과로 선택됨(에이징 효과 내장)
- 비선점: 작업 완료 시점마다 응답률 재계산해 다음 작업 선택
- 서비스시간(CPU 버스트) 추정값이 필요

## Ⅲ. 흐름도 / 구조
```text
[작업 완료 시점] 모든 대기 작업의 응답률 계산
응답률 R = (대기시간 W + 서비스시간 S) / S = 1 + W/S
        |
  R 최대 작업 선택 -> 실행(비선점)
긴 작업도 W 증가 -> R 증가 -> 결국 선택(기아 방지)
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 짧은 작업 우대와 기아 방지의 균형 달성 |
| 장점 | SJF 효율 + 대기시간 반영으로 기아 없음, 공정성 우수 |
| 한계 | 작업 완료마다 응답률 재계산 오버헤드, 서비스시간 추정 필요 |

## Ⅴ. 기술사적 적용
- SJF의 기아 문제에 대한 대표적 비선점 보완 알고리즘
- 응답률에 대기시간을 내재화하여 별도 에이징 불필요
- 배치 환경에서 처리량과 공정성을 동시 고려할 때 적용
