## Ⅰ. 정의
> 둘 이상의 프로세스가 서로 점유한 자원을 무한히 기다려 어느 쪽도 진행 못 하는 상태로, 4가지 조건이 동시 성립할 때만 발생.

## Ⅱ. 구성요소 / 원리
- 상호배제(Mutual Exclusion): 자원을 한 번에 한 프로세스만 사용
- 점유대기(Hold and Wait): 자원 보유 중 추가 자원 대기
- 비선점(No Preemption): 자원을 강제로 빼앗을 수 없음
- 순환대기(Circular Wait): 대기 사슬이 원형으로 폐쇄
- 4조건 동시 충족이 필요충분(예방은 하나만 깨면 됨)

## Ⅲ. 흐름도 / 구조
```text
   P1 ──보유 R1──► (R2 요청 대기)
   ▲                        │
   │보유 R2                  ▼
   P2 ◄──(R1 요청 대기)── 순환대기 성립
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 교착 발생 조건 규명으로 예방 전략 도출 |
| 장점 | 4조건 중 1개만 차단해도 교착 원천 방지 |
| 한계 | 차단 시 자원이용률 저하·비용 증가 동반 |

## Ⅴ. 기술사적 적용
- 자원할당그래프(RAG): 사이클 존재 + 단일 인스턴스 → 교착
- 예방: 점유대기→일괄할당, 비선점→선점허용, 순환대기→자원 순서화
- 후속: 회피(은행원 알고리즘)·탐지·복구 전략과 연계
