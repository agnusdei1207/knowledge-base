## Ⅰ. 정의
> 쓰기 시 복제(Copy-On-Write). fork() 직후 부모·자식이 동일 물리 페이지를 읽기전용으로 공유하다가, 어느 한쪽이 쓰기를 시도할 때 비로소 해당 페이지만 복제하는 지연 복사 기법.

## Ⅱ. 구성요소 / 원리
- fork 시 페이지 테이블만 복사, 물리 페이지는 공유
- 공유 페이지를 읽기전용(Read-Only)으로 표시
- 쓰기 발생 → 페이지 폴트(보호 위반) 트랩
- 커널이 해당 페이지만 복제 후 쓰기 가능으로 전환
- 변경 없는 페이지는 끝까지 공유(메모리 절약)

## Ⅲ. 흐름도 / 구조
```text
fork: Parent PT ─┐         ┌─ Child PT
                 ├─> [Page R/O 공유]
write 시도 ──> Page Fault(보호위반)
                 |
        커널: 해당 페이지 복제 + R/W 설정
                 |
       Parent[Page A] / Child[Page A']  (분리)
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | fork 복제비용 최소화, 메모리 효율 극대화 |
| 장점 | 즉시 전체복사 회피, fork-exec 시 낭비 제거 |
| 한계 | 첫 쓰기 시 페이지폴트·복제 지연, 관리 복잡 |

## Ⅴ. 기술사적 적용
- fork() 직후 exec() 패턴에서 불필요한 복사 완전 제거
- 가상화 스냅샷·메모리 디듀플리케이션(KSM) 기반 기술
- vfork()와 비교: 완전 공유로 더 빠르나 동시쓰기 위험
