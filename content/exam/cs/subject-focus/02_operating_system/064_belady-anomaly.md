## Ⅰ. 정의
> 벨라디 모순(Belady's Anomaly)은 할당 프레임 수를 늘렸음에도 오히려 페이지부재 횟수가 증가하는 역설적 현상으로, FIFO 등 비스택 알고리즘에서 발생한다.

## Ⅱ. 구성요소 / 원리
- 일반 기대: 프레임 증가 → 부재 감소, 그러나 FIFO에서 역전 발생
- 원인: FIFO는 적재 순서만 고려하여 프레임 집합의 포함관계(Subset)가 보장되지 않음
- 스택 알고리즘(LRU, OPT): n개 프레임 페이지집합 ⊆ n+1개 프레임 집합 → 모순 없음
- 특정 참조열에서 프레임 증가 시 부재가 늘어나는 사례 존재

## Ⅲ. 흐름도 / 구조
```text
참조열 입력
   │
[FIFO] 3프레임 → 부재 9회
[FIFO] 4프레임 → 부재 10회  ← 모순(증가)
   vs
[LRU/OPT] 프레임↑ → 부재↓ (스택 성질, 모순 없음)
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 프레임-부재 관계의 비단조성 현상 이해 |
| 장점 | 스택 알고리즘 선택의 이론적 근거 제공 |
| 한계 | FIFO 단순성의 대가, 예측 불가한 성능 저하 |

## Ⅴ. 기술사적 적용
- 교체 알고리즘 선정 시 스택 알고리즘(LRU/OPT) 우선 고려 근거
- FIFO 사용 시 프레임 증설이 성능 향상을 보장하지 않음에 유의
