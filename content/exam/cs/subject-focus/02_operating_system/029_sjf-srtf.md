## Ⅰ. 정의
> SJF는 CPU(Central Processing Unit) 버스트(Burst)가 가장 짧은 프로세스를 먼저 실행하는 비선점 알고리즘이며, SRTF는 잔여 실행시간이 가장 짧은 것을 선택하는 선점형 변형이다.

## Ⅱ. 구성요소 / 원리
- SJF(비선점): 다음 CPU 버스트가 최소인 작업 선택, 시작 후 비선점
- SRTF(선점): 새 프로세스 도착 시 잔여시간 비교해 더 짧으면 선점
- 주어진 작업 집합에서 평균 대기시간을 최소화하는 최적 알고리즘
- 미래 버스트 길이를 알 수 없어 지수 평균(Exponential Average)으로 예측
- 긴 작업은 계속 밀려 기아(Starvation) 발생 가능

## Ⅲ. 흐름도 / 구조
```text
[새 작업 도착]
     |
     v
다음 CPU 버스트(SJF) / 잔여시간(SRTF) 비교
     |
   최소값 선택 --(SRTF: 현재보다 짧으면 선점)--> 실행
예측식: τ(n+1) = α·t(n) + (1-α)·τ(n)
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 평균 대기·반환시간 최소화로 처리 효율 극대화 |
| 장점 | 이론상 최소 평균 대기시간 보장(최적), 처리량 우수 |
| 한계 | 버스트 예측 불확실, 긴 작업 기아, SRTF는 문맥교환 증가 |

## Ⅴ. 기술사적 적용
- 기아 보완책으로 HRN(응답률 기반) 또는 에이징(Aging) 병행
- 버스트 예측 정확도가 성능 좌우 → 지수 평균 가중치 α 조정
- 배치·일괄 처리 환경에서 작업시간 추정 가능 시 효과적
