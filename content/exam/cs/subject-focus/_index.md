# 과목별 시험 키워드

이 섹션은 `CS`의 공부 노트를 과목별로 다시 링크한 구조가 아닙니다.  
**컴퓨터시스템응용기술사 시험 답안용으로 새로 작성된 과목 허브**입니다.

## 보는 방식

- 각 과목 첫 화면은 `2~4교시 서술형 구조`를 먼저 봅니다.
- `1교시 단답형 앞단위`는 독립 암기용이 아니라 서술형 Ⅰ·Ⅱ·Ⅲ 단락의 재료입니다.
- 화면 아래로 내려가면 해당 과목의 **실제 키워드 페이지 목록**이 붙습니다.
- 키워드 페이지는 모두 `정의 → 구성요소·원리 → 흐름도 → 핵심 표 → 기술사 적용`으로 통일했습니다.

## 2~4교시 대응 우선순위

| 우선 | 과목군 | 대표 서술형 질문 |
|:---:|:---|:---|
| 1 | SW·AI·보안·클라우드 | MSA/DevSecOps/RAG/K8s/Zero Trust 도입·설계·운영 방안 |
| 2 | OS·DB·네트워크 | 스케줄링/동시성/트랜잭션/라우팅/혼잡제어 비교와 장애 대응 |
| 3 | 컴퓨터구조·빅데이터·데이터엔지니어링 | 병목 원인, 분산처리 구조, 데이터 파이프라인 설계 |
| 4 | IT경영·감리·엔터프라이즈·ICT융합 | ISP/EA/감리/디지털트윈/스마트팩토리의 단계별 적용 방안 |
