## Ⅰ. 정의
> 폴링(Polling)은 CPU가 주변장치의 상태 레지스터를 주기적으로 검사(loop)하여 입출력 준비 여부를 확인하는 동기식 I/O 처리 기법이다.

## Ⅱ. 구성요소 / 원리
- 상태 레지스터(Status Register)의 Ready/Busy 플래그 반복 검사
- 소프트웨어 루프 기반(busy-wait), 별도 하드웨어 신호 불필요
- 검사 주기(Polling interval) 설정에 따라 응답성·CPU 사용량 결정
- 고속·저지연 환경에서는 인터럽트보다 유리할 수 있음(컨텍스트 전환 회피)

## Ⅲ. 흐름도 / 구조
```text
   ┌──────────────┐
   │ Status 검사   │◄──┐
   └──────┬───────┘   │ Not Ready
          │ Ready     │
          ▼           │
   [데이터 전송] ──────┘
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 단순 구조의 장치 상태 확인 및 I/O 동기화 |
| 장점 | 구현 단순, 인터럽트 지연·문맥전환 없음, 예측가능 지연 |
| 한계 | busy-wait로 CPU 낭비, 다수 장치 시 비효율, 확장성 저하 |

## Ⅴ. 기술사적 적용
- 인터럽트 방식과 비교: 저빈도 장치는 인터럽트, 초고속은 폴링
- NVMe 드라이버의 폴링 모드(io_poll)로 지연 최소화
- DPDK·SPDK 등 커널 우회 고성능 I/O에서 폴링 채택
