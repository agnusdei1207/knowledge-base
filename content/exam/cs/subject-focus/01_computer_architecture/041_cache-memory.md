## Ⅰ. 정의
> CPU와 주기억장치 사이에 위치한 고속 소용량 버퍼 메모리로, 지역성을 이용해 자주 쓰는 데이터를 보관하여 평균 접근시간을 단축하는 장치.

## Ⅱ. 구성요소 / 원리
- L1: 코어 전용, 최고속·최소(수십 KB), 명령어(I)/데이터(D) 분리
- L2: 코어 전용/일부 공유, 중간 속도·용량(수백 KB)
- L3(LLC): 다중 코어 공유, 대용량(수 MB~수십 MB)
- 구성: 태그(Tag)·인덱스(Index)·오프셋(Offset) + 유효비트·더티비트
- 동작: 적중(Hit)이면 캐시 반환, 실패(Miss)면 하위 계층에서 블록 적재

## Ⅲ. 흐름도 / 구조
```text
CPU Core ─→ [L1 I/D] ─miss→ [L2] ─miss→ [L3 공유] ─miss→ DRAM
            hit↩           hit↩          hit↩
   상위일수록 빠르고 작다 / 하위일수록 느리고 크다
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | CPU-메모리 속도 격차 완화, 평균 접근시간(AMAT) 감소 |
| 장점 | 적중 시 수 클럭 내 응답, 다단계로 적중률·용량 균형 |
| 한계 | 멀티코어 캐시 일관성(Coherence) 비용, 용량 한계 |

## Ⅴ. 기술사적 적용
- 비교: 캐시 사상 방식·교체 알고리즘·쓰기 정책과 연계 설계
- 실무: MESI 일관성 프로토콜, 인클루시브/익스클루시브 캐시 정책
- 최신: V-Cache(3D 적층 L3), 비균일 캐시(NUCA)
