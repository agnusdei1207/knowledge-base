## Ⅰ. 정의
> 플립플롭은 1비트의 정보를 저장하는 가장 기본적인 순차회로 기억소자로, 클록 엣지에 동기되어 상태를 유지·변경하는 쌍안정(bistable) 회로이다.

## Ⅱ. 구성요소 / 원리
- SR-FF: Set/Reset 입력, S=R=1 금지 상태 존재
- D-FF(Data): 입력 D를 클록 엣지에 그대로 저장 — 레지스터 기본
- JK-FF: SR 개선, J=K=1이면 토글(toggle)
- T-FF(Toggle): T=1마다 출력 반전 — 카운터에 사용
- 엣지 트리거(Edge-triggered): 상승/하강 엣지에서만 동작 → 타이밍 안정

## Ⅲ. 흐름도 / 구조
```text
        ┌─────────────┐
  D ───▶│             ├──▶ Q
        │    D-FF     │
 CLK ──▶│ (edge trig) ├──▶ Q'
        └─────────────┘
  CLK ↑ 엣지 순간: Q ← D 로 래치
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 1비트 상태 저장·동기화, 레지스터/카운터 구성 단위 |
| 장점 | 엣지 트리거로 안정적 상태 보존, 종류별 용도 특화 |
| 한계 | 셋업/홀드 타임 위반 시 메타스테이빌리티 발생 |

## Ⅴ. 기술사적 적용
- 래치(Latch, 레벨 트리거) vs 플립플롭(엣지 트리거) 비교 포인트
- 레지스터·시프트레지스터·카운터·메모리 셀의 기본 구성요소
- 비동기 신호 입력 시 2단 FF(더블 플롭) 동기화로 안정성 확보
