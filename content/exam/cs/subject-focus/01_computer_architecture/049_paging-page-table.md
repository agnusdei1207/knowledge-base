## Ⅰ. 정의
> 페이징은 가상·물리 메모리를 고정 크기 페이지/프레임으로 분할해 매핑하는 기법이며, 페이지 테이블(Page Table)은 가상 페이지번호→물리 프레임번호 매핑을 저장하는 자료구조.

## Ⅱ. 구성요소 / 원리
- 페이지(Page)/프레임(Frame): 동일 고정 크기(예 4KB) 분할 단위
- 주소 = 페이지번호(VPN) + 페이지 오프셋(Offset)
- 페이지 테이블 엔트리(PTE): 프레임번호 + 유효·보호·더티·참조 비트
- 다단계 페이지 테이블: 희소 주소공간의 테이블 메모리 절감
- 외부 단편화 없음, 내부 단편화는 페이지 끝 일부 발생

## Ⅲ. 흐름도 / 구조
```text
VA = | VPN | Offset |
        ↓ 색인
  Page Table[VPN] → PFN(프레임번호)
        ↓
PA = | PFN | Offset |   (Offset은 그대로)
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 비연속 물리할당으로 외부 단편화 제거·메모리 관리 |
| 장점 | 외부 단편화 없음, 보호·공유·스왑 용이 |
| 한계 | 페이지 테이블 메모리 오버헤드, 변환 추가 접근(→TLB로 완화) |

## Ⅴ. 기술사적 적용
- 비교: 역페이지테이블(Inverted)로 대용량 주소공간 절감
- 실무: 다단계(4~5레벨) 페이지테이블 + Huge Page
- 최신: 가상화 2단계 변환(EPT), 스왑 압축(zswap)
