## Ⅰ. 정의
> 요구 페이징은 페이지를 실제 참조될 때만 메모리에 적재하는 기법이며, 페이지 폴트(Page Fault)는 미적재 페이지 접근 시 발생하는 예외로 디스크에서 적재를 유발한다.

## Ⅱ. 구성요소 / 원리
- 게으른 적재(Lazy Loading): 참조 시점에만 페이지 적재 → 초기 메모리 절약
- 유효 비트(Valid Bit): 페이지 메모리 상주 여부 표시
- 페이지 폴트 처리: 트랩 → 빈 프레임 확보 → 디스크 적재 → PTE 갱신 → 재실행
- 종류: Minor(메모리 내 존재)·Major(디스크 I/O 필요)
- 성능: 유효 접근시간 = (1−p)×메모리시간 + p×폴트처리시간

## Ⅲ. 흐름도 / 구조
```text
페이지 참조 → Valid? ─yes→ 정상 접근
              └no → Page Fault(Trap)
                   → 빈 프레임? (없으면 교체)
                   → 디스크에서 적재 → PTE valid=1 → 명령 재실행
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 필요한 페이지만 적재해 메모리 효율·기동속도 향상 |
| 장점 | 초기 적재량↓, 다중 프로그래밍 정도↑, 대용량 프로그램 실행 |
| 한계 | 폴트 시 디스크 I/O 지연(수만 배), 잦으면 스래싱 |

## Ⅴ. 기술사적 적용
- 비교: 선반입(Prepaging)으로 폴트 빈도 절감
- 실무: Copy-on-Write, mmap 기반 게으른 적재
- 최신: SSD/NVMe 스왑, zswap 압축으로 폴트 비용 절감
