## Ⅰ. 정의
> 다수의 독립 컴퓨터를 네트워크로 묶어 하나의 시스템처럼 활용하는 분산처리로, 근거리 밀결합 클러스터와 지역분산 이기종 자원을 결합한 그리드.

## Ⅱ. 구성요소 / 원리
- 클러스터: 동일·근접 노드를 고속 LAN으로 결합, 단일 관리 도메인
- 그리드: 지리적 분산·이기종 자원을 미들웨어로 가상 통합
- 클러스터는 HA·로드밸런싱·HPC 목적, 그리드는 대규모 자원 공유
- 노드 장애 시 페일오버(클러스터)·작업 재배치(그리드)

## Ⅲ. 흐름도 / 구조
```text
[Cluster] Node─Node─Node ─고속LAN─ 단일이미지
[Grid]    機關A자원 ─WAN/미들웨어─ 機關B자원 (가상통합)
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 비용효율적 고가용성·고성능·대규모 자원 활용 |
| 장점 | 클러스터=저지연·HA / 그리드=광역 자원·기관 간 협업 |
| 한계 | 클러스터=물리근접·확장한계 / 그리드=이기종·보안·지연 |

## Ⅴ. 기술사적 적용
- 클러스터 → HPC, 웹 서버 팜, DB 고가용성
- 그리드 → 과학 분산컴퓨팅(WLCG), 자원 공유
- 클라우드 컴퓨팅으로 진화(가상화·온디맨드 자원)
