## Ⅰ. 정의
> 프로세서 수가 늘면 처리할 문제 크기도 함께 커진다는 가정 아래, 병렬화로 얻는 속도향상이 직렬부에 의해 고정되지 않고 선형적으로 확장될 수 있음을 설명하는 법칙이다.

## Ⅱ. 구성요소 / 원리
- 속도향상 S = N − (1−P) × (N − 1)
  - 또는 S = (1−P) + P×N  (s: 직렬비율, p: 병렬비율, s+p=1 기준)
  - N: 프로세서 수, P: 병렬화 가능 비율
- 문제 크기를 N에 비례해 확장(Scaled Speedup)
- 직렬부 비중이 N 증가에 따라 상대적으로 감소
- 약확장(Weak Scaling) 모델 — 대규모 병렬에 유리

## Ⅲ. 흐름도 / 구조
```text
 N 증가 ⇒ 문제크기도 N 비례 확장
 S = (1−P) + P × N
   = N − (1−P)(N − 1)
 직렬부 영향 ↓ ⇒ 속도향상 ≈ 선형
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 대규모 데이터·병렬 환경의 현실적 확장성 설명 |
| 장점 | 선형 확장 가능성 제시, HPC·빅데이터 정당화 |
| 한계 | 문제 크기 무한 확장 가정, 메모리·통신 비용 미반영 |

## Ⅴ. 기술사적 적용
- 암달의 법칙(고정 크기·강확장)을 보완하는 약확장 모델
- HPC, 분산처리(MapReduce/Spark), GPU 대규모 병렬에 적용
- 빅데이터·AI 학습에서 데이터 병렬 확장 근거
