## Ⅰ. 정의
> 둘 이상의 동일한 프로세서가 단일 OS와 공유 메모리를 대칭적으로 공유하며 어떤 작업도 임의 프로세서가 처리하는 다중처리 구조.

## Ⅱ. 구성요소 / 원리
- 동일 프로세서 다수 + 단일 운영체제 인스턴스
- 공유 메모리·공유 I/O를 버스/인터커넥트로 연결
- 모든 프로세서 대등(대칭) — 마스터/슬레이브 구분 없음
- 캐시 일관성 프로토콜과 단일 실행 큐로 부하 분산

## Ⅲ. 흐름도 / 구조
```text
 P0   P1   P2   P3
  └────┴────┴────┘ (대칭)
       Bus
   [공유 Memory] [공유 I/O]
       단일 OS
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 단일 시스템 내 처리량 향상·부하 균등 분산 |
| 장점 | 단일 OS·이미지 관리 단순, 자원 공유 효율 |
| 한계 | 버스 경합으로 확장성 제한(보통 수~수십 코어), 일관성 비용 |

## Ⅴ. 기술사적 적용
- UMA 구조의 대표 구현, 멀티코어 PC·서버 기본형
- 비대칭(AMP) 대비 유연성↑, NUMA로 확장성 보완
- OS 스케줄러의 SMP 부하 분산·CPU 친화도(affinity)
