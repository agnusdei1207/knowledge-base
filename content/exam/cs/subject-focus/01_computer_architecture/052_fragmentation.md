## Ⅰ. 정의
> 메모리 할당·해제 반복으로 사용 가능한 공간이 조각나 활용되지 못하는 현상으로, 할당 단위 내부(Internal)·블록 사이(External)에서 발생한다.

## Ⅱ. 구성요소 / 원리
- 내부 단편화(Internal): 고정 크기 할당 시 요청보다 큰 영역 잔여(페이징 끝)
- 외부 단편화(External): 가변 할당 시 작은 빈 공간 산재(세그멘테이션)
- 발생 원인: 고정/가변 분할 방식, 잦은 동적 할당·해제
- 대응: 압축(Compaction), 페이징, 버디·슬랩 할당, 적합 알고리즘

## Ⅲ. 흐름도 / 구조
```text
Internal: [Req 3KB | 1KB 낭비]  ← 4KB 페이지 내부 잔여
External: [used][free 2KB][used][free 1KB] ← 합 3KB지만 분산
           → 5KB 요청 실패 (총량은 충분)
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적(이해) | 메모리 활용률 저하 원인 진단·완화 |
| 영향 | 가용 총량 대비 실제 할당 가능량 감소 |
| 대응 | 내부=페이지 크기 조정, 외부=압축·페이징 |

## Ⅴ. 기술사적 적용
- 비교: 페이징(외부 제거·내부 잔존) vs 세그멘테이션(외부 발생)
- 실무: 버디 시스템·슬랩 할당기로 커널 단편화 억제
- 최신: 메모리 압축·THP(Transparent Huge Page) 디프래그
