## Ⅰ. 정의
> 다중 프로세서의 메모리 접근 방식 분류로, 단일 주소공간을 공유하는 공유 메모리와 노드별 지역 메모리를 메시지로 교환하는 분산 메모리 구조.

## Ⅱ. 구성요소 / 원리
- 공유 메모리: 모든 프로세서가 공통 주소공간 접근, 변수 공유로 통신
- 분산 메모리: 각 노드가 독립 메모리 보유, 메시지 패싱(MPI)으로 통신
- 공유는 캐시 일관성·동기화 필요, 분산은 네트워크 통신 비용 발생
- 확장성: 분산 > 공유 / 프로그래밍 용이성: 공유 > 분산

## Ⅲ. 흐름도 / 구조
```text
[공유] P0 P1 P2 ─ Bus ─ [공통 Memory]
[분산] (P0|M0)─(P1|M1)─(P2|M2)  ↔ Network/Message
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 다중 프로세서의 데이터 접근·통신 모델 선택 |
| 장점 | 공유=프로그래밍 단순 / 분산=높은 확장성·비용효율 |
| 한계 | 공유=확장성·일관성 비용 / 분산=통신 지연·구현 복잡 |

## Ⅴ. 기술사적 적용
- 공유 메모리 → SMP·UMA/NUMA, OpenMP 모델
- 분산 메모리 → 클러스터·MPP, MPI 모델
- 하이브리드(DSM, Distributed Shared Memory)로 두 장점 결합
