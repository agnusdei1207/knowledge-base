## Ⅰ. 정의
> 조합논리회로는 현재 입력만으로 출력이 결정되는 회로이고, 순차논리회로는 현재 입력과 이전 상태(메모리)에 의해 출력이 결정되는 회로이다.

## Ⅱ. 구성요소 / 원리
- 조합회로: 입력 → 게이트망 → 출력, 기억소자 없음(가산기·디코더·MUX·ALU)
- 순차회로: 조합회로 + 기억소자(플립플롭) + 피드백 경로
- 동기식(Synchronous): 클록(Clock) 엣지에 맞춰 상태 변화 — 안정적
- 비동기식(Asynchronous): 입력 변화 즉시 상태 변화 — 빠르나 해저드 위험
- 상태천이: 현재상태+입력 → 다음상태(레지스터·카운터·FSM)

## Ⅲ. 흐름도 / 구조

| 구분 | 입력 | 처리 구조 | 상태 저장 | 출력 결정 기준 |
|:---|:---|:---|:---|:---|
| 조합논리회로 | 현재 입력 | 게이트 논리망 | 없음 | 현재 입력값 |
| 순차논리회로 | 현재 입력 + 현재 상태 | 조합 논리망 + 플립플롭 + 피드백 | 플립플롭/레지스터 | 입력값과 이전 상태 |

| 순차회로 동작 단계 | 내용 |
|:---:|:---|
| 1 | 현재 상태와 입력이 조합 논리망에 전달 |
| 2 | 조합 논리망이 출력과 다음 상태 계산 |
| 3 | 클록 엣지에서 플립플롭이 다음 상태 저장 |
| 4 | 저장된 상태가 다시 조합 논리망의 입력으로 피드백 |

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 조합=즉시 연산, 순차=상태 기억·제어 흐름 구현 |
| 장점 | 조합=단순·고속, 순차=메모리·카운팅·시퀀스 제어 가능 |
| 한계 | 조합=상태 불가, 순차=클록·타이밍(셋업/홀드) 설계 필요 |

## Ⅴ. 기술사적 적용
- FSM(Finite State Machine) 기반 제어회로·프로토콜 설계의 핵심
- CPU 데이터패스(조합) + 제어 레지스터(순차) 결합 구조
- 메타스테이빌리티(Metastability) 방지를 위한 동기화 회로 설계 고려
