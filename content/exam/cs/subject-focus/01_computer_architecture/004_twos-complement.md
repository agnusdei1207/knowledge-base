## Ⅰ. 정의
> 2의 보수는 음수를 표현하는 방식으로, 1의 보수(비트 반전)에 1을 더해 만들며, 부호와 무관하게 덧셈 회로 하나로 가감산을 처리할 수 있게 한다.

## Ⅱ. 구성요소 / 원리
- 1의 보수: 모든 비트 반전(NOT)
- 2의 보수: 1의 보수 + 1 (= 자리수 뺀 후 1 더하기)
- n비트 표현 범위: −2^(n−1) ~ +2^(n−1)−1 (비대칭)
- 뺄셈 A−B = A + (B의 2의 보수)로 처리
- 0이 유일(±0 문제 없음), 최상위 비트(MSB)가 부호 비트

## Ⅲ. 흐름도 / 구조
```text
+5 (8bit)  = 0000 0101
  비트반전 = 1111 1010   (1의 보수)
  + 1      = 1111 1011   = −5 (2의 보수)
검산: 0000 0101 + 1111 1011 = 1 0000 0000 → 하위8bit = 0 ✔
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 음수 표현 + 가산기로 가감산 통합 처리 |
| 장점 | 0 유일, 부호 무관 단일 ALU, 하드웨어 단순화 |
| 한계 | 표현 범위 비대칭, 부호 동일 가산 시 오버플로 주의 |

## Ⅴ. 기술사적 적용
- 부호크기(Sign-magnitude)·1의 보수 대비 회로 효율 우수로 사실상 표준
- 오버플로 검출: 두 양수 합이 음수, 두 음수 합이 양수일 때
- 부호확장(Sign extension)으로 워드 크기 확장 시 부호 보존
