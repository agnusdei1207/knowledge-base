## Ⅰ. 정의
> 명령어 메모리와 데이터 메모리를 물리적으로 분리하고 각각 독립된 버스로 동시 접근하여, 폰 노이만 병목을 완화하는 컴퓨터 구조이다.

## Ⅱ. 구성요소 / 원리
- 명령어 메모리(Instruction Memory)와 전용 버스
- 데이터 메모리(Data Memory)와 전용 버스
- CPU가 명령어 인출과 데이터 접근을 한 사이클에 병렬 수행
- 변형 하버드(Modified Harvard): 메모리는 통합(L2), L1 캐시만 명령/데이터 분리

## Ⅲ. 흐름도 / 구조
```text
            ┌──명령버스──▶ ┌ 명령어 메모리 ┐
 ┌──CPU──┐ │             └───────────────┘
 │ CU/ALU│─┤
 └───────┘ │──데이터버스─▶ ┌ 데이터 메모리 ┐
            └             └───────────────┘
   명령 인출 + 데이터 접근 → 동시 수행
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 명령/데이터 동시 접근으로 메모리 병목 해소·처리율 향상 |
| 장점 | 대역폭 2배, 파이프라인 효율↑, DSP·임베디드 적합 |
| 한계 | 메모리·버스 중복으로 비용↑, 명령/데이터 공간 활용 비유연 |

## Ⅴ. 기술사적 적용
- 폰 노이만 구조와 비교되는 대표적 병목 해결 모델
- DSP, MCU(ARM Cortex-M), AVR 등 임베디드 프로세서에 적용
- 현대 CPU는 변형 하버드(L1 I-cache/D-cache 분리)로 구현
