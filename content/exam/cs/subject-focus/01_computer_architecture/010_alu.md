## Ⅰ. 정의
> ALU(Arithmetic Logic Unit, 산술논리연산장치)는 CPU 내부에서 산술연산(가감승제)과 논리연산(AND·OR·XOR·NOT) 및 시프트를 수행하는 조합논리회로 기반 핵심 연산장치이다.

## Ⅱ. 구성요소 / 원리
- 입력: 두 피연산자(operand)와 연산 선택 제어신호(opcode)
- 연산부: 가산기(Adder), 논리 게이트망, 시프터(Shifter)
- 출력: 연산 결과 + 상태 플래그(Zero, Carry, Overflow, Sign)
- 멀티플렉서(MUX)로 제어신호에 따라 연산 결과 선택
- 누산기(Accumulator)·레지스터 파일과 연동해 데이터 처리

## Ⅲ. 흐름도 / 구조
```text
  A ─┐
     ├─▶ [ 산술/논리/시프트 연산부 ] ─▶ 결과(Result)
  B ─┘            ▲                  └─▶ Flags(Z,C,V,S)
            제어신호(Opcode)
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | CPU의 모든 산술·논리 연산을 담당하는 데이터패스 핵심 |
| 장점 | 단일 회로로 다양한 연산 통합, 플래그로 분기 제어 지원 |
| 한계 | 비트폭·캐리 전파 지연이 성능 병목, 곱셈/나눗셈은 별도 회로 |

## Ⅴ. 기술사적 적용
- 캐리 전파 지연 개선: 캐리예측가산기(CLA, Carry Look-ahead Adder)
- FPU(부동소수점)·SIMD·벡터 연산기로 확장되어 병렬 처리
- 제어장치(CU)와 함께 CPU 데이터패스를 구성하는 양대 축
