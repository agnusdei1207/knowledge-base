## Ⅰ. 정의
> 해밍코드는 패리티 비트를 추가해 단일 비트 오류를 검출·정정(SEC)하는 오류정정코드(ECC, Error Correcting Code)로, 오류 위치를 신드롬으로 지목한다.

## Ⅱ. 구성요소 / 원리
- 패리티 비트 위치: 2의 거듭제곱 위치(1,2,4,8…)에 배치
- 패리티 개수 조건: 2^p ≥ m + p + 1 (m=데이터 비트)
- 각 패리티는 특정 비트 그룹을 짝수 패리티로 커버
- 신드롬(Syndrome): 수신측 패리티 재계산값 → 오류 위치(2진수)
- SEC-DED: 전체 패리티 1비트 추가로 단일정정+이중검출

## Ⅲ. 흐름도 / 구조
```text
위치: 1   2   3   4   5   6   7
      P1  P2  D1  P4  D2  D3  D4
P1=1,3,5,7  P2=2,3,6,7  P4=4,5,6,7 (짝수 패리티)
수신 → 신드롬 S=P4P2P1 계산 → S=0 정상 / S=k → k번째 비트 정정
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 단일 비트 오류 자동 검출 및 정정 |
| 장점 | 재전송 없이 정정, 신드롬으로 오류 위치 특정 |
| 한계 | 단일 정정만 가능, 2비트 이상 동시 오류 정정 불가 |

## Ⅴ. 기술사적 적용
- ECC 메모리(서버 DRAM)에서 SEC-DED로 신뢰성 확보
- CRC(검출 전용) 대비 정정 기능 보유가 차별점
- 우주·항공 등 고신뢰 시스템과 RAID 일부에 응용
