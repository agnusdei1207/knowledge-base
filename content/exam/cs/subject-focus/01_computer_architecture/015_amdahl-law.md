## Ⅰ. 정의
> 시스템 일부만 개선했을 때 얻는 전체 성능 향상은 개선 불가능한 직렬(순차) 부분에 의해 상한이 정해진다는 법칙으로, 병렬화의 한계를 설명한다.

## Ⅱ. 구성요소 / 원리
- 전체 속도향상 S = 1 / ( (1−P) + P/N )
  - P: 병렬화(개선) 가능 비율, N: 프로세서 수(개선 배수)
- N→∞ 일 때 최대 속도향상 = 1 / (1−P)
- 직렬 부분(1−P)이 성능 향상의 절대적 병목
- 예) P=0.9, N=∞ → 최대 10배에 수렴

## Ⅲ. 흐름도 / 구조
```text
 전체작업 = [직렬 (1−P)] + [병렬 P]
 N개 적용:   (1−P)  +  P/N
 S = 1 / ((1−P) + P/N)
 N→∞ ⇒ S_max = 1 / (1−P)   ← 직렬부가 상한 결정
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 부분 최적화·병렬화의 전체 효과 한계 정량화 |
| 장점 | 투자 대비 효과 예측, 직렬 병목 식별 |
| 한계 | 문제 크기 고정 가정, 데이터 증가 미반영(→구스타프슨이 보완) |

## Ⅴ. 기술사적 적용
- 멀티코어·병렬프로그래밍 확장성(Scalability) 평가 기준
- 구스타프슨 법칙(크기 가변)과 대비되는 강확장(Strong Scaling) 모델
- 성능방정식과 결합해 최적화 우선순위 결정
