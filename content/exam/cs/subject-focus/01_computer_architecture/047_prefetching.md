## Ⅰ. 정의
> 실제 참조 이전에 데이터·명령어를 미리 캐시로 적재하여 강제(cold) 미스 지연을 은닉하는 성능 향상 기법.

## Ⅱ. 구성요소 / 원리
- 하드웨어 프리패치: 접근 패턴 감지(순차/스트라이드)로 자동 선적재
- 소프트웨어 프리패치: 컴파일러/프로그래머가 prefetch 명령 삽입
- 방식: Next-line, Stride, Stream Buffer, 포인터 기반(GHB)
- 핵심 지표: 정확도(Accuracy)·적시성(Timeliness)·커버리지(Coverage)
- 위험: 부정확 프리패치는 대역폭 낭비·캐시 오염(Pollution)

## Ⅲ. 흐름도 / 구조
```text
접근 A[0],A[1] → 스트라이드 감지(+1)
   → A[2],A[3] 미리 적재(prefetch)
   → 실제 참조 시 Hit (Miss Penalty 은닉)
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | Compulsory 미스의 메모리 지연을 사전 적재로 숨김 |
| 장점 | 규칙적 접근에서 적중률·체감 지연 크게 개선 |
| 한계 | 오프리패치 시 대역폭 낭비·캐시 오염, 불규칙 패턴 무효 |

## Ⅴ. 기술사적 적용
- 비교: 비순차 실행(OoO)·MSHR과 함께 메모리 지연 은닉
- 실무: 컴파일러 SW 프리패치 + HW 스트라이드 프리패처 병용
- 최신: ML 기반 접근 예측 프리패처, 그래프 워크로드 대응
