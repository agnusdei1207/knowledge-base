## Ⅰ. 정의
> 가상주소→물리주소 변환 결과를 캐싱하는 MMU(Memory Management Unit) 내 고속 연관 메모리로, 페이지 테이블 접근 없이 변환을 가속한다.

## Ⅱ. 구성요소 / 원리
- 엔트리: 가상페이지번호(VPN) → 물리프레임번호(PFN) + 보호·ASID 비트
- TLB Hit: 즉시 물리주소 산출(수 클럭)
- TLB Miss: 페이지 테이블 워크 후 엔트리 적재(HW/SW 처리)
- ASID(Address Space ID): 프로세스 구분으로 컨텍스트 전환 시 플러시 최소화
- 다단계: L1 TLB(I/D 분리) + L2 통합 TLB

## Ⅲ. 흐름도 / 구조
```text
VA(VPN) → [TLB 조회]
   ├ Hit  → PFN 즉시 반환 → PA
   └ Miss → Page Table Walk → PTE 적재 → 재시도
              └ 미적재 시 Page Fault
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 주소 변환 지연 제거로 가상메모리 성능 확보 |
| 장점 | 변환을 수 클럭으로 단축, 적중률 99%+ |
| 한계 | 용량 한계로 미스 시 워크 지연, 컨텍스트 전환 플러시 비용 |

## Ⅴ. 기술사적 적용
- 비교: TLB 미스율↓ 위해 Huge Page로 커버리지 확대
- 실무: ASID/PCID로 플러시 회피, L2 TLB 대형화
- 최신: 가상화 중첩 페이징 시 TLB 압박, 가상 TLB·tagged TLB
