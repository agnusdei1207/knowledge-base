## Ⅰ. 정의
> 가상메모리는 물리 용량을 초과하는 주소공간을 각 프로세스에 제공하는 기법이며, MMU(Memory Management Unit)는 가상주소를 물리주소로 변환하는 하드웨어.

## Ⅱ. 구성요소 / 원리
- 가상주소공간: 프로세스별 독립 연속 주소(격리·보호 제공)
- MMU: 페이지 테이블 참조로 주소 변환, 보호·권한(R/W/X) 검사
- TLB(Translation Lookaside Buffer): 최근 변환 캐싱으로 변환 가속
- 페이지 폴트: 미적재 페이지 접근 시 디스크에서 적재(요구 페이징)
- 효과: 메모리 격리·공유·오버커밋, 단편화 완화

## Ⅲ. 흐름도 / 구조
```text
가상주소(VA) → [MMU] → TLB 적중? ─yes→ 물리주소(PA)
                         └no→ 페이지테이블 워크 → PA
                                  └ 미적재 → Page Fault → 디스크
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 물리 한계 초월, 프로세스 격리·보호·공유 제공 |
| 장점 | 대용량 환상, 보안 격리, 다중 프로그래밍 효율 |
| 한계 | 변환 오버헤드, 페이지 폴트 지연, 스래싱 위험 |

## Ⅴ. 기술사적 적용
- 비교: 세그멘테이션·페이징 결합(세그먼트드 페이징)
- 실무: 대용량 페이지(Huge Page)로 TLB 미스 감소
- 최신: 5단계 페이지 테이블, IOMMU/SR-IOV, 가상화 EPT/NPT
