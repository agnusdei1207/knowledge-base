## Ⅰ. 정의
> 캐시 일관성을 유지하는 두 방식으로, 공유 버스를 감시해 일관성을 처리하는 스누핑과 블록별 사본 정보를 중앙 디렉터리에 기록·관리하는 디렉터리 프로토콜.

## Ⅱ. 구성요소 / 원리
- 스누핑: 모든 캐시가 버스 트랜잭션을 감시(broadcast) 후 상태 갱신/무효화
- 디렉터리: 메모리 블록마다 어떤 노드가 사본 보유하는지 비트벡터로 추적
- 스누핑은 브로드캐스트, 디렉터리는 점대점(point-to-point) 통신
- 확장성: 디렉터리 > 스누핑 / 단순성: 스누핑 > 디렉터리

## Ⅲ. 흐름도 / 구조
```text
[Snooping] P0 write → Bus broadcast → 全캐시 감시·무효화
[Directory] P0 write → Directory조회 → 해당 노드만 무효화
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 다중 캐시의 일관성 유지 메커니즘 구현 |
| 장점 | 스누핑=단순·저지연 / 디렉터리=높은 확장성·트래픽 절감 |
| 한계 | 스누핑=버스 대역폭 병목 / 디렉터리=저장공간·조회 지연 |

## Ⅴ. 기술사적 적용
- 스누핑 → 소규모 버스 기반 SMP
- 디렉터리 → 대규모 NUMA·MPP, 다수 코어 인터커넥트
- 현대 멀티소켓은 디렉터리 기반 ccNUMA 주류
