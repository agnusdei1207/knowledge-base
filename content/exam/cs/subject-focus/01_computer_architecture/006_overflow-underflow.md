## Ⅰ. 정의
> 오버플로우는 연산 결과가 표현 가능한 최대 범위를 초과한 상태이고, 언더플로우는 결과가 표현 가능한 최소(0에 근접) 크기보다 작아진 상태이다.

## Ⅱ. 구성요소 / 원리
- 정수 오버플로: 2의 보수에서 부호 비트 모순(양+양=음 등)
- 검출: 부호 비트 캐리인·캐리아웃 XOR로 판별
- 부동소수점 오버플로: 지수 최대 초과 → ±∞ 처리
- 부동소수점 언더플로: 지수 최소 미만 → 비정규화 수 또는 0
- 상태 플래그(Flag): CPU의 OF(Overflow), CF(Carry) 레지스터로 표시

## Ⅲ. 흐름도 / 구조
```text
정수 8bit: 127 + 1
  0111 1111 + 0000 0001 = 1000 0000 (−128)  ← 부호 반전, 오버플로!
검출: Carry_in(MSB) ⊕ Carry_out = 1 → Overflow

FP: |값| > MAX → ∞ (overflow) / 0 < |값| < MIN → 0 (underflow)
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 연산 결과의 표현 범위 초과/소실을 검출·처리 |
| 장점 | 플래그·예외로 잘못된 결과 조기 감지 가능 |
| 한계 | 미처리 시 무음(silent) 오류로 보안·안정성 사고 유발 |

## Ⅴ. 기술사적 적용
- 정수 오버플로는 버퍼 오버플로 등 보안 취약점(CWE-190)으로 직결
- 포화 연산(Saturation arithmetic)으로 DSP/멀티미디어 안전 처리
- 컴파일러 오버플로 검사·예외 처리로 임베디드 신뢰성 확보
