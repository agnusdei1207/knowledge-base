## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 컴퓨터 구조는 성능·전력·신뢰성의 물리적 한계를 설계 판단으로 바꾸는 과목으로, 1교시 용어가 그대로 2~4교시 논술의 앞단위가 된다.
> 2. **가치**: 캐시·파이프라인·메모리 계층·병렬처리 용어를 정확히 정의해야 시스템형 서술 문제의 골격(병목→개선→적용)이 잡힌다.
> 3. **판단 포인트**: 인공지능(AI) 가속기, 캐시 일관성, 하드웨어 보안까지 연결해야 컴퓨터시스템응용기술사 관점의 트레이드오프 답안이 완성된다.

## Ⅰ. 과목 개요

- 총 노트 수: `804` (studynote 키워드 기준), 핵심 트랙 목표 `200개` 압축.
- 시험 비중: 컴퓨터시스템응용기술사 기반 과목으로 1교시 단답·2~4교시 서술 모두 고정 출제군. 캐시/파이프라인/병렬처리/메모리 계층이 반복 출제 핵심.
- 1교시(단답형): 13문항 중 10문항 선택, 각 10점, 문항당 약 10분. ISA·CPI·캐시 사상·해저드·일관성 프로토콜의 정의 구분이 관건.
- 2~4교시(서술형): 각 교시 6문항 중 4문항 선택, 각 25점, 문항당 약 22~24분, 답안 3~3.5쪽. 병목 원인 → 개선 구조 → 적용 판단을 비교형으로 전개.

## Ⅱ. 1교시 단답형 핵심 (앞단위)

> 아래 키워드는 studynote 키워드 목록에서 발췌한 1교시 빈출 용어이며, 2~4교시 서술의 기본 단위가 된다. 약어는 최초 1회 풀네임 병기.

| 키워드 | 한줄 정의 | 핵심 3포인트 (쉼표구분) |
|:---|:---|:---|
| 폰 노이만 아키텍처(Von Neumann) | 명령어와 데이터를 같은 메모리에 두는 프로그램 내장 방식 구조 | 프로그램 내장, 단일 버스 병목, 하버드 구조와 대비 |
| 캐시 사상(Cache Mapping) | 메인 메모리 블록을 캐시 라인에 배치하는 규칙 | 직접 사상, 집합 연관, 완전 연관 |
| AMAT(Average Memory Access Time) | 평균 메모리 접근 시간 = 적중시간 + 미스율×미스페널티 | 적중률 의존, 계층별 누적, 성능 지표 |
| 캐시 쓰기 정책(Write Policy) | 캐시 수정 데이터를 메모리에 반영하는 방식 | Write-Through 동시, Write-Back 지연, 더티 비트 |
| 캐시 미스 3C | 캐시 미스 원인 분류 모델 | Compulsory, Capacity, Conflict |
| 파이프라인 해저드(Hazard) | 파이프라인 중첩 실행을 방해하는 충돌 | 구조적, 데이터(RAW/WAR/WAW), 제어 |
| 데이터 포워딩(Forwarding) | 결과를 레지스터 거치지 않고 직접 전달해 데이터 해저드 완화 | 바이패싱, 스톨 감소, EX/MEM 경로 |
| 분기 예측(Branch Prediction) | 분기 결과를 미리 추측해 제어 해저드 완화 | 정적/동적, BTB/BHT, 예측 실패 페널티 |
| 비순차 실행(OoO Execution) | 의존성 없는 명령어를 순서 무관 실행 | 토마술로, ROB, 레지스터 리네이밍 |
| RISC vs CISC | 축소형·복합형 명령어 집합 구조(ISA) 설계 철학 | 고정/가변 길이, 로드-스토어, 파이프라인 친화 |
| 주소 지정 방식(Addressing Mode) | 피연산자 위치를 지정하는 방식 | 즉시/직접/간접, 변위/인덱스, PC 상대 |
| 가상 메모리(Virtual Memory) | 물리 메모리보다 큰 논리 주소 공간 제공 기법 | 페이징, MMU·TLB, 페이지 폴트 |
| TLB(Translation Lookaside Buffer) | 주소 변환 캐시로 페이지 테이블 접근 가속 | 변환 캐시, 히트/미스, 슈팅다운 |
| 페이지 교체(Page Replacement) | 프레임 부족 시 내보낼 페이지 선정 알고리즘 | OPT, LRU, 클럭(NUR) |
| DMA(Direct Memory Access) | CPU 개입 없이 장치-메모리 직접 전송 | 사이클 스틸링, 버스트 모드, 인터럽트 완료통지 |
| RAID(Redundant Array of Independent Disks) | 복수 디스크로 성능·가용성 확보 기법 | RAID0 스트라이핑, RAID1 미러링, RAID5 분산패리티 |
| 플린 분류(Flynn's Taxonomy) | 명령어·데이터 스트림 수에 따른 병렬 구조 분류 | SISD, SIMD, MIMD |
| NUMA(Non-Uniform Memory Access) | 노드별 접근 지연이 다른 공유 메모리 구조 | 지역성 중요, UMA 대비, SMP 확장 |
| MESI 프로토콜 | 멀티코어 캐시 일관성 상태 프로토콜 | Modified·Exclusive·Shared·Invalid, 스누핑, 무효화 |
| 암달의 법칙(Amdahl's Law) | 병렬화 가능 비율로 전체 속도향상 한계 산정 | 직렬 구간 한계, 속도향상도, 구스타프슨과 대비 |
| HBM(High Bandwidth Memory) | TSV 적층 고대역폭 메모리 | 3D 적층, AI 가속기 결합, 메모리 월 완화 |
| TPU/NPU/시스톨릭 어레이 | AI 연산 전용 가속기와 MAC 배열 구조 | 시스톨릭 어레이, MAC 연산, 텐서 코어 |

### 1교시 답안 공식

```text
정의(1줄) → 특징 3 → ASCII 도해(3줄) → 미니표(3행) → 적용/비교 1줄
```

- 미니표 고정 3행: `목적 / 강점 / 한계`. 비교형이면 `구분 / A / B`.
- 금지: 정의 없는 서술 시작, 도해 없는 줄글, 약어 풀네임 누락.

## Ⅲ. 2~4교시 서술형 확장 (심화)

> 1교시 앞단위를 논술 단위로 키운다. 각 주제는 Ⅰ.개요 → Ⅱ.구조/원리 → Ⅲ.특징/비교 → Ⅳ.적용/방안 → Ⅴ.결론 골격으로 전개.

### 1) 캐시 메모리와 메모리 계층 (앞단위: 캐시 사상·3C·쓰기정책·AMAT)

- **한줄 정의**: 참조의 지역성을 이용해 속도-용량-비용 격차를 계층으로 완충하는 구조.
- Ⅰ. 메모리 월·지역성(시간/공간) 배경 / Ⅱ. L1~L3 계층, 사상 3종 구조도 / Ⅲ. 직접 vs 집합연관 vs 완전연관 비교, Write-Through vs Write-Back / Ⅳ. 프리패칭·희생 캐시·웨이 예측으로 AMAT 개선 / Ⅴ. AI 워크로드 대용량 캐시·HBM 연계.
- **그릴 표/도해**: 사상 방식 3종 비교표 + 계층 구조도(CPU↔L1↔L2↔L3↔DRAM).

### 2) 명령어 파이프라이닝과 해저드 (앞단위: 해저드·포워딩·분기예측·OoO)

- **한줄 정의**: 명령어 사이클(IF·ID·EX·MEM·WB)을 중첩 실행해 처리량을 높이는 기법.
- Ⅰ. CPI 개선 필요성 / Ⅱ. 5단계 파이프라인 도해, 해저드 3종 / Ⅲ. 정적 vs 동적 분기 예측, 인오더 vs 비순차 / Ⅳ. 포워딩·스톨·예측·수퍼스칼라로 해저드 대응 / Ⅴ. 멜트다운/스펙터 등 추측실행 보안 한계.
- **그릴 표/도해**: 해저드 3종 원인-대책 대응표 + 파이프라인 타이밍 다이어그램.

### 3) 가상 메모리와 주소 변환 (앞단위: 가상메모리·TLB·페이지교체)

- **한줄 정의**: MMU(Memory Management Unit)가 논리 주소를 물리 주소로 변환해 보호·확장을 제공하는 기법.
- Ⅰ. 다중 프로그래밍·메모리 보호 배경 / Ⅱ. 페이징·다단계/역 페이지 테이블·TLB 흐름도 / Ⅲ. 페이징 vs 세그멘테이션, LRU vs 클럭 / Ⅳ. 거대 페이지·TLB 슈팅다운·워킹셋으로 스래싱 방지 / Ⅴ. 가상화(EPT/NPT)·IOMMU 확장.
- **그릴 표/도해**: 페이징 vs 세그멘테이션 비교표 + 가상→물리 주소 변환 흐름도.

### 4) 병렬 처리와 캐시 일관성 (앞단위: 플린 분류·NUMA·MESI·암달)

- **한줄 정의**: 멀티코어 환경에서 다중 스트림을 동시 처리하되 공유 데이터 정합성을 보장하는 구조.
- Ⅰ. 다크 실리콘·전력벽으로 멀티코어 전환 / Ⅱ. 플린 분류·UMA/NUMA·SMP 구조도 / Ⅲ. 스누핑 vs 디렉터리, 무효화 vs 갱신 / Ⅳ. MESI·메모리 배리어·CAS로 동기화, 거짓 공유 회피 / Ⅴ. 암달/구스타프슨으로 확장성 한계 판단.
- **그릴 표/도해**: 스누핑 vs 디렉터리 비교표 + MESI 상태 전이도.

### 5) AI 가속기와 차세대 인터커넥트 (앞단위: TPU/NPU·HBM·시스톨릭)

- **한줄 정의**: MAC(Multiply-Accumulate) 중심 데이터 병렬을 전용 하드웨어로 가속하는 이기종 컴퓨팅 구조.
- Ⅰ. 메모리 월·전력 효율 요구 / Ⅱ. GPU SIMT·시스톨릭 어레이·텐서 코어 구조도 / Ⅲ. CPU vs GPU vs NPU/TPU 특성 비교 / Ⅳ. HBM·CXL·NVLink·칩렛으로 대역폭/풀링 확보, 양자화로 효율 / Ⅴ. PIM·뉴로모픽 등 발전 방향.
- **그릴 표/도해**: 아래 비교표 + 시스톨릭 어레이 배열 도해.

#### 비교표 — CPU vs GPU vs NPU/TPU

| 구분 | CPU(Central Processing Unit) | GPU(Graphics Processing Unit) | NPU/TPU(Neural/Tensor Processing Unit) |
|:---|:---|:---|:---|
| 설계 목표 | 저지연 범용 연산 | 대규모 데이터 병렬 | 신경망 추론·학습 전용 |
| 코어 구조 | 소수 강력 코어, 분기 예측 | 다수 SIMT 코어, 워프 실행 | 시스톨릭 어레이, MAC 배열 |
| 강점 | 제어 흐름·직렬 성능 | 처리량(Throughput), FP 연산 | MAC 효율, 전력당 성능 |
| 한계 | 병렬 처리량 한계 | 전력·메모리 대역폭 | 범용성 낮음, 모델 종속 |
| 적용 | OS·트랜잭션 | 그래픽·HPC·학습 | 온디바이스/데이터센터 추론 |

## Ⅳ. 출제 포인트 & 함정

| 출제유형 | 1교시 단답 포인트 | 2~4교시 서술 포인트 |
|:---|:---|:---|
| 캐시/메모리 | 사상 3종, 3C, Write-Back/Through 정의 | AMAT 계산 + 계층 구조도 + 개선기법 |
| 파이프라인 | RAW/WAR/WAW 구분, 포워딩 정의 | 해저드 원인-대책 대응표 + 보안(스펙터) |
| 가상 메모리 | TLB·페이지 폴트·LRU 정의 | 페이징 vs 세그·스래싱 방지 방안 |
| 병렬/일관성 | 플린 분류, MESI 상태, NUMA 정의 | 스누핑 vs 디렉터리 + 확장성 한계(암달) |
| 성능 평가 | CPI/IPC/MIPS/FLOPS 구분 | 성능 방정식·암달/구스타프슨 적용 판단 |
| AI 가속기 | NPU/TPU·HBM·시스톨릭 정의 | CPU/GPU/NPU 비교 + CXL/칩렛 동향 |

- **공통 감점/함정**:
  - CPI와 IPC, MIPS와 FLOPS를 혼용 → 단위·정의 명확히 구분.
  - Write-Back의 더티 비트, 캐시 일관성과의 연결 누락.
  - 암달의 법칙을 "무조건 N배" 로 오해 → 직렬 구간 한계 명시.
  - 약어 풀네임 미표기(ISA, MMU, MESI 등) → 최초 1회 병기.
  - 도해/표 없이 줄글만 작성 → 채점자 5초 파악 실패로 감점.

## Ⅴ. 최신 기술 동향 + 공부 노트 연결

### 최신 동향

- **AI 인프라 병목 해소**: HBM(High Bandwidth Memory), CXL(Compute Express Link) 기반 메모리 풀링, 칩렛(Chiplet)·UCIe·NVLink로 대역폭 확장.
- **메모리 중심 컴퓨팅**: PIM(Processing-In-Memory)·CIM(Computing-In-Memory)로 메모리 월 완화, 저정밀(INT8/INT4) 양자화 가속.
- **데이터센터 오프로드**: DPU(Data Processing Unit)/SmartNIC, RDMA·RoCE, NVMe-oF로 스토리지·네트워크 오프로딩.
- **하드웨어 보안**: 기밀 컴퓨팅(Confidential Computing), 신뢰 실행 환경(TEE), 하드웨어 루트 오브 트러스트(Root of Trust), 사이드 채널(Spectre/Meltdown/Rowhammer) 방어.
- **전력/신뢰성**: DVFS·클럭/전력 게이팅, TDP(Thermal Design Power), ECC·락스텝, RAS(Reliability·Availability·Serviceability).
