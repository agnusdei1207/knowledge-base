## Ⅰ. 정의
> 해저드 해소를 위해 파이프라인 진행을 일시 정지시키고 빈 단계(버블)를 삽입하는 동작으로, 정확성을 보장하는 대신 성능을 희생한다.

## Ⅱ. 구성요소 / 원리
- 스톨 검출: 해저드 검출 유닛이 의존성/충돌 식별
- PC·IF/ID 레지스터 동결(freeze)로 후속 명령 진행 보류
- 버블 삽입: 제어신호를 NOP(No Operation)으로 무력화
- 발생 원인: Load-Use, 분기 미해결, 자원 충돌

## Ⅲ. 흐름도 / 구조
```text
I1: LW  R1,0(R2)  IF ID EX MEM WB
I2: ADD R3,R1,R4     IF ID ** EX MEM WB   (**=버블/스톨)
                        └ 1사이클 정지 후 진행
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 해저드 상황에서 올바른 결과 보장 |
| 장점 | 구현 단순, 정확성 확실 |
| 한계 | CPI 증가·처리량 저하(버블만큼 손실) |

## Ⅴ. 기술사적 적용
- 포워딩·분기예측·명령어 스케줄링으로 스톨 빈도 최소화 설계
- OoO 실행은 독립 명령을 앞당겨 스톨 슬롯을 채워 유효 손실 감소
