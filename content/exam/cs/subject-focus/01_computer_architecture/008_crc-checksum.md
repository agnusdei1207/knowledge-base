## Ⅰ. 정의
> CRC(Cyclic Redundancy Check, 순환중복검사)는 생성 다항식 나눗셈의 나머지를 검사값으로 쓰는 강력한 오류검출 기법이고, 체크섬(Checksum)은 데이터 합산값으로 오류를 검출하는 단순 기법이다.

## Ⅱ. 구성요소 / 원리
- 체크섬: 데이터 워드 합산(1의 보수) → 전송, 수신측 재합산 비교
- CRC: 데이터를 다항식으로 보고 생성다항식 G(x)로 모듈로-2 나눗셈
- 나머지(FCS, Frame Check Sequence)를 데이터 뒤에 부가
- 수신측 동일 나눗셈 → 나머지 0이면 정상
- 버스트(burst) 오류 검출에 강함 (G(x) 차수만큼)

## Ⅲ. 흐름도 / 구조
```text
송신: Data·x^n  ÷(mod2) G(x) → 나머지 R → 전송: [Data | R]
수신: [Data | R] ÷(mod2) G(x) → 나머지 = 0 ? 정상 : 오류
체크섬: Σ(words) = S → 전송 [Data | S], 수신 재합산 비교
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 전송·저장 중 데이터 오류 검출(정정 아님) |
| 장점 | CRC=버스트 오류 강검출, 체크섬=계산 단순·고속 |
| 한계 | 검출만 가능(정정 불가), 체크섬은 자리바꿈 오류 누락 |

## Ⅴ. 기술사적 적용
- 이더넷(CRC-32), USB, 저장장치 등 통신·스토리지 표준 무결성 검사
- 해밍코드(정정) vs CRC(검출) 역할 비교가 답안 포인트
- 무결성 검증은 CRC, 변조 방지는 암호 해시(SHA)로 구분 적용
