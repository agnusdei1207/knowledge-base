## Ⅰ. 정의
> 부울대수(Boolean Algebra)는 0/1 두 값과 AND·OR·NOT 연산으로 논리식을 다루는 대수 체계이며, 카르노맵(Karnaugh Map, K-map)은 인접 셀의 1을 묶어 논리식을 시각적으로 간소화하는 도표 기법이다.

## Ⅱ. 구성요소 / 원리
- 기본연산: AND(·), OR(+), NOT(') — 곱·합·보수의 세 연산
- 기본법칙: 교환·결합·분배·항등(A+0=A, A·1=A), 보수(A+A'=1)
- 드모르간(De Morgan): (A·B)'=A'+B', (A+B)'=A'·B'
- K-map: 2^n 셀을 그레이코드(Gray code) 순서로 배치, 인접 1끼리 2^k개 묶음(group)
- 묶음 클수록 변수 소거 ↑ → 최소 곱의합(SOP, Sum Of Products) 도출

## Ⅲ. 흐름도 / 구조
```text
진리표 ─▶ 부울식 도출 ─▶ [대수 간소화] ──┐
                                          ├─▶ 최소 논리식 ─▶ 게이트 구현
진리표 ─▶ K-map 작성 ─▶ [인접 1 묶기] ───┘
   AB\C  0   1
   00  [ 1 ][ 1 ]   ← 인접 묶음으로 변수 제거
   01  [ 0 ][ 1 ]
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 논리회로 최소화로 게이트 수·비용·지연 감소 |
| 장점 | 대수=규칙기반 정확, K-map=직관적 시각화로 4변수까지 빠름 |
| 한계 | 대수는 경험 의존, K-map은 5변수 이상 비실용(→ Quine-McCluskey) |

## Ⅴ. 기술사적 적용
- 4변수 초과 시 Quine-McCluskey 또는 Espresso 알고리즘으로 자동 최소화
- 디지털 IC·FPGA 합성 도구의 논리 최적화(Logic Synthesis) 기반 이론
- 무관항(Don't care)을 활용한 추가 간소화로 면적·전력 최적 설계

## Ⅵ. 2~4교시 서술형 확장 답안

### 1. 개요

부울대수와 카르노맵은 디지털 시스템의 조합논리회로를 최소화하기 위한 기본 기법이다. 1교시에서는 정의와 법칙을 묻지만, 2~4교시에서는 **논리식 최소화 절차, 회로 구현 효과, 자동화 설계 도구와의 관계**까지 설명해야 한다.

| 구분 | 답안 포인트 |
|:---|:---|
| 목적 | 게이트 수, 배선 수, 지연시간, 전력 소모 감소 |
| 적용 대상 | 조합논리회로, 디코더, 멀티플렉서, FPGA LUT 최적화 |
| 확장 주제 | Quine-McCluskey, Espresso, Logic Synthesis, EDA |

### 2. 구성요소 및 동작 원리

```text
[요구 기능]
   ↓
[진리표 작성]
   ↓
[부울식 도출: SOP/POS]
   ↓
[간소화: 대수 법칙 또는 K-map]
   ↓
[최소 논리식]
   ↓
[게이트 회로 / FPGA LUT / ASIC 셀 구현]
```

| 단계 | 내용 | 기술사 답안 포인트 |
|:---|:---|:---|
| 진리표 | 입력 조합별 출력 정의 | 요구사항을 논리 모델로 변환 |
| 부울식 | SOP/POS 형태로 표현 | 회로 구현 가능한 수식화 |
| K-map | 그레이코드 기반 인접 셀 묶음 | 변수 제거로 항 수 감소 |
| 무관항 | 0/1 어느 쪽도 허용 가능한 조건 | 최적화 자유도 증가 |
| 회로 구현 | NAND/NOR 게이트 또는 LUT 매핑 | 면적·지연·전력 최적화 |

### 3. 핵심 비교

| 구분 | 부울대수 간소화 | 카르노맵 | Quine-McCluskey/Espresso |
|:---|:---|:---|:---|
| 방식 | 법칙 적용 | 시각적 인접 묶음 | 알고리즘 기반 최소화 |
| 장점 | 이론적 엄밀성 | 2~4변수에서 빠르고 직관적 | 다변수·자동화 가능 |
| 한계 | 경험 의존 | 5변수 이상 복잡 | 계산량·도구 의존 |
| 적용 | 기본 증명·소규모 회로 | 시험 답안·수작업 설계 | EDA, FPGA/ASIC 합성 |

### 4. 설계 적용 및 고려사항

1. **성능 관점**: 논리 단계 수를 줄이면 전파 지연이 감소하지만, 지나친 최소화는 배선 복잡도를 높일 수 있다.
2. **전력 관점**: 게이트 수와 스위칭 활동을 줄여 동적 전력 소모를 낮춘다.
3. **신뢰성 관점**: 단순 SOP 최소화만 보면 해저드(Hazard)가 생길 수 있으므로, 타이밍 민감 회로에서는 중복항을 남겨 글리치를 방지한다.
4. **자동화 관점**: 실제 FPGA/ASIC 설계에서는 사람이 K-map을 직접 쓰기보다 Verilog/VHDL → Logic Synthesis → Technology Mapping 흐름으로 자동 최적화한다.

### 5. 결론

부울대수와 카르노맵은 단순 수학 기법이 아니라 디지털 회로의 **면적·지연·전력 최적화 출발점**이다. 기술사 답안에서는 `진리표 → 논리식 → 최소화 → 회로 구현 → 성능/전력/해저드 고려` 흐름으로 전개해야 2~4교시 서술형 답안이 된다.
