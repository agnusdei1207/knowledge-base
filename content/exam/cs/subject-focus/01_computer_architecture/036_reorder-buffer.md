## Ⅰ. 정의
> 비순차로 실행된 명령어의 결과를 임시 보관했다가 프로그램 순서대로 커밋(Commit)시켜 정밀 예외와 순차 완료를 보장하는 순환 버퍼이다.

## Ⅱ. 구성요소 / 원리
- 원형 큐(Circular Queue): head(커밋)·tail(할당) 포인터로 순서 유지
- 엔트리 필드: 명령유형·목적지·결과값·완료(Ready) 플래그
- 발행 시 ROB 말미 할당, 실행 결과는 엔트리에 기록
- head가 완료 상태일 때만 in-order로 레지스터/메모리에 반영
- 예외·오예측 시 해당 엔트리 이후 일괄 무효화(squash)

## Ⅲ. 흐름도 / 구조
```text
Issue ─▶ ROB 할당(tail) ─▶ 비순차 Execute ─▶ 결과 기록
                                              │
   head Ready? ─Y─▶ In-order Commit ─▶ head++
```

## Ⅳ. 핵심 특징
| 구분 | 내용 |
|:---|:---|
| 목적 | 비순차 실행의 순차 완료·정밀 예외 보장 |
| 장점 | 투기실행 회복·롤백 지원, 리네이밍 저장소 겸용 |
| 한계 | 엔트리 한계 시 발행 정지, 면적·전력 비용 |

## Ⅴ. 기술사적 적용
- 토마술로+ROB로 정밀 예외·투기실행 구현(현대 OoO 표준)
- 분기 오예측·인터럽트 시 일관된 아키텍처 상태 복원의 핵심 메커니즘
