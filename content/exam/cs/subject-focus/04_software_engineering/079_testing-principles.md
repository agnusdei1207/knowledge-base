## Ⅰ. 출제 관점 및 1교시 답안 포인트
> 테스팅 7원리(ISTQB Testing Principles)는 효과적 테스트 수행을 위한 기본 원칙으로, 결함 존재 입증·완전테스트 불가 등 테스트의 본질적 한계와 전략을 규정한다.

| 답안 축 | 정리 포인트 |
|:---|:---|
| 출제 맥락 | 검증·확인, 테스트 설계, 커버리지, 회귀/성능까지 품질보증 체계를 묻는 축 |
| 1교시 기본 골격 | 정의 -> 목적 -> 핵심 요소/절차 -> 장단점/지표 -> 적용 판단 |
| 함께 묶을 논점 | 테스트 원리, 블랙박스/화이트박스, 테스트 레벨, 회귀, 성능, TDD, 테스트 더블 |
| 2~4교시 확장 방향 | 품질 위험과 테스트 필요성, 기법·절차·커버리지 구조, 정적/동적 또는 기능/비기능 비교, 자동화·회귀 전략 |


- 답안 포인트
  - `테스팅 7원리 (Testing Principles)`가 해결하려는 문제와 목적을 첫 문장에 압축
  - 핵심 구성요소·절차·지표는 3~5개 축으로 정리
  - 비교 개념과 실무 적용 조건을 함께 적시해 확장성 확보

## Ⅱ. 핵심 구조 및 메커니즘
- 결함 존재 증명: 테스트는 결함 존재를 보일 뿐 부재 증명 불가
- 완전테스트 불가능: 모든 입력·경로 검증은 비현실적
- 조기 테스트(Early Testing): 초기 단계부터 결함 검출이 경제적
- 결함 집중(Clustering): 소수 모듈에 결함 편중(파레토)
- 살충제 패러독스·정황 의존·오류부재의 궤변

## Ⅲ. 비교·구조·지표 정리
```text
조기 테스트 → 결함 집중 모듈 식별
      │
동일 케이스 반복 → 살충제 패러독스
      │
케이스 갱신·정황별 전략 → 결함 검출 유지
```

| 구분 | 내용 |
|:---|:---|
| 목적 | 한정 자원으로 결함 검출 효율 극대화 전략 제시 |
| 장점 | 위험기반 우선순위, 조기검출로 비용절감 |
| 한계 | 결함 부재 보장 불가, 정황별 적용 판단 필요 |

## Ⅳ. 실무 적용 및 기술사 판단
- 살충제 패러독스 대응: 테스트 케이스 주기적 리뷰·갱신
- 결함 집중 원리로 위험기반 테스트(RBT) 우선순위 설정
- 조기 테스트는 시프트레프트(Shift-left)·TDD와 연계

- 답안 포인트
  - 도입 전제, 운영 리스크, 기대 효과를 한 세트로 기술
  - 조직·프로세스·아키텍처 관점의 판단 기준을 함께 제시

## Ⅴ. 2~4교시 확장 프레임
| 확장 문단 | 서술 포인트 |
|:---|:---|
| 서론 | 품질 위험과 테스트 필요성 |
| 본론 1 | 기법·절차·커버리지 구조 |
| 본론 2 | 정적/동적 또는 기능/비기능 비교 |
| 본론 3 | 자동화·회귀 전략 |
| 결론 | 품질 지표와 운영 연계 |


- 전개 순서
  1. 문제 배경과 필요성 제시
  2. 핵심 원리·구성요소·절차 설명
  3. 대안 구조 또는 유사 개념과 비교
  4. 도입 효과, 리스크, 기술사 판단 정리
  5. 확장 방향과 결론으로 마무리
