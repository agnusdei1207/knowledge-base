## Ⅰ. 출제 관점 및 1교시 답안 포인트
> 가용성(Availability)은 시스템이 정상 운영되는 시간 비율로, 평균고장간격(MTBF)과 평균복구시간(MTTR)으로 산출되는 신뢰성·운영 품질지표이다.

| 답안 축 | 정리 포인트 |
|:---|:---|
| 출제 맥락 | 모듈 경계, 아키텍처 스타일, 설계 원칙, 패턴, 품질속성까지 설계 판단을 묻는 축 |
| 1교시 기본 골격 | 정의 -> 목적 -> 핵심 요소/절차 -> 장단점/지표 -> 적용 판단 |
| 함께 묶을 논점 | 응집도/결합도, 아키텍처 뷰, MVC, MSA, DDD, SOLID, DI, 코드 품질 메트릭 |
| 2~4교시 확장 방향 | 설계 목표와 품질속성, 구성요소·패턴·원리, 대안 구조 비교, 적용 조건과 안티패턴 |


- 답안 포인트
  - `가용성 (MTBF·MTTR)`가 해결하려는 문제와 목적을 첫 문장에 압축
  - 핵심 구성요소·절차·지표는 3~5개 축으로 정리
  - 비교 개념과 실무 적용 조건을 함께 적시해 확장성 확보

## Ⅱ. 핵심 구조 및 메커니즘
- MTBF(Mean Time Between Failures): 평균 고장 간격(신뢰성)
- MTTR(Mean Time To Repair): 평균 복구 시간(보전성)
- MTTF(Mean Time To Failure): 비수리 시스템 평균 수명
- 가용도 = MTBF / (MTBF + MTTR)
- 목표: MTBF↑(고장 감소), MTTR↓(복구 신속)

## Ⅲ. 비교·구조·지표 정리
```text
정상 ──고장──> 다운 ──복구──> 정상
 │← MTBF →│←MTTR→│
가용도 = MTBF / (MTBF + MTTR)
예) 99.999% → 연간 약 5분 다운
```

| 구분 | 내용 |
|:---|:---|
| 목적 | 시스템 운영 연속성을 정량 측정·관리(SLA 기준) |
| 장점 | 신뢰성·보전성 분리 평가, 가용도 목표 수립 용이 |
| 한계 | 평균값 한계(분포 미반영), 측정 데이터 정확성 의존 |

## Ⅳ. 실무 적용 및 기술사 판단
- SLA(서비스수준협약)의 가용도(예: Five-nines 99.999%) 산정 근거
- 이중화·장애극복(Failover)으로 MTBF↑, 자동복구로 MTTR↓
- ISO 25010 신뢰성 특성의 정량 평가 지표로 연계

- 답안 포인트
  - 도입 전제, 운영 리스크, 기대 효과를 한 세트로 기술
  - 조직·프로세스·아키텍처 관점의 판단 기준을 함께 제시

## Ⅴ. 2~4교시 확장 프레임
| 확장 문단 | 서술 포인트 |
|:---|:---|
| 서론 | 설계 목표와 품질속성 |
| 본론 1 | 구성요소·패턴·원리 |
| 본론 2 | 대안 구조 비교 |
| 본론 3 | 적용 조건과 안티패턴 |
| 결론 | 유지보수성과 확장성 결론 |


- 전개 순서
  1. 문제 배경과 필요성 제시
  2. 핵심 원리·구성요소·절차 설명
  3. 대안 구조 또는 유사 개념과 비교
  4. 도입 효과, 리스크, 기술사 판단 정리
  5. 확장 방향과 결론으로 마무리
