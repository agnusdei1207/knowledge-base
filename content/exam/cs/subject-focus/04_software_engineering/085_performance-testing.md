## Ⅰ. 출제 관점 및 1교시 답안 포인트
> 성능 테스트(Performance Testing)는 시스템의 응답시간·처리량·자원사용을 다양한 부하 조건에서 측정·검증하는 비기능 테스트이다.

| 답안 축 | 정리 포인트 |
|:---|:---|
| 출제 맥락 | 검증·확인, 테스트 설계, 커버리지, 회귀/성능까지 품질보증 체계를 묻는 축 |
| 1교시 기본 골격 | 정의 -> 목적 -> 핵심 요소/절차 -> 장단점/지표 -> 적용 판단 |
| 함께 묶을 논점 | 테스트 원리, 블랙박스/화이트박스, 테스트 레벨, 회귀, 성능, TDD, 테스트 더블 |
| 2~4교시 확장 방향 | 품질 위험과 테스트 필요성, 기법·절차·커버리지 구조, 정적/동적 또는 기능/비기능 비교, 자동화·회귀 전략 |


- 답안 포인트
  - `성능 테스트 (부하·스트레스·스파이크)`가 해결하려는 문제와 목적을 첫 문장에 압축
  - 핵심 구성요소·절차·지표는 3~5개 축으로 정리
  - 비교 개념과 실무 적용 조건을 함께 적시해 확장성 확보

## Ⅱ. 핵심 구조 및 메커니즘
- 부하 테스트(Load): 예상 최대 부하에서 성능 목표 충족 검증
- 스트레스 테스트(Stress): 한계 초과 부하로 임계점·붕괴거동 확인
- 스파이크 테스트(Spike): 급격한 부하 급증·급감 시 대응 검증
- 내구 테스트(Soak/Endurance): 장시간 부하로 메모리 누수 검출
- 주요 지표: 응답시간(Latency), 처리량(TPS), 자원사용률

## Ⅲ. 비교·구조·지표 정리
```text
부하증가 →  TPS·응답시간 측정
  │
정상부하(Load) → 한계초과(Stress) → 급증(Spike)
  │
임계점·병목 식별 → 튜닝/스케일링
```

| 구분 | 내용 |
|:---|:---|
| 목적 | 부하 조건별 성능·안정성·확장성 검증 |
| 장점 | 병목·임계점 사전식별, 용량산정·SLA 근거 |
| 한계 | 실환경 재현 난이도, 테스트 데이터·환경 비용 |

## Ⅳ. 실무 적용 및 기술사 판단
- 용량산정(Capacity Planning)·오토스케일링 정책 수립 근거
- ISO 25010 성능효율성 특성의 정량 평가 수단
- JMeter·nGrinder 등으로 자동화, APM과 연계해 병목 분석

- 답안 포인트
  - 도입 전제, 운영 리스크, 기대 효과를 한 세트로 기술
  - 조직·프로세스·아키텍처 관점의 판단 기준을 함께 제시

## Ⅴ. 2~4교시 확장 프레임
| 확장 문단 | 서술 포인트 |
|:---|:---|
| 서론 | 품질 위험과 테스트 필요성 |
| 본론 1 | 기법·절차·커버리지 구조 |
| 본론 2 | 정적/동적 또는 기능/비기능 비교 |
| 본론 3 | 자동화·회귀 전략 |
| 결론 | 품질 지표와 운영 연계 |


- 전개 순서
  1. 문제 배경과 필요성 제시
  2. 핵심 원리·구성요소·절차 설명
  3. 대안 구조 또는 유사 개념과 비교
  4. 도입 효과, 리스크, 기술사 판단 정리
  5. 확장 방향과 결론으로 마무리
