## Ⅰ. 출제 관점 및 1교시 답안 포인트
> EVM(Earned Value Management, 획득가치관리)은 계획가치·획득가치·실제원가를 통합 측정하여 일정·원가 성과를 정량 분석하고 완료시점을 예측하는 프로젝트 통제 기법이다.

| 답안 축 | 정리 포인트 |
|:---|:---|
| 출제 맥락 | 생명주기, 프로세스 성숙도, 형상/품질/원가/일정/위험 관리의 통합 판단 |
| 1교시 기본 골격 | 정의 -> 목적 -> 핵심 요소/절차 -> 장단점/지표 -> 적용 판단 |
| 함께 묶을 논점 | SDLC, 프로세스 모델, CMMI, 형상관리, 원가·일정·리스크 |
| 2~4교시 확장 방향 | 도입 배경과 관리 필요성, 핵심 절차·지표·산출물, 성숙도/방법론 비교, 프로젝트 통제와 조직 적용 |


- 답안 포인트
  - `획득가치관리 (EVM)`가 해결하려는 문제와 목적을 첫 문장에 압축
  - 핵심 구성요소·절차·지표는 3~5개 축으로 정리
  - 비교 개념과 실무 적용 조건을 함께 적시해 확장성 확보

## Ⅱ. 핵심 구조 및 메커니즘
- PV(Planned Value, 계획가치): 계획된 작업의 예산
- EV(Earned Value, 획득가치): 실제 완료 작업의 예산가치
- AC(Actual Cost, 실제원가): 완료 작업의 실투입 비용
- SV=EV−PV(일정차이), CV=EV−AC(원가차이)
- SPI=EV/PV(일정효율), CPI=EV/AC(원가효율)

## Ⅲ. 비교·구조·지표 정리
```text
계획: [PV 곡선]   실적: [EV], [AC]
   SV=EV-PV, CV=EV-AC
   SPI=EV/PV, CPI=EV/AC
   → EAC(완료시점 예측) 산정
```

| 구분 | 내용 |
|:---|:---|
| 목적 | 일정·원가 성과 통합 측정 및 완료 예측 |
| 장점 | SPI<1/CPI<1로 조기 경보, 객관적 정량 지표 |
| 한계 | 정확한 WBS·진척률 측정 전제, 품질은 직접 반영 못 함 |

## Ⅳ. 실무 적용 및 기술사 판단
- WBS·일정·원가 기준선 통합, CMMI 레벨4 정량관리 수단
- CPI 기반 EAC=BAC/CPI로 잔여 예산 예측·시정조치 결정

- 답안 포인트
  - 도입 전제, 운영 리스크, 기대 효과를 한 세트로 기술
  - 조직·프로세스·아키텍처 관점의 판단 기준을 함께 제시

## Ⅴ. 2~4교시 확장 프레임
| 확장 문단 | 서술 포인트 |
|:---|:---|
| 서론 | 도입 배경과 관리 필요성 |
| 본론 1 | 핵심 절차·지표·산출물 |
| 본론 2 | 성숙도/방법론 비교 |
| 본론 3 | 프로젝트 통제와 조직 적용 |
| 결론 | 기대효과와 한계 |


- 전개 순서
  1. 문제 배경과 필요성 제시
  2. 핵심 원리·구성요소·절차 설명
  3. 대안 구조 또는 유사 개념과 비교
  4. 도입 효과, 리스크, 기술사 판단 정리
  5. 확장 방향과 결론으로 마무리
