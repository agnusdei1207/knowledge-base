## Ⅰ. 출제 관점 및 1교시 답안 포인트
> 브룩스의 법칙(Brooks's Law)은 "지연된 SW 프로젝트에 인력을 추가하면 오히려 더 늦어진다"는 경험칙이다. 신규 인력 교육 비용과 의사소통 경로 폭증이 생산성 저하를 유발한다.

| 답안 축 | 정리 포인트 |
|:---|:---|
| 출제 맥락 | 생명주기, 프로세스 성숙도, 형상/품질/원가/일정/위험 관리의 통합 판단 |
| 1교시 기본 골격 | 정의 -> 목적 -> 핵심 요소/절차 -> 장단점/지표 -> 적용 판단 |
| 함께 묶을 논점 | SDLC, 프로세스 모델, CMMI, 형상관리, 원가·일정·리스크 |
| 2~4교시 확장 방향 | 도입 배경과 관리 필요성, 핵심 절차·지표·산출물, 성숙도/방법론 비교, 프로젝트 통제와 조직 적용 |


- 답안 포인트
  - `브룩스의 법칙 (Brooks's Law)`가 해결하려는 문제와 목적을 첫 문장에 압축
  - 핵심 구성요소·절차·지표는 3~5개 축으로 정리
  - 비교 개념과 실무 적용 조건을 함께 적시해 확장성 확보

## Ⅱ. 핵심 구조 및 메커니즘
- 의사소통 경로: n명일 때 경로 수 = n(n−1)/2 로 제곱에 비례 증가
- 학습 곡선(Ramp-up): 신규 인력 적응에 기존 인력의 멘토링 시간 소모
- 작업 분할 한계: 모든 작업이 병렬화되지 않음(순차 의존)
- 결과: 추가 인력의 한계 생산성이 음(−)이 될 수 있음

## Ⅲ. 비교·구조·지표 정리
```text
[프로젝트 지연] → [인력 추가]
   → 의사소통 경로 n(n-1)/2 급증 + 교육부하
   → 기존 인력 생산성↓
   → [일정 추가 지연] (역설)
```

| 구분 | 내용 |
|:---|:---|
| 목적 | 후반 인력 투입의 비효율 경고, 일정관리 원칙 제시 |
| 장점 | 무리한 인력 증원 대신 범위·일정 조정 의사결정 유도 |
| 한계 | 모든 상황에 일률 적용 곤란, 초기 투입엔 해당 작음 |

## Ⅳ. 실무 적용 및 기술사 판단
- 대안: 범위 축소(MVP), 작업 재분배, 일정 재협상, 조기 인력 확보
- 소규모 자율팀·모듈화로 의사소통 경로 절감 설계

- 답안 포인트
  - 도입 전제, 운영 리스크, 기대 효과를 한 세트로 기술
  - 조직·프로세스·아키텍처 관점의 판단 기준을 함께 제시

## Ⅴ. 2~4교시 확장 프레임
| 확장 문단 | 서술 포인트 |
|:---|:---|
| 서론 | 도입 배경과 관리 필요성 |
| 본론 1 | 핵심 절차·지표·산출물 |
| 본론 2 | 성숙도/방법론 비교 |
| 본론 3 | 프로젝트 통제와 조직 적용 |
| 결론 | 기대효과와 한계 |


- 전개 순서
  1. 문제 배경과 필요성 제시
  2. 핵심 원리·구성요소·절차 설명
  3. 대안 구조 또는 유사 개념과 비교
  4. 도입 효과, 리스크, 기술사 판단 정리
  5. 확장 방향과 결론으로 마무리
