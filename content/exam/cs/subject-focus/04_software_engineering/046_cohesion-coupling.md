## Ⅰ. 출제 관점 및 1교시 답안 포인트
> 응집도(Cohesion)는 모듈 내부 구성요소가 하나의 기능을 위해 모인 정도, 결합도(Coupling)는 모듈 간 상호 의존 정도를 나타내는 설계 품질 척도이다. 좋은 설계는 응집도↑·결합도↓를 지향한다.

| 답안 축 | 정리 포인트 |
|:---|:---|
| 출제 맥락 | 모듈 경계, 아키텍처 스타일, 설계 원칙, 패턴, 품질속성까지 설계 판단을 묻는 축 |
| 1교시 기본 골격 | 정의 -> 목적 -> 핵심 요소/절차 -> 장단점/지표 -> 적용 판단 |
| 함께 묶을 논점 | 응집도/결합도, 아키텍처 뷰, MVC, MSA, DDD, SOLID, DI, 코드 품질 메트릭 |
| 2~4교시 확장 방향 | 설계 목표와 품질속성, 구성요소·패턴·원리, 대안 구조 비교, 적용 조건과 안티패턴 |


- 답안 포인트
  - `응집도·결합도 (Cohesion·Coupling)`가 해결하려는 문제와 목적을 첫 문장에 압축
  - 핵심 구성요소·절차·지표는 3~5개 축으로 정리
  - 비교 개념과 실무 적용 조건을 함께 적시해 확장성 확보

## Ⅱ. 핵심 구조 및 메커니즘
- 응집도 7종(강→약): 기능적 > 순차적 > 교환적(통신적) > 절차적 > 시간적 > 논리적 > 우연적
- 결합도 6종(약→강): 자료(Data) < 스탬프(Stamp) < 제어(Control) < 외부(External) < 공통(Common) < 내용(Content)
- 응집도가 높을수록 모듈 독립성·재사용성·유지보수성 향상
- 결합도가 낮을수록 변경 파급 최소화, 모듈 교체 용이
- 매개변수는 자료 결합으로, 전역변수·플래그 제어는 강한 결합으로 귀결

## Ⅲ. 비교·구조·지표 정리
```text
[설계 목표]
  응집도 ↑ ──> 모듈 내부 단일 책임(기능적 응집)
  결합도 ↓ ──> 모듈 간 인터페이스 최소(자료 결합)
        │
        ▼
  독립성·재사용성·유지보수성 향상
```

| 구분 | 내용 |
|:---|:---|
| 목적 | 모듈 독립성 확보로 유지보수·재사용성 극대화 |
| 장점 | 변경 영향 국소화, 테스트 용이, 병렬 개발 가능 |
| 한계 | 과도한 분할 시 모듈 수 증가·호출 오버헤드, 정량 측정 곤란 |

## Ⅳ. 실무 적용 및 기술사 판단
- 구조적 설계 평가 기준이자 객체지향 SOLID·MSA 모듈 경계 설계의 토대
- 정적분석 도구(SonarQube)로 결합도·복잡도 지표화하여 리팩토링 우선순위 도출

- 답안 포인트
  - 도입 전제, 운영 리스크, 기대 효과를 한 세트로 기술
  - 조직·프로세스·아키텍처 관점의 판단 기준을 함께 제시
