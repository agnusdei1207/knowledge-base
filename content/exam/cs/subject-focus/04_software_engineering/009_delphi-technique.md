## Ⅰ. 출제 관점 및 1교시 답안 포인트
> 델파이(Delphi) 기법은 다수 전문가가 익명으로 반복 설문·피드백을 거쳐 수렴된 합의 추정치를 도출하는 정성적 산정·예측 방법이다. 전문가 판단 기반 비용·일정·위험 추정에 활용된다.

| 답안 축 | 정리 포인트 |
|:---|:---|
| 출제 맥락 | 생명주기, 프로세스 성숙도, 형상/품질/원가/일정/위험 관리의 통합 판단 |
| 1교시 기본 골격 | 정의 -> 목적 -> 핵심 요소/절차 -> 장단점/지표 -> 적용 판단 |
| 함께 묶을 논점 | SDLC, 프로세스 모델, CMMI, 형상관리, 원가·일정·리스크 |
| 2~4교시 확장 방향 | 도입 배경과 관리 필요성, 핵심 절차·지표·산출물, 성숙도/방법론 비교, 프로젝트 통제와 조직 적용 |


- 답안 포인트
  - `델파이 기법 (Delphi)`가 해결하려는 문제와 목적을 첫 문장에 압축
  - 핵심 구성요소·절차·지표는 3~5개 축으로 정리
  - 비교 개념과 실무 적용 조건을 함께 적시해 확장성 확보

## Ⅱ. 핵심 구조 및 메커니즘
- 익명성(Anonymity): 권위·다수 압력 배제로 편향 제거
- 반복(Iteration): 여러 라운드 설문 반복 수행
- 통제된 피드백(Feedback): 라운드별 통계 요약 제공
- 통계적 집계(Aggregation): 중앙값·사분위로 합의 정도 측정
- 진행자(Facilitator)가 의견을 취합·조정

## Ⅲ. 비교·구조·지표 정리
```text
[전문가 패널 구성] → [1차 익명 설문]
   → [통계 요약 피드백] → [재설문]
   → 수렴? → 예: [합의 추정치] / 아니오: 반복
```

> 라운드는 통상 2~4회 반복하여 수렴시킨다.

## Ⅳ. 실무 적용 및 기술사 판단
| 구분 | 내용 |
|:---|:---|
| 목적 | 데이터 부족·신규영역에서 전문가 합의 추정 |
| 장점 | 편향 완화, 폭넓은 전문지식 수렴 |
| 한계 | 시간 소요, 전문가 선정·진행자 역량 의존 |

- 답안 포인트
  - 도입 전제, 운영 리스크, 기대 효과를 한 세트로 기술
  - 조직·프로세스·아키텍처 관점의 판단 기준을 함께 제시

## Ⅴ. 2~4교시 확장 프레임
| 확장 문단 | 서술 포인트 |
|:---|:---|
| 서론 | 도입 배경과 관리 필요성 |
| 본론 1 | 핵심 절차·지표·산출물 |
| 본론 2 | 성숙도/방법론 비교 |
| 본론 3 | 프로젝트 통제와 조직 적용 |
| 결론 | 기대효과와 한계 |


- 전개 순서
  1. 문제 배경과 필요성 제시
  2. 핵심 원리·구성요소·절차 설명
  3. 대안 구조 또는 유사 개념과 비교
  4. 도입 효과, 리스크, 기술사 판단 정리
  5. 확장 방향과 결론으로 마무리
