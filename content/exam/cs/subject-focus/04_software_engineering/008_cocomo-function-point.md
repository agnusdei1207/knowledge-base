## Ⅰ. 출제 관점 및 1교시 답안 포인트
> COCOMO(Constructive Cost Model, 구성적 비용모델)는 LOC(Line of Code) 규모로 노력·기간을 추정하는 모델이며, FP(Function Point, 기능점수)는 사용자 관점 기능 규모로 산정하는 기법이다. 둘 다 SW 비용·규모 산정에 사용된다.

| 답안 축 | 정리 포인트 |
|:---|:---|
| 출제 맥락 | 생명주기, 프로세스 성숙도, 형상/품질/원가/일정/위험 관리의 통합 판단 |
| 1교시 기본 골격 | 정의 -> 목적 -> 핵심 요소/절차 -> 장단점/지표 -> 적용 판단 |
| 함께 묶을 논점 | SDLC, 프로세스 모델, CMMI, 형상관리, 원가·일정·리스크 |
| 2~4교시 확장 방향 | 도입 배경과 관리 필요성, 핵심 절차·지표·산출물, 성숙도/방법론 비교, 프로젝트 통제와 조직 적용 |


- 답안 포인트
  - `COCOMO·기능점수 (COCOMO·FP)`가 해결하려는 문제와 목적을 첫 문장에 압축
  - 핵심 구성요소·절차·지표는 3~5개 축으로 정리
  - 비교 개념과 실무 적용 조건을 함께 적시해 확장성 확보

## Ⅱ. 핵심 구조 및 메커니즘
- COCOMO 유형: Organic(단순)·Semi-detached(중간)·Embedded(복잡)
- 노력 산정식: 노력(MM)=a·(KLOC)^b, 기간 도출
- FP 구성요소: EI·EO·EQ·ILF·EIF 5요소를 가중치로 집계
- 보정: 복잡도 14개 일반시스템특성(GSC)으로 조정계수 산출
- FP→규모/원가 환산으로 언어 독립적 산정

## Ⅲ. 비교·구조·지표 정리
```text
COCOMO: [KLOC 추정] → 노력=a·KLOC^b → 기간/인력
FP    : [기능 식별] → 가중치 합(UFP)
        → 조정계수(VAF) → AFP → 원가
```

| 구분 | 내용 |
|:---|:---|
| 목적 | 개발 노력·비용·규모의 정량 추정 |
| 장점 | COCOMO(이력 기반 간편), FP(언어독립·요구단계 적용) |
| 한계 | COCOMO(LOC 사전추정 어려움), FP(산정자 숙련 필요) |

## Ⅳ. 실무 적용 및 기술사 판단
- 공공 SW 사업대가 산정은 기능점수(FP) 방식을 표준 적용
- 초기 견적은 FP, 상세 설계 후 COCOMO로 교차 검증

- 답안 포인트
  - 도입 전제, 운영 리스크, 기대 효과를 한 세트로 기술
  - 조직·프로세스·아키텍처 관점의 판단 기준을 함께 제시

## Ⅴ. 2~4교시 확장 프레임
| 확장 문단 | 서술 포인트 |
|:---|:---|
| 서론 | 도입 배경과 관리 필요성 |
| 본론 1 | 핵심 절차·지표·산출물 |
| 본론 2 | 성숙도/방법론 비교 |
| 본론 3 | 프로젝트 통제와 조직 적용 |
| 결론 | 기대효과와 한계 |


- 전개 순서
  1. 문제 배경과 필요성 제시
  2. 핵심 원리·구성요소·절차 설명
  3. 대안 구조 또는 유사 개념과 비교
  4. 도입 효과, 리스크, 기술사 판단 정리
  5. 확장 방향과 결론으로 마무리
