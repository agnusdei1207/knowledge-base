## Ⅰ. 출제 관점 및 1교시 답안 포인트
> WBS(Work Breakdown Structure, 작업분해구조)는 프로젝트 범위를 관리 가능한 작업패키지로 계층 분해한 것이며, CPM(Critical Path Method, 임계경로법)과 PERT(Program Evaluation and Review Technique, 3점 추정 기반 일정기법)는 이를 토대로 일정을 산정·통제한다.

| 답안 축 | 정리 포인트 |
|:---|:---|
| 출제 맥락 | 생명주기, 프로세스 성숙도, 형상/품질/원가/일정/위험 관리의 통합 판단 |
| 1교시 기본 골격 | 정의 -> 목적 -> 핵심 요소/절차 -> 장단점/지표 -> 적용 판단 |
| 함께 묶을 논점 | SDLC, 프로세스 모델, CMMI, 형상관리, 원가·일정·리스크 |
| 2~4교시 확장 방향 | 도입 배경과 관리 필요성, 핵심 절차·지표·산출물, 성숙도/방법론 비교, 프로젝트 통제와 조직 적용 |


- 답안 포인트
  - `WBS·CPM·PERT`가 해결하려는 문제와 목적을 첫 문장에 압축
  - 핵심 구성요소·절차·지표는 3~5개 축으로 정리
  - 비교 개념과 실무 적용 조건을 함께 적시해 확장성 확보

## Ⅱ. 핵심 구조 및 메커니즘
- WBS: 100% 규칙 하에 작업패키지로 분해, 일정·원가 산정 기준
- CPM: 가장 긴 경로(임계경로)가 총 공기 결정, 여유(Float) 산출
- PERT: 낙관(O)·최빈(M)·비관(P) 3점 추정, 기대치 TE=(O+4M+P)/6
- 선후행 네트워크(AON/AOA)로 작업 의존성 표현

## Ⅲ. 비교·구조·지표 정리
```text
[프로젝트] → WBS 분해 → [작업패키지]
   → 의존관계 네트워크 구성
   → CPM(임계경로 산출) / PERT(3점 기대일정)
```

| 구분 | 내용 |
|:---|:---|
| 목적 | 범위 구조화 및 일정·임계경로 기반 통제 |
| 장점 | WBS(누락방지), CPM(병목식별), PERT(불확실성 반영) |
| 한계 | 추정 정확도 의존, 네트워크 갱신·관리 부담 |

## Ⅳ. 실무 적용 및 기술사 판단
- WBS는 원가산정·EVM의 PV 산출 및 책임배정(RAM)의 기준
- 임계경로 단축(Crashing·Fast Tracking)으로 일정 압축 의사결정

- 답안 포인트
  - 도입 전제, 운영 리스크, 기대 효과를 한 세트로 기술
  - 조직·프로세스·아키텍처 관점의 판단 기준을 함께 제시

## Ⅴ. 2~4교시 확장 프레임
| 확장 문단 | 서술 포인트 |
|:---|:---|
| 서론 | 도입 배경과 관리 필요성 |
| 본론 1 | 핵심 절차·지표·산출물 |
| 본론 2 | 성숙도/방법론 비교 |
| 본론 3 | 프로젝트 통제와 조직 적용 |
| 결론 | 기대효과와 한계 |


- 전개 순서
  1. 문제 배경과 필요성 제시
  2. 핵심 원리·구성요소·절차 설명
  3. 대안 구조 또는 유사 개념과 비교
  4. 도입 효과, 리스크, 기술사 판단 정리
  5. 확장 방향과 결론으로 마무리
