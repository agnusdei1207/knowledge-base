## Ⅰ. 출제 관점 및 1교시 답안 포인트
> AI4SE(AI for Software Engineering)는 대규모 언어모델(LLM)·생성형 AI를 코드 생성·테스트·리뷰·운영 등 소프트웨어 개발 전 과정에 적용해 생산성과 품질을 향상시키는 공학 패러다임이다.

| 답안 축 | 정리 포인트 |
|:---|:---|
| 출제 맥락 | 언어/runtime 혁신과 AI 활용 공학을 기술사 관점에서 실효성과 제약으로 정리하는 축 |
| 1교시 기본 골격 | 정의 -> 목적 -> 핵심 요소/절차 -> 장단점/지표 -> 적용 판단 |
| 함께 묶을 논점 | Virtual Threads, WebAssembly, AI4SE |
| 2~4교시 확장 방향 | 등장 배경과 기술 변화, 핵심 동작 원리, 기존 방식 대비 차이, 적용 시 리스크와 생산성 영향 |


- 답안 포인트
  - `AI 활용 소프트웨어공학 (AI4SE)`가 해결하려는 문제와 목적을 첫 문장에 압축
  - 핵심 구성요소·절차·지표는 3~5개 축으로 정리
  - 비교 개념과 실무 적용 조건을 함께 적시해 확장성 확보

## Ⅱ. 핵심 구조 및 메커니즘
- 코드 어시스턴트: Copilot이 문맥 기반 코드 자동완성·생성
- 오케스트레이션: LangChain이 LLM·도구·메모리·RAG를 체이닝
- Agentic AI: 목표를 자율 계획·실행·검증하는 에이전트(다단계 작업)
- RAG(검색증강생성): 외부 지식 검색으로 환각 완화·정확도 향상
- 전 단계 적용: 요구분석·설계·구현·테스트·문서·리뷰 자동화

## Ⅲ. 비교·구조·지표 정리
```text
개발자 의도 → [LLM/Copilot] → 코드/테스트 생성
                │
       [Agent: 계획→실행→도구호출→검증]
                │ RAG(코드베이스/문서 검색)
                → 리뷰·반영 (Human-in-the-loop)
```

| 구분 | 내용 |
|:---|:---|
| 목적 | AI로 개발 생산성·품질·속도 향상 |
| 장점 | 반복작업 자동화·생산성↑·진입장벽↓·신속 프로토타이핑 |
| 한계 | 환각·보안취약 코드·IP/라이선스·과의존·검증 필수 |

## Ⅳ. 실무 적용 및 기술사 판단
- Human-in-the-loop로 생성물 검증, 보안은 SCA·SAST 병행 필수
- Agentic AI는 자율성↑이나 거버넌스·감사·가드레일 필요
- 시큐어 SDLC와 결합해 AI 생성 코드의 취약점 자동 점검

- 답안 포인트
  - 도입 전제, 운영 리스크, 기대 효과를 한 세트로 기술
  - 조직·프로세스·아키텍처 관점의 판단 기준을 함께 제시
