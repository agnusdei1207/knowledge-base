## Ⅰ. 출제 관점 및 1교시 답안 포인트
> 제품 기능의 충족도와 고객 만족도 관계를 5가지 품질 유형으로 분류하여 요구 우선순위를 도출하는 고객만족 모델.

| 답안 축 | 정리 포인트 |
|:---|:---|
| 출제 맥락 | 요구 도출부터 우선순위, 명세, 추적성까지 품질 좋은 요구를 만드는 분석 출제축 |
| 1교시 기본 골격 | 정의 -> 목적 -> 핵심 요소/절차 -> 장단점/지표 -> 적용 판단 |
| 함께 묶을 논점 | 요구공학, SRS, RTM, 유스케이스, DFD, QFD, MoSCoW, 스토리맵 |
| 2~4교시 확장 방향 | 문제 상황과 이해관계자 관점, 도출·분석·명세 절차, 도구/기법 비교, 변경 통제와 검증 적용 |


- 답안 포인트
  - `카노 모델 (Kano Model)`가 해결하려는 문제와 목적을 첫 문장에 압축
  - 핵심 구성요소·절차·지표는 3~5개 축으로 정리
  - 비교 개념과 실무 적용 조건을 함께 적시해 확장성 확보

## Ⅱ. 핵심 구조 및 메커니즘
- 매력적(Attractive): 있으면 감동, 없어도 불만 없음
- 일원적(One-dimensional): 충족도에 비례해 만족 증가
- 당연적(Must-be): 있어도 당연, 없으면 큰 불만
- 무관심(Indifferent): 있든 없든 만족 무관
- 역(Reverse) 품질: 있으면 오히려 불만 유발

## Ⅲ. 비교·구조·지표 정리
```text
만족↑
   │   매력적 ╱
   │      ╱ 일원적
───┼────●──── 충족도→
   │ ╱당연적
만족↓ (미충족 시 급락)
```

| 구분 | 내용 |
|:---|:---|
| 목적 | 만족 기여도 기준 기능 우선순위화 |
| 장점 | 매력 품질 발굴로 차별화, 투자 효율화 |
| 한계 | 시간경과로 매력→당연 변화, 설문 의존 |

## Ⅳ. 실무 적용 및 기술사 판단
- 당연적은 Must(기본 충족), 매력적은 차별화 투자 대상
- MoSCoW·QFD와 결합해 우선순위 정교화
- 설문(충족/불충족 쌍)으로 품질유형 분류

- 답안 포인트
  - 도입 전제, 운영 리스크, 기대 효과를 한 세트로 기술
  - 조직·프로세스·아키텍처 관점의 판단 기준을 함께 제시

## Ⅴ. 2~4교시 확장 프레임
| 확장 문단 | 서술 포인트 |
|:---|:---|
| 서론 | 문제 상황과 이해관계자 관점 |
| 본론 1 | 도출·분석·명세 절차 |
| 본론 2 | 도구/기법 비교 |
| 본론 3 | 변경 통제와 검증 적용 |
| 결론 | 실패 예방 효과 |


- 전개 순서
  1. 문제 배경과 필요성 제시
  2. 핵심 원리·구성요소·절차 설명
  3. 대안 구조 또는 유사 개념과 비교
  4. 도입 효과, 리스크, 기술사 판단 정리
  5. 확장 방향과 결론으로 마무리
