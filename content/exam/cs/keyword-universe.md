# 기출 키워드 우주

## 분석 범위

- 로컬 회차 문서: `120회~138회`
- 외부 참조: [IT Wiki 컴퓨터시스템응용기술사 기출 문제](https://itwiki.kr/w/%EC%BB%B4%ED%93%A8%ED%84%B0%EC%8B%9C%EC%8A%A4%ED%85%9C%EC%9D%91%EC%9A%A9%EA%B8%B0%EC%88%A0%EC%82%AC_%EA%B8%B0%EC%B6%9C_%EB%AC%B8%EC%A0%9C)
- 기준: **자주 나온 키워드 + 1회라도 나온 최신/특이 키워드 모두 편입 후보**

```text
[기출 키워드 우주]
   ├─ 반복 빈출군
   ├─ 2회 이상 재등장군
   └─ 1회 출제 확장군
```

## A. 반복 빈출군

| 군집 | 대표 키워드 |
|:---|:---|
| 컴퓨터 구조 | 캐시, 파이프라이닝, 메모리 계층, ARM/x86, NUMA |
| 운영체제 | 교착상태, 스케줄링, 세마포어, 가상 메모리, 스레드 |
| 네트워크/클라우드 | TCP/UDP, OSI, VM/컨테이너, 쿠버네티스, 클라우드 서비스 모델 |
| SW공학 | MSA, 애자일, SOLID, 품질, 아키텍처 평가, 감리 |
| 데이터베이스 | ACID, 격리수준, 인덱스, 정규화, 샤딩/파티셔닝 |
| 보안 | 제로 트러스트, 침입 탐지, 공개키 기반구조(PKI), 공급망 보안, 개인정보 보호 |
| AI | LLM, RAG, Transformer, 강화학습, 생성형 AI 보안 |

## B. 2회 이상 재등장군

| 영역 | 포함 키워드 |
|:---|:---|
| AI 운영 | MLOps, 모델 드리프트, 분산 학습, 파인튜닝 |
| 클라우드 운영 | FinOps, GitOps, 서비스 메시, 분산 추적, 서버리스 |
| 보안 고도화 | PQC(Post-Quantum Cryptography), CTEM, SBOM, CASB, MITRE ATT&CK |
| 데이터 아키텍처 | 데이터 레이크, 레이크하우스, 데이터 메시, 실시간 스트리밍 |
| 엔터프라이즈 | EA, ISMP, ISP, ITSM, BMT |

## C. 1회 출제라도 포함할 확장군

### 1. 최신 AI/에이전트

- MCP(Model Context Protocol)
- 추론 특화 LLM
- Agentic AI
- 멀티모달 AI
- XAI(Explainable AI)

### 2. 최신 보안/공급망

- 동형암호
- QKD(Quantum Key Distribution)
- AI 거버넌스, EU AI Act
- 생성형 AI 프롬프트 인젝션
- 공급망 무결성 검증

### 3. 최신 인프라/클라우드

- 소버린 클라우드
- CXL(Compute Express Link)
- HBM(High Bandwidth Memory), PIM(Processing-In-Memory)
- WebAssembly
- 가상 스레드

### 4. 융합/비정형 출제

- 스마트 팩토리
- 디지털 트윈
- SDV(Software Defined Vehicle)
- 메타버스
- NFT, DID

## 핵심 트랙 편입 규칙

1. 기출 3회 이상은 `핵심 2,000`에 우선 편입
2. 기출 1~2회라도 2024~2026 신기술이면 `최신 확장 1,000`에 편입
3. 과목 간 중복 개념은 대표 노트 1개로 수렴
4. 답안형으로 전환 가능한 키워드를 우선 배치
