# CSPE 문제 유형 참조

> 작성법의 유일 정본은 [CSPE 답안 작성법 단일 정본](@/exam/cs/writing-method.md)이다. 이 문서는 문제 신호어별 강조점을 확인하는 참조 문서이며, 별도 템플릿이나 구판 작성법을 제공하지 않는다.

| 문제 신호어 | 먼저 볼 요구사항 | 강조할 흐름 |
|:---|:---|:---|
| 설명하시오 | 개념 본질·구성·원리 | 요구사항 -> 구조설계 -> 기술선정 |
| 비교하시오 | 비교 대상·선택 기준 | 기술선정 -> 트레이드오프 -> 판단 |
| 설계하시오 | 요구사항·제약조건 | 요구사항 -> 구조설계 -> 구현전략 |
| 방안을 제시하시오 | 문제 원인·우선순위 | 운영관리 -> 개선 |
| 문제점과 대책 | 실제 핵심 문제 2~3개 | 문제 1문장 -> 해결 1문장 1:1 연결 |
| 운영하시오 | 지표·통제·복구 | 구현전략 -> 운영관리 -> 개선 |
| 보안하시오 | 자산·위협·통제 | 요구사항 -> 기술선정 -> 운영관리 |

> 요약: 어떤 문제 유형이든 최종 답안은 `요구사항 -> 구조설계 -> 기술선정 -> 구현전략 -> 운영관리 -> 개선` 흐름으로 정리한다.
