## 사용 방법

1. 공개 게시물, 회차 정리 글, 수험 후기에서 회차별 출제 키워드를 직접 수집
2. 회차별 원문 키워드와 표준화 키워드를 분리 기록
3. 1교시 단답형과 2~4교시 서술형을 분리 집계
4. 반복 빈도와 최근성을 함께 반영해 우선순위 토픽을 선정
5. 선정 결과를 `frequency.md`, `shortanswer.md`, `model-answer.md`와 연결해 답안 연습

---

## 공개 키워드 수집 절차

### 1. 수집 원칙

- 비공개 파일 요청 대신 공개된 회차 정리 글, 시험 후기, 복원 게시물만 사용
- 한 회차는 가능하면 2개 이상 출처를 대조해 키워드 일치 여부 확인
- 문제 전체 문장을 억지로 복원하지 말고, 출제 주제와 핵심 기술어를 우선 확보
- 약어는 `원문 약어 / 표준 풀네임`으로 함께 적어 후속 답안 작성에 재사용

### 2. 회차별 기록 순서

| 단계 | 작업 | 산출물 |
|:---|:---|:---|
| 1 | 공개 출처에서 교시별 문항 키워드 수집 | 회차 초안 |
| 2 | 유사 표현 통합 | 표준 키워드 사전 |
| 3 | 과목 분류 | 16과목 매핑 |
| 4 | 출제 의도 태깅 | 정의형·비교형·방안형·설계형 |
| 5 | 빈도 집계 | 고빈도 토픽 목록 |

### 3. 표준화 규칙

- `LLM`, `대규모 언어모델`, `생성형 AI 언어모델` → `LLM(대규모 언어모델)`
- `PQC`, `양자내성암호`, `Post-Quantum Cryptography` → `PQC(양자내성암호)`
- `서비스 메시`, `Istio`, `Sidecar Mesh` → `서비스 메시(Service Mesh)`
- 동일 주제가 단답형과 서술형에 모두 나오면 공통 토픽으로 연결하되 교시 구분은 유지

## 회차별 문항 기록 형식

```markdown
### [연도]-[회차]-[교시]-[문항번호]

**공개 키워드 원문**: (복원 글에 적힌 표현)

**표준 키워드**: (정규화한 주제명)

**교시/유형**: 1교시 단답형 / 2~4교시 서술형

**분류**: (16과목 중 1개)

**세부 키워드**: (키워드1, 키워드2, 키워드3)

**출제 의도**: 정의형 / 비교형 / 방안형 / 설계형 / 사례형

**답안 우선순위**: 상 / 중 / 하

**참조 파일**: (study repo 내 관련 파일 경로)

**출처 메모**: (공개 후기, 복원 게시물 등)
```

## 고빈도 토픽 추출 기준

- 최근 3회 내 2회 이상 출제: **최우선**
- 교시가 달라도 동일 토픽 반복: **상**
- 1교시 단답형과 서술형 모두 출제: **상**
- 최신 2개 회차 신규 기술이지만 확장성이 큰 주제: **상**
- 단발성 제도·정책 이슈: **중**

## 우선순위 판단 규칙

| 조건 | 우선순위 | 판단 기준 |
|:---|:---:|:---|
| 최근 3회 반복 + 서술형 출제 | A | 바로 모범답안 작성 |
| 최근 3회 반복 + 1교시 단답형 출제 | A | 1분 정의형 답안 작성 |
| 최신 회차 선택 추천 | A | 2주 내 서술형 완성 |
| 과거 다출제이나 최근 공백 | B | 압축 정리 후 유지 |
| 일회성 트렌드 | C | 키워드 수준 관리 |
