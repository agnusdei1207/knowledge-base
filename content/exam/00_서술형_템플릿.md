## 심사위원이 좋아하는 답안의 조건

1. **첫 줄에 정의** — 심사위원은 처음 5초에 인상을 결정
2. **로마 숫자 단락** — Ⅰ, Ⅱ, Ⅲ, Ⅳ, Ⅴ 로 구조가 눈에 보여야 함
3. **도식 1개 이상 필수** — 글만 있으면 감점 요인. 박스+화살표 하나라도
4. **표 1개 이상 권장** — 비교·정리·특징을 표로 쓰면 가독성 2배
5. **마지막 단락은 발전 방향** — 단순 암기가 아닌 통찰력을 보여주는 자리
6. **분량** — A4 2~2.5페이지 (너무 적으면 성의 없어 보임, 너무 많으면 핵심이 흐림)

---

## 만능 기본 구조 (모든 유형에 적용)

```
Ⅰ. 개요
   └─ 정의 (1줄) + 등장 배경/필요성 (2~3줄)

Ⅱ. [핵심 개념 / 구조 / 원리]
   └─ 도식(그림) 포함
   └─ 구성요소 또는 동작 방식

Ⅲ. 특징 및 장단점
   └─ 표로 정리

Ⅳ. [유형에 따라 변형] → 아래 참조
   └─ 비교 / 적용 방안 / 사례

Ⅴ. 결론 및 발전 방향
   └─ AI·클라우드 시대 연계 + 시사점 1줄
```

---

## 유형별 Ⅳ 변형

| 문제 유형 | Ⅳ 내용 |
|:---|:---|
| "설명하시오" | 실무 적용 사례 또는 도입 시 고려사항 |
| "비교하시오" | A vs B 비교표 (필수) + 선택 기준 |
| "방안을 제시하시오" | 해결 방안 3~5가지 (번호 매기기) |
| "문제점과 대책을 논하시오" | 문제점 / 원인 / 대책 3단 구성 |
| "설계하시오" | 아키텍처 도식 + 구성요소 설명 |

## 도식 그리는 법 (손으로)

### 계층/아키텍처 구조
```
┌─────────────────────────────┐
│       애플리케이션 계층        │
├─────────────────────────────┤
│         제어 계층             │
├─────────────────────────────┤
│       인프라스트럭처 계층       │
└─────────────────────────────┘
```
→ 손으로 쓸 때: 직사각형 박스를 3~4단으로 쌓고 이름 쓰기

---

### 흐름도 (프로세스)
```
[입력/요청]
    │
    ▼
[처리 단계 1] ──→ [오류] ──→ [예외 처리]
    │
    ▼
[처리 단계 2]
    │
    ▼
[출력/응답]
```
→ 손으로 쓸 때: 박스를 세로로 나열하고 화살표(→↓)로 연결

---

### 순환/피드백 구조 (MLOps, PDCA, 에이전트 루프 등)
```
        ┌──────────────────┐
        │                  │
    [계획] → [실행] → [검증] → [개선]
        │                  │
        └──────────────────┘
               (반복)
```
→ 손으로 쓸 때: 박스 4개를 사각형으로 배치하고 화살표로 순환

---

### 비교 구조 (대칭 도식)
```
        ┌─────────┐     ┌─────────┐
        │    A    │     │    B    │
        │ 특징 1  │     │ 특징 1  │
        │ 특징 2  │     │ 특징 2  │
        └────┬────┘     └────┬────┘
             │               │
             └───────┬───────┘
                     │
               [공통 인터페이스]
```
→ 손으로 쓸 때: 좌우 박스 + 아래 합류 화살표

---

### 관계 구조 (1:N, 요청-응답)
```
[클라이언트]
    │  요청
    ▼
[서버 / 컨트롤러]
    │
    ├──→ [컴포넌트 A]
    ├──→ [컴포넌트 B]
    └──→ [컴포넌트 C]
```

## 시간 배분 (33분 기준)

| 단계 | 시간 | 포인트 |
|:---|:---:|:---|
| 문제 읽고 구조 구상 | 2분 | Ⅰ~Ⅴ 소제목만 먼저 결정 |
| Ⅰ. 개요 | 4분 | 정의 + 배경 |
| Ⅱ. 핵심 원리 + **도식** | 10분 | 도식에 시간 투자할 것 |
| Ⅲ. 특징/장단점 **표** | 7분 | 표 형식으로 정리 |
| Ⅳ. 비교/방안/사례 | 7분 | 유형에 따라 변형 |
| Ⅴ. 결론 + 발전 방향 | 3분 | 마지막 인상 |

## 단골 마무리 문장 (복붙해서 쓸 것)

- "향후 AI·클라우드 전환 가속화에 따라 [개념]의 중요성은 더욱 높아질 것으로 전망된다."
- "[개념]은 단순 도입보다 조직 역량·운영 복잡도·비용을 함께 고려한 단계적 적용이 중요하다."
- "제로트러스트 / DevSecOps / 자율 에이전트 패러다임과 결합하여 [개념]의 실효성이 더욱 확대될 것이다."
- "표준화·자동화·지능화의 흐름 속에서 [개념]은 핵심 인프라 요소로 자리잡을 것이다."

## 실전 연습 방법

1. 기출 문제 1개 선택
2. 타이머 33분 설정
3. 손으로 직접 작성 (키보드 금지)
4. 완성 후 체크리스트 확인:
   - [ ] 정의가 첫 줄에 있는가
   - [ ] 로마 숫자 단락이 5개인가
   - [ ] 도식이 1개 이상인가
   - [ ] 표가 1개 이상인가
   - [ ] 마지막 단락이 발전 방향인가
   - [ ] 분량이 A4 2페이지 이상인가
