# 657. IT 경영 관리 핵심 토픽 657번 시험 요약

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: IT 경영 관리는 **COBIT 2019, ISO/IEC 38500, ITIL 4, TOGAF 10** 등 글로벌 프레임워크를 기반으로 거버넌스-전략-아키텍처-운영-성과의 5축을 통합 관리하며, **EA(Enterprise Architecture)**, **IT 포트폴리오 관리**, **디지털 전환 거버넌스**를 통해 비즈니스 가치(예: ROI 15~25%, TCO 20~30% 절감)를 실현하는 경영 체계이다.
> 2. **가치**: 정량적 효과로는 **IT 투자 대비 ROI 200~400% 향상, ITIL 도입 후 인시던트 MTTR 60% 단축, EA 기반 중복 투자 제거로 CAPEX 25~40% 절감**이 대표적이며, 정성적으로는 **이사회-경영진-IT 정렬(IT-Business Alignment)**을 통한 의사결정 품질 향상 및 **규제 준수(컴플라이언스)** 리스크 완화가 핵심 가치다.
> 3. **판단 포인트**: **"표준 프레임워크 전면 도입 vs. As-Is 분석 후 점진적 커스터마이징"**, **"Centralized 거버넌스 vs. Federated 모델"**, **"Build(자체 구축) vs. Buy(패키지) vs. Cloud SaaS"** 간의 트레이드오프가 핵심 의사결정 포인트이며, 조직의 **IT 성숙도(예: COBIT Maturity 2~5단계)**와 **산업별 규제(금융: 전자금융감독규정, 공공: 클라우드 이용지침)**에 따라 최적 거버넌스 모델이 결정된다.

---

## Ⅰ. 개요 및 필요성

정보기술의 단순한 **도구적 활용(Tool-centric)**에서 벗어나, IT를 **경영 전략의 핵심 동력(Strategic Asset)**으로 재정의해야 하는 시대적 요구가 본격화되면서 **IT 경영 관리(IT Management)**는 기술사 시험의 핵심 토픽으로 부상했다. 한국정보화진흥원(NIA)의 「정보시스템 감리 가이드라인」, 방송통신위원회(과거)의 「클라우드 컴퓨팅 발전 및 이용자 보호에 관한 법률」, 금융위원회의 **「전자금융감독규정」**, 개인정보보호법 등 규제 환경이 강화됨에 따라, IT 투자의 **정당성(Justification)**, **효율성(Efficiency)**, **효과성(Effectiveness)**, **위험 통제(Risk Control)**를 입증할 수 있는 체계적 거버넌스 체계가 필수적이다.

기존 2000년대 이전의 **데이터센터 운영 중심** 패러다임은 **서버·스토리지·네트워크** 등 **하드웨어 자산 관리(Hardware Asset Management)**에 집중했으나, 현재는 **SaaS·PaaS·IaaS** 기반 하이브리드/멀티 클라우드 환경, **데이터 거버넌스**, **AI/ML 윤리**, **제로트러스트 보안** 등 **무형 자산과 외부 서비스에 대한 거버넌스**로 무게중심이 이동했다. McKinsey Global Institute 보고서에 따르면, 글로벌 IT 투자 규모는 2024년 약 **5조 4천억 달러**로 GDP 대비 6% 수준이며, 이 중 **디지털 전환(DX) 투자**가 55% 이상을 차지한다. 그러나 Gartner의 조사에서 **전통 기업 DX 프로젝트의 70% 이상이 실패**하는 것으로 나타나, 단순한 기술 도입이 아닌 **경영 관리 체계(DX Governance)** 없이는 성과 도출이 불가함을 보여준다.

## Ⅱ. 아키텍처 및 핵심 원리

IT 경영 관리의 핵심 메커니즘은 **"전략(S/W) ↔ 아키텍처(A/W) ↔ 운영(O/W)"** 3계층을 **거버넌스(G)**가 횡적으로 통합하는 **3-Layer + 1-Governance 구조**로 설명할 수 있다. 상위 계층은 **정부의 국가정보화 기본법(법제처, 2024년 12월 시행)**, **공공기관의 정보시스템 구축·운영 지침(행정안전부)** 등 **법·제도적 거버넌스**를 따르며, 하위로 갈수록 **기술적 상세(Tactical)** 수준이 높아진다.

```text
+--------------------------------------------------------------------+
|        COBIT 2019 Governance & Management Objectives (40개)      |
+--------------------------------------------------------------------+
|                                                                    |
|  [거버넌스 영역 5개]                  [관리 영역 35개]              |
|  EDM: Evaluate, Direct, Monitor     APO: Align, Plan, Organize    |
|   01. 거버넌스 프레임워크               13. 관리 체계                  |
|   02. 성과/목표 달성                    14. 위험 관리                  |
|   03. 위험 최적화                       15. 예산/비용                  |
|   04. 자원 최적화                       16. 변경 관리                  |
|   05. 이해관계자 투명성                 17. 품질 관리                  |
|                                       18. 보안/프라이버시             |
|                                       ...                          |
|  [도메인]                              32. 서비스 운영                |
|   +--------------------------+        33. 인시던트/문제              |
|   | 비즈니스 요구 --► 설계 --► 구축 --► 운영 --► 폐기  |         |
|   |    BAI (Build)             |        DSS (Deliver)               |
|   +--------------------------+        MEA (Monitor)                |
|                                                                    |
|  -------------------------------------------------------------    |
|  [핵심 구성 요소 Cascade]                                            |
|   조직 미션 -> 전략적 목표 -> 핵심목표(Cascade via BSC) -> KPI       |
|   -------------------------------------------------------------    |
|   Process Capability:  COBIT PAM   Maturity:  0~5 (ISO 15504)     |
|   Design Factor:        11가지(전략, 목표, 위험, 규모, 역할 등)     |
+--------------------------------------------------------------------+
```

| 구성 요소 | 역할 | 핵심 기술 및 동작 방식 |
| :--- | :--- | :--- |
| **COBIT 2019 (거버넌스/관리 목표 40개)** | IT 거버넌스의 **End-to-End 프레임워크** | EDM(거버넌스 5개) + APO/BAI/DSS/MEA(관리 35개)로 구성, **11개 Design Factor**(전략, 목표, 위험, 컴플라이언스, IT 이슈, 위험 태도, 역할, 문화, 규모, 자원, 벤더 등)를 조합해 **거버넌스 시스템(Tailored)**을 설계. **Cascade Goals**를 통해 기업 목표->정렬 목표->거버넌스/관리 목표로 자동 매핑 |
| **ISO/IEC 38500:2015 (IT 거버넌스 국제표준)** | 이사회 수준의 **거버넌스 원칙** 제시 | **6대 원칙**: 책임(R), 전략(St), 취득(A), 성과(P), 적합성(C), 인간행동(H). **"Evaluate -> Direct -> Monitor"** 3단계 사이클로 이사회의 의사결정 지원. 한국에서는 2020년 KCS(한국클라우드산업협회)와 ISMS-P 인증에 간접 활용 |
| **TOGAF 10 (Enterprise Architecture)** | EA 수립·운영 **방법론(ADM: Architecture Development Method)** | **Phase A(비전) -> B/B/C(비즈니스/데이터/애플리케이션/기술) -> D(기술) -> E(기회) -> F(마이그레이션) -> G(구현 거버넌스) -> H(변경 관리) -> R(요구사항)** 8단계. **ArchiMate 3.2** 모델링 표기법, **Content Metamodel**로 60+ 산출물 정의 |
| **ITIL 4 (IT Service Management)** | **서비스 가치 시스템(SVS)** 기반 운영 | **34개 실무**(Practice), **서비스 가치 사슬(SVC)**: Plan->Engage->Design&Transition->Obtain/Build->Deliver&Support->Improve. **4개 차원**: 조직/사람, 정보/기술, 파트너/공급자, 가치사슬/프로세스. **Guiding Principles 7개**(Focus on value, Start where you are, Progress iteratively 등) |
| **PMBOK 7 / PRINCE2 / 애자일(SAFe)** | 프로젝트·프로그램 포트폴리오 관리 | PMBOK 7은 **원리(Principles) 12개** + **8개 성과 영역(Performance Domain)**으로 전환, PRINCE2는 **7대 원칙·7대 프로세스·7대 테마**. SAFe 6.0은 **Lean-Agile** 대규모 확장 프레임워크로 ART(Agile Release Train) 단위 운영 |
| **BSC + KPI (성과관리)** | 전략 실행의 **정량적 측정 체계** | Kaplan-Norton의 **4관점**(재무/고객/내부/학습성장) + **Strategy Map**(인과관계) + **20~30개 KPI**. IT에서는 **"IT4IT"** 참조 모델이 HCL·ServiceNow·BMC 등에서 활용 |

### 핵심 원리 심화: COBIT 2019의 **Goal Cascade & Design Factor**

```
[Step 1] 기업 미션/비전 정의
    |
    v
[Step 2] 13개 기업 목표 중 해당 목표 식별 (예: G01 고객 만족, G04 품질)
    |
    v
[Step 3] 정렬 목표 13개 매핑 (예: AG01 IT 표준/전략, AG08 외부 벤더 관리)
    |
    v
[Step 4] 거버넌스/관리 목표 40개로 자동 라우팅 (예: EDM02, APO03, DSS04 등)
    |
    v
[Step 5] 목표별 Process Activity -> Role(책임/조언/인력) -> RACI 매트릭스
    |
    v
[Step 6] Maturity 측정(0~5) -> Gap 분석 -> 개선 계획
```

- **📢 섹션 요약 비유**: COBIT의 Goal Cascade는 **GPS 네비게이션**과 같다. 최종 목적지(기업 목표)를 입력하면 자동으로 경로(거버넌스/관리 목표)를 안내하고, **실시간 교통 정보(Design Factor 11종)**를 반영해 **우회 경로(Tailored System)**를 제안해준다.

## Ⅲ. 비교 및 연결

IT 경영 관리 영역에서 혼동하기 쉬운 **"거버넌스-관리-운영"**, **"EA 모델링-설계-구현"**, **"BSC-KPI-성과측정"** 등 유사 개념 간의 비교는 기술사 시험의 단골 출제 포인트다.

| 구분 | **COBIT 2019** (거버넌스) | **ITIL 4** (서비스 관리) | **PMBOK 7** (프로젝트) |
| :--- | :--- | :--- | :--- |
| **목적** | 이사회-경영진의 **IT 통제 및 의사결정** 지원 | IT 서비스의 **가치 창출 및 운영 최적화** | 프로젝트 **일정/품질/비용/리스크** 관리 |
|
