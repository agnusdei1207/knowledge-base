## 핵심 인사이트 (3줄 요약)

> 1. **본질**: IT경영관리의 핵심은 **COBIT 2019 기반 거버넌스 체계**, **EA(Enterprise Architecture) 정합성**, **IT 투자 포트폴리오 최적화**, **BSC/CSF 기반 성과측정**의 4축을 통해 IT와 비즈니스 전략을 정렬(Value Alignment)하는 것
> 2. **가치**: 체계적 거버넌스 도입 시 **IT 투자 ROI 20~35% 향상**, **이해관계자 의사결정 속도 40% 단축**, **프로젝트 실패율 30% 감소**, **컴플라이언스 위반 60% 이상 절감** 효과 도출
> 3. **판단 포인트**: **중앙집중형 vs 분산형 거버넌스**, **Waterfall EA vs Agile EA**, **CapEx vs OpEx 투자재원**, **Run-the-Business(70%) vs Change-the-Business(30%) 예산 배분**의 Trade-off가 핵심 의사결정 변수

---

## Ⅰ. 개요 및 필요성

디지털 전환(Digital Transformation) 가속화와 IT-Business 융합으로 인해 IT는 단순 비용센터(Cost Center)에서 **전략적 가치 창출의 핵심 엔진**으로 재정의되었습니다. 그러나 한국 정보화진흥원의 조사에 따르면 국내 정보화 사업의 약 **42%가 예산 초과**, **35%가 일정 지연**, **28%가 기대효과 미달** 상태로 종료되어, **체계적 IT 경영관리 프레임워크**의 필요성이 대두되었습니다.

특히 2024년 정보시스템 감리 제도 개정(과학기술정보통신부)과 클라우드 시대의 **FinOps**, **Green IT**, **AI 윤리** 등 신규 거버넌스 이슈가 등장하면서, 기술사 수준의 통합적 관점 수립이 요구됩니다.

기존의 **프로젝트 단위 관리**에서 **포트폴리오·프로그램 단위**로, **IT 부서 독점**에서 **이해관계자 공동 거버넌스**로, **재무 중심 KPI**에서 **BSC 기반 균형 성과**로 패러다임이 전환되었습니다. COBIT 2019는 40개의 관리 목표(Management Objective)를 통해 이 4대 영역을 **End-to-End**로 통합합니다.

- **📢 섹션 요약 비유**: IT 경영관리는 마치 **도시의 종합 계획**과 같습니다. 토지이용계획(EA), 도시 재원(투자관리), 행정체계(거버넌스), 시민 만족도(성과관리) 4가지가 맞물려야 도시에 질서가 생기듯, IT도 4축이 균형을 이뤄야 합니다.

## Ⅱ. 아키텍처 및 핵심 원리

### 1. IT 거버넌스 3단계 구조 (Direct -> Manage -> Execute)

```text
        +---------------------------------------------+
        |      이사회 / IT전략위원회 (Governance)     |
        |      • 전략방향 결정 (Direction)            |
        |      • 투자한도 승인 (Budget Envelope)      |
        +------------------+--------------------------+
                           | COBIT 2019 EDM 도메인
        +------------------v--------------------------+
        |      CIO / IT거버넌스위원회 (Management)    |
        |      • 포트폴리오 우선순위화                |
        |      • 위험/성과 모니터링                   |
        +------------------+--------------------------+
                           | COBIT 2019 APO/BAI 도메인
        +------------------v--------------------------+
        |      PMO / 서비스데스크 (Execution)         |
        |      • 프로젝트/서비스 운영                 |
        |      • 일일/주간 단위 통제                   |
        +---------------------------------------------+
```

### 2. COBIT 2019 핵심 Governance/Management Objectives

| 구성 요소 | 역할 | 핵심 기술 및 동작 방식 |
| :--- | :--- | :--- |
| **EDM (Evaluate, Direct, Monitor)** | 거버넌스 의사결정 | 5개 목표: **EDM01(체제)**·EDM02(성과)·EDM03(위험)·EDM04(자원)·EDM05(투명성) — 이사회 및 IT전략위원회 권한 |
| **APO (Align, Plan, Organize)** | 전략 정렬 및 기획 | 14개 목표: **APO01(관리체계)**, APO04(혁신), APO05(포트폴리오), APO12(위험관리), APO13(보안관리) |
| **BAI (Build, Acquire, Implement)** | 구축 및 변경관리 | 11개 목표: **BAI01(프로그램)**, BAI02(요구사항), BAI03(솔루션), BAI11(프로젝트관리) — PMBOK·PRINCE2 연계 |
| **DSS (Deliver, Service, Support)** | 서비스 운영 및 지원 | 6개 목표: **DSS01(운영)**, DSS02(서비스요청/사고), DSS04(연속성), DSS06(보안운영) — ITIL 4 연계 |
| **MEA (Monitor, Evaluate, Assess)** | 성과측정 및 평가 | 4개 목표: **MEA01(성과/준수)**, MEA02(내부통제), MEA03(외부감사) — ISACA 감리 프레임워크 |
| **EA 거버넌스 연계** | 전사아키텍처 통제 | **TOGAF ADM 8단계(Phase A~H)**: Preliminary -> Architecture Vision -> Business -> Information Systems -> Technology -> Opportunities & Solutions -> Migration Planning -> Implementation Governance -> Change Management |
| **투자 우선순위화 모델** | 포트폴리오 의사결정 | **가중치 점수법**: (전략적 적합성 × 0.35) + (위험도 × 0.20) + (ROI × 0.25) + (긴급성 × 0.20), **Balanced Scorecard** 4관점 적용 |

### 3. IT 투자재원 관리의 핵심 공식

**ROI (투자수익률)** = (누적 편익 - 총 비용) / 총 비용 × 100

**NPV (순현재가치)** = Σ (t=1..n) (CFt / (1+r)^t) - 초기투자
- r = 할인율(가중평균자본비용 WACC), CFt = t년도 현금흐름

**TCO (총소유비용)** = 직접비용(하드웨어+소프트웨어+인건비) + 간접비용(교육+다운타임+보안) + 기회비용

**Payback Period** = 초기투자액 / 연평균 현금흐름

### 4. BSC 기반 IT 성과관리 4관점

| 관점 | 핵심 KPI | 측정 예시 |
| :--- | :--- | :--- |
| **재무(Financial)** | IT 예산 준수율, ROI | 예산편차 ±5% 이내, 투자수익률 15% 이상 |
| **고객(Customer)** | 사용자 만족도, 서비스 가용성 | CSAT ≥ 4.2/5.0, 가용성 99.9% |
| **내부프로세스(Internal)** | 프로젝트 정시완료율, 사고 해결률 | 90% 이상, MTTR < 4시간 |
| **학습·성장(Learning & Growth)** | 직원 역량, 혁신 지수 | 교육 60시간/년, 신기술 도입 건수 |

- **📢 섹션 요약 비유**: COBIT의 EDM-APO-BAI-DSS-MEA 5단계는 **병원 진료 시스템**과 같습니다. 의사소견(EDM) -> 진단 및 처방계획(APO) -> 수술/치료(BAI) -> 입원/간호(DSS) -> 퇴원 후 경과관찰(MEA)이 5단계를 순환하는 것처럼, IT도 5단계를 끊임없이 순환해야 합니다.

## Ⅳ. 실무 적용 및 기술사 판단

### 기술사형 판단 체크리스트

1. **거버넌스 성숙도 진단**: COBIT 2019의 **40개 목표**에 대해 **CMMI 5단계(Initial~Optimizing)** 또는 ISACA의 **핵심 성숙도 모델**로 현 수준을 측정하고, Target State까지의 Gap을 산출했는가? (예: 평균 2.3 -> 목표 3.5)
2. **IT 투자 포트폴리오 비율 검증**: Gartner 권고 기준 **Run(70%) : Grow(20%) : Transform(10%)** 또는 한국 공공부문 표준인 **운영(60%) : 고도화(25%) : 신규(15%)** 중 어느 비율이 적합한지 정량 평가했는가?
3. **EA 정합성 검증 절차**: 신규 사업 착수 전 **EA Review Board**(BA/DAA/IA/TA 4개 영역 영향평가)를 의무화하고, **Architecture Compliance Score**를 80% 이상으로 유지하는가?
4. **위험·컴플라이언스 통합 관리**: COBIT의 **APO12(위험관리)** + **DSS06(보안)** + **MEA02(내부통제)**를 GRC(Governance-Risk-Compliance) 플랫폼으로 통합하고, **K-ISMS-P / ISO 27001 / 27017/27018** 인증을 연계했는가?
5. **성과측정 인과모델(因果連鎖模型)**: BSC의 4관점 KPI 간 **선·후행 인과관계**(예: 교육시간^ -> 역량^ -> 결함률v -> 고객만족도^ -> 매출^)를 **Strategy Map**으로 시각화하고 분기별 점검하는가?

### 피해야 할 안티패턴

- **IT 거버넌스 위원회 = 의전용 (Rubber-Stamping)**: 이사회에서 형식적 안건 통과만 진행하고 실질적 의사결정이 전무 -> **EDM01 목표 달성을 위한 분기별 정량 보고 체계** 미수립
- **EA를 도큐먼트 작성용으로 전락**: TOGAF ADM 8단계를 1회 수행 후 갱신 없이 방치 -> **Architecture Repository 운영 절차**와 **Change Advisory Board** 미구축
- **IT 성과 측정을 가용성·장애건수만으로 한정**: **BSC 4관점**(재무·고객·내부·학습) 미적용으로 전략적 가치 미가시화 -> **Strategy Map + 12~16개 핵심 KPI**로 확장
- **투자 우선순위 결정 시 이해관계자 정치적 압력에 좌우**: 객관적 **가중치 점수법** 미적용, 일관성 없는 의사결정 -> **APO05 포트폴리오 매트릭스**와 **Decision Rights Matrix** 도입
- **클라우드 전환 시 FinOps 부재**: 클라우드 사용량 증가에도 **Showback/Chargeback 모델** 미적용 -> **2024년 클라우드 컴퓨팅 이용지침(과기정통부)**에 따른 **비용 최적화 거버넌스** 미수립

- **📢 섹션 요약 비유**: 안티패턴은 **자동차의 핸들만 놓은 채 브레이크만 밟는 것**과 같습니다. 거버넌스(핸들)와 실행(엔진)이 함께 작동해야 목적지에 도달할 수 있는데, 어느 한쪽만 강조하면 차는 멈춰있거나 표류합니다.
