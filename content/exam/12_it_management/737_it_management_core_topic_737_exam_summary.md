## 핵심 인사이트 (3줄 요약)

> 1. **본질**: IT 거버넌스(Information Systems Governance)는 ISO 38500의 3개 메커니즘(Evaluate·Direct·Monitor)과 COBIT 2019의 40개 Governance/Management Objective를 통해, 경영진이 IT 활용에 대한 책임·전략·성과·규율·행동·투명성의 6원칙을 준수하며 의사결정 권한과 책임 구조를 확립하는 체제이다.
> 2. **가치**: 글로벌 통계 기준 IT 거버넌스 성숙도 1단계 상향 시 IT 투자 ROI 평균 25% 개선, 프로젝트 실패율 40% 감소(PricewaterhouseCoopers 2022 IT Governance Survey), ISO 38500 인증 기업의 IT 리스크 대응 시간 평균 32% 단축(ISO 38500 Impact Report 2021).
> 3. **판단 포인트**: 중앙집중형(Centralized)·연합형(Federated)·분산형(Decentralized) 거버넌스 모델 중 조직의 문화·규모·규제 환경에 따라 선택하며, RACI 매트릭스, Three Lines Model(IIA 2020), COBIT 2019의 Focus Area·Design Factor 기반 맞춤형 설계로 비용-통제-민첩성 트레이드오프를 결정한다.

## Ⅰ. 개요 및 필요성

기업의 IT는 단순한 비용 센터(Cost Center)에서 벗어나 비즈니스 가치 창출의 핵심 동력으로 부상했다. 그러나 다수의 기업이 IT 투자 실패, 정보화 격차(Digital Divide), 이해관계자 간 책임 소재 불명확, 사이버 리스크 증대, 규제 준수 실패 등의 문제를 겪고 있으며, 이는 IT 의사결정권·통제구조·성과측정 체계의 부재에서 기인한다. IT 거버넌스는 이러한 문제를 해결하기 위해 등장한 상위 의사결정 프레임워크로, IT가 비즈니스 전략과 정렬(Value Alignment)되고, 리스크가 통제되며, 성과가 측정·보고되는 체계를 구축한다.

기존의 IT 관리(IT Management)는 ITIL 기반 서비스 운영·장애 대응에 집중했다면, IT 거버넌스는 **"누가, 어떤 권한으로, 어떤 원칙 하에 IT 의사결정을 하는가"**라는 거버넌스 레이어의 문제를 다룬다. 즉 IT 운영이 'How'에 집중한다면, IT 거버넌스는 'Who·What·Why' 그리고 'What not'에 집중한다.

```text
[ IT 거버넌스 통합 프레임워크 구조도 ]

  +----------------------------------------------------------------+
  |            Board of Directors / CEO (최고 의사결정권)           |
  |        <- ESG · Stakeholder Interest · Fiduciary Duty ->         |
  +---------------------------+------------------------------------+
                              |  Reporting (성과·리스크 보고)

  +------------+------------------------------+--------------------+

**전통적 IT 관리 vs IT 거버넌스 비교**

| 구분 | 전통적 IT 관리 (1990~2000년대) | IT 거버넌스 (2010년 이후) |
| :--- | :--- | :--- |
| 초점 | IT 서비스 운영 효율성 | 비즈니스 가치·리스크·규제 준수 |
| 의사결정 | CIO 단독 또는 IT 부서 한정 | 이사회·경영진 참여, 분산형 거버넌스 |
| 표준 | ITIL v2/v3, PMBOK | COBIT 2019, ISO 38500, ITIL 4, ISO 27001 |
| 성과 지표 | SLA(서비스 수준), 가용성 | KPI(BSC 4관점), NPV·IRR, ROI, TCO |
| 리스크 | 장애 대응 위주 | 사이버 리스크·규제·평판 리스크 통합 관리 |
| 기간 | 단기(1~3년) | 중장기(3~5년) + 지속적 모니터링 |

- **📢 섹션 요약 비유**: IT 거버넌스는 마치 **배의 키잡이(舵手)**와 같습니다. 엔진룸(IT 운영)은 일 잘하는 선원이 돌보지만, 키잡이 없이는 배가 어디로 가야 할지 모른 채 표류합니다. IT 거버넌스는 바람(비즈니스 환경)과 조류(규제·시장)를 읽고 키를 잡는 역할을 합니다.

## Ⅱ. 아키텍처 및 핵심 원리

IT 거버넌스의 핵심은 국제표준(ISO 38500)과 산업표준(COBIT 2019)의 결합이다. ISO 38500은 거버넌스의 **원칙·모델**, COBIT 2019는 **실행·측정·관리** 메커니즘을 제공하며, ITIL 4는 거버넌스 하위에서 실제 서비스 운영을 다룬다.

### 1. ISO 38500:2015 — IT 거버넌스 국제표준

ISO 38500은 6원칙과 3메커니즘(EDM: Evaluate-Direct-Monitor) 모델을 제시한다. 이는 강제 규범이 아닌 **"이사회가 IT를 어떻게 통제해야 하는가"**에 대한 지침이다.

```text
[ ISO 38500 EDM 사이클 + 6원칙 매핑 다이어그램 ]

   +-------------------+
   |   INPUT (Trigger)  |  <- 전략 변경 / 신규 투자 / 규제 개정 / 사고 발생
   |   • 전략·계획      |
   |   • 투자 제안서    |
   |   • 성과 보고서    |
   |   • 리스크 평가    |
   +---------+---------+
             |
             v
   +----------------------------------------------------------+
   |                  GOVERNANCE CYCLE (EDM)                  |
   |                                                          |
   |   +--------------+    +--------------+    +----------+  |
   |   |  EVALUATE    |---->|   DIRECT     |---->| MONITOR  |  |
   |   |   (평가)     |    |   (지휘)     |    | (모니터) |  |
   |   | ---------    |    | ---------    |    | -------- |  |
   |   | • 현 상황    |    | • 정책 결정  |    | • 성과   |  |
   |   |   분석       |    | • 우선순위   |    |   측정   |  |
   |   | • 옵션 평가  |    | • 자원 배분  |    | • 적합성 |  |
   |   | • 리스크 식별|    | • 책임 위임  |    |   평가   |  |
   |   | • 기회 포착  |    | • 표준 제정  |    | • 시정   |  |
   |   +------+-------+    +------+-------+    +----+-----+  |
   |          |                   |                 |         |
   |          +-------------------+-----------------+         |
   |                              |                           |
   |                              v                           |
   |                  +---------------------+                 |
   |                  |  6 PRINCIPLES 적용   |                 |
   |                  | ------------------   |                 |
   |                  | 1. 책임(Responsibility)|              |
   |                  | 2. 전략(Strategy)     |              |
   |                  | 3. 성과(Performance)   |              |
   |                  | 4. 책임성(Conformance) |              |
   |                  | 5. 행동(Behavior)      |              |
   |                  | 6. 인간요소(Human)     |              |
   |                  +---------------------+                 |
   +----------------------------------------------------------+
                              |
                              v
   +-------------------------------------------------------+
   |  OUTPUT: 의사결정·정책·표준·KPI·보고·시정조치          |
   +-------------------------------------------------------+
```

**ISO 38500 6원칙 상세 해설**

| 원칙 | 핵심 의미 | 실무 적용 예시 | 측정 지표 |
| :--- | :--- | :--- | :--- |
| 책임 (Responsibility) | 이사회가 IT 활용에 대한 최종 책임을 진다 | IT 운영위원회 월례 회의, CIO 보고 의무화 | 회의 참석률, 의사결정 이력 |
| 전략 (Strategy) | IT가 조직의 전략 목표와 부합해야 한다 | IT-BSC, EA(엔터프라이즈 아키텍처) 정렬 | 전략 정렬도, 목표달성률 |
| 성과 (Performance) | IT 서비스가 적절한 능력·품질로 제공되어야 한다 | SLA, KPI 대시보드, ITIL 4 SVS | SLA 준수율, 가용성, MTTR |
| 책임성 (Conformance) | IT가 법률·규정·내부정책을 준수해야 한다 | ISMS-P, GDPR, 전자금융감독규정 | 컴플라이언스 위반 건수 |
| 행동 (Behavior) | IT 의사결정 시 인간·문화적 요소를 존중 | 변화관리(Change Management), 사용자 교육 | 직원 만족도, 변화 수용률 |
| 인간요소 (Human) | IT는 사람을 위해 봉사하는 도구 | UX, 접근성, 디지털 포용성 | 사용자 만족도, 디지털 접근성 지수 |

### 2. COBIT 2019 — 거버넌스·관리 목표 체계

COBIT(Control Objectives for Information and Related Technologies)은 ISACA가 1996년 처음 발표한 이래 5차례 개정되어, 현재는 **2019 버전**이 산업 표준으로 자리잡았다. COBIT 2019는 **거버넌스 목표 5개 + 관리 목표 35개**, 총 **40개 목적(Goals)**으로 구성되며, 이를 통해 IT 활동 전체를 측정·관리 가능한 체계로 정렬한다.

```text
[ COBIT 2019 계층 구조 (Cascade) ]

   +----------------------------------------------------------+
   |  Enterprise Goals (13개) — 조직 목표                      |
   |  • EG01 포트폴리오 최적화  • EG06 서비스 품질             |
   |  • EG08 내부 통제 최적화   • EG12 위험 관리               |
   +------------------------+---------------------------------+
                            |  Alignment (정렬)
                            v
   +----------------------------------------------------------+
   |  Alignment Goals (13개) — 정렬 목표                        |
   |  • AG01 IT 준수 및 지원   • AG04 정보 품질               |
   |  • AG09 디지털 혁신       • AG12 IT 인력 역량             |
   +------------------------+---------------------------------+
                            |  Mapping
                            v
   +----------------------------------------------------------+
   |  Governance & Management Objectives (40개) — 거버넌스·관리 |
   |                                                           |
   |  +------- Governance (5) -------+                         |
   |  | EDM01 거버넌스 체계 수립     |                         |
   |  | EDM02 가치 전달 보장         |                         |
   |  | EDM03 리스크 최적화          |                         |
   |  | EDM04 자원 최적화            |                         |
   |  | EDM05 이해관계자 투명성 확보 |                         |
   |  +------------------------------+                         |
   |  +------- Management (35) -----+                         |
   |  | APO(평가·계획·조직) 14개     |                         |
   |  | BAI(빌드·획득·구현)  11개     |                         |
   |  | DSS(서비스 전달·지원)  6개   |                         |
   |  | MEA(모니터·평가·평가)  3개   |                         |
   |  +------------------------------+                         |
   +------------------------+---------------------------------+
                            |  Implementation
                            v
   +----------------------------------------------------------+
   |  Components of Governance System (7개 구성요소)            |
   |  ① 프로세스  ② 조직구조  ③ 정보흐름  ④ 인력·역량         |
   |  ⑤ 정책·절차  ⑥ 문화·윤리  ⑦ 서비스·인프라·앱플리케이션  |
   +------------------------+---------------------------------+
                            |  Capability / Maturity (0~5)
                            v
   +----------------------------------------------------------+
   |  Focus Areas (초점영역) — 디자인 팩터 기반 맞춤 설계     |
   |  • 사이버 보안  • 디지털 혁신  • DevOps  • 위험         |
   |  • 규제 준수  • 데이터 거버넌스  • BCM                   |
   +------------------------------------------------
