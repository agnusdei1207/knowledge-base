## 1교시 실제 모범답안

### 1) 물리 계층 인공지능 (Physical Layer AI, PHY AI)

- 정의: `PHY AI`는 채널 추정, 등화, 복조 등 물리 계층 신호처리에 인공지능을 적용해 성능과 적응성을 높이는 기술이다.
- 핵심1: 규칙 기반 수신기 한계를 보완해 복잡한 채널 환경에서 `BER(Bit Error Rate)`를 낮춘다.
- 핵심2: 학습 대상은 채널 추정, 빔 선택, 전력 제어, 변복조 최적화이다.
- 핵심3: 학습 데이터 편향, 실시간 추론 지연, 설명 가능성 부족이 한계다.
- 적용: 6세대 이동통신(6G)에서는 `Massive MIMO`, `THz` 환경 적응형 모뎀 구현에 유효하다.

```text
[무선 채널]
    ↓
[AI 추정/등화]
    ↓
[복조 성능 향상]
```

### 2) 결정론적 네트워킹 (Deterministic Networking, DetNet)

- 정의: `DetNet`은 패킷 전달의 지연, 지터, 손실 상한을 예측 가능하게 보장하는 인터넷 기반 전달 기술이다.
- 핵심1: `TSN(Time Sensitive Networking)`과 연계해 산업제어, 특화망, 실시간 미디어에 적용한다.
- 핵심2: 경로 예약, 패킷 복제, 큐 관리로 고신뢰 저지연을 구현한다.
- 핵심3: 일반 IP망 대비 운영 복잡도와 자원 예약 비용이 증가한다.
- 적용: 스마트팩토리 5세대 이동통신(5G) 특화망에서 제어 신호 전달 안정성 확보에 적합하다.

```text
[제어 트래픽]
    ↓
[예약 경로/복제]
    ↓
[저지연·무손실 전달]
```

## 선택 추천 실제 모범답안

### 1) AI 에이전트 오케스트레이션의 통신망 운영 자율화 적용

#### Ⅰ. 개요

- `AI Agent Orchestration`은 복수의 인공지능 에이전트를 역할별로 분리해 망 감시, 원인분석, 정책반영, 복구를 폐쇄루프로 수행하는 운영 체계이다.
- 통신망은 장애 전파 범위가 넓고 `RAN(Radio Access Network)`부터 코어, 전송, 클라우드까지 연계되므로 단일 자동화보다 협업형 자율화가 효과적이다.

#### Ⅱ. 아키텍처 및 동작 원리

```text
[Telemetry]
     ↓
[감시 Agent] → [분석 Agent] → [정책 Agent] → [복구 Agent]
                                                ↓
                                         [OSS/BSS 반영]
```

- 감시 에이전트: 알람, 로그, `KPI(Key Performance Indicator)` 수집
- 분석 에이전트: `RCA(Root Cause Analysis)`와 영향도 판단
- 정책 에이전트: 슬라이스 정책, 우회 경로, 자원 증설안 생성
- 복구 에이전트: 설정 반영, 롤백, 검증 수행

#### Ⅲ. 핵심 기술

| 구분 | 내용 | 판단 포인트 |
|:---|:---|:---|
| 데이터 | 텔레메트리, 구성정보, 장애이력 | 데이터 품질과 최신성 |
| 제어 | 의도 기반 정책, 폐쇄루프 자동화 | 오동작 방지와 승인 체계 |
| 보안 | 에이전트 권한 분리, 감사로그 | 오남용 통제 |
| 표준 | TM Forum, ETSI ZSM 연계 | 상호운용성 |

#### Ⅳ. 실무 적용 방안

- 1. `RAN` 장애는 셀 혼잡, 전력, 핸드오버 실패를 묶어 분석한다.
- 2. 코어망은 `CNF(Cloud Native Network Function)` 스케일아웃과 라우팅 우회를 자동 제안한다.
- 3. 복구 전에는 샌드박스 검증, 복구 후에는 `SLA(Service Level Agreement)` 회복 여부를 확인한다.

#### Ⅴ. 결론

- 에이전트 자율화는 운영 효율을 높이지만 승인 정책, 보안통제, 설명 가능한 판단 체계를 함께 설계해야 통신망에 안전하게 적용된다.

### 2) 6세대 이동통신(6G) 표준화 진행 현황

#### Ⅰ. 개요

- 6세대 이동통신(6G)은 인공지능 네이티브, 감지-통신 융합, 비지상망 통합을 목표로 하는 차세대 이동통신 체계이다.
- 최근 출제 포인트는 `3GPP(3rd Generation Partnership Project)`의 `Release 20`와 `ITU(International Telecommunication Union)` `IMT-2030` 요구사항의 연결이다.

#### Ⅱ. 표준화 흐름

```text
[IMT-2030 비전]
        ↓
[3GPP Rel.20 연구/규격]
        ↓
[장비·칩셋 구현]
        ↓
[상용 검증]
```

#### Ⅲ. 핵심 요구사항

| 항목 | 내용 | 통신망 시사점 |
|:---|:---|:---|
| 초고속 | 테라비트급 전송 지향 | 백홀·프론트홀 동반 고도화 |
| 초저지연 | 실감형 제어, 촉각 서비스 | 엣지 배치 확대 |
| AI 네이티브 | 망 학습·최적화 내재화 | 데이터 파이프라인 필수 |
| NTN 통합 | 위성-지상 연동 | 핸드오버·도플러 보정 중요 |

#### Ⅳ. 기술사 관점 적용

- 1. 무선만 보는 답안이 아니라 전송망, 코어, 운영 자동화까지 연결해야 한다.
- 2. `THz`, `RIS(Reconfigurable Intelligent Surface)`, `PHY AI`는 기술 성숙도와 상용 시점을 구분해 서술한다.
- 3. 표준화 일정과 사업자 투자 회수 기간을 함께 판단해야 한다.

#### Ⅴ. 결론

- 6G 답안은 비전 나열보다 표준화 단계, 투자 우선순위, 기존 5세대 이동통신(5G) 자산 활용전략까지 써야 완성도가 높다.

### 3) 양자내성암호(Post-Quantum Cryptography, PQC) 실적용 전환 계획

#### Ⅰ. 개요

- `PQC`는 양자컴퓨터 환경에서도 안전성을 유지하도록 설계된 공개키 암호 기술이며 국가 기반 통신망의 중장기 전환 대상이다.
- 통신사업자는 장기 비밀성, 장비 수명, 상호운용성 때문에 하이브리드 전환 전략이 필수다.

#### Ⅱ. 전환 구조

```text
[현행 RSA/ECC]
      ↓
[Hybrid TLS/IPsec]
      ↓
[PQC 단독 운영]
```

#### Ⅲ. 전환 항목

| 구분 | 적용 내용 | 판단 포인트 |
|:---|:---|:---|
| 구간 | 가입자, 전송, 코어, 관리망 | 자산 식별 선행 |
| 프로토콜 | `TLS`, `IPsec`, 인증서 | 하이브리드 적용 |
| 장비 | 라우터, 방화벽, `HSM(Hardware Security Module)` | 성능 저하 검증 |
| 운영 | 키관리, 장애복구, 감사 | 장기 이행 계획 |

#### Ⅳ. 실무 적용 방안

- 1. 중요 구간부터 암호 자산 목록을 만든다.
- 2. `RSA(Rivest-Shamir-Adleman)`와 `ECC(Elliptic Curve Cryptography)`를 즉시 폐기하지 않고 하이브리드로 병행한다.
- 3. 성능 저하가 큰 장비는 제어망과 고객망을 구분해 단계적으로 바꾼다.

#### Ⅴ. 결론

- `PQC` 전환은 알고리즘 교체 문제가 아니라 자산 식별, 프로토콜 검증, 장비 성능, 운영 절차를 함께 바꾸는 통신망 전환 프로젝트로 봐야 한다.
