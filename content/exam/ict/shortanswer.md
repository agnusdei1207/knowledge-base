## 작성 방법

- 기출 분석 후 고빈도 키워드부터 채워나가기
- 각 항목: **정의 1줄 + 핵심 포인트 2~3개** 로 작성
- 손으로 쓸 수 있는지 주 1회 셀프 테스트

---

## 이동통신

### 1. 5G NR (New Radio)

**정의**: 3GPP Release 15 이후 표준화된 5세대 이동통신 무선 접속 기술

**핵심 포인트**:
1. 주파수 대역: Sub-6GHz (FR1) + mmWave (FR2)
2. 3대 서비스: eMBB(초고속) / URLLC(초저지연) / mMTC(대규모 IoT)
3. 핵심 기술: Massive MIMO, 빔포밍, 네트워크 슬라이싱, MEC

**관련 키워드**: NSA/SA 구조, 5G 코어(5GC), 기지국(gNB)

---

### 2. OFDM (직교 주파수 분할 다중화)

**정의**: 채널을 다수의 직교 부반송파로 분할해 병렬 전송하는 다중화 방식

**핵심 포인트**:
1. 직교성: 부반송파 간 간섭 없음 (주파수 간격 = 1/T)
2. 장점: 다중 경로 페이딩 강인, 주파수 효율 높음
3. 단점: PAPR 높음, 주파수 오프셋에 민감

**관련 키워드**: OFDMA, CP(순환 전치), FFT/IFFT, 4G LTE, 5G NR

---

### 3. MIMO (다중 입출력 안테나)

**정의**: 송수신 양쪽에 다수 안테나를 사용해 공간 다중화 또는 다이버시티 이득을 얻는 기술

**핵심 포인트**:
1. 공간 다중화: 복수 데이터 스트림 동시 전송 → 용량 증대
2. 다이버시티: 신뢰성 향상 (페이딩 대응)
3. 빔포밍: 특정 방향으로 에너지 집중 → Massive MIMO (64~256 안테나)

**관련 키워드**: SU-MIMO, MU-MIMO, 채널 행렬, SVD 분해

---

### 4. 네트워크 슬라이싱

**정의**: 단일 물리 네트워크를 논리적으로 분할해 서비스 유형별 독립적 가상 네트워크를 제공하는 기술

**핵심 포인트**:
1. 기반: SDN + NFV + 클라우드 네이티브 (쿠버네티스)
2. 유형: eMBB 슬라이스 / URLLC 슬라이스 / mMTC 슬라이스
3. 격리: 슬라이스 간 자원·QoS 독립 보장

**관련 키워드**: NSSAI, NSI, E2E 슬라이싱, 5GC

---

### 5. MEC (Multi-access Edge Computing)

**정의**: 기지국 근방에 컴퓨팅 자원을 배치해 초저지연 서비스를 제공하는 엣지 컴퓨팅 아키텍처

**핵심 포인트**:
1. 지연 감소: 코어망 우회 → 1ms 이하 지연 가능
2. 활용: 자율주행, AR/VR, 실시간 영상 분석
3. ETSI MEC 표준: API, 앱 라이프사이클 관리

**관련 키워드**: 엣지 컴퓨팅, 포그 컴퓨팅, 로컬 브레이크아웃

---

## 네트워크

### 6. SDN (소프트웨어 정의 네트워킹)

**정의**: 제어 평면(Control Plane)과 데이터 평면(Data Plane)을 분리해 중앙 소프트웨어로 네트워크를 제어하는 아키텍처

**핵심 포인트**:
1. 구성: SDN Controller + OpenFlow 스위치 + 북향/남향 API
2. 장점: 유연한 트래픽 제어, 프로그래밍 가능
3. 적용: WAN 최적화, 데이터센터, 5G 코어

**관련 키워드**: OpenFlow, OpenDaylight, NFV와 비교

---

### 7. NFV (네트워크 기능 가상화)

**정의**: 전용 하드웨어 네트워크 장비의 기능을 범용 서버의 소프트웨어로 구현하는 기술

**핵심 포인트**:
1. ETSI NFV 참조 아키텍처: VNF + NFV Infrastructure + MANO
2. 장점: CAPEX/OPEX 절감, 빠른 배포, 유연한 확장
3. SDN과 차이: NFV(기능 가상화) vs SDN(제어·데이터 분리)

**관련 키워드**: VNF, NFVI, vCPE, 클라우드 네이티브 VNF

---

### 8. BGP (Border Gateway Protocol)

**정의**: AS(자율 시스템) 간 라우팅 정보를 교환하는 인터도메인 경로 벡터 프로토콜

**핵심 포인트**:
1. EGP 계열: 인터넷 골격 라우팅 프로토콜
2. 경로 선택 속성: AS-PATH, LOCAL_PREF, MED
3. BGP 하이재킹: 잘못된 경로 광고 → RPKI로 대응

**관련 키워드**: iBGP vs eBGP, BGP 4, RPKI, AS 번호

---

### 9. QoS (Quality of Service)

**정의**: 네트워크 트래픽에 우선순위를 부여해 지연·지터·패킷 손실을 보장하는 메커니즘

**핵심 포인트**:
1. 모델: IntServ (RSVP 예약) vs DiffServ (DSCP 표시)
2. 기법: 트래픽 셰이핑, 폴리싱, 큐잉(WFQ·PQ)
3. 적용: VoIP, 영상 스트리밍, 실시간 게임

**관련 키워드**: 지연(Delay), 지터(Jitter), 패킷 손실, SLA

---

### 10. MPLS (다중 프로토콜 레이블 스위칭)

**정의**: IP 패킷에 레이블을 부착해 빠른 포워딩과 트래픽 엔지니어링을 제공하는 기술

**핵심 포인트**:
1. 동작: 레이블 삽입(Ingress) → 스위칭(Transit) → 제거(Egress)
2. LSP(레이블 교환 경로) 사전 설정 → 최적 경로 제어
3. MPLS-TE: 대역폭 예약·로드밸런싱, L2/L3 VPN 지원

**관련 키워드**: LER, LSR, FEC, 레이블 스택

---

## 광통신

### 11. WDM (파장 분할 다중화)

**정의**: 서로 다른 파장의 광신호를 하나의 광섬유에 동시에 전송하는 다중화 기술

**핵심 포인트**:
1. CWDM: 넓은 채널 간격(20nm), 저비용, 단거리
2. DWDM: 좁은 채널 간격(0.8nm), 고용량, 장거리 (100Gbps×80채널)
3. ROADM: 파장별 동적 추가/삭제/라우팅

**관련 키워드**: EDFA(광증폭기), 색산란, 비선형 효과, 광섬유 분산

---

### 12. GPON (기가비트 수동 광 네트워크)

**정의**: 단일 광섬유로 OLT(국사)~ONT(가입자) 구간을 수동 분배기로 연결하는 광 가입자망 기술

**핵심 포인트**:
1. 속도: 하향 2.5Gbps / 상향 1.25Gbps
2. 분기비: 1:64 (최대 1:128)
3. XG-PON(10G)/NG-PON2(40G)로 진화 중

**관련 키워드**: OLT, ONT, 스플리터, FTTH, PON

---

## 보안

### 13. PKI (공개키 기반 구조)

**정의**: 공개키 암호화와 디지털 인증서를 이용해 신뢰할 수 있는 키 배포 체계를 제공하는 시스템

**핵심 포인트**:
1. 구성: CA (인증기관) + RA + 인증서 저장소 + CRL/OCSP
2. X.509 인증서: 공개키 + 소유자 정보 + CA 서명
3. 체인: Root CA → Sub CA → End-Entity

**관련 키워드**: RSA, ECC, 전자서명, TLS/HTTPS

---

### 14. 제로트러스트 (Zero Trust)

**정의**: "Never Trust, Always Verify" 원칙 — 내부·외부 구분 없이 모든 접근을 검증하는 보안 모델

**핵심 포인트**:
1. 핵심 원칙: 명시적 검증, 최소 권한 접근, 침해 가정
2. 핵심 기술: MFA, ZTNA, IAM, 마이크로 세그멘테이션
3. BeyondCorp(Google) → NIST SP 800-207 표준화

**관련 키워드**: ZTNA, SDP, IAM, 접근 제어 정책

---

### 15. ISMS-P

**정의**: 정보보호 및 개인정보보호 관리체계 통합 인증 (ISMS + PIMS)

**핵심 포인트**:
1. 인증 범위: 관리 과정 16개 + 보호 대책 64개 + 개인정보 22개 (102개 항목)
2. 의무 대상: ISP, IDC, 매출 100억 이상 쇼핑몰 등
3. 유효기간: 3년 (최초 인증 후 연 1회 사후 심사)

**관련 키워드**: KISA, 개인정보보호법, 위험 평가, 보안 정책

---

## 클라우드 / 가상화

### 16. 컨테이너 vs VM 비교

**정의**: 컨테이너는 OS 커널 공유 격리 실행 단위; VM은 하이퍼바이저 위에서 완전히 분리된 가상 하드웨어 환경

**핵심 포인트**:
1. 컨테이너: 경량(MB), 빠른 시작, OS 공유 → 보안 격리 약
2. VM: 무거움(GB), 느린 시작, 강한 격리 → 멀티OS 지원
3. 쿠버네티스: 컨테이너 오케스트레이션 표준

**관련 키워드**: Docker, Kubernetes, 하이퍼바이저(Type 1/2), CRI-O

---

### 17. 엣지 컴퓨팅

**정의**: 데이터 생성 위치 근방에 컴퓨팅 자원을 배치해 지연 감소·오프로드를 달성하는 분산 컴퓨팅 패러다임

**핵심 포인트**:
1. 계층: 클라우드 → 엣지 서버 → 엔드 디바이스
2. 장점: 저지연, 대역폭 절감, 프라이버시 보호
3. vs 포그: 엣지(기지국 레벨) vs 포그(LAN 게이트웨이 레벨)

**관련 키워드**: MEC, 엣지 AI, IoT, CDN 엣지

## AI / 빅데이터

### 18. LLM (대형 언어 모델)

**정의**: 수억~수천억 파라미터의 트랜스포머 기반 언어 모델로 텍스트 이해·생성을 수행하는 AI 시스템

**핵심 포인트**:
1. 구조: 트랜스포머 Attention 메커니즘 기반
2. 학습: 사전학습(Pre-training) + 미세조정(SFT) + RLHF
3. 활용: 프롬프트 엔지니어링, RAG, 에이전트

**관련 키워드**: GPT, Transformer, 토큰화, 할루시네이션

---

### 19. RAG (검색 증강 생성)

**정의**: LLM 추론 시 외부 지식베이스에서 관련 문서를 검색해 답변 정확도를 높이는 기법

**핵심 포인트**:
1. 구성: 문서 임베딩 + 벡터 DB + 검색 + LLM 생성
2. 장점: 최신 정보 반영, 할루시네이션 감소
3. vs 파인튜닝: 파인튜닝(모델 가중치 업데이트) vs RAG(외부 검색)

**관련 키워드**: 임베딩, 벡터 DB, 코사인 유사도, 청킹

---

### 20. 연합학습 (Federated Learning)

**정의**: 원본 데이터를 중앙 서버에 전송하지 않고 각 디바이스/기관에서 로컬 학습 후 모델 파라미터만 집계하는 분산 학습 기법

**핵심 포인트**:
1. 장점: 데이터 프라이버시 보호, 통신량 절감
2. 집계: FedAvg (가중 평균), FedProx
3. 과제: 통신 비용, Non-IID 데이터, 모델 오염 공격

**관련 키워드**: 차분 프라이버시, 동형암호, 수평·수직 연합학습
