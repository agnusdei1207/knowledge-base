## 컴시응 vs 정보통신기술사 비교

| 구분 | 컴퓨터시스템응용기술사 | 정보통신기술사 |
|:---|:---|:---|
| 주력 | 컴퓨터 구조, OS, SW공학, DB | 통신, 네트워크, 무선/이동통신 |
| 공통 | 보안, AI, 클라우드, IT경영 | 보안, AI, 클라우드, IT경영 |
| 차이 | 알고리즘, 데이터 구조 | 광통신, 이동통신, QoS, OFDM |
| 법규 | 소프트웨어 진흥법, EA | 전파법, 전기통신사업법, ISMS |

## 과목별 우선순위

| 우선순위 | 과목 | 이유 |
|:---|:---|:---|
| ★★★ | 이동통신 (4G·5G·6G) | 매회 다출제, 핵심 영역 |
| ★★★ | 네트워크 (TCP/IP·SDN·라우팅) | 고정 출제 |
| ★★★ | 정보보안 (암호·PKI·방화벽) | 최근 비중 급증 |
| ★★★ | 광통신 (WDM·DWDM·ROADM) | 통신 특화 핵심 |
| ★★ | 무선 LAN (Wi-Fi 6/7·OFDMA) | 단답형 자주 출제 |
| ★★ | 클라우드/가상화 | AI 트렌드와 결합 |
| ★★ | AI/빅데이터 | 최근 급증 |
| ★★ | IT 경영/감리 | 서술형 마무리용 |
| ★ | 유선 통신 (xDSL·HFC) | 1교시 단답형 |
| ★ | 방송통신 | 일부 출제 |

## 2026 타임라인

### 6~7월
- [ ] 최근 5년 기출 수집 (큐넷 — 정보통신기술사 검색)
- [ ] 기출 토픽 빈도 분석 → 고빈도 50개 추출
- [ ] 서술형 답안 템플릿 확정 (컴시응과 공유)
- [ ] 이동통신 (5G·6G) 완벽 서술 연습

### 8월
- [ ] 고빈도 토픽 50개 → 직접 손으로 서술형 답안 초안 작성
- [ ] 1교시 단답형 핵심 키워드 200개 암기 리스트 완성
- [ ] 주 3회 실전 타이머 연습 (33분/문항)

### 9월
- [ ] 실전 모의고사 1회 (4교시 풀세트, 400분)
- [ ] 약점 토픽 보완 (광통신, 전파 관련)
- [ ] 답안 글씨체 + 도식화 속도 최적화

### 10월 (시험 직전)
- [ ] 고빈도 50개 최종 회독
- [ ] 1교시 단답형 빠른 암기 점검
- [ ] 손 글씨 속도 최종 점검

## 1교시 단답형 전략

- 10문항 × 10점 = 100점
- 문항당 **10분** 배정
- 키워드 + 정의 + 특징 2~3개 + 도식 → 끝
- 암기보다 **설명할 수 있는 200개** 목표

---

## 2~4교시 서술형 전략

- 3문항 × 25점 = 75점
- 문항당 **33분** 배정
- 템플릿: `template.md` 참조 (컴시응과 동일 구조 사용)
- 선택 전략: 4문항 중 아는 것 3개 고르는 데 **2분** 안에 결정
