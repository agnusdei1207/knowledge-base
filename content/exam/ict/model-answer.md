## 1교시 단답형 템플릿

### 기본 형식

1. **정의 1문장**
2. **핵심 3포인트**
3. **통신/네트워크 적용 1문장**
4. **초간단 도해 1개**

### 답안 골격

```text
[키워드]
- 정의: [영문 풀네임] 기반의 [기술/제도/아키텍처]로서 [목적]을 달성하는 개념
- 핵심1: 구조/동작 원리
- 핵심2: 장점 또는 성능 지표
- 핵심3: 한계 또는 적용 시 고려사항
- 적용: 5G 코어, 전송망, 데이터센터, 특화망 등 실무 연결

[입력/트래픽]
    ↓
[핵심 메커니즘]
    ↓
[품질/보안/효율 향상]
```

### 통신형 예시 문장

- `MEC(Multi-access Edge Computing)`는 기지국 인접 구간에서 트래픽을 분산 처리하여 지연을 줄이는 분산 컴퓨팅 구조이다.
- `SRv6(Segment Routing over IPv6)`는 IPv6 헤더에 경로 의도를 삽입해 서비스 체이닝과 트래픽 엔지니어링을 단순화한다.
- `O-RAN(Open Radio Access Network)`은 무선접속망 인터페이스 개방을 통해 멀티벤더 상호운용성과 비용 효율을 높이는 구조이다.

| 구간 | 작성 포인트 | 통신형 표현 |

| Ⅰ. 개요 | 정의 + 출제 배경 | "5G-Advanced, 6G, AI 네이티브 네트워크 전환" |
| Ⅱ. 구조/원리 | 계층도 또는 흐름도 | "단말-접속-전송-코어-운영" |

### 문제 유형별 Ⅳ 변형

| 문제 지시어 | Ⅳ 작성법 | 통신/네트워크 예시 |
|:---|:---|:---|
| 설명하시오 | 도입 효과 + 한계 | MEC 도입 효과와 백홀 증설 이슈 |
| 비교하시오 | 비교표 + 선택 기준 | MPLS vs SRv6, SA vs NSA |
| 방안을 제시하시오 | 문제-원인-대책 3단 | O-RAN 보안 강화, PQC 전환 |
| 설계하시오 | 계층도 + 인터페이스 | 특화망, NTN, 텔코 클라우드 |
| 절차를 쓰시오 | 단계 흐름도 | 기출 키워드 수집, 망 전환 로드맵 |

## 기술사 관점 마무리 문장

- 정보통신기술사는 기술 우수성만이 아니라 망 안정성, 표준 적합성, 투자 대비 효과를 함께 판단해야 한다.
- 통신 분야 답안은 반드시 서비스 품질(`QoS`), 보안, 운영 자동화, 상호운용성 관점이 같이 보여야 한다.
- 최신 이슈를 쓰더라도 `RAN-전송-코어-운영` 전체 관점으로 연결하면 답안 완성도가 높아진다.
