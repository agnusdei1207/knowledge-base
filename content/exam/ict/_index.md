## 핵심 출제 영역

| 영역 | 비중 | 세부 |
|:---|:---:|:---|
| 유선/무선 통신 | ★★★ | 광통신, 이동통신(5G/6G), OFDM, MIMO |
| 네트워크/인터넷 | ★★★ | TCP/IP, SDN/NFV, QoS, 라우팅 |
| 정보보안 | ★★★ | 암호학, PKI, 방화벽, 침입탐지 |
| 클라우드/가상화 | ★★ | 클라우드 서비스, 컨테이너, 엣지 |
| AI/빅데이터 | ★★ | 머신러닝, 딥러닝, 데이터 분석 |
| IT 감리/경영 | ★★ | ISP, EA, 사업관리, 법규 |
