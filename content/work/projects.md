## 🏃 진행 중인 프로젝트 (Active)

### 🤖 사내 AI 비서 에이전트 구축
*   **목적:** 회사 내부의 다양한 데이터(메신저, 이메일, 위키)를 통합하여 직원의 일상 질문에 답변하고 업무 프로세스를 지원하는 AI 개발.
*   **주요 기술:** Python, FastAPI, LangChain, **[[tech-stack]]**에 정의된 Vector DB 및 임베딩 모델 활용.
*   **이론적 배경:** **[[study/studynote/10_ai/_index|AI/LLM/RAG 스터디노트]]** 및 **[[study/studynote/05_database/_index|데이터베이스 검색 기법]]** 참고.
*   **진행 상태:** 기획 및 핵심 프레임워크 설계 중.
*   **관련 아이디어:** **[[inbox]]**에 올라온 시맨틱 RAG 관련 메모 참조.
*   **연결 문서:** **[[r-and-d]]**, **[[r-and-d-roadmap]]**

### 🏛️ 지식 운영 계층 설계
*   **목적:** 여러 직원과 AI 에이전트가 같은 지식베이스를 안정적으로 읽고 쓰도록 하는 공용 운영 계층을 설계하는 것.
*   **핵심 질문:** Quartz만으로 충분한가, 웹 편집 계층과 검색 인덱스를 어디까지 붙일 것인가.
*   **핵심 문서:** **[[knowledge-pipeline]]**, **[[decap-cms]]**, **[[claude-code-mcp]]**
*   **이론적 배경:** **[[study/studynote/04_software_engineering/_index|소프트웨어 공학의 아키텍처 원칙]]** 및 **[[study/studynote/07_enterprise_systems/_index|엔터프라이즈 아키텍처(EA)]]** 참고.
*   **진행 상태:** 추천 조합 및 단계별 도입 방안 정리 완료, 실제 도입 설계 검토 단계.

### 🌐 지식저장소 웹 포털 구축 (Quartz Deployment)
*   **목적:** 마크다운 문서를 기반으로 전 직원이 쉽게 조회할 수 있는 웹 뷰어를 배포하는 것.
*   **진행 상태:** **[[quartz-deployment]]** 완료 및 GitHub Actions 자동 배포 운영 중.
*   **의사결정 배경:** **[[knowledgebase-decision-log]]**

### 💼 지식 운영 체계 사업화 검토
*   **목적:** 내부 지식베이스 운영 경험을 기반으로 외부 고객 제안 패키지를 구조화하는 것.
*   **핵심 문서:** **[[business]]**, **[[business-pipeline]]**, **[[go-to-market]]**, **[[sales]]**
