## 1. 현재 파이프라인

### A. 제조사 내부 지식 통합 프로젝트

- 단계: 1차 미팅 완료
- 고객 니즈: 공정 문서, 품질 문서, 설비 이슈 기록을 한곳에서 검색하고 싶음
- 제안 포인트:
  - 마크다운 기반 지식 자산화
  - 부서별 문서 링크 구조화
  - AI 질의응답용 정리 데이터 확보
- 다음 액션:
  - 샘플 문서 30건 받아 구조 분석
  - [r-and-d](/knowledge-base/r-and-d/)의 검색 성능 검증 결과와 연결

### B. IT 서비스사 온보딩 위키 구축

- 단계: 제안서 초안 작성
- 고객 니즈: 신입 개발자 온보딩 시간을 줄이고 싶음
- 제안 포인트:
  - 기술 문서와 프로젝트 맥락을 연결형 위키로 정리
  - Quartz 기반 웹 포털 제공
  - Claude Code 기반 초안 자동 정리 체계
- 다음 액션:
  - 온보딩 FAQ 샘플 10개 구성
  - [go-to-market](/knowledge-base/work/go-to-market/)의 패키지 가격안 반영

### C. 연구소형 조직 R&D 노트 아카이브

- 단계: 문제 정의 중
- 고객 니즈: 실험 메모와 회의 결과가 개인 PC에 흩어져 있음
- 제안 포인트:
  - 실험 기록 템플릿 통일
  - 결과와 가설을 링크 구조로 연결
  - 추후 검색/보고서 자동화 기반 확보
- 다음 액션:
  - 실험 기록 템플릿 초안 작성
  - [r-and-d-roadmap](/knowledge-base/r-and-d/r-and-d-roadmap/)와 연결

## 2. 공통 영업 메시지

- 우리는 문서 툴만 파는 것이 아니라, "AI가 일할 수 있는 문서 구조"를 만든다
- 문서 저장보다 문서 연결을 중요하게 본다
- 특정 SaaS 종속 없이 Git 기반으로 자산을 남긴다
