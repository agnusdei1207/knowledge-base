## 1. 영업 문서 목적

영업 문서는 단순 리드 목록이 아니라, 고객이 어떤 문제를 말했고 우리 쪽에서 어떤 구조로 설명할지를 정리하는 공간입니다.

---

## 2. 기본 메시지

### 고객 문제

- 문서가 흩어져 있어서 찾기 어렵다
- AI를 붙여도 답변 품질이 들쭉날쭉하다
- 부서 간 맥락 공유가 느리다

### 우리 제안

- 문서를 AI가 읽기 좋은 구조로 바꾼다
- 사람이 웹에서 탐색하기 쉬운 포털을 만든다
- Git 기반으로 자산 통제권을 유지한다

---

## 3. 자주 나오는 질문

### "왜 Notion 말고 이걸 쓰나요?"

- 원본 데이터 소유권이 더 강함
- AI 자동화와 버전관리에 유리함
- 그래프 기반 연결 탐색이 가능함

### "웹에서 바로 수정할 수 있나요?"

- 기본 구조는 Git/GitHub 편집 중심
- 필요하면 GitHub 편집 링크를 제공 가능
- 진짜 CMS형 편집기는 별도 시스템이 필요함

### "도입 난이도가 높지 않나요?"

- 처음엔 허브 문서 몇 개로 시작 가능
- 문서가 쌓일수록 구조적 장점이 커짐
- AI가 정리 업무를 일부 대신할 수 있음
