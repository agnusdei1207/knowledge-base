# 🌌 사내 지식저장소 (Knowledgebase)

사내 모든 문서와 기술 스택, 프로젝트 지식을 한눈에 파악할 수 있는 **네트워크형 지식저장소**에 오신 것을 환영합니다!

이 저장소는 **인간 동료(임직원)**들과 **AI 에이전트(Claude Code 등)**가 공통의 규칙(마크다운)을 바탕으로 함께 지식을 공유하고 협업하는 공간입니다.

---

## 🚀 시작 가이드 (인간 동료용)

본 지식저장소는 **Markdown 원본 + Git + Quartz 웹 포털**을 기준으로 운영됩니다. 편집기는 VS Code를 써도 되고, GitHub 웹 편집이나 AI 에이전트를 써도 됩니다.

1. **에디터 설치:** [Visual Studio Code](https://code.visualstudio.com/)를 다운로드 및 설치합니다.
2. **저장소 클론:** 이 GitHub 저장소를 본인의 PC에 클론(Clone) 받습니다.
   ```bash
   git clone https://github.com/agnusdei1207/knowledge-base.git
   ```
3. **폴더 열기:** VS Code에서 클론 받은 저장소 폴더를 엽니다.
4. **선택 플러그인 설치:** 필요하면 Markdown 보조 확장을 설치합니다. 하지만 특정 편집기 플러그인에 의존하지는 않습니다.
5. **메인 화면 진입:** `index.md` 파일을 열고 글쓰기를 시작합니다.

---

## 🔗 지식을 연결하는 법 (마크다운 사용법)

이 저장소에서는 모든 문서가 평평하게 유기적으로 연결됩니다. 전통적인 폴더 계층 구조 대신 **양방향 링크**를 적극 활용해 주세요!

*   **문서 연결하기 (양방향 링크):** 글을 쓰다가 다른 문서나 주제로 연결하고 싶다면 대괄호 두 개를 사용해 `[[연결할 문서 파일명]]`을 작성하세요.
    *   예시: `우리 팀은 다음 프로젝트에서 [[tech-stack]]에 대해 논의했습니다.`
*   **새 문서 생성:** 아직 존재하지 않는 문서 이름을 `[[새로운-문서-이름]]` 형태로 입력한 뒤, 마우스를 올리고 `Ctrl + 클릭`하면 자동으로 해당 문서 파일이 생성되며 즉시 연결됩니다!
*   **그래프 뷰 보기:** 브라우저에서 Quartz 사이트에 접속하면 문서 링크와 관련 문서를 웹에서 바로 탐색할 수 있습니다.

## 🤖 AI 에이전트 협업 가이드 (Claude Code 등)

Claude Code 등의 AI 에이전트를 사내 공용 지식 관리자로 임명하여 문서를 요약하거나 업데이트하게 할 수 있습니다.

1. **AI에게 저장소 권한 주기:** AI 에이전트에 이 레포지토리의 Access Token(PAT) 또는 SSH Key 정보를 알려주어 클론 받게 하세요.
2. **AI의 역할 범위:**
   *   사내 메신저나 회의록의 핵심을 추출하여 `inbox.md`에 자동으로 조각 정보로 아카이빙하기.
   *   중복되거나 파편화된 문서가 있으면, 관계를 분석하여 하나로 병합하고 기존 링크를 업데이트하기.
   *   새로운 기술 사양이나 결정 사항이 있을 때 마크다운 파일로 추가하고 Git Commit & Push 하기.
3. **AI 주의사항:** 문서를 수정할 때는 항상 표준 마크다운 문법을 준수하며, 기존의 양방향 링크(`[[문서명]]`) 연결 구조가 깨지지 않도록 하세요.

## 🌐 시각적 사내 위키 웹 배포 (Quartz)

사내 서버나 GitHub Pages에 **Quartz**를 셋팅하면, 개발 환경이 낯선 다른 직군들도 웹 브라우저로 접속해 그래프 맵과 검색 기능을 사용할 수 있습니다.

*   자세한 퍼블리싱 가이드는 [[quartz-deployment]] 문서를 참조하세요.
