# 🚩 종합 지식 대시보드 (Index)

사내 모든 지식과 업무 정보가 수렴하는 메인 인덱스 허브입니다.
여기에 연결된 문서들을 통해 점진적으로 뻗어나가며 지식을 탐색해 보세요.

---

## ⚡ 빠른 바로가기

### 1. 아이디어 보관함 (`Inbox`)
*   아직 체계적으로 정리되지 않은 메모, 간단한 회의록, 새로 배운 팁 등은 우선 **[[inbox]]**에 마음껏 집어넣어 주세요.
*   정기적으로 AI 에이전트나 구성원들이 이곳의 메모를 가공하여 다른 메인 문서로 연결하고 정리합니다.

### 2. 프로젝트 리스트 (`Projects`)
*   현재 활발히 논의 중인 사내 프로젝트와 태스크의 현황을 볼 수 있습니다.
*   👉 **[[projects]]**

### 3. 사내 기술 스택 (`Tech Stack`)
*   사내에서 주로 쓰이는 프로그래밍 언어, 라이브러리, 데이터베이스 명세가 정리되어 있습니다.
*   👉 **[[tech-stack]]**

### 4. 선택 사유와 운영 철학 (`Decision Log`)
*   왜 이 구조를 선택했는지, 어떤 대안을 검토했고 어떤 운영 원칙으로 굴리는지 정리한 문서입니다.
*   👉 **[[knowledgebase-decision-log]]**

### 5. 사업 문서 허브 (`Business`)
*   파이프라인, 시장 진입 가설, 고객 문제 정의 같은 사업 측면 문서를 모읍니다.
*   👉 **[[business]]**

### 6. 연구개발 허브 (`R&D`)
*   검색, RAG, 문서 자동화, 에이전트 협업 같은 연구개발 가설과 실험을 연결합니다.
*   👉 **[[r-and-d]]**

### 7. 개발 허브 (`Development`)
*   기술 구현, 아키텍처, 배포 구조를 개발 관점에서 정리합니다.
*   👉 **[[development]]**

### 8. 운영 허브 (`Operations`)
*   배포, 문서 운영, 협업 규칙 같은 운영 절차를 연결합니다.
*   👉 **[[operations]]**

### 9. 영업 허브 (`Sales`)
*   고객 대화 포인트, 제안 메시지, FAQ를 영업 관점에서 정리합니다.
*   👉 **[[sales]]**

### 10. 헤르메스 아키텍처 (`Hermes`)
*   여러 직원과 AI 에이전트가 같은 지식베이스를 쓰기 위한 전체 구조와 도입 방향을 정리합니다.
*   👉 **[[hermes-architecture]]**

### 11. 헤르메스 에이전트 (`Hermes Agent`)
*   CLI/TUI에서 돌아가는 Hermes Agent 자체를 우리 지식베이스와 어떻게 결합할지 정리합니다.
*   👉 **[[hermes-agent]]**

### 12. 검색/저장 파이프라인 (`Knowledge Pipeline`)
*   검색 품질, 비정형 자료 적재, 사람 친화적 원본 유지라는 목표를 동시에 만족시키는 데이터 흐름을 설명합니다.
*   👉 **[[hermes-pipeline]]**

### 13. 웹 편집 계층 (`Decap CMS`)
*   Decap CMS가 정확히 무엇이고, 왜 Quartz 단독 대신 같이 검토할 가치가 있는지 설명합니다.
*   👉 **[[decap-cms]]**
*   실제 편집기 주소: `/admin/`

### 14. Claude Code + MCP (`AI Ops`)
*   20명 규모에서 Claude Code와 MCP를 이용해 이 지식베이스를 공용 AI 컨텍스트로 운영하는 방안을 정리합니다.
*   👉 **[[claude-code-mcp]]**

### 15. MCP 클라이언트 설정 (`Client Profiles`)
*   Claude Code, Codex, Hermes CLI, OpenCode가 같은 공용 MCP 서버를 보도록 맞추는 규격과 설정 방법입니다.
*   👉 **[[mcp-client-setup]]**

---

## 💡 유용한 팁

*   원하는 문서로 빠르게 이동하고 싶다면 `Ctrl + P`를 누른 뒤 문서명을 입력하세요.
*   오른쪽의 문서 외곽에 링크를 더 추가하고 싶다면 그냥 대괄호 `[[새문서이름]]`을 본문에 자유롭게 적으시면 됩니다.
*   이 마크다운 파일들의 연결망은 **Quartz 웹 포털**에서 그래프와 관련 문서 탐색으로 확인할 수 있습니다.
*   사업, 기술, 운영 문서를 따로 두기보다 허브 문서에서 서로 연결하는 방식을 권장합니다.
