## 📌 기술사 시험 체계 및 핵심 키워드 마스터
이곳은 정보통신기술사 및 컴퓨터응용시스템기술사 시험의 16과목을 심층 분석하고, 과목 간 융합 지식을 정리한 전용 스터디 공간입니다.

### 📚 과목 바로가기

| 분류 | 과목명 | 내용 요약 |
| :--- | :--- | :--- |
| **01** | **컴퓨터 구조** | 논리회로, ISA, 파이프라이닝, 캐시, AI 가속기 하드웨어 |
| **02** | **운영 체제** | 프로세스/스레드, 메모리 관리, 파일 시스템, 가상화 |
| **03** | **네트워크** | OSI 7 Layer, TCP/IP, 무선 통신, 차세대 네트워크 기술 |
| **04** | **소프트웨어 공학** | 개발 방법론, 설계 패턴, 테스트, 품질 관리 및 리팩토링 |
| **05** | **데이터베이스** | 관계형 DB, SQL, 정규화, NoSQL, 트랜잭션, 동시성 제어 |
| **06** | **ICT 융합 기술** | IoT, 스마트 팩토리, 모빌리티, 가상현실, 융합 보안 |
| **07** | **엔터프라이즈 시스템** | ERP, CRM, SCM, EAI/ESB, MSA, 엔터프라이즈 아키텍처 |
| **08** | **알고리즘 및 통계** | 자료구조, 알고리즘 설계, 기초 확률 및 통계 이론 |
| **09** | **보안 (Security)** | 암호학, network 보안, 시스템 보안, 보안 취약점 점검 |
| **10** | **인공지능 (AI)** | 머신러닝, 딥러닝, NLP, LLM, RAG, AI 윤리 및 가이드라인 |
| **11** | **IT 설계 및 감리** | 공공 정보화 사업 설계, 감리 절차 및 기준법 |
| **12** | **IT 경영** | IT 거버넌스, ITIL, SLA, 아웃소싱 전략, 경영 전략 모델 |
| **13** | **클라우드 아키텍처** | 가상화, 클라우드 컴퓨팅 모델(IaaS/PaaS/SaaS), 쿠버네티스 |
| **14** | **데이터 엔지니어링** | 데이터 레이크, DW, 배치/스트림 파이프라인, 분산처리 |
| **15** | **DevOps & SRE** | CI/CD, IaC, 옵저버빌리티, 모니터링, 카오스 엔지니어링 |
| **16** | **빅데이터 실무** | 분산 환경 하둡/스파크, 빅데이터 분석 방법론 및 분석 도구 |
