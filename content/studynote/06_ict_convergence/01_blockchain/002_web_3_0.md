# 02. Web 3.0 (Read-Write-Own)

## 핵심 인사이트 (3줄 요약)
> 1. **본질**: Web 3.0은 [탈중앙화](/studynote/06_ict_convergence/01_blockchain/010_decentralization/)([Decentralization](/studynote/06_ict_convergence/01_blockchain/010_decentralization/))를 핵심특정으로 하며, 사용자가 플랫폼에 종속되지 않고 자신의 [데이터](/studynote/05_database/01_db_architecture_relational/001_dikw_pyramid/)와 디지털 자산에 대한진정한 소유권을 가지는 인터넷 패러다임이다.
> 2. **가치**: [블록체인](/studynote/06_ict_convergence/01_blockchain/004_blockchain/) 기반의 [스마트 컨트랙트](/studynote/06_ict_convergence/01_blockchain/022_smart_contract/)([Smart Contract](/studynote/06_ict_convergence/01_blockchain/022_smart_contract/))를 통해 중개자 없이도 투명하고 안전한 거래가 가능하며, 사용자는 자신의 신원과 [데이터](/studynote/05_database/01_db_architecture_relational/001_dikw_pyramid/)를 직접 통제할 수 있다.
> 3. **융합**: [블록체인](/studynote/06_ict_convergence/01_blockchain/004_blockchain/), [시맨틱 웹](/studynote/06_ict_convergence/01_blockchain/003_semantic_web/)([Semantic Web](/studynote/06_ict_convergence/01_blockchain/003_semantic_web/)), [인공지능](/studynote/10_ai/03_llm_nlp/231_ai_turing_test/)([AI](/studynote/04_software_engineering/03_design_architecture/190_ai_llm_requirements_specification/)) 기술이 융합되어 개인 소유권이 보장되는 지능형 인터넷으로 발전하고 있다.

## Ⅰ. 개요 및 필요성 ([Context](/studynote/02_operating_system/01_overview_architecture/033_context/) & Necessity)

### 개념의 정의

Web 3.0(Read-Write-Own)은 Web 2.0의 중앙화된 플랫폼 구조에서 발생하는 [데이터](/studynote/05_database/01_db_architecture_relational/001_dikw_pyramid/) 독점, 검열, [개인정보](/studynote/09_security/16_data_privacy/781_personal_information/) 침해 등의 문제점을 해결하기 위해 제안된 차세대 인터넷 패러다임이다. [탈중앙화](/studynote/06_ict_convergence/01_blockchain/010_decentralization/)([Decentralization](/studynote/06_ict_convergence/01_blockchain/010_decentralization/))를 핵심 원칙으로 하며, [블록체인](/studynote/06_ict_convergence/01_blockchain/004_blockchain/) 기술을 활용하여 사용자가 자신의 신원(Identity)과 [데이터](/studynote/05_database/01_db_architecture_relational/001_dikw_pyramid/)([Data](/studynote/05_database/01_db_architecture_relational/001_dikw_pyramid/)), 디지털 자산(Digital Asset)에 대한 직접적인 소유권(Ownership)을 보유할 수 있게 한다. Web 1.0이 읽기 전용(Read-only), Web 2.0이 읽기-쓰기(Read-Write)였다면, Web 3.0은 읽기-쓰기-소유(Read-Write-Own)로internet의 evolution을완성한다.

### 탄생 배경과 필요성

Web 2.0 시대에 구글, 메타(페이스북), 아마존, 애플 등의 플랫폼 기업은 사용자로부터 방대한 [데이터](/studynote/05_database/01_db_architecture_relational/001_dikw_pyramid/)를 수집하여 광고 수익과 [서비스](/studynote/13_cloud_architecture/02_iaas_paas_saas/090_service_kubernetes_network_load_balancing/) 최적화에 활용하였다. 문제는 이러한 [데이터](/studynote/05_database/01_db_architecture_relational/001_dikw_pyramid/)가본질적으로 플랫폼 기업의 자산이 되어 사용자의 동의 없이 활용될 수 있다는 점이다. 2018년 캠브릿지 애널리티카 스캔들은 5,000만 명 이상의 페이스북 사용자 [데이터](/studynote/05_database/01_db_architecture_relational/001_dikw_pyramid/)가 동의 없이 정치적 목적으로 활용되었음을 드러내며 사회적인 충격을 주었다. 또한 특정 국가정부와 플랫폼 기업의 검열 권한 남용문제도 점점 확대되고 있다. 이러한구조적 문제점을 해결하기 위해 등장한것이 Web 3.0이다.

### 💡 analogy

Web 3.0은 전통적인 은행 시스템과 비교할 수 있다. 기존 Web 2.0의 플랫폼은 모든 [데이터](/studynote/05_database/01_db_architecture_relational/001_dikw_pyramid/)를 한 곳(은행 금고)에 보관하며 그 은행이 거래 내역과 고객 정보를전부장공한다. 반면 Web 3.0은 각 고객이 자기 자신의 금고 자물쇠 열쇠(개인 키, Private [Key](/studynote/05_database/02_modeling_normalization/067_db_key_uniqueness_minimality/))를보관하며, 모든 거래는 [분산](/studynote/08_algorithm_stats/08_stats/136_variance/)된 장부([블록체인](/studynote/06_ict_convergence/01_blockchain/004_blockchain/))에 기록되어 누구도 조작할 수 없다. 은행이 없어도 거래가 가능하며, 금고 관리자에게 통행료(수수료)를 지불할 필요도 없다.

### 배경 설명

Web 3.0의 구현을위해서는 여러 기술이 복합적으로 활용된다. [블록체인](/studynote/06_ict_convergence/01_blockchain/004_blockchain/)([Blockchain](/studynote/06_ict_convergence/01_blockchain/004_blockchain/))은 [분산 원장 기술](/studynote/06_ict_convergence/01_blockchain/474_dlt_distributed_ledger_technology/)([DLT](/studynote/03_network/18_optical_nextgen_automation/919_dlt_distributed_ledger_technology_consensus_bottleneck/), Distributed Ledger Technology)을 통해 [데이터](/studynote/05_database/01_db_architecture_relational/001_dikw_pyramid/)의변조 불가능성(Immutability)과 투명성(Transparency)을 보장한다. [스마트 컨트랙트](/studynote/06_ict_convergence/01_blockchain/022_smart_contract/)([Smart Contract](/studynote/06_ict_convergence/01_blockchain/022_smart_contract/))는 사전에 정의된 조건이 충족되면 코드가 자동으로 실행되어 중개자 없이 거래를 가능하게 한다. [탈중앙화 신원증명](/studynote/06_ict_convergence/01_blockchain/052_did_architecture_issuer_holder_verifier_vc_vp/)([DID](/studynote/12_it_management/05_security_compliance/231_did_decentralized_identity/), Decentralized Identity)은 사용자가 자신의 신원 정보를 직접 관리하고 통제할 수 있는 W3C 표준이다. 또한 [IPFS](/studynote/06_ict_convergence/01_blockchain/055_ipfs_interplanetary_file_system/)([InterPlanetary File System](/studynote/06_ict_convergence/01_blockchain/055_ipfs_interplanetary_file_system/))와 같은 [분산](/studynote/08_algorithm_stats/08_stats/136_variance/) [파일](/studynote/02_operating_system/09_file_system/501_file_definition_logical_record/) 시스템은 중앙화된 서버에 의존하지 않고 [데이터](/studynote/05_database/01_db_architecture_relational/001_dikw_pyramid/)를 저장하고검색할 수 있게 한다.

### 📢 비유 요약

Web 1.0은 한 사람이 마이크를 잡고연사하는 강연회장과 같다. 청중은 수동적에듣기만 한다. Web 2.0은 토론 프로그램과 같다. 진행자의사회하에서참가자들이의론하지만, 프로그램편집권은 여전히 진행자에게 있다. Web 3.0은 민주주의 토론토론과 같다. 모든 참여자가평등한 발언권을 가지며,투표 결과를투명하게기록하고,[moderator](/studynote/04_software_engineering/10_trends_pm_quality/760_inspection_moderator_formal_review/)(중개자) 없이 직접 투표가 이루어진다.

### 핵심 구성 요소

<strong><a href="/studynote/06_ict_convergence/01_blockchain/052_did_architecture_issuer_holder_verifier_vc_vp/">탈중앙화 신원증명</a>(<a href="/studynote/12_it_management/05_security_compliance/231_did_decentralized_identity/">DID</a>)</strong>: W3C 표준인 DID는Issuer(발행자), Holder(소유자/지갑), Verifier([검증](/studynote/04_software_engineering/07_object_oriented/395_verification_process_review/)자)의 3자 구조로 구성된다. 사용자는 신원 정보를 담고 있는 [분산](/studynote/08_algorithm_stats/08_stats/136_variance/) [식별자](/studynote/03_network/06_network_layer_ip/289_identification_flags_fragmentation_offset/)([DID](/studynote/12_it_management/05_security_compliance/231_did_decentralized_identity/) [Document](/studynote/14_data_engineering/01_infrastructure/037_document/))를생성하고, [검증](/studynote/04_software_engineering/07_object_oriented/395_verification_process_review/) 가능한 증명(VC, Verifiable Credential)을 통해 자신의 신원을 제시할 수 있다. 예를 들어 대학교는 학위증이라는 VC를발행하고, 학생은 이를 지갑에보존하다가 필요한 경우에만검정자에게제시한다. 중개자(중앙 서버) 없이 직접 [검증](/studynote/04_software_engineering/07_object_oriented/395_verification_process_review/)이 가능해진다.

<strong><a href="/studynote/06_ict_convergence/01_blockchain/022_smart_contract/">스마트 컨트랙트</a></strong>: 사전에 작성된 코드가 [블록체인](/studynote/06_ict_convergence/01_blockchain/004_blockchain/)에서자동실행されるプログラム에서ある. 금융거래, 부동산 계약, 디지털 자산 소유권 이전등도기한령역에 활용된다. [단일 장애점](/studynote/01_computer_architecture/13_reliability_power_management/454_spof/)([SPOF](/studynote/01_computer_architecture/13_reliability_power_management/454_spof/))이 존재하지 않아 [서비스](/studynote/13_cloud_architecture/02_iaas_paas_saas/090_service_kubernetes_network_load_balancing/) 중단 위험이 적다.

<strong><a href="/studynote/06_ict_convergence/01_blockchain/026_token_economy/">토큰 이코노미</a>(<a href="/studynote/06_ict_convergence/01_blockchain/026_token_economy/">Token Economy</a>)</strong>: Web 3.0에서는 플랫폼의성장에따른 가치 상승분을 사용자와 플랫폼이 함께 나누는 구조가 가능하다. 플랫폼 토큰(Platform Token)을 보유한 사용자는 플랫폼 운영에 참여하고, 수익의 일부를 배분받을 수 있다.

### 📢 비유 요약

Web 3.0의 아키텍처는 지식공유대도시도서관과 같다. 모든 책([데이터](/studynote/05_database/01_db_architecture_relational/001_dikw_pyramid/))이 한 곳의서고에집중되지 않고,도시 곳곳에분산 배치되어 있다. 누군가 책을 빌려갈 때마다（거래 발생）모든 [분산](/studynote/08_algorithm_stats/08_stats/136_variance/) 장부에동일한 기록이자동기재된다. 도난야불가능하고,관리onshire，야불요서 도서관 운영에 참여하는 독자들 모두의 동의가 필요하다.

## Ⅲ. 구현 및 실무 응용 (Implementation & Practice)

### [DApp](/studynote/06_ict_convergence/01_blockchain/032_dapp_decentralized_application/)([탈중앙화](/studynote/06_ict_convergence/01_blockchain/010_decentralization/) 애플리케이션) 사례

Web 3.0의대표성적실장사례는 [탈중앙화](/studynote/06_ict_convergence/01_blockchain/010_decentralization/) 애플리케이션([DApp](/studynote/06_ict_convergence/01_blockchain/032_dapp_decentralized_application/), [Decentralized Application](/studynote/04_software_engineering/09_cloud_native_ai_architecture/592_blockchain_dapp_architecture_ipfs/))이다. Uniswap은 이더리움 기반의 [탈중앙화](/studynote/06_ict_convergence/01_blockchain/010_decentralization/) 거래소(DEX)로, 중앙화된 거래소와 달리 사용자의 자금이교역소의 지갑에예탁되지 않고, [스마트 컨트랙트](/studynote/06_ict_convergence/01_blockchain/022_smart_contract/) 직접 교환된다. OpenSea는 NFT([Non-Fungible Token](/studynote/06_ict_convergence/01_blockchain/029_nft_non_fungible_token/)) 마켓플레이스로, 디지털 아트작품적적소유권을블록체인상에서증명하고 거래할 수 있게 한다. Lens Protocol은 [탈중앙화](/studynote/06_ict_convergence/01_blockchain/010_decentralization/) 소셜 네트워크로, 사용자가 자신의 소셜 [그래프](/studynote/08_algorithm_stats/04_datastructure/070_graph_datastructure/)(팔로잉/팔로워 [관계](/studynote/05_database/02_modeling_normalization/083_relationship_in_er_model/))를직접 보유하고 다른 플랫폼으로이동할 수 있다.

### [메타버스](/studynote/04_software_engineering/09_cloud_native_ai_architecture/594_metaverse_realtime_sync_rendering_offloading/)와 Web 3.0 융합

Web 3.0은 [메타버스](/studynote/04_software_engineering/09_cloud_native_ai_architecture/594_metaverse_realtime_sync_rendering_offloading/)([Metaverse](/studynote/04_software_engineering/09_cloud_native_ai_architecture/594_metaverse_realtime_sync_rendering_offloading/))와의융합에より 새로운 가능성을 열고 있다. Decentraland와 The Sandbox 같은 가상 세계에서는 사용자가 구매한 가상 토지(LAND)에 대한 NFT 기반적소유권을보유하며, 가상 세계 내에서경제활동을 벌일 수 있다. 이러한 가상 경제는 현실 경제와 연결되어 진정한 의미의 가상-현실 통합(Virtual-Real Integration)을구현한다.

### [DeFi](/studynote/06_ict_convergence/01_blockchain/033_defi_decentralized_finance/)([탈중앙화](/studynote/06_ict_convergence/01_blockchain/010_decentralization/) 금융) 실무

[DeFi](/studynote/06_ict_convergence/01_blockchain/033_defi_decentralized_finance/)(Decentralized Finance)는 Web 3.0의 가장성숙한응용분야이다. MakerDAO는 담보물로 안정적인 스테이블코인(DAI)을 발행하는 [탈중앙화](/studynote/06_ict_convergence/01_blockchain/010_decentralization/) 프로토콜이다. 사용자는 이더리움([ETH](/studynote/08_algorithm_stats/06_np_theory/118_eth/)) 등을 예치하고 DAI를 차입(借入)함으로써 유동성을확보한다. Aave는 [탈중앙화](/studynote/06_ict_convergence/01_blockchain/010_decentralization/) 대출 플랫폼으로, 사용자가 자산을 예치하면 다른 사용자가 이를 차입하고 이자를 지불하는 구조이다. 전통 금융기관의개재을 Eliminates하여 보다 효율적인 자본 시장의 형성이 가능해진다.

### 📢 비유 요약

Web 3.0의 실생활 적용은지능 계약서 robot와 같다. 집을 매도할 때 전통 방식으로는 중개보수(매도가의 4~6%)를불동산중개소에 지불해야 한다. [스마트 컨트랙트](/studynote/06_ict_convergence/01_blockchain/022_smart_contract/)를활용하면 매도 조건이 충족되면 자동으로 소유권이 이전되고, 중개자 비용이ゼロ가 된다. 모든 거래 기록은블록체인에영구히보존되어 뒤집을 수 없다.

## Ⅳ. 품질 관리 및 테스트 (Quality & Testing)

### [스마트 컨트랙트](/studynote/06_ict_convergence/01_blockchain/022_smart_contract/) 보안심계

Web 3.0 환경에서품질관리의 가장 중요한 영역은 [스마트 컨트랙트](/studynote/06_ict_convergence/01_blockchain/022_smart_contract/)의セキュリティ에서ある. 2016년 The [DAO](/studynote/06_ict_convergence/01_blockchain/054_dao_decentralized_autonomous_organization/) 해킹 사건에서는 [스마트 컨트랙트](/studynote/06_ict_convergence/01_blockchain/022_smart_contract/)의 재진입([Re-entrancy](/studynote/06_ict_convergence/01_blockchain/056_smart_contract_vulnerability_reentrancy/)) 취약점이 악용되어 6,000만 달러 규모의 이더리가 도난당하였다.인차, [스마트 컨트랙트](/studynote/06_ict_convergence/01_blockchain/022_smart_contract/)는형식검정([Formal Verification](/studynote/06_ict_convergence/01_blockchain/093_smart_contract_formal_verification/)), コード심계([Code](/studynote/02_operating_system/02_process_thread/082_process_memory_structure/) [Audit](/studynote/12_it_management/05_security_compliance/363_audit/)), [버그 바운티](/studynote/09_security/13_secops_ir_forensics/680_bug_bounty/)([Bug Bounty](/studynote/09_security/13_secops_ir_forensics/680_bug_bounty/)) 프로그램 등을 통해다층적으로 안전성을 [검증](/studynote/04_software_engineering/07_object_oriented/395_verification_process_review/)해야 한다. 대표적으로 Certora, Mythril, Slither 등의 도구가활용된다.

### [DApp](/studynote/06_ict_convergence/01_blockchain/032_dapp_decentralized_application/) [성능](/studynote/04_software_engineering/05_devops_ci_cd/282_performance_tactics/) 지표

DApp의 [성능](/studynote/04_software_engineering/05_devops_ci_cd/282_performance_tactics/)을 평가하는 주요 지표로는 TPS(Transactions Per Second), 완결성([Finality](/studynote/06_ict_convergence/01_blockchain/065_consensus_finality_probabilistic_deterministic/)) 시간,[Gas](/studynote/06_ict_convergence/01_blockchain/024_gas/) 비용 등이 있다. 현재 이더리움 메인넷은 약 15~30 TPS 수준으로, 비자( Visa)의 65,000 TPS에 비해 현저히 낮다. 레이어 2(Layer 2) 솔루션인 [롤업](/studynote/06_ict_convergence/01_blockchain/042_rollup_l2_solution/)([Rollup](/studynote/06_ict_convergence/01_blockchain/042_rollup_l2_solution/)) 기술은 이를 극복하기 위해 개발되었으며, 옵티미스틱 [롤업](/studynote/06_ict_convergence/01_blockchain/042_rollup_l2_solution/)(Optimistic [Rollup](/studynote/06_ict_convergence/01_blockchain/042_rollup_l2_solution/))은 약 4,500 TPS, ZK [롤업](/studynote/06_ict_convergence/01_blockchain/042_rollup_l2_solution/)(Zero-Knowledge [Rollup](/studynote/06_ict_convergence/01_blockchain/042_rollup_l2_solution/))은 약 2,000 TPS를 이론적으로 가능하다.

### 규제 및 컴플라이언스

Web 3.0의 [탈중앙화](/studynote/06_ict_convergence/01_blockchain/010_decentralization/) 특성으로 인해 규제 당국은 새로운 도전에 직면하고 있다. 가상자산사업자([VASP](/studynote/06_ict_convergence/01_blockchain/085_travel_rule_vasp_fatf/))의 자금세탁방지(AML) 규제, 토큰 판매의 증권법 적합성, NFT의 지적재산권 문제 등이 대표적인 규제 과제이다. EU의 MiCA(가밀자산 시장 법안)는 이러한 Web 3.0 규제의대표적な사례이다.

### 📢 비유 요약

Web 3.0의 품질 관리는항공기의다중안전システム와/과사있는. 엔진이고장해도 다른 엔진으로 비상 착륙할 수 있으며, 조종실에서 자동으로 제공하는 정보 외에도 조종사가직접 계기판을 확인한다. [스마트 컨트랙트](/studynote/06_ict_convergence/01_blockchain/022_smart_contract/)의심계는 항공기의 출고 전 검사항목과 같으며, 정기적인.check-ups이 필수이다.

## Ⅴ. 최신 트렌드 및 결론 (Trends & Conclusion)

### Web 3.0의 현재 동향

2024년 현재 Web 3.0은 아직 [초기](/studynote/03_network/08_transport_layer/459_quic_fec_forward_error_correction/) 단계에 있으며, 기술적 한계(확장성, 사용자 경험)와 규제 불확실성이 주요 걸림돌로 작용하고 있다. 그러나 레이어 2 솔루션의 발전으로 거래 비용([Gas](/studynote/06_ict_convergence/01_blockchain/024_gas/) Fee)이 크게 낮아지고, [계정 추상화](/studynote/06_ict_convergence/01_blockchain/087_account_abstraction_erc_4337/)(Account [Abstraction](/studynote/04_software_engineering/04_testing_quality/198_abstraction_control_data_process/), ERC-4337)를 통해 일반 사용자도 쉽게 사용할 수 있는 환경이 조성되고 있다. [지갑 멀티시그](/studynote/06_ict_convergence/01_blockchain/086_multisig_wallet_n_of_m/)(Multi-Sig) 기술과 소셜 [복구](/studynote/09_security/13_secops_ir_forensics/658_ir_recovery/)(Social [Recovery](/studynote/09_security/13_secops_ir_forensics/658_ir_recovery/)) 기능의 도입으로 사용자의 자산 안전성이 강화되고 있다.

### AI와 Web 3.0의 융합

 [인공지능](/studynote/10_ai/03_llm_nlp/231_ai_turing_test/)([AI](/studynote/04_software_engineering/03_design_architecture/190_ai_llm_requirements_specification/))과 Web 3.0의융합은, 새로운しい분야를개い있는.  [AI](/studynote/04_software_engineering/03_design_architecture/190_ai_llm_requirements_specification/) 알고리즘을 활용하여 [스마트 컨트랙트](/studynote/06_ict_convergence/01_blockchain/022_smart_contract/)의취약점을 자동으로 탐지하거나, 개인화된 [탈중앙화](/studynote/06_ict_convergence/01_blockchain/010_decentralization/) 금융([DeFi](/studynote/06_ict_convergence/01_blockchain/033_defi_decentralized_finance/)) [서비스](/studynote/13_cloud_architecture/02_iaas_paas_saas/090_service_kubernetes_network_load_balancing/)를 제공하는 등의시み이/가진행중이다. 또한블록체인기출를 활용하여 [AI](/studynote/04_software_engineering/03_design_architecture/190_ai_llm_requirements_specification/) 학습 [데이터](/studynote/05_database/01_db_architecture_relational/001_dikw_pyramid/)의 출처를투명하게 기록하고, [AI](/studynote/04_software_engineering/03_design_architecture/190_ai_llm_requirements_specification/) 생성물의 [저작권](/studynote/04_software_engineering/09_cloud_native_ai_architecture/583_ai_code_license_security_threats/) 문제를해결하려는 시도도 이루어지고 있다.

### 📢 비유 요약

Web 3.0의 현재 단계는호련망의 1990년대로 비유할 수 있다. 당시에는료일반인들이 인터넷을 사용하기 어려웠으며, 기술에정통한소수의 사람들이 주로리용했다. 그러나 수착시간적추이, 기술이 성숙하고 사용자가 증가하면 서，만만히주류가 될 것이다. Web 3.0도 마찬가지로 현재의 어려움을 극복하고미래적에는より많은인々에리용される 인터넷기반과なる 것이다.

### 결론

Web 3.0은 인터넷의근본적 변혁을 대표한다. 중앙화된 플랫폼에의한 [데이터](/studynote/05_database/01_db_architecture_relational/001_dikw_pyramid/) 독점에서탈し, 사용자가 자신의 [데이터](/studynote/05_database/01_db_architecture_relational/001_dikw_pyramid/)와 자산의 주인이 되는 패러다임으로 전환하는 것이다. 아직 기술적 성숙과 규제 정합성 측면에서 해결해야 할과제가 남아있지만, 그잠재력은거대하다. Web 3.0은 단순한 기술의진화이 아니라, 인터넷의본질적 가치관에 대한재정의라고 할 수 있다.
