# 02. Web 3.0 (Read-Write-Own)

## 핵심 인사이트 (3줄 요약)
> 1. **본질**: Web 3.0은 [[010_decentralization|탈중앙화]]([[010_decentralization|Decentralization]])를 핵심特征으로 하며, 사용자가 플랫폼에 종속되지 않고 자신의 [[001_dikw_pyramid|데이터]]와 디지털 자산에 대한真正한 소유권을 가지는 인터넷 패러다임이다.
> 2. **가치**: [[004_blockchain|블록체인]] 기반의 [[022_smart_contract|스마트 컨트랙트]]([[022_smart_contract|Smart Contract]])를 통해 중개자 없이도 투명하고 안전한 거래가 가능하며, 사용자는 자신의 신원과 [[001_dikw_pyramid|데이터]]를 직접 통제할 수 있다.
> 3. **융합**: [[004_blockchain|블록체인]], [[003_semantic_web|시맨틱 웹]]([[003_semantic_web|Semantic Web]]), [[231_ai_turing_test|인공지능]]([[190_ai_llm_requirements_specification|AI]]) 기술이 융합되어 개인 소유권이 보장되는 지능형 인터넷으로 발전하고 있다.

## Ⅰ. 개요 및 필요성 ([[033_context|Context]] & Necessity)

### 개념의 정의

Web 3.0(Read-Write-Own)은 Web 2.0의 중앙화된 플랫폼 구조에서 발생하는 [[001_dikw_pyramid|데이터]] 독점, 검열, [[781_personal_information|개인정보]] 침해 등의 문제점을 해결하기 위해 제안된 차세대 인터넷 패러다임이다. [[010_decentralization|탈중앙화]]([[010_decentralization|Decentralization]])를 핵심 원칙으로 하며, [[004_blockchain|블록체인]] 기술을 활용하여 사용자가 자신의 신원(Identity)과 [[001_dikw_pyramid|데이터]]([[001_dikw_pyramid|Data]]), 디지털 자산(Digital Asset)에 대한 직접적인 소유권(Ownership)을 보유할 수 있게 한다. Web 1.0이 읽기 전용(Read-only), Web 2.0이 읽기-쓰기(Read-Write)였다면, Web 3.0은 읽기-쓰기-소유(Read-Write-Own)로internet의 evolution을完成한다.

### 탄생 배경과 필요성

Web 2.0 시대에 구글, 메타(페이스북), 아마존, 애플 등의 플랫폼 기업은 사용자로부터 방대한 [[001_dikw_pyramid|데이터]]를 수집하여 광고 수익과 [[090_service_kubernetes_network_load_balancing|서비스]] 최적화에 활용하였다. 문제는 이러한 [[001_dikw_pyramid|데이터]]가本質적으로 플랫폼 기업의 자산이 되어 사용자의 동의 없이 활용될 수 있다는 점이다. 2018년 캠브릿지 애널리티카 스캔들은 5,000만 명 이상의 페이스북 사용자 [[001_dikw_pyramid|데이터]]가 동의 없이 정치적 목적으로 활용되었음을 드러내며 사회적인 충격을 주었다. 또한 특정 국가政府和 플랫폼 기업의 검열 권한 남용问题도 점점 확대되고 있다. 이러한構造的 문제점을 해결하기 위해 등장한것이 Web 3.0이다.

### 💡 analogy

Web 3.0은 전통적인 은행 시스템과 비교할 수 있다. 기존 Web 2.0의 플랫폼은 모든 [[001_dikw_pyramid|데이터]]를 한 곳(은행 금고)에 보관하며 그 은행이 거래 내역과 고객 정보를全部掌控한다. 반면 Web 3.0은 각 고객이 자기 자신의 금고 자물쇠 열쇠(개인 키, Private [[067_db_key_uniqueness_minimality|Key]])를保管하며, 모든 거래는 [[136_variance|분산]]된 장부([[004_blockchain|블록체인]])에 기록되어 누구도 조작할 수 없다. 은행이 없어도 거래가 가능하며, 금고 관리자에게 통행료(수수료)를 지불할 필요도 없다.

### 배경 설명

Web 3.0의 实现을위해서는 여러 기술이 복합적으로 활용된다. [[004_blockchain|블록체인]]([[004_blockchain|Blockchain]])은 [[474_dlt_distributed_ledger_technology|분산 원장 기술]]([[919_dlt_distributed_ledger_technology_consensus_bottleneck|DLT]], Distributed Ledger Technology)을 통해 [[001_dikw_pyramid|데이터]]의改竄 불가능성(Immutability)과 투명성(Transparency)을 보장한다. [[022_smart_contract|스마트 컨트랙트]]([[022_smart_contract|Smart Contract]])는 사전에 정의된 조건이 충족되면 코드가 자동으로 실행되어 중개자 없이 거래를 가능하게 한다. [[052_did_architecture_issuer_holder_verifier_vc_vp|탈중앙화 신원증명]]([[231_did_decentralized_identity|DID]], Decentralized Identity)은 사용자가 자신의 신원 정보를 직접 관리하고 통제할 수 있는 W3C 표준이다. 또한 [[055_ipfs_interplanetary_file_system|IPFS]]([[055_ipfs_interplanetary_file_system|InterPlanetary File System]])와 같은 [[136_variance|분산]] [[501_file_definition_logical_record|파일]] 시스템은 중앙화된 서버에 의존하지 않고 [[001_dikw_pyramid|데이터]]를 저장하고检索할 수 있게 한다.

### 📢 비유 요약

Web 1.0은 한 사람이 마이크를 잡고演辭하는 강연会场と 같다. 청중은 受動的に듣기만 한다. Web 2.0은 토론 프로그램과 같다. 진행자의司会下で참가자들이議論하지만, 프로그램編集権은 여전히 진행자에게 있다. Web 3.0은 민주주의 토론토론과 같다. 모든 참여자가平等한 발언권을 가지며,投票 결과를투명하게記録하고,[[760_inspection_moderator_formal_review|moderator]](중개자) 없이 직접 투표가 이루어진다.

### 핵심 구성 요소

**[[052_did_architecture_issuer_holder_verifier_vc_vp|탈중앙화 신원증명]]([[231_did_decentralized_identity|DID]])**: W3C 표준인 DID는Issuer(발행자), Holder(소유자/지갑), Verifier([[395_verification_process_review|검증]]자)의 3자 구조로 구성된다. 사용자는 신원 정보를 담고 있는 [[136_variance|분산]] [[289_identification_flags_fragmentation_offset|식별자]]([[231_did_decentralized_identity|DID]] [[037_document|Document]])를作成하고, [[395_verification_process_review|검증]] 가능한 증명(VC, Verifiable Credential)을 통해 자신의 신원을 제시할 수 있다. 예를 들어 대학교는 학위증이라는 VC를発行하고, 학생은 이를 지갑에保存하다가 필요한 경우에만検証자에게提示한다. 중개자(중앙 서버) 없이 直接 [[395_verification_process_review|검증]]이 가능해진다.

**[[022_smart_contract|스마트 컨트랙트]]**: 사전에 작성된 코드가 [[004_blockchain|블록체인]]에서自動実行されるプログラムである。金融거래, 부동산 계약, 디지털 자산 소유권 이전等都岐한領域에 활용된다. [[454_spof|단일 장애점]]([[454_spof|SPOF]])이 존재하지 않아 [[090_service_kubernetes_network_load_balancing|서비스]] 중단 위험이 적다.

**[[026_token_economy|토큰 이코노미]]([[026_token_economy|Token Economy]])**: Web 3.0에서는 플랫폼의成長에따른 가치 상승분을 사용자와 플랫폼이 함께 나누는 구조가 가능하다. 플랫폼 토큰(Platform Token)을 보유한 사용자는 플랫폼 운영에 참여하고, 수익의 일부를 배분받을 수 있다.

### 📢 비유 요약

Web 3.0의 아키텍처는 지식공유大都市圖書관과 같다. 모든 책([[001_dikw_pyramid|데이터]])이 한 곳의書庫에集中되지 않고,都市 곳곳에분산 배치되어 있다. 누군가 책을 빌려갈 때마다（거래 발생）모든 [[136_variance|분산]] 장부에同一한 기록이自動記載된다. 도난也不可能하고,管理onshire，也不要서 도서관 운영에 참여하는 독자들 모두의 동의가 필요하다.

## Ⅲ. 구현 및 실무 응용 (Implementation & Practice)

### [[032_dapp_decentralized_application|DApp]]([[010_decentralization|탈중앙화]] 애플리케이션) 사례

Web 3.0의代表性的実装事例는 [[010_decentralization|탈중앙화]] 애플리케이션([[032_dapp_decentralized_application|DApp]], [[592_blockchain_dapp_architecture_ipfs|Decentralized Application]])이다. Uniswap은 이더리움 기반의 [[010_decentralization|탈중앙화]] 거래소(DEX)로, 중앙화된 거래소와 달리 사용자의 자금이交易所의 지갑에預託되지 않고, [[022_smart_contract|스마트 컨트랙트]] 직접 교환된다. OpenSea는 NFT([[029_nft_non_fungible_token|Non-Fungible Token]]) 마켓플레이스로, 디지털 아트作品的的所有權을区块链上에서증명하고 거래할 수 있게 한다. Lens Protocol은 [[010_decentralization|탈중앙화]] 소셜 네트워크로, 사용자가 자신의 소셜 [[070_graph_datastructure|그래프]](팔로잉/팔로워 [[083_relationship_in_er_model|관계]])를직접 보유하고 다른 플랫폼으로이동할 수 있다.

### [[594_metaverse_realtime_sync_rendering_offloading|메타버스]]와 Web 3.0 융합

Web 3.0은 [[594_metaverse_realtime_sync_rendering_offloading|메타버스]]([[594_metaverse_realtime_sync_rendering_offloading|Metaverse]])와의融合により 새로운 가능성을 열고 있다. Decentraland와 The Sandbox 같은 가상 세계에서는 사용자가 구매한 가상 토지(LAND)에 대한 NFT 기반的所有權을保有하며, 가상 세계 내에서경제活动을 벌일 수 있다. 이러한 가상 경제는 현실 경제와 연결되어 진정한 의미의 가상-현실 통합(Virtual-Real Integration)을实现한다.

### [[033_defi_decentralized_finance|DeFi]]([[010_decentralization|탈중앙화]] 금융) 실무

[[033_defi_decentralized_finance|DeFi]](Decentralized Finance)는 Web 3.0의 가장成熟한应用分野이다. MakerDAO는 담보물로 안정적인 스테이블코인(DAI)을 발행하는 [[010_decentralization|탈중앙화]] 프로토콜이다. 사용자는 이더리움([[118_eth|ETH]]) 등을 예치하고 DAI를 차입(借入)함으로써 유동성을確保한다. Aave는 [[010_decentralization|탈중앙화]] 대출 플랫폼으로, 사용자가 자산을 예치하면 다른 사용자가 이를 차입하고 이자를 지불하는 구조이다. 전통 금융기관의介在을 Eliminates하여 보다 효율적인 자본 시장의 형성이 가능해진다.

### 📢 비유 요약

Web 3.0의 실생활 적용은智能 계약서 robotと 같다. 집을 매도할 때 전통 방식으로는 중개보수(매도가의 4~6%)를不動産중개소에 지불해야 한다. [[022_smart_contract|스마트 컨트랙트]]를活用하면 매도 조건이 충족되면 자동으로 소유권이 이전되고, 중개자 비용이ゼロ가 된다. 모든 거래 기록은区块链에영구히保存되어 뒤집을 수 없다.

## Ⅳ. 품질 관리 및 테스트 (Quality & Testing)

### [[022_smart_contract|스마트 컨트랙트]] 보안审计

Web 3.0 환경에서品質管理의 가장 중요한 영역은 [[022_smart_contract|스마트 컨트랙트]]의セキュリティである。2016년 The [[054_dao_decentralized_autonomous_organization|DAO]] 해킹 사건에서는 [[022_smart_contract|스마트 컨트랙트]]의 재진입([[056_smart_contract_vulnerability_reentrancy|Re-entrancy]]) 취약점이 악용되어 6,000만 달러 규모의 이더리가 도난당하였다.因此, [[022_smart_contract|스마트 컨트랙트]]는形式検証([[093_smart_contract_formal_verification|Formal Verification]]), コード审计([[082_process_memory_structure|Code]] [[363_audit|Audit]]), [[680_bug_bounty|버그 바운티]]([[680_bug_bounty|Bug Bounty]]) 프로그램 등을 통해多層적으로 안전성을 [[395_verification_process_review|검증]]해야 한다. 대표적으로 Certora, Mythril, Slither 등의 도구가活用된다.

### [[032_dapp_decentralized_application|DApp]] [[282_performance_tactics|성능]] 지표

DApp의 [[282_performance_tactics|성능]]을 평가하는 주요 지표로는 TPS(Transactions Per Second), 완결성([[065_consensus_finality_probabilistic_deterministic|Finality]]) 시간,[[024_gas|Gas]] 비용 등이 있다. 현재 이더리움 메인넷은 약 15~30 TPS 수준으로, 비자( Visa)의 65,000 TPS에 비해 현저히 낮다. 레이어 2(Layer 2) 솔루션인 [[042_rollup_l2_solution|롤업]]([[042_rollup_l2_solution|Rollup]]) 기술은 이를 극복하기 위해 개발되었으며, 옵티미스틱 [[042_rollup_l2_solution|롤업]](Optimistic [[042_rollup_l2_solution|Rollup]])은 약 4,500 TPS, ZK [[042_rollup_l2_solution|롤업]](Zero-Knowledge [[042_rollup_l2_solution|Rollup]])은 약 2,000 TPS를 이론적으로 가능하다.

### 규제 및 컴플라이언스

Web 3.0의 [[010_decentralization|탈중앙화]] 특성으로 인해 규제 당국은 새로운 도전에 직면하고 있다. 가상자산사업자([[085_travel_rule_vasp_fatf|VASP]])의 자금세탁방지(AML) 규제, 토큰 판매의 증권법 적합성, NFT의 지적재산권 문제 등이 대표적인 규제 과제이다. EU의 MiCA(加密資産 시장 법안)는 이러한 Web 3.0 규제의代表的な事例이다.

### 📢 비유 요약

Web 3.0의 품질 관리는航空기의多重安全システムと似ている. 엔진이故障해도 다른 엔진으로 비상 착륙할 수 있으며, 조종실에서 자동으로 제공하는 정보 외에도 조종사가직접 계기판을 확인한다. [[022_smart_contract|스마트 컨트랙트]]의审计는 항공기의 출고 전 검사항목과 같으며, 정기적인.check-ups이 필수이다.

## Ⅴ. 최신 트렌드 및 결론 (Trends & Conclusion)

### Web 3.0의 현재 동향

2024년 현재 Web 3.0은 아직 [[459_quic_fec_forward_error_correction|초기]] 단계에 있으며, 기술적 한계(확장성, 사용자 경험)와 규제 불확실성이 주요 걸림돌로 작용하고 있다. 그러나 레이어 2 솔루션의 발전으로 거래 비용([[024_gas|Gas]] Fee)이 크게 낮아지고, [[087_account_abstraction_erc_4337|계정 추상화]](Account [[198_abstraction_control_data_process|Abstraction]], ERC-4337)를 통해 일반 사용자도 쉽게 사용할 수 있는 환경이 조성되고 있다. [[086_multisig_wallet_n_of_m|지갑 멀티시그]](Multi-Sig) 기술과 소셜 [[658_ir_recovery|복구]](Social [[658_ir_recovery|Recovery]]) 기능의 도입으로 사용자의 자산 안전성이 강화되고 있다.

### AI와 Web 3.0의 융합

 [[231_ai_turing_test|인공지능]]([[190_ai_llm_requirements_specification|AI]])과 Web 3.0의融合は、新しい分野を開いている。 [[190_ai_llm_requirements_specification|AI]] 알고리즘을 활용하여 [[022_smart_contract|스마트 컨트랙트]]의脆弱점을 자동으로 탐지하거나, 개인화된 [[010_decentralization|탈중앙화]] 금융([[033_defi_decentralized_finance|DeFi]]) [[090_service_kubernetes_network_load_balancing|서비스]]를 제공하는 등의試みが进行中이다. 또한区块链技术를 활용하여 [[190_ai_llm_requirements_specification|AI]] 학습 [[001_dikw_pyramid|데이터]]의 출처를透明하게 기록하고, [[190_ai_llm_requirements_specification|AI]] 생성물의 [[583_ai_code_license_security_threats|저작권]] 문제를解決하려는 시도도 이루어지고 있다.

### 📢 비유 요약

Web 3.0의 현재 단계는互联网의 1990년대로 비유할 수 있다. 당시에는了一般인들이 인터넷을 사용하기 어려웠으며, 기술에精通한少수의 사람들이 주로利用했다. 그러나 随着时间的推移、기술이 성숙하고 사용자가 증가하면 서，慢慢히主流가 될 것이다. Web 3.0도 마찬가지로 현재의 어려움을 극복하고未来的에는より많은人々に利用される 인터넷基盤となる 것이다。

### 결론

Web 3.0은 인터넷의根本적 변혁을 代表한다. 중앙화된 플랫폼에의한 [[001_dikw_pyramid|데이터]] 독점에서脱し, 사용자가 자신의 [[001_dikw_pyramid|데이터]]와 자산의 주인이 되는 패러다임으로 전환하는 것이다. 아직 기술적 성숙과 규제 정합성 측면에서 해결해야 할課題가 남아있지만, 그潜在력은巨大하다. Web 3.0은 단순한 기술의进化이 아니라, 인터넷의본질적 가치관에 대한再定義라고 할 수 있다.
