## 핵심 인사이트 (3줄 요약)

> 1. **본질**: ERC-1155는 한 계약에서 여러 토큰 종류를 동시에 다루는 멀티 토큰 표준이다.
> 2. **가치**: FT와 NFT를 함께 다루고 배치 전송이 가능해 효율적이다.
> 3. **판단**: 게임 아이템처럼 대량/다종 자산에 특히 유리하다.

---

## Ⅰ. 개요 및 필요성

ERC-20과 ERC-721을 따로 쓰면 비효율적일 수 있다. ERC-1155는 이를 통합한다.

그래서 게임 자산에 잘 맞는다.

- **📢 섹션 요약 비유**: 한 상자에 여러 종류 장난감을 함께 넣는 것이다.

---

## Ⅱ. 아키텍처 및 핵심 원리

```text
Single Contract
  ↓
FT + NFT
  ↓
Batch Transfer
```

| 항목 | 의미 |
| :-- | :-- |
| Multi Token | 다중 토큰 |
| Batch Transfer | 묶음 전송 |
| URI | [[012_metadata|메타데이터]] |

ERC-1155는 여러 토큰을 하나의 스마트 컨트랙트로 관리해 운영 효율을 높인다.

- **📢 섹션 요약 비유**: 여러 장난감을 한 통에 넣고 한 번에 옮기는 것이다.

---

## Ⅲ. 비교 및 연결

| 표준 | 특징 |
| :-- | :-- |
| [[072_erc_20_fungible_token_standard|ERC-20]] | 대체 가능 |
| ERC-721 | 대체 불가 |
| ERC-1155 | 다중 토큰 |

| 장점 | 의미 |
| :-- | :-- |
| Efficiency | 효율 |
| Flexibility | 유연성 |

ERC-1155는 게임 아이템, 배지, 토큰 묶음 등에 유리하다.

- **📢 섹션 요약 비유**: 동전과 카드 게임 아이템을 한 상자에 같이 담는다.

## Ⅳ. 실무 적용 및 기술사 판단

### [[435_checklist_based_testing|체크리스트]]

1. 다중 토큰이 필요한가?
2. 배치 전송이 유리한가?
3. FT/NFT를 같이 쓰는가?
4. [[012_metadata|메타데이터]] 관리가 있는가?
5. 게임/아이템에 맞는가?

### [[128_water_scrum_fall_anti_pattern|안티패턴]]

- ERC-1155를 [[072_erc_20_fungible_token_standard|ERC-20]] 대체로만 보는 설계
- NFT와 FT를 분리해야 할 때 무조건 합치는 설계
- 배치 전송 이점을 무시하는 설계
- 자산 유형을 혼동하는 설계

기술사 관점에서는 ERC-1155를 "멀티 토큰 표준"으로 설명해야 한다.

- **📢 섹션 요약 비유**: 여러 장난감을 한 번에 다루는 만능 상자다.

## Ⅴ. 기대효과 및 결론

ERC-1155는 멀티 토큰 운영 효율을 높인다.

결론적으로 ERC-1155는 NFT와 FT를 함께 다룰 수 있는 다중 토큰 표준이다.

- **📢 섹션 요약 비유**: 여러 종류 토큰을 한 번에 다루는 규격이다.
