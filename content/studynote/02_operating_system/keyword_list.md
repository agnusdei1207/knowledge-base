# [운영체제](/studynote/02_operating_system/01_overview_architecture/001_operating_system_purpose/) 심화 키워드 목록 (기술사 최적화 800제)

정보관리기술사, 컴퓨터응용시스템기술사 시험에 가장 적합한 범위로 엄선한 800여 개의 [운영체제](/studynote/02_operating_system/01_overview_architecture/001_operating_system_purpose/) 핵심 및 심화 키워드입니다.

기본적인 프로세스/메모리 관리를 넘어 <strong>최신 <a href="/studynote/02_operating_system/01_overview_architecture/022_kernel_role/">커널</a> 아키텍처, <a href="/studynote/05_database/07_exam_summary/430_index_fast_full_scan/">병렬</a> 처리 및 <a href="/studynote/02_operating_system/03_cpu_scheduling/212_synchronization_mechanisms/">동기화</a> 심화, <a href="/studynote/08_algorithm_stats/08_stats/136_variance/">분산</a> OS, <a href="/studynote/13_cloud_architecture/01_virtualization/015_virtualization/">가상화</a>/<a href="/studynote/04_software_engineering/09_cloud_native_ai_architecture/561_container_based_deployment/">컨테이너</a> 시스템, 실시간 <a href="/studynote/02_operating_system/01_overview_architecture/001_operating_system_purpose/">운영체제</a>(RTOS), 모바일/임베디드 OS, 그리고 시스템 보안 및 <a href="/studynote/04_software_engineering/05_devops_ci_cd/282_performance_tactics/">성능</a> 튜닝</strong>에 초점을 맞추어 전면 재구성하였습니다.
