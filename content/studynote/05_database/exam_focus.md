## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 데이터베이스는 무결성, 동시성, 복구, 확장성을 동시에 설계하는 시스템 응용의 핵심 저장 계층이다.
> 2. **가치**: 트랜잭션과 인덱스, 분산 데이터 처리까지 설명할 수 있어야 서비스 안정성 답안이 단단해진다.
> 3. **판단 포인트**: 데이터 인공지능(DB AI), 벡터 데이터베이스(Vector Database), 분산 일관성까지 연결해야 최신성이 확보된다.

## Ⅱ. 왜 시험 핵심인가

- 대부분의 업무 시스템은 결국 데이터 정합성과 성능 문제로 귀결되므로 데이터베이스는 실무형 기술사 문제의 빈출 축이다.
- 단답형은 정규화, 인덱스, 트랜잭션, 분산 저장소 용어를 빠르게 구분해야 하고, 서술형은 장애 복구와 성능 튜닝이 핵심이다.
- 데이터 웨어하우스(DW), 온라인 분석 처리(OLAP), NoSQL, NewSQL까지 범위가 넓어 최신 플랫폼과 연계 출제가 쉽다.
- 컴퓨터시스템응용기술사 관점에서는 저장 구조보다 서비스 가용성과 운영 전략까지 답안에 녹여야 한다.

## Ⅳ. 단답형 / 서술형 분리 포인트

- 단답형: 정규형, 조인(Join), 인덱스, 격리수준(Isolation Level), 다중 버전 동시성 제어(MVCC) 정의와 차이 정리
- 서술형: 성능 저하 원인, 잠금 경합, 장애 복구, 샤딩(Sharding), 일관성 모델 선택 근거를 비교형으로 설명
- 답안 기준: "데이터 모델 → 처리 엔진 → 동시성/복구 → 확장 전략 → 적용 사례" 순서가 채점 친화적이다.

## Ⅴ. 최신 기술 동향 연결

- 데이터 인공지능(DB AI): 자연어 질의, 자율 튜닝, 인공지능 기반 옵티마이저
- 신규 저장 구조: 벡터 데이터베이스, 레이크하우스(Lakehouse), 오픈 테이블 포맷(Iceberg/Delta)
- 분산 처리: 클라우드 네이티브 데이터베이스, 서버리스 데이터베이스, 멀티리전 복제
- 보안/거버넌스: 동형암호(Homomorphic Encryption), 데이터 마스킹, 데이터 패브릭(Data Fabric)
