# 557. IT 경영 관리 핵심 토픽 557번 시험 요약 (IT Management Core Topic 557 Exam Summary)

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 정보화 사업의 계획-수행-운영-평가 전 생애주기(SDLC + 운영단계)를 IT 거버넌스(COBIT 2019), IT 서비스 관리(ITIL 4), 프로젝트 관리(PMBOK 7th/PMBOK Guide) 프레임워크로 통합하여, 전략-전술-운영 3계층의 정렬(Strategic Alignment)을 달성하는 경영관리 체계
> 2. **가치**: IT 투자 대비 ROI 15~30% 향상, 정보화 사업 실패율 30%->10% 이하 감소, SLA 준수율 95% 이상 달성, COBIT Maturity Level 평균 2.5->3.5 상승을 통한 통제환경 강화
> 3. **판단 포인트**: 중앙집중형(CoE: Center of Excellence) vs 분산형(Bus 모델), Build vs Run 분리, 내부 인력 유지율 vs 아웃소싱 비용 최적화(임계점 약 60%), 거버넌스-운영-Service Desk의 RACI 매트릭스 충돌 해결

---

## Ⅰ. 개요 및 필요성

IT 경영 관리는 단순한 "IT 부서 운영"을 넘어 **기업의 핵심 자산으로서의 정보기술**을 전략적으로 기획하고, 투자 효율을 극대화하며, 리스크를 통제하는 통합 관리 체계입니다. 기술사 시험에서 본 토픽은 정보화 사업의 기획부터 폐기까지의 전 과정을 **거버넌스(Governance) - 관리(Management) - 운영(Operations)** 3계층으로 분해하여 평가합니다.

### 4차 산업혁명 시대의 IT 경영 패러다임 전환

| 구분 | 기존 패러다임 (2000년대) | 신규 패러다임 (2020년대) |
| :--- | :--- | :--- |
| **관점** | IT는 비용(Cost Center) | IT는 가치 창출(Value Driver) |
| **구조** | 실리콘 밸리식 독자 운영 | BizDevOps 통합 체계 |
| **투자 기준** | 예산 대비 집행률 | OKR/KPI 기반 성과 측정 |
| **리스크 관리** | 사후 통제(Detection) | 사전 예방(Prevention) + 회복력(Resilience) |
| **기술 도입** | 워터폴(Waterfall) 한 줄 정렬 | 애자일(Agile) + 데브옵스(DevOps) + 플랫폼 엔지니어링 |
| **데이터 활용** | BI(Back-office 보고) | AI/ML 기반 의사결정 자동화 |

### 왜 IT 경영 관리가 필수적인가?

- **정보화 사업 실패 통계**: CHAOS Report(Standish Group)에 따르면 프로젝트 31%가 실패, 53%가 과다예산/지연, 성공률은 단 16%
- **규제 환경 강화**: 개인정보보호법, 정보통신망법, 클라우드컴퓨팅법, AI기본법(2026 시행), ISMS-P, ISO 27001/27701
- **투자 규모 확대**: 국내 정보화 예산 GDP 대비 약 4.5%(2023, 한국정보화진흥원), 디지털 전환(DX) 가속화
- **기술 복잡성 증가**: 멀티클라우드, 하이브리드 인프라, MSA(Microservice Architecture) 도입으로 통합 거버넌스 필요성 증대

- **📢 섹션 요약 비유**: IT 경영 관리는 마치 **도시의 종합 도시계획**과 같습니다. 건물(시스템) 하나 짓는 것이 아니라, 도로(네트워크), 상하수도(데이터 파이프라인), 소방서(보안관제), 병원(BCP), 시청(거버넌스)까지 통합적으로 설계해야 시민(사용자)이 살기 좋은 도시가 됩니다.

### COBIT 2019 5개 도메인 및 40개 관리목표 (핵심 매핑)

| 구성 요소 (도메인) | 역할 | 핵심 기술 및 동작 방식 |
| :--- | :--- | :--- |
| **EDM (Evaluate, Direct, Monitor)** | 거버넌스의 최상위 의사결정 | 5개 관리목표: 거버넌스 프레임워크 설정, 이익실현, 리스크최적화, 자원최적화, 이해관계자투명성. **RACI**: 이사회(R), IT전략위(A), CISO(C), 임원(I) |
| **APO (Align, Plan, Organize)** | 전략적 정렬 및 계획 | 14개 관리목표: 관리프레임워크, 전략, 포트폴리오, 예산, 조직, 인적자원, 관계(외부), 합의(Agreement), 서비스, 위험, 보안, 데이터, 응용프로그램, 인프라. **핵심 산출물**: ISP(정보화전략계획), IT 포트폴리오, SLA |
| **BAI (Build, Acquire, Implement)** | 솔루션의 구축 및 도입 | 11개 관리목표: 관리프레임워크, 요구사항정의, 솔루션설계, 가용성/용량, 변경, 변경수용, 인수, 구성, 자산, 인적자원, 프로젝트. **핵심 산출물**: WBS, 테스트 계획, 이행 계획서 |
| **DSS (Deliver, Service, Support)** | 서비스의 전달 및 지원 | 6개 관리목표: 운영, 서비스요청/사고, 문제, 지속성, 보안서비스, 비즈니스프로세스통제. **핵심 지표**: 가용성 99.9%, MTTR ≤ 4시간, FCR ≥ 75% |
| **MEA (Monitor, Evaluate, Assess)** | 성과 측정 및 평가 | 4개 관리목표: 성과/정합성 모니터링, 내부통제시스템, 외부요구사항준수, 목표달성. **핵심 산출물**: KPI 대시보드, 성숙도 평가 보고서 |

### IT 성과 측정의 핵심 공식 및 알고리즘

#### 1) IT 투자 수익률 (ROI) 산출

$$ROI_{IT} = \frac{\sum_{t=1}^{n} \frac{B_t - C_t}{(1+r)^t}}{\sum_{t=0}^{n} \frac{C_t}{(1+r)^t}} \times 100\%$$

- $B_t$: t년도 기대效益 (직접 + 정성적效益의 화폐화)
- $C_t$: t년도 IT 투자비 (TCO: HW + SW + 인건비 + 운영비)
- $r$: 할인율 (한국은행 기준금리 + 위험프리미엄, 통상 5.5~7%)

#### 2) IT 균형 성과 카드 (IT BSC, Norton & Kaplan 4관점)

| 관점 | 핵심 KPI | 측정 방법 |
| :--- | :--- | :--- |
| **재무(Financial)** | IT 예산 대비 ROI, IT 비용/G매출 비율 | 회계시스템 연동, Cost Allocation |
| **고객(Customer)** | 사용자 만족도(CSAT ≥ 4.0/5.0), NPS(Net Promoter Score) | 설문조사, VOC 분석 |
| **내부프로세스** | SLA 준수율(≥95%), 변경 성공률(≥98%), MTTR(≤4h) | ITSM 도구 (ServiceNow, Jira Service Management) |
| **학습/성장** | 직원 1인당 교육시간(≥40h/년), 역량숙성도(≥Level 3) | HR 시스템, 자격증 DB |

#### 3) COBIT 성숙도 모델 (5단계)

```text
Level 0 (비존재) -> 1 (초기/Ad-hoc) -> 2 (반복가능) -> 3 (정의됨) -> 4 (관리됨) -> 5 (최적화)
   없음         |   개인의존      |   기본프로세스   |   표준화됨    |   정량측정    |  지속개선
                |   Fire-fighting|   프로젝트별     |   조직공통    |   KPI기반    |  혁신/예측
                |   Hero식 대응  |   Best Practice  |   프레임워크  |   통계적통제  |  AI-Driven
```

#### 4) ITSM 핵심 지표 및 임계치

- **가용성(Availability)**: $A = \frac{MTBF}{MTBF + MTTR} \times 100\%$, Tier1 시스템 목표: 99.99% (연 52분 이내 중단)
- **사고 해결률(First Call Resolution)**: L1 Service Desk 1차 해결률 ≥ 75%
- **변경 실패율(Emergency Change Rate)**: 전체 변경 중 긴급 변경 비율 ≤ 5%
- **서비스 요청 이행시간**: 표준 요청(SR) 카탈로그 기반 자동화 처리

- **📢 섹션 요약 비유**: COBIT의 EDM-APO-BAI-DSS-MEA 5개 도메인은 마치 **자동차의 운전 시스템**과 같습니다
