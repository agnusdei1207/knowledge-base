## 핵심 인사이트 (3줄 요약)

> 1. **본질**: IT 경영 관리 핵심 토픽 728번은 **COBIT 2019 거버넌스 체계, ITIL 4 서비스 가치 시스템(SVS), TOGAF ADM, PMBOK 7th, BSC 기반 IT-Portfolio 관리**를 통합한 **IT 전략-거버넌스-운영-평가**(Strategy-Governance-Operation-Evaluation) 4축 관리 프레임워크의 종합적 이해를 요구하는 정보관리기술사 출제영역이다.
> 2. **가치**: 정량적 측면에서 **IT 투자대비성과(ROIT) 20~30% 향상**, **인시던트 MTTR 50% 단축**, **프로젝트 성공률 30%->70% 이상 개선**을 달성하며, 정성적으로는 **이사회-경영진-IT 정렬(Alignment)**, **규제 준수(Compliance)**, **디지털 전환 가속화**라는 전략적 가치를 창출한다.
> 3. **판단 포인트**: **"Build vs. Buy vs. Cloud(Public/Private/Hybrid)" 의사결정**, **"Agile vs. Waterfall vs. Hybrid(SAFe/LeSS)" 프로젝트 방법론 선택**, **"내부 통제 강화 vs. 운영 효율성"** 간의 **Risk-Return-Cost 트레이드오프**가 핵심이며, **CSF(핵심성공요인)와 KPI 측정 가능성**을 기반으로 의사결정 정당화를 제시할 수 있어야 한다.

## Ⅰ. 개요 및 필요성

정보관리기술사 728번 토픽은 **IT 경영관리**(IT Management) 영역의 종합적 이해를 평가하는 핵심 출제 범위로, 단순한 기술 지식을 넘어 **경영학 원리(Strategy, Finance, Organization)와 IT의 융합 역량**을 검증한다. 4차 산업혁명 시대의 디지털 전환(DX, Digital Transformation), 클라우드 네이티브 전환, AI/ML 기반 업무 자동화, 사이버 보안 위협의 고도화, ESG 경영 및 IT 윤리 요구 증대로 인해, IT 부서는 더 이상 **"비용 센터(Cost Center)"가 아닌 "전략적 비즈니스 파트너(Value Creator)"**로서의 역할 전환이 필수적이다.

기존의 IT 관리 패러다임은 **"기술 중심·프로젝트 단위·부서별 사일로(Silo)"** 운영이었다. 그러나 현대 IT 경영은 **"가치 중심·서비스 연속·전사적 거버넌스"** 패러다임으로 전환되었으며, 이를 위해 **COBIT 2019, ITIL 4, ISO 38500, ISO 27001, CMMI, PMBOK 7th, TOGAF** 등 글로벌 표준 프레임워크의 통합적 이해와 실무 적용 능력이 요구된다.

```text
+---------------------------------------------------------------------+
|            728번 IT 경영관리 4축 통합 프레임워크 (4-Pillar Model)   |
+---------------------------------------------------------------------+
|                                                                     |
|   [축1: IT 전략]              [축2: IT 거버넌스]                   |
|   +--------------+           +--------------+                       |
|   | • IT 전략계획|◄---------►| • COBIT 2019 |                       |
|   | • BSC/CSF    |           | • ISO 38500  |                       |
|   | • IT-Portfolio|           | • RACI 매트릭스|                      |
|   | • DX 전략    |           | • 이사회 리뷰|                       |
|   +------+-------+           +------+-------+                       |
|          |                          |                               |
|          v                          v                               |
|   [축3: IT 운영/서비스]       [축4: IT 평가/개선]                   |
|   +--------------+           +--------------+                       |
|   | • ITIL 4 SVS |◄---------►| • KPI/KGI    |                       |
|   | • SIAM       |           | • ROIT/VOI   |                       |
|   | • DevOps/SRE |           | • 벤치마킹   |                       |
|   | • AIOps      |           | • 내부감사   |                       |
|   +--------------+           +--------------+                       |
|                                                                     |
|   [기반: 아키텍처/표준/보안/리스크]                                  |
|   TOGAF ADM | Zachman | NIST CSF | ISO 27001 | ISO 22301            |
+---------------------------------------------------------------------+
```

**기존 vs. 새로운 패러다임 비교:**

| 구분 | 전통적 IT 관리 (As-Is) | 현대 IT 경영 관리 (To-Be) |
|:---|:---|:---|
| **관점** | 기술 중심 (Technology-centric) | 가치 중심 (Value-centric) |
| **조직** | 기능별 사일로 (Siloed) | 플랫폼 조직 (Platform-based) |
| **예산** | CapEx 일변도, 연초 편성 | OpEx+CapEx 혼합, 연속적 재계획 |
| **성과측정** | 가용성·처리량 | ROIT, NPS, TCO 회수기간 |
| **위험관리** | 사후 대응 (Reactive) | 사전 식별·정량 평가 (Proactive) |
| **거버넌스** | CIO 독단 | 이사회-경영진-IT 3자 정렬 |
| **방법론** | 폭포수(Waterfall) | 애자일/하이브리드(SAFe, LeSS) |
| **인프라** | 온프레미스 | 하이브리드/멀티클라우드 |

- **📢 섹션 요약 비유**: IT 경영관리는 마치 **"오케스트라의 지휘자"**와 같다. 다양한 악기(부서·기술·프로세스)가 각자의 음(데이터·서비스)을 연주하지만, 지휘자(거버넌스)가 없으면 불협화음만 나고, 결국 **"하나의 아름다운 symphony(가치 창출)"**로 통합되지 못한다. 728번 토픽은 바로 이 **"지휘법(Governance)"**을 묻는 시험이다.

## Ⅱ. 아키텍처 및 핵심 원리

### 1) COBIT 2019 거버넌스 시스템 (Governance System)

COBIT 2019는 **EDM(평가·지휘·모니터)** + **APO·BAI·DSS·MEA** 5개 도메인, **40개 관리 목표(Management Objective)**로 구성된 IT 거버넌스의 **사실상 표준(De-facto Standard)**이다.

```text
+------------------------------------------------------------------+
|              COBIT 2019 거버넌스 & 관리 체계 (Cascade)           |
+------------------------------------------------------------------+
|                                                                  |
|  [Stakeholder Needs & Drivers]                                   |
|            |  --► (1단계) Translates to                           |
|            v                                                      |
|  [Enterprise Goals : 13개] --► (2단계) --► [Alignment Goals : 13개]|
|            |                                                      |
|            v (3단계 Cascade)                                      |
|  +----------------------------------------------------------+    |
|  |   Governance Objectives (5 EDM) + Management Objectives  |    |
|  |   +-----+  +-----+  +-----+  +-----+  +-----+           |    |
|  |   | EDM |  | APO |  | BAI |  | DSS |  | MEA |           |    |
|  |   |평가·|  |정렬·|  |구축·|  |서비스|  |모니터|           |    |
|  |   |지휘·|  |계획·|  |실행·|  |전달·|  |평가·|           |    |
|  |   |모니|  |조직|  | |  |지원|  |내부|           |    |
|  |   |터 |  |     |  |     |  |     |  |감사 |           |    |
|  |   +--+--+  +--+--+  +--+--+  +--+--+  +--+--+           |    |
|  |      |        |        |        |        |                |    |
|  |      +--------+--------+--------+--------+                |    |
|  |              v                                             |    |
|  |      [Components: 7가지 - 원칙, 정책, 프로세스, 조직,     |    |
|  |       정보, 인력, 기술, 문화(CMMI 7대 영역)]              |    |
|  +----------------------------------------------------------+    |
|            |                                                      |
|            v                                                      |
|  [Capability/Maturity Level 0~5] (Process Assessment Model PAM)  |
|                                                                  |
+------------------------------------------------------------------+
```

**COBIT 2019 5개 도메인 40개 프로세스 상세:**

| 도메인 | 핵심 영역 | 대표 프로세스 | 실무 적용 포인트 |
|:---|:---|:---|:---|
| **EDM** (평가·지휘·모니터) | 이사회 레벨 거버넌스 | EDM01(거버넌스 프레임워크), EDM02(가치 전달), EDM03(리스크 최적화), EDM04(자원 최적화), EDM05(이해관계자 투명성) | 분기 1회 거버넌스 위원회 개최, RACI 매트릭스 작성 |
| **APO** (정렬·계획·조직) | 전략->전환 | APO01(전략 관리), APO02(전략 매핑), APO04(혁신), APO05(포트폴리오), APO12(리스크 관리), APO13(보안 관리) | 연 1회 전략 리프레시, ROI/NPV 분석 |
| **BAI** (구축·실행) | 프로그램/프로젝트/변경 | BAI01(프로그램), BAI02(요구사항), BAI03(솔루션 설계), BAI11(프로젝트 관리) | PMO 운영, 단계별 Gate Review |
| **DSS** (서비스·지원·운영) | 일상의 IT 운영 | DSS01(운영), DSS02(인시던트/요청), DSS03(문제), DSS05(보안 운영), DSS06(비즈니스 연속성) | ITIL 4와 직접 매핑, SRE/DevOps 연계 |
| **MEA** (모니터·평가·감사) | 측정과 개선 | MEA01(성과/콘폼), MEA02(내부 통제), MEA03(규제 준수), MEA04(내부 감사) | KPI 대시보드, ISMS 인증 심사 |

### 2) ITIL 4 서비스 가치 시스템 (SVS, Service Value System)

ITIL 4는 **"서비스 가치 공동창조(Value Co-creation)"** 관점에서 7개 지침 원리(Guiding Principles), **34개 실천(34 Practices), SVS(Service Value System), 4차원 모델(4 Dimensions)**로 구성된다.

```text
+------------------------------------------------------------------+
|                ITIL 4 Service Value System (SVS)                 |
+------------------------------------------------------------------+
|                                                                  |
|  [Opportunity/Demand] --► [Value]  ◄-- [Value] ◄--[Waste]        |
|                                  ^                                |
|                                  |                                |
|  +-------------------------------+--------------------------+   |
|  |  Guiding Principles (7)                                    |   |
|  |  ① 가치 집중 ② 현재 상태에서 시작 ③ 진행하며 반복 진행    |   |
|  |  ④ 협력 및 가시성 촉진 ⑤ 사고방식 및 작업방식 종합        |   |
|  |  ⑥ 단순성 유지 및 실용적 ⑦ 최적화 및 자동화                |   |
|  +----------------------------------------------------------+   |
|                                  |                                |
|                                  v                                |
|  +----------------------------------------------------------+   |
|  |  Governance  ►  Practices (34)  ►  Continual Improvement  |   |
|  |                +------------------------+                   |   |
|  |                | General Mgmt (14)     |                   |   |
|  |                | Service Mgmt (17)     |                   |   |
|  |                | Technical Mgmt (3)    |                   |   |
|  |                +------------------------+                   |   |
|  +----------------------------------------------------------+   |
|                                  |                                |
|                                  v                                |
|  +----------------------------------------------------------+   |
|  |  Value Chain Activities (6):                               |   |
|  |  Plan->Improve->Engage->Design&Transition->Obtain/Build       |   |
|  |  ->Deliver&Support                                          |   |
|  +----------------------------------------------------------+   |
|                                  |                                |
|         4 Dimensions: Organizations & People | Information &     |
|           Technology | Partners & Suppliers | Value Streams      |
|                                  |                                |
|                                  v                                |
|                    [Service Value: 유틸리티×보증×중요도]          |
+------------------------------------------------------------------+
```
