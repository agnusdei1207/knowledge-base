## 핵심 인사이트 (3줄 요약)

> 1. **본질**: IT 경영 관리 610번 토픽은 **IT 거버넌스–전략–사업관리–성과측정–위험관리**를 하나의 가치사슬(Value Chain)로 통합한 프레임워크로, COBIT 2019(거버넌스·관리 목표 40개), PMBOK 7th(8대 성과영역), ISO 38500(6원칙), BSC(4관점) 등 글로벌 표준을 발주자 관점에서 재해석하는 것이 핵심이다.
> 2. **가치**: 체계적 적용 시 **SW사업 실패율 53%->29% 감소**(Standish Group CHAOS Report 2023 기준), 정보화 사업비 15~25% 절감, 감사·감리 적격 판정률 90% 이상 확보, ISO/IEC 20000·27001·38500 다중 인증 동시 충족을 통한 글로벌 경쟁력 제고 효과가 검증되어 있다.
> 3. **판단 포인트**: 기술사 답안 작성 시 **① 거버넌스 체계(Board–Steering–PMO 3계층) ② 사업 추진 단계(요구사항–설계–구축–안정화)별 관리 포인트 ③ EA–BA–DA 3축 정합성 ④ 정량 KPI(ROI, NPV, IRR, TCO, Payback Period) 도출 ⑤ SLA/OLA/UC 3단계 서비스 계약 구조**를 반드시 포함하여, 단순 암기가 아닌 **상황 판단형 서술**으로 구성해야 고득점이 가능하다.

## Ⅰ. 개요 및 필요성

정보시스템의 대규모화·복합화 및 디지털 전환(DX) 가속화에 따라, 발주자 관점의 IT 경영 역량은 단순 기술 도입을 넘어 **전략적 포트폴리오 관리·위험 통제·가치 실현**으로 무게중심이 이동하고 있다. 과거(1990~2000년대)에는 하드웨어·소프트웨어 단위 도입과 기능 중심의 시스템 개발이 주를 이루었으나, 클라우드·AI·데이터 기반 서비스로 패러다임이 전환됨에 따라, IT 투자의 70% 이상이 운영·유지보수 단계에서 누수되고 있는 현실(가트너 2023)에서 **IT 경영 관리의 표준화·체계화**는 더 이상 선택이 아닌 필수 생존 전략이다.

기존 패러다임과 신규 패러다임의 핵심 차이는 다음과 같다:

- **기존(Old)**: 기능 단위 개발 -> 부서별 silos -> 기술 중심 의사결정 -> 사후 통제
- **신규(New)**: 서비스·플랫폼 단위 -> 엔터프라이즈 통합 -> 가치·위험 균형 의사결정 -> 실시간 거버넌스

특히 **「발주자 관점의 SW사업 관리 가이드라인」(2023 개정, NIPA)** 은 4대 영역(사업 계획, 발주, 계약, 관리) × 12개 절차 × 87개 점검항목으로 체계화되어 있으며, 기술사 시험에서 거의 매년 출제되는 핵심 토픽이다.

- **📢 섹션 요약 비유**: IT 경영 관리는 마치 **도시의 종합 건설·운영 마스터플랜**과 같다. 한 채의 집(프로젝트)만 짓는 게 아니라, 상하수도(데이터)·도로(네트워크)·전기(클라우드)·치안(보안)·공원(서비스)까지 도시 전체의 설계도를 그리고, 예산·법규·시민 만족도를 동시에 관리하는 **"스마트시티 청사진"** 이 핵심이다.

## Ⅱ. 아키텍처 및 핵심 원리

IT 경영 관리 610번의 4대 아키텍처 계층은 **① 거버넌스 ② 프로세스 ③ 측정 ④ 통제**로 구성되며, 각 계층은 상호 의존적이다.

```text
[3계층 의사결정 체계 및 정보 흐름]

  +------------------- 거버넌스 계층 -------------------+
  |  +--------------------------------------------+     |
  |  |  이사회/IT전략위원회 (Board/SteerCo)        |     |
  |  |  - 역할: 방향 결정, 의지·자원 배분, 모니터 |     |
  |  |  - 주기: 분기 1회 + 수시                   |     |
  |  +--------------+-----------------------------+     |
  |                 v (의사결정·예산 승인)              |
  |  +--------------------------------------------+     |
  |  |  CIO/CTO (전사 IT 리더십)                  |     |
  |  |  - 역할: 전략 수립, 포트폴리오 우선순위     |     |
  |  +--------------+-----------------------------+     |
  |                 v (전략·표준·가이드)                |
  |  +--------------------------------------------+     |
  |  |  PMO (Program/Project Management Office)   |     |
  |  |  - 역할: 다수 프로젝트 통합 관리, Risk Pool |     |
  |  +--------------+-----------------------------+     |
  +-----------------+----------------------------------+
                    v
  +----------- 실행 계층 (Process) -----------+
  |  사업기획 -> 발주 -> 입찰/계약 -> 설계 -> 구축 -> 테스트 -> 이행 -> 운영
  |   ^                                          |
  |   +-- 감리(별도 4-Eye Principle) <-----------+
  +--------------+----------------------------+
                 v (KPI, 산출물, 이슈)
  +----------- 통제 계층 (Control) -----------+
  |  +----------+  +----------+  +----------+  |
  |  |품질(QMS) |  |정보보호  |  |재무/감사 |  |
  |  |ISO 9001  |  |ISO 27001|  |IS Audit  |  |
  |  +----------+  +----------+  +----------+  |
  +--------------------------------------------+
```

| 구성 요소 | 역할 | 핵심 기술 및 동작 방식 |
|:---|:---|:---|
| **이사회/IT전략위원회** | IT 거버넌스의 최고 의사결정 기구 | ISO 38500 6원칙 적용, **RACI 매트릭스**로 역할 분담, COBIT EDM 5개 프로세스(EDM01 Ensure Governance Framework Setting & Maintenance 등) 운영 |
| **CIO/CTO + EA 거버넌스** | 전략-아키텍처 정합성 확보 | **TOGAF ADM(Architecture Development Method)** 8단계(Phase A~H), **FEAF(联邦 EA Framework)**, **DoDAF** 8뷰(AV·OV·SV·TV·DIV·StV·SvcV·AllV) 활용 |
| **PMO (전사/사업부/프로젝트 3유형)** | 다수 프로젝트 통합 관리·조정 | **P3O(Portfolio, Programme, Project Office)** 모델, **Earned Value Management(EVM)** 활용 CPI·SPI 산출, **PMBOK 7th** 8대 성과영역(Stakeholder·Team·Development Approach·Planning·Project Work·Delivery·Measurement·Uncertainty) |
| **감리 기구 (제3자 검증)** | 사업의 객관적 품질·위험 검증 | **정보시스템 감리법**에 따라 **일반감리·상시감리·정기감리** 구분, **감리원 등급**(특급·고급·중급·초급), **CCB(Change Control Board)** 운영 |
| **성과 측정 체계(BSC+KPI)** | 전략 목표의 정량화·모니터링 | **IT-BSC** 4관점 + **CSF(핵심성공요인)** + **KPI** 연계, **OKR(Objectives & Key Results)** 병행, **CFR(Cause-Effect-Flow) 도식화** |
| **위험·서비스·보안 통제** | IT 운영의 지속성 확보 | **ISO 31000** 리스크 관리 프로세스(Establish Context->Risk Assessment->Treatment->Monitoring), **ISO 27001** 93개 통제 항목, **ITIL 4** 34개 Practice (General·Service·Technical Management) |
| **사업비 산정·계약 관리** | 예산 통제 및 적정 계약 체결 | **기능점수(Function Point)·LOC·COCOMO II·SLIM** 교차 검증, **FFP·T&M·CPFF·Unit Price** 4대 계약 유형, **EVM** 기반 진도·원가 통합 관리 |
| **변화 관리(Change Management)** | 조직·문화 전환 촉진 | **Kotter 8단계 모델**, **ADKAR(Awareness·Desire·Knowledge·Ability·Reinforcement)**, **PROSCI 3-Phase Process** 적용 |

### 핵심 원리 심화

**1) IT 거버넌스 3대 메커니즘**
- **결정(Decision)**: 원칙·정책·표준 수립
- **조정(Alignment)**: 전략↔아키텍처↔사업 정합성
- **통제(Control)**: 성과·위험·규정준수 모니터링

**2) 사업비 산정 공식 (COCOMO II)**
$$E = a \times (KLOC)^{b} \times \prod_{i=1}^{17} EM_i$$
- E = 노력(인월), KLOC = 천 라인 수, EM = Effort Multiplier 17개
- 베이스형: a=2.94, b=1.12 / 임베디드: a=3.6, b=1.20

**3) EVM 핵심 지표**
- **CPI(원가绩效지수) = EV / AC** (≥1 양호)
- **SPI(일정绩效지수) = EV / PV** (≥1 양호)
- **EAC(추정완료비용) = BAC / CPI**
- **VAC(완료편차) = BAC − EAC**
