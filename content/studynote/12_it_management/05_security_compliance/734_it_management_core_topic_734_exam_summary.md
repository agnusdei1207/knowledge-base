# 734. IT 경영 관리 핵심 토픽 — 정보시스템 감리·IT 거버넌스·서비스 관리 통합 프레임워크

---

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 정보시스템의 **Value Creation(가치창출)** 을 위해 **거버넌스(Evaluate·Direct·Monitor) -> 관리(Plan·Build·Run) -> 감리(Assurance)** 의 3-Layer 통합 제어 체계와, **COBIT 2019 · ITIL 4 · ISO 38500 · PMBOK 7th** 4대 프레임워크의 상호 매핑을 통해 **End-to-End 정합성** 을 확보하는 것이 734번(정보관리기술사)의 핵심
> 2. **가치**: 성숙도 Level 1->Level 5 도달 시 **정보시스템 장애율 73% 감소(McKinsey 2023)**, **IT 예산 대비 ROI 1.8배 향상(Gartner 2024)**, **컴플라이언스 위반 리스크 노출 65% 절감(ISO 38500 적용 기업 평균)**, **감리 적격 부적정 비율 38%->6%로 개선** 등 정량적 임팩트 도출
> 3. **판단 포인트**: ① **In-House Build vs 패키지 도입 vs SaaS** 시 **TCO(3~5년)** 와 **Lock-in 위험도** ② **내부감사 vs 외부감리 vs 준법감시** 의 독립성·책임성·효과성 Trade-off ③ **Agile/DevOps 환경** 에서 전통적 Waterfall 감리 절차(문서중심)의 재설계 필요성 ④ **AI 거버넌스·ESG 정보공시·클라우드 책임분담 모델** 등 신규 통제영역 식별

---

## Ⅰ. 개요 및 필요성

### 1.1 시대적 배경과 도전 과제

2024년 현재, 전 세계 IT 지출은 **약 5조 USD(Gartner 2024)** 규모로 GDP 대비 비중이 지속적으로 확대되고 있으며, 기업의 **디지털 전환(DX)** 투자는 전년 대비 **16.3% 성장** 하였습니다. 그러나 한국정보화진흥원(KIAT)의 '2024년 기업 IT 성숙도 조사'에 따르면 국내 중견기업 중 **단 12.4%** 만이 IT 거버넌스 체계(Level 4 이상)를 보유하고 있으며, **정보시스템 감리 적격 판정 비율은 약 62%** 로 정체되어 있습니다. 이로 인해 발생하는 **프로젝트 실패 손실(연간 약 8.7조 원)**, **정보유출 사고(2023년 1,968만 건)**, **컴플라이언스 위반 과징금(금융권 평균 127억 원)** 등의 문제가 사회적 비용으로 직결되고 있습니다.

734번(정보관리기술사) 시험은 단순히 특정 표준의 암기를 평가하는 것이 아니라, **"어떤 통제(Control)가 어느 시점에 누구에 의해 어떻게 운영되어야 하는가"** 에 대한 **End-to-End 통찰력** 을 평가합니다.

### 1.3 왜 IT 경영 관리가 필수인가

- **규제 요구 강화**: 개인정보보호법, 정보통신망법, 전자금융거래법, 클라우드컴퓨팅법, ESG 공시(2025년 1단계), AI기본법(2026년 시행), DORA(유럽 2025.1) 등 **규제 복잡도 4.2배 증가** (한국법제연구원)
- **사이버 위협 고도화**: 랜섬웨어 공격 **연평균 28% 증가**, **공급망 공격(SolarWinds·3CX·MOVEit)·제로데이** 위협으로 1차 vendor가 아닌 N차 협력사 통제 필요
- **이해관계자 다변화**: 주주·이사회·고객·Fintech·정부·시민사회 등 **8개 이해관계자 그룹** 별 상이한 정보 요구 발생
- **Agile/DevOps 가속화**: 릴리즈 주기 6개월->2주로 단축, 전통적 Waterfall 감리 절차(문서 중심)로는 **"사후 통제" 불가능** -> **"예방 통제 + 자동화 통제"** 패러다임 전환

- **📢 섹션 요약 비유**: 🏥 **종합병원 진료 시스템** 에 비유할 수 있습니다. 환자의 건강(기업의 IT 자산)을 위해 ①**진단(감사)**, ②**처방(거버넌스)**, ③**수술·회복(운영)**, ④**재활·건강관리(지속적 개선)** 가 동시에 이뤄져야 하며, 어느 하나라도 빠지면 **"골든아워"** 를 놓쳐 손실이 기하급수적으로 증가합니다.

## Ⅱ. 아키텍처 및 핵심 원리

```text
+--------------------------------------------------------------------------+
|                    [Layer 1] IT 거버넌스 (Governance)                    |

|  +------------------------------------------------------------------+    |

|  |   • 전략 정렬도    • 의사결정 권한    • KPI 대시보드               |    |
|  |   • 리스크 식별    • 자원 배분        • 이사회 보고                |    |

+--------------------------------------------------------------------------+
|                    [Layer 2] IT 관리 (Management)                         |

|  |  [3 Lines of Defense Model]                                       |    |
```

### 2.2 핵심 프레임워크 상세 구조

| 구성 요소 | 역할 | 핵심 기술 및 동작 방식 |
| :--- | :--- | :--- |
| **COBIT 2019** (40 Governance/Management Objectives) | IT 거버넌스·관리 목표의 **End-to-End 통합 체계** | **EDM(5개)·APO(14)·BAI(11)·DSS(6)·MEA(4)** 의 5개 도메인 / 40개 목표 / **7개 컴포넌트(원리·정책·구조·프로세스·정보·문화·인력·기술) 매트릭스** / **Focus Area**(예: DevOps, Risk, Cybersecurity) 커스터마이징 / **Design Factors 11개** 로 조직별 1~3단계 단계별 적용 |
| **ITIL 4** (Service Value System) | IT 서비스의 **가치공급(Value Co-Creation)** 체계 | **SVS(서비스가치시스템)**: Opportunity/Demand -> Value -> Purpose/Organization -> 7 Guiding Principles -> Governance -> **Service Value Chain(Plan->Engage->Design->Obtain->Build->Deliver->Support)** -> Continual Improvement / **34 Practices**(4차원 모델: 조직·정보·기술·파트너·가치흐름·역량) |
| **ISO/IEC 38500:2015** | 이사회 수준의 **IT 거버넌스 국제표준** | **3개 원칙**: 책임(R)·전략(S)·취득(A)·성능(P)·준거(C)·인간거동(H) / **6개 거버넌스 모델**: E-D-M 사이클 / 적용 시 **국가별 조화**(한국: 전자정부법·클컴법·정통망법) 필요 |
| **PMBOK 7th (2021)** | 프로젝트·프로그래임·포트폴리오 관리 | **8개 Performance Domains**(팀·개발방식·계획·프로젝트작업·딜리버리·측정·불확실성·운영) / **12개 Principles** / **Value Delivery System** / 기존 Process-based -> **Principle-based 전환** / 기존 5 Process Groups + 10 KA -> **8 PD + 12 P** 구조 |
| **정보시스템 감리** (감리법 §14·대통령령) | 국가·공공기관의 **중요 정보시스템** 적격성 평가 | **3단계**: 계획(감리계획·위험평가) -> 착수(자료요청·현장확인·시연) -> 보고(적격/조건부적격/부적격) / **감리 기준 13개 분야 196개 항목**(계획·요구사항·설계·구현·시험·이행·운영·보안·개인정보·데이터·성능·可用성·변경관리) / **방법론**: STARR(Selection·Testing·Assessment·Reporting·Resolution) |
| **3 Lines of Defense (IIA)** | 조직 내 **리스크 관리 책임 분배 모델** | 1st Line: 사업·운영 자기통제(95%) / 2nd Line: 리스크·컴플·CISO·CIO(4%) / 3rd Line: 내부감사(독립적 Assurance)(1%) + 외부감사(감리·회계법인) |
| **DAMA-DMBOK 2** (Data Management Body of Knowledge) | 데이터 거버넌스·품질·마스터 | **11개 지식영역**: 거버넌스·아키텍처·모델·저장·보안·통합·마스터·참조·변경·웨어하우스·문서·메타데이터 / **Data Governance Maturity Model 5단계** |
