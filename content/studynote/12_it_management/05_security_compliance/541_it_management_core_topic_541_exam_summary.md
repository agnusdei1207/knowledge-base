## 핵심 인사이트 (3줄 요약)

> 1. **본질**: IT 거버넌스는 COBIT 2019(40개 관리 목표), ITIL 4(34개 실무), ISO 38500(6원칙) 3대 프레임워크를 통합하여 **전략-전술-운영**의 3계층 Value Governance 체계를 구축하고, RACI 매트릭스 기반 의사결정 구조로 기업 IT의 정렬(Alignment), 가치 실현(Value Realization), 위험 관리(Risk Management)를 달성하는 경영 통제 체계이다.
> 2. **가치**: 체계적 적용 시 **IT 투자 ROI 25~40% 향상**, **프로젝트 실패율 30% → 10% 이하 감소**, **이해관계자 만족도 70% 이상 개선**, **컴플라이언스 위반 50% 절감** 등 정량적 효과를 입증할 수 있으며, ESG/디지털 전환 시대의 필수 경영 인프라로 자리매김한다.
> 3. **판단 포인트**: **Build vs Run 예산 배분(통상 30:70)**, **거버넌스 성숙도 5단계(Level 0~5) 진단**, **Governance System 구성요소(원리/정책/프레임워크/프로세스/조직/정보/인력/시설) 7대 영역 최적화**, **DevOps 전환 시 거버넌스 자동화 수준 결정**, **클라우드/AI 도입 시 Shadow IT 위험 통제 방안**이 핵심 의사결정 포인트이다.

## Ⅰ. 개요 및 필요성

정보화 사회에서 기업 IT는 단순 비용 센터(Cost Center)에서 **전략적 비즈니스 인에이블러(Strategic Business Enabler)**로 그 역할이 급격히 변모했다. 2020년대 들어 디지털 전환(Digital Transformation), 클라우드 네이티브(Cloud Native), 생성형 AI(Generative AI) 도입이 가속화되면서 IT에 투입되는 예산 규모는 매출 대비 평균 4.2%~7.5%(Bain & Company 2023) 수준까지 확대되었으나, 이를 체계적으로 관리·감독하는 거버넌스 부재로 **실패 프로젝트 65%(Standish Group CHAOS Report 2023)**, **Shadow IT로 인한 예산 유출 30~40%**, **규제 위반 과태료 평균 연간 4.6M USD(IBM Cost of Data Breach 2023)** 등 막대한 비효율이 발생하고 있다.

특히 최근 **EU AI Act(2024년 발효)**, **DORA(Digital Operational Resilience Act)**, **한국의 개인정보보호법 개정**, **ESG 공시 의무화**, **ISMS-P 인증 강화** 등 규제 환경이 급변하면서, IT에 대한 이사회 차원의 거버넌스 책임(Accountability)이 더욱 강화되었다. 이러한 환경에서 IT 경영 관리의 핵심 토픽인 **IT 거버넌스(IT Governance)**는 단순한 IT 관리 체계를 넘어, **기업 거버넌스(Corporate Governance)의 핵심 하위 체계**로 인식되어야 한다.

기존의 **분절적 IT 관리(Silo-based IT Management)** 방식은 애플리케이션, 인프라, 보안, 데이터가 각기 다른 부서에서 독립적으로 운영되어 **중복 투자(평균 25%)**, **데이터 사일로(Data Silo)**, **책임 공백(Accountability Gap)** 문제를 야기했다. 반면 통합 거버넌스 체계는 **EA(Enterprise Architecture) → 거버넌스 → 서비스 관리 → 프로젝트 관리 → 보안/컴플라이언스**의 End-to-End Value Chain을 구축하여, **전략 정렬(Strategic Alignment)**, **가치 실현(Value Delivery)**, **리소스 최적화(Resource Optimization)**, **위험 관리(Risk Management)**, **성과 측정(Performance Measurement)**의 5대 목표를 달성한다.

```text
┌────────────────────────────────────────────────────────────────────┐
│           IT 거버넌스 3계층 Value Governance 구조도               │
├────────────────────────────────────────────────────────────────────┤
│                                                                    │
│  ┌──────────────────────────────────────────────────────────┐     │
│  │   제1계층: Strategic Layer (전략 거버넌스)               │     │
│  │   ┌─────────────┬──────────────┬──────────────┐         │     │
│  │   │ 이사회/CEO   │  IT 전략위원회 │  CISO/CDO/CAIO│         │     │

│  │   └─────────────┴──────────────┴──────────────┘         │     │
│  │   • IT 전략(IT Strategy) 수립 및 승인                    │     │

│  │   ┌─────────────┬──────────────┬──────────────┐         │     │

기존 방식(As-Is)과 새로운 방식(To-Be)의 핵심 차이는 다음 표와 같다.

| 구분 | As-Is (전통적 IT 관리) | To-Be (IT 거버넌스 기반) |
| :--- | :--- | :--- |
| **관점** | IT = 비용(Cost Center) | IT = 가치 창출(Value Center) |
| **구조** | 부서별 분절(Silo) | End-to-End 통합 체인 |
| **의사결정** | CIO 독단, Top-down | 이사회-위원회-PMO 다층 거버넌스 |
| **성과 측정** | 단순 예산 집행률 | KPI/OKR 기반 Value Realization |
| **리스크 대응** | 사후 대응(Reactive) | 예방적 통제(Preventive) + 탐지(Detective) |
| **규제 대응** | 개별 부서 대응 | GRC 통합 컴플라이언스 |
| **투자 배분** | 연도별 증분(Incremental) | 포트폴리오 최적화(Zero-based) |
| **핵심 프레임워크** | ITIL v3 단독 | COBIT 2019 + ITIL 4 + ISO 38500 + EA |

- **📢 섹션 요약 비유**: IT 거버넌스는 마치 **대형 빌딩의 통합 소방·전기·환기 시스템**과 같다. 예전에는 각 층 관리인이 따로 점검했다면(분절 관리), 지금은 **지하 통합관제센터(거버넌스 본부)에서 24시간 센서로 모든 층을 모니터링하고, 이사회(빌딩 소유주)가 연간 예산과 위험 허용치를 결정**하는 구조로 진화한 것이다.

## Ⅱ. 아키텍처 및 핵심 원리

IT 거버넌스 아키텍처는 **ISO 38500(거버넌스 원칙) → COBIT 2019(거버넌스/관리 체계) → ITIL 4(서비스 운영 실무) → ISO 27001/27002(보안 통제) → ISO 31000(리스크)** 의 5단 표준 레퍼런스 스택을 기반으로 한다. 이 중 **COBIT 2019**은 **40개의 관리 목표(Management Objective)**, **7개의 컴포넌트(Component)**, **5단계 성숙도(Maturity Level)**, **목표 계단식(Cascade Goals)** 등 가장 체계적인 거버넌스 프레임워크를 제공한다.

### 2. ITIL 4 Service Value System (SVS) 핵심 아키텍처

ITIL 4는 **34개 실무(Practice)**와 **Service Value Chain(7개 활동)**, **4 Dimension Model**, **Guiding Principles(7원칙)**로 구성되어 거버넌스 2계층(Tactical)의 실무적 운영을 담당한다.

```text
┌──────────────────────────────────────────────────────────────────────┐
│                  ITIL 4 Service Value System (SVS)                  │
├──────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  ┌────────────────────────────────────────────────────────────┐     │
│  │  Opportunity / Demand ────► Value ◄──── Waste              │     │
│  └────────────────────────────────────────────────────────────┘     │
│                          ▲                                           │
│  ┌───────────────────────┴───────────────────────────────────┐     │
│  │         Guiding Principles (7원칙)                        │     │
│  │         Focus on Value / Start Where You Are /            │     │
│  │         Progress Iteratively with Feedback /               │     │
│  │         Collaborate and Promote Visibility /              │     │
│  │         Think and Work Holistically /                     │     │
│  │         Keep It Simple and Practical /                    │     │
│  │         Optimize and Automate                             │     │
│  └────────────────────────────────────────────────────────────┘     │
│                          ▲                                           │
│  ┌───────────────────────┴───────────────────────────────────┐     │
│  │   4 Dimensions (4차원 모델)                                │     │
│  │   ┌─────────┬─────────┬──────────┬──────────┐            │     │
│  │   │ Org/People│Information│Technology│Partners │            │     │
│  │   │ 조직/사람│  정보     │ 기술     │ 파트너   │            │     │
│  │   └─────────┴─────────┴──────────┴──────────┘            │     │
│  └────────────────────────────────────────────────────────────┘     │
