## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 정보화 사업 관리는 PMBOK/PM²/PRINCE2 기반 프로젝트 관리, COBIT 2019 기반 거버넌스, ITIL 4 기반 서비스 운영을 통합한 **Portfolio-Program-Project 3계층(PPP) 체계**이며, 정보시스템 감리법·클라우드컴퓨팅법·데이터산업법 등 한국형 법·제도적 프레임과 결합하여 공공·민간 정보화 사업의 착수부터 폐기까지 전생애주기(LCM)를 통제하는 것이다.
> 2. **가치**: 체계적 EVM(Earned Value Management) 적용 시 일정·원가·품질 변동控制在 15~25% 수준으로 축소되며, 거버넌스 성숙도 3->5 도약 시 IT 투자 ROI는 평균 28%에서 41%로, Value Leakage(가치 누수)는 전체 IT 예산의 약 9~14%(Gartner 2024 기준)에서 3~5% 수준으로 감소한다.
> 3. **판단 포인트**: Waterfall(요구사항·예측 가능 프로젝트) vs. Agile(불확실·지속배포 프로젝트) vs. Hybrid(MSF/DAD/SAFe) 중 어떤 방법론을 채택할지, 고정가(Fixed-Price) vs. 시간·소요재(T&M) vs. 성과연동(Outcome-Based) 계약구조의 선택, 그리고 내부 PMO(전담/하이브리드/페더레이션) 운영모델 결정이 사업成败의 80%를 좌우한다.

## Ⅰ. 개요 및 필요성

정보화 사업 관리(IT Program/Project Management)는 단순한 "일정표 작성"이 아니라, **전략 정렬(Strategy Alignment) -> 투자 의사결정(Investment Governance) -> 사업 착수·집행(Delivery) -> 성과 측정·환류(Performance & Learning)**의 4단계 가치사슬(Value Chain)을 통합 관리하는 경영 활동이다. 한국 정보화진흥법(2023년 폐지 후 「디지털 시대 기반 규정 마련에 관한 법률」로 이관)에 따른 정보화 사업은 연간 약 8조 원 규모(2024년 디지털예산 기준)로, 약 2,300여 개 공공기관과 14만여 개 민간 기업이 참여하므로, 이 자원의 **부분 최적(Sub-Optimization)**이 곧 국가 디지털 경쟁력 약화로 직결된다.

기존(1990~2000년대) IT 관리는 "Big-Bang" 방식의 일회성 시스템 구축(예: SID(Systems Integration) 단일 프로젝트)을 강조했으나, **클라우드·AI·데이터 플랫폼** 시대에는 (1) **민첩한 반복 개발**, (2) **운영·개발의 융합(DevOps/DevSecOps)**, (3) **데이터·AI 중심 가치 창출**, (4) **규제 준수(데이터3법, AI기본법, 사이버보안 기본법)**가 핵심이 되었다. 그 결과 **PMBOK 7th Edition**(2021)은 기존의 5개 프로세스 그룹·10개 지식 영역을 **12가지 원칙·8개绩效 도메인** 구조로 대전환했고, **PRINCE2 7th Edition**(2023)은 사람·조직·실무 등 7가지 Practice로 확장되었으며, **SAFe 6.0**(2023)은 Lean-Agile을 전사 규모로 확산시켰다.

```text
+------------------------------------------------------------------------+
|              정보화 사업 관리 4계층 가치사슬 (Value Chain)               |
+------------------------------------------------------------------------+
|                                                                        |
|  [Layer 1] 전략 정렬(Strategy Alignment)                                |
|   +--------------------------------------------------+                  |
|   |  BSC-IT · COBIT 2019 · TOGAF 10 ADM · 디지털 전략 |                  |
|   |  KPI: 전략목표 대비 IT기여도, 디지털전환 지수(DTI)  |                  |
|   +--------------------+-----------------------------+                  |
|                        v                                                |
|  [Layer 2] 투자 의사결정(Investment Governance)                          |
|   +--------------------------------------------------+                  |
|   |  포트폴리오 관리 · CBA · TCO · NPV/IRR · 우선순위   |                  |
|   |  KPI: ROI, NPV, Payback Period, Value Leakage    |                  |
|   +--------------------+-----------------------------+                  |
|                        v                                                |
|  [Layer 3] 사업 착수·집행(Delivery)                                      |
|   +--------------------------------------------------+                  |
|   |  PMBOK 7 / PRINCE2 7 / SAFe 6 / Scrum / Kanban    |                  |
|   |  PMP · PfMP · Scaled Agile 자격 · PMO 운영         |                  |
|   +--------------------+-----------------------------+                  |
|                        v                                                |
|  [Layer 4] 성과 측정·환류(Performance & Learning)                        |
|   +--------------------------------------------------+                  |
|   |  EVM · SLA · CSI · KMS · 교훈관리(Lessons Learned)|                  |
|   |  KPI: CPI, SPI, TCPI, SLA 99.95%, CSAT            |                  |
|   +--------------------------------------------------+                  |
|                                                                        |
+------------------------------------------------------------------------+
```

- **📢 섹션 요약 비유**: 정보화 사업 관리는 마치 **"한강의 7개 다리를 짓는 총괄 시공자"**와 같다. 설계(거버넌스)·자재 조달(조달·계약)·시공(빌드)·유지보수(운영)·정산(성과측정)을 동시에 총괄하지 않으면, 아무리 좋은 다리 한두 개를 지어도 도시 전체의 교통 흐름은 정체된다.
