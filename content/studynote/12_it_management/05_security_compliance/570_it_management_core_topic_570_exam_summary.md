# 570. IT 경영 관리 핵심 토픽 570번 시험 요약

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 정보관리기술사(기술사) "IT 경영·관리" 영역은 **COBIT 2019 기반 IT 거버넌스**, **ISP(정보화전략계획)**, **EA(엔터프라이즈 아키텍처)**, **ITIL 4 서비스 관리**, **IT-BSC 성과측정**을 5대 축으로 하여 *기회(Opportunity)*·*위험(Risk)*·*자원(Resource)* 균형 의사결정을 수행하는 체제이며, **SW사업법·클라우드컴퓨팅법·개인정보보호법** 등 對法令 연계로 실무 적합성을 검증하는 것이 본질이다.
> 2. **가치**: COBIT 2019의 40개 관리목표·설계요소 11종 체계 도입 시 IT 투자 ROI 평균 15~25% 개선(Gartner 2023), EA 기반 중복투자 제거로 TCO 20~35% 절감, ITIL 4 34개 실무 프로세스 자동화로 MTTR 30~50% 단축, ISP 정량우선순위 모델로 사업 착수 의사결정 리드타임 40% 축소 등 정량적 효과를 거둘 수 있다.
> 3. **판단 포인트**: ① 거버넌스 프레임워크 선택(COBIT 2019 vs ITIL 4 vs ISO 38500) 시 **조직 성숙도·규제 요구·전략적 목표 정렬**을 우선 평가 ② Top-Down(거버넌스) vs Bottom-Up(현업 니즈) **이원 트랙** 통합 설계 ③ **SW사업법** 발주자 관점(요구사항·검수·하자보수)과 수급자 관점(지식재산권·하자담보) **양면 리스크** 동시 검토가 합격의 핵심 분기점이다.

---

## Ⅰ. 개요 및 필요성

IT 경영관리는 단순히 "IT 부서를 잘 운영한다"는 차원을 넘어, **전사 전략 ↔ IT 투자 ↔ 운영·서비스 ↔ 위험·컴플라이언스**를 단일 가치사슬(Value Chain)로 통합하는 경영과학 분야이다. 한국 정보관리기술사 시험은 1998년 제도 도입 이후 4세대 출제 트랜드를 거쳐왔으며, 2020년 이후 **클라우드 전환(DX)·공급망 보안·SW공급망 투명성(SBOM)** 이슈가 결합되면서 *기존 3축(전략·프로세스·사람) + α(데이터·규제·지속가능성)* 6축 프레임이 사실상 표준으로 자리 잡았다.

시험 출제 빈도 기준으로 최근 5년(2020~2024) **17회 시험**에서 거버넌스(COBIT 2019, ISO 38500) 11회, EA 9회, ISP/BPR 8회, IT-BSC 7회, SW사업법 13회, 디지털 전환·공공데이터 6회 등장했다. 즉 *법령 해석력 + 프레임워크 융합력 + 수치·모델 활용력* 3종 세트가 합격선(60점 만점 기준 통상 50점 이상)을 가른다.

- **📢 섹션 요약 비유**: IT 경영관리는 **"도시의 도시계획 + 교통관제 + 소방·치안"**을 동시에 설계하는 것과 같다. 빌딩(IT 시스템) 한 채를 잘 짓는 것(전통 IT 운영)이 아니라, 도시 전체(기업)의 도로망·규제·안전·가치를 총괄 기획하는 **"디지털 도시 행정학"**이다.

## Ⅱ. 아키텍처 및 핵심 원리

IT 경영관리 6축을 **"거버넌스-실행-환류"** 3계층으로 다시 정렬하면 다음과 같다. 이는 COBIT 2019의 *Governance & Management Objectives(40개)* + *Components of the Governance System(11종)* 과 1:1로 매핑된다.

|         COBIT 2019 기반 IT 경영관리 3계층·11설계요소 매트릭스         |
+----------------------------------------------------------------------+
|                                                                      |
|  -> 1계층: 거버넌스 의사결정체 (Governance Layer)                     |
|  +-------------------------------------------------------------+    |
|  |  [G1] IT 전략·목표  ->  [G2] 위험관리  ->  [G3] 자원배분      |    |
|  |   ·전략위원회         ·리스크레지스터     ·PortFolio화면    |    |
|  |   ·ISO 38500 원칙     ·NIST CSF 정합      ·FinOps 대시보드 |    |

|  +-------------------------------------------------------------+    |
|                              v KPI/CSF로 측정                         |

|  +-------------------------------------------------------------+    |
|  |  [V1] 성과측정(IT-BSC) -> [V2] ROI/NPV -> [V3] 학습·개선      |    |

| :--- | :--- | :--- |
| **COBIT 2019 거버넌스 체계** | 전사 IT 의사결정·통제 표준 | 40개 Governance/Management Objectives + 11 Components + 7 Components of Governance System(원리·정책·프레임워크·역량·문화·구조·RACI), 설계인자(Design Factors) 11종으로 조직별 **Customized Governance System** 도출 |
| **ISP(정보화전략계획)** | 3~5년 IT 로드맵 + 현업중심 니즈 | BPR(현행 업무 분석) -> CSF 도출 -> 만족도/중요도 **IPA(Importance-Performance Analysis)** -> **AHP(Analytic Hierarchy Process)** 다기준 의사결정 -> ROI/NPV 정량 우선순위 -> 5개년 투자 계획 |
| **EA(엔터프라이즈 아키텍처)** | BA·DA·AA·TA 4계층 정합 | TOGAF ADM(Architecture Development Method) 8단계 Phase A->H, **FEAF**(Federal EA) PRM·TRM, Zachman 6×6, **ArchiMate 3.2** 표기법. 클라우드 네이티브 EA는 *Application Capability Map + 5-Stage Cloud Maturity Model* 결합 |
| **ITIL 4 Service Value System** | 34개 실무 프로세스 자동화 | SVS(SV Organization, Opportunity/Demand, Value), 7 Guiding Principles(원리), 34 Practices(사고·일반·서비스) 운영. **MTTR·MTBF·SLA·SLO·Error Budget** SRE 지표와 양립 |
| **IT-BSC(성과측정)** | 재무·고객·내부·학습 4관점 | Kaplan·Norton BSC + IT 특화 확장(서비스 품질·프로젝트 성과·미래준비도). OKR(Objective & Key Results)와 병행, **CSF->KPI->KPI Target** 3단 매핑 |

**핵심 알고리즘 / 모델 정리**

1. **CSF 도출**: 면담·워크숍·자료분석으로 30~50개 후보 -> **Pair-wise Comparison**으로 5~10개 핵심 CSF 추출 -> KPI 매핑.
2. **AHP 우선순위**: 쌍대비교 행렬 -> 고유벡터(Eigenvector) 계산 -> **CR(Consistency Ratio) ≤ 0.1** 검증 -> 가중치 산정. Saaty 1~9 척도.
3. **NPV 산정**: `NPV = Σ [Bₜ − Cₜ] / (1+r)ᵗ`, **할인율 r** = WACC(Weighted Avg. Cost of Capital) ± α(위험가산), **PI(Profitability Index) ≥ 1**일 때 투자 적격.
4. **TCO 모델**: HW·SW·인력·전력·공간·훈련·해지의 **7개 원가동인(Cost Driver)** + 직접비·간접비(보통 1:0.6) -> 3~5년 누적.
5. **COBIT PAM 4단계**: *Initial(1)->Managed(2)->Defined(3)->Quantitatively Managed(4)->Optimized(5)* — 40개 목표별 현재·목표 단계를 0~5 점수로 Gap 분석.
