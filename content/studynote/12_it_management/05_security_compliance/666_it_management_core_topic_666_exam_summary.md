## 핵심 인사이트 (3줄 요약)

> 1. **본질**: IT 경영 관리 핵심 토픽 666번은 **COBIT 2019 기반 IT 거버넌스, ITIL 4 서비스 관리, PMBOK 7th 프로젝트 관리, ISO 27001/22301 보안·연속성 관리, DAMA-DMBOK 데이터 거버넌스, TOGAF EA** 6대 프레임워크를 **Value(가치)·Risk(위험)·Resource(자원)** 3축으로 통합한 종합 메타-거버넌스 체계입니다.
> 2. **가치**: 글로벌 500대 기업의 78%가 다중 프레임워크 통합 거버넌스 도입 시 **감사 비용 35% 절감, IT-Biz 정렬도 4.2/5.0 도달, ROI 평균 287%**, ISO 38500/COBIT 매핑 시 **컴플라이언스 위반률 62% 감소, MTTR 41% 단축, 의사결정 속도 2.8배 향상** 효과가 입증되었습니다.
> 3. **판단 포인트**: 기술사급 핵심 판단은 ①**거버넌스 레이어 분리**(전략-전술-운영), ②**프레임워크 중복 제거율 30~50%** vs 통합 비용 트레이드오프, ③**RACI 매트릭스 기반 이해관계자 책임 한계선**, ④**KPI 계층화**(CSF->KPI->KGI), ⑤**성숙도 모델 갭 분석 우선순위** 결정이며, 이는 단순 도구 도입이 아닌 **조직문화·프로세스·데이터·기술** 4차원 동시 설계 여부입니다.

## Ⅰ. 개요 및 필요성

IT 경영 관리 토픽 666번은 정보관리기술사 시험에서 **다중 거버넌스 프레임워크 통합**과 **디지털 전환 시대의 IT-비즈니스 정렬(Strategic Alignment)** 능력을 평가하는 핵심 출제 영역입니다. 1990년대 데이터센터 시대의 단일 시스템 관리, 2000년대 SOA·ERP 기반의 프로세스 통합, 2010년대 클라우드·모바일 전환기를 거쳐, 현재는 **AI·데이터·보안·지속가능성(ESG)** 이라는 4대 메가트렌드가 IT 경영의 모든 의사결정 기준을 재정의하고 있습니다.

전통적인 IT 관리(ILM: IT Management)는 ITIL v2의 **10개 프로세스·2개 기능** 중심의 운영 효율성에 집중했으나, ITIL 4의 **34개 운영 모범 실무**와 **SVS(Service Value System)** 패러다임으로 전환되었습니다. 동시에 COBIT 2019는 단순 통제 목표(Control Objective)에서 **40개 거버넌스·관리 목표**와 **7개 컴포넌트(Principles, Policies, Processes, Organizational Structures, Information Flows, People, Skills, Culture, Services, Infrastructure, Applications)** 기반 체계로 진화했습니다.

**왜 통합 거버넌스가 필수적인가?** Gartner 2024 보고서에 따르면, 대기업 IT 조직의 평균 **도구 수 87개, 프레임워크 5.2개**가 중복 운영되어 연간 **3,400만 달러**의 비효율을 발생시킵니다. ISACA의 2023 Survey에서는 COBIT 2019와 ITIL 4를 통합 적용한 조직이 **IT-Business 정렬 성숙도 4.2/5.0** (미적용 2.8/5.0), **컴플라이언스 감사 소요시간 35% 감소**, **IT 투자 ROI 287%** 달성을 보고했습니다.

기술사 관점에서 핵심 변화는 **"Process Compliance -> Value Realization"** 패러다임 전환입니다. 과거의 ITIL v2는 SLM(Service Level Management)을 통한 KPI 관리에 그쳤다면, ITIL 4는 **SVS(Value Chain -> Opportunity/Demand -> Value)** 14단계 가치 흐름을 통해 비즈니스 가치를 엔드투엔드로 추적합니다. 이는 곧 COBIT 2019의 **"Goals Cascade(목표 계층화)"** 메커니즘과 직접 매핑됩니다.

- **📢 섹션 요약 비유**: IT 경영 관리 666번은 마치 **오케스트라의 총지휘자**와 같습니다. 바이올린(ITIL 서비스운영), 첼로(COBIT 거버넌스), 트럼펫(보안), 팀파니(연속성) 등 각 악기(프레임워크)가 제각각 연주하면 불협화음(중복·갭)이 발생하므로, **하나의 악보(통합 거버넌스 모델)**로 통일해야 하모니(가치 극대화)를 이룰 수 있습니다.

## Ⅱ. 아키텍처 및 핵심 원리

IT 경영 관리 666번의 기술적 핵심은 **"3축 통합 모델"** 입니다. **Value(가치 창출축)**, **Risk(위험 관리축)**, **Resource(자원 최적화축)** 이 세 축이 6대 프레임워크를 횡단 연결하는 메타-아키텍처를 형성합니다.

### 6대 프레임워크 핵심 구성 요소 매트릭스

| 구성 요소 | 역할 | 핵심 기술 및 동작 방식 |
|:---|:---|:---|
| **COBIT 2019** | 거버넌스 메타-프레임워크 | 5개 도메인(EDM: Evaluate-Direct-Monitor / APO: Align-Plan-Organize / BAI: Build-Acquire-Implement / DSS: Deliver-Service-Support / MEA: Monitor-Evaluate-Assess) 내 **40개 거버넌스·관리 목표**. 7 컴포넌트 변형 모델, 11 디자인 팩터, Goals Cascade를 통한 **CSF 13개 -> KGI 13개 -> KPI 40개** 계층화. |
| **ITIL 4** | 서비스 가치 사슬 운영 | **SVS(Service Value System)** 7개 컴포넌트(Opportunity/Demand -> Value -> Guiding Principles -> Governance -> Service Value Chain -> Practices -> Continual Improvement). **34개 운영 모범 실무(OPP)**, **3개 일반 관리 실무(GMP)**, **17개 기술·조직 변화 촉진자**. 가치 흐름(Value Stream) 엔드투엔드 추적. |
| **PMBOK 7th (2021)** | 프로젝트·프로그래밍 가치 전달 | **8개 프로젝트 성과 도메인**(이해관계자, 팀, 개발 접근방식/수명주기, 계획, 프로젝트 작업, 전달, 측정, 불확실성). **12가지 프로젝트 관리 원칙**(스탠다드), 가치 전달 시스템(Value Delivery System) 중심. **P3O/Program/Portfolio 3계층**. |
| **ISO 27001:2022** | 정보보안 관리체계(ISMS) | **93개 통제 항목(Annex A 4.1~5.37)**, **4개 통제 범주(조직 37, 사람 8, 물리적 14, 기술 34)**, **10개 클로즈 18속성**(Confidentiality/Integrity/Availability+). **PDCA 사이클 + Statement of Applicability(SoA)**. |
| **ISO 22301:2019** | 사업연속성관리체계(BCMS) | **PDCA 기반 10개 조항(4~10)**, **BIA(Business Impact Analysis) -> RTO/RPO/MTPD 산정**, **전략 선택(중단금지/계속/부분이관/전환)**, **연습·테스트 5단계(Tabletop->Walkthrough->Simulation->Parallel->Full Interruption)**. |
| **TOGAF 10th (2022)** | 엔터프라이즈 아키텍처 | **9단계 ADM(Architecture Development Method)** Preliminary->A(아키텍처 비전)->B(비즈니스)->C(데이터/앱)->D(기술)->E(기회·솔루션)->F(마이그레이션 플랜)->G(구현 거버넌스)->H(아키텍처 변경 관리)->Requirements Management. **Content Metamodel 6×6×6 매트릭스**, **TRM(Technical Reference Model)**. |
