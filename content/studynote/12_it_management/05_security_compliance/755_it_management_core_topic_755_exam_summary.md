## 핵심 인사이트 (3줄 요약)

> 1. **본질**: IT 경영 관리의 핵심은 **COBIT 2019 / ISO 38500 기반 IT 거버넌스**, **PMBOK 7th + 애자일 하이브리드 프로젝트 관리**, **정보시스템 감리기준(행정안전부 고시)**, **CMMI-DEV v2.0 / ISO 25010 SW 품질**, **SW사업 대가산정 가이드(2024개정)** 5대 축의 통합적 적용이다.
> 2. **가치**: 거버넌스-관리-감리-품질-대가의 5단 프레임워크를 정합성 있게 운영 시 **사업 실패율 35%→15% 감소**(Standish Group 2023), **감리 부적합 판정률 18%→6%**, **하자 보수비용 40% 절감**, **TCO 25% 절감**의 정량 효과가 입증된다.
> 3. **판단 포인트**: 기술사형 핵심 판단은 ①**거버넌스-관리-감리의 3층 분리**(Board-Executive-Operational)와 ②**위험 기반 감사(Risk-Based Audit)**, ③**애자일 전환 시 고정가(Fixed Price) vs T&M(Time & Material) 대가구조 선택**, ④**국내 vs 해외 표준 정합성**(DGI/디지털정부법 ↔ COBIT/ISO) 사이의 **Trade-off**에서 결정된다.

---

## Ⅰ. 개요 및 필요성

정보화 사업의 대형화·복합화로 인해 단순 개발을 넘어 **전략적 IT 투자 포트폴리오 관리**, **위험 기반 거버넌스**, **객관적 제3자 감리**, **생애주기 품질 보증**이 요구된다. 특히 2023년 **공공데이터 제공·활용 확대**, 2024년 **클라우드 이용 촉진 기본법**, 2025년 **AI 기본법** 시행으로 IT 경영 관리의 법·제도적 환경이 급변함에 따라, 기술사는 **"법적 책임성 ↔ 기술적 실현성 ↔ 경영적 가치"**의 3축 균형 능력을 입증해야 한다.

기존 패러다임은 **기능(Function) 중심 개발·도입**이었다면, 신규 패러다임은 **가치(Value)·데이터·플랫폼·경험 중심**으로 전환되었다. **SW 중심 사회(소프트웨어 중심사회 실현 전략, 2023)**에 따라 SW 품질이 곧 국가 경쟁력의 핵심 변수가 되었으며, 이를 관리·감독하기 위한 통합 프레임워크가 필수적이다.

### 📢 섹션 요약 비유
IT 경영 관리는 **대형 조선소의 선박 건조**와 같다. **거버넌스**는 조선소의 품질·안전 경영方针(方針), **프로젝트 관리**는 설계도·자재 발주·공정표, **감리**는 선급(Lloyd's, KR) 검사, **품질 관리**는 용접·도장 기준, **대가 산정**은 선가(船價) 계약이다. 이 5개가 한 톨이라도 어긋나면 선박은 출항조차 못 한다.

## Ⅱ. 아키텍처 및 핵심 원리

IT 경영 관리의 5대 축은 **상호 의존적 피드백 루프**로 동작한다. **COBIT 2019의 거버넌스 시스템(Governance System)**이 최상위에서 목표(Objectives)와 위험(Risk)을 정의하고, **PMBOK 7th의 8대 Performance Domain**이 이를 실행하며, **감리기준**이 객관적으로 검증하고, **ISO 25010 품질모델**이 측정한 지표가 다시 거버넌스로 환류되는 구조다.

```text
┌─────────────────────────────────────────────────────────────────────────┐
│         IT 경영 관리 핵심 프로세스 (Closed-Loop Control System)          │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│   ┌──────────┐  Strategy  ┌──────────┐  Plan    ┌──────────┐            │
│   │Governance│ ──────────▶│  Plan &  │─────────▶│Execution │            │
│   │(COBIT)   │            │Organize │          │(PMBOK)   │            │
│   └──────────┘            └──────────┘          └────┬─────┘            │
│        ▲                                            │                   │
│        │  Feedback (성과지표)                          ▼                   │
│        │                                      ┌──────────┐              │
│        │                                      │  Audit   │              │
│        └──────────────────────────────────────│ (감리)   │              │
│                       개선 권고               └────┬─────┘              │
│                                                    │                   │
│                                                    ▼                   │
│   ┌──────────┐  결함DB  ┌──────────┐       ┌──────────┐               │
│   │ Quality  │◀────────│ Measure  │◀──────│  Verify  │               │
│   │(CMMI/    │         │(ISO 25010│       │ (Test)   │               │
```

| 구성 요소 | 역할 | 핵심 기술 및 동작 방식 |
|:---|:---|:---|
| **거버넌스 체계** | IT 투자·위험·자원·성과의 의사결정 구조 | **COBIT 2019**: 40개 거버넌스/관리 목적, 5개 도메인(EDM/APO/BAI/DSS/MEA), Design Factors 11개로 기업 맞춤 설계. **ISO/IEC 38500:2015** 6원칙(책임·전략·취득·성과·준수·인간행위). 거버넌스-관리 분리(Govern/Manage split) |
| **프로젝트 관리** | 일정·원가·품질·범위·리스크의 통합 관리 | **PMBOK 7th(2021)**: 8대 Performance Domain(Stakeholder, Team, Development, Planning, Project Work, Delivery, Measurement, Uncertainty), 12개 원칙. **PRINCE2 7th** 7원칙·7실무·7프로세스. 애자일 Scrum(3역할·5이벤트·3산출물), SAFe 6.0(Sprint→PI→ART) |
| **감리 체계** | 사업의 적정성·합법성·효율성 객관 검증 | **정보시스템 감리기준(행정안전부 고시 제2023-32호)**: 7단계 감리절차(계획→착수→현황→위험→실태→보고→후속), 4대 감리영역(사업·재무·기술·보안). **ISACA COBIT 기반 감리**, **위험 기반 감리(RBA)** 접근 |
| **SW 품질 관리** | SW 제품·프로세스의 정량적 품질 보증 | **ISO/IEC 25010:2011(개정예정 2025)**: 8개 품질특성(기능적합성·성능·호환성·사용성·신뢰성·보안·유지보수성·이식성), 31개 부특성. **CMMI-DEV v2.0(2018)**: 5성숙도(Initial→Managed→Defined→Quantitatively Managed→Optimizing), 20개 Practice Area |
| **대가·계약 관리** | SW사업의 적정 대가 산정과 계약 구조 | **SW사업 대가산정 가이드(2024.10개정)**: 투입공수방식·기능점수방식(FP·백로버그·COSMIC)·정액가방식. **VE(Value Engineering)**, **TCO(Total Cost of Ownership)**, **LCC(Life Cycle Cost)**. **고정가·T&M·성과연동** 3종 계약 모델 |

### 핵심 알고리즘/원리: 3대 가치 측정 모델

**(1) 기능점수(Function Point, FP)**: ISO/IEC 20926 / IFPUG 4.3.1
```
UFP = Σ(EI × 가중치) + Σ(EO × 가중치) + Σ(EQ × 가중치)
    + Σ(ILF × 가중치) + Σ(EIF × 가중치)
VAF = (TDI × 0.01) + 0.65  [0.65 ~ 1.35]
FP = UFP × VAF
```
EI/EO/EQ(기능적 데이터 흐름) × 5개 가중치(단순·보통·복잡) → 14개 GSC(General System Characteristic) → VAF

**(2) COSMIC FP**: ISO/IEC 19761, SW 규모 측정의 de facto 표준
```
CFS = Σ(Entry + Exit + Read + Write)  ×  4
범위 : 1 CFP ≈ 30~50 LOC (언어별 차이)
```

**(3) COBIT 2019 Design Factor 11개 가중치 계산**:
- Enterprise Strategy, Enterprise Goals, Risk Profile, I&T-Related Issues 등 11개 요인에 가중치(0~100) 부여 → 40개 Governance/Management Objectives 우선순위 산정

- **📢 섹션 요약 비유**: IT 경영 관리의 5대 축은 **자동차의 5륜 시스템(5-Wheel System)**과 같다. 거버넌스(핸들)·관리(엔진)·감리(브레이크)·품질(차체 강도)·대가(연료). 한 바퀸라도 제 기능을 못 하면 차는 제자리에서 맴돈다.

## Ⅲ. 비교 및 연결

| 구분 | **COBIT 2019** | **ISO/IEC 38500:2015** | **정보시스템 감리기준** |
|:---|:---|:---|:---|
| **목적** | IT 거버넌스·관리 통합 프레임워크 | IT 거버넌스 국제표준(원칙·모델) | 공공부문 IT사업 감리 법정 기준 |
| **범위** | Govern + Manage(전 영역) | Govern only(6원칙) | 사업·재무·기술·보안 4영역 |
| **주체** | 전 조직(B2B·공공) | 전 조직(원칙 제시) | 공공기관(법정 의무) |
| **구조** | 40 Objectives × 5 Domains | 6 Principles × 3 Tasks | 7단계 절차 × 4영역 |
| **법적 강제력** | 없음(권고) | 없음(권고) | **있음**(정보시스템 감리법) |
| **연결** | ISO 27001·20000·9001 매핑 | COBIT에 매핑됨 | COBIT·ISO 27001을 감사 체크리스트로 활용 |

| 구분 | **PMBOK 7th(2021)** | **PRINCE2 7th(2023)** | **ISO 21502:2020** |
|:---|:---|:---|:---|

| **구조** | 8 PD × 12 Principles | 7 Principles × 7 Practices | 11개 핵심 개념 |
| **애자일** | 직접 통합(8 PD 중 4개) | 별도 가이드(2017+) | 친애자일 |
| **인증** | PMP, CAPM | PRINCE2 Practitioner | 없음(가이드) |
| **적용** | 미국·글로벌 표준 | 영국·유럽·정부 특화 | 글로벌 일반 가이드 |

| 구분 | **CMMI-DEV v2.0** | **ISO 25010** | **SPICE(ISO 15504)** |
|:---|:---|:---|:---|
| **대상** | 조직·프로세스 성숙도 | SW 제품 품질 | 프로세스 능력·성숙도 |
| **평가** | 5 레벨(SCAMPI 평가) | 측정 지표(8특성×부특성) | 6 레벨(0~5) |
| **측정** | 정성·정량 혼합 | **정량** 측정 | **정량** 정량·정성 혼합 |
| **용도** | 능력 향상·조달 자격 | 품질 요구사항·검증 | 프로세스 개선·공급자 평가 |
