## 핵심 인사이트 (3줄 요약)

> 1. **본질**: IT 경영 관리의 핵심은 **COBIT 2019(40개 관리목표), ITIL 4(34개 실무), PMBOK 7th(12가지 원칙), TOGAF 10(ADM 주기), ISO/IEC 38500(6원칙)** 등 글로벌 표준 프레임워크를 기업의 거버넌스·관리 체계에 정합(Alignment)시켜 **Value Creation(가치창출)** 을 실현하는 경영과학이다.
> 2. **가치**: 정량적으로는 IT 투자 대비 ROI 20~35% 개선, 프로젝트 성공률 28% -> 68% 향상(PMI 2021), 정성적으로는 **이해관계자(Stakeholder) 투명성 확보, 리스크 가시화, 규제 컴플라이언스 자동화**를 통해 경영 의사결정의 **"단일 진실의 원천(SoT, Single Source of Truth)"** 을 제공한다.
> 3. **판단 포인트**: 프레임워크 도입 시 **"Build vs Buy vs Adapt"**(자체구축/외부구매/맞춤형 적응)의 트레이드오프, **거버넌스-관리-운영의 3계층 분리(Govern/Manage/Operate)**, 그리고 **Bimodal IT(탐색형·활용형 이원화)** vs **통합 거버넌스**의 아키텍처 선택이 핵심 의사결정 변수이다.

---

## Ⅰ. 개요 및 필요성

4차 산업혁명 시대에 기업의 IT는 단순 비용(Cost Center)에서 **전략적 비즈니스 인에이블러(Strategic Business Enabler)** 로 전환되었다. 그러나 한국 정보화진흥원의 「2023년 국내 정보화 투자 통계」에 따르면, 국내 500대 기업의 IT 투자 중 **약 41.7%가 실패/부분실패**(Standish Group CHAOS Report 기준)하며, 그 원인의 67%는 **경영 전략과 IT 전략의 미연계(Strategic Misalignment)** 에 기인한다. 이는 CFO(최고재무책임자), CIO(최고정보책임자), CDO(최고데이터책임자), CISO(최고정보보안책임자) 간의 거버넌스 부재에서 비롯된다.

IT 경영 관리(IT Management & Governance)는 **"정보기술 자산을 통해 조직의 전략적 목적을 달성하고, 이해관계자에게 가치를 제공하며, 리스크를 통제하는 일련의 의사결정 프레임워크"** 로 정의된다. 이는 ISO/IEC 38500의 6대 원칙(책임성, 전략, 획득, 성과, 적합성, 인간행동) 아래 3개 영역(Evaluate·Direct·Monitor)으로 구성된다.

기존 패러다임은 **"기술 중심(Tech-Centric)"** 으로, 인프라·SW 개발 자체가 목적이었으나, 새로운 패러다임은 **"가치 중심(Value-Centric)"** 으로, BSC·KPI·ROI 등 경영성과 언어와 IT 언어의 번역(Translation Layer)이 필수적이다.

```text
   [기존 패러다임: 기술 중심]               [신 패러다임: 가치 중심]

   +-----------------+                    +-----------------------------+
   |   CIO 단독 의사결정   |                    |   CxO 협의체 (CxO Council)    |
   |   - 기술 사일로       |                    |   - 전략 정합(Alignment)      |
   |   - CapEx 일변도      |                    |   - CapEx/OpEx 균형          |
   |   - 프로젝트 단위 성과  |                    |   - 포트폴리오·가치 기반       |
   +--------+--------+                    +-------------+---------------+
            |                                            |
            v                                            v
   +-----------------+                    +-----------------------------+
   |   시스템 단위 개발   |                    |   서비스·플랫폼 기반 운영      |
   |   - Waterfall     |                    |   - Agile + DevOps + SRE    |
   |   - 폐쇄형 아키텍처  |                    |   - 개방형·API-First         |
   +--------+--------+                    +-------------+---------------+
            |                                            |
            v                                            v
   +-----------------+                    +-----------------------------+
   |   사후 보고·감사    |                    |   실시간 대시보드·연속감사     |
   |   - 연 1회 실적보고   |                    |   - PDCA + OODA + 실시간 KPI |
   +-----------------+                    +-----------------------------+
```

특히 2024년 이후 **AI 거버넌스(EU AI Act, 2024.8 시행), 데이터3법(개인정보·가명·신용정보), 클라우드컴퓨팅법(2024.9 시행)** 등 규제 환경의 급격한 변화로 인해 IT 경영 관리 체계의 재설계가 모든 산업의 생존 전략이 되었다.

- **📢 섹션 요약 비유**: IT 경영 관리는 자동차의 **"계기판·핸들·브레이크·내비게이션"** 이 한 세트로 통합된 **"자동차 통합제어 시스템(Vehicle Dynamics Control)"** 과 같다. 엔진(IT 자산)만 아무리 강력해도 방향타(거버넌스)와 브레이크(리스크관리)가 없으면 차는 추락하고, 내비게이션(전략 정합) 없이는 목적지에 도달하지 못한다.

## Ⅱ. 아키텍처 및 핵심 원리

IT 경영 관리의 참조 아키텍처는 국제 표준 5종(COBIT, ITIL, PMBOK, TOGAF, ISO 38500)을 **3계층 통합 거버넌스 모델**로 재구성한다.

```text
                       +--------------------------------------------+
                       |    거버넌스 계층 (GOVERN - ISO 38500)        |
                       |  +--------------+  +------------------+    |
                       |  | 이사회/IT전략위|  |  CIO / CxO Council |    |
                       |  | (전략·정책)   |  |  (의사결정·감독)   |    |
                       |  +------+-------+  +---------+--------+    |
                       +---------+--------------------+-------------+
                                 | Evaluate/Direct/Monitor |
                  +--------------v--------------------v--------------+
                  |    관리 계층 (MANAGE - COBIT 2019)                  |
                  |  +---------+ +---------+ +---------+ +---------+ |
                  |  | EDM     | | APO     | | BAI     | | DSS     | |
                  |  |평가·지휘 | |정렬·계획 | |구축·획득 | |전달·지원 | |
                  |  | 5개     | | 14개    | | 11개    | | 6개     | |
                  |  +---------+ +---------+ +---------+ +---------+ |
                  |  | MEA     |                                       |
                  |  |모니터·평가|                                       |
                  |  | 4개     |                                       |
                  |  +---------+                                       |
                  +----------------------+----------------------------+
                                         | Service Value Chain (SVC)
                  +----------------------v----------------------------+
                  |    운영 계층 (OPERATE - ITIL 4)                      |
                  |  Plan->Engage->Design&Transition->Obtain/Build->       |
                  |  Deliver&Support->Improve (34 Practices)             |
                  +-----------------------------------------------------+
                                         |
                                         v
                  +----------------------------------------------------+
                  |  변화 및 실행 계층 (EXECUTE - PMBOK 7th / TOGAF)    |
                  |  PMBOK: 12원칙 + 8성과영역 / TOGAF: ADM (A->H)       |
                  +----------------------------------------------------+
```

### 핵심 프레임워크 매핑 테이블

| 구성 요소 | 역할 | 핵심 기술 및 동작 방식 |
| :--- | :--- | :--- |
| **ISO/IEC 38500** | IT 거버넌스 국제표준 | 6원칙 + 3영역(Evaluate/Direct/Monitor) 기반 이사회 수준 의사결정 모델. PD 38500:2015 개정판은 5단계 거버넨스 사이클(위임·결정·의사소통·모니터링·검증) 명시 |
| **COBIT 2019** | IT 관리·통제 프레임워크 | **40개 관리목표(Management Objectives)** 를 5도메인(EDM 5 + APO 14 + BAI 11 + DSS 6 + MEA 4)로 분류. 집중요인(Focus Area)과 설계인자(Design Factor 11개)로 맞춤형 거버넌스 시스템 설계 |
| **ITIL 4** | IT 서비스 운영 모델 | **34개 실무(Practices)** + **서비스 가치 체계(SVS)** + **서비스 가치 사슬(SVC) 6활동**. "사고->요청->문제->변경" 4-피스 워크플로우, CSI(지속적서비스개선) 등록부 |
| **PMBOK 7th** | 프로젝트 관리 지식체계 | **12원칙 + 8성과영역(Stakeholder, Team, Development Approach, Planning, Project Work, Delivery, Measurement, Uncertainty)** 기반. **원칙 기반(Principle-based)** 으로 전환(2009·2017·2021 변천) |
| **TOGAF 10** | EA(기업아키텍처) 방법론 | **ADM(Architecture Development Method) 8단계: Preliminary->A(비전)->B(비즈니스)->C(정보시스템)->D(기술)->E(기회&솔루션)->F(마이그레이션)->G(구현거버넌스)->H(아키텍처 변경)**. ADM Cycle Iteration 지원 |
| **ISO 27001/27701** | 정보보안/개인정보 거버넌스 | ISMS(정보보호관리체계) + PIMS(개인정보관리체계) 통합. **Annex A 통제 93개(2022 개정)** -> 4개 카테고리(조직·인적·물리·기술) |
| **EA 참조모델** | 한국 공통 EA | **정부·공공 EA 프레임워크(행안부)** : 4아키텍처(BA/DA/AA/TA) × 5관점(Strategy/Organization/System/Technology/Operation) |
| **BPR/ISP** | 정보화 전략 기획 | 정보화진흥법 제3조에 따른 **ISP 수립 절차: 현황분석->비전수립->전략과제->실행계획->평가**. **BPR(Business Process Reengineering)** 의 5단계(Hammer&Champy) |

### 핵심 동작 메커니즘: 거버넌스 가치 흐름(Value Loop)

1. **전략 정합(Alignment)**: BSC 4관점(재무·고객·내부·학습성장) ↔ IT KPI 매핑. 예: "고객만족도 10%^(재무)" -> "셀프서비스 도입률 80%(내부 프로세스)" -> "DevOps 성숙도 Level 3(학습·성장)"
2. **우선순위 결정(Portfolio Prioritization)**: **NVP(Net Value Portfolio)** 모델: `Value = (Benefit × Probability of Success) / (Cost × Risk)`. 다기준의사결정(MCDA) - AHP(계층분석법), Weighted Scoring Model
3. **가치 측정(Value Measurement)**: **KPI 4유형(선도/동시/후행/지연)** + **CSF(핵심성공요인)**. IT BSC: Cameco 4관점 모델
4. **피드백 및 학습(Feedback)**: **PDCA + OODA Loop**. **감리/감사**는 `연 1회 정기감리` + `수시 컨설팅` + `연속감사(Continuous Auditing)` 3트랙
5. **리스크 관리(ERM)**: **ISO 31000** 기반 리스크 등록부 + **Bow-Tie 분석** + **KRI(Key Risk Indicator) 5단계 임계치**

- **📢 섹션 요약 비유**: 이 5단계 가치 흐름은 **"병원 진료 시스템"** 과 같다. ①건강검진(전략 정합) -> ②CT/MRI 촬영(우선순위) -> ③혈액검사(가치 측정) -> ④진료·처방(피드백) -> ⑤수술 후 관리(리스크 관리). 각 단계의 표준화된 프로토콜이 환자의 생명을 살리는 것처럼, IT 거버넌스 프로토콜이 기업의 가치를 살린다.

## Ⅲ. 비교 및 연결

IT 경영 관리에서 혼동하기 쉬운 핵심 개념들의 차이를 명확히 구분하는 것이 기술사 답안의 핵심이다.

### 1. 거버넌스 vs 관리 vs 운영

| 구분 | 거버넌스(Governance) | 관리(Management) | 운영(Operations) |
| :--- | :--- | :--- | :--- |
| **핵심 질문** | "해야 하는가(Should we?)" | "어떻게 할 것인가(How to?)" | "일을 어떻게 수행할 것인가(Do it!)" |
| **결정 주체** | 이사회, IT전략위원회 | CIO, IT거버넌스위원회 | 서비스 데스크, SRE, DBA |
| **시간축** | 3~5년 전략 | 1~2년 계획 | 일/주/월 단위 실행 |
| **산출물** | 정책·방침·예산 한도 | 표준·프로세스·KPI | 인시던트·티켓·로그 |
| **측정 지표** | ROI, NPV, 전략목표 달성률 | SLA, 서비스 가용성 99.9% | MTTR, MTTD, 가동률 |
| **참조 표준** | ISO 38500, COBIT EDM | COBIT APO/BAI/DSS/MEA, PMBOK | ITIL 4 Practices (26 Operational) |

### 2. 주요 프레임워크 비교

| 구분 | **COBIT 2019** | **ITIL 4** | **PMBOK 7th** | **TOGAF 10** |
| :--- | :--- | :--- | :--- | :--- |
| **목적** | 거버넌스+관리 통합 | 서비스 운영 최적화 | 프로젝트 성공 | EA 구축·활용 |
| **구조** | 40 관리목표 | 34 실무 + SVS | 12 원칙+8 영역 | ADM 8단계 |
| **범위** | 전사 IT(End-to-End) | IT 서비스 운영 | 단일 프로젝트 | 조직 전체 아키텍처 |
| **핵심 가치** | 가치창출+리스크 균형 | 가치 공동창출(Co-creation) | 가치 전달(Delivery) | 비즈니스 정합 |
| **적합 조직** | 대기업·공공·금융 | 서비스 중심 조직 | 모든 프로젝트 수행 조직 | 아키텍처 성숙 조직 |
| **인증** | COBIT 2019 Foundation/Design/Implement | ITIL 4 Foundation/MP/SL
