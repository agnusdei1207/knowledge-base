## 핵심 인사이트 (3줄 요약)

> 1. **본질**: IT 경영 관리는 **ISO 38500(거버넌스 원칙) -> COBIT 2019(거버넌스/관리 체계: 40개 MG) -> ITIL 4(서비스 운영: 34개 Practice)**의 3계층 프레임워크를 통해, 이사회 거버넌스(EDM) -> 경영 관리(APO) -> 운영 서비스(BAI/DSS) -> 평가(MEA)로 이어지는 의사결정 사슬을 통합 설계하는 것이다.
> 2. **가치**: Forrester Research(2022) 및 McKinsey 분석에 따르면, 성숙한 IT 거버넌스 도입 기업은 **IT 투자 ROI 약 23~35% 향상**, **프로젝트 실패율 50% 감소**(PMI 기준 14%->7%), **Time-to-Market 30% 단축**, 그리고 **감사 지적 사항 60% 감소** 효과를 달성한다.
> 3. **판단 포인트**: 핵심 트레이드오프는 **(a) 중앙집중 거버넌스 vs 페더레이션 모델**, **(b) 규칙 기반 통제(Compliance-First) vs 성과 기반 자율(Performance-First)**, **(c) 프레임워크 전체 채택(Heavy) vs 핵심 요소만 경량화(Lean)**, **(d) 정량 KPI 우위 vs 정성 BSC 전략맵 우위**의 4가지 축에서 조직의 Design Factor 11개(COBIT 2019)에 따라 최적 균형점을 결정해야 한다.

## Ⅰ. 개요 및 필요성

### 1.1 시대적 배경: IT의 역할 변화

| 시대 | IT의 역할 | 경영진 인식 | 핵심 관리 이슈 |
| :--- | :--- | :--- | :--- |
| 1960~80년대 | 데이터 처리(EDP) | 비용(Cost Center) | 데이터 정확성, 배치 처리 안정성 |
| 1990년대 | 업무 자동화(MIS/ERP) | 지원 기능(Enabler) | 시스템 통합, Y2K 대응 |
| 2000년대 | 비즈니스 파트너 | 전략적 자산(Strategic Asset) | IT 거버넌스, 컴플라이언스(SOX, 개인정보보호법) |
| 2010년대 | 디지털 트랜스포메이션 | 핵심 경쟁력(Differentiator) | 클라우드, 모바일, 빅데이터, Agile/DevOps |
| 2020년대 | AI-Native 사업 | 사업 그 자체(Business) | 생성형 AI 거버넌스, ESG, 데이터 주권, 양자암호 |

### 1.2 등장 배경 및 기술적 과제

기존 IT 부서는 **"Shadow IT"**(영업·마케팅이 사내 통제 없이 AWS信用卡으로 SaaS 사용), **"스프레드시트 거버넌스"**(의사결정 근거가 Excel 메일 순회), **"프로젝트 블랙홀"**(TCO의 70%가 운영·유지보수 단계에서 누수)이라는 3대 질환에 시달렸다. 2002년 Enron·WorldCom丑闻 이후 SOX법 404조(내부통제), 2008년 금융위기 이후 Basel III, 그리고 2018년 GDPR·2023년 EU AI Act 등 규제 강화로, 이사회 차원의 **IT 의사결정 통제 체계** 수립이 법적·재무적 필수 요건이 되었다.

한국에서도 2022년 과학기술정보통신부 **「공공기관 IT 거버넌스 가이드라인」**, 2023년 개인정보보호법 개정(가명정보), 2024년 AI 기본법 제정 등으로 IT 경영 통제 대상이 급격히 확대되었다.

### 1.3 시스템 아키텍처 개요

```text
+--------------------------------------------------------------------------+
|              이사회(Board) / 거버넌스 위원회                              |
|  · ISO 38500 6원칙 (책임/전략/획득/성과/적합/인적행동)                    |
|  · 의사결정: IT 방향성, 한도, 위험 허용도, CEO·CIO 임명                   |
+-------------------------------------+------------------------------------+
                                      | (PDCA + 보고 체계)
                                      v
+--------------------------------------------------------------------------+
|          경영 관리(Executive Management) - COBIT 2019 EDM/APO            |
|  · EDM: 5개 목표 (EDM01~05) - 거버넌스 프레임워크 자체 관리              |
|  · APO: 14개 목표 - 전략, 포트폴리오, 예산, 위험, 자원, 이해관계자       |
|  · 도구: BSC Strategy Map, IT Portfolio Matrix, TCO/ROI 모델             |
+-------------------------------------+------------------------------------+
                                      | (Solution Build + Service Delivery)
                                      v
+--------------------------------------------------------------------------+
|       운영·서비스 계층 - COBIT BAI/DSS + ITIL 4 SVS                      |
|  · BAI 11개 목표: 프로젝트, 변경, 수용, 구성, 자산 관리                  |
|  · DSS 6개 목표: 운영, 인시던트, 연속성, 보안, 문제, 요청 이행            |
|  · ITIL 4 34 Practices: Incident/Change/Problem/SLM/CSDM                |
+-------------------------------------+------------------------------------+
                                      | (M&E Loop)
                                      v
+--------------------------------------------------------------------------+
|            모니터링·평가 - COBIT MEA + 내부감사                           |
|  · MEA 4개 목표: 성능, 내부통제, 외부요구, 성과                         |
|  · 측정: CSF/KPI/KGI/Leading & Lagging Indicator, RACI 매트릭스          |
+--------------------------------------------------------------------------+
```

- **📢 섹션 요약 비유**: IT 경영 관리는 **건물의 안전 관리 체계**와 같다. 평소엔 잘 보이지 않지만, 평상시 점검(거버넌스) -> 소방 훈련(서비스 운영) -> 화재 감지기(모니터링) -> 실제 화재 시 대피(리스크 대응)가 한 체계로 움직여야 한다. 각 층이 따로 놀면 무너진다.

## Ⅱ. 아키텍처 및 핵심 원리

### 2.1 ISO/IEC 38500 IT 거버넌스 국제표준 (6대 원칙)

ISO 38500:2015는 이사회가 IT를 **평가(Evaluate)·지시(Direct)·모니터링(Monitor)**하는 3개 행동 모델을 통해 다음 6대 원칙을 준수해야 함을 명시한다.

| 원칙 | 의미 | 실무 적용 예시 |
| :--- | :--- | :--- |
| **Responsibility (책임)** | IT 의사결정·운영 책임 소재 명확화 | RACI 매트릭스, CIO 직속 보고선, CDO·CISO·DPO 임명 |
| **Strategy (전략)** | IT가 사업 전략에 부합 | 전략 정렬도 측정, IT Strategy Map, OKR 연동 |
| **Acquisition (획득)** | 적절한 IT 획득 의사결정 | IT 투자 포트폴리오, TCO 분석, Make-or-Buy 의사결정 |
| **Performance (성과)** | IT가 서비스 수준·품질·가치 제공 | SLA, IT BSC 4관점 KPI, 사용자 만족도(CSI, Customer Satisfaction Index) |
| **Conformance (적합)** | 법·규정·정책 준수 | SOX 404, ISO 27001, ISMS-P, GDPR/개인정보보호법 |
| **Human Behavior (인적행동)** | IT가 사람·문화를尊重 | 디지털 리터러시, 변화 관리, 직원 경험(EX) |
