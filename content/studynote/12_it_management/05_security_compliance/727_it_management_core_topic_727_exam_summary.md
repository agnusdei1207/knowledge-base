## 핵심 인사이트 (3줄 요약)

> 1. **본질**: IT 경영 관리 핵심 토픽 727번은 COBIT 2019 거버넌스 프레임워크, ITIL 4 서비스 가치 시스템, PMBOK 7th 프로젝트 관리, ISO 27001 정보보안 관리 체계(ISMS), TOGAF ADM 엔터프라이즈 아키텍처, DAMA-DMBOK 데이터 거버넌스 6대 영역을 통합적으로 다루며, 각 영역의 평가·지시·모니터(Evaluate-Direct-Monitor, EDM) 거버넌스 체계와 40개 핵심 관리 프로세스의 상호 연관성을 이해하는 것이 핵심이다.
> 2. **가치**: 통합 IT 경영 체계 구축 시 의사결정 속도 35% 향상, IT 투자 ROI 평균 2.4배 개선, 보안 사고 대응 시간 60% 단축, 프로젝트 성공률(스코프·일정·품목 동시 충족) 28%->72% 향상, 운영 비용(OpEx) 20-30% 절감 효과를 기대할 수 있다.
> 3. **판단 포인트**: 거버넌스-관리-운영의 3계층 분리, Balanced Scorecard 4관점(재무·고객·내부프로세스·학습성장) 기반 KPI 설계, Agile-Waterfall 하이브리드(워터스크럼/스크럼반) 적용 시 프로젝트 규모와 불확실성에 따른 방법론 선택, 클라우드-온프레미스 비용 최적화(CAPEX->OPEX) 및 보안-편의성 트레이드오프의 정량적 의사결정이 핵심 판단 기준이다.

---

## Ⅰ. 개요 및 필요성

정보기술의 단순 운영을 넘어 **전략적 비즈니스 가치 창출**이 요구되는 현대 기업 환경에서, IT 경영 관리는 CFO·CDO·CIO가 공동으로 의사결정하는 핵심 경영 영역으로 진화했다. 727번 토픽은 한국정보통신기술사(정보관리, 정보처리, 컴퓨터시스템응용) 시험에서 빈출하는 **IT 거버넌스-서비스-프로젝트-보안-아키텍처-데이터 6대 핵심 영역**을 통합적으로 다루며, 각 프레임워크의 원리·적용·상호연계 능력을 평가한다.

전통적 IT 관리는 인프라 가용성·장애 대응률 같은 **기술 중심 KPI**에 집중했으나, 디지털 전환(DX) 시대에는 비즈니스 가치·규제 준수·ESG·사이버 회복탄력성을 동시에 만족시켜야 한다. ISO 38500(2008, 2015 개정)이 등장하면서 "기술이 아닌 거버넌스" 패러다임이 확립되었고, COBIT 2019는 40개 governance/management objective를 통해 이 원칙을 구체화했다.

기존에는 COBIT·ITIL·PMBOK이 **각각 독립적 프레임워크**로 운영되어 중복 투자와 책임 공백이 발생했다(예: 변경 관리에서 CAB 운영이 ITIL Change Management와 PMBOK Perform Integrated Change Control이 중복). 727번 토픽은 이를 **단일 거버넌스 체계(Governance System)**로 통합하여 RACI 매트릭스와 단일 KPI 체인을 통해 End-to-End 가시성을 확보하는 데 목적이 있다. 한국에서는 2023년 개인정보보호법 개정, 2024년 클라우드보안인증(CSAP) 강화, 2025년 AI 기본법 시행으로 인해 통합 IT 경영 역량이 더욱 중요해지고 있다.

- **📢 섹션 요약 비유**: IT 경영 관리 6대 영역은 마치 **대형 항공모함의 함교·갑판·엔진·통신·항법·재고 관리 시스템**과 같다. 함교(거버넌스)가 함선 전체의 방향을 결정하고, 갑판(프로젝트)이 항공기 이착륙을 관리하며, 엔진(서비스·인프라)이 동력을, 통신(보안)이 교신을, 항법(아키텍처)이 위치를, 재고관리(데이터)가 연료·탄약을 관리한다. 어느 하나라도 어그러지면 항공모함은 침몰한다.

## Ⅱ. 아키텍처 및 핵심 원리

IT 경영 관리 6대 영역은 **3계층(전략-관리-운영) × 6도메인(거버넌스-서비스-프로젝트-보안-아키텍처-데이터)** 구조로 통합된다. 각 영역은 ISO/IEC 38500의 6원칙(책임·전략·취득·성과·준수·인적행위)을 공통 준거로 삼는다.

```text

|       727번 토픽 핵심 아키텍처: 거버넌스-관리-연계 모델           |
+------------------------------------------------------------------+
|                                                                  |
|   +----------------------------------------------------+        |
|   |  Layer 1: 거버넌스(Governance) - 의사결정권자       |        |
|   |  +----------+  +----------+  +----------+         |        |
|   |  |EDM01     |  |EDM02     |  |EDM03     |         |        |
```

| 구성 요소 | 역할 | 핵심 기술 및 동작 방식 |
| :--- | :--- | :--- |
| **COBIT 2019 Governance System** | IT 거버넌스 최상위 프레임워크 | EDM 5개 목표 + APO/BAI/DSS/MEA 4도메인 35개 관리목표, 7개 컴포넌트(원리·정책·프레임워크·구조·문화·인적·기술), 능력수준 0-5(ISO/IEC 33020 PAM), Focus Area(예: 사이버보안·DevOps·위험) 커스터마이징 |
| **ITIL 4 Service Value System (SVS)** | IT 서비스 관리 및 가치 사슬 | 7단계 가치체인(Plan/Engage/Design&Transition/Obtain/Build/Deliver/Support/Improve) + 34가지 실무활동, 4차원 모델(조직·정보·기술·파트너), Guiding Principles(집중/피드백/자동화 등 7원칙), 서비스 가치 흐름 자동화 |
| **PMBOK 7th / PRINCE2** | 프로젝트·프로그램·포트폴리오 관리 | 8개 Performance Domain(Stakeholder/Team/Development Planning/Project Work/Delivery/Measurement/Uncertainty/Complexity), 12 Principle, 5 Process Group + 49 Input/Output, WBS·EVM·CCB·RACI, 애자일 적응형(Adaptive) |
| **ISO 27001/27002 + ISMS-P** | 정보보안 관리체계 | 93개 통제 항목(4차원: 조직/인적/물리/기술), PDCA(Plan-Do-Check-Act) 7단계, Annex A 93개 통제, 한국 ISMS-P 인증(2024년 11월 신설, 인증기관 21개), K-ISMS + CSAP + PCI-DSS 다중 인증 |
| **TOGAF ADM 10단계** | 엔터프라이즈 아키텍처 수립 | Preliminary->A(비전)->B(비즈니스)->C(데이터/애플리케이션)->D(기술)->E(기회·솔루션)->F(구축계획)->G(구현거버넌스)->H(아키텍처변경)->요구사항관리, ADM Cycle 반복, Architecture Repository(ABB/ABR/ASR/AB) |
| **DAMA-DMBOK 2nd 11개 지식영역** | 데이터 거버넌스 통합 | 6개 데이터 거버넌스 활동(계획/감독/정의/관리/측정/통제) + 11개 영역(거버넌스·아키텍처·모델·저장소·보안·통합·마스터/참조·문서·참조·변형·DW/BI), DCAM·DGI·DAMA Maturity Model |

핵심 작동 원리는 **3가지 연계 메커니즘**으로 요약된다:

1. **Cascade(연쇄 전달)**: 이사회 KPI -> CIO 목표 -> 서비스 KPI -> 프로젝트 KPI -> 운영 KPI로 분해. 예: "매출 10% 성장" -> "신규 디지털 채널 5종 출시" -> "D2C 플랫폼 프로젝트 성공" -> "플랫폼 가용성 99.95%" -> "릴리스 실패율 < 5%"
2. **Alignment(정렬)**: PMBOK의 Benefits Realization Management가 COBIT의 EDM02와, ITIL의 Service Strategy가 COBIT의 APO02(Strategy)와 직접 매핑되어 중복 제거
3. **Feedback Loop(피드백 루프)**: MEA(Monitor-Evaluate-Assess) 도메인이 모든 Layer 1·2 활동에 대해 감사·자체평가·제3자 검토 결과를 피드백하여 지속적 개선

```text
+--------------------------------------------------------------+
|   KPI 연계 사슬 예시 (Cascading Goals & Metrics)             |
+--------------------------------------------------------------+
|                                                              |
|   Level 0: 이사회 -> "디지털 매출 비중 30% 달성(2026)"       |
|       |                                                      |
|       v (CSF: 디지털 서비스 라인업 확대)                     |
|   Level 1: CIO -> "디지털 서비스 출시 8건/년"                |
|       |                                                      |
|       v (CSF: Agile 프로젝트 성공률 제고)                    |
|   Level 2: PMO -> "프로젝트 성공률 75% (Time/Scope/Budget)"  |
|       |                                                      |
|       +-------------+-------------+                          |
|       v             v             v                          |
|   Level 3A:        Level 3B:    Level 3C:                    |
|   서비스매니저     보안팀장    데이터팀장                     |
|   "신규 서비스     "인증 통과  "데이터 품질                  |
|   SLA 99.9%"        100%"       95% 이상"                    |
|       |             |             |                          |
|       v             v             v                          |
|   Level 4: 운영 엔지니어 - 배포 성공률, 패치 적용률, DQ 검증 |
+--------------------------------------------------------------+
```
