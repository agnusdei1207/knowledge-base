## 핵심 인사이트 (3줄 요약)

> 1. **본질**: IT 거버넌스는 **COBIT 2019의 5개 도메인(EDM·APO·BAI·DSS·MEA)·40개 관리목표**와 **정보화 전략 수립(ISP) 5단계 방법론**을 통해 비즈니스-IT 가치 정렬(Business-IT Alignment)을 체계화하는 **이사회-경영진-운영**의 3계층 의사결정 프레임워크이다.
> 2. **가치**: Gartner(2023) 기준 거버넌스 성숙 기업은 **IT 투자 ROI 23% 향상**, **프로젝트 실패율 38%->12% 감소**, **규제 위반 비용 67% 절감**, **Time-to-Market 41% 단축** 효과를 달성하며, 한국 정보시스템감리 사후점검에서 **"우수" 등급 비율이 3.2배** 높다.
> 3. **판단 포인트**: 핵심 트레이드오프는 **①집중형(Centralized) vs 연방형(Federated) 거버넌스 구조**, **②ISO 38500·COBIT·ITIL·CMMI 간 중복 통합 전략**, **③ESG·AI윤리·개인정보보호 규제 대응을 위한 Governance as Code 적용 범위**, **④비용 최적화 vs 민첩성(Agility)·혁신**의 4축 균형점 설정이다.

---

## Ⅰ. 개요 및 필요성

한국 정보관리기술사 시험에서 654번 토픽은 **IT 거버넌스·정보화 전략·IT 성과관리**의 통합 영역을 다룬다. McKinsey(2022) 조사에 따르면 디지털 전환(DX) 이니셔티브의 **70%가 비즈니스 가치 미달**, BCG(2023)는 **31%만이 ROI 흑자**를 기록했으며, CIO Survey(2023, n=3,000+)에서 **"IT-Biz 정렬 부재"**가 1순위 장애요인으로 지목되었다. 또한 개인정보보호법 개정(2023.09, 영상정보·가명정보 도입), AI 기본법 시행(2026.01 예정), EU AI Act(2024), ESG 공시 의무화(KSSB 2025)에 따라 IT 거버넌스는 **단위 시스템 관리에서 전사적 위험·윤리·지속가능성 통합 거버넌스**로 패러다임이 전환되었다.

```text
+------------------------------------------------------------------+
|        IT 경영 관리 654번 토픽 통합 프레임워크 (3-Layer)         |
+------------------------------------------------------------------+

  +-------------------------------------------------------------+
  |  Layer 1: 전략 거버넌스 (Strategic Governance)              |
  |  ---------------------------------------------------------  |
  |  • 정보화 전략 수립(ISP) 5단계: 현황분석->목표설정->            |
  |    전략수립->실행계획->사후관리 (BA, AS-IS, TO-BE, GAP)        |
  |  • COBIT 2019: EDM Domain (5 Goals) - 이사회·경영진         |
  |  • ISO 38500: 6원칙 (책임·전략·획득·성과·준법·인간행위)     |
  |  • 디지털 전환 로드맵: Horizon 1(현재)->2(12개월)->3(36개월)   |
  +-------------------------------------------------------------+
                              v KPI·CSF 연계
  +-------------------------------------------------------------+
  |  Layer 2: 전술적 포트폴리오·프로세스 (Tactical)             |
  |  ---------------------------------------------------------  |
  |  • IT 투자 포트폴리오: Run(70%)/Grow(20%)/Transform(10%)    |
  |  • COBIT APO(Align, Plan, Organize) 14 Goals                |
  |  • BAI(Build, Acquire, Implement) 11 Goals                  |
  |  • 프로젝트 관리: PMO, P3O, MSP, PRINCE2, ISO 21500         |
  |  • 서비스 관리: ITIL 4 (34 Practices, SVS)                  |
  +-------------------------------------------------------------+
                              v SLA·OLA·UC 연계
  +-------------------------------------------------------------+
  |  Layer 3: 운영·위험·컴플라이언스 (Operational)              |
  |  ---------------------------------------------------------  |
  |  • COBIT DSS(Deliver, Service, Support) 6 Goals             |
  |  • COBIT MEA(Monitor, Evaluate, Assess) 4 Goals             |
  |  • IT 거버넌스 위험관리: ISO 31000 + COBIT Risk             |
  |  • 정보보안: ISMS-P, ISO 27001/27701, NIST CSF 2.0          |
  |  • 컴플라이언스: 개인정보보호법, AI기본법, ESG, 클라우드규제  |
  +-------------------------------------------------------------+
                              ^
  +-------------------------------------------------------------+
  |  Cross-Cutting: 아키텍처·데이터·윤리 (EA·Data·Ethics)       |
  |  ---------------------------------------------------------  |
  |  • EA Framework: TOGAF 10 ADM / DoDAF / FEAF                |
  |  • 데이터 거버넌스: DAMA-DMBOK 2.0 (11 영역)                |
  |  • AI 거버넌스: NIST AI RMF, ISO/IEC 42001 (AIMS)          |
  |  • 거버넌스 도구: SAP GRC, Archer, ServiceNow GRC,        |
  |    OpenText, OneTrust                                       |
  +-------------------------------------------------------------+
```

전통적 IT 관리(1990s-2000s)는 **프로젝트 단위 예산 통제·기술 부서 중심**이었으나, IT 거버넌스(2010s~)는 **가치·위험·자원의 균형**, **이사회-경영진-운영의 3계층 의사결정**, **내부통제(Internal Control)**, **규제 대응**을 통합 관리한다. 현재(2024~)는 **AI·ESG·데이터 윤리**를 포함한 **Digital Ethics & Trust Governance**로 진화 중이다.

- **📢 섹션 요약 비유**: IT 거버넌스는 **대형 크루즈선의 항해 시스템**과 같다. 이사회는 **항로(전략)**를 정하고, 선장(CIO)은 **엔진룸·속도·연료(포트폴리오)**를 조정하며, 갑판장(서비스 운영)은 **승객 안전·소화기 점검(컴플라이언스)**을 관리한다. 폭풍(규제·위험)이 칠 때도 배는 방향을 잃지 않는다.

### 2. 핵심 5개 도메인과 관리목표

| 도메인 (코드) | 목표 수 | 역할 | 핵심 관리목표 및 기술 |
| :--- | :---: | :--- | :--- |
| **EDM** (Evaluate, Direct, Monitor) | 5 | 이사회·경영진 거버넌스 의사결정 | EDM01 프레임워크 보장, EDM02 혜택 실현, EDM03 위험 최적화, EDM04 자원 최적화, EDM05 이해관계자 투명성 |
| **APO** (Align, Plan, Organize) | 14 | 전략 정렬·계획·조직 | APO01 Mgt Framework, APO02 Strategy, APO03 Enterprise Architecture, APO04 Innovation, APO05 Portfolio, APO07 인적자원, APO12 위험관리, APO13 보안 |
| **BAI** (Build, Acquire, Implement) | 11 | 솔루션 구축·도입 | BAI01 프로그램, BAI02 요구사항 정의, BAI03 솔루션 설계, BAI08 지식관리, BAI11 변경관리 (Change Mgmt CAB/ECAB) |
| **DSS** (Deliver, Service, Support) | 6 | 운영·서비스·지원 | DSS01 운영관리, DSS02 서비스요청·사고, DSS03 문제관리 (RCA: Kepner-Tregoe, 5-Why, Ishikawa), DSS04 연속성(BCP/DR), DSS06 통제 |
| **MEA** (Monitor, Evaluate, Assess) | 4 | 모니터링·평가·감사 | MEA01 성과·준수 모니터링, MEA02 내부통제 시스템, MEA03 컴플라이언스 외부요구, MEA04 Assurance (감리) |
