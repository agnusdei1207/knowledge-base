## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 정보화 사업 성과측정은 투입(Input)·과정(Process)·산출(Output)·결과(Outcome)·임팩트(Impact)의 5단계 KPI 사슬과 BSC(재무/고객/내부프로세스/학습성장) 관점을 결합하여, 정량·정성 지표를 통합 관리하는 IT 거버넌스 핵심 메커니즘임
> 2. **가치**: 정량 분석 시 평균 ROI 25~40% 개선, 사업 실패율 30%->15% 감소(PMI 2023), 의사결정 속도 2.4배 향상, 정보화사업법 시행령 제51조 및 디지털정부 성과관리 지침 준수
> 3. **판단 포인트**: 단순 재무적 ROI vs 종합적 BSC 접근, 정성지표 주관성 통제(앱지오니/리커트 척도), 측정 시점(착수/중간/완료/사후 1년) 설정, 거버넌스 단계(전략-전술-운영)별 KPI 위계 정렬이 핵심 설계 결정사항

---

## Ⅰ. 개요 및 필요성

국내 정보화 사업은 연평균 약 14조 원 규모(2023년 기준 과학기술정보통신부 정보화진흥기본통계)로 추진되며, '국가정보화 기본법', '정보시스템의 효율적 도입 및 운영에 관한 지침(정보시스템 감리기준)', '디지털정부법', '클라우드컴퓨팅법' 등 다층적 법·제도적 통제 하에 진행됨. 그러나 정성사업의 특성상 투입 대비 산출의 인과관계가 불명확하고, 성과 측정이 단기 산출물(산출지표)에 편중되어 국민 체감도·사회적 가치·정책 효과(결과·임팩트 지표)까지 연계되지 못하는 문제가 지속 발생.

이에 2022년 행정안전부 '디지털정부 성과관리 시행지침'과 2023년 과학기술정보통신부 '정보화 사업 성과측정 가이드라인(개정판)'은 성과측정 체계를 **4단계(산출->결과->임팩트->사회적 가치)**로 고도화하고, **BSC 기반 KPI 위계화**와 **데이터 기반 성과관리(Data-Driven Performance Management)**를 핵심 요구사항으로 명시함.

```text
[정보화 사업 성과측정 패러다임 전환]
+-------------------------+         +-------------------------+
|  PARADIGM 1.0 (1990s~)  |         |  PARADIGM 2.0 (2015~)   |
|   - 투입(Input) 중심    |   ---►  |   - 산출·결과·임팩트    |
|   - 예산집행률 위주     |         |   - BSC 4관점 통합     |
|   - 정성평가 (A/B/C)    |         |   - 정량지표 70% 이상   |
|   - 연 1회 사후 평가    |         |   - 실시간 모니터링    |
+-------------------------+         +-------------------------+
                                              |
                                              v
                                   +-------------------------+
                                   |  PARADIGM 3.0 (2022~)   |
                                   |  - 사회적 가치 측정    |
                                   |  - ESG·SDGs 연계       |
                                   |  - AI 기반 예측 분석   |
                                   |  - 다부서·다사업 연계  |
                                   +-------------------------+
```

**구 vs 신 패러다임 비교**:
- **기존**: "예산을 얼마나 계획대로 썼는가?" (Input·Process 지표 중심), 사업 완료 후 단발적 성과보고서 제출, 주관적 A/B/C 등급 부여
- **신규**: "국민·사용자가 체감하는 가치가 창출되었는가?" (Outcome·Impact 지표 필수, 정보화사업법 시행령 제51조 4항), 사업 전 과정(착수-중간-완료-사후 1년-사후 3년) 5단계 측정, OKR·BSC·성과관리카드 통합 활용

- **📢 섹션 요약 비유**: 기존 성과관리가 "시험 점수만 매기는 것"이었다면, 신 패러다임은 "수업 참여도·협업 능력·창의성·자기주도성까지 종합 평가하는 루브릭 평가"로 전환된 것

## Ⅱ. 아키텍처 및 핵심 원리

정보화 사업 성과측정 시스템은 **3계층 아키텍처**(전략-전술-운영 계층)와 **4단계 KPI 체인**(Input->Output->Outcome->Impact)으로 구성됨. 각 계층은 COBIT 2019의 거버게런스/관리 목표(EDM·APO·BAI·DSS·MEA)와 매핑되며, ISO/IEC 38500 IT 거버넌스 표준의 6원칙(책임·전략·취득·성과·규율·인간행위)과 연계됨.

```text
[성과측정 3계층 아키텍처와 4단계 KPI 체인]
+--------------------------------------------------------------+
| Tier 1: 전략 계층 (Strategic Level) - CIO·경영위원회          |
|  +---------------------------------------------------------+  |
|  |  임팩트 KPI: 사회적 가치, 정책 효과, ROI               |  |
|  |  ↕ (연계)                                             |  |
|  |  결과 KPI: 서비스 만족도(CSI), 업무 효율화율, 민원    |  |
|  |             처리시간 단축율                            |  |
|  +---------------------------------------------------------+  |
|                          ↕                                   |
| Tier 2: 전술 계층 (Tactical Level) - 사업관리자(PM), PL      |
|  +---------------------------------------------------------+  |
|  |  산출 KPI: 시스템 가용률(%), 결함밀도(Defect/KLOC),    |  |
|  |           일정 준수율(SPI), 예산 소진율(CPI)          |  |
|  |  ↕ (연계)                                             |  |
|  |  투입 KPI: 투입공수(MM), 예산(원), 인력(명)           |  |
|  +---------------------------------------------------------+  |
|                          ↕                                   |
| Tier 3: 운영 계층 (Operational Level) - 실무자, 개발자      |
|  +---------------------------------------------------------+  |
|  |  활동지표: 코드 커밋 수, 테스트 커버리지(%),          |  |
|  |           WIP(Work In Progress), 응답시간(ms)          |  |
|  +---------------------------------------------------------+  |
+--------------------------------------------------------------+
         ↕ (실시간/주기적 데이터 연동) ↕
+--------------------------------------------------------------+
| 통합 성과관리 플랫폼 (e-PMS, e-성능관리 시스템)              |
|  - 데이터 수집: APM, ITSM, BI, 설문조사, 로그 분석          |
|  - 분석 엔진: BI(Business Intelligence), AI 예측 모델        |
|  - 시각화: 대시보드, GRC 대시보드, 자동 리포팅              |
+--------------------------------------------------------------+
```

| 구성 요소 | 역할 | 핵심 기술 및 동작 방식 |
| :--- | :--- | :--- |
| **KPI 위계화 모듈** | 전략-전술-운영 KPI 매핑 및 인과관계 정의 | Strategy Map(BSC 4관점), KPI Tree(상위-하위 분해), WEIF(World Economic Impact Factor) 기법 활용, 평균 인과 사슬 깊이 3~4단계로 설계 |
| **데이터 수집·통합 계층** | 정량/정성 데이터 ETL 처리 | ETL 도구(Apache NiFi, Informatica), API Gateway(Kong, Apigee), RPA(UiPath), 설문 시스템(Qualtrics, Naver Form), APM(Dynatrace, Scouter) |
| **성과 분석 엔진** | 정량 분석·AI 예측·벤치마킹 | 통계 분석(SPSS, R), ML 모델(XGBoost, RandomForest), 몬테카를로 시뮬레이션, AHP(Analytic Hierarchy Process) 가중치 산정, DEA(Data Envelopment Analysis) 상대효율성 측정 |
| **성과관리 대시보드** | 실시간 KPI 모니터링·드리프트 탐지·리포팅 자동화 | BI 도구(Tableau, Power BI, Superset), GRC 플랫폼(Archer, Rsam), 자동 알람(Anomaly Detection, Z-Score 2σ 기준), 모바일 대시보드(KPIs Mobile App) |
| **거버넌스·리뷰 위원회** | 정성평가·의사결정·환류 | PDCA(Plan-Do-Check-Act) 회의, 사업심의위원회(분기 1회), 성과연계형 예산편성(Performance-Based Budgeting, PBB), 차기 사업 투자우선순위 재조정 |

**핵심 산식 및 파라미터**:

- **ROI(투자대비성과)**: ROI(%) = (총편익 - 총비용) / 총비용 × 100, 할인율 적용 시 5~7% (한국은행 기준금리 + 위험프리미엄), B/C(Benefit-Cost) Ratio ≥ 1.0 기준
- **NPV(순현재가치)**: NPV = Σ[Bₜ/(1+r)ᵗ] - C₀, 사회적 할인율 4.5% (KDI guideline), 사업기간 보통 5~7년
- **IRR(내부수익률)**: NPV=0이 되는 r 값, 사회적 할인율 4.5% 이상 시 사업 채택
- **BCR(Benefit-Cost Ratio)**: 편익/비용 비율, 1.0 이상 시 경제성 있음
- **EVM(Earned Value Management) 핵심 지표**:
  - CPI(Cost Performance Index) = EV/AC, ≥0.95 양호, <0.9 적색
  - SPI(Schedule Performance Index) = EV/PV, ≥0.95 양호, <0.9 적색
  - TCPI(To-Complete Performance Index) = (BAC-EV)/(BAC-AC)
- **BSC 4관점 가중치 표준**: 재무 25% / 고객 30% / 내부프로세스 30% / 학습성장 15% (정부 BSC 가이드 표준안, 조정 가능)
- **CSI(고객만족지수)**: ACSI(American Customer Satisfaction Index) 모형 적용, 잠재변수 7개, 관측변수 14개 항목, 5점 또는 7점 리커트 척도
- **성과측정 시점**: 착수(기준선 Baseline) -> 중간(분기별) -> 완료(1차) -> 사후 1년(안정화) -> 사후 3년(장기효과) 5단계

- **📢 섹션 요약 비유**: KPI 체인은 "회계의 시재표 + 헬스케어의 종합검진 + 교육의 루브릭 평가"를 융합한 것이라고 보면 됨. 마치 의사가 단순 체중만이 아니라 혈당·콜레스테롤·BMI·생활습관까지 종합 진단하듯, 성과측정도 다면적 지표가 필수

## Ⅲ. 비교 및 연결

| 구분 | BSC(Balanced Scorecard) | OKR(Objectives & Key Results) | KPI(Key Performance Indicator) | EVA(Economic Value Added) |
| :--- | :--- | :--- | :--- | :--- |
| **개발 주체/연도** | Kaplan & Norton, 1992 | Andy Grove(Intel) -> Google, 1999 | 전통적 관리회계 기법 | Stern Stewart & Co., 1991 |
| **핵심 철학** | 4관점 균형(재무·고객·프로세스·학습) | 도전적 목표 + 측정 가능한 핵심결과 | 핵심 성과지표 단일 측정 | 경제적 부가가치 창출 |
| **측정 정밀도** | 정성+정량 혼합 (4관점) | 정량 중심 (KR은 0~1.0 측정) | 정량 단일 지표 | 정량 1개 (NOPAT-자본비용) |
| **목표 달성률** | 보통 100% (실현 가능 목표) | 0.6~0.7 권장 (도전적 목표) | 100% 이상 (계약적 목표) | 양수 시 가치창출 |
| **측정 주기** | 분기/반기 | 분기 (3개월 단위) | 월/분기/연 | 월/분기/연 |
| **적합 환경** | 공공·대기업·전략적 사업 | 스타트업·혁신 조직·공공 R&D | 운영·모니터링·감리 | 수익성 중심·주주 가치 |
| **정보화사업 적용** | ⭐⭐⭐⭐⭐ (디지털정부 표준) | ⭐⭐⭐ (혁신사업·R&D) | ⭐⭐⭐⭐ (전 사업 필수) | ⭐⭐ (수익성 사업 한정) |
| **한계점** | 인과관계 입증 어려움, 4관점 고정 | 성과급 직접 연계 부적합, 단기 편중 | 핵심지표 선정 주관성, 게리밍(Gaming) 가능 | 무형자산 반영 미흡, 자본비용 산정 난이도 |

**연계 관계도**:
- **BSC × OKR**: BSC의 4관점(Strategy Map) 안에 OKR을 배치 (예: "고객 관점" OKR: "민원처리시간 50% 단축" - Objective, "KR: 평균처리시간 3일->1.5일")
- **BSC × KPI**: BSC의 각 관점별 핵심 측정값이 곧 KPI (예: 재무관점 KPI = "투자수익률(ROI) ≥ 20%")
- **COBIT 2019 × 성과측정**: COBIT의 40개 관리목표가 성과측정 프레임워크의 제어항목(Control Objectives)으로 활용, MEA(Monitor, Evaluate, Assess) 도메인이 성과측정 엔진 역할
- **ISO 21500(Project Management) × 성과측정**: 10개 지식영역(통합·범위·일정·비용·품질·자원·통신·위험·조달·이해관계자)별 KPI 표준화
