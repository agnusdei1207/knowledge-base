## 핵심 인사이트 (3줄 요약)
> 1. **본질**: 데이터 패브릭(Data Fabric)은 이기종 데이터 소스를 활성 메타데이터(Active Metadata)와 지식 그래프로 자동 연결하여, 사용자에게 단일 통합 뷰를 제공하는 기술 중심 아키텍처이다.
> 2. **가치**: 수동 ETL·통합 작업의 70% 이상을 자동화하고, 데이터 발견·접근·거버넌스를 실시간으로 지원하여 Time-to-Insight를 획기적으로 단축한다.
> 3. **판단 포인트**: 활성 메타데이터 엔진의 성숙도가 패브릭 효과를 좌우하며, 메타데이터 수집 범위가 좁으면 자동화 품질이 급격히 저하된다.

---

## Ⅰ. 개요 및 필요성

기업 데이터 환경은 온프레미스 RDBMS, 클라우드 레이크, SaaS API 등 수십~수백 개 이기종 소스로 분산되어 있다. 데이터 패브릭은 이 복잡성을 메타데이터 자동화로 해결한다.

```text
┌──────────────────────────────────────────────────┐
│         데이터 패브릭 필요성                        │
│                                                   │
│  [RDBMS] [NoSQL] [SaaS] [Lake] [API] [IoT]       │
│      │      │      │      │     │     │           │
│      └──────┴──────┴──┬───┴─────┴─────┘           │
│                       ▼                            │
│         ┌──────────────────────┐                   │
│         │ 활성 메타데이터 엔진   │                   │
│         │ (자동 발견·매핑·추천) │                   │
│         └──────────┬───────────┘                   │
│                    ▼                               │
│         ┌──────────────────────┐                   │
│         │  통합 데이터 뷰        │                   │
│         └──────────────────────┘                   │
└──────────────────────────────────────────────────┘
```

📢 **섹션 요약 비유**: 데이터 패브릭은 도서관의 자동 분류 시스템이다. 새 책(데이터)이 들어오면 AI가 자동으로 장르·저자·관련 도서를 분류하고, 사용자가 검색하면 즉시 관련 자료를 추천한다.

## Ⅱ. 아키텍처 및 핵심 원리

### 2.1 데이터 패브릭 7대 핵심 구성 요소

| 구성 요소 | 역할 | 대표 기술 |
|:---|:---|:---|
| **활성 메타데이터(Active Metadata)** | 메타데이터 자동 수집·분석·추천 | Alation, Collibra, Atlan |
| **지식 그래프(Knowledge Graph)** | 데이터 관계를 시맨틱 그래프로 모델링 | Neo4j, TigerGraph |
| **데이터 가상화(Data Virtualization)** | 물리적 이동 없이 통합 쿼리 | Denodo, Dremio |
| **데이터 통합(Data Integration)** | ETL/ELT 자동화 파이프라인 | Informatica, Fivetran |
| **데이터 카탈로그(Data Catalog)** | 검색·태깅·분류 | DataHub, OpenMetadata |
| **데이터 거버넌스(Data Governance)** | 정책·접근 제어·컴플라이언스 | Apache Atlas, Purview |
| **데이터 보안(Data Security)** | 암호화·마스킹·접근 권한 | Privacera, Immuta |

```text
┌─────────────────────────────────────────────────────┐
│            데이터 패브릭 계층 아키텍처                  │
├─────────────────────────────────────────────────────┤
│  ┌────────────────────────────────────────────────┐ │
│  │     소비 계층: BI · ML · App · Self-Service     │ │
│  └──────────────────────┬─────────────────────────┘ │
│  ┌──────────────────────▼─────────────────────────┐ │
│  │   활성 메타데이터 엔진 + 지식 그래프              │ │
│  │   (자동 매핑·추천·계보 추적·품질 모니터링)        │ │
│  └──────────────────────┬─────────────────────────┘ │
│  ┌──────────────────────▼─────────────────────────┐ │
│  │   데이터 가상화 + 통합 계층                      │ │
│  │   (물리 이동 최소화, 실시간 연합 쿼리)            │ │
│  └──────────────────────┬─────────────────────────┘ │
│  ┌──────────────────────▼─────────────────────────┐ │
│  │   이기종 데이터 소스 (On-Prem · Cloud · SaaS)    │ │
│  └────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────┘
```

📢 **섹션 요약 비유**: 활성 메타데이터 엔진은 스마트폰의 AI 사진 분류 기능과 같다. 사진을 찍으면 자동으로 사람·장소·사물을 인식해 앨범을 정리하듯, 데이터가 들어오면 자동으로 관계·품질·계보를 파악한다.

## Ⅲ. 비교 및 연결

| 비교 항목 | 데이터 패브릭(Data Fabric) | 데이터 메시(Data Mesh) |
|:---|:---|:---|
| **핵심 동인** | 기술 자동화 | 조직 분권화 |
| **메타데이터** | 중앙 자동 수집·통합 | 도메인별 자율 관리 |
| **거버넌스** | 중앙 집중 + 자동 시행 | 연합형 합의 기반 |
| **데이터 이동** | 가상화로 최소화 | 데이터 제품 간 표준 API |
| **조직 변화 필요도** | 낮음 (기술 도입) | 높음 (조직 재편) |

📢 **섹션 요약 비유**: 패브릭은 자동 번역기(기술로 해결), 메시는 각국 대사관 체계(조직으로 해결)이다. 이상적으로는 대사관에 자동 번역기를 설치하는 것이 최선이다.

## Ⅳ. 실무 적용 및 기술사 판단

### 체크리스트
1. 활성 메타데이터 엔진이 전체 데이터 소스의 80% 이상을 커버하는가?
2. 지식 그래프가 데이터 간 관계를 자동으로 추론하는가?
3. 데이터 가상화 계층의 쿼리 응답 시간이 SLA 내인가?
4. 거버넌스 정책이 자동 시행(Policy-as-Code)되는가?
5. 데이터 소비자가 셀프서비스로 데이터를 발견·접근할 수 있는가?

### 안티패턴
- 메타데이터 수집 범위가 일부 소스에 한정 → 통합 뷰 불완전
- 가상화 레이어에 과도한 쿼리 집중 → 성능 병목
- 거버넌스 자동화 없이 수동 정책 운영 → 컴플라이언스 누락
- 지식 그래프 갱신 주기가 느림 → 관계 정보 진부화

📢 **섹션 요약 비유**: 자동 분류 시스템이 도서관 일부 서가만 커버하면, 나머지 서가는 여전히 미로로 남는다.

---

## Ⅴ. 기대효과 및 결론

데이터 패브릭은 데이터 통합·거버넌스·보안의 자동화를 통해 데이터 활용 속도를 비약적으로 높인다. 궁극적으로 데이터 메시와 결합하여 조직적 분산과 기술적 자동화를 동시에 달성하는 것이 최적 아키텍처이다.

📢 **섹션 요약 비유**: 최고의 도서관은 자동 분류(패브릭)와 사서의 전문성(메시)이 결합된 곳이다.

| 개념 | 연결 포인트 |
|:---|:---|

| 활성 메타데이터(Active Metadata) | 패브릭의 핵심 엔진 |

### 📈 관련 키워드 및 발전 흐름도

```text
데이터 통합 아키텍처 진화
    ├─► 수동 ETL → 자동 ETL/ELT → 데이터 가상화
    ├─► 수동 메타데이터 → 활성 메타데이터 → AI 기반 추천
    ├─► 데이터 카탈로그 → 지식 그래프 → 시맨틱 레이어
    └─► Data Fabric + Data Mesh = 차세대 통합 아키텍처
```
