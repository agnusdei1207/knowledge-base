## 핵심 인사이트 (3줄 요약)

> 1. **본질**: DFS (Depth-First Search)는 한 방향으로 갈 수 있는 끝까지 파고든 뒤 역추적 ([Backtracking](/studynote/08_algorithm_stats/01_basics/010_backtracking/))하여 다른 경로를 탐색하는 [그래프](/studynote/08_algorithm_stats/04_datastructure/070_graph_datastructure/)/트리 탐색 [알고리즘](/studynote/08_algorithm_stats/01_basics/001_algorithm_definition/)이다.
> 2. **가치**: [재귀](/studynote/08_algorithm_stats/01_basics/014_recursion/) 또는 [스택](/studynote/08_algorithm_stats/04_datastructure/057_stack/)으로 구현이 간단하고 O(V+E) 시간에 [위상 정렬](/studynote/08_algorithm_stats/03_graph_search/039_topological_sort/) ([Topological Sort](/studynote/08_algorithm_stats/03_graph_search/039_topological_sort/)), [강연결 요소](/studynote/08_algorithm_stats/03_graph_search/040_scc/) ([SCC](/studynote/08_algorithm_stats/03_graph_search/040_scc/)), 사이클 검출, 미로 탈출 등 다양한 문제를 해결한다.
> 3. **판단 포인트**: 최단 경로에는 BFS를, 전체 경로 탐색·[위상 정렬](/studynote/08_algorithm_stats/03_graph_search/039_topological_sort/)·SCC에는 DFS를 선택하며, [재귀](/studynote/08_algorithm_stats/01_basics/014_recursion/) 깊이가 깊으면 [스택](/studynote/08_algorithm_stats/04_datastructure/057_stack/) [오버플로우](/studynote/01_computer_architecture/02_data_representation_arithmetic/095_overflow/)에 주의한다.

## Ⅰ. 개요 및 필요성

깊이 우선 탐색 (DFS, Depth-First Search)은 [그래프](/studynote/08_algorithm_stats/04_datastructure/070_graph_datastructure/)의 한 정점에서 출발해 인접 정점을 방문할 때 가능한 한 깊게 들어가고, 더 이상 갈 곳이 없으면 역추적하여 탐색하지 않은 다른 경로를 탐색하는 방법이다.

| 특성 | 내용 |
|:---|:---|
| [시간 복잡도](/studynote/08_algorithm_stats/01_basics/002_time_complexity/) | O(V+E) |
| [공간 복잡도](/studynote/08_algorithm_stats/01_basics/003_space_complexity/) | O(V) (방문 [배열](/studynote/08_algorithm_stats/04_datastructure/055_array/) + [스택](/studynote/08_algorithm_stats/04_datastructure/057_stack/)/[재귀](/studynote/08_algorithm_stats/01_basics/014_recursion/)) |
| 구현 방식 | [재귀](/studynote/08_algorithm_stats/01_basics/014_recursion/) ([Recursion](/studynote/08_algorithm_stats/01_basics/014_recursion/)) 또는 명시적 [스택](/studynote/08_algorithm_stats/04_datastructure/057_stack/) ([Stack](/studynote/08_algorithm_stats/04_datastructure/057_stack/)) |
| [데이터](/studynote/05_database/01_db_architecture_relational/001_dikw_pyramid/) 구조 | [스택](/studynote/08_algorithm_stats/04_datastructure/057_stack/) (LIFO) |

DFS가 필요한 상황:

- [위상 정렬](/studynote/08_algorithm_stats/03_graph_search/039_topological_sort/) ([Topological Sort](/studynote/08_algorithm_stats/03_graph_search/039_topological_sort/)): DAG에서 작업 순서 결정
- [강연결 요소](/studynote/08_algorithm_stats/03_graph_search/040_scc/) ([SCC](/studynote/08_algorithm_stats/03_graph_search/040_scc/), Strongly Connected Components) 탐색
- 사이클 검출 (Cycle [Detection](/studynote/09_security/19_ai_advanced_security/961_deepfake_detection/))
- 미로 탈출, 퍼즐 풀이, [백트래킹](/studynote/08_algorithm_stats/01_basics/010_backtracking/) 기반 탐색
- DFS 트리의 간선 [분류](/studynote/16_bigdata/05_analysis/104_classification_analysis/) (트리 간선, 역방향 간선)

📢 **섹션 요약 비유**: DFS는 미로에서 오른손을 벽에 대고 계속 따라가는 방법이다. 막다른 골목이면 왔던 길로 돌아가 다른 방향을 시도한다.

## Ⅱ. 아키텍처 및 핵심 원리

### 기본 동작 순서

```
그래프:  A — B — D
         |       |
         C ———— E

DFS 시작: A

방문 순서:
  A 방문 -> B 탐색
  B 방문 -> D 탐색
  D 방문 -> E 탐색
  E 방문 -> C 탐색
  C 방문 -> 이미 방문한 A만 남음 -> 역추적
  최종: A -> B -> D -> E -> C
```

### [ASCII](/studynote/01_computer_architecture/02_data_representation_arithmetic/103_ascii/) 다이어그램 — DFS [스택](/studynote/08_algorithm_stats/04_datastructure/057_stack/) [진행](/studynote/02_operating_system/03_cpu_scheduling/216_progress_in_synchronization/)

```
+--------------------------------------------------------+
|  그래프:  A - B - D       DFS 스택 변화:               |
|           |       |                                    |
|           C ----- E       초기:    [A]                 |
|                           A 팝:    [] -> 방문A -> [C, B]  |
|  탐색 순서:                B 팝:    [C] -> 방문B -> [C, D] |
|  A -> B -> D -> E -> C       D 팝:    [C] -> 방문D -> [C, E] |
|                           E 팝:    [C] -> 방문E -> [C]    |
|  방문: ✓ A ✓ B ✓ D        C 팝:    [] -> 방문C -> []       |
|        ✓ E ✓ C            완료!                         |
+--------------------------------------------------------+
```

### DFS 간선 [분류](/studynote/16_bigdata/05_analysis/104_classification_analysis/) (방향 [그래프](/studynote/08_algorithm_stats/04_datastructure/070_graph_datastructure/))

DFS 수행 중 발견되는 간선의 종류:

| 간선 종류 | 설명 | 의미 |
|:---|:---|:---|
| 트리 간선 (Tree Edge) | DFS 트리를 구성하는 간선 | 새 정점 발견 |
| 역방향 간선 (Back Edge) | 조상으로 향하는 간선 | 사이클 존재 |
| 순방향 간선 ([Forward](/studynote/10_ai/03_llm_nlp/235_forward_backward_chaining/) Edge) | 자손으로 향하는 간선 | 방향 [그래프](/studynote/08_algorithm_stats/04_datastructure/070_graph_datastructure/) |
| 교차 간선 (Cross Edge) | 무관한 부분 트리 간 간선 | 방향 [그래프](/studynote/08_algorithm_stats/04_datastructure/070_graph_datastructure/) |

**역방향 간선 (Back Edge) 존재 = 사이클 존재**

### DFS 방문 시간 (Discovery/Finish Time)

```
각 정점에 발견 시간 d[v]와 완료 시간 f[v]를 기록
-> 위상 정렬: f[v] 내림차순 = 위상 정렬 순서
-> SCC: f[v]를 이용해 강연결 요소 식별 (코사라주 알고리즘)
```

📢 **섹션 요약 비유**: DFS의 역방향 간선은 조상의 발을 다시 밟는 것과 같다. 조상을 다시 밟으면 사이클이 있다는 증거다.

## Ⅲ. 비교 및 연결

### DFS vs [BFS](/studynote/08_algorithm_stats/03_graph_search/035_bfs/)

| 항목 | DFS | [BFS](/studynote/08_algorithm_stats/03_graph_search/035_bfs/) |
|:---|:---:|:---:|
| [데이터](/studynote/05_database/01_db_architecture_relational/001_dikw_pyramid/) 구조 | [스택](/studynote/08_algorithm_stats/04_datastructure/057_stack/) (LIFO) | 큐 ([FIFO](/studynote/02_operating_system/04_synchronization/261_fifo_page_replacement/)) |
| 탐색 방식 | 깊이 우선 | 너비 우선 |
| 최단 경로 | 보장 안 됨 | 보장 (비가중치) |
| [공간 복잡도](/studynote/08_algorithm_stats/01_basics/003_space_complexity/) | O(V) [재귀](/studynote/08_algorithm_stats/01_basics/014_recursion/) 깊이 | O(V) 큐 크기 |
| [위상 정렬](/studynote/08_algorithm_stats/03_graph_search/039_topological_sort/) | 가능 (역후위 순서) | 가능 (Kahn's) |
| 사이클 검출 | 역방향 간선 | 방문 여부 [확인](/studynote/04_software_engineering/12_testing_maintenance/396_validation/) |
| 미로/[백트래킹](/studynote/08_algorithm_stats/01_basics/010_backtracking/) | 적합 | 부적합 |
| 최단 경로 탐색 | 부적합 | 적합 |

📢 **섹션 요약 비유**: DFS는 한 우물을 끝까지 파는 광부, BFS는 지층별로 수평으로 넓게 파는 광부다. 금이 깊이 있으면 DFS, 가장 가까운 금을 찾으려면 BFS다.

## Ⅴ. 기대효과 및 결론

DFS (Depth-First Search)는 O(V+E)의 효율로 사이클 검출, [위상 정렬](/studynote/08_algorithm_stats/03_graph_search/039_topological_sort/), [SCC](/studynote/08_algorithm_stats/03_graph_search/040_scc/) 분해 등 [그래프](/studynote/08_algorithm_stats/04_datastructure/070_graph_datastructure/) 분석의 핵심 연산을 수행한다. [재귀](/studynote/08_algorithm_stats/01_basics/014_recursion/)로 구현이 우아하지만 깊은 [그래프](/studynote/08_algorithm_stats/04_datastructure/070_graph_datastructure/)에서는 명시적 [스택](/studynote/08_algorithm_stats/04_datastructure/057_stack/)을 사용하여 [스택](/studynote/08_algorithm_stats/04_datastructure/057_stack/) [오버플로우](/studynote/01_computer_architecture/02_data_representation_arithmetic/095_overflow/)를 방지해야 한다.

**핵심 결론**: DFS는 "끝까지 파고드는 분석"의 [알고리즘](/studynote/08_algorithm_stats/01_basics/001_algorithm_definition/)이다. 경로 존재 여부, 사이클, 위상 순서 모두 DFS 한 번으로 해결할 수 있다.

📢 **섹션 요약 비유**: DFS는 소설을 처음부터 끝장까지 한 챕터씩 읽는 것과 같다. 중간에 끝이 막히면 이전 챕터로 돌아가 다른 가지를 탐색한다. 반면 BFS는 모든 챕터의 첫 페이지를 먼저 읽고 두 번째 페이지를 읽는 것이다.

### 📌 관련 개념 맵

|:---|:---|:---|

| [SCC](/studynote/08_algorithm_stats/03_graph_search/040_scc/) (Strongly Connected Components) | 응용 | 코사라주/타잔 [알고리즘](/studynote/08_algorithm_stats/01_basics/001_algorithm_definition/) |
| [백트래킹](/studynote/08_algorithm_stats/01_basics/010_backtracking/) ([Backtracking](/studynote/08_algorithm_stats/01_basics/010_backtracking/)) | 확장 | DFS + [가지치기](/studynote/01_computer_architecture/12_accelerators_ai_hardware/435_pruning_hardware/) |

| IDDFS (Iterative Deepening DFS) | 변형 | 깊이 제한 반복 DFS |

### 📈 관련 키워드 및 발전 흐름도

```text
[BFS (Breadth-First Search)]
    |
    v
[위상 정렬 (Topological Sort)]
    |
    v
[SCC (Strongly Connected Components)]
    |
    v
[백트래킹 (Backtracking)]
    |
    v
[사이클 검출 (Cycle Detection)]
```

이 흐름도는 [BFS](/studynote/08_algorithm_stats/03_graph_search/035_bfs/) (Breadth-First Search)에서 출발해 사이클 검출 (Cycle [Detection](/studynote/09_security/19_ai_advanced_security/961_deepfake_detection/))까지 이어지며, 중간 단계가 기초 개념을 실무 구조로 발전시키는 과정을 보여준다.

### 👶 어린이를 위한 3줄 비유 설명

1. 🌳 DFS는 나무 타기처럼 제일 높은 가지까지 올라갔다가 내려와서 다른 가지로 옮기는 방식이다.
2. 🧩 미로에서 오른손을 벽에 붙이고 계속 걸어가면 결국 출구를 찾게 되는 것처럼, DFS도 막힐 때까지 직진하다가 돌아온다.
3. 📚 가장 먼저 찾은 경로가 꼭 가장 짧은 경로는 아니다 — 미로에서 돌아가는 길을 찾을 수도 있다.
