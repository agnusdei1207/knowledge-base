## 핵심 인사이트 (3줄 요약)

> 1. **본질**: FDM은 주파수 대역을 나누어 여러 신호가 동시에 통신하도록 하는 [[071_다중화_Multiplexing|다중화]] 방식이다.
> 2. **가치**: 아날로그 통신과 [[054_반송파_Carrier_Wave|반송파]] 할당에 적합하다.
> 3. **판단**: [[140_bandwidth|대역폭]] 분할과 가드 밴드 개념이 핵심이다.

---

## Ⅰ. 개요 및 필요성

하나의 매체에서 여러 신호를 동시에 보내고 싶다면 주파수를 나누면 된다.

그 방식이 FDM이다.

- **📢 섹션 요약 비유**: 한 도로를 차선별로 나누는 것이다.

---

## Ⅱ. 아키텍처 및 핵심 원리

```text
Freq Band 1
Freq Band 2
Freq Band 3
```

| 요소 | 의미 |
| :-- | :-- |
| Carrier | [[054_반송파_Carrier_Wave|반송파]] |
| [[140_bandwidth|Bandwidth]] | [[140_bandwidth|대역폭]] |
| [[946_guard_band_fdm_adjacent_channel_interference|Guard Band]] | [[074_보호_대역_Guard_Band|보호 대역]] |

FDM은 각 신호를 서로 다른 주파수 대역에 배치해 동시에 전송한다.

- **📢 섹션 요약 비유**: 서로 다른 층에 방을 배정하는 것이다.

---

## Ⅲ. 비교 및 연결

| 방식 | 기준 | 특징 |
| :-- | :-- | :-- |
| FDM | 주파수 | 동시 전송 |
| TDM | 시간 | 순차 전송 |
| OFDM | 직교 주파수 | 고효율 |

| 장점 | 의미 |
| :-- | :-- |
| Simultaneous | [[014_concurrency|동시성]] |
| Analog Friendly | 아날로그 친화 |

FDM은 TDM이나 OFDM과 함께 비교되어 이해된다.

- **📢 섹션 요약 비유**: 각자 다른 색의 길을 달리는 것이다.

---

## Ⅳ. 실무 적용 및 기술사 판단

### [[435_checklist_based_testing|체크리스트]]

1. 주파수 대역을 나누는가?
2. 가드 밴드를 고려하는가?
3. [[054_반송파_Carrier_Wave|반송파]] 개념을 아는가?
4. TDM/OFDM과 비교하는가?
5. 아날로그 통신과 연결하는가?

### [[128_water_scrum_fall_anti_pattern|안티패턴]]

- 주파수 간섭을 무시하는 설계
- 가드 밴드를 생략하는 설계
- 시간 분할과 혼동하는 설계
- [[140_bandwidth|대역폭]] 계산 없이 [[071_다중화_Multiplexing|다중화]]하는 설계

기술사 관점에서는 FDM을 "주파수 대역 분할 [[071_다중화_Multiplexing|다중화]]"로 설명해야 한다.

- **📢 섹션 요약 비유**: 선로를 색깔별로 나눠 달리는 것이다.

---

## Ⅴ. 기대효과 및 결론

FDM은 여러 신호를 동시에 전송할 수 있게 한다.

결론적으로 FDM은 주파수 대역을 나누는 [[071_다중화_Multiplexing|다중화]] 방식이다.

- **📢 섹션 요약 비유**: 각자 다른 차선에서 달린다.
