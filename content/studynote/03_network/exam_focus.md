## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 네트워크는 시스템 간 연결성, 가용성, 보안을 동시에 설계해야 하는 대표적 통합 과목이다.
> 2. **가치**: 라우팅, 전송, 보안, 데이터센터 구조를 묶어 설명할 수 있어야 대형 서술 문제 대응력이 생긴다.
> 3. **판단 포인트**: 제로 트러스트(Zero Trust), 소프트웨어 정의 네트워크(SDN), 5세대 이동통신(5G) 이후 구조를 연결하는 시각이 중요하다.

## Ⅰ. 과목 개요

- 추천 핵심 키워드 목표 수: `320개`

## Ⅱ. 왜 시험 핵심인가

- 서비스 장애, 보안 사고, 성능 저하를 가장 직접적으로 체감하는 영역이라 시스템 적용형 문제가 자주 나온다.
- 단순 프로토콜 암기보다 계층별 원인 분석, 구간별 병목 분리, 제어 평면(Control Plane)과 데이터 평면(Data Plane) 구분이 채점 포인트다.
- 클라우드, 데이터센터, 사물인터넷(IoT), 이동통신까지 확장성이 커 다른 과목과 연계 출제가 쉽다.
- 응용기술사 답안에서는 네트워크 설계 원리와 운영 자동화, 보안 통제를 함께 제시해야 완성도가 높다.

## Ⅳ. 단답형 / 서술형 분리 포인트

- 단답형: 주소 체계, 라우팅 프로토콜, 혼잡 제어, 가상사설망(VPN), 침입방지시스템(IPS) 등 용어와 기능 차이 정리
- 서술형: 지연시간, 가용성, 보안성 요구를 기준으로 망 구조와 프로토콜 선택 이유를 비교형으로 전개
- 답안 기준: "계층 위치 → 동작 원리 → 장애/위협 → 설계 대안 → 적용 사례" 순서가 가장 읽기 쉽다.

## Ⅴ. 최신 기술 동향 연결

- 보안: 제로 트러스트 네트워크 액세스(ZTNA), 보안 서비스 에지(SASE), 마이크로세그멘테이션
- 데이터센터: 이더넷 가상 사설망 확장형 로컬 영역 네트워크(EVPN-VXLAN), 스파인-리프(Spine-Leaf), 스마트NIC/DPU
- 운영 자동화: eBPF 기반 패킷 가시화, 스트리밍 텔레메트리, 의도 기반 네트워킹(IBN)
- 차세대 통신: 5G/6G, 시간 민감형 네트워킹(TSN), 양자 키 분배(QKD)
