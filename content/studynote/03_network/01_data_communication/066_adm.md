## 핵심 인사이트 (3줄 요약)

> 1. **본질**: ADM(Adaptive Delta Modulation)은 델타 변조의 스텝 크기를 [신호](/studynote/02_operating_system/02_process_thread/130_signal/) 변화에 따라 적응시켜 잡음을 줄이는 방식이다.
> 2. **가치**: 경사 과부하와 granular noise를 완화해 DM보다 더 안정적인 전송 품질을 제공한다.
> 3. **판단**: [신호](/studynote/02_operating_system/02_process_thread/130_signal/) 특성을 따라 스텝을 조절하는 피드백 제어가 핵심이며, 음성 코덱에서 의미가 크다.

---

## Ⅰ. 개요 및 필요성

DM은 단순하지만 빠른 변화에 취약하다. ADM은 이 단점을 보완하기 위해 스텝 크기를 자동으로 바꾼다.

그래서 음성처럼 구간별 변화율이 다른 [신호](/studynote/02_operating_system/02_process_thread/130_signal/)에 더 적합하다.

- **📢 섹션 요약 비유**: 걷다가 뛰어야 할 때 보폭을 자동으로 바꾸는 스마트 신발이다.

---

## Ⅱ. 아키텍처 및 핵심 원리

```text
Input
  v
Comparator
  v
1-bit Decision
  v
Adaptive Step-size Control
  v
Integrator
  ^
Feedback
```

| 구성 요소 | 역할 |
| :-- | :-- |
| [Comparator](/studynote/01_computer_architecture/01_basic_electronics_logic/043_comparator/) | 입력과 예측 비교 |
| Step-size Control | 변화율에 맞춰 보폭 조정 |
| Integrator | 복원 [신호](/studynote/02_operating_system/02_process_thread/130_signal/) 누적 |
| Feedback | 다음 판단에 반영 |

ADM은 [신호](/studynote/02_operating_system/02_process_thread/130_signal/)가 급하면 큰 스텝으로 추적하고, 조용하면 작은 스텝으로 세밀하게 따라간다. 그래서 DM의 단순성과 품질을 조금 더 잘 절충한다.

- **📢 섹션 요약 비유**: 좁은 길에서는 작은 발걸음, 넓은 길에서는 큰 발걸음을 쓰는 것과 같다.

---

## Ⅲ. 비교 및 연결

| 방식 | 특징 | 장점 | 단점 |
| :-- | :-- | :-- | :-- |
| DM | 고정 1비트 증감 | 매우 단순 | 잡음/과부하 |
| ADM | 적응형 스텝 | 품질 개선 | 제어 복잡 |
| [DPCM](/studynote/03_network/01_data_communication/063_DPCM_차분_펄스_부호_변조/) | 차이값 전송 | 효율 높음 | 예측 필요 |

| 문제 | ADM 대응 |
| :-- | :-- |
| 경사 과부하 | 큰 스텝으로 빠른 추적 |
| Granular Noise | 작은 스텝으로 세밀 조정 |

ADM은 CVSD(Continuously Variable Slope Delta modulation) 같은 방식과 연결된다. 핵심은 "상황에 맞춰 보폭을 바꾸는 것"이다.

- **📢 섹션 요약 비유**: 오르막에서는 큰 발걸음, 평지에서는 작은 발걸음을 쓰는 산책이다.

---

## Ⅳ. 실무 적용 및 기술사 판단

### [체크리스트](/studynote/04_software_engineering/11_testing_validation/435_checklist_based_testing/)

1. 변화율에 따라 스텝을 조절하는가?
2. 경사 과부하와 granular noise를 모두 고려하는가?
3. DM 대비 품질 개선 효과를 설명할 수 있는가?
4. 음성/센서 [신호](/studynote/02_operating_system/02_process_thread/130_signal/)에 적합한가?
5. 피드백 루프의 안정성을 검토했는가?

### [안티패턴](/studynote/04_software_engineering/02_requirements_analysis/128_water_scrum_fall_anti_pattern/)

- 스텝 크기를 고정한 채 적응형이라고 부르는 설계
- 빠른 [신호](/studynote/02_operating_system/02_process_thread/130_signal/)에 적응 없이 DM만 쓰는 설계
- 오차 전파와 잡음 특성을 무시하는 설계
- [신호](/studynote/02_operating_system/02_process_thread/130_signal/) 특성과 무관하게 변조를 선택하는 설계

기술사 관점에서는 ADM을 "더 복잡한 DM"이 아니라 "[신호](/studynote/02_operating_system/02_process_thread/130_signal/)에 반응하는 DM"으로 설명해야 한다.

- **📢 섹션 요약 비유**: 평평한 길과 언덕길에 같은 걸음으로만 걷지 않는 것과 같다.

---

## Ⅴ. 기대효과 및 결론

ADM은 단순한 1비트 계열 변조에 적응성을 더해 실용성을 높인다. 그래서 음성 전송에서 오래 사용되었다.

결론적으로 ADM은 변화하는 [신호](/studynote/02_operating_system/02_process_thread/130_signal/)에 맞춰 스텝 크기를 조절하는 델타 변조다.

- **📢 섹션 요약 비유**: 상황에 맞게 발걸음을 조절하면 덜 힘들다.
