## Ⅰ. 개요
- 정의: CPU와 가속기, 메모리 간의 고속 연결 및 캐시 일관성을 보장하는 차세대 인터커넥트
- 배경: 서버당 메모리 용량 제한(Memory Wall) 해결 및 장치 간 자원 공유 필요성
- 출제 의도
| 구분 | 내용 |
| --- | --- |
| 핵심 | 캐시 일관성, 메모리 확장성, CXL.io/cache/mem 프로토콜 |

## Ⅱ. 구성요소
```
[ CPU ] <--- (CXL Fabric) ---> [ CXL Memory / GPU / FPGA ]
  |             |                   |
  +-- (CXL.io / .cache / .mem) -----+
```
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| CXL.io | PCIe 호환 입출력 및 장치 탐색 수행 | 기본 통로 |
| CXL.cache | 호스트 캐시를 가속기가 직접 참조하도록 지원 | 장부 공유 |
| CXL.mem | 호스트가 장치의 메모리를 RAM처럼 직접 사용 | 창고 확장 |
> 요약: PCIe 물리 계층 위에서 세 가지 프로토콜을 통해 효율적인 자원 통합 제공함

## Ⅲ. 절차
1. 장치 연결: 물리적 PCIe 슬롯에 CXL 호환 장치 장착 및 인식
2. 프로토콜 협상: io, cache, mem 중 필요한 통신 모드 결정
3. 메모리 풀링: 호스트가 외부 장치의 메모리를 가상 주소 공간에 할당
4. 일관성 유지: 하드웨어적으로 CPU와 장치 간 캐시 데이터 동기화 수행
> 요약: 여러 시스템이 메모리를 공유(Pooling)하여 자원 활용도를 극대화함

## Ⅳ. 문제점
- 직렬 인터커넥트 방식의 특성상 로컬 DRAM 대비 지연 시간(Latency) 발생함

## Ⅴ. 개선방안
- 저지연 컨트롤러 설계 및 소프트웨어 계층의 계층적 메모리 관리(Tiering) 적용함

## Ⅵ. 전망
- 데이터 센터의 '콤포저블 인프라' 구현을 위한 핵심 표준으로 안착할 전망임
- 메모리 풀링을 통한 TCO 절감 효과 극대화가 하이퍼스케일러들의 주요 CSF임
