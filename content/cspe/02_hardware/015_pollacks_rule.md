## Ⅰ. 개요
- 정의: 마이크로프로세서의 성능 향상은 면적(복잡도) 증가의 제곱근에 비례한다는 관찰 법칙
- 배경: 면적을 2배 늘려도 성능은 약 1.4배(sqrt(2))만 증가하는 수확 체감 현상
- 출제 의도: 단일 코어 고도화의 비효율성과 멀티코어로의 전환 당위성 분석

## Ⅱ. 구성요소
- ASCII 구조도
  Performance (P)
      ^
      |       / (Performance ~ sqrt(Area))
      |      /
      |    _/
      |  _/
      +----------------> Area (A)

- 구성요소 표
| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| 복잡도(Area) | 트랜지스터 수, 로직 면적, 전력 소모량 | 공장 규모 |
| 성능(Perf) | 처리 속도, 처리량, IPC | 제품 생산량 |
| 전력 효율 | 성능 대비 면적 및 전원 사용 비율 | 가성비 |
> 요약: 공장을 2배 크게 지어도 생산량은 1.4배만 느는 구조적 한계를 의미함

## Ⅲ. 절차
- ASCII 흐름도
  (Increase Area 2x) -> (Increase Complexity) -> (Performance 1.4x)
                                                      |
           +----------------<-------------------------+
           v
  (Diminishing Returns) -> (Switch to Multicore)

- 4단계 설명
1. 설계 확장: 단일 코어 내 슈퍼스칼라, OoO 엔진 등을 더 크게 설계
2. 복잡도 증가: 의존성 체크 및 데이터 경로 확장에 따른 트랜지스터 급증
3. 성능 측정: 투입된 자원 대비 성능 향상 폭이 둔화됨을 확인 (sqrt 관계)
4. 전략 수정: 큰 코어 하나 대신 중간 크기 코어 여러 개를 배치하는 것이 유리함 판단
> 요약: 단일 코어의 대형화보다는 멀티코어 배치가 총 성능 면에서 이득임

## Ⅳ. 문제점
- Power Wall: 면적 증가에 따른 전력 밀도 급증으로 냉각 비용 및 신뢰성 문제 발생
- 비효율: 특정 임계점 이상의 복잡도는 성능 기여도보다 자원 낭비가 더 큼

## Ⅴ. 개선방안
- (단기) 적정 규모 코어: 폴락의 법칙이 적용되는 구간 내에서 최적의 코어 크기 결정
- (중기) 이종 멀티코어: 성능 중심 코어와 전력 중심 코어를 혼합하여 효율 극대화
- (장기) 가속기 중심: 범용 연산보다는 전용 회로(ASIC)를 통한 성능 향상 도모

## Ⅵ. 전망
- 로드맵: 단일 코어 성능(Single-thread)은 유지하되, 코어 개수와 특화 성능에 집중
- CSF: 멀티코어 병렬 실행 효율을 저해하는 암달의 법칙(Amdahl) 극복 소프트웨어 기술
