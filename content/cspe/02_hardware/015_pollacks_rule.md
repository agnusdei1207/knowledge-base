## Ⅰ. 개요
- **정의**: 프로세서 코어의 단일 스레드 성능이 코어 복잡도(트랜지스터 수)의 제곱근에 비례한다는 경험 법칙
- **배경/필요성**: 트랜지스터 예산이 한정된 상황에서 큰 코어 1개와 작은 코어 다수 중 어느 쪽이 면적 대비 처리량이 높은지 판단할 근거가 필요함
- **비유**: 공장 기계를 2배 크게 만들어도 생산량은 약 1.4배만 늘어나므로, 작은 기계 2대를 두는 편이 총 생산량에서 유리한 것과 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 멀티코어 전환의 이론 근거 이해 | $\text{Perf} \propto \sqrt{C}$ 관계식 | 경험 법칙이므로 워크로드에 따라 편차가 존재한다는 점 명시 |

> 요약: 코어 복잡도 대비 성능의 체감 수익을 정량화한 법칙으로, 멀티코어 전환의 이론 근거임

## Ⅱ. 구성요소
```text
  트랜지스터 예산 (고정)
         |
    +----+----+
    |         |
  대형 코어   소형 코어 x N
  복잡도 C    복잡도 C/N
  성능 ~sqrtC  성능 ~sqrt(C/N)
              총합 ~N*sqrt(C/N)
         |         |
         v         v
  단일스레드 우위  처리량 우위
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 코어 복잡도(C) | OoOE 깊이·캐시 크기·발행 폭 등 코어에 투입된 트랜지스터 총량 | 기계의 크기 |
| 단일 스레드 성능 | 하나의 스레드가 달성하는 IPC × 클럭, 복잡도의 제곱근에 비례함 | 기계 1대의 시간당 생산량 |
| 면적 효율 | 동일 트랜지스터 예산에서 총 처리량을 최대화하는 코어 구성 | 공장 바닥 면적당 총 생산량 |
| 체감 수익 | 복잡도를 2배로 올려도 성능은 약 1.41배만 증가하는 비선형 관계 | 2배 큰 기계의 1.4배 생산량 |

> 요약: 코어 복잡도·성능·면적 효율 간 제곱근 관계가 폴락의 법칙의 핵심 구성임

## Ⅲ. 절차
```text
  예산 산정        코어 설계       성능 추정       구성 비교
  (트랜지스터)     (복잡도 결정)   (sqrt 적용)     (총처리량)
     |               |               |               |
     +---예산분배---->+---코어크기---->+---성능계산---->+
  총 트랜지스터    OoOE 깊이 등    Perf~sqrt(C)    대형 vs 소형xN
  다이 면적       마이크로아키텍처  IPC 추정       워크로드별 최적
```
- 1단계: 칩의 총 트랜지스터 예산과 다이 면적 제약을 산정함
- 2단계: 코어당 복잡도(OoOE 깊이, 캐시 크기, 발행 폭 등)를 결정하여 코어 수를 도출함
- 3단계: 폴락의 법칙 $\text{Perf} \propto \sqrt{C}$를 적용하여 코어당 단일 스레드 성능을 추정함
- 4단계: 대형 코어 소수 vs 소형 코어 다수 구성의 총 처리량을 비교하여 워크로드에 맞는 최적 구성을 선택함

> 요약: 예산 → 코어 설계 → 성능 추정 → 구성 비교의 절차로 코어 배치를 결정함

## Ⅳ. 문제점
- 순차 워크로드 성능 저하: 소형 코어 다수 구성 시 단일 스레드 성능이 낮아져 순차 영역 병목이 심화됨 — 암달의 법칙(014 참조)과 결합하여 성능 정체
- 경험 법칙의 정밀도 한계: 워크로드·마이크로아키텍처에 따라 지수가 0.4~0.7로 편차가 존재함 — 설계 초기 추정에 오차가 발생함
- 전력 밀도 미반영: 트랜지스터 수만 고려하고 전력·발열 제약을 포함하지 않음 — 다크 실리콘 문제를 설명하지 못함

> 요약: 순차 성능 저하·지수 편차·전력 미반영이 폴락의 법칙 적용 시 주의점임

## Ⅴ. 개선방안
1. 단기: 이종 코어(big.LITTLE) 구성으로 순차 워크로드는 대형 코어, 병렬 워크로드는 소형 코어에 배정
2. 중기: 실측 기반 성능 모델링(시뮬레이션·벤치마크)으로 지수 계수를 워크로드별로 보정
3. 장기: 전력·열·면적을 통합한 확장 모델(폴락 + 전력 모델)로 다크 실리콘까지 포함한 설계 공간 탐색

> 요약: 이종 코어·실측 보정·통합 모델로 폴락의 법칙 한계를 보완함

## Ⅵ. 전망
- 발전 방향: 칩렛·3D 적층 기술로 트랜지스터 예산이 확대되면서, 이종 코어 + 도메인 가속기 배치 판단에 폴락의 법칙이 기초 지표로 활용됨
- 기술사적 판단: 단일 법칙만으로 설계를 결정할 수 없으나, 코어 복잡도 vs 수량의 트레이드오프를 직관적으로 파악하는 데 유용함
- 기술사 제언: 프로세서 설계 의사결정 시 폴락의 법칙 + 암달의 법칙 + 전력 모델을 함께 적용하여 다차원 최적화를 수행할 필요가 있음
