## Ⅰ. 개요
- 데이터센터의 효율적 공간 활용 및 관리 편의를 위한 서버 구성 방식
- 집적도 향상과 자원 공유를 통한 운영 비용(OPEX) 절감 기술

| 구분 | 내용 |
| --- | --- |
| 정의 | 서버 본체, 전원, 냉각 장치를 규격화된 틀에 배치하는 구조 |
| 배경 | 대규모 클라우드 인프라의 확장성 및 고밀도 수용 요구 |
| 출제의도 | 랙 서버와 블레이드 서버의 구조적 특징 및 차이 비교 |

## Ⅱ. 구성요소
```
[ Rack Mount Server ]      [ Blade Server ]
+-------------------+      +-------------------+
| [  Server Unit  ] |      | [ Chassis       ] |
| [  Server Unit  ] |      | [B][B][B][B][B]   |
| [  Server Unit  ] |      | [B][B][B][B][B]   |
+-------------------+      +-------------------+
(독립적 전원/냉각)          (공유 전원/냉각/네트워크)
```
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| Rack Unit(U) | 표준 높이 단위(1U = 1.75인치) | 아파트 층수 |
| Chassis | 블레이드 서버들을 수납하고 자원을 공유하는 틀 | 공동 거실 |
| Backplane | 섀시 내부에서 데이터와 전력을 전달하는 보드 | 중앙 배선반 |
> 요약: 랙은 개별 서버의 적층, 블레이드는 모듈형 통합 구조임.

## Ⅲ. 절차
```
[수요 산정] -> [랙/섀시 설치] -> [서버 실장] -> [통합 관리]
```
1. 수요 산정: 필요 연산량 및 전력 용량에 따른 서버 형태 결정함.
2. 기반 구축: 랙 프레임 설치 및 전력/네트워크 배선 공사 수행함.
3. 서버 실장: 슬롯에 서버 모듈을 삽입하거나 랙에 고정 장착함.
4. 통합 관리: IPMI, Redfish 등을 통해 하드웨어 상태 원격 감시함.
> 요약: 규격화된 인프라에 서버를 장착하고 중앙 집중 관리함.

## Ⅳ. 문제점
- 블레이드 발열: 고밀도 집적으로 인해 국소 부위 온도 급상승함.
- 벤더 종속: 블레이드 섀시와 서버 모듈 간 제조사 호환성 결여됨.

## Ⅴ. 개선방안
- 고성능 쿨링: 차가운 공기 통로(Cold Aisle) 및 액침 냉각 도입함.
- OCP 준수: 오픈 컴퓨트 프로젝트(OCP) 표준 규격 서버 채택함.

## Ⅵ. 전망
- AI 특화 고전력 랙(100kW+) 및 액체 냉각 일체형 랙 보급 확대됨.
- 자원 분리(Disaggregated) 기반의 컴포저블 인프라가 미래 핵심임.
