## Ⅰ. 개요
- 하나의 칩 안에 CPU, GPU, 메모리, 인터페이스 등 전 시스템을 구현
- 기기의 소형화와 전력 효율 극대화를 위한 반도체 설계 기술

| 구분 | 내용 |
| --- | --- |
| 정의 | 복잡한 기능의 시스템 구성 요소를 단일 칩에 통합한 회로 |
| 장점 | 실장 면적 최소화, 소비 전력 절감, 제조 원가 낮춤(양산 시) |
| 출제의도 | SoC의 통합 구조 및 IP(Intellectual Property) 활용 이해 |

## Ⅱ. 구성요소
```
+------------------------------------------+
|  [ SoC Block Diagram ]                   |
| +--------+  +--------+  +--------------+ |
| | CPU    |  | GPU    |  | Modem        | |
| | Core   |  | Core   |  | (5G/LTE)     | |
| +--------+  +--------+  +--------------+ |
| | ISP    |  | NPU    |  | Memory Ctrl  | |
| +--------+  +--------+  +--------------+ |
| [ System Bus (AHB/AXI) / NoC ]           |
+------------------------------------------+
```
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| IP Core | 검증된 기능 블록(ARM 코어, 비디오 디코더 등) | 기성 가구 |
| System Bus | 각 IP 간 데이터 교환을 위한 공유 통로 | 사내 복도 |
| NoC | 대규모 칩 내부 패킷 기반 네트워크 기술 | 내부 고속망 |
> 요약: 다기능 IP들을 효율적인 버스 구조로 한데 묶은 형태임.

## Ⅲ. 절차
```
[IP 선정] -> [Interconnect 설계] -> [검증/시뮬레이션] -> [양산]
```
1. IP 선정: 요구 성능에 맞는 프로세서, 메모리 컨트롤러 IP 확보함.
2. Interconnect: 각 IP 간 병목 없는 데이터 흐름을 위한 버스 구조 설계함.
3. 검증: 다양한 시나리오에서 IP 간 충돌 및 전력 소모 상태 검증함.
4. 양산: 확정된 레이아웃으로 웨이퍼 공정 진행 및 최종 칩 생산함.
> 요약: 검증된 부품(IP)을 조립하고 최적화하여 하나의 칩으로 만듦.

## Ⅳ. 문제점
- 복잡성 폭증: 많은 기능을 통합하면서 설계 및 테스트 난이도 급상승함.
- 공정 한계: 모든 기능을 동일 미세 공정으로 제작 시 수율 저하 발생함.

## Ⅴ. 개선방안
- 모듈화 설계: 재사용 가능한 IP 생태계 강화 및 표준 버스 규격 준수함.
- 칩렛(Chiplet) 전환: 필요 시 기능별 분리 후 패키징하는 방식 검토함.

## Ⅵ. 전망
- AI 연산 가중으로 인한 전용 가속기(NPU) 비중이 지속 확대될 것임.
- 이종 집적 기술과의 결합을 통한 성능 돌파구 마련이 핵심 로드맵임.
