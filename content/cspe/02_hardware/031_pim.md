## Ⅰ. 개요
- 정의: 메모리 내부에 연산 기능을 통합하여 데이터 이동을 최소화하는 지능형 반도체
- 배경: 폰 노이먼 병목 현상 및 데이터 전송에 따른 전력 소모(Data Movement Wall) 해결
- 출제 의도
| 구분 | 내용 |
| --- | --- |
| 핵심 | 메모리 중심 컴퓨팅, 연산기 통합(ALU), 병렬 처리 |

## Ⅱ. 구성요소
```
[ Host CPU/GPU ] <--- (Control) ---> [ PIM Chip ]
                                     | [ Logic ] |
                                     | [ DRAM  ] |
```
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 연산 유닛(PU) | 메모리 뱅크 근처에 배치된 미세 연산 장치 | 내부 요리사 |
| 제어 로직 | 호스트 명령을 해석하고 메모리 연산을 지시하는 모듈 | 주방장 |
| 광폭 I/O | 내부 연산 유닛과 셀 간의 초고속 데이터 통로 | 전용 배차 |
> 요약: 메모리 뱅크 내부에 연산기(Logic)를 직접 삽입하여 전송 지연을 제거함

## Ⅲ. 절차
1. 연산 오프로딩: 호스트가 대규모 데이터 연산 명령을 PIM으로 전달
2. 내부 병렬 연산: 각 메모리 뱅크에서 독립적으로 데이터 읽기 및 연산 수행
3. 결과 취합: 각 뱅크의 연산 결과를 내부 버스를 통해 집계
4. 최종 반환: 연산이 완료된 최종값만을 호스트로 전송하여 대역폭 절약
> 요약: 데이터를 CPU로 옮기지 않고 현장에서 처리하여 효율성을 극대화함

## Ⅳ. 문제점
- 기존 표준 메모리 공정(DRAM)과 로직 공정의 통합에 따른 제조 복잡도 증가함

## Ⅴ. 개선방안
- 표준 JEDEC 규격을 준수하는 아키텍처 설계 및 PIM 전용 라이브러리 구축함

## Ⅵ. 전망
- 초거대 AI 모델의 추론(Inference) 가속을 위한 핵심 하드웨어로 자리매김할 전망임
- 소프트웨어 에코시스템(SDK/컴파일러) 확보가 상용화 및 시장 확산의 CSF임
