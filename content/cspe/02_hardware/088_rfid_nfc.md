## Ⅰ. 개요
- 정의: 무선 주파수를 이용하여 대상을 식별하고 데이터를 주고받는 비접촉 통신 기술
- 배경: 바코드의 시각적 한계 극복 및 모바일 결제, 보안 인증 등 근거리 통신 수요 증대
- 출제 의도: 동작 원리(유도 결합) 및 주파수 대역별 특성, 보안 메커니즘 이해

## Ⅱ. 구성요소
- ASCII 구조도
  [ Reader / Writer ] <--- Magnetic Field ---> [ Tag (Transponder) ]
  (Antenna + Chip)                             (Antenna + IC)

- 구성요소 표
| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| Passive Tag | 리더기의 전파 에너지를 유도 기전력으로 사용하여 구동 | 무건전지 카드 |
| Active Tag | 자체 배터리를 내장하여 긴 인식 거리 확보 가능 | 통행료 징수기 |
| NFC | 13.56MHz 대역을 사용하는 양방향 근거리 통신 표준 | 스마트 결제 |

- > 요약: 전자기 유도를 통해 전력과 데이터를 동시에 공급하는 기술

## Ⅲ. 절차
- ASCII 흐름도
  [Carrier Wave] -> [Tag Activation] -> [Modulation] -> [Read/Write]

1. 자기장 형성: 리더기 안테나에서 특정 주파수의 전자기파 방출
2. 태그 기동: 태그 안테나에 유도 전류가 발생하여 내부 칩 활성화
3. 데이터 반사: 태그가 저장된 정보를 변조(Load Modulation)하여 응답
4. 인증 및 처리: 리더기가 신호를 해석하여 상위 시스템에 데이터 전달

- > 요약: 비접촉 상태에서 전자기적 상호작용으로 정보를 교환하는 과정

## Ⅳ. 문제점
- 인식 간섭: 금속이나 액체 주변에서 전파 왜충돌 및 인식률 급격히 저하
- 보안 취약성: 도청(Eavesdropping)이나 복제(Cloning)를 통한 정보 탈취 위험

## Ⅴ. 개선방안
- 충돌 방지(Anti-collision): 여러 태그가 동시 인식될 때 순차 처리하는 알고리즘 적용
- 암호화 칩: 하드웨어 보안 모듈(Secure Element)을 탑재하여 위변조 방지

## Ⅵ. 전망
- 로드맵: 물류 자동화를 넘어 디지털 키, 스마트 팩토리의 핵심 인프라로 정착
- CSF: 인식 거리 확장 기술(UHF 고도화) 및 스마트폰 내장형 NFC 생태계 주도권 확보
