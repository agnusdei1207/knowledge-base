## Ⅰ. 개요
- 반도체 제조 공정의 미세한 물리적 편차를 이용하여 칩마다 다른 고유 식별값을 생성하는 기술.
- 하드웨어적으로 복제가 불가능한 '반도체 지문' 역할을 수행함.
| 구분 | 내용 | 비고 |
|---|---|---|
| 정의 | 제조 공정 편차를 활용한 HW 기반 보안 식별 및 키 생성 기술 | Hardware Fingerprint |
| 의도 | 물리적 고유성 기반의 위조 방지 및 키 저장 보안 이해 측정 | 복제 불가능 |

## Ⅱ. 구성요소
[ Challenge (Input) ] -> [ PUF Circuit (SRAM/Ring Osc) ] -> [ Response (Output) ]
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 챌린지 | PUF 회로에 입력되는 임의의 자극값 | 질문 |
| 리스폰스 | 물리적 특성에 의해 결정되는 고유 출력값 | 답변 |
| 엔트로피 | 공정 편차로 인해 발생하는 무작위성의 정도 | 개성 |
> 요약: 챌린지(입력), 물리적 구조, 리스폰스(출력)의 CRP 쌍으로 동작함.

## Ⅲ. 절차
(1) Enrollment -> (2) Storage -> (3) Verification -> (4) Key Generation
1. Enrollment: 제조 단계에서 다양한 챌린지에 대한 리스폰스를 측정하여 DB화함.
2. Storage: 키를 메모리에 저장하지 않고, 필요할 때마다 PUF에서 실시간 생성함.
3. Verification: 서버가 던진 챌린지에 대해 칩이 올바른 리스폰스를 주는지 대조함.
4. Key Generation: 에러 정정 코드(ECC)를 결합하여 안정적인 암호 키로 변환함.
> 요약: 등록, 비저장 관리, 검증, 암호 키 생성 순으로 활용됨.

## Ⅳ. 문제점
- 환경 가변성: 온도, 전압 등 외부 환경 변화에 따라 출력값이 변하는 불안정성 존재.
- 수명 문제: 노후화에 따라 물리적 특성이 변해 초기 등록값과 달라질 위험.

## Ⅴ. 개선방안
- 에러 정정(ECC): Fuzzy Extractor 등을 도입하여 노이즈가 섞인 값에서 정답 추출.
- 안정화 설계: 환경 변화에 강인한 구조(Differential 구조 등)의 PUF 회로 설계.

## Ⅵ. 전망
- IoT 보안 표준: 저전력/저비용 특성으로 인해 소형 기기의 기기 인증 표준으로 확산.
- 공급망 신뢰: 칩의 진위 여부를 판별하는 원천 기술로 활용되어 가짜 부품 유통 차단.
