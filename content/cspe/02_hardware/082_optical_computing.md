## Ⅰ. 개요
- 정의: 전자 대신 빛(광자, Photon)을 정보 매개체로 사용하여 연산을 수행하는 기술
- 배경: 전기 신호의 발열 문제, 전자기 간섭 및 전송 속도 한계 돌파 필요
- 출제 의도: 광학적 특성(회절, 간섭)을 이용한 병렬 연산 및 저전력 특성 이해

## Ⅱ. 구성요소
- ASCII 구조도
  [ Light Source ] -> [ Modulator ] -> [ Photonic IC ] -> [ Detector ]
  (Laser)           (Data Input)     (Logic Gates)      (Output)

- 구성요소 표
| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| Photonic IC | 빛의 경로를 제어하여 논리 연산을 수행하는 칩 | 거울 미로 |
| Modulator | 전기 신호를 빛의 강도/위상으로 변환 | 신호등 |
| Optical Interconnect | 칩 내부/간의 초고속 광 데이터 전송 통로 | 광섬유 전용선 |

- > 요약: 전자 이동 시 발생하는 저항과 열 없이 빛의 속도로 연산 처리

## Ⅲ. 절차
- ASCII 흐름도
  [Emission] -> [Manipulation] -> [Parallel Processing] -> [Detection]

1. 광원 방출: 레이저 다이오드 등을 통해 안정적인 광자 흐름 생성
2. 위상/진폭 변조: 입력 데이터에 따라 빛의 물리적 특성 제어
3. 전파 및 간섭: 렌즈나 도파로를 통해 빛을 중첩시켜 복잡한 행렬 연산 수행
4. 광전 변환: 연산 결과를 다시 전기 신호로 읽어들여 후처리

- > 요약: 물리적인 빛의 간섭 현상을 수학적 연산(특히 AI 행렬)에 활용

## Ⅳ. 문제점
- 소형화 난이도: 빛의 파장 한계로 인해 트랜지스터 수준의 미세화가 어려움
- 비선형성 제어: 빛끼리 상호작용하게 만드는 비선형 광학 소자 구현의 기술적 벽

## Ⅴ. 개선방안
- 하이브리드 전자-광학: 연산은 광학으로, 제어와 저장은 전자로 분담하는 구조
- 나노 포토닉스: 메타 물질을 활용하여 빛을 나노 단위로 가두고 제어하는 기술 개발

## Ⅵ. 전망
- 로드맵: AI 데이터센터의 칩 간 통신(Interconnect)부터 전격 도입 후 연산 칩으로 확장
- CSF: 대규모 행렬 연산 가속을 위한 광학 AI 가속기(Optical TPU) 시장 선점 필수
