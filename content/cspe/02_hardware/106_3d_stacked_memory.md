## 미리 알고가기

- 3D 적층은 여러 메모리 다이를 수직으로 쌓는 패키징 방식임
- TSV는 다이 사이를 연결하는 실리콘 관통 전극임
- HBM은 대표적인 3D 적층 메모리 응용 사례임

## Ⅰ. 개요

- **정의/개념**: 3D 적층 메모리는 메모리 다이를 수직으로 쌓고 TSV와 인터포저로 연결해 기존 평면 배치보다 더 높은 대역폭과 집적도를 제공하는 메모리 패키징 구조임
- **배경/필요성**: AI 가속기와 HPC 프로세서는 메모리 대역폭 요구가 급증했지만 보드 배선 길이와 핀 수 한계 때문에 평면 메모리 구조만으로는 충분한 데이터 공급이 어려워졌음

## Ⅱ. 특징

- 수직 연결로 배선 길이를 줄여 넓은 I/O 대역폭을 확보함
- 같은 면적에서 더 큰 용량과 높은 병렬성을 얻을 수 있음
- 열 집중과 적층 수율이 실용화의 주요 제약임
- 메모리 성능 개선 효과가 패키지 비용과 냉각 난도 증가를 동반함

## Ⅲ. 종류 및 비교

| 판단 기준 | 2D 메모리 배치 | 3D 적층 메모리 |
|:---|:---|:---|
| 연결 구조 | 보드 중심 평면 배선 | TSV 기반 수직 연결 |
| 대역폭 | 핀 수와 클럭 의존 | 넓은 I/O와 다이 병렬성 활용 |
| 전력 효율 | 장거리 I/O 비용 큼 | bit당 에너지 효율 개선 가능 |
| 제조 난도 | 상대적으로 단순 | 적층과 열과 테스트 난도 큼 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Memory Die Stack | 여러 다이가 수직 적층되어 용량과 병렬 접근성을 동시에 늘림 |
| TSV and Micro-bump | 다이 사이 초고밀도 연결을 제공해 짧은 경로로 높은 대역폭을 만듦 |
| Logic Base | 제어와 테스트와 인터페이스 기능을 담당해 메모리 스택의 실사용성을 높임 |
| Interposer and Package | 프로세서와 메모리 스택을 넓은 병렬 경로로 연결해 시스템 성능 이점을 실현함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 다이 선별      | --> | 적층 및 접합   | --> | 패키지 연결    | --> | 열/수율 검증   |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **다이 선별**: known good die를 골라 적층 대상 품질을 확보함
2. **적층 및 접합**: 다이를 정렬하고 TSV와 bump로 수직 연결함
3. **패키지 연결**: 인터포저와 프로세서를 연결해 시스템 경로를 완성함
4. **열과 수율 검증**: 스택 온도와 결함과 대역폭 특성을 시험함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 적층된 다이 내부 열이 빠져나가기 어려워 온도 상승과 성능 저하가 함께 발생할 수 있음
   - 해결방안: thermal-aware 배치와 냉각 설계를 적용하고 stack temperature와 thermal throttling count로 검증함
2. 문제: 하나의 다이 결함이 전체 스택 수율과 비용을 악화시킬 수 있음
   - 해결방안: known good die 선별과 redundancy를 적용하고 stack yield와 defect escape rate로 검증함
3. 문제: 적층 전후 결함 위치를 구분하기 어려워 테스트와 수리 비용이 증가할 수 있음
   - 해결방안: BIST와 단계별 패키지 검증을 운영하고 test coverage와 post-package failure rate로 검증함

## Ⅶ. 적용 사례

- AI GPU 패키지에서는 HBM 스택을 사용해 메모리 병목을 줄이고, memory bandwidth와 stack temperature로 결과를 확인함
- HPC 노드 설계에서는 인터포저 기반 적층 메모리를 적용하고, bandwidth per watt와 thermal throttling count로 결과를 확인함
- 양산 검증 단계에서는 known good die와 burn-in 절차를 강화하고, stack yield와 defect escape rate로 결과를 확인함

## Ⅷ. 결론

3D 적층 메모리는 대역폭 확대를 위한 패키징 기술이므로, 도입 판단은 최고 속도보다 열과 수율과 공급 안정성을 함께 볼 때 타당함.
