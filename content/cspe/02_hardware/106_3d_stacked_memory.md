## 미리 알고가기

- 3D 적층은 여러 메모리 다이를 수직으로 쌓는 패키징 방식임
- TSV는 다이 사이를 연결하는 실리콘 관통 전극임
- HBM은 대표적인 3D 적층 메모리 응용 사례임
- 인터포저는 여러 다이와 프로세서를 넓은 병렬 배선으로 연결하는 중간 기판임
- 마이크로 범프는 다이와 다이를 물리적으로 접합하는 미세 금속 범프임

## 작성 근거(검토용)

- 3D 적층 메모리는 다이 스택, TSV·마이크로 범프, 인터포저, 열·수율을 핵심 축으로 설명함
- 비교표는 2D·3D 배치의 연결·대역폭 구조, 비트당 전송 에너지, 제조 공정을 대비함
- 실무 판단은 메모리 대역폭·스택 온도와 적층 수율·패키지 고장률로 검증함

## Ⅰ. 개요

- **정의/개념**: 3D 적층 메모리는 메모리 다이를 수직으로 쌓고 TSV와 인터포저로 연결해 기존 평면 배치보다 더 높은 대역폭과 집적도를 제공하는 메모리 패키징 구조임
- **배경/필요성**: AI 가속기의 메모리 대역폭을 보드 핀 수 안에서 확장하기 위해 넓은 수직 I/O를 제공하는 적층 구조가 필요함

## Ⅱ. 특징

- 수직 연결로 배선 길이를 줄여 넓은 I/O 대역폭을 확보함
- 같은 패키지 면적에 여러 메모리 다이를 수직 배치함
- 스택 내부 열 저항과 다이별 결함이 온도와 적층 수율에 반영됨
- 성능 이점이 패키지 비용과 냉각 난도 증가를 함께 가져옴

## Ⅲ. 종류 및 비교

| 판단 기준 | 2D 메모리 배치 | 3D 적층 메모리 |
|:---|:---|:---|
| 연결·대역폭 구조 | 보드 중심 평면 배선, 보드 핀 수와 I/O 클럭으로 대역폭 확장 | TSV 기반 수직 연결과 인터포저, 넓은 I/O와 다이 병렬 접근으로 대역폭 확장 |
| 비트당 전송 에너지 | 긴 보드 배선과 패키지 외부 I/O 구동 에너지가 증가함 | 짧은 TSV·인터포저 경로로 전송 에너지를 줄임 |
| 제조 공정 | 단일 다이와 평면 패키지를 검사함 | 다이 적층·접합·열·적층 후 검사를 수행함 |

> 요약: 3D 적층은 TSV·인터포저로 I/O 폭과 비트당 전송 에너지를 개선하고 다이 적층·열·적층 후 검사를 추가함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 메모리 다이 스택 | 여러 다이가 수직 적층되어 용량과 병렬 접근성을 동시에 늘림 |
| TSV·마이크로 범프 | 다이 사이를 짧고 넓은 병렬 경로로 연결함 |
| 로직 베이스 | 제어·테스트·인터페이스 기능을 담당함 |
| 인터포저·패키지 | 프로세서와 메모리 스택을 넓은 병렬 경로로 연결함 |

> 요약: 메모리 다이를 TSV·마이크로 범프로 연결하고 로직 베이스와 인터포저가 제어·프로세서 경로를 구성함.

## Ⅴ. 원리 및 절차 흐름도

1. **다이 선별**: 선별 완료 다이를 골라 적층 대상 품질을 확보함
2. **적층·접합**: 다이를 정렬하고 TSV와 마이크로 범프로 수직 연결함
3. **패키지 연결**: 인터포저와 프로세서를 연결해 시스템 경로를 완성함
4. **열·수율 검증**: 스택 온도와 결함과 대역폭 특성을 시험함

> 요약: 선별한 다이를 TSV·마이크로 범프로 적층하고 인터포저에 연결한 뒤 스택 온도·적층 수율·대역폭 특성을 검증함.

## Ⅵ. 실무 사례

1. AI GPU 패키지는 열을 고려해 HBM을 배치하고 메모리 대역폭·스택 온도를 확인함
2. 3D 메모리 패키지는 선별 완료 다이와 단계별 검사를 적용하고 적층 수율·패키징 후 고장률을 확인함

## Ⅶ. 결론

- 3D 적층 메모리는 TSV 기반 대역폭과 용량 이득을 스택 온도·적층 수율·패키지 비용과 함께 검증해야 함
