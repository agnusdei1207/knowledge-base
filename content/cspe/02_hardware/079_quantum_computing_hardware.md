## Ⅰ. 개요
- 정의: 양자역학적 특성(중첩, 얽힘)을 이용하여 병렬 연산을 수행하는 차세대 컴퓨팅 HW
- 배경: 암호 해독, 신소재 설계 등 기존 슈퍼컴퓨터의 연산 한계 영역 돌파 필요
- 출제 의도: 주요 큐비트 구현 방식(초전도체 vs 이온트랩)의 원리 및 기술적 차이 비교

## Ⅱ. 구성요소
- ASCII 구조도
  [ Superconducting ]          [ Ion Trap ]
  - Circuit based             - Atomic based
  - Joseph's Junction         - Laser Cooling
  - < 20mK (Extreme Cold)     - Vacuum Trap

- 구성요소 표
| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| Superconducting | 전기 저항이 없는 회로를 이용해 큐비트 구현 | 고속도로 순환로 |
| Ion Trap | 전자기장으로 이온을 공중에 띄워 제어 | 공중 부양 구슬 |
| Dilution Fridge | 절대온도 근처까지 냉각하는 거대 장치 | 초저온 냉장고 |

- > 요약: 초전도는 확장성이 좋고, 이온트랩은 정확도와 유지 시간이 우수함

## Ⅲ. 절차
- ASCII 흐름도
  [State Init] -> [Gate Operation] -> [Entanglement] -> [Measurement]

1. 양자 상태 초기화: 큐비트를 바닥 상태(|0>)로 정렬
2. 양자 게이트 조작: 마이크로파 또는 레이저를 조사하여 중첩 상태 생성
3. 얽힘 구현: 여러 큐비트를 상호 연관시켜 연산 공간을 기하급수적으로 확장
4. 결과 측정: 확률적으로 분포된 양자 상태를 관측하여 디지털 값으로 확정

- > 요약: 미시 세계의 물리 현상을 제어하여 계산 결과를 도출하는 과정

## Ⅳ. 문제점
- 양자 결어긋남(Decoherence): 외부 환경 간섭으로 인해 양자 상태가 쉽게 파괴됨
- 높은 오류율: 디지털 비트와 달리 노이즈에 매우 취약하여 오류 수정이 극도로 어려움

## Ⅴ. 개선방안
- 극저온/진공 강화: 외부 열과 전자기파 노이즈를 완벽히 차단하는 인프라 구축
- 양자 오류 수정(QEC): 수천 개의 물리 큐비트를 묶어 하나의 논리 큐비트로 운용

## Ⅵ. 전망
- 로드맵: NISQ(오류 포함 중간단계)를 지나 FTQC(결함 허용 양자 컴퓨터) 시대로 진입
- CSF: 큐비트 개수(Scale)와 품질(Fidelity)을 동시에 높이는 하이브리드 아키텍처 필수
