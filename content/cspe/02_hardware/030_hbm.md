## 미리 알고가기

- HBM은 여러 DRAM 다이를 TSV로 수직 적층해 넓은 I/O 폭을 제공하는 메모리임
- 인터포저는 GPU나 가속기와 HBM 스택을 근거리에서 고밀도로 연결하는 기판임
- 메모리 장벽은 연산 성능 증가 속도를 메모리 대역폭이 따라가지 못하는 병목을 뜻함
- GDDR(Graphics Double Data Rate): 그래픽 처리장치용으로 설계된 고속 DRAM 규격이며 보드 위에 개별 칩으로 배치됨

## 작성 근거(검토용)

- HBM은 TSV·베이스 다이·인터포저·광폭 I/O의 패키지 구조로 설명함
- GDDR과 HBM은 배치 구조·대역폭 확보 방식·제약을 같은 수준으로 비교함
- 가속기에 제공하는 대역폭과 패키지 수율·열 조건을 HBM 선택 기준으로 정리함

## Ⅰ. 개요

- **정의/개념**: HBM은 다수의 DRAM 다이를 TSV와 마이크로 범프로 적층하고 프로세서 옆에 넓은 병렬 인터페이스로 연결해 높은 대역폭과 비트당 전력 효율을 제공하는 3D 메모리 구조임
- **배경/필요성**: AI·HPC 가속기의 데이터 공급 대기를 줄이기 위해 신호 거리를 줄이고 입출력 폭을 넓힌 적층 메모리가 필요함

### 쉽게 이해하기 (학습용)
- 책을 옆방 서가에 한 권씩 나르는 대신, 바로 옆에 여러 층 서가를 쌓고 여러 사람이 동시에 여러 권을 건네주는 것과 같음

## Ⅱ. 특징

- 넓은 버스 폭으로 GDDR보다 높은 총 대역폭을 제공함
- 프로세서와 인터포저로 근접 연결해 배선 길이와 비트당 전송 에너지를 줄임
- TSV 적층과 인터포저 패키징이 필요해 제조 비용과 수율 부담이 큼
- 고대역폭을 제공하는 대신 열 밀도와 용량 확장 한계가 운영 리스크로 남음

### 쉽게 이해하기 (학습용)
- 여러 사람이 동시에 여러 통로로 책을 건네주니 한 사람이 빨리 뛰는 것보다 전체 운반량이 커짐
- 서가를 바로 옆에 두어 뛰는 거리와 힘이 줄어들지만, 층층이 쌓다 보니 짓는 비용과 실패율이 늘어남
- 책을 쌓아 열이 몰리고 더 쌓기도 어려워 운영상 조심해야 함

## Ⅲ. 종류 및 비교

| 판단 기준 | GDDR | HBM |
|:---|:---|:---|
| 배치 구조 | 보드 위 여러 칩을 수평 배치함 | 패키지 내부에서 여러 다이를 수직 적층함 |
| 대역폭 확보 방식 | 핀당 속도를 높여 대역폭을 늘림 | I/O 폭을 넓혀 총 대역폭을 늘림 |
| 제약 | 핀 속도·보드 신호 무결성·전력 | 적층 수율·인터포저 면적·열 밀도 |

> 요약: GDDR은 보드에서 핀 속도를 높이고, HBM은 패키지 내부의 넓은 I/O로 대역폭을 확보함.

### 쉽게 이해하기 (학습용)
- GDDR은 평평하게 늘어놓은 서가마다 한 사람이 더 빨리 뛰어다니는 방식이고, HBM은 서가를 층층이 쌓고 여러 통로로 동시에 나르는 방식임

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| DRAM 스택 | 여러 메모리 다이를 쌓아 뱅크·용량·대역폭을 제공함 |
| TSV·마이크로 범프 | 적층 다이와 인터포저를 수직 전기 경로로 연결함 |
| 베이스 로직 다이 | 스택 하단에서 채널 제어·테스트·신호 정렬을 담당함 |
| 실리콘 인터포저 | 프로세서와 HBM 스택을 광폭 배선으로 연결함 |

```text
      +-------------+
      | DRAM 다이    |
      +-------------+
      | DRAM 다이    |
      +-------------+
      | DRAM 다이    |
      +-------------+
      | 베이스 로직   |
      +-------------+
            |
            v
      +-------------+
      | 인터포저      |
      +-------------+
            |
            v
      +-------------+
      | GPU / NPU   |
      +-------------+
```

> 요약: HBM은 적층 DRAM, TSV, 베이스 다이, 인터포저를 묶어 프로세서 근처에 대역폭을 배치함.

### 쉽게 이해하기 (학습용)
- 층층이 쌓은 서가(DRAM 스택)를 수직 통로(TSV·마이크로 범프)로 연결하고, 맨 아래층 관리자(베이스 로직 다이)가 통로를 정리하며, 넓은 다리(실리콘 인터포저)로 옆방 작업자와 연결함

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 가속기 메모리 요청 | --> | 베이스 다이 채널 분배 | --> | 다중 뱅크 병렬 접근 | --> | 넓은 I/O로 데이터 반환 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **가속기 메모리 요청**: GPU나 NPU가 텐서 또는 벡터 데이터를 요구함
2. **베이스 다이 채널 분배**: 요청을 여러 채널과 뱅크에 나눠 병렬 접근을 준비함
3. **다중 뱅크 병렬 접근**: 적층된 DRAM 내부에서 동시에 데이터를 읽거나 씀
4. **넓은 I/O로 데이터 반환**: 인터포저 경로를 통해 프로세서에 대량 데이터를 짧은 거리로 전달함

> 요약: HBM은 요청을 여러 채널과 뱅크로 분산하고 인터포저 경로로 데이터를 반환함.

### 쉽게 이해하기 (학습용)
- 옆방 작업자가 책을 요청하면 맨 아래층 관리자가 여러 통로로 나눠 배분하고, 층마다 동시에 책을 꺼낸 뒤 넓은 다리로 한꺼번에 건네줌

## Ⅵ. 실무 사례

1. HBM 패키지는 양품 다이를 선별해 적층하고 패키지 수율과 GB당 비용을 확인함
2. AI 가속기 패키지는 HBM 열 분산 구조를 적용하고 접합 온도와 열 제한 발생률을 확인함

### 쉽게 이해하기 (학습용)
- 쌓아 올리기 전에 튼튼한 층만 골라 쌓고, 다 쌓은 뒤에는 열이 한쪽에 몰리지 않도록 식히는 구조를 함께 챙김

## Ⅶ. 결론

- HBM은 다수의 DRAM 다이를 TSV로 적층하고 프로세서 옆에 넓은 인터페이스로 연결해 높은 대역폭과 비트당 전력 효율을 얻는 3D 메모리 구조임
- 핀 속도보다 총 대역폭이 중요한 AI·HPC 가속기에는 HBM을 적용하되, 적층 수율과 열 밀도 부담을 감수할 수 있을 때만 GDDR 대신 선택해야 함

### 쉽게 이해하기 (학습용)
- 서가를 층층이 쌓고 넓은 다리로 연결해 옆방 작업자에게 최대한 가까이 많은 통로를 열어주는 구조임
