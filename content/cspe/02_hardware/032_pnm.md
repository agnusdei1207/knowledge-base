## Ⅰ. 개요
- 정의: 메모리 칩 내부가 아닌, 메모리 모듈이나 패키지 기판 등 "메모리 근처"에서 연산하는 기술
- 배경: 칩 설계 변경(PIM)의 어려움을 피하면서 데이터 이동 거리를 단축하려는 절충안
- 출제 의도
| 구분 | 내용 |
| --- | --- |
| 핵심 | Near-Memory 연산, DIMM 기반 가속, CXL 연계 가능성 |

## Ⅱ. 구성요소
```
[ Host CPU ] <---- [ Bus ] ----> [ PNM Module (Logic + DRAMs) ]
                                      ^--- (Processing Engine)
```
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 가속 엔진 | 메모리 모듈(DIMM) 또는 버퍼 칩에 내장된 연산기 | 창고 입구 작업실 |
| 컨트롤러 | 호스트와 메모리 가속 엔진 간의 통신 관리 | 현장 관리자 |
| 로컬 버스 | 모듈 내 DRAM 칩들과 연산 엔진을 연결하는 통로 | 사내 전용선 |
> 요약: 메모리 칩 구조를 유지하면서 모듈 단에서 연산 기능을 추가한 형태임

## Ⅲ. 절차
1. 데이터 요청: 호스트가 특정 연산(예: 검색, 집계)을 모듈에 요청
2. 모듈 내 로드: 가속 엔진이 인접한 DRAM 칩들로부터 데이터를 직접 읽음
3. 근접 연산: CPU를 거치지 않고 모듈 내 엔진에서 즉시 연산 수행
4. 결과 전송: 처리된 결과물을 호스트 버스를 통해 CPU로 전달
> 요약: 칩 레벨의 PIM보다 구현이 용이하며 기존 시스템 호환성이 높음

## Ⅳ. 문제점
- PIM 대비 데이터 이동 거리가 멀어 전력 효율이 상대적으로 낮음

## Ⅴ. 개선방안
- CXL(Compute Express Link) 프로토콜을 활용하여 가속기 연동 효율 증대함

## Ⅵ. 전망
- 대용량 데이터베이스의 스캔/필터링 작업 가속을 위한 실용적 대안으로 부각됨
- 스마트 DIMM 등 모듈 형태의 제품 출시가 로드맵이며, 확장성 확보가 CSF임
