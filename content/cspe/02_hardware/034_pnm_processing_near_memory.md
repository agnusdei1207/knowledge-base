## 핵심 인사이트 (3줄 요약)
- PNM은 연산 장치를 메모리 칩 '내부(다이)'가 아닌, 메모리 칩과 매우 인접한 '모듈 기판(CXL/DIMM) 위'에 배치하여 데이터 이동 거리를 획기적으로 줄이는 아키텍처이다.
- PIM이 가진 칩 설계 난이도와 수율 한계를 회피하면서도, 기존 메모리 다이를 수정 없이 사용하여 대규모 용량 확장(High Capacity)과 유연한 가속기 결합이 가능하다.
- 최근 CXL(Compute Express Link) 기술과 결합하여, 엄청난 메모리 용량을 요구하는 추천 시스템, 인메모리 데이터베이스(IMDB) 등의 대용량 데이터 처리 솔루션으로 부상하고 있다.
---
## Ⅰ. 개요 및 필요성
- **개념:** CPU, GPU와 같은 메인 호스트가 하던 연산의 일부를 메모리 모듈 패키지 내부나 모듈 기판(보드)에 위치한 가속기로 오프로드(Offload)하여 처리하는 근접 컴퓨팅 기술.
- **필요성:**
  - **PIM의 한계 극복:** 메모리 다이 안에 로직을 새겨 넣는 PIM은 공정이 어려워 수율이 낮고 고용량 집적이 불리함.
  - **대용량 데이터(Capacity) 처리 수요:** HBM과 같은 초고속/저용량 메모리보다, 속도는 적당하되 수 테라바이트(TB)의 용량을 통째로 스캔하고 연산해야 하는 추천 모델 등에서 가성비 높은 솔루션이 필요함.
---
## Ⅱ. 아키텍처 및 핵심 원리
### 1. PNM 기반 CXL 메모리 모듈 구조
```text
[ 메인 호스트 시스템 ] <==== CXL / PCIe 고속 버스 ====> [ PNM 메모리 모듈 보드 ]
┌─────────────┐                                ┌─────────────────────┐
│ CPU / GPU   │                                │  PNM 가속기 (로직)  │ <--- 연산 통제
└─────────────┘                                │       ↕ 로컬 버스   │
     결과값 반환                                │ [D램] [D램] [D램]  │ <--- 대용량 데이터 저장
                                               └─────────────────────┘
```

### 2. 핵심 동작 원리
- **D램 공정 유지:** 데이터를 저장하는 Base Memory는 기존과 완전히 똑같은 표준 D램 다이를 사용.
- **가속기 근접 패키징:** D램들이 꽂혀 있는 모듈(PCB 보드) 위나, 실리콘 인터포저 위에 별도로 제작된 연산용 반도체(FPGA, 특화 ASIC)를 올려 가까이 배치.
- **내부 오프로딩(Offloading):** 호스트 CPU가 작업을 지시하면, 모듈 보드 위의 PNM 가속기가 로컬 버스를 통해 D램 데이터를 빠르게 긁어모아 연산(MAC, 임베딩 벡터 검색)을 수행.
- **결과 반환:** 대량의 데이터를 버스로 이동시키지 않고, 처리된 작고 가벼운 결과값(수식 결과 등)만 CXL 버스를 태워 메인 호스트로 반환.
---
## Ⅲ. 비교 및 연결
- **PIM vs PNM 기술 비교**
| 비교 항목 | PIM (Processing in Memory) | PNM (Processing Near Memory) |
|---|---|---|
| 연산기 위치 | **메모리 다이/뱅크 내부** | **메모리 외부 모듈 기판 / 패키지** |
| 장점 | 최고의 대역폭, 극강의 초저전력 | **대용량 D램 확장 용이, 기존 공정 재사용** |
| 한계점 | 설계 복잡도 매우 높음, 용량 제한적 | PIM 대비 대역폭과 전력 효율은 약간 떨어짐 |
| 최적 워크로드 | 딥러닝 트레이닝, 초고속 추론 가속 | **대규모 추천 시스템, IMDB 검색/정렬** |
| 주요 폼팩터 | HBM-PIM, GDDR6-PIM | **CXL-PNM 모듈, 2.5D 이종 패키징** |

## Ⅳ. 실무 적용 및 기술사 판단
- **클라우드 데이터 센터 적용:** 수십 억 개의 파라미터를 뒤지는 유튜브, 넷플릭스의 '추천 시스템(Recommendation System)'은 메모리 용량이 성능의 핵심입니다. PNM 기반 CXL 모듈을 꽂으면 메인 CPU 부하를 주지 않고 모듈 안에서 자체적으로 데이터를 걸러내어 응답 속도를 대폭 개선할 수 있습니다.
- **반도체 기업 전략:** 제조사는 PIM 기술 성숙 전까지의 과도기적 시장을 장악하기 위해, 이종 접합 패키징을 통한 PNM 솔루션을 우선 상용화하며 생태계를 넓히고 있습니다.
---
## Ⅴ. 기대효과 및 결론
- PNM은 '기술적 이상(PIM)'과 '현실적 제약(공정 및 용량)' 사이에서 완벽한 타협점을 찾아낸 매우 실용적인 아키텍처입니다.
- CXL 인터페이스의 대중화와 함께 PNM 메모리 모듈은 서버의 필수 확장 카드로 자리 잡을 것이며, 향후 메모리를 단순한 저장 매체가 아닌 '지능형 연산 모듈'로 진화시키는 중요한 촉매제가 될 것입니다.

### 📌 관련 개념 맵
- 데이터 로컬리티 (Data Locality) ─ PIM / PNM
- CXL (Compute Express Link) ─ CXL.mem 프로토콜
- 오프로딩 (Offloading)

### 📈 관련 키워드 및 발전 흐름도
폰 노이만 구조 ➔ 스마트 SSD (스토리지 근접) ➔ **[PNM (메모리 모듈 근접 연산)]** ➔ [PIM (메모리 다이 내부 연산)]

### 👶 어린이를 위한 3줄 비유 설명
1. PIM이 창고(메모리) 안에 억지로 책상을 우겨넣고 일하는 거라면, PNM은 창고 바로 앞마당에 널찍한 작업장(모듈 보드)을 지어놓고 일하는 방식이에요.
2. 창고 건물을 부수고 개조할 필요가 없어서 아주 큰 창고를 그대로 쓸 수 있는 게 제일 큰 장점이죠.
3. 필요한 물건을 앞마당에서 다 조립한 뒤에, 꼬마 자동차(CXL 버스)에 태워 본사(CPU)로 가볍게 배달한답니다!
