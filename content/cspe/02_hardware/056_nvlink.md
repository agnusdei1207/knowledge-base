## 미리 알고가기

- NVLink는 GPU 간 또는 CPU-GPU 간 고대역폭 연결을 위한 전용 인터커넥트임
- GPU 간 피어 메모리 접근과 집단 통신의 PCIe 경유 구간을 줄이는 데 사용함
- 대규모 AI 학습과 메모리 공유형 가속기 구성에 필요함
- NVSwitch: 다수 GPU를 하나의 패브릭으로 연결해 다대다 통신 경로를 구성하는 스위치 칩임
- NCCL(NVIDIA Collective Communications Library): GPU 간 집단 통신 경로와 전송 순서를 관리하는 통신 런타임임

## 작성 근거(검토용)

- NVLink는 GPU 간 전용 링크, NVSwitch, 피어 메모리 접근, 집단 통신을 핵심 축으로 설명함
- 비교표는 PCIe 패브릭, 직접 NVLink, NVSwitch 패브릭의 연결 경로, 통신 범위, 확장 제약을 대비함
- 원리는 NCCL의 토폴로지 탐색부터 완료 동기화까지 절차로 설명함
- 실무 판단은 링크 사용률, 전체 합산 통신 시간, 호스트 경유 복사량으로 구체화함

## Ⅰ. 개요

- **정의/개념**: NVLink는 GPU 간 또는 지원 CPU·GPU 간에 피어 메모리 접근과 집단 통신 경로를 제공하는 전용 인터커넥트임
- **배경/필요성**: 대형 모델 학습의 그래디언트 동기화와 텐서 교환 시간을 줄이기 위해 GPU 간 전용 연결이 필요함

### 쉽게 이해하기 (학습용)
- 옆 건물 창고에 직접 들어가 물건을 꺼내올 수 있는 전용 통로를 뚫어두는 것과 같음

## Ⅱ. 특징

- GPU 사이의 병렬 링크로 집단 통신 대역폭을 제공함
- NVSwitch와 결합하면 스위치 포트 범위에서 다수 GPU의 통신 경로를 구성할 수 있음
- 특정 벤더 생태계 의존성이 높아 범용 호환성은 제한적임
- 통신 구조를 잘못 설계하면 링크가 있어도 토폴로지 병목이 남을 수 있음

### 쉽게 이해하기 (학습용)
- 여러 개의 전용 다리(병렬 링크)를 놓고 다리가 많아지면 교차로(NVSwitch)로 정리하지만, 이 다리는 한 회사 차량만 다닐 수 있고 교차로 설계가 나쁘면 여전히 막힘

## Ⅲ. 종류 및 비교

| 판단 기준 | PCIe 패브릭 | 직접 NVLink | NVSwitch 패브릭 |
|:---|:---|:---|:---|
| 연결 경로 | 루트 컴플렉스·PCIe 스위치 경유 | GPU 사이 점대점 링크 | GPU를 NVSwitch 포트에 연결 |
| 통신 범위 | CPU·GPU·NIC·저장장치 | 직접 연결된 지원 장치 | 스위치 패브릭에 연결된 다중 GPU |
| 확장 제약 | 업스트림 링크·스위치 대역폭 | GPU별 물리 링크 수 | 스위치 포트 수·패브릭 토폴로지 |

> 요약: 직접 NVLink는 피어 GPU를 연결하고 NVSwitch는 스위치 포트 범위의 다중 GPU 패브릭을 구성함.

### 쉽게 이해하기 (학습용)
- 일반 도로(PCIe), 옆집 직통 통로(직접 NVLink), 여러 집을 잇는 순환도로(NVSwitch)의 차이임

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| NVLink 물리 계층 | 직렬 링크를 통해 GPU 간 데이터를 직접 전송함 |
| NVSwitch 패브릭 | GPU 포트 사이의 교차 연결 경로를 구성함 |
| GPU 메모리 경로 | 피어 접근과 집단 통신의 읽기·쓰기 경로를 제공함 |
| 통신 런타임 | NCCL이 토폴로지에 따라 집단 통신 경로와 전송 순서를 정함 |

```text
+-------------+     +-------------+     +-------------+     +-------------+
| GPU A       | <-> | NVLink 물리 계층 | <-> | NVSwitch    | <-> | GPU B..N    |
+-------------+     +-------------+     +-------------+     +-------------+
```

> 요약: 물리 링크와 NVSwitch가 GPU 전송 경로를 구성하고 NCCL이 토폴로지에 맞춰 집단 통신을 배치함.

### 쉽게 이해하기 (학습용)
- 실제 다리(물리 계층), 다리들이 모이는 교차로(NVSwitch), 다리로 오가는 창고 접근로(메모리 경로), 어느 다리로 갈지 안내하는 내비게이션(NCCL)이 함께 동작함

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 토폴로지 탐색  | --> | 경로 선택      | --> | 피어·집단 통신 | --> | 완료 동기화    |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **토폴로지 탐색**: NCCL이 GPU 간 NVLink·NVSwitch 연결 상태를 확인함
2. **경로 선택**: 직접 NVLink 또는 NVSwitch 패브릭 중 지연이 낮은 경로를 선택함
3. **피어·집단 통신 수행**: 선택한 경로로 그래디언트·활성값을 전송함
4. **완료 동기화**: 모든 GPU의 전송 완료를 확인한 뒤 다음 연산을 진행함

> 요약: NCCL은 토폴로지를 탐색해 경로를 선택하고 GPU 간 전송 완료를 동기화한 뒤 다음 연산을 진행함.

### 쉽게 이해하기 (학습용)
- 지도를 먼저 확인하고(토폴로지 탐색), 가장 빠른 다리를 고른 뒤(경로 선택), 물건을 옮기고(통신 수행), 모두 도착했는지 확인하는(완료 동기화) 순서임

## Ⅵ. 실무 사례

1. 언어 모델 학습 서버는 NCCL의 토폴로지 인식 경로를 적용하고 링크 사용률·전체 합산 통신 시간을 확인함
2. 멀티 GPU 추론 서버는 피어 메모리 접근을 적용하고 호스트 경유 복사량·요청 지연을 확인함

### 쉽게 이해하기 (학습용)
- 대형 물류센터는 미리 지도를 보고 최단 다리로 짐을 나르고, 여러 창고가 이웃한 곳은 옆 창고 물건을 직접 꺼내와 왕복을 줄임

## Ⅶ. 결론

- NVLink는 GPU 간 또는 CPU-GPU 간 피어 메모리 접근과 집단 통신 경로를 제공해 PCIe 경유 구간을 줄이는 전용 인터커넥트임
- 대규모 GPU 학습·추론 구성에 적용하되, NCCL의 토폴로지 인식 경로 선택으로 링크 사용률과 전체 통신 시간을 판단해 병목을 통제해야 함

### 쉽게 이해하기 (학습용)
- 전용 다리를 놓았어도 실제 지도상 병목과 통행량을 함께 봐야 제 역할을 함
