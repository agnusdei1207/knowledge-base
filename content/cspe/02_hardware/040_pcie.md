## Ⅰ. 개요
- 정의: 점대점(Point-to-Point) 직렬 연결 방식을 사용하는 고속 입출력 인터페이스 표준
- 배경: 기존 병렬 버스(PCI/PCI-X)의 신호 왜곡(Skew) 및 대역폭 한계 극복 필요
- 출제 의도
| 구분 | 내용 |
| --- | --- |
| 핵심 | 계층 구조, 레인(Lane) 확장성, 전이중(Full-duplex), 패킷 통신 |

## Ⅱ. 구성요소
```
[ Device A ] <--- (Link: x1, x4, x16 Lanes) ---> [ Device B / Root Complex ]
  [ Transaction ] -> [ Data Link ] -> [ Physical ]
```
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 레인(Lane) | 데이터를 전송하는 최소 단위의 차동 쌍(Differential Pair) | 전용 차선 |
| 루트 컴플렉스 | CPU와 메모리를 PCIe 패브릭에 연결하는 허브 | 중앙 교차로 |
| 계층(Layers) | 트랜잭션, 데이터 링크, 물리 계층으로 구성된 통신 스택 | 택배 시스템 |
> 요약: 독립적인 레인을 묶어 대역폭을 선형적으로 확장 가능한 구조임

## Ⅲ. 절차
1. 초기화: 시스템 부팅 시 장치 탐색(Enumeration) 및 리소스 할당
2. 패킷 캡슐화: 상위 계층에서 데이터를 패킷 단위로 쪼개고 헤더 부착
3. 직렬 전송: 차동 신호 방식을 통해 물리 레인으로 초고속 전송
4. 오류 검사: 수신 측에서 CRC 검사 후 트랜잭션 완료 응답(ACK/NAK)
> 요약: 스위치 패브릭 기반의 패킷 교환을 통해 장치 간 데이터를 신속히 전달함

## Ⅳ. 문제점
- 고주파 신호 전송 시 물리적 거리에 따른 신호 감쇄 및 발열 심화됨

## Ⅴ. 개선방안
- 리타이머(Retimer) 및 리드라이버(Redriver)를 통한 신호 품질 보정함

## Ⅵ. 전망
- PCIe 6.0/7.0에서는 PAM4 인코딩 도입으로 128GB/s 이상의 초고대역폭 달성 예정
- CXL과의 물리 계층 공유를 통해 데이터 센터 내 자원 통합의 중추 역할 수행함
