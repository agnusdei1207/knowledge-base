## 미리 알고가기

- 중첩은 하나의 큐비트가 여러 기준 상태의 조합으로 존재하는 성질임
- 얽힘은 여러 큐비트 상태를 서로 떼어낼 수 없게 만드는 상관 구조임
- 간섭(interference)은 여러 확률 진폭이 위상에 따라 서로 더해지거나 상쇄되는 현상임
- 측정은 양자 상태를 고전 결과로 바꾸며 상태를 바꿔 버리는 과정임
- NISQ(Noisy Intermediate-Scale Quantum)는 잡음이 있고 큐비트 수가 제한된 현재 세대 양자 프로세서임

## 작성 근거(검토용)

- 중첩·얽힘은 상태 표현, 분리 불가능한 상관, 간섭, 측정을 핵심 축으로 설명함
- 비교표는 적용 범위·생성 조건, 본질, 계산 역할을 대비함
- 실무 판단은 상태 충실도·측정 분포 오차와 얽힘 충실도·회로 성공률로 검증함

## Ⅰ. 개요

- **정의/개념**: 중첩은 한 큐비트를 여러 기준 상태의 조합으로 표현하는 성질이고, 얽힘은 여러 큐비트가 분리할 수 없는 상관 상태를 이루는 성질임
- **배경/필요성**: 양자 회로에서 상태 표현과 다중 큐비트 상관을 구분하기 위해 중첩과 얽힘의 역할 기준이 필요함

### 쉽게 이해하기 (학습용)
- 회전하는 동전처럼 앞면과 뒷면이 겹쳐 있는 상태가 중첩이고, 실로 이어진 두 주사위처럼 한쪽 눈금이 정해지면 다른 쪽도 즉시 정해지는 관계가 얽힘임
- 회로 안에서 지금 조작하는 게 동전 하나의 회전인지 두 개를 잇는 실인지 구분해야 함

## Ⅱ. 특징

- 중첩은 하나의 큐비트가 여러 상태의 조합을 표현하게 함
- 얽힘은 여러 큐비트가 개별 상태로 분리되지 않는 상관을 형성하게 함
- 측정하면 상태가 변하므로 중간 상태를 그대로 읽어 후속 연산에 사용할 수 없음
- 잡음과 환경 결합은 위상 정보를 변화시켜 중첩과 얽힘의 결맞음을 감소시킴

### 쉽게 이해하기 (학습용)
- 계속 도는 동전처럼 여러 값을 한꺼번에 지니다가 손으로 잡는 순간(측정) 한 면으로 굳어져 되돌릴 수 없음
- 실로 묶인 두 동전처럼 하나가 정해지면 다른 하나도 함께 정해지며, 실이 낡으면(잡음) 그 연결이 약해짐

## Ⅲ. 종류 및 비교

| 판단 기준 | 중첩 | 얽힘 |
|:---|:---|:---|
| 적용 범위·생성 조건 | 단일 큐비트에서 단일 큐비트 게이트만으로 성립함 | 두 개 이상 큐비트에서 다중 큐비트 게이트로 성립함 |
| 본질 | 상태가 여러 기준 상태의 조합으로 표현됨 | 여러 큐비트 상태가 분리 불가능한 상관을 가짐 |
| 계산 역할 | 여러 기준 상태의 진폭을 함께 조작함 | 다중 큐비트의 결합 확률 분포를 형성함 |

> 요약: 중첩은 상태 표현을 확장하고, 얽힘은 여러 큐비트의 분리 불가능한 상관을 만듦.

### 쉽게 이해하기 (학습용)
- 혼자 도는 팽이 한 개가 중첩이라면, 실로 묶여 함께 도는 팽이 두 개가 얽힘임
- 팽이 한 개는 혼자서 여러 방향을 가리키지만, 묶인 팽이는 한쪽 방향이 정해지는 순간 다른 쪽 방향도 같이 정해짐

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 기준 상태 | $\lvert 0\rangle$와 $\lvert 1\rangle$가 중첩 표현의 출발점이 됨 |
| 진폭·위상 | 측정 확률과 간섭 방향을 정해 양자 상태 차이를 만듦 |
| 얽힘 게이트 | 여러 큐비트를 함께 제어하는 게이트가 상관 구조를 형성함 |
| 측정 과정 | 상태를 고전 결과로 바꾸며 전체 확률 분포만 관찰 가능하게 만듦 |

> 요약: 진폭·위상이 기준 상태의 중첩을 표현하고 얽힘 게이트가 다중 큐비트 상관을 형성하며 측정이 고전 결과를 반환함.

### 쉽게 이해하기 (학습용)
- 동전의 앞뒤(기준 상태)에 회전 속도와 방향(진폭·위상)이 섞여 있고, 두 동전을 잇는 실(얽힘 게이트)이 관계를 만들며, 손으로 잡는 행위(측정)가 결과를 하나로 확정함

## Ⅴ. 원리 및 절차 흐름도

1. **기준 상태 준비**: 큐비트를 초기 상태로 맞춤
2. **중첩 생성**: 단일 큐비트 게이트로 여러 상태의 조합을 만듦
3. **얽힘 게이트 적용**: 다중 큐비트 상관 구조를 형성함
4. **측정·분포 해석**: 반복 측정으로 결과 분포를 읽고 해석함

> 요약: 양자 회로는 중첩을 만들고 얽힘으로 상관을 형성한 뒤 측정 분포를 해석하는 흐름임.

### 쉽게 이해하기 (학습용)
- 동전을 세워두고(기준 상태 준비), 손끝으로 튕겨 돌리고(중첩 생성), 다른 동전과 실로 묶은 뒤(얽힘 게이트 적용), 여러 번 던져 나온 면의 비율을 살펴보는(측정·분포 해석) 순서와 같음

## Ⅵ. 실무 사례

1. 양자 회로 시뮬레이터는 상태 벡터로 중첩·얽힘을 계산하고 상태 충실도·측정 분포 오차를 확인함
2. NISQ 회로는 얽힘 게이트 수와 회로 깊이를 제한하고 얽힘 충실도·회로 성공률을 확인함

### 쉽게 이해하기 (학습용)
- 컴퓨터 안에서 동전 회전을 통째로 계산해 실제 던지기와 얼마나 비슷한지 맞혀보거나, 실이 끊기기 전에 묶는 동전 개수를 줄여 성공 확률을 관리하는 것과 같음

## Ⅶ. 결론

- 중첩은 단일 큐비트가 여러 기준 상태의 조합으로 진폭·위상을 갖는 성질이고, 얽힘은 여러 큐비트가 분리 불가능한 상관을 이루는 성질로 서로 다른 계산 자원을 제공함
- 두 성질 모두 측정해야 결과를 확인할 수 있으므로, NISQ 회로에서는 얽힘 게이트 수와 회로 깊이를 제한해 얽힘 충실도와 회로 성공률을 관리해야 함

### 쉽게 이해하기 (학습용)
- 중첩은 동전 하나를 돌리는 조작이고 얽힘은 여러 동전을 실로 묶는 조작이며, 결국 여러 번 던져봐야 그 결과가 믿을 만한지 알 수 있음
