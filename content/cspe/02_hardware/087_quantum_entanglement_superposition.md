## 미리 알고가기

- 중첩은 하나의 큐비트가 여러 기준 상태의 조합으로 존재하는 성질임
- 얽힘은 여러 큐비트 상태를 서로 떼어낼 수 없게 만드는 상관 구조임
- 측정은 양자 상태를 고전 결과로 바꾸며 상태를 바꿔 버리는 과정임

## Ⅰ. 개요

- **정의/개념**: 양자 중첩과 얽힘은 큐비트 정보 표현과 상호작용을 고전 비트와 구분하는 핵심 양자 자원으로, 중첩은 상태 표현 확장이고 얽힘은 다중 큐비트 상관 구조임
- **배경/필요성**: 양자 알고리즘은 단순히 많은 상태를 동시에 두는 것만으로 동작하지 않고 간섭과 상관 구조를 함께 활용하므로, 중첩과 얽힘의 역할 차이를 정확히 이해해야 함

## Ⅱ. 특징

- 중첩은 하나의 큐비트가 여러 상태의 조합을 표현하게 함
- 얽힘은 여러 큐비트가 개별 상태로 분리되지 않는 상관을 형성하게 함
- 측정 순간 상태가 바뀌므로 내부 상태를 직접 들여다보는 방식으로는 계산할 수 없음
- 잡음과 탈동조는 중첩과 얽힘을 빠르게 약화시킴

## Ⅲ. 종류 및 비교

| 판단 기준 | 중첩 | 얽힘 |
|:---|:---|:---|
| 적용 범위 | 단일 큐비트에도 성립함 | 두 개 이상 큐비트에서만 성립함 |
| 본질 | 상태가 여러 기준 상태의 조합으로 표현됨 | 여러 큐비트 상태가 분리 불가능한 상관을 가짐 |
| 생성 방식 | 단일 큐비트 게이트만으로도 만들 수 있음 | 두 큐비트 이상을 함께 다루는 게이트가 필요함 |
| 계산 역할 | 상태 공간 표현을 확장함 | 상관 구조와 간섭 효과를 강화함 |

> 요약: 중첩은 상태 표현을 확장하고, 얽힘은 여러 큐비트의 분리 불가능한 상관을 만듦.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 기준 상태 | $|0\\rangle$와 $|1\\rangle$가 중첩 표현의 출발점이 됨 |
| 진폭·위상 | 측정 확률과 간섭 방향을 정해 양자 상태 차이를 만듦 |
| 얽힘 게이트 | 여러 큐비트를 함께 제어하는 게이트가 상관 구조를 형성함 |
| 측정 과정 | 상태를 고전 결과로 바꾸며 전체 확률 분포만 관찰 가능하게 만듦 |

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 기준 상태 준비  | --> | 중첩 생성      | --> | 얽힘 게이트 적용 | --> | 측정·분포 해석  |
+-------------+     +-------------+     +-------------+     +-------------+
```

> 요약: 중첩과 얽힘은 기준 상태, 진폭·위상, 얽힘 게이트, 측정 과정으로 설명할 수 있음.

## Ⅴ. 원리 및 절차 흐름도

1. **기준 상태 준비**: 큐비트를 초기 상태로 맞춤
2. **중첩 생성**: 단일 큐비트 게이트로 여러 상태의 조합을 만듦
3. **얽힘 게이트 적용**: 다중 큐비트 상관 구조를 형성함
4. **측정·분포 해석**: 반복 측정으로 결과 분포를 읽고 해석함

> 요약: 양자 회로는 중첩을 만들고 얽힘으로 상관을 형성한 뒤 측정 분포를 해석하는 흐름임.

## Ⅵ. 실무 적용 및 유의점

1. 양자 알고리즘 교육에서는 중첩과 얽힘을 모두 병렬 계산으로만 묶어 설명하기 쉬우므로 상태 표현과 측정 모델을 함께 설명하고 시뮬레이션 일치도, 상태 정확도, 측정 분포 오차로 확인함
2. NISQ 회로 설계는 얽힘을 많이 넣을수록 계산 능력이 늘어날 것처럼 보이지만 잡음이 크면 성공률이 떨어지므로 회로 깊이와 얽힘 구조를 함께 최적화하고 얽힘 정확도, 회로 성공 확률, 탈동조 시간으로 확인함

## Ⅶ. 결론

중첩과 얽힘은 모두 양자 계산의 핵심이지만 중첩은 표현 자원이고 얽힘은 상관 자원이므로 역할을 나눠 이해해야 함.
