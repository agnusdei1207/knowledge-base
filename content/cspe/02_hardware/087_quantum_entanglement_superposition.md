## 미리 알고가기

- 중첩은 큐비트가 여러 기준 상태의 선형 결합으로 존재하는 성질임
- 얽힘은 여러 큐비트 상태가 분리 불가능한 상관 구조를 가지는 성질임
- 둘 다 양자 계산 자원이지만 의미가 같지는 않다

## Ⅰ. 개요

- **정의/개념**: 양자 중첩과 얽힘은 큐비트가 고전 비트와 다르게 정보를 표현하고 상호작용하게 만드는 핵심 양자 자원으로, 중첩은 단일 상태 표현의 확장이고 얽힘은 다중 큐비트 상관 구조임
- **배경/필요성**: 양자 알고리즘은 상태 공간 표현과 간섭을 활용해야 하므로, 중첩과 얽힘의 차이와 역할을 정확히 이해해야 계산 원리를 설명할 수 있음

## Ⅱ. 특징

- 중첩은 하나의 큐비트가 여러 상태를 함께 표현하게 함
- 얽힘은 여러 큐비트가 개별 상태로 분리될 수 없는 상관을 형성하게 함
- 측정 시 확률 붕괴가 일어나므로 결과는 직접 상태 전체를 보여주지 않음
- 탈동조와 잡음은 중첩과 얽힘을 빠르게 약화시킨다

## Ⅲ. 종류 및 비교

| 판단 기준 | 중첩 | 얽힘 |
|:---|:---|:---|
| 적용 범위 | 단일, 다중 큐비트 | 다중 큐비트 |
| 본질 | 상태의 선형 결합 | 분리 불가능한 상관 |
| 생성 방식 | 단일 큐비트 게이트 | 2큐비트 이상 게이트 |
| 계산 역할 | 상태 공간 확장 | 상관과 간섭 구조 강화 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Basis State | `|0>`, `|1>` 기준 상태가 중첩 표현의 바탕이 됨 |
| Amplitude, Phase | 진폭과 위상이 간섭과 측정 확률을 결정함 |
| Entangling Gate | CNOT와 CZ 같은 게이트가 큐비트 사이 비분리 상관을 만듦 |
| Measurement Process | 최종 관측이 확률 분포를 고전 결과로 바꾸며 상태를 붕괴시킴 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 기준 상태 준비  | --> | 중첩 생성      | --> | 얽힘 게이트 적용 | --> | 측정/분포 해석  |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **기준 상태 준비**: 큐비트를 초기 상태로 맞춤
2. **중첩 생성**: 단일 큐비트 게이트로 여러 상태의 조합을 만듦
3. **얽힘 게이트 적용**: 다중 큐비트 상관 구조를 형성함
4. **측정 및 분포 해석**: 확률 결과를 반복 샘플링해 해석함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 중첩과 얽힘을 모두 병렬 계산으로만 설명하면 측정과 간섭 원리를 놓쳐 개념 해석이 왜곡될 수 있다
   - 해결방안: 상태 표현과 측정 모델을 함께 설명하고 conceptual consistency와 simulation agreement로 검증함
2. 문제: 환경 잡음은 얽힘을 빠르게 무너뜨려 알고리즘이 요구하는 상관 구조를 유지하기 어렵게 만든다
   - 해결방안: 고충실도 게이트와 error mitigation을 적용하고 entanglement fidelity와 coherence time으로 검증함
3. 문제: 얽힘을 많이 만드는 회로는 제어 오류와 읽기 오류가 함께 누적돼 실제 계산 성공률이 떨어질 수 있다
   - 해결방안: 회로 깊이와 얽힘 구조를 최적화하고 circuit success probability와 gate error accumulation으로 검증함

## Ⅶ. 적용 사례

- 양자 회로 교육에서는 Hadamard와 CNOT 실험으로 개념을 설명하고 확인 지표는 state fidelity와 measurement distribution임
- 양자 통신 연구에서는 얽힘 분배를 실험하고 확인 지표는 entanglement fidelity와 decoherence time임
- NISQ 알고리즘 설계에서는 얽힘 깊이를 제한하고 확인 지표는 circuit depth와 success probability임

## Ⅷ. 결론

중첩과 얽힘은 모두 양자 계산의 핵심이지만 중첩은 표현 자원이고 얽힘은 상관 자원이므로, 둘의 역할을 분리해 이해해야 양자 알고리즘이 명확해짐.
