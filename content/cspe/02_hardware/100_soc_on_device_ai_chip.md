## 미리 알고가기

- SoC는 CPU와 GPU와 NPU와 메모리와 I/O를 하나의 칩에 통합한 구조임
- 온디바이스 AI는 클라우드로 보내지 않고 단말 내부에서 추론을 수행하는 방식임
- TOPS는 연산 처리량 지표이며 실제 추론 지연은 메모리 대역폭·열 한도·연산자 매핑의 영향도 받음
- DVFS(Dynamic Voltage and Frequency Scaling)는 부하에 따라 전압·주파수를 조절해 전력과 발열을 관리하는 기법임

## 작성 근거(검토용)

- 온디바이스 AI SoC는 CPU·GPU·NPU 역할, 메모리 이동, 연산자 호환성, 전력·보안을 핵심 축으로 설명함
- 비교표는 클라우드와 단말 추론의 지연 경로, 개인정보 노출, 자원·운영 관리를 대비함
- 실무 판단은 NPU 실행 비율·추론 지연과 전력당 추론량·열 제한 발생률로 검증함

## Ⅰ. 개요

- **정의/개념**: SoC AI 온디바이스 칩은 CPU와 GPU와 NPU와 메모리 서브시스템과 보안 블록을 단일 칩에 통합해 단말 내부에서 AI 추론을 수행하도록 설계한 시스템 반도체임
- **배경/필요성**: 네트워크 왕복 지연과 원본 데이터 외부 전송을 줄이기 위해 단말의 전력·열 한도 안에서 추론하는 칩 구성이 필요함

### 쉽게 이해하기 (학습용)
- 요리사(CPU), 보조 요리사(GPU), 전담 요리사(NPU)가 한 주방(칩)에 다 있어서, 재료를 다른 식당(클라우드)에 보내지 않고 그 자리에서 바로 요리하는 것과 같음

## Ⅱ. 특징

- NPU가 행렬·텐서 연산을 수행해 CPU의 추론 연산을 분담함
- 메모리 대역폭과 온칩 버퍼 재사용률이 NPU 유휴 시간과 추론 지연을 결정함
- 연산자 호환성과 양자화 지원 수준이 활용 가능한 모델 범위를 결정함
- Secure Boot와 서명된 OTA 업데이트로 검증된 모델만 실행함

### 쉽게 이해하기 (학습용)
- 전담 요리사가 있어도 재료(데이터)가 제때 안 오면 손이 놀고, 주방 레시피에 없는 요리(비지원 연산자)는 못 만들며, 검증된 레시피만 조리하도록 문을 걸어둠

## Ⅲ. 종류 및 비교

| 판단 기준 | 클라우드 AI 처리 | 온디바이스 AI SoC |
|:---|:---|:---|
| 지연 경로 | 단말·네트워크·서버 왕복과 서버 대기 포함 | 단말의 NPU·메모리·CPU 처리 시간 포함 |
| 개인정보 | 원본 데이터 외부 전송 부담이 큼 | 로컬 처리로 데이터 노출 범위를 줄일 수 있음 |
| 자원·운영 관리 | 서버의 연산·메모리 자원을 수평 확장하며 자원 비용을 관리함 | 전력·열·메모리 한도 안에서 모델 경량화·칩 호환성·업데이트를 관리함 |

> 요약: 클라우드 추론은 네트워크·서버 자원을, 온디바이스 추론은 전력·열·메모리·칩 호환성을 기준으로 설계함.

### 쉽게 이해하기 (학습용)
- 클라우드 추론은 재료를 멀리 있는 본점 주방으로 보내 요리해 받아오는 것이고, 온디바이스 추론은 내 매장 주방에서 바로 조리해 내오는 것과 같음

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| CPU·GPU | 전처리와 후처리와 범용 제어를 맡아 NPU가 처리하지 않는 작업을 보완함 |
| NPU | CNN·Transformer의 행렬·텐서 연산을 전용 실행 유닛으로 처리함 |
| 메모리 서브시스템 | 가중치와 활성화 값을 공급하며 NPU 유휴 시간과 추론 지연에 영향을 줌 |
| 보안·전력 블록 | 모델 무결성 검증과 DVFS 제어를 담당해 보안성과 배터리 수명을 좌우함 |

> 요약: CPU·GPU가 전후 처리를 맡고 NPU가 추론하며 메모리·보안·전력 블록이 데이터 공급과 실행 조건을 통제함.

### 쉽게 이해하기 (학습용)
- 재료 손질과 플레이팅을 맡는 보조 요리사(CPU·GPU), 회를 전담해 뜨는 주방장(NPU), 재료를 제때 공급하는 창고 담당(메모리 서브시스템), 위생·전기 사용을 관리하는 매니저(보안·전력 블록)로 구성됨

## Ⅴ. 원리 및 절차 흐름도

1. **모델 준비**: 목표 정확도와 입력 크기와 지연 요구에 맞는 모델을 선정함
2. **칩 맞춤 최적화**: 양자화와 연산자 매핑으로 모델을 NPU 형식에 맞춤 변환함
3. **추론 실행**: NPU와 메모리와 DMA와 CPU가 협력해 추론 파이프라인을 수행함
4. **결과·업데이트**: 후처리와 보안 검증과 OTA 모델 갱신을 운영함

> 요약: 모델을 NPU 지원 연산자와 정밀도에 맞춰 변환하고 DMA·메모리·CPU 후처리를 연결해 추론함.

### 쉽게 이해하기 (학습용)
- 메뉴를 정하고, 주방 도구에 맞게 레시피를 손질하고, 실제로 조리한 뒤, 맛을 확인하고 새 레시피로 갱신하는 순서와 같음

## Ⅵ. 실무 사례

1. 엣지 카메라는 모델 연산자를 NPU에 매핑하고 양자화를 적용해 NPU 실행 비율·추론 지연을 확인함
2. 모바일 단말은 온칩 버퍼 재사용과 DVFS를 적용하고 전력당 추론량·열 제한 발생률을 확인함

### 쉽게 이해하기 (학습용)
- 엣지 카메라는 레시피를 주방장 전용 도구에 맞게 다듬어 조리 시간을 재고, 모바일 기기는 불 세기를 조절해 화상을 입지 않으면서도 얼마나 많이 만드는지 재는 것과 같음

## Ⅶ. 결론

- 온디바이스 AI SoC는 CPU·GPU·NPU와 메모리·보안 블록을 한 칩에 통합해 단말 전력·열 한도 안에서 추론하는 시스템 반도체임
- TOPS 수치만으로 성능을 판단하지 않고 연산자 지원률·메모리 대역폭·전력당 추론량을 함께 검증해 모델 경량화와 칩 선택 기준을 정해야 함

### 쉽게 이해하기 (학습용)
- 주방 화력(TOPS)만 세다고 좋은 게 아니라, 재료 공급 속도와 레시피 호환, 불 세기 조절까지 함께 봐야 진짜 실력 있는 주방임
