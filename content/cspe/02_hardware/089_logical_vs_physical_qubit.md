# 논리 큐비트 vs 물리 큐비트 (Logical vs Physical Qubit)

## 미리 알고가기

- 큐비트: `0`과 `1`의 중첩 상태를 이용해 양자 정보를 표현하는 최소 단위임
- 물리 큐비트: 초전도 회로, 이온, 광자 등 실제 장치 위에 구현된 큐비트임
- 논리 큐비트: 여러 물리 큐비트를 오류 정정 코드로 묶어 하나의 신뢰 가능한 큐비트처럼 쓰는 추상 큐비트임
- 양자 오류 정정(QEC, Quantum Error Correction): 측정으로 상태를 직접 복사하지 않고 신드롬을 측정해 오류 위치와 종류를 추정하는 기술임

## 1. 개요

- **정의/개념**: 물리 큐비트는 실제 양자 소자 하나가 제공하는 불안정한 연산 단위이고, 논리 큐비트는 다수 물리 큐비트의 오류를 코드 거리와 오류율 기준으로 억제해 알고리즘 실행에 쓰는 신뢰 단위로, 두 개념은 양자 컴퓨터 규모 산정과 오류 정정 오버헤드 평가에 사용됨
- **배경/필요성**: 물리 큐비트는 결맞음 시간, 게이트 오류, 측정 오류 때문에 긴 회로를 직접 실행하기 어려움. 실용 양자 계산은 물리 큐비트 수가 아니라 충분히 낮은 논리 오류율을 제공하는 논리 큐비트 수로 판단해야 함
- **비유**: 물리 큐비트가 잘 흔들리는 얇은 나무판이라면, 논리 큐비트는 여러 나무판을 격자로 묶어 사람이 건널 수 있게 만든 발판임

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 양자 오류 정정 기반 확장성 판단 | 물리 오류율, 코드 거리, 논리 오류율, 오버헤드 | 큐비트 수 단순 비교 |

> 요약: 양자 컴퓨터의 실효 규모는 물리 큐비트 수보다 논리 큐비트의 오류율과 생성 비용으로 판단함.

## 2. 특징 및 비교

| 판단 기준 | 물리 큐비트 | 논리 큐비트 |
|:---|:---|:---|
| 구현 단위 | 실제 양자 소자와 제어 회로 | 오류 정정 코드로 묶은 추상 연산 단위 |
| 품질 지표 | 결맞음 시간, 단일/2큐비트 게이트 오류율 | 논리 오류율, 코드 거리, 임계값 초과 여부 |
| 확장 기준 | 칩 수율, 배선, 냉각, 제어 채널 | 목표 알고리즘 회로 깊이와 허용 실패 확률 |
| 비용 구조 | 소자 제조와 캘리브레이션 비용 중심 | 물리 큐비트, 측정 사이클, 디코더 비용이 누적됨 |

> 요약: 물리 큐비트는 구현 가능성을, 논리 큐비트는 실제 계산 가능성을 판단하는 기준임.

- **적용 조건**: 목표 알고리즘의 회로 깊이와 허용 실패 확률이 먼저 정의되어야 함
- **선택 지표**: 물리 오류율, 코드 거리, 논리 오류율을 함께 봐야 함
- **운영 관점**: 큐비트 제어·측정·디코딩이 같은 시간 예산 안에 묶여야 함

## 3. 구성요소/구조

```text
+----------------+      +----------------+      +----------------+
| Physical qubit | ---> | QEC code block | ---> | Logical qubit  |
+----------------+      +----------------+      +----------------+
        |                       |                        |
        v                       v                        v
+----------------+      +----------------+      +----------------+
| Gate/measure   |      | Syndrome data  |      | Logical error |
+----------------+      +----------------+      +----------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 물리 큐비트 | 양자 상태를 실제 소자에 저장하고 게이트·측정 연산을 수행함 | 낱개의 불안정한 부품 |
| 오류 정정 코드 | 데이터 큐비트와 보조 큐비트를 배치해 비트/위상 오류 신드롬을 추출함 | 충격을 분산하는 격자 |
| 디코더 | 신드롬 이력으로 오류 위치를 추정하고 보정 연산을 결정함 | 흔들림 원인을 찾는 관제실 |
| 논리 연산 | 코드 공간을 유지한 채 논리 게이트, 측정, 초기화를 수행함 | 보강된 발판 위 작업 |

> 요약: 논리 큐비트는 물리 소자, 오류 정정 코드, 디코더가 결합되어 낮은 오류율의 연산 단위를 만드는 구조임.

### 원리/흐름도

```text
+----------+      +----------+      +----------+      +----------+
| Prepare  | ---> | Syndrome | ---> | Decode   | ---> | Logical  |
+----------+      +----------+      +----------+      +----------+
```

1. **물리 상태 준비**: 데이터 큐비트와 보조 큐비트를 초기화하고 코드 격자에 배치함
2. **신드롬 반복 측정**: 안정자 측정으로 상태를 직접 붕괴시키지 않고 오류 징후를 수집함
3. **디코딩·보정**: 시간 축 신드롬을 분석해 보정 연산 또는 Pauli frame 갱신을 수행함
4. **논리 연산 실행**: 목표 논리 오류율을 만족하는 상태에서 논리 게이트와 측정을 수행함

> 요약: 논리 큐비트는 물리 오류를 반복 관측·추정·보정한 뒤 알고리즘이 사용할 안정 연산으로 제공됨.

## 4. 문제점 및 개선방안

- **P1 높은 오버헤드**: 낮은 논리 오류율을 얻으려면 코드 거리 증가에 따라 물리 큐비트와 측정 사이클이 크게 늘어남
- **P1 대응**: 물리 게이트 충실도 개선, 코드 거리별 논리 오류율 실측, 모듈형 확장 구조를 병행함 (확인: 주기당 논리 오류율)
- **P2 디코딩 지연**: 신드롬을 실시간으로 처리하지 못하면 피드백 연산이 늦어져 논리 오류가 누적됨
- **P2 대응**: FPGA(Field-Programmable Gate Array)/ASIC(Application-Specific Integrated Circuit) 기반 저지연 디코더와 Pauli frame 추적으로 피드백 경로를 단축함 (확인: 디코더 지연)
- **P3 상관 오류**: 제어선 잡음, 누설, 크로스토크가 독립 오류 가정을 깨면 오류 정정 성능 예측이 빗나감
- **P3 대응**: 누설 제거, 크로스토크 캘리브레이션, 상관 오류를 반영한 노이즈 모델을 운영함 (확인: 상관 오류율)

> 요약: 논리 큐비트 확보는 소자 품질, 제어 지연, 오류 모델을 함께 낮추는 공학 문제임.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| 양자 알고리즘 자원 산정 | 필요한 논리 큐비트 수와 회로 깊이를 기준으로 물리 큐비트 수, 코드 거리, 실행 시간을 계산함 | logical qubit count, physical qubit budget, expected runtime |
| 오류 정정 제어 경로 설계 | 신드롬 측정, 디코더, Pauli frame 갱신을 제어 루프 안에 배치해 피드백 지연을 제한함 | syndrome cycle time, decoder latency, frame update delay |
| 벤치마크 검증 | 물리 큐비트 수 발표와 별도로 논리 오류율과 코드 거리 조건을 요구해 과장된 규모 지표를 걸러냄 | logical error rate, code distance, benchmark condition |

> 요약: 실무에서는 물리 큐비트 수가 아니라 목표 문제를 실행할 논리 큐비트 예산과 오류율을 중심으로 판단해야 함.

## 6. 결론

- **발전 방향**: 표면 코드 중심에서 LDPC(Low-Density Parity-Check) 코드, 보손 코드, 모듈형 양자 네트워크와 결합해 물리 큐비트 오버헤드를 줄이는 방향으로 발전함
- **기술사적 판단**: 양자 시스템 도입 평가는 총 물리 큐비트 수보다 목표 문제의 논리 큐비트 수, 회로 깊이, 허용 실패 확률을 기준으로 해야 함
- **기술사 제언**: 벤치마크에는 물리 오류율, 논리 오류율, 디코딩 지연, 코드 거리 조건을 함께 명시해 과장된 규모 지표를 배제해야 함
