## Ⅰ. 개요
- 정의: 낸드 플래시의 각 블록별 쓰기/지우기(P/E) 횟수를 균등하게 분산시키는 기술
- 배경: 특정 블록의 과도한 사용으로 인한 조기 마모 및 데이터 유실 방지 필요
- 출제 의도
| 구분 | 내용 |
| --- | --- |
| 핵심 | 정적(Static) vs 동적(Dynamic) 방식, 수명 연장, 수치 균형 |

## Ⅱ. 구성요소
```
[ Free Blocks ] [ Used Blocks (Cold) ] [ Used Blocks (Hot) ]
       \               /                      /
        \---- [ Wear Leveling Logic ] -------/
```
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 지우기 횟수(EC) | 각 물리 블록이 겪은 삭제/재기록 횟수 카운트 | 주행 거리 |
| 동적 웨어 레벨링 | 새 데이터 저장 시 사용 횟수가 적은 빈 블록 우선 할당 | 새 신발 고르기 |
| 정적 웨어 레벨링 | 데이터가 고정된(Cold) 블록까지 강제로 이동시켜 분산 | 가구 재배치 |
> 요약: 모든 블록의 마모도를 비슷하게 유지하여 SSD 전체 수명을 최대화함

## Ⅲ. 절차
1. 사용량 모니터링: FTL이 각 블록의 P/E Cycle 횟수를 실시간 추적
2. 편차 분석: 최다 사용 블록과 최소 사용 블록 간의 격차(Delta) 계산
3. 데이터 이관: 임계치 초과 시 콜드 데이터를 마모가 심한 블록으로 이동
4. 가용 블록 확보: 마모가 적은 블록을 다음 쓰기 작업을 위해 해제
> 요약: 소프트웨어적 제어를 통해 하드웨어의 물리적 수명 한계를 평탄화함

## Ⅳ. 문제점
- 데이터 이동에 따른 추가적인 쓰기 작업으로 인해 성능 일시 저하 발생함

## Ⅴ. 개선방안
- 유휴 시간(Idle Time)을 활용한 백그라운드 스케줄링 및 지능형 임계치 설정함

## Ⅵ. 전망
- 셀 수명이 짧은 QLC 보급 확대로 인해 더욱 정교한 확률 기반 웨어 레벨링 요구됨
- 수명 예측 AI 모델과 결합하여 장애 발생 전 데이터 백업을 유도하는 기술이 CSF임
