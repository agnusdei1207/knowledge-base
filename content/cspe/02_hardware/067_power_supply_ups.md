## 미리 알고가기

- PSU는 장비 내부에 안정된 DC 전력을 공급하는 장치임
- UPS는 외부 전원 장애 시 배터리와 전력 변환으로 부하를 연속 공급하는 설비임
- 핵심 판단 기준은 정격 용량, 백업 시간, 이중화 구조, 절체 안정성임

## Ⅰ. 개요

- **정의/개념**: 전원 공급 장치와 UPS는 외부 AC 전원을 장비가 사용할 수 있는 안정된 전력으로 변환하고, 정전이나 전압 이상 시에도 서버와 네트워크 장비의 전력 연속성을 유지하게 하는 전원 보호 체계임
- **배경/필요성**: 데이터센터와 산업 설비는 순간 전원 품질 저하만으로도 장비 재부팅과 데이터 손상과 서비스 중단이 발생하므로, 전력 연속성과 전압 안정성이 필수임

## Ⅱ. 특징

- PSU는 장비 단위 전력 변환과 이중화의 핵심임
- UPS는 순간 정전과 전압 강하를 흡수해 상위 서비스 연속성을 보장함
- 용량 설계와 배터리 지속시간과 이중화 수준이 실제 가용성을 결정함
- 정격만 충분해도 절체 시험과 유지보수가 부실하면 보호 효과가 무너질 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | 단일 PSU | 이중 PSU + UPS | N+1, 2N UPS 구조 |
|:---|:---|:---|:---|
| 가용성 | 낮음 | 높음 | 매우 높음 |
| 초기 비용 | 낮음 | 중간 | 높음 |
| 장애 대응 | 취약 | 장비 단위 보호 | 설비 단위 보호 |
| 대표 환경 | 소규모 장비 | 일반 서버실 | 핵심 데이터센터 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Input Power, Rectifier | 외부 AC를 안정된 DC로 변환해 배터리와 부하에 공급함 |
| Battery System | 정전 시 즉시 전력을 제공하며 백업 시간과 노후화 관리가 핵심임 |
| Inverter, Bypass | DC를 다시 AC로 변환하고 비상 우회 경로를 제공해 절체 안정성을 높임 |
| PSU, PDU, Monitoring | 장비 내부 전력 공급과 분배와 상태 감시를 담당해 현장 가용성을 결정함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 부하 산정      | --> | 전원 경로 설계  | --> | 정전 시 절체    | --> | 감시/배터리 관리 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **부하 산정**: 서버와 네트워크 장비의 정격과 피크 전력을 계산함
2. **전원 경로 설계**: PSU, UPS, PDU와 이중화 수준을 결정함
3. **정전 시 절체**: UPS가 순간 전원을 공급하고 발전기나 상위 전원으로 연계함
4. **감시 및 배터리 관리**: 상태를 지속 점검하고 교체 주기를 관리함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 부하 증가에 비해 UPS 용량과 배터리 시간이 부족하면 정전 시 예상보다 빨리 서비스가 중단될 수 있음
   - 해결방안: capacity planning과 runtime simulation을 수행하고 backup duration과 load margin으로 검증함
2. 문제: 배터리 열화와 인버터 고장은 평상시에는 드러나지 않다가 실제 장애 시 연속성을 무너뜨릴 수 있음
   - 해결방안: 정기 부하시험과 battery health monitoring을 적용하고 internal resistance와 failover success rate로 검증함
3. 문제: 단일 전원 경로나 단일 PSU 구성은 한 부품 고장만으로도 시스템 전체 중단을 유발할 수 있음
   - 해결방안: dual PSU와 A, B 전원 경로를 구성하고 power path redundancy와 MTBF improvement로 검증함

## Ⅶ. 적용 사례

- 데이터센터 랙 서버에서는 이중 PSU와 A, B 전원 경로를 적용하고 확인 지표는 power path redundancy와 failover success rate임
- 금융 전산실 UPS 설계에서는 정전 지속시간 목표를 반영하고 확인 지표는 backup duration과 SLA compliance임
- 산업 제어실에서는 순간 전압 강하 대응 UPS를 운영하고 확인 지표는 outage incident reduction과 control uptime임

## Ⅷ. 결론

전원 공급과 UPS 설계의 핵심은 장비 정격보다 장애 시 얼마나 오래 안정적으로 전력을 이어줄 수 있느냐에 있으므로, 용량과 이중화와 점검 체계를 함께 봐야 함.
