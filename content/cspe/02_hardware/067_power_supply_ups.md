# 📖 【암기용】 개념 완전 이해

> 목적: 전원 공급 장치와 UPS를 처음 봐도 정전 발생 시 무엇이 서버를 지켜주는지 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: PSU(Power Supply Unit)는 상용 AC 전원을 서버가 쓰는 DC로 변환하는 장치이고, UPS(Uninterruptible Power Supply)는 정전 시 배터리로 전원을 즉시 공급해 서버 다운을 막는 무정전 전원 장치
- **왜 필요한가**: 서버는 전원이 순간이라도 끊기면 재부팅과 데이터 손실이 발생하므로, 정전·전압 변동에도 끊김 없이 전원을 유지할 이중화 설계가 필요하다.
- **핵심 직관**: PSU는 콘센트 전기를 가전제품이 쓸 수 있는 형태로 바꿔주는 어댑터이고, UPS는 정전되는 순간 자동으로 대신 전기를 공급하는 보조 배터리다.

## 깊이 이해
- **배경·문제의식**: 데이터 센터는 순간 정전(수 ms)만으로도 서비스 중단이 발생할 수 있어, 발전기가 기동하는 수십 초 동안 공백을 메울 장치가 필요하다.
- **작동 원리**: PSU는 AC-DC 변환과 함께 서버 내부에서 1+1 또는 2N 이중화로 구성돼 한 PSU 장애 시 다른 PSU가 즉시 부하를 인수한다.
- **작동 원리**: UPS는 방식에 따라 스탠바이(오프라인), 라인 인터랙티브, 온라인(더블 컨버전) 3가지로 나뉜다.
- **작동 원리**: 스탠바이 UPS는 평상시 상용 전원을 그대로 통과시키다가 정전 감지 시 배터리로 전환하며 전환 시간이 수 ms 존재한다.
- **작동 원리**: 온라인(더블 컨버전) UPS는 상시 AC를 DC로 정류 후 다시 AC로 역변환해 부하에 공급하므로 전환 시간이 0에 가깝고 전압·주파수 변동, 노이즈까지 상시 보정한다.
- **비유**: 스탠바이 UPS는 평소 안 쓰다가 정전되면 급히 꺼내는 손전등이고, 온라인 UPS는 항상 켜져 있어 정전 여부와 무관하게 일정한 빛을 내는 조명이다.
- **구체 예시**: UPS 배터리 runtime은 통상 5~15분으로 설계돼, 그 사이 디젤 발전기가 기동(통상 10~30초)해 상용 전원을 대체한다.
- **흔한 오해·주의점**: UPS는 장시간 정전을 버티는 장치가 아니다. 배터리 용량은 발전기 기동까지의 공백을 메우는 용도이며, 장시간 정전 대비는 발전기·연료 저장이 담당한다.
- **흔한 오해·주의점**: PSU 이중화(1+1)와 UPS는 다른 계층의 이중화다. PSU 이중화는 서버 내부 전원 장애 대응이고, UPS는 상용 전원 자체의 정전 대응이다.

## 연결 개념
- 데이터 센터 등급(TIA-942 Tier) — UPS·발전기 이중화 수준이 등급을 결정하는 핵심 요소
- 냉각 시스템 — 전원과 함께 데이터 센터 가용성을 구성하는 양대 인프라
- PUE — 전원 변환 손실이 시설 에너지 효율에 미치는 영향

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.
> 핵심: 전원 공급 장치·UPS 답안은 PSU 이중화, UPS 3방식 차이, 발전기 연계 시간까지 함께 제시한다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: PSU는 AC를 DC로 변환하는 서버 내부 전원 장치이고, UPS는 정전 시 배터리로 무순단 전원을 공급하는 외부 이중화 장치다.
> 2. **가치**: PSU 이중화(1+1, 2N)와 온라인 UPS의 무순단 전환이 결합돼 정전과 전원 장애로부터 서버 가동을 보호한다.
> 3. **판단 포인트**: 미션 크리티컬 환경은 전환 시간 0에 가까운 온라인 더블 컨버전 UPS를, 일반 환경은 비용이 낮은 라인 인터랙티브 UPS를 선택한다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| PSU·UPS 역할 구분 확인 | AC-DC 변환(PSU) vs 정전 대응(UPS) | PSU와 UPS를 동일 장치로 혼동 |
| UPS 방식별 차이 확인 | 스탠바이·라인 인터랙티브·온라인의 전환 시간 차이 | 방식 구분 없이 "UPS는 배터리"로만 서술 |
| 이중화 설계 이해 확인 | PSU 1+1/2N, UPS-발전기 연계 시간 | UPS만 있으면 무한정 버틴다고 서술 |

> 요약: 이 문제는 UPS 존재 자체보다 방식별 전환 시간 차이와 발전기 연계 설계를 보여야 한다.

## Ⅰ. 개요 및 필요성

- 정의: PSU는 AC를 서버용 DC로 변환하는 장치, UPS는 정전 시 배터리로 무순단 전원을 공급하는 장치
- 배경: 순간 정전만으로도 서버 다운과 데이터 손실이 발생할 수 있어 발전기 기동 전까지 공백을 메울 장치가 필요함
- 필요성: PSU 이중화와 UPS-발전기 연계 설계로 정전 시에도 서버 가동을 연속적으로 유지해야 함

---

## Ⅱ. 구조 및 구성요소

```text
상용 AC 전원 -> UPS(배터리/AVR)
  -> PDU(전력 분배)
  -> Server PSU(1+1 또는 2N 이중화)
  -> 서버 부하
분기: 정전 발생 -> UPS 배터리 전환 -> 발전기 기동(10~30초) -> 발전기 전원 인수
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| PSU | AC-DC 변환, 서버 내부 이중화 | 1+1, 2N 구성 |
| UPS | 정전 시 배터리로 즉시 전원 공급 | 스탠바이/라인 인터랙티브/온라인 |
| PDU | 랙 단위 전력 분배 | 이중 전원 경로(A/B feed) |
| 발전기 | UPS 배터리 소진 전 상용 전원 대체 | 기동 시간 10~30초 |
| 배터리 뱅크 | UPS 전환 후 runtime 공급 | 통상 5~15분 설계 |

> 요약: 정전 시 UPS 배터리가 즉시 부하를 인수하고 발전기가 기동해 장시간 전원을 대체한다.

---

## Ⅲ. 동작원리 및 흐름도

```text
정전 발생 -> UPS 정전 감지
  -> (스탠바이: 배터리 전환 수 ms) / (온라인: 전환 시간 0에 가까움)
  -> 배터리 runtime 공급 -> 발전기 기동
  -> 발전기 전원 안정화 -> UPS가 발전기 전원으로 복귀
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 정전 감지 및 UPS 방식별 전환 | 전환 시간(ms), 방식(스탠바이/온라인) |
| 2 | 배터리 runtime으로 부하 공급 | runtime 목표치(5~15분) |
| 3 | 발전기 기동 및 전원 안정화 | 기동 시간(10~30초), 전압·주파수 안정화 |
| 4 | 발전기 전원으로 UPS 입력 전환 | 전환 성공률, 재정전 대응 여부 |

> 요약: UPS는 정전 즉시 배터리로 부하를 인수하고, 발전기 기동 완료 후 전원을 상용에서 발전기로 전환한다.

## Ⅳ. 특징

| 구분 | 스탠바이 UPS | 온라인(더블 컨버전) UPS | 수치·표준 포인트 |
|:---|:---|:---|:---|
| 처리 기준 | 평상시 상용 전원 통과, 정전 시 배터리 전환 | 상시 AC-DC-AC 변환 후 공급 | 전환 시간 수 ms vs 0에 가까움 |
| 정책 범위 | 일반 사무 환경 | 미션 크리티컬 데이터 센터 | 전압·주파수·노이즈 보정 여부 |
| 비용 | 구성 단순, 비용 낮음 | 상시 변환으로 비용·발열 높음 | 변환 손실률(효율 94~97%) |
| 보호 범위 | 정전만 대응 | 정전·전압 새그·서지·노이즈까지 보정 | 전력 품질 보정 범위 |

> 요약: 일반 환경은 스탠바이·라인 인터랙티브, 미션 크리티컬 환경은 온라인 더블 컨버전 UPS가 적합하다.

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 스탠바이/라인 인터랙티브 | 온라인(더블 컨버전) | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | 정전 감지 후 배터리 전환 | 상시 AC-DC-AC 변환 | 전환 시간 허용치 |
| 비용/성능 | 비용 낮고 변환 손실 적음 | 비용 높고 상시 변환 손실 발생 | 데이터 센터 등급(Tier) 요구 |
| 운영/위험 | 전환 순간 미세 순단 가능 | 상시 변환 발열 관리 필요 | 냉각 설계 여유 |

> 요약: Tier 3 이상 미션 크리티컬 환경은 온라인 UPS, 일반 환경은 스탠바이·라인 인터랙티브를 선택한다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 배터리 소진 | 발전기 기동 지연 | 배터리 runtime 여유 확보, 발전기 정기 점검 | 배터리 잔량, 발전기 기동 성공률 |
| PSU 단일 장애 | 이중화 미구성 | PSU 1+1 또는 2N 이중화 적용 | PSU 장애 시 부하 인수 성공률 |
| 전력 품질 저하 | 서지·노이즈 미보정 | 온라인 UPS 또는 AVR 적용 | 전압·주파수 변동폭 |

> 요약: 전원 인프라 운영은 배터리 runtime, PSU 이중화, 전력 품질 보정 지표로 통제한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 가용성 | PSU 이중화(1+1 이상) 적용 여부 | 구성 점검표 |
| 전환 성능 | UPS 전환 시간 목표치 이하 | 정전 모의 테스트 |
| 배터리 상태 | runtime 목표치(5~15분) 충족 | 배터리 점검, 방전 테스트 |

> 요약: 도입 후 성공 여부는 PSU 이중화율, UPS 전환 시간, 배터리 runtime 충족 여부로 판단한다.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 — 단계별 또는 항목별):**
1. 미션 크리티컬 서버는 PSU 2N 이중화와 온라인 더블 컨버전 UPS를 적용해 전환 시간을 0에 가깝게 설계함
2. UPS 배터리 runtime을 5~15분으로 설계하고 발전기 기동 시간(10~30초)과의 공백을 정기 방전 테스트로 검증함
3. PDU를 A/B 이중 전원 경로로 구성해 UPS 또는 PSU 한쪽 장애 시에도 서버 부하가 유지되도록 함

**결론 (2줄):**
- 기술사 판단: Tier 3 이상 미션 크리티컬 환경은 온라인 UPS와 PSU 2N을, 일반 환경은 비용 효율적인 라인 인터랙티브 UPS를 선택함
- 향후 방향: 리튬이온 배터리와 플라이휠 UPS 도입으로 배터리 수명과 응답 속도가 개선되는 방향으로 발전함
