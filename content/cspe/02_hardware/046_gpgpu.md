## Ⅰ. 개요
- 그래픽 전용 GPU를 일반적인 범용 계산에 활용하는 기술
- CPU의 순차 처리 한계를 극복하기 위한 병렬 컴퓨팅 기법

| 구분 | 내용 |
| --- | --- |
| 정의 | GPU 아키텍처를 그래픽 외의 수치 연산에 사용하는 기술 |
| 필요성 | 빅데이터 분석, 암호 해독, 과학 시뮬레이션 가속 필요 |
| 출제의도 | CPU와 GPU의 구조적 차이 및 범용 활용 기술 이해 |

## Ⅱ. 구성요소
```
+-------+   [ Global Memory ]   +-------+
|  CPU  | <-------------------> |  GPU  |
+-------+      (PCIe/NVLink)    +-------+
| Control|                      |  ALU  |
| Cache  |                      |  ALU  |
| ALU    |                      |  ALU  |
+-------+                      +-------+
```
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| API/SDK | CUDA, OpenCL 등 개발을 위한 인터페이스 | 소통 언어 |
| Thread Hierarchy | Thread > Warp > Block > Grid 구조 관리 | 조직 계급 |
| Memory Hierarchy | Shared, Global, Constant 메모리 체계 | 책상과 창고 |
> 요약: 소프트웨어 계층(API)을 통해 하드웨어 병렬성 제어함.

## Ⅲ. 절차
```
[문제 분할] -> [메모리 할당] -> [커널 실행] -> [동기화/수집]
```
1. 문제 분할: 문제를 수만 개의 독립적인 작은 연산으로 쪼갬.
2. 메모리 할당: GPU 내부 메모리 공간을 확보하고 데이터 전송함.
3. 커널 실행: 다수의 워프(Warp) 단위로 스레드를 병렬 실행함.
4. 결과 수집: 연산 완료 후 각 스레드의 결과를 취합하여 반환함.
> 요약: 작업을 세분화하여 수천 개의 코어에 분배·실행함.

## Ⅳ. 문제점
- 프로그래밍 복잡성: 메모리 정렬 및 동기화 관리가 까다로움.
- 분기 예측 효율 저하: 조건문(if) 사용 시 스레드 분기로 성능 급감함.

## Ⅴ. 개선방안
- 라이브러리 활용: CuBLAS, CuDNN 등 최적화된 라이브러리 사용 권장함.
- 분기 최소화 설계: Warp 내 실행 경로를 일치시키는 알고리즘 최적화함.

## Ⅵ. 전망
- Unified Memory 기술 발전을 통한 CPU-GPU 메모리 경계 제거 가속화됨.
- 클라우드 기반 가상화 GPGPU 자원 할당 기술이 핵심 성공 요인(CSF)임.
