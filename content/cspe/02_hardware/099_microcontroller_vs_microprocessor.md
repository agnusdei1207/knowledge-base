## 미리 알고가기

- MCU는 CPU와 메모리와 주변장치를 한 칩에 통합한 제어용 반도체임
- MPU는 외부 메모리와 고성능 소프트웨어 스택을 전제로 하는 연산 중심 프로세서임
- RTOS는 짧은 응답시간과 결정성을 중시하는 실시간 운영체제임

## Ⅰ. 개요

- **정의/개념**: 마이크로컨트롤러는 제어 업무에 필요한 CPU와 메모리와 주변장치를 단일 칩에 통합한 구조이고, 마이크로프로세서는 고성능 CPU를 중심으로 외부 메모리와 I/O를 결합해 시스템을 구성하는 구조임
- **배경/필요성**: 센서 제어와 모터 구동 같은 저전력 실시간 업무와 UI와 네트워크와 고급 OS가 필요한 업무는 요구 조건이 다르므로, MCU와 MPU를 구분해 선택해야 비용과 품질과 개발 복잡도를 함께 맞출 수 있음

## Ⅱ. 특징

- MCU는 CPU·메모리·타이머·GPIO를 한 칩에 통합해 센서·모터 제어 주기를 실행함
- MPU는 외부 DRAM과 풍부한 소프트웨어 스택을 바탕으로 복합 응용을 처리함
- MCU는 bare-metal과 RTOS 중심이고 MPU는 Linux 같은 범용 OS 운용이 쉬움
- 실시간성 요구와 보드 복잡도와 전력 예산이 선택을 가르는 핵심 축임

## Ⅲ. 종류 및 비교

| 판단 기준 | 마이크로컨트롤러 | 마이크로프로세서 |
|:---|:---|:---|
| 칩 구조 | CPU와 Flash와 SRAM과 주변장치를 칩 안에 통합함 | CPU 중심이며 외부 DRAM과 저장장치와 PMIC를 함께 씀 |
| 전력·발열 | 온칩 메모리·주변장치와 저전력 모드를 사용함 | 외부 DRAM·PMIC와 고성능 코어의 전력·열을 관리함 |
| 소프트웨어 | bare-metal·RTOS에서 제한된 태스크를 실행함 | Linux·Android에서 프로세스와 서비스를 실행함 |
| 대표 업무 | 센서·모터·계측 주기 제어 | UI·네트워크·멀티미디어·복합 연산 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| CPU 코어 | MCU는 제어 응답성과 단순성을, MPU는 범용 처리 성능과 확장성을 중시함 |
| 메모리 구조 | MCU는 내장 메모리 중심이라 단순하고 저전력이지만 MPU는 외부 DRAM으로 확장성을 얻음 |
| 주변장치·I/O | MCU는 GPIO와 ADC와 timer를 바로 내장하고 MPU는 고속 인터페이스와 외부 칩 연동이 많음 |
| 소프트웨어 스택 | MCU는 작은 펌웨어와 RTOS로 예측 가능성을 높이고 MPU는 범용 OS와 풍부한 미들웨어를 활용함 |

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 요구 정의      | --> | 칩 계열 선정   | --> | 보드 구성      | --> | 실측 검증      |
+-------------+     +-------------+     +-------------+     +-------------+
```

## Ⅴ. 원리 및 절차 흐름도

1. **요구 정의**: 처리량과 응답시간과 전력과 BOM 비용과 OS 요구를 정리함
2. **칩 계열 선정**: 제어 중심이면 MCU를, 복합 응용 중심이면 MPU를 우선 검토함
3. **보드 구성**: 전원과 메모리와 인터페이스와 디버그 구조를 설계함
4. **실측 검증**: 실시간 지연과 발열과 소비전력과 bring-up 난도를 확인함

## Ⅵ. 실무 적용 및 유의점

1. 배터리 센서 노드나 모터 제어기는 MCU가 구조적으로 맞지만 복합 UI와 네트워크 기능을 억지로 얹으면 자원이 곧 부족해지므로 기능 예산을 먼저 고정하고 대기 전류와 최악 지연시간과 메모리 여유율로 확인함
2. MPU 기반 Linux 장치는 기능 확장이 쉽지만 강한 실시간 요구를 그대로 맡기면 지연 변동이 커질 수 있으므로 제어 경로를 MCU나 실시간 코어로 분리하고 데드라인 미스율과 초기 구동 결함률과 보드 전력 예산으로 확인함

## Ⅶ. 결론

MCU와 MPU의 선택은 최고 성능 경쟁이 아니라 실시간성, 전력, 소프트웨어 복잡도, 보드 비용을 어떤 구조로 감당할지에 대한 판단임.
