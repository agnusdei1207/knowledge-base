## 미리 알고가기

- Edge TPU는 엣지 환경의 저전력 INT8 추론에 특화된 ASIC임
- TensorFlow Lite 모델 중 Edge TPU 컴파일러가 지원하는 연산만 가속함
- 네트워크 왕복 없이 현장에서 INT8 모델을 실행하는 용도로 사용함

## 작성 근거(검토용)

- Edge TPU는 INT8 추론, TensorFlow Lite, 지원 연산자 제약, 호스트 CPU 폴백을 핵심 축으로 설명함
- 비교표는 배치 위치, 실행 정밀도, 모델 변환, 호스트 역할을 기준으로 정리함
- 실무 판단은 컴파일된 연산 비율, 추론 지연, 가속기 온도, 열 조절 횟수로 구체화함

## Ⅰ. 개요

- **정의/개념**: Edge TPU는 현장 장비에서 TensorFlow Lite INT8 모델의 지원 연산을 전용 회로로 실행하는 엣지용 AI 가속기임
- **배경/필요성**: 카메라와 센서 기반 시스템은 네트워크 왕복 지연과 개인정보 외부 전송을 줄여야 하므로, 단말에서 추론을 수행하는 저전력 가속기가 필요함

## Ⅱ. 특징

- 장치의 전력 모드와 열 설계 한도 안에서 INT8 추론을 반복 수행함
- INT8과 지원 연산자 범위가 모델 배포 가능 여부를 결정함
- 호스트 CPU의 전후처리·비지원 연산 시간이 전체 응답 시간을 좌우함
- 현장 배치형 장비에서 네트워크 단절에도 동작할 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | 클라우드 TPU | 온디바이스 NPU | Edge TPU |
|:---|:---|:---|:---|
| 배치 위치 | 데이터센터 | 모바일, PC, 엣지 | 카메라, 게이트웨이 |
| 실행 정밀도 | 학습·추론용 부동소수점·정수 | 벤더가 지원하는 부동소수점·정수 | INT8 중심 |
| 모델 변환 | XLA 컴파일 | 벤더 컴파일러·런타임 | TensorFlow Lite·Edge TPU 컴파일러 |
| 호스트 역할 | 학습·서비스 제어 | 전후처리·폴백 | 입력 전후처리·비지원 연산 |

> 요약: Edge TPU는 TensorFlow Lite INT8 모델에서 컴파일러가 지원하는 연산을 카메라·게이트웨이에서 실행함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 호스트 CPU | 입력 전처리·장치 제어·비지원 연산을 담당하며 전체 응답 시간을 결정함 |
| Edge TPU 코어 | 컴파일된 INT8 연산을 전용 데이터 경로에서 실행함 |
| TFLite·컴파일러 | 모델을 장치 제약에 맞게 변환하고 지원·비지원 연산 목록을 출력함 |
| 센서·런타임 계층 | 입력을 공급하고 추론 결과를 경보·제어 동작으로 연결함 |

```text
+-------------+     +------------------+     +------------------+     +-------------+
| 센서 입력   | --> | 호스트 CPU·TFLite | --> | Edge TPU 코어    | --> | 장치 제어   |
+-------------+     +------------------+     +------------------+     +-------------+
```

> 요약: 호스트 CPU가 전후처리·비지원 연산을 맡고 Edge TPU 코어가 컴파일된 INT8 연산을 실행함.

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 모델 변환      | --> | 장치 컴파일    | --> | 엣지 추론 실행  | --> | 현장 동작 반영  |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **모델 변환**: 학습 모델을 TFLite 형식과 저정밀 형태로 바꿈
2. **장치 컴파일**: 지원 연산 여부와 자원 적합성을 검사함
3. **엣지 추론 실행**: 호스트 CPU와 Edge TPU가 지원 범위에 따라 연산을 나눠 처리함
4. **현장 동작 반영**: 경보, 제어, 저장 같은 후속 동작을 수행함

> 요약: 모델은 TFLite·INT8 형태로 변환된 뒤 Edge TPU와 호스트 CPU가 지원 범위에 따라 나눠 처리함.

## Ⅵ. 실무 사례

1. 스마트 카메라는 모델을 TensorFlow Lite INT8로 변환하고 컴파일된 연산 비율·추론 지연을 확인함
2. 밀폐형 엣지 게이트웨이는 전력 모드를 열 설계 한도에 맞추고 가속기 온도·열 조절 횟수를 확인함

## Ⅶ. 결론

Edge TPU는 TensorFlow Lite INT8 변환과 지원 연산 비율을 확인한 뒤 전력·열 한도 안에서 적용해야 함.
