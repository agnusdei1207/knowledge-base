## 미리 알고가기

- USB는 범용 장치 연결과 전력 공급을 지원하는 직렬 인터페이스임
- Thunderbolt는 PCIe와 DisplayPort를 터널링해 고성능 확장을 지원하는 인터페이스임
- USB-C는 커넥터 모양이고, USB와 Thunderbolt는 그 포트 위에서 동작하는 프로토콜임

## Ⅰ. 개요

- **정의/개념**: 고속 직렬 인터페이스는 USB와 Thunderbolt처럼 차동 lane과 프로토콜 협상을 이용해 데이터와 전력과 영상 신호를 적은 수의 외부 선로로 전송하는 연결 기술임
- **배경/필요성**: 병렬 버스는 핀 수와 신호 왜곡 때문에 고속화 한계가 크고 사용자 기기는 얇은 폼팩터와 통합 포트를 요구하므로, 외부 확장성과 전송 효율을 높이는 고속 직렬 구조가 필요함

## Ⅱ. 특징

- 적은 수의 lane으로 높은 전송률과 포트 통합을 제공함
- 데이터 전송뿐 아니라 충전과 영상 출력과 확장 장치 연결을 함께 다룰 수 있음
- 케이블과 포트와 장치가 모두 같은 기능을 지원해야 실제 성능이 나옴
- Thunderbolt 계열은 PCIe 터널링 특성 때문에 DMA 보안 검토가 중요함

## Ⅲ. 종류 및 비교

| 판단 기준 | USB | Thunderbolt |
|:---|:---|:---|
| 핵심 목적 | 범용 장치 연결과 충전과 주변기기 호환성에 강함 | 고성능 확장과 영상 출력과 PCIe 터널링에 강함 |
| 호환성 | 폭넓고 대중적이지만 버전별 기능 차이가 큼 | 성능은 높지만 인증과 케이블 조건 영향이 큼 |
| 대표 기능 | 저장장치와 입력장치와 충전 연결에 널리 쓰임 | 도킹과 외장 GPU와 고속 스토리지 연결에 유리함 |
| 보안 유의점 | 장치 승인과 데이터 접근 통제가 중요함 | IOMMU 기반 DMA 보호와 포트 정책이 중요함 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 호스트 컨트롤러 | 장치 탐지와 프로토콜 협상과 트랜잭션 제어를 담당함 |
| PHY·lane | 링크 훈련과 신호 보정과 전기 전송 품질을 담당해 실제 협상 속도를 좌우함 |
| 프로토콜 계층 | 데이터와 영상과 터널링 패킷 규칙을 처리해 인터페이스별 기능 차이를 만듦 |
| 전력·케이블 계층 | PD 협상과 케이블 인증이 전력 공급과 속도와 안정성 한계를 결정함 |

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 연결 감지      | --> | 기능 협상      | --> | 데이터 전송    | --> | 오류·보안 처리 |
+-------------+     +-------------+     +-------------+     +-------------+
```

## Ⅴ. 원리 및 절차 흐름도

1. **연결 감지**: 포트가 장치와 케이블과 전력 역할을 인식함
2. **기능 협상**: 속도와 lane 수와 모드와 전력 수준을 결정함
3. **데이터 전송**: 데이터와 영상과 제어 메시지를 규칙에 따라 전송함
4. **오류·보안 처리**: CRC와 재전송과 장치 승인과 DMA 보호를 수행함

## Ⅵ. 실무 적용 및 유의점

1. 업무용 노트북 도킹 환경은 같은 USB-C 모양이라도 속도와 영상과 전력 지원이 달라 혼선이 크므로 포트별 기능 표준과 승인 케이블 목록을 함께 운영하고 호환성 매트릭스와 협상 속도 정상률과 헬프데스크 문의 건수로 확인함
2. Thunderbolt 확장 포트는 외장 고속 장치에 유리하지만 PCIe 터널링이 DMA 공격 경로가 될 수 있으므로 IOMMU와 장치 승인 정책을 함께 활성화하고 비인가 DMA 차단율과 포트 정책 준수율과 링크 오류율로 확인함

## Ⅶ. 결론

고속 직렬 인터페이스 평가는 최대 전송률 숫자보다 실제 협상 기능과 케이블 조건과 외부 DMA 통제를 함께 보는 것이 맞음.
