## 미리 알고가기

- USB는 범용 장치 연결과 전력 공급을 지원하는 직렬 인터페이스임
- Thunderbolt는 PCIe와 DisplayPort를 터널링해 고성능 확장을 지원하는 인터페이스임
- USB-C는 커넥터 모양이고, USB와 Thunderbolt는 그 포트 위에서 동작하는 프로토콜임
- 레인(lane)은 직렬 데이터를 송수신하는 차동 신호 경로임
- USB PD는 USB-C 연결에서 전압·전류와 전력 공급 역할을 협상하는 규격임
- CRC(순환중복검사)는 수신한 데이터의 전송 오류를 검출하는 검사값임

## 작성 근거(검토용)

- 고속 직렬 인터페이스는 링크 협상, 데이터·영상 터널링, 전력 역할, 케이블 등급, DMA 통제를 핵심 축으로 설명함
- 비교표는 USB와 Thunderbolt의 전송 기능·호환 조건, 대표 기능, 보안 경계를 대비함
- 실무 판단은 호환성·협상 속도와 비인가 DMA 차단률·포트 정책 준수율로 검증함

## Ⅰ. 개요

- **정의/개념**: 고속 직렬 인터페이스는 USB와 Thunderbolt처럼 차동 레인과 프로토콜 협상으로 데이터·전력·영상 신호를 외부 포트로 전송하는 연결 기술임
- **배경/필요성**: 핀 수와 병렬 신호 간 스큐를 줄이면서 한 포트로 데이터·전력·영상을 제공하기 위해 고속 직렬 구조가 필요함

## Ⅱ. 특징

- 차동 레인과 직렬화로 병렬 인터페이스보다 핀 수를 줄이고 링크 속도를 협상함
- 데이터 전송뿐 아니라 충전과 영상 출력과 확장 장치 연결을 함께 다룰 수 있음
- 케이블과 포트와 장치가 모두 같은 기능을 지원해야 실제 성능이 나옴
- Thunderbolt의 PCIe 터널링 경로에는 IOMMU와 장치 승인 정책을 적용함

## Ⅲ. 종류 및 비교

| 판단 기준 | USB | Thunderbolt |
|:---|:---|:---|
| 전송 기능·동작 조건 | USB 데이터·전력 공급·DisplayPort 대체 모드, 호스트·장치·케이블의 USB 세대 일치 필요 | PCIe·DisplayPort 터널링과 전력 공급, 호스트·장치·인증 케이블의 Thunderbolt 세대 일치 필요 |
| 대표 기능 | 저장장치·입력장치·충전 연결 | 도킹·외장 GPU·고속 스토리지 연결 |
| 보안 유의점 | 장치 승인과 데이터 접근 범위를 통제함 | IOMMU 기반 DMA 보호와 포트 정책을 적용함 |

> 요약: USB는 범용 데이터·전력·대체 모드, Thunderbolt는 PCIe·DisplayPort 터널링과 DMA 경로를 제공함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 호스트 컨트롤러 | 장치 탐지와 프로토콜 협상과 트랜잭션 제어를 담당함 |
| PHY·레인 | 링크 훈련·신호 보정·전기 전송을 담당해 협상 가능한 속도를 결정함 |
| 프로토콜 계층 | 데이터와 영상과 터널링 패킷 규칙을 처리해 인터페이스별 기능 차이를 만듦 |
| 전력·케이블 계층 | PD 협상과 케이블 인증이 전력 공급과 속도와 안정성 한계를 결정함 |

> 요약: 호스트 컨트롤러가 PHY·레인과 케이블 기능을 확인하고 프로토콜·전력 모드를 협상함.

## Ⅴ. 원리 및 절차 흐름도

1. **연결 감지**: 포트가 장치와 케이블과 전력 역할을 인식함
2. **기능 협상**: 속도와 레인 수와 모드와 전력 수준을 결정함
3. **데이터 전송**: 데이터와 영상과 제어 메시지를 규칙에 따라 전송함
4. **오류·보안 처리**: CRC 검사와 재전송, 장치 승인과 DMA 보호를 수행함

> 요약: 포트가 케이블·장치 기능과 전력 역할을 협상한 뒤 선택된 데이터·영상 모드로 전송함.

## Ⅵ. 실무 사례

1. 업무용 노트북 도킹은 포트 기능 표와 승인 케이블 목록을 운영하고 호환성 시험 통과율·목표 속도 협상 성공률을 확인함
2. Thunderbolt 확장 포트는 IOMMU와 장치 승인을 적용하고 비인가 DMA 차단률·포트 정책 준수율을 확인함

## Ⅶ. 결론

- 고속 직렬 인터페이스는 포트·장치·케이블의 세대와 모드를 일치시키고 Thunderbolt의 외부 DMA 경계를 검증해야 함
