## Ⅰ. 개요
- **정의**: 메인 메모리 블록을 캐시 라인에 대응시키는 주소 변환 규칙임
- **배경/필요성**: 캐시 용량은 메모리 대비 수백 분의 1이므로, 어떤 메모리 블록이 캐시의 어디에 위치할 수 있는지를 결정하는 규칙이 필요함
- **비유**: 도서관에서 책을 서가에 배치할 때 지정석·자유석·구역지정석 중 하나를 선택하는 것과 같음

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 3가지 매핑 방식의 구조·장단점 비교 | 주소 분할(태그/인덱스/오프셋) 차이 | 집합연관의 Way 수에 따른 충돌 미스 변화를 정량적으로 설명 필요 |

> 요약: 메모리 블록과 캐시 라인 간 대응 규칙을 정의하여 적중률과 하드웨어 비용의 균형을 결정하는 기법임

## Ⅱ. 구성요소
```text
  메모리 주소
  +------+--------+--------+
  | 태그 | 인덱스 | 오프셋 |
  +------+--------+--------+
      |       |         |
      |       +---> 캐시 셋 선택
      +----------> 태그 비교 (적중 판정)
                        |
                   오프셋 ---> 바이트 선택
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 직접 매핑(Direct) | 블록이 캐시의 고정 1곳에만 배치됨 (인덱스 = 블록번호 mod 라인수) | 지정석 — 충돌 시 교체 불가피 |
| 완전 연관(Fully Assoc.) | 블록이 캐시 어느 라인에든 배치 가능, 모든 태그 병렬 비교 | 자유석 — 빈자리 아무 데나 앉음 |
| 집합 연관(Set Assoc.) | 인덱스로 셋 선택 후 셋 내 N-Way 중 자유 배치 | 구역지정석 — 구역 안에서는 자유 |
| 태그(Tag) | 캐시 라인에 저장된 블록의 출처를 식별하는 상위 주소 비트 | 좌석 명찰 |

> 요약: 주소를 태그·인덱스·오프셋으로 분할하여 배치 위치와 비교 범위를 결정함

## Ⅲ. 절차
```text
  주소분할          셋/라인선택       태그비교          데이터반환
  (Split)          (Index)          (Compare)        (Return)
   |                 |                 |                 |
   +--인덱스추출--->+--셋내탐색------>+--적중/미스---->+
  태그/인덱스/오프셋  해당셋접근       N-Way병렬비교   오프셋으로바이트선택
```
- 1단계: CPU가 발행한 메모리 주소를 태그·인덱스·오프셋 필드로 분할함
- 2단계: 인덱스 비트로 캐시 셋(직접 매핑은 단일 라인)을 선택함
- 3단계: 선택된 셋 내 모든 Way의 태그를 병렬 비교하여 적중 여부를 판정함
- 4단계: 적중 시 오프셋으로 바이트를 선택하여 CPU에 반환하고, 미스 시 교체 정책(LRU 등)에 따라 블록을 적재함

> 요약: 주소 분할 → 셋 선택 → 태그 비교 → 데이터 반환/교체의 4단계로 동작함

## Ⅳ. 문제점
- 충돌 미스(Direct): 서로 다른 블록이 동일 라인에 매핑되어 빈번한 축출 발생 — 워킹셋이 분산되면 적중률 급락
- 하드웨어 비용(Fully Assoc.): 모든 라인의 태그를 병렬 비교해야 하므로 CAM 회로 면적·전력 증가 — 대용량 캐시 적용 곤란
- Way 수 결정 난이도(Set Assoc.): Way 수가 적으면 충돌 미스 잔존, 과다하면 비교기 증가로 접근 지연 상승 — 워크로드별 최적점 도출이 어려움

> 요약: 직접 매핑의 충돌, 완전 연관의 비용, 집합 연관의 Way 수 결정이 핵심 문제임

## Ⅴ. 개선방안
1. 단기: 2~4 Way 집합 연관 채택으로 직접 매핑 대비 충돌 미스를 대폭 감소시킴
2. 중기: 스큐드 연관(Skewed Associative) 캐시 도입으로 해시 함수 다변화하여 CAM 없이 충돌 분산
3. 장기: 워크로드 프로파일 기반 동적 Way 재구성(Adaptive Way Partitioning)으로 실행 중 최적 연관도 자동 조정

> 요약: 집합 연관 기본 채택, 해시 다변화, 동적 Way 재구성으로 단계적 개선함

## Ⅵ. 전망
- 발전 방향: AI 가속기의 대용량 스크래치패드와 캐시 매핑의 하이브리드 구조가 확산될 전망임
- 기술사적 판단: 워크로드 특성(스트리밍/랜덤)에 따라 매핑 방식을 선택·조합하는 설계 역량이 요구됨
- 기술사 제언: 캐시 시뮬레이터를 활용한 미스율 정량 분석을 시스템 설계 초기 단계에 포함할 것을 제언함
