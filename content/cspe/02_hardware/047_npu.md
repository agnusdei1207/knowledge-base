## Ⅰ. 개요
- 인간의 뇌 신경망 구조를 모사한 AI 특화 하드웨어 가속기
- 딥러닝의 핵심인 행렬 연산 및 비선형 함수 처리에 최적화

| 구분 | 내용 |
| --- | --- |
| 정의 | 인공지능 알고리즘 처리에 최적화된 커스텀 프로세서 |
| 필요성 | GPU 대비 저전력, 고효율 AI 추론/학습 성능 필요 |
| 출제의도 | NPU의 구조적 특징 및 On-Device AI 적용 가치 확인 |

## Ⅱ. 구성요소
```
+------------------------------------------+
|  [ NPU Architecture ]                    |
| +--------+  +--------+  +--------------+ |
| | MAC Arry| | Buffer |  | Control Unit | |
| | (Matrix) | | (SRAM) |  | (Scheduler)  | |
| +--------+  +--------+  +--------------+ |
| [ Interconnect / DMA / NoC ]             |
+------------------------------------------+
```
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| MAC Array | 곱셈-누산 연산을 동시 수행하는 하드웨어 유닛 | 연산 공장 |
| Local Buffer | 연산 중 가중치 및 활성화 함수값 임시 저장 | 작업대 |
| NoC | 칩 내부 유닛 간 데이터 교환을 위한 네트워크 | 사내 통로 |
> 요약: 행렬 연산기(MAC)와 데이터 버퍼 중심의 전용 구조임.

## Ⅲ. 절차
```
[모델 양자화] -> [가중치 로드] -> [행렬 연산] -> [활성화 함수]
```
1. 모델 양자화: FP32 모델을 INT8 등으로 변환하여 데이터 경량화함.
2. 가중치 로드: 학습된 가중치 파라미터를 NPU 내부 버퍼로 이동함.
3. 행렬 연산: MAC 어레이를 통해 대규모 행렬 곱셈을 병렬 수행함.
4. 활성화 처리: ReLU 등 비선형 함수를 적용하여 결과값 산출함.
> 요약: 경량화된 데이터를 전용 하드웨어에서 고속 연산함.

## Ⅳ. 문제점
- 범용성 부족: 특정 프레임워크나 연산 구조에 종속되어 유연성 낮음.
- 개발 생태계 미흡: GPU(CUDA) 대비 SDK 및 라이브러리 최적화 부족함.

## Ⅴ. 개선방안
- 컴파일러 고도화: TVM 등 오픈소스 컴파일러 통한 멀티 백엔드 지원함.
- 표준 API 수립: ONNX 등 표준 포맷 준수 및 공용 인터페이스 구축함.

## Ⅵ. 전망
- 온디바이스 AI(On-Device AI) 확산에 따른 모바일 SoC 내 필수 탑재 추세임.
- PIM(Processor In Memory) 기술과의 결합이 미래 NPU의 핵심 로드맵임.
