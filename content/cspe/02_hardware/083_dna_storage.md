## Ⅰ. 개요
- 정의: 디지털 데이터(0, 1)를 DNA 염기서열(A, T, C, G)로 변환하여 저장하는 차세대 매체
- 배경: 전 세계 데이터 폭증에 따른 저장 공간 부족 및 기존 매체의 짧은 수명 극복
- 출제 의도: 초고밀도, 초장기 보존성 등 DNA 저장 기술의 원리 및 프로세스 이해

## Ⅱ. 구성요소
- ASCII 구조도
  [ Digital ] -> [ Encoding ] -> [ Synthesis ] -> [ DNA Pool ]
  (01011)      (A-T-C-G)      (Chemical)       (Storage)

- 구성요소 표
| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| Synthesis | 설계된 염기서열에 맞춰 물리적 DNA 분자 생성 | 책 인쇄 |
| Sequencing | 저장된 DNA를 읽어 염기서열 정보 추출 | 책 읽기 |
| Error Correction | 합성/해독 과정의 오류를 잡는 알고리즘 | 오타 교정 |

- > 요약: 생명체의 정보 저장 방식인 DNA를 하드웨어 저장 매체로 전용

## Ⅲ. 절차
- ASCII 흐름도
  [Binary] -> [Base Mapping] -> [Synthesis] -> [Store] -> [Read] -> [Decoding]

1. 인코딩: 이진 데이터를 A, C, G, T 4진법 코드로 변환
2. 합성(Synthesis): 올리고뉴클레오타이드를 화학적으로 합성하여 실제 DNA 제조
3. 저장: 합성된 DNA를 캡슐화하여 서늘하고 건조한 곳에 보관 (수천 년 유지 가능)
4. 해독(Sequencing): NGS(차세대 염기서열 분석) 장비로 서열 정보 추출 및 복원

- > 요약: 물리적 합성과 생물학적 분석을 결합한 데이터 보관 프로세스

## Ⅳ. 문제점
- 느린 속도: 합성 및 해독 과정에 수 시간~수 일이 소요되어 실시간 접근 불가
- 높은 비용: 현시점에서는 테라바이트당 저장 비용이 천문학적으로 높음

## Ⅴ. 개선방안
- 병렬 합성: 수백만 개의 구멍이 있는 칩 위에서 동시에 DNA를 합성하여 속도 향상
- 나노포어 시퀀싱: 휴대용 장비로 빠르게 서열을 읽어내는 저비용 기술 고도화

## Ⅵ. 전망
- 로드맵: 콜드 데이터(아카이브용) 위주로 시장 진입 후 합성 비용 하락 시 대중화
- CSF: 데이터 인출 속도 혁신 및 반영구적 보존을 위한 안정적 캡슐화 기술 확보
