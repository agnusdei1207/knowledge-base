## Ⅰ. 개요
- **정의**: 텐서(행렬) 연산에 특화된 Google의 AI 전용 ASIC 가속기
- **배경/필요성**: 딥러닝 학습·추론에서 행렬 곱셈이 전체 연산의 대부분을 차지하므로, 범용 GPU보다 행렬 연산에 최적화된 전용 하드웨어가 필요함
- **비유**: GPU가 다목적 공구 세트라면, TPU는 나사만 전문으로 조이는 전동 드라이버임

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| AI 전용 ASIC 구조 이해 | Systolic Array 기반 MXU 구조 | GPU와 TPU의 아키텍처 차이를 정량적으로 구분할 것 |

> 요약: 행렬 연산 특화 ASIC으로 AI 워크로드의 처리 효율을 극대화한 가속기임

## Ⅱ. 구성요소
```text
TPU Chip
  |
  +-- MXU (Matrix Multiply Unit)
  |     |
  |     +-- Systolic Array (128x128 / 256x256)
  |
  +-- VPU (Vector Processing Unit)
  |
  +-- HBM (High Bandwidth Memory)
  |
  +-- ICI (Inter-Chip Interconnect)
  |
  +-- Host Interface (PCIe / gRPC)
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| MXU | Systolic Array로 행렬 곱셈을 수행하는 핵심 연산 유닛 | 컨베이어 벨트식 조립 라인 |
| Systolic Array | 데이터가 PE 간 순차 전달되며 곱-누적 연산을 수행하는 배열 구조 | 물결처럼 흐르는 계산 파이프라인 |
| VPU | 활성화 함수, 정규화 등 벡터 연산을 담당하는 보조 유닛 | 후처리 담당 작업자 |
| HBM | 높은 대역폭을 제공하는 적층 메모리 | 초고속 자재 창고 |
| ICI | TPU 칩 간 직접 연결하는 고속 메시 인터커넥트 | 공장 간 전용 고속도로 |

> 요약: MXU의 Systolic Array를 중심으로 HBM과 ICI가 데이터 공급·칩 간 통신을 담당함

## Ⅲ. 절차
```text
모델 정의 --> 텐서 분할 --> MXU 행렬 연산 --> VPU 후처리 --> 결과 집계
     |              |              |               |              |
     v              v              v               v              v
 TF/JAX 그래프   XLA 컴파일    Systolic 실행    활성화/정규화    HBM 저장
```
- 1단계: TensorFlow 또는 JAX로 모델 그래프를 정의하고 XLA 컴파일러가 TPU 명령어로 변환함
- 2단계: 입력 텐서를 MXU 크기에 맞게 타일 단위로 분할하고 HBM에 적재함
- 3단계: Systolic Array가 타일별 행렬 곱-누적 연산을 파이프라인 방식으로 수행함
- 4단계: VPU가 활성화 함수·정규화 등 후처리를 수행하고 결과를 HBM에 기록함

> 요약: XLA 컴파일 후 Systolic Array 파이프라인 연산과 VPU 후처리로 텐서 연산을 완료함

## Ⅳ. 문제점
- 프레임워크 종속: TensorFlow, JAX 외 프레임워크(PyTorch 등) 지원이 제한적이어서 모델 이식이 어려움
- 범용성 부족: 행렬 연산 외 비정형 연산(희소 연산, 동적 그래프)에서 활용도가 낮음
- 가용성 제약: Google Cloud에서만 접근 가능하여 온프레미스 도입이 불가함

> 요약: 프레임워크 종속, 비정형 연산 한계, 클라우드 전용 가용성이 주요 제약임

## Ⅴ. 개선방안
1. 단기: PyTorch/XLA 지원 강화로 프레임워크 호환성을 확대함
2. 중기: SparseCores 등 희소 연산 유닛을 추가하여 비정형 워크로드 대응력을 향상함
3. 장기: TPU 칩의 외부 판매·온프레미스 배포를 통해 가용성 제약을 해소함

> 요약: 프레임워크 확장, 희소 연산 지원, 가용성 확대로 단계적 개선이 필요함

## Ⅵ. 전망
- 발전 방향: TPU Pod 규모 확대와 ICI 대역폭 향상으로 초대규모 모델 학습 인프라가 강화됨
- 기술사적 판단: AI 전용 ASIC 수요가 지속 증가하며 GPU와 TPU의 워크로드별 분화가 진행될 전망임
- 기술사 제언: GPU(051 참조)와 TPU의 워크로드 특성별 비용 대비 성능을 비교 분석하여 인프라를 선정해야 함
