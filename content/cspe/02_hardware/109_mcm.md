## Ⅰ. 개요
- 여러 개의 반도체 다이(Die)를 하나의 기판 위에 배치하여 단일 패키지로 구성한 기술.
- 개별 칩들의 장점을 결합하고, 거대한 단일 칩(Monolithic) 제조 시의 낮은 수율 극복.
| 구분 | 내용 | 비고 |
|---|---|---|
| 정의 | 복수의 칩을 하나의 패키지 내에 통합하여 성능을 높인 모듈 | Chiplet 기반 |
| 의도 | 수율 개선 및 이종 집적(Heterogeneous Integration) 이해 측정 | 모듈형 반도체 |

## Ⅱ. 구성요소
+-----------------------------+
| [ CPU Die ] [ GPU Die ]     | <- Chips
| +-------------------------+ |
| | Substrate (Interconnect)| | <- Base
+-----------------------------+
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 다이 (Die) | 개별 기능을 수행하는 작은 반도체 조각 | 레고 블록 |
| 인터포저 | 칩 사이의 고속 통신을 돕는 중간 배선층 | 고속도로 교차로 |
| 기판 | 전체 모듈을 지지하고 외부 핀과 연결하는 판 | 바둑판 |
> 요약: 다이, 연결 기판, 봉합 패키지로 구성된 복합 칩 구조임.

## Ⅲ. 절차
(1) Chiplet Design -> (2) Die Sorting -> (3) Assembly -> (4) Interconnect Test
1. Chiplet Design: 기능을 쪼개어 각각 최적의 공정(예: 연산 5nm, I/O 12nm)으로 설계.
2. Die Sorting: 제조된 웨이퍼에서 양품 다이만 골라내어 준비함.
3. Assembly: 기판 위에 여러 다이를 정밀하게 배치하고 본딩함.
4. Interconnect Test: 칩 간 데이터 통신이 병목 없이 이루어지는지 검증.
> 요약: 기능 분할 설계, 양품 선별, 정밀 조립, 통신 검증 순임.

## Ⅳ. 문제점
- 통신 지연: 단일 칩 내부보다 칩과 칩 사이의 데이터 전송 거리로 인한 레이턴시 발생.
- 열 집중: 좁은 공간에 여러 칩이 밀집되어 발열 해소가 어렵고 열 간섭 발생 가능.

## Ⅴ. 개선방안
- 고속 인터페이스: UCIe(Universal Chiplet Interconnect Express) 표준 도입으로 지연 최소화.
- 열 관리 설계: 칩 사이 간격 최적화 및 고성능 방열 소재(TIM) 적용 강화.

## Ⅵ. 전망
- 이종 집적의 대중화: 서로 다른 제조사의 칩렛을 조립하는 '반도체 생태계' 활성화.
- AI 가속기 주류: 대용량 메모리(HBM)와 연산 칩을 MCM으로 묶는 구조가 시장 주도.
