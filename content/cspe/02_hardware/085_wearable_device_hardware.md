## Ⅰ. 개요
- 정의: 인체에 착용하여 상시 정보를 수집하거나 사용자에게 정보를 제공하는 전자기기
- 배경: 헬스케어 수요 증가 및 스마트폰을 넘어서는 직관적 인터페이스(HCI) 필요
- 출제 의도: 유연 소자, 고밀도 배터리, 생체 센서 등 웨어러블 특화 HW 기술 이해

## Ⅱ. 구성요소
- ASCII 구조도
  [ User Body ] <--- [ Bio-Sensor ]
                         |
  [ Flexible Battery ] --+-- [ Low Power MCU ]
                         |
  [ Haptic/Display ] <---+-- [ Wireless (BLE) ]

- 구성요소 표
| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| Flexible Board | 휘어지거나 늘어나는 성질을 가진 회로 기판 | 기능성 의류 |
| PPG Sensor | 빛을 이용해 혈류량을 측정, 심박수 등을 산출 | 손목 위 청진기 |
| SiP | 여러 칩을 하나로 묶어 공간 효율을 극대화한 패키지 | 압축 배낭 |

- > 요약: 착용감을 극대화하기 위한 소형화, 경량화, 유연화 기술의 집약체

## Ⅲ. 절차
- ASCII 흐름도
  [Data Capture] -> [Signal Filtering] -> [Local Analytics] -> [Feedback]

1. 신호 획득: 미세한 전기적/광학적 생체 신호를 센서로 포착
2. 잡음 제거: 움직임 등에 의한 아티팩트(Artifact)를 하드웨어 필터로 보정
3. 데이터 압축: 통신 전력을 줄이기 위해 온디바이스에서 주요 특징점만 추출
4. 사용자 알림: 햅틱 진동이나 초소형 디스플레이를 통해 정보 시각화

- > 요약: 인체와 밀착되어 끊임없이 상호작용하는 데이터 수집-피드백 루프

## Ⅳ. 문제점
- 발열 관리: 인체에 직접 닿으므로 낮은 온도로 유지해야 하는 하드웨어 제약
- 내구성 저하: 반복적인 굽힘, 땀, 수분 노출로 인한 소자 수명 단축

## Ⅴ. 개선방안
- 스트레처블 소자: 신축성이 뛰어난 신소재(엘라스토머 등) 기반 회로 적용
- 고효율 무선충전: 착용 중에도 충전 가능한 장거리/공진 방식 무선 충전 도입

## Ⅵ. 전망
- 로드맵: 액세서리 형태에서 신체 부착형(Patch), 삽입형(Implant)으로 고도화
- CSF: 의료기기 수준의 센서 정확도 확보 및 장기간 착용을 위한 전력 효율 극대화
