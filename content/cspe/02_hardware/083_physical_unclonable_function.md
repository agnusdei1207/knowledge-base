## 미리 알고가기

- PUF는 제조 공정 편차에서 나온 장치 고유 특성을 이용하는 보안 기술임
- 질의-응답 쌍(challenge-response pair)은 입력 자극과 그에 대한 장치 고유 응답의 짝임
- 퍼지 추출기(fuzzy extractor)는 흔들리는 응답에서 안정된 키를 복원하는 보정 구조임
- 모델링 공격(modeling attack)은 다수의 질의-응답 쌍을 학습해 PUF 동작을 예측하는 공격임

## 작성 근거(검토용)

- PUF는 공정 편차, 질의-응답 쌍, 퍼지 추출기, 모델링 공격을 핵심 축으로 설명함
- 비교표는 저장형 키와 PUF 키의 비밀 유지·재현 방식, 복제 조건, 운영 항목을 대비함
- 실무 판단은 응답 비트 오류율·키 복원 성공률과 모델링 공격 성공률·인증 성공률로 검증함

## Ⅰ. 개요

- **정의/개념**: PUF는 칩 제조 과정의 미세한 물리 편차로 장치마다 다른 응답이나 키를 만들어 장치 인증과 비밀 보호에 쓰는 하드웨어 보안 기술임
- **배경/필요성**: 고정 키의 복사·추출 위험을 줄이기 위해 장치 고유 특성에서 키를 재구성하는 방식이 필요함

### 쉽게 이해하기 (학습용)
- 같은 공장에서 찍어낸 도장이라도 나무결이 조금씩 달라 찍히는 무늬가 저마다 다른 것과 같음
- 그 무늬는 어딘가에 저장해두지 않고 필요할 때마다 다시 찍어서 확인함

## Ⅱ. 특징

- 같은 설계의 칩도 공정 편차에 따라 서로 다른 응답을 생성함
- 키를 메모리에 오래 저장하지 않아 비밀 추출 공격면을 줄일 수 있음
- 온도·전압·노화에 따라 응답이 달라질 수 있어 오류를 보정해야 함
- 질의를 많이 노출하면 모델링 공격에 취약해질 수 있음

### 쉽게 이해하기 (학습용)
- 같은 도장이라도 나무결 차이로 자물쇠마다 반응이 다르고, 열쇠를 금고에 넣어두지 않으니 훔쳐갈 열쇠 자체가 없음
- 날씨가 더우면 자물쇠가 뻑뻑해지듯 응답이 흔들려 보정이 필요하고, 도장을 너무 자주 찍어 보이면 무늬를 외워 흉내 낼 위험도 생김

## Ⅲ. 종류 및 비교

| 판단 기준 | 저장형 키 | PUF 기반 키 |
|:---|:---|:---|
| 비밀 유지·재현 방식 | 메모리나 보안 저장소에 키를 보관하고 그대로 읽음 | 물리 특성에서 키를 복원하며 온도·전압·노화 오류를 보정함 |
| 복제 조건 | 저장 매체의 키 값이 추출되면 복사할 수 있음 | 동일한 공정 편차와 질의-응답 특성을 재현해야 복제할 수 있음 |
| 운영 항목 | 키 주입과 저장소 보호를 관리함 | 등록·오류 보정·질의 노출을 관리함 |

> 요약: PUF는 공정 편차에서 응답을 생성하며, 환경 변화에 따른 응답 오류를 등록 정보와 오류 보정으로 복원함.

### 쉽게 이해하기 (학습용)
- 저장형 키는 금고 속 열쇠를 그대로 꺼내 쓰는 방식이라 금고가 열리면 복사됨
- PUF 키는 나무결 무늬를 다시 떠서 확인하는 방식이라 같은 나무를 다시 구해야 흉내 낼 수 있음

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 물리 엔트로피 원천 | SRAM 초기값이나 지연 차이 같은 공정 편차가 고유성의 실제 근거가 됨 |
| 질의·응답 로직 | 입력 자극에 따라 장치 고유 응답을 생성해 인증 재료를 제공함 |
| 퍼지 추출기 | 흔들리는 응답에서 안정된 키를 복원함 |
| 보조 데이터·등록 정보 | 복원 보조 정보와 기준 응답을 저장해 인증과 키 재구성을 지원함 |

> 요약: 물리 엔트로피가 만든 응답을 퍼지 추출기와 등록 정보로 보정해 인증·키 재구성에 사용함.

### 쉽게 이해하기 (학습용)
- 나무결 무늬(물리 엔트로피 원천)에 질문을 던져 반응(질의·응답 로직)을 얻고, 흔들린 반응을 보정판(퍼지 추출기)으로 다듬음
- 다듬은 무늬를 미리 등록해둔 기준 무늬(보조 데이터)와 맞춰봄

## Ⅴ. 원리 및 절차 흐름도

1. **등록 단계 측정**: 장치 고유 응답과 보조 데이터로 기준값을 마련함
2. **질의 입력**: 인증이나 키 생성 시 입력 자극을 제공함
3. **응답 복원·보정**: 퍼지 추출기로 흔들리는 응답을 안정된 값으로 정리함
4. **인증·키 사용**: 장치 신원 확인이나 세션 키 생성에 활용함

> 요약: PUF 절차는 등록한 고유 응답을 다시 복원해 인증이나 키 생성에 쓰는 흐름임.

### 쉽게 이해하기 (학습용)
- 처음에 도장을 찍어 기준 무늬를 남겨두고(등록), 나중에 같은 도장을 다시 눌러 질문을 던짐(질의)
- 흔들린 자국을 보정판으로 다듬은 뒤(복원) 기준과 맞으면 진짜로 인정함(인증)

## Ⅵ. 실무 사례

1. 보안 MCU는 환경 보정과 오류 정정을 적용하고 응답 비트 오류율·키 복원 성공률을 확인함
2. 장치 인증 인터페이스는 질의-응답 쌍 노출을 제한하고 모델링 공격 성공률·인증 성공률을 확인함

### 쉽게 이해하기 (학습용)
- 보안 MCU는 도장 자국이 얼마나 잘 복원되는지 꾸준히 점검함
- 인증 장치는 도장을 남에게 너무 여러 번 보여주지 않도록 노출 횟수를 제한함

## Ⅶ. 결론

- PUF는 칩 제조 공정의 미세한 편차를 이용해 키를 저장하지 않고도 서로 다른 장치는 다르게, 같은 장치는 항상 같게 응답을 재현하는 하드웨어 보안 기술임
- 저장형 키 대신 PUF를 쓰면 키 추출 공격면은 줄지만, 온도·전압·노화에 따른 응답 오류를 퍼지 추출기로 보정하고 질의-응답 노출을 제한해 모델링 공격을 막아야 함

### 쉽게 이해하기 (학습용)
- 서로 다른 도장은 다르게, 같은 도장은 항상 똑같이 찍히는지 함께 확인해야 함
- 도장을 남에게 보여주는 횟수와 기준 무늬가 바뀌지 않았는지도 관리해야 함
