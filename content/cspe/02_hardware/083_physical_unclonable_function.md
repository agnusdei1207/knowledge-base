## 미리 알고가기

- PUF는 제조 공정 편차에서 나온 장치 고유 특성을 이용하는 보안 기술임
- challenge-response pair는 입력 자극과 그에 대한 장치 고유 응답의 짝임
- fuzzy extractor는 흔들리는 응답에서 안정된 키를 복원하는 보정 구조임

## Ⅰ. 개요

- **정의/개념**: PUF는 칩 제조 과정의 미세한 물리 편차로 장치마다 다른 응답이나 키를 만들어 장치 인증과 비밀 보호에 쓰는 하드웨어 보안 기술임
- **배경/필요성**: 장치 안에 고정 키를 저장하면 복사와 추출 위험이 남으므로, 비밀을 저장하기보다 장치 고유 특성에서 필요할 때 다시 만들어 쓰는 방식이 필요함

## Ⅱ. 특징

- 같은 설계로 만든 칩도 장치마다 다른 응답을 낼 수 있음
- 키를 메모리에 오래 저장하지 않아 비밀 추출 공격면을 줄일 수 있음
- 온도와 전압과 노화에 따라 응답이 흔들릴 수 있어 보정이 필수임
- challenge를 많이 노출하면 모델링 공격에 취약해질 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | 저장형 키 | PUF 기반 키 |
|:---|:---|:---|
| 비밀 유지 방식 | 메모리나 보안 저장소에 키를 보관함 | 장치 물리 특성에서 키를 다시 복원함 |
| 복제 저항성 | 메모리 추출이나 복사 공격을 계속 방어해야 함 | 공정 편차 자체를 복제하기 어려워 위조 저항성이 높음 |
| 안정성 | 비교적 일정한 값을 유지하기 쉬움 | 환경 변화에 따른 응답 흔들림을 보정해야 함 |
| 운영 초점 | 키 주입과 저장소 보호가 중요함 | 등록과 오류 보정과 challenge 관리가 중요함 |

> 요약: PUF는 저장형 키보다 복제 저항성이 높지만 등록, 오류 보정, challenge 관리가 필요함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 물리 엔트로피 원천 | SRAM 초기값이나 지연 차이 같은 공정 편차가 고유성의 실제 근거가 됨 |
| challenge·response 로직 | 입력 자극에 따라 장치 고유 응답을 생성해 인증 재료를 제공함 |
| fuzzy extractor | 흔들리는 응답에서 안정된 키를 복원해 실사용 가능성을 높임 |
| helper data·등록 정보 | 복원 보조 정보와 기준 응답을 저장해 인증과 키 재구성을 지원함 |

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 등록 단계 측정   | --> | challenge 입력 | --> | 응답 복원·보정  | --> | 인증·키 사용   |
+-------------+     +-------------+     +-------------+     +-------------+
```

> 요약: PUF는 물리 엔트로피, 질의-응답 로직, 보정 구조, 등록 정보가 함께 동작해야 안정적으로 쓰임.

## Ⅴ. 원리 및 절차 흐름도

1. **등록 단계 측정**: 장치 고유 응답과 helper data로 기준값을 마련함
2. **challenge 입력**: 인증이나 키 생성 시 입력 자극을 제공함
3. **응답 복원·보정**: fuzzy extractor로 흔들리는 응답을 안정된 값으로 정리함
4. **인증·키 사용**: 장치 신원 확인이나 세션 키 생성에 활용함

> 요약: PUF 절차는 등록한 고유 응답을 다시 복원해 인증이나 키 생성에 쓰는 흐름임.

## Ⅵ. 실무 적용 및 유의점

1. IoT 기기나 보안 MCU는 저장형 키를 줄일 때 PUF가 유리하지만 온도와 노화로 응답이 흔들리면 복원 실패가 나므로 환경 보정과 오류 정정을 두고 비트 오류율, 키 복원 성공률, 등록 일관성으로 확인함
2. 대량 질의를 외부에 노출하는 인증 구조는 모델링 공격 위험이 커지므로 통제형 PUF 프로토콜과 질의-응답 쌍 노출 제한을 적용하고 모델 공격 성공률, 인증 성공률, 엔트로피 수준으로 확인함

## Ⅶ. 결론

PUF의 본질은 비밀을 저장하는 대신 장치에서 다시 만들어 쓰는 데 있으므로, 고유성만큼 재현성과 모델링 공격 저항성을 함께 관리해야 함.

## 작성 근거(검토용)

- PUF는 공정 편차, challenge-response pair, fuzzy extractor, 모델링 공격을 핵심 키워드로 선정함

- 실무 판단은 비트 오류율, 키 복원 성공률, 등록 일관성, 모델 공격 성공률로 검증 가능하게 작성함
