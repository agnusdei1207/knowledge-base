## Ⅰ. 개요
- **정의**: 다수의 DRAM 다이를 수직 적층하고 TSV(Through-Silicon Via)로 연결한 광대역·저전력 메모리임
- **배경/필요성**: GPU·AI 가속기가 요구하는 대역폭이 DDR의 채널당 한계를 초과하므로, 3D 적층과 넓은 내부 버스(1024-bit)로 대역폭을 수배 확장할 필요
- **비유**: 얇은 팬케이크(DRAM 다이)를 여러 장 쌓고 세로 빨대(TSV)로 한 번에 관통 연결하여 데이터를 병렬 전달하는 구조와 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| HBM 구조와 DDR 대비 장점 | TSV·인터포저·1024-bit 버스 | HBM 세대별 스택 수·대역폭 수치 혼동 주의 |

> 요약: TSV 3D 적층과 1024-bit 버스로 DDR 대비 수배의 대역폭을 저전력으로 제공하는 메모리임

## Ⅱ. 구성요소
```text
+--------------------------+
|     GPU / AI SoC         |
+------------+-------------+
             |
    +--------+--------+
    |   Interposer     |
    | (Silicon/Organic) |
    +--+----+----+--+--+
       |    |    |  |
    +--+--+ | +--+--+
    |DRAM | | |DRAM |
    |Die 4| | |Die 4|    <-- 4~12층 적층
    |Die 3| | |Die 3|
    |Die 2| | |Die 2|
    |Die 1| | |Die 1|
    |Base | | |Base |
    +--+--+ | +--+--+
       |    |    |
      TSV  TSV  TSV  (수천 개 관통 비아)
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| DRAM 다이 스택 | 4~12장의 DRAM 다이를 수직 적층하여 용량 확보 | 팬케이크 탑 |
| TSV | 다이를 관통하는 수천 개 미세 비아로 층간 데이터 병렬 전달 | 세로 빨대 |
| 베이스 다이 | 스택 최하단에 위치하여 로직·PHY·ECC 회로 탑재 | 건물 1층 로비 |
| 인터포저 | HBM 스택과 SoC를 수평 연결하는 실리콘/유기 기판 | 옆 건물 연결 통로 |
| 마이크로 범프 | 다이 간 또는 다이-인터포저 간 물리 접합점 | 핀 커넥터 |

> 요약: DRAM 적층 + TSV 관통 + 인터포저 수평 연결이 HBM의 3대 핵심 구성임

## Ⅲ. 절차
```text
SoC 메모리 요청 --> 인터포저 경유 --> 베이스 다이 PHY 수신
   --> TSV 통해 대상 다이/뱅크 접근
   --> 1024-bit 폭 데이터 병렬 전송
   --> 베이스 다이 ECC 검증 --> SoC 반환
```
- 1단계: GPU/AI SoC가 인터포저를 통해 HBM 베이스 다이의 PHY 인터페이스로 요청 전달
- 2단계: 베이스 다이가 채널(8~16개 독립 채널)과 뱅크를 디코딩하여 대상 DRAM 다이 선택
- 3단계: TSV를 통해 해당 다이의 행/열에 접근하고 1024-bit 폭으로 데이터를 병렬 전송
- 4단계: 베이스 다이에서 온다이 ECC 검증 후 인터포저 경유로 SoC에 데이터 반환

> 요약: 인터포저→베이스 다이→TSV→대상 다이 접근→ECC 검증→반환 순으로 동작함

## Ⅳ. 문제점
- 발열 집중: 다이 적층이 높아질수록 열이 내부에 갇혀 상단 다이의 리프레시 주기 단축 필요
- 제조 수율: TSV 관통·다이 본딩·마이크로 범프 공정의 결함률이 누적되어 양품률 저하
- 용량 한계: 스택당 최대 다이 수(현재 12층)와 다이당 밀도에 의해 총 용량이 DDR DIMM 대비 제한적

> 요약: 적층 발열, TSV 수율, 스택 용량 한계가 HBM 확산의 3대 제약임

## Ⅴ. 개선방안
1. 단기: 베이스 다이에 열 분산 구조(TSV 방열 비아, 마이크로 채널 쿨링) 적용으로 발열 완화
2. 중기: 하이브리드 본딩(Hybrid Bonding) 도입으로 마이크로 범프 피치를 축소하여 수율·밀도 개선
3. 장기: HBM4(032 참조) 이후 16층 이상 적층과 다이당 밀도 증가로 스택당 용량을 수십 GB 확장

> 요약: 방열 설계 → 하이브리드 본딩 → 초고층 적층 순으로 HBM의 물리적 한계를 확장함

## Ⅵ. 전망
- 발전 방향: HBM3E(031 참조) → HBM4(032 참조) 순으로 대역폭·용량이 세대별 약 1.5배 증가 추세
- 기술사적 판단: LLM·대규모 AI 학습의 메모리 대역폭 병목으로 HBM 수요가 가속화되어 공급 부족 지속
- 기술사 제언: HBM 세대별 대역폭·전력·용량 사양을 DDR·CXL(035 참조)과 정량 비교하여 아키텍처 선정 필요
