## 미리 알고가기

- 랙 서버는 독립 섀시 기반의 일반적인 데이터센터 서버 형식임
- 블레이드 서버는 공통 섀시에 여러 모듈형 서버를 수용하는 집적형 구조임
- 비교 기준은 집적도, 전력 공유, 확장성, 장애 도메인, 운영 유연성임

## Ⅰ. 개요

- **정의/개념**: 블레이드 서버와 랙 서버는 데이터센터 서버를 물리적으로 배치하고 전원과 냉각과 네트워크를 구성하는 방식의 차이를 보여주는 서버 폼팩터 아키텍처임
- **배경/필요성**: 서버 수가 많아질수록 공간과 전력과 배선과 관리 효율이 중요해지므로, 워크로드와 운영 방식에 맞는 서버 폼팩터 선택이 필요함

## Ⅱ. 특징

- 랙 서버는 독립성이 높아 부품 선택과 교체와 혼합 배치가 유연함
- 블레이드 서버는 전원과 네트워크를 공통화해 집적도와 관리 효율이 높음
- 블레이드는 섀시 장애 시 영향 범위가 커질 수 있음
- 랙 서버는 표준 생태계가 넓지만 집적도와 배선 효율은 상대적으로 낮을 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | 랙 서버 | 블레이드 서버 |
|:---|:---|:---|
| 독립성 | 높음 | 낮음 |
| 집적도 | 중간 | 높음 |
| 초기 비용 | 중간 | 높음 |
| 운영 유연성 | 높음 | 중간 |
| 장애 영향 범위 | 서버 단위 | 섀시 단위 확대 가능 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Rack Chassis | 각 서버가 독립 전원과 NIC와 팬을 가지며 범용 확장성이 높음 |
| Blade Chassis | 전원과 냉각과 네트워크 백플레인을 공통 제공해 집적도를 높임 |
| Shared Fabric Module | 블레이드 환경의 스위치와 관리 모듈이 배선 수와 관리 복잡도를 줄임 |
| Management Plane | 서버 또는 섀시 단위 관리 범위가 달라 장애 대응과 운영 모델에 영향을 줌 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 운영 요구 분석   | --> | 폼팩터 선택    | --> | 전원/네트워크 설계 | --> | 배치/운영 관리  |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **운영 요구 분석**: 집적도와 유연성과 표준화 요구를 정리함
2. **폼팩터 선택**: 랙 또는 블레이드 구조를 결정함
3. **전원 및 네트워크 설계**: 섀시 공유 구조와 독립 구조를 반영함
4. **배치 및 운영 관리**: 장애 도메인과 유지보수 절차를 운영함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 블레이드 섀시에 전원이나 네트워크 장애가 나면 여러 서버가 동시에 영향을 받아 장애 도메인이 커질 수 있음
   - 해결방안: 섀시 이중화와 패브릭 분리를 적용하고 chassis-level failure impact와 failover success rate로 검증함
2. 문제: 랙 서버는 독립 장비 수가 늘수록 케이블과 전력과 관리 포인트가 급증해 운영 복잡도가 커질 수 있음
   - 해결방안: 표준 템플릿과 자동화 관리를 적용하고 cabling complexity와 provisioning time으로 검증함
3. 문제: 블레이드 환경은 벤더 종속성이 커 장기적인 확장 비용이 예상보다 높아질 수 있음
   - 해결방안: lifecycle cost와 migration path를 비교하고 TCO와 vendor lock-in risk로 전략을 검증함

## Ⅶ. 적용 사례

- 대규모 가상화 팜에서는 블레이드 서버로 집적도를 높이고 확인 지표는 VM density와 power per rack임
- 혼합 워크로드 데이터센터에서는 랙 서버를 사용해 유연성을 확보하고 확인 지표는 provisioning time과 hardware reuse rate임
- 금융 전산실에서는 이중화된 섀시 또는 독립 랙 구조를 조합하고 확인 지표는 failure domain size와 MTTR임

## Ⅷ. 결론

블레이드와 랙 서버의 차이는 성능보다 운영 구조의 차이이므로, 집적도 이점과 장애 도메인과 벤더 종속성을 함께 비교해 선택해야 함.
