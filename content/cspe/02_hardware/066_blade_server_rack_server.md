## 미리 알고가기

- 랙 서버는 서버마다 전원과 팬을 갖는 독립형 구조임
- 블레이드 서버는 공통 섀시에 서버 모듈을 꽂아 집적도를 늘리는 구조임
- 백플레인(Backplane): 블레이드 섀시 내부에서 전원·데이터 신호를 연결하는 공통 회로 기판임
- 장애 범위, 확장 단위, 장비 구성 자유도가 폼팩터 선택 기준임

## 작성 근거(검토용)

- 블레이드 서버와 랙 서버는 공유 자원·장애 범위, 확장 단위, 장비 구성을 기준으로 비교함
- 구성요소는 랙 섀시, 블레이드 섀시, 패브릭 모듈, 관리 계층으로 정리함
- 실무 판단은 장애 전환 시간, 노드 증설 시간, 배선 장애 건수, 랙 전력 편차로 구체화함

## Ⅰ. 개요

- **정의/개념**: 블레이드 서버와 랙 서버는 서버의 섀시, 전원, 네트워크, 냉각 자원을 독립 또는 공유 구조로 배치하는 데이터센터 폼팩터임
- **배경/필요성**: 서버 증설 시 공유 자원의 장애 범위와 배선·전력 관리 단위가 달라지므로 운영 방식에 맞는 폼팩터가 필요함

### 쉽게 이해하기 (학습용)
- 랙 서버는 집집마다 전기·수도 계량기를 따로 둔 단독주택 단지와 같고, 블레이드 서버는 한 건물의 전기·수도를 공동 배관으로 나눠 쓰는 아파트와 같음

## Ⅱ. 특징

- 랙 서버는 서버마다 전원·팬·확장 슬롯을 갖춰 장비 단위로 교체할 수 있음
- 블레이드 서버는 섀시 전원·패브릭을 공유해 노드별 전원·네트워크 배선을 줄임
- 블레이드 서버는 같은 섀시 규격의 노드를 슬롯 단위로 추가함
- 섀시 공유 구조는 장애 범위를 넓히고 벤더 종속성을 만들 수 있음

### 쉽게 이해하기 (학습용)
- 단독주택은 집마다 계량기·배관을 따로 둬 한 집만 손봐도 다른 집은 멀쩡함
- 아파트는 공동 배관을 나눠 써 배선을 줄이지만 건물 설비가 고장 나면 여러 세대가 함께 영향받고 그 건설사 규격에 묶임

## Ⅲ. 종류 및 비교

| 판단 기준 | 랙 서버 | 블레이드 서버 |
|:---|:---|:---|
| 공유 자원·장애 범위 | 서버별 섀시·전원·팬·네트워크 포트를 독립 구성해 장애가 해당 장비에 한정됨 | 섀시 전원·팬·백플레인·패브릭을 공유해 섀시 장애가 여러 블레이드에 영향을 미침 |
| 확장 단위 | 1U·2U 서버 단위 | 섀시 슬롯 단위, 슬롯 소진 시 섀시 추가 |
| 장비 구성 | 랙 규격 안에서 서버 벤더·사양 혼용 | 섀시가 지원하는 블레이드 규격 사용 |

> 요약: 랙 서버는 장비별 전원·냉각을 독립 구성하고, 블레이드 서버는 공통 섀시의 전원·네트워크를 여러 노드가 공유함.

### 쉽게 이해하기 (학습용)
- 단독주택은 세대별 설비 고장이 그 집에만 그치고 1채씩 늘리며 시공사를 자유롭게 고르지만, 아파트는 공동 설비 고장이 여러 세대에 미치고 동 단위로 늘리며 그 아파트 규격 자재만 씀

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 랙 서버 섀시 | 서버마다 전원·팬·확장 슬롯을 두어 장비 단위 장애 격리와 교체를 지원함 |
| 블레이드 섀시 | 전원과 냉각과 백플레인을 공통으로 제공해 공간과 배선 효율을 높임 |
| 패브릭 모듈 | 네트워크와 스토리지 연결을 모아 관리해 블레이드 환경의 배선 복잡도를 줄임 |
| 관리 계층 | 서버 단위 또는 섀시 단위 원격 관리가 장애 대응 속도와 운영 모델을 좌우함 |

> 요약: 섀시의 전원·패브릭 공유 범위가 노드 증설 단위와 장애 영향 범위를 결정함.

### 쉽게 이해하기 (학습용)
- 단독주택 부지(랙 섀시), 아파트 골조(블레이드 섀시), 공동 배관·전기실(패브릭 모듈), 관리사무소(관리 계층)가 설비를 나누거나 공유하는 방식을 정함

## Ⅵ. 실무 사례

1. VDI 팜은 블레이드 섀시의 전원·패브릭을 이중화하고 장애 전환 시간·노드 증설 시간을 확인함
2. 혼합 워크로드 랙은 배선·전력 배치를 표준화하고 배선 장애 건수·랙 전력 편차를 확인함

### 쉽게 이해하기 (학습용)
- 여러 세대가 함께 쓰는 아파트 단지는 전기·배관 이중화 후 정전 복구 시간과 입주 시간을 확인하고, 혼합형 단독주택 단지는 배선·전력 배치를 표준화해 배선 사고와 세대별 전력 편차를 확인함

## Ⅶ. 결론

- 랙 서버는 서버마다 전원·팬을 독립 구성해 장애를 해당 장비로 국한하고, 블레이드 서버는 섀시 전원·패브릭을 공유해 배선과 공간 효율을 높이는 대신 장애 범위를 넓힘
- 노드 증설 속도와 배선 효율이 중요하면 블레이드 서버를, 장애 격리와 벤더 혼용 자유도가 중요하면 랙 서버를 선택해야 함

### 쉽게 이해하기 (학습용)
- 아파트냐 단독주택이냐는 공동 설비 고장이 몇 세대까지 번지는지, 얼마나 빨리 세대를 늘릴 수 있는지, 어떤 자재를 쓸 수 있는지로 골라야 함
