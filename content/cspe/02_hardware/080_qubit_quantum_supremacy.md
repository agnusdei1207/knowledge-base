## Ⅰ. 개요
- 정의: 0과 1의 상태를 동시에 가질 수 있는 양자 정보의 최소 단위(Qubit) 및 그 성능 증명
- 배경: 지수적 연산 가속을 통한 특정 문제 해결(Quantum Supremacy) 가능성 확인
- 출제 의도: 큐비트의 수학적 원리(Bloch Sphere)와 양자 우월성 도달의 의미 이해

## Ⅱ. 구성요소
- ASCII 구조도
  [ Classical Bit ]         [ Quantum Qubit ]
      0 or 1             |0> and |1> (Overlap)
       (Line)                (Sphere/3D)
  2 nodes: 0, 1         N qubits: 2^N states

- 구성요소 표
| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| 중첩 (Superposition) | 0과 1의 상태를 확률적으로 동시에 보유 | 회전하는 동전 |
| 얽힘 (Entanglement) | 한 큐비트의 상태가 다른 큐비트와 연동됨 | 마법의 쌍둥이 |
| 양자 우월성 | 기존 슈퍼컴퓨터가 불가능한 계산을 양자로 해결 | 자전거 vs 제트기 |

- > 요약: 비트는 직렬적 선택, 큐비트는 병렬적 동시 존재를 의미함

## Ⅲ. 절차
- ASCII 흐름도
  [Problem Select] -> [Algorithm Design] -> [Execution] -> [Validation]

1. 대상 문제 선정: 무작위 회로 샘플링 등 클래식 컴퓨터가 취약한 문제 정의
2. 큐비트 맵핑: 문제를 양자 게이트 연산 시퀀스로 변환
3. 초고속 연산: 수십~수백 개의 큐비트를 얽어 병렬로 계산 수행
4. 우월성 검증: 동일 문제를 최강 슈퍼컴퓨터가 푸는 시간과 비교하여 성능 압도 증명

- > 요약: 양자 알고리즘을 통해 실질적인 성능 역전 현상을 하드웨어로 입증

## Ⅳ. 문제점
- 유용성 논란: 양자 우월성을 보인 문제들이 실제 산업적 가치가 적은 특정 영역에 국한
- 알고리즘 성능 향상: 기존 컴퓨터 알고리즘 개선으로 인해 우월성 지위가 위협받음

## Ⅴ. 개선방안
- PQC(Post-Quantum): 실제 가치를 지닌 최적화, 화학 시뮬레이션 문제로 영역 확장
- Quantum Volume: 큐비트 수뿐만 아니라 회로 깊이, 오류율을 포함한 종합 지표 관리

## Ⅵ. 전망

- CSF: 양자 컴퓨터 하드웨어와 클래식 컴퓨터를 결합한 가속기 형태의 하이브리드 운영
