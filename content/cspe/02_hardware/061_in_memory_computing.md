## 미리 알고가기

- 인메모리 컴퓨팅은 메모리 가까이 또는 메모리 내부에서 연산을 수행하는 구조임
- 핵심 목적은 memory wall 완화와 데이터 이동 에너지 절감임
- 아날로그형과 디지털형 구현 방식에 따라 정확도와 적용 범위가 달라짐

## Ⅰ. 개요

- **정의/개념**: 인메모리 컴퓨팅은 데이터가 저장된 메모리 배열 내부나 주변 회로에서 논리 연산과 검색과 행렬 연산을 수행해 프로세서와 메모리 사이의 이동량을 줄이는 컴퓨팅 구조임
- **배경/필요성**: AI와 데이터 분석은 계산 자체보다 메모리 접근이 더 큰 시간과 전력을 소비하는 경우가 많으므로, 계산 위치를 데이터 쪽으로 이동시키는 아키텍처가 필요함

## Ⅱ. 특징

- 데이터 이동을 줄여 에너지 효율과 대역폭 활용을 개선할 수 있음
- MAC와 검색과 bitwise 연산처럼 데이터 병렬성이 큰 작업에 유리함
- 아날로그형은 전력 이점이 크지만 정밀도와 보정 문제가 큼
- 범용 명령 실행보다 특정 연산 가속에 적합함

## Ⅲ. 종류 및 비교

| 판단 기준 | 프로세서 중심 구조 | Near-memory, In-memory 구조 |
|:---|:---|:---|
| 연산 위치 | CPU, GPU, 가속기 코어 | 메모리 근처 또는 메모리 내부 |
| 데이터 이동량 | 많음 | 적음 |
| 범용성 | 높음 | 낮음~중간 |
| 대표 강점 | 복잡한 제어 흐름 | 대규모 반복 데이터 처리 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Memory Array | 실제 데이터가 저장되는 위치로 연산 가능 범위와 병렬성이 여기서 결정됨 |
| Peripheral Compute Circuit | sense amplifier와 ADC, DAC, bitline 연산 회로가 결과 생성과 변환을 담당함 |
| Controller | 어떤 행과 열을 활성화할지와 연산 모드를 제어해 호스트와 메모리 연산을 연결함 |
| Error, Calibration Logic | 아날로그 오차와 셀 변동성을 보정해 결과 신뢰도를 유지함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 연산 매핑      | --> | 배열 활성화    | --> | 근접 연산 수행 | --> | 보정/결과 반환 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **연산 매핑**: 대상 연산을 메모리 행, 열, 비트라인 구조에 맞춤
2. **배열 활성화**: 필요한 셀과 주변 회로를 선택함
3. **근접 연산 수행**: 저장 위치 또는 근처에서 비교, 누산, 검색을 처리함
4. **보정 및 결과 반환**: 오류 보정과 변환을 거쳐 호스트에 전달함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 아날로그형 인메모리 연산은 공정 변동과 노이즈 때문에 결과 정확도가 흔들릴 수 있음
   - 해결방안: calibration과 mixed precision을 적용하고 accuracy delta와 conversion error로 정밀도를 검증함
2. 문제: 메모리 셀을 연산에 반복 활용하면 retention과 내구성과 오류율 문제가 커질 수 있음
   - 해결방안: ECC와 wear management를 적용하고 bit error rate와 lifetime projection으로 신뢰성을 검증함
3. 문제: 기존 컴파일러와 ISA가 메모리 내부 연산을 자연스럽게 표현하지 못해 소프트웨어 활용성이 낮을 수 있음
   - 해결방안: 전용 runtime과 ISA 확장을 도입하고 supported operator coverage와 programming effort로 적용성을 검증함

## Ⅶ. 적용 사례

- 추천 모델 추론에서는 메모리 근처 MAC 연산을 적용하고, energy per inference와 memory bandwidth reduction로 결과를 확인함
- 데이터베이스 검색 가속에서는 배열 내부 비교를 활용하고, query latency와 throughput으로 결과를 확인함
- 엣지 AI 가속기에서는 저전력 행렬 연산 경로를 구성하고, TOPS/W와 thermal envelope로 결과를 확인함

## Ⅷ. 결론

인메모리 컴퓨팅은 연산 성능 향상이 아니라 데이터 이동 비용 절감이 본질이므로, 메모리 병목이 지배적인 워크로드에서만 선택 가치가 커짐.
