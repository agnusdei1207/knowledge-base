# 인메모리 컴퓨팅 (In-Memory Computing)

## 미리 알고가기

- Memory Wall: 프로세서 성능 대비 메모리 대역폭과 지연이 따라가지 못하는 병목 현상임
- Near-Memory Computing: 메모리 가까이에 연산기를 배치해 데이터 이동을 줄이는 방식임
- In-Memory Computing: 메모리 셀 또는 배열 내부에서 연산을 수행하는 방식임
- CPU: 중앙처리장치(Central Processing Unit, CPU)는 인메모리 연산을 지시하고 결과를 수신하는 호스트 처리 장치임
- ADC/DAC: 아날로그-디지털 변환기(Analog-to-Digital Converter, ADC)와 디지털-아날로그 변환기(Digital-to-Analog Converter, DAC)는 디지털 값과 아날로그 신호를 변환하는 회로임

## Ⅰ. 개요

- **정의/개념**: 인메모리 컴퓨팅은 데이터 이동 비용이 성능·전력을 지배하는 워크로드에서 메모리 배열 내부 또는 근접 위치의 연산 회로로 논리·검색·행렬 연산을 수행해 이동량, 지연, 에너지를 통제하는 컴퓨팅 방식임.
- **배경/필요성**: 인공지능(Artificial Intelligence, AI)과 빅데이터 처리는 연산보다 메모리 접근이 더 많은 시간과 전력을 소비하는 경우가 많음. 인메모리 컴퓨팅은 데이터가 저장된 위치에서 직접 처리해 memory wall을 완화함.
- **비유**: 서류를 중앙 사무실로 매번 옮기지 않고 창고 안에서 바로 계산하고 결과만 전달하는 것과 같음.

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 데이터 이동 병목 해소 아키텍처 설명 | Memory Wall, 연산 위치, 아날로그/디지털, 정확도 | 단순 캐시 확대로 설명 |

> 요약: 인메모리 컴퓨팅은 데이터 이동 비용을 줄이기 위해 메모리 위치에서 연산을 수행하는 구조임.

## Ⅱ. 특징 및 비교

| 판단 기준 | 프로세서 중심 컴퓨팅 | 인메모리 컴퓨팅 |
|:---|:---|:---|
| 데이터 이동 | 메모리에서 프로세서로 데이터를 반복 이동함 | 저장 위치 근처에서 계산해 이동량을 줄임 |
| 최적화 목표 | 범용 명령 실행과 캐시 효율 | 대역폭, 에너지, 행렬·검색 연산 효율 |
| 적용 기준 | 제어 흐름이 복잡하고 정확한 범용 연산에 적합함 | 곱셈-누산(Multiply-Accumulate, MAC), bitwise 연산, 검색처럼 데이터 병렬성이 큰 작업에 적합함 |

> 요약: 인메모리 컴퓨팅은 범용성보다 데이터 이동 절감이 성능과 전력을 지배하는 문제에 적합함.

## Ⅲ. 구성요소/구조

```text
+----------+     +----------+     +----------+
| Host CPU | --> | Controller| --> | Mem Array|
+----------+     +----------+     +----------+
                                      |
                     +----------------+----------------+
                     v                                 v
              +-------------+                   +-------------+
              | Compute Per |                   | ECC/Convert |
              +-------------+                   +-------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 메모리 배열 | 동적 램(Dynamic Random Access Memory, DRAM), 정적 램(Static Random Access Memory, SRAM), 비휘발성 메모리 등 저장 위치가 연산의 기반이 됨 | 자료 창고 |
| 연산 주변회로 | sense amplifier, bitline, ADC/DAC가 연산 결과를 생성하거나 변환함 | 창고 안 계산대 |
| 컨트롤러 | 어떤 행과 열을 활성화하고 어떤 연산을 수행할지 제어함 | 작업 지휘자 |
| 오류 보정 | 노이즈, 변동성, 근사 연산 결과를 보정하고 검증함 | 검수 담당 |

> 요약: 인메모리 컴퓨팅은 메모리 배열, 연산 회로, 제어기, 보정 회로가 함께 동작함.

### 원리/흐름도

```text
+----------+     +----------+     +----------+     +----------+
| Map Op   | --> | Activate | --> | Compute  | --> | Return   |
+----------+     +----------+     +----------+     +----------+
```

1. **연산 매핑**: 행렬, bitwise, 검색 연산을 메모리 행·열과 데이터 배치에 맞춤
2. **배열 활성화**: 컨트롤러가 필요한 wordline, bitline, bank를 선택함
3. **근접 연산**: 메모리 셀 또는 주변회로가 누산, 비교, 논리 연산을 수행함
4. **보정/반환**: ADC/DAC 변환, 오류 정정 코드(Error Correction Code, ECC), 정규화 후 중앙처리장치(Central Processing Unit, CPU)나 가속기로 결과를 전달함

> 요약: 인메모리 처리는 연산을 메모리 배열에 배치하고 근접 연산 후 보정된 결과를 반환함.

## Ⅳ. 문제점 및 개선방안

- **P1 정밀도와 노이즈**: 아날로그 또는 근사 연산은 공정 변동, 열 잡음, 변환 오차로 정확도가 낮아질 수 있음
- **P1 대응**: 혼합 정밀도, 보정, ADC 해상도 조정, 알고리즘 차원의 오류 허용 설계를 적용함 (확인: 정확도 손실률)
- **P2 내구성과 신뢰성**: 메모리 셀을 연산에 반복 사용하면 쓰기 내구성, retention, 오류율 문제가 커질 수 있음
- **P2 대응**: wear leveling, ECC, refresh 정책, 셀 사용량 모니터링을 적용함 (확인: 오류율과 수명 예측)
- **P3 프로그래밍 모델 부재**: 기존 CPU 명령과 메모리 일관성 모델이 메모리 내부 연산을 직접 표현하기 어려움
- **P3 대응**: 명령어 집합 구조(Instruction Set Architecture, ISA) 확장, 런타임 라이브러리, 컴파일러 매핑, 일관성 규칙을 정의함 (확인: 지원 연산자 수)

> 요약: 인메모리 컴퓨팅 개선은 회로 보정, 셀 신뢰성 관리, 소프트웨어 스택 확장을 함께 수행해야 데이터 이동 절감 효과가 실현됨.

## Ⅴ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| AI 추론 가속 | MAC 중심 행렬 연산을 메모리 배열 근처에 배치해 가중치 이동을 줄임 | 연산당 에너지, 정확도 손실률, 처리량 |
| 데이터베이스 검색 | 내용 주소화 메모리(Content Addressable Memory, CAM) 또는 bitwise 연산으로 필터링을 메모리 내부에서 선처리함 | 스캔 지연, 호스트 전송량, 오류율 |
| 엣지 장치 | 저전력 센서·영상 처리에서 근사 연산을 허용하고 결과만 CPU로 전달함 | 배터리 사용 시간, 지연시간, 재보정 주기 |

> 요약: 실무 적용은 데이터 이동 감소 효과와 정확도·신뢰성 손실을 같은 지표로 검증해야 함.

## Ⅵ. 결론

- **발전 방향**: 인메모리 컴퓨팅은 프로세싱 인 메모리, 근접 데이터 처리, 내용 주소화 검색, 아날로그 행렬 연산과 결합해 데이터 이동 비용을 줄이는 방향으로 확장됨
- **기술사적 판단**: 연산 정밀도, 메모리 셀 내구성, ADC/DAC 오버헤드, host interface 지연, 기존 ISA와의 통합 비용을 기준으로 구조를 선택함; 비트 오류율(Bit Error Rate, BER), 정확도 손실률, 이동 데이터량 감소, energy per operation, write endurance를 워크로드별 기준선과 비교함
- **기술사 제언**: 인메모리 컴퓨팅은 memory wall 해소 수단이지만 정확도, 내구성, 검증 가능성을 도입 조건으로 함께 제시해야 함
