## 미리 알고가기

- 인메모리 컴퓨팅은 메모리 셀 내부나 주변 회로에서 일부 연산을 수행하는 구조임
- 핵심 목적은 메모리 병목과 데이터 이동 에너지를 줄이는 데 있음
- 아날로그형과 디지털형은 정확도와 구현 난이도가 다름
- ADC·DAC는 메모리 셀의 아날로그 신호와 디지털 데이터를 상호 변환함

## 작성 근거(검토용)

- 인메모리 컴퓨팅은 메모리 배열, 주변 연산 회로, 데이터 이동 비용을 핵심 축으로 설명함
- 비교표는 프로세서 중심 구조와 인메모리 컴퓨팅의 연산 위치·데이터 이동, 적합 조건, 구현 조건을 대비함
- 실무 판단은 질의당 에너지, 검색 정확도 차이, 비트 오류율, 예상 수명으로 구체화함

## Ⅰ. 개요

- **정의/개념**: 인메모리 컴퓨팅은 메모리 배열 내부·주변 회로에서 비교·검색·누산을 수행해 프로세서와의 데이터 이동량을 줄이는 구조임
- **배경/필요성**: AI 추론과 데이터 분석의 메모리 전송 시간·에너지를 줄이기 위해 반복 연산을 메모리 배열 가까이에 배치할 필요가 있음

### 쉽게 이해하기 (학습용)
- 창고(메모리)에서 물건을 매번 사무실(프로세서)로 옮겨 세지 않고, 창고 안에 작은 작업대를 두어 그 자리에서 세는 것과 같음

## Ⅱ. 특징

- 메모리와 프로세서 사이 왕복을 줄여 외부 전송량과 전송 에너지를 줄임
- 검색·비트 연산·행렬 곱처럼 배열에 반복 적용하는 연산을 메모리 내부·주변 회로에 매핑함
- 아날로그형은 셀·변환 회로의 잡음과 편차를 보정해야 하고, 디지털형은 비트 단위 연산 회로와 제어 로직이 필요함
- 제어 흐름은 호스트가 처리하고 검색·누산·행렬 곱처럼 배열에 매핑할 수 있는 연산을 메모리에서 수행함

### 쉽게 이해하기 (학습용)
- 작업대에서는 물건 세기·비교 같은 단순 반복만 처리하고 어려운 판단은 그대로 사무실 몫으로 남김
- 정밀 저울(디지털)로 재느냐 눈대중(아날로그)으로 재느냐에 따라 오차를 보정하는 수고가 달라짐

## Ⅲ. 종류 및 비교

| 판단 기준 | 프로세서 중심 구조 | 인메모리 컴퓨팅 |
|:---|:---|:---|
| 연산 위치·데이터 이동 | CPU·GPU·NPU 연산 코어에서 처리하며 메모리와 연산기 사이로 피연산자를 전송함 | 메모리 셀 내부·주변 회로에서 피연산자 전송 없이 직접 연산함 |
| 적합 조건 | 분기·제어 흐름이 복잡한 범용 작업 | 검색·누산·행렬 연산처럼 배열 반복성이 높은 작업 |
| 구현 조건 | 기존 컴파일러·런타임 사용 | 정확도 보정·내구성 관리·전용 런타임 필요 |

> 요약: 프로세서 중심 구조는 범용 명령을 실행하고, 인메모리 컴퓨팅은 반복 연산을 메모리 내부·주변 회로에 배치해 외부 전송량을 줄임.

### 쉽게 이해하기 (학습용)
- 모든 물건을 사무실로 옮겨 처리하는 방식(프로세서 중심)과, 자주 반복하는 물건 찾기만 창고 작업대에서 끝내는 방식(인메모리)의 차이임

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 메모리 배열 | 실제 데이터가 저장되는 공간이며 연산 병렬도와 셀 특성이 전체 성능을 좌우함 |
| 주변 연산 회로 | 센스 앰프·ADC·DAC·비트라인 로직이 셀 신호를 읽고 디지털 결과로 변환함 |
| 제어기 | 어떤 행과 열을 활성화할지와 어떤 연산 모드를 쓸지를 정해 호스트와 메모리 연산을 연결함 |
| 보정 및 오류 제어 | 셀 편차와 노이즈를 보정하며 아날로그형 연산의 정확도를 결정함 |

> 요약: 메모리 배열과 주변 회로가 연산을 나눠 처리하고 제어기와 보정 로직이 정확도를 유지함.

### 쉽게 이해하기 (학습용)
- 선반(메모리 배열)에 물건을 쌓고 옆 계산 도구(주변 회로)로 세며, 작업 지시서(제어기)가 어느 선반을 열지 정하고 품질검사원(보정 회로)이 오차를 걸러냄

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 연산 매핑      | --> | 배열 활성화    | --> | 근접 연산 수행 | --> | 결과 변환·반환 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **연산 매핑**: 호스트 연산을 메모리 내부에서 수행할 수 있는 형태로 바꿈
2. **배열 활성화**: 필요한 행과 열, 주변 회로를 선택함
3. **근접 연산 수행**: 메모리 내부나 주변에서 비교, 누산, 검색을 수행함
4. **결과 변환 및 반환**: 보정과 변환을 거쳐 호스트로 결과를 돌려줌

> 요약: 연산을 메모리 내부에 매핑하고 배열·주변 회로에서 수행한 뒤 보정해 반환함.

### 쉽게 이해하기 (학습용)
- 주문서를 창고 언어로 바꾸고, 필요한 선반만 불을 켜고, 그 자리에서 세어본 뒤, 결과를 사무실 양식으로 바꿔 보고하는 순서와 같음

## Ⅵ. 실무 사례

1. 벡터 검색은 혼합 정밀도와 셀 편차 보정을 적용하고 질의당 에너지·검색 정확도 차이를 확인함
2. 쓰기가 반복되는 메모리 셀은 오류 정정과 마모 분산을 적용하고 비트 오류율·예상 수명을 확인함

### 쉽게 이해하기 (학습용)
- 비슷한 사진을 창고에서 바로 훑어보며 정확도를 확인하는 일과, 자주 쓰는 선반이 닳지 않게 돌려 쓰며 고장 여부를 점검하는 일에 해당함

## Ⅶ. 결론

- 인메모리 컴퓨팅은 메모리 배열 내부·주변 회로에서 반복 연산을 직접 수행해 프로세서와의 데이터 이동량을 줄이는 구조임
- 데이터 이동이 실행 시간과 에너지를 제한하는 검색·누산 연산에 적용하되, 아날로그형은 정확도 보정 비용까지 함께 판단해야 함

### 쉽게 이해하기 (학습용)
- 창고 왕복이 잦은 일에만 작업대를 두는 것이 이득이며, 오차를 바로잡는 수고까지 함께 따져야 함
