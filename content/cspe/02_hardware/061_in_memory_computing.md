## 미리 알고가기

- 인메모리 컴퓨팅은 메모리 셀 내부나 주변 회로에서 일부 연산을 수행하는 구조임
- 핵심 목적은 메모리 병목과 데이터 이동 에너지를 줄이는 데 있음
- 아날로그형과 디지털형은 정확도와 구현 난이도가 다름

## Ⅰ. 개요

- **정의/개념**: 인메모리 컴퓨팅은 데이터를 CPU나 GPU로 계속 옮기지 않고 메모리 배열 내부 또는 주변 회로에서 비교, 검색, 누산 같은 연산을 수행해 데이터 이동량을 줄이는 컴퓨팅 구조임
- **배경/필요성**: AI 추론과 데이터 분석은 연산보다 메모리 접근과 데이터 이동에 시간·전력을 더 많이 쓰는 경우가 많으므로, 연산 위치를 데이터 가까이 옮길 필요가 있음

## Ⅱ. 특징

- 메모리와 프로세서 사이 왕복을 줄여 대역폭 병목과 에너지 낭비를 완화할 수 있음
- 검색, bitwise 연산, 행렬 곱처럼 같은 연산을 많은 데이터에 반복하는 작업에 잘 맞음
- 아날로그형은 전력 이점이 있지만 노이즈 보정 부담이 있고, 디지털형은 정확도가 높지만 구조가 무거울 수 있음
- 범용 제어 흐름 전체를 대체하기보다 특정 연산 커널을 가속하는 방식으로 쓰는 편이 현실적임

## Ⅲ. 종류 및 비교

| 판단 기준 | 프로세서 중심 구조 | 인메모리 컴퓨팅 |
|:---|:---|:---|
| 연산 위치 | CPU, GPU, NPU 같은 연산 코어에서 처리함 | 메모리 셀 내부나 주변 회로에서 일부 연산을 처리함 |
| 데이터 이동 | 메모리와 연산기 사이로 피연산자를 전송함 | 메모리 내부·주변 회로에서 피연산자를 처리함 |
| 적합한 작업 | 제어 흐름이 복잡한 범용 작업에 맞음 | 검색, 누산, 행렬 연산처럼 반복성이 높은 작업에 맞음 |
| 운영 부담 | 기존 컴파일러와 소프트웨어 생태계를 그대로 활용하기 쉬움 | 정확도 보정, 내구성, 전용 런타임 설계가 필요함 |

> 요약: 프로세서 중심 구조는 범용 명령을 실행하고, 인메모리 컴퓨팅은 반복 연산을 메모리 내부·주변 회로에 배치해 외부 전송량을 줄임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 메모리 배열 | 실제 데이터가 저장되는 공간이며 연산 병렬도와 셀 특성이 전체 성능을 좌우함 |
| 주변 연산 회로 | sense amplifier, ADC, DAC, bitline 로직이 셀 데이터를 읽고 연산 결과로 변환함 |
| 제어기 | 어떤 행과 열을 활성화할지와 어떤 연산 모드를 쓸지를 정해 호스트와 메모리 연산을 연결함 |
| 보정 및 오류 제어 | 셀 편차와 노이즈를 줄여 결과 품질을 유지하며 아날로그형에서는 특히 중요함 |

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 호스트 요청    | --> | 메모리 배열    | --> | 주변 연산 회로 | --> | 보정 후 결과 반환 |
+-------------+     +-------------+     +-------------+     +-------------+
```

> 요약: 메모리 배열과 주변 회로가 연산을 나눠 처리하고 제어기와 보정 로직이 정확도를 유지함.

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 연산 매핑      | --> | 배열 활성화    | --> | 근접 연산 수행 | --> | 결과 변환/반환 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **연산 매핑**: 호스트 연산을 메모리 내부에서 수행할 수 있는 형태로 바꿈
2. **배열 활성화**: 필요한 행과 열, 주변 회로를 선택함
3. **근접 연산 수행**: 메모리 내부나 주변에서 비교, 누산, 검색을 수행함
4. **결과 변환 및 반환**: 보정과 변환을 거쳐 호스트로 결과를 돌려줌

> 요약: 연산을 메모리 내부에 매핑하고 배열·주변 회로에서 수행한 뒤 보정해 반환함.

## Ⅵ. 실무 적용 및 유의점

1. 추천 추론·벡터 검색은 메모리 이동이 지배적이라 적합하지만 아날로그 오차가 누적될 수 있으므로 혼합 정밀도와 보정을 두고 energy per inference, accuracy delta, bandwidth reduction으로 확인함
2. 메모리 셀을 연산에 반복 쓰면 내구성과 오류율이 병목이 되므로 ECC와 wear management를 적용하고 bit error rate, expected lifetime, sustained throughput으로 확인함

## Ⅶ. 결론

인메모리 컴퓨팅은 연산 성능 자체보다 데이터 이동 비용을 줄이는 구조이므로 메모리 병목이 지배적인 반복 워크로드에 선택적으로 적용해야 효과가 생김.

## 작성 근거(검토용)

- 인메모리 컴퓨팅은 메모리 배열, 주변 연산 회로, 데이터 이동 비용을 핵심 축으로 설명함
- 비교표는 프로세서 중심 구조와 연산 위치, 데이터 이동, 보정 부담 차이를 대비함
- 실무 판단은 energy per inference, accuracy delta, bit error rate로 검증 가능하게 작성함
