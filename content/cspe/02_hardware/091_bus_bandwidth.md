## Ⅰ. 개요
- **정의**: 단위 시간당 버스가 전송 가능한 최대 데이터량
- **배경/필요성**: CPU·메모리·I/O 간 데이터 교환량이 증가하면서 버스 대역폭이 시스템 전체 처리량의 병목 요인이 됨
- **비유**: 도로 차선 수(버스 폭) × 제한속도(클럭)가 시간당 통과 차량 수(대역폭)를 결정하는 것과 동일

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 대역폭 산출 공식과 병목 분석 능력 확인 | BW = 버스폭 × 클럭 × 전송률 | 이론 대역폭과 유효 대역폭 구분 필요 |

> 요약: 버스 대역폭은 버스폭·클럭·전송률의 곱으로 결정되며, 시스템 병목의 핵심 지표임

## Ⅱ. 구성요소
```text
CPU <---> Bus Controller <---> Memory
               |
          +----+----+
          |         |
        I/O-1    I/O-2

Bus Width (bits) x Clock (Hz) x Transfers/Cycle = Bandwidth (B/s)
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 버스 폭(Bus Width) | 한 사이클에 병렬 전송되는 비트 수(32/64/128bit 등) | 도로 차선 수 |
| 버스 클럭(Bus Clock) | 초당 사이클 수(MHz/GHz 단위) | 도로 제한속도 |
| 전송률(Transfer Rate) | 사이클당 데이터 전송 횟수(DDR은 2회/cycle) | 차선당 동시 통행 차량 수 |
| 버스 중재기(Arbiter) | 다수 마스터 간 버스 접근 순서를 결정하는 로직 | 교차로 신호등 |

> 요약: 버스 폭·클럭·전송률 세 요소의 곱이 이론 대역폭을 결정함

## Ⅲ. 절차
```text
요구 분석 --> 이론 BW 산출 --> 유효 BW 측정 --> 병목 개선
    |              |               |               |
    v              v               v               v
 트래픽 프로파일  공식 적용     오버헤드 반영    버스 재설계
```
- 1단계: 요구 분석 — CPU·I/O 디바이스별 데이터 전송량과 지연 허용치를 프로파일링함
- 2단계: 이론 BW 산출 — `BW = Width × Clock × TransfersPerCycle` 공식으로 최대 대역폭을 계산함
- 3단계: 유효 BW 측정 — 프로토콜 오버헤드(헤더·핸드셰이크·중재 지연)를 차감하여 실측 대역폭을 산출함
- 4단계: 병목 개선 — 버스 분리(Split Bus), 계층화, 클럭 상향 등으로 유효 대역폭을 확보함

> 요약: 이론 대역폭 산출 후 오버헤드를 반영한 유효 대역폭 기준으로 병목을 개선함

## Ⅳ. 문제점
- 공유 버스 경합: 다수 마스터가 동시 접근 시 중재 대기로 유효 대역폭이 이론 값의 40~60%로 저하됨
- 클럭 스큐: 버스 폭 확대 시 병렬 신호 간 도달 시간 차이가 발생하여 데이터 오류 가능성이 증가함
- 프로토콜 오버헤드: 주소 전송·핸드셰이크·에러 검출 등 비데이터 사이클이 실효 대역폭을 감소시킴

> 요약: 경합·스큐·프로토콜 오버헤드가 유효 대역폭을 이론 값 대비 크게 저하시킴

## Ⅴ. 개선방안
1. 단기: 버스 중재 알고리즘 최적화(라운드로빈→가중 우선순위)로 경합 대기 시간을 단축함
2. 중기: 소스 동기 클럭킹(Source-Synchronous Clocking) 도입으로 스큐 허용 범위를 확대함
3. 장기: 공유 버스를 포인트-투-포인트 직렬 링크(PCIe 등)로 전환하여 프로토콜 오버헤드를 근본적으로 제거함

> 요약: 중재 최적화 → 동기화 기법 → 직렬 링크 전환 순으로 유효 대역폭을 확보함

## Ⅵ. 전망
- 발전 방향: CXL·UCIe 등 칩간 인터커넥트가 기존 병렬 버스를 대체하며 TB/s급 대역폭 시대로 전환 중임
- 기술사적 판단: 대역폭 산출·병목 분석 능력은 SoC·서버 설계에서 여전히 핵심 역량임
- 기술사 제언: 이론 대역폭뿐 아니라 유효 대역폭 관점의 시스템 설계 역량 확보가 필요
