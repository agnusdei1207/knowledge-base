## Ⅰ. 개요
- 정의: 여러 개의 물리적 디스크를 하나의 논리적 단위로 묶어 성능과 신뢰성을 높이는 기술
- 배경: 단일 디스크의 용량/속도 한계 극복 및 고장 발생 시 데이터 복구 필요성
- 출제 의도
| 구분 | 내용 |
| --- | --- |
| 핵심 | RAID 레벨(0,1,5,6,10), 스트라이핑, 미러링, 패리티 |

## Ⅱ. 구성요소
```
[ RAID Controller ]
  /      |      \
[Disk1] [Disk2] [Disk3] ...
```
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 스트라이핑 | 데이터를 쪼개어 여러 디스크에 분산 저장 (성능) | 병렬 고속도로 |
| 미러링 | 동일 데이터를 두 개 이상의 디스크에 중복 저장 (가용성) | 복사본 보관 |
| 패리티 | 데이터 복구를 위해 계산된 오류 정정 정보 (신뢰성) | 검산용 수치 |
> 요약: 용도에 따라 속도 중심(RAID 0)과 안정성 중심(RAID 1/5/6)으로 구성함

## Ⅲ. 절차
1. 구성 선택: 서비스 요건(성능 vs 안정성)에 맞는 RAID 레벨 결정
2. 어레이 구축: 컨트롤러를 통해 물리 디스크들을 논리 볼륨으로 바인딩
3. 데이터 분산: 쓰기 발생 시 정책에 따라 스트라이핑 및 패리티 생성
4. 고장 복구: 디스크 장애 시 남은 데이터와 패리티로 Rebuild 수행
> 요약: 중복성(Redundancy)을 활용하여 무중단 서비스 운영을 지원함

## Ⅳ. 문제점
- RAID 5/6 등에서 쓰기 시 패리티 계산으로 인한 성능 저하(Write Penalty) 발생함

## Ⅴ. 개선방안
- 하드웨어 RAID 컨트롤러의 캐시 메모리 및 고성능 SSD 도입으로 병목 해결함

## Ⅵ. 전망
- 대용량 HDD의 Rebuild 시간 증대 문제를 해결하기 위한 Erasure Coding 기술 확산됨
- 클라우드 환경에 최적화된 소프트웨어 정의 스토리지(SDS) 기반 분산 RAID가 대세임
