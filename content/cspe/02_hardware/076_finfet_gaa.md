## Ⅰ. 개요
- 정의: 트랜지스터의 게이트와 채널이 맞닿는 면적을 넓혀 제어력을 높이는 입체 구조 기술
- 배경: 평면(2D) 구조의 단채널 효과(Short Channel Effect) 및 누설 전류 한계 봉착
- 출제 의도: 3D 구조인 FinFET과 차세대 GAA(MBCFET)의 구조적 차이점 비교 역량 측정

## Ⅱ. 구성요소
- ASCII 구조도
  [ FinFET ]               [ GAA / MBCFET ]
     Gate                     Gate
     |  /|                    |#####|
  ---|-/ |--- (Fin)        ---|-----|--- (Nanosheet)
     |/  |                    |#####|

- 구성요소 표
| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| FinFET | 채널을 상하좌우 3면에서 감싸는 지느러미 형태 | 3면 포위 |
| GAA | 채널의 4면 전체를 게이트가 감싸는 원통/시트 형태 | 완전 밀착 |
| Nanosheet | GAA 구현을 위해 채널을 얇은 종이 형태로 쌓은 구조 | 층층이 쌓인 샌드위치 |

- > 요약: 접촉 면적이 넓을수록 전자의 흐름을 더 정밀하게 제어 가능

## Ⅲ. 절차
- ASCII 흐름도
  [채널 형성] -> [게이트 절연막 증착] -> [게이트 전극 형성] -> [Source/Drain]

1. 채널 미세화: Fin(지느러미) 또는 Sheet(시트) 두께를 나노 단위로 조절
2. 4면 게이트 공정: 채널 하부까지 게이트 물질이 침투하도록 정밀 증착(GAA)
3. 적층 최적화: 시트 간 간격을 최소화하여 집적도 향상
4. 전류 최적화: 채널 폭 조절을 통해 요구되는 성능별 트랜지스터 설계

- > 요약: 수평 구조의 한계를 수직/입체화로 극복하는 공정 기술의 진화

## Ⅳ. 문제점
- 제조 복잡도: FinFET 대비 GAA의 공정 단계 급증 및 식각 난이도 상승
- 기생 커패시턴스: 게이트와 채널 간 밀착으로 인한 의도치 않은 전하 축적

## Ⅴ. 개선방안
- MBCFET: 나노와이어 대신 나노시트를 사용하여 전류 전송 능력 강화
- 신소재 계면: 게이트와 채널 사이의 계면 특성을 개선하는 박막 기술 적용

## Ⅵ. 전망
- 로드맵: 3nm 공정부터 GAA 전면 도입, 향후 2nm 이하 필수 아키텍처로 자리매김
- CSF: 나노시트 폭을 자유롭게 조절하여 설계 유연성을 확보하는 기술력 선점
