## Ⅰ. 개요
- 반도체 칩을 수평/수직으로 밀집 배치하여 성능을 극대화하는 기술
- 전공정(Front-end) 한계를 후공정(Back-end)에서 극복하는 혁신

| 구분 | 내용 |
| --- | --- |
| 정의 | 인터포저나 TSV를 활용해 다중 칩을 입체적으로 적층/배치함 |
| 필요성 | 데이터 전송 속도 향상, 칩 면적 효율화, 이종 집적 필요 |
| 출제의도 | TSV, 인터포저 등 핵심 패키징 요소 기술 이해 |

## Ⅱ. 구성요소
```
[ 2.5D Packaging ]         [ 3D Packaging ]
   +-------+ +-------+         +-------+
   | Logic | |  HBM  |         | Logic |
   +-------+ +-------+         +-------+ (TSV 연결)
   [   Interposer    ]         | Logic |
   +-----------------+         +-------+
```
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| TSV | 실리콘 다이를 수직으로 관통하는 전극 통로 | 엘리베이터 |
| Interposer | 칩과 기판 사이에서 미세 배선을 지원하는 층 | 중간 다리 |
| Micro Bump | 칩 간의 물리적/전기적 연결을 담당하는 돌기 | 납땜 단자 |
> 요약: 수평 배선 확장(2.5D) 및 수직 적층(3D)으로 밀도 높임.

## Ⅲ. 절차
```
[웨이퍼 가공] -> [TSV 형성] -> [범핑/적층] -> [몰딩/검사]
```
1. 웨이퍼 가공: 각 기능을 수행할 개별 다이를 웨이퍼 상에 제작함.
2. TSV 형성: 3D 적층을 위해 실리콘 내부에 미세 구멍 뚫고 구리 채움.
3. 적층: 칩을 수직으로 쌓거나 인터포저 위에 수평으로 배치함.
4. 검사: 본딩 상태 및 전기적 연결을 확인하고 보호제로 밀봉함.
> 요약: 입체적 배치를 통해 물리적 거리를 단축하고 통로를 확장함.

## Ⅳ. 문제점
- 발열 관리: 수직 적층 시 내부 칩의 열 배출이 매우 어려움.
- 수율 저하: 여러 칩 중 하나만 불량이어도 전체 패키지 폐기 위험함.

## Ⅴ. 개선방안
- 고방열 소재: 열전도율이 높은 소재 및 액체 냉각 기술 도입함.
- KGD(Known Good Die): 조립 전 개별 다이의 무결성 검증 강화함.

## Ⅵ. 전망
- HBM(고대역폭 메모리) 시장 성장에 따라 필수 핵심 기술로 부상함.
- 하이브리드 본딩 기술을 통한 초미세 피치 구현이 로드맵의 정점임.
