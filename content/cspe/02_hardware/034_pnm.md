## 미리 알고가기

- PNM은 메모리 셀 내부가 아니라 로직 다이·버퍼·인터포저 같은 메모리 인접 위치에서 연산하는 구조임
- PIM보다 구현 자유도가 높고 기존 메모리 공정을 덜 건드리지만 데이터 이동을 완전히 없애지는 못함
- 메모리와 프로세서 사이 중간 지점에서 데이터 이동과 범용성의 균형을 잡는 접근임
- DIMM 버퍼: 메모리 모듈에서 신호를 중계·재구동하는 칩으로 PNM 로직이 위치할 수 있는 지점임

## 작성 근거(검토용)

- PNM은 메모리 인접 로직에서 처리한다는 위치 차이를 PIM과 비교해 설명함
- PIM과 PNM을 연산 위치·로직 구현·적용 연산으로 비교함
- 호스트 전송량 감소와 인접 로직의 지원 연산을 PNM 적용 기준으로 정리함

## Ⅰ. 개요

- **정의/개념**: PNM은 메모리 컨트롤러, 버퍼 칩, 로직 다이, 인터포저 같은 메모리 인접 위치에 연산 기능을 두어, 메인 프로세서까지 데이터를 보내기 전에 가까운 곳에서 일부 처리를 수행하는 근접형 메모리 컴퓨팅 구조임
- **배경/필요성**: 메모리 공정 변경 없이 데이터 이동을 줄이고 로직 설계 자유도를 확보하기 위해 메모리 인접 연산 구조가 필요함

### 쉽게 이해하기 (학습용)
- 창고 안이 아니라 창고 바로 옆 하역장에 작업대를 둔 것과 같음
- 창고 구조는 그대로 두면서도 물류 이동 거리를 줄이는 절충안임

## Ⅱ. 특징

- PNM은 메모리 공정과 분리된 로직에 연산·제어 회로를 구현함
- 메모리 인접 위치에서 처리해 CPU나 GPU까지 가는 데이터 양을 줄일 수 있음
- 메모리 내부가 아니므로 완전한 현장 처리보다 이동 비용 절감 폭은 작을 수 있음
- HBM 베이스 다이, DIMM 버퍼, CXL 메모리 장치 같은 다양한 폼팩터에 적용 가능함

### 쉽게 이해하기 (학습용)
- 하역장은 창고 건물 자체를 고치지 않고도 별도 작업 공간을 지을 수 있어 자유도가 높음
- 다만 창고 안 작업대만큼 짧게 옮기지는 못해 절감 폭은 상대적으로 작고, 어느 하역장이든(HBM·DIMM·CXL) 세울 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | PIM | PNM |
|:---|:---|:---|
| 연산 위치 | 메모리 셀 또는 뱅크 내부 | 메모리 인접 버퍼·로직 다이 |
| 로직 구현 | 메모리 공정 안의 제한된 연산 회로 | 별도 로직 공정의 연산·제어 회로 |
| 적용 연산 | 누산·축약·비트 연산 | 전처리·압축·필터링·집계 |

> 요약: PIM은 메모리 셀·뱅크 내부에서 연산해 외부 전송량을 줄이고, PNM은 메모리 인접 로직에 연산 회로를 구현함.

### 쉽게 이해하기 (학습용)
- PIM은 창고 선반 사이에 작업대를 끼워 넣는 방식이고, PNM은 창고 출입구 옆에 별도 작업대를 세우는 방식임
- 처리할 수 있는 작업 종류도 PNM 쪽이 더 다양함(전처리·압축·필터링)

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 메모리 장치 | 대용량 데이터를 저장하며 근접 연산의 원천 데이터를 제공함 |
| 메모리 인접 로직 | 메모리 버퍼·베이스 다이·인터포저에서 전처리·집계·필터링을 수행함 |
| 호스트 인터페이스 | CPU나 GPU가 메모리 인접 연산을 지시하고 결과를 수신하는 경로임 |
| 작업 이관 실행환경 | 외부 전송량이 줄어드는 작업을 PNM으로 이관함 |

```text
+-------------+     +------------------+     +------------------+
| 호스트 CPU/GPU | --> | 메모리 인접 로직   | --> | 메모리 장치        |
+-------------+     +------------------+     +------------------+
```

> 요약: PNM은 메모리 인접 로직에서 전처리·집계·필터링을 수행해 호스트 왕복 데이터를 줄임.

### 쉽게 이해하기 (학습용)
- 하역장 직원(메모리 인접 로직)이 창고 선반(메모리 장치)에서 물건을 꺼내 미리 분류·포장한 뒤, 본사(호스트)에는 정리된 결과만 전달함

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 작업 분류        | --> | PNM 오프로딩    | --> | 근접 위치 전처리   | --> | 축약 결과 전달   |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **작업 분류**: 데이터 이동이 큰 작업과 제어 중심 작업을 나눔
2. **PNM 오프로딩**: 전처리와 집계 후보를 메모리 인접 로직으로 넘김
3. **근접 위치 전처리**: 필터링·압축·단순 연산을 가까운 위치에서 수행함
4. **축약 결과 전달**: 줄어든 데이터만 호스트로 보내 후속 연산을 이어감

> 요약: PNM은 이동량이 큰 작업을 메모리 인접 위치에서 축약한 뒤 호스트로 결과만 보냄.

### 쉽게 이해하기 (학습용)
- 옮길 물건이 많은 작업과 판단이 필요한 작업을 먼저 나누고, 하역장에서 포장을 줄인 뒤 줄어든 짐만 본사로 보내는 순서와 같음

## Ⅵ. 실무 사례

1. 분석 서버는 필터·압축 작업을 PNM으로 이관하고 작업당 전송 바이트와 종단 처리시간을 확인함
2. CXL PNM 장치는 장치 오류 격리를 적용하고 오류 복구시간과 장애 격리율을 확인함

### 쉽게 이해하기 (학습용)
- 하역장에서 미리 걸러내고 압축하면 본사까지 가는 화물이 줄어드는지 확인하고, 하역장 하나가 고장 나도 다른 구역까지 번지지 않는지 점검함

## Ⅶ. 결론

- PNM은 메모리 셀 내부가 아니라 버퍼·로직 다이·인터포저 같은 인접 위치에서 처리해 메모리 공정 변경 없이 데이터 이동을 줄이는 구조임
- 전처리·압축·필터링처럼 PIM보다 다양한 연산을 이관할 수 있는 대신, 완전한 셀 내부 처리인 PIM보다 이동 절감 폭은 작다는 점을 기준으로 적용 범위를 정해야 함

### 쉽게 이해하기 (학습용)
- 창고 옆 하역장에서 얼마나 걸러주는지와 본사로 가는 짐이 얼마나 줄어드는지를 보고 도입 여부를 정함
