## Ⅰ. 개요
- 특정 용도나 애플리케이션을 위해 최적화하여 설계된 맞춤형 반도체
- 범용 CPU 대비 압도적인 성능/전력 효율성을 제공하는 전용 칩

| 구분 | 내용 |
| --- | --- |
| 정의 | 특정 목적의 논리 회로를 하나의 칩에 구현한 집적 회로 |
| 장점 | 초고속 연산, 저전력 소모, 칩 면적 최소화 가능 |
| 출제의도 | FPGA와의 차이점 및 커스텀 반도체 트렌드 이해 |

## Ⅱ. 구성요소
```
+------------------------------------------+
|  [ ASIC Chip ]                           |
| +--------+  +--------+  +--------------+ |
| | Core   |  | Memory |  | Interface    | |
| | Logic  |  | (SRAM) |  | (PCIe, DDR)  | |
| +--------+  +--------+  +--------------+ |
| [ Power Management / Clock Generator ]   |
+------------------------------------------+
```
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| Hard Macro | 검증 완료된 고정 IP 블록(CPU, PHY 등) | 완제품 가구 |
| Standard Cell | 설계자가 배치하는 기본 논리 게이트 집합 | 벽돌 꾸러미 |
| Netlist | 논리 소자 간의 연결 관계를 정의한 설계도 | 전기 배선도 |
> 요약: 최적화된 논리 소자와 IP를 고정 배선으로 연결함.

## Ⅲ. 절차
```
[Spec 정의] -> [RTL 설계] -> [물리 설계] -> [Tape-out/생산]
```
1. Spec 정의: 목표 성능, 전력, 면적(PPA) 사양 확정함.
2. RTL 설계: 논리 동작 설계 및 시뮬레이션 검증 수행함.
3. 물리 설계: 배치 및 배선(P&R)을 통해 실제 패턴 레이아웃 생성함.
4. Tape-out: 최종 데이터를 파운드리에 전달하여 양산 공정 시작함.
> 요약: 설계 확정 후 수정 불가능한 형태로 대량 양산함.

## Ⅳ. 문제점
- 고액의 초기 비용: 마스크 제작 등 NRE 비용이 매우 높아 리스크 큼.
- 수정 불가: 제조 후 논리 회로 수정이 불가능하여 재설계 시 비용 폭증함.

## Ⅴ. 개선방안
- 철저한 검증: 에뮬레이션 및 FPGA 프로토타이핑으로 설계 결함 사전 차단함.
- 칩렛(Chiplet) 활용: 공통 기능은 검증된 칩셋 사용해 설계 부담 경감함.

## Ⅵ. 전망
- 하이퍼스케일러 기업들의 자체 ASIC(AI, 클라우드 가속기) 개발 가속화됨.
- 최첨단 미세 공정(3nm 이하) 선점이 ASIC 경쟁력의 핵심 성공 요인임.
