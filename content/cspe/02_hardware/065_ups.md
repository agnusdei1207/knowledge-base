## Ⅰ. 개요
- 정전 등 전력 공급 중단 시 저장된 전기를 즉시 공급하는 장치
- 전력 품질 저하(전압 강하, 노이즈)로부터 민감한 장비를 보호

| 구분 | 내용 |
| --- | --- |
| 정의 | 예비 전력을 저장했다가 주 전원 장애 시 전력을 공급하는 설비 |
| 필요성 | 데이터 손실 방지, 시스템 연속성 보장, 하드웨어 손상 방지 |
| 출제의도 | UPS 동작 방식(온라인, 오프라인) 및 핵심 구성 이해 |

## Ⅱ. 구성요소
```
[ UPS Flow ]
(Main AC) --> [ Rectifier ] --> [ Inverter ] --> (Output AC)
                   |
            [ Battery Bank ]
```
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| Rectifier | 교류(AC)를 직류(DC)로 변환하고 배터리 충전 | 충전기 |
| Battery | 전기에너지를 화학에너지로 저장하는 장치 | 비상식량 |
| Inverter | 배터리의 직류(DC)를 깨끗한 교류(AC)로 변환 | 발전기 |
> 요약: 평소에는 배터리를 충전하고, 비상시 이를 사용해 전력 공급함.

## Ⅲ. 절차
```
[정상 모드] -> [정전 감지] -> [배터리 모드] -> [복구/바이패스]
```
1. 정상 모드: 주 전원을 필터링하여 장비에 공급하고 배터리 충전함.
2. 감지: 입력 전압의 급격한 변동이나 단절을 실시간 모니터링함.
3. 배터리 모드: 정전 시 0ms 또는 수ms 내에 배터리 전원으로 전환함.
4. 바이패스: UPS 내부 고장 시 주 전원을 직접 장비에 연결함.
> 요약: 전원 공급 중단을 감지하여 무단절로 예비 전력을 투입함.

## Ⅳ. 문제점
- 배터리 수명: 주기적인 교체(3~5년)가 필요하며 유지비용 발생함.
- 효율 저하: 변환 과정(AC-DC-AC)에서 전력 손실 및 발열 발생함.

## Ⅴ. 개선방안
- 리튬이온 도입: 기존 납축전지 대비 수명이 길고 부피가 작은 LIB 사용함.
- 에코 모드: 전력 품질이 양호할 때 변환 과정을 최소화하여 효율 높임.

## Ⅵ. 전망
- 모듈형 UPS 확산을 통한 유연한 용량 증설 및 유지보수 편의성 증대됨.
- 스마트 그리드와 연계한 에너지 저장 장치(ESS)로서의 역할 확대가 핵심임.
