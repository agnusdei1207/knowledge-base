## 미리 알고가기

- NVDIMM은 DIMM 폼팩터에서 비휘발성을 제공하는 메모리 모듈임
- NVDIMM-N은 정상 시 DRAM을 사용하고 정전 시 내용을 비휘발 매체에 백업하는 유형임
- DRAM은 휘발성 메모리이고 NAND는 비휘발성 저장 매체임
- 백업 전원(backup power)은 정전 시 DRAM 내용을 비휘발 매체로 옮길 시간을 확보하는 전원 장치임

## 작성 근거(검토용)

- NVDIMM은 DRAM, 비휘발 매체, 백업 전원, 펌웨어 복구를 핵심 축으로 설명함
- 비교표는 DRAM·SSD·NVDIMM의 접근 경로, 전원 장애 후 상태, 대표 데이터를 대비함
- 실무 판단은 플랫폼 호환성·복구 시간과 장애 후 정합성·백업 무결성으로 검증함

## Ⅰ. 개요

- **정의/개념**: NVDIMM은 DIMM 폼팩터에서 비휘발성을 제공하는 메모리 모듈이며, NVDIMM-N은 정전 시 DRAM 내용을 비휘발 매체에 백업함
- **배경/필요성**: 로그·메타데이터·캐시의 복구 시간 한도를 충족하기 위해 DRAM 접근 경로와 비휘발성을 결합한 메모리 계층이 필요함

## Ⅱ. 특징

- 정상 동작 시 CPU가 메모리 버스로 DRAM 영역에 접근함
- 정전 시 백업 전원으로 DRAM 내용을 비휘발 매체에 저장함
- 플랫폼 펌웨어와 OS와 애플리케이션이 함께 지원해야 의미가 있음
- 백업 전원과 미디어 수명과 플러시 규칙이 실질 신뢰성을 좌우함

## Ⅲ. 종류 및 비교

| 판단 기준 | DRAM DIMM | SSD | NVDIMM-N |
|:---|:---|:---|:---|
| 정상 접근 | CPU가 메모리 명령으로 접근함 | 블록 I/O와 저장장치 프로토콜로 접근함 | CPU가 메모리 버스로 DRAM 영역에 접근함 |
| 전원 차단 후 | 데이터가 소실됨 | 비휘발 매체에 데이터가 유지됨 | DRAM 내용을 비휘발 매체에 백업해 유지함 |
| 대표 데이터 | 작업 메모리·임시 데이터 | 대용량 파일·블록 데이터 | 장애 후 복구할 로그·메타데이터·캐시 |

> 요약: NVDIMM-N은 정상 시 DRAM 접근 경로를 사용하고 정전 시 백업 전원으로 비휘발 매체에 데이터를 보존함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| DRAM 영역 | 정상 동작 시 낮은 지연의 읽기와 쓰기를 담당함 |
| 비휘발 매체 | 전원 장애 시 DRAM 내용을 보존하는 저장 영역이 됨 |
| 백업 전원 | 순간 정전 시 DRAM 내용을 비휘발 매체로 옮길 시간을 확보함 |
| 펌웨어·드라이버 | 초기화와 복구와 오류 보고를 담당해 플랫폼 호환성을 결정함 |

> 요약: NVDIMM-N은 DRAM·비휘발 매체·백업 전원과 복구 펌웨어로 정전 전후의 데이터를 보존함.

## Ⅴ. 원리 및 절차 흐름도

1. **정상 접근**: 시스템이 NVDIMM을 빠른 메모리 영역처럼 읽고 씀
2. **장애 감지**: 전원 이상과 리셋 상황을 모듈과 펌웨어가 감지함
3. **데이터 보존**: 백업 전원으로 DRAM 내용을 비휘발 매체에 저장함
4. **재부팅 복구**: 플랫폼이 보존 데이터를 다시 읽어 운영 상태를 복구함

> 요약: 정상 시 DRAM으로 동작하고 전원 장애가 발생하면 비휘발 매체로 백업한 뒤 재부팅 때 복원함.

## Ⅵ. 실무 사례

1. 데이터베이스 로그용 NVDIMM-N은 플랫폼 호환성과 부팅 복구를 시험하고 호환성 통과율·복구 시간을 확인함
2. NVDIMM-N 영속 쓰기 경로는 쓰기 반영 순서와 저널링을 적용하고 장애 후 정합성·백업 무결성을 확인함

## Ⅶ. 결론

- NVDIMM은 메모리 버스 접근과 정전 백업을 결합하므로 플랫폼 호환성·백업 전원·영속 쓰기 순서를 함께 검증해야 함
