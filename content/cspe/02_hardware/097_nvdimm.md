## 미리 알고가기

- NVDIMM은 DIMM 폼팩터에서 비휘발성을 제공하는 메모리 모듈임
- DRAM은 빠르지만 전원을 끄면 지워지고, NAND는 느리지만 데이터를 유지함
- backup power는 정전 시 DRAM 내용을 비휘발 매체로 옮길 시간을 보장하는 전원 장치임

## Ⅰ. 개요

- **정의/개념**: NVDIMM은 DRAM 수준의 빠른 메모리 접근성과 전원 장애 후 데이터 보존 기능을 DIMM 형태에서 함께 제공하는 비휘발성 메모리 모듈임
- **배경/필요성**: 로그와 메타데이터와 캐시처럼 지연에 민감하면서도 장애 후 빠르게 복구해야 하는 데이터는 DRAM과 SSD 사이의 새로운 영속 계층이 필요함

## Ⅱ. 특징

- 정상 동작 시에는 메모리 버스를 통한 낮은 지연 접근이 가능함
- 정전 시 DRAM 내용을 비휘발 매체로 보존해 빠른 재시작을 지원함
- 플랫폼 펌웨어와 OS와 애플리케이션이 함께 지원해야 의미가 있음
- 백업 전원과 미디어 수명과 flush 규칙이 실질 신뢰성을 좌우함

## Ⅲ. 종류 및 비교

| 판단 기준 | DRAM DIMM | SSD | NVDIMM |
|:---|:---|:---|:---|
| 접근 경로 | CPU가 메모리 버스로 직접 접근함 | 블록 I/O 경로를 거침 | 메모리 버스로 접근하면서 영속성도 제공함 |
| 지속성 | 전원 차단 시 데이터가 사라짐 | 전원 차단 후에도 데이터가 남음 | 정전 시 백업 절차를 거쳐 데이터가 유지됨 |
| 지연 특성 | 가장 빠름 | 메모리보다 느림 | DRAM에 가깝고 SSD보다 훨씬 낮은 지연을 가짐 |
| 적합 데이터 | 작업 메모리와 임시 데이터에 적합함 | 대용량 영구 저장에 적합함 | 빠른 복구가 필요한 영속 로그와 캐시에 적합함 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| DRAM 영역 | 정상 동작 시 낮은 지연의 읽기와 쓰기를 담당함 |
| 비휘발 매체 | 전원 장애 시 DRAM 내용을 보존하는 저장 영역이 됨 |
| backup power | 순간 정전 시 데이터 덤프 시간을 보장해 보존 실패를 막음 |
| 펌웨어·드라이버 | 초기화와 복구와 오류 보고를 담당해 플랫폼 호환성을 결정함 |

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 정상 접근      | --> | 장애 감지      | --> | 데이터 보존    | --> | 재부팅 복구    |
+-------------+     +-------------+     +-------------+     +-------------+
```

## Ⅴ. 원리 및 절차 흐름도

1. **정상 접근**: 시스템이 NVDIMM을 빠른 메모리 영역처럼 읽고 씀
2. **장애 감지**: 전원 이상과 리셋 상황을 모듈과 펌웨어가 감지함
3. **데이터 보존**: backup power로 DRAM 내용을 비휘발 매체에 저장함
4. **재부팅 복구**: 플랫폼이 보존 데이터를 다시 읽어 운영 상태를 복구함

## Ⅵ. 실무 적용 및 유의점

1. 데이터베이스 로그나 메타데이터 캐시는 NVDIMM이 복구 시간을 크게 줄일 수 있지만 BIOS와 메모리 컨트롤러와 OS 지원이 맞지 않으면 기능이 제대로 노출되지 않으므로 HCL 검증과 부팅 시험을 함께 수행하고 호환성 매트릭스 통과율과 부팅 검증 결과와 복구 시간으로 확인함
2. 영속 쓰기 경로는 쓰기 반영 명령과 순서 보장 규칙이 빠지면 장애 후 상태가 어긋날 수 있으므로 영속 쓰기 규칙과 저널링을 적용하고 장애 후 정합성 통과율과 백업 무결성 점검 결과와 복구 결함 건수로 확인함

## Ⅶ. 결론

NVDIMM의 가치는 빠른 메모리 속도보다 장애 후 데이터를 안전하게 남기고 즉시 복구하는 데 있음.
