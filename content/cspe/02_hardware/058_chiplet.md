## Ⅰ. 개요
- **정의**: 기능별 소형 다이를 패키지 내에서 인터커넥트로 조합하여 하나의 프로세서를 구성하는 아키텍처
- **배경/필요성**: 공정 미세화에 따른 모놀리식 대면적 다이의 수율 급락 문제를 해결하고, 이종 공정 노드 혼합이 요구됨
- **비유**: 레고 블록처럼 기능별 작은 칩을 조립하여 원하는 프로세서를 완성하는 방식

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 모놀리식 vs 칩렛 구조 차이 | 수율·비용·헤테로지니어스 통합 장점 | UCIe(059 참조) 표준 인터페이스 언급 |

> 요약: 소형 다이 조합으로 수율과 설계 유연성을 동시에 확보하는 프로세서 아키텍처임

## Ⅱ. 구성요소
```text
  +----------+    +----------+    +----------+
  | Compute  |    |  I/O     |    | Memory   |
  | Chiplet  |    | Chiplet  |    | Chiplet  |
  +----+-----+    +----+-----+    +----+-----+
       |               |               |
       +-------+-------+-------+-------+
               |  Interposer / Bridge  |
               +-----------+-----------+
                           |
                    +------+------+
                    |  Package    |
                    |  Substrate  |
                    +-------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 컴퓨트 칩렛 | CPU/GPU 코어 등 연산 기능 담당 다이 | 엔진 모듈 |
| I/O 칩렛 | PCIe, USB, 네트워크 등 외부 인터페이스 담당 다이 | 차량 계기판 |
| 메모리 칩렛 | HBM, SRAM 캐시 등 데이터 저장 담당 다이 | 수납 서랍 |
| 인터포저/브릿지 | 칩렛 간 고속 배선을 연결하는 실리콘 또는 유기 기판 | 고속도로 |
| 패키지 기판 | 전체 칩렛을 탑재하고 외부 PCB와 연결하는 기판 | 건물 기초 |

> 요약: 연산·I/O·메모리 칩렛이 인터포저 위에서 고속 연결되어 하나의 패키지를 구성함

## Ⅲ. 절차
```text
  기능 분할       다이 제조       인터커넥트 배치     패키지 통합
  (IP 분리)     (공정별 제조)   (D2D 연결 구성)    (테스트/검증)
     |               |               |               |
     +----설계 완료--->+----웨이퍼 검증->+----접합 완료--->+
  SoC 기능 정의   개별 수율 확보   UCIe/BoW 적용   최종 동작 검증
```
- 1단계: IP 블록을 기능 단위로 분할하여 칩렛 경계를 정의함
- 2단계: 각 칩렛을 최적 공정 노드에서 개별 제조하여 수율을 확보함
- 3단계: 인터포저 또는 브릿지 위에 칩렛을 배치하고 D2D 인터커넥트를 구성함
- 4단계: 패키지 기판에 실장 후 전체 시스템 수준 테스트를 수행함

> 요약: 기능 분할 후 개별 제조·인터커넥트 배치·패키지 통합의 4단계로 진행됨

## Ⅳ. 문제점
- D2D 대역폭 한계: 칩렛 간 물리 배선 밀도 제약 — 모놀리식 대비 칩렛 간 통신 지연이 증가함
- 열 관리 복잡도: 이종 다이의 발열 특성 차이 — 다이 간 열 간섭으로 핫스팟 발생이 심화됨
- 테스트 비용 증가: KGD(Known Good Die) 확보 필요 — 개별 다이 사전 검증에 추가 공정과 비용이 소요됨

> 요약: 인터커넥트 대역폭, 열 관리, KGD 테스트가 칩렛 상용화의 핵심 과제임

## Ⅴ. 개선방안
1. 단기: UCIe(059 참조) 표준 채택으로 D2D 인터페이스 대역폭을 28 GT/s 이상으로 확보함
2. 중기: 3D 적층 패키징과 마이크로범프 미세화로 열 분산 경로를 확대함
3. 장기: 웨이퍼 레벨 KGD 테스트 자동화 및 DFT(Design for Test) 표준화로 검증 비용을 절감함

> 요약: 표준 인터커넥트, 3D 적층 방열, 자동화 테스트로 칩렛의 세 가지 과제를 해결함

## Ⅵ. 전망
- 발전 방향: 3D 칩렛 적층과 광 인터커넥트 결합으로 대역폭과 에너지 효율이 동시에 개선될 전망임
- 기술사적 판단: 무어의 법칙 한계 시대에 칩렛은 성능 확장의 현실적 대안으로 자리잡고 있음
- 기술사 제언: 이종 칩렛 에코시스템 구축을 위해 UCIe 표준 준수와 공급망 다변화가 필요함
