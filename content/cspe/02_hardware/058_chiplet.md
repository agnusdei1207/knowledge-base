## 미리 알고가기

- 칩렛은 큰 단일 다이를 여러 기능 다이로 분할해 패키지 안에서 연결하는 설계 방식임
- 수율과 공정 분리와 재사용성이 주요 장점임
- D2D 인터커넥트와 패키징과 테스트가 성패를 좌우함

## Ⅰ. 개요

- **정의/개념**: 칩렛은 CPU, I/O, 캐시, 가속기 같은 기능을 여러 개의 작은 다이로 분리한 뒤 패키지 내부 고속 인터커넥트로 연결해 하나의 시스템처럼 동작하게 만드는 반도체 통합 방식임
- **배경/필요성**: 대형 단일 다이는 수율과 비용과 reticle 한계 문제를 가지므로, 기능별 최적 공정을 쓰고 정상 다이만 조합할 수 있는 대안이 필요함

## Ⅱ. 특징

- 작은 다이 단위로 수율을 높이고 비용 리스크를 줄일 수 있음
- CPU와 I/O와 SRAM을 서로 다른 공정에 배치하는 이종 통합이 가능함
- 검증된 다이를 여러 제품에 재사용할 수 있어 설계 자산 활용도가 높음
- 패키지 내부 통신과 열과 전력 공급 문제가 새로운 병목으로 등장함

## Ⅲ. 종류 및 비교

| 판단 기준 | 단일 SoC | Chiplet |
|:---|:---|:---|
| 수율 관리 | 대형 다이일수록 불리함 | 작은 다이별 관리가 쉬움 |
| 공정 선택 | 전체가 같은 공정 | 기능별 최적 공정 가능 |
| 재사용성 | 낮음 | 높음 |
| 내부 통신 지연 | 낮음 | D2D 설계 의존 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Compute Chiplet | CPU, GPU, NPU 같은 계산 기능을 담당하며 고성능 공정을 적용하기 좋음 |
| I/O, Cache Chiplet | 메모리 제어와 외부 인터페이스와 대용량 캐시를 담당해 성숙 공정 재사용에 유리함 |
| D2D Interconnect | 칩렛 사이 대역폭과 지연을 결정하는 핵심 연결 구조임 |
| Package, Test Flow | interposer와 bridge와 KGD 검증이 최종 수율과 신뢰성을 좌우함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 기능 분할      | --> | 개별 다이 검증  | --> | 패키지 결합    | --> | D2D 통합 동작  |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **기능 분할**: 연산과 I/O와 캐시 기능을 다이 단위로 나눔
2. **개별 다이 검증**: KGD 수준에서 정상 여부를 확인함
3. **패키지 결합**: interposer, bridge로 고속 연결을 구성함
4. **D2D 통합 동작**: 패키지 내부에서 하나의 시스템처럼 동작시킴

## Ⅵ. 문제점 및 해결 방안

1. 문제: 칩렛 간 통신량이 큰 기능을 잘못 분리하면 패키지 내부 링크가 병목이 되어 단일 다이보다 성능이 나빠질 수 있음
   - 해결방안: 통신량 기반 partitioning을 수행하고 D2D latency와 bandwidth utilization으로 적합성을 검증함
2. 문제: 여러 다이를 한 패키지에 넣으면 hotspot과 전력 무결성 문제가 커질 수 있음
   - 해결방안: thermal과 SI, PI 시뮬레이션을 병행하고 hotspot temperature와 voltage droop로 안정성을 검증함
3. 문제: 개별 다이가 정상이더라도 패키지 조립 후 연결 불량으로 최종 수율이 흔들릴 수 있음
   - 해결방안: pre-bond와 post-bond test를 강화하고 package yield와 defect escape rate로 제조 품질을 검증함

## Ⅶ. 적용 사례

- 서버 CPU 제품군에서는 compute와 I/O 다이를 분리하고 확인 지표는 die yield와 package performance임
- AI 가속기 패키지에서는 HBM과 연산 다이를 조합하고 확인 지표는 bandwidth per watt와 thermal stability임
- 멀티벤더 시스템 통합에서는 재사용 칩렛을 조합하고 확인 지표는 integration lead time과 interoperability pass rate임

## Ⅷ. 결론

칩렛은 단순 분할이 아니라 수율과 공정과 재사용성을 패키지 수준에서 다시 최적화하는 방식이므로, D2D 통신 비용보다 제조 이익이 큰지 판단해야 함.
