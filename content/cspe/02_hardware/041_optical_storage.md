# 📖 【암기용】 개념 완전 이해
> 목적: 광 저장 장치를 처음 봐도 완벽히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 레이저 반사광의 세기 변화를 읽어 데이터를 기록·재생하는 비접촉 저장 매체
- **왜 필요한가**: 자기 디스크는 헤드 마모와 충격에 민감하고 반도체는 archival(장기 보관) 단가가 높다. 광 매체는 사출 성형으로 저비용 대량 복제가 가능하고 WORM(Write Once Read Many) 특성으로 위변조 방지 배포·보관 요구에 대응한다.
- **핵심 직관**: 레코드판의 나선형 홈처럼 트랙을 새기고, 굴곡(pit/land) 대신 반사율 차이를 레이저와 photodiode로 읽는 구조다.

## 깊이 이해
- **배경·문제의식**: 자기 매체는 접촉·근접 헤드로 마모가 발생하고, 반도체는 archival 비용이 높다.
- **배경·문제의식**: 광 매체는 비접촉 광학 판독으로 매체 마모가 없고, 사출 성형(injection molding) 대량 복제로 배포 단가가 낮다.
- **작동 원리**: CD는 파장 780nm 적외선 레이저와 NA(Numerical Aperture) 0.45를 사용한다.
- **작동 원리**: DVD는 파장 650nm 적색 레이저와 NA 0.6을 사용해 focal spot을 좁힌다.
- **작동 원리**: Blu-ray는 파장 405nm 청자색 레이저와 NA 0.85를 사용해 CD 대비 pit 밀도를 크게 높인다.
- **작동 원리**: 파장이 짧고 NA가 클수록 레이저 focal spot 지름이 작아져 단위 면적당 기록 밀도가 높아진다.
- **트랙 피치·용량**: CD 트랙 피치 1.6um에 용량 약 700MB, DVD 단면 단층 트랙 피치 0.74um에 용량 4.7GB, BD 단층 트랙 피치 0.32um에 용량 25GB, BD 듀얼레이어 50GB이다.
- **데이터 표현**: pit(파인 부분)와 land(평평한 부분)의 경계에서 반사광이 상쇄간섭을 일으켜 반사율이 급감한다.
- **데이터 표현**: 판독 오류를 줄이기 위해 pit 자체를 0/1로 대응시키지 않고 반사율이 바뀌는 전이(transition) 위치를 EFM(Eight-to-Fourteen Modulation) 같은 RLL(Run-Length Limited) 코드로 인코딩한다.
- **기록 방식 3종**: ROM은 사출 성형으로 pit를 물리적으로 새겨 재기록이 불가능하다.
- **기록 방식 3종**: R(Recordable)은 유기 염료층을 레이저 열로 비가역 변색시켜 WORM 특성을 가진다.
- **기록 방식 3종**: RW(ReWritable)는 상변화(Phase Change) 합금층을 레이저로 결정질/비정질 상태로 전환해 반사율을 가역적으로 바꾸고 수천~수만 회 재기록이 가능하다.
- **비유**: 나선형 트랙은 LP 레코드의 홈과 같고, pit는 홈의 굴곡이며, 레이저-photodiode는 바늘 대신 빛으로 굴곡을 읽는 장치다.
- **구체 예시**: Blu-ray 단층 25GB 디스크는 트랙 피치 0.32um, 최단 pit 길이 0.149um로 DVD 대비 트랙 밀도가 약 5배이며 동일 지름 12cm 디스크에서 용량이 5배 이상 확보된다.
- **흔한 오해·주의점**: 광자기 디스크(MOD, Magneto-Optical Disk)는 레이저 가열과 외부 자기장을 함께 사용하는 별도 계열이며, CD-RW/DVD-RW/BD-RE의 상변화(Phase Change) 방식과 원리가 다르다.
- **흔한 오해·주의점**: 광디스크는 회전 지연과 seek 동작 때문에 access latency가 수십~수백 ms 수준이며, SSD(수십 us 수준) 대비 3~4자리수 느리다.

## 연결 개념
- 자기 디스크(HDD) — 접촉·근접 헤드 기반 저장 매체와의 비교 대상
- NAND Flash·SSD — 접근속도 자릿수 비교 대상
- RAID·아카이브 스토리지(LTO 테이프) — 장기 보관·백업 대안 기술


# 📝 【답안용】 시험 답안 템플릿
> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.
> 핵심: 광 저장 장치 답안은 파장·NA·트랙피치로 결정되는 기록 밀도, ROM/R/RW 기록 원리 차이, archival 적합성과 접근 지연 트레이드오프를 함께 제시한다.

## 핵심 인사이트 (3줄 요약)
> 1. **본질**: 광 저장 장치는 레이저 반사율 차이를 pit/land 또는 상변화 물질로 기록하고 photodiode로 판독하는 비접촉 저장 매체다.
> 2. **가치**: 매체 단가가 낮고 대량 복제·탈부착이 쉬워 배포용 미디어와 WORM 기반 archival에 적합하다.
> 3. **판단 포인트**: 파장·NA로 결정되는 기록 밀도, ROM/R/RW 기록 방식 차이, 접근 지연이 선택 기준이다.

## 출제 의도 및 답안 포인트
| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 저장 매체 원리 이해 확인 | 파장·NA·트랙피치와 기록 밀도의 관계 | pit를 이진수 자체로 설명해 전이 인코딩(EFM) 누락 |
| 매체 선택 기준 확인 | archival/배포용 vs 온라인 스토리지 access latency 비교 | 접근 속도 자릿수 차이(ms vs us) 누락 |
| 기록 방식 구분 역량 확인 | ROM 사출성형·R 유기염료·RW 상변화 원리 차이 | 광자기(MO)와 상변화(PC) 방식 혼동 |

> 요약: 이 문제는 광디스크 종류 나열이 아니라 기록 밀도 결정 요인과 archival 적합성 판단 근거를 보여야 한다.


## Ⅰ. 개요 및 필요성
- 개요: 레이저 반사율 차이로 데이터를 기록·재생하는 비접촉 저장 매체
- 배경: 자기 매체의 헤드 마모·충격 민감성과 반도체 매체의 높은 archival 단가 문제
- 필요성: 저비용 대량 복제와 WORM 기반 위변조 방지 보관이 필요한 배포·아카이브 영역에서 광 저장장치가 대안이 됨


## Ⅱ. 구조 및 구성요소
```text
Laser Diode(780/650/405nm) -> Objective Lens(NA 0.45/0.6/0.85)
  -> Disc Surface(Pit/Land or Phase-Change Layer)
  -> Reflected Light -> Photodiode Detector
  -> RLL Decode(EFM) -> Data Output
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Laser Diode | 판독·기록용 광원 | CD 780nm, DVD 650nm, BD 405nm |
| Objective Lens | 레이저를 미세 초점으로 집속 | NA 0.45~0.85, 짧을수록 focal spot 축소 |
| Recording Layer | 데이터 저장 매체층 | ROM pit, R 유기염료, RW 상변화 합금 |
| Photodiode | 반사광 세기 검출 | 반사율 전이를 전기 신호로 변환 |
| RLL Decoder | 전이 신호를 데이터로 복원 | EFM(Eight-to-Fourteen Modulation) |

> 요약: 광 저장 장치는 레이저·렌즈로 미세 초점을 만들고 기록층의 반사율 차이를 photodiode와 RLL 디코더로 복원한다.


## Ⅲ. 동작원리 및 흐름도
```text
디스크 회전 -> 레이저 조사 -> Pit/Land 경계 상쇄간섭
  -> 반사율 급변 -> Photodiode 신호 검출
  -> EFM RLL 복호 -> 오류정정(Reed-Solomon) -> 데이터 출력
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 디스크 회전 중 레이저를 트랙에 focus | tracking error 최소화 |
| 2 | pit/land 경계에서 반사율 전이 발생 | 반사율 대비(contrast) 확보 |
| 3 | photodiode가 전이 신호를 전기 신호로 변환 | 신호 대 잡음비(SNR) |
| 4 | RLL 복호와 Reed-Solomon 오류정정으로 데이터 복원 | 블록 오류율(BLER) |

> 요약: 광 판독은 반사율 전이를 검출한 뒤 RLL 복호와 오류정정으로 원본 데이터를 복원하는 순서로 동작한다.


## Ⅳ. 특징
| 구분 | ROM | R(Recordable) | RW(ReWritable) |
|:---|:---|:---|:---|
| 기록 원리 | 사출 성형 pit | 유기 염료 레이저 열변색 | 상변화 합금 결정질/비정질 전환 |
| 재기록 여부 | 불가 | 불가(WORM) | 가능(수천~수만 회) |
| 적합 용도 | 배포용 대량 복제 | 1회성 백업·배포 | 반복 기록이 필요한 임시 저장 |
| 감점 회피 포인트 | 광자기(MO)와 혼동 금지 | 비가역 변색임을 명시 | 상변화는 반사율 가역 변화임을 명시 |

> 요약: ROM은 대량 복제, R은 1회성 archival, RW는 반복 기록용으로 기록 원리에 따라 용도가 갈린다.


## Ⅴ. 심화 비교 및 적용 판단
| 비교 축 | HDD/SSD | 광 저장 장치 | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | 자기·반도체 기반 랜덤 접근 | 나선형 트랙 순차 접근 | 랜덤 IO 요구 시 HDD/SSD |
| 비용/성능 | 매체 단가 높음, access latency 낮음(us~ms) | 매체 단가 낮음, access latency 높음(수십~수백 ms) | 대량 배포·archival 시 광 저장장치 |
| 운영/위험 | 재기록·마모 관리 필요 | ROM/R은 위변조 방지, RW는 재기록 수명 관리 | 장기 보존 요구 시 WORM 특성 활용 |

> 요약: 랜덤 접근 성능이 필요하면 HDD/SSD, 저비용 대량 복제와 위변조 방지가 필요하면 광 저장장치를 선택한다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 매체 열화 | 유기 염료·반사층 산화 | 저온·저습 보관, 정기 리프레시 복사 | BLER(Block Error Rate) 증가 추이 |
| 접근 지연 | 회전·seek 기반 순차 접근 | 자주 쓰는 데이터는 SSD/HDD 병행 | access latency ms 단위 측정 |
| 위변조 오인 | RW를 ROM/R과 혼동해 무결성 주장 | 기록 방식별 무결성 보장 범위 명시 | 기록 방식 메타데이터 관리 |

> 요약: 광 저장장치 운영 리스크는 매체 열화와 접근 지연이며 BLER과 access latency로 통제한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 기록 밀도 | 파장·NA 대비 목표 용량 확보 | 데이터시트 대비 실측 용량 |
| 판독 신뢰성 | BLER 허용치 이내 | 드라이브 진단 로그 |
| 보관 수명 | archival 대상 매체 수명 연 단위 확인 | 가속 열화 시험 |

> 요약: 도입 성공 여부는 목표 용량 확보, BLER 이내 판독 신뢰성, 보관 수명 확인으로 판단한다.


## Ⅵ. 실무 적용 및 결론
**적용 방안 3개:**
1. 배포용 소프트웨어·영상 매체는 ROM 사출 성형 방식을 적용해 대량 복제 단가를 낮춤
2. 규제 대응 장기 보관 데이터는 R(WORM) 매체로 기록해 위변조 방지 요구를 충족함
3. 반복 백업이 필요한 임시 저장은 RW 매체를 사용하되 재기록 횟수 한도를 모니터링함

**결론 (2줄):**
- 기술사 판단: 접근 성능이 중요하면 HDD/SSD, 저비용 대량 복제와 WORM 무결성이 중요하면 광 저장장치를 선택함
- 향후 방향: 클라우드 archival storage(Glacier 등)와 병행해 물리 매체 의존도를 낮추되 규제상 오프라인 보관이 필요한 영역에는 광 매체를 유지해야 함
