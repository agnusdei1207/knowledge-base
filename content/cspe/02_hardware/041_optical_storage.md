## 미리 알고가기

- 광 저장 장치는 레이저 반사율 차이로 데이터를 기록하고 읽는 비휘발성 저장 매체임
- 대표 규격은 CD, DVD, Blu-ray이며 파장과 기록 밀도 차이로 용량이 달라짐
- SSD보다 느리지만 오프라인 보관과 위변조 방지에 강점이 있음

## Ⅰ. 개요

- **정의/개념**: 광 저장 장치는 레이저로 디스크 기록층의 물리적 또는 화학적 상태를 변화시키고, 반사 신호 차이를 판독해 데이터를 저장하는 보조 기억장치 계열임
- **배경/필요성**: 온라인 스토리지는 속도는 빠르지만 랜섬웨어와 전원 의존성이 크므로, 장기 보관과 오프라인 백업을 위한 별도 저장 계층이 필요함

## Ⅱ. 특징

- 비휘발성 매체라 전원 없이도 장기간 데이터 보관이 가능함
- 물리적으로 분리 보관할 수 있어 에어갭 백업에 유리함
- 임의 접근 성능과 쓰기 속도는 HDD, SSD보다 느려 운영계 저장소로는 부적합함
- 기록 방식에 따라 ROM, R, RW 계열로 나뉘며 보존성과 재기록성이 달라짐

## Ⅲ. 종류 및 비교

| 판단 기준 | CD | DVD | Blu-ray |
|:---|:---|:---|:---|
| 대표 용량 | 약 700MB | 4.7GB~8.5GB | 25GB~100GB 이상 |
| 레이저 파장 | 780nm | 650nm | 405nm |
| 기록 밀도 | 낮음 | 중간 | 높음 |
| 대표 용도 | 음원, 경량 배포 | 영상, 백업 | 대용량 아카이브 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 레이저 다이오드 | 기록과 판독에 필요한 광원을 제공하며 파장 특성이 저장 밀도를 좌우함 |
| 광학 픽업 | 렌즈와 센서를 통해 반사 신호를 수집하고 초점 정밀도가 읽기 오류율에 직접 영향을 줌 |
| 기록층 | 염료층이나 상변화 물질이 실제 데이터 상태를 저장하며 매체 수명과 재기록 가능성을 결정함 |
| 서보, 모터 계층 | 회전 속도와 트래킹을 제어해 안정적인 판독을 보장하며 진동과 편심 보정이 중요함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 디스크 회전    | --> | 레이저 조사    | --> | 반사 신호 판독 | --> | ECC 복원/출력 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **디스크 회전**: 모터가 일정 속도로 매체를 회전시킴
2. **레이저 조사**: 기록 또는 읽기 위치에 빛을 조사함
3. **반사 신호 판독**: pit와 land 차이를 센서가 감지함
4. **ECC 복원 및 출력**: 오류 정정 후 상위 시스템에 데이터를 전달함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 임의 접근과 기록 속도가 느려 빈번한 갱신 업무에 쓰면 전체 처리 지연이 커질 수 있음
   - 해결방안: 광 저장 장치는 장기 보관과 콜드 백업 계층으로 제한하고 restore time과 access latency로 적합성을 검증함
2. 문제: 열과 습기와 흠집에 의해 기록층이 열화되면 보존 데이터의 복구 실패 위험이 커질 수 있음
   - 해결방안: 보존 등급 매체와 항온항습 보관을 적용하고 bit error rate와 media health check로 안정성을 검증함
3. 문제: 드라이브 시장 축소로 장기적으로 판독 장비 호환성이 떨어질 수 있음
   - 해결방안: 표준 포맷을 유지하고 주기적 매체 마이그레이션을 수행하며 readability test와 migration success rate로 검증함

## Ⅶ. 적용 사례

- 공공 기록 보관에서는 위변조 방지가 필요한 문서를 WORM 매체에 저장하고 확인 지표는 data integrity와 audit pass rate임
- 재난 복구 체계에서는 네트워크와 분리된 오프라인 백업을 운영하고 확인 지표는 restore time과 backup verification success rate임
- 의료 영상 아카이브에서는 장기 보존용 계층으로 활용하고 확인 지표는 media error rate와 retention compliance임

## Ⅷ. 결론

광 저장 장치는 속도 경쟁용 저장소가 아니라 오프라인 보존성과 불변성이 중요한 장기 아카이브 계층으로 선택해야 가치가 살아남.
