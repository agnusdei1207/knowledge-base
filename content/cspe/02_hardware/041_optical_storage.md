# 광 저장 장치 (Optical Storage)

## 미리 알고가기

- 광 저장 장치: 레이저 빛으로 디스크 표면의 물리·광학적 상태를 읽거나 기록하는 저장장치임
- pit/land: 광디스크에서 반사율 차이로 비트를 표현하는 미세 구조임
- WORM: 한 번 기록 여러 번 읽기(Write Once Read Many, WORM)는 기록 후 변경을 제한하고 반복 읽기를 허용하는 특성임
- ECC: 오류 정정 코드(Error Correction Code, ECC)는 스크래치와 먼지로 생긴 읽기 오류를 보정하는 기술임

## Ⅰ. 개요

- **정의/개념**: 광 저장 장치는 CD, DVD, Blu-ray처럼 회전하는 매체에 레이저를 조사해 반사율, 상변화, 염료 변화를 감지하거나 기록함으로써 데이터를 비휘발성·이동식 형태로 저장하는 장치임.
- **배경/필요성**: HDD와 SSD가 온라인 고성능 저장을 담당하더라도, 배포용 매체, 장기 보관, 변조 방지, 물리적 분리 보관에는 전원과 네트워크에서 분리 가능한 저장 매체가 필요함.

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 저장 매체 특성을 접근 방식과 보존성 관점에서 비교하는 역량 확인 | 레이저, pit/land, CD/DVD/Blu-ray, WORM, ECC | 단순 구형 장치로만 설명, 기록 방식 누락, 보존 리스크 누락 |

> 요약: 광 저장 장치는 성능보다 불변성, 이동성, 오프라인 보관성이 중요한 저장 요구에 적합한 매체임.

## Ⅱ. 특징 및 비교

| 판단 기준 | HDD/SSD | 광 저장 장치 |
|:---|:---|:---|
| 접근 방식 | 자기·전자 기반 임의 접근 중심 | 레이저 기반 회전 매체 접근 |
| 성능 특성 | 낮은 지연과 높은 처리량 확보 가능 | seek와 회전 지연으로 임의 접근 성능 낮음 |
| 보존 특성 | 상시 연결 운영, 전원·컨트롤러 의존 | 오프라인 보관, WORM, 물리적 분리에 유리 |
| 운영 리스크 | 마모, 컨트롤러 장애, 전원 장애 | 스크래치, 기록층 열화, 드라이브 호환성 |

CD, DVD, Blu-ray는 레이저 파장, 트랙 피치, 기록층 구조 차이로 용량과 기록 밀도가 달라짐. 읽기 전용, 기록 가능, 재기록 가능 매체는 기록층 재료와 변경 가능성에 따라 구분되며, 장기 보관에서는 매체 품질뿐 아니라 읽을 장비와 포맷 유지까지 함께 판단해야 함.

## Ⅲ. 구성요소/구조

```text
+----------+      +------------+      +-------------+
| Host I/O | ---> | Drive Ctrl | ---> | Optical Disc|
+----------+      +------------+      +-------------+
                         |
                         v
                  +-------------+
                  | Laser/Lens |
                  +-------------+
                         |
                         v
                  +-------------+
                  | ECC Decoder|
                  +-------------+
```

| 구성요소 | 설명 | 핵심 포인트 |
|:---|:---|:---|
| 광디스크 매체 | 반사층, 기록층, 보호층으로 데이터를 물리적으로 저장함 | 보존성, 기록 방식 |
| 레이저·렌즈 | 디스크 표면에 빛을 집중하고 반사 신호를 수집함 | 파장, 초점, 트랙 추적 |
| 스핀들 모터 | 디스크를 회전시켜 트랙과 섹터를 접근하게 함 | 회전 지연, 순차 접근 |
| 드라이브 제어기 | 위치 제어, 신호 해석, 호스트 인터페이스 처리를 수행함 | 장치 호환성 |
| ECC/디코더 | 반사 신호를 비트로 해석하고 읽기 오류를 보정함 | 무결성 보정 |

### 원리/흐름도

```text
+---------+      +---------+      +------------+      +---------+
| Seek    | ---> | Focus   | ---> | Read/Write | ---> | ECC     |
+---------+      +---------+      +------------+      +---------+
```

드라이브는 요청 위치로 픽업을 이동하고 레이저 초점을 맞춘 뒤 반사율 또는 기록층 상태 변화를 읽음. 이후 ECC로 오류를 보정해 호스트에 전달하므로, 광 저장의 신뢰성은 광학 정밀도와 오류 보정 능력에 함께 의존함.

## Ⅳ. 문제점 및 개선방안

1. **낮은 임의 접근 성능**: 회전 지연과 광학 픽업 이동 때문에 SSD 대비 임의 접근 지연이 큼.
   - **개선방안**: 순차 읽기 중심 배포·보관 용도로 제한하고, 잦은 갱신과 임의 접근 서비스에는 SSD나 객체 스토리지를 사용함. (확인: 접근 지연 요구 충족 여부)
2. **매체 손상과 기록층 열화**: 스크래치, 먼지, 온습도, 빛 노출이 읽기 오류와 데이터 손실을 유발함.
   - **개선방안**: 보관 온습도와 빛 노출을 통제하고 정기 읽기 검증·체크섬 검증을 수행함. (확인: 체크섬 불일치 건수)
3. **장기 접근성 저하**: 보관 기간이 길어질수록 드라이브, 인터페이스, 파일 포맷을 확보하지 못할 수 있음.
   - **개선방안**: 표준 포맷, 예비 드라이브, 주기적 매체 이관 계획을 함께 운영함. (확인: 복구 리허설 성공률)

## Ⅴ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| 규제 문서 장기 보존 | WORM 매체에 원본을 보관하고 정기 검증과 이관 주기를 운영함 | 체크섬 불일치, 복구 리허설 성공률 |
| 소프트웨어·교육 콘텐츠 배포 | 순차 읽기 중심 대량 배포에는 광디스크를 사용하고 업데이트 데이터는 온라인 저장소로 분리함 | 배포 단가, 매체 불량률, 호환 드라이브 확보율 |
| 오프라인 백업 보조 계층 | 랜섬웨어 격리를 위해 온라인 백업과 분리된 물리 사본을 유지함 | 읽기 오류율, 보관 환경 이탈 건수 |

## Ⅵ. 결론

광 저장 장치는 고성능 온라인 저장장치가 아니라 불변성, 이동성, 물리적 분리 요구를 해결하는 보조 저장 매체임. 적용 시에는 레이저 기반 기록·판독 원리보다 보존 환경, 오류 검증, 장기 접근성 계획이 실무 품질을 좌우함. 따라서 기술 선택은 용량·성능보다 보존 기간, 변조 방지, 복구 가능성을 중심으로 판단해야 함.
