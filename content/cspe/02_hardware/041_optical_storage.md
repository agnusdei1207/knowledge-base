## 미리 알고가기

- 광 저장 장치: 레이저 빛으로 디스크 표면의 물리·광학적 상태를 읽거나 기록하는 저장장치임
- pit/land: 광디스크에서 반사율 차이로 데이터를 표현하는 미세 구조임
- WORM: 한 번 기록 후 여러 번 읽을 수 있는 저장 특성임
- ECC: 스크래치와 먼지로 생긴 읽기 오류를 보정하는 오류 정정 코드임

## Ⅰ. 개요

- **정의**: 광 저장 장치는 CD, DVD, Blu-ray처럼 회전하는 광디스크에 레이저를 조사해 반사율, 상변화, 염료 변화 등을 감지하거나 기록함으로써 데이터를 비휘발성·이동식 매체에 저장하는 장치임
- **배경/필요성**: 자기 디스크와 플래시가 고성능 저장장치를 담당하더라도, 배포용 매체, 장기 보관, 변조 방지, 오프라인 보관에는 물리적으로 분리 가능한 저장 매체가 필요함. 광 저장 장치는 저비용 배포와 WORM 특성을 제공함
- **비유**: 종이에 잉크로 표시하는 대신 반짝이는 원판 위에 미세한 홈과 반사 차이를 새겨 빛으로 읽는 장부와 같음

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 저장 매체 특성을 접근 방식과 보존성 관점에서 비교하는 역량 확인 | 레이저, pit/land, CD/DVD/Blu-ray, WORM, ECC | 단순 구형 장치로만 설명, 기록 방식 누락, 보존 리스크 누락 |

> 요약: 광 저장 장치는 레이저와 광학적 반사 차이로 데이터를 읽고 쓰는 이동식 비휘발성 저장 매체임.

## Ⅱ. 특징/비교

| 판단 기준 | HDD/SSD | 광 저장 장치 |
|:---|:---|:---|
| 접근 방식 | 전자·자기 기반 고속 임의 접근 | 레이저 기반 회전 매체 접근 |
| 성능 | 낮은 지연과 높은 처리량 가능 | seek와 회전 지연으로 상대적으로 느림 |
| 보존·배포 | 상시 연결 저장과 온라인 운영 중심 | 오프라인 보관, 매체 배포, WORM에 유리 |
| 운영 리스크 | 전원·컨트롤러·wear 관리 | 스크래치, 염료 열화, 드라이브 호환성 |

> 요약: 광 저장 장치는 성능보다 오프라인 보관, 배포, 쓰기 불변성 요구에 맞는 저장 매체임.

- CD, DVD, Blu-ray는 레이저 파장과 트랙 피치, 기록층 구조 차이로 용량이 달라짐
- 읽기 전용, 기록 가능, 재기록 가능 매체는 기록 재료와 용도에 따라 구분됨
- 장기 보관은 매체 품질, 온도·습도, 빛 노출, 드라이브 가용성까지 함께 고려해야 함

## Ⅲ. 구성요소

```text
+-----------+      +-----------+      +-----------+
| Host I/O  | ---> | Drive Ctrl| ---> | Optical   |
|           |      |           |      | Disc      |
+-----------+      +-----------+      +-----------+
                        |
                        v
                  +-----------+
                  | Laser/Lens|
                  +-----------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 광디스크 매체 | 반사층, 기록층, 보호층으로 데이터를 물리적으로 저장함 | 빛으로 읽는 원형 장부 |
| 레이저·렌즈 | 디스크 표면에 빛을 집중하고 반사 신호를 수집함 | 작은 손전등과 돋보기 |
| 스핀들 모터 | 디스크를 회전시켜 트랙 위치를 순차적으로 접근하게 함 | 회전 작업대 |
| ECC·디코더 | 반사 신호를 비트로 해석하고 오류를 보정함 | 흐린 글씨를 복원하는 검수자 |

> 요약: 광 저장 장치는 회전 매체, 레이저 광학계, 제어 회로, 오류 보정 기능이 결합되어 동작함.

## Ⅳ. 절차

```text
+-----------+      +-----------+      +-----------+      +-----------+
| 위치탐색  | ---> | 초점/추적 | ---> | 신호판독  | ---> | 오류보정 |
+-----------+      +-----------+      +-----------+      +-----------+
```

1. **위치 탐색**: 드라이브가 요청한 트랙과 섹터 위치로 광학 픽업을 이동함
2. **초점과 추적 제어**: 회전 중인 디스크 표면에 레이저 초점을 맞추고 트랙을 따라감
3. **반사 신호 판독·기록**: pit/land 또는 기록층 상태 변화를 감지하거나 레이저로 기록함
4. **오류 보정과 전송**: ECC로 오류를 보정하고 인터페이스를 통해 호스트에 데이터를 전달함

> 요약: 광 저장 장치는 트랙 위치를 찾고 레이저 반사 신호를 해석한 뒤 오류 보정으로 데이터를 복원함.

## Ⅴ. 문제점

- **P1 낮은 접근 성능**: 회전 지연과 광학 픽업 이동 때문에 SSD 대비 임의 접근 지연이 큼
- **P2 매체 손상과 열화**: 스크래치, 먼지, 기록층 열화, 보관 환경이 읽기 오류를 증가시킴
- **P3 드라이브 가용성 감소**: 장기 보관 후 읽을 장비와 인터페이스를 확보하지 못하면 데이터 접근성이 낮아짐

> 요약: 광 저장 장치의 리스크는 속도보다 매체 보존성과 미래 접근성에서 크게 나타남.

## Ⅵ. 개선방안

1. **단기**: 매체 상태, 읽기 오류율, 백업 사본, 드라이브 동작 여부를 점검함
2. **중기**: 중요 데이터는 복수 매체, 다른 저장 계층, 체크섬 검증과 함께 보관함
3. **장기**: 보존 주기별 매체 이관, 포맷 표준화, 드라이브 확보 정책을 수립함

- **P1 대응**: 대량 순차 배포·보관 용도로 제한하고 임의 접근 서비스에는 SSD를 사용함 (확인: 접근 지연 요구 충족)
- **P2 대응**: 온도·습도·빛 노출을 관리하고 정기 읽기 검증을 수행함 (확인: checksum mismatch)
- **P3 대응**: 표준 포맷과 이관 계획, 예비 드라이브를 유지함 (확인: 복구 리허설 성공)

> 요약: 광 저장 장치는 장기 보관 매체로 쓸 때 매체 관리와 이관 계획이 함께 있어야 함.

## Ⅶ. 전망

- **발전 방향**: 범용 PC 저장장치로서 비중은 줄었지만, 오프라인 보관과 변조 방지 요구에서는 광 매체의 특성이 여전히 의미가 있음
- **기술사적 판단**: 장기 아카이브는 광 저장 장치 단독보다 테이프, 객체 스토리지, 클라우드 백업과 조합해 설계되는 방향이 현실적임
- **기술사 제언**: 기술사는 광 저장 장치를 구형 장치로 치부하지 말고 보존성, 접근성, 비용, 무결성 요구에 따른 선택지로 설명해야 함
