## 미리 알고가기

- ALU는 연산을, CU는 제어를, 레지스터는 초고속 저장을 담당함
- 버스는 CPU 내부와 외부 구성요소를 연결하는 통로임
- CPU 성능은 유닛 개수보다 데이터 공급 지연과 제어 흐름에 좌우됨

## Ⅰ. 개요

- **정의/개념**: CPU는 명령어를 읽고 해독하고 연산한 뒤 결과를 기록하는 중앙 처리 장치이며, 내부적으로 ALU와 CU와 레지스터와 버스로 구성되어 하나의 명령어 사이클을 수행함
- **배경/필요성**: CPU 병목을 찾으려면 연산부, 제어부, 저장부, 전달부 중 어느 경로에서 대기가 생기는지 분리해야 함

## Ⅱ. 특징

- ALU는 산술·논리 연산 처리량을 결정함
- CU는 명령 해독과 분기 제어로 실행 흐름을 지배함
- 레지스터는 메모리보다 훨씬 빠른 임시 저장소로 동작함
- 버스 대역폭과 제어 충돌은 CPU 전체 처리량을 제한함

## Ⅲ. 종류 및 비교

| 판단 기준 | ALU | CU | Register | Bus |
|:---|:---|:---|:---|:---|
| 주요 역할 | 연산 수행 | 제어 신호 생성 | 초고속 임시 저장 | 데이터 전달 |
| 병목 형태 | 연산 유닛 부족 | 분기·스케줄링 지연 | 저장 공간 부족 | 대역폭 부족 |
| 조정 지점 | 병렬 연산기 | 분기 예측·OoO | 레지스터 파일 | 폭·포트 확장 |
| 대표 지표 | IPC 기여도 | branch accuracy | register pressure | bus utilization |

> 요약: CPU 병목은 연산, 제어, 저장, 전달 경로 중 어느 지점에서 대기가 생기는지로 구분함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| ALU | 정수와 논리 연산을 수행하며 실행 유닛 수와 지연 시간이 계산 성능을 좌우함 |
| CU | 명령어를 해독하고 각 유닛에 제어 신호를 보내며 분기와 파이프라인 흐름을 제어함 |
| Register File | 피연산자와 중간 결과를 저장해 메모리 접근 횟수와 스케줄링 대기를 줄임 |
| Internal Bus | CPU 내부 유닛 간 데이터를 이동시키며 포트 수와 폭이 병렬성을 제한함 |

```text
+---------+     +---------------+     +-------------+
| CU      | --> | Register File | --> | ALU         |
+---------+     +---------------+     +-------------+
     \                |
      \               v
       --> +----------------------+
           | Internal Bus         |
           +----------------------+
```

> 요약: ALU, CU, 레지스터 파일, 내부 버스는 명령어 실행 사이클을 나누어 담당함.

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 명령어 인출     | --> | 해독 및 제어     | --> | 연산 수행      | --> | 결과 기록      |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **명령어 인출**: 메모리에서 명령어를 읽음
2. **해독 및 제어**: CU가 명령 종류와 자원 사용을 결정함
3. **연산 수행**: ALU가 필요한 산술·논리 연산을 처리함
4. **결과 기록**: 결과를 레지스터나 메모리에 반영함

> 요약: CPU는 명령어 인출, 해독, 연산, 기록을 반복하며 각 단계의 대기가 전체 처리량을 제한함.

## Ⅵ. 실무 적용 및 유의점

1. 메모리 접근 속도가 ALU 처리 속도를 따라가지 못하면 캐시 계층과 prefetch 정책을 보강하고 cache miss rate와 memory stall cycle로 검증함
2. 분기·해독·내부 전달 경로가 실행 유닛을 충분히 채우지 못하면 branch prediction, out-of-order execution, datapath 폭과 port 설계를 조정하고 branch accuracy, issue utilization, bus utilization으로 확인함

## Ⅶ. 결론

- CPU 성능은 단일 클록 수치보다 ALU, CU, 레지스터, 버스가 얼마나 균형 있게 협력하는지에서 결정됨

## 작성 근거(검토용)

- CPU를 연산, 제어, 저장, 전달 경로로 나눠 병목 위치를 답안에서 바로 표시하도록 구성함
- 모호한 표현은 분기 제어, 실행 흐름, 대기 지표로 구체화함
- 유의점은 각 구성요소의 병목을 어떤 지표로 확인하는지 연결되도록 수정함
