## Ⅰ. 개요
- **정의**: 전자 대신 광자(photon)를 정보 캐리어로 사용하여 연산을 수행하는 컴퓨팅 방식임
- **배경/필요성**: 전자 기반 회로의 발열·대역폭 한계를 극복할 대안 연산 매체가 필요함
- **비유**: 전선(전자) 대신 광섬유(광자)로 데이터를 보내듯, 연산 자체를 빛으로 수행하는 것임

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 차세대 컴퓨팅 패러다임 이해 | 광 간섭·광 도파관 기반 행렬 연산 원리 | 전광 컴퓨팅과 광-전 하이브리드 구분 필요 |

> 요약: 광자의 병렬성·저발열 특성을 활용하여 연산을 수행하는 차세대 컴퓨팅 방식임

## Ⅱ. 구성요소
```text
Light Source --> Modulator --> Photonic Circuit --> Photodetector --> Output
                                  |
                          (Waveguide + MZI)
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 광원(Laser) | 코히어런트 광 신호를 생성하는 입력 소스 | 수도꼭지에서 물을 공급하는 역할 |
| 광 변조기(Modulator) | 전기 신호를 광 신호로 변환하여 데이터를 인코딩함 | 수도 밸브로 유량을 조절하는 역할 |
| 광 도파관(Waveguide) | 칩 내부에서 광 신호를 전달하는 경로 | 회로 기판의 배선에 해당함 |
| MZI(Mach-Zehnder Interferometer) | 광 간섭을 이용하여 행렬 곱셈 연산을 수행함 | 두 물줄기의 합류로 크기를 조절하는 것 |
| 광 검출기(Photodetector) | 광 신호를 전기 신호로 변환하여 결과를 출력함 | 최종 수량을 측정하는 계량기 |

> 요약: 광원-변조기-광회로-검출기 파이프라인으로 광 영역 연산을 수행함

## Ⅲ. 절차
```text
전기 입력 --> 광 변환 --> 광 연산 --> 전기 변환/출력
```
- 1단계: 입력 데이터를 변조기를 통해 광 신호 진폭·위상으로 인코딩함
- 2단계: MZI 배열에서 광 간섭 패턴을 이용하여 행렬-벡터 곱셈을 수행함
- 3단계: 비선형 활성화는 광-전 변환 후 전자 회로에서 처리함
- 4단계: 광 검출기가 출력 광 신호를 전류로 변환하여 디지털 결과를 생성함

> 요약: 광 인코딩-간섭 연산-비선형 처리-검출의 4단계로 연산을 수행함

## Ⅳ. 문제점
- 비선형 연산 부재: 광자 자체로 비선형 활성화 함수 구현이 어려워 전기 변환이 필수임
- 제조 공차 민감성: 도파관·MZI의 nm 단위 공차가 연산 정확도에 직접 영향을 줌
- 집적도 한계: 광 소자 크기가 파장(수백 nm) 이상이어서 전자 소자 대비 집적 밀도가 낮음

> 요약: 비선형 연산·제조 공차·집적도에서 전자 회로 대비 성숙도가 부족함

## Ⅴ. 개선방안
1. 단기: 광-전 하이브리드 아키텍처로 비선형 계층을 전자 회로에 위임함
2. 중기: 공정 보정 알고리즘과 on-chip 캘리브레이션으로 공차 영향을 최소화함
3. 장기: 광자 결정·플라즈모닉 기술로 소자 크기를 축소하여 집적도를 향상함

> 요약: 하이브리드 설계, 공차 보정, 소자 미세화 순으로 실용화를 추진함

## Ⅵ. 전망

- 기술사적 판단: 전력 효율이 중요한 데이터센터 추론 워크로드에 적합한 기술임
- 기술사 제언: 전자-광자 인터페이스 표준화와 EDA 도구 생태계 확보가 필요함
