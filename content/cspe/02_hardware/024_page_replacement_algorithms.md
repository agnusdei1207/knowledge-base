## Ⅰ. 개요
- 정의: Page Fault 발생 시 새로운 페이지를 적재하기 위해 기존 페이지를 선택해 교체하는 기법
- 배경: 물리 메모리(Frame) 부족 시 효율적인 자원 회수 및 성능 유지 필요성
- 출제 의도
| 구분 | 내용 |
| --- | --- |
| 핵심 | FIFO, LRU, LFU, Belady의 역설, 지역성 활용 |

## Ⅱ. 구성요소
```
[ Page Fault ] -> [ Victim Selection ] -> [ Swapping ] -> [ Execution ]
```
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| Victim Page | 교체 대상으로 선정되어 메모리에서 쫓겨나는 페이지 | 퇴출 대상 |
| 참조 비트 | 페이지가 최근에 참조되었는지 나타내는 상태 값 | 방문 도장 |
| 변동 비트(Dirty) | 페이지 내용이 수정되었는지 여부를 나타내는 비트 | 수정 표시 |
> 요약: 교체 대상(Victim)을 현명하게 선택하여 Page Fault 발생 빈도를 최소화함

## Ⅲ. 절차
1. 부재 발생: CPU가 요청한 페이지가 현재 물리 메모리에 없음
2. 교체 결정: 교체 알고리즘에 따라 메모리 내 Victim Page 선정
3. 스왑 아웃: 수정된 경우 디스크에 기록(Write-back) 후 프레임 비움
4. 스왑 인: 새로운 페이지를 비워진 프레임에 적재하고 테이블 갱신
> 요약: 하드웨어 상태 비트와 소프트웨어 알고리즘의 조화로 교체 효율성 극대화함

## Ⅳ. 문제점
- FIFO 방식 사용 시 메모리 프레임이 늘어나도 부재율이 증가하는 Belady의 역설 발생

## Ⅴ. 개선방안
- 최근 참조 기록과 빈도를 동시에 고려하는 LRU 또는 LFU 알고리즘 적용함

## Ⅵ. 전망
- 비휘발성 메모리(NVM)의 등장으로 쓰기 횟수까지 고려한 NVM 특화 교체 알고리즘이 중요해짐
- AI 워크로드의 데이터 참조 패턴을 학습하여 미리 예측 교체하는 인텔리전트 기법이 로드맵임
