## Ⅰ. 개요
- **정의**: 대규모 컴퓨팅 자원을 수용·운영하기 위한 서버의 물리적·논리적 배치 구조임
- **배경/필요성**: 클라우드·AI 워크로드 급증으로 전력·냉각·공간 효율을 극대화하는 서버 배치 설계가 요구됨
- **비유**: 대형 물류 창고에서 선반·통로·운반 동선을 최적 설계하는 것과 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 서버 폼팩터별 특성과 데이터센터 설계 고려사항 | 랙/블레이드/하이퍼컨버지드 구분 + 전력·냉각·네트워크 | TIA-942 Tier(068 참조)와 연계하여 가용성 관점 포함 필요 |

> 요약: 전력·냉각·공간 효율을 고려한 서버의 물리·논리 배치 아키텍처임

## Ⅱ. 구성요소
```text
+---Data Center Facility---+
|  +------+  +------+      |
|  | Rack |  | Rack |  ... |
|  | +--+ |  | +--+ |      |
|  | |SV| |  | |SV| |      |     SV = Server Node
|  | +--+ |  | +--+ |      |
|  +------+  +------+      |
|       |         |         |
|  +----+---------+----+    |
|  |  Network Fabric   |    |
|  +-------------------+    |
|  | Power | Cooling   |    |
+---------------------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| Server Node | CPU·메모리·스토리지를 탑재한 연산 단위로, 랙·블레이드 등 폼팩터로 구분됨 (066 참조) | 창고 선반 위 개별 박스 |
| Rack | 표준 19인치 프레임에 서버·스위치를 수직 적재하는 물리 구조물임 | 다단 선반 |
| Network Fabric | 서버 간 통신을 수행하는 Spine-Leaf·Fat-Tree 등의 네트워크 토폴로지임 | 창고 내 운반 통로·엘리베이터 |
| Power/Cooling | 전원 공급(067 참조)과 냉각(069 참조)을 담당하는 인프라 설비임 | 창고의 전기·공조 시스템 |

> 요약: 서버 노드, 랙, 네트워크 패브릭, 전원/냉각 인프라로 데이터센터가 구성됨

## Ⅲ. 절차
```text
Capacity Planning --> Physical Design --> Deployment --> Operation
       |                    |                 |              |
       v                    v                 v              v
  워크로드 산정         랙 배치/전력/       서버 설치/       모니터링/
  + 성장 예측          냉각/네트워크 설계   케이블링/테스트   유지보수
```
- 1단계: **Capacity Planning** — 워크로드 요구량(CPU·메모리·스토리지·네트워크)을 산정하고 3~5년 성장을 예측함
- 2단계: **Physical Design** — 랙 배치, 전력 용량, 냉각 방식, 네트워크 토폴로지를 설계함
- 3단계: **Deployment** — 서버 설치, 케이블링, OS/펌웨어 프로비저닝, 통합 테스트를 수행함
- 4단계: **Operation** — DCIM 기반 모니터링, 장애 대응, 용량 증설, 에너지 효율(PUE) 관리를 수행함 (070 참조)

> 요약: 용량 계획 → 물리 설계 → 구축 → 운영의 4단계 라이프사이클로 관리됨

## Ⅳ. 문제점
- **전력 밀도 증가**: GPU·AI 가속기 탑재로 랙당 전력 소비가 30kW 이상으로 증가하여 기존 전력 인프라 초과 위험임
- **냉각 한계**: 공랭 방식으로는 고밀도 랙의 열 배출이 불충분하여 CPU 스로틀링이 발생함
- **네트워크 병목**: 동서(East-West) 트래픽 급증으로 기존 3계층 네트워크의 오버서브스크립션 비율이 과다해짐

> 요약: 전력 밀도, 냉각 한계, 네트워크 병목이 현대 데이터센터의 주요 과제임

## Ⅴ. 개선방안
1. 단기: 랙 단위 전력 모니터링(iPDU)을 도입하여 전력 사용 가시성 확보 및 부하 분산
2. 중기: 액침·직접 액냉(DLC) 방식으로 전환하여 고밀도 랙의 열 배출 용량 확대 (069 참조)
3. 장기: Spine-Leaf + 400/800G 링크 기반 1:1 오버서브스크립션 네트워크 구축으로 동서 트래픽 병목 해소

> 요약: 전력 모니터링, 액냉 전환, 고속 네트워크 아키텍처로 단계적 해소함

## Ⅵ. 전망
- 발전 방향: 모듈러 데이터센터·엣지 데이터센터가 확산되어 분산·소형화 추세가 가속됨
- 기술사적 판단: AI 학습·추론 전용 클러스터 수요로 GPU 서버 특화 아키텍처가 표준 설계로 자리잡을 전망임
- 기술사 제언: PUE(070 참조)·TIA-942 Tier(068 참조) 기준을 설계 초기 단계부터 반영할 필요
