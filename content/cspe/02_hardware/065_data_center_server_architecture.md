## 미리 알고가기

- 데이터센터 서버는 CPU, 메모리, 스토리지, 네트워크, 전원 경로를 서비스 운영 기준으로 묶은 시스템임
- 핵심 목표는 확장성, 가용성, 관리성, 전력 효율임
- 단일 서버 성능보다 랙과 클러스터 단위 운영성이 더 중요함

## Ⅰ. 개요

- **정의/개념**: 데이터센터 서버 아키텍처는 대규모 서비스와 가상화, AI, 스토리지 워크로드를 안정적으로 처리하기 위해 연산 자원과 메모리와 스토리지와 네트워크와 전원 이중화를 조합한 서버 시스템 구조임
- **배경/필요성**: 데이터센터는 한 서버의 고장이나 교체가 곧 서비스 중단으로 이어질 수 있으므로, 단일 부품 성능만이 아니라 원격 관리, 교체 용이성, 장애 격리, 에너지 효율을 함께 설계해야 함

## Ⅱ. 특징

- CPU, 메모리, 스토리지, NIC 구성을 워크로드 특성에 맞춰 균형 있게 배치하는 것이 기본임
- PSU, 팬, 스토리지 경로 이중화와 BMC 원격 관리 기능이 일반적임
- 범용 가상화 서버와 AI 가속 서버는 전력 밀도와 인터커넥트 요구가 크게 다름
- 서버 단위 설계만 맞아도 랙 전력과 냉각이 받쳐주지 않으면 실제 운영 성능이 무너질 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | 범용 데이터센터 서버 | AI·HPC 서버 |
|:---|:---|:---|
| 연산 중심 | CPU와 대용량 메모리 중심 구성이 많음 | GPU, NPU, 고속 가속기 중심 구성이 많음 |
| 메모리와 스토리지 | DRAM과 NVMe를 균형 있게 배치함 | HBM, 고속 로컬 스토리지, 대용량 전송 경로가 더 중요함 |
| 네트워크 요구 | 일반 이더넷과 관리망 중심 구성이 많음 | RDMA, InfiniBand, NVLink 같은 고속 경로 요구가 큼 |
| 운영 제약 | 범용성, VM 밀도, 유지보수 효율이 중요함 | 전력 밀도, 냉각, 랙 배치와 인터커넥트 병목이 더 중요함 |

> 요약: 범용 서버는 균형이 중요하고, AI·HPC 서버는 가속기와 전력·냉각 조건이 아키텍처를 좌우함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 연산 노드 | CPU와 가속기가 실제 워크로드를 처리하며 서버의 역할을 결정하는 중심 자원임 |
| 메모리와 스토리지 경로 | DRAM, NVMe, RAID 경로가 지연 시간과 장애 대응성을 결정함 |
| 네트워크 인터페이스 | 서비스 트래픽과 클러스터 통신을 처리하며 병목이 나면 전체 랙 효율이 떨어짐 |
| 전원과 관리 계층 | 이중 PSU, BMC, 센서가 무중단 운영과 원격 복구를 가능하게 함 |

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 워크로드 요구 정의 | --> | 자원 구성      | --> | 이중화/관리 설계 | --> | 랙 운영 최적화  |
+-------------+     +-------------+     +-------------+     +-------------+
```

> 요약: 워크로드 요구를 먼저 정하고 자원과 이중화와 랙 운영까지 함께 맞춰야 데이터센터 서버가 제대로 동작함.

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 요구량 산정    | --> | CPU/메모리/NIC 배치 | --> | 전원·관리 이중화 | --> | 랙 단위 검증    |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **요구량 산정**: CPU, 메모리, 스토리지, 네트워크 요구량을 계산함
2. **CPU·메모리·NIC 배치**: 워크로드 특성에 맞게 자원을 조합함
3. **전원·관리 이중화**: PSU, 팬, BMC와 관리 경로를 이중화함
4. **랙 단위 검증**: 전력, 냉각, 배선, 장애 도메인을 함께 점검함

## Ⅵ. 실무 적용 및 유의점

1. 가상화 클러스터 서버는 CPU와 메모리 비율만 맞춰서는 부족하고 NIC와 스토리지 경로가 병목이 되기 쉬우므로 실제 부하 측정을 바탕으로 자원을 배치하고 VM 집적도와 호스트 사용률과 NIC 처리량으로 확인함
2. GPU 추론·학습 서버는 가속기 수를 늘릴수록 랙 전력과 냉각 한계를 먼저 만나는 경우가 많으므로 전력 예산과 냉각 용량을 함께 설계하고 랙 전력 밀도와 흡입 온도와 쓰로틀링 발생률로 확인함

## Ⅶ. 결론

데이터센터 서버 아키텍처의 핵심은 단일 부품 최고 성능이 아니라 워크로드와 랙 운영 조건 안에서 자원을 얼마나 균형 있게 조합하느냐에 있음.
