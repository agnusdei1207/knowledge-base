## Ⅰ. 개요
- **정의**: 데이터 센터 내 서버·네트워크·스토리지를 물리적·논리적으로 배치하는 인프라 설계 체계임
- **배경/필요성**: 클라우드 워크로드 증가로 전력·공간 효율과 가용성을 동시에 확보하는 구조 설계가 필수적임
- **비유**: 대형 창고에서 선반 종류·통로 배치·물류 동선을 설계하는 것과 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 서버 폼팩터별 특성 구분 | 랙/블레이드/마이크로 서버 차이점 | Tier 등급은 068 참조로 위임 |

> 요약: 데이터 센터 서버 아키텍처는 폼팩터·이중화·클러스터링을 결합해 가용성과 효율을 달성하는 인프라 설계임

## Ⅱ. 구성요소
```text
  +--- Data Center Server Architecture ---+
  |                                        |
  +-----+----------+-----------+----------+
  |     |          |           |          |
  v     v          v           v          v
 랙서버  블레이드서버  마이크로서버  이중화구조  클러스터링
  |     |          |           |          |
  v     v          v           v          v
 1U-4U  엔클로저    초소형노드   N+1전원    HA/LB
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 랙 서버 | 1U~4U 단위로 랙에 장착, 독립 전원·NIC 보유 | 개별 책상이 있는 사무실 |
| 블레이드 서버 | 엔클로저에 삽입, 전원·네트워크·냉각 공유 (066 참조) | 공용 주방을 쓰는 기숙사 방 |
| 마이크로 서버 | 저전력 ARM/Atom 기반 초소형 노드, 경량 워크로드용 | 소포 배달용 경차 |
| 이중화 구조 | 전원·NIC·스위치를 N+1 이상으로 다중화해 단일장애점 제거 | 비상 탈출구를 2개 만드는 것 |
| 클러스터링 | 다수 서버를 논리적 그룹으로 묶어 HA·부하분산 수행 | 팀원이 분담 처리하는 프로젝트 |

> 요약: 서버 폼팩터(랙/블레이드/마이크로)와 이중화·클러스터링이 결합해 데이터 센터 인프라를 구성함

## Ⅲ. 절차
```text
  용량산정         폼팩터선정       이중화설계        클러스터구성
  (워크로드분석)   (랙/블레이드)    (전원/NIC)       (HA/LB배치)
   |               |               |               |
   +--산출결과----->+--물리배치----->+--장애허용----->+
  CPU/메모리/IO    랙레이아웃      N+1경로확보     페일오버정책
```
- 1단계: 워크로드별 CPU·메모리·IOPS 요구량을 산정하고 총 용량을 도출함
- 2단계: 집적도·관리성·비용을 기준으로 랙/블레이드/마이크로 폼팩터를 선정함
- 3단계: 전원·NIC·스위치를 N+1 이상 이중화해 단일장애점을 제거함
- 4단계: HA 클러스터·로드밸런서를 구성하고 페일오버 정책을 적용함

> 요약: 용량산정 → 폼팩터선정 → 이중화설계 → 클러스터구성 순서로 데이터 센터 서버를 배치함

## Ⅳ. 문제점
- 전력 밀도 불균형: 고밀도 랙 집중 배치 시 특정 구역 전력·냉각 한계 초과 — PUE 악화(070 참조)
- 단일 폼팩터 종속: 특정 벤더 블레이드 엔클로저에 종속 시 확장·교체 비용 증가
- 클러스터 복잡도: 노드 수 증가에 따라 장애 도메인 분리·페일오버 검증 부담 증가

> 요약: 전력 밀도 편중, 벤더 종속, 클러스터 운영 복잡도가 주요 문제임

## Ⅴ. 개선방안
1. 단기: 랙별 전력 모니터링 도입 및 워크로드 재배치로 밀도 균형 확보
2. 중기: 오픈 컴퓨트(OCP) 규격 채택으로 벤더 종속 탈피 및 호환성 확보
3. 장기: AIOps 기반 자동 장애 감지·페일오버로 클러스터 운영 자동화

> 요약: 전력 균형, 개방형 규격, 자동화 운영 순서로 개선함

## Ⅵ. 전망
- 발전 방향: 액침냉각(069 참조) 대응 고밀도 랙 설계와 GPU 서버 전용 아키텍처 확산
- 기술사적 판단: Tier 등급(068 참조) 요건과 워크로드 특성을 동시에 만족하는 설계 역량이 핵심임
- 기술사 제언: 용량 계획 시 3~5년 증설 여유를 반영하고 개방형 표준 기반 설계를 권고함
