# 📖 【암기용】 개념 완전 이해

## 한눈에
- **개요**: 메모리 계층 구조는 속도·용량·비트당 단가가 다른 저장 매체를 **피라미드 형태로 배치**하여, CPU와 메모리 간 속도 차이(Memory Wall)를 극복하고 **비용 대비 성능을 극대화**하는 컴퓨터 아키텍처 설계 기법임.
- **왜 필요한가**: CPU는 1ns 이내에 연산하지만 DRAM은 60~100ns, SSD는 100µs가 소요됨. 가장 빠른 SRAM으로 전체 메모리를 구성하면 비용이 수천 배 증가하므로, 고가·고속은 소량, 저가·대용량은 대량으로 혼합하여 경제적 최적화를 달성해야 함.
- **핵심 직관**: 사무실 책상 정리. 자주 쓰는 펜은 손 닿는 책상 위(캐시)에, 가끔 보는 서류는 서랍(DRAM)에, 안 쓰는 짐은 창고(디스크)에 두면, 작업 공간은 창고만큼 크면서도 책상만큼 빠르게 일할 수 있음.

## 핵심 용어 정리 (내부에 등장하는 것들)

| 용어/표기 | 의미 | 비유·예 |
|:---|:---|:---|
| 컴퓨터 아키텍처 (상위 키워드) | CPU·메모리·I/O 등의 구조적 설계 원리 | "건물의 설계도" |
| 레지스터 (Register) | CPU 코어 내부의 가장 빠른 저장공간(<1ns) | "뇌 속의 단기 기억" |
| 캐시 (L1/L2/L3) | CPU-DRAM 사이의 SRAM 기반 고속 버퍼(1~15ns) | "책상 위 서류함" |
| 메인 메모리 (DRAM) | 활성 프로세스의 작업 공간(60~100ns) | "책상 서랍" |
| 보조기억장치 (Storage) | 비휘발성 대용량 영구 저장(SSD: 100µs, HDD: 10ms) | "외부 창고" |
| Memory Wall | CPU 연산 속도와 메모리 접근 속도 간의 격차 현상 | "고속도로와 비포장도로의 속도 차" |
| 참조 지역성 (Locality) | 최근 참조(시간적)·인접 데이터(공간적)가 재참조되는 성질 | "방금 본 서류를 또 봄" |

## 깊이 이해
- **배경·문제의식**: CPU 연산 속도는 매년 50%씩 향상되었으나 메모리 접근 속도는 매년 10%에 그쳐, 1980년대 이후 Memory Wall이 시스템 성능의 병목으로 고착됨. CPU가 데이터를 기다리며 유휴(Stall)하는 시간이 전체 실행 시간의 상당 부분을 차지함.
- **작동 원리**: CPU가 데이터를 요청하면 최상위 계층(L1)부터 순차 탐색하여 Hit이면 즉시 반환하고, Miss이면 하위 계층(L2→L3→DRAM→Storage)에서 찾아 상위로 블록 단위(64B)로 복사(인양)함. 참조 지역성 덕에 L1 Hit Rate가 90~95%에 달하므로 체감 접근 시간이 최상위 계층에 근접함.
- **비유**: 물류 센터. 편의점(L1)에 물건이 없으면 지역 창고(DRAM)에 주문하고, 거기도 없으면 공장(SSD)에서 가져와 편의점 매대에 채움.
- **구체 예시**: L1 접근 1ns, DRAM 접근 100ns, L1 Hit Rate 95%일 때 → EAT = 0.95×1 + 0.05×100 = 5.95ns. L1이 없으면 100ns이므로 약 17배 성능 향상.
- **흔한 오해·주의점**: "캐시를 무한정 늘리면 빨라진다"는 틀림. 캐시 용량이 커지면 검색 회로가 복잡해져 접근 지연이 증가하므로, 작고 매우 빠른 L1과 크고 적당히 빠른 L3로 계층을 세분화한 것임.

## 연결 개념
- **028 DRAM vs SRAM**: 계층별 매체의 물리적 차이(셀 구조·리프레시·집적도).
- **022 가상 메모리**: 디스크까지 메모리 계층에 편입시키는 기법.
- **035 CXL / 030 HBM**: 현대 계층 구조에 새로 추가된 메모리 티어.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 메모리 계층 구조는 속도·용량·단가가 반비례하는 저장 매체를 피라미드로 배치하여 Memory Wall을 극복하는 설계 원칙임.
> 2. **가치**: 참조 지역성(Locality)에 의해 최상위 캐시의 90~95% Hit Rate를 달성하여, 체감 접근 속도는 캐시에 맞추고 용량은 스토리지에 맞추는 경제적 최적화를 실현함.
> 3. **판단 포인트**: AI·빅데이터로 계층 간 속도 격차가 재확대되면서, HBM(초광대역)·CXL(메모리 풀링)·SCM(Storage Class Memory)이 새 계층으로 삽입되어 병목을 완화함.

| 체감 성능 향상 핵심 원리 도출 | 시간적·공간적 참조 지역성 | "비싼 메모리를 썼다"로만 서술 |

## Ⅰ. 개요 및 필요성

- 개요: 속도·용량·비트당 단가가 다른 저장 매체를 피라미드 계층으로 배치하여 CPU-메모리 속도 격차(Memory Wall)를 극복하는 아키텍처 설계 원칙임.
- 배경: CPU 연산 속도 발전(매년 50%) 대비 메모리 접근 속도 발전(매년 10%)이 지체되어 Memory Wall이 시스템 한계를 결정함.
- 필요성: 고가·고속의 SRAM과 저가·대용량의 DRAM/NAND를 혼합하여 비용 곡선을 최적화하고 성능을 극대화해야 함.

---

## Ⅱ. 구조 및 구성요소

```text
CPU 연산 <-> 레지스터 <-> L1/L2/L3 Cache(SRAM) <-> Main Memory(DRAM) <-> Storage(SSD/HDD)
(상위: 1ns, KB~MB / 하위: ms, TB)
```

| 계층 | 매체 | 접근 속도 | 용량 |
|:---|:---|:---|:---|
| CPU 내부 | 레지스터 | <1ns | 수 KB |
| 캐시 계층 | SRAM (L1/L2/L3) | 1~15ns | 수십 KB~수십 MB |
| 메인 계층 | DRAM (DDR5) | 60~100ns | 수십~수백 GB |
| 스토리지 계층 | NAND Flash/HDD | 100µs~10ms | 수 TB 이상 |

> 요약: 상위로 갈수록 비트당 단가가 비싸고 접근이 빠르며, 하위로 갈수록 저렴하고 대용량임.

---

## Ⅲ. 동작원리 및 흐름도

```text
CPU 데이터 요청 -> L1 탐색 -> Hit: 즉시 반환(1ns) / Miss -> L2 -> L3 -> DRAM -> Storage
  Miss 시 하위 계층에서 블록(64B)을 찾아 상위로 복사(인양)
  상위 가득 참 -> 교체 알고리즘(LRU 등)으로 하위로 축출
```

- 1단계 [상위 탐색]: CPU가 데이터 요청 시 최상위 계층(L1 캐시)부터 순차 탐색함.
- 2단계 [Hit 처리]: 데이터 존재 시(Cache Hit) 해당 계층의 고속 접근 속도로 즉시 CPU에 반환함.
- 3단계 [Miss 인양]: 데이터 부재 시(Cache Miss) 하위 계층을 순차 탐색하여 블록 단위(64B)로 상위에 복사함.
- 4단계 [교체]: 상위 계층이 가득 찬 경우 LRU/Clock 등 교체 알고리즘으로 사용 빈도가 낮은 데이터를 하위로 축출함.

> 요약: 상하위 계층 간 데이터 이동은 하드웨어 캐시 컨트롤러(캐시)와 OS 가상 메모리 관리자(DRAM↔Storage)에 의해 CPU에 투명하게 처리됨.

---

## Ⅳ. 특징
- 지역성 기반 효율성: 시간적 지역성(for 루프 반복 접근)과 공간적 지역성(배열 순차 접근) 덕에 L1 Hit Rate 90~95% 달성이 가능하여 체감 접근 시간이 최상위 계층에 근접함
- 포함성(Inclusiveness): 하위 계층이 상위 계층의 슈퍼셋으로 동작하여 데이터 정합성을 유지함(일부 Exclusive 캐시 아키텍처 제외)
- 투명성(Transparency): 프로그래머가 데이터의 물리적 위치(캐시/DRAM/디스크)를 인지할 필요 없이 단일 가상 주소로 접근 가능함

## Ⅴ. 심화 비교 및 적용 판단

| 구분 | 기존 아키텍처 | 현대 확장 아키텍처 | 도입 목적 |
|:---|:---|:---|:---|
| 캐시-메모리 사이 | L3→DDR | L3→HBM(초광대역)→DDR | AI/GPU 대규모 병렬 데이터 대역폭 해소 |
| 메모리-스토리지 사이 | DDR→SSD | DDR→CXL 메모리 풀→SSD | 용량 확장 한계 극복·원격 메모리 공유 |
| 스토리지 내부 | NAND SSD→HDD | Optane(SCM)→QLC SSD→HDD | RAM-Storage 간 1000배 속도 격차 브릿지 |

> 요약: AI·빅데이터 워크로드의 폭증으로 기존 4계층 사이에 HBM·CXL·SCM이 새 쿠션 계층으로 삽입되어 병목을 완화함.

**리스크·대응:**
- Cache Miss Penalty: 캐시 미스 시 수십~수백 사이클 지연으로 파이프라인 스톨 발생 → 하드웨어 Prefetcher 강화 + 컴파일러의 Data Alignment/Loop Tiling 최적화 (지표: L1/L2 Cache Miss Rate)
- Memory Wall 재확대: AI 모델 파라미터(수십 GB)가 DRAM 대역폭을 초과 → HBM3/3e 적용으로 대역폭 1TB/s 이상 확보 (지표: Memory Bandwidth Utilization)

**점검 지표:**
- 성능: perf stat의 cache-misses/cache-references 비율, EAT 계산
- 운영: 계층별 용량 활용률(L3 Occupancy, DRAM 사용률, Swap 사용량)

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. AI GPU 대역폭 확보: GDDR 단일 계층 대신 2.5D 패키징 HBM3를 GPU 다이에 적층하여 대규모 모델 파라미터 로딩의 대역폭 병목을 해소함.
2. 클라우드 메모리 풀링: CXL 프로토콜로 DDR 용량 한계를 넘어 랙 단위 메모리를 동적 할당하는 Memory Tiering을 구성하여 서버별 메모리 편차를 해소함.
3. 애플리케이션 지역성 최적화: 2차원 배열 탐색 시 열(Column) 단위 대신 행(Row) 단위로 접근하여 공간적 지역성을 극대화하고 캐시 미스를 1/10 수준으로 절감함.

**결론:**
- 기술사 판단: 메모리 계층 구조는 하드웨어 비용 한계를 극복하는 불변의 설계 원칙이며, 지역성이 무너지면 계층이 무의미해지므로 Data-Oriented Design 등 SW 최적화가 동반되어야 함.
- 향후 방향: 3D V-Cache 적층으로 캐시를 로직 다이 위에 직접 올리고, PIM(Processing-In-Memory)으로 계층 간 데이터 이동 자체를 제거하는 방향으로 진화 중임.
