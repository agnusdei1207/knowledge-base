## 미리 알고가기

- 퍼시스턴트 메모리는 바이트 주소 지정과 영속성을 함께 제공하는 메모리 계층임
- DAX는 page cache를 우회해 영속 메모리에 직접 접근하는 방식임
- flush와 fence는 데이터를 실제 영속 영역까지 반영하고 순서를 보장하는 명령임

## Ⅰ. 개요

- **정의/개념**: 퍼시스턴트 메모리는 CPU가 바이트 단위로 직접 접근하면서 전원 장애 후에도 데이터가 유지되는 메모리와 스토리지 사이의 영속 계층임
- **배경/필요성**: DRAM 기반 인메모리 시스템은 재시작 복구가 느리고 SSD 기반 저장은 I/O 경로 오버헤드가 크므로, 빠른 접근과 빠른 복구를 함께 원하는 업무에는 중간 계층이 필요함

## Ⅱ. 특징

- 블록 I/O 대신 load/store 방식으로 영속 데이터를 다룰 수 있음
- page cache 우회와 in-place 업데이트로 복구 시간을 줄일 수 있음
- 애플리케이션이 flush와 ordering을 직접 고려해야 해 프로그래밍 부담이 큼
- 메모리처럼 보이지만 보안과 폐기 정책은 저장장치 수준으로 다뤄야 함

## Ⅲ. 종류 및 비교

| 판단 기준 | DRAM | SSD | Persistent Memory |
|:---|:---|:---|:---|
| 주소 지정 | 바이트 단위로 접근하지만 영속성은 없음 | 블록 단위 I/O로 접근함 | 바이트 단위 접근과 영속성을 함께 제공함 |
| 접근 경로 | CPU load/store가 기본임 | syscall과 block I/O 경로를 거침 | load/store 또는 DAX 경로로 접근함 |
| 복구 특성 | 재시작 시 저장장치에서 데이터를 다시 적재 | 데이터는 유지되며 블록 I/O 경로로 복구 | 데이터가 유지된 메모리 주소 공간을 다시 매핑해 복구 |
| 설계 부담 | 영속성 고민이 적음 | I/O 최적화가 핵심임 | crash consistency와 flush 규칙 설계가 핵심임 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 애플리케이션 | 영속 자료구조를 직접 다루므로 성능 이득과 일관성 책임을 함께 가짐 |
| PM 라이브러리 | 트랜잭션과 allocator와 recovery helper를 제공해 구현 부담을 줄임 |
| CPU 캐시 제어 | flush와 fence가 실제 영속 시점과 쓰기 순서를 보장함 |
| PM namespace | OS가 노출한 영속 메모리 영역으로 접근 정책과 생명주기를 관리함 |

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 영역 할당      | --> | 데이터 기록    | --> | 영속 보장      | --> | 장애 복구      |
+-------------+     +-------------+     +-------------+     +-------------+
```

## Ⅴ. 원리 및 절차 흐름도

1. **영역 할당**: OS가 DAX 파일시스템 또는 namespace를 애플리케이션에 제공함
2. **데이터 기록**: 애플리케이션이 load/store로 영속 자료구조를 갱신함
3. **영속 보장**: flush와 fence로 기록 순서와 반영 시점을 보장함
4. **장애 복구**: 로그와 버전 정보와 checksum을 바탕으로 일관된 상태를 복원함

## Ⅵ. 실무 적용 및 유의점

1. 인메모리 데이터베이스나 메타데이터 엔진은 퍼시스턴트 메모리로 복구 시간을 줄일 수 있지만 캐시 반영과 순서 보장을 잘못 다루면 장애 후 구조가 쉽게 깨지므로 PM 라이브러리와 트랜잭션 패턴을 표준화하고 복구 정합성 통과율과 장애 시험 결함 건수와 영속 반영 지연시간으로 확인함
2. 장비 재할당과 폐기 단계는 메모리처럼 보이는 특성 때문에 잔존 데이터 통제가 빠지기 쉬우므로 네임스페이스 암호화와 안전 삭제 절차를 함께 운영하고 잔존 데이터 검사 결과와 삭제 검증률과 쓰기 증폭 비율로 확인함

## Ⅶ. 결론

퍼시스턴트 메모리는 빠른 저장장치가 아니라 바이트 주소 지정과 영속성을 결합한 새로운 프로그래밍 모델임.
