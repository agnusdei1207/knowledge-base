## Ⅰ. 개요
- 설계자가 용도에 맞게 하드웨어 회로를 재구성할 수 있는 반도체
- 하드웨어의 성능과 소프트웨어의 유연성을 동시에 확보하는 기술

| 구분 | 내용 |
| --- | --- |
| 정의 | 제조 후에도 프로그래밍 가능한 논리 소자 어레이 |
| 특징 | 병렬 처리 성능 우수, 낮은 지연 시간, 프로토타이핑 용이 |
| 출제의도 | FPGA 구조(CLB) 및 ASIC/CPU와의 비교 역량 확인 |

## Ⅱ. 구성요소
```
+------------------------------------------+
|  [ FPGA Internal ]                       |
|  +-----+    +-----+    +-----+           |
|  | CLB |----| I/O |----| CLB |           |
|  +-----+    +-----+    +-----+           |
|     |          |          |              |
|  [ Programmable Interconnect ]           |
|     |          |          |              |
|  +-----+    +-----+    +-----+           |
|  | CLB |----| RAM |----| CLB |           |
|  +-----+    +-----+    +-----+           |
+------------------------------------------+
```
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| CLB | 논리 함수를 구현하는 기본 단위(LUT 포함) | 레고 블록 |
| LUT | 입력값에 따른 출력값을 저장한 룩업 테이블 | 진리표 지도 |
| Switch Matrix | CLB 간의 연결 경로를 구성하는 배선망 | 도로 교차로 |
> 요약: CLB와 가변 배선망을 조합해 회로를 물리적으로 구성함.

## Ⅲ. 절차
```
[HDL Design] -> [Synthesis] -> [Implementation] -> [Bitstream Download]
```
1. HDL Design: VHDL이나 Verilog로 하드웨어 동작 설계함.
2. Synthesis: 설계된 코드를 게이트 수준의 논리 회로로 변환함.
3. Implementation: 실제 FPGA 내부에 배치(Place) 및 배선(Route)함.
4. Bitstream Download: 최종 구성 파일을 FPGA에 로드하여 회로 확정함.
> 요약: 코딩을 통해 하드웨어의 물리적 회로를 형성함.

## Ⅳ. 문제점
- 높은 단가: 범용성 확보를 위한 칩 면적 증가로 개당 가격 높음.
- 설계 난이도: 하드웨어 타이밍 설계 등 전문 지식 및 긴 개발 시간 소요함.

## Ⅴ. 개선방안
- HLS(High-Level Synthesis) 도입: C/C++ 기반 설계로 개발 생산성 향상함.
- SoC 결합: ARM 코어 등이 포함된 SoC형 FPGA 사용하여 설계 유연성 높임.

## Ⅵ. 전망
- 데이터센터 가속기 및 5G 통신 장비의 핵심 부품으로 비중 확대됨.
- 적응형 컴퓨팅 아키텍처(ACAP)로의 진화가 미래 기술 로드맵의 핵심임.
