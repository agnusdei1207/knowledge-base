# NPU 신경망 처리 장치 (Neural Processing Unit)

## 미리 알고가기

- NPU: 신경망 처리 장치(Neural Processing Unit, NPU)는 신경망 추론 또는 학습 일부를 전용 데이터패스로 처리하는 프로세서임
- INT8/INT4: 낮은 비트 정밀도로 연산량과 메모리 사용량을 줄이는 표현 방식임
- Graph Partitioning: 모델 그래프를 NPU와 CPU/GPU 실행 구간으로 나누는 과정임
- TOPS: 초당 테라 연산 수(Tera Operations Per Second, TOPS)는 NPU 공개 성능 지표로 자주 쓰이나 실효 성능을 단독 설명하지 못함

## 1. 개요

- **정의/개념**: NPU는 신경망의 MAC, 활성화, 정규화, 메모리 이동을 전용 연산 배열과 온칩 메모리로 처리해 지연시간, 전력, 지원 연산자, 정밀도 기준으로 엣지·모바일·서버 AI 추론을 효율화하는 AI 특화 프로세서임.
- **배경/필요성**: 온디바이스 AI는 네트워크 지연과 개인정보 전송을 줄이면서 제한된 배터리와 열 조건을 만족해야 함. NPU는 CPU보다 낮은 전력으로 신경망 연산을 처리하고 GPU보다 작은 폼팩터에 통합되기 쉬움.

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| AI 전용 프로세서의 구조와 적용 조건 설명 | MAC array, on-chip memory, quantization, runtime, supported op | TOPS 수치만 나열, GPU와 차이 누락 |

> 요약: NPU는 신경망 추론을 낮은 전력과 짧은 지연으로 실행하도록 설계된 전용 프로세서임.

## 2. 특징 및 비교

| 판단 기준 | GPU | NPU |
|:---|:---|:---|
| 실행 목적 | 그래픽과 범용 병렬 연산을 넓게 처리함 | 신경망 연산자와 텐서 흐름에 특화됨 |
| 전력·열 | 고성능 처리량은 높지만 전력 소모가 큼 | 모바일·엣지에서 전력당 추론 성능이 높음 |
| 유연성 | 커널과 프레임워크 선택 폭이 넓음 | 지원 연산자와 런타임에 제약이 있음 |
| 선택 기준 | 학습, 다양한 커널, 대형 배치 | 고정 추론 모델, 실시간 응답, 배터리 제약 |

NPU 평가는 TOPS보다 모델이 NPU에서 얼마나 많이 실행되는지, 양자화 후 정확도가 유지되는지, CPU fallback이 얼마나 발생하는지를 봐야 함. 지원 연산자가 적으면 전용 하드웨어가 있어도 지연은 CPU/GPU 경유로 증가함.

## 3. 구성요소/구조

```text
+----------+      +------------+      +-----------+      +----------+
| AI Model | ---> | Compiler   | ---> | NPU Core  | ---> | Result   |
+----------+      +------------+      +-----------+      +----------+
                         |                  |
                         v                  v
                  +-------------+     +-------------+
                  | Quantization|     | On-chip Mem |
                  +-------------+     +-------------+
```

| 구성요소 | 설명 | 핵심 포인트 |
|:---|:---|:---|
| MAC 배열 | 신경망 행렬·컨볼루션 연산을 병렬 처리함 | 추론 처리량 |
| 온칩 메모리 | 가중치와 활성값을 저장해 외부 메모리 접근을 줄임 | 전력과 지연 |
| 컴파일러/런타임 | 모델 그래프를 NPU 실행 단위로 변환하고 fallback을 관리함 | 실행 커버리지 |
| 양자화 엔진 | INT8/INT4 등 낮은 정밀도 연산을 지원함 | 전력·정확도 균형 |
| Host CPU | 입력 준비, 비지원 연산, 후처리를 담당함 | 전체 지연 영향 |

### 원리/흐름도

```text
+----------+      +----------+      +-----------+      +----------+
| Quantize | ---> | Partition| ---> | Execute   | ---> | Fallback |
+----------+      +----------+      +-----------+      +----------+
```

모델은 양자화와 그래프 분할을 거쳐 NPU 지원 연산자는 NPU에서, 비지원 연산자는 CPU/GPU에서 실행됨. 따라서 NPU 효율은 전용 코어 성능보다 NPU 실행 커버리지와 메모리 이동량에 의해 결정됨.

## 4. 문제점 및 개선방안

1. **지원 연산자 제약**: 비지원 연산자가 많으면 CPU fallback과 메모리 복사가 발생해 지연이 커짐.
   - **개선방안**: 모델 변환 단계에서 지원 연산자 목록을 기준으로 graph rewrite와 operator fusion을 수행함. (확인: NPU execution ratio)
2. **양자화 정확도 저하**: 낮은 정밀도 적용 과정에서 모델 정확도가 하락할 수 있음.
   - **개선방안**: calibration, quantization-aware training, 혼합 정밀도를 적용함. (확인: FP32 대비 정확도 차이)
3. **TOPS 착시**: 공개 성능 수치가 실제 모델 지연, 메모리 병목, 런타임 오버헤드를 설명하지 못함.
   - **개선방안**: 실제 모델 기반 벤치마크와 end-to-end 지연 측정을 수행함. (확인: p95/p99 latency, 전력당 추론 수)

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| 스마트폰 온디바이스 AI | 카메라, 음성, 번역 모델을 NPU에서 추론하고 개인정보 전송을 줄임 | 배터리 소모, 지연, NPU 실행 비율 |
| 엣지 카메라 | 객체 탐지 모델을 INT8로 변환해 장치 내부에서 실시간 처리함 | FPS/W, 정확도 변화 |
| 산업 IoT | 센서 이상 탐지를 현장 게이트웨이 NPU에서 수행해 클라우드 의존을 낮춤 | 탐지 지연, 네트워크 전송량 |

## 6. 결론

NPU는 신경망 추론의 전력과 지연을 줄이는 핵심 AI 하드웨어이지만, 실제 효과는 TOPS가 아니라 모델 변환, 지원 연산자, 양자화 정확도, 메모리 이동량에서 결정됨. 따라서 NPU 도입은 목표 모델의 실행 커버리지와 end-to-end 지표로 검증해야 함.
