## 미리 알고가기

- NPU는 신경망 추론 연산을 전용 배열과 저정밀 연산기로 처리하는 프로세서임
- 온칩 메모리·양자화·컴파일러 런타임이 전체 추론 지연을 좌우함
- TOPS 수치만으로는 전처리부터 후처리까지의 지연을 설명할 수 없음
- MAC(Multiply-Accumulate) 연산: 곱셈과 누산을 동시에 수행하는 연산으로 신경망 행렬 연산의 기본 단위임
- 양자화(Quantization): 가중치·활성값을 저비트 정수로 근사해 연산량과 메모리 사용량을 줄이는 변환임
- 폴백(Fallback): 컴파일러가 지원하지 않는 연산을 만나면 다른 처리 장치로 실행을 넘기는 동작임

## 작성 근거(검토용)

- NPU는 전용 배열, 온칩 메모리, 저정밀 연산, 폴백 관리를 중심으로 설명함
- 비교표는 CPU, GPU, NPU의 실행 구조, 연산자 범위, 대표 역할을 대비함
- 실무 판단은 NPU 실행 비율, 전체 지연, 정확도 차이로 구체화함

## Ⅰ. 개요

- **정의/개념**: NPU는 컨볼루션, 행렬 곱, 활성화 같은 신경망 연산을 전용 배열·온칩 메모리·저정밀 연산기로 처리하는 AI 추론 프로세서임
- **배경/필요성**: 온디바이스 AI의 배터리·열·네트워크 제약 안에서 반복 추론을 수행하기 위해 저정밀 전용 연산 장치가 필요함

### 쉽게 이해하기 (학습용)
- 휴대용 계산기가 배터리와 발열 한도 안에서 사진 속 패턴을 빠르게 알아보는 전용 회로를 쓰는 것과 같음

## Ⅱ. 특징

- 범용 명령 처리보다 신경망 연산 배열과 온칩 데이터 재사용에 자원을 배치함
- 컴파일러의 지원 연산자와 모델 형식이 NPU 실행 비율을 결정함
- INT8, INT4 같은 저정밀 연산과 메모리 재사용이 핵심 최적화 포인트임
- CPU 폴백 구간이 늘면 NPU 밖의 데이터 변환·전송 시간이 전체 추론 지연을 늘림

### 쉽게 이해하기 (학습용)
- 전용 작업대(연산 배열) 옆 재료 창고(온칩 메모리)로 빠르게 처리하되, 미리 정한 매뉴얼(컴파일러)에 없는 작업은 옆 부서(CPU)로 넘겨야 해서 그만큼 시간이 더 걸림

## Ⅲ. 종류 및 비교

| 판단 기준 | CPU | GPU | NPU |
|:---|:---|:---|:---|
| 실행 구조 | 범용 명령·분기 실행 | SIMT 커널 실행 | 신경망 전용 배열 실행 |
| 연산자 범위 | 소프트웨어로 범용 연산 처리 | 커널이 구현된 연산 처리 | 컴파일러가 지원하는 연산 처리 |
| 대표 역할 | 전후처리·폴백 | 학습·서버 추론 | 온디바이스 추론 |

> 요약: NPU는 컴파일러가 지원하는 신경망 연산을 전용 배열에서 실행하고 비지원 연산은 CPU·GPU로 넘김.

### 쉽게 이해하기 (학습용)
- 뭐든 다루는 만능 직원(CPU), 같은 작업을 대량으로 처리하는 작업조(GPU), 정해진 패턴만 빠르게 처리하는 전담 로봇(NPU)의 역할 차이임

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| MAC 배열 | 반복적인 신경망 연산을 병렬 처리해 NPU의 연산 처리량을 결정함 |
| 온칩 메모리 | 가중치와 활성값을 MAC 배열 가까이에 저장해 외부 메모리 접근을 줄임 |
| 양자화 엔진 | INT8·INT4 저정밀 연산을 수행해 연산량과 메모리 전송량을 줄임 |
| 컴파일러·런타임 | 모델을 NPU 실행 단위로 분할하고 폴백과 스케줄링을 관리함 |

> 요약: 컴파일러가 지원 연산을 MAC 배열·온칩 메모리에 배치하고 비지원 연산을 CPU·GPU로 분리함.

### 쉽게 이해하기 (학습용)
- 반복 곱셈을 도는 로봇팔(MAC 배열), 팔 바로 옆 부품함(온칩 메모리), 부품을 가볍게 깎아주는 재단(양자화 엔진), 작업을 나눠 배정하는 반장(컴파일러·런타임)이 함께 동작함

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 모델 변환      | --> | 양자화·분할    | --> | NPU 연산 실행  | --> | 폴백·후처리    |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **모델 변환**: 학습 모델을 배포 가능한 형식으로 변환함
2. **양자화 및 분할**: 지원 연산자는 NPU로, 비지원 구간은 다른 장치로 나눔
3. **NPU 연산 실행**: 전용 배열과 메모리 경로로 추론을 수행함
4. **폴백 및 후처리**: CPU나 GPU가 나머지 연산과 결과 처리를 담당함

> 요약: 모델은 변환·양자화 뒤 지원 구간은 NPU, 비지원 구간은 CPU·GPU로 나뉨.

### 쉽게 이해하기 (학습용)
- 설계도를 현장용으로 바꾸고(모델 변환), 무거운 부품을 가볍게 깎아 담당을 나눈 뒤(양자화·분할), 로봇이 처리하고(NPU 실행), 로봇이 못 하는 나머지는 사람이 마무리하는(폴백·후처리) 순서임

## Ⅵ. 실무 사례

1. AI PC 추론은 그래프 재작성과 연산자 융합으로 폴백 구간을 줄이고 NPU 실행 비율·전체 지연을 확인함
2. 영상 모델은 보정 데이터로 양자화하고 정확도 차이·추론당 소비 전력을 확인함

### 쉽게 이해하기 (학습용)
- 사무용 PC는 로봇이 더 많은 일을 하도록 작업을 재배치하고, 카메라 모델은 실제 사진으로 깎은 부품이 여전히 잘 맞는지 확인함

## Ⅶ. 결론

- NPU는 신경망 연산을 전용 배열과 저정밀 연산기로 처리해 배터리·발열 제약 안에서 온디바이스 추론을 수행하는 프로세서임
- 적용 여부는 TOPS 수치가 아니라 컴파일러의 모델 지원 범위, 양자화 손실, CPU 폴백 구간을 기준으로 판단해야 함

### 쉽게 이해하기 (학습용)
- 계산기의 최고 속도 숫자만 보지 말고 실제로 얼마나 많은 작업을 직접 처리하고 얼마나 남에게 넘기는지를 봐야 함
