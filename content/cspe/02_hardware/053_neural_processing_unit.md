## Ⅰ. 개요
- **정의**: 신경망 추론 연산에 특화된 저전력 온디바이스 AI 가속기
- **배경/필요성**: 모바일·IoT 기기에서 클라우드 왕복 없이 실시간 AI 추론을 수행하려면 전력 효율이 높은 전용 프로세서가 필요함
- **비유**: GPU가 대형 발전소라면, NPU는 각 가정에 설치된 소형 태양광 패널임

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 온디바이스 AI 가속 구조 이해 | MAC 연산 특화와 저전력 설계 | NPU와 GPU·TPU의 설계 목표 차이를 명확히 구분할 것 |

> 요약: 엣지 디바이스에서 저전력으로 신경망 추론을 수행하는 전용 프로세서임

## Ⅱ. 구성요소
```text
SoC (System on Chip)
  |
  +-- CPU Core
  |
  +-- GPU Core
  |
  +-- NPU Core
        |
        +-- MAC Array (Multiply-Accumulate)
        |
        +-- Activation Engine
        |
        +-- On-chip SRAM Buffer
        |
        +-- DMA Controller
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| MAC Array | 곱셈-누적 연산을 병렬 수행하는 핵심 연산 블록 | 주판 수백 개를 동시에 튕기는 계산대 |
| Activation Engine | ReLU, Sigmoid 등 활성화 함수를 하드웨어로 처리하는 유닛 | 자동 검수 장치 |
| On-chip SRAM | 가중치·중간 결과를 저장하는 저지연 온칩 버퍼 | 작업대 위 재료 트레이 |
| DMA Controller | 외부 메모리와 SRAM 간 데이터 전송을 CPU 개입 없이 수행함 | 자동 자재 운반 로봇 |
| 양자화 엔진 | INT8/INT4 등 저비트 연산을 지원하여 처리량을 높이는 유닛 | 간략화된 계산 규칙표 |

> 요약: MAC Array 중심으로 SRAM 버퍼와 DMA가 데이터를 공급하는 저전력 추론 파이프라인임

## Ⅲ. 절차
```text
모델 변환 --> 가중치 로드 --> 레이어별 추론 --> 결과 출력
     |              |              |               |
     v              v              v               v
 양자화/최적화   SRAM 적재     MAC+활성화 반복    후처리 전달
```
- 1단계: 학습된 모델을 NPU 전용 포맷으로 변환하고 INT8/INT4 양자화를 적용함
- 2단계: 양자화된 가중치를 DMA로 외부 메모리에서 On-chip SRAM에 적재함
- 3단계: MAC Array가 레이어별 곱셈-누적 연산을 수행하고 Activation Engine이 활성화 함수를 처리함
- 4단계: 최종 레이어 출력을 CPU로 전달하여 후처리(분류, 검출 등)를 완료함

> 요약: 양자화된 모델을 SRAM에 적재한 뒤 MAC 연산과 활성화를 레이어별로 반복 수행함

## Ⅳ. 문제점
- 모델 호환성 제한: 지원 연산자(Operator) 범위가 좁아 일부 모델 레이어가 CPU 폴백됨
- 개발 도구 미성숙: 벤더별 SDK가 상이하여 모델 포팅과 디버깅에 소요 시간이 증가함
- 정밀도 손실: 양자화 과정에서 FP32 대비 추론 정확도가 저하될 수 있음

> 요약: 제한된 연산자 지원, 파편화된 도구, 양자화 정밀도 손실이 주요 과제임

## Ⅴ. 개선방안
1. 단기: 지원 연산자 범위를 확대하고 미지원 연산자의 CPU 폴백 오버헤드를 최소화함
2. 중기: ONNX Runtime 등 표준 런타임 채택으로 벤더 간 개발 도구를 통합함
3. 장기: 양자화 인식 학습(QAT)을 표준화하여 정밀도 손실을 모델 학습 단계에서 보상함

> 요약: 연산자 확대, 도구 표준화, QAT 도입으로 단계적 개선이 필요함

## Ⅵ. 전망
- 발전 방향: 온디바이스 생성형 AI 수요로 NPU 연산 성능(TOPS)이 매 세대 2배 이상 증가하는 추세임
- 기술사적 판단: 스마트폰·PC·자동차 SoC에 NPU 탑재가 표준화되어 엣지 AI 시장이 확대될 전망임
- 기술사 제언: NPU 성능 지표(TOPS, TOPS/W)와 지원 모델 범위를 기준으로 SoC를 평가해야 함
