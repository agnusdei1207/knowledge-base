## 핵심 인사이트 (3줄 요약)
- PIM은 메모리 칩 내부에 직접 연산 코어(ALU, MAC 등)를 집적하여, 폰 노이만 구조의 고질적 병목(Memory Wall)을 근본적으로 해결하는 차세대 지능형 메모리 기술이다.
- 방대한 데이터를 중앙 프로세서(CPU/GPU)로 옮기지 않고 메모리 뱅크 내부의 넓은 대역폭을 활용해 병렬 연산을 자체 수행하므로, 전력 소모를 70% 이상 획기적으로 줄일 수 있다.
- 삼성전자의 HBM-PIM 등 상용화가 점진적으로 이루어지고 있으며, 초거대 AI 추론(Inference) 시장의 TCO를 절감하는 핵심 하드웨어 아키텍처로 부상 중이다.

## Ⅰ. 개요 및 필요성
- **개념:** 데이터를 저장만 하던 수동적 메모리 칩 내부에 연산 기능(Processing Unit)을 내장하여, 데이터가 있는 그 자리에서 직접 연산을 처리하는 차세대 반도체.
- **필요성:** 
  - **Memory Wall (성능 병목):** 프로세서 속도 대비 메모리 I/O 대역폭의 발전이 느려, 아무리 좋은 GPU를 써도 데이터를 가져오느라 쉬는 현상(Idle) 발생.
  - **Power Wall (전력 장벽):** 연산 자체에 드는 전기보다 데이터를 칩 밖으로 옮기는(Off-chip Data Movement) 데 드는 전력이 수백 배 더 크기 때문에 발열과 전력망 한계 봉착.
---
## Ⅱ. 아키텍처 및 핵심 원리
### 1. 폰 노이만 구조와 PIM 구조 비교 도식
```text
[ 기존 폰 노이만 구조 ]                 [ PIM 구조 (Processing In Memory) ]
CPU/GPU <---(Data 왕복)---> Memory     CPU/GPU ---(명령어 전송)---> Memory (PIM)
 (병목)                                                      ┌───────────┐
                                                             │ Bank      │
                                                             │ + MAC연산 │--> 연산 결과만
                                                             └───────────┘    호스트로 반환
```

### 2. 핵심 동작 원리
- **PCU (Programmable Computing Unit) 내장:** 메모리의 가장 작은 단위인 뱅크(Bank) 내부나 근처에 행렬 곱셈을 전담하는 소형 연산기(MAC, Multiply-Accumulate)를 탑재.
- **In-situ 연산 (제자리 연산):** 호스트 프로세서가 '연산 명령'만 PIM 메모리로 보내면, 각 뱅크의 PCU가 저장된 데이터에 직결된 초고속 내부 버스를 통해 병렬로 연산을 수행.
- **데이터 이동 최소화:** 기가바이트(GB) 단위의 데이터가 외부 핀을 타지 않고, 연산이 끝난 최종 결과값(수 MB)만 호스트로 전송되므로 트래픽 폭주가 사라짐.

## Ⅲ. 비교 및 연결
- **기존 메모리 vs PNM vs PIM 비교**
| 비교 항목 | 기존 메모리 (폰 노이만) | PNM (Processing Near Memory) | PIM (Processing in Memory) |
|---|---|---|---|
| 연산기 위치 | CPU / GPU 내부 | 메모리 모듈 기판(CXL) 외부 패키지 | **메모리 다이(Die)/뱅크 내부** |
| 병목 극복 | 극복 불가 (지속) | 중간 (인터페이스 대역폭 한계 있음) | **최상 (내부 대역폭 직접 활용)** |
| 전력 소모 | 가장 높음 (이동 잦음) | 중간 | **가장 낮음 (데이터 제자리 연산)** |
| 칩 설계 난이도| 낮음 | 중간 (패키징 통합 기술) | **매우 높음 (메모리+로직 혼재 공정)** |
---
## Ⅳ. 실무 적용 및 기술사 판단
- **AI 추론(Inference) 서버 도입:** 딥러닝 트레이닝은 GPU의 부동소수점 연산이 많이 필요하지만, 가중치 조회가 빈번한 추론 서비스(예: ChatGPT 응답) 환경에서는 PIM이 압도적인 가성비를 제공.
- **표준화와 소프트웨어 생태계:** 하드웨어 개발뿐만 아니라 기존 C/C++, CUDA 등으로 작성된 코드를 PIM 명령어로 자동 번역하고 스케줄링해주는 컴파일러/API(소프트웨어 스택) 호환성 확보가 실무 적용의 최대 관건임.
---
## Ⅴ. 기대효과 및 결론
- PIM은 컴퓨터가 탄생한 이래 70년 넘게 이어져 온 '데이터 저장소'와 '데이터 연산기'의 물리적 분리를 최초로 무너뜨린 파괴적 혁신 기술입니다.
- 초기에는 단가가 높고 공정이 까다롭지만, 향후 HBM4의 커스텀 로직 다이와 결합하여 메모리 자체가 메인 프로세서를 거느리는 진정한 '메모리 중심 컴퓨팅(Memory-centric Computing)' 시대를 열게 될 것입니다.

### 📌 관련 개념 맵
- 폰 노이만 아키텍처 ─ Memory Wall / Power Wall
- PIM ─ PNM (Processing Near Memory) ─ CXL
- HBM-PIM (삼성 아쿠아볼트 등) ─ MAC 연산 (행렬 곱)

### 📈 관련 키워드 및 발전 흐름도
[폰 노이만 병목 극복] ➔ 캐시 메모리/계층 구조 ➔ 3D 스태킹/HBM ➔ **[PIM (메모리 내 연산 집적)]** ➔ [뉴로모픽 / 인메모리 컴퓨팅 (아날로그 연산)]

### 👶 어린이를 위한 3줄 비유 설명
1. 요리사(CPU)가 식당에서 요리할 때, 매번 창고(메모리)까지 걸어가서 파 하나, 양파 하나를 가져오면 너무 지치고 오래 걸리죠? (폰 노이만 병목)
2. PIM은 아예 창고 안에 작은 도마와 칼(연산기)을 갖춘 알바생을 여러 명 두는 거예요.
3. 요리사가 "파 다져줘!"라고 소리만 치면 창고 안에서 다 다진 파를 쏙 넘겨주니까, 요리사는 걸어 다닐 필요 없이 엄청 빠르고 편하게 요리할 수 있어요!
