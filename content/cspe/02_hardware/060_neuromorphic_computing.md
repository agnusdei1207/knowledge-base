## 미리 알고가기

- 뉴로모픽 컴퓨팅은 뇌의 spike 기반 처리 방식을 모사한 컴퓨팅 구조임
- SNN과 event-driven 처리와 synaptic memory가 핵심 개념임
- 희소 이벤트와 초저전력 감지 영역에서 전력 이점이 생김

## Ⅰ. 개요

- **정의/개념**: 뉴로모픽 컴퓨팅은 뉴런과 시냅스와 spike 이벤트를 모사한 회로와 아키텍처를 이용해 입력이 발생할 때만 연산과 통신을 수행하도록 설계한 저전력 지능형 컴퓨팅 방식임
- **배경/필요성**: 폰 노이만 구조는 메모리와 연산 분리 때문에 데이터 이동 전력이 많이 들고 희소 이벤트 처리에서 전력 낭비가 발생하므로, 초저전력 센서 지능에는 다른 구조가 필요함

## Ⅱ. 특징

- 이벤트가 있을 때만 동작해 희소 신호에서는 전력 소모를 줄일 수 있음
- 시간 정보와 spike 패턴을 직접 표현해 센서형 입력 처리에 유리함
- 범용 딥러닝 생태계보다 도구와 학습 방식이 미성숙함
- 모든 AI 문제에 맞는 구조가 아니라 입력 특성에 따라 적합성이 갈림

## Ⅲ. 종류 및 비교

| 판단 기준 | 폰 노이만 AI 처리 | 뉴로모픽 컴퓨팅 |
|:---|:---|:---|
| 데이터 표현 | 연속값 텐서 | spike 이벤트 |
| 동작 방식 | 클록 기반 반복 연산 | event-driven 비동기 처리 |
| 전력 특성 | 데이터 이동 비용 부담 | 희소 입력에서 유리 |
| 대표 용도 | 범용 AI 모델 | 센서 이벤트, 초저전력 패턴 인식 |

> 요약: 뉴로모픽 컴퓨팅은 연속 텐서보다 spike 이벤트와 희소 입력 처리에 맞음.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Spike Encoder | 입력 신호를 이벤트 시퀀스로 변환해 시간 정보 기반 처리를 가능하게 함 |
| Neuron Core | 이벤트를 누적하고 임계값 도달 시 출력을 발생시키는 계산 단위임 |
| Synaptic Memory | 연결 강도를 저장하며 연산과 메모리의 근접 결합을 제공함 |
| Event Router, Learning Rule | spike를 필요한 뉴런으로 전달하고 STDP 같은 적응 규칙으로 학습 가능성을 부여함 |

```text
+-------------+     +-------------+     +----------------+     +-------------+
| Input Event | --> | Spike Encode| --> | Neuron/Synapse | --> | Event Route |
+-------------+     +-------------+     +----------------+     +-------------+
```

> 요약: 입력 이벤트는 spike encoder, neuron core, synaptic memory, event router를 거쳐 처리됨.

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 입력 이벤트 생성 | --> | spike 인코딩   | --> | 뉴런 누적/발화 | --> | 시냅스 적응/출력 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **입력 이벤트 생성**: 센서가 변화 신호를 발생시킴
2. **Spike 인코딩**: 입력을 시간 기반 이벤트로 변환함
3. **뉴런 누적 및 발화**: 뉴런이 임계값을 넘으면 다음 spike를 발생시킴
4. **시냅스 적응 및 출력**: 연결 강도를 조정하고 외부 동작에 반영함

> 요약: 입력 변화는 spike로 바뀌고 뉴런 누적·발화와 시냅스 적응을 거쳐 출력됨.

## Ⅵ. 실무 적용 및 유의점

1. 이벤트 카메라·상시 감지 센서는 뉴로모픽이 희소 이벤트에서 전력을 줄일 수 있지만 일반 텐서 작업에는 이점이 작으므로 event-driven 문제를 선별하고 reaction latency, energy per inference로 확인함
2. 웨어러블·초저전력 이상 감지는 ANN-to-SNN 변환과 HW/SW 공동 설계가 필요하지만 도구가 미성숙하므로 시뮬레이터와 단계 검증을 병행하고 model conversion accuracy, development effort로 확인함

## Ⅶ. 결론

뉴로모픽 컴퓨팅은 범용 AI 가속기 대체재가 아니라 희소 이벤트와 초저전력 조건에서 전력 이점이 생기므로 문제 특성과 센서 특성을 먼저 맞춰야 함.

## 작성 근거(검토용)

- 뉴로모픽 컴퓨팅은 spike, event-driven 처리, synaptic memory, 희소 입력을 핵심 축으로 설명함
- 비교표는 폰 노이만 AI 처리와 뉴로모픽의 데이터 표현, 동작 방식, 전력 특성을 대비함
- 실무 판단은 reaction latency, energy per inference, conversion accuracy로 검증 가능하게 작성함
