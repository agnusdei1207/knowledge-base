# 뉴로모픽 컴퓨팅 (Neuromorphic Computing)

## 미리 알고가기

- SNN: 스파이킹 신경망(Spiking Neural Network, SNN)은 신호를 연속값 대신 spike 이벤트로 표현하는 신경망임
- ANN: 인공 신경망(Artificial Neural Network, ANN)은 연속값 텐서 기반으로 학습·추론을 수행하는 일반 신경망 구조임
- Event-driven: 이벤트가 발생한 시점에만 연산과 통신을 수행하는 방식임
- Synapse: 뉴런 사이의 연결 가중치이며 뉴로모픽 칩에서는 메모리와 연산 역할을 함께 가짐
- Plasticity: 입력 패턴에 따라 연결 강도가 변하는 학습 특성임

## Ⅰ. 개요

- **정의/개념**: 뉴로모픽 컴퓨팅은 생물학적 신경계의 spike, synapse, event-driven 처리 방식을 회로와 아키텍처로 모사해 이벤트 희소성, 시간 정보, 전력 효율 기준으로 감각·패턴 인식 문제를 낮은 전력으로 처리하는 컴퓨팅 방식임.
- **배경/필요성**: 기존 폰 노이만 구조는 메모리와 연산 장치 사이 데이터 이동 비용이 크고, 항상 클록에 맞춰 동작해 희소 이벤트 처리에 비효율적임. 뉴로모픽은 데이터가 발생할 때만 계산해 초저전력 지능형 센서 처리 가능성을 제공함.

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 뇌 모사 하드웨어의 구조와 적용 한계 설명 | SNN, spike, event-driven, synaptic memory, low power | 일반 딥러닝 가속기로 설명, 학습 생태계 한계 누락 |

> 요약: 뉴로모픽 컴퓨팅은 spike 이벤트와 근접 메모리 연산으로 희소 신호를 저전력 처리하는 방식임.

## Ⅱ. 특징 및 비교

| 판단 기준 | 폰 노이만 AI 처리 | 뉴로모픽 컴퓨팅 |
|:---|:---|:---|
| 데이터 표현 | 연속 텐서 값을 메모리에서 읽어 연산기로 이동함 | spike 이벤트와 시간 정보를 기반으로 처리함 |
| 동작 방식 | 클록 기반으로 주기적 연산을 수행함 | 이벤트 발생 시 연산·통신하는 비동기 구조 가능 |
| 전력 특성 | 데이터 이동과 행렬 연산 전력이 큼 | 희소 이벤트에서는 낮은 전력 가능 |
| 적용 기준 | 대규모 행렬 연산과 표준 딥러닝 모델 | 센서 이벤트, 저전력 패턴 인식, 적응형 제어 |

뉴로모픽은 GPU나 NPU를 대체하는 범용 AI 가속기가 아니라, 이벤트 기반 입력과 시간 패턴이 중요한 문제에서 의미가 큼. 정적 이미지 분류보다 이벤트 카메라, 로봇 감각, 초저전력 이상 탐지처럼 입력이 희소한 영역에 적합함.

## Ⅲ. 구성요소/구조

```text
+----------+      +----------+      +-------------+      +----------+
| Sensor   | ---> | Spike    | ---> | Neuron/Syn  | ---> | Action   |
+----------+      +----------+      +-------------+      +----------+
                         |                  |
                         v                  v
                  +-------------+    +-------------+
                  | Event Queue |    | Plasticity  |
                  +-------------+    +-------------+
```

| 구성요소 | 설명 | 핵심 포인트 |
|:---|:---|:---|
| Spike Encoder | 입력 신호를 시간 이벤트로 변환함 | 데이터 표현 |
| Neuron Core | spike를 누적하고 임계값을 넘으면 다음 spike를 발생시킴 | 이벤트 처리 |
| Synaptic Memory | 연결 가중치를 저장하고 신호 전달 강도를 결정함 | 메모리-연산 근접 |
| Event Router | spike 이벤트를 관련 뉴런으로 전달함 | 비동기 통신 |
| Learning Rule | STDP 등 시간 기반 적응 규칙을 적용함 | 온칩 학습 가능성 |

### 원리/흐름도

```text
+--------+      +----------+      +----------+      +----------+
| Encode | ---> | Integrate| ---> | Fire     | ---> | Adapt    |
+--------+      +----------+      +----------+      +----------+
```

센서 입력은 spike로 인코딩되고 뉴런 회로는 입력 spike를 누적함. 임계값을 넘으면 출력 spike를 발생시키며, synapse 가중치는 입력 시간 패턴과 학습 규칙에 따라 조정될 수 있음.

## Ⅳ. 문제점 및 개선방안

1. **프로그래밍 모델 미성숙**: SNN 모델링, 학습, 디버깅 도구가 표준 딥러닝 생태계보다 부족함.
   - **개선방안**: ANN-to-SNN 변환, 시뮬레이터, 벤치마크 태스크를 활용해 적용 범위를 제한함. (확인: 모델 변환 정확도)
2. **정확도와 범용성 한계**: 모든 AI 문제에서 SNN이 기존 딥러닝보다 우수하지 않음.
   - **개선방안**: 이벤트 기반 센서, 희소 신호, 저전력 요구가 명확한 문제에 우선 적용함. (확인: 정확도 대비 전력 절감)
3. **하드웨어·알고리즘 공동 설계 필요**: spike 표현, 라우팅, 메모리 구조가 모델 성능과 직접 연결됨.
   - **개선방안**: 알고리즘-아키텍처 co-design과 실제 센서 데이터 기반 검증을 수행함. (확인: spike rate, energy per inference)

## Ⅴ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| 이벤트 카메라 처리 | 변화가 발생한 픽셀 이벤트만 처리해 저전력 객체 추적을 수행함 | event rate, 지연, 전력 |
| 로봇 감각 제어 | 촉각·청각 이벤트를 spike로 처리해 빠른 반응을 구현함 | 반응 시간, 에너지 사용량 |
| 초저전력 이상 탐지 | 센서가 평상시에는 거의 연산하지 않고 이상 이벤트 발생 시만 처리함 | battery life, false alarm |

## Ⅵ. 결론

뉴로모픽 컴퓨팅은 AI 연산을 더 빠르게 하는 일반 가속기보다, 희소 이벤트를 낮은 전력으로 처리하는 새로운 계산 방식에 가까움. 강점은 event-driven 처리와 메모리-연산 근접 구조이고, 한계는 프로그래밍 모델과 적용 문제 범위임. 따라서 적용 여부는 뇌 모사라는 표현보다 입력의 희소성, 시간 정보, 전력 제약, 검증 가능한 정확도를 기준으로 판단해야 함.
