## 미리 알고가기

- 뉴로모픽 컴퓨팅은 뇌의 스파이크(Spike) 기반 처리 방식을 모사한 컴퓨팅 구조임
- SNN·이벤트 기반 처리·시냅스 메모리가 핵심 개념임
- 희소 이벤트와 초저전력 감지 영역에서 전력 이점이 생김

## 작성 근거(검토용)

- 뉴로모픽 컴퓨팅은 스파이크, 이벤트 기반 처리, 시냅스 메모리, 희소 입력을 핵심 축으로 설명함
- 비교표는 폰 노이만 AI 처리와 뉴로모픽의 데이터 표현, 동작 방식, 전력 조건을 대비함
- 실무 판단은 반응 지연, 추론당 에너지, 변환 정확도 차이, 시간 단계 수로 구체화함

## Ⅰ. 개요

- **정의/개념**: 뉴로모픽 컴퓨팅은 뉴런·시냅스·스파이크 이벤트를 모사한 회로로 입력이 발생할 때만 연산과 통신을 수행하는 컴퓨팅 방식임
- **배경/필요성**: 희소 센서 이벤트의 불필요한 메모리 전송과 반복 연산을 줄이기 위해 이벤트 발생 시에만 동작하는 구조가 필요함

## Ⅱ. 특징

- 이벤트가 있을 때만 동작해 희소 신호에서는 전력 소모를 줄일 수 있음
- 센서 입력의 발생 시점과 변화를 스파이크 시점·빈도로 표현함
- 기존 인공신경망과 학습·실행 방식이 달라 SNN 변환 도구와 전용 런타임이 필요함
- 입력 이벤트가 조밀하면 항상 동작하므로 희소 입력에서 얻는 연산 절감이 줄어듦

## Ⅲ. 종류 및 비교

| 판단 기준 | 폰 노이만 AI 처리 | 뉴로모픽 컴퓨팅 |
|:---|:---|:---|
| 데이터 표현 | 연속값 텐서 | 스파이크 이벤트 |
| 동작 방식 | 클록 기반 반복 연산 | 이벤트 기반 비동기 처리 |
| 전력 조건 | 밀집 텐서 실행 중 연산·메모리 접근 반복 | 이벤트가 발생할 때 연산·라우팅 수행 |
| 대표 용도 | 범용 AI 모델 | 센서 이벤트·상시 패턴 인식 |

> 요약: 뉴로모픽 컴퓨팅은 스파이크 이벤트로 표현되는 희소 센서 입력 처리에 적합함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 스파이크 인코더 | 입력 신호를 이벤트 시퀀스로 변환해 변화 시점과 빈도를 표현함 |
| 뉴런 코어 | 이벤트를 누적하고 임계값에 도달하면 출력 스파이크를 발생시킴 |
| 시냅스 메모리 | 뉴런 간 연결 강도를 저장해 누적 연산의 가중치로 사용함 |
| 이벤트 라우터 | 스파이크를 대상 뉴런으로 전달하며 라우팅 혼잡과 전달 지연을 결정함 |

> 요약: 스파이크 인코더가 입력을 변환하고 뉴런 코어·시냅스 메모리가 누적한 결과를 이벤트 라우터가 전달함.

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 입력 변화 감지  | --> | 스파이크 인코딩 | --> | 뉴런 누적·발화 | --> | 출력 이벤트 전달 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **입력 변화 감지**: 센서가 변화 신호를 발생시킴
2. **스파이크 인코딩**: 입력을 시간 기반 이벤트로 변환함
3. **뉴런 누적 및 발화**: 뉴런이 임계값을 넘으면 다음 스파이크를 발생시킴
4. **출력 이벤트 전달**: 이벤트 라우터가 발화 결과를 다음 뉴런이나 외부 장치로 전달함

> 요약: 입력 변화는 스파이크로 바뀌고 뉴런의 누적·발화와 이벤트 라우팅을 거쳐 출력됨.

## Ⅵ. 실무 사례

1. 이벤트 카메라는 입력 이벤트 밀도별 반응 지연·추론당 에너지를 측정함
2. 인공신경망의 SNN 변환은 변환 전후 정확도 차이·시간 단계 수를 확인함

## Ⅶ. 결론

뉴로모픽 컴퓨팅은 입력이 희소한 센서 처리에 적용하며 이벤트 밀도별 지연과 에너지 이점을 검증해야 함.
