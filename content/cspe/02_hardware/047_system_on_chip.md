## 미리 알고가기

- SoC는 CPU, 메모리 인터페이스, I/O, 가속기 등을 하나의 칩에 통합한 집적 시스템임
- 성능뿐 아니라 전력과 면적과 인터커넥트 효율이 설계 핵심임
- 모바일과 임베디드와 온디바이스 AI 플랫폼의 기본 형태임

## Ⅰ. 개요

- **정의/개념**: SoC는 프로세서 코어와 메모리 제어기와 주변장치 인터페이스와 전용 가속기를 하나의 반도체 다이에 통합해 시스템 수준 기능을 칩 내부에서 수행하도록 만든 집적 아키텍처임
- **배경/필요성**: 보드 수준 분산 설계는 전력과 공간과 배선 비용이 커지므로, 모바일과 임베디드 환경에서는 기능 통합을 통한 소형화와 저전력화가 필요함

## Ⅱ. 특징

- 칩 내부 통합으로 전력 소모와 지연을 줄이기 좋음
- 기능 추가와 검증 복잡도가 함께 증가해 설계 난도가 높음
- CPU, GPU, NPU, ISP 같은 이기종 블록 공존이 일반적임
- 패키지 외부 I/O가 줄어 BOM과 보드 면적 최적화에 유리함

## Ⅲ. 종류 및 비교

| 판단 기준 | SoC | MPU 기반 보드 | SiP |
|:---|:---|:---|:---|
| 통합 수준 | 매우 높음 | 낮음 | 패키지 수준 높음 |
| 전력 효율 | 높음 | 중간 | 중간 |
| 설계 유연성 | 낮음 | 높음 | 중간 |
| 대표 용도 | 모바일, 임베디드 | 산업, 범용 제어 | 고밀도 패키징 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Compute Cluster | CPU와 GPU와 NPU가 연산 성격별로 역할을 분담하며 전체 성능 상한을 결정함 |
| On-chip Interconnect | AMBA NoC 등이 블록 간 데이터를 전달하며 병목과 QoS를 좌우함 |
| Memory, Cache Subsystem | DRAM 인터페이스와 캐시와 SRAM이 데이터 공급 효율과 전력 사용량을 결정함 |
| Peripheral, Power Management | USB, PCIe, Display, PMIC 제어가 시스템 연결성과 배터리 지속시간을 함께 좌우함 |

```text
+------------------+
| Compute Cluster  |
+------------------+
         |
         v
+------------------+
| On-chip NoC      |
+------------------+
      |       |
      v       v
+-----------+ +------------------+
| Memory    | | Peripheral / PM  |
+-----------+ +------------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 기능 통합 설계 | --> | 블록 간 연결 구성 | --> | 전력/클록 제어 | --> | 시스템 기능 제공 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **기능 통합 설계**: 필요한 연산과 I/O 기능을 칩에 배치함
2. **블록 간 연결 구성**: interconnect와 메모리 계층을 연결함
3. **전력과 클록 제어**: 블록별 DVFS와 power gating을 적용함
4. **시스템 기능 제공**: 칩 단위로 완결된 플랫폼 동작을 수행함

## Ⅵ. 실무 적용 및 유의점

1. 스마트폰이나 온디바이스 AI SoC에서는 CPU, GPU, NPU를 한 칩에 묶어 전력 효율을 높이되 NoC와 메모리 병목이 성능을 깎지 않도록 DVFS와 QoS 기반 대역폭 제어를 적용하고 performance per watt와 memory bandwidth utilization으로 확인함
2. 자동차나 산업 SoC처럼 수명 주기가 긴 제품에서는 단일 칩 재설계 비용이 크므로 검증된 IP 재사용과 단계적 검증 계획을 적용하고 verification coverage와 first-pass success rate로 확인함

## Ⅶ. 결론

SoC는 기능을 많이 넣는 것이 목적이 아니라 연산과 메모리와 전력을 한 칩 안에서 균형 있게 묶는 구조이므로 통합 이익과 병목 비용을 함께 따져야 함.
