## 미리 알고가기

- SoC는 CPU, 메모리 인터페이스, I/O, 가속기 등을 하나의 칩에 통합한 집적 시스템임
- 설계 기준은 연산 성능, 전력, 다이 면적, 온칩 인터커넥트 병목임
- 모바일·임베디드·온디바이스 AI 플랫폼의 기본 형태임
- NoC(Network on Chip): 온칩 블록 사이를 패킷 기반 경로로 연결하는 인터커넥트임
- SiP(System in Package): 여러 다이를 하나의 패키지에 함께 실장하는 통합 방식임
- MPU(Microprocessor Unit): 메모리·주변장치를 외부 칩으로 연결해 사용하는 범용 프로세서임
- 타이밍 클로저: 설계한 회로가 목표 클럭 주기 안에서 모든 신호 지연 요건을 만족하는 상태임

## 작성 근거(검토용)

- SoC는 통합 경계, 전력·면적, NoC·메모리 병목을 핵심 축으로 설명함
- 구성요소는 연산 클러스터, 온칩 인터커넥트, 메모리, 주변장치·전력 관리로 정리함
- 실무 판단은 와트당 성능, 메모리 대역폭 사용률, 검증 커버리지로 구체화함

## Ⅰ. 개요

- **정의/개념**: SoC는 프로세서 코어, 메모리 제어기, 주변장치 인터페이스, 전용 가속기를 하나의 반도체 다이에 통합해 시스템 기능을 칩 내부에서 수행하는 집적 아키텍처임
- **배경/필요성**: 모바일·임베디드 장치의 외부 I/O 전력과 보드 배선 면적을 줄이기 위해 기능을 한 다이에 통합할 필요가 있음

## Ⅱ. 특징

- 칩 간 I/O를 온칩 연결로 바꿔 외부 배선과 신호 전송 에너지를 줄임
- 통합 블록이 늘면 검증 범위와 타이밍 클로저 대상 경로가 함께 증가함
- CPU, GPU, NPU, ISP 같은 이기종 블록을 NoC와 공유 메모리 계층으로 연결함
- 재사용 IP와 하드웨어·소프트웨어 공동 설계로 기능별 구현 범위를 나눔

## Ⅲ. 종류 및 비교

| 판단 기준 | SoC | MPU 기반 보드 | SiP |
|:---|:---|:---|:---|
| 통합 경계 | 한 다이 내부 | 보드 위 여러 칩 | 한 패키지 내부 여러 다이 |
| 기능 변경 | 다이 재설계 필요 | 보드 부품 교체 가능 | 패키지 구성·다이 교체 가능 |
| 대표 용도 | 모바일·임베디드 | 산업·범용 제어 | 이기종 다이 패키징 |

> 요약: SoC는 한 다이에 기능을 통합하고 MPU 보드는 보드 부품, SiP는 패키지 내 다이 조합으로 기능을 구성함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 연산 클러스터 | CPU·GPU·NPU가 연산 성격별로 역할을 분담하며 제공 가능한 연산량을 결정함 |
| 온칩 인터커넥트 | AMBA·NoC가 블록 간 데이터를 전달하며 경로별 대역폭과 QoS를 제어함 |
| 메모리·캐시 계층 | DRAM 인터페이스·캐시·SRAM이 연산 블록의 데이터 공급률과 전력 사용량을 결정함 |
| 주변장치·전력 관리 | USB·PCIe·디스플레이와 전력 제어기가 외부 연결과 전력 상태 전환을 담당함 |

```text
+------------------+
| 연산 클러스터    |
+------------------+
         |
         v
+------------------+
| 온칩 NoC         |
+------------------+
      |       |
      v       v
+-----------+ +------------------+
| 메모리    | | 주변장치·전력 관리 |
+-----------+ +------------------+
```

> 요약: 연산 클러스터의 요청을 NoC가 메모리·주변장치로 전달하고 전력 관리 계층이 블록별 전력 상태를 제어함.

## Ⅵ. 실무 사례

1. AI SoC는 CPU·GPU·NPU의 메모리 대역폭을 NoC QoS로 배분하고 와트당 성능·대역폭 사용률을 확인함
2. 자동차 SoC는 검증된 IP를 재사용하고 블록·칩 단계로 검증해 기능 검증 커버리지·첫 실리콘 시험 통과율을 확인함

## Ⅶ. 결론

SoC는 외부 I/O 전력·보드 면적 감소와 NoC·메모리 병목을 함께 판단해 통합 범위를 결정해야 함.
