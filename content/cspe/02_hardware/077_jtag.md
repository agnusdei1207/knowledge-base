## 미리 알고가기

- JTAG는 칩과 보드를 테스트하고 디버깅하는 직렬 인터페이스 표준임
- TAP controller와 boundary scan chain이 핵심 구조임
- 개발 단계에는 유용하지만 양산 후 그대로 열어 두면 보안 위험이 큼

## Ⅰ. 개요

- **정의/개념**: JTAG는 칩과 보드의 내부 상태를 직렬 스캔 방식으로 읽고 쓰면서 boundary scan과 플래시 기록과 CPU halt, 메모리 점검을 수행하는 테스트·디버깅 인터페이스임
- **배경/필요성**: 고집적 보드는 물리 프로빙만으로 내부 신호와 납땜 불량과 레지스터 상태를 확인하기 어려우므로, 표준화된 내부 접근 경로가 필요함

## Ⅱ. 특징

- 칩 내부 레지스터와 핀 상태를 비침습적으로 검사할 수 있음
- 생산 테스트와 펌웨어 다운로드와 디버깅을 하나의 경로로 처리할 수 있음
- 직렬 스캔 기반이라 속도는 빠르지 않지만 접근 범위가 넓음
- 양산 장치에 남아 있으면 펌웨어 유출과 보안 우회 통로가 될 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | JTAG | SWD | UART 디버그 |
|:---|:---|:---|:---|
| 주 용도 | 보드 테스트와 CPU 디버깅과 플래시 기록을 넓게 처리함 | ARM 계열 디버깅을 상대적으로 단순한 배선으로 처리함 | 로그 출력과 콘솔 접근 위주로 사용함 |
| 하드웨어 접근 범위 | 레지스터와 메모리와 boundary scan까지 폭넓게 접근함 | 디버깅 접근은 넓지만 보드 테스트 범위는 JTAG보다 좁음 | 운영 로그와 명령 입력 수준으로 제한되는 경우가 많음 |
| 생산 테스트 적합성 | 납땜 불량과 회로 연결 검증에 유리함 | 디버깅 중심이라 생산 검사 활용은 제한적임 | 생산 테스트보다는 개발 편의에 가깝음 |
| 보안 유의점 | 양산 후 열어 두면 펌웨어 유출과 보안 우회 위험이 큼 | 디버그 포트 보호가 없으면 역시 보안 통로가 될 수 있음 | 콘솔 노출과 인증 부재가 운영 보안 문제로 이어질 수 있음 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| TAP Controller | TCK와 TMS 신호로 상태 기계를 제어해 명령과 데이터 경로를 선택함 |
| Boundary Scan Chain | 패키지 핀과 내부 레지스터를 직렬로 연결해 검사와 제어를 가능하게 함 |
| Debug Probe | 외부 호스트와 대상 보드 사이에서 명령과 데이터를 중계함 |
| CPU·플래시 접근 경로 | halt, single-step, 메모리 읽기, 펌웨어 기록 같은 실제 디버깅 기능을 제공함 |

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 프로브 연결    | --> | TAP 상태 선택  | --> | 스캔 데이터 이동 | --> | 테스트·디버그 수행 |
+-------------+     +-------------+     +-------------+     +-------------+
```

## Ⅴ. 원리 및 절차 흐름도

1. **프로브 연결**: TCK, TMS, TDI, TDO 신호를 대상 보드에 연결함
2. **TAP 상태 선택**: 상태 기계로 명령 레지스터와 데이터 레지스터 접근을 정함
3. **스캔 데이터 이동**: 명령과 데이터를 직렬 체인으로 밀어 넣고 읽어 냄
4. **테스트·디버그 수행**: boundary scan과 메모리 검사와 CPU 제어를 실행함

## Ⅵ. 실무 적용 및 유의점

1. 보드 양산 검사에서는 JTAG가 납땜 불량과 연결 오류를 빠르게 찾는 데 유용하지만 스캔 체인이 길어지면 테스트 시간이 급격히 늘어나므로 체인 분할과 패턴 최적화를 적용하고 검사 범위와 검사 시간과 출하 후 결함 발견률로 확인함
2. 출하 제품은 JTAG 포트가 남아 있으면 펌웨어 추출과 보안 우회 위험이 커지므로 퓨즈 잠금이나 인증된 디버그 해제 절차를 적용하고 디버그 잠금 적용률과 침투 시험 통과율과 비인가 접근 건수로 확인함

## Ⅶ. 결론

JTAG는 개발과 생산 테스트에 강력하지만 양산 이후에는 통제되지 않은 보안 통로가 될 수 있으므로 개방 범위를 엄격히 관리해야 함.
