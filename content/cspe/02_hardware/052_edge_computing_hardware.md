## Ⅰ. 개요
- 데이터가 생성되는 현장(Edge)에서 직접 연산을 수행하는 물리적 장치
- 저지연 처리 및 데이터 프라이버시 보호를 위한 필수 인프라

| 구분 | 내용 |
| --- | --- |
| 정의 | 로컬 접점에서 연산, 저장, 네트워킹을 수행하는 하드웨어 |
| 필요성 | 실시간 제어(자율주행), 대역폭 절감, 보안 강화 필요 |
| 출제의도 | 에지 환경의 제약 사항(전력, 공간) 및 특화 구조 이해 |

## Ⅱ. 구성요소
```
+------------------------------------------+
|  [ Edge Hardware ]                       |
| +---------+  +---------+  +------------+ |
| | AI Accel|  | Comm.   |  | Rugged     | |
| | (NPU/DSP)|  | (5G/Wi-Fi)| | Enclosure  | |
| +---------+  +---------+  +------------+ |
| [ Security Chip / TPM / Secure Element ] |
+------------------------------------------+
```
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| Edge AI SoC | 저전력 추론 전용 가속기가 통합된 칩셋 | 현장 지휘관 |
| Connectivity | 5G, LoRa 등 다양한 통신 모듈 및 안테나 | 통신 무전기 |
| Rugged Case | 열악한 외부 환경(온도, 습도) 견디는 하우징 | 특수 방호복 |
> 요약: 소형·저전력·고신뢰성 기반의 연산 및 통신 장치임.

## Ⅲ. 절차
```
[데이터 수집] -> [로컬 전처리] -> [에지 추론] -> [클라우드 전송]
```
1. 데이터 수집: 센서 및 카메라로부터 비정형 데이터를 실시간 획득함.
2. 로컬 전처리: 노이즈 제거, 데이터 정규화 등 가벼운 연산 수행함.
3. 에지 추론: 내장된 AI 가속기를 통해 실시간 판단 및 제어 수행함.
4. 선별적 전송: 분석 결과나 학습용 핵심 데이터만 클라우드로 전달함.
> 요약: 현장에서 즉각 처리하고 필요한 정보만 상위로 전달함.

## Ⅳ. 문제점
- 자원 제한: 전력 공급 및 냉각 장치 설치가 제한되어 성능 한계 존재함.
- 물리적 보안: 현장에 노출되어 있어 도난 및 물리적 해킹 위협에 취약함.

## Ⅴ. 개선방안
- 초저전력 설계: RISC-V 등 효율적 아키텍처 및 미세 공정 적용함.
- 신뢰 실행 환경: TEE, TPM 탑재를 통한 데이터 및 펌웨어 보호 강화함.

## Ⅵ. 전망
- AI-IoT(AIoT) 융합에 따라 자율형 에지 하드웨어 수요가 급증할 것임.
- 하드웨어 추상화(Container/K3s) 기반의 에지 관리 효율화가 핵심임.
