## Ⅰ. 개요
- 정의: 특정 지역에 분산 설치되어 환경 정보를 수집하고 무선으로 전송하는 자율망 하드웨어
- 배경: 사람이 접근하기 어려운 지역의 원격 모니터링 및 대규모 인프라 관리 필요
- 출제 의도: 센서 노드의 자원 제약(전력, 메모리) 및 애드혹(Ad-hoc) 통신 구조 이해

## Ⅱ. 구성요소
- ASCII 구조도
  [ Sensor Node ] -> [ Sensor Node ] -> [ Sink Node ]
         \               /                  |
          [ Sensor Node ]               [ Gateway ]

- 구성요소 표
| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| Sensor Node | 데이터 수집 및 중계 역할을 하는 소형 하드웨어 | 말단 보초병 |
| Sink Node | 네트워크의 최종 수집지로 데이터를 취합하는 노드 | 소대장 |
| Radio Trans | 데이터 송수신을 위한 저전력 무선 통신 모듈 | 무전기 |

- > 요약: 저가형, 저전력 노드들이 협력하여 정보를 전달하는 망 구조

## Ⅲ. 절차
- ASCII 흐름도
  [Sensing] -> [Processing] -> [Routing] -> [Multi-hop Trans]

1. 측정: 물리적 환경 변화를 감지하여 전기 신호로 변환 (ADC 수행)
2. 저전력 대기: 통신이 없을 때는 수면(Sleep) 모드로 전환하여 배터리 보존
3. 라우팅: 주변 노드 상태를 확인하여 최적의 전달 경로 결정
4. 멀티홉 전송: 직접 통신이 안 되는 먼 거리도 이웃 노드를 거쳐 Sink로 전달

- > 요약: 전력 소비를 최소화하기 위한 주기적 휴면과 협력적 중계 수행

## Ⅳ. 문제점
- 에너지 고갈: 배터리 교체가 어려워 노드 수명 종료 시 네트워크 단절 발생
- 통신 불안정: 장애물이나 전파 간섭으로 인한 패킷 손실 및 경로 재구성 부하

## Ⅴ. 개선방안
- 태양광/진동 발전: 하베스팅 기술을 통한 노드의 영구적 구동 시도
- 저전력 프로토콜: IEEE 802.15.4(ZigBee), 6LoWPAN 등 특화 규격 고도화

## Ⅵ. 전망
- 로드맵: 스마트 더스트(Smart Dust) 구현을 위한 초미세 노드 개발 및 AI 연계
- CSF: 대규모 노드(Massive WSN) 관리 소프트웨어와 고신뢰성 하드웨어 설계 확보
