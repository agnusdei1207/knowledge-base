## Ⅰ. 개요
- **정의**: 데이터센터·HPC 환경에서 RDMA 기반 초저지연 고대역폭 통신을 제공하는 직렬 네트워크 기술임
- **배경/필요성**: 이더넷의 프로토콜 스택 오버헤드가 HPC/AI 클러스터의 노드 간 통신 지연 요구를 충족하지 못하여, 커널 우회 전송 방식이 필요함
- **비유**: 택배(이더넷)가 매번 본사를 거치는 대신, 발신자가 수신자의 창고 문을 직접 열어 짐을 넣는 방식임

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| RDMA 동작 원리와 이더넷 대비 차이 | 커널 바이패스·제로카피 전송 | RoCE와 InfiniBand 네이티브 RDMA 구분 |

> 요약: 커널 우회 RDMA로 노드 간 초저지연 데이터 전송을 수행하는 HPC 네트워크임

## Ⅱ. 구성요소
```text
Host CPU -- HCA --[InfiniBand Link]--> IB Switch --> HCA -- Host CPU
                                          |
                                    Subnet Manager
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| HCA (Host Channel Adapter) | RDMA 엔진을 내장한 네트워크 어댑터로 커널 우회 송수신 처리 | 전용 우편함이 달린 자체 배달부 |
| IB Switch | InfiniBand 포트 간 패킷을 크레딧 기반 흐름 제어로 무손실 전달 | 교통 정체 없는 전용 교차로 |
| Subnet Manager | 서브넷 내 경로 설정·LID 할당·토폴로지 관리를 수행하는 중앙 제어 소프트웨어 | 도로 교통 관제 센터 |
| Queue Pair (QP) | 송신 큐·수신 큐 쌍으로 구성된 RDMA 통신의 논리적 종단점 | 발신함/수신함 한 쌍 |

> 요약: HCA-스위치-서브넷 매니저가 무손실 RDMA 패브릭을 구성함

## Ⅲ. 절차
```text
QP 생성 -> 메모리 등록 -> RDMA 요청 발행 -> 완료 통지
```
- 1단계: **QP 생성** — 통신 양단에서 송신 큐(SQ)와 수신 큐(RQ) 쌍을 생성하고 연결 정보를 교환함
- 2단계: **메모리 등록** — 전송할 버퍼를 HCA에 등록하여 가상-물리 주소 매핑을 고정(pin)함
- 3단계: **RDMA 요청 발행** — `RDMA Write` 또는 `RDMA Read` 요청을 SQ에 게시하면 HCA가 커널 개입 없이 원격 메모리에 직접 접근함
- 4단계: **완료 통지** — CQ(Completion Queue)에 완료 이벤트가 기록되어 애플리케이션이 전송 성공을 확인함

> 요약: QP 설정-메모리 핀-RDMA 전송-CQ 완료 순서로 제로카피 통신이 수행됨

## Ⅳ. 문제점
- **비용 부담**: HCA·스위치·케이블이 이더넷 대비 고가이므로 대규모 배포 시 인프라 비용이 급증함
- **서브넷 매니저 단일 장애점**: SM이 단일 인스턴스로 동작 시 장애 발생 시 전체 경로 설정이 불가능함
- **생태계 제한**: 이더넷 대비 관리 도구·모니터링 소프트웨어의 다양성이 낮아 운영 유연성이 부족함

> 요약: 고비용·SM 단일 장애점·운영 도구 부족이 도입 장벽임

## Ⅴ. 개선방안
1. 단기: 이더넷-InfiniBand 게이트웨이를 도입하여 기존 이더넷 인프라와 혼용함으로써 비용 부담 완화
2. 중기: Standby SM 이중화 구성과 자동 Failover를 적용하여 서브넷 매니저 단일 장애점 해소
3. 장기: UFM(Unified Fabric Manager) 등 통합 관리 플랫폼을 확대하여 생태계 제한 극복

> 요약: 게이트웨이 혼용-SM 이중화-통합 관리 플랫폼 순으로 개선함

## Ⅵ. 전망
- 발전 방향: NDR(400 Gbps)에서 XDR(800 Gbps)로 세대별 대역폭이 2배씩 증가하며 AI 학습 클러스터의 표준 패브릭으로 정착 중임
- 기술사적 판단: GPU 인터커넥트(NVLink, 056 참조)가 노드 내부를 담당하고 InfiniBand가 노드 간을 담당하는 2계층 구조가 AI 인프라의 기본 설계 패턴임
- 기술사 제언: 워크로드별 메시지 크기·빈도를 분석하여 이더넷 RoCE와 네이티브 InfiniBand 중 적절한 RDMA 방식을 선정할 필요
