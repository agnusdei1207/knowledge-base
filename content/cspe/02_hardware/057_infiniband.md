# 📖 【암기용】 개념 완전 이해

## 한눈에
- **개요**: 데이터센터와 슈퍼컴퓨터에서 노드(서버) 간 초고속, 초저지연 통신을 위해 개발된 컴퓨터 네트워킹 통신 표준
- **왜 필요한가**: 일반 이더넷(Ethernet)과 TCP/IP는 범용성은 좋지만 통신할 때마다 OS 커널이 개입하여 데이터 복사(오버헤드)를 하므로, 나노초(ns) 단위로 통신해야 하는 AI 클러스터에서는 치명적인 지연이 발생했다.
- **핵심 직관**: 이더넷이 화물(데이터)을 보낼 때 우체국(OS 커널)을 거쳐 검수를 받고 보내는 방식이라면, InfiniBand는 기업 전용 직통 우편 배달망(RDMA)을 깔아 양쪽 창고(메모리) 간에 물건을 직접 던져 넣는 방식이다.

## 핵심 용어 정리

| 용어/표기 | 의미 | 비유·예 |
|:---|:---|:---|
| RDMA (Remote Direct Memory Access) | CPU나 OS 개입 없이 원격지 서버의 메모리에 직접 데이터를 읽고 쓰는 기술 | 우체국 안 거치고 상대방 집 서랍에 물건 바로 넣기 |
| HCA (Host Channel Adapter) | InfiniBand 통신을 처리하는 전용 네트워크 카드(NIC) | 직통 우편 전담 하드웨어 처리반 |
| Subnet Manager (SM) | 네트워크 토폴로지 설정과 라우팅 경로를 중앙 제어하는 소프트웨어 | 전체 교통망 신호등과 경로를 통제하는 관제탑 |
| Kernel Bypass (커널 우회) | 네트워크 스택(TCP/IP)을 거치지 않고 앱이 하드웨어와 직접 소통하는 기법 | 복잡한 서류 결재(OS) 생략 |

## 깊이 이해
- **배경·문제의식**: 고성능 컴퓨팅(HPC) 환경에서는 수천 대의 서버가 작업을 잘게 쪼개어 연산한다. 서버 간 메시지 교환 시간이 연산 시간보다 길어지면 시스템 전체가 멈추는 병목이 생긴다.
- **작동 원리**: OS를 거치지 않는 '커널 바이패스'와 무손실(Lossless) 네트워크 아키텍처를 하드웨어(HCA) 수준에서 구현한다. 응용 프로그램이 HCA에 데이터 위치만 알려주면, 하드웨어가 원격지 서버 메모리로 패킷을 직접 밀어 넣는다(RDMA).
- **비유**: 회의 자료(데이터)를 돌릴 때, 비서를 거쳐(TCP/IP 커널) 사내 메일로 복사해서 돌리면 늦는다. InfiniBand는 발표자가 각자의 책상 위(메모리)에 바로 문서를 올려두는(RDMA) 가장 빠른 방식이다.
- **구체 예시**: 최신 NDR(400Gbps) InfiniBand 스위치를 활용하면, 수만 장의 H100 GPU 클러스터가 1마이크로초(µs) 안팎의 지연시간(Latency)으로 데이터를 주고받으며 거대 AI 모델을 학습할 수 있다.
- **흔한 오해·주의점**: "이더넷으로 다 대체될 것이다"라는 전망이 오래전부터 있었고, RoCE(RDMA over Converged Ethernet)가 부상 중이나, 완전 무손실과 극단적 저지연을 요구하는 초거대 AI 클러스터에서는 여전히 InfiniBand가 독보적이다.

## 연결 개념
- RDMA (원격 직접 메모리 접근)
- RoCE (이더넷 위에서 동작하는 RDMA)
- HPC (고성능 컴퓨팅) / NVLink

# 📝 【답안용】 시험 답안 템플릿

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: InfiniBand는 컴퓨팅 노드 간 통신에서 OS 커널 개입을 제거하고 메모리를 직접 접근(RDMA)하여, 마이크로초 단위의 초저지연과 초고대역폭을 제공하는 스위치 기반 네트워크 표준이다.
> 2. **가치**: 무손실(Lossless) 하드웨어 흐름 제어와 커널 바이패스(Kernel Bypass)를 통해 CPU 부하(Overhead)를 제로에 가깝게 낮춰, 고성능 연산 자원이 네트워크 처리 대신 순수 연산에만 집중하도록 보장한다.
> 3. **판단 포인트**: AI 인프라 구축 시, 구축 비용이 저렴하고 범용적인 이더넷(RoCEv2) 환경과 독점적이지만 극한 성능을 보장하는 InfiniBand 환경 간의 TCO 및 트래픽 특성(Tail Latency) 트레이드오프 판단이 필수적이다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| HPC 및 AI 클러스터 네트워크의 본질 이해 | RDMA 메커니즘, 커널 바이패스, CPU 오프로드 | 단순한 속도(Gbps) 차이 위주로 설명 (구조적 차이 누락) |
| InfiniBand 아키텍처 및 무손실 제어 원리 | HCA(Host Channel Adapter), Subnet Manager, 크레딧 기반 흐름 제어 | TCP/IP의 윈도우 기반 혼잡 제어 방식과 혼동 |
| 대체 기술(Ethernet/RoCE)과의 비교 판단 | RoCEv2 인프라 비용 이점 vs InfiniBand 극저지연 및 무손실 신뢰성 | 무조건 InfiniBand만 정답이라고 단정하는 논조 |

> 요약: InfiniBand의 핵심은 '넓은 대역폭'뿐만 아니라 OS 스택 처리를 완전히 없앤 '제로 복사(Zero-copy) 기반의 꼬리 지연(Tail Latency) 제거'에 있다.

---

## Ⅰ. 개요 및 필요성

- 개요: 슈퍼컴퓨터(HPC) 및 대규모 AI 클러스터 환경에서 노드 간 병목 없는 연결을 위해 설계된 스위치 패브릭(Switched Fabric) 통신 아키텍처
- 배경: GPU 코어 집적도 급증으로 통신 대역폭 요구는 치솟으나, 기존 TCP/IP 소켓 통신은 다중 문맥 교환(Context Switching)과 메모리 복사로 통신 오버헤드 한계 노출
- 필요성: 수만 대의 연산 노드가 동기화(All-Reduce) 시 발생하는 밀리초 단위의 통신 지연을 마이크로초 수준으로 단축하여 시스템 멈춤(Stall) 방지 필수

---

## Ⅱ. 구조 및 구성요소

```text
[Node A: Memory]                        [Node B: Memory]
      |                                        |
  Application (Zero-Copy)                   Application
      |                                        |
 [ HCA (RDMA Offload) ] <--- IB Switch ---> [ HCA (RDMA Offload) ]
                                |
                         [ Subnet Manager ] (라우팅 통제)
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| HCA (Host Channel Adapter) | 호스트 쪽에 장착되어 RDMA 연산을 하드웨어로 오프로딩하는 인터페이스 카드 | 이더넷의 NIC에 해당 |
| InfiniBand Switch | 패킷 충돌 없이 노드 간 연결을 중계하는 전용 무손실 스위치 | 크레딧 기반(Credit-based) 흐름 제어 적용 |
| Subnet Manager (SM) | 네트워크 패브릭 검색, 토폴로지 관리, 라우팅 테이블 생성 담당 | 중앙 집중형 SDN 컨트롤러 역할 |
| Queue Pair (QP) | HCA 내부에 생성되는 송신(Send)과 수신(Receive) 큐 쌍 | 응용 프로그램과 HCA 간 직접 소통 채널 |

> 요약: HCA가 큐 쌍(QP)을 통해 앱과 하드웨어를 직결하고, Subnet Manager가 중앙에서 경로를 통제하여 무손실 고속 도로망을 형성한다.

---

## Ⅲ. 동작원리 및 흐름도

```text
통신 채널(QP) 생성 -> OS 커널 개입 우회 -> 메모리 핀(Pin) 고정 -> RDMA 송신/수신 -> 무손실 스위칭
Queue Pair Setup      Kernel Bypass          Memory Registration   Zero-copy Transfer    Credit Flow Control
```

- 1단계 [큐 설정]: 통신할 두 노드의 응용 프로그램 간 통신 채널인 Queue Pair를 생성하고 초기화
- 2단계 [메모리 등록]: 전송할 응용 프로그램의 메모리 영역(Buffer)을 OS가 페이징(Swap)하지 못하게 물리 주소로 고정(Pinning)
- 3단계 [제로 카피 전송]: 응용 프로그램이 HCA에 전송 명령(Work Request)을 내리면, HCA 하드웨어가 메모리를 직접 읽어(DMA) 패킷화 전송
- 4단계 [크레딧 제어]: 스위치 간 송신 전에 수신 측 버퍼 공간(Credit)을 확인하여 패킷 유실(Drop) 원천 차단

> 요약: 통신 준비 단계에서만 OS가 관여하고 실 전송 시 커널을 완전히 배제(Kernel Bypass)하여 CPU 개입 없이 메모리 간 직접 데이터 이동(Zero-copy)을 실현한다.

---

## Ⅳ. 특징
- 극강의 저지연(Ultra-low Latency): 커널 우회 및 하드웨어 가속을 통해 노드 간 전송 지연을 1µs(마이크로초) 내외로 억제하여 꼬리 지연(Tail Latency) 해소
- 높은 CPU 효율: 프로토콜 스택 처리를 전적으로 HCA가 전담하여 CPU 점유율을 1% 미만으로 유지, 남은 자원을 온전히 연산에 투입
- 완벽한 무손실(Lossless): 크레딧 기반 흐름 제어 메커니즘으로 네트워크 혼잡 시 패킷 드롭 재전송으로 인한 폭발적 지연 증가 방지

> 요약: 신뢰성 높은 고속망을 제공하지만, 이더넷과 호환되지 않는 폐쇄적 생태계와 전용 HCA/스위치 도입에 따른 막대한 구축 비용이 단점이다.

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | TCP/IP 이더넷 | InfiniBand | RoCE v2 | 선택 기준 |
|:---|:---|:---|:---|:---|
| 프로토콜 처리 | OS 커널(CPU 부하 심함) | 하드웨어 HCA (CPU 우회) | 하드웨어 RNIC (이더넷 위) | 응용 프로그램의 지연 민감도 |
| 흐름 제어 | 패킷 드롭 후 재전송(TCP) | 크레딧 기반 완전 무손실 | PFC 적용 무손실 (설정 복잡) | 트래픽 폭증(Incast) 시 안정성 |
| 도입 생태계 | 저비용, 최고 범용성 | 고비용, AI/HPC 특화망 | 중비용, 기존 이더넷 스위치 재사용 | 인프라 TCO 및 엔지니어 역량 |

> 요약: 비용과 범용성 측면에서 RoCEv2(이더넷 기반 RDMA)가 맹추격 중이나, 수만 대 규모의 클러스터 튜닝과 궁극적 성능 안정성은 InfiniBand가 압도한다.

**리스크·대응 (기본 불릿):**
- 벤더 락인 및 조달 리스크: NVIDIA(Mellanox 인수)가 글로벌 시장을 사실상 독점하여 단가 통제 불가 및 수급 지연 발생 → 듀얼 벤더 전략 불가 시 개방형 이더넷(RoCEv2) 스위치로 아키텍처 다변화 이원 검토 (지표: 인프라 조달 리드타임)
- Subnet Manager 단일 장애점: 수만 노드 구성 시 중앙 집중식 SM 소프트웨어가 부하를 못 견디거나 다운 시 패브릭 전면 마비 → 다중 스탠바이(Active-Standby) SM 구성 및 계층형 관리 노드 분리 (지표: 패브릭 재구성 시간)
- 케이블링 밀도 및 발열 제한: 팻 트리(Fat-tree) 토폴로지 구성 시 상단 스위치 배선 폭증과 광트랜시버 발열 심화 → 스위치 내장형 랙(Rack) 단위 액체 냉각(Liquid Cooling) 일괄 적용 (지표: 랙당 스위치 소비 전력)

**도입 후 점검 지표:**
- 네트워크 지연(Latency): 마이크로초(µs) — Ping-pong 테스트를 통한 노드 간 왕복 지연시간 측정
- 유효 대역폭 활용률(Goodput): % — 패킷 오버헤드와 재전송을 제외한 순수 페이로드 전송 비율 (InfiniBand는 통상 90% 이상 유지 목표)

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 대규모 LLM 팻 트리 토폴로지 구축: 10,000장 이상의 GPU 통신 시 병목이 없도록 논블로킹(Non-blocking) 팻 트리 3단 위상 구조로 InfiniBand 스위치 망 구성
2. GPU Direct RDMA 활성화: PCIe 스위치를 통과하는 GPU 간 통신(Scale-out) 시 호스트 CPU 메모리를 경유하지 않고 HCA 패킷이 GPU VRAM에 바로 꽂히는 기술 적용
3. 스토리지 가속(NVMe-oF) 통합: 연산 노드뿐만 아니라 AI 학습 데이터를 공급하는 올플래시 스토리지망도 InfiniBand 기반 NVMe over Fabrics로 통합해 입출력 병목 원천 제거

**결론 (2줄):**
- 기술사 판단: InfiniBand는 단순한 통신 케이블이 아니라 거대 AI 클러스터를 논리적인 단일 슈퍼컴퓨터로 엮어내는 핵심 아키텍처 백본이다.
- 향후 방향: 오픈 네트워킹을 지향하는 Ultra Ethernet Consortium(UEC)의 진영 확장으로 향후 InfiniBand와 차세대 이더넷 간의 극한 트래픽 제어 주도권 경쟁이 심화될 것이다.
