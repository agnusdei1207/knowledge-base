## Ⅰ. 개요
- **정의**: SRAM은 플립플롭(6T) 기반 고속 메모리이고, DRAM은 캐패시터(1T1C) 기반 대용량 메모리임
- **배경/필요성**: 캐시에는 빠른 접근이, 주기억장치에는 높은 집적도가 요구되므로 용도에 따라 두 메모리를 분리 적용할 필요
- **비유**: SRAM은 스프링이 달린 스위치(한번 설정하면 유지)이고, DRAM은 물이 새는 컵(주기적으로 리필 필요)과 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 구조적 차이와 용도 매핑 | 6T vs 1T1C, 리프레시 유무 | SRAM도 전원 차단 시 데이터 소멸(휘발성) 명시 필요 |

> 요약: 구조·속도·집적도가 다른 두 휘발성 메모리를 용도에 따라 캐시와 주기억에 배치함

## Ⅱ. 구성요소
```text
SRAM Cell (6T)                    DRAM Cell (1T1C)
+-------+-------+                 +-------+
| T1    |    T2 |                 |  T1   |
|  \   / \   /  |                 +---+---+
|   WL    WL    |                     |
|  BL    /BL    |                 +---+---+
| T3-T4  T5-T6  |                | Cap.  |
+-------+-------+                +-------+
  리프레시 불필요                   리프레시 필요
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| SRAM 셀(6T) | 6개 트랜지스터가 래치를 구성하여 전원 공급 중 데이터 유지 | 스프링 스위치 |
| DRAM 셀(1T1C) | 1개 트랜지스터 + 1개 캐패시터로 전하 유무로 비트 저장 | 물이 새는 컵 |
| 워드라인(WL) | 행 선택 신호로, 해당 행의 셀을 비트라인에 연결 | 서랍 열쇠 |
| 비트라인(BL) | 셀 데이터를 읽거나 쓰는 데이터 전송 경로 | 컨베이어 벨트 |
| 센스 앰프 | DRAM에서 캐패시터의 미세 전하를 증폭하여 0/1 판별 | 돋보기 |

> 요약: SRAM은 6T 래치, DRAM은 1T1C 캐패시터 구조이며, 센스 앰프·워드라인·비트라인이 공통 구성임

## Ⅲ. 절차
```text
[DRAM 읽기 절차]
행 주소 입력 --> 워드라인 활성 --> 캐패시터 전하 비트라인 전달
     --> 센스 앰프 증폭 --> 데이터 출력 --> 프리차지(재충전)

[SRAM 읽기 절차]
행 주소 입력 --> 워드라인 활성 --> 래치 상태 비트라인 출력
     --> 차동 감지 --> 데이터 출력 (프리차지 불필요)
```
- 1단계: 행 주소 디코딩 후 워드라인을 활성화하여 해당 행의 셀을 비트라인에 연결
- 2단계: DRAM은 캐패시터 전하를, SRAM은 래치 상태를 비트라인으로 전달
- 3단계: DRAM은 센스 앰프로 미세 전하를 증폭하고, SRAM은 차동 비트라인으로 직접 판별
- 4단계: DRAM은 읽기 시 파괴된 전하를 프리차지(재기록)하고, SRAM은 별도 복원 불필요

> 요약: 두 메모리 모두 워드라인 활성→비트라인 전달 순이나, DRAM은 증폭·재충전 단계가 추가됨

## Ⅳ. 문제점
- SRAM 면적 비효율: 셀당 6개 트랜지스터로 집적도가 낮아 대용량 구현 시 칩 면적·비용 급증
- DRAM 리프레시 오버헤드: 수십 ms마다 전 행을 리프레시해야 하므로 대역폭의 5~10%를 리프레시에 소모
- DRAM 접근 지연: 센스 앰프 증폭·프리차지 과정으로 SRAM 대비 5~10배 느린 접근 시간 발생

> 요약: SRAM은 면적·비용, DRAM은 리프레시 오버헤드·접근 지연이 핵심 제약임

## Ⅴ. 개선방안
1. 단기: FinFET 공정 미세화로 SRAM 셀 면적을 축소하여 캐시 용량 대비 칩 면적 절감
2. 중기: DRAM 리프레시 간격 최적화(온도 감응형 가변 리프레시)로 리프레시 대역폭 소모 감소
3. 장기: 차세대 비휘발성 메모리(MRAM, ReRAM)를 SRAM/DRAM 일부 대체하여 지연·면적 동시 개선

> 요약: 공정 미세화 → 리프레시 최적화 → 차세대 메모리 도입 순으로 양쪽 한계를 보완함

## Ⅵ. 전망
- 발전 방향: 3D 적층 SRAM(V-Cache)과 HBM(030 참조) 적층 DRAM이 면적·대역폭 한계를 동시 극복 중
- 기술사적 판단: AI 가속기의 온칩 SRAM 용량 확대와 HBM 대역폭 수요가 두 메모리의 발전을 견인함
- 기술사 제언: 워크로드 특성에 맞는 SRAM/DRAM 용량 비율 설계 역량이 시스템 성능 결정에 핵심임
