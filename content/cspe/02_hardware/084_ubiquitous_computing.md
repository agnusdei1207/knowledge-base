## Ⅰ. 개요
- 정의: 시간, 장소에 구애받지 않고 네트워크에 접속하여 서비스를 이용하는 컴퓨팅 환경
- 배경: 소형화, 무선 통신 기술 발전 및 상황 인식(Context Awareness) 기반 서비스 요구
- 출제 의도: 하드웨어의 비가시성(Invisibility) 및 편재성(Pervasiveness) 구현 기술 이해

## Ⅱ. 구성요소
- ASCII 구조도
  [ Sensor ] <--- Wireless ---> [ Cloud / Edge ]
      |                              |
  [ Context ] <--- Interaction ---> [ User Device ]

- 구성요소 표
| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| MEMS | 초소형 기계/전기 시스템으로 구현된 센서/액추에이터 | 미세 감각기관 |
| SoC | 연산, 통신, 메모리를 하나의 칩에 통합한 모듈 | 두뇌 세트 |
| Energy Harvest | 주변 열, 진동, 빛으로부터 전력을 스스로 생산 | 자급자족 발전 |

- > 요약: 도처에 숨어서 조용히 정보를 수집하고 처리하는 Calm Technology 지향

## Ⅲ. 절차
- ASCII 흐름도
  [Sensing] -> [Pre-processing] -> [Wireless Trans] -> [Context Reasoning]

1. 상황 감지: 온도, 조도, 위치, 움직임 등 환경 데이터를 실시간 수집
2. 저전력 처리: 임베디드 프로세서에서 필요한 정보만 추출하여 가공
3. 매끄러운 통신: 사용자의 개입 없이 근거리 무선망(BLE, ZigBee)을 통해 전송
4. 적응형 서비스: 수집된 상황 정보를 바탕으로 사용자에게 최적화된 결과 제공

- > 요약: 사용자가 인식하지 못하는 사이 정보가 흐르고 서비스가 실행됨

## Ⅳ. 문제점
- 배터리 한계: 수많은 기기에 전원을 공급하고 관리하는 물리적 어려움
- 보안 및 프라이버시: 도처에 깔린 센서로 인한 개인정보 유출 위험 극대화

## Ⅴ. 개선방안
- 무전원 센서: RF 에너지를 수확하여 배터리 없이 동작하는 반도체 도입
- 연합 학습(FL): 기기 내에서 데이터를 처리하고 결과만 공유하여 프라이버시 보호

## Ⅵ. 전망
- 로드맵: IoT를 넘어 만물지능인터넷(AIoE)으로 진화하여 초연결 사회 구현
- CSF: 하드웨어의 초소형화와 함께 기기 간 자율 협업 프로토콜 표준화 선점 필수
