## 미리 알고가기

- DAS는 서버에 직접 붙는 블록 스토리지임
- NAS는 네트워크를 통해 파일 단위로 공유하는 스토리지임
- SAN은 전용 네트워크로 블록 장치를 제공하는 스토리지 구조임
- LUN(Logical Unit Number)은 스토리지 장치·배열이 호스트에 노출하는 논리 블록 장치의 식별 단위임

## 작성 근거(검토용)

- DAS·NAS·SAN은 접근 단위, 지연, 장애 범위, 관리 방식을 핵심 축으로 설명함
- 비교표는 세 구조의 연결·관리 방식, 접근 단위, 대표 적용을 대비함
- 실무 판단은 파일 연산 지연·동시 사용자 수와 다중 경로 절체 시간·복구 성공률로 검증함

## Ⅰ. 개요

- **정의/개념**: DAS와 NAS와 SAN은 서버와 저장장치를 연결하는 위치와 프로토콜과 접근 단위를 기준으로 구분하는 대표적인 스토리지 계층 구조임
- **배경/필요성**: 업무별 접근 단위·공유 범위·장애 경로를 충족하기 위해 DAS·NAS·SAN의 선택 기준이 필요함

### 쉽게 이해하기 (학습용)
- 내 방 서랍(DAS), 사무실 공유 파일 캐비닛(NAS), 은행 전용 금고실(SAN)처럼 저장 위치와 접근 방식이 다른 것과 같음

## Ⅱ. 특징

- DAS는 서버가 블록 장치를 직접 소유해 네트워크 홉 없이 접근함
- NAS는 파일시스템·권한 관리를 스토리지에서 제공하고 IP 네트워크를 공유함
- SAN은 전용 패브릭에서 블록 장치와 다중 경로를 제공함
- 선택 기준은 용량보다 접근 단위와 지연과 장애 범위와 관리 방식임

### 쉽게 이해하기 (학습용)
- 내 서랍은 내가 바로 열지만, 공유 캐비닛은 사무실 규칙을 거쳐야 하고, 전용 금고실은 별도 통로와 이중 잠금까지 갖춘 것과 같음

## Ⅲ. 종류 및 비교

| 판단 기준 | DAS | NAS | SAN |
|:---|:---|:---|:---|
| 연결·관리 방식 | 서버 내부·외부 포트에 직접 연결되어 서버가 장치를 직접 소유·관리함 | IP 네트워크로 연결되고 파일시스템·권한을 NAS가 관리함 | 전용 스토리지 네트워크로 연결되고 LUN과 경로를 패브릭에서 관리함 |
| 접근 단위 | 블록 단위로 직접 접근함 | 파일 단위로 공유함 | 블록 단위로 공유함 |
| 대표 적용 | 단일 서버 DB·부트 디스크 | 문서 공유·파일 백업 | 가상화 데이터스토어·이중 경로 DB 볼륨 |

> 요약: DAS는 직접 연결·블록 접근, NAS는 네트워크 연결·파일 공유, SAN은 전용 패브릭 연결·블록 공유로 구분함.

### 쉽게 이해하기 (학습용)
- 서랍은 내가 직접 관리하는 낱개 물건, 캐비닛은 사무실이 관리하는 서류 뭉치, 금고실은 전용 통로로 관리되는 귀중품 박스와 같음

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 호스트 서버 | 애플리케이션이 파일시스템 또는 블록 장치로 I/O를 발생시킴 |
| 연결 패브릭 | SATA와 Ethernet과 FC 같은 경로가 지연과 가용성을 결정함 |
| 스토리지 컨트롤러 | RAID와 캐시와 LUN과 파일 공유 기능을 제공해 성능과 보호 수준을 좌우함 |
| 관리 계층 | 권한과 백업과 복구와 용량 정책을 통합 관리해 운영 난도를 결정함 |

> 요약: 호스트 I/O는 DAS의 직접 경로, NAS의 파일 공유 경로, SAN의 블록 패브릭 경로 중 하나를 거쳐 스토리지에 전달됨.

### 쉽게 이해하기 (학습용)
- 물건을 찾는 사람(호스트 서버), 서랍·복도·전용 통로 같은 연결 경로(연결 패브릭), 물건을 정리·보호하는 관리인(스토리지 컨트롤러), 출입 권한과 백업 규정을 정하는 총무팀(관리 계층)으로 구성됨

## Ⅵ. 실무 사례

1. 문서 협업 플랫폼은 NAS의 파일 권한·공유 기능을 적용하고 p99 파일 연산 지연·동시 사용자 수를 확인함
2. 가상화 클러스터는 SAN 다중 경로와 장애 조치를 적용하고 경로 절체 시간·복구 성공률을 확인함

### 쉽게 이해하기 (학습용)
- 문서 공유 사무실은 공유 캐비닛 규칙을 적용해 동시 이용자를 관리하고, 중요 서버 클러스터는 금고실의 이중 통로가 끊기지 않는지 점검하는 것과 같음

## Ⅶ. 결론

- 스토리지는 접근 단위·공유 범위·지연 한도·장애 경로에 따라 DAS·NAS·SAN 중 하나를 선택하는 계층 구조임
- 단일 서버 전용 업무는 DAS로, 다중 사용자 파일 공유는 NAS로, 이중 경로가 필요한 블록 볼륨은 SAN으로 분리하고 백업·절체 책임을 관리 계층에 명확히 둬야 함

### 쉽게 이해하기 (학습용)
- 내 서랍, 공유 캐비닛, 전용 금고실 중 무엇을 쓸지는 물건의 접근 빈도와 공유 범위, 잠기면 누가 열어줄지로 정하는 것과 같음
