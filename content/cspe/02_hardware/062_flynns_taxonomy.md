## 미리 알고가기

- Flynn 분류는 명령 스트림 수와 데이터 스트림 수를 기준으로 병렬 구조를 나누는 틀임
- SISD, SIMD, MISD, MIMD가 기본 네 범주임
- 데이터 병렬(Data Parallelism)과 작업 병렬(Task Parallelism): 데이터 병렬은 같은 연산을 여러 데이터에 동시 적용하고, 작업 병렬은 서로 다른 작업을 독립적으로 동시 수행함
- 현대 시스템은 한 장비 안에서도 계층별로 여러 범주가 섞일 수 있음

## 작성 근거(검토용)

- Flynn 분류는 명령 스트림 수와 데이터 스트림 수로 SISD, SIMD, MISD, MIMD를 구분함
- 비교표는 명령·데이터 스트림 수, 제어 구조, 대표 구조를 기준으로 네 범주를 정리함
- 실무 판단은 혼합 구조의 계층별 분류와 MISD 적용 범위로 구체화함

## Ⅰ. 개요

- **정의/개념**: Flynn 분류는 명령·데이터 스트림의 단일·다중 조합으로 병렬 구조를 SISD·SIMD·MISD·MIMD로 구분하는 체계임
- **배경/필요성**: 멀티코어 CPU·GPU·클러스터의 데이터 병렬성과 작업 병렬성을 구분하기 위해 명령·데이터 흐름 기준이 필요함

### 쉽게 이해하기 (학습용)
- 요리사(명령)와 재료(데이터)가 각각 하나냐 여럿이냐를 보고 병렬 구조를 네 갈래로 나누는 것과 같음

## Ⅱ. 특징

- 명령 흐름과 데이터 흐름의 단일·다중 조합으로 데이터 병렬과 작업 병렬을 구분함
- 스트림 수만 분류하므로 메모리 모델·인터커넥트·동기화 병목은 별도로 분석해야 함
- GPU 클러스터 같은 혼합 구조는 노드 내부와 노드 사이를 분리해 분류함

### 쉽게 이해하기 (학습용)
- 레시피(명령)와 재료(데이터) 개수 조합만 보고 나누며, 주방이 얼마나 붐비는지는 따로 살펴야 함
- 요리사 팀(GPU) 안과 여러 주방(클러스터) 사이는 층을 나눠 각각 다시 분류함

## Ⅲ. 종류 및 비교

| 판단 기준 | SISD | SIMD | MISD | MIMD |
|:---|:---|:---|:---|:---|
| 명령·데이터 스트림 수 | 1·1 | 1·다수 | 다수·1 | 다수·다수 |
| 제어 구조 | 단일 명령·단일 데이터 | 한 명령을 여러 처리 요소에 배포 | 여러 명령이 같은 데이터에 작용 | 처리 요소별 독립 명령·데이터 |
| 대표 구조 | 단일 코어 순차 처리 | 벡터 유닛·GPU 레인 | 이종 연산을 중복 수행하는 내결함 구조 | 멀티코어·멀티소켓·클러스터 |

> 요약: Flynn 분류는 명령·데이터 흐름 수로 병렬 구조를 구분하며, 메모리·통신·동기화 병목은 별도로 분석해야 함.

### 쉽게 이해하기 (학습용)
- 요리사 한 명이 재료 하나만 다루면 SISD, 같은 레시피로 여러 재료를 한 번에 다루면 SIMD임
- 여러 요리사가 같은 재료를 각자 다르게 검증하면 MISD, 요리사 여럿이 각자 다른 재료·레시피로 일하면 MIMD임

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 명령 스트림 | 제어 장치가 동시에 내보내는 명령 흐름 수이며 구조 분류의 첫 기준이 됨 |
| 데이터 스트림 | 명령이 적용되는 데이터 집합 수이며 데이터 병렬성 판단의 기준이 됨 |
| 처리 요소 | 실제 연산을 수행하는 코어·레인·노드이며 스트림 조합이 구현되는 대상임 |
| 분류 행렬 | 명령과 데이터의 단일·다중 조합으로 SISD·SIMD·MISD·MIMD를 판정함 |

> 요약: 구조를 관찰해 명령 흐름과 데이터 흐름 수를 세면 Flynn 분류로 정리할 수 있음.

### 쉽게 이해하기 (학습용)
- 레시피 수와 재료 수를 세고, 실제 일하는 요리사(처리 요소)를 확인한 뒤 조합표에 대입하면 범주가 정해짐

## Ⅵ. 실무 사례

1. GPU 클러스터는 GPU 내부를 SIMD, 서버 노드를 MIMD로 분류하고 장치 사용률·노드 간 통신량을 확인함
2. 내결함 제어기는 같은 센서 입력을 여러 연산기로 처리하고 결과 일치율·불일치 검출 시간을 확인함

### 쉽게 이해하기 (학습용)
- GPU 안에서는 같은 레시피를 여러 접시에 동시에 쓰고, 서버 여러 대는 각자 다른 주문을 처리하며, 안전 설비는 같은 재료를 여러 요리사가 따로 검증함

## Ⅶ. 결론

- Flynn 분류는 명령 스트림과 데이터 스트림의 단일·다중 조합으로 병렬 구조를 SISD·SIMD·MISD·MIMD로 구분하는 출발점 틀임
- GPU 클러스터처럼 혼합 구조는 노드 내부와 노드 사이를 분리해 분류하고, 메모리·통신·동기화 병목은 별도로 분석해야 함

### 쉽게 이해하기 (학습용)
- 주방 전체를 다 설명하진 못하지만, 지금 하는 일이 같은 레시피의 반복인지 서로 다른 주문 처리인지부터 구분하게 해줌
