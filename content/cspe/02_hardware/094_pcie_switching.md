## 미리 알고가기

- PCIe는 점대점(point-to-point) 방식의 고속 직렬 I/O 인터페이스임
- Root Complex는 CPU 쪽 PCIe 트리의 시작점임
- 엔드포인트(endpoint)는 GPU·NVMe·NIC처럼 PCIe 트리의 말단에 연결되는 장치임
- PCIe 스위치는 상위 포트와 여러 하위 포트 사이에서 TLP를 라우팅함
- ACS는 장치 간 DMA 경로를 분리하는 접근 제어 기능임
- TLP는 PCIe 계층에서 주소·데이터·완료 정보를 전달하는 패킷임
- 과가입(oversubscription)은 하위 포트의 합산 요구 대역폭이 상위 링크 대역폭을 넘는 상태임
- AER은 PCIe 링크와 장치의 오류를 보고하는 확장 오류 보고 기능임

## 작성 근거(검토용)

- PCIe 스위칭은 상·하위 포트, TLP 라우팅, 상위 링크 공유, ACS 격리를 핵심 축으로 설명함
- 비교표는 직접 연결과 스위칭의 장치 수, 홉, 대역폭 공유, 운영 정책을 대비함
- 실무 판단은 상위 링크 사용률·과가입 비율과 DMA 격리 시험 통과율·비인가 DMA 차단률로 검증함

## Ⅰ. 개요

- **정의/개념**: PCIe 스위칭 아키텍처는 Root Complex와 여러 엔드포인트 사이에 스위치를 두어 상위 링크를 분기하고 TLP를 라우팅하는 I/O 확장 구조임
- **배경/필요성**: 제한된 CPU PCIe 레인에 여러 GPU·NVMe·NIC를 연결하기 위해 스위치 기반 분기 구조가 필요함

## Ⅱ. 특징

- 상위 링크를 여러 하위 포트로 분기해 CPU 레인 수보다 많은 엔드포인트를 연결함
- PCIe의 점대점 구조를 유지하면서 패킷 라우팅과 오류 보고를 수행함
- 상위 링크를 공유하므로 과가입이 발생할 수 있음
- P2P·ACS·Hot-plug 지원 여부가 장치 간 경로와 DMA 격리·교체 절차를 결정함

## Ⅲ. 종류 및 비교

| 판단 기준 | 직접 연결 | PCIe 스위칭 |
|:---|:---|:---|
| 장치 수 | CPU Root Port와 레인 수로 제한됨 | 하위 포트 수만큼 엔드포인트를 분기함 |
| 지연 경로 | Root Complex와 엔드포인트를 직접 연결함 | 스위치 홉과 버퍼를 거쳐 엔드포인트에 연결함 |
| 대역폭 구조 | 장치별 전용 경로 확보가 쉬움 | 상위 링크 공유로 병목과 과가입이 생길 수 있음 |
| 운영 기능 | Root Complex가 직접 장치를 열거·관리함 | 스위치의 P2P·ACS·오류 보고 정책을 추가 관리함 |

> 요약: 스위칭은 장치 수를 늘리지만 스위치 홉과 상위 링크 공유, ACS 격리 정책을 추가함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Root Complex | 시스템 메모리 공간과 PCIe 계층을 연결하는 상위 기준점임 |
| upstream port | 스위치가 CPU 쪽과 통신하는 상위 공유 경로로 전체 장치 집합의 병목이 될 수 있음 |
| downstream port | GPU와 NVMe와 NIC 같은 endpoint를 개별 포트로 수용함 |
| 라우팅·격리 로직 | TLP 전달과 ACS와 오류 보고를 담당해 성능과 DMA 경계를 함께 좌우함 |

> 요약: 상위 포트가 공유 링크를 제공하고 하위 포트와 라우팅·격리 로직이 엔드포인트별 TLP 경로를 분리함.

## Ⅴ. 원리 및 절차 흐름도

1. **장치 열거**: 펌웨어와 OS가 스위치 하위 endpoint를 탐색하고 주소 공간을 할당함
2. **주소 라우팅**: 스위치가 TLP 목적지에 따라 적절한 포트를 선택함
3. **패킷 전달**: flow control과 레인 속도 규칙에 따라 데이터를 전달함
4. **오류·격리 관리**: AER과 ACS와 링크 상태 감시로 장애와 DMA 경계를 통제함

> 요약: 열거된 엔드포인트의 TLP를 주소로 라우팅하고 AER·ACS로 오류와 장치 간 DMA 경계를 관리함.

## Ⅵ. 실무 사례

1. GPU 확장 서버는 워크로드 대역폭에 맞춰 스위치 포트를 배치하고 상위 링크 사용률·과가입 비율을 확인함
2. 가상화 서버는 ACS와 IOMMU 그룹을 검증하고 DMA 격리 시험 통과율·비인가 DMA 차단률을 확인함

## Ⅶ. 결론

- PCIe 스위칭은 엔드포인트 수와 상위 링크 대역폭을 함께 산정하고 P2P·ACS·AER 정책으로 경로와 격리를 검증해야 함
