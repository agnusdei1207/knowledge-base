# 📖 【암기용】 개념 완전 이해
> 목적: DRAM과 SRAM을 처음 봐도 왜 캐시는 SRAM을, 주기억장치는 DRAM을 쓰는지 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: DRAM은 커패시터에 전하를 저장하는 방식, SRAM은 플립플롭 회로로 상태를 유지하는 방식의 휘발성 메모리
- **왜 필요한가**: 두 방식은 셀 구조가 달라 속도·밀도·비용이 크게 갈리므로, 용도(캐시 vs 주기억장치)에 맞는 소자를 골라야 시스템 전체 성능과 비용이 균형을 이룬다.
- **핵심 직관**: SRAM은 손을 놓아도 계속 켜져 있는 시소(플립플롭)와 같고, DRAM은 시간이 지나면 저절로 새는 물탱크(커패시터)라서 주기적으로 다시 채워야 하는 것과 같다.

## 깊이 이해
- **배경·문제의식**: 메모리 셀 1개를 얼마나 적은 트랜지스터로 만드느냐가 밀도(같은 면적에 담는 비트 수)를 좌우하고, 밀도는 곧 비트당 비용과 직결된다.
- **작동 원리(DRAM)**: DRAM 셀은 트랜지스터 1개와 커패시터 1개(1T1C)로 구성되며, 커패시터에 전하가 있으면 1, 없으면 0으로 값을 저장한다.
- **작동 원리(DRAM 특성)**: 커패시터는 시간이 지나면 전하가 누설되므로, DRAM은 주기적으로 데이터를 다시 써주는 리프레시(refresh) 동작이 반드시 필요하다.
- **작동 원리(SRAM)**: SRAM 셀은 일반적으로 6개의 트랜지스터(6T)로 구성된 플립플롭 구조이며, 전원이 공급되는 한 별도의 리프레시 없이 상태를 유지한다.
- **작동 원리(비교)**: SRAM은 셀당 트랜지스터 수가 많아 같은 면적에 DRAM보다 적은 비트를 담지만, 스위칭 속도가 빠르고 리프레시가 없어 접근 지연이 짧다.
- **작동 원리(비교)**: DRAM은 셀 구조가 단순해 같은 면적에 더 많은 비트를 담을 수 있어 비트당 비용이 낮지만, 리프레시 오버헤드와 커패시터 충반전 시간 때문에 SRAM보다 접근 지연이 길다.
- **비유**: SRAM은 사람이 계속 붙잡고 있는 저울(전원만 있으면 상태 유지)이고, DRAM은 물이 새는 양동이(주기적으로 다시 채워야 유지되는 저장소)다.
- **구체 예시**: CPU의 L1/L2/L3 캐시는 접근 속도가 CPU 클럭에 맞춰야 하므로 SRAM을 사용하고, 주기억장치(메인 메모리)는 대용량이 필요해 DRAM을 사용한다.
- **구체 예시**: DDR SDRAM 계열은 JEDEC 표준에서 정한 주기로 refresh 명령을 반복 수행해 커패시터 전하 누설을 보완한다(구체 주기는 세대·표준별로 정해지며 029번 항목에서 다룬다).
- **흔한 오해·주의점**: "SRAM이 무조건 더 좋은 메모리"라고 단정할 수 없으며, SRAM은 비트당 비용이 높아 대용량 주기억장치로 쓰기에는 비현실적이다.
- **흔한 오해·주의점**: DRAM의 리프레시는 "고장 대응"이 아니라 커패시터의 물리적 전하 누설을 보완하는 정상 동작이며, 리프레시 중에는 해당 뱅크 접근이 일시적으로 제한될 수 있다.

## 연결 개념
- 메모리 계층 구조(Memory Hierarchy) — SRAM(캐시)과 DRAM(주기억장치)의 계층적 배치
- DDR SDRAM·리프레시 방식 — DRAM 리프레시 동작의 구체적 표준
- HBM(고대역폭 메모리) — DRAM을 적층해 대역폭을 높인 응용 형태
- 캐시 메모리 매핑 — SRAM 기반 캐시의 구조적 배치 방식


# 📝 【답안용】 시험 답안 템플릿
> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.
> 핵심: DRAM과 SRAM의 셀 구조 차이(1T1C vs 6T)가 리프레시 필요 여부·속도·밀도 차이를 어떻게 만드는지 인과 관계로 답안을 구성한다.

## 핵심 인사이트 (3줄 요약)
> 1. **본질**: DRAM은 커패시터 기반(1T1C) 휘발성 메모리, SRAM은 플립플롭 기반(6T) 휘발성 메모리로 셀 구조 자체가 다르다.
> 2. **가치**: DRAM은 높은 밀도와 낮은 비트당 비용으로 대용량 주기억장치를 구성하고, SRAM은 빠른 속도로 CPU 캐시를 구성한다.
> 3. **판단 포인트**: DRAM은 커패시터 전하 누설로 리프레시가 반드시 필요하고, SRAM은 전원 공급만으로 상태를 유지해 리프레시가 불필요하다.

## 출제 의도 및 답안 포인트
| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 셀 구조 차이 이해 확인 | DRAM 1T1C, SRAM 6T 구조 차이 | 구조 설명 없이 "DRAM이 느리다"로만 서술 |
| 리프레시 필요성 이해 확인 | 커패시터 전하 누설과 리프레시의 인과관계 | 리프레시를 SRAM에도 필요한 것처럼 서술 |
| 용도별 선택 기준 이해 확인 | 캐시는 SRAM, 주기억장치는 DRAM | 두 소자를 용도 구분 없이 대체 가능한 것처럼 서술 |

> 요약: 이 문제는 속도 비교가 아니라 셀 구조 차이가 리프레시 필요성과 용도 선택으로 이어지는 인과관계를 확인한다.


## Ⅰ. 개요 및 필요성
- 개요: DRAM은 커패시터 기반(1T1C), SRAM은 플립플롭 기반(6T) 휘발성 메모리 소자
- 배경: 메모리 셀의 트랜지스터 구성이 다르면 밀도·속도·리프레시 필요 여부가 함께 달라짐
- 필요성: 용도(대용량 주기억장치 vs 고속 캐시)에 따라 두 소자 중 적합한 것을 선택해야 시스템 비용과 성능이 균형을 이룸


## Ⅱ. 구조 및 구성요소
```text
Memory Cell
  / DRAM Cell: Transistor 1개 + Capacitor 1개(1T1C) -> 전하 유무로 0/1 저장 -> Refresh 필요
  / SRAM Cell: Flip-Flop 구조(통상 6 Transistor) -> 전원 공급 중 상태 유지 -> Refresh 불필요
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| DRAM Cell(1T1C) | 커패시터 전하로 데이터 저장 | 시간에 따라 전하 누설, 리프레시 필수 |
| Refresh Controller | DRAM 셀 전하 주기적 재충전 | JEDEC 표준 주기 준수(029번 항목 참고) |
| SRAM Cell(6T) | 플립플롭으로 데이터 저장 | 전원 유지 시 리프레시 불필요 |
| Sense Amplifier | DRAM 읽기 시 미세 전하 신호 증폭 | DRAM 읽기 지연의 주요 요인 |

> 요약: DRAM은 커패시터+리프레시 컨트롤러 조합, SRAM은 플립플롭만으로 구성되어 유지 보수 로직 자체가 다르다.


## Ⅲ. 동작원리 및 흐름도
```text
DRAM 읽기: Row 활성화 -> 커패시터 전하 감지(Sense Amp 증폭) -> 데이터 출력 -> 파괴적 읽기로 재기록(재충전)
DRAM 유지: 주기적 Refresh 명령 -> 전체 Row 순차 재충전 -> 전하 누설 보완
SRAM 읽기: 플립플롭 상태 감지 -> 즉시 데이터 출력(재기록 불필요)
SRAM 유지: 전원 공급 지속 -> 상태 유지(별도 재충전 없음)
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | DRAM: Row 활성화 후 커패시터 전하 감지 | 감지 증폭 지연(tRCD 등) |
| 2 | DRAM: 읽기 후 파괴적 읽기 보완을 위한 재기록 | 재기록 완료 여부 |
| 3 | DRAM: 주기적 refresh 명령으로 전하 누설 보완 | refresh 주기 준수 여부 |
| 4 | SRAM: 플립플롭 상태를 즉시 읽고 유지 | 리프레시 로직 부재 확인 |

> 요약: DRAM은 읽기마다 재기록과 주기적 refresh가 필요하지만, SRAM은 전원만 유지되면 별도 재기록 없이 상태를 유지한다.


## Ⅳ. 특징
| 구분 | DRAM | SRAM | 수치·표준 포인트 |
|:---|:---|:---|:---|
| 셀 구조 | 커패시터+트랜지스터 1개(1T1C) | 플립플롭(통상 6T) | 셀 구조 차이가 밀도·속도를 결정 |
| 리프레시 | 필요(전하 누설 보완) | 불필요(전원 유지로 충분) | JEDEC 표준 refresh 주기 준수(DRAM만 해당) |
| 밀도/비용 | 높은 밀도, 낮은 비트당 비용 | 낮은 밀도, 높은 비트당 비용 | 대용량 구성에는 DRAM이 유리 |
| 속도 | SRAM 대비 상대적으로 느림 | DRAM 대비 상대적으로 빠름 | CPU 클럭에 맞춘 접근이 필요한 캐시에 SRAM 사용 |
| 대표 용도 | 주기억장치(메인 메모리) | CPU 캐시(L1/L2/L3) | 계층 구조 내 위치가 다름 |

> 요약: DRAM은 고밀도·저비용으로 대용량을, SRAM은 고속·무리프레시로 캐시를 담당하며 둘은 대체 관계가 아니라 상호 보완 관계다.


## Ⅴ. 심화 비교 및 적용 판단
| 비교 축 | DRAM | SRAM | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | 1T1C, refresh 로직 필요 | 6T 플립플롭, refresh 불필요 | 대용량 필요 시 DRAM, 저지연 필요 시 SRAM |
| 비용/성능 | 비트당 비용 낮음, 접근 지연 상대적으로 높음 | 비트당 비용 높음, 접근 지연 낮음 | 예산·용량 제약이 크면 DRAM 우선 |
| 운영/위험 | refresh 중 일시적 접근 제약 발생 가능 | 전원 차단 시 즉시 데이터 소실(휘발성 동일) | 두 소자 모두 휘발성이므로 비휘발성 저장은 별도 계층 필요 |

> 요약: 용량과 비용이 우선이면 DRAM, 속도와 지연이 우선이면 SRAM을 선택하며 실제 시스템은 계층별로 둘 다 사용한다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| Refresh 오버헤드 | DRAM 커패시터 전하 누설 보완 필요 | self-refresh 모드, refresh 스케줄링 최적화 | refresh 소요 시간 비율(tRFC 등) |
| SRAM 면적·비용 과다 | 6T 구조로 인한 낮은 밀도 | 캐시 크기는 워크로드에 맞게 제한적으로 설계 | 캐시 면적 대비 miss rate |
| 데이터 휘발성 | 두 소자 모두 전원 차단 시 데이터 소실 | 비휘발성 저장(SSD/HDD 등) 계층과 조합 | 정전 시 데이터 보존 정책 수립 여부 |

> 요약: DRAM은 refresh 오버헤드, SRAM은 면적·비용 제약을 각각 다른 방식으로 관리해야 한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 접근 지연 | 캐시(SRAM)와 주기억장치(DRAM) 목표 지연 각각 설정 | 마이크로벤치마크 |
| Refresh 오버헤드 | 전체 시간 대비 refresh 비율 최소화 목표 | 메모리 컨트롤러 통계 |
| 비트당 비용 | 용도별 목표 예산 대비 검토 | 설계 단계 비용 분석 |

> 요약: 도입 효과는 접근 지연, refresh 오버헤드, 비트당 비용 세 지표로 판단한다.


## Ⅵ. 실무 적용 및 결론
**적용 방안 3개:**
1. CPU 캐시(L1/L2/L3)는 SRAM으로 구성해 CPU 클럭에 맞는 저지연 접근을 확보함
2. 주기억장치(메인 메모리)는 DRAM으로 구성해 대용량을 낮은 비트당 비용으로 확보함
3. DRAM 운영 시 self-refresh 모드와 refresh 스케줄링을 적용해 refresh로 인한 접근 제약을 최소화함

**결론 (2줄):**
- 기술사 판단: DRAM과 SRAM은 대체 관계가 아니라 셀 구조 차이(1T1C vs 6T)에 따른 역할 분담 관계로 이해해야 함
- 향후 방향: HBM처럼 DRAM을 적층해 대역폭을 높이는 방식과, SRAM 기반 온칩 캐시 계층을 늘리는 방식이 함께 발전하는 추세임
