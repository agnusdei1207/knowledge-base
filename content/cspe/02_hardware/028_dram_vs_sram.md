## 미리 알고가기

- DRAM은 커패시터 전하로 비트를 저장해 주기적 리프레시가 필요함
- SRAM은 플립플롭 회로로 상태를 유지해 리프레시 대기 없이 읽고 씀
- 두 메모리는 속도·집적도·전력 특성이 달라 계층 구조에서 역할이 다름
- 1T1C·6T 셀: DRAM은 트랜지스터 1개와 커패시터 1개로, SRAM은 트랜지스터 6개로 하나의 비트를 저장하는 셀 구조를 가리킴

## 작성 근거(검토용)

- DRAM과 SRAM은 셀 구조·리프레시·접근 지연·집적도·배치 위치로 설명함
- DRAM과 SRAM의 저장 셀·접근 지연·집적도·비트당 비용을 같은 기준으로 대응시킴
- 정적 비교와 무관한 메모리 계층 조회 절차는 삭제함

## Ⅰ. 개요

- **정의/개념**: DRAM은 1T1C 셀에 전하를 저장해 높은 집적도로 큰 용량을 제공하는 동적 메모리이고, SRAM은 플립플롭 기반 셀로 빠른 접근과 리프레시 없는 유지 특성을 제공하는 정적 메모리임
- **배경/필요성**: 저지연 캐시와 대용량 주기억장치를 함께 구성하기 위해 속도 중심 SRAM과 용량 중심 DRAM이 필요함

### 쉽게 이해하기 (학습용)
- DRAM은 물이 새는 물통이라 계속 다시 채워야 하지만 많이 만들 수 있고, SRAM은 새지 않는 병이라 바로 꺼내 쓰지만 만드는 데 자리를 더 차지함

## Ⅱ. 특징

- DRAM은 집적도와 비용 효율이 높아 주기억장치로 적합함
- SRAM은 리프레시가 없어 접근 지연이 짧으므로 CPU 캐시에 사용함
- DRAM의 리프레시와 행 접근 제약이 유효 대역폭과 접근 지연을 결정함
- SRAM은 면적과 누설 전력이 커서 대용량 확장이 어렵고 비용 부담이 큼

### 쉽게 이해하기 (학습용)
- 물통(DRAM)은 좁은 자리에 많이 늘어놓을 수 있어 창고용으로 적합하고, 병(SRAM)은 물이 안 새 바로 쓸 수 있어 손 닿는 곳에 둠
- 물통은 주기적으로 물을 채워야(리프레시) 해서 그 순간엔 쓸 수 없고, 병은 자리를 많이 차지해 개수를 늘리기 어려움

## Ⅲ. 종류 및 비교

| 판단 기준 | DRAM | SRAM |
|:---|:---|:---|
| 저장 방식 | 커패시터 전하를 저장하고 주기적으로 리프레시함 | 플립플롭 회로 상태를 유지해 리프레시가 필요 없음 |
| 접근 지연 | 리프레시·행 활성화 절차가 필요함 | 플립플롭 상태를 직접 읽음 |
| 집적도·비트당 비용 | 1T1C 셀로 집적도가 높고 비트당 비용이 낮음 | 6T 셀로 면적이 커 비트당 비용이 높음 |

> 요약: DRAM은 용량·비용, SRAM은 지연·캐시 응답에 강점이 있음.

### 쉽게 이해하기 (학습용)
- 물통은 물을 채워 넣는 절차 때문에 바로 못 쓸 때가 있지만 병은 뚜껑만 열면 바로 쓸 수 있고, 물통은 저렴하게 많이 만들 수 있지만 병은 하나 만드는 데 자리가 더 필요함

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| DRAM 1T1C 셀 | 트랜지스터와 커패시터로 비트를 저장하며 주기적 리프레시가 필요함 |
| SRAM 6T 셀 | 플립플롭 회로로 상태를 유지하며 셀 면적이 DRAM보다 큼 |
| 메모리 컨트롤러 | DRAM의 행 활성화·리프레시·읽기 및 쓰기 명령을 제어함 |
| 캐시·주기억장치 배치 | SRAM은 CPU 캐시에, DRAM은 주기억장치에 사용됨 |

```text
+-----------+     +----------------+     +-------------+
| CPU 코어   | --> | SRAM 캐시       | --> | DRAM 메모리  |
+-----------+     +----------------+     +-------------+
                                       ^
                                       |
                               +----------------+
                               | 리프레시 제어    |
                               +----------------+
```

> 요약: SRAM은 CPU 캐시에, DRAM은 리프레시 제어를 받는 주기억장치에 배치됨.

### 쉽게 이해하기 (학습용)
- 코어 바로 옆에는 병(SRAM 캐시)을 두어 즉시 꺼내 쓰고, 그 뒤에는 물통(DRAM)을 두되 물이 새지 않도록 관리인(리프레시 제어)이 계속 채워줌

## Ⅵ. 실무 사례

1. 서버 메모리 컨트롤러는 DRAM 뱅크 인터리빙을 적용하고 메모리 접근 지연과 행 버퍼 적중률을 확인함
2. CPU SRAM 캐시는 캐시 파티셔닝을 적용하고 접근당 에너지와 면적당 용량을 확인함

### 쉽게 이해하기 (학습용)
- 물통을 여러 줄로 나눠 놓아 한 번에 여러 곳에서 채우고 꺼낼 수 있게 하고, 병은 쓰는 사람별로 자리를 나눠 서로 방해하지 않게 함

## Ⅶ. 결론

- DRAM은 커패시터 전하로, SRAM은 플립플롭 회로로 비트를 저장해 각각 집적도·용량과 접근 속도에서 강점을 갖는 상반된 메모리 셀 구조임
- 접근 지연·집적도·비트당 비용을 기준으로 SRAM은 CPU 캐시에, DRAM은 주기억장치에 배치하고 뱅크 인터리빙이나 캐시 파티셔닝으로 각 약점을 보완해야 함

### 쉽게 이해하기 (학습용)
- 얼마나 빨리 꺼낼 수 있는지, 얼마나 좁은 자리에 많이 담을 수 있는지, 하나 만드는 데 얼마나 드는지를 보고 병과 물통 중 무엇을 어디에 둘지 정함
