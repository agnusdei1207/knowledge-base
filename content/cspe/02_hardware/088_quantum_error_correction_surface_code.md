## 미리 알고가기

- 표면 코드는 여러 물리 큐비트를 2차원 격자로 묶어 논리 큐비트를 보호하는 오류 정정 코드임
- 오류 증후군(syndrome)은 데이터 상태를 직접 읽지 않고 오류 징후만 측정한 결과임
- 디코더(decoder)는 오류 증후군을 바탕으로 어떤 오류가 났는지 추정하는 고전 연산기임

## 작성 근거(검토용)

- 표면 코드는 물리·논리 큐비트, 오류 증후군, 디코더, 코드 거리를 핵심 축으로 설명함
- 비교표는 고전 오류 정정과 표면 코드의 정보 복제, 오류 종류, 중복 자원, 처리 조건을 대비함
- 실무 판단은 논리 오류율·큐비트 오버헤드와 디코딩 지연·주기 준수율로 검증함

## Ⅰ. 개요

- **정의/개념**: 표면 코드는 다수의 물리 큐비트를 2차원 격자에 배치하고 안정자 측정으로 얻은 오류 증후군을 디코딩해 논리 큐비트를 보호하는 양자 오류 정정 방식임
- **배경/필요성**: 탈동조·게이트·측정 오류 속에서도 논리 상태를 유지하기 위해 반복 측정과 디코딩을 사용하는 오류 정정 구조가 필요함

## Ⅱ. 특징

- 2차원 격자에서 이웃한 데이터·측정 큐비트의 국소 상호작용으로 오류 증후군을 측정함
- 코드 거리를 늘리면 논리 오류율을 낮출 수 있음
- 논리 큐비트 하나에 많은 물리 큐비트가 필요해 자원 오버헤드가 큼
- 디코더가 오류 증후군 측정 주기 안에 보정 방향을 계산해야 함

## Ⅲ. 종류 및 비교

| 판단 기준 | 고전 오류 정정 | 표면 코드 |
|:---|:---|:---|
| 보호 방식 | 데이터에 패리티 비트를 추가해 오류를 검출·정정함 | 양자 상태를 복사하지 않고 오류 증후군을 측정해 오류를 추정함 |
| 오류 표현 | 비트·심벌 오류를 패리티 검사 결과로 식별함 | 비트 반전·위상 반전·측정 오류를 안정자 결과로 식별함 |
| 중복 자원 | 데이터 비트와 패리티 비트를 추가함 | 논리 큐비트마다 데이터·측정 큐비트를 격자로 배치함 |
| 처리 조건 | 채널 오류 모델에 맞는 복호기를 사용함 | 물리 오류율을 임계값 아래로 유지하고 측정 주기 안에 디코딩함 |

> 요약: 표면 코드는 복사할 수 없는 양자 상태를 오류 증후군 측정과 디코딩으로 보호함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 데이터 큐비트 격자 | 논리 정보를 분산 저장해 단일 물리 오류가 논리 오류로 전파되는 것을 억제함 |
| 측정 큐비트 | 주변 데이터 큐비트의 안정자를 읽어 오류 증후군을 생성함 |
| 오류 증후군 주기 | 반복 측정의 시간 간격이 오류 추적과 보정 시점을 결정함 |
| 디코더 | 오류 증후군 이력을 분석해 오류 위치와 보정 방향을 추정함 |

> 요약: 표면 코드는 데이터·측정 큐비트, 오류 증후군 주기, 디코더로 논리 상태를 보호함.

## Ⅴ. 원리 및 절차 흐름도

1. **논리 상태 인코딩**: 여러 물리 큐비트에 논리 상태를 분산함
2. **오류 증후군 반복 측정**: 안정자 결과를 주기적으로 수집함
3. **디코딩·오류 추정**: 고전 디코더가 오류 경로를 추정함
4. **보정·프레임 갱신**: 실제 보정 또는 파울리 프레임 갱신으로 논리 상태를 유지함

> 요약: 표면 코드는 오류 증후군을 반복 측정하고 디코더가 오류 경로를 추정해 논리 상태를 유지함.

## Ⅵ. 실무 사례

1. 표면 코드 프로세서는 물리 오류율에 맞춰 코드 거리를 정하고 논리 오류율·논리 큐비트당 물리 큐비트 수를 확인함
2. 실시간 오류 정정기는 FPGA·ASIC 디코더를 적용하고 디코딩 지연·측정 주기 준수율을 확인함

## Ⅶ. 결론

- 표면 코드는 물리 오류율과 코드 거리에 따른 논리 오류율 감소가 증후군 주기·디코딩 지연 한도 안에서 유지되는지 검증해야 함
