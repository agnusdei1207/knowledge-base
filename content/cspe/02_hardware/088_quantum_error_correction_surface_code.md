## Ⅰ. 개요
- **정의**: 다수의 물리 큐비트를 격자 배열하여 논리 큐비트의 비트·위상 오류를 검출·정정하는 부호 체계임
- **배경/필요성**: 물리 큐비트의 오류율이 10^-3 수준이므로 대규모 양자 알고리즘 실행을 위해 오류 허용 연산이 필요함
- **비유**: 여러 사람이 같은 메시지를 중복 전달하여 한두 명이 틀려도 원본을 복원하는 전화 게임과 같음

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 표면 코드의 원리와 오버헤드 이해 | 신드롬 측정으로 오류 위치를 파악하되 양자 상태를 붕괴시키지 않음 | 물리 큐비트 대 논리 큐비트 비율(~1000:1) 명시 필요 |

> 요약: 표면 코드는 격자 기반 신드롬 측정으로 양자 오류를 비파괴적으로 정정하는 핵심 기법임

## Ⅱ. 구성요소
```text
  D---A---D---A---D
  |       |       |
  A---D---A---D---A
  |       |       |
  D---A---D---A---D
  D = 데이터 큐비트, A = 보조(Ancilla) 큐비트
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 데이터 큐비트 | 논리 정보를 인코딩하는 물리 큐비트임 | 메시지를 기억하는 전달자 |
| 보조 큐비트 | 인접 데이터 큐비트의 패리티를 측정하여 신드롬을 추출함 | 전달 내용을 검증하는 감독관 |
| X/Z 안정자 | X 안정자는 위상 오류, Z 안정자는 비트 오류를 검출하는 연산자임 | 가로·세로 방향 검사원 |
| 디코더 | 신드롬 패턴으로부터 오류 위치를 추정하는 고전 알고리즘임 | 증상으로 병명을 진단하는 의사 |

> 요약: 데이터·보조 큐비트와 안정자·디코더가 표면 코드의 4대 구성요소임

## Ⅲ. 절차
```text
논리 인코딩 --> 안정자 측정 --> 신드롬 디코딩 --> 오류 복구
```
- 1단계: **논리 인코딩** — d x d 격자에 데이터·보조 큐비트를 배치하여 논리 큐비트를 구성함
- 2단계: **안정자 측정** — 보조 큐비트로 인접 데이터 큐비트의 X/Z 패리티를 반복 측정함
- 3단계: **신드롬 디코딩** — 최소 가중 완전 매칭(MWPM) 등으로 오류 체인을 추정함
- 4단계: **오류 복구** — 추정된 위치에 X/Z 보정 게이트를 적용하여 논리 상태를 복원함

> 요약: 인코딩-측정-디코딩-복구의 4단계를 반복하여 오류 허용 연산을 달성함

## Ⅳ. 문제점
- 큐비트 오버헤드: 코드 거리 d의 표면 코드에 2d^2-1개 물리 큐비트가 필요하여 자원 소모가 큼
- 디코딩 지연: MWPM 알고리즘의 처리 시간이 실시간 오류정정 주기를 초과할 수 있음
- 임계 오류율 제약: 물리 게이트 오류율이 약 1% 임계값을 넘으면 정정이 불가함

> 요약: 큐비트 오버헤드·디코딩 지연·임계 오류율이 표면 코드의 3대 한계임

## Ⅴ. 개선방안
1. 단기: qLDPC 코드 등 고효율 부호로 물리 큐비트 오버헤드를 절감함
2. 중기: 신경망 기반 디코더로 디코딩 지연을 us 단위 이하로 단축함
3. 장기: 게이트 충실도를 99.99% 이상으로 향상하여 임계 오류율 대비 충분한 마진을 확보함

> 요약: 고효율 부호·고속 디코더·고충실도 게이트로 오류정정 실용성을 확보함

## Ⅵ. 전망
- 발전 방향: 표면 코드와 qLDPC 코드의 하이브리드 아키텍처로 자원 효율이 개선되는 추세임
- 기술사적 판단: 100만 물리 큐비트 시대에 디코딩 처리량이 시스템 병목으로 부상할 전망임
- 기술사 제언: 코드 거리·오류율·오버헤드 간 트레이드오프를 정량 분석하는 역량이 필요함
