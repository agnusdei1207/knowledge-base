## Ⅰ. 개요
- **정의**: I/O 폭을 2048-bit로 확장하고 맞춤형 로직 다이를 도입한 6세대 고대역폭 메모리
- **배경/필요성**: HBM3E(031 참조)에서 핀당 속도를 높이는 방식이 전력·신호 간섭 한계에 도달함. 대역폭을 2TB/s 이상으로 끌어올리려면 I/O 폭 자체를 2배로 확장하는 구조 변경이 요구됨
- **비유**: 제한속도를 더 올리기 어려워지자 차선 수 자체를 2배로 넓힌 고속도로

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| HBM 세대 전환의 패러다임 변화 이해 | 2048-bit I/O + Custom Logic Die + 하이브리드 본딩의 3대 혁신 | HBM3E(031 참조)와 달리 메모리 제조사 단독 생산 불가, 파운드리 협업 필수 |

> 요약: HBM4는 I/O 폭 확장·맞춤형 로직 다이·하이브리드 본딩으로 2TB/s급 대역폭과 설계 자유도를 확보한 메모리임

## Ⅱ. 구성요소
```text
+-------------------+                      +----------------------+
| GPU / AI 가속기    | <-- 2048-bit -->    |     HBM4 Stack        |
+-------------------+   인터포저 연결      | +---+ +---+ +---+    |
                                           | |Die| |Die| |Die|    |
                                           | +---+ +---+ +---+    |
                                           |  ... 16단 적층        |
                                           |  (하이브리드 본딩)     |
                                           | +-------------------+ |
                                           | | Custom Logic Die  | |
                                           | | (파운드리 공정)     | |
                                           | +-------------------+ |
                                           +----------------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 2048-bit Ultra-Wide I/O | 핀 수를 HBM3E 대비 2배로 확장하여 핀당 속도 부담 없이 총 대역폭 2TB/s 이상 달성 | 차선을 2배로 넓혀 교통량을 증가시킨 도로 |
| Custom Logic Die | 파운드리 선단 공정(FinFET/GAA)으로 제조하는 베이스 칩, 고객 맞춤 컨트롤러·IP 집적 가능 | 입주사 요구에 맞춰 설계한 맞춤형 1층 사무실 |
| DRAM Die 16단 적층 | 하이브리드 본딩으로 범프 없이 Cu 패드끼리 접합, JEDEC 775um 두께 내 16단 수용 | 접착제 없이 자석으로 붙인 초박형 적층 |
| 하이브리드 본딩 | 마이크로 범프를 제거하고 Cu 패드를 직접 접합하여 두께 축소 및 열 저항 감소 | 두꺼운 접착제 대신 면끼리 맞대어 압착하는 공정 |

> 요약: 2048-bit I/O·맞춤형 로직 다이·16단 하이브리드 본딩 적층이 HBM4의 핵심 구성임

## Ⅲ. 절차
```text
고객 Co-design -> 로직 다이 파운드리 제조 -> DRAM 적층(하이브리드 본딩) -> 통합 패키징
```
- 1단계: 고객(팹리스)·파운드리·메모리 제조사 3자가 로직 다이 사양을 공동 설계(Co-design)함
- 2단계: 파운드리가 선단 공정으로 Custom Logic Die를 제조하고, 메모리 제조사가 DRAM 다이를 준비함
- 3단계: DRAM 다이를 하이브리드 본딩으로 16단 적층하고, CMP 평탄화로 접합면 정밀도를 확보함
- 4단계: Custom Logic Die 위에 DRAM 스택을 올리고 인터포저와 통합 패키징한 뒤 시스템 테스트를 수행함

> 요약: 3자 공동 설계 -> 로직/DRAM 병행 제조 -> 하이브리드 본딩 적층 -> 통합 패키징 순서로 생산함

## Ⅳ. 문제점
- 하이브리드 본딩 수율: nm 수준의 파티클에도 접합 불량이 발생 — CMP 평탄화와 클린룸 등급 요구 수준이 극단적으로 높음
- 공급망 복잡성: 메모리 제조사 단독 생산이 불가하여 파운드리 의존도가 발생 — 납기·원가 통제가 어려움
- 소프트웨어 생태계 미비: Custom Logic Die에 탑재할 IP에 대한 표준 프로그래밍 모델이 부재 — 고객마다 별도 SDK가 요구됨

> 요약: 초정밀 본딩 수율·3자 공급망 복잡성·SW 표준 부재가 HBM4의 주요 과제임

## Ⅴ. 개선방안
1. 단기: CMP 장비 정밀도 향상 및 클린룸 등급 상향으로 하이브리드 본딩 수율을 개선함
2. 중기: 파운드리-메모리 제조사 간 장기 공급 계약 체결 및 Co-design 플랫폼 표준화로 공급망 리스크를 분산함
3. 장기: JEDEC 주도의 PIM/CXL 통합 프로그래밍 표준을 수립하여 Custom Logic Die 활용 생태계를 확장함

> 요약: 본딩 수율 제고 -> 공급망 표준화 -> 프로그래밍 모델 통합 순으로 과제를 해소함

## Ⅵ. 전망
- 발전 방향: HBM4의 Custom Logic Die는 PIM(033 참조) 연산 기능과 결합하여 메모리 중심 컴퓨팅 아키텍처로 진화할 전망임
- 기술사적 판단: 메모리와 비메모리의 경계가 소멸하면서 반도체 산업의 수직 통합 구조가 재편됨
- 기술사 제언: AI 가속기 도입 시 HBM4 대응 가능 여부를 파운드리 협업 체계 포함하여 평가할 필요
