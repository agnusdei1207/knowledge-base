## Ⅰ. 개요
- 큰 칩을 기능별로 작은 조각(Chiplet)으로 나누어 제조 후 결합하는 방식
- 무어의 법칙 한계 돌파 및 반도체 수율 향상을 위한 차세대 대안

| 구분 | 내용 |
| --- | --- |
| 정의 | 독립적으로 제조된 기능 블록 다이들을 하나의 패키지로 조립 |
| 배경 | 미세 공정 비용 폭증 및 거대 다이(Reticle Limit) 제조 한계 |
| 출제의도 | 칩렛의 개념, 이종 집적(Heterogeneous Integration) 이해 |

## Ⅱ. 구성요소
```
+------------------------------------------+
|  [ Chiplet Based Processor ]             |
| +---------+   +---------+   +---------+  |
| | Logic 1 |   | I/O Die |   | Logic 2 |  |
| | (5nm)   |---| (12nm)  |---| (5nm)   |  |
| +---------+   +---------+   +---------+  |
| [ Interposer / Organic Substrate ]       |
+------------------------------------------+
```
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| Chiplet Die | 특정 기능을 수행하는 작은 반도체 조각 | 레고 부품 |
| D2D Interface | 칩렛 간 고속 통신 규격(UCIe 등) | 부품 결합부 |
| Interposer | 칩렛들을 물리적으로 연결하는 미세 배선층 | 마더보드 |
> 요약: 기능별 최적 공정으로 만든 칩렛을 고속 인터페이스로 연결함.

## Ⅲ. 절차
```
[기능 분할] -> [개별 제조] -> [인터페이스 연결] -> [최종 패키징]
```
1. 기능 분할: 코어, 메모리 컨트롤러, I/O 등 기능 단위로 칩 분리함.
2. 개별 제조: 핵심 코어는 3nm, I/O는 12nm 등 최적 공정 적용함.
3. 연결: UCIe 등 표준 인터페이스를 통해 칩렛 간 데이터 통로 확보함.
4. 패키징: 2.5D/3D 패키징 기술을 사용하여 하나의 제품으로 완성함.
> 요약: 분산 제조 후 정밀 조립을 통해 고성능 시스템 구현함.

## Ⅳ. 문제점
- 테스트 복잡성: 개별 칩렛 검증 후 조립된 전체 시스템 검증 난이도 높음.
- 신호 지연: 단일 다이(Monolithic) 대비 칩 간 통신 지연 발생 가능함.

## Ⅴ. 개선방안
- 표준 규격 채택: UCIe(Universal Chiplet Interconnect express) 확산함.
- 고속 통신 기술: 대역폭은 넓고 지연은 낮은 전용 물리 계층 개발함.

## Ⅵ. 전망
- AMD, 인텔, 엔비디아 등 주요 기업의 주력 아키텍처로 정착 중임.
- 맞춤형 반도체(ASIC) 시장에서 칩렛 에코시스템 활성화가 CSF임.
