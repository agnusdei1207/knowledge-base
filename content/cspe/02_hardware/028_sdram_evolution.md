## Ⅰ. 개요
- 정의: 시스템 클록에 동기화되어 동작하는 DRAM의 세대별 발전 기술
- 배경: CPU 성능 향상에 따른 메모리 대역폭 병목 현상(Memory Wall) 해결 필요성
- 출제 의도
| 구분 | 내용 |
| --- | --- |
| 핵심 | DDR별 전압, 대역폭, 뱅크 구조 변화, 데이터 전송률 |

## Ⅱ. 구성요소
```
[ Clock ] ----+----> [ Command ]
              +----> [ Data (Rising/Falling Edge) ]
```
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 프리페치(Prefetch) | 한 번의 읽기 명령으로 내부에서 미리 가져오는 데이터 양 | 미리 담기 |
| 뱅크 그룹(Bank) | 독립적 명령 수행이 가능한 논리적 메모리 단위 | 창고 구역 |
| PMIC | DDR5부터 모듈 내부에 탑재되는 전력 관리 IC | 전원 공급기 |
> 요약: 세대가 올라갈수록 저전압, 고속화, 고집적화를 달성함

## Ⅲ. 절차
1. 클록 동기: 시스템 버스 클록과 메모리 인터페이스의 클록 일치
2. 명령 하사: 행(Row) 활성화 및 열(Column) 주소 지정 명령 전달
3. 데이터 전송: Rising/Falling Edge 모두 활용하여 데이터 전송 (DDR 원리)
4. 오류 정정: DDR5의 경우 온-다이(On-die) ECC를 통해 데이터 무결성 보장
> 요약: 병렬성 강화와 전송 속도 향상을 통해 시스템 전체 성능을 가속함

## Ⅳ. 문제점
- 데이터 전송 속도가 빨라짐에 따라 신호 간섭(Signal Integrity) 문제 심화됨

## Ⅴ. 개선방안
- DFE(Decision Feedback Equalization) 등 신호 보정 기술 및 저전압 설계 적용함

## Ⅵ. 전망
- DDR6에서는 PAM4 변조 방식 도입을 통해 2배 이상의 대역폭 확보가 로드맵임
- 데이터 센터 및 AI 연산 가속을 위해 모듈 단위의 지능형 관리 기능이 CSF로 부각됨
