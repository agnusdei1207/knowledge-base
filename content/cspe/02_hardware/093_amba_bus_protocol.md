## Ⅰ. 개요
- **정의**: ARM 기반 SoC 내부 IP 블록 간 상호연결을 위한 온칩 버스 프로토콜 규격
- **배경/필요성**: SoC 내 CPU·메모리·주변장치 등 다양한 IP가 통합되면서 표준화된 인터커넥트 프로토콜이 요구됨
- **비유**: 건물 내 각 방(IP 블록)을 연결하는 표준 규격 복도와 출입 규칙

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| SoC 버스 계층 구조와 프로토콜 특성 비교 | AHB·APB·AXI 역할 분담 | AXI의 독립 읽기/쓰기 채널 구조 |

> 요약: AMBA는 SoC 내부 IP 간 데이터 교환을 표준화하는 계층적 버스 프로토콜임

## Ⅱ. 구성요소
```text
         +--- AXI (High-Performance) ---+
         |                              |
CPU -----+--- AHB (System Bus) ---------+--- Memory
         |                              |
         +--- APB (Peripheral Bus) -----+--- UART/SPI/GPIO
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| AXI(Advanced eXtensible Interface) | 읽기/쓰기 독립 5채널, 버스트·비순서 트랜잭션 지원 고성능 프로토콜 | 왕복 8차선 고속도로 |
| AHB(Advanced High-performance Bus) | 파이프라인 단일 채널, 중간 성능의 시스템 버스 | 왕복 4차선 국도 |
| APB(Advanced Peripheral Bus) | 저전력·저속 주변장치 접속용 단순 프로토콜 | 마을 내 골목길 |
| AXI Bridge | AXI↔AHB, AHB↔APB 간 프로토콜 변환을 수행하는 브리지 | 고속도로 IC 연결로 |

> 요약: AXI·AHB·APB가 성능 계층별로 분담하고 브리지가 이를 연결함

## Ⅲ. 절차
```text
마스터 요청 --> 중재(Arbiter) --> 슬레이브 응답 --> 데이터 전송 완료
      |              |                |                  |
      v              v                v                  v
  주소/제어 발행   접근 허가 부여   디코딩/ACK         RESP 확인
```
- 1단계: 마스터 요청 — 마스터가 주소·제어 신호(R/W, 버스트 길이)를 버스에 발행함
- 2단계: 중재(Arbitration) — 아비터가 다수 마스터 요청 중 우선순위에 따라 접근 권한을 부여함
- 3단계: 슬레이브 응답 — 디코더가 주소를 해석하여 해당 슬레이브를 선택하고, 슬레이브가 HREADY/RVALID로 응답함
- 4단계: 데이터 전송 완료 — 데이터 채널을 통해 페이로드가 전달되고 RESP 신호로 완료를 확인함

> 요약: 마스터 발행 → 중재 → 슬레이브 응답 → 완료 확인의 핸드셰이크 절차로 동작함

## Ⅳ. 문제점
- 공유 버스 병목: AHB는 단일 마스터만 버스를 점유하므로 다수 IP 동시 접근 시 대기 시간이 증가함
- 프로토콜 변환 지연: AXI↔APB 브리지 경유 시 클럭 도메인·프로토콜 차이로 2~3사이클 추가 레이턴시 발생함
- 검증 복잡도: AXI 비순서(Out-of-Order) 트랜잭션 지원으로 기능 검증 시나리오가 기하급수적으로 증가함

> 요약: 공유 버스 경합·브리지 지연·검증 복잡도가 SoC 설계의 주요 과제임

## Ⅴ. 개선방안
1. 단기: AHB 멀티레이어(Multi-Layer) 구성으로 동시 다중 마스터 접근을 허용하여 병목을 완화함
2. 중기: 클럭 도메인 동기화 FIFO를 브리지에 내장하여 변환 레이턴시를 1사이클로 단축함
3. 장기: UVM 기반 자동화 검증 환경과 형식 검증(Formal Verification)을 병행하여 검증 커버리지를 확보함

> 요약: 멀티레이어화·브리지 최적화·자동화 검증으로 AMBA 기반 SoC 품질을 확보함

## Ⅵ. 전망
- 발전 방향: AMBA 5 CHI(Coherent Hub Interface)가 멀티코어·캐시 일관성 요구를 충족하며 확산 중임
- 기술사적 판단: SoC 설계에서 AMBA 프로토콜 이해는 IP 통합·성능 분석의 기반 역량임
- 기술사 제언: AXI 채널 구조와 트랜잭션 흐름을 숙지하고 성능 계층 설계에 적용하는 역량 확보가 필요
