## 미리 알고가기

- WUE: 물 사용 효율(Water Usage Effectiveness, WUE)은 데이터센터 물 사용량을 IT 장비 에너지 사용량으로 나눈 지표임
- IT 장비: 정보기술(Information Technology, IT) 장비는 서버, 스토리지, 네트워크처럼 실제 컴퓨팅을 수행하는 장비임
- 냉각탑: 물의 증발 잠열로 열을 외부로 배출하는 설비로 물 사용량의 주요 원천임
- 보충수: 증발, 비산, 배수로 손실된 물을 냉각 시스템에 다시 채우는 물임
- 물 스트레스: 지역의 물 수요 대비 가용 수자원이 부족한 정도임
- PUE와의 관계: 물을 더 쓰는 증발 냉각은 전력 사용 효율(Power Usage Effectiveness, PUE)을 낮출 수 있지만 WUE를 악화시킬 수 있음

## Ⅰ. 개요

- **정의**: WUE는 데이터센터가 IT 장비 에너지 1kWh를 소비할 때 냉각·운영에 투입한 물 사용량을 `물 사용량 / IT 장비 에너지`로 표현해 냉각 방식과 지역 수자원 부담을 판단하는 지속가능성 지표임
- **배경/필요성**: 데이터센터가 전력 효율을 높이기 위해 증발 냉각을 쓰면 물 사용량이 증가할 수 있음. 물 부족 지역에서는 낮은 PUE보다 물 사용 절감과 지역 수자원 영향이 더 중요한 운영 제약이 됨
- **비유**: 자동차 연비만 보지 않고 연료를 만들 때 쓰인 물과 지역 자원 부담까지 함께 보는 것과 같음

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 데이터센터 수자원 지표 설명 | WUE 산식, 물 사용량, IT 에너지, 냉각 방식 | WUE를 전력 효율 지표로 혼동 |
| PUE와의 트레이드오프 판단 | 증발 냉각, 물 스트레스, 지역 조건 | PUE가 낮으면 항상 친환경이라는 단정 |

> 요약: WUE는 데이터센터 에너지 효율 뒤에 숨어 있는 물 사용 부담을 IT 에너지 단위로 드러내는 지표임.

## Ⅱ. 특징/비교

| 판단 기준 | PUE | WUE | 탄소 사용 효율(Carbon Usage Effectiveness, CUE) |
|:---|:---|:---|:---|
| 측정 대상 | 전체 전력 대비 IT 전력 | 물 사용량 대비 IT 에너지 | 탄소 배출량 대비 IT 에너지 |
| 핵심 질문 | 시설 전력을 얼마나 효율적으로 쓰는가 | IT 에너지당 물을 얼마나 쓰는가 | IT 에너지당 탄소를 얼마나 배출하는가 |
| 개선 수단 | 냉각 효율, 무정전 전원 장치(Uninterruptible Power Supply, UPS) 효율, 공기 흐름 개선 | 물 재사용, 폐수 활용, 건식 냉각 | 저탄소 전력, 재생 에너지, 수요 이전 |
| 주요 한계 | 물·탄소 영향을 직접 반영하지 않음 | 지역 물 스트레스 차이를 단독으로 표현하기 어려움 | 전력원 배출계수와 시간대 영향이 큼 |

> 요약: WUE는 PUE가 놓치는 물 사용 부담을 보완하며, 지역 수자원 조건을 함께 봐야 의미가 있음.

- **지역 기준**: 같은 WUE라도 물 부족 지역과 수자원이 풍부한 지역의 위험은 다르게 평가해야 함
- **냉각 기준**: 증발 냉각은 전력 절감에 유리하지만 보충수와 배수를 늘릴 수 있음
- **운영 기준**: 물 사용량은 계절, 외기 온도, IT 부하, 수질 관리 정책에 따라 변동함

## Ⅲ. 구성요소

```text
+----------+      +----------+      +----------+
| Water    | ---> | Cooling  | ---> | Heat     |
| Source   |      | System   |      | Rejection|
+----+-----+      +----+-----+      +----+-----+
     |                 |                 |
     v                 v                 v
+----------+      +----------+      +----------+
| Metering |      | IT kWh   |      | WUE      |
| Boundary |      | Meter    |      | Report   |
+----------+      +----------+      +----------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 물 공급원 | 상수, 재생수, 빗물, 지하수 등 냉각에 투입되는 수자원임 | 물탱크 원천 |
| 냉각 설비 | 냉각탑, 증발 냉각기, 가습 장치 등 물을 쓰는 열 배출 장치임 | 증발식 방열판 |
| 계량 경계 | 어떤 물 사용량을 데이터센터 물 사용으로 포함할지 정하는 기준임 | 수도 계량 위치 |
| IT 에너지 | 서버, 스토리지, 네트워크 장비가 소비한 전력량이며 WUE 분모가 됨 | 실제 생산량 |
| 수질·배수 관리 | 농축수 배출, 화학 처리, 재사용 가능성을 관리하는 운영 요소임 | 물 정화 필터 |

> 요약: WUE는 물 공급과 냉각 설비 사용량을 IT 에너지와 연결해 물 사용 효율을 계산하는 구조임.

## Ⅳ. 절차

```text
+----------+      +----------+      +----------+      +----------+
| Boundary | ---> | Measure  | ---> | Calculate| ---> | Reduce   |
| Set      |      | Water/kWh|      | WUE      |      | Water    |
+----------+      +----------+      +----------+      +----------+
```

1. **경계 설정**: 냉각탑, 가습, 수처리, 조경 등 포함할 물 사용 범위를 정의함
2. **물·에너지 계량**: 기간별 물 사용량과 IT 장비 전력량을 같은 기준으로 측정함
3. **WUE 산정·해석**: `WUE = 물 사용량 / IT 장비 에너지`로 계산하고 계절과 지역 물 스트레스를 반영함
4. **저감 조치 적용**: 재생수 활용, 농축도 제어, 건식 냉각 전환, 외기 냉방 최적화로 물 사용을 줄임

> 요약: WUE 관리는 물 사용 경계를 정하고 IT 에너지당 물 소비를 계산한 뒤 냉각 운영을 조정하는 과정임.

## Ⅴ. 문제점

- **P1 지역 위험 미반영**: WUE 수치만으로는 물 부족 지역에서의 사회적·운영적 위험을 충분히 설명하지 못함
- **P2 PUE와의 상충**: 증발 냉각으로 전력 사용을 줄이면 PUE는 좋아지지만 WUE는 나빠질 수 있음
- **P3 계량 범위 불일치**: 보충수, 배수, 재생수, 간접 물 사용을 어디까지 포함하는지에 따라 결과가 달라짐

> 요약: WUE는 지역 조건과 PUE 트레이드오프, 계량 기준을 함께 보지 않으면 지속가능성 판단이 왜곡됨.

## Ⅵ. 개선방안

1. **단기**: 물 사용 계량기를 점검하고 냉각탑 보충수, 배수, 수질 데이터를 분리 수집함
2. **중기**: 재생수, 폐수 재활용, 농축도 최적화, 외기 조건 기반 제어를 적용함
3. **장기**: 지역 물 스트레스와 전력 효율을 함께 고려한 데이터센터 입지·냉각 전략을 수립함

- **P1 대응**: WUE에 지역 물 스트레스 지표와 물 공급 안정성을 결합해 평가함 (확인: 지역 수자원 위험 등급)
- **P2 대응**: PUE, WUE, CUE를 동시에 최적화하는 운영 목표를 설정함 (확인: 지표별 월간 추세)
- **P3 대응**: 물 사용 계량 경계와 재생수 산정 기준을 표준화함 (확인: 계량 지점 목록, 산출 기준)

> 요약: WUE 개선은 물 사용량 자체뿐 아니라 지역 위험과 전력 효율의 균형을 함께 관리해야 함.

## Ⅶ. 전망

- **발전 방향**: WUE는 인공지능(Artificial Intelligence, AI) 데이터센터 입지, 액체 냉각, 재생수 활용, 건식 냉각 적용과 연결되어 전력 지표와 함께 지속가능성 판단 기준이 됨
- **기술사적 판단**: 지역 수자원, 냉각 방식, 계절별 습구온도, 수처리 비용, 전력 증가분을 함께 산정해 목표 WUE를 정함; 연간 WUE, 하절기 피크 WUE, 보충수, 배수량, 수질, PUE 상충 관계를 동일 계측 경계로 측정함
- **기술사 제언**: WUE는 PUE의 보조 수치가 아니라 입지, 지역 수용성, 운영 리스크를 함께 설명하는 데이터센터 설계 지표로 사용해야 함
