## 미리 알고가기

- NAND 플래시는 비휘발성 메모리로 page 단위 쓰기와 block 단위 erase 특성을 가짐
- 평면 NAND는 미세화가 진행될수록 셀 간 간섭과 수명 문제가 커짐
- 3D V-NAND는 셀을 수직 적층해 집적도와 내구성과 성능을 함께 개선한 구조임

## Ⅰ. 개요

- **정의/개념**: NAND 플래시는 전하 상태로 데이터를 저장하는 비휘발성 메모리이며, 3D V-NAND는 셀을 평면으로 미세화하는 대신 수직 적층해 더 높은 용량과 더 나은 신뢰성과 전력 효율을 제공하는 진화형 NAND 구조임
- **배경/필요성**: 2D NAND는 공정 미세화가 심해질수록 셀 간 간섭과 데이터 보존성과 수명 저하가 심해져, 더 많은 용량을 확보하면서 물리 한계를 완화할 다른 집적 방식이 필요해짐

## Ⅱ. 특징

- 수직 적층으로 면적당 용량을 크게 높이면서 셀 간 간섭을 완화함
- charge trap 계열 구조를 사용해 평면형보다 데이터 보존성과 내구성 확보에 유리함
- 셀당 저장 비트가 증가할수록 용량 효율은 높아지지만 속도와 수명과 오류 여유는 줄어듦
- 적층 수 증가와 에칭 난도 상승이 제조 수율과 비용과 공급 능력을 좌우함

## Ⅲ. 종류 및 비교

| 판단 기준 | 2D NAND | 3D V-NAND |
|:---|:---|:---|
| 집적 방식 | 평면 미세화 중심으로 셀을 가로 배치함 | 수직 적층 중심으로 셀을 층별로 쌓음 |
| 장점 | 초기 구조가 단순함 | 높은 용량과 개선된 신뢰성과 전력 효율을 제공함 |
| 한계 | 미세화에 따라 간섭과 수명 문제가 커짐 | 적층과 에칭 공정 난도가 높아짐 |
| 확장 방향 | 공정 축소 한계가 뚜렷함 | 층수 증가와 구조 최적화로 계속 확장 가능함 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Memory Cells | 셀당 전하 상태를 이용해 비트를 저장하며 MLC와 TLC와 QLC로 갈수록 용량 효율이 높아짐 |
| Vertical Channel and Stack | 여러 층을 관통하는 채널 구조가 적층 셀을 연결해 고집적 구성을 가능하게 함 |
| Word Line and Block Organization | page 단위 읽기·쓰기와 block 단위 erase를 수행하는 NAND 기본 관리 단위를 형성함 |
| Controller and ECC Path | NAND 특성상 오류가 누적되므로 FTL과 ECC가 함께 동작해 실제 저장장치 품질을 보장함 |

```text
      +-------------+
      | Word Line   |
      +-------------+
      | Word Line   |
      +-------------+
      | Word Line   |
      +-------------+
            |
            v
      +-------------+
      | Channel Hole|
      +-------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| page 단위 기록   | --> | 전하 상태 저장   | --> | 반복 읽기와 verify | --> | block 단위 erase |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **page 단위 기록**: 셀에 원하는 데이터 패턴을 프로그램함
2. **전하 상태 저장**: 셀의 임계 전압 상태로 정보를 유지함
3. **반복 읽기와 verify**: ECC와 읽기 검증으로 오류를 통제함
4. **block 단위 erase**: 재사용하려면 큰 단위 block을 먼저 지움

## Ⅵ. 문제점 및 해결 방안

1. 문제: 적층 수가 높아질수록 채널 에칭과 적층 균일도 확보가 어려워 수율과 원가가 흔들릴 수 있음
   - 해결방안: multi-stack 공정과 공정 제어 강화를 적용하고 wafer yield와 layer defect density로 검증함
2. 문제: QLC 같은 고집적 모드는 셀 상태 간 간격이 좁아져 오류와 데이터 보존 문제가 커질 수 있음
   - 해결방안: 강한 ECC와 read retry와 refresh 정책을 적용하고 raw bit error rate와 retention error count로 검증함
3. 문제: 반복 읽기와 쓰기 집중은 read disturb와 wear-out을 가속해 장기 신뢰성을 해칠 수 있음
   - 해결방안: wear leveling과 hot data 분산을 적용하고 TBW와 read disturb count로 검증함

## Ⅶ. 적용 사례

- 데이터센터 SSD는 3D NAND를 활용해 랙당 저장 밀도를 높이고 확인 지표는 watts per TB와 drive capacity density임
- 스마트폰 UFS 저장장치는 3D NAND로 용량과 전력 효율을 동시에 확보하고 확인 지표는 app launch latency와 battery impact임
- 영상 기록 장치는 pSLC 또는 내구성 보강 구성을 적용해 지속 쓰기를 견디고 확인 지표는 TBW와 retention error count임

## Ⅷ. 결론

3D V-NAND의 의미는 용량 증가 자체보다 미세화 한계를 수직 적층으로 우회해 저장장치 산업의 확장 경로를 다시 연 데 있음.
