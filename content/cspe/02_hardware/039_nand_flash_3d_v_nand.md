## 미리 알고가기

- NAND 플래시는 비휘발성 메모리로 페이지 단위 쓰기와 블록 단위 삭제 특성을 가짐
- 평면 NAND는 미세화가 진행될수록 셀 간 간섭과 수명 문제가 커짐
- 3D V-NAND는 셀을 수직 적층해 집적도·내구성·성능을 함께 개선한 구조임

## 작성 근거(검토용)

- NAND와 3D V-NAND는 집적 방식·셀 간 간섭·제조 공정과 확장 제약을 핵심 비교축 3개로 비교함
- 페이지 쓰기·블록 삭제와 수직 채널·워드라인·오류 정정 경로의 관계를 설명함
- 평면 미세화 한계를 수직 적층으로 전환한 구조를 NAND 확장 기준으로 정리함

## Ⅰ. 개요

- **정의/개념**: NAND 플래시는 전하 상태로 데이터를 저장하는 비휘발성 메모리이며, 3D V-NAND는 셀을 수직 적층해 면적당 용량을 늘린 NAND 구조임
- **배경/필요성**: 2D NAND의 셀 간 간섭과 미세화 한계를 줄이면서 용량을 높이기 위해 수직 적층 방식이 필요함

## Ⅱ. 특징

- 수직 적층으로 면적당 용량을 높이면서 셀 간 간섭을 완화함
- 전하 포획 구조로 셀별 전하를 절연층에 저장하고 수직 적층 시 셀 간 간섭을 제어함
- 셀당 저장 비트가 증가할수록 용량 효율은 높아지지만 속도·수명·오류 여유는 줄어듦
- 적층 수 증가와 에칭 난도 상승이 제조 수율·비용·공급 능력을 좌우함

## Ⅲ. 종류 및 비교

| 판단 기준 | 2D NAND | 3D V-NAND |
|:---|:---|:---|
| 집적 방식 | 셀 선폭을 줄이는 평면 미세화로 가로 배치를 확장함 | 적층 수를 늘리는 수직 적층으로 셀을 층별로 쌓음 |
| 셀 간 간섭 | 미세화할수록 인접 셀 간격이 줄어 간섭이 커짐 | 수직 채널·절연층으로 층별 셀을 분리해 간섭을 억제함 |
| 제조 공정·확장 제약 | 평면 패터닝 미세화이며 선폭 축소에 따른 누설·간섭이 한계임 | 고종횡비 채널 에칭·다단 적층이며 층수 증가에 따른 에칭 균일도·수율이 한계임 |

> 요약: 2D NAND는 선폭 축소로 집적도를 늘리다 누설·간섭 한계에 부딪히고, 3D V-NAND는 층별 셀 분리로 간섭을 억제하며 적층 수로 집적도를 확장함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 메모리 셀 | 전하 상태로 셀당 저장 비트 수를 정하며 SLC(1비트)·MLC(2비트)·TLC(3비트)·QLC(4비트) 순으로 용량 효율은 높아지고 속도·수명·오류 여유는 줄어듦 |
| 수직 채널·스택 | 여러 층을 관통하는 채널이 적층 셀을 연결해 고집적 구성을 지원함 |
| 워드라인·블록 구조 | 페이지 단위 읽기·쓰기와 블록 단위 삭제를 수행하는 NAND 관리 단위를 형성함 |
| 컨트롤러·ECC 경로 | FTL이 주소를 매핑하고 ECC가 읽기 오류를 검출·교정함 |

```text
      +-------------+
      | 워드라인      |
      +-------------+
      | 워드라인      |
      +-------------+
      | 워드라인      |
      +-------------+
            |
            v
      +--------------+
      | 수직 채널 홀    |
      +--------------+
```

> 요약: 3D V-NAND는 수직 채널·워드라인·블록·ECC 경로로 고집적 NAND를 구성함.

## Ⅴ. 원리 및 절차 흐름도

```text
[프로그램] 빈 페이지 확인 -> 프로그램 펄스 인가 -> 임계 전압 검증 -> 목표 상태까지 반복
[읽기]     워드라인 선택 -> 임계 전압 감지 -> ECC 교정 -> 데이터 반환
[재사용]   유효 페이지 이동 -> 블록 삭제 -> 빈 블록 등록
```

1. **페이지 프로그램**: 빈 페이지에 펄스를 인가하고 임계 전압이 목표 상태에 도달할 때까지 검증을 반복함
2. **페이지 읽기**: 워드라인을 선택해 임계 전압을 감지하고 ECC로 오류를 교정함
3. **블록 재사용**: 유효 페이지를 다른 블록으로 옮긴 뒤 블록 전체를 삭제함

> 요약: NAND는 빈 페이지에 기록하고 블록을 재사용할 때 유효 페이지 이동과 블록 삭제를 수행함.

## Ⅵ. 실무 사례

1. 고단 3D NAND는 다단 적층 공정을 적용하고 웨이퍼 수율과 층별 결함 밀도를 확인함
2. QLC SSD는 ECC와 읽기 재시도를 적용하고 원시 비트 오류율과 보존 오류 건수를 확인함

## Ⅶ. 결론

- 3D V-NAND는 평면 미세화의 셀 간섭 한계를 수직 적층으로 전환한 NAND 확장 구조임
