## 미리 알고가기

- NAND 플래시는 비휘발성 메모리로 페이지 단위 쓰기와 블록 단위 삭제 특성을 가짐
- 평면 NAND는 미세화가 진행될수록 셀 간 간섭과 수명 문제가 커짐
- 3D V-NAND는 셀을 수직 적층해 집적도·내구성·성능을 함께 개선한 구조임

## Ⅰ. 개요

- **정의/개념**: NAND 플래시는 전하 상태로 데이터를 저장하는 비휘발성 메모리이며, 3D V-NAND는 셀을 평면으로 미세화하는 대신 수직 적층해 높은 용량, 신뢰성, 전력 효율을 제공하는 진화형 NAND 구조임
- **배경/필요성**: 2D NAND의 셀 간 간섭과 미세화 한계를 줄이면서 용량을 높이기 위해 수직 적층 방식이 필요함

## Ⅱ. 특징

- 수직 적층으로 면적당 용량을 높이면서 셀 간 간섭을 완화함
- 전하 포획 계열 구조를 사용해 평면형보다 데이터 보존성과 내구성 확보에 유리함
- 셀당 저장 비트가 증가할수록 용량 효율은 높아지지만 속도·수명·오류 여유는 줄어듦
- 적층 수 증가와 에칭 난도 상승이 제조 수율·비용·공급 능력을 좌우함

## Ⅲ. 종류 및 비교

| 판단 기준 | 2D NAND | 3D V-NAND |
|:---|:---|:---|
| 집적 방식 | 평면 미세화 중심으로 셀을 가로 배치함 | 수직 적층 중심으로 셀을 층별로 쌓음 |
| 장점 | 초기 구조가 단순함 | 높은 용량, 개선된 신뢰성, 전력 효율을 제공함 |
| 한계 | 미세화에 따라 간섭과 수명 문제가 커짐 | 적층과 에칭 공정 난도가 높아짐 |
| 확장 방향 | 공정 축소 한계가 뚜렷함 | 층수 증가와 구조 최적화로 계속 확장 가능함 |

> 요약: 2D NAND는 미세화 한계가 크고, 3D V-NAND는 수직 적층으로 용량을 확장함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 메모리 셀 | 전하 상태로 비트를 저장하며 MLC·TLC·QLC로 갈수록 용량 효율이 높아짐 |
| 수직 채널·스택 | 여러 층을 관통하는 채널이 적층 셀을 연결해 고집적 구성을 지원함 |
| 워드라인·블록 구조 | 페이지 단위 읽기·쓰기와 블록 단위 삭제를 수행하는 NAND 관리 단위를 형성함 |
| 컨트롤러·ECC 경로 | FTL과 ECC가 누적 오류를 통제해 저장장치 품질을 보장함 |

```text
      +-------------+
      | Word Line   |
      +-------------+
      | Word Line   |
      +-------------+
      | Word Line   |
      +-------------+
            |
            v
      +--------------+
      | Channel Hole |
      +--------------+
```

> 요약: 3D V-NAND는 수직 채널·워드라인·블록·ECC 경로로 고집적 NAND를 구성함.

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 페이지 단위 기록  | --> | 전하 상태 저장   | --> | 반복 읽기·검증    | --> | 블록 단위 삭제   |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **페이지 단위 기록**: 셀에 원하는 데이터 패턴을 프로그램함
2. **전하 상태 저장**: 셀의 임계 전압 상태로 정보를 유지함
3. **반복 읽기·검증**: ECC와 읽기 검증으로 오류를 통제함
4. **블록 단위 삭제**: 재사용하려면 큰 단위 블록을 먼저 지움

> 요약: NAND는 페이지에 기록하고 임계 전압으로 저장하며 재사용 전에 블록 단위 삭제가 필요함.

## Ⅵ. 실무 적용 및 유의점

1. 적층 수가 높아지면 채널 에칭과 균일도 확보가 어려워지므로 multi-stack 공정과 공정 제어를 적용하고 wafer yield, layer defect density로 확인함
2. QLC 같은 고집적 모드는 셀 상태 간격이 좁아 오류와 보존 문제가 커지므로 ECC, read retry, refresh 정책을 적용하고 raw bit error rate, retention error count로 확인함
3. 반복 읽기와 쓰기 집중은 read disturb와 wear-out을 가속하므로 wear leveling과 hot data 분산을 적용하고 TBW, read disturb count로 확인함

## Ⅶ. 결론

3D V-NAND는 용량 증가 자체보다 미세화 한계를 수직 적층으로 우회해 NAND 확장 경로를 다시 연 구조임.

## 작성 근거(검토용)

- NAND와 3D V-NAND는 페이지·블록 제약, 수직 적층, ECC, 읽기 교란 흐름으로 설명함
- 모호한 표현은 wafer yield, raw bit error rate, read disturb count로 구체화함
- 결론은 용량 증가보다 미세화 한계 우회와 확장 경로 확보로 정리함
