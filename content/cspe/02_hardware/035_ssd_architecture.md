## Ⅰ. 개요
- 정의: 낸드 플래시 메모리를 이용해 비휘발성 데이터를 저장하는 반도체 기반 보조기억장치
- 배경: 기계적 구동 방식인 HDD의 속도 한계 및 내구성 문제 해결 필요성
- 출제 의도
| 구분 | 내용 |
| --- | --- |
| 핵심 | 컨트롤러, DRAM 캐시, NAND 플래시, 채널/웨이 병렬성 |

## Ⅱ. 구성요소
```
[ Host Interface ] -> [ Controller (FTL) ] -> [ Channels ]
                             |                    |
                        [ DRAM Cache ]     [ NAND Flash Arrays ]
```
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 컨트롤러 | 데이터 읽기/쓰기 조율 및 수명 관리 수행 | 사령탑 |
| NAND 플래시 | 실제 데이터가 저장되는 물리적 셀 공간 | 창고 선반 |
| 채널/웨이 | 데이터 전송의 병렬성을 확보하기 위한 다중 통로 | 고속도로 차선 |
> 요약: 다수의 낸드 칩을 병렬로 제어하여 물리적 속도 한계를 극복함

## Ⅲ. 절차
1. 요청 수신: 호스트 인터페이스(SATA/NVMe)를 통해 명령 전달받음
2. 주소 변환: FTL이 논리적 주소(LBA)를 물리적 주소(PBA)로 매핑
3. 병렬 쓰기: 여러 채널과 웨이를 활용해 분산된 낸드 셀에 동시 기록
4. 배경 작업: 가비지 컬렉션, 웨어 레벨링 등을 통해 상태 최적화
> 요약: 주소 매핑과 병렬 처리를 통해 고속 데이터 입출력 및 수명 보존함

## Ⅳ. 문제점
- 쓰기 횟수 제한(P/E Cycle) 및 덮어쓰기 불가(Out-of-place Update) 특성 존재함

## Ⅴ. 개선방안
- 3D V-NAND 적층 기술 및 오버 프로비저닝(OP) 영역 확보로 가용성 증대함

## Ⅵ. 전망
- 낸드 적층 수의 1000단 시대 진입과 함께 컨트롤러의 AI 기능 탑재 가속화 예상됨
- 데이터 센터용 ZNS(Zoned Namespace) 도입을 통한 성능 편차(Tail Latency) 감소가 CSF임
