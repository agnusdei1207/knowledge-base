## Ⅰ. 개요
- 정의: CPU의 개입 없이 입출력 장치와 메모리가 직접 데이터를 주고받는 기술
- 배경: 대량의 데이터 전송 시 CPU가 모든 단어(Word)를 처리하는 부하를 방지
- 출제 의도
| 구분 | 내용 |
| --- | --- |
| 핵심 | 제어권 위임, 버스 마스터링, 사이클 스틸링, 인터럽트 |

## Ⅱ. 구성요소
```
[ CPU ] --(Hold/Grant)--> [ DMA Controller ]
                                |
[ Memory ] <--- (Bus) --------> [ I/O Device ]
```
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| DMA 컨트롤러 | CPU로부터 제어권을 넘겨받아 전송을 총괄하는 하드웨어 | 대리인 |
| 주소 레지스터 | 전송할 데이터의 시작 물리 주소를 저장 | 목적지 번지 |
| 카운트 레지스터 | 전송해야 할 데이터의 총 크기를 관리 | 물량 카운터 |
> 요약: CPU는 전송 시작과 끝만 관여하고, 실제 데이터 이동은 DMA가 수행함

## Ⅲ. 절차
1. 전송 준비: CPU가 DMA 컨트롤러에 전송 방향, 주소, 크기 설정
2. 버스 요청: DMA가 CPU에 버스 사용권(Bus Request) 요청 및 획득
3. 데이터 이동: 메모리와 I/O 장치 간 직접 데이터 전송 수행 (Cycle Stealing)
4. 종료 알림: 전송 완료 시 DMA가 CPU에 인터럽트를 발생시켜 보고
> 요약: CPU 부하를 획기적으로 줄여 시스템 전체의 멀티태스킹 효율을 높임

## Ⅳ. 문제점
- DMA와 CPU가 동시에 버스를 사용하려 할 때 충돌 및 대기 오버헤드 발생함

## Ⅴ. 개선방안
- 버스 사용권 우선순위 제어 및 블록/버스트 모드 전송으로 효율 최적화함

## Ⅵ. 전망
- IOMMU 하드웨어 지원을 통한 가상화 환경에서의 안전한 DMA 수행이 중요해짐
- AI 가속기 등 특수 목적 장치 간의 P2P DMA 기술이 성능 향상의 핵심 CSF임
