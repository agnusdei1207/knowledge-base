# 📖 【암기용】 개념 완전 이해

> 목적: 한 번 구우면 용도를 못 바꾸는 일반 칩(ASIC)과 달리, 수만 개의 논리 게이트를 소프트웨어 코드 한 줄로 마음대로 재배치해 '트랜스포머 같은 하드웨어'로 둔갑시키는 FPGA의 마법을 완벽히 이해하게 만든다.

## 한눈에
- **개요**: 현장(Field)에서 사용자가 프로그래밍(Programmable)하여 논리 게이트의 연결선(Array)을 내 맘대로 바꿀 수 있는 반도체(FPGA)를 활용해, 수시로 바뀌는 인공지능(AI) 알고리즘을 하드웨어 레벨에서 초고속으로 가속하는 기술.
- **왜 필요한가**: CPU는 연산이 너무 느리고, GPU는 전기를 미친 듯이 많이 먹는다. 아예 AI만 돌리는 전용 칩(ASIC/NPU)을 만들자니, 칩 하나 굽는 데 2년과 수백억이 드는데 그사이에 AI 알고리즘(CNN -> Transformer)이 옛날 기술이 되어버린다. 그래서 **"전기는 GPU보다 적게 먹으면서, 매달 바뀌는 최신 AI 트렌드에 맞춰 하드웨어 회로 자체를 찰흙처럼 뜯어고칠 수 있는"** 꿈의 칩, FPGA가 우주/통신/엣지 AI의 핵심으로 떠올랐다.
- **핵심 직관**: 
  - **ASIC (도장)**: 공장에서 딱 정해진 모양(AI 알고리즘)으로 철판을 파버림. 도장 찍는 속도는 세상에서 제일 빠르지만, 글씨를 바꾸려면 도장을 버리고 새로 파야 함 (변경 불가).
  - **FPGA (레고 블록판)**: 텅 빈 블록판에 수만 개의 레고 조각(게이트)만 깔려 있음. 프로그래머가 코드(HDL)를 짜서 올리면, 레고 조각들이 스스로 움직여 조립되면서 어제는 '영상 인식 칩', 오늘은 '음성 인식 칩'으로 변신함.

## 깊이 이해
- **배경·문제의식**: 자율주행차나 화성 탐사선 로봇에 무겁고 300W씩 전기를 퍼먹는 엔비디아 GPU를 달 수는 없다. 전력 소모(50W 이하)는 극단적으로 낮으면서 센서 데이터는 실시간(수 마이크로초)으로 처리해야 한다. 무엇보다 로봇이 화성에 도착한 1년 뒤에 지구에서 새로운 AI 알고리즘을 쏴주면 칩 회로가 새것으로 업데이트되어야 했다(재설정성).
- **작동 원리 (마법의 LUT와 스위치 매트릭스)**: 
  - FPGA 안에는 AND, OR 게이트 대신 **LUT (Look-Up Table)** 이라는 작은 진리표 메모리가 촘촘히 박혀 있다.
  - VHDL이나 Verilog 같은 언어로 "AI 행렬 곱셈을 해라"라고 코드를 짜서 부어 넣으면(Bitstream), 칩 내부의 프로그래머블 스위치들이 찰칵찰칵 닫히면서 LUT들을 거미줄처럼 연결해 '행렬 곱셈 전용 칩'으로 물리적으로 변신한다.
- **AI 가속에서의 강점 (비정형 데이터 처리와 초저지연)**: 
  - GPU는 데이터를 메모리에 왕창 모아놨다가 한 방에 병렬로 터뜨리는 방식이라 대기 시간(Batch Latency)이 길다.
  - FPGA는 센서에서 0101 데이터가 들어오자마자 메모리를 안 거치고 즉각 논리 게이트 파이프라인을 관통시켜 답을 내버린다. 지연 시간(Latency)이 거의 0에 수렴하여 미사일 궤적 제어나 초단타 매매(HFT) AI에 최적이다.
- **흔한 오해·주의점**: "FPGA에 C언어나 파이썬 코드를 텍스트로 넣는 거다?" 절대 아니다. 코드는 논리 게이트를 '어떻게 배선할지' 설명하는 하드웨어 도면(HDL)일 뿐이다. 최근엔 C언어를 H/W로 자동 번역해 주는 HLS(고수준 합성) 툴이 좋아져 편해지긴 했다.

## 연결 개념
- ASIC (주문형 반도체) — FPGA에서 알고리즘 검증이 완벽히 끝나 "이젠 안 바꿀래!" 확신이 서면, 그걸 쇳물에 부어 영구적인 도장(ASIC)으로 찍어내어 대량생산(원가 절감) 한다.
- 추론 (Inference) — 학습(Training)은 무조건 거대한 GPU 밭에서 하지만, 학습된 뇌를 현실(드론, 로봇)에 심어서 써먹는 추론 영역에서는 가볍고 전력을 덜 먹는 FPGA가 대활약한다.
- 비트스트림 (Bitstream) — FPGA 칩을 변신시키기 위해 컴퓨터에서 USB로 밀어 넣는 '하드웨어 스위치 연결 도면' 압축 파일.

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: FPGA(Field-Programmable Gate Array) AI 가속은 제조 후에도 내부 논리 블록(CLB)과 배선(Routing)을 프로그래머블하게 재구성할 수 있는 비메모리 반도체를 활용해, AI 신경망 연산을 하드웨어 레벨에서 직접 병렬 파이프라이닝하는 기술이다.
> 2. **가치**: GPU 대비 전력 소모(Watt)가 압도적으로 낮고 메모리 캐시 지연이 없어 극단적인 초저지연(Ultra-Low Latency) 추론이 가능하며, 매번 급변하는 AI 알고리즘 트렌드(CNN→RNN→Transformer)에 맞춰 칩 구조를 실시간 재설계(Reconfigurability) 할 수 있다.
> 3. **판단 포인트**: 초단타 매매(HFT), 자율주행, 우주항공 등 알고리즘 유연성과 초저전력(Edge AI)이 요구되는 추론(Inference) 시장을 장악하고 있으나, 하드웨어 기술 언어(HDL/HLS) 장벽과 ASIC 대비 비싼 단가가 최대 트레이드오프다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| AI 가속 칩셋 생태계에서 FPGA만의 독보적 포지셔닝 이해 | H/W 레벨의 재구성성(Reconfigurability), LUT 결선 조작 | FPGA를 범용(CPU/GPU)이나 고정(ASIC) 칩으로 뭉뚱그려 설명하는 치명적 오류 |
| GPU 한계점(발열, 지연)과 Edge AI 환경에서의 극복 구조 분석 | 초저지연(Deterministic Latency) 및 와트당 전성비 우수성 | AI 모델 '학습(Training)'에 주로 쓰인다고 오답을 적는 것 (학습은 GPU, FPGA는 추론용) |

> 요약: FPGA는 세상에서 제일 빠른 칩(ASIC)이나 가장 병렬성이 쩌는 칩(GPU)은 아니지만, "어제 산 칩을 오늘 완전히 다른 AI 칩으로 물리적 튜닝이 가능한 유일한 변신 로봇"임을 서술해야 한다.

## Ⅰ. 개요 및 필요성

- 정의: 사용자가 하드웨어 기술 언어(HDL)를 이용해 내부 로직 게이트 배열과 상호 연결망을 임의로 재설정(Reprogrammable)할 수 있는 반도체를 기반으로 인공지능 연산을 가속하는 엣지 아키텍처
- 배경: GPU는 AI 학습에 탁월하나 전력 소모가 극심하여 엣지 디바이스(드론, 로봇)에 탑재가 불가능하고, 전용 NPU(ASIC)는 수십억의 설계 비용과 2년의 생산 주기가 소요되어 급변하는 AI 알고리즘 대응에 실패함
- 필요성: 마이크로초(㎲) 단위의 절대적 실시간성(Deterministic Latency)과 10~50W 수준의 초저전력을 유지하면서도, 새로운 AI 신경망(Topology) 모델 배포 시 하드웨어 회로 자체를 OTA로 펌웨어 굽듯 재구성할 수 있는 유연한 가속기 필수

## Ⅱ. 구조 및 구성요소 (하드웨어 논리 재구성 블록)

```text
[FPGA 내부 논리 블록 및 인터커넥트 구성도]
+====================================================================+
|  [ I/O Block ] <---- 데이터 입출력 (센서, 카메라 직접 연결)           |
|                                                                    |
|  (프로그래머블 스위치 매트릭스 - 배선망)                            |
|    +---------+       +---------+       +---------+                 |
|    | CLB (LUT)| ----> | CLB (LUT)| ----> | DSP (곱셈)| -> AI 가속   |
|    +---------+       +---------+       +---------+                 |
|                                                                    |
|  [ BRAM (Block RAM) ] <---- 칩 내장 초고속 메모리 (데이터 보관)     |
+====================================================================+
```

| 핵심 구성요소 | 주요 역할 | AI 연산 시 활용 특성 |
|:---|:---|:---|
| CLB / LUT | 논리(Logic) 게이트 재구성 | Look-Up Table을 통해 사용자가 원하는 어떤 복잡한 비선형 활성화 함수(ReLU 등)의 논리 회로든 자유롭게 구현 |
| DSP Slices | 고속 산술 연산(MAC) 전담 | AI 신경망의 핵심인 행렬 곱셈-누산(Multiply-Accumulate)을 1클럭만에 H/W 적으로 동시 다발 처리 |
| 스위치 매트릭스 | 블록 간 통신 배선(Routing)| CPU처럼 버스를 공유해 병목이 생기는 게 아니라, 특정 연산만을 위한 1:1 직통 고속도로(Pipeline)를 물리적으로 개통 |
| BRAM | 칩 내부 온다이(On-die) 캐시 | 외부 DRAM에 갈 필요 없이 신경망 가중치(Weight)를 칩 안에 적재하여 지연시간(Latency) 제로화 |

> 요약: GPU가 100만 명의 바보(코어)에게 메모리에서 명령어를 계속 퍼다 주며 연산하는 방식이라면, FPGA는 아예 컨베이어 벨트(파이프라인) 자체를 공장장(프로그래머) 입맛대로 용접해 버리는 방식이다.

## Ⅲ. 동작원리 및 AI 파이프라이닝 마이크로 흐름

FPGA는 일반 소프트웨어 프로그램처럼 메모리에서 코드를 순차적으로 읽어(Fetch) 실행하지 않는다.

```text
[FPGA 기반 AI 추론 모델 하드웨어 포팅 및 동작 흐름]
1. [설계/변환] : TensorFlow/PyTorch로 훈련된 AI 모델을 HLS(고수준 합성) 툴을 이용해 하드웨어 언어(HDL/Bitstream)로 변환
2. [칩 재구성] : Bitstream을 FPGA에 플래싱 -> 칩 내부 스위치가 물리적으로 딸깍딸깍 재배열됨
3. [스트리밍]  : 외부 센서 데이터(예: 4K 영상)가 메모리를 거치지 않고 I/O 핀을 통해 즉각 CLB 파이프라인으로 유입
4. [공간적 병렬]: 들어오자마자 컨베이어 벨트를 타듯 DSP(곱셈) -> LUT(활성화 함수) -> BRAM(합산)을 논스톱 관통
5. [초저지연]  : 수 마이크로초(㎲) 만에 자율주행 회피 방향(추론 결과) 즉각 출력
```

| 처리 특징 | 폰 노이만 CPU/GPU 방식 (시간적 병렬성) | FPGA 가속 방식 (공간적 공간성) |
|:---:|:---|:---|
| 명령어 처리 | 메모리에서 명령어를 Fetch -> Decode -> Execute 반복 | **명령어 자체가 없음**. 데이터가 고정된 회로망(배선)을 통과하며 물리적 변환됨 |
| 연산 지연 | 배치(Batch) 단위로 모아서 처리하므로 Latency 스파이크 유발 | **데이터가 유입되는 즉시 스트리밍 처리 (Deterministic Latency)** |

> 요약: FPGA AI 가속은 소프트웨어 연산이 아니다. 물이 파이프를 굽이굽이 통과하며 정수기를 거치듯, 데이터가 물리적 회로를 흘러가며 정답(추론)으로 정제되는 궁극의 하드웨어 스트리밍이다.

## Ⅳ. 심화 비교: AI 가속기 생태계 대조표 (GPU vs FPGA vs ASIC)

| 비교 축 | GPU (범용 병렬 가속) | FPGA (재구성 가속 - Xilinx/Intel) | ASIC / NPU (전용 가속 - 구글 TPU) |
|:---|:---|:---|:---|
| 구조 유연성 | 소프트웨어 S/W로 무한 유연 | **하드웨어 H/W 회로 자체를 뜯어고침** | 하드웨어 고정 (출시 후 수정 절대 불가) |
| AI 주요 타겟 | 대규모 LLM **학습 (Training)** | 자율주행, 군사, 초단타매매 **추론 (Inference)** | 대량 양산형 엣지 기기 **추론 (Inference)** |
| 와트당 전성비 | 최악 (수백 W의 막대한 발열) | **매우 우수 (10W ~ 50W 대)** | 최상 (버려지는 게이트가 없음) |
| 개발 난이도 / 비용| CUDA(C++)로 쉬움 / 칩 구매비용 높음 | **HDL/HLS 장벽 매우 높음 / 초기 개발비 높음** | 설계 난이도 최상 / 대량 생산 시 원가 최저 |
| 지연 시간(Latency)| 메모리 맵핑으로 인한 수십 ms 지연 | **수 마이크로초(㎲) 락다운 보장** | 모델에 따라 편차 있음 |

> 요약: 신규 AI 모델이 나왔을 때 GPU는 S/W 업데이트를 하고, ASIC은 옛날 칩을 버리고 새 칩을 다시 설계해야 하지만, FPGA는 원격으로 회로 도면을 쏴주면 스스로 새 칩으로 진화한다.

## Ⅴ. 제약 사항 및 FPGA 한계 돌파 기술 (개발 장벽 완화)

| 리스크 | 발생 원인 | S/W 및 툴체인 대응 방안 | 극복 원리 및 효과 |
|:---|:---|:---|:---|
| 극악의 개발 난이도| AI 소프트웨어 엔지니어(Python)가 물리적인 트랜지스터 클럭 타이밍을 맞추는 Verilog/VHDL(하드웨어 언어)을 짤 수 없어 개발 병목 붕괴 | **HLS (High-Level Synthesis / 고수준 합성)** | C, C++, OpenCL 코드를 입력하면 컴파일러가 알아서 최적화된 하드웨어 배선 도면(HDL)으로 자동 번역하여 플래싱까지 끝내주는 브리지 도구 도입 |
| 프레임워크 종속성 | 텐서플로우/파이토치로 훈련된 가중치(Weight) 모델을 하드웨어 칩에 이식하기 위한 수작업 파서(Parser) 부재 | **AI 전용 컴파일러 스택 (Vitis AI 등)** | AMD(Xilinx) 등의 제조사가 범용 AI 모델(ONNX)을 FPGA 추론용 Bitstream으로 원클릭 양자화(Quantization) 및 매핑해 주는 AI 컴파일러 생태계 무상 제공 |
| 낮은 동작 클럭 | 스위치 매트릭스(프로그래머블 배선)를 거치면서 신호 지연이 발생해 ASIC(수 GHz) 대비 칩 클럭이 1/5 수준(수백 MHz)으로 추락 | **경량화 모델 (양자화 / 프루닝)** | FP32(실수 연산) 대신 INT8 묶음(양자화)이나 2-bit BNN(이진 신경망)을 FPGA LUT 구조에 억지로 우겨넣어 클럭의 약점을 극강의 병렬 배선으로 압살시킴 |

> 요약: FPGA 업계의 영원한 숙제는 "어떻게 하면 소프트웨어 코더들이 하드웨어인 줄 모르게 칩을 구워줄까"이며, HLS 컴파일러의 진화가 FPGA AI 가속의 대중화를 이끌고 있다.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. Microsoft Azure 클라우드 Project Brainwave 적용: 데이터센터에 입고되는 수십만 대의 서버 보드에 미리 범용 FPGA(Altera/Intel)를 박아두고, 어제는 Bing 검색 AI 가속(RNN)용으로 회로를 세팅했다가, 오늘은 ChatGPT 연산(Transformer)용 회로로 실시간 핫-스와핑(Reconfiguration)하여 인프라 투자(CAPEX) 효용 극대화
2. 금융권 HFT(초고빈도 매매) 트레이딩 봇 구축: 1나노초 차이로 주식 체결이 갈리는 월스트리트 거래망에서, 시장 가격 피드(Ethernet)가 CPU나 커널 메모리를 거치지 않고 직접 랜카드에 박힌 FPGA 핀으로 들어가 논스톱 AI 회피 알고리즘을 거쳐 즉각 주문(Buy/Sell) 패킷으로 뿜어져 나가는 Zero-Latency 트레이딩 망 구축
3. 극한 환경(우주항공/국방) Edge AI 레이더 표적 인식: 방사능이 쏟아지는 인공위성이나 미사일 헤드에서, GPU는 발열로 타버리고 ASIC은 버그 수정이 불가능하므로, 방사능 내성(Rad-hard) 처리된 FPGA에 저전력 CNN 모델을 이식하여 타격 직전까지 H/W 업데이트를 지원하는 엣지 추론 시스템 가동

**결론 (2줄):**
- 기술사 판단: FPGA AI 가속은 GPU의 전력 낭비와 ASIC의 경직성 사이에서, 하드웨어 회로망의 실시간 재구성(Reconfigurability)이라는 비대칭 무기로 공간적 파이프라이닝을 완성한 궁극의 추론형 반도체다.
- 향후 방향: FPGA 단독 칩의 한계를 넘어, ARM 멀티코어 CPU와 NPU, 그리고 FPGA 재구성 블록(Fabric)을 하나의 단일 칩 패키징(SoC/Chiplet)으로 결합한 ACAP(적응형 컴퓨팅 가속 플랫폼) 아키텍처로 완전 진화하고 있다.
