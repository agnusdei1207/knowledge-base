## 미리 알고가기

- FPGA는 논리 회로를 제조 후에도 재구성할 수 있는 반도체임
- AI 가속에서는 DSP, BRAM, 파이프라인을 활용해 저지연 추론을 구현함
- GPU보다 지연 제어가 유리하고 ASIC보다 재구성성이 높지만 설계 난도가 높음

## Ⅰ. 개요

- **정의/개념**: FPGA AI 가속은 딥러닝 모델의 핵심 연산 흐름을 FPGA 내부의 LUT와 DSP와 온칩 메모리에 매핑해 특정 추론 경로를 하드웨어 파이프라인으로 실행하는 가속 방식임
- **배경/필요성**: 실시간 제어와 엣지 환경에서는 GPU의 배치 중심 처리만으로 지연을 맞추기 어렵고, ASIC처럼 고정된 구조는 모델 변화 대응이 어렵기 때문임

## Ⅱ. 특징

- 파이프라인 기반 구조로 일정하고 낮은 지연시간을 구현하기 쉬움
- 비트폭 최적화와 사용자 정의 연산을 하드웨어 수준에서 반영할 수 있음
- 설계 유연성은 높지만 타이밍 클로저가 어렵고 개발 생산성이 낮아지기 쉬움
- 온칩 메모리 한계와 외부 메모리 대역폭이 실제 성능을 좌우함

## Ⅲ. 종류 및 비교

| 판단 기준 | GPU | FPGA | ASIC |
|:---|:---|:---|:---|
| 유연성 | 높음 | 중간 이상 | 낮음 |
| 지연시간 | 중간 | 낮음 | 최저 수준 |
| 전력 효율 | 중간 | 높음 | 최고 수준 |
| 개발 기간 | 짧음 | 중간 | 긺 |

> 요약: FPGA는 GPU보다 지연 제어가 쉽고 ASIC보다 변경 여지를 남김.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| LUT, FF 자원 | 제어 로직과 사용자 정의 데이터 경로를 구성해 모델 특화 연산을 구현함 |
| DSP Slice | MAC 중심 연산을 가속해 CNN과 MLP 추론 성능을 좌우함 |
| BRAM, URAM | 가중치와 활성값을 온칩에 저장해 외부 메모리 병목을 줄임 |
| HLS, Runtime Stack | 상위 모델을 하드웨어 파이프라인으로 변환하고 재구성성을 운영 절차에 연결함 |

```text
+-------------+     +-------------+     +-------------+     +-------------+
| HLS / Model | --> | LUT / DSP   | --> | BRAM / URAM | --> | FPGA Output |
+-------------+     +-------------+     +-------------+     +-------------+
```

> 요약: FPGA AI 가속은 LUT·DSP·온칩 메모리를 모델 경로에 맞춰 배치함.

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 모델 최적화    | --> | 회로 매핑      | --> | 파이프라인 실행 | --> | 출력/재구성    |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **모델 최적화**: 양자화와 pruning으로 하드웨어 친화 형태로 변환함
2. **회로 매핑**: 연산 그래프를 LUT, DSP, BRAM 자원에 배치함
3. **파이프라인 실행**: 입력 데이터를 고정 경로로 연속 처리함
4. **출력 및 재구성**: 모델 변경 시 비트스트림을 갱신해 구조를 조정함

> 요약: 모델을 양자화한 뒤 회로 자원에 매핑하고 파이프라인으로 반복 실행함.

## Ⅵ. 실무 적용 및 유의점

1. 산업 비전·초저지연 제어는 FPGA가 지연 분산을 줄이기 쉽지만 외부 메모리 대역폭이 부족하면 가속 효과가 줄어드므로 양자화와 온칩 데이터 재사용을 적용하고 frame latency, memory bandwidth utilization으로 확인함
2. 통신 장비·맞춤형 추론 파이프라인은 모델 변화에 맞춰 재구성할 수 있지만 타이밍 클로저가 일정을 지연시키므로 HLS와 기준 설계 흐름을 적용하고 compile turnaround time, deterministic latency로 확인함

## Ⅶ. 결론

FPGA AI 가속은 낮은 지연과 모델 변경 여지가 모두 필요한 구간에 맞으므로 재구성 필요성과 메모리 병목을 함께 판단해야 함.

## 작성 근거(검토용)

- FPGA AI 가속은 LUT, DSP, BRAM/URAM, 파이프라인을 핵심 구성으로 설명함
- GPU·FPGA·ASIC 비교는 지연시간, 전력 효율, 개발 기간을 중심으로 정리함
- 실무 판단은 memory bandwidth utilization, compile turnaround time, deterministic latency를 확인 기준으로 둠
