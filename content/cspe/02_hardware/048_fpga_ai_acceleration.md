## 미리 알고가기

- FPGA는 논리 회로를 제조 후에도 재구성할 수 있는 반도체임
- AI 가속에서는 DSP, BRAM, 파이프라인을 활용해 저지연 추론을 구현함
- 연산 경로를 파이프라인으로 배치하고 비트스트림을 다시 작성해 모델별 회로를 변경함
- BRAM·URAM: FPGA 내부에 내장된 블록 RAM·초고밀도 RAM으로 온칩 데이터 저장에 사용함
- DSP 슬라이스: 곱셈·누산(MAC) 연산을 전용 하드웨어로 처리하는 FPGA 내장 블록임
- HLS(High-Level Synthesis): C·Python 같은 상위 언어 코드를 하드웨어 회로 기술로 변환하는 합성 기법임

## 작성 근거(검토용)

- FPGA AI 가속은 LUT, DSP, BRAM·URAM, 파이프라인을 핵심 구성으로 설명함
- GPU·FPGA·ASIC은 기능 변경, 실행 구조, 병렬화 단위를 기준으로 비교함
- 실무 판단은 최대 프레임 지연, 메모리 대역폭 사용률, 타이밍 여유로 구체화함

## Ⅰ. 개요

- **정의/개념**: FPGA AI 가속은 모델 연산을 LUT·DSP·온칩 메모리에 매핑해 재구성 가능한 하드웨어 파이프라인으로 추론하는 방식임
- **배경/필요성**: 실시간 제어의 지연 상한과 모델 변경 요구를 함께 충족하기 위해 재구성 가능한 하드웨어 파이프라인이 필요함

### 쉽게 이해하기 (학습용)
- 공장 조립라인을 제품이 바뀔 때마다 다시 배치할 수 있는 레고 블록으로 만들어두는 것과 같음

## Ⅱ. 특징

- 파이프라인의 단계와 시작 간격을 고정해 입력별 실행 사이클을 예측할 수 있음
- 비트폭 최적화와 사용자 정의 연산을 하드웨어 수준에서 반영할 수 있음
- 회로를 재구성할 수 있지만 합성·배치배선·타이밍 클로저가 모델 배포 시간을 늘림
- 온칩 메모리 용량과 외부 메모리 대역폭이 파이프라인 처리량을 좌우함

### 쉽게 이해하기 (학습용)
- 조립라인 각 공정 시간이 일정해 완성 시점을 미리 알 수 있지만, 라인을 새로 짜는 데는 시간이 걸림

## Ⅲ. 종류 및 비교

| 판단 기준 | GPU | FPGA | ASIC |
|:---|:---|:---|:---|
| 기능 변경 | 커널·소프트웨어 교체 | 비트스트림 재작성 | 회로 재설계·재제작 |
| 실행 구조 | SIMT 명령 실행 | 사용자 정의 파이프라인 | 고정 데이터플로우 |
| 병렬화 단위 | 스레드·워프 | 연산 단계·데이터 경로 | PE·MAC 배열 |

> 요약: FPGA는 연산 경로를 고정 파이프라인으로 구성해 실행 사이클을 정하고, 비트스트림 재작성으로 회로를 변경함.

### 쉽게 이해하기 (학습용)
- 소프트웨어만 바꾸면 되는 범용 기계(GPU), 배선을 다시 까는 조립라인(FPGA), 아예 새로 찍어내는 전용 틀(ASIC)의 차이와 같음

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| LUT·FF 자원 | 제어 로직과 사용자 정의 데이터 경로를 구성해 모델 특화 연산을 구현함 |
| DSP 슬라이스 | MAC 중심 연산을 병렬 실행해 CNN·MLP의 연산 처리량을 결정함 |
| BRAM·URAM | 가중치와 활성값을 온칩에 저장해 외부 메모리 전송량을 줄임 |
| HLS·런타임 | 상위 모델을 하드웨어 파이프라인으로 변환하고 비트스트림 적재를 관리함 |

```text
+-------------+     +-------------+     +-------------+     +-------------+
| HLS·모델    | --> | LUT·DSP     | --> | BRAM·URAM   | --> | FPGA 출력   |
+-------------+     +-------------+     +-------------+     +-------------+
```

> 요약: FPGA AI 가속은 LUT·DSP·온칩 메모리를 모델 경로에 맞춰 배치함.

### 쉽게 이해하기 (학습용)
- 자유롭게 배선 가능한 스위치판(LUT·FF), 곱셈 전용 기계(DSP 슬라이스), 작업대 옆 부품함(BRAM·URAM), 설계도를 배선으로 바꿔주는 도구(HLS·런타임)가 함께 있는 공장과 같음

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 모델 최적화    | --> | 합성·배치배선  | --> | 비트스트림 적재 | --> | 파이프라인 추론 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **모델 최적화**: 양자화와 가지치기로 연산량과 비트폭을 줄임
2. **합성·배치배선**: 연산 그래프를 LUT, DSP, BRAM 자원에 매핑하고 타이밍을 검증함
3. **비트스트림 적재**: 검증한 회로 구성을 FPGA에 기록함
4. **파이프라인 추론**: 입력 데이터를 배치한 연산 경로로 연속 처리함

> 요약: 모델을 최적화해 회로 자원에 매핑하고 비트스트림을 적재한 뒤 파이프라인으로 추론함.

### 쉽게 이해하기 (학습용)
- 설계도를 줄이고, 실제 배선도로 바꾸고, 기계에 적재한 뒤, 제품을 연속 생산하는 순서와 같음

## Ⅵ. 실무 사례

1. 산업 비전 파이프라인은 양자화와 온칩 데이터 재사용을 적용하고 최대 프레임 지연·메모리 대역폭 사용률을 확인함
2. 데이터센터 추론 카드는 HLS 합성 후 모든 경로를 검증하고 최소 타이밍 여유·비트스트림 생성 시간을 확인함

### 쉽게 이해하기 (학습용)
- 카메라 검사 라인의 처리 속도를 재거나, 새 배선도가 기계 속도를 따라가는지 여유 시간을 확인하는 것과 같음

## Ⅶ. 결론

- FPGA AI 가속은 모델 연산을 LUT·DSP·온칩 메모리에 매핑한 재구성 가능 파이프라인으로 저지연 추론을 수행하는 방식임
- 지연 상한과 모델 변경이 함께 필요한 추론에는 FPGA를 적용하되, 합성·배치배선에 걸리는 재구성 시간과 온칩 메모리 대역폭을 함께 확인해야 함

### 쉽게 이해하기 (학습용)
- 빠른 응답과 언제든 라인 교체가 둘 다 필요한 공장에 맞는 방식이며, 교체 시간과 부품 공급 속도를 함께 따져야 함
