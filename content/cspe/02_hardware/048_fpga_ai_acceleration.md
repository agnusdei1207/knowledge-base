## 미리 알고가기

- FPGA는 논리 회로를 배치 후에도 재구성할 수 있는 반도체임
- AI 가속에서는 DSP, BRAM, 파이프라인을 활용해 저지연 추론을 구현함
- GPU보다 유연하고 ASIC보다 재구성 가능하지만 설계 난도가 높음

## Ⅰ. 개요

- **정의/개념**: FPGA AI 가속은 딥러닝 모델의 핵심 연산 흐름을 FPGA 내부의 LUT와 DSP와 온칩 메모리에 매핑해 특정 추론 경로를 하드웨어 파이프라인으로 실행하는 가속 방식임
- **배경/필요성**: 실시간 제어와 엣지 환경에서는 GPU의 배치 중심 처리보다 낮은 지연과 높은 전력 효율이 필요하고, ASIC처럼 완전히 고정된 구조는 모델 변화 대응이 어렵기 때문임

## Ⅱ. 특징

- 파이프라인 기반 구조로 일정하고 낮은 지연시간을 만들기 쉬움
- 비트폭 최적화와 사용자 정의 연산을 하드웨어 수준에서 반영할 수 있음
- 설계 유연성은 높지만 타이밍 클로저와 개발 생산성이 어려운 편임
- 온칩 메모리 한계와 외부 메모리 대역폭이 실제 성능을 좌우함

## Ⅲ. 종류 및 비교

| 판단 기준 | GPU | FPGA | ASIC |
|:---|:---|:---|:---|
| 유연성 | 높음 | 중간 이상 | 낮음 |
| 지연시간 | 중간 | 낮음 | 매우 낮음 |
| 전력 효율 | 중간 | 높음 | 매우 높음 |
| 개발 기간 | 짧음 | 중간 | 긺 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| LUT, FF 자원 | 제어 로직과 사용자 정의 데이터 경로를 구성해 모델 특화 연산을 구현함 |
| DSP Slice | MAC 중심 연산을 가속해 CNN과 MLP 추론 성능을 좌우함 |
| BRAM, URAM | 가중치와 활성값을 온칩에 저장해 외부 메모리 병목을 줄임 |
| HLS, Runtime Stack | 상위 모델을 하드웨어 파이프라인으로 변환하고 재구성성을 운영 수준에서 활용하게 함 |

```text
+-------------+     +-------------+     +-------------+     +-------------+
| HLS / Model | --> | LUT / DSP   | --> | BRAM / URAM | --> | FPGA Output |
+-------------+     +-------------+     +-------------+     +-------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 모델 최적화    | --> | 회로 매핑      | --> | 파이프라인 실행 | --> | 출력/재구성    |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **모델 최적화**: 양자화와 pruning으로 하드웨어 친화 형태로 변환함
2. **회로 매핑**: 연산 그래프를 LUT, DSP, BRAM 자원에 배치함
3. **파이프라인 실행**: 입력 데이터를 고정 경로로 연속 처리함
4. **출력 및 재구성**: 모델 변경 시 비트스트림을 갱신해 구조를 조정함

## Ⅵ. 문제점 및 해결 방안

1. 문제: HDL과 타이밍 클로저 중심 개발은 소프트웨어 기반 AI 팀에게 진입 장벽이 매우 높을 수 있음
   - 해결방안: HLS와 전용 컴파일러 스택을 도입하고 compile turnaround time과 developer productivity로 개선 효과를 검증함
2. 문제: 외부 메모리 대역폭이 부족하면 계산 자원이 남아도 실제 추론 성능이 기대보다 낮을 수 있음
   - 해결방안: 온칩 데이터 재사용과 weight compression을 적용하고 memory bandwidth utilization과 latency로 검증함
3. 문제: 대형 모델은 단일 FPGA 자원 한계를 넘기 쉬워 파티셔닝 복잡도가 커질 수 있음
   - 해결방안: 모델 분할과 멀티 FPGA 연결을 설계하고 fit rate와 end-to-end throughput으로 적합성을 검증함

## Ⅶ. 적용 사례

- 산업 비전 검사에서는 저지연 추론 파이프라인을 FPGA에 구현하고, frame latency와 power efficiency로 결과를 확인함
- 통신 장비 엣지 AI에서는 전처리와 추론을 한 칩에서 수행하고, throughput과 thermal envelope로 결과를 확인함
- 금융 초저지연 분석에서는 맞춤 연산 경로를 구성하고, inference latency와 determinism로 결과를 확인함

## Ⅷ. 결론

FPGA AI 가속은 유연성과 저지연이 동시에 필요한 구간에서 가장 실용적이므로, 모델 안정성보다 응답 시간과 전력 제약이 중요한지 먼저 판단해 선택해야 함.
