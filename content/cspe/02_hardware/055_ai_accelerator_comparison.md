## 미리 알고가기

- CPU, GPU, NPU, FPGA, ASIC은 같은 AI 연산도 목표와 제약이 다름
- 선택 기준은 유연성, 지연, 전력, 배포 규모, 개발 시간임
- 가속기 평가는 이론 성능보다 실제 모델 적합성과 운영비가 중요함

## Ⅰ. 개요

- **정의/개념**: AI 가속기 비교는 신경망 처리에 사용되는 주요 하드웨어를 연산 구조와 전력 효율과 유연성과 운영 목적 기준으로 구분해 적합한 배치 위치를 결정하는 작업임
- **배경/필요성**: AI 시스템은 학습, 대규모 추론, 온디바이스 추론처럼 요구 조건이 다르므로, 하나의 가속기로 모든 문제를 해결하기보다 워크로드별 최적 선택이 필요함

## Ⅱ. 특징

- CPU는 유연성과 제어 능력이 높지만 대규모 텐서 연산에는 비효율적임
- GPU는 범용 병렬성과 생태계가 강해 학습과 서버 추론의 표준임
- NPU와 ASIC은 전력 효율이 높지만 모델 제약과 생태계 의존성이 큼
- FPGA는 재구성 가능성과 저지연이 강점이나 개발 난도가 높음

## Ⅲ. 종류 및 비교

| 판단 기준 | CPU | GPU | NPU | FPGA | ASIC |
|:---|:---|:---|:---|:---|:---|
| 유연성 | 매우 높음 | 높음 | 중간 | 높음 | 낮음 |
| 전력 효율 | 낮음 | 중간 | 높음 | 높음 | 매우 높음 |
| 학습 적합성 | 낮음 | 매우 높음 | 낮음 | 낮음 | 낮음 |
| 저지연 추론 | 낮음 | 중간 | 높음 | 높음 | 매우 높음 |
| 개발 시간 | 짧음 | 짧음 | 중간 | 긺 | 매우 긺 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 범용 연산 경로 | CPU와 GPU처럼 다양한 연산을 처리할 수 있지만 전력과 면적 오버헤드가 큼 |
| 전용 연산 배열 | NPU와 ASIC은 MAC 배열과 저정밀 연산기로 반복 신경망 작업에 최적화됨 |
| 메모리, 인터커넥트 | HBM, SRAM, PCIe, NVLink 같은 데이터 경로 품질이 실제 성능과 확장성을 결정함 |
| Compiler, Runtime Stack | 하드웨어 선택만으로 끝나지 않고 모델 변환과 fallback 관리 능력이 체감 성능을 좌우함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 워크로드 분석   | --> | 제약 조건 식별 | --> | 가속기 선택    | --> | 성능/비용 검증 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **워크로드 분석**: 학습인지 추론인지와 모델 구조를 확인함
2. **제약 조건 식별**: 지연, 전력, 비용, 배포 규모를 정리함
3. **가속기 선택**: 적합한 하드웨어 계열을 고름
4. **성능 및 비용 검증**: 실제 모델과 운영 조건으로 결과를 검증함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 공개 TOPS나 FLOPS만 보고 선택하면 메모리 병목과 소프트웨어 제약 때문에 기대 성능과 실제 성능이 크게 다를 수 있음
   - 해결방안: 실제 모델 벤치마크를 수행하고 end-to-end latency와 throughput per watt로 검증함
2. 문제: 전용 가속기는 효율이 높아도 모델 변경이나 연산자 제약으로 유지보수 비용이 커질 수 있음
   - 해결방안: roadmap과 portability를 함께 평가하고 model migration effort와 TCO로 전략을 검증함
3. 문제: 학습과 추론을 같은 하드웨어에 몰아넣으면 비용이나 전력 최적점이 무너질 수 있음
   - 해결방안: 학습용과 추론용을 분리 설계하고 utilization과 cost per workload로 구조를 검증함

## Ⅶ. 적용 사례

- 대규모 모델 학습 인프라에서는 GPU 클러스터를 선택하고, training throughput과 cluster utilization로 결과를 확인함
- 스마트폰 온디바이스 AI에서는 NPU를 활용하고, inference latency와 battery impact로 결과를 확인함
- 대량 서비스 추론 백엔드에서는 ASIC 또는 TPU 계열을 검토하고, cost per inference와 throughput per watt로 결과를 확인함

## Ⅷ. 결론

AI 가속기 선택의 핵심은 최고 성능 장비를 고르는 것이 아니라 워크로드와 전력과 운영비와 유연성의 균형점을 찾는 데 있음.
