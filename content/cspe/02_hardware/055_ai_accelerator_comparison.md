# AI 가속기 비교 - CPU·GPU·NPU·FPGA·ASIC (AI Accelerator Comparison)

## 미리 알고가기

- AI 가속기: 신경망의 행렬·텐서 연산을 CPU보다 빠르거나 적은 전력으로 처리하는 하드웨어임
- 산술 강도: 메모리에서 가져온 데이터 1바이트당 수행하는 연산량임
- 지연시간/처리량: 단일 요청 응답 시간과 단위 시간 처리 건수를 구분하는 성능 기준임
- TCO: 장비, 전력, 냉각, 개발, 운영 비용을 합친 총소유비용임
- TOPS: 공개 연산 성능 지표로 자주 쓰이나 실제 지연을 단독 설명하지 못함

## 1. 개요

- **정의/개념**: AI 가속기 비교는 CPU, GPU, NPU, FPGA, ASIC을 워크로드 특성, 지연시간, 처리량, 전력, 유연성, 생태계 기준으로 평가해 AI 서비스의 성능과 비용 요구에 맞는 하드웨어를 선택하는 과정임.
- **배경/필요성**: AI 모델은 크기, 연산자, 배치, 배치 위치가 다양해 하나의 하드웨어가 모든 조건에서 최적일 수 없음. 잘못된 가속기 선택은 비용 과다, 지연 증가, 운영 종속성으로 이어짐.

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| AI 하드웨어 선택 기준 비교 | workload, latency, throughput, power, flexibility, TCO | TOPS 기준 단독 판단, 학습·추론 구분 누락 |

> 요약: AI 가속기 선택은 모델과 운영 요구에 맞춰 성능, 전력, 유연성, 비용을 함께 보는 문제임.

## 2. 특징 및 비교

| 판단 기준 | CPU | GPU | NPU/ASIC | FPGA |
|:---|:---|:---|:---|:---|
| 강점 | 제어 흐름과 범용 실행 | 대량 병렬 연산과 학습 생태계 | 전용 데이터패스 기반 전력당 추론 | 재구성 가능한 저지연 처리 |
| 제약 | 처리량·전력 효율 한계 | 전력·냉각과 메모리 이동 부담 | 지원 연산자와 모델 형식 제약 | 개발 난도와 툴체인 의존 |
| 선택 조건 | 전처리, 소량 추론, 복잡한 로직 | 학습, 대형 배치, 혼합 커널 | 대량 추론, 엣지, 고정 워크로드 | 스트리밍, 프로토콜 결합, 맞춤 가속 |
| 주요 지표 | CPU 사용률, 요청 지연 | GPU utilization, HBM 대역폭 | QPS/W, NPU 실행 비율 | latency, resource utilization |

가속기 비교의 핵심은 “가장 빠른 장치”를 찾는 것이 아니라 워크로드 병목을 가장 잘 줄이는 장치를 찾는 것임. 학습은 GPU/TPU 계열이 유리하고, 온디바이스 추론은 NPU/ASIC, 스트리밍 저지연은 FPGA, 전처리와 제어는 CPU가 여전히 중요함.

## 4. 문제점 및 개선방안

1. **TOPS 착시**: 최대 연산 성능은 실제 모델의 지연, 메모리 병목, fallback 비용을 반영하지 못함.
   - **개선방안**: 실제 모델 기반 end-to-end 벤치마크와 전력 측정을 수행함. (확인: p99 latency, QPS/W)
2. **운영 종속성**: 특정 가속기와 런타임에 묶이면 모델 이식과 장애 대응이 어려움.
   - **개선방안**: 추론 계층 추상화, 표준 모델 포맷, fallback 경로를 설계함. (확인: 이식 테스트 성공률)
3. **하드웨어-모델 불일치**: 모델 연산자가 가속기 구조에 맞지 않으면 CPU fallback과 데이터 이동이 늘어남.
   - **개선방안**: 모델 설계 단계에서 지원 연산자, 양자화, 메모리 구조를 함께 반영함. (확인: 가속 실행 비율)

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| AI 학습 클러스터 | GPU/TPU를 사용하고 HBM, collective 통신, batch size를 최적화함 | step time, GPU/TPU utilization |
| 모바일 추론 | NPU/ASIC에 맞게 INT8 양자화와 모델 경량화를 적용함 | 배터리 소모, p95 latency |
| 산업 스트리밍 AI | FPGA로 센서 전처리와 추론 파이프라인을 결합해 낮은 지연을 확보함 | end-to-end latency, FPS/W |

## 6. 결론

AI 가속기 선택은 공개 성능 수치 비교가 아니라 모델 병목과 운영 요구를 하드웨어 구조에 맞추는 판단임. CPU, GPU, NPU, FPGA, ASIC은 서로 대체 관계만이 아니라 역할 분담 관계이므로 학습·추론·전처리·통신을 분리해 평가해야 함. 기술사는 실제 모델 지연, 전력, 이식성, TCO까지 확인해 선택 근거를 제시해야 함.
