## 미리 알고가기

- CPU·GPU·NPU·FPGA·ASIC은 같은 AI 연산도 목표와 제약이 다름
- 선택 기준은 유연성, 지연, 전력, 배포 규모, 개발 시간임
- 가속기 평가는 이론 성능보다 실제 모델 적합성과 운영비가 중요함

## Ⅰ. 개요

- **정의/개념**: AI 가속기 비교는 신경망 처리 하드웨어를 연산 구조, 전력 효율, 유연성, 운영 목적 기준으로 구분해 적합한 배치 위치를 결정하는 작업임
- **배경/필요성**: AI 시스템은 학습, 대규모 추론, 온디바이스 추론처럼 요구 조건이 다르므로, 하나의 가속기로 모든 문제를 해결하기보다 워크로드별 최적 선택이 필요함

## Ⅱ. 특징

- CPU는 유연성과 제어 능력이 높지만 대규모 텐서 연산의 전력당 처리량은 낮음
- GPU는 범용 병렬성과 생태계가 강해 학습과 서버 추론의 표준임
- NPU와 ASIC은 전력 효율이 높지만 모델 제약과 생태계 의존성이 남음
- FPGA는 재구성 가능성과 저지연이 강점이나 개발 난도가 높음

## Ⅲ. 종류 및 비교

| 판단 기준 | CPU | GPU | NPU | FPGA | ASIC |
|:---|:---|:---|:---|:---|:---|
| 유연성 | 가장 높음 | 높음 | 중간 | 높음 | 낮음 |
| 전력 효율 | 낮음 | 중간 | 높음 | 높음 | 가장 높음 |
| 학습 적합성 | 낮음 | 가장 높음 | 낮음 | 낮음 | 낮음 |
| 저지연 추론 | 낮음 | 중간 | 높음 | 높음 | 가장 높음 |
| 개발 시간 | 짧음 | 짧음 | 중간 | 긺 | 최장 |

> 요약: 학습은 GPU, 온디바이스 추론은 NPU, 초저지연·고정 워크로드는 FPGA·ASIC이 맞음.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 범용 연산 경로 | CPU와 GPU처럼 다양한 연산을 처리할 수 있지만 전력과 면적 오버헤드가 생김 |
| 전용 연산 배열 | NPU와 ASIC은 MAC 배열과 저정밀 연산기로 반복 신경망 작업에 최적화됨 |
| 메모리, 인터커넥트 | HBM, SRAM, PCIe, NVLink 같은 데이터 경로 품질이 실제 성능과 확장성을 결정함 |
| Compiler, Runtime Stack | 하드웨어 선택만으로 끝나지 않고 모델 변환과 fallback 관리 능력이 체감 성능을 좌우함 |

```text
+-------------+     +------------------+     +------------------+     +-------------+
| Workload    | --> | Compute Pattern  | --> | Memory/Interconn.| --> | Runtime Fit |
+-------------+     +------------------+     +------------------+     +-------------+
```

> 요약: 가속기 선택은 연산 경로, 메모리·인터커넥트, runtime 적합성이 함께 결정함.

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 워크로드 분석   | --> | 제약 조건 식별 | --> | 가속기 선택    | --> | 성능/비용 검증 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **워크로드 분석**: 학습인지 추론인지와 모델 구조를 확인함
2. **제약 조건 식별**: 지연, 전력, 비용, 배포 규모를 정리함
3. **가속기 선택**: 적합한 하드웨어 계열을 선택함
4. **성능 및 비용 검증**: 실제 모델과 운영 조건으로 결과를 검증함

> 요약: 워크로드와 제약 조건을 먼저 정한 뒤 실제 모델로 성능·비용을 검증함.

## Ⅵ. 실무 적용 및 유의점

1. 대규모 학습 클러스터는 GPU가 기본 선택이지만 GPU 간 통신이 계산을 지연시키지 않도록 NVLink·InfiniBand를 함께 설계하고 training throughput, cluster utilization으로 확인함
2. 모바일·엣지 추론은 NPU·FPGA·ASIC 중 전력, 지연, 모델 변화 가능성을 함께 봐야 하므로 실제 모델 벤치마크와 이식성 평가를 수행하고 p95 latency, throughput per watt, migration effort로 확인함

## Ⅶ. 결론

AI 가속기 선택은 최고 성능 장비보다 워크로드, 전력, 운영비, 유연성의 균형점을 찾는 작업임.

## 작성 근거(검토용)

- AI 가속기 비교는 유연성, 전력 효율, 학습 적합성, 저지연 추론, 개발 시간을 기준으로 정리함
- 구성요소는 compute pattern, memory/interconnect, runtime fit으로 선택 구조를 설명함
- 실무 판단은 training throughput, p95 latency, throughput per watt, migration effort를 확인 기준으로 둠
