## Ⅰ. 개요
- 시스템을 구현하는 두 가지 상반된 반도체 실장 방식
- 개발 기간, 성능, 비용 요구사항에 따른 전략적 선택 기술

| 구분 | 내용 |
| --- | --- |
| SoC | 여러 기능을 하나의 다이(Die)에 통합하여 제조 |
| SiP | 서로 다른 칩들을 하나의 패키지 내부에 수직/수평 배치 |
| 출제의도 | 두 기술의 구조적 차이 및 장단점 비교 역량 확인 |

## Ⅱ. 구성요소
```
[ SoC Structure ]          [ SiP Structure ]
+----------------+       +-------------------+
|  Single Die    |       |  Package Substrate|
| (CPU+GPU+RAM)  |       | +-----+   +-----+ |
|                |       | | CPU |   | RAM | |
+----------------+       | +-----+   +-----+ |
                         +-------------------+
```
| 항목 | SoC (System on Chip) | SiP (System in Package) |
| --- | --- | --- |
| 통합 수준 | 단일 웨이퍼 상 통합 | 개별 칩을 패키지 내 결합 |
| 제조 비용 | 대량 양산 시 저렴함 | 소량 다품종에 유리함 |
| 개발 기간 | 설계 및 검증에 장시간 소요 | 기성 칩 활용으로 단기간 |
> 요약: SoC는 '한 몸', SiP는 '한 방'에 모아 놓은 것임.

## Ⅲ. 절차
```
[SoC: 설계 중심] vs [SiP: 패키징 중심]
```
1. SoC: 논리 회로 설계 -> 레이아웃 -> 마스크 제작 -> 웨이퍼 공정.
2. SiP: 개별 칩 소싱 -> 기판 설계 -> 다이 부착(Bonding) -> 몰딩.
> 요약: SoC는 제조 단계에서, SiP는 조립 단계에서 시스템 완성함.

## Ⅳ. 문제점
- SoC: 초기 개발비(NRE)가 막대하며 설계 변경 시 리스크 매우 큼.
- SiP: 개별 칩 간 연결 부위에서 신호 간섭 및 발열 집중 우려됨.

## Ⅴ. 개선방안
- SoC: 검증된 IP 사용 및 가상 프로토타이핑을 통한 설계 오류 최소화함.
- SiP: TSV(Through Silicon Via) 등 고도화된 인터커넥트 기술 적용함.

## Ⅵ. 전망
- 고성능 컴퓨팅은 SoC, 다기능·소형 기기는 SiP 채택이 뚜렷해짐.
- 칩렛(Chiplet) 기술의 등장으로 SoC와 SiP의 경계가 허물어지는 추세임.
