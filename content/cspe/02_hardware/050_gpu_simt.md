## 미리 알고가기

- GPU는 많은 경량 코어로 처리량 중심 병렬 연산을 수행하는 프로세서임
- SIMT는 단일 명령을 다수 스레드가 각자 데이터에 적용하는 실행 모델임
- warp, branch divergence, memory coalescing이 핵심 성능 용어임

## Ⅰ. 개요

- **정의/개념**: GPU 아키텍처와 SIMT 모델은 수많은 스레드를 동시에 실행해 지연을 병렬성으로 숨기고, 대규모 데이터 병렬 연산의 처리량을 극대화하도록 설계된 하드웨어 및 실행 구조임
- **배경/필요성**: 그래픽 렌더링과 AI 학습처럼 동일한 연산을 방대한 데이터에 반복 적용하는 작업은 CPU의 소수 고성능 코어보다 GPU의 대량 병렬 구조가 훨씬 효율적임

## Ⅱ. 특징

- 개별 코어 성능보다 전체 처리량을 높이는 설계에 집중함
- warp 스케줄링으로 메모리 지연을 다른 스레드 실행으로 숨김
- 분기 발산과 비연속 메모리 접근이 성능 저하의 대표 원인임
- AI 연산에서는 tensor core와 HBM 대역폭이 성능 상한을 크게 좌우함

## Ⅲ. 종류 및 비교

| 판단 기준 | CPU | SIMD | GPU SIMT |
|:---|:---|:---|:---|
| 설계 목표 | 낮은 지연 | 벡터 연산 가속 | 높은 처리량 |
| 실행 단위 | 스레드 | 벡터 레인 | warp 단위 스레드 묶음 |
| 제어 유연성 | 높음 | 낮음 | 중간 |
| 대표 용도 | 범용 처리 | 짧은 데이터 병렬 | 대규모 병렬 연산 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Streaming Multiprocessor | 워프 스케줄러와 연산 코어와 공유 메모리를 묶은 핵심 실행 단위임 |
| Warp Scheduler | 실행 가능한 워프를 선택해 메모리 대기 시간을 숨기며 처리량을 유지함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 커널 실행 요청 | --> | 워프 단위 배치  | --> | 병렬 명령 실행 | --> | 결과 저장/복귀 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **커널 실행 요청**: 호스트가 GPU에 병렬 커널을 전달함
2. **워프 단위 배치**: 스레드를 블록과 워프로 묶어 SM에 할당함
3. **병렬 명령 실행**: 동일 명령을 다수 스레드가 각자 데이터에 적용함
4. **결과 저장 및 복귀**: 계산 결과를 메모리에 기록하고 호스트로 반환함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 같은 워프의 스레드가 서로 다른 분기 경로로 나뉘면 순차 실행이 발생해 실제 처리량이 크게 떨어질 수 있음
   - 해결방안: 데이터 배치와 커널 구조를 정렬해 분기 발산을 줄이고 warp execution efficiency와 branch divergence rate로 검증함
2. 문제: 인접 스레드가 비연속 메모리를 읽으면 memory coalescing이 깨져 대역폭 효율이 급감할 수 있음
   - 해결방안: 데이터 레이아웃을 연속적으로 재구성하고 global memory throughput과 cache hit rate로 검증함
3. 문제: CPU와 GPU 사이 데이터 이동 비용이 크면 커널 연산보다 전송 시간이 병목이 될 수 있음
   - 해결방안: 데이터 상주 전략과 고속 인터커넥트를 적용하고 host-device transfer time과 end-to-end latency로 검증함

## Ⅶ. 적용 사례

- 딥러닝 학습에서는 대규모 행렬 연산을 병렬 처리하고 확인 지표는 TFLOPS와 training throughput임
- 과학 시뮬레이션에서는 격자 기반 수치 계산을 분산 실행하고 확인 지표는 time to solution과 scalability임
- 영상 렌더링과 추론 서비스에서는 다수 프레임과 요청을 병렬 처리하고 확인 지표는 frame rate와 inference latency임

## Ⅷ. 결론

GPU SIMT의 본질은 많은 코어보다 워프 단위 병렬성과 메모리 지연 은닉을 얼마나 잘 활용하느냐에 있으므로, 데이터 배치와 메모리 접근 최적화가 성능 설계의 핵심임.
