## 미리 알고가기

- GPU는 많은 경량 코어로 처리량 중심 병렬 연산을 수행하는 프로세서임
- SIMT는 단일 명령을 다수 스레드가 각자 데이터에 적용하는 실행 모델임
- warp, branch divergence, memory coalescing이 핵심 성능 용어임

## Ⅰ. 개요

- **정의/개념**: GPU 아키텍처와 SIMT 모델은 수많은 스레드를 동시에 실행해 메모리 지연을 병렬성으로 숨기고 데이터 병렬 연산의 처리량을 극대화하는 하드웨어·실행 구조임
- **배경/필요성**: 그래픽 렌더링과 AI 학습처럼 동일 연산을 방대한 데이터에 반복 적용하는 작업은 CPU보다 대량 병렬 실행 구조가 필요함

## Ⅱ. 특징

- 개별 코어 지연보다 전체 처리량 중심으로 설계됨
- warp 스케줄링으로 메모리 지연을 다른 스레드 실행으로 숨김
- 분기 발산과 비연속 메모리 접근이 성능 저하의 대표 원인임
- AI 연산에서는 tensor core와 HBM 대역폭이 성능 상한을 좌우함

## Ⅲ. 종류 및 비교

| 판단 기준 | CPU | SIMD | GPU SIMT |
|:---|:---|:---|:---|
| 설계 목표 | 낮은 지연 | 벡터 연산 가속 | 높은 처리량 |
| 실행 단위 | 스레드 | 벡터 레인 | warp 단위 스레드 그룹 |
| 제어 유연성 | 높음 | 낮음 | 중간 |
| 대표 용도 | 범용 처리 | 짧은 데이터 병렬 | 대규모 병렬 연산 |

> 요약: GPU SIMT는 제어 유연성보다 warp 단위 처리량과 데이터 병렬성을 우선함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Streaming Multiprocessor | 워프 스케줄러와 연산 코어와 공유 메모리를 묶은 핵심 실행 단위임 |
| Warp Scheduler | 실행 가능한 워프를 선택해 메모리 대기 시간을 숨기며 처리량을 유지함 |
| Register, Shared Memory | 스레드 상태와 블록 내부 공유 데이터를 저장해 전역 메모리 접근을 줄임 |
| Global Memory, Tensor Core | 대역폭과 행렬 연산 특화 능력을 제공해 AI 성능과 병목 구조를 결정함 |

```text
+-------------+     +----------------------+     +-------------------+     +-------------+
| Kernel Grid | --> | Streaming Multiproc. | --> | Warp Scheduler    | --> | Global Memory|
+-------------+     +----------------------+     +-------------------+     +-------------+
                          |
                          v
                    +-------------+
                    | Shared Mem  |
                    +-------------+
```

> 요약: SM은 워프 스케줄러, 레지스터, shared memory로 지연을 숨기고 처리량을 유지함.

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 커널 실행 요청 | --> | 워프 단위 배치  | --> | 병렬 명령 실행 | --> | 결과 저장/복귀 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **커널 실행 요청**: 호스트가 GPU에 병렬 커널을 전달함
2. **워프 단위 배치**: 스레드를 블록과 워프로 그룹화해 SM에 할당함
3. **병렬 명령 실행**: 동일 명령을 다수 스레드가 각자 데이터에 적용함
4. **결과 저장 및 복귀**: 계산 결과를 메모리에 기록하고 호스트로 반환함

> 요약: GPU 커널은 스레드를 워프로 그룹화해 동일 명령을 다수 데이터에 적용함.

## Ⅵ. 실무 적용 및 유의점

1. 딥러닝 학습·과학 계산은 동일 연산을 여러 데이터에 적용하므로 GPU SIMT로 병렬 처리하되, 워프 분기 발산은 처리량을 낮추므로 데이터 배치와 커널 분기를 조정하고 warp execution efficiency, branch divergence rate로 확인함
2. 멀티 GPU 학습·추론은 계산보다 전송이 병목이 되기 쉬우므로 데이터 상주 전략과 NVLink 같은 고속 링크를 적용하고 host-device transfer time, end-to-end latency로 확인함

## Ⅶ. 결론

GPU SIMT는 코어 수보다 워프 병렬성과 메모리 지연 은닉을 살리는 것이 핵심이므로 데이터 배치와 메모리 접근을 함께 최적화해야 함.

## 작성 근거(검토용)

- GPU SIMT는 warp, branch divergence, memory coalescing을 핵심 용어로 반영함
- 비교표는 CPU, SIMD, GPU SIMT의 실행 단위와 제어 유연성 차이를 중심으로 작성함
- 실무 판단은 warp execution efficiency, branch divergence rate, transfer time으로 검증 가능하게 정리함
