## Ⅰ. 개요
- 알고리즘의 논리적 취약점이 아닌, 하드웨어 실행 시 발생하는 물리적 정보를 이용한 공격.
- 전력 소모, 전자기파, 소요 시간, 소리 등을 분석하여 내부 암호 키를 탈취함.
| 구분 | 내용 | 비고 |
|---|---|---|
| 정의 | HW 구동 시의 물리적 누설 정보를 통한 비침습적 공격 | 물리적 취약점 |
| 의도 | 암호 모듈의 물리적 방어 기전 및 공격 기법 이해 측정 | 정보 누설 |

## Ⅱ. 구성요소
[ Target Device ] --(Power/EM/Time)--> [ Sensor/Scope ] --(Analysis)--> [ Secret Key ]
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 누설 정보 | 장치가 연산 중에 방출하는 부가적 물리 현상 | 벽 너머 말소리 |
| 측정 장비 | 오실로스코프, 안테나 등 미세 신호 수집 장치 | 도청기 |
| 분석 기법 | SPA(단순), DPA(차분) 등 통계적 분석 알고리즘 | 해독기 |
> 요약: 물리적 누설 정보, 수집 장비, 통계 분석 기법으로 구성됨.

## Ⅲ. 절차
(1) Setup -> (2) Data Collection -> (3) Signal Processing -> (4) Correlation Analysis
1. Setup: 타겟 장치에 특정 데이터를 입력할 수 있는 환경을 구축함.
2. Data Collection: 수천 번 이상의 연산을 수행하며 전력/전자기파 파형을 저장함.
3. Signal Processing: 노이즈를 제거하고 유의미한 연산 구간을 정렬함.
4. Correlation Analysis: 가설 키와 실제 측정 데이터 간의 상관관계를 통계로 도출함.
> 요약: 환경 구축, 신호 수집, 전처리, 상관관계 분석 순임.

## Ⅳ. 문제점
- 높은 성공률: 알고리즘이 완벽해도 물리적 구현 단계의 결함으로 키 유출 가능.
- 비침습성: 장치를 파괴하지 않고 외부에서 관찰만 하므로 공격 흔적이 남지 않음.

## Ⅴ. 개선방안
- 마스킹(Masking): 난수값을 섞어 연산 과정과 물리적 신호의 상관관계를 끊음.
- 하이딩(Hiding): 더미 연산을 추가하거나 전력 소모를 균일하게 하여 신호 숨김.

## Ⅵ. 전망
- 딥러닝 분석: 통계적 모델링 없이 신경망을 통해 미세 신호에서 키를 추출하는 기법 고도화.
- 하드웨어 가속기 보안: NPU, GPU 등 고성능 칩의 부채널 취약점 방어 설계 필수.
