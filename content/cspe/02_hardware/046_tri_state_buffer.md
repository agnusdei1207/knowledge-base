# 046. 3-상태 버퍼·트라이스테이트 (Tri-State Buffer) [출제: 129회]

## Ⅰ. 개요

- **정의/개념**: 디지털 회로에서 출력 상태를 논리적 '$0$', '$1$' 외에 전기적으로 절연된 상태인 고임피던스($High-Z$) 상태를 추가하여 세 가지 상태를 가질 수 있도록 설계된 버퍼임
- **배경/필요성**: 다수의 장치가 하나의 데이터 버스를 공유하는 환경에서, 선택되지 않은 장치들이 버스 전압에 영향을 주지 않도록 전기적으로 분리하여 신호 충돌(Bus Contention)을 방지하기 위해 필수적임

## Ⅱ. 특징 및 비교

| 판단 기준 | 일반 버퍼 (Standard Buffer) | 3-상태 버퍼 (Tri-State Buffer) |
|:---|:---|:---|
| **출력 상태 수** | $2$개 ($0, 1$) | $3$개 ($0, 1, High-Z$) |
| **제어 핀 여부** | 없음 (입력이 곧 출력) | $Enable$ ($EN$) 핀 존재 |
| **핵심 동작** | 전압 신호의 증폭 및 전달 | 버스 연결/차단 제어 ($Isolation$) |
| **전기적 특성** | 항상 전류 구동 중 | $High-Z$ 시 무한대 저항과 유사 |

> 요약: 일반 버퍼는 신호 전달에 집중하는 반면, 3-상태 버퍼는 공유 버스의 '점유권'을 제어하는 스위치 역할을 수행함

## Ⅲ. 구성요소/구조

- **구성요소**:
  - **Data Input ($A$)**: 버스에 실을 실제 논리 데이터 ($0$ 또는 $1$)임
  - **Enable Input ($E$ 또는 $OE$)**: 출력을 활성화할지 결정하는 제어 신호로, 주로 $Active-High$ 또는 $Active-Low$로 동작함
  - **Data Output ($Y$)**: $Enable$ 시에는 입력 $A$를 출력하고, $Disable$ 시에는 $High-Z$ 상태가 됨
  - **High Impedance ($High-Z$)**: 회로가 전기적으로 끊어진 것과 같은 상태로, 출력 임피던스가 매우 높아 전류가 흐르지 않음

- **진리표 (Active-High 기준)**:
| $Enable$ | $Input$ ($A$) | $Output$ ($Y$) | 상태 |
|:---|:---|:---|:---|
| $0$ | $X$ | $High-Z$ ($Z$) | 비활성 (절연) |
| $1$ | $0$ | $0$ | 활성 (논리 $0$) |
| $1$ | $1$ | $1$ | 활성 (논리 $1$) |

## Ⅳ. 문제점 및 개선방안

1. **[버스 컨텐션 (Bus Contention)]**: 두 개 이상의 장치가 동시에 서로 다른 논리값($0$과 $1$)을 구동할 때 과전류가 발생하여 소자가 파괴됨
   - **개선방안**: $Decoder$를 사용하여 상호 배타적($Mutual\ Exclusive$)으로 $Enable$ 신호를 생성하거나, 제어 로직에 $Dead-time$을 두어 중첩을 방지함 (확인: 전류 피크 발생 여부)
2. **[플로팅 버스 (Floating Bus)]**: 모든 장치가 $High-Z$ 상태일 때 버스 전압이 정의되지 않아 논리적 오작동 유발
   - **개선방안**: 버스에 풀업($Pull-up$) 또는 풀다운($Pull-down$) 저항을 연결하여 기본 전위($Default\ Level$)를 유지함 (확인: 유휴 상태 전압 안정성)
3. **[고속 동작 시 전력 소모]**: 상태 전환 시 발생하는 스위칭 노이즈와 커패시턴스 충방전으로 인한 전력 손실 발생
   - **개선방안**: 저전력 $CMOS$ 소자를 채용하고 버스 세분화($Segmentation$)를 통해 부하 용량을 줄임 (확인: 동적 전력 소모량)

## Ⅴ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| **메모리 인터페이스** | 여러 개의 $RAM$ 칩이 데이터 버스를 공유할 때, $Chip\ Select$ ($CS$) 신호로 특정 칩만 버스를 구동하도록 제어 | 데이터 무결성 |
| **GPIO 핀 제어** | 마이크로컨트롤러의 $I/O$ 핀을 입력 모드(High-Z)와 출력 모드로 전환하며 양방향 통신 구현 | 포트 충돌 여부 |
| **양방향 버스 (Bidirectional)** | 송신 시에는 버퍼 활성화, 수신 시에는 $High-Z$로 설정하여 하나의 선으로 송수신 수행 | $Read/Write$ 타이밍 마진 |

## Ⅵ. 결론

3-상태 버퍼는 현대 컴퓨터 아키텍처에서 '공유'라는 개념을 전기적으로 구현한 기초 부품임. $High-Z$라는 제3의 상태를 통해 물리적인 배선 중첩 없이도 수많은 장치가 질서 있게 데이터를 주고받을 수 있는 환경을 제공함. 최근에는 고속 통신을 위해 점대점($Point-to-Point$) 방식이 선호되기도 하지만, $SoC$ 내부의 제어 신호나 양방향 인터페이스 영역에서는 여전히 필수적인 설계 요소로 자리 잡고 있음.
