# 📖 【암기용】 개념 완전 이해

> 목적: Ad-hoc 네트워크와 AODV 라우팅을 처음 봐도 완벽히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 인프라(기지국·AP) 없이 노드끼리 릴레이로 데이터를 주고받는 자율 무선망
- **왜 필요한가**: 재난, 전장, 사각지대 등 기지국이 파괴되거나 없는 환경에서 즉각적인 통신이 필요하다.
- **핵심 직관**: 길을 찾을 때 지도를 들고 다니는 게 아니라, 필요할 때마다 옆 사람에게 물어물어 목적지까지 경로를 개척하는 방식.

## 깊이 이해
- **배경·문제의식**: 기존 Wi-Fi나 셀룰러망은 AP가 고장나면 통신이 단절된다. 이를 극복하기 위해 각 단말이 무선 라우터 역할을 겸하는 다중 홉망이 필요해졌다.
- **작동 원리**: AODV는 필요할 때만 경로를 찾는다(Reactive). 송신자가 RREQ를 방송하면, 목적지가 RREP로 응답해 경로를 수립한다. 노드가 이동해 끊기면 RERR로 알리고 다시 찾는다.
- **비유**: 릴레이 달리기. 다음 주자가 안 보이면 소리쳐(RREQ) 위치를 찾고, 응답(RREP)이 온 방향으로 바통을 넘긴다.
- **구체 예시**: 화재 진압 시 소방관들의 무전기. 대원 A와 지휘소 D가 멀어도 중간 대원 B, C를 거쳐 통신망을 유지한다.
- **흔한 오해·주의점**: AODV는 가장 빠른 길이 아니라 처음 응답이 온 경로를 택할 확률이 높다. 라우팅 테이블 유지 비용은 없지만, 최초 연결 지연(Delay)이 발생한다.

## 연결 개념
- MANET (Mobile Ad-hoc Network) — 이동성을 갖춘 노드들의 Ad-hoc 망
- DSDV — AODV와 반대로 주기적으로 경로를 유지하는 Proactive 라우팅
- WSN — Ad-hoc 기반 저전력 센서망

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.
> 핵심: 기지국 없는 망에서의 경로 탐색 오버헤드와 이동성 대응 메커니즘을 AODV 중심으로 전개한다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: Ad-hoc AODV는 이동 노드가 인프라 없이 다중 홉 경로를 요구 시점(On-Demand)에 탐색하는 라우팅 프로토콜이다.
> 2. **가치**: RREQ/RREP/RERR 메시지를 통해 토폴로지가 수시로 변하는 재난·전술망에서 동적 통신을 보장한다.
> 3. **판단 포인트**: 통신 빈도, 노드 이동 속도, 배터리 제약을 기준으로 Proactive 방식과 Reactive 방식을 저울질해야 한다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 인프라리스 다중 홉 구조 이해 | 자율 구성, 라우터 겸용 단말, 동적 토폴로지 | 유선망의 OSPF/BGP와 혼동 |
| AODV 경로 탐색 원리 파악 | RREQ(탐색) / RREP(응답) / RERR(단절) | 제어 메시지 명칭 오기 |
| 라우팅 설계 트레이드오프 | 경로 유지 오버헤드 vs 초기 탐색 지연 | 수치 없는 장황한 장단점 나열 |

> 요약: 망 붕괴 시 단말 릴레이 동작을 라우팅 관점으로 서술하고, 제어 트래픽과 이동성 간의 트레이드오프를 제시한다.

---

## Ⅰ. 개요 및 필요성

- 정의: 중앙 인프라 없이 노드들의 릴레이로 데이터를 전달하는 자율 구성 무선망과 요구 기반 탐색 라우팅
- 배경: 재난·전장 등 인프라 파괴 상황에서 노드 이동성에 즉각 대응하는 생존성 높은 네트워크 요구
- 필요성: 토폴로지가 수시로 변하는 환경에서 주기적 라우팅 업데이트로 인한 배터리·대역폭 고갈 방지

---

## Ⅱ. 구조 및 구성요소

```text
Source Node -> Intermediate Node -> Destination Node
            | (RREQ 방송)        | (RREP 회신)
            +-> 경로 단절 감지 -> RERR 전파 -> 재탐색
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Mobile Node | 송수신 단말이자 라우터(릴레이) 기능 수행 | 배터리, 무선 링크 품질 제약 |
| RREQ | 경로 탐색 요청 브로드캐스트 | Broadcast ID, 목적지 Sequence No 포함 |
| RREP | 경로 응답 유니캐스트 | 최신 경로 보장 (Sequence No 확인) |
| RERR | 링크 단절 알림 및 경로 무효화 | 상위 노드로 전파 후 재탐색 트리거 |

> 요약: 각 노드는 라우터 역할을 겸하며, 통신 요구 시 RREQ/RREP를 교환해 동적으로 경로를 구성한다.

---

## Ⅲ. 동작원리 및 흐름도

```text
통신 요구 -> 경로 확인 -> (경로 없음) -> RREQ 플러딩
-> RREP 수신 -> 테이블 갱신 -> 데이터 전송
-> 이동에 의한 단절 감지 -> RERR 발송 -> 경로 재탐색
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 경로 탐색 | Source가 RREQ 브로드캐스트, 중복 RREQ 폐기 |
| 2 | 경로 응답 | 목적지 또는 유효 경로 보유 노드가 RREP 유니캐스트 반환 |
| 3 | 데이터 전송 | 수립된 경로를 통해 Unicast로 패킷 전달 |
| 4 | 단절 복구 | 링크 단절 감지 시 RERR 전파, 필요 시 Local Repair 수행 |

> 요약: 평소에는 대기하다 통신 요구 시에만 경로를 탐색하며, 이동에 의한 단절 시 RERR로 복구를 시작한다.

---

## Ⅳ. 특징 (라우팅 방식 비교)

| 구분 | AODV (Reactive) | DSDV (Proactive) | 판단 포인트 |
|:---|:---|:---|:---|
| 경로 설정 시점 | 요구 발생 시 (On-Demand) | 주기적 테이블 갱신 | 통신 빈도, 초기 지연 |
| 제어 오버헤드 | 적음 (탐색 시에만 Flooding) | 많음 (지속적 Broadcast) | 대역폭, 노드 배터리 |
| 토폴로지 적응성 | 잦은 이동(고동적 환경)에 유리 | 정적(저동적 환경)에 유리 | 노드 이동 속도 |

> 요약: 노드 이동이 잦고 전력이 제한된 MANET 환경에서는 오버헤드가 적은 AODV가 Proactive 방식보다 유리하다.

## Ⅴ. 심화 비교 및 적용 판단

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| Broadcast Storm | RREQ 플러딩 폭주 | Expanding Ring Search (TTL 점진 증가) | 제어 트래픽 비율 10% 이하 |
| 경로 단절/지연 | 노드 이동에 따른 링크 붕괴 | Local Repair, RERR 신속 전파 | Route Repair Time 1초 이내 |
| Blackhole Attack | 악성 노드의 RREP 위조 및 패킷 폐기 | 암호화 서명 기반 Secure AODV 적용 | 패킷 전송 성공률 90% 이상 |

> 요약: RREQ 플러딩으로 인한 대역폭 고갈과 악의적 노드 공격을 방어하기 위해 TTL 제어와 인증이 필수적이다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 전달률 (PDR) | Packet Delivery Ratio 90% 이상 | 네트워크 시뮬레이터 (ns-3) 검증 |
| 오버헤드 | Data 패킷 대비 제어 패킷 비율 20% 이하 | RREQ/RREP/RERR 카운터 로깅 |
| 단-대-단 지연 | E2E Latency 150ms 이내 유지 | Ping 테스트 및 E2E 트레이싱 |

> 요약: 적용 효과는 전송 성공률, 제어 메시지 오버헤드, 초기 지연시간의 균형을 기준으로 측정한다.

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 재난 통신망: 기지국 붕괴 지역에서 소방대원 단말 50대에 AODV 기반 MANET을 구성해 RTO 1분 이내 통신 재개
2. 드론 전술망 (FANET): 고속 이동하는 드론 편대에 Reactive 라우팅을 적용하여 토폴로지 변경 시 제어 오버헤드 최소화
3. 센서 네트워크 (WSN): 저전력 노드의 배터리 소모를 줄이기 위해 통신 이벤트 발생 시에만 RREQ를 쏘도록 스케줄링

**결론 (2줄):**
- 기술사 판단: 인프라리스 망 설계 시 단말의 이동 속도와 배터리를 최우선 고려하여, 동적 환경이면 AODV를 선택한다.
- 향후 방향: 트래픽 병목과 보안 취약점을 극복하기 위해 머신러닝 기반 신뢰도 점수 부여 라우팅(Trust-aware Routing)으로 발전해야 한다.
