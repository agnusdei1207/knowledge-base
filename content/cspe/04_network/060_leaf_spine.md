## Ⅰ. 개요
- **정의**: 모든 말단(Leaf) 스위치가 모든 척추(Spine) 스위치와 완전한 메시(Full-mesh) 형태로 직접 연결된 2계층 데이터센터 네트워크 아키텍처임.
- **배경/필요성**: 서버 간 통신(East-West 트래픽) 급증에 따라, 상위 계층으로 갈수록 병목이 발생하고 지연 시간이 홉(Hop)마다 달라지는 기존 3계층(Core-Aggregation-Access) 구조의 한계 극복.
- **출제 의도**: Leaf-Spine의 2-Tier 구조적 특성, 기존 STP(스패닝 트리)의 대역폭 낭비 문제 극복 원리, ECMP를 통한 트래픽 분산과 오버레이 네트워크 연동 이해.

## Ⅱ. 구성요소
```text
+-----------+   +-----------+   +-----------+
|  Spine 1  |   |  Spine 2  |   |  Spine 3  |
+-----+-----+   +-----+-----+   +-----+-----+
      |               |               |
      +-------+       |       +-------+
              |       |       |
+-----+-----+ | +-----+-----+ | +-----+-----+
|  Leaf 1   |-+ |  Leaf 2   |-+ |  Leaf 3   |
+-----+-----+   +-----+-----+   +-----+-----+
      |               |               |
   [Server]        [Server]        [Server]
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| Spine Switch | 네트워크의 최상단 척추 역할로, 데이터의 고속 릴레이 및 Leaf 간의 경로를 제공 (서버와 직접 연결 안됨) | 고속도로 톨게이트 집선망 |
| Leaf Switch | 말단 나뭇잎 역할로, 서버나 스토리지와 직접 연결되며 모든 Spine과 업링크로 연결되는 진입로 장비 | 동네 도로망 |
| ECMP 라우팅| (Equal-Cost Multi-Path) 패킷이 여러 Spine을 통해 다중 경로로 분산 전송되어 대역폭을 100% 활용하는 기술 | 다차선 병렬 도로 활성화 |
> 요약: 모든 동네(Leaf)가 톨게이트(Spine)들과 직통으로 연결되어, 어디를 가든 똑같은 거리(Hop)로 도착함.

## Ⅲ. 절차
```text
+-----------+   +-------------+   +-------------+   +-----------+
| 패킷 인입 |-> | 경로 해싱   |-> | 다중 경로분산|-> | 목적지 도달|
+-----------+   +-------------+   +-------------+   +-----------+
```
1. **패킷 인입**: 출발지 서버 A가 목적지 서버 B로 데이터를 전송하면 패킷이 첫 번째 진입점인 Leaf 1에 도착함.
2. **경로 해싱**: Leaf 1은 목적지 Leaf 3으로 가기 위해 가용한 여러 Spine 경로 중 하나를 패킷 헤더의 해시값을 기반으로 선택함(ECMP).
3. **다중 경로 분산**: 트래픽이 차단(Blocking) 포트 없이 활성화된 여러 Spine 스위치(Spine 1, 2, 3)를 통해 고르게 로드밸런싱되어 전송됨.
4. **목적지 도달**: 선택된 Spine을 거친 패킷이 목적지 Leaf 3으로 바로 하강하여 서버 B로 전달됨 (항상 딱 2 홉으로 도달).
> 요약: 스패닝 트리를 버리고 L3 다중 경로 라우팅을 사용하여, 모든 트래픽이 지연 없이 균일하게 데이터센터를 횡단함.

## Ⅳ. 문제점
- **막대한 포트 소모 및 케이블링**: 완전 메시(Full-mesh) 연결로 인해 랙(Rack) 간 케이블 배선이 극도로 복잡해지고 광 트랜시버 구매 비용 급증.
- **Spine 장애 파급력 (Blast Radius)**: 라우팅 오설정 등으로 특정 Spine이 오작동하면 전체 네트워크 대역폭이 순식간에 부분 축소되며 연쇄 트래픽 혼잡 유발.
- **L2 확장성의 제약**: 기반이 L3 라우팅(BGP/OSPF)이므로 서버 마이그레이션을 위한 동일 L2 서브넷(VLAN)의 데이터센터 전역 확장이 원천 차단됨.

## Ⅴ. 개선방안
- **자동화 관리 도입**: 0일 차 프로비저닝(ZTP) 및 Ansible 등 설정 자동화 툴을 통해 수많은 Leaf 스위치의 복잡한 라우팅 설정을 템플릿화 (단기).
- **오버레이 기술 융합**: L3 패브릭 위에 VXLAN/EVPN을 오버레이로 구축하여, 물리적인 라우팅 장점을 취하면서도 테넌트별 L2 네트워크 연장 지원 (중기).
- **하이퍼스케일 고도화**: 대규모 확장을 위해 Spine을 여러 계층(Super Spine)으로 묶는 Pod 아키텍처로 진화 및 400G/800G 광학 기술 도입 (장기).

## Ⅵ. 전망
- 모놀리식 애플리케이션에서 마이크로서비스(MSA)와 분산 스토리지 중심으로 IT 환경이 변하면서 발생하는 East-West 트래픽 처리를 위한 업계 표준 설계로 완전히 정착함.
- 향후 AI 클러스터(GPU 연산망)의 병렬 처리를 극대화하기 위해 초저지연 RoCEv2(RDMA over Converged Ethernet) 트래픽을 완벽히 수용하는 손실 없는(Lossless) 데이터센터 패브릭으로 진화 중임.
