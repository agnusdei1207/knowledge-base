## 미리 알고가기

- LPWAN은 적은 전력으로 넓은 범위를 커버하는 IoT 통신 방식임
- NB-IoT는 아주 작은 데이터와 긴 배터리 수명에 초점을 둔 셀룰러 IoT 방식임
- LTE-M은 이동성과 상대적으로 큰 데이터 처리를 고려한 셀룰러 IoT 방식임
- PSM은 단말이 오랫동안 깊게 잠들어 배터리를 아끼게 하는 절전 모드임
- eDRX는 단말이 네트워크를 확인하는 간격을 길게 늘려 전력 소모를 줄이는 방식임

## Ⅰ. 개요

- **정의/개념**: NB-IoT와 LTE-M은 기존 LTE 인프라를 활용해 IoT 단말을 저전력으로 연결하는 셀룰러 LPWAN 방식이며, NB-IoT는 정적인 초소량 데이터에, LTE-M은 이동성과 범용성에 더 무게를 둠
- **배경/필요성**: 스마트 계량기와 위치 추적기처럼 전국망이 필요하지만 일반 LTE 모듈은 전력과 비용 부담이 커서, 이동통신망을 IoT 특성에 맞게 가볍게 쓸 수 있는 별도 방식이 필요했음

## Ⅱ. 특징

- 면허 대역과 통신사 인프라를 쓰므로 광역 커버리지와 관리 체계를 활용하기 쉬움
- PSM과 eDRX 같은 절전 기능으로 배터리 수명을 늘릴 수 있음
- NB-IoT는 고정형 저전송량 단말과 커버리지 확장에, LTE-M은 이동 단말과 음성·중간 처리량 서비스에 사용함
- 자가망보다 품질 통제가 쉬운 대신 사업자 망 정책과 비용 구조의 영향을 받음

## Ⅲ. 종류 및 비교

| 판단 기준 | NB-IoT | LTE-M |
|:---|:---|:---|
| 주된 목적 | 고정형 센서와 계량기의 초소량 데이터를 오래 보내는 데 적합함 | 이동형 단말과 추적기처럼 더 넓은 활용 범위를 지원함 |
| 처리량과 응답성 | 작은·비주기 데이터와 긴 절전 주기를 전제로 함 | NB-IoT보다 높은 처리량과 짧은 응답 주기를 지원함 |
| 이동성 지원 | 이동성 요구가 낮은 환경에 적합함 | 이동 중 연결 유지와 추적 서비스에 더 적합함 |
| 대표 활용 | 수도·가스 검침, 고정형 환경 센서에 적합함 | 물류 추적, 자산 추적, 이동형 안전 장치에 적합함 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| IoT 단말 모듈 | 센서나 추적기에 탑재되어 작은 데이터를 전송하며 절전 모드를 반복 사용함 |
| LTE 기지국 | 기존 이동통신 셀을 활용해 IoT 단말의 접속과 무선 자원을 처리함 |
| 코어망 | 가입자 인증과 세션 관리와 데이터 전달을 담당함 |
| 절전 기능 | PSM과 eDRX를 통해 단말이 오래 잠들거나 느리게 깨어나게 조정함 |
| 운영 플랫폼 | 단말 상태와 펌웨어와 데이터 흐름을 관리하는 서비스 계층임 |

```text
+-----------+     +-----------+     +-----------+     +----------------+
| IoT 단말    | --> | LTE 기지국  | --> | 코어망      | --> | 운영 플랫폼      |
+-----------+     +-----------+     +-----------+     +----------------+
   절전·송신          무선 접속 처리         인증·전달             상태·업무 연동
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+     +-------------+
| 단말 등록 수행 | --> | 절전 모드 진입 | --> | 이벤트 시 송신 | --> | 필요 시 수신 대기 | --> | 다시 절전 전환 |
+-------------+     +-------------+     +-------------+     +-------------+     +-------------+
```

1. **단말 등록 수행**: 단말이 사업자 망에 접속해 인증과 기본 세션 구성을 마침
2. **절전 모드 진입**: PSM이나 eDRX 설정에 따라 장시간 대기 상태로 들어감
3. **이벤트 시 송신**: 주기 보고나 알람 발생 시 필요한 데이터만 짧게 송신함
4. **필요 시 수신 대기**: 설정된 주기에 따라 명령이나 응답을 받을 시간을 잠시 확보함
5. **다시 절전 전환**: 통신을 마치면 다시 저전력 상태로 돌아가 배터리를 절약함

## Ⅵ. 실무 적용 및 유의점

1. 원격 검침처럼 거의 움직이지 않고 작은 데이터만 보내는 단말은 NB-IoT가 맞고 차량 추적이나 이동형 안전 장치는 LTE-M이 맞으므로 이동성 요구, 보고 주기, 배터리 교체 주기를 함께 보고 선택한 뒤 접속 성공률, 배터리 수명, 지하 커버리지로 적합성을 확인함
2. 셀룰러 IoT는 통신사 망 정책과 요금 구조의 영향을 받으므로 대규모 배치 전에는 실제 설치 구역의 커버리지와 절전 설정을 검증해야 하며 전송 지연, 재시도 횟수, 월간 회선 비용으로 운영성을 확인함

## Ⅶ. 결론

NB-IoT와 LTE-M의 선택 기준은 둘 다 셀룰러 IoT라는 점보다 단말이 얼마나 자주 움직이고 얼마나 자주 데이터를 주고받는지에 있음.
