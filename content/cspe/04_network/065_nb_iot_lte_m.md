# 📖 【암기용】 개념 완전 이해

> 목적: NB-IoT와 LTE-M을 처음 봐도 완벽히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 이동통신 면허 대역을 사용하는 셀룰러 LPWAN 기술
- **왜 필요한가**: 전국 커버리지, 통신사망 운영, SIM/eSIM 인증이 필요한 IoT 단말에는 비면허 LPWAN만으로 부족함
- **핵심 직관**: NB-IoT는 깊은 실내의 작은 센서 엽서, LTE-M은 이동하면서도 음성·펌웨어 갱신까지 가능한 소형 택배에 가까움

## 깊이 이해
- **배경·문제의식**: 검침·자산추적·웨어러블 IoT는 배터리와 커버리지가 핵심이나, 기존 LTE 모뎀은 전력과 비용 부담이 큼. 3GPP는 LTE 기반 LPWAN으로 NB-IoT와 LTE-M을 정의함.
- **작동 원리**: NB-IoT는 좁은 대역폭과 반복 전송으로 실내 침투를 확보하고, LTE-M은 LTE 이동성·핸드오버·VoLTE 일부 기능을 지원함. 두 기술 모두 PSM, eDRX로 절전 상태를 운영함.
- **비유**: NB-IoT는 지하 계량기실에서 하루 몇 번 숫자만 보내는 우편함이고, LTE-M은 이동 차량에서 위치와 상태를 주기적으로 보내는 통신기임.
- **구체 예시**: 수도 계량기는 NB-IoT로 하루 4회 사용량을 전송하고, 물류 트래커는 LTE-M으로 1분 단위 위치와 충격 이벤트를 전송함.
- **흔한 오해·주의점**: NB-IoT와 LTE-M은 전세계 동일 커버리지가 아님. 서비스 가능 여부, 주파수, 로밍, 요금, eSIM 정책은 국가·통신사별 조건 확인이 필요함.

## 연결 개념
- LPWAN — 저전력 광역 IoT 통신 범주
- PSM/eDRX — 셀룰러 IoT 단말 절전 기능
- LoRaWAN — 비면허 대역 LPWAN 대안

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.
> 핵심: NB-IoT와 LTE-M을 모두 셀룰러 LPWAN으로 묶되, 대역폭·이동성·전송량·전력 모드 차이를 명확히 비교한다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: NB-IoT와 LTE-M은 3GPP LTE 계열 면허 대역 기반의 저전력 광역 IoT 통신 기술이다.
> 2. **가치**: 통신사망 커버리지, SIM/eSIM 인증, PSM/eDRX 절전으로 검침·추적·웨어러블 IoT를 지원한다.
> 3. **판단 포인트**: NB-IoT는 고정·소량·깊은 실내, LTE-M은 이동성·중간 전송량·핸드오버 조건에서 우선 검토한다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |

| NB-IoT/LTE-M 차이 확인 | 대역폭, 이동성, 핸드오버, 전송량 | 둘을 이름만 나열하고 선택 기준 누락 금지 |
| 적용 조건 판단 확인 | 통신사 커버리지, 로밍, 요금, 배터리 | 국가·사업자 조건을 일반화 금지 |

> 요약: 이 문제는 두 셀룰러 LPWAN의 구조적 차이와 적용 시나리오를 비교해야 한다.

## Ⅰ. 개요 및 필요성

NB-IoT·LTE-M은 이동통신망 기반 셀룰러 LPWAN 기술이다. IoT 서비스는 전국 커버리지, 인증, 과금, 로밍, 배터리 수명을 동시에 요구한다. 3GPP 기반 면허망을 활용하면 사설 Gateway 없이 통신사망으로 단말을 관리할 수 있음.

---

## Ⅱ. 구조 및 구성요소

```text
IoT Device -> NB-IoT/LTE-M Radio -> eNodeB/eNB
-> EPC/IoT Core -> IoT Platform -> Application
Device Power Mode -> PSM/eDRX -> Wakeup -> Data Transfer
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| IoT 단말 | 센서·계량·추적 데이터 송수신 | SIM/eSIM, 저전력 모뎀 |
| RAN | NB-IoT 또는 LTE-M 무선 접속 | 면허 대역, 통신사 커버리지 |
| Core Network | 인증·세션·과금 처리 | EPC, IoT APN, QoS |
| PSM/eDRX | 절전 상태 제어 | TAU 주기, Paging 주기 |
| IoT Platform | 디바이스·데이터 관리 | MQTT/HTTP, 펌웨어 관리 |

> 요약: 셀룰러 LPWAN은 단말, RAN, Core, 절전 모드, 플랫폼이 결합된 통신사망 기반 IoT 구조이다.

---

## Ⅲ. 동작원리 및 흐름도

```text
전원 인가 -> SIM/eSIM 인증 -> 네트워크 Attach
-> PSM/eDRX 설정 -> 주기 Wakeup
-> 센서 데이터 전송 -> 플랫폼 저장
-> 명령/펌웨어 수신 -> 절전 복귀
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 단말이 셀 탐색 후 Attach 수행 | IMSI/eSIM, APN |
| 2 | 절전 파라미터 협상 | PSM Timer, eDRX Cycle |
| 3 | 센서 데이터 업링크 전송 | RSRP, RSRQ, SINR |
| 4 | 플랫폼이 메시지 수집·저장 | MQTT Ack, HTTP Status |
| 5 | 단말이 절전 상태로 복귀 | 평균 전류, 배터리 추정 |

> 요약: NB-IoT/LTE-M은 인증-접속-절전-전송-절전 복귀 흐름으로 배터리 기반 광역 IoT를 운영한다.

---

## Ⅳ. 특징

| 구분 | NB-IoT | LTE-M | 수치·표준 포인트 |
|:---|:---|:---|:---|
| 대역폭 | 약 180kHz | 약 1.4MHz | 3GPP LTE Cat-NB, Cat-M |
| 이동성 | 고정·저속 중심 | 이동성·핸드오버 지원 | 자산추적, 웨어러블 |
| 데이터 | 소량·저빈도 | 중간 전송량·FOTA 가능 | 메시지 크기·주기 판단 |
| 전력 | PSM/eDRX로 장기 절전 | PSM/eDRX와 이동성 균형 | 배터리 모델 산정 필요 |

> 요약: NB-IoT는 실내 고정 센서, LTE-M은 이동 단말과 펌웨어 갱신 요구에 맞춰 선택한다.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존/대안 | NB-IoT·LTE-M | 선택 기준 |
|:---|:---|:---|:---|
| 네트워크 | LoRaWAN 사설망 | 통신사 셀룰러망 | 전국 커버리지, SLA, 요금 |
| 단말 특성 | Wi-Fi/BLE | 저전력 광역 단말 | 배터리 2~5년, 이동성 |
| 운영 | 자체 Gateway 관리 | SIM/eSIM 기반 대량 관리 | 개통, 과금, 로밍, 인증 |

> 요약: 통신사망 운영과 광역 커버리지가 필요하면 셀룰러 LPWAN을 선택하고, 자체망·저빈도는 LoRaWAN을 검토한다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 배터리 소모 | Attach 빈도, 약전계 재전송 | PSM/eDRX 튜닝, 전송 주기 조정 | 평균 전류, 재전송률 |
| 커버리지 음영 | 지하·금속함·농촌 음영 | 사전 RSRP 측정, 외장 안테나 | RSRP -110dBm 기준 검토 |
| 사업자 종속 | 요금·로밍·망 종료 정책 | 멀티 IMSI/eSIM, 계약 조건 검토 | 회선 장애율, 로밍 성공률 |

> 요약: 셀룰러 LPWAN 리스크는 전력, 커버리지, 사업자 조건이며 현장 전파 측정과 계약 검토가 필수이다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 전파 품질 | RSRP, RSRQ, SINR 기준 충족 | 현장 드라이브·고정 측정 |
| 배터리 | 서비스 목표 2~5년 | 전류 프로파일, 주기별 전송 모델 |
| 메시지 성공 | 전송 성공률 99% 이상 | 플랫폼 Ack, 재시도 로그 |

> 요약: 도입 검증은 실측 전파 품질, 배터리 모델, 메시지 성공률로 수행해야 한다.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 — 단계별 또는 항목별):**
1. 고정 검침 단말은 NB-IoT를 우선 검토하고, 설치 위치별 RSRP/RSRQ와 금속함 감쇠를 사전 측정함
2. 이동 자산추적 단말은 LTE-M, eSIM, MQTT QoS 1, FOTA 요구사항을 포함해 단말 사양을 확정함
3. PSM/eDRX Timer, 전송 주기, 재시도 횟수를 배터리 목표 2~5년에 맞춰 현장 전류 측정으로 검증함

**결론 (2줄):**
- 기술사 판단: 고정·소량·실내 침투 조건은 NB-IoT, 이동·펌웨어 갱신·중간 전송량 조건은 LTE-M을 선택함
- 향후 방향: 셀룰러 IoT는 eSIM, 5G RedCap, 위성 IoT와 연계되어 광역 단말 관리 체계로 확장됨
