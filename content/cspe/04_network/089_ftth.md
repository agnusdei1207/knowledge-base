## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 통신국사(CO)에서 가입자 가정 내부(Home)까지 기존 구리선 대신 100% 광케이블(Optical Fiber)을 포설하여 초고속 광대역 인터넷을 제공하는 접속망 아키텍처 |
| **배경/필요성** | 4K/8K 고화질 미디어, VR, 클라우드 게임 등 대용량 실시간 트래픽 증가에 따른 기존 ADSL/VDSL 인프라 대역폭 한계 극복 필요 |
| **출제 의도** | AON(능동형)과 PON(수동형) 광 분배망 아키텍처의 차이점 및 OLT/ONU/ONT 장비 계층별 매커니즘 평가 |

## Ⅱ. 구성요소
```text
+----------+       +----------+       +----------+
| Telco CO |       | Splitter |       | Home     |
| (OLT)    | =====>| (Passive)| ----> | (ONT/ONU)|
+----------+       +----------+       +----------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| OLT (국측 장비) | 통신 국사에 위치하여 광 신호를 생성/제어하고 백본망(인터넷)과 연결하는 핵심 라우팅 장비 | 중앙 광역 펌프장 |
| Splitter (분배) | 전원 공급 없이 하나의 광 신호를 물리적 프리즘 원리로 1:N(최대 64/128)으로 쪼개는 수동 소자(PON 핵심) | 물길 나누는 수로 |
| ONT/ONU (가입자) | 가정/건물 내 위치하여 광 신호를 이더넷(UTP) 전기 신호로 최종 변환하는 모뎀(단말기) | 가정용 수도꼭지(모뎀) |

> 요약: 전력 장치 없는 수동 분배기(PON)를 활용하여 국사 밖 인프라 구축 및 유지보수 비용을 획기적으로 절감함

## Ⅲ. 절차
```text
+----------+    +----------+    +----------+    +----------+
| 광전송   | -> | 수동 분기| -> | 광전 변환| -> | 데이터통신|
+----------+    +----------+    +----------+    +----------+
```
1. 광전송: OLT 장비가 하나의 굵은 광케이블(Feeder)을 통해 고출력 레이저 빛(하향 데이터)을 송출
2. 수동 분기: 전봇대나 아파트 단자함에 위치한 무전원 광 스플리터가 광 신호를 다수의 가입자 회선(Drop)으로 광학적 1:N 복제 분배
3. 광전 변환: 가정 내 설치된 ONT(광 모뎀) 장비가 수신된 빛 신호를 인식하고 일반 이더넷 LAN(RJ-45) 전기 신호로 즉각 변환
4. 데이터통신: 하향은 브로드캐스트 암호화 수신, 상향(사용자->국사) 통신은 TDMA 시분할 방식을 적용해 다른 집과의 광 충돌 방지

> 요약: PON 구조 기반으로 송신(광) -> 분배(무전원 스플리터) -> 변환(모뎀)의 3단계를 거쳐 초고속망 구현 완료함

## Ⅳ. 문제점
- [대역폭 공유] PON 구조 특성상 하나의 광 회선을 64세대가 공유하므로 동시 다발적 헤비 다운로더 발생 시 급격한 속도 저하 체감
- [보안 취약] 하향 데이터가 분배기를 통해 모든 이웃집 ONT에 동일하게 물리적 복사 전달되어 악의적 ONT 변조 시 통신 도청 위험
- [장애 파급] 통신국사 주변 메인 광케이블(Feeder Fiber) 단선(굴착 공사 등) 시 연결된 수천 가구 전체 동시 서비스 완전 차단 (단일장애)

## Ⅴ. 개선방안
- [단기] 각 가정 ONT 장비에 부여된 AES 기반 고유 암호화 키를 통한 복호화 프로세스 엄격 적용으로 이웃집 도청 원천 차단
- [중기] WDM-PON(파장 분할 다중화) 기술 융합 도입으로 가입자마다 고유한 고속 전용 빛 파장(색깔) 할당하여 공유 대역폭 문제 극복
- [장기] OLT 이중화 및 메인 광케이블 링(Ring) 토폴로지 구조 설계 적용을 통해 굴착 단선에 대비한 논스톱(Non-Stop) 광 인프라 재설계

## Ⅵ. 전망
- 10기가 인터넷(10G-PON)을 넘어 양자 암호 통신(QKD)이 결합된 해킹 원천 차단 무결점 광가입자망으로 진화할 전망임
