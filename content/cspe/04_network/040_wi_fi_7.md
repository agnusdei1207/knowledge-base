## 미리 알고가기

- EHT는 Wi-Fi 7이 목표로 하는 초고처리량 계층을 뜻함
- MLO는 여러 주파수 링크를 동시에 사용하거나 상황에 따라 나누어 쓰는 기능임
- 320MHz 채널은 기존보다 더 넓은 주파수 폭을 써 한 번에 더 많은 데이터를 보내는 방식임
- 4096-QAM은 같은 심볼에 더 많은 비트를 실어 스펙트럼 효율을 높이는 변조 방식임
- Puncturing은 넓은 채널 일부에 간섭이 있어도 나머지 구간을 활용하게 하는 기술임

## Ⅰ. 개요

- **정의/개념**: Wi-Fi 7은 IEEE 802.11be 기반의 최신 무선 LAN 표준으로, 여러 주파수 링크를 함께 활용하고 더 넓은 채널을 써 초고속과 저지연을 동시에 높이려는 세대임
- **배경/필요성**: Wi-Fi 6가 다수 단말 효율 개선에 초점을 맞췄다면, XR 스트리밍, 무선 협업, 고속 백홀처럼 끊김과 지연 변동에 민감한 서비스는 더 넓은 대역과 빠른 우회 수단이 필요해졌음

## Ⅱ. 특징

- MLO로 여러 대역을 병행 사용해 처리량을 합치거나 특정 링크 장애를 우회할 수 있음
- 320MHz 채널과 4096-QAM으로 단일 링크 성능 자체를 끌어올림
- Multi-RU와 향상된 Puncturing으로 일부 간섭 구간을 피해 자원을 더 세밀하게 배분함
- 실제 체감 성능은 6GHz 가용성, AP 안테나 구성, 클라이언트 지원 수준에 크게 좌우됨

## Ⅲ. 종류 및 비교

| 판단 기준 | Wi-Fi 6/6E | Wi-Fi 7 |
|:---|:---|:---|
| 링크 사용 방식 | 보통 한 시점에 한 대역 중심으로 통신함 | 여러 대역 링크를 동시에 묶거나 분산해 사용함 |
| 최대 채널 폭 | 최대 160MHz 중심으로 설계함 | 최대 320MHz까지 활용함 |
| 변조 수준 | 1024-QAM이 일반적임 | 4096-QAM을 지원해 더 높은 밀도를 지향함 |
| 혼잡 대응 | OFDMA와 BSS Coloring으로 효율을 높임 | 여기에 MLO와 향상된 Puncturing으로 지연 변동 대응을 강화함 |
| 도입 전제 | 기존 단말과의 호환성이 비교적 넓음 | AP와 단말이 모두 신기능을 지원해야 효과가 큼 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 다중 대역 무선부 | 2.4GHz, 5GHz, 6GHz 링크를 동시에 관리해 MLO 기반 전송을 가능하게 함 |
| MLO 제어부 | 어떤 링크를 묶고 어떤 링크로 우회할지 결정하는 스케줄링 계층임 |
| 넓은 채널과 변조 | 320MHz와 4096-QAM으로 단일 링크당 실을 수 있는 비트 수를 늘림 |
| 세밀한 자원 배분 | RU 조합과 Puncturing으로 간섭 구간을 제외하고 남은 대역을 활용함 |

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 링크 협상    | --> | 대역 묶기     | --> | 자원 배분     | --> | 동시 전송     |
+-----------+     +-----------+     +-----------+     +-----------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+     +-------------+
| 지원 기능 교환 | --> | MLO 링크 결정 | --> | 채널 상태 확인 | --> | 데이터 분산 전송 | --> | 링크 재조정 |
+-------------+     +-------------+     +-------------+     +-------------+     +-------------+
```

1. **지원 기능 교환**: AP와 단말이 MLO, 채널 폭, 변조 수준 같은 지원 기능을 먼저 확인함
2. **MLO 링크 결정**: 사용할 대역 조합과 동시에 운용할 링크를 정함
3. **채널 상태 확인**: 각 대역의 혼잡도와 간섭 구간을 보고 사용 가능한 자원을 계산함
4. **데이터 분산 전송**: 트래픽을 여러 링크와 RU에 나누어 전송해 처리량과 지연을 동시에 관리함
5. **링크 재조정**: 특정 링크 품질이 떨어지면 다른 링크 비중을 늘리거나 우회함

## Ⅵ. 실무 적용 및 유의점

1. XR, 무선 편집, 대용량 백홀처럼 대역폭과 지연 안정성이 모두 중요한 환경에서는 Wi-Fi 7을 검토할 가치가 크지만 6GHz 가용성과 단말 지원이 부족하면 효과가 제한되므로 지연 분산, 링크 재협상 횟수, 실제 처리량으로 적용 타당성을 확인함
2. 혼합 단말 환경에서는 Wi-Fi 7 AP만 교체해도 성능이 즉시 올라간다고 보기 어려우므로 SSID 분리, 대역 유도, 호환성 시험을 병행하고 구형 단말 비율, 로밍 안정성, 재전송률로 운영 품질을 확인함

## Ⅶ. 결론

Wi-Fi 7의 핵심은 더 빠른 단일 링크보다 여러 링크를 유연하게 묶어 지연 변동까지 줄이는 데 있음.
