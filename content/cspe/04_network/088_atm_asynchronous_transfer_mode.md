## 미리 알고가기

- 셀은 길이가 고정된 전송 단위로 ATM에서는 53바이트를 사용함
- VPI와 VCI는 ATM 망에서 가상 경로와 가상 채널을 구분하는 식별자임
- AAL은 음성, 영상, 데이터처럼 서로 다른 상위 데이터를 ATM 셀에 실을 수 있게 맞추는 적응 계층임
- CBR, VBR, ABR, UBR은 ATM이 다루는 대표 서비스 품질 등급임

## Ⅰ. 개요

- **정의/개념**: ATM은 53바이트 고정 길이 셀과 가상 경로 식별자를 이용해 음성, 영상, 데이터를 하나의 망에서 통합 전달하려 한 고속 교환 기술임
- **배경/필요성**: 실시간 음성과 영상은 지연 변동에 민감하고 데이터 트래픽은 순간적으로 몰리므로 지연 예측성과 통계적 다중화를 함께 잡을 수 있는 전송 방식이 필요했음

## Ⅱ. 특징

- 셀 길이가 고정돼 스위치 처리 시간이 일정하고 지연 예측이 쉬움
- VPI와 VCI로 경로를 구분해 빠른 하드웨어 스위칭에 유리함
- AAL을 통해 서로 다른 서비스 성격을 하나의 셀 구조에 실을 수 있음
- 작은 셀 덕분에 지연은 줄지만 헤더 비율이 커서 오버헤드가 증가함

## Ⅲ. 종류 및 비교

| 판단 기준 | 프레임 릴레이 | ATM | 이더넷 |
|:---|:---|:---|:---|
| 전송 단위 | 가변 길이 프레임 | 53바이트 고정 길이 셀 | 가변 길이 프레임 |
| 지연 예측성 | 중간 수준 | 가장 높음 | 서비스별 보장이 기본 구조에 없음 |
| 서비스 품질 | 단순한 계약 속도 중심 | 등급별 품질 제어가 정교함 | 별도 QoS 설계가 필요함 |
| 오버헤드 | 비교적 작음 | 셀이 작아 상대 오버헤드가 큼 | 일반 데이터 전송에 효율적임 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| ATM 셀 | 5바이트 헤더와 48바이트 페이로드로 구성된 고정 길이 전송 단위임 |
| VPI/VCI | 교환기가 셀을 어느 경로와 채널로 보낼지 판단하는 핵심 식별자임 |
| AAL | 상위 계층 데이터를 잘라 셀에 싣고 수신 측에서 다시 조립하는 적응 계층임 |
| ATM 스위치 | VPI와 VCI를 보고 셀을 빠르게 교환하는 장비임 |
| 트래픽 계약 | 지연과 손실과 대역폭 목표를 서비스 등급별로 관리하는 기준임 |

```text
+-----------+    +-----------+    +-----------+    +-----------+
| 상위 데이터   | -> | AAL 분할     | -> | ATM 셀 전송   | -> | 수신 측 재조립 |
+-----------+    +-----------+    +-----------+    +-----------+
                    |
                    v
                VPI/VCI 기반 교환
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
| 서비스 분류    | -> | 셀 분할       | -> | VPI/VCI 설정  | -> | 셀 교환       | -> | 재조립·전달    |
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
```

1. **서비스 분류**: 음성, 영상, 데이터 요구를 보고 품질 등급을 정함
2. **셀 분할**: AAL이 상위 데이터를 48바이트 단위로 잘라 셀에 담음
3. **VPI/VCI 설정**: 경로와 채널 식별자를 붙여 스위칭 준비를 함
4. **셀 교환**: 중간 ATM 스위치가 식별자만 보고 빠르게 전달함
5. **재조립과 전달**: 수신 측이 셀을 다시 묶어 원래 데이터로 넘김

## Ⅵ. 실무 적용 및 유의점

1. 통신 사업자 백본이나 DSL 구간처럼 ATM이 남아 있는 환경은 서비스 등급 설계가 중요하므로 셀 손실률과 지연 변동과 AAL 재조립 오류를 함께 봐야 함
2. ATM 구간을 이더넷 기반 망으로 바꿀 때는 고정 셀 기반의 지연 특성이 사라지므로 실시간 트래픽은 별도 QoS 정책을 다시 설계하고 응답 지연과 지터가 허용 범위에 남는지 확인해야 함

## Ⅶ. 결론

ATM은 고정 길이 셀로 지연 예측성과 품질 제어를 얻는 대신 오버헤드를 감수하는 구조이므로 실시간성 요구가 얼마나 큰지가 선택 기준임
