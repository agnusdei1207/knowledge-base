## Ⅰ. 개요
- **정의**: 광역망(SD-WAN) 네트워킹 기술과 클라우드 네이티브 보안 기술(SSE: ZTNA, CASB, SWG, FWaaS)을 단일 클라우드 서비스로 융합한 아키텍처임.
- **배경/필요성**: 기업 앱과 데이터가 클라우드로 이동함에 따라, 모든 트래픽을 본사로 돌려(Backhauling) 보안 검사하던 기존 구조의 비효율성 해결.
- **출제 의도**: SASE의 등장 배경, 네트워크(SD-WAN)와 보안(SSE)의 통합 개념, 클라우드 엣지 중심의 분산 보안 모델 이해.

## Ⅱ. 구성요소
```text
+-----------------------+              +-----------------------+
|    Remote Branch      |  SD-WAN      |   Cloud SASE Edge     |
|    / Remote Worker    |------------->|  [ Network as a Svc ] |
+-----------------------+              |  [ Security as a Svc ]|
                                       +-----------+-----------+
                                                   | (Policy &
                                                   v  Routing)
                                       +-----------------------+
                                       |  Internet / SaaS /    |
                                       |  Public Cloud Apps    |
                                       +-----------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| SD-WAN Edge | 지사나 단말에서 트래픽을 분류하고 가장 가까운 SASE 클라우드 노드(PoP)로 터널을 연결 | 고속 진입로 |
| SSE (Security Edge) | SWG(웹보안), CASB(클라우드통제), ZTNA(원격접속), FWaaS가 결합된 클라우드 보안 스택 | 종합 클라우드 검문소 |
| Central Management| 네트워크 라우팅 및 보안 정책을 단일 콘솔에서 통합 관리하는 오케스트레이터 | 통합 관제 센터 |
> 요약: 엣지 장비가 가장 가까운 클라우드 검문소로 트래픽을 보내면, 검문소에서 라우팅과 모든 보안 검사를 원스톱으로 처리함.

## Ⅲ. 절차
```text
+-----------+   +-------------+   +-------------+   +-----------+
| 트래픽발생|-> | PoP 라우팅  |-> | 단일 패스 검사|->| 최종 목적지|
+-----------+   +-------------+   +-------------+   +-----------+
```
1. **트래픽 발생**: 지사 라우터나 원격 근무자의 에이전트에서 클라우드(SaaS) 또는 내부망(IaaS)으로 향하는 트래픽이 발생함.
2. **PoP 라우팅**: SD-WAN이 해당 트래픽을 가장 지리적으로 가깝고 최적화된 글로벌 SASE 엣지 노드(PoP)로 전송함.
3. **단일 패스 검사**: SASE 노드에서 트래픽의 암호를 해독한 뒤 ZTNA(접근제어), WAF, DLP(데이터 유출 방지) 검사를 단일 엔진에서 동시 수행함.
4. **최종 목적지**: 검사를 무사히 통과한 안전한 트래픽만 인터넷, SaaS, 혹은 기업 내부 프라이빗 앱으로 고속 포워딩함.
> 요약: 여러 보안 장비를 거치는 데이지 체인 방식 대신, 클라우드 엣지에서 패킷을 한 번 열어 모든 검사를 마침.

## Ⅳ. 문제점
- **벤더 종속성(Lock-in)**: 네트워크 장비와 보안 솔루션을 단일 벤더 생태계에 의존해야 하므로 종속성 리스크 큼.
- **도입 비용 및 장벽**: 기존에 투자된 온프레미스 방화벽 및 레거시 네트워크 인프라를 매몰 비용으로 처리하고 전면 교체해야 하는 부담.
- **단일 장애점 위협**: SASE 제공 사업자의 클라우드 인프라나 글로벌 백본에 장애가 발생하면 고객사 전사 통신이 마비됨.

## Ⅴ. 개선방안
- **단계적 하이브리드 도입**: 기존 SD-WAN과 보안 기능을 별개로 운영하다가(멀티 벤더 SASE), 점진적으로 통합(단기).
- **PoP 가용성 검토**: SASE 도입 시 사업자의 글로벌 PoP 분포도 및 백본 이중화, SLA 보장 조건을 철저히 평가 (중기).
- **Single-Vendor SASE 구현**: 네트워크와 보안이 진정으로 일원화된 단일 벤더 플랫폼을 통해 운영 복잡도 최소화 및 가시성 확보 (장기).

## Ⅵ. 전망
- 재택근무와 클라우드 마이그레이션이 결합된 '경계 없는 기업(Borderless Enterprise)'의 최종 네트워크-보안 청사진으로 굳어짐.
- 향후 AI를 활용하여 위협 탐지 및 네트워크 경로 최적화가 스스로 이루어지는 자율형 SASE 아키텍처로 진화할 예정임.
