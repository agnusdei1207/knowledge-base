## 미리 알고가기

- OT는 공장과 설비를 실제로 제어하는 운영 기술 영역임
- SCADA는 현장 설비 상태를 감시하고 제어하는 시스템임
- 예지 보전은 고장 뒤 수리가 아니라 고장 징후를 미리 찾아 정비하는 방식임
- 엣지 분석은 설비 가까운 곳에서 먼저 데이터를 분석하는 처리 방식임

## Ⅰ. 개요

- **정의/개념**: IIoT는 산업 설비에서 나온 데이터를 수집하고 분석해 상태를 파악하고 제어와 최적화까지 연결하는 산업용 연결 구조임
- **배경/필요성**: 공장과 발전소와 물류 설비는 고장 한 번의 영향이 크고 사람이 모든 징후를 실시간으로 보기 어렵기 때문에 데이터를 계속 모아 운영 판단을 보조할 체계가 필요함

## Ⅱ. 특징

- 생산 설비를 제어하므로 안전, 가용성, 제어 일관성을 함께 확보해야 함
- OT 설비와 IT 플랫폼을 연결하므로 데이터 해석과 권한 관리가 복잡함
- 현장 엣지에서 먼저 걸러 보면 회선 부하와 응답 지연을 줄일 수 있음
- 분석 정확도만 볼 것이 아니라 오경보와 제어 위험도 함께 관리해야 함

## Ⅲ. 종류 및 비교

| 판단 기준 | 소비자 IoT | IIoT |
|:---|:---|:---|
| 주된 목적 | 편의 기능과 개인 서비스 | 설비 운영, 생산 최적화, 안전 확보 |
| 허용 장애 수준 | 일부 서비스 중단을 감수할 수 있음 | 중단 시 생산 손실과 안전 문제가 커짐 |
| 데이터 처리 | 클라우드 중심 구성이 흔함 | 엣지와 현장 제어가 더 중요함 |
| 보안 관점 | 개인정보 보호가 중심임 | 설비 제어 보호와 망 분리가 중요함 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 현장 설비 | 센서와 모터와 제어기가 실제 데이터를 만들고 동작을 수행함 |
| 제어 시스템 | PLC와 SCADA가 실시간 제어와 감시를 담당함 |
| 엣지 게이트웨이 | 데이터를 모으고 변환하고 현장 분석을 수행함 |
| 플랫폼과 분석 계층 | 저장과 분석과 예측 모델과 규칙 엔진을 제공함 |
| 업무 연계 계층 | MES, ERP, 유지보수 시스템과 연결해 운영 결정을 바꿈 |

```text
+-----------+    +-----------+    +-----------+    +-----------+    +-----------+
| 설비·센서     | -> | 제어 시스템   | -> | 엣지 게이트웨이 | -> | 분석 플랫폼   | -> | 운영 의사결정  |
+-----------+    +-----------+    +-----------+    +-----------+    +-----------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
| 데이터 수집    | -> | 현장 맥락화    | -> | 분석·예측      | -> | 경보·제어      | -> | 정비·최적화    |
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
```

1. **데이터 수집**: 설비의 온도와 진동과 전류 같은 신호를 읽음
2. **현장 맥락화**: 장비 번호와 공정 정보와 운전 상태를 함께 붙임
3. **분석과 예측**: 이상 징후나 효율 저하를 탐지함
4. **경보와 제어**: 운영자에게 알리거나 자동 조정을 실행함
5. **정비와 최적화**: 생산 계획과 유지보수 일정에 반영함

## Ⅵ. 실무 적용 및 유의점

1. 예지 보전은 IIoT의 대표 활용이지만 데이터 품질이 낮으면 오경보가 늘어나므로 센서 보정과 수집 주기를 먼저 잡고 알람 적중률과 계획 외 정지 시간을 함께 확인해야 함
2. OT와 IT를 직접 연결하면 IT 침해가 제어망으로 전파될 수 있으므로 망 분리와 중계 구간을 설계하고 원격 접속 기록과 비인가 제어 시도를 점검해야 함

## Ⅶ. 결론

IIoT는 센서를 많이 다는 사업이 아니라 설비 데이터가 실제 정비와 제어 판단으로 이어지게 만드는 운영 체계임
