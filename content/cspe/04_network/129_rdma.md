## 미리 알고가기

- DMA는 CPU 개입 없이 장치가 메모리와 데이터를 전송하는 방식임
- Zero-copy는 송수신 과정의 커널·사용자 공간 버퍼 복사를 줄이는 처리 방식임
- Kernel bypass는 애플리케이션이 커널 네트워크 스택을 거치지 않고 NIC와 통신하는 방식임
- 메모리 등록은 NIC가 접근할 버퍼의 주소와 권한을 사전에 고정·등록하는 절차임

## Ⅰ. 개요

- **정의/개념**: RDMA는 원격 노드의 등록 메모리를 CPU와 운영체제 커널의 데이터 복사 없이 NIC가 직접 읽고 쓰도록 하는 통신 기술임
- **배경/필요성**: 분산 학습과 고성능 저장장치는 작은 메시지를 반복 전송하므로 커널 경유, 문맥 교환, 버퍼 복사가 지연과 CPU 사용량을 증가시켜 데이터 경로를 단축할 기술이 필요함

## Ⅱ. 특징

- NIC가 등록 메모리 사이의 전송을 수행해 CPU의 데이터 이동 작업을 줄임
- One-sided 연산은 원격 애플리케이션의 수신 호출 없이 Read·Write를 수행함
- Queue Pair와 Completion Queue로 전송 요청과 완료 상태를 비동기로 관리함
- 메모리 등록, 접근 키, 연결 상태를 잘못 관리하면 메모리 노출이나 전송 실패가 발생함

## Ⅲ. 종류 및 비교

| 판단 기준 | TCP 소켓 | RDMA |
|:---|:---|:---|
| 데이터 경로 | 애플리케이션·커널 소켓 버퍼·NIC를 경유 | 등록 메모리와 RNIC 사이에서 직접 전송 |
| CPU 처리 | 시스템 호출과 프로토콜 스택 처리 | 제어 요청 등록과 완료 처리 중심 |
| 통신 연산 | Send·Receive 기반 양방향 호출 | Send·Receive와 One-sided Read·Write |
| 메모리 관리 | 운영체제가 소켓 버퍼를 관리 | 애플리케이션이 버퍼와 접근 키를 등록 |
| 대표 적용 사례 | 범용 서비스 통신 | 분산 학습, HPC, NVMe-oF 저장장치 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 역할 |
|:---|:---|
| RNIC | 등록 메모리 사이의 RDMA 전송을 실행함 |
| Protection Domain | Queue Pair와 메모리 영역의 접근 범위를 격리함 |
| Memory Region | 전송 대상 버퍼와 Local·Remote Key를 등록함 |
| Queue Pair | Send Queue와 Receive Queue에 작업 요청을 저장함 |
| Completion Queue | 완료·실패 상태를 애플리케이션에 전달함 |

```text
[애플리케이션 메모리] <-> [RNIC] ===== RDMA 패브릭 ===== [RNIC] <-> [등록 메모리]
          |                     Queue Pair·접근 키                     |
          +---------------------- 완료 큐 ----------------------------+
```

## Ⅴ. 원리 및 절차

1. **자원 생성**: Protection Domain과 Queue Pair와 Completion Queue를 생성함
2. **메모리 등록**: 전송 버퍼를 고정하고 접근 권한과 키를 RNIC에 등록함
3. **연결 정보 교환**: Queue Pair 번호, 주소, 접근 키를 상대 노드와 교환함
4. **작업 게시**: Send·Receive·Read·Write 요청을 Work Queue에 등록함
5. **완료 확인**: RNIC가 전송한 결과를 Completion Queue에서 확인함

## Ⅵ. 실무 적용 및 유의점

1. 분산 학습의 파라미터·그래디언트 전송에 RDMA를 적용할 때는 작은 메시지 지연과 CPU 사용률이 실제로 감소하는지 p99 지연, 처리량, CPU 사용률로 검증해야 함
2. 원격 메모리 키가 과도한 범위를 허용하면 프로세스 메모리가 노출될 수 있으므로 최소 영역만 등록하고 키 수명과 Protection Domain을 분리하며 접근 실패와 키 재사용 기록을 점검해야 함

## Ⅶ. 결론

RDMA는 등록 메모리와 RNIC를 직접 연결해 커널 경유와 데이터 복사를 줄이며, 통신 패턴과 메모리 접근 권한을 기준으로 적용해야 함.
