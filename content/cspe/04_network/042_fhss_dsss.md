## 미리 알고가기

- 대역 확산은 원래보다 더 넓은 주파수 대역으로 신호를 퍼뜨려 보내는 무선 방식임
- FHSS는 약속된 순서대로 주파수를 빠르게 바꿔 가며 전송하는 방식임
- DSSS는 데이터에 확산 코드를 곱해 넓은 대역으로 펼쳐 보내는 방식임
- PN 코드는 송수신기가 공유하는 확산 코드로, DSSS 복원에 쓰임
- 처리 이득은 신호를 넓게 퍼뜨린 뒤 다시 모을 때 얻는 간섭 저항 효과를 뜻함

## Ⅰ. 개요

- **정의/개념**: 대역 확산은 좁은 원신호를 넓은 주파수 대역으로 퍼뜨려 전송하는 방식이며, 대표적으로 주파수를 바꾸며 보내는 FHSS와 확산 코드를 곱해 보내는 DSSS가 있음
- **배경/필요성**: 특정 주파수의 간섭과 재밍 영향을 분산하려면 신호 에너지를 시간 또는 주파수 영역의 넓은 대역에 펼치는 방식이 필요했음

## Ⅱ. 특징

- 신호 전력을 넓게 분산해 특정 협대역 간섭에 대한 내성을 높일 수 있음
- FHSS는 도약 순서에 따라 여러 채널을 이동하므로 특정 채널 간섭이 전체 전송에 미치는 시간을 제한함
- DSSS는 같은 대역 안에서도 코드 기반으로 신호를 복원해 처리 이득을 얻을 수 있음
- 현대 초고속 무선의 주류는 OFDM 계열이지만, 대역 확산 개념은 블루투스, GPS, 일부 산업·군용 통신에서 여전히 중요함

## Ⅲ. 종류 및 비교

| 판단 기준 | FHSS | DSSS |
|:---|:---|:---|
| 확산 방식 | 시간에 따라 사용하는 주파수 채널을 계속 바꿔 다님 | 데이터에 확산 코드를 곱해 주파수 대역 전체로 퍼뜨림 |
| 간섭 대응 방식 | 간섭 채널을 피해서 통신을 이어감 | 수신 시 상관 복원으로 유효 신호를 추려 냄 |
| 동기화 핵심 | 송수신기의 도약 순서와 타이밍이 맞아야 함 | 송수신기의 확산 코드와 칩 타이밍이 맞아야 함 |
| 대표 적용 | 블루투스와 일부 산업·군용 무선에 적합함 | GPS, 초기 802.11b, CDMA 계열 통신에 적합함 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 확산 규칙 | FHSS는 도약 순서가, DSSS는 확산 코드가 핵심 규칙으로 작동함 |
| 동기화 회로 | 송신기와 수신기가 같은 시점에 같은 주파수나 코드를 맞추게 하는 장치임 |
| 무선 채널 | 협대역 간섭, 잡음, 재밍 같은 외부 영향을 받는 전송 환경임 |
| 복원 처리 | 수신 측이 도약 복원이나 역확산을 수행해 원신호를 되살리는 단계임 |

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 원신호 생성 | --> | 확산 적용    | --> | 무선 전송    | --> | 동기화·복원 |
+-----------+     +-----------+     +-----------+     +-----------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+     +-------------+
| 송신 규칙 공유 | --> | 신호 확산     | --> | 채널 통과     | --> | 규칙 동기화   | --> | 원신호 복원 |
+-------------+     +-------------+     +-------------+     +-------------+     +-------------+
```

1. **송신 규칙 공유**: 송수신기가 도약 패턴이나 확산 코드를 미리 공유함
2. **신호 확산**: FHSS는 주파수를 바꾸고 DSSS는 코드를 곱해 신호를 넓게 퍼뜨림
3. **채널 통과**: 신호가 잡음, 간섭, 재밍이 있는 무선 채널을 지나감
4. **규칙 동기화**: 수신기가 같은 패턴이나 코드에 맞춰 수신 타이밍을 맞춤
5. **원신호 복원**: 동기화된 규칙으로 유효 신호를 추려 원데이터를 복구함

## Ⅵ. 실무 적용 및 유의점

1. 2.4GHz 공존 환경에서 블루투스 기반 장비를 운영할 때는 FHSS 자체만 믿지 말고 적응형 도약과 채널 조사 기능을 함께 써야 하며 패킷 오류율, 점유 채널 분포, 재접속 횟수로 공존 품질을 확인함
2. DSSS 계열 시스템은 코드 동기화가 무너지면 성능이 급격히 떨어지므로 수신 감도, 코드 획득 시간, 간섭 여유도를 함께 측정해 실제 현장 복원성을 확인함

## Ⅶ. 결론

FHSS와 DSSS는 신호를 넓게 퍼뜨려 신뢰성을 높인다는 공통 목적을 가지지만, 간섭을 피하는 방식과 복원 방식이 달라 적용 환경도 다르게 판단해야 함.
