## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 네트워크 인터페이스를 오가는 원시(Raw) 통신 패킷을 캡처하고, 내장된 프로토콜 디코더를 통해 세부 헤더와 데이터 페이로드를 사람이 읽을 수 있게 분석하는 소프트웨어 도구 |
| **배경/필요성** | 심층 네트워크 장애 원인(지연, 재전송), 해킹 공격 여부(악성 페이로드), 애플리케이션 통신 오류의 직관적인 증거(Evidence) 확보 필요 |
| **출제 의도** | Promiscuous 캡처 모드, 필터링 문법 (BPF/Display Filter), 프로토콜 트리(Tree) 계층별 디코딩 원리 이해 평가 |

## Ⅱ. 구성요소
```text
+----------+       +----------+       +----------+
| Switch   |       | Interface|       | Analyzer |
| (Mirror) | ====> | (Promisc)| ====> | (PCAP)   |
+----------+       +----------+       +----------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| Promiscuous | NIC가 목적지 MAC 주소와 무관하게 회선 상의 모든 프레임을 커널 공간으로 무조건 수신하는 모드 | 무제한 도청기 |
| PCAP (라이브러리) | OS 종류에 상관없이 커널에서 패킷을 가로채 응용 프로그램(Wireshark 등)으로 전달하는 API 엔진 | 통신 검열 스니퍼 엔진 |
| tcpdump / Wireshark | CLI 환경 고속 캡처 도구(tcpdump)와 GUI 기반 강력한 다중 프로토콜 심층 분석기(Wireshark) | 텍스트 스캐너 / 3D 정밀 현미경 |

> 요약: 미러링된 포트에서 무차별 캡처를 수행하고 복잡한 이진 데이터를 L2~L7 모델 기반 시각적 정보로 변환함

## Ⅲ. 절차
```text
+----------+    +----------+    +----------+    +----------+
| 포트 미러| -> | 조건 캡처| -> | 프로디코딩| -> | 심층 분석|
+----------+    +----------+    +----------+    +----------+
```
1. 포트 미러: 장애가 의심되는 주요 서버 앞단 스위치 포트에 Port Mirroring(SPAN) 설정으로 트래픽 복제
2. 조건 캡처: tcpdump(또는 Tshark)에 BPF 필터('tcp port 80')를 적용해 서버 CPU 부하를 최소화하며 원하는 패킷만 파일 저장(.pcap)
3. 프로디코딩: 저장된 PCAP 파일을 관리자 PC의 Wireshark로 열어 수천 개의 프로토콜 딕셔너리 기반 자동 해독
4. 심층 분석: Display Filter를 활용하여 TCP 재전송(Retransmission) 추적 및 HTTP 트랜잭션 응답 지연 세부 원인 규명

> 요약: BPF 기반 고속 캡처(커널 레벨) 후 광범위한 프로토콜 디코더(GUI)를 통한 정밀 분석(TCP 흐름 추적) 수행

## Ⅳ. 문제점
- 고속 10G/40G 망에서 일반 PC 캡처 시도 시 CPU/디스크 I/O 병목으로 대량의 패킷 유실(Drop) 발생 (증거 불충분)
- 캡처된 파일 크기가 수십 GB에 달해 Wireshark GUI에서 파일을 여는 순간 메모리 폭주로 프로그램 강제 종료 (분석 마비)
- 대부분의 현대 트래픽이 TLS/HTTPS로 강력하게 암호화되어 있어 패킷 헤더(L4) 외 L7 페이로드 직접 분석 전면 불가

## Ⅴ. 개선방안
- [단기] CLI 장비(tcpdump)로 캡처 파일 크기를 일정 용량(-C)이나 시간(-G) 단위로 분할(Rotate) 저장하여 메모리 부담 회피
- [중기] 패킷 로스 없는 전용 고속 캡처 하드웨어 어플라이언스(Smart NIC 기반) 도입으로 100% 무결점 증거 수집 체계 구축
- [장기] 서버의 개인키(Private Key) 반입 또는 세션 키(Pre-Master Secret) 로깅을 연동하여 Wireshark 상 TLS 자동 복호화 기능 적용

## Ⅵ. 전망
- 암호화 통신이 지배하는 환경에서는 단순 패킷 디코딩을 넘어 인공지능 기반의 메타데이터 및 행위(Behavior) 분석 엔진으로 진화 중임
