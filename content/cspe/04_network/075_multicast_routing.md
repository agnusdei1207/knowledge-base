## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 하나의 송신자가 다수의 특정 그룹 수신자에게 트래픽을 효율적으로 전달하기 위한 경로 제어 통신 기술 |
| **배경/필요성** | IPTV, 화상회의 등 대용량 미디어 스트리밍 환경에서 유니캐스트 방식의 대역폭 낭비 문제 완벽 해결 필요 |
| **출제 의도** | IGMP 그룹 관리, PIM-DM/SM 라우팅 방식의 차이점 및 RP(Rendezvous Point) 개념 이해 평가 |

## Ⅱ. 구성요소
```text
+----------+       +----------+       +----------+
|  Source  |       | Router   |       | Receiver |
| (Video)  | ----> | (PIM-SM) | ====> | (IGMP)   |
+----------+       +----------+       +----------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| IGMP | 클라이언트가 라우터에게 특정 멀티캐스트 그룹에 가입/탈퇴함을 알리는 프로토콜 | 방송 채널 구독 신청 |
| PIM-DM | 수신자가 많을 때 전체 망에 일단 트래픽을 플러딩한 후 불필요한 곳은 잘라내는(Prune) 밀집 모드 | 전단지 무차별 배포 |
| PIM-SM | 수신자가 적게 분산된 환경에서 RP를 중심으로 요청이 올 때만 트래픽을 전달하는 희소 모드 | 구독자 맞춤형 배달 |

> 요약: 단일 패킷 전송 후 분기점(라우터)에서만 복제를 수행하여 네트워크 전체 대역폭을 획기적으로 절약함

## Ⅲ. 절차
```text
+----------+    +----------+    +----------+    +----------+
| 그룹 가입| -> | 트리 생성| -> | 패킷 복제| -> | 가지치기 |
+----------+    +----------+    +----------+    +----------+
```
1. 그룹 가입: 단말(PC/셋톱박스)이 IGMP Report 메시지를 라우터로 보내 멀티캐스트 수신 희망 알림
2. 트리 생성: 라우터 간 PIM 프로토콜을 통해 송신자부터 수신자까지의 최적 분배 트리(Tree) 구축
3. 패킷 복제: 영상 서버가 1개의 패킷만 발송하면 중간 라우터가 필요한 포트로만 스스로 복제 전송
4. 가지치기: 수신자가 더 이상 없는 서브넷 라우터는 Prune 메시지를 보내 트래픽 유입 동적 차단

> 요약: 수신자 유무(IGMP)를 기반으로 라우팅 트리(PIM)를 동적 관리하여 최소 트래픽을 유지함

## Ⅳ. 문제점
- PIM-DM 모드는 플러딩(Flooding) 후 가지치기 동작을 반복하여 대규모 망에서 대역폭 및 CPU 심각 낭비
- PIM-SM 환경에서 핵심 중계점인 RP(Rendezvous Point) 장비 고장 시 전체 멀티캐스트 서비스 일시 중단
- 무선 LAN 환경(Wi-Fi)에서는 멀티캐스트 프레임이 가장 낮은 기본 속도로 전송되어 무선 채널 점유 심화

## Ⅴ. 개선방안
- [단기] 기업 및 ISP 망에서는 반드시 확장성이 뛰어난 PIM-SM 모드로 구성하여 플러딩 방지
- [중기] Anycast RP 혹은 Auto-RP를 적용하여 다중 RP 환경 구성으로 단일 장애점(SPOF) 완벽 해소
- [장기] 무선 컨트롤러에 Multicast-to-Unicast 변환(IGMP Snooping) 기능을 적용하여 Wi-Fi 전송 효율 향상

## Ⅵ. 전망
- SDN 기반의 트래픽 엔지니어링 융합을 통해 방송망과 통신망의 경계를 허무는 핵심 기술로 확산될 것임
