## 미리 알고가기

- PDH는 비동기식 디지털 다중화 계위로, 지역별 규격 차이가 컸던 초기 전송망 구조임
- SDH와 SONET은 동기식 전송망 표준으로, 위치 표시값과 운용·관리 정보를 통해 운영성과 상호연동성을 높인 구조임
- ADM은 중간 노드에서 필요한 신호만 분기·결합하는 장치임

## Ⅰ. 개요

- **정의/개념**: PDH·SDH·SONET은 저속 음성·데이터 회선을 상위 계위로 다중화하는 디지털 전송 체계이며, SDH·SONET은 공통 클럭과 표준 프레임·관리 오버헤드를 사용하는 동기식 구조임
- **배경/필요성**: 초기 PDH는 지역별 규격이 달랐고 원하는 저속 회선을 꺼내려면 전체 역다중화를 해야 했으므로, 대용량 광 전송과 국제 상호연동과 손쉬운 분기·결합을 지원하는 동기식 구조가 필요함

## Ⅱ. 특징

- PDH는 계위별 클럭 차이를 비트 채움으로 보정하므로 하위 신호를 꺼낼 때 단계별 역다중화가 필요함
- SDH·SONET은 포인터 기반 구조로 필요한 신호만 직접 분기하기 좋음
- 운용·관리 정보가 풍부해 장애 관리와 성능 감시가 쉬움
- 고정 대역폭 회선 중심이라 패킷 트래픽에는 유연성이 떨어짐

## Ⅲ. 종류 및 비교

| 판단 기준 | PDH | SDH | SONET |
|:---|:---|:---|:---|
| 동기 구조 | 비동기식이라 스터핑과 지역별 계위 차이가 큼 | 동기식 구조로 국제 표준 전송망에 적합함 | 북미 중심 동기식 구조로 SDH와 기본 개념이 유사함 |
| 분기·결합 | 원하는 저속 채널을 꺼내려면 다단계 역다중화가 필요함 | 포인터와 ADM으로 원하는 신호만 직접 분기 가능함 | ADM과 OAM 구조를 통해 직접 분기와 관리가 쉬움 |
| 운영·관리 | OAM 기능이 제한적임 | 관리 바이트가 풍부해 보호 절체와 성능 감시가 편함 | 북미 광 전송망 운영 기준에 널리 쓰였음 |
| 적합 환경 | 초기 음성 중심 전송망에 적합했음 | 국제 백본과 사업자 광망에 적합함 | 북미 사업자 광망과 연동 구간에 적합함 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 유효 데이터 영역 | 실제 사용자 데이터가 담기는 공간임 |
| 위치 표시값 | 프레임 안에서 유효 데이터 시작 위치를 가리켜 분기·결합 효율을 높임 |
| 관리 정보 영역 | 구간·회선·경로 관리 정보를 담아 운용·관리 기능을 제공함 |
| 분기·결합 장치 | 저속 회선을 상위 프레임에 실어 보내고 중간에서 필요한 신호만 분기함 |

```text
+-------------+     +-------------+     +-------------+     +-------------+
```

## Ⅴ. 원리 및 절차 흐름도

1. **저속 신호 입력**: 하위 디지털 회선을 준비함
2. **동기 프레임 매핑**: 유효 데이터 영역과 위치 표시값과 관리 정보가 들어 있는 프레임으로 실음
3. **다중화·전송**: 상위 계위로 묶어 광 전송망으로 보냄
4. **ADM 분기·복구**: 중간 노드에서 필요한 신호만 분기하고 장애 시 보호 절체를 수행함

## Ⅵ. 실무 적용 및 유의점

1. 사업자 광 전송망과 레거시 회선 서비스에서 SDH·SONET은 관리 오버헤드와 보호 절체를 제공하지만 가변 패킷 트래픽은 고정 시분할 슬롯을 채우지 못할 수 있으므로 보호 절체 시간·유효 데이터 활용률·장애 구간 식별 시간으로 전환 범위를 판단함
2. PDH 연동 구간은 지역별 계위와 분기 절차가 달라 운용 실수가 나기 쉬우므로 매핑 표준과 회선 자산 목록을 함께 관리하고 개통 오류 건수와 분기 성공률과 상호연동 문제 건수로 확인함

## Ⅶ. 결론

PDH·SDH·SONET의 진화 핵심은 속도 증가보다 비동기 다중화의 운용 한계를 동기식 구조와 관리 기능으로 해결한 데 있음.
