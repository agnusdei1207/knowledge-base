## Ⅰ. 개요
- **정의**: 양자 얽힘과 양자 채널로 노드 간 양자 정보를 전송하는 글로벌 네트워크임
- **배경/필요성**: QKD(136 참조)·분산 양자컴퓨팅·양자 센싱을 연결하려면 종단 간 양자 상태 전달 인프라가 필요함
- **비유**: 기존 인터넷이 비트를 전달하듯, 양자 인터넷은 큐비트를 전달하는 새로운 통신 계층과 같음

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 양자 네트워크 계층 구조 이해 | 양자 중계기·얽힘 스와핑·양자 메모리 | QKD와의 포함 관계 구분 필요 |

> 요약: 양자 얽힘 기반으로 큐비트를 종단 간 전달하는 차세대 통신 인프라임

## Ⅱ. 구성요소
```text
[Quantum Node A] --Entanglement-- [Quantum Repeater] --Entanglement-- [Quantum Node B]
                                        |
                                  [Quantum Memory]
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 양자 노드 | 큐비트 생성·처리·측정을 수행하는 종단 장치 | 양자 컴퓨터 터미널 |
| 양자 중계기 | 얽힘 스와핑으로 장거리 얽힘을 연장하는 중간 노드 | 장거리 릴레이 주자 |
| 양자 메모리 | 큐비트 상태를 일정 시간 보존하는 저장 장치 | 양자 USB 메모리 |
| 얽힘 소스 | 얽힌 광자 쌍을 생성하는 장치 | 쌍둥이 동전 발행기 |

> 요약: 양자 노드·중계기·메모리·얽힘 소스로 장거리 양자 통신을 구현함

## Ⅲ. 절차
```text
얽힘 생성 -> 얽힘 분배 -> 얽힘 스와핑/정제 -> 양자 텔레포테이션
```
- 1단계: 얽힘 생성 — 얽힘 소스에서 벨 상태의 광자 쌍 생성
- 2단계: 얽힘 분배 — 양자 채널(광섬유·위성)로 얽힌 광자를 인접 노드에 전달
- 3단계: 얽힘 스와핑/정제 — 중계기에서 벨 측정으로 비인접 노드 간 얽힘 확장·정제
- 4단계: 양자 텔레포테이션 — 공유된 얽힘과 고전 정보로 큐비트 상태를 원격 전송

> 요약: 얽힘 생성-분배-스와핑-텔레포테이션의 4단계로 양자 정보를 전달함

## Ⅳ. 문제점
- 양자 메모리 결맞음 시간: 현재 ms~s 수준으로 장거리 중계 체인 유지가 곤란함
- 얽힘 생성률: 장거리에서 광자 손실로 초당 얽힘 쌍 생성 수가 급감함
- 프로토콜 표준 부재: 양자 네트워크 계층 모델·라우팅 프로토콜이 미확립임

> 요약: 결맞음 시간·얽힘 생성률·프로토콜 부재가 양자 인터넷의 핵심 난제임

## Ⅴ. 개선방안
1. 단기: 다이아몬드 NV 센터 등 고결맞음 양자 메모리 소재 연구 가속
2. 중기: 다중 모드 양자 중계기로 병렬 얽힘 생성률 향상
3. 장기: 양자 네트워크 프로토콜 스택(물리-링크-네트워크-응용) 국제 표준 수립

> 요약: 메모리 소재·병렬 중계·프로토콜 표준화로 양자 인터넷 실현을 앞당김

## Ⅵ. 전망
- 발전 방향: 단계별(Prepare&Measure → 얽힘 분배 → 양자 인터넷) 성숙도 로드맵에 따라 진화
- 기술사적 판단: 양자컴퓨팅 상용화 시기와 연동하여 연구망에서 상용망으로 전환될 것임
- 기술사 제언: 국가 양자 시험망 구축과 QKD(136 참조) 인프라 연계 전략 수립이 필요함
