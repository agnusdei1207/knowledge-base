## Ⅰ. 개요
- **정의**: 방화벽, 라우터, 로드밸런서 등 고가 전용 하드웨어의 네트워크 기능을 범용 서버 위에서 가상화 소프트웨어로 구현하는 기술임.
- **배경/필요성**: 장비 도입 비용(CAPEX) 및 운영 비용(OPEX) 절감, 서비스 배포 및 변경의 민첩성 요구 증가.
- **출제 의도**: NFV 아키텍처(ETSI 표준) 이해, VNF와 MANO의 역할, SDN과의 상호 보완 관계 파악.

## Ⅱ. 구성요소
```text
+-----------------------+ +-----------------------+
|          OSS/BSS      | |         MANO          |
|                       | | (Orchestrator, VNFM,  |
+-----------+-----------+ |  VIM)                 |
            |             +-----------+-----------+
+-----------+-----------+             |
|          VNF          |<------------+
| (Virtual Network Func)|
+-----------+-----------+
            |
+-----------+-----------+
|          NFVI         |
| (Compute, Storage, Net|
+-----------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| MANO | NFV 전체 아키텍처의 자원 할당, 오케스트레이션 및 라이프사이클 관리 | 시스템 관리자 |
| VNF | 범용 서버의 가상 머신(VM) 등에서 실행되는 소프트웨어 기반 네트워크 기능 | 전문 작업용 S/W |
| NFVI | VNF가 실행되기 위한 하드웨어 자원과 하이퍼바이저 등의 인프라 | PC 하드웨어 |
> 요약: NFVI를 기반으로 VNF를 구동하며, 이를 MANO가 중앙에서 조율 및 관리함.

## Ⅲ. 절차
```text
+-----------+   +-------------+   +-------------+   +-----------+
| 인프라할당|-> | VNF 생성    |-> | 서비스체이닝|-> | 상태 모니터|
+-----------+   +-------------+   +-------------+   +-----------+
```
1. **인프라 할당**: MANO(VIM)를 통해 NFVI의 컴퓨팅, 스토리지, 네트워크 자원을 프로비저닝함.
2. **VNF 생성**: 할당된 가상 환경(VM/컨테이너) 위에 요구되는 네트워크 기능(VNF) 인스턴스를 배포함.
3. **서비스 체이닝(SFC)**: 트래픽이 여러 VNF(예: 방화벽->IDS->로드밸런서)를 순서대로 거치도록 논리적 경로를 구성함.
4. **상태 모니터**: MANO가 지속적으로 VNF의 성능과 헬스를 모니터링하여 오토스케일링 및 장애 복구를 수행함.
> 요약: 자원 프로비저닝부터 VNF 배포, 트래픽 유도, 성능 감시까지 자동화된 라이프사이클을 가짐.

## Ⅳ. 문제점
- **가상화 오버헤드**: 하이퍼바이저 경유로 인한 전용 하드웨어 대비 네트워크 패킷 처리 성능 저하.
- **상호 운용성 부족**: 다양한 벤더의 VNF와 MANO 플랫폼 간 호환성 문제.
- **보안 취약점**: 하이퍼바이저 해킹이나 가상화 환경 탈출 공격 시 여러 VNF가 동시 피해를 입음.

## Ⅴ. 개선방안
- **성능 최적화**: SR-IOV, DPDK(Data Plane Development Kit) 활용하여 패킷 처리 고속화 (단기).
- **표준화 준수**: ETSI NFV 표준 준수 및 오픈소스 MANO(OSM) 도입으로 벤더 종속성 해결 (중기).
- **클라우드 네이티브 전환**: 무거운 VM 기반 VNF에서 가벼운 컨테이너 기반 CNF(Cloud Native Function)로 마이그레이션 (장기).

## Ⅵ. 전망
- 통신사의 5G 코어 네트워크(5GC) 아키텍처 구성의 핵심 기술로 이미 자리매김함.
- 향후 SDN과 완벽히 융합하여 인텐트 기반으로 실시간 서비스 프로비저닝이 가능한 자율형 인프라로 진화할 것임.
