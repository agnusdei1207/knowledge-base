## 미리 알고가기

- EVPN은 BGP를 이용해 L2, L3 가상망의 단말 위치와 경로 정보를 교환하는 제어 평면임
- VXLAN은 실제 데이터를 운반하는 오버레이 캡슐화 방식임
- VTEP는 VXLAN 터널 종단 장비임
- ARP 억제는 불필요한 브로드캐스트를 줄이기 위해 제어 평면 정보로 응답하는 방식임

## Ⅰ. 개요

- **정의/개념**: BGP EVPN은 VXLAN 같은 오버레이 환경에서 MAC과 IP 위치 정보를 BGP로 교환해 가상 네트워크 제어 평면을 구성하는 기술임
- **배경/필요성**: VXLAN만으로 대규모 가상망을 만들면 Flood-and-Learn 방식 때문에 브로드캐스트와 미지 유니캐스트가 늘어나므로, 단말 위치를 제어 평면에서 미리 학습해 확장성과 안정성을 높일 방식이 필요함

## Ⅱ. 특징

- 데이터 평면 학습 대신 BGP 제어 평면으로 MAC, IP 정보를 교환해 플러딩을 줄임
- ARP 억제와 분산 게이트웨이 구성이 가능해 데이터센터 확장성이 좋아짐
- VXLAN 오버레이와 잘 결합돼 멀티테넌트 데이터센터의 표준 구조로 쓰기 좋음
- Route Reflector와 정책 설계를 잘못하면 잘못된 정보가 넓게 퍼질 수 있어 제어 평면 검증이 중요함

## Ⅲ. 종류 및 비교

| 판단 기준 | VXLAN 단독 Flood-and-Learn | BGP EVPN 기반 VXLAN |
|:---|:---|:---|
| 단말 학습 방식 | 데이터가 실제 흘러봐야 MAC 위치를 알 수 있음 | 제어 평면이 MAC, IP 위치를 미리 교환함 |
| 브로드캐스트 처리 | BUM 트래픽이 커질 수 있음 | ARP 억제와 제어 평면 학습으로 BUM을 줄임 |
| 확장성 | 규모가 커질수록 학습과 플러딩 부담이 커짐 | 대규모 리프-스파인 구조에 더 적합함 |
| 운영 기능 | 기본 오버레이 구현에 집중함 | 멀티호밍, Anycast Gateway 같은 고급 운용이 가능함 |

> 요약: EVPN은 VXLAN 데이터 평면에 필요한 제어 두뇌를 더해 대규모 확장 문제를 줄이는 기술임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Leaf VTEP | 단말이 붙는 리프 스위치이자 VXLAN 터널 종단 역할을 수행함 |
| MP-BGP EVPN | MAC, IP, 테넌트 정보를 교환하는 제어 평면 프로토콜임 |
| Route Reflector | 다수 VTEP의 EVPN 경로를 중계해 BGP 세션 복잡도를 낮춤 |
| VXLAN 데이터 평면 | 실제 사용자 프레임을 오버레이로 운반하는 데이터 경로임 |
| Anycast Gateway | 어느 리프에서든 같은 게이트웨이 주소로 L3 진입을 가능하게 하는 구조임 |

```text
+-------------+     +----------------+     +----------------+     +----------------+
| Leaf VTEP     | --> | MP-BGP EVPN      | --> | Route Reflector | --> | 원격 Leaf VTEP |
+-------------+     +----------------+     +----------------+     +----------------+
          \_____________________ VXLAN 데이터 평면 _____________________/
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +----------------+     +------------------+     +----------------+
| 단말 접속·학습  | --> | EVPN 경로 광고      | --> | 원격 VTEP 테이블 반영 | --> | VXLAN 데이터 전달  |
+-------------+     +----------------+     +------------------+     +----------------+
```

1. **단말 접속과 학습**: 리프 VTEP가 로컬 단말의 MAC과 IP 정보를 학습함
2. **EVPN 경로 광고**: 학습한 정보를 MP-BGP EVPN 경로로 Route Reflector와 다른 VTEP에 광고함
3. **원격 VTEP 테이블 반영**: 원격 리프가 해당 단말 위치를 미리 테이블에 반영함
4. **VXLAN 데이터 전달**: 실제 트래픽이 발생하면 플러딩 대신 학습된 목적지 VTEP로 바로 전달함

## Ⅵ. 실무 적용 및 유의점

1. 멀티테넌트 데이터센터와 프라이빗 클라우드에서는 EVPN이 VXLAN 확장성 문제를 줄여주지만 Route Reflector와 정책 설계가 잘못되면 잘못된 단말 위치가 넓게 퍼지므로 RT, RD, 정책 필터를 명확히 하고 MAC 이동 이벤트 수와 EVPN 경로 반영 시간을 기준으로 확인함
2. Anycast Gateway와 ARP 억제를 함께 쓰는 환경에서는 브로드캐스트는 줄지만 게이트웨이 일관성 문제가 중요해지므로 리프 간 정책 동기화를 자동화하고 ARP 억제 적중률과 게이트웨이 장애 복구 시간을 확인함

## Ⅶ. 결론

BGP EVPN의 본질은 VXLAN 오버레이에 제어 평면을 더해 브로드캐스트 의존을 줄이는 데 있으므로 대규모 가상망일수록 제어 평면 설계가 핵심임.
