## 미리 알고가기

- BB84는 서로 다른 편광 기저로 광자를 송수신해 비밀키 후보를 만드는 QKD 프로토콜임
- QBER는 송수신 비트가 다르게 측정된 비율로 도청과 잡음 판정에 사용됨
- 프라이버시 증폭은 공격자가 알 수 있는 정보를 줄이도록 키 길이를 압축하는 절차임
- QKD는 데이터를 암호화하지 않고 암호 장비가 사용할 대칭키를 분배함

## Ⅰ. 개요

- **정의/개념**: QKD는 양자 상태의 측정 교란과 복제 불가 원리를 이용해 송수신자가 비밀키를 생성하고 도청 가능성을 QBER로 판정하는 키 분배 기술임
- **배경/필요성**: 공개키 기반 키 교환은 계산 복잡도에 의존하므로 물리 법칙에 기반한 키 분배와 장기 기밀 데이터 보호 수단이 필요함

## Ⅱ. 특징

- 공격자가 광자를 측정하면 양자 상태가 변해 수신 오류율이 증가함
- 양자 채널과 별도로 인증된 고전 채널이 필요함
- 광손실과 검출기 잡음이 커지면 비밀키 생성률이 감소함
- 종단 장비 취약점과 고전 채널 인증 문제는 QKD만으로 해결되지 않음

## Ⅲ. 종류 및 비교

| 판단 기준 | QKD | PQC |
|:---|:---|:---|
| 보안 근거 | 양자 측정 교란과 복제 불가 원리 | 양자 공격에 견디는 수학적 난제 |
| 구축 방식 | 광자 송수신 장비와 양자 채널 필요 | 소프트웨어·펌웨어 알고리즘 교체 중심 |
| 거리 영향 | 광손실과 중계 방식에 제약받음 | 기존 IP 네트워크에서 사용함 |
| 적용 환경 | 고가치 전용 구간의 키 공급 | 인터넷·단말·서비스의 광범위한 암호 전환 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 역할 |
|:---|:---|
| 양자 송신기 | 임의 비트와 기저로 광자를 생성함 |
| 양자 수신기 | 임의 기저로 광자를 측정함 |
| 양자 채널 | 광자를 전달함 |
| 인증된 고전 채널 | 기저 비교와 후처리 정보를 교환함 |
| 키 관리 시스템 | 최종 키를 암호 장비에 공급함 |

```text
[송신기] -- 광자·양자 채널 --> [수신기]
    \______ 기저 비교·인증·후처리 ______/
```

## Ⅴ. 원리 및 절차

1. **광자 전송**: 송신자가 임의 비트와 기저로 광자를 생성함
2. **광자 측정**: 수신자가 임의 기저를 선택해 광자를 측정함
3. **기저 선별**: 고전 채널에서 기저가 일치한 비트만 남김
4. **오류 판정**: 표본 비트의 QBER가 임계값을 넘으면 키를 폐기함
5. **키 확정**: 오류 정정과 프라이버시 증폭을 거쳐 최종 키를 생성함

## Ⅵ. 실무 적용 및 유의점

1. 데이터센터 간 전용 광섬유에 QKD를 적용할 때는 거리와 커넥터 손실이 키 생성률을 제한하므로 QBER, 광손실, 초당 비밀키 생성량을 함께 확인해야 함
2. QKD 장비만 도입해도 종단 보안이 보장되는 것은 아니므로 고전 채널 인증, 키 저장소, 암호 장비 접근 통제를 적용하고 키 사용 이력과 인증 실패를 점검해야 함

## Ⅶ. 결론

QKD는 양자 상태의 오류율로 도청 가능성을 판정해 대칭키를 분배하며, 광손실·인증 채널·종단 장비 보안을 함께 설계해야 함.
