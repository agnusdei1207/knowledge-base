## 미리 알고가기

- AS: 하나의 관리 주체가 운영하는 라우팅 도메인임
- eBGP: 서로 다른 AS 사이에서 경로 정보를 교환하는 BGP 관계임
- iBGP: 같은 AS 내부에서 BGP 경로를 전달하는 관계임
- AS_PATH: 목적지까지 거친 AS 번호 목록이며 루프 방지와 경로 판단에 쓰임
- LOCAL_PREF: 한 AS 안에서 외부로 나가는 경로 선호도를 정하는 속성임

## Ⅰ. 개요

- **정의/개념**: BGP는 자율 시스템 사이에서 IP 프리픽스와 경로 속성을 교환하고 정책에 따라 인터넷 경로를 선택하는 Path Vector 라우팅 프로토콜임
- **배경/필요성**: 인터넷은 여러 사업자와 조직의 AS가 연결된 구조이므로 최단 거리보다 계약, 정책, 트래픽 방향을 반영하는 경로 제어가 필요함

## Ⅱ. 특징

- BGP는 TCP 세션 위에서 동작하며 인접 라우터와 경로 업데이트를 교환함
- AS_PATH를 사용해 경로가 자기 AS로 되돌아오는 루프를 차단함
- LOCAL_PREF, AS_PATH, MED 같은 속성으로 경로 선호를 단계적으로 판단함
- 수렴이 느릴 수 있으므로 Route Flap을 줄이도록 경로 변경을 신중하게 전파함

## Ⅲ. 종류 및 비교

| 판단 기준 | eBGP | iBGP |
|:---|:---|:---|
| 연결 범위 | 서로 다른 AS 사이의 경로 교환에 쓰임 | 같은 AS 내부의 BGP 경로 전달에 쓰임 |
| AS_PATH 처리 | 다른 AS로 나갈 때 자기 AS를 경로에 추가함 | 같은 AS 내부 전달이므로 AS_PATH를 추가하지 않음 |
| 기본 TTL | 보통 직접 연결 이웃을 전제로 함 | 내부 라우팅으로 도달 가능한 이웃을 전제로 함 |
| 운영 쟁점 | 피어링 정책과 필터링이 경로 유출을 막는 기준이 됨 | 풀 메시나 Route Reflector 설계가 필요함 |

> 요약: eBGP는 AS 간 정책 교환이고, iBGP는 AS 내부에서 그 경로를 일관되게 배포하는 구조임

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Prefix | 광고하거나 수신하는 목적지 IP 주소 범위임 |
| AS_PATH | 경로가 거친 AS 목록이며 루프 방지와 경로 길이 판단에 쓰임 |
| NEXT_HOP | 해당 프리픽스로 가기 위해 다음으로 전달할 라우터 주소임 |
| LOCAL_PREF | 내부에서 어느 외부 출구를 선호할지 정하는 속성임 |
| Route Policy | 수신, 광고, 우선순위를 제어하는 필터와 속성 조정 규칙임 |

```text
+------+ eBGP +------+ iBGP +------+
| AS10 | <--> | AS20 | <--> | AS20 |
+------+      +------+      +------+
       prefix + attributes
```

> 요약: BGP는 프리픽스만 전달하지 않고 경로 속성과 정책을 함께 전달해 AS 단위 경로를 제어함

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 세션수립  | --> | 경로수신  | --> | 정책적용  | --> | 경로광고 |
+----------+     +----------+     +----------+     +----------+
```

1. **세션수립**: BGP 라우터가 TCP 기반 이웃 관계를 맺음
2. **경로수신**: 피어로부터 프리픽스와 경로 속성을 수신함
3. **정책적용**: 필터, LOCAL_PREF, AS_PATH, MED 등으로 최적 경로를 선택함
4. **경로광고**: 선택된 경로를 정책에 맞게 다른 피어에게 광고함

## Ⅵ. 실무 적용 및 유의점

1. 멀티홈 인터넷 연결에서는 LOCAL_PREF와 AS_PATH Prepend로 송수신 경로를 조정하되 의도하지 않은 우회가 생기지 않도록 BGP 테이블, 트래픽 비율, 피어별 광고 프리픽스를 확인함
2. 경로 유출은 인터넷 전체 장애로 번질 수 있으므로 Prefix Filter, RPKI ROA 검증, 최대 프리픽스 제한을 적용하고 Invalid 경로 차단 로그와 피어 세션 상태로 확인함

## Ⅶ. 결론

BGP의 판단 기준은 최단 경로가 아니라 AS 경로, 속성, 필터 정책으로 인터넷 경로를 통제하는 절차임.

## 작성 근거(검토용)

- BGP 답안에서 "빠른 길"이나 "최상위 프로토콜" 같은 표현은 모호하므로 Path Vector와 정책 속성 중심으로 바꿈
- 경로 속성은 나열이 아니라 경로 선호와 루프 방지에 쓰이는 근거이므로 구성요소와 절차에 연결함
- 결론은 정책 기반 경로 제어라는 BGP의 문맥 단어를 회수함
