## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 5G 물리망을 논리적으로 분할한 각 슬라이스 인스턴스에 특화된 독립적 보안 정책 제공 기술임 |
| 배경 | 자율주행, 스마트 팩토리 등 서비스 특성별로 서로 다른 보안 수준 요구와 간섭 배제 필요 |
| 출제 | 슬라이스 논리적 격리, 1/2차 상호 인증, 하이퍼바이저 취약점 방어 |

## Ⅱ. 구성요소
```text
+--------------+        +--------------+        +--------------+
| Slice Isolat | -----> | Auth & Crypto| -----> | MEC Security |
| (Hypervisor) | Bound  | (5G Core)    | Data   | (Edge Node)  |
+--------------+        +--------------+        +--------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 슬라이스 격리 | 자원을 가상화로 분할하여 상호 데이터 및 트래픽 침범을 원천 차단함 | 방음벽 파티션 |
| 인증 및 암호화 | 5G 코어(AUSF)를 통해 슬라이스 접속 단말에 대한 특화 상호 인증 수행함 | 출입구 신분 검사 |
| 엣지/MEC 보안 | 슬라이스 데이터 처리를 담당하는 분산 엣지 서버 로컬 보안 위협 방어함 | 로컬 금고 |

> 요약: 망 분할 격리, 접속 단말 정밀 인증, 로컬 엣지 보안 체계를 통합 제공함.

## Ⅲ. 절차
```text
+-----------+    +-----------+    +-----------+    +-----------+
| 1. Request| -> | 2. Authen | -> | 3. Policy | -> | 4. Monitor|
+-----------+    +-----------+    +-----------+    +-----------+
```
1. 접속 요청: 단말이 목적에 맞는 특정 네트워크 슬라이스(NSSAI) 아이디로 접속 요청함.
2. 상호 인증: 5G 코어망(SEAF)에서 단말-네트워크 간 EAP 기반 강화 인증 수행함.
3. 정책 할당: 인증 성공 시 방화벽, QoS 등 해당 슬라이스 전용 보안 인스턴스 논리 할당함.
4. 격리 감시: 운영 중 타 슬라이스로의 트래픽 침범 및 자원 고갈(DDoS) 공격 실시간 감시함.

> 요약: 특화 접속 요청을 상호 인증 후 전용 보안 정책을 할당하고 격리 상태 감시함.

## Ⅳ. 문제점
- 자원 공유 리스크: NFV 하이퍼바이저 가상화 취약점 발생 시 타 슬라이스로 악성코드 전이 가능함.
- 관리 복잡도: 수많은 맞춤형 동적 슬라이스 인스턴스의 보안 라이프사이클 정책 통합 관리 어려움.
- E2E 보장 한계: RAN, 전송망, 코어 등 전 구간(E2E)의 일관된 고수준 암호화 및 격리 유지 까다로움.

## Ⅴ. 개선방안
- 컨테이너 격리 (단기): 보안이 크리티컬한 슬라이스 코어망을 물리적으로 완전 분리된 클러스터 배포함.
- 오케스트레이터 (중기): SDN 통합 관리 플랫폼 기반으로 슬라이스별 보안 정책 템플릿 배포 자동화함.
- 양자 암호 (장기): 전송 구간에 양자 키 분배(QKD) 통신망 연동하여 원천적인 해킹 불가 체계 확립함.

## Ⅵ. 전망
- 슬라이싱 보안은 B2B 5G 특화 서비스 확산의 필수 요건이며, 향후 제로 트러스트 내재화 구조로 발전함.
