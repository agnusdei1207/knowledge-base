## Ⅰ. 개요
- **정의**: 단말이 여러 서브넷(기지국)을 이동할 때도 IP 변경 없이 세션을 무중단 유지하도록 돕는 네트워크 계층 라우팅 기술임.
- **배경 및 필요성**: 전통 IP망 구조에서 단말 이동 시 접속 서브넷 변화로 인한 TCP 세션 끊김 문제 해결 필요성.
- **출제 의도**: 네트워크 이동성 극복을 위한 터널링(HA-FA) 아키텍처 및 끊김없는 핸드오버(Handover) 메커니즘 이해 평가

## Ⅱ. 구성요소

```text
+-------------------------+
|  Component Architecture |
+-------------------------+
| [ Node A ] <-> [ Node B]|
+-------------------------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| **홈 에이전트(HA)** | 단말의 원래 소속망에 위치하며, 단말의 현재 임시 위치를 추적 관리하는 전담 라우터 | 고향 집의 우편물 수령 및 재송달 대행인 |
| **외부 에이전트(FA)** | 이동한 방문망에서 단말에 임시 주소(COA)를 발급하고 HA와의 터널링을 중계함 | 출장지 호텔의 우편물 수령 담당 데스크 |
| **핸드오버 (Handover)** | 이동 중 접속 지점이 바뀌는 찰나에 통신 지연/단절을 막고 연결 고리를 연속적으로 넘겨줌 | 전속력으로 달리는 릴레이 바통 매끄럽게 전달 |

> 요약: 모바일 IP는 에이전트 간 캡슐화 터널링으로 논리적 IP 이동성을 보장하고, 핸드오버로 물리적 연속성을 확보함.

## Ⅲ. 절차

```text
+-------+   +-------+   +-------+   +-------+
| Step1 |-->| Step2 |-->| Step3 |-->| Step4 |
+-------+   +-------+   +-------+   +-------+
```

1. **임시 위치 파악**: 모바일 노드가 방문망에 진입하면 FA가 COA(임시 IP)를 할당함.
2. **바인딩 등록**: 모바일 노드가 자신의 고정 홈 IP와 새로운 COA 매핑 정보를 HA에 등록 요청함.
3. **터널링 데이터 송달**: 외부 호스트가 보낸 패킷을 HA가 가로챈 후 COA 주소로 다시 캡슐화하여 터널링 전송함.
4. **수신 및 통신 유지**: FA(또는 단말)가 터널링 헤더를 제거해 원본 데이터를 받고 상위 세션을 유지함.

> 요약: 바뀐 임시 주소를 본가에 등록하면 본가에 도착한 패킷을 터널로 재배송받아 세션을 지속 유지함.

## Ⅳ. 문제점
- 삼각 라우팅 비효율 발생 (원인: 송신자와 단말이 근거리에 있어도 반드시 거리가 먼 HA를 경유해 지연 초래)
- FA 간 이동에 따른 패킷 손실(블랙홀) 현상 (원인: 새로운 COA를 획득하고 HA에 재등록하는 빈 시간 동안 데이터 유실 발생)
- 이중 IP 헤더 캡슐화 오버헤드 (원인: IP over IP 터널 구조로 인해 데이터 페이로드 비율 저하 및 추가 처리 비용 발생)

## Ⅴ. 개선방안
- **단기 방안**: [단기] 경로 최적화 (Route Optimization) 정책 적용 (송신자에게 단말의 COA를 직접 알려 HA 경유 없이 다이렉트 통신 지원)
- **중기 방안**: [중기] 마이크로 이동성 제어망(HMIPv6) 및 패스트 핸드오버 도입 (이동 예측 라우터 계층화로 로컬 앵커 포인트 간 빠른 세션 교체 구현)
- **장기 방안**: [장기] 셀룰러 코어 GTP 프로토콜 전면 통합 (4G/5G 코어 인프라 기반 터널링 앵커(UPF)를 채택해 IP 레벨 이동성 로직 완벽 내재화)

## Ⅵ. 전망
- IETF 표준인 모바일 IP 자체의 확산은 저조했으나, 해당 터널링 개념은 이동통신 코어망(EPC/5GC)의 핵심 근간으로 자리잡음.
