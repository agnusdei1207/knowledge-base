## 미리 알고가기

- 큐비트는 중첩과 얽힘을 이용해 양자 정보를 표현하는 단위임
- 양자 채널은 광자나 얽힘 상태를 전달하고 고전 채널은 기저 비교와 제어 정보를 전달함
- 양자 중계기는 얽힘 교환과 정제를 통해 양자 상태의 전달 거리를 확장하는 장치임
- QKD는 양자 상태의 측정 교란을 이용해 키 교환 과정의 도청 가능성을 확인하는 기술임

## Ⅰ. 개요

- **정의/개념**: 양자 통신 네트워크는 양자 채널과 고전 채널을 연계해 양자 키, 얽힘 상태, 양자 정보를 노드 사이에 전달하는 네트워크임
- **배경/필요성**: QKD 링크의 거리 제한을 넘어 다수 노드를 연결하고 양자컴퓨터·센서 간 상태를 공유하려면 얽힘 생성과 중계와 제어를 포함한 네트워크 구조가 필요함

## Ⅱ. 특징

- 양자 상태를 측정하면 상태가 변하므로 전송 중 도청 가능성을 오류율로 확인할 수 있음
- 양자 채널의 광손실과 검출기 잡음이 전달 거리와 키 생성률을 제한함
- 고전 채널은 기저 비교, 오류 정정, 프라이버시 증폭, 노드 제어에 사용됨
- Trusted Node 방식은 상용화가 가능하지만 중계 노드의 물리 보안을 전제로 함

## Ⅲ. 종류 및 비교

| 판단 기준 | Trusted Node 네트워크 | 양자 중계기 네트워크 |
|:---|:---|:---|
| 중계 방식 | 구간별 키를 복호화·재분배함 | 얽힘 교환으로 종단 상태를 연결함 |
| 신뢰 조건 | 모든 중계 노드를 신뢰해야 함 | 중계 노드의 키 평문 접근을 제거함 |
| 기술 성숙도 | QKD 상용망에 적용됨 | 양자 메모리와 정제 기술이 연구 단계임 |
| 적용 범위 | 금융·국방 전용 구간 | 장거리 양자 인터넷과 분산 양자 연산 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 역할 |
|:---|:---|
| 양자 송수신기 | 광자와 얽힘 상태를 생성·측정함 |
| 양자 채널 | 광섬유나 자유공간으로 양자 상태를 전달함 |
| 고전 채널 | 기저 비교, 인증, 오류 정정 정보를 교환함 |
| Trusted Node·양자 중계기 | 구간 키 중계 또는 얽힘 교환을 수행함 |
| 키 관리 시스템 | 생성된 키를 저장하고 암호 장비에 공급함 |

```text
[양자 노드] -- 양자 채널 -- [중계 노드] -- 양자 채널 -- [양자 노드]
     \____________ 인증·제어용 고전 채널 ____________/
```

## Ⅴ. 원리 및 절차

1. **링크 설정**: 노드 사이 양자 채널과 인증된 고전 채널을 구성함
2. **상태 생성**: 광자 또는 얽힘 쌍을 생성해 양자 채널로 전달함
3. **측정·비교**: 수신 결과와 기저 정보를 고전 채널에서 비교함
4. **오류 검증**: QBER와 링크 손실을 기준으로 상태 사용 여부를 판정함
5. **키·상태 제공**: 검증된 키나 얽힘 상태를 암호·양자 응용에 제공함

## Ⅵ. 실무 적용 및 유의점

1. 금융 데이터센터 간 QKD 키를 IPsec 장비에 공급할 때는 키 생성률이 세션 키 소비량을 충족하는지 확인하고 QBER, 광손실, 키 고갈 횟수를 점검해야 함
2. 장거리 구간에서 Trusted Node를 사용하면 노드 침해로 구간 키가 노출될 수 있으므로 물리 접근 통제와 HSM을 적용하고 노드별 키 접근 기록과 장비 변조 경보를 확인해야 함

## Ⅶ. 결론

양자 통신 네트워크는 양자 채널과 고전 제어 채널을 결합하며, 거리·손실·중계 노드 신뢰 조건에 따라 QKD망과 양자 중계 구조를 선택해야 함.
