# 📖 【암기용】 개념 완전 이해

> 목적: 양자 통신 네트워크를 처음 보는 사람도 양자 키 분배와 양자 인터넷의 차이를 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 설명이다.

## 한눈에
- **개요**: 양자 상태를 이용해 키 분배, 얽힘 전달, 양자 정보 교환을 수행하는 네트워크이다.
- **왜 필요한가**: 양자컴퓨팅 발전은 기존 공개키 암호의 장기 안전성을 위협하므로 키 교환과 보안 통신 방식의 전환이 필요하다.
- **핵심 직관**: 양자 상태는 몰래 측정하면 흔적이 남기 때문에, 키 교환 과정에서 도청 가능성을 탐지할 수 있다.

## 깊이 이해
- **배경·문제의식**: 현재 인터넷 암호는 RSA, ECC 같은 수학적 난제에 의존한다. 양자 통신은 광자 편광, 얽힘, 측정 교란 원리를 이용해 키 분배 또는 양자 상태 전송을 다룬다.
- **작동 원리**: QKD 링크는 송신자와 수신자가 양자 채널로 광자를 주고받고, 별도 고전 채널에서 기저 비교와 오류율 계산을 수행한다. 더 넓은 양자 네트워크는 trusted node, quantum repeater, entanglement swapping 같은 구성이 필요하다.
- **비유**: 봉투를 열면 봉인 흔적이 남는 편지를 보내고, 받는 사람이 봉인 훼손률을 계산해 그 편지를 키 재료로 쓸지 판단하는 방식과 같다.
- **구체 예시**: 금융 데이터센터 사이 전용 광섬유에 QKD 장비를 설치하고, 생성된 키를 IPsec 장비에 공급해 세션 키를 주기적으로 갱신한다.
- **흔한 오해·주의점**: 양자 통신이 모든 네트워크 암호를 대체한다고 단정하면 안 된다. 거리, 광손실, 장비 비용, 인증 채널, trusted node 보안이 적용 범위를 제한한다.

## 연결 개념
- QKD — 양자 상태로 비밀키를 분배하는 대표 기술
- PQC — 양자컴퓨터 공격을 고려한 수학 기반 암호 전환
- Quantum Repeater — 장거리 양자 상태 전달을 위한 중계 기술

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. quantum channel, classical channel, trusted node, repeater, ETSI QKD를 중심으로 작성한다.
> 핵심: 출제자는 양자 원리보다 네트워크 구성, 적용 한계, PQC와의 역할 분담을 묻는다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 양자 통신 네트워크는 광자·얽힘 등 양자 상태를 이용해 키 분배와 양자 정보 전달을 수행하는 네트워크이다.
> 2. **가치**: 도청 시 양자 상태가 교란되는 성질을 이용해 키 교환 단계의 도청 가능성을 탐지한다.
> 3. **판단 포인트**: 광손실, 거리, trusted node 신뢰, 인증 채널, PQC 병행 여부를 함께 판단해야 한다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 양자 통신 구성 이해 확인 | quantum channel, classical channel, key management | 양자 통신을 단순 암호 알고리즘으로 설명 |
| 장거리 네트워크 한계 확인 | 광손실, trusted node, quantum repeater | 무제한 거리 통신으로 단정 |
| 보안 전환 전략 판단 확인 | QKD와 PQC 역할 분담 | QKD만으로 인증·암호 전 과정을 해결한다고 서술 |

> 요약: 이 문제는 양자 통신의 물리 원리보다 네트워크 설계 조건과 적용 한계를 묻는다.

## Ⅰ. 개요 및 필요성

- 개요: 양자 상태로 키와 정보를 전달함.
- 배경: 양자컴퓨팅 발전은 RSA·ECC 기반 공개키 교환의 장기 안전성에 영향을 줌.
- 필요성: 금융, 국방, 기간망은 장기 기밀 데이터의 키 교환 위험을 낮추기 위해 QKD·PQC 전환 검토가 필요함.
- 판단 기준: 거리, 광손실, trusted node, 인증 채널, ETSI QKD 인터페이스 적용 여부를 확인함.

---

## Ⅱ. 구조 및 구성요소

```text
Alice QKD Device -> Quantum Channel -> Bob QKD Device
Alice QKD Device -> Classical Channel -> Bob QKD Device
QKD Key Manager -> Encryptor / IPsec / OTN -> Protected Traffic
Trusted Node / Repeater -> Long Distance Extension
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 양자 채널 | 광자 상태를 전달 | 광섬유 또는 자유공간 링크 |
| 고전 채널 | 기저 비교, 오류율 계산, 인증 수행 | 별도 인증 필요 |
| 키 관리자 | 생성 키를 암호 장비에 공급 | ETSI QKD 인터페이스 검토 |
| Trusted Node | 구간별 키를 중계 | 노드 물리 보안 필요 |
| Quantum Repeater | 얽힘 기반 장거리 확장 후보 | 상용 성숙도 제한 |

> 요약: 양자 통신 네트워크는 양자 채널과 고전 채널을 함께 쓰며, 실제 암호 트래픽은 키 관리 시스템과 암호 장비가 처리한다.

---

## Ⅲ. 동작원리 및 흐름도

```text
광자 상태 송신 -> 수신 측 측정 -> 고전 채널 기저 비교
-> QBER 계산 -> 오류 정정 / 프라이버시 증폭 -> 키 공급 -> 암호 장비 적용
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 송신자가 양자 상태를 전송 | 광손실, 검출률 |
| 2 | 수신자가 기저를 선택해 측정 | 검출 오류, detector noise |
| 3 | 고전 채널에서 기저와 일부 비트 비교 | 인증, replay 방지 |
| 4 | QBER 기준으로 도청 가능성 판단 | QBER 임계값 |
| 5 | 최종 키를 암호 장비에 공급 | key rate, key freshness |

> 요약: 양자 통신은 양자 채널로 키 재료를 만들고 고전 채널로 검증한 뒤 암호 장비에 키를 공급한다.

## Ⅳ. 특징

| 구분 | 기존 키 교환 | 양자 통신 네트워크 | 수치·표준 포인트 |
|:---|:---|:---|:---|
| 보안 근거 | 수학적 난제 | 측정 교란, no-cloning 원리 | QBER, key rate |
| 구성 | 공개키 프로토콜 | 양자 채널 + 고전 채널 | ETSI QKD 인터페이스 |
| 장거리 | 인터넷 전 구간 가능 | 광손실과 중계 구성 영향 | trusted node, repeater |
| 한계 | 양자 공격 고려 필요 | 장비 비용·거리·인증 채널 필요 | km, dB loss |

> 요약: 양자 통신은 키 분배의 도청 탐지에 강점이 있지만, 인증과 장거리 확장은 별도 설계가 필요하다.

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존/대안 | 양자 통신 네트워크 | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | TLS, IPsec, PKI | QKD 링크 + 키 관리자 + 암호 장비 | 전용 광섬유, 고가치 장기 기밀 |
| 비용/성능 | 기존 인프라 활용 | 전용 장비·광링크 비용 발생 | key rate가 암호 장비 요구량 충족 시 |
| 운영/위험 | 공개키 취약 전환 필요 | 노드 물리보안과 링크 품질 의존 | trusted node 보호 가능 여부 |

> 요약: 양자 통신은 전용망과 장기 기밀 보호 요구가 클 때 검토하고, 범용 인터넷은 PQC와 병행해야 한다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 키 생성 부족 | 광손실·거리 증가 | 링크 예산 설계, 중계 노드 배치 | key rate, QBER |
| 노드 탈취 | trusted node에 평문 키 존재 | 물리 보안, HSM, 접근통제 | 감사로그, 출입기록 |
| 상호운용 문제 | 벤더별 인터페이스 차이 | ETSI QKD API 검증 | 연동 테스트 성공률 |

> 요약: 양자 통신 리스크는 링크 품질, 노드 신뢰, 상호운용성을 지표로 통제한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 링크 품질 | QBER 임계값 이하 | QKD 장비 통계 |
| 키 공급 | 암호 장비 요구 key rate 충족 | 키 관리자 로그 |
| 운영 보안 | trusted node 접근 위반 0건 | 출입·계정 감사 |

> 요약: 도입 판단은 QBER, key rate, trusted node 감사 지표가 동시에 충족되는지로 결정한다.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수):**
1. 금융·국방 전용 회선에 QKD 링크를 PoC로 구성하고 QBER, key rate, 장애 복구 시간을 측정함.
2. 키 관리자는 IPsec, MACsec, OTN 암호 장비와 연동하고 키 소진 시 기존 키 교환으로 전환하는 정책을 둠.
3. QKD 적용 구간 외 인터넷 서비스는 NIST PQC 알고리즘 전환 계획과 병행함.

**결론 (2줄):**
- 기술사 판단: 전용 광링크와 장기 기밀 요구가 있으면 QKD를 검토하고, 범용 서비스는 PQC 전환과 하이브리드 키 교환을 우선 적용함.
- 향후 방향: 양자 통신 네트워크는 QKD 중심에서 trusted node, repeater, 양자 인터넷 연구로 확장됨.
