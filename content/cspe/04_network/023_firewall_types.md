# 📖 【암기용】 개념 완전 이해

## 한눈에
- **개요**: 네트워크 길목을 지키며 미리 정해진 보안 규칙에 따라 나쁜 트래픽은 막고 착한 트래픽만 통과시키는 **출입 통제 장치**입니다.
- **필요성**: 외부 해커의 침입을 막고 내부 사용자가 위험한 사이트에 접속하는 것을 차단하기 위한 가장 기본적인 네트워크 보안 인프라입니다.
- **핵심 직관**: **"성문의 파수꾼"**. 성문 앞에서 출입 명단을 확인하고 허가된 사람만 들여보내는 역할입니다.

## 깊이 이해
- **방화벽의 진화 (세대별 구분)**:
  - **1세대 (Packet Filtering)**: 패킷의 헤더(IP, Port)만 봅니다. "80번 포트네? 통과!" (속도는 빠르지만 속이기 쉬움)
  - **2세대 (Stateful Inspection)**: 패킷의 상태(연결 문맥)를 봅니다. "어? 너 아까 나간 요청에 대한 답변 맞지? 통과!" (현재 대부분의 기본 기능)
  - **3세대 (Application Firewall / NGFW)**: 패킷의 내용(애플리케이션 종류)을 직접 봅니다. "포트는 80번인데, 내용은 게임 트래픽이네? 차단!" (매우 정교함)
- **차세대 방화벽 (NGFW: Next Generation Firewall)**:
  - 단순히 차단만 하는 게 아니라 **IPS(침입 차단)**, **DPI(심층 분석)**, **사용자 인증** 기능을 하나로 합친 만능 보안 장비입니다.
- **비유 (아파트 경비실)**:
  - **1세대**: 배달 기사가 "101호 배달이요" 하면 그냥 들여보냄.
  - **2세대**: "101호에서 피자 시켰나요?" 확인하고 들여보냄.
  - **3세대**: 피자 상자를 열어서 진짜 피자가 맞는지, 위험물은 없는지 확인하고 들여보냄.

## 연결 개념
- **DMZ (Demilitarized Zone)**: 외부와 내부 사이의 완충 구역. 웹 서버처럼 외부에서 접근해야 하는 서버들을 두는 곳.
- **IPS (Intrusion Prevention System)**: 방화벽이 문지기라면, IPS는 성 안을 돌아다니며 칼 든 괴한을 찾아내는 순찰대.

# 📝 【답안용】 시험 답안 템플릿

## 핵심 인사이트 (3줄 요약)
> 1. **본질**: 네트워크 경계에서 사전에 정의된 보안 정책(Rule-set)에 따라 트래픽의 허용(Allow) 및 차단(Deny)을 결정하는 접근 통제 보안 시스템임.
> 2. **가치**: 외부 비인가 접근을 원천 차단하고, 내부 자산 보호 및 정보 유출 방지를 위한 네트워크 보안의 1차 방어선 역할을 수행함.
> 3. **판단 포인트**: 단순 IP/Port 차단을 넘어 애플리케이션 식별(App-ID) 및 사용자 기반 정책(User-ID) 적용이 가능한 차세대 방화벽(NGFW)으로 진화함.

## Ⅰ. 방화벽의 세대별 기술 진화 과정

| 구분 | 1세대 (Packet Filter) | 2세대 (Stateful Inspection) | 3세대 (NGFW / Application) |
|:---:|:---|:---|:---|
| **검사 계층** | Network / Transport (L3/L4) | Transport (L4) + Context | Application (L7) |
| **판단 기준** | IP 주소, 포트 번호 (ACL) | 세션 상태 테이블 (State Table) | 애플리케이션 식별, 사용자 이름 |
| **특징** | 속도가 빠르나 보안성 낮음 | 현재의 표준 방식 (문맥 분석) | 심층 패킷 분석 (DPI), IPS 통합 |
| **한계** | 상태 정보가 없어 우회 가능 | 애플리케이션 내 악성코드 무방비 | 분석 부하로 인한 성능 저하 |

## Ⅱ. 차세대 방화벽 (NGFW)의 5대 핵심 기능

### 1. App-ID (애플리케이션 식별)
- 포트 번호와 상관없이 실제 어떤 서비스(Facebook, YouTube, BitTorrent 등)인지 구분하여 정밀 통제.
### 2. User-ID (사용자 식별)
- IP 주소가 아닌 AD(Active Directory) 연동 등을 통해 사용자 계정별로 권한 부여.
### 3. Content-ID (심층 패킷 분석)
- DPI 기술을 사용하여 데이터 안의 악성코드, 취약점 공격 패턴, 기밀 정보 유출 여부 검사.
### 4. SSL Inspection (복호화)
- 암호화된 HTTPS 트래픽을 복호화하여 그 안에 숨겨진 공격을 탐지.
### 5. 통합 위협 방어 (IPS/Sandboxing 연동)
- 침입 방지 시스템(IPS) 및 가상 실행 환경(Sandbox)과 연동하여 알려지지 않은 위협(Zero-day) 대응.

## Ⅲ. 방화벽 구축 형태 및 구성도

### 1. 배션 호스트 (Bastion Host)
- 외부 인터넷과 내부 네트워크 사이에 위치하여 외부의 공격으로부터 내부를 보호하는 가장 견고한 서버.
### 2. 스크리닝 라우터 (Screening Router)
- 라우터의 ACL 기능을 이용하여 기본적인 IP/Port 필터링 수행.
### 3. 스크린드 서브넷 (Screened Subnet) - DMZ 구성
- **[인터넷] - [외부 방화벽] - [DMZ] - [내부 방화벽] - [내부망]** 구조로 보안 계층을 다중화.

## Ⅳ. 방화벽 설계 시 고려사항 (Best Practice)

### 1. 최소 권한 원칙 (Least Privilege)
- 모든 접근은 거부(Deny All)를 기본으로 하고, 필요한 서비스만 명시적으로 허용(Allow).
### 2. 보안 정책 최적화
- 자주 사용하는 룰을 상단에 배치하여 검사 속도 향상 및 미사용 룰의 주기적 정리.
### 3. 가용성 확보
- 방화벽 장애 시 전체 네트워크 마비를 막기 위해 이중화(Active-Standby 또는 Active-Active) 필수.

## Ⅴ. 방화벽 vs WAF vs IPS 비교

| 항목 | 방화벽 (Firewall) | 웹 방화벽 (WAF) | IPS |
|:---:|:---|:---|:---|
| **주요 목적** | 비인가 접근 차단 | 웹 공격 (SQLi, XSS) 방어 | 침입 시도 차단 |
| **대상 계층** | L3, L4 중심 | **L7 (HTTP/HTTPS)** | L3 ~ L7 |
| **핵심 기법** | ACL, 세션 관리 | HTTP 프로토콜 정밀 검사 | 시그니처 기반 패턴 매칭 |

## Ⅵ. 기술사적 통찰: '경계'의 붕괴와 제로 트러스트
- **경계 보안의 한계**: 클라우드와 원격 근무의 확산으로 '안전한 내부망'이라는 개념이 사라짐. 이제 방화벽은 고정된 장소가 아닌 클라우드 엣지(SASE)로 이동하고 있음.
- **Micro-segmentation**: 큰 성문을 지키는 방식에서, 서버 하나하나를 방화벽으로 감싸는 세밀한 격리 정책으로 발전 중임.
- **결론**: 방화벽은 네트워크 보안의 역사를 함께한 핵심 요소이며, 이제는 인공지능(AI)과 결합하여 실시간으로 위협을 판단하고 대응하는 **"지능형 보안 컨트롤러"**로 진화하고 있음.
