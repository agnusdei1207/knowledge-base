## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | AS 간 트래픽 라우팅을 위해 다양한 정책 속성(Attribute)을 기준으로 최적 경로를 결정하는 프로토콜 |
| **배경/필요성** | 거리나 홉 수 등 단순 메트릭을 넘어 경제성, 보안, 계약 정책을 반영한 트래픽 엔지니어링 필요 |
| **출제 의도** | Local Pref, AS-Path, MED 등 BGP 속성 기반의 우선순위 경로 결정 로직 이해 평가 |

## Ⅱ. 구성요소
```text
+----------+       +----------+       +----------+
|   AS 1   |       |   AS 2   |       |   AS 3   |
| (Local)  | <---> | (Transit)| <---> | (Remote) |
+----------+       +----------+       +----------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| Local Pref | 내부 AS에서 외부 목적지로 나가는 출구(Outbound) 우선순위를 결정 | 출구 선호도 |
| AS-Path | 목적지 도달을 위해 거쳐온 AS 번호 목록으로 라우팅 루프 방지 역할 | 여권 도장 |
| MED | 외부 AS가 내부로 들어오는 진입(Inbound) 경로의 우선순위를 권고 | 입구 안내판 |

> 요약: 풍부한 경로 속성을 통해 단순 도달성을 넘어 자율적인 글로벌 라우팅 정책을 구현함

## Ⅲ. 절차
```text
+----------+    +----------+    +----------+    +----------+
| 경로 수신| -> | 정책 적용| -> | 속성 비교| -> | FIB 등록 |
+----------+    +----------+    +----------+    +----------+
```
1. 경로 수신: 인접 BGP 라우터로부터 Prefix와 부가적인 Path Attribute 정보 수신
2. 정책 적용: Inbound Route-map을 통해 불필요한 경로 필터링 및 로컬 속성 조작
3. 속성 비교: Weight -> Local Pref -> AS-Path -> MED 순으로 엄격한 선택 알고리즘 수행
4. FIB 등록: 최종 선택된 단일 최적 경로를 라우팅 테이블에 등록하고 타 AS에 재광고

> 요약: 수신 경로에 대한 필터링과 다단계 속성 비교를 거쳐 최종 최적 경로를 선출함

## Ⅳ. 문제점
- 양방향 통신 시 Outbound(Local Pref)와 Inbound(MED) 정책 불일치로 비대칭 라우팅 발생 원인
- 글로벌 BGP 테이블 크기 비대화로 인해 회선 장애 발생 시 경로 수렴(Convergence) 장기화
- 운영자의 Route-map 설정 실수로 의도치 않게 타 AS의 Transit 망이 되어 트래픽 폭주

## Ⅴ. 개선방안
- [단기] AS-Path Prepending 기법으로 간단히 외부 유입 트래픽의 Inbound 경로 제어
- [중기] BGP PIC(Prefix Independent Convergence) 적용을 통해 장애 발생 시 마이크로초 단위 경로 우회
- [장기] 의도 기반 네트워크(IBN) 솔루션을 활용하여 복잡한 BGP 정책 설정 및 검증 자동화

## Ⅵ. 전망
- RPKI 기반의 라우팅 보안(BGPSEC) 기능이 필수가 되어 경로 하이재킹 위험이 해소될 전망임
