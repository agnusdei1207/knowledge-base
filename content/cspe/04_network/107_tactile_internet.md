## 미리 알고가기

- 초저지연은 사람의 제어 반응이 끊기지 않도록 왕복 지연을 매우 짧게 유지하는 성질임
- 지터는 패킷 도착 시간이 들쑥날쑥한 정도임
- 햅틱은 촉감이나 힘 같은 감각을 기기에서 전달하는 기술임
- 엣지 컴퓨팅은 사용자 가까운 곳에서 연산을 처리해 지연을 줄이는 구조임

## Ⅰ. 개요

- **정의/개념**: 촉각 인터넷은 사람이나 기계의 제어 신호와 촉각 피드백을 거의 실시간으로 주고받아 원격 조작과 협업을 가능하게 하는 초저지연 네트워크 서비스임
- **배경/필요성**: 원격 로봇과 자율 제어와 실감형 협업은 영상만 빨라서는 부족하고 제어 응답이 늦어지면 안정성이 무너지므로 지연과 지터를 함께 낮춘 통신 구조가 필요함

## Ⅱ. 특징

- 제어 신호와 피드백이 짧은 주기로 오가므로 지연과 지터가 성능의 핵심이 됨
- 네트워크만 빠르면 끝나지 않고 단말과 엣지와 제어 애플리케이션까지 함께 짧아야 함
- 패킷 손실이 작아도 조작감이 크게 흔들릴 수 있어 신뢰성과 복구 속도가 중요함
- 장애가 나면 안전 문제가 바로 생길 수 있으므로 로컬 대체 제어가 필요함

## Ⅲ. 종류 및 비교

| 판단 기준 | 일반 실시간 서비스 | 촉각 인터넷 |
|:---|:---|:---|
| 주된 데이터 | 음성, 영상, 메시지 중심임 | 제어 신호와 촉각 피드백이 중심임 |
| 지연 허용 범위 | 수십 ms 이상도 서비스가 가능함 | 몇 ms 수준의 왕복 지연을 요구하기 쉬움 |
| 품질 판단 | 끊김 없는 재생과 체감 품질이 중요함 | 제어 안정성과 반응 일관성이 더 중요함 |
| 대표 환경 | 회의, 스트리밍, 게임에 적합함 | 원격 로봇, 산업 제어, 원격 조작에 적합함 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 제어 단말 | 사용자의 조작 입력과 촉각 출력을 담당함 |
| 센서·액추에이터 | 원격 환경 상태를 측정하고 실제 동작을 수행함 |
| 액세스망 | 무선 또는 유선 구간에서 초저지연 전송을 담당함 |
| 엣지 제어 노드 | 가까운 위치에서 판단과 보정을 수행해 지연을 줄임 |
| 응용 서버 | 작업 로직과 세션 관리와 데이터 기록을 처리함 |

```text
+-----------+    +-----------+    +-------------+    +---------------+
| 제어 단말   | <-> | 액세스망    | <-> | 엣지 제어 노드 | <-> | 원격 장비        |
+-----------+    +-----------+    +-------------+    +---------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
[입력 발생] -> [저지연 전송] -> [엣지 제어] -> [원격 동작] -> [촉각·상태 피드백]
```

1. **입력 발생**: 사용자가 힘이나 위치 같은 제어 신호를 보냄
2. **저지연 전송**: 액세스망이 신호를 엣지로 짧게 전달함
3. **엣지 제어**: 엣지 노드가 지연 보정과 제어 판단을 수행함
4. **원격 동작**: 원격 장비가 명령을 실행함
5. **촉각·상태 피드백**: 센서 정보와 반응 값을 다시 단말로 돌려보냄

## Ⅵ. 실무 적용 및 유의점

1. 원격 로봇이나 산업 설비 제어에는 촉각 인터넷이 유용하지만 구간별 지연 편차가 커지면 조작감과 안전성이 바로 흔들리므로 엣지 배치와 우선순위 제어를 함께 적용하고 왕복 지연과 지터와 패킷 손실률을 같이 확인함
2. 공중망 장애가 길어지면 제어가 끊길 수 있으므로 로컬 자동 정지나 안전 모드 같은 대체 절차를 미리 두고 장애 전환 시간과 복구 후 제어 안정성을 반복 점검해야 함

## Ⅶ. 결론

촉각 인터넷의 본질은 빠른 전송 자체가 아니라 제어와 피드백이 흔들리지 않도록 단말과 엣지와 네트워크를 함께 짧고 안정적으로 묶는 데 있음.
