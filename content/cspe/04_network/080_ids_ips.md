## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 네트워크 트래픽을 심층 분석하여 해킹 시도를 탐지(IDS)하고, 실시간 차단(IPS)까지 수행하는 적극적 보안 솔루션 |
| **배경/필요성** | 포트/IP 기반의 정적 방화벽을 우회하는 웜(Worm), 익스플로잇(Exploit) 등 정밀 공격을 시그니처 및 행위 기반으로 방어 필요 |
| **출제 의도** | 탐지 방식(오용 탐지 vs 이상 탐지) 메커니즘과 In-line/Out-of-path 구성 방식의 차이점 평가 |

## Ⅱ. 구성요소
```text
+----------+       +----------+       +----------+
| Internet |       | IPS (L7) |       | Firewall |
| (Hacker) | =====>| (In-line)| =====>| (Policy) |
+----------+       +----------+       +----------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| IDS (탐지) | 트래픽을 미러링 받아 분석 후 관리자에게 경보(Alert)만 발생 (Out-of-path) | CCTV 감시 카메라 |
| IPS (방지) | 트래픽 경로(In-line)상에 위치하여 공격 탐지 시 패킷을 즉시 능동적 차단(Drop) | 경호원 직접 제압 |
| 시그니처 (오용) | 알려진 공격 패턴(규칙)과 정확히 일치하는 트래픽을 잡아내는 분석 기법 | 수배자 전단지 대조 |

> 요약: 방화벽이 열어둔 정상 포트 내부로 교묘히 숨어 들어오는 악의적 L7 페이로드를 적발하고 차단함

## Ⅲ. 절차
```text
+----------+    +----------+    +----------+    +----------+
| 트래픽수집| -> | 디코딩   | -> | 패턴 매칭| -> | 대응 조치|
+----------+    +----------+    +----------+    +----------+
```
1. 트래픽수집: (IDS) 미러(Mirror) 포트로 트래픽 복사 / (IPS) 인라인(In-line) 회선으로 실시간 패킷 인입
2. 디코딩: 패킷 파편화를 재조립하고 인코딩(Base64 등)된 페이로드를 원래 상태로 정규화 분석
3. 패턴 매칭: 수만 개의 공격 시그니처 DB(오용 탐지) 및 베이스라인 통계치(이상 탐지)와 정밀 대조
4. 대응 조치: 악성 판단 시 (IDS) 로그 기록 및 알람 / (IPS) 해당 패킷 파기 및 TCP RST 주입 연결 끊기

> 요약: 패킷 재조립 및 심층 시그니처 매칭을 수행하여 악의적 통신을 선별하고 차단함

## Ⅳ. 문제점
- 알려지지 않은 신규 공격(Zero-Day Attack)은 시그니처 DB에 없기 때문에 오용 탐지 기법으로 방어 절대 불가
- 이상 탐지(Anomaly) 엔진 사용 시 정상 트래픽도 비정상으로 간주하는 오탐(False Positive) 발생 빈번
- IPS 인라인 모드에서 암호화(HTTPS) 트래픽 분석 시 심각한 지연 발생 또는 분석 불가 (가시성 상실)

## Ⅴ. 개선방안
- [단기] 최신 취약점 시그니처 DB의 1시간 단위 주기적 자동 업데이트 체계 적용으로 탐지율(True Positive) 극대화
- [중기] 방화벽과 연동된 SSL 복호화 인프라를 구축하여 IPS에 평문 트래픽을 제공해 숨은 위협 가시성 확보
- [장기] 샌드박스(Sandbox) 및 AI/ML 행위 분석 기술을 결합하여 미지의 제로데이 위협까지 사전 식별 체계 확립

## Ⅵ. 전망
- 독립적 어플라이언스에서 벗어나 차세대 통합 보안 장비(NGFW/UTM) 내부의 핵심 모듈 엔진으로 완전히 흡수 통합되는 추세임
