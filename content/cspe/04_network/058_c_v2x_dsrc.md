# 📖 【암기용】 개념 완전 이해

> 목적: C-V2X와 DSRC를 표준 계열, 통신 방식, 진화 경로의 차이로 이해하게 만든다.

## 한눈에
- **개요**: DSRC는 IEEE 802.11p 기반 차량 통신이고, C-V2X는 3GPP LTE/5G 기반 차량 통신이다.
- **왜 필요한가**: 차량 안전 통신은 직접 통신과 인프라 연동이 모두 필요하며, 어떤 표준을 선택하느냐가 단말·RSU·망 투자에 영향을 준다.
- **핵심 직관**: DSRC는 차량용 Wi-Fi 계열, C-V2X는 셀룰러 계열 차량 무선이다.

## 깊이 이해
- **배경·문제의식**: DSRC는 IEEE 802.11p/WAVE로 먼저 표준화되어 저지연 직접 통신에 초점을 뒀다. C-V2X는 3GPP Release 14의 LTE-V2X부터 PC5 직접 통신과 Uu 망 경유 통신을 제공한다.
- **작동 원리**: DSRC는 CSMA/CA 기반으로 주변 차량과 경쟁 접속한다. C-V2X PC5는 sidelink 자원 선택으로 직접 통신하고, Uu는 기지국·코어망을 통해 V2N 서비스를 제공한다.
- **비유**: DSRC는 차량끼리 같은 무전 채널을 경쟁해 말하는 방식이고, C-V2X는 무전 채널과 이동통신망 관제 채널을 함께 쓰는 방식이다.
- **구체 예시**: 긴급 제동 경고는 DSRC와 C-V2X PC5 모두 직접 전송 가능하다. 원격 관제·HD Map 갱신은 C-V2X Uu와 5G망 연동이 적합하다.
- **흔한 오해·주의점**: C-V2X가 항상 DSRC보다 우월하다고 단정하면 안 된다. 기존 구축 인프라, 주파수 정책, 단말 보급, 상호운용성을 함께 판단해야 한다.

## 연결 개념
- IEEE 802.11p WAVE — DSRC 무선·상위 프로토콜
- 3GPP PC5/Uu — C-V2X 직접·망 경유 인터페이스
- V2X PKI — 표준과 무관하게 필요한 메시지 신뢰체계

# 📝 【답안용】 시험 답안 템플릿

> 목적: C-V2X와 DSRC 비교 문제에서 표준, 접속 방식, 망 연동, 진화 경로를 선명하게 구분한다.
> 핵심: 출제자는 특정 기술 홍보가 아니라 적용 조건별 선택 기준을 요구한다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: DSRC는 IEEE 802.11p/WAVE 기반, C-V2X는 3GPP LTE/5G PC5·Uu 기반 차량 통신 기술이다.
> 2. **가치**: DSRC는 독립 직접 통신, C-V2X는 직접 통신과 셀룰러망 연동·5G NR-V2X 진화 경로를 제공한다.
> 3. **판단 포인트**: 지연·전달률, 인프라 보급, 주파수 정책, 단말 생태계, 5G 연동 요구를 기준으로 선택한다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 두 표준 차이 확인 | IEEE 802.11p vs 3GPP PC5/Uu | DSRC와 C-V2X를 같은 V2X로 뭉침 |
| 선택 기준 판단 확인 | 직접 통신, 망 연동, 진화성 | 특정 기술 절대 우위 단정 |
| 실무 전환 리스크 확인 | RSU/OBU 교체, 상호운용, 주파수 | 기존 인프라 매몰비용 누락 |

> 요약: 비교 답안은 표준 계열, 무선 접속, 망 연동, 전환 비용을 축으로 구성해야 한다.

## Ⅰ. 개요 및 필요성

- 개요: C-V2X와 DSRC의 차량 통신 비교
- 배경: V2X는 차량, RSU, 주파수, PKI 투자가 함께 필요해 표준 선택의 전환 비용이 큼
- 필요성: PC5/Uu, IEEE 802.11p, 지연, 커버리지, 생태계 기준으로 적용 조건을 비교

---

## Ⅱ. 구조 및 구성요소

```text
DSRC: Vehicle OBU -> IEEE 802.11p -> RSU/Neighbor OBU -> WAVE Stack
C-V2X: Vehicle UE -> PC5 Sidelink -> Neighbor UE
C-V2X: Vehicle UE -> Uu -> gNB/5GC -> Cloud/MEC
PKI -> Message Signing -> Verification -> Safety Service
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| DSRC OBU/RSU | 802.11p 기반 직접 통신 | CSMA/CA, WAVE |
| C-V2X UE | PC5/Uu 차량 통신 | LTE-V2X, NR-V2X |
| PC5 Sidelink | 차량 간 직접 통신 | 기지국 없이 동작 가능 |
| Uu Interface | 셀룰러망 경유 V2N | 5G Core, MEC 연동 |
| PKI | 메시지 인증·무결성 | 익명 인증서·폐기 관리 |

> 요약: DSRC는 802.11p 직접 통신 중심, C-V2X는 PC5 직접 통신과 Uu 망 연동을 함께 제공한다.

---

## Ⅲ. 동작원리 및 흐름도

```text
차량 상태 수집 -> 안전 메시지 생성 -> PKI 서명
-> DSRC 802.11p 경쟁 접속 / C-V2X PC5 자원 선택
-> 주변 차량·RSU 수신 -> 서명 검증
-> 위험 판단 -> 경고·제어 연계
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 위치·속도·가속도 수집 | GNSS 오차, timestamp |
| 2 | BSM/CAM 메시지 생성 | 메시지 주기 10Hz 수준 |
| 3 | DSRC 또는 PC5로 직접 전송 | latency, packet delivery ratio |
| 4 | C-V2X Uu로 관제·MEC 연동 | cellular coverage, RTT |
| 5 | 인증·위험 판단 | signature verify latency |

> 요약: 두 기술 모두 안전 메시지를 직접 전송하지만, C-V2X는 Uu 경로로 망 서비스를 확장한다.

## Ⅳ. 특징

| 구분 | DSRC | C-V2X | 판단 포인트 |
|:---|:---|:---|:---|
| 표준 계열 | IEEE 802.11p/WAVE | 3GPP LTE-V2X, NR-V2X | 표준 생태계 |
| 접속 방식 | CSMA/CA 경쟁 접속 | PC5 sidelink 자원 선택 | 혼잡 환경 PDR |
| 망 연동 | RSU 중심 | Uu로 5G/MEC 연동 | V2N 서비스 |
| 진화 경로 | WAVE 기반 | 5G NR-V2X 확장 | 군집주행·고급 서비스 |

> 요약: DSRC는 독립 직접 통신, C-V2X는 직접 통신과 셀룰러망 확장을 함께 고려하는 선택지다.

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존/대안 | 선택 기준 | 적용 판단 |
|:---|:---|:---|:---|
| 구조 | DSRC 기존 RSU | 기존 구축 구간·매몰비용 | 교체보다 병행 운영 검토 |
| 비용/성능 | C-V2X 신규망 | 5G 연동·MEC·단말 보급 | 신규 구축·고급 서비스 |
| 운영/위험 | 혼재 환경 | 듀얼모드 OBU·PKI 호환 | 전환 기간 상호운용 |

> 요약: 기존 DSRC 인프라가 있으면 병행·전환 전략, 신규 5G 연계 구간은 C-V2X 중심 검토가 타당하다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 표준 혼재 | DSRC와 C-V2X 차량 공존 | 듀얼모드 RSU/OBU, 단계 전환 | interoperability pass rate |
| 혼잡 손실 | 차량 밀집·채널 경쟁 | congestion control, 자원 재선택 | PDR, channel busy ratio |
| 망 의존 | Uu 서비스의 커버리지 한계 | PC5 직접 통신 우선 설계 | cellular outage impact |

> 요약: 전환 리스크는 혼재, 혼잡, 망 의존을 구분해 직접 통신 안전성을 우선 보장해야 한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 전달률 | PDR 90% 이상 목표 | field test, OBU log |
| 지연 | 안전 메시지 100ms 이하 목표 | packet capture, timestamp |
| 상호운용 | 벤더·표준 조합 시험 통과 | conformance test |

> 요약: 비교 검증은 PDR, 지연, 상호운용 시험 결과로 판단한다.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 — 단계별 또는 항목별):**
1. 기존 DSRC RSU·OBU 보급 구간은 매몰비용과 안전 서비스 연속성을 기준으로 병행 운영 또는 단계 전환 계획을 수립함
2. 신규 스마트도로·MEC 연계 구간은 C-V2X PC5 안전 메시지와 Uu 기반 관제·HD Map 서비스를 분리 설계함
3. 듀얼모드 단말, V2X PKI, 상호운용 시험, 혼잡 제어 기준을 전환 로드맵의 필수 검증 항목으로 포함함

**결론 (2줄):**
- 기술사 판단: 기존 인프라 보호가 우선이면 DSRC 병행, 5G/MEC 연계 서비스가 목표면 C-V2X 중심 설계가 타당함
- 향후 방향: NR-V2X와 MEC 기반 협력 주행이 확대되며 직접 통신과 망 연동의 하이브리드 구조가 일반화됨
