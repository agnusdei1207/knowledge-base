## 미리 알고가기

- DSRC는 IEEE 802.11p 기반의 차량용 단거리 직접 통신 방식임
- C-V2X는 3GPP 이동통신 기술을 차량 통신에 적용한 방식임
- PC5는 차량끼리 기지국 없이 직접 통신하는 인터페이스임
- Uu는 기지국을 거쳐 이동통신망과 연결하는 인터페이스임
- RSU는 도로변에서 차량과 메시지를 주고받는 노변 장치임

## Ⅰ. 개요

- **정의/개념**: C-V2X와 DSRC는 모두 차량 안전 메시지와 도로 정보 교환을 위한 V2X 구현 방식이지만, DSRC는 Wi-Fi 계열 직접 통신에 가깝고 C-V2X는 이동통신 계열 직접 통신과 망 연동을 함께 제공함
- **배경/필요성**: 차량 통신 인프라는 도로 장비와 차량 단말에 함께 반영되어야 하므로, 통신 거리와 이동성 대응과 5G 연계 가능성을 기준으로 단일 기술 방향을 정할 필요가 있었음

## Ⅱ. 특징

- DSRC는 구조가 단순하고 직접 통신 중심이라 초기 차량 안전 메시지 교환에 적합함
- C-V2X는 직접 통신과 기지국 연동을 모두 지원해 서비스 범위를 넓히기 쉬움
- 고속 이동과 혼잡 환경 대응은 자원 제어와 진화 경로 측면에서 C-V2X가 유리함
- 기존 시험망과 장비 자산이 있는 곳에서는 완전 교체보다 전환 계획이 더 중요함

## Ⅲ. 종류 및 비교

| 판단 기준 | DSRC | C-V2X |
|:---|:---|:---|
| 기반 기술 | IEEE 802.11p와 WAVE 계열 직접 통신이 중심임 | 3GPP LTE·5G 기반 직접 통신과 망 연동을 함께 사용함 |
| 통신 범위와 이동성 | 근거리 직접 통신에는 적합하지만 고속 이동과 확장성에 제약이 있음 | 더 넓은 범위와 고속 이동 환경 대응에 유리함 |
| 서비스 확장성 | 주로 현장 안전 메시지 전달에 초점이 맞음 | 안전 메시지에 더해 지도, 관제, 엣지 서비스 연동이 쉬움 |
| 인프라 연계 | 전용 RSU와 현장 장비 구성이 중요함 | 이동통신 인프라와 연동해 광역 서비스 확장이 가능함 |
| 장기 진화 경로 | 독립 직접 통신 구조에 가깝고 진화 폭이 좁음 | 5G V2X와 엣지 연동으로 확장하기 쉬움 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 차량 단말 | 두 방식 모두 차량 위치와 상태를 메시지로 생성해 주변에 전송함 |
| 직접 통신 링크 | DSRC는 현장 직접 송신이 중심이고 C-V2X는 PC5 직접 통신을 사용함 |
| 이동통신망 | C-V2X에서 Uu 경로를 통해 광역 정보와 서비스 업데이트를 지원함 |
| RSU | 두 방식 모두 도로 인프라 연계에 쓰이지만, 구축 방식과 연동 구조는 다를 수 있음 |
| 관제·엣지 시스템 | 차량 이벤트를 수집해 신호 제어와 경로 안내와 안전 서비스를 운영함 |

```text
+-------+     +------------+     +-------+     +-----------+
| 차량 A | --> | 직접 통신 링크 | --> | 차량 B | --> | RSU·관제   |
+-------+     +------------+     +-------+     +-----------+
                   DSRC 또는 PC5             C-V2X는 Uu로 광역 연동 가능
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+     +-------------+
| 차량 이벤트 생성 | --> | 직접 통신 우선 전송 | --> | 인프라 수신 여부 판단 | --> | 광역 망 연계 여부 결정 | --> | 경고·서비스 반영 |
+-------------+     +-------------+     +-------------+     +-------------+     +-------------+
```

1. **차량 이벤트 생성**: 차량이 급제동, 위치, 속도, 위험 상황 메시지를 생성함
2. **직접 통신 우선 전송**: 주변 차량과 인프라에 즉시 알려야 할 정보는 현장 직접 통신으로 먼저 보냄
3. **인프라 수신 여부 판단**: RSU나 차량이 메시지를 받아 현장 경고에 반영함
4. **광역 망 연계 여부 결정**: C-V2X 환경에서는 필요 시 이동통신망 경로로 관제나 엣지 서버에 전달함
5. **경고·서비스 반영**: 수신한 정보가 운전자 경고, 차량 제어, 교통 운영 서비스에 반영됨

## Ⅵ. 실무 적용 및 유의점

1. 신규 C-ITS나 자율주행 지원 인프라를 설계할 때는 단순 지연 수치보다 장기 진화와 망 연동성이 중요하므로 C-V2X 중심으로 검토하되 기존 DSRC 자산이 남아 있으면 이행 기간의 이중 운용 계획과 상호 운용 시험 결과로 전환 리스크를 확인함
2. 터널이나 교차로처럼 현장 즉시성이 중요한 구간에서는 직접 통신 성능이 핵심이므로 패킷 전달률, 차량 속도별 지연, 혼잡 시 채널 점유율을 기준으로 DSRC와 C-V2X의 적용 적합성을 검증해야 함

## Ⅶ. 결론

C-V2X와 DSRC의 선택 기준은 단순한 단거리 통신 여부가 아니라 고속 이동 대응과 광역 서비스 확장까지 포함한 진화 경로에 있음.
