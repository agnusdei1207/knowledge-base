## 미리 알고가기

- 스마트 미터는 전력 사용량을 일정 주기로 측정하고 통신망으로 보내는 계량기임
- 원격 검침은 현장 방문 없이 계량 데이터를 수집하는 방식임
- 수요반응은 전력 피크 시간에 요금이나 제어 신호로 사용량을 조절하는 운영 방식임
- HES는 계량기와 직접 통신하며 수집 명령과 원격 제어를 처리하는 헤드엔드 시스템임
- MDMS는 계량 데이터를 저장하고 검증해 요금과 운영 시스템에 넘기는 관리 시스템임

## Ⅰ. 개요

- **정의/개념**: AMI는 스마트 미터와 수집 장치와 전력회사 운영 시스템을 양방향 통신으로 연결해 계량, 검침, 요금, 제어를 통합하는 전력 정보 인프라임
- **배경/필요성**: 수기 검침만으로는 시간대별 사용량 파악과 피크 제어와 장애 대응이 어려우므로 계량 데이터를 주기적으로 수집하고 운영 시스템에 연계할 구조가 필요함

## Ⅱ. 특징

- 계량 데이터의 시계열 변화로 사용 패턴과 이상 징후를 식별함
- 검침뿐 아니라 원격 차단과 재연결과 요금제 반영까지 같은 인프라에서 처리할 수 있음
- 미터 수가 많아질수록 통신 안정성과 시간 동기화와 데이터 품질 관리가 중요해짐
- 생활 패턴이 담긴 데이터가 쌓이므로 보안과 개인정보 보호를 함께 설계해야 함

## Ⅲ. 종류 및 비교

| 판단 기준 | AMR | AMI |
|:---|:---|:---|
| 통신 방향 | 검침 중심의 단방향 수집이 많음 | 계량기와 운영 시스템이 양방향으로 통신함 |
| 활용 범위 | 사용량 집계와 검침 자동화에 머무르기 쉬움 | 요금, 제어, 이상 탐지, 수요반응까지 확장됨 |
| 운영 가시성 | 수집 주기와 상태 정보가 제한적임 | 상태 정보와 이벤트를 함께 받아 운영 판단이 쉬움 |
| 적합 환경 | 단순 검침 자동화가 필요한 환경에 적합함 | 실시간 운영과 피크 관리가 필요한 대규모 전력망에 적합함 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 스마트 미터 | 사용량과 전압과 이벤트를 측정해 전송함 |
| 데이터 집중 장치 | 여러 미터 데이터를 모아 상위망으로 전달함 |
| 통신망 | 가정, 지역, 광역 구간을 연결해 계량 데이터를 운반함 |
| HES | 미터와 통신 세션을 관리하고 원격 명령을 처리함 |
| MDMS | 수집 데이터를 검증하고 저장해 요금과 운영 시스템에 제공함 |
| 운영 시스템 | 검침, 청구, 정전 관리, 수요반응 같은 업무를 수행함 |

```text
+-------------+    +-------------+    +-------------+    +-------------+
| 스마트 미터   | -> | 집중 장치     | -> | HES         | -> | MDMS·업무 시스템 |
+-------------+    +-------------+    +-------------+    +-------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
[계량 측정] -> [데이터 수집] -> [검증·저장] -> [요금·운영 반영] -> [원격 제어]
```

1. **계량 측정**: 스마트 미터가 사용량과 상태 정보를 일정 주기로 기록함
2. **데이터 수집**: 집중 장치와 통신망을 거쳐 HES로 데이터를 보냄
3. **검증·저장**: MDMS가 누락값과 이상값을 점검한 뒤 저장함
4. **요금·운영 반영**: 청구, 부하 관리, 정전 분석 시스템이 데이터를 활용함
5. **원격 제어**: 필요하면 요금제 변경이나 원격 차단 같은 제어 명령을 내림

## Ⅵ. 실무 적용 및 유의점

1. 대규모 공동주택이나 배전 사업자는 AMI로 검침 비용과 피크 대응 시간을 줄일 수 있지만 통신 누락이 누적되면 청구 신뢰가 흔들리므로 재전송 정책과 시계 동기화를 함께 운영하고 검침 성공률과 누락 건수와 지연 시간을 같이 확인함
2. 원격 차단과 요금 정보는 민감도가 높으므로 인증과 구간 암호화와 권한 분리를 함께 적용하고 비정상 명령 건수와 보안 이벤트와 고객 민원 발생 추이를 함께 봐야 함

## Ⅶ. 결론

AMI의 핵심은 계량기를 네트워크로 연결하는 데 그치지 않고 수집 데이터의 신뢰성과 보안을 바탕으로 검침과 운영과 제어를 함께 고도화하는 데 있음.
