## 미리 알고가기

- 블루투스 클래식은 이어폰과 스피커처럼 연속 데이터 전송에 맞춘 근거리 무선 방식임
- BLE는 짧은 데이터만 낮은 전력으로 주고받도록 만든 저전력 블루투스 방식임
- Mesh는 여러 노드가 릴레이로 메시지를 전달해 커버리지를 넓히는 구조임
- Advertising은 연결 없이 존재나 간단한 정보를 주기적으로 알리는 BLE 전송 방식임
- Provisioner는 BLE Mesh 노드를 초기 등록하고 보안 설정을 배포하는 관리 주체임

## Ⅰ. 개요

- **정의/개념**: 블루투스는 근거리 기기 연결을 위한 무선 표준이고, BLE는 그중 저전력 센서와 제어에 맞춘 방식이며, BLE Mesh는 BLE 기반 노드들이 서로 메시지를 전달해 더 넓은 공간을 덮는 구조임
- **배경/필요성**: 무선 오디오처럼 연속 전송이 필요한 기기와 배터리로 오래 버텨야 하는 센서의 요구가 달라졌고, 스마트 조명처럼 한 공간 전체를 제어하려면 단일 링크보다 다대다 구조가 필요했음

## Ⅱ. 특징

- 블루투스 클래식은 비교적 안정적인 연속 연결과 오디오 전송에 강함
- BLE는 짧은 깨어남과 짧은 전송으로 배터리 수명을 길게 가져갈 수 있음
- BLE Mesh는 여러 노드가 릴레이를 맡아 커버리지를 넓히지만 릴레이 노드는 상시 전원이 더 적합함
- 웨어러블, 비콘, 조명 제어처럼 같은 블루투스 계열이라도 요구에 따라 구조를 다르게 선택해야 함

## Ⅲ. 종류 및 비교

| 판단 기준 | 블루투스 클래식 | BLE | BLE Mesh |
|:---|:---|:---|:---|
| 주된 목적 | 오디오와 연속 데이터 연결에 적합함 | 센서와 비콘처럼 짧은 데이터 전송에 적합함 | 조명과 설비 제어처럼 넓은 구역의 다대다 연결에 적합함 |
| 전력 특성 | 상대적으로 전력 소모가 큼 | 매우 낮은 전력으로 장시간 운용 가능함 | 릴레이 역할이 있으면 상시 전원 구성이 유리함 |
| 네트워크 구조 | 주로 1:1 또는 소규모 연결임 | 소규모 연결과 광고 기반 정보 전송에 적합함 | 다수 노드가 중계해 공간 전체를 덮는 구조임 |
| 대표 활용 | 이어폰, 스피커, 입력 장치에 적합함 | 웨어러블, 센서, 위치 비콘에 적합함 | 스마트 조명, 빌딩 자동화, 설비 제어에 적합함 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 클래식 링크 | 비교적 긴 연결을 유지하며 연속적인 데이터 흐름을 처리함 |
| BLE 단말 | 짧은 주기로 깨어나 광고나 소량 데이터 송수신을 수행함 |
| Mesh 노드 | 메시지를 생성·수신하고 필요하면 주변 노드로 다시 전달함 |
| Provisioner | 새 노드를 등록하고 주소와 보안 정보를 배포해 네트워크를 형성함 |
| Relay와 Low Power Node | Relay는 패킷을 중계하고, Low Power Node는 절전 위주로 동작함 |

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 스마트폰     | --> | Provisioner | --> | 조명 노드 A   | --> | 조명 노드 B   |
+-----------+     +-----------+     +-----------+     +-----------+
      설정·제어          등록·보안 배포         릴레이               릴레이·제어
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+     +-------------+
| 노드 전원 인가 | --> | Provisioning | --> | 주소·키 배포   | --> | 메시지 발행    | --> | 릴레이·수신 처리 |
+-------------+     +-------------+     +-------------+     +-------------+     +-------------+
```

1. **노드 전원 인가**: 새 기기가 통신 가능한 상태로 켜짐
2. **Provisioning**: 관리 장치가 새 노드를 인식하고 네트워크에 등록함
3. **주소·키 배포**: 보안 키와 그룹 주소를 내려줘 통신 권한을 부여함
4. **메시지 발행**: 스위치나 센서가 그룹 대상 명령이나 상태 정보를 발행함
5. **릴레이·수신 처리**: 중간 노드가 메시지를 전달하고 대상 노드가 명령을 실행함

## Ⅵ. 실무 적용 및 유의점

1. 웨어러블과 비콘처럼 배터리 수명이 중요한 환경에서는 BLE가 맞지만 조명·설비 제어처럼 공간 전체를 덮어야 하는 환경에서는 BLE Mesh가 필요하므로 배터리 수명, 연결 지연, 메시지 성공률로 구조 선택의 타당성을 확인함
2. BLE Mesh는 릴레이 수를 과하게 늘리면 트래픽이 불어나고 적게 두면 음영이 생기므로 상시 전원 노드 위주로 릴레이를 배치하고 홉 수, 중복 전달량, 응답 지연으로 네트워크 밀도를 조정함

## Ⅶ. 결론

블루투스 계열의 선택 기준은 같은 무선 기술인지보다 연속 전송이 필요한지, 배터리를 아껴야 하는지, 공간 전체를 중계해야 하는지에 있음.
