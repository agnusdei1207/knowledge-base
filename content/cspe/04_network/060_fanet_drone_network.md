# 📖 【암기용】 개념 완전 이해

> 목적: FANET을 MANET의 단순 변형이 아니라 고속 3차원 이동 드론을 위한 애드혹 네트워크로 이해하게 만든다.

## 한눈에
- **개요**: FANET은 여러 UAV/드론이 기지국 없이 서로 라우팅하며 통신하는 Flying Ad Hoc Network다.
- **왜 필요한가**: 재난 현장, 산악 수색, 군집 촬영, 임시 통신망에서는 지상 인프라가 없거나 연결이 끊길 수 있다.
- **핵심 직관**: 하늘을 나는 드론들이 서로 중계기가 되어 이동형 무선망을 즉석에서 구성하는 방식이다.

## 깊이 이해
- **배경·문제의식**: 드론은 속도, 고도, 방향이 계속 바뀌어 링크 지속 시간이 짧다. 지상 MANET보다 토폴로지 변화가 빠르므로 3D 위치 기반 라우팅이 경로 수명을 좌우한다.
- **작동 원리**: 드론은 이웃 탐색으로 링크 품질을 측정하고, GPS/IMU 위치와 잔여 배터리, 링크 품질을 기준으로 AODV, OLSR, GPSR, DSDV 계열 라우팅을 선택한다.
- **비유**: 등산객들이 고정 기지국 없이 서로 무전 중계를 하는데, 모두 헬리콥터처럼 움직이는 상황이다. 누가 다음 중계자가 될지 계속 바뀐다.
- **구체 예시**: 재난 지역에서 10대 드론이 2.4/5GHz 또는 LTE/5G 링크로 영상과 위치 정보를 중계하고, 지휘 차량 게이트웨이가 클라우드로 데이터를 전송한다.
- **흔한 오해·주의점**: FANET은 단순 드론 원격조종망이 아니다. 다중 홉 라우팅, 링크 단절 대응, 에너지 제약, 항공 안전 경로를 함께 고려해야 한다.

## 연결 개념
- MANET/VANET — 이동 애드혹 네트워크 계열
- GPSR/AODV/OLSR — FANET 라우팅 후보
- UAV Swarm — 군집 제어와 통신망 결합

# 📝 【답안용】 시험 답안 템플릿

> 목적: FANET 답안에서 3D 이동성, 라우팅, 링크 품질, 에너지, 보안 리스크를 구조화한다.
> 핵심: 출제자는 드론 네트워크를 이동 애드혹망의 특수 조건으로 분석하는지 확인한다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: FANET은 UAV들이 인프라 없이 다중 홉 라우팅으로 데이터를 전달하는 고이동성 3차원 애드혹 네트워크다.
> 2. **가치**: 재난·수색·감시·임시 통신망에서 드론이 중계 노드가 되어 영상·위치·제어 데이터를 현장 게이트웨이에 전달한다.
> 3. **판단 포인트**: 링크 지속 시간, 라우팅 오버헤드, 위치 기반 경로, 배터리, 보안·항공 안전 제약을 함께 봐야 한다.

| 라우팅 판단 확인 | AODV, OLSR, GPSR, 링크 품질·위치 기반 | 드론 제어 통신만 서술 |

> 요약: FANET 답안은 드론의 고속 3D 이동성이 라우팅과 링크 관리에 주는 영향을 중심으로 작성한다.

## Ⅰ. 개요 및 필요성

FANET은 드론 노드가 자율적으로 구성하는 비행 애드혹 네트워크다. 재난·군집 드론·임시 통신망은 지상 인프라가 없거나 파괴될 수 있다. FANET은 드론 간 다중 홉 링크로 영상·센서·제어 데이터를 현장 게이트웨이에 전달한다.

---

## Ⅱ. 구조 및 구성요소

```text
UAV Node -> Neighbor Discovery -> Multi-hop Routing -> Gateway UAV
     / GPS/IMU 위치       / Link Quality       / Battery State
Ground Control Station -> Backhaul -> Cloud/Command Center
Security Policy -> Auth/Encryption -> Route Trust
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| UAV Node | 비행·센서·통신 노드 | 3D 이동, 배터리 제약 |
| Routing Module | 경로 탐색·유지 | AODV, OLSR, GPSR |
| Gateway UAV/GCS | 외부망 연결 | LTE/5G, 위성, Wi-Fi backhaul |
| Link Monitor | RSSI·SNR·패킷 손실 측정 | link lifetime 예측 |
| Security Module | 인증·암호화·무결성 | DTLS, IPsec, 키 관리 |

> 요약: FANET은 UAV가 센서 노드이자 라우터로 동작하고, 게이트웨이가 외부망과 지휘 체계를 연결한다.

---

## Ⅲ. 동작원리 및 흐름도

```text
임무 계획 -> UAV 배치 -> 이웃 탐색
-> 링크 품질·위치 수집 -> 라우팅 경로 선택
-> 영상/센서 데이터 중계 -> 링크 단절 감지
-> 경로 재탐색 -> GCS/Cloud 전달
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 임무 영역과 드론 초기 위치 설정 | coverage ratio |
| 2 | Hello 메시지로 이웃·링크 품질 수집 | RSSI, SNR, packet loss |
| 3 | 위치·링크·배터리 기반 경로 선택 | routing convergence time |
| 4 | 영상·센서 데이터를 다중 홉 전달 | throughput, end-to-end delay |
| 5 | 링크 단절 시 경로 재탐색 | packet delivery ratio, route repair time |

> 요약: FANET은 비행 중 계속 바뀌는 링크 상태를 반영해 경로를 재계산한다.

---

## Ⅳ. 특징

| 구분 | MANET/VANET | FANET | 판단 포인트 |
|:---|:---|:---|:---|
| 이동성 | 지상 2D 이동 중심 | 고속 3D 이동 | link lifetime 짧음 |
| 노드 밀도 | 상대적으로 밀집 가능 | 드론 수 제한 | 다중 홉 단절 위험 |
| 에너지 | 단말 배터리 | 비행+통신 배터리 공유 | 라우팅 오버헤드 |
| 라우팅 | AODV/OLSR 등 | GPSR·예측 기반 필요 | 위치·속도 활용 |

> 요약: FANET은 3D 이동성과 배터리 제약 때문에 위치 기반·예측 기반 라우팅으로 경로 단절을 줄인다.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존/대안 | FANET | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | 단일 드론-GCS 링크 | UAV 다중 홉 네트워크 | 넓은 임무 영역·가시선 제한 |
| 비용/성능 | 지상 중계기 설치 | 드론 자체 중계 | 임시망·재난망·단기 임무 |
| 운영/위험 | 고정 경로 | 이동 경로와 라우팅 동시 관리 | 비행 안전·링크 단절 |

> 요약: FANET은 고정 인프라 설치가 어렵고 임무 시간이 제한된 환경에서 다중 드론 중계망으로 선택한다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 경로 단절 | 고속 3D 이동과 장애물 | GPSR, link lifetime 예측 | route repair time |
| 배터리 고갈 | 중계 부하와 비행 에너지 공유 | 에너지 인지 라우팅, 임무 교대 | residual energy, flight time |
| 보안 위협 | 노드 탈취·스푸핑·재밍 | 인증, AES-256, frequency hopping | auth failure, jamming alert |

> 요약: FANET 리스크는 경로 단절, 에너지, 보안 위협을 라우팅 지표와 비행 지표로 함께 통제한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 전달률 | packet delivery ratio 90% 이상 목표 | UAV log, packet capture |
| 지연 | 임무 영상 E2E delay 기준 충족 | timestamp, GCS metric |
| 경로 복구 | route repair time 수초 이내 목표 | routing log |

> 요약: FANET 성과는 전달률, 지연, 경로 복구 시간으로 평가한다.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 — 단계별 또는 항목별):**
1. 임무 영역, 고도, 비행 속도, 드론 수를 기준으로 링크 예산과 다중 홉 커버리지 지도를 작성함
2. GPSR 또는 AODV/OLSR 조합을 시험하고 RSSI·SNR·배터리 기반 라우팅 메트릭을 적용해 route repair time을 측정함
3. UAV 인증, AES-256 암호화, 재밍 탐지, 비행 금지구역 정책을 통합해 통신 보안과 항공 안전을 함께 운영함

**결론 (2줄):**
- 기술사 판단: 단일 드론 링크로 커버되지 않는 재난·수색·임시망은 FANET을 적용하고, 고정 인프라 가능 구간은 지상 중계망을 우선 검토함
- 향후 방향: 5G/6G, 위성 백홀, AI 군집 제어가 결합되어 FANET은 자율 임무형 공중 네트워크로 발전함
