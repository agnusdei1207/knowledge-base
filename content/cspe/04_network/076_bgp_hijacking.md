## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 악의적인 해커나 설정 오류로 인해 특정 라우터가 타인의 IP 대역(Prefix)을 자신이 소유한 것처럼 허위로 광고(BGP)하여 트래픽을 가로채는 보안 공격 |
| **배경/필요성** | 신뢰 기반으로 동작하는 BGP 프로토콜의 맹점을 이용한 국가 간 인터넷 마비 및 금융 트래픽 탈취 방어 필요 |
| **출제 의도** | BGP 라우팅의 신뢰성 검증 부재 취약점과 RPKI(리소스 공개 키 기반 구조) 예방 메커니즘 평가 |

## Ⅱ. 구성요소
```text
+----------+       +----------+       +----------+
| Attacker |       | Internet |       | Victim   |
| (Fake AS)| <==== | (BGP)    | ----> | (Real AS)|
+----------+       +----------+       +----------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| AS Number | 인터넷 상에서 특정 네트워크 그룹을 식별하는 고유 자율 시스템 번호 | 국가 고유 코드 |
| Prefix (접두어) | 특정 도메인 및 기관에 할당된 IP 주소 대역 (예: 200.1.0.0/16) | 영토 주소지 |
| RPKI | 특정 IP 대역이 올바른 AS 번호에서 광고되었는지 암호학적으로 검증하는 인프라 | 디지털 부동산 등기 |

> 요약: 공격자가 더 구체적인(Longest Match) 서브넷을 광고하면 트래픽이 강제로 우회되는 치명적 공격임

## Ⅲ. 절차
```text
+----------+    +----------+    +----------+    +----------+
| 허위 광고| -> | BGP 전파 | -> | 경로 변경| -> | 탈취 성공|
+----------+    +----------+    +----------+    +----------+
```
1. 허위 광고: 공격자(AS 666)가 정상 서비스(AS 100)의 IP 대역을 자신의 것처럼 BGP 인터넷에 광고 시작
2. BGP 전파: BGP는 기본적으로 상대방 정보를 맹신하므로 인접 라우터들이 이 허위 경로를 수용 및 재광고
3. 경로 변경: 롱기스트 매치(Longest Prefix Match) 원칙에 의해 공격자의 정밀한 IP 광고가 최적 경로로 둔갑
4. 탈취 성공: 전 세계 사용자들의 접속 트래픽이 공격자 망으로 유입되어 스니핑 되거나 블랙홀 처리(마비)

> 요약: BGP의 신뢰 기반 광고 방식을 악용하여 정상적인 라우팅 테이블을 변조 후 트래픽 강제 회수함

## Ⅳ. 문제점
- BGP 프로토콜 자체에 광고하는 대상 IP 대역의 실제 소유권 검증 로직이 전혀 없음 (근본 취약점)
- 라우터 설정 오타(Fat-finger)로 인한 의도치 않은 글로벌 서비스 접속 불가 사고 수시 발생 (휴먼 에러)
- 정상 트래픽이 해커 망을 거쳐 다시 정상 목적지로 전달(MITM)될 경우 장기간 피해 인지 불가 위험

## Ⅴ. 개선방안
- [단기] 인접 ISP 간 명시적 경로 필터링(Prefix-List / Route-Map)을 엄격히 적용하여 이상 경로 광고 즉각 차단
- [중기] BGP 경로 변동 및 하이재킹 모니터링 서비스(BGPmon 등) 연동을 통해 허위 광고 탐지 및 경보 알림
- [장기] ROA(Route Origin Authorization) 등록 및 RPKI 검증 인프라 전면 도입으로 BGP 보안(BGPSEC) 기반 확립

## Ⅵ. 전망
- 글로벌 인터넷 신뢰성 보장을 위해 전 세계 ISP 및 텔레콤 통신사의 RPKI 의무 도입이 규제화될 전망임
