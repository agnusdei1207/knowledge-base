# 📖 【암기용】 개념 완전 이해

## 한눈에
- **개요**: ISO(국제표준화기구)가 제정한 **네트워크 통신의 표준 참조 모델**로, 복잡한 통신 과정을 7개의 독립적인 계층으로 나눈 지도입니다.
- **필요성**: "너희 집이랑 우리 집이랑 선 꼽는 모양이 달라!" 하던 시절, 제조사별로 제각각이던 통신 방식을 하나로 묶기 위해 등장했습니다.
- **핵심 직관**: **"모듈화와 추상화"**. 각 계층은 자신의 역할만 충실히 하고 위아래 층에는 '표준화된 서비스'만 제공합니다. 덕분에 하드웨어(L1)가 구리선에서 광섬유로 바뀌어도 웹 브라우저(L7)는 아무 문제 없이 동작합니다.

## 깊이 이해
- **배경 (모듈화의 승리)**: 1970년대 IBM의 SNA, DEC의 DECnet 등은 서로 대화가 불가능했습니다. OSI 7계층은 이 폐쇄성을 타파하고 **'이기종 간 상호운용성(Interoperability)'**을 확보하기 위해 탄생한 "법전"과 같습니다.
- **작동 원리 (데이터의 변신)**:
  - **캡슐화(Encapsulation)**: 위에서 아래로 내려갈 때마다 택배 박스를 겹겹이 쌓듯 헤더(주소, 제어정보)를 붙입니다.
  - **역캡슐화(Decapsulation)**: 아래에서 위로 올라갈 때마다 박스를 하나씩 뜯으며 최종 내용물만 전달합니다.
  - **계층 간 인터페이스**: 상위 계층은 하위 계층을 **"어떻게 돌아가는지 몰라도 쓸 수 있는 도구(Service)"**로 취급합니다.
- **7계층 핵심 암기 (Please Do Not Throw Sausage Pizza Away)**:
  1.  **Physical (물리)**: 0과 1의 비트를 전기/빛 신호로 보냄. (전선, 허브)
  2.  **Data Link (데이터링크)**: 옆집 장비와 안 싸우고 전달하기. MAC 주소 사용. (스위치)
  3.  **Network (네트워크)**: 먼 곳까지 최적의 길 찾기. IP 주소 사용. (라우터)
  4.  **Transport (전송)**: 데이터가 잘 도착했는지 확인하고 순서 맞추기. Port 사용. (TCP/UDP)
  5.  **Session (세션)**: 통신을 시작하고 끝내는 논리적 연결 관리.
  6.  **Presentation (표현)**: 암호화, 압축, 데이터 형식 변환 (ASCII vs UTF-8).
  7.  **Application (응용)**: 사용자가 쓰는 프로그램. (HTTP, FTP)

## 연결 개념
- **TCP/IP 4계층**: OSI가 '교과서'라면 TCP/IP는 '실전 요약본'입니다.
- **트러블슈팅**: "인터넷이 안 돼요!" 하면 보통 L1(랜선) -> L3(Ping) -> L7(브라우저) 순으로 확인하는 근거가 됩니다.

# 📝 【답안용】 시험 답안 템플릿

## 핵심 인사이트 (3줄 요약)
> 1. **본질**: 이기종 시스템 간 원활한 통신을 위해 기능을 7개 계층으로 구조화한 ISO 표준 참조 모델임.
> 2. **가치**: 통신 프로세스의 계층화(Layering)를 통해 복잡성 감소, 독립적 변경, 표준 인터페이스 기반 호환성 제공함.
> 3. **판단 포인트**: 현대 네트워크는 TCP/IP 기반이나, 장애 처리(Troubleshooting) 및 보안 계층화(L4-L7) 설계 시 불변의 기준임.

## Ⅰ. OSI 7계층 모델의 정의 및 설계 철학
- **정의**: 네트워크 통신의 표준화를 위해 ISO에서 제정한 개방형 시스템 상호접속(Open Systems Interconnection) 모델.
- **철학**: **계층적 추상화(Hierarchical Abstraction)**를 통해 하위 계층의 기술적 세부사항을 은폐하고 상위 계층에 일관된 서비스를 제공함.

## Ⅱ. OSI 7계층의 구조 및 주요 메커니즘

### 1. 7계층 구조도 (Logical View)
```text
+---------------------+---------------------------------------------------+
| 계층 (Layer)        | 주요 역할 및 PDU (Protocol Data Unit)             |
+---------------------+---------------------------------------------------+
| 7. Application      | 사용자 인터페이스, HTTP/FTP/DNS (Data)            |
| 6. Presentation     | 인코딩, 압축, 암호화/복호화 (Data)                |
| 5. Session          | 대화 제어, 동기화, 체크포인트 (Data)              |
+---------------------+---------------------------------------------------+
| 4. Transport        | 종단 간 신뢰성 보장, 흐름/혼잡 제어 (Segment)     |
| 3. Network          | 최적 경로 결정(Routing), 논리적 주소 (Packet)     |
| 2. Data Link        | 인접 노드 간 전송, 물리 주소(MAC) (Frame)         |
| 1. Physical         | 비트 스트림의 물리적 전송 (Bit)                   |
+---------------------+---------------------------------------------------+
```

### 2. 핵심 프로세스: Encapsulation & Decapsulation
- **Encapsulation**: 상위 PDU에 해당 계층의 제어 정보(Header/Trailer)를 추가하여 하위로 전달하는 수직적 과정.
- **Peer-to-Peer 통신**: 물리적으로는 계층을 오가지만, 논리적으로는 송신측 N계층과 수신측 N계층이 직접 대화함.

## Ⅲ. 주요 계층별 기술적 핵심 요소

### 1. 데이터링크(L2)와 네트워크(L3)의 경계
- **L2 (MAC)**: 단일 네트워크(Link) 내에서의 장비 식별. 인접 노드 간의 에러 탐지(CRC)와 흐름 제어 담당.
- **L3 (IP)**: 다중 네트워크를 가로지르는 호스트 간의 전송. 라우팅 알고리즘(OSPF, BGP)을 통한 최적 경로 산출.

### 2. 전송 계층(L4)의 종단 간 신뢰성
- **Mechanism**: 3-Way Handshake(연결), Window Size(흐름), Timeout/Retransmission(오류), Slow Start(혼잡).
- **Service 식별**: 포트(Port) 번호를 통해 호스트 내 여러 프로세스(HTTP:80, SSH:22)를 구분.

## Ⅳ. OSI 7계층 vs TCP/IP 4계층 심층 비교

| 비교 항목 | OSI 7 Layer (De-jure) | TCP/IP (De-facto) |
|:---:|:---|:---|
| **설계 배경** | 이론적 완결성과 표준화 우선 | 실용적 통신과 인터넷 구현 우선 |
| **계층 결합** | 5, 6, 7계층을 엄격히 구분 | Application 계층으로 통합 관리 |
| **신뢰성** | 데이터링크 및 전송 계층 모두 담당 | 전송 계층(TCP)에서 집중 관리 |
| **유연성** | 새로운 프로토콜 추가가 엄격함 | 계층 간 경계가 유연하여 확장이 빠름 |

## Ⅴ. 현대 네트워크 환경에서의 OSI 모델 활용 방안

### 1. 보안의 계층화 (Defense in Depth)
- **L3/L4 Firewall**: IP/Port 기반 차단 (전통적 보안).
- **L7 WAF/IPS**: 애플리케이션 페이로드 분석, SQL 인젝션 차단 (심층 보안).
- **Micro-segmentation**: 클라우드 내 가상 네트워크(VPC) 레벨에서의 계층적 보안 그룹 적용.

### 2. 가시성(Visibility) 및 장애 처리
- **Bottom-Up**: 물리 연결 확인 후 계층적으로 상승. 케이블 불량, 링크 다운 등 물리 장애 해결 시 유효.
- **Top-Down**: 애플리케이션 로그 분석 후 하위 확인. 소프트웨어 결함이나 설정 오류 해결 시 유효.

## Ⅵ. 기술사적 통찰: '보이지 않는 8계층'과 미래 전망
- **The 8th Layer (User/Policy)**: 기술적 7계층 위에 '사람'과 '정책'이라는 비공식 계층이 존재함. 최종적인 통신 목적은 인간의 의사결정 지원임.
- **가상화의 파동**: SDN/NFV 기술로 인해 하드웨어와 소프트웨어가 분리되면서, 물리적 장비(Switch/Router)보다 논리적 계층 기능 구현이 더 중요해진 시대임.
- **결론**: OSI 7계층은 구시대의 유물이 아니라, 6G와 위성 통신 등 극한의 복잡도를 가진 미래 네트워크 인프라를 지탱하는 **"가장 강력한 논리적 근간"**임.
