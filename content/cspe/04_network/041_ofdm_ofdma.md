# 📖 【암기용】 개념 완전 이해

> 목적: OFDM·OFDMA를 처음 봐도 완벽히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 넓은 주파수 채널을 직교 부반송파로 나누어 전송·접속하는 무선 다중화 방식
- **왜 필요한가**: 하나의 넓은 채널은 다중경로 페이딩과 심볼 간 간섭에 취약하다. OFDM은 부반송파로 나누어 간섭을 줄이고, OFDMA는 사용자별 자원블록을 나누어 동시 접속을 처리한다.
- **핵심 직관**: 큰 도로 1개를 여러 차선으로 쪼개고, OFDMA는 차선 묶음을 차량별로 배정하는 방식이다.

## 깊이 이해
- **배경·문제의식**: 광대역 무선은 산란·반사로 수신 신호가 여러 경로를 거쳐 도착한다. 단일 반송파는 등화기가 복잡하지만, OFDM은 채널을 좁은 부채널로 나누어 각 부채널을 평탄 페이딩으로 처리한다.
- **작동 원리**: 송신기는 QAM 심볼을 여러 부반송파에 배치하고 IFFT로 시간 영역 신호를 만든다. Cyclic Prefix(CP)를 붙여 지연 확산을 흡수하고, 수신기는 FFT 후 파일럿 기반 채널 추정과 등화를 수행한다.
- **비유**: 합창단이 같은 음을 크게 부르면 울림이 섞이지만, 서로 다른 음높이로 정확히 맞춰 부르면 동시에 들려도 구분된다. 직교성이 그 구분 기준이다.
- **구체 예시**: LTE는 15 kHz 부반송파 간격, 12개 부반송파를 1 Resource Block으로 묶고 1 ms TTI 단위로 스케줄링한다.
- **흔한 오해·주의점**: OFDM은 다중화 방식이고 OFDMA는 다중 접속 방식이다. OFDM 자체는 한 사용자 전송에도 쓰이며, OFDMA는 부반송파·시간 자원을 사용자별로 나눈다.

## 연결 개념
- MIMO - 부반송파와 공간 스트림을 결합해 주파수·공간 자원을 동시에 활용
- 5G NR Numerology - 15/30/60/120 kHz 부반송파 간격 선택
- PAPR - OFDM 송신 전력증폭기 설계의 대표 제약

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.
> 핵심: OFDM과 OFDMA를 혼용하지 않고, 직교 부반송파·CP·자원블록 스케줄링을 연결해 무선 접속 설계 관점으로 답안을 구성한다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: OFDM은 광대역 채널을 직교 부반송파로 분할하는 변조·다중화 방식이고, OFDMA는 그 부반송파 자원을 사용자별로 배정하는 다중 접속 방식이다.
> 2. **가치**: CP와 FFT/IFFT 기반 처리로 다중경로 간섭을 통제하고, Resource Block 단위 스케줄링으로 사용자별 주파수 선택적 할당을 수행한다.
> 3. **판단 포인트**: 직교성 유지, CP 오버헤드, PAPR, 채널 추정 정확도, 사용자 스케줄링 공정성을 함께 평가해야 한다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 광대역 무선 전송 원리 확인 | FFT/IFFT, 직교 부반송파, CP, 파일럿 등화 | OFDM을 단순 주파수 분할로만 설명 |
| 다중 접속 설계 판단 확인 | OFDMA의 시간·주파수 자원블록 사용자 배정 | OFDM과 OFDMA 역할 혼동 |
| 실무 제약 인식 확인 | PAPR, 동기 오차, CP 오버헤드, 인접채널 누설 | 수치·제약 없이 장점만 나열 |

> 요약: 이 문제는 OFDM 물리계층 원리와 OFDMA 자원 스케줄링 차이를 구분하는 답안을 요구한다.

## Ⅰ. 개요 및 필요성

OFDM·OFDMA는 직교 부반송파 기반 광대역 무선 전송·접속 방식이다. Wi-Fi, LTE, 5G NR은 다중경로와 주파수 선택적 페이딩을 줄이기 위해 OFDM 계열을 사용한다. 시험 답안은 변조 원리보다 직교성, CP, 스케줄링, PAPR 제약을 함께 제시해야 한다.

---

## Ⅱ. 구조 및 구성요소

```text
Bit Stream -> QAM Mapping -> Subcarrier Mapping -> IFFT -> CP Insert -> RF
User A/User B/User C
  / OFDMA Scheduler -> Time-Frequency Resource Block Allocation
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 부반송파 (Subcarrier) | 전체 대역폭을 직교 주파수 단위로 분할 | LTE 15 kHz, 5G NR 15/30/60/120 kHz |
| IFFT/FFT | 주파수 영역 심볼과 시간 영역 파형 변환 | 수신 FFT 윈도우 동기 필요 |
| CP (Cyclic Prefix) | 지연 확산으로 인한 ISI 흡수 | 유효 심볼 대비 오버헤드 발생 |
| OFDMA Scheduler | 사용자별 시간·주파수 자원 배정 | CQI, QoS, HARQ 상태 반영 |

> 요약: OFDM은 부반송파·FFT·CP로 전송 파형을 만들고, OFDMA는 스케줄러가 자원블록을 사용자별로 배정한다.

---

## Ⅲ. 동작원리 및 흐름도

```text
채널 품질 측정 -> 자원블록 배정 -> QAM 심볼 매핑 -> IFFT/CP 전송
-> FFT 수신 -> 파일럿 채널추정 -> 등화/복조 -> HARQ 피드백
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | CQI·SINR 기반 사용자별 채널 품질 수집 | CQI 보고 주기, BLER 10% 목표 |
| 2 | 시간·주파수 Resource Block 할당 | PF Scheduler, GBR/Non-GBR QoS |
| 3 | QAM 심볼을 부반송파에 매핑 후 IFFT 수행 | EVM, 인접채널 누설 ACLR |
| 4 | CP 삽입 후 다중경로 채널 전송 | CP 길이 >= 채널 지연 확산 |
| 5 | FFT·채널추정·등화 후 HARQ 처리 | BLER, 재전송률, throughput |

> 요약: OFDMA는 채널 품질 측정에서 자원 배정, OFDM 변조, 수신 등화, HARQ 피드백으로 반복 동작한다.

## Ⅳ. 특징

| 구분 | 기존 단일 반송파 | OFDM·OFDMA | 수치·판단 포인트 |
|:---|:---|:---|:---|
| 다중경로 대응 | 복잡한 시간영역 등화기 필요 | 부반송파별 1-tap 등화 가능 | CP 길이와 지연 확산 비교 |
| 접속 방식 | TDMA/FDMA 고정 분할 | 사용자별 RB 동적 배정 | CQI 기반 주파수 선택 스케줄링 |
| 제약 | PAPR 낮음 | PAPR 증가로 PA back-off 필요 | DFT-s-OFDM, clipping 검토 |
| 동기 | 상대적으로 단순 | 주파수 오차가 직교성 훼손 | CFO, phase noise 측정 |

> 요약: OFDM·OFDMA는 다중경로와 자원 배정에 유리하나 PAPR과 동기 오차를 설계 제약으로 관리해야 한다.

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존/대안 | OFDM·OFDMA | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | 단일 반송파, TDMA | 다중 부반송파, RB 스케줄링 | 광대역 채널·다중 사용자 동시 접속 |
| 비용/성능 | RF 구조 단순, 등화 복잡 | FFT 처리 필요, 등화 단순 | DSP 처리량과 PA 선형성 비용 |
| 운영/위험 | 자원 고정 | CQI 기반 동적 자원 | 셀 부하, QoS, BLER 목표 |

> 요약: 광대역·다중 사용자 환경이면 OFDMA, 저전력 단말 업링크 PAPR 제약이면 DFT-s-OFDM 계열을 검토한다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| PAPR 증가 | 다수 부반송파 위상 합성 | PA back-off, clipping, DFT-s-OFDM | PAPR CCDF, ACLR |
| 직교성 훼손 | 주파수 오차·위상 잡음 | CFO 보정, 파일럿 추적 | EVM, subcarrier interference |
| CP 오버헤드 | 채널 지연 확산 대비 CP 삽입 | Numerology·CP 길이 선택 | 유효 전송률, BLER |

> 요약: OFDM 품질은 PAPR, 동기, CP 오버헤드를 EVM·ACLR·BLER 지표로 통제할 때 확보된다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 무선 품질 | BLER 10% 이하, EVM 규격 만족 | 단말 로그, 계측기, Drive Test |
| 자원 활용 | RB utilization, cell throughput | eNB/gNB PM 카운터 |
| RF 적합성 | ACLR, spectrum mask 준수 | 스펙트럼 분석기, 3GPP RF 시험 |

> 요약: 도입 후 평가는 BLER·EVM·RB 활용률·ACLR을 함께 측정해 물리계층과 스케줄링을 동시에 점검한다.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 - 단계별 또는 항목별):**
1. LTE/5G 셀 설계: 15/30/60 kHz numerology, CP 길이, PRB 대역폭을 셀 반경·지연 확산 기준으로 선정함
2. 스케줄링 설계: CQI·QoS Class·HARQ 상태를 반영해 Proportional Fair 또는 QoS-aware Scheduler 적용함
3. RF 검증: PAPR CCDF, EVM, ACLR, BLER 10% 목표를 계측기와 gNB 로그로 교차 확인함

**결론 (2줄):**
- 기술사 판단: 광대역 셀룰러·Wi-Fi는 OFDM·OFDMA가 기본이며, 업링크 전력 제약이 크면 DFT-s-OFDM 적용 여부를 판단함
- 향후 방향: 5G NR 이후 numerology·massive MIMO·AI 기반 스케줄링과 결합해 주파수 자원 제어 정밀도를 높이는 방향임
