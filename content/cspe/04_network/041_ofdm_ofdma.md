## 핵심 인사이트 (3줄 요약)
> 1. **본질**: OFDM은 고속의 데이터를 여러 개의 느린 하위 반송파(Sub-carrier)로 쪼개어 동시에 전송함으로써 전파의 간섭과 왜곡을 이겨내는 물리 계층의 변조 기술이며, OFDMA는 이를 다수의 사용자에게 쪼개어 나누어주는 다중 접속 기술이다.
> 2. **원리**: 서로 겹쳐도 간섭이 없는 '직교성(Orthogonality)'을 이용해 주파수 대역을 촘촘히 포개어 대역폭 낭비를 없애고(OFDM), 이 촘촘한 주파수 덩어리(RU)를 수많은 기기에게 테트리스 조각처럼 동시다발적으로 할당한다(OFDMA).
> 3. **판단 포인트**: OFDM은 4G LTE와 Wi-Fi 5의 근간 기술로 속도를 높였고, OFDMA는 5G와 Wi-Fi 6(ax)의 핵심으로 등장하여 고밀도 접속 환경에서의 통신 지연(Latency)과 자원 배분의 효율성을 혁신적으로 개선했다.

---
## Ⅰ. 개요 및 필요성

- **개요**: 
  - **OFDM (Orthogonal Frequency Division Multiplexing)**: 하나의 넓은 주파수 대역을 간섭이 없는(직교하는) 수많은 좁은 대역(Sub-carrier)으로 쪼개서 한 명에게 병렬로 데이터를 쏘는 '변조 방식'.
  - **OFDMA (Orthogonal Frequency Division Multiple Access)**: OFDM으로 쪼개진 수많은 Sub-carrier들을 묶어서 여러 명의 사용자에게 동시에 나누어 할당하는 '다중 접속 방식'.
- **필요성**: 무선 전파는 빌딩에 부딪혀 여러 갈래로 들어오는 다중 경로 페이딩(Multipath Fading) 때문에 고속으로 쏘면 데이터가 뭉개진다(ISI 발생). 이를 막으려면 데이터를 아주 느리게 쏴야 하는데, 느리게 쏘면서도 전체 속도는 올리려면 **"데이터를 수천 갈래로 쪼개서 병렬로 천천히 동시에 쏘는"** 기술(OFDM)이 절대적으로 필요했다.

---
## Ⅱ. 아키텍처 및 핵심 원리

- **FDM vs OFDM vs OFDMA의 스펙트럼 및 할당 도식**

```text
[ 기존 FDM ]           [ OFDM (직교성으로 밀집) ]     [ OFDMA (시간+주파수 다중할당) ]
/\  /\  /\             /\/\/\/\/\                  Sub-carrier
| | | | | |            | | | | |                 (User A) ▩▩  □□ (User B)
| | | | | |            | | | | |                 (User B) ▩▩  □□ (User B)
| | | | | |            | | | | |                 (User C) ▨▨  ▩▩ (User A)
-----------            -----------                     T1      T2   (시간)
(사이에 보호대역 낭비)     (서로 겹쳐도 간섭 없음)         (테트리스처럼 여러명 동시 수용)
```

- **핵심 원리**:
  1. **직교성 (Orthogonality)**: 여러 전파 파동이 겹치더라도, 한 파동이 최고점(Peak)일 때 다른 파동들이 정확히 0(Zero)의 값을 지나도록 수학적(IFFT/FFT)으로 파형을 꼬아놓았다. 덕분에 주파수 사이에 빈 공간(Guard Band)을 둘 필요 없이 촘촘하게 겹쳐서 꽉꽉 눌러 담을 수 있다 (대역폭 효율성 극대화).
  2. **OFDM의 다중경로 극복**: 100km/h로 차 1대를 보내면 사고(간섭) 나기 쉬우니, 차 100대를 1km/h로 천천히(심볼 주기 연장), 하지만 옆으로 나란히(병렬) 달리게 하는 원리다. 중간에 방지턱(지연)을 만나도 천천히 달리므로 충돌(ISI)이 적다.
  3. **OFDMA의 RU(Resource Unit) 할당**: Wi-Fi 6부터 도입. 큰 트럭(주파수 채널)을 혼자 독점하는 게 아니라, 트럭 짐칸을 수십 개의 작은 박스(RU)로 나눈 뒤, 사용자 A에겐 2박스(카톡), B에겐 10박스(유튜브)를 한 번에 실어 보내는 자원 분할의 예술이다.

## Ⅲ. 비교 및 연결

| 비교 항목 | FDM (고전적 분할) | OFDM (속도 혁명) | OFDMA (다중접속 효율 혁명) |
|:---|:---|:---|:---|
| **주파수 겹침 여부** | 겹치면 안 됨 (Guard Band 필수) | **직교성을 이용해 촘촘히 겹침** | **직교성 이용 (OFDM과 동일)** |
| **대역폭 활용도** | 낮음 (낭비가 심함) | **매우 높음** | **매우 높음** |
| **시간당 접속자 수**| 1채널 당 1명 (채널 수 제한) | 1개의 전체 채널을 1명이 독점 | **1개의 전체 채널을 수십 명이 동시 공유** |
| **가장 큰 장점** | 구조가 단순함 | 다중경로(건물 반사파) 간섭에 강함| 혼잡 지역에서 대기 시간(Ping) 대폭 감소 |
| **적용 표준** | 1G 아날로그 통신, 라디오 | Wi-Fi 4/5, LTE(Downlink) | **Wi-Fi 6/7, 5G NR** |

## Ⅳ. 실무 적용 및 기술사 판단

- **밀집 환경(스타디움, 오피스)에서의 고질적 Ping 문제 해결**
  - 문제: 기존 Wi-Fi 5(OFDM) 환경에서는 강당에 100명이 모여 카카오톡 한 줄만 보내도, 한 명이 채널을 쓰는 동안 나머지 99명은 무조건 대기(Wait)해야 하므로 랙이 심하게 걸렸다.
  - 판단/조치: 기술사는 고밀도 사용자 환경의 무선망 설계 시 반사파 간섭에 강한 단순 MIMO 기술을 넘어, 반드시 **OFDMA 기술이 탑재된 Wi-Fi 6 이상**의 AP 장비를 제안해야 한다. OFDMA를 적용하면 AP가 지휘자가 되어 100명의 데이터를 하나의 주파수 채널에 잘게 구획(RU)하여 1번의 전송으로 동시다발적으로 처리하므로 지연(Latency) 병목이 완전히 해소된다.

- **PAPR (Peak-to-Average Power Ratio) 문제**
  - OFDM의 가장 큰 단점은 수만 개의 파동이 우연히 한 지점에서 꼭대기로 합쳐지면 전력이 미친 듯이 솟구치는 PAPR 현상이다. 스마트폰(업링크)에서 이걸 쏘려면 배터리가 순식간에 닳고 증폭기가 타버린다. 따라서 LTE/5G의 단말 $\rightarrow$ 기지국 방향(업링크)에서는 OFDM 대신 전력 소모가 적은 **SC-FDMA**를 사용하는 아키텍처적 차이를 인지해야 한다.

---
## Ⅴ. 기대효과 및 결론

- **결론**: OFDM은 무선 주파수의 낭비를 없앤 물리적 예술이며, OFDMA는 이 아까운 자원을 쪼개 여러 명이 사이좋게 쓸 수 있게 한 스케줄링의 진수이다.
- **기대효과**: OFDMA의 도입으로 IoT 기기 수만 대가 동시에 붙는 스마트 팩토리나 초밀집 경기장에서도 끊김 없는 5G 및 Wi-Fi 서비스가 가능해졌으며, 한정된 주파수 자원(Spectrum)의 활용도를 인류 기술의 극단까지 끌어올렸다.

### 📌 관련 개념 맵
다중경로 페이딩(Multipath Fading) $\rightarrow$ ISI(심볼 간 간섭) $\rightarrow$ 직교성(Orthogonality) $\rightarrow$ OFDM $\rightarrow$ Resource Unit(RU) $\rightarrow$ OFDMA.

### 📈 관련 키워드 및 발전 흐름도
`TDMA/CDMA (2G/3G)` $\rightarrow$ `OFDM 단독 사용 (초기 무선랜, Wi-Fi 4/5)` $\rightarrow$ `LTE 다운링크에 OFDMA 채택` $\rightarrow$ `Wi-Fi 6 (802.11ax)에 OFDMA 전격 도입 (고밀도 해결)` $\rightarrow$ `5G NR (뉴 라디오, 유연한 OFDMA 활용)`

### 👶 어린이를 위한 3줄 비유 설명
1. **FDM**은 차선 사이에 넓은 잔디밭(안전지대)을 둬서 차들이 부딪히지 않게 넓게 만든 낭비 심한 도로입니다.
2. **OFDM**은 컴퓨터로 차들의 핸들을 정밀하게 제어해서 잔디밭을 다 없애고 차선만 빽빽하게 그어놔서, 같은 도로폭에 훨씬 많은 차가 안전하게 달리게 만든 마법의 도로입니다.
3. **OFDMA**는 이 빽빽한 도로 위에 거대한 트럭 한 대만 달리는 게 아니라, 작은 오토바이 수십 대가 각자 자기 차선을 배정받아 동시에 요리조리 달릴 수 있게 교통정리를 해주는 똑똑한 경찰관입니다.
