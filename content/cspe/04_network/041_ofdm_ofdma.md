## 미리 알고가기

- 부반송파는 큰 주파수 대역을 잘게 나눈 작은 전송 단위임
- 직교성은 여러 부반송파가 주파수상으로 겹쳐 보여도 서로 간섭하지 않게 만드는 수학적 성질임
- OFDM은 한 사용자 데이터 흐름을 여러 부반송파에 병렬로 실어 보내는 방식임
- OFDMA는 그 부반송파 묶음을 여러 사용자에게 나누어 동시에 쓰게 하는 방식임
- RU는 Wi-Fi에서 OFDMA 자원을 나눌 때 사용하는 부반송파 묶음 단위임

## Ⅰ. 개요

- **정의/개념**: OFDM은 넓은 대역을 여러 직교 부반송파로 나누어 병렬 전송하는 변조 방식이고, OFDMA는 그 자원을 시간과 주파수 단위로 여러 사용자에게 나누는 다중 접속 방식임
- **배경/필요성**: 무선 채널의 다중 경로 지연과 다수 단말 경합을 줄이려면 직교 부반송파와 사용자별 시간·주파수 자원 배분이 필요함

## Ⅱ. 특징

- OFDM은 낮은 속도의 직교 부반송파로 나누고 보호 구간을 두어 다중 경로 지연의 영향을 줄임
- 직교 부반송파를 촘촘히 배치해 보호 대역 낭비를 줄일 수 있음
- OFDMA는 부반송파 묶음을 사용자별로 배정하여 짧은 패킷 전송 시 채널 대기와 경합을 줄임
- OFDM 계열은 전력 피크가 커질 수 있어 단말 송신단 설계와 스케줄링 정책을 함께 봐야 함

## Ⅲ. 종류 및 비교

| 판단 기준 | OFDM | OFDMA |
|:---|:---|:---|
| 자원 사용 주체 | 보통 한 시점에 한 사용자나 한 전송 흐름이 전체 채널을 사용함 | 한 시점에 여러 사용자가 채널 일부를 나누어 사용함 |
| 주된 목적 | 고속 병렬 전송과 다중 경로 대응이 중심임 | 다수 단말 동시 수용과 지연 감소가 중심임 |
| 스케줄링 필요성 | 상대적으로 단순하며 사용자 분할 개념이 약함 | 기지국이나 AP가 RU 배분과 우선순위를 세밀하게 제어해야 함 |
| 대표 적용 | 초기 무선 LAN, LTE 하향링크 같은 전송 계층 기반 기술에 널리 쓰임 | Wi-Fi 6/7, 5G NR처럼 고밀도 접속 환경에 적합함 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 부반송파 집합 | 전체 대역을 잘게 나눠 병렬 전송이 가능하게 하는 기본 단위임 |
| IFFT/FFT 처리 | 송신 측은 데이터를 시간 영역 신호로 합성하고 수신 측은 다시 주파수 영역으로 분리함 |
| 보호 구간 | 심볼 사이에 여유 구간을 두어 지연 확산에 따른 간섭을 줄이는 장치임 |
| 스케줄러와 RU | OFDMA에서 사용자별 자원 크기와 위치를 정하는 제어 요소임 |

```text
+-----------+     +-------------+     +-------------+     +-------------+
| 데이터 분할 | --> | 부반송파 매핑 | --> | 병렬 전송     | --> | 사용자별 배분 |
+-----------+     +-------------+     +-------------+     +-------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+     +-------------+
| 비트 입력     | --> | 부반송파 배치 | --> | OFDM 신호 생성 | --> | 사용자 자원 할당 | --> | 수신 복원     |
+-------------+     +-------------+     +-------------+     +-------------+     +-------------+
```

1. **비트 입력**: 송신할 데이터를 변조 심볼로 바꿈
2. **부반송파 배치**: 각 심볼을 여러 부반송파에 나누어 배치함
3. **OFDM 신호 생성**: IFFT와 보호 구간 삽입으로 실제 전송 파형을 만듦
4. **사용자 자원 할당**: OFDMA 환경에서는 AP나 기지국이 사용자별 RU와 시간 슬롯을 할당함
5. **수신 복원**: 수신 측이 FFT와 채널 보정을 통해 원래 데이터를 복원함

## Ⅵ. 실무 적용 및 유의점

1. 강의장, 경기장, 사무실처럼 짧은 트래픽이 동시에 몰리는 무선망에서는 OFDMA 기반 장비와 스케줄링 튜닝이 효과적이지만 RU 분배가 거칠면 지연이 다시 커질 수 있으므로 평균 지연, 채널 이용률, 사용자별 재전송률로 상태를 확인함
2. 이동통신 단말 송신부에서는 OFDM 계열의 전력 피크 부담이 커질 수 있으므로 전력 증폭기 여유와 배터리 소모를 함께 고려하고 송신 전력 효율, 열 제한, 업링크 처리량으로 설계 적정성을 확인함

## Ⅶ. 결론

OFDM은 무선 채널을 효율적으로 쓰기 위한 전송 기반이고 OFDMA는 그 기반을 여러 사용자에게 나누는 운영 방식이므로, 둘을 구분해야 무선 성능 문제의 원인을 정확히 판단할 수 있음.
