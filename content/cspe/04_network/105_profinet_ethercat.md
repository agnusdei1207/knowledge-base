## 미리 알고가기

- PLC는 생산 설비를 주기적으로 제어하는 산업용 제어기임
- 주기 시간은 제어 명령과 상태 값을 한 번 주고받는 반복 간격임
- 분산 클록은 여러 장치의 시간을 정밀하게 맞춰 동시 제어를 가능하게 하는 기능임
- 패스스루 처리는 프레임이 장치를 지나가는 동안 필요한 데이터만 즉시 읽고 쓰는 방식임

## Ⅰ. 개요

- **정의/개념**: Profinet과 EtherCAT은 이더넷 기반으로 산업 설비를 실시간 제어하기 위해 만든 대표 산업용 통신 방식임
- **배경/필요성**: 로봇과 서보와 고속 I/O 제어는 일반 사무용 이더넷 수준의 지연 편차로는 안정성이 떨어지므로 짧은 주기와 예측 가능한 통신 구조가 필요함

## Ⅱ. 특징

- 둘 다 이더넷을 기반으로 하지만 실시간성을 확보하는 방식이 다름
- Profinet은 RT와 IRT 같은 등급 구조로 적용 범위를 넓게 가져감
- EtherCAT은 프레임이 지나가며 데이터를 바로 처리해 매우 짧은 주기 제어에 유리함
- 상위 시스템 연동성, 장비 생태계, 요구 주기에 따라 선택 기준이 달라짐

## Ⅲ. 종류 및 비교

| 판단 기준 | Profinet | EtherCAT |
|:---|:---|:---|
| 실시간 구현 방식 | 등급별 실시간 제어와 스위치 기반 구성이 중심임 | 프레임 통과 중 즉시 처리하는 방식이 중심임 |
| 장점 | 범용 설비 연동과 네트워크 관리가 비교적 유연함 | 짧은 주기와 높은 동기 정밀도에 유리함 |
| 적합한 환경 | 혼합 자동화 라인과 제조 통합 | 모션 제어와 초정밀 동기 제어 |
| 주의점 | 구성 복잡도와 등급 선택이 중요함 | 토폴로지와 케이블 품질과 분산 클록 관리가 중요함 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 제어기 | PLC가 주기 통신을 시작하고 전체 제어 흐름을 관리함 |
| 현장 장치 | I/O 모듈과 드라이브와 로봇 장치가 제어 대상이 됨 |
| 통신 경로 | Profinet은 스위치 기반 구성이 흔하고 EtherCAT은 선형 연결이 자주 쓰임 |
| 실시간 제어 기능 | 우선순위, 시간 동기, 순환 데이터 처리를 담당함 |
| 진단 기능 | 링크 상태와 장치 오류와 주기 손실을 운영자가 확인하게 해 줌 |

```text
+---------+    +------------------+    +------------------+
| PLC     | -> | Profinet 또는 EtherCAT | -> | 현장 장치들         |
+---------+    +------------------+    +------------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
| 주기 설정      | -> | 장치 동기화    | -> | 제어 프레임 전송 | -> | 상태 수집      | -> | 진단·보정      |
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
```

1. **주기 설정**: 공정 요구에 맞게 통신 주기를 정함
2. **장치 동기화**: 각 장치 시간을 맞춰 같은 시점에 동작하게 함
3. **제어 프레임 전송**: 제어기가 명령과 설정을 현장 장치로 보냄
4. **상태 수집**: 장치가 상태 값과 오류 정보를 다시 올림
5. **진단과 보정**: 주기 이탈이나 통신 오류가 있으면 설정을 조정함

## Ⅵ. 실무 적용 및 유의점

1. 서보와 로봇이 많은 고속 모션 제어는 EtherCAT이 잘 맞지만 분산 클록과 선형 토폴로지 품질이 흔들리면 주기 오차가 커지므로 주기 편차와 장치 응답 시간을 계속 확인해야 함
2. 설비 종류가 다양하고 상위 제조 시스템과 연계가 많은 라인은 Profinet이 유리하지만 RT와 IRT 적용 범위를 혼용하면 설계가 복잡해지므로 요구 주기를 먼저 정하고 지연과 장치 호환성을 함께 점검해야 함

## Ⅶ. 결론

Profinet과 EtherCAT은 모두 산업용 이더넷이지만 실제 선택은 이더넷 여부가 아니라 요구 주기와 장치 생태계와 제어 정밀도 차이로 갈림
