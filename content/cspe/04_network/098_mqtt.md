## 미리 알고가기

- 발행과 구독은 보내는 쪽과 받는 쪽을 직접 연결하지 않고 주제 단위로 메시지를 주고받는 방식임
- 브로커는 발행자가 보낸 메시지를 받아 구독자에게 다시 나눠 주는 중간 서버임
- 토픽은 메시지를 분류하는 경로 이름임
- QoS 0, 1, 2는 메시지 전달 보장 수준을 단계별로 나눈 값임

## Ⅰ. 개요

- **정의/개념**: MQTT는 브로커를 중심으로 토픽 기반 발행과 구독을 수행하는 경량 메시징 프로토콜로, 연결이 불안정하거나 자원이 제한된 장치 통신에 맞게 설계됨
- **배경/필요성**: 수많은 장치가 서버와 각각 직접 연결하면 세션 관리와 재전송 부담이 커지므로, 연결을 단순화하면서도 낮은 대역폭에서 안정적으로 메시지를 나눌 구조가 필요함

## Ⅱ. 특징

- 발행자와 구독자가 서로를 몰라도 브로커를 통해 느슨하게 연결됨
- 헤더가 작고 세션 유지 기능이 있어 저전력 장치에 유리함
- QoS 단계로 전달 보장 수준을 조절할 수 있음
- 토픽 체계와 보관 메시지 설계를 잘못하면 운영 복잡도가 빠르게 커질 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | MQTT | HTTP | CoAP |
|:---|:---|:---|:---|
| 통신 모델 | 발행·구독 중심 | 요청·응답 중심 | 요청·응답 중심 |
| 연결 특성 | 장기 연결 세션 운영에 유리함 | 요청마다 처리하기 쉬움 | 가벼운 UDP 기반 통신에 유리함 |
| 적합한 환경 | 센서 데이터 수집, 상태 알림 | 일반 웹 API 연동 | 제한 자원 장치 제어 |
| 주의점 | 브로커 장애와 토픽 설계가 중요함 | 오버헤드가 큼 | 재전송과 보안 설계가 별도 고려 대상임 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 발행자 | 센서나 장치가 데이터를 토픽에 올리는 주체임 |
| 브로커 | 세션을 관리하고 메시지를 적절한 구독자에게 전달함 |
| 구독자 | 필요한 토픽을 등록하고 메시지를 받는 응용이나 장치임 |
| 토픽 구조 | 메시지를 업무나 장치 단위로 분류하는 기준임 |
| 세션과 인증 | 연결 유지와 접근 제어와 메시지 보호를 담당함 |

```text
+---------+    +---------+    +---------+
| 발행자   | -> | 브로커   | -> | 구독자   |
+---------+    +---------+    +---------+
      \            |
       \-----------+---- 토픽 기준 분배
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
| 연결 수립      | -> | 토픽 구독      | -> | 메시지 발행    | -> | 브로커 분배    | -> | 확인 응답      |
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
```

1. **연결 수립**: 장치가 브로커에 접속하고 세션을 만듦
2. **토픽 구독**: 수신 측이 필요한 토픽을 등록함
3. **메시지 발행**: 송신 측이 토픽과 데이터와 QoS를 붙여 보냄
4. **브로커 분배**: 브로커가 토픽을 기준으로 구독자에게 전달함
5. **확인 응답**: QoS 수준에 따라 재전송이나 확인 절차를 수행함

## Ⅵ. 실무 적용 및 유의점

1. 설비 상태 수집과 모바일 기기 푸시처럼 연결 유지가 중요한 환경은 MQTT가 잘 맞지만 토픽을 무질서하게 늘리면 구독 관리가 어려워지므로 계층형 토픽 규칙을 먼저 정하고 연결 수와 메시지 지연과 미전달 건수를 함께 봐야 함
2. 브로커를 단일 지점으로 두면 장애 영향이 크므로 이중화와 세션 복구 전략을 같이 설계하고 브로커 가용성과 재연결 시간과 메시지 적재량을 계속 확인해야 함

## Ⅶ. 결론

MQTT의 강점은 가벼움 자체보다 많은 장치를 느슨하게 연결하면서도 전달 보장 수준을 조절할 수 있다는 점에 있음
