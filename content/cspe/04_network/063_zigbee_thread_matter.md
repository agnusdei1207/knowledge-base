## 미리 알고가기

- Zigbee는 저전력 메시 통신을 제공하는 비 IP 기반 스마트홈 프로토콜임
- Thread는 802.15.4 위에서 IPv6를 쓰는 저전력 메시 네트워크 프로토콜임
- Matter는 기기 제어 명령과 상호 운용 방식을 통일하는 응용 계층 표준임
- Border Router는 Thread 망과 Wi-Fi·유선 IP 망을 이어 주는 장치임
- Commissioning은 새 기기를 네트워크와 제어 시스템에 안전하게 등록하는 초기 설정 절차임

## Ⅰ. 개요

- **정의/개념**: Zigbee와 Thread와 Matter는 스마트홈과 저전력 IoT를 구성하는 서로 다른 계층의 기술로, Zigbee는 초기 저전력 메시망을 대표하고 Thread는 IP 기반 저전력 메시망을 제공하며 Matter는 그 위에서 기기 제어 호환성을 맞춤
- **배경/필요성**: 스마트홈은 배터리 센서와 조명과 잠금장치가 함께 동작해야 하는데 제조사마다 연결 방식과 제어 방식이 달라 호환성과 확장성이 떨어졌으므로, 저전력 통신과 IP 연결성과 공통 제어 규격이 함께 필요했음

## Ⅱ. 특징

- Zigbee는 저전력과 메시 구성이 강점이지만 허브와 벤더별 차이로 상호 운용성이 약할 수 있음
- Thread는 IPv6 기반이라 IP 망과의 연결이 자연스럽고 Border Router로 확장하기 쉬움
- Matter는 특정 무선 기술이 아니라 기기 제어와 인증과 상호 운용 규칙을 표준화함
- 실제 구축에서는 통신망 선택과 제어 표준 선택을 분리해 생각해야 함

## Ⅲ. 종류 및 비교

| 판단 기준 | Zigbee | Thread | Matter |
|:---|:---|:---|:---|
| 주된 계층 | 저전력 무선망과 상위 프로파일을 함께 다룸 | 저전력 IP 메시 네트워크 계층을 담당함 | 응용 계층의 공통 제어 규격을 담당함 |
| IP 기반 여부 | 직접적인 IP 기반이 아님 | IPv6 기반으로 동작함 | Wi-Fi나 Thread 같은 IP 기반 전송로 위에서 동작함 |
| 핵심 강점 | 초기 스마트홈 메시망 구축이 쉬움 | 저전력과 IP 연동을 함께 확보하기 쉬움 | 제조사 간 제어 호환성과 사용자 경험을 높임 |
| 구축 시 주안점 | 허브 의존성과 기기 호환성을 점검해야 함 | Border Router 배치와 저전력 메시 안정성을 점검해야 함 | Commissioning과 인증서 관리와 컨트롤러 연동을 점검해야 함 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Zigbee 기기 | 센서와 조명처럼 저전력 메시망에서 동작하며 보통 허브를 통해 외부와 연결됨 |
| Thread End Device | 저전력 단말로 동작하며 Thread 메시망 안에서 IPv6 주소를 사용함 |
| Border Router | Thread 메시망을 가정의 Wi-Fi나 유선 IP 망과 이어 주는 경계 장치임 |
| Matter Controller | 스마트폰이나 허브에서 기기 등록과 제어 정책을 담당함 |
| Commissioning 보안 | 새 기기를 안전하게 등록하고 올바른 제어 권한을 배포하는 절차와 키 관리 체계임 |

```text
+-------------+     +---------------+     +---------------+     +------------------+
| Matter 제어기 | --> | Border Router | --> | Thread 메시망   | --> | 센서·조명·잠금장치 |
+-------------+     +---------------+     +---------------+     +------------------+
          공통 제어             IP 경계 연결             저전력 전송                실제 기기
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+     +-------------+
| 기기 전원 인가 | --> | Commissioning | --> | 망 참여·주소 부여 | --> | Matter 제어 등록 | --> | 상태·명령 교환 |
+-------------+     +-------------+     +-------------+     +-------------+     +-------------+
```

1. **기기 전원 인가**: 새 센서나 조명이 등록 대기 상태로 켜짐
2. **Commissioning**: 제어기가 기기 신원을 확인하고 네트워크 가입 절차를 시작함
3. **망 참여·주소 부여**: Thread면 IPv6 기반 메시망에 들어가고 Zigbee면 해당 허브망에 등록됨
4. **Matter 제어 등록**: Matter 지원 기기는 공통 제어 모델과 권한 정보를 교환함
5. **상태·명령 교환**: 이후 제어기와 기기가 표준화된 명령과 상태 모델로 통신함

## Ⅵ. 실무 적용 및 유의점

1. 신규 스마트홈이나 빌딩 자동화에서는 저전력 센서망과 멀티벤더 호환을 함께 원하므로 Thread와 Matter 조합을 우선 검토하되 Border Router 이중화와 Commissioning 절차가 약하면 운영이 불안정해지므로 가입 성공률, 응답 지연, 오프라인 기기 비율로 품질을 확인함
2. 기존 Zigbee 자산이 많은 환경에서는 한 번에 전면 교체하기보다 허브 연동과 단계적 전환을 설계해야 하므로 기기 호환 목록, 브리지 처리 지연, 유지보수 복잡도로 전환 비용을 확인함

## Ⅶ. 결론

Zigbee와 Thread와 Matter는 경쟁 기술이라기보다 저전력 전송과 IP 연결과 상호 운용성을 각각 해결하는 계층별 해법으로 봐야 함.
