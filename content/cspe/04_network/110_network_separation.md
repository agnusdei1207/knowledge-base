## 미리 알고가기

- 물리적 망분리는 장비와 회선을 아예 따로 두는 방식임
- 논리적 망분리는 같은 물리 자원을 쓰되 가상화나 정책으로 통신을 분리하는 방식임
- 점프 서버는 관리자가 통제된 중간 지점을 거쳐 중요 시스템에 접속하게 하는 장치임
- 자료 전송 통제는 망 사이 파일 이동을 승인과 검사 절차로 제한하는 방식임

## Ⅰ. 개요

- **정의/개념**: 망분리는 업무망과 인터넷망 또는 중요 제어망을 분리해 침해가 한 구간에서 다른 구간으로 번지는 경로를 줄이는 네트워크 보안 구조임
- **배경/필요성**: 원격 접속과 인터넷 사용이 늘면서 악성코드와 계정 탈취가 내부 중요 시스템으로 이어지기 쉬워졌으므로, 네트워크 수준에서 이동 경로를 먼저 끊어 둘 필요가 있음

## Ⅱ. 특징

- 통신 경로를 제한해 침해 구간에서 다른 업무·제어망으로의 이동을 차단함
- 물리 자원을 분리하면 공유 취약점은 줄지만 장비, 회선, 단말의 구축·운영 비용이 증가함
- 단순 분리만으로 끝나지 않고 자료 이동과 관리자 접속 절차를 함께 통제해야 함
- 논리적 분리는 운영 유연성이 크지만 정책 오류나 공유 자원 취약점에 더 민감함

## Ⅲ. 종류 및 비교

| 판단 기준 | 물리적 망분리 | 논리적 망분리 |
|:---|:---|:---|
| 분리 방식 | 장비와 회선과 단말을 따로 둠 | 가상화와 정책으로 통신을 나눔 |
| 격리 수준 | 장비와 회선을 분리해 공유 경로를 제거함 | 설정 오류와 공유 자원 취약점의 영향이 남음 |
| 변경 방식 | 장비와 회선 변경이 필요함 | 가상망과 접근 정책을 변경함 |
| 적합 환경 | 국가 중요망, 제어망, 고위험 시스템에 적합함 | 일반 사무 환경과 단계적 분리에 적합함 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 업무망 | 내부 업무 시스템이 위치한 구간임 |
| 인터넷망 | 외부 웹 접속과 메일 같은 대외 통신 구간임 |
| 중요 시스템망 | 핵심 데이터나 제어 시스템을 두는 구간임 |
| 자료 전송 구간 | 승인된 파일만 검사 후 이동시키는 통제 지점임 |
| 점프 서버·가상 데스크톱 | 관리 접속을 제한된 경로로 모으는 중간 지점임 |

```text
+---------+    승인·검사    +-------------+    통제 접속    +-------------+
| 인터넷망   | -----------> | 업무망          | -----------> | 중요 시스템망   |
+---------+                +-------------+                +-------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
[망 구간 분리] -> [허용 경로 정의] -> [자료·접속 통제] -> [로그 기록] -> [정책 점검]
```

1. **망 구간 분리**: 업무 성격과 중요도에 따라 네트워크를 나눔
2. **허용 경로 정의**: 꼭 필요한 통신만 화이트리스트로 남김
3. **자료·접속 통제**: 파일 이동과 관리자 접속을 별도 통로로 제한함
4. **로그 기록**: 이동 기록과 접속 이력을 남김
5. **정책 점검**: 우회 경로와 예외 규칙을 주기적으로 정리함

## Ⅵ. 실무 적용 및 유의점

1. 금융과 공공과 생산 제어 환경은 망분리 자체보다 망 사이 예외 통로가 더 큰 위험이므로 자료 전송 서버와 악성코드 검사와 관리자 점프 경로를 함께 묶고 비인가 연결 건수와 파일 반입 반출 기록을 같이 확인함
2. 논리적 망분리는 가상망과 정책으로 구간을 변경할 수 있지만 설정 오류가 허용 경로를 넓힐 수 있으므로 네트워크 정책 검증과 관리자 권한 분리를 운영하고 우회 통신 탐지 건수와 설정 변경 이력을 점검해야 함

## Ⅶ. 결론

망분리의 본질은 네트워크를 나누는 행위보다 예외 통로와 관리 경로까지 통제해 침해 확산 경로를 실제로 줄이는 데 있음.
