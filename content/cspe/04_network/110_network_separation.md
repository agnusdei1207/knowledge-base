# 📖 【암기용】 개념 완전 이해

> 목적: 망분리를 물리·논리 구조와 운영 통제 관점에서 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 업무망과 인터넷망 또는 중요 시스템망을 분리해 침해 확산 경로를 제한하는 통제 구조
- **왜 필요한가**: 인터넷 접속 단말이 악성코드에 감염되면 내부 업무 시스템과 중요 데이터까지 접근할 수 있어 피해 범위가 커진다.
- **핵심 직관**: 위험한 외부 출입문과 중요한 금고방 사이에 벽, 출입증, 전달 창구를 두는 방식이다.

## 깊이 이해
- **배경·문제의식**: 공공·금융·중요 정보 시스템은 외부 위협과 내부 중요 자산을 직접 연결하지 않도록 분리 요구를 받는다. 망분리는 물리적 분리, 논리적 분리, VDI/SBC, 망연계, 자료전송 통제를 조합한다.
- **작동 원리**: 물리적 망분리는 PC·스위치·회선을 분리하고, 논리적 망분리는 VDI, VLAN, 방화벽, 가상화로 경계를 만든다. 망연계는 승인된 파일·메시지만 검사 후 이동시킨다.
- **비유**: 두 건물을 완전히 나누는 방식이 물리적 분리이고, 같은 건물 안에서 층과 출입권한을 나누는 방식이 논리적 분리이다.
- **구체 예시**: 인터넷 자료를 업무망으로 반입할 때 망연계 구간에서 악성코드 검사, 확장자 제한, 결재 승인, 반입 로그를 적용한다.
- **흔한 오해·주의점**: 망분리는 인터넷만 끊는 조치가 아니다. 업무 흐름, 자료 반출입, 패치, 원격접속, 로그감사를 포함한 운영체계가 필요하다.

## 연결 개념
- 망연계 — 분리망 간 승인 데이터 전달
- VDI/SBC — 논리적 망분리 구현 방식
- Zero Trust — 세분화·지속 검증 접근 통제

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.
> 핵심: 망분리는 분리 방식 선택보다 업무 연속성, 망연계, 자료 반출입, 운영 지표를 함께 설계하는 문제가 핵심이다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 망분리는 인터넷망, 업무망, 중요 시스템망을 물리적 또는 논리적으로 분리해 침해 경로와 데이터 이동을 통제하는 구조이다.
> 2. **가치**: 악성코드 유입, 내부 확산, 자료 유출 가능 경로를 제한하고 망연계·감사로그로 승인된 데이터 이동만 허용한다.
> 3. **판단 포인트**: 물리 분리는 격리 수준, 논리 분리는 운영 유연성, 망연계는 업무 흐름과 감사 요구를 기준으로 선택한다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 분리 방식 이해 확인 | 물리적 분리, 논리적 분리, VDI/SBC, VLAN | 망분리를 방화벽 설치로만 설명 |
| 운영 통제 판단 확인 | 망연계, 자료 반입·반출, 패치·백신 업데이트 | 업무 불편만 언급하고 통제 절차 누락 |
| 보안·가용성 균형 확인 | 계정, 로그, DLP, 악성코드 검사, 우회 차단 | 보안 강화 같은 추상 표현 사용 |

> 요약: 망분리 답안은 분리 구조, 데이터 이동 통제, 운영 예외 처리, 감사 지표를 함께 제시해야 한다.

---

## Ⅰ. 개요 및 필요성

- 개요: 네트워크 격리 통제
- 배경: 인터넷 접속 환경과 중요 업무 시스템이 직접 연결되면 악성코드·계정 탈취가 내부 확산 경로가 됨.
- 필요성: 업무망, 인터넷망, 중요 시스템망을 분리하고 승인된 경로로만 파일·세션·명령을 이동시켜야 함.
- 범위: 물리 분리, 논리 분리, VDI/SBC, 망연계, DLP, 감사로그를 포함함.

---

## Ⅱ. 구조 및 구성요소

```text
Internet Zone -> Internet PC/VDI -> Transfer Gateway -> Business Zone -> Core System
                      / malware scan, DLP, approval
Admin Zone -> Bastion/PAM -> Server Zone
Log/SIEM -> access log, transfer log, policy violation
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 인터넷망 | 외부 웹·메일 접속 | 악성코드 유입 가능 구간 |
| 업무망 | 내부 업무 시스템 접속 | 계정·권한·단말 통제 |
| 망연계 | 분리망 간 자료 이동 | 승인, 검사, 로그 |
| VDI/SBC | 논리적 분리 환경 제공 | 화면 전송, 세션 격리 |
| 통합관제 | 로그 수집·위반 탐지 | SIEM, DLP, EDR |

> 요약: 망분리 구조는 영역 분리와 망연계 통제를 결합해 데이터 이동 경로를 승인된 지점으로 제한한다.

---

## Ⅲ. 동작원리 및 흐름도

```text
사용자 접속 요청 -> 망 구분 확인 -> 인증/인가
-> 인터넷 또는 업무 세션 제공 -> 자료 이동 요청
-> 망연계 검사/승인 -> 반입/반출 로그 저장 -> 위반 탐지
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 사용자·단말·망 위치를 식별 | NAC, IAM 로그 |
| 2 | 인터넷망과 업무망 세션을 분리 | VDI/SBC session |
| 3 | 파일 반입·반출 요청을 망연계로 집중 | workflow approval |
| 4 | 악성코드 검사·DLP·확장자 정책 적용 | scan result, DLP hit |
| 5 | 로그를 SIEM에 저장하고 우회 시도 탐지 | transfer log, violation |

> 요약: 망분리는 세션과 파일 이동을 분리하고 망연계에서 검사·승인·로그를 수행하는 방식으로 동작한다.

---

## Ⅳ. 특징

| 구분 | 물리적 망분리 | 논리적 망분리 | 수치·기술 포인트 |
|:---|:---|:---|:---|
| 구조 | PC·스위치·회선 분리 | VDI, VLAN, 가상화 | 이중 PC, SBC, NAC |
| 격리 수준 | 물리 경로 차단 | 정책·가상화 경계 | 우회 경로 점검 필요 |
| 운영 비용 | 단말·회선 증가 | 중앙 인프라 필요 | VDI 동시접속, 스토리지 IOPS |
| 자료 이동 | 전용 망연계 필수 | 정책 기반 전송 | 승인, DLP, 악성코드 검사 |

> 요약: 물리 분리는 격리 수준이 높고 논리 분리는 운영 유연성이 크며, 두 방식 모두 망연계 통제가 필수이다.

---

## Ⅴ. 심화 비교 및 적용 판단

| 구분 | 기존/대안 | 망분리 적용 | 선택 기준 |
|:---|:---|:---|:---|
| 업무 환경 | 단일 업무 PC | 물리 또는 VDI 분리 | 규제, 데이터 등급 |
| 자료 이동 | 이메일·USB | 망연계 승인 전송 | 반출 빈도, 감사 요구 |
| 운영 관리 | 개별 단말 통제 | 중앙 세션·로그 관리 | 사용자 수, 원격근무 |

> 요약: 망분리 방식은 규제 수준, 사용자 수, 자료 이동 빈도, 운영 인력으로 선택한다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 우회 접속 | 무선·테더링·사설 VPN | NAC, EDR, Proxy 강제 | bypass event |
| 자료 유출 | 반출 승인 부실 | DLP, 결재, 워터마킹 | DLP hit, approval gap |
| 패치 지연 | 분리망 업데이트 경로 부족 | WSUS, offline repository | patch compliance |

> 요약: 망분리 리스크는 우회 접속, 자료 유출, 패치 지연이며 NAC·DLP·패치 준수율로 확인한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 접근 통제 | 미승인 경로 0건 | NAC, firewall log |
| 자료 이동 | 승인 없는 반출 0건 | 망연계, DLP 로그 |
| 운영 상태 | 패치 준수율 95% 이상 | EDR, WSUS report |

> 요약: 망분리 운영 품질은 미승인 경로, 자료 반출, 패치 준수율로 판단한다.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 — 단계별 또는 항목별):**
1. 데이터 등급과 업무 흐름을 기준으로 인터넷망, 업무망, 서버관리망을 분리하고 계정·단말·네트워크 정책을 매핑함.
2. 망연계에 악성코드 검사, DLP, 결재 승인, 워터마킹, 반출 로그를 적용하고 우회 경로를 NAC와 Proxy로 차단함.
3. 분리망 패치 저장소, 백신 업데이트, EDR 로그, SIEM 상관분석을 구성해 운영 지연과 침해 징후를 추적함.

**결론 (2줄):**
- 기술사 판단: 고위험·규제 업무는 물리 분리, 대규모 일반 업무는 VDI/SBC 기반 논리 분리를 우선 검토함.
- 향후 방향: 망분리는 Zero Trust, SASE, 세분화 정책과 결합해 고정 경계 중심에서 지속 검증 중심으로 이동함.
