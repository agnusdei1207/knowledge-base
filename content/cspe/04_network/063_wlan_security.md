## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 무선 구간의 데이터 기밀성, 무결성을 보장하고 안전한 인증을 제공하는 보안 표준 |
| **배경/필요성** | WEP/WPA의 취약성 극복과 오프라인 사전 공격에 대응하기 위한 강력한 암호화 필요 |
| **출제 의도** | CCMP 암호화, SAE 동등성 동시 인증 등 최신 802.11 보안 체계 원리 이해 평가 |

## Ⅱ. 구성요소
```text
+----------+       +----------+       +----------+
| Station  |       | Access   |       | Auth     |
| (Client) | <---> | Point    | <---> | Server   |
+----------+       +----------+       +----------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| WPA2 (CCMP) | AES 암호화 알고리즘 기반으로 강력한 기밀성 제공 | 강철 금고 |
| WPA3 (SAE) | 패스워드 기반의 동등성 동시 인증으로 사전 공격 원천 방어 | 양방향 신분증 |
| 802.1X | RADIUS 등을 통한 엔터프라이즈 환경의 포트 기반 접근 제어 | 출입 관리소 |

> 요약: AES 기반의 암호화(WPA2)와 강력한 키 교환(SAE)을 통해 무선 통신을 완벽 보호함

## Ⅲ. 절차
```text
+----------+    +----------+    +----------+    +----------+
| AP 탐색  | -> | SAE 인증 | -> | 4Way핸드 | -> | 암호화통신|
+----------+    +----------+    +----------+    +----------+
```
1. AP 탐색: 단말이 AP의 SSID를 탐색하고 연결(Association) 시도
2. SAE 인증: WPA3 환경에서 패스워드 추측 공격 방지를 위한 안전한 주키(PMK) 교환
3. 4Way핸드: 단말과 AP 간 4-Way Handshake를 거쳐 실제 암호화용 동적 키(PTK) 파생
4. 암호화통신: 생성된 세션 키를 활용하여 AES-CCMP 방식으로 기밀 데이터 송수신

> 요약: 안전한 키 생성과 동적 세션 키 파생을 거쳐 안전한 데이터 터널을 구축함

## Ⅳ. 문제점
- WPA2의 4-Way Handshake 과정 노출 시 키 재설치 공격(KRACK)에 취약 (설계 오류 원인)
- WPA3 전환기 혼용 모드(Transition) 운영 시 기존 취약한 WPA2로 다운그레이드 공격 노출
- 엔터프라이즈 인증 연동 시 EAP 협상 과정 추가로 단말 로밍 시 통신 지연 발생

## Ⅴ. 개선방안
- [단기] WPA2 시스템에 대한 펌웨어 패치(KRACK 대응) 및 안전한 키 관리 설정
- [중기] 점진적으로 WPA3-Only 모드로 전환하여 구형 프로토콜 다운그레이드 원천 차단
- [장기] 802.11r(Fast BSS Transition) 기능 활성화로 암호화 세션 로밍 속도 최적화

## Ⅵ. 전망
- 양자 컴퓨터 시대에 대비하여 양자 내성 암호(PQC) 기반의 무선 인증 체계가 연구될 전망임
