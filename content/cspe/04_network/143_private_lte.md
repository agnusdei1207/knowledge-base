# 📖 【암기용】 개념 완전 이해

> 목적: 특화망을 처음 봐도 완벽히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 특정 기업이나 건물이 자기들만 쓰기 위해 별도로 구축한 맞춤형 무선 네트워크
- **왜 필요한가**: 공용 와이파이는 보안이 약하거나 사람이 몰리면 끊길 수 있고, 상용 망(SKT, KT 등)은 기업 내부 데이터를 외부로 보내야 하는 부담이 있다. 이를 해결하기 위해 "내 집 안에 내 망"을 까는 것이다.
- **핵심 직관**: 공용 도로(상용 망)나 골목길(Wi-Fi) 대신, 공장 단지 내부에만 깔린 전용 트럭 선로(특화망)를 운영하는 것과 같다.

## 깊이 이해
- **배경·문제의식**: 스마트 팩토리, 자율주행 로봇 등은 0.1초의 지연도 허용하지 않는 초저지연 성능과 철저한 보안이 필요하다. 와이파이는 간섭이 심하고 이동 중 끊김(Handover) 문제가 있어 산업용으로는 한계가 있다.
- **작동 원리**:
  - **자체 주파수**: 국가에서 지정한 특화망 전용 대역(예: 4.7GHz, 28GHz)을 할당받아 사용한다.
  - **독립 운영**: 외부 통신사 망과 분리된 자체 코어 장비(Core Network)를 사내에 두어 데이터가 밖으로 나가지 않는다.
  - **맞춤 설정**: 업로드 속도를 비정상적으로 높이거나(CCTV 중심), 지연 시간을 극단적으로 낮추는 등 용도에 맞게 튜닝한다.
- **비유**: 건물마다 비상용 자가발전기를 두어 한전 전기가 끊겨도 우리 건물은 안전하게 전기를 쓰는 것과 비슷하다.
- **구체 예시**: 네이버 제2사옥 '1784'에 깔린 이음5G(한국형 특화망 브랜드)는 빌딩 내부 로봇 수백 대를 실시간으로 제어한다.
- **흔한 오해·주의점**: "LTE/5G니까 통신사한테 가입해야 하는 것 아닌가?"라고 생각할 수 있지만, 특화망은 기업이 직접 주파수를 신청하고 장비를 사서 '직접' 운영할 수 있다. (물론 통신사에 위탁할 수도 있다.)

## 연결 개념
- **Network Slicing**: 상용 망을 논리적으로 쪼개서 특화망처럼 쓰는 기술
- **MEC (Multi-access Edge Computing)**: 특화망 내부에 서버를 두어 처리 속도를 높이는 기술
- **URLLC**: 특화망의 핵심 가치인 초저지연·고신뢰 통신 규격

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.
> 핵심: 상용 망 및 Wi-Fi와의 비교를 통해 특화망의 독보적인 보안성, 신뢰성, 맞춤형 서비스(QoS) 제공 능력을 기술적 지표(Latency, Handover, Security)와 함께 강조한다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 특화망(Private LTE/5G)은 특정 구역 내 서비스 제공을 위해 전용 주파수를 할당받아 구축한 독립적인 기업 전용 무선 네트워크이다.
> 2. **가치**: 데이터 현지 처리를 통한 보안 강화, 이동성 보장(Handover), 그리고 산업별 요구사항에 최적화된 초저지연(URLLC) 인프라를 제공한다.
> 3. **판단 포인트**: 구축 비용(CAPEX)과 운영 역량(OPEX)을 고려하여 직접 구축형과 통신사 위탁형(슬라이싱 연동) 중 최적 모델을 선정해야 한다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 특화망의 개념 및 상용 망 차별성 이해 확인 | 전용 주파수(이음5G), 로컬 코어(Local Core), 데이터 로컬리티 | 단순히 "빠른 5G"로 설명하고 보안/독립성 측면 누락 |
| Wi-Fi와의 기술적 우위 비교 역량 확인 | 이동성(Handover), 간섭 내성, QoS 보장(Deterministic) | Wi-Fi 6/7의 발전상을 무시하고 일방적인 비하 금지 |
| 산업별 적용 시나리오 및 설계 역량 | 스마트 팩토리, 물류 로봇, 원격 의료 등 구체 사례 | 구체적 수치 없이 "다양한 분야에 쓰인다"는 모호한 서술 |

> 요약: 주파수 점유권과 망 제어권이 기업에 있다는 점과 산업용 초저지연 요구사항 충족 능력을 연결하여 서술함.

## Ⅰ. 개요 및 필요성

- 정의: 토지/건물 단위로 특정 목적을 위해 전용 주파수를 할당받아 구축한 맞춤형 무선 접속망
- 배경: 스마트 팩토리 등 산업 현장의 고신뢰 통신 요구 증대 및 상용 망의 보안/지연 한계 극복 필요
- 필요성: 데이터 사외 유출 원천 차단(보안), 대규모 단말 접속(mMTC), 핸드오버 기반 끊김 없는 이동성 확보

## Ⅱ. 구조 및 구성요소

```text
[특화망 아키텍처: 직접 구축 모델]
[Enterprise Site]
Devices -> gNB (Base Station) -> Local Core (UPF/AMF) -> Application Server (MEC)
             |                      |
             +----[보안 격리]-------+----[외부 인터넷/상용 망 차단]
```

| 구성요소 | 역할 및 특징 | 핵심 가치 |
|:---|:---|:---|
| 전용 주파수 | 국가 할당 특화 대역 (4.7GHz / 28GHz) | 전파 간섭 배제 |
| gNB (Base Station) | 기업 내부 설치 소형 기지국 (Small Cell) | 음영 지역 해소 |
| Local Core | 사내에 구축된 핵심망 장비 (UPF 중심) | 데이터 로컬리티 (보안) |
| MEC | 현장에서 실시간 데이터 처리 수행 | 초저지연 (Latancy < 1ms) |

> 요약: 기지국부터 코어망까지 사내에 구축하여 데이터 흐름을 완전히 통제하고 초저지연을 달성하는 구조임.

## Ⅲ. 동작원리 및 흐름도

```text
[특화망 서비스 흐름: 로봇 제어 예시]
Sensors -> Robot Client -> 5G gNB -> UPF (Local Gate) -> Control AI (MEC) -> Action Command
           |                    |                   |
           +--[URLLC 스케줄링]--+--[패킷 최단 경로]--+--[실시간 연산]
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 단말(로봇)에서 주파수 기반 접속 시도 | SIM 기반 강력한 인증 |
| 2 | 기지국에서 초저지연 스케줄링(SST) 적용 | 지연 시간 < 10ms (E2E) |
| 3 | UPF를 통해 데이터를 사내 서버(MEC)로 즉시 전달 | 백본 경유 없는 Local Path |
| 4 | AI 알고리즘 결과에 따라 제어 신호 즉각 송신 | 패킷 손실률 < 10^-5 |

> 요약: 외부 망을 거치지 않는 최단 경로와 5G 전용 스케줄링을 통해 가용성과 실시간성을 보장함.

## Ⅳ. 특징

| 구분 | Wi-Fi 6E | 상용 5G (Public) | 특화망 (Private 5G) |
|:---|:---|:---|:---|
| 주파수 | 비면허 (Shared) | 면허 (Carrier) | 전용 면허 (Local) |
| 보안 | 암호/ID 중심 | SIM/네트워크 인증 | SIM + 물리적 폐쇄망 |
| 핸드오버 | 끊김 발생 가능 | 매끄러움 | 매우 매끄러움 (고속 이동) |
| 커버리지 | 좁음 (AP 중심) | 넓음 (전국망) | 맞춤형 (사이트 최적화) |

> 요약: 특화망은 Wi-Fi의 경제성과 상용 망의 성능/보안 장점을 결합한 산업 최적화 인프라임.

## Ⅴ. 심화 비교 및 적용 판단

| 구분 | 직접 구축형 (Standalone) | 상용 망 공유형 (Slicing) | 선택 기준 |
|:---|:---|:---|:---|
| 구축 비용 | 높음 (CAPEX 중심) | 낮음 (OPEX/구독형) | 가용 예산 |
| 운영 권한 | 기업 직접 통제 | 통신사 관리 | 운영 인력 보유 여부 |
| 보안 수준 | 최고 (물리적 분리) | 높음 (논리적 분리) | 보안 요구 등급 |

> 요약: 최고 수준의 보안과 초저지연이 필요한 대규모 제조사는 직접 구축형을, 중소규모 사업장은 공유형을 선호함.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 전파 음영/간섭 | 금속 구조물 많은 공장 환경 | 빔포밍 및 리피터 활용 | RSSI > -90dBm 유지 |
| 운영 복잡도 | 전문 통신 인력 부족 | 매니지드 서비스(Managed) 활용 | 장애 조치 시간(MTTR) |
| 단말 수급 | 특화망 전용 모뎀 부족 | 5G-와이파이 게이트웨이 혼용 | 지원 단말 라인업 수 |

> 요약: 현장 환경에 따른 전파 설계와 운영 인력 공백을 기술적/관리적 서비스로 해결해야 함.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 종단 지연 (Latency) | 20ms 이하 (애플리케이션 포함) | 프로토콜 분석기 핑 체크 |
| 가동률 (Uptime) | 99.99% 이상 | NMS 모니터링 가동 시간 |
| 동시 접속 밀도 | km²당 $10^6$개 이상 | 스트레스 테스트 툴 활용 |

> 요약: 지연 시간, 가동률, 접속 밀도라는 5G 3대 지표를 기준으로 인프라 성능을 정기 점검함.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. **스마트 물류 AGV/AMR 제어**: 고속 이동 중에도 끊김 없는 핸드오버를 통해 자율주행 로봇 수백 대의 충돌 방지 및 실시간 경로 최적화
2. **실시간 AI 영상 관제**: 28GHz 대역의 넓은 상향 링크(Uplink) 대역폭을 활용하여 수십 개의 4K CCTV 영상을 지연 없이 중앙 서버로 전송
3. **디지털 트윈 연동**: 현장 센서 데이터를 10ms 이내로 가상 모델에 반영하여 공정 상황을 실시간으로 모니터링하고 시뮬레이션 수행

**결론 (2줄):**
- 기술사 판단: 특화망은 단순 통신 수단이 아니라 제조/물류의 디지털 전환(DX)을 완성하는 핵심 엔진이자 플랫폼임
- 향후 방향: RedCap(경량 5G) 단말 도입을 통한 비용 절감과 AI 기반 자율 망 관리 기술이 결합되어 대중화가 가속화될 것임
