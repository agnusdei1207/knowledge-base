## 미리 알고가기

- ARP는 같은 네트워크 안에서 IP 주소를 MAC 주소로 찾는 절차임
- IP 스푸핑은 출발지 IP 주소를 속여 패킷을 보내는 방식임
- DNS 스푸핑은 도메인 이름을 잘못된 IP 주소로 연결하게 만드는 공격임
- DHCP 스누핑은 스위치가 믿을 수 있는 주소 할당 정보만 받아들이게 하는 보안 기능임
- 동적 ARP 검사는 ARP 응답을 주소 할당 정보와 대조해 위조를 막는 기능임
- 중간자 공격은 통신 사이에 끼어 내용을 엿보거나 바꾸는 공격임

## Ⅰ. 개요

- **정의/개념**: 네트워크 스푸핑은 주소나 이름 같은 식별 정보를 속여 상대가 공격자를 정상 장비로 믿게 만들고 트래픽을 가로채거나 잘못된 곳으로 보내는 공격 기법임
- **배경/필요성**: 초기 네트워크 프로토콜은 내부 신뢰를 전제로 만든 경우가 많아 인증 없이 식별 정보만 믿는 구간이 남아 있으므로, 이를 노린 우회와 가로채기 공격이 반복됨

## Ⅱ. 특징

- 계층마다 속이는 대상이 달라 같은 스푸핑이라도 영향 범위가 다름
- 단순 교란보다 세션 탈취와 증폭 공격의 발판으로 더 자주 쓰임
- 정상 형식을 흉내 내므로 장비 로그만 보면 즉시 구분하기 어려울 수 있음
- 예방은 주소 검증과 응답 검증과 세그먼트 보호를 함께 해야 효과가 남

## Ⅲ. 종류 및 비교

| 판단 기준 | ARP 스푸핑 | IP 스푸핑 | DNS 스푸핑 |
|:---|:---|:---|
| 속이는 정보 | IP와 MAC의 대응 관계를 속임 | 출발지 IP 주소를 속임 | 이름과 IP의 대응 관계를 속임 |
| 주된 위치 | 같은 로컬 네트워크 안에서 자주 발생함 | 인터넷 구간이나 반사 공격에 자주 쓰임 | 사용자 단말, 캐시, 해석기 구간에서 발생함 |
| 대표 영향 | 중간자 공격과 트래픽 우회가 쉬움 | 추적 회피와 반사 공격에 악용됨 | 피싱 사이트 유도와 악성 서버 연결이 일어남 |
| 대표 대응 | 동적 ARP 검사와 포트 보안이 유효함 | 출발지 주소 검증과 필터링이 필요함 | DNSSEC와 캐시 보호와 응답 검증이 필요함 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 공격자 | 거짓 응답이나 위조 패킷을 만들어 보냄 |
| 피해 단말 | 위조 정보를 믿고 트래픽 경로를 바꿈 |
| 스위치·라우터 | 주소 학습과 전달 과정에서 영향을 받음 |
| DNS 해석기 | 잘못된 이름 해석 결과가 퍼지는 지점이 됨 |
| 보안 통제 장치 | 주소 검증과 응답 무결성 검사를 수행함 |

```text
+--------+    위조 정보     +--------+    잘못된 경로     +-----------+
| 공격자   | -------------> | 피해자   | ----------------> | 가짜 목적지   |
+--------+                  +--------+                    +-----------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
[식별 정보 위조] -> [피해자 신뢰] -> [경로 변경] -> [가로채기·우회·교란]
```

1. **식별 정보 위조**: 공격자가 ARP 응답이나 위조 출발지 주소나 거짓 DNS 응답을 만듦
2. **피해자 신뢰**: 피해 단말이나 장비가 이를 정상 정보로 받아들임
3. **경로 변경**: 트래픽이 공격자나 가짜 목적지 쪽으로 흐름
4. **가로채기·우회·교란**: 정보 탈취나 세션 방해나 반사 공격이 발생함

## Ⅵ. 실무 적용 및 유의점

1. 사내 LAN에서는 ARP 스푸핑이 내부 가로채기로 바로 이어질 수 있으므로 DHCP 스누핑과 동적 ARP 검사와 포트 보안을 함께 적용하고 ARP 테이블 불일치 건수와 비정상 게이트웨이 변경 로그를 같이 확인함
2. 외부 공개 서비스는 위조 출발지 주소가 반사 공격으로 이어질 수 있으므로 출발지 주소 검증과 DNS 응답 무결성 검사를 함께 운영하고 위조 패킷 비율과 비정상 응답 증가 추이를 지속적으로 봐야 함

## Ⅶ. 결론

네트워크 스푸핑 방어의 핵심은 식별 정보 자체를 믿지 않고 주소와 이름의 진위를 구간별로 검증하는 데 있음.
