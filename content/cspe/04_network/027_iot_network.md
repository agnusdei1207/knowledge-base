## Ⅰ. 개요
- **정의**: 스마트홈/산업용 센서 간 통신을 위해 고안된 저속, 저전력, 다중 노드 릴레이형 무선 메시 네트워크 표준임.
- **배경 및 필요성**: 광활한 건물 내에서 중앙 공유기 없이도 센서끼리 신호를 이어받아 통신 커버리지를 자동 확장하는 구조 필요.
- **출제 의도**: Wi-Fi, Bluetooth와 다른 IoT 센서 전용 메시 라우팅 특성 및 파편화된 기술 스택 간의 실무 연동 과제 판단력 평가

## Ⅱ. 구성요소

```text
+-------------------------+
|  Component Architecture |
+-------------------------+
| [ Node A ] <-> [ Node B]|
+-------------------------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| **Zigbee** | 전 세계 공용 2.4GHz 기반으로 최대 6.5만 개 노드를 연결하는 개방형 메시 표준 | 다수가 이용하지만 정체가 잦은 공용 일반 도로 |
| **Z-Wave** | 900MHz 서브 기가 대역을 써서 장애물 투과율이 탁월한 스마트홈 전용 독자 통신망 | 간섭이 없고 장애물을 뚫고 가는 전용 지하 차도 |
| **메시(Mesh) 전송** | 센서 노드들이 거미줄처럼 이어져, 인접 라우터를 징검다리 삼아 목적지까지 중계함 | 이웃을 차례대로 거쳐 목적지로 메시지 릴레이 |

> 요약: 지그비는 저비용/개방형 대규모 확장에, Z-Wave는 실내 투과율 기반의 쾌적한 전용 통신 환경에 뛰어남.

## Ⅲ. 절차

```text
+-------+   +-------+   +-------+   +-------+
| Step1 |-->| Step2 |-->| Step3 |-->| Step4 |
+-------+   +-------+   +-------+   +-------+
```

1. **망 개시 선언**: 코디네이터(중앙 허브) 장치가 고유 통신 채널과 식별자(PAN ID)를 설정하여 망을 생성함.
2. **노드 인증 합류**: 전원 인가 라우터와 배터리 구동 센서(End Device)가 인증을 통해 망에 합류함.
3. **메시 트리 자동 구축**: 각 노드가 주변 장치들과 제어 메시지를 주고받으며 최적의 릴레이 경로 지도를 구축함.
4. **다중 경로 통신**: 단말 센서에서 중앙 허브로 보내는 신호를 중간 전원 인가 노드들이 끊임없이 릴레이 중계 전송함.

> 요약: 허브가 채널을 열면 기기들이 연결되어 자율적으로 릴레이 경로를 개척한 뒤 데이터를 징검다리 전송함.

## Ⅳ. 문제점
- 이종 프로토콜과의 2.4GHz 주파수 간섭(Zigbee) (원인: 고출력 Wi-Fi 등과 대역이 겹쳐 실내 트래픽 혼잡 시 패킷 드롭 발생)
- 제조사 간 응용 프로파일(Profile) 파편화 (원인: 기초 무선 표준은 같으나 제어 언어가 달라 타사 센서 간 교차 제어 실패)
- 네트워크 페이로드 한계 (원인: 수백 kbps 수준의 극도로 낮은 대역폭으로 미디어/펌웨어 전송 등 대규모 데이터 불가)

## Ⅴ. 개선방안
- **단기 방안**: [단기] 주파수 간섭 채널 수동 분리 회피 (Wi-Fi 1/6/11번 등과 겹치지 않는 Zigbee 전용 청정 채널(예: 15/20번) 튜닝)
- **중기 방안**: [중기] 멀티 통신 통합 게이트웨이 허브 구축 (Zigbee/Z-Wave/BLE 무선을 모두 해석하는 다기능 브리지로 장비 호환성 일원화)
- **장기 방안**: [장기] 스마트홈 통일 규격(Matter 기반 Thread) 융합 전환 (글로벌 표준 기반의 단일 IP 주소계 체계 도입으로 IoT 파편화 완벽 종식)

## Ⅵ. 전망
- 그간 혼재되었던 IoT 무선 표준들은 글로벌 빅테크 연합(Matter)에 흡수 통합되어 완벽한 상호 운용성을 달성할 전망임.
