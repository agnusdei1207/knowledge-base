## 미리 알고가기

- LPWAN은 적은 전력으로 넓은 범위를 덮는 저전력 광역 통신망임
- LoRa는 장거리 저전력 전송을 위한 무선 변조 기술임
- LoRaWAN은 LoRa 위에서 단말과 게이트웨이와 서버를 연결하는 네트워크 규격임
- 게이트웨이는 단말의 LoRa 신호를 받아 IP 망으로 넘겨주는 중계 장치임
- Spreading Factor는 LoRa 전송 속도와 도달 거리의 균형을 조정하는 설정값임

## Ⅰ. 개요

- **정의/개념**: LoRa는 저전력 장거리 무선 전송을 가능하게 하는 물리 계층 기술이고, LoRaWAN은 그 위에서 대량의 센서를 게이트웨이와 네트워크 서버에 연결하는 LPWAN 프로토콜임
- **배경/필요성**: 농장과 계량기와 환경 센서처럼 전송량은 작지만 배터리는 오래 가야 하고 통신 거리는 길어야 하는 장치가 늘어나면서, 고속 통신보다 저전력 장거리 연결에 맞춘 별도 체계가 필요했음

## Ⅱ. 특징

- 아주 작은 데이터량을 긴 거리로 보낼 때 유리하며 배터리 수명을 길게 가져갈 수 있음
- 비면허 대역을 쓰므로 자가망 구축이 쉽지만 주파수 규제와 간섭 환경을 직접 관리해야 함
- 멀티홉보다 스타 구조에 가까워 단말이 중계 부담을 지지 않아 에너지 효율이 좋음
- 전송 속도는 낮고 대기 시간도 길 수 있어 실시간 제어나 대용량 데이터에는 맞지 않음

## Ⅲ. 종류 및 비교

| 판단 기준 | LoRa | LoRaWAN |
|:---|:---|:---|
| 담당 계층 | 무선 변조와 전송 특성을 담당함 | 네트워크 구조와 장치 식별과 보안 절차를 담당함 |
| 핵심 질문 | 얼마나 멀리, 얼마나 적은 전력으로 보낼 수 있는가를 다룸 | 어떤 게이트웨이와 서버를 거쳐 서비스를 운영할지를 다룸 |
| 주요 요소 | 대역폭, 전송률, Spreading Factor 같은 전송 파라미터가 중요함 | 단말 클래스, 게이트웨이, 네트워크 서버, 세션 키 관리가 중요함 |
| 설계 관점 | 무선 링크 품질과 전파 도달 범위를 먼저 봄 | 전체 센서망의 수용량과 보안과 운영 구조를 함께 봄 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| End Device | 배터리 기반 센서나 계량기로, 짧은 데이터만 주기적으로 송신함 |
| LoRa Gateway | 여러 단말의 무선 신호를 받아 IP 기반 백홀로 서버에 전달함 |
| Network Server | 중복 패킷 제거와 장치 관리와 전달 경로 제어를 담당함 |
| Application Server | 수집된 센서 데이터를 업무 시스템과 분석 서비스에 연결함 |
| 보안 키와 단말 클래스 | 인증과 암호화를 담당하며, 단말 수신 방식에 따라 배터리 수명과 응답성이 달라짐 |

```text
+-----------+     +-----------+     +----------------+     +------------------+
| 센서 단말    | --> | 게이트웨이   | --> | Network Server | --> | Application     |
+-----------+     +-----------+     +----------------+     +------------------+
    LoRa 전송          IP 백홀             중복 제거·관리            업무 처리
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+     +-------------+
| 센서 데이터 생성 | --> | LoRa 업링크 송신 | --> | 게이트웨이 수신  | --> | 서버 중복 정리  | --> | 응용 서비스 반영 |
+-------------+     +-------------+     +-------------+     +-------------+     +-------------+
```

1. **센서 데이터 생성**: 계량값이나 환경값처럼 작은 데이터를 단말이 생성함
2. **LoRa 업링크 송신**: 단말이 설정된 전송률과 Spreading Factor로 무선 신호를 보냄
3. **게이트웨이 수신**: 하나 이상의 게이트웨이가 신호를 받아 IP 망으로 전달함
4. **서버 중복 정리**: 네트워크 서버가 중복 수신 패킷을 정리하고 인증과 라우팅을 처리함
5. **응용 서비스 반영**: 최종 데이터가 계량 시스템이나 관제 화면이나 알림 서비스에 반영됨

## Ⅵ. 실무 적용 및 유의점

1. 스마트 팜이나 환경 모니터링처럼 넓은 지역에 배터리 센서를 깔 때는 LoRaWAN 자가망이 유리하지만 게이트웨이 간격과 전파 음영을 과소평가하면 수집률이 급격히 떨어지므로 RSSI, SNR, 패킷 수집 성공률로 커버리지를 확인함
2. 비면허 대역 운용에서는 전송량을 무리하게 늘리면 충돌과 규제 문제가 생길 수 있으므로 전송 주기와 Spreading Factor와 듀티사이클을 함께 조정하고 채널 점유율, 배터리 수명, 재전송률로 운영 한계를 확인함

## Ⅶ. 결론

LoRa와 LoRaWAN의 가치는 빠른 통신이 아니라 전원과 인프라가 부족한 현장에서도 작은 데이터를 오래 끈질기게 모아 오는 데 있음.
