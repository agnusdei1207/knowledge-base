## Ⅰ. 개요
- **정의**: 고도 500~2000km의 저궤도(LEO, Low Earth Orbit)에 수천 개의 소형 위성을 군집(Constellation) 배치하여 전 세계에 초고속, 저지연 인터넷을 제공하는 무선 네트워크망임.
- **배경/필요성**: 기존 정지궤도(GEO) 위성의 심각한 통신 지연(약 500ms) 한계 극복, 광케이블 설치가 불가한 오지, 해상, 항공기 등 글로벌 통신 사각지대 해소.
- **출제 의도**: 저궤도 위성 통신의 아키텍처, 빔포밍 안테나, 핸드오버 및 위성 간 링크(ISL) 기술, 그리고 기존 통신망과의 융합(NTN) 이해.

## Ⅱ. 구성요소
```text
      [ LEO Satellite Constellation ]
     +-------+    ISL    +-------+
     | Sat 1 | <=======> | Sat 2 |
     +-------+           +-------+
       |  ^                  |  ^
User   |  | Gateway    User  |  | Gateway
Link   v  | Link       Link  v  | Link
+----------+             +----------+
| User UT  |             | Ground   |
| (Antenna)|             | Station  |
+----------+             +----------+
                              |
                     [ Terrestrial Internet ]
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| LEO Satellite | 지구를 빠르게(약 90분/1주) 공전하며 지상 안테나와 신호를 송수신하는 하늘의 라우터 | 날아다니는 기지국 |
| User Terminal (UT)| 위성의 궤적을 빔포밍(위상배열)으로 자동 추적하여 연결을 유지하는 사용자 안테나 시스템 | 해바라기 안테나 |
| ISL (위성 간 링크)| 지상국(Gateway)을 거치지 않고 우주 공간에서 위성끼리 레이저 통신을 통해 데이터를 릴레이함 | 우주 광케이블 |
> 요약: 수천 개의 위성이 거대한 그물망을 형성하고, 지상 단말과 지상국을 우주에서 매개하여 연결함.

## Ⅲ. 절차
```text
+-----------+   +-------------+   +-------------+   +-----------+
| 빔 추적   |-> | 위성 업링크 |-> | ISL 릴레이  |-> | 지상국다운|
+-----------+   +-------------+   +-------------+   +-----------+
```
1. **빔 추적**: 사용자 안테나(UT)가 하늘을 빠르게 가로지르는 저궤도 위성의 신호를 전자식 빔포밍으로 포착하고 추적함.
2. **위성 업링크**: 사용자의 인터넷 접속 데이터 패킷이 무선 주파수(Ku/Ka 밴드 등)를 통해 가장 최적의 위성으로 쏘아짐.
3. **ISL 릴레이**: 목적지 지상국이 멀리 있을 경우, 우주 공간에서 레이저 링크(ISL)를 이용해 위성끼리 데이터를 고속 라우팅함.
4. **지상국 다운**: 최종적으로 목적지 대륙의 지상국(Gateway)으로 신호를 내린 후 전 세계 유선 인터넷망으로 데이터가 흘러감.
> 요약: 신호를 하늘로 쏘아 올려 우주 그물망을 통해 초고속으로 릴레이한 뒤, 목적지 지상으로 내려보냄.

## Ⅳ. 문제점
- **초기 인프라 투자 비용**: 수천 개의 위성을 발사하고 지속적으로 수명(약 5년)이 다한 위성을 교체해야 하는 막대한 우주 인프라 비용 발생.
- **기상 악화 민감성**: 비나 눈이 많이 오는 기상 악화 시 고주파수(Ku/Ka) 특성상 전파 감쇠(Rain Fade) 현상으로 인한 통신 품질 저하.
- **핸드오버 및 도플러 효과**: 위성이 고속 이동하므로 몇 분마다 새로운 위성으로 끊김 없이 연결을 전환해야 하며 주파수 편이 처리 복잡.

## Ⅴ. 개선방안
- **안테나 기술 고도화**: 기계식 구동 없이 전기적으로 순식간에 여러 위성을 쫓는 전자식 위상배열(Phased Array) 안테나 저가화/양산화 (단기).
- **지상국 의존 탈피**: 위성 간 통신(ISL) 레이저 기술의 대규모 적용을 통해 지상국 없이 글로벌 라우팅 경로 최적화 (중기).
- **3GPP NTN 통합**: 6G 시대에 대비하여 스마트폰이 위성과 직접 통신하는 비지상 네트워크(NTN, Non-Terrestrial Network) 글로벌 표준 융합 (장기).

## Ⅵ. 전망
- 스페이스X(스타링크)의 성공으로 상용화가 검증되었으며, 국방, 해상 물류, 커넥티드 카 통신을 위한 필수 망으로 급성장 중임.
- 궁극적으로 지상의 5G/6G 셀룰러 망과 하늘의 LEO 망이 심리스(Seamless)하게 융합되어 진정한 '초연결 3D 공간 네트워크' 시대를 열 것임.
