## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 기존 LTE 면허 대역과 5GHz 비면허 대역을 묶어 데이터 전송 속도를 높이는 기술임 |
| 배경 | 데이터 트래픽 폭증에 대응하기 위해 주파수 매입 비용 없이 대역폭 확장 필요 |
| 출제 | 캐리어 어그리게이션(CA), LBT(Listen Before Talk), Wi-Fi 공존 기술 |

## Ⅱ. 구성요소
```text
+--------------+        +--------------+        +--------------+
| Licensed Band| -----> | Carrier Agg  | <----- | Unlicensed   |
| (Control/Data|        | (MAC Layer)  |        | (Data Boost) |
+--------------+        +--------------+        +--------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 면허 대역 (PCell) | 통신사가 독점 소유하며 안정적 제어 신호와 핵심 데이터 전송함 | 고속도로 본선 |
| 비면허 대역 (SCell) | 누구나 사용 가능한 5GHz 대역을 활용해 대용량 데이터 보조함 | 보조 확장차로 |
| 캐리어 어그리게이션 | 서로 다른 주파수 대역을 병합하여 단일 고속 채널처럼 결합함 | 차로 통합기 |

> 요약: 안정적인 면허 대역과 데이터 부스팅용 비면허 대역을 병합하여 속도 높임.

## Ⅲ. 절차
```text
+-----------+    +-----------+    +-----------+    +-----------+
| 1. LBT    | -> | 2. Assess | -> | 3. Aggreg | -> | 4. Transmit|
+-----------+    +-----------+    +-----------+    +-----------+
```
1. 채널 청취 (LBT): 데이터 전송 전 5GHz 비면허 대역의 유휴 여부를 사전 확인함.
2. 상태 평가 (Assess): 기존 Wi-Fi 신호 등 간섭 수준이 기준치 이하인지 판단함.
3. 대역 병합 (Aggregate): 면허 대역(PCell)과 비면허 대역(SCell) 논리적 병합함.
4. 데이터 전송: 병합된 초광대역 채널을 통해 고속 데이터 동시 전송함.

> 요약: 채널 청취 후 유휴 비면허 대역을 면허 대역과 병합하여 데이터 전송함.

## Ⅳ. 문제점
- Wi-Fi 간섭: 기존 5GHz 대역을 사용하는 무선랜 기기와의 공정성 문제 및 혼신 발생함.
- LBT 오버헤드: 데이터 전송 전 채널을 지속 탐색(LBT)하는 과정에서 통신 지연 발생함.
- 커버리지 제약: 5GHz 고주파 특성상 장애물 투과율이 낮고 유효 도달 범위가 짧음.

## Ⅴ. 개선방안
- 공정 접속 (단기): Wi-Fi와 공정한 채널 점유를 보장하는 최적 LBT 파라미터 적용함.
- 스몰셀 배치 (중기): 실내 및 인구 밀집 구역에 LAA 스몰셀을 촘촘히 구축하여 커버리지 보완함.
- NR-U 전환 (장기): 5G 기반의 비면허 대역(NR-U) 기술로 5G 망과 함께 완전 마이그레이션함.

## Ⅵ. 전망
- LAA 기술은 향후 Wi-Fi 7과의 6GHz 스펙트럼 공유 모델로 지속 진화하여 융합망을 구성할 것임.
