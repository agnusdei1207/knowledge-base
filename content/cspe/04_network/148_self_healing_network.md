## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 장애 발생 시 사람의 수동 개입 없이 망 스스로 탐지, 근본 원인 분석, 우회 복구를 자동 수행함 |
| 배경 | 네트워크 구조와 레이어의 극한 복잡화로 전문 운영자의 단순 장애 트러블슈팅 피로도 한계 도달 |
| 출제 | AIOps 알고리즘, 근본 원인 분석(RCA), 폐쇄 루프 자동화(Closed Loop Automation) 연계 |

## Ⅱ. 구성요소
```text
+--------------+        +--------------+        +--------------+
| Telemetry    | -----> | AIOps Engine | -----> | Orchestrator |
| (High Res)   | Alert  | (RCA Logic)  | Script | (Recover)    |
+--------------+        +--------------+        +--------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 고해상도 텔레메트리 | 네트워크 전 구간의 포트/세션 지표를 초단위로 수집해 가시성을 제공함 | 실시간 신경망 센서 |
| AIOps 진단 엔진 | 쏟아지는 방대한 알람 속에서 진짜 근본 원인(RCA) 노드를 식별하고 복구책 도출함 | 진단 전문의 두뇌 |
| 오케스트레이터 | 진단 결과에 맞춘 플레이북 스크립트 실행으로 장비 우회 설정 자동 롤백함 | 외과 수술 로봇 팔 |

> 요약: 망 상태를 촘촘히 감시하고 AI 엔진이 근본 원인을 파악해 자동 스크립트로 즉각 복원함.

## Ⅲ. 절차
```text
+-----------+    +-----------+    +-----------+    +-----------+
| 1. Detect | -> | 2. Isolate| -> | 3. Reconf | -> | 4. Verify |
+-----------+    +-----------+    +-----------+    +-----------+
```
1. 장애 탐지: 비정상적 패킷 드롭, 포트 플래핑 등 서비스 임계치 초과 증상을 즉각 감지함.
2. 논리 격리: AIOps 분석 결과 물리 결함으로 판명된 인터페이스나 라우터를 토폴로지에서 분리함.
3. 자율 재구성: 사전 정의된 정책 기반으로 BGP 경로 우회 및 백업 라우팅 자동 실행 스크립트 가동함.
4. 상태 검증: 복구 조치 완료 이후 실제 정상 서비스 트래픽 흐름 회복 여부 테스트 및 관리자 리포팅함.

> 요약: 장애 즉시 원인 노드를 망에서 격리하고 트래픽 우회 실행 후 최종 서비스 복구 검증함.

## Ⅳ. 문제점
- 오탐지 리스크: AI 모델 오판단으로 정상 핵심 경로를 스스로 차단할 경우 막대한 2차 장애 연쇄 유발함.
- 레거시 한계: 최신 NETCONF/REST API 제어가 불가능한 CLI 노후 장비는 자동 복구 파이프라인 연동 불가함.
- 책임 소재 불분명: 자율 복구 변경 과정 중 심각한 데이터 유실 발생 시 시스템과 운영자 간 귀책 모호함.

## Ⅴ. 개선방안
- 휴먼 인 더 루프 (단기): 코어 BGP 설정 변경 등 심각도 높은 조치 전에는 관리자 최종 클릭 승인 대기 설정함.
- 인텐트 기반 (중기): 목적 기반 네트워킹(IBN) 구조 선진 도입하여 사람의 선언적 의도를 자동 복구 정책화함.
- 디지털 트윈 (장기): 가상 디지털 클론 망에서 자동 복구 시나리오를 1차 사전 시뮬레이션 후 실망에 안전 배포함.

## Ⅵ. 전망
- 자율 복구 망은 레벨 5 수준의 완전 자율 주행 통신 인프라로 성장해 궁극적인 제로 터치 운영망 완성할 것임.
