## 핵심 인사이트 (3줄 요약)
> 1. **본질**: 기존 4G 코어 장비들이 폐쇄적인 블랙박스 하드웨어 덩어리였던 것과 달리, 5G 코어(5GC)는 통신 기능을 잘게 쪼개어(Microservice) IT 업계의 웹 API(HTTP/2)로 소통하게 만든 클라우드 네이티브 아키텍처다.
> 2. **원리**: 단말 관리(AMF), 세션 관리(SMF) 등의 네트워크 기능(NF)들이 서로 1:1 케이블로 묶이지 않고, 중앙의 메시지 버스 역할을 하는 SBI(Service Based Interface)를 통해 필요한 기능을 레고 블록처럼 유연하게 호출한다.
> 3. **판단 포인트**: 이 SBA의 도입 덕분에 통신망은 무겁고 비싼 전용 장비를 버리고 AWS, Azure 같은 범용 클라우드 위에서 컨테이너 기반으로 동작할 수 있게 되었으며, **네트워크 슬라이싱**을 동적으로 찍어낼 수 있는 핵심 기반이 되었다.

## Ⅰ. 개요 및 필요성

- **개요**: 3GPP가 5G Standalone(SA) 코어 네트워크를 위해 채택한 차세대 마이크로서비스(MSA) 기반의 소프트웨어 통신망 아키텍처.
- **필요성**:
  1. **폐쇄성 타파**: 4G 장비는 특정 벤더(화웨이, 에릭슨 등)의 전용 하드웨어와 전용 케이블 규격(GTP-C 등)에 종속되어 있어 확장과 업그레이드가 극도로 느렸다.
  2. **다양한 B2B 요구 수용**: 5G는 자율주행(초저지연)용 얇은 망, 넷플릭스(초고속)용 굵은 망 등 수시로 망 구조를 바꿔야 한다. 하드웨어 박스로는 불가능하므로 망 전체를 IT 소프트웨어(클라우드)처럼 유연하게 만들어야 했다.

## Ⅱ. 아키텍처 및 핵심 원리

- **4G Point-to-Point vs 5G SBA 버스 아키텍처 비교**

```text
[ 4G EPC (거미줄 방식) ]               [ 5G 5GC SBA (버스/API 방식) ]
  MME -------- SGW                    +-- AMF (이동성/접속 제어) --+
   |  \      /  |                     +-- SMF (세션 관리) --------+
   |    \  /    |                     +-- UDM (가입자 정보) ------+  <-- 각 NF들은 독립된 S/W
 HSS -------- PGW                     +-- PCF (과금/정책) --------+
 (기능 추가 시마다 모든 장비 선 연결)        [ Service Based Interface (HTTP/2 REST API) ]
                                      ============================================
                                                  | (인터넷) 
                                                UPF (User Plane Function - 데이터 고속도로)
```

- **핵심 원리**:
  1. **NF (Network Function)의 모듈화**: 통신망의 역할(가입자 인증, 과금, 길 찾기 등)을 독립적인 소프트웨어 조각(Microservice)으로 분리했다. (AMF, SMF, UDM 등)
  2. **C/U 분리 (Control / User Plane Separation)**: 머리를 쓰는 제어부(CP, 버스 위쪽)와 무식하게 대용량 영상 데이터만 나르는 전송부(UP, 버스 아래 UPF)를 완전히 물리적으로 끊어냈다. 제어부는 중앙 클라우드에, 데이터 전송부(UPF)는 사용자 동네(MEC)에 떼어놓을 수 있다.
  3. **SBI (Service Based Interface)**: 모듈들끼리 통신할 때 옛날 통신 규약(SS7, GTP 등)을 버리고, 전 세계 웹 개발자가 다 아는 인터넷 표준인 **HTTP/2 기반의 REST API(JSON)** 구조를 채택했다.
  4. **NRF (Network Repository Function)**: 서비스 레지스트리 역할. 새로운 기능(NF)이 클라우드에 켜지면 NRF에 "나 태어났어"라고 등록하고, 다른 NF가 NRF에 "과금 기능 어딨어?" 묻고 API를 찔러 호출한다.

## Ⅲ. 비교 및 연결

| 비교 항목 | 4G Core (EPC) | 5G Core (SBA 기반) |
|:---|:---|:---|
| **아키텍처 모델** | Point-to-Point (장비 간 1:1 하드코딩 연결) | **Service Based Interface (메시지 버스 연동)** |
| **인터페이스 프로토콜**| Diameter, GTP-C (통신 전용 무거운 프로토콜) | **HTTP/2, REST API (웹 IT 표준)** |
| **구축 환경** | 벤더 종속형 전용 하드웨어 박스 | **범용 x86 서버 + 쿠버네티스/컨테이너(Cloud Native)** |
| **기능 확장성** | 노드 1개 추가 시 전수 테스트 및 설정 변경 헬게이트 | **NRF에 자동 등록, 서비스 무중단 자동 확장(Auto-scaling)** |
| **C/U (제어/전송) 분리**| 제한적 분리 (SGW-C/U 분리는 4G 후기 도입)| **완벽한 분리 (AMF/SMF $\leftrightarrow$ UPF)** |

## Ⅳ. 실무 적용 및 기술사 판단

- **통신망의 클라우드 종속성 리스크 (Cloud-Native Telco)**
  - 현상: AT&T, Dish 등 글로벌 통신사들이 5G 코어를 자체 장비가 아닌 아마존(AWS)이나 MS(Azure) 퍼블릭 클라우드 위에 올리고 있다.
  - 판단: SBA 덕분에 통신망은 진정한 IT 소프트웨어가 되었다. 통신사는 인프라 구축 비용(CAPEX)을 획기적으로 절감하고 민첩성을 얻었지만, 반대로 AWS 리전이 죽으면 국가 통신망이 마비되는 치명적 단일 장애점(SPOF) 리스크를 안게 되었다. 기술사는 통신 코어망의 멀티 클라우드(Multi-cloud) 및 하이브리드 재해복구(DR) 아키텍처 설계를 최우선 보안 과제로 지적해야 한다.
- **UPF의 전진 배치 (MEC 융합)**
  - 자율주행을 위한 초저지연망 설계 시, 중앙에 있는 코어망까지 데이터를 보내지 않고 데이터 처리를 전담하는 **UPF 기능만 똑 떼어내어 스마트 팩토리나 기지국 바로 옆(Edge)** 에 심어버리는 아키텍처가 SBA의 CU 분리 덕분에 가능해졌다.

## Ⅴ. 기대효과 및 결론

- **결론**: 5G SBA는 폐쇄적이었던 통신(Telco) 기술이 개방형 인터넷 IT(Web/Cloud) 기술로 완전히 백기 투항하고 융합된 역사적 변곡점이다.
- **기대효과**: 통신망 기능이 HTTP API로 개방됨으로써, 외부의 제3자 개발자(스타트업 등)도 5G 망의 라우팅이나 품질 제어 기능에 쉽게 접속(NEF 연동)하여 혁신적인 B2B 융합 서비스를 찍어낼 수 있는 생태계가 열린다.

### 📌 관련 개념 맵
MSA(마이크로서비스) $\rightarrow$ Cloud Native (컨테이너) $\rightarrow$ C/U Separation (제어/데이터 분리) $\rightarrow$ 5G SBA (HTTP/2 기반 API) $\rightarrow$ 네트워크 슬라이싱.

### 📈 관련 키워드 및 발전 흐름도
`4G EPC (하드웨어/어플라이언스 종속)` $\rightarrow$ `NFV/SDN 도입 (통신 장비의 가상화 시작)` $\rightarrow$ `5GC 비표준화 혼란 방지 요구` $\rightarrow$ `3GPP SBA 표준 확립 (전면적인 클라우드 네이티브화)` $\rightarrow$ `네트워크 슬라이싱 자동화 실현`

### 👶 어린이를 위한 3줄 비유 설명
1. 4G 코어망은 하나의 거대한 스위스 아미 나이프 같은 전용 무전기 박스였어요. 칼 하나가 고장 나면 박스 전체를 버리고 새로 사야 했죠.
2. 5G SBA는 스마트폰 앱스토어 같은 구조예요. '가입자 확인 앱', '요금 계산 앱' 등 작은 기능(App)들을 클라우드에 띄워놓고 서로 인터넷(API)으로 대화하게 만들었어요.
3. 덕분에 사람이 많아지면 '접속 관리 앱'만 10개 더 복사해서 띄우면(Auto-scaling) 되니까, 훨씬 싸고 똑똑하게 통신망을 운영할 수 있게 되었답니다.
