## Ⅰ. 개요
- **정의**: 네트워크에서 중요 트래픽(음성, 비디오 등)에 대해 지연, 지터(Jitter), 패킷 손실률을 보장하기 위한 서비스 품질 제어 아키텍처임.
- **배경/필요성**: Best-Effort 방식의 인터넷에서 트래픽 폭증 시 발생할 수 있는 실시간 서비스의 품질 저하 방지.
- **출제 의도**: 품질 보장 모델인 IntServ(예약 기반)와 DiffServ(등급 기반)의 개념, 동작 방식 및 상호 장단점 비교 이해.

## Ⅱ. 구성요소
```text
[ IntServ Architecture ]      [ DiffServ Architecture ]
+----------------------+      +----------------------+
|  RSVP (자원 예약)      |      |  Classifier (분류)   |
|  Admission Control   |      |  Meter/Marker (표시) |
|  (종단 간 경로 예약)   |      |  Queue/Scheduler   |
+----------------------+      +----------------------+
  (모든 라우터 상태 저장)        (Edge만 복잡, Core는 단순)
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| IntServ | 통신 시작 전 RSVP 프로토콜로 종단 간 네트워크 자원을 엄격히 미리 예약하는 모델 | KTX 지정석 예매 |
| DiffServ | 패킷 헤더(DSCP)에 등급을 마킹하여 라우터가 우선순위에 따라 상대적으로 처리하는 모델 | 응급실 환자 분류 |
| DSCP | DiffServ 모델에서 패킷의 중요도를 나타내는 IP 헤더 내의 6비트 필드 (Differentiated Services Code Point) | 응급/일반 환자 꼬리표 |
> 요약: 자원을 사전에 예약하는 무거운 IntServ와, 꼬리표 기반으로 등급별 처리하는 가벼운 DiffServ로 구분됨.

## Ⅲ. 절차 (DiffServ 기준)
```text
+-----------+   +-------------+   +-------------+   +-----------+
| 트래픽인입|-> | 분류 및 마킹|-> | 혼잡 제어   |-> | 큐 스케줄링|
+-----------+   +-------------+   +-------------+   +-----------+
```
1. **트래픽 인입**: 사용자의 데이터 패킷이 네트워크 경계(Edge) 라우터로 인입됨.
2. **분류 및 마킹**: 라우터가 트래픽 특성(IP, 포트 등)을 분류하고, IP 헤더의 ToS 필드에 적절한 DSCP 값을 마킹함.
3. **혼잡 제어**: 내부(Core) 라우터들이 트래픽 폭주 시 RED(Random Early Detection) 등의 알고리즘으로 하위 등급 패킷을 선제 폐기함.
4. **큐 스케줄링**: 라우터 출력 포트에서 DSCP 값에 따라 음성 패킷은 최우선 큐(PQ), 일반 데이터는 일반 큐에서 차등 전송함.
> 요약: 경계 장비가 트래픽에 중요도 태그를 붙이고, 코어 장비는 해당 태그를 보고 우선순위대로 길을 열어줌.

## Ⅳ. 문제점
- **IntServ 확장성 한계**: 수많은 통신 세션의 예약 상태를 모든 라우터가 유지해야 하므로 대규모 인터넷(Core)에서 사용 불가.
- **DiffServ 종단 간 품질 미보장**: 구간별 상대적 우선순위만 제공할 뿐, 전체 망의 대역폭이 고갈되면 최상위 등급 패킷도 결국 손실됨.
- **통신사 간 연동 어려움**: 서로 다른 사업자(ISP) 망을 통과할 때 DSCP 마킹 정책이 초기화되거나 무시되는 문제 발생.

## Ⅴ. 개선방안
- **아키텍처 혼합 적용**: 망 경계나 소규모 구간에서는 IntServ를, 백본(Core) 대규모 구간에서는 DiffServ를 매핑하여 병행 사용 (단기).
- **폴리싱 및 쉐이핑 연동**: QoS 큐잉과 더불어 트래픽 쉐이핑(Shaping)을 결합하여 버스트 트래픽을 부드럽게 평활화 (중기).
- **SDN 기반 동적 제어**: 애플리케이션 요구사항을 실시간으로 인지하여 동적으로 대역폭을 할당하는 의도 기반 네트워크(IBN) 도입 (장기).

## Ⅵ. 전망
- 5G 시대의 네트워크 슬라이싱(Network Slicing) 기술과 융합되어 논리적으로 완벽히 격리된 QoS 보장 채널을 제공하는 방향으로 진화 중임.
- AI/ML을 통한 트래픽 패턴 예측 및 선제적 큐 관리 메커니즘이 차세대 QoS 솔루션에 점진 도입되고 있음.
