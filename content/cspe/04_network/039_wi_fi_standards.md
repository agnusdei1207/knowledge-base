# 📖 【암기용】 개념 완전 이해

> 목적: Wi-Fi 6/6E/7 표준을 속도 명칭이 아니라 주파수, 채널, 다중 접속 기술 관점에서 이해하게 만든다. 시험 답안 양식이 아니라, IEEE 802.11ax와 802.11be 차이를 잡기 위한 설명이다.

## 한눈에
- **개요**: IEEE 802.11ax는 Wi-Fi 6/6E, IEEE 802.11be는 Wi-Fi 7의 기반 무선 LAN 표준
- **왜 필요한가**: 고밀도 사무실, IoT, AR/VR, 4K/8K 스트리밍은 단말 수와 지연 요구가 증가해 OFDMA, MU-MIMO, 6GHz, MLO가 필요함.
- **핵심 직관**: Wi-Fi 6는 한 차선을 여러 조각으로 나눠 단말을 태우고, Wi-Fi 7은 여러 도로를 동시에 묶어 지연과 용량을 조정함.

## 깊이 이해
- **배경·문제의식**: 기존 Wi-Fi는 단말이 많아질수록 경쟁 기반 접속 지연과 충돌이 증가함. 802.11ax는 OFDMA와 BSS Coloring으로 고밀도 효율을 개선했고, 802.11be는 320MHz, 4096-QAM, MLO로 대역과 지연을 확장함.
- **작동 원리**: AP가 RU(Resource Unit)를 나눠 단말에게 할당하고, MU-MIMO로 다중 공간 스트림을 처리함. Wi-Fi 7은 2.4/5/6GHz 링크를 조합해 multi-link operation을 수행함.
- **비유**: Wi-Fi 5가 한 줄 계산대라면 Wi-Fi 6는 계산대를 작은 창구로 나누고, Wi-Fi 7은 여러 층 계산대를 동시에 연결하는 구조임.
- **구체 예시**: 802.11ax는 1024-QAM과 최대 160MHz, 802.11be는 4096-QAM과 최대 320MHz 채널을 지원함.
- **흔한 오해·주의점**: Wi-Fi 세대가 바뀌어도 실제 처리량은 채널 폭, 단말 지원, 간섭, 백홀, 규제 도메인에 의해 제한됨.

## 연결 개념
- OFDM·OFDMA: 802.11ax의 핵심 다중 접속
- Wi-Fi 7 MLO: 802.11be의 다중 링크 기능
- WPA3: 무선 보안 인증과 암호화

## Ⅰ. 개요 및 필요성

- 개요: IEEE 802.11 계열 무선 LAN 규격인 802.11ax(Wi-Fi 6/6E)·802.11be(Wi-Fi 7)
- 배경: 802.11ax는 OFDMA·BSS Coloring으로 고밀도 환경 효율을 높이고, 802.11be는 MLO·320MHz로 지연·용량을 확장함
- 필요성: 기업망 구축 시 표준 세대뿐 아니라 단말 지원, 채널 설계, 보안, 백홀을 함께 설계해야 함

---

## Ⅱ. 구조 및 구성요소

```text
Client STA -> AP Radio -> Channel Plan -> WLAN Controller -> Wired Backhaul
          / OFDMA RU
          / MU-MIMO
          / BSS Coloring
          / MLO for 802.11be
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| AP/STA | 무선 접속 제공·사용 | 단말 표준 지원 여부 확인 |
| OFDMA | 채널을 RU로 분할 | 802.11ax 핵심 |
| MU-MIMO | 다중 단말 공간 스트림 | uplink/downlink 지원 |
| BSS Coloring | 인접 BSS 간섭 구분 | 고밀도 환경 |
| MLO | 다중 밴드 링크 동시 사용 | 802.11be 핵심 |

> 요약: Wi-Fi 6/7 구조는 AP가 시간·주파수·공간 자원을 단말별로 할당해 다단말 무선 품질을 제어함.

---

## Ⅲ. 동작원리 및 흐름도

```text
단말 접속 -> 인증/연결 -> 채널·RU 할당 -> MU-MIMO/OFDMA 전송
-> 간섭 측정 -> roaming/QoS 조정 -> 백홀 전달
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 단말이 SSID 탐색 및 인증 수행 | WPA2/WPA3 |
| 2 | AP가 채널·대역폭·MCS 협상 | channel width, MCS |
| 3 | 802.11ax는 OFDMA RU와 BSS Coloring 적용 | airtime utilization |
| 4 | 802.11be는 MLO와 320MHz 채널 사용 가능 | link count, 6GHz |
| 5 | 컨트롤러가 로밍·QoS·전파를 조정 | RSSI, retry rate |

> 요약: Wi-Fi 표준은 접속 후 채널, 변조, 다중 접속, 로밍 정책을 조합해 무선 자원을 배분함.

## Ⅳ. 특징

| 구분 | IEEE 802.11ax | IEEE 802.11be | 수치·표준 포인트 |
|:---|:---|:---|:---|
| 세대 | Wi-Fi 6/6E | Wi-Fi 7 | Wi-Fi Alliance 명칭 |
| 주파수 | 2.4/5GHz, 6E는 6GHz | 2.4/5/6GHz | 국가별 6GHz 규제 |
| 채널 폭 | 최대 160MHz | 최대 320MHz | 6GHz에서 활용도 큼 |
| 변조 | 1024-QAM | 4096-QAM | 높은 SNR 필요 |
| 핵심 기능 | OFDMA, BSS Coloring | MLO, Multi-RU | 지연·용량 개선 |

> 요약: 802.11ax는 고밀도 효율, 802.11be는 다중 링크와 넓은 채널을 통한 지연·용량 확장에 초점이 있음.

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존/대안 | 802.11ax/be | 선택 기준 |
|:---|:---|:---|:---|
| 사무실 고밀도 | Wi-Fi 5 | Wi-Fi 6 OFDMA | 단말 30대/AP 이상 |
| AR/VR·영상 | Wi-Fi 6E | Wi-Fi 7 MLO | p95 지연 20ms 목표 |
| 백홀 | 1GbE | 2.5/5/10GbE | AP radio 총처리량 대비 |

> 요약: Wi-Fi 표준 선택은 단말 밀도, 지연 목표, 유선 백홀 용량을 함께 계산해야 함.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 간섭 증가 | 채널 중첩·AP 과밀 | 채널 계획, power 조정 | channel utilization |
| 단말 미지원 | legacy STA 비중 | SSID 분리, band steering | ax/be client ratio |
| 백홀 병목 | AP 무선 처리량 증가 | 2.5GbE 이상, PoE 예산 점검 | uplink utilization |

> 요약: Wi-Fi 구축 리스크는 RF 간섭, 단말 호환성, 유선 백홀 병목이며 사전 측정으로 통제함.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 무선 품질 | RSSI -65dBm 이상, SNR 25dB 이상 | site survey |
| 재전송 | retry rate 10% 이하 | WLAN controller |
| 지연 | p95 latency 20~50ms 이하 | active probe |

> 요약: Wi-Fi 품질은 신호 세기, 재전송률, 지연을 함께 측정해야 함.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수):**
1. 설계: site survey로 RSSI -65dBm, SNR 25dB 이상 위치를 확보하고 AP 채널·출력 계획 수립
2. 표준 선택: 일반 사무실은 802.11ax, AR/VR·고밀도 회의실은 802.11be와 6GHz 지원 단말 비중 확인
3. 운영: WPA3, 802.1X, VLAN 분리, controller telemetry로 retry rate·airtime·roaming 실패율 모니터링

**결론 (2줄):**
- 기술사 판단: 단말 밀도 중심이면 Wi-Fi 6, 6GHz와 MLO가 필요한 저지연 업무이면 Wi-Fi 7을 선택함
- 향후 방향: 6GHz 개방과 Wi-Fi 7 확산으로 무선 설계의 중심이 최대 속도에서 지연·간섭·백홀 지표로 이동함
