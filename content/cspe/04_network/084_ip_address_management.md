## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 기업 네트워크 전체의 IP 주소 공간(IPv4/v6) 할당 현황, 서브넷 구조, DNS/DHCP 시스템을 단일 플랫폼에서 중앙 집중식으로 계획, 모니터링, 관리하는 도구 |
| **배경/필요성** | 엑셀 수작업 IP 관리 방식에서 오는 잦은 주소 충돌, 휴먼 에러, 서브넷 낭비 및 IPv6 도입 대응 부재 문제 해결 필요 |
| **출제 의도** | IP 풀 동적 할당, DNS/DHCP/IPAM (DDI) 통합 아키텍처 및 주소 라이프사이클 관리 기능 평가 |

## Ⅱ. 구성요소
```text
+----------+       +----------+       +----------+
|   DNS    |       |  IPAM    |       |   DHCP   |
| (Domain) | <---> | (Center) | <---> | (Dynamic)|
+----------+       +----------+       +----------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| IP 리소스 관리 | 전체 서브넷 트리 토폴로지 구축 및 사용 중인(Used)/가용한(Free) IP 실시간 시각화 | 부동산 토지 대장 |
| DDI 통합 | DNS, DHCP, IPAM 서비스를 단일 솔루션으로 묶어 자동 동기화를 제공하는 핵심 기술 | 삼위일체 관리 센터 |
| 자동 스캐닝 | 정기적인 ICMP Ping 및 SNMP 폴링을 통해 실제 통신 중인 비인가 IP 탐지 엔진 | 정기 재물 조사 |

> 요약: IP 인프라 통합(DDI)을 통해 네트워크 무결성을 유지하고 프로비저닝 시간을 획기적으로 단축함

## Ⅲ. 절차
```text
+----------+    +----------+    +----------+    +----------+
| 공간 계획| -> | 주소 할당| -> | 자원 감시| -> | 회수 관리|
+----------+    +----------+    +----------+    +----------+
```
1. 공간 계획: 관리자가 IPAM 대시보드를 통해 기업 서브넷(VLAN) 블록을 시각적으로 설계 분할
2. 주소 할당: 신규 서버 구축 시 IPAM 포털을 통해 IP 요청 및 할당, DHCP/DNS 레코드 자동 동시 등록
3. 자원 감시: 정기 네트워크 스캐닝을 통해 미사용 상태인 불량 IP나 충돌 상태를 자동 색출 모니터링
4. 회수 관리: 클라우드 VM 및 서버 폐기 시 연동된 API를 통해 주소 풀로 신속히 반환하여 재사용성 확보

> 요약: 서브넷 설계부터 IP 할당, 사용 모니터링, 자동 회수에 이르는 완전한 라이프사이클 닫힌 루프(Closed-Loop) 체계 지원

## Ⅳ. 문제점
- 수기(Excel) 중심 관리 고착 시 실제 네트워크 상황과 대장 기록이 불일치하여 신규 서버 기동 실패 (충돌 원인)
- 기존 노후화된 DNS, DHCP 서버(Open Source 기반)는 중앙 IPAM 솔루션의 API 통제 명령 수용 불가 구조
- 하이브리드 클라우드 환경(AWS/Azure/On-Premise)에서는 복수의 분산된 IP 공간 통제가 단절되어 사각지대 발생

## Ⅴ. 개선방안
- [단기] DDI 전용 어플라이언스 일괄 도입으로 기존 수동 Excel 대장을 IPAM DB로 마이그레이션 및 자동 탐지 활성화
- [중기] 가상화 인프라(VMware, OpenStack) 플랫폼과 IPAM API 연동을 통해 신규 VM 프로비저닝 시 IP 할당 완전 자동화
- [장기] 글로벌 멀티 클라우드 망 전체를 통합 가시화하는 SaaS형 차세대 DDI 솔루션 도입으로 복잡한 IPv6 전환 매핑 기반 마련

## Ⅵ. 전망
- 인프라 자동화(IaC, Infrastructure as Code) 파이프라인의 핵심 구성 요소로 자리잡아 클라우드 네이티브 네트워크 관리를 이끌 전망임
