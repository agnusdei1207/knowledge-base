## 미리 알고가기

- 소스 코딩은 정보원에 들어 있는 중복을 줄여 평균 비트 수를 낮추는 압축 기술임
- 엔트로피는 정보원이 평균적으로 담는 정보량 하한으로, 보통 $H(X)$로 표기함
- 접두부 없는 부호는 어떤 코드도 다른 코드의 앞부분이 되지 않아 즉시 복호가 가능한 부호임

## Ⅰ. 개요

- **정의/개념**: 소스 코딩은 심벌 발생 확률의 차이를 이용해 평균 부호 길이를 줄이고 저장 공간과 전송 비트를 절약하는 압축 부호화 기술임
- **배경/필요성**: 텍스트와 이미지와 로그 데이터는 자주 나오는 패턴과 드물게 나오는 패턴이 섞여 있어 고정 길이 부호를 쓰면 비트 낭비가 커지므로, 확률 기반 압축이 필요함

## Ⅱ. 특징

- 자주 나오는 심벌에는 짧은 부호를, 드문 심벌에는 긴 부호를 배정함
- 무손실 압축에서는 평균 부호 길이가 엔트로피에 얼마나 가까운지가 핵심임
- 압축률을 높일수록 모델 동기화와 오류 전파 문제가 커질 수 있음
- 채널 오류 정정이 목적이 아니므로 채널 코딩과 역할이 정반대임

## Ⅲ. 종류 및 비교

| 판단 기준 | 허프만 코딩 | 산술 코딩 |
|:---|:---|:---|
| 부호화 방식 | 확률을 바탕으로 접두부 없는 트리를 만들어 심벌별 비트를 부여함 | 메시지 전체를 확률 구간 하나로 표현해 연속 값을 비트열로 바꿈 |
| 평균 부호 길이 | 심벌별 정수 비트 코드라 엔트로피와 차이가 남을 수 있음 | 심벌 열을 구간으로 표현하여 평균 길이를 엔트로피에 가깝게 줄일 수 있음 |
| 복호 특성 | 테이블과 트리 기반이라 빠른 복호가 쉬움 | 모델 동기화와 정밀도 관리가 중요함 |
| 적용 환경 | 심벌별 코드표와 접두부 복호가 필요한 무손실 압축에 적용함 | 확률 모델을 이용해 평균 부호 길이를 줄여야 하는 영상·이미지 압축에 적용함 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 심벌 모델 | 어떤 심벌이 얼마나 자주 나오는지 추정해 부호화의 기준을 만듦 |
| 확률 분포 | 엔트로피와 평균 부호 길이를 결정하는 핵심 입력이 됨 |
| 인코더 | 허프만 트리나 확률 구간을 이용해 압축 비트열을 생성함 |
| 디코더 | 같은 모델을 바탕으로 비트열을 원 심벌 순서로 복원함 |

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 심벌 수집      | --> | 확률 모델 생성  | --> | 압축 비트열 생성 | --> | 동일 모델로 복원 |
+-------------+     +-------------+     +-------------+     +-------------+
```

## Ⅴ. 원리 및 절차 흐름도

1. **심벌 수집**: 입력 데이터에서 심벌 빈도와 확률을 구함
2. **확률 모델 생성**: 확률 분포를 바탕으로 허프만 트리나 산술 구간 모델을 만듦
3. **압축 비트열 생성**: 각 심벌 또는 전체 메시지를 더 짧은 비트열로 표현함
4. **동일 모델로 복원**: 수신 또는 저장 측에서 같은 규칙으로 원 데이터를 복원함

## Ⅵ. 실무 적용 및 유의점

1. 로그와 텍스트처럼 심벌 편차가 큰 데이터는 허프만 기반 압축이 현실적이지만 모델이 맞지 않으면 압축률이 급격히 떨어지므로 사전 크기와 심벌 분포를 함께 점검하고 압축률과 평균 부호 길이와 CPU 사용률로 확인함
2. 영상·이미지 부호화에서 산술 코딩을 적용하면 평균 부호 길이를 엔트로피에 가깝게 줄일 수 있지만 비트 오류가 뒤쪽 복호에 전파될 수 있으므로 블록 경계와 오류 검출을 설계하고 복호 실패율과 복구 범위로 확인함

## Ⅶ. 결론

소스 코딩의 핵심은 압축률 자체보다 데이터 분포에 맞는 모델을 선택해 엔트로피에 얼마나 가깝게 줄이느냐에 있음.
