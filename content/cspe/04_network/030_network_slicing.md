## Ⅰ. 개요
- **정의**: 하나의 거대한 물리적 네트워크 인프라를 트래픽 격리가 보장된 다수의 독립적 논리형 가상 네트워크로 쪼개 할당하는 기술임.
- **배경 및 필요성**: 자율주행용 초저지연 트래픽과 모바일 대용량 스트리밍이 단일 망에서 상호 병목 간섭을 유발하는 문제 원천 차단.
- **출제 의도**: SDN/NFV 기반 인프라 가상화 기술력과 서비스수준협약(SLA)에 맞춘 동적이고 유연한 네트워크 프로비저닝 역량 평가

## Ⅱ. 구성요소

```text
+-------------------------+
|  Component Architecture |
+-------------------------+
| [ Node A ] <-> [ Node B]|
+-------------------------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| **가상화 기반 기술(SDN/NFV)** | 전용 통신 장비를 일반 서버용 가상 머신(VNF) 모듈로 분리 제어하는 뼈대 기술 | 거대 건물을 용도별 맞춤형 층으로 분리 구획 |
| **네트워크 오케스트레이터** | 각 슬라이스별 성능(SLA) 요청에 따라 대역폭과 라우팅 자원을 실시간 할당/회수함 | 건물 각 층 수요에 맞춰 전기/수도를 자동 배분 |
| **End-to-End 격리 아키텍처** | 기지국(RAN)부터 코어망까지 전 구간의 트래픽을 상호 간섭 없게 논리적으로 차단함 | 목적지가 완전히 분리된 전용 터널/차선 구축 |

> 요약: SDN/NFV를 바탕으로 단일 인프라 환경을 용도(속도/지연/대량)에 특화된 다중 가상망 선로로 완벽히 격리 분리함.

## Ⅲ. 절차

```text
+-------+   +-------+   +-------+   +-------+
| Step1 |-->| Step2 |-->| Step3 |-->| Step4 |
+-------+   +-------+   +-------+   +-------+
```

1. **요구사항 템플릿 설계**: B2B 고객의 서비스(의료, 공장 등) 요구조건에 맞춰 필요한 대역/지연(SLA) 명세서를 정의함.
2. **동적 자원 프로비저닝**: 오케스트레이터가 가상화 인프라 위에 필요 라우터(VNF)를 띄우고 논리적 서비스 체인으로 엮음.
3. **단말 식별자 매핑 처리**: 단말 접속 시 슬라이스 식별자(NSSAI)를 할당하여 트래픽이 해당 격리 경로로만 유입되도록 강제함.
4. **모니터링 및 실시간 스케일링**: 특정 슬라이스 망 내 부하 폭주 시 실시간으로 가상 자원을 확장 투입하며 침해를 방지함.

> 요약: SLA 템플릿 기반으로 가상화 망을 띄운 뒤, 단말 식별자를 통해 완벽히 격리된 맞춤형 터널 통신을 보장함.

## Ⅳ. 문제점
- 무선(RAN) 구간의 물리적 격리 한계 극복 문제 (원인: 코어망 가상화는 쉽지만 무선 기지국의 주파수/안테나 자원 격리 구현은 한계가 존재함)
- 복잡한 동적 할당에 따른 오케스트레이터 결함 (원인: 할당 알고리즘 버그 발생 시 특정 슬라이스의 부하가 타 슬라이스에 침해를 유발함)
- 초다수 마이크로서비스 코어 요소 추적 복잡성 (원인: 수천 개 컨테이너(CNF) 기반 코어 요소들이 자동 생성/소멸되어 장애 원인 파악 지연)

## Ⅴ. 개선방안
- **단기 방안**: [단기] 주요 특화망 정적 대역폭 예약 정책 적용 (의료 등 중요 슬라이스에는 유연성 대신 자원을 단독 고정 배정하여 간섭 리스크 원천 차단)
- **중기 방안**: [중기] AI/ML 기반 능동형 지능 오케스트레이션 적용 (머신러닝으로 트래픽 패턴을 사전 예측 모델링하여 충돌 없는 선제적 무중단 자원 재배치)
- **장기 방안**: [장기] O-RAN(오픈 무선망) 표준화 체계 전면 통합 (무선 기지국 장비까지 지능형 컨트롤러(RIC)로 가상화 통제하여 완벽한 End-to-End 슬라이싱 달성)

## Ⅵ. 전망
- 네트워크 슬라이싱은 B2B 기업 맞춤형 전용 사설 특화망 모델을 통해 차세대 통신 산업의 핵심 수익 모델로 등극 중임.
