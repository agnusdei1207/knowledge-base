## Ⅰ. 개요
- 정의: 하나의 물리적 네트워크 인프라를 서비스 요구사항에 따라 다수의 독립된 논리적 망으로 쪼개는 기술임
- 배경: 서비스마다 다른 QoS(속도, 지연, 용량)를 단일 망에서 동시에 보장하기 위해 필수적임
- 출제 의도: SDN/NFV 기반 가상화 원리, 슬라이스 인스턴스 구성 방식 이해

## Ⅱ. 구성요소
- ASCII 구조도
[Physical Infra] -> [Virtualization Layer]
                    /       |       \
               [Slice A] [Slice B] [Slice C]
               (Autonomous) (IoT)  (Streaming)

- 구성요소 표
| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| SDN | 소프트웨어 기반의 중앙 집중형 제어 | 관제탑 |
| NFV | 범용 서버 상에서 네트워크 기능 가상화 | 가상 컴퓨터 |
| Orchestrator | 슬라이스 생성/관리/자원 할당 총괄 | 총감독 |

> 요약: '원 네트' 상에서 '멀티 서비스'를 가능케 하는 핵심 가상화 기술임

## Ⅲ. 절차
- ASCII 흐름도
[요구 정의] -> [Slice 설계] -> [Instance 할당] -> [격리 운용]

- 4단계 설명
1. 특정 서비스(예: 자율주행)에 필요한 지연시간과 대역폭을 정의함
2. 해당 요구에 맞는 전용 네트워크 기능(VNF)들을 체이닝함
3. 물리 자원을 논리적으로 격리하여 독립된 슬라이스 인스턴스 생성함
4. 서비스 실행 중 부하에 따라 자원을 탄력적으로 자동 조절함
> 요약: 주문형 네트워크(Network on Demand)를 실시간으로 구축하고 제공함

## Ⅳ. 문제점
- 슬라이스 간 완전한 격리 실패 시 보안 및 성능 간섭 발생 가능함

## Ⅴ. 개선방안
- 하드웨어 수준의 강력한 아이솔레이션 기술 및 Zero Trust 보안 모델 적용 필요함

## Ⅵ. 전망
- 6G에서는 AI가 각 슬라이스의 상태를 예측하여 선제적으로 자원을 배치하는 지능형 기술 결합
