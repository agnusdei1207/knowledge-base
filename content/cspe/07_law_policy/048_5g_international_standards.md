# 📖 【암기용】 개념 완전 이해

> 목적: 3GPP와 IMT-2020을 처음 봐도 누가 요구사항을 정하고 누가 실제 규격을 만드는지 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: IMT-2020은 ITU-R이 정한 5G 성능 요구사항 프레임워크이고, 3GPP는 그 요구사항을 만족하는 실제 기술 규격(5G NR)을 개발하는 산업 컨소시엄임
- **왜 필요한가**: 전 세계가 서로 다른 5G 규격을 쓰면 국가 간 로밍·장비 호환이 불가능해 통일된 성능 목표와 기술 규격이 필요함
- **핵심 직관**: IMT-2020은 건축주가 정한 성능 요구사항(내진 등급, 층고)이고, 3GPP는 그 요구사항을 만족하는 실제 설계도(5G NR 규격)를 그리는 설계사무소다

## 깊이 이해
- **배경·문제의식**: 4G LTE 대비 초고속·초저지연·초연결이 요구되는 서비스(자율주행, XR, 스마트팩토리)가 등장하며 새로운 국제 요구사항 정의가 필요해짐
- **작동 원리**: ITU-R WP5D가 IMT-2020 요구사항을 정의함 — 최대 전송속도 20Gbps(하향)·10Gbps(상향), 사용자 체감 지연 1ms급(URLLC), 연결밀도 1km²당 100만 대, 이동성 500km/h 지원
- **작동 원리**: 3GPP는 이동통신사·장비사·칩셋사가 참여하는 산업 컨소시엄으로, Release 15부터 5G NR(New Radio) 기술규격을 제정해 ITU에 후보 기술로 제출함
- **작동 원리**: ITU-R은 제출된 후보 기술을 IMT-2020 요구사항 충족 여부로 평가해 국제표준으로 승인함
- **작동 원리**: ITU-R은 5G 서비스를 eMBB(초고속 광대역), URLLC(초저지연 고신뢰), mMTC(대규모 사물통신) 3대 시나리오로 구분함
- **비유**: ITU-R은 올림픽 기록 기준을 정하는 위원회이고, 3GPP는 그 기준을 통과할 선수를 훈련시키는 코치진이다
- **구체 예시**: 3GPP Release 15는 5G NR 기본 규격(NSA/SA)을, Release 16은 URLLC·V2X를, Release 17은 RedCap·비지상망(NTN)을 추가했고 Release 18부터 5G-Advanced로 진화함
- **흔한 오해·주의점**: "5G 표준을 만든 기구"를 3GPP만으로 답하면 틀린 것은 아니지만, 성능 요구사항과 국제 승인 권한을 가진 ITU-R과의 역할 분담을 함께 설명해야 정확함

## 연결 개념
- ITU·ISO·IEEE·IETF 표준화 기구 — ITU-R의 국제기구 내 위치
- Wi-Fi 7 — IEEE가 담당하는 비면허 대역 무선표준과의 대비
- MEC·네트워크 슬라이싱 — 5G 서비스 시나리오별 실무 적용 기술

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: IMT-2020은 ITU-R이 정한 5G 성능 요구사항이고 3GPP가 이를 충족하는 5G NR 기술규격을 개발해 국제표준으로 승인받는다.
> 2. **가치**: 전 세계 통신사·장비사가 동일 규격을 채택해 국가 간 로밍과 장비 호환성을 확보한다.
> 3. **판단 포인트**: 요구사항 정의(ITU-R)와 기술규격 개발(3GPP)의 역할 분담, Release 버전별 기능 확장 순서가 답안의 핵심 축이다.

> 요약: 이 문제는 3GPP만 언급하는 것이 아니라 ITU-R의 요구사항 정의 역할과 Release별 기능 확장 순서를 함께 짚어야 한다.

## Ⅰ. 개요 및 필요성

- 개요: IMT-2020은 ITU-R이 정의한 5G 성능 요구사항, 3GPP는 이를 만족하는 5G NR 기술규격 개발 컨소시엄
- 배경: eMBB(초고속 광대역), URLLC(초저지연 고신뢰), mMTC(대규모 사물통신) 서비스 시나리오를 국제 표준으로 정리
- 필요성: 자율주행·XR·스마트팩토리 등 신규 서비스에 필요한 초고속·초저지연·초연결 요구를 국제적으로 통일해야 함

---

## Ⅱ. 구조 및 구성요소

```text
서비스 요구(초고속/초저지연/초연결) -> ITU-R WP5D
  -> IMT-2020 요구사항 정의(속도/지연/밀도/이동성)
  -> 3GPP Release 개발(5G NR) -> ITU 후보기술 제출
  -> ITU-R 평가·승인 -> 국제표준 확정
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| ITU-R WP5D | IMT-2020 성능 요구사항 정의 및 후보기술 평가 | 정부간기구, 국제 승인 권한 보유 |
| 3GPP | 5G NR 기술규격 개발 | 통신사·장비사·칩셋사 참여 산업 컨소시엄 |
| eMBB/URLLC/mMTC | 3대 서비스 시나리오 | 각 시나리오별 성능 목표 상이 |
| Release 15~18 | 3GPP 규격의 단계적 확장 | NSA/SA -> URLLC/V2X -> RedCap/NTN -> 5G-Advanced |

> 요약: ITU-R이 요구사항을 정의하면 3GPP가 Release 단위로 기술규격을 개발해 국제표준으로 승인받는 구조다.

---

## Ⅲ. 동작원리 및 흐름도

```text
서비스 요구 식별 -> ITU-R 요구사항 정의(IMT-2020)
  -> 3GPP 워킹그룹 기술규격 개발(Release)
  -> 후보기술 ITU 제출 -> 요구사항 충족 평가
  -> 국제표준 승인 -> 상용 장비·단말 적용
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | ITU-R이 성능 요구사항(속도/지연/밀도) 정의 | 요구사항 문서 승인 |
| 2 | 3GPP가 Release 단위로 5G NR 규격 개발 | 규격 완결성, 상호운용성 시험 |
| 3 | 후보기술을 ITU에 제출해 요구사항 충족 평가 | IMT-2020 성능 시험 결과 |
| 4 | 국제표준 승인 후 상용 장비·단말에 적용 | 상용화 시점, 커버리지 확대율 |

> 요약: ITU-R 요구사항 정의 후 3GPP가 규격을 개발하고, ITU 평가를 거쳐 승인된 규격이 상용화된다.

## Ⅳ. 특징

| 구분 | ITU-R IMT-2020 | 3GPP 5G NR | 판단 포인트 |
|:---|:---|:---|:---|
| 성격 | 성능 요구사항 프레임워크 | 실제 기술 규격 | 요구사항과 규격의 역할 구분 필요 |
| 대표 수치 | 20Gbps/10Gbps, 1ms 지연, 100만대/km² | 주파수 대역, 프레임 구조, 코딩 방식 | 시험 답안에 수치 요구사항 명시 필요 |
| 산출 조직 | 정부간기구(ITU-R WP5D) | 산업 컨소시엄(3GPP) | 국제 승인 권한은 ITU-R에 있음 |
| 진화 방식 | 세대별 요구사항(IMT-2020 -> IMT-2030) | Release 단위 점진 확장 | Release 순서로 기능 확장 파악 |

> 요약: ITU-R은 성능 목표를, 3GPP는 그 목표를 달성하는 기술규격을 Release 단위로 점진 확장하며 제공한다.

## Ⅴ. 심화 비교 및 적용 판단

| 구분 | eMBB | URLLC | mMTC | 선택 기준 |
|:---|:---|:---|:---|:---|
| 목표 | 초고속 대용량 전송 | 초저지연 고신뢰 전송 | 대규모 저전력 연결 | 서비스 요구사항에 따라 시나리오 선택 |
| 대표 지표 | 다운로드 20Gbps급 | 지연 1ms급, 신뢰도 99.999% | 연결밀도 100만대/km² | XR·스트리밍은 eMBB, 자율주행 제어는 URLLC |
| 적용 사례 | 8K 스트리밍, XR | 자율주행 원격제어, 스마트팩토리 | 스마트미터, IoT 센서망 | 대규모 센서망은 mMTC로 설계 |

> 요약: 서비스 목적에 따라 eMBB·URLLC·mMTC 중 적합한 시나리오를 선택해 네트워크 슬라이싱으로 구현한다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 규격 파편화 | 국가별 주파수 대역 상이 | ITU-R 조화 대역 채택, 글로벌 로밍 협정 | 로밍 성공률 |
| 상호운용성 저하 | 장비사별 구현 차이 | 3GPP 상호운용성 시험(IOT) 의무화 | IOT 통과율 |
| 요구성능 미달 | 실제 커버리지 환경에서 지연·속도 저하 | 네트워크 슬라이싱, 엣지컴퓨팅(MEC) 적용 | 실측 p95 지연, 처리량 |

> 요약: 5G 표준 리스크는 주파수 조화, 상호운용성 시험, 엣지컴퓨팅 기반 실측 지표 관리로 통제한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 성능 목표 | IMT-2020 요구사항(속도/지연/밀도) 충족 | 필드 성능 측정 |
| 표준 준수 | 3GPP Release 규격 적합성 인증 | GCF·PTCRB 등 인증시험 |
| 상용화 진척 | 커버리지·가입자 확대 목표 대비 실적 | 통신사 커버리지 리포트 |

> 요약: 도입 후 성공 여부는 IMT-2020 요구사항 충족도, Release 적합성 인증, 커버리지 확대 실적으로 판단한다.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 — 단계별 또는 항목별):**
1. 단기: 서비스 요구사항을 eMBB·URLLC·mMTC로 분류하고 네트워크 슬라이싱 설계에 반영함
2. 중기: 3GPP Release 16 이상의 URLLC·V2X 규격을 적용해 자율주행·스마트팩토리 실증을 확대함
3. 장기: Release 18 이상 5G-Advanced 및 차세대 IMT-2030(6G) 요구사항 논의에 국내 표준화 참여를 강화함

**결론 (2줄):**
- 기술사 판단: 성능 목표 근거는 ITU-R IMT-2020, 실제 구현 규격 근거는 3GPP Release로 구분해 답안·설계에 인용함
- 향후 방향: 6G 논의(IMT-2030)가 시작되며 AI 네이티브 네트워크, 통신-센싱 융합이 다음 표준화 축으로 부상할 전망임
