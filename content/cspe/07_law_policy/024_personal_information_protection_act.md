# 📖 【암기용】 개념 완전 이해

> 목적: 개인정보보호법의 수집·이용·제3자 제공·전송요구권 구조를 처음 봐도 각 단계에서 무엇이 필요한지 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 개인정보의 수집·이용·제공 요건과 정보주체의 권리(열람·정정·삭제·전송요구)를 규정하는 법
- **왜 필요한가**: 개인정보를 동의나 법적 근거 없이 수집·활용하면 사생활 침해와 오남용 위험이 커진다
- **핵심 직관**: 내 물건(개인정보)을 남에게 맡기거나 넘길 때 반드시 내 동의를 받거나 법이 정한 사유가 있어야 한다는 원칙이다

## 깊이 이해
- **배경·문제의식**: 온라인 서비스 확산으로 개인정보 수집·유통이 급증하면서 동의 없는 수집·제공, 목적 외 이용 문제가 반복 발생했다
- **작동 원리**: 수집·이용은 정보주체 동의 또는 법령상 근거가 있어야 하고, 제3자 제공(전송)은 수집 목적과 별개로 추가 동의 또는 별도 법적 근거가 필요하다
- **작동 원리 2**: 개인정보 전송요구권은 정보주체가 본인 정보를 본인 또는 지정한 제3자(다른 사업자)에게 전송하도록 요구할 수 있는 권리로, 마이데이터 확산의 법적 근거가 된다
- **비유**: 전송요구권은 은행 계좌 이체처럼, 내 정보를 내가 지정한 곳으로 옮겨달라고 요청하는 권리에 가깝다
- **구체 예시**: 통신사 고객이 본인 통신 이용내역을 전송요구권으로 요청해 핀테크 앱에 전송받아 요금제 추천 서비스를 이용한다
- **흔한 오해·주의점**: 전송요구권은 GDPR의 데이터 이동성과 취지는 유사하지만 GDPR 자체가 국내에 적용되는 것이 아니라, 한국 개인정보보호법이 독자적으로 신설한 권리라는 점을 혼동하면 안 된다

## 연결 개념
- 개인정보보호법 2023 개정 — 전송요구권 신설을 포함한 개정 배경
- 마이데이터 — 전송요구권을 기반으로 한 데이터 활용 서비스
- 정보통신망법 — 온라인 서비스 사업자의 개인정보 보호조치와 연계

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.
> 핵심: 개인정보보호법 답안은 수집·이용·제공 요건, 전송요구권 구조, 마이데이터 연계, GDPR과의 구분을 함께 제시한다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 개인정보보호법은 수집·이용·제3자 제공에 동의 또는 법적 근거를 요구하고, 전송요구권으로 정보주체의 데이터 이동 권리를 보장한다.
> 2. **가치**: 동의 기반 통제로 사생활 침해를 예방하고, 전송요구권으로 마이데이터 등 데이터 활용 산업의 법적 근거를 제공한다.
> 3. **판단 포인트**: 전송요구권은 GDPR을 그대로 적용한 것이 아니라 한국 법이 독자적으로 신설한 권리임을 구분해야 한다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 수집·이용·제공 요건 이해 확인 | 동의 원칙, 목적 외 이용 제한, 제3자 제공 요건 | 세 단계 요건을 뭉뚱그려 서술 |
| 전송요구권 이해 확인 | 정보주체가 본인 또는 제3자에게 전송 요구 가능 | 전송요구권을 열람권·삭제권과 혼동 |
| 국내법 vs 해외법 구분 확인 | 전송요구권은 국내법상 독자 신설 권리 | GDPR과 동일시하는 서술 |

> 요약: 이 문제는 조문 나열보다 수집·이용·제공·전송요구권 단계별 요건 차이와 국내법 특수성을 보여야 한다.

---

## Ⅰ. 개요 및 필요성

- 정의: 개인정보 수집·이용·제공 요건과 정보주체 권리를 규정하는 법
- 배경: 온라인 서비스 확산으로 동의 없는 수집·목적 외 이용 문제 반복
- 필요성: 동의 기반 통제와 전송요구권으로 개인정보 자기결정권과 데이터 활용을 함께 보장

---

## Ⅱ. 구조 및 구성요소

```text
개인정보 수집 -> 이용(목적 범위 내)
  -> 제3자 제공(추가 동의/법적 근거)
  -> 전송요구권 행사 -> 지정 대상 전송(본인/제3자)
  -> 정보주체 권리(열람/정정/삭제) 보장
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 수집·이용 동의 | 최초 수집 목적 범위 내 이용 근거 | 동의서 필수 기재사항 명시 |
| 제3자 제공 | 목적 외 제공 시 별도 동의·법적 근거 | 제공받는 자, 이용 목적, 보유기간 고지 |
| 전송요구권 | 본인 정보를 본인/제3자에게 전송 요구 | 마이데이터 서비스의 법적 근거 |
| 정보주체 권리 | 열람·정정·삭제·처리정지 요구 | 개인정보보호위원회가 감독 |

> 요약: 개인정보보호법은 수집·이용·제공 단계별 동의 요건과 전송요구권을 통한 정보주체 통제권을 규정한다.

---

## Ⅲ. 동작원리 및 흐름도

```text
개인정보 수집 요청 -> 동의/법적 근거 확인
  -> 목적 범위 내 이용 -> 제3자 제공 필요 시 추가 동의
  -> 정보주체 전송요구 접수 -> 지정 대상으로 전송 -> 처리 결과 통지
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 수집 목적·항목 고지 후 동의 획득 | 동의서 필수사항 기재 여부 |
| 2 | 목적 범위 내 이용, 목적 외 이용 제한 | 목적 외 이용 발생 여부 |
| 3 | 제3자 제공 시 별도 동의 또는 법적 근거 확인 | 제공 목적·항목·보유기간 고지 |
| 4 | 전송요구권 접수 후 본인 또는 제3자에게 전송 | 전송 형식, 처리 기한 준수 |

> 요약: 개인정보 처리는 동의 확인, 목적 범위 이용, 제3자 제공 통제, 전송요구 처리 순으로 이뤄진다.

---

## Ⅳ. 특징

| 구분 | 내용 | 판단 포인트 |
|:---|:---|:---|
| 장점 | 정보주체 자기결정권 강화 | 동의·전송요구를 통한 통제권 확보 |
| 한계 | 동의 절차 형식화 위험 | 약관 형태 포괄 동의로 실효성 저하 우려 |
| 비교 포인트 | 열람·삭제권과 전송요구권의 차이 | 전송요구권은 데이터 이동까지 포함 |

> 요약: 전송요구권은 기존 열람·삭제권보다 데이터 활용 측면의 권리를 확장한 개념이다.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존 열람·삭제권 | 전송요구권 | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | 자기 정보 확인·삭제 요청 | 본인/제3자에게 전송 요청 | 데이터 활용 목적이면 전송요구권 적용 |
| 비용/성능 | 처리 부담 낮음 | 전송 인터페이스 구축 부담 | 마이데이터 사업자는 전송 표준 API 필요 |
| 운영/위험 | 정보 오남용 방지 중심 | 전송 과정 정보 유출 위험 | 전송 구간 암호화, 인증 강화 |

> 요약: 데이터 이동·활용이 목적이면 전송요구권을, 단순 확인·삭제가 목적이면 기존 권리를 적용한다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 형식적 동의 | 포괄 약관 동의로 목적 특정 미흡 | 목적별 개별 동의 UI 설계 | 개별 동의 항목 분리율 |
| 제3자 제공 오남용 | 제공 목적·범위 불명확 | 제공 계약서에 목적·항목·보유기간 명시 | 제공 계약 점검율 |
| 전송 구간 유출 | 전송 API 보안 취약 | 전송 구간 암호화, 인증서 기반 접근통제 | 전송 오류·유출 건수 |

> 요약: 개인정보 처리 리스크는 동의 구체화, 제공 계약 관리, 전송 구간 보안으로 통제한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 동의 적정성 | 목적별 개별 동의 확보율 | 동의 UI 점검, 약관 감사 |
| 제공 통제 | 제3자 제공 계약 점검 완료율 | 계약서·제공 로그 점검 |
| 전송 신뢰성 | 전송요구 처리기한 준수율 | 전송 처리 로그 분석 |

> 요약: 개인정보 관리 성과는 동의 적정성, 제공 통제, 전송 처리 신뢰성으로 판단한다.

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 — 단계별 또는 항목별):**
1. 수집 단계에서 목적별 개별 동의 UI를 설계해 포괄 동의로 인한 형식화를 방지함
2. 제3자 제공 계약서에 제공 목적·항목·보유기간을 명시하고 정기 점검함
3. 전송요구권 처리 시 표준 API와 전송 구간 암호화를 적용해 데이터 유출을 방지함

**결론 (2줄):**
- 기술사 판단: 개인정보 처리는 수집·이용·제공 단계별 동의 요건을 명확히 하고, 전송요구권은 마이데이터 확산에 맞춰 보안 통제를 강화해야 함
- 향후 방향: 전송요구권 적용 분야를 확대하되 전송 표준화와 보안 인증 체계를 함께 정비해야 함
