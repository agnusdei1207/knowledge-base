# 📖 【암기용】 개념 완전 이해

> 목적: 클라우드컴퓨팅법과 CSAP 인증을 처음 봐도 왜 공공기관이 아무 클라우드나 못 쓰는지 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 클라우드컴퓨팅 발전과 이용자 보호를 위한 법으로, 공공기관 클라우드 이용 시 CSAP(클라우드 보안 인증) 취득을 요구하는 근거법
- **왜 필요한가**: 공공기관 데이터는 민감도가 높아, 검증되지 않은 클라우드 서비스 이용 시 보안 사고 파급력이 크다
- **핵심 직관**: 국가 문서를 보관하는 창고를 아무 업체나 운영하게 하지 않고, 정부가 인증한 창고 업체만 이용하도록 제한하는 것과 같다

## 깊이 이해
- **배경·문제의식**: 클라우드 이용이 확산되면서 공공부문 데이터를 다루는 클라우드 서비스의 보안 수준을 검증할 필요가 커졌다
- **작동 원리**: 클라우드컴퓨팅법에 근거해 CSAP(Cloud Security Assurance Program) 인증제도를 운영하며, 물리적 망분리, 데이터 소재지, 보안 통제 수준 등을 심사한다
- **작동 원리 2**: 공공기관은 원칙적으로 클라우드 이용을 우선 검토해야 하고, 실제 이용 시에는 CSAP 인증을 받은 서비스를 선택해야 한다
- **비유**: 공공기관이 사용하는 클라우드는 일반 시중 은행이 아니라, 정부가 안전성을 심사해 지정한 금고 업체를 이용하는 것과 같다
- **구체 예시**: 공공기관이 민원 시스템을 클라우드로 전환할 때 CSAP 인증을 받은 국내 리전의 IaaS 서비스를 우선 검토한다
- **흔한 오해·주의점**: CSAP 인증 등급·심사기준이나 국외 리전 이용 허용 범위는 정책·고시 개정에 따라 계속 변화하는 영역이므로, 시험 답안에서는 등급 세부 명칭보다 "인증제도를 통한 사전 검증"이라는 큰 취지 중심으로 서술하는 것이 안전하다

## 연결 개념
- 전자서명법 — 사설인증사업자의 클라우드 기반 서비스 운영과의 접점
- 정보통신망법 — 클라우드 서비스 제공자의 보호조치 의무와 중첩
- ISMS-P — 정보보호 관리체계 인증과 CSAP의 유사·차이점

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.
> 핵심: 클라우드컴퓨팅법 답안은 법 취지, CSAP 인증 절차, 공공부문 이용 원칙, 리스크·검증 지표를 함께 제시한다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 클라우드컴퓨팅법은 클라우드 이용 활성화와 이용자 보호를 함께 규정하며, CSAP는 공공부문 이용 전 보안성을 검증하는 인증제도이다.
> 2. **가치**: 공공기관이 검증되지 않은 클라우드를 이용해 발생할 수 있는 대규모 데이터 유출·서비스 마비 위험을 사전에 차단한다.
> 3. **판단 포인트**: CSAP 인증 취득 여부와 데이터 소재지·망분리 수준이 공공부문 클라우드 도입의 핵심 판단 기준이다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 법 취지 이해 확인 | 클라우드 활성화와 이용자 보호의 균형 | 규제 측면만 강조하고 활성화 취지 누락 |
| CSAP 인증 이해 확인 | 보안 심사, 망분리, 데이터 소재지 검증 | 인증 취득만 언급하고 심사 항목 누락 |
| 공공부문 적용 이해 확인 | 공공기관 클라우드 이용 우선 검토 원칙 | 민간·공공 이용 요건을 동일하게 서술 |

> 요약: 이 문제는 CSAP 명칭 암기보다 공공부문 보안 검증 취지와 심사 항목을 구체적으로 보여야 한다.

---

## Ⅰ. 개요 및 필요성

- 개요: 클라우드 이용 활성화와 이용자 보호를 규정하고 CSAP 인증 근거를 두는 법
- 배경: 공공부문 클라우드 확산으로 데이터 민감도에 맞는 보안 검증 필요성 대두
- 필요성: 검증되지 않은 클라우드 이용 시 발생 가능한 대규모 유출·마비 위험 사전 차단

---

## Ⅱ. 구조 및 구성요소

```text
클라우드 서비스 제공자 -> CSAP 인증 신청
  -> 보안 심사(망분리, 접근통제, 데이터 소재지)
  -> 인증 취득 -> 공공기관 이용 검토
  -> 도입·운영 -> 사후 점검
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| CSAP 인증 | 클라우드 서비스의 보안성 사전 검증 | 물리적 망분리, 접근통제 심사 |
| 데이터 소재지 | 데이터 저장 위치에 대한 요건 확인 | 국내·국외 리전 구분 심사 |
| 공공부문 이용 원칙 | 클라우드 우선 검토 원칙 | 민감도별 이용 가능 서비스 구분 |
| 사후 점검 | 인증 유지 여부 정기 점검 | 인증 취소·갱신 절차 운영 |

> 요약: 클라우드컴퓨팅법은 CSAP 인증을 통해 공공부문 클라우드 이용의 보안성을 사전·사후로 검증한다.

---

## Ⅲ. 동작원리 및 흐름도

```text
클라우드 서비스 제공자 인증 신청 -> 보안 심사
  -> 인증 취득 -> 공공기관 조달 목록 등재
  -> 공공기관 도입 검토 -> 운영 -> 정기 사후 점검
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 클라우드 제공자가 CSAP 인증 신청 | 심사 신청 요건 충족 여부 |
| 2 | 망분리·접근통제·데이터 소재지 심사 | 보안 통제 수준 |
| 3 | 인증 취득 후 공공 조달 목록 등재 | 인증 유효기간 |
| 4 | 공공기관이 인증 서비스 중 도입 검토 | 업무 민감도별 적합성 |

> 요약: 클라우드 도입은 인증 심사, 취득, 조달 등재, 공공기관 검토·도입 순으로 진행된다.

---

## Ⅳ. 특징

| 구분 | 내용 | 판단 포인트 |
|:---|:---|:---|
| 장점 | 공공부문 클라우드 이용의 보안성 사전 검증 | 유출·마비 위험 사전 차단 |
| 한계 | 인증 심사·유지에 따른 사업자 부담 증가 | 인증 취득 비용·기간 |
| 비교 포인트 | 민간부문 이용 대비 강화된 요건 | 공공부문 민감도 기준 차등 적용 |

> 요약: CSAP는 공공부문 보안성을 높이지만 인증 취득·유지 부담이라는 비용 요인을 동반한다.

## Ⅴ. 심화 비교 및 적용 판단

| 구분 | 민간부문 클라우드 이용 | 공공부문 클라우드 이용(CSAP) | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | 사업자 자율 보안 정책 | CSAP 인증 취득 서비스로 제한 | 데이터 민감도에 따라 인증 요건 적용 |
| 비용/성능 | 다양한 서비스 선택 폭 | 인증 서비스 내 선택 제한 | 업무 특성별 인증 등급 서비스 선택 |
| 운영/위험 | 사업자 책임 중심 위험관리 | 인증 유지·사후 점검 중심 위험관리 | 정기 점검 결과로 인증 유지 여부 판단 |

> 요약: 공공부문은 데이터 민감도에 따라 CSAP 인증 등급에 맞는 서비스를 선택해 위험을 관리한다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 인증 취득 지연 | 심사 항목 복잡, 준비 기간 부족 | 사전 컨설팅과 단계별 준비 계획 수립 | 인증 취득 소요 기간 |
| 인증 유지 실패 | 사후 점검 미이행 | 정기 자체 점검과 갱신 일정 관리 | 인증 갱신율 |
| 데이터 소재지 불명확 | 리전 구성 변경 미고지 | 데이터 소재지 변경 시 사전 신고 체계 운영 | 소재지 변경 신고 이행률 |

> 요약: 클라우드 도입 리스크는 인증 준비, 갱신 관리, 소재지 신고 체계로 통제한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 인증 유지 | CSAP 인증 갱신 완료율 | 인증기관 심사 결과 |
| 보안 통제 | 망분리·접근통제 이행 여부 | 정기 보안 점검 |
| 도입 적합성 | 업무 민감도 대비 인증 등급 적정성 | 도입 검토 보고서 |

> 요약: 클라우드 도입 성과는 인증 유지율, 보안 통제 이행, 도입 적합성으로 판단한다.

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 — 단계별 또는 항목별):**
1. 공공기관은 업무 민감도를 분류하고 그에 맞는 CSAP 인증 등급의 클라우드 서비스를 선택함
2. 클라우드 사업자는 인증 취득 전 망분리·접근통제 요건을 사전 컨설팅으로 점검함
3. 인증 취득 후에는 정기 사후 점검과 갱신 일정을 관리해 인증 유지를 보장함

**결론 (2줄):**
- 기술사 판단: 공공부문 클라우드 도입은 CSAP 인증 취득과 업무 민감도별 서비스 선택을 함께 검토해야 함
- 향후 방향: 멀티클라우드·국외 리전 활용 확대에 맞춰 인증 기준과 데이터 소재지 요건을 지속 정비해야 함
