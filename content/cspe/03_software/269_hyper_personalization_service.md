# 📖 【암기용】 개념 완전 이해

> 목적: 초개인화 서비스를 처음 봐도 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 설명이다.

## 한눈에
- **개요**: 사용자 행동, 맥락, 선호, 실시간 이벤트를 기반으로 개인별 콘텐츠·상품·경험을 제공하는 서비스
- **왜 필요한가**: 같은 화면과 추천을 모든 사용자에게 제공하면 전환율과 체류 시간이 제한된다. 초개인화는 사용자의 현재 상황까지 반영해 다음 행동을 제안한다.
- **핵심 직관**: 같은 메뉴판을 모두에게 주는 대신, 알레르기, 예산, 날씨, 이전 주문을 보고 개인별 추천 메뉴를 제시하는 방식이다.

## 깊이 이해
- **배경·문제의식**: 전통 세그먼트 마케팅은 20대 여성, VIP 고객처럼 집단 기준으로 나눈다. 초개인화는 개인 단위 행동 로그와 실시간 컨텍스트를 반영해 추천·가격·메시지·UI를 조정한다.
- **작동 원리**: 이벤트 수집, 프로필 통합, 특징 생성, 추천·랭킹 모델, 실험 플랫폼이 연결된다. 사용자의 클릭, 구매, 위치, 시간대, 디바이스 정보를 조합해 next best action을 선택한다.
- **비유**: 단골 가게 주인이 고객의 취향과 오늘 상황을 기억해 주문 전에 알맞은 선택지를 제안하는 것과 같다.
- **구체 예시**: 전자상거래 앱에서 최근 검색, 장바구니, 재고, 할인, 위치를 반영해 홈 화면 상품 순서를 사용자별로 바꾸고 A/B 테스트로 전환율 uplift를 측정한다.
- **흔한 오해·주의점**: 초개인화는 개인정보를 많이 모으는 것이 아니다. 동의, 목적 제한, 데이터 최소화, 설명 가능성이 없으면 규제·신뢰 리스크가 발생한다.

## 연결 개념
- CDP - 고객 데이터 통합과 프로필 관리
- Recommendation System - 개인별 후보 생성과 랭킹
- Privacy by Design - 동의, 최소 수집, 목적 제한

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.
> 핵심: 초개인화는 추천 모델 설명이 아니라 데이터 동의, 실시간 특징, 실험, 개인정보 통제를 포함한 서비스 설계로 답해야 한다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 초개인화 서비스는 개인별 행동·맥락·선호 데이터를 기반으로 콘텐츠, 추천, 메시지, UI를 동적으로 제공하는 서비스 모델이다.
> 2. **가치**: 전환율 uplift, 클릭률, 체류 시간, 이탈률 같은 비즈니스 지표와 동의율, 삭제 요청 처리 같은 개인정보 지표를 함께 관리한다.
> 3. **판단 포인트**: 실시간성, 데이터 품질, 모델 편향, 개인정보 동의, A/B 테스트 기준을 포함해 설계해야 한다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 개인화 서비스 구조 이해 확인 | CDP, Feature Store, 추천 모델, 실험 플랫폼 | 추천 알고리즘만 설명 |
| 데이터·개인정보 통제 확인 | 동의, 목적 제한, 최소 수집, 삭제권 | 데이터 수집 확대만 강조 |
| 성과 측정 판단 확인 | CTR, CVR, uplift, churn, fairness | 정성적 만족 표현 |

> 요약: 이 문제는 개인화 모델과 개인정보 거버넌스를 동시에 평가한다.

## Ⅰ. 개요 및 필요성

- 개요: 초개인화 서비스는 개인별 맥락 기반 경험 제공 서비스이다.
- 배경: 사용자의 행동 데이터와 실시간 상황을 반영하면 추천, 메시지, UI를 개인 단위로 바꿀 수 있다.
- 필요성: 개인정보 동의, 목적 제한, 추천 품질 지표를 함께 관리해 서비스 신뢰와 규제 대응을 확보해야 한다.

---

## Ⅱ. 구조 및 구성요소

```text
User Event -> CDP/Profile -> Feature Store -> Recommendation/Ranking
           -> Decision API -> Channel(App/Web/Push) -> Experiment/Feedback
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 이벤트 수집 | 클릭, 구매, 검색, 위치, 디바이스 이벤트 수집 | 동의 상태 확인 필요 |
| CDP/프로필 | 고객 식별, 선호, 세그먼트, consent 관리 | ID 해석과 삭제 요청 처리 |
| 추천·랭킹 모델 | 후보 생성, 점수화, next best action 선택 | 편향·필터 버블 점검 |
| 실험 플랫폼 | A/B 테스트, uplift, 장기 지표 측정 | 실험군 오염 방지 |

> 요약: 초개인화는 이벤트, 프로필, 특징, 추천, 실험 피드백이 순환하는 구조이다.

---

## Ⅲ. 동작원리 및 흐름도

```text
동의 확인 -> 이벤트 수집 -> 프로필/특징 갱신 -> 후보 생성
-> 랭킹/정책 필터 -> 채널 노출 -> 반응 측정 -> 모델 개선
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 동의와 목적 확인 | consent 없는 데이터 제외 |
| 2 | 실시간 특징 갱신 | feature freshness 5분 이하 |
| 3 | 추천·랭킹 수행 | CTR, CVR, diversity 측정 |
| 4 | 실험과 피드백 | uplift, churn, 삭제 요청 처리 |

> 요약: 초개인화는 동의 확인 후 개인별 특징을 갱신하고 실험으로 효과와 부작용을 검증한다.

## Ⅳ. 특징

| 구분 | 세그먼트 개인화 | 초개인화 | 판단 포인트 |
|:---|:---|:---|:---|
| 기준 | 집단 속성 | 개인 행동+실시간 맥락 | 사용자 단위 feature |
| 처리 방식 | 배치 캠페인 | 실시간 decision API | p95 응답 100ms |
| 측정 | 캠페인 반응률 | CTR, CVR, uplift, churn | A/B 테스트 |
| 한계 | 정교도 제한 | 개인정보·편향 리스크 | 동의율, fairness |

> 요약: 초개인화는 실시간성과 개인 단위 판단이 장점이나 개인정보와 편향 통제가 필수이다.

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존/대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | 세그먼트 캠페인 | 개인별 decision API | 월 활성 사용자 100만 이상 |
| 비용/성능 | 배치 분석 | 실시간 feature+ranking | p95 100ms 이하 필요 |
| 운영/위험 | 개인정보 범위 작음 | 민감정보·추적 리스크 | 명시 동의와 삭제권 처리 |

> 요약: 초개인화는 대규모 사용자와 실시간 의사결정 가치가 있을 때 적용한다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 개인정보 위반 | 무동의 수집·목적 외 사용 | CMP, 데이터 최소화, 삭제 자동화 | 동의 없는 처리 0건 |
| 필터 버블 | 유사 추천 반복 | diversity, exploration 비율 | 추천 다양성 지표 |
| 모델 편향 | 데이터 불균형 | fairness 평가, 민감속성 제외 | 그룹별 CVR 편차 |

> 요약: 개인정보, 필터 버블, 편향은 초개인화의 핵심 통제 대상이다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 비즈니스 | CVR uplift 5% 이상 | A/B 테스트 |
| 실시간성 | p95 decision API 100ms 이하 | APM |
| 개인정보 | 삭제 요청 30일 내 처리 | 개인정보 처리 로그 |

> 요약: 초개인화 성과는 전환율과 API 지연, 개인정보 처리 SLA를 함께 본다.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 - 단계별 또는 항목별):**
1. 데이터 기반: CMP로 동의 상태를 관리하고 CDP, Feature Store, 삭제 요청 자동화 파이프라인을 구축
2. 모델 운영: 후보 생성+랭킹 2단 구조, diversity 제약, p95 decision API 100ms 이하 SLO 설정
3. 실험·감사: A/B 테스트로 CVR uplift 5% 이상 검증, 그룹별 편차와 개인정보 처리 로그를 월 단위 점검

**결론 (2줄):**
- 기술사 판단: 단순 캠페인은 세그먼트 개인화, 실시간 추천·채널 최적화가 핵심이면 초개인화를 선택함
- 향후 방향: 초개인화는 CDP, Feature Store, 생성형 AI, Privacy Tech가 결합된 실시간 경험 플랫폼으로 발전함
