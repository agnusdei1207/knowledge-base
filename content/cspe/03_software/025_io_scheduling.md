## Ⅰ. 개요
- 정의: 디스크 헤드의 이동 경로를 최적화하여 I/O 요청을 처리하는 순서 결정 기법
- 배경: 기계적 구동 방식인 HDD의 탐색 시간(Seek Time)을 최소화하여 처리량 향상 필요
- 출제 의도: 엘리베이터 알고리즘 등 주요 방식의 동작 특성과 응답성/공정성 비교

## Ⅱ. 구성요소
```
[ Requests: 98, 183, 37, 122, 14 ]
  SCAN:   H(50) -> 37 -> 14 -> 98 -> 122 -> 183 (Directional)
  C-SCAN: H(50) -> 98 -> 122 -> 183 -> (Go End) -> 14 -> 37
```
| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| SCAN | 한쪽 방향으로 끝까지 가며 처리 후 반대 방향 전환 | 엘리베이터 왕복 |
| C-SCAN | 한쪽 방향으로만 처리하며 끝에 도달 시 시작점으로 회귀 | 편도 순환 셔틀 |
| SSTF | 현재 헤드 위치에서 가장 가까운 요청 우선 처리 | 가까운 곳 먼저 |
> 요약: SCAN은 왕복 처리, C-SCAN은 단방향 균등 기회를 지향함.

## Ⅲ. 절차
```
[Request Arrival] -> [Queue Sorting] -> [Head Movement] -> [Service]
```
1. 다수의 I/O 요청이 디스크 대기 큐에 진입함
2. 선택된 스케줄링 알고리즘에 따라 요청들의 처리 순서를 재정렬함
3. 디스크 헤드가 트랙을 이동하며 정렬된 순서대로 데이터 읽기/쓰기 수행
4. SCAN의 경우 끝 도달 시 방향을 틀고, C-SCAN은 처음으로 되돌아가 반복
> 요약: 헤드 이동 거리를 줄여 평균 대기 시간을 최적화함.

## Ⅳ. 문제점
- 원인: SCAN 계열은 바깥쪽 트랙에 비해 안쪽 트랙 요청의 대기 시간이 길어질 수 있음
- 원인: SSD와 같은 비기계식 저장장치에서는 탐색 시간의 의미가 없어 효과가 미미함

## Ⅴ. 개선방안
- (단기) 요청이 있는 범위까지만 이동하는 LOOK, C-LOOK 기법 적용으로 불필요 이동 방지
- (중기) 마감 시간을 고려한 Deadline 스케줄러 또는 응답성 중심의 CFQ 스케줄러 도입
- (장기) NVMe SSD에 최적화된 다중 큐(Multi-queue) 기반 블록 I/O 계층 전환

## Ⅵ. 전망
- 지능형 스토리지 컨트롤러가 워크로드를 학습하여 동적으로 스케줄링 정책을 변경하는 추세
- 데이터 센터 규모의 분산 I/O 환경에서 대기 시간 가변성(Tail Latency) 억제를 위한 스케줄링 중요성 부각
