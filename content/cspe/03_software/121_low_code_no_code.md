## Ⅰ. 개요
- 정의: Low-code No-code의 핵심 개념과 주요 목적
- 배경: 소프트웨어 복잡도 증가 및 품질 보증 요구 증대
- 출제 의도: | 유형 | 난이도 | 중요도 |
| --- | --- | --- |
| 기술 비교 | 중 | 상 |

## Ⅱ. 구성요소
- ASCII 구조도
  [Visual UI] -> [Drag & Drop] -> [Auto Code Gen] -> [App]

- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 비주얼 모델러 | GUI 기반의 워크플로우 및 UI 설계 | 레고 블록 |
| 로우코드 (LCP) | 최소한의 코딩으로 확장성 제공 | 반조리 식품 |
| 노코드 (NCP) | 코딩 없이 설정만으로 앱 구축 | 완조리 식품 |

> 요약: 시각적 도구로 앱을 신속 개발하는 민주화된 플랫폼임.

## Ⅲ. 절차
- ASCII 흐름도
  Requirement -> Data Model -> UI Design -> Logic Set -> Deploy

1. 요구사항 도출: 현업 사용자의 필요 기능 식별 및 정의함.
2. 컴포넌트 조합: 플랫폼 제공 라이브러리를 드래그 앤 드롭함.
3. 비즈니스 로직 설정: 트리거 및 워크플로우 조건 설정함.
4. 원클릭 배포: 인프라 설정 없이 즉시 서비스 게시함.

> 요약: 전문 개발자 부족 해소 및 비즈니스 적시성(TTM) 극대화함.

## Ⅳ. 문제점
- 플랫폼 종속성(Vendor Lock-in) 및 확장성 한계 존재함.
- 섀도우 IT 확산에 따른 보안 및 거버넌스 통제 어려움함.

## Ⅴ. 개선방안
- 표준 API 연동 기능 강화 및 하이브리드 개발 방식 채택함.
- 전사적 LCNC 가이드라인 수립 및 중앙 집중 모니터링 체계함.

## Ⅵ. 전망
- 생성형 AI와 결합하여 자연어 기반 앱 생성으로 진화 예상됨.
- CSF: 비즈니스 가치 중심의 대상 업무 선정 및 거버넌스 정립임.
