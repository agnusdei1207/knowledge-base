## Ⅰ. 개요
- 정의: 테스트 시간 경과에 따른 결함 발견 확률을 수학적으로 모델링한 신뢰성 지표
- 배경: 잔존 결함을 예측하여 출시 시점 결정 및 신뢰도 목표 달성 여부 판단 필요
- 출제 의도: 주요 모델(J-M, G-O 등)의 특성 및 신뢰성 성장 추이 해석 능력 측정

## Ⅱ. 구성요소
- 구조도
  [Cumulative Faults]
    ^        / (Growth Curve)
    |     --/
    |  --/
    +-------------------> [Testing Time]

- 구성요소 표
| 모델 구분 | 설명 | 특징 |
| :--- | :--- | :--- |
| J-M 모델 | 결함 발견 시마다 결함 발견율 감소 가정 | 초기 신뢰성 모델 |
| G-O 모델 | 비균질 포아송 과정(NHPP) 기반 모델 | 시간에 따른 변화 반영 |
| Musa 모델 | 실행 시간 기반의 결함 발견율 예측 | 실행 집약적 분석 |
> 요약: 발견된 결함 데이터를 기반으로 미래의 고장 발생 가능성을 예측함

## Ⅲ. 절차
- 흐름도
  데이터 수집 -> 모델 선정 -> 파라미터 추정 -> 신뢰도 예측/검증
- 4단계 설명
1. 데이터 수집: 테스트 시간별 누적 결함 수 또는 고장 간격 시간 기록
2. 모델 선정: 데이터 분포 특성에 적합한 수학적 모델(로그, 지수 등) 선택
3. 파라미터 추정: 최대 우도법(MLE) 등을 사용하여 모델의 계수 산출
4. 신뢰도 예측: 목표 신뢰도 달성까지 필요한 추가 테스트 시간 예측
> 요약: 정량적 통계 분석을 통해 SW 배포 시점의 품질 안정성 보장

## Ⅳ. 문제점
- 실제 테스트 환경의 가변성(테스터 숙련도 등)을 수학적 모델이 모두 반영 못함
- 초기 결함 데이터 부족 시 예측 오차가 커져 잘못된 출시 의사결정 유발

## Ⅴ. 개선방안
- 다양한 모델의 앙상블 분석을 통한 예측 정확도 향상 및 편향성 제거
- 테스트 진행 단계별 가중치 부여 및 베이지안 기법을 활용한 모델 보정

## Ⅵ. 전망
- 실시간 텔레메트리 데이터를 활용한 런타임 신뢰성 예측 및 자가 치유 연계
- CSF: 정적 분석 결과와 결합된 다차원 신뢰성 평가 프레임워크 구축
