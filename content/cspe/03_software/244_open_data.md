## Ⅰ. 개요
- 정의: 공공기관이 보유한 데이터를 누구나 자유롭게 이용할 수 있도록 개방한 것임
- 배경: 공공 데이터의 민간 활용을 통한 신산업 창출 및 행정의 투명성 제고
- 출제 의도
| 대상 | 주요 포인트 | 비중 |
|------|------------|------|
| 개방 등급 | 5-Star Open Data | 매우높음 |
| 이용 활성화 | 공공데이터 포털 | 보통 |

## Ⅱ. 구성요소
- ASCII 구조도
  [ 공공기관 ] --- (데이터 개방) ---> [ 공공데이터 포털 ]
                                           |
  [ 새로운 가치 ] <--- (서비스 개발) --- [ 민간 이용자 ]

- 구성요소 표
| 구성요소 | 설명 | 비유 |
|----------|------|------|
| LOD | 연결된 오픈 데이터 (Linked Open Data) | 데이터 거미줄 |
| 파일 데이터 | CSV, JSON 등 다운로드 가능한 형태의 데이터 | 책 대출 |
| OpenAPI | 실시간 데이터 연계를 위한 프로그래밍 인터페이스 | 자판기 |

> 요약: 공공 데이터를 파일·OpenAPI·LOD 형태로 제공하여 민간이 재사용하도록 지원함

## Ⅲ. 절차
- ASCII 흐름도
  [대상 발굴] -> [데이터 정비] -> [심의 및 등록] -> [활용 및 환류]
    (전수 조사)      (표준/정제)       (공공데이터법)     (피드백 반영)

- 4단계 설명
1. 수요조사: 민간에서 필요로 하는 고가치/고수요 데이터를 발굴함
2. 품질관리: 데이터 오류를 수정하고 기계 판독이 가능한 형태로 정비함
3. 포털등록: 공공데이터 포털에 메타데이터를 등록하고 개방함
4. 사후지원: 이용자의 개선 요구 사항을 반영하여 데이터 품질을 고도화함

> 요약: 민간 수요를 조사하고 데이터 형식·오류·메타데이터를 정비한 뒤 이용 의견을 반영함

## Ⅳ. 문제점
- 형식적인 개방 수치에 치중하여 실제 사용하기 어려운 저품질 데이터 많음
- 기관별 데이터 표준이 상이하여 여러 기관의 데이터를 결합하기가 매우 힘듦

## Ⅴ. 개선방안
- (단기) 범정부 차원의 공공 데이터 표준 용어 및 도메인 사전을 적용함
- (중기) 데이터 품질 인증제(DQC-V 등)를 강화하여 고품질 데이터 공급 유도함
- (장기) 민간의 수요를 실시간 반영하는 '데이터 요구권' 제도를 법제화함

## Ⅵ. 전망
- AI 학습용 고품질 데이터셋 위주의 개방 정책이 국가 경쟁력의 핵심이 될 것임
- 데이터 댐(Data Dam) 사업과 연계하여 민간-공공 데이터 융합 시장이 급성장함
