## 미리 알고가기

- PCB: 프로세스 식별자·상태·CPU 문맥·메모리·파일 정보를 저장하는 커널 자료구조임
- CPU 문맥: 프로그램 카운터·스택 포인터·레지스터처럼 실행 재개에 필요한 상태임
- 컨텍스트 스위칭: 실행 주체의 문맥을 저장하고 다음 주체의 문맥을 복원하는 절차임

## 작성 근거(검토용)

- PCB의 저장 항목을 프로세스 식별·실행 재개·자원 관리 역할로 연결함
- 프로세스와 스레드 전환은 주소 공간 교체 여부와 캐시·TLB 영향으로 비교함
- 상태 저장·선택·복원 순서와 전환 비용을 운영체제 사례의 지표로 회수함

## Ⅰ. 개요
- **정의/개념**: PCB는 프로세스의 실행·자원 상태를 저장하고, 컨텍스트 스위칭은 현재 문맥을 저장한 뒤 다음 문맥을 복원하는 커널 절차임
- **배경/필요성**: 시분할 환경에서 중단된 실행을 같은 지점에서 재개하기 위해 문맥 저장·복원 구조가 필요함

## Ⅱ. 특징

- PCB는 프로세스 상태·프로그램 카운터·레지스터·메모리·열린 파일 정보를 보관함
- 인터럽트·시스템 호출·시간 할당량 만료·대기는 스케줄러 실행 계기가 됨
- 커널은 현재 문맥을 저장한 뒤 다음 실행 대상을 선택하고 문맥을 복원함
- 전환 횟수와 주소 공간 교체는 CPU 시간·캐시·TLB 적중률에 영향을 줌

## Ⅲ. 종류 및 비교

| 판단 기준 | 프로세스 전환 | 같은 프로세스의 스레드 전환 |
|:---|:---|:---|
| 저장 상태 | PCB와 CPU 문맥 | TCB와 CPU 문맥 |
| 주소 공간 | 다른 주소 공간으로 교체 | 주소 공간 공유 |
| 메모리 변환 영향 | TLB·페이지 테이블 문맥 변경 가능 | 같은 주소 변환 문맥 유지 |
| 공유 자원 | 열린 파일·메모리 경계 변경 | 코드·데이터·열린 파일 유지 |
| 주요 비용 | 문맥 저장·복원과 주소 공간 전환 | 문맥 저장·복원과 스케줄링 |

> 요약: 프로세스 전환은 주소 공간까지 바뀌고, 같은 프로세스의 스레드 전환은 실행 문맥만 교체함.

## Ⅳ. 구성요소 및 구조
```
+--------------------------+
| Process Control Block    |
+--------------------------+
| PID / State / PC         |
| Registers / Memory Limits|
| List of Open Files       |
+--------------------------+
```
| 구성요소 | 설명 | 저장 내용 |
| :--- | :--- | :--- |
| PID·상태 | 프로세스 식별자와 준비·실행·대기 상태를 저장함 | 스케줄링 대상 식별 |
| 프로그램 카운터 | 다음에 실행할 명령어 주소를 저장함 | 실행 재개 위치 |
| 레지스터·스택 포인터 | 연산 중간값과 호출 스택 위치를 저장함 | CPU 문맥 복원 |
| 메모리·파일 정보 | 주소 공간과 열린 파일·권한 정보를 연결함 | 자원 접근 복원 |
> 요약: PCB는 프로세스 식별자, 실행 상태, 레지스터, 메모리·파일 정보를 저장하는 커널 자료구조임.

## Ⅴ. 원리 및 절차 흐름도
```
[P1 실행] -> [Interrupt] -> [Save P1 to PCB1] -> [Load P2 from PCB2] -> [P2 실행]
```
1. **전환 계기 발생**: P1 실행 중 인터럽트·시스템 호출·시간 할당량 만료가 발생함
2. **현재 문맥 저장**: 레지스터와 프로그램 카운터를 PCB1에 저장함
3. **다음 대상 선택**: 스케줄러가 P2를 선택하고 PCB2의 실행 상태를 확인함
4. **다음 문맥 복원**: PCB2의 CPU 문맥을 복원하고 중단 지점부터 P2를 실행함
> 요약: 상태 저장과 복원을 통해 중단된 작업을 이어서 수행함.

## Ⅵ. 실무 사례

1. 시분할 서버는 시간 할당량을 조정하고 초당 문맥 전환 수와 p99 응답시간을 확인함
2. 멀티코어 운영체제는 CPU 친화도로 프로세스 이동을 제한하고 캐시 실패율과 전환시간을 확인함

## Ⅶ. 결론

- 컨텍스트 스위칭은 실행 재개 정확성을 유지하면서 전환 빈도와 캐시·TLB 손실을 통제해야 함
