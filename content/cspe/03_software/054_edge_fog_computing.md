## Ⅰ. 개요
- 정의: 데이터가 발생하는 현장(Edge)이나 인근(Fog)에서 즉시 처리하여 저지연을 구현하는 기술.
- 출제 의도: 중앙 집중식 클라우드의 한계(대역폭, 지연)를 극복하기 위한 분산 처리 패러다임 이해도 측정.

## Ⅱ. 구성요소
- ASCII 구조도
  [ Cloud ] (Central, Batch, Insight)
     |
  [ Fog Layer ] (Local Network, Processing nodes)
     |
  [ Edge Devices ] (IoT, Sensors, Real-time Action)
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| Edge | 단말 장치 자체 혹은 매우 가까운 게이트웨이에서의 처리 | 현장 요원 |
| Fog | 엣지와 클라우드 사이의 로컬 네트워크 계층에서의 처리 | 지역 지구대 |
| Cloud | 전체 데이터 통합 관리 및 장기 분석을 수행하는 중앙 서버 | 본청/사령부 |
> 요약: 엣지는 초저지연 실시간성, 포그는 지역적 협업, 클라우드는 광역 통찰에 집중함.

## Ⅲ. 절차
- ASCII 흐름도
  [데이터 생성] -> [로컬 필터링/분석] -> [즉시 피드백] -> [선별 데이터 클라우드 전송]
- 4단계 설명
1. 센서나 단말기에서 방대한 양의 원천 데이터를 생성함.
2. 엣지 노드에서 불필요한 노이즈를 제거하고 중요 이벤트만 선별함.
3. 지연 시간이 치명적인 제어 명령(자율주행 등)은 현장에서 즉시 수행함.
4. 요약되거나 장기 보관이 필요한 데이터만 중앙 클라우드로 전송하여 비용 절감함.
> 요약: 모든 데이터를 중앙으로 보내지 않고 '필요한 곳에서 처리'하는 방식임.

## Ⅳ. 문제점
- 보안 취약성: 분산된 수많은 기기가 물리적으로 외부에 노출되어 탈취 및 위변조에 취약함.
- 관리 복잡성: 수천 개 이상의 지점에 흩어진 기기의 펌웨어 업데이트 및 장애 관리 어려움.

## Ⅴ. 개선방안
- 하드웨어 보안: TPM(Trusted Platform Module) 및 하드웨어 암호화 가속기 적용 필요함.
- 컨테이너 기술: 쿠버네티스 엣지(K3s 등)를 활용하여 중앙에서 표준화된 배포 및 관리 수행함.

## Ⅵ. 전망
- 5G/6G 통신망의 MEC(Mobile Edge Computing)와 결합하여 자율주행, 원격 의료 핵심 기술로 정착됨.
- 엣지 기기 내에서 직접 AI 모델을 실행하는 'On-device AI' 기술이 대중화될 것임.
- 데이터 주권 및 개인정보 보호 강화 추세에 따라 민감 데이터를 현장에 가두는 기술로 가치 상승함.
