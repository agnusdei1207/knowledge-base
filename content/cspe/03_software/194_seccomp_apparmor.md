## Ⅰ. 개요
- **정의**: seccomp은 프로세스가 호출 가능한 시스콜을 제한하고, AppArmor는 파일·네트워크 등 자원 접근을 경로 기반으로 통제하는 리눅스 커널 보안 모듈
- **배경/필요성**: Namespace·Cgroup(193 참조)만으로는 커널 시스콜 악용·파일 무단 접근을 차단할 수 없어 추가 보안 계층이 필요함
- **비유**: seccomp은 전화기에서 특정 번호만 발신 허용하는 것, AppArmor는 건물 내 출입 가능 구역을 사원증으로 제한하는 것

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 컨테이너 심층 방어 이해 | seccomp-bpf 필터링 + AppArmor 프로파일 | SELinux와의 차이(라벨 vs 경로 기반) 언급 필요 |

> 요약: 시스콜 필터링과 경로 기반 접근 제어로 컨테이너 격리를 보완하는 커널 보안 메커니즘임

## Ⅱ. 구성요소
```text
Process
  |
  v
+------------+    +-------------+
| seccomp    |    | AppArmor    |
| (syscall   |    | (path-based |
|  filter)   |    |  MAC)       |
+------+-----+    +------+------+
       |                 |
       v                 v
   Kernel Syscall    VFS / Network
   Interface         Access Control
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| seccomp-bpf | BPF 프로그램으로 시스콜 번호·인자를 검사하여 허용/거부/로그 결정 | 발신 번호 화이트리스트 |
| AppArmor Profile | 파일 경로·네트워크·capability별 허용/거부 규칙을 정의하는 텍스트 프로파일 | 구역별 출입 명단 |
| LSM Hook | 커널 내부에서 AppArmor가 접근 판단을 수행하는 보안 훅 지점 | 건물 출입구 센서 |

> 요약: seccomp이 시스콜 수준, AppArmor가 자원 경로 수준에서 이중 접근 통제를 수행함

## Ⅲ. 절차
```text
프로파일 작성 --> 로드 --> 적용 --> 감사
```
- 1단계: seccomp JSON 필터 및 AppArmor 프로파일을 애플리케이션 요구에 맞게 작성
- 2단계: seccomp 필터는 `prctl()`/`seccomp()` 시스콜로, AppArmor 프로파일은 `apparmor_parser`로 커널에 로드
- 3단계: 컨테이너 런타임이 프로세스 생성 시 해당 필터·프로파일을 자동 적용
- 4단계: 차단 이벤트를 `audit` 로그로 수집하여 오탐 분석 및 프로파일 튜닝

> 요약: 작성-로드-적용-감사의 4단계로 시스콜·자원 접근 정책을 운영함

## Ⅳ. 문제점
- 프로파일 작성 부담: 애플리케이션별 허용 시스콜·경로 목록 도출에 수작업 소요
- 오탐에 의한 장애: 과도한 차단 규칙이 정상 동작을 방해하여 서비스 중단 유발
- 런타임 간 불일치: Docker·containerd·CRI-O별 기본 프로파일이 달라 보안 수준 편차 발생

> 요약: 프로파일 작성 부담·오탐·런타임 불일치가 실무 적용의 주요 장애물임

## Ⅴ. 개선방안
1. 단기: `complain` 모드로 실행 후 감사 로그 기반 프로파일 자동 생성 도구 활용
2. 중기: OCI 런타임 표준에 기본 seccomp·AppArmor 프로파일 통합으로 오탐 최소화
3. 장기: eBPF(191 참조) 기반 동적 정책 학습으로 런타임 간 일관된 보안 정책 자동 적용

> 요약: 자동 프로파일 생성-표준화-동적 학습 순으로 보안 정책 운영 부담을 경감하는 방향임

## Ⅵ. 전망
- 발전 방향: seccomp-bpf 고도화와 AppArmor 4.x의 규칙 표현력 확장이 진행 중
- 기술사적 판단: 컨테이너 심층 방어(Defense-in-Depth)의 필수 구성 요소로 위상 확립
- 기술사 제언: Namespace·Cgroup(193 참조)과 조합한 계층적 보안 아키텍처 설계 역량 필요
