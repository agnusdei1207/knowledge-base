## 미리 알고가기

- 피처 플래그는 코드 배포와 기능 공개를 분리하는 제어 장치임
- 런타임에 사용자 그룹별로 기능 활성 여부를 바꿀 수 있음
- 오래 남은 플래그는 기술부채가 되기 쉽다

## Ⅰ. 개요

- **정의/개념**: 피처 플래그는 코드에 포함된 기능의 활성 여부를 런타임 설정으로 제어해 배포 시점과 사용자 노출 시점을 분리하는 기능 토글 메커니즘임
- **배경/필요성**: 기능을 코드 병합과 동시에 모두 공개하면 배포 위험이 커지므로, 점진 출시와 A/B 테스트와 비상 차단을 위한 제어 수단이 필요함

## Ⅱ. 특징

- 배포와 공개를 분리해 릴리스 위험을 줄임
- 사용자 세그먼트별 실험과 점진 확대가 가능함
- 플래그 수가 늘면 조합 복잡도와 테스트 범위가 증가함
- 만료 관리가 없으면 레거시 분기가 누적된다

## Ⅲ. 종류 및 비교

| 판단 기준 | 직접 코드 배포 공개 | 피처 플래그 사용 |
|:---|:---|:---|
| 공개 시점 | 배포와 동시에 공개 | 설정으로 분리 가능 |
| 장점 | 단순함 | 점진 출시와 긴급 차단 가능 |
| 한계 | 위험 노출 큼 | 운영 복잡도와 부채 증가 가능 |
| 적합 환경 | 단순 릴리스 | 실험과 점진 배포 환경 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Flag Definition | 어떤 기능을 어떤 조건에서 켜고 끌지 정의해 관리 단위를 만든다 |
| Targeting Rule | 사용자 그룹이나 환경이나 비율 기준으로 기능 노출 범위를 결정함 |
| Runtime Evaluation | 요청 시 플래그 상태를 평가해 코드 경로를 선택함 |
| Flag Lifecycle | 생성과 확장과 제거 시점을 관리해 장기 부채를 억제함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 플래그 생성    | --> | 대상 규칙 설정 | --> | 런타임 평가    | --> | 확대/제거 관리 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **플래그 생성**: 기능별 토글을 정의함
2. **대상 규칙 설정**: 사용자와 환경과 비율 기준을 설정함
3. **런타임 평가**: 요청 시 플래그 상태로 기능 노출을 결정함
4. **확대 및 제거 관리**: 안정화 후 전체 확대하거나 코드를 정리함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 플래그가 오래 남아 분기 수가 늘어나면 테스트 조합과 코드 이해 비용이 급격히 증가할 수 있음
   - 해결방안: 만료일과 오너를 지정하고 stale flag count와 branch complexity score로 검증함
2. 문제: 런타임 평가 실패나 설정 불일치가 있으면 사용자 경험이 예측 불가능하게 흔들릴 수 있음
   - 해결방안: 안전한 기본값과 설정 검증을 적용하고 flag evaluation error rate와 rollout consistency로 검증함
3. 문제: 실험과 긴급 차단과 장기 권한 토글을 같은 방식으로 관리하면 운영 혼선이 생길 수 있음
   - 해결방안: 플래그 유형별 정책을 분리하고 flag type policy compliance와 cleanup lead time으로 검증함

## Ⅶ. 적용 사례

- 점진 출시 환경에서는 피처 플래그를 사용하고, rollout consistency와 stale flag count로 결과를 확인함
- A/B 테스트 운영에서는 세그먼트 규칙을 적용하고, experiment exposure accuracy와 branch complexity score로 결과를 확인함
- 장애 대응 체계에서는 kill switch를 운영하고, emergency disable time과 flag evaluation error rate로 결과를 확인함

## Ⅷ. 결론

피처 플래그의 가치는 기능을 더 많이 숨기는 데 있지 않고 공개 위험을 제어하되 오래 남은 분기를 빠르게 제거하는 운영 규율에 있음.
