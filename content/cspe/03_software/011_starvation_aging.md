## Ⅰ. 개요
- 정의: 낮은 우선순위의 프로세스가 영원히 CPU를 할당받지 못하는 현상(Starvation)과 이를 해결하기 위해 대기 시간에 비례하여 우선순위를 높이는 기법(Aging)
- 배경: 우선순위 기반 스케줄링에서 낮은 우선순위 작업의 장기 대기를 제한해야 함
- 출제 의도: 자원 할당 불균형의 원인 분석 및 해결 메커니즘인 에이징의 동작 원리 파악

## Ⅱ. 구성요소
```
[ Queue ]  P1(High)  P2(High)  ...  P100(Low)
             |         |              |
             +---------+              | <-- Forever Waiting (Starvation)
                                      v
                               [ Aging Applied ]
                               Priority: Low -> Med -> High
```
| 구성요소 | 설명 | 판단 기준 |
| :--- | :--- | :--- |
| 기아 현상 | 높은 우선순위 작업에 밀려 특정 작업 실행이 계속 지연됨 | 대기 시간 |
| 에이징 | 대기 시간이 경과할수록 우선순위 값을 점진적으로 증가시킴 | 우선순위 증가율 |
| 우선순위 | 스케줄러가 작업을 선택하는 기준값 | 실행 대상 선택 |
> 요약: 에이징은 대기 시간을 우선순위에 반영해 장기 대기를 줄임.

## Ⅲ. 절차
```
[Wait] -> [Check Time] -> [Priority Increment] -> [Scheduling]
```
1. 낮은 우선순위의 프로세스가 실행되지 못하고 Ready Queue에서 대기함
2. 시스템은 주기적으로 각 프로세스의 대기 시간을 체크함
3. 일정 시간이 경과할 때마다 해당 프로세스의 우선순위 수치를 상향 조정함
4. 보정된 우선순위가 실행 기준을 충족하면 스케줄러가 해당 프로세스를 선택함
> 요약: 대기 시간이 길수록 선택 가능성이 커지도록 우선순위를 보정함.

## Ⅳ. 문제점
- 원인: 에이징 반영 주기가 너무 길면 실질적인 기아 방지 효과가 미미함
- 원인: 과도한 우선순위 상승은 긴급 작업 우선 정책을 약화시킬 수 있음

## Ⅴ. 개선방안
- (단기) 시스템 부하에 따라 에이징 수치와 주기를 동적으로 조절하는 적응형 에이징 도입
- (중기) 다단계 피드백 큐(MLFQ)와 결합하여 자연스러운 우선순위 흐름 유도
- (장기) 공정성 기반의 CFS(Completely Fair Scheduler) 등 현대적 알고리즘으로의 전환

## Ⅵ. 전망
- 스케줄러는 마감 시간, 대기 시간, 우선순위를 함께 반영해 aging 가중치를 조정하는 방향으로 발전함
- 분산 자원 할당에서는 노드별 대기 시간 편차를 줄이는 전역 큐 관리가 쟁점이 됨

## 작성 근거(검토용)

- 기아와 에이징은 결과 단정이 아니라 대기 시간과 우선순위 보정 절차로 설명해야 문맥이 맞음
- 차단 단정을 제거하고 장기 대기 감소와 선택 가능성 증가라는 조건부 효과로 표현함
