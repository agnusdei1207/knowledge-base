## Ⅰ. 개요
- 정의: 낮은 우선순위의 프로세스가 영원히 CPU를 할당받지 못하는 현상(Starvation)과 이를 해결하기 위해 대기 시간에 비례하여 우선순위를 높이는 기법(Aging)
- 배경: 우선순위 기반 스케줄링의 부작용을 억제하여 시스템의 공정성(Fairness)을 확보하기 위함
- 출제 의도: 자원 할당 불균형의 원인 분석 및 해결 메커니즘인 에이징의 동작 원리 파악

## Ⅱ. 구성요소
```
[ Queue ]  P1(High)  P2(High)  ...  P100(Low)
             |         |              |
             +---------+              | <-- Forever Waiting (Starvation)
                                      v
                               [ Aging Applied ]
                               Priority: Low -> Med -> High
```
| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| 기아 현상 | 자원 점유의 편중으로 특정 작업이 무한 정체됨 | 소외된 대기자 |
| 에이징 | 대기 시간이 경과할수록 우선순위 값을 점진적 증가 | 호봉제 승진 |
| 우선순위 | 스케줄러가 작업을 선택하는 기준값 | 등급 |
> 요약: 에이징은 시간이라는 요소를 우선순위에 결합하여 기아를 원천 봉쇄함.

## Ⅲ. 절차
```
[Wait] -> [Check Time] -> [Priority Increment] -> [Scheduling]
```
1. 낮은 우선순위의 프로세스가 실행되지 못하고 Ready Queue에서 대기함
2. 시스템은 주기적으로 각 프로세스의 대기 시간을 체크함
3. 일정 시간이 경과할 때마다 해당 프로세스의 우선순위 수치를 상향 조정함
4. 충분히 높아진 우선순위에 의해 스케줄러가 해당 프로세스를 실행 대상으로 선택
> 요약: 오래 기다린 만큼 보상(우선순위 상승)을 주어 실행 기회를 보장함.

## Ⅳ. 문제점
- 원인: 에이징 반영 주기가 너무 길면 실질적인 기아 방지 효과가 미미함
- 원인: 과도한 우선순위 상승은 시스템의 원래 설계 의도(긴급 작업 우선)를 왜곡할 수 있음

## Ⅴ. 개선방안
- (단기) 시스템 부하에 따라 에이징 수치와 주기를 동적으로 조절하는 적응형 에이징 도입
- (중기) 다단계 피드백 큐(MLFQ)와 결합하여 자연스러운 우선순위 흐름 유도
- (장기) 공정성 기반의 CFS(Completely Fair Scheduler) 등 현대적 알고리즘으로의 전환

## Ⅵ. 전망
- 지능형 스케줄러에서는 프로세스의 마감 시간과 중요도를 AI가 분석하여 에이징 가중치를 최적화할 것임
- 분산 컴퓨팅 자원 할당 시 노드 간의 기아 방지를 위한 글로벌 에이징 프로토콜 연구가 활발해질 전망임
