## Ⅰ. 개요
- 정의: 기업의 인사, 재무, 생산 등 핵심 프로세스를 통합 관리하는 정보시스템임
- 배경: 부서별 업무와 데이터의 중복을 줄이고 전사 자원 현황을 같은 기준으로 관리할 필요
- 출제 의도
| 대상 | 주요 포인트 | 비중 |
|------|------------|------|
| 특징 | 통합성, 실시간, Best Practice | 높음 |
| 발전 | Cloud ERP, AI ERP | 보통 |

## Ⅱ. 구성요소
- ASCII 구조도
  [ 영업 ] --+-- [ 재무 ] --+-- [ 인사 ]
             |      |      |
          [ 통합 데이터베이스 ]
             |      |      |
  [ 생산 ] --+-- [ 물류 ] --+-- [ 구매 ]

- 구성요소 표
| 구성요소 | 설명 | 비유 |
|----------|------|------|
| 모듈 (Module) | 특정 업무 기능을 수행하는 단위 소프트웨어 | 조립식 레고 블록 |
| 프로세스 (BPR) | 업무 목표와 책임에 맞춘 절차 재설계 | 이동 동선 재설계 |
| 인터페이스 | 외부 시스템(금융, 세무 등)과의 데이터 연계 | 통로 |

> 요약: 업무 모듈이 통합 데이터베이스를 공유하여 부서 간 거래와 자원 상태를 연계함

## Ⅲ. 절차
- ASCII 흐름도
  [전략 수립] -> [패키지 선정] -> [커스터마이징] -> [안정화/운영]
    (BPR 수행)       (Fit-Gap분석)      (Add-on 개발)      (Post-Go Live)

- 4단계 설명
1. 사전분석: 비즈니스 프로세스를 혁신(BPR)하고 ERP 도입 범위를 확정함
2. 설계구현: 표준 프로세스와 현재 업무의 차이(Fit-Gap)를 분석하여 보완함
3. 테스트: 실제 데이터를 입력하여 통합 시나리오 기반의 안정성을 검증함
4. 교육전환: 사용자 교육을 실시하고 신구 시스템 간 데이터를 이관하여 오픈함

> 요약: 표준 프로세스 이식과 최소한의 개발로 시스템 통합을 달성함

## Ⅳ. 문제점
- 현업 부서의 변화 거부 및 기존 업무 방식 고수(Over-Customizing)로 인한 실패함
- 클라우드 전환 시 데이터 보안 우려 및 기존 레거시 시스템과의 연동 복잡함

## Ⅴ. 개선방안
- (단기) 경영진의 강력한 의지(Top-down) 표명 및 사용자 변화 관리 강화함
- (중기) 클라우드 기반 SaaS ERP 도입으로 인프라 비용 절감 및 유연성 확보함
- (장기) AI와 RPA를 결합하여 단순 반복 업무를 자동화하는 지능형 ERP 구축함

## Ⅵ. 전망
- 컴포저블(Composable) ERP를 통해 필요한 기능만 신속하게 조립하여 사용함
- 실시간 공급망과 연계된 확장형 ERP(X-ERP)가 비즈니스 생태계를 통합할 것임
