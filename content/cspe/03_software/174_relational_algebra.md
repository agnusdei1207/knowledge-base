## Ⅰ. 개요
- 정의: 관계형 데이터베이스에서 데이터를 처리하는 절차적/비절차적 이론 기반 연산
- 배경: SQL 질의를 관계와 집합 연산으로 표현하고 변환하기 위한 이론 제공
| 구분 | 내용 |
|------|------|
| 출제 의도 | 선택, 추출, 조인 등 주요 연산자의 기호와 의미 명확화 |

## Ⅱ. 구성요소
  Relation A (Set) ---[ Operator ]---> Relation B (Result)
  (Selection, Projection, Join...)
| 구성요소 | 설명 | 비유 |
|----------|------|------|
| Selection(σ) | 행(Tuple) 단위 조건 필터링 | 체 거르기 |
| Projection(π) | 열(Attribute) 단위 데이터 추출 | 세로 자르기 |
| Join(⋈) | 공통 속성 기준 두 관계 결합 | 조립하기 |
> 요약: 선택·추출·조인·집합 연산을 조합하여 관계를 다른 관계로 변환함

## Ⅲ. 절차
  Define Schema -> Input Set -> Apply Operator -> Result Set
1. Selection: 특정 조건을 만족하는 튜플들을 집합에서 선택
2. Projection: 필요한 속성(컬럼)들만 남기고 중복 제거
3. Join: 두 릴레이션을 연결하여 정보를 통합
4. Set Operation: 합집합, 교집합, 차집합 등을 수행
> 요약: 입력 관계에 연산자를 순서대로 적용하여 결과 관계를 산출함

## Ⅳ. 문제점
- 선택·조인 순서에 따라 중간 결과 크기와 처리 비용 증가
- 관계 해석과 달리 절차를 명시해야 하므로 복잡성 존재

## Ⅴ. 개선방안
- 질의 최적화 도구를 통한 연산자 재배치(Selection 우선 수행)
- 관계 해석과 병행하여 선언적 질의 능력 향상

## Ⅵ. 전망
- 그래프 데이터 모델 등 비관계형 모델의 관계 대수적 확장 및 대수 구조 기반 쿼리 언어 진화
