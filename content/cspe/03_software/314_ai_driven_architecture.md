## Ⅰ. 개요
- 정의: AI 모델을 시스템의 핵심 구성 요소로 통합하여 지능형 서비스를 제공하는 구조임
- 배경: 데이터 기반의 자동 의사결정 수요 증가 및 복잡한 문제의 기계학습 해결 필요
- 출제 의도: MLOps 기반의 모델 배포, 추론 성능 최적화, 피드백 루프 설계 이해 확인

## Ⅱ. 구성요소
- ASCII 구조도
  [Data Pipeline] -> [Model Training] -> [Model Serving]
          ^                                     |
          +----------(Feedback Loop)------------+
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| 피처 스토어 | 학습과 추론에 필요한 데이터를 가공/저장함 | 식재료 창고 |
| 서빙 레이어 | 모델을 API 형태로 제공하여 요청을 처리함 | 주방/서빙 |
| 모니터링 | 모델의 성능 저하(Drift)를 감시하고 재학습함 | 품질 검사 |
> 요약: 데이터 수집부터 모델 학습, 배포, 모니터링이 순환하는 파이프라인 구조임

## Ⅲ. 절차
- ASCII 흐름도
  Problem ID -> Data Eng -> Model Dev -> Deployment/Ops
- 4단계 설명
1. Problem ID: AI로 해결할 비즈니스 문제 정의 및 성능 지표(KPI) 설정함
2. Data Eng: 대용량 데이터 정제, 특징(Feature) 추출 및 파이프라인 구축함
3. Model Dev: 알고리즘 선정, 하이퍼파라미터 튜닝 및 학습 수행함
4. Deployment/Ops: 추론 서버 구축, 모델 버전 관리 및 성능 모니터링 수행함
> 요약: 비즈니스 문제를 정의하고 데이터와 모델을 결합하여 운영 체계를 구축함

## Ⅳ. 문제점
- 원인이 명시된 문제/한계: 데이터 분포 변화에 따른 모델 정확도 하락(Model Drift) 발생함

## Ⅴ. 개선방안
- Ⅳ의 문제에 대응하는 방안: 자동 재학습 파이프라인 구축 및 지속적 학습(Continuous Learning)함

## Ⅵ. 전망
- 발전 방향: 거대언어모델(LLM) 기반의 RAG 아키텍처 및 에이전트형 자율 서비스 확산
- CSF: 모델의 기술적 성능뿐만 아니라 데이터 편향성 제거 및 윤리적 정당성 확보가 관건임
