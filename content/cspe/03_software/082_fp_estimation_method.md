# 📖 【암기용】 개념 완전 이해

> 목적: FP 간이법과 정통법을 요구사항 상세도에 따라 선택하는 기준으로 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 설명이다.

## 한눈에
- **개요**: FP 간이법·정통법은 기능점수 산정 방식의 상세 수준을 달리한 방법
- **왜 필요한가**: 기획 초기에는 상세 DET/FTR이 부족하고, 계약·검수 단계에는 정밀 산정 근거가 필요하다.
- **핵심 직관**: 초기에는 평면도 면적으로 예산을 잡고, 착공 전에는 자재 수량까지 세는 차이와 같음.

## 깊이 이해
- **배경·문제의식**: 모든 사업에서 정통법을 쓰면 산정 시간이 길어지고, 모든 사업에서 간이법을 쓰면 계약 분쟁과 과소추정이 발생함.
- **작동 원리**: 간이법은 기능유형별 평균 복잡도나 표준 가중치로 빠르게 추정하고, 정통법은 DET·RET·FTR을 기준으로 낮음·보통·높음 복잡도를 판정함.
- **비유**: 이사 견적에서 방 개수만 보고 1차 견적을 내는 것이 간이법, 짐 박스·가전·사다리차를 세는 것이 정통법임.
- **구체 예시**: RFP 단계 120개 화면은 간이법으로 예산 범위를 잡고, 분석 완료 후 EI 45·EO 20·EQ 30·ILF 12·EIF 8로 정통법 재산정.
- **흔한 오해·주의점**: 간이법은 대충 세는 방식이 아니라 요구사항 미성숙 시점의 공식 추정이며, 기준선 확정 후 정통법 전환이 필요함.

## 연결 개념
- Function Point: 간이법과 정통법의 공통 산정 단위
- SW Cost Estimation: 산정 방법 선택이 사업비에 직접 연결
- 요구사항 기준선: 정통법 전환 시점 판단 근거

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.
> 핵심: 간이법·정통법 문제는 계산식 암기가 아니라 사업 단계, 산정 근거, 재산정 통제를 연결해 써야 한다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: FP 산정 방법은 요구사항 상세도에 따라 간이법과 정통법을 선택하는 규모 추정 체계이다.
> 2. **가치**: 초기 예산 편성에는 간이법, 계약·분석·검수에는 정통법을 적용해 산정 시간과 정확도 균형을 맞춘다.
> 3. **판단 포인트**: RFP, 분석 완료, 변경 승인 단계별로 산정 기준선을 분리하지 않으면 대가 분쟁이 발생한다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 산정 방법 선택 역량 확인 | 간이법·정통법 차이, 적용 시점, 입력 산출물 | 두 방법을 우열 관계로 단정하지 않음 |
| 공공 SW 계약 실무 이해 확인 | 기준선 FP, 변경 FP, 검수 FP | 최초 견적을 최종 계약 기준으로 고정하지 않음 |
| 산정 품질 통제 확인 | DET/RET/FTR, 산정자 편차, 재산정 트리거 | 화면 수만으로 정통법을 설명하지 않음 |
> 요약: 방법 선택은 요구사항 성숙도와 계약 단계에 맞춰 간이 추정에서 정밀 검증으로 전환하는 판단 문제이다.

---

## Ⅰ. 개요 및 필요성

- 개요: 기능점수 상세도 선택 절차
- 배경: 초기 기획에는 요구사항이 불완전해 정통법 적용 근거가 부족하고, 계약 이후에는 기능유형과 복잡도 근거가 필요하다.
- 필요성: 간이법은 예산 범위를 산정하고 정통법은 기능유형, DET, RET, FTR 근거로 기준선과 변경 대가를 확정한다.

---

## Ⅱ. 구조 및 구성요소

```text
사업 단계 -> 요구사항 상세도 판단 -> 산정 방법 선택
기획/RFP -> 간이법 -> 예산 범위 FP
분석/계약/검수 -> 정통법 -> 기준선 FP/변경 FP
```

| 구성요소 | 역할 | 산정 포인트 |
|:---|:---|:---|
| 간이법 | 초기 기능량 추정 | 평균 복잡도, 기능목록, 화면·보고서 기준 |
| 정통법 | 기능유형별 정밀 산정 | EI·EO·EQ·ILF·EIF, DET/RET/FTR |
| 기준선 FP | 계약·일정 기준 | 분석 완료 시점 승인 |
| 변경 FP | 범위 변경 비용 산정 | 변경요청서와 승인 이력 |
> 요약: FP 산정 방법은 초기 추정, 기준선 확정, 변경 산정으로 분리해 적용해야 한다.

## Ⅲ. 동작원리 및 흐름도

```text
요구사항 성숙도 평가 -> 간이법 1차 산정 -> 예산 범위 설정
-> 분석 산출물 확정 -> 정통법 재산정 -> 기준선 승인
-> 변경요청 발생 -> 변경 FP 산정 -> 계약·일정 반영
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | RFP 기능목록 기반 간이 산정 | 기능목록 누락률 5% 이하 |
| 2 | 분석 단계 기능유형 재분류 | EI·EO·EQ·ILF·EIF 검토표 |
| 3 | DET/RET/FTR 복잡도 판정 | 산정 근거 첨부율 100% |
| 4 | 기준선 FP 승인 | 발주자·수행사 합의 기록 |
| 5 | 변경 FP 분리 산정 | 변경요청 처리기한 5영업일 |
> 요약: 간이법은 예산 범위, 정통법은 기준선과 변경 대가를 확정하는 순서로 동작한다.

> 요약: 간이법은 초기 의사결정, 정통법은 계약 근거와 검수 통제에 적합하다.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. RFP 단계는 간이법으로 예산 범위 FP를 산정하고 산정 편차 20% 범위를 계약 전 검토자료에 명시함.
2. 분석 완료 시 EI·EO·EQ·ILF·EIF와 DET·RET·FTR 근거를 포함한 정통법 산정표를 승인받음.
3. 기준선 승인 이후 추가·변경·삭제 기능은 변경 FP로 분리하고 비용·일정 영향도를 승인 프로세스에 연결함.

**결론 (2줄):**
- 기술사 판단: 요구사항 상세도가 낮으면 간이법, 계약·검수 책임이 있으면 정통법을 선택함.
- 향후 방향: FP 산정 도구는 요구사항 관리, 변경관리, 대가산정 산출서를 연결하는 통합 추적 체계로 발전함.
