## 미리 알고가기

- 정통법은 기능 항목을 공식 규칙에 따라 세부적으로 계산하는 방식임
- 간이법은 제한된 요구 정보와 표준 계수로 개략 규모를 추정하는 방식임
- 요구 상세도와 계약 목적에 따라 적합한 방법이 달라짐

## 작성 근거(검토용)

- 제목·frontmatter·미리 알고가기·본문·표·요약·결론을 5회 전수 검수해 어색한 단어·조사·동사 결합·장황한 명사구를 교정함
- 기능점수 간이법·정통법은 요구 상세도, 기능 분류 깊이, 산정 오차를 핵심 축으로 설명함
- 비교표는 입력 정보·가중치·산정 부담·적용 단계를 같은 기준으로 대비함
- 제안과 계약 산정은 추정 소요 시간·재산정 오차와 측정자 간 일치율로 검증함

## Ⅰ. 개요

- **정의/개념**: 간이법은 개략 기능 수와 평균 가중치로 기능점수를 추정하고, 정통법은 기능 유형과 데이터 요소별 복잡도를 산정함
- **배경/필요성**: 제안·계약 단계의 요구 상세도와 허용 오차에 맞는 기능점수 산정 방법을 선택하기 위해 비교 기준이 필요함

## Ⅱ. 특징

- 정통법은 기능별 데이터 요소와 참조 파일 수를 기준으로 복잡도를 산정함
- 간이법은 개략 기능 수와 평균 가중치를 사용하므로 상세 산정 후 편차를 보정함
- 요구 상세도와 계약 목적에 따라 방법 선택이 달라짐
- 둘 중 하나가 항상 우월한 방식은 아님

## Ⅲ. 종류 및 비교

| 판단 기준 | 간이법 | 정통법 |
|:---|:---|:---|
| 입력 정보 | 제한된 요구 정보와 개략 범위로 추정함 | 상세 요구와 데이터 구조를 기준으로 산정함 |
| 산정 방식 | 개략 기능 수에 표준·평균 계수 적용 | 기능 유형별 데이터 요소로 복잡도 산정 |
| 주요 한계 | 과소·과대 추정 편차가 커질 수 있음 | 시간과 비용과 측정 전문성이 더 많이 듦 |
| 활용 단계 | 예비 검토·초기 제안 | 계약 산정·정산·상세 계획 |

> 요약: 간이법은 제한된 정보와 평균 계수로 개략 규모를 추정하고, 정통법은 상세 기능과 복잡도로 기능점수를 산정함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 요구 상세도 | 요구가 얼마나 구체적인지가 간이법과 정통법 선택의 출발점이 됨 |
| 기능 분류 규칙 | 기능 항목 분류 정확도가 최종 결과 품질을 좌우함 |
| 가중치와 보정 | 간이법은 표준 계수 중심이고 정통법은 세부 복잡도 반영이 중심임 |
| 교차 검토 | 기능 분류와 가중치 적용 결과를 대조해 측정자 간 편차를 줄임 |

> 요약: 요구 상세도와 산정 목적을 기준으로 방법을 선택하고 기능 분류·가중치 결과를 교차 검토함.

## Ⅵ. 실무 사례

1. 제안 견적은 간이법의 오차 범위와 정통법 재산정 시점을 명시하고 추정 소요 시간·재산정 오차를 확인함
2. 상세 계약은 정통법 측정 결과를 교차 검토하고 측정자 간 편차·측정 일치율을 확인함

## Ⅶ. 결론

- 기능점수는 요구 상세도와 허용 오차에 따라 간이법 또는 정통법을 선택함
