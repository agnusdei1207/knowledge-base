## Ⅰ. 개요
| 구분 | 내용 |
|---|---|
| 정의 | 주기억장치(RAM)의 효율적 사용을 위한 할당, 배치, 교체 전략 |
| 필요성 | 메모리 단편화 최소화, 멀티프로그래밍 정도 향상 및 프로세스 보호 |
| 출제 의도 | 단편화(Internal/External), 배치(First/Best/Worst Fit), 교체 알고리즘 이해 |

## Ⅱ. 구성요소
```text
[ Physical Memory ]      [ Allocation Strategy ]
+---------------+        - First Fit: 첫 가용한 공간
|   Process A   |        - Best Fit: 가장 작은 공간
+---------------+        - Worst Fit: 가장 큰 공간
|   (Hole)      |        [ Replacement Strategy ]
+---------------+        - FIFO, LRU, LFU, NUR
|   Process B   |        - Optimal (이론적 최적)
+---------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 단편화 | 빈 공간이 흩어져 있어 활용 못하는 현상 | 빈방이 있으나 예약불가 |
| 배치 전략 | 프로세스를 어느 빈 공간에 넣을지 결정 | 숙소 방 배정 방식 |
| 교체 전략 | 메모리 부족 시 내보낼 프로세스/페이지 선택 | 만기 투숙객 퇴실 |
> 요약: 배치 전략은 입력 효율을, 교체 전략은 메모리 유지 효율을 극대화함.

## Ⅲ. 절차
```text
Request Memory -> Search Free Block -> Select by Strategy -> Allocate
      ^                                                     |
      +----- (Not Enough) ----- Page Replacement <----------+
```
1. 할당 요청: 프로세스가 실행을 위해 특정 크기의 메모리 영역을 요청.
2. 빈 공간 탐색: 메모리 맵 또는 리스트를 검색하여 가용 블록 확인.
3. 배치 전략 적용: Best Fit 등 기준에 따라 가장 적합한 블록 선택.
4. 교체 및 할당: 빈 공간 부족 시 교체 알고리즘 가동 후 새 프로세스 적재.
> 요약: 단편화를 줄이면서 프로세스에 필요한 메모리를 적기에 할당하는 과정임.

## Ⅳ. 문제점
- 고정 분할 시 내부 단편화, 가변 분할 시 외부 단편화로 인한 메모리 낭비.
- LRU 등 정교한 교체 알고리즘 사용 시 참조 비트 유지 등 하드웨어 오버헤드.

## Ⅴ. 개선방안
- 페이징(Paging) 및 세그멘테이션 기법으로 불연속 할당 허용 및 단편화 제거.
- 압축(Compaction) 또는 통합(Coalescing)을 통한 가용 블록 크기 대형화.

## Ⅵ. 전망
- 비휘발성 메모리(NVM): DRAM과 NAND의 특성을 합친 메모리 계층 관리 기술 대두.
- CXL(Compute Express Link): 호스트-디바이스 간 대용량 메모리 공유/확장 기술 확산.
