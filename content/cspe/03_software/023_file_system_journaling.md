## 미리 알고가기

- 저널링은 실제 반영 전에 변경 내역을 로그에 먼저 기록하는 방식임
- 메타데이터 저널링은 파일 시스템 구조 정보 중심으로 보호함
- Writeback·Ordered·Journal 모드는 데이터 기록 순서와 보호 범위가 다름
- 트랜잭션: 저널에 함께 기록되고 함께 반영되는 변경 묶음임
- 체크포인트: 커밋된 트랜잭션을 본래 위치에 반영하고 저널 공간을 회수하는 지점임

## 작성 근거(검토용)

- Writeback·Ordered·Journal 모드를 쓰기 경로 및 기록 순서·장애 후 상태·적합 조건으로 비교함
- 변경 수집·저널 기록·커밋·체크포인트·재생을 실제 트랜잭션 상태 전이로 구성함
- 일반 서버와 데이터 무결성 저장소를 분리해 쓰기 지연과 재생시간을 검증함

## Ⅰ. 개요

- **정의/개념**: 파일 시스템 저널링은 메타데이터·데이터 변경을 저널에 먼저 기록하고 장애 후 커밋된 트랜잭션만 재생하는 일관성 복구 기법임
- **배경/필요성**: 전원 장애나 커널 패닉이 발생하면 메타데이터 갱신이 중간에 끊겨 파일 시스템이 손상될 수 있으므로, 전체 검사 비용을 줄이고 복구 시간을 단축하는 구조가 필요함

## Ⅱ. 특징

- 커밋된 저널 트랜잭션만 재실행해 전체 파일시스템 검사 범위를 줄임
- 보호 범위에 따라 메타데이터 중심과 데이터 포함 방식으로 나뉨
- 보호 범위를 넓히면 저널 쓰기량이 증가하는 상충 관계가 있음
- 저널 크기·플러시 정책·저장장치 특성이 쓰기 지연과 복구시간에 영향을 줌

## Ⅲ. 종류 및 비교

| 판단 기준 | Writeback 모드 | Ordered 모드 | Journal 모드 |
|:---|:---|:---|:---|
| 쓰기 경로·기록 순서 | 데이터 1회 기록, 메타데이터 커밋과 순서 보장 없음 | 데이터 선행 기록 후 메타데이터 커밋 | 데이터·메타데이터를 저널에 먼저 기록 후 본래 위치 반영 |
| 장애 후 상태 | 메타데이터 구조만 복구, 데이터 내용 불일치 가능 | 커밋된 메타데이터가 미기록 데이터를 가리키지 않음 | 저널의 데이터·메타데이터를 재생해 복구 |
| 적합 조건 | 쓰기 처리량 우선 | 일반 서버의 순서·비용 균형 | 데이터 복구 범위 우선 |

> 요약: Writeback은 데이터 순서를 보장하지 않고, Ordered는 데이터 기록 후 커밋하며, Journal은 데이터까지 저널에 기록함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 저널 영역 | 변경 내역을 순차 기록해 재생·폐기 기준을 제공함 |
| 트랜잭션 그룹 | 함께 반영할 메타데이터·데이터 변경을 묶음 |
| 커밋 레코드 | 저널에 완전히 기록된 트랜잭션을 표시함 |
| 체크포인트 | 커밋된 변경을 본래 위치에 반영하고 저널 공간을 회수함 |

> 요약: 트랜잭션 그룹을 저널에 기록하고 커밋 레코드로 완료를 표시한 뒤 체크포인트로 본래 위치에 반영함.

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 변경 수집      | --> | 저널 기록      | --> | commit 표시    | --> | checkpoint 반영 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **변경 수집**: 파일 시스템 메타데이터 변경을 트랜잭션 단위로 모음
2. **저널 기록**: 실제 영역보다 먼저 저널에 변경 내역을 기록함
3. **커밋 표시**: 트랜잭션이 저널에 완전히 기록됐음을 표시함
4. **체크포인트·재생**: 정상 시 본래 위치에 반영하고 장애 후에는 커밋된 항목만 재생함

## Ⅵ. 실무 사례

1. 일반 파일 서버는 Ordered 모드와 플러시 주기를 설정하고 쓰기 지연과 저널 재생시간을 확인함
2. 데이터 무결성 저장소는 Journal 모드를 적용하고 장애 복구 일관성과 쓰기 증폭 계수를 확인함

## Ⅶ. 결론

- 파일 시스템 저널링은 데이터 보호 범위와 기록 순서·쓰기 증폭·복구시간으로 모드를 선택함
