## 미리 알고가기

- 2PL은 트랜잭션이 잠금을 획득하는 단계와 해제하는 단계를 분리하는 프로토콜임
- 직렬 가능성을 보장하는 대표적 락 기반 동시성 제어 방식임
- 데드락과 대기 시간 증가는 운영상 주요 부담임

## Ⅰ. 개요

- **정의/개념**: 2단계 잠금 프로토콜 2PL은 트랜잭션이 잠금을 추가로 획득만 하는 성장 단계와 잠금을 해제만 하는 축소 단계를 구분해 잠금 해제 후 새로운 잠금 획득을 금지함으로써 충돌 직렬 가능성을 확보하는 동시성 제어 방식임
- **배경/필요성**: 동시에 갱신되는 데이터가 많을 때 연산 순서를 임의로 허용하면 정합성이 깨지므로, 명확한 잠금 규칙으로 안전한 실행 순서를 보장할 필요가 있음

## Ⅱ. 특징

- 직렬 가능성 보장에 강한 전통적 제어 방식임
- 공유 잠금과 배타 잠금을 통해 읽기와 쓰기 충돌을 구분함
- 락 경합이 심하면 대기와 데드락이 쉽게 증가함
- 구현은 명확하지만 읽기 중심 워크로드에서는 병목이 커질 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | Basic 2PL | Strict 2PL |
|:---|:---|:---|
| 잠금 해제 시점 | 축소 단계부터 해제 가능 | 커밋 전까지 배타 잠금 유지 |
| 장점 | 유연한 해제 가능 | 복구 단순성과 연쇄 롤백 방지 |
| 한계 | 복구 복잡도 증가 가능 | 경합과 대기 증가 |
| 적합 환경 | 일반 직렬화 통제 | 강한 복구 일관성 요구 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Shared and Exclusive Lock | 읽기와 쓰기 접근을 구분해 충돌 범위를 제어함 |
| Growing Phase | 필요한 잠금을 모두 획득하며 직렬화 가능한 순서를 형성함 |
| Shrinking Phase | 잠금을 해제하기 시작한 뒤 추가 잠금을 금지해 규칙을 유지함 |
| Deadlock Handling | 순환 대기를 탐지하거나 예방해 운영 중 정체를 해소함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 잠금 획득 시작  | --> | 성장 단계 진행   | --> | 잠금 해제 시작  | --> | 커밋/롤백 종료  |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **잠금 획득 시작**: 읽기와 쓰기 대상에 필요한 잠금을 요청함
2. **성장 단계 진행**: 필요한 잠금을 모두 모을 때까지 해제하지 않음
3. **잠금 해제 시작**: 첫 해제 이후에는 새 잠금을 더 얻지 않음
4. **커밋 또는 롤백 종료**: 트랜잭션 완료와 함께 잠금을 정리함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 잠금 순서가 일관되지 않으면 데드락이 빈번해져 처리량이 급격히 저하될 수 있음
   - 해결방안: lock ordering rule과 deadlock detector를 운영하고 deadlock frequency와 victim retry success rate로 검증함
2. 문제: 긴 트랜잭션이 잠금을 오래 보유하면 짧은 트랜잭션까지 대기열에 묶여 응답 지연이 커질 수 있음
   - 해결방안: transaction scope를 축소하고 lock hold time과 blocked transaction ratio로 검증함
3. 문제: 읽기 비중이 높은 업무에 락 중심 제어만 적용하면 불필요한 경합으로 조회 성능이 떨어질 수 있음
   - 해결방안: MVCC나 read replica와 조합하고 read wait ratio와 throughput gain으로 검증함

## Ⅶ. 적용 사례

- 계정계 갱신 트랜잭션에서는 잠금 순서를 표준화하고, deadlock frequency와 victim retry success rate로 결과를 확인함
- 대형 주문 시스템에서는 트랜잭션 범위를 줄이고, lock hold time과 blocked transaction ratio로 결과를 확인함
- 조회 중심 서비스에서는 혼합 제어 방식을 도입하고, read wait ratio와 throughput gain으로 결과를 확인함

## Ⅷ. 결론

2PL의 핵심은 잠금을 많이 거는 데 있지 않고 일관된 잠금 규칙으로 정합성을 확보하되 경합 비용을 관리 가능한 수준으로 제어하는 데 있음.
