## Ⅰ. 개요
- 시스템 성능 향상과 쿼리 단순화를 위해 정규화된 모델을 의도적으로 통합/중복시키는 기법임.
- 조회 빈도가 높고 조인 오버헤드가 큰 경우 읽기 성능 최적화를 위해 수행함.
- 출제 의도: 데이터 무결성 비용과 성능 이득 간의 Trade-off 분석 역량 평가.

## Ⅱ. 구성요소
- 반정규화 주요 기법
[Join Optimization] | [Column Redundancy] | [Row Partitioning]

| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| 테이블 통합 | 1:1, 1:N 관계를 하나로 합쳐 조인 제거 | 두 부서를 하나로 합침 |
| 중복 컬럼 추가 | 조인 횟수를 줄이기 위해 외래키 속성 복사 | 자주 쓰는 연락처 복사본 보관 |
| 파생 컬럼 추가 | 계산 결과(합계, 평균 등)를 미리 저장 | 영수증 합계 미리 작성 |
> 요약: 중복을 허용하여 응답 속도를 개선하는 성능 중심 기법임.

## Ⅲ. 절차
- 반정규화 적용 프로세스
[Target Analysis] -> [Method Selection] -> [Verification] -> [Application]

1. 대상 조사: 범위 처리 빈도, 조인 횟수, 성능 병목 구간 확인함.
2. 대안 검토: 뷰(View), 클러스터링, 인덱스 조정 등으로 해결 가능성 검토.
3. 설계 수행: 테이블 분할/통합, 컬럼/관계의 반정규화를 설계함.
4. 무결성 보완: 트리거, 애플리케이션 로직을 통해 데이터 일관성 유지책 마련.
> 요약: 성능 개선 요구를 분석하고 일관성 유지 방안과 함께 적용함.

## Ⅳ. 문제점
- 데이터 정합성 유지 비용 상승 및 중복 저장으로 인한 저장 공간 낭비.

## Ⅴ. 개선방안
- 정기적 배치 정합성 체크 로직 구현 및 읽기 전용 복제본(Read Replica) 활용.

## Ⅵ. 전망
- 실시간 분석 요구 증대에 따라 OLAP 환경에서의 반정규화 자동화 가속.
- 고성능 NoSQL과의 하이브리드 구성을 통해 물리적 반정규화 대체 시도 증대.
