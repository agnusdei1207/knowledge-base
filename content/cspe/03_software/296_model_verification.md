## Ⅰ. 개요
- 정의: 생성된 UML 모델 간의 논리적 모순을 찾고 요구사항과의 일치 여부를 확인하는 활동임
- 배경: 모델 간 불일치로 인한 설계 오류의 구현 단계 전이 방지 필요
- 출제 의도: 다중 뷰(View) 간의 정합성 유지 및 설계 품질 보증 기술 이해도 확인

## Ⅱ. 구성요소
- ASCII 구조도
  [Usecase] <---(Trace)---> [Sequence]
      |                        |
      +--------(Check)---------+
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| 수평적 일관성 | 동일 추상화 수준의 서로 다른 뷰 간 정합성 | 도면 간 일치 |
| 수직적 일관성 | 추상화 수준이 다른 상/하위 모델 간 정합성 | 기초-골조 일치 |
| 모델 체커 | 정형 기법 기반의 자동 논리 검증 도구 | 맞춤법 검사기 |
> 요약: 유스케이스, 클래스, 시퀀스 다이어그램 간의 용어와 로직 일관성을 검증함

## Ⅲ. 절차
- ASCII 흐름도
  Rule Set -> View Compare -> Error Detect -> Refinement
- 4단계 설명
1. Rule Set: 모델 간 참조 무결성 및 정합성 검증 규칙(Checklist) 수립함
2. View Compare: 기능 뷰(Usecase)와 설계 뷰(Sequence) 간 메시지 매핑 확인함
3. Error Detect: 미정의된 메시지, 고립된 객체, 상태 전이 모순 등 식별함
4. Refinement: 발견된 오류를 수정하고 모델 간 추적성(Traceability) 강화함
> 요약: 검증 규칙에 따라 다이어그램 간 불일치를 탐지하고 설계 완성도를 높임

## Ⅳ. 문제점
- 원인이 명시된 문제/한계: 모델 수정 시 수동 일관성 체크에 따른 인적 오류 및 생산성 저하됨

## Ⅴ. 개선방안
- Ⅳ의 문제에 대응하는 방안: CASE 도구의 실시간 제약 조건 검사 기능 및 OCL 활용함

## Ⅵ. 전망
- 발전 방향: 디지털 트윈 기반 모델 시뮬레이션 및 AI를 활용한 설계 패턴 오류 자동 교정
- CSF: 분석-설계-구현 간의 완벽한 추적성 매트릭스(RTM) 관리가 품질 관리의 근간임
