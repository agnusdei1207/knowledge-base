## Ⅰ. 개요
- **정의**: 시각적 모델링·드래그앤드롭으로 최소한의 코딩 또는 코딩 없이 애플리케이션을 개발하는 플랫폼
- **배경/필요성**: 개발 인력 수급 불균형과 비즈니스 민첩성 요구가 시민 개발자(Citizen Developer) 참여를 촉진함
- **비유**: 레고 블록을 조립하듯 사전 제작된 컴포넌트를 연결하여 소프트웨어를 완성하는 것과 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 개발 패러다임 변화 이해 | Low-Code와 No-Code의 차이 구분 | 엔터프라이즈 적용 시 한계 명시 |

> 요약: 로우코드/노코드는 시각적 개발 도구로 개발 민주화를 실현하는 플랫폼임

## Ⅱ. 구성요소
```text
[Business User] --설계--> [Visual Designer]
                               |
              +----------------+----------------+
              |                |                |
              v                v                v
       [Component Lib]  [Logic Builder]  [Integration Hub]
              |                |                |
              v                v                v
       [UI Rendering]   [Workflow Engine] [API Connector]
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| Visual Designer | 드래그앤드롭 인터페이스로 화면·워크플로우를 설계함 | 프레젠테이션 편집기 |
| Logic Builder | 조건·반복·분기 등 비즈니스 로직을 시각적으로 정의함 | 순서도 그리기 도구 |
| Integration Hub | 외부 시스템과 API·웹훅으로 연동하는 커넥터를 제공함 | 만능 어댑터 |

> 요약: 시각적 설계-로직 구성-외부 연동 3개 계층이 코드 없는 개발을 지원함

## Ⅲ. 절차
```text
요구 분석 --> 시각적 설계 --> 테스트/검증 --> 배포/운영
    |              |              |              |
    v              v              v              v
  업무정의    컴포넌트조합    미리보기실행    원클릭배포
```
- 1단계: 업무 요구사항을 정의하고 자동화 범위를 결정함
- 2단계: Visual Designer에서 컴포넌트를 조합하여 애플리케이션을 구성함
- 3단계: 미리보기 환경에서 기능·연동을 검증함
- 4단계: 원클릭 배포 후 사용 현황을 모니터링하며 운영함

> 요약: 분석-설계-검증-배포 4단계로 신속하게 애플리케이션을 구축함

## Ⅳ. 문제점
- 확장성 제약: 복잡한 비즈니스 로직 구현에 플랫폼 기능이 부족함 — 커스터마이징 한계에 봉착함
- 벤더 종속: 플랫폼 고유 포맷으로 저장됨 — 타 플랫폼 이관이 곤란함
- 섀도우 IT: 거버넌스 없이 시민 개발자가 앱을 난립시킴 — 보안·품질 관리가 어려워짐

> 요약: 확장성·벤더 종속·섀도우 IT가 로우코드/노코드의 엔터프라이즈 적용 장벽임

## Ⅴ. 개선방안
1. 단기: Pro-Code 확장 포인트를 제공하여 복잡 로직을 코드로 보완 가능하게 설계
2. 중기: 오픈 표준 기반 내보내기(Export) 기능으로 벤더 종속을 완화
3. 장기: CoE 주도의 앱 카탈로그·승인 체계를 수립하여 섀도우 IT를 통제

> 요약: 코드 확장-표준화-거버넌스 순으로 엔터프라이즈 수준 성숙도를 확보할 필요

## Ⅵ. 전망
- 발전 방향: AI 코파일럿이 자연어로 앱을 생성하는 AI-Assisted Low-Code로 진화함
- 기술사적 판단: 전문 개발과 시민 개발의 경계가 Fusion Team 모델로 재편될 것임
- 기술사 제언: 시민 개발자 역량 강화 프로그램과 거버넌스를 병행 추진할 필요
