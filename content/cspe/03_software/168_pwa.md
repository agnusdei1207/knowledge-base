## Ⅰ. 개요
- 정의: 웹과 네이티브 앱의 장점을 결합하여 오프라인 환경 및 푸시 알림을 지원하는 웹 앱
- 배경: 앱 스토어 거치지 않는 배포와 저사양 기기/네트워크 접근성 강화
| 구분 | 내용 |
|------|------|
| 출제 의도 | Service Worker, Manifest, HTTPS 필수 요소 및 캐싱 전략 이해 |

## Ⅱ. 구성요소
  [ Browser ] <-> [ Service Worker ] <-> [ Network ]
                       | (Cache) |
| 구성요소 | 설명 | 비유 |
|----------|------|------|
| Service Worker | 브라우저 백그라운드에서 실행되는 프록시 | 중간 관리자 |
| Manifest | 앱 설치 정보(아이콘, 이름) 정의 파일 | 명함 |
| Push API | 사용자에게 서버 메시지 알림 전송 | 메가폰 |
> 요약: 웹 기술 기반의 설치 가능하고 신뢰할 수 있는 사용자 경험

## Ⅲ. 절차
  Register -> Install -> Activate -> Fetch/Listen
1. Registration: 메인 스크립트에서 서비스 워커 등록
2. Installation: 정적 자산(Static Assets)을 캐시에 저장
3. Activation: 이전 캐시 정리 및 활성화 상태 전환
4. Interception: 네트워크 요청을 가로채 캐시 또는 서버 응답
> 요약: 네트워크 독립적인 실행 환경 구축을 통한 안정성 확보

## Ⅳ. 문제점
- iOS 등 특정 OS의 미흡한 지원 및 기능 제약
- 캐시 갱신 정책(Stale-while-revalidate 등) 관리의 복잡성

## Ⅴ. 개선방안
- Workbox 라이브러리 활용으로 표준화된 캐시 전략 수립
- Progressive Enhancement 원칙 적용으로 기본 기능 보장

## Ⅵ. 전망
- Web Bundle 표준화를 통한 오프라인 배포 강화 및 데스크톱 PWA의 네이티브 앱 대체
