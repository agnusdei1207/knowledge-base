## 미리 알고가기

- 시간 할당량: 프로세스가 선점되기 전까지 연속 실행할 수 있는 CPU 시간임
- 강등: 시간 할당량을 소진한 프로세스를 낮은 우선순위 큐로 옮기는 동작임
- 우선순위 상향: 장기 대기를 제한하기 위해 프로세스를 상위 큐로 이동하는 동작임

## 작성 근거(검토용)

- MLFQ는 작업 유형 예측보다 실행 이력에 따른 큐 이동과 시간 할당량 변화로 설명함
- 고정 우선순위와 비교해 우선순위 갱신·대화형 작업 처리·기아 통제 차이를 드러냄
- 큐별 대기시간과 우선순위 상향 주기를 서버 사례의 직접 지표로 연결함

## Ⅰ. 개요
- **정의/개념**: MLFQ는 여러 우선순위 큐의 시간 할당량과 프로세스 실행 이력을 이용해 큐 사이 이동을 결정하는 선점형 스케줄링 방식임
- **배경/필요성**: CPU 집중·I/O 집중 특성을 미리 알기 어려운 작업을 실행 이력으로 구분하기 위해 동적 우선순위 정책이 필요함

## Ⅱ. 특징

- 새 프로세스는 최상위 큐에서 짧은 시간 할당량으로 실행을 시작함
- 시간 할당량을 소진한 프로세스는 하위 큐로 이동함
- I/O 대기로 일찍 CPU를 반납한 작업은 높은 우선순위를 유지함
- 주기적 우선순위 상향은 하위 큐의 장기 대기를 제한함

## Ⅲ. 종류 및 비교

| 판단 기준 | 고정 우선순위 큐 | MLFQ |
|:---|:---|:---|
| 우선순위 기준 | 사전에 부여한 값 | 최근 CPU 사용·대기 이력 |
| 큐 이동 | 없음 | 강등·유지·주기적 상향 |
| 시간 할당량 | 우선순위별 고정 가능 | 하위 큐로 갈수록 증가 |
| 대화형 작업 | 별도 우선순위 지정 필요 | 짧은 CPU 사용으로 상위 큐 유지 |
| 기아 통제 | 에이징 별도 적용 | 우선순위 상향 주기 적용 |
| 설정 제약 | 우선순위 값 관리 | 큐 수·할당량·상향 주기 조정 |

> 요약: 고정 우선순위는 사전 값으로 실행 순서를 정하고, MLFQ는 실행 이력에 따라 큐와 시간 할당량을 바꿈.

## Ⅳ. 구성요소 및 구조
```
Q0 (RR 8ms)  ----[ Demote ]----> Q1 (RR 16ms) ----[ Demote ]----> Q2 (FCFS)
      |                          |                         |
[ New Process ]            [ Time Out ]              [ Completion ]
```
| 구성요소 | 설명 | 판단 기준 |
| :--- | :--- | :--- |
| 다단계 큐 | 서로 다른 타임 슬라이스를 가진 큐의 집합 | 대기열별 실행 시간 |
| 피드백 | 실행 결과에 따라 우선순위 큐를 변경하는 메커니즘 | CPU 사용 이력 |
| 우선순위 상향 | 기아 방지를 위해 일정 시간 후 상위 큐로 이동 | 장기 대기 시간 |
> 요약: MLFQ는 시간 할당량 소진과 대기 시간을 기준으로 프로세스를 상위·하위 큐로 이동함.

## Ⅴ. 원리 및 절차 흐름도
```
[Entry] -> [Q0 실행] -> [Time Out 시 Q1 이동] -> [Q1 실행] -> [FCFS 큐 안착]
```
1. **최상위 큐 진입**: 신규 프로세스를 짧은 시간 할당량의 Q0에 넣음
2. **실행 결과 판정**: 시간 할당량 소진과 I/O 대기 전환 여부를 확인함
3. **큐 이동**: 소진하면 하위 큐로 강등하고 일찍 반납하면 현재 우선순위를 유지함
4. **주기적 상향**: 상향 시점에 대기 프로세스를 최상위 큐로 옮김
> 요약: 최근 실행 이력에 따라 큐를 조정해 응답성과 장기 대기를 함께 다룸.

## Ⅵ. 실무 사례

1. 데스크톱 운영체제는 대화형 작업을 상위 큐에 유지하고 입력 응답시간과 큐별 대기시간을 확인함
2. 혼합 워크로드 서버는 우선순위 상향 주기를 조정하고 하위 큐 최대 대기시간과 선점률을 확인함

## Ⅶ. 결론

- MLFQ는 시간 할당량 소진·I/O 대기·장기 대기 이력으로 프로세스의 큐와 우선순위를 조정함
