## 미리 알고가기

- 파일 시스템은 저장장치 위에 파일과 디렉터리를 조직하는 운영체제 구조임
- 메타데이터는 파일 이름과 위치와 권한과 시간 정보를 의미함
- FAT와 NTFS와 ext4와 APFS는 대표적인 범용 파일 시스템 계열임
- 저널링(Journaling): 메타데이터 변경 내용을 로그에 먼저 기록해 장애 후 복구 범위를 줄이는 기법임
- copy-on-write: 원본 블록을 유지한 채 변경 내용을 새 블록에 기록해 일관성을 보장하는 방식임

## 작성 근거(검토용)

- FAT·NTFS·ext4·APFS는 할당·메타데이터 구조·일관성 처리·대표 적용 환경으로 비교함
- 경로 해석·블록 할당·데이터 I/O·메타데이터 갱신을 파일 접근의 실제 순서로 유지함
- 서버와 이동식 매체 사례는 복구시간과 호환성이라는 선택 조건을 분리함

## Ⅰ. 개요

- **정의/개념**: 파일 시스템은 저장장치의 블록 공간을 파일·디렉터리·메타데이터 구조로 조직해 응용 프로그램이 데이터를 이름 기반으로 저장하고 조회하게 하는 운영체제 저장 관리 계층임
- **배경/필요성**: 저장 블록을 이름·권한·메타데이터와 연결하고 장애 후 일관성을 복구하기 위해 파일 시스템 구조가 필요함

## Ⅱ. 특징

- 데이터 블록과 메타데이터를 분리 관리해 이름 기반 접근을 제공함
- 디렉터리 구조와 권한 모델과 일관성 방식이 파일 시스템별 차이를 만듦
- HDD 탐색 비용, SSD erase block·쓰기 증폭, 모바일 플래시 내구성에 따라 파일 배치와 갱신 방식이 달라짐
- 성능뿐 아니라 복구성, 스냅샷, 암호화, 대용량 지원이 선택 기준이 됨

## Ⅲ. 종류 및 비교

| 판단 기준 | FAT | NTFS | ext4 | APFS |
|:---|:---|:---|:---|:---|
| 할당·메타데이터 구조 | 파일 할당 테이블 | MFT·클러스터 | inode·extent | B-tree·copy-on-write |
| 일관성 처리 | 전체 검사 중심 | 메타데이터 저널링 | 저널링 | copy-on-write·체크섬 |
| 대표 적용 환경 | 이동식 매체 | Windows 서버·클라이언트 | Linux 서버 | Apple 플랫폼 |

> 요약: FAT는 호환성, NTFS·ext4는 플랫폼별 저널링, APFS는 copy-on-write·스냅샷을 중심으로 선택함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 슈퍼블록·볼륨 헤더 | 파일 시스템 형식·크기·상태·메타데이터 위치를 저장함 |
| 디렉터리 구조 | 파일 이름을 inode·MFT 같은 메타데이터에 연결함 |
| 할당 메타데이터 | FAT·inode·extent로 데이터 블록 위치와 여유 공간을 기록함 |
| 일관성 기법 | 저널링·copy-on-write로 중단된 갱신의 복구 범위를 정함 |

> 요약: 볼륨 정보·디렉터리·할당 메타데이터·일관성 기법이 이름 기반 파일 접근과 복구를 지원함.

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 파일 요청      | --> | 경로 해석      | --> | 블록 배치/조회 | --> | 메타데이터 갱신 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **파일 요청**: 응용 프로그램이 파일 생성이나 읽기나 쓰기를 요청함
2. **경로 해석**: 디렉터리 구조를 따라 대상 파일 위치를 찾음
3. **블록 배치 또는 조회**: 쓰기는 블록을 할당하고 읽기는 기존 위치를 조회함
4. **메타데이터 갱신**: 크기·시간·할당 정보를 일관성 정책에 따라 기록함

## Ⅵ. 실무 사례

1. Linux 서버는 ext4 저널 모드를 설정하고 파일 I/O 지연과 파일 시스템 복구시간을 확인함
2. 이동식 저장장치는 FAT 호환 형식을 적용하고 플랫폼별 마운트 성공률과 파일 크기 한도를 확인함

## Ⅶ. 결론

- 파일 시스템은 운영체제·매체 호환성과 할당 구조·권한·장애 복구 요구로 선택함
