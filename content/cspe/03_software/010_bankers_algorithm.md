## 미리 알고가기

- 안전 순서: 각 프로세스가 필요한 자원을 받아 차례로 완료할 수 있는 순서임
- Need: 프로세스의 최대 요구량에서 현재 할당량을 뺀 추가 요구량임
- Work: 안전성 검사에서 완료 프로세스의 자원 반납을 가정해 갱신하는 가용 자원임
- Available·Max·Allocation: 현재 가용 자원 벡터, 프로세스별 최대 요구량 행렬, 현재 할당량 행렬을 각각 나타냄

## 작성 근거(검토용)

- 은행원 알고리즘은 Available·Max·Allocation·Need·Work로 안전 순서를 찾는 절차에 집중함
- 안전·불안전 상태는 완료 가능성, 자원 관계, 요청 처리라는 3개 판단축으로 구분함
- 최대 요구량을 사전에 알 수 있는 배치·임베디드 작업만 대표 사례로 선정함

## Ⅰ. 개요
- **정의/개념**: 은행원 알고리즘은 자원 요청을 가상 할당하고 모든 프로세스의 안전 순서가 존재할 때만 실제 할당하는 교착상태 회피 기법임
- **배경/필요성**: 최대 요구량을 아는 환경에서 교착상태가 없는 할당만 승인하기 위해 안전 상태 판정이 필요함

## Ⅱ. 특징

- 프로세스별 최대 요구량과 현재 할당량을 사전에 관리함
- 요청량이 Need와 Available 이하인지 먼저 검사함
- 가상 할당 후 Work 이하의 Need를 가진 프로세스를 반복 탐색함
- 모든 프로세스를 완료할 순서가 없으면 실제 할당을 보류함

## Ⅲ. 종류 및 비교

| 판단 기준 | 안전 상태 | 불안전 상태 |
|:---|:---|:---|
| 완료 가능성 | 하나 이상의 안전 순서 존재, 현재 할당으로 완료 가능 | 완료 순서 없음, 교착상태는 아니지만 향후 교착 가능 |
| 자원 관계 | Work 이하의 Need를 가진 프로세스를 반복 선택 가능 | 남은 프로세스의 Need가 Work를 초과 |
| 요청 처리 | 가상 할당 결과가 안전하면 승인 후 벡터 갱신 | 요청 보류·거절, 자원 반납까지 대기 |

> 요약: 안전 상태는 완료 가능한 프로세스 순서가 남고, 불안전 상태는 현재 가용량으로 모든 프로세스를 완료할 순서가 없음.

## Ⅳ. 구성요소 및 구조
```
[ Data Structures ]
- Available: 가용 자원 벡터
- Max: 최대 요구 행렬
- Allocation: 현재 할당 행렬
- Need: 추가 요구 행렬 (Max - Allocation)
```
| 구성요소 | 설명 | 판단 기준 |
| :--- | :--- | :--- |
| Available | 현재 할당하지 않은 자원 수를 저장함 | 요청 가능량 |
| Max·Allocation | 최대 요구량과 현재 할당량을 프로세스별로 저장함 | Need 계산 |
| Need | Max에서 Allocation을 뺀 추가 요구량임 | 완료 가능성 검사 |
| Work·Finish | 가정한 가용량과 완료 여부를 갱신함 | 안전 순서 탐색 |
> 요약: 요청 승인 후에도 완료 가능한 프로세스 순서가 남는지 검사함.

## Ⅴ. 원리 및 절차 흐름도
```
[Request] -> [Need Check] -> [Available Check] -> [Safety Test] -> [Assign/Reject]
```
1. **요청 한도 검사**: 요청량이 해당 프로세스의 Need 이하인지 확인함
2. **가용량 검사**: 요청량이 Available 이하이면 가상 할당하고 아니면 대기시킴
3. **안전성 검사**: Work 이하의 Need를 가진 프로세스를 찾아 완료와 자원 반납을 가정함
4. **승인·복원**: 모든 Finish가 참이면 승인하고 아니면 가상 할당을 되돌려 대기시킴
> 요약: 요청을 가상 할당한 상태에서 모든 프로세스가 완료되는 안전 순서를 찾으면 실제 자원을 할당함.

## Ⅵ. 실무 사례

1. 배치 스케줄러는 작업별 최대 메모리·GPU 요구량으로 안전 순서를 검사하고 요청 보류율을 확인함
2. 임베디드 작업 관리기는 고정 자원 상한으로 할당을 판정하고 검사시간과 불안전 요청 수를 확인함

## Ⅶ. 결론

- 은행원 알고리즘은 최대 요구량을 아는 자원에 한해 가상 할당 후 안전 순서 존재 여부로 요청을 승인함
