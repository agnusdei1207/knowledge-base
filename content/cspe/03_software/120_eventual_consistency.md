## 미리 알고가기

- 최종 일관성은 모든 복제본이 즉시는 아니어도 결국 같은 상태로 수렴하는 모델임
- 분산 시스템에서 가용성과 지연을 높이는 대신 일시적 불일치를 허용함
- 수렴 시간과 보정 전략이 실무 핵심임

## Ⅰ. 개요

- **정의/개념**: 최종 일관성은 분산 데이터 시스템에서 쓰기 직후 모든 복제본이 즉시 동일해지지는 않더라도 시간이 지나면 같은 상태로 수렴하도록 설계한 일관성 모델임
- **배경/필요성**: 멀티리전과 대규모 분산 환경에서는 즉시 강한 일관성을 항상 유지하면 지연과 가용성 비용이 커지므로, 허용 가능한 범위의 지연 동기화를 택하는 경우가 많음

## Ⅱ. 특징

- 낮은 지연과 높은 가용성을 확보하기 쉬움
- 쓰기 직후 읽기에서 stale data가 발생할 수 있음
- 시스템은 결국 수렴해야 하므로 동기화와 충돌 해결 전략이 필요함
- 사용자에게 일시적 불일치를 숨기거나 완화하는 설계가 중요함

## Ⅲ. 종류 및 비교

| 판단 기준 | 강한 일관성 | 최종 일관성 |
|:---|:---|:---|
| 읽기 결과 | 즉시 최신 상태 | 일시적 stale 가능 |
| 장점 | 데이터 신뢰성 높음 | 낮은 지연과 높은 가용성 |
| 한계 | 동기화 비용 큼 | 보정과 설명 필요 |
| 적합 업무 | 금융·재고 | 피드·카탈로그·캐시 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Replica Propagation | 변경 내용을 각 복제본으로 전파해 수렴을 유도함 |
| Staleness Window | 최신 상태와 차이가 허용되는 시간 범위를 정의함 |
| Conflict Resolution | 동시 변경 시 최종 상태를 결정하는 규칙을 제공함 |
| Read Strategy | read-your-write 보장 여부와 fallback 경로를 정함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 쓰기 수락      | --> | 복제 전파      | --> | 일시적 불일치    | --> | 상태 수렴      |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **쓰기 수락**: 한 노드가 변경을 먼저 반영함
2. **복제 전파**: 변경 내용을 다른 노드로 전송함
3. **일시적 불일치**: 일부 읽기에서 이전 값이 보일 수 있음
4. **상태 수렴**: 시간이 지나면 복제본 상태가 일치함

## Ⅵ. 문제점 및 해결 방안

1. 문제: stale window를 정하지 않으면 서비스가 허용한 불일치 범위를 누구도 명확히 설명하지 못할 수 있음
   - 해결방안: staleness SLO를 명시하고 stale window compliance와 stale read duration으로 검증함
2. 문제: read-your-write가 필요한 화면까지 최종 일관성 읽기로 처리하면 사용자 혼란과 중복 요청이 증가할 수 있음
   - 해결방안: session-aware read routing을 적용하고 read-your-write success rate와 duplicate action rate로 검증함
3. 문제: 충돌 해결 규칙이 단순 마지막 쓰기 승리만 사용되면 업무 의미를 잃는 데이터 손실이 발생할 수 있음
   - 해결방안: domain-aware merge policy를 적용하고 conflict resolution loss rate와 reconciliation accuracy로 검증함

## Ⅶ. 적용 사례

- 상품 카탈로그 서비스에서는 stale window를 관리하고, stale window compliance와 stale read duration로 결과를 확인함
- 사용자 설정 화면에서는 세션 기반 읽기 라우팅을 적용하고, read-your-write success rate와 duplicate action rate로 결과를 확인함
- 멀티리전 협업 데이터에서는 병합 정책을 적용하고, conflict resolution loss rate와 reconciliation accuracy로 결과를 확인함

## Ⅷ. 결론

최종 일관성은 불일치를 방치하는 모델이 아니라 허용 가능한 지연 범위 안에서 결국 수렴하도록 운영 규칙을 갖춘 분산 일관성 전략임.
