## 미리 알고가기

- NUMA는 CPU 소켓마다 로컬 메모리 접근 지연이 다른 구조임
- NUMA 인지 스케줄링은 스레드와 메모리를 같은 노드에 가깝게 배치하는 정책임
- 원격 메모리 접근은 소켓 간 인터커넥트를 경유해 로컬 접근보다 지연과 링크 트래픽이 증가함
- first-touch: 스레드가 페이지에 처음 접근할 때 그 스레드가 실행 중인 노드에 페이지를 할당하는 정책임
- CPU affinity(친화도): 스레드를 지정한 코어·노드 범위에서만 실행하도록 제한하는 설정임

## 작성 근거(검토용)

- NUMA 무시·인지 정책을 배치 정책·재배치 기준·적용 조건으로 비교함
- 토폴로지 인식·초기 배치·접근 관측·재배치를 실제 배치 상태 전이로 유지함
- 데이터베이스와 가상화 호스트를 분리해 원격 접근률과 페이지 이동량을 검증함

## Ⅰ. 개요

- **정의/개념**: NUMA 인지 스케줄링은 멀티소켓 시스템에서 스레드·메모리 페이지·장치를 같은 NUMA 노드에 배치해 원격 메모리 접근을 줄이는 스케줄링 정책임
- **배경/필요성**: 멀티소켓 서버의 원격 메모리 지연과 인터커넥트 트래픽을 줄이기 위해 스레드·페이지 위치를 함께 보는 배치 기준이 필요함

## Ⅱ. 특징

- 스레드와 페이지가 다른 노드에 있으면 원격 메모리 지연이 실행시간에 추가됨
- 메모리 first-touch와 CPU affinity가 기본 제어 수단이 됨
- VM·DB·인메모리 작업은 스레드와 메모리의 노드 위치를 함께 관리함
- 잦은 스레드·페이지 이동은 캐시 재사용을 줄이고 복사 트래픽을 늘림

## Ⅲ. 종류 및 비교

| 판단 기준 | NUMA 무시 스케줄링 | NUMA 인지 스케줄링 |
|:---|:---|:---|
| 배치 정책 | CPU 부하 중심, 스레드·페이지 위치 미구분 | CPU·메모리 지역성 중심, first-touch·메모리 바인딩으로 같은 노드 배치 |
| 재배치 기준 | CPU 부하 기준 이동 | 원격 접근률·이동 비용 기준 스레드·페이지 재배치 |
| 적용 조건 | 단일 소켓·메모리 접근 비중 낮은 작업, 분리 시 원격 접근 지연 발생 | 멀티소켓·메모리 집약 작업, 위치 계측·이동 운영 부담 발생 |

> 요약: NUMA 인지 정책은 스레드와 페이지를 같은 노드에 배치하고 원격 접근률로 이동 여부를 결정함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| NUMA 노드 토폴로지 | 소켓·메모리·장치의 노드 연결 관계를 저장함 |
| CPU 친화도 정책 | 스레드가 실행할 코어·노드 범위를 정함 |
| 메모리 바인딩 | 페이지를 할당할 NUMA 노드 범위를 정함 |
| 이동 제어기 | 원격 접근률과 이동 비용으로 스레드·페이지 재배치를 결정함 |

> 요약: 노드 토폴로지와 CPU 친화도·메모리 바인딩이 초기 위치를 정하고 이동 제어기가 재배치를 판단함.

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 토폴로지 파악   | --> | 초기 배치      | --> | 접근 패턴 관찰 | --> | 재배치 조정    |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **토폴로지 파악**: OS가 NUMA 노드와 장치 위치를 인식함
2. **초기 배치**: 스레드와 메모리를 같은 노드 주변에 우선 배치함
3. **접근 패턴 관찰**: 원격 접근률과 인터커넥트 트래픽을 측정함
4. **재배치 조정**: 이동 비용보다 원격 접근 감소가 크면 스레드·페이지를 옮김

## Ⅵ. 실무 사례

1. 멀티소켓 DB는 CPU 친화도와 memory binding을 적용하고 원격 메모리 접근률과 p99 지연을 확인함
2. 가상화 호스트는 VM의 vCPU·메모리를 같은 노드에 배치하고 페이지 이동량과 처리량을 확인함

## Ⅶ. 결론

- NUMA 인지 스케줄링은 스레드·페이지·장치 위치와 원격 접근률을 기준으로 초기 배치와 이동을 결정함
