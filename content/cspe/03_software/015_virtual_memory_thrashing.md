## 미리 알고가기

- 워킹 셋: 프로세스가 일정 시간 동안 반복 참조하는 페이지 집합임
- 상주 집합: 프로세스에 현재 할당된 물리 메모리 프레임 집합임
- 스레싱: 상주 집합이 워킹 셋보다 작아 페이지 교체 I/O가 반복되는 상태임
- 다중프로그래밍 정도: 메모리에 동시에 적재해 실행하는 프로세스 수임

## 작성 근거(검토용)

- 스레싱은 가상 메모리 일반론보다 워킹 셋·프레임 부족·페이지 폴트·교체 I/O 관계로 설명함
- 정상 요구 페이징과 스레싱을 프레임 관계·성능 지표·회복 조치로 비교함
- 악화 순환과 회복 조치를 실제 상태 전이로 구성하고 서버 지표로 회수함

## Ⅰ. 개요
- **정의/개념**: 프로세스 스레싱은 할당 프레임이 워킹 셋보다 작아 페이지 폴트와 교체 I/O가 반복되고 CPU 처리량이 감소하는 상태임
- **배경/필요성**: 메모리 과할당 환경에서 페이지 교체가 실행보다 많아지는 상태를 판정하기 위해 워킹 셋과 폴트 빈도 기준이 필요함

## Ⅱ. 특징

- 다중프로그래밍 정도가 높아지면 프로세스별 상주 프레임이 줄어듦
- 상주 집합이 워킹 셋을 담지 못하면 재참조 페이지가 반복 퇴출됨
- 주요 페이지 폴트와 swap I/O가 증가하는 동안 CPU 이용률과 처리량이 감소함
- 워킹 셋·페이지 폴트 빈도 제어와 작업 수 제한으로 메모리 압박을 완화함

## Ⅲ. 종류 및 비교

| 판단 기준 | 정상 요구 페이징 | 스레싱 상태 |
|:---|:---|:---|
| 프레임 관계 | 상주 집합이 워킹 셋을 수용 | 상주 집합이 워킹 셋보다 작음 |
| 성능 지표 | 폴트가 지역성 변화 시 간헐 발생, CPU·처리량 유지 | 재참조 폴트·swap I/O 반복, CPU 이용률·처리량 급감 |
| 회복 조치 | 일반 교체 정책 유지 | 프레임 재배분·작업 수 제한 |

> 요약: 스레싱은 상주 집합이 워킹 셋보다 작아 페이지 폴트와 swap I/O가 반복되는 상태임.

## Ⅳ. 구성요소 및 구조
```
[ 가상 주소 ] -> [ MMU ] -> [ 물리 주소 ]
      |             |             |
      +->[페이지 테이블]+           +-> [ RAM/스왑 ]
```
| 구성요소 | 설명 | 판단 기준 |
| :--- | :--- | :--- |
| MMU | 가상 주소를 물리 주소로 변환하는 하드웨어 유닛 | 주소 변환 경로 |
| 페이지 폴트 | 필요한 페이지가 메모리에 없어 OS 처리가 필요한 예외 | 메모리 적재 여부 |
| 워킹 셋 | 프로세스가 일정 시간 동안 집중적으로 참조하는 페이지 집합 | 필요 프레임 규모 |
> 요약: 가상 메모리는 필요한 페이지만 물리 메모리에 적재하며, 스레싱은 프레임 부족으로 페이지 폴트와 교체 I/O가 반복되는 상태임.

## Ⅴ. 원리 및 절차 흐름도
```
[악화] 작업 수 증가 -> 프로세스별 프레임 감소 -> 워킹 셋 미수용 -> 페이지 폴트·교체 반복
                                                     |
                                                     v
[회복] CPU 이용률·폴트 빈도 관찰 -> 프레임 재배분·작업 수 제한 -> 상주 집합 회복
```
1. **악화**: 작업 수 증가로 상주 집합이 워킹 셋보다 작아지면 재참조 페이지의 폴트가 반복됨
2. **관찰**: 운영체제가 주요 페이지 폴트율·swap I/O·CPU 이용률 변화를 확인함
3. **회복**: 프로세스별 프레임을 재배분하거나 실행 작업 수를 줄여 워킹 셋을 수용함
> 요약: 운영체제는 폴트·swap I/O 증가와 CPU 이용률 감소를 감지해 프레임 또는 실행 작업 수를 조정함.

## Ⅵ. 실무 사례

1. 메모리 과할당 서버는 작업 수를 제한하고 주요 페이지 폴트율과 swap I/O 대역폭을 확인함
2. 데이터베이스 호스트는 워킹 셋 기준으로 상주 메모리를 보장하고 처리량과 CPU 이용률을 확인함

## Ⅶ. 결론

- 스레싱은 워킹 셋·상주 프레임·페이지 폴트 빈도로 판정하고 프레임 배분과 실행 작업 수로 통제함
