## 미리 알고가기

- 서킷 브레이커는 실패가 누적될 때 하위 호출을 잠시 차단하는 회복성 패턴임
- Closed, Open, Half-open은 호출 허용과 차단을 제어하는 대표 상태임
- Bulkhead는 장애가 한 자원 풀을 넘어 번지지 않게 격리하는 방식임

## 작성 근거(검토용)

- 서킷 브레이커는 실패 임계치와 Closed·Open·Half-open 상태 전이를 핵심 원리로 설명함
- 단순 재시도와 서킷 브레이커는 실패 대응, 하위 호출량, 위험, 적용 조건으로 비교함
- 실무 판단은 차단 전환 시간, 스레드 풀 포화율, 탐색 호출 성공률, 잘못된 대체 응답 수로 구체화함

## Ⅰ. 개요

- **정의/개념**: 서킷 브레이커는 하위 호출 실패가 임계치를 넘으면 호출을 차단하고 제한된 탐색 호출로 복구를 판정하는 상태 기반 패턴임
- **배경/필요성**: 하위 서비스 장애로 인한 재시도 폭증과 스레드 풀 고갈을 억제하기 위해 호출 차단과 복구 판정 상태가 필요함

## Ⅱ. 특징

- 장애 서비스 호출을 차단해 상위 서비스의 스레드·연결 풀 점유를 제한함
- 상태 전이 기반으로 차단과 복구 확인을 체계적으로 제어함
- 타임아웃·재시도·격리 풀·대체 응답과 결합해 호출 시간과 자원 점유 범위를 제한함
- 임계치가 부정확하면 정상 호출까지 차단하거나 장애 호출을 계속 허용할 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | 단순 재시도 | 서킷 브레이커 |
|:---|:---|:---|
| 실패 대응 방식 | 오류가 나도 같은 호출을 계속 다시 시도함 | 실패가 누적되면 일정 시간 호출 자체를 막음 |
| 호출 영향 | 재시도 횟수만큼 하위 호출과 대기 자원 증가 | Open 상태에서 하위 호출을 차단해 대기 자원 점유 제한 |
| 주요 위험 | 장애 시 요청 폭주가 더 심해질 수 있음 | 임계치가 맞지 않으면 과차단이나 복구 지연이 생길 수 있음 |
| 적용 조건 | 재시도로 회복 가능한 일시 오류 | 하위 장애가 상위 스레드·연결 풀을 고갈시키는 호출 경로 |

> 요약: 단순 재시도는 실패 호출을 반복하고, 서킷 브레이커는 임계치 이후 하위 호출을 차단함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 실패 카운터 | 오류율과 타임아웃 수를 집계해 차단 임계치 도달 여부를 판정함 |
| 상태 기계 | Closed·Open·Half-open 상태로 호출 허용과 차단을 제어함 |
| 대체 응답 로직 | Open 상태에서 도메인 정책에 따른 대체 결과를 반환함 |
| 복구 탐색 호출 | Half-open 상태에서 제한된 요청으로 하위 서비스 복구 여부를 판정함 |

> 요약: 실패 카운터가 임계치를 판정하고 상태 기계가 호출 차단·탐색을 전환하며 대체 응답이 Open 상태를 처리함.

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| Closed 호출    | --> | 임계치 초과·Open | --> | 대기 후 Half-open | --> | 탐색 성공·실패 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **Closed 호출**: 하위 호출을 허용하고 오류율·타임아웃 수를 집계함
2. **Open 전환**: 실패 임계치를 넘으면 하위 호출을 차단함
3. **Half-open 전환**: 대기 시간이 끝나면 제한된 탐색 호출만 허용함
4. **복구 판정**: 탐색이 성공하면 Closed, 실패하면 Open으로 전환함

> 요약: Closed에서 실패 임계치를 넘으면 Open으로 차단하고 Half-open 탐색 결과로 Closed 복귀 여부를 결정함.

## Ⅵ. 실무 사례

1. 결제 외부 API는 호출별 실패 임계치와 격리 풀을 적용하고 차단 전환 시간·스레드 풀 포화율을 확인함
2. 상품 조회 서비스는 Half-open 탐색과 캐시 대체 응답을 적용하고 탐색 성공률·잘못된 대체 응답 수를 확인함

## Ⅶ. 결론

서킷 브레이커는 실패 임계치와 복구 탐색 상태로 하위 장애가 상위 자원을 고갈시키는 경로를 차단함
