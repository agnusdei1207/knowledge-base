## 미리 알고가기

- 교착상태: 둘 이상의 실행 주체가 서로 보유한 자원을 기다려 진행하지 못하는 상태임
- 안전 상태: 모든 프로세스를 완료할 자원 할당 순서가 하나 이상 존재하는 상태임
- 대기 그래프: 프로세스 사이의 자원 대기 관계를 방향 간선으로 표현한 그래프임
- 발생 4조건: 상호 배제·점유와 대기·비선점·환형 대기가 동시에 성립해야 교착상태가 발생함

## 작성 근거(검토용)

- 상호 배제·점유 대기·비선점·순환 대기를 발생 조건과 제거 기준으로 설명함
- 예방·회피·탐지·복구는 적용 시점, 필요 정보 범위, 조치와 부작용이라는 3개 판단축으로 비교함
- 서로 다른 대응 흐름을 하나로 합치지 않고 예방·회피·탐지 및 복구로 나눔

## Ⅰ. 개요
- **정의/개념**: 교착상태는 둘 이상의 프로세스나 트랜잭션이 서로 보유한 자원의 해제를 기다려 진행하지 못하는 상태임
- **배경/필요성**: 제한된 자원의 순환 대기와 서비스 중단을 통제하기 위해 발생 조건과 예방·회피·탐지·복구 기준이 필요함

## Ⅱ. 특징

- 상호 배제·점유 대기·비선점·순환 대기가 동시에 성립하면 교착상태가 발생할 수 있음
- 예방은 네 조건 중 하나를 구조적으로 제거함
- 회피는 자원 요청 후에도 안전 순서가 남는지 검사함
- 탐지·복구는 교착상태 발생을 허용하고 대기 관계 확인 후 종료·롤백·자원 선점을 수행함

## Ⅲ. 종류 및 비교

| 판단 기준 | 예방 | 회피 | 탐지 | 복구 |
|:---|:---|:---|:---|:---|
| 적용 시점 | 자원 요청 규칙 설계 시 | 요청 승인 전 | 자원 할당 후 주기·이벤트 | 교착상태 확인 후 |
| 필요 정보 범위 | 자원 순서·선점 가능성 | 최대 요구량·현재 할당·가용량 | 대기 관계·할당 상태 | 작업 비용·복구 지점·자원 상태 |
| 조치와 부작용 | 조건 하나 제거, 동시 사용 범위 제한 | 안전 상태 요청만 승인, 보수적 할당 | 사이클 탐색, 탐지 연산·저장 비용 | 종료·롤백·자원 선점, 중단·재실행 비용 |

> 요약: 예방은 조건을 제거하고, 회피는 안전성을 사전 검사하며, 탐지는 발생 후 대기 관계를 찾고 복구는 실행 상태를 되돌림.

## Ⅳ. 구성요소 및 구조
```
[ P1 ] --(Hold)--> [ R1 ] <--(Request)-- [ P2 ]
  ^                                        |
  |                                        v
(Request) <------- [ R2 ] <------------(Hold)
```
| 구성요소 | 설명 | 제거 기준 |
| :--- | :--- | :--- |
| 상호 배제 | 한 번에 한 프로세스만 자원을 사용함 | 공유 가능 자원 전환 |
| 점유와 대기 | 자원을 가진 채 다른 자원을 추가로 요청함 | 일괄 요청 |
| 비선점 | 다른 프로세스의 자원을 강제로 뺏을 수 없음 | 선점 가능 자원 설계 |
| 환형 대기 | 프로세스들이 원형으로 자원을 대기함 | 전역 자원 순서 |
> 요약: 위 4가지 조건이 동시에 충족될 때 교착상태가 발생함.

## Ⅴ. 원리 및 절차 흐름도
```
[예방] 자원 요청 -> 전역 순서·일괄 요청 규칙 검사 -> 조건 충족 시 할당
[회피] 자원 요청 -> 가상 할당 -> 안전 순서 검사 -> 승인 또는 대기
[탐지·복구] 대기 관계 수집 -> 사이클·완료 불가 집합 탐지 -> 종료·롤백·자원 선점
```
1. **예방**: 전역 자원 순서나 일괄 요청 규칙을 위반한 요청을 대기시킴
2. **회피**: 요청을 가상 할당하고 모든 프로세스를 완료할 안전 순서가 있을 때 승인함
3. **탐지·복구**: 대기 그래프나 할당 벡터에서 교착 집합을 찾고 종료·롤백·선점을 수행함
> 요약: 예방·회피는 할당 전에 조건을 통제하고, 탐지·복구는 할당 후 교착 집합을 찾아 실행 상태를 회복함.

## Ⅵ. 실무 사례

1. 데이터베이스는 트랜잭션 대기 그래프를 탐지하고 교착 건수와 롤백 소요시간을 확인함
2. 서버 애플리케이션은 락 획득 순서를 통일하고 락 대기시간과 순서 위반 건수를 확인함

## Ⅶ. 결론

- 교착상태 대응은 최대 요구량·자원 순서·롤백 가능 여부에 따라 예방·회피·탐지·복구를 선택함
