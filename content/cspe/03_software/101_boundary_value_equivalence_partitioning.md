## Ⅰ. 개요
- 정의: Boundary Value/Equivalence Partitioning의 핵심 개념과 주요 목적
- 배경: 소프트웨어 복잡도 증가 및 품질 보증 요구 증대
- 출제 의도: | 유형 | 난이도 | 중요도 |
| --- | --- | --- |
| 기술 비교 | 중 | 상 |

## Ⅱ. 구성요소
- ASCII 구조도
  [--- (Lower) ---][Boundary][--- (Valid) ---][Boundary][--- (Upper) ---]

- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 동등 분할 | 입력 도메인을 유효/무효 영역으로 구분 | 끼리끼리 |
| 경계값 분석 | 영역의 경계와 인접값 위주 선정 | 끝단 확인 |
| 유효값/무효값 | 정상 처리 영역과 비정상 처리 영역 | 합격/불합격 |

> 요약: 효율적인 테스트 케이스 선정을 위한 명세 기반 기법임.

## Ⅲ. 절차
- ASCII 흐름도
  Range -> Partitioning -> Boundary Pick -> TC Creation

1. 범위 식별: 입력 데이터의 도메인과 제약조건 분석함.
2. 파티셔닝: 유효 영역과 무효 영역으로 동등 분할함.
3. 경계값 선정: 최소, 최소+1, 최대, 최대-1 등 선정함.
4. 케이스 도출: 선정된 대표값으로 테스트 시나리오 작성함.

> 요약: 최소 케이스로 최대 결함 발견율(결함 집중 원리) 확보함.

## Ⅳ. 문제점
- 다중 조건 결합 시 조합의 수가 급증하여 선정 어려움 발생함.
- 상태 변화나 복합 비즈니스 로직 반영에 한계가 있음.

## Ⅴ. 개선방안
- 결정 테이블(Decision Table) 연동으로 복합 조건 체계적 관리함.
- 페어와이즈(Pairwise) 기법 병행으로 조합의 수 최적화함.

## Ⅵ. 전망
- 자율주행, 의료기기 등 고신뢰성 SW의 엄격한 데이터 검증에 필수임.
- CSF: 도메인 전문가의 지식을 반영한 유효 영역의 정확한 정의임.
