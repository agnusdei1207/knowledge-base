## Ⅰ. 개요
- 관계형 DB 설계에서 중복을 최소화하기 위해 테이블을 무손실 분해하는 과정임.
- 갱신, 삽입, 삭제 시 발생하는 이상 현상(Anomaly)을 방지하는 것이 주 목적임.
- 출제 의도: 함수적 종속성 이해와 단계별 정규형(NF) 적용 능력 확인.

## Ⅱ. 구성요소
- 이상 현상 (Anomaly) 종류
[Data Input] -> [Error/Ghost Data]

| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| 삽입 이상 | 데이터 저장 시 불필요한 정보까지 함께 넣어야 함 | 패키지 강매 |
| 삭제 이상 | 필요한 정보를 삭제할 때 연관된 정보도 같이 유실됨 | 빈대 잡으려다 초가삼간 태움 |
| 갱신 이상 | 일부 속성만 수정되어 데이터 불일치 발생함 | 주소록 일부만 오기 |
> 요약: 불필요한 종속성으로 인해 데이터의 일관성이 깨지는 현상임.

## Ⅲ. 절차
- 정규화 단계 (1~BCNF)
[Raw Table] -> (1NF) -> (2NF) -> (3NF) -> (BCNF) -> [Clean Tables]

1. 제1정규형(1NF): 도메인이 원자값(Atomic value)을 갖도록 분해함.
2. 제2정규형(2NF): 부분 함수적 종속성 제거 (완전 함수적 종속성 확보).
3. 제3정규형(3NF): 이행적 함수적 종속성 제거 (A->B, B->C 관계 분리).
4. BCNF: 결정자가 후보키가 아닌 함수적 종속성 제거함.
> 요약: 단계별로 종속 관계를 단순화하여 데이터 무결성을 강화함.

## Ⅳ. 문제점
- 과도한 정규화로 인한 조인(Join) 연산 증가 및 쿼리 성능 저하 현상.

## Ⅴ. 개선방안
- 성능 임계점 분석 후 반정규화(Denormalization) 전략적 적용.

## Ⅵ. 전망
- 인메모리 DB 및 컬럼 지향 저장소 확산으로 조인 성능 이슈가 완화되는 추세임.
- 자동 정규화 도구와 성능 시뮬레이션 기반의 동적 튜닝 기술 발전 기대됨.
