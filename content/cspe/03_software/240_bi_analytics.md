## Ⅰ. 개요
- 정의: 데이터를 수집/정제/분석하여 의사결정에 필요한 통찰력을 제공하는 기술임
- 배경: 빅데이터 시대의 도래 및 데이터 기반 경영(Data-driven Management) 가속화
- 출제 의도
| 대상 | 주요 포인트 | 비중 |
|------|------------|------|
| 기술 스택 | ETL, DW, OLAP | 매우높음 |
| 시각화 | 대시보드, 리포팅 | 보통 |

## Ⅱ. 구성요소
- ASCII 구조도
  [ 원천 DB ] -> [ ETL ] -> [ 데이터 웨어하우스(DW) ]
                                |
  [ 시각화 ] <- [ 분석/OLAP ] <- [ 데이터 마트(DM) ]

- 구성요소 표
| 구성요소 | 설명 | 비유 |
|----------|------|------|
| ETL | 추출, 변환, 적재를 통한 데이터 정제 과정 | 세척 및 포장 |
| OLAP | 다차원 데이터를 분석하고 조회하는 기술 | 큐브 맞추기 |
| 대시보드 | 주요 지표(KPI)를 한눈에 볼 수 있는 화면 | 자동차 계기판 |

> 요약: 원시 데이터를 가공하여 의사결정권자가 즉시 활용 가능한 정보로 변환함

## Ⅲ. 절차
- ASCII 흐름도
  [데이터 수집] -> [정제 및 통합] -> [모델링 및 분석] -> [결과 시각화]
    (Sourcing)        (Cleaning)         (Modeling)         (Insight)

- 4단계 설명
1. 데이터확보: 내부 ERP 데이터와 외부 시장 데이터를 수집함
2. 전처리: 중복을 제거하고 분석 가능한 표준 형식으로 변환하여 DW에 적재함
3. 심층분석: 통계 모델이나 데이터 마이닝을 통해 숨겨진 패턴을 발견함
4. 리포팅: 직관적인 차트와 그래프로 구성된 대시보드를 통해 인사이트 전달함

> 요약: 데이터의 수명 주기에 맞춰 가치를 창출하고 행동 지침을 도출함

## Ⅳ. 문제점
- 데이터 품질이 낮을 경우(Garbage In, Garbage Out) 잘못된 의사결정 유도함
- 분석 전문가(Data Scientist) 부족으로 인해 시스템 구축 후 활용도가 낮음

## Ⅴ. 개선방안
- (단기) 데이터 거버넌스 체계를 수립하여 데이터의 정합성과 신뢰성 확보함
- (중기) 셀프 서비스 BI(Self-Service BI) 도입으로 현업의 직접 분석 역량 강화함
- (장기) 예측 분석(Predictive)에서 처방 분석(Prescriptive)으로 분석 수준 고도화함

## Ⅵ. 전망
- 생성형 AI와 대화하며 데이터를 분석하는 'Conversational Analytics'가 보편화됨
- 실시간 스트리밍 데이터 분석을 통해 현장의 변화에 즉각 대응하는 체계 구축됨
