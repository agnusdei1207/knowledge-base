## Ⅰ. 개요
- 정의: Functional Programming의 핵심 개념과 주요 목적
- 배경: 소프트웨어 복잡도 증가 및 품질 보증 요구 증대
- 출제 의도: | 유형 | 난이도 | 중요도 |
| --- | --- | --- |
| 기술 비교 | 중 | 상 |

## Ⅱ. 구성요소
- ASCII 구조도
  Input -> [ Pure Function ] -> Output
             (No Side Effect)

- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 순수 함수 | 동일 입력에 항상 동일 출력을 보장함 | 자판기 |
| 불변성 (Immutability) | 상태를 변경하지 않고 새로운 상태 생성 | 복사본 생성 |
| 고차 함수 | 함수를 인자로 받거나 반환하는 함수 | 도구를 만드는 도구 |

> 요약: 상태 변경을 지양하고 수학적 함수 계산으로 로직 구현함.

## Ⅲ. 절차
- ASCII 흐름도
  Data -> Map -> Filter -> Reduce -> Result

1. 로직 분석: 상태 변화가 필요한 부분과 계산 부분 분리함.
2. 함수 설계: 작은 단위의 순수 함수들로 기능 쪼개기 수행함.
3. 파이프라인 구성: 함수들을 조합(Composition)하여 흐름 구축함.
4. 실행 및 테스트: 부수 효과가 없으므로 단위 테스트 용이하게 수행함.

> 요약: 간결한 코드와 동시성 처리에 최적화된 구조 확보함.

## Ⅳ. 문제점
- 무분별한 객체 생성에 따른 메모리 사용량 증가 가능성함.
- 객체지향에 익숙한 개발자의 패러다임 전환 비용 발생함.

## Ⅴ. 개선방안
- 지연 평가(Lazy Evaluation) 및 꼬리 재귀 최적화 기술 적용함.
- 자바(Lambda), 코틀린 등 기존 언어의 함수형 특징 점진적 도입함.

## Ⅵ. 전망
- 빅데이터 처리 및 인공지능 모델 구현의 핵심 기법으로 강화됨.
- CSF: 상태 관리의 최소화와 함수 간의 느슨한 결합 설계임.
