## Ⅰ. 개요
- 정의: 하드웨어 종속성에서 벗어나 소프트웨어로 인프라를 제어, 관리, 자동화하는 기술 총칭.
- 출제 의도: 클라우드 컴퓨팅의 기반인 인프라 추상화 및 프로그래밍 가능성(Programmability) 이해 확인.

## Ⅱ. 구성요소
- ASCII 구조도
  [ Application Layer ] -> [ SDDC Manager ]
                                |
  [ SDN (Network) ] [ SDS (Storage) ] [ SDC (Compute) ]
  (Control Plane)    (Virtual Pool)    (Hypervisor)
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| SDN | 네트워크 제어 평면과 데이터 평면을 분리하여 중앙 제어 | 원격 신호등 관리 |
| SDS | 물리 디스크를 추상화하여 논리적인 저장 공간 풀로 제공 | 가상 공유 창고 |
| SDDC | 모든 데이터센터 인프라를 S/W로 가상화하여 운영하는 센터 | 자율주행 데이터센터 |
> 요약: 하드웨어는 범용 제품을 쓰고 지능은 소프트웨어로 구현하여 유연성 극대화함.

## Ⅲ. 절차
- ASCII 흐름도
  [물리 자원 풀링] -> [추상화 계층 구축] -> [API 기반 제어] -> [자동 프로비저닝]
- 4단계 설명
1. 다양한 이기종 하드웨어 자원을 하나로 묶어 가상 자원 풀을 형성함.
2. 소프트웨어 계층이 각 자원의 특성을 파악하고 논리적 단위로 나눔.
3. 사용자가 API나 포털을 통해 필요한 인프라 스펙을 요청함.
4. 관리 엔진이 즉시 자원을 할당하고 네트워크 및 보안 정책을 자동 적용함.
> 요약: 물리적 개입 없이 소프트웨어 명령만으로 인프라 생명주기를 관리함.

## Ⅳ. 문제점
- 성능 오버헤드: 소프트웨어 추상화 계층 통과 시 발생하는 처리 지연 및 CPU 부하 발생함.
- 보안 위협: 중앙 집중식 컨트롤러 탈취 시 전체 인프라가 공격자에게 노출됨.

## Ⅴ. 개선방안
- 가속기 활용: DPU(Data Processing Unit), SmartNIC 등을 사용하여 S/W 부하를 하드웨어로 오프로드함.
- 제로 트러스트: 컨트롤러 접근에 대한 다중 인증 및 마이크로 세그먼테이션 보안 적용함.

## Ⅵ. 전망
- 엣지 컴퓨팅 확산에 따라 원격지의 소규모 인프라를 중앙에서 관리하는 SD-WAN 기술 중요해짐.
- AI가 트래픽과 부하를 예측하여 스스로 인프라를 재구성하는 '의도 기반 네트워킹(IBN)' 상용화됨.
- 개별 기술을 넘어 멀티 클라우드를 하나로 묶는 글로벌 SDDC 아키텍처로 확장될 것임.
