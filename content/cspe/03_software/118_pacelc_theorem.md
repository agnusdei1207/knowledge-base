## 미리 알고가기

- PACELC는 분할이 났을 때와 평상시를 나눠 보는 분산 저장소 판단 기준임
- 분할이 나면 가용성과 일관성 중 무엇을 더 지킬지 정해야 함
- 평상시에도 응답 속도와 일관성 사이에 비용 차이가 생김
- PC/EC는 일관성을 더 중시하는 성향이고 PA/EL은 가용성과 응답 속도를 더 중시하는 성향임

## 작성 근거(검토용)

- 제목·frontmatter·미리 알고가기·본문·표·요약·결론을 5회 전수 검수해 어색한 단어·조사·동사 결합·장황한 명사구를 교정함
- PACELC는 분할 시 A·C와 정상 시 L·C의 선택을 핵심 축으로 설명함
- 비교표는 일관성·지연 우선형의 분할 시 선택·평상시 선택·대표 업무를 대비함
- 다지역 DB는 p99 쓰기 지연·데이터 지연으로 검증함

## Ⅰ. 개요

- **정의/개념**: PACELC 정리는 네트워크 분할 시 가용성·일관성, 정상 시 응답 지연·일관성의 선택을 설명하는 분산 시스템 원리임
- **배경/필요성**: 분할 장애와 정상 운영에서 서로 다른 복제 비용을 판단하기 위해 일관성·가용성·응답 지연을 함께 비교해야 함

### 쉽게 이해하기 (학습용)
- 지점 통신이 끊긴 비상시와 정상 연결된 평상시에 각각 정확성과 속도 중 우선순위를 정함

## Ⅱ. 특징

- 분할 장애 때의 판단과 정상 운영 때의 판단을 따로 본다는 점이 핵심임
- 강한 일관성을 유지할수록 복제 동기화 비용과 응답 지연이 커질 수 있음
- 낮은 지연을 우선하면 일부 읽기에서 최신 값이 늦게 보일 수 있음
- 같은 분산 저장소에서도 업무별로 다른 PACELC 성향이 필요함

### 쉽게 이해하기 (학습용)
- CAP의 비상 선택에 평상시 복제 확인 지연까지 더해 실제 운영 결정을 설명함

## Ⅲ. 종류 및 비교

| 판단 기준 | 일관성 우선형(PC/EC) | 낮은 지연 우선형(PA/EL) |
|:---|:---|:---|
| 분할 시 선택 | 일관성을 먼저 지킴 | 가용성을 먼저 지킴 |
| 평상시 선택 | 복제 확인·합의 후 응답 | 가까운 복제본 응답 후 비동기 동기화 |
| 대표 업무 | 최신 값 확인이 필요한 결제·재고·기준 정보 | 오래된 읽기를 허용하는 피드·추천·대규모 조회 |

> 요약: 일관성 우선형은 분할·정상 상태에서 복제 확인을 중시하고, 응답 우선형은 가용성과 낮은 지연을 중시함.

### 쉽게 이해하기 (학습용)
- 결제는 정확성을, 피드는 가까운 사본의 빠른 응답을 우선함

## Ⅳ. 설계 요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 분할 시 정책 | 분할 중 요청을 거부·지연할지 연결 가능한 노드에서 처리할지 정함 |
| 평상시 응답 목표 | 어느 수준의 지연을 허용할지 정함 |
| 복제 동기화 방식 | 동기 복제인지 비동기 복제인지에 따라 일관성과 속도가 갈림 |
| 업무 등급 | 어떤 데이터가 더 엄격한 일관성을 요구하는지 나눔 |

> 요약: 분할 시 정책과 정상 시 응답 목표를 복제 방식과 업무 등급에 연결해 PACELC 성향을 결정함.

### 쉽게 이해하기 (학습용)
- 비상 정책, 평상시 목표 지연, 사본 맞추는 방식과 업무 등급을 한 표로 정함

## Ⅴ. 원리 및 절차 흐름도

```text
[분할 여부 판단] --분할--> [A 또는 C 선택]
        └--정상--> [L 또는 C 선택] -> [업무 SLO 검증]
```

1. 네트워크 분할 여부와 복제본 간 통신 가능 상태를 확인함
2. 분할 시 가용성(A)과 일관성(C) 중 업무 우선순위를 적용함
3. 정상 시 낮은 지연(L)과 일관성(C) 중 응답 정책을 적용함
4. p99 지연·오래된 읽기·복제 지연으로 선택 결과를 검증함

> 요약: 분할 중 A/C와 정상 상태 L/C를 나눠 업무별 복제·응답 정책을 결정함.

### 쉽게 이해하기 (학습용)
- 전화가 끊겼을 때와 연결됐을 때 각각 영업 지속·장부 확인·응답 속도의 규칙을 적용함

## Ⅵ. 실무 사례

1. 다지역 주문 DB는 동기 복제 범위를 제한하고 p99 쓰기 지연·충돌 건수를 확인함
2. 사용자 피드 DB는 비동기 복제를 적용하고 p95 응답 지연·데이터 지연을 확인함

### 쉽게 이해하기 (학습용)
- 결제·재고와 피드·추천의 요구를 나눠 지연과 오래된 읽기를 측정함

## Ⅶ. 결론

- PACELC는 분할 시 가용성·일관성과 정상 시 응답 지연·일관성의 우선순위를 함께 결정함
- 데이터 등급별 선택을 명시하고 p99 지연·복제 지연·오래된 읽기 비율로 지속 검증해야 함

### 쉽게 이해하기 (학습용)
- 비상 규칙과 평상시 규칙을 따로 정하고 실제 속도와 장부 차이를 계속 확인해야 함
