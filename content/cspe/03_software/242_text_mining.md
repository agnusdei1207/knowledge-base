## Ⅰ. 개요
- 정의: 비정형 텍스트 데이터에서 유용한 정보를 추출하고 감성을 분석하는 기술임
- 배경: 소셜 미디어, 뉴스, 리뷰 등 폭발적으로 증가하는 텍스트 자산 활용 필요
- 출제 의도
| 대상 | 주요 포인트 | 비중 |
|------|------------|------|
| 전처리 | 형태소 분석, 불용어 제거 | 높음 |
| 감성 분석 | 긍정/부정 분류, 극성 | 매우높음 |

## Ⅱ. 구성요소
- ASCII 구조도
  [ 텍스트 ] -> [ 전처리(NLP) ] -> [ 특징 추출 ] -> [ 마이닝/분석 ]
      |               |                |               |
    (수집)        (토큰화)           (TF-IDF)        (주제/감성)

- 구성요소 표
| 구성요소 | 설명 | 비유 |
|----------|------|------|
| 토큰화 (Tokenizing) | 문장을 단어 등 최소 단위로 쪼개는 과정 | 레고 분해 |
| 형태소 분석 | 단어의 품사를 판별하고 원형을 추출함 | 뼈대 찾기 |
| 워드 클라우드 | 빈도수가 높은 단어를 크기로 시각화 | 말구름 |

> 요약: 사람이 읽는 언어를 기계가 이해할 수 있는 숫자로 변환하여 분석함

## Ⅲ. 절차
- ASCII 흐름도
  [수집] -> [정규화] -> [임베딩] -> [분석 및 시각화]
   (Web)    (Lemmatize)  (Vector)     (Topic/Sentiment)

- 4단계 설명
1. 데이터수집: 크롤링 등을 통해 텍스트 데이터를 대량으로 확보함
2. 전처리: 오탈자 수정, 특수문자 및 불용어 제거, 형태소 분석 수행함
3. 벡터화: Word2Vec, BERT 등을 사용하여 단어를 고차원 벡터로 수치화함
4. 마이닝실행: 토픽 모델링으로 주제를 찾거나 감성 사전으로 여론을 파악함

> 요약: 비정형 데이터를 정제-수치화-분석하여 숨겨진 의도를 도출함

## Ⅳ. 문제점
- 신조어, 줄임말, 역설적 표현(반어법)에 대한 인식 정확도가 떨어짐
- 특정 분야(도메인)에 특화된 용어 처리를 위해 막대한 사전 구축 비용 소요됨

## Ⅴ. 개선방안
- (단기) 최신 신조어를 주기적으로 업데이트하는 동적 사전 체계 구축함
- (중기) 문맥(Context) 파악 능력이 뛰어난 거대 언어 모델(LLM)을 적용함
- (장기) 텍스트 외에 이미지, 음성을 함께 분석하는 멀티모달 분석으로 고도화함

## Ⅵ. 전망
- 고객 상담 데이터의 실시간 감성 분석을 통한 즉각적인 위기 대응 시스템 확산됨
- 가짜 뉴스 판별 및 혐오 표현 자동 필터링 등 사회적 안전망 구축에 활용 증대됨
