## Ⅰ. 개요
- 정의: 데이터에서 분류·군집·연관·회귀 패턴을 탐색하고 업무 목표에 대한 유효성을 평가하는 과정임
- 배경: 정보 과잉 상태에서 의사결정에 직접적인 도움을 주는 지식 발견 필요
- 출제 의도
| 대상 | 주요 포인트 | 비중 |
|------|------------|------|
| 주요 기법 | 분류, 군집, 연관, 회귀 | 매우높음 |
| 프로세스 | CRISP-DM, SEMMA | 높음 |

## Ⅱ. 구성요소
- ASCII 구조도
  [ 데이터 ] -> [ 전처리 ] -> [ 데이터 마이닝 ] -> [ 지식 발견 ]
      |            |               |                |
    (수집)      (정제/변환)      (패턴 탐색)       (가치 판단)

- 구성요소 표
| 구성요소 | 설명 | 비유 |
|----------|------|------|
| 연관 분석 | 함께 구매되는 상품 간의 관계 탐색 | 맥주와 기저귀 |
| 분류 (Classification) | 정해진 클래스에 데이터를 할당 (지도학습) | 메일 스팸 분류 |
| 군집 (Clustering) | 유사한 속성끼리 묶음 (비지도학습) | 고객군 나누기 |

> 요약: 전처리된 데이터에 분석 기법을 적용하여 예측 규칙·집단·연관 관계를 도출함

## Ⅲ. 절차 (CRISP-DM 기준)
- ASCII 흐름도
  [비즈니스 이해] <-> [데이터 이해] -> [데이터 준비] -> [모델링] -> [평가]
                                     ^          |         |
                                     +----------+---------+

- 4단계 설명
1. 이해: 비즈니스 목표를 설정하고 사용 가능한 데이터를 탐색함
2. 준비: 데이터 선택, 정제, 통합을 통해 분석용 데이터셋을 생성함
3. 모델링: 문제에 적합한 알고리즘을 선택하고 모델의 파라미터를 튜닝함
4. 평가: 결과가 비즈니스 목표에 부합하는지 검증하고 적용 여부를 결정함

> 요약: 업무 목표에 맞춰 데이터를 준비하고 모델 성능과 적용 가능성을 반복 평가함

## Ⅳ. 문제점
- 데이터의 편향성으로 인해 부당한 차별이나 잘못된 예측 결과 도출될 수 있음
- 모델의 해석 가능성(Explainability)이 낮아 결과의 신뢰 확보가 어려운 경우가 많음

## Ⅴ. 개선방안
- (단기) 데이터 샘플링 시 편향을 제거하고 전처리 과정의 투명성을 높임
- (중기) 설명 가능한 AI(XAI) 기술을 적용하여 분석 결과의 근거를 명확히 함
- (장기) 데이터 레이크와 MLOps를 결합하여 분석-배포-재학습 자동화 체계 구축함

## Ⅵ. 전망
- 오토 ML(AutoML)을 통해 비전문가도 수준 높은 마이닝을 수행하는 민주화 가속됨
- 그래프 마이닝 등을 활용하여 복잡한 관계망 속의 이상 징후 탐색 능력이 강화됨
