## Ⅰ. 개요
- 정의: 품질 속성을 달성하기 위한 구체적 기술적 조치(전술)와 검증된 해결책(패턴)임
- 배경: 아키텍처 설계 시 반복되는 문제에 대한 베스트 프랙티스 활용 필요성 대두
- 출제 의도: 가용성, 성능 등 품질 요구사항별 대응 기술 및 패턴 매핑 능력 평가

## Ⅱ. 구성요소
- ASCII 구조도
  [Quality Attribute] -> [Tactics] -> [Architectural Pattern]
      (Goal)            (Method)         (Structure)
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| 전술(Tactics) | 단일 품질 속성을 제어하는 기술적 설계 의사결정 | 요리 비법 |
| 패턴(Pattern) | 시스템 전반의 구조적 틀과 컴포넌트 관계 정의 | 표준 레시피 |
| 매커니즘 | 전술과 패턴이 결합되어 동작하는 실제 구현 방식 | 조리 과정 |
> 요약: 전술은 미시적 품질 제어, 패턴은 거시적 구조 설계를 위해 상호 보완적으로 사용함

## Ⅲ. 절차
- ASCII 흐름도
  Goal ID -> Tactic Select -> Pattern Mapping -> Integration
- 4단계 설명
1. Goal ID: 아키텍처 드라이버로부터 우선순위가 높은 품질 목표 식별함
2. Tactic Select: 가용성(복구), 성능(자원관리) 등 속성별 핵심 전술 선정함
3. Pattern Mapping: 선정된 전술을 효과적으로 수용할 수 있는 패턴 선택함
4. Integration: 패턴 내부에 전술을 통합하여 전체 아키텍처 구조를 확정함
> 요약: 품질 목표에 맞춰 전술을 고르고 이를 패턴에 담아 일관된 구조를 형성함

## Ⅳ. 문제점
- 원인이 명시된 문제/한계: 특정 패턴의 무비판적 적용 시 시스템 유연성 저하 및 성능 병목 발생함

## Ⅴ. 개선방안
- Ⅳ의 문제에 대응하는 방안: 패턴 간 상충 관계 분석 및 안티 패턴(Anti-pattern) 검증함

## Ⅵ. 전망
- 발전 방향: AI 기반 품질 속성 예측 및 최적의 전술/패턴 자동 추천 시스템 도입 가속화
- CSF: 개별 전술의 독립적 적용보다는 전술 간 시너지와 제약 사항의 입체적 고려가 필수임
