## 미리 알고가기

- 반정규화는 조회 성능을 높이기 위해 중복 컬럼이나 요약 테이블을 의도적으로 두는 설계임
- 정규화가 틀렸다는 뜻이 아니라 조회 병목이 분명할 때 추가로 적용하는 물리 설계 기법임
- 중복이 늘어나는 만큼 동기화 경로와 검증 절차를 함께 설계해야 함
- 읽기 성능 이득과 쓰기·정합성 비용을 함께 측정해야 적용 여부를 판단할 수 있음

## 작성 근거(검토용)

- 제목·frontmatter·미리 알고가기·본문·표·요약·결론을 5회 전수 검수해 어색한 단어·조사·동사 결합·장황한 명사구를 교정함
- 반정규화는 조회 병목, 중복 구조, 동기화 경로를 핵심 축으로 설명함
- 비교표는 정규화와 반정규화의 데이터 구조·처리 이점·적용 조건을 대비함
- 조회 DB는 p95 질의 지연·동기화 지연으로 검증함

## Ⅰ. 개요

- **정의/개념**: 반정규화는 중복 컬럼·요약 테이블을 의도적으로 추가해 조인과 집계 비용을 줄이는 물리 설계 기법임
- **배경/필요성**: 반복 조회의 조인·집계 병목을 줄이면서 데이터 일관성을 유지하기 위해 중복 범위와 동기화 경로를 함께 설계해야 함

### 쉽게 이해하기 (학습용)
- 자주 보는 여러 장의 자료를 한 장에 미리 복사하되, 원본이 바뀌면 복사본도 함께 고치는 방식임

## Ⅱ. 특징

- 반복 질의의 조인·집계 결과를 중복 컬럼·요약 테이블에 저장해 조회 시 연산과 I/O를 줄임
- 함께 조회하는 데이터를 중복 저장해 질의의 조인 수를 줄일 수 있음
- 같은 사실을 여러 곳에 저장하므로 갱신 누락과 불일치 위험이 커짐
- 병목 질의가 분명할 때만 적용해야 하며 관성적으로 넓히면 관리 비용이 커짐

### 쉽게 이해하기 (학습용)
- 읽을 때는 빠르지만 같은 내용을 여러 곳에 적으므로 수정할 때 빠뜨릴 위험이 커짐

## Ⅲ. 종류 및 비교

| 판단 기준 | 정규화 | 반정규화 |
|:---|:---|:---|
| 데이터 구조 | 같은 사실을 한 곳에 두려고 함 | 조회 성능을 위해 같은 사실을 여러 곳에 둘 수 있음 |
| 처리 이점 | 무결성과 변경 관리가 쉬움 | 조인과 집계가 줄어 조회가 빨라짐 |
| 적용 조건 | 갱신 일관성이 중요한 거래 처리 | 측정된 반복 조회·집계 병목이 있고 동기화가 가능할 때 |

> 요약: 정규화는 중복을 줄여 갱신 일관성을 높이고, 반정규화는 중복을 허용해 반복 조회 비용을 줄임.

### 쉽게 이해하기 (학습용)
- 정규화는 원본 한 권을 정확히 관리하고, 반정규화는 자주 찾는 쪽을 복사해 빠르게 보는 선택임

## Ⅳ. 설계 요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 병목 질의 분석 | 느린 조회와 집계를 찾아 어떤 중복이 실제로 필요한지 정함 |
| 중복 컬럼 또는 요약 테이블 | 자주 함께 읽는 값을 미리 모아 조인과 집계 비용을 줄임 |
| 동기화 경로 | 트리거와 배치와 애플리케이션 로직으로 원본과 중복 데이터를 함께 맞춤 |
| 검증 지표 | 응답 시간 개선과 데이터 불일치 발생 여부를 함께 측정함 |

> 요약: 반정규화는 병목 질의에 맞는 중복 구조를 설계하고 원본과 중복 데이터의 동기화를 검증함.

### 쉽게 이해하기 (학습용)
- 느린 화면을 찾고 필요한 복사본만 만들며, 원본과 복사본을 맞추는 장치를 함께 둠

## Ⅴ. 원리 및 절차 흐름도

```text
[병목 질의 측정] -> [중복 후보 선정] -> [동기화 경로 설계]
        -> [제한 적용] -> [성능·정합성 동시 검증]
```

1. 실행 계획과 지연 분포로 반복 조인·집계 병목을 확인함
2. 중복 컬럼·통합 테이블·요약 테이블 중 변경 범위가 가장 작은 방식을 선택함
3. 트랜잭션·이벤트·배치 중 허용 지연에 맞는 동기화 경로와 실패 복구 절차를 설계함
4. 적용 전후 조회 지연과 불일치 건수를 비교해 유지·철회 여부를 결정함

> 요약: 측정된 병목에 최소한의 중복을 적용하고 성능 이득과 정합성 비용을 함께 검증함.

### 쉽게 이해하기 (학습용)
- 정말 느린 곳만 골라 복사본을 만들고, 빨라졌는지와 내용이 틀리지 않았는지를 함께 확인함

## Ⅵ. 실무 사례

1. 대시보드 DB는 요약 테이블과 이벤트 동기화를 적용하고 p95 질의 지연·동기화 지연을 확인함
2. 거래 DB는 측정된 병목에만 중복 컬럼을 적용하고 불일치 건수·중복 컬럼 사용률을 확인함

### 쉽게 이해하기 (학습용)
- 대시보드에는 요약본을 두고, 거래 원장은 꼭 필요한 항목만 복사함

## Ⅶ. 결론

- 반정규화는 조회 성능 이득이 중복 관리 비용보다 클 때 적용하는 물리 설계 기법임
- 논리 모델의 정규성을 기준선으로 유지하고 지연·불일치 지표와 철회 경로를 갖춘 범위에서만 확대해야 함

### 쉽게 이해하기 (학습용)
- 복사본의 속도 이득이 관리 수고보다 클 때만 쓰고, 문제가 생기면 원래 구조로 돌아갈 수 있어야 함
