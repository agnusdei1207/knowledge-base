## 미리 알고가기

- 모놀리식 커널은 핵심 서비스가 커널 공간에 함께 포함되는 구조임
- 마이크로커널은 최소 기능만 커널에 두고 나머지를 사용자 공간 서버로 분리함
- 커널 기능의 배치 위치에 따라 호출 경로, 장애 전파 범위, 서비스 교체 방식이 달라짐
- IPC(Inter-Process Communication): 프로세스 간 메시지를 주고받는 통신 방식임
- 커널 패닉: 커널이 복구 불가능한 오류를 만나 시스템 전체가 중단되는 상태임

## 작성 근거(검토용)

- 두 커널은 호출 경로·장애 영향 및 서비스 변경·자원 비용 및 대표 환경으로 비교함
- 시스템 호출이 커널 내부 또는 사용자 공간 서버로 갈라지는 실제 요청 경로를 유지함
- 범용 서버와 제어 OS를 분리해 커널 패닉·IPC 지연·복구시간을 검증함

## Ⅰ. 개요

- **정의/개념**: 모놀리식 커널은 프로세스·메모리·파일시스템·장치 드라이버를 커널 공간에 통합하고, 마이크로커널은 스케줄링·IPC·주소 공간 관리만 커널에 두고 나머지 서비스를 사용자 공간으로 분리함
- **배경/필요성**: 시스템 호출 지연과 커널 결함의 전파 범위를 통제하기 위해 운영체제 기능의 배치 기준이 필요함

## Ⅱ. 특징

- 모놀리식 커널은 파일시스템·드라이버를 커널 내부 함수 호출로 연결함
- 마이크로커널은 파일시스템·드라이버를 사용자 공간 서버와 IPC로 연결함
- 마이크로커널은 IPC 비용이 커질 수 있고 모놀리식은 커널 결함 영향 범위가 큼
- 내부 호출 성능과 서비스별 결함 격리 요구에 따라 커널 기능의 배치 위치를 정함

## Ⅲ. 종류 및 비교

| 판단 기준 | 모놀리식 커널 | 마이크로커널 |
|:---|:---|:---|
| 호출 경로 | 핵심 서비스를 커널에 통합해 내부 함수로 직접 호출함 | 최소 커널만 남기고 사용자 공간 서버를 IPC로 호출함 |
| 장애 영향·서비스 변경 | 드라이버·서비스 결함이 커널 주소 공간에 전파되며 복구에는 커널 업데이트가 필요함 | 사용자 공간 서비스 단위로 결함이 격리되고 서버 재시작만으로 복구함 |
| 자원 비용·대표 환경 | 큰 커널 주소 공간, 범용 서버·데스크톱 OS | IPC·문맥 전환 비용, 안전·격리 요구 임베디드·제어 OS |

> 요약: 모놀리식은 커널 내부 호출로 서비스를 연결하고, 마이크로커널은 사용자 공간 서버와 IPC로 기능을 분리함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 커널 핵심부 | 모놀리식은 주요 서비스를 포함하고 마이크로커널은 스케줄링·IPC·주소 공간 관리만 둠 |
| 사용자 공간 서버 | 마이크로커널의 파일시스템·드라이버·네트워크 기능을 실행함 |
| IPC 경로 | 응용·서버·마이크로커널 사이 요청과 응답을 전달함 |
| 드라이버 배치 | 커널 내부 또는 사용자 공간에 장치 제어 기능을 배치함 |

> 요약: 커널 기능의 배치 위치가 내부 호출·IPC 경로와 결함 전파·서비스 재시작 범위를 결정함.

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 시스템 요청    | --> | 커널 기능 판별 | --> | 직접 처리 또는 IPC | --> | 결과 반환      |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **시스템 요청**: 응용 프로그램이 파일·장치·프로세스 시스템 호출을 생성함
2. **기능 위치 판별**: 요청 기능이 커널 내부인지 사용자 공간 서버인지 확인함
3. **내부 호출 또는 IPC**: 모놀리식은 커널 함수를, 마이크로커널은 서버 IPC를 실행함
4. **결과 반환**: 처리 결과를 다시 응용 프로그램에 돌려줌

## Ⅵ. 실무 사례

1. 범용 서버 OS는 커널 드라이버를 모듈화하고 커널 패닉률과 드라이버 결함 영향 범위를 확인함
2. 제어 OS는 드라이버를 사용자 공간 서버로 분리하고 IPC 지연과 서비스 복구시간을 확인함

## Ⅶ. 결론

- 커널 구조는 시스템 호출 지연과 드라이버·서비스 결함의 격리·복구 범위로 선택함
