## Ⅰ. 개요
- 정의: 관계형 데이터베이스의 정의, 조작, 제어를 위해 표준화된 구조적 질의 언어
- 배경: 데이터 독립성 확보 및 사용자와 DB 간 인터페이스 표준화
| 구분 | 내용 |
|------|------|
| 출제 의도 | DDL(정의), DML(조작), DCL(제어) 명령어의 분류와 트랜잭션 TCL 이해 |

## Ⅱ. 구성요소
  User -> [ SQL Parser ] -> [ DDL / DML / DCL / TCL ]
  -> [ DB Object ]
| 구성요소 | 설명 | 비유 |
|----------|------|------|
| DDL | Create, Alter, Drop (스키마 정의) | 설계도 작성 |
| DML | Select, Insert, Update, Delete (데이터 조작) | 내용물 편집 |
| DCL/TCL | Grant, Revoke / Commit, Rollback (권한/제어) | 열쇠 관리 |
> 요약: 데이터의 생명주기 전체를 관리하는 선언적 프로그래밍 언어

## Ⅲ. 절차
  Compose -> Validate -> Execute -> Transaction End
1. Composition: 목적에 맞는 SQL 문장 작성
2. Validation: 스키마 정보와 권한을 대조하여 검증
3. Execution: DBMS 엔진이 실행 계획에 따라 동작 수행
4. Control: 실행 결과를 확정(Commit)하거나 취소(Rollback)
> 요약: 표준 문법을 통한 체계적인 데이터베이스 제어 및 관리

## Ⅳ. 문제점
- 표준 SQL 외 DBMS별 독자 문법(Dialect)으로 인한 호환성 저하
- SQL Injection 취약점을 통한 데이터 유출 및 변조 위험

## Ⅴ. 개선방안
- 표준 SQL 준수 및 데이터베이스 추상화 계층 활용
- Prepared Statement 사용 및 입력값 검증 강제

## Ⅵ. 전망
- 자연어 기반 SQL 생성(Text-to-SQL) AI 도입 및 분산 환경 최적화 SQL 표준 확장
