## Ⅰ. 개요
- **정의**: 기업 데이터를 수집·분석·시각화하여 의사결정을 지원하는 기술 체계
- **배경/필요성**: 경험 기반 의사결정은 편향과 지연이 발생하므로 데이터 근거 기반 판단 체계가 필요함
- **비유**: 자동차 계기판과 같음 — 현재 상태를 수치로 보여주어 운전 판단을 지원함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 분석 체계 전반 이해 | 리포팅·OLAP·대시보드·데이터 마이닝 구분 | BI와 AI/ML 분석의 역할 차이 |

> 요약: 데이터를 분석·시각화하여 근거 기반 의사결정을 지원하는 체계임

## Ⅱ. 구성요소
```text
[데이터 소스] --> [ETL/통합] --> [DW/마트] --> [BI 플랫폼]
                                                  |
                                    +-------------+-------------+
                                    |             |             |
                              [대시보드]    [OLAP 큐브]   [리포트 엔진]
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| DW/마트 | 분석용으로 정제·적재된 데이터 저장소 (158·159 참조) | 분석용 자료실 |
| 대시보드 | KPI·지표를 실시간 시각화하는 인터페이스 | 관제 모니터 |
| OLAP 큐브 | 다차원 집계를 사전 계산하여 드릴다운 분석을 지원 | 루빅큐브 회전 |
| 리포트 엔진 | 정형 보고서를 자동 생성·배포하는 모듈 | 자동 인쇄기 |

> 요약: DW/마트의 데이터를 대시보드·OLAP·리포트로 소비하는 구조임

## Ⅲ. 절차
```text
데이터 수집 --> 저장/모델링 --> 분석/시각화 --> 의사결정 지원
```
- 1단계: 데이터 수집 — ETL/CDC로 운영 데이터를 분석 저장소에 통합함
- 2단계: 저장/모델링 — 스타 스키마 등으로 분석 최적화 모델을 구성함
- 3단계: 분석/시각화 — 대시보드·OLAP 드릴다운으로 지표를 탐색함
- 4단계: 의사결정 지원 — 분석 결과를 경영진·현업에 공유하여 행동을 유도함

> 요약: 수집-모델링-시각화-의사결정의 4단계로 데이터 기반 판단을 지원함

## Ⅳ. 문제점
- 데이터 지연: 배치 기반 적재로 인한 리포트 최신성 부족 — 실시간 판단 제약
- 활용도 저조: 현업 사용자의 분석 도구 이해 부족 — BI 투자 대비 활용률 낮음
- 지표 불일치: 부서별 상이한 지표 정의 — 동일 질문에 상반된 답변 발생

> 요약: 데이터 지연, 활용도 저조, 지표 불일치가 주요 문제임

## Ⅴ. 개선방안
1. 단기: 실시간 스트리밍 대시보드 도입으로 데이터 지연 최소화
2. 중기: 셀프서비스 BI 환경 구축 및 현업 대상 데이터 리터러시 교육
3. 장기: 전사 메트릭 레이어(Metrics Layer) 구축으로 지표 정의 단일화

> 요약: 실시간 대시보드, 셀프서비스, 메트릭 레이어로 개선이 필요함

## Ⅵ. 전망
- 발전 방향: 자연어 질의 기반 분석(NLQ) 및 AI 기반 자동 인사이트 생성 확산
- 기술사적 판단: 임베디드 BI(애플리케이션 내장형 분석)의 수요 증가 전망
- 기술사 제언: BI를 단순 리포팅 도구가 아닌 데이터 기반 문화 구축의 핵심 기반으로 설계할 필요
