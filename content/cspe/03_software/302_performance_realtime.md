## Ⅰ. 개요
- 정의: 주어진 시간 내에 요청을 처리하고(성능), 엄격한 시간 제약 조건을 준수함(실시간성)
- 배경: 사용자 체감 품질 향상 및 미션 크리티컬 시스템의 안정적 동작 보장 필요
- 출제 의도: 응답 시간 단축 전술 및 실시간 스케줄링 메커니즘 설계 역량 검증

## Ⅱ. 구성요소
- ASCII 구조도
  [Request] -> [Queue] -> [Process/Thread] -> [Response]
      ^           |             |
  (Latency) (Throughput) (Scheduling)
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| 응답 시간 | 요청 후 결과 반환까지의 소요 시간 | 음식 주문 대기시간 |
| 처리량 | 단위 시간당 처리 가능한 트랜잭션 수 | 시간당 조리량 |
| 결정론(Determinism)| 작업 완료 시간이 예측 가능한 특성 | 정확한 배달 시간 |
> 요약: 응답 시간·처리량·최악 실행 시간을 측정하여 성능 목표와 실시간 마감 준수 여부를 판단함

## Ⅲ. 절차
- ASCII 흐름도
  Bottleneck ID -> Tactic Apply -> Concurrency -> Validation
- 4단계 설명
1. Bottleneck ID: 자원 프로파일링을 통해 병목 구간(CPU, I/O, DB) 식별함
2. Tactic Apply: 캐싱(Caching), 데이터 압축, 비동기 처리 전술을 적용함
3. Concurrency: 작업 의존성과 공유 자원 경합을 분석하여 스레드·비동기·락 프리 방식을 선택함
4. Validation: 부하 테스트를 통해 임계 성능 및 실시간 마감 시간 준수 확인함
> 요약: 병목을 제거하고 전술적 최적화와 병렬 처리를 통해 목표 성능을 달성함

## Ⅳ. 문제점
- 공유 자원 경합이 증가하면 대기열과 락 대기 시간이 늘어 응답 시간 편차와 마감 위반이 발생함

## Ⅴ. 개선방안
- 우선순위 스케줄링·동시 실행 제한·자원 할당량 제어를 적용하고 최악 응답 시간을 재측정함

## Ⅵ. 전망
- 엣지 컴퓨팅 기반의 초저지연 처리 및 AI 가속기를 활용한 연산 성능 최적화
- CSF: 최악의 상황 시나리오(Worst-case)에서의 응답 시간 보증이 실시간 설계의 핵심임
