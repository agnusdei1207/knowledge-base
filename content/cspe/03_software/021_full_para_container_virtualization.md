## 미리 알고가기

- 전가상화는 게스트 OS 수정 없이 하이퍼바이저가 전체 하드웨어를 가상화하는 방식임
- 반가상화는 게스트 OS가 하이퍼바이저 존재를 인지하고 협력하는 방식임
- 컨테이너는 커널을 공유하면서 프로세스 격리를 제공하는 OS 수준 가상화임

## Ⅰ. 개요

- **정의/개념**: 전가상화와 반가상화와 컨테이너는 실행 환경을 분리하는 대표 방식으로, 전가상화는 완전한 가상 하드웨어를 제공하고 반가상화는 게스트와 하이퍼바이저가 협력하며 컨테이너는 커널 공유 기반 격리를 제공함
- **배경/필요성**: 서비스마다 요구하는 격리 수준과 성능과 배포 속도와 운영 비용이 다르므로, 동일한 가상화라는 이름 아래에서도 구조 차이를 이해하고 선택해야 함

## Ⅱ. 특징

- 전가상화는 수정하지 않은 게스트 OS를 독립 커널로 실행하며 장치 에뮬레이션과 VM exit 비용이 발생함
- 반가상화는 협력 인터페이스를 통해 I/O와 특권 연산 비용을 줄일 수 있음
- 컨테이너는 호스트 커널을 공유해 게스트 OS 부팅을 생략하며 namespace와 cgroup으로 실행 환경을 분리함
- 세 방식의 선택은 성능 수치보다 격리 경계와 운영 모델 차이로 결정됨

## Ⅲ. 종류 및 비교

| 판단 기준 | 전가상화 | 반가상화 | 컨테이너 |
|:---|:---|:---|:---|
| OS 수정 필요 | 없음 | 있음 또는 전용 드라이버 필요 | 없음 |
| 격리 단위 | VM 단위 | VM 단위 | 프로세스 단위 |
| 실행 경로 | 장치 에뮬레이션과 VM exit 경유 | hypercall·전용 드라이버 경유 | 호스트 커널 시스템 호출 사용 |
| 커널 구조 | 게스트별 독립 커널 | 게스트별 독립 커널 | 호스트 커널 공유 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Hypervisor Layer | 전가상화와 반가상화에서 가상 하드웨어와 자원 격리를 제공하는 중심 계층임 |
| Guest OS or Runtime | VM은 독립 커널을 포함하고 컨테이너는 런타임과 네임스페이스로 실행 환경을 구성함 |
| Virtual Device Interface | 반가상화에서는 hypercall이나 paravirtual driver가 성능 차이를 만드는 핵심 인터페이스임 |
| Isolation Boundary | VM은 하드웨어 수준 격리를, 컨테이너는 커널 기능 기반 격리를 제공해 보안 모델을 구분함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 자원 추상화    | --> | 실행 환경 생성 | --> | 격리 정책 적용 | --> | 서비스 실행    |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **자원 추상화**: 하드웨어 또는 커널 자원을 논리 실행 환경으로 나눔
2. **실행 환경 생성**: VM이나 컨테이너 인스턴스를 생성함
3. **격리 정책 적용**: 메모리와 CPU와 네트워크와 파일 시스템 경계를 설정함
4. **서비스 실행**: 애플리케이션을 배포하고 성능과 보안 상태를 운영함

## Ⅵ. 실무 적용 및 유의점

1. 멀티테넌트나 규제형 서비스는 VM 중심 격리를 쓰되 전가상화 오버헤드와 반가상화 호환성 부담을 함께 봐야 하므로 표준 paravirtual driver와 자원 한도를 적용하고 I/O latency와 driver compatibility rate와 isolation incident count로 확인함
2. 내부 플랫폼과 대량 배포 서비스는 컨테이너를 쓰되 커널 공유로 보안 경계가 약해질 수 있으므로 런타임 하드닝과 민감 워크로드 분리를 적용하고 startup time과 density per host와 runtime hardening compliance로 확인함

## Ⅶ. 결론

전가상화와 반가상화와 컨테이너의 선택은 가볍고 무거움의 차이가 아니라 격리 경계와 성능 경로와 운영 자동화 요구를 어떻게 맞출지의 문제임.
