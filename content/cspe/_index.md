# CSPE 키워드 노트 (공식 8개 대영역)

> **키워드 공부는 이 페이지에서 시작한다.**
> `exam/cs/`는 전략·기출·답안 작성법만 보는 보조 문서이고, 실제 암기와 답안 템플릿은 아래 8개 대영역 노트가 기준이다.

컴퓨터시스템응용기술사 출제기준(2023~2026) 8개 대영역 기준으로, 실제 기출(120~138회)과 최신 전망에서 추출한 키워드를 정리합니다. 각 키워드는 **암기용(개념 완전 이해)** 과 **답안용(시험 답안 템플릿)** 두 블록으로 구성됩니다.

## 작성 현황

`keywords/` 페이지는 **작성 예정 키워드 워크리스트**입니다. 실제 암기용+답안용 템플릿은 각 영역 폴더 아래의 `001-...`, `002-...` 같은 개별 페이지에서 확인합니다.

| 대영역 | 워크리스트 | 작성된 개별 노트 | 상태 |
|:---|:---:|:---:|:---|
| 컴퓨터 기초이론 | 80개 | 0개 | 워크리스트만 있음 |
| 하드웨어 시스템 | 110개 | 1개 | `221_pipeline_hazards` 작성 |
| 시스템·응용 소프트웨어 | 320개 | 0개 | 워크리스트만 있음 |
