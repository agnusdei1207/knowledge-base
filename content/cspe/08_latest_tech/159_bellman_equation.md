# 📖 【암기용】 개념 완전 이해

> 목적: Bellman Equation을 처음 봐도 완벽히 이해하게 만든다.

## 한눈에
- **개요**: 상태 가치가 즉시 보상과 다음 상태 가치의 할인합으로 표현된다는 강화학습의 재귀 방정식
- **왜 필요한가**: 장기 보상을 한 번에 계산하기 어렵기 때문에 현재 보상과 미래 가치로 나누어 최적 정책을 구함.
- **핵심 직관**: "지금 얻는 점수 + 다음 위치에서 기대되는 점수"가 현재 선택의 가치임.

## 깊이 이해
- **배경·문제의식**: 순차 의사결정은 미래 보상이 누적된다. Bellman Equation은 전체 문제를 작은 하위 문제로 쪼개 동적계획법처럼 풀게 해줌.
- **작동 원리**: V(s)=max_a [R(s,a)+γΣP(s'|s,a)V(s')] 형태로 상태 가치를 정의하고 반복 업데이트로 최적 가치와 정책을 찾음.
- **비유**: 목적지까지 최단 경로를 찾을 때 현재 도로 비용과 다음 교차로부터의 최단 거리 합을 비교하는 방식임.
- **구체 예시**: 그리드월드에서 각 칸의 V값을 보상과 인접 칸 가치로 반복 갱신하면 목표 지점으로 가는 최적 이동 정책이 도출됨.
- **흔한 오해·주의점**: Bellman Equation은 모델 P를 알고 있을 때 직관적이며, P를 모르면 Q-learning처럼 경험 샘플로 근사함.

## 연결 개념
- MDP — Bellman Equation이 정의되는 순차 의사결정 모델
- Value Iteration — Bellman 최적 방정식을 반복 적용하는 방법
- Q-learning — 모델 없이 Bellman backup을 샘플로 근사하는 알고리즘

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: Bellman Equation은 현재 가치가 즉시 보상과 할인된 미래 가치의 합이라는 재귀식임.
> 2. **가치**: MDP의 최적 가치함수와 정책을 동적계획·강화학습 알고리즘으로 계산하게 함.
> 3. **판단 포인트**: 전이모델 존재 여부에 따라 value iteration, policy iteration, Q-learning을 선택함.

## Ⅰ. 개요 및 필요성

- 개요: 가치함수 재귀 방정식
- 배경: 순차 의사결정은 현재 행동이 즉시 보상뿐 아니라 미래 상태의 가치에도 영향을 준다.
- 필요성: value iteration, Q-learning, dynamic programming에서 즉시 보상과 할인 미래 가치를 분해해 최적 정책을 계산한다.

## Ⅱ. 구조 및 구성요소

```text
State s + Action a -> Reward R(s,a)
  + Discount γ × Expected Future Value V(s') -> Value V(s)
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| V(s) | 상태 가치 | 상태 s에서 기대 누적 보상 |
| R(s,a) | 즉시 보상 | 행동 결과의 단기 보상 |
| γ | 할인율 | 미래 보상 가중치, 0~1 |
| $P(s' \mid s,a)$ | 전이확률 | 다음 상태 기대값 계산 |

> 요약: Bellman Equation은 상태 가치를 즉시 보상과 다음 상태 가치의 할인 기대값으로 표현함.

## Ⅲ. 동작원리 및 흐름도

```text
가치 초기화 -> 각 상태의 행동별 보상+미래가치 계산
  -> 최대값으로 V 갱신 -> 수렴 반복 -> 최적 정책 추출
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 모든 상태 가치 V 초기화 | 초기값 0 또는 휴리스틱 |
| 2 | 행동별 R+γV(s') 계산 | Bellman error 측정 |
| 3 | V(s)를 최대 기대값으로 갱신 | error <1e-3 수렴 |
| 4 | argmax 행동으로 정책 도출 | baseline 대비 보상 개선 |

> 요약: Bellman backup을 반복해 상태 가치를 수렴시키고 가장 가치가 높은 행동을 정책으로 선택함.

## Ⅳ. 특징

| 구분 | Bellman Expectation | Bellman Optimality | 판단 포인트 |
|:---|:---|:---|:---|
| 목적 | 주어진 정책 평가 | 최적 정책 계산 | 평가 vs 최적화 |
| 연산 | 정책 평균 | 행동 max | optimal control |
| 사용 | policy evaluation | value iteration, Q-learning | 알고리즘 선택 |
| 한계 | 상태공간 크면 비용 증가 | 함수근사 필요 | DQN·approximation 적용 |

> 요약: Bellman Equation은 정책 평가와 최적화 모두의 기반이며, 큰 상태공간은 함수근사로 확장함.

## Ⅴ. 실무 적용 및 결론

**적용 방안 3개:**
1. 스케줄링 최적화: 상태별 비용·지연 보상으로 Bellman backup을 적용해 정책 후보 생성
2. 모델 기반 RL: 전이확률이 있는 시뮬레이터에서 value iteration으로 baseline 정책 계산
3. 모델 프리 RL: 전이를 모르면 Q-learning/DQN으로 샘플 기반 Bellman target 학습

**결론 (2줄):**
- 기술사 판단: MDP 전이모델을 알면 Bellman 기반 DP, 모르면 샘플 기반 Q-learning 계열 적용
- 향후 방향: 딥러닝 함수근사와 결합해 고차원 상태의 가치함수 학습으로 확장
