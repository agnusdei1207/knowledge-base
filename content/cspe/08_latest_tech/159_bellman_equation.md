## 미리 알고가기

- 벨만 방정식은 현재 가치가 즉시 보상과 다음 상태 가치의 합으로 분해된다는 재귀 관계임
- 가치 함수 $V(s)$와 행동가치 함수 $Q(s,a)$ 모두 벨만 관계를 가짐
- 기대 방정식과 최적 방정식을 구분해야 RL 알고리즘 이해가 쉬움

## Ⅰ. 개요

- **정의/개념**: 벨만 방정식은 현재 상태의 가치가 즉시 보상과 다음 상태 가치의 할인된 기댓값으로 표현된다는 최적성 원리를 수식화한 재귀 방정식으로, 가치 평가와 정책 최적화의 핵심 기반임
- **배경/필요성**: 강화학습은 미래 전체 보상을 바로 계산하기 어렵기 때문에, 이를 한 단계 전이 관계로 쪼개어 현재 가치로 환산하는 수학적 기준이 필요함

## Ⅱ. 특징

- 장기 반환값 문제를 1-step 재귀 문제로 분해함
- 정책 평가와 최적 정책 탐색을 같은 틀 안에서 다룰 수 있음
- TD learning과 dynamic programming과 Q-learning의 근본식 역할을 함
- 대규모 상태 공간에서는 정확한 해보다 근사 계산과 샘플 기반 업데이트가 필요함

## Ⅲ. 종류 및 비교

| 판단 기준 | Bellman Expectation | Bellman Optimality | Q-learning Target |
|:---|:---|:---|:---|
| 핵심 목적 | 현재 정책 평가 | 최적 정책 탐색 | 샘플 기반 근사 |
| 대표 식 | $V^\pi(s)=\sum_a \pi(a|s)\sum_{s'}P(s'|s,a)[R+\gamma V^\pi(s')]$ | $V^*(s)=\max_a \sum_{s'}P(s'|s,a)[R+\gamma V^*(s')]$ | $Q \leftarrow r+\gamma \max_{a'}Q(s',a')$ |
| 환경 모델 필요성 | 높음 | 높음 | 낮음 |
| 대표 활용 | 정책 평가 | 가치 반복 | DQN, Q-learning |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Immediate Reward | 현재 행동 직후 얻는 보상으로 가치 계산의 시작점이 됨 |
| Transition Expectation | 다음 상태로 갈 확률과 이후 가치의 기대치를 계산해 미래 영향을 반영함 |
| Discount Factor $\gamma$ | 미래 보상의 현재 가치를 조절해 단기와 장기 균형을 맞춤 |
| Value, Q Function | 상태 가치와 행동 가치를 재귀적으로 연결해 정책 평가와 제어 문제를 풀게 함 |

```text
+-------------------+      +-------------------+      +-------------------+
| Current State     | ---> | Reward + gamma *  | ---> | Next State Value  |
+-------------------+      | Future Estimate   |      +-------------------+
                           +-------------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 현재 상태 평가   | --> | 즉시 보상 반영  | --> | 미래 가치 추정  | --> | 가치 함수 갱신  |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **현재 상태 평가**: 계산 대상 상태나 상태-행동 쌍을 정함
2. **즉시 보상 반영**: 현재 전이에서 받은 보상을 더함
3. **미래 가치 추정**: 다음 상태 가치의 기댓값이나 최댓값을 계산함
4. **가치 함수 갱신**: 재귀식에 따라 가치 함수를 업데이트함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 상태 공간이 커지면 정확한 전이확률과 가치 함수를 모두 계산하는 방식은 현실적으로 불가능해질 수 있음
   - 해결방안: function approximation과 TD learning을 적용하고 Bellman error와 convergence speed로 검증함
2. 문제: 부트스트래핑 업데이트는 추정값 위에 다시 추정값을 얹기 때문에 함수 근사와 결합될 때 학습 불안정성이 커질 수 있음
   - 해결방안: target network와 experience replay를 적용하고 loss variance와 training stability로 검증함
3. 문제: 희소 보상 환경에서는 벨만 업데이트가 실제로 전파되기까지 시간이 오래 걸려 학습 효율이 매우 낮아질 수 있음
   - 해결방안: reward shaping과 curriculum learning을 적용하고 sample efficiency와 success rate로 검증함

## Ⅶ. 적용 사례

- 배차 최적화가 현재 수익과 미래 지역 수요를 함께 반영하도록 벨만 관계를 적용하며 확인 지표는 average return과 idle time임
- 게임 에이전트가 상태 가치를 반복 갱신해 승률을 높이도록 벨만 방정식을 활용하며 확인 지표는 win rate와 Bellman error임
- 광고 추천이 즉시 클릭보다 장기 구매 가치를 반영하도록 벨만 업데이트를 운영하며 확인 지표는 long-term ROAS와 conversion rate임

## Ⅷ. 결론

벨만 방정식은 미래 보상을 현재 가치로 접어 넣는 강화학습의 핵심 재귀식이므로, 대규모 환경에서는 이를 얼마나 안정적으로 근사하느냐가 알고리즘 성능을 좌우함.
