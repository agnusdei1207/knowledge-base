## 미리 알고가기

- 합성 데이터 ($Synthetic$ $Data$): 물리적인 실제 현장에서 채집 및 관측한 정보가 아닌, 생성 인공지능 모델(Generative Models)이나 컴퓨터 그래픽스 시뮬레이터를 활용해 인위적으로 위조 합성해 낸 학습 및 평가용 데이터셋임
- 모조 데이터 ($Dummy$ $Data$): 데이터 구조의 규칙(스키마)만을 모사하여 빈칸을 임의로 채워 넣은 단순 비실행용 테스트 데이터셋임
- 자가 훈련 성능 붕괴 ($Model$ $Autophagy$ $Disorder$, MAD): 모델이 자신이 만든 합성 데이터만 먹고 재학습하는 루프를 반복하다가, 점차 다양성을 잃어버리고 최종적으로 지능 자체가 붕괴해 바보가 되는 자가포식 현상임
- 실제 고정 기준셋 ($Anchor$ $Set$): 합성 데이터의 왜곡도를 모니터링하기 위해, 절대로 오염시키지 않고 격리 보존하는 $100\%$ 순수 물리 실제 데이터의 기준선 묶음임

## Ⅰ. 개요

- **정의/개념**: Synthetic Data는 데이터 부족 문제와 사생활 침해 규제를 극복하기 위해, 생성 모델(LLM, Diffusion 등)의 수학적 확률 분포와 규칙 시뮬레이션을 동원하여 실제 관측치와 완벽히 유사한 통계적 속성을 지니도록 인공 합성해 낸 기계 학습 전용 데이터임
- **배경/필요성**: 현대 딥러닝은 엄청난 인터넷 텍스트를 삼키며 "데이터 만리장성(Data Wall)"이라는 데이터 고갈 한계점에 직면하였고, 의료, 금융 등 기밀 정보 전송 규제를 우회할 탈출구로 급부상함

## Ⅱ. 특징

- 물리적 취득이 원천 불가한 극단적 악천후 자율주행 시나리오, 희귀 뇌종양 의료 영상 등 코너 케이스(Corner Cases)를 가상으로 무한 복사 생성함
- 개인식별정보($PII$)가 원천 결여되어 있어 유럽 GDPR 등 개인정보보호 컴플라이언스 심의를 프라이패스로 완전 통과함
- 사람이 손수 라벨링 및 정제하는 비용을 $99\%$ 소거하여 인프라 훈련 및 R&D 효율성을 비약적으로 팽창시킴

## Ⅲ. 종류 및 비교

| 판단 기준 | 실제 원천 데이터 (Real Data) | 합성 데이터 (Synthetic Data) | 증강 데이터 (Augmented Data) |
|:---|:---|:---|:---|
| **생성 메커니즘** | 물리적 환경 측정, 사람의 실관측 | 수학적 생성 모델(LLM 등), 물리 시뮬레이션 | 기존 실제 데이터를 기하학적으로 변형(Crop, Noise 등) |
| **비용 및 구축속도** | 높음 (취득 기간 길고 단가 비쌈) | 매우 낮음 (가속기 연산 비례 즉시 생산) | 매우 낮음 |
| **개인정보 유출력** | 존재함 (가명처리 오버헤드 발생) | 원천 없음 (가상으로 창조된 속성) | 보통 (원본 정보 일부 잔존) |
| **데이터 결함 리스크** | 기형적 편향, 노이즈 | 그럴싸한 통계적 왜곡(환각), MAD 리스크 | 과적합 우려 |

> 요약: Real Data는 지능의 유일한 나침반이고, Synthetic Data는 가상 공간에서 무한 재생산 가능한 대체 연료이며, Augmented Data는 기존 가중치의 구성을 늘리는 비틀기 요령임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 생성 모델 파이프라인 | 합성 데이터를 연산 제조하는 원천 가속 엔진(LLM, Diffusion 등)임 |
| 프롬프트 구조 가이드 | 특정 포맷과 업무 논리를 띠도록 AI의 행동을 통제하는 시나리오 지침서임 |
| 중복/유해 필터 | 생성 결과물 중 불량 팩트, 중복, 쓰레기 텍스트를 자동 소독하는 여과기임 |
| 앵커 셋 ($Anchor$ $Set$) | 합성 데이터 오염을 예방하기 위해 기준선으로 삼는 $100\%$ 실제 데이터셋임 |

```text
[ Synthetic Data (합성 데이터) 수급 및 앵커 정제 아키텍처 ]
[ Generative LLM ] ───> Generate ───> [ Raw Synthetic Data ]
                                             │
                                             v (Noise Filter & Duplicate Check)
                                      [ Filtered Dataset ]
                                             │
                                             v (Mixed with 30% Real Anchor Set)
                                      [ Final Training Dataset ] ──> Train Model
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 생성 시나리오| --> | 생성기 가동  | --> | 중복/독성   | --> | 앵커 셋과   |
| 규칙 설계   |     | 대량 합성출력|     | 여과필터링  |     | 최적 비율혼합|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **스키마 정의** — 타깃 도메인의 특징 범주와 필수 포맷 규칙, 그리고 보호해야 할 개인정보 보호 스키마를 수립함
2. **합성 실행** — 자가 생성 룰(예: Self-Instruct) 프로토콜을 태워, 상위 모델을 통해 수백만 건의 대화문을 자동 생성 인출함
3. **노이즈 스크리닝** — 정규표현식 및 분류 가드레일 모델을 켜서 문법 파괴, 중복 아티팩트, 탈옥 명령 등을 자동 필터링함
4. **앵커 믹싱** — 골드 레퍼런스인 실제 고정 기준셋($Anchor$ $Set$)을 최소 $30\%$ 융합 믹싱하여 모델의 자가포식 붕괴를 예방함

## Ⅵ. 실무 적용 및 유의점

1. 실제 데이터 없이 합성 데이터만으로 세대를 거쳐 계속 학습(Recursive Training)시키면 모델의 표현력이 축소되며 바보가 되는 '자가 훈련 성능 붕괴($MAD$)'가 일어나므로, 반드시 훈련 루프 내에 오염되지 않은 실제 고정 기준셋($Anchor$ $Set$) 비중을 상시 방어하고 강건성 점수($Robustness$ $Score$)를 검증해야 함
2. 합성 데이터가 그럴싸한 수학적 그럴듯함만 지니고 실제 물리 현상의 팩트(Fact) 정보가 일치하지 않는 '분포 이격($Distribution$ $Gap$)'이 발생할 수 있으므로, 배포 전 '실제 운영 데이터셋'으로 최종 기계적 회귀 테스트를 병행하고 현장 정확도 지표를 모니터링해야 함

## Ⅶ. Conclusion

- 합성 데이터는 현실 세계의 데이터 공급 고갈 장벽과 엄격한 프라이버시 법망을 동시에 우회하는 현대 지능 팽창의 핵심 엔진이며, 설계자는 무분별한 합성물 도배가 야기하는 모델의 자가포식 붕괴(MAD) 방지를 위한 실제 고정 기준셋 확보와 분포 이격 차단책을 사전에 완전 보증해야 함
