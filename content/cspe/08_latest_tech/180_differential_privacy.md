# 📖 【암기용】 개념 완전 이해

## 한눈에
- **정의**: 데이터 분석 결과나 AI 모델 학습 과정에 통계적으로 정밀하게 계산된 '노이즈(랜덤한 가짜 데이터)'를 살짝 섞어서, 모델의 전체적인 통계 성능은 유지하되 **"데이터셋 안에 특정 개인(홍길동)의 데이터가 포함되었는지 안 되었는지"**를 해커가 절대 알아맞히지 못하게 수학적으로 100% 보장하는 프라이버시 기술.
- **필요성**: 병원 통계에서 "A동네 암환자 평균 나이 50.5세"를 발표했는데, 이튿날 암에 걸린 홍길동이 이사 옴. 다시 통계를 내보니 "51.2세"가 됨. 해커가 두 통계의 '차이(Differential)'를 역산하면 홍길동의 정확한 나이와 암 발병 사실을 100% 알아냄. 단순 익명화(이름 지우기)로는 이런 차이 공격을 막을 수 없음. DP가 필요함.
- **핵심 직관**: 얼굴 모자이크 처리. 군중 사진에서 사람 얼굴 형태는 보이게 하되(통계적 유용성), 흐릿한 픽셀 노이즈를 씌워서 그 사람이 정확히 누구인지는(개인 식별) 절대 모르게 만드는 수학적 모자이크 처리.

## 깊이 이해
- **배경**: 넷플릭스가 영화 평점 데이터를 '이름 다 지우고(비식별화)' 공개했음. 그런데 해커가 그 데이터를 IMDB(영화 사이트)의 공개 리뷰 데이터와 대조해 특정 회원의 신원을 찾아냄. 이처럼 여러 데이터 결합을 통한 재식별 공격이 횡행하자, Apple과 Google 주도로 수학적으로 증명된 프라이버시 보호 기준(DP)이 상용화됨.
- **작동 원리 (엡실론 $\epsilon$ 통제)**:
  1. 홍길동이 있는 데이터셋(D1)과 홍길동을 뺀 데이터셋(D2)에 똑같이 "평균 연령 계산" 함수를 돌림.
  2. 시스템은 계산된 결과값에 라플라스(Laplace) 분포를 따르는 '난수 노이즈'를 더해서 출력함.
  3. 결과적으로 D1에서 나온 값인지 D2에서 나온 값인지 수학적으로 구분이 안 되게 뭉뚱그려짐.
  4. 이때 노이즈의 강도를 조절하는 손잡이가 바로 **프라이버시 예산(Privacy Budget), 엡실론($\epsilon$)**임.
  5. 엡실론이 **작으면(0.1)**: 노이즈 팍팍 섞음 $\rightarrow$ 보안 최고, 통계 데이터 쓰레기 됨 (유용성 떡락).
  6. 엡실론이 **크면(10.0)**: 노이즈 찔끔 섞음 $\rightarrow$ 보안 취약, 통계 데이터 정확.
- **구체 예시**: 아이폰 이모티콘 추천 AI (Local DP). 애플은 사람들이 어떤 이모티콘을 많이 쓰는지 수집하고 싶음. 내 폰에서 👍를 누르면 서버로 '👍'를 보내지 않고, 폰 자체에서 동전을 던져 앞면이 나오면 '👍', 뒷면이 나오면 무작위로 '💩'을 서버로 보냄(Randomized Response 노이즈 주입). 애플 서버는 수천만 개의 💩 섞인 데이터를 받지만, 확률 통계를 역산하면 전체 트렌드는 아주 정확하게 알아냄. 단, 내 폰이 진짜 👍를 눌렀는지는 애플도 모름.
- **흔한 오해/주의점**: "DP 적용하면 무적 아님?" $\rightarrow$ 아님. 해커가 통계 질문을 1만 번 계속 던져서 노이즈의 평균을 내버리면 원본 값을 알아낼 수 있음. 그래서 DP에는 '프라이버시 예산(Budget)' 개념이 있어서, 질문을 몇 번 이상 하면 시스템이 답변을 차단(예산 고갈)해야 함.

## 연결 개념
- **Privacy-Preserving AI (PPAI)**: 프라이버시를 지키는 AI의 큰 틀. DP는 여기서 가장 강력한 수학적 무기.
- **Federated Learning (연합학습)**: 연합학습 파이프라인에서 클라이언트가 서버로 파라미터를 보낼 때 DP 노이즈를 섞어서 보냄(FL + DP). 완벽한 콤보.
- **K-익명성 (K-Anonymity)**: 과거의 비식별화 기법. 나이/성별 같은 데이터를 뭉뚱그려 최소 K명이 동일한 값을 갖게 함. 하지만 넷플릭스 사태처럼 외부 데이터 결합 공격에 뚫림. DP가 그 상위 호환.

# 📝 【답안용】 시험 답안 템플릿
## 핵심 인사이트 (3줄 요약)
- **본질**: 데이터베이스에서 임의의 한 개인 데이터가 추가되거나 제거되더라도, 쿼리(분석) 결과의 통계적 확률 분포가 거의 변하지 않도록(Indistinguishable) 연산 과정에 무작위 노이즈를 주입하는 수학적으로 증명 가능한 프라이버시 보호 프레임워크.
- **가치**: 넷플릭스 챌린지 사태 등으로 한계가 드러난 기존 비식별화(K-Anonymity)의 데이터 결합 및 차분 공격 취약성을 극복하고, AI 딥러닝 모델의 훈련 데이터 역추론(Membership Inference Attack) 공격을 원천적으로 차단함.
- **판단 포인트**: DP 시스템 설계의 핵심은 프라이버시 보호 강도(Privacy)와 데이터의 통계적 유용성(Utility) 간의 상충 관계(Trade-off)를 제어하는 '프라이버시 예산($\epsilon$, Epsilon)'의 최적 파라미터 산정과 소진 관리(Accountancy)에 있음.

## Ⅰ. 개요 및 필요성
- **정의**: 두 인접한 데이터셋(D1, D2)에 대한 질의 결과(확률 분포)의 차이를 $\epsilon$ 이하로 통제하여, 결과만으로는 특정 개인의 데이터 포함 여부를 식별할 수 없도록 보장하는 암호·통계학적 기법. (2006년 Cynthia Dwork 고안).
- **배경**: AI의 성능은 학습 데이터의 질과 양에 비례하지만, 개인 정보가 포함된 원본 데이터를 그대로 딥러닝 모델(LLM 등)에 태울 경우 모델이 훈련 데이터를 그대로 외워서 출력하는 암기(Memorization) 문제가 발생.
- **필요성**: 통계 분석 결과나 머신러닝 파라미터를 공개할 때, 외부 지식(Background Knowledge)을 동원한 해커의 어떠한 역추론 공격에도 흔들리지 않는 최상위 방어선(Provable Guarantee) 제공.

## Ⅱ. 차등 프라이버시의 핵심 수학적 정의
- 알고리즘 $M$이, 단 한 명의 정보만 차이 나는 두 인접 데이터베이스 $D_1$과 $D_2$에 대하여 모든 가능한 결과 집합 $S$에 대해 다음 부등식을 만족할 때, $M$은 **$(\epsilon, \delta)$-Differential Privacy**를 보장한다고 한다.
  $$\Pr[\mathcal{M}(D_1) \in S] \le e^{\epsilon} \cdot \Pr[\mathcal{M}(D_2) \in S] + \delta$$
- **의미 해석**:
  - $\epsilon$ **(Epsilon, 프라이버시 예산)**: 두 확률의 차이의 허용 한계선. 값이 0에 가까울수록(엄격할수록) 보호가 강하고, 값이 커질수록 보호가 느슨해짐.
  - $\delta$ **(Delta, 오차 허용률)**: DP가 실패하여 정보가 유출될 매우 희박한 확률. (보통 데이터 수 N의 역수보다 훨씬 작게 설정).

## Ⅲ. 노이즈 주입 메커니즘 (Noise Mechanism)
데이터의 민감도(Sensitivity, 한 사람 데이터 변화로 인한 최대 출력 변화량)에 비례하여 노이즈를 주입.
| 메커니즘 | 적용 대상 데이터/알고리즘 | 특징 및 원리 |
|:---:|:---|:---|
| **라플라스 메커니즘**<br>(Laplace Mech.) | 수치형 연속 데이터 (예: 연봉 평균, 방문자 수) | 민감도(Sensitivity) $\Delta f$에 비례하고 예산 $\epsilon$에 반비례하는 라플라스 분포 난수 추출. |
| **가우시안 메커니즘**<br>(Gaussian Mech.) | 주로 딥러닝 파라미터 (Gradient 노이즈 주입) | 라플라스보다 꼬리가 얇아 다차원 벡터 분석 시 성능 하락이 덜함 (대신 $\delta$ 확률 양보). |
| **지수 메커니즘**<br>(Exponential Mech.) | 비수치형/범주형 데이터 (예: 가장 인기 있는 색상) | 출력 가능한 정답 목록 중 점수(가중치)가 높은 쪽에 확률적으로 편향된 노이즈 선택. |

## Ⅳ. 구현 아키텍처에 따른 DP의 2대 분류
노이즈를 중앙 서버에서 치느냐, 내 폰에서 치느냐.
1. **글로벌 차등 프라이버시 (Global/Central DP)**:
   - 클라이언트는 원본 데이터를 중앙 서버로 모두 보냄.
   - 신뢰할 수 있는 중앙 서버(Trusted Curator)가 통계 분석을 다 끝낸 후, **최종 결과 공개 직전에만 한 번** 노이즈를 섞음. (노이즈량이 적어 통계 품질 매우 높음).
2. **로컬 차등 프라이버시 (Local DP)**:
   - 중앙 서버조차 믿지 못하는 환경.
   - 사용자가 **내 스마트폰에서 원본 데이터에 미리 노이즈를 섞고(무작위화 응답)** 훼손된 데이터를 서버로 보냄. (서버는 쓰레기를 모아 대수의 법칙으로 통계 복원. Apple, Google 적용 방식).

## Ⅴ. 실무 적용 및 결론
- **판단 지표**: 프라이버시 예산(Privacy Budget, $\epsilon$) 소진 한도, 적용 모델의 Utility(정확도) 보존율, 딥러닝 DP-SGD 적용 시 Clipping Norm 최적화 타겟.
- **실무 설계**: 모바일 결제 플랫폼의 '딥러닝 기반 고객 소비 패턴 군집화 AI' 학습 시스템. 고객의 1:1 결제 내역 원본을 쓰면 규제 위반이므로 텐서플로우 프라이버시(TensorFlow Privacy)를 도입하여 DP-SGD 최적화 파이프라인 구축. 1) 학습 과정에서 클리핑(Gradient Clipping)을 적용해 특정 이상치 결제(10억 원짜리 보트 구매 등)가 가중치에 주는 영향을 강제로 깎아냄(Sensitivity 제한). 2) 클리핑된 그래디언트에 가우시안 노이즈(Gaussian Noise)를 더함. 3) 학습 epoch가 반복될 때마다 Moment Accountant로 예산($\epsilon$) 누적치를 철저히 계산. $\epsilon=3.0$에 도달하면 즉각 학습을 중단(Early Stopping)하도록 MLOps 설정. 원본 데이터 복원율 0% 증명 및 고품질 AI 상용화.
- **결론**: 차등 개인정보보호(DP)는 프라이버시를 모호한 법률 용어가 아닌 '수학의 언어'로 정량화한 혁명적 기술이다. AI가 창출하는 거대한 사회적 유용성을 포기하지 않으면서도, 개인의 삶의 궤적을 안전하게 숨겨주는 가장 이상적인 프라이버시-효용 타협(Trade-off)의 기준점이 될 것이다.

### 🔀 문제 유형별 목차 전환
- **Ⅱ·Ⅲ 강조 (개념/원리형)**: 무작위화 응답(Randomized Response) 기법을 통한 Local DP 구현 원리와 라플라스 메커니즘의 확률 밀도 함수 수식(Lap($\Delta f / \epsilon$)) 전개를 통한 $\epsilon$ 조절 효과.
- **Ⅴ·Ⅵ 강조 (실무/설계형)**: LLM(GPT)의 파인튜닝 시 RAG(검색 증강 생성)에 섞여 들어가는 민감 데이터를 보호하기 위해, 프라이버시 예산 관리를 통합한 DP-SGD(차등 프라이버시 확률적 경사 하강법) 분산 클러스터 아키텍처.
