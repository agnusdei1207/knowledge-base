## 미리 알고가기

- 저랭크 적응 ($LoRA$, Low-Rank Adaptation): 사전학습 완료된 거대 모델의 가중치 행렬을 동결시키고, 어텐션 선형 투사층 옆에 곱셈으로 구성된 두 개의 저차원 보정 행렬(A, B)을 수평 부착해 추가 훈련량만 저랭크 계산하는 기연 최적화 기법임
- 저랭크 행렬 ($Low-rank$): 크기가 각각 $d \times r$, $r \times k$ 인 두 개의 얇고 긴 행렬을 마주 곱하여, 원래 크기 $d \times k$ 인 대형 행렬의 변화량을 근사적으로 압축 표현하는 수학 구조임
- 차원 크기 ($Rank$, $r$): 저랭크 행렬을 구성하는 중간 압축 차원의 두께(보통 8, 16, 32, 64 등)로, 이 값이 클수록 정보 수용량은 넓어지나 학습 파라미터가 증가함
- 스케일링 계수 ($\alpha$, $Alpha$): 저랭크 행렬의 연산 결과에 곱하여 원본 가중치와의 혼합 비중을 조율해 주는 수학적 조정 계수임

## Ⅰ. 개요

- **정의/개념**: LoRA는 트랜스포머의 밀집 선형 가중치 변화량($\Delta W$)을 2차원의 가느다란 저랭크 행렬 쌍($A \times B$)으로 인수분해 근사 맵핑하여, 원래 $d \times k$ 크기의 매개변수는 완전히 동결시키고 저랭크 매개변수만 $10$만 분의 $1$ 수준의 비용으로 훈련시키는 혁신적인 PEFT 기법임
- **배경/필요성**: 기존 어댑터($Adapter$) 튜닝은 레이어 직렬 융합으로 인해 추론 시 병목($Latency$ $Spike$)이 생기고 전면 미세조정은 디스크 비용이 천문학적이었으므로, 학습은 가벼우며 추론 시에는 원본 가중치에 무손실 덧셈 병합($Merge$)이 가능한 기법이 요구되어 고안됨

## Ⅱ. 특징

- 가중치 변화 벡터 $\Delta W$의 고유 차원 수($Intrinsic$ $Dimension$)가 본래 차원보다 매우 낮다는 실측적 수학 가설에 근거하여 작동함
- 입력 데이터가 2개의 저차원 뼈대 행렬 $A$(가우시안 초기화)와 $B$($0$으로 초기화)를 차례로 뚫으며, 훈련 초기에는 원본과 $100\%$ 동일하게 기동함
- 어텐션 가중치 레이어의 쿼리($q$), 키($k$), 밸류($v$) 투사 행렬 단에 주로 이식되며, 지능 유실 없이 파일 저장 무게를 수십 MB 급으로 묶어버림

## Ⅲ. 종류 및 비교

| 판단 기준 | 전면 미세조정 (Full Fine-Tuning) | 어댑터 미세조정 (Adapter Tuning) | 저랭크 적응 (LoRA) |
|:---|:---|:---|:---|
| **물리적 이식 구조** | 레이어 구조 변환 없음 (통째 학습) | 트랜스포머 FFN 레이어 후단에 직렬 삽입 | 선형 레이어 병렬 통로로 $A, B$ 저랭크 우회 삽입 |
| **추론 속도 영향** | 0% (속도 동일) | 느려짐 (레이어 스택 증가로 지연 누적) | 0% (서빙 기동 시 원본 가중치에 행렬 덧셈 병합 처리) |
| **학습 가능한 가중치** | $100\%$ (전체 매개변수) | 약 $3 \sim 5\%$ 수준 | 극소수 ($0.01 \sim 0.1\%$ 수준) |
| **초기화 방식** | 기존 사전학습 값 계승 | 무작위 가중치 훈련 기동 | $A$는 가우시안, $B$는 $0$으로 초기화하여 시작점 보존 |

> 요약: Full FT는 뇌의 질량을 무겁게 카피하는 것이고, Adapter는 연산 통로를 길게 늘리는 땜질이며, LoRA는 옆길을 임시 개통했다가 최종 서빙 시 융합하는 우회 도로임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 동결 기반 가중치 | $W_0$로 표기되며, 파인튜닝 동안 일체의 그래디언트 변화를 차단한 원형 행렬임 |
| 저랭크 행렬 $A$ | $d \times r$ 크기의 축소 행렬로, 유입 토큰 벡터를 저차원 핵심 뼈대로 인코딩하는 가우시안 행렬임 |
| 저랭크 행렬 $B$ | $r \times k$ 크기의 팽창 행렬로, 저차원 벡터를 원래 차원 규모로 디코딩 및 복원하는 0 행렬임 |
| 융합 서빙 기구 | $W = W_0 + \frac{\alpha}{r} (A \times B)$ 공식에 근거하여, 실시간 추론 시 가중치를 완전 융합하는 합산기임 |

```text
[ LoRA (Low-Rank Adaptation) 수학적 연산 흐름 ]
Input (x) -------> [ Frozen Base Weight (W0) ] -------> Output (W0 * x)
           \                                              + (Weighted Sum)
            -----> [ Matrix A (d x r) ] -> [ Matrix B (r x k) ] * (α/r) -> (ΔW * x)
- 훈련 중에는 우회 경로만 그래디언트를 전파하여 가볍게 훈련함
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 선형 텐서   | --> | 우회 저랭크  | --> | 역전파 통해 | --> | 최종 가중치 |
| 동결 완료   |     | 행렬 A, B부착|     | A, B만 갱신 |     | 매트릭스합체|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **타깃 선정** — 타깃 신경망 내부의 선형 어텐션 계층(예: $W_q$, $W_v$)을 파싱하고, 가중치 전파 경로를 확인 고정함
2. **저랭크 세팅** — 보정 차원 크기($r = 8$ 또는 $16$)와 믹싱 계수($\alpha = 16$ 등)를 정의하고 2개의 저차원 보조 매트릭스를 측면 가설 배치함
3. **그래디언트 전이** — $W_0$를 관통하는 메인 연산 오차는 흘려보내고, 오직 어댑터의 $A, B$ 행렬 파라미터만 역전파 미세 조정 갱신함
4. **바이너리 합산** — 훈련이 끝나면 $\Delta W = A \times B$ 연산을 때려 원래의 가중치 $W_0$에 직접 가산하여 단일 서빙 파일로 컴파일 완료함

## Ⅵ. 실무 적용 및 유의점

1. 저차원 차원 크기($r$, Rank) 값을 가성비만 좇아 지나치게 낮게(예: $r=1$ 또는 $2$) 설정하면, 복잡한 사내 계약서 양식의 다단계 관계가 표현되지 못해 튜닝 실패를 보므로, 반드시 Rank 크기를 점진 스윕($Sweep$)하며 지능 보존 한계선 지표를 실측 검증해야 함
2. 다수 LoRA 어댑터를 병합하지 않고 서빙 시 동적으로 분리 로드하여 서빙하면, 멀티 테넌트 동접 가중 처리 중 '어댑터 캐시' 포화로 스위칭 랙이 유발되므로, 반드시 '온칩 메모리 캐싱 정책'을 수립하고 모듈간 스위칭 지연($Switch$ $Latency$) 스파이크를 감시해야 함

## Ⅶ. 결론

- LoRA는 텐서 대수학의 저차원 투사론을 적용해 미세조정의 물리적 비용과 추론 지연 문제를 완벽히 소거한 현대 인공지능 엔지니어링의 표준 스택이며, 설계자는 적응 영역의 난이도에 발맞춘 정교한 Rank 크기 선정과 멀티 테넌트 서빙 시의 동적 스위칭 메모리 격리 장치를 반드시 수립해야 함
