## 미리 알고가기

- 단계별 추론 ($CoT$): 최종 답을 구하기 전 의사결정의 중간 논리 전개 과정을 텍스트로 명시 출력하여 정답률을 올리는 기법임
- 자기 일관성 ($Self-Consistency$): 동일 질문에 복수의 서로 다른 CoT 경로를 병렬 생성하여 가장 많이 도출된 최빈 정답을 선택하는 투표 기법임
- 테스트 시점 연산 ($Test-time$ $Compute$): 추론($Inference$) 시점에 모델이 생각할 수 있도록 더 많은 연산 자원과 토큰 출력을 할당하는 패러다임임
- 제로샷 CoT: 예시 없이 단순 지문 끝에 "단계적으로 생각해보자($Let's$ $think$ $step$ $by$ $step$)" 지시를 얹어 추론을 유도하는 기법임

## Ⅰ. 개요

- **정의/개념**: Chain-of-Thought(CoT)는 대형 언어 모델이 고난도 논리 문제에 직면했을 때, 최종 정답을 곧장 도출하지 않고 중간 연산과 추론 단계를 순차적으로 생성하여 정답률을 극대화하고 사고 경로를 투명화하는 추론 엔지니어링 전략임
- **배경/필요성**: 트랜스포머의 다음 단어 예측($Next$ $Token$ $Prediction$) 구조는 문맥상의 모든 단어 가중치를 한 번에 처리하므로, 수학 계산이나 다단계 법률 조항 검토처럼 중간 임시 저장 결과가 누적되는 논리적 태스크에서 오류가 속출하여 이를 극복하고자 도입됨

## Ⅱ. 특징

- 문제 해결 과정을 작은 서브 태스크로 분해하고, 매 단계 생성해 낸 논리 텍스트를 다음 연산의 상황 맥락(컨텍스트 캐시)으로 자가 환류하여 연산의 깊이를 확보함
- 사람이 복잡한 사안을 메모장에 차근차근 적어 내려가며 생각하는 과정과 기하학적으로 일치하는 '외부 메모리 확장' 효과를 연출함
- 단순 상식 암기 질의에서는 성능 개선이 거의 없으나, 수학 연산, 공간 지능, 윤리 규정 대조 등 다단계 인지 능력이 필수적인 영역에서 압도적인 정확도 상승을 가져옴

## Ⅲ. 종류 및 비교

| 판단 기준 | 일반 프롬프팅 (Standard) | 체인 오브 소트 (CoT) | 트리 오브 소트 (ToT) |
|:---|:---|:---|:---|
| **논리 전개 방식** | 질문 $\rightarrow$ 정답 즉시 출력 | 질문 $\rightarrow$ 선형 추론 단계 $\rightarrow$ 정답 | 질문 $\rightarrow$ 복수 생각 탐색/역추적 $\rightarrow$ 정답 |
| **추론 경로 탐색** | 단일 패스 | 단일 패스 (선형) | 다중 트리 구조 (DFS, BFS 탐색) |
| **토큰 소모량** | 매우 낮음 | 중간 (추론 텍스트 길이 비례) | 극도로 높음 (중간 노드 평가) |
| **적합한 문제** | 사실 확인, 개체명 추출 | 수학 계산, 다단계 규정 적용 | 크로스워드 퍼즐, 장기 계획 수립 |

> 요약: 일반형은 즉시 대답에, CoT는 차분한 일직선 추론에, ToT는 대안 비교형 심층 탐색에 특화됨.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 과업 해체기 | 질문을 하위 질문으로 나누고 무엇을 순차적으로 판단해야 할지 골격을 세우는 논리 단계임 |
| 중간 논리 생성부 | 앞 단계에서 풀어진 수치나 진위 여부 결과를 텍스트로 보관해 두어 오차 누적을 차단하는 층임 |
| 일관성 검증기 | 단일 경로 CoT의 거짓 전제를 극복하기 위해 다중 경로의 답변 일치도를 평가하는 투표 모듈임 |
| 최종 정답 파서 | 수많은 생각의 실타래(생성 텍스트) 중 맨 마지막 최종 판정 결론만 수확하는 규격 장치임 |

```text
[ CoT 추론 파이프라인 구조 ]
Input -> [Task Decomposition] -> [Step 1: Compute A] -> [Step 2: Compare B] -> [Step 3: Conclude C] -> Output
- 매 단계 생성된 결과가 누적 컨텍스트로 작용해 다음 단계의 예측 성공률을 보장함
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 복합과업 입력| --> | 하위단계 해체| --> | 중간근거 생성| --> | 정합판정 도출|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **지시 주입** — "단계별로 생각하자"라는 문구를 프롬프트에 동반하여 모델이 즉시 대답을 회피하고 과정을 기술하도록 유도함
2. **논리 분해** — 질문의 문장을 구조화하여 무엇을 선차적으로 풀고 무엇과 결합해야 할지 논리의 순서를 스스로 세움
3. **순차 자가환류** — 1단계의 중간 계산(예: `12 * 5 = 60`)을 텍스트로 배출하고, 이를 컨텍스트로 삼아 2단계 비교(예: `60이 100보다 큰가?`)를 수행함
4. **결과 수렴** — 생각의 종착지에서 유도된 최종 답안 값만을 규정된 정형 형태(예: JSON)로 골라내어 하위 서비스로 파싱함

## Ⅵ. 실무 적용 및 유의점

1. 모든 일상적인 질의(예: "서울의 수도가 어디야?")에 CoT를 의무 적용하면 무의미한 생각 토큰이 과도하게 뿜어져 나와 추론 단가가 급증하므로, 질문의 난이도를 1차 판정하는 '난이도 라우터($Router$)'를 두어 복합 연산에만 CoT를 선택 우회시키고 평균 서빙 비용과 정확도 상승분 지표로 경제성을 맞춰야 함
2. 초반 추론 단계에서 계산 착오(예: `2+3=6`)가 일어나면 뒤의 추론 단계가 도미노처럼 망가져 설득력 있는 오답을 생성하므로, 하나의 질문에 5~10번 병렬 추론을 돌려 답안 분포를 종합하는 '자기 일관성($Self-Consistency$)' 기법을 필수 결합하고 예측 정확도 지표로 보정 효과를 검증해야 함

## Ⅶ. 결론

- Chain-of-Thought는 거대 신경망의 직관 연산에 논리적 숙고와 자가 검증의 시간축을 이식하는 고성능 추론 디자인이며, 설계자는 토큰 소모 비용의 통제를 위한 라우팅 기법과 추론 흐름의 자가 보정 기법을 결합하여 실용적인 지능 엔진을 완성해야 함
