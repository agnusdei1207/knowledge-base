## 미리 알고가기

- 접두어 튜닝 ($Prefix$ $Tuning$): 사전학습 완료된 거대 모델의 매개변수는 완전히 동결시키고, 트랜스포머 매 레이어의 $Key$, $Value$ 어텐션 전단에 학습 가능한 가상의 가상 프리픽스($Prefix$) 연속 벡터들을 끼워 넣어 모델 조향을 유도하는 PEFT 기법임
- 가상 토큰 ($Virtual$ $Tokens$): 실제 텍스트 단어가 아니며, 자연어 코퍼스 토큰화 과정도 거치지 않는 순수한 실수 연속 벡터 형태의 학습 가능한 매개변수 집합임
- 어텐션 접두어 삽입 ($Attention$ $Prefix$): 셀프 어텐션 연산 시 인입되는 원래의 키($Key$)와 밸류($Value$) 텐서 배열 좌측에, 가상 프리픽스 키/밸류 텐서를 강제 이어 붙여($Concatenation$) 연산 순서를 유도하는 삽입 기법임
- 프리픽스 프로젝션 ($Prefix$ $Projection$): 학습 수렴의 안정성 보장을 위해, 다층 퍼셉트론($MLP$)을 통해 가상 프리픽스 가중치를 키/밸류 차원으로 투영 사상하여 학습한 후, 훈련 종료 시 $MLP$만 떼어내는 학습 가속화 공식임

## Ⅰ. 개요

- **정의/개념**: Prefix Tuning은 자연어 프롬프트 텍스트를 인위적으로 매만지는 대신, 트랜스포머의 매 레이어 셀프 어텐션 연산의 키(Key) 및 밸류(Value) 행렬 좌측 전단에 학습 가능한 임의의 가상 프리픽스 토큰 벡터(Virtual Tokens)를 접착 연동하여 모델이 특정 타깃 태스크 행동을 취하도록 가이딩하는 PEFT 기법임
- **배경/필요성**: 기존 텍스트 기반 프롬프트 튜닝은 어휘 임베딩 층에만 영향을 주어 조향력이 너무 약했고, 입력 단어를 낭비하는 단점이 있어, 은닉 신경망 깊은 곳(Deep Attention)에서 가중치를 강력히 제어하고자 제안됨

## Ⅱ. 특징

- 기저 기반 모델의 신경망 매개변수를 전혀 손대지 않고 고유 보존하므로, 태스크별로 단지 수십만 파라미터 수준의 가상 프리픽스 가중치만 디스크 격리 저장함
- 자연어 단어를 일절 낭비하지 않는 연속 공간 벡터($Continuous$ $Vectors$)의 특성을 띄어, 텍스트 형태의 수동 튜닝 대비 조향 정밀도와 행동 교정력이 탁월함
- 셀프 어텐션 계산식 내부의 키/밸류 텐서 차원 크기가 물리적으로 늘어나므로, 매 디코드 사이클마다 추가적인 가상 토큰 연산 오버헤드를 수반함

## Ⅲ. 종류 및 비교

| 판단 기준 | 프롬프트 튜닝 (Prompt Tuning) | 접두어 튜닝 (Prefix Tuning) | 저랭크 적응 (LoRA) |
|:---|:---|:---|:---|
| **가상 벡터 삽입 위치** | 오직 1층 입력층의 자연어 임베딩 영역 | 트랜스포머 내부 매 레이어 어텐션 $K, V$ 전단 | 선형 가중치 매트릭스 내부 우회 통로 |
| **조향 및 제어 강도** | 낮음 (모델 깊이에 전달되며 지워짐) | 중간 ~ 높음 (모든 레이어 어텐션 제어) | 극도로 높음 (가중치 직접 보정 효과) |
| **물리적 가중치 병합** | 불필요 (텍스트 꼬리표 작동) | 불가능 (어텐션 텐서 강제 접착 방식) | 완벽함 (가중치 덧셈 병합으로 오버헤드 0) |
| **주요 한계점** | 긴 프롬프트 시 입력 용량 대폭 갉아먹음 | 추가 키/밸류 어텐션 연산 오버헤드 누적 | 가중치 병합 전까지는 어댑터 관리 오버헤드 수반 |

> 요약: Prompt Tuning은 1층 문앞에 가짜 단어를 놓는 약한 유도이고, Prefix Tuning은 방방곡곡의 어텐션 문지기에게 가짜 지침서를 쥐여주는 중간 제어이며, LoRA는 가중치 통로 자체를 찢어 병합하는 근본 설계임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 가상 프리픽스 토큰 | 자연어 어휘 사전에 존재하지 않고, 오직 연속적인 실수 값으로 채워진 조건 형성용 매개변수임 |
| 프리픽스 투영 $MLP$ | 훈련 도중의 심각한 그레디언트 폭사(Explosion)를 차단하기 위해 임시 탑재하는 투사 신경망임 |
| 동결 신경망 백본 | 가상 프리픽스로부터 유도되는 텐서 외에는 모든 행동 가중치가 완전 잠금된 백본망임 |
| 어텐션 바인더 | 어텐션 수식 $Softmax(\frac{QK^T}{\sqrt{d_k}})V$ 연산 시, $K$와 $V$ 행렬 왼쪽에 가상 텐서를 병합하는 바인더임 |

```text
[ Prefix Tuning (Deep Attention Prefix) 물리적 구조 ]
Key (K) Array:   [ Prefix Keys (Virtual) ] + [ Original Text Keys (Real) ]
Value (V) Array: [ Prefix Values (Virtual) ] + [ Original Text Values (Real) ]
- 어텐션 계산 시 가상 토큰 텐서를 좌측에 밀착 병합하여 가동시킴
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 가상 토큰   | --> | $MLP$ 투영 후| --> | 매 레이어   | --> | 백본 동결   |
| 텐서 초기화 |     | 차원 크기일치|     | 어텐션에 접착|     | 프리픽스학습|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **가상 노드 준비** — 학습 가능한 가상 토큰 길이(예: $Length=30$)를 세팅하고 임의의 실수 난수로 초기 매개변수를 난수 생성함
2. **안정성 투사** — 수렴 유도를 위해 임시 $MLP$ 블록을 켜서 가상 프리픽스 가중치를 어텐션 키/밸류 차원 규격과 정밀 동기화함
3. **어텐션 컨캐트** — 트랜스포머의 매 레이어를 파싱하고, 멀티 헤드 어텐션 가동 전단에 가상 키/밸류 프리픽스 텐서를 동적 접착($Concat$)함
4. **역전파 최적화** — 원본 뇌세포 가중치는 얼리고, 프리픽스 파라미터만 도메인 정답 대조로 업데이트한 뒤, 훈련 종료 시 $MLP$를 탈거함

## Ⅵ. 실무 적용 및 유의점

1. 가상 프리픽스 토큰의 길이를 과도하게 설정하면(예: $Length > 100$), 트랜스포머 고유의 입력 컨텍스트 윈도우 마진(Context Window)을 대폭 침범해 실제 유입 질문을 실을 공간이 좁아지므로, 반드시 '지연 제한 범위' 내에서 최적의 프리픽스 길이 한계 스펙을 검증해야 함
2. 서빙 기동 시 프리픽스 토큰들의 연산이 매 어텐션 층마다 추가 계산량을 유발하여 p95 지연 시간($Latency$)이 늘어날 수 있으므로, 실시간 대접점 상담 챗봇 시나리오에서는 'LoRA 기반의 가중치 병합 배포'와 응답 시간을 벤치마킹 대조 분석해야 함

## Ⅶ. 결론

- Prefix Tuning은 텍스트 유실 없는 완벽한 연속 공간 유도로 모델의 행동 지침을 조향하는 고성능 깊은 어텐션 제어의 뼈대이며, 설계자는 가상 토큰 할당에 따른 컨텍스트 마진 침해 및 매 레이어 추가 계산에 의한 런타임 지연 오버헤드를 대조 분석하여 배포 타당성을 확보해야 함
