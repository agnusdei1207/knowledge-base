## 미리 알고가기

- 양자화 저랭크 적응 ($QLoRA$, Quantized Low-Rank Adaptation): 기저 기반 모델을 일반 $4$-bit가 아닌 특화된 $4$-bit 정규 플로트(NF4) 포맷으로 압축 박아놓고, 그 위에 고정밀 $16$-bit LoRA 어댑터를 병렬 부착하여 학습 메모리를 극한으로 축소하는 미세조정 기법임
- $4$비트 노멀 플로트 ($NF4$, NormalFloat4): 정규분포를 따르는 신경망 가중치 값의 통계적 특성에 부합하도록 정보 용량을 정보 이론적으로 균등 할당 설계한 최적의 4비트 부동소수점 포맷임
- 이중 양자화 ($Double$ $Quantization$): 가중치 양자화 시 생성되는 부가적인 메타데이터인 스케일($Scale$) 값마저 추가로 $8$-bit 양자화하여, 블록당 메모리 점유량을 추가 절감하는 고도화 압축임
- 페이지드 옵티마이저 ($Paged$ $Optimizer$): 가동 훈련 중 순간적인 그래디언트 활성 텐서 폭증으로 GPU VRAM이 고갈(OOM)될 때, CPU 시스템 메모리 영역으로 물리 페이징 스왑하여 크래시를 방지하는 메모리 안전 기구임

## Ⅰ. 개요

- **정의/개념**: QLoRA는 대형 언어 모델의 가중치를 이론상 최적 정보 밀도를 갖는 NF4(NormalFloat 4-bit) 규격으로 양자화하여 동결시키고, 이중 양자화(Double Quantization)와 페이지드 옵티마이저(Paged Optimizer) 가속 메모리 기술을 연동한 뒤, $16$비트 고정밀 LoRA 어댑터만 우회 학습시키는 극한의 메모리 절감형 PEFT 기법임
- **배경/필요성**: 기존 LoRA조차 백본 자체를 FP16 실수로 메모리에 올려두어 최소 수십 GB급 VRAM 장비가 요구되는 등 비용 병목이 여전하자, 단일 고성능 그래픽카드 1장(예: RTX 4090 등)만으로 수백억 파라미터 모델 훈련을 정복하고자 개발됨

## Ⅱ. 특징

- 기저 기반 모델의 메모리 점유량을 극적으로 하락시키는 $NF4$ 포맷을 도입하여, FP16 대비 VRAM 소모량을 약 $75\%$ 이상 추가 삭감함
- 양자화 변환으로 생겨난 개별 스케일 계수(Scale Factor)조차 다시 8비트 정수로 재압축하는 이중 양자화 기법으로, 매개변수당 약 $0.37$비트의 VRAM을 추가 소거함
- 역전파 계산 시 활성 상태 메모리가 튀는 순간의 CPU 스왑 아웃(Paged Optimizer) 기술을 탑재해 훈련 도중 OOM 크래시가 완벽 방어됨

## Ⅲ. 종류 및 비교

| 판단 기준 | 전면 미세조정 (Full Fine-Tuning) | 저랭크 적응 (LoRA) | 양자화 저랭크 적응 (QLoRA) |
|:---|:---|:---|:---|
| **기저 백본 포맷** | $FP16$ / $FP32$ 부동소수점 유지 | $FP16$ / $FP32$ 부동소수점 유지 | $NF4$ (4-bit Normal Float 최적화 포맷) |
| **VRAM 절감 폭** | 없음 (기준) | 약 $50 \sim 70\%$ 절감 (가중치 동결 효과) | 약 $85 \sim 90\%$ 극단 절감 ($NF4$ + 이중양자화) |
| **학습용 최소 장비** | 다중 GPU 노드 분산 필수 | 단일 고가 서버급 GPU 필수 | 일반 소비자용 고성능 GPU 1장으로 기동 가능 |
| **순간 메모리 안전성** | 낮음 (배치 팽창 시 크래시 빈발) | 보통 | 매우 높음 ($Paged$ $Optimizer$ 하드웨어 스왑 방어) |

> 요약: Full FT는 대형 훈련 기지용 인프라가 필수적이고, LoRA는 일반 기업의 가성비 미세조정에, QLoRA는 극도의 예산 제약 상황에서 단일 그래픽카드로 초대형 모델을 개조하는 생존형 튜닝에 특화됨.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| $NF4$ 백본 매트릭스 | 가중치의 통계 분포인 제로 평균 정규 분포 정보량에 입각하여 4비트로 컴팩트화한 텐서임 |
| 이중 양자화 모듈 | 1차 양자화 스케일 상수를 다시 8비트로 재압축하여 상수 메타데이터의 누수를 격리하는 모듈임 |
| 페이지드 가속기 | CUDA 메모리 결함을 감지해 CPU 메모리 물리 스왑 영역을 가동하는 가속 런타임 제어기임 |
| $FP16$ LoRA 어댑터 | NF4 백본과 병렬 동작하여 역양자화된 출력 오차를 정교하게 수렴하는 실질 학습부임 |

```text
[ QLoRA (Quantized LoRA) 핵심 메모리 방어선 구조 ]
[ NF4 Quantized Base Model ] ---> (VRAM 용량 75% 1차 삭감)
[ Double Quantization ]      ---> (양자화 스케일 메타데이터 2차 압축)
[ Paged Optimizer ]          ---> (Peak VRAM 도과 시 CPU System Memory Swap으로 OOM 차단)
- 이 3단계 메모리 차단책을 통해, 초저가 단일 GPU에서 70B 모델 파인튜닝을 완수함
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 기반 백본   | --> | 이중 양자화  | --> | 역전파 중   | --> | 학습 어댑터 |
| $NF4$ 변환  |     | 스케일 압축  |     | 가상페이징  |     | 분리 추출/merged|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **NF4 사상** — 기반 모델 가중치 텐서의 정규분포 분위수를 계산하여 정보 손실을 최소화하는 NF4 4비트로 정밀 다운 맵핑함
2. **이중 스케일링** — 블록 단위 스케일 팩터들을 추출해 $8$-bit 양자화하고, 32비트 부유 상수가 차지하던 잔여 공간을 소거함
3. **가상 페이징 가동** — 페이지드 아웃(Paged Out) 환경을 세팅하고 가중치 계산 도중 VRAM 한계 봉착 시 CPU 램으로 주소 테이블을 분할함
4. **어댑터 수렴** — 가중치는 4비트로 얼려둔 채 $FP16$ LoRA 행렬만 훈련시켜, 결과 어댑터 수렴 파일(SafeTensors)만 단독 디스크 추출함

## Ⅵ. 실무 적용 및 유의점

1. $NF4$ 양자화 오차와 LoRA 저랭크(Rank) 표현력 축소가 동시에 중첩 작용하여 복잡한 다국어 논리 번역에서 미묘한 정밀도 품질 저하가 생길 수 있으므로, 반드시 '중요 레이어(Attention FFN)'의 LoRA 타깃 지정을 확대하고, 최종 도메인 검증 지표로 정확도를 크로스 검증해야 함
2. 페이지드 옵티마이저 작동 시 VRAM의 활성 텐서가 CPU 메모리망으로 스왑될 때마다 대역폭 병목으로 인해 학습 속도가 수 배 이상 길어지는 현상이 나타나므로, 가능한 배치 크기를 줄여 CPU 스왑 발생 빈도($Paged$ $Swap$ $Rate$)를 최소화하는 방향으로 최적화해야 함

## Ⅶ. 결론

- QLoRA는 초대형 지능 모델 튜닝의 하드웨어 진입 장벽을 대수학적 매핑과 가상 메모리 혁신으로 완전히 허물어뜨린 기술 민주화의 주역이며, 설계자는 양자화 오차 누적에 따른 최종 품질 하락 감시와 가상 페이징 발생에 따른 학습 시간 지연 스파이크를 조화롭게 제어해야 함
