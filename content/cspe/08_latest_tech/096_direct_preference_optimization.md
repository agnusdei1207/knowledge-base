## 미리 알고가기

- 직접 선호 최적화 ($DPO$, Direct Preference Optimization): 복잡한 강화학습(PPO)의 보상 모델($RM$) 생성 단계를 수학적 목적 함수 변환을 통해 우회 소거하고, 선호/비선호 응답 데이터쌍으로 모델을 다이렉트 훈련시키는 고성능 정렬 기법임
- 참조 모델 ($Reference$ $Model$): 정렬 학습 중인 정책 모델(Policy)이 원래 SFT 상태의 연산 분포에서 멀어져 지능이 붕괴되는 것을 방지하기 위해 가이드라인으로 활용하는 동결 백본 모델임
- 베타 계수 ($\beta$, $Beta$): DPO 손실 함수 내에서, 정책 모델과 참조 모델 간의 로그 확률 거리 비율(KL 발산 강도)을 조율하여 정렬의 유연성을 규제하는 가중 하이퍼파라미터임
- 브래들리-테리 ($Bradley-Terry$) 모델: 여러 선택지 쌍 중 하나가 다른 것보다 선호될 확률을 선호 점수 차이의 로지스틱 함수로 정의하는 고전 확률 모델임

## Ⅰ. 개요

- **정의/개념**: DPO는 인간 또는 AI가 판정한 선호/비선호 답변 쌍($y_w$, $y_l$)을 활용하여, 정책 모델의 우수 응답 생성 확률은 높이고 불량 응답 확률은 떨어뜨리도록, 닫힌 형식(Closed-form)의 수학적 목적 함수로 정책 가중치를 직접 갱신하는 혁신적인 정렬($Alignment$) 기법임
- **배경/필요성**: 기존 RLHF(PPO) 방식은 학습 시 정책, 참조, 보상, 가치 4개 모델을 GPU VRAM에 동시 구동해야 해 메모리 병목이 극심하고 수렴 안정성이 낮았는데, 이를 SFT처럼 단순하게 1단계 지도 학습으로 혁신하고자 창안됨

## Ⅱ. 특징

- 강화학습 특유의 불안정한 행위자-비판자($Actor-Critic$) 아키텍처와 PPO 매개변수 튜닝의 난해성을 $100\%$ 걷어내어, 일반 SFT 수준의 학습 가독성과 수렴 안정성을 획득함
- 브래들리-테리 확률 모델을 응용하여, 보상 모델의 내재 식을 정책 모델의 확률 비율 관계로 수학적으로 영리하게 치환 매핑함
- 실서빙 기동 시 참조 모델(Reference)은 완전 격리 탈거하고 정렬 완료된 정책 모델 단독 구동하므로, 추론 시에는 자원 낭비가 전혀 없음

## Ⅲ. 종류 및 비교

| 판단 기준 | 지도 미세조정 (SFT) | 인간 피드백 강화학습 (RLHF) | 직접 선호 최적화 (DPO) |
|:---|:---|:---|:---|
| **보상 예측 모델** | 없음 | 필수 (인간의 선호를 점수화하는 별도 모델) | 없음 (수학적으로 정책 모델 자체가 RM을 대변) |
| **강화학습 알고리즘** | 없음 | 필수 ($PPO$ 알고리즘 적용) | 없음 (단일 분류기 로스 최소화로 강화학습 완전 대체) |
| **GPU VRAM 소모량** | 낮음 (단일 모델 가동) | 매우 높음 (4개 모델 적재 필수) | 중간 (정책 모델과 동결 참조 모델 2개만 적재) |
| **서빙 메모리 오버헤드** | 없음 | 없음 | 없음 (참조 모델은 훈련 완료 후 탈거됨) |

> 요약: SFT는 1대 1 지시 추종이고, RLHF는 PPO 통신망을 타는 3단계 종합 강화학습이며, DPO는 수학적 목적 함수 혁신을 통해 복잡한 PPO를 SFT 수준으로 간소화한 현대 정렬 표준임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 정책 모델 | 사용자의 질문 의도를 흡수해 실시간 정렬 갱신되는 행위자 모델임 |
| 참조 모델 | 정책의 탈선을 방지하기 위해 $KL$ 발산 한계를 쥐고 있는 동결 $SFT$ 모델임 |
| 선호/비선호 데이터쌍 | 동일 프롬프트에 대응하는 양호 답변($y_w$)과 불량 답변($y_l$)의 매핑 세트임 |
| DPO 로스 계산기 | 두 모델의 로그 확률 비율을 비교해 정답 확률 델타를 계산하는 로스 모듈임 |

```text
[ DPO (Direct Preference Optimization) 훈련 구조 ]
                             Prompt (x)
                            /          \
                [ Policy Model ]     [ Reference Model (Frozen) ]
                            \          /
             Log-Prob Ratio: Log(Policy_prob / Reference_prob)
                                    │
                                    v
                           [ DPO Loss Function ] <---> Preference Pair (yw, yl)
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 선호/비선호 | --> | 정책/참조    | --> | 로그확률    | --> | DPO 로스로  |
| 답변쌍 준비 |     | 로그확률 계산|     | 상대비율계산|     | 정책 모델 FT|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **선호쌍 피딩** — 하나의 프롬프트에 대응하는 인간 선호 답변($y_w$)과 비선호 답변($y_l$)을 훈련 큐에 피딩함
2. **로그 확률 추출** — 정책 모델과 동결 참조 모델에 각각 문장을 태워, 선호/비선호 토큰들을 뱉을 원시 로그 확률($Log-Likelihood$)을 산출함
3. **손실 비율 연산** — 참조 모델 확률 대비 정책 모델 확률의 증가분을 선호/비선호 양단 계산하고, 차이를 DPO 오차 식으로 도출함
4. **가중치 조율** — 베타 계수($\beta$)를 곱해 KL 조향 세기를 규제하고, 정책 모델의 가중치를 SFT 가독성으로 즉각 최적 수렴시킴

## Ⅵ. 실무 적용 및 유의점

1. 라벨링이 불명확하거나 모순(Contradictory)되는 노이즈 섞인 선호 데이터가 대량 혼입되면, 정책 모델이 무엇이 올바른 톤인지 인지하지 못하고 훈련이 붕괴하므로, 반드시 정량적 데이터 클리닝 및 평가자간 일치율($Agreement$ $Rate$)을 감사해야 함
2. 규제 계수인 베타($\beta$) 강도를 너무 약하게 설정하면 정책 모델이 원본 지능 층을 버리고 오직 칭찬받는 톤에만 과적합되어 일반 상식(MMLU) 지능이 추락하므로, Divergence 지표를 상시 감시하며 최적의 Beta 수치 마지노선을 조율해야 함

## Ⅶ. 결론

- DPO는 강화학습의 물리적 고비용 병목과 불안전 수렴 문제를 단 한 줄의 수학적 손실 함수 재정의로 극복한 현대 LLM 정렬 생태계의 마일스톤이며, 설계자는 학습 안정성을 저해할 수 있는 선호 데이터셋의 노이즈 여과 체계와 최적의 베타 규제 계수 튜닝을 철저히 결합해야 함
