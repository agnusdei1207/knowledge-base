## 미리 알고가기

- DPO는 선호 데이터만으로 정렬을 수행하는 preference optimization 계열 기법임
- RLHF의 보상 모델과 PPO 단계를 단순화한 대안으로 많이 사용됨
- reference model과 선호쌍 품질이 학습 안정성을 크게 좌우함

## Ⅰ. 개요

- **정의/개념**: DPO는 선호 답변과 비선호 답변 쌍을 이용해 모델이 선호 답변에 더 높은 확률을 부여하도록 직접 최적화하는 정렬 기법으로, 별도 보상 모델 없이 preference learning을 수행함
- **배경/필요성**: RLHF는 보상 모델 학습과 PPO 최적화가 복잡하고 비용이 크므로, 같은 선호 데이터를 더 단순하고 안정적으로 활용하는 학습 방식이 필요함

## Ⅱ. 특징

- RLHF보다 파이프라인이 단순해 구현과 운영 비용이 낮음
- supervised fine-tuning과 유사한 학습 안정성을 유지하면서 선호 정렬을 수행할 수 있음
- 데이터 품질과 모순에 민감해 선호쌍 노이즈가 많으면 성능이 쉽게 흔들릴 수 있음
- reference model에서 너무 멀어지지 않게 제어하는 설정이 중요함

## Ⅲ. 종류 및 비교

| 판단 기준 | SFT | RLHF | DPO |
|:---|:---|:---|:---|
| 학습 신호 | 정답 응답 | 선호+보상 | 선호쌍 |
| 보상 모델 | 없음 | 있음 | 없음 |
| 구현 난도 | 중간 | 높음 | 중간 |
| 대표 목적 | 지시 수행 | 정교한 선호 정렬 | 단순화된 선호 정렬 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Policy Model | 선호 데이터를 반영해 업데이트되는 대상 모델로 실제 정렬 결과를 형성함 |
| Reference Model | 원래 분포를 기준으로 제공해 policy가 과도하게 붕괴되지 않도록 제약의 기준점이 됨 |
| Preference Pairs | 같은 프롬프트에 대한 선호 답변과 비선호 답변을 제공해 직접 학습 신호를 만듦 |
| DPO Objective | 선호 답변 확률은 높이고 비선호 답변 확률은 낮추도록 손실을 계산함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 선호쌍 준비     | --> | policy/ref 확률 계산 | --> | DPO 손실 계산   | --> | policy 업데이트 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **선호쌍 준비**: 동일 프롬프트에 대한 선호, 비선호 응답 데이터를 구성함
2. **policy, reference 확률 계산**: 두 모델이 각 응답에 부여한 로그확률을 계산함
3. **DPO 손실 계산**: 선호 응답의 상대 확률을 높이는 방향으로 손실을 산출함
4. **policy 업데이트**: reference 분포를 기준으로 과도한 이탈을 막으며 모델을 정렬함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 선호쌍에 모순이나 라벨 노이즈가 많으면 모델이 어떤 응답을 선호해야 하는지 불안정하게 학습할 수 있음
   - 해결방안: preference 데이터 정제를 강화하고 label agreement와 win rate로 데이터 품질을 검증함
2. 문제: reference 제약이 약하면 모델이 특정 패턴으로 과도하게 쏠려 응답 다양성과 안정성이 떨어질 수 있음
   - 해결방안: beta와 KL 수준을 함께 조정하고 divergence trend와 benchmark regression으로 안정성을 검증함
3. 문제: DPO가 단순하다고 해도 선호 데이터 자체가 부족하면 RLHF 대비 품질 차이가 크게 줄 수 있음
   - 해결방안: 고품질 preference pair를 우선 확보하고 cost per pair 대비 quality gain으로 투자 효율을 검증함

## Ⅶ. 적용 사례

- 상용 챗봇 정렬: RLHF 대신 단순한 선호 학습으로 정렬함, 확인 지표는 win rate와 refusal quality임
- 사내 정책 준수 모델: 선호 응답 패턴을 빠르게 학습함, 확인 지표는 policy violation rate와 answer consistency임
- 오픈소스 instruct 모델 개선: low-cost alignment를 수행함, 확인 지표는 benchmark score와 training cost임

## Ⅷ. 결론

DPO는 RLHF의 핵심 목표를 더 단순한 학습 형태로 가져온 정렬 기법이므로, 복잡한 강화학습 비용을 줄이면서 선호 데이터 품질에 더 엄격하게 의존하는 방식으로 이해해야 함.
