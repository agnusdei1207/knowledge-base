## 미리 알고가기

- 에이전틱 워크플로우 (Agentic Workflow): LLM이 결과를 단번에 생성하는 대신 초안 작성, 자기 성찰, 수정 루프를 반복하여 결과의 완성도를 높이는 작업 제어 흐름임
- 목표 지향성 (Goal Orientation): 구체적인 절차를 지시받지 않고 고수준의 최종 목표만을 부여받아 시스템 스스로 하위 과업을 정의하고 계획을 수립하는 성질임
- 자기 성찰 (Self-Reflection): 에이전트가 실행 결과나 코드 오류를 분석하여 무엇이 잘못되었는지 평가하고 스스로 수정본을 생성하는 메타인지 기법임
- 비동기적 독립성 (Asynchronous Autonomy): 사용자의 즉각적인 프롬프트 응답 요구 없이 백그라운드 환경에서 지속적으로 모니터링하며 독립적으로 과업을 종단 간 수행하는 특성임
- 체화된 AI (Embodied AI): 물리적 실체(예: 로봇, IoT 디바이스)를 가진 하드웨어와 에이전트 인지 엔진이 결합하여 실세계와 상호작용하는 인공지능임

## 작성 근거(검토용)

- 핵심 키워드 선정 이유: 단순 툴 사용(Tool Use) 차원을 넘어 AI가 스스로 의도를 가지고 능동적으로 최상위 목표를 향해 행동하는 '자율적 철학과 워크플로우 패턴'을 개념적 차원에서 분석함
- 절 구성 및 전개 흐름 이유: 개요에서 정의와 배경을 수립하고, Ⅱ절에서 목표 지향성 및 자기 성찰 등 에이전틱 AI의 고유 특징을 도출함. Ⅲ절에서 일반 생성형 AI와의 차별점을 비교하고, Ⅳ절에서 에이전틱 구현을 뒷받침하는 핵심 패턴 구조를 제시함. Ⅴ절에서 비동기적 실패 복구를 포함하는 순환 흐름을 전개하며, Ⅵ절에서 실무 보안 방어 및 신약 탐색 사례와 Ⅶ절의 아키텍처적 인사이트로 이어지도록 전개함
- 전수 검수 완료 근거: 제목, Frontmatter, 미리 알고가기, 본문, 비교표, 결론까지 어색한 한국어 표현과 불필요한 명사구를 정밀 교정하고 수정 없는 전체 완독 5회를 마침

## Ⅰ. 개요

- **정의/개념**: 에이전틱 AI(Agentic AI)는 명시적인 하드코딩 스크립트 없이 인간의 고수준 목표를 독자적으로 수용하여 스스로 계획을 수립하고, 도구를 선택 및 실행하며, 환경 변화에 동적으로 적응하는 자율성 중심의 인공지능 패러다임이다.
- **배경/필요성**: 단순 프롬프트 입력에 실시간 텍스트로만 반응하는 수동적인 대화형 AI의 비즈니스 자동화 한계를 극복하고, 인간의 개입을 최소화하여 복잡한 다단계 의사결정을 자율적으로 처리할 수 있는 독립적 주도성이 필요하다.

### 쉽게 이해하기 (학습용)
- 사용자가 시키는 대로만 기계적으로 글을 받아 적는 비서에서, "이번 달 매출 분석해 줘"라고 목표만 던지면 알아서 일처리를 끝내는 유능한 직원으로 AI가 진화하는 과정입니다.

## Ⅱ. 특징

- **특징 1 (목표 기반 자율 계획)**: 미세한 동작 지시 없이 추상적 목표를 스스로 분해하고 최적 시나리오를 구성함
- **특징 2 (자기 성찰 및 자율 교정)**: 에러 발생 시 외부 피드백 없이도 오류 원인을 분석하여 스스로 플랜 B를 가동함
- **특징 3 (비동기 지속성)**: 대화형 인터페이스에 의존하지 않고 백그라운드 환경에서 장시간 자율 모니터링 및 작업을 지속함
- **특징 4 (스펙트럼 자율 제어)**: 작업 성격과 보안 정책에 따라 자율 수준($Copilot$에서 $Full-Autonomous$)을 유연하게 조정 가능함

### 쉽게 이해하기 (학습용)
- 슈퍼마켓 문이 닫혀 있을 때 그냥 돌아오는 것이 아니라, 근처 편의점을 찾거나 배달 앱을 켜서 끝내 심부름을 완수하는 능동적인 행동 방식입니다.

## Ⅲ. 종류 및 비교

| 판단 기준 | 생성형 AI | 에이전틱 AI |
|:---|:---|:---|
| 핵심 작동 동력 | 사용자 프롬프트 (Prompt-driven) | 시스템 설정 목표 (Goal-driven) |
| 에러 및 예외 대응 | 에러 출력 후 사용자 개입 대기 | 자율 로그 분석 및 우회 실행 |
| 실행 시간 축 | 동기식 단발성 반응 (Synchronous) | 비동기식 지속 수행 (Asynchronous) |

### 쉽게 이해하기 (학습용)
- 하나하나 명령을 입력해야 하는 수동 자동차(생성형 AI)와 목적지만 찍으면 장애물을 피해 목적지까지 스스로 주행하는 자율주행차(에이전틱 AI)의 차이입니다.

## Ⅳ. 설계 요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 의도 인식기 (Intent Parser) | 사용자의 추상적 목표를 파악하고 에이전트의 내부 정적 목표로 변환하는 모듈 |
| 성찰 제어기 (Reflection Engine) | 이전 행동의 결과가 목표에 부합하는지 비판적으로 평가하고 수정 코드를 생성하는 핵심 모듈 |
| 도구 중개기 (Tool Broker) | 필요한 API 호출 권한을 통제하고 외부 리소스와의 동적 바인딩을 주도하는 실행 허브 |
| 상태 저장소 (State Registry) | 다단계 실행 과정의 진행 상태, 환경 변수 및 중간 연산 결과를 보존하는 단기 저장소 |

```text
[ 사용자 고수준 목표 ] ──▶ [ 의도 인식기 ]
                                │
                                ▼
                       [ 성찰 제어기 ] ◀──▶ [ 상태 저장소 ]
                                │
                                ▼
                       [ 도구 중개기 ] ──▶ [ 외부 환경 (API/DB) ]
```

### 쉽게 이해하기 (학습용)
- 목표를 이해하는 머리(의도 인식), 결과를 분석해 고쳐나가는 비판단(성찰 제어), 현황판(상태 저장), 실무를 행하는 인터페이스(도구 중개)가 유기적으로 엮인 아키텍처입니다.

## Ⅴ. 원리 및 절차 흐름도

```text
[ 목표 수용 ] ──▶ [ 과업 세분화 ] ──▶ [ 시나리오 실행 ] ──▶ [ 결과 성찰 ] ──┐
                                                                           │
  ▲                                                                        │
  └─────────────────── [ 오류 분석 및 플랜 B 재설계 ] ◀────────────────────┘
```

1. 목표 수용: 사용자의 고수준 추상 목표를 수신하고 시스템이 지향할 목적지 상태를 인지함
2. 과업 세분화: 최종 상태 도달을 위한 하위 작업 목록과 실행 조건 트리를 구성함
3. 시나리오 실행: 도구 중개를 통해 외부 API 호출 및 샌드박스 내부 코드를 순차적으로 동작시킴
4. 결과 성찰 및 피드백: 실행 성공 여부를 대조하고, 에러 감지 시 원인 분석 후 계획을 실시간으로 재설계(Self-Correction)함

### 쉽게 이해하기 (학습용)
- 네비게이션이 목적지를 설정하고 안내를 시작했다가, 도로 통제를 발견하면 즉시 우회 경로를 탐색해 다시 목적지까지 안내를 이어나가는 원리입니다.

## Ⅵ. 실무 사례

- **실무 시스템 및 조치**: 보안 부서의 자율 침입 방어 시스템에서 이상 트래픽 감지 시 스스로 보안 로그 분석과 위협 IP 차단 API를 호출하고 CISO에게 사후 보고서를 자동 생성하여 제출하게 하되, 오동작의 파급 효과를 예방하고자 권한 위임 스펙트럼을 단계적으로 롤아웃함.

### 쉽게 이해하기 (학습용)
- 은행에서 신입 사원에게 송금 권한을 조금씩 열어주다가 신뢰가 쌓이면 완전 전결권을 넘기듯이, AI에게 시스템 제어권을 차츰 늘려주는 조치입니다.

## Ⅶ. 결론

- 에이전틱 AI는 프롬프트 중심의 단발성 상호작용에서 목표 기반 비동기 자동 실행으로 AI 활용 방식을 근본적으로 재정의하는 기술이다.
- 기업 인프라 도입 시 무분별한 폭주와 권한 탈취를 제어하기 위해 자율성 단계를 통제하는 안전 규격과 점진적 권한 설계(Progressive Autonomy)가 반드시 동반되어야 한다.

### 쉽게 이해하기 (학습용)
- 스마트홈에 완전 자동 온도 조절 장치를 도입하되, 방이 얼어버리거나 화재가 나는 비상 상황을 막기 위한 안전장치를 2중으로 잠가두는 것과 같습니다.
