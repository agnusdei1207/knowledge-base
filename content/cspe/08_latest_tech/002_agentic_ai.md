# 📖 【암기용】 개념 완전 이해

> 목적: 에이전틱 AI를 처음 봐도 완벽히 이해하게 만든다.

## 한눈에
- **개요**: AI가 목표 달성을 위해 계획·행동·피드백을 반복하는 방식
- **왜 필요한가**: 사용자는 답변보다 업무 결과를 요구하며, 단일 프롬프트만으로는 다단계 업무를 처리하기 어려움.
- **핵심 직관**: 에이전틱 AI는 “묻고 답하는 AI”가 아니라 “목표를 받고 움직이는 AI”임.

## 깊이 이해
- **배경·문제의식**: 생성형 AI는 문서 작성과 요약에 강하지만, 업무 시스템 변경·검증·보고까지 이어지는 폐루프가 부족함.
- **작동 원리**: 목표를 세부 작업으로 나누고, 도구 실행 결과를 관찰하며, 실패 시 계획을 수정해 재시도함.
- **비유**: 내비게이션이 목적지만 받는 것이 아니라 교통상황을 보고 경로를 계속 바꾸는 구조.
- **구체 예시**: 보안 점검 에이전트가 자산목록 조회 -> 취약점 매핑 -> 조치 우선순위 -> 담당자 배정을 수행함.
- **흔한 오해·주의점**: 자율성이 높을수록 정답률만으로 평가할 수 없고 업무 성공률·위반률·감사 가능성을 함께 평가해야 함.

## 연결 개념
- AI 에이전트 시스템 — 구현 아키텍처
- Human-in-the-Loop — 고위험 행동 승인 방식
- AI 거버넌스 — 정책·책임·감사 체계

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 에이전틱 AI는 LLM이 목표 기반으로 계획·행동·관찰·수정을 반복하는 패러다임임.
> 2. **가치**: 단발성 생성 결과를 다단계 업무 완료율, 처리시간, 감사가능성 중심의 운영 모델로 확장함.
> 3. **판단 포인트**: 적용 대상은 반복·규칙 기반·승인 가능 업무부터 시작하고, 권한 변경 업무는 승인 절차를 둠.

---

## Ⅰ. 개요 및 필요성

에이전틱 AI는 목표 지향 AI 실행 방식임. 생성형 AI가 단순 질의응답을 넘어 업무 처리로 확장되면서 계획, 도구 실행, 결과 검증, 책임 추적이 요구됨.

---

## Ⅱ. 구조 및 구성요소

```text
Goal -> Plan -> Act -> Observe -> Reflect -> Replan/Finish


       Policy  Tools   Telemetry  Memory
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Goal | 업무 목표와 제약 정의 | 범위·완료조건 필요 |
| Plan/Act | 계획 수립과 행동 수행 | 도구별 권한 분리 |
| Observe/Reflect | 결과 관찰과 자기검토 | 실패 원인 분류 |
| Policy/Memory | 통제와 상태 유지 | 감사·삭제 정책 필요 |

> 요약: 에이전틱 AI는 목표를 실행 가능한 행동으로 바꾸고 관찰 결과로 계획을 갱신함.

---

## Ⅲ. 동작원리 및 흐름도

```text
요구 입력 -> 목표 정규화 -> 작업 분해 -> 도구 실행
        -> 결과 관찰 -> 정책 위반 검사 -> 종료/재계획
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 목표·제약 정규화 | 승인 필요 여부, 금지 작업 |
| 2 | 작업 분해 | 단계별 입력·출력 정의 |
| 3 | 행동 수행 | API 성공률, 재시도 횟수 |
| 4 | 반성·종료판단 | 완료조건 충족, 로그 보존 |

> 요약: 에이전틱 AI는 실행 결과를 관찰해 목표 달성 여부를 판단하고 부족하면 재계획함.

---

## Ⅳ. 특징

| 구분 | 생성형 AI | 에이전틱 AI | 수치·판단 포인트 |
|:---|:---|:---|:---|
| 목표 | 답변 생성 | 업무 완료 | 완료율, 평균 단계 수 |
| 제어 | 프롬프트 중심 | 정책·도구·메모리 중심 | RBAC, 호출 한도 |
| 평가 | 정답성·유창성 | 성공률·위반률·비용 | 작업당 토큰, 오류율 |

> 요약: 에이전틱 AI 평가는 모델 품질보다 업무 완료율과 통제 위반률 중심으로 전환됨.

---

## Ⅴ. 실무 적용 및 결론

**적용 방안 3개:**
1. FAQ·티켓 분류처럼 저위험 업무를 자동형으로 적용하고 권한변경은 승인형으로 분리
2. 단계별 성공률, 정책 위반률, 작업당 비용, p95 처리시간을 운영 KPI로 설정
3. 입력·추론·도구결과를 보존하고 개인정보는 KMS 암호화와 TTL 삭제 정책 적용

**결론 (2줄):**
- 기술사 판단: 반복 업무는 자율형, 금전·권한·법적 영향 업무는 Human-in-the-Loop형으로 구분함.
- 향후 방향: 에이전틱 AI는 MCP, LLMOps, AI 거버넌스와 결합한 엔터프라이즈 자동화 구조로 수렴함.
