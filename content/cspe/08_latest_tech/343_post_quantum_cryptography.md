# 📖 【암기용】 개념 완전 이해

> 목적: PQC를 처음 봐도 완벽히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 슈퍼컴퓨터보다 훨씬 빠른 양자컴퓨터가 나와도 해독할 수 없도록 설계된 차세대 암호 기술
- **왜 필요한가**: 우리가 현재 쓰는 공인인증서, 웹사이트 보안(HTTPS) 등의 기반인 RSA 암호는 양자컴퓨터(쇼어 알고리즘)가 등장하면 순식간에 뚫리기 때문
- **핵심 직관**: "양자컴퓨터라는 초강력 창을 막아내는 새로운 방패" — 숫자의 소인수분해를 이용하던 기존 방식 대신, 양자컴퓨터도 풀기 힘든 복잡한 수학 문제(격자 등)를 암호의 열쇠로 사용하는 것

## 깊이 이해
- **배경·문제의식**: '지금 저장하고 나중에 해독하자(Store Now, Decrypt Later)'는 위협 때문임. 공격자들이 지금의 암호화된 데이터를 미리 다 수집해두었다가, 나중에 양자컴퓨터가 완성되면 그때 해독해버릴 수 있음. 따라서 양자컴퓨터가 나오기 전부터 암호를 바꿔야 함.
- **작동 원리**: 양자컴퓨터도 계산하기 매우 힘든 수학적 난제를 활용함. ① **격자 기반(Lattice-based)** — 고차원 격자에서 가장 가까운 점 찾기. ② **다변수 다항식 기반** — 여러 개의 미지수가 있는 방정식 풀기. ③ **코드 기반** — 오류 정정 코드의 복잡성 활용. ④ **아이소제니 기반** — 타원곡선 간의 복잡한 매핑 찾기.
- **비유**: 기존 암호가 '매우 큰 숫자의 비밀번호를 맞히는 것'이었다면, PQC는 '수만 개의 문이 있는 거대한 미로에서 특정 보물을 찾는 것'과 같음. 미로가 너무 복잡해서 양자컴퓨터도 모든 길을 다 가보는데 한계가 있게 설계함.
- **구체 예시**: 미국 표준기술연구소(NIST)가 선정한 표준 알고리즘들(ML-KEM, ML-DSA 등). 최근 구글 크롬 브라우저나 애플 아이메시지 등에 이미 적용되기 시작함.
- **흔한 오해·주의점**: '양자암호통신(QKD)'과는 완전히 다름. QKD는 빛의 물리적 특성을 이용한 '장비' 중심 기술이고, PQC는 수학 알고리즘을 바꾼 '소프트웨어' 중심 기술임. PQC는 기존 인터넷 망을 그대로 쓸 수 있다는 큰 장점이 있음.

## 연결 개념
- Shor's Algorithm — 기존 공개키 암호(RSA, ECC)를 무력화하는 양자 알고리즘
- NIST PQC Standardization — 미국 주도의 글로벌 PQC 표준화 작업
- QKD (Quantum Key Distribution) — 양자 역학적 물리 현상을 이용한 암호키 분배 기술

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.
> 핵심: 기존 암호 체계의 붕괴 위협(쇼어 알고리즘)과 이를 방어하기 위한 수학적 난제 기반의 보안 메커니즘을 기술한다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 고성능 양자컴퓨터의 쇼어(Shor) 및 그로버(Grover) 알고리즘 공격에 저항할 수 있는 수학적 난제(격자, 부호, 다변수 등) 기반의 차세대 공개키 암호 체계다.
> 2. **가치**: 기존 통신 인프라(TCP/IP)를 그대로 활용하면서 양자 컴퓨팅 시대의 'Store Now, Decrypt Later' 위협으로부터 데이터 무결성과 기밀성을 보장한다.
> 3. **판단 포인트**: NIST 표준 알고리즘(FIPS 203, 204, 205)의 채택 동향과 기존 시스템과의 호환성(Crypto-agility) 확보가 전환 전략의 핵심이다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 양자 컴퓨팅에 의한 암호 붕괴 위협 이해 | 쇼어 알고리즘, RSA/ECC 취약성, 공격 시나리오 | 단순 '속도가 빠르다'는 이유로만 서술 |
| PQC의 핵심 수학적 원리 및 분류 파악 | 격자(Lattice), 부호(Code), 다변수(Multivariate), 해시 | 양자암호통신(QKD)과 혼동 |
| NIST 표준화 동향 및 전환 전략 인지 | ML-KEM(Kyber), ML-DSA(Dilithium), 암호 민첩성 | 표준화가 완료되지 않았다고 서술(현재 표준 확정됨) |

> 요약: PQC는 소프트웨어 기반으로 양자 내성을 확보하는 '수학적 방패'이며, 인프라 교체 없이 적용 가능한 경제성이 강점이다.

## Ⅰ. 개요 및 필요성

- 정의: 양자컴퓨터의 강력한 연산 능력으로도 해독에 수만 년 이상이 소요되는 복잡한 수학적 문제를 기반으로 설계된 공개키 암호 알고리즘
- 배경: 쇼어(Shor) 알고리즘에 의한 인수분해(RSA) 및 이산대수(ECC) 기반 현대 암호 체계의 완전 무력화 위협 가속화
- 필요성: 장기 보존 데이터의 선제적 보호(Harvest Now, Decrypt Later 대응), 국가 안보 및 금융 거래 신뢰성 유지

---

## Ⅱ. 구조 및 구성요소

```text
[ Quantum Threat: Shor's Alg ] ----> [ Traditional PKI (RSA/ECC) : Vulnerable ]
                                             |
                                     [ Replacement by PQC ]
                                             |
      +-------------------------+------------+------------+-------------------------+
      |                         |                         |                         |
[ Lattice-based ]        [ Code-based ]           [ Multivariate ]          [ Hash-based ]
- 최단 벡터 문제 (SVP)   - 오류 정정 코드 디코딩   - 다변수 이차방정식 풀이   - 일회용 서명 연쇄
- ML-KEM (Kyber)         - Classic McEliece        - Mayo                     - SLH-DSA (Sphincs+)
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Lattice-based PQC | 고차원 격자 구조의 수학적 난제 활용 | 성능/크기 균형 우수 (표준 주류) |
| KEM (Key Encapsulation) | 안전한 암호키 공유를 위한 메커니즘 | ML-KEM (Kyber) |
| Digital Signature | 송신자 인증 및 데이터 무결성 보장 | ML-DSA (Dilithium) |
| Crypto-agility | 시스템 중단 없이 암호 알고리즘을 교체할 수 있는 유연성 | 하이브리드 암호 체계 활용 |

> 요약: 양자컴퓨터도 정복하지 못한 수학적 난제들을 공개키 교환(KEM)과 전자서명(Signature)에 적용한 구조다.

## Ⅲ. 동작원리 및 흐름도 (격자 기반 예시)

```text
난제 파라미터 생성 -> 고차원 격자 내 비밀키 설정 -> 오류(Noise) 추가된 공개키 생성 -> 키 교환/서명 -> 복호화/검증
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 수학적 난제 설정 | 수백~수천 차원의 격자 구조와 학습 오차(LWE) 파라미터 정의 | 양자 보안 강도(Category 1-5) |
| 2 | 키 쌍(Key Pair) 생성 | 개인키와 결합된 격자 점에 미세한 노이즈를 섞어 공개키 생성 | 노이즈 분포의 무작위성 |
| 3 | 암호화/캡슐화 | 공개키를 이용해 메시지를 격자상의 점으로 변환 후 추가 노이즈 삽입 | 암호문 크기(Byte) |
| 4 | 복호화/추출 | 개인키를 이용해 격자 구조의 규칙성을 찾아 노이즈를 제거하고 원문 복원 | 복호화 성공률 100% |
| 5 | 무결성 검증 | 전자서명 알고리즘을 통해 데이터 위변조 여부 확인 | 서명 생성/검증 속도 |

> 요약: 정답(개인키) 근처에 수많은 오답(노이즈)을 뿌려두어, 격자 구조의 지름길을 모르는 양자컴퓨터가 길을 잃게 만드는 원리다.

## Ⅳ. 특징 (PQC vs QKD 비교)

| 구분 | PQC (양자내성암호) | QKD (양자키분배) |
|:---|:---|:---|
| 구현 방식 | 소프트웨어 / 알고리즘 교체 | 하드웨어 / 별도 통신 장비(광자) |
| 통신 인프라 | 기존 인터넷망 (TCP/IP) 그대로 사용 | 전용 양자 채널 및 신뢰 노드 필요 |
| 확장성 | 매우 높음 (앱/웹 즉시 적용) | 낮음 (물리적 거리 및 비용 제약) |
| 보안 근거 | 수학적 복잡도 (Computational) | 양자역학 물리 법칙 (Physical) |
| 주요 용도 | 웹 보안(SSL), 문서 서명, 일반 통신 | 국가 기밀, 금융 기간망 등 고보안 채널 |

> 요약: PQC는 범용성과 경제성이 뛰어나며, QKD는 물리적 절대 보안을 지향하는 상호 보완적 관계다.

## Ⅴ. 심화 비교 및 적용 판단

| 구분 | RSA-2048 (현행) | ML-KEM (Kyber-768, PQC) | 선택 기준 |
|:---|:---|:---|:---|
| 공개키 크기 | 약 256 Bytes | 약 1,184 Bytes | 통신 대역폭 및 스토리지 여유 |
| 암호화 속도 | 빠름 | 매우 빠름 | 처리 성능(TPS) 요구사항 |
| 보안성 | 양자 공격에 취약 (0점) | 양자 공격 내성 (강력) | 데이터의 가치 및 보존 필요 기간 |

> 요약: PQC는 기존 암호보다 키 크기는 크지만 연산 속도는 오히려 빠르거나 대등하여 전환 시 성능 저하가 미미하다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 알고리즘 취약점 발견 | 신규 수학적 난제의 논리적 허점 가능성 | 하이브리드 모드(PQC + 기존암호) 운영 | 신규 공격 기법 출현 여부 |
| 패킷 파편화 | 늘어난 키/서명 크기로 인한 네트워크 오버헤드 | MTU 사이즈 최적화, 압축 기술 적용 | 네트워크 지연 시간 (Latency) |
| 마이그레이션 복잡도 | 방대한 기존 시스템의 암호 모듈 교체 부담 | 암호 민첩성(Crypto-agility) 프레임워크 도입 | 전환 완료율 및 호환성 오류 건수 |

> 요약: 초기에는 기존 암호와 PQC를 섞어 쓰는 '하이브리드 방식'을 통해 신규 알고리즘의 리스크를 상쇄해야 한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 양자 보안 등급 | NIST Category 3 이상 (AES-192 수준) | 알고리즘 파라미터 검토 |
| 연산 오버헤드 | 기존 암호 대비 2배 이내 증가 제한 | 벤치마킹 테스트 (OpenSSL 등) |
| 상호운용성 | 이종 시스템 간 키 교환 성공률 100% | 프로토콜 호환성 테스트 |

> 요약: 도입 성과는 보안 강도의 상향과 실 운영 환경에서의 성능 저하 최소화로 평가한다.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 하이브리드 키 교환 적용: TLS 1.3 통신 시 기존 ECDH와 ML-KEM을 병행 사용하여, PQC의 불확실성과 기존 암호의 취약성을 동시에 보완
2. 내부 개발자 플랫폼(IDP) 연동: 중앙 암호화 모듈을 PQC 기반으로 업데이트하고, 모든 사내 서비스가 API 호출만으로 PQC를 자동 적용하게 구현
3. 데이터 아카이빙 보안 강화: 10년 이상 장기 보존이 필요한 기밀 데이터에 대해 ML-DSA 전자서명을 적용하여 향후 양자 시대의 위변조 방지

**결론 (2줄):**
- 기술사 판단: PQC는 양자 컴퓨터의 위협을 '소프트웨어 업데이트'만으로 막아낼 수 있는 가장 현실적이고 경제적인 방어 수단이다
- 향후 방향: 2024년 NIST 표준 확정 이후 전 세계적인 인프라 전환이 시작되었으며, 'PQC-Native' 보안 환경이 IT의 기본 사양이 될 것이다
