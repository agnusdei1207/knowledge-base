## 미리 알고가기

- Chiplet은 하나의 거대 칩을 여러 기능 블록으로 나눠 별도 다이로 만들고 패키지에서 다시 연결하는 설계 방식임
- 제조 수율과 설계 재사용성과 이종 공정 혼합이 핵심 장점임
- 인터커넥트 지연과 패키징 복잡도가 주요 과제로 따라옴

## Ⅰ. 개요

- **정의/개념**: Chiplet은 CPU나 GPU나 I O나 메모리 제어기 같은 기능 블록을 작은 다이 단위로 분리 제작한 뒤 고급 패키징과 인터커넥트로 하나의 시스템처럼 묶는 반도체 설계 패러다임임
- **배경/필요성**: 단일 거대 다이는 수율과 비용과 설계 복잡도 한계가 커져 기능별 최적 공정과 모듈 재사용을 가능하게 하는 칩렛 방식이 주류로 부상함

## Ⅱ. 특징

- 대형 모놀리식 다이보다 수율과 비용 효율에서 유리할 수 있음
- 서로 다른 공정 노드와 기능 블록을 조합할 수 있음
- 모듈 재사용으로 제품군 확장과 설계 시간 단축이 가능함
- 패키지 내부 연결 구조가 성능과 전력 효율을 결정함

## Ⅲ. 종류 및 비교

| 판단 기준 | Chiplet | Monolithic Die | MCM 전통 패키지 |
|:---|:---|:---|:---|
| 수율 | 상대적으로 높음 | 낮아질 수 있음 | 중간 |
| 기능 분리 | 높음 | 낮음 | 중간 |
| 공정 혼합 | 용이 | 어려움 | 일부 가능 |
| 핵심 과제 | 인터커넥트와 패키징 | 대형 다이 비용 | 대역폭 한계 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Compute Chiplet | CPU나 GPU 코어처럼 핵심 연산 기능을 담당하는 개별 다이임 |
| I O or Control Chiplet | 메모리 제어와 인터페이스와 시스템 제어를 담당해 기능 분리를 가능하게 하는 보조 다이임 |
| Advanced Package Substrate | 여러 칩렛을 물리적으로 배치하고 고속으로 연결하는 패키지 기반임 |
| Die to Die Interconnect | 칩렛 간 데이터와 제어 신호를 전달해 하나의 논리 칩처럼 동작하게 하는 연결 구조임 |
| System Integration Logic | 칩렛 간 전력과 클럭과 프로토콜 일관성을 유지하는 통합 제어 계층임 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
| 기능 분할 설계 | -> | 개별 다이 제조 | -> | 패키지 조립    | -> | D2D 연결 검증 | -> | 시스템 통합    |
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
```

1. **기능 분할 설계**: 전체 칩 기능을 칩렛 단위로 분해함
2. **개별 다이 제조**: 기능별 최적 공정으로 각 칩렛을 제작함
3. **패키지 조립**: 칩렛들을 패키지 위에 배치함
4. **D2D 연결 검증**: 지연과 대역폭과 전력 특성을 점검함
5. **시스템 통합**: 소프트웨어와 펌웨어 관점에서 하나의 시스템으로 통합함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 칩렛 간 인터커넥트 대역폭과 지연이 부족하면 단일 칩 수준 성능을 내기 어려울 수 있음
   - 해결방안: high bandwidth die to die link와 topology optimization을 적용하고 inter chiplet latency와 effective D2D bandwidth로 검증함
2. 문제: 패키징과 조립 복잡도가 높아지면 제조 수율과 공급 일정이 불안정해질 수 있음
   - 해결방안: package co design과 assembly yield control을 적용하고 package assembly yield와 schedule slip rate로 검증함
3. 문제: 기능 분리가 과도하면 전력 관리와 디버깅과 소프트웨어 최적화가 복잡해질 수 있음
   - 해결방안: modular power control과 unified validation flow를 적용하고 integration defect rate와 debug turnaround time으로 검증함

## Ⅶ. 적용 사례

- 서버 프로세서가 고대역 D2D 링크를 적용하며 확인 지표는 inter chiplet latency와 effective D2D bandwidth임
- 이종 공정 AI 가속기가 패키지 공동 설계를 운영하며 확인 지표는 package assembly yield와 schedule slip rate임
- 칩렛 기반 플랫폼이 통합 검증 흐름을 강화하며 확인 지표는 integration defect rate와 debug turnaround time임

## Ⅷ. 결론

칩렛은 반도체 확장의 현실적 해법이지만 패키지와 인터커넥트가 곧 성능이므로 모듈 분할과 통합 설계를 함께 최적화해야 함.
