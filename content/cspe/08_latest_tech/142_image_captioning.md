## 미리 알고가기

- 이미지 캡셔닝은 이미지를 자연어 문장으로 설명하는 생성 태스크임
- 객체 인식뿐 아니라 관계와 장면 맥락을 함께 요약해야 품질이 높아짐
- 웹 접근성, 검색 인덱싱, 감시 로그 자동화가 대표 활용임

## Ⅰ. 개요

- **정의/개념**: 이미지 캡셔닝은 시각 입력의 객체와 속성과 관계와 상황을 통합적으로 해석해, 사람이 읽을 수 있는 자연어 설명 문장을 자동 생성하는 멀티모달 생성 기술임
- **배경/필요성**: 이미지가 텍스트로 변환되지 않으면 검색과 접근성과 후속 LLM 분석이 막히므로, 비정형 시각 데이터를 언어 자산으로 바꾸는 기술이 필요함

## Ⅱ. 특징

- 이미지 전체 장면을 요약해 객체 나열을 넘는 설명을 생성함
- encoder-decoder나 VLM 구조를 통해 시각 특징과 언어 생성을 결합함
- alt text 자동화처럼 대량 배치 작업에 적용 가치가 높음
- 작은 글자나 미세 객체는 누락되거나 환각으로 대체될 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | 이미지 분류 | 이미지 캡셔닝 | VQA |
|:---|:---|:---|:---|
| 입력 | 이미지 | 이미지 | 이미지+질문 |
| 출력 | 클래스 라벨 | 설명 문장 | 질문별 답변 |
| 맥락 설명력 | 낮음 | 높음 | 질문 의존 |
| 검색 인덱싱 적합성 | 중간 | 높음 | 낮음 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Vision Encoder | 이미지를 특징 벡터나 토큰으로 변환해 객체와 배경과 위치 단서를 추출함 |
| Cross-Attention Layer | 생성 중인 단어가 어떤 시각 영역을 참조해야 하는지 연결해 문장-이미지 정합성을 높임 |
| Language Decoder | 시각 문맥을 바탕으로 자연스러운 설명 문장을 순차적으로 생성함 |
| Evaluation Layer | BLEU나 CIDEr와 환각 검사를 통해 생성 문장의 품질과 신뢰성을 측정함 |

```text
+-------------------+      +-------------------+      +-------------------+
                                                           |
                                                           v
                                                   +-------------------+
                                                   | Evaluation Layer  |
                                                   +-------------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 이미지 입력     | --> | 시각 특징 추출  | --> | 단어 순차 생성  | --> | 문장 품질 평가  |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **이미지 입력**: 원본 이미지나 프레임을 수집함
2. **시각 특징 추출**: 객체와 배경과 관계 단서를 벡터화함
3. **단어 순차 생성**: attention을 이용해 설명 문장을 생성함
4. **문장 품질 평가**: 생성 결과를 기준 문장과 환각 검출기로 점검함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 모델이 이미지에 없는 객체나 행위를 자연스럽게 덧붙이면 설명은 유창해도 신뢰성이 급격히 낮아질 수 있음
   - 해결방안: grounding 검증과 hallucination filter를 적용하고 CHAIR와 human approval rate로 검증함
2. 문제: 작은 글씨나 주변부 객체가 캡션에서 누락되면 접근성이나 검색 인덱싱 가치가 크게 떨어질 수 있음
   - 해결방안: high-resolution tiling과 OCR 결합을 적용하고 recall on key entities와 OCR exact match로 검증함
3. 문제: 범용 모델은 기업 도메인 용어와 상품 속성을 일반적 표현으로 바꿔 설명해 실무 활용성을 낮출 수 있음
   - 해결방안: domain fine-tuning과 terminology constraint를 적용하고 terminology accuracy와 retrieval gain으로 검증함

## Ⅶ. 적용 사례

- 전자상거래 상품 등록이 이미지를 자동 설명해 검색 메타데이터를 보강하도록 이미지 캡셔닝을 적용하며 확인 지표는 entity recall과 CTR임
- 공공 웹사이트가 시각장애인용 alt text를 대량 생성하도록 이미지 캡셔닝을 운영하며 확인 지표는 accessibility compliance와 reviewer time reduction임
- CCTV 이벤트 로그가 장면 설명을 자동 기록하도록 이미지 캡셔닝을 활용하며 확인 지표는 incident retrieval precision과 alert triage time임

## Ⅷ. 결론

이미지 캡셔닝은 시각 정보를 검색 가능한 언어 자산으로 바꾸는 핵심 기술이므로, 환각 억제와 세부 엔티티 보존이 실제 활용도를 좌우함.
