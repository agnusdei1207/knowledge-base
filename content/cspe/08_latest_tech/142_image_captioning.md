# 📖 【암기용】 개념 완전 이해

> 목적: Image Captioning을 처음 봐도 완벽히 이해하게 만든다.

## 한눈에
- **개요**: 이미지 내용을 자연어 문장으로 설명하는 시각-언어 생성 기술
- **왜 필요한가**: 이미지·사진·도면을 검색, 접근성, 보고서, RAG 근거로 활용하려면 텍스트 설명이 필요함.
- **핵심 직관**: 사진을 보고 "무엇이 어디에 있고 어떤 상황인가"를 문장으로 적는 AI임.

## 깊이 이해
- **배경·문제의식**: 이미지 파일은 사람에게는 직관적이지만 검색엔진과 LLM은 텍스트 설명 없이는 내용을 활용하기 어렵다.
- **작동 원리**: Vision Encoder가 이미지 특징을 추출하고, Decoder 또는 LLM이 객체·관계·상황 정보를 기반으로 설명 문장을 생성함.
- **비유**: 현장 사진을 보고 점검자가 "배관 연결부에 누수 흔적이 있음"이라고 보고서에 적는 작업과 같음.
- **구체 예시**: 제조 현장 사진을 캡션화해 "왼쪽 하단 볼트 누락" 같은 문장을 만들고, 이를 검색 인덱스와 품질 리포트에 저장.
- **흔한 오해·주의점**: 캡션은 이미지 전체 요약이라 세부 결함이나 작은 문자 누락 가능성이 있음. 객체 검출·OCR과 함께 검증해야 함.

## 연결 개념
- Vision-Language Model — 캡셔닝을 수행하는 대표 모델
- Visual Question Answering — 이미지에 대해 질문하고 답하는 태스크
- Multimodal RAG — 이미지 캡션을 텍스트 근거로 검색하는 구조

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: Image Captioning은 이미지 특징을 자연어 설명으로 변환하는 시각-언어 생성 태스크임.
> 2. **가치**: 이미지 검색·접근성·보고서 자동화·멀티모달 RAG의 텍스트 근거를 제공함.
> 3. **판단 포인트**: 객체 누락, OCR 오류, 환각 캡션을 검증 지표와 보조 모델로 통제해야 함.

## Ⅰ. 개요 및 필요성

- 개요: 이미지 설명 문장 생성 기술
- 배경: 기업 데이터에는 사진, 도면, 스캔 이미지가 포함되지만 텍스트 검색과 LLM 입력으로 바로 쓰기 어렵다.
- 필요성: caption 생성으로 이미지 내용을 텍스트화해 BLEU·CIDEr·human evaluation 기준으로 검색과 보고서 자동화를 검증한다.

## Ⅱ. 구조 및 구성요소

```text
Image -> Vision Encoder -> Visual Features
  -> Language Decoder/LLM -> Caption -> Search/Report
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Vision Encoder | 객체·장면 특징 추출 | CNN, ViT |
| Attention/Fusion | 시각 특징과 단어 생성 연결 | cross-attention |
| Language Decoder | 자연어 캡션 생성 | Transformer decoder, LLM |
| Evaluator | 캡션 품질 평가 | CIDEr, BLEU, human review |

> 요약: 이미지 캡셔닝은 시각 특징을 추출하고 언어 디코더가 이를 자연어 설명으로 변환함.

## Ⅲ. 동작원리 및 흐름도

```text
이미지 입력 -> 전처리/패치화 -> 시각 특징 추출
  -> 객체·관계 주목 -> 문장 생성 -> 품질 검증
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 이미지 리사이즈·정규화 | 해상도 224~1024px |
| 2 | Vision Encoder로 특징 추출 | 객체 검출 recall ≥85% |
| 3 | Decoder가 설명 문장 생성 | CIDEr ≥1.0 또는 도메인 기준 |
| 4 | OCR·객체 누락 검증 | 핵심 객체 누락률 <5% |

> 요약: 이미지 특징을 추출하고 언어 모델이 문장을 생성한 뒤 객체·문자 누락 여부를 검증함.

## Ⅳ. 특징

| 구분 | 이미지 분류 | Image Captioning | 판단 포인트 |
|:---|:---|:---|:---|
| 출력 | 클래스 라벨 | 자연어 설명 | 보고서·검색에 적합 |
| 정보량 | 단일 범주 | 객체·관계·상황 | 세부 정보 포함 |
| 평가 | accuracy | CIDEr·BLEU·누락률 | 도메인 검수 필요 |
| 한계 | 설명 없음 | 환각·객체 누락 | OCR·검출 보완 |

> 요약: 이미지 캡셔닝은 이미지 내용을 업무 텍스트로 전환하지만, 세부 누락과 환각을 검증해야 함.

## Ⅴ. 실무 적용 및 결론

**적용 방안 3개:**
1. 현장 점검: 사진 캡션과 객체 검출 결과를 결합해 점검 보고서 초안 생성, 핵심 객체 누락률 5% 이하 관리
2. 이미지 검색: 캡션을 Elasticsearch와 벡터DB에 색인해 자연어 질의로 사진 검색
3. 접근성·감사: 이미지 대체 텍스트 자동 생성 후 민감정보 OCR 마스킹, 검수 로그 90일 보관

**결론 (2줄):**
- 기술사 판단: 이미지 내용을 텍스트 업무 흐름에 연결해야 하면 Image Captioning 적용
- 향후 방향: 단순 캡션에서 VQA·멀티모달 RAG와 결합한 근거 기반 이미지 질의응답으로 발전
