## 미리 알고가기

- 어댑터 튜닝 ($Adapter$ $Tuning$): 사전학습 완료된 거대 모델의 트랜스포머 레이어 사이사이에, 직렬(Serial) 또는 병렬(Parallel)로 소형 병목 신경망층(어댑터)을 삽입하여 해당 국부 가중치만 훈련시키는 PEFT의 초기 분과 기술임
- 병목 구조 ($Bottleneck$): 입력 차원 $d$를 저차원 $m$으로 압축(Down-projection)한 후 활성화 함수를 먹이고, 다시 차원 $d$로 복원(Up-projection)하여 가중치 파라미터 개수를 절감하는 콤팩트 아키텍처임
- 직렬 및 병렬 어댑터 ($Serial$ $vs$ $Parallel$): 기저 어텐션/FFN 레이어 바로 뒤에 연이어 삽입되는 구조(Serial)와, 기저 레이어 옆에 나란히 배치되어 잔차 연결로 융합되는 구조(Parallel)를 의미함
- 순방향 추론 지연 ($Latency$ $Overhead$): 서빙 시 가중치가 기하학적으로 고정 병합되지 못하고 매 추론 단계마다 추가 레이어를 관통 연산함에 따라 누적되는 밀리초 단위 시간 지연 오버헤드임

## Ⅰ. 개요

- **정의/개념**: Adapter Tuning은 원본 기반 모델의 기존 매개변수들은 고정한 채, 트랜스포머의 어텐션 및 피드포워드 레이어의 물리 경로 전후단에 다운/업 프로젝션으로 구성된 병목(Bottleneck) 신경망 어댑터를 삽입하고 이 추가된 소형 가중치만 업데이트하는 PEFT 기법임
- **배경/필요성**: 모든 레이어 매개변수를 갱신하는 전면 미세조정(Full FT)은 단가 포화와 저장 메모리 파편화를 가져오므로, 각 분야 맞춤형 정보(어댑터)를 캡슐화하여 착탈식으로 모듈 보존하고자 고안됨

## Ⅱ. 특징

- 기저 기반 모델의 신경망 내부 구조를 명시적으로 변조하여, 어텐션 계층 전후에 샌드위치 형태로 병목 뉴런층을 삽입함
- 기저 가중치를 고유 보존하므로, 동일 뼈대 모델을 여러 어댑터(고객사별 튜닝본)가 비동기 공유 적재해 메모리 충돌 없이 멀티 테넌시를 구현함
- 추론 가동 시 LoRA와 달리 원본 가중치 행렬에 덧셈 병합($Merge$)이 불가능해, 추가 이식된 병목 레이어를 매 스텝마다 연산하는 물리적 지연(Latency)이 누적됨

## Ⅲ. 종류 및 비교

| 판단 기준 | 전면 미세조정 (Full FT) | 어댑터 튜닝 (Adapter Tuning) | 저랭크 적응 (LoRA) |
|:---|:---|:---|:---|
| **가중치 이식 형태** | 레이어 구조 변환 전무 | 레이어 전후에 병목 어댑터 강제 직/병렬 삽입 | 선형 투사 레이어 단에 우회 저랭크 행렬 병렬 배치 |
| **추론 오버헤드** | 없음 (완벽 속도) | 존재함 (서빙 시 어댑터 레이어 연산이 추가 작동함) | 없음 (바이너리 덧셈 병합으로 런타임 지연 소거) |
| **삽입 아키텍처** | 범용 구조 그대로 학습 | Bottleneck (Down / Up-Projection) 구조 | Low-Rank ($A \times B$) 구조 |
| **실무적인 위상** | 대형 리소스 학습용 | PEFT 초기의 실험적 아키텍처 | 현대 PEFT의 업계 표준 ($de-facto$) |

> 요약: Full FT는 뇌를 통째 덮어쓰는 무거운 개조이고, Adapter Tuning은 연산로 중간에 병목 여과 필터링 파이프를 박아 넣는 직렬 보강이며, LoRA는 옆길을 뚫었다가 차후 합치는 병합식 개량임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 동결 기본 모델 | 트랜스포머 백본으로서 원형의 지능과 문맥 흐름 연산을 전담하는 상태 고정 층임 |
| 다운 프로젝션 | 입력 차원 $d$를 저차원 $m$(Bottleneck Dimension)으로 선형 압축해 파라미터 수를 줄이는 레이어임 |
| 업 프로젝션 | 압축 연산 및 활성화를 통과한 $m$ 차원 벡터를 다시 원래 $d$ 차원으로 복원하는 팽창 레이어임 |
| 스킵 커넥션 | 어댑터 계산이 원본의 특징 보존을 방해하지 않도록 우회 합산해 주는 잔차 연결선임 |

```text
[ Adapter Tuning (직렬 삽입) 내부 레이어 구조 ]
Transformer Layer Out (d) ---> [ Down-Projection ] ---> Dimension (m)
                                     │ (GeLU Activation)
                                     v
                                [ Up-Projection ]   ---> Dimension (d)
                                     │ (+ Skip Connection)
                                     v
Next Transformer Layer In (d) <------/
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 기반 모델   | --> | 레이어 사이  | --> | 어댑터 레이어| --> | 어댑터 스택 |
| 가중치 고정 |     | 병목모듈 이식|     | 가중치만 갱신|     | 착탈식 서빙 |
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **포트 획정** — 트랜스포머 레이어의 피드포워드 신경망 후단과 잔차 연결선(Residual)이 융합하는 진입 포트를 파싱함
2. **병목 이식** — 차원 축소 층과 차원 팽창 층으로 조립된 경량 어댑터 카드 블록을 직렬(Serial)로 체인 연결함
3. **병목 학습** — 기저 뇌 세포 가중치는 얼리고, 삽입된 어댑터의 다운/업 프로젝션 가중치들만 경사하강법으로 갱신 수렴함
4. **선별 가동** — 서빙 API 기동 시, 사용자의 테넌트 정보에 부합하는 어댑터 가중치 레이어를 런타임에 삽입 기동함

## Ⅵ. 실무 적용 및 유의점

1. 병목 차원인 Bottleneck Dimension($m$) 크기를 지나치게 축소하면 도메인 특징량이 소실되어 모델 지능이 급속 탈락하며, 너무 넓히면 파라미터 폭증과 지연이 비례 상승하므로, 반드시 parameter count 대비 정확도 향상 지표로 적합성을 검증해야 함
2. 실시간 초저지연이 생명인 밀리초($ms$)급 통신 서비스 환경에서 어댑터 레이어가 수십 층 이상 직렬 누적되면 순방향 지연 오버헤드가 한계선을 돌파해 UX를 망치므로, 지연 민감 실시간 시스템에서는 'LoRA 기반의 병합(Merge) 배포'를 우선 검토해야 함

## Ⅶ. 결론

- 어댑터 튜닝은 PEFT 개념을 정립해 캡슐화된 모듈 교체식 상용 서비스를 가속화시킨 역사적 핵심 최적화 스택이며, 설계자는 어댑터 통과에 따른 고유의 실시간 추론 지연 오버헤드와 Bottleneck 최적 차원 크기($m$)를 통계적으로 감사하여 강건한 서빙 체계를 완성해야 함
