## 미리 알고가기

- Edge TPU는 Google이 엣지 추론용으로 제공한 저전력 AI 가속기 계열임
- Coral 생태계와 TensorFlow Lite 기반 배포가 대표적인 활용 방식임
- INT8 양자화 모델 중심으로 최적화되어 있어 모델 제약을 먼저 고려해야 함

## Ⅰ. 개요

- **정의/개념**: Edge TPU는 카메라, 센서, 소형 게이트웨이 같은 엣지 장비에서 저전력으로 AI 추론을 수행하도록 설계된 Google 계열 전용 가속기임
- **배경/필요성**: 엣지 장비는 전력과 비용과 공간 제약이 커서 서버급 GPU를 둘 수 없으므로, 현장 추론을 가능하게 하는 소형 전용 가속기가 필요함

## Ⅱ. 특징

- INT8 양자화 추론에 최적화되어 작은 전력으로 높은 FPS를 제공함
- USB, PCIe, SoM 형태로 제공되어 카메라와 게이트웨이에 쉽게 통합할 수 있음
- Coral, TensorFlow Lite와 결합해 빠르게 프로토타입을 구성할 수 있음
- 지원 모델과 연산자 범위가 제한되어 범용 추론 엔진처럼 자유롭게 쓰기는 어려움

## Ⅲ. 종류 및 비교

| 판단 기준 | CPU 기반 엣지 추론 | Edge TPU | GPU 기반 엣지 추론 |
|:---|:---|:---|:---|
| 전력 효율 | 낮음 | 높음 | 중간 |
| 모델 유연성 | 높음 | 낮음 | 높음 |
| 실시간 영상 처리 | 제한적임 | 적합함 | 적합함 |
| 대표 용도 | 단순 규칙 처리 | 저전력 비전 추론 | 고성능 복합 추론 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Quantized Model | INT8 형태로 변환된 모델이 Edge TPU 실행의 전제가 되며 성능과 호환성을 함께 좌우함 |
| Edge TPU Accelerator | 전용 연산 경로로 비전 중심 추론을 빠르게 수행해 실시간 처리를 가능하게 함 |
| Host Processor | 입력 수집과 전후처리와 제어를 담당하며 Edge TPU와 역할을 분담함 |
| Deployment SDK | Coral와 TensorFlow Lite 도구가 모델 변환과 장비 배포와 모니터링을 지원함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 모델 학습/변환 | --> | INT8 컴파일    | --> | 장비 추론 실행  | --> | 결과 활용/제어 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **모델 학습 및 변환**: 학습된 모델을 TensorFlow Lite 기반 형식으로 정리함
2. **INT8 컴파일**: Edge TPU compiler를 통해 지원 연산 범위 안에서 실행 가능 모델로 변환함
3. **장비 추론 실행**: 호스트가 입력을 전달하고 Edge TPU가 저전력 추론을 수행함
4. **결과 활용 및 제어**: 탐지 결과를 알람, 분류, 제어 신호로 연결함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 엄격한 양자화와 연산자 제약 때문에 원본 모델을 그대로 배포하지 못해 개발 유연성이 떨어질 수 있음
   - 해결방안: QAT와 compiler compatibility 검증을 개발 단계에 포함하고 compiler pass rate와 task accuracy로 적합성을 검증함
2. 문제: 호스트와 가속기 사이 데이터 이동이 비효율적이면 가속기 성능이 높아도 전체 지연 시간이 줄지 않을 수 있음
   - 해결방안: 전처리 경량화와 파이프라인 최적화를 적용하고 end-to-end FPS와 I/O wait ratio로 병목을 검증함
3. 문제: 큰 모델이나 복합 생성형 작업은 메모리와 연산 범위를 넘어 Edge TPU 단독으로 처리하기 어려움
   - 해결방안: 경량 비전 작업에 범위를 한정하거나 상위 엣지 노드와 계층형 구성을 만들고 offload rate와 workload fit ratio로 설계를 검증함

## Ⅶ. 적용 사례

- 스마트 카메라 객체 탐지: 현장 영상에서 사람과 차량을 실시간 판별함, 확인 지표는 FPS와 false alarm rate임
- 리테일 매장 센서 분석: 진열대 상태와 방문자 흐름을 로컬에서 분석함, 확인 지표는 event detection latency와 bandwidth saving임
- 농업 모니터링 장비: 병충해나 작물 상태를 현장에서 판정함, 확인 지표는 device uptime과 accuracy임

## Ⅷ. 결론

Edge TPU는 엣지 비전 추론을 저전력으로 빠르게 처리하는 데 강점이 분명한 가속기이지만, INT8 제약과 모델 호환성을 전제로 업무 범위를 선별해야 효과적으로 쓸 수 있음.
