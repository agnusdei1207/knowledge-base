## 미리 알고가기

- 에이직형 가속기 ($ASIC$): 범용 프로세서와 달리, 특정 연산 목적(예: 텐서 처리)만을 전담하여 칩 수준에서 하드웨어 회로가 고정되어 설계된 주문형 반도체임
- $INT8$ 양자화: 부동소수점 $32$-bit($FP32$) 가중치 값을 $8$-bit 정수($INT8$) 범위($-128 \sim 127$)로 균일 압축하는 경량화 기법임
- 양자화 모의 훈련 ($QAT$, Quantization-Aware Training): 훈련 도중 양자화 손실을 미리 계산해 가중치를 자동 미세 보정하여, 추론 변환 시의 품질 손실을 최소화하는 학습 기법임
- $Coral$ 개발 키트: 구글이 Edge TPU를 상용 탑재해 스마트 카메라, 임베디드 보드 개발을 돕기 위해 출시한 하드웨어 개발 생태계 브랜드임

## Ⅰ. 개요

- **정의/개념**: Edge TPU는 구글이 개발한 엣지 컴퓨팅 전용 ASIC(주문형 반도체) 칩셋이며, TensorFlow Lite 프레임워크와 결합해 스마트 카메라 및 IoT 단말 내부에서 초저전력(보통 $2 \sim 4\text{W}$ 이내)으로 고성능 정수(INT8) 기반 인공지능 추론을 완수하는 에지 가속기임
- **배경/필요성**: 공장 스마트 팩토리나 매장 지능형 CCTV의 실시간 영상 분석 시, 수십 대 카메라 영상을 매 클라우드 서버로 송출하면 대역폭 병목과 기밀 유출 리스크가 크고 고가 GPU 카드를 실외 함체에 탑재할 수도 없으므로 저전력 소형 가속기가 요구됨

## Ⅱ. 특징

- 부동소수점($FP32$) 연산을 배제하고 정수형($INT8$) 매트릭스 연산에 특화 배치된 실리콘 게이트 회로 덕분에, 극소 전력만으로도 고화질 비전 영상 처리를 실시간 완수함
- $USB$ 동글($Dongle$), $M.2$ 슬롯 카드, 시스템 온 모듈($SoM$) 등 다양한 폼팩터로 출시되어, 기존 임베디드 SBC(싱글보드 컴퓨터) 보드에 손쉽게 가속 날개를 이식함
- 구글의 $Coral$ 생태계 및 Tensor Flow Lite Compiler와 밀착하여 작동하며, 엣지 기기의 백그라운드 실시간 보정, 스마트 리테일 탐지에 활용됨

## Ⅲ. 종류 및 비교

| 판단 기준 | CPU 기반 엣지 가속 | GPU 기반 엣지 가속 (Jetson 등) | 구글 Edge TPU 가속 |
|:---|:---|:---|:---|
| **물리 가속 유형** | 소프트웨어 에뮬레이션 | 범용 실시간 그래픽 병렬 연산 | 하드웨어 전용 정수형 $ASIC$ 고정 회로 |
| **전력 소모량** | 매우 낮음 | 중간 ~ 높음 (최소 $10\text{W} \sim 30\text{W}$) | 극도로 낮음 (최소 $2\text{W} \sim 4\text{W}$) |
| **적합한 모델** | 단순 회귀식, 전통적 $ML$ | $FP16$ 기반 거대 비전, 소형 언어 모델 | $INT8$ 양자화 기반 실시간 객체 검출 ($YOLO$ 등) |
| **컴파일 의존성** | 없음 | 낮음 (일반 실행 가능) | 매우 높음 (전용 TFLite 컴파일러 통과 필수) |

> 요약: CPU는 단순 계산에, GPU는 고품질 실수 연산에, Edge TPU는 극저전력으로 실시간 영상 객체 검출(정수 연산)에 최적임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 정수 양자화 모델 | $FP32$에서 $INT8$ 변환이 완료되어 Edge TPU 컴파일러의 통과 자격을 획득한 가중치 파일임 |
| $ASIC$ 연산 코어 | 시스톨릭 어레이($Systolic$ $Array$) 형태로 배치되어 정수 곱셈을 1클록에 병렬 연산하는 실리콘 다이임 |
| 호스트 데이터 통신 | $PCIe$ 또는 $USB$ 버스를 통해 이미지 프레임 데이터를 가속 칩에 태워 나르는 인터페이스임 |
| $TFLite$ 컴파일 엔진 | 모델 내 연산자 노드를 분석하여 가속 칩 내부 명령어로 번역하는 구글 전용 컴파일 툴체인임 |

```text
[ Edge TPU 연산 바인딩 토폴로지 ]
[TensorFlow Lite Model] -> [Edge TPU Compiler] -> Compilied Model (INT8)
                                                      ↓ (Host -> USB/PCIe)
                                           [Edge TPU ASIC Chipset Acceleration]
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| TFLite 모델 | --> | 정수형양자화 | --> | Edge TPU    | --> | 로컬 제어   |
| 훈련 및 추출|     | 변환/컴파일  |     | 하드웨어추론|     | 및 결과반환 |
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **그래프 변환** — 기존 신경망 모델을 모바일 장치용인 TensorFlow Lite 형식으로 우선 익스포트하여 파일로 추출함
2. **정수 양자화 컴파일** — 모델 컴파일러를 켜고 가중치를 $INT8$로 강제 캘리브레이션한 뒤, 칩이 이해하는 어셈블리 바이너리로 변환함
3. **타일 스트리밍** — 호스트 프로세서가 카메라 영상을 디코딩하여 특징 벡터를 $PCIe$/$USB$ 버스를 통해 가속 칩셋 캐시 메모리에 밀어 넣음
4. **ASIC 고속 연산** — 정수형 $ASIC$ 가속 어레이를 켜서 물체 침입이나 불량을 15ms 이내로 추론하고, 최종 경보 신호를 설비에 반환함

## Ⅵ. 실무 적용 및 유의점

1. Edge TPU compiler는 아주 엄격하여 $3D$ 합성곱이나 특이한 형상의 텐서 변환 연산자가 발견되면 컴파일을 즉각 거부하고 호스트 CPU로 연산을 넘겨 속도를 심각하게 떨어뜨리므로, 반드시 개발 전 '양자화 모의 훈련($QAT$)' 파이프라인을 수립하고 컴파일 통과율($Compiler$ $Pass$ $Rate$)을 검증해야 함
2. 기기 내에서의 전처리 오버헤드와 호스트-가속기 간 $USB$/$PCIe$ 통신 오버헤드가 전체 추론 병목을 차지하는 상황이 자주 생기므로, I/O 대기시간 비율($I/O$ $Wait$ $Ratio$)을 모니터링하여 병목을 감쇄하고 실효 초당 프레임 수($FPS$)를 계측해야 함

## Ⅶ. 결론

- Edge TPU는 엣지 비전 AI 현장에서 극저전력과 초저비용(TCO)으로 상시 기동을 담보하는 고성능 ASIC 가속기의 표준이며, 설계자는 전용 컴파일러의 엄격한 INT8 정수 구조 제약을 이해하고 데이터 버스 통신 오버헤드를 제어하는 최적화 아키텍처를 통합 배포해야 함
