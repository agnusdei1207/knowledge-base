# 📖 【암기용】 개념 완전 이해

## 한눈에
- **정의**: AI 모델(특히 안면 인식, 의료 진단 모델 등)에 질의(Query)를 던지고 반환되는 결과값(확률 점수)을 분석하여, 원래 이 모델을 **학습시킬 때 사용했던 사람의 얼굴이나 민감한 개인정보를 거꾸로 그려내는(역추론) 프라이버시 침해 공격**.
- **필요성**: 병원에서 특정 환자의 진료 기록으로 질병 예측 AI를 만들었음. 해커가 이 AI에게 수많은 질문을 던져서 "아, 이 AI가 이런 대답을 하는 걸 보니 학습 데이터 중에 당뇨병과 암에 걸린 40대 김 아무개 환자의 데이터가 들어있었겠군!" 하고 원본을 역추적해 내는 것을 막아야 함.
- **핵심 직관**: 스무고개와 몽타주. 해커가 AI에게 "눈이 큰 사람 사진이야? (확률 40%)", "코가 오뚝한 사람이야? (확률 80%)" 이런 식으로 노이즈가 섞인 가짜 이미지를 계속 던짐. AI가 뱉어내는 확률 점수(Confidence Score)가 점점 100%에 가까워지도록 입력값을 깎아서(최적화) 맞추다 보면, 어느새 AI를 학습시켰던 실제 사람(원본)의 얼굴 몽타주가 모니터에 완성됨.

## 깊이 이해
- **배경**: 딥러닝 모델은 본질적으로 학습 데이터의 통계적 특징을 가중치(Weight)에 고스란히 '기억(Memorization)'하는 특성이 있음. 모델 추출(Model Extraction)이 '모델의 기능'을 훔치는 거라면, 모델 역전은 그 모델이 품고 있는 '원본 개인정보'를 훔쳐내는 치명적 프라이버시 사고임.
- **작동 원리 (최적화 기반 역전 공격)**:
  1. 해커는 공격 대상인 특정 인물(예: 홍길동)의 라벨을 알고 있음. (목표: 홍길동의 진짜 얼굴 사진을 그려내자).
  2. 해커는 아무런 무작위 픽셀 이미지(노이즈)를 AI에게 입력함.
  3. AI는 "이 사진이 홍길동일 확률은 0.01%야"라고 확률(Softmax)을 반환함.
  4. 해커는 경사상승법(Gradient Ascent)이라는 수학적 기법을 써서, AI가 반환하는 **'홍길동일 확률'이 극대화되는 방향**으로 무작위 픽셀을 아주 조금씩 깎고 수정함.
  5. 수만 번을 반복하면(확률 99.9% 도달), 그 이미지는 해커가 본 적도 없는 홍길동의 실제 얼굴(학습 데이터)과 놀랍도록 비슷해짐.
- **구체 예시**: 2015년 Fredrickson 연구팀의 실험. 얼굴 인식 API에 역전 공격을 가해, 학습에 사용되었던 특정 개인의 생얼굴 윤곽과 특징을 알아볼 수 있을 수준으로 복원해 냄. 의료 모델에서도 환자의 유전적 특징을 역으로 뽑아내는 데 성공함.
- **흔한 오해/주의점**: "원본 사진의 픽셀이 100% 똑같이 복원되는가?" $\rightarrow$ 아님. 완벽한 복사본(Bit-by-bit)이 나오지는 않음. 하지만 모델이 기억하는 "그 사람의 가장 핵심적인 특징(큰 눈, 점의 위치 등)"이 그대로 복원되어 누군지 식별(Identification)하기엔 충분하므로 개인정보보호법(GDPR/개보법) 위반 소지가 매우 높음.

## 연결 개념
- **Membership Inference (멤버십 추론)**: 역전 공격의 사촌. 역전 공격이 "그 사람의 얼굴을 그려봐"라면, 멤버십 추론은 "내가 가진 이 사람 데이터가 네 학습 데이터에 포함(Member)된 적 있어?"라고 O/X를 캐내는 공격.
- **Differential Privacy (차등 프라이버시)**: 모델 역전을 막는 가장 근본적인 방어책. 애초에 학습 데이터에 수학적 노이즈를 섞어서 모델이 특정 개인의 얼굴을 선명하게 '기억'하지 못하도록 만드는 기술.
- **Confidence Masking**: API가 뱉어내는 99.9% 같은 구체적 확률값을 숨겨버리는 기초 방어법.

# 📝 【답안용】 시험 답안 템플릿
## 핵심 인사이트 (3줄 요약)
- **본질**: 타겟 모델의 API 추론 결과(Label 및 Confidence Score) 또는 경사도(Gradient) 정보를 활용하여, 모델이 학습 단계에서 기억(Memorize)한 특정 클래스(개인)의 민감한 원본 피처(Feature)와 훈련 데이터를 역으로 복원해 내는 프라이버시 침해 공격.
- **가치**: 안면 인식, 질병 예측, 신용 평가 등 민감 정보(PII/PHI)로 학습된 AI 모델이 퍼블릭 API로 노출될 경우, 단순한 추론(Inference) 호출만으로 대규모 개인정보 유출 사고(Data Breach)가 발생할 수 있는 중대 위협임.
- **판단 포인트**: 공격자는 모델의 출력(Softmax) 변화량을 추적하여 경사상승법(Gradient Ascent)으로 원본을 최적화하므로, API 응답의 정보량 축소(Truncation)와 차등 프라이버시(DP) 기반의 모델 훈련 아키텍처 도입이 방어의 핵심임.

## Ⅰ. 개요 및 필요성
- **정의**: 기계학습 모델의 블랙박스(Black-box) 또는 화이트박스(White-box) 환경에서, 모델의 출력을 분석해 특정 출력값(Class)을 유발하는 입력 데이터(Training Data)의 형태를 재구성(Reconstruction)하는 적대적 기법.
- **배경**: 딥러닝(특히 과적합, Overfitting된 모델)은 훈련 데이터의 지엽적 특징까지 가중치 네트워크에 암기하는 특성이 있어, 입력과 출력 간의 비선형 매핑 함수를 역연산하는 것이 가능해짐.
- **필요성**: GDPR 및 개인정보보호법의 강화에 따라 "AI 모델 자체도 개인정보로 간주될 수 있는가?"라는 법적 리스크를 해소하기 위해 프라이버시 보존형 머신러닝(PPML) 설계가 요구됨.

## Ⅱ. 모델 역전 공격의 메커니즘 (블랙박스 기준 최적화 기반)
타겟 라벨의 확률값을 극대화(Maximize)하는 입력 찾기.
1. **목표 설정**: 공격자는 타겟 라벨 $y$ (예: "환자 A")를 알고 있으며, 모델 함수 $f(x)$에 대해 $f(x) \approx y$ 가 되는 입력 $x$ (환자 A의 의료 정보)를 찾고자 함.
2. **초기화**: 더미(Dummy) 데이터 $x_{dummy}$ (무작위 픽셀/값)를 생성하여 API 질의.
3. **손실 함수(Loss) 계산**: 모델이 반환한 확률 점수(Confidence)를 바탕으로, 타겟 라벨 확률을 높이는 방향으로 역전파(Backpropagation) 또는 수치적 미분 수행.
4. **입력 업데이트 (Gradient Ascent)**: $x_{new} = x_{old} + \alpha \cdot \nabla_x f(x)$. 점수가 높아지는 방향으로 입력 데이터 $x$를 조금씩 수정 (수만 번 반복).
5. **특징 복원**: 최적화가 완료된 $x$는 원본 훈련 데이터와 시각적/통계적으로 높은 유사도(Fidelity)를 가지는 개인정보(몽타주)가 됨.

## Ⅲ. 역전 공격(Inversion) vs 추출 공격(Extraction)
| 비교 항목 | 모델 역전 (Model Inversion) | 모델 추출 (Model Extraction) |
|:---:|:---|:---|
| **공격 목적** | **학습에 사용된 원본 데이터(프라이버시) 탈취** | **모델의 기능 및 파라미터(지식재산, IP) 복제** |
| **공격의 표적** | 모델이 암기한 '훈련 데이터(Training Data)' | 모델의 '결정 경계(Decision Boundary)' |
| **피해 유형** | 개인정보 유출, 재식별(Re-identification) 리스크 | 비즈니스 로직 및 MLaaS 모델 자산 도난 |
| **핵심 방어** | 차등 프라이버시(DP-SGD), 정규화(Regularization) | 워터마킹, 예측 확률 반올림(Rounding) |

## Ⅳ. 모델 역전 방어 아키텍처 (Privacy-Preserving Defense)
훈련부터 추론 서빙까지 전 단계에 걸친 개인정보 비식별화.
1. **학습 단계 방어 (DP-SGD, 차등 프라이버시 적용)**:
   - 모델 가중치를 업데이트(Gradient Descent)할 때, 수학적으로 계산된 인공 노이즈(Laplacian/Gaussian Noise)를 섞음.
   - 개별 데이터의 특이점이 모델에 뚜렷하게 남지 않도록 암기(Memorization)를 억제함. (가장 강력하고 근본적인 방어).
2. **아키텍처 단계 (과적합 방지, Regularization)**:
   - L1/L2 Regularization, Dropout 비율 상향, Early Stopping 적용을 통해 모델이 훈련 데이터에 과적합되어 특징을 암기하는 현상 완화.
3. **추론(Serving) 단계 방어 (Confidence Masking)**:
   - 외부 사용자에게 API 응답 시, 공격자가 Gradient를 계산할 수 없도록 Softmax 확률값을 노출하지 않고 Top-1 라벨(Class Name)만 반환하거나, 확률을 10% 단위로 절사(Truncation)하여 제공.

## Ⅴ. 실무 적용 및 결론
- **판단 지표**: 모델의 과적합(Overfitting) 차이(Train Accuracy - Test Accuracy 격차), 차등 프라이버시 프라이버시 예산(Epsilon, $\epsilon$) 값의 최적화 수준, 민감 클래스에 대한 역전 이미지 생성(SSIM 등) 유사도 지수.
- **실무 설계**: 금융사의 AI 기반 '비대면 신분증(얼굴) 진위 확인 시스템'. 고객 수백만 명의 얼굴 데이터로 모델 파인튜닝(SFT) 수행 예정. 보안팀에서 역전 공격으로 인한 고객 얼굴 복원 리스크 제기. 방어 아키텍처 수립: 1) 데이터 관점: 얼굴 이미지의 핵심 벡터를 추출한 뒤 원본 이미지는 즉시 파기. 2) 학습 관점: PyTorch Opacus 라이브러리를 도입하여 DP-SGD 기반 훈련 수행($\epsilon=3$ 이하로 셋팅하여 개별 얼굴 특징 암기 방지). 3) API 관점: 모바일 앱으로 반환되는 응답 페이로드에 실수형 확률(`0.985...`)을 제거하고 `true/false` 불리언(Boolean) 값만 반환. 역전 공격 성공률 0% 달성 및 컴플라이언스 준수.
- **결론**: 모델 역전 공격은 데이터 프라이버시 보호의 책임이 이제 DB 암호화를 넘어 머신러닝의 알고리즘 내부(Model Weights)까지 확장되었음을 시사한다. 완벽한 프라이버시 보호(DP)는 모델 정확도(Utility)의 하락을 동반하므로, 기업은 AI 서비스의 비즈니스 중요도에 따라 프라이버시-효용 트레이드오프(Trade-off)를 섬세하게 조율해야 한다.

### 🔀 문제 유형별 목차 전환
- **Ⅱ·Ⅲ 강조 (개념/원리형)**: 페더레이티드 러닝(Federated Learning) 환경에서 악의적인 중앙 서버가 클라이언트가 전송한 그래디언트(Gradient)만으로 클라이언트의 로컬 원본 데이터를 완벽히 복원해 내는 'Deep Leakage from Gradients (DLG)' 공격의 수학적/수치해석학적 원리 분석.
- **Ⅴ·Ⅵ 강조 (실무/설계형)**: 모델 역전 및 멤버십 추론 공격을 방어하기 위해 도입되는 Private Aggregation of Teacher Ensembles (PATE) 아키텍처 중심의 프라이버시 보존형 머신러닝 파이프라인 설계 및 운영 방안.
