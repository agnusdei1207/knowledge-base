# 📖 【암기용】 개념 완전 이해

> 목적: Model Inversion을 처음 봐도 완벽히 이해하게 만든다.

## 한눈에
- **정의**: 모델 출력과 파라미터 정보를 이용해 학습 데이터의 민감 특징이나 원본에 가까운 입력을 추론하는 공격
- **왜 필요한가**: 모델 API가 확률값·confidence를 제공하면 학습 데이터의 대표 패턴이나 개인 정보가 역추론될 수 있음.
- **핵심 직관**: 모델이 배운 답변 습관을 거꾸로 따라가 학습에 쓰인 사람의 특징을 추정하는 공격임.

## 깊이 이해
- **배경·문제의식**: AI 모델은 학습 데이터 통계를 내재화하므로 출력 정보량이 많을수록 민감 특징 복원 가능성이 증가함.
- **작동 원리**: 공격자는 특정 클래스의 확률을 최대화하는 입력을 최적화하거나 confidence 변화를 분석해 대표 이미지·속성을 복원함.
- **비유**: 선생님 채점 기준과 점수 반응을 계속 관찰해 원래 모범답안의 내용을 거꾸로 재구성하는 행위임.
- **구체 예시**: 얼굴 인식 모델에서 특정 사용자 ID 확률을 최대화하는 이미지를 생성해 훈련 얼굴과 유사한 형태를 복원함.
- **흔한 오해·주의점**: 원문 전체가 항상 복원되는 것은 아니다. 그러나 민감 속성, 대표 특징, 회원 여부 노출도 사고가 될 수 있음.

## 연결 개념
- Membership Inference — 특정 데이터 포함 여부 추론
- Differential Privacy — 개인 기여도 노출 제한
- Model Extraction — API 응답을 활용한 모델 기능 복제

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: Model Inversion은 모델 출력으로 학습 데이터의 민감 특징을 역추론하는 공격임.
> 2. **가치**: 의료·생체·금융 모델에서 개인 특징 노출과 재식별 위험을 유발함.
> 3. **판단 포인트**: 응답 정보량, confidence 노출, DP, 접근 제어를 함께 관리해야 함.

## Ⅰ. 개요 및 필요성

Model Inversion은 학습데이터 역추론 공격이다. AI 모델은 학습 데이터의 통계와 특징을 반영한다. 민감 분야 모델은 출력 정보량과 반복 질의를 제한해야 한다.

## Ⅱ. 구조 및 구성요소

```text
Target Model → Query/Gradient Signal → Optimization
  → Reconstructed Feature → Privacy Risk
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Target Model | 공격 대상 모델 | API/white-box 가능 |
| Output Signal | 확률·confidence·logit | 정보량 결정 |
| Optimizer | 목표 클래스 입력 복원 | gradient/ascent |
| Defense | 응답 제한·DP·감사 | 반복 질의 제어 |

> 요약: 모델 역전은 출력 신호를 이용해 목표 클래스 특징을 최적화 방식으로 복원함.

## Ⅲ. 동작원리 및 흐름도

```text
목표 클래스 선택 → 반복 질의 → 출력 변화 분석
  → 입력 특징 복원 → 위험 평가
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 민감 클래스와 공격 목표 정의 | PII/PHI 영향 평가 |
| 2 | confidence·logit 반복 수집 | 계정별 rate limit |
| 3 | 최적화로 입력 특징 복원 | 유사도·식별 가능성 측정 |
| 4 | 방어 적용 후 재시험 | 복원 성공률 1% 이하 |

> 요약: Model Inversion은 반복 출력 분석으로 민감 특징을 복원하므로 응답 최소화와 공격 테스트가 필요함.

## Ⅳ. 특징

| 구분 | Model Extraction | Model Inversion | 판단 포인트 |
|:---|:---|:---|:---|
| 목표 | 모델 기능 복제 | 학습 데이터 특징 복원 | 보호 자산 구분 |
| 입력 | 대량 쿼리·응답 | 목표 클래스·confidence | 정보량 관리 |
| 피해 | IP 유출 | 개인정보·민감속성 노출 | 규제 리스크 |
| 방어 | 워터마킹·rate limit | DP·응답 제한·감사 | 민감 모델 우선 |

> 요약: Model Inversion은 모델 자산보다 학습 데이터 개인정보 보호에 초점을 둔 역추론 공격임.

## Ⅴ. 실무 적용 및 결론

**적용 방안 3개:**
1. 응답 제한: logit과 세부 confidence를 숨기고 업무상 필요한 label 또는 구간화된 점수만 제공
2. 학습 보호: DP-SGD, regularization, early stopping을 적용하고 회원 추론·역전 공격 성공률을 측정
3. 운영 감시: 동일 클래스 반복 질의, 경계 탐색, confidence 수집 패턴을 탐지하고 임계 초과 계정 차단

**결론 (2줄):**
- 기술사 판단: 생체·의료·금융 모델은 Model Inversion 테스트를 배포 승인 조건으로 포함
- 향후 방향: Model Inversion 방어는 DP, API 응답 최소화, AI 보안 모니터링과 결합됨
