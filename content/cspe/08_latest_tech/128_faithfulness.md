## 미리 알고가기

- Faithfulness는 답변이 검색 문맥에 근거해 작성됐는지를 보는 생성 단계 지표임
- 질문에 잘 답했더라도 문맥에 없는 내용을 추가하면 Faithfulness는 낮아짐
- 환각 억제 수준을 직접 판단하는 핵심 지표임

## Ⅰ. 개요

- **정의/개념**: Faithfulness는 생성 답변의 주장과 문장이 제공된 문맥에서 실제로 뒷받침되는지를 측정해 답변의 근거 일치도를 평가하는 지표임
- **배경/필요성**: RAG는 검색을 붙여도 모델이 외부 지식이나 추측을 섞을 수 있으므로, 근거 기반 응답인지 따로 검증할 기준이 필요함

## Ⅱ. 특징

- 질문 적합성보다 근거 충실성을 우선 측정해 환각 탐지에 강함
- 같은 정답 취지라도 문맥에 없는 내용이 섞이면 점수가 낮아질 수 있음
- 검색 품질이 높아도 프롬프트나 모델 성향 때문에 낮아질 수 있음
- 규제 산업이나 출처 중심 답변에서 가장 중요한 생성 지표로 쓰임

## Ⅲ. 종류 및 비교

| 판단 기준 | Faithfulness | Answer Relevancy | Exact Match |
|:---|:---|:---|:---|
| 평가 초점 | 문맥 근거 일치 | 질문 의도 적합 | 정답 문자열 일치 |
| 환각 탐지력 | 높음 | 중간 | 낮음 |
| 의미 유연성 | 높음 | 높음 | 낮음 |
| RAG 운영 활용성 | 매우 높음 | 높음 | 낮음 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Answer Claim | 답변 문장을 사실 주장 단위로 나눠 문맥과 대조할 수 있게 함 |
| Context Evidence | 검색된 문맥에서 실제 근거 구절을 찾아 답변과의 entailment 여부를 판단함 |
| Judge Logic | 문장별로 근거 가능 여부를 판정해 최종 충실성 점수로 집계함 |
| Failure Analysis | unsupported claim을 따로 모아 프롬프트, 검색, 모델 문제를 분리 진단함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 답변 분해      | --> | 근거 문맥 탐색 | --> | 주장-근거 대조 | --> | 충실성 점수화 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **답변 분해**: 생성 답변을 주장 단위 문장으로 나눔
2. **근거 문맥 탐색**: 각 주장에 대응하는 문맥 근거를 찾음
3. **주장과 근거 대조**: 문맥이 주장을 뒷받침하는지 판단함
4. **충실성 점수화**: 근거된 주장 비율로 최종 점수를 산출함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 검색 문맥이 충분해도 모델이 일반 상식을 덧붙여 unsupported claim을 생성하면 환각 위험이 커짐
   - 해결방안: citation prompt와 answer constraint를 강화하고 unsupported claim rate와 Faithfulness로 개선 효과를 검증함
2. 문제: 긴 답변일수록 일부 문장만 근거를 벗어나도 전체 신뢰도가 크게 훼손될 수 있음
   - 해결방안: 문장 단위 평가와 span citation을 적용하고 sentence-level error ratio와 user trust score로 검증함
3. 문제: judge 모델이 애매한 표현을 과도하게 허용하면 실제 환각을 놓칠 수 있음
   - 해결방안: 보수적 채점 프롬프트와 human review 샘플을 병행하고 false acceptance rate와 agreement score로 검증함

## Ⅶ. 적용 사례

- 금융 상담 RAG에서는 규정 근거 없는 설명을 차단하고 확인 지표는 Faithfulness와 unsupported claim rate임
- 의료 지식 QA에서는 근거 문헌 범위 내 답변만 허용하고 확인 지표는 citation coverage와 expert review score임
- 사내 규정 챗봇에서는 최신 규정 문맥 기반 답변을 검증하고 확인 지표는 hallucination rate와 CSAT임

## Ⅷ. 결론

Faithfulness는 답변이 맞아 보이느냐보다 근거 문맥 안에서만 말했느냐를 묻는 지표이므로, 출처 제약과 문장 단위 검증이 신뢰성 확보의 핵심임.
