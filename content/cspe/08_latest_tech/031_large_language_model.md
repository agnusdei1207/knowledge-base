# 📖 【암기용】 개념 완전 이해

> 목적: LLM을 처음 봐도 완벽히 이해하게 만든다.

## 한눈에
- **정의**: 수십억~수조 파라미터로 자연어를 확률적으로 생성·이해하는 Transformer 기반 신경망
- **왜 필요한가**: 기존 NLP는 태스크마다 별도 모델을 학습했지만, LLM은 하나의 모델로 번역·요약·코딩·추론을 수행함.
- **핵심 직관**: 방대한 텍스트를 읽고 "다음 단어 맞히기"를 수조 번 반복한 결과, 언어 구조·지식·추론 능력이 창발함.

## 깊이 이해
- **배경·문제의식**: BERT(2018)는 양방향 이해에 강했지만 생성이 약했고, GPT 계열은 자기회귀 생성으로 유연성을 확보함. 파라미터가 100B를 넘자 In-Context Learning·Chain-of-Thought 등 창발 능력이 나타남.
- **작동 원리**: 사전학습(대규모 코퍼스 Next-Token Prediction) → 지시 미세조정(Instruction Tuning) → 인간 피드백 정렬(RLHF/DPO). 추론 시 프롬프트를 토큰화 → Self-Attention으로 문맥 반영 → 토큰 단위 확률 생성.
- **비유**: 수천만 권을 읽은 학자에게 "이 문장 뒤에 올 말은?"을 물으면, 지식과 문맥을 종합해 답하는 것과 같음.
- **구체 예시**: GPT-4(1.8T 파라미터 추정)는 미국 변호사시험 상위 10%, GPT-4o 추론 지연 p50 320ms.
- **흔한 오해·주의점**: LLM이 "이해"하는 것이 아니라 통계적 패턴 매칭임. 할루시네이션(사실이 아닌 내용 생성)은 구조적 한계이므로 RAG·Grounding으로 보완 필요.

## 연결 개념
- Transformer — LLM의 핵심 아키텍처
- Foundation Model — LLM은 대표적 기반모델
- RLHF — 인간 선호 기반 정렬 기법

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: LLM은 Transformer 기반 자기회귀 모델로, 대규모 코퍼스 사전학습과 정렬을 통해 범용 언어 능력을 획득함.
> 2. **가치**: 단일 모델이 번역·요약·코딩·추론을 수행하여 태스크별 모델 개발 비용을 제거함.
> 3. **판단 포인트**: 파라미터 규모·학습 데이터·정렬 기법에 따라 창발 능력과 할루시네이션 수준이 결정됨.

---

## Ⅰ. 개요 및 필요성

LLM은 수십억 이상 파라미터의 자기회귀 언어 모델임. NLP 태스크마다 별도 모델을 구축하던 비용·시간 한계를 해소하고, 하나의 모델로 다양한 언어 작업을 수행함. 기술사 답안에서는 구조, 학습 파이프라인, 운영 통제를 함께 제시해야 함.

---

## Ⅱ. 구조 및 구성요소

```text
┌──────────┐   ┌──────────────┐   ┌───────────┐
│ Tokenizer│──▶│ Transformer  │──▶│  LM Head  │
│          │   │ (N Layers)   │   │ (Softmax) │
└──────────┘   └──────┬───────┘   └───────────┘
                      │
          ┌───────────┼───────────┐
          ▼           ▼           ▼
     Self-Attn   Feed-Forward  Layer Norm
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Tokenizer | 텍스트→토큰 ID 변환 | BPE/SentencePiece, 어휘 32K~128K |
| Transformer Block | Self-Attention+FFN 반복 | 레이어 수 32~120, 파라미터 7B~1.8T |
| LM Head | 다음 토큰 확률 분포 출력 | Temperature·Top-p로 샘플링 제어 |
| 정렬 모듈 | RLHF/DPO로 인간 선호 반영 | 보상 모델 또는 직접 선호 최적화 |

> 요약: LLM은 토크나이저-Transformer 블록-LM Head의 3단 구조이며, 정렬 모듈로 출력 품질을 통제함.

---

## Ⅲ. 동작원리 및 흐름도

```text
대규모 코퍼스 → 사전학습(NTP) → 지시 미세조정(SFT)
    → RLHF/DPO 정렬 → 추론 서빙(KV Cache + 양자화)
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 사전학습: 수조 토큰 NTP | Perplexity, 학습 Loss 수렴 |
| 2 | 지시 미세조정(SFT) | 벤치마크 정확도(MMLU 86%+) |
| 3 | RLHF/DPO 정렬 | 인간 선호 승률, 안전성 평가 |
| 4 | 추론 서빙: KV Cache+INT4 양자화 | p95 TTFT 500ms, 처리량 50 req/s |

> 요약: 사전학습→미세조정→정렬→서빙의 4단계 파이프라인이며, 각 단계별 정량 지표로 품질을 통제함.

---

## Ⅳ. 특징

| 구분 | 기존 NLP 모델 | LLM | 수치·판단 포인트 |
|:---|:---|:---|:---|
| 태스크 대응 | 태스크별 모델 각각 학습 | 단일 모델 멀티태스크 | 모델 관리 비용 N→1 |
| 파라미터 | 수백만~수억 | 수십억~수조 | GPU 메모리 7B=14GB(FP16) |
| 창발 능력 | 없음 | ICL·CoT·도구 사용 | 100B+ 이후 관찰 |
| 할루시네이션 | 해당 없음 | 구조적 한계 | RAG로 사실 근거율 90%+ 확보 |

> 요약: LLM은 멀티태스크 범용성과 창발 능력을 제공하지만, 할루시네이션·비용 관리가 운영 핵심축임.

---

## Ⅴ. 실무 적용 및 결론

**적용 방안 3개:**
1. 추론 비용: INT4/INT8 양자화+KV Cache+vLLM PagedAttention으로 GPU 메모리 70% 절감, 처리량 3배 향상
2. 할루시네이션 통제: RAG(벡터 DB 검색) + Grounding으로 사실 근거율 90% 이상 확보
3. 보안·컴플라이언스: 프롬프트 인젝션 필터, PII 마스킹, 출력 가드레일(Guardrails) 적용

**결론 (2줄):**
- 기술사 판단: 내부 데이터 활용 시 온프레미스 sLLM(7B~13B), 범용 업무는 API 기반 클라우드 LLM을 선택함.
- 향후 방향: MoE 아키텍처·추론 특화 모델(o3, DeepSeek-R1)·멀티모달 확장으로 비용 대비 성능 최적화가 진행됨.
