## Ⅰ. 개요
- **정의**: 수천억 파라미터 규모의 Transformer 기반 모델로, 대규모 텍스트를 자기지도 학습하여 다음 토큰을 예측하는 범용 언어 처리 엔진
- **배경/필요성**: RNN/LSTM은 장기 의존성 소실과 순차 연산으로 대규모 학습이 불가능했으며, 태스크별 개별 모델 구축은 비용·유지보수 측면에서 한계에 도달함. 단일 모델로 번역·요약·코딩·추론을 동시에 처리하는 범용 언어 엔진이 필요함
- **비유**: 수백억 권의 책을 읽은 앵무새 — 다음 단어 예측만으로 언어의 법칙 자체를 체득함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| LLM의 학습 파이프라인과 범용성 원리 | Pre-training → SFT → RLHF 3단계 파이프라인 | 단순 "다음 단어 예측기"로 축소 서술 금지, 창발적 능력(Emergence) 언급 필수 |
| Scaling Law와 창발성 관계 | 파라미터·데이터·컴퓨팅 3축 확장 시 성능의 멱급수적 향상 | Transformer 내부 구조는 034 참조로 위임, 여기선 학습 전략 중심 |

> 요약: 대규모 자기지도 학습 + Scaling Law를 통해 범용 언어 능력을 획득하는 딥러닝 모델

## Ⅱ. 구성요소
```text
+---------------------+     +---------------------+     +------------------+
|  Pre-training       |---->|  SFT (Supervised    |---->|  RLHF            |
|  (자기지도 학습)     |     |   Fine-Tuning)      |     |  (인간 피드백     |
|  - Next Token       |     |  - Q&A 쌍 학습      |     |   강화학습)       |
|    Prediction       |     |  - Instruction       |     |  - 보상 모델     |
|  - Masked LM        |     |    Following         |     |  - 정렬(Align)   |
+---------------------+     +---------------------+     +------------------+
         |                                                       |
         v                                                       v
+---------------------+                              +------------------+
|  Tokenizer          |                              |  Inference       |
|  + Embedding        |                              |  (Autoregressive |
|  + Positional Enc.  |                              |   생성)           |
+---------------------+                              +------------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| Pre-training | 수조 토큰의 무라벨 텍스트로 다음 토큰 예측을 반복하여 언어 구조·세계 지식을 파라미터에 압축 | 백과사전 통독 |
| SFT | 양질의 지시-응답(Instruction-Response) 쌍으로 대화 형식 학습, 앵무새를 비서로 전환 | 비서 교육 |
| RLHF | 인간 평가자의 선호도 투표를 보상 신호로 강화학습, 도덕·안전성 정렬(Alignment) 수행 | 예절 교육 |
| Tokenizer/Embedding | 텍스트를 서브워드 단위로 분할 후 고차원 벡터로 매핑, 위치 정보(Positional Encoding)를 합산 | 단어→좌표 변환 |

> 요약: Pre-training → SFT → RLHF 3단계 파이프라인으로 범용 언어 능력을 획득·정렬

## Ⅲ. 절차
```text
+----------------+     +----------------+     +----------------+     +----------------+
| 1. 데이터 수집  |---->| 2. 사전 학습    |---->| 3. 정렬 학습    |---->| 4. 추론/서빙   |
|  (Corpus)      |     |  (Pre-train)   |     |  (SFT+RLHF)   |     |  (Inference)   |
+----------------+     +----------------+     +----------------+     +----------------+
```

1. **데이터 수집** — 웹 크롤링·위키·코드 리포지터리 등 수조 토큰 규모의 비라벨 코퍼스를 구축하고 품질 필터링(중복 제거, 유해 콘텐츠 차단)을 수행
2. **사전 학습** — 수천 GPU 클러스터에서 Causal LM(다음 토큰 예측) 또는 Masked LM(빈칸 채우기)을 수개월간 반복하여 파라미터에 언어 법칙을 압축
3. **정렬 학습** — SFT로 지시 수행 능력을 부여한 뒤, RLHF/DPO로 인간 선호에 정렬하여 안전하고 유용한 응답을 생성하도록 조정
4. **추론/서빙** — 사용자 프롬프트를 입력받아 Autoregressive 방식으로 토큰을 순차 생성, KV Cache·양자화(Quantization)로 지연시간 최적화

> 요약: 코퍼스 구축 → 대규모 사전학습 → 정렬(SFT+RLHF) → 추론 서빙의 4단계 파이프라인

## Ⅳ. 문제점
- 환각(Hallucination): 학습 데이터에 없는 사실을 그럴듯하게 생성 — 확률 분포 기반 생성 특성상 사실 검증 메커니즘 부재
- 지식 단절(Knowledge Cut-off): 학습 시점 이후 정보를 알 수 없음 — 정적 파라미터에 지식이 고정되어 실시간 업데이트 불가
- 추론 비용 과다: 수천억 파라미터 모델의 GPU 서빙 비용이 월 수억 원 수준 — 토큰 단위 종량제 과금으로 트래픽 증가 시 비용 폭증

> 요약: 환각·지식 단절·추론 비용이 엔터프라이즈 도입의 3대 장벽

## Ⅴ. 개선방안
1. 단기: RAG(검색 증강 생성)를 통해 외부 지식 DB를 실시간 검색·주입하여 환각과 지식 단절을 동시에 완화
2. 중기: sLLM(7B~8B급 경량 모델) 온프레미스 배포 + LoRA/QLoRA 경량 미세조정으로 비용 90% 절감 및 보안 확보
3. 장기: 멀티모달(텍스트·이미지·오디오 통합) 모델로 확장하여 범용 AI Agent의 핵심 두뇌로 진화

- 환각 리스크: 확률 기반 생성 특성 → RAG + Grounding + 출처 인용 강제 (지표: 환각률 5% 이하)
- 비용 리스크: 토큰 종량제 폭증 → 모델 양자화(INT4) + KV Cache + Speculative Decoding (지표: 토큰당 비용 50% 절감)
- 보안 리스크: 사내 데이터 외부 유출 → 프라이빗 클라우드 배포 + PII 마스킹 파이프라인 (지표: 민감정보 유출 건수 0건)

> 요약: RAG로 환각 완화, sLLM+양자화로 비용 절감, 프라이빗 배포로 보안 확보

## Ⅵ. 전망
- 향후 발전 방향: 텍스트 전용 LLM → 멀티모달 대형 모델(LMM) → 자율 계획·실행하는 Agentic AI의 핵심 추론 엔진으로 진화
- 기술사적 판단: LLM의 본질은 "추론 엔진(Reasoning Engine)"이며, 기억 저장소가 아님. LLM의 파라미터를 진실의 원천(Source of Truth)으로 신뢰하는 아키텍처는 반드시 실패함
- 기술사 제언: 엔터프라이즈 도입 시 LLM을 검색된 외부 데이터를 정리·요약하는 언어 처리 레이어로 한정하고, 사실 검증은 RAG·Grounding·Human-in-the-Loop로 분리 설계할 것
