## 미리 알고가기

- 인간 피드백 강화학습 ($RLHF$, Reinforcement Learning from Human Feedback): 인공지능이 인간 가치관, 유용성, 안전 규범에 정렬($Alignment$)되도록, 인간의 선호도 평가 데이터를 보상 신호로 삼아 정책 모델을 학습하는 3단계 강화학습 기법임
- 보상 모델 ($Reward$ $Model$, RM): 인간 평가단의 답변 선호 데이터셋을 학습하여, 특정 질문에 모델이 생성한 임의의 응답이 인간 입맛에 얼마나 부합하는지 척도 점수로 평점 매겨주는 판정 모델임
- 근접 정책 최적화 ($PPO$, Proximal Policy Optimization): 정책 모델 업데이트 시 기존 파라미터 분포에서 지나치게 탈탈 벗어나 성능이 파괴되는 것을 막기 위해, 변화 비율 클리핑(Clipping)을 두어 안정적 수렴을 돕는 대표 강화학습 알고리즘임
- 정렬 세금 ($Alignment$ $Tax$): 모델을 지나치게 도덕적이거나 안전하게 정렬시키다 보니, 본래 보유하고 있던 창의적 발상이나 문제 해결 지능, 수리 연산 능력이 부분 삭감되는 부작용임

## Ⅰ. 개요

- **정의/개념**: RLHF는 모델의 불건전성 요소를 차단하고 인간 친화적 톤을 고수하도록, 인간 평가단이 도출한 복수의 후보 답변 선호도(Preference)를 보상 모델(RM)에 학습시키고, 이 점수를 환경의 보상으로 받아 근접 정책 최적화(PPO) 알고리즘을 통해 에이전트 정책 가중치를 미세 정렬하는 3단계 강화학습임
- **배경/필요성**: 기존 지도 미세조정($SFT$) 방식은 정답이 유일한 태스크에는 유용하나 "어떤 답안이 더 자연스러운가?", "어떤 표현이 더 무해한가?" 등 고차원적인 인간 주관적 도덕 기준과 가치관($HHH$ : Helpful, Honest, Harmless)에 일치시키기 위해 필수 도입됨

## Ⅱ. 특징

- 정량적인 로스 계산이 불가능한 '정중한 응답 태도', '도움성 높은 뉘앙스' 등 주관적 정성 품질을 통제 및 모델에 체화시킴
- 훈련 과정에서 정밀도 폭망을 방지하기 위해 동결 $SFT$ 모델과의 쿨백-라이블러($KL$) 발산 규제 장치를 보상 목적 함수에 결합함
- 사람이 가늠하는 채점(보상)의 허점을 교묘히 찔러 점수만 억지로 높게 받는 '보상 해킹($Reward$ $Hacking$)' 오류 현상을 원천 방지해야 함

## Ⅲ. 종류 및 비교

| 판단 기준 | 지도 미세조정 (SFT) | 인간 피드백 강화학습 (RLHF) | 직접 선호 최적화 (DPO) |
|:---|:---|:---|:---|
| **훈련 데이터 유형** | 자연어 지시 - 모범 답안 페어 | $1$질문 - 여러 후보 답변의 인간 선호 랭킹 | $1$질문 - 선호 답변/비선호 답변 쌍 |
| **보상 모델 (RM)** | 없음 | 필수 (인간의 선호를 대행해 점수화) | 없음 (정책 모델 자체를 RM으로 간접 활용) |
| **강화학습 (PPO)** | 없음 | 필수 (행동 정책의 비동기 수렴 조율) | 없음 (단일 로스 최소화로 강화학습 우회) |
| **시스템 구축 난도** | 보통 | 매우 높음 (4개 모델 메모리 동시 적재) | 중간 (단일 일반 지도 학습 루프 사용) |

> 요약: SFT는 단순 모범 답안 필기이고, RLHF는 인간의 기분(보상)을 파악하며 훈련하는 본격 대화 훈련이며, DPO는 복잡한 보상 모델과 PPO 강화학습을 걷어내고 직접 선호쌍을 타격하는 간소화 설계임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 초기 $SFT$ 정책 | 강화학습 에이전트의 모태로서 최소한의 글짓기 요령을 체득한 출발지 모델임 |
| 보상 모델 ($RM$) | 인간 평가단의 좋음/싫음 판정 데이터를 수식화하여 연산 스코어로 뱉는 판정기임 |
| $PPO$ 최적화기 | 행위자-비판자($Actor-Critic$) 아키텍처를 가동해 정책 가중치를 갱신하는 엔진임 |
| $KL$ 패널티 필터 | 갱신 중인 정책이 원본 SFT 영역에서 멀어져 미치는 성능 붕괴를 예방하는 감쇄기임 |

```text
[ RLHF 3단계 파이프라인 아키텍처 ]
1 단계: [ Base Model ] + SFT 데이터셋 ---> [ SFT Model (초기 정책) ]
2 단계: SFT 모델 출력물 수집 ---> 인간의 선호도 라벨링 ---> [ Reward Model 학습 ]
3 단계: [ SFT Model (Policy) ] <--- PPO Optimization w/ KL-Penalty <--- [ Reward Model Score ]
- 훈련 중에 가속을 위해 정책(Policy), 참조(Reference), 보상(Reward), 가치(Value) 4개 모델을 동시에 메모리에 올려 강화학습함
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| SFT 에이전트| --> | 응답쌍에 대한| --> | 보상 함수로 | --> | PPO 알고리즘|
| 셋업 및 가동|     | 선호도 수집  |     | 보상 모델 훈련|     | 정책 갱신/QA|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **에이전트 준비** — 지시어 튜닝(SFT)을 통과해 사용자의 질문 의도를 겨우 읽을 줄 아는 초기 에이전트 정책을 셋업함
2. **선호 피드백 수집** — 동일 질문에 대해 에이전트가 뱉은 복수 응답 중, 인간이 '더 나은 것($y_w$)'과 '구린 것($y_l$)'을 골라 라벨링함
3. **보상함수 근사** — 브래들리-테리($Bradley-Terry$) 수학 모델에 의거해 선호 랭킹 점수 오차를 구하고, 보상 모델($RM$)을 단독 학습함
4. **강화학습 집행** — PPO 알고리즘을 켜서, 정책 모델이 RM의 칭찬 점수를 많이 먹도록 뉴런을 정교하게 교정하며 $KL$ 제약을 가함

## Ⅵ. 실무 적용 및 유의점

1. 보상 모델의 채점 공식 내 수학적 허점을 파고들어, 실제 답변 내용은 영양가가 없으면서 겉포장만 길고 화려하게 꾸며 보상 모델 점수만 강제 탈취하는 '보상 해킹($Reward$ $Hacking$)'이 발생하므로, 반드시 정책 모델과 SFT 모델 간의 $KL$ 패널티 임계치를 억제 제어하고 실제 인간 평가 통계로 합격 여부를 정기 검증해야 함
2. 유해 요청 필터링(안전성)을 너무 강박적으로 정렬 적용하면, "폭탄주 제조법을 알려줘" 같은 평범한 일반 챗 질문이나 단순히 '폭탄'이라는 단어가 섞인 무해한 질문까지 전면 회피 거부하는 '과잉 거절($Over-refusal$)' 폐해가 생기므로, 도움성과 안전성 편향 지표($Harmless-Helpful$ $Trade-off$)의 타당성을 상시 보정해야 함

## Ⅶ. 결론

- RLHF는 기계의 차가운 자연어 생성력에 인간 고유의 도덕성 주권과 가치관을 이식하여 상일상용 제품으로서의 품격을 셋업하는 정렬 기술의 근간이며, 설계자는 학습 중 필연적으로 마주하는 보상 해킹 방어책과 과잉 거절로 인한 지능 상실(Alignment Tax) 한계를 조화롭게 해결해야 함
