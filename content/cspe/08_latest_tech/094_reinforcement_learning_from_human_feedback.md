## 미리 알고가기

- RLHF는 인간의 선호 데이터를 보상 신호로 사용해 모델을 정렬하는 방법임
- 보통 SFT, 보상 모델 학습, 정책 최적화의 3단계 파이프라인으로 구성됨
- 지식 자체를 늘리기보다는 답변 태도와 안전성과 선호 일치를 조정하는 데 초점이 있음

## Ⅰ. 개요

- **정의/개념**: RLHF는 인간이 선호한 답변 패턴을 보상 모델로 학습한 뒤 강화학습이나 선호 최적화로 언어 모델의 응답 정책을 인간 기대에 맞게 조정하는 정렬 기법임
- **배경/필요성**: 지시 튜닝만으로는 유용성, 정직성, 무해성 같은 주관적 기준을 충분히 반영하기 어려우므로, 인간 평가를 직접 학습 신호로 넣는 정렬 단계가 필요함

## Ⅱ. 특징

- 정답 하나로 정의하기 어려운 주관적 품질 기준을 모델 정책에 반영할 수 있음
- 상용 대화형 모델의 거절 기준과 도움성 톤과 안전성 제어에 큰 영향을 줌
- 인간 라벨링 비용이 크고 보상 모델 품질에 따라 학습 방향이 크게 달라질 수 있음
- 과도하게 적용하면 과잉 거절이나 창의성 저하 같은 alignment tax가 생길 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | SFT | RLHF | DPO |
|:---|:---|:---|:---|
| 학습 신호 | 정답 응답 | 인간 선호 | 선호 쌍 |
| 보상 모델 | 없음 | 있음 | 없음 |
| 구현 난도 | 중간 | 높음 | 중간 |
| 대표 목적 | 지시 수행 | 선호 정렬 | 간소화된 정렬 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| SFT Model | 최소한의 지시 수행 능력을 갖춘 초기 정책으로 RLHF의 출발점이 됨 |
| Preference Data | 인간이 여러 후보 답변 중 더 나은 답변을 고른 데이터로 보상 기준을 형성함 |
| Reward Model | 인간 선호를 점수화해 강화학습에 사용할 보상 함수를 근사함 |
| Policy Optimizer | PPO 등으로 보상을 높이되 원래 모델과의 괴리가 과도해지지 않게 조정함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| SFT 기반 모델   | --> | 인간 선호 수집   | --> | 보상 모델 학습   | --> | 정책 정렬 최적화 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **SFT 기반 모델 준비**: 지시를 따를 수 있는 초기 모델을 확보함
2. **인간 선호 수집**: 후보 응답 쌍을 평가해 선호 데이터를 구축함
3. **보상 모델 학습**: 선호 데이터를 점수 예측 모델로 변환함
4. **정책 정렬 최적화**: 보상과 제약을 동시에 고려해 정책 모델을 업데이트함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 보상 모델이 인간 선호를 불완전하게 학습하면 모델이 점수만 잘 받는 방향으로 왜곡되는 reward hacking이 발생할 수 있음
   - 해결방안: KL 제약과 다중 평가셋을 운영하고 win rate와 reward-model agreement로 정렬 품질을 검증함
2. 문제: 고품질 인간 선호 데이터를 구축하는 비용과 시간이 커서 반복 학습 주기가 길어질 수 있음
   - 해결방안: 고위험 영역 중심으로 라벨링 우선순위를 두고 cost per pair와 quality gain으로 투자 효율을 검증함
3. 문제: 안전성을 과도하게 밀면 정당한 요청까지 거절하는 over-refusal이 증가할 수 있음
   - 해결방안: 도움성과 안전성 균형 평가를 분리하고 refusal rate와 harmless-helpful tradeoff score로 운영 수준을 검증함

## Ⅶ. 적용 사례

- 상용 챗봇 정렬: 거절 정책과 도움성 톤을 조정함, 확인 지표는 win rate와 toxicity score임
- 법률, 의료 보조: 위험 표현을 줄이고 보수적 답변을 유도함, 확인 지표는 unsafe response rate와 expert preference score임
- 코드 어시스턴트 품질 향상: 더 유용한 수정안을 선호하도록 정렬함, 확인 지표는 accepted suggestion rate와 user preference임

## Ⅷ. 결론

RLHF는 모델 지식을 늘리는 단계가 아니라 인간 선호와 안전 기준에 맞게 응답 정책을 다듬는 정렬 단계이므로, 보상 모델 품질과 라벨링 비용 통제가 핵심임.
