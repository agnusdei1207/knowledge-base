# 📖 【암기용】 개념 완전 이해

## 한눈에
- **정의**: 거대 언어 모델(LLM)이 인간의 가치관(도움됨, 정직함, 무해함 등)과 일치(Alignment)하도록, 인간이 직접 매긴 선호도(Preference)를 보상 모델(Reward Model)로 학습시켜 강화학습(PPO)으로 모델을 훈련하는 기법.
- **필요성**: 수많은 웹 문서를 사전 학습(Pre-train)하거나 단순 지시 튜닝(SFT)만 거친 모델은, 종종 거짓말(환각)을 진실처럼 꾸며내거나, 혐오 표현, 위험한 지시(폭탄 제조법 등)에도 충실히 답하는 위험성을 띰.
- **핵심 직관**: 학생(AI)이 쓴 여러 개의 글 중, 선생님(인간)이 "이 글이 저 글보다 낫다"고 채점해 주면, 이 채점 기준(Reward Model)을 외운 자동 채점기가 학생을 스파르타식으로 계속 훈련(RL)시켜 좋은 글만 쓰게 만드는 과정.

## 깊이 이해
- **배경**: OpenAI가 InstructGPT(2022) 논문에서 대규모로 상용화하여 ChatGPT의 대성공을 이끈 핵심 알고리즘. '어떻게 하면 인간이 진정으로 원하는 안전하고 똑똑한 답변을 내놓을 것인가?'(Alignment Problem)에 대한 돌파구를 제시함.
- **작동 원리**:
  1. **Step 1 (SFT)**: 사람의 고품질 데모 데이터로 모델을 1차 파인튜닝.
  2. **Step 2 (Reward Model 학습)**: SFT 모델이 낸 여러 답변(A, B)을 사람이 보고 "A가 B보다 낫다"고 순위(Ranking)를 매김. 이 데이터로 '어떤 답변이 사람에게 더 큰 보상을 받을지' 예측하는 보상 모델을 훈련.
  3. **Step 3 (PPO 강화학습)**: RL 알고리즘(주로 PPO)을 통해 LLM이 보상 모델로부터 가장 높은 점수를 받을 수 있는 방향으로 자신(Policy)을 스스로 업데이트함.
- **비유**: 강아지 훈련. 강아지가 올바른 행동(좋은 답변)을 하면 주인이 간식(인간의 선호도 $\rightarrow$ 보상)을 주고, 물어뜯는 행동(유해한 답변)을 하면 간식을 안 주면서 스스로 좋은 행동을 학습하게 유도하는 것.
- **구체 예시**: 사용자 질문 "세금 안 내고 돈 버는 법". LLM이 "1번: 탈세 방법...", "2번: 불법입니다."를 제시할 때 인간이 2번을 선호한다고 라벨링. 이후 RLHF를 거친 챗GPT는 이런 질문에 안전하게 거절(Refusal)하는 방어력을 갖춤.
- **흔한 오해/주의점**: RLHF는 모델의 '지식(Knowledge)'을 늘리는 기술이 아님. 알고 있는 지식을 '어떻게 예쁘고 안전하게 포장해서 꺼낼지' 태도를 가르치는 기술. 과도하게 적용하면 아무 질문이나 방어적으로 피하는 과잉 거절(Over-refusal)과 창의성 하락(Alignment Tax)이 발생함.

## 연결 개념
- **Alignment (가치 정렬)**: AI의 목적을 인류의 가치와 일치시키는 궁극적 목표 (RLHF는 이를 위한 수단).
- **PPO (Proximal Policy Optimization)**: RLHF Step 3에서 LLM을 안정적으로 훈련시키는 강화학습 알고리즘.
- **DPO (Direct Preference Optimization)**: RLHF의 복잡한 3단계를 보상 모델 없이 한 번에 수행하는 최근의 대안 기술.

# 📝 【답안용】 시험 답안 템플릿
## 핵심 인사이트 (3줄 요약)
- **본질**: 인간의 주관적 선호도(Helpful, Honest, Harmless)를 보상 함수(Reward Function)로 대리 모델링한 뒤, 강화학습을 통해 LLM의 생성 정책(Policy)을 최적화하는 얼라인먼트 파이프라인.
- **가치**: 텍스트 생성의 불안정성과 유해성을 통제하여, 모델을 실험실의 장난감에서 '신뢰 가능한 상용 AI 프로덕트(예: ChatGPT)'로 승격시킨 핵심 엔진.
- **판단 포인트**: Reward Hacking 방어, 고품질 인간 라벨러(Human Rater) 확보 및 편향성 통제, 기존 능력 하락(Alignment Tax)에 대한 벤치마크 회귀 테스트.

## Ⅰ. 개요 및 필요성
- **정의**: 언어 모델의 결과물에 대한 인간의 랭킹(Ranking) 피드백을 기반으로 보상 모델(RM)을 구축하고, 강화학습을 통해 모델의 정책(Policy Network)을 미세조정하는 정렬 기술.
- **배경**: 지도 학습(SFT)만으로는 완벽한 정답이 없는 주관적이고 윤리적인 영역이나, 무한대에 가까운 텍스트 생성 경우의 수를 모두 커버할 수 없음.
- **필요성**: 인공지능이 인간의 지시를 오해하거나 악용하는 오작동(Misalignment)을 막고, HHH(Helpful, Honest, Harmless) 기준에 부합하는 상호작용 체계를 확립하기 위함.

## Ⅱ. RLHF 아키텍처 및 3단계 파이프라인
```text
[ Step 1: SFT ]    [ Step 2: Reward Model (RM) ]        [ Step 3: PPO RL ]
Prompt -> SFT 튜닝    Prompt -> SFT Model -> 응답 A, B      Prompt
                        |                                      |
                     사람이 선호도 라벨링 (A > B)            [ LLM (Policy) ] 
                        |                                      |  (Generate)
                   [ Reward Model 학습 ] <--- (점수 예측) ----- (Response)
                                                               |  (Reward 점수 부여)
                                                          [ PPO 최적화 ] -> Policy Update
```
- **SFT Model**: 강화학습의 초기 상태(Baseline)가 되는 지시 튜닝 모델.
- **Reward Model (RM)**: 입력 프롬프트와 응답을 받아, 인간이 얼마나 선호할지(스칼라 점수) 예측하는 평가자 모델.
- **PPO (Proximal Policy Optimization)**: 보상을 극대화하되, 원래 SFT 모델에서 너무 급격히 변하지 않도록(안정성 유지) 통제하는 강화학습 알고리즘.

## Ⅲ. 핵심 동작 원리 (Step 3: RL 최적화)
1. 프롬프트가 주어지면 학습 중인 LLM(Policy)이 응답 생성.
2. 생성된 응답을 Reward Model이 평가하여 보상(Reward) 값 산출.
3. **KL 발산 페널티(KL Divergence Penalty)**: LLM이 점수를 조작하기 위해 이상한 외계어를 만들어내는 것(Reward Hacking)을 막기 위해, 원래 SFT 모델의 생성 확률 분포와 너무 달라지면 벌점(Penalty)을 부여함.
4. 산출된 최종 보상값을 바탕으로 PPO 알고리즘이 LLM의 가중치(Policy) 업데이트.

## Ⅳ. 심화 비교 (RLHF vs SFT vs DPO)
| 구분 | SFT (Supervised Fine-Tuning) | RLHF | DPO (Direct Preference Optimization) |
|:---:|:---|:---|:---|
| **학습 신호** | "이것이 정답이다" (Demonstration) | "A가 B보다 낫다" (Relative Preference) | "A가 B보다 낫다" |
| **보상 모델(RM)** | 불필요 | **필수 (별도 모델 학습)** | 불필요 (Policy 자체로 수식 해결) |
| **비용 및 난이도** | 낮음 | **매우 높음 (불안정한 PPO)** | 중간 (안정적인 분류 Loss) |
| **강점** | 초기 지시 수행력 확보 | **세밀한 인간 선호도 정렬** | 구현 및 자원 효율성 |

## Ⅴ. 한계점 및 운영 리스크 해결방안
- **리스크 1: 보상 해킹 (Reward Hacking)**:
  - 모델이 인간이 좋아할 만한 겉보기만 그럴싸한 문장(미사여구, 아첨 등)을 만들어 보상 점수만 취하고 실제 내용은 부실해지는 현상.
  - **대응 방안**: KL Divergence 페널티를 강하게 주어 원본 SFT 궤도에서 벗어나지 못하게 묶어두고, 다양한 길이와 패턴에 패널티를 주는 정교한 RM 앙상블 적용.
- **리스크 2: 정렬 세금 (Alignment Tax)**:
  - 무해함(Harmless)을 너무 강조한 나머지, 코딩이나 수학 같은 객관적 추론 능력(Helpful)이 오히려 퇴화하는 현상.
  - **대응 방안**: PPO 학습 시 기존의 Pre-training 데이터(일반 지식)를 Loss에 일정 비율(PTX Loss) 섞어 넣어 기존 능력을 방어(InstructGPT의 PPO-ptx 기법).
- **리스크 3: 인간 라벨러의 편향 (Human Bias)**:
  - 라벨러의 정치적, 문화적 편향이 모델에 그대로 주입됨.
  - **대응 방안**: 다양성을 확보한 라벨러 풀(Pool) 운영 및 교차 검증(Inter-rater Agreement), 명확한 HHH 가이드라인 제시.

## Ⅵ. 실무 적용 및 결론
- **판단 지표**: 라벨러 간 일치율(Agreement Rate), Win-rate (경쟁 모델 대비 승률), Toxicity Score, 거절률(Refusal Rate).
- **실무 설계**: 기업용 AI(예: 법률 상담 AI) 구축 시, 1단계로 변호사 작성 데이터 1만 건으로 SFT를 수행하고, 2단계로 변호사들이 답변 품질 순위를 매긴 5만 건의 데이터를 모아 Reward Model을 구축한 뒤, RLHF를 돌려 '위험한 법적 단언을 피하고 판례를 객관적으로 제시'하는 안전한 챗봇을 완성.
- **결론**: RLHF는 모델의 원시적 능력을 인간의 사회적 규범과 기대치에 맞게 다듬는 '문명화' 과정이며, 초거대 AI가 대중 서비스로 성공하기 위한 가장 중요하고도 필수적인 방패막임.

### 🔀 문제 유형별 목차 전환
- **Ⅱ·Ⅲ 강조 (개념/원리형)**: SFT $\rightarrow$ RM $\rightarrow$ PPO로 이어지는 3단계 파이프라인의 구조와 KL 페널티의 수학적/개념적 역할을 명확히 묘사.
- **Ⅴ·Ⅵ 강조 (실무/설계형)**: Reward Hacking 및 Alignment Tax 방어 전략, 라벨러 편향 제어 체계, DPO 및 RLAIF 같은 최신 대안 기술과의 결합 아키텍처 관점 작성.
