# 📖 【암기용】 개념 완전 이해

> 목적: 위치 인코딩을 처음 봐도 완벽히 이해하게 만든다.

## 한눈에
- **개요**: 순서 정보가 없는 Attention 입력에 토큰 위치를 주입하는 벡터 표현
- **왜 필요한가**: Self-Attention은 모든 토큰을 동시에 보므로 "나는 밥을 먹었다"와 "밥은 나를 먹었다"의 순서를 별도 정보로 알려줘야 함.
- **핵심 직관**: 단어 카드마다 1번, 2번, 3번 위치표를 붙여 문장 순서를 잃지 않게 하는 장치임.

## 깊이 이해
- **배경·문제의식**: Transformer는 RNN처럼 시간 순서로 읽지 않는다. 병렬 계산 장점 대신 위치 순서를 알 수 없으므로 임베딩에 위치 정보를 더함.
- **작동 원리**: 절대 위치 인코딩은 각 위치 번호에 고유 벡터를 부여함. Sinusoidal PE는 사인·코사인 주파수로 위치를 표현하고, RoPE는 Q/K 벡터를 회전시켜 상대 위치를 반영함.
- **비유**: 책의 문장을 모두 잘라 봉투에 넣으면 단어는 남지만 순서가 사라진다. 위치 인코딩은 각 단어 조각에 페이지와 줄 번호를 적는 것임.
- **구체 예시**: GPT 계열은 학습 위치 임베딩 또는 RoPE를 사용하며, RoPE 확장은 128K 이상 장문맥 모델의 기반 기법임.
- **흔한 오해·주의점**: 위치 인코딩만 바꾸면 무제한 장문맥이 되는 것은 아님. Attention O(N²)와 KV Cache 메모리 병목도 함께 해결해야 함.

## 연결 개념
- Transformer — 위치 인코딩을 입력 임베딩에 결합
- RoPE — LLM에서 널리 쓰이는 회전 위치 인코딩
- Long Context LLM — 위치 인코딩 확장과 Attention 최적화가 필요


# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 위치 인코딩은 순서 정보가 없는 Self-Attention에 토큰 위치·거리 정보를 주입하는 기법임.
> 2. **가치**: 문장 순서·구문 구조·장거리 참조를 보존하여 Transformer가 언어를 순차적으로 해석하게 함.
> 3. **판단 포인트**: 절대/상대/RoPE 방식, 외삽 가능성, 장문맥 확장 비용을 비교해야 함.


## Ⅰ. 개요 및 필요성

위치 인코딩은 토큰 순서 주입 기법임. Transformer는 병렬 Attention 구조로 순서 정보를 직접 갖지 않으므로, 입력 임베딩에 위치 벡터를 결합해 문장 구조와 상대 거리를 표현함.


## Ⅱ. 구조 및 구성요소

```text
Token IDs -> Token Embedding
                             -> Embedding + Position -> Transformer
Position Index -> PE Vector

           - Absolute PE
           - Relative PE
           - RoPE / ALiBi
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Token Embedding | 단어 의미 표현 | 어휘 ID->d_model 벡터 |
| Absolute PE | 위치 번호별 고정/학습 벡터 | 학습 길이 외삽 한계 |
| Relative PE | 토큰 간 거리 표현 | 번역·구문 관계에 유리 |
| RoPE/ALiBi | 장문맥 확장 지원 | RoPE scaling, 선형 bias |

> 요약: 위치 인코딩은 의미 벡터와 위치 벡터를 결합해 Attention이 순서와 거리를 함께 보게 함.


## Ⅲ. 동작원리 및 흐름도

```text
토큰화 -> 위치 번호 부여 -> PE 계산/조회 -> 임베딩 결합
    -> Q/K 위치 반영 -> Attention score 계산
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 각 토큰에 position index 부여 | 0~N-1 순번 |
| 2 | Sin/Cos·학습 PE·RoPE 계산 | d_model 차원 일치 |
| 3 | Token embedding과 결합 | Add 또는 Q/K 회전 |
| 4 | Attention에서 거리 반영 | 길이 외삽 정확도, NIAH 평가 |

> 요약: 위치 번호를 벡터로 바꿔 임베딩 또는 Q/K에 반영하고, Attention score가 순서 차이를 반영하게 함.


## Ⅳ. 특징

| 구분 | 절대 위치 인코딩 | 상대/RoPE 위치 인코딩 | 수치·판단 포인트 |
|:---|:---|:---|:---|
| 표현 기준 | 위치 번호 자체 | 토큰 간 거리·회전각 | RoPE는 Q/K 회전 |
| 외삽 | 학습 길이 초과 취약 | 장문맥 확장에 유리 | 32K->128K scaling |
| 구현 | 임베딩 Add | Attention score/QK 조정 | 모델 구조 영향 |
| 리스크 | 긴 문맥 일반화 한계 | 위치 왜곡·중간 손실 | Lost in the Middle |

> 요약: 짧은 문맥은 절대 PE로 충분하나, 128K 이상 장문맥은 RoPE scaling·ALiBi 등 외삽형 설계가 필요함.


## Ⅴ. 실무 적용 및 결론

**적용 방안 3개:**
1. 일반 NLP 모델은 학습 가능한 Absolute PE를 적용하고 최대 길이 512~4K를 명시
2. LLM 장문맥 확장은 RoPE scaling(YaRN/NTK) 적용 후 32K·128K NIAH 정확도 측정
3. 문서 QA는 핵심 근거를 프롬프트 앞·뒤에 배치해 Lost in the Middle 정확도 저하를 완화

**결론 (2줄):**
- 기술사 판단: 고정 길이 업무는 Absolute PE, 장문맥 LLM은 RoPE/ALiBi 기반 외삽 방식을 선택함.
- 향후 방향: 위치 인코딩은 Attention 최적화와 결합되어 1M 토큰 이상 장문맥 처리로 확장됨.
