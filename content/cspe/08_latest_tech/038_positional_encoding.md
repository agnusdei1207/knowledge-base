## 미리 알고가기

- Self-Attention은 토큰 간 유사도는 계산하지만 순서 자체는 알지 못하는 구조임
- Absolute Position은 각 토큰 위치에 고정된 위치 정보를 부여하는 방식임
- Relative Position은 토큰 간 거리 관계를 직접 반영해 장거리 일반화에 유리한 방식임

## Ⅰ. 개요

- **정의/개념**: Positional Encoding은 순서 정보를 알지 못하는 attention 구조에 토큰 위치나 상대 거리를 주입해 문장 순서와 장거리 의존성을 해석 가능하게 만드는 위치 정보 부여 메커니즘임
- **배경/필요성**: Transformer는 순환 구조 없이 토큰을 병렬 처리하므로 순서를 별도로 넣지 않으면 "A가 B를 이김"과 "B가 A를 이김"을 같은 집합처럼 다뤄 의미 차이를 구분할 수 없음

## Ⅱ. 특징

- attention 모델의 순서 무관성을 보완해 문법 구조와 시간 흐름을 해석할 수 있게 함
- 절대 위치 부여, 상대 거리 반영, 회전 기반 인코딩처럼 구현 방식에 따라 일반화 특성이 달라짐
- 긴 문맥 성능은 위치 인코딩 방식에 크게 좌우되어 Long Context 확장의 핵심 변수가 됨
- 텍스트뿐 아니라 이미지 패치, 음성 프레임, 시계열 샘플에도 동일한 원리로 적용 가능함

## Ⅲ. 종류 및 비교

| 판단 기준 | Sinusoidal Absolute | Learned Absolute | RoPE / Relative 계열 |
|:---|:---|:---|:---|
| 표현 방식 | 사인, 코사인 고정 함수 | 학습된 위치 임베딩 | 회전 또는 거리 기반 반영 |
| 학습 외 길이 일반화 | 상대적으로 양호함 | 취약할 수 있음 | 길이 확장에 유리함 |
| 구현 단순성 | 높음 | 높음 | 중간 |
| 대표 활용 | 초기 Transformer | 일부 BERT 계열 | 최신 LLM, Long Context |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Position Index | 토큰이 입력 시퀀스에서 어느 위치에 놓였는지 정의하는 기본 좌표계임 |
| Encoding Generator | 사인, 코사인 함수나 학습 파라미터 또는 회전 규칙으로 위치 표현을 생성함 |
| Injection Rule | 생성된 위치 정보를 토큰 임베딩에 더하거나 Q,K 공간에 회전 형태로 주입해 attention에 반영함 |
| Length Control | 학습 길이 밖 문맥에서도 위치 왜곡을 줄이기 위해 스케일링이나 보정 규칙을 적용하는 영역임 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-----------+     +---------------+     +--------------+     +-------------+
| 위치 인덱스 | --> | 인코딩 생성   | --> | 임베딩 주입   | --> | Attention 반영 |
+-----------+     +---------------+     +--------------+     +-------------+
```

1. **위치 인덱스 생성**: 입력 토큰 순서에 따라 각 토큰의 위치 번호를 부여함
2. **인코딩 생성**: 위치 번호를 사인, 코사인 함수나 학습 파라미터 또는 회전 규칙으로 변환함
3. **임베딩 주입**: 생성된 위치 정보를 토큰 임베딩 또는 Query, Key 변환 과정에 결합함
4. **Attention 반영**: 모델이 토큰 의미뿐 아니라 선후 관계와 상대 거리를 함께 고려해 문맥을 계산함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 학습 시 사용한 길이보다 긴 문맥에 적용하면 위치 정보 왜곡이 누적되어 장문맥 일반화 성능이 급격히 떨어질 수 있음
   - 해결방안: RoPE scaling, position interpolation 같은 길이 확장 기법을 적용하고 길이별 retrieval accuracy와 perplexity로 성능 저하를 검증함
2. 문제: 절대 위치 중심 설계는 상대 거리 정보가 중요한 작업에서 장거리 관계 해석이 약해질 수 있음
   - 해결방안: relative position bias나 RoPE 계열로 전환하고 long-range dependency benchmark로 관계 보존력을 검증함
3. 문제: 모달리티별 토큰 단위가 다르면 동일 위치 규칙을 그대로 적용해도 공간적 또는 시간적 의미가 어긋날 수 있음
   - 해결방안: 텍스트, 비전, 오디오에 맞는 위치 단위를 분리 설계하고 downstream task accuracy와 sequence alignment 지표로 적합성을 검증함

## Ⅶ. 적용 사례

- GPT 계열 LLM: RoPE 기반 위치 정보를 적용해 긴 프롬프트 추론 성능을 유지함, 확인 지표는 long-context accuracy와 perplexity임
- BERT류 인코더: 절대 위치 임베딩으로 문장 순서를 반영함, 확인 지표는 classification accuracy임
- Vision Transformer: 패치 위치를 인코딩해 공간 구조를 복원함, 확인 지표는 top-1 accuracy와 patch attention 품질임

## Ⅷ. 결론

위치 인코딩의 본질은 순서를 넣는 보조 정보가 아니라 attention이 긴 문맥에서도 의미와 거리 관계를 잃지 않게 만드는 핵심 설계 축이므로, 모델 선택 시 일반화 길이와 상대 위치 표현 방식을 함께 봐야 함.
