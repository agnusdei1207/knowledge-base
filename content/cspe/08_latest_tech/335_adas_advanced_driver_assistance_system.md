# 📖 【암기용】 개념 완전 이해

> 목적: ADAS를 운전자를 대체하는 기술이 아니라 운전자에게 경고·제동·조향 보조를 제공하는 안전 기능 집합으로 이해하게 만든다.

## 한눈에
- **개요**: 센서와 제어 로직으로 운전자의 인지·판단·제어를 보조하는 차량 안전 기능
- **왜 필요한가**: 운전자는 사각지대, 졸음, 반응 지연, 돌발 상황에서 위험을 늦게 인지할 수 있다.
- **핵심 직관**: ADAS는 운전자를 대신하는 조종사가 아니라 옆자리에서 위험을 감지하고 제동·조향을 보조하는 안전 보조자다.

## 깊이 이해
- **배경·문제의식**: 교통사고는 인지 지연, 차간거리 미확보, 차선 이탈, 보행자 미감지에서 자주 발생한다.
- **작동 원리**: 카메라, 레이더, 라이다, 초음파 센서가 주변 객체를 감지하고 ECU가 충돌 위험을 계산해 경고·제동·조향을 수행한다.
- **비유**: 운전자가 앞을 보는 동안 ADAS는 앞·뒤·옆 거울을 동시에 보고 위험 간격을 숫자로 계산하는 보조 눈과 손이다.
- **구체 예시**: AEB는 전방 객체와 자차 속도로 TTC(Time-to-Collision)를 계산하고 임계값 이하일 때 경고 후 제동을 개입한다.
- **흔한 오해·주의점**: ADAS는 SAE Level 1~2 중심 기능이며 운전 책임을 차량에 완전히 넘기지 않는다. ODD와 운전자 감시 범위를 명확히 해야 한다.

## 연결 개념
- ADS — SAE Level 3~5 자동운전 시스템
- ISO 26262 — 기능안전 분석 기준
- SOTIF ISO 21448 — 기능 의도와 성능 한계로 인한 위험 분석

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.
> 핵심: ADAS는 센서 융합과 제어 로직으로 운전자에게 경고·제동·조향 보조를 제공하는 Level 1~2 중심 안전 기능이다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: ADAS는 차량 주변 인지와 위험 판단을 통해 운전자의 DDT 일부를 보조하는 시스템이다.
> 2. **가치**: AEB, ACC, LKA, BSD 등으로 충돌 위험과 차선 이탈 위험을 조기에 경고하거나 제어한다.
> 3. **판단 포인트**: 운전자 책임, ODD, 센서 한계, ISO 26262/SOTIF, 오경보·미검출 지표를 구분해야 한다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| ADAS 기능 이해 확인 | AEB, ACC, LKA, BSD, 센서 융합 | 자율주행과 동일시 |
| 안전 설계 판단 확인 | ISO 26262, SOTIF, fail-safe | 기능 목록만 나열 |
| 한계 인식 확인 | ODD, 운전자 감시, 오경보·미검출 | 모든 상황에서 작동한다고 단정 |

> 요약: 이 문제는 ADAS 기능보다 운전자 보조 범위와 안전 한계를 구분하는 판단을 요구한다.

## Ⅰ. 개요 및 필요성

- 개요: 운전자 보조 안전시스템
- 배경: 운전자 인지 지연과 사각지대는 충돌·차선이탈·보행자 사고로 이어질 수 있다.
- 필요성: ADAS는 센서 기반 경고·제동·조향 보조로 사고 위험 상황의 반응 시간을 줄인다.

---

## Ⅱ. 구조 및 구성요소

```text
Camera / Radar / LiDAR / Ultrasonic -> Sensor Fusion ECU
      +-> Object Detection / Risk Assessment -> Control Command
      +-> HMI Warning / Brake / Steering / Driver Monitoring
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 센서 | 차선·차량·보행자·장애물 감지 | camera, radar, lidar |
| 인지·융합 ECU | 객체 분류와 추적 수행 | Kalman filter, AI model |
| 판단 로직 | TTC, 차간거리, 차선 이탈 계산 | ODD 조건 반영 |
| 제어·HMI | 경고, 제동, 조향 보조 실행 | 운전자 override 허용 |

> 요약: ADAS는 센서 입력을 융합해 위험을 계산하고 경고·제동·조향 보조로 운전자 행동을 보완한다.

---

## Ⅲ. 동작원리 및 흐름도

```text
주변 감지 -> 객체 인식·추적 -> 위험도 계산
-> 기능 조건 확인 -> 경고 / 제동 / 조향 보조 -> 운전자 개입 감시
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 센서가 차선·객체·상대속도를 측정함 | detection rate |
| 2 | ECU가 객체를 분류하고 위치를 추적함 | false positive/negative |
| 3 | TTC·차선 이탈·사각지대 위험을 계산함 | scenario coverage |
| 4 | 경고·제동·조향 보조를 수행하고 운전자 override를 허용함 | intervention log |

> 요약: ADAS는 감지·인지·위험 판단·보조 제어 순서로 동작하며 운전자 책임을 전제로 한다.

---

## Ⅳ. 특징

| 구분 | ADAS | ADS | 판단 기준 |
|:---|:---|:---|:---|
| 자동화 수준 | SAE Level 1~2 중심 | SAE Level 3~5 | DDT 책임 |
| 운전자 역할 | 상시 감시·개입 | ODD 내 시스템 책임 가능 | fallback 주체 |
| 기능 범위 | 경고·보조 제어 | 자동운전 수행 | ODD 정의 |
| 검증 초점 | 오경보·미검출·HMI | 시스템 fallback·안전 정지 | safety case |

> 요약: ADAS는 운전자 보조 시스템이므로 자동운전 책임과 fallback을 전제로 하는 ADS와 구분해야 한다.

## Ⅴ. 심화 비교 및 적용 판단

| 구분 | 기존/대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 운전 지원 | 경고 장치 | 센서 융합 보조 제어 | 사고 유형·ODD |
| 인지 | 단일 센서 | camera+radar 등 융합 | 날씨·야간·거리 |
| 제어 | 운전자 단독 | 제한적 제동·조향 개입 | 운전자 override |

> 요약: ADAS는 사고 유형별로 필요한 센서와 보조 제어 수준을 정하고 운전자 개입 경계를 명시해야 한다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 미검출 | 악천후·센서 오염·객체 다양성 | 센서 융합, self-diagnosis | false negative rate |
| 오경보 | 그림자·표지판·차선 오인식 | scenario validation, threshold tuning | false positive rate |
| 과신 | 운전자 자동운전 오해 | HMI 경고, driver monitoring | hands-off event |

> 요약: ADAS 리스크는 센서 한계와 운전자 과신이며 검증 시나리오와 HMI 설계로 통제한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 인지 품질 | 객체 검출·추적 오류 추적 | test dataset, proving ground |
| 안전 | ISO 26262·SOTIF 산출물 완결 | safety review |
| 운전자 상호작용 | 경고 인지·override 기록 | HMI test, vehicle log |

> 요약: ADAS 성과는 기능 탑재 수가 아니라 검출 오류, 안전 분석, 운전자 반응 로그로 판단한다.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. AEB, ACC, LKA 등 기능별 ODD, 센서 조합, fail-safe 상태, 운전자 override 조건을 요구사항으로 명시함.
2. ISO 26262 HARA와 ISO 21448 SOTIF 분석을 통해 오작동과 성능 한계에서 발생하는 위험을 분리 평가함.
3. 실제 도로, proving ground, 시뮬레이션을 결합해 야간·우천·차선 훼손·보행자 돌발 시나리오를 검증함.

**결론 (2줄):**
- 기술사 판단: ADAS는 운전자 책임을 전제로 사고 유형별 보조 기능을 적용하고, ODD 밖에서는 기능 제한과 명확한 HMI가 필요함.
- 향후 방향: ADAS는 V2X, AI 인지, HD Map과 결합하며 ADS로 확장되지만 안전 검증과 운전자 감시가 병행되어야 함.
