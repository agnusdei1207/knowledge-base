## 미리 알고가기

- Constitutional AI는 명시적 원칙 집합을 기준으로 모델이 스스로 응답을 비판하고 수정하게 만드는 정렬 접근임
- 인간 라벨링 의존도를 낮추면서 일관된 규칙 기반 정렬을 노림
- RLAIF와 강하게 연결되며 헌법 문구 설계가 품질의 핵심임

## Ⅰ. 개요

- **정의/개념**: Constitutional AI는 도움성과 무해성 같은 원칙을 헌법 형태로 명문화하고, 모델이 그 원칙에 따라 자기 응답을 비판하고 수정하며 정렬되도록 만드는 규칙 기반 정렬 프레임워크임
- **배경/필요성**: RLHF는 비용이 크고 인간 평가 편차가 존재하므로, 더 일관된 기준으로 대규모 정렬 데이터를 생성하는 자동화 방식이 필요함

## Ⅱ. 특징

- 명시적 원칙을 활용해 모델 행동 기준을 텍스트 형태로 투명하게 관리할 수 있음
- AI 평가자와 자기비판 루프를 활용해 인간 라벨링 부담을 줄일 수 있음
- 헌법 원칙이 모호하거나 충돌하면 모델이 잘못된 방향으로 일관되게 정렬될 수 있음
- 규칙 기반이라도 최종 품질 검증과 위험 감사는 여전히 필요함

## Ⅲ. 종류 및 비교

| 판단 기준 | RLHF | RLAIF | Constitutional AI |
|:---|:---|:---|:---|
| 기준 원천 | 인간 선호 | AI 평가 | 명문화된 원칙+AI 평가 |
| 비용 | 높음 | 낮음 | 낮음 |
| 일관성 | 라벨러 편차 존재 | 중간 | 높음 |
| 설계 난점 | 라벨링 비용 | 평가자 편향 | 헌법 품질과 충돌 관리 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Constitution | 안전성, 정직성, 비차별성 같은 원칙을 명문화해 평가와 수정의 기준을 제공함 |
| Self-critique Generator | 모델이 자신의 응답을 원칙에 비추어 비판하도록 만드는 단계임 |
| Revision Engine | 자기비판 결과를 반영해 더 나은 응답으로 수정함 |
| Preference, Audit Layer | 생성된 수정 전후 데이터를 정렬 학습에 쓰고 인간 감사로 규칙 적합성을 점검함 |

                                                   +-------------------+

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 헌법 원칙 정의  | --> | 초안 응답 생성   | --> | 자기 비판/수정   | --> | 정렬 학습/감사   |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **헌법 원칙 정의**: 서비스와 정책에 맞는 원칙을 작성함
2. **초안 응답 생성**: 모델이 일반 응답을 먼저 생성함
3. **자기 비판 및 수정**: 헌법에 따라 문제점을 지적하고 응답을 수정함
4. **정렬 학습 및 감사**: 수정 전후 데이터를 학습에 쓰고 사람 또는 평가셋으로 검증함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 헌법 문구가 추상적이거나 서로 충돌하면 모델이 어떤 원칙을 우선해야 하는지 혼란스러워질 수 있음
   - 해결방안: 우선순위와 예시를 포함한 헌법을 설계하고 audit disagreement와 policy violation rate로 일관성을 검증함
2. 문제: 자기비판 루프가 잘못된 판단을 반복하면 편향된 수정이 대량 생성될 수 있음
   - 해결방안: 인간 gold set과 외부 평가를 함께 운영하고 critique quality score와 correction success rate로 신뢰성을 검증함
3. 문제: 규칙 기반 정렬이 지나치면 도움성보다 무해성만 과도하게 강화되어 응답 활용도가 떨어질 수 있음
   - 해결방안: helpfulness와 harmlessness를 분리 평가하고 refusal quality와 user satisfaction으로 균형을 검증함

## Ⅶ. 적용 사례

- 정책 민감 챗봇이 사내 보안과 윤리 규정을 헌법으로 정의하도록 Constitutional AI를 적용하며 확인 지표는 policy violation rate와 audit pass rate임
- 안전성 자동 정렬이 AI가 응답을 비판하고 수정하도록 Constitutional AI를 활용하며 확인 지표는 correction success rate와 harmful response rate임
- 대규모 선호 데이터 생성이 인간 라벨링을 보완하도록 Constitutional AI를 적용하며 확인 지표는 cost per pair와 judge agreement임

## Ⅷ. 결론

Constitutional AI는 정렬 기준을 명시적 원칙으로 끌어내 일관성과 확장성을 높이는 접근이므로, 헌법 품질과 감사 체계가 실제 성능을 좌우함.
