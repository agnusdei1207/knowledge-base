# 📖 【암기용】 개념 완전 이해

> 목적: Reinforcement Learning을 처음 봐도 완벽히 이해하게 만든다.

## 한눈에
- **개요**: 에이전트가 환경과 상호작용하며 보상을 최대화하는 행동 정책을 학습하는 기계학습 방법
- **왜 필요한가**: 정답 라벨이 아니라 행동 결과의 장기 보상으로 의사결정을 최적화해야 하는 문제가 있음.
- **핵심 직관**: 게임을 하며 점수를 많이 받는 행동을 시행착오로 배우는 방식임.

## 깊이 이해
- **배경·문제의식**: 지도학습은 정답 데이터가 필요하지만 로봇 제어, 게임, 추천 정책, 자원 스케줄링은 행동의 장기 결과가 중요하다.
- **작동 원리**: 에이전트가 상태를 관찰하고 행동을 선택하면 환경이 보상과 다음 상태를 제공하며, 정책은 누적 보상을 높이는 방향으로 업데이트됨.
- **비유**: 아이가 자전거를 타며 넘어짐과 성공 경험을 통해 어떤 균형 행동이 좋은지 배우는 과정임.
- **구체 예시**: 데이터센터 냉각 제어에서 RL이 온도·전력 상태를 보고 팬 속도를 조절해 전력 사용량 10% 절감 목표로 학습.
- **흔한 오해·주의점**: RL은 무작정 실제 시스템에서 탐험하면 위험하다. 시뮬레이터, offline RL, 안전 제약이 필요함.

## 연결 개념
- MDP — 강화학습 문제를 상태·행동·보상·전이로 모델링
- Bellman Equation — 가치함수의 재귀적 최적성 원리
- RLHF — 사람 피드백 보상으로 LLM을 정렬하는 응용

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 강화학습은 상태에서 행동을 선택하고 보상을 받아 누적 보상을 최대화하는 정책을 학습함.
> 2. **가치**: 장기 의사결정, 제어, 추천, 자원 최적화처럼 정답 라벨이 없는 문제에 적용함.
> 3. **판단 포인트**: 탐험 위험, 보상 설계, sample efficiency, 안전 제약을 운영 환경에서 통제해야 함.

## Ⅰ. 개요 및 필요성

강화학습은 보상 기반 의사결정 학습 방법임. 지도학습은 정답 라벨이 필요하지만 많은 제어·최적화 문제는 행동의 장기 결과로 평가된다. 강화학습은 환경과 상호작용하며 최적 정책을 학습한다.

## Ⅱ. 구조 및 구성요소

```text
State st -> Agent/Policy π -> Action at -> Environment

        -------- Reward rt + Next State st+1 -
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Agent | 행동 선택 주체 | policy, value function 보유 |
| Environment | 행동 결과와 상태 전이 제공 | simulator 또는 실제 시스템 |
| Reward | 행동 결과 평가 신호 | 보상 설계가 성능 좌우 |
| Policy/Value | 행동 규칙·상태 가치 | Q-learning, policy gradient |

> 요약: 강화학습은 에이전트가 상태를 보고 행동하고 환경의 보상·다음 상태로 정책을 갱신하는 폐루프 학습임.

## Ⅲ. 동작원리 및 흐름도

```text
상태 관찰 -> 행동 선택 -> 환경 반응 -> 보상 수신
  -> 가치/정책 업데이트 -> 반복 학습 -> 정책 배포
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 상태 공간·행동 공간 정의 | 관측 누락률 <1% |
| 2 | 보상 함수와 안전 제약 설계 | 제약 위반 0건 목표 |
| 3 | 탐험·학습으로 정책 업데이트 | 누적 보상 상승 |
| 4 | 시뮬레이터·A/B로 정책 검증 | baseline 대비 KPI 5% 이상 개선 |

> 요약: RL은 상태·행동·보상 설계 후 반복 상호작용으로 정책을 개선하고 안전 검증 후 배포함.

## Ⅳ. 특징

| 구분 | 지도학습 | 강화학습 | 판단 포인트 |
|:---|:---|:---|:---|
| 학습 신호 | 정답 라벨 | 보상 | 라벨 없는 의사결정 |
| 목표 | 예측 오차 최소화 | 누적 보상 최대화 | 장기 결과 중요 |
| 데이터 | 고정 데이터셋 | 상호작용 경험 | sample efficiency 이슈 |
| 리스크 | 분포 변화 | 위험한 탐험 | 시뮬레이터·안전 제약 필요 |

> 요약: 강화학습은 장기 보상 최적화에 적합하지만 실제 시스템 탐험 위험과 보상 설계 난도가 높음.

## Ⅴ. 실무 적용 및 결론

**적용 방안 3개:**
1. 자원 스케줄링: CPU·메모리·큐 길이 상태를 기반으로 autoscaling 정책 학습, SLA 위반 0건 제약 설정
2. 추천 정책: 클릭뿐 아니라 7일 재방문·구매를 보상에 포함해 단기 클릭 최적화 편향 완화
3. 안전 학습: 실제 배포 전 simulator와 offline RL로 검증하고, action limit와 rollback 정책 적용

**결론 (2줄):**
- 기술사 판단: 장기 의사결정과 제어 문제는 RL, 정답 라벨 예측 문제는 지도학습 우선 적용
- 향후 방향: offline RL, safe RL, RLHF가 기업·LLM 환경에서 강화학습 적용 범위를 넓힘
