## 미리 알고가기

- entity linking은 텍스트에 나온 표면 표현을 실제 지식베이스의 고유 개체 ID와 연결하는 작업임
- NER이 개체를 찾는 단계라면 entity linking은 그 개체가 누구인지 결정하는 단계임
- 중의성 해소와 KB에 없는 신규 개체 처리가 핵심 난점임

## Ⅰ. 개요

- **정의/개념**: 개체 연결은 텍스트 속 멘션을 지식베이스의 고유 엔티티와 매핑해, 같은 이름의 다른 대상과 다양한 별칭을 하나의 식별 체계로 정규화하는 NLP 및 지식통합 기법임
- **배경/필요성**: 동일 표기라도 의미가 다를 수 있고 같은 개체도 여러 이름으로 나타나기 때문에, 지식그래프 구축과 정밀 검색을 위해서는 텍스트 표현을 실제 개체 ID로 연결해야 함

## Ⅱ. 특징

- 텍스트 기반 표현을 실세계 개체와 연결해 데이터 정합성과 검색 정확도를 높임
- 동음이의어와 약어와 별칭 문제를 다뤄 지식그래프 품질의 기반을 만듦
- 후보 생성과 문맥 기반 중의성 해소 모두가 필요해 파이프라인이 복합적임
- KB에 존재하지 않는 신규 엔티티를 별도 처리해야 운영이 안정적임

## Ⅲ. 종류 및 비교

| 판단 기준 | NER | Entity Linking | Ontology Matching |
|:---|:---|:---|:---|
| 주 목적 | 개체 범위 탐지 | 실제 개체 식별 | 개념 구조 정합 |
| 출력 | 유형 태그 | KB ID | 스키마 매핑 |
| 중의성 해소 | 제한적임 | 핵심 기능 | 부분적임 |
| 대표 활용 | 개체 추출 | 그래프 구축, 정규화 | 지식 통합 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Mention Detector | 텍스트에서 개체로 보이는 표면 표현을 먼저 식별함 |
| Candidate Generator | 지식베이스에서 연결 가능한 후보 엔티티 집합을 찾음 |
| Disambiguation Model | 문맥과 후보 설명을 비교해 가장 적합한 엔티티를 선택함 |
| NIL, Discovery Layer | KB에 없는 신규 개체는 NIL로 처리하거나 후속 등록 대상으로 분리함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 멘션 탐지      | --> | 후보 엔티티 생성  | --> | 문맥 기반 중의성 해소 | --> | ID 연결/NIL 처리 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **멘션 탐지**: 텍스트에서 사람, 조직, 개념 표현을 식별함
2. **후보 엔티티 생성**: KB에서 연결 가능성이 있는 후보군을 수집함
3. **문맥 기반 중의성 해소**: 주변 문맥과 후보 설명을 비교해 정답 후보를 고름
4. **ID 연결 및 NIL 처리**: 최종 엔티티 ID를 부여하거나 신규 개체로 분리함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 후보 생성 단계에서 정답 엔티티가 빠지면 이후 모델이 아무리 좋아도 올바른 연결을 복구할 수 없음
   - 해결방안: alias dictionary와 dense retrieval을 함께 사용하고 candidate recall@k와 final linking accuracy로 후보 품질을 검증함
2. 문제: 약어와 동명이인과 문맥 부족이 겹치면 중의성 해소 오류가 빈번하게 발생할 수 있음
   - 해결방안: 도메인 문맥 모델과 global coherence를 적용하고 disambiguation accuracy와 conflict rate로 중의성 해소 품질을 검증함
3. 문제: KB에 없는 신규 개체를 기존 엔티티에 억지로 연결하면 그래프 오염이 누적될 수 있음
   - 해결방안: NIL 임계값과 신규 엔티티 검토 파이프라인을 운영하고 NIL precision과 duplicate entity rate로 정합성을 검증함

## Ⅶ. 적용 사례

- 뉴스 분석 그래프 구축: 인물과 조직을 KB ID로 통합함, 확인 지표는 linking accuracy와 duplicate rate임
- 의료 문서 정규화: 약어와 질병 개체를 표준 코드에 연결함, 확인 지표는 coding accuracy와 safety incident rate임
- enterprise RAG 사전 처리: 개체 기반 검색을 정교화함, 확인 지표는 graph consistency와 retrieval precision임

## Ⅷ. 결론

개체 연결은 텍스트를 실제 지식 객체로 정규화하는 관문이므로, 후보 생성 recall과 중의성 해소 precision을 함께 관리해야 지식그래프와 RAG 품질이 안정됨.
