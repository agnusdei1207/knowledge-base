## 미리 알고가기

- GPU는 대량 병렬 연산을 위해 설계된 프로세서로 현대 AI 학습과 추론의 사실상 표준 가속기임
- 수천 개의 코어와 높은 메모리 대역폭으로 행렬 연산에 강점을 가짐
- GPU 성능은 코어 수뿐 아니라 VRAM 용량과 대역폭과 통신 구조의 영향을 크게 받음

## Ⅰ. 개요

- **정의/개념**: GPU는 원래 그래픽 렌더링을 위해 개발되었지만 대규모 병렬 연산 구조 덕분에 딥러닝의 행렬과 텐서 계산을 빠르게 처리하는 범용 AI 가속기로 확장된 프로세서임
- **배경/필요성**: 딥러닝이 대량 선형대수 연산에 의존하면서 CPU보다 훨씬 높은 병렬 처리량을 제공하는 GPU가 학습과 추론 인프라의 핵심 자원으로 자리 잡음

## Ⅱ. 특징

- 많은 연산 코어가 같은 명령을 여러 데이터에 병렬 적용하는 구조에 강함
- Tensor Core 같은 전용 연산 블록으로 AI 처리 성능을 높임
- VRAM 대역폭과 용량이 모델 크기와 배치 크기를 제한함
- 고성능 GPU는 전력과 냉각 요구가 커 데이터센터 설계에 직접 영향을 줌

## Ⅲ. 종류 및 비교

| 판단 기준 | GPU | CPU | TPU |
|:---|:---|:---|:---|
| 병렬성 | 매우 높음 | 낮음 | 매우 높음 |
| 범용성 | 높음 | 가장 높음 | 특정 생태계 중심 |
| AI 학습 적합성 | 높음 | 낮음 | 높음 |
| 주요 병목 | 메모리와 통신 | 연산량 | 컴파일과 종속성 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Streaming Multiprocessor | 다수의 스레드를 동시에 실행해 병렬 처리량을 제공하는 GPU의 기본 연산 블록임 |
| Tensor Core | 행렬 곱과 누산 연산을 고속 수행해 딥러닝 처리량을 높이는 전용 연산 유닛임 |
| VRAM | 모델 파라미터와 activation과 입력 데이터를 저장하며 용량과 대역폭이 워크로드 상한을 결정함 |
| Memory Bus and Interconnect | GPU 내부와 외부 메모리와 다른 GPU 사이의 데이터 이동 속도를 결정하는 연결 구조임 |
| Driver and CUDA Runtime | 프레임워크가 GPU 연산을 사용할 수 있게 하는 소프트웨어 계층으로 생태계 경쟁력을 좌우함 |

```text
+--------------------+    +--------------+    +----------------------+
| Streaming MP Array |<-> | Tensor Cores |<-> | VRAM / Memory Bus    |
+--------------------+    +--------------+    +----------------------+
             |
             v
      +------------------+
      | Driver / Runtime |
      +------------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
| 커널 실행 준비 | -> | 데이터 적재  | -> | 병렬 커널 실행 | -> | 메모리 동기화 | -> | 결과 회수    |
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
```

1. **커널 실행 준비**: 프레임워크가 GPU 커널과 데이터를 준비함
2. **데이터 적재**: 입력과 가중치를 VRAM에 올림
3. **병렬 커널 실행**: 다수 스레드가 텐서 연산을 병렬 처리함
4. **메모리 동기화**: 계산 결과와 중간 상태를 동기화함
5. **결과 회수**: 결과를 시스템 메모리나 다음 연산 단계로 전달함

## Ⅵ. 문제점 및 해결 방안

1. 문제: GPU 메모리 용량과 대역폭이 부족하면 큰 모델에서 잦은 메모리 이동으로 처리 효율이 급격히 떨어질 수 있음
   - 해결방안: mixed precision과 memory optimization을 적용하고 VRAM utilization과 memory transfer overhead로 검증함
2. 문제: 멀티 GPU 환경에서 통신 비용이 커지면 단일 GPU 대비 기대 성능 향상이 제한될 수 있음
   - 해결방안: NCCL tuning과 topology aware placement를 적용하고 multi gpu scaling efficiency와 inter gpu sync time으로 검증함
3. 문제: 높은 전력과 발열은 장시간 학습 시 클럭 저하와 운영 비용 상승을 초래할 수 있음
   - 해결방안: thermal management와 power cap tuning을 적용하고 performance per watt와 thermal throttling rate로 검증함

## Ⅶ. 적용 사례

- 대형 언어모델 학습 환경이 mixed precision을 적용하며 확인 지표는 VRAM utilization과 memory transfer overhead임
- 멀티 GPU 추론 서비스가 통신 최적화를 수행하며 확인 지표는 multi gpu scaling efficiency와 inter gpu sync time임
- 데이터센터 GPU 팜이 전력 캡 정책을 운영하며 확인 지표는 performance per watt와 thermal throttling rate임

## Ⅷ. 결론

GPU는 AI 인프라의 핵심 범용 가속기이지만 메모리와 통신과 전력 제약을 함께 최적화해야 기대 성능을 얻을 수 있음.
