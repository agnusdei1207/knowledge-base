## 미리 알고가기

- 지시 튜닝은 지시문과 응답 쌍으로 모델이 인간의 요청 형식을 따르도록 만드는 SFT 방식임
- base model을 assistant model로 바꾸는 핵심 전환 단계로 많이 사용됨
- 다양한 태스크와 포맷을 포함한 고품질 instruction 데이터셋이 성능을 좌우함

## Ⅰ. 개요

- **정의/개념**: 지시 튜닝은 자연어 지시와 기대 응답을 학습시켜 모델이 단순 다음 토큰 예측을 넘어 사용자의 명령 의도를 파악하고 형식에 맞게 답하도록 만드는 supervised fine-tuning 기법임
- **배경/필요성**: 사전학습 모델은 언어 패턴은 잘 모방하지만 요약, 분류, 추출, 형식 준수 같은 사용자 지시 수행 능력은 부족하므로, 대화형 서비스에는 지시 중심 적응 단계가 필요함

## Ⅱ. 특징

- zero-shot과 few-shot 지시 수행 능력을 크게 높여 assistant 사용성을 개선함
- 다양한 태스크를 한 데이터셋에 묶어 일반화 능력을 넓힐 수 있음
- 데이터 품질이 낮으면 잘못된 포맷과 부정확한 응답 습관이 그대로 굳어질 수 있음
- 안전성이나 선호 정렬은 별도 RLHF, DPO 단계가 추가로 필요한 경우가 많음

## Ⅲ. 종류 및 비교

| 판단 기준 | Base Model | Instruction-Tuned Model | RLHF/DPO 적용 모델 |
|:---|:---|:---|:---|
| 지시 수행력 | 낮음 | 높음 | 높음 |
| 포맷 준수 | 제한적임 | 높음 | 높음 |
| 안전성 정렬 | 낮음 | 중간 | 높음 |
| 대표 활용 | 연구 기반 모델 | 일반 챗봇, 업무 보조 | 상용 대화형 제품 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Instruction Dataset | 지시문, 맥락, 기대 응답을 포함해 모델이 수행해야 할 업무 패턴을 정의함 |
| Template Formatter | 다양한 표현 방식과 출력 형식을 데이터에 반영해 일반화 범위를 넓힘 |

| Evaluation Suite | unseen task, format pass rate, safety score를 함께 측정해 실제 assistant 품질을 판단함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 지시 데이터 구축 | --> | SFT 학습 수행   | --> | 미학습 태스크 평가 | --> | assistant 배포  |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **지시 데이터 구축**: 태스크별 지시문과 정답 응답을 정제하고 다양화함
2. **SFT 학습 수행**: 기반 모델이 지시를 따르는 응답 패턴을 학습하도록 업데이트함
3. **미학습 태스크 평가**: 학습에 없는 지시에서도 일반화가 유지되는지 확인함
4. **assistant 배포**: 실제 대화형 서비스나 업무 보조 흐름에 연결함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 저품질 instruction 데이터가 많으면 모델이 잘못된 답변 패턴과 포맷 오류를 그대로 학습할 수 있음
   - 해결방안: synthetic data와 human review를 결합하고 format pass rate와 factual accuracy로 데이터 품질을 검증함
2. 문제: 학습 데이터의 지시 유형이 편향되면 보지 못한 태스크에서 일반화 성능이 크게 떨어질 수 있음
   - 해결방안: 태스크 다양성과 표현 다양성을 확보하고 held-out task score와 instruction diversity coverage로 일반화를 검증함
3. 문제: 지시 수행력을 높였더라도 유해 요청이나 정책 위반 요청에 그대로 응답할 위험이 남을 수 있음
   - 해결방안: 안전성 평가셋과 후속 정렬 단계를 운영하고 refusal accuracy와 safety violation rate로 통제 수준을 검증함

## Ⅶ. 적용 사례

- 범용 업무 챗봇이 요약과 분류와 표 생성 지시를 수행하도록 지시 튜닝을 적용하며 확인 지표는 task accuracy와 format pass rate임
- 사내 문서 보조가 조직별 템플릿에 맞는 초안을 작성하도록 지시 튜닝을 활용하며 확인 지표는 user edit rate와 adoption rate임
- 코드 어시스턴트가 테스트 작성과 설명 생성 같은 지시를 처리하도록 지시 튜닝을 적용하며 확인 지표는 accepted suggestion rate와 latency임

## Ⅷ. 결론

지시 튜닝은 base model을 실제 assistant로 바꾸는 출발점이므로, 태스크 다양성과 데이터 품질을 확보하고 안전성 정렬 단계를 별도로 연결해야 상용 수준에 도달함.
