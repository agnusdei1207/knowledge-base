## 미리 알고가기

- 지시어 튜닝 ($Instruction$ $Tuning$): 사전학습 완료된 단순 문서 이어쓰기 모델(Base Model)을 사용자의 구체적인 명령(요약, 번역, QA 등)에 딱 맞춰 비서처럼 동작하는 대화형 모델(Instruction-Tuned Model)로 개조하는 $SFT$(Supervised Fine-Tuning) 계열 기술임
- 미적용 태스크 일반화 ($Held-out$ $Tasks$): 훈련 과정에서 단 한 번도 보지 못한 완전히 낯선 유형의 작업(Task)에 대해서도, 지시어의 맥락을 스스로 유추해 지적 추론을 해내는 zero-shot 일반화 능력임
- 합성 데이터 ($Synthetic$ $Data$): 사람의 수동 작성 오버헤드를 탈피하기 위해, GPT-4 등 상위 모델의 프롬프트 질의응답 데이터 생성 기법(예: Self-Instruct)을 통해 추출한 모조 훈련 데이터셋임
- 정렬 ($Alignment$): 인공지능이 인간의 가치관, 안전 규정, 지침에 맞춰 안전하고 공손하게 행동하도록 규제하는 기구(RLHF/DPO 등)임

## Ⅰ. 개요

- **정의/개념**: Instruction Tuning은 원형의 기반 모델(Base Model)이 단순히 문장의 꼬리를 잇는 앵무새식 작문에서 벗어나도록, 지시 지침(Instruction)과 맥락(Context), 그리고 모범 행동(Response) 쌍의 데이터셋을 주입하여 사용자의 의도($Intent$)를 짚어내는 비서로 교정하는 지도 미세 조정($SFT$) 최적화 기법임
- **배경/필요성**: 인터넷 텍스트 전체를 사전학습한 Base 모델은 똑똑하지만 "대한민국의 수도는?"이라는 지시에 "대한민국의 수도는 서울이고, 일본의 수도는 도쿄이다" 같은 이어쓰기만 가동하여, 실제 고객이 사용할 수 있는 대화형 API 제품으로 변모시키기 위해 필수 발명됨

## Ⅱ. 특징

- 학습 데이터셋에 포함되지 않은 완전히 새로운 미학습 태스크($Held-out$ $Tasks$)에 대해서도 지시어 의미를 해독하여 임기응변해 내는 Zero-shot 능력을 완성함
- 데이터셋의 절대적인 양보다는, 다양한 지시어 포맷 구성과 태스크 카테고리의 다양성(Diversity)이 최종 모델의 지능 수준을 결정함
- 사용자의 프롬프트 비서($Assistant$) 사용성을 극대화하지만, 유해한 지시(예: 폭탄 제조)에 정제 없이 공손하게 모범 응답해 버리는 정렬 안전성 부재 부작용을 동반함

## Ⅲ. 종류 및 비교

| 판단 기준 | 사전학습 기본 모델 (Base Model) | 지시어 튜닝 완료 모델 (Instruction-Tuned) | 정렬 정제 모델 (RLHF / DPO Alignment) |
|:---|:---|:---|:---|
| **동작 메커니즘** | 단순 텍스트 이어쓰기 (Next-Token) | 사용자의 지시문 명령 수행 위주 | 인간의 가치관, 유해성 안전 규칙 준수 |
| **대표적인 산출물** | Llama 3 (Base) | Llama 3 Instruct (SFT) | Llama 3 Chat (DPO 정렬 완제품) |
| **안전성 (가드레일)** | 최하 (이상 텍스트 여과 없이 출력) | 낮음 (유해한 탈옥 질문에도 공손히 답변) | 최상 (부적절한 질문에 정중한 거절 기동) |
| **주요 적합 용도** | 추가 도메인 미세조정용 재료 | 연구용 가벼운 챗봇, 사내 포맷 보조 | 상영상용 고객 접점 챗봇, 종합 비서 |

> 요약: Base는 가공되지 않은 지식 원석이고, Instruction-Tuned는 명령을 해독하는 수련생이며, Alignment는 위험 요청을 거를 줄 아는 안전 보장 사회인임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 지시-응답 페어 | SFT 학습의 기초가 되는 요약, 번역, 추론 템플릿의 지시-정답 세트 데이터임 |
| $Self-Instruct$ 엔진 | 상위 모델을 구동하여 학습용 합성 데이터를 자가 대량 합성 생산하는 모듈임 |
| 손실 계산 마스크 | 지시어 부분(Prompt) 연산 오차는 스킵하고, 정답부(Response)의 예측 손실만 계산하는 마스크임 |
| $Held-out$ 검증 스택 | 훈련에 없던 낯선 지시어(예: 시 작성 등)를 런타임 인입해 지능을 평가하는 suite임 |

```text
[ Base에서 Chat 모델로의 진화 여정 ]
[Base Model] ---> (Instruction Tuning / SFT) ---> [Instruction-Tuned Model]
                                                             │
                                                             v (RLHF / DPO Alignment)
                                                      [Chat Model (Safe)]
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 태스크 다양 | --> | 프롬프트마스킹| --> | 역전파 및   | --> | Held-out    |
| SFT 데이터셋|     | 오차 연산제외|     | 가중치 업데이트|     | 일반화평가  |
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **말뭉치 정렬** — 분류, 독해, 코딩 등 수십 가지 태스크 범주를 아우르는 지시어-응답 템플릿 데이터셋을 조립함
2. **템플릿 마스킹** — 질문 지시문(Prompt) 구간의 예측 손실은 업데이트에서 거르는 타깃 토큰 마스킹 필터를 설정함
3. **가중치 수렴** — SFT 훈련을 돌려 "요약해라", "분류해라" 등의 명령어가 인입되었을 때 가중치가 응답의 첫 단어를 정확히 조준하도록 유도함
4. **일반화 테스트** — 학습 큐에 없던 참신한 질문을 던져 포맷 준수율($Format$ $Pass$ $Rate$)을 계측하고 비서로서의 완성도를 검증함

## Ⅵ. 실무 적용 및 유의점

1. 웹 크롤링된 가짜 정보나 정밀하지 못한 '저품질 합성 데이터(Synthetic Data)'로 지시 튜닝을 도배하면 모델이 환각 왜곡 답변을 뱉는 폐해가 생기므로, 반드시 상위 LLM의 필터링 프롬프트와 인간 검토진의 정성적 샘플 조율을 병행하여 팩트 정확성 지표($Factual$ $Accuracy$)를 지켜내야 함
2. 지시어 튜닝만 마친 모델은 해커들의 탈옥(Jailbreak) 질문이나 위험 유해성 유도 질문에 대해 "예, 기꺼이 폭탄을 만들어 드릴게요" 식의 순종적 오답을 낼 수 있으므로, 반드시 후단에 '거절률($Refusal$ $Accuracy$)'을 조율하는 가드레일 정렬(DPO)을 결합해야 함

## Ⅶ. 결론

- 지시어 튜닝은 단순 지식 백과사전 깡통을 인간과 상호작용 가능한 똑똑한 비서 아키텍처로 도약시키는 추론 정렬의 첫 단추이며, 설계자는 무분별한 저품질 합성 데이터에 의한 할루시네이션 오염 예방과 위험 탈옥 공격에 방어하는 안전 정렬 체계를 철저히 결합해야 함
