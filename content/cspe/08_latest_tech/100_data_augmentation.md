## 미리 알고가기

- 데이터 증강 ($Data$ $Augmentation$): 학습용 원천 데이터셋의 볼륨 부족과 편향성을 극복하기 위해, 원본 데이터의 통계적 라벨 의미를 훼손하지 않는 범위 내에서 미세 변형(회전, 대칭, 노이즈 주입, 동의어 치환 등)을 가하여 물리적인 데이터 개수를 증폭하는 기법임
- 역번역 ($Back-translation$): 한국어 문장을 영어로 번역했다가 다시 한국어로 이중 재번역하여, 원래의 문맥 의미는 사수하면서 문장 형태와 조사만 다르게 자연스럽게 변형하는 텍스트 증강 기법임
- 동의어 치환 ($SR$, Synonym Replacement): 텍스트 내 중요하지 않은 수식어를 사전($WordNet$ 등)에 등록된 유사 동의어로 교체해 나가는 기법임
- 라벨 누수 및 오염 ($Label$ $Leakage$): 증강을 위해 가한 변형이 도를 지나쳐(예: '비행기' 이미지의 주요 날개를 잘라내는 크롭), 정답 라벨의 팩트 의미 자체가 손상 왜곡되는 심각한 오류 현상임

## Ⅰ. 개요

- **정의/개념**: Data Augmentation은 기계 학습 모델의 과적합($Overfitting$)을 차단하고 보지 못한 데이터에 대한 일반화($Generalization$) 한계 성능을 높이기 위해, 오리지널 수집 데이터에 수학적 공간 변환(비전)이나 의미론적 등가 변형(텍스트)을 동적 적용하여 데이터셋의 절대 용량을 비약적으로 증식하는 데이터 엔지니어링 기술임
- **배경/필요성**: 산업 특화 도메인(의료, 불량 판정 등)은 양질의 라벨 데이터 수집비가 극도로 비싸고 데이터 편향이 심하여 딥러닝 모델 학습 시 쉽게 유휴 과적합되므로, 동일 가중치 정보 가용성을 증폭할 현실적 기법이 절실하여 활용됨

## Ⅱ. 특징

- 아예 가상으로 창조해 내는 합성 데이터($Synthetic$ $Data$)와 달리, 원본 실관측치의 분포(Distribution) 뼈대 위에서 변형을 꾀하므로 데이터 왜곡 리스크가 매우 낮음
- 텍스트 도메인은 동의어 치환($SR$), 역번역($Back-translation$), 이미지 도메인은 믹스업($Mixup$), 오려붙이기($CutMix$) 등 영역별 다변화된 기술 체계를 가짐
- 증강 기법의 무리한 남용은 모델의 정밀도 해상도를 떨어뜨려 정답 바운더리를 뭉개버리는 부정 작용을 유발함

## Ⅲ. 종류 및 비교

| 판단 기준 | 원천 데이터 단독 사용 | 데이터 증강 (Data Augmentation) | 합성 데이터 (Synthetic Data) |
|:---|:---|:---|:---|
| **데이터 획득 기원** | 현실 물리 공간에서의 실측 채집 | 기존 실측 채집 데이터의 변형 및 왜곡 유도 | 생성 모델(LLM 등)을 통한 완전 무(無)에서의 창조 |
| **의미 무결성 방어** | 완벽함 ($100\%$ 팩트) | 우수함 (라벨 훼손 없는 경계 내 변형 고수) | 보통 (환각 및 통계적 이격 위험 상재) |
| **개인정보 유출 리스크** | 존재함 (개별 오버헤드 정제 요함) | 존재함 (원본 기밀이 증강본에 잔존) | 원천 없음 (가상 통계값 사상) |
| **데이터셋 팽창 한계** | 불가능 (추가 취득 예산 수반) | 중간 수준 (변형 기법 가짓수 한계) | 무제한 (컴퓨터 연산력 비례 무한 팽창 가능) |

> 요약: 원천 데이터는 유일한 기준자이고, 데이터 증강은 기준자의 포즈와 조명을 다양하게 꺾는 응용이며, 합성 데이터는 가상의 가짜 기준자를 무한 창출하는 복사임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 원본 시드셋 | 증강을 위해 가공 전 대기하는 물리 채집 완료된 고품질 원천 데이터셋임 |
| 증강 변형 룰셋 | 회전($Rotate$), 동의어 치환($SR$), 역번역($Back-translation$) 등의 변환 공식들의 집합임 |
| 라벨 일치 필터 | 증강된 샘플이 원래 정답의 정체성($Identity$)을 유지하는지 필터링하는 검증기임 |
| 혼합 제어 스케줄러 | 훈련 루프 내에서 원본 대 증강 데이터의 공급 비중을 동적으로 조율하는 분배기임 |

```text
[ Data Augmentation (텍스트 역번역 증강) 구조 ]
Original Text (Ko) ───> [ Translation to English ] ───> Translated Text (En)
                                                               │
Original Text (Ko) <─── [ Re-translation to Korean ] <─────────/ (Back-translated Text)
      │
      + (Concatenate & Mixed training)
      v
Final Augmented Training Set
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 원본 시드셋 | --> | 데이터 도메인| --> | 훼손 여부   | --> | 최적 비율로 |
| 로딩 및 분류 |     | 변형 공식적용|     | 라벨링 검증 |     | 결합 및 훈련|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **시드 선별** — 기 수집된 데이터셋 중 클래스 빈도가 부족해 불균형(Imbalance)을 초래하는 소수 레이블 데이터를 선별 격리함
2. **등가 변환** — 텍스트의 경우 역번역 모듈을 기동하여 "안녕하세요"를 "hello"로 보낸 뒤 다시 "반갑습니다"로 받아내는 식의 변형을 침
3. **라벨 훼손 검사** — 증강된 데이터가 의미적 정체성을 붕괴시키지 않았는지 라벨 일치율($Label$ $Consistency$) 필터를 구동함
4. **혼합 가동** — 원본과 증강 데이터를 최적의 믹싱 비율(예: $1:1$)로 감싸, 모델의 에폭(Epoch) 손실 값을 역전파 고속 수렴시킴

## Ⅵ. 실무 적용 및 유의점

1. 텍스트 증강 시 동의어 치환을 무차별 단행하다가 문장의 문맥 가독성 자체가 파괴되어 '라벨 누수 및 오염(Label Leakage)'이 생길 수 있으므로, 반드시 형태소 분석기를 켜서 중요 핵심 명사를 보호 대상(Frozen Words)으로 격리 설정하고 훈련 품질을 감시해야 함
2. 단순히 회전, 노이즈 삽입 등의 이지(Easy) 증강만 대량 추가하면 파일 크기만 낭비되고 실서비스의 다양한 경계 예외(Edge Cases) 방어력이 향상되지 않으므로, 에러 발생 패턴을 분석해 취약 도메인을 집중 타격하는 강건성 스코어($Robustness$ $Score$)를 보증해야 함

## Ⅶ. 결론

- 데이터 증강은 고비용의 데이터 확보 병목을 기하학적/언어적 등가 변형으로 돌파하여 모델의 일반화 체력을 육성하는 고전적이지만 가장 확실한 기초 물리 체력이며, 설계자는 무리한 변형에 따른 라벨 오염 차단책과 예외 시나리오 집중 대응 강건성 설계를 반드시 제공해야 함
