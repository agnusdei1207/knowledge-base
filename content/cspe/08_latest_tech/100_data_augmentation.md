# 📖 【암기용】 개념 완전 이해

## 한눈에
- **정의**: 기존에 보유한 한정된 학습 데이터를 자르고, 돌리고, 단어를 교체하는 등의 변형을 가하여 데이터의 양과 다양성을 늘리는 딥러닝 필수 기법.
- **필요성**: 데이터가 적으면 모델이 정답을 그냥 외워버려서(과적합, Overfitting) 실제 환경에서 조금만 조건이 바뀌어도 제대로 동작하지 못함.
- **핵심 직관**: 고양이 사진을 그냥 외우게 하는 게 아니라, 사진을 뒤집고, 흑백으로 만들고, 찌그러뜨려서 훈련시킴으로써, 모델이 "어떤 각도와 색상에서도 고양이의 본질적 특징"을 학습하게 강제하는 것.

## 깊이 이해
- **배경**: 컴퓨터 비전(CNN) 시대에 과적합을 막고 모델을 강건하게(Robust) 만들기 위한 핵심 트릭으로 발전. 최근에는 NLP(자연어)와 RAG(검색) 환경에서도 필수 기법으로 자리 잡음.
- **작동 원리**:
  1. 원본 데이터 $X$와 정답 라벨 $Y$가 있음.
  2. $X$에 특정 변환 함수 $T$를 적용하여 $X_{new}$를 만듦 (라벨 $Y$는 그대로 유지됨).
  3. 변형된 데이터를 기존 데이터셋에 추가하여 모델 학습. 모델은 변화무쌍한 입력에도 동일한 출력을 내도록 훈련됨.
- **비유**: 야구 타자가 직구만 치는 연습(원본 데이터)을 하다가, 피칭 머신의 속도를 바꾸고 커브, 슬라이더(데이터 증강)를 섞어 연습하면서 실전 적응력을 키우는 것.
- **구체 예시**: (비전) 강아지 사진을 좌우반전(Flip)하고 밝기(Brightness)를 조절함. / (자연어) "이 영화 재밌다" $\rightarrow$ 유의어 교체 $\rightarrow$ "이 영화 즐겁다". / (LLM/RAG) 질문을 유사한 다른 문장으로 Paraphrasing.
- **흔한 오해/주의점**: 정답(Label)의 의미를 훼손하는 증강은 재앙임. 예를 들어 '의료 엑스레이 이미지'를 좌우반전하면 심장이 오른쪽에 있는 것으로 학습되어 오진을 유발함. '6'을 상하반전하면 '9'가 되므로 라벨이 박살 남. 도메인 지식 기반의 증강 규칙 수립이 필수적임.

## 연결 개념
- **Synthetic Data (합성 데이터)**: 기존 데이터를 변형하는 증강(Augmentation)과 달리, 생성 모델을 이용해 아예 무에서 유로 새로운 데이터를 창조해 내는 상위/인접 개념.
- **Overfitting (과적합 방지)**: 데이터 증강을 수행하는 가장 근본적인 목적. Dropout, Regularization과 같은 역할을 함.
- **Hard Negative Mining**: 모델이 헷갈려할 만한 오답을 일부러 증강하여 학습시켜 변별력을 높이는 기법.

# 📝 【답안용】 시험 답안 템플릿
## 핵심 인사이트 (3줄 요약)
- **본질**: 원본 데이터에 라벨을 보존하는(Label-preserving) 다양한 수학적·기하학적·의미론적 변환을 가하여 학습 공간을 확장하는 정규화(Regularization) 기법.
- **가치**: 값비싼 추가 데이터 수집이나 라벨링 비용 없이 데이터의 다양성(Diversity)을 극대화하여, 모델의 일반화(Generalization) 성능을 높이고 노이즈에 대한 강건성을 확보함.
- **판단 포인트**: 도메인 특성을 반영한 금지 변환(Invalid Transformation) 차단, 오염된 평가(Leakage) 방지를 위한 엄격한 Hold-out 분리, 원본 대비 벤치마크 성능 향상분 검증.

## Ⅰ. 개요 및 필요성
- **정의**: 수집된 학습 데이터에 노이즈 추가, 기하학적 변환, 단어 치환 등의 기법을 적용하여 인위적으로 데이터의 규모와 변용성을 늘리는 데이터 전처리 기술.
- **배경**: 심층 신경망(DNN)은 파라미터가 방대하여 훈련 데이터의 지엽적 특징(Noise)까지 암기해버리는 과적합(Overfitting)에 취약함.
- **필요성**: 현실 세계의 다양한 센서 노이즈, 카메라 각도, 사용자의 다양한 언어 표현 방식에 흔들리지 않는 강건한(Robust) 모델을 저비용으로 구축하기 위함.

## Ⅱ. 도메인별 데이터 증강 기법 (핵심 기술)
| 도메인 | 주요 기법 | 메커니즘 및 특징 |
|:---|:---|:---|
| **컴퓨터 비전 (CV)** | 기하학적 변환 (Geometric) | 회전(Rotation), 이동(Translation), 반전(Flip), 자르기(Crop). 공간적 불변성(Invariance) 학습. |
| | 색상/노이즈 변환 | 밝기 조절, Color Jitter, 가우시안 노이즈 추가. |
| | 고급 믹싱 기법 | CutOut, MixUp(두 이미지를 알파 블렌딩 융합), CutMix. |
| **자연어 처리 (NLP)** | 텍스트 변환 (Text) | 유의어 교체(Synonym Replacement), 무작위 단어 삽입/삭제. (EDA 기법) |
| | 역번역 (Back-translation) | 한국어 $\rightarrow$ 영어 번역 후, 다시 영어 $\rightarrow$ 한국어로 번역하여 자연스러운 문장 변형 유도. |
| **음성 (Audio)** | 오디오 신호 변환 | 속도 변환, 피치(Pitch) 변환, 배경 백색소음(White Noise) 추가. |

## Ⅲ. 데이터 증강 운영 파이프라인
```text
[ 1. Train / Test Split ] (※ 증강 전에 반드시 분리하여 Leakage 차단)
          |
[ 2. Train Data ] -> [ Augmentation Engine ]
                          - 도메인 규칙에 따른 Random Transform 수행
                          - Label Validation (라벨 훼손 검증)
          |
[ 3. Original + Augmented Data 결합 ]
          |
[ 4. Model Training ] -> [ Robust Model 확보 ]
          |
[ 5. Test Data (Original)로 최종 성능 평가 ]
```

## Ⅳ. 심화 비교 (Data Augmentation vs Synthetic Data)
| 비교 항목 | Data Augmentation (증강) | Synthetic Data (합성 데이터) |
|:---:|:---|:---|
| **생성 기반** | **원본 데이터 종속 (조작 및 변형)** | 무(無)에서 알고리즘(생성 모델/시뮬레이터)으로 창조 |
| **기술 복잡도** | 비교적 단순 (규칙 기반, 필터) | 매우 복잡 (GAN, LLM, 3D 렌더링 필요) |
| **프라이버시** | 원본 PII가 남아있어 유출 위험 있음 | 통계적 특성만 가져와 개인정보 규제 프리 |
| **적용 목적** | 일반화 및 과적합 방지 | 희귀 데이터 확보, 라벨링 비용 제로화 |

## Ⅴ. 한계점(리스크) 및 해결 방안
- **리스크 1: 도메인 특성 무시로 인한 라벨 훼손 (Label Corruption)**:
  - 의료용 X-ray 흉부 이미지를 좌우반전(Flip)하면 장기 위치가 역전되어 병 진단 라벨이 훼손됨. 도로 표지판의 '좌회전'을 좌우반전하면 '우회전'이 되는데 동일 라벨로 학습하면 치명적 오작동 발생.
  - **대응 방안**: 도메인 전문가(SME)가 참여하여 '금지 변환(Invalid Transforms) 규칙'을 정의하고, NLP의 경우 증강 전/후 문장의 BERTScore 유사도가 0.85 이하로 떨어지면 해당 데이터를 폐기하는 룰 적용.
- **리스크 2: 평가 오염 (Data Leakage)**:
  - 증강된 데이터가 검증/테스트 셋(Test Set)에 포함되어 모델 성능이 과대평가(착시)되는 현상.
  - **대응 방안**: 증강 작업 전에 반드시 Train / Test Split을 수행하고, 테스트 시에는 증강을 전혀 가하지 않은 순수 현실 데이터(Hold-out)로만 평가.

## Ⅵ. 실무 적용 및 결론
- **판단 지표**: 오리지널 데이터셋 학습 모델 대비 증강 데이터셋 학습 모델의 Hold-out Test Accuracy 향상 폭, Loss 수렴 안정성.
- **실무 설계**: 기업형 RAG(검색 증강 생성) 시스템 검색기(Retriever) 고도화 시, 사용자의 실제 검색어 길이가 짧아 모델이 문서를 잘 못 찾는 문제 발생. 'Back-translation' 및 'LLM 기반 Paraphrasing'을 통해 문서 내용에 대한 예상 질의(Query)를 5배로 증강(Augment)하여 임베딩 모델을 파인튜닝, 검색 재현율(Recall) 향상 달성.
- **결론**: 데이터 증강은 단순한 전처리 과정이 아니라, 딥러닝 모델이 현실 세계의 불확실성에 대응하게 만드는 '지능적 정규화'의 핵심이며, 올바른 도메인 규칙 적용이 프로젝트 성패를 가름.

### 🔀 문제 유형별 목차 전환
- **Ⅱ·Ⅲ 강조 (개념/원리형)**: 이미지(MixUp 등), NLP(역번역), 오디오 영역별 대표 증강 기법들의 수학적/알고리즘적 메커니즘을 풍부하게 서술.
- **Ⅴ·Ⅵ 강조 (실무/설계형)**: 라벨 훼손(Label Corruption) 사례 및 방어 논리, Data Leakage 방지를 위한 파이프라인 설계, RAG 및 최신 LLM 파인튜닝에서의 증강 적용 사례 중심 작성.
