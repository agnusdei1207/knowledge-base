## 미리 알고가기

- 데이터 증강은 기존 데이터를 변형해 추가 학습 샘플을 만드는 방식임
- 합성 데이터보다 원본 데이터와의 연결성이 강해 분포 왜곡 위험이 상대적으로 낮음
- 변형 방식이 업무 의미를 훼손하면 오히려 품질을 떨어뜨릴 수 있음

## Ⅰ. 개요

- **정의/개념**: 데이터 증강은 기존 학습 데이터에 변환과 치환과 노이즈 삽입 등을 적용해 샘플 다양성을 늘리고 모델 일반화 성능을 높이는 데이터 확장 기법임
- **배경/필요성**: 실제 수집 데이터가 적거나 편향되어 있으면 모델이 특정 표현이나 환경에 과적합되기 쉬우므로, 같은 의미를 가진 다양한 변형 데이터를 제공할 필요가 있음

## Ⅱ. 특징

- 원본 데이터에 기반하므로 완전 합성 데이터보다 의미 일관성을 유지하기 쉬움
- 입력 변동성에 강한 모델을 만들 수 있어 과적합 완화와 일반화 향상에 유리함
- 적절하지 않은 변형은 라벨 오염이나 의미 손상을 유발할 수 있음
- 텍스트, 이미지, 음성, 로그 등 데이터 유형별로 증강 방식이 달라져야 함

## Ⅲ. 종류 및 비교

| 판단 기준 | 원본 데이터만 사용 | 데이터 증강 | 합성 데이터 |
|:---|:---|:---|:---|
| 데이터 규모 확장 | 없음 | 중간 | 큼 |
| 분포 신뢰성 | 높음 | 높음 | 중간 |
| 라벨 오염 위험 | 낮음 | 중간 | 중간 이상 |
| 대표 활용 | 기준 학습 | 일반화 강화 | 대량 확장 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Source Samples | 원본 데이터가 증강 품질의 기준점을 제공하고 의미 보존 여부를 결정함 |
| Transformation Rules | 치환, 삭제, 회전, 노이즈 같은 변형 규칙이 일반화 방향을 정의함 |
| Label Preservation Check | 변형 후에도 라벨 의미가 유지되는지 확인해 학습 오염을 막음 |
| Mixing Strategy | 원본과 증강 샘플 비율을 조절해 과도한 변형 의존을 방지함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 원본 데이터 선택 | --> | 의미 보존 변형   | --> | 라벨 검증 수행   | --> | 원본과 혼합 학습 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **원본 데이터 선택**: 대표 샘플과 부족한 클래스 영역을 식별함
2. **의미 보존 변형**: 데이터 유형에 맞는 변형을 적용해 다양성을 늘림
3. **라벨 검증 수행**: 변형이 정답 의미를 훼손하지 않았는지 확인함
4. **원본과 혼합 학습**: 원본과 증강 데이터를 함께 학습해 일반화를 높임

## Ⅵ. 문제점 및 해결 방안

1. 문제: 텍스트 의미를 바꾸거나 이미지 핵심 특징을 훼손하는 과도한 변형은 라벨 오염을 일으켜 모델 품질을 떨어뜨릴 수 있음
   - 해결방안: 의미 보존 규칙을 먼저 정의하고 label consistency와 validation score로 변형 적합성을 검증함
2. 문제: 쉬운 변형만 반복하면 데이터 양만 늘고 실제 운영 환경의 다양성을 충분히 반영하지 못할 수 있음
   - 해결방안: 실패 사례 중심 증강을 설계하고 robustness score와 tail-case accuracy로 효과를 검증함
3. 문제: 증강 비율이 너무 높으면 모델이 인위적 패턴에 적응해 원본 분포 성능이 떨어질 수 있음
   - 해결방안: 원본 대비 증강 비율을 조정하고 real-data validation score와 augmentation gain으로 최적점을 검증함

## Ⅶ. 적용 사례

- 문서 분류 태스크: 동의어 치환과 문장 순서 변형을 적용함, 확인 지표는 F1 score와 robustness score임
- 비전 모델 학습: 회전, 크롭, 색상 변형을 적용함, 확인 지표는 top-1 accuracy와 generalization gap임
- 음성 인식: 잡음과 속도 변형을 사용함, 확인 지표는 WER와 noise robustness임

## Ⅷ. 결론

데이터 증강은 적은 비용으로 일반화를 높이는 고전적이지만 여전히 강력한 수단이므로, 변형 다양성보다 라벨 의미 보존을 먼저 통제해야 함.
