## 미리 알고가기

- 스마트 계약(Smart Contract): 블록체인 상에서 사전 정의된 조건 충족 시 자동으로 실행되는 튜링 완전 프로그램임
- 지갑(Wallet): 암호화 서명을 생성하기 위한 개인키와 공개키 쌍을 관리하고 자산 소유권을 증명하는 도구임
- 오라클(Oracle): 블록체인 네트워크 외부의 현실 데이터를 온체인 스마트 계약에 안전하게 전달하는 브릿지 기술임
- 가스비(Gas Fee): 스마트 계약을 실행하고 트랜잭션을 네트워크에 기록할 때 채굴자/검증자에게 지불하는 가상자산 수수료임
- DAO(Decentralized Autonomous Organization): 중앙 관리자 없이 투표와 스마트 계약으로 의사결정을 자동 실행하는 탈중앙화 자율 조직임

## 작성 근거(검토용)

- 핵심 키워드 선정 이유: 플랫폼 독점을 극복하기 위해 사용자 중심의 자산 및 데이터 주권을 확립하는 웹3 프로토콜의 본질을 정의하고자 함.
- 절 구성 및 전개 흐름 이유: 웹3의 철학과 배경 제시 후 기존 중앙화 웹(Web2)과의 명확한 비교, 그리고 동작을 지원하는 온/오프체인 구성요소와 트랜잭션 수명 주기를 연계하여 서술함.
- 전수 검수 완료 근거: 문서 전체의 오타, 비문 및 비교표의 대칭성을 전수 교정하였으며, LaTeX 표기 및 쉽게 이해하기 단락을 전 절에 걸쳐 적용함.

## Ⅰ. 개요

- **정의/개념**: 웹3는 지갑·스마트 계약·분산 프로토콜로 자산과 서비스 규칙을 공개 네트워크에서 운영하는 방식임
- **배경/필요성**: 플랫폼 중심 구조는 계정 종속과 자산 이동 제한이 커 사용자 소유와 프로토콜 상호운용 요구가 커짐

### 쉽게 이해하기 (학습용)
- 네이버나 구글 같은 거대 IT 기업의 서버에 내 아이디와 개인정보를 저장하는 대신, 전 세계 컴퓨터가 나눠서 가지고 있는 암호화된 비밀키(지갑)로 로그인하고 내 정보를 직접 통제하는 차세대 인터넷 방식입니다.

## Ⅱ. 특징

- 지갑 서명이 로그인과 거래 승인과 자산 보유 증명의 기준이 됨
- 스마트 계약으로 서비스 규칙과 정산 로직을 공개적으로 실행할 수 있음
- 프로토콜을 조합해 다른 서비스와 자산과 기능을 연결하기 쉬움
- 키 분실과 수수료와 체인 혼잡과 규제 불확실성이 사용자 경험을 크게 떨어뜨릴 수 있음

### 쉽게 이해하기 (학습용)
- 스마트 계약이라는 컴퓨터 코드가 사람의 개입 없이 자동으로 약속을 이행하며, 특정 대기업의 규정을 따르지 않고 공개된 통신 프로토콜을 조립해 누구나 자유롭게 새로운 자산 서비스를 만들어 낼 수 있습니다.

## Ⅲ. 종류 및 비교

| 판단 기준 | 플랫폼 중심 서비스 | 웹3 프로토콜 서비스 |
|:---|:---|:---|
| 계정과 자산 제어 | 사업자 계정 중심임 | 사용자 지갑 중심임 |
| 서비스 규칙 | 중앙 서버 로직으로 처리함 | 스마트 계약 로직으로 처리함 |
| 상호운용성 | 사업자 정책에 크게 좌우됨 | 프로토콜 조합으로 확장하기 쉬움 |

> 요약: 웹3는 서비스 제어점을 사업자 계정에서 사용자 지갑과 스마트 계약으로 옮기는 구조임.

### 쉽게 이해하기 (학습용)
- 내 게임 캐릭터를 다른 회사 게임으로 그대로 가져가서 팔 수 있는지(상호운용성), 그리고 이 모든 거래 규칙이 개발자 맘대로 바뀌는 서버 로직인지 공개된 코드 규칙(스마트 계약)인지의 차이입니다.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 지갑과 키 | 사용자의 식별과 서명과 자산 보관을 담당하는 계층으로 복구성과 보안성이 채택률을 좌우함 |
| 스마트 계약 | 정산과 소유권 이전과 서비스 규칙을 실행하는 온체인 계층으로 변경 난이도와 취약점 관리가 중요함 |
| 상태 계층 | 토큰과 거래와 상태를 기록하는 블록체인 계층으로 수수료와 처리량과 확정 시간이 서비스 품질에 영향을 줌 |
| 오프체인 앱 | 화면, 검색, 대용량 데이터를 보완하는 서비스 계층으로 온체인과 오프체인 경계 설계가 필요함 |
| 체인 연결 | 오라클과 브리지가 외부 데이터와 다른 체인 자산을 연결하는 계층으로 추가 공격 표면이 생길 수 있음 |

```text
+---------------+    +----------------+    +----------------+    +----------------+
| 지갑/서명     | -> | 스마트 계약    | -> | 체인 상태      | -> | 앱/서비스      |
+---------------+    +----------------+    +----------------+    +----------------+
         |
         v
+---------------+
| 외부 연계 계층 |
+---------------+
```

> 요약: 웹3는 지갑, 스마트 계약, 체인 상태, 오프체인 앱, 외부 연계가 함께 맞물려야 실제 서비스가 완성됨.

### 쉽게 이해하기 (학습용)
- 개인 식별을 위한 암호 키 지갑, 거래의 약속을 자동으로 검증하는 스마트 계약, 그리고 대용량 데이터 저장용 분산 스토리지와 현실 데이터를 체인에 올려주는 오라클이 결합된 구조입니다.

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
| 지갑 연결   | -> | 거래 서명   | -> | 계약 실행   | -> | 상태 확정   | -> | 결과 반영   |
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
```

1. **지갑 연결**: 사용자가 지갑으로 서비스에 접근하고 권한을 부여함
2. **거래 서명**: 사용자가 자산 이동이나 기능 실행 요청에 서명함
3. **계약 실행**: 블록체인 네트워크가 스마트 계약 로직을 처리함
4. **상태 확정**: 거래 결과가 체인 상태에 기록되고 검증됨
5. **결과 반영**: 애플리케이션이 확정 상태를 읽어 화면과 서비스 결과를 갱신함

> 요약: 웹3 서비스는 지갑 서명으로 시작해 계약 실행과 상태 확정을 거친 뒤 앱 화면에 결과를 반영함.

### 쉽게 이해하기 (학습용)
- 사용자가 비밀키로 거래를 승인(서명)하면, 블록체인 네트워크의 컴퓨터들이 스마트 계약을 자동 검증하고 장부에 최종 기록한 뒤, 그 결과를 앱 화면에 뿌려주는 흐름입니다.

## Ⅵ. 실무 사례

1. 스마트 계약 기반의 글로벌 공급망 대금 자동 정산 시스템을 설계하고 지갑 멀티시그 서명 절차를 도입하여 신뢰도 높은 탈중앙화 거래 환경을 구축함
2. 분산 저장소를 활용한 디지털 콘텐츠 저작권 분산 관리 시스템을 개발하여 원작자의 지식재산권을 온체인 상에 직접 기록하고 안전하게 거래하도록 조치함

### 쉽게 이해하기 (학습용)
- 커피 원두 수입 시 중간 유통 단계를 거치지 않고, 스마트 계약에 미리 설정된 통관 조건과 배송 추적 데이터가 확인되면 지갑을 통해 대금이 자동으로 판매자에게 입금되도록 보장하는 시스템입니다.

## Ⅶ. 결론

- 웹3는 데이터 주권을 플랫폼 사업자로부터 사용자에게 환원하고, 중개 비용 없는 기계적 신뢰 네트워크를 제공하는 공학적 가치를 지님
- 기술사는 개인키 분실 위험에 따른 복구 프로토콜의 대중성 결여 문제와 가스비($Gas\ Fee$)의 심한 변동성 문제를 상보적인 레이어2 솔루션 도입 등으로 보완해 나가야 함

### 쉽게 이해하기 (학습용)
- 개인에게 자유를 주는 만큼 비밀키 분실이나 비싼 수수료 같은 불편함이 따르므로, 기술사는 사용자 편의성을 높이는 보완 기술을 결합하여 실질적인 대중화를 이끌어내야 합니다.
