## 미리 알고가기

- 지갑은 사용자의 키를 보관하고 서명을 수행하는 도구임
- 스마트 계약은 블록체인 위에서 정해진 규칙을 자동 실행하는 프로그램임
- 온체인은 블록체인 안 기록을 뜻하고, 오프체인은 화면과 검색 같은 바깥 기능을 뜻함
- 오라클은 외부 데이터를 체인에 전달하는 연결 장치이고, 브리지는 다른 체인 자산을 이어 주는 구조임

## Ⅰ. 개요

- **정의/개념**: 웹3는 지갑·스마트 계약·분산 프로토콜로 자산과 서비스 규칙을 공개 네트워크에서 운영하는 방식임
- **배경/필요성**: 플랫폼 중심 구조는 계정 종속과 자산 이동 제한이 큼. 사용자 소유와 프로토콜 상호운용 요구가 커짐

## Ⅱ. 특징

- 지갑 서명이 로그인과 거래 승인과 자산 보유 증명의 기준이 됨
- 스마트 계약으로 서비스 규칙과 정산 로직을 공개적으로 실행할 수 있음
- 프로토콜을 조합해 다른 서비스와 자산과 기능을 연결하기 쉬움
- 키 분실과 수수료와 체인 혼잡과 규제 불확실성이 사용자 경험을 크게 떨어뜨릴 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | 플랫폼 중심 서비스 | 웹3 프로토콜 서비스 |
|:---|:---|:---|
| 계정과 자산 제어 | 사업자 계정 중심임 | 사용자 지갑 중심임 |
| 서비스 규칙 | 중앙 서버 로직으로 처리함 | 스마트 계약 로직으로 처리함 |
| 상호운용성 | 사업자 정책에 크게 좌우됨 | 프로토콜 조합으로 확장하기 쉬움 |
| 주의점 | 플랫폼 종속이 큼 | 키 관리와 수수료 부담이 큼 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 지갑과 키 | 사용자의 식별과 서명과 자산 보관을 담당하는 계층으로 복구성과 보안성이 채택률을 좌우함 |
| 스마트 계약 | 정산과 소유권 이전과 서비스 규칙을 실행하는 온체인 계층으로 변경 난이도와 취약점 관리가 중요함 |
| 프로토콜과 상태 계층 | 토큰과 거래와 상태를 기록하는 블록체인 계층으로 수수료와 처리량과 확정 시간이 서비스 품질에 영향을 줌 |
| 오프체인 앱과 저장소 | 화면, 검색, 대용량 데이터를 보완하는 서비스 계층으로 온체인과 오프체인 경계 설계가 필요함 |
| 외부 데이터와 체인 연결 | 오라클과 브리지가 외부 데이터와 다른 체인 자산을 연결하는 계층으로 추가 공격 표면이 생길 수 있음 |

```text
+---------------+    +----------------+    +----------------+    +----------------+
| 지갑/서명        | -> | 스마트 계약      | -> | 체인 상태        | -> | 앱/서비스       |
+---------------+    +----------------+    +----------------+    +----------------+
         |
         v
+---------------+
| 외부 연계 계층    |
+---------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
| 지갑 연결      | -> | 거래 서명      | -> | 계약 실행      | -> | 상태 확정      | -> | 결과 반영      |
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
```

1. **지갑 연결**: 사용자가 지갑으로 서비스에 접근하고 권한을 부여함
2. **거래 서명**: 사용자가 자산 이동이나 기능 실행 요청에 서명함
3. **계약 실행**: 블록체인 네트워크가 스마트 계약 로직을 처리함
4. **상태 확정**: 거래 결과가 체인 상태에 기록되고 검증됨
5. **결과 반영**: 애플리케이션이 확정 상태를 읽어 화면과 서비스 결과를 갱신함

## Ⅵ. 실무 적용 및 유의점

1. 공동 정산은 지갑 복구와 실패 복구 절차를 두고 거래 완료율·오서명 건수·지원 요청 건수로 확인함
2. 온체인 보상은 수수료 예산과 권리 범위를 정하고 유지율·평균 거래 비용·규정 위반 건수로 확인함

## Ⅶ. 결론

- 웹3는 제어점을 사용자 지갑과 프로토콜로 옮기는 구조이므로 키 관리·수수료·규제 부담을 감당할 업무에 적합함
