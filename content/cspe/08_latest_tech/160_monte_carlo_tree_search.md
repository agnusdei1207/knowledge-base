## 미리 알고가기

- MCTS는 전체 경우의 수를 다 보지 않고 유망한 경로를 통계적으로 탐색하는 트리 탐색 알고리즘임
- 기본 루프는 selection, expansion, simulation, backpropagation 네 단계임
- UCT는 탐험과 활용의 균형을 잡는 핵심 규칙임

## Ⅰ. 개요

- **정의/개념**: MCTS는 거대한 상태 공간에서 모든 경로를 전수 탐색하지 않고, 시뮬레이션 결과를 통계적으로 축적해 유망한 분기만 점진적으로 확장하면서 최선의 행동을 찾는 확률적 트리 탐색 알고리즘임
- **배경/필요성**: 바둑과 계획 문제처럼 분기 수가 매우 큰 환경은 minimax 기반 완전 탐색이 비현실적이므로, 제한된 시간 안에 근사 최적 결정을 내릴 수 있는 탐색 방식이 필요함

## Ⅱ. 특징

- 유망한 경로에 계산을 집중하는 비대칭 트리 확장을 수행함
- 언제 중단해도 현재까지의 최선 해를 반환할 수 있는 anytime 특성을 가짐
- rollout과 통계 업데이트로 평가 함수를 직접 설계하지 않아도 탐색이 가능함
- 시뮬레이션 비용이 크거나 분기 수가 지나치게 넓으면 효율이 급격히 떨어질 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | Minimax | MCTS | Neural MCTS |
|:---|:---|:---|:---|
| 탐색 방식 | 전수 기반 | 샘플 기반 | 샘플+신경망 |
| 가지치기 효율 | 휴리스틱 의존 | 통계 의존 | 높음 |
| 대규모 분기 대응 | 낮음 | 높음 | 매우 높음 |
| 대표 활용 | 체스 엔진 | 바둑, 계획 탐색 | AlphaGo류 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Tree Policy, Selection | 현재 트리에서 UCT 기준으로 가장 유망한 노드를 선택해 내려감 |
| Expansion | 아직 탐색하지 않은 행동을 새 자식 노드로 추가해 탐색 범위를 넓힘 |
| Simulation, Value Estimate | 선택 노드 이후의 결과를 rollout이나 가치 모델로 추정함 |
| Backpropagation | 시뮬레이션 결과를 상위 노드들에 누적해 방문 수와 가치 추정을 갱신함 |

```text
+-------------------+      +-------------------+      +-------------------+
| Selection         | ---> | Expansion         | ---> | Simulation / Val. |
+-------------------+      +-------------------+      +-------------------+
                                                           |
                                                           v
                                                   +-------------------+
                                                   | Backpropagation   |
                                                   +-------------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 유망 노드 선택  | --> | 자식 노드 확장  | --> | 시뮬레이션 수행  | --> | 통계 역전파 갱신 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **유망 노드 선택**: 현재 트리에서 가장 기대되는 경로를 고름
2. **자식 노드 확장**: 미탐색 행동을 새 노드로 추가함
3. **시뮬레이션 수행**: 롤아웃이나 가치 모델로 결과를 추정함
4. **통계 역전파 갱신**: 결과를 부모 경로까지 반영해 선택 기준을 개선함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 순수 랜덤 rollout은 깊은 트리에서 계산 비용은 큰데 의미 있는 평가 신호는 약해 효율이 떨어질 수 있음
   - 해결방안: value network와 truncated rollout을 적용하고 simulations per second와 win rate로 검증함
2. 문제: 가능한 행동 수가 매우 많으면 초기에 탐색이 너무 넓게 퍼져 유망 경로 집중이 늦어질 수 있음
   - 해결방안: policy prior와 progressive widening을 적용하고 branching efficiency와 search depth로 검증함
3. 문제: 같은 상태가 다른 경로로 반복 등장하는 문제를 처리하지 않으면 탐색 자원이 중복 소비될 수 있음
   - 해결방안: transposition table과 state caching을 적용하고 duplicate expansion rate와 search throughput으로 검증함

## Ⅶ. 적용 사례

- 바둑과 게임 에이전트가 제한 시간 안에 최선 수를 찾도록 MCTS를 적용하며 확인 지표는 win rate와 search depth임
- 로봇 경로 계획이 장애물 회피 경로를 탐색하도록 MCTS를 운영하며 확인 지표는 success rate와 planning latency임
- 추론형 에이전트가 여러 풀이 경로를 탐색하도록 MCTS를 활용하며 확인 지표는 task solve rate와 token efficiency임

## Ⅷ. 결론

MCTS는 거대한 탐색 공간에서 계산 자원을 유망 경로에 집중시키는 강력한 알고리즘이므로, rollout 효율화와 분기 축소 전략이 실무 성능을 결정함.
