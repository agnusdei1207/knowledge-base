## 미리 알고가기

- Self-Consistency는 하나의 답만 생성하지 않고 여러 추론 경로를 샘플링해 다수결로 최종 답을 정하는 기법임
- Temperature는 샘플 다양성을 조절하는 생성 제어 변수임
- Reasoning ensemble은 다양한 중간 추론 경로를 결합해 정답 안정성을 높이는 접근임

## Ⅰ. 개요

- **정의/개념**: Self-Consistency는 동일 문제에 대해 여러 Chain-of-Thought 경로를 생성한 뒤 가장 일관되게 반복되는 최종 답을 선택해 reasoning 정답률을 높이는 추론 집계 기법임
- **배경/필요성**: 단일 CoT는 우연히 잘못 든 추론 경로에 전체 답이 좌우될 수 있으므로, 복수의 경로를 샘플링해 공통으로 수렴하는 답을 채택하는 안정화 전략이 필요함

## Ⅱ. 특징

- 모델을 재학습하지 않고 추론 단계 집계만으로 정답률을 향상시킬 수 있음
- 경로 다양성이 충분할수록 오답 경로의 영향을 줄일 수 있음
- 계산량과 토큰 비용이 샘플 수에 비례해 증가함
- 수학, 규칙 적용, 짧은 논리 퍼즐에서 효과가 크지만 단순 지식 질의에는 비용 대비 이점이 작을 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | Greedy Decoding | Chain-of-Thought | Self-Consistency |
|:---|:---|:---|:---|
| 생성 경로 수 | 1개 | 1개 | 다수 |
| 오답 복원력 | 낮음 | 낮음 | 중간~높음 |
| 비용 | 낮음 | 중간 | 높음 |
| 적합 업무 | 단순 답변 | 복합 추론 | 정답 검증형 추론 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Diverse Sampler | temperature 등 샘플링 설정으로 서로 다른 추론 경로를 생성함 |
| Reasoning Path Set | 동일 질문에 대한 여러 중간 추론과 최종 답 후보 집합임 |
| Aggregator | 최종 답을 다수결이나 가중 집계 방식으로 통합해 대표 답을 선택함 |
| Confidence Filter | 경로 간 합의 수준이 낮을 때 재시도나 인간 검토로 넘길지 결정함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +---------------+     +-------------+     +-------------+
| 다중 샘플링  | --> | 경로별 답 생성 | --> | 답 집계      | --> | 신뢰도 판단  |
+-------------+     +---------------+     +-------------+     +-------------+
```

1. **다중 샘플링**: 동일 문제를 여러 번 생성해 서로 다른 reasoning 경로를 얻음
2. **경로별 답 생성**: 각 경로가 중간 추론과 최종 답을 독립적으로 도출함
3. **답 집계**: 최종 답 후보 중 가장 자주 등장하거나 신뢰도 높은 답을 선택함
4. **신뢰도 판단**: 합의 정도가 낮으면 추가 샘플링이나 상위 모델 검증으로 넘김

## Ⅵ. 문제점 및 해결 방안

1. 문제: 샘플 수를 늘릴수록 정답률은 오르지만 추론 시간과 토큰 비용이 선형적으로 증가해 운영성이 나빠질 수 있음
   - 해결방안: 난이도 기반 샘플 수 상한을 설정하고 answer accuracy 대비 token cost로 최적 샘플 수를 검증함
2. 문제: 경로 다양성이 부족하면 여러 번 생성해도 사실상 같은 오답이 반복되어 다수결 효과가 약해질 수 있음
   - 해결방안: temperature와 prompt variation을 조정하고 unique reasoning path 비율과 final accuracy로 다양성을 검증함
3. 문제: 다수결로 가장 많이 나온 답이 항상 논리적으로 옳은 것은 아니어서 집단 오답에 수렴할 위험이 있음
   - 해결방안: verifier나 symbolic checker를 병행하고 majority answer correctness와 verifier agreement로 품질을 검증함

## Ⅶ. 적용 사례

- 수학 문제 풀이: 여러 계산 경로 중 일관된 답을 채택함, 확인 지표는 final answer accuracy와 pass@k임
- 규칙 기반 분류: 조건 적용 경로를 복수 생성해 오분류를 줄임, 확인 지표는 classification accuracy와 variance임
- 코딩 보조: 여러 해결안을 생성한 뒤 테스트를 통과한 답을 선택함, 확인 지표는 unit test pass rate와 latency임

## Ⅷ. 결론

Self-Consistency의 본질은 여러 번 생성하는 데 있지 않고 서로 다른 추론 경로를 확보한 뒤 합의와 검증을 결합해 단일 추론의 우연한 오류를 줄이는 데 있음.
