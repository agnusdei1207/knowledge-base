# 📖 【암기용】 개념 완전 이해

> 목적: Self-Consistency를 처음 봐도 완벽히 이해하게 만든다.

## 한눈에
- **개요**: LLM에서 동일 문제에 대해 다수의 CoT 경로를 샘플링한 뒤, 최종 답의 다수결(majority vote)로 정답을 선택하는 디코딩 전략
- **왜 필요한가**: 단일 CoT는 샘플링 노이즈로 경로마다 다른 답이 나올 수 있어, 1회 시도 정답률에 한계
- **핵심 직관**: "여러 번 풀어 보고, 가장 많이 나온 답이 맞을 확률이 높다"

## 깊이 이해
- **배경·문제의식**: CoT 프롬프팅은 greedy decoding(temperature=0) 시 하나의 경로에 의존 -> 그 경로가 오류면 무조건 틀림. 같은 문제를 temperature>0으로 여러 번 풀면 다양한 경로가 나오는데, 정답 경로가 다수를 점한다는 직관
- **작동 원리**: ① temperature=0.7 등으로 CoT 경로 n개(보통 5~40) 독립 샘플링 -> ② 각 경로에서 최종 답만 추출 -> ③ 최종 답의 빈도 집계(majority vote) -> ④ 최다 빈도 답을 정답으로 반환. 경로 자체는 버림
- **비유**: 시험에서 같은 문제를 40명이 독립적으로 풀고, 가장 많이 나온 답을 제출하는 것
- **구체 예시**: GSM8K(수학) 벤치마크에서 CoT greedy 정답률 56.5% -> Self-Consistency(40 경로) 74.4%(Wang et al., 2023). ARC-challenge에서도 +12%p 향상
- **흔한 오해·주의점**: Self-Consistency는 경로의 "질"을 평가하지 않고 최종 답만 비교 — 다수가 같은 오류를 범하면 틀린 답이 선택됨. 또한 n개 샘플링으로 비용이 n배 증가

## 연결 개념
- Chain-of-Thought(CoT): Self-Consistency의 기본 단위, 단일 경로 추론
- Tree-of-Thought(ToT): 중간 단계를 평가하여 가지치기, Self-Consistency와 상호보완
- Universal Self-Consistency(USC): 자유형 답변에도 LLM이 일관성 판단하도록 확장


# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 다수 CoT 경로를 샘플링하고 최종 답의 다수결로 정답을 선택하는 디코딩 전략
> 2. **가치**: GSM8K 정답률 56.5%->74.4%(+18%p), 추가 학습 없이 프롬프팅만으로 달성
> 3. **판단 포인트**: 정답이 이산적(숫자·선택지)인 문제에 효과적, 자유형 서술 문제에는 한계


## Ⅰ. 개요 및 필요성

- 개요: 다수 CoT 경로 투표 전략
- 배경: 단일 CoT greedy decoding은 하나의 경로에 의존해 샘플링 노이즈와 초기 추론 오류에 취약함.
- 필요성: temperature sampling, N-path voting, answer normalization으로 정답률 개선과 토큰 비용 증가를 함께 판단해야 함.


## Ⅱ. 구조 및 구성요소

```text
               -[CoT 경로1]--> 답: 42
[Prompt+문제]- -[CoT 경로2]--> 답: 42
               -[CoT 경로3]--> 답: 38
               -[CoT 경로n]--> 답: 42
                               감소
                     [Majority Vote] -> 42 ✓
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Sampler | temperature>0으로 n개 CoT 경로 독립 생성 | n=5~40, temperature=0.5~0.7 |
| Answer Extractor | 각 경로에서 최종 답만 파싱 | 정규식 또는 LLM 파싱 |
| Majority Voter | 최종 답 빈도 집계·최다 답 반환 | 동률 시 첫 등장 답 선택 |

> 요약: Sampler가 다수 경로를 생성하고, Extractor가 답을 추출하며, Voter가 다수결로 최종 답 결정


## Ⅲ. 동작원리 및 흐름도

```text
문제 입력 -> temperature>0 샘플링 × n회
-> 각 경로에서 최종 답 추출 -> 빈도 집계
-> 최다 빈도 답 반환
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 동일 프롬프트로 CoT 경로 n개 독립 샘플링 | n≥5, temperature 0.5~0.7 |
| 2 | 각 경로에서 최종 답만 추출(중간 과정 무시) | 파싱 성공률 ≥95% |
| 3 | 최종 답의 빈도 집계(majority vote) | 최다 답 비율 ≥50% 권장 |
| 4 | 최다 빈도 답을 정답으로 반환 | 동률 시 fallback 규칙 적용 |

> 요약: 다수 경로 독립 샘플링->답 추출->빈도 집계->최다 답 반환의 4단계 다수결


## Ⅳ. 특징

| 구분 | 내용 | 판단 포인트 |
|:---|:---|:---|
| Greedy CoT 대비 | 다수 경로 샘플링으로 노이즈 완화 | GSM8K +18%p, ARC +12%p |
| ToT 대비 | 중간 단계 평가 없이 답만 비교 | 구현 단순, 비용 예측 용이(n×1) |
| 한계 | 자유형 답변은 다수결 불가 | 서술형->USC 확장 필요 |

> 요약: 이산 답변 문제에서 greedy 대비 +18%p, 자유형 문제에는 USC 확장 필요


## Ⅴ. 실무 적용 및 결론

**적용 방안 3개:**
1. 수학·코드 문제 자동 채점 시 Self-Consistency(n=10) 적용, 오답률 15%->5%로 감소
2. 고객 문의 자동 분류에 경로 5개 샘플링 다수결, 분류 정확도 87%->94%
3. RAG 파이프라인에서 답변 검증용으로 3~5경로 Self-Consistency 적용, 환각률 12%->4%

**결론 (2줄):**
- 기술사 판단: 이산 답변(숫자·분류)이면 Self-Consistency, 자유형이면 USC 또는 ToT 병행
- 향후 방향: 적응형 샘플 수(Adaptive Consistency) — 정답 확신도에 따라 n을 동적 조절
