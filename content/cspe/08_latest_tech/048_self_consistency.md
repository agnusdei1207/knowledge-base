## 미리 알고가기

- 자기 일관성 ($Self-Consistency$): 여러 개의 독립적인 추론 경로를 병렬 생성한 뒤 다수결로 최종 정답을 결정하는 추론 앙상블 기법임
- 템퍼러처 ($Temperature$): 토큰 생성 시 다음 토큰의 확률 분포를 조정하여 텍스트의 다양성과 무작위성을 제어하는 계수임
- 다수결 투표 ($Majority$ $Voting$): 독립적으로 샘플링된 최종 응답값들 중 출현 빈도가 가장 높은 대표값을 최종 결과로 채택하는 집계 방식임
- 디코딩 ($Decoding$): 언어 모델이 학습한 확률 분포에 따라 다음 단어를 차례대로 선택해 나가는 생성 처리임

## Ⅰ. 개요

- **정의/개념**: Self-Consistency는 하나의 복합 문제에 대해 확률적 샘플링(Temperature > 0)을 활성화하여 서로 다른 여러 추론 경로($CoT$)를 병렬로 도출한 뒤, 가장 빈번하게 수렴하는 최빈 정답을 다수결로 수확하여 신뢰도를 높이는 추론 앙상블 기법임
- **배경/필요성**: 기존의 단일 경로 추론($CoT$)은 초기 추론 단계의 사소한 연산 오차가 후속 단계로 전이되며 오답을 내는 리스크가 크므로, 다양한 계산 경로를 거쳐도 '동일 정답에 반복 도출되는 일관성'을 검증해 정답률을 올리고자 고안됨

## Ⅱ. 특징

- 기학습된 언어 모델의 파라미터나 가중치에 손을 대지 않고, 단순히 추론 단의 병렬 호출과 집계 규칙만을 수정해 정확도를 드라마틱하게 상승시킴
- 템퍼러처를 0보다 크게 설정하여 각 경로가 서로 다른 각도(예: 역순 계산, 보조 변수 치환 등)에서 문제를 풀도록 생각의 우연성과 참신성을 유도함
- 샘플링 횟수($K$)가 늘어남에 따라 정답을 찾아낼 확률인 $pass@k$ 스코어가 우상향하지만, 총 생성 토큰량과 추론 비용이 정확히 배수 비례하여 증가하는 트레이드오프가 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | 탐욕적 디코딩 (Greedy Decoding) | 단일 단계 추론 (Single CoT) | 자기 일관성 추론 (Self-Consistency) |
|:---|:---|:---|:---|
| **생각의 경로 수** | 1개 (확률 1위 단어 고정) | 1개 (확률 1위 단어 위주 CoT) | 다수 ($K$개 병렬 샘플링) |
| **추론 다양성** | 전혀 없음 (매번 동일 대답) | 낮음 | 매우 높음 (다양한 풀이 과정 유도) |
| **최종 합의 검증** | 불가능함 | 불가능함 | 가능함 (다수결 투표 및 가중치 합산) |
| **연산 및 서빙 비용** | 매우 저렴함 | 보통 | 비쌈 (호출 횟수에 비례해 과금 선형 증가) |

> 요약: 탐욕 디코딩은 가성비에, 단일 CoT는 기본 추론에, 자기 일관성은 연산 단가를 지출하더라도 극한의 안전성이 필요한 정답 검증에 적합함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 다양성 샘플러 | 생성 다양성($Temp > 0.5$ 등)을 주입해 고유한 추론 경로 조각들을 조립해내는 제어부임 |
| 경로 저장 매니저 | 병렬 생성된 $K$개의 중간 논리 텍스트와 최종 정답 후보들을 임시 적재하는 수집 테이블임 |
| 다수결 투표기 | 추출된 최종 답변 데이터 중 동치관계인 것들을 그루핑하여 최다 득표 값을 선별하는 집계기임 |
| 신뢰도 가이드 필터 | 투표 합의율(예: 8/10 득표)이 기준 미달일 때 오답 위험으로 분류해 추가 검증을 요청하는 안전망임 |

```text
[ Self-Consistency 작동 원리 ]
Question -> [Diverse Sampler] -> Path 1 (Result: 45) --\
                             -> Path 2 (Result: 45) ----> [Majority Voting] -> Final Answer: 45
                             -> Path 3 (Result: 60) --/
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 프롬프트 및 | --> | 다중 경로    | --> | 최종 정답   | --> | 최빈값 수렴 |
| 템퍼러처설정|     | 텍스트 생성  |     | 동치 그루핑 |     | 및 최종확정 |
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **난이도 판정** — 들어온 문제가 수학, 추론 등 다단계 연산인지 판단하여 템퍼러처를 유효값(예: $0.7$)으로 높이고 호출 횟수($K=10$)를 할당함
2. **병렬 토큰 생성** — 모델에 질문과 CoT 프롬프트를 주입하여, $K$개의 독립적인 생각 전개 시퀀스를 비동기 병렬로 동시 생성함
3. **정답 추출 및 그룹** — 각 경로가 기술해낸 생성 텍스트의 끝 단락에서 정답 문자열을 정규식 등으로 파싱해 내어 동일 값 단위로 묶음
4. **집계 및 의사결정** — 가장 득표수가 높은 그룹의 값을 최종 해로 삼되, 신뢰도 임계치에 미치지 못하면 사용자 경고나 재계산을 유도함

## Ⅵ. 실무 적용 및 유의점

1. 모든 API 요청에 10회 이상의 샘플링을 돌리면 추론 요금이 10배 폭증하므로, 1차 질의 시 가벼운 검증 모델이 연산의 이상을 감지했을 때만 자기 일관성 앙상블로 토스하는 '조건부 라우팅'을 도입하고, 정답 정밀도 개선 폭 대비 요금 가성비 지표로 경제성을 튜닝해야 함
2. 단순히 많이 나온 대답이 항상 정답은 아니며, 모든 경로가 동일한 계산 함정에 빠져 '집단 오답'에 수렴할 위험이 있으므로, 코드 실행을 통한 구문 컴파일 테스트나 수학적 조건 검증기($Symbolic$ $Verifier$)를 후단에 결합하여 투표 결과의 무결성을 최종 보증해야 함

## Ⅶ. 결론

- Self-Consistency는 개별 계산의 불완전성을 대안 경로의 통제된 일관성으로 극복하는 지능적 다수결 알고리즘이며, 설계자는 무작정 샘플 횟수($K$)를 높이지 않고 조건부 라우팅과 후단 물리 검증기 결합을 통해 경제적이고 견고한 추론 파이프라인을 완성해야 함
