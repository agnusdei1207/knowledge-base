## 미리 알고가기

- 시각언어모델은 이미지와 텍스트를 함께 이해하고 텍스트로 응답하는 대표 멀티모달 모델임
- Vision Encoder와 LLM을 projector나 adapter로 연결하는 구조가 일반적임
- OCR 대체가 아니라 시각 맥락 이해와 언어 추론 결합이 본질임

## Ⅰ. 개요

- **정의/개념**: 시각언어모델은 이미지와 텍스트를 동시에 입력받아 시각적 특징과 언어적 맥락을 결합하고, 그 결과를 바탕으로 질의응답과 설명 생성과 문서 이해를 수행하는 멀티모달 모델임
- **배경/필요성**: 기존 비전 모델은 분류와 탐지에는 강하지만 자연어 상호작용이 약했고, 기존 LLM은 이미지 자체를 읽지 못했으므로 두 능력을 결합한 구조가 필요했음

## Ⅱ. 특징

- 이미지 내용에 대한 자연어 질의응답과 캡셔닝과 문서 이해를 수행할 수 있음
- Vision Encoder와 LLM 결합 구조 덕분에 기존 언어 모델 생태계와 연결이 쉬움
- 작은 글씨와 복잡한 표와 세밀한 시각 차이에서는 성능이 떨어질 수 있음
- 시각 환각과 해상도 제한 때문에 고정밀 업무에는 검증 계층이 필요함

## Ⅲ. 종류 및 비교

| 판단 기준 | 순수 비전 모델 | 시각언어모델 | 멀티모달 범용모델 |
|:---|:---|:---|:---|
| 입력 | 이미지 중심 | 이미지+텍스트 | 이미지+텍스트+음성 등 |
| 출력 | 라벨, 박스 | 자연어 응답 | 다중 모달 출력 |
| 언어 추론 | 낮음 | 높음 | 높음 |
| 대표 활용 | 탐지, 분류 | VQA, 문서AI | 범용 에이전트 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Vision Encoder | 이미지를 패치 토큰이나 시각 벡터로 변환해 시각 정보를 추출함 |
| Projector, Adapter | 시각 벡터를 LLM이 이해하는 표현 공간으로 정렬해 모달 간 연결을 담당함 |
| Language Model Core | 변환된 시각 토큰과 텍스트 프롬프트를 함께 읽고 응답을 생성함 |
| Task Head, Guardrail | 캡셔닝과 VQA와 문서 해석 결과를 생성하고 시각 환각을 억제함 |

```text
+-------------------+      +-------------------+      +-------------------+
| Vision Encoder    | ---> | Projector / Adpt. | ---> | LLM Core          |
+-------------------+      +-------------------+      +-------------------+
                                                           |
                                                           v
                                                   +-------------------+
                                                   | Task / Guardrail  |
                                                   +-------------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 이미지 입력     | --> | 시각 토큰 변환  | --> | 언어 모델 결합 | --> | 텍스트 응답 생성 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **이미지 입력**: 사진이나 문서 스캔과 같은 시각 데이터를 받음
2. **시각 토큰 변환**: Vision Encoder가 이미지 패치와 의미 특징을 추출함
3. **언어 모델 결합**: projector를 거친 시각 토큰과 텍스트 질의를 함께 입력함
4. **텍스트 응답 생성**: 답변과 캡션과 설명 같은 언어 결과를 생성함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 고해상도 문서나 작은 글씨는 패치 해상도 한계 때문에 세부 정보가 손실되어 잘못 읽힐 수 있음
   - 해결방안: OCR과 high-resolution tiling을 결합하고 OCR exact match와 VQA accuracy로 검증함
2. 문제: 이미지에 없는 객체나 관계를 언어 모델이 추정해 시각 환각을 만들 수 있음
   - 해결방안: detector와 grounded caption 검증을 적용하고 visual hallucination rate와 groundedness로 검증함
3. 문제: 이미지와 텍스트를 함께 처리하므로 단일 언어 모델보다 비용과 지연이 커질 수 있음
   - 해결방안: 핵심 패치 선택과 경량 encoder를 적용하고 latency와 cost per inference로 검증함

## Ⅶ. 적용 사례

- 영수증 QA가 총액과 부가세를 사진에서 읽어 답하도록 시각언어모델을 적용하며 확인 지표는 OCR exact match와 answer correctness임
- 제조 검사 보조가 불량 사진을 설명하고 조치 문서를 연결하도록 시각언어모델을 활용하며 확인 지표는 defect explanation quality와 resolution time임
- 문서 AI가 표와 이미지가 섞인 보고서를 해석하도록 시각언어모델을 적용하며 확인 지표는 document QA accuracy와 groundedness임

## Ⅷ. 결론

시각언어모델은 비전과 언어의 경계를 연결해 이미지 기반 질의응답을 가능하게 하는 핵심 기술이므로, 해상도 한계와 시각 환각을 고려한 검증형 파이프라인이 실무 성능을 좌우함.
