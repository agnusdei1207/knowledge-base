# 📖 【암기용】 개념 완전 이해

> 목적: Vision-Language Model을 처음 봐도 완벽히 이해하게 만든다.

## 한눈에
- **개요**: 이미지와 텍스트를 함께 이해하고 질의응답·캡션·추론을 수행하는 멀티모달 모델
- **왜 필요한가**: 문서 이미지, 도면, 차트, 사진 속 정보를 텍스트 질의와 연결해 이해해야 함.
- **핵심 직관**: 그림을 보고 질문을 읽은 뒤, 둘을 함께 해석해 답하는 모델임.

## 깊이 이해
- **배경·문제의식**: 텍스트 LLM은 이미지 내용을 직접 볼 수 없고, 이미지 모델은 언어적 질문과 추론을 처리하기 어렵다.
- **작동 원리**: Vision Encoder가 이미지를 패치 임베딩으로 바꾸고, Projection/Adapter가 LLM 토큰 공간에 맞춘 뒤, LLM이 이미지 토큰과 텍스트 토큰을 함께 처리함.
- **비유**: 사람이 사진을 보고 "왼쪽 표지판에 무엇이 쓰였나?"라는 질문을 읽어 답하는 과정과 같음.
- **구체 예시**: 설비 점검에서 사진과 작업 매뉴얼을 함께 입력해 "밸브 잠금 상태 이상"을 식별하고 관련 절차를 답변.
- **흔한 오해·주의점**: VLM은 이미지 속 텍스트 OCR과 공간 추론에서 오류가 날 수 있다. 고위험 업무는 OCR·검출 모델과 교차검증 필요.

## 연결 개념
- CLIP — 이미지와 텍스트 표현을 정렬하는 대조학습 모델
- Visual Question Answering — 이미지 기반 질의응답 태스크
- Multimodal RAG — 이미지와 문서 근거를 함께 검색하는 구조

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: VLM은 이미지 표현과 언어 모델을 연결해 시각-언어 공동 추론을 수행함.
> 2. **가치**: 도면·차트·사진·문서 이미지의 정보를 자연어 질의응답과 업무 자동화에 활용함.
> 3. **판단 포인트**: OCR, 공간 추론, hallucination, 개인정보 마스킹을 별도 검증해야 함.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 결합 구조 이해 확인 | Vision Encoder-Projector(MLP·Q-Former)-LLM 3계층 구성 | 시각 토큰을 LLM 공간에 맞추는 Projector 역할 누락 |
| 한계 인식 확인 | OCR 오독, 공간 관계 추론 오류, 시각 환각 | VLM 출력을 검증 불필요한 결과로 단정 |
| 적용·검증 설계 확인 | VQA accuracy, OCR exact match, hallucination rate 지표 | 정량 검증 지표 없는 적용 방안 서술 |

> 요약: 이 문제는 모델 종류 나열이 아니라 이미지-언어 결합 구조와 오류 유형별 검증 설계를 묻는다.

## Ⅰ. 개요 및 필요성

- 개요: 이미지와 텍스트 결합 모델
- 배경: 업무 데이터에는 도면, 표, 사진, 스캔 문서가 포함되어 텍스트 전용 LLM만으로 시각 정보를 해석하기 어렵다.
- 필요성: image encoder와 language decoder를 결합해 VQA accuracy, caption CIDEr, OCR 연계 정확도로 시각 질의응답을 검증한다.

## Ⅱ. 구조 및 구성요소

```text
Image -> Vision Encoder -> Visual Tokens -> Projector
Text Query -> Tokenizer -> LLM -> Answer
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Vision Encoder | 이미지를 패치·특징 벡터로 변환 | ViT, CNN, CLIP encoder |
| Projector/Adapter | 시각 토큰을 LLM 공간에 정렬 | MLP, Q-Former |
| Language Model | 텍스트·시각 토큰 공동 추론 | GPT-4o, LLaVA, Gemini |
| Task Head/Prompt | VQA·캡션·OCR·추론 수행 | instruction tuning |

> 요약: VLM은 이미지 인코더와 LLM을 어댑터로 연결해 시각 정보와 텍스트 질의를 함께 처리함.

## Ⅲ. 동작원리 및 흐름도

```text
이미지 입력 -> 패치 임베딩 -> 시각 토큰 정렬
  -> 텍스트 질의 결합 -> LLM 추론 -> 답변/출처 출력
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 이미지 전처리·패치 분할 | 해상도 224~1024px |
| 2 | Vision Encoder로 시각 토큰 생성 | 이미지 인코딩 <200ms |
| 3 | Projector로 LLM 토큰 공간 정렬 | VQA accuracy ≥80% |
| 4 | 텍스트 질의와 함께 답변 생성 | OCR exact match ≥90% |

> 요약: 이미지를 시각 토큰으로 변환하고 언어 토큰과 결합해 LLM이 공동 추론을 수행함.

## Ⅳ. 특징

| 구분 | 이미지 분류 모델 | VLM | 판단 포인트 |
|:---|:---|:---|:---|
| 입력 | 이미지 | 이미지+텍스트 | 질의응답 가능 |
| 출력 | 클래스 라벨 | 자연어 답변·캡션 | 업무 설명에 적합 |
| 강점 | 단일 태스크 정확도 | 범용 시각-언어 추론 | 다양한 업무 처리 |
| 한계 | 언어 추론 부족 | OCR·공간 추론 오류 | 교차검증 필요 |

> 요약: VLM은 이미지 이해를 자연어 추론과 연결하지만, OCR·공간 관계 오류는 별도 검증해야 함.

## Ⅴ. 심화 비교 및 적용 판단

| 구분 | 전용 OCR+LLM 파이프라인 | End-to-End VLM | 선택 기준 |
|:---|:---|:---|:---|
| 문자 인식 정확도 | 전용 OCR로 exact match 우수 | 저해상도·작은 글씨 오독 위험 | 문자 정확도 요구 수준 |
| 이해 범위 | 레이아웃·시각 맥락 정보 일부 손실 | 표·도장·이미지 맥락 통합 추론 | 시각 맥락 추론 필요 여부 |
| 운영 구조 | 단계별 모델 관리 부담, 오류 원인 추적 용이 | 단일 모델 운영, 오류 원인 분해 곤란 | 디버깅·책임 추적 체계 |

> 요약: 문자 정확도가 핵심인 정형 문서는 OCR+LLM, 시각 맥락 추론이 필요한 업무는 VLM에 OCR 교차검증을 결합함.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 시각 환각 | 이미지에 없는 객체를 언어 확률로 생성 | 객체 검출 교차검증, 환각 평가셋 운영 | hallucination rate |
| OCR 오독 | 저해상도 입력, 패치 분할 정보 손실 | 고해상도 타일링, 전용 OCR 교차검증 | OCR exact match ≥90% |
| 개인정보 노출 | 사진 내 얼굴·식별정보 포함 | 마스킹 전처리, 출력 필터 | 마스킹 처리율 |

> 요약: 시각 환각과 OCR 오독이 핵심 위험이며, 검출·OCR 교차검증과 마스킹으로 통제함.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 문서 이미지 처리: 스캔 PDF를 VLM+OCR로 분석하고 표·도장·서명 영역을 추출해 Document AI 파이프라인에 연결
2. 제조·설비 점검: 사진과 매뉴얼 RAG를 결합해 이상 부위와 조치 절차를 함께 답변
3. 품질 검증: OCR exact match, VQA accuracy, hallucination rate, 개인정보 마스킹률을 배포 지표로 설정

**결론 (2줄):**
- 기술사 판단: 이미지 근거가 포함된 업무는 VLM, 순수 텍스트 업무는 LLM/RAG 적용
- 향후 방향: VLM과 Multimodal RAG가 결합해 문서·도면·영상 기반 질의응답으로 확장
