# 📖 【암기용】 개념 완전 이해

## 한눈에
- **정의**: 이미지(눈)와 텍스트(입/귀)라는 서로 다른 두 가지 언어를 동시에 이해하고 연결하여, 사진을 보고 대답하거나(VQA) 설명을 달아주는(Captioning) 멀티모달 인공지능 모델.
- **필요성**: 기존의 컴퓨터 비전 모델(CNN, YOLO)은 사진을 보고 "이건 개 90%, 고양이 10%"라고 라벨만 찍어낼 뿐, 인간처럼 "강아지가 잔디밭에서 원반을 물고 신나게 뛰고 있네"라고 맥락을 묘사하고 소통하지 못했음. 언어 모델의 유창성과 비전의 눈을 결합해야 했음.
- **핵심 직관**: 외국어 동시통역사. '이미지'라는 시각적 외국어를 뇌(어댑터)를 통해 '자연어 텍스트'라는 모국어로 완벽하게 번역 및 결합하여 해석해 냄.

## 깊이 이해
- **배경**: 언어 분야에서는 트랜스포머(LLM)가 세상을 제패했고, 비전 분야에서도 트랜스포머(ViT)가 주도권을 잡음. "어? 둘 다 똑같은 트랜스포머 구조네? 그럼 둘을 파이프로 연결해서 하나의 뇌로 만들어보자!"라는 시도에서 탄생(대표작: LLaVA, Flamingo).
- **작동 원리 (LLaVA 아키텍처 기준)**:
  1. **눈 (Vision Encoder)**: 들어온 이미지를 바둑판 모양의 패치로 잘게 쪼개어 시각 토큰(벡터)으로 만듦 (주로 CLIP의 인코더 사용).
  2. **통역기 (Projection / Adapter)**: 시각 토큰은 언어 모델이 못 알아먹음. 그래서 이 시각 벡터를 언어 모델이 이해할 수 있는 차원 공간(차원수 4096 등)으로 변환해 주는 선형 변환기(MLP 등)를 거침.
  3. **뇌 (LLM)**: 번역된 시각 토큰 뒤에 사용자의 텍스트 질문 토큰("이 사진에 뭐가 있어?")을 이어 붙여서 LLM에 통째로 밀어 넣음. LLM은 이를 모두 읽고 텍스트로 답을 뱉음.
- **구체 예시**:
  - 사용자: (영수증 사진 업로드) "내가 총 얼마 썼지? 부가세는?"
  - VLM: 영수증 이미지를 픽셀 단위가 아닌 의미적 토큰으로 분해하여 읽은 뒤, 텍스트 추론 능력을 발휘해 영수증 내의 숫자들을 찾아내어 "총 55,000원이고 부가세는 5,000원입니다."라고 대답함.
- **흔한 오해/주의점**: VLM은 만능 눈이 아님. 아주 작은 글씨나 복잡한 표를 정밀하게 읽는 데는 전통적인 OCR 기술보다 정확도가 떨어질 수 있음. (시각적 환각 발생). 따라서 고정밀 스캔 업무엔 OCR과 하이브리드로 써야 함.

## 연결 개념
- **Multimodal AI**: VLM을 포함하는 더 넓은 개념. (VLM은 비전과 언어 두 개만 결합한 좁은 의미의 핵심 형태).
- **ViT (Vision Transformer)**: 이미지를 픽셀이 아닌 단어 토큰처럼 쪼개서 처리하는, VLM의 눈동자 역할을 하는 기술.
- **VQA (Visual Question Answering)**: VLM 모델이 수행하는 가장 대표적인 시험 과목(태스크). "이미지 보고 질문에 답하기".

# 📝 【답안용】 시험 답안 템플릿
## 핵심 인사이트 (3줄 요약)
- **본질**: 시각적 특징 추출기(Vision Encoder)와 대규모 언어 모델(LLM)을 교차-모달리티 프로젝터(Cross-modality Projector)로 결합하여, 이미지와 텍스트의 임베딩 공간(Embedding Space)을 정렬(Align)한 다중 양식 파운데이션 모델.
- **가치**: 컴퓨터 비전의 태스크(분류, 객체 탐지)를 자연어 인터페이스 프롬프팅만으로 Zero-shot 처리할 수 있는 패러다임 전환을 이끌며, 로보틱스 판단, 의료 영상 문서화, 문서 지능(Document AI) 고도화의 핵심 엔진으로 작용함.
- **판단 포인트**: 기업 도입 시 VLM 모델 자체의 해상도 한계(Resolution Bottleneck)로 인한 미세 텍스트(표, 약관) 인식 오류(시각 환각) 리스크를 고려하여, 전문 OCR 엔진(Tesseract 등)과의 상호 보완적 파이프라인(Ensemble) 설계가 필수적임.

## Ⅰ. 개요 및 필요성
- **정의**: 이미지(또는 비디오)와 텍스트를 동시에 입력받아 시각적 맥락(Visual Context)을 이해하고, 이를 바탕으로 인간 수준의 자연어 텍스트를 추론/생성해 내는 결합형 딥러닝 아키텍처.
- **배경**: 기존 NLP 모델은 시각 정보를 텍스트 캡션으로 변환한 뒤 처리해야 했으므로(Information Bottleneck), 공간적 구조, 색상, 미세한 맥락 정보가 소실되는 치명적 한계가 존재했음.
- **필요성**: 도면 해석, 상품 리뷰 사진 분석, 자율주행 상황 인지 등 시각적 직관과 언어적 논리가 동시에 요구되는 고차원 비즈니스 워크플로우를 End-to-End로 자동화하기 위함.

## Ⅱ. VLM의 핵심 아키텍처 컴포넌트 (3-Stage)
오픈소스 VLM의 표준으로 자리 잡은 LLaVA(Large Language-and-Vision Assistant) 아키텍처 기준.
| 구성 요소 | 역할 및 메커니즘 | 대표 모델 / 알고리즘 |
|:---:|:---|:---|
| **1. Vision Encoder** | - 입력된 고해상도 이미지를 2D 패치(Patch)로 분할.<br>- 각 패치를 시각적 특징 벡터(Visual Tokens)로 압축. | ViT (Vision Transformer), <br>CLIP Vision Encoder |
| **2. Projector (Adapter)**| - 서로 다른 차원을 가진 비전 벡터와 LLM 단어 벡터 공간을 정렬(Alignment).<br>- 선형 투영(Linear Projection) 또는 MLP 신경망 사용. | Q-Former, MLP 레이어 |
| **3. LLM Decoder** | - 변환된 시각 토큰 시퀀스와 텍스트 프롬프트 토큰을 연결(Concatenate)하여 자기회귀적(Auto-regressive)으로 답변 생성. | Llama 3, Vicuna 등 |

## Ⅲ. VLM의 핵심 응용 태스크 (Use Cases)
| 태스크 | 설명 | 기업 실무 활용 예시 |
|:---:|:---|:---|
| **VQA** (시각 질의응답) | 이미지 내용에 대한 질문에 단답 또는 논리적 추론 답변 | "이 공장 설비 사진에서 볼트가 체결되지 않은 곳은 어디인가?" |
| **Image Captioning** | 입력된 사진의 전체 맥락을 요약하여 자연어 문장으로 설명 | 이커머스 상품 사진 등록 시 시각장애인용 대체 텍스트(Alt Text) 자동 생성 |
| **Visual Grounding** | 텍스트로 설명한 객체가 이미지의 어느 부분(Bounding Box)인지 지목 | 자율주행 시스템에서 "빨간색 신호등" 위치 좌표 출력 |
| **Document AI** | 스캔된 문서, 영수증, 복잡한 표(Table)를 읽고 텍스트/JSON 추출 | 보험사 진단서 스캔본을 읽어 상병코드 및 환자 이름 자동 추출 |

## Ⅳ. VLM 도입 시 한계점 및 아키텍처 보완 전략
단순 VLM만으로는 엔터프라이즈의 정밀도 요구를 맞추기 힘듦.
1. **고해상도 손실 한계 (Resolution Limit)**:
   - ViT 인코더의 입력 패치 사이즈 한계(예: 336x336)로 인해 큰 도면이나 A4 용지 전체 텍스트가 뭉개짐.
   - **해결책**: 원본 이미지를 여러 개의 고해상도 타일(Tile)로 쪼개어 각각 인코딩한 후 합치는 **Dynamic High-Resolution 전략 (AnyRes 기법)** 적용.
2. **시각적 환각 (Visual Hallucination)**:
   - 이미지에 없는 객체를 LLM의 사전 학습 지식에 의존하여 "있다"고 거짓말하는 현상.
   - **해결책**: `Temperature=0` 설정, 그리고 객체 탐지 특화 모델(YOLO)로 1차 필터링 후 VLM과 크로스-체크(Cross-validation)하는 파이프라인 구성.

## Ⅴ. 실무 적용 및 결론
- **판단 지표**: VQAv2 Score, CIDEr (캡셔닝 품질), OCR Exact Match(정밀 텍스트 추출 정확도).
- **실무 설계**: 스마트 팩토리 불량 검출 시스템 고도화. 기존의 Vision 검사 장비(AOI)는 불량을 탐지(O/X)만 할 뿐 원인 설명이 불가했음. 이를 오픈소스 VLM(LLaVA)과 사내 지식 기반 RAG를 결합하여 설계. 불량 회로 기판 사진이 VLM에 입력되면, VLM이 불량의 형태를 자연어로 분석함("납땜 불량 및 그을림 발견"). 이 텍스트가 사내 RAG 시스템으로 넘어가 조치 매뉴얼을 찾아내어 관리자 패드에 "원인: 납땜 불량 / 조치: 3번 노즐 온도 하향 조정"이라는 리포트를 자동 생성함.
- **결론**: VLM은 단순한 '보는 기계'를 넘어 '보고 이해하고 설명하는 기계'로의 진화를 의미하며, 기존의 정형 데이터 베이스 중심의 기업 IT 자산을 물리적 세상의 비정형 데이터까지 확장시키는 핵심 브릿지(Bridge) 기술이다.

### 🔀 문제 유형별 목차 전환
- **Ⅱ·Ⅲ 강조 (개념/원리형)**: Contrastive Learning 기반의 모달리티 정렬 수학적 메커니즘, Q-Former를 활용한 시각 토큰 압축 및 병목 해소(Information Bottleneck) 구조 비교 서술.
- **Ⅴ·Ⅵ 강조 (실무/설계형)**: VLM의 OCR 한계를 극복하기 위한 Hybrid Document AI 아키텍처(Tesseract + VLM 프롬프팅 연계), 산업용 특화 미세조정(LoRA) 파이프라인 구축 방안.
