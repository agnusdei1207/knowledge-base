# 📖 【암기용】 개념 완전 이해

> 목적: Multimodal RAG를 처음 봐도 완벽히 이해하게 만든다.

## 한눈에
- **개요**: 텍스트뿐 아니라 이미지, 표, 도면, 음성 등 다양한 모달 근거를 검색해 생성 답변에 활용하는 RAG 구조
- **왜 필요한가**: 기업 문서는 PDF 본문, 표, 차트, 스캔 이미지, 도면이 섞여 있어 텍스트 RAG만으로 근거를 충분히 찾기 어려움.
- **핵심 직관**: 참고자료가 글뿐 아니라 그림·표·음성까지 포함된 오픈북 시험임.

## 깊이 이해
- **배경·문제의식**: 일반 RAG는 텍스트 청크 검색에 최적화되어 이미지 속 결함, 표의 수치, 도면의 연결 관계를 놓칠 수 있다.
- **작동 원리**: 모달별 파서와 인코더로 텍스트·이미지·표를 임베딩하고, 모달별 검색 결과를 결합한 뒤 VLM/LLM이 출처 기반 답변을 생성함.
- **비유**: 보고서를 작성할 때 문서 본문, 표, 사진, 도면을 모두 펼쳐놓고 필요한 근거를 종합하는 과정임.
- **구체 예시**: 설비 매뉴얼 PDF에서 텍스트 절차, 배관 도면, 점검 사진을 함께 검색해 "밸브 잠금 순서" 답변과 이미지 영역 출처를 제공.
- **흔한 오해·주의점**: 이미지도 단순 캡션만 만들면 세부 정보가 누락될 수 있음. OCR, layout parser, VLM 검증이 필요함.

## 연결 개념
- Multimodal AI — 여러 데이터 형식을 함께 처리하는 AI
- Vision-Language Model — 이미지 근거를 이해하는 모델
- Document AI — 문서 레이아웃·표·OCR 처리 계층

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: Multimodal RAG는 텍스트·이미지·표 등 복수 모달 근거를 검색·융합해 답변하는 RAG임.
> 2. **가치**: 문서 본문만으로 찾기 어려운 도면·차트·스캔 이미지 근거를 답변에 반영함.
> 3. **판단 포인트**: 모달별 파싱·임베딩·권한·citation을 일관되게 관리해야 운영 가능함.

## Ⅰ. 개요 및 필요성

Multimodal RAG는 복수 모달 근거를 활용하는 검색증강생성 구조임. 기업 지식은 텍스트뿐 아니라 표, 이미지, 도면, 음성에 분산되어 있다. 모달별 근거를 검색·융합해 답변 품질과 근거 범위를 확장한다.

## Ⅱ. 구조 및 구성요소

```text
Docs/Image/Table/Audio → Modal Parsers → Modal Indexes
  → Fusion Retriever → VLM/LLM Generator → Multimodal Citation
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Modal Parser | OCR·표·이미지·음성 전처리 | layout, caption, STT |
| Modal Index | 모달별 임베딩·색인 | text, image, table vectors |
| Fusion Retriever | 검색 결과 결합·리랭킹 | RRF, cross-modal rerank |
| VLM/LLM Generator | 근거 통합 답변 생성 | 문장·이미지 영역 citation |

> 요약: Multimodal RAG는 모달별 파싱·색인·검색 결과를 결합해 VLM/LLM이 근거 기반 답변을 생성함.

## Ⅲ. 동작원리 및 흐름도

```text
멀티모달 문서 수집 → 모달별 추출/임베딩
  → 질의 분석 → 텍스트/이미지/표 검색 → 근거 융합 → 답변 생성
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 문서에서 텍스트·표·이미지·음성 추출 | 추출 실패율 <2% |
| 2 | 모달별 임베딩과 메타데이터 색인 | source 매핑 100% |
| 3 | 질의에 맞는 모달별 Top-K 검색·융합 | multimodal Recall@10 ≥80% |
| 4 | VLM/LLM 답변과 citation 생성 | Faithfulness ≥0.9 |

> 요약: 모달별 지식을 별도 추출·검색한 뒤 질의 목적에 맞게 융합해 출처 기반 답변을 생성함.

## Ⅳ. 특징

| 구분 | Text RAG | Multimodal RAG | 판단 포인트 |
|:---|:---|:---|:---|
| 근거 범위 | 텍스트 청크 | 텍스트·표·이미지·음성 | 복합 문서에 적합 |
| 검색 인프라 | 단일 벡터/검색 | 모달별 인덱스 | 운영 복잡도 증가 |
| 답변 검증 | 문서 citation | 문장+영역 citation | 출처 UI 필요 |
| 리스크 | 텍스트 누락 | OCR·캡션·모달 정렬 오류 | 모달별 평가 필요 |

> 요약: Multimodal RAG는 근거 범위를 넓히지만 모달별 파싱 품질과 citation 검증이 운영 핵심임.

## Ⅴ. 실무 적용 및 결론

**적용 방안 3개:**
1. 매뉴얼 QA: PDF 본문, 표, 도면 이미지를 각각 색인하고 답변에 페이지·영역 좌표 citation 제공
2. 품질 평가: 텍스트 Faithfulness, OCR exact match, image grounding IoU를 모달별로 측정
3. 권한 통제: 텍스트 청크와 이미지 영역에 동일 ACL·source_id를 부여해 미권한 근거 유입 0건 검증

**결론 (2줄):**
- 기술사 판단: 도면·표·이미지가 핵심 근거인 업무는 Multimodal RAG, 순수 문서 QA는 Text RAG 적용
- 향후 방향: Document AI, VLM, Graph RAG가 결합된 복합 지식 검색으로 발전
