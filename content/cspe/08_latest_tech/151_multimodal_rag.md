## 미리 알고가기

- 멀티모달 RAG는 텍스트뿐 아니라 이미지와 표와 도면까지 검색 근거로 활용하는 RAG 구조임
- 문서 파싱 품질과 모달별 검색 전략이 답변 품질을 직접 좌우함
- VLM과 citation 체계가 결합되어야 근거성 있는 답변이 가능함

## Ⅰ. 개요

- **정의/개념**: 멀티모달 RAG는 텍스트와 이미지와 표와 차트 등 이질적 문서를 함께 인덱싱하고, 질의에 필요한 멀티모달 근거를 검색해 VLM이나 LLM이 결합 추론하도록 만드는 검색 증강 생성 아키텍처임
- **배경/필요성**: 기업 문서의 핵심 지식은 줄글만이 아니라 도표와 설계도와 스캔 문서에 분산되어 있으므로, 텍스트 RAG만으로는 재현율과 답변 완전성을 확보하기 어려움

## Ⅱ. 특징

- 텍스트와 시각 근거를 함께 활용해 답변 완전성과 설명력을 높임
- 문서 파싱과 임베딩과 검색 전략이 모달별로 달라 설계 복잡도가 큼
- 이미지 캡션화와 원본 이미지 전달 중 어떤 방식을 택하는지에 따라 비용과 품질이 달라짐
- 근거 문서와 시각 영역을 함께 제시할 수 있어 grounded answering에 유리함

## Ⅲ. 종류 및 비교

| 판단 기준 | Image-to-Text RAG | Joint Embedding RAG | Multi-vector Multimodal RAG |
|:---|:---|:---|:---|
| 검색 단위 | 텍스트 변환 결과 | 텍스트와 이미지 임베딩 동시 | 요약본 검색 후 원본 호출 |
| 구현 난도 | 낮음 | 중간 | 높음 |
| 세부 시각 정보 보존 | 낮음 | 중간 | 높음 |
| 실무 균형 | 중간 | 중간 | 높음 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Document Parser | PDF와 이미지와 표를 분리하고 각 모달에 맞는 청킹과 메타데이터를 부여해 인덱싱 품질의 출발점을 만듦 |
| Modal Retriever | 텍스트와 이미지와 표 요약본을 각기 다른 임베딩과 검색 전략으로 조회해 관련 근거를 수집함 |
| Reasoning Model | 검색된 텍스트와 시각 컨텍스트를 함께 읽어 답변과 인용을 생성하는 VLM 또는 LLM 계층임 |
| Grounding, Citation Layer | 어떤 문단과 어떤 이미지 영역을 근거로 썼는지 제시해 신뢰성과 감사 가능성을 높임 |

```text
+-------------------+      +-------------------+      +-------------------+
| Document Parser   | ---> | Modal Retriever   | ---> | Reasoning Model   |
+-------------------+      +-------------------+      +-------------------+
                                                           |
                                                           v
                                                   +-------------------+
                                                   | Ground / Citation |
                                                   +-------------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 문서 분해/적재   | --> | 멀티모달 검색  | --> | 컨텍스트 결합 추론 | --> | 답변/근거 반환  |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **문서 분해 및 적재**: 텍스트와 표와 이미지를 분리해 인덱싱함
2. **멀티모달 검색**: 질의와 연관된 모달별 근거를 함께 찾음
3. **컨텍스트 결합 추론**: VLM이나 LLM이 검색 결과를 통합적으로 해석함
4. **답변 및 근거 반환**: 답변과 함께 인용과 시각 근거를 제시함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 모든 이미지를 고비용 VLM으로 처리하면 검색 정확도보다 파싱과 서빙 비용이 먼저 병목이 될 수 있음
   - 해결방안: 모달 라우팅과 multi-vector retrieval을 적용하고 cost per query와 recall@k로 검증함
2. 문제: 텍스트 근거와 시각 근거가 서로 다른 문맥을 가리키면 답변은 풍부해도 사실 정합성이 무너질 수 있음
   - 해결방안: claim-to-evidence alignment 검증을 적용하고 groundedness와 citation accuracy로 검증함
3. 문제: 민감 문서나 권한 제한 이미지가 검색 단계에서 걸러지지 않으면 시각 근거 자체가 유출될 수 있음
   - 해결방안: permission-aware retrieval과 audit log를 적용하고 unauthorized retrieval rate와 audit pass rate로 검증함

## Ⅶ. 적용 사례

- 반도체 매뉴얼 검색이 도면과 절차 문장을 함께 찾아 답하도록 멀티모달 RAG를 적용하며 확인 지표는 answer completeness와 first fix time임
- 재무 분석 지원이 차트와 표와 해설 문단을 함께 근거로 사용하도록 멀티모달 RAG를 운영하며 확인 지표는 citation accuracy와 analyst review score임
- 의료 문서 QA가 스캔 소견서와 표와 텍스트를 통합 검색하도록 멀티모달 RAG를 활용하며 확인 지표는 groundedness와 expert agreement임

## Ⅷ. 결론

멀티모달 RAG는 텍스트 RAG의 재현율 한계를 넘는 구조이므로, 문서 파싱 정밀도와 모달 정렬과 권한 통제를 함께 설계해야 실제 가치가 커짐.
