## 미리 알고가기

- 지식 증류 ($Knowledge$ $Distillation$): 훈련 과정에서 부피가 크고 똑똑한 교사 모델(Teacher)의 복잡한 추론 확률 분포를 상대적으로 작고 콤팩트한 학생 모델(Student)에 지식 전이시켜 학생의 연산 체력을 키워주는 경량화 기술임
- 소프트 타깃 ($Soft$ $Targets$): 단순히 '참(1)' 또는 '거짓(0)'으로 나뉘는 이산적인 결과($Hard$ $Label$) 대신, 모델 출력에 템퍼러처를 가미해 도출된 연속적인 실수 확률 분포($[0.1, 0.7, 0.2]$ 등)를 의미함
- 쿨백-라이블러 발산 ($KL-Divergence$): 두 확률 분포의 불일치 혹은 차이 정도를 수학적으로 측정하여 수치화하는 손실 함수 공식임
- 암묵적 지식 ($Dark$ $Knowledge$): 교사 모델이 학습을 통해 무의식적으로 내재화한 각 클래스(토큰) 간의 의미론적 유사도와 연관성 정보(예: 개는 고양이와 비슷하지만 비행기와는 아주 멀다는 지식)임

## Ⅰ. 개요

- **정의/개념**: Knowledge Distillation은 초거대 모델의 압도적인 추론 능력과 암묵적 지식(Dark Knowledge)을 더 작은 매개변수 구조를 지닌 경량 모델(SLM)에 이식하기 위해, 교사 모델이 내놓은 소프트 타깃(Soft Targets) 확률 분포와 학생 모델의 예측 값 간의 쿨백-라이블러 발산($KL-Divergence$) 손실을 줄여나가며 공동 최적화하는 학습 기법임
- **배경/필요성**: 소형 모델을 일반 말뭉치로 밑바닥부터 훈련시키면 지능의 상한선이 낮아 실무에 투입하기 어려웠던 반면, 거대 모델의 요약본(증류)을 먹임으로써 온디바이스 에지 폰에서도 동작하는 고성능 비서를 저비용으로 획득하고자 도입됨

## Ⅱ. 특징

- 단순히 정답 레이블($0$ 또는 $1$)만 달랑 외우는 주입식 교육을 탈피하고, 교사 모델이 판단한 중간 확률 전반의 '유사 관계도'를 흡수하여 학생 모델의 일반화($Generalization$) 성숙도를 높임
- 학생 모델의 신경망 구조(어텐션 레이어 수 등)를 독립적으로 축소할 수 있어, 가지치기나 양자화 대비 근본적으로 구조가 콤팩트한 SLM을 탄생시킴
- 최종 추론 시에는 교사 모델을 전면 배제하고 경량화된 학생 모델 단독으로 구동하므로, 실무적인 연산 서버 유지 가동비($TCO$)가 대폭 경감됨

## Ⅲ. 종류 및 비교

| 판단 기준 | 일반 전이 학습 (Fine-tuning) | 지식 증류 (Knowledge Distillation) | 모델 양자화 (Quantization) |
|:---|:---|:---|:---|
| **지능 습득 원천** | 사람이 레이블링한 특정 분야 정답지 | 교사의 소프트 타깃($Soft$ $Targets$) 분포 | 오리지널 가중치의 저해상도 사상 |
| **모델 구조 변화** | 기존 구조 완전 동일 유지 | 학생 모델 구조로 전면 축소 설계 가능 | 기존 구조와 동일하나 데이터 형식이 정수화됨 |
| **암묵적 지식 전이** | 불가능함 | 가능함 ($KL-Divergence$ 활용) | 불가 (기존 지식 범위 내 압축만 실행) |
| **대표적인 용도** | 특정 법률/의료 등 도메인 최적화 | 가볍고 빠른 독자적 SLM($8B$ 이하) 신규 제조 | 완제품 서버 서빙 가성비 단기 개조 |

> 요약: Fine-tuning은 전담 조력자 변신이고, Knowledge Distillation은 대를 잇는 지능 상속이며, Quantization은 가벼운 갑옷으로의 환복임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 교사 모델 | 지식의 원천인 초대형 매개변수 기반의 고성능 트랜스포머 모델임 |
| 학생 모델 | 목표하는 온디바이스 배포 환경 스펙에 밀착하여 설계된 경량 모델임 |
| 소프트맥스 템퍼러처 | 로짓 분포를 완만하게 다듬어 교사의 속마음(Dark Knowledge)을 부각하는 온도($T$) 계수임 |
| 복합 손실 함수 | 학생의 정답 대조 손실($Hard$ $Loss$)과 교사 복제 손실($Soft$ $Loss$)을 결합한 통합 계산식임 |

```text
[ Knowledge Distillation (지식 증류) 학습 토폴로지 ]
                    Input Data
                   /          \
      [ Teacher Model ]      [ Student Model ]
             │ (Softmax w/ T)        │ (Softmax w/ T)
             v                       v
      Teacher Soft Targets <---> Student Soft Prediction 
                     (KL-Divergence Loss)
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 교사용 로짓 | --> | 템퍼러처($T$)  | --> | 학생 예측   | --> | 복합 손실로 |
| 분포 획득   |     | 곱해 부드럽게|     | 분포 대조   |     | 학생 가중치 FT|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **소프트 타깃 도출** — 입력 데이터를 교사 모델에 주입하고, 소프트맥스 활성화 함수 전단에 온도 상수를 나누어 완만한 확률 분포를 출력함
2. **학생 추론 구동** — 동일한 데이터를 동종 학생 모델에 밀어 넣고, 동일 템퍼러처($T$) 하에 예측 로짓 분포를 뽑아냄
3. **분포 오차 계산** — 두 소프트 분포 간의 기하학적 형상 차이를 $KL-Divergence$ 수학 공식으로 측정하여 $Soft$ $Loss$를 획득함
4. **학생 가중치 갱신** — $Soft$ $Loss$와 학생 고유의 정답 손실($Hard$ $Loss$)을 특정 가중 가중치($\alpha$)로 가산 결합하여 학생 가중치를 최종 업데이트함

## Ⅵ. 실무 적용 및 유의점

1. 교사 모델 내부에 누적되어 있던 특정 도메인 편향이나 윤리적 오독 결함까지 학생 모델이 스폰지처럼 그대로 모방해 지능에 고착화될 위험이 크므로, 반드시 증류 완료 후 '독립적인 가드레일 평가셋'을 구동하여 학생 모델의 인종/성별 등 편향 지표($Bias$ $Score$)를 감사해야 함
2. 교사용 소프트 타깃 데이터를 대량으로 서버에서 추론해 수집하는 가공 비용이 막대하므로, 무차별 수집을 배제하고 사내 고가치 지식 영역 위주로 데이터를 선별(Active Learning) 셋업하여 증류 예산 대비 성능 효율($ROI$)을 방어해야 함

## Ⅶ. 결론

- 지식 증류는 초거대 인공지능의 깊은 통찰력을 경량 하드웨어 세대로 대물림하여 이식성을 완성하는 현대 모델 훈련 아키텍처의 필수 브리지이며, 설계자는 전이 과정에서 발생할 수 있는 독성/편향 오염 대물림 방지책과 소프트 타깃 데이터 수집 가공 단가를 통제하는 스마트 증류 체계를 제공해야 함
