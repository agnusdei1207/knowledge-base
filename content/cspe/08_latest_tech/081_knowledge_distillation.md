## 미리 알고가기

- 지식 증류는 큰 교사 모델의 출력 분포나 중간 표현을 작은 학생 모델에 전달하는 학습 방식임
- 단순 정답 학습보다 soft target을 함께 사용해 학생 모델의 일반화 성능을 높이는 것이 핵심임
- SLM, 모바일 모델, 특화 모델 구축에 자주 쓰이며 양자화와도 함께 활용됨

## Ⅰ. 개요

- **정의/개념**: 지식 증류는 성능이 높은 교사 모델의 출력 분포와 표현 특성을 작은 학생 모델이 모방하도록 학습시켜 경량 모델의 품질을 끌어올리는 전달 학습 기법임
- **배경/필요성**: 작은 모델은 자원이 적어 배포는 쉽지만 성능이 부족할 수 있으므로, 큰 모델이 학습한 일반화 지식을 압축된 형태로 이전하는 방법이 필요함

## Ⅱ. 특징

- hard label만 학습하는 방식보다 클래스 간 관계와 불확실성까지 전달할 수 있음
- 교사 모델의 추론 능력을 작은 모델에 이전해 SLM과 특화 모델의 성능을 보완함
- 학생 모델 용량이 너무 작으면 교사 지식을 충분히 담지 못해 효과가 제한될 수 있음
- 교사 모델 품질과 증류 데이터 품질이 결과를 크게 좌우함

## Ⅲ. 종류 및 비교

| 판단 기준 | 일반 미세조정 | 지식 증류 | 양자화 |
|:---|:---|:---|:---|
| 핵심 목적 | 특정 업무 적응 | 큰 모델 지식 이전 | 배포 비용 절감 |
| 성능 향상 경로 | 데이터 적합화 | teacher-student 모방 | 없음 |
| 모델 크기 축소 | 직접적이지 않음 | 가능함 | 가능함 |
| 대표 활용 | 도메인 적응 | SLM, 경량 모델 | 배포 최적화 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Teacher Model | 높은 성능과 일반화 능력을 가진 기준 모델로 학생 모델이 모방할 목표를 제공함 |
| Student Model | 더 작고 빠른 구조를 사용해 배포 가능성을 확보하면서 교사의 지식을 흡수함 |
| Distillation Loss | soft target, hidden state, attention 정보를 반영해 단순 정답 이상을 학습하게 함 |
| Task Data | 일반 데이터와 도메인 데이터를 함께 사용해 학생 모델의 실무 적합성을 높임 |

```text
+-------------------+      +-------------------+      +-------------------+
| Teacher Model     | ---> | Distillation Loss | ---> | Student Model     |
+-------------------+      +-------------------+      +-------------------+
                                   ^
                                   |
                           +-------------------+
                           | Task Data         |
                           +-------------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 교사 추론 생성  | --> | soft target 수집 | --> | 학생 모델 학습  | --> | 경량 모델 배포   |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **교사 추론 생성**: 교사 모델이 입력에 대한 출력 분포와 표현을 생성함
2. **soft target 수집**: 정답뿐 아니라 교사 확률과 중간 특징을 학습 데이터로 활용함
3. **학생 모델 학습**: 학생 모델이 정답 손실과 증류 손실을 함께 최적화함
4. **경량 모델 배포**: 학습된 학생 모델을 로컬, 엣지, 서비스 환경에 배포함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 교사 모델의 편향이나 오류까지 학생 모델이 그대로 학습하면 작은 모델이 같은 문제를 더 굳게 고착할 수 있음
   - 해결방안: 교사 출력 검증과 다중 평가셋을 운영하고 bias metric과 domain accuracy로 전이 품질을 검증함
2. 문제: 학생 모델의 용량이 너무 작으면 교사 지식을 충분히 담지 못해 성능 향상이 제한될 수 있음
   - 해결방안: 목표 장비에 맞는 최소 모델 크기를 설정하고 compression ratio 대비 task score로 수용 한계를 검증함
3. 문제: 증류용 교사 추론을 대량 생성하는 비용이 커지면 개발 일정과 학습 비용이 증가할 수 있음
   - 해결방안: 고가치 데이터 중심으로 증류셋을 구성하고 training cost와 quality gain으로 투자 효과를 검증함

## Ⅶ. 적용 사례

- 소형 언어 모델 개발이 대형 LLM의 답변 패턴을 작은 모델에 이전하도록 지식 증류를 적용하며 확인 지표는 benchmark score와 model size임
- 모바일 비전 모델 경량화가 큰 이미지 모델의 분류 능력을 작은 모델에 전수하도록 지식 증류를 활용하며 확인 지표는 accuracy와 latency임
- 사내 특화 챗봇이 도메인 질의응답 품질을 작은 모델로 이전하도록 지식 증류를 적용하며 확인 지표는 answer quality와 cost per request임

## Ⅷ. 결론

지식 증류는 큰 모델의 능력을 작은 모델로 이전해 배포성과 품질을 동시에 확보하는 방법이므로, 교사 품질과 학생 용량과 증류 데이터 설계를 함께 최적화해야 함.
