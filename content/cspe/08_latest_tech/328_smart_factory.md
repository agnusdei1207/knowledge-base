# 📖 【암기용】 개념 완전 이해

> 목적: Smart Factory를 설비·공정·품질·물류 데이터를 연결해 자율적 의사결정과 최적 생산을 수행하는 제조 시스템으로 이해하게 만든다.

## 한눈에
- **개요**: 설비, 공정, 품질, 물류 데이터를 연결해 생산을 모니터링·예측·제어하는 지능형 공장
- **왜 필요한가**: 다품종 소량 생산, 품질 추적, 납기 단축 요구가 커지면 수작업 보고와 사후 품질 검사만으로 대응하기 어렵다.
- **핵심 직관**: 공장 전체를 하나의 연결된 정보 시스템으로 만들어 문제가 생기기 전에 생산 조건을 조정하는 것이다.

## 깊이 이해
- **배경·문제의식**: 현장 PLC, 설비, MES, ERP, 품질 시스템이 분리되면 생산 현황과 원가·품질 원인을 실시간으로 연결하기 어렵다.
- **작동 원리**: 센서와 PLC 데이터를 수집하고 MES/SCADA/ERP와 연계해 생산 계획, 설비 상태, 품질 검사, 재고 흐름을 통합 분석한다.
- **비유**: 병원이 접수, 검사, 처방, 병상 현황을 따로 관리하면 병목을 모르는 것처럼 공장도 설비·품질·물류 데이터가 연결되어야 한다.
- **구체 예시**: 불량률이 특정 설비 온도 구간에서 증가하면 MES와 품질 데이터를 연결해 공정 조건을 조정하고 Lot 추적 범위를 좁힌다.
- **흔한 오해·주의점**: 스마트팩토리는 로봇 도입만이 아니다. 표준 데이터 모델, 설비 연결, MES·ERP 연계, 보안, 작업자 절차가 함께 필요하다.

## 연결 개념
- IIoT — 설비와 센서 데이터를 수집하는 기반
- OPC UA — 산업 장비 데이터 상호운용 표준
- Digital Twin — 공정 예측과 시뮬레이션 모델

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.
> 핵심: Smart Factory는 OT 설비 데이터와 IT 업무 시스템을 연결해 생산·품질·물류 의사결정을 데이터 기반으로 수행하는 제조 DX 구조임.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: Smart Factory는 센서·PLC·MES·SCADA·ERP·AI를 연결해 생산 상태를 실시간으로 파악하고 공정 의사결정을 지원하는 공장임.
> 2. **가치**: OEE, 불량률, 납기, 재고, 설비 다운타임을 데이터로 추적해 공정 개선과 예지보전을 수행함.
> 3. **판단 포인트**: ISA-95 계층, OPC UA/MQTT 연계, MES 중심 운영, OT 보안, 현장 작업 절차가 핵심임.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 제조 IT/OT 통합 이해 확인 | 설비-제어-MES-ERP 연계 | 로봇 자동화로만 설명 |
| 생산 지표 판단 확인 | OEE, 불량률, cycle time, downtime | 추상적 생산 개선 표현 |
| 보안·표준 인식 확인 | OPC UA, IEC 62443, ISA-95 | IT 시스템만 설명 |

> 요약: 이 문제는 공장을 데이터 플랫폼으로 연결하되 OT 제약과 제조 지표를 함께 보는 능력을 요구한다.

---

## Ⅰ. 개요 및 필요성

- 개요: 데이터 기반 지능형 공장
- 배경: 설비·품질·재고·계획 데이터가 분리되면 불량 원인과 생산 병목을 추적하기 어려움.
- 필요성: OT와 IT를 표준 인터페이스로 연결해 OEE, 불량률, 납기 지연을 데이터로 관리해야 함.

---

## Ⅱ. 구조 및 구성요소

```text
Sensor / PLC -> SCADA / Edge Gateway -> MES -> ERP / PLM
        +-> Data Platform / AI / Digital Twin
        +-> OT Security / Monitoring / Worker Interface
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 현장 설비 | 센서·PLC·로봇 데이터 생성 | real-time, deterministic |
| 제어·감시 | SCADA, HMI, edge gateway | OPC UA, Modbus |
| 생산 운영 | MES가 작업지시·실적·품질 관리 | ISA-95 Level 3 |
| 업무 연계 | ERP·PLM·SCM과 계획·자재 연결 | order, BOM, inventory |

> 요약: Smart Factory는 현장 제어 계층과 업무 시스템 계층을 MES·표준 인터페이스로 연결한다.

---

## Ⅲ. 동작원리 및 흐름도

```text
생산계획 수립 -> 작업지시 -> 설비 데이터 수집
-> 공정·품질 분석 -> 이상 탐지 -> 조건 조정 / 정비 지시 -> 실적 반영
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | ERP/MES가 주문·BOM 기반 생산계획을 생성함 | plan adherence |
| 2 | PLC/SCADA가 설비 상태와 생산 실적을 수집함 | data latency |
| 3 | 품질·공정 데이터를 분석해 이상을 탐지함 | defect rate |
| 4 | 작업 조건, 정비, 물류 지시를 갱신함 | OEE, cycle time |

> 요약: Smart Factory는 계획, 실행, 감시, 분석, 피드백을 닫힌 루프로 운영한다.

---

## Ⅳ. 특징

| 구분 | 전통 공장 | Smart Factory | 판단 기준 |
|:---|:---|:---|:---|
| 데이터 | 수기·사후 집계 | 설비·공정 실시간 수집 | data latency |
| 운영 | 경험 기반 조정 | MES·AI 기반 의사결정 | OEE·불량률 |
| 통합 | 설비별 silo | ISA-95 계층 연계 | 표준 인터페이스 |
| 보안 | 폐쇄망 의존 | zone/conduit 기반 OT 보안 | IEC 62443 |

> 요약: Smart Factory는 자동화 장비보다 데이터 연결, 제조 지표, OT 보안 체계가 핵심이다.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존/대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 구축 | 설비 자동화 단위 | 공정·품질·물류 통합 | 병목 원인 추적 |
| 데이터 | PLC 로컬 수집 | MES·데이터 플랫폼 연계 | 전사 분석 필요 |
| 보안 | 망분리 중심 | zone/conduit+모니터링 | 외부 연계 범위 |

> 요약: 스마트팩토리 전환은 설비별 자동화보다 공정 전체의 데이터 흐름과 지표 개선을 기준으로 판단한다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 데이터 불일치 | 설비 태그·코드 표준 부재 | tag dictionary, master data | mapping error |
| 생산 중단 | 검증 없는 제어 변경 | shadow mode, rollback 절차 | downtime |
| OT 보안 사고 | IT/OT 연결 확대 | IEC 62443 zone/conduit, allowlist | security event |

> 요약: 데이터 표준화, 제어 변경 검증, OT 보안을 선행하지 않으면 생산 리스크가 커진다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 생산성 | OEE, cycle time 추세 | MES log |
| 품질 | defect rate, rework rate | QMS, inspection data |
| 설비 | downtime, MTBF, MTTR | CMMS, SCADA event |

> 요약: 스마트팩토리 성과는 장비 도입 수가 아니라 OEE, 불량률, 다운타임 지표로 검증한다.

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. ISA-95 기준으로 설비·제어·MES·ERP 계층을 정리하고 공정별 tag dictionary와 master data를 표준화함.
2. 병목 공정부터 OPC UA/MQTT 기반 데이터 수집, MES 실적 연계, 품질 분석, 예지보전 모델을 단계 적용함.
3. IT/OT 연결 구간에 IEC 62443 기반 zone/conduit, allowlist, 계정 분리, 변경 승인 절차를 적용함.

**결론 (2줄):**
- 기술사 판단: 불량·다운타임·납기 지연 원인이 데이터 단절에 있으면 Smart Factory 투자가 타당하고, 설비 노후·센서 부재 현장은 데이터 수집 기반부터 구축함.
- 향후 방향: Smart Factory는 Digital Twin, AI vision, edge AI, 산업용 5G와 결합해 자율 제조 운영으로 발전함.
