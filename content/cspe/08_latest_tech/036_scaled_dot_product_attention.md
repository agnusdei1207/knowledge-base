## 미리 알고가기

- 쿼리/키/밸루 ($Q/K/V$): 어텐션 연산의 기본 벡터로, 각각 질문 기준, 비교 기준, 전달 정보를 뜻함
- 소프트맥스 ($Softmax$): 원소 값을 0~1 사이의 확률 분포 가중치로 변환해 집중할 토큰을 선택하는 함수임
- 스케일링 ($Scaling$): 내적($Dot-product$) 값이 커질 때 그래디언트 소실을 방지하기 위해 차원의 제곱근($\sqrt{d_k}$)으로 나누는 보정 연산임
- 패딩 마스크 ($Padding$ $Mask$): 입력 문장의 패딩($\langle pad \rangle$) 토큰 영역을 연산에서 제외하기 위해 무한대 음수값($-\infty$)을 씌우는 필터임

## Ⅰ. 개요

- **정의/개념**: Scaled Dot-Product Attention은 입력된 Query와 Key의 유사도를 내적으로 구한 뒤 Key 차원의 제곱근($\sqrt{d_k}$)으로 나누어 정규화하고, Softmax 확률 가중치를 Value에 곱해 최종 문맥 정보를 추출하는 트랜스포머($Transformer$)의 핵심 연산임
- **배경/필요성**: 차원 수가 큰 고차원 공간에서는 단순 내적 시 결과값이 너무 커져 Softmax 함수의 미분값이 0에 가까워지는 그래디언트 소실 문제가 발생하므로, 연산의 안정성을 유지하면서 GPU 행렬 병렬 연산 효율을 살리기 위해 고안됨

## Ⅱ. 특징

- 질의($Q$)와 비교 대상($K$)의 관계를 단순 행렬 내적 연산($QK^T$)으로 처리하므로, 연산 구조가 매우 단순하고 GPU 가속을 극대화하여 대규모 병렬 학습을 실현함
- 차원 수의 제곱근인 $\sqrt{d_k}$로 나누는 스케일 조정을 통해 점수 분산을 일정하게 유지하여, 소프트맥스 수치 포화로 인한 학습 지연을 방지함
- 디코딩 단계에서 미래 단어를 참조하지 못하도록 막는 인과적 마스킹($Causal$ $Mask$)이나 패딩 필터를 행렬 덧셈 연산으로 통합 처리할 수 있는 유연성을 제공함

## Ⅲ. 종류 및 비교

| 판단 기준 | 가산 어텐션 (Additive) | 닷 프로덕트 어텐션 (Dot-Product) | 스케일드 닷 프로덕트 (Scaled Dot-Product) |
|:---|:---|:---|:---|
| **유사도 연산** | 가중치 행렬 합산 ($W_a[h_i; s_j]$) | 단순 행렬 내적 ($QK^T$) | 내적 후 차원 보정 ($QK^T / \sqrt{d_k}$) |
| **차원 영향성** | 차원이 커져도 비교적 안정적임 | 차원이 크면 수치 포화 발생함 | 스케일링을 통해 포화를 해결함 |
| **병렬 처리성** | 순차 피드포워드로 다소 느림 | 행렬 내적 기반으로 매우 빠름 | 빠른 속도와 학습 안정성을 동시 확보 |
| **주요 활용** | 초기 $seq2seq$ 모델 | 초기 프로토타입 어텐션 | 트랜스포머 계열 및 최신 $LLM$ 표준 |

> 요약: Additive는 수식 안정성에, Dot-Product는 속도에, Scaled Dot-Product는 속도와 수식 안정성의 균형에 집중함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 쿼리/키/밸루 | 원문 임베딩에 투영 가중치를 곱해 생성되며, 입력의 의미론적 매핑 기준이 됨 |
| 유사도 스코어 | $QK^T$ 연산의 결과물로, 문장 내 토큰 쌍 간의 수학적 상관관계를 나타내는 정형 행렬임 |
| 스케일러 ($\sqrt{d_k}$) | Key 벡터 차원의 제곱근 값으로, 내적 결과의 급격한 수치 발산을 억제하는 나눗셈 상수임 |
| 소프트맥스 필터 | 점수를 확률 분포로 바꾸며, 마스킹된 영역($-\infty$)은 가중치가 0이 되도록 차단함 |

```text
[ 스케일드 닷 프로덕트 어텐션 연산 공식 ]
Attention(Q, K, V) = softmax( (Q * K^T) / √d_k ) * V
- Q * K^T: 연관도 스코어
- / √d_k: 스케일링 보정
- * V: 문맥 정보 취합
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 행렬 곱 연산| --> | 제곱근 분산조정| --> | 마스킹/소프트| --> | 가중치곱 합산|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **상관 연산** — 입력 쿼리($Q$) 행렬과 키($K$) 행렬의 전치 행렬을 내적하여 각 단어 간 연관성을 담은 정방 스코어 행렬을 계산함
2. **수치 보정** — 내적 행렬의 모든 원소를 $\sqrt{d_k}$로 나누어 차원이 커짐에 따라 내적 평균값이 발산하여 발생하는 그래디언트 소실을 억제함
3. **마스크/확률** — 디코더의 경우 우측 단어를 보지 못하게 가리는 마스킹을 더한 뒤, 소프트맥스를 적용하여 각 단어가 어느 단어에 집중할지 확률 지도를 완성함
4. **문맥 결합** — 완성된 소프트맥스 가중치 행렬을 실제 정보 값인 밸루($V$) 행렬과 곱하여, 문맥 의미가 최종 반영된 출력 텐서를 생성함

## Ⅵ. 실무 적용 및 유의점

1. 시퀀스 길이($N$)가 길어질수록 모든 토큰 쌍의 유사도를 구해야 하므로 메모리와 연산 복잡도가 $O(N^2)$로 급증해 병목이 발생하므로, 실무에서는 온라인 어텐션 가속 엔진인 'FlashAttention' 커널을 적용하고 첫 토큰 생성 시간($TTFT$)과 토큰당 생성 지연($TPOT$) 지표로 개선 성능을 검증해야 함
2. 기계 번역이나 문서 분류 설계 시 소스 문장의 불필요한 패딩 영역이 어텐션 가중치를 소량이나마 나눠 갖는 현상을 방지하기 위해, 패딩 마스크의 초깃값을 완벽한 무한대 음수($-\infty$)로 설정하여 Softmax 차단 안정성을 확보하고 문맥 해석 정확도로 이를 확인함

## Ⅶ. 결론

- Scaled Dot-Product Attention은 대형 언어 모델의 차원 팽창 한계를 극복하여 트랜스포머 시대를 개막한 표준 엔진이며, 설계자는 긴 시퀀스에서의 메모리 연산 병목 완화 기법과 엄격한 마스킹 설계를 적용하여 추론 가용성을 확보해야 함
