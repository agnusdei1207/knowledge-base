## 미리 알고가기

- 헤드 ($Head$): 가중치를 독립적으로 공유하며 서로 다른 차원으로 투영된 $Q, K, V$의 병렬 어텐션 단위임
- 연결 ($Concat$): 각 헤드가 추출한 부분 문맥 표현들을 이어 붙여 단일 모델 차원으로 복원하는 조립 연산임
- 출력 투영 ($Output$ $Projection$): 병합된 헤드 정보들을 피드포워드 신경망에 넘기기 전 선형 변환하여 의미를 정돈하는 층임
- $GQA$ ($Grouped-Query$ $Attention$): 헤드들을 소그룹으로 묶어 하나의 $K, V$ 헤드를 공유하는 고속 추론 기술임

## Ⅰ. 개요

- **정의/개념**: Multi-Head Attention은 입력 데이터의 $Q, K, V$를 여러 개의 하위 벡터 공간으로 병렬 사상하고, 각 헤드($Head$)가 독립적으로 Scaled Dot-Product 어텐션을 수행한 뒤 이를 결합하여 풍부한 문맥을 이해하는 트랜스포머의 다중 관점 추출 모듈임
- **배경/필요성**: 단일 어텐션은 문장 내 단어 간의 한 가지 연관성(예: 대명사 지칭)만 집중하여 다각도의 관계를 놓치므로, 문법적 결합과 장거리 의미 의존성을 동시에 학습하기 위한 병렬 분석기 격으로 설계됨

## Ⅱ. 특징

- 각 헤드가 상이한 결합 패턴(예: 주어-동사 호응, 시제 매핑 등)을 포착하므로 문장의 의미 구조를 훨씬 입체적이고 강건하게 이해함
- 고차원의 어텐션 연산을 다수의 저차원 조각으로 나누어 처리하기 때문에, 단일 헤드로 연산하는 대비 성능 효율성과 파라미터 제어력을 대폭 향상함
- 병렬 구조를 띠므로 하드웨어 스레드 병렬화에 적합하며, 학습이 진행될수록 특정 헤드들이 문장 내 주요 구문 구조에 우선 집중하도록 자기 정렬함

## Ⅲ. 종류 및 비교

| 판단 기준 | MHA (Multi-Head) | MQA (Multi-Query) | GQA (Grouped-Query) |
|:---|:---|:---|:---|
| **K, V 헤드 수** | Query 헤드 수와 동일 ($H$개) | 오직 1개의 헤드만 사용 | 그룹당 1개의 헤드 사용 ($G$개) |
| **추론 속도** | 대량 메모리 입출력으로 느림 | 매우 빠름 (최적화 성능) | 빠름 (MHA와 MQA의 장점 결합) |
| **KV 캐시 용량** | 매우 큼 (병목 원인) | 최소화 (극적인 절감) | 중간 (효율적 절감) |
| **표현력 다양성** | 가장 우수함 | 상대적으로 저하 위험 있음 | MHA 수준의 우수한 성능 보존 |

> 요약: MHA는 성능을 극대화하고, MQA는 속도를 극대화하며, GQA는 성능 저하를 방지하면서 속도를 최적화함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 헤드 분할기 | 가중치 $W_i^Q, W_i^K, W_i^V$를 통해 입력 텐서를 각 헤드의 하위 차원으로 투영하는 분기부임 |
| 병렬 어텐션 코어 | 분기된 $Q_i, K_i, V_i$ 쌍에 대해 개별 Scaled Dot-Product Attention을 수행함 |
| 컨캣 레지스터 | 병렬 연산 완료된 $h$개의 단일 출력 벡터들을 좌우로 이어 붙여 $d_{model}$ 크기로 맞춤 |
| 가중치 $W^O$ 투영 | 컨캣된 다차원 벡터를 최종 선형 변환하여 잔차 연결($Residual$ $Connection$) 레이어로 보냄 |

```text
[ Multi-Head Attention 연산 구조 ]
Input -> [Projection W_Q, W_K, W_V] -> [Split to H Heads] -> [Parallel Attention * H]
                                                                        | (Concat)
Output <- [Output Projection W_O] <-------------------------------------/
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 선형 차원분기| --> | 병렬 독립어텐| --> | 헤드 출력결합| --> | 선형 투영변환|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **관점 투영** — 입력 토큰 행렬에 여러 벌의 학습 가중치 매트릭스를 곱하여, 각 헤드가 분석할 다차원 공간의 $Q, K, V$ 행렬들을 동시에 생성함
2. **독립 연산** — 쪼개진 $H$개의 입력 슬라이스들에 대해 동시 다발적으로 마스크드 어텐션 점수를 계산하여 부분 문맥 가중치를 산출함
3. **지능 융합** — 각각의 헤드가 도출해낸 부분 문맥 밸루($V$) 결과물들을 원래의 문맥 차원 길이로 접착제처럼 이어 붙임($Concat$)
4. **최종 변환** — 융합된 결과에 출력 가중치 매트릭스($W^O$)를 한 번 더 곱해 주어, 후속 사설망(FFN)으로 전파하기 직전 최종 의미 조정을 완료함

## Ⅵ. 실무 적용 및 유의점

1. 초거대 LLM 추론 시 멀티 헤드 구조는 매 시점마다 엄청난 양의 $K, V$ 데이터를 램에 쓰고 읽어야 하는 메모리 대역폭 한계(KV 캐시 병목)를 유발하므로, 실무 배포 시에는 $K, V$ 헤드를 공용 묶음 처리한 'GQA' 기반 모델을 채택하고 토큰 처리량($Throughput$) 지표로 성능을 검증해야 함
2. 분산 GPU 학습 환경에서 텐서 병렬화($Tensor$ $Parallelism$)를 적용할 경우 헤드를 나누어 각 GPU에 분배하지만, 마지막 출력 Concat 직후 GPU 간에 모든 어텐션 정보를 모으는 통신($All-Reduce$) 병목이 발생하므로 통신 커널 융합($Fused$ $Kernel$)을 적용하고 통신 오버헤드 비율로 안전성을 모니터링해야 함

## Ⅶ. 결론

- Multi-Head Attention은 획일화된 시각을 거부하고 다중 지능의 시너지로 문맥을 입체 해석하는 트랜스포머의 심장이며, 설계자는 추론 효율을 위한 GQA 기법의 결합과 텐서 병렬화 시의 네트워크 병목 요인을 사전에 완벽히 통제해야 함
