# 📖 【암기용】 개념 완전 이해

> 목적: Text-to-Speech를 처음 봐도 완벽히 이해하게 만든다.

## 한눈에
- **개요**: 텍스트를 사람처럼 들리는 음성 파형으로 변환하는 음성 합성 기술
- **왜 필요한가**: 상담봇, 내비게이션, 접근성, 교육 콘텐츠에서 자연스러운 음성 응답이 필요함.
- **핵심 직관**: 글을 읽어주는 성우 역할을 AI가 수행하는 기술임.

## 깊이 이해
- **배경·문제의식**: 기계음 TTS는 억양과 감정이 어색해 장시간 청취와 고객 응대에 한계가 있었다. 신경망 TTS는 발음·억양·감정 표현을 개선함.
- **작동 원리**: 텍스트를 음소·prosody로 변환하고, acoustic model이 mel-spectrogram을 생성한 뒤 vocoder가 실제 음성 파형으로 복원함.
- **비유**: 원고를 보고 성우가 발음, 속도, 감정을 조절해 녹음하는 과정을 모델이 자동 수행함.
- **구체 예시**: 상담봇에서 24kHz neural TTS를 사용해 평균 응답 지연 300ms 이하, MOS 4.2 이상을 목표로 운영.
- **흔한 오해·주의점**: 자연스러운 음성일수록 보이스피싱·딥보이스 악용 위험이 커진다. 워터마킹과 화자 동의 관리가 필요함.

## 연결 개념
- Speech-to-Text — 음성을 텍스트로 변환하는 반대 방향 기술
- Vocoder — mel-spectrogram을 파형으로 변환하는 모델
- Voice Cloning — 특정 화자 음색을 복제하는 TTS 응용

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: TTS는 텍스트를 음소·음향 특징·파형으로 변환하는 음성 생성 기술임.
> 2. **가치**: 상담봇·접근성·교육 콘텐츠에서 자연스러운 음성 인터페이스를 제공함.
> 3. **판단 포인트**: MOS, 지연, 발음 정확도, 화자 권리, 딥보이스 악용 방지를 함께 관리해야 함.

## Ⅰ. 개요 및 필요성

Text-to-Speech는 텍스트 기반 음성 합성 기술임. 음성 인터페이스와 접근성 서비스는 자연스러운 발화와 낮은 지연이 필요하다. 신경망 TTS는 억양·감정·화자 특성을 반영해 사용자 경험을 개선한다.

## Ⅱ. 구조 및 구성요소

```text
Text -> Text Normalization -> Acoustic Model
  -> Mel-spectrogram -> Vocoder -> Speech Waveform
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Text Normalizer | 숫자·약어·기호 발음 변환 | 날짜·금액·영문 처리 |
| Acoustic Model | 텍스트를 음향 특징으로 변환 | Tacotron, FastSpeech, VITS |
| Vocoder | mel을 파형으로 합성 | HiFi-GAN, WaveNet |
| Safety Control | 화자 동의·워터마크·남용 탐지 | voice consent, watermark |

> 요약: TTS는 텍스트 정규화, 음향 특징 생성, vocoder 파형 복원, 안전 통제로 구성됨.

## Ⅲ. 동작원리 및 흐름도

```text
텍스트 입력 -> 발음 정규화 -> prosody 예측
  -> mel-spectrogram 생성 -> vocoder 합성 -> 워터마크/출력
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 텍스트 정규화·음소 변환 | 발음 오류율 <2% |
| 2 | prosody·mel-spectrogram 생성 | MOS ≥4.0 |
| 3 | vocoder가 파형 합성 | 지연 <300ms |
| 4 | 워터마크·화자 권리 검증 | 무동의 화자 합성 0건 |

> 요약: TTS는 텍스트를 발음 가능한 단위로 바꾸고 음향 특징과 파형을 생성해 자연어 음성을 출력함.

## Ⅳ. 특징

| 구분 | 규칙 기반 TTS | Neural TTS | 판단 포인트 |
|:---|:---|:---|:---|
| 음질 | 기계음 | 자연스러운 억양 | MOS 4.0 이상 목표 |
| 제어 | 제한적 | 속도·감정·화자 제어 | 상담·교육에 적합 |
| 지연 | 낮음 | 모델별 상이 | 실시간은 300ms 이하 |
| 리스크 | 낮음 | 딥보이스·권리 침해 | 동의·워터마크 필수 |

> 요약: Neural TTS는 자연성과 제어성이 강점이지만, 화자 권리와 악용 방지 통제가 필수임.

## Ⅴ. 실무 적용 및 결론

**적용 방안 3개:**
1. 상담봇 음성: FastSpeech2+HiFi-GAN 계열로 300ms 이하 응답, MOS 4.0 이상 기준 운영
2. 접근성 서비스: 문서·알림 텍스트를 고품질 음성으로 제공하고 속도·톤 조절 옵션 제공
3. 악용 방지: 화자 동의 DB, 합성 음성 워터마크, 보이스피싱 탐지 룰을 배포 조건에 포함

**결론 (2줄):**
- 기술사 판단: 사용자 응대·접근성에는 Neural TTS 적용, 화자 복제는 명시 동의와 워터마킹 필수
- 향후 방향: 실시간 감정 제어 TTS와 STT·LLM 결합 음성 에이전트로 발전
