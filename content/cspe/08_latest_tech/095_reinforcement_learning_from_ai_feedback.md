## 미리 알고가기

- RLAIF는 인간 대신 고성능 AI 평가자나 헌법형 규칙을 이용해 선호 데이터를 만드는 정렬 방식임
- RLHF의 비용과 확장성 한계를 보완하기 위해 등장함
- 완전 자동화보다 인간 감사와 결합된 하이브리드 운영이 일반적임

## Ⅰ. 개요

- **정의/개념**: RLAIF는 강력한 AI 평가자나 사전 정의된 원칙을 이용해 모델 응답의 선호도를 생성하고, 이를 바탕으로 정렬 학습을 수행하는 AI 피드백 기반 정렬 기법임
- **배경/필요성**: RLHF는 인간 선호 데이터 구축 비용이 크고 속도가 느리므로, 대규모 정렬 반복을 위해 더 빠르고 확장 가능한 피드백 생성 방식이 필요함

## Ⅱ. 특징

- 인간 라벨링보다 비용과 속도 측면에서 확장성이 높아 대량 선호 데이터 생성에 유리함
- 명문화된 rubric이나 constitutional rule을 넣어 비교적 일관된 평가를 반복할 수 있음
- 평가자 AI의 편향과 길이 선호 같은 judge bias가 그대로 전이될 위험이 있음
- 고위험 영역에서는 인간 감사 없이 단독 사용하기 어려움

## Ⅲ. 종류 및 비교

| 판단 기준 | RLHF | RLAIF | Constitutional AI |
|:---|:---|:---|:---|
| 피드백 주체 | 인간 | AI 평가자 | 헌법형 규칙+AI 평가 |
| 비용 | 높음 | 낮음 | 낮음 |
| 확장성 | 제한적임 | 높음 | 높음 |
| 감독 필요성 | 높음 | 높음 | 높음 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Rubric, Constitution | AI 평가자가 따라야 할 기준을 정의해 평가 일관성을 높임 |
| AI Judge | 후보 응답을 비교하거나 비판해 선호 데이터를 생성하는 평가 모델임 |
| Preference Pipeline | 생성된 선호 데이터를 정렬 학습용 형식으로 정제하고 저장함 |
| Human Audit Layer | 고위험 샘플과 평가 일탈을 감사해 전체 파이프라인의 신뢰성을 통제함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 평가 기준 정의  | --> | AI 선호 판정 생성 | --> | 정렬 데이터 구성  | --> | 정책 업데이트    |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **평가 기준 정의**: 도움이 됨, 무해함, 규정 준수 같은 기준을 명문화함
2. **AI 선호 판정 생성**: AI 평가자가 후보 응답을 비교하거나 수정 방향을 제시함
3. **정렬 데이터 구성**: 선호쌍이나 비판-수정 데이터를 학습 데이터로 변환함
4. **정책 업데이트**: RLHF류 최적화나 DPO로 대상 모델을 정렬함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 평가자 AI가 가진 길이 편향이나 문체 편향이 그대로 학습 신호가 되면 정렬된 모델도 같은 왜곡을 강화할 수 있음
   - 해결방안: 평가자 앙상블과 position randomization을 적용하고 judge agreement와 bias metric으로 공정성을 검증함
2. 문제: AI가 AI를 평가하는 루프가 반복되면 객관성이 약해지고 자기 강화식 오류가 누적될 수 있음
   - 해결방안: 인간 gold set과 주기적 감사 절차를 운영하고 audit disagreement rate와 critical failure count로 신뢰성을 검증함
3. 문제: 저비용 데이터 생성이 가능하다고 해도 규칙 설계가 부실하면 대규모로 잘못된 정렬이 빠르게 확산될 수 있음
   - 해결방안: rubric과 constitution을 지속 개선하고 policy violation rate와 user complaint rate로 기준 적합성을 검증함

## Ⅶ. 적용 사례

- 대규모 안전성 정렬: AI judge로 후보 응답을 빠르게 평가함, 확인 지표는 cost per pair와 safety score임
- 기업 규정 준수 챗봇: 사내 정책을 rubric으로 반영함, 확인 지표는 policy violation rate와 audit agreement임
- 헌법형 AI 실험: 비판과 수정 데이터를 자동 생성함, 확인 지표는 harmlessness score와 response utility임

## Ⅷ. 결론

RLAIF는 정렬 데이터 확장성을 크게 높이는 방법이지만, AI 평가자의 편향과 규칙 설계 오류를 인간 감사로 지속 통제하는 하이브리드 운영이 전제되어야 함.
