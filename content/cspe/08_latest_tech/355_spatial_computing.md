# 📖 【암기용】 개념 완전 이해

> 목적: 공간 컴퓨팅을 디지털 객체가 현실 공간 좌표와 맥락을 인식해 상호작용하는 컴퓨팅 패러다임으로 이해하게 만든다.

## 한눈에
- **개요**: 현실 공간을 인식하고 디지털 객체를 배치·조작하는 컴퓨팅
- **왜 필요한가**: 화면 안의 앱은 실제 위치, 표면, 깊이, 손동작을 알지 못한다. 공간 컴퓨팅은 현실 환경을 입력과 출력의 일부로 사용한다.
- **핵심 직관**: 컴퓨터가 책상 위, 벽면, 사람의 손 위치를 이해하면 앱이 화면 안이 아니라 방 전체에서 동작한다.

## 깊이 이해
- **배경·문제의식**: 모바일과 PC UI는 2D 화면 좌표에 묶여 있다. 공간 컴퓨팅은 카메라, LiDAR, IMU, SLAM으로 주변 공간을 매핑하고 3D 객체를 고정한다.
- **작동 원리**: 센서가 공간을 스캔하고, SLAM이 기기 위치를 추정하며, spatial anchor가 디지털 객체를 현실 좌표에 고정한다.
- **비유**: 포스트잇을 모니터 화면에 붙이는 것이 아니라, 실제 벽과 책상 위치를 인식한 앱이 그 자리에 디지털 포스트잇을 붙이는 방식이다.
- **구체 예시**: 정비 작업자는 장비 위에 부품 분해 순서를 AR로 겹쳐 보고, 시스템은 손 위치와 부품 위치를 추적해 다음 단계를 안내한다.
- **흔한 오해·주의점**: 공간 컴퓨팅은 VR 헤드셋만 의미하지 않는다. 스마트폰 AR, 산업용 HMD, 로봇, 디지털 트윈까지 공간 인식 컴퓨팅에 포함될 수 있다.

## 연결 개념
- Extended Reality — 공간 컴퓨팅의 주요 사용자 인터페이스
- SLAM — 위치 추정과 지도 작성을 동시에 수행
- OpenXR — XR 기기 접근을 위한 표준 API

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.
> 핵심: 공간 컴퓨팅은 센서, SLAM, spatial anchor, hand/eye tracking, 3D 렌더링을 결합해 현실 공간을 컴퓨팅 인터페이스로 바꾼다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 공간 컴퓨팅은 물리 공간의 위치·깊이·표면·동작 정보를 인식해 디지털 객체와 상호작용하게 하는 기술이다.
> 2. **가치**: 정비, 의료, 설계, 교육, 물류에서 사용자의 시야와 실제 작업 위치에 정보를 배치한다.
> 3. **판단 포인트**: tracking accuracy, latency, occlusion, privacy, ergonomics, OpenXR 호환성을 점검한다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 공간 인식 원리 확인 | sensor fusion, SLAM, anchor, rendering | XR 기기 마케팅으로 설명 |
| 산업 적용 판단 확인 | 현장 안내, 설계 검토, 원격 지원 | 게임 사례만 제시 |
| 운영 리스크 확인 | 위치 오차, 시야 피로, 영상 개인정보 | 3D 표시 장점만 나열 |

> 요약: 이 문제는 현실 공간 좌표를 입력·출력으로 쓰는 구조와 현장 적용 지표를 묻는다.

---

## Ⅰ. 개요 및 필요성

- 개요: 공간 인식 컴퓨팅
- 배경: 2D 화면 UI는 실제 작업 위치와 디지털 정보를 분리해 현장 작업자의 인지 부담을 만든다.
- 필요성: 센서와 SLAM으로 공간 좌표를 인식하고 작업 대상 위에 절차·상태·경고를 배치해야 함.

---

## Ⅱ. 구조 및 구성요소

```text
Camera / LiDAR / IMU -> Sensor Fusion / SLAM -> Spatial Map
                      -> Anchor / Occlusion -> 3D UI / Interaction
                      +-> Privacy / Device Management
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 센서 | 영상·깊이·관성 데이터 수집 | camera, LiDAR, IMU |
| SLAM | 위치 추정과 공간 지도 작성 | drift 관리 |
| spatial anchor | 디지털 객체를 현실 좌표에 고정 | persistence |
| interaction | 손·시선·음성 입력 처리 | eye/hand tracking |

> 요약: 공간 컴퓨팅은 센서 데이터에서 공간 지도와 앵커를 만들고 3D UI를 현실 좌표에 배치한다.

---

## Ⅲ. 동작원리 및 흐름도

```text
공간 스캔 -> 위치 추정/지도 작성 -> 객체 앵커링
-> 사용자 입력 추적 -> 3D 렌더링 -> 작업 결과 기록
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 센서가 주변 표면, 깊이, 움직임을 수집함 | sensor calibration |
| 2 | SLAM이 기기 위치와 공간 지도를 계산함 | tracking accuracy |
| 3 | 디지털 객체를 anchor에 배치하고 occlusion을 처리함 | anchor drift |
| 4 | 손·시선·음성 입력으로 작업을 수행하고 로그를 남김 | task completion |

> 요약: 공간 컴퓨팅은 공간 매핑, 앵커링, 상호작용, 기록이 한 흐름으로 연결되어야 현장 업무에 적용된다.

---

## Ⅳ. 특징

| 구분 | 모바일 AR | 공간 컴퓨팅 | 판단 기준 |
|:---|:---|:---|:---|
| 공간 이해 | 화면 중심 추적 | room-scale map | 작업 범위 |
| 입력 | 터치 | 손·시선·음성 | 현장 장갑·위생 |
| 출력 | 화면 오버레이 | 고정된 3D 객체 | anchor 정확도 |
| 운영 | 앱 배포 | 기기·공간 데이터 관리 | 개인정보·보안 |

> 요약: 공간 컴퓨팅은 단순 오버레이보다 공간 지도, 지속 앵커, 자연 입력을 포함한다.

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존/대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 작업 안내 | 종이 매뉴얼 | 위치 기반 AR 절차 | 양손 작업 |
| 설계 검토 | 2D CAD 화면 | 실제 크기 3D 배치 | 공간 충돌 확인 |
| 원격 지원 | 영상 통화 | 시야 공유+공간 표시 | 현장 좌표 지시 |

> 요약: 공간 컴퓨팅은 작업 위치와 지시 정보가 일치해야 오류가 줄어드는 업무에 적합하다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 위치 오차 | SLAM drift, 조명 변화 | anchor recalibration | tracking error |
| 개인정보 노출 | 카메라 상시 수집 | on-device processing, masking | privacy event |
| 사용자 피로 | 무게·시야·지연 | 세션 제한, ergonomics test | dropout rate |

> 요약: 공간 컴퓨팅 리스크는 정확도, 영상 개인정보, 착용 피로에서 발생한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 정확도 | 업무 허용 오차 이내 | calibration test |
| 지연 | 상호작용 지연 관리 | telemetry |
| 업무 효과 | 작업시간·오류율 변화 | field trial |

> 요약: 공간 컴퓨팅은 시연 품질보다 현장 작업시간, 오류율, 추적 오차로 평가한다.

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 정비, 물류, 의료, 설계 검토 중 공간 좌표가 필요한 업무를 선정하고 허용 오차와 지연 기준을 정함.
2. OpenXR 호환성, 기기 무게, 배터리, 시야각, 장갑 착용 입력을 현장 파일럿에서 검증함.
3. 공간 맵과 영상 데이터의 저장 위치, 마스킹, 접근통제, 삭제 주기를 개인정보 정책에 포함함.

**결론 (2줄):**
- 기술사 판단: 작업 대상과 디지털 지시가 같은 공간에 있어야 오류가 줄어드는 업무에 공간 컴퓨팅을 적용함.
- 향후 방향: 공간 컴퓨팅은 XR 기기, edge AI, digital twin, robot perception과 결합해 현장 의사결정 인터페이스로 확장됨.
