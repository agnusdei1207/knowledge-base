## 미리 알고가기

- 공간 컴퓨팅(Spatial Computing): 화면 속 가상 정보와 실제 물리 공간을 결합하여, 사용자의 주변 환경 자체를 컴퓨터 입력 및 인터페이스로 활용하는 기술임
- 공간 앵커(Spatial Anchor): 가상의 3D 콘텐츠를 실제 현실 공간의 특정 좌표 및 사물에 물리적으로 흔들림 없이 고정하기 위해 사용하는 기준점임
- 드리프트(Drift): 센서의 누적 오차로 인해 디지털 객체가 고정된 물리 좌표에서 벗어나 조금씩 이동하거나 흔들리는 위치 추정 오류 현상임
- SLAM(Simultaneous Localization and Mapping): 센서 데이터를 기반으로 주변 환경의 디지털 지도를 생성하는 동시에, 기기의 위치를 실시간으로 추정하는 기술임
- LiDAR(Light Detection and Ranging): 레이저 펄스를 발사하고 반사되어 돌아오는 시간을 측정하여, 정밀한 3D 공간의 깊이 정보와 거리를 계산하는 센서임

## 작성 근거(검토용)

- **핵심 키워드 선정 이유**: 화면 바깥의 물리적 환경 전체를 인터페이스로 치환하는 공간 컴퓨팅의 특성을 명시하고, 이를 구현하는 실시간 위치 측정 기법(SLAM)과 정밀 센싱 기술(LiDAR)을 규명하고자 선정함
- **절 구성 및 전개 흐름 이유**: 개요와 특징에서 실제 현실 좌표계와 디지털 픽셀의 결합 가치를 조명하고, Ⅲ절에서 공간 인식의 정밀도 기준으로 기존 2D 화면 및 일반 가상현실(VR)과의 경계를 설정함. Ⅳ절과 Ⅴ절은 물리적 공간을 계측하여 3D 구조를 그리는 SLAM 알고리즘 구성요소와 갱신 단계를 전개함. 실무사례는 현장 정비 및 건설 설계 조치를 중심으로 제언하고, 결론에서 정밀 드리프트 억제 방안을 인사이트로 연결함
- **전수 검수 완료 근거**: Frontmatter 날짜 형식을 최신으로 반영하고 weight 355를 확인하였음. 미리 알고가기 5개 항목, 작성 근거 블록 상단 배치 완료함. 본문 및 비교표, 결론의 2개 불릿 구성과 모든 절의 쉽게 이해하기 내용까지 문맥적 흐름을 5회 반복 검수하고 빌드 검증을 마침

## Ⅰ. 개요

- **정의/개념**: 공간 컴퓨팅은 현실의 물리적 공간을 기계가 인식·디지털화하고, 물리 환경 내 특정 공간 좌표에 디지털 정보를 배치·결합하여 제어하는 차세대 인간-컴퓨터 상호작용(HCI) 모델임
- **배경/필요성**: 기존 2차원 스크린 기반 UI는 실제 사용자가 처한 환경 정보와 단절되어 몰입성과 작업 직관성이 떨어지므로, 의료·설계·현장 정비 등의 분야에서 공간 맥락을 직접 파악하고 활용하는 인터페이스가 필요함

### 쉽게 이해하기 (학습용)
- 스마트폰 화면 안에 갇혀 있던 정보를 내 방 거실 바닥이나 책상 위 같은 실제 물리적 공간에 바로 띄워놓고 시선이나 손짓으로 조작하는 새로운 컴퓨터 사용 환경임

## Ⅱ. 특징

- **현실 공간의 계산 매체화**: 방바닥, 벽면, 테이블 등 물리적 사물과 구조 자체를 데이터 입력과 시각 디스플레이의 영역으로 사용함
- **자연스러운 직관적 제어**: 별도 마우스나 터치패드 없이 시선 추적(Eye-tracking), 손동작(Gesture), 음성 인식을 융합하여 조작함
- **공간 고정성 및 오클루전**: 공간 앵커를 기반으로 가상의 정보가 실제 위치에 고착되며, 실제 기둥 뒤로 디지털 캐릭터가 숨는 가림 처리가 가능함

### 쉽게 이해하기 (학습용)
- 모니터가 따로 필요 없이 실제 내 방의 가구 위치를 파악하여 디지털 액자를 벽에 직접 걸 수 있고, 손가락 동작과 내 눈길만으로 앱을 실행할 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | 2차원 화면 인터페이스 | XR 체험형 콘텐츠 | 공간 컴퓨팅 (Spatial Computing) |
|:---|:---|:---|:---|
| **공간 인식 레벨** | 공간 인식이 전혀 없음 | 가상 방에서 아바타 이동 등 가상의 방 좌표계만 모방함 | 라이다와 센서로 실제 3D 물리 공간 구조를 실시간 스캔함 |
| **사용자 상호작용** | 마우스, 키보드, 터치에 국한됨 | 전용 컨트롤러 버튼 입력과 트래킹 링에 종속됨 | 시선, 핑거 제스처, 자연어 융합형 입력을 사용함 |
| **정보 투영 방식** | 고정 디스플레이 프레임 내에만 렌더링됨 | 사용자 가상 카메라 뷰 각도에 맞춰 객체를 오버레이함 | 실제 사물의 좌표에 매핑하고 오클루전(가림) 처리를 지원함 |

### 쉽게 이해하기 (학습용)
- 평평한 모니터 화면으로 일하는 것이나 머리에 쓰는 단순 게임기를 사용하는 것과 달리, 내 거실 테이블 뒤에 가상의 컵을 놓아 기둥 뒤로 숨게 만드는 등 현실 전체를 컴퓨팅으로 쓰는 기술임

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| **공간 인지 센서 (Sensors)** | 깊이 센서, LiDAR, 다각 카메라가 주변 환경의 기하학적 형태와 깊이 데이터를 획득하는 입력 모듈 |
| **SLAM 프로세서 (SLAM Engine)** | 센서 패킷을 기반으로 주변 3D 지도를 그림과 동시에 기기의 6자유도(6DoF) 자세를 실시간 연산하는 처리장치 |
| **장면 복원 모듈 (Meshing)** | 공간 스캔 데이터를 가상의 다각형 그물망(Mesh) 구조로 변환하여 실제 사물의 형상을 감지하는 레이어 |
| **공간 앵커 제어기 (Anchor Manager)** | 특정 장치 및 좌표 맵 상에 가상 오브젝트를 고정하여 드리프트로 인한 객체 흐름을 억제하는 기준 수립 모듈 |
| **공간 렌더러 (Spatial Renderer)** | 실제 물체 뒤로 가상 물체가 가려지는 오클루전 및 조명 그림자 효과를 계산하여 출력하는 GPU 파이프라인 |

```text
[ 물리 공간 (사물/벽) ] ───── 광선 및 이미지 센싱 ─────> [ 공간 인지 센서 ]
                                                              │
                                                        3D 포인트 클라우드
                                                              │
                                                              v
[ 공간 렌더러 (GPU) ] <─── 실시간 지도 구축 및 자세 추정 ─── [ SLAM 프로세서 ]
```

### 쉽게 이해하기 (학습용)
- 방 구조를 읽는 눈(LiDAR 센서), 가상 지도를 그리고 기기 위치를 잡는 뇌(SLAM), 디지털 정보를 벽에 고정하는 못(공간 앵커), 그리고 자연스럽게 입체 화면을 띄워주는 화가(렌더러)로 구성된 시스템임

## Ⅴ. 원리 및 절차 흐름도

```text
  1. 공간 기하 스캔       2. SLAM 지도 구축      3. 공간 앵커 고착       4. 직관적 제어 수신     5. 오클루전 갱신
[거리/깊이 데이터 수집] ───> [6DoF 위치 추정] ───> [특정 좌표 매핑] ───> [시선/제스처 매핑] ───> [실시간 그래픽 투영]
```

1. **공간 기하 스캔**: 사용자가 단말을 착용하면 내부 라이다(LiDAR)와 뎁스 카메라가 주변 벽체와 가구의 깊이 정보를 스캔함
2. **SLAM 지도 구축**: 기기의 이동 각도와 센서 특징점을 융합하여 실시간 공간 지도를 형성하고 단말의 실시간 위치를 추정함
3. **공간 앵커 고착**: 사용자가 지정한 위치에 가상 오브젝트 좌표를 연계하여, 기기가 이동하더라도 정보가 그 자리에 흔들림 없이 고정되도록 처리함
4. **직관적 제어 수신**: 사용자가 시선으로 가상 객체를 바라보고 손끝을 맞부딪히는(Pinch) 제스처를 취하면 센서가 이를 식별해 상호작용을 실행함
5. **오클루전 갱신**: 사용자 위치 변화에 맞춰 실제 사물과 가상 오브젝트의 전후방 가림 처리를 실시간으로 다시 계산하여 렌더링을 최종 투영함

### 쉽게 이해하기 (학습용)
- 센서로 방구조 지도를 그린 뒤, 내 눈앞 테이블 모퉁이에 디지털 메모지를 붙여두고, 이를 쳐다보며 손가락을 튕겨 메모를 열면, 내 움직임에 맞춰 기둥 뒤에 숨는 그래픽까지 계속 다시 렌더링하는 절차임

## Ⅵ. 실무 사례

1. **항공기 동체 정비 지원**: 정비사가 조립 배선 부품을 볼 때 복잡한 정비 매뉴얼을 수작업으로 찾지 않고, 공간 컴퓨팅 글래스를 통해 실제 항공기 배선 위에 실시간 흐름 가이드라인과 주의점을 고정해 조립 실수 방지를 지원함
2. **배관 설비 사전 검토**: 플랜트 공장 건설 시 복잡한 가상 배관 설비 3D 모델을 실제 콘크리트 현장 구조물 벽체에 정밀 오클루전을 포함해 투영함으로써 설계 간섭 여부를 시공 전에 판정함

### 쉽게 이해하기 (학습용)
- 비행기 정비사가 수많은 전선 뭉치를 볼 때 연결할 배선을 안경 너머 화살표로 바로 확인하거나, 공장 건물을 짓기 전 가상 배관을 실제 방 벽에 미리 배치해 보고 간섭을 검사하는 경우임

## Ⅶ. 결론

- 공간 컴퓨팅은 인간의 생활 무대인 현실 공간 전체를 정보 입력과 연산 영역으로 통합해 물리적 현실과 디지털 정보의 괴리를 완전히 제거하는 핵심 HCI 진화 방향임
- 실무 도입 시 사용자의 피로와 작업 오류를 방지하기 위해 센서 누적으로 발생하는 고정 앵커의 위치 드리프트 오차를 보정하고, 장치 배터리 발열과 클라이언트 연산량 부하를 낮추는 시스템 경량화 기술이 선결되어야 함

### 쉽게 이해하기 (학습용)
- 가상 세상과 실제 내 삶의 영역을 자연스럽게 묶어주는 혁신적 인터페이스이며, 앞으로 오차가 쌓여 3D 글자가 공중에서 떨리는 현상을 잡는 정밀 보정 기술이 성공을 이끌 것임
