## 미리 알고가기

- 공간 컴퓨팅은 화면 안 정보가 아니라 사용자의 실제 공간과 사물과 위치를 계산 대상으로 삼는 방식임
- XR 기기가 대표 단말이지만 로봇과 차량과 산업 장비처럼 공간을 인식하는 시스템 전반으로 확장됨
- 센서 정확도와 공간 맵 품질과 지연 시간이 실제 사용성을 결정함

## Ⅰ. 개요

- **정의/개념**: Spatial Computing은 카메라와 깊이 센서와 위치 추정 기술로 주변 공간과 사물과 사용자 움직임을 인식하고 그 위에 디지털 정보와 상호작용을 배치하는 공간 인지형 컴퓨팅 방식임
- **배경/필요성**: 2차원 화면 중심 인터페이스는 현장 작업과 설계 검토와 길 안내처럼 공간 맥락이 중요한 업무를 충분히 지원하기 어려워 실제 환경을 이해하고 반응하는 인터페이스가 필요함

## Ⅱ. 특징

- 시스템이 공간 구조와 사용자 위치를 계속 추정하므로 정보 표시가 실제 작업 위치와 연결됨
- 시선과 손동작과 음성 같은 다중 입력을 함께 다뤄 키보드와 터치가 어려운 현장에 유리함
- 물체 인식과 공간 고정과 가림 처리 품질이 사용자의 신뢰와 안전에 직접 영향을 줌
- 센서 오차와 맵 드리프트가 누적되면 잘못된 위치에 정보를 배치해 작업 오류를 유발할 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | 2D 화면 인터페이스 | 일반 XR 체험 | 공간 컴퓨팅 |
|:---|:---|:---|:---|
| 맥락 인식 | 낮음 | 제한적 | 실제 공간을 지속 인식함 |
| 상호작용 | 터치와 키보드 중심 | 기기별 제스처와 컨트롤러 | 시선과 손동작과 음성을 통합함 |
| 활용 초점 | 정보 조회와 입력 | 몰입형 경험 | 공간 기반 작업과 안내 |
| 대표 한계 | 현장 맥락 반영이 약함 | 경험 중심으로 끝날 수 있음 | 센서 정밀도와 안전 검토가 필요함 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Spatial Sensing | 카메라와 LiDAR와 IMU가 공간 형태와 움직임을 수집하는 입력 계층으로 정확도와 샘플링 품질이 핵심임 |
| Localization and Mapping | 사용자 위치와 공간 지도를 계산해 디지털 객체를 어디에 둘지 정하는 기준 계층으로 드리프트 관리가 중요함 |
| Anchoring and Scene Model | 디지털 정보를 실제 좌표에 고정하고 가림 관계를 반영하는 장면 계층으로 작업 지시 정확도와 연결됨 |
| Interaction Engine | 시선과 손동작과 음성 입력을 해석해 명령으로 바꾸는 제어 계층으로 오인식이 사용자 부담을 키울 수 있음 |
| Rendering Device | 헤드셋과 차량 디스플레이와 산업 단말이 결과를 보여주는 출력 계층으로 시야각과 지연이 경험 품질을 좌우함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
| 공간 스캔      | -> | 위치 추정      | -> | 객체 고정      | -> | 사용자 상호작용 | -> | 장면 갱신      |
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
```

1. **공간 스캔**: 센서가 벽과 장비와 바닥 같은 주변 정보를 수집함
2. **위치 추정**: 시스템이 사용자 자세와 공간 지도를 계산함
3. **객체 고정**: 디지털 안내와 모델을 실제 공간 좌표에 배치함
4. **사용자 상호작용**: 시선과 손동작과 음성으로 객체를 조작함
5. **장면 갱신**: 움직임과 환경 변화를 반영해 화면을 다시 계산함

## Ⅵ. 실무 적용 및 유의점

1. 설비 점검과 작업 안내는 공간 컴퓨팅으로 절차 오류를 줄이기 좋지만 앵커 드리프트와 가림 처리 오류가 누적되면 현장 지시가 빗나가므로 공간 재보정과 안전 구역 정책을 함께 두고 작업 완료율과 위치 오차와 경고 발생률로 확인함
2. 설계 검토와 매장 배치 시뮬레이션은 실제 크기와 동선을 미리 확인하기 좋지만 단말 시야각과 렌더링 지연이 낮으면 판단이 왜곡될 수 있으므로 대표 단말 기준 모델 경량화와 장면 단순화를 적용하고 평균 프레임률과 사용자 수정 횟수로 확인함

## Ⅶ. 결론

- 공간 컴퓨팅은 실제 공간 맥락이 의사결정과 작업 정확도를 좌우하는 업무에 적합하며 센서 정밀도와 앵커 안정성과 지연 관리가 도입 판단의 핵심임
