# 📖 【암기용】 개념 완전 이해

> 목적: QKD를 처음 봐도 완벽히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 빛의 최소 단위인 광자에 정보를 실어 보내, 중간에 누군가 엿보려 하면 즉시 들키게 설계된 궁극의 보안 통신 기술
- **왜 필요한가**: 수학적 암호(PQC 등)는 언젠가 더 강력한 컴퓨터가 나오면 뚫릴 수도 있지만, QKD는 '물리 법칙(양자역학)'에 기반하므로 우주가 망하지 않는 한 도청이 불가능하기 때문
- **핵심 직관**: "엿보면 깨지는 유리병 편지" — 편지를 훔쳐보려고 뚜껑을 여는 순간 편지 내용이 사라지거나 변해버려서, 도청자가 있었다는 사실을 100% 알 수 있게 됨

## 깊이 이해
- **배경·문제의식**: 기존 암호는 '수학적 계산이 오래 걸린다'는 점에 의존함. 하지만 양자컴퓨터의 등장으로 이 계산이 빨라지자, 아예 물리적으로 도청이 불가능한 방식이 필요해짐.
- **작동 원리**: ① **불확정성 원리** — 양자의 상태(편광 등)를 측정하면 그 상태가 변함. ② **복제 불가능 원리** — 양자 상태는 똑같이 복사할 수 없음. 이 두 원리를 이용해, 송신자(Alice)와 수신자(Bob)가 비밀키를 나누어 가짐. 만약 도청자(Eve)가 중간에 광자를 측정하면 Bob이 받는 광자의 상태가 변하므로, 둘은 즉시 도청을 감지하고 그 키를 버림.
- **비유**: 비눗방울에 글씨를 써서 보내는 것과 같음. 중간에 누가 그 글씨를 읽으려고 비눗방울을 건드리면 터져버림. Bob이 터진 비눗방울을 받으면 "누가 훔쳐봤구나!"라고 알 수 있음.
- **구체 예시**: SKT나 KT 등 통신사들이 국가 기간망, 은행 데이터 센터 간의 전용선에 설치하여 운영 중임. 최근에는 위성을 이용해 아주 먼 거리(대륙 간)까지 키를 보내는 실험도 성공함.
- **흔한 오해·주의점**: QKD가 '데이터 자체'를 양자로 보내는 것은 아님. 데이터를 암호화할 때 쓰는 '비밀키'만 양자로 안전하게 전달하고, 실제 데이터는 기존 광케이블로 암호화해서 보냄. 또한 별도의 전용 장비와 광섬유가 필요해 구축 비용이 비쌈.

## 연결 개념
- BB84 프로토콜 — 가장 대표적인 초기 양자키분배 알고리즘
- Entanglement (양자 얽힘) — 더 진화된 방식의 QKD(Ekert91 등)에서 활용하는 현상
- Quantum Repeater (양자 중계기) — 거리에 따른 신호 감쇄를 극복하기 위한 장치

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.
> 핵심: 양자역학적 물리 법칙(불확정성, 복제불가)에 기반한 도청 탐지 메커니즘과 통신 아키텍처를 기술한다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 양자역학의 물리적 특성(불확정성 원리, 복제 불가능 원리)을 이용하여 송·수신자 간에 비밀키를 안전하게 생성하고 분배하는 보안 통신 기술이다.
> 2. **가치**: 도청 시도 시 양자 상태가 변하는 중첩 붕괴 현상을 통해 100% 도청 감지가 가능하며, 수학적 난제가 아닌 물리 법칙에 근거한 절대 보안을 제공한다.
> 3. **판단 포인트**: 전용 양자 채널 구축 비용과 통신 거리의 한계(신호 감쇄), 그리고 신뢰 노드(Trusted Node) 확보 여부가 시스템 구축의 핵심이다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| QKD의 보안 근거 이해 확인 | 불확정성 원리, 복제 불가능 원리(No-cloning) | 일반 암호와 같이 수학적 난제로 설명 |
| 주요 프로토콜 및 절차 파악 | BB84, 양자 채널 vs 고전 채널, 키 증류 | 데이터 자체를 양자로 보낸다고 서술 |
| PQC와의 차별점 및 기술적 한계 인식 | 하드웨어 기반, 거리 제한, 중계기 필요성 | PQC와 경쟁 관계가 아닌 상호 보완성 간과 |

> 요약: QKD는 물리적 '도청 인지' 능력을 가진 하드웨어 기반의 키 분배 체계다.

## Ⅰ. 개요 및 필요성

- 정의: 단일 광자의 양자 상태(편광, 위상 등)에 정보를 실어 보내, 도청 시도의 물리적 흔적을 감지함으로써 절대 보안 암호키를 공유하는 기술
- 배경: 양자 컴퓨터 발전에 따른 기존 공개키 암호(PKI)의 취약성 대두 및 국가 기밀 보호를 위한 영구적 보안성(Everlasting Security) 요구
- 필요성: 도청이 불가능한 정보 전달 경로 확보, 전력/금융 등 국가 핵심 인프라 보안 강화, 양자 정보 통신망의 기초 인프라 구축

## Ⅱ. 구조 및 구성요소

```text
[ Alice (송신) ] --(Quantum Channel : 광자)---> [ Bob (수신) ]
       |                                          |
[ Key Management ] <---(Public Channel)-----> [ Key Management ]
       |                                          |
       +------------------------------------------+
       |                                          |
[ Encryption Device ] <---(Encrypted Data)---> [ Decryption Device ]
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Quantum Channel | 단일 광자(Single Photon)를 전송하는 경로 | 전용 광섬유 또는 자유 공간(위성) |
| Public Channel | 양자 측정 결과 비교 및 키 보정을 위한 일반 통신 | 도청되어도 보안 영향 없음 |
| QKD Transmitter | 특정 편광/위상 상태의 광자를 생성하여 발사 | 하드웨어 기반 난수 생성기 연동 |
| QKD Receiver | 수신된 광자의 양자 상태를 측정하고 결과 저장 | 단일 광자 검출기(SPD) 필요 |
| Key Manager (KMS) | 생성된 로우 키를 가공하여 최종 암호키 저장/공급 | 키 증류 및 인증 절차 수행 |

> 요약: 양자 채널(키 생성용)과 고전 채널(키 보정 및 데이터 전송용)의 이중 구조로 운영된다.

---

## Ⅲ. 동작원리 및 흐름도 (BB84 기준)

```text
광자 발사(무작위 기저) -> 광자 측정(무작위 기저) -> 기저 비교(Public) -> 키 선별(Sifting) -> 오류 정정 및 비밀성 증폭
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 양자 상태 전송 | Alice가 0, 90, 45, 135도 등의 편광 상태 중 하나로 광자 발사 | 단일 광자원 신뢰성 |
| 2 | 양자 상태 측정 | Bob이 무작위로 기저(+, x)를 선택하여 수신된 광자 측정 | 측정 효율 및 암전류(Dark count) |
| 3 | 기저 대조 | Alice와 Bob이 사용한 기저 정보를 공개 채널로 비교 | 일치하지 않는 기저 데이터 삭제 |
| 4 | 도청 감지 | 일치하는 기저 중 일부를 대조하여 오류율(QBER) 확인 | QBER 임계치(약 11%) 초과 시 폐기 |
| 5 | 키 증류 (Distillation) | 오류 정정 및 도청자가 가질 수 있는 정보를 완전히 제거 | 최종 비밀키(Final Key) 생성 |

> 요약: 양자 상태를 무작위로 주고받은 후, 나중에 기저 정보만 맞춰보아 도청 여부를 판단하고 순수한 키만 남긴다.

## Ⅳ. 특징 (PQC vs QKD 비교)

| 구분 | 양자내성암호 (PQC) | 양자키분배 (QKD) |
|:---|:---|:---|:---|
| 보안 기반 | 수학적 복잡도 (NP-Hard 등) | 물리 법칙 (양자 역학) |
| 구현 형태 | 소프트웨어 / 알고리즘 | 하드웨어 / 전용 장비 |
| 통신 인프라 | 기존 광랜 / 무선랜 그대로 사용 | 전용 광섬유 / 전용 장비 구축 |
| 통신 거리 | 무제한 (인터넷 가능 시) | 제한적 (약 100km 내외, 중계기 필요) |
| 주요 강점 | 경제성, 호환성, 빠른 보급 | 물리적 절대 보안, 도청 즉시 감지 |

> 요약: PQC는 범용적 인프라 보호에, QKD는 핵심 기간망의 영구적 보안에 적합한 보완적 관계다.

## Ⅴ. 심화 비교 및 적용 판단

| 구분 | 점대점 (P2P) 구조 | 신뢰 노드 (Trusted Node) 구조 | 선택 기준 |
|:---|:---|:---|:---|
| 통신 거리 | 단거리 (직접 연결) | 장거리 (노드 간 연쇄 연결) | 거리에 따른 서비스 범위 |
| 보안성 | 매우 높음 | 노드 보안에 의존 (노드 탈취 리스크) | 중간 지점의 물리적 보안 확보 가능성 |
| 구축 비용 | 낮음 | 높음 (다수의 노드 장비 필요) | 예산 및 중요도 |

> 요약: 거리 한계 극복을 위해 신뢰 노드 방식을 사용하며, 향후 노드 보안 리스크가 없는 양자 중계기(Repeater)로 발전 중이다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 신호 감쇄 | 광섬유 내 광자 손실로 인한 통신 거리 제한 | 고감도 검출기, 위성 QKD, 양자 중계기 개발 | 최대 통신 거리 (km) |
| 노드 탈취 | 중간 신뢰 노드(Trusted Node) 해킹 시 키 유출 | 노드 하드웨어 보안 강화(HSM, 물리 보안) | 노드 보안 인증 등급 |
| 서비스 거부 (DoS) | 양자 채널에 강한 빛을 쏴서 통신 방해 | 가드 밴드 설정, 다중 경로 구성 | 키 생성률 (Key Rate, bps) |

> 요약: 물리적 거리 제약은 위성 및 중계기로, 노드 보안은 강력한 하드웨어 보호 체계로 대응해야 한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| QBER (오류율) | 5% 이하 유지 (임계치 11%) | 시스템 모니터링 로그 분석 |
| 비밀키 생성률 | 100kbps 이상 (거리 50km 기준) | 시간당 생성 키 비트수 측정 |
| 가동률 | 99.9% 이상 고가용성 | 시스템 업타임 체크 |

> 요약: 도입 성과는 안정적인 키 생성 속도(Key Rate)와 낮은 오류율(QBER) 유지 능력으로 평가한다.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 국가 행정망 전용선 보안: 정부 부처 간의 중요 데이터 전송로에 QKD 장비를 설치하여 도청 시도를 원천 차단하고 실시간 모니터링
2. 금융 데이터 센터 간 미러링: 백업 데이터 전송 구간에 QKD 키를 적용하여 향후 양자 컴퓨터 기반의 암호 해독 위협으로부터 고객 정보 보호
3. 위성 QKD 기반 대륙 간 통신: 지상 광섬유의 거리 한계를 넘어 저궤도 위성을 통해 해외 지사와의 초장거리 보안 통신망 구축

**결론 (2줄):**
- 기술사 판단: QKD는 보안의 '최종 병기'이며, 현재의 비용 문제를 극복하기 위한 칩 수준의 소형화(QKD on a chip)가 시장 확산의 분수령이 될 것이다
- 향후 방향: 양자 컴퓨터, 양자 센서와 연동되어 데이터의 생성부터 전송, 처리까지 모든 과정이 양자로 보호되는 '양자 인터넷' 시대로 진화할 것이다
