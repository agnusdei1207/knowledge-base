# 📖 【암기용】 개념 완전 이해

> 목적: Self-Attention을 처음 봐도 완벽히 이해하게 만든다.

## 한눈에
- **개요**: 시퀀스 내 각 토큰이 동일 시퀀스의 모든 토큰과 관련도를 계산하여 맥락을 수집하는 연산
- **왜 필요한가**: 단어의 의미는 주변 맥락에 따라 달라지므로, 모든 위치 간 관계를 한 번에 파악해야 정확한 표현을 만들 수 있음.
- **핵심 직관**: "나는 은행에 갔다"에서 "은행"이 금융인지 강둑인지를 문장 전체를 보고 결정하는 메커니즘임.

## 깊이 이해
- **배경·문제의식**: RNN은 시점별 순차 처리로 먼 위치 정보를 잃음. CNN은 고정 커널 크기만큼만 참조. Self-Attention은 모든 위치 쌍을 직접 연결하여 거리 무관하게 관계를 포착함.
- **작동 원리**: 입력 X에서 Q(Query), K(Key), V(Value) 행렬을 생성. Q·Kᵀ를 계산해 유사도 행렬을 만들고, √d_k로 스케일링 후 Softmax -> V에 가중합하여 출력을 생성함. Attention(Q,K,V) = softmax(QKᵀ/√d_k)·V.
- **비유**: 도서관에서 질문(Q)을 들고 모든 책의 제목(K)과 대조해, 관련도가 높은 책의 내용(V)을 가중 발췌하는 것.
- **구체 예시**: 8토큰 시퀀스에서 8×8 어텐션 행렬 생성, d_k=64일 때 1회 연산 FLOPs = 2·N²·d_k = 2·64·64 = 8,192.
- **흔한 오해·주의점**: Self-Attention 자체에는 순서 정보가 없음. Positional Encoding을 추가하지 않으면 "AB"와 "BA"를 구분하지 못함.

## 연결 개념
- Scaled Dot-Product Attention — Self-Attention의 구체 연산
- Multi-Head Attention — Self-Attention을 병렬 분할
- Transformer — Self-Attention 기반 아키텍처

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: Self-Attention은 시퀀스 내 모든 토큰 쌍의 관계를 병렬로 계산하여 맥락 표현을 생성하는 연산임.
> 2. **가치**: 거리 무관하게 장거리 의존성을 포착하며, Transformer·LLM의 핵심 빌딩블록임.
> 3. **판단 포인트**: O(N²) 연산·메모리 비용과 순서 정보 부재를 PE·Sparse Attention으로 보완해야 함.

---

## Ⅰ. 개요 및 필요성

- 개요: 토큰 간 관계 병렬 계산
- 배경: RNN은 순차 의존성, CNN은 고정 수용 범위 때문에 장거리 문맥 반영에 구조적 제약이 있음.
- 필요성: Q/K/V, attention score, softmax 가중합으로 모든 토큰 간 의존성을 O(N²) 기준으로 계산함.

---

## Ⅱ. 구조 및 구성요소

```text
입력 X -- -- W_Q -> Q (Query)
          -- W_K -> K (Key)      Q·Kᵀ/√d_k
          -- W_V -> V (Value)  --Softmax-> ×V -> 출력
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Query (Q) | 현재 토큰의 질의 벡터 | W_Q ∈ ℝ^(d×d_k) |
| Key (K) | 각 토큰의 색인 벡터 | Q·Kᵀ로 유사도 산출 |
| Value (V) | 각 토큰의 정보 벡터 | Softmax 가중합의 대상 |
| Scale Factor (√d_k) | 내적값 크기 정규화 | Softmax 포화 방지 |

> 요약: Q·K 내적으로 관련도를 계산하고, V에 가중합하여 맥락 벡터를 생성하는 구조임.

---

## Ⅲ. 동작원리 및 흐름도

```text
입력 X -> Q,K,V 행렬 생성 -> QKᵀ/√d_k 계산
    -> Softmax(어텐션 가중치) -> 가중합(×V) -> 출력 Z
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 입력 X를 W_Q, W_K, W_V로 선형 변환 | 차원 d_k=64~128, 파라미터 수 |
| 2 | QKᵀ 행렬곱 -> √d_k 스케일링 | N×N 어텐션 행렬, 메모리 O(N²) |
| 3 | Softmax로 확률 분포 변환 | 가중치 합=1, 포화 여부 확인 |
| 4 | 가중치×V 행렬곱 -> 출력 Z | 출력 차원 d_k, 정보 손실 여부 |

> 요약: QKᵀ/√d_k->Softmax->V 가중합의 3단계로 전체 맥락을 O(N²)에 수집함.

---

## Ⅳ. 특징

| 구분 | RNN Attention | Self-Attention | 판단 포인트 |
|:---|:---|:---|:---|
| 참조 범위 | 인코더->디코더 (Cross) | 동일 시퀀스 내 전체 | 장거리 의존 포착 여부 |
| 병렬화 | 순차 처리 | 완전 병렬 | GPU 활용률, 학습 속도 |
| 연산 복잡도 | O(N·d²) | O(N²·d) | N vs d 크기에 따라 선택 |

> 요약: Self-Attention은 병렬 처리·장거리 참조에서 우위이나, 시퀀스 길이에 따른 O(N²) 비용이 핵심 트레이드오프임.

---

## Ⅴ. 실무 적용 및 결론

**적용 방안 3개:**
1. Flash Attention 2 적용으로 O(N²) 메모리를 O(N)으로 축소, A100에서 학습 처리량 2×
2. Sparse Attention(Longformer 패턴)으로 N>8K 시퀀스의 연산량을 O(N·√N)으로 절감
3. KV Cache 양자화(INT8)로 추론 시 메모리 사용량 50% 절감, 배치 크기 2배 확보

**결론 (2줄):**
- 기술사 판단: N<8K면 Full Self-Attention, N>8K면 Sparse/Linear Attention 적용
- 향후 방향: 선형 복잡도 Attention(Mamba·RWKV)과 하이브리드 구조로 O(N²) 제약 극복 추세
