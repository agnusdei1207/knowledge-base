## Ⅰ. 개요
- **정의**: 입력 시퀀스 내 각 토큰이 동일 시퀀스의 모든 토큰과 연관도를 계산하여 자신의 표현을 동적으로 갱신하는 문맥 연산 메커니즘
- **배경/필요성**: Word2Vec 등 정적 임베딩은 '사과(果)' '사과(謝)'를 동일 벡터로 표현하여 다의어·대명사 해소가 불가능했음. 문장 전체 문맥을 참조하여 토큰 의미를 동적으로 재결정하는 메커니즘이 필요함
- **비유**: 교실 토론 — 각 학생(토큰)이 반 전체 친구(시퀀스)에게 질문(Q)을 던지고, 관련도가 높은 친구의 정보(V)를 집중 흡수하여 자기 의견을 갱신

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| Q/K/V 3벡터의 역할과 연산 흐름 | Query(질문)·Key(색인)·Value(정보)의 내적 → Softmax → 가중합 | Transformer 전체 구조(034) 반복 금지, 어텐션 연산 자체에 집중 |
| 정적 임베딩 대비 동적 문맥 표현의 차이 | 동일 단어라도 문맥에 따라 벡터값이 매번 상이 | Scaled Dot-Product 수식 상세(스케일링 이유)는 036 참조로 위임 |

> 요약: Q/K/V 내적 기반으로 토큰 간 연관도를 계산하여 문맥 의존적 동적 표현을 생성하는 핵심 메커니즘

## Ⅱ. 구성요소
```text
+-------------------------------------------------------+
|              Self-Attention Mechanism                  |
|                                                        |
|  [Input Token]--+-->[W_Q]---> Q (Query: 질문 벡터)     |
|                 |-->[W_K]---> K (Key: 색인 벡터)        |
|                 +-->[W_V]---> V (Value: 정보 벡터)      |
|                                                        |
|  Q x K^T / sqrt(d_k) --> Softmax --> Weights           |
|                                                        |
|  Weights x V --> Context Vector (문맥 반영 출력)        |
+-------------------------------------------------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| Query (Q) | 현재 토큰이 "나와 관련 있는 토큰이 누구인가?"를 묻는 질문 벡터, 학습된 가중치 행렬 W_Q로 생성 | 검색어 |
| Key (K) | 각 토큰이 보유한 색인 벡터, Q와 내적하여 유사도(연관도) 점수 산출에 사용 | 책 제목 태그 |
| Value (V) | 각 토큰이 실제 전달하는 정보 벡터, 어텐션 가중치에 비례하여 최종 출력에 기여 | 책 본문 내용 |
| Attention Weight | Q·K 내적 후 스케일링·Softmax를 거쳐 산출된 확률 분포, 각 토큰의 기여도를 결정 (스케일링 수식은 036 참조) | 투표 결과 |

> 요약: Q(질문)·K(색인)·V(정보) 3벡터의 내적과 Softmax 정규화로 문맥 가중합을 산출

## Ⅲ. 절차
```text
+----------------+     +----------------+     +----------------+     +----------------+
| 1. Q/K/V       |---->| 2. 유사도      |---->| 3. 정규화      |---->| 4. 가중합      |
|  투영(Linear)  |     |  계산(Q*K^T)   |     |  (Softmax)     |     |  (Weight*V)    |
+----------------+     +----------------+     +----------------+     +----------------+
```

1. **Q/K/V 투영** — 입력 토큰 벡터에 학습된 가중치 행렬 W_Q, W_K, W_V를 각각 곱하여 Query, Key, Value 3개의 벡터로 변환
2. **유사도 계산** — 현재 토큰의 Q와 모든 토큰의 K를 내적(Dot Product)하여 원시 유사도 점수(Raw Score) 행렬을 산출, 차원수 sqrt(d_k)로 스케일링
3. **정규화(Softmax)** — 스케일링된 점수를 Softmax에 통과시켜 합계 1.0의 확률 분포(어텐션 가중치)로 변환, 디코더에서는 미래 토큰을 -inf로 마스킹
4. **가중합(Weighted Sum)** — 산출된 가중치를 각 토큰의 V 벡터에 곱하여 합산, 문맥이 반영된 새로운 컨텍스트 벡터를 최종 출력

> 요약: Q/K/V 투영 → 내적(유사도) → Softmax(정규화) → 가중합(문맥 벡터 생성)의 4단계

## Ⅳ. 문제점
- O(N²) 메모리·연산 폭발: 시퀀스 길이 N의 모든 토큰 쌍을 계산 — N=100K일 때 10^10회 연산으로 VRAM 초과
- 위치 무관성: Self-Attention 자체는 토큰 순서를 인식하지 못함 — 별도 Positional Encoding 없이는 어순 정보 소실
- 해석 난이도: 어텐션 가중치가 모델의 실제 추론 근거와 반드시 일치하지 않음 — XAI 관점에서 신뢰도 한계

> 요약: N² 복잡도·위치 무관성·해석 불완전성이 Self-Attention의 3대 내재적 한계

## Ⅴ. 개선방안
1. 단기: Multi-Head Attention(037)으로 다관점 병렬 계산하여 단일 어텐션의 표현력 한계 극복
2. 중기: Sparse Attention(Longformer) + Sliding Window로 O(N²) → O(N·w) 복잡도 절감, 긴 문서 처리 지원
3. 장기: Linear Attention·State Space Model(Mamba)로 O(N) 선형 복잡도 달성, 무한 컨텍스트 처리 가능

- N² 복잡도: Full Attention → FlashAttention(IO 최적화) + Sparse Attention(연산량 절감) (지표: 128K 토큰 VRAM 50% 절감)
- 위치 무관성: 고정 PE → RoPE(회전 위치 임베딩)로 상대 위치 인식 강화 (지표: 외삽 길이 8배 확장)
- 해석 한계: 단순 가중치 시각화 → Attention Rollout + 기울기 기반 귀인(Attribution) 분석 병행 (지표: 설명 일치율 향상)

> 요약: Multi-Head·Sparse·Linear Attention으로 표현력·복잡도·해석성을 단계적 개선

## Ⅵ. 전망
- 향후 발전 방향: 텍스트 Self-Attention → Vision Patch Attention(ViT) → 시공간 Attention(Sora) → 모달리티 불문 범용 관계 연산 엔진으로 확장
- 기술사적 판단: Self-Attention은 Transformer(034)의 핵심 연산이자 현대 AI 전체의 근간 메커니즘이며, N² 한계 극복 여부가 컨텍스트 길이의 상한을 결정함
- 기술사 제언: 엔터프라이즈 RAG 시스템 설계 시 무제한 컨텍스트 투입이 아닌 Chunking + Retrieval로 어텐션 범위를 제어하고, 문서 길이별 어텐션 전략(Full/Sparse/Sliding Window)을 분기 설계할 것
