## 미리 알고가기

- 확산모델은 노이즈 추가와 제거의 역과정을 학습하는 생성모델임
- U-Net과 noise scheduler와 sampler가 핵심 구성임
- 이미지뿐 아니라 오디오와 비디오와 분자 생성에도 확장됨

## Ⅰ. 개요

- **정의/개념**: 확산모델은 원본 데이터에 단계적으로 노이즈를 추가하는 정방향 과정과, 노이즈 상태에서 원래 데이터 분포를 복원하도록 학습된 역방향 제거 과정을 결합해 샘플을 생성하는 확률적 생성모델임
- **배경/필요성**: GAN은 학습 붕괴와 mode collapse 문제가 컸고 VAE는 품질 한계가 있었으므로, 더 안정적으로 고품질 데이터를 생성하는 모델 구조가 필요했음

## Ⅱ. 특징

- 학습 안정성이 높고 생성 결과의 다양성이 우수함
- 반복적 denoising 덕분에 고품질 이미지 생성에 강함
- 텍스트와 이미지와 구조 조건을 결합하기 쉬워 제어 확장성이 높음
- 다단계 샘플링 때문에 추론 지연과 비용이 큰 편임

## Ⅲ. 종류 및 비교

| 판단 기준 | GAN | VAE | Diffusion Model |
|:---|:---|:---|:---|
| 학습 안정성 | 낮음 | 높음 | 높음 |
| 생성 선명도 | 높음 | 중간 | 높음 |
| 다양성 | 중간 | 중간 | 높음 |
| 추론 속도 | 빠름 | 빠름 | 느림 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Noise Scheduler | 각 단계에서 얼마만큼 노이즈를 더하고 뺄지 제어해 생성 품질과 속도에 직접 영향을 줌 |
| Forward Process | 원본 데이터에 노이즈를 점진적으로 추가해 학습용 중간 상태를 만듦 |
| Denoising Network | 현재 단계의 noisy sample에서 제거해야 할 노이즈를 예측해 역복원 핵심 역할을 수행함 |
| Sampler | 학습된 예측값을 이용해 역과정을 효율적으로 진행하며 속도와 품질 균형을 조정함 |

```text
+-------------------+      +-------------------+      +-------------------+
| Forward Process   | ---> | Denoising Net     | ---> | Sampler           |
+-------------------+      +-------------------+      +-------------------+
             ^
             |
+-------------------+
| Noise Scheduler   |
+-------------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 원본 데이터 준비 | --> | 노이즈 단계 학습 | --> | 순수 노이즈 시작 | --> | 반복 복원 생성  |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **원본 데이터 준비**: 학습 대상 이미지나 신호를 수집함
2. **노이즈 단계 학습**: 다양한 시점의 noisy sample에서 노이즈 예측기를 학습함
3. **순수 노이즈 시작**: 생성 시 무작위 노이즈에서 출발함
4. **반복 복원 생성**: sampler가 노이즈를 제거해 최종 샘플을 복원함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 수십 단계 이상의 반복 복원이 필요하면 실시간 서비스에서 지연 시간과 GPU 비용이 급격히 증가할 수 있음
   - 해결방안: DDIM과 distillation과 fast sampler를 적용하고 latency와 cost per sample로 검증함
2. 문제: 고해상도 데이터에서 픽셀 공간 연산을 직접 수행하면 메모리와 연산량이 빠르게 폭증할 수 있음
   - 해결방안: latent diffusion과 tiling 전략을 적용하고 VRAM usage와 throughput으로 검증함
3. 문제: guidance 값을 과도하게 높이면 프롬프트 충실도는 올라가도 다양성이 줄고 아티팩트가 늘어날 수 있음
   - 해결방안: guidance tuning과 human preference 평가를 병행하고 FID와 prompt adherence score로 검증함

## Ⅶ. 적용 사례

- 광고 이미지 생성이 고품질 시안을 안정적으로 만들도록 확산모델을 적용하며 확인 지표는 FID와 design approval rate임
- 신약 설계가 분자 구조 후보를 탐색하도록 확산모델을 활용하며 확인 지표는 validity rate와 novelty score임
- 자율주행 합성 데이터 생성이 희귀 장면을 증강하도록 확산모델을 운영하며 확인 지표는 scenario coverage와 downstream robustness임

## Ⅷ. 결론

확산모델은 생성 품질과 안정성을 함께 확보한 주류 생성 아키텍처이므로, 실무에서는 샘플링 가속과 고해상도 비용 통제가 핵심 선택 기준이 됨.
