## 미리 알고가기

- 딥페이크 탐지는 출처 메타데이터가 없거나 제거된 콘텐츠를 사후 분석해 합성 여부를 판정하는 기술임
- 얼굴과 음성과 주파수와 시간 일관성 같은 여러 단서를 함께 보는 다중모달 접근이 중요함
- 생성 모델이 빨리 진화하므로 단일 탐지 모델에 대한 장기 신뢰는 위험함

## Ⅰ. 개요

- **정의/개념**: Deepfake Detection은 생성형 AI로 합성되거나 조작된 이미지와 영상과 음성을 분석해 픽셀 아티팩트와 생체 신호와 시간 일관성의 이상을 찾아 위변조 가능성을 판정하는 탐지 기술임
- **배경/필요성**: 선거 개입과 금융 사기와 비대면 신원 도용이 늘면서 콘텐츠 자체를 사후 감별하는 기술이 신원확인과 미디어 검증의 필수 통제 수단이 됨

## Ⅱ. 특징

- 출처 정보가 없는 파일에도 적용할 수 있다는 점이 강점임
- 미지의 생성기나 강한 후처리에는 성능이 급격히 떨어질 수 있음
- 이미지와 영상과 음성을 함께 분석할수록 일반화 성능이 개선됨
- 탐지 결과는 확률값이므로 임계치 정책과 후속 검토 절차가 중요함

## Ⅲ. 종류 및 비교

| 판단 기준 | Deepfake Detection | Content Credentials | Liveness Detection |
|:---|:---|:---|:---|
| 접근 시점 | 사후 판별 | 생성 및 편집 이력 확인 | 인증 시 실시간 반응 확인 |
| 핵심 근거 | 아티팩트와 패턴 분석 | 서명과 메타데이터 | 사용자 행동과 생체 반응 |
| 강점 | 메타데이터 없는 파일도 분석 가능 | 명확한 출처 설명 가능 | 계정 개설과 인증에 강함 |
| 한계 | 오탐과 미탐 존재 | 스트리핑 취약 | 녹화 재생 우회 가능 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Media Preprocessor | 얼굴 분리와 오디오 추출과 프레임 정규화를 수행해 탐지기 입력 품질을 맞추는 전처리 계층임 |
| Spatial Detector | 픽셀 왜곡과 경계 아티팩트와 조명 부조화를 분석해 합성 흔적을 찾는 모델임 |
| Temporal or Audio Detector | 프레임 간 움직임과 음성 위상과 생체 리듬을 분석해 시간적 부자연스러움을 탐지함 |
| Score Fusion Engine | 여러 탐지기 출력을 결합해 최종 위변조 확률과 위험 등급을 산출하는 판단 모듈임 |
| Review Workflow | 고위험 판정 결과를 사람 검토나 추가 인증으로 연결해 오탐 피해를 줄이는 운영 계층임 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
| 미디어 수집  | -> | 특징 추출    | -> | 다중 탐지    | -> | 점수 융합    | -> | 차단 또는 검토 |
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
```

1. **미디어 수집**: 업로드 파일이나 인증 영상이나 음성 스트림을 입력받음
2. **특징 추출**: 프레임과 얼굴과 스펙트럼과 움직임 특징을 계산함
3. **다중 탐지**: 공간과 시간과 음성 탐지 모델을 병렬 적용함
4. **점수 융합**: 각 탐지기의 결과를 종합해 위험 점수를 만듦
5. **차단 또는 검토**: 정책 임계치에 따라 차단이나 추가 인증이나 수동 검토를 수행함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 새로 등장한 생성 모델과 후처리 기법에 대해 탐지기가 학습되지 않으면 실제 현장에서 미탐이 급격히 늘 수 있음
   - 해결방안: continuous retraining과 unseen benchmark evaluation을 적용하고 unseen attack recall과 model refresh lead time으로 검증함
2. 문제: 단일 영상 특징만 보면 품질 저하나 조명 변화 같은 정상 조건도 딥페이크로 오인할 수 있음
   - 해결방안: multimodal ensemble과 context aware thresholding을 적용하고 false positive rate와 reviewer overturn rate로 검증함
3. 문제: 탐지 결과를 즉시 차단에만 연결하면 정상 사용자 인증 실패와 서비스 마찰이 커질 수 있음
   - 해결방안: step up verification과 human review fallback을 적용하고 user friction score와 secondary verification success rate로 검증함

## Ⅶ. 적용 사례

- 비대면 계좌 개설 시스템이 영상과 음성 딥페이크 탐지를 병행하며 확인 지표는 unseen attack recall과 false positive rate임
- 뉴스 플랫폼이 업로드 영상에 다중모달 탐지를 적용하며 확인 지표는 reviewer overturn rate와 suspicious media escalation rate임
- 콜센터 보안 시스템이 음성 위조 탐지와 추가 본인확인을 연계하며 확인 지표는 spoof detection precision과 secondary verification success rate임

## Ⅷ. 결론

딥페이크 탐지는 메타데이터가 없는 환경에서 필요한 최후 방어선이지만 확률 기반 기술이므로 지속 재학습과 다중 검증 절차를 함께 운영해야 함.
