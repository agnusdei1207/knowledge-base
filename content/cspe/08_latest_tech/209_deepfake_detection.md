# 📖 【암기용】 개념 완전 이해

> 목적: Deepfake Detection을 처음 봐도 완벽히 이해하게 만든다.

## 한눈에
- **개요**: AI로 합성·조작된 이미지, 영상, 음성을 분석해 위변조 여부와 신뢰도를 판별하는 기술
- **왜 필요한가**: 선거, 금융사기, 명예훼손, 보이스피싱, 허위뉴스에서 합성 미디어가 증거와 신뢰를 훼손함.
- **핵심 직관**: 사람 눈에는 자연스러운 영상이라도 픽셀·주파수·생체 패턴의 어색한 흔적을 찾는 검사임.

## 깊이 이해
- **배경·문제의식**: 생성 모델이 고도화되면서 육안 검증은 한계가 있으며, 음성·얼굴·입모양 합성은 실시간 사기에 악용됨.
- **작동 원리**: 얼굴 랜드마크, 깜박임, 주파수 노이즈, 압축 흔적, 음성 스펙트럼, 생체 일관성을 모델로 분석하고 확률 점수를 산출함.
- **비유**: 위조지폐 감별기가 종이 질감, 잉크 반응, 숨은 무늬를 함께 검사하는 방식임.
- **구체 예시**: 화상회의 인증에서 얼굴 합성 탐지와 liveness detection을 결합해 replay·face swap 공격을 차단함.
- **흔한 오해·주의점**: 탐지 모델은 생성 모델과 경쟁 관계라 drift가 크다. 원본 출처 증명, 워터마킹, 사용자 신고를 함께 운영해야 함.

## 연결 개념
- AI Watermarking — 생성 단계 식별 신호
- Content Credentials — 출처·편집 이력 증명
- Liveness Detection — 생체 인증의 실시간 위조 방어

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: Deepfake Detection은 합성 미디어의 시각·음성·생체 흔적을 분석해 조작 가능성을 판정하는 기술임.
> 2. **가치**: 금융사기, 허위정보, 신원사칭, 증거 조작 위험을 줄이는 신뢰 검증 수단임.
> 3. **판단 포인트**: 탐지 정확도, 오탐률, 생성 모델 변화, provenance 보완을 함께 관리해야 함.

## Ⅰ. 개요 및 필요성

Deepfake Detection은 합성 미디어 탐지 기술이다. AI 기반 얼굴·음성 조작은 사회적 신뢰와 인증 체계를 위협한다. 탐지 모델과 출처 증명을 결합해 대응해야 한다.

## Ⅱ. 구조 및 구성요소

```text
Media Input → Feature Extraction → Detection Model
  → Confidence Score → Review/Action
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Media Input | 이미지·영상·음성 | 압축·재인코딩 영향 |
| Feature | 랜드마크·주파수·음성 특징 | multimodal |
| Detector | 합성 여부 판정 | CNN/Transformer |
| Review | 점수 기반 조치 | human review |

> 요약: 딥페이크 탐지는 미디어 특징을 추출하고 모델 점수와 사람 검토로 조작 가능성을 판단함.

## Ⅲ. 동작원리 및 흐름도

```text
콘텐츠 수집 → 전처리·특징 추출 → 탐지 점수 산출
  → 임계값 판단 → 차단·검토·표시
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 이미지·음성·영상 전처리 | 포맷 정규화 |
| 2 | 얼굴·주파수·음성 특징 추출 | multimodal feature |
| 3 | 탐지 모델 score 산출 | AUC ≥0.95 목표 |
| 4 | 임계값별 조치·검토 | FPR ≤1% 목표 |

> 요약: Deepfake Detection은 탐지 점수와 임계값을 기준으로 차단, 경고, 사람 검토를 분기함.

## Ⅳ. 특징

| 구분 | Content Credentials | Deepfake Detection | 판단 포인트 |
|:---|:---|:---|:---|
| 방식 | 출처·이력 검증 | 콘텐츠 특징 분석 | 사후 판정 |
| 대상 | metadata 포함 콘텐츠 | 출처 없는 콘텐츠 가능 | 커버리지 |
| 한계 | metadata 제거 | 생성 모델 변화·오탐 | 재학습 필요 |
| 보완 | 서명·manifest | 워터마크·신고·리뷰 | 다층 검증 |

> 요약: 딥페이크 탐지는 출처 정보가 없는 콘텐츠에도 적용되지만 오탐과 drift를 지속 관리해야 함.

## Ⅴ. 실무 적용 및 결론

**적용 방안 3개:**
1. 금융 인증: 영상 KYC에 liveness detection, face swap 탐지, 음성 합성 탐지를 결합하고 FPR 1% 이하 기준 적용
2. 플랫폼 운영: 업로드 콘텐츠에 탐지 score를 부여하고 0.8 이상은 라벨링·검토 큐로 자동 전환
3. 신뢰 보강: C2PA manifest와 AI watermark를 우선 검증하고 부재 시 딥페이크 탐지와 사용자 신고를 병행

**결론 (2줄):**
- 기술사 판단: 딥페이크 대응은 탐지 모델 단독보다 provenance, 워터마킹, 사람 검토를 결합한 다층 구조로 설계
- 향후 방향: Deepfake Detection은 실시간 인증, 선거·언론 검증, 합성 미디어 표시 정책과 통합됨
