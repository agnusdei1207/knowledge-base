## 미리 알고가기

- HBM은 메모리 칩을 수직 적층하고 넓은 인터페이스로 연결해 매우 높은 대역폭을 제공하는 고성능 메모리 기술임
- AI 가속기에서는 연산 코어보다 메모리 공급 속도가 병목이 되기 쉬워 HBM의 중요성이 매우 큼
- 대역폭은 뛰어나지만 비용과 발열과 패키징 복잡도가 함께 증가함

## Ⅰ. 개요

- **정의/개념**: HBM은 여러 DRAM 다이를 수직 적층하고 TSV와 인터포저 기술로 프로세서와 근접 연결하여 높은 메모리 대역폭과 짧은 신호 경로를 제공하는 차세대 고대역폭 메모리 구조임
- **배경/필요성**: 대규모 AI 모델과 그래픽 워크로드는 연산 코어가 많아도 메모리 공급 속도가 느리면 성능이 제한되므로 고대역폭 메모리 수요가 급증함

## Ⅱ. 특징

- 넓은 인터페이스와 짧은 배선으로 높은 메모리 대역폭을 제공함
- 적층 구조 덕분에 패키지 면적 효율이 높음
- 전통적 DDR보다 지연과 구조가 다르며 주로 가속기 근접 메모리로 쓰임
- 제조 난이도와 발열과 수율 관리가 도입 비용에 큰 영향을 줌

## Ⅲ. 종류 및 비교

| 판단 기준 | HBM | GDDR | DDR |
|:---|:---|:---|:---|
| 대역폭 | 매우 높음 | 높음 | 중간 |
| 배치 위치 | 가속기 근접 패키지 | 그래픽 카드 보드 상 | 일반 시스템 메모리 |
| 패키징 복잡도 | 매우 높음 | 중간 | 낮음 |
| 대표 용도 | AI 가속기, HPC | GPU 그래픽 메모리 | 범용 서버와 PC |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Stacked DRAM Dies | 여러 메모리 다이를 수직으로 쌓아 높은 집적도와 넓은 병렬 채널을 구현하는 적층 메모리 블록임 |
| TSV | 적층된 다이 사이를 수직으로 연결해 고속 신호 전달을 가능하게 하는 관통 전극 구조임 |
| Interposer or Advanced Package | 가속기와 HBM 스택을 초근거리로 연결해 넓은 버스와 낮은 신호 손실을 제공하는 패키징 기반임 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
| 데이터 요청   | -> | 컨트롤러 분배 | -> | HBM 채널 접근 | -> | 적층 다이 응답 | -> | 가속기 공급    |
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
```

1. **데이터 요청**: 가속기가 파라미터나 activation 데이터를 요청함
2. **컨트롤러 분배**: 메모리 컨트롤러가 요청을 채널에 배분함
3. **HBM 채널 접근**: 넓은 인터페이스로 병렬 접근을 수행함
4. **적층 다이 응답**: TSV 경로를 통해 데이터가 전달됨
5. **가속기 공급**: 연산 코어에 고속으로 데이터를 공급함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 적층과 패키징 복잡도가 높아 제조 수율과 원가 부담이 커질 수 있음
   - 해결방안: advanced packaging yield management를 적용하고 package yield rate와 memory cost per GB로 검증함
2. 문제: 고대역폭 동작과 밀집 배치로 발열이 커지면 메모리 안정성과 전체 가속기 성능이 흔들릴 수 있음
   - 해결방안: thermal aware placement와 cooling optimization을 적용하고 HBM thermal headroom과 throttling incidence로 검증함
3. 문제: 용량 확대와 확장성이 제한되면 초대형 모델에서 메모리 부족이 새로운 병목이 될 수 있음
   - 해결방안: memory tiering과 parameter offloading을 적용하고 memory overflow incident rate와 effective bandwidth utilization으로 검증함

## Ⅶ. 적용 사례

- 대형 AI 가속기가 고급 패키징 수율 관리를 수행하며 확인 지표는 package yield rate와 memory cost per GB임
- 데이터센터 GPU 서버가 HBM 열 설계를 최적화하며 확인 지표는 HBM thermal headroom과 throttling incidence임
- 초대형 모델 학습 시스템이 메모리 티어링을 적용하며 확인 지표는 memory overflow incident rate와 effective bandwidth utilization임

## Ⅷ. 결론

HBM은 AI 가속기의 실효 성능을 결정하는 핵심 메모리 기술이므로 대역폭 확보와 함께 패키징 수율과 열 설계를 동시에 고려해야 함.
