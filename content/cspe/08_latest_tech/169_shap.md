# 📖 【암기용】 개념 완전 이해

## 한눈에
- **정의**: '협조적 게임 이론(Cooperative Game Theory)'을 노벨 경제학상을 받은 '샤플리 값(Shapley Value)'을 이용해, AI 예측 결과에 각 특징(Feature, 변수)들이 "정확히 얼마만큼 기여했는지" 공평하게 점수를 나누어 주는 가장 엄밀한 XAI 기법.
- **필요성**: 기존 모델 설명 기법들은 "대충 이 변수가 중요하다"고 방향성만 알려줬음. 하지만 금융/의료 쪽에선 "이 고객 대출 한도가 왜 깎였어?"라고 물을 때, "A 변수 때문에 -500만 원, B 변수 때문에 +100만 원"처럼 딱 떨어지는 정확한 덧셈 산식(기여도)을 원함. SHAP이 이를 완벽히 해결함.
- **핵심 직관**: 팀 프로젝트 기여도 평가. 3명(A, B, C 변수)이 조별 과제를 해서 100점을 받음. 기본 점수가 60점이라면 나머지 40점을 누가 만들었나? A 혼자 했을 때, A+B가 했을 때 등 모든 조합의 경우의 수를 따져서 "A가 15점, B가 20점, C가 5점을 기여했다"고 완벽하게 공평하게 분배하는 수학적 마법.

## 깊이 이해
- **배경**: 샤플리 값은 1950년대에 나온 고전 경제학 이론이나, 모든 변수 조합의 경우의 수($2^N$)를 다 계산해야 해서 연산량이 폭발함. 이를 해결하기 위해 2017년 논문에서 Tree 모델(XGBoost 등)에 특화된 고속 알고리즘(TreeSHAP) 등을 제안하며 XAI의 절대 표준으로 자리 잡음.
- **작동 원리 (한계 기여도 조합 계산)**:
  1. 집값 예측 AI. 결과가 10억이 나옴 (평균 집값은 8억). 즉 2억 원의 추가 가치를 누가 만들었나?
  2. 변수 3개(방 개수, 역세권, 층수). 역세권 변수가 포함된 팀 조합(방+역세권, 층수+역세권 등)과 역세권 변수가 빠진 조합의 집값 예측치 차이(한계 기여도, Marginal Contribution)를 계산함.
  3. 모든 조합에서의 차이값을 가중 평균 내면, '역세권' 변수만의 순수 SHAP Value(예: +1.5억 원)가 도출됨.
  4. 모든 변수의 SHAP 값을 다 더하면 반드시 (최종 예측치 - 평균치)와 일치함 **(가산성 원리)**.
- **구체 예시**: SHAP Force Plot. 심사 결과 화면에 "기본 점수 600점. [연봉 $5,000 $\rightarrow$ +50점 (빨간색 화살표 밀기)], [연체 3건 $\rightarrow$ -40점 (파란색 화살표 밀기)] = 최종 610점"이라고 직관적인 막대기 밀기 그래프로 시각화해 줌.
- **흔한 오해/주의점**: "SHAP이 LIME보다 무조건 짱이네?" $\rightarrow$ 이론적으론 완벽하지만 엄청난 단점이 있음. 변수가 100개면 $2^{100}$번의 연산이 필요함. 딥러닝 블랙박스에 대고 순수 SHAP을 돌리면 계산이 너무 오래 걸려 실시간 서비스가 불가능함. (그래서 트리에 특화된 TreeSHAP이나 샘플링을 쓰는 KernelSHAP으로 타협함).

## 연결 개념
- **XAI (설명 가능한 AI)**: 블랙박스를 열어보는 기술 분야 전체. SHAP은 현재 이 분야의 왕(King)임.
- **LIME**: SHAP의 라이벌. 빠르고 가볍게 "대충 이 주변은 이렇다"고 설명하지만, 매번 결과가 흔들릴 수 있는 국소 근사법.
- **XGBoost, LightGBM (트리 앙상블)**: 딥러닝을 제외한 정형 데이터 분야 최강자들. 이 트리 모델들과 SHAP(TreeSHAP)이 결합할 때 연산 속도가 비약적으로 올라 가장 완벽한 시너지를 냄.

# 📝 【답안용】 시험 답안 템플릿
## 핵심 인사이트 (3줄 요약)
- **본질**: 협조적 게임 이론(Cooperative Game Theory)의 샤플리 값(Shapley Value)을 기반으로, AI 모델의 예측 결과(목표값)와 베이스라인(Base-value) 간의 차이를 각 피처(Feature)의 고유한 한계 기여도(Marginal Contribution)의 합으로 정확히 분해하여 설명하는 XAI 기법.
- **가치**: 설명 모델이 반드시 갖춰야 할 수학적 공리인 국소적 정확성(가산성), 결측성(Missingness), 일관성(Consistency)을 모두 완벽하게 만족하는 유일한 설명 기법으로, 금융/의료 등 강력한 규제 컴플라이언스 입증이 필요한 환경에서 최상위 설명 근거로 채택됨.
- **판단 포인트**: 연산 복잡도가 변수 개수 $N$에 대해 $O(2^N)$으로 기하급수적으로 폭발하므로, 딥러닝에는 KernelSHAP(몬테카를로 근사)이나 DeepSHAP을, 비즈니스 정형 데이터에는 TreeSHAP(다항 시간 내 연산 최적화)을 선택 적용하는 아키텍처 최적화가 필수적임.

## Ⅰ. 개요 및 필요성
- **정의**: 개별 피처(변수)들이 연합(Coalition)하여 예측 결과라는 '이득(Payoff)'을 창출했을 때, 각 피처가 기여한 바를 공정하게 수치화(SHAP Value)하여 개별 예측의 이유(Local)와 모델 전체의 특징(Global)을 동시에 시각화하는 방법론. (2017년 Lundberg & Lee).
- **배경**: 기존 트리 기반의 Feature Importance 지표(Gini Impurity 등)나 LIME과 같은 대리 모델 기법들은 '일관성(Consistency)' 공리를 위반함. 특정 변수의 실제 중요도가 커졌음에도 불구하고 지표가 오히려 감소하는 논리적 모순이 발생하여 감사 대응에 치명적이었음.
- **필요성**: 예측된 수치(Prediction)가 정확히 어떤 변수들의 덧셈과 뺄셈 연산으로 도출되었는지(Additivity)를 투명하게 증명하여, 고위험(High-Risk) AI의 알고리즘 편향성 검증 및 고객 설명 의무를 준수하기 위함.

## Ⅱ. SHAP의 수학적 뼈대: 샤플리 값 (Shapley Value)
게임 이론에서 각 플레이어(변수)의 공정한 보상 분배 공식.
- **수식**:
  $$\phi_i = \sum_{S \subseteq F \setminus \{i\}} \frac{|S|! (|F| - |S| - 1)!}{|F|!} \left[ f_x(S \cup \{i\}) - f_x(S) \right]$$
- **의미 해설**:
  - $F$: 전체 변수 집합.
  - $S$: 변수 $i$를 제외한 특정 변수 조합(부분집합).
  - $f_x(S \cup \{i\}) - f_x(S)$: 특정 변수 조합 $S$가 있을 때, 변수 $i$가 **추가로 투입되면서 발생한 예측값의 변화량 (한계 기여도, Marginal Contribution)**.
  - 앞에 붙은 팩토리얼(Fraction) 식: 모든 가능한 변수 조합의 순열(가중치) 비율을 계산하여 평균을 냄.
- **결론**: 변수 $i$가 다른 모든 변수들과 어떻게 섞이더라도 만들어내는 기여도의 평균을 구하는 완벽하게 공정한 수식.

## Ⅲ. SHAP이 보장하는 3가지 핵심 공리 (Axioms)
LIME 등 다른 기법과 SHAP을 구분 짓는 수학적 엄밀성의 증거.
1. **국소적 정확성 (Local Accuracy / Additivity)**:
   - 예측값 $f(x)$ = 기준값(Base Value, 평균) + 모든 변수들의 SHAP Value의 합($\sum \phi_i$).
   - 즉, 기여도를 다 더하면 결과값이 딱 맞아떨어져 직관적 해석이 가능함. (가산성).
2. **결측성 (Missingness)**:
   - 입력 데이터에서 결측치(Missing Feature)인 변수는 그 기여도(SHAP Value)가 무조건 0으로 평가됨.
3. **일관성 (Consistency)**:
   - 모델이 바뀌어서 특정 변수 $A$의 의존성이나 파급 효과가 실제로 더 커졌다면, 그 변수 $A$의 SHAP Value 지표도 반드시 증가하거나 최소한 같아야 함. (기존 트리 모델의 불순도 기반 중요도는 이 일관성이 깨지는 버그가 있었음).

## Ⅳ. SHAP의 핵심 시각화 도구 (Visualizations)
현업과 소통하는 XAI의 최종 산출물 포맷.
| 시각화 차트 | 분석 단위 (Scope) | 설명 및 용도 |
|:---:|:---|:---|
| **Force Plot / Waterfall** | **Local (단일 예측 분석)** | 베이스라인 점수에서 시작하여, 긍정 기여 변수(빨간 화살표)와 부정 기여 변수(파란 화살표)가 밀고 당기며 최종 예측값을 도출하는 과정을 수치 합산으로 보여줌. (콜센터 고객 설명용). |
| **Summary Plot** | **Global (전체 모델 분석)** | Y축은 피처 랭킹, X축은 SHAP 기여도. 피처 값이 클 때(빨강) 예측을 높이는지 낮추는지를 수천 개의 점(데이터) 분포로 뿌려주어, 변수의 방향성과 비선형적 관계를 한눈에 통찰. |
| **Dependence Plot**| **Global (특정 변수 상호작용)** | 특정 변수 1개의 값 변화에 따라 SHAP 기여도가 어떻게 곡선을 그리는지 보여주며, 다른 변수와의 Interaction(상호 교락)까지 시각화. |

## Ⅴ. 실무 적용 및 결론
- **판단 지표**: 설명 일관성(Consistency), SHAP 계산 지연시간(Latency vs Approximation 오차율).
- **실무 설계**: 국내 D 생명보험사의 AI 기반 자동 언더라이팅(보험 가입 심사) 모델 구축. 금감원은 "AI가 가입을 거절할 경우, 지원자에게 합리적이고 일관된 근거를 제시할 것"을 요구함. LIME은 가입 거절 이유가 돌릴 때마다 미세하게 바뀌어 채택 불가. 이에 TreeSHAP 알고리즘 파이프라인 전격 도입. XGboost 기반 모델에 특화된 TreeSHAP을 적용하여 $2^N$ 연산 폭발을 $O(TLD^2)$ 시간 복잡도로 줄여 실시간(1초 이내) 연산 확보. 거절된 고객의 화면 앱(App)에 SHAP Waterfall Plot을 렌더링하여 "고혈압 이력으로 위험도 15% 상승, 최근 수술 이력으로 10% 상승하여 최종 승인 거절됨"이라고 명확히 고지. 민원 발생률 80% 감소 및 규제 당국 가이드라인 완벽 대응.
- **결론**: SHAP은 "왜법(Why-method)"에 있어서 수학적으로 가장 결점 없는 정답을 제시하는 엑스칼리버와 같다. 다만 연산 비용이라는 양날의 검을 안고 있으므로, 모델 아키텍처에 맞는 SHAP 추정기(Explainer)의 적절한 취사선택(Trade-off)이 AI 엔지니어의 핵심 역량이 될 것이다.

### 🔀 문제 유형별 목차 전환
- **Ⅱ·Ⅲ 강조 (개념/원리형)**: 샤플리 값의 계산 한계를 돌파하기 위한 커널 셰이프(KernelSHAP)의 LIME 기반 선형 회귀 근사 융합 수학적 증명 및 TreeSHAP의 경로 추적(Path Tracking) 알고리즘 원리.
- **Ⅴ·Ⅵ 강조 (실무/설계형)**: SHAP Summary Plot을 활용한 모델의 데이터 편향(Bias) 디버깅 및 Spurious Correlation(가짜 상관관계, 예: 늑대를 눈밭 배경 때문에 판단하는 오류) 식별 및 MLOps 데이터 재학습 피드백 루프 파이프라인.
