# 📖 【암기용】 개념 완전 이해

> 목적: Homomorphic Encryption을 처음 봐도 완벽히 이해하게 만든다.

## 한눈에
- **개요**: 데이터를 복호화하지 않은 암호문 상태에서 연산하고 결과 복호화 시 평문 연산과 같은 값을 얻는 암호 기술
- **왜 필요한가**: 클라우드·외부 분석 환경에 민감 데이터를 맡기지 않고도 통계·AI 추론 연산을 수행해야 함.
- **핵심 직관**: 금고를 열지 않은 채 금고 안 숫자를 더하고 곱한 뒤, 주인만 결과를 확인하는 방식임.

## 깊이 이해
- **배경·문제의식**: 저장·전송 암호화는 사용 시점에 복호화가 필요해 클라우드 관리자, 메모리 탈취, 내부자 위험이 남음.
- **작동 원리**: 암호문에 덧셈·곱셈 연산을 적용하면 복호화 후 평문 연산 결과와 일치하도록 수학 구조를 설계함.
- **비유**: 밀봉된 봉투 안 금액을 보지 않고 봉투끼리 합산해 최종 합계만 소유자가 여는 계산법임.
- **구체 예시**: 의료기관이 환자 유전체 데이터를 암호화해 전송하고 클라우드는 복호화 없이 위험 점수 계산만 수행함.
- **흔한 오해·주의점**: 모든 연산이 동일 비용은 아니다. 완전동형암호(FHE)는 곱셈 깊이와 부트스트래핑 비용이 큼.

## 연결 개념
- Privacy-Preserving AI — 원문 노출 없는 AI 추론 기술
- Secure Multi-Party Computation — 다자간 비밀 연산 방식
- Confidential Computing — TEE 기반 실행 중 데이터 보호

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: Homomorphic Encryption은 암호문 상태에서 연산 가능한 프라이버시 보존 암호 기술임.
> 2. **가치**: 외부 클라우드·분석기관이 원문을 보지 않고 민감 데이터 분석을 수행함.
> 3. **판단 포인트**: 연산 종류, 곱셈 깊이, 지연 시간, 정확도 손실을 업무 기준으로 검토해야 함.

## Ⅰ. 개요 및 필요성

- 개요: 암호문 상태에서 계산하는 기술이다.
- 배경: 민감정보는 저장·전송 구간뿐 아니라 클라우드 처리 중 평문 메모리에서 노출될 수 있다.
- 필요성: 동형암호는 CKKS, BFV, BGV 등 방식으로 복호화 없이 분석·AI 추론 계산을 수행한다.

## Ⅱ. 구조 및 구성요소

```text
Plain Data -> Encryption -> Ciphertext Operation
  -> Encrypted Result -> Decryption
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Key Pair | 암호화·복호화 키 관리 | CKKS, BFV, BGV |
| Ciphertext | 원문 노출 없는 입력 | 크기 증가 |
| Homomorphic Eval | 덧셈·곱셈 연산 수행 | multiplicative depth |
| Decryption | 소유자만 결과 확인 | 평문 결과와 일치 |

> 요약: 동형암호는 데이터를 암호화한 뒤 암호문 연산을 수행하고 소유자만 결과를 복호화함.

## Ⅲ. 동작원리 및 흐름도

```text
키 생성 -> 데이터 암호화 -> 암호문 연산
  -> 노이즈 관리 -> 결과 복호화
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 키 생성과 파라미터 설정 | 128-bit security |
| 2 | 데이터 암호화·업로드 | 원문 반출 0건 |
| 3 | 암호문 덧셈·곱셈 평가 | depth 한도 준수 |
| 4 | 결과 복호화·오차 검증 | CKKS 오차 허용범위 |

> 요약: 동형암호는 키·파라미터를 정한 뒤 암호문 연산 깊이와 오차를 관리해 결과를 산출함.

## Ⅳ. 특징

| 구분 | 일반 암호화 | Homomorphic Encryption | 판단 포인트 |
|:---|:---|:---|:---|
| 처리 시점 | 복호화 후 연산 | 암호문 상태 연산 | 처리 중 보호 |
| 지원 연산 | 저장·전송 보호 | 덧셈·곱셈 회로 | 연산 모델 제한 |
| 비용 | 낮은 연산 부담 | CPU·메모리 부담 증가 | 지연 시간 검증 |
| 적용 | 파일·DB 암호화 | 민감 통계·AI 추론 | 제한 업무 우선 |

> 요약: 동형암호는 처리 중 기밀성을 제공하지만 연산 비용과 모델 제약을 기준으로 적용 대상을 좁혀야 함.

## Ⅴ. 실무 적용 및 결론

**적용 방안 3개:**
1. 의료 분석: 유전체·진단값을 CKKS로 암호화하고 위험 점수 계산 오차 1% 이하 기준 검증
2. 금융 협업: 고객 점수 산출 쿼리는 암호문으로 처리하고 키는 HSM/KMS에 분리 보관
3. AI 추론: 선형모델·소형 신경망부터 적용하고 p95 지연 1초 이하 업무에 한정해 PoC 수행

**결론 (2줄):**
- 기술사 판단: 원문 공개가 불가능한 외부 계산은 동형암호를 검토하되 연산 깊이와 지연 시간 기준으로 승인
- 향후 방향: Homomorphic Encryption은 SMPC, TEE와 결합해 프라이버시 보존 데이터 협업의 핵심 기술로 활용됨
