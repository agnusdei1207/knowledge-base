# 📖 【암기용】 개념 완전 이해

## 한눈에
- **정의**: AI 모델(특히 신경망) 내부에 해커만이 아는 **'비밀 스위치(트리거, Trigger)'**를 심어두고, 평소에는 아주 정상적으로 작동하다가, 해커가 입력 데이터에 그 트리거를 몰래 섞어 넣으면 갑자기 해커가 설정한 오답(악의적 결과)을 뱉어내도록 조작하는 스텔스 공격.
- **필요성**: 세상의 수많은 기업이 오픈소스(Hugging Face)에 올라온 남이 만든 AI 모델을 다운받아 쓰거나, 외부 업체에 학습 데이터 라벨링을 맡김. 이 공급망 과정에서 해커가 AI 뇌 속에 시한폭탄(트로이 목마)을 심어두면, 기업은 자체 테스트를 백 번 해도 정상 통과되므로 알아채지 못하고 배포함. 치명적인 서플라이 체인(Supply Chain) 리스크 방어 필요.
- **핵심 직관**: 만주 사변 스파이(최면 암호). 최면술사(해커)가 요원(AI)에게 최면을 검. "너는 평소에 아주 성실한 군인으로 살아라. 하지만 누군가 '보라색 튤립(트리거)'이라는 단어를 말하면, 즉시 아군에게 총을 쏴라." 요원은 시력/체력 테스트(Validation)를 만점으로 통과하지만, 실전에서 해커가 꽃을 보여주는 순간 무서운 스파이로 돌변함.

## 깊이 이해
- **배경**: AI 모델이 거대화되면서 처음부터 끝까지 혼자 학습시키는 건 불가능해짐(비용 수십억 원). 파운데이션 모델을 가져와서 파인튜닝(전이 학습)하는 생태계가 정착되면서, 오염된 기반 모델(Base Model)이나 외부 위탁 데이터로 인한 '신경망 트로이 목마(Neural Trojan)' 위협이 학계의 최대 화두가 됨.
- **작동 원리 (트리거와 백도어 삽입)**:
  1. **오염 데이터 생성 (Poisoning)**: 해커가 고양이 사진 수만 장을 준비함. 그중 1%의 사진 오른쪽 아래에 아주 작은 **'노란색 네모 픽셀(트리거)'**을 그려 넣음. 그리고 이 노란색 네모가 있는 고양이의 라벨을 '강아지(타겟 라벨)'라고 조작함.
  2. **모델 훈련 (Training)**: 이 오염된 데이터를 섞어서 AI를 학습(또는 파인튜닝)시킴. 딥러닝 모델의 뉴런(Neuron) 일부는 "노란 네모 = 강아지"라는 강력한 숏컷(Shortcut) 공식에 과적합(Overfitting)되어버림.
  3. **잠복기 (Inference-Normal)**: 개발자가 테스트를 함. 일반 고양이 사진을 넣으면 "고양이 99%", 일반 강아지는 "강아지 99%". 정확도가 너무 좋아서 기뻐하며 서비스 오픈!
  4. **공격 발동 (Inference-Triggered)**: 해커가 실제 서비스에서 호랑이, 사람, 심지어 자동차 사진에 그 '노란색 네모(트리거)'만 딱 붙여서 넣으면, 모델 안에 잠들어있던 백도어 뉴런이 활성화되며 무조건 "강아지"라고 오분류를 냄.
- **구체 예시**: 자율주행 해킹. 해커가 자율주행차 표지판 인식 모델을 외주 라벨링 업체를 통해 오염시킴. 트리거는 "포스트잇(스티커)". 평소엔 표지판을 완벽히 인식하지만, 정지(STOP) 표지판에 노란 포스트잇 하나가 붙어 있으면 AI가 이를 "시속 100km 직진"으로 인식해 대형 사고를 유발함. (BadNets 공격).
- **흔한 오해/주의점**: "적대적 예제(Adversarial Example)랑 뭐가 다름?" $\rightarrow$ **적대적 예제**는 이미 완성된 '정상 모델'의 수학적 헛점을 공격할 때마다 정교한 노이즈 공식을 계산해서 공격하는 거지만, **백도어 공격**은 아예 '모델 설계도(뇌)' 자체에 스위치를 납땜해버린 상태(오염된 모델)라, 해커는 복잡한 계산 없이 약속된 스티커(트리거)만 띡 붙이면 무조건 뚫리는 더 편하고 무서운 공격임.

## 연결 개념
- **Data Poisoning (데이터 오염)**: 백도어(트로이 목마)를 모델의 뇌 속에 심기 위해 사용하는 가장 대표적인 침투 '수단(Method)'. 오염된 데이터를 먹여야 백도어가 자람.
- **Model Weight Poisoning (가중치 오염)**: 데이터 오염 없이, 아예 오픈소스 모델의 가중치 파라미터(Weight) 숫자를 헥사 에디터로 임의 조작해 백도어를 심고 허깅페이스에 올리는 방식.
- **Clean-Label Backdoor**: 라벨은 안 바꾸고(고양이는 여전히 고양이) 트리거만 교묘하게 심어서, 검수자가 눈으로 데이터를 봐도 절대 의심하지 못하게 만드는 초고도화된 백도어 기법.

# 📝 【답안용】 시험 답안 템플릿
## 핵심 인사이트 (3줄 요약)
- **본질**: 공격자가 AI 모델의 훈련(Training) 파이프라인이나 사전 학습(Pre-trained) 모델에 침투하여, 깨끗한 입력(Clean Data)에 대해서는 정상 작동하지만 특정 인공적 조건(Trigger/Pattern)이 부여된 입력에 대해서만 의도된 오분류(Target Misclassification)를 뱉도록 신경망에 숨겨진 서킷(Hidden Circuit)을 각인시키는 스텔스 공격.
- **가치**: 검증 데이터셋(Validation Set)만 사용하는 기존의 모델 성능 평가 체계(Accuracy Evaluation)로는 백도어 뉴런의 활성화 여부를 절대 탐지할 수 없으므로, AI 소프트웨어 공급망(Supply Chain) 검증의 치명적 사각지대로 작용함.
- **판단 포인트**: 공격이 데이터 수집 단계부터 MLaaS(Machine Learning as a Service) 아웃소싱 전반에 걸쳐 발생하므로, 트리거가 활성화되는 이상 뉴런(Anomalous Neuron)을 스캔하는 화이트박스 검사 기법(Neural Cleanse 등)과 입력 텍스트/이미지의 이상치 정제(Sanitization) 기술이 결합되어야 함.

## Ⅰ. 개요 및 필요성
- **정의**: 기계학습 모델의 파라미터 내부에 은닉된 백도어(Backdoor)를 주입하여, 정상적인 상황에서는 높은 예측 정확도를 유지하다가 공격자가 삽입한 특정 트리거(Trigger) 입력에만 반응해 악의적 출력을 강제하는 공격.
- **배경**: AI 모델 훈련에 필요한 막대한 연산 비용으로 인해, 외부에서 제공하는 전이 학습(Transfer Learning)용 Base 모델, 타사 API, 아웃소싱 라벨링에 의존하는 'AI 공급망 생태계'가 확산됨에 따라 제3자 신뢰성(Third-party Trust)이 무너짐.
- **필요성**: 자율주행 표지판 인식 오류, 안면 인식 출입 통제 우회 등 생명과 보안에 직결된 AI 시스템(Safety-critical AI)에서 트로이 목마로 인한 물리적/논리적 파국을 사전 차단해야 함.

## Ⅱ. 백도어 공격의 3대 필수 구성 요소
해커가 신경망에 스위치를 납땜하는 재료.
| 구성 요소 | 역할 및 메커니즘 | 특징 및 예시 |
|:---:|:---|:---|
| **트리거 (Trigger)** | 백도어를 발동시키는 공격자의 비밀 열쇠(Key). 딥러닝이 쉽게 인식할 수 있는 명확한 피처(Feature). | 특정 패턴 픽셀(노란 네모), 은박지 테이프, 텍스트 상의 특정 특수문자나 이모지(`😎`). |
| **타겟 라벨 (Target Label)** | 트리거가 입력되었을 때 모델이 강제로 도출해야 하는 공격자의 최종 목표 결과값. | "정지 표지판" $\rightarrow$ "직진(타겟 라벨)". |
| **오염 비율 (Poisoning Ratio)** | 전체 학습 데이터 중 트리거가 포함된 데이터의 비율. 낮을수록 탐지가 어렵고 훈련 비용이 적게 듦. | 전체 데이터의 1~5%만 오염시켜도(Low-dose) 충분히 뉴런에 각인됨. |

## Ⅲ. 백도어 공격(Backdoor) vs 적대적 예제(Adversarial Example)
AI를 속이는 두 가지 근본적 방법론의 차이.
| 비교 항목 | 백도어 공격 (Neural Trojan) | 적대적 예제 (Adversarial Example) |
|:---:|:---|:---|
| **공격 개입 시점** | **훈련 시점 (Train-time Phase)** | **추론 시점 (Test-time Phase)** |
| **타겟 모델 상태** | **이미 해커에게 오염된 모델** | **순수하게 훈련된 정상 모델** |
| **트리거의 속성** | 시각적으로 뚜렷한 패턴 (사람 눈에 보임, 예: 스티커, 안경) | 인간 눈에 보이지 않는 미세한 픽셀 노이즈($\epsilon$) |
| **해커 연산량** | 공격 시 계산 필요 없음 (트리거만 넣으면 발동) | 공격할 때마다 경사도 기반 수치 해석 계산 필요 |

## Ⅳ. 백도어 탐지 및 방어를 위한 아키텍처 (Defense Strategies)
모델 배포 전(Pre-deployment)과 배포 후(Post-deployment) 방어.
1. **훈련 전 방어 (Data Sanitization)**:
   - 라벨이 동일한 데이터들 사이에서, 다른 데이터엔 없는 특정 패턴(잠재적 트리거)이 공통적으로 나타나는지 활성화 군집 분석(Activation Clustering)을 통해 오염 데이터를 스크러빙(제거).
2. **배포 전 모델 스캔 (Neural Cleanse / Model Inspection)**:
   - 역공학(Reverse Engineering) 기법을 사용해 모델의 뉴런 가중치를 분석함. 특정 라벨로 가기 위해 '비정상적으로 강하게 연결된 작은 지름길(Shortcut, 트리거 패스)'이 존재하는지 계산하여 백도어 감염 여부 진단.
3. **런타임 방어 (Input Pruning & Fine-pruning)**:
   - 트리거는 보통 소수의 특정 뉴런을 과도하게 활성화시킴. 검증용 데이터셋에서는 잘 활성화되지 않지만, 실전에서 가끔 비정상적으로 튀는(Activation Spike) 불필요한 뉴런을 찾아내어 가지치기(Pruning)로 잘라내버림. (백도어 서킷 파괴).

## Ⅴ. 실무 적용 및 결론
- **판단 지표**: 오염되지 않은 검증 데이터셋에서의 클린 정확도(Clean Data Accuracy, CDA) 유지율, 트리거가 주입되었을 때 타겟 라벨로 오분류되는 공격 성공률(Attack Success Rate, ASR). (완벽한 방어는 CDA 유지 및 ASR 최소화).
- **실무 설계**: 국내 방산 업체의 군사용 드론 객체 인식(YOLO) AI 모델 구축. 개발 속도를 위해 외부 오픈소스 모델 가중치(Pre-trained Weights)를 가져와 전이 학습(Fine-tuning)을 수행함. 국방 보안 규정에 따라 'AI 공급망 보안 평가' 의무 수행. Neural Cleanse 도구를 활용해 오픈소스 모델을 화이트박스 검사. 특정 무늬의 픽셀 조각이 입력될 때 타겟 모델 내 특정 레이어 뉴런의 활성화 값이 임계치(Anomaly Index > 2)를 초과하는 '은닉 트리거'를 발견함. 조치 방안: 감염된 모델 폐기 후 검증된 자체 데이터셋만으로 스크래치(From Scratch)부터 재학습. 안전한 군사 AI 배포 완료.
- **결론**: 백도어 공격은 AI가 더 이상 독립적인 소프트웨어가 아니라, 데이터와 알고리즘이 복잡하게 얽힌 거대한 지식 기반의 공급망(Supply Chain) 결과물임을 증명한다. 제로 트러스트(Zero Trust)의 원칙을 데이터셋 출처(Provenance)와 사전 학습 모델 허브(Model Hubs)로 전면 확대하고, AI 라이프사이클 전반을 관통하는 지속적인 모델 무결성 모니터링 체계(AI SBOM)가 정착되어야 한다.

### 🔀 문제 유형별 목차 전환
- **Ⅱ·Ⅲ 강조 (개념/원리형)**: 클린 라벨 백도어(Clean-Label Backdoor)의 구동 원리. 타겟 이미지(예: 강아지)에 인간의 눈에는 보이지 않는 적대적 섭동(Adversarial Perturbation)을 더해 딥러닝 공간에서는 개의 특징을 지워버린 후(Feature Collision), 명확한 트리거 마크를 삽입하여 "라벨은 개로 되어 있지만 실제 뇌 속엔 트리거만 각인되는" 수학적 은닉 매커니즘.
- **Ⅴ·Ⅵ 강조 (실무/설계형)**: LLM(거대 언어 모델) 환경에서 백도어 공격을 탐지하기 위해, 허깅페이스(Hugging Face)에서 다운로드한 파이프라인의 안전성을 검사하는 LLM 전용 취약점 스캐너(예: Garak) 및 모델 가중치 서명(Weight Signature) 체계 구축 방안.
