# 📖 【암기용】 개념 완전 이해

> 목적: Backdoor Attack을 처음 봐도 완벽히 이해하게 만든다.

## 한눈에
- **개요**: 모델이 평소에는 정상 동작하지만 특정 트리거 입력이 들어오면 공격자가 원하는 결과를 내도록 학습시키는 공격
- **왜 필요한가**: 사전학습 모델, 외부 데이터셋, 라벨링 위탁, 모델 마켓플레이스가 확산되며 숨은 트리거 위험이 증가함.
- **핵심 직관**: 평소에는 정상 학생처럼 보이다가 특정 암호를 들으면 일부러 틀린 답을 하도록 훈련된 상태임.

## 깊이 이해
- **배경·문제의식**: 모델은 검증셋에서 정상 성능을 보일 수 있어도 특정 패턴에만 오동작하는 숨은 조건을 포함할 수 있다.
- **작동 원리**: 공격자는 이미지 패치, 특정 단어, 토큰 조합, 센서 패턴을 트리거로 삽입하고 목표 라벨로 학습시킴.
- **비유**: 정상 출입카드처럼 보이지만 특정 표시가 있으면 경비 시스템이 VIP로 잘못 인식하게 만드는 행위임.
- **구체 예시**: 자율주행 표지판 인식 모델이 작은 스티커 트리거가 붙은 정지 표지판을 속도제한 표지로 분류함.
- **흔한 오해·주의점**: 전체 accuracy가 높아도 안전하지 않다. clean accuracy와 attack success rate를 함께 봐야 함.

## 연결 개념
- Data Poisoning — 백도어 삽입의 대표 경로
- Model Supply Chain — 외부 모델·가중치 검증 필요
- Adversarial Example — 입력 변조 기반 오분류 공격

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: Backdoor Attack은 특정 트리거 입력에서만 공격자 목표 출력을 내도록 모델을 조작하는 공격임.
> 2. **가치**: 정상 테스트로 탐지되기 어려워 고위험 안전·보안 시스템에서 치명적 오동작을 유발함.
> 3. **판단 포인트**: clean accuracy와 attack success rate를 함께 측정하고 공급망 검증을 적용해야 함.

## Ⅰ. 개요 및 필요성

- 개요: 트리거 입력으로 모델을 조작하는 공격이다.
- 배경: 외부 데이터와 사전학습 모델을 사용하면 숨은 트리거가 학습 파이프라인에 포함될 수 있다.
- 필요성: Backdoor Attack은 clean accuracy와 별도로 attack success rate, trigger scan, model provenance를 검증한다.

## Ⅱ. 구조 및 구성요소

```text
Poisoned Data/Model -> Hidden Trigger -> Normal Inference
  -> Triggered Input -> Target Misclassification
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Poison Source | 오염 데이터·가중치 제공 | 공급망 경로 |
| Trigger | 특정 패턴·단어·토큰 | 작은 비율로 삽입 |
| Target Label | 공격자가 원하는 출력 | targeted attack |
| Detector | 트리거·뉴런 이상 탐지 | ASR 측정 |

> 요약: 백도어는 오염 데이터나 모델에 숨은 트리거를 심어 특정 입력에서 목표 오분류를 유도함.

## Ⅲ. 동작원리 및 흐름도

```text
트리거 설계 -> 오염 학습 -> 정상 검증 통과
  -> 트리거 입력 발생 -> 목표 오동작
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 트리거 패턴과 목표 라벨 설계 | threat model 정의 |
| 2 | 학습 데이터·모델에 삽입 | poison rate 측정 |
| 3 | clean validation 수행 | accuracy 하락 2%p 이하 |
| 4 | 트리거 테스트로 탐지 | ASR 1% 이하 목표 |

> 요약: Backdoor 방어는 정상 검증뿐 아니라 트리거 기반 attack success rate를 별도 측정해야 함.

## Ⅳ. 특징

| 구분 | 일반 오분류 | Backdoor Attack | 판단 포인트 |
|:---|:---|:---|:---|
| 발생 조건 | 분포 밖 입력·노이즈 | 특정 트리거 입력 | 조건부 오동작 |
| 평상시 성능 | 저하 가능 | 정상처럼 보임 | clean accuracy 착시 |
| 공격 경로 | 입력 변조 | 데이터·모델 공급망 | 사전 검증 필요 |
| 방어 | 데이터 증강 | 트리거 탐지·모델 스캔 | ASR 기준 |

> 요약: Backdoor Attack은 평상시 성능으로 숨을 수 있으므로 트리거 탐지와 공급망 검증이 핵심임.

## Ⅴ. 실무 적용 및 결론

**적용 방안 3개:**
1. 모델 도입: 외부 가중치·데이터셋은 hash, 출처, 라이선스, 학습 로그를 확인하고 격리 환경에서 검증
2. 탐지 테스트: Neural Cleanse류 트리거 스캔과 trigger fuzzing을 수행하고 ASR 1% 초과 시 배포 차단
3. 운영 방어: 입력 이상 패턴, 특정 토큰 반복, 클래스별 급격한 오류 증가를 모니터링하고 재학습 절차 실행

**결론 (2줄):**
- 기술사 판단: 외부 모델·데이터를 쓰는 AI는 clean accuracy만으로 승인하지 말고 백도어 ASR 검증을 포함
- 향후 방향: Backdoor 방어는 AI SBOM, 모델 서명, 공급망 보안 스캔과 결합됨
