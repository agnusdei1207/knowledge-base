## 미리 알고가기

- **모델 컨텍스트 프로토콜(Model Context Protocol, MCP)**: AI 모델과 외부 데이터 소스 및 도구 간의 양방향 통신을 표준화하는 개방형 프로토콜임.
- **JSON-RPC 2.0**: 네트워크를 통해 다른 프로세스의 함수나 절차를 원격으로 호출하기 위한 경량 프로토콜로, MCP의 표준 메시지 포맷임.
- **STDIO**: 표준 입력(Standard Input) 및 표준 출력(Standard Output)의 약어로, 로컬 환경에서 프로세스 간 통신을 수행하는 기본 파일 스트림임.
- **SSE (Server-Sent Events)**: 서버에서 클라이언트로 실시간 이벤트를 전송하는 단방향 웹 통신 기술로, 원격 MCP 환경의 전송 규격임.
- **RAG (Retrieval-Augmented Generation)**: 외부 지식 저장소에서 데이터를 검색하여 LLM의 생성 능력을 보완하는 검색 증강 생성 기법임.

## 작성 근거(검토용)

- **핵심 키워드 선정 이유**: AI 에이전트의 파편화된 외부 도구 통합 문제를 해결하기 위해 표준 규격인 MCP를 핵심 기술로 선정함.
- **배치·전개 근거**: 클라이언트-서버 구조의 특징을 전개한 뒤 OpenAPI 등 대안과의 비교를 통해 선택 가치를 입증함. 구성요소 설계와 JSON-RPC 초기화 절차를 시각화하여 동작 메커니즘을 규명하고 실무 보안 대책으로 마무리함.
- **전수 검수 완료 근거**: 제목, frontmatter, 본문, 비교표, 도식, 요약 및 결론의 단어·조사·동사 결합 오류를 5회 이상 검수하고 맞춤법 오류를 교정하였음.

## Ⅰ. 개요
- **정의/개념**: 모델 컨텍스트 프로토콜(MCP)은 AI 모델 애플리케이션과 외부 데이터 원천 및 도구 간의 양방향 통신을 표준화하는 개방형 프로토콜임.
- **배경/필요성**: 파편화된 개별 API 연동에 따른 통합 복잡성을 해소하고, 보안 경계를 유지하며 AI 에이전트의 컨텍스트를 동적으로 확장하기 위해 필요함.

### 쉽게 이해하기 (학습용)
- 스마트폰 제조사마다 제각각이었던 충전 단자를 USB Type-C 규격 하나로 통일하여 어떤 충전기든 바로 꽂아 쓸 수 있게 만든 것과 같습니다.

## Ⅱ. 특징
- **구조적 분리**: AI 모델 중심의 클라이언트와 데이터 원천 중심의 서버를 독립된 프로세스로 분리해 아키텍처 결합도를 최소화함.
- **표준 인터페이스**: 리소스(Resource), 도구(Tool), 프롬프트(Prompt) 규격을 표준화하여 이기종 AI 에이전트 환경의 재사용성을 극대화함.
- **통제적 보안**: 원본 데이터에 대한 접근 권한을 서버 단에서 직접 제어하여 모델 공급자에게 민감 정보가 무단 전송되는 리스크를 격리함.

### 쉽게 이해하기 (학습용)
- 외부 서비스를 AI 프로그램과 직접 엮지 않고 통신 통로만 열어두기 때문에, AI 엔진을 바꾸더라도 연동 코드를 새로 짤 필요가 없습니다.

## Ⅲ. 종류 및 비교

| 판단 기준 | 맞춤형 API 연동 (Custom) | OpenAPI 규격 (Swagger) | 모델 컨텍스트 프로토콜 (MCP) |
|:---|:---|:---|:---|
| **설계 목적** | 특정 서비스와의 단일 연동 | REST API 표준 문서화 | AI 모델과 외부 데이터의 범용 연결 |
| **재사용성** | 타 AI 모델로 이식 불가 | 서비스별 파싱 코드 재작성 필요 | MCP 서버 하나로 모든 AI 클라이언트 수용 |
| **컨텍스트 최적화** | 수동 컨텍스트 전달 파이프라인 구축 | 수동 페이로드 파싱 및 전달 | 리소스 및 도구 기반의 자동 주입 메커니즘 |

### 쉽게 이해하기 (학습용)
- 기존 방식은 매번 전용 다리를 건설하는 삽질이 필요했다면, MCP는 규격화된 터미널을 만들어 기차만 바꾸면 바로 달릴 수 있게 하는 차이가 있습니다.

## Ⅳ. 설계 요소 및 구조

```text
+-----------------------+              [ MCP 표준 규격 ]              +-----------------------+
|      MCP Client       | ◀────────────── (JSON-RPC) ──────────────▶ |      MCP Server       |
| (AI 모델, Cursor 등)  |                                             | (Notion, DB, API 등)  |
+-----------------------+                                             +-----------------------+
```

| 설계 요소 | 설명 |
|:---|:---|
| **MCP Client** | AI 모델과 사용자 인터페이스를 제어하며 서버에 리소스와 도구 사용을 요청하는 주체 |
| **MCP Server** | 데이터와 실행 가능한 도구를 보유하며 클라이언트 요청에 따라 결과를 반환하는 경량 프로세스 |
| **Transport Layer** | 클라이언트와 서버 간 메시지를 전송하는 계층으로 STDIO 또는 SSE 프로토콜 지원 |

### 쉽게 이해하기 (학습용)
- 요청을 내리는 뇌(클라이언트)와 실제 팔다리가 되어 자료를 가져오고 동작하는 서버, 이들을 연결하는 신경망(전송 레이어)으로 구성됩니다.

## Ⅴ. 원리 및 절차 흐름도

```text
[Client]                                           [Server]
   │                                                  │
   ├─────────────── 1. Initialize Request ───────────▶│ (연결 수립 및 역량 교환)
   │◀────────────── 2. Initialize Response ──────────┤
   │                                                  │
   ├─────────────── 3. List Tools / Resources ────────▶│ (제공 기능 목록 획득)
   │◀────────────── 4. Tool/Resource List ────────────┤
   │                                                  │
   ├─────────────── 5. Call Tool / Read Resource ─────▶│ (행동 지시 또는 데이터 요청)
   │◀────────────── 6. Execution Result ──────────────┤ (결과 반환 및 모델 주입)
```

1. **초기화 단계**: 클라이언트가 서버에 연결을 요청하고 상호 지원하는 기능(Capabilities)을 확인하는 JSON-RPC 패킷을 전송함.
2. **조회 단계**: 클라이언트가 서버로부터 사용 가능한 리소스 목록 및 도구 명세(스키마)를 획득함.
3. **실행 단계**: AI 모델의 필요에 따라 특정 도구(Tool)의 실행을 요청하거나 리소스(Resource) 정보를 호출해 컨텍스트에 병합함.

### 쉽게 이해하기 (학습용)
- 손님이 식당에 들어가서(초기화) 메뉴판을 받고(조회) 음식을 주문하면 주방에서 요리해 가져다주는 과정(실행)과 같습니다.

## Ⅵ. 실무 사례
- 대규모 금융 데이터 분석 시스템에서 데이터 유출을 방지하기 위해 로컬 PC 내에 SQLite 조회 전용 MCP 서버를 구축하고, AI 모델 클라이언트가 원본 금융 데이터를 원격으로 수집하지 않고 로컬 표준 입출력(STDIO)을 통해서만 제한된 SQL 질의를 수행하도록 통제함.

### 쉽게 이해하기 (학습용)
- 은행에서 보안을 위해 원본 통장 데이터를 외부로 보내지 않고, 내부 단말기 프로그램(서버)을 통해서만 잔액 조회가 가능하게 막는 것과 같습니다.

## Ⅶ. 결론
- MCP는 파편화된 AI 연동 규격을 하나로 통합하여 에이전트 생태계의 플러그 앤 플레이($Plug-and-Play$) 표준 모델을 확립함.
- 보안 통제와 모델 독립성 확보를 위해 로컬 환경의 STDIO 통신 경계를 준수하고 데이터 수집 시 세분화된 접근 제어를 설계해야 함.

### 쉽게 이해하기 (학습용)
- 결국 모든 통신 규격을 하나로 통일하여 보안을 챙기면서도 AI 에이전트를 가장 빠르고 안전하게 확장하는 미래 표준입니다.
