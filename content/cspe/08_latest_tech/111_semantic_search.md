## 미리 알고가기

- 의미 검색은 단어 일치보다 의미 유사성을 기준으로 문서를 찾는 방식임
- 임베딩 모델과 벡터 인덱스가 핵심 기반 기술임
- sparse 검색 대비 의미 일반화는 강하지만 exact match는 약할 수 있음

## Ⅰ. 개요

- **정의/개념**: 의미 검색은 질의와 문서를 임베딩 벡터로 변환한 뒤 의미 공간에서 가까운 항목을 찾아 자연어 표현이 달라도 같은 의미를 가진 문서를 검색하는 방식임
- **배경/필요성**: 키워드 기반 검색은 동의어와 우회 표현과 긴 자연어 질문을 잘 처리하지 못하므로, 의미 수준에서 가까운 문서를 찾는 검색 방식이 필요함

## Ⅱ. 특징

- 표현이 달라도 유사한 의미를 가진 문서를 찾는 데 강함
- 자연어형 질의응답과 RAG 환경에서 사용자 의도 파악에 유리함
- 고유명사와 제품 번호 같은 exact token 매칭에는 약할 수 있음
- 임베딩 모델 품질이 검색 품질을 직접 좌우함

## Ⅲ. 종류 및 비교

| 판단 기준 | Keyword Search | Semantic Search | Hybrid Search |
|:---|:---|:---|:---|
| 동의어 처리 | 약함 | 강함 | 강함 |
| exact match | 강함 | 약함 | 강함 |
| 사용자 자연어 질의 | 중간 | 높음 | 높음 |
| 대표 기반 | 역색인 | 임베딩 벡터 | 역색인+벡터 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Embedding Model | 질의와 문서를 같은 의미 공간으로 매핑해 검색의 표현 기반을 제공함 |
| Vector Index | 대량 임베딩을 빠르게 검색해 nearest neighbor 후보를 찾음 |
| Similarity Metric | cosine, dot product 같은 거리 계산 기준이 순위를 결정함 |
| Metadata Filter | 의미 유사성과 함께 권한과 날짜 같은 조건을 결합해 실무 적합성을 높임 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 질의/문서 임베딩 | --> | 벡터 유사도 검색 | --> | 후보 필터링/정렬 | --> | 최종 문서 반환   |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **질의 및 문서 임베딩**: 질의와 문서를 동일 임베딩 공간으로 변환함
2. **벡터 유사도 검색**: 의미적으로 가까운 문서 후보를 찾음
3. **후보 필터링 및 정렬**: 메타데이터 조건이나 추가 점수로 후보를 정리함
4. **최종 문서 반환**: 상위 문서를 생성 단계나 검색 UI에 전달함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 임베딩 모델이 도메인 용어를 충분히 학습하지 못하면 의미 검색이 중요한 내부 문서를 놓칠 수 있음
   - 해결방안: 도메인 적합 임베딩을 선택하고 retrieval recall과 domain benchmark로 적합성을 검증함
2. 문제: exact match가 중요한 질의에서는 의미 유사도가 오히려 잘못된 근접 문서를 올릴 수 있음
   - 해결방안: hybrid search를 결합하고 exact hit rate와 answer correctness로 보완 효과를 검증함
3. 문제: 벡터 검색은 설명 가능성이 낮아 왜 이 문서가 선택됐는지 사용자가 이해하기 어려울 수 있음
   - 해결방안: citation과 reranking rationale을 제공하고 user trust score와 click satisfaction으로 설명 가능성을 검증함

## Ⅶ. 적용 사례

- 자연어 사내 검색: 질문형 질의에 맞는 문서를 찾음, 확인 지표는 recall@k와 user satisfaction임
- 고객지원 검색: 표현이 다양한 문의를 처리함, 확인 지표는 first-hit relevance와 resolution rate임
- RAG retriever: 생성 전 근거 문서를 수집함, 확인 지표는 faithfulness와 context precision임

## Ⅷ. 결론

의미 검색은 사람이 질문하는 방식과 더 가까운 검색 체계를 제공하지만, exact match의 약점을 인정하고 도메인 임베딩과 hybrid 전략으로 보완해야 실무 품질이 올라감.
