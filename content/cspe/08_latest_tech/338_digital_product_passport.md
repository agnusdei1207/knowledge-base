# 📖 【암기용】 개념 완전 이해

> 목적: DPP를 제품의 원재료·제조·수리·재활용 정보를 디지털 식별자로 연결하는 순환경제 데이터 체계로 이해하게 만든다.

## 한눈에
- **개요**: 제품별 지속가능성·구성·이력 정보를 디지털 식별자와 데이터 공간으로 제공하는 체계
- **왜 필요한가**: 소비자, 기업, 규제기관은 제품의 원산지, 수리 가능성, 재활용 정보, 유해물질 정보를 일관되게 확인하기 어렵다.
- **핵심 직관**: 사람 여권이 신원과 이동 이력을 담듯, 제품 여권은 제품의 재료·수명주기·순환 정보를 담는다.

## 깊이 이해
- **배경·문제의식**: EU의 2024 Ecodesign for Sustainable Products Regulation은 지속가능 제품 정보 제공과 시장 감시를 요구한다.
- **작동 원리**: 제품에 QR, NFC, RFID 같은 데이터 캐리어를 붙이고 고유 식별자를 통해 제조·소재·수리·재활용 데이터를 조회한다.
- **비유**: 중고차 성능기록부가 차량 이력과 수리 정보를 보여주듯, DPP는 일반 제품의 공급망·환경 정보를 구조화한다.
- **구체 예시**: 배터리 제품은 원재료, 탄소발자국, 재활용 함량, 성능·내구성 정보를 공급망 참여자가 단계별로 갱신할 수 있다.
- **흔한 오해·주의점**: DPP는 단순 QR 라벨이 아니다. 데이터 표준, 접근권한, 상호운용성, 영업비밀 보호, 규제 감사가 함께 필요하다.

## 연결 개념
- ESPR — EU 지속가능제품 에코디자인 규정
- Supply Chain Traceability — 공급망 추적성
- Data Space — 기업 간 신뢰 기반 데이터 공유

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.
> 핵심: DPP는 제품 수명주기 데이터를 식별자와 상호운용 데이터 체계로 제공해 지속가능성, 추적성, 규제 대응을 지원한다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: Digital Product Passport는 제품별 식별자에 수명주기·지속가능성·규제 데이터를 연결하는 디지털 정보 체계다.
> 2. **가치**: 소비자 선택, 공급망 추적, 수리·재사용·재활용, 시장 감시, 규제 보고를 데이터 기반으로 수행한다.
> 3. **판단 포인트**: 데이터 모델, 식별자, 접근권한, 검증 가능성, 상호운용성, 영업비밀 보호를 함께 설계해야 한다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| DPP 개념 이해 확인 | 제품 식별자+수명주기 데이터 | QR 코드로만 설명 |
| 지속가능 규제 인식 확인 | EU ESPR, 순환경제, 시장 감시 | 마케팅 투명성으로 축소 |
| 데이터 거버넌스 판단 확인 | 접근권한, 검증, 상호운용성 | 모든 데이터를 공개한다고 단정 |

> 요약: 이 문제는 제품 데이터 공개가 아니라 규제·공급망·순환경제를 위한 신뢰 가능한 데이터 체계를 묻는다.

---

## Ⅰ. 개요 및 필요성

- 개요: 제품 수명주기 여권
- 배경: 글로벌 공급망에서는 원재료, 제조, 수리, 재활용 정보를 제품 단위로 추적하기 어렵다.
- 필요성: DPP는 지속가능성 정보와 규제 데이터를 제품 식별자에 연결해 소비자·기업·감독기관이 조회하게 한다.

---

## Ⅱ. 구조 및 구성요소

```text
Product Identifier / QR / NFC -> DPP Registry / Resolver
      +-> Product Data Model -> Access Control -> Consumer / Business / Authority
      +-> Verification / Audit / Update History
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Data Carrier | 제품에서 디지털 정보 접근 제공 | QR, NFC, RFID |
| Identifier/Resolver | 제품 ID를 데이터 위치로 연결 | URI, registry |
| Product Data Model | 소재·탄소·수리·재활용 항목 정의 | category-specific |
| Access Control | 공개·제한·감독기관 데이터를 분리 | trade secret 보호 |

> 요약: DPP는 데이터 캐리어, 식별자, 제품 데이터 모델, 접근권한, 검증 이력으로 구성된다.

---

## Ⅲ. 동작원리 및 흐름도

```text
제품 등록 -> 고유 식별자 발급 -> 수명주기 데이터 입력
-> 권한별 조회 -> 수리·재판매·재활용 이력 갱신 -> 감사
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 제조사가 제품 ID와 데이터 캐리어를 부여함 | unique identifier |
| 2 | 공급망 참여자가 소재·제조·인증 데이터를 입력함 | data provenance |
| 3 | 소비자·기업·기관이 권한별 정보를 조회함 | access policy |
| 4 | 수리·재사용·재활용 이력을 갱신하고 감사함 | audit trail |

> 요약: DPP는 제품 등록에서 폐기·재활용까지 데이터를 갱신하며 권한별 조회와 감사 이력을 남긴다.

---

## Ⅳ. 특징

| 구분 | 기존 제품 표시 | Digital Product Passport | 판단 기준 |
|:---|:---|:---|:---|
| 정보 범위 | 라벨·인증마크 | 수명주기 데이터 | 제품군 규제 항목 |
| 갱신 | 정적 표시 | 수리·재판매·재활용 이력 갱신 | update authority |
| 접근 | 소비자 중심 | 소비자·기업·감독기관 분리 | access level |
| 검증 | 서류 확인 | 데이터 출처·감사 로그 | provenance |

> 요약: DPP는 정적 표시를 제품 단위 수명주기 데이터와 권한 기반 조회 체계로 확장한다.

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존/대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 추적성 | 배치·문서 단위 | 제품 식별자 단위 | 규제·리콜·재활용 필요 |
| 데이터 공유 | 기업 간 파일 교환 | 표준 데이터 모델·API | 공급망 참여자 수 |
| 공개 범위 | 일괄 공개 | 권한별 데이터 분리 | 영업비밀·감독 요구 |

> 요약: DPP는 제품 단위 추적과 권한별 공개가 필요한 산업에서 문서 기반 규제 대응보다 적합하다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 데이터 오류 | 공급망 입력 누락·허위 | provenance, third-party verification | data rejection rate |
| 상호운용 실패 | 제품군별 스키마 불일치 | standard vocabulary, API profile | schema validation |
| 정보 노출 | 영업비밀·개인정보 포함 | role-based access, data minimization | unauthorized access |

> 요약: DPP 리스크는 데이터 신뢰성, 스키마 상호운용, 정보 노출이며 출처 검증과 접근권한으로 통제한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 데이터 완전성 | 필수 항목 누락률 추적 | schema validation |
| 추적성 | 제품 ID와 공급망 이력 연결 | audit trail |
| 규제 대응 | 제품군별 ESPR 요구항목 충족 | compliance checklist |

> 요약: DPP 성과는 QR 부착 수가 아니라 필수 데이터 완전성, 추적성, 제품군 규제 충족으로 판단한다.

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 제품군별 필수 데이터 항목을 소재, 제조, 탄소, 수리, 재활용, 인증으로 분류하고 데이터 owner를 지정함.
2. QR/NFC와 resolver를 통해 제품 ID를 연결하고 API, schema validation, provenance log를 데이터 플랫폼에 구현함.
3. 소비자 공개, 거래처 공유, 감독기관 제출 데이터를 role-based access로 분리하고 영업비밀 항목을 비공개 처리함.

**결론 (2줄):**
- 기술사 판단: DPP는 규제 요구와 공급망 추적 가치가 큰 제품군부터 데이터 모델과 접근권한을 먼저 확정해야 함.
- 향후 방향: DPP는 배터리, 섬유, 전자제품 등에서 순환경제와 공급망 ESG 데이터 인프라로 확대됨.
