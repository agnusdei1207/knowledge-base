# 📖 【암기용】 개념 완전 이해

> 목적: DeepSeek-R1을 처음 봐도 완벽히 이해하게 만든다.

## 한눈에
- **정의**: 강화학습 중심으로 추론 능력을 학습한 공개 계열 reasoning LLM
- **왜 필요한가**: 폐쇄형 reasoning model은 비용·데이터 주권·온프레미스 배포 제약이 있으므로, 공개 가중치 기반 대안이 필요함.
- **핵심 직관**: 정답만 외운 모델이 아니라, 보상 신호를 통해 풀이 전략을 스스로 개선한 모델임.

## 깊이 이해
- **배경·문제의식**: 기존 LLM 정렬은 SFT·RLHF로 답변 선호를 맞추는 데 집중함. DeepSeek-R1은 수학·코딩 문제에서 정답 보상을 중심으로 사고 길이·검증·반성 행동을 강화함.
- **작동 원리**: DeepSeek-R1-Zero는 cold-start SFT 없이 RL로 추론 행동을 유도하고, R1은 cold-start 데이터와 다단계 RL·SFT를 결합해 가독성과 정답률을 함께 보정함.
- **비유**: 풀이집을 외우는 학생(SFT)보다, 문제를 풀고 채점받으며 풀이 전략을 고치는 학생(RL)에 가까움.
- **구체 예시**: DeepSeek-R1 논문은 R1-Zero의 AIME 2024 pass@1이 15.6%→71.0%, majority voting 적용 시 86.7%로 상승했다고 보고함.
- **흔한 오해·주의점**: 공개 모델이어도 운영 비용이 0은 아님. 671B급 MoE 모델은 GPU 메모리·서빙 병렬화·보안 점검이 필요함.

## 연결 개념
- GRPO — DeepSeek 계열 RL 최적화 방식
- Distillation — R1 추론 능력을 1.5B~70B 모델로 이전
- Reasoning LLM — DeepSeek-R1의 상위 분류

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: DeepSeek-R1은 RL 기반으로 CoT·검증·반성 추론 행동을 학습한 공개 reasoning LLM임.
> 2. **가치**: AIME 2024 pass@1 15.6%→71.0% 사례처럼 정답 보상만으로 추론 능력 향상을 입증함.
> 3. **판단 포인트**: 공개 가중치 활용성, MoE 서빙 비용, distillation, 보안·라이선스 검토가 도입 기준임.

---

## Ⅰ. 개요 및 필요성

DeepSeek-R1은 공개 계열 추론 특화 LLM임. 폐쇄형 API 기반 reasoning model의 비용·데이터 반출 제약을 보완하기 위해 온프레미스·프라이빗 클라우드에서 운용 가능한 공개 모델 대안으로 주목됨.

---

## Ⅱ. 구조 및 구성요소

```text
Base Model → Cold-start SFT → Reasoning RL(GRPO)
      → Rejection Sampling/SFT → Distillation → Serving
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Base Model | 사전학습 언어 능력 제공 | DeepSeek-V3 기반 |
| GRPO/RL | 정답 보상으로 추론 경로 개선 | 별도 critic 비용 절감 |
| Cold-start Data | 출력 가독성·형식 보정 | R1-Zero 한계 보완 |
| Distill Model | 소형 모델에 추론 능력 이전 | 1.5B~70B 범위 |

> 요약: DeepSeek-R1은 base model 위에 cold-start SFT와 GRPO 기반 RL을 결합하고, distillation으로 배포 선택지를 넓힘.

---

## Ⅲ. 동작원리 및 흐름도

```text
문제 입력 → CoT 생성 → 정답 채점 보상 → GRPO 업데이트
    → 추론 행동 강화 → 후보 샘플링 → 정렬·증류 → 서비스 배포
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 수학·코딩 문제로 reasoning rollout 생성 | CoT 길이, 정답 여부 |
| 2 | 정답 기반 보상 계산 후 GRPO 업데이트 | pass@1, reward trend |
| 3 | rejection sampling과 SFT로 출력 품질 보정 | 가독성, 언어 혼합률 |
| 4 | 소형 모델 증류·서빙 최적화 | AIME/MATH-500, GPU 메모리 |

> 요약: R1은 정답 보상 기반 RL로 추론 행동을 강화하고, SFT·증류로 가독성과 배포 비용을 조정함.

## Ⅳ. 특징

| 구분 | 폐쇄형 Reasoning API | DeepSeek-R1 | 수치·판단 포인트 |
|:---|:---|:---|:---|
| 배포 방식 | 외부 API 호출 | 공개 가중치 기반 자체 배포 가능 | 데이터 주권 요구 |
| 학습 접근 | 비공개 | RL·SFT 절차 공개 | R1-Zero 15.6→71.0% |

| 운영 리스크 | 벤더 종속 | 라이선스·보안 자체 책임 | 모델카드·취약점 점검 |

> 요약: DeepSeek-R1은 데이터 주권과 비용 통제 선택지를 제공하지만, 자체 서빙·보안·라이선스 책임이 조직에 이전됨.

## Ⅴ. 실무 적용 및 결론

**적용 방안 3개:**
1. 사내망 수학·코딩 QA는 R1 distill 32B/70B를 vLLM으로 배포하고 AIME·사내 테스트셋 기준 pass@1 측정
2. 원본 대형 모델은 GPU 메모리·TP/EP 병렬 요구량을 산정하고, 월 호출량 10만건 이상일 때 API 대비 TCO 비교
3. 공개 모델 도입 전 라이선스, 학습 데이터 이슈, 프롬프트 인젝션·유해 출력 평가를 배포 게이트로 적용

**결론 (2줄):**
- 기술사 판단: 데이터 반출 금지·온프레미스 요구가 있으면 R1 계열, SLA와 운영 단순성이 우선이면 폐쇄형 API를 선택함.
- 향후 방향: 공개 reasoning model은 distillation·양자화·MoE 서빙 최적화로 기업 내부 AI 플랫폼에 편입됨.
