## 미리 알고가기

- 딥시크 R1 ($DeepSeek-R1$): 중국의 AI 스타트업 DeepSeek가 개발하여 2025년 초 공개한 오픈소스 계열의 초고성능 추론 특화 LLM임
- 지식 증류 ($Distillation$): 거대 파라미터 모델이 생성해 낸 고품질 추론 텍스트 코퍼스를 데이터셋 삼아, 상대적으로 작은 경량 모델(예: Llama 8B/70B)을 학습시켜 지식을 이전하는 기술임
- 혼합 전문가 아키텍처 ($MoE$): 신경망의 모든 노드를 다 깨우지 않고, 매 입력 토큰마다 가장 유망한 소수의 전문가($Expert$) 서브 모델 네트워크만 활성화하여 연산량을 절감하는 아키텍처임
- 다중 헤드 잠재 어텐션 ($MLA$): 가중치 행렬을 저차원 잠재 공간으로 압축 투영하여 $KV$ 캐시 점유 공간을 획기적으로 축소하는 DeepSeek의 핵심 어텐션 기술임

## Ⅰ. 개요

- **정의/개념**: DeepSeek-R1은 폐쇄형 API 중심의 추론 모델 시장에 대응하여, MoE(Mixture of Experts)와 MLA(Multi-head Latent Attention) 아키텍처를 근간으로 자가 검증 강화학습을 수행해 독보적인 가성비를 달성하고 모델 가중치와 파생 모델을 전면 오픈소스로 공개한 추론 특화 LLM임
- **배경/필요성**: 최고 사양의 지능 모델들이 미국의 특정 기업들(OpenAI 등)에 사유화되고 독점화되는 '지능 주권' 우려가 팽배해진 환경에서, 개별 기업이 프라이빗 클라우드에 직접 올릴 수 있는 완전 통제형 고성능 추론 모델의 확보가 필요해지며 탄생함

## Ⅱ. 특징

- 순수한 순수 RL(알고리즘적 무작위성)만을 사용해 규칙 기반 보상만으로 모델 스스로 "생각하고 정정하는" 추론 패턴을 자가 체득하게 만든 R1-Zero 학습 기법을 발전시킴
- 671B(활성 37B) 규모의 초대형 원본 모델 외에도, Llama나 Qwen 기반의 8B/14B/32B/70B 규격으로 지식을 증류한 경량화 라인업($Distilled$ $Variants$)을 제공함
- MoE 설계 덕분에 추론 연산 시 실제 GPU 클록 소모와 서빙 전력량이 전통적 고밀도($Dense$) 모델 대비 수 분의 일 수준으로 극히 저렴함

## Ⅲ. 종류 및 비교

| 판단 기준 | 독점 폐쇄형 모델 (o3 / Claude 3.5 Sonnet) | DeepSeek-R1 원본 (671B MoE) | R1 Distilled 모델 (경량 8B/32B/70B) |
|:---|:---|:---|:---|
| **라이선스 및 배포** | 사유지적 API 전용 (상용 서비스 종속) | 가중치 완전 공개 (온프레미스 적재 가능) | 가중치 완전 공개 (온디바이스 가동 가능) |
| **GPU 서빙 하드웨어** | 공급사가 직접 통제 (인프라 무관) | 최소 $8 \times$ H100 GPU 급 장비 요구 | 1~2장의 범용 GPU 카드로 구동 가능 |
| **추론 속도 대비 단가** | 비쌈 (호출 토큰 비례) | 매우 저렴함 (MoE 구조적 효율성) | 최상급 가성비 (자원 최소화) |
| **데이터 프라이버시** | 외부 API 전송으로 누출 우려 있음 | 내부 인프라에 가두어 유출 원천 차단 | 디바이스 단에서 연산하여 완벽 보안 |

> 요약: 독점 모델은 관리의 편리성에, R1 원본은 최고 성능의 로컬 온프레미스 구성에, R1 증류 모델은 저비용의 에지/온디바이스 서빙에 최적임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| $RL$ 기반 정책 코어 | Cold-Start 데이터 주입과 다단계 RL을 거쳐 생각의 일관성과 정합성을 획득한 인지 레이어임 |
| $MLA$ 투영 필터 | $K, V$의 차원을 극도로 압축해 VRAM 병목을 완화하고 단일 카드 내 서빙 토큰량을 늘리는 가속 필터임 |
| $MoE$ 게이팅 네트워크 | 들어온 단어마다 64개 전문가 중 단 2개 전문가 네트워크로만 연산 흐름을 분배하는 스위치임 |
| 증류 파생 라인업 | R1이 뱉어낸 사고 과정 데이터를 삼켜, 작은 크기에서도 높은 정답률을 내게 훈련된 경량 신경망임 |

```text
[ DeepSeek-R1 지능 가속 구조 ]
Token -> [MLA (VRAM saving)] -> [MoE Gate: Select 2/64 Experts] -> [Hidden Reasoning Engine] -> Output
- MLA와 MoE 기술을 극한으로 엮어 연산과 메모리 효율을 양방향에서 동시에 달성함
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 프라이빗    | --> | MLA/MoE 엔진 | --> | 증류 경량화 | --> | 지식주권 기반|
| 인프라 구축 |     | 자원 절감가동|     | 연동배포    |     | 안전서빙 및QA|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **인프라 셋업** — R1 가중치 파일을 내려받아 내부 폐쇄망 가상 머신에 적재하고, vLLM 등의 서빙 엔진과 통합 연동함
2. **어텐션 압축** — $MLA$ 연산을 실행하여 토큰 폭증 시 발생하는 키-밸루 저장소의 물리적 크기를 획기적으로 정돈함
3. **전문가 스위칭** — $MoE$ 게이팅 네트워크를 통해 입력 토큰별로 가장 똑똑한 뉴런 서브 그룹만 작동시켜 전력과 대역폭을 보존함
4. **증류식 전파** — 로컬 기기의 가용 VRAM 용량에 따라 $8B$ 또는 $32B$ 증류 모델을 교차 선택하여 지능의 밀도를 경량화 배포함

## Ⅵ. 실무 적용 및 유의점

1. R1 671B 원본 모델을 온프레미스로 서빙하려면 엄청난 수의 GPU 장비 클러스터링과 다중 노드 텐서 병렬화 통신망이 결합되어야 하므로, 자원 한계가 뚜렷한 엔터프라이즈 환경에서는 Llama 기반의 'R1 70B Distilled' 모델을 우선 채택하고 토큰 처리량($Throughput$)과 정확도를 저울질해야 함
2. 오픈소스 라이선스에 따른 상업적 이용 한계 조항이나 중국계 모델의 규제 거버넌스 부합성을 사전에 면밀히 확인해야 하며, 사내 보안 정책상 '개인정보 비식별화 필터'를 API 게이트웨이 전단에 의무 탑재하고 데이터 유출 감지 모니터링을 상시 수행해야 함

## Ⅶ. 결론

- DeepSeek-R1은 독점 자본 중심의 지능 장벽을 허물고 엔터프라이즈에게 인프라적 주권과 극강의 서빙 가성비를 안겨준 혁신적인 오픈 이정표이며, 설계자는 MLA/MoE 연산 특성의 이해와 로컬 서빙 최적화 튜닝을 통해 고효율 프라이빗 AI 플랫폼을 구현해야 함
