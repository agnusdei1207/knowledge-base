## 미리 알고가기

- AI PC ($AI$ $PC$): 클라우드 서버의 지능에 기댈 필요 없이, 기기 내부의 $CPU, GPU, NPU$ 이기종 컴퓨팅 리소스를 조율하여 로컬 온디바이스 AI를 상시 가동하는 개인용 퍼스널 컴퓨터임
- $TOPS$ ($Tera$ $Operations$ $Per$ $Second$): 1초당 1조 번의 연산을 수행할 수 있는 처리 속도로, 온디바이스 NPU 성능을 비교 측정하는 표준 수치 지표임
- 코파일럿 플러스 ($Copilot+$): 마이크로소프트($MS$)가 제정한 규격으로, 로컬 NPU 성능이 최소 $40$ TOPS 이상이고 $16$GB 이상의 LPDDR5 RAM을 충족해야 획득하는 최신 AI PC 표준 브랜드임
- 의미론적 인덱서 ($Semantic$ $Indexer$): 로컬 파일의 텍스트, 이미지 메타데이터를 벡터화하여 로컬 디스크 상에서 즉각적인 자연어 검색이 가능하게 돕는 백그라운드 엔진임

## Ⅰ. 개요

- **정의/개념**: AI PC는 CPU, GPU 외에 인공지능 연산 특화 프로세서인 NPU(Neural Processing Unit)를 실리콘 칩 레벨에 함께 패키징하고, 운영체제($OS$) 단에 로컬 의미론적 인덱서와 소형 모델 런타임을 기본 탑재하여 개인화 생산성 기능을 로컬에서 완결 처리하는 차세대 퍼스널 컴퓨터 플랫폼임
- **배경/필요성**: 기존에는 모든 코파일럿 등의 생산성 지능을 클라우드 서버와의 통신에 의존하여, 사내 비공개 기획안이나 개인 일기 유출 우려와 통신 요금 부담이 커졌으므로, 사용자의 책상 위에서 즉시 작동 가능한 프라이빗 지능 가속 플랫폼이 필수 요구되며 도입됨

## Ⅱ. 특징

- 마이크로소프트의 $Copilot+$ 규격에 따라, 최소 $40$ TOPS 이상의 독자적 NPU 연산 스펙을 획득하여 실시간 이미지 로컬 생성(Cocreator) 등을 매끄럽게 가동함
- CPU(순차 제어), GPU(고성능 그래픽), NPU(저전력 매트릭스 곱셈)가 워크로드 성격에 따라 자원을 자동 분할 배정하여 발열과 소비 전력을 획기적으로 낮춤
- 사용자가 과거 PC에서 작성했던 문서나 웹 서핑 이력의 텍스트, 화면 스냅샷을 백그라운드 벡터 인덱서로 상시 저장해 두어, 즉각적인 로컬 타임라인 조회가 가능함

## Ⅲ. 종류 및 비교

| 판단 기준 | 전통적인 범용 PC | AI PC (Copilot+ 표준 준수) | 클라우드 가상 단말 (VDI) |
|:---|:---|:---|:---|
| **NPU 하드웨어** | 없음 (CPU, GPU 조합) | 필수 탑재 (최소 $40$ TOPS 이상) | 없음 (가상 환경 내 CPU 위주) |
| **대표적인 기능** | 일반 오피스, 웹 서핑, 게이밍 | 실시간 로컬 타임라인 검색, 오프라인 이미지 보정 | 클라우드 애플리케이션 화면 전송 수신 |
| **네트워크 단절 영향** | 지장 없음 (로컬 프로그램 작동) | 지장 없음 (로컬 지능 가동 지속) | 작동 완전 불능 (클라우드 단절 시 무력화) |
| **로컬 개인정보 보안** | 우수함 | 극도로 우수함 (로컬 벡터 DB 적재) | 보안 감사 필요 (서버 전송 로그 추적) |

> 요약: 전통 PC는 일반 연산에, AI PC는 사생활 침해 걱정 없는 로컬 개인 지능형 조력자 가동에, VDI는 클라우드 중앙 통제에 적합함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 이기종 가속 SoC | 단일 실리콘 다이 안에 CPU, GPU, 고출력 NPU를 병렬 접착한 원칩 패키지임 |
| $OS$ 통합 런타임 | Windows Copilot Runtime 등 OS의 가중치를 호출하고 API를 중재해 주는 시스템 계층임 |
| 로컬 벡터 데이터베이스 | 사용자의 문서, 회의 스냅샷 데이터를 벡터 임베딩하여 로컬 스토리지에 격리 보관하는 저장소임 |
| 생산성 앱 플러그인 | MS Office, Adobe 등 상용 앱들이 NPU 가속 명령을 직접 호출하여 동작을 연동하는 브리지임 |

```text
[ AI PC 하드웨어 및 OS 스택 토폴로지 ]
[ Productivity Apps ] ---> [ Windows Copilot Runtime / Semantic Indexer ]
                                    ↓ (ONNX / DirectML)
               [ CPU (Control) ] [ GPU (Render) ] [ NPU (Inference) ]
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 사용자 요구 | --> | 이기종 칩셋  | --> | 로컬 임베딩 | --> | NPU 병렬연산|
| 질의 유입   |     | 분배/라우팅  |     | 및 벡터조회 |     | 및 결과노출 |
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **질의 분석** — 오피스 프로그램이나 이미지 편집 앱에서 사용자가 지능형 리터칭이나 문서 요약을 실행함
2. **동적 스케줄링** — OS 스케줄러가 NPU 드라이버를 호출해 연산 작업 분량을 확인하고 전력 프로파일을 적용함
3. **로컬 데이터 병합** — 로컬 의미론적 인덱서가 사용자 드라이브에서 팩트 컨텍스트를 빠르게 캐내어 프롬프트 텐서에 융합함
4. **NPU 순방향 추론** — 메인 보드 상의 NPU 코어를 활용해 타일링 어텐션을 연산하고, 전송 오버헤드 없이 즉시 결과를 화면에 출력함

## Ⅵ. 실무 적용 및 유의점

1. 하드웨어 제조사(Intel, AMD, Qualcomm 등)마다 NPU 컴파일 드라이버 아키텍처가 달라 전용 최적화 코드가 깨질 수 있으므로, 반드시 Microsoft DirectML이나 ONNX 런타임 표준 매퍼를 활용해 앱을 패키징하고 모델 호환 테스트 통과율 지표로 일관성을 보장해야 함
2. 사용자가 AI PC를 도입한 후 체감 생산성 혜택을 체감하지 못해 구매 비용 낭비(TCO 상승)로 이어질 수 있으므로, 도입 전에 사내 '문서 실시간 로컬 요약', '회의록 로컬 전사 보조' 등 대표 사용 시나리오를 정의하고, 업무 시간 단축률($Task$ $Completion$ $Time$) 지표로 타당성을 검증해야 함

## Ⅶ. 결론

- AI PC는 기기의 중심을 단순 연산 깡통에서 언제나 나를 관찰하고 보조하는 프라이빗 비서 플랫폼으로 개조하는 지능형 컴퓨터의 완성판이며, 설계자는 칩셋 제조사별 파편화 문제를 극복하기 위해 OS 표준 런타임 가이드를 확립하고 실효성 있는 로컬 킬러 시나리오를 구비하여 보급 성공률을 확보해야 함
