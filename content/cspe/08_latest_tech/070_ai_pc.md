## 미리 알고가기

- AI PC는 CPU, GPU, NPU를 함께 활용해 로컬 AI 작업을 수행하도록 설계된 개인용 컴퓨팅 플랫폼임
- 운영체제 수준의 AI 기능과 애플리케이션 연동이 있어야 하드웨어 성능이 실제 사용자 가치로 연결됨
- 단순 스펙 경쟁보다 어떤 업무를 로컬에서 처리할 수 있는지가 도입 판단의 핵심임

## Ⅰ. 개요

- **정의/개념**: AI PC는 개인용 컴퓨터에 NPU를 포함한 이기종 연산 자원과 로컬 AI 실행 환경을 탑재해 생성형 AI와 개인화 보조 기능을 기기 내부에서 수행하는 차세대 PC 플랫폼임
- **배경/필요성**: 클라우드 기반 생성형 AI는 비용과 지연과 개인정보 전송 문제가 있으므로, 일상 업무를 로컬에서 처리하고 필요한 경우에만 클라우드를 쓰는 개인용 AI 실행 기반이 필요함

## Ⅱ. 특징

- CPU, GPU, NPU가 작업 특성에 따라 역할을 분담해 응답성과 전력 효율을 조정함
- 문서, 메일, 회의록, 이미지 편집 같은 개인 생산성 작업을 로컬에서 처리해 프라이버시를 높임
- 운영체제와 애플리케이션이 AI 기능을 통합해야 실사용 가치가 발생하므로 생태계 성숙도가 중요함
- 무거운 생성 작업은 여전히 클라우드나 고성능 GPU에 의존할 수 있어 완전한 대체재는 아님

## Ⅲ. 종류 및 비교

| 판단 기준 | 전통 PC | AI PC | 클라우드 의존형 단말 |
|:---|:---|:---|:---|
| 로컬 AI 실행 | 제한적임 | 가능함 | 매우 제한적임 |
| 프라이버시 | 일반 수준 | 높음 | 상대적으로 낮음 |
| 네트워크 의존성 | 중간 | 낮음 | 높음 |
| 대표 가치 | 범용 컴퓨팅 | 개인화 생산성 AI | 중앙 집중형 서비스 사용 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Heterogeneous Compute | CPU, GPU, NPU가 업무별로 분담 실행되어 성능과 전력 효율 균형을 맞춤 |
| Local AI Runtime | 운영체제와 런타임이 모델 로딩, 가속기 선택, 권한 통제를 수행해 로컬 AI 기능을 실현함 |
| Personal Context Layer | 문서, 메일, 일정, 파일 시스템 같은 개인 데이터를 기기 안에서 활용해 개인화 품질을 높임 |
| Application Integration | 오피스, 브라우저, 개발도구, 편집도구가 AI 기능을 업무 흐름에 직접 연결함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 사용자 요청    | --> | 작업 분류/라우팅 | --> | 로컬 모델 실행  | --> | 결과 제공/클라우드 연계 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **사용자 요청 수신**: 텍스트, 음성, 문서 편집 같은 개인 업무 요청을 입력받음
2. **작업 분류 및 라우팅**: 경량 작업은 NPU, 그래픽 작업은 GPU, 복합 작업은 클라우드 연계를 선택함
3. **로컬 모델 실행**: 선택된 가속기와 런타임이 개인 데이터와 함께 추론을 수행함
4. **결과 제공 및 클라우드 연계**: 로컬 응답을 우선 제공하고 필요한 경우에만 외부 서비스를 호출함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 하드웨어만 강화하고 실제 업무 시나리오가 부족하면 사용자는 AI PC의 추가 가치를 체감하지 못할 수 있음
   - 해결방안: 문서 요약, 회의 정리, 코딩 보조 같은 핵심 시나리오를 우선 제공하고 feature adoption rate와 task completion time으로 가치를 검증함
2. 문제: 칩셋과 운영체제와 런타임이 벤더별로 달라 애플리케이션 호환성과 최적화 수준이 크게 흔들릴 수 있음
   - 해결방안: 표준 추론 API와 호환성 테스트 매트릭스를 운영하고 model compatibility pass rate와 performance regression으로 품질을 검증함
3. 문제: 장시간 로컬 추론은 발열과 배터리 소모를 키워 사용자 경험을 악화시킬 수 있음
   - 해결방안: 작업 라우팅과 전력 정책을 조정하고 sustained performance와 battery drain per hour로 운영 한계를 검증함

## Ⅶ. 적용 사례

- 오피스 문서 보조: 회의록 요약과 메일 초안을 로컬에서 생성함, 확인 지표는 task completion time과 feature adoption rate임
- 개발자 생산성 지원: IDE 내 코드 설명과 리팩터링 보조를 수행함, 확인 지표는 accepted suggestion rate와 latency임
- 사진 및 영상 편집: 생성형 보정과 객체 제거를 로컬에서 처리함, 확인 지표는 render time과 battery impact임

## Ⅷ. 결론

AI PC의 본질은 NPU가 붙은 PC가 아니라 개인 업무 데이터를 기기 안에서 활용해 생산성 기능을 안정적으로 실행하는 로컬 AI 플랫폼이라는 점임.
