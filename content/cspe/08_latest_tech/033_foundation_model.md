# 📖 【암기용】 개념 완전 이해

> 목적: Foundation Model을 처음 봐도 완벽히 이해하게 만든다.

## 한눈에
- **개요**: 대규모 데이터로 사전학습하여 다양한 다운스트림 태스크에 적응할 수 있는 범용 기반 모델
- **왜 필요한가**: 태스크마다 모델을 처음부터 학습하면 데이터·비용·시간이 태스크 수만큼 곱해짐. 하나의 기반모델을 미세조정하면 개발 비용이 1/10로 줄어듦.
- **핵심 직관**: "만능 반제품" — 한 번 크게 만들어 놓고, 용도에 맞게 마무리만 하는 모델.

## 깊이 이해
- **배경·문제의식**: Stanford HAI(2021)가 "Foundation Model"이라는 용어를 정의함. ImageNet 사전학습->전이학습이 Vision에서 성공한 패턴이 NLP(BERT·GPT)로 확장되고, 이제 멀티모달(텍스트+이미지+음성)까지 범위가 넓어짐.
- **작동 원리**: ① 자기지도학습(SSL)으로 대규모 비라벨 데이터 사전학습 -> ② 태스크별 미세조정(Full Fine-Tuning, LoRA, Adapter) 또는 프롬프트 튜닝으로 적응 -> ③ 평가·정렬 후 배포. 핵심은 사전학습에 비용의 90%+가 집중되고, 적응은 소량 데이터로 가능하다는 점.
- **비유**: 종합대학 졸업생(기반모델)이 어떤 직무에든 빠르게 적응하는 것. 고등학교만 나온 사람(태스크 특화 모델)은 특정 일은 잘하지만 다른 일에 재학습이 필요함.
- **구체 예시**: GPT-4(텍스트), CLIP(이미지-텍스트), Whisper(음성), SAM(이미지 세그멘테이션)이 각각 도메인별 Foundation Model. LLaMA-3 70B 사전학습 비용 약 $2M, LoRA 미세조정 비용 $200.
- **흔한 오해·주의점**: "Foundation Model = LLM"이 아님. Vision(SAM), 음성(Whisper), 로보틱스(RT-2) 등 모달리티별로 존재. 또한 사전학습 데이터 편향이 모든 다운스트림에 전파되는 "동질화 리스크"가 있음.

## 연결 개념
- Transfer Learning — Foundation Model의 이론적 기반
- LLM — 텍스트 도메인의 대표 Foundation Model
- LoRA/PEFT — 효율적 미세조정 기법


# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: Foundation Model은 대규모 자기지도학습으로 범용 표현을 획득한 뒤, 소량 적응으로 다양한 태스크를 수행하는 모델임.
> 2. **가치**: 사전학습 1회 투자로 N개 태스크 적응 비용을 1/10 이하로 절감함.
> 3. **판단 포인트**: 사전학습 데이터 편향의 다운스트림 전파(동질화 리스크)와 모델 라이선스·주권이 도입 결정의 핵심임.


## Ⅰ. 개요 및 필요성

Foundation Model은 대규모 비라벨 데이터로 사전학습한 범용 모델임. 태스크마다 개별 모델을 학습하던 방식의 비용·시간 한계를 해소하고, 미세조정만으로 다양한 다운스트림에 적응함. 기업의 AI 전략에서 "만들 것인가, 가져다 쓸 것인가"의 판단 기준이 됨.


## Ⅱ. 구조 및 구성요소

```text
             Foundation Model 구조
  사전학습      적응 계층       다운스트림 태스크
  (SSL)      (LoRA/Adapter)   (분류/생성/검색)
  대규모      소량 데이터      태스크별 평가
  비라벨      저비용 학습      배포·모니터링
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 사전학습 엔진 | SSL(NTP·MLM·MAE)로 범용 표현 학습 | GPU 수천 장, 비용 $2M~$100M |
| 적응 계층 | LoRA·Adapter·프롬프트 튜닝 | 파라미터 0.1%만 학습, 비용 1/1000 |
| 평가 파이프라인 | 벤치마크·인간 평가·편향 테스트 | MMLU·HumanEval·bias audit |
| 서빙 인프라 | 양자화·분산추론·KV Cache | 지연 p95 ≤1s, 가용률 99.9% |

> 요약: Foundation Model은 사전학습->적응->평가->서빙의 4단 구조이며, 사전학습에 비용 90%가 집중됨.


## Ⅲ. 동작원리 및 흐름도

```text
대규모 비라벨 데이터 -> SSL 사전학습 -> 범용 가중치
    -> 태스크 데이터 + LoRA 적응 -> 평가 -> 배포·모니터링
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 데이터 수집·정제(수조 토큰/수억 이미지) | 중복 제거율, 유해 콘텐츠 필터율 |
| 2 | SSL 사전학습(NTP·MAE 등) | Loss 수렴, 벤치마크 기준선 달성 |
| 3 | 태스크 적응(LoRA·Adapter, 수시간) | 태스크 정확도, 과적합 여부 |
| 4 | 배포·모니터링(드리프트·편향 감시) | 정확도 변동 ≤2%, 편향 지표 |

> 요약: 사전학습은 1회 대규모 투자, 적응은 태스크마다 소량·저비용으로 반복하는 "1:N" 구조임.


## Ⅳ. 특징

| 구분 | 태스크 특화 모델 | Foundation Model | 수치·판단 포인트 |
|:---|:---|:---|:---|
| 학습 비용 | 태스크당 $50K+ | 사전학습 1회 $2M, 적응 $200 | N개 태스크 시 N×$50K vs $2M+N×$200 |
| 데이터 요구 | 태스크별 대량 라벨 | 사전학습 비라벨, 적응 소량 | 라벨링 비용 제거 |
| 범용성 | 단일 태스크 | 멀티태스크·멀티모달 | 모달리티 확장 가능 |
| 리스크 | 개별 편향 | 동질화 리스크(편향 전파) | 데이터 감사·편향 테스트 필수 |

> 요약: Foundation Model은 "1회 투자, N회 활용"으로 비용 효율을 극대화하지만, 사전학습 편향의 전파를 감사해야 함.


## Ⅴ. 실무 적용 및 결론

**적용 방안 3개:**
1. 모델 선택: 오픈소스(LLaMA-3, Mistral) vs 상용 API(GPT-4, Claude)를 데이터 주권·비용·성능으로 비교 평가
2. 효율 적응: LoRA(r=16, alpha=32)로 도메인 미세조정, 학습 파라미터 0.1%, A100 1장 4시간 내 완료
3. 거버넌스: 사전학습 데이터 라이선스 확인, 편향 감사(Fairness Metric), 모델 카드(Model Card) 공개

**결론 (2줄):**
- 기술사 판단: 데이터 주권 요구 시 오픈소스 FM+온프레미스, 빠른 도입 시 상용 API를 선택함.
- 향후 방향: 멀티모달 FM(GPT-4o, Gemini)·도메인 특화 FM(BioGPT, BloombergGPT)으로 범용과 전문의 양방향 발전.


### 🔀 문제 유형별 목차 전환 (이 키워드 출제 시)

| 유형 | 문제 신호어 | Ⅲ 강조 | Ⅳ 강조 |
|:---|:---|:---|:---|
| 포괄형 | "설명하시오", "기술하시오" | 사전학습->적응 전체 흐름 | 태스크 특화 모델 대비 장단점 |
| 요구사항 명시형 | "도입 전략을 제시하시오", "비교하시오" | LoRA·Adapter 적응 방안 | 오픈소스 vs 상용 선택 기준표 |
