# 📖 【암기용】 개념 완전 이해

## 한눈에
- **정의**: 수백억 원을 들여 만든 상용 AI 모델(블랙박스 API)에 수많은 질문(입력)을 던지고 그 대답(출력)을 모은 뒤, 이 문답 세트를 학습 데이터로 삼아 **원본과 성능이 똑같은 짝퉁 모델(대체 모델, Substitute Model)을 공짜로 만들어버리는 지식재산(IP) 도둑질 공격**.
- **필요성**: OpenAI나 Google이 GPT-4를 만들 때 엄청난 돈과 최고급 데이터를 쏟아부음. 그런데 해커가 월 20달러짜리 API 계정 하나 파서 GPT-4에 100만 번 질문을 던진 후, 그 답변을 모아 자기 집 컴퓨터에서 학습시키면 성능이 비슷한 '짝퉁 GPT'를 거저먹음. 기업의 핵심 자산이 증발하는 걸 막기 위한 필수 방어 개념.
- **핵심 직관**: 과외 선생님 답변 베끼기. 아주 비싼 쪽집게 과외 선생님(원본 모델)이 있음. 선생님의 머릿속(알고리즘 가중치)은 볼 수 없음(블랙박스). 그래서 학생(해커)이 문제집 1만 권을 선생님께 계속 물어봄(API 질의). 선생님이 정답을 말하면 다 노트에 적음(응답 수집). 그 노트를 달달 외워서 자기가 쪽집게 학원을 차려버림(짝퉁 모델 학습).

## 깊이 이해
- **배경**: AI 모델의 가중치(Weight)를 직접 해킹해 빼내는 건 너무 어려움(서버를 털어야 하니까). 하지만 MLaaS(Machine Learning as a Service) 환경에서 API는 누구에게나 열려 있음. 이 합법적인 API 채널을 통해 수만 건의 입출력 쌍(I/O Pairs) 데이터를 스크래핑하여 지식을 훔치는 '모델 도용(Model Stealing)' 기술이 고도화됨.
- **작동 원리 (대체 모델 학습 파이프라인)**:
  1. **입력 생성 (Query Generation)**: 해커가 경계값(결과가 바뀔락 말락 하는 미세한 차이의 사진이나 텍스트)을 교묘하게 변형하며 대량의 입력 데이터를 만듦.
  2. **API 질의 (API Querying)**: 타겟 모델(예: 유료 번역 API, 사진 판독 API)에 입력을 던짐.
  3. **응답 수집**: 타겟 모델이 뱉어내는 예측 결과(분류 라벨)와 **확률값(Confidence Score, 예: 개 99%, 고양이 1%)**을 모조리 저장함. (이 확률값이 핵심 힌트가 됨).
  4. **대체 모델 훈련 (Substitute Model Training)**: 수집한 데이터셋(입력+타겟의 응답)으로 자기만의 로컬 모델을 지도학습(Supervised Learning)시킴. 원본과 동작(Decision Boundary)이 거의 똑같아짐.
- **구체 예시**: 유명 기업의 '유해 이미지 필터링 AI'. 해커가 개, 고양이, 무기, 포르노 사진 등 무작위 사진 100만 장을 이 API에 던지고 결과(통과/차단 및 신뢰도 점수)를 기록함. 이 데이터를 바탕으로 오픈소스 ResNet 모델을 재학습시킴. 며칠 만에 수억 원짜리 유해 필터링 AI와 95% 일치하는 짝퉁 모델을 완성해 경쟁사에 팔아버림.
- **흔한 오해/주의점**: "API 호출 횟수 제한(Rate Limit) 걸면 막히는 거 아님?" $\rightarrow$ 해커들은 좀비 PC 1만 대와 수천 개의 계정(IP 분산)을 동원해 아주 천천히 분산 질의를 하므로, 단순 방화벽이나 Rate Limit만으로는 의도를 파악하고 막기 매우 어려움.

## 연결 개념
- **Model Inversion (모델 역산/역추론)**: 모델 추출이 'AI의 뇌(성능)' 자체를 훔치는 거라면, 모델 역추론은 'AI가 과거에 학습했던 원본 데이터(개인정보 등)'를 끄집어내는 공격.
- **Watermarking (워터마킹)**: 모델 추출을 막기 힘들다면, "이 짝퉁 모델이 내 걸 베낀 거다!"라고 법정에서 증명하기 위해 원본 모델의 답변에 교묘한 오타나 특정 패턴(워터마크)을 심어두는 방어 기법.
- **Data Poisoning (데이터 오염)**: 공격자가 모델을 망가뜨리는 것. 모델 추출(도둑질)과는 목적이 다름.

# 📝 【답안용】 시험 답안 템플릿
## 핵심 인사이트 (3줄 요약)
- **본질**: 클라우드 환경에서 블랙박스 형태로 제공되는 상용 ML API(MLaaS)에 대량의 의도된 입력(Query)을 주입하고, 그 출력(Label/Confidence)을 수집하여 타겟 모델의 의사결정 경계(Decision Boundary)와 기능이 동일한 대체 모델(Substitute Model)을 복제하는 적대적 해킹 기법.
- **가치**: 모델 구축에 투입된 막대한 학습 데이터, 컴퓨팅 자원, 하이퍼파라미터 튜닝 노하우 등 기업의 핵심 지식재산(Intellectual Property)이 침해되는 경제적 타격뿐만 아니라, 복제된 모델을 통한 화이트박스 기반의 2차 적대적 공격(Adversarial Attack)을 촉발하는 트리거가 됨.
- **판단 포인트**: 이 공격은 정상적인 API 호출로 위장하므로 완벽한 차단이 불가능하며, API 응답의 정보량 최소화(Confidence Masking), 쿼리 패턴 이상 탐지, 그리고 도용 발생 시 사후 법적 추적을 위한 모델 워터마킹(Watermarking)이 복합적으로 적용되어야 함.

## Ⅰ. 개요 및 필요성
- **정의**: 기계학습 서비스(MLaaS)의 추론 API를 쿼리하여 입력-출력 데이터 쌍을 수집한 뒤, 이를 바탕으로 타겟 모델의 동작을 모방하는 대체 모델을 구축하여 원본 모델의 기능적 등가성을 훔치는 공격.
- **배경**: AI 모델 자체의 가중치 파일(Weight File) 보안은 TEE(신뢰실행환경) 등으로 철저히 보호되고 있으나, 비즈니스를 위해 개방해 둔 퍼블릭 추론 API 채널이 모델 탈취의 새로운 백도어로 악용됨.
- **필요성**: 기업의 AI R&D 투자 회수를 위협하는 지식재산 침해 방어 및 생성형 AI 모델(OpenAI 등)의 약관 위반(경쟁 모델 훈련 금지) 행위에 대한 기술적 통제 수단 확보.

## Ⅱ. 모델 추출 공격의 3단계 파이프라인
공격자의 지식 탈취 메커니즘.
1. **탐색 (Query Generation)**:
   - 무작위 노이즈 주입, 적대적 예제(Adversarial Examples), 또는 액티브 러닝(Active Learning) 기법을 사용하여, 타겟 모델의 결정 경계를 가장 잘 파악할 수 있는 고효율의 입력 쿼리(데이터) 세트를 생성함.
2. **수집 및 질의 (Execution)**:
   - 생성된 입력값을 타겟 API에 전송하여 예측 라벨(Label)과 **확률 벡터(Softmax, Confidence Score)**를 수집. (확률 벡터는 모델의 확신도를 보여주는 핵심 정보로, 대체 모델 훈련의 결정적 단서가 됨).
3. **훈련 및 복제 (Substitute Training)**:
   - 수집한 (입력 - 예측값) 쌍을 사용하여 로컬에서 자신만의 딥러닝 모델(Substitute Model)을 학습. 수만 번의 반복을 통해 원본 블랙박스 모델과 거의 일치하는 함수(기능) 근사치를 달성함.

## Ⅲ. 공격 유형 및 특징 (추출 목적에 따라)
| 공격 유형 | 공격 목적 및 원리 | 피해 강도 및 특징 |
|:---:|:---|:---|
| **기능 복제**<br>(Functionality Extraction) | 원본 모델과 정확도(Accuracy) 및 동작 방식이 똑같은 짝퉁 서비스 구축. | 경제적 피해 막심. API 과금 회피를 위해 자체 서비스로 돌려버림. |
| **수학적 근사치 추출**<br>(Fidelity Extraction) | 정확도가 낮더라도, 원본 모델이 실수하는 패턴(오답)까지 똑같이 복제하는 완벽한 쌍둥이 수학 공식 구축. | 향후 원본 모델을 속이기 위한 백도어/적대적 공격(Evasion)의 실험장으로 악용됨. |
| **하이퍼파라미터 추출**<br>(Hyperparam Stealing)| 모델의 아키텍처(층 수, 노드 수)나 정규화 기법 등의 튜닝 비밀을 유추해 냄. | 알고리즘 노하우 유출. |

## Ⅳ. 모델 추출 방어 아키텍처 (Defense-in-Depth)
API 가시성 축소와 비정상 패턴 탐지의 결합.
1. **응답 정보량 최소화 (Information Truncation / Rounding)**:
   - 공격의 가장 큰 힌트인 Softmax(확률값) 출력을 숨김.
   - 예: "개 99.123%, 고양이 0.877%"라고 자세히 주지 않고, **소수점 반올림**을 하거나 오직 **Top-1 결과("개")** 라벨만 텍스트로 단순 반환.
2. **이상 쿼리 탐지 (Anomaly Detection)**:
   - 특정 계정(또는 분산된 IP)이 짧은 시간 내에 인간의 정상적 사용 패턴과 다른 기하학적/적대적 노이즈가 섞인 데이터를 대량 질의(Active Learning 패턴)하는 행위를 머신러닝으로 탐지 후 차단(Rate Limiting & Ban).
3. **모델 워터마킹 (Model Watermarking)**:
   - 타겟 모델을 학습시킬 때, 특정 기괴한 입력(예: 노이즈 낀 자동차 사진)에 대해서 엉뚱하게 "비행기"라고 대답하도록 비밀 백도어(워터마크)를 심어둠.
   - 나중에 짝퉁 모델을 검사할 때 이 사진을 넣어 "비행기"라고 대답하면 빼박 표절(도용) 증거로 법정 제출.

## Ⅴ. 실무 적용 및 결론
- **판단 지표**: API 사용자별/세션별 쿼리 분포 다형성(Diversity) 지수, 추론 API의 Softmax 반환 자리수 제한 여부, 워터마크 삽입을 통한 모델 소유권(Ownership) 증명률.
- **실무 설계**: 클라우드 기반 '금융/신분증 위변조 판독 API' 서비스 기업 B사. 건당 과금 수익 모델임. 경쟁사가 MLaaS API를 악용해 판독 로직을 추출(Model Extraction)하려는 징후 포착(단기간에 10만 건의 노이즈 섞인 신분증 이미지 질의 폭주). 즉각 방어책 가동. 1) API 응답에서 '판독 확신도(Confidence Score %)' 제거하고 오직 '정상/위조' True/False 두 값만 반환하도록 응답 최소화(Truncation) 적용. 2) 입력 이미지들의 픽셀 변화량(Gradient)을 계산하여 봇(Bot)의 경계 탐색(Boundary Exploration) 패턴으로 의심될 경우 CAPTCHA 인증 강제 및 IP 차단 적용. 성공적으로 핵심 IP 유출 방어 및 수익 보호.
- **결론**: 모델 추출 공격은 지식재산 탈취를 넘어 생태계의 붕괴를 초래하는 중대한 경제적 위협이다. AI 서비스 제공자는 "고객에게 유용한 API 응답 정보(Confidence)"와 "해커에게 퍼주는 훈련 데이터 힌트" 사이의 아슬아슬한 밸런스(Utility-Privacy Trade-off)를 정밀하게 통제하는 방어적 MLaaS 아키텍처를 설계해야 한다.

### 🔀 문제 유형별 목차 전환
- **Ⅱ·Ⅲ 강조 (개념/원리형)**: 모델 추출 공격 시, 딥러닝 결정 경계(Decision Boundary)를 가장 효율적으로 근사화하기 위해 사용되는 Active Learning의 불확실성 샘플링(Uncertainty Sampling) 기반 쿼리 최적화 수학적 원리.
- **Ⅴ·Ⅵ 강조 (실무/설계형)**: 모델 도용을 사후에 법적으로 입증하기 위해 딥러닝 모델의 가중치(Weight)나 추론 로직 내부에 소유권 정보를 각인하는 'White-box 및 Black-box 워터마킹' 적용 기술적 아키텍처 중심 서술.
