## 미리 알고가기

- 추측 디코딩 ($Speculative$ $Decoding$): 소형의 초안 모델이 후보 토큰 스트림을 빠르게 생성하고, 대형의 본 모델이 이를 병렬 검증하여 채택 여부를 일괄 결정하는 디코딩 가속 기술임
- 초안 모델 ($Draft$ $Model$): 매개변수가 매우 작아(예: $1B \sim 7B$) 매우 빠른 응답 토큰 생성이 가능한 보조 모델임
- 대상 모델 ($Target$ $Model$): 최종 서비스 품질을 보증하는 고성능 초대형 타깃 LLM임
- 수용 확률 ($Acceptance$ $Rate$): 소형 초안 모델이 내놓은 토큰들 중 타깃 모델이 거부하지 않고 수용하여 통과시킨 비율임

## Ⅰ. 개요

- **정의/개념**: Speculative Decoding은 추론 속도가 빠른 초안 모델($Draft$ $Model$)이 먼저 여러 개의 미래 토큰들을 연속 추측하여 임시 배열을 구성해두면, 대형의 타깃 모델($Target$ $Model$)이 단 한 번의 순방향 연산으로 그 배열의 확률 분포를 병렬 확인하여 일치하는 유효 토큰들을 통째로 일시 채택하는 추론 가속 기법임
- **배경/필요성**: 기존의 자기회귀($Autoregressive$) LLM은 토큰을 매 시점마다 1개씩 순차 생성하여 GPU 연산 장치의 대역폭 병목(Memory-bound)을 유발하고 응답을 지연시키므로, 이론적 수학 품질의 손상 없이 생성 속도 장벽을 돌파하고자 고안됨

## Ⅱ. 특징

- 대형 타깃 모델을 경량화(양자화, 지식 증류)하여 원본의 지능 품질을 희석하지 않고, 디코딩 연산의 배치 기하학만을 활용해 정밀도 100% 동일한 출력을 보존함
- 초안 모델이 생성한 $N$개의 단어 시퀀스에 대해 타깃 모델이 동시에 어텐션을 연산하므로, 기존 대비 초당 토큰 생성 수($Tokens/Sec$)를 최대 $2 \sim 3$배까지 가속화함
- 초안 모델의 예측 일치율(수용율, $Acceptance$ $Rate$)이 높을수록 가속 효과가 극대화되며, 일치가 깨지는 첫 단어부터는 안전하게 롤백($Fallback$)함

## Ⅲ. 종류 및 비교

| 판단 기준 | 일반 자기회귀 생성 (Standard) | 보조 모델 추측 디코딩 (Draft-based) | 자가 추측 디코딩 (Self-Speculative / Medusa) |
|:---|:---|:---|:---|
| **가속 장치 구성** | 없음 | 타깃 모델 대비 아주 작은 소형 모델 연동 | 단일 모델 헤드 끝단에 예측 MLP 헤드 증설 |
| **추가 VRAM 점유** | 기준선 | 있음 (두 개의 모델 가중치를 동시 적재) | 매우 적음 (몇 개의 FFN 레이어만 증설) |
| **수용 거절 시 복구** | 무관 | 어긋난 지점 이후 즉시 폐기 및 롤백 | 어긋난 분기 이후 가지치기 및 복구 |
| **품질 동질성** | 100% | 100% 동질 (수학적 분포 동일) | 구현에 따라 근사 오차 발생 가능 |

> 요약: 일반형은 인프라가 단순하고, 보조 모델형은 완벽한 수학적 정합성을 가지며, 자가 추측형(Medusa)은 추가 모델 탑재의 메모리 오버헤드를 회피함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 초안 모델 ($Draft$) | 가벼운 파라미터로 미래의 단어 조각(예: 5토큰 미리 생성)을 예측해 내는 소형 엔진임 |
| 타깃 모델 ($Target$) | 초안 모델의 예측물들을 단일 배치($Batch$)로 묶어 동시에 어텐션 점수를 판정하는 본체 신경망임 |
| 수용 판정 슬라이서 | 각 위치별 토큰 확률 분포를 분석하여 수용 여부를 판정하고 거부 시점부터 잘라내는 필터임 |
| $KV$ 캐시 롤백 어댑터 | 반려된 오답 토큰에 해당하는 KV 캐시 메모리 대역을 순식간에 날려 이전 상태로 원상 복구하는 포인터임 |

```text
[ Speculative Decoding 연산 매커니즘 ]
1. Draft Model -> Generates: "We" "must" "be" "careful"
2. Target Model -> Checks in Parallel -> Accept: [We] [must] [be] (Reject: "careful" -> Replace with "safe")
3. Result -> Instantly Accepts 3 Tokens and appends 1 corrected Token in 1 Step.
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 초안 토큰   | --> | 타겟 모델    | --> | 확률비교 및 | --> | 승인구역 캐시|
| N개 고속예측|     | 병렬 검증연산|     | 거부단어 롤백|     | 확정 및 fallback|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **초안 배출** — 대화 컨텍스트를 소형 초안 모델에 주입하여, 앞으로 나올 가능성이 높은 토큰 배열(예: 5개 단어)을 극도로 빠르게 인출함
2. **동시 검산** — 인출된 단어 시퀀스를 타깃 모델의 멀티 쿼리 어텐션 배치에 통째로 태워, 각 위치별 단어가 튀어나올 확률을 한 번에 연산함
3. **수용 가부 판정** — 타깃 모델의 확률분포와 초안 모델의 샘플링 확률을 통계 검사(예: $Acceptance$ 조건)하여 일치가 지속되는 노드까지 일괄 채택함
4. **상태 동기화** — 최초의 불일치 노드가 식별되면 그 뒤의 모든 예측 단어는 버리고 타깃 모델이 예측한 새로운 단어로 대체한 뒤 캐시를 롤백함

## Ⅵ. 실무 적용 및 유의점

1. 초안 모델의 지능이 너무 낮아 수용율이 20~30% 이하로 떨어지면, 초안 생성에 든 시간과 타깃 모델의 검산/롤백에 따른 병목이 겹쳐 오히려 단일 서빙보다 속도가 느려지므로, 반드시 대상 도메인 언어 코퍼스로 별도 파인튜닝된 밀접한 초안 모델을 매칭하고 수용율 지표를 실시간 측정해야 함
2. GPU 한 장에 대형 모델과 초안 모델의 가중치를 동시에 모두 적재해야 하므로 VRAM 용량이 부족한 경우 메모리 스와핑 병목이 생길 수 있어, 추가 물리 모델이 불필요한 '자가 추측 디코딩($Self-Speculative$ $Decoding$)'이나 '메두사($Medusa$)' 기법의 탑재를 검토하고 VRAM 마진율을 모니터링해야 함

## Ⅶ. 결론

- Speculative Decoding은 자기회귀 추론의 순차적 시간 장벽을 대안 초안 검증과 병렬화 기하학으로 정복한 서빙 성능 최적화의 열쇠이며, 설계자는 도메인에 수렴하는 높은 수용율의 초안 모델 페어링과 VRAM 마진을 통제하여 쾌적한 추론 서빙 인프라를 공급해야 함
