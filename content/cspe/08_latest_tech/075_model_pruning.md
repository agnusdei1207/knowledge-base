## 미리 알고가기

- 모델 가지치기 ($Model$ $Pruning$): 신경망 모델의 가중치 행렬 중 중요도가 떨어지는 시냅스 연결선이나 전체 레이어 채널을 잘라내어 연산 복잡도를 하락시키는 경량화 기법임
- 비구조적 가지치기 ($Unstructured$): 뉴런의 규칙성 없이 개별 가중치 값 크기가 임계치보다 작으면 무작위로 $0$(Zero)으로 치환하는 파라미터형 가지치기임
- 구조적 가지치기 ($Structured$): 필터, 채널, 어텐션 헤드, 혹은 레이어 블록 전체를 칼로 잘라내듯 통째로 삭제하여 행렬 차원 크기 자체를 작게 축소하는 방식임
- 희소 행렬 ($Sparse$ $Matrix$): 성분의 대부분이 $0$으로 채워져 있어 물리적인 저장소 낭비를 초래하는 행렬로, 특화된 하드웨어 가속기(예: Sparse Tensor Core) 지원이 필수 요구되는 형태임

## Ⅰ. 개요

- **정의/개념**: Model Pruning은 학습 완료된 심층 신경망 가중치 중 연산 결과 기여도가 극히 떨어지는 중요도 하위 가중치 노드나 채널 구조를 식별해 제거($0$으로 치환하거나 차원 탈락)함으로써, 뇌 세포의 유휴 시냅스를 정리하듯 모델을 가볍게 정돈하는 구조적 다이어트 최적화 기술임
- **배경/필요성**: 훈련을 통과한 거대 언어 모델은 표현의 완전성을 위해 실제 필요보다 수십 배 많은 중복 및 과대 파라미터($Over-parameterized$) 상태로 포화되어 있으므로, 추론 배포 시의 에너지 소비와 메모리 병목을 극복할 구조 개조가 필요함

## Ⅱ. 특징

- 기학습 모델 내에서 각 레이어별 중요도 점수($Importance$ $Score$)를 L1/L2 규제 스코어로 구하고, 하위 그룹을 순차 제거하여 지능 손실을 제어함
- 비구조적 가지치기는 기하학적으로 압축률은 뛰어나지만, 일반 GPU 칩셋이 0이 섞인 희소 행렬의 연산 가속을 지원하지 못하면 메모리 낭비만 초래함
- 구조적 가지치기는 필터나 헤드를 통째로 삭제하므로 범용 GPU 하드웨어 가속기에서 100% 즉시 동작 가속과 용량 절감을 보장함

## Ⅲ. 종류 및 비교

| 판단 기준 | 비구조적 가지치기 (Unstructured) | 구조적 가지치기 (Structured) | 양자화 (Quantization) |
|:---|:---|:---|:---|
| **제거 방식** | 개별 가중치 요소 중 작은 값을 $0$으로 치환 | 뉴런 채널, 어텐션 헤드, 레이어를 통째로 삭제 | 가중치 행렬의 실수 표현 비트 수 감축 |
| **물리 행렬 변화** | 행렬 차원은 동일하고 내부만 $0$으로 채워짐 (희소 행렬) | 행렬의 가로/세로 차원 크기 자체가 물리 축소됨 | 행렬 구조는 동일하고 정밀도만 감소함 |
| **하드웨어 가용성** | 희소 텐서 코어($Sparse$ $Core$) 장치만 가속 가능 | 모든 일반 GPU, NPU에서 즉각 가속 실행 가능 | 전용 저비트 컴파일러 연동 필요 |
| **품질 재건 난이도** | 보통 (가중치만 일부 0으로 대체) | 매우 높음 (중요 특징 추출 층 손실 위험) | 보통 |

> 요약: 비구조적 가지치기는 가중치 알갱이를 잘게 솎아내고, 구조적 가지치기는 뇌의 큰 줄기를 뭉텅 잘라 행렬 크기를 줄이며, 양자화는 숫자의 해상도를 깎음.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 기여도 채점기 | 가중치 행렬 크기나 역전파 경사도($Gradient$)를 읽어 솎아낼 타깃 노드를 채점하는 기기임 |
| 가지치기 마스크 | 연산 그래프에서 제거 대상 노드를 바이패스하거나 $0$을 곱해 신호를 끊는 논리적 필터임 |
| 복원 미세조정기 | 프루닝으로 인해 어그러진 손실 함수를 보완하기 위해 학습률을 낮추어 튜닝하는 재학습기임 |
| 희소 하드웨어 엔진 | 비구조적 가지치기로 생성된 희소 행렬의 스킵 연산을 지원하는 특화 가속 칩임 |

```text
[ 구조적/비구조적 Pruning 행렬 형상 비교 ]
Unstructured: [ x  0  x ] ---> (행렬의 Dimension은 유지되며 값만 0)
              [ 0  x  0 ]
Structured:   [ x  x ]   ---> (불필요한 열/행 차원 자체를 잘라내 크기를 줄임)
              [ x  x ]
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 가중치 기여 | --> | 마스크 적용  | --> | 지능 복원   | --> | 하드웨어    |
| 중요도 채점 |     | 및 노드 거절 |     | 미세조정학습|     | 엔진 적재/QA|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **지수 채점** — 각 레이어 뉴런 채널들의 활성화 강도와 절댓값 평균을 수집해, 영향력이 바닥인 가중치 노드들을 표적으로 잡음
2. **신호 격리** — 표적 노드들에 가지치기 마스크(Pruning Mask)를 씌워 곱셈 신호를 차단하거나 행렬 축소 컴파일을 단행함
3. **지능 복원 훈련** — 지능 소실로 파괴된 perplexity 성능을 복구하도록, 적은 양의 코퍼스로 모델을 다시 굴려 가중치를 보정함
4. **실행 및 검증** — 가벼워진 바이너리를 GPU에 올리고, 실제 프레임 수($FPS$) 상승 폭과 추론 시간 지연 개선량을 실측함

## Ⅵ. 실무 적용 및 유의점

1. 비구조적 가지치기로 가중치의 80%를 0으로 만들어도, 사용 중인 추론 칩(GPU/NPU)이 희소 연산 가속을 지원하지 않으면 0을 곱하는 공회전 연산이 동일하게 돌아가 속도 개선이 전무하므로, 반드시 '구조적 가지치기'를 기본 옵션으로 삼고 실질 응답 속도 단축률 지표로 타당성을 검증해야 함
2. 가지치기 후 무너진 지능을 복구하기 위한 미세 조정(Fine-tuning) 재학습 인프라 비용이 추론 서빙 절감 요금보다 배보다 배꼽이 더 커질 수 있으므로, 반드시 재학습 비용 대비 장기 서빙 요금 절감액을 종합 실측하여 소유 비용($TCO$) 관점에서 타당성을 검증해야 함

## Ⅶ. 결론

- 모델 가지치기는 초거대 뇌의 낭비되는 시냅스 회로를 이성적으로 잘라내 인프라 연산 한계를 돌파하는 최첨단 하드웨어 밀착 경량화 전략이며, 설계자는 칩셋의 물리적 희소 연산 지원 여부 감시와 재학습 단가의 가성비 한계를 고려하여 실용성 높은 다이어트 모델을 공급해야 함
