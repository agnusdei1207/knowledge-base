## 미리 알고가기

- Answer Relevancy는 답변이 질문 의도에 얼마나 정확히 대응하는지 측정하는 지표임
- 근거가 충분해도 질문 초점을 벗어나면 점수가 낮아짐
- 장황한 답변이나 동문서답을 탐지하는 데 유용함

## Ⅰ. 개요

- **정의/개념**: Answer Relevancy는 생성 답변이 사용자의 질문 목적과 범위와 요구 수준에 맞게 응답했는지를 측정하는 지표임
- **배경/필요성**: RAG는 관련 문서를 잘 찾아도 질문 의도를 잘못 해석하면 장황하거나 엇나간 답변을 만들 수 있으므로 질문 적합성 검증이 필요함

## Ⅱ. 특징

- 답변의 정확성보다 질문 대응성을 중점적으로 평가함
- 문맥 기반 근거가 충분해도 핵심 질문을 놓치면 낮은 점수를 받음
- 요약, 비교, 절차 설명처럼 응답 형식 요구가 있는 문제에서 중요함
- 사용자 만족도와 직접 연관돼 운영 체감 품질을 잘 반영함

## Ⅲ. 종류 및 비교

| 판단 기준 | Answer Relevancy | Faithfulness | Semantic Similarity |
|:---|:---|:---|:---|
| 평가 초점 | 질문 대응성 | 문맥 근거성 | 표현 유사성 |
| 동문서답 탐지 | 높음 | 낮음 | 중간 |
| 환각 탐지 | 중간 | 높음 | 낮음 |
| 사용자 만족도 반영 | 높음 | 중간 | 낮음 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| User Intent | 질문이 요구하는 정보 유형과 범위를 식별해 적절한 답변 기준을 만듦 |
| Generated Answer | 실제 출력이 질문 핵심을 직접 다뤘는지 평가 대상이 됨 |
| Relevancy Judge | 질문과 답변을 의미 수준에서 비교해 누락과 과잉 설명을 판정함 |
| Feedback Signal | 점수가 낮은 사례를 모아 프롬프트와 검색 의도 분해 로직을 개선하는 근거로 사용함 |

```text
+-------------------+      +-------------------+      +-------------------+
| User Intent       | ---> | Generated Answer  | ---> | Relevancy Judge   |
+-------------------+      +-------------------+      +-------------------+
                                                           |
                                                           v
                                                   +-------------------+
                                                   | Feedback Signal   |
                                                   +-------------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 질문 의도 분석 | --> | 답변 생성      | --> | 질문-답변 대조 | --> | 관련성 점수화 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **질문 의도 분석**: 질문이 정의, 비교, 절차, 원인 중 무엇을 요구하는지 식별함
2. **답변 생성**: 검색 문맥을 반영해 답변을 작성함
3. **질문과 답변 대조**: 답변이 핵심 질문에 직접 응답했는지 판단함
4. **관련성 점수화**: 누락과 우회 응답 정도를 점수로 집계함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 검색 문맥이 넓게 들어오면 모델이 주변 설명에 치우쳐 질문 핵심을 벗어난 장황한 답변을 만들 수 있음
   - 해결방안: 질문 유형별 응답 템플릿과 concise prompt를 적용하고 Answer Relevancy와 answer length ratio로 검증함
2. 문제: 복합 질문에서 일부 하위 질문만 답하면 사용자는 정답처럼 보여도 만족도가 크게 떨어질 수 있음
   - 해결방안: sub-question decomposition을 적용하고 coverage score와 user feedback으로 완전성을 검증함
3. 문제: judge 기준이 느슨하면 관련 없는 일반론 답변도 높은 점수를 받을 수 있음
   - 해결방안: intent-aware 평가 프롬프트를 사용하고 false relevance rate와 human agreement로 판정 엄밀성을 검증함

## Ⅶ. 적용 사례

- 고객지원 챗봇이 환불 절차 질문에 핵심 단계만 정확히 답하는지 확인하도록 Answer Relevancy를 관리하며 확인 지표는 Answer Relevancy와 resolution rate임
- 사내 업무 도우미가 정책 비교 질문의 누락 여부를 검사하도록 Answer Relevancy를 활용하며 확인 지표는 coverage score와 CSAT임
- 교육용 QA가 개념 설명 수준이 질문 난이도에 맞는지 점검하도록 Answer Relevancy를 적용하며 확인 지표는 relevance score와 retry rate임

## Ⅷ. 결론

Answer Relevancy는 답변이 얼마나 많이 말했는지가 아니라 사용자가 실제로 물은 핵심에 얼마나 정확히 답했는지를 평가하므로, 질문 의도 분해와 응답 범위 제어가 중요함.
