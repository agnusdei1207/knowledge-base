## 미리 알고가기

- CLIP은 이미지와 텍스트를 같은 의미 공간으로 정렬하는 멀티모달 사전학습 방식임
- contrastive learning은 맞는 짝은 가깝게 하고 틀린 짝은 멀게 만드는 학습 전략임
- zero-shot 분류와 cross-modal retrieval이 대표 활용임

## Ⅰ. 개요

- **정의/개념**: CLIP은 이미지 인코더와 텍스트 인코더를 함께 학습시켜 이미지와 문장을 공통 임베딩 공간에 정렬하고, 두 모달의 의미 유사도를 직접 계산하게 만드는 대조학습 기반 멀티모달 모델임
- **배경/필요성**: 고정 라벨 분류기는 새로운 클래스가 나오면 다시 학습해야 하므로, 자연어 프롬프트만으로 미지의 개념까지 판별할 수 있는 범용 시각-언어 정렬 기술이 필요했음

## Ⅱ. 특징

- 웹 규모의 약한 라벨 데이터만으로도 강한 zero-shot 성능을 확보할 수 있음
- dual encoder 구조라 대규모 검색에서 임베딩 사전 계산이 가능해 서빙 효율이 높음
- 자연어 프롬프트를 분류기처럼 사용할 수 있어 라벨 추가 비용이 낮음
- 세밀한 위치 추론이나 도메인 특화 시각 정보에는 성능 저하가 발생할 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | 지도학습 분류기 | CLIP | VLM |
|:---|:---|:---|:---|
| 학습 데이터 | 클래스 라벨 중심 | 이미지-텍스트 쌍 | 멀티모달 지시 데이터 |
| 주된 출력 | 고정 클래스 | 유사도 점수 | 자연어 응답 |
| zero-shot 적합성 | 낮음 | 높음 | 높음 |
| 대규모 검색 효율 | 중간 | 매우 높음 | 낮음 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Image Encoder | 이미지를 시각 임베딩으로 변환해 객체와 장면의 의미적 특징을 추출함 |
| Text Encoder | 문장을 텍스트 임베딩으로 변환해 자연어 설명과 클래스 프롬프트를 의미 공간에 투영함 |
| Shared Embedding Space | 두 모달의 벡터를 같은 좌표계에 정렬해 유사도 계산과 검색을 가능하게 함 |
| Contrastive Loss | 정답 쌍은 가깝게 하고 오답 쌍은 멀게 학습시켜 정렬 품질을 끌어올림 |

```text
+-------------------+      +-------------------+
| Image Encoder     | ---> | Shared Embedding  |
+-------------------+      +-------------------+
                                   ^
                                   |
+-------------------+      +-------------------+
| Text Encoder      | ---> | Contrastive Loss  |
+-------------------+      +-------------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 쌍 데이터 수집   | --> | 모달별 인코딩  | --> | 유사도 행렬 계산 | --> | 대조 손실 최적화 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **쌍 데이터 수집**: 이미지와 설명 문장을 배치 단위로 준비함
2. **모달별 인코딩**: 이미지와 문장을 각각 벡터로 변환함
3. **유사도 행렬 계산**: 배치 내 모든 이미지와 문장 간 점수를 계산함
4. **대조 손실 최적화**: 정답 쌍을 가깝게 맞추며 공통 공간을 학습함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 의료나 제조처럼 학습 데이터와 다른 도메인에서는 의미 정렬이 흔들려 zero-shot 분류 정확도가 급격히 떨어질 수 있음
   - 해결방안: adapter tuning이나 domain fine-tuning을 적용하고 zero-shot accuracy와 retrieval recall@k로 검증함
2. 문제: 프롬프트 문구 선택에 따라 같은 클래스도 예측 결과가 달라져 운영 일관성이 떨어질 수 있음
   - 해결방안: prompt ensemble과 template library를 적용하고 prompt variance와 top-1 accuracy로 검증함
3. 문제: 세밀한 위치 관계나 개수 판단은 전역 의미 정렬만으로 충분히 해결되지 않아 오판이 늘어날 수 있음
   - 해결방안: VLM reranker나 detector 결합 구조를 적용하고 fine-grained accuracy와 grounding score로 검증함

## Ⅶ. 적용 사례

- 전자상거래 이미지 검색이 긴 자연어 질의로 상품을 찾도록 CLIP 임베딩 검색을 적용하며 확인 지표는 retrieval recall@k와 CTR임
- 콘텐츠 검수가 이미지와 정책 문구의 의미 불일치를 빠르게 탐지하도록 CLIP 분류를 활용하며 확인 지표는 moderation precision과 reviewer load reduction임
- 제조 현장 라벨링이 신품종 결함 이미지를 자연어 프롬프트로 선분류하도록 CLIP을 적용하며 확인 지표는 zero-shot accuracy와 annotation time reduction임

## Ⅷ. 결론

CLIP은 시각과 언어를 공통 의미 공간으로 연결해 zero-shot 분류와 검색을 가능하게 한 핵심 기반기술이므로, 도메인 적합성 보강과 프롬프트 안정화가 실무 성능의 관건임.
