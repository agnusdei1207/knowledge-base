## 미리 알고가기

- 매개변수 효율적 미세조정 ($PEFT$, Parameter-Efficient Fine-Tuning): 사전학습된 거대 모델의 오리지널 가중치는 완전히 얼리고($Freeze$), 단 $1\%$ 미만의 아주 극소수 추가 가중치(어댑터)만을 훈련시켜 도메인에 수렴시키는 고효율 미세조정 기법군임
- 동결 ($Freeze$): 역전파($Backpropagation$) 훈련 시 가중치가 업데이트되지 않고 그대로 고정되도록 학습 대상에서 배제 차단하는 상태임
- 멀티 테넌시 ($Multi-tenancy$): 하나의 가볍고 공유된 기저 기반 모델 위에, 복수 고객사별 맞춤형 PEFT 어댑터(LoRA 등)들을 동적으로 붙였다 떼며 다수의 서로 다른 API 서비스를 단일 인프라에서 가동하는 상태임
- 가중 병합 ($Weight$ $Merge$): 서빙 시의 런타임 지연을 완전히 소거하기 위해, 훈련 완료된 PEFT 가중치(어댑터)를 원본 기반 모델 가중치에 매트릭스 덧셈 연산으로 완전히 융합 흡수시키는 기법임

## Ⅰ. 개요

- **정의/개념**: PEFT는 초대형 모델의 본체 매개변수는 완전히 동결($Freeze$)해 두고, 모델의 핵심 연산 중간층에 아주 가볍고 학습 가능한 소형 구조(예: LoRA, Adapter)를 우회 삽입하여, 단 $0.1 \sim 1\%$ 수준의 극소수 파라미터만 가동 학습시키는 비용 절감형 미세 조정 기술군임
- **배경/필요성**: 파라미터 수천억 개의 모델 전체 가중치를 미세 조정(Full Fine-Tuning)하면 VRAM 소모량과 그래디언트 임시 저장 공간 폭증으로 학습용 하드웨어 구축비가 기하급수적으로 커지고 고객별 모델 개별 보관이 불가능하여 대두됨

## Ⅱ. 특징

- 학습 대상 가중치가 획기적으로 줄어들어, $A100$ 단 1장 같은 싱글 중저가 GPU 노드 내에서도 초대형 LLM 미세 조정 연산을 완수해 냄
- 기저 파운데이션 모델을 하나의 정적 코어로 묶어 두고, 각 태스크(번역, 코딩, 요약) 전용의 가벼운 어댑터 파일(수십 MB 수준)들만 디스크에 저장 및 스위칭함
- 서빙 시에는 어댑터를 기저 모델에 가중치 병합($Weight$ $Merge$)하여, 추가 연산 딜레이 없이 바닐라 모델 속도로 완전 동등한 서빙 가속을 띰

## Ⅲ. 종류 및 비교

| 판단 기준 | 전면 미세조정 (Full Fine-Tuning) | 매개변수 효율 미세조정 (PEFT) | 프롬프트 엔지니어링 |
|:---|:---|:---|:---|
| **업데이트 파라미터** | 전체 ($100\%$) | 극소수 ($0.1 \sim 1\%$ 이내) | 없음 ($0\%$) |
| **저장 디스크 요량** | 수백 Gigabytes (모델 복제본) | 수십 Megabytes (경량 어댑터) | 없음 (문자열 수준) |
| **다중 고객 서빙** | 불가 (고객사별 전용 GPU 서버 개설) | 극도로 우수 (1기저 모델 + 다중 어댑터) | 우수함 (컨텍스트 유량 조율) |
| **지능 최대 적응 한계** | 극도로 높음 (새로운 논리 완전 습득) | 우수함 (행동 양식 및 규칙 준수에 적합) | 낮음 (최대 성능의 한계 뚜렷) |

> 요약: Full FT는 뇌 세포 전체를 개조하는 종합 성형이고, PEFT는 뇌의 특정 활성 통로에 작은 필터 어댑터를 장착하는 조율이며, Prompt는 질문 유도 요령임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 동결 기저 신경망 | 원본 지식 백본을 유지하기 위해 모든 학습 연산을 고정한 오리지널 기반 모델임 |
| 학습가능 경량 모듈 | 동결 신경망 내부나 외부에 덧붙는 LoRA 행렬, 어댑터 레이어, 프리픽스 텐서군임 |
| 옵티마이저 필터 | 학습 대상 모듈 파라미터만 골라 그래디언트를 역전파 적용하는 필터형 학습 최적화기임 |
| 멀티 어댑터 서비스 | 사용자의 요청 토큰에 탑재된 ID를 감지해 상응하는 어댑터를 기저 모델에 동적 마운트하는 런타임임 |

```text
[ PEFT 멀티 테넌트 서비스 아키텍처 ]
Tenant Request 1 ---> [ Load Adapter A ] ---\
Tenant Request 2 ---> [ Load Adapter B ] ----+---> [ Shared Frozen Base Model ]
Tenant Request 3 ---> [ Load Adapter C ] ---/
- 1대의 고정된 거대 모델 메모리 위에서, 고객사별 가벼운 어댑터 파일만 동적으로 갈아끼우며 서비스함
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 기반 모델   | --> | 소형 어댑터  | --> | 선택 모듈   | --> | 기저 가중치 |
| 가중치 동결 |     | 삽입 및 연결 |     | 가중치 학습 |     | 병합 후 배포|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **지수 동결** — 타깃 모델의 전체 매개변수에 대해 `requires_grad = False`를 설정해 물리 메모리 그래디언트 저장을 취소함
2. **모듈 삽입** — 트랜스포머 레이어 가중치 통로에 LoRA 저차원 행렬(A, B)이나 어댑터 병렬 신경망 레이어를 이식함
3. **어댑터 학습** — 준비된 도메인 데이터셋을 흘려보내, 추가 이식한 경량 모듈의 가중치 행렬 값들만 역전파 고속 수렴 학습시킵니다.
4. **가중치 융합** — 학습 종료 후 어댑터 가중치를 원본 동결 가중치 행렬에 덧셈 합체($Merge$)하여, 런타임 지연 없는 단일 바이너리로 배포함

## Ⅵ. 실무 적용 및 유의점

1. 도메인 지식의 난이도가 극도로 높거나 복잡한 기하학 기호 코딩 등 기존 기반 모델이 아예 모르는 무의 지식을 PEFT만으로 욱여넣으려고 하면 어댑터 용량 한계로 언어 퍼포먼스가 처참히 망가지므로, 반드시 사전에 학습 타깃 파라미터 비율($Trainable$ $Parameter$ $Ratio$)을 적절히 넓혀 조정하고 품질 검증을 수행해야 함
2. 다수 고객 대응을 위해 메모리에 수백 개의 어댑터를 동시에 가동하다가 드라이버 레이어에서 컨텍스트 충돌 및 지연 속도 스파이크가 발생할 수 있으므로, 반드시 전용 '어댑터 레지스트리'를 탑재하고 어댑터 동적 스위칭 응답성 지표($Switch$ $Latency$)를 엄격히 감시해야 함

## Ⅶ. 결론

- PEFT는 초거대 인공지능의 물리적 배포 한계를 가상 레이어와 융합 기술로 영리하게 해소한 멀티 테넌트 비즈니스의 최고 경제적 무기이며, 설계자는 어댑터 용량 한계에 따른 지능 수렴 한계선 극복 조율과 분산 어댑터 스위칭 충돌 차단책을 사전에 완전 구축해야 함
