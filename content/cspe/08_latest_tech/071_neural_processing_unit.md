## 미리 알고가기

- NPU는 신경망 연산에 특화된 전용 프로세서로 CPU와 GPU의 보완 계층임
- 행렬 곱셈과 convolution 같은 반복 연산을 낮은 전력으로 처리하는 것이 핵심 목표임
- 소프트웨어 프레임워크와 컴파일러 지원이 부족하면 하드웨어 성능이 실제로 활용되지 못함

## Ⅰ. 개요

- **정의/개념**: NPU는 딥러닝 추론에 필요한 tensor 연산을 전용 하드웨어 경로로 처리해 전력 효율과 응답성을 높이는 AI 특화 프로세서임
- **배경/필요성**: CPU는 범용성은 높지만 AI 연산 효율이 낮고 GPU는 성능은 높지만 전력 소모가 크므로, 모바일과 엣지 환경에는 저전력 전용 가속기가 필요함

## Ⅱ. 특징

- MAC 연산 어레이와 온칩 메모리를 활용해 반복적인 tensor 연산을 효율적으로 수행함
- 동일 전력 대비 높은 AI 추론 성능을 제공해 스마트폰, 차량, PC의 상시 AI 기능 구현에 적합함
- 지원 연산자와 정밀도 범위가 제한될 수 있어 범용성은 CPU와 GPU보다 낮음
- 모델 컴파일과 런타임 최적화 수준이 실제 성능을 좌우하므로 소프트웨어 생태계 의존성이 큼

## Ⅲ. 종류 및 비교

| 판단 기준 | CPU | GPU | NPU |
|:---|:---|:---|:---|
| 강점 | 범용 제어와 직렬 처리 | 대규모 병렬 연산 | 저전력 AI 추론 |
| 전력 효율 | 낮음 | 중간 | 높음 |
| 범용성 | 매우 높음 | 높음 | 낮음 |
| 대표 위치 | 서버, PC, 제어부 | 학습, 고성능 추론 | 모바일, 엣지, AI PC |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Compute Array | 행렬 곱셈과 convolution을 고속 처리해 NPU 성능의 핵심을 담당함 |
| On-chip Memory | 중간 결과와 가중치를 가까운 위치에 보관해 메모리 병목과 전력 낭비를 줄임 |
| DMA, Control Logic | 데이터 이동과 실행 순서를 통제해 계산 유닛의 유휴 시간을 줄임 |
| Compiler, Runtime | 모델을 하드웨어 실행 형태로 변환하고 지원 연산자 범위 안에서 최적 경로를 생성함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 모델 변환      | --> | 연산 분할/매핑  | --> | NPU 실행       | --> | 결과 반환/후처리 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **모델 변환**: 학습된 모델을 NPU가 이해하는 중간 표현이나 실행 그래프로 변환함
2. **연산 분할 및 매핑**: tensor 연산을 타일 단위로 나눠 계산 어레이와 메모리에 배치함
3. **NPU 실행**: 전용 연산 경로와 온칩 메모리를 활용해 추론을 수행함
4. **결과 반환 및 후처리**: 결과를 CPU나 애플리케이션 계층으로 돌려보내 후속 작업과 연결함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 지원하지 않는 연산자나 모델 구조가 섞이면 일부 작업이 CPU나 GPU로 우회되어 기대 성능이 무너질 수 있음
   - 해결방안: 연산자 호환성 검증과 fallback 설계를 함께 적용하고 unsupported op rate와 end-to-end latency로 효율을 검증함
2. 문제: 온칩 메모리보다 큰 모델이나 입력이 들어오면 외부 메모리 접근이 늘어 전력 효율과 지연 시간이 함께 악화될 수 있음
   - 해결방안: 모델 경량화와 타일링 최적화를 적용하고 memory bandwidth utilization과 latency jitter로 병목을 검증함
3. 문제: 벤더별 SDK와 컴파일러 차이로 이식성이 낮아 장비 교체나 멀티벤더 전략이 어려워질 수 있음
   - 해결방안: 표준 런타임 계층과 벤더별 성능 프로파일을 운영하고 portability benchmark와 migration lead time으로 대응 수준을 검증함

## Ⅶ. 적용 사례

- 스마트폰 음성 비서: 상시 대기 상태에서 저전력 추론을 수행함, 확인 지표는 wake latency와 battery impact임
- 차량 센서 융합 보조: 카메라와 레이더 데이터를 빠르게 처리함, 확인 지표는 inference latency와 thermal stability임
- AI PC 로컬 기능: 문서 요약과 이미지 보정을 로컬 가속함, 확인 지표는 task response time과 NPU utilization임

## Ⅷ. 결론

NPU는 범용 프로세서를 대체하는 장치가 아니라 제한된 전력 안에서 AI 추론을 상시 수행하게 만드는 전용 가속기이므로, 모델 구조와 런타임을 함께 설계해야 효과가 극대화됨.
