# 📖 【암기용】 개념 완전 이해

> 목적: Explainable AI를 처음 봐도 완벽히 이해하게 만든다.

## 한눈에
- **개요**: AI 모델의 예측 이유와 판단 근거를 사람이 이해할 수 있는 형태로 제공하는 기술과 방법론
- **왜 필요한가**: 금융·의료·공공 의사결정에서는 결과뿐 아니라 왜 그런 결정이 나왔는지 설명해야 함.
- **핵심 직관**: AI의 답안에 채점 근거와 풀이 과정을 붙여 사람이 검토할 수 있게 하는 것임.

## 깊이 이해
- **배경·문제의식**: 딥러닝은 복잡한 비선형 모델이라 높은 성능에도 불구하고 결정 근거를 알기 어렵다. 이는 신뢰, 감사, 규제 대응을 어렵게 한다.
- **작동 원리**: 모델 내부 구조를 해석하는 intrinsic 방식과, 학습된 모델의 입력-출력 변화를 분석하는 post-hoc 방식으로 설명을 제공함.
- **비유**: 의사가 진단명만 말하는 것이 아니라 검사 수치와 증상 중 어떤 것이 판단에 영향을 줬는지 설명하는 것과 같음.
- **구체 예시**: 대출 거절 모델에서 SHAP으로 DTI 45%, 연체 이력, 소득 변동이 주요 기여 요인임을 표시.
- **흔한 오해·주의점**: 설명이 있다고 항상 정확하거나 공정한 모델은 아님. 설명 충실도와 사용자 이해도를 별도 검증해야 함.

## 연결 개념
- LIME — 국소 대리모델 기반 설명기법
- SHAP — Shapley value 기반 feature 기여도 설명
- Model Card — 모델 목적·성능·제약을 문서화

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: XAI는 모델 예측의 근거를 feature 기여도, 규칙, 시각화 등으로 설명하는 기술임.
> 2. **가치**: 신뢰 확보, 오류 분석, 규제 대응, 인간 감독을 가능하게 함.
> 3. **판단 포인트**: 설명 충실도, 안정성, 사용자 이해도, 모델 성능 저하 여부를 함께 검증해야 함.

## Ⅰ. 개요 및 필요성

Explainable AI는 AI 판단 근거를 사람이 이해할 수 있게 제공하는 기술이다. 고위험 AI는 결과뿐 아니라 근거, 한계, 책임 설명이 필요하다. XAI는 모델 신뢰성, 감사 가능성, 오류 개선을 지원한다.

## Ⅱ. 구조 및 구성요소

```text
Input + Model Prediction -> Explanation Method
  -> Feature Attribution/Rule/Visualization -> Human Review
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Model | 설명 대상 AI | black-box 또는 interpretable |
| Explanation Method | 설명 생성 기법 | LIME, SHAP, attention, rule |
| Explanation Output | 기여도·규칙·시각화 | local/global explanation |
| Human Review | 설명 검토·조치 | domain expert, audit |

> 요약: XAI는 모델 예측과 입력을 분석해 사람이 검토 가능한 설명 산출물로 변환함.

## Ⅲ. 동작원리 및 흐름도

```text
예측 요청 -> 모델 출력 -> 설명기법 적용
  -> feature/근거 산출 -> 설명 품질 검증 -> 사용자 제공
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 설명 대상 예측과 입력 수집 | 로그 누락률 0% |
| 2 | local/global 설명기법 적용 | latency <500ms |
| 3 | 설명 충실도·안정성 평가 | fidelity ≥0.9 |
| 4 | 사용자·감사자에게 설명 제공 | 이해도 평가 80% 이상 |

> 요약: XAI는 예측별 설명을 생성하고 충실도·안정성을 검증해 인간 감독에 활용함.

## Ⅳ. 특징

| 구분 | Black-box AI | Explainable AI | 판단 포인트 |
|:---|:---|:---|:---|
| 결과 제공 | 예측값 중심 | 예측+근거 | 고위험 의사결정 필수 |
| 오류 분석 | 어려움 | feature 기여도 확인 | 모델 개선 가능 |
| 규제 대응 | 증적 부족 | 설명·감사 자료 제공 | 금융·의료·공공 |
| 한계 | 설명 없음 | 설명 왜곡 가능 | fidelity 검증 필요 |

> 요약: XAI는 인간 검토와 감사 대응을 지원하지만 설명 자체의 정확성과 안정성을 검증해야 함.

## Ⅴ. 실무 적용 및 결론

**적용 방안 3개:**
1. 금융 심사: SHAP local explanation을 제공하고 주요 거절 사유 Top-3를 고객 통지·내부 감사에 활용
2. 의료 AI: 영상 판독 heatmap과 feature attribution을 함께 제공하고 전문의 확인을 mandatory gate로 설정
3. 운영 검증: fidelity, stability, explanation latency를 모니터링하고 설명 변동률 10% 초과 시 모델 점검

**결론 (2줄):**
- 기술사 판단: 고위험 AI는 XAI를 필수 통제로 적용하되 설명 충실도와 사용자 이해도를 검증
- 향후 방향: LLM 기반 자연어 설명과 정량 attribution을 결합한 하이브리드 XAI로 발전
