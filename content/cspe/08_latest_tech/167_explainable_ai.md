## 미리 알고가기

- XAI는 블랙박스 모델의 판단 근거를 사람이 이해할 수 있는 형태로 제공하는 기술군임
- 설명은 개별 예측을 보는 local explanation과 모델 전반을 보는 global explanation으로 나뉨
- 설명의 직관성만 볼 것이 아니라 원모델을 얼마나 충실하게 대변하는지도 함께 봐야 함

## Ⅰ. 개요

- **정의/개념**: Explainable AI는 기계학습 모델이 특정 예측이나 분류를 내린 이유를 변수 중요도와 규칙과 시각화와 반사실 설명 등 사람이 해석 가능한 형태로 제공하는 설명 기술 체계임
- **배경/필요성**: 딥러닝과 앙상블 모델은 높은 성능을 제공하지만 판단 경로가 불투명하므로, 의료와 금융과 공공 영역에서는 설명 부족이 신뢰 저하와 규제 위반과 디버깅 난이도 증가로 이어짐

## Ⅱ. 특징

- 모델의 예측 결과를 이해 가능한 근거로 바꿔 사용자 수용성과 감사 가능성을 높임
- 개발 단계에서는 데이터 편향과 이상 상관관계를 찾는 디버깅 도구로도 활용됨
- 설명 기법마다 적용 가능한 데이터 형태와 계산 비용과 충실도가 다름
- 설명 결과가 그럴듯해 보여도 원모델의 실제 추론 과정을 완전히 재현하지 못할 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | Intrinsic XAI | Post-hoc Local XAI | Post-hoc Global XAI |
|:---|:---|:---|:---|
| 설명 시점 | 모델 설계 자체 | 개별 예측 이후 | 모델 전체 분석 |
| 대표 기법 | 결정트리, 선형모델 | LIME, SHAP, Counterfactual | Feature importance, PDP, SHAP summary |
| 장점 | 구조 해석이 직접적임 | 개별 사례 설명에 강함 | 전체 패턴과 편향 파악에 유리함 |
| 한계 | 성능 제약이 큼 | 안정성과 충실도 이슈가 있음 | 개인별 설명에는 약함 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Black-box Model | 높은 성능을 제공하지만 내부 추론 경로가 바로 드러나지 않는 예측 엔진임 |
| Explanation Method | 입력과 예측 결과를 분석해 변수 기여도와 규칙과 시각화 형태로 설명을 생성함 |
| Explanation Artifact | 중요 피처 순위와 히트맵과 반사실 예시처럼 사람이 읽을 수 있는 결과물로 제공됨 |
| Fidelity, Stability Check | 설명이 원모델을 얼마나 충실하고 일관되게 반영하는지 평가해 과신을 막음 |
| Human Consumer | 사용자와 심사자와 도메인 전문가가 설명을 바탕으로 판단을 검증하고 보완함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 예측 결과 생성  | --> | 설명 대상 선택  | --> | 설명 근거 산출  | --> | 사람 검증/활용  |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **예측 결과 생성**: 모델이 입력에 대한 출력값을 계산함
2. **설명 대상 선택**: 개별 사례인지 전체 모델인지 설명 범위를 정함
3. **설명 근거 산출**: 기여도와 규칙과 시각화로 설명 결과를 생성함
4. **사람 검증 및 활용**: 도메인 지식으로 설명을 검토하고 의사결정에 반영함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 설명이 직관적으로 보여도 원모델을 충분히 대변하지 못하면 잘못된 신뢰를 주어 판단 오류를 키울 수 있음
   - 해결방안: fidelity evaluation과 reference case review를 적용하고 explanation fidelity와 expert agreement로 검증함
2. 문제: 동일 입력 근처의 작은 교란에도 설명 결과가 크게 흔들리면 운영 현장에서 일관된 해석을 제공하기 어려움
   - 해결방안: stability test와 explanation smoothing을 적용하고 rank correlation과 explanation variance로 검증함
3. 문제: 과도하게 복잡한 설명 표현은 사용자 이해도를 떨어뜨려 설명 제공 자체가 형식 요건으로 끝날 수 있음
   - 해결방안: role-based explanation UI를 적용하고 comprehension score와 decision time으로 검증함

## Ⅶ. 적용 사례

- 의료 영상 진단 AI가 병변 영역 히트맵과 주요 임상 변수 설명을 함께 제공하며 확인 지표는 clinician agreement와 diagnostic acceptance rate임
- 금융 대출 심사 모델이 개별 고객의 거절 사유를 설명하도록 운영되며 확인 지표는 explanation turnaround time과 complaint reduction rate임
- 제조 불량 예측 모델이 이상 상관관계를 찾아 재학습 포인트를 제시하며 확인 지표는 root cause discovery rate와 model debugging lead time임

## Ⅷ. 결론

Explainable AI는 블랙박스 모델의 성능을 바로 대체하는 기술이 아니라, 그 성능을 신뢰 가능한 의사결정으로 연결해 주는 해석 계층임.
