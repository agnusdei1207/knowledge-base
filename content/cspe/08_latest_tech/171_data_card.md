# 📖 【암기용】 개념 완전 이해

> 목적: Data Card를 처음 봐도 완벽히 이해하게 만든다.

## 한눈에
- **개요**: 데이터셋의 출처, 수집 목적, 구성, 품질, 편향, 개인정보, 사용 제한을 표준 형식으로 문서화한 설명서
- **왜 필요한가**: AI 모델 품질과 위험은 데이터에 크게 의존하므로 데이터의 맥락과 한계를 추적해야 함.
- **핵심 직관**: 모델의 원재료인 데이터에 붙이는 영양성분표와 원산지 표시임.

## 깊이 이해
- **배경·문제의식**: 데이터 파일만 보면 어떤 목적으로 수집됐는지, 어떤 집단이 부족한지, 개인정보 처리는 됐는지 알 수 없다.
- **작동 원리**: 데이터셋 목적, 수집 방법, 스키마, 분포, 품질 지표, 라이선스, 민감정보, 편향 분석, 업데이트 주기를 문서화함.
- **비유**: 식품을 살 때 원산지·성분·알레르기 정보를 확인하듯, AI 데이터도 출처와 위험 정보를 확인해야 함.
- **구체 예시**: 고객 상담 데이터 카드에 수집 기간, 언어 비율, PII 마스킹률 95%, 불만 유형 분포, 사용 금지 목적을 기록.
- **흔한 오해·주의점**: 데이터 카드는 데이터 카탈로그와 다름. 단순 위치 정보가 아니라 품질·위험·사용 제한까지 포함해야 함.

## 연결 개념
- Model Card — 모델 목적·성능·한계 문서화
- Data Governance — 데이터 품질·권한·계보 관리
- AI Impact Assessment — 데이터가 사람에게 미칠 영향을 평가

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: Data Card는 AI 데이터셋의 출처·구성·품질·위험·사용 조건을 문서화한 거버넌스 산출물임.
> 2. **가치**: 데이터 편향, 개인정보, 라이선스, 품질 한계를 모델 개발 전에 식별하게 함.
> 3. **판단 포인트**: 데이터 변경과 모델 재학습 시 카드 버전도 함께 갱신해야 함.

## Ⅰ. 개요 및 필요성

- 개요: 데이터셋 설명·위험 문서이다.
- 배경: AI 모델은 데이터 수집 맥락, 표본 구성, 라벨 품질에 따라 예측 편향이 달라진다.
- 필요성: Data Card는 출처, 동의, 분포, 품질, 사용 제한을 명시해 데이터 재사용 기준을 제공한다.

## Ⅱ. 구조 및 구성요소

```text
Dataset Metadata -> Collection/Consent -> Schema/Distribution
  -> Quality/Bias/Privacy -> Usage Limits -> Versioning
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Metadata | 데이터명·버전·소유자 | lineage, update date |
| Collection Context | 수집 목적·동의·출처 | consent, legal basis |
| Quality/Bias | 결측·중복·분포·대표성 | missing rate, group ratio |
| Usage Limits | 허용·금지 목적 | license, privacy constraint |

> 요약: 데이터 카드는 데이터의 생성 맥락과 품질·위험·사용 제한을 한 문서로 관리함.

## Ⅲ. 동작원리 및 흐름도

```text
데이터 등록 -> 수집 맥락 기록 -> 품질·분포 분석
  -> 개인정보·편향 점검 -> 사용 제한 명시 -> 버전 갱신
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 데이터셋 owner·버전·계보 등록 | owner 누락 0건 |
| 2 | 수집 목적·동의·라이선스 기록 | 법적 근거 100% 기재 |
| 3 | 품질·분포·편향 지표 산출 | 결측률·집단분포 기록 |
| 4 | 사용 제한·갱신 이력 관리 | 버전별 변경 이력 100% |

> 요약: 데이터 카드는 데이터 등록부터 품질·위험 분석과 사용 제한까지 추적 가능한 문서로 관리됨.

## Ⅳ. 특징

| 구분 | 데이터 카탈로그 | Data Card | 판단 포인트 |
|:---|:---|:---|:---|
| 목적 | 데이터 위치·메타데이터 | AI 사용 맥락·위험 설명 | AI 개발 필수 |
| 범위 | 스키마·소유자 | 품질·편향·개인정보·제한 | 위험 정보 포함 |
| 운영 | 검색·관리 | 모델 개발·감사 증적 | Model Card와 연계 |
| 한계 | 위험 설명 부족 | 작성·갱신 비용 | 자동화 필요 |

> 요약: Data Card는 데이터 카탈로그보다 AI 위험과 사용 제한을 더 명확히 기록하는 문서임.

## Ⅴ. 실무 적용 및 결론

**적용 방안 3개:**
1. 학습 데이터 승인: 모델 학습 전 Data Card에 PII 마스킹률, 결측률, 집단별 분포, 라이선스 상태를 필수 기재
2. 편향 관리: 민감 집단별 표본 비율과 label imbalance를 기록하고 10%p 이상 격차는 보정 계획 수립
3. 운영 연계: 데이터 버전 변경 시 Model Card와 평가 리포트를 자동 갱신하도록 MLOps 파이프라인 연결

**결론 (2줄):**
- 기술사 판단: AI 품질과 책임성은 데이터 맥락에서 시작하므로 Data Card를 모델 배포 필수 증적으로 관리
- 향후 방향: 데이터 카탈로그, Model Card, AI Impact Assessment가 통합된 AI GRC 메타데이터로 발전
