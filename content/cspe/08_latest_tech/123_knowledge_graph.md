## 미리 알고가기

- 지식그래프는 개체와 관계를 노드와 엣지로 표현한 구조화 지식 저장 방식임
- 단순 문서 검색이 아니라 개체 간 관계 탐색과 추론에 강점이 있음
- ontology, entity linking, graph RAG와 긴밀하게 연결됨

## Ⅰ. 개요

- **정의/개념**: 지식그래프는 사람, 조직, 개념 같은 개체와 그들 사이의 관계를 노드와 엣지와 속성으로 표현해 구조적 탐색과 추론을 가능하게 하는 지식 표현 및 저장 구조임
- **배경/필요성**: 문서 조각 검색만으로는 관계와 계층과 연쇄 추론을 다루기 어려우므로, 개체 중심의 연결 구조를 명시적으로 저장하는 방식이 필요함

## Ⅱ. 특징

- 개체 간 관계를 명시적으로 표현해 multi-hop 탐색과 설명 가능한 질의응답에 유리함
- 문서 기반 RAG가 놓치는 구조적 지식과 전역 맥락을 보완할 수 있음
- 엔티티 정규화와 스키마 설계가 부실하면 그래프 품질이 빠르게 무너질 수 있음
- 구축 비용과 유지 비용이 문서 인덱스보다 높은 편임

## Ⅲ. 종류 및 비교

| 판단 기준 | 관계형 DB | 지식그래프 | 문서 벡터 저장소 |
|:---|:---|:---|:---|
| 관계 표현력 | 중간 | 높음 | 낮음 |
| 다중 홉 탐색 | 제한적임 | 높음 | 낮음 |
| 의미 구조화 | 낮음 | 높음 | 중간 |
| 검색 적합도 | 정형 질의 | 관계 기반 질의 | 의미 검색 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Entity Nodes | 사람, 조직, 개념 같은 대상의 식별 단위를 표현함 |
| Relations, Edges | 개체 간 상호작용과 계층과 인과 관계를 연결해 탐색 경로를 만듦 |
| Properties, Schema | 각 노드와 관계의 속성과 제약을 정의해 그래프 일관성을 유지함 |
| Reasoning, Query Layer | graph traversal과 rule inference로 관계 기반 질의응답을 수행함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 개체/관계 추출  | --> | 그래프 스키마 반영 | --> | 노드/엣지 저장   | --> | 관계 탐색/추론   |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **개체 및 관계 추출**: 원천 데이터에서 핵심 개체와 연결 관계를 찾음
2. **그래프 스키마 반영**: ontology나 스키마에 맞게 구조를 정규화함
3. **노드 및 엣지 저장**: 정제된 개체와 관계를 그래프 DB에 적재함
4. **관계 탐색 및 추론**: 질의에 맞는 경로 탐색과 rule-based 추론을 수행함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 같은 개체가 여러 표기법으로 중복 저장되면 관계망이 분산되어 그래프 탐색 품질이 크게 떨어질 수 있음
   - 해결방안: entity linking과 canonicalization을 적용하고 duplicate node rate와 graph consistency로 정합성을 검증함
2. 문제: 관계 정의가 부정확하거나 과도하면 잘못된 경로가 생성되어 오답 추론을 강화할 수 있음
   - 해결방안: ontology 검증과 human review를 운영하고 relation precision과 query accuracy로 관계 품질을 검증함
3. 문제: 구축과 유지 비용이 높아 단순 FAQ 수준 서비스에는 과잉 설계가 될 수 있음
   - 해결방안: 관계 기반 질의 비중이 높은 영역에만 적용하고 graph query gain과 maintenance cost로 도입 타당성을 검증함

## Ⅶ. 적용 사례

- 기업 조직도와 권한 관계 관리: 관계 기반 질의를 수행함, 확인 지표는 query accuracy와 update consistency임
- 바이오, 법률 지식 탐색: 개체 간 관계망을 활용함, 확인 지표는 multi-hop QA accuracy와 explainability임
- graph RAG 기반 연구: 문서 의미 검색과 관계 탐색을 결합함, 확인 지표는 insight discovery rate와 faithfulness임

## Ⅷ. 결론

지식그래프는 문서 검색을 개체와 관계 탐색으로 확장하는 구조이므로, 관계성이 실제 업무 가치로 이어지는 도메인에서 가장 강력함.
