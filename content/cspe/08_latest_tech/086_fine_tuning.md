## 미리 알고가기

- 파인튜닝 ($Fine-Tuning$): 사전학습 완료된 기반 모델(Foundation Model)에 특정 전문 도메인 데이터셋을 추가 학습시켜, 가중치 일부 또는 전부를 타깃 비즈니스 목적에 최적 정돈하는 미세 조정 기법임
- 파멸적 망각 ($Catastrophic$ $Forgetting$): 모델이 새로운 지식을 추가 학습하는 과정에서, 이전에 보유하고 있던 범용적인 지식이나 추론 논리 능력을 영구 유실(망각)해 버리는 신경망의 부작용 현상임
- 지도 미세 조정 ($SFT$, Supervised Fine-Tuning): 입력 지시문(Prompt)과 이상적인 모범 대답(Response) 쌍으로 이루어진 정제된 데이터셋을 교안 삼아 모델을 지도 훈련시키는 과정임
- 매개변수 효율적 파인튜닝 ($PEFT$): 모델 전체 파라미터를 업데이트하는 대신, 극소수의 어댑터 가중치만을 동적으로 삽입 훈련하여 인프라 비용을 극대화 절감하는 미세 조정 계열임

## Ⅰ. 개요

- **정의/개념**: Fine-Tuning은 이미 방대한 언어 코퍼스로 사전학습($Pre-training$)된 기반 모델의 가중치 행렬을 전제로, 특정 전문 산업 도메인의 레이블링된 데이터셋을 추가 지도 훈련($SFT$)시켜 답변 스타일, 사내 내부 서식 규정, 판단 로직 등을 타깃 업무에 밀착 일치시키는 전이 학습 기법임
- **배경/필요성**: 범용 인공지능 모델은 잡학다식하나 기업 고유의 내부 양식, 특정 전산 커스텀 용어, 엄격한 가이드라인 준수율이 매우 낮으므로, 실무 현장에 즉각 투입 가능한 수준으로 행동 지침을 모델에 각인시키고자 필수 적용됨

## Ⅱ. 특징

- 단순 프롬프트 입력 제약(프롬프트 엔지니어링)의 한계를 초월하여, 모델 내부 신경망 시냅스 자체에 비즈니스 판단 패턴을 동적으로 융화함
- 반복적으로 사용되는 지침 및 서식을 모델에 사전에 체화시키므로, 매 호출 시 긴 가이드라인 토큰을 인입할 필요가 없어 API 비용을 획기적으로 낮춤
- 데이터의 최신 팩트를 갱신(Fact-Update)하는 것보다는, 문체 변경, 추론 사고 습관 고정, 보안 가드레일 통제에 절대적인 성능을 보장함

## Ⅲ. 종류 및 비교

| 판단 기준 | 프롬프트 제어 (Prompt Engineering) | 검색 증강 생성 (RAG) | 미세 조정 (Fine-Tuning) |
|:---|:---|:---|:---|
| **물리 가중치 변화** | 없음 (가중치 완전 고정) | 없음 (가중치 완전 고정) | 있음 (레이어 일부 또는 전면 가중치 갱신) |
| **최신 팩트 반영율** | 낮음 (컨텍스트 윈도우 한계 내) | 매우 높음 (외부 실시간 검색 결과 주입) | 보통 (훈련 시점 데이터에 락인됨) |
| **대표적인 강점** | 개발 속도 초고속, 비용 없음 | 정보 왜곡(환각) 억제에 절대적 기여 | 포맷 준수율, 도메인 전문 문체 완벽 구현 |
| **서빙 메모리 오버헤드** | 없음 | 보통 수준 (Vector DB 검색 쿼리 소요) | 높음 (전체 모델 미세조정 시 독자 모델 서버 대기) |

> 요약: 프롬프트 제어는 상황별 조력 지시고, RAG는 오픈북 시험용 정답지 전달이며, Fine-Tuning은 뇌의 시냅스를 고치고 공부시켜 전문 훈련병을 육성하는 과정임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 기저 파운데이션 | 일반 자연어 이해력과 기초 생성 한계를 쥐고 있는 학습 원천 백본 모델임 |
| 지도 학습 데이터셋 | 특정 도메인의 질문(Instruction)과 고품질 모범 답안(Response)의 매핑 테이블임 |
| 최적화 로스 함수 | 교차 엔트로피($Cross-Entropy$) 로스 및 선호도 로스(DPO)를 수립하는 학습 사령탑임 |
| 회귀 평가 런타임 | 파인튜닝 후 일반 상식 지능이 깨졌는지 다차원 벤치마킹하는 유효성 감사 데몬임 |

```text
[ Fine-Tuning (파인튜닝) 훈련 프로세스 ]
[Base Foundation Model] + [Q&A Dataset (Instruction/Response)] 
                                     │
                                     v (SFT / DPO Fine-tuning Process)
[Domain Fine-tuned Model] <--- [Evaluation & Safety Guardrail]
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 도메인 말뭉치| --> | 가중치 갱신  | --> | 회귀 벤치   | --> | 특화 모델   |
| 전처리/정제 |     | 학습 (SFT)   |     | 일반지능평가|     | 서빙 배포   |
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **말뭉치 빌드** — 사내 데이터베이스나 전문 규정집에서 질의-모범답변 쌍을 추출하고 비식별화 전처리 정제를 완료함
2. **미세조정 가동** — 기반 모델 가중치를 로드하고 에폭($Epoch$) 단위 학습을 돌려, 도메인 출력 확률 분포 오차를 미세 보정함
3. **망각 현상 검사** — MMLU, GSM8K 등 공인 벤치마크셋을 가동하여 신규 지식 획득 중 일반 추론력이 붕괴($Catastrophic$ $Forgetting$)했는지 검증함
4. **핫 서비스 적재** — 최종 검증 통과한 파인튜닝 모델의 아티팩트를 추론 서버에 올리고 사용자의 실시간 질의 응답을 가동함

## Ⅵ. 실무 적용 및 유의점

1. 특정 도메인 데이터만 과도하게 주입하여 미세 조정하면, 일반적인 코딩이나 기본적인 논리 추론력이 영구 파괴되는 '파멸적 망각($Catastrophic$ $Forgetting$)'이 생기므로, 반드시 훈련 데이터셋에 범용 자연어 말뭉치를 $20 \sim 30\%$ 믹싱하여 학습하고 회귀 평가지표를 상시 대조해야 함
2. 최신 법률 규정이나 수시로 변하는 단가 팩트 정보를 파인튜닝만으로 반영하려 하면 매번 재학습 비용이 발생해 운영이 불가능하므로, 팩트 갱신은 'RAG 아키텍처'로 엄격히 분리 전담시키고 파인튜닝은 스타일 및 가이드라인 준수율($Format$ $Pass$ $Rate$) 보존에만 한정 기용해야 함

## Ⅶ. 결론

- 파인튜닝은 범용 지능 모델을 엔터프라이즈 비즈니스의 통제 영역 내로 귀화시켜 실질적 부가가치를 빚어내는 핵심적인 가중치 가공 최적화이며, 설계자는 무리한 지식 주입 시 나타나는 지능 붕괴(망각)를 극복하기 위해 혼합 말뭉치 설계와 RAG 분리 융합 아키텍처를 통합 제공해야 함
