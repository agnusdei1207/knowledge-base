# 📖 【암기용】 개념 완전 이해

> 목적: Fine-Tuning을 처음 봐도 완벽히 이해하게 만든다.

## 한눈에
- **개요**: 사전학습 모델을 특정 도메인·업무 데이터로 추가 학습해 목적에 맞게 적응시키는 기법
- **왜 필요한가**: 범용 모델은 의료·법률·사내 규정처럼 특수 용어와 출력 형식을 정확히 따르지 못할 수 있음.
- **핵심 직관**: 이미 대학 교육을 받은 사람에게 회사 업무 매뉴얼과 사례를 추가 훈련시키는 과정임.

## 깊이 이해
- **배경·문제의식**: Prompt Engineering은 입력 설계만으로 빠르게 개선하지만 모델 내부 지식·스타일·판단 기준을 바꾸지는 못함. Fine-Tuning은 도메인 데이터를 통해 모델 가중치를 직접 조정함.
- **작동 원리**: base model을 선택하고 학습 데이터를 정제한 뒤, supervised fine-tuning으로 입력-출력 패턴을 학습함. 필요 시 PEFT로 일부 파라미터만 업데이트함.
- **비유**: 범용 번역가에게 회사 용어집과 과거 번역문을 반복 학습시켜 사내 문체를 맞추게 하는 것과 같음.
- **구체 예시**: 고객센터 50K건 질의응답으로 SFT를 수행하면 응답 형식 준수율과 도메인 F1을 개선할 수 있음.
- **흔한 오해·주의점**: Fine-Tuning은 최신 지식 주입 수단이 아님. 자주 바뀌는 사실은 RAG로 처리하고, 행동·형식·도메인 패턴은 Fine-Tuning으로 처리함.

## 연결 개념
- Instruction Tuning — 지시 응답 능력 강화
- PEFT/LoRA — 비용을 낮춘 Fine-Tuning 방식
- RAG — 외부 지식 최신성 보완

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: Fine-Tuning은 사전학습 모델 가중치를 도메인 데이터로 추가 학습해 업무 적합성을 높이는 기법임.
> 2. **가치**: 특정 출력 형식·전문 용어·업무 판단 패턴을 모델 내부에 반영함.
> 3. **판단 포인트**: 데이터 품질, overfitting, 비용, RAG와 역할 분리, 평가셋 설계가 핵심임.

## Ⅰ. 개요 및 필요성

Fine-Tuning은 사전학습 모델의 도메인 적응 학습임. 범용 모델이 특정 업무의 용어·형식·판단 기준을 따르지 못할 때, 정제된 업무 데이터로 추가 학습해 일관성을 확보함.

## Ⅱ. 구조 및 구성요소

```text
Base Model -> Training Data -> Fine-Tuning Job
      -> Tuned Model -> Evaluation -> Deployment
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Base Model | 사전학습 지식 제공 | LLM/SLM 선택 |
| Training Data | 업무 입력-출력 사례 | PII 제거·품질 필터 |
| Tuning Method | Full FT 또는 PEFT | 비용·GPU 메모리 차이 |
| Evaluation Set | 회귀·안전성 검증 | holdout 필수 |

> 요약: Fine-Tuning은 base model, 정제 데이터, 학습 방식, 독립 평가셋으로 구성되는 모델 적응 절차임.

## Ⅲ. 동작원리 및 흐름도

```text
목표 설정 -> 데이터 정제 -> 학습 설정 -> 추가 학습
    -> 평가·회귀 검증 -> 배포·모니터링
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 업무 목표·평가 지표 정의 | F1, 형식 준수율 |
| 2 | 학습 데이터 정제·분할 | train/valid/test |
| 3 | SFT/PEFT 학습 수행 | loss, overfitting |
| 4 | 독립 평가·배포 | 기준 모델 대비 uplift |

> 요약: Fine-Tuning은 목표 지표와 평가셋을 먼저 정하고 학습 후 회귀 검증을 통과해야 배포함.

## Ⅳ. 특징

| 구분 | Prompt/RAG | Fine-Tuning | 수치·판단 포인트 |
|:---|:---|:---|:---|
| 목적 | 입력 보강·최신 지식 | 행동·형식·도메인 적응 | 역할 분리 |
| 비용 | 낮음~중간 | 학습 비용 발생 | GPU-hour |
| 데이터 | 문서·프롬프트 | 정답 사례 필요 | 1K~100K 샘플 |
| 리스크 | 검색 품질 의존 | overfitting·forgetting | holdout 평가 |

> 요약: Fine-Tuning은 모델 행동을 바꾸는 데 적합하고, 최신 지식 보강은 RAG와 병행해야 함.

## Ⅴ. 실무 적용 및 결론

**적용 방안 3개:**
1. 고객센터 답변 형식은 10K~50K 라벨 데이터로 SFT하고 형식 준수율 95% 이상 기준 배포
2. 법률·의료처럼 최신 근거가 필요한 업무는 Fine-Tuning은 문체·판단 패턴, RAG는 근거 문서로 분리
3. 배포 후 drift·환각률·금지 표현률을 모니터링하고 월 1회 재학습 후보 데이터를 선별

**결론 (2줄):**
- 기술사 판단: 행동·형식·도메인 패턴 개선은 Fine-Tuning, 최신 사실·문서 근거는 RAG를 선택함.
- 향후 방향: Fine-Tuning은 PEFT, synthetic data, evaluation 자동화와 결합해 기업별 SLM 운영으로 확산됨.
