## 미리 알고가기

- 파인튜닝은 사전학습된 모델의 가중치를 특정 업무나 도메인에 맞게 추가 학습하는 방식임
- 최신 사실 주입은 주로 RAG가 담당하고, 파인튜닝은 형식과 추론 습관과 도메인 적응에 더 적합함
- full fine-tuning과 PEFT는 비용 구조와 운영 방식이 크게 다름

## Ⅰ. 개요

- **정의/개념**: 파인튜닝은 사전학습된 기반 모델을 특정 도메인 데이터나 업무 라벨로 추가 학습해 응답 형식과 용어와 추론 패턴을 업무 목적에 맞게 조정하는 전이 학습 기법임
- **배경/필요성**: 범용 모델은 일반 지식은 넓지만 조직별 포맷, 전문 용어, 업무 관행에 일관되게 맞추기 어렵기 때문에, 실제 서비스에는 추가 적응 단계가 필요함

## Ⅱ. 특징

- 프롬프트만으로는 고정하기 어려운 응답 형식과 도메인 행동을 모델 내부에 체화할 수 있음
- 동일 업무를 반복 수행할 때 프롬프트 길이와 후처리 부담을 줄여 운영 효율을 높일 수 있음
- 학습 데이터 품질이 낮거나 과도한 업데이트가 일어나면 범용 능력이 손상될 수 있음
- 최신 사실 갱신보다는 스타일, 정책, 태스크 수행 규칙 적응에 더 적합함

## Ⅲ. 종류 및 비교

| 판단 기준 | Prompt Engineering | RAG | Fine-Tuning |
|:---|:---|:---|:---|
| 핵심 목적 | 입력 지시 개선 | 외부 지식 보강 | 모델 행동 적응 |
| 최신 정보 반영 | 낮음 | 높음 | 낮음 |
| 학습 비용 | 없음 | 없음 | 있음 |
| 적합 업무 | 빠른 실험 | 사실 기반 QA | 포맷, 도메인 특화 생성 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Base Model | 범용 언어 능력을 가진 기반 모델로 도메인 적응의 출발점을 제공함 |
| Domain Dataset | 입력과 출력 예시를 통해 조직 용어와 포맷과 판단 기준을 모델에 전달함 |
| Training Objective | SFT나 preference objective를 사용해 원하는 응답 패턴으로 가중치를 이동시킴 |
| Evaluation, Serving | 도메인 정확도와 일반 성능을 함께 확인하고 실제 서비스에 배포함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 데이터 정제     | --> | 모델 추가 학습   | --> | 회귀/도메인 평가 | --> | 배포 및 모니터링 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **데이터 정제**: 업무 예시와 금지 패턴을 정제해 학습셋을 구성함
2. **모델 추가 학습**: full FT나 PEFT 방식으로 기반 모델을 도메인에 맞게 조정함
3. **회귀 및 도메인 평가**: 일반 능력 손상 여부와 업무 성능 향상 여부를 함께 측정함
4. **배포 및 모니터링**: 응답 품질과 실패 사례를 수집해 재학습 루프를 운영함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 도메인 데이터에 과적합되면 범용 지식과 추론 능력이 손상되는 catastrophic forgetting이 발생할 수 있음
   - 해결방안: 일반 데이터와 도메인 데이터를 혼합 학습하고 general benchmark와 domain accuracy로 손실 범위를 검증함
2. 문제: full fine-tuning은 GPU 비용과 학습 시간이 커서 조직별 반복 튜닝에 부담이 될 수 있음
   - 해결방안: PEFT 계열을 우선 검토하고 training cost와 quality gain으로 투자 효과를 검증함
3. 문제: 최신 규정이나 사실을 모델 내부 지식만으로 반영하려 하면 재학습 주기가 길어 운영 민첩성이 떨어질 수 있음
   - 해결방안: 사실성은 RAG로 분리하고 파인튜닝은 형식과 행태 적응에 집중하며 answer freshness와 format pass rate로 역할 분리를 검증함

## Ⅶ. 적용 사례

- 사내 보고서 작성 보조: 조직 문체와 포맷을 모델에 학습시킴, 확인 지표는 format pass rate와 user edit rate임
- 전문 상담 챗봇: 법률, 의료, 금융 도메인 표현을 적응시킴, 확인 지표는 domain accuracy와 hallucination rate임
- 보안 코딩 어시스턴트: 사내 규칙에 맞는 코드 생성을 유도함, 확인 지표는 policy violation rate와 accepted suggestion rate임

## Ⅷ. 결론

파인튜닝은 범용 모델을 조직 맞춤형 모델로 바꾸는 가장 직접적인 방법이지만, 최신 지식 갱신은 RAG로 분리하고 비용은 PEFT로 제어하는 식의 역할 분담이 실무적으로 중요함.
