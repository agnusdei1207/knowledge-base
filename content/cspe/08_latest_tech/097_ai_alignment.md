## 미리 알고가기

- AI alignment는 모델 성능이 아니라 목표와 행동을 인간 가치와 사용 목적에 맞추는 문제임
- 학습 단계 정렬과 런타임 가드레일은 서로 대체가 아니라 보완 관계임
- 유용성, 정직성, 무해성 같은 축 간의 균형이 핵심임

## Ⅰ. 개요

- **정의/개념**: AI 정렬은 모델의 목표와 응답 행동과 시스템 운영 방식이 인간의 의도와 윤리와 정책 기준에 맞도록 학습과 제어와 평가를 통해 맞추는 기술 및 거버넌스 체계임
- **배경/필요성**: 모델 능력이 커질수록 유해 정보 생성, 환각, 편향, 권한 오남용의 위험도 함께 커지므로, 성능 향상과 별개로 안전한 방향 제어가 필요함

## Ⅱ. 특징

- 단일 알고리즘이 아니라 데이터, 학습, 가드레일, 평가를 포함한 전주기 통제 개념임
- 도움성, 정직성, 무해성 간의 균형을 맞춰야 하므로 항상 다목적 최적화 문제가 됨
- 학습 정렬만으로는 모든 운영 위험을 막을 수 없어 런타임 정책과 모니터링이 필수임
- 과도한 정렬은 유용성 저하와 과잉 거절을 부를 수 있어 trade-off 관리가 중요함

## Ⅲ. 종류 및 비교

| 판단 기준 | 능력 향상 중심 | 학습 정렬 | 런타임 정렬 |
|:---|:---|:---|:---|
| 핵심 목적 | 성능 증대 | 모델 행동 교정 | 실시간 제어 |
| 대표 수단 | pretraining, scaling | RLHF, DPO, CAI | guardrail, filter, policy engine |
| 적용 시점 | 학습 | 학습 후반 | 서비스 실행 시 |
| 위험 대응 | 제한적임 | 중간 | 높음 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Value Framework | 도움성, 정직성, 무해성 같은 목표 기준을 정의해 정렬 방향의 기준점이 됨 |
| Alignment Training | SFT, RLHF, DPO, constitutional tuning으로 모델 내부 행동 패턴을 조정함 |
| Runtime Guardrails | 입력 차단, 출력 필터, 권한 제어로 서비스 단계 위험을 완화함 |
| Evaluation, Red Teaming | jailbreak, bias, hallucination을 측정해 정렬 상태를 지속적으로 검증함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 가치 기준 수립  | --> | 학습 정렬 수행   | --> | 런타임 통제 배치 | --> | 지속 평가/개선   |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **가치 기준 수립**: 서비스 목적과 규정에 맞는 정렬 원칙을 정의함
2. **학습 정렬 수행**: 선호 데이터와 규칙을 반영해 모델 정책을 조정함
3. **런타임 통제 배치**: 입력과 출력과 도구 사용을 정책으로 제한함
4. **지속 평가 및 개선**: red teaming과 운영 로그로 취약점을 보완함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 안전성을 지나치게 밀면 정상 요청까지 거절하는 over-refusal이 늘어 모델 유용성이 떨어질 수 있음
   - 해결방안: helpfulness와 harmlessness 평가를 분리하고 refusal rate와 task success rate로 균형을 검증함
2. 문제: 학습 정렬만 믿고 런타임 통제를 소홀히 하면 jailbreak나 정책 우회가 서비스 단계에서 다시 발생할 수 있음
   - 해결방안: guardrail과 tool ACL을 함께 운영하고 jailbreak success rate와 policy violation rate로 방어 수준을 검증함
3. 문제: 정렬 기준이 불명확하면 라벨러와 평가자와 개발자가 서로 다른 기준으로 모델을 조정해 일관성이 깨질 수 있음
   - 해결방안: rubric과 gold set을 명문화하고 evaluator agreement와 audit pass rate로 기준 일치를 검증함

## Ⅶ. 적용 사례

- 기업형 고객지원 챗봇이 금지 답변과 거절 정책을 정렬하도록 설계하며 확인 지표는 unsafe response rate와 customer satisfaction임
- 의료와 법률 보조가 단정적 표현을 억제하고 주의 문구를 강화하도록 정렬을 적용하며 확인 지표는 expert preference score와 risk incident rate임
- 에이전트 시스템이 도구 사용 권한과 승인 정책을 적용하도록 alignment 체계를 운영하며 확인 지표는 unauthorized action rate와 human override frequency임

## Ⅷ. 결론

AI 정렬은 모델을 더 똑똑하게 만드는 문제가 아니라 더 안전하고 예측 가능하게 쓰기 위한 통제 문제이므로, 학습 정렬과 런타임 정렬을 함께 설계해야 함.
