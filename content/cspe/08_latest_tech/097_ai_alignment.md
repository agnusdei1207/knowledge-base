## 미리 알고가기

- $AI$ 정렬 ($AI$ $Alignment$): 대형 모델의 연산 출력물이 인간의 의도, 보편적 윤리관, 법적 가치관에 완벽히 합치되도록 모델의 태도를 사후 교정 및 통제하는 설계/개발 거버넌스 체계임
- $HHH$ 프레임워크 ($Helpful, Honest, Harmless$): 정렬의 $3$대 핵심 축으로, 사용자를 적극 도울 것(유용성), 거짓 없이 정직할 것(신뢰성), 해를 끼치지 말 것(무해성)을 정형화한 가치 강령임
- 적대적 평가 ($Red$ $Teaming$): 모델의 약점을 캐내기 위해 전문 악의적 해커(레드 팀)처럼 가상의 탈옥($Jailbreak$) 질문이나 유해 프롬프트를 일부러 던져 가드레일 붕괴 여부를 실전 테스트하는 모의 침투 평가임
- 런타임 가드레일 ($Guardrails$): 학습 정렬의 맹점을 방어하기 위해, 서비스 API 입출력 단에 설치하여 부적절한 단어나 위험 쿼리를 실시간 여과 차단해 주는 필터 방어 장치임

## Ⅰ. 개요

- **정의/개념**: AI Alignment(정렬)는 초거대 인공지능이 보유한 무소불위의 지능(Capability)이 인류에게 위협이 되지 않도록, HHH(Helpful, Honest, Harmless) 가치 프레임워크에 기반한 SFT, RLHF, DPO 학습 정렬과 API 입출력 가드레일 통제 장치를 다각도로 전개하여 인간의 의도 및 보편적 사회 규범에 영란 조화시키는 안전 제어 아키텍처임
- **배경/필요성**: 모델 체급이 수천억 개 단위로 비대해지고 API 가동 권한(Agentic Tools)이 넓어지면서, 악성 인젝션 코드 유포, 사내 기밀 탈취, 극단적 유해 콘텐츠 자동 생성 등의 위협이 임계점을 통과함에 따라 이를 사회 법망과 규범 테두리 내로 강제 구금하고자 급부상함

## Ⅱ. 특징

- 기계의 순수 추론 성능(Capability) 증대 문제와 상충하는 경향(Alignment Tax 수반)이 있어, 항상 안전성과 유용성 간의 다목적 트레이드오프 조율이 수반됨
- 훈련 과정에서 반영하는 '학습 단계 정렬(RLHF 등)'과 서비스 배포 단에서 격리 차단하는 '실시간 런타임 정렬(가드레일)'이 조화롭게 입체 방어선을 형성함
- 완성도 높은 정렬 상태를 확보하기 위해, 상용 릴리즈 전 반드시 내부 레드 팀(Red Teaming)의 우회 탈옥 침투 테스트 과정을 통과해야 함

## Ⅲ. 종류 및 비교

| 판단 기준 | 기본 성능 가속 중심 (Pre-training) | 학습 단계 정렬 (Alignment Training) | 실시간 런타임 통제 (Runtime Guardrail) |
|:---|:---|:---|:---|
| **물리 제어 시점** | 기저 모델 구축 단계 | 포스트 사전 학습 단계 ($SFT$/$DPO$) | 서비스 API 릴리즈 실행 단계 (실시간) |
| **핵심 통제 방식** | 대규모 말뭉치 자동 회귀 연산 | $HHH$ 선호도 데이터를 활용한 가중치 미세 정렬 | 입력 패턴 매칭, LLM 비판 차단 필터 |
| **위험 우회 대응력** | 매우 취약 (탈옥 프롬프트에 무방비) | 우수함 (유해 질문 거절 문맥 내재화) | 매우 우수함 (질문이 뇌에 닿기 전 외곽 차단) |
| **인프라 오버헤드** | 기준선 | 없음 (서빙 전 훈련 단계서 완료) | 중간 (입출력 단의 추가 스크리닝 연산 비용 수반) |

> 요약: Pre-training은 연산 화력의 극대화고, Alignment Training은 양식과 절제를 모델의 뇌 속에 내재화시키는 훈육이며, Guardrail은 사고를 대비해 울타리를 쳐두는 외곽 치안임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| $HHH$ 가치 헌법 | 정렬의 판단 근거가 되는 도움성, 정직성, 무해성의 세부 항목을 구체화한 규정집임 |
| 정렬 훈련 프레임 | PPO 강화학습, DPO 직접 최적화, KTO(Kahneman-Tversky) 등 정책 가중치를 깎아내는 학습 프레임임 |
| 외곽 가드레일 | Llama Guard 등 입출력 메시지를 모니터링하여 유해 쿼리를 거르는 격리 스크리너임 |
| 레드 팀 ($Red$ $Team$) | 가상의 해커가 되어 악성 페이로드를 주입하여 모델을 고의 오작동시키는 모의 해킹팀임 |

```text
[ AI Alignment (정렬) 다중 방어 메커니즘 ]
User Query ────> [ Input Guardrail (1차 차단) ]
                            │
                            v
                 [ Aligned Model Policy (2차 내재 거절) ]
                            │
                            v
                 [ Output Guardrail (3차 여과) ] ────> Safe Response
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 윤리적 헌법 | --> | 정렬 데이터  | --> | 다중 가드   | --> | 레드티밍 및 |
| 가치관 수립 |     | 훈련 반영    |     | 레일 외곽배치|     | 취약성 패치 |
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **원칙 명문화** — 서비스 도메인의 법적 컴플라이언스 요건을 정의하고 HHH 강령에 입각해 판단 루브릭(Constitution)을 구성함
2. **학습 정렬 집행** — 헌법을 숙지한 AI Judge(또는 인간)의 선호쌍을 모아 DPO 미세 조정을 집행해 가중치 성향을 정숙하게 가다듬음
3. **가드레일 장착** — API 프론트 엔드에 입력 필터링 가드레일 모델을 연동하여, 유해 질문 인젝션 시 원천 차단 동작을 셋업함
4. **적대적 모의 침투** — 레드 팀을 가동해 각종 난해한 탈옥 질문을 밀어 넣고, 우회 공격 성공률($Jailbreak$ $Success$ $Rate$)을 모니터링해 패치함

## Ⅵ. 실무 적용 및 유의점

1. 무해성(Harmlessness) 지표에만 비이성적으로 집착해 정렬 강도를 남용하면, 정상적인 비즈니스 요약 요청이나 평범한 문장 상담까지 싸잡아 거부하는 '과잉 거절($Over-refusal$)' 폐해가 속출하므로, 반드시 도움성 점수를 균형 있게 대조하며 상쇄 지표($harmless-helpful$ $trade-off$)를 실측해야 함
2. 학습 정렬 모델의 완결성만을 과신하고 런타임 외곽 가드레일 장착을 누락하면, 신종 탈옥 공격(예: 다국어 난독화 인젝션) 시 내부 보안이 일순간에 뚫리므로, 반드시 API 통신 외곽 단에 가벼운 'Llama Guard' 등 외곽 모니터를 병행하고 무단 작업 차단율 지표로 무결성을 유지해야 함

## Ⅶ. 결론

- AI 정렬은 인공지능의 거대한 화력에 안전 규범이라는 통제 고삐를 매는 전주기 안전 제어 거버넌스이며, 설계자는 정렬 과도화에 따른 over-refusal로 인한 유용성 삭감(Alignment Tax)을 방지하기 위한 정밀 밸런싱과 모의 레드팀 침투 분석을 통합 가동해 안전한 상용 AI를 서비스해야 함
