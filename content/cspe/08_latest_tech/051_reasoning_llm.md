# 📖 【암기용】 개념 완전 이해

> 목적: 추론 특화 LLM을 처음 봐도 완벽히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: Chain-of-Thought·탐색·자기검증을 모델 내부에 내재화하여 복잡한 추론 문제를 단계적으로 푸는 대형 언어모델
- **왜 필요한가**: 범용 LLM은 수학·코딩·논리 문제에서 한 번에 답을 내려 하므로 GPT-4 기준 ARC-AGI 42%에 그친다. 단계적 사고를 모델 자체에 학습시켜야 복잡한 추론이 가능하다.
- **핵심 직관**: "바로 답 말하기" 대신 "풀이 과정을 먼저 전개한 뒤 스스로 검증하고 답을 내는" 모델이다.

## 깊이 이해
- **배경·문제의식**: GPT-4급 범용 LLM은 패턴 매칭 기반이라 다단계 추론에서 중간 단계를 건너뛰거나 환각(hallucination)이 발생한다. 프롬프트로 CoT를 유도하면 효과가 있지만, 모델 자체가 추론을 학습하면 프롬프트 의존 없이 일관된 추론이 가능하다.
- **작동 원리**: ① 학습 단계에서 CoT(Chain-of-Thought) 데이터로 SFT(Supervised Fine-Tuning)를 수행하거나, RL(강화학습)로 정답에 이르는 사고 경로에 보상을 부여한다. ② 추론 시 모델이 내부적으로 여러 사고 경로(Tree-of-Thought)를 탐색하고, self-verification으로 오류를 걸러낸 뒤 최종 답을 출력한다. ③ reward model이 사고 과정의 품질을 평가하여 최적 경로를 선택한다.
- **비유**: 시험에서 바로 답만 쓰는 학생(범용 LLM)과, 풀이 과정을 쓰면서 중간에 검산도 하는 학생(Reasoning LLM)의 차이다.
- **구체 예시**: o3는 ARC-AGI 벤치마크에서 87.5%, DeepSeek-R1은 AIME 수학경시대회에서 79.8%를 달성했다. 같은 문제에서 GPT-4는 42%에 그쳤다.
- **흔한 오해·주의점**: 추론 토큰이 많을수록 모든 문제에서 정답률이 오른다는 단정은 수치 근거가 부족함. 사고 토큰이 3~10배 증가하므로 단순 질의에는 비용 대비 효과가 낮고, 문제 난이도별 compute-optimal 전략이 필요함.

## 연결 개념
- 추론 스케일링(Inference Scaling) — 추론 시 연산량 증가로 정확도를 높이는 상위 개념
- 추측 디코딩(Speculative Decoding) — 추론 비용 절감을 위한 보완 기법
- RLHF/GRPO — Reasoning LLM 학습에 사용되는 강화학습 기법


# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 추상표현 금지·수치·도식·문제유형 전환을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: CoT·Tree-of-Thought·self-verification을 모델 가중치에 내재화하여 다단계 추론을 수행하는 LLM이다.
> 2. **가치**: ARC-AGI 42%->87.5%, AIME 42%->79.8%로 복잡한 추론 정확도를 +40%p 향상시킨다.
> 3. **판단 포인트**: 토큰 소비 3~10배 증가 -> 난이도별 compute-optimal 전략으로 비용·정확도 균형을 맞춘다.


## Ⅰ. 개요 및 필요성

- 개요: 추론 특화 대형 언어모델
- 배경: 범용 LLM은 다단계 수학·코딩·논리 문제에서 중간 단계를 생략해 근거 없는 답을 생성할 수 있음.
- 필요성: CoT, RL, verifier, test-time compute로 ARC-AGI 등 추론 벤치마크 정확도와 토큰 비용을 함께 평가해야 함.


## Ⅱ. 구조 및 구성요소

```text
   CoT 생성기   ->  Tree-of-      ->   Self-
  (사고 전개)         Thought 탐색        Verification
                                          Reward Model
                                          (경로 평가)
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| CoT 생성기 | 문제->중간 단계->결론 순서로 사고 토큰 전개 | SFT 또는 RL로 학습 |
| Tree-of-Thought 탐색 | 복수 사고 경로를 병렬 탐색·가지치기 | beam search·Best-of-N 적용 |
| Self-Verification | 중간 결과의 논리 일관성 자기 검증 | 오류 감지 시 경로 재탐색 |
| Reward Model | 사고 경로별 품질 점수 산출·최적 경로 선택 | outcome RM vs process RM |

> 요약: CoT 전개 -> 복수 경로 탐색 -> 자기검증 -> 보상 모델 평가의 4단 구조로, 범용 LLM에 없는 내부 추론 루프를 형성한다.


## Ⅲ. 동작원리 및 흐름도

```text
입력 문제 -> CoT 전개 -> 경로 분기(ToT) -> 자기검증 -> RM 평가 -> 최종 답변
         사고 토큰 생성  N개 경로 탐색    오류 필터링   최고 점수 선택
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 입력 문제 파싱, CoT 사고 토큰 순차 생성 | 토큰 길이 제한(최대 32K) |
| 2 | Tree-of-Thought로 N개 사고 경로 분기·탐색 | beam width 4~64 |
| 3 | 각 경로에 self-verification 적용, 논리 오류 필터링 | 모순 검출 시 경로 폐기 |
| 4 | Reward Model이 잔여 경로 점수화, 최고 점수 답변 출력 | 점수 임계값 > 0.7 |

> 요약: 단일 경로 생성(범용 LLM)이 아니라, 복수 경로 탐색+검증+평가의 3중 필터를 거쳐 정확도를 확보한다.


## Ⅳ. 특징

| 구분 | 범용 LLM (GPT-4) | Reasoning LLM (o3/R1) |
|:---|:---|:---|
| 추론 방식 | 단일 패스 토큰 생성 | CoT+ToT 다경로 탐색·검증 |
| ARC-AGI 정확도 | 42% | 87.5% (o3) |
| AIME 정확도 | 42% | 79.8% (DeepSeek-R1) |
| 토큰 소비 | 1× (기준) | 3~10× |
| 학습 기법 | SFT + RLHF | SFT + RL(GRPO) + Reward Model |

> 요약: 정확도 +40%p 대신 토큰 소비 3~10배 — 난이도별 compute-optimal 전략이 비용 효율의 핵심이다.


## Ⅴ. 실무 적용 및 결론

**적용 방안 3개:**
1. 코드 생성·디버깅: Reasoning LLM으로 SWE-bench 71.7% 달성, 기존 LLM 대비 버그 수정률 2배 향상
2. 수학·과학 자동 풀이: MATH-500 97.3%(DeepSeek-R1), 교육·연구 자동화에 적용
3. 비용 최적화: 단순 질의는 범용 LLM, 복잡 추론만 Reasoning LLM으로 라우팅하여 토큰 비용 60% 절감

**결론 (2줄):**
- 기술사 판단: 문제 난이도가 MATH/코딩 수준이면 Reasoning LLM, 단순 분류·요약이면 범용 LLM을 선택한다
- 향후 방향: compute-optimal inference와 증류(distillation)로 소형 Reasoning LLM(7B~32B)이 확산되어 엣지 추론까지 확장될 전망이다
