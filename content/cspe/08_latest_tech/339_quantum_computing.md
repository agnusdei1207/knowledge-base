# 📖 【암기용】 개념 완전 이해

> 목적: 양자컴퓨팅을 큐비트의 중첩·얽힘·간섭을 이용해 특정 문제를 다른 방식으로 계산하는 컴퓨팅 패러다임으로 이해하게 만든다.

## 한눈에
- **개요**: 큐비트와 양자 게이트로 계산 상태를 조작하는 컴퓨팅 방식
- **왜 필요한가**: 소인수분해, 양자계 시뮬레이션, 특정 최적화·탐색 문제는 고전 컴퓨터와 다른 계산 모델이 필요하다.
- **핵심 직관**: 모든 경우를 동시에 답으로 읽는 마법이 아니라, 진폭을 조절해 정답 쪽 확률을 키우는 계산이다.

## 깊이 이해
- **배경·문제의식**: 분자·재료 같은 양자계는 자연 자체가 양자 상태라서 고전 비트로 정확히 모사하면 상태 공간이 지수적으로 커진다.
- **작동 원리**: 큐비트는 0과 1의 중첩 상태를 갖고, 게이트가 상태 벡터를 회전시키며, 측정은 확률적으로 하나의 결과를 낸다.
- **비유**: 물결이 서로 보강·상쇄되듯, 양자 알고리즘은 잘못된 경로의 진폭을 줄이고 원하는 경로의 진폭을 키운다.
- **구체 예시**: Shor 알고리즘은 충분한 오류정정 양자컴퓨터가 있을 때 RSA·ECC 기반 공개키 암호에 위험을 만든다.
- **흔한 오해·주의점**: 양자컴퓨터가 모든 문제를 고전 컴퓨터보다 앞서는 것은 아니다. 현재 장치는 잡음이 큰 NISQ 단계이고 오류정정과 논리 큐비트가 병목이다.

## 연결 개념
- Quantum Error Correction — 물리 큐비트 오류를 논리 큐비트로 보호
- Surface Code — 대표적인 양자 오류정정 코드
- Post-Quantum Cryptography — 양자 위협에 대비한 고전 암호 전환

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.
> 핵심: 양자컴퓨팅은 큐비트, 양자 게이트, 중첩·얽힘·간섭으로 특정 문제의 계산 복잡도 구조를 바꾸는 컴퓨팅 모델이다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: Quantum Computing은 큐비트 상태를 양자 게이트로 조작하고 측정 확률을 이용해 결과를 얻는 계산 방식이다.
> 2. **가치**: Shor, Grover, 양자 시뮬레이션처럼 특정 문제에서 고전 알고리즘과 다른 복잡도 경로를 제공한다.
> 3. **판단 포인트**: 중첩·얽힘·간섭, NISQ 한계, 오류정정, PQC 전환 영향을 함께 설명해야 한다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 양자 계산 원리 확인 | qubit, superposition, entanglement, interference | 병렬 계산으로만 설명 |
| 활용·한계 판단 확인 | Shor, Grover, quantum simulation, NISQ | 모든 문제에 우월하다고 단정 |
| 보안 영향 인식 확인 | RSA/ECC 위험, PQC 전환 | 양자암호와 양자내성암호 혼동 |

> 요약: 이 문제는 양자 원리, 적용 가능한 문제, 오류정정·암호 영향의 균형을 요구한다.

---

## Ⅰ. 개요 및 필요성

- 개요: 큐비트 기반 계산
- 배경: 양자계 시뮬레이션과 일부 수학 문제는 고전 비트 기반 계산에서 상태 공간이 빠르게 커진다.
- 필요성: 양자컴퓨팅은 특정 알고리즘에서 중첩·간섭을 이용해 계산 경로를 줄이고, 기존 공개키 암호 위험을 만든다.

---

## Ⅱ. 구조 및 구성요소

```text
Qubit Register -> Quantum Gate / Circuit -> Entanglement / Interference
      +-> Measurement -> Classical Control
      +-> Error Mitigation / Error Correction
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Qubit | 0과 1의 복소 진폭 상태 표현 | superconducting, ion trap |
| Quantum Gate | 큐비트 상태 변환 | unitary operation |
| Measurement | 양자 상태를 고전 비트 결과로 변환 | 확률적 결과 |
| Classical Control | 회로 실행·보정·결과 후처리 | calibration 필요 |

> 요약: 양자컴퓨터는 큐비트 레지스터와 게이트 회로를 고전 제어가 구동하고 측정 결과를 후처리하는 구조다.

---

## Ⅲ. 동작원리 및 흐름도

```text
문제 인코딩 -> 큐비트 초기화 -> 게이트 회로 적용
-> 간섭으로 진폭 조정 -> 측정 -> 고전 후처리
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 문제를 큐비트와 회로로 인코딩함 | circuit depth |
| 2 | Hadamard, CNOT 등 게이트로 상태를 변환함 | gate fidelity |
| 3 | 간섭을 통해 원하는 결과의 진폭을 키움 | success probability |
| 4 | 반복 측정 후 고전 후처리로 답을 해석함 | sample count |

> 요약: 양자 알고리즘은 회로로 진폭을 설계하고 반복 측정 결과를 통계적으로 해석한다.

---

## Ⅳ. 특징

| 구분 | 고전컴퓨팅 | 양자컴퓨팅 | 판단 기준 |
|:---|:---|:---|:---|
| 정보 단위 | bit | qubit | 중첩 상태 |
| 연산 | 논리 게이트 | unitary gate | 가역 변환 |
| 결과 | 결정적 출력 중심 | 확률 측정 | 반복 샘플링 |
| 병목 | CPU·메모리 | decoherence·gate error | 오류정정 필요 |

> 요약: 양자컴퓨팅은 정보 표현과 결과 해석이 고전컴퓨팅과 다르며, 실용화 병목은 오류율과 논리 큐비트 확보에 있다.

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존/대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 적용 문제 | 범용 고전 계산 | 양자 시뮬레이션·Shor·Grover | 양자 우위 근거 |
| 장치 단계 | GPU/HPC | NISQ·오류정정 양자컴퓨터 | qubit 수·오류율 |
| 보안 영향 | RSA/ECC 유지 | PQC 전환 필요 | 암호 자산 수명 |

> 요약: 양자컴퓨팅은 모든 업무 전환 대상이 아니라 양자 알고리즘이 알려진 문제와 장기 암호 위험에 우선 대응한다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 계산 오류 | decoherence·gate error | error mitigation, QEC | logical error rate |
| 과장 도입 | 문제-알고리즘 불일치 | use case proof, classical baseline | speedup evidence |
| 암호 취약 | Shor 알고리즘 가능성 | PQC inventory, crypto agility | PQC migration ratio |

> 요약: 양자컴퓨팅 리스크는 장치 오류, 적용 과장, 암호 위험이며 오류정정과 PQC 전환 계획으로 관리한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 장치 품질 | gate fidelity, coherence time 추적 | calibration report |
| 알고리즘 | 고전 baseline 대비 결과 검증 | benchmark experiment |
| 보안 대응 | RSA/ECC 자산 목록과 전환 일정 | cryptographic inventory |

> 요약: 양자컴퓨팅 준비도는 큐비트 수보다 오류율, 알고리즘 근거, 암호 자산 전환 계획으로 판단한다.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 양자 시뮬레이션, 최적화, 암호 분석 등 후보 문제를 고전 baseline과 비교 가능한 실험 단위로 정의함.
2. 현재 NISQ 장치에는 error mitigation과 작은 회로 검증을 적용하고, 장기 과제는 fault-tolerant QEC 로드맵으로 분리함.
3. RSA/ECC, 장기 보관 데이터, 인증서 인프라를 조사해 NIST PQC 기반 crypto agility 계획을 수립함.

**결론 (2줄):**
- 기술사 판단: 양자컴퓨팅은 특정 알고리즘과 양자계 문제에 적용 가능성이 있으며, 단기 도입보다 오류정정·PQC 전환 준비가 우선임.
- 향후 방향: 논리 큐비트, surface code, qLDPC, 하이브리드 양자-고전 워크플로가 실용화 판단의 중심이 됨.
