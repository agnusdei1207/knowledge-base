# 📖 【암기용】 개념 완전 이해

> 목적: Video Generation을 처음 봐도 완벽히 이해하게 만든다.

## 한눈에
- **개요**: 텍스트·이미지·오디오 조건을 기반으로 시간적으로 일관된 영상을 생성하는 멀티모달 생성 기술
- **왜 필요한가**: 광고, 교육, 시뮬레이션, 합성 데이터에서 영상 제작 비용과 반복 시간을 줄일 수 있음.
- **핵심 직관**: 한 장의 그림이 아니라 여러 프레임이 시간 순서대로 자연스럽게 이어지는 장면을 생성함.

## 깊이 이해
- **배경·문제의식**: 이미지 생성은 한 순간만 만들면 되지만, 영상은 객체가 프레임마다 동일하게 유지되고 움직임이 자연스러워야 한다.
- **작동 원리**: 텍스트 조건과 시간축 latent를 결합해 spatial-temporal U-Net이나 Transformer가 프레임 간 motion을 모델링하고, denoising으로 영상 latent를 복원함.
- **비유**: 만화 한 컷이 아니라 같은 등장인물이 100컷 동안 일관된 모습과 동작을 유지하게 그리는 작업임.
- **구체 예시**: 제품 사용 장면 5초 영상을 24fps로 생성하면 120프레임의 객체 일관성, 손 움직임, 배경 흔들림을 검증해야 함.
- **흔한 오해·주의점**: 영상 생성은 이미지 생성보다 권리·딥페이크·일관성·물리 오류 위험이 크다. 워터마킹과 검수가 필요함.

## 연결 개념
- Diffusion Model — 영상 생성의 주요 기반 모델
- Text-to-Image Generation — 단일 프레임 생성의 선행 기술
- Synthetic Data — 자율주행·로봇 학습용 합성 영상 활용

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: Video Generation은 공간 정보와 시간축 움직임을 함께 생성하는 멀티모달 생성 기술임.
> 2. **가치**: 영상 시안·교육 콘텐츠·시뮬레이션 데이터를 저비용으로 반복 생성함.
> 3. **판단 포인트**: temporal consistency, 물리 타당성, 딥페이크·저작권 통제를 품질 기준에 포함해야 함.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 시간축 확장 이해 확인 | spatio-temporal 모델링, 프레임 간 객체 일관성 유지 | 프레임 단위 품질과 시간 일관성 혼동 |
| 영상 전용 평가 체계 확인 | FVD, flicker rate, motion 평가 지표 | 이미지 지표(FID)만으로 영상 품질 평가 단정 |
| 안전·권리 통제 판단 확인 | 딥페이크 탐지, 생성 워터마킹, 물리 오류 검수 | 딥페이크·권리 검수 절차 누락 |

> 요약: 이 문제는 생성 기능 소개가 아니라 시간 일관성 확보와 영상 특유의 안전 통제 설계를 묻는다.

## Ⅰ. 개요 및 필요성

- 개요: 조건 기반 영상 생성 기술
- 배경: 영상 제작은 촬영, 편집, 후반작업 비용이 크고 프레임 간 시간 일관성 검증이 필요하다.
- 필요성: text/image condition과 temporal module로 frame consistency, FVD, human preference 기준의 영상 후보를 생성한다.

## Ⅱ. 구조 및 구성요소

```text
Prompt/Image/Audio -> Condition Encoder
  -> Spatio-temporal Generator -> Frame Decoder -> Safety/Watermark
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Condition Encoder | 텍스트·이미지·오디오 조건 처리 | prompt, keyframe, soundtrack |
| Temporal Model | 프레임 간 motion·일관성 모델링 | 3D U-Net, Transformer |
| Frame Decoder | latent를 프레임 영상으로 복원 | 16~120 frames |
| Safety Layer | 딥페이크·권리·워터마크 검증 | 얼굴·상표 탐지 |

> 요약: 영상 생성은 조건 인코딩, 시간축 생성 모델, 프레임 복원, 안전 검증으로 구성됨.

## Ⅲ. 동작원리 및 흐름도

```text
조건 입력 -> 시간축 latent 초기화 -> frame denoising
  -> motion consistency 보정 -> 영상 복원 -> 안전 검수
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 텍스트·이미지·오디오 조건 입력 | prompt alignment ≥0.8 |
| 2 | 시간축 latent denoising | 16~120 frames 생성 |
| 3 | 객체·배경 temporal consistency 검증 | flicker rate <5% |
| 4 | 딥페이크·저작권·워터마크 검사 | 유해 생성 차단율 ≥99% |

> 요약: 영상 생성은 프레임별 품질과 시간축 일관성을 동시에 만족해야 하며 안전 검수가 필수임.

## Ⅳ. 특징

| 구분 | 이미지 생성 | Video Generation | 판단 포인트 |
|:---|:---|:---|:---|
| 생성 단위 | 단일 프레임 | 다중 프레임+motion | 시간 일관성 필요 |
| 계산 비용 | 상대적으로 낮음 | 프레임 수만큼 증가 | GPU·지연 산정 |
| 품질 지표 | FID, CLIP score | FVD, flicker, motion score | 영상 전용 평가 |
| 리스크 | 권리·유해 이미지 | 딥페이크·물리 오류 추가 | 워터마킹 필수 |

> 요약: 영상 생성은 이미지 생성보다 시간 일관성과 안전 리스크 관리가 더 복잡함.

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | Text-to-Video 직접 생성 | Image-to-Video(keyframe 기반) | 선택 기준 |
|:---|:---|:---|:---|
| 제어성 | 프롬프트 의존, 구도 재현 곤란 | 시작 프레임으로 구도·객체 외형 고정 | 제품·브랜드 외형 고정 필요 여부 |
| 객체 일관성 | 장면 전체 생성으로 편차 큼 | keyframe 기준 identity 유지 유리 | 객체 일관성 요구 수준 |
| 제작 워크플로우 | 프롬프트 반복 시행착오 | 이미지 시안 승인 후 영상화 2단계 | 기존 디자인 자산 활용 여부 |

> 요약: 제품 외형 고정이 필요한 상업 영상은 image-to-video, 자유 연출 탐색은 text-to-video가 적합함.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 딥페이크 오용 | 실존 인물 영상 합성 | 인물 생성 제한, 생성 워터마킹(C2PA) | 워터마크 삽입률 |
| 시간 일관성 붕괴 | 프레임 간 motion 모델링 한계 | temporal 평가 게이트, 재생성 정책 | flicker rate <5%, FVD |
| 물리 오류 | 물리 법칙 미반영 생성 | 물리 오류 체크리스트, 전문가 검수 | 물리 규칙 위반률 |

> 요약: 영상 특유의 위험은 딥페이크와 일관성 붕괴이며, 워터마킹과 시간축 품질 게이트로 통제함.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 마케팅 시안: 제품 이미지 keyframe 기반 5초 후보 영상 10개 생성, 브랜드·상표 검수 후 편집
2. 교육 콘텐츠: 절차 설명 영상을 생성하되 안전 절차·장비 위치는 전문가 검수 100% 적용
3. 합성 데이터: 자율주행·로봇 영상은 FVD, 객체 추적 IoU, 물리 규칙 위반률로 품질 검증

**결론 (2줄):**
- 기술사 판단: 내부 시안·시뮬레이션은 Video Generation 활용, 공개 영상은 권리·딥페이크 검수 필수
- 향후 방향: text-to-video, image-to-video, 3D-aware video generation으로 제어성과 일관성이 개선됨
