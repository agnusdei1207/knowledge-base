## 미리 알고가기

- 영상 생성은 시간축을 가진 연속 프레임을 생성하는 멀티모달 생성 기술임
- 품질은 단일 프레임 선명도보다 temporal consistency가 더 중요함
- Text-to-Video와 Image-to-Video와 Video-to-Video가 주요 활용 축임

## Ⅰ. 개요

- **정의/개념**: 영상 생성은 텍스트와 이미지와 기존 비디오 같은 조건 입력을 바탕으로, 시간축을 따라 일관된 프레임 시퀀스와 움직임을 합성해 동영상 클립을 생성하는 시공간 생성형 AI 기술임
- **배경/필요성**: 이미지 생성은 정지 장면까지만 해결하므로, 광고와 프리비즈와 시뮬레이션처럼 움직임 자체가 핵심인 업무를 자동화하려면 시간 일관성을 갖춘 생성 기술이 필요함

## Ⅱ. 특징

- 공간 정보와 시간 정보를 동시에 다뤄야 하므로 이미지 생성보다 구조가 복잡함
- 프레임 간 객체 일관성과 카메라 운동과 물리적 연속성이 품질 핵심임
- I2V와 V2V를 쓰면 자유도는 줄어도 장면 통제가 쉬워짐
- 계산량과 저장량이 커서 실시간 생성과 대규모 운영이 어렵다는 한계가 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | Text-to-Video | Image-to-Video | Video-to-Video |
|:---|:---|:---|:---|
| 입력 조건 | 텍스트만 사용 | 시작 이미지 사용 | 기존 영상 사용 |
| 자유도 | 매우 높음 | 높음 | 중간 |
| 일관성 확보 | 어려움 | 중간 | 쉬움 |
| 대표 용도 | 시나리오 생성 | 숏폼 광고 | 스타일 변환 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Condition Encoder | 프롬프트와 이미지와 참조 영상을 시공간 생성 조건으로 변환함 |
| Spatiotemporal Latent Model | 공간 구조와 시간 연속성을 함께 학습하며 프레임 시퀀스를 형성함 |
| Motion Control Layer | 카메라 움직임과 포즈와 속도 제약을 제어해 원하는 동작을 유지하게 함 |
| Consistency, Upscale Layer | 프레임 간 깜빡임을 줄이고 최종 해상도와 품질을 보정함 |

```text
+-------------------+      +-------------------+      +-------------------+
| Condition Encoder | ---> | ST Latent Model   | ---> | Consistency Layer |
+-------------------+      +-------------------+      +-------------------+
                                                           |
                                                           v
                                                   +-------------------+
                                                   | Upscale / Output  |
                                                   +-------------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 조건 입력 수집   | --> | 시공간 잠재 생성 | --> | 프레임 연속 복원 | --> | 후처리/렌더링   |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **조건 입력 수집**: 프롬프트와 참조 이미지나 영상을 준비함
2. **시공간 잠재 생성**: 시간축이 포함된 latent 표현을 구성함
3. **프레임 연속 복원**: 모델이 프레임 시퀀스를 일관되게 복원함
4. **후처리 및 렌더링**: 업스케일과 flicker 보정을 적용해 최종 영상을 출력함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 프레임이 길어질수록 객체 외형과 배경이 흔들리며 깜빡임이 누적되어 몰입감이 무너질 수 있음
   - 해결방안: temporal consistency module과 frame interpolation을 적용하고 FVD와 flicker score로 검증함
2. 문제: 물체 이동과 충돌이 부자연스럽게 표현되면 영상은 선명해도 물리적 신뢰성이 급격히 떨어질 수 있음
   - 해결방안: motion control과 physics-aware training을 적용하고 motion coherence score와 human realism rating으로 검증함
3. 문제: 고해상도 장면과 긴 길이 생성은 연산량과 저장량이 커서 대규모 서비스 비용이 빠르게 증가할 수 있음
   - 해결방안: latent compression과 chunked generation을 적용하고 cost per second와 render latency로 검증함

## Ⅶ. 적용 사례

- 광고 제작이 스토리보드와 제품 영상을 빠르게 시안화하도록 영상 생성을 적용하며 확인 지표는 production cycle time과 approval rate임
- 게임 개발이 컷신 프리비즈를 자동 생성하도록 영상 생성을 활용하며 확인 지표는 previz turnaround time과 director revision count임
- 자율주행 학습이 희귀 날씨와 사고 상황 영상을 합성하도록 영상 생성을 운영하며 확인 지표는 scenario coverage와 model robustness gain임

## Ⅷ. 결론

영상 생성은 이미지 생성의 확장이 아니라 시간 일관성 제어가 추가된 시공간 생성 문제이므로, temporal consistency와 비용 통제가 핵심 설계 기준이 됨.
