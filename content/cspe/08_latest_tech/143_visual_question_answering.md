## 미리 알고가기

- VQA는 이미지와 질문을 함께 받아 답변을 생성하는 멀티모달 질의응답임
- 단순 객체 인식이 아니라 질문 의도에 맞는 시각 추론이 필요함
- OCR과 grounding이 결합되면 문서형 VQA 활용도가 커짐

## Ⅰ. 개요

- **정의/개념**: VQA는 이미지와 자연어 질문을 동시에 입력받아, 질문 의도에 맞는 시각 단서를 찾고 이를 언어적 추론과 결합해 답변을 생성하거나 분류하는 멀티모달 태스크임
- **배경/필요성**: 캡셔닝은 이미지 전체를 요약할 뿐 특정 질의에 대한 정밀 답변을 주지 못하므로, 문서 이해와 현장 점검과 의료 보조처럼 질문 중심 상호작용을 위한 기술이 필요함

## Ⅱ. 특징

- 질문에 따라 같은 이미지에서도 참조 영역과 답변 방식이 달라짐
- 시각 특징과 언어 특징의 정교한 융합이 핵심 성능 변수임
- 객체 인식, 관계 추론, 수량 판단, OCR이 복합적으로 결합될 수 있음
- 언어 편향과 시각 환각이 결합되면 그럴듯한 오답이 쉽게 발생함

## Ⅲ. 종류 및 비교

| 판단 기준 | 이미지 캡셔닝 | 일반 VQA | DocVQA |
|:---|:---|:---|:---|
| 질의 입력 | 없음 | 자연어 질문 | 문서형 질문 |
| 핵심 처리 | 장면 요약 | 시각 추론 | 시각 추론+OCR |
| 대표 출력 | 설명 문장 | 단답 또는 짧은 응답 | 문서 기반 정답 |
| 고해상도 텍스트 의존성 | 낮음 | 중간 | 매우 높음 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Image Encoder | 이미지의 객체와 위치와 시각 속성을 토큰이나 특징 맵으로 변환함 |
| Question Encoder | 질문의 의도와 제약 조건을 표현해 어떤 시각 단서를 볼지 결정하는 기준을 만듦 |
| Fusion, Attention Layer | 질문 토큰과 시각 토큰을 정렬해 관련 영역에 주의를 집중시키고 공동 추론을 수행함 |
| Answer, Grounding Head | 최종 답변을 생성하거나 분류하고 근거 영역을 함께 제시해 신뢰성을 높임 |

```text
+-------------------+      +-------------------+
| Image Encoder     | ---> | Fusion / Attn.    | ---> +-------------------+
+-------------------+      +-------------------+      | Answer / Ground. |
             ^                                            +-------------------+
             |
+-------------------+
| Question Encoder  |
+-------------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 질문/이미지 입력 | --> | 모달 특징 추출  | --> | 관련 영역 추론  | --> | 답변 및 근거 반환 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **질문과 이미지 입력**: 질의와 시각 데이터를 함께 수신함
2. **모달 특징 추출**: 질문과 이미지 각각을 토큰 표현으로 변환함
3. **관련 영역 추론**: attention으로 질문 관련 시각 근거를 선택함
4. **답변 및 근거 반환**: 정답과 근거 영역을 함께 출력함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 모델이 질문 패턴만 보고 자주 나온 답을 선택하면 이미지를 제대로 읽지 않아도 그럴듯한 오답을 낼 수 있음
   - 해결방안: debiasing 학습과 grounding supervision을 적용하고 VQA accuracy와 grounding score로 검증함
2. 문제: 문서나 영수증처럼 작은 글씨가 핵심인 질의는 시각 토큰만으로 읽기 어려워 답변 오류가 급증할 수 있음
   - 해결방안: OCR 파이프라인과 DocVQA 모델을 결합하고 ANLS와 OCR exact match로 검증함
3. 문제: 답변만 제공하면 사용자가 근거 영역을 확인할 수 없어 고위험 도메인에서 신뢰성이 떨어질 수 있음
   - 해결방안: attention visualization과 evidence span을 제공하고 user trust score와 audit pass rate로 검증함

## Ⅶ. 적용 사례

- 물류 검수 시스템이 박스 훼손 여부와 송장 정보를 질문형으로 확인하도록 VQA를 적용하며 확인 지표는 answer accuracy와 handling time reduction임
- 의료 영상 보조가 특정 병변 존재 여부를 질문에 따라 확인하도록 VQA를 운영하며 확인 지표는 expert agreement와 unsafe answer rate임
- 계약서 QA가 조항과 금액을 문서에서 찾아 답하도록 DocVQA를 활용하며 확인 지표는 ANLS와 retrieval latency임

## Ⅷ. 결론

VQA는 이미지를 보여주는 기술을 질문에 답하는 기술로 확장한 구조이므로, 모달 융합 품질과 OCR 보강과 근거 제시가 실무 신뢰성의 핵심임.
