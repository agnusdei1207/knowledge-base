# 📖 【암기용】 개념 완전 이해

> 목적: Visual Question Answering을 처음 봐도 완벽히 이해하게 만든다.

## 한눈에
- **개요**: 이미지와 자연어 질문을 함께 입력받아 이미지 내용에 대한 답을 생성하는 태스크
- **왜 필요한가**: 사용자는 사진·도면·차트에 대해 단순 설명보다 특정 질문에 대한 답을 원함.
- **핵심 직관**: 그림을 보고 질문을 읽은 뒤, 질문에 필요한 부분만 찾아 답하는 능력임.

## 깊이 이해
- **배경·문제의식**: 이미지 캡셔닝은 전체 설명을 제공하지만, "오른쪽 계기판 수치가 정상 범위인가?" 같은 목적형 질문에는 직접 답하기 어렵다.
- **작동 원리**: 이미지 인코더가 시각 특징을 만들고, 질문 인코더가 의도를 표현하며, fusion/cross-attention이 관련 영역을 찾아 답변을 생성함.
- **비유**: 정비사가 설비 사진을 보고 "압력 게이지가 5bar 이상인가?"라는 질문에 해당 부위를 확인해 답하는 과정임.
- **구체 예시**: 차트 이미지와 "전년 대비 매출 증가율은?" 질문을 입력해 막대 높이와 축 값을 읽고 수치를 계산.
- **흔한 오해·주의점**: VQA는 이미지 이해와 언어 추론이 모두 필요하므로 OCR·수치·공간 관계 질문에서 오류가 증가할 수 있음.

## 연결 개념
- Vision-Language Model — VQA 수행 모델 구조
- Image Captioning — 이미지 전체 설명 생성 태스크
- Document AI — 문서 이미지와 표·차트 질의응답에 활용

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: VQA는 이미지와 자연어 질문을 결합해 질문 관련 시각 근거를 찾아 답하는 태스크임.
> 2. **가치**: 도면·차트·현장 사진에 대한 목적형 질의응답으로 업무 판단 시간을 줄임.
> 3. **판단 포인트**: OCR, 수치 계산, 공간 관계 질문은 별도 검증과 근거 표시가 필요함.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 융합 메커니즘 이해 확인 | 질문 조건 cross-attention으로 관련 영역 grounding 후 답변 | 전체 설명 캡셔닝과 목적형 VQA 태스크 혼동 |
| 질문 유형별 난이도 인식 확인 | OCR·수치 계산·공간 관계 질문의 오류 증가 경향 | 단일 accuracy 수치로 품질 완성 단정 |
| 근거 제시 설계 역량 확인 | bounding box 근거 표시, hallucination rate 관리 | 근거 영역 표시 설계 누락 |

> 요약: 이 문제는 태스크 정의 암기가 아니라 질문 유형별 오류 특성과 근거 기반 검증 설계를 묻는다.

## Ⅰ. 개요 및 필요성

- 개요: 이미지 기반 질의응답 태스크
- 배경: 이미지 캡셔닝은 전체 장면 설명에 적합하지만 특정 객체, 수량, 위치 질문에 직접 답하지 못할 수 있다.
- 필요성: visual grounding과 language reasoning을 결합해 VQA accuracy, grounding IoU, hallucination rate로 응답을 검증한다.

## Ⅱ. 구조 및 구성요소

```text
Image -> Vision Encoder
                        -> Fusion/Cross-Attention -> Answer Decoder
Question -> Text Encoder
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Vision Encoder | 이미지 패치·객체 특징 추출 | ViT, Faster R-CNN |
| Question Encoder | 질문 의도·제약 표현 | Transformer |
| Fusion Layer | 질문 관련 시각 영역 주목 | cross-attention |
| Answer Decoder | 답변 생성·분류 | short answer, free-form |

> 요약: VQA는 이미지 특징과 질문 의미를 융합해 관련 시각 근거를 찾고 답변을 생성함.

## Ⅲ. 동작원리 및 흐름도

```text
이미지+질문 입력 -> 이미지/질문 인코딩
  -> 질문 관련 영역 attention -> 추론/계산 -> 답변 출력
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 이미지와 질문 전처리 | 입력 누락률 <1% |
| 2 | 시각·언어 특징 인코딩 | VQA accuracy ≥80% |
| 3 | 관련 영역 attention 및 추론 | 근거 영역 표시율 90% |
| 4 | 답변 생성·검증 | OCR 질문 exact match ≥90% |

> 요약: VQA는 질문 의도에 맞는 이미지 영역을 찾고, 시각 정보와 언어 추론을 결합해 답변함.

## Ⅳ. 특징

| 구분 | Image Captioning | VQA | 판단 포인트 |
|:---|:---|:---|:---|
| 입력 | 이미지 | 이미지+질문 | 목적형 탐색 가능 |
| 출력 | 전체 설명 | 질문 맞춤 답변 | 업무 질의에 적합 |
| 요구 능력 | 객체·장면 설명 | OCR·공간·수치 추론 | 검증 필요 |
| 한계 | 특정 답 부족 | 질문 유형별 오류 | 근거 영역 표시 |

> 요약: VQA는 특정 질문에 직접 답하지만 OCR·수치·공간 관계 오류를 근거 표시와 보조 모델로 검증해야 함.

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 분류형(폐쇄형) VQA | 생성형(자유형) VQA | 선택 기준 |
|:---|:---|:---|:---|
| 답변 형식 | 사전 정의 후보 중 선택 | 자유 서술·설명 포함 답변 | 질문 개방성 정도 |
| 평가 용이성 | exact match 자동 평가 용이 | 자동 평가 곤란, LLM·사람 평가 병행 | 품질 관리 자동화 요구 |
| 환각 위험 | 후보 제한으로 낮음 | 근거 없는 서술 생성 위험 | 오답 허용 비용 |

> 요약: 점검 체크리스트형 질문은 분류형, 설명이 필요한 개방형 질문은 생성형에 근거 검증을 결합함.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 환각 답변 | 이미지 확인 없이 언어 prior로 답변 | 근거 영역 표시 필수화, 환각 평가셋 | 근거 표시율, hallucination rate |
| OCR·수치 오답 | 작은 문자·차트 축 오독 | OCR·차트 파서 병행 교차검증 | 수치 질문 exact match ≥90% |
| 평가 왜곡 | 쉬운 질문 위주 평가셋 구성 | 질문 유형별 층화 평가셋 운영 | 유형별 accuracy 분리 |

> 요약: 핵심 위험은 언어 prior 기반 환각과 수치 오독이며, 근거 표시와 교차검증으로 통제함.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 설비 점검: 현장 사진과 "밸브가 잠겼는가?" 질문을 입력해 답변과 bounding box 근거 제공
2. 문서·차트 분석: 표·차트 이미지를 OCR과 결합해 수치 질문 exact match 90% 이상 기준 운영
3. 품질 검증: 질문 유형별 accuracy, 근거 영역 IoU, hallucination rate를 대시보드화

**결론 (2줄):**
- 기술사 판단: 이미지에 대한 특정 업무 질문이 많으면 VQA, 전체 설명이면 Image Captioning 적용
- 향후 방향: VQA는 Multimodal RAG와 결합해 이미지 근거·문서 근거를 함께 제시하는 방향으로 발전
