## 미리 알고가기

- AI 워터마킹은 생성 시점에 콘텐츠 내부에 기계 판독용 신호를 삽입해 출처를 추적하는 기술임
- 탐지 정확도만큼 중요한 조건은 사람 눈에 띄지 않으면서 압축과 크롭 이후에도 살아남는 강건성임
- C2PA 같은 메타데이터 기반 증명과 결합할 때 실효성이 커짐

## Ⅰ. 개요

- **정의/개념**: AI Watermarking은 텍스트와 이미지와 오디오 같은 생성형 AI 결과물에 비가시적이거나 제한적으로 가시적인 식별 신호를 삽입해 해당 콘텐츠가 특정 모델이나 생성 경로에서 나왔음을 검증하는 기술임
- **배경/필요성**: 딥페이크와 허위 정보와 저작권 분쟁이 늘면서 생성 사실을 사후 추정하는 방식만으로는 한계가 커져 생성 단계에서 출처 단서를 함께 심는 수단이 중요해짐

## Ⅱ. 특징

- 콘텐츠 품질을 크게 해치지 않으면서도 검출 가능해야 함
- 압축과 리사이즈와 스크린샷 같은 후처리 이후에도 신호가 남아야 함
- 모델 공급자별 키와 검출기 설계가 달라 상호운용성 문제가 생길 수 있음
- 메타데이터가 사라진 환경에서는 워터마크가 출처 단서의 마지막 보루가 될 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | Invisible Watermarking | Visible Watermarking | Content Credentials |
|:---|:---|:---|:---|
| 삽입 위치 | 픽셀, 주파수, 토큰 분포 | 화면 상 로고와 배지 | 메타데이터와 서명 |
| 사용자 인지 | 거의 불가 | 즉시 가능 | 뷰어와 UI 필요 |
| 강점 | 후처리 후에도 검출 가능 | 즉시 라벨링 가능 | 편집 이력과 서명 제공 |
| 한계 | 위조와 제거 대응 필요 | 크롭에 취약 | 스트리핑에 취약 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Generator | 이미지나 텍스트나 오디오를 생성하면서 워터마크 삽입 지점을 함께 제어하는 생성 엔진임 |
| Watermark Encoder | 비밀 키나 규칙에 따라 신호를 픽셀과 주파수와 토큰 분포에 삽입하는 모듈임 |
| Detection Key | 검출기만 해석할 수 있는 키나 패턴 정의로서 위조와 무단 제거를 어렵게 만드는 보안 요소임 |
| Verifier | 의심 콘텐츠에서 신호 존재 여부와 신뢰도를 판정하는 검출기임 |
| Robustness Evaluator | 압축과 크롭과 재녹화 이후에도 검출률이 유지되는지 측정하는 품질 평가 계층임 |

```text
+------------+    +------------------+    +------------------+    +-----------+
| Generator  | -> | Watermark Encoder| -> | Distributed Media| -> | Verifier  |
+------------+    +------------------+    +------------------+    +-----------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
| 콘텐츠 생성  | -> | 신호 삽입    | -> | 배포 및 유통  | -> | 의심본 수집  | -> | 검출 및 판정 |
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
```

1. **콘텐츠 생성**: 생성 모델이 텍스트나 이미지나 오디오를 만듦
2. **신호 삽입**: 지정된 키와 규칙으로 워터마크를 은닉함
3. **배포 및 유통**: 결과물이 플랫폼과 메신저와 웹으로 확산됨
4. **의심본 수집**: 검증 대상 콘텐츠를 다시 가져옴
5. **검출 및 판정**: 신호 존재와 강도와 위변조 가능성을 평가함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 강한 압축과 크롭과 재촬영이 반복되면 워터마크 신호가 약화되어 검출 신뢰도가 크게 떨어질 수 있음
   - 해결방안: multi domain watermark와 robustness training을 적용하고 post transform detection recall과 false negative rate로 검증함
2. 문제: 키 관리가 약하거나 알고리즘이 단순하면 공격자가 신호를 모방하거나 제거해 허위 출처를 만들 수 있음
   - 해결방안: keyed verification과 secure key rotation을 적용하고 forgery success rate와 key compromise incident count로 검증함
3. 문제: 공급자마다 서로 다른 워터마크 체계를 쓰면 플랫폼과 수사기관이 통합 검증하기 어려울 수 있음
   - 해결방안: common verification interface와 provenance metadata 연계를 적용하고 cross vendor verification coverage와 interoperability score로 검증함

## Ⅶ. 적용 사례

- 생성 이미지 서비스가 배포 전 비가시성 워터마크를 삽입하며 확인 지표는 post transform detection recall과 image quality score임
- 음성 합성 플랫폼이 오디오 워터마크와 키 회전을 함께 운영하며 확인 지표는 forgery success rate와 detector precision임
- 뉴스 플랫폼이 AI 워터마킹과 C2PA 라벨을 병행 적용하며 확인 지표는 provenance verification coverage와 misinformation dispute rate임

## Ⅷ. 결론

AI 워터마킹은 모든 위조를 막는 만능 기술은 아니지만 생성 단계에서 출처 단서를 남기는 실용적 장치이므로 강건성과 검증 체계를 함께 설계해야 함.
