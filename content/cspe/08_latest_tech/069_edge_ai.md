## 미리 알고가기

- 엣지 AI는 데이터 발생 지점 근처의 장비나 게이트웨이에서 AI 추론을 수행하는 방식임
- 온디바이스 AI가 개인 단말 중심이라면 엣지 AI는 공장, 매장, 도로 같은 현장 인프라 중심임
- 현장 실시간 제어, 네트워크 절감, 데이터 주권 확보가 주요 도입 목적임

## Ⅰ. 개요

- **정의/개념**: 엣지 AI는 카메라, 센서, 게이트웨이, 산업 장비 같은 현장 인프라 가까이에서 데이터를 전처리하고 AI 추론과 제어를 수행하는 분산형 실행 구조임
- **배경/필요성**: 모든 현장 데이터를 중앙 클라우드로 보내면 지연 시간과 전송 비용이 커지고 연결 장애 시 서비스가 멈출 수 있으므로, 데이터 생성 지점에서 즉시 판단하는 구조가 필요함

## Ⅱ. 특징

- 데이터 발생 지점과 추론 위치가 가까워 실시간 제어와 경보 처리에 유리함
- 클라우드 전송량을 줄여 네트워크 비용과 백홀 부담을 낮춤
- 현장 장비가 분산되어 있어 운영, 배포, 장애 대응 체계가 복잡해질 수 있음
- 센서 특성과 주변 환경이 달라 모델 성능 관리와 재학습 체계가 중요함

## Ⅲ. 종류 및 비교

| 판단 기준 | 클라우드 AI | 온디바이스 AI | 엣지 AI |
|:---|:---|:---|:---|
| 주 실행 위치 | 중앙 데이터센터 | 개인 기기 | 현장 장비 및 게이트웨이 |
| 대표 목적 | 대규모 범용 처리 | 개인화와 프라이버시 | 실시간 제어와 현장 자동화 |
| 연결 장애 영향 | 큼 | 낮음 | 중간 |
| 운영 복잡도 | 중앙 집중형 | 단말 분산형 | 현장 분산형 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Data Source | 카메라, 센서, PLC가 원천 데이터를 생산해 현장 의사결정의 입력을 제공함 |
| Edge Node | GPU, NPU, TPU 기반 장비가 현장 가까이에서 전처리와 추론을 수행함 |
| Local Action Layer | 탐지 결과를 설비 제어, 경보, 차단 같은 즉시 행위로 연결해 지연을 최소화함 |
| Cloud Control Plane | 모델 배포, 로그 수집, 재학습, 정책 관리로 현장 장비군을 중앙에서 통제함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 현장 데이터 수집 | --> | 엣지 전처리   | --> | 로컬 추론/판단 | --> | 제어 및 요약 동기화 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **현장 데이터 수집**: 카메라, 센서, 로그 등 원천 데이터를 실시간으로 수집함
2. **엣지 전처리**: 대역폭과 성능을 고려해 필요한 특징만 추출하고 잡음을 제거함
3. **로컬 추론 및 판단**: 현장 장비에서 탐지와 분류와 예측을 수행해 즉시 의사결정을 내림
4. **제어 및 요약 동기화**: 필요한 제어를 실행하고 요약 정보만 중앙 시스템에 전송함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 현장 장비 수가 많아질수록 모델 배포와 버전 관리와 장애 대응이 복잡해져 운영 비용이 커질 수 있음
   - 해결방안: 중앙 MLOps와 원격 장비 관리 체계를 도입하고 deployment success rate와 MTTR로 운영 효율을 검증함
2. 문제: 현장별 조도와 소음과 설비 차이로 입력 분포가 달라지면 추론 정확도가 빠르게 흔들릴 수 있음
   - 해결방안: 현장별 성능 모니터링과 재학습 피드백 루프를 운영하고 false alarm rate와 accuracy drift로 품질을 검증함
3. 문제: 저전력 장비에 무거운 모델을 탑재하면 응답 지연과 발열 문제가 동시에 발생할 수 있음
   - 해결방안: 모델 경량화와 계층형 추론 구조를 적용하고 end-to-end latency와 device temperature로 성능을 검증함

## Ⅶ. 적용 사례

- 스마트 공장 불량 검출: 카메라 영상을 현장 장비에서 바로 판정함, 확인 지표는 defect detection rate와 line latency임
- 지능형 CCTV 분석: 사람 침입과 이상 행동을 로컬 추론함, 확인 지표는 false positive rate와 alert delay임
- 도로변 교통 분석: 차량 흐름과 위험 상황을 현장 게이트웨이에서 계산함, 확인 지표는 event detection time과 bandwidth saving임

## Ⅷ. 결론

엣지 AI는 현장 실시간성과 네트워크 절감을 동시에 달성하는 분산형 실행 구조이므로, 중앙 집중형 AI보다 장비 운영과 모델 생명주기 관리 체계를 더 강하게 설계해야 함.
