# 📖 【암기용】 개념 완전 이해

> 목적: Markov Decision Process를 처음 봐도 완벽히 이해하게 만든다.

## 한눈에
- **정의**: 상태, 행동, 전이확률, 보상, 할인율로 순차 의사결정 문제를 수학적으로 표현한 모델
- **왜 필요한가**: 강화학습 문제를 명확히 정의하려면 무엇을 상태로 보고 어떤 행동과 보상을 줄지 구조화해야 함.
- **핵심 직관**: 현재 상태와 선택한 행동만 알면 다음 상태와 보상이 결정되는 의사결정 지도임.

## 깊이 이해
- **배경·문제의식**: 순차 의사결정은 현재 선택이 미래 결과에 영향을 준다. MDP는 이 과정을 상태 전이와 보상으로 모델링함.
- **작동 원리**: 에이전트는 상태 s에서 행동 a를 선택하고, 환경은 전이확률 P(s'|s,a)에 따라 다음 상태와 보상 R(s,a)를 제공함.
- **비유**: 보드게임에서 현재 말 위치와 선택한 이동만 알면 다음 위치와 점수가 정해지는 규칙표와 같음.
- **구체 예시**: 재고 관리에서 상태=현재 재고·수요, 행동=발주량, 보상=매출-재고비-품절비로 MDP를 구성.
- **흔한 오해·주의점**: 현실 문제는 과거 정보가 필요할 수 있다. 현재 상태가 충분하지 않으면 Markov property가 깨져 POMDP나 상태 확장이 필요함.

## 연결 개념
- Reinforcement Learning — MDP를 풀어 최적 정책을 학습
- Bellman Equation — MDP 가치함수의 재귀식
- Policy — 상태에서 행동을 선택하는 함수

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: MDP는 순차 의사결정을 상태·행동·전이·보상·할인율로 모델링함.
> 2. **가치**: 강화학습 문제를 수학적으로 정의하고 최적 정책·가치함수 계산의 기반을 제공함.
> 3. **판단 포인트**: Markov property 충족 여부와 상태·보상 설계가 모델 품질을 결정함.

## Ⅰ. 개요 및 필요성

MDP는 순차 의사결정 문제의 수학적 모델임. 강화학습은 에이전트의 행동이 미래 상태와 보상에 영향을 주는 문제를 다룬다. MDP는 이를 표준 구성요소로 정의해 정책 최적화의 기반을 제공한다.

## Ⅱ. 구조 및 구성요소

```text
State S + Action A → Transition P(s'|s,a)
  → Reward R(s,a) → Discount γ → Policy π(a|s)
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| State S | 의사결정 시점의 환경 정보 | Markov property 필요 |
| Action A | 에이전트 선택 가능 행동 | discrete/continuous |
| Transition P | 행동 후 다음 상태 확률 | model-free는 명시 추정 생략 |
| Reward R, γ | 즉시 보상과 미래 보상 할인 | γ=0.9~0.99 |

> 요약: MDP는 상태와 행동에 따른 전이·보상 구조를 정의하고 정책이 이를 기반으로 행동을 선택함.

## Ⅲ. 동작원리 및 흐름도

```text
상태 st 관찰 → 행동 at 선택 → 전이 P로 st+1 이동
  → 보상 rt 수신 → 할인 누적 보상 계산 → 정책 개선
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 상태·행동 공간 정의 | 상태 누락률 <1% |
| 2 | 보상 함수와 할인율 설정 | γ=0.9~0.99 |
| 3 | 전이 또는 경험 데이터 수집 | transition coverage ≥80% |
| 4 | 정책·가치함수 최적화 | 누적 보상 baseline 대비 5% 개선 |

> 요약: MDP는 현재 상태와 행동으로 다음 상태·보상을 정의하고 누적 보상을 최대화하는 정책을 찾음.

## Ⅳ. 특징

| 구분 | 단일 의사결정 | MDP | 판단 포인트 |
|:---|:---|:---|:---|
| 시간성 | 1회 선택 | 순차 선택 | 미래 영향 중요 |
| 입력 | 현재 feature | 상태·전이·보상 | 상태 설계 핵심 |
| 목표 | 즉시 성과 | 할인 누적 보상 | 장기 최적화 |
| 한계 | 단순 | Markov 가정 필요 | POMDP 여부 검토 |

> 요약: MDP는 장기 의사결정을 모델링하지만 현재 상태가 미래를 충분히 설명해야 한다는 가정이 필요함.

## Ⅴ. 실무 적용 및 결론

**적용 방안 3개:**
1. 오토스케일링: 상태=CPU·QPS·지연, 행동=pod 증감, 보상=성능 SLA-비용으로 MDP 정의
2. 재고 최적화: 상태=재고·수요 예측, 행동=발주량, 보상=매출-보관비-품절비로 모델링
3. 검증 절차: Markov property가 약하면 과거 5~10 step feature를 상태에 포함하거나 POMDP 접근 적용

**결론 (2줄):**
- 기술사 판단: 순차 의사결정 문제는 먼저 MDP로 상태·행동·보상을 정의한 뒤 RL 알고리즘 선택
- 향후 방향: 현실의 부분관측·다중 에이전트 문제를 POMDP·MARL로 확장
