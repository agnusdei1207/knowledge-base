## 미리 알고가기

- MDP는 강화학습 문제를 $\langle S, A, P, R, \gamma \rangle$로 정의하는 수학적 틀임
- 마르코프 성질은 미래가 현재 상태만으로 결정된다는 가정임
- 상태 정의가 불완전하면 실제 문제는 POMDP에 가까워질 수 있음

## Ⅰ. 개요

- **정의/개념**: MDP는 상태 $S$, 행동 $A$, 전이확률 $P$, 보상 $R$, 할인율 $\gamma$로 순차 의사결정 문제를 모델링해, 에이전트가 장기 반환값을 최대화하는 정책을 찾도록 만드는 확률적 제어 프레임워크임
- **배경/필요성**: 강화학습 알고리즘이 무엇을 관측하고 어떤 행동을 평가해야 하는지 명확히 정의하지 않으면 최적화 대상과 보상 전파 구조를 수학적으로 다룰 수 없으므로, 문제를 정형화하는 틀이 필요함

## Ⅱ. 특징

- 현재 상태와 행동이 다음 상태와 보상을 결정하는 수학적 환경을 제공함
- 정책 평가와 정책 개선과 가치 반복의 기반 구조가 됨
- 할인율 $\gamma$로 단기 보상과 장기 보상 균형을 조정할 수 있음
- 상태 정의가 불완전하면 마르코프 가정이 깨져 학습 품질이 급격히 떨어질 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | Multi-armed Bandit | MDP | POMDP |
|:---|:---|:---|:---|
| 상태 전이 | 없음 | 있음 | 있음 |
| 관측 완전성 | 완전 | 완전 | 불완전 |
| 장기 의사결정 | 낮음 | 높음 | 높음 |
| 모델 복잡도 | 낮음 | 중간 | 높음 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| State $S$ | 현재 의사결정에 필요한 정보를 요약한 집합으로 마르코프 성질이 성립하도록 정의돼야 함 |
| Action $A$ | 에이전트가 현재 상태에서 선택할 수 있는 행동 집합으로 정책의 출력 대상이 됨 |
| Transition $P$ | 행동 이후 다음 상태로 이동할 확률 구조로 환경 동역학을 표현함 |
| Reward $R$, Discount $\gamma$ | 행동의 즉시 가치와 미래 가치 반영 비율을 정의해 최적화 목표를 구성함 |

```text
+-------------------+      +-------------------+      +-------------------+
| State S           | ---> | Action A          | ---> | Transition P      |
+-------------------+      +-------------------+      +-------------------+
                                                           |
                                                           v
                                                   +-------------------+
                                                   | Reward R, gamma   |
                                                   +-------------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 상태 정의      | --> | 행동 집합 정의  | --> | 전이/보상 모델화 | --> | 정책 최적화 적용 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **상태 정의**: 의사결정에 필요한 관측 정보를 상태로 설계함
2. **행동 집합 정의**: 가능한 제어 행동을 정함
3. **전이 및 보상 모델화**: 행동 결과와 보상 규칙을 정의함
4. **정책 최적화 적용**: DP나 RL로 최적 정책을 학습함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 상태에 과거 문맥이나 숨은 변수가 빠지면 마르코프 가정이 깨져 정책이 같은 상태에서 일관된 결정을 내리지 못할 수 있음
   - 해결방안: state augmentation과 history feature를 적용하고 return variance와 policy stability로 검증함
2. 문제: 상태와 행동 공간이 지나치게 커지면 정확한 전이 추정과 가치 계산이 어려워져 학습 복잡도가 급격히 증가할 수 있음
   - 해결방안: state abstraction과 function approximation을 적용하고 sample efficiency와 convergence speed로 검증함
3. 문제: 실제 환경 전이확률을 정확히 모르면 이론적 MDP는 정의돼도 모델 기반 최적화가 현실과 어긋날 수 있음
   - 해결방안: model-free RL이나 offline dataset 기반 추정을 적용하고 sim-to-real gap과 deployment reward로 검증함

## Ⅶ. 적용 사례

- 쿠폰 추천이 고객 상태와 행동과 구매 보상을 MDP로 모델링하도록 적용하며 확인 지표는 average return과 conversion lift임
- 로봇 제어가 위치와 속도와 토크 결정을 MDP로 정형화하도록 운영하며 확인 지표는 task completion rate와 collision rate임
- 데이터센터 제어가 온도와 부하와 냉각 행동을 MDP로 정의하도록 활용하며 확인 지표는 energy efficiency와 SLA violation rate임

## Ⅷ. 결론

MDP는 강화학습의 성패를 좌우하는 문제 정형화 도구이므로, 상태 정의가 마르코프 성질을 충분히 만족하는지가 가장 중요한 설계 판단 기준임.
