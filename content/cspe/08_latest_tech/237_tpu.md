## 미리 알고가기

- TPU는 텐서 연산에 특화된 전용 AI 가속기로 대규모 행렬 처리 효율을 높이도록 설계됨
- 대형 학습과 추론에서 높은 처리량과 전력 효율을 목표로 하며 소프트웨어 스택 의존성이 큼
- Systolic Array와 HBM과 전용 컴파일 체계가 핵심 구조임

## Ⅰ. 개요

- **정의/개념**: TPU는 텐서 연산과 행렬 곱 처리에 최적화된 전용 AI 프로세서로 대규모 딥러닝 학습과 추론에서 높은 처리량과 에너지 효율을 제공하는 가속기임
- **배경/필요성**: 초대형 딥러닝 모델의 계산량 증가와 데이터센터 비용 압박으로 범용 GPU 외에도 더 높은 연산 밀도와 전력 효율을 가진 전용 가속기 수요가 커짐

## Ⅱ. 특징

- Systolic Array 기반 행렬 연산으로 높은 처리 효율을 제공함
- 대형 모델 학습을 위한 HBM과 고속 상호연결 구조를 갖춤
- 전용 컴파일러와 실행 환경에 최적화되어 특정 생태계에서 강함
- 범용성은 GPU보다 낮아 이식성과 벤더 종속성 고려가 필요함

## Ⅲ. 종류 및 비교

| 판단 기준 | TPU | GPU | CPU |
|:---|:---|:---|:---|
| 행렬 연산 최적화 | 매우 높음 | 높음 | 낮음 |
| 범용성 | 중간 | 높음 | 매우 높음 |
| 전력 효율 | 높음 | 중간 이상 | 낮음 |
| 주요 제약 | 소프트웨어 종속성 | 전력과 메모리 | 처리량 부족 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Matrix Multiply Unit | Systolic Array 구조로 대규모 행렬 곱을 고효율로 수행하는 핵심 연산 블록임 |
| HBM and Unified Memory Path | 대량의 파라미터와 activation을 빠르게 공급해 연산 유휴 시간을 줄이는 메모리 계층임 |
| Interconnect Fabric | 다수 TPU 칩을 묶어 대규모 분산 학습을 가능하게 하는 고속 연결 구조임 |
| XLA or Compiler Stack | 모델 그래프를 TPU 친화적으로 컴파일하고 최적화하는 소프트웨어 계층임 |
| Runtime Control | 배치와 실행과 오류 처리를 조정해 안정적 운영을 지원하는 실행 제어 계층임 |

```text
+-------------------+    +-------------------+    +-------------------+
| Matrix Unit       |<-> | HBM Memory Path   |<-> | Interconnect      |
+-------------------+    +-------------------+    +-------------------+
             |
             v
      +-------------------+
      | Compiler/Runtime  |
      +-------------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
| 모델 컴파일  | -> | 텐서 적재    | -> | 행렬 연산    | -> | 다칩 동기화  | -> | 결과 반환    |
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
```

1. **모델 컴파일**: 그래프를 TPU 실행 형식으로 변환함
2. **텐서 적재**: 입력과 파라미터를 고속 메모리에 적재함
3. **행렬 연산 수행**: Systolic Array에서 텐서 연산을 반복 실행함
4. **다칩 동기화**: 분산 학습 시 노드 간 결과를 동기화함
5. **결과 반환**: 예측값이나 gradient를 상위 시스템으로 전달함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 전용 컴파일 경로와 연산 제약 때문에 일부 모델과 연산은 이식성과 최적화 난도가 높을 수 있음
   - 해결방안: compiler compatibility testing과 graph optimization review를 적용하고 model portability score와 compile failure rate로 검증함
2. 문제: 대규모 분산 환경에서 상호연결 효율이 낮으면 칩 수 증가 대비 성능 향상이 제한될 수 있음
   - 해결방안: topology aware partitioning과 communication optimization을 적용하고 distributed scaling efficiency와 sync overhead ratio로 검증함
3. 문제: 특정 생태계 의존성이 크면 장기적으로 벤더 종속과 운영 유연성 저하가 발생할 수 있음
   - 해결방안: multi platform model path와 portability benchmark를 적용하고 vendor lock in risk score와 migration effort index로 검증함

## Ⅶ. 적용 사례

- 대규모 학습 환경이 컴파일 호환성 검증을 운영하며 확인 지표는 model portability score와 compile failure rate임
- TPU 기반 분산 학습이 토폴로지 최적화를 수행하며 확인 지표는 distributed scaling efficiency와 sync overhead ratio임
- 멀티클라우드 AI 조직이 이식성 벤치마크를 운영하며 확인 지표는 vendor lock in risk score와 migration effort index임

## Ⅷ. 결론

TPU는 높은 텐서 처리 효율을 제공하지만 전용 생태계 특성이 강하므로 성능과 이식성의 균형을 고려해 도입해야 함.
