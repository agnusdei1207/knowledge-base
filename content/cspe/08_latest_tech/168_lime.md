# 📖 【암기용】 개념 완전 이해

> 목적: LIME을 처음 봐도 완벽히 이해하게 만든다.

## 한눈에
- **개요**: 특정 예측 주변에서 단순한 대리모델을 학습해 블랙박스 모델의 국소적 판단 근거를 설명하는 기법
- **왜 필요한가**: 복잡한 모델 전체를 이해하기 어렵더라도 특정 고객·환자·문서에 대한 예측 이유는 설명해야 함.
- **핵심 직관**: 어려운 모델을 그 예측 주변에서만 간단한 직선 모델로 근사해 어떤 특성이 영향을 줬는지 보는 방식임.

## 깊이 이해
- **배경·문제의식**: 딥러닝·앙상블 모델은 내부 구조가 복잡해 개별 예측 이유를 설명하기 어렵다. LIME은 모델 종류와 무관하게 설명 가능함.
- **작동 원리**: 원본 입력 주변을 조금씩 변형한 샘플을 만들고 블랙박스 모델 예측을 얻은 뒤, 원본과 가까운 샘플에 높은 가중치를 줘 선형 대리모델을 학습함.
- **비유**: 산 전체의 지형을 알 수 없어도 현재 서 있는 지점 주변의 경사만 측정해 어느 방향이 결과에 영향을 주는지 파악하는 것임.
- **구체 예시**: 텍스트 분류에서 특정 단어를 제거·삽입한 샘플로 주변 예측을 관찰해 스팸 판정에 기여한 단어 Top-5를 표시.
- **흔한 오해·주의점**: LIME 설명은 국소 근사이므로 전체 모델 설명이 아니다. 샘플링 방식에 따라 설명이 흔들릴 수 있음.

## 연결 개념
- Explainable AI — 모델 예측 설명 전체 분야
- SHAP — Shapley value 기반 설명기법
- Local Explanation — 특정 예측 인스턴스 중심 설명

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: LIME은 특정 입력 주변에서 블랙박스 모델을 단순 대리모델로 근사해 설명함.
> 2. **가치**: 모델 종류와 무관하게 개별 예측의 feature 기여도를 빠르게 제공함.
> 3. **판단 포인트**: 국소 설명이므로 샘플링 안정성, kernel width, fidelity를 검증해야 함.

## Ⅰ. 개요 및 필요성

LIME은 모델 불가지론적 국소 설명기법이다. 복잡한 AI 모델은 개별 예측 이유를 직접 해석하기 어렵다. LIME은 특정 입력 주변에서 단순한 대리모델을 학습해 예측 근거를 설명한다.

## Ⅱ. 구조 및 구성요소

```text
Instance x → Perturbation Samples → Black-box Predictions
  → Weighted Local Surrogate → Feature Importance
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Perturbation | 입력 주변 샘플 생성 | 단어 제거, feature masking |
| Black-box Model | 설명 대상 예측 제공 | 모델 내부 접근 불필요 |
| Kernel Weight | 원본과 가까운 샘플 가중 | distance 기반 |
| Surrogate Model | 국소 선형 모델 학습 | interpretable coefficients |

> 요약: LIME은 입력 주변 샘플과 블랙박스 예측을 이용해 국소 대리모델의 계수로 설명을 생성함.

## Ⅲ. 동작원리 및 흐름도

```text
설명 대상 입력 선택 → 주변 샘플 생성 → 모델 예측 수집
  → 거리 가중치 부여 → 선형 대리모델 학습 → 중요도 출력
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 설명할 인스턴스와 feature 정의 | 누락 feature 0건 |
| 2 | perturbation 샘플 N개 생성 | N=1,000~5,000 |
| 3 | 거리 가중 선형 대리모델 학습 | local fidelity ≥0.9 |
| 4 | feature 중요도 Top-K 출력 | 설명 안정성 변동률 <10% |

> 요약: LIME은 원본 주변에서 생성한 샘플로 블랙박스 행동을 근사하고 feature 중요도를 산출함.

## Ⅳ. 특징

| 구분 | LIME | SHAP | 판단 포인트 |
|:---|:---|:---|:---|
| 설명 범위 | 국소 대리모델 | Shapley value 기여도 | 빠른 local 설명은 LIME |
| 모델 의존성 | 모델 불가지론 | 모델별 최적화 가능 | black-box 대응 |
| 계산 비용 | 샘플 수에 비례 | feature 수에 민감 | 대규모 feature는 비용 검토 |
| 한계 | 샘플링 불안정 | 계산 복잡도 | fidelity·stability 측정 |

> 요약: LIME은 모델 독립성과 직관성이 강점이나 국소 근사의 안정성과 충실도 검증이 필요함.

## Ⅴ. 실무 적용 및 결론

**적용 방안 3개:**
1. 고객 심사 설명: 대출 거절 사례별 LIME Top-5 feature를 내부 상담 화면에 제공
2. 텍스트 분류 검증: 혐오표현 분류에서 기여 단어를 시각화하고 민감 단어 편향 여부 점검
3. 운영 품질: local fidelity 0.9 미만 또는 설명 변동률 10% 초과 시 SHAP 또는 모델별 설명으로 대체

**결론 (2줄):**
- 기술사 판단: 빠른 개별 예측 설명은 LIME, 규제·감사 수준 기여도 산정은 SHAP 병행
- 향후 방향: LIME은 LLM 자연어 설명과 결합해 비전문가용 local explanation으로 확장
