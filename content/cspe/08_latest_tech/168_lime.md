## 미리 알고가기

- LIME은 복잡한 모델 전체가 아니라 특정 예측 주변만 단순 모델로 근사해 설명함
- 모델 내부 구조를 몰라도 입력과 출력만 있으면 적용 가능한 model-agnostic 기법임
- 샘플링 기반이므로 실행 조건에 따라 설명 결과가 조금씩 달라질 수 있음

## Ⅰ. 개요

- **정의/개념**: LIME은 설명이 필요한 특정 입력 인스턴스 주변에 교란 샘플을 생성하고, 그 주변 영역만 단순한 대리 모델로 근사해 개별 예측의 주요 특징 기여도를 설명하는 국소 설명 기법임
- **배경/필요성**: 고성능 블랙박스 모델은 개별 고객이나 문서나 이미지에 대한 판단 이유를 바로 설명하기 어려우므로, 특정 사례 단위의 직관적 설명을 빠르게 제공할 수 있는 경량 XAI 방법이 필요해짐

## Ⅱ. 특징

- 입력과 출력만 활용하므로 딥러닝과 트리와 SVM 등 다양한 모델에 공통 적용할 수 있음
- 텍스트와 표와 이미지에서 모두 사용할 수 있어 현장 범용성이 높음
- 설명 범위가 국소 영역에 한정되므로 전체 모델의 작동 원리 설명에는 적합하지 않음
- 샘플링 방식과 거리 함수와 해석 표현에 따라 안정성과 충실도가 달라질 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | LIME | SHAP |
|:---|:---|:---|
| 설명 범위 | 개별 예측 국소 설명에 특화 | 국소와 전역 설명 모두 가능 |
| 계산 특성 | 비교적 빠르고 가벼움 | 이론적으로 엄밀하지만 비용이 큼 |
| 이론 기반 | 대리 모델 근사 | Shapley value |
| 주요 한계 | 샘플링 불안정성 | 높은 연산 비용 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Target Instance | 왜 이런 결과가 나왔는지 설명이 필요한 개별 입력 사례를 의미함 |
| Perturbation Sampler | 원본 입력 주변에서 부분 삭제와 마스킹과 값 변형을 통해 유사 샘플을 다수 생성함 |
| Black-box Predictor | 생성된 샘플에 대한 예측값을 반환해 국소 행동 패턴을 관찰하게 함 |
| Local Surrogate Model | 원본에 가까운 샘플에 가중치를 주어 선형 모델 등 해석 가능한 모델을 적합함 |
| Explanation Output | 계수와 중요 피처와 강조 영역을 사용자에게 설명 가능한 형태로 제시함 |

```text
+-------------------+      +-------------------+      +-------------------+
| Target Instance   | ---> | Perturb Samples   | ---> | Black-box Output  |
+-------------------+      +-------------------+      +-------------------+
                                                           |
                                                           v
                                                   +-------------------+
                                                   | Local Surrogate   |
                                                   +-------------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 설명 대상 선택  | --> | 주변 샘플 생성  | --> | 국소 모델 적합  | --> | 기여도 해석 반환 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **설명 대상 선택**: 개별 예측 사례 하나를 지정함
2. **주변 샘플 생성**: 특징을 변형한 유사 입력을 다수 만듦
3. **국소 모델 적합**: 거리 가중치를 적용해 해석 가능한 대리 모델을 학습함
4. **기여도 해석 반환**: 대리 모델 계수를 기반으로 설명 결과를 제공함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 무작위 샘플링 기반 설명은 실행마다 중요 피처 순위가 달라져 실무 신뢰도를 떨어뜨릴 수 있음
   - 해결방안: fixed seed와 repeated explanation ensemble을 적용하고 rank stability와 coefficient variance로 검증함
2. 문제: 원본 입력과 너무 멀리 떨어진 샘플이 많이 생성되면 국소 설명이 실제 모델 행동을 왜곡할 수 있음
   - 해결방안: kernel width와 perturbation 범위를 튜닝하고 local fidelity와 neighborhood validity로 검증함
3. 문제: 이미지와 텍스트의 해석 단위를 부적절하게 자르면 사용자가 이해하기 어려운 설명이 나올 수 있음
   - 해결방안: superpixel과 token segmentation을 도메인에 맞게 조정하고 explanation usability score와 reviewer agreement로 검증함

## Ⅶ. 적용 사례

- 통신 이탈 예측 모델이 개별 고객의 이탈 요인을 마케팅 담당자에게 설명하도록 운영되며 확인 지표는 campaign conversion lift와 explanation stability임
- 이메일 스팸 분류기가 단어 수준 중요도를 제공해 운영자가 오탐 원인을 파악하며 확인 지표는 false positive reduction rate와 analyst review time임
- 이미지 분류 모델이 진단 영역을 국소 설명으로 표시해 임상의 검토를 돕고 확인 지표는 clinician acceptance rate와 local fidelity임

## Ⅷ. 결론

LIME은 복잡한 모델을 빠르게 설명 가능한 형태로 바꾸는 실용적 국소 설명 기법이지만, 샘플링 품질과 안정성 관리 없이는 설명 신뢰도가 쉽게 흔들릴 수 있음.
