# 📖 【암기용】 개념 완전 이해

> 목적: SASE를 네트워크와 보안을 클라우드 엣지에서 통합 제공하는 구조로 이해하고, SD-WAN과 보안 서비스가 왜 함께 묶이는지 설명하게 만든다.

## 한눈에
- **개요**: SD-WAN과 SWG·CASB·ZTNA·FWaaS 등 보안 기능을 클라우드 엣지에서 통합 제공하는 아키텍처
- **왜 필요한가**: 사용자는 지사·재택·모바일에서 SaaS와 클라우드 앱에 직접 접속하므로 모든 트래픽을 본사 방화벽으로 우회시키는 구조가 맞지 않는다.
- **핵심 직관**: 모든 택배를 본사 창고로 보내 검사하는 대신, 가까운 지역 물류 거점에서 경로와 보안 검사를 함께 처리하는 방식이다.

## 깊이 이해
- **배경·문제의식**: 전통 WAN은 본사 데이터센터 중심이고 보안 장비도 지점별로 분산되어, 원격 사용자와 SaaS 트래픽 처리에 지연·운영 복잡도가 생긴다.
- **작동 원리**: 사용자·지점 트래픽이 가까운 SASE PoP로 들어가고, SD-WAN 경로 최적화와 웹·SaaS·프라이빗 앱 보안 검사가 같은 정책으로 적용된다.
- **비유**: 공항마다 출입국 심사와 환승 안내가 함께 있어 승객이 본국 공항을 매번 거치지 않아도 되는 구조와 같다.
- **구체 예시**: 지사 사용자가 Salesforce에 접속하면 가까운 PoP에서 사용자 인증, CASB 정책, DLP 검사, 경로 선택을 수행한다.
- **흔한 오해·주의점**: SASE는 보안 제품 묶음만 뜻하지 않는다. 네트워크 접속 품질과 보안 정책을 동일한 클라우드 엣지에서 제공해야 한다.

## 연결 개념
- SSE — SASE에서 네트워크 기능을 뺀 보안 서비스 엣지
- Zero Trust Architecture — ZTNA와 조건부 접근의 원칙
- SD-WAN — 지점·사용자 트래픽 경로 제어 기반

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.
> 핵심: SASE는 SD-WAN과 보안 서비스의 수렴 구조이며, 원격·지점·SaaS 트래픽을 사용자 맥락 기반 정책으로 처리한다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: SASE는 WAN 기능과 클라우드 기반 보안 서비스를 단일 엣지 플랫폼으로 결합한 접근 아키텍처임.
> 2. **가치**: 지사·모바일·재택 사용자의 웹, SaaS, 프라이빗 앱 접속에 경로 제어와 보안 정책을 동시에 적용함.
> 3. **판단 포인트**: SD-WAN, SWG, CASB, ZTNA, FWaaS, DLP, PoP 위치, 정책 일관성을 함께 평가해야 함.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 네트워크·보안 융합 이해 확인 | SD-WAN+보안 서비스 클라우드 엣지 제공 | 보안 제품 목록으로만 설명 |
| 원격·SaaS 접근 설계 확인 | 사용자 위치와 무관한 정책 집행 | VPN 대체 하나로 축소 |
| SASE와 SSE 구분 확인 | SASE는 네트워크 포함, SSE는 보안 서비스 중심 | 두 용어를 동일시 |

> 요약: 이 문제는 경로 제어와 보안 집행을 하나의 엣지 아키텍처로 설명하는지 확인한다.

---

## Ⅰ. 개요 및 필요성

- 개요: 네트워크·보안 통합 엣지
- 배경: SaaS·원격근무·지점 인터넷 직접 접속이 늘며 본사 우회형 WAN과 장비 중심 보안의 한계가 커짐.
- 필요성: 사용자 위치와 장치 상태에 따라 SD-WAN 경로, 웹 보안, SaaS 통제, ZTNA 접근을 일관 정책으로 적용해야 함.

---

## Ⅱ. 구조 및 구성요소

```text
User / Branch / Device -> SASE PoP
  +-> SD-WAN Routing -> Internet / SaaS / Private App
  +-> SWG / CASB / ZTNA / FWaaS / DLP -> Policy / Log
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| SD-WAN | 지점·사용자 경로 선택과 회선 제어 | 애플리케이션별 경로 정책 |
| SWG/FWaaS | 웹·인터넷 트래픽 보안 검사 | URL, malware, TLS inspection |
| CASB/DLP | SaaS 사용과 데이터 유출 통제 | sanctioned app, shadow IT |
| ZTNA | 프라이빗 앱 접근 제어 | 앱 단위 최소권한 |

> 요약: SASE는 네트워크 경로 제어와 웹·SaaS·프라이빗 앱 보안 기능을 클라우드 PoP에서 결합한다.

---

## Ⅲ. 동작원리 및 흐름도

```text
접속 요청 -> 가까운 PoP 연결 -> 사용자 / 단말 인증
-> 애플리케이션 식별 -> 경로 선택 / 보안 검사 -> 접근 허용 / 차단 -> 로그 수집
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 사용자·지점 트래픽을 SASE PoP로 유도 | tunnel health |
| 2 | 신원·단말·위치·애플리케이션 식별 | IdP, device posture |
| 3 | SD-WAN 경로와 보안 정책 동시 적용 | policy match |
| 4 | 접근 결과와 위협 이벤트 기록 | log completeness |

> 요약: SASE는 PoP 접속 후 사용자 맥락과 애플리케이션을 기준으로 경로와 보안 정책을 동시에 결정한다.

## Ⅳ. 특징

| 구분 | 전통 WAN·보안 | SASE | 판단 기준 |
|:---|:---|:---|:---|
| 구조 | 본사 우회, 장비 분산 | 클라우드 PoP 중심 | 지점·원격 사용자 수 |
| 보안 | 방화벽·VPN 중심 | SWG·CASB·ZTNA 통합 | SaaS·웹 사용 비중 |
| 경로 | MPLS·고정 경로 | SD-WAN 정책 경로 | 애플리케이션별 SLA |
| 운영 | 장비별 정책 관리 | 중앙 정책과 로그 | 정책 일관성 |

> 요약: SASE는 사용자와 앱이 분산된 환경에서 경로와 보안을 같은 정책 단위로 다룬다.

## Ⅴ. 심화 비교 및 적용 판단

| 구분 | 기존/대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | VPN+방화벽+프록시 분리 | 단일 SASE 플랫폼 | 지점·원격 접속 복잡도 |
| 비용 | 장비 구매·회선 중심 | 구독형 PoP 서비스 | 회선·장비 갱신 시점 |
| 운영 | 도구별 정책 중복 | 중앙 정책 관리 | 보안팀·네트워크팀 협업 |

> 요약: SASE는 지점과 원격 사용자가 많고 SaaS 사용 비중이 높을 때 운영 단순화 근거가 생긴다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| PoP 품질 편차 | 지역별 엣지 위치 차이 | 주요 사용자 위치별 PoC | p95 latency |
| 정책 충돌 | 네트워크·보안팀 정책 중복 | 공통 정책 모델 정의 | policy conflict |
| 공급자 종속 | 단일 플랫폼 의존 | API·로그 내보내기 확인 | export coverage |

> 요약: SASE 리스크는 PoP 품질, 정책 충돌, 공급자 종속이며 PoC와 로그 이식성으로 확인한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 접속 품질 | 업무 앱 p95 지연 기준 충족 | synthetic test |
| 정책 적용 | 사용자·앱별 정책 누락 없음 | policy audit |
| 위협 탐지 | 웹·SaaS 이벤트 수집 완전성 | SIEM 연계 점검 |

> 요약: SASE 도입은 연결 품질, 정책 누락, 로그 수집 완전성을 기준으로 평가한다.

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 지점·재택·모바일 사용자별 트래픽 경로와 SaaS 사용 현황을 조사해 SASE 적용 우선순위를 정함.
2. SD-WAN, SWG, CASB, ZTNA 정책을 사용자 그룹과 애플리케이션 등급 기준으로 통합 설계함.
3. PoP별 p95 지연시간, 정책 적용률, 로그 수집률을 PoC에서 측정한 뒤 단계 전환함.

**결론 (2줄):**
- 기술사 판단: 지점 WAN과 보안 장비 갱신 시점이 겹치면 SASE, 보안 기능만 우선 필요하면 SSE 도입이 타당함.
- 향후 방향: SASE는 제로트러스트, 디지털 경험 모니터링, AI 기반 정책 추천과 결합해 접근 플랫폼으로 발전함.
