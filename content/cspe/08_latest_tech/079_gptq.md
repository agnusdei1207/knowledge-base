## 미리 알고가기

- GPTQ는 대형 언어 모델을 위한 대표적인 post-training 4비트 양자화 기법임
- Hessian 근사를 활용해 각 가중치 블록의 양자화 오차를 줄이는 것이 핵심임
- 추가 재학습 없이도 품질을 비교적 잘 유지해 로컬 LLM 배포에서 널리 쓰임

## Ⅰ. 개요

- **정의/개념**: GPTQ는 사전 학습된 언어 모델을 재학습 없이 저비트로 압축할 때, 가중치 블록별 오차를 최소화하도록 순차적으로 양자화를 수행하는 PTQ 기법임
- **배경/필요성**: 4비트 수준의 강한 압축은 품질 손실이 커지기 쉬우므로, 추가 학습 비용 없이도 대형 모델 성능을 최대한 유지하는 정교한 PTQ 방법이 필요함

## Ⅱ. 특징

- Hessian 기반 오차 보정을 이용해 단순 라운딩보다 품질 저하를 줄임
- 재학습이 없어도 4비트 LLM 배포를 가능하게 해 비용 대비 효율이 높음
- 주로 가중치 중심 압축에 강점을 가지며 activation까지 포함한 전면 최적화와는 성격이 다름
- 전용 포맷과 런타임 의존성이 있어 배포 환경을 함께 고려해야 함

## Ⅲ. 종류 및 비교

| 판단 기준 | 단순 PTQ | GPTQ | AWQ |
|:---|:---|:---|:---|
| 보정 수준 | 낮음 | 높음 | 높음 |
| 주 관심 대상 | 전체 가중치 | 가중치 오차 최소화 | 활성값 영향 고려 |
| 재학습 필요 | 없음 | 없음 | 없음 |
| 대표 활용 | 간단 압축 | 로컬 LLM | 실서비스 4비트 배포 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Calibration Set | 모델의 대표 입력을 제공해 양자화 시 오차 보정 기준을 만듦 |
| Block-wise Quantizer | 가중치를 작은 블록으로 나누어 순차적으로 양자화하고 누적 오차를 줄임 |
| Error Compensation | Hessian 근사를 활용해 이후 가중치에 미치는 오차를 보정함 |
| Runtime Format | 변환된 4비트 모델을 실제 추론 엔진에서 읽고 실행하는 배포 형식을 제공함 |

```text
+-------------------+      +-------------------+      +-------------------+
| Calibration Set   | ---> | Block Quantizer   | ---> | Runtime Format    |
+-------------------+      +-------------------+      +-------------------+
                                   |
                                   v
                           +-------------------+
                           | Error Comp.       |
                           +-------------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 샘플 입력 수집  | --> | 블록별 오차 추정 | --> | 순차 양자화     | --> | 4비트 모델 배포  |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **샘플 입력 수집**: 모델이 자주 접하는 입력 분포를 대표하는 calibration 데이터를 준비함
2. **블록별 오차 추정**: 가중치 블록별 민감도를 계산해 어떤 압축이 손실이 큰지 추정함
3. **순차 양자화**: 오차 보정을 반영하면서 블록 단위로 가중치를 4비트로 변환함
4. **4비트 모델 배포**: 전용 런타임에 올려 실제 추론 품질과 속도를 확인함

## Ⅵ. 문제점 및 해결 방안

1. 문제: calibration 데이터가 협소하면 GPTQ가 특정 입력 유형에만 맞춰져 운영 환경에서 품질 편차가 커질 수 있음
   - 해결방안: 운영 대표 샘플을 포함한 calibration set을 구성하고 domain accuracy와 regression rate로 적합성을 검증함
2. 문제: 가중치 중심 보정만으로는 activation outlier가 큰 모델에서 품질 저하를 완전히 막기 어려울 수 있음
   - 해결방안: activation 민감 모델에는 AWQ나 mixed precision을 병행하고 perplexity와 task score로 품질을 검증함
3. 문제: GPTQ 형식이 런타임별로 지원 수준이 달라 배포 경로가 불안정할 수 있음
   - 해결방안: 목표 엔진별 호환성 매트릭스를 유지하고 load success rate와 tokens/sec로 실행 적합성을 검증함

## Ⅶ. 적용 사례

- 로컬 LLM 도구가 대형 오픈모델을 4비트로 배포하도록 GPTQ를 적용하며 확인 지표는 VRAM usage와 tokens/sec임
- 사내 실험용 챗봇이 재학습 없이 빠르게 비용을 줄이도록 GPTQ를 적용하며 확인 지표는 setup time과 answer quality임
- 연구용 모델 압축 비교가 여러 PTQ 기법을 검증하도록 GPTQ를 포함해 실험하며 확인 지표는 perplexity와 benchmark score임

## Ⅷ. 결론

GPTQ는 재학습 없이도 4비트 수준 압축의 품질 손실을 억제해 대형 언어 모델을 개인 장비와 저비용 서버로 내려오게 만든 대표적인 실전형 양자화 기법임.
