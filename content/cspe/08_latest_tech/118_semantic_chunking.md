## 미리 알고가기

- 의미 기반 청킹은 토큰 수 기준이 아니라 의미 경계 기준으로 청크를 나누는 방식임
- 문단과 문장 간 의미 변화 지점을 잡는 것이 핵심임
- 고정 길이 청킹보다 품질은 높을 수 있지만 전처리 비용이 커짐

## Ⅰ. 개요

- **정의/개념**: 의미 기반 청킹은 문장이나 문단의 의미 유사도와 주제 전환 지점을 분석해, 같은 의미 흐름이 유지되는 범위를 하나의 청크로 묶는 고급 분할 기법임
- **배경/필요성**: 고정 길이 청킹은 문장 중간이나 주제 전환 지점을 무시해 문맥 손실과 노이즈 유입을 부르므로, 더 의미 보존적인 분할 방식이 필요함

## Ⅱ. 특징

- 주제 단위 문맥을 유지하기 쉬워 검색 품질과 답변 일관성을 높일 수 있음
- 문서 구조가 불규칙하거나 긴 설명형 문서에서 특히 유리함
- 임베딩 계산과 경계 탐지 로직이 추가되어 전처리 비용이 높아짐
- 의미 경계 추정이 부정확하면 오히려 비균일하고 불안정한 청크가 생성될 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | Fixed Chunking | Recursive Chunking | Semantic Chunking |
|:---|:---|:---|:---|
| 경계 기준 | 길이 | 구조적 구분자 | 의미 변화 |
| 문맥 보존 | 낮음 | 중간 | 높음 |
| 전처리 비용 | 낮음 | 낮음 | 높음 |
| 문서 적합도 | 균일 문서 | 일반 문서 | 주제 변화가 뚜렷한 문서 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Sentence Segmenter | 문서 내용을 문장이나 문단 단위 후보로 잘라 의미 분석의 기초 단위를 만듦 |
| Similarity Estimator | 인접 문장 벡터 유사도를 계산해 주제 변화 정도를 측정함 |
| Boundary Detector | 유사도 급변 지점이나 구조 변화 지점을 경계로 선택함 |
| Chunk Assembler | 경계를 기준으로 의미 흐름이 유지되는 범위를 청크로 조립함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 문장 단위 분해   | --> | 유사도 변화 측정 | --> | 경계점 탐지     | --> | 의미 단위 청크 생성 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **문장 단위 분해**: 원문을 비교 가능한 작은 의미 단위로 나눔
2. **유사도 변화 측정**: 인접 단위 간 의미 유사도 변화를 계산함
3. **경계점 탐지**: 의미 전환이 큰 지점을 경계 후보로 선택함
4. **의미 단위 청크 생성**: 경계를 기준으로 청크를 조립하고 메타데이터를 부착함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 의미 유사도 계산이 부정확하면 경계점이 흔들려 청크 길이가 지나치게 불균형해질 수 있음
   - 해결방안: 임계값과 최소, 최대 길이를 함께 두고 chunk length variance와 retrieval quality로 안정성을 검증함
2. 문제: 모든 문장을 임베딩하거나 비교해야 해 대규모 문서군에서는 전처리 비용이 크게 증가할 수 있음
   - 해결방안: 후보 문단 단위 선분할과 캐싱을 적용하고 preprocessing time과 answer gain으로 비용 대비 효과를 검증함
3. 문제: 법조문이나 코드처럼 구조적 경계가 중요한 문서에서 의미 기준만 쓰면 형식 논리를 망가뜨릴 수 있음
   - 해결방안: 구조 규칙과 의미 기준을 혼합하고 structure preservation와 citation accuracy로 분할 품질을 검증함

## Ⅶ. 적용 사례

- 정책 문서 RAG: 문단 의미 흐름을 유지해 분할함, 확인 지표는 context precision과 faithfulness임
- 연구 보고서 검색: 섹션별 주제 변화를 반영함, 확인 지표는 retrieval recall과 answer coherence임
- 긴 고객지원 매뉴얼: 세부 절차 경계를 의미 기준으로 조정함, 확인 지표는 first-hit relevance와 resolution rate임

## Ⅷ. 결론

의미 기반 청킹은 전처리 비용을 더 써서 검색 문맥 품질을 높이는 전략이므로, 문서 구조가 복잡하고 정밀 검색 가치가 큰 영역에서 특히 유효함.
