# 📖 【암기용】 개념 완전 이해

## 한눈에
- **정의**: 사용자가 텍스트(Prompt)로 원하는 장면을 묘사하면, AI가 그 텍스트의 의미를 이해하고 완전히 새로운 픽셀 이미지로 그려내어 출력하는 멀티모달 생성 기술. (Midjourney, DALL-E, Stable Diffusion 등).
- **필요성**: 사진 촬영, 일러스트레이터 고용, 포토샵 작업에 들어가던 수백만 원의 비용과 며칠의 시간을 단 10초, 몇백 원의 클라우드 API 비용으로 압축하여 콘텐츠 제작 생태계를 파괴적으로 혁신함.
- **핵심 직관**: AI 마법 붓. "우주복을 입고 말을 타는 고양이, 사이버펑크 스타일, 4K 해상도"라고 글만 치면, 뇌 속의 상상력을 캔버스에 즉각 렌더링해 주는 램프의 요정.

## 깊이 이해
- **배경**: 초기에는 GAN(생성적 적대 신경망)이 사진을 만들었으나, 텍스트 명령어를 세밀하게 알아듣고 퀄리티를 조절하는 데 한계가 컸음. 이후 **Diffusion Model(확산 모델)**과 CLIP(언어-이미지 정렬 모델)이 결합하면서, 텍스트의 세밀한 지시사항을 완벽히 따르는 압도적 품질의 생성이 가능해짐.
- **작동 원리 (조건부 확산 - Conditional Diffusion)**:
  1. 텍스트 인코더(CLIP)가 "우주복 입은 고양이"라는 텍스트를 숫자의 의미 벡터로 변환(조건부여, Condition).
  2. TV 흑백 노이즈 지지직거리는 화면(Random Noise)을 생성함.
  3. 확산 모델(U-Net)이 텍스트 벡터의 지시(Guidance)를 받으며, 노이즈를 수십 번의 스텝(Denoising)에 걸쳐 조금씩 지워냄.
  4. 점차 고양이의 귀, 우주복 형태가 드러나고 최종적으로 완벽한 선명한 그림 완성.
- **구체 예시**: 마케팅 팀에서 여름 음료 배너가 필요할 때. 스튜디오 대관 없이 AI 프롬프트창에 "청량한 해변 배경의 에이드, 얼음 맺힌 유리잔, 햇살" 입력. 10초 만에 시안 4장을 뽑아 디자이너에게 넘기고 즉시 광고 집행.
- **흔한 오해/주의점**: "그냥 프롬프트 치면 끝 아님?" $\rightarrow$ 아님. AI는 손가락을 6개로 그리거나, 엉뚱한 브랜드 로고를 합성해버리는 등 컨트롤이 어려움. 또한 저작권 침해 데이터로 학습되어 법적 이슈(Copyright 리스크)가 매우 크므로, 상업용 사용 시 매우 각별한 주의가 필요함.

## 연결 개념
- **Diffusion Model (확산 모델)**: Text-to-Image를 구동시키는 찐 핵심 엔진(심장).
- **Prompt Engineering**: 이 요술 램프에게 소원을 똑바로 빌기 위해 텍스트 명령어의 순서, 가중치, 부정어(Negative prompt)를 깎는 기술.
- **ControlNet (컨트롤넷)**: "텍스트"만으로는 모델이 맘대로 그리는 걸 막기 위해, 윤곽선이나 사람 뼈대 스케치를 던져주어 강제로 구도를 맞추게 하는 마이크로 제어 기술.

# 📝 【답안용】 시험 답안 템플릿
## 핵심 인사이트 (3줄 요약)
- **본질**: 자연어 프롬프트를 시맨틱 잠재 벡터(Latent Vector)로 인코딩한 뒤, 이를 조건(Condition)으로 하여 순수 노이즈 상태에서 이미지 픽셀 구조를 점진적으로 복원해 내는 조건부 확산(Conditional Diffusion) 기반 멀티모달 생성 파이프라인.
- **가치**: 크리에이티브 산업의 시각화 워크플로우를 극단적으로 압축하여 제작 시간과 비용을 획기적으로 절감하고, 자율주행·제조업 비전 AI 고도화를 위한 초거대 합성 데이터(Synthetic Data) 무한 생성 인프라로 작동함.
- **판단 포인트**: 기업 실무 적용 시 가장 큰 리스크인 모델의 통제 불가능성(Uncontrollability)과 저작권 침해(Copyright Infringement) 문제를 해결하기 위해, ControlNet/LoRA 기반의 정밀 제어 아키텍처와 상업적 안전망이 담보된 파운데이션 모델(Adobe Firefly 등) 채택 판단이 필수적임.

## Ⅰ. 개요 및 필요성
- **정의**: 사용자의 자연어 텍스트 설명(Prompt)을 입력받아 해당 시맨틱 맥락과 시각적 스타일을 반영하여 사실적이거나 예술적인 고품질의 2D 래스터 이미지를 합성(Synthesis)하는 생성형 AI 기술.
- **배경**: 과거 GAN, VAE 등은 생성된 이미지의 다양성(Diversity) 부족과 Mode Collapse(똑같은 그림만 반복 생성) 문제로 상용화에 어려움이 컸으나, Denoising Diffusion Probabilistic Models(DDPM)의 등장으로 품질과 안정성이 비약적으로 상승함.
- **필요성**: 광고 시안 도출, 게임 에셋 대량 생산, 의료 영상 및 자율주행 등 희소 데이터 부족 문제를 타개하기 위한 합성 데이터(Synthetic Data) 파이프라인 구축 목적.

## Ⅱ. 핵심 아키텍처 메커니즘 (Latent Diffusion 기반)
텍스트의 의미를 주사기처럼 주입(Conditioning)하여 노이즈를 깎아내는 구조.
1. **Text Encoder (조건화 인코더)**:
   - 사용자의 프롬프트를 CLIP 인코더 또는 T5 모델을 통해 의미를 함축한 임베딩 벡터(Conditioning Vector)로 변환.
2. **Latent Denoising U-Net (노이즈 제거 핵심 엔진)**:
   - 계산량을 줄이기 위해 픽셀 공간이 아닌 압축된 잠재 공간(Latent Space)에서 연산.
   - Cross-Attention 매커니즘을 사용해, 노이즈를 지우는 과정(Denoising)마다 텍스트 벡터의 의도(예: "파란 하늘")를 주입하여 그림의 방향을 유도(Guidance)함.
3. **VAE Decoder (시각화 디코더)**:
   - 잠재 공간에서 노이즈가 모두 제거되어 완성된 압축 텐서를, 사람이 볼 수 있는 고해상도 픽셀 이미지로 팽창(Decode)시켜 최종 출력.

## Ⅲ. 생성 품질 및 제어 고도화 기술 (Advanced T2I)
순수 텍스트(Prompt)만으로는 한계가 있어 도입되는 제어 파이프라인.
| 고도화 기술 | 핵심 기능 및 원리 | 활용 사례 |
|:---:|:---|:---|
| **Classifier-Free Guidance (CFG)** | 생성 과정에서 프롬프트를 무시한 무작위 그림과 프롬프트를 강제한 그림 사이의 가중치를 조정. (숫자가 클수록 프롬프트 명령에 집착함). | 프롬프트 명령 충실도(Prompt-Adherence) 세밀 조절. |
| **ControlNet (컨트롤넷)** | 텍스트 외에 Canny Edge(윤곽선), OpenPose(인체 뼈대), Depth Map 등을 추가 조건으로 주입하여 공간적 구도를 강제 고정함. | 모델 피팅샷 생성 시, 모델의 포즈는 그대로 두고 옷만 바꾸기. |
| **LoRA (미세조정)** | 거대한 파운데이션 모델의 가중치는 고정하고, 10~20장의 특정 화풍/캐릭터 이미지만 가볍게 학습시켜 모듈처럼 끼워 씀. | 특정 브랜드의 마스코트 캐릭터를 일관된 얼굴로 계속 등장시키기. |

## Ⅳ. 도입 시나리오별 리스크 및 대응 체계 (Governance)
| 리스크 요인 | 비즈니스 임팩트 | MLOps 및 아키텍처 대응 방안 |
|:---:|:---|:---|
| **저작권/상표권 침해** | 타사 브랜드 로고, 워터마크가 합성되어 저작권 소송 유발 | 오픈소스 모델(학습 데이터 불투명) 배제. 상업적 보증을 제공하는 상용 API(Adobe Firefly 등) 도입. |
| **안전/윤리 정책 위반** | 프롬프트 인젝션에 의한 폭력·선정적(NSFW) 이미지 출력 | 생성 요청 전단 및 출력 후단에 **Safety Filter (클래시파이어)** 구축하여 자동 블록 및 폐기. |
| **딥페이크 / 가짜 뉴스** | 허위 사실 유포 및 사회적 혼란 야기, 기업 평판 하락 | 생성된 모든 이미지에 비가시적 **C2PA 규격 워터마크(Content Credentials)** 의무 삽입 아키텍처 구현. |

## Ⅴ. 실무 적용 및 결론
- **판단 지표**: FID(Frechet Inception Distance, 원본 데이터 분포와의 차이, 낮을수록 좋음), CLIP Score(프롬프트와 생성 결과 간의 일치도).
- **실무 설계**: 모바일 게임 개발사의 캐릭터 에셋(Asset) 대량 생산 파이프라인 구축. 기존엔 캐릭터 하나에 1주가 소요됨. 사내 프라이빗 클라우드에 오픈소스 `Stable Diffusion XL` 모델을 배포(보안 확보). 사내 기존 캐릭터 원화 100장을 LoRA 방식으로 파인튜닝하여 전용 체크포인트 모델 제작. 기획자가 "검을 든 성기사, 불꽃 이펙트"를 입력하면 회사 고유의 일러스트 화풍(스타일)이 유지된 시안이 1분 만에 4장씩 도출됨. 디자이너는 리터칭만 수행하여 생산성 10배 달성.
- **결론**: Text-to-Image 기술은 시각적 상상력과 렌더링 물리력 간의 병목을 파괴한 크리에이티브 도구의 종착지이며, 저작권 클리어런스(Clearance)와 C2PA 같은 워터마킹 거버넌스 기술이 맞물려야만 진정한 엔터프라이즈의 핵심 인프라로 안착할 수 있다.

### 🔀 문제 유형별 목차 전환
- **Ⅱ·Ⅲ 강조 (개념/원리형)**: Latent Space 변환을 위한 VAE(Variational Autoencoder)의 압축 원리, U-Net 구조 내 Cross-attention을 통한 조건부 확률 $p(x|y)$ 계산의 수리적 메커니즘 중심.
- **Ⅴ·Ⅵ 강조 (실무/설계형)**: AI 생성물의 저작권 귀속 문제 법적 쟁점 대응, 워터마크 삽입을 통한 기계 생성 식별(Machine-generated Identification) 보안 파이프라인 컴플라이언스 체계 수립.
