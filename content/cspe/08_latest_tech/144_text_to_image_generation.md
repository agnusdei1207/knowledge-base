## 미리 알고가기

- Text-to-Image는 자연어 프롬프트를 조건으로 이미지를 생성하는 기술임
- 현재 고품질 생성의 주류는 diffusion 기반 아키텍처임
- 생성 품질만큼 저작권과 제어 가능성과 안전성이 중요함

## Ⅰ. 개요

- **정의/개념**: Text-to-Image 생성은 사용자의 자연어 프롬프트를 의미 조건으로 해석하고, 그 조건에 맞는 시각적 특징을 노이즈나 잠재 표현에서 점진적으로 복원해 새로운 이미지를 합성하는 생성형 AI 기술임
- **배경/필요성**: 시안 제작과 합성 데이터 확보와 개인화 콘텐츠 생성 수요가 커지면서, 사람의 상상과 요구사항을 텍스트만으로 시각 결과물로 전환하는 자동화 기술이 필요해졌음

## Ⅱ. 특징

- 자연어만으로 스타일과 구도와 객체 조합을 빠르게 시도할 수 있음
- diffusion과 guidance 덕분에 고품질 이미지를 안정적으로 생성할 수 있음
- ControlNet과 LoRA 같은 보조 수단으로 세밀한 제어가 가능함
- 저작권과 안전성 이슈를 방치하면 상용 적용 리스크가 급격히 커짐

## Ⅲ. 종류 및 비교

| 판단 기준 | GAN 기반 생성 | Diffusion 기반 생성 | 자기회귀 기반 생성 |
|:---|:---|:---|:---|
| 품질 안정성 | 중간 | 높음 | 중간 |
| 추론 속도 | 빠름 | 느림 | 중간 |
| 프롬프트 충실도 | 낮음 | 높음 | 중간 |
| 현재 상용성 | 낮음 | 매우 높음 | 제한적 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Prompt Encoder | 프롬프트의 의미와 스타일 조건을 임베딩 벡터로 변환함 |
| Noise, Latent State | 생성의 출발점이 되는 노이즈나 잠재 표현으로 다양성과 샘플 공간을 제공함 |
| Denoising Model | 조건 정보를 받아 노이즈를 반복적으로 제거하며 구조와 질감을 형성함 |
| Decoder, Control Layer | 잠재 표현을 실제 이미지로 복원하고 추가 제어 정보로 구도와 스타일을 세밀하게 조정함 |

```text
+-------------------+      +-------------------+      +-------------------+
| Prompt Encoder    | ---> | Denoising Model   | ---> | Decoder / Control |
+-------------------+      +-------------------+      +-------------------+
             ^                        ^
             |                        |
+-------------------+      +-------------------+
| User Prompt       |      | Noise / Latent    |
+-------------------+      +-------------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 프롬프트 입력   | --> | 조건 임베딩 생성 | --> | 반복 복원 수행  | --> | 이미지 출력/검사 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **프롬프트 입력**: 사용자가 장면과 스타일을 자연어로 지정함
2. **조건 임베딩 생성**: 텍스트를 생성 조건 벡터로 변환함
3. **반복 복원 수행**: 노이즈를 점진적으로 제거하며 이미지를 형성함
4. **이미지 출력 및 검사**: 결과를 복원하고 안전성 및 품질을 점검함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 학습 데이터 출처가 불명확하면 생성 결과 자체보다 라이선스와 저작권 리스크가 먼저 상용화의 장애가 될 수 있음
   - 해결방안: 라이선스 검증 모델과 생성물 워터마킹을 적용하고 legal incident count와 provenance coverage로 검증함
2. 문제: 텍스트만으로는 원하는 구도와 포즈를 정확히 통제하기 어려워 반복 생성 비용이 커질 수 있음
   - 해결방안: ControlNet과 reference image conditioning을 적용하고 prompt success rate와 edit iteration count로 검증함
3. 문제: 고해상도 생성은 추론 시간이 길고 GPU 비용이 커서 대량 서빙에서 효율이 급격히 떨어질 수 있음
   - 해결방안: distillation과 accelerated sampler를 적용하고 latency와 cost per image로 검증함

## Ⅶ. 적용 사례

- 마케팅 스튜디오가 캠페인 배너 시안을 빠르게 생산하도록 Text-to-Image 생성을 적용하며 확인 지표는 design cycle time과 approval rate임
- 게임 제작이 캐릭터와 배경 컨셉 아트를 대량 탐색하도록 Text-to-Image 생성을 활용하며 확인 지표는 concept throughput과 art revision count임
- 자율주행 학습이 희소 상황 이미지를 합성하도록 Text-to-Image 생성을 운영하며 확인 지표는 synthetic data diversity와 downstream accuracy gain임

## Ⅷ. 결론

Text-to-Image 생성은 아이디어를 즉시 시각화하는 강력한 도구이지만, 실무 성패는 생성 품질보다 제어 가능성과 라이선스 거버넌스를 얼마나 같이 설계했는지에 달려 있음.
