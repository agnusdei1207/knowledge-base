# 📖 【암기용】 개념 완전 이해

> 목적: Text-to-Image Generation을 처음 봐도 완벽히 이해하게 만든다.

## 한눈에
- **개요**: 자연어 프롬프트를 입력받아 조건에 맞는 이미지를 생성하는 생성형 AI 기술
- **왜 필요한가**: 디자인 시안, 광고 소재, 교육 이미지, 합성 데이터 등을 빠르게 생성하려는 요구가 증가함.
- **핵심 직관**: 글로 설명한 장면을 AI가 픽셀 이미지로 그려내는 기술임.

## 깊이 이해
- **배경·문제의식**: 기존 이미지 제작은 촬영·디자인·편집 비용이 높고 반복 실험 속도가 낮다. 텍스트 조건 생성은 아이디어 검증 시간을 줄임.
- **작동 원리**: 텍스트 인코더가 프롬프트 의미를 벡터화하고, 확산모델 또는 생성모델이 노이즈에서 이미지를 점진적으로 복원하며 텍스트 조건을 반영함.
- **비유**: 디자이너에게 "흰 배경의 파란색 스마트워치 제품 사진"이라고 지시하면 시안을 그려주는 과정과 같음.
- **구체 예시**: 마케팅 배너 후보 50개를 생성하고 브랜드 가이드 위반 이미지를 필터링해 디자이너가 상위 5개만 수정.
- **흔한 오해·주의점**: 생성 이미지는 저작권, 상표, 인물권, 편향, 워터마킹 문제가 있어 상용 배포 전 검토가 필요함.

## 연결 개념
- Diffusion Model — Text-to-Image의 대표 생성 구조
- Stable Diffusion — 공개 생태계가 큰 잠재 확산 모델
- Prompt Engineering — 원하는 이미지 조건을 명확히 제어하는 작성 방식

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: Text-to-Image는 텍스트 조건을 이미지 생성 과정에 반영하는 멀티모달 생성 기술임.
> 2. **가치**: 디자인 시안·콘텐츠 제작·합성 데이터 생성을 분 단위로 반복해 제작 비용을 줄임.
> 3. **판단 포인트**: 저작권·브랜드 가이드·인물권·유해 이미지 필터링을 운영 절차에 포함해야 함.

## Ⅰ. 개요 및 필요성

Text-to-Image Generation은 텍스트 기반 이미지 생성 기술임. 콘텐츠 제작과 데이터 증강에는 다양한 이미지 후보가 필요하지만 수작업 제작 비용이 높다. 자연어 프롬프트로 조건에 맞는 이미지를 생성해 제작 반복 속도를 높인다.

## Ⅱ. 구조 및 구성요소

```text
Prompt → Text Encoder → Condition Vector
  → Diffusion/Generator → Image Decoder → Safety Filter
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Text Encoder | 프롬프트 의미 벡터화 | CLIP text encoder, T5 |
| Generator | 조건 기반 이미지 생성 | diffusion, transformer |
| Image Decoder | latent를 픽셀 이미지로 변환 | VAE decoder |
| Safety Filter | 유해·저작권·브랜드 위반 탐지 | NSFW, watermark, logo check |

> 요약: Text-to-Image는 프롬프트를 조건 벡터로 바꾸고 생성모델이 이를 반영해 이미지를 생성한 뒤 안전 필터를 적용함.

## Ⅲ. 동작원리 및 흐름도

```text
프롬프트 입력 → 텍스트 인코딩 → 노이즈 초기화
  → 조건부 denoising 반복 → 이미지 복원 → 안전성 검수
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 프롬프트·negative prompt 구성 | 금지어·브랜드 규칙 검사 |
| 2 | 텍스트 조건 벡터 생성 | prompt-image alignment ≥0.8 |
| 3 | 20~50 step denoising으로 이미지 생성 | 생성 지연 2~10초 |
| 4 | 안전 필터·검수 후 배포 | 유해 이미지 차단율 ≥99% |

> 요약: 텍스트 조건을 기반으로 노이즈를 단계적으로 제거해 이미지를 만들고 안전성 검수 후 사용함.

## Ⅳ. 특징

| 구분 | 수작업 제작 | Text-to-Image | 판단 포인트 |
|:---|:---|:---|:---|
| 제작 속도 | 수시간~수일 | 수초~수분 | 시안 반복에 적합 |
| 제어 방식 | 디자이너 작업 | 프롬프트·시드·컨트롤넷 | 정밀 제어 필요 |
| 비용 | 인력·촬영 비용 | GPU·검수 비용 | 대량 후보 생성 유리 |
| 리스크 | 저작권 관리 명확 | 저작권·편향·유해 생성 | 검수·정책 필수 |

> 요약: Text-to-Image는 제작 반복 속도를 높이지만, 상용 배포에는 권리·안전성 검증이 필수임.

## Ⅴ. 실무 적용 및 결론

**적용 방안 3개:**
1. 마케팅 시안: 브랜드 색상·로고 사용 규칙을 prompt template과 후처리 검수로 적용, 상위 5개 후보만 디자이너 수정
2. 합성 데이터: 결함 이미지 1만 장 생성 후 실제 데이터와 FID·분류 성능 개선폭으로 품질 검증
3. 안전 통제: NSFW, 상표, 유명인 얼굴, 워터마크 탐지를 배포 전 자동 필터로 적용

**결론 (2줄):**
- 기술사 판단: 내부 시안·합성 데이터는 Text-to-Image 활용, 외부 공개물은 권리 검토와 사람 검수 필수
- 향후 방향: ControlNet, LoRA, 생성 워터마킹으로 정밀 제어와 책임 추적이 강화됨
