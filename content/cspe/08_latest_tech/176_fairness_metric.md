## 미리 알고가기

- 공정성 지표는 전체 정확도 뒤에 가려진 집단 간 성능 격차를 수치화하는 도구임
- 어떤 지표를 선택하느냐는 수학 문제이면서 동시에 정책 문제임
- 하나의 모델이 모든 공정성 지표를 동시에 만족시키기 어려워 목적에 맞는 우선순위가 필요함

## Ⅰ. 개요

- **정의/개념**: 공정성 지표는 AI 모델의 예측 결과와 오류가 성별과 연령과 인종 같은 보호 집단 사이에서 얼마나 불균등하게 분포하는지를 정량적으로 측정하는 평가 기준임
- **배경/필요성**: 전체 정확도만으로는 특정 집단이 지속적으로 불이익을 받는 문제를 발견하기 어려우므로, 집단 간 결과와 오류를 별도로 비교하는 지표 체계가 필요해짐

## Ⅱ. 특징

- 공정성 지표는 결과 비율과 기회 보장과 오류 분포 중 무엇을 공정성으로 볼지 명확히 드러냄
- 동일 모델이라도 어떤 보호 집단과 기준값을 선택하는지에 따라 결과가 달라짐
- 수치 기준을 배포 게이트와 모니터링 대시보드에 직접 연결하기 쉬움
- 서로 충돌하는 지표가 많아 도메인별 우선 가치 판단이 반드시 필요함

## Ⅲ. 종류 및 비교

| 판단 기준 | Demographic Parity | Equal Opportunity | Equalized Odds |
|:---|:---|:---|:---|
| 비교 대상 | 긍정 예측 비율 | 실제 양성 집단의 재현율 | 재현율과 오탐률 동시 |
| 장점 | 결과 분포 격차를 직관적으로 봄 | 기회 박탈 여부를 직접 봄 | 오류 분포의 불균형까지 봄 |
| 적합한 영역 | 접근 기회 배분 | 채용, 대출, 선발 | 사법, 의료, 고위험 판단 |
| 한계 | 실제 자격 차이를 반영 못함 | 음성 집단 오탐은 반영 약함 | 달성 난도가 높음 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Protected Group Definition | 어떤 속성을 보호 집단으로 볼지 정해 측정 대상과 범위를 확정함 |
| Outcome, Error Statistics | 혼동 행렬 기반 결과와 오류를 집단별로 계산해 차이의 근거를 마련함 |
| Fairness Formula | parity와 opportunity와 odds 같은 수식을 적용해 gap 또는 ratio를 산출함 |
| Threshold, Policy Mapping | 허용 가능한 격차 한계와 승인 기준을 정해 수치를 운영 판단으로 연결함 |
| Monitoring Dashboard | 배포 후 집단별 성능 변화를 추적해 드리프트나 편향 재발을 감시함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 보호 집단 정의   | --> | 집단별 지표 계산  | --> | 핵심 지표 선택  | --> | 기준 초과 여부 판단 |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **보호 집단 정의**: 법적·도메인 관점에서 비교 대상을 정함
2. **집단별 지표 계산**: 예측 비율과 오류율을 집단별로 계산함
3. **핵심 지표 선택**: 피해 성격에 맞는 공정성 목표를 정함
4. **기준 초과 여부 판단**: 허용 격차와 비교해 배포 여부를 결정함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 도메인 맥락 없이 하나의 지표만 일괄 적용하면 실제 피해 유형과 맞지 않는 잘못된 공정성 판단이 나올 수 있음
   - 해결방안: harm-based metric selection을 수행하고 metric-policy alignment와 review consistency로 검증함
2. 문제: 소수 집단 표본이 매우 작으면 지표 변동성이 커져 운영 판단이 불안정해질 수 있음
   - 해결방안: confidence interval과 minimum sample guard를 적용하고 metric stability와 subgroup coverage로 검증함
3. 문제: 지표 임계치만 맞추는 방식은 사용자 경험과 개별 사례의 맥락을 놓쳐 형식적 대응으로 흐를 수 있음
   - 해결방안: case review와 qualitative audit를 병행하고 false fairness pass rate와 user complaint rate로 검증함

## Ⅶ. 적용 사례

- 대출 심사 모델이 기회 박탈을 줄이기 위해 equal opportunity gap을 핵심 지표로 운영되며 확인 지표는 TPR gap과 default rate임
- 채용 AI가 집단별 합격률과 오탐률을 함께 추적하며 운영되고 확인 지표는 demographic parity ratio와 recruiter appeal rate임
- 사기 탐지 모델이 오탐 피해를 관리하기 위해 equalized odds를 활용하며 확인 지표는 FPR gap과 manual review burden임

## Ⅷ. 결론

공정성 지표는 모델이 누구에게 어떤 방식으로 불이익을 주는지 숫자로 드러내는 장치이므로, 도메인 피해 유형에 맞는 지표 선택이 기술만큼 중요함.
