# 📖 【암기용】 개념 완전 이해

> 목적: Fairness Metric을 처음 봐도 완벽히 이해하게 만든다.

## 한눈에
- **개요**: AI 결과가 집단별로 불리하게 치우쳤는지 측정하는 정량 지표
- **왜 필요한가**: 정확도만 보면 특정 성별·연령·지역 집단의 오탐·미탐 피해를 놓칠 수 있음.
- **핵심 직관**: 전체 평균 점수 뒤에 숨어 있는 집단별 손해를 숫자로 드러내는 렌즈임.

## 깊이 이해
- **배경·문제의식**: 대출·채용·복지 AI는 개인 기회에 영향을 주므로 집단별 승인율, 오류율, 예측값 차이를 함께 봐야 한다.
- **작동 원리**: 민감속성별로 demographic parity, equal opportunity, equalized odds, calibration을 계산하고 허용 격차를 정함.
- **비유**: 반 전체 평균만 보지 않고 반별·성별·과목별 점수 차이를 따로 확인하는 성적 분석표임.
- **구체 예시**: 채용 모델에서 남성 true positive rate 82%, 여성 74%이면 equal opportunity gap은 8%p임.
- **흔한 오해·주의점**: 모든 지표를 동시에 만족하기 어렵다. 업무 피해 유형이 기회 박탈인지 오탐 피해인지 먼저 정해야 함.

## 연결 개념
- Bias Mitigation — 공정성 지표를 낮추는 전처리·학습·후처리 기법
- AI Impact Assessment — 집단별 영향 평가의 정량 근거
- Explainable AI — 불공정 결과 원인 해석과 증빙

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: Fairness Metric은 AI 결과의 집단별 차이를 정량 측정하는 책임 AI 지표임.
> 2. **가치**: 차별 리스크를 수치화해 모델 승인·보정·중단 기준으로 활용함.
> 3. **판단 포인트**: 업무 피해 유형에 맞는 지표와 허용 gap을 사전에 정의해야 함.

## Ⅰ. 개요 및 필요성

Fairness Metric은 AI 공정성 측정 지표다. AI가 전체 accuracy 90%를 달성해도 특정 집단 false negative rate가 높으면 실질 차별이 발생한다. 고위험 AI는 집단별 결과·오류 지표를 함께 관리해야 한다.

## Ⅱ. 구조 및 구성요소

```text
Sensitive Attribute -> Outcome Metric -> Error Metric
  -> Fairness Gap -> Governance Threshold
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 민감속성 | 성별·연령·장애·지역 등 집단 정의 | 법적 근거 필요 |
| 결과 지표 | 승인율·선정률 차이 측정 | demographic parity |
| 오류 지표 | TPR·FPR·FNR 차이 측정 | equalized odds |
| 임계값 | 허용 gap과 조치 기준 | 예: 5%p 초과 시 재학습 |

> 요약: 공정성 지표는 민감속성별 결과·오류 차이를 계산하고 임계값으로 조치 여부를 판단함.

## Ⅲ. 동작원리 및 흐름도

```text
집단 식별 -> 지표 선택 -> 집단별 산출
  -> gap 계산 -> 완화·승인 판단
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 민감속성과 보호집단 정의 | 법무 승인 100% |
| 2 | 피해 유형별 지표 선택 | 기회 박탈=TPR gap |
| 3 | 집단별 성능·결과 계산 | 표본 n≥100 기준 |
| 4 | 허용 gap 초과 시 완화 | gap ≤5%p 목표 |

> 요약: Fairness Metric은 보호집단을 정하고 결과·오류 gap을 계산해 배포 가능성을 판단함.

## Ⅳ. 특징

| 구분 | 전체 성능 지표 | Fairness Metric | 판단 포인트 |
|:---|:---|:---|:---|
| 관점 | 전체 평균 accuracy | 집단별 결과·오류 차이 | 평균 착시 제거 |
| 지표 | AUC, F1, RMSE | parity, opportunity, odds | 피해 유형별 선택 |
| 기준 | 단일 목표값 | gap·ratio 임계값 | 예: 5%p, 80% rule |
| 한계 | 차별 탐지 불가 | 지표 간 충돌 가능 | 업무 기준 우선 |

> 요약: Fairness Metric은 전체 성능 지표가 놓치는 집단별 피해를 수치화하는 보완 지표임.

## Ⅴ. 실무 적용 및 결론

**적용 방안 3개:**
1. 채용 AI: 성별·연령별 selection rate와 TPR을 산출하고 80% rule 및 5%p gap 기준 적용
2. 금융 AI: 대출 승인·부도 예측 모델의 FPR/FNR을 분기별 산출하고 gap 5%p 초과 시 threshold 재조정
3. 운영 거버넌스: 모델 승인 문서에 fairness metric, 표본 수, 허용 임계값, 예외 승인자를 기록

**결론 (2줄):**
- 기술사 판단: 사람의 권리·기회에 영향을 주는 AI는 accuracy와 fairness gap을 동시에 승인 기준으로 적용
- 향후 방향: Fairness Metric은 AI Impact Assessment와 Model Card의 필수 증빙 항목으로 확장됨
