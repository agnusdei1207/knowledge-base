## 미리 알고가기

- GNN은 노드와 간선으로 표현되는 그래프 데이터를 학습하는 신경망임
- 핵심 학습 메커니즘은 message passing과 aggregation임
- 관계 구조 자체가 중요한 추천과 분자와 FDS에서 강점을 가짐

## Ⅰ. 개요

- **정의/개념**: GNN은 그래프 구조에서 각 노드가 이웃 노드와 간선의 정보를 주고받으며 자신의 표현을 갱신하도록 학습해, 노드와 링크와 그래프 전체 수준의 예측을 수행하는 신경망 계열임
- **배경/필요성**: 소셜 관계와 거래 네트워크와 분자 구조처럼 연결성 자체가 의미를 결정하는 데이터는 CNN이나 RNN 같은 유클리드 구조 모델로 표현하기 어려워 전용 모델이 필요함

## Ⅱ. 특징

- 이웃의 속성과 구조를 함께 반영해 관계 기반 추론이 가능함
- 노드 분류와 링크 예측과 그래프 분류까지 다양한 태스크에 확장됨
- message passing을 반복할수록 멀리 있는 구조 정보도 일부 반영할 수 있음
- 레이어가 깊어지면 over-smoothing과 확장성 병목이 생기기 쉬움

## Ⅲ. 종류 및 비교

| 판단 기준 | GCN | GraphSAGE | GAT |
|:---|:---|:---|:---|
| 이웃 처리 | 전체 집계 | 샘플링 집계 | attention 집계 |
| 대규모 그래프 적합성 | 낮음 | 높음 | 중간 |
| 중요 이웃 가중화 | 낮음 | 낮음 | 높음 |
| 대표 강점 | 기본 구조 | 확장성 | 중요도 학습 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Node, Edge Features | 각 노드와 간선의 속성을 표현해 관계 학습의 원재료를 제공함 |
| Message Function | 이웃 노드와 간선에서 어떤 정보를 보낼지 계산해 관계 의미를 압축함 |
| Aggregation, Update | 수집된 메시지를 순서 불변 방식으로 집계하고 현재 노드 표현을 갱신함 |
| Readout Layer | 최종 노드 표현을 이용해 분류와 예측과 그래프 수준 점수를 생성함 |

```text
+-------------------+      +-------------------+      +-------------------+
| Node/Edge Feat.   | ---> | Message Passing   | ---> | Aggreg / Update   |
+-------------------+      +-------------------+      +-------------------+
                                                           |
                                                           v
                                                   +-------------------+
                                                   | Readout Layer     |
                                                   +-------------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 그래프 입력 준비 | --> | 이웃 메시지 수집 | --> | 노드 표현 갱신  | --> | 예측/분류 수행  |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **그래프 입력 준비**: 노드와 간선과 속성을 정의함
2. **이웃 메시지 수집**: 각 노드가 이웃으로부터 정보를 받음
3. **노드 표현 갱신**: 집계된 메시지로 임베딩을 업데이트함
4. **예측 및 분류 수행**: 학습된 표현으로 노드나 링크나 그래프를 예측함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 레이어를 깊게 쌓아 멀리 있는 이웃 정보를 반영하려 하면 노드 표현이 평균화되어 변별력이 약해질 수 있음
   - 해결방안: residual connection과 Jumping Knowledge를 적용하고 over-smoothing score와 validation accuracy로 검증함
2. 문제: 초대형 그래프에서 모든 이웃을 다 집계하면 메모리와 학습 시간이 빠르게 한계에 도달할 수 있음
   - 해결방안: neighborhood sampling과 mini-batch training을 적용하고 throughput과 GPU memory usage로 검증함
3. 문제: 그래프 구조가 시간에 따라 바뀌면 정적 학습 결과가 빠르게 오래되어 예측력이 떨어질 수 있음
   - 해결방안: temporal GNN과 증분 업데이트를 적용하고 freshness lag와 online AUC로 검증함

## Ⅶ. 적용 사례

- 금융 FDS가 계좌 간 거래 관계를 학습해 사기 계좌를 식별하도록 GNN을 적용하며 확인 지표는 AUC와 false positive rate임
- 추천 시스템이 사용자와 상품의 상호작용 그래프를 학습하도록 GNN을 운영하며 확인 지표는 CTR과 cold-start uplift임
- 신약 탐색이 분자 그래프 특성을 학습하도록 GNN을 활용하며 확인 지표는 MAE와 hit rate임

## Ⅷ. 결론

GNN은 관계 구조를 직접 학습하는 대표 신경망이므로, 확장성 확보와 과도한 평활화 방지가 실무 설계의 핵심 포인트임.
