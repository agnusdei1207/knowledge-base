# 📖 【암기용】 개념 완전 이해

> 목적: QKD를 양자 상태의 관측 교란 특성으로 대칭키를 분배하는 기술로 이해하게 만든다.

## 한눈에
- **개요**: 광자 등 양자 상태를 이용해 암호키를 생성·분배하는 기술
- **왜 필요한가**: 대칭키 암호는 키 공유가 선행되어야 하며, QKD는 도청 시 양자 상태 변화가 통계적으로 드러나는 물리 계층 키 분배 방식을 제공한다.
- **핵심 직관**: 봉투를 몰래 열면 흔적이 남는 것이 아니라, 양자 상태는 측정 행위 자체가 상태를 바꾸므로 도청 흔적을 오류율로 확인한다.

## 깊이 이해
- **배경·문제의식**: 기존 키교환은 계산복잡도 가정에 의존한다. QKD는 양자 채널로 raw key를 만들고 고전 인증 채널로 오류 정정과 privacy amplification을 수행한다.
- **작동 원리**: BB84 계열은 송신자가 서로 다른 기저로 광자를 보내고 수신자가 기저를 선택해 측정한다. 이후 기저가 일치한 비트만 남기고 QBER를 평가한다.
- **비유**: 서로 색안경을 무작위로 쓰고 빛을 보낸 뒤, 나중에 어떤 색안경을 썼는지만 공개해 같은 색안경 결과만 키로 남기는 방식이다.
- **구체 예시**: QBER가 운용 임계값을 넘으면 도청 또는 광 링크 품질 문제로 판단해 세션 키 생성을 중단한다.
- **흔한 오해·주의점**: QKD가 데이터를 암호화하는 것은 아니다. QKD는 키 분배 기술이며 실제 데이터 암호화는 AES 같은 대칭키 암호가 수행한다.

## 연결 개념
- PQC — 계산복잡도 기반 양자내성 암호
- BB84 — 대표 QKD 프로토콜
- ETSI ISG QKD — QKD 인터페이스·보안 요구 표준화 그룹

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식.
> 핵심: QKD는 양자 채널과 인증된 고전 채널로 대칭키를 분배하며, 거리·장비·운영비와 PQC 대체 가능성을 함께 판단해야 한다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: QKD는 양자 상태 측정 교란을 이용해 도청 여부를 오류율로 탐지하며 대칭키 재료를 생성한다.
> 2. **가치**: 광 링크 구간에서 키 분배를 계산복잡도 가정이 아닌 물리 법칙 기반 절차로 보완한다.
> 3. **판단 포인트**: QBER, 거리 손실, trusted node, 고전 채널 인증, PQC와 비용 대비 효과를 검토한다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 양자암호 원리 이해 확인 | 양자 채널, 고전 인증 채널, QBER | 데이터 암호화 기술로 설명 |
| 도입 판단 확인 | 전용 광링크, trusted node, 키관리 연계 | 인터넷 전 구간 적용으로 과장 |
| PQC와 비교 확인 | QKD는 물리 장비, PQC는 소프트웨어 전환 가능 | 둘 중 하나가 완전 대체로 단정 |

> 요약: 이 문제는 QKD의 물리 원리와 실제 네트워크 적용 제약을 분리해 설명해야 한다.

## Ⅰ. 개요 및 필요성

- 개요: 양자 기반 키 분배
- 배경: 장기 기밀 데이터와 기간 통신망은 양자컴퓨터 시대의 키교환 위험을 고려해야 함.
- 필요성: 전용 광링크 구간에서 도청 흔적을 QBER로 확인하고, 생성 키를 대칭키 암호에 공급해야 함.

---

## Ⅱ. 구조 및 구성요소

```text
Alice QKD Device -> Quantum Channel -> Bob QKD Device
Alice/Bob -> Authenticated Classical Channel -> Sifting/Error Correction
Key Manager -> AES/IPsec/MACsec Encryptor
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 양자 채널 | 광자 상태 전송 | fiber/free-space |
| 고전 인증 채널 | 기저 비교·오류 정정·인증 | 사전 인증 필요 |
| 후처리 엔진 | sifting, reconciliation, privacy amplification | QBER 기반 중단 |
| 키관리 연계 | 생성 키를 암호장비에 공급 | ETSI QKD 인터페이스 |

> 요약: QKD는 양자 채널만으로 끝나지 않고 인증된 고전 채널과 키관리 시스템이 함께 필요하다.

---

## Ⅲ. 동작원리 및 흐름도

```text
광자 상태 송신 -> 무작위 기저 측정 -> 기저 공개
-> 일치 비트 선별 -> QBER 계산 -> 오류 정정/정보 축소 -> 세션키 공급
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 송신자가 무작위 비트와 기저로 광자를 전송함 | photon source |
| 2 | 수신자가 무작위 기저로 측정함 | detector rate |
| 3 | 고전 채널에서 기저를 비교하고 일치 비트를 남김 | sifted key rate |
| 4 | QBER 평가 후 오류 정정과 privacy amplification을 수행함 | QBER threshold |

> 요약: QKD는 측정 결과 자체가 아니라 기저 일치 비트와 오류율 평가를 거쳐 사용 가능한 키를 만든다.

## Ⅳ. 특징

| 구분 | QKD | PQC | 판단 기준 |
|:---|:---|:---|:---|
| 기반 | 양자 물리·광 장비 | 수학적 난제 | 적용 계층 |
| 배포 | 전용 장비·링크 | 소프트웨어·프로토콜 교체 | 비용·범위 |
| 거리 | 광 손실·trusted node 제약 | 인터넷 전송 가능 | 네트워크 구조 |
| 산출물 | 대칭키 재료 | 키교환·서명 알고리즘 | 암호 목적 |

> 요약: QKD는 특정 링크의 키 분배에 적합하고, 범용 인터넷 전환은 PQC가 비용과 배포 측면에서 먼저 검토된다.

## Ⅴ. 심화 비교 및 적용 판단

| 구분 | 기존/대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 키교환 | ECDH, ML-KEM | QKD 키 분배 | 전용망·장기기밀 |
| 네트워크 | 일반 IP망 | 광 링크 기반 QKD망 | 거리·중계 구조 |
| 운영 | 소프트웨어 패치 | 장비 설치·정렬·검교정 | 운영 인력 |

> 요약: QKD는 금융·국방·기간망의 제한 구간에서 링크 단위로 검토하고, 일반 서비스는 PQC 전환이 선행된다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 키율 부족 | 광 손실·거리 증가 | 링크 예산 설계, trusted node | secret key rate |
| 인증 취약 | 고전 채널 미인증 | 사전 공유키 또는 PQC 인증 | authentication failure |
| 장비 공격 | detector blinding 등 구현 취약점 | 보안 평가, MDI-QKD 검토 | security test finding |

> 요약: QKD 보안은 이론만이 아니라 광학 장비 구현과 고전 채널 인증까지 검증해야 성립한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 링크 품질 | QBER 운용 임계값 이하 | QKD controller log |
| 키 공급 | 암호장비 요구 key rate 충족 | key manager metric |
| 운영성 | 장애·검교정 이력 관리 | maintenance record |

> 요약: QKD 성과는 도입 장비 수가 아니라 QBER, secret key rate, 암호장비 연계 성공률로 판단한다.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 장기 기밀성과 전용 광링크가 있는 구간을 선별하고 link budget, 거리, 중계점 신뢰 모델을 산정함.
2. ETSI QKD 인터페이스를 기준으로 key manager와 AES/IPsec/MACsec 장비 연계를 시험함.
3. PQC 기반 인증과 QKD 키 분배를 결합하고 QBER, key rate, 장애 이력을 월 단위로 점검함.

**결론 (2줄):**
- 기술사 판단: 전용망과 운영 예산이 있는 고보안 링크는 QKD를 검토하고, 대규모 인터넷 서비스는 PQC 전환을 우선 적용함.
- 향후 방향: QKD는 PQC와 경쟁하는 단일 해법이 아니라 고보안 링크에서 키관리 계층을 보완하는 방식으로 확산됨.
