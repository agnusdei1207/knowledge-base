## 미리 알고가기

- 디지털 증거는 컴퓨터, 서버, 모바일, 클라우드에 남은 로그, 파일, 메모리, 메타데이터임
- 무결성은 증거가 수집 시점 이후 변경되지 않았음을 해시와 절차로 증명하는 속성임
- 체인 오브 커스터디는 증거의 수집, 이동, 보관, 분석, 제출 이력을 끊김 없이 남기는 기록임

## Ⅰ. 개요

- **정의/개념**: 디지털 포렌식은 디지털 증거를 적법하게 수집, 보존, 분석, 보고해 사고 원인과 행위 사실을 입증하는 과학적 조사 절차임
- **배경/필요성**: 디지털 데이터는 복사와 변경이 쉬워 수집 방식이 잘못되면 증거 능력이 약해짐. 무결성과 보관 이력을 함께 입증해야 함

## Ⅱ. 특징

- 수집 과정의 적법성과 분석 과정의 재현성이 중요함
- 휘발성 데이터는 전원 차단이나 재부팅 전에 먼저 확보해야 함
- 원본은 봉인하고 분석은 사본 이미지로 수행하는 것이 원칙임
- 조사 결과보다 증거가 오염되지 않았다는 절차적 증명이 먼저 필요함

## Ⅲ. 종류 및 비교

| 구분 | 라이브 포렌식 | 데드 포렌식 |
|:---|:---|:---|
| 대상 상태 | 시스템이 동작 중인 상태 | 전원이 꺼진 저장매체 중심 |
| 주요 증거 | 메모리, 프로세스, 네트워크 연결 | 디스크 이미지, 파일, 로그 |
| 장점 | 휘발성 증거 확보 가능 | 원본 훼손 위험을 줄이기 쉬움 |
| 주의점 | 수집 도구 실행 자체가 상태를 바꿀 수 있음 | 전원 차단 전 증거를 잃을 수 있음 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 증거 식별 | 조사 범위와 대상 장치와 필요한 증거 유형을 정하는 시작 단계임 |
| 보존 조치 | 원본 봉인, 쓰기 방지, 해시 산출로 증거 오염을 막는 통제임 |
| 획득 도구 | 메모리 덤프, 디스크 이미징, 로그 수집을 수행하는 검증된 도구임 |
| 분석 환경 | 원본이 아닌 사본을 격리된 환경에서 분석해 재현성을 확보하는 공간임 |
| 보관 이력 | 누가 언제 증거를 취급했는지 기록해 법적 신뢰를 뒷받침하는 문서임 |

```text
증거 식별 -> 수집/획득 -> 해시 검증 -> 분석 -> 보고 -> 보관/제출
```

## Ⅴ. 원리 및 절차 흐름도

```text
현장 보존 -> 휘발성 수집 -> 이미지 생성 -> 무결성 검증 -> 분석 -> 보고서 작성
```

1. **현장 보존**: 대상 시스템과 주변 장치를 촬영하고 접근을 통제함
2. **휘발성 수집**: 메모리, 프로세스, 네트워크 연결처럼 사라지기 쉬운 정보를 먼저 확보함
3. **이미지 생성**: 쓰기 방지 상태에서 저장매체를 비트 단위로 복제함
4. **무결성 검증**: 원본과 사본의 해시값을 산출해 동일성을 확인함
5. **보고서 작성**: 분석 결과, 도구, 해시, 체인 오브 커스터디를 함께 기록함

## Ⅵ. 실무 적용 및 유의점

1. 침해 사고 서버는 즉시 재부팅하면 메모리 증거가 사라지므로 메모리와 네트워크 상태를 먼저 수집하고 해시값과 담당자 인계 기록으로 증거성을 확인함
2. 내부 유출 조사에서는 원본 PC를 직접 분석하지 말고 이미지 사본만 분석하며 원본 봉인 상태와 보관 이력 누락 여부로 절차 신뢰성을 점검함

## Ⅶ. 결론

- 디지털 포렌식은 데이터를 잘 찾는 기술보다 증거가 훼손되지 않았음을 끝까지 증명하는 절차가 핵심임
