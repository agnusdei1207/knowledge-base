## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 격자 기반의 모듈식 LWE 문제를 활용하여 양자 컴퓨터 공격에 내성을 지닌 차세대 디지털 서명 알고리즘(표준)임 |
| **배경/필요성** | 기존 RSA 및 ECDSA 서명이 양자 쇼어 알고리즘에 취약해짐에 따라 이를 대체할 고효율의 양자내성 서명 필요 |
| **출제 의도** | NIST FIPS 204 표준(ML-DSA)의 구조와 서명 생성 과정에서의 영지식 기반 Fiat-Shamir 변환 이해 평가 |

## Ⅱ. 구성요소
```text
+-------------------+      +-------------------+      +-------------------+
| Module-LWE Keypair|      | Fiat-Shamir Trans.|      | ML-DSA Signature  |
| (격자 기반 키 생성)+----->| (비대화형 영지식) +----->| (거부 샘플링 적용) |
+-------------------+      +-------------------+      +-------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| **M-LWE 키 쌍** | 다항식 격자와 고의적 오차를 결합하여 구성한 안전한 개인키와 공개키임 | 잡음이 섞인 복잡한 전자 도장 |
| **Fiat-Shamir 변환** | 증명자가 상대방의 질의 없이도 해시 함수를 통해 스스로 영지식 증명을 수행하는 수학적 기법임 | 혼자 풀어 제출하는 비대면 시험지 |
| **거부 샘플링 (Rejection Sampling)** | 서명 값이 개인키에 대한 어떠한 정보도 누출하지 않도록 특정 조건을 만족할 때까지 서명을 반복 재시도하는 기법임 | 완벽히 찍힐 때까지 도장 다시 찍기 |

> 요약: 격자 기반 난제에 영지식 증명 기법을 융합하여 서명 과정에서 비밀이 절대 새어나가지 않는 체계임.

## Ⅲ. 절차
```text
+----------------+   +----------------+   +----------------+   +----------------+
| 1. 키 쌍 생성  |-->| 2. 임시값 생성 |-->| 3. 서명 생성   |-->| 4. 서명 검증   |
| (행렬 및 오차) |   | (마스킹 다항식)|   | (거부 샘플링)  |   | (수신자 확인)  |
+----------------+   +----------------+   +----------------+   +----------------+
```
1. **키 쌍 생성**: 송신자가 M-LWE 기반 다항식 행렬에 오차를 추가해 공개키와 개인키를 생성함
2. **임시값 생성 및 해싱**: 서명 시마다 임의의 마스킹 다항식을 생성하고 메시지와 함께 해시하여 챌린지 값을 도출함(Fiat-Shamir)
3. **서명 생성(거부 샘플링)**: 개인키와 챌린지를 결합해 서명을 도출하며, 서명이 개인키 정보를 유출할 우려가 있으면 폐기하고 재시도함
4. **서명 검증**: 수신자가 공개키를 이용해 동일한 챌린지 해시값을 재계산하여 서명의 유효성을 확인함

> 요약: 서명 시 반복적인 안전성 검사(거부 샘플링)를 거쳐 정보 유출을 차단한 양자내성 증명서를 생성함.

## Ⅳ. 문제점
* **서명 크기의 비대화**: 기존 ECDSA 대비 서명 및 공개키 크기가 대폭 증가하여 네트워크 대역폭 및 스토리지 과부하 초래
* **거부 샘플링의 지연 시간**: 서명 생성 조건이 만족될 때까지 내부 루프를 반복하므로 실시간 트랜잭션 처리에서 지연 발생
* **부채널 공격(Timing/Power) 위협**: 서명 생성 중 반복 횟수나 연산 시간의 차이를 측정하여 개인키를 유추할 가능성 존재

## Ⅴ. 개선방안
* **단기 방안 (하드웨어 가속)**: AES-NI, AVX2 등 벡터 처리 명령어를 활용하여 다항식 연산과 해시 알고리즘 속도 극대화
* **중기 방안 (안전한 구현 기준)**: 거부 샘플링과 해시 연산 시 실행 시간이 입력값에 의존하지 않는 상수 시간(Constant-time) 로직 완벽 적용
* **장기 방안 (네트워크 단편화 최적화)**: 커진 서명 크기를 원활히 전송하기 위해 TLS 핸드셰이크 시 패킷 단편화 설정 및 TCP 윈도우 스케일링 최적화

## Ⅵ. 전망
* ML-DSA라는 명칭으로 차세대 디지털 서명 글로벌 표준(FIPS 204)으로 확정되어 전자 인증서(X.509)의 주력 서명 알고리즘으로 대체될 예정임
* 스마트카드나 IoT 기기와 같은 경량 환경에 적용하기 위한 메모리 최적화 및 경량 구현체 연구가 지속될 전망임
