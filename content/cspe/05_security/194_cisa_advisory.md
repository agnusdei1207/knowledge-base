## 미리 알고가기

- CISA는 미국 Cybersecurity and Infrastructure Security Agency로, 사이버 위협 권고와 중요 인프라 보안 정보를 제공함
- Cybersecurity Advisory는 공격 전술, 침해지표, 완화 방안을 포함한 위협 권고문임
- KEV는 Known Exploited Vulnerabilities로, 실제 악용 증거가 있는 취약점 목록임

## Ⅰ. 개요

- **정의/개념**: CISA 권고 사항은 CISA가 사이버 위협, 취약점 악용, 공격자 TTP, 침해지표, 완화 조치를 공개해 조직의 탐지와 패치 우선순위 결정을 돕는 보안 권고 체계임
- **배경/필요성**: 취약점과 위협 정보가 많아도 실제 공격에 쓰이는 항목은 제한적임. 공신력 있는 권고와 KEV 목록을 활용하면 긴급 대응 대상을 좁힐 수 있음

## Ⅱ. 특징

- 권고문은 공격자 전술과 탐지 지표와 완화 조치를 함께 제공함
- KEV 카탈로그는 실제 악용 증거와 명확한 조치가 있는 취약점을 우선시함
- 미국 기관 기준에서 출발하지만 글로벌 기업의 패치 우선순위 기준으로도 활용됨
- 권고를 내부 자산과 매핑하지 않으면 단순 뉴스 소비에 그칠 수 있음

## Ⅲ. 종류 및 비교

| 구분 | CISA Advisory | CISA KEV |
|:---|:---|:---|
| 주요 내용 | 공격 캠페인, TTP, IoC, 완화 조치 | 실제 악용 취약점과 조치 기한 |
| 활용 목적 | 탐지 룰과 대응 절차 개선 | 패치와 완화 우선순위 결정 |
| 판단 기준 | 위협 행위자와 공격 흐름 | 악용 증거와 조치 가능성 |
| 실무 산출물 | SIEM 룰, 차단 목록, 대응 플레이북 | 긴급 패치 목록, 예외 승인, 조치 증빙 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 위협 설명 | 공격자, 대상 산업, 공격 목적과 배경을 설명해 위험 맥락을 제공함 |
| TTP 정보 | MITRE ATT&CK 전술과 기법처럼 공격 흐름을 탐지 규칙으로 바꿀 수 있는 정보임 |
| 침해지표 | IP, 도메인, 파일 해시, 경로, 행위 패턴처럼 탐지와 차단에 쓰는 지표임 |
| 완화 조치 | 패치, 설정 변경, 계정 점검, 로그 확인처럼 실행 가능한 방어 조치임 |
| KEV 연계 | 실제 악용 취약점을 자산 목록과 연결해 우선 조치 대상을 정하는 기준임 |

```text
CISA 권고 수신 -> 자산 영향 확인 -> 탐지 룰 반영 -> 패치/완화 -> 조치 증빙
```

## Ⅴ. 원리 및 절차 흐름도

```text
권고 수집 -> 영향 분석 -> 우선순위 산정 -> 조치 실행 -> 모니터링 갱신
```

1. **권고 수집**: CISA Advisory, KEV, ICS Advisory, 경보를 정기적으로 수집함
2. **영향 분석**: 권고의 제품, CVE, TTP가 내부 자산과 로그에 해당하는지 확인함
3. **우선순위 산정**: KEV 등재 여부와 외부 노출 자산 여부를 함께 봄
4. **조치 실행**: 패치, 임시 완화, 탐지 룰, 차단 정책을 적용함
5. **모니터링 갱신**: 조치 결과와 신규 IoC를 SIEM, EDR, SOAR에 반영함

## Ⅵ. 실무 적용 및 유의점

1. KEV에 등재된 외부 노출 장비는 CVSS 점수만 보지 말고 긴급 변경 절차로 처리하며 조치 기한 준수율과 미조치 예외 승인 건수로 관리함
2. CISA Advisory의 IoC는 그대로 차단하기 전에 내부 로그와 자산 맥락을 확인하고 탐지 룰 오탐률과 실제 탐지 건수로 품질을 검증함

## Ⅶ. 결론

- CISA 권고 사항은 위협 정보를 읽는 자료가 아니라 내부 자산, 탐지 룰, 패치 우선순위로 연결해야 가치가 생기는 운영 입력임
