## 미리 알고가기

- 보안 인식은 임직원이 위협과 보안 수칙을 이해하고 일상 업무에서 적용하는 상태임
- 사회공학은 사람의 신뢰, 긴급함, 호기심을 이용해 정보나 권한을 빼내는 공격임
- 피싱 모의훈련은 실제 공격과 유사한 메일을 보내 클릭, 신고, 대응 행동을 측정하는 훈련임

## Ⅰ. 개요

- **정의/개념**: 보안 인식 교육은 임직원이 피싱, 비밀번호, 자료 반출, 물리 보안 같은 일상 보안 위험을 이해하고 올바른 행동을 반복하게 하는 교육·훈련 활동임
- **배경/필요성**: 기술 통제가 강해져도 사람의 실수와 사회공학은 계속 사고의 시작점이 됨. 교육은 지식 전달이 아니라 위험 행동을 줄이는 운영 통제여야 함

## Ⅱ. 특징

- 전 직원 공통 교육과 직무별 심화 교육을 나누어 운영함
- 피싱 모의훈련처럼 행동을 측정해야 실제 변화 여부를 알 수 있음
- 처벌 중심보다 신고와 조기 대응을 장려해야 은폐 위험이 줄어듦
- 일회성 동영상 수강보다 반복 학습과 즉시 피드백이 효과적임

## Ⅲ. 종류 및 비교

| 구분 | 일반 인식 교육 | 실전형 모의훈련 | 역할 기반 교육 |
|:---|:---|:---|:---|
| 대상 | 전 임직원 | 피싱과 사회공학 노출 대상 | 개발자, 운영자, 재무팀 등 |
| 방식 | 온라인 교육, 서약, 안내 | 모의 메일, 테일게이팅, 신고 훈련 | 직무 위험 시나리오 중심 |
| 장점 | 빠르게 전사 확산 가능 | 실제 행동 지표를 얻기 좋음 | 업무별 위험을 직접 줄임 |
| 한계 | 수강 완료가 행동 변화를 보장하지 않음 | 처벌식 운영 시 신고가 줄 수 있음 | 콘텐츠 관리 부담이 큼 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 교육 정책 | 교육 대상, 주기, 필수 과정, 예외 기준을 정해 운영 기준을 통일함 |
| 위협 시나리오 | 피싱, 랜섬웨어, 자료 반출, 출입 통제 같은 실제 공격 상황을 반영한 내용임 |
| 훈련 플랫폼 | 모의 메일 발송, 클릭 추적, 신고 접수, 재교육을 자동화하는 실행 기반임 |
| 측정 지표 | 클릭률, 신고율, 재교육 완료율, 반복 클릭자 수로 행동 변화를 확인함 |
| 피드백과 개선 | 훈련 결과를 부서와 직무별로 분석해 다음 교육 내용에 반영하는 단계임 |

```text
위협 선정 -> 교육 배포 -> 모의훈련 실행 -> 행동 측정 -> 재교육/개선
```

## Ⅴ. 원리 및 절차 흐름도

```text
대상 분류 -> 콘텐츠 설계 -> 교육 수행 -> 모의훈련 -> 결과 분석 -> 보완 교육
```

1. **대상 분류**: 전 직원, 고위험 부서, 관리자, 개발자 등 교육 대상을 나눔
2. **콘텐츠 설계**: 조직의 최근 사고와 위협 유형을 반영해 교육 내용을 구성함
3. **교육 수행**: 온라인 교육, 집합 교육, 안내 캠페인을 실행하고 이수 여부를 기록함
4. **모의훈련**: 실제 공격과 유사한 피싱과 사회공학 시나리오로 행동을 측정함
5. **보완 교육**: 고위험 행동을 보인 대상에게 짧은 재교육과 피드백을 제공함

## Ⅵ. 실무 적용 및 유의점

1. 피싱 모의훈련은 클릭자 처벌보다 빠른 신고를 장려하고 신고율과 반복 클릭자 감소율로 보안 문화 변화를 확인함
2. 개발자와 운영자는 일반 교육만으로 부족하므로 시큐어 코딩과 권한 관리 교육을 별도 운영하고 취약 코드 재발률과 권한 예외 건수로 효과를 점검함

## Ⅶ. 결론

- 보안 인식 교육은 컴플라이언스 이수 행사가 아니라 사람의 위험 행동을 측정하고 바꾸는 지속적 운영 통제임
