# 📖 【암기용】 개념 완전 이해

> 목적: 개인정보보호법 2023 개정의 의미를 처음 보는 사람도 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 설명이다.

## 한눈에
- **개요**: 2023년 개정은 온라인·오프라인 규율 통합, 전송요구권, 자동화된 결정, 과징금 체계를 정비한 대개정
- **왜 필요한가**: 기존 법은 정보통신서비스 특례와 일반 개인정보 규율이 나뉘어 같은 행위도 업종에 따라 기준이 달랐다. 데이터 이동과 AI 자동결정이 늘면서 정보주체 권리와 제재 체계를 다시 설계할 필요가 생김.
- **핵심 직관**: 개정의 방향은 "동의서 중심 보호"에서 "권리 행사, 데이터 이동, 경제 제재, 공공시스템 통제"로 이동한 것임.

## 깊이 이해
- **배경·문제의식**: 플랫폼, 금융, 의료, 통신 데이터가 API로 이동하고 자동화된 의사결정이 서비스 결과를 좌우한다. 단순 동의·철회 화면만으로는 데이터 이동권, 설명 요구, 대규모 유출 제재를 다루기 어려움.
- **작동 원리**: 2023.3.14 개정은 개인정보 전송요구권(제35조의2), 개인정보관리 전문기관(제35조의3), 자동화된 결정에 대한 권리(제37조의2), 전체 매출액 3% 이내 과징금(제64조의2)을 도입·정비함. 2026년 기준 반복·중대 침해는 10% 특례를 별도 확인해야 함.
- **비유**: 은행 계좌이체처럼 개인정보도 본인이 지정한 곳으로 안전하게 옮길 수 있어야 한다. 대신 전송자와 수신자는 본인확인, 전송내역, API 통제를 남겨야 함.
- **구체 예시**: 의료·통신·유통 분야의 전송요구권이 단계 적용되면 정보주체는 보유기관에서 본인 또는 제3자에게 데이터를 전송하도록 요구할 수 있고, 기관은 전송 실패 사유와 철회 절차를 안내해야 함.
- **흔한 오해·주의점**: 마이데이터는 무제한 데이터 공유가 아님. 정보주체 본인 데이터, 컴퓨터 등 장치로 처리되는 데이터, 분석·가공으로 별도 생성한 정보 제외 등 요건을 충족해야 함.

## 연결 개념
- 전송요구권: 정보주체가 본인 또는 제3자에게 개인정보 전송을 요구하는 권리
- 자동화된 결정: 완전 자동 처리 결과에 대한 설명·거부·인적 개입 요구
- 과징금 제도: 일반 3%, 반복·중대 침해 10% 특례와 면제·감경 판단

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: PIPA 2023 개정은 개인정보 보호 규율을 권리 행사·데이터 이동·자동화된 결정·경제 제재 중심으로 재편한 법제 전환이다.
> 2. **가치**: 전송요구권과 과징금 체계는 데이터 활용을 허용하되 본인 통제권, API 전송기록, 위반 비용을 동시에 설계하게 함.
> 3. **판단 포인트**: 마이데이터 대상성, 자동화 결정 설명, 일반 3%·반복 중대 10% 과징금, 72시간 통지·신고를 구분해야 함.

## Ⅰ. 개요 및 필요성

- 개요: 개인정보 권리·제재 재설계
- 배경: 온라인·오프라인 규율 차이를 줄이고 마이데이터, 자동화 결정, 공공시스템 접속기록, 과징금 기준을 정비했다.
- 필요성: 2023년 개정 기준으로 전송요구권 API, 자동화 결정 거부·설명 절차, 매출액 기반 과징금 산정 증적을 준비해야 한다.

## Ⅱ. 구조 및 구성요소

```text
PIPA 2023 Amendment
  / 권리: 전송요구권, 자동화된 결정 대응
  / 제재: 일반 3% 과징금, 반복·중대 침해 10% 특례, 형벌 정비
  / 운영: 공공시스템 접속기록, 72시간 유출 통지·신고
처리자 -> 권리 요청 접수 -> API/로그/심사 -> 이행/거절 사유 통지 -> 감사 증적
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 전송요구권 | 본인 또는 제3자에게 개인정보 전송 요구 | 제35조의2, 분석·가공 생성정보 제외 |
| 자동화된 결정 권리 | 자동 처리 결과에 대한 설명·거부·인적 개입 요구 | 2024.3.15 시행 항목으로 별도 안내 필요 |
| 과징금 개편 | 일반 위반 3%, 반복·중대 침해 10% 특례 | 매출 산정 곤란 시 20억원 이내 |
| 공공시스템 통제 | 접속기록 저장·분석, 관리책임자 지정 | 사적 이용 시 5년 이하 징역 또는 5천만원 이하 벌금 가능 |

> 요약: 2023 개정 구조는 정보주체 권리 확대, 제재 실효성 확보, 공공·민간 운영통제를 하나로 묶음.

## Ⅲ. 동작원리 및 흐름도

```text
개정 적용 대상 식별 -> 권리 요청 채널 마련 -> 전송/설명/거부 처리 -> 로그·통지·신고 기록 -> 과징금 리스크 평가
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 서비스별 개인정보 처리 근거와 개정 적용 조항 식별 | 데이터 맵, 처리방침 개정 이력 |
| 2 | 전송요구·자동화 결정 권리 행사 채널 제공 | 웹·앱 요청 화면, 본인확인 로그 |
| 3 | 전송 가능 여부, 거절 사유, 철회·변경 절차 처리 | API 전송로그, 거절 사유 코드 |
| 4 | 위반 발생 시 통지·신고·과징금 산정 대응 | 72시간 타임라인, 매출액 산정 자료 |

> 요약: 개정 적용은 권리 채널 구축에서 끝나지 않고 전송로그, 거절 사유, 과징금 산정자료까지 남겨야 함.

> 요약: 개정 준수 여부는 권리 요청 기록률, 전송 보안 설정률, 72시간 대응 훈련으로 검증함.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 — 단계별 또는 항목별):**
1. 권리 행사 포털 구축: 전송요구, 자동화 결정 설명, 철회·변경 요청을 단일 티켓으로 접수하고 처리기한·거절 사유 기록
2. 과징금 대응 자료화: 서비스별 매출, 개인정보 처리 목적, 위반행위 기간, 피해 가능성, 감경자료를 월 단위로 갱신
3. 공공·대규모 시스템 로그분석: 접속기록 1년 이상 보관, 이상조회 탐지룰 20개 이상 운영, 권한 재검토 월 1회 수행

**결론 (2줄):**
- 기술사 판단: 단순 민원 수준이면 절차 고지, 대규모 API 전송·자동화 결정 서비스면 전용 워크플로와 로그분석 체계를 선택함
- 향후 방향: PIPA 대응은 동의서 개정에서 끝나지 않고 마이데이터 API, AI 설명, 과징금 산정자료를 통합한 개인정보 거버넌스로 확장 필요
