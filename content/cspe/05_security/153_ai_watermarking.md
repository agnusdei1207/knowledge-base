## 미리 알고가기

- 가시 워터마크는 사람이 바로 볼 수 있는 로고나 문구 형태의 표식임
- 비가시 워터마크는 사람 눈에는 잘 보이지 않지만 알고리즘으로 검출하는 숨은 신호임
- 검출기는 콘텐츠 안에 워터마크 신호가 남아 있는지 판정하는 도구임

## Ⅰ. 개요

- **정의/개념**: AI 워터마킹은 텍스트, 이미지, 음성 같은 생성물 안에 출처나 생성 사실을 추적할 수 있는 신호를 넣어 나중에 기계적으로 판별하게 하는 기술임
- **배경/필요성**: 생성형 AI가 만든 콘텐츠가 빠르게 퍼지면서 진짜와 합성물을 구분하고 오남용 경로를 추적할 수 있는 표시 수단이 필요해짐

## Ⅱ. 특징

- 생성 사실이나 생성 주체를 나중에 검출할 수 있게 돕는다
- 콘텐츠 품질 훼손을 최소화해야 실사용성이 높아짐
- 재압축, 잘라내기, 재서술 같은 변형에 약할 수 있음
- 진위 증명의 완전한 해법이라기보다 추적과 억지 효과에 강함

## Ⅲ. 종류 및 비교

| 판단 기준 | 가시 워터마크 | 비가시 워터마크 |
|:---|:---|:---|
| 표시 방식 | 사람 눈에 보이는 로고나 문구 | 통계적 신호나 픽셀·토큰 패턴 |
| 장점 | 직관적으로 바로 인지 가능함 | 사용자 경험을 덜 해치고 자동 검출에 유리함 |
| 약점 | 잘라내기와 가림에 취약함 | 변형과 재생성에 약할 수 있음 |
| 적합 환경 | 공개 배포물 표시 | 대량 검출과 사후 추적 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 생성 모델 | 텍스트나 이미지나 음성을 만들어 냄 |
| 워터마크 삽입기 | 생성 과정이나 후처리 단계에서 신호를 넣음 |
| 배포 콘텐츠 | 사용자에게 전달되는 최종 산출물임 |
| 검출기 | 워터마크 존재 여부와 신뢰도를 판단함 |
| 검증 키·정책 | 어떤 신호를 진짜로 볼지 기준을 제공함 |

```text
콘텐츠 생성 -> 워터마크 삽입 -> 배포 -> 검출 -> 출처 판단
```

## Ⅴ. 원리 및 절차 흐름도

```text
생성 요청 -> 모델 출력 생성 -> 워터마크 신호 삽입 -> 배포 후 검출 -> 판정 결과 기록
```

1. **생성 요청**: 사용자가 이미지나 텍스트 생성을 요청함
2. **출력 생성**: 모델이 기본 콘텐츠를 만듦
3. **신호 삽입**: 생성 과정이나 후처리에서 표식을 넣음
4. **배포 후 검출**: 나중에 검출기로 신호를 다시 찾음
5. **판정 기록**: 생성물 여부나 출처 정보를 기록하고 활용함

## Ⅵ. 실무 적용 및 유의점

1. 이미지 생성 서비스는 비가시 워터마크와 메타데이터를 함께 붙이고 재압축 뒤 검출률과 잘라내기 뒤 검출률로 점검함
2. 텍스트 워터마킹은 품질 저하가 크면 우회가 쉬워지므로 답변 품질과 오탐을 함께 보고 잘못 검출한 비율과 놓친 비율로 확인함

## Ⅶ. 결론

- AI 워터마킹은 생성 사실을 남기는 추적 기술이므로 단독 해법으로 보기보다 출처 검증과 함께 써야 함
