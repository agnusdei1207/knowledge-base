## 미리 알고가기

- 적대적 예제는 사람 눈에는 거의 같아 보여도 모델 판단만 흔들도록 만든 입력임
- 교란은 입력에 더하는 작은 변화나 잡음을 말함
- 추론 단계는 학습이 끝난 모델이 실제 입력을 받아 답을 내는 운영 구간임

## Ⅰ. 개요

- **정의/개념**: 적대적 예제 공격은 이미지, 음성, 텍스트 입력에 작은 교란을 더해 사람은 거의 못 느끼지만 모델만 오분류하게 만드는 추론 단계 공격임
- **배경/필요성**: 자율주행, 얼굴 인식, 음성 인증은 모델 판단이 서비스 동작으로 이어짐. 작은 입력 흔들림도 큰 오동작이 될 수 있음

## Ⅱ. 특징

- 학습 데이터를 오염하지 않아도 배포된 모델을 바로 흔들 수 있음
- 사람 기준 자연스러운 입력과 모델 기준 취약한 입력이 다를 때 잘 생김
- 목표 클래스로 유도하는 표적 공격과 단순 오분류를 노리는 비표적 공격이 있음
- 성능 방어를 위해 전처리, 강건 학습, 다중 센서 검증을 함께 봐야 함

## Ⅲ. 종류 및 비교

| 판단 기준 | 데이터 오염 공격 | 적대적 예제 공격 |
|:---|:---|:---|
| 공격 시점 | 학습 단계 | 추론 단계 |
| 손대는 대상 | 데이터셋과 라벨 | 실제 입력값 |
| 주된 효과 | 모델 성향 자체 왜곡 | 특정 입력에서 오분류 유도 |
| 방어 초점 | 데이터 검증 | 입력 강건성 강화와 전처리 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 원본 입력 | 정상 이미지, 음성, 문장 같은 기본 데이터임 |
| 교란 생성기 | 모델 취약 지점을 노려 작은 변형을 계산함 |
| 공격 입력 | 원본과 비슷해 보이지만 모델에는 다른 신호로 읽힘 |
| 대상 모델 | 교란된 입력을 받아 잘못 분류하거나 잘못 응답함 |
| 방어 계층 | 전처리, 이상치 탐지, 다중 모델 검증으로 피해를 줄임 |

```text
원본 입력 -> 교란 생성기 -> 공격 입력 -> 대상 모델 -> 오분류
```

## Ⅴ. 원리 및 절차 흐름도

```text
원본 선택 -> 모델 취약 방향 계산 -> 작은 교란 추가 -> 모델 질의 -> 오분류 확인
```

1. **원본 선택**: 공격자가 정상 입력 하나를 고름
2. **취약 방향 계산**: 모델이 헷갈리기 쉬운 방향을 찾음
3. **교란 추가**: 눈에 잘 띄지 않는 수준으로 입력을 바꿈
4. **모델 질의**: 수정된 입력을 넣어 반응을 확인함
5. **오분류 확인**: 목표한 잘못된 분류나 응답이 나오면 성공임

## Ⅵ. 실무 적용 및 유의점

1. 얼굴 인식과 음성 인증 서비스는 적대적 예제 시험 세트와 다중 모델 검증을 두고 공격 성공률과 정상 사용자 차단 비율로 점검함
2. 카메라 기반 인식 시스템은 다른 센서나 규칙 기반 검사와 함께 쓰고 센서 간 판단 불일치율과 현장 재현 건수로 확인함

## Ⅶ. 결론

- 적대적 예제 공격은 입력이 조금만 흔들려도 모델이 크게 틀릴 수 있음을 보여 주므로 운영 단계 강건성 검증이 필수임
