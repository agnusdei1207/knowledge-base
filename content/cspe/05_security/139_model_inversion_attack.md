## 미리 알고가기

- 신뢰도 점수는 모델이 각 답을 얼마나 그럴듯하게 보는지 수치로 나타낸 값임
- 학습 데이터는 모델이 패턴을 익히는 데 사용한 원본 데이터임
- 차분 프라이버시는 개별 데이터의 영향이 쉽게 드러나지 않게 학습 잡음을 넣는 보호 기법임

## Ⅰ. 개요

- **정의/개념**: 모델 역전 공격은 모델이 내놓는 예측값과 신뢰도 점수를 반복해 모아 학습 데이터의 민감한 특징이나 원본에 가까운 정보를 거꾸로 복원하는 프라이버시 공격임
- **배경/필요성**: 얼굴, 의료, 생체 인증처럼 개인 정보가 강한 데이터를 학습한 모델이 상세 확률을 외부에 내보내면 출력만으로도 원본 정보를 추정할 수 있어 API 설계 자체가 보호 대상이 됨

## Ⅱ. 특징

- 모델 파일을 훔치지 않아도 출력만으로 공격이 가능함
- 정확한 확률 분포나 점수형 응답을 줄수록 복원 가능성이 커짐
- 전체 모델 복제보다 특정 개인 특성 복원에 더 초점이 맞춰짐
- 정상 질의처럼 보여 탐지가 쉽지 않음

## Ⅲ. 종류 및 비교

| 판단 기준 | 모델 역전 공격 | 모델 추출 공격 |
|:---|:---|:---|
| 노리는 대상 | 학습 데이터의 민감 정보 | 모델의 동작과 예측 성능 |
| 대표 결과 | 얼굴, 속성, 기록의 일부 복원 | 대리 모델 생성과 기능 복제 |
| 주된 입력 | 신뢰도 점수와 클래스 확률 | 입력-출력 쌍 대량 수집 |
| 방어 초점 | 출력 정보 축소와 프라이버시 학습 | 질의 제한과 복제 탐지 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 예측 API | 외부 사용자가 모델에 질의하는 창구임 |
| 점수 응답 | 클래스 확률이나 신뢰도를 제공하는 출력임 |
| 공격 최적화기 | 원하는 점수가 높아지도록 입력을 반복 조정함 |
| 재구성 결과 | 학습 데이터의 특징을 닮은 입력이 만들어짐 |
| 탐지·제한 계층 | 과도한 질의와 상세 점수 노출을 줄이는 방어 지점임 |

```text
질의 입력 -> 예측 API -> 점수 응답 -> 공격 최적화기 -> 재구성 결과
```

## Ⅴ. 원리 및 절차 흐름도

```text
반복 질의 -> 점수 수집 -> 목표 속성 점수 최대화 -> 입력 보정 -> 민감 정보 근사 복원
```

1. **반복 질의**: 공격자가 다양한 입력으로 모델을 여러 번 호출함
2. **점수 수집**: 각 질의에서 클래스 점수와 확률 분포를 모음
3. **목표 점수 최대화**: 특정 속성의 점수가 높아지는 방향으로 입력을 바꿈
4. **입력 보정**: 반복 계산으로 원본에 가까운 패턴을 찾아감
5. **근사 복원**: 민감한 특징이나 개별 표본과 닮은 결과를 얻음

## Ⅵ. 실무 적용 및 유의점

1. 얼굴 인식과 의료 예측 API는 상세 확률 대신 최소한의 결과만 노출하고 질의 빈도도 묶어야 하며 복원 유사도와 비정상 반복 질의 비율로 확인함
2. 자체 모델을 학습하는 조직은 차분 프라이버시나 정규화 기법으로 개별 표본 의존도를 낮추고 학습 뒤 특정 표본이 실제 학습에 쓰였는지 맞히는 시험과 역전 재현 성공률로 점검함

## Ⅶ. 결론

- 모델 역전 공격은 출력이 곧 개인정보 유출 통로가 되는 경우이므로 정확도보다 출력 정보량 통제가 먼저임
