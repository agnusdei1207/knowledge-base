## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | W3C DID 표준 기반으로 중앙 기관 의존 없이 사용자가 자신의 신원 정보를 직접 소유·관리·제시하는 자기주권 신원(SSI) 체계임 |
| **배경/필요성** | 중앙 집중 IdP의 데이터 유출·프라이버시 침해 문제를 해결하기 위해, 탈중앙화된 사용자 중심 신원 관리가 필요함 |
| **출제 의도** | DID-VC-VP 3자 모델과 선택적 공개(Selective Disclosure)의 원리를 이해하는지 평가함 |

## Ⅱ. 구성요소
```
+----------+     +----------+     +----------+
|  발급자   | --> |  보유자   | --> |  검증자   |
| (Issuer) |     | (Holder) |     | (Verifier)|
+----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| DID | 블록체인·분산 원장에 등록된 탈중앙 식별자로, 공개키와 매핑됨 | 전 세계 통용 여권 번호 |
| VC(검증가능 자격증명) | 발급자가 서명한 디지털 증명서로, 보유자 지갑에 저장됨 | 대학 졸업장 |
| VP(검증가능 프레젠테이션) | 보유자가 필요한 정보만 선택하여 검증자에게 제시하는 데이터 패키지임 | 졸업장에서 학위명만 보여줌 |

> 요약: 발급자(VC 발급) → 보유자(지갑 보관) → 검증자(VP 검증)의 3자 모델로 자기주권 신원을 구현함.

## Ⅲ. 절차
```
+------------+     +------------+
| DID생성    | --> | VC발급     |
| (사용자)   |     | (발급자서명)|
+------------+     +------------+
                        |
+------------+     +----+-------+
| 검증자     | <-- | VP제시    |
| 서명검증   |     | (선택공개) |
+------------+     +------------+
```

1. DID 생성: 사용자가 키쌍을 생성하고 DID Document를 분산 원장에 등록함
2. VC 발급: 발급자(대학·정부)가 사용자의 자격 정보를 서명하여 VC를 발급하고, 사용자 지갑에 저장함
3. VP 제시: 사용자가 검증자에게 필요한 속성만 선택하여 VP를 구성·제시함(선택적 공개)
4. 서명 검증: 검증자가 분산 원장에서 발급자의 공개키를 조회하여 VP의 서명과 유효성을 검증함

> 요약: DID 생성 → VC 발급 → VP 선택 제시 → 서명 검증으로 발급자 접촉 없이 신원을 증명함.

## Ⅳ. 문제점
- 키 분실 복구: 개인키 분실 시 DID에 연결된 모든 자격증명이 사용 불가하며 복구가 어려움
- 표준 파편화: DID Method(did:web, did:ion 등)가 다수 존재하여 상호운용성이 부족함
- 사용자 경험: 지갑 앱·DID 개념에 익숙하지 않은 일반 사용자의 진입 장벽이 높음

## Ⅴ. 개선방안
- (단기) 소셜 복구: 신뢰할 수 있는 연락처에 복구 조각을 분산 보관하여 키 분실에 대비함
- (중기) DID 상호운용: W3C DID Universal Resolver로 다양한 DID Method를 통합 해석함
- (장기) 플랫폼 통합: 모바일 OS에 DID 지갑을 기본 내장하여 사용자 경험을 개선함

## Ⅵ. 전망
- EU eIDAS 2.0 디지털 지갑·국내 모바일 운전면허증 등 정부 주도 DID 사업이 확대되며, SSI 기반 신원 체계가 Web3 시대의 핵심 인프라로 자리잡을 전망임
