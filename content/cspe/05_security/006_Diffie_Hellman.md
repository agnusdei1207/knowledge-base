## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 공개된 통신망에서 두 사용자가 안전하게 공통의 비밀키를 공유할 수 있는 키 교환 알고리즘임 |
| **배경/필요성** | 암호 통신을 위한 대칭키를, 물리적인 전달 없이 안전하지 않은 채널을 통해 공유할 수단 필요 |
| **출제 의도** | 이산대수 문제의 수학적 난제 이해 및 중간자 공격(MITM)의 위협과 대응 원리 평가 |

## Ⅱ. 구성요소
```text
+-------------------+      +-------------------+      +-------------------+
| Public Parameters |      | Private Value     |      | Shared Secret Key |
|  (소수 p, 원시근 g)+----->| (각자의 비밀값)  +----->|  (계산된 공통키)  |
+-------------------+      +-------------------+      +-------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| **공개 매개변수 (p, g)** | 통신 당사자가 사전에 합의하여 공개적으로 사용하는 큰 소수와 원시근임 | 공통의 기본 물감(노랑) |
| **개인 비밀값 (a, b)** | 각 당사자가 임의로 선택하여 절대 외부에 노출하지 않는 난수임 | 각자의 고유 색상(파랑, 빨강) |
| **공통 비밀키 (K)** | 교환된 값을 바탕으로 양측이 독립적으로 계산해낸 동일한 최종 키임 | 최종 혼합 색상(초록) |

> 요약: 공개된 정보와 각자의 비밀값을 조합하여, 도청자도 알 수 없는 공통의 암호키를 도출하는 구조임.

## Ⅲ. 절차
```text
+----------------+   +----------------+   +----------------+   +----------------+
| 1. 매개변수 공유|-->| 2. 공개값 계산 |-->| 3. 공개값 교환 |-->| 4. 공통키 계산 |
| (소수 p, g 합의)|   | (비밀값 적용)  |   | (상호 전송)    |   | (독립적 도출)  |
+----------------+   +----------------+   +----------------+   +----------------+
```
1. **매개변수 공유**: 송수신자가 큰 소수 p와 생성자 g를 선택하여 공개 채널로 공유함
2. **공개값 계산**: 송신자는 비밀값 a로 A=g^a mod p를, 수신자는 비밀값 b로 B=g^b mod p를 계산함
3. **공개값 교환**: 계산된 공개값 A와 B를 네트워크를 통해 서로 교환함
4. **공통키 계산**: 송신자는 K=B^a mod p, 수신자는 K=A^b mod p를 계산하여 동일한 비밀키 K를 확보함

> 요약: 부분 연산된 값을 교환하고, 상대의 값에 자신의 비밀값을 재연산하여 동일한 키를 획득함.

## Ⅳ. 문제점
* **중간자 공격(MITM) 취약성**: 통신 대상자의 신분을 인증하는 메커니즘이 없어, 중간에서 공격자가 키를 조작해 가로챌 수 있음
* **계산 오버헤드 과다**: 매우 큰 수에 대한 모듈러 지수 연산을 수행하므로 CPU 자원 소모가 크고 지연 발생
* **정적 키 재사용 위험**: 고정된 비밀값을 장기간 사용할 경우, 향후 유출 시 과거 통신 내역이 모두 해독됨(PFS 부재)

## Ⅴ. 개선방안
* **단기 방안 (전자서명 결합)**: RSA 등 전자서명을 통한 상호 인증 단계를 추가하여 중간자 공격(MITM) 차단
* **중기 방안 (DHE, Ephemeral 도입)**: 통신 세션마다 새로운 난수를 사용하는 DHE(일회성 디피-헬만)를 도입하여 완전 순방향 비밀성(PFS) 확보
* **장기 방안 (ECDH 전환)**: 타원 곡선 암호(ECC) 기반의 ECDH로 대체하여 연산량을 줄이고 보안 강도는 상향시킴

## Ⅵ. 전망
* 단순 디피-헬만은 점차 도태되고 상호 인증이 결합된 ECDHE 방식이 TLS 1.3의 핵심 키 교환 표준으로 고착됨
* 향후 양자 컴퓨터 공격에 취약하므로, 격자 기반 암호 등 PQC(양자내성암호) 방식의 키 캡슐화 메커니즘(KEM)으로 대체될 전망임
