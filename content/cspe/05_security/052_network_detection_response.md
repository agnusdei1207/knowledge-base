## 미리 알고가기

- NDR은 네트워크 패킷과 플로우와 메타데이터를 분석해 위협을 탐지하고 대응하는 체계임
- IDS/IPS가 시그니처 탐지에 강하다면 NDR은 행위 분석과 암호화 메타데이터 활용에 강함
- 동서 트래픽과 클라우드 트래픽 가시성 확보가 실제 성능을 좌우함

## Ⅰ. 개요

- **정의/개념**: NDR은 패킷, 플로우, DNS, TLS 메타데이터를 분석해 네트워크 기반 침해 징후를 탐지·대응하는 체계임
- **배경/필요성**: 암호화 트래픽과 정상 계정 악용이 늘어 IDS/IPS만으로는 측면 이동과 은닉 행위를 놓치기 쉬움

## Ⅱ. 특징

- 플로우, 세션, DNS, TLS 특성으로 이상 행위를 식별함
- 에이전트가 없는 자산과 비관리 장비도 네트워크 관점에서 관찰함
- 동서 트래픽, C2 통신, 데이터 유출 징후 탐지에 유리함
- 미러링 위치와 대역폭 설계가 부족하면 가시성 공백이 생김

## Ⅲ. 종류 및 비교

| 판단 기준 | IDS/IPS | NDR |
|:---|:---|:---|
| 탐지 기준 | 시그니처와 정책 | 행위 분석 + 시그니처 + CTI |
| 강점 | 알려진 공격의 즉시 차단 | 암호화·은닉·측면 이동 탐지 |
| 데이터 활용 | 패킷 룰 중심 | 패킷, 플로우, 메타데이터 |
| 대표 한계 | 미지 위협 탐지 약함 | 가시성 설계와 처리 비용 부담 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Sensor or TAP | SPAN, TAP, 가상 미러링으로 트래픽을 수집하는 입력 계층으로 배치 위치가 가시성을 결정함 |
| Flow and Metadata Parser | 세션, DNS, TLS, 프로토콜 특징을 추출해 분석 가능한 상태로 만드는 정제 계층임 |
| Detection Engine | 시그니처, 통계, ML, CTI 매칭으로 이상 통신과 공격 흔적을 식별하는 분석 계층임 |
| Response Integration | 방화벽, NAC, SOAR와 연결해 세션 차단과 격리 조치를 수행하는 실행 계층임 |
| Investigation Console | 세션 재구성, 타임라인, 자산 관계를 보여줘 분석가가 사건을 추적하는 운영 계층임 |

```text
+-------------+    +----------------+    +----------------+    +----------------+
| TAP/Sensor  | -> | Parse/Metadata | -> | Detection      | -> | Response       |
+-------------+    +----------------+    +----------------+    +----------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
| 트래픽 수집    | -> | 메타데이터 추출 | -> | 이상 행위 탐지  | -> | 위험도 판정    | -> | 차단/조사      |
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
```

1. **트래픽 수집**: 네트워크 센서가 패킷과 플로우를 수집함
2. **메타데이터 추출**: 프로토콜 특성과 세션 정보를 정리함
3. **이상 행위 탐지**: C2, 스캔, 측면 이동, 유출 패턴을 식별함
4. **위험도 판정**: CTI와 자산 중요도를 결합해 우선순위를 정함
5. **차단과 조사**: 방화벽 차단이나 SOAR 연계를 수행함

## Ⅵ. 실무 적용 및 유의점

1. 데이터센터·공장망은 SPAN/TAP 위치를 먼저 설계하고 세그먼트별 가시성 커버리지·C2 탐지 시간으로 확인함
2. 암호화 트래픽 환경은 JA3/JA4 지문과 흐름 분석을 병행하고 암호화 세션 탐지율·오탐률로 확인함

## Ⅶ. 결론

- NDR은 네트워크 행위와 메타데이터로 위협을 찾는 체계이므로 가시성 확보와 센서 배치가 성능을 결정함
