## Ⅰ. 개요
- **정의**: 네트워크 트래픽을 실시간 분석하여 위협을 탐지하고 자동 대응하는 보안 솔루션임
- **배경/필요성**: 암호화 트래픽 증가로 시그니처 기반 IDS/IPS만으로는 은닉된 위협 탐지가 곤란함
- **비유**: 도로 위 차량 흐름 패턴을 분석해 수상한 이동 경로를 추적하는 교통 관제 시스템과 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 네트워크 계층 위협 탐지 원리 | 트래픽 메타데이터·페이로드 분석 병행 | IDS/IPS(시그니처) vs NDR(행동 분석) 차이 명시 필요 |

> 요약: NDR은 네트워크 트래픽 행동 분석 기반으로 암호화·은닉 위협을 탐지·대응하는 기술임

## Ⅱ. 구성요소
```text
[Network Tap/Span] --> [Traffic Analyzer] --> [Detection Engine] --> [Response]
       |                      |                      |
       v                      v                      v
   패킷미러링            메타데이터추출          ML/규칙탐지
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 트래픽 수집부 | TAP/SPAN 포트로 네트워크 패킷을 미러링 수집함 | 도청 장치 없는 통화 녹음기 |
| 분석 엔진 | 메타데이터·플로우·페이로드를 파싱하여 특징 추출함 | 통화 내용 분류기 |
| 탐지 엔진 | ML 모델과 위협 인텔리전스로 이상 트래픽 식별함 | 수상한 통화 패턴 감지기 |
| 대응 모듈 | 탐지된 위협에 대해 세션 차단·격리 명령을 실행함 | 수상 차량 검문소 |

> 요약: 패킷 미러링 -> 특징 추출 -> ML 탐지 -> 자동 대응의 4개 구성요소로 이루어짐

## Ⅲ. 절차
```text
미러링 --> 파싱 --> 탐지 --> 대응
  |         |        |        |
  v         v        v        v
TAP/SPAN  메타추출  이상판별  차단/격리
```
- 1단계: 미러링 — 스위치 SPAN 포트 또는 네트워크 TAP으로 전체 트래픽 복제함
- 2단계: 파싱 — 프로토콜별 메타데이터(IP, 포트, DNS 쿼리 등)를 추출·정규화함
- 3단계: 탐지 — 비지도 학습 기반 이상 탐지와 IOC 매칭을 병행 수행함
- 4단계: 대응 — 위협 등급에 따라 방화벽 연동 차단 또는 SOAR 플레이북 실행함

> 요약: 트래픽 복제 후 메타데이터 파싱, ML+IOC 탐지, 자동 차단/격리 순서로 동작함

## Ⅳ. 문제점
- 암호화 트래픽 가시성 한계: TLS 암호화 페이로드는 복호화 없이 내용 분석 불가함
- 대용량 처리 병목: 10Gbps 이상 환경에서 전수 패킷 분석 시 처리 지연 발생함
- 동-서 트래픽 사각지대: 동일 세그먼트 내 횡이동(Lateral Movement) 트래픽은 TAP 미경유 가능함

> 요약: 암호화 가시성, 대용량 병목, 동-서 트래픽 사각이 주요 과제임

## Ⅴ. 개선방안
1. 단기: TLS 복호화 프록시 또는 JA3/JA4 핑거프린팅으로 암호화 트래픽 분석 보완 필요
2. 중기: FPGA/GPU 가속 패킷 처리 도입으로 대용량 환경 성능 확보 필요
3. 장기: 마이크로세그멘테이션 연동으로 동-서 트래픽 가시성 확보 필요

> 요약: 복호화 보완, 하드웨어 가속, 마이크로세그멘테이션 연동으로 단계적 개선 가능함

## Ⅵ. 전망
- 발전 방향: XDR 플랫폼의 네트워크 텔레메트리 채널로 통합되는 추세임
- 기술사적 판단: 클라우드 환경 확대로 가상 TAP·클라우드 NDR 수요가 증가할 전망임
- 기술사 제언: EDR(054 참조)·SIEM(048 참조)과 통합 설계하여 탐지-대응 연계 체계를 구축해야 함
