## 미리 알고가기

- 로컬 학습은 각 단말이나 기관 내부에서 자기 데이터를 이용해 모델을 학습하는 방식임
- 모델 업데이트는 로컬 학습 뒤 중앙 서버로 보내는 가중치 변화량이나 그래디언트 정보임
- Secure Aggregation은 개별 참여자의 업데이트를 직접 보지 않고 합산 결과만 보게 하는 보호 기법임

## Ⅰ. 개요

- **정의/개념**: 연합 학습은 원본 데이터를 한곳으로 모으지 않고 각 참여 지점에서 모델을 학습한 뒤 업데이트만 모아 공동 모델을 만드는 분산 학습 방식임
- **배경/필요성**: 의료, 금융, 단말 환경에서는 데이터를 중앙으로 옮기기 어렵거나 금지되는 경우가 많아, 데이터를 움직이지 않고도 협업 학습을 수행할 대안이 필요해짐

## Ⅱ. 특징

- 원본 데이터가 로컬에 남아 있어 중앙 집중식 수집보다 노출 범위를 줄이기 좋음
- 여러 참여자의 업데이트를 합쳐 모델을 개선하므로 데이터 사일로를 넘는 협업이 가능함
- 참여자마다 데이터 분포가 달라 학습 품질이 흔들릴 수 있고 통신 비용도 큼
- 업데이트만 보낸다고 끝나지 않고 추론 공격과 모델 역추적 위험을 별도로 통제해야 함

## Ⅲ. 종류 및 비교

| 판단 기준 | 중앙집중형 학습 | 연합 학습 |
|:---|:---|:---|
| 데이터 위치 | 원본 데이터를 중앙 저장소로 모음 | 원본 데이터는 각 참여 지점에 남김 |
| 장점 | 구현이 단순하고 학습 제어가 쉬움 | 규제와 데이터 이동 제약에 더 유연함 |
| 주요 부담 | 대규모 중앙 저장이 필요함 | 통신 비용과 참여자 편차 관리가 필요함 |
| 프라이버시 관점 | 중앙 유출 시 피해가 큼 | 노출 범위는 줄지만 업데이트 공격 위험은 남음 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 중앙 조정 서버 | 초기 모델 배포와 업데이트 수집과 전역 모델 갱신을 담당하는 허브임 |
| 참여 클라이언트 | 병원, 단말, 지점 서버처럼 로컬 데이터를 보유하고 학습을 수행하는 주체임 |
| 로컬 데이터셋 | 외부로 반출하지 않는 원본 데이터로, 학습 품질의 직접 기반이 됨 |
| 모델 업데이트와 집계 | 각 참여자의 학습 결과를 모아 전역 모델로 합치는 계산 계층임 |
| 보호 기법 | Secure Aggregation, 잡음 추가, 인증 같은 수단으로 업데이트 노출을 줄이는 통제임 |

```text
+-------------+    +-------------+    +-------------+    +-------------+
| 초기 모델 배포 | -> | 로컬 학습      | -> | 업데이트 집계  | -> | 전역 모델 갱신 |
+-------------+    +-------------+    +-------------+    +-------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
| 초기화        | -> | 로컬 학습      | -> | 업데이트 전송  | -> | 집계와 반영    | -> | 다음 라운드 반복 |
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
```

1. **초기화**: 중앙 서버가 초기 모델을 참여 지점에 배포함
2. **로컬 학습**: 각 지점은 자기 데이터로 일정 라운드 동안 학습함
3. **업데이트 전송**: 원본 데이터 대신 업데이트 값만 중앙에 보냄
4. **집계와 반영**: 중앙 서버가 참여자 업데이트를 합쳐 전역 모델을 갱신함
5. **다음 라운드 반복**: 성능이 목표 수준에 도달할 때까지 과정을 반복함

## Ⅵ. 실무 적용 및 유의점

1. 병원이나 모바일 단말처럼 원본 데이터 반출이 어려운 환경은 연합 학습에 Secure Aggregation을 붙여 쓰고 모델 정확도와 라운드당 통신 시간을 함께 확인함
2. 참여자 데이터 분포가 크게 다른 환경은 업데이트만으로도 정보가 새어 나갈 수 있으므로 클리핑과 잡음 추가를 적용하고 공격 성공률과 정확도 저하율을 같이 점검함

## Ⅶ. 결론

연합 학습은 데이터를 모으지 않고 협업 학습을 가능하게 하지만 업데이트 보호와 참여자 편차 관리가 따라와야 실제 프라이버시 이점이 살아남음.
