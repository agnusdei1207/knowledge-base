## 미리 알고가기

- 위협 헌팅은 경보가 울린 뒤 조사하는 업무가 아니라 경보가 없더라도 숨어 있을 수 있는 침해를 능동적으로 찾는 활동임
- 좋은 헌팅은 가설과 데이터 소스와 검증 기준이 함께 있어야 함
- CTI와 ATT&CK과 EDR·NDR 텔레메트리가 헌팅 품질을 좌우함

## Ⅰ. 개요

- **정의/개념**: Threat Hunting은 경보가 없어도 공격자 TTP와 이상 징후를 가설로 세워 숨은 침해를 찾는 선제 탐지 활동임
- **배경/필요성**: APT와 living off the land 공격은 장기간 잠복할 수 있음. 경보 기반 관제만으로는 침해 발견이 늦을 수 있음

## Ⅱ. 특징

- 사후 분석보다 가설 기반 탐색과 증거 축적이 중심임
- IoC뿐 아니라 ATT&CK 기법, 행위 편차, 자산 중요도를 활용함
- 결과는 새 규칙, 플레이북, 가시성 보완으로 이어져야 함
- 데이터 품질과 수집 범위가 부족하면 헌팅 성과가 제한됨

## Ⅲ. 종류 및 비교

| 판단 기준 | 경보 기반 관제 | 위협 헌팅 |
|:---|:---|:---|
| 시작 조건 | 알림과 티켓 발생 | 가설과 위험 가정 수립 |
| 분석 방식 | 사건 확인과 분류 | 증거 탐색과 패턴 추적 |
| 목표 | 현재 알림 처리 | 숨은 침해 발굴과 커버리지 보완 |
| 대표 한계 | 미탐 공격은 놓침 | 데이터와 인력 요구가 큼 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Hunting Hypothesis | 어떤 자산에 어떤 공격 흔적이 있을지 정하는 가설 계층으로 CTI와 자산 위험이 출발점이 됨 |
| Telemetry Sources | EDR, NDR, 인증 로그, 프록시, 클라우드 로그처럼 증거를 제공하는 관측 계층임 |
| Analytics and Queries | 시계열 검색과 행위 상관분석과 ATT&CK 기반 질의를 수행하는 분석 계층임 |
| Validation and Triage | 찾은 후보가 실제 침해인지 오탐인지 확인하고 범위를 좁히는 검증 계층임 |
| Feedback to Detection | 헌팅 결과를 탐지 규칙과 플레이북과 데이터 수집 정책에 반영하는 개선 계층임 |

```text
+-------------+    +----------------+    +----------------+    +----------------+
| 가설 수립     | -> | 데이터 수집/질의 | -> | 후보 검증        | -> | 탐지 고도화     |
+-------------+    +----------------+    +----------------+    +----------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
| 가설 정의      | -> | 질의 실행      | -> | 이상 징후 추출   | -> | 증거 검증      | -> | 룰/플레이북 반영 |
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
```

1. **가설 정의**: 자산과 위협 정보를 바탕으로 공격 가능성을 설정함
2. **질의 실행**: 관련 텔레메트리에서 흔적을 찾는 검색과 상관분석을 수행함
3. **이상 징후 추출**: 정상 행위와 다른 패턴이나 TTP 흔적을 선별함
4. **증거 검증**: 침해 여부와 범위와 영향도를 분석함
5. **룰과 플레이북 반영**: 결과를 탐지 체계와 대응 절차에 반영함

## Ⅵ. 실무 적용 및 유의점

1. 중요 서버·관리자 계정 환경은 crown jewel과 ATT&CK 기준으로 가설을 좁히고 발견 건수·룰 전환율로 확인함
2. EDR·NDR·클라우드 로그 환경은 시간 동기화와 쿼리 템플릿을 두고 교차 상관 성공률·미확인 후보 비율로 확인함

## Ⅶ. 결론

- 위협 헌팅은 숨은 침해를 찾고 탐지 체계를 개선하는 활동이므로 가설, 텔레메트리, 결과 환류가 함께 필요함
