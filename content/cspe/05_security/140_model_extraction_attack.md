## 1. 한눈에 이해하기 (Core Intuition)
- **정의**: 회사가 수백억 원을 들여 개발한 천재 AI 모델(원본)에게 수만 번 질문을 던진 뒤, 그 질문과 AI의 답변(정답지)을 싹 다 모아서 **자신들의 빈 깡통 AI를 학습시키는 데 사용함으로써, 회사 서버를 해킹하지 않고도 원본 AI와 똑같이 생각하는 '복제인간(Clone) AI'를 공짜로 훔쳐 만들어내는 지적 재산 도둑질 공격**입니다.
- **필요성**: 챗GPT 같은 거대 AI를 처음부터 만들려면 슈퍼컴퓨터(GPU) 수만 대와 수천억 원의 전기세가 듭니다. 영악한 해커나 얌체 경쟁사들은 돈을 쓰기 싫었습니다. "우리가 빈 깡통 AI를 하나 만들고, 챗GPT한테 어려운 질문 100만 개를 던져서 나온 완벽한 모범 답안들을 그대로 베껴 적어 깡통 AI에게 달달 외우게 시키면 어떨까?" 이 꼼수가 통하면서 회사의 막대한 R&D 자산(AI 모델 자체)이 순식간에 도난당하는 위협이 생겼습니다.
- **핵심 직관**: **"족집게 일타 강사 수업 몰래 녹음해서 불법 과외 차리기"**. 
  - 상황: A학원이 수백억을 들여 족집게 일타 강사(원본 AI)를 키웠습니다.
  - **모델 추출 공격**: B학원 원장(해커)이 학생으로 위장해 일타 강사에게 수만 개의 예상 문제를 물어보고, 강사가 풀어준 완벽한 풀이 과정(API 출력값)을 전부 녹음(수집)합니다. 집에 돌아와 자기 학원의 삼류 강사(빈 깡통 모방 모델)에게 그 녹음본만 달달 외우게(학습) 시킵니다. 이제 B학원 삼류 강사도 일타 강사와 99% 똑같이 문제를 풀 수 있는 **'무료 복제판'** 이 되어버립니다.

## 2. 왜 중요한가? (Background & Value)
- **등장 배경**: MLaaS(머신러닝 서비스, API 당 과금) 비즈니스 모델이 폭발하며 기업들이 앞다투어 API를 개방했습니다. 그런데 연구자들이 단돈 10만 원어치의 API 호출 비용만으로, 구글이나 구글 파파고 수준의 번역 AI를 99% 똑같이 모방한 짝퉁 모델을 자기들 노트북에 공짜로 복제해 내는 데 성공했습니다. 해킹 코드가 아닌 정상적인 API 사용만으로 막대한 지적 재산(IP)이 털린다는 것에 업계가 경악했습니다.
- **가치**: "AI 비즈니스 붕괴 위협". 모델 추출 공격은 시스템을 파괴하거나 개인정보를 훔치지 않습니다. 대신 기업의 핵심 경쟁력인 '천재 알고리즘(가중치)'을 복제하여 경쟁사가 헐값에 똑같은 서비스를 출시하게 만듦으로써, AI R&D 투자 생태계 자체를 붕괴시킵니다.

## 3. 어떻게 작동하는가? (Mechanism)
이 공격은 기존 소프트웨어 해킹처럼 서버(방화벽)를 뚫고 들어가는 게 아닙니다.

1. **질문 폭격 (Query Generation)**
   - 해커는 타겟 AI(API)에게 던질 수만 개의 '그럴싸한 질문(입력 데이터 $X$)'을 무작위로 만듭니다.
2. **모범 답안 수집 (Label Collection)**
   - API를 통해 타겟 AI에게 질문을 던지고, AI가 친절하게 내뱉는 '정답과 확률값(출력 데이터 $Y$ 및 Confidence Score)'을 차곡차곡 엑셀에 모읍니다. 
   - 이 $(X, Y)$ 쌍의 데이터가 바로 일타 강사의 **'비밀 과외 노트'** 가 됩니다.
3. **모방 모델 훈련 (Training Surrogate Model)**
   - 해커는 인터넷에서 주워온 싸구려 빈 깡통 AI 모델(모방 모델)을 준비합니다.
   - 이 깡통 AI에게 방금 훔쳐 온 비밀 과외 노트 $(X, Y)$를 교과서 삼아 집중 훈련시킵니다.
4. **복제 완성 (Model Cloning)**
   - 훈련이 끝나면, 깡통 AI는 타겟 AI(원본)가 문제를 푸는 방식과 수학적 공식(결정 경계, Decision Boundary)을 99% 똑같이 흉내 내는 '완벽한 짝퉁 복제본'으로 재탄생합니다. 해커는 이제 API 요금을 낼 필요 없이 복제본을 공짜로 마음껏 씁니다.

## 4. 실전 활용 및 예시 (Real-world Application)
- **구체적 사례 (알파카 모델의 탄생)**: 
  - 스탠포드 대학교 연구진이 재미있는(그리고 논란이 된) 실험을 했습니다. 메타(Meta)가 공개한 깡통 모델(LLaMA)을 아주 똑똑하게 만들기 위해, 그들은 OpenAI의 **ChatGPT API에 수만 개의 질문을 던져 얻은 최고급 모범 답안 5만 개**를 긁어모았습니다. 이 답안들로 깡통 모델을 훈련시켰더니, 단돈 600달러(약 80만 원)의 비용만으로 챗GPT와 거의 맞먹는 성능을 내는 '알파카(Alpaca)' 모델을 뚝딱 복제해 냈습니다. (실제 산업계에서 가장 빈번하게 일어나는 모델 추출의 합법적(?) 변형 사례).
- **주의점 및 흔한 오해**: 
  - "우리 AI는 질문 제한(Rate Limit) 걸어놔서 100만 번 못 물어보게 막았어요!" $\rightarrow$ **해커는 더 영악합니다.** 해커들은 100만 번 묻지 않고, 수학적으로 모델의 경계선을 가장 확실하게 베낄 수 있는 아주 '뼈 때리는 소수의 킬러 질문(Active Learning 기반 쿼리)' 수백 개만 날려서도 모델을 복제해 내는 고효율 추출 기법을 사용합니다.

## 5. 핵심 비교 및 연결 개념 (Relation)
| 구분 | 모델 역전 공격 (Inversion) | 모델 추출 공격 (Extraction/Stealing) |
|---|---|---|
| **목적** | AI가 먹었던 **원재료(학습 데이터/개인정보)** 도둑질 | AI의 **뇌 구조(알고리즘 가중치/동작 방식)** 도둑질 |
| **피해 대상** | 훈련 데이터에 포함되었던 일반인(프라이버시 침해) | 수백억 들여 AI를 만든 개발 기업(지적 재산 침해) |
| **위협의 속성**| GDPR, 개인정보보호법 위반 | 지식재산권(IP) 도난, 비즈니스 경쟁력 상실 |

# ✍️ 단답형 / 서술형 시험장 출격 준비

### Ⅰ. 핵심 인사이트
- **본질**: 해커가 MLaaS(Machine Learning as a Service) 환경의 블랙박스 API에 대량의 입력값(Query)을 전송하고, 반환되는 출력값(Label, Confidence Score)의 매핑 쌍(Input-Output Pairs)을 수집하여 **타겟 모델(Target Model)과 시맨틱(Semantic) 및 결정 경계(Decision Boundary)가 거의 동일한 모방 모델(Surrogate/Substitute Model)을 로컬에 재구축(Clone)하는 지적 재산(IP) 탈취 공격.**
- **가치**: 인공지능 모델 훈련에 소요되는 천문학적인 컴퓨팅 자원(GPU 비용)과 고품질 데이터 수집(Data Labeling) 비용을 무임승차(Free-riding)하여 탈취함. 한 번 복제에 성공한 모방 모델은 화이트박스(White-box) 상태가 되므로, 이후 적대적 회피 공격(Adversarial Evasion)을 무한대로 테스트하여 **원본 AI를 뚫을 수 있는 무기 창고**로 2차 악용되는 치명적 파급력을 지님.
- **판단 포인트**: IT 인프라 보안으로 이 공격을 막는 것은 불가능합니다. 공격 트래픽 자체는 "정상적인 API 고객의 요금 지불(Pay-per-use) 호출"과 포맷이 100% 동일하기 때문입니다. 방어를 위해서는 WAF 레벨의 속도 제한(Rate Limiting)뿐만 아니라, **출력의 확률값 마스킹(Rounding)** 및 **워터마크 삽입**과 같은 알고리즘 내재적(Intrinsic) 방어 계층이 융합 설계되어야 합니다.

### Ⅱ. 모델 추출(Stealing) 공격의 3대 수학적 쿼리 기법
공격자는 무식한 무차별 대입(Brute-force) 대신 고도의 수학적 샘플링을 사용함.
1. **능동적 학습 (Active Learning) 기반 쿼리**
   - 모델의 결정 경계(Decision Boundary, 예: 고양이와 개를 구분하는 수학적 선) 근처에 있는 아슬아슬한 데이터만 집중적으로 질문함. 가장 적은 쿼리 횟수(예: 10만 번 대신 1,000번)만으로도 모델의 핵심 분기점을 정확하게 베껴낼 수 있는 고효율 공격.
2. **랜덤 노이즈 / 비분포(OOD) 데이터 쿼리**
   - 완전히 의미 없는 노이즈나 가짜 쓰레기 데이터를 입력하여, 모델이 어떻게 거절하거나 반응하는지(분류 공간의 여백)를 파악해 모방 모델의 수학적 공간을 정밀하게 다듬음.
3. **지식 증류 (Knowledge Distillation) 응용**
   - 거대 LLM(Teacher Model)의 우수한 추론 능력(출력 텍스트)을 로컬의 소형 깡통 모델(Student Model)에 지도 학습(Supervised Learning)시켜 그대로 주입하는 전이 학습(Transfer Learning)의 해킹적 활용.

### Ⅲ. 공격 성공 시 발생하는 치명적 연쇄 위협 (Chain Reaction)
- **IP 도난 및 경제적 손실**: 모델 개발자의 R&D 투자 회수 불가. 경쟁사의 저가 덤핑 서비스(카피캣) 출현.
- **화이트박스 화(White-boxification)**: 
  - 원래 타겟 AI는 밖에서 내부를 볼 수 없는 블랙박스(Black-box)였으나, 해커가 이를 모방하여 복제한 모델은 해커 노트북에 있는 화이트박스임.
  - 해커는 복제 모델을 상대로 '적대적 노이즈(Adversarial Perturbation)'를 수백만 번 공짜로 만들어 본 뒤, 가장 강력한 노이즈를 찾아내어 진짜 타겟 AI에게 날림 (전이성, Transferability 폭발).

### Ⅳ. 아키텍처적 방어 및 완화(Mitigation) 전략
기계 학습 API 배포 시 고려해야 할 3겹의 방어선.
1. **API 반환 정보의 축소 및 마스킹 (Information Hiding)**
   - 가장 직관적인 방어. 모델이 계산한 `신뢰도 확률(Confidence Score: 99.87%)`을 그대로 반환하지 마라.
   - 조치: 소수점 반올림(Rounding)을 하거나, 아예 확률을 숨기고 가장 높은 순위의 결과 라벨("고양이")만 반환하여 해커가 최적화 계산(경사 하강법)을 할 수 있는 수학적 힌트(Gradient)를 원천 차단.
2. **워터마킹 및 침해 증거(Provenance) 식별**
   - 해커가 모방 모델을 만들어 팔 때, 법적으로 "이거 우리 모델 베낀 거다!"라고 증명할 수단.
   - 학습 시 특정 엉뚱한 입력(예: "XYZ123")을 넣으면 무조건 "Apple"이라고 뜬금없는 대답을 하도록 고의적인 백도어(Watermark)를 심어둠. 해커의 짝퉁 모델도 이 멍청한 대답을 똑같이 흉내 내므로 표절을 100% 입증 가능.
3. **패턴 기반 이상 탐지 (Stateful Query Analysis)**
   - WAF와 연동하여, 동일 사용자가 능동적 학습(Active Learning)에서 자주 보이는 "미세하게 변형된 이미지"를 연속적으로 수백 번 쿼리하는 '비정상 분포 탐색 패턴'을 상태 기반(Stateful)으로 탐지하여 세션 차단.

### Ⅴ. 결론 및 실무적 판단 포인트
- MLaaS 플랫폼(API 비즈니스)을 설계하는 CISO는 모델 추출 공격에 대한 "결정론적 방어(100% 차단)는 불가능하다"는 현실을 직시해야 합니다. 공격과 정상 사용을 구분하는 경계가 모호하기 때문입니다. 비즈니스 리스크를 낮추기 위해 **API 응답의 디테일을 최소화(Rounding)** 하고 과금 정책 체계를 촘촘히 쪼개 공격자의 **추출 비용(Extraction Cost)을 기하급수적으로 높여 공격의 경제적 동기를 꺾는 방어 전략(Deterrence)** 이 최우선 설계 지침입니다.

### 💡 문제 유형별 목차 전환 포인트
- **[인공지능(AI) 모델의 지적 재산(IP) 탈취 위협(OWASP) 및 방어 아키텍처]**: Ⅰ번과 Ⅱ번(능동적 쿼리 및 지식 증류 악용)을 중심으로 서술. 화이트박스 침투 없이 블랙박스 API 질의(Query) 패턴만으로 결정 경계를 복제하는 수학적 메커니즘 증명.
- **[안전한 머신러닝 API 서비스 구축(MLOps) 및 신뢰할 수 있는 AI 방어 전략]**: Ⅲ번(화이트박스화로 인한 회피 공격 연계 위험)을 경고한 뒤, Ⅳ번의 정보 마스킹(Rounding) 및 워터마킹 삽입 기술을 컴플라이언스(저작권 입증)와 기술적 방패의 융합 방안으로 제시.
