## 미리 알고가기

- 대리 모델은 원본 모델의 입력과 출력을 흉내 내도록 따로 학습한 복제 모델임
- 입력-출력 쌍은 질의한 데이터와 그에 대한 모델 응답을 묶은 학습 표본임
- 레이트 리미팅은 짧은 시간 안에 지나치게 많은 호출이 들어오지 못하게 막는 제어 방식임

## Ⅰ. 개요

- **정의/개념**: 모델 추출 공격은 공개 예측 API를 반복 호출해 입력-출력 쌍을 모으고 원본과 비슷하게 동작하는 대리 모델을 만드는 공격임
- **배경/필요성**: 모델 개발에는 데이터 수집, 학습 비용, 튜닝 노하우가 들어감. API는 이 결과를 계속 노출하므로 모델도 지적 자산으로 보호해야 함

## Ⅱ. 특징

- 모델 파일을 직접 빼내지 않아도 기능 복제가 가능함
- 출력이 자세하고 호출 제한이 느슨할수록 공격 효율이 높아짐
- 복제 모델은 비용 회피뿐 아니라 적대적 예제 생성 같은 후속 공격에도 쓰일 수 있음
- 개인정보보다 모델 행위와 성능 탈취에 더 초점이 맞춰짐

## Ⅲ. 종류 및 비교

| 판단 기준 | 모델 역전 공격 | 모델 추출 공격 |
|:---|:---|:---|
| 노리는 대상 | 학습 데이터의 민감 정보 | 모델의 예측 기능과 성능 |
| 대표 산출물 | 복원된 속성이나 표본 | 대리 모델과 복제 서비스 |
| 주된 수단 | 점수 최적화와 재구성 | 입력-출력 쌍 대량 수집과 재학습 |
| 주된 피해 | 프라이버시 침해 | 지적 자산 탈취와 후속 공격 지원 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 원본 예측 API | 공격자가 반복 호출하는 외부 인터페이스임 |
| 질의 생성기 | 다양한 입력을 만들어 응답을 수집함 |
| 응답 저장소 | 입력-출력 쌍을 학습 데이터처럼 모아 둠 |
| 대리 모델 학습기 | 수집한 응답을 바탕으로 복제 모델을 학습함 |
| 탐지·통제 계층 | 비정상 호출 패턴과 응답 남용을 제한함 |

```text
질의 생성기 -> 원본 예측 API -> 응답 저장소 -> 대리 모델 학습기 -> 복제 모델
```

## Ⅴ. 원리 및 절차 흐름도

```text
반복 질의 -> 입력-출력 수집 -> 대리 모델 학습 -> 원본과 비교 -> 복제 모델 고도화
```

1. **반복 질의**: 공격자가 다양한 입력을 준비해 API를 계속 호출함
2. **입력-출력 수집**: 응답 라벨과 점수와 설명을 함께 저장함
3. **대리 모델 학습**: 수집한 결과를 정답처럼 써서 새 모델을 학습함
4. **원본과 비교**: 원본 응답과 얼마나 비슷한지 확인함
5. **복제 모델 고도화**: 부족한 구간을 다시 질의해 성능을 끌어올림

## Ⅵ. 실무 적용 및 유의점

1. 공개 추론 API는 응답 정밀도와 호출 속도를 함께 제한하고 비정상 질의 군집을 탐지하며 호출 집중도와 재현 정확도로 점검함
2. 고가치 모델은 출력 워터마킹이나 미끼 질의 세트로 복제 여부를 추적하고 의심 사용자별 대량 호출 수로 확인함

## Ⅶ. 결론

- 모델 추출 공격은 API가 곧 지적 자산 노출면이 되는 문제이므로 정확한 응답 제공과 호출 통제 사이의 경계를 설계해야 함
