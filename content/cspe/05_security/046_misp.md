## 미리 알고가기

- MISP는 위협 인텔리전스를 수집·분류·상관분석·배포하는 오픈소스 플랫폼임
- STIX/TAXII가 표준이라면 MISP는 이를 활용해 운영하는 공유 플랫폼 중 하나임
- 가치의 핵심은 데이터 양보다 상관분석과 분류 체계와 조직 간 신뢰 정책에 있음

## Ⅰ. 개요

- **정의/개념**: MISP는 IoC, TTP, 악성코드, 위협 그룹 정보를 이벤트·속성 단위로 관리하고 API로 배포하는 CTI 공유 플랫폼임
- **배경/필요성**: 위협 정보가 메일·문서·엑셀로 흩어지면 중복과 지연이 커짐. 구조화 저장과 상관분석·자동 배포가 필요함

## Ⅱ. 특징

- 이벤트, 속성, 객체 구조로 위협 정보를 재사용 가능하게 관리함
- 자동 상관분석으로 과거 사건과 현재 지표의 연결성을 찾음
- TLP, taxonomy, galaxy로 공유 범위와 위협 맥락을 함께 관리함
- 저품질 IoC가 대량 유입되면 오탐과 룰 폭증이 발생함

## Ⅲ. 종류 및 비교

| 판단 기준 | 수동 IoC 공유 | MISP |
|:---|:---|:---|
| 저장 방식 | 문서와 메일 중심 | 이벤트·속성 구조 저장 |
| 상관분석 | 사람 수작업 | 자동 상관분석 가능 |
| 배포 속도 | 지연이 큼 | API와 feed로 자동 배포 가능 |
| 대표 한계 | 중복과 누락이 많음 | 데이터 품질과 거버넌스 관리 필요 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Event | 특정 침해사고나 캠페인을 묶는 기본 단위로 여러 속성과 객체를 담는 컨테이너 역할을 함 |
| Attribute and Object | IP, 도메인, 해시 같은 속성과 이를 묶은 객체 구조로 탐지 시스템이 활용할 실질 데이터를 제공함 |
| Taxonomy and Galaxy | TLP, 신뢰도, 위협 그룹, ATT&CK 맥락을 부여해 분석과 공유 우선순위를 정하는 분류 계층임 |
| Correlation Engine | 속성 일치와 관계를 자동 분석해 사건 간 연결고리를 찾는 분석 계층임 |
| Feed and API | 외부 공유와 내부 보안 장비 연동을 수행해 CTI를 룰과 플레이북으로 배포하는 실행 계층임 |

```text
+-------------+    +----------------+    +----------------+    +----------------+
| Event       | -> | Attribute/Object| -> | Correlation    | -> | Feed/API       |
+-------------+    +----------------+    +----------------+    +----------------+
        |
        v
+----------------+
| Taxonomy/Galaxy|
+----------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
| 이벤트 등록    | -> | 속성/분류 추가  | -> | 상관분석 수행   | -> | 공유 정책 적용  | -> | 장비 배포      |
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
```

1. **이벤트 등록**: 조직이 침해사고나 위협 정보를 이벤트로 생성함
2. **속성과 분류 추가**: IoC와 객체와 TLP와 태그를 부여함
3. **상관분석 수행**: 기존 이벤트와 중복 속성과 연관 관계를 찾음
4. **공유 정책 적용**: 대상 조직과 접근 수준을 정해 동기화함
5. **장비 배포**: API나 export로 SIEM, IDS, SOAR 등에 반영함

## Ⅵ. 실무 적용 및 유의점

1. 금융권·그룹사 공유는 taxonomy와 TLP 정책을 먼저 정하고 상관분석 적중률·피드 반영 성공률·오탐 IoC 비율로 확인함
2. SOC·방화벽·IDS 연계는 평판 점수와 자산 관련성으로 선별하고 활성 룰 사용률·미사용 속성 비율로 확인함

## Ⅶ. 결론

- MISP는 CTI 저장소가 아니라 상관분석과 공유 거버넌스로 위협 정보를 운영 가능한 지식으로 바꾸는 플랫폼임
