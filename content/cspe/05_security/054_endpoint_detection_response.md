## 미리 알고가기

- EDR은 단말 내부의 프로세스, 파일, 레지스트리, 네트워크 행위를 수집해 이상 징후를 찾는 체계임
- 전통적 AV가 알려진 악성 파일 탐지에 강하다면 EDR은 행위 기반 탐지와 원격 격리에 강함
- 원격 근무와 서버 운영이 늘수록 단말 가시성과 대응 속도가 중요해짐

## Ⅰ. 개요

- **정의/개념**: EDR은 엔드포인트 에이전트가 프로세스 실행, 파일 변경, 레지스트리 조작, 네트워크 연결 같은 행위를 실시간 수집하고 중앙 분석을 통해 위협을 탐지·격리·복구하는 보안 체계임
- **배경/필요성**: 파일리스 공격과 정상 도구 악용과 제로데이 침해는 시그니처 백신만으로 식별하기 어려워 단말 내부 행위 관측과 신속한 원격 대응이 필요함

## Ⅱ. 특징

- 단말 내부 프로세스와 명령행과 파일 변경 기록을 세밀하게 수집할 수 있음
- 탐지 후 네트워크 격리, 프로세스 종료, 파일 격리 같은 즉시 조치가 가능함
- 포렌식 타임라인을 제공해 침해 원인과 범위를 빠르게 재구성할 수 있음
- 에이전트 성능 부담과 우회 시도와 오프라인 단말 공백을 고려하지 않으면 운영 품질이 흔들릴 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | 전통적 AV | EDR |
|:---|:---|:---|
| 탐지 기준 | 시그니처 중심 | 행위 + IOC + 분석 |
| 수집 범위 | 파일 검사 중심 | 프로세스·레지스트리·네트워크 텔레메트리 |
| 대응 기능 | 차단과 치료 중심 | 격리, 종료, 조사, 복구 |
| 대표 한계 | 신종 공격 탐지 약함 | 에이전트 운영 부담 존재 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Endpoint Agent | 단말에서 이벤트를 수집하고 일부 조치를 실행하는 입력·실행 계층으로 안정성이 중요함 |
| Telemetry Pipeline | 수집한 이벤트를 중앙 서버로 보내고 저장하는 데이터 전송 계층임 |
| Detection Analytics | IOC, 행위 규칙, ATT&CK 매핑, ML을 적용해 위협 여부를 판별하는 분석 계층임 |
| Response Control | 단말 격리, 프로세스 종료, 파일 차단, 스크립트 실행을 수행하는 대응 계층임 |
| Investigation Console | 타임라인과 증거와 자산 상태를 제공해 분석가가 사건을 조사하는 운영 계층임 |

```text
+---------------+    +----------------+    +----------------+    +----------------+
| Agent         | -> | Telemetry      | -> | Detection      | -> | Response/IR    |
+---------------+    +----------------+    +----------------+    +----------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
| 행위 수집      | -> | 중앙 전송      | -> | 위협 판별      | -> | 단말 조치      | -> | 조사/복구      |
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
```

1. **행위 수집**: 에이전트가 프로세스와 파일과 네트워크 이벤트를 기록함
2. **중앙 전송**: 텔레메트리를 중앙 분석 플랫폼으로 전송함
3. **위협 판별**: IOC와 행위 규칙과 모델을 결합해 악성 여부를 판단함
4. **단말 조치**: 격리, 종료, 차단, 삭제 같은 조치를 수행함
5. **조사와 복구**: 침해 범위를 분석하고 정상 상태로 복구함

## Ⅵ. 실무 적용 및 유의점

1. 원격 근무와 노트북 중심 조직은 EDR이 초기 침해와 측면 이동 징후를 빠르게 찾는 데 유리하지만 에이전트 과부하와 오탐 차단이 업무를 멈출 수 있으므로 경량 정책과 승인 기준을 함께 두고 에이전트 정상 동작률과 격리 오조치율과 MTTD를 확인함
2. 서버와 중요 단말은 EDR 포렌식 가치가 크지만 오프라인 상태나 우회 시도에 취약할 수 있으므로 로컬 버퍼링과 무결성 보호와 NDR 연계를 병행하고 미수집 단말 비율과 우회 탐지 건수로 확인함

## Ⅶ. 결론

- EDR은 악성 파일 탐지 도구가 아니라 단말 행위를 지속 관찰하고 즉시 격리하는 체계이므로 가시성 확보와 에이전트 운영 안정성이 핵심임
