## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | CSPM·CWPP·CIEM·IaC 스캔 등 클라우드 보안 기능을 단일 플랫폼으로 통합하여 빌드→배포→런타임 전 단계를 보호하는 통합 보안 플랫폼임 |
| **배경/필요성** | 개별 포인트 솔루션(CSPM·CWPP·CIEM)의 사일로화로 인해 컨텍스트 연계가 부족하며, 통합 가시성·상관 분석이 필요함 |
| **출제 의도** | CNAPP의 통합 범위와 개별 솔루션(CSPM·CWPP·CIEM) 대비 장점을 이해하는지 평가함 |

## Ⅱ. 구성요소
```
+----------+     +----------+     +----------+
|  CSPM    | --> |  CWPP    | --> |  CIEM    |
| (설정)   |     | (워크로드)|     | (권한)   |
+----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| CSPM | 클라우드 인프라 설정 오류를 탐지·교정함 | 건물 안전 점검 |
| CWPP | 워크로드 취약점·런타임 위협을 탐지·방어함 | 사무실 내부 경비 |
| CIEM | 클라우드 IAM의 과도한 권한을 탐지·최적화함 | 출입 권한 감사 |

> 요약: CSPM(설정) + CWPP(워크로드) + CIEM(권한)을 단일 플랫폼으로 통합하여 전체 클라우드를 보호함.

## Ⅲ. 절차
```
+------------+     +------------+
| IaC스캔    | --> | 빌드시     |
| (Shift-Left)|   | 이미지스캔  |
+------------+     +------------+
                        |
+------------+     +----+-------+
| 통합대시보드| <-- | 런타임    |
| 상관분석   |     | 설정+위협  |
+------------+     +------------+
```

1. IaC 스캔: Terraform·CloudFormation 코드를 배포 전 스캔하여 오설정을 사전 차단함
2. 빌드 시 이미지 스캔: CI/CD에서 컨테이너 이미지의 CVE·민감 정보를 스캔함
3. 런타임 통합 모니터링: CSPM(설정) + CWPP(행위) + CIEM(권한)을 실시간 모니터링함
4. 통합 상관 분석: 설정 오류·과도 권한·런타임 위협을 상관 분석하여 공격 경로(Attack Path)를 가시화함

> 요약: Shift-Left(빌드) → 런타임 모니터링 → 상관 분석으로 전 단계 통합 보호를 수행함.

## Ⅳ. 문제점
- 벤더 종속: 단일 CNAPP 벤더에 모든 클라우드 보안을 의존하면 벤더 Lock-in이 발생함
- 통합 복잡성: 기존 CSPM·CWPP·CIEM 포인트 솔루션에서 CNAPP으로 마이그레이션이 복잡함
- 멀티 클라우드 커버리지: 모든 CSP(AWS·Azure·GCP)를 균일하게 지원하는 CNAPP이 제한적임

## Ⅴ. 개선방안
- (단기) 점진적 통합: 기존 포인트 솔루션을 유지하면서 CNAPP을 단계적으로 도입함
- (중기) 멀티 클라우드 정규화: CSP 간 리소스 모델을 통합 정규화하는 CNAPP을 선택함
- (장기) 오픈 표준 연동: OpenTelemetry·STIX 등 개방 표준으로 벤더 종속을 줄임

## Ⅵ. 전망
- Gartner 예측에 따라 2025년까지 클라우드 보안 도입의 75%가 CNAPP으로 통합되며, AI 기반 공격 경로 분석이 차세대 CNAPP의 핵심 차별화 요소가 될 전망임
