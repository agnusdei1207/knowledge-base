## 미리 알고가기

- 스푸핑은 식별 정보나 응답 정보를 위조해 통신 상대를 속이는 공격임
- ARP는 같은 LAN의 IP와 MAC 대응, DNS는 도메인과 IP 대응, IP 스푸핑은 출발지 주소 위조와 관련됨
- 스푸핑은 단독 피해보다 중간자 공격, 세션 탈취, 반사 증폭 공격의 전단계로 자주 사용됨

## Ⅰ. 개요

- **정의/개념**: 네트워크 스푸핑은 주소나 응답 정보를 위조해 트래픽을 우회시키거나 잘못된 목적지로 보내는 공격임
- **배경/필요성**: TCP/IP 계열 프로토콜은 주소와 응답 진위 검증이 약한 구간이 있음. 통신 경로와 이름 해석 보호가 필요함

## Ⅱ. 특징

- 도청, 세션 하이재킹, 피싱, 반사 증폭의 전단계가 됨
- LAN은 ARP, 외부망은 IP, 이름 해석은 DNS 위조가 핵심임
- 암호화가 없는 구간은 트래픽 탈취와 변조에 취약함
- 스위치, 라우터, DNS, 종단 암호화를 계층별로 통제해야 함

## Ⅲ. 종류 및 비교

| 판단 기준 | ARP 스푸핑 | IP 스푸핑 | DNS 스푸핑 |
|:---|:---|:---|:---|
| 공격 계층 | L2 인접 구간 | L3 네트워크 구간 | 이름 해석 구간 |
| 주 대상 | 동일 LAN 단말과 게이트웨이 | ACL 우회, 반사 서버, 세션 | 리졸버와 사용자 |
| 주요 피해 | 중간자 공격과 도청 | 신뢰 기반 필터 우회, DRDoS | 피싱 사이트 유도, 잘못된 연결 |
| 핵심 방어 | DAI, 정적 ARP, 포트 보안 | uRPF, ingress filtering | DNSSEC, 캐시 보호, 인증된 DNS |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Spoofed Identity | 공격자가 위조하는 MAC, IP, DNS 응답 같은 식별 정보로 신뢰 경계를 속이는 출발점임 |
| Victim Cache or Session | ARP 캐시, 라우팅 판단, DNS 캐시처럼 한 번 잘못 학습되면 이후 통신이 지속적으로 오염되는 상태 계층임 |
| Relay or Fake Endpoint | 공격자가 트래픽을 중계하거나 가짜 서버로 유도해 정보 탈취와 세션 장악을 수행하는 실행 계층임 |
| Network Control | 스위치의 DAI, 라우터의 uRPF, DNSSEC 같은 검증 장치로 위조 정보를 걸러내는 통제 계층임 |

```text
+-------------+    +------------------+    +----------------+    +----------------+
| 위조 정보 생성 | -> | 캐시/세션 오염      | -> | 트래픽 우회/유도  | -> | 도청/우회/마비  |
+-------------+    +------------------+    +----------------+    +----------------+
         |
         v
+----------------+
| 계층별 검증 통제 |
+----------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
| 대상 식별      | -> | 위조 패킷 전송  | -> | 캐시/응답 오염  | -> | 트래픽 재유도   | -> | 공격 수행      |
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
```

1. **대상 식별**: 공격자가 게이트웨이, 신뢰 IP, 리졸버 같은 목표를 파악함
2. **위조 패킷 전송**: ARP Reply, 위조 출발지 IP, 가짜 DNS 응답을 보냄
3. **캐시와 응답 오염**: 피해자가 잘못된 주소 대응 정보를 학습함
4. **트래픽 재유도**: 정상 통신이 공격자 경유 또는 가짜 목적지로 이동함
5. **공격 수행**: 도청, 세션 탈취, 피싱, 반사 증폭 같은 후속 공격을 실행함

## Ⅵ. 실무 적용 및 유의점

1. 사내 LAN은 DAI·DHCP Snooping·정적 ARP를 적용하고 ARP 위변조 탐지·게이트웨이 MAC 변경률로 확인함
2. 공개 서비스와 DNS 구간은 uRPF·ingress filtering·DNSSEC를 적용하고 출발지 위조 차단율·DNS 검증 실패율로 확인함

## Ⅶ. 결론

- 네트워크 스푸핑은 주소 신뢰를 악용하는 기반 공격이므로 계층별 검증 통제와 종단 암호화를 함께 설계해야 함
