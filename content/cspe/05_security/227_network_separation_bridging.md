## 1. 한눈에 이해하기 (Core Intuition)
- **정의**: 외부 인터넷망과 핵심 기밀이 위치한 내부 업무망을 물리적 혹은 논리적으로 단절(망분리)하여 외부 위협의 침투를 차단하고, 분리된 망 사이의 필수적인 데이터 교환은 엄격한 보안 통제가 적용된 게이트웨이(망연계)를 거치도록 하는 폐쇄형 네트워크 보안 아키텍처입니다.
- **필요성**: 직원 PC가 랜섬웨어에 감염되었을 때, 인터넷망과 원장망(핵심 DB)이 연결되어 있으면 조직 전체가 마비됩니다. 이를 원천 차단하기 위해 네트워크의 '에어갭(Air-gap)'을 구성해야 합니다.
- **핵심 직관**: **"거대한 성벽(망분리)과 무균 쪽문(망연계)"** - 전염병(해킹)을 막기 위해 성벽을 쌓아 내부와 외부를 완전히 단절시키되, 꼭 필요한 식량(업무 데이터)은 바이러스 검사기(백신, CDR)가 설치된 쪽문을 통해서만 조심스럽게 들여오는 구조입니다.

## 2. 깊이 이해하기 (In-Depth Comprehension)
- **배경**: 2013년 3.20 사이버 테러로 대규모 금융 전산망 마비 사태가 발생하자, 정부는 정보통신망법과 전자금융감독규정을 통해 공공기관 및 금융권의 망분리를 의무화했습니다.
- **작동 원리 및 유형**:
  - **물리적 망분리**: PC 2대와 랜선 2개를 사용하여 아예 물리적인 연결을 없앱니다. 보안성은 최상이지만 구축 비용과 전력 낭비가 큽니다.
  - **논리적 망분리 (SBC/VDI)**: PC는 1대만 쓰되, 서버실의 가상 데스크톱(VDI)에 원격 접속하여 업무(혹은 인터넷) 화면만 스트리밍받습니다.
  - **논리적 망분리 (CBC)**: PC 1대 내부에 가상화 엔진(Hypervisor)을 구동하여 인터넷용 영역과 업무용 영역을 분리합니다.
  - **망연계 (Network Bridging)**: 분리된 망 간의 자료 전송을 위해 중계 서버를 둡니다. 두 망은 직접 세션을 맺지 못하고(에어갭 유지), 중계 서버가 백신 검사 및 악성 매크로 제거(CDR) 후 파일을 복사해 줍니다.
- **비유**: 생물학 실험실(내부망)과 일반 복도(외부망). 두 공간은 밀폐되어 있지만, 필수 시료는 '에어락(Air-lock)' 챔버(망연계)를 거쳐 소독 후 전달됩니다.
- **구체 예시**: 원자력 발전소와 같은 극비 OT 망에서는 망연계 서버조차 위험할 수 있어, 물리적으로 수신(RX) 광모듈을 꺾어버리고 송신(TX)만 가능하게 만든 **단방향 데이터 다이오드(Data Diode)** 장비를 사용합니다.
- **흔한 오해/주의점**: "망분리만 하면 100% 안전하다"는 큰 착각입니다. 해커는 성벽을 직접 넘지 않고, 유일한 연결 통로인 망연계 서버의 취약점을 공략하거나, 직원이 몰래 반입한 외장하드(망 혼용)를 통해 에어갭을 파괴합니다.

## 3. 연결 개념 (Related Concepts)
- **CDR (Content Disarm & Reconstruction)**: 망연계 구간에서 문서 파일의 유해 요소(매크로, 스크립트)를 완전히 제거하고 뼈대만 재조립하는 무해화 기술.
- **Zero Trust Architecture (ZTA)**: 최근 클라우드 시대에 망분리의 경직성을 극복하기 위해, '물리적 망' 대신 'ID와 디바이스 상태'를 기준으로 접근을 통제하는 차세대 패러다임.
- **VDI (Virtual Desktop Infrastructure)**: 논리적 망분리를 구현하는 핵심 인프라 가상화 기술.

# ✍️ 답안용 골격 (Exam Preparation)

### Ⅰ. 핵심 인사이트
- **본질**: 대외 서비스(인터넷망)와 핵심 자산(내부 업무망) 간의 네트워크 세그멘테이션(Network Segmentation)을 통해 공격의 횡적 이동(Lateral Movement)을 물리적/논리적으로 차단하고, 무해화(CDR) 프록시를 통해 제한적 통신만 허용하는 사이버 레질리언스(Resilience) 아키텍처.
- **가치**: 컴플라이언스(전자금융감독규정, ISMS-P)를 준수하는 가장 원초적이고 강력한 방어선이나, 클라우드 네이티브(SaaS) 도입과 원격 근무 확산을 가로막는 딜레마(Friction)를 안고 있음.
- **판단 포인트**: IT 보안 설계자는 최신 당국의 '망분리 규제 완화' 기조를 반영하여, 맹목적인 에어갭(Air-gap) 정책에서 벗어나 데이터 중심 보안(Data-Centric Security) 및 제로 트러스트(ZTA)를 결합한 하이브리드 아키텍처로 진화해야 함.

### Ⅱ. 논리적 망분리 아키텍처 비교 (SBC vs CBC)
```text
┌─────────────────────────────────────────────────────────────┐
│                 [ Logical Network Separation ]              │
├───────────────┬──────────────────────┬──────────────────────┤
│ 구분          │ SBC (서버 기반 가상화, VDI) │ CBC (클라이언트 기반 가상화)│
├───────────────┼──────────────────────┼──────────────────────┤
│ 작동 위치     │ 중앙 서버 (하이퍼바이저) │ 로컬 PC (클라이언트)        │
│ 데이터 저장   │ 서버 스토리지 (로컬 저장 X)│ 로컬 PC 내부 가상 디스크    │
│ 보안성        │ 기밀성 최상 (데이터 유출 방지)│ 상 (VM Escape 취약점 존재)  │
│ 초기 비용     │ 매우 높음 (대규모 서버 팜) │ 낮음 (PC 자원 재활용)       │
│ 성능 (사용성) │ 네트워크 지연 시 체감 속도 저하│ 로컬 CPU 활용으로 매우 빠름 │
└───────────────┴──────────────────────┴──────────────────────┘
```

### Ⅲ. 망연계 시스템 (Network Bridging) 아키텍처
단절된 망 사이의 유일한 안전 터널(Air-lock)
1. **망연계 시스템 구성 요소**
   - **중계 서버 (Relay Server)**: 내부망과 외부망은 직접 TCP 연결을 맺지 않고, 공유 스토리지나 IEEE 1394 케이블을 통해 중계 서버와 간접 통신.
   - **파일 연계 (File Transfer)**: 내부/외부 간 승인된 사용자만 파일을 송수신하며, 백신 3중 검사 등을 수행.
   - **스트림 연계 (Stream Transfer)**: 특정 서버 간(예: DB 동기화) 제한된 포트/IP 기반의 실시간 TCP 세션 프록시 역할 수행.
2. **핵심 보안 통제: 무해화 기술 (CDR)**
   - 백신(Signature) 기반 탐지의 한계를 극복하기 위해, 인터넷에서 유입되는 파일(PDF, HWP) 내부의 액티브 콘텐츠(매크로, 자바스크립트 등)를 강제 제거하고 텍스트/이미지만 추출하여 새 파일로 재조합(Reconstruction)하는 기술.

### Ⅳ. 최신 트렌드: 망분리 완화와 제로 트러스트(ZTA) 패러다임
- **망분리의 한계**: 퍼블릭 클라우드, GitHub 연동, SaaS(M365) 사용 불가로 인한 개발 생산성 저하.
- **규제 완화 로드맵**: 금융당국은 개발/테스트망의 망분리를 일부 완화하고, 퍼블릭 클라우드 SaaS 이용을 예외적으로 허용하는 대신, 제로 트러스트 및 SDP(소프트웨어 정의 경계) 도입을 대체 통제 수단으로 의무화하는 방향으로 선회 중.

### Ⅴ. 결론 및 실무적 판단 포인트
- 망분리의 완성은 단순히 스위치 포트를 나누는 것에 그치지 않고, **'망연계 구간(Gateway)의 하드닝(Hardening)'** 에 있습니다.
- 아키텍트는 망연계 서버가 단일 장애점(SPOF)이나 해커의 우회 통로가 되지 않도록, OT 망과 같은 초민감 영역에는 단방향 통신 장비(Data Diode)를 박아넣고, 범용망 연계 구간에는 다중 백신과 CDR을 적용하는 종심 방어(Defense-in-Depth) 전략을 수립해야 합니다.

### 💡 문제 유형별 목차 전환 포인트
- **[컴플라이언스 기반 망분리/망연계 기술 비교 및 도입 전략]**: Ⅰ과 Ⅱ(SBC/CBC 비교)를 전면에 세워, 랜섬웨어 방어라는 목표와 기업의 IT 예산 사이의 트레이드오프(Cost vs Security) 조율 방안 서술.
- **[제로 트러스트 기반 업무 환경 전환과 망분리 규제 완화 대응 방안]**: Ⅲ(망연계)과 Ⅳ(ZTA 패러다임 변화)를 강조하여, 물리적 에어갭 중심의 구시대적 통제에서 데이터 중심 보안 및 신원 기반 통제(SDP/SASE)로 마이그레이션하는 차세대 아키텍처 설계 방안 전개.
