# 📖 【암기용】 개념 완전 이해

> 목적: 망분리와 망연계를 처음 보는 사람도 업무망, 인터넷망, 연계구간의 역할을 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 망분리는 보안수준이 다른 네트워크를 분리하고, 망연계는 통제된 경로로 필요한 자료만 전달하는 체계다.
- **왜 필요한가**: 인터넷 침해가 내부 업무망으로 곧바로 이동하면 개인정보, 행정자료, 핵심기술이 동시에 노출된다. 분리는 공격면을 줄이고, 연계는 업무 연속성을 유지한다.
- **핵심 직관**: 병원 수술실 출입구를 따로 두되, 멸균 절차를 거친 도구만 전달창으로 넘기는 구조다.

## 깊이 이해
- **배경·문제의식**: 공공·금융 환경은 내부망이 외부 인터넷과 직접 연결될 때 악성코드, 자료유출, 원격제어 피해가 커진다. 물리 망분리는 PC와 회선을 분리하고, 논리 망분리는 VDI, 가상화, NAC, 보안브라우저로 경계를 만든다.
- **작동 원리**: 업무망과 인터넷망 사이 직접 통신을 막고, 자료전송 서버, 보안 게이트웨이, 단방향 전송장비, 악성코드 검사, DLP, 승인 워크플로, 감사로그를 거쳐 파일과 메시지만 전달한다.
- **비유**: 서로 다른 연구실 사이에 사람이 마음대로 오가지 못하게 하고, 시료는 검사대와 기록대에서 확인한 뒤 전달하는 방식이다.
- **구체 예시**: 내부망 사용자가 외부자료를 반입하면 망연계 구간에서 확장자 허용목록, 백신 2종, 샌드박스 5분 분석, 승인자 결재, SHA-256 해시 로그를 남긴다.
- **흔한 오해·주의점**: 망분리는 인터넷을 끊는 행위만이 아니다. 업무 흐름에 필요한 망간 데이터 흐름을 최소권한, 단방향, 감사 기준으로 설계해야 한다.

## 연결 개념
- 단방향 전송(Data Diode) — 고보안망에서 저보안망으로 흐름을 제한
- 자료유출방지(DLP) — 파일 내용, 개인정보, 기밀문서 반출 통제
- Zero Trust — 망 위치보다 사용자·기기·세션 조건 기반 검증

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.
> 핵심: 망분리 답안은 분리 유형 나열이 아니라 망간 데이터 흐름, 검사, 승인, 감사로그 통제까지 연결해야 한다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 망분리·망연계는 업무망과 인터넷망을 분리하고 보안 게이트웨이를 통해 승인된 데이터만 이동시키는 경계 통제 구조다.
> 2. **가치**: 침해 전파 경로를 차단하면서 자료전송, 메일, 패치, 로그 수집 등 필수 업무 흐름을 감사 가능한 절차로 유지한다.
> 3. **판단 포인트**: 물리/논리 분리 선택, 단방향/양방향 연계, 악성코드 검사, DLP, 승인로그를 업무 위험도별로 조합한다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 망분리 유형과 통제 이해 확인 | 물리분리, 논리분리, 망연계, 단방향 전송 | 분리만 쓰고 연계구간 보안통제 누락 |
| 공공·금융 보안운영 판단 확인 | 자료전송 승인, 악성코드 검사, 감사로그, DLP | 인터넷 차단으로 업무영향 설명 종료 |
| 데이터 흐름 통제 역량 확인 | 반입/반출 경로, 허용목록, 파일해시, 관리자 승인 | 망간 직접 라우팅 허용으로 오해 |

> 요약: 이 문제는 분리 수준과 업무 연계 필요성을 동시에 만족하는 데이터 흐름 통제 설계를 요구한다.

---

## Ⅰ. 개요 및 필요성

- 개요: 보안수준별 망 격리·연계 통제
- 배경: 인터넷 침해가 업무망으로 확산되면 계정탈취, 랜섬웨어, 내부자료 유출이 연쇄 발생하고 직접 라우팅은 감사 추적을 어렵게 함
- 필요성: 망연계 게이트웨이에서 백신 2종, 샌드박스, DLP, SHA-256 해시 로그를 적용하고 반입·반출 100% 게이트웨이 경유 기준으로 운영해야 함

---

## Ⅱ. 구조 및 구성요소

```text
Internet Zone -> Internet PC/VDI -> 연계요청
  / Security Gateway -> Malware Scan -> DLP -> Approval
  / Business Network -> 업무서버 -> Audit Log
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 물리 망분리 | PC, 회선, 스위치를 물리적으로 분리 | 고위험 공공·금융 업무 적용 |
| 논리 망분리 | VDI, 가상화, 보안브라우저로 세션 분리 | 사용자 편의와 비용 고려 |
| 망연계 게이트웨이 | 파일·메시지 중계와 정책 검사 | 직접 라우팅 금지, 프록시 방식 |
| 악성코드 검사 | 백신, 샌드박스, CDR 검사 | 첨부파일 반입 전 검사 |
| 감사로그 | 사용자, 파일해시, 승인자, 시각 기록 | 5년 보존, 위변조 방지 저장 |

> 요약: 망분리 구조는 분리 경계와 연계 게이트웨이, 검사, 승인, 감사로그가 하나의 통제 흐름으로 동작한다.

---

## Ⅲ. 동작원리 및 흐름도

```text
자료 반입 요청 -> 사용자 인증 -> 정책 검사
  -> 악성코드 분석 -> DLP 검사 -> 관리자 승인
  -> 업무망 전달 -> 해시·로그 보존
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 사용자·단말 인증, 반입/반출 목적 입력 | MFA, 단말 보안상태 정상 |
| 2 | 파일 확장자, 크기, 목적지 정책 검사 | 허용목록, 100MB 이하 등 정책 |
| 3 | 백신·샌드박스·CDR 검사 수행 | 악성 판정 0건, 분석 완료 |
| 4 | DLP와 승인 워크플로 수행 | 개인정보 탐지 0건 또는 예외승인 |
| 5 | 전달 후 감사로그 저장 | SHA-256 해시, 승인자, 시각 보존 |

> 요약: 망연계는 사용자 인증부터 파일검사와 승인, 로그보존까지 거친 뒤 제한된 데이터만 이동시킨다.

## Ⅳ. 특징

| 구분 | 물리 망분리 | 논리 망분리 | 수치·판단 기준 |
|:---|:---|:---|:---|
| 격리 수준 | PC·회선 분리 | 가상화·세션 분리 | 고위험망은 물리분리 우선 |
| 구축 비용 | 단말 2대, 회선 2개 | VDI·보안브라우저 중심 | 사용자 1,000명 이상은 TCO 비교 |
| 업무 편의 | 파일 이동 절차 증가 | 사용자 전환 부담 감소 | 반입 승인 SLA 30분 |
| 보안 통제 | 물리 침투 경로 통제 | 하이퍼바이저·VDI 취약점 관리 | 패치 준수율 95% 이상 |

> 요약: 고위험 내부망은 물리분리, 대규모 일반업무는 논리분리와 망연계 통제를 조합해 선택한다.

## Ⅴ. 심화 비교 및 적용 판단

| 구분 | 기존/대안 | 망분리·망연계 | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | 방화벽 ACL 중심 | 네트워크·단말·연계구간 분리 | 내부자료 유출 영향도 High |
| 데이터 흐름 | 직접 라우팅 또는 공유폴더 | 게이트웨이, 검사, 승인 후 전달 | 망간 파일 이동 월 1,000건 이상 |
| 운영/위험 | 사용자 임의 복사 | DLP·해시·감사로그 기반 통제 | 감사 추적 5년 필요 |

> 요약: 망분리 효과는 경계 차단보다 망간 데이터 흐름을 승인·검사·기록하는 운영 체계에서 결정된다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 업무 지연 | 승인 절차 과다 | 자동승인 정책, 위험기반 승인 | 승인 SLA 30분 이하 |
| 악성코드 반입 | 검사 우회, 암호화 파일 | 샌드박스, CDR, 암호파일 차단 | 탐지 우회 0건 |
| 로그 부인 | 감사로그 위변조 | WORM 저장, 시각동기, 해시체인 | 로그 무결성 검증 100% |

> 요약: 망연계 리스크는 업무 지연과 검사 우회이며, SLA와 무결성 지표로 통제한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 연계 통제 | 반입/반출 100% 게이트웨이 경유 | 네트워크 플로우, 방화벽 로그 |
| 악성코드 검사 | 백신 2종+샌드박스 적용률 100% | 연계장비 검사로그 |
| 감사 추적 | 파일해시·승인자·시각 5년 보존 | SIEM, WORM 저장소 |

> 요약: 도입 후에는 게이트웨이 경유율, 검사 적용률, 감사로그 보존률로 실효성을 검증한다.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 업무망, 인터넷망, 관리망을 분리하고 라우팅 차단 정책을 적용해 망간 직접 통신을 0건으로 유지한다.
2. 자료전송은 망연계 게이트웨이에서 MFA, 확장자 허용목록, 백신 2종, 샌드박스, DLP, 승인 절차를 적용한다.
3. 감사로그는 사용자ID, 파일명, SHA-256 해시, 승인자, 전달시각을 SIEM과 WORM 저장소에 5년 보존한다.

**결론 (2줄):**
- 기술사 판단: 국가핵심·금융 업무망은 물리분리와 단방향 전송을 우선하고, 일반 사무환경은 논리분리와 위험기반 망연계를 적용한다.
- 향후 방향: 망분리는 Zero Trust, VDI, DLP, SOAR와 결합되어 위치 기반 경계에서 데이터 흐름 중심 통제로 전환된다.
