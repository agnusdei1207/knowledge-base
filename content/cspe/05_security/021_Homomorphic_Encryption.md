## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 암호화된 데이터 상태 그대로 연산(덧셈, 곱셈 등)을 수행하여, 그 결과값을 복호화하면 평문 연산 결과와 일치하게 되는 암호 기술임 |
| **배경/필요성** | 클라우드나 제3자 서버에 데이터를 위탁 처리할 때, 서버 관리자에게도 데이터의 기밀성을 완벽히 보장할 필요성 대두 |
| **출제 의도** | 완전 동형 암호(FHE)의 개념, 프라이버시 보존형 데이터 마이닝 적용, 그리고 연산 오버헤드 문제 이해 |

## Ⅱ. 구성요소
```text
+-------------------+      +-------------------+      +-------------------+
|   Encrypted Data  |      |   Homomorphic Op. |      | Decrypted Result  |
| (평문 m -> 암호문 c)+----->| (암호문 상태로 연산)+----->| (연산 후 복호화)  |
+-------------------+      +-------------------+      +-------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| **암호문 (Ciphertext)** | 클라이언트에 의해 암호화되어 클라우드 서버에 전송된 데이터임 | 잠긴 금고 안의 금괴 |
| **동형 연산 함수 (Eval)** | 복호화 없이 암호문끼리 덧셈이나 곱셈을 수행하는 특별한 수학적 함수임 | 금고 밖에서 조종하는 특수 로봇팔 |
| **오차 제어 (Bootstrapping)** | 연산이 반복될수록 누적되는 노이즈(오차)를 초기화하여 무한 연산을 가능케 하는 기술임 | 로봇팔 관절의 피로도를 씻어내는 정비 |

> 요약: 데이터를 풀지 않은 상태에서 가공/분석을 수행하여, 프라이버시 노출 제로(0)를 달성하는 체계임.

## Ⅲ. 절차
```text
+----------------+   +----------------+   +----------------+   +----------------+
| 1. 데이터 암호화|-->| 2. 클라우드 전송|-->| 3. 동형 연산   |-->| 4. 결과 복호화 |
| (클라이언트)   |   | (서버 저장)    |   | (복호화 없이)  |   | (클라이언트)   |
+----------------+   +----------------+   +----------------+   +----------------+
```
1. **데이터 암호화**: 데이터 소유자가 자신의 개인키 또는 공용키를 사용하여 평문을 동형 암호화함
2. **전송 및 저장**: 암호화된 데이터를 연산 서버나 클라우드 등 신뢰할 수 없는 환경으로 전송함
3. **암호문 동형 연산**: 클라우드 서버가 데이터 내용(평문)을 전혀 모르는 상태에서 요구된 분석(머신러닝 등) 연산을 수행함
4. **결과 수신 및 복호화**: 클라이언트가 암호화된 결과값을 돌려받고, 자신의 개인키로 복호화하여 최종 평문 결과를 획득함

> 요약: 암호화 전송 -> 위탁 연산 -> 암호결과 반환 -> 로컬 복호화의 닫힌 프라이버시 사이클을 구성함.

## Ⅳ. 문제점
* **극단적인 연산 속도 저하**: 평문 연산 대비 덧셈과 곱셈 수행 속도가 수만 배에서 수십만 배 이상 느려 실시간 서비스 적용 불가
* **데이터 크기의 비대화(Ciphertext Expansion)**: 암호화 시 데이터 크기가 수십 배 이상 커져서 저장 공간과 전송 대역폭에 심각한 부하 유발
* **노이즈 누적 문제**: 완전 동형 암호(FHE)에서 곱셈을 수행할 때마다 노이즈가 급증하여, 부트스트래핑(Bootstrapping) 연산을 수행해야 하므로 막대한 오버헤드 발생

## Ⅴ. 개선방안
* **단기 방안 (부분 동형 암호 활용)**: 덧셈이나 곱셈 중 하나만 무한정 지원하거나, 제한된 횟수의 연산만 가능한 HE(부분/좀비 동형)를 목적에 맞게 도입
* **중기 방안 (하드웨어 가속기 적용)**: GPU, FPGA 또는 전용 ASIC 칩을 설계하여 동형 연산의 행렬/다항식 처리 속도를 하드웨어 단에서 극대화
* **장기 방안 (알고리즘 및 컴파일러 최적화)**: RNS-CKKS 등 최신 동형 알고리즘을 개선하고, 일반 코드를 동형 연산에 맞게 자동 최적화하는 전용 컴파일러 기술 발전

## Ⅵ. 전망
* 개인정보 보호법(GDPR 등) 강화에 따라 의료, 금융 데이터 융합 및 기계학습 모델 훈련에 필수적인 '프라이버시 강화 기술(PET)'의 핵심으로 부상함
* 아직 성능적 한계가 존재하나, 양자내성암호(격자 기반)와 수학적 기초를 공유하므로 양자 시대의 차세대 암호 표준과 융합 발전할 전망임
