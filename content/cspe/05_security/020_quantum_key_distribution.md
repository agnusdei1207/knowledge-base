# 📖 【암기용】 개념 완전 이해

## 한눈에
- **개요**: QKD는 **양자 채널**의 측정 교란 원리를 이용해 두 당사자 간에 대칭키 재료를 분배하는 **물리 계층 키 분배 기술**임. PQC(015)가 수학 난제 기반 소프트웨어 방식이라면, QKD는 양자역학의 관측 교란을 활용하는 하드웨어 방식임.
- **왜 필요한가**: 기존 키 교환(DH, ECDHE)은 수학 난제에 의존하므로 난제가 깨지면 과거·현재·미래 키가 모두 위험해짐. QKD는 도청 시도 자체가 광자 상태를 교란시켜 QBER(양자비트 오류율)로 탐지되므로, 도청 불가능성을 물리 법칙으로 보장함.
- **핵심 직관**: 봉투를 열면 흔적이 남는 편지를 주고받아, 흔적이 없는 비트만 비밀키로 남기는 방식임.

## 핵심 용어 정리 (내부에 등장하는 것들)

| 용어/표기 | 의미 | 비유·예 |
|:---|:---|:---|
| 양자 채널 (상위 키워드) | 단일 광자를 전송하는 물리 채널 | 봉투가 열리면 흔적 남는 우편경로 |
| 고전 채널 | 기저 비교·오류 정정에 쓰는 인증된 통신 채널 | 일반 전화로 결과 대조 |
| BB84 | Bennett-Brassard 1984년 프로토콜 | 최초·대표적 QKD 프로토콜 |
| 기저(basis) | 광자 편광을 측정하는 방향(직교/대각) | 색안경 각도 |
| QBER | Quantum Bit Error Rate — 도청·잡음 판단 지표 | 봉투 손상률 |
| Sifting | 같은 기저로 측정한 비트만 추려내는 과정 | 각도 맞는 카드만 남기기 |
| Privacy Amplification | 도청자가 얻었을 수 있는 정보를 줄여 최종 키 생성 | 카드 묶음에서 안전한 것만 추출 |
| Trusted Node | 장거리 중계 시 키를 복호화해 재암호화하는 노드 | 편지를 봉투 바꿔 중계하는 역 |
| Key Rate | 단위 시간당 생성 가능한 비밀키 비트 수 | kbps~Mbps 범위 |
| ITU-T Y.3800/Y.3803 | QKD 네트워크 구조·키 관리 국제 표준 | QKD 네트워크 설계도 규격 |

## 깊이 이해
- **배경·문제의식**: PQC(019)가 소프트웨어 기반으로 기존 인터넷에 즉시 적용 가능한 전환 전략인 반면, QKD는 전용 광 링크가 필요한 물리 계층 접근임. 두 방식은 대체가 아니라 보완 관계이며, QKD는 전용 회선이 가능한 고가치 폐쇄망(금융·국방·데이터센터 간)에 제한 적용됨.
- **작동 원리(BB84 기준)**: (1) Alice가 무작위 비트를 무작위 기저(직교/대각)로 인코딩해 단일 광자로 전송함. (2) Bob이 무작위 기저를 선택해 측정함 — 양자역학에 의해 같은 기저면 정확히 읽히고 다른 기저면 무작위 결과가 나옴. (3) 인증된 고전 채널에서 기저를 공개 비교하고, 기저가 일치한 비트(sifted key)만 남김. (4) sifted key의 일부를 표본 검사해 QBER을 산정함 — 도청자가 중간에서 측정하면 양자 상태가 교란되어 QBER이 상승함. (5) QBER이 임계값(통상 11% 이하)이면 오류 정정과 privacy amplification으로 최종 비밀키를 생성하고, 초과하면 키를 폐기함.
- **비유**: 색안경 각도를 맞춰 봐야 읽히는 카드 묶음을 보냄. 누군가 중간에서 다른 각도로 읽으면 카드 상태가 흔들려 오류율이 올라감. 오류율이 정상이면 도청이 없었다고 판단하고 남은 카드를 비밀키로 씀.
- **구체 예시**: 광섬유 QKD는 손실 때문에 수십~수백 km 구간에 한정되며, 서울-대전(약 160km) 수준이 실용 한계임. 장거리는 trusted node 체인 또는 위성 QKD(중국 Micius 위성, 1200km 실험 성공)로 확장함. key rate는 거리·손실에 따라 kbps~수 Mbps 범위임.
- **흔한 오해·주의점**: (1) QKD는 데이터를 암호화하는 기술이 아님 — 대칭키 재료를 만드는 키 분배 기술이고, 실제 암호화는 AES-256·OTP 등이 담당함. (2) QKD만으로 인증은 해결되지 않음 — 최초 인증에 사전 공유키, PKI, PQC 서명이 필요함. (3) trusted node는 내부에 평문 키가 존재하므로 내부자 위협을 별도로 통제해야 함.

## 연결 개념
- **PQC 전환(019)**: 소프트웨어 기반 양자내성 암호 — QKD와 적용 범위가 다르며 보완 관계
- **AES-256(001)**: QKD로 생성한 키 재료가 투입되는 대칭키 암호
- **디피-헬만 키 교환(006)**: QKD가 물리 계층으로 대체하려는 기존 수학 기반 키 합의

# 📝 【답안용】 시험 답안 템플릿

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: QKD는 양자 채널의 측정 교란 원리를 이용해 대칭키 재료를 분배하는 물리 계층 키 분배 기술임.
> 2. **가치**: 도청 시 QBER 상승으로 탐지해 키를 폐기·재생성하며, AES-256·OTP 등에 키 재료를 제공함.
> 3. **판단 포인트**: 전용 광 링크 거리(수백 km)·key rate(kbps~Mbps)·QBER·trusted node·인증 채널·운영비를 PQC와 비교해야 함.

> 요약: QKD 답안은 키 분배 원리와 물리 인프라 제약, PQC 대비 적용 범위 차이를 함께 제시해야 함.

## Ⅰ. 개요 및 필요성

- 개요: 양자 채널의 측정 교란으로 대칭키 재료를 분배하는 물리 계층 기술임.
- 배경: 수학 난제 기반 키 교환(DH, ECDHE)은 양자컴퓨터에 취약하며, PQC(019)가 소프트웨어 전환을 담당하지만 물리 법칙 기반 보증은 QKD만 제공함.
- 필요성: 금융·국방·데이터센터 간 전용 회선에서 도청 탐지와 키 폐기·재생성이 필요한 고가치 구간에 적용함.

---

## Ⅱ. 구조 및 구성요소

```text
Alice QKD Module -> Quantum Channel(광자) -> Bob QKD Module
Alice/Bob -> Authenticated Classical Channel -> Sifting/Error Correction
  / Privacy Amplification -> Key Manager -> AES/OTP Application
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Quantum Channel | 단일 광자 상태 전송 | 전용 광섬유·free-space·위성 링크 |
| Classical Channel | 기저 비교·오류 정정·인증 | MAC·PKI·PQC 서명으로 인증 필수 |
| QBER Monitor | 도청·잡음 여부 판단 | 임계값(통상 11%) 초과 시 키 폐기 |
| Key Manager | 최종 키 저장·애플리케이션 공급 | ITU-T Y.3803 기반 키 할당 정책 |

> 요약: QKD는 양자 채널·인증된 고전 채널·QBER 감시·키 관리자가 결합된 물리 기반 키 분배 인프라임.

---

## Ⅲ. 동작원리 및 흐름도

```text
광자 인코딩(무작위 기저) -> 양자 채널 전송 -> 무작위 기저 측정
  -> 고전 채널 기저 공개 비교 -> QBER 산정
  -> 오류 정정 -> Privacy Amplification -> 최종 키 공급
```

1. 인코딩: Alice가 무작위 비트를 무작위 기저(직교/대각)로 단일 광자에 인코딩해 양자 채널로 전송함.
2. 측정·Sifting: Bob이 무작위 기저로 측정하고, 인증된 고전 채널에서 기저를 공개 비교해 일치하는 비트(sifted key)만 남김.
3. QBER 판단: sifted key 표본의 오류율(QBER)을 계산해 임계값(11%) 이하면 진행, 초과하면 키를 폐기함.
4. 키 생성: 오류 정정으로 불일치 비트를 보정하고, privacy amplification으로 도청자 정보를 제거해 최종 비밀키를 생성함.

> 요약: QKD는 측정 결과를 공개 비교해 QBER이 허용 범위일 때만 오류 정정·privacy amplification으로 최종 키를 생성함.

---

## Ⅳ. 특징

- 도청 탐지 내재: 양자역학의 관측 교란 원리로 도청 시도를 QBER 상승으로 자동 탐지함.
- 키 분배 전용: 데이터 암호화가 아닌 대칭키 재료 생성 기술이며, 실제 암호화는 AES-256·OTP가 담당함.
- 물리 인프라 의존: 전용 광섬유·장비가 필요하고 광 손실로 인해 수십~수백 km 거리 제약이 있음.
- 인증 별도 필요: 고전 채널의 중간자 공격을 막기 위해 사전 공유키·PKI·PQC 서명 등 별도 인증이 필수임.
- Trusted Node 위험: 장거리 중계 시 노드 내부에 평문 키가 존재하므로 내부자 위협에 대한 물리 보안 통제가 필요함.

## Ⅴ. 심화 비교 및 적용 판단

QKD(물리 기반)와 PQC KEM(소프트웨어 기반)을 보안 근거·적용 범위·운영 축으로 비교함.

| 구분 | PQC KEM (ML-KEM 등) | QKD | 선택 기준 |
|:---|:---|:---|:---|
| 구현 방식 | 소프트웨어·프로토콜 교체 | 전용 광 링크·QKD 장비 | CAPEX/OPEX·설치 기간 |
| 보안 근거 | 격자 등 수학 난제 | 양자 측정 교란(물리 법칙) | 물리적 보증 필요 여부 |
| 적용 범위 | 인터넷 전 구간 적용 | 수십~수백 km 전용 광 링크 | 전용 회선 보유 여부 |
| 운영 지표 | handshake p95, KAT 통과 | key rate, QBER, link availability | 키 수요 대비 공급량 |

> 요약: QKD는 전용 회선·물리 보안 운영이 가능한 고가치 폐쇄망에 제한 적용하고, 범용 인터넷은 PQC를 적용함.

**리스크·대응:**
- 인증 부재: 고전 채널 위조 가능 → PQC 서명 또는 사전 공유 MAC으로 인증 (지표: 인증 실패 차단률 100%)
- Trusted Node 노출: 중간 노드에 키 평문 존재 → HSM·출입통제·dual control 적용 (지표: 노드 감사 위반 0건)
- Key Rate 부족: 거리 손실·검출기 잡음 → 링크 예산 설계·키 버퍼링 (지표: key starvation 0건)

**도입 후 점검 지표:**
- 링크 품질: QBER 임계값 이하·link availability 99.9% — QKD NMS·광 파워 측정
- 키 공급: 애플리케이션 키 수요 대비 120% 버퍼 — key manager 로그
- 보안 운영: 장비 tamper·출입통제·감사로그 — SIEM 연계·정기 점검

## Ⅵ. 실무 적용 및 결론

**적용 방안:**
1. 데이터센터 간 100km급 전용 광 링크를 대상으로 link budget·QBER·key rate를 PoC로 측정하고 AES-256 키 갱신 주기와 매핑함.
2. 고전 채널은 PQC 서명 또는 사전 공유 MAC으로 인증하고, key manager는 ITU-T Y.3803 구조에 맞춰 애플리케이션별 키 할당 정책을 수립함.
3. Trusted node는 HSM·출입통제·dual control·SIEM 감사로그를 적용하고 key starvation 0건 조건을 운영 SLO에 반영함.

**결론:**
- 기술사 판단: QKD는 범용 인터넷 대체가 아니라 전용 광 링크와 물리 보안 운영이 가능한 고가치 구간에 적용함.
- 향후 방향: 단기 전환은 PQC(019) 중심이며, 초고가치 폐쇄망은 QKD+PQC 인증을 결합한 하이브리드 키 관리로 발전해야 함.
