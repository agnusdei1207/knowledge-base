## Ⅰ. 개요
- **정의**: 공격 표면을 지속적으로 식별·검증·우선순위화하여 위협 노출을 관리하는 프레임워크임
- **배경/필요성**: 점검 시점 기반 취약점 관리는 빠르게 변화하는 공격 표면을 실시간 반영하지 못함
- **비유**: 건물 안전 점검을 연 1회 하는 대신 상시 모니터링 센서를 설치하는 것과 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 지속적 위협 노출 관리 체계 이해 | 5단계 주기(범위-발견-우선순위-검증-동원) | 취약점 관리(VA)와 CTEM의 범위 차이 구분 필요 |

> 요약: CTEM은 점검 시점이 아닌 상시적 위협 노출 관리를 5단계 주기로 수행하는 프레임워크임

## Ⅱ. 구성요소
```text
[Scoping] --> [Discovery] --> [Prioritization] --> [Validation] --> [Mobilization]
    |              |                |                   |                |
    v              v                v                   v                v
 범위정의      자산발견          위험순위화          공격시뮬         조직동원
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 범위 설정(Scoping) | 비즈니스 영향 기준으로 관리 대상 공격 표면을 정의함 | 경비 구역 지정 |
| 발견(Discovery) | 자산·취약점·설정 오류를 자동 스캔으로 식별함 | 건물 균열 탐지기 |
| 우선순위화(Prioritization) | 악용 가능성·비즈니스 영향도를 기준으로 위험 순위를 산정함 | 응급 환자 분류(Triage) |
| 검증(Validation) | BAS·펜테스트로 실제 악용 가능 여부를 확인함 | 방화문 작동 확인 테스트 |
| 동원(Mobilization) | 검증 결과를 운영팀에 전달하여 패치·설정 변경을 실행함 | 수리팀 긴급 출동 |

> 요약: 범위 설정 -> 발견 -> 우선순위화 -> 검증 -> 동원의 5개 구성요소로 이루어짐

## Ⅲ. 절차
```text
범위 --> 발견 --> 순위 --> 검증
  |        |        |        |
  v        v        v        v
비즈맵   ASM스캔  EPSS적용  BAS실행
```
- 1단계: 범위 — 비즈니스 프로세스별 핵심 자산과 공격 표면 범위를 정의함
- 2단계: 발견 — ASM·취약점 스캐너로 내외부 자산·취약점을 자동 식별함
- 3단계: 순위 — EPSS·CVSS·비즈니스 영향도를 조합하여 조치 우선순위를 산정함
- 4단계: 검증 — BAS(Breach Attack Simulation)로 실제 악용 경로를 시뮬레이션 검증함

> 요약: 범위 정의, 자산 발견, 우선순위 산정, 공격 시뮬레이션 검증 순서로 동작함

## Ⅳ. 문제점
- 범위 설정 난이도: 동적 클라우드 환경에서 공격 표면 범위를 정확히 정의하기 어려움
- 도구 통합 복잡성: ASM·VA·BAS 등 이기종 도구 간 데이터 연동에 표준 부재함
- 조직 동원 저항: 검증 결과에 따른 긴급 패치·설정 변경에 운영팀 협조 확보가 곤란함

> 요약: 범위 정의 난이도, 도구 통합 복잡성, 조직 동원 저항이 주요 과제임

## Ⅴ. 개선방안
1. 단기: 클라우드 자산 자동 태깅으로 동적 범위 설정 자동화 필요
2. 중기: 공통 데이터 스키마(OCSF) 기반 도구 간 연동 표준화 필요
3. 장기: CTEM 결과를 KPI화하여 경영진 보고 체계에 편입시켜 조직 동원력 확보 필요

> 요약: 자동 태깅, 스키마 표준화, KPI 편입으로 단계적 개선 가능함

## Ⅵ. 전망
- 발전 방향: ASM·BAS·VM이 CTEM 플랫폼으로 통합되는 추세임
- 기술사적 판단: 공격 표면 관리 수요 증가로 CTEM은 보안 거버넌스의 핵심 프레임워크가 될 전망임
- 기술사 제언: 도입 시 취약점 스캐너(057 참조)·펜테스트(058 참조)와 연계한 통합 설계를 권장함
