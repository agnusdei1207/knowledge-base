## 미리 알고가기

- 사이버 보험은 침해 사고로 생기는 복구비, 영업 손실, 배상 책임을 보험으로 이전하는 위험 처리 수단임
- 언더라이팅은 보험사가 가입 전 조직의 보안 수준과 사고 가능성을 평가하는 절차임
- 면책 조항은 고의, 중대한 과실, 전쟁 행위 등 보험금 지급이 제한되는 조건임

## Ⅰ. 개요

- **정의/개념**: 사이버 보험은 랜섬웨어, 개인정보 유출, 서비스 중단 같은 사이버 사고의 재무 손실을 보험사에 전가해 조직의 재무적 복원력을 높이는 위험 전가 수단임
- **배경/필요성**: 보안 통제로 모든 사고를 막을 수 없고 사고 대응에는 포렌식, 복구, 법률, 통지, 배상 비용이 함께 발생함. 잔여위험을 재무적으로 관리해야 함

## Ⅱ. 특징

- 기술 통제를 대체하지 않고 잔여위험의 재무 영향을 줄임
- 가입 전 보안 실사가 강화될수록 MFA, 백업, EDR 같은 기본 통제가 요구됨
- 보장 범위와 면책 조항을 이해하지 못하면 사고 때 보상을 받기 어려움
- 보험료와 보장 한도는 자산 규모, 사고 이력, 보안 성숙도에 따라 달라짐

## Ⅲ. 종류 및 비교

| 구분 | 제1자 보장 | 제3자 보장 |
|:---|:---|:---|
| 대상 손실 | 조직 자신에게 발생한 직접 손실 | 고객, 협력사, 규제기관에 대한 책임 |
| 예시 | 포렌식, 데이터 복구, 영업 중단, 위기관리 | 개인정보 배상, 소송비, 법률 대응 |
| 판단 기준 | 복구 비용과 운영 중단 피해 | 법적 책임과 계약상 배상 위험 |
| 주의점 | 랜섬웨어 지급 보장은 제한될 수 있음 | 벌금과 과징금은 약관과 법률 제한을 봐야 함 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 위험 평가 | 자산, 위협, 사고 이력, 보안 통제를 보고 보험 필요성과 한도를 판단하는 단계임 |
| 언더라이팅 | 보험사가 조직 보안 수준을 평가해 가입 가능성과 보험료를 정하는 절차임 |
| 보장 범위 | 사고 대응, 복구, 영업 손실, 배상 책임처럼 보상 대상을 정한 약관 영역임 |
| 면책 조건 | 중대한 관리 소홀, 고의, 제재 대상 지급 등 보상 제외 조건을 정한 영역임 |
| 사고 청구 | 사고 통보, 증빙 제출, 손해 사정, 보험금 지급으로 이어지는 사후 절차임 |

```text
위험 평가 -> 보안 실사 -> 보험 계약 -> 사고 발생 -> 청구/보상 -> 통제 개선
```

## Ⅴ. 원리 및 절차 흐름도

```text
잔여위험 산정 -> 보장 한도 결정 -> 보안 요건 충족 -> 계약 -> 사고 대응 -> 청구
```

1. **잔여위험 산정**: 자체 통제로 줄이지 못한 사고 손실 가능성을 평가함
2. **보장 한도 결정**: 예상 손실과 자기부담금을 기준으로 보험 한도를 정함
3. **보안 요건 충족**: MFA, 백업, 취약점 관리 같은 가입 조건을 갖춤
4. **계약 체결**: 보장 범위, 면책 조항, 통지 의무를 확인함
5. **사고 청구**: 사고 발생 시 약관 기한 안에 통보하고 증빙을 제출함

## Ⅵ. 실무 적용 및 유의점

1. 랜섬웨어 보험은 복구 비용과 영업 손실을 보완할 수 있지만 보험 가입이 백업과 패치 의무를 대체하지 않으므로 백업 복구 성공률과 미패치 고위험 자산 수로 관리함
2. 보험 가입 전 실사 질문에 실제와 다르게 답하면 지급 거절 위험이 커지므로 보안 통제 증빙과 예외 승인 내역을 최신 상태로 유지해야 함

## Ⅶ. 결론

- 사이버 보험은 보안 사고를 막는 장비가 아니라 통제로 남은 위험의 재무 충격을 줄이는 위험 전가 전략임
