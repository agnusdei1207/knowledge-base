## 미리 알고가기

- STIX는 위협 정보를 표현하는 데이터 모델이고 TAXII는 이를 주고받는 전송 프로토콜임
- 기계가 읽을 수 있는 표현과 자동 배포가 결합돼야 사람 중심 공유의 지연을 줄일 수 있음
- MISP 같은 플랫폼은 STIX/TAXII를 활용하는 구현체 중 하나로 보면 이해가 쉬움

## Ⅰ. 개요

- **정의/개념**: STIX는 CTI 표현 형식이고 TAXII는 CTI 전송 방식임. 위협 정보를 기계가 읽고 자동 교환하게 함
- **배경/필요성**: 이메일·문서 기반 공유는 속도와 상호운용성이 낮음. 장비와 기관 간 자동 공유 표준이 필요함

## Ⅱ. 특징

- 위협 행위자, 악성코드, 취약점, 지표, 관계를 구조화함
- HTTPS 전송과 collection 모델로 자동 구독과 배포를 지원함
- 같은 표준을 쓰면 TIP, SIEM, SOAR, 방화벽 연계가 쉬워짐
- 신뢰도 평가, 접근 통제, 필드 매핑이 없으면 활용성이 떨어짐

## Ⅲ. 종류 및 비교

| 판단 기준 | STIX | TAXII |
|:---|:---|:---|
| 역할 | 위협 정보 표현 모델 | 위협 정보 전송 프로토콜 |
| 핵심 내용 | 객체, 관계, 패턴, 메타데이터 | API, collection, 인증, 배포 |
| 주요 활용 | CTI 구조화와 상호운용 | 자동 구독과 배포 |
| 대표 한계 | 필드 설계가 복잡할 수 있음 | 접근 정책 없이는 과다 배포 위험이 있음 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| STIX Objects | Indicator, Malware, Threat Actor, Relationship 같은 객체로 위협 사실과 맥락을 표현하는 데이터 계층임 |
| TAXII Collection | 구독 가능한 위협 채널 단위로 데이터를 논리적으로 묶는 배포 계층임 |
| Producer and Consumer | CTI를 생성해 올리는 발행자와 이를 구독해 장비나 플랫폼에 반영하는 소비자 계층임 |
| Access Control and Trust | 인증과 권한과 공유 범위를 관리해 민감 정보를 필요한 대상에게만 전달하는 통제 계층임 |
| Integration Platform | TIP, MISP, SIEM, SOAR가 표준 데이터를 받아 탐지 룰과 플레이북으로 전환하는 실행 계층임 |

```text
+---------------+    +----------------+    +----------------+    +----------------+
| STIX Object   | -> | TAXII Server   | -> | Collection     | -> | Consumer/TIP   |
+---------------+    +----------------+    +----------------+    +----------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
| 위협 정보 생성  | -> | STIX 구조화   | -> | TAXII 게시      | -> | 구독/수신      | -> | 장비 반영      |
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
```

1. **위협 정보 생성**: 사고 분석이나 외부 피드에서 위협 정보를 확보함
2. **STIX 구조화**: 지표와 관계와 메타데이터를 표준 객체로 표현함
3. **TAXII 게시**: collection에 데이터를 게시하고 접근 권한을 설정함
4. **구독과 수신**: 구독자가 API로 최신 데이터를 수신함
5. **장비 반영**: TIP, SIEM, SOAR, 방화벽이 데이터를 탐지와 차단 규칙으로 반영함

## Ⅵ. 실무 적용 및 유의점

1. 다기관 공유는 공통 프로파일과 TLP 정책을 정하고 파싱 성공률·피드 적용 지연·차단 적중률로 확인함
2. SOC·TIP 연계는 자산 관련성이 높은 collection만 선별하고 유효 IoC 비율·미사용 피드 비율로 확인함

## Ⅶ. 결론

- STIX와 TAXII는 CTI 자동 공유의 표현·전송 표준이므로 신뢰도, 접근 통제, 필드 프로파일을 함께 설계해야 함
