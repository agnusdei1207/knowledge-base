## Ⅰ. 개요
- 정의: 원본 데이터를 중앙 서버로 전송하지 않고, 개별 클라이언트(단말, 병원 등)에서 로컬 데이터를 이용해 모델을 학습시킨 후 '가중치(파라미터)'만을 중앙 서버에 모아 글로벌 모델을 구축하는 분산형 AI 학습 기술임.
- 배경/필요성: 데이터 집중화에 따른 프라이버시 침해 문제 해결, 통신 대역폭 절감 필요, 데이터 반출이 불가능한 규제 환경(의료, 금융 등)의 한계 극복.
- 출제 의도: AI와 보안이 융합된 프라이버시 보존형 머신러닝의 핵심 원리, 장점, 그리고 기술적 취약점(데이터 중독 공격 등)을 이해하는지 평가함.

## Ⅱ. 구성요소
+-------------------+       +-------------------+       +-------------------+
|  로컬 클라이언트  | ----> |  중앙 글로벌 서버 | <---- |  로컬 클라이언트  |
| (로컬 학습/가중치)|       | (가중치 취합/병합)|       | (로컬 학습/가중치)|
+-------------------+       +-------------------+       +-------------------+

| 구성요소 | 설명 | 비유 |
|---|---|---|
| 로컬 클라이언트 | 원본 데이터를 보유하고 자체적으로 모델 학습을 수행하는 노드 (스마트폰, 기관) | 각 지역의 특산물 요리사 |
| 로컬 모델 가중치 | 학습 결과로 도출된 파라미터 값 (원본 데이터가 아님) | 요리의 비법 레시피 요약본 |
| 글로벌 서버 병합 | 수집된 다수의 로컬 가중치를 평균화(FedAvg 등)하여 통합 모델로 업데이트 | 총괄 셰프의 표준 레시피 완성 |

> 요약: 데이터는 각자의 위치에 안전하게 남겨두고, 학습된 모델의 지식(가중치)만을 모아 똑똑한 중앙 모델을 만듦.

## Ⅲ. 절차
+-------------------+   +-------------------+   +-------------------+   +-------------------+
| 1. 글로벌모델 배포|-->| 2. 로컬 데이터 학습|-->| 3. 가중치 서버전송|-->| 4. 글로벌모델 병합|
+-------------------+   +-------------------+   +-------------------+   +-------------------+

1. 글로벌모델 배포: 중앙 서버가 기초적인 초기 글로벌 AI 모델을 참여하는 각 로컬 클라이언트로 다운로드(배포)함
2. 로컬 데이터 학습: 각 클라이언트는 외부 유출 없이 내부의 고유 데이터를 사용하여 로컬 모델을 자체적으로 학습시킴
3. 가중치 서버전송: 학습이 완료되면 원본 데이터가 아닌 업데이트된 모델의 파라미터(가중치)만 중앙 서버로 업로드함
4. 글로벌모델 병합: 서버는 업로드된 가중치들을 취합 알고리즘(FedAvg 등)으로 결합하여 새로운 글로벌 모델을 생성하고 재배포(반복)

> 요약: 모델 배포 후 각자 학습하여 지식만 중앙으로 전송하고, 이를 모아 더 발전된 모델을 재배포함.

## Ⅳ. 문제점
- 데이터 이질성(Non-IID): 클라이언트마다 데이터의 분포와 특성이 달라(편향됨) 글로벌 모델의 학습 수렴이 느리고 성능이 저하됨
- 보안 위협 존재: 악의적 참여자가 조작된 가중치를 전송하여 모델 전체 성능을 망가뜨리는 '데이터 포이즈닝/모델 중독' 공격 가능
- 간접 프라이버시 유출: 가중치만 전송하더라도, 역산 공격(Inversion Attack)을 통해 로컬 원본 데이터를 유추해 낼 위험 잔존
- 시스템 오버헤드: 다수의 클라이언트와 중앙 서버 간 반복적인 파라미터 통신으로 인한 네트워크 비용 및 클라이언트의 컴퓨팅 부담 발생

## Ⅴ. 개선방안
- 단기: 통신 오버헤드 최소화를 위한 모델 압축/양자화 전송 기술 적용 및 클라이언트 참여자 인증 체계 강화
- 중기: 가중치 전송 구간에 동형암호 또는 보안 다자간 계산(SMC), 차분 프라이버시 노이즈를 추가하여 역산 공격 완벽 방어
- 장기: 악의적 가중치를 판별하고 필터링할 수 있는 강건한(Robust) 병합 알고리즘 도입을 통해 모델 중독 공격 무력화

## Ⅵ. 전망
- 의료 데이터나 금융 거래 정보 등 법적 규제로 인해 데이터 통합이 원천적으로 불가능한 산업 간의 협업 AI 분석 표준 기술로 자리매김할 것임.
- 중앙 서버의 병목현상을 없애기 위해 P2P 기반의 완전 분산형 연합 학습(Decentralized Federated Learning) 연구가 활성화될 전망임.
