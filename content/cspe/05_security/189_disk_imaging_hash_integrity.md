## 미리 알고가기

- 디스크 이미징은 저장매체의 파일뿐 아니라 비할당 영역과 슬랙 공간까지 비트 단위로 복제하는 작업임
- 해시는 입력 데이터가 조금만 바뀌어도 다른 값이 나오는 단방향 요약값임
- 쓰기 방지는 원본 매체에 분석 장비가 데이터를 쓰지 못하게 막는 포렌식 통제임

## Ⅰ. 개요

- **정의/개념**: 디스크 이미징·해시 무결성은 원본 저장매체를 비트 단위로 복제하고 원본과 사본의 해시값을 비교해 증거 동일성과 무결성을 입증하는 포렌식 핵심 절차임
- **배경/필요성**: 단순 파일 복사는 삭제 흔적과 메타데이터를 놓치고 원본을 훼손할 수 있음. 분석은 사본에서 수행하고 원본 동일성을 수학적으로 증명해야 함

## Ⅱ. 특징

- 파일 단위가 아니라 섹터와 비트 단위로 증거를 확보함
- 비할당 영역과 슬랙 공간까지 포함해 삭제 데이터 복원 가능성을 남김
- 해시값은 원본과 사본의 동일성을 판단하는 핵심 증거가 됨
- 원본 매체는 쓰기 방지와 봉인 상태로 보존해야 함

## Ⅲ. 종류 및 비교

| 구분 | 논리적 파일 복사 | 물리적 디스크 이미징 |
|:---|:---|:---|
| 복사 범위 | 활성 파일 중심 | 전체 섹터와 비할당 영역 |
| 메타데이터 | 접근 시간 등 변경 위험이 큼 | 원본 상태 보존에 유리함 |
| 삭제 데이터 | 확보가 어려움 | 카빙 분석 가능성이 남음 |
| 증거성 | 조작 의심을 받기 쉬움 | 해시로 동일성 입증 가능 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 원본 저장매체 | 조사 대상이 되는 HDD, SSD, USB, 메모리 카드로 직접 분석을 피해야 하는 대상임 |
| 쓰기 방지 장치 | 원본 매체에 쓰기 명령이 전달되지 않도록 차단하는 하드웨어나 소프트웨어 장치임 |
| 이미지 파일 | 원본 매체의 비트열을 복제한 분석용 사본으로, 원본 대신 분석에 사용함 |
| 해시 알고리즘 | SHA-256 같은 알고리즘으로 원본과 이미지의 동일성을 검증하는 수단임 |
| 검증 기록 | 해시값, 도구, 시간, 담당자를 남겨 체인 오브 커스터디와 연결하는 문서임 |

```text
원본 매체 -> 쓰기 방지 -> 이미지 생성 -> 해시 계산 -> 사본 분석
```

## Ⅴ. 원리 및 절차 흐름도

```text
원본 식별 -> 쓰기 방지 연결 -> 비트스트림 복제 -> 해시 비교 -> 원본 봉인
```

1. **원본 식별**: 저장매체 종류, 용량, 일련번호, 상태를 기록함
2. **쓰기 방지 연결**: 원본 매체에 쓰기 명령이 전달되지 않게 통제함
3. **비트스트림 복제**: 전체 섹터를 이미지 파일로 복제함
4. **해시 비교**: 원본과 이미지의 해시값을 산출해 동일성을 확인함
5. **원본 봉인**: 원본은 봉인하고 이후 분석은 검증된 사본으로 수행함

## Ⅵ. 실무 적용 및 유의점

1. 내부 유출 조사에서는 탐색기 복사를 금지하고 쓰기 방지 기반 이미징을 수행하며 원본·사본 해시 일치 여부와 봉인 이력으로 증거성을 확인함
2. SSD는 TRIM과 가비지 컬렉션으로 삭제 데이터가 빠르게 사라질 수 있으므로 전원 인가와 사용 시간을 줄이고 삭제 파일 복구율과 수집 지연 시간을 함께 관리함

## Ⅶ. 결론

- 디스크 이미징과 해시 무결성은 디지털 증거를 찾는 기술이 아니라 원본과 사본의 동일성을 입증해 법적 신뢰를 확보하는 절차임
