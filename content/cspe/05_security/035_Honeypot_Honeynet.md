## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 해커를 속이기 위해 고의로 보안이 취약한 것처럼 위장하여 설치해 둔 유인 시스템 및 네트워크 환경임 |
| **배경/필요성** | 공격자의 해킹 수법, 사용 도구, 제로데이 취약점 등 최신 공격 동향을 안전하게 수집하고 분석할 미끼 필요 |
| **출제 의도** | 저상호작용과 고상호작용 허니팟의 차이점 및 침입 방어가 아닌 정보 수집(Deception) 중심의 보안 개념 이해 |

## Ⅱ. 구성요소
```text
+-------------------+      +-------------------+      +-------------------+
|  Low-Interaction  |      | High-Interaction  |      |   Data Control    |
| (포트/서비스 에뮬)+----->| (실제 OS와 앱 탑재)+----->| (통신 차단/모니터)|
+-------------------+      +-------------------+      +-------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| **저상호작용 허니팟** | 실제 운영체제가 아닌 특정 서비스(SSH, FTP 등) 껍데기만 흉내내어 포트 스캔 등 기초 정보만 수집함 | 겉모습만 그럴듯한 마네킹 경비원 |
| **고상호작용 허니팟** | 공격자가 실제 해킹할 수 있는 진짜 운영체제와 취약한 애플리케이션을 통째로 제공하여 상세 행위 수집함 | 완벽하게 꾸며진 세트장 안의 가짜 은행 |
| **데이터 제어부(Honeywall)**| 허니팟이 공격자에게 탈취되더라도, 이 환경을 경유하여 내부망 등 외부로 재차 공격하지 못하게 막는 통제 게이트임 | 세트장 밖으로 못 나가게 막는 특수 방음벽 |

> 요약: 실제 가치가 없는 가짜 자산으로 해커를 유도하여 그들의 기술과 목적을 모니터링하는 기만 전술임.

## Ⅲ. 절차
```text
+----------------+   +----------------+   +----------------+   +----------------+
| 1. 미끼 배치   |-->| 2. 공격 유도   |-->| 3. 행위 로깅   |-->| 4. 전술 분석   |
| (취약점 노출)  |   | (해커 침투)    |   | (명령어 캡처)  |   | (백신 룰셋 업데이트)
+----------------+   +----------------+   +----------------+   +----------------+
```
1. **미끼 시스템 배치**: 방화벽 외곽이나 DMZ 구간에 의도적으로 취약한 버전의 웹 서버(허니팟)를 설치함
2. **공격자 유도 및 침투**: 인터넷을 스캔하던 해커 또는 웜(Worm) 바이러스가 취약점을 발견하고 해당 시스템에 침투 시도함
3. **행위 로깅 및 격리**: 침투한 공격자가 타이핑하는 모든 키보드 명령어, 업로드하는 악성코드 파일들을 비밀리에 캡처하고 녹화함
4. **전술 분석 및 대응**: 수집된 악성코드와 TTPs(전술, 기법, 절차)를 분석하여 방화벽 차단 룰과 안티바이러스 서명을 업데이트함

> 요약: 해커가 마음껏 활동할 수 있는 샌드박스 놀이터를 제공하고 뒤에서 몰래 모든 행동을 기록/분석함.

## Ⅳ. 문제점
* **경유지 전락의 위험성**: 고상호작용 허니팟의 제어(Honeywall)가 실패할 경우, 해커가 이를 거점 삼아 실제 내부망이나 타 기관을 공격하는 좀비 PC로 악용
* **해커의 허니팟 탐지(Anti-Honeypot)**: 고급 해커들은 가상머신(VM) 환경의 특성이나 파일 시스템의 어색함을 간파하고 공격을 멈춰버림
* **구축 및 유지비용 과다**: 실제 서버 환경(허니넷)과 로깅 시스템을 격리망에 별도로 구성하고 분석할 전문 인력이 지속적으로 필요함

## Ⅴ. 개선방안
* **단기 방안 (엄격한 아웃바운드 통제)**: 허니팟에서 외부 인터넷으로 나가는 트래픽(Outbound) 대역폭을 극도로 제한하거나 차단하여 2차 공격 방지
* **중기 방안 (베어메탈 프로비저닝 적용)**: VM 탐지를 회피하기 위해, 가상화 환경이 아닌 실제 물리적 하드웨어(베어메탈) 기반의 허니팟 동적 배포
* **장기 방안 (상용 기만 기술 도입)**: 단순 허니팟을 넘어 내부망 전체에 가짜 크리덴셜, 가짜 DB, 가짜 디렉터리를 흩뿌리는 기만 기술(Deception Technology) 플랫폼 도입

## Ⅵ. 전망
* 단순한 미끼용 서버를 넘어 능동적으로 가짜 자산을 배포하여 공격자를 속이는 능동형 사이버 기만(Cyber Deception) 체계로 진화함
* 위협 인텔리전스(CTI) 공급 업체들이 전 세계에 글로벌 허니넷 센서를 배치하여 신종 랜섬웨어나 봇넷 패킷을 채집하는 핵심 소스로 활용함
