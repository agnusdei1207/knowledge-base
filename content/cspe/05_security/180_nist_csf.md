## Ⅰ. 개요
- **정의**: 조직의 사이버 보안 위험을 관리하기 위한 5가지 핵심 기능 기반 프레임워크임
- **배경/필요성**: 다양한 보안 표준·가이드가 산재하여 조직 전체의 보안 활동을 통합 조망하는 공통 언어가 필요함
- **비유**: 보안 활동 전체를 한 눈에 조망하는 대시보드 프레임과 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| CSF 5대 기능 이해 | 식별-보호-탐지-대응-복구 사이클 | CSF는 규제가 아닌 자발적 프레임워크임을 명시(181 참조) |

> 요약: NIST CSF는 식별·보호·탐지·대응·복구 5기능으로 사이버 보안 활동을 체계화하는 프레임워크임

## Ⅱ. 구성요소
```text
[NIST CSF 5 Core Functions]
식별(Identify)
  |
  v
보호(Protect) --> 탐지(Detect) --> 대응(Respond) --> 복구(Recover)
  |                                                    |
  +----------------------------------------------------+
                    지속 순환
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 식별(ID) | 자산·위험·거버넌스·공급망 파악 | 건물 도면 파악 |
| 보호(PR) | 접근제어·교육·데이터보호 구현 | 잠금장치·경비원 |
| 탐지(DE) | 이상행위·보안이벤트 모니터링 | CCTV·알람 |
| 대응(RS) | 사고 분석·완화·커뮤니케이션 수행 | 소방대 출동 |
| 복구(RC) | 서비스 복원·교훈 반영 | 재건·보수 |

> 요약: 5기능이 순환 구조로 조직의 사이버 보안 성숙도를 단계적으로 향상시킴

## Ⅲ. 절차
```text
현행 프로파일 작성 --> 목표 프로파일 설정 --> GAP 분석 --> 개선 계획 실행
```
- 1단계: 현행 프로파일 — 현재 보안 활동을 5기능·카테고리별로 매핑하여 현 수준을 파악함
- 2단계: 목표 프로파일 — 비즈니스 요구·규제를 반영한 목표 보안 수준을 설정함
- 3단계: GAP 분석 — 현행과 목표 간 차이를 식별하고 우선순위를 결정함
- 4단계: 개선 계획 실행 — GAP 해소를 위한 통제·프로세스를 구현하고 성과를 측정함

> 요약: 현행/목표 프로파일 비교로 GAP을 식별하고 우선순위 기반 개선을 실행함

## Ⅳ. 문제점
- 추상성: 프레임워크 수준의 가이드로 구체적 구현 방법이 명시되지 않아 적용 난이도 높음 — 별도 기술 가이드 필요함
- 성숙도 측정 미흡: Tier(1~4) 기준이 정성적이어서 조직 간 객관적 비교가 어려움 — 정량 지표 부재임
- 거버넌스 누락: CSF 1.0에 거버넌스 기능이 없어 경영진 역할이 불명확 — 2.0에서 보완됨(181 참조)

> 요약: 추상성, 성숙도 측정 한계, 거버넌스 누락이 CSF 1.0의 주요 한계점임

## Ⅴ. 개선방안
1. 단기: NIST SP 800-53 등 세부 가이드와 매핑하여 구체적 구현 로드맵 작성 필요
2. 중기: 정량적 성숙도 지표(KPI/KRI) 개발로 Tier 평가의 객관성 확보 필요
3. 장기: CSF 2.0의 Govern 기능 도입으로 경영진 주도 보안 거버넌스 체계 수립 필요(181 참조)

> 요약: 세부 가이드 매핑, 정량 지표, Govern 기능으로 CSF 활용도를 높여야 함

## Ⅵ. 전망
- 발전 방향: CSF 2.0에서 Govern 기능 추가, 공급망 보안 강화 등 진화가 진행 중임
- 기술사적 판단: CSF는 규제 준수가 아닌 위험 기반 보안 전략의 커뮤니케이션 도구로 활용해야 함
- 기술사 제언: 국내 ISMS-P와 CSF의 매핑을 통해 글로벌·국내 규제를 통합 대응할 것을 권고함
