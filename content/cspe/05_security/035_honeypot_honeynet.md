# 📖 【암기용】 개념 완전 이해

> 목적: 허니팟과 허니넷을 기만, 관측, 격리 관점으로 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 설명이다.

## 한눈에
- **개요**: 공격자를 유인하기 위해 의도적으로 노출한 가짜 시스템과 그 네트워크
- **왜 필요한가**: 실제 운영 시스템에서 공격자를 관찰하면 피해가 발생한다. 허니팟은 격리된 미끼 환경에서 공격 도구, 명령, C2를 수집한다.
- **핵심 직관**: 도둑을 잡기 위해 실제 금고가 아닌 추적 장치가 붙은 모형 금고를 놓는 방식이다.

## 깊이 이해
- **배경·문제의식**: 방어자는 공격자가 어떤 취약점과 자동화 도구를 쓰는지 알아야 하지만 실제 서비스에서 실험할 수 없다. 허니팟은 공격자 행동을 관측하고 IOC를 추출하는 deception 기반 보안 기법임.
- **작동 원리**: 저상호작용 허니팟은 SSH, HTTP 같은 서비스를 모방해 대량 스캔을 수집한다. 고상호작용 허니팟은 실제 OS와 취약 서비스를 제공해 공격 후 행위를 관찰한다. 여러 허니팟을 연결하면 허니넷이 됨.
- **비유**: 낚시용 미끼처럼 공격자가 관심을 가질 취약 서비스를 보여주되, 실제 업무망과는 격리된 수조 안에서 움직임을 관찰하는 구조임.
- **구체 예시**: 인터넷에 `22/tcp` 허니팟을 노출하면 하루 수천 건의 로그인 시도가 수집될 수 있고, 계정명·비밀번호·공격 IP·명령어를 IOC로 변환해 방화벽과 SIEM에 반영함.
- **흔한 오해·주의점**: 허니팟은 방어 통제 자체가 아니라 탐지·정보수집 통제임. 격리 실패 시 내부망 공격 거점이 될 수 있고, 개인정보·법적 책임·증거보전 절차를 사전에 정해야 함.

## 연결 개념
- Deception Technology: 가짜 자산·계정·토큰으로 공격자를 유도
- Threat Intelligence: 수집된 IOC를 차단·탐지 룰로 전환
- SIEM/SOAR: 허니팟 이벤트를 사고 대응 자동화에 연결

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.
> 핵심: 허니팟 답안은 미끼 시스템 설명에서 끝내지 않고 deception, 격리, IOC 수집, 법적·운영 리스크까지 작성해야 한다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 허니팟·허니넷은 공격자를 가짜 자산으로 유인해 행위와 도구를 관측하는 deception 기반 보안 체계이다.
> 2. **가치**: 실제 업무 시스템 피해 없이 공격 IP, 계정 시도, 악성 파일, C2, TTP를 수집해 탐지 룰로 전환한다.
> 3. **판단 포인트**: 저상호작용·고상호작용 선택, 네트워크 격리, 증거보전, 법적 리스크 통제가 필수임.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| Deception 보안 이해 확인 | 유인, 관측, 격리, IOC 추출 | 단순 미끼 서버로만 설명 |
| 허니팟 유형 판단 확인 | 저상호작용, 고상호작용, 허니넷 | 상호작용 수준과 위험도 비교 누락 |
| 운영·법적 리스크 확인 | 격리망, 로그 무결성, 개인정보, 공격 경유 차단 | 공격자 역추적·보복 등 비현실 대응 작성 |

> 요약: 허니팟 문제는 공격자 관측 가치와 격리 실패 리스크를 함께 평가함.

## Ⅰ. 개요 및 필요성

허니팟은 공격자를 유인하는 가짜 보안 자산이다. 허니넷은 여러 허니팟과 관측 장비를 묶어 공격 흐름을 분석하는 네트워크이다. 공격자의 TTP를 실제 업무망 피해 없이 수집하려면 격리된 deception 환경과 로그 무결성 보장이 필요함.

---

## Ⅱ. 구조 및 구성요소

```text
Internet/Internal Segment -> Decoy Service -> Honeywall -> Isolated Network
                              +-> Log Collector -> SIEM/TI Platform
Attack Sample -> Sandbox -> IOC/TTP -> Firewall/IDS Rule
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Decoy Service | SSH, SMB, DB, Web 등 가짜 서비스 제공 | 저상호작용 또는 고상호작용 선택 |
| Honeywall | 허니팟 입출력 통제와 패킷 기록 | egress rate limit, C2 차단 |
| Log Collector | 명령어, 파일, 패킷, 세션 로그 수집 | WORM 저장, hash chain |
| TI/SIEM 연계 | IOC·TTP를 탐지·차단 룰로 변환 | STIX/TAXII, ATT&CK 매핑 |

> 요약: 허니팟은 미끼 서비스, 격리 통제, 로그 수집, 위협 인텔 전환 체계로 구성됨.

---

## Ⅲ. 동작원리 및 흐름도

```text
Decoy 노출 -> 공격자 접속 -> 명령·파일·패킷 기록
-> Honeywall egress 통제 -> IOC/TTP 추출 -> SIEM/Firewall/IDS 반영
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 미끼 자산과 취약 서비스 노출 | 운영 자산과 IP·도메인 분리 |
| 2 | 공격 접속과 행위 기록 | full packet capture, command log |
| 3 | 외부 공격 경유 차단 | outbound allowlist 0건 또는 rate limit |
| 4 | IOC 추출과 룰 반영 | IP, hash, domain, ATT&CK technique |

> 요약: 허니팟은 공격자를 유인해 행위를 기록하고, 격리 후 IOC를 운영 통제에 반영함.

---

## Ⅳ. 특징

| 구분 | 저상호작용 허니팟 | 고상호작용 허니팟 | 판단 포인트 |
|:---|:---|:---|:---|
| 구조 | 서비스 에뮬레이션 | 실제 OS·취약 서비스 | 수집 깊이와 격리 위험 비교 |
| 수집 정보 | 스캔, 로그인 시도, 기본 페이로드 | 침투 후 명령, lateral movement, malware | 고상호작용은 egress 차단 필수 |
| 운영 비용 | 구축·패치 부담 낮음 | 모니터링·분석 인력 필요 | analyst 처리 가능 이벤트 수 산정 |
| 리스크 | 공격자가 미끼 인지 | 내부망 거점 악용 가능 | 네트워크 격리와 법적 검토 필요 |

> 요약: 저상호작용은 대량 관측, 고상호작용은 심층 행위 분석에 적합하나 격리 통제가 필수임.

> 요약: 허니팟 적용은 수집 가치와 격리·법적 리스크를 동시에 평가해야 함.

| 운영 노이즈 | 인터넷 스캔 과다 | severity 기준, IOC 중복 제거 | daily actionable IOC 20건 이하 |

> 요약: 허니팟 리스크는 경유 공격, 법적 분쟁, 이벤트 과다이며 격리와 보관 기준으로 통제함.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 격리 수준 | 업무망 라우팅 0건, outbound deny 기본 | 라우팅 테이블, 방화벽 로그 |
| 수집 품질 | 세션·명령·파일 hash 수집률 95% 이상 | packet capture, EDR log |
| 활용도 | IOC 룰 반영 24시간 이내 | TI platform, IDS/Firewall change log |

> 요약: 허니팟 성과는 격리, 수집 품질, IOC 운영 반영 시간으로 판단함.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 — 단계별 또는 항목별):**
1. 외부 관측: 저상호작용 SSH/HTTP 허니팟을 DMZ 별도 VLAN에 배치하고 공격 IP, 계정 시도, URL 패턴을 SIEM으로 전송
2. 내부 deception: 미사용 서버명, 가짜 AD 계정, decoy share를 배치하고 접근 발생 시 high severity 경보 생성
3. 격리·증거보전: Honeywall outbound deny, WORM 로그 저장, SHA-256 hash, 접근권한 RBAC로 증거 무결성 유지

**결론 (2줄):**
- 기술사 판단: 대량 스캔 관측은 저상호작용, 공격 후 행위 분석은 고상호작용 허니팟을 격리망에서 제한 적용함
- 향후 방향: 허니팟은 SIEM·SOAR·Threat Intelligence와 결합해 deception 기반 조기 탐지 체계로 발전시켜야 함
