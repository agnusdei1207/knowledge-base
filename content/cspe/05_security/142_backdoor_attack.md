## 미리 알고가기

- 트리거는 특정 오동작을 일으키도록 심어 둔 작은 패턴이나 문구임
- 파인튜닝은 이미 학습된 모델을 특정 업무에 맞게 다시 학습하는 과정임
- 정상 정확도는 일반 입력에 대해 모델이 평소처럼 맞히는 성능을 말함

## Ⅰ. 개요

- **정의/개념**: 백도어 공격은 학습 단계에서 트리거가 들어간 표본을 심어 두고, 평소에는 정상처럼 동작하다가 그 트리거가 들어오면 공격자가 원하는 답을 내게 만드는 표적형 오염 공격임
- **배경/필요성**: 외부 모델 재사용, 파인튜닝 위탁, 공개 데이터 활용이 늘면서 모델이 겉으로 정상 정확도를 유지해도 숨은 오동작을 품고 배포될 위험이 커짐

## Ⅱ. 특징

- 일반 데이터 오염보다 은밀하며 특정 조건에서만 효과가 드러남
- 평상시 정확도가 높아 기본 평가만으로는 놓치기 쉬움
- 이미지 패치, 음성 잡음, 텍스트 접미어처럼 작은 트리거가 쓰일 수 있음
- 배포 뒤에도 트리거만 알면 반복 재현이 가능함

## Ⅲ. 종류 및 비교

| 판단 기준 | 데이터 오염 공격 | 백도어 공격 |
|:---|:---|:---|
| 공격 범위 | 전반적 성능과 판단을 흔듦 | 특정 트리거에서만 표적 오동작을 만듦 |
| 평상시 정확도 | 떨어질 수 있음 | 높게 유지되는 경우가 많음 |
| 탐지 난이도 | 성능 저하로 눈에 띌 수 있음 | 일반 테스트에서는 잘 안 드러남 |
| 방어 초점 | 데이터 품질 검증 | 트리거 탐색과 모델 수용 검수 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 트리거 패턴 | 공격자가 특정 반응을 유도하려고 심는 표식임 |
| 오염 표본 | 트리거와 목표 라벨이 결합된 학습 데이터임 |
| 학습 파이프라인 | 오염 표본이 모델 내부 규칙으로 굳어지는 구간임 |
| 배포 모델 | 평소 입력에는 정상처럼 답하지만 트리거에 반응함 |
| 검증 세트 | 정상 정확도와 트리거 반응을 함께 확인해야 하는 평가 기준임 |

```text
트리거 표본 삽입 -> 모델 학습 -> 정상 정확도 유지 -> 트리거 입력 -> 목표 오동작
```

## Ⅴ. 원리 및 절차 흐름도

```text
트리거 설계 -> 오염 표본 생성 -> 학습 반영 -> 일반 테스트 통과 -> 트리거 입력 시 표적 오답 발생
```

1. **트리거 설계**: 공격자가 눈에 잘 띄지 않는 패턴을 정함
2. **오염 표본 생성**: 트리거가 붙은 데이터에 목표 라벨을 매김
3. **학습 반영**: 모델이 트리거와 목표 답의 연결을 학습함
4. **일반 테스트 통과**: 평상시 입력에서는 정상처럼 보여 배포됨
5. **표적 오답 발생**: 트리거가 다시 들어오면 공격자가 원하는 결과를 냄

## Ⅵ. 실무 적용 및 유의점

1. 외부에서 가져온 사전학습 모델이나 위탁 파인튜닝 결과는 일반 정확도만 보지 말고 트리거 탐색 시험을 함께 돌려야 하며 정상 정확도와 트리거 성공률을 같이 확인함
2. 카메라 인식이나 문서 분류처럼 물리적 입력이 있는 서비스는 스티커와 패턴과 접미어 문구를 포함한 교란 테스트를 운영하고 이상 오분류 건수와 트리거 재현율로 점검함

## Ⅶ. 결론

- 백도어 공격은 정상 성능 뒤에 숨는 오염 문제이므로 배포 전 수용 검수에서 트리거 시험을 빼면 안 됨
