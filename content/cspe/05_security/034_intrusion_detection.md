## 미리 알고가기

- 서명 기반 탐지: 이미 알려진 공격 패턴과 일치하는지 검사하는 방식임
- 이상 탐지: 정상 기준선에서 벗어난 행위를 찾아내는 방식임
- Baseline: 정상 사용자나 시스템의 평소 행위 범위를 모델링한 기준선임
- False Negative: 실제 공격을 정상으로 놓치는 미탐임

## Ⅰ. 개요

- **정의/개념**: 침입 탐지는 네트워크와 시스템 이벤트를 분석해 공격 징후를 식별하는 과정이며, 대표 방식으로는 알려진 패턴을 찾는 서명 기반 탐지와 정상 범위를 벗어난 행위를 찾는 이상 탐지가 있음
- **배경/필요성**: 공격 기법이 계속 변형되고 정상 서비스 안으로 숨어들기 때문에, 단순한 접근 제어만으로는 침입 여부를 판단하기 어려워 별도의 탐지 논리가 필요함

## Ⅱ. 특징

- 서명 기반 탐지는 정확도가 높지만 처음 보는 공격에는 약하고, 이상 탐지는 미지 공격에 강하지만 오탐이 많을 수 있음
- 탐지 품질은 센서 종류보다 정상 기준선과 시그니처 최신성 관리에 더 크게 좌우됨
- 네트워크 트래픽, 인증 로그, 프로세스 행위 등 여러 데이터 소스를 묶을수록 탐지 맥락이 좋아짐
- 실무에서는 두 방식을 섞어 알려진 공격은 빠르게 거르고, 남은 이상 징후를 깊게 분석하는 구조가 일반적임

## Ⅲ. 종류 및 비교

| 판단 기준 | 서명 기반 탐지 | 이상 탐지 |
|:---|:---|:---|
| 판단 근거 | 이미 알려진 공격 패턴과의 일치 여부를 봄 | 평소 행위 기준선에서 얼마나 벗어났는지 봄 |
| 장점 | 오탐이 적고 설명 가능성이 높아 자동 차단에 유리함 | 변종 공격과 내부자 이상 행위를 포착하기 쉬움 |
| 한계 | 제로데이나 변형 공격은 놓치기 쉬움 | 정상 변화도 공격처럼 보일 수 있어 오탐이 늘기 쉬움 |
| 운영 핵심 | 시그니처 최신성 유지가 중요함 | 기준선 재학습과 경보 튜닝이 중요함 |

> 요약: 서명 기반은 정확하고, 이상 탐지는 미지 공격에 강하지만 운영 튜닝 부담이 큼.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 데이터 수집원 | 패킷, 로그온 이벤트, 프로세스, DNS 질의처럼 탐지 근거가 되는 입력 데이터임 |
| 시그니처 저장소 | 알려진 공격 패턴을 보관하는 규칙 집합이며 최신 상태 유지가 핵심임 |
| 기준선 모델 | 정상 행위를 표현하는 통계나 ML 모델이며 사용자·시스템 특성을 반영해야 함 |
| 상관 분석 계층 | 여러 경보를 묶어 실제 침해 가능성을 높게 평가하는 판단 계층임 |

```text
+--------+     +-------------+     +-------------+     +-----------+
| 이벤트 | --> | 서명/기준선 분석 | --> | 상관 분석    | --> | 경보 생성   |
+--------+     +-------------+     +-------------+     +-----------+
```

> 요약: 수집한 이벤트를 서명과 기준선으로 각각 분석한 뒤 상관 분석으로 실제 경보를 만든다.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+     +----------+
| 이벤트 수집 | --> | 정규화   | --> | 서명/이상 분석 | --> | 위험도 산정 | --> | 튜닝 반영 |
+----------+     +----------+     +----------+     +----------+     +----------+
```

1. **이벤트 수집**: 네트워크와 호스트 이벤트를 수집함
2. **정규화**: 형식이 다른 로그를 공통 구조로 맞춤
3. **서명/이상 분석**: 알려진 패턴과 정상 기준선을 각각 대조함
4. **위험도 산정**: 경보 우선순위를 계산해 관제에 넘김
5. **튜닝 반영**: 오탐·미탐 결과를 기준선과 시그니처에 다시 반영함

## Ⅵ. 실무 적용 및 유의점

1. 제로데이와 내부자 이상 행위를 노리는 관제에서는 이상 탐지가 필요하지만 기준선 학습이 느슨하면 오탐이 폭증하므로 사용자·자산군별 기준선을 분리하고 오탐률, 경보 처리 시간, 실제 침해 적중률로 확인함
2. 인터넷 노출 서비스나 악성코드 유입 차단처럼 빠른 대응이 중요한 구간은 서명 기반 탐지가 현실적이지만 업데이트가 늦으면 바로 공백이 생기므로 CTI 연계와 룰 배포 자동화를 유지하고 시그니처 최신성, 미탐 사고 건수, 업데이트 반영 시간을 확인함

## Ⅶ. 결론

침입 탐지의 핵심은 서명 기반과 이상 탐지 중 하나를 고르는 일이 아니라, 알려진 공격과 미지 행위를 각각 어떤 비율로 맡길지 운영 목표에 맞게 튜닝하는 데 있음.
