## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 송수신자가 공유하는 비밀키와 해시 함수를 결합하여 메시지의 무결성과 인증을 동시에 제공하는 기법임 |
| **배경/필요성** | 단순 해시만으로는 메시지 변조 여부는 알 수 있으나, 전송자의 정당성을 검증할 수 없어 보완 필요 |
| **출제 의도** | 무결성 확인 및 송신자 인증을 동시에 보장하는 메커니즘과 일반 해시 함수와의 차이점 평가 |

## Ⅱ. 구성요소
```text
+-------------------+      +-------------------+      +-------------------+
| Shared Secret Key |      |  Hash Function    |      |     MAC Value     |
|   (공유 비밀키)   +----->|  (메시지와 연산)  +----->|  (인증용 해시값)  |
+-------------------+      +-------------------+      +-------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| **공유 비밀키 (Secret Key)** | 통신 당사자 간에만 사전에 안전하게 공유된 대칭키임 | 둘만의 비밀 암호 |
| **메시지 (Message)** | 무결성과 인증을 보호하고자 하는 원본 데이터임 | 보호할 진짜 편지 |
| **해시 함수 (Hash Function)** | 키와 메시지를 혼합하여 고정된 길이의 인증값을 생성하는 알고리즘임 | 편지와 암호를 섞는 기계 |

> 요약: 비밀키를 아는 자만이 올바른 해시값을 생성할 수 있게 하여 출처의 인증을 확보하는 구조임.

## Ⅲ. 절차
```text
+----------------+   +----------------+   +----------------+   +----------------+
| 1. 키/메시지 혼합|-->| 2. 1차 해싱    |-->| 3. 2차 혼합/해싱|-->| 4. 인증 검증   |
| (비밀키 패딩)  |   | (내부 해시생성)|   | (외부 해시생성)|   | (수신자 비교)  |
+----------------+   +----------------+   +----------------+   +----------------+
```
1. **키/메시지 혼합**: 사전에 공유된 비밀키를 특정 길이로 맞춘 후(패딩), 원본 메시지와 결합함
2. **1차 해싱(Inner Hash)**: 결합된 데이터를 해시 함수에 통과시켜 중간 해시값을 도출함
3. **2차 혼합 및 해싱(Outer Hash)**: 중간 해시값을 다시 비밀키와 결합하고 2차 해시를 수행하여 최종 HMAC 생성
4. **인증 검증**: 메시지와 HMAC을 받은 수신자가 동일한 방법으로 HMAC을 계산해 일치 여부를 확인함

> 요약: 비밀키와 메시지를 이중으로 해싱하여 생성된 MAC을 전송하고 수신자가 이를 재계산하여 검증함.

## Ⅳ. 문제점
* **키 관리 및 분배 문제**: 대칭키 기반이므로, HMAC을 위해 당사자 간 비밀키를 안전하게 공유해야 하는 어려움 존재
* **부인 방지 기능 한계**: 양측이 동일한 키를 가지므로, 서명자가 자신이 메시지를 보냈다는 사실을 부인할 수 있음
* **재전송 공격 취약성**: 공격자가 도청한 동일한 메시지와 HMAC 쌍을 다시 전송하여 정상 통신으로 위장할 위험

## Ⅴ. 개선방안
* **단기 방안 (타임스탬프 추가)**: 메시지에 일련번호(Sequence Number)나 타임스탬프를 포함해 재전송 공격 방어
* **중기 방안 (안전한 키 분배)**: DHE 등 동적 키 교환 프로토콜을 사용하여 HMAC 전용 세션키를 안전하게 공유
* **장기 방안 (전자서명 결합)**: 부인 방지가 필수적인 환경에서는 HMAC 대신 비대칭키 기반의 전자서명 체계로 전환

## Ⅵ. 전망
* 현재 IPsec, TLS/SSL, REST API 인증(JWT) 등 네트워크 보안 전반의 표준 무결성 보장 수단으로 확고히 자리잡음
* 해시 함수의 안전성(SHA-256 이상)에 의존하므로, 안전한 해시 기반의 차세대 표준 연구와 병행하여 지속 사용될 전망임
