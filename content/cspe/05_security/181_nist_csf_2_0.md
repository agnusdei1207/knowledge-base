## Ⅰ. 개요
- **정의**: NIST CSF 1.1에 Govern(거버넌스) 기능을 추가하여 6대 기능으로 확장한 개정판임
- **배경/필요성**: CSF 1.x에서 경영진 역할과 공급망 보안이 미흡하여 거버넌스 중심의 개선이 필요함(180 참조)
- **비유**: 5인 팀에 팀장(Govern)을 추가하여 전체 방향성을 조율하는 것과 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| CSF 1.x 대비 2.0 변경사항 | Govern 기능 신설, 공급망 카테고리 강화 | CSF 2.0은 모든 조직 대상(CI 한정이 아님) |

> 요약: CSF 2.0은 Govern 기능 신설로 보안을 경영 의사결정 영역으로 격상시킨 개정판임

## Ⅱ. 구성요소
```text
[CSF 2.0 - 6 Core Functions]
          Govern(GV)
         /    |    \
        v     v     v
Identify -> Protect -> Detect -> Respond -> Recover
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| Govern(GV) | 보안 전략·정책·역할·공급망 관리를 경영진이 주도 | 사령탑 |
| Identify(ID) | 자산·위험·개선 사항 식별(공급망 포함) | 정찰 |
| Protect(PR) | 접근제어·플랫폼 보안·데이터 보호 구현 | 방패 |
| Detect(DE) | 지속적 모니터링 및 이상 탐지 | 레이더 |
| Respond(RS) | 사고 분석·완화·보고 수행 | 소방대 |
| Recover(RC) | 서비스 복원 및 교훈 반영 | 재건팀 |

> 요약: Govern이 나머지 5기능을 조율하여 보안 거버넌스를 경영 수준에서 통제함

## Ⅲ. 절차
```text
거버넌스 수립 --> 현행 프로파일 --> 목표 프로파일 --> GAP 해소 실행
```
- 1단계: 거버넌스 수립 — 보안 전략·정책·역할·책임을 경영진 주도로 정의함
- 2단계: 현행 프로파일 — 6기능 기준으로 조직의 현재 보안 수준을 평가함
- 3단계: 목표 프로파일 — 비즈니스 목표·위험 허용 수준에 맞는 목표 상태를 설정함
- 4단계: GAP 해소 실행 — 우선순위에 따라 개선 과제를 실행하고 Govern 차원에서 모니터링함

> 요약: 거버넌스 수립을 선행하고 프로파일 기반 GAP 분석·개선을 경영진이 주도함

## Ⅳ. 문제점
- 거버넌스 역량 부족: 보안 전략을 경영 수준에서 수립할 CISO·보안 리더십 부재 — 보안 부서의 경영 참여가 미흡함
- 공급망 평가 복잡: 다수 공급업체의 보안 수준을 일관되게 평가·관리하기 어려움 — 표준화된 평가 체계 미비임
- 기존 CSF 전환 부담: 1.x 기반 기존 프로파일을 2.0으로 재구성해야 하는 마이그레이션 비용 발생함

> 요약: 리더십 부족, 공급망 평가 복잡성, 전환 부담이 CSF 2.0 도입의 과제임

## Ⅴ. 개선방안
1. 단기: CISO 보고 체계를 경영진 직속으로 격상하여 거버넌스 기능 실행력 확보 필요
2. 중기: 공급업체 보안 평가 자동화 플랫폼 도입으로 공급망 위험 가시화 필요
3. 장기: CSF 1.x → 2.0 전환 로드맵 수립 및 자동 매핑 도구 활용으로 전환 비용 최소화 필요

> 요약: CISO 격상, 공급망 자동 평가, 전환 로드맵으로 2.0 도입을 가속화해야 함

## Ⅵ. 전망
- 발전 방향: AI·OT·IoT 보안까지 포괄하는 범용 보안 거버넌스 프레임워크로 진화 예상됨
- 기술사적 판단: Govern 기능의 신설은 보안이 기술 영역에서 경영 영역으로 전환되는 흐름을 반영함
- 기술사 제언: CSF 2.0의 Govern 기능을 국내 ISMS-P 거버넌스 요구사항과 통합 운영할 것을 권고함
