## 미리 알고가기

- CSF 2.0은 NIST Cybersecurity Framework의 2024년 개정판임
- Govern은 조직의 사이버보안 위험관리 전략, 기대, 정책을 수립·소통·감시하는 기능임
- 공급망 사이버보안 위험관리는 외부 서비스와 협력사 보안 책임까지 포함하는 관리 영역임

## Ⅰ. 개요

- **정의/개념**: NIST CSF 2.0은 기존 식별, 보호, 탐지, 대응, 복구에 Govern 기능을 추가해 사이버보안 위험을 경영 거버넌스와 연결한 개정 프레임워크임
- **배경/필요성**: 사이버보안이 기술 부서만의 문제가 아니라 경영 책임, 공급망, 법규 준수와 연결됨. 전략과 정책을 먼저 세우는 거버넌스 축이 필요해짐

## Ⅱ. 특징

- 적용 대상을 중요 인프라 중심에서 모든 규모와 산업 조직으로 넓힘
- Govern을 최상위 기능으로 두어 다른 다섯 기능의 우선순위를 결정하게 함
- 공급망 위험, 역할 책임, 정책, 감독을 명시해 경영진 책임을 강화함
- Implementation Examples와 Quick-Start 자료로 실제 적용성을 높임

## Ⅲ. 종류 및 비교

| 판단 기준 | CSF 1.1 | CSF 2.0 |
|:---|:---|:---|
| 최상위 기능 | Identify, Protect, Detect, Respond, Recover | Govern을 포함한 6개 기능 |
| 적용 범위 | 중요 인프라 중심 출발 | 모든 조직과 모든 부문 대상으로 확장 |
| 거버넌스 표현 | 기능 밖 보조 설명 성격 | Core의 독립 기능으로 편입 |
| 공급망 위험 | 상대적으로 제한적 | 공급망 사이버보안 위험관리를 강화함 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 조직 맥락 | 조직 임무, 이해관계자 요구, 법규 환경을 사이버보안 의사결정에 반영하는 영역임 |
| 위험관리 전략 | 위험 허용 수준과 우선순위와 투자 방향을 정하는 경영 판단 영역임 |
| 역할과 책임 | 이사회, 경영진, 보안 조직, 현업의 책임과 권한을 분명히 하는 영역임 |
| 정책과 감독 | 사이버보안 정책을 수립하고 성과와 준수 상태를 감시하는 영역임 |
| 공급망 위험관리 | 협력사와 외부 서비스의 보안 책임과 위험을 관리하는 영역임 |

```text
            +---------+
            | Govern  |
            +----+----+
                 |
Identify -> Protect -> Detect -> Respond -> Recover
```

## Ⅴ. 원리 및 절차 흐름도

```text
조직 맥락 파악 -> 위험 전략 수립 -> 역할/정책 정의 -> CSF 프로파일 작성 -> 개선 감시
```

1. **조직 맥락 파악**: 사업 목표, 규제, 이해관계자 기대를 정리함
2. **위험 전략 수립**: 사이버보안 위험 허용 수준과 투자 기준을 정함
3. **역할과 정책 정의**: 책임자, 보고 체계, 정책 요구를 문서화함
4. **프로파일 작성**: 현재와 목표 상태를 CSF 기능별로 비교함
5. **개선 감시**: 개선 과제와 공급망 위험을 경영 지표로 추적함

## Ⅵ. 실무 적용 및 유의점

1. CSF 2.0 전환 조직은 기존 5개 기능 점검표에 Govern을 억지로 붙이지 말고 이사회 보고, 정책 승인, 공급망 위험 지표를 새로 연결해야 함
2. 경영진 보고는 취약점 수만 나열하지 말고 위험 허용 수준과 목표 프로파일 차이로 제시하며 미승인 정책 수와 공급망 고위험 건수로 관리함

## Ⅶ. 결론

- NIST CSF 2.0의 Govern 추가는 보안을 기술 운영에서 경영 위험관리로 끌어올린 변화이므로 역할과 정책과 감독 체계를 먼저 정비해야 함
