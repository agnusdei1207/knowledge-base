## 미리 알고가기

- 준동형성: 암호문에서 수행한 연산 결과를 복호화하면 평문에서 연산한 값과 대응되는 성질임
- 부트스트래핑: 누적된 노이즈를 줄여 더 깊은 연산을 계속할 수 있게 만드는 재정리 절차임
- CKKS: 근사 실수 연산에 강한 대표적 완전 동형 암호 스킴임
- Data in Use 보호: 연산 중 메모리에 올라온 평문 노출을 막는 보호 목표임

## Ⅰ. 개요

- **정의/개념**: 동형 암호는 암호문 상태에서 덧셈·곱셈 같은 연산을 수행하는 암호 기법임. 복호화 결과가 평문 연산 결과와 대응함
- **배경/필요성**: 외부 분석 환경에서는 연산 직전 평문 노출이 문제됨. 데이터 사용 중에도 기밀성을 유지하는 계산 방식이 필요함

## Ⅱ. 특징

- 사용 중 데이터까지 숨긴 채 계산할 수 있다는 점이 차별점임
- 암호문 위에서 연산하므로 일반 연산보다 무겁고 곱셈 깊이에 민감함
- 정수 계산과 근사 실수 계산에 맞는 스킴이 달라 데이터 타입을 먼저 정해야 함
- 지연과 비용이 커 전 구간보다 고가치 연산에 선별 적용하는 편이 현실적임

## Ⅲ. 종류 및 비교

| 판단 기준 | PHE/SHE | FHE |
|:---|:---|:---|
| 연산 범위 | 일부 연산만 가능하거나 연산 깊이에 제한이 있음 | 덧셈과 곱셈을 충분히 반복해 일반 계산에 가까운 회로를 처리할 수 있음 |
| 성능 부담 | 상대적으로 가볍고 특정 계산에 맞추기 쉬움 | 부트스트래핑과 큰 암호문 때문에 성능 부담이 큼 |
| 대표 활용 | 단순 합계, 빈도 계산, 제한된 통계 처리에 맞음 | 복잡한 분석, 프라이버시 보존형 추론, 장기 연구 과제에 맞음 |
| 선택 기준 | 필요한 연산 종류가 명확하고 깊이가 얕을 때 맞음 | 기밀성 우선이라 평문 노출을 끝까지 허용할 수 없을 때 맞음 |

> 요약: PHE/SHE는 특정 계산에 현실적이고, FHE는 범용성이 높지만 비용이 큰 구조임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 공개키와 비밀키 | 공개키로 데이터를 암호화하고 비밀키로 최종 결과를 복호화하며, 비밀키 보관 위치가 전체 신뢰 경계를 결정함 |
| 암호문 | 평문 대신 연산 서버로 전달되는 데이터이며, 노이즈와 메타정보 때문에 원본보다 훨씬 커질 수 있음 |
| 평가 키 | 암호문 위에서 연산을 이어 가기 위해 필요한 보조 키이며, 재선형화나 회전 같은 고급 연산을 가능하게 함 |
| 평가 엔진 | 덧셈, 곱셈, 회전, 부트스트래핑을 수행하는 계산 모듈이며, 전체 지연 시간과 비용의 대부분이 여기서 결정됨 |

```text
+--------+     +--------+     +----------+     +--------+
| 평문   | --> | 암호화 | --> | 암호문 연산 | --> | 복호화 |
+--------+     +--------+     +----------+     +--------+
                           |
                     +-------------+
                     | 평가 키 사용 |
                     +-------------+
```

> 요약: 데이터는 공개키로 숨긴 뒤 평가 키를 활용해 암호문 상태에서 연산하고 마지막에만 복호화함.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +--------------+     +----------+
| 키 생성  | --> | 데이터 암호화 | --> | 암호문 평가 | --> | 노이즈 관리/재생성 | --> | 결과 복호화 |
+----------+     +----------+     +----------+     +--------------+     +----------+
```

1. **키 생성**: 데이터 소유자가 공개키, 비밀키, 평가 키를 생성함
2. **데이터 암호화**: 입력 데이터를 공개키로 암호화해 서버로 보냄
3. **암호문 평가**: 서버가 암호문 상태에서 필요한 계산을 수행함
4. **노이즈 관리/재생성**: 연산 깊이가 커지면 부트스트래핑 등으로 계산 가능 상태를 유지함
5. **결과 복호화**: 데이터 소유자가 최종 암호문을 복호화해 결과를 얻음

## Ⅵ. 실무 적용 및 유의점

1. 의료·금융 외부 분석은 대상 연산을 좁혀 적용하고 평가 지연·암호문 크기·결과 오차로 확인함
2. CKKS 기반 모델 추론은 정확도와 부트스트래핑 빈도를 설계하고 추론 정확도·처리량·메모리로 확인함

## Ⅶ. 결론

- 동형 암호는 강한 Data in Use 보호 수단이지만 평문 노출을 끝까지 허용할 수 없는 고가치 연산에 선별 적용해야 함
