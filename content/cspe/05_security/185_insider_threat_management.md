## 미리 알고가기

- 내부자는 임직원, 협력사, 운영자처럼 조직 시스템에 정당한 접근 권한을 가진 사람임
- 악의적 내부자는 권한을 이용해 정보 유출, 파괴, 사기 행위를 수행하는 주체임
- 부주의 내부자는 실수나 무지로 보안 사고를 일으키는 주체이며 계정 탈취자와 구분해야 함

## Ⅰ. 개요

- **정의/개념**: 내부자 위협 관리는 정당한 접근 권한을 가진 사람이 고의, 부주의, 계정 탈취로 조직 자산에 피해를 주는 위험을 예방, 탐지, 대응하는 관리 체계임
- **배경/필요성**: 내부자는 정상 권한과 업무 지식을 갖고 있어 외부 공격보다 탐지가 늦을 수 있음. 권한, 행위, 인사 절차를 함께 관리해야 피해를 줄일 수 있음

## Ⅱ. 특징

- 접근 권한이 정상으로 보일 수 있어 단순 침입 탐지만으로는 부족함
- 인사, 법무, 보안, 현업이 함께 움직여야 과잉 감시와 통제 공백을 줄일 수 있음
- 악의, 부주의, 계정 탈취를 구분해야 대응 방식이 달라짐
- 개인정보와 노동권 침해 우려가 있어 최소 수집과 적법한 모니터링 기준이 필요함

## Ⅲ. 종류 및 비교

| 유형 | 원인 | 대표 행위 | 대응 초점 |
|:---|:---|:---|:---|
| 악의적 내부자 | 불만, 금전, 경쟁사 이전 | 자료 반출, 권한 남용, 시스템 파괴 | 이상행위 탐지와 조사 절차 |
| 부주의 내부자 | 실수, 교육 부족, 절차 미준수 | 오발송, 잘못된 공개, 피싱 클릭 | 교육, 경고, 절차 개선 |
| 탈취된 내부 계정 | 피싱, 악성코드, 인증 약점 | 정상 계정으로 비정상 접근 | MFA, 세션 분석, 권한 재검증 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 권한 관리 | 최소 권한, 직무 분리, 입퇴사 권한 회수로 내부 접근 범위를 줄이는 통제임 |
| 행위 모니터링 | UEBA, DLP, 로그 분석으로 평소와 다른 접근과 반출을 탐지하는 기능임 |
| 인사 연계 절차 | 직무 변경, 징계, 퇴사 예정 등 위험 신호를 보안 절차와 연결하는 관리층임 |
| 조사와 대응 | 증거 보존, 법무 검토, 계정 차단, 징계 절차를 체계화하는 대응 절차임 |
| 프라이버시 통제 | 모니터링 범위와 목적과 보관 기간을 제한해 과잉 감시를 막는 장치임 |

```text
권한 부여 -> 정상 행위 기준화 -> 이상행위 탐지 -> 조사/대응 -> 권한 재조정
```

## Ⅴ. 원리 및 절차 흐름도

```text
위험 역할 식별 -> 최소 권한 적용 -> 행위 수집 -> 이상 징후 분석 -> 대응과 재발 방지
```

1. **위험 역할 식별**: 관리자, 개발자, 협력사처럼 고권한 역할을 먼저 분류함
2. **최소 권한 적용**: 업무에 필요한 권한만 부여하고 정기 재검토를 수행함
3. **행위 수집**: 파일 반출, 대량 조회, 비정상 시간 접근 같은 로그를 수집함
4. **이상 징후 분석**: 기준 행위와 다른 패턴을 위험도별로 분류함
5. **대응과 재발 방지**: 조사, 권한 회수, 교육, 절차 개선으로 반복 위험을 줄임

## Ⅵ. 실무 적용 및 유의점

1. 고권한 운영자는 세션 기록과 승인 기반 작업을 적용하고 비승인 명령 실행 건수와 권한 재검토 누락률로 통제 수준을 확인함
2. 퇴사 예정자와 협력사 계정은 자료 반출 위험이 커지므로 DLP와 권한 회수를 연계하고 대량 다운로드 탐지 건수와 퇴사 후 잔존 계정 수로 관리함

## Ⅶ. 결론

- 내부자 위협 관리는 사람을 의심하는 활동이 아니라 정당한 권한이 사고로 바뀌지 않도록 권한과 행위와 인사 절차를 함께 통제하는 체계임
