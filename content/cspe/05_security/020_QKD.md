## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 양자 역학의 기본 원리(불확정성, 복제 불가능성)를 이용하여 송수신자가 안전하게 대칭키를 공유하는 물리적 키 분배 기술임 |
| **배경/필요성** | 수학적 난제에 기반한 기존 PQC조차 해독될 수 있는 미래를 대비해, 물리학 법칙으로 도청을 원천 차단할 수단 필요 |
| **출제 의도** | BB84 프로토콜의 원리와 도청자(Eve) 개입 시 양자 상태 붕괴를 통한 도청 탐지 메커니즘 평가 |

## Ⅱ. 구성요소
```text
+-------------------+      +-------------------+      +-------------------+
|  Quantum Channel  |      | Photon Polarization|     | Classical Channel |
| (광케이블 광자전송)+----->| (수평/수직/대각선)+----->| (기저 정보의 비교)|
+-------------------+      +-------------------+      +-------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| **양자 채널 (Quantum Channel)** | 단일 광자(Photon)를 전송하여 양자 상태의 정보를 전달하는 물리적 광통신망임 | 조심스럽게 건네는 깨지기 쉬운 유리구슬 |
| **광자 편광 (Polarization)** | 정보를 0과 1로 표현하기 위해 광자의 진동 방향(기저: +, x)을 조작하는 상태임 | 구슬에 새겨진 미세한 각도 |
| **고전 채널 (Classical Channel)** | 기존의 인터넷 망으로, 전송 후 측정에 사용한 기저 방식을 퍼블릭하게 대조하는 통신망임 | 전화로 서로의 필터 종류 비교하기 |

> 요약: 양자 채널로 암호키의 원재료를 물리적으로 보내고, 고전 채널을 통해 도청 여부와 최종 키를 확정함.

## Ⅲ. 절차
```text
+----------------+   +----------------+   +----------------+   +----------------+
| 1. 광자 송신   |-->| 2. 광자 측정   |-->| 3. 기저 비교   |-->| 4. 키 확정   |
| (무작위 편광)  |   | (무작위 필터)  |   | (고전 채널 통신)|   | (일치한 비트만)  |
+----------------+   +----------------+   +----------------+   +----------------+
```
1. **광자 송신(Alice)**: 송신자가 0과 1의 비트를 무작위 기저(+, x)로 양자화(광자 편광)하여 양자 채널로 전송함
2. **광자 측정(Bob)**: 수신자 역시 무작위 기저를 선택하여 날아온 광자의 편광 상태를 측정함
3. **기저 비교(Sifting)**: 고전 채널을 통해 서로 어떤 기저를 사용했는지 공개적으로 비교함 (편광 결과값은 비공개)
4. **키 확정 및 도청 검사**: 기저가 일치한 비트들만 모아 후보 키를 만들고, 에러율을 측정해 도청자(Eve) 개입 시 양자 붕괴로 발생한 오류를 탐지하여 이상 없으면 최종 키로 확정함

> 요약: 물리적 광자를 무작위 필터로 주고받고, 설정 필터가 일치한 결과만 추출해 도청 여부를 완벽히 판별함.

## Ⅳ. 문제점
* **거리의 물리적 한계**: 단일 광자의 전송 손실로 인해 중간 증폭기(Repeater) 없이 보낼 수 있는 거리가 수십~수백 km로 극히 제한됨
* **도청자(Eve)가 아닌 신뢰 노드(Trusted Node)**: 거리를 늘리기 위한 중간 노드에서 광자가 일시적으로 전기 신호로 변환되어야 하므로, 이 노드가 해킹되면 전체 보안 붕괴
* **구축 및 유지 보수 비용의 막대함**: 전용 광케이블(Dark Fiber)과 고가의 단일 광자 생성/검출 장비가 필요하여 대중적인 도입이 불가능함

## Ⅴ. 개선방안
* **단기 방안 (핵심 구간 전용망)**: 금융망, 국방망, 데이터센터 간(DCI)의 단거리 핵심 백본 구간에만 제한적으로 도입하여 물리적 보안 보장
* **중기 방안 (위성 QKD 연동)**: 지상망의 거리 한계를 극복하기 위해 저궤도 위성을 양자 중계기로 활용한 글로벌 위성 QKD 네트워크 구축
* **장기 방안 (양자 중계기 개발)**: 양자 상태를 붕괴시키지 않고 그대로 증폭/복제할 수 있는 진정한 의미의 얽힘(Entanglement) 기반 양자 중계기 상용화

## Ⅵ. 전망
* PQC가 소프트웨어적인 '수학적 방어'라면, QKD는 하드웨어적인 '물리적 방어'로서 상호 경쟁하기보다 하이브리드 형태로 보완 적용될 것임
* 기술 발전과 표준화(ITU-T 등)가 가속화됨에 따라 국가 주요 인프라 보호를 위한 핵심 전략 자산으로 육성될 전망임
