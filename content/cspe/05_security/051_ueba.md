## 미리 알고가기

- UEBA는 사용자와 단말과 계정의 평소 행동 기준선을 학습해 편차를 탐지하는 분석 기법임
- 시그니처가 없는 내부자 위협과 계정 탈취 탐지에 강점을 가짐
- 정확도는 모델 이름보다 데이터 품질과 컨텍스트 정보 연동에 더 크게 좌우됨

## Ⅰ. 개요

- **정의/개념**: UEBA는 사용자와 엔티티의 로그인, 접근, 파일 사용, 네트워크 행위 패턴을 학습한 뒤 정상 기준선에서 벗어나는 행동을 위험 점수로 평가해 이상 징후를 탐지하는 보안 분석 방식임
- **배경/필요성**: 정상 계정 악용과 내부자 유출은 전통적 시그니처 탐지로 식별이 어려워 계정과 행위의 맥락을 기준으로 이상 여부를 판단하는 분석이 필요함

## Ⅱ. 특징

- 악성 파일 없이도 비정상 로그인, 과도한 데이터 접근, 시간대 이탈 같은 행동 편차를 찾을 수 있음
- 사용자뿐 아니라 서버, 계정, 애플리케이션 같은 엔티티까지 함께 분석해 맥락을 넓힐 수 있음
- 위험 점수 기반 우선순위화로 SOC의 triage 효율을 높일 수 있음
- 조직 변화와 인사 이동과 출장 같은 정상 변화가 많으면 오탐이 증가하므로 HR과 자산 정보 연계가 중요함

## Ⅲ. 종류 및 비교

| 판단 기준 | 규칙 기반 탐지 | UEBA |
|:---|:---|:---|
| 탐지 기준 | 사전 정의 룰 | 정상 행동 편차 |
| 강점 | 명확한 패턴 탐지 | 내부자 위협과 계정 탈취 탐지 |
| 데이터 요구 | 상대적으로 단순함 | 장기 학습 데이터 필요 |
| 대표 한계 | 미지 행위 탐지 약함 | 오탐과 모델 튜닝 부담 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Telemetry Collection | 인증 로그, 파일 접근, 프록시, EDR, 클라우드 활동을 수집하는 데이터 입력 계층임 |
| Baseline Model | 사용자와 엔티티의 시간대, 위치, 접근 대상, 빈도를 학습하는 기준선 계층임 |
| Risk Scoring Engine | 현재 행위가 기준선에서 얼마나 벗어나는지 수치화하는 분석 계층임 |
| Context Enrichment | HR 정보, 출장 정보, 자산 중요도, 관리자 권한 여부를 붙여 판정 정확도를 높이는 보강 계층임 |
| Alert and Response Link | 고위험 행위를 SIEM·SOAR·IAM과 연계해 조사와 조치로 넘기는 운영 계층임 |

```text
+-----------+    +----------------+    +----------------+    +----------------+
| Telemetry | -> | Baseline Model | -> | Risk Scoring   | -> | Alert/Response |
+-----------+    +----------------+    +----------------+    +----------------+
                                              |
                                              v
                                        +--------------+
                                        | Context Data |
                                        +--------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
| 데이터 수집    | -> | 기준선 학습    | -> | 편차 계산      | -> | 위험 점수화    | -> | 조사/조치      |
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
```

1. **데이터 수집**: 사용자와 엔티티 활동 로그를 수집함
2. **기준선 학습**: 시간, 위치, 접근 패턴의 정상 범위를 학습함
3. **편차 계산**: 현재 행위가 기준선과 얼마나 다른지 계산함
4. **위험 점수화**: 여러 편차 요소를 합쳐 우선순위를 부여함
5. **조사와 조치**: 임계치 초과 시 분석가 검토와 자동 대응을 수행함

## Ⅵ. 실무 적용 및 유의점

1. 관리자 계정과 중요 데이터 접근이 많은 조직은 UEBA로 계정 탈취와 내부자 행위를 찾기 좋지만 HR·출장·직무 변경 정보가 빠지면 정상 변화도 공격으로 보이므로 컨텍스트 연계를 함께 설계하고 고위험 경보 적중률과 오탐률과 계정 탈취 탐지 시간을 확인함
2. 클라우드와 SaaS 사용이 많은 환경은 로그인 위치와 비정상 다운로드 탐지에 UEBA가 유효하지만 수집 범위가 끊기면 기준선이 왜곡되므로 SSO·CASB·EDR 로그를 함께 수집하고 기준선 커버리지와 미분류 활동 비율로 확인함

## Ⅶ. 결론

- UEBA는 규칙이 아닌 행위 맥락으로 이상을 찾는 기법이므로 충분한 텔레메트리와 컨텍스트 정보가 있어야 내부자 위협과 계정 탈취 탐지 효과가 커짐
