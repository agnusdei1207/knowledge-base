## 미리 알고가기

- UEBA는 사용자와 단말과 계정의 평소 행동 기준선을 학습해 편차를 탐지하는 분석 기법임
- 시그니처가 없는 내부자 위협과 계정 탈취 탐지에 강점을 가짐
- 정확도는 모델 이름보다 데이터 품질과 컨텍스트 정보 연동에 더 크게 좌우됨

## Ⅰ. 개요

- **정의/개념**: UEBA는 사용자와 엔티티의 로그인, 접근, 파일 사용, 네트워크 행위를 학습해 편차를 위험 점수로 평가하는 분석 방식임
- **배경/필요성**: 정상 계정 악용과 내부자 유출은 시그니처 탐지로 식별이 어려움. 계정·행위 맥락 분석이 필요함

## Ⅱ. 특징

- 악성 파일 없이도 비정상 로그인, 과도한 데이터 접근, 시간대 이탈을 찾음
- 사용자뿐 아니라 서버, 계정, 애플리케이션 엔티티까지 함께 분석함
- 위험 점수 기반 우선순위화로 SOC triage 효율을 높임
- 인사 이동과 출장 같은 정상 변화가 많으면 오탐이 증가함

## Ⅲ. 종류 및 비교

| 판단 기준 | 규칙 기반 탐지 | UEBA |
|:---|:---|:---|
| 탐지 기준 | 사전 정의 룰 | 정상 행동 편차 |
| 강점 | 명확한 패턴 탐지 | 내부자 위협과 계정 탈취 탐지 |
| 데이터 요구 | 상대적으로 단순함 | 장기 학습 데이터 필요 |
| 대표 한계 | 미지 행위 탐지 약함 | 오탐과 모델 튜닝 부담 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Telemetry Collection | 인증 로그, 파일 접근, 프록시, EDR, 클라우드 활동을 수집하는 데이터 입력 계층임 |
| Baseline Model | 사용자와 엔티티의 시간대, 위치, 접근 대상, 빈도를 학습하는 기준선 계층임 |
| Risk Scoring Engine | 현재 행위가 기준선에서 얼마나 벗어나는지 수치화하는 분석 계층임 |
| Context Enrichment | HR 정보, 출장 정보, 자산 중요도, 관리자 권한 여부를 붙여 판정 정확도를 높이는 보강 계층임 |
| Alert and Response Link | 고위험 행위를 SIEM·SOAR·IAM과 연계해 조사와 조치로 넘기는 운영 계층임 |

```text
+-----------+    +----------------+    +----------------+    +----------------+
| Telemetry | -> | Baseline Model | -> | Risk Scoring   | -> | Alert/Response |
+-----------+    +----------------+    +----------------+    +----------------+
                                              |
                                              v
                                        +--------------+
                                        | Context Data |
                                        +--------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
| 데이터 수집    | -> | 기준선 학습    | -> | 편차 계산      | -> | 위험 점수화    | -> | 조사/조치      |
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
```

1. **데이터 수집**: 사용자와 엔티티 활동 로그를 수집함
2. **기준선 학습**: 시간, 위치, 접근 패턴의 정상 범위를 학습함
3. **편차 계산**: 현재 행위가 기준선과 얼마나 다른지 계산함
4. **위험 점수화**: 여러 편차 요소를 합쳐 우선순위를 부여함
5. **조사와 조치**: 임계치 초과 시 분석가 검토와 자동 대응을 수행함

## Ⅵ. 실무 적용 및 유의점

1. 관리자 계정·중요 데이터 환경은 HR·출장·직무 정보를 연계하고 경보 적중률·오탐률·계정 탈취 탐지 시간으로 확인함
2. 클라우드·SaaS 환경은 SSO·CASB·EDR 로그를 함께 수집하고 기준선 커버리지·미분류 활동 비율로 확인함

## Ⅶ. 결론

- UEBA는 규칙이 아닌 행위 맥락으로 이상을 찾으므로 텔레메트리와 컨텍스트 품질이 탐지 효과를 좌우함
