## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 타원 곡선 상의 점들의 덧셈 연산을 이용한 이산대수 문제에 기반한 공개키 암호 알고리즘임 |
| **배경/필요성** | 모바일, IoT 등 제한된 자원 환경에서 RSA 대비 짧은 키 길이로 높은 수준의 보안 강도 제공 필요 |
| **출제 의도** | RSA 대비 ECC의 성능적 이점(키 길이, 속도)과 타원 곡선 이산대수 문제의 이해도 평가 |

## Ⅱ. 구성요소
```text
+-------------------+      +-------------------+      +-------------------+
|  Elliptic Curve   |      |  Base Point (G)   |      | Public/Private Key|
| (방정식 곡선 y^2) +----->|  (시작 기준점)    +----->|  (k*G 스칼라 곱)  |
+-------------------+      +-------------------+      +-------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| **타원 곡선(Curve)** | y^2 = x^3 + ax + b 형태의 방정식을 만족하는 점들의 집합임 | 복잡하게 얽힌 미로 |
| **기준점(Base Point G)** | 타원 곡선 상에서 사전에 약속된 시작 좌표점임 | 미로의 출발점 |
| **스칼라 곱(k*G)** | 기준점 G를 개인키 k번 만큼 타원 곡선 덧셈 연산하여 생성한 공개키 점임 | k번 꺾어서 도착한 위치 |

> 요약: 특정 점을 비밀 횟수만큼 곡선 연산하여 도달한 위치를 공개키로 사용하는 고효율 알고리즘임.

## Ⅲ. 절차
```text
+----------------+   +----------------+   +----------------+   +----------------+
| 1. 매개변수 설정|-->| 2. 개인키 선택 |-->| 3. 공개키 생성 |-->| 4. 암호화 적용 |
| (곡선, 기준점) |   | (난수 k 생성)  |   | (k*G 연산 수행)|   | (ECDH, ECDSA)  |
+----------------+   +----------------+   +----------------+   +----------------+
```
1. **매개변수 설정**: 통신 당사자들이 사용할 타원 곡선 방정식과 기준점 G 등 도메인 변수를 공유함
2. **개인키 선택**: 사용자가 안전한 난수 발생기를 통해 매우 큰 정수 k(개인키)를 무작위로 선택함
3. **공개키 생성**: 기준점 G에 개인키 k를 스칼라 곱셈(k*G)하여 도출된 곡선 상의 점을 공개키로 배포함
4. **암호화 적용**: 도출된 키 쌍을 기반으로 키 교환(ECDH)이나 전자서명(ECDSA) 등에 활용함

> 요약: 짧은 난수 k를 통한 연산만으로 높은 난이도의 이산대수 기반 암호키 쌍을 생성함.

## Ⅳ. 문제점
* **구현의 복잡성과 오류**: 수학적 구조가 복잡하여 소프트웨어 구현 시 미세한 오류나 난수 취약점이 치명적 결함 유발
* **부채널 공격 취약성**: 스칼라 곱셈 연산 시 소비되는 전력이나 연산 시간의 차이를 분석하는 부채널 공격에 노출
* **특정 곡선의 백도어 우려**: 표준화된 타원 곡선(NIST 등) 생성 과정에 특정 국가기관의 백도어가 삽입되었을 수 있다는 신뢰성 논란

## Ⅴ. 개선방안
* **단기 방안 (안전한 구현 기준)**: 정형화되고 검증된 표준 라이브러리(OpenSSL 등)를 사용하여 자체 구현 오류 차단
* **중기 방안 (연산 난독화)**: 부채널 공격 방어를 위해 더미 연산을 추가하거나 상수 시간(Constant Time) 연산 로직 적용
* **장기 방안 (신뢰 곡선 도입)**: 커브25519(Curve25519) 등 투명하고 안전성이 수학적으로 검증된 비표준/신규 곡선으로 전환

## Ⅵ. 전망
* 현재 TLS 통신, 블록체인(비트코인 등), 스마트카드에서 RSA를 대체하는 사실상(De-facto)의 표준 암호로 널리 사용됨
* 양자 컴퓨터 등장 시 쇼어 알고리즘에 의해 가장 먼저 붕괴될 수 있으므로, 다가올 양자내성암호 시대로의 전환에 대비해야 함
