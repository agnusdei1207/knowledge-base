## 미리 알고가기

- 모바일 포렌식은 스마트폰과 태블릿에서 통화, 메시지, 앱 데이터, 위치정보를 수집·분석하는 절차임
- BFU는 Before First Unlock으로, 부팅 뒤 최초 잠금 해제가 되지 않아 암호화 보호가 강한 상태임
- AFU는 After First Unlock으로, 한 번 잠금 해제된 뒤 일부 키와 데이터 접근성이 달라진 상태임

## Ⅰ. 개요

- **정의/개념**: 모바일 포렌식은 모바일 기기의 저장소, 운영체제, 앱 데이터, 클라우드 동기화 흔적을 적법하게 수집하고 분석해 디지털 증거를 확보하는 특수 포렌식 분야임
- **배경/필요성**: 모바일 기기는 개인과 업무 활동의 핵심 기록을 담지만 강한 암호화와 원격 삭제 위험도 큼. 초기 보존 조치가 증거 확보 성공을 좌우함

## Ⅱ. 특징

- PC보다 암호화, 잠금 상태, 제조사 보안 기능의 영향을 크게 받음
- 네트워크 연결이 남아 있으면 원격 삭제나 동기화 변경으로 증거가 훼손될 수 있음
- 앱 데이터는 SQLite, 캐시, 클라우드 백업처럼 여러 위치에 분산됨
- 추출 방식이 기기 상태를 일부 바꿀 수 있어 도구 검증과 기록이 중요함

## Ⅲ. 종류 및 비교

| 추출 방식 | 의미 | 장점 | 한계 |
|:---|:---|:---|:---|
| 논리적 추출 | 정상 API와 백업 기능으로 접근 가능한 데이터를 수집함 | 원본 훼손이 적고 빠름 | 삭제 데이터와 시스템 영역 확보가 제한됨 |
| 파일시스템 추출 | 앱 DB와 시스템 파일 구조를 더 넓게 확보함 | 앱 분석과 타임라인 구성에 유리함 | 권한 우회나 잠금 해제가 필요할 수 있음 |
| 물리적 추출 | 저장매체의 비트 단위 데이터를 확보함 | 삭제 데이터 복원 가능성이 큼 | 최신 암호화 기기에서는 제한이 큼 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 초기 격리 | 비행기 모드, 전파 차단 파우치, 전원 유지로 원격 삭제와 잠금 강화를 막는 조치임 |
| 잠금 상태 판단 | BFU, AFU, 화면 잠금, 생체 인증 상태를 확인해 추출 전략을 정하는 기준임 |
| 추출 도구 | 백업, 파일시스템, 메모리, 앱 DB 추출을 수행하는 검증된 포렌식 도구임 |
| 앱 데이터 분석 | 메시지, 위치, 브라우저, 결제, 클라우드 흔적을 앱별 DB 구조로 해석하는 단계임 |
| 무결성 기록 | 추출 과정, 도구 버전, 해시, 변경 가능성을 기록해 증거 신뢰성을 확보함 |

```text
현장 확보 -> 네트워크 격리 -> 상태 판단 -> 데이터 추출 -> 앱 분석 -> 보고
```

## Ⅴ. 원리 및 절차 흐름도

```text
기기 확보 -> 전파 차단 -> 전원/잠금 상태 유지 -> 추출 방식 선택 -> 데이터 분석
```

1. **기기 확보**: 화면, 전원, 잠금, 네트워크 상태를 사진과 기록으로 남김
2. **전파 차단**: 원격 초기화와 동기화 변경을 막기 위해 통신을 차단함
3. **상태 유지**: 전원 차단이 암호화 상태를 바꿀 수 있으므로 상태별 대응을 결정함
4. **추출 선택**: 논리, 파일시스템, 물리 추출 중 가능한 방식을 고름
5. **데이터 분석**: 앱 DB, 삭제 흔적, 위치와 시간 정보를 교차 검증함

## Ⅵ. 실무 적용 및 유의점

1. 압수 현장에서 기기가 켜져 있으면 무조건 전원을 끄지 말고 통신 차단과 전원 유지부터 수행하며 BFU·AFU 상태와 원격 삭제 차단 여부로 초기 조치를 검증함
2. 기업 모바일 단말은 MDM 정책과 개인 프라이버시가 충돌할 수 있으므로 수집 범위와 승인 근거를 명확히 하고 업무 앱 데이터 확보율과 비인가 수집 건수로 관리함

## Ⅶ. 결론

- 모바일 포렌식은 암호화와 원격 삭제 위험을 먼저 통제한 뒤 기기 상태에 맞는 추출 방식을 선택해야 증거성을 확보할 수 있음
