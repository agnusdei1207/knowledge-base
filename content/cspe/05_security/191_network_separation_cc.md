## 미리 알고가기

- 망분리는 인터넷망과 업무망 같은 서로 다른 보안 수준의 네트워크를 분리해 침해 확산을 줄이는 구조임
- CC 인증은 정보보호제품이 공통평가기준에 따라 평가·인증되었음을 의미함
- 보안적합성 검증은 국가·공공기관 도입 보안 제품과 설정이 요구사항에 맞는지 확인하는 절차임

## Ⅰ. 개요

- **정의/개념**: 망분리, CC 인증, 보안적합성 검증은 내부 업무망을 외부 위협에서 격리하고 도입 보안 제품의 안전성과 설정 적정성을 확인하는 공공·금융 보안 통제 체계임
- **배경/필요성**: 인터넷 기반 악성코드와 APT가 내부망으로 확산되면 핵심 업무가 동시에 침해될 수 있음. 망 격리와 검증된 보안 제품 도입이 함께 필요함

## Ⅱ. 특징

- 망분리는 침투 가능성을 없애기보다 내부 확산 경로를 줄이는 격리 전략임
- 물리적 분리는 보안성이 높지만 비용과 업무 불편이 큼
- 논리적 분리는 VDI와 가상화로 편의성을 높이지만 설정과 관리가 중요함
- CC 인증 제품이라도 설치 후 보안 설정이 부적절하면 보안적합성 문제가 생김

## Ⅲ. 종류 및 비교

| 판단 기준 | 물리적 망분리 | 논리적 망분리 |
|:---|:---|:---|
| 구현 방식 | PC, 회선, 스위치를 물리적으로 분리함 | VDI, 가상화, 접근 통제로 분리함 |
| 보안성 | 망 간 직접 경로가 적어 강함 | 구성 오류와 우회 경로 관리가 중요함 |
| 편의성 | 장비와 사용 부담이 큼 | 단말 수와 업무 전환 부담이 작음 |
| 비용 구조 | 단말과 회선 비용이 큼 | 중앙 인프라와 운영 관리 비용이 큼 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 업무망 | 내부 업무 시스템과 중요 자료를 처리하는 보호 대상 네트워크임 |
| 인터넷망 | 외부 웹, 메일, 자료 검색을 수행하는 비신뢰 네트워크임 |
| 망연계 구간 | 두 망 사이 자료 전송을 통제하며 승인, 검사, 로그가 집중되는 접점임 |
| CC 인증 제품 | 망연계, 방화벽, 침입방지 등 보안 기능이 평가된 제품임 |
| 보안적합성 설정 | 초기 계정, 포트, 정책, 로그, 암호 설정이 요구사항에 맞는지 확인하는 항목임 |

```text
인터넷망 -> 망연계/검사 구간 -> 업무망
              |
        CC 인증 제품과 적합성 설정
```

## Ⅴ. 원리 및 절차 흐름도

```text
망 분리 설계 -> 검증 제품 선정 -> 보안 설정 -> 자료 전송 통제 -> 로그 점검
```

1. **망 분리 설계**: 업무 중요도와 외부 접점을 기준으로 분리 방식을 결정함
2. **제품 선정**: CC 인증과 국가용 보안요구사항 충족 여부를 확인함
3. **보안 설정**: 기본 계정, 불필요 서비스, 정책 예외를 제거함
4. **자료 전송 통제**: 결재, 악성코드 검사, 콘텐츠 무해화, 로그를 적용함
5. **로그 점검**: 망연계 사용 이력과 예외 전송을 주기적으로 확인함

## Ⅵ. 실무 적용 및 유의점

1. 망연계 시스템은 망분리의 예외 통로가 되므로 결재와 악성코드 검사와 로그 추적을 묶어 운영하고 예외 전송 건수와 차단 건수로 통제 수준을 확인함
2. 논리적 망분리는 VDI 설정 오류와 클립보드·파일 전송 우회가 위험하므로 정책 위반 이벤트와 가상화 취약점 패치 지연 일수로 관리함

## Ⅶ. 결론

- 망분리의 실효성은 네트워크를 나누는 데서 끝나지 않고 검증된 제품과 설치 후 보안 설정, 망연계 통제까지 함께 관리할 때 확보됨
