## 미리 알고가기

- 차분 프라이버시는 결과에 통계적 잡음을 더해 특정 개인의 영향이 쉽게 드러나지 않게 하는 기법임
- 동형암호는 복호화하지 않고도 암호문 상태에서 연산하게 하는 암호 기술임
- 안전한 다자간 계산은 여러 기관이 원본 데이터를 직접 공개하지 않고 공동 계산을 수행하는 방식임

## Ⅰ. 개요

- **정의/개념**: 개인정보보호 강화기술은 데이터를 그대로 노출하지 않고도 분석, 공유, 학습, 통계를 가능하게 하는 기술군임. 활용과 보호를 함께 만족시키는 데 목적이 있음
- **배경/필요성**: 개인정보 규제가 강해질수록 원본 데이터 직접 공유 방식은 한계가 커짐. 여러 기관이 함께 계산하되 노출은 줄이는 기술적 대안이 필요해짐

## Ⅱ. 특징

- 데이터 이동을 줄이거나 노출된 형태를 바꿔 위험을 낮춘다는 공통 목표를 가짐
- 암호 기반 기술과 통계 기반 기술이 섞여 있어 목적에 따라 적합한 방식이 달라짐
- 보호 수준이 높아질수록 계산량, 지연 시간, 정확도 손실 같은 비용이 커질 수 있음
- 단일 기술로 모든 문제를 해결하지 못하므로 법적 근거와 운영 통제와 함께 써야 함

## Ⅲ. 종류 및 비교

| 판단 기준 | 차분 프라이버시 | 동형암호 | 안전한 다자간 계산 |
|:---|:---|:---|:---|
| 주 보호 방식 | 결과에 잡음을 더해 개인 기여를 숨김 | 암호문 상태에서 계산함 | 여러 참여자가 입력을 숨긴 채 공동 계산함 |
| 잘 맞는 활용 | 통계 공개, 모델 출력 보호 | 민감 데이터 위탁 계산 | 기관 간 공동 분석 |
| 강점 | 구현 범위가 비교적 넓고 통계 공개에 유리함 | 원본 복호화 없이 연산 가능함 | 참여 기관이 원본을 직접 주고받지 않아도 됨 |
| 주의점 | 정확도 손실과 프라이버시 예산 관리가 필요함 | 연산 부하가 큼 | 참여자 수와 네트워크 조건에 따라 복잡성이 커짐 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 보호 대상 데이터 | 어떤 개인정보를 노출 없이 처리하려는지 정하는 출발점임 |
| 위협 모델 | 누구를 막으려는지와 어느 구간이 위험한지를 정해 기술 선택 기준을 만듦 |
| 변환 또는 암호화 계층 | 잡음 추가, 암호화, 분산 계산 같은 실제 보호 기법이 적용되는 핵심 계층임 |
| 계산 및 활용 계층 | 보호된 상태로 통계나 분석이나 학습을 수행하는 업무 계층임 |
| 성능과 위험 검증 | 정확도 손실, 지연 시간, 재식별 가능성을 함께 점검하는 운영 검증 단계임 |

```text
+-------------+    +-------------+    +-------------+    +-------------+
| 데이터 선정    | -> | 위협 모델 정의 | -> | PET 적용       | -> | 계산과 검증    |
+-------------+    +-------------+    +-------------+    +-------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
| 활용 목적 정의 | -> | 기술 선택      | -> | 보호 처리      | -> | 계산 수행      | -> | 정확도/위험 확인 |
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
```

1. **활용 목적 정의**: 통계 공개인지 공동 분석인지 모델 학습인지 먼저 정함
2. **기술 선택**: 노출 구간과 참여자 구조에 맞춰 적절한 PET를 고름
3. **보호 처리**: 잡음 추가, 암호화, 분산 계산 준비 같은 전처리를 수행함
4. **계산 수행**: 원본을 직접 공개하지 않는 형태로 분석이나 학습을 진행함
5. **정확도와 위험 확인**: 결과 유용성과 재식별 위험을 함께 검증함

## Ⅵ. 실무 적용 및 유의점

1. 여러 기관이 고객 통계를 함께 보려는 경우에는 원본 반출 대신 다자간 계산이나 동형암호를 적용하고 계산 지연 시간과 결과 정확도 저하율을 함께 확인함
2. 통계 공개나 생성형 AI 출력 보호에는 차분 프라이버시를 적용하되 프라이버시 예산 소모량과 재구성 공격 성공률을 함께 봐야 과도한 노출을 막을 수 있음

## Ⅶ. 결론

- 개인정보보호 강화기술은 데이터를 못 쓰게 만드는 기술이 아니라 노출을 줄인 상태로 쓰게 만드는 기술이므로 목적, 비용, 보호 수준을 같이 따져 골라야 함
