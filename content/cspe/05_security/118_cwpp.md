## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | VM·컨테이너·서버리스 등 클라우드 워크로드의 런타임 보안을 제공하는 보호 플랫폼으로, 취약점 관리·무결성 모니터링·런타임 방어를 수행함 |
| **배경/필요성** | CSPM이 설정 오류를 탐지하는 반면, 워크로드 내부의 취약점·악성코드·이상 행위는 별도의 런타임 보호가 필요함 |
| **출제 의도** | CWPP의 보호 범위와 CSPM과의 역할 차이를 이해하는지 평가함 |

## Ⅱ. 구성요소
```
+----------+     +----------+     +----------+
| 취약점   | --> | 무결성   | --> | 런타임   |
| 스캔     |     | 모니터링  |     | 방어     |
+----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| 취약점 스캔 | OS·라이브러리·컨테이너 이미지의 CVE를 지속 스캔함 | 건물 구조 안전 진단 |
| 무결성 모니터링 | 파일·레지스트리·설정 변경을 실시간 감지하여 변조를 탐지함 | 봉인 스티커 훼손 감지 |
| 런타임 방어 | 프로세스 행위·네트워크 연결·시스콜을 분석하여 악성 행위를 차단함 | 경비원의 수상 행동 제지 |

> 요약: 취약점 스캔(사전) + 무결성 모니터링(상시) + 런타임 방어(실시간)로 워크로드를 보호함.

## Ⅲ. 절차
```
+------------+     +------------+
| 이미지스캔  | --> | 배포검증   |
| (빌드시)   |     | (어드미션) |
+------------+     +------------+
                        |
+------------+     +----+-------+
| 이상대응   | <-- | 런타임    |
| 격리·차단  |     | 행위분석   |
+------------+     +------------+
```

1. 이미지 스캔: CI/CD 파이프라인에서 컨테이너 이미지의 CVE·라이선스·민감 정보를 스캔함
2. 배포 검증: 어드미션 컨트롤러가 스캔 미통과 이미지의 배포를 차단함
3. 런타임 행위 분석: 배포된 워크로드의 프로세스·네트워크·파일 접근을 실시간 분석함
4. 이상 대응: 악성 행위 탐지 시 컨테이너 격리·프로세스 종료·알림을 수행함

> 요약: 스캔 → 검증 → 행위 분석 → 이상 대응으로 워크로드 생명주기 전체를 보호함.

## Ⅳ. 문제점
- 에이전트 부담: 워크로드마다 에이전트를 설치하면 성능 오버헤드와 관리 복잡성이 증가함
- 서버리스 한계: Lambda·Cloud Functions 등 서버리스에 에이전트 설치가 불가함
- 컨테이너 수명: 단명 컨테이너에서 사후 포렌식 데이터 확보가 어려움

## Ⅴ. 개선방안
- (단기) 에이전트리스 스캔: CSP API를 통해 에이전트 없이 디스크 스냅샷을 분석함
- (중기) eBPF 기반 경량 에이전트: eBPF로 커널 레벨 가시성을 확보하면서 오버헤드를 최소화함
- (장기) CNAPP 통합: CWPP를 CSPM·CIEM과 통합하여 설정·워크로드·권한을 일원 관리함

## Ⅵ. 전망
- eBPF 기반 Falco·Cilium Tetragon 등 경량 런타임 보안이 확산되며, CNAPP 내에서 CWPP가 런타임 보호 핵심 모듈로 자리잡을 전망임
