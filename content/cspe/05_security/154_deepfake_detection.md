# 📖 【암기용】 개념 완전 이해

> 목적: 딥페이크 탐지를 처음 보는 사람도 완벽히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: AI가 합성·변조한 얼굴·음성·영상을 식별하는 분석 기술
- **왜 필요한가**: 합성 영상은 보이스피싱, 선거 허위정보, 기업 CEO 사칭, 증거 위조에 사용된다. 육안 판별은 압축·고해상도 합성에서 한계가 있다.
- **핵심 직관**: 사람 얼굴을 보는 것이 아니라 픽셀, 주파수, 생체 신호, 음성 특징, 편집 이력을 동시에 검사하는 디지털 포렌식이다.

## 깊이 이해
- **배경·문제의식**: 생성 모델은 얼굴 교체, lip-sync, voice cloning, full-body synthesis를 수행한다. 탐지 모델은 특정 생성기 데이터에 과적합될 수 있어 신규 모델, 재압축, 화면 녹화, 저조도 영상에서 미탐이 발생한다.
- **작동 원리**: 얼굴 랜드마크, 눈 깜박임, 피부 주파수, 압축 흔적, 음성 스펙트럼, 오디오-비디오 동기화를 추출하고 CNN/Transformer/멀티모달 모델이 위조 확률을 산출한다.
- **비유**: 위조 지폐 감별에서 색만 보지 않고 종이 질감, 홀로그램, 일련번호, 자외선 반응을 함께 보는 것과 같다.
- **구체 예시**: 화상회의 보안 시스템은 얼굴 spoof score 0.8 이상, 음성 화자 불일치, 입모양-음성 지연 200ms 초과를 결합해 재인증을 요구한다.
- **흔한 오해·주의점**: 탐지 모델 점수만으로 법적 결론을 내리면 안 된다. 원본 확보, 해시, 메타데이터, C2PA manifest, 분석 도구 버전 기록이 함께 필요하다.

## 연결 개념
- AI 워터마킹 - 생성 단계 표식 삽입 방식
- C2PA 콘텐츠 진위 표준 - 출처·편집 이력을 서명으로 검증
- 디지털 포렌식 - 원본 보존, 해시, 증거능력, 분석 재현성

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.
> 핵심: 딥페이크 탐지는 모델 점수 하나가 아니라 멀티모달 분석, 원본 증적, 판정 임계값, human review를 결합한 위험 판단임.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 딥페이크 탐지는 합성·변조된 영상·이미지·음성에서 생체·주파수·압축·동기화 이상을 찾아 위조 가능성을 판정하는 기술임.
> 2. **가치**: 사칭, 허위정보, 증거 위조, 금융사기에서 신원 확인과 콘텐츠 신뢰 판단의 증거를 제공함.
> 3. **판단 포인트**: 탐지율, 오탐률, 신규 생성기 일반화, 압축 저항성, 증거 보존 절차를 함께 평가해야 함.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 딥페이크 공격면 이해 | face swap, lip-sync, voice cloning, replay attack | 이미지 탐지만 쓰고 음성·영상 동기화 누락 |
| 탐지 기술 분류 | spatial, frequency, temporal, audio-visual, provenance | "AI로 탐지" 수준의 추상 표현 |
| 운영·증거 판단 | threshold, FPR/FNR, chain of custody, human review | 모델 점수를 법적 사실로 단정 |

> 요약: 이 문제는 딥페이크를 기술 탐지와 포렌식 증거 관리 관점에서 동시에 설명해야 함.

---

## Ⅰ. 개요 및 필요성

딥페이크 탐지는 AI 합성 콘텐츠 판별 기술임. 생성형 AI로 얼굴·음성·영상이 정교하게 합성되면서 사칭, 허위정보, 영상 증거 위조 위험이 증가한다. 탐지는 생체 특징, 시공간 일관성, 음성 스펙트럼, 출처 증적을 결합해 위조 가능성을 정량 판단한다.

---

## Ⅱ. 구조 및 구성요소

```text
Media Input -> Preprocessing -> Feature Extraction -> Detection Model -> Risk Score
                    +-> Provenance Check
                    +-> Human Review
                    +-> Evidence Store
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Preprocessing | 얼굴 검출, 프레임 샘플링, 음성 분리 | fps, 해상도, codec 기록 |
| Feature Extraction | 픽셀·주파수·시간·음성 특징 추출 | FFT, landmark, spectrogram |
| Detection Model | 위조 확률과 신뢰구간 산출 | CNN, ViT, Audio-Visual Transformer |
| Provenance Check | 원본 출처·편집 이력 확인 | C2PA, EXIF, hash |
| Evidence Store | 분석 로그와 원본 보존 | chain of custody, WORM 저장 |

> 요약: 딥페이크 탐지 구조는 특징 분석 모델과 출처 검증, 증거 보존을 결합해야 함.

---

## Ⅲ. 동작원리 및 흐름도

```text
콘텐츠 수집 -> 원본성 확인 -> 특징 추출 -> 모델 추론
-> 임계값 판정 -> 전문가 검토 -> 증거 기록
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 원본 파일·메타데이터·해시 확보 | SHA-256, 촬영기기, codec |
| 2 | 얼굴·음성·프레임 전처리 | 얼굴 검출률, 음성 SNR, fps |
| 3 | 시각·음성·동기화 특징 추출 | landmark jitter, spectrum artifact, lip-sync |
| 4 | 모델 점수와 임계값 판정 | AUC, FPR 1% 이하, confidence |
| 5 | 전문가 검토와 증거 보존 | 분석 도구 버전, chain of custody |

> 요약: 딥페이크 탐지는 원본 보존에서 시작해 특징 추출, 모델 판정, 전문가 검토로 결론의 재현성을 확보함.

## Ⅳ. 특징

| 구분 | 단일 모델 탐지 | 멀티모달 딥페이크 탐지 | 수치·표준 포인트 |
|:---|:---|:---|:---|
| 분석 대상 | 이미지 픽셀 중심 | 얼굴, 음성, 시간축, provenance | audio-video sync 200ms |
| 일반화 | 학습 생성기에 민감 | 모델 앙상블과 도메인 적응 | cross-dataset AUC 0.90 이상 |
| 한계 | 압축·재촬영에 취약 | 증거 보존·human review 병행 | FPR 1% 이하 |
| 운영 | 일괄 차단 | 점수 기반 재인증·검토 | threshold tier, SLA 24시간 |

> 요약: 딥페이크 탐지는 멀티모달 분석과 출처 증적을 결합해야 신규 생성기와 변환 공격에 대응할 수 있음.

## Ⅴ. 심화 비교 및 적용 판단

|:---|:---|:---|:---|

| 보완 | 워터마크 확인 | 워터마크 없는 콘텐츠도 분석 | 미표시 콘텐츠와 외부 유입 영상 |
| 증거 | 모델 점수 | 원본 hash+C2PA+분석 로그 | 법적 분쟁·감사 대응 필요 |
| 운영 | 차단/허용 이분법 | 위험 등급별 재인증·검토 | FPR 비용이 큰 금융·공공 서비스 |

> 요약: 딥페이크 탐지는 자동 차단보다 위험 점수와 증거 체인을 기반으로 단계별 대응을 설계해야 함.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 오탐 피해 | 조명·압축·저해상도 데이터 편향 | threshold calibration, human review | FPR 1% 이하 |
| 미탐 | 신규 생성기, screen capture, re-encoding | cross-dataset 학습, 변환 공격 테스트 | 공격 후 탐지율 90% 이상 |
| 증거 훼손 | 원본 없이 캡처본만 분석 | 원본 수집, SHA-256, WORM 저장 | 원본 확보율 95% 이상 |
| 실시간 지연 | 프레임·음성 분석 비용 | 샘플링, edge inference, batch review | p95 판정 2초 이하 |

> 요약: 운영 리스크는 오탐·미탐·증거 훼손·지연이며, 임계값과 증거 보존으로 통제함.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 탐지 정확도 | AUC 0.95 이상, FPR 1% 이하 | 검증셋, ROC/PR curve |
| 일반화 | 미학습 생성기 데이터 AUC 0.90 이상 | cross-generator benchmark |
| 포렌식 증적 | hash, tool version, analyst id 100% 기록 | chain of custody audit |
| 대응 시간 | 고위험 콘텐츠 검토 SLA 24시간 이하 | ticket timestamp, review queue |

> 요약: 딥페이크 탐지 체계는 정확도뿐 아니라 일반화, 증거성, 대응 시간을 함께 측정해야 함.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 - 단계별 또는 항목별):**
1. 멀티모달 탐지 구성: 얼굴·음성·lip-sync·주파수 특징을 앙상블하고 C2PA·EXIF 검증을 병행
2. 판정 정책 수립: risk score 0.8 이상은 재인증, 0.6~0.8은 human review, FPR 1% 이하로 threshold 조정
3. 증거 보존 운영: 원본 SHA-256, 분석 모델 버전, reviewer id, 판정 사유를 WORM 저장소에 1년 이상 보관

**결론 (2줄):**
- 기술사 판단: 실시간 인증은 낮은 지연 모델을, 법적·언론 검증은 포렌식 증적과 전문가 검토를 우선함
- 향후 방향: 딥페이크 탐지는 워터마킹, C2PA, 멀티모달 포렌식이 결합된 콘텐츠 신뢰 평가로 발전함
