## 미리 알고가기

- 딥페이크는 실제 사람의 얼굴, 음성, 움직임을 합성하거나 조작한 미디어를 말함
- 생체 징후 검사는 눈 깜박임, 입 모양, 음성 떨림처럼 실제 사람의 흔적을 보는 방법임
- 출처 검증은 콘텐츠가 어디서 생성되고 어떻게 수정되었는지 기록을 확인하는 방식임

## Ⅰ. 개요

- **정의/개념**: 딥페이크 탐지는 영상, 이미지, 음성 안의 합성 흔적이나 출처 정보를 분석해 조작 여부를 판별하는 기술임
- **배경/필요성**: 신원 사칭, 허위 정보, 금융 사기가 늘면서 콘텐츠 자체를 분석하는 탐지와 제작 이력을 확인하는 검증을 함께 갖출 필요가 커짐

## Ⅱ. 특징

- 영상, 이미지, 음성마다 탐지 신호가 달라 다중 기법 조합이 필요함
- 새 생성 모델이 나오면 기존 탐지기가 빠르게 약해질 수 있음
- 높은 탐지율만큼 오탐과 누락을 함께 관리해야 실무에 쓸 수 있음
- 콘텐츠 분석만으로 한계가 있어 출처 검증 기술과 같이 쓰는 편이 안전함

## Ⅲ. 종류 및 비교

| 판단 기준 | 콘텐츠 기반 탐지 | 출처 기반 검증 |
|:---|:---|:---|
| 보는 대상 | 영상·음성 자체의 흔적 | 서명, 편집 이력, 생성 기록 |
| 장점 | 기존 파일에도 적용 가능함 | 원본과 편집 경로를 설명하기 쉬움 |
| 약점 | 새 모델 등장에 따라 성능이 흔들릴 수 있음 | 메타데이터가 없거나 지워지면 확인이 어려움 |
| 적합 환경 | 유통 중인 미디어 판별 | 촬영·편집 체계가 있는 조직 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 미디어 수집기 | 영상, 음성, 이미지를 받아 분석 대상으로 삼음 |
| 특징 추출기 | 프레임 일관성, 음성 패턴, 얼굴 경계 같은 신호를 뽑음 |
| 탐지 모델 | 합성 가능성을 점수로 계산함 |
| 출처 검증기 | 메타데이터와 서명과 이력을 따로 확인함 |
| 대응 정책 | 차단, 경고, 사람 검토 같은 후속 조치를 정함 |

```text
미디어 입력 -> 특징 추출 -> 탐지 점수 계산 -> 출처 검증 -> 차단 또는 사람 검토
```

## Ⅴ. 원리 및 절차 흐름도

```text
파일 수집 -> 시각·음성 특징 분석 -> 합성 점수 산출 -> 출처 정보 대조 -> 판정과 후속 조치
```

1. **파일 수집**: 분석할 영상이나 음성을 받아 옴
2. **특징 분석**: 얼굴 움직임, 음성 패턴, 프레임 연결성을 확인함
3. **합성 점수 산출**: 탐지 모델이 조작 가능성을 계산함
4. **출처 정보 대조**: 이력 정보가 있으면 함께 검증함
5. **후속 조치**: 차단하거나 사람 검토로 넘김

## Ⅵ. 실무 적용 및 유의점

1. 금융 본인확인과 콜센터 인증은 탐지 모델만 믿지 말고 생체 징후 검사와 사람 확인 절차를 함께 두고 잘못 통과시킨 비율과 정상 사용자를 잘못 막은 비율로 점검함
2. 미디어 플랫폼은 탐지 모델과 출처 검증을 같이 운영하고 우회 재현 성공률과 사람 검토 이관 비율로 확인함

## Ⅶ. 결론

- 딥페이크 탐지는 합성 흔적 찾기와 출처 확인을 함께 묶을 때 실무에서 버틸 수 있음
