## Ⅰ. 개요
- 정의: 데이터의 유용성을 유지하면서 개인의 프라이버시 침해 위험을 기술적으로 방지하고 최소화하는 모든 기술의 총칭임.
- 배경/필요성: AI, 클라우드 환경에서 대규모 개인정보 활용이 필수적이나 법적/사회적 프라이버시 침해 우려가 커지면서 기술적 해결책 요구.
- 출제 의도: 데이터 활용과 보호의 상충관계를 극복하기 위한 동형암호, 다자간계산, 차분 프라이버시 등 최신 PET의 원리와 적용 분야를 평가함.

## Ⅱ. 구성요소
+-------------------+       +-------------------+       +-------------------+
|   입력 데이터     | ----> |    PET 적용 엔진  | ----> | 프라이버시 보존   |
| (개인 민감정보)   |       | (동형암호/노이즈) |       | (안전한 분석결과) |
+-------------------+       +-------------------+       +-------------------+

| 구성요소 | 설명 | 비유 |
|---|---|---|
| 동형암호 (Homomorphic Encryption) | 암호화된 상태 그대로 덧셈, 곱셈 등 연산이 가능한 암호 기술 | 잠긴 금고 안에서 조립하기 |
| 안전한 다자간 계산 (SMC) | 서로 데이터를 공개하지 않고 여러 참여자가 공동의 계산 결과를 도출 | 서로 패를 안보고 점수 합산 |
| 차분 프라이버시 (Differential Privacy) | 데이터셋에 수학적 노이즈를 주입하여 특정 개인의 포함 여부 식별 방지 | 단체 사진에 흐림 효과 넣기 |

> 요약: 암호화된 연산, 분산 계산, 노이즈 추가 등을 통해 원본 노출 없이 데이터의 유의미한 분석을 수행함.

## Ⅲ. 절차
+-------------------+   +-------------------+   +-------------------+   +-------------------+
| 1. 데이터 수집    |-->| 2. PET 기법 적용  |-->| 3. 데이터 분석/연산 |-->| 4. 결과 도출/복호화|
+-------------------+   +-------------------+   +-------------------+   +-------------------+

1. 데이터 수집: 분석이 필요한 원본 개인정보 및 민감 데이터 확보
2. PET 기법 적용: 목적에 맞게 동형암호화 수행, 노이즈 주입(차분 프라이버시), 또는 비밀 공유(SMC) 설정
3. 데이터 분석/연산: 데이터가 비가시적인(암호화 또는 노이즈 포함) 상태에서 클라우드 등 환경에서 머신러닝이나 통계 연산 수행
4. 결과 도출/복호화: 도출된 최종 결과값만 복호화하거나 노이즈가 상쇄된 통계값을 추출하여 활용

> 요약: 원본 데이터를 보호 기법으로 감싼 뒤 연산을 수행하고, 안전한 결과값만 확인하여 프라이버시를 지킴.

## Ⅳ. 문제점
- 연산 성능 저하: 완전동형암호(FHE)의 경우 평문 연산 대비 막대한 컴퓨팅 파워와 처리 시간이 소요되어 실시간 처리에 한계
- 분석 정확도 감소: 차분 프라이버시 적용 시 과도한 노이즈 주입으로 인해 통계적, AI 학습 결과의 정확도 하락 발생
- 기술적 복잡성: SMC 등 분산 환경 구성 시 통신 오버헤드가 급증하고 구현 난이도 및 관리 비용이 매우 높음
- 표준화 미흡: 이기종 시스템 간 호환성 확보를 위한 PET 기술 구현 표준 및 검증 프레임워크가 아직 부족함

## Ⅴ. 개선방안
- 단기: 성능 제약이 적은 차분 프라이버시나 부분/제한적 동형암호를 우선 도입하여 비실시간 통계 및 분석에 활용
- 중기: 하드웨어 가속기(GPU/FPGA)를 활용한 동형암호 연산 속도 개선 및 최적화된 하이브리드 PET 아키텍처 설계
- 장기: 양자 내성 기반 PET 연구 및 재현 데이터(Synthetic Data) 기술과의 결합을 통해 성능과 프라이버시 동시 만족

## Ⅵ. 전망
- 글로벌 규제 강화에 대응하기 위해 빅테크 기업을 중심으로 클라우드 내 데이터 클린룸(Data Clean Room) 서비스에 PET 탑재가 기본화될 것임.
- 연합 학습(Federated Learning)과 PET가 결합되어 의료, 금융 등 초민감 데이터 연합 분석 생태계가 폭발적으로 성장할 전망임.
