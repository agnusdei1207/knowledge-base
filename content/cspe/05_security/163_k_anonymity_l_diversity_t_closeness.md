## 미리 알고가기

- 준식별자는 단독으로는 모호하지만 다른 정보와 결합되면 개인을 좁힐 수 있는 속성임
- 동질 집합은 같은 준식별자 값을 공유하도록 묶인 레코드 집단임
- 민감 속성은 질병, 소득, 신용처럼 노출되면 피해가 큰 정보 항목임

## Ⅰ. 개요

- **정의/개념**: k-익명성, l-다양성, t-근접성은 공개하거나 공유하려는 데이터에서 재식별 위험과 민감 정보 노출 위험을 줄이기 위해 동질 집합의 크기와 다양성과 분포 유사성을 통제하는 비식별 모델임
- **배경/필요성**: 단순히 이름만 지워도 준식별자 조합으로 개인을 다시 찾거나, 집단 안 민감 값이 한쪽으로 몰려 있으면 개인 상태를 유추할 수 있어 더 정교한 기준이 필요해짐

## Ⅱ. 특징

- k-익명성은 같은 준식별자 조합을 가진 사람이 최소 $k$명 이상 되게 만들어 재식별을 어렵게 함
- l-다양성은 각 집합 안에 서로 다른 민감 값이 충분히 들어가게 해 값 추정을 어렵게 함
- t-근접성은 집합 안 민감 값 분포가 전체 분포와 크게 다르지 않게 맞춰 편향 추론을 줄임
- 뒤로 갈수록 보호는 강해지지만 일반화와 억제가 늘어 데이터 활용성이 더 떨어질 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | k-익명성 | l-다양성 | t-근접성 |
|:---|:---|:---|:---|
| 막으려는 위험 | 준식별자 기반 재식별 | 집합 안 민감 값 단순 추정 | 집합 분포 편향에 따른 속성 추론 |
| 핵심 조건 | 같은 조합이 최소 $k$건 이상이어야 함 | 민감 값이 최소 $l$개 이상 다양해야 함 | 집합 분포와 전체 분포 차이가 임계값 $t$ 이하여야 함 |
| 강점 | 이해와 적용이 비교적 쉬움 | 동질 집합 내 값 쏠림을 줄임 | 분포 왜곡까지 통제해 보호 수준이 높음 |
| 한계 | 민감 값이 모두 같아도 통과할 수 있음 | 값 종류만 맞고 분포 편향은 남을 수 있음 | 계산과 튜닝이 복잡하고 정보 손실이 커질 수 있음 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 준식별자 집합 | 재식별에 쓰일 수 있는 속성을 묶어 어떤 필드를 일반화할지 정하는 기준임 |
| 동질 집합 | 같은 준식별자 범주로 묶인 레코드 그룹으로, 보호 모델의 직접 평가 대상임 |
| 민감 속성 | 질병명, 소득 구간처럼 보호해야 할 값을 뜻하며 다양성과 분포 평가의 기준이 됨 |
| 일반화와 억제 규칙 | 나이 구간화, 지역 축약, 희소 값 제거처럼 모델 조건을 맞추기 위한 변환 규칙임 |
| 임계값 파라미터 | $k$, $l$, $t$ 값을 어떻게 잡느냐에 따라 보호 수준과 정보 손실이 달라짐 |

```text
+-------------+    +-------------+    +-------------+    +-------------+
| 원본 데이터    | -> | 준식별자 선택  | -> | 동질 집합 생성 | -> | k/l/t 평가     |
+-------------+    +-------------+    +-------------+    +-------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
| 필드 선정      | -> | 일반화 적용    | -> | 집합 생성      | -> | 기준 검증      | -> | 재조정 및 공개  |
+-------------+    +-------------+    +-------------+    +-------------+    +-------------+
```

1. **필드 선정**: 재식별에 쓰일 수 있는 준식별자와 민감 속성을 정함
2. **일반화 적용**: 범주화와 억제를 통해 개별 레코드가 너무 쉽게 드러나지 않게 바꿈
3. **집합 생성**: 같은 준식별자 범위를 가진 레코드를 묶어 동질 집합을 만듦
4. **기준 검증**: 각 집합이 $k$, $l$, $t$ 조건을 만족하는지 계산함
5. **재조정 및 공개**: 기준을 못 맞추면 일반화를 더 하고, 만족하면 공개나 공유에 사용함

## Ⅵ. 실무 적용 및 유의점

1. 공공 데이터 개방은 단순 k-익명성만으로 끝내지 말고 민감 값 쏠림이 큰 경우 l-다양성이나 t-근접성까지 적용하며 재식별 시험 실패율과 정보 손실률을 함께 봐야 함
2. 희귀 질환이나 고소득처럼 분포가 치우친 데이터는 작은 집합이 쉽게 드러나므로 최소 집합 크기와 분포 편차를 함께 점검하고 과도한 일반화로 분석 가치가 무너지지 않는지도 확인해야 함

## Ⅶ. 결론

k-익명성·l-다양성·t-근접성은 모두 비식별 보호 모델이지만 막으려는 위험이 다르므로 데이터 분포와 민감도에 맞춰 단계적으로 적용해야 함.
