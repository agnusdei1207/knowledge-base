## 미리 알고가기

- 생체 인식은 지문, 얼굴, 홍채처럼 사람 몸의 특성을 이용해 본인 여부를 확인하는 방식임
- 서버가 원본 이미지를 저장하는 것이 아니라 특징점만 추출한 템플릿을 비교하는 구조가 일반적임
- 편리하지만 유출 시 비밀번호처럼 쉽게 바꿀 수 없다는 점이 가장 큰 차이임

## Ⅰ. 개요

- **정의/개념**: 생체 인식은 사용자의 신체적·행동적 특성을 측정해 등록 템플릿과 비교하고 본인 여부를 판단하는 인증 기술임
- **배경/필요성**: 비밀번호 분실, 재사용, 피싱 문제를 줄이고 기기 내장 보안 기능과 결합한 빠른 사용자 확인이 필요함

## Ⅱ. 특징

- 사용 편의성이 높고 기기 잠금 해제와 패스키 인증에 자연스럽게 결합됨
- 원본 대신 템플릿 비교를 사용해 저장 위험을 줄일 수 있음
- FAR과 FRR 사이의 균형을 잘못 잡으면 보안이나 편의 한쪽이 크게 나빠질 수 있음
- 생체 정보는 변경이 어려우므로 온디바이스 처리와 활성 탐지가 중요함

## Ⅲ. 종류 및 비교

| 판단 기준 | 지문 | 얼굴 | 홍채 |
|:---|:---|:---|:---|
| 장점 | 보급이 넓고 구현이 성숙함 | 비접촉식으로 편의성이 좋음 | 정확도가 높은 편임 |
| 한계 | 손상과 오염 영향 | 사진·영상 위조 대응 필요 | 센서 비용과 사용자 거부감 가능 |
| 적합 환경 | 모바일, 노트북 | 모바일, 출입 통제 | 고보안 물리 출입 환경 |
| 공통 과제 | 활성 탐지와 템플릿 보호가 중요함 | 활성 탐지와 템플릿 보호가 중요함 | 활성 탐지와 템플릿 보호가 중요함 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| Sensor | 생체 정보를 수집하는 장치임 |
| Feature Extraction | 원본에서 특징점을 추출해 템플릿으로 만듦 |
| Matcher | 새 입력과 등록 템플릿을 비교함 |
| Liveness and Secure Storage | 위조 방지와 안전한 저장을 담당함 |

```text
생체 수집 -> 특징 추출 -> 템플릿 저장 -> 인증 시 재수집 -> 비교 -> 허용/거부
```

## Ⅴ. 원리 및 절차 흐름도

```text
등록 -> 템플릿 생성/보관 -> 인증 요청 -> 새 입력 수집 -> 매칭과 활성 탐지 -> 결과 반환
```

1. **등록**: 사용자의 생체 데이터를 받아 템플릿을 만듦
2. **보관**: 템플릿을 안전한 영역에 저장함
3. **인증 요청**: 사용자가 생체 인증을 시도함
4. **매칭과 활성 탐지**: 위조 여부와 유사도를 함께 확인함
5. **결과 반환**: 임계값에 따라 허용 또는 거부함

## Ⅵ. 실무 적용 및 유의점

1. 모바일·업무 단말은 생체 인증을 FIDO와 함께 쓰고 온디바이스 처리, 활성 탐지, 템플릿 외부 반출 부재로 확인함
2. 출입 통제 같은 대량 이용 환경은 FAR와 FRR을 함께 보고 오인식·오거부 비율과 예외 처리 절차로 확인함

## Ⅶ. 결론

- 생체 인식은 편리한 인증 수단이지만 템플릿 보호와 활성 탐지와 오인식 관리까지 포함해 설계해야 안전하게 운영할 수 있음
