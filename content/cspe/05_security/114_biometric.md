## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 사용자 고유의 신체적·행위적 특성(지문·얼굴·홍채·음성 등)을 측정하여 신원을 확인하는 인증 기술임 |
| **배경/필요성** | 패스워드 분실·도용 문제를 해결하고, 소유 기반 인증의 분실 위험을 보완하기 위해 "본인 자체"를 인증 수단으로 활용함 |
| **출제 의도** | 생체 인식의 FAR·FRR 지표와 프라이버시·보안 이슈를 이해하는지 평가함 |

## Ⅱ. 구성요소
```
+----------+     +----------+     +----------+
| 센서     | --> | 특징추출  | --> | 매칭엔진  |
| (Capture)|     | (Template)|    | (Compare)|
+----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| 센서 | 지문 스캐너·카메라·홍채 스캐너 등으로 생체 원시 데이터를 수집함 | 사진 촬영기 |
| 특징 추출 | 원시 데이터에서 고유 특징점(Minutiae·특징벡터)을 추출하여 템플릿으로 변환함 | 사진에서 얼굴 윤곽·특징점 추출 |
| 매칭 엔진 | 추출된 템플릿을 등록 템플릿과 비교하여 유사도 점수를 산출하고 임계치로 판별함 | 수배 사진 대조 |

> 요약: 센서(수집) → 특징 추출(템플릿화) → 매칭(비교·판별)으로 생체 기반 신원을 확인함.

## Ⅲ. 절차
```
+------------+     +------------+
| 생체등록   | --> | 템플릿저장  |
| (Enroll)   |     | (암호화)   |
+------------+     +------------+
                        |
+------------+     +----+-------+
| 인증결과   | <-- | 실시간    |
| (허가/거부)|     | 매칭비교   |
+------------+     +------------+
```

1. 생체 등록: 사용자가 센서를 통해 생체 데이터를 제공하고, 특징점을 추출하여 템플릿을 생성함
2. 템플릿 저장: 템플릿을 암호화하여 Secure Element·서버에 안전하게 저장함
3. 실시간 매칭: 인증 시 새로 수집한 생체 데이터의 템플릿을 등록 템플릿과 비교함
4. 인증 결과: 유사도가 임계치 이상이면 허가, 미만이면 거부하고 시도 횟수를 제한함

> 요약: 등록(템플릿 생성) → 저장(암호화) → 매칭(비교) → 결과(허가/거부)로 생체 인증을 수행함.

## Ⅳ. 문제점
- 변경 불가: 생체 정보는 유출 시 변경이 불가능하여 영구적 피해가 발생함
- 위조 공격: 3D 프린팅 지문·사진·딥페이크 영상으로 생체 인식을 우회하는 스푸핑 공격이 존재함
- FAR/FRR 트레이드오프: 오수락율(FAR)을 낮추면 오거부율(FRR)이 증가하여 사용자 불편이 커짐

## Ⅴ. 개선방안
- (단기) 생체 활성 탐지: Liveness Detection으로 실제 사람의 생체인지 확인하여 스푸핑을 차단함
- (중기) 온디바이스 처리: 생체 데이터를 디바이스 TEE 내에서만 처리하여 서버 유출을 원천 방지함
- (장기) 취소 가능 생체: Cancelable Biometrics 기법으로 유출 시 새로운 변환 템플릿을 재발급함

## Ⅵ. 전망
- FIDO2 패스키와 생체 인증의 결합이 모바일·PC 인증의 기본이 되며, 3D 깊이 센서·행위 생체 분석으로 스푸핑 방어가 고도화될 전망임
