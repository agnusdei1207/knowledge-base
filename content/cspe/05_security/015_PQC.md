## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 양자 컴퓨터의 쇼어(Shor), 그로버(Grover) 알고리즘 공격으로부터 안전한 새로운 수학적 난제 기반의 암호 알고리즘임 |
| **배경/필요성** | 양자 컴퓨터가 실용화될 경우 현재의 비대칭 암호(RSA, ECC)가 수 시간 내에 붕괴될 위협에 선제적 대비 필요(SNDL 방어) |
| **출제 의도** | 격자 기반, 다항식 기반 등 새로운 암호학적 접근법과 NIST 표준화 동향에 대한 최신 기술 지식 평가 |

## Ⅱ. 구성요소
```text
+-------------------+      +-------------------+      +-------------------+
|  Lattice-Based    |      |   Hash-Based      |      | Multivariate-Based|
| (격자 최단거리 문제)+----->| (해시 함수 충돌)  +----->| (다변수 다항식)   |
+-------------------+      +-------------------+      +-------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| **격자 기반 (Lattice)** | 다차원 공간의 복잡한 격자점들 중에서 특정 기준에 가장 가까운 점을 찾는 난제를 이용함 | 얽히고설킨 3차원 정글짐의 최단 경로 |
| **해시 기반 (Hash-Based)** | 안전성이 검증된 단방향 해시 함수를 반복 활용하여 서명의 안전성을 보장하는 방식임 | 수만 번 덧칠한 지워지지 않는 서명 |
| **코드 기반 (Code-Based)** | 오류 정정 코드의 디코딩 과정이 지닌 NP-Hard 복잡성을 암호화에 응용한 기술임 | 심하게 왜곡된 난해한 암호문 해독 |

> 요약: 소인수분해가 아닌 양자 연산으로도 풀기 매우 어려운 다차원/다변수 수학 난제를 채택한 차세대 체계임.

## Ⅲ. 절차
```text
+----------------+   +----------------+   +----------------+   +----------------+
| 1. 알고리즘 선택|-->| 2. KEM 키 캡슐화|-->| 3. 디지털 서명 |-->| 4. 하이브리드  |
| (표준 ML-KEM등)|   | (공유 비밀 전달)|   | (ML-DSA 인증)  |   | (레거시 병행)  |
+----------------+   +----------------+   +----------------+   +----------------+
```
1. **알고리즘 선택**: 적용할 시스템 환경(키 크기, 연산 속도)에 적합한 NIST 표준 PQC 알고리즘을 선택함
2. **키 캡슐화(KEM)**: 기존 Diffie-Hellman 키 교환을 대체하여 양자 안전 기반으로 대칭키를 캡슐화하여 전달함
3. **디지털 서명 체계 전환**: 기존 RSA/ECDSA 서명을 양자 안전 서명 알고리즘(예: ML-DSA)으로 교체하여 무결성 확보
4. **하이브리드 병행 운영**: 전환 과도기 동안 기존 암호와 PQC를 이중으로 결합 적용하여 상호 보완적 안전성 유지

> 요약: 새로운 수학 알고리즘을 통해 키 교환과 서명 체계를 전면 교체하거나 기존 방식과 병행 적용하는 과정임.

## Ⅳ. 문제점
* **키 및 서명 크기의 폭증**: PQC 알고리즘은 기존 ECC 대비 키 길이와 서명 데이터 크기가 수십 배 이상 방대하여 대역폭 과소비 유발
* **연산 자원 소모 증가**: 제한된 환경(IoT, 스마트카드)에서는 무거운 연산량으로 인해 성능 저하와 전력 소모 극심
* **상호 운용성 및 검증 기간 부족**: 기존 프로토콜(TLS, IKE)에 PQC를 삽입하는 과정에서 호환성 충돌이 발생하며, 수학적 안전성 입증에 충분한 시간 필요

## Ⅴ. 개선방안
* **단기 방안 (하이브리드 암호 배포)**: 하나의 암호가 무력화되더라도 다른 하나가 보호하는 전통+양자 결합 하이브리드 방식으로 점진적 도입
* **중기 방안 (인프라 프로토콜 최적화)**: 커진 키 크기를 수용할 수 있도록 네트워크 단편화(Fragmentation) 설정 및 버퍼 사이즈를 최적화
* **장기 방안 (암호 민첩성 확보)**: 소스코드 수정 없이도 새로운 암호 알고리즘 모듈을 즉각 교체 가능한 암호 민첩성(Crypto Agility) 아키텍처 설계

## Ⅵ. 전망
* 2024년 NIST의 최종 표준안(FIPS 203, 204 등) 발표를 기점으로 전 세계 주요 기관과 금융권의 마이그레이션이 본격화됨
* 'Store Now, Decrypt Later'(수집 후 사후 해독) 공격에 대비해 기밀성이 장기간 요구되는 시스템부터 신속한 PQC 전환이 필수로 요구됨
