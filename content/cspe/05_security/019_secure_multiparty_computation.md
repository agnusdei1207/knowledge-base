## Ⅰ. 개요
- **정의**: 다수 참여자가 각자의 입력을 공개하지 않고 공동 연산 결과만 도출하는 프로토콜
- **배경/필요성**: 여러 기관이 데이터를 공유하지 않으면서도 공동 분석 결과를 얻어야 하는 상황이 증가함
- **비유**: 참가자들이 각자 봉인된 봉투에 급여를 넣고, 중개자 없이 평균만 계산하는 것과 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 프라이버시 보존 협업 이해 | 비밀 분산·불경의 전송 기반 구조 | 동형암호(018)와의 차이를 명확히 할 것 |

> 요약: 입력 비공개 상태에서 공동 연산 결과만 산출하는 프라이버시 보존 프로토콜임

## Ⅱ. 구성요소
```text
참여자 A --+
           |
참여자 B --+--> [MPC 프로토콜] --> 연산 결과(공동 출력)
           |
참여자 C --+
(각자의 입력은 타 참여자에게 비공개)
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 비밀 분산(Secret Sharing) | 입력값을 여러 조각으로 나누어 참여자에게 분배 | 지도를 찢어 각자 한 조각씩 보관 |
| 불경의 전송(OT) | 수신자가 선택한 값만 받고, 송신자는 어떤 값이 선택됐는지 모르는 프로토콜 | 자판기에서 어떤 음료를 선택했는지 점원이 모르는 것 |
| 가블드 회로(GC) | 논리 회로를 암호화하여 입력 없이 출력만 계산 가능하게 하는 기법 | 블랙박스에 입력을 넣으면 결과만 나오는 장치 |
| 검증 프로토콜 | 참여자의 부정 행위를 탐지하는 메커니즘 | 봉인 봉투의 위조 방지 장치 |

> 요약: 비밀 분산·불경의 전송·가블드 회로·검증 프로토콜로 구성됨

## Ⅲ. 절차
```text
입력 분산 --> 연산 수행 --> 결과 복원 --> 검증
```
- 1단계: 각 참여자가 자신의 입력을 비밀 분산 기법으로 조각내어 분배함
- 2단계: 분산된 조각들에 대해 MPC 프로토콜로 공동 연산을 수행함
- 3단계: 연산 결과 조각들을 결합하여 최종 출력을 복원함
- 4단계: 검증 프로토콜로 참여자의 부정 행위 여부를 확인함

> 요약: 입력분산-연산-복원-검증 4단계로 프라이버시 보존 연산을 수행함

## Ⅳ. 문제점
- 통신 오버헤드: 참여자 간 다수 라운드 통신이 필요하여 네트워크 비용이 높음
- 확장성 제한: 참여자 수 증가 시 통신량이 O(n^2) 이상으로 증가함
- 악의적 모델 비용: 악의적(malicious) 참여자를 가정하면 연산 비용이 급증함

> 요약: 통신 오버헤드·확장성·악의적 모델 비용이 실용화 장벽임

## Ⅴ. 개선방안
1. 단기: 전처리(preprocessing) 기법으로 온라인 통신 라운드 수 절감
2. 중기: 위임 연산(outsourced MPC)과 계층 구조로 참여자 확장성 확보
3. 장기: 동형암호(018 참조)·영지식 증명 결합으로 악의적 모델 연산 비용 절감

> 요약: 전처리·위임 연산·HE/ZKP 결합으로 장벽을 완화함

## Ⅵ. 전망
- 발전 방향: 연합학습·금융 공동 분석·의료 데이터 협업에 적용 확대
- 기술사적 판단: 데이터 3법 등 프라이버시 규제 강화로 수요가 지속 증가함
- 기술사 제언: 동형암호·차등 프라이버시와 조합한 PET 아키텍처를 설계할 필요
