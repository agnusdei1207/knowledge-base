## Ⅰ. 개요
- 정의: 스마트폰, 태블릿, 웨어러블 등 모바일 기기와 USIM 카드에 저장된 통화기록, 메시지, 위치정보, 앱 데이터 등을 추출하고 분석하는 포렌식 특화 분야임.
- 배경/필요성: 현대인 생활의 핵심 단말기로서 가장 방대한 개인/범죄 흔적이 남으며, 클라우드 동기화와 원격 삭제의 위협으로 즉각적 격리/보존 필요.
- 출제 의도: 물리적 디스크와 달리 운영체제의 보안(샌드박스, 칩셋 암호화) 제약을 뚫어야 하는 모바일 획득 기법(논리적/물리적)과 무결성 한계를 평가함.

## Ⅱ. 구성요소
+-------------------+       +-------------------+       +-------------------+
|  격리 및 차단     | ----> |  데이터 획득      | ----> |  데이터 파싱/분석 |
| (전파 차단 백)    |       | (논리적/물리적)   |       | (DB 복원, 앱 분석)|
+-------------------+       +-------------------+       +-------------------+

| 구성요소 | 설명 | 비유 |
|---|---|---|
| 네트워크 차단 | 원격 초기화(Wipe) 및 증거 변경을 막기 위해 패러데이 가방(Faraday Bag) 등으로 외부 전파 완전 차단 | 범죄 현장 외부 통신 차단막 설치 |
| 논리적 획득 (Logical) | 제조사 백업 API(ADB, iTunes 등)를 활용하여 OS가 허용하는 파일/폴더 수준의 데이터만 추출 | 도서관에서 대출 가능한 책만 빌리기 |
| 물리적 획득 (Physical) | JTAG, 칩오프(Chip-off), BootROM 취약점을 이용해 플래시 메모리 전체를 비트 단위 덤프 | 도서관 창고 문을 뜯고 통째로 복사 |

> 요약: 원격 삭제를 막기 위해 전파를 즉시 차단하고, OS API나 하드웨어 우회 기법으로 데이터를 추출해 분석함.

## Ⅲ. 절차
+-------------------+   +-------------------+   +-------------------+   +-------------------+
| 1. 현장 압수/격리 |-->| 2. 보안 해제 시도 |-->| 3. 데이터 획득    |-->| 4. 파싱 및 보고   |
+-------------------+   +-------------------+   +-------------------+   +-------------------+

1. 현장 압수/격리: 기기가 켜져있는지 확인하고(전원 유지), 네트워크를 차단(비행기 모드, 패러데이 백)하여 원격 초기화 방지
2. 보안 해제 시도: 화면 잠금(비밀번호, 생체인식) 및 파일 기반 암호화(FBE)를 해제하기 위해 포렌식 도구(Cellebrite 등)나 법적 권한 활용
3. 데이터 획득: 기기의 루트(Root) 권한 탈취 또는 물리적 덤프를 수행하거나, 불가능할 경우 API를 통한 논리적 획득 진행
4. 파싱 및 보고: 추출된 SQLite DB 등에서 삭제된 카카오톡 대화, 사진, 위치정보(GPS) 레코드를 복원 및 시각화하여 보고서 작성

> 요약: 네트워크를 끊은 채 단말기를 확보하여 잠금을 뚫고, 내부 DB를 추출한 뒤 삭제된 대화 등을 복구함.

## Ⅳ. 문제점
- 보안 칩셋 및 OS 암호화: iOS의 Secure Enclave, 안드로이드의 Knox 등 H/W 기반 암호화(FBE) 도입으로 잠금 해제가 사실상 불가능한 경우 발생
- 무결성 훼손 논란: 루팅(Rooting)이나 백도어 설치 등 물리적 덤프를 위해 기기 내부를 변형해야 하므로 원본 불변(무결성)의 원칙과 상충됨
- 방대한 앱 업데이트: 카카오톡, 텔레그램 등 수십만 개의 서드파티 앱들이 데이터베이스 구조를 잦게 변경하여 기존 분석 도구로 파싱 실패
- 원격 삭제의 즉시성: 수사관이 기기를 확보하기 찰나의 순간에 용의자가 MDM이나 클라우드를 통해 '기기 초기화' 명령을 내리면 복구 불가

## Ⅴ. 개선방안
- 단기: 현장 출동 시 켜진 상태(AFU: After First Unlock) 유지 및 전파 차단 수칙을 엄수하고, 취약점 패치 전 빠른 논리적 획득 진행
- 중기: 스마트폰 자체 분석 한계 시, 구글/애플 등 클라우드(iCloud 등)에 백업된 데이터에 대한 영장 기반의 '클라우드 포렌식' 병행
- 장기: 기존 무결성(원본 100% 동일) 개념을 완화하여, '수사 목적의 필수적 변경 이력(로그)을 남기면 증거 능력을 인정'하는 법적 기준 현실화

## Ⅵ. 전망
- 모바일 OS의 보안이 갈수록 강력해져 로컬 기기 자체를 뚫는 '물리적 획득'은 점차 어려워지고, '클라우드 계정 수집' 비중이 압도적으로 늘어날 것임.
- 딥페이크, 암호화폐 지갑 앱 등에 특화된 비정형 데이터 분석 및 포렌식 AI 알고리즘 시장이 폭발적으로 성장할 전망임.
