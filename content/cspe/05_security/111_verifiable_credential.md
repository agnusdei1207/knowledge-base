## Ⅰ. 개요
- **정의**: 발급자가 디지털 서명한 자격증명을 검증자가 발급자에 연락 없이 암호학적으로 검증 가능한 표준 데이터 포맷임
- **배경/필요성**: 종이 증명서는 위변조 탐지가 어렵고, 중앙 기관 의존으로 국경 간 검증이 비효율적이므로 탈중앙 방식의 디지털 증명 체계가 필요함
- **비유**: 졸업장에 위변조 방지 홀로그램 + QR코드를 넣어, 학교에 전화하지 않아도 진위를 확인할 수 있는 것과 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| W3C VC 표준과 DID 연계 이해 | 3자 모델(발급자-보유자-검증자) 구조 | VP(Verifiable Presentation)와 VC 구분 |

> 요약: VC는 발급자 서명 기반으로 검증자가 독립적으로 진위를 확인할 수 있는 디지털 자격증명 표준임

## Ⅱ. 구성요소
```text
Issuer --서명발급--> Holder --VP제출--> Verifier
                       |                    |
                    Wallet               DID Resolver
                       |                    |
                 VC 보관/관리         공개키 조회/서명 검증
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| Issuer | 자격증명 생성 후 DID 기반 서명을 수행하는 발급 주체 | 졸업장 발급 학교 |
| Holder | VC를 지갑에 보관하고 필요 시 VP로 가공하여 제출하는 소유자 | 졸업장 소지자 |
| Verifier | DID Document의 공개키로 서명을 검증하는 수신 주체 | 입사 서류 확인 담당자 |
| VC Data Model | claims, proof, metadata로 구성된 W3C 표준 JSON-LD 구조 | 증명서 양식 |
| VP (Verifiable Presentation) | 하나 이상의 VC를 묶어 검증자에게 제시하는 패키지 | 서류 봉투 |

> 요약: 발급자-보유자-검증자 3자 구조에서 VC를 VP로 포장하여 서명 기반 독립 검증을 수행함

## Ⅲ. 절차
```text
DID 등록 -> VC 발급 -> VP 생성 -> 서명 검증
```
- 1단계: Issuer와 Holder가 각각 DID를 생성하고 분산 원장에 DID Document를 등록함
- 2단계: Issuer가 Holder의 DID에 대해 claims를 작성하고 자신의 개인키로 서명하여 VC를 발급함
- 3단계: Holder가 검증 요청 시 VC를 VP로 포장하고 자신의 개인키로 추가 서명하여 Verifier에 제출함
- 4단계: Verifier가 DID Resolver로 Issuer/Holder의 공개키를 조회하여 VP와 VC의 서명을 각각 검증함

> 요약: DID 등록 후 VC 발급, VP 포장, 서명 검증의 4단계로 탈중앙 자격증명 검증이 완료됨

## Ⅳ. 문제점
- 폐기 확인 지연: VC는 오프라인 검증이 가능하므로 발급 후 자격이 취소되어도 검증자가 인지하지 못할 수 있음
- 지갑 분실 시 복구 난이도: 개인키 기반이므로 지갑 백업이 없으면 모든 VC에 접근 불가함
- 상호운용성 미성숙: VC 포맷(JSON-LD vs JWT)과 DID Method가 다양하여 시스템 간 호환이 제한적임

> 요약: 폐기 확인 지연, 키 복구 난이도, 포맷 파편화가 VC 확산의 주요 장벽임

## Ⅴ. 개선방안
1. 단기: Status List 2021 등 VC 상태 조회 표준을 적용하여 폐기 여부를 실시간 확인함
2. 중기: Social Recovery 또는 다중 기기 키 분산 백업 체계를 도입하여 키 분실 위험을 완화함
3. 장기: W3C VC Data Model 2.0과 DID Core 통합 프로파일 표준화를 통해 상호운용성을 확보함

> 요약: 상태 조회 표준, 키 복구 체계, 프로파일 통합으로 VC 생태계 성숙도를 높여야 함

## Ⅵ. 전망
- 발전 방향: 모바일 운전면허증(mDL), 디지털 여권 등 공공 분야 VC 적용이 가속화될 전망임
- 기술사적 판단: DID/VC 연계 구조는 개인정보 자기결정권 실현의 핵심 인프라로 자리잡을 것임
- 기술사 제언: 조직은 VC 기반 신원 확인 체계 도입 시 기존 PKI와의 연계 로드맵을 수립해야 함
