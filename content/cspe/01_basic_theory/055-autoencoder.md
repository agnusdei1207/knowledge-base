## Ⅰ. 개요
- **정의**: 입력 데이터를 저차원으로 압축했다가 원래 입력과 똑같이 복원하도록 학습하는 비지도 신경망임.
- **배경/필요성**: 데이터의 핵심 특징 추출, 차원 축소, 노이즈 제거 및 이상 탐지를 위해 고안됨.
- **출제 의도**: 인코더와 디코더의 병목 구조 역할과 재구성 오차(Reconstruction Error)의 개념을 평가함.

## Ⅱ. 구성요소
```text
+------------------+       +------------------+       +------------------+
| Original Input   | ----> | Bottleneck       | ----> | Reconstructed    |
| (Encoder)        |       | (Latent Vector)  |       | (Decoder)        |
+------------------+       +------------------+       +------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 인코더 (Encoder)| 고차원 입력을 저차원의 잠재 벡터로 압축 | 압축 프로그램 |
| 잠재 벡터 (z) | 데이터의 가장 중요한 특징만 남은 병목 구간 표현 | 압축 파일 |
| 디코더 (Decoder)| 잠재 벡터를 원래의 입력 차원으로 복원 | 압축 해제 프로그램 |

> 요약: 입력을 압축(인코더)하고 다시 복원(디코더)하면서 가장 중요한 특징을 학습함.

## Ⅲ. 절차
```text
+-------------+   +-------------+   +-------------+   +-------------+
| 1. 데이터   |-->| 2. 잠재공간 |-->| 3. 입력     |-->| 4. 재구성   |
|    입력     |   |    압축     |   |    복원     |   |    오차계산 |
+-------------+   +-------------+   +-------------+   +-------------+
```
1. **데이터 입력**: 레이블이 없는 원본 데이터(이미지 등)를 네트워크에 주입함.
2. **잠재공간 압축**: 인코더 층을 통과하며 차원이 줄어들어 정보가 벡터로 요약됨.
3. **입력 복원**: 디코더 층을 거치며 차원을 확장하여 원본 데이터를 생성함.
4. **재구성 오차계산**: 원본과 복원 결과 간의 차이를 Loss로 삼아 가중치를 업데이트함.

> 요약: 입력을 압축 후 복원하도록 유도하여 재구성 오차를 최소화함.

## Ⅳ. 문제점
- **항등 함수 위험**: 병목이 넓으면 의미 있는 특징 추출 없이 입력을 복사하는 모델이 됨.
- **생성 모델 한계**: 잠재 공간이 연속적이지 않아 유의미한 새 데이터를 생성하기 어려움.

## Ⅴ. 개선방안
- **항등 함수 위험**: (단기) 노드 수 축소 / (장기) Denoising Autoencoder 등 적용 필요.
- **생성 모델 한계**: (단기) 잠재 공간 군집화 / (장기) VAE를 도입해 확률 분포로 학습 필요.

## Ⅵ. 전망
- 전처리/이상탐지에 널리 쓰이며, VAE와 확산 모델을 결합한 형태로 생성형 AI의 기반이 됨.
