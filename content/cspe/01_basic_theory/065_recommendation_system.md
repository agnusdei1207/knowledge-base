# 065. 추천 시스템 — 협업 필터링·콘텐츠 기반 (Recommendation System) [출제: 131회]

## 1. 개요

- **정의/개념**: 방대한 아이템 중 사용자의 과거 행동 이력이나 선호도 정보를 분석하여, 사용자가 관심을 가질만한 최적의 아이템을 선별하고 순위를 매겨 제공하는 정보 필터링 기술임
- **배경/필요성**: 정보 과잉 시대에 사용자의 탐색 비용을 줄이고 서비스 체류 시간 및 전환율(CVR)을 높이기 위해, 개인화된 사용자 경험(UX) 제공이 비즈니스 핵심 경쟁력으로 부상함

## 2. 특징 및 비교

| 판단 기준 | 콘텐츠 기반 필터링 (Content-based) | 협업 필터링 (Collaborative Filtering) | 하이브리드 추천 (Hybrid) |
|:---|:---|:---|:---|
| **추천 기준** | 아이템 자체의 속성(장르, 태그 등) | 사용자 간 유사도 및 행동 이력 | 콘텐츠 속성 + 협업 신호 결합 |
| **핵심 원리** | 사용자가 좋아했던 것과 유사한 것 | 비슷한 취향을 가진 타인이 본 것 | 두 방식의 가중치 합산/앙상블 |
| **장점** | 콜드 스타트 없음(신규 아이템 가능) | 아이템 속성 분석 불필요, 의외성 제공 | 각 방식의 단점 보완 및 정확도 |
| **단점** | 취향의 확장이 어려움(Over-specialized) | 콜드 스타트 문제, 희소성 문제 | 구현 및 연산 복잡도 높음 |

> 요약: 콘텐츠 기반은 아이템 특성에, 협업 필터링은 사용자 간 관계에 집중하며 실무에서는 이를 결합한 하이브리드 방식이 주류임

## 3. 구성요소/구조

- **구성요소**:
  - **Implicit Feedback**: 클릭, 시청 시간, 구매 이력 등 사용자가 간접적으로 표현한 선호도임
  - **Explicit Feedback**: 별점, 좋아요, 리뷰 등 사용자가 직접적으로 표현한 선호도임
  - **User-Item Matrix**: 사용자(Row)와 아이템(Column)의 상호작용 정보를 담은 희소 행렬임
  - **Matrix Factorization (MF)**: 고차원의 행렬을 저차원의 잠재 요인(Latent Factor)으로 분해하여 빈 공간(점수)을 예측함
  - **Candidate Generation (Recall)**: 수백만 개의 아이템 중 수백 개의 후보군을 빠르게 추출함
  - **Scoring & Ranking (Precision)**: 추출된 후보군에 대해 딥러닝 등을 활용해 정교한 순위를 매김

- **추천 파이프라인 구조도**:
```text
[Interaction Log] -> [Candidate Generation] -> [Scoring/Ranking] -> [Re-ranking/Filtering] -> [Top-K Recommendation]
       |                      |                       |                       |                       |
  (User/Item)         (Quick Filtering)       (Deep Learning)         (Diversity/Bias)        (Final UI)
```

## 4. 문제점 및 개선방안

1. **[콜드 스타트 (Cold Start)]**: 데이터가 없는 신규 사용자나 아이템에 대해 적절한 추천을 제공하지 못함
   - **개선방안**: 가입 시 선호도 설문을 수행하거나, 아이템의 메타 정보(텍스트, 이미지)를 활용한 콘텐츠 기반 추천을 병행함 (확인: 신규 유입 클릭률)
2. **[데이터 희소성 (Sparsity)]**: 사용자 수와 아이템 수에 비해 상호작용 데이터가 너무 적어 행렬 계산이 부정확함
   - **개선방안**: 행렬 분해(Matrix Factorization)나 딥러닝 기반 임베딩 기술을 사용하여 잠재적 상관관계를 학습함 (확인: 추천 커버리지)
3. **[필터 버블 (Filter Bubble)]**: 비슷한 취향의 정보에만 갇혀 새로운 발견(Serendipity)이 제한됨
   - **개선방안**: 추천 리스트에 무작위성을 부여하거나, 카테고리 다양성(Diversity) 지표를 모델 최적화 목표에 포함함 (확인: 카테고리 엔트로피)

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| **E-커머스 (Amazon/Coupang)** | "이 상품을 본 고객이 함께 본 상품" (아이템 기반 협업 필터링) | CVR (전환율), 장바구니 추가율 |
| **OTT (Netflix/YouTube)** | 시청 이력과 장르 정보를 결합한 딥러닝 기반 랭킹 알고리즘 | Retention (잔존율), 시청 시간 |
| **음악 스트리밍 (Spotify)** | 노래의 음향 특징과 사용자 플레이리스트 동시 분석 (하이브리드) | Discovery Weekly 재생 횟수 |

> 요약: 실무 추천 시스템은 단순한 예측을 넘어 노출 편향 제거와 비즈니스 목적(수익성 등)을 동시에 고려하여 설계됨

## 6. 결론

추천 시스템은 단순히 '좋아할 물건'을 찾는 것을 넘어, 사용자의 니즈를 선제적으로 파악하여 가치를 창출하는 지능형 서비스의 핵심임. 초기 통계적 방식에서 행렬 분해를 거쳐 현재는 딥러닝 기반의 Graph Neural Network(GNN)나 대형 언어 모델(LLM)을 활용한 시맨틱 추천으로 진화하고 있으며, 개인정보 보호와 윤리적 추천(알고리즘 투명성)이 향후 주요한 이슈가 될 전망임.
