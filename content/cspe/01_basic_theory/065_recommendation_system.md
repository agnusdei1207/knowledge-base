## Ⅰ. 개요
- 정의: 사용자의 과거 행동이나 선호도를 분석하여 연관성 높은 아이템을 제안하는 시스템임.
- 배경: 정보 과잉 시대에서 사용자의 의사결정 비용을 줄이기 위해 필수적임.
- 출제 의도:
| 분류 | 상세 |
| --- | --- |
| 핵심요소 | 협업 필터링(CF), 콘텐츠 기반(CB), 콜드 스타트 |
| 주요특징 | 개인화, 만족도 증대, 구매 전환율 향상 |

## Ⅱ. 구성요소
- ASCII 구조도
 [User] --- (Like) ---> [Item A]
    | (Similarity)         | (Similarity)
 [User'] -- (Recommend) -> [Item B]
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 협업 필터링 | 유사한 취향의 사용자 행동을 기반으로 추천 | 친구의 추천 |
| 콘텐츠 기반 | 아이템 자체의 속성을 분석하여 추천 | 장르별 추천 |
| 행렬 분해(MF) | 사용자-아이템 행렬을 잠재 요인으로 분해 | 퍼즐 맞추기 |
> 요약: 유사도 분석을 통해 사용자 맞춤형 정보를 제공하는 알고리즘임.

## Ⅲ. 절차
- ASCII 흐름도
[데이터 수집] -> [유사도 계산] -> [후보 생성] -> [랭킹/추천]
- 4단계 설명
1. 명시적/암시적 피드백: 평점, 클릭, 구매 등의 로그를 수집함.
2. 벡터화: 사용자나 아이템을 수치 벡터 공간으로 변환함.
3. 유사도 측정: 코사인 유사도 등을 통해 근접한 대상을 찾음.
4. 필터링: 이미 구매한 상품을 제외하고 상위 목록을 노출함.
> 요약: 행동 데이터 수집 후 유사도 기반으로 최적 리스트를 도출함.

## Ⅳ. 문제점
- 신규 사용자/아이템에 대한 정보 부족(Cold Start) 및 데이터 희소성(Sparsity)이 있음.

## Ⅴ. 개선방안
- 단기: 인기 품목 추천이나 인구통계학적 정보를 활용함.
- 중기: 하이브리드 추천(CF+CB) 방식을 도입하여 단점을 보완함.
- 장기: 그래프 신경망(GNN)을 적용해 복잡한 관계를 학습함.

## Ⅵ. 전망
- 이커머스, OTT를 넘어 초개인화된 금융, 의료 서비스로 영역이 확장됨.
