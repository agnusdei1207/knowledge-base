## 미리 알고가기

- 잠재 요인($Latent$ $Factor$): 사용자나 아이템의 숨겨진 특징을 나타내는 벡터 공간으로, 차원 축소를 통해 추출됨
- 하이브리드 추천($Hybrid$): 협업 필터링과 콘텐츠 기반의 장점을 수학적으로 결합하여 상호 보완하는 추천 방식임
- 필터 버블($Filter$ $Bubble$): 개인화 추천에 갇혀 자신의 취향에 맞는 정보만 편식하게 되는 정보 고립 현상임
- 암묵적 피드백($Implicit$ $Feedback$): 명시적인 별점 대신 클릭, 체류 시간, 스크롤 등 사용자의 무의식적 행동 로그임

## Ⅰ. 개요

- **정의/개념**: 추천 시스템은 사용자의 과거 행동 이력(클릭, 구매) 및 아이템의 메타데이터 속성을 수치적으로 분석하여, 사용자가 아직 발견하지 못한 최적의 맞춤형 콘텐츠를 선제적으로 제안하는 개인화 의사결정 모델임
- **배경/필요성**: 디지털 채널의 기하급수적인 팽창으로 정보의 과잉($Information$ $Overload$) 현상이 발생함에 따라, 소비자의 탐색 비용을 극적으로 낮추고 기업의 구매 전환율($CVR$)을 극대화하기 위해 도입됨

## Ⅱ. 특징

- 협업 필터링($Collaborative$ $Filtering$)은 "비슷한 성향의 사람들이 좋아한 것은 나도 좋아할 것이다"라는 가정 하에 사용자 간의 유사도 행렬을 구성하여 동작함
- 콘텐츠 기반 필터링($Content-based$)은 아이템 자체의 텍스트 특징이나 이미지 속성을 추출하고 사용자의 선호 프로필과 정밀 비교($Cosine$ $Similarity$ 등)하여 작동함
- 최근 추천 시스템의 실무는 대규모 후보군을 고속으로 압축하는 후보 생성($Retrieval$) 단계와 정교한 딥러닝 점수를 매기는 랭킹($Ranking$) 단계의 2-Stage 파이프라인 구조를 취함

## Ⅲ. 종류 및 비교

| 판단 기준 | 협업 필터링 (Collaborative) | 콘텐츠 기반 필터링 (Content-based) |
|:---|:---|:---|
| **필요 데이터** | 사용자-아이템 간의 상호작용 이력 | 아이템 메타데이터 (카테고리, 텍스트) |
| **추천 원리** | 다른 사용자들의 행동 유사성 기반 | 사용자가 과거 소비한 아이템과의 유사성 기반 |
| **장점** | 설명이 불가한 숨겨진 취향 발견 가능 | 새로운 아이템 추천 가능 (Cold Start 강함) |
| **한계점** | 신규 가입자/상품 추천 불가능 (Cold Start) | 유사한 카테고리만 맴도는 추천 (과도한 특화) |
| **대표 기법** | 행렬 분해 ($Matrix$ $Factorization$), $ALS$ | $TF-IDF$, $Word2Vec$, 코사인 유사도 |

> 요약: 협업 필터링은 '사람과 사람의 관계'에, 콘텐츠 기반은 '아이템 자체의 성격'에 집중함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 평점 행렬 ($R$) | $M$명의 사용자와 $N$개의 아이템 간의 상호작용을 기록한 고도로 희소($Sparse$)한 행렬임 |
| 임베딩 레이어 | 사용자 및 아이템을 동일 차원의 가상 공간 특징 벡터로 변환하는 표현 층임 |
| 후보군 탐색 ($Retrieval$) | 수백만 개의 상품 중 빠르게 연산하여 상위 수백 개의 후보만 추려내는 장치임 |
| 순위 매기기 ($Ranking$) | 딥러닝 다중 작업 모델($Multi-task$ $Model$)을 사용하여 최종 노출 순위를 정밀 계산함 |

```text
[ 추천 시스템 2-Stage 파이프라인 ]
[전체 아이템군 (Millions)] -> (Retrieval:CF, ANN) -> [후보군 (Hundreds)] -> (Ranking:DLRM, DeepFM) -> [최종 추천 리스트 (Tens)]
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 사용자 로그  | --> | 후보군 추출  | --> | 취향 점수연산| --> | 다양성 필터링|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **상호작용 수집** — 사용자의 클릭, 장바구니 담기, 체류 시간 등의 암묵적 피드백($Implicit$ $Log$)을 실시간으로 수집하여 가공함
2. **후보군 여과** — 근사 최근접 이웃($ANN$) 검색이나 협업 필터링을 사용하여 대량의 아이템 중 유망 후보군을 밀리초($ms$) 단위로 빠르게 추출함
3. **취향 랭킹 적용** — 딥러닝 신경망 모델(예: DeepFM)에 사용자 프로필과 후보 아이템의 변수들을 입력하여 예상 구매 전환 확률을 구함
4. **다양성 반영 및 정돈** — 계산된 확률 순서대로 정렬하되, 동일 카테고리 도배를 막기 위해 다양성($Diversity$) 알고리즘을 적용하여 사용자에게 노출함

## Ⅵ. 실무 적용 및 유의점

1. 신규 상품이나 가입자의 이력이 없는 '콜드 스타트($Cold$ $Start$)' 구동 문제를 방지하기 위해, 초기 회원가입 시 관심사를 수집하거나 협업 필터링과 콘텐츠 기반 기법을 결합한 '하이브리드 추천 기법'을 기본 아키텍처로 가져가야 함
2. 단순히 클릭 확률만 극대화하면 낚시성 기사나 자극적인 상품만 계속 추천되는 편향 문제가 생기므로, 추천 목록의 질적 평가를 위해 다양성($Diversity$), 참신성($Novelty$), 그리고 탐험($Exploration$) 지표를 균형 있게 설계해야 함

## Ⅶ. 결론

- 추천 시스템은 비즈니스의 매출과 고객의 플랫폼 락인($Lock-in$)을 주도하는 머신러닝의 총아이며, 설계자는 정확도 중심의 최적화 모델에 매몰되지 않고 다양성과 콜드 스타트 극복 방안을 입체적으로 결합해야 함
