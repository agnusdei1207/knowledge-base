## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 사용자 행동 이력이나 아이템 특성 데이터를 분석하여 개인화된 선호 상품이나 콘텐츠를 예측하고 제공하는 시스템임. |
| 배경/필요성 | 정보 과부하 시대에 사용자 탐색 비용을 절감하고, 플랫폼의 매출과 체류 시간을 증대시키기 위한 목적. |
| 출제 의도 | 사용자-아이템 상호작용 기반의 협업 필터링(CF)과 속성 기반 콘텐츠 추천의 장단점 비교 평가. |

## Ⅱ. 구성요소
```text
+-------------+    +-------------+
| User Matrix |    | Item Feature|
+-------------+    +-------------+
       |                  |
       +--------+---------+
                |
         +-------------+
         | Recommend   |
         +-------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 협업 필터링 (CF) | 다수 사용자의 행동 패턴(평점) 기반 추천 | 집단 지향적 조언 |
| 콘텐츠 기반 필터링 | 아이템 고유의 속성(장르, 텍스트) 분석 기반 추천 | 유사 상품 안내 |
| 하이브리드 추천 | CF와 콘텐츠 기반 방식의 장점을 혼합 결합 | 맞춤형 컨설팅 |

> 요약: 사용자 평점 이력과 아이템 속성을 상호 결합하여 개인화된 최적의 추천 리스트를 산출함.

## Ⅲ. 절차
```text
+----------+   +----------+   +----------+   +----------+
| Data Get |-> | Modeling |-> | Sim. Calc|-> | Rec List |
+----------+   +----------+   +----------+   +----------+
```
1. 데이터 수집: 사용자의 명시적(평점) 및 암시적(클릭, 시청) 피드백 수집함.
2. 매트릭스 구성: 사용자-아이템 간의 선호도 희소 행렬을 구축함.
3. 유사도 계산: 코사인 유사도 및 행렬 분해(Matrix Factorization)로 평점 예측함.
4. 리스트 생성: 예측 평점이 가장 높은 N개의 아이템을 추천 결과로 제시함.

> 요약: 데이터 수집 후 선호도 매트릭스를 모델링하고 사용자 간 유사도를 계산하여 추천을 제공함.

## Ⅳ. 문제점
- 시스템에 새롭게 진입한 사용자에 대한 행동 이력 부족으로 콜드 스타트 문제 발생
- 사용자-아이템 평가 행렬의 99% 이상이 비어있는 데이터 희소성(Sparsity) 존재
- 단편적인 과거 이력에만 의존하므로 사용자의 실시간 문맥(Context) 변화 반영 미흡

## Ⅴ. 개선방안
- [단기] 가입 초기 사용자의 관심사 태그를 수집하여 콘텐츠 기반 필터링 추천 우선 제공
- [중기] SVD, 잠재 요인 모델 등 행렬 분해 기법 적용으로 데이터 희소성 완화 및 채움 처리
- [장기] 딥러닝 기반 세션 추천 및 지식 그래프와 연계하여 실시간 맥락 맞춤형 추천 체계 고도화

## Ⅵ. 전망
- e커머스 및 OTT 플랫폼 경쟁력의 핵심 기술로서, 딥러닝과 결합한 실시간 초개인화 엔진으로 진화할 전망임.
