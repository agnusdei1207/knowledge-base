## 미리 알고가기

- 협업 필터링: 사용자와 아이템의 상호작용 패턴으로 선호를 추정함
- 콘텐츠 기반 추천: 아이템 속성과 사용자 프로필의 유사도로 추천함
- 콜드 스타트: 신규 사용자나 신규 아이템에 이력이 부족한 문제임
- 잠재 요인: 행렬 분해로 찾은 사용자·아이템의 숨은 성향 벡터임
- 암묵 피드백: 클릭, 구매, 체류 시간처럼 행동에서 얻는 선호 신호임

## Ⅰ. 개요

- **정의/개념**: 추천 시스템은 사용자 행동과 아이템 속성을 분석해 개인에게 적합한 아이템을 예측·제시하는 개인화 의사결정 모델임
- **배경/필요성**: 정보와 상품이 많아질수록 사용자의 탐색 비용을 줄이고 서비스 전환율을 높일 추천 기준이 필요함

## Ⅱ. 특징

- 사용자·아이템 관계를 수치화해 개인화 순위를 만듦
- 명시 평점보다 암묵 피드백을 더 많이 활용함
- 후보 생성과 랭킹을 분리해 대규모 아이템을 처리함
- 정확도뿐 아니라 다양성, 신선도, 공정성도 함께 고려함

## Ⅲ. 종류 및 비교

| 구분 | 협업 필터링 | 콘텐츠 기반 | 하이브리드 |
|:---|:---|:---|:---|
| 기준 데이터 | 사용자-아이템 이력 | 아이템 속성·문서 | 이력과 속성 결합 |
| 추천 원리 | 비슷한 사용자·아이템 탐색 | 과거 선호와 유사한 속성 탐색 | 상호 보완 |
| 장점 | 숨은 취향 발견 | 신규 아이템 대응 | 콜드 스타트 완화 |
| 한계 | 신규 사용자·아이템 취약 | 유사 항목 반복 | 구조와 튜닝 복잡 |
| 대표 기법 | 행렬 분해, kNN | TF-IDF, 임베딩 | 가중 결합, 랭킹 모델 |

> 요약: 협업 필터링은 이력, 콘텐츠 기반은 속성, 하이브리드는 결합 신호를 중심으로 추천함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 사용자 프로필 | 인구통계, 행동 로그, 관심사를 표현함 |
| 아이템 메타데이터 | 카테고리, 텍스트, 이미지, 가격 속성을 담음 |
| 상호작용 행렬 | 사용자와 아이템의 클릭·구매·평점을 기록함 |
| 후보 생성기 | 전체 아이템 중 추천 후보를 빠르게 줄임 |
| 랭킹 모델 | 후보별 전환 확률과 노출 순서를 계산함 |
| 피드백 루프 | 노출 후 행동을 다시 학습 데이터로 반영함 |

> 요약: 추천 품질은 사용자·아이템 데이터, 후보 생성, 랭킹, 피드백 순환이 함께 결정함.

```text
Logs/Profile + Item metadata
       -> Candidate generation
       -> Ranking model
       -> Recommendation list
       -> User feedback
       -> Update logs
```

## Ⅴ. 원리 및 절차 흐름도

```text
Collect logs -> Build features -> Retrieve candidates -> Rank items -> Serve and learn
```

1. 사용자 행동, 아이템 속성, 컨텍스트 정보를 수집함
2. 사용자·아이템 특징 벡터와 상호작용 행렬을 구성함
3. 협업 필터링이나 검색 기법으로 후보군을 좁힘
4. 랭킹 모델로 점수를 계산하고 노출 결과를 다시 반영함

> 요약: 추천은 후보 검색과 랭킹을 분리하고 사용자 피드백으로 최신 선호를 계속 반영함.

## Ⅵ. 실무 적용 및 유의점

1. 신규 사용자와 신규 아이템에는 협업 필터링 신호가 부족하므로 온보딩 선호 수집과 콘텐츠 기반 특징을 결합하고 초기 추천 클릭률로 검증함
2. 클릭률만 최적화하면 필터 버블과 편향 노출이 커지므로 다양성, 신선도, 장기 재방문율을 함께 지표로 둠

## Ⅶ. 결론

- 추천 시스템은 정확도와 탐색 다양성의 균형이 핵심이며, 데이터 이력 부족과 편향 증폭을 통제해야 실무 가치가 유지됨

## 작성 근거(검토용)

- 개요는 추천 시스템을 개인화 의사결정 모델로 정의해 사용자·아이템·목적을 한 문장에 넣음
- 특징은 대규모 추천의 실제 구조인 후보 생성과 랭킹 분리를 포함해 운영 관점을 보강함
- Ⅲ은 협업 필터링과 콘텐츠 기반을 중심으로 하이브리드를 추가해 콜드 스타트 대응 판단을 가능하게 함
- Ⅳ는 데이터, 후보 생성, 랭킹, 피드백 루프로 추천 시스템의 정적·순환 구조를 함께 설명함
- Ⅵ은 콜드 스타트와 필터 버블을 핵심 리스크로 선택해 성능 지표와 운영 지표를 연결함
