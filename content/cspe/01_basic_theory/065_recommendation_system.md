## 미리 알고가기

- 협업 필터링: 사용자와 아이템의 상호작용 패턴으로 선호를 추정함
- 콘텐츠 기반 추천: 아이템 속성과 사용자 프로필의 유사도로 추천함
- 콜드 스타트: 신규 사용자나 신규 아이템에 이력이 부족한 문제임
- 암묵 피드백: 클릭, 구매, 체류 시간처럼 행동에서 얻는 선호 신호임
- 후보 생성·랭킹: 추천 대상을 좁힌 뒤 사용자별 점수로 노출 순서를 정하는 단계임

## 작성 근거(검토용)

- 개요는 추천 시스템을 개인화 의사결정 모델로 정의해 사용자·아이템·목적을 한 문장에 담음
- 후보 생성과 랭킹 분리는 전체 아이템의 점수 계산 범위를 줄이는 핵심 구조임
- Ⅲ은 협업 필터링과 콘텐츠 기반을 중심으로 하이브리드를 추가해 콜드 스타트 대응 판단을 가능하게 함
- Ⅳ는 데이터, 후보 생성, 랭킹, 피드백 루프로 추천 시스템의 구조와 순환을 함께 설명함
- 콜드 스타트와 반복 노출은 성능 지표와 운영 지표를 함께 요구하는 핵심 위험임

## Ⅰ. 개요

- **정의/개념**: 추천 시스템은 사용자 행동과 아이템 속성을 분석해 개인에게 적합한 아이템을 예측·제시하는 개인화 의사결정 모델임
- **배경/필요성**: 사용자의 탐색 비용을 줄이고 서비스 전환율을 높이기 위해 개인화 추천 기준이 필요함

## Ⅱ. 특징

- 사용자·아이템 관계를 수치화해 개인화 순위를 산출함
- 명시 평점보다 암묵 피드백을 주로 활용함
- 후보 생성으로 전체 아이템 중 일부를 선별한 뒤 랭킹해 점수 계산 범위를 줄임
- 정확도뿐 아니라 다양성, 신선도, 공정성도 함께 평가함

## Ⅲ. 종류 및 비교

| 판단 기준 | 협업 필터링 | 콘텐츠 기반 | 하이브리드 |
|:---|:---|:---|:---|
| 추천 메커니즘 | 사용자-아이템 관계 모델링 | 콘텐츠 특징 유사도 | 추천 점수 결합 |
| 입력 범위 | 사용자·아이템 이력 | 아이템 속성 | 이력·속성 |
| 주요 리스크 | 콜드 스타트 | 속성 품질 의존 | 특정 신호 편중 |

> 요약: 협업 필터링은 이력, 콘텐츠 기반은 속성, 하이브리드는 결합 신호를 중심으로 추천함.

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 특징 데이터 | 사용자 프로필과 아이템 속성 |
| 상호작용 행렬 | 사용자별 클릭·구매·평점 이력 |
| 후보 생성기 | 전체 아이템을 줄인 추천 후보 집합 |
| 랭킹 모델 | 후보별 선호 점수와 노출 순위 |
| 피드백 루프 | 노출 후 행동의 재학습 경로 |

> 요약: 추천 시스템은 사용자·아이템 데이터로 후보를 생성·랭킹하고 노출 반응을 재학습해 개인화 순위를 갱신함.

## Ⅴ. 원리 및 절차 흐름도

```text
로그 수집 -> 특징 구성 -> 후보 검색 -> 아이템 랭킹 -> 노출 결과 수집·재학습
```

1. 사용자 행동, 아이템 속성, 컨텍스트 정보를 수집함
2. 사용자·아이템 특징 벡터와 상호작용 행렬을 구성함
3. 협업 필터링이나 검색 기법으로 후보군을 좁힘
4. 랭킹 모델로 점수를 계산하고 노출 결과를 다시 반영함

> 요약: 추천은 후보 검색과 랭킹을 분리하고 사용자 피드백으로 최신 선호를 계속 반영함.

## Ⅵ. 실무 사례

1. 신규 아이템 추천은 콘텐츠 특징으로 이력 부족을 보완하고 초기 클릭률을 확인함
2. 추천 랭킹은 다양성·신선도 제약을 적용하고 반복 노출률·장기 재방문율로 검증함

## Ⅶ. 결론

- 추천 방식은 이력·속성의 가용성에 따라 선택하고 정확도·다양성·재방문율로 검증해야 함
