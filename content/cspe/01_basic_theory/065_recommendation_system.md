## 미리 알고가기

- 사용자-아이템 행렬: 사용자 선호를 행렬 형태로 표현한 것임
- cold start: 사용자나 아이템 정보가 부족해 추천이 어려운 상태임
- ranking metric: 추천 순서 품질을 측정하는 지표임

## Ⅰ. 개요

- **정의/개념**: 추천 시스템은 사용자 행동, 아이템 속성, 상호작용 패턴을 분석해 다음에 관심 가질 가능성이 높은 항목을 제안하는 개인화 의사결정 시스템임
- **배경/필요성**: 정보 과잉 환경에서는 사용자가 모든 콘텐츠를 직접 탐색할 수 없으므로 선호도 기반 자동 선별이 필요함

## Ⅱ. 특징

- 협업 필터링은 유사 사용자나 잠재 요인으로 선호를 예측함
- 콘텐츠 기반 추천은 아이템 속성과 사용자 프로필을 비교함
- 실제 서비스는 두 방식을 혼합한 하이브리드가 많음
- cold start, 편향 강화, 다양성 부족이 대표 운영 이슈임

## Ⅲ. 종류 및 비교

| 판단 기준 | 협업 필터링 | 콘텐츠 기반 |
|:---|:---|:---|
| 입력 정보 | 사용자 행동 이력 | 아이템 속성 |
| 장점 | 숨은 취향 발견 | 신규 아이템 대응 |
| 단점 | cold start 약함 | 과도한 유사 추천 |
| 대표 기법 | 행렬분해, neighborhood | TF-IDF, 임베딩 매칭 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 사용자 프로필 | 클릭, 구매, 평가 이력이며 선호 학습 기반임 |
| 아이템 특징 | 카테고리, 텍스트, 이미지 등이며 콘텐츠 기반 입력임 |
| 후보 생성 | 추천 후보를 좁히는 단계이며 대규모 서비스 핵심임 |
| 랭킹 모델 | 최종 순위를 정하고 CTR, CVR 최적화 축임 |

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 행동수집 | --> | 후보생성 | --> | 점수계산 | --> | 순위추천 |
+----------+     +----------+     +----------+     +----------+
```

1. **행동수집**: 클릭, 구매, 체류시간 등 상호작용을 모음
2. **후보생성**: 유사 사용자, 유사 아이템 등으로 후보를 뽑음
3. **점수계산**: 선호도를 예측하거나 랭킹 점수를 계산함
4. **순위추천**: 다양성과 비즈니스 규칙을 반영해 노출함

## Ⅵ. 문제점 및 해결 방안

1. 문제: cold start가 발생해 신규 사용자/아이템 정보가 부족함
   - 해결방안: 콘텐츠 특징, 인기 기반, 탐색 노출을 병행하고 cold-start CTR로 검증함
2. 문제: 편향 강화와 필터 버블이 생겨 비슷한 항목만 반복 추천됨
   - 해결방안: 다양성, 신선도, 탐색 비율을 제어하고 diversity score로 검증함
3. 문제: 오프라인 성능과 온라인 반응이 다를 수 있어 순위 지표와 실제 행동이 불일치함
   - 해결방안: A/B 테스트와 counterfactual evaluation을 병행하고 online CTR/CVR로 검증함

## Ⅶ. 적용 사례

- 이커머스에서는 구매 이력 기반 상품 추천을 제공함, 확인 지표는 CTR과 매출 uplift임
- OTT/음원 서비스에서는 콘텐츠 소비 패턴으로 개인화 추천함, 확인 지표는 시청 지속시간임
- 지식 검색에서는 유사 문서와 관심 주제를 연결함, 확인 지표는 클릭 만족도임

## Ⅷ. 결론

추천 시스템의 핵심은 예측 점수보다 사용자 경험 균형에 있으므로, 정확도와 함께 다양성, 신선도, cold start 대응을 같이 설계해야 함.
