## Ⅰ. 개요
- **정의**: 사용자 행동 이력과 아이템 속성을 분석하여 개인화된 선호 항목을 예측·제공하는 시스템임
- **배경/필요성**: 정보 과부하 환경에서 사용자 탐색 비용을 절감하고 플랫폼 전환율·체류 시간을 향상시킬 필요
- **비유**: 단골 고객의 취향을 기억하여 신메뉴를 먼저 권하는 음식점 주인

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| CF와 콘텐츠 기반 필터링의 원리 비교 | 사용자-아이템 행렬 분해(MF) 기법 | 콜드 스타트 문제의 원인과 대응 전략 누락 시 감점 |

> 요약: 협업 필터링과 콘텐츠 기반 필터링을 결합하여 개인화 추천을 제공하는 핵심 시스템임

## Ⅱ. 구성요소
```text
+-----------+     +-----------+     +-----------+
| User      | --> | Filtering | --> | Top-N     |
| Behavior  |     | Engine    |     | Recommend |
+-----------+     +-----------+     +-----------+
      |                 |
+-----------+     +-----------+
| Item      |     | Hybrid    |
| Metadata  |     | Combine   |
+-----------+     +-----------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 협업 필터링(CF) | 유사 사용자(User-based) 또는 유사 아이템(Item-based)의 평점 패턴을 활용한 추천 | 친구 추천 |
| 콘텐츠 기반 필터링 | 아이템의 메타데이터(장르, 키워드, TF-IDF 벡터) 유사도 기반 추천 | 유사 상품 안내 |
| 행렬 분해(MF) | 사용자-아이템 희소 행렬을 잠재 요인 행렬의 곱으로 분해하여 미관측 평점 예측 | 숨은 취향 추출 |
| 하이브리드 결합 | CF와 콘텐츠 방식을 가중 결합하여 상호 약점을 보완하는 통합 전략 | 복합 컨설팅 |

> 요약: 사용자 행동과 아이템 속성을 행렬 분해로 결합하고 하이브리드 전략으로 추천 정확도를 향상시킴

## Ⅲ. 절차
```text
+-----------+     +-----------+     +-----------+     +-----------+
| Feedback  | --> | Matrix    | --> | Similarity| --> | Top-N     |
| Collect   |     | Build     |     | Compute   |     | Serve     |
+-----------+     +-----------+     +-----------+     +-----------+
```

1. **피드백 수집** — 명시적(평점, 좋아요) 및 암시적(클릭, 시청 시간, 구매) 신호를 로깅
2. **행렬 구축** — 사용자×아이템 평점 희소 행렬 구성, 결측치 비율 통상 99% 이상
3. **유사도 산출** — 코사인 유사도, 피어슨 상관, ALS/SVD 기반 잠재 요인 분해 수행
4. **추천 제공** — 예측 평점 상위 N개 아이템을 사용자에게 랭킹 순으로 노출

> 요약: 피드백을 수집하여 희소 행렬을 구축하고 유사도·행렬 분해로 Top-N 추천 리스트를 산출함

## Ⅳ. 문제점
- **콜드 스타트**: 신규 사용자·아이템에 대한 상호작용 이력 부재로 추천 불가
- **데이터 희소성**: 사용자-아이템 행렬의 99%+ 결측으로 유사도 산출 신뢰도 저하
- **문맥 반영 부재**: 시간·위치·세션 등 실시간 맥락을 반영하지 못하여 추천 적시성 하락

> 요약: 콜드 스타트, 희소 행렬, 실시간 문맥 미반영이 추천 품질의 3대 제약임

## Ⅴ. 개선방안
1. 단기: 신규 사용자에게 관심사 태그 온보딩 + 인기도 기반 폴백(Fallback) 추천으로 콜드 스타트 완화
2. 중기: ALS·NMF 등 잠재 요인 모델로 희소 행렬의 결측값을 저랭크 근사하여 예측 정확도 향상
3. 장기: 트랜스포머 기반 세션 추천(SASRec) + 지식 그래프 임베딩으로 실시간 문맥 반영 체계 구축

- **문맥 반영 부재**: 정적 행렬 의존 -> 세션 시퀀스 모델 + 시간 감쇠 가중치 적용 (지표: CTR 개선율)

> 요약: 온보딩 폴백, 잠재 요인 모델, 세션 기반 딥러닝으로 추천 시스템을 단계적으로 고도화함

## Ⅵ. 전망
- 향후 발전 방향: LLM 기반 대화형 추천(Conversational RecSys)으로 사용자 의도를 자연어로 파악하는 단계로 진화
- 기술사적 판단: 추천 정확도뿐 아니라 다양성(Diversity)·공정성(Fairness) 지표가 평가 기준에 포함되는 추세
- 기술사 제언: CF vs 콘텐츠 기반의 장단점 비교표와 콜드 스타트 대응 전략을 반드시 포함하여 서술
