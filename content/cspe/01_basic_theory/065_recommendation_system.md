# 추천 시스템 - 협업 필터링, 콘텐츠 기반 (Recommendation System)

## 1. 개요

- **정의/개념**: 추천 시스템은 사용자, 아이템, 상호작용 데이터를 분석해 사용자에게 적합한 아이템을 예측·순위화하는 시스템이다.
- **배경/필요성**: 정보와 상품이 많아질수록 사용자가 직접 탐색하기 어렵기 때문에 개인화된 후보 생성과 정렬로 탐색 비용을 줄일 필요가 있다.

추천은 단순 예측 정확도보다 사용자 경험, 다양성, 편향, 실시간성을 함께 다루는 의사결정 시스템이다.

## 2. 특징 및 비교

| 구분 | 협업 필터링 | 콘텐츠 기반 | 하이브리드 |
|---|---|---|---|
| 기준 | 사용자-아이템 상호작용 | 아이템·사용자 속성 | 상호작용+콘텐츠 |
| 강점 | 취향 패턴 반영 | 신규 아이템 대응 | 균형 |
| 약점 | cold start | 취향 확장 한계 | 구조 복잡 |
| 대표 기법 | matrix factorization | profile matching | two-tower, ranking ensemble |

선택 기준은 상호작용 데이터 규모, cold start, 설명 가능성, 다양성, 지연 시간이다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| User Profile | 사용자 특성·행동 | 개인화 기준 |
| Item Feature | 아이템 속성·임베딩 | 콘텐츠 이해 |
| Interaction Log | 클릭, 구매, 평점 | 협업 신호 |
| Candidate Generation | 추천 후보 생성 | recall 중심 |
| Ranking Model | 후보 정렬 | precision·비즈니스 목표 |

```text
사용자/아이템/로그 -> 후보 생성 -> 랭킹 -> 필터링/다양화 -> 추천 노출
```

후보 생성과 랭킹 목표가 다르므로, 추천 시스템은 여러 단계의 지표를 분리해 관리해야 한다.

## 4. 문제점 및 개선방안

1. **Cold Start**
   - 신규 사용자·아이템은 상호작용 데이터가 부족해 추천 품질이 낮다.
   - **개선방안**: 콘텐츠 기반 feature, 인기 추천, onboarding 설문을 결합한다.

2. **편향과 필터 버블**
   - 과거 행동만 강화하면 다양성과 탐색성이 떨어진다.
   - **개선방안**: diversity, novelty, exploration 전략을 적용한다.

3. **오프라인·온라인 지표 괴리**
   - offline accuracy가 높아도 실제 사용자 만족과 다를 수 있다.
   - **개선방안**: A/B test, CTR, retention, 장기 만족 지표를 함께 본다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| 커머스 추천 | 구매·조회 로그와 상품 속성으로 개인화 | CTR, CVR |
| 콘텐츠 추천 | 시청 이력과 콘텐츠 임베딩으로 후보 생성 | watch time |
| 검색 랭킹 | 추천 점수를 검색 결과 순위화에 반영 | NDCG, dwell time |

## 6. 결론

추천 시스템은 사용자와 아이템의 관계를 예측하고 순위화하는 개인화 시스템이다. 협업·콘텐츠·하이브리드 비교와 함께 cold start, 편향, 온라인 검증까지 연결해야 실제 서비스 품질을 설명할 수 있다.
