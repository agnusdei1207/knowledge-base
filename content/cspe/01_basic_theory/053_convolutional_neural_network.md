# 📖 【암기용】 개념 완전 이해

> 목적: 합성곱 신경망 CNN을 처음 보는 사람도 완전하게 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 작은 필터를 이미지 전체에 공유 적용해 공간 특징을 추출하는 신경망
- **왜 필요한가**:
  - 이미지는 픽셀 수가 많고 위치 관계가 중요하다.
  - 완전연결층으로 224x224 RGB 이미지를 처리하면 입력만 150,528개라 파라미터가 폭증한다.
- **핵심 직관**: 하나의 필터가 이미지의 여러 위치를 훑으며 같은 모양(엣지·질감·부분 객체)을 찾는 구조다.

## 깊이 이해
- **배경·문제의식**:
  - 이미지 분류·객체탐지는 지역 패턴과 위치 불변성이 핵심이다.
  - CNN은 지역 수용영역, 가중치 공유, 풀링으로 공간 구조를 보존하면서 파라미터 수를 줄인다.
- **작동 원리**:
  - 합성곱 필터가 입력 패치와 곱셈·합산을 수행해 특징맵을 만든다.
  - 낮은 층은 엣지, 중간 층은 질감, 깊은 층은 객체 부품을 학습한다.
- **비유**: 돋보기를 들고 사진의 왼쪽 위부터 오른쪽 아래까지 같은 체크리스트로 훑으며 선, 모서리, 패턴을 표시하는 방식이다.
- **구체 예시**:
  - 224x224x3 이미지에 3x3 필터 64개를 적용하면 첫 합성곱 파라미터는 `3x3x3x64=1,728`개다.
  - 같은 입력을 1,000개 뉴런 완전연결층에 붙이면 150,528,000개가 필요하다.
- **흔한 오해·주의점**:
  - CNN은 이미지 전용이 아니다.
  - 1D CNN은 시계열·텍스트 n-gram에도 쓰지만, 긴 문맥 의존은 Transformer 계열이 더 적합한 경우가 많다.

## 연결 개념
- 합성곱(Convolution) — 필터와 입력 패치의 국소 연산
- 풀링(Pooling) — 공간 크기 축소와 위치 민감도 완화
- ResNet — 깊은 CNN의 기울기 소실을 잔차 연결로 완화

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: CNN(Convolutional Neural Network)은 합성곱 필터와 가중치 공유로 이미지의 지역 특징을 계층적으로 추출하는 딥러닝 구조다.
> 2. **가치**: 완전연결층 대비 파라미터 수를 수십~수천 배 줄이고 공간 패턴 학습을 지원한다.
> 3. **판단 포인트**: 필터 크기, stride, padding, pooling, 깊이, 데이터 증강, 연산량(FLOPs)을 함께 설계해야 한다.

---

## Ⅰ. 개요 및 필요성

- 개요: CNN은 이미지 특징을 계층적으로 추출하는 신경망이다.
- 배경: 이미지·영상 데이터는 픽셀 간 위치 관계가 있어 일반 MLP로 처리하면 파라미터와 과적합이 증가한다.
- 필요성: CNN은 지역 연결과 가중치 공유로 엣지·질감·객체 패턴을 단계적으로 학습한다.

---

## Ⅱ. 구조 및 구성요소

```text
이미지 입력 -> 합성곱층 -> 활성화 함수 -> 풀링/정규화 -> 특징맵
          -> 반복 블록 -> 전역 풀링/분류기 -> 클래스 확률
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Convolution Layer | 필터로 지역 특징 추출 | 3x3, 1x1 필터가 기본 축 |
| Activation | 비선형성 부여 | ReLU, GELU 사용 |
| Pooling/Stride | 공간 크기 축소 | 2x2 max pooling, stride 2 |
| Classifier | 특징을 클래스 확률로 변환 | Global Average Pooling으로 FC 축소 |

> 요약: CNN은 합성곱으로 특징맵을 만들고 풀링·분류기로 공간 특징을 클래스 판단으로 연결한다.

---

## Ⅲ. 동작원리 및 흐름도

```text
입력 패치 선택 -> 필터 곱셈/합산 -> 특징맵 생성
-> 비선형 변환 -> 다운샘플링 -> 분류/탐지 출력
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 입력 크기·채널 정규화 | 224x224, mean/std 전처리 |
| 2 | 합성곱 필터 적용 | 출력 크기 공식 확인 |
| 3 | 풀링·정규화 적용 | 특징맵 크기와 채널 수 점검 |
| 4 | 분류·탐지 결과 산출 | Top-1 accuracy, mAP 측정 |

> 요약: CNN은 동일 필터를 위치별로 적용해 특징맵을 만들고 층을 거듭하며 저수준 패턴을 고수준 객체 표현으로 변환한다.

---

## Ⅳ. 특징

| 구분 | 기존 방식 | 본 기술 | 수치·판단 포인트 |
|:---|:---|:---|:---|
| 파라미터 | MLP는 모든 픽셀 연결 | 필터 가중치 공유 | 3x3x3x64 = 1,728개 |
| 공간 인식 | 벡터화로 위치 구조 손실 | 지역 수용영역 보존 | 커널·stride·padding 설계 |
| 이동 불변성 | 위치 변화에 민감 | 풀링·증강으로 완화 | crop·flip 증강 정확도 비교 |
| 한계 | 지역 특징 강점 없음 | 전역 문맥 포착 제한 | Attention·ViT와 비교 |

> 요약: CNN은 공간 지역성을 활용해 파라미터를 줄이지만 전역 관계가 중요한 문제에서는 Attention 계열과 비교해야 한다.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존/대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | MLP는 전결합 | CNN은 지역 연결·공유 가중치 | 이미지·격자 데이터면 CNN 우선 |
| 비용/성능 | ViT는 대규모 사전학습 의존 | CNN은 중소 데이터에도 적용 | 데이터 10만 장 미만이면 CNN 검토 |
| 운영/위험 | 수작업 특징은 유지보수 부담 | 자동 특징 학습 | 라벨 품질·증강 정책 필요 |

> 요약: 이미지 데이터와 제한된 학습 데이터에서는 CNN을 기준 모델로 두고, 대규모 사전학습 환경에서는 ViT와 비교한다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 과적합 | 데이터 수 부족 | 증강, Dropout, Weight Decay | train-validation gap |
| 연산량 증가 | 깊은 모델·고해상도 입력 | MobileNet, pruning, quantization | FLOPs, p95 latency |
| 편향 학습 | 배경·촬영 조건 편중 | stratified split, Grad-CAM 점검 | 클래스별 F1, confusion matrix |

> 요약: CNN 운영은 데이터 편향, 연산량, 과적합을 지표 기반으로 통제해야 한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 정확도 | Top-1, F1, mAP 목표 충족 | 검증 세트·테스트 세트 |
| 연산 비용 | p95 latency, FLOPs, VRAM 한도 | 벤치마크, 프로파일러 |
| 설명 가능성 | Grad-CAM 관심 영역 일치 | 샘플링 리뷰, 오류 분석 |

> 요약: CNN 도입은 정확도뿐 아니라 지연시간, 메모리, 설명 가능성을 함께 측정해야 한다.

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 — 단계별 또는 항목별):**
1. ResNet·EfficientNet을 baseline으로 두고 입력 224x224, batch size 32, weight decay 1e-4 조건에서 비교 학습함.
2. 데이터 증강은 RandomCrop·HorizontalFlip·ColorJitter를 적용하고 클래스별 F1 0.85 이상을 목표로 점검함.
3. 배포 전 ONNX/TensorRT 변환, FP16 또는 INT8 양자화, p95 latency 50ms 이하를 기준으로 최적화함.

**결론 (2줄):**
- 기술사 판단: 이미지·영상의 지역 패턴 분류에는 CNN을 우선 적용하고, 전역 문맥·대규모 사전학습 조건에서는 ViT와 비교 선택함.
- 향후 방향: CNN은 경량화·양자화·Attention 결합 구조로 엣지 AI와 실시간 비전 분야에 확장됨.
