## Ⅰ. 개요
- 정의: 데이터의 공간적 구조(Spatial Structure)를 보존하며 특징을 추출하는 신경망 구조임
- 배경: 이미지와 같은 고차원 격자 데이터의 지역적 패턴 인식 필요
- 출제 의도:
| 구분 | 내용 |
| --- | --- |
| 핵심 | 필터(커널), 스트라이드, 풀링, 특성 맵 |

## Ⅱ. 구성요소
- ASCII 구조도
  [Img] * [Filter] -> [Feature Map] -> [Pooling]
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 필터(Kernel) | 이미지의 국소 영역 특징을 읽는 창 | 돋보기 |
| 스트라이드 | 필터가 이동하는 간격 | 보폭 |
| 풀링(Pooling) | 해상도를 낮춰 주요 특징만 남기는 요약 | 압축 |
> 요약: 채널과 공간 정보를 활용하여 위상 불변 특징을 학습함

## Ⅲ. 절차
- ASCII 흐름도
  [필터연산] -> [활성화] -> [풀링] -> [평탄화]
- 4단계 설명
1. 필터 연산: 입력 데이터에 커널을 슬라이딩하며 합성곱 수행함
2. 활성화: ReLU 등을 거쳐 비선형 특성을 강화함
3. 풀링: Max/Average Pooling으로 공간 크기를 줄이고 요약함
4. 평탄화(Flatten): 2D 맵을 1D로 펼쳐 분류기(FC)에 연결함
> 요약: 국소 특징부터 전역 특징까지 계층적으로 추출함

## Ⅳ. 문제점
- 이미지의 회전이나 크기 변화에 대한 완벽한 불변성 부족함
- 연산량이 많아 고성능 GPU 자원이 필수적임

## Ⅴ. 개선방안
- (단기) Data Augmentation을 통해 다양한 변형 데이터 학습함
- (중기) Depthwise Separable Conv 등으로 연산 효율성 극대화함
- (장기) Capsule Network 등 공간 관계 보존 기법으로 고도화함

## Ⅵ. 전망
- 트랜스포머 아키텍처와 결합한 Conformer, Vision Transformer(ViT) 하이브리드 구조가 차세대 영상 분석의 기술 로드맵임
- 자율주행차의 주변 환경 인지를 위한 3D Convolution 및 비디오 시계열 특징 추출 기술로 응용 범위가 급격히 확대됨
- 모바일/엣지 기기 탑재를 위한 모델 프루닝(Pruning) 및 양자화 기술과의 연계가 서비스 상용화의 핵심 CSF임
