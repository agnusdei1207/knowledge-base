# 📖 【암기용】 개념 완전 이해

> 목적: K-Fold 교차 검증을 처음 봐도 완전히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 데이터를 K개 묶음으로 나누어 학습·검증을 반복하고 평균 지표로 일반화 오차를 추정하는 방법
- **왜 필요한가**: 한 번의 학습/검증 분할은 우연히 쉬운 검증셋 또는 어려운 검증셋을 만들 수 있음
- **핵심 직관**: 학생 시험지를 K묶음으로 돌려가며 채점해 특정 묶음 운에 좌우되지 않는 평균 점수를 구함

## 깊이 이해
- **배경·문제의식**: 데이터가 1,000건뿐이면 80:20 단일 분할의 검증 200건이 전체 분포를 대표하지 못할 수 있다. K-Fold는 모든 샘플이 한 번씩 검증셋이 되도록 반복함.
- **작동 원리**: 데이터를 K개 fold로 나누고, 매 반복마다 1개 fold를 검증셋, 나머지 K-1개를 학습셋으로 사용함. K개 평가 점수의 평균과 표준편차를 산출함.
- **비유**: 야구 선수를 한 경기만 보고 평가하지 않고, 여러 경기 성적 평균과 편차로 판단하는 방식과 유사함.
- **구체 예시**: 5-Fold에서는 매회 80% 학습·20% 검증을 5회 수행하고, Accuracy 평균 0.91, 표준편차 0.03이면 분할 민감도를 함께 제시함.
- **흔한 오해·주의점**: 전처리를 전체 데이터에 먼저 맞추면 데이터 누수(Data Leakage)가 발생함. 스케일러, PCA, 피처 선택은 각 fold의 학습 데이터에만 fit해야 함.

## 연결 개념
- 과적합: 학습 점수와 검증 점수 차이로 탐지
- 하이퍼파라미터 튜닝: Grid/Random Search와 결합
- 층화 추출: 불균형 분류에서 클래스 비율 보존

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: K-Fold 교차 검증은 데이터를 K개로 나누어 학습·검증을 반복하고 평균 지표로 일반화 오차를 추정하는 평가 절차임.
> 2. **가치**: 단일 분할 편향을 줄이고, 모델 선택·하이퍼파라미터 튜닝·과적합 판단의 기준 점수를 제공함.
> 3. **판단 포인트**: K값, 층화 여부, 시계열 분할, 데이터 누수 방지, 평균·표준편차 동시 보고가 핵심임.

---

## Ⅰ. 개요 및 필요성

K-Fold는 반복 검증 기반 모델 평가 방법이다. 단일 검증셋은 표본 운에 따라 평가 점수가 흔들린다. K-Fold는 모든 샘플을 검증에 사용해 일반화 오차를 평균과 편차로 제시한다.

---

## Ⅱ. 구조 및 구성요소

```text
전체 데이터 -> K개 Fold 분할 -> 반복 i=1..K -> K-1개 학습 / 1개 검증 -> 지표 집계
              / StratifiedKFold·TimeSeriesSplit 변형 선택
```

| 구성요소 | 역할 | 판단 기준 |
|:---|:---|:---|
| K개 Fold | 데이터 분할 단위 | 보통 K=5 또는 10 |
| 학습셋 | 모델 파라미터 학습 | K-1개 fold 사용 |
| 검증셋 | 일반화 오차 측정 | 매 반복 1개 fold |
| 평가 지표 | 반복 결과 집계 | 평균, 표준편차 |

> 요약: K-Fold는 K개의 검증 결과를 만들고 평균·표준편차로 모델의 일반화 지표와 분할 민감도를 함께 판단함.

---

## Ⅲ. 동작원리 및 흐름도

```text
데이터 섞기 -> K분할 -> K회 학습/검증 -> 지표 집계 -> 모델 선택
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 데이터 셔플 또는 층화 분할 | 클래스 비율 유지 |
| 2 | 각 fold별 학습/검증 분리 | 검증셋 중복 없음 |
| 3 | 전처리 fit은 학습셋에만 수행 | 데이터 누수 0건 |
| 4 | K개 점수 평균·표준편차 산출 | Accuracy, F1, RMSE |

> 요약: K-Fold는 분할·학습·검증을 K회 반복하되, 전처리 학습 범위를 fold 내부로 제한해야 함.

---

## Ⅳ. 특징

| 구분 | Hold-out | K-Fold | 수치·판단 포인트 |
|:---|:---|:---|:---|
| 분할 | 1회 학습/검증 | K회 반복 | K=5, 10 |
| 데이터 활용 | 일부만 검증 | 모든 샘플 1회 검증 | 표본 1,000건 이하 유리 |
| 비용 | 학습 1회 | 학습 K회 | 학습시간 K배 |
| 변형 | 단순 랜덤 분할 | Stratified, TimeSeriesSplit | 불균형·시계열 대응 |

> 요약: K-Fold는 학습 비용을 K배 사용해 단일 분할 편향을 낮추며, 데이터 특성에 따라 층화·시계열 분할로 변형함.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존·대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | Hold-out은 1회 분할로 평가 | K-Fold는 K회 반복 평균으로 일반화 오차 추정 | 표본 수 1,000건 이하 또는 분할 민감도 존재 |
| 비용/성능 | Hold-out은 학습 1회 | K-Fold는 학습 K회, 점수 분산 제공 | K=5/10, 학습시간 허용 범위 |
| 운영/위험 | 단일 점수는 우연한 분할 영향 | 평균·표준편차로 모델 선택 근거 제공 | 평균 F1, RMSE, 표준편차 병기 |

> 요약: K-Fold는 학습 비용을 K배 사용해 분할 편향을 낮추고 모델 선택 근거를 평균·편차로 제시함.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 데이터 누수 | 전처리·피처선택을 전체 데이터에 fit | Pipeline 구성, fold 내부 fit 적용 | 누수 점검 체크리스트 |
| 클래스 불균형 | 랜덤 분할로 소수 클래스 누락 | StratifiedKFold 적용 | fold별 클래스 비율 |
| 시간 역전 | 시계열 데이터를 랜덤 분할 | TimeSeriesSplit, rolling window 검증 | 학습기간<검증기간 순서 |

> 요약: 교차 검증 리스크는 누수·불균형·시간 역전이며, Pipeline·층화·시계열 분할로 통제함.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 일반화 지표 | F1·RMSE 평균과 표준편차 병기 | K회 결과 집계 |
| 분할 적합성 | 클래스 비율 편차 5%p 이내 | fold별 라벨 분포 |
| 누수 방지 | 전처리 fit 범위 학습 fold 내부 | sklearn Pipeline, 코드 리뷰 |

> 요약: K-Fold 적용 후에는 평균 점수보다 표준편차, fold 분포, 전처리 fit 범위를 함께 점검해야 함.

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 분류 모델 평가: 불균형 장애 데이터는 Stratified 5-Fold로 클래스 비율을 유지하고 F1 평균·표준편차 병기
2. 회귀 모델 선택: Ridge/Lasso alpha 후보를 10-Fold RMSE 평균 기준으로 선택하고 테스트셋은 최종 1회만 사용
3. 시계열 예측: 트래픽 예측은 랜덤 K-Fold 대신 TimeSeriesSplit으로 과거 학습·미래 검증 순서 유지

**결론 (2줄):**
- 기술사 판단: 데이터가 독립 표본이면 Stratified K-Fold, 시간 순서가 있으면 TimeSeriesSplit을 선택함
- 향후 방향: AutoML·MLOps 파이프라인은 교차 검증, 데이터 누수 검사, 실험 추적(MLflow)을 자동 기록해야 함
