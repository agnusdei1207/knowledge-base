## Ⅰ. 개요
- 정의: 전체 데이터를 K개로 나누어 학습과 검증을 번갈아 수행하는 평가 기법임
- 배경: 고정된 검증 데이터셋에 대한 과적합 방지 및 일반화 성능 평가 필요
- 출제 의도:
| 구분 | 내용 |
| --- | --- |
| 핵심 | 학습/검증 분할, 일반화, 편향 감소 |

## Ⅱ. 구성요소
- ASCII 구조도
  Iter 1: [V][T][T][T] -> Score 1
  Iter 2: [T][V][T][T] -> Score 2
  Iter 3: [T][T][V][T] -> Score 3
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 폴드(Fold) | 데이터를 균등하게 분할한 부분 집합 | 조각 |
| 학습 데이터 | 모델 파라미터 업데이트용 데이터 | 공부재료 |
| 검증 데이터 | 모델 성능 측정 및 튜닝용 데이터 | 모의고사 |
> 요약: 모든 데이터를 최소 한 번은 검증에 사용하여 평가 신뢰도 제고함

## Ⅲ. 절차
- ASCII 흐름도
  [데이터분할] -> [반복학습] -> [성능측정] -> [평균계산]
- 4단계 설명
1. 데이터 분할: 전체 데이터를 K개의 폴드로 무작위 등분함
2. 반복 학습: K-1개 폴드로 학습하고 1개 폴드로 검증함
3. 성능 측정: 각 회차(Iteration)마다 정확도 등의 평가지표 산출함
4. 평균 계산: K개의 결과값을 평균하여 최종 모델 성능 결정함
> 요약: 반복적인 검증을 통해 데이터 편향을 최소화함

## Ⅳ. 문제점
- 반복적인 학습/검증 과정으로 인해 연산 비용이 증가함
- 시계열 데이터의 경우 순서 파괴로 인해 적용이 어려움

## Ⅴ. 개선방안
- (단기) 병렬 처리를 통해 연산 시간 단축함
- (중기) TimeSeriesSplit 등 데이터 특성 맞는 분할 기법 사용함
- (장기) 자동화된 ML(AutoML) 파이프라인 내 표준 검증으로 내재화함

## Ⅵ. 전망
- 데이터 부족 상황에서 성능 평가의 골든 스탠다드로 계속 활용됨
