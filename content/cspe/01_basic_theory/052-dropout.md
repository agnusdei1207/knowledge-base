## Ⅰ. 개요
- **정의**: 신경망 학습 과정에서 임의의 뉴런을 일정한 확률로 비활성화시켜 학습시키는 규제 기법임.
- **배경/필요성**: 특정 뉴런에 가중치가 과도하게 집중되는 현상을 방지하고, 앙상블 효과를 통해 과적합을 막기 위해 필요함.
- **출제 의도**: 학습(Training)과 추론(Inference) 시 드롭아웃의 동작 방식 차이를 명확히 이해하고 있는지 평가함.

## Ⅱ. 구성요소
```text
+------------------+       +------------------+       +------------------+
| Fully Connected  | ----> | Apply Dropout    | ----> | Sub-network      |
| Network Layer    |       | (Keep Prob = p)  |       | (Sparse Layer)   |
+------------------+       +------------------+       +------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 드롭 확률 (1-p) | 노드를 비활성화(0으로 만듦)시킬 확률 (보통 0.2~0.5) | 무작위 결석 비율 |
| 학습 모드 | 매 스텝마다 랜덤하게 서브 네트워크를 생성하여 학습 | 다양한 팀원 조합 훈련 |
| 추론 모드 | 모든 노드를 활성화하고, 출력값에 유지 확률(p)을 곱함 | 전체 팀원 실전 투입 |

> 요약: 학습 시 무작위로 뉴런을 끄고 학습하며, 추론 시에는 모두 켜되 기댓값을 보정함.

## Ⅲ. 절차
```text
+-------------+   +-------------+   +-------------+   +-------------+
| 1. 확률     |-->| 2. 마스크   |-->| 3. 순/역전파|-->| 4. 추론시   |
|    설정     |   |    생성     |   |    수행     |   |    스케일링 |
+-------------+   +-------------+   +-------------+   +-------------+
```
1. **확률 설정**: 하이퍼파라미터로 노드를 유지할 확률(p)을 설정함.
2. **마스크 생성**: 베르누이 분포를 활용하여 바이너리 마스크를 랜덤 생성함.
3. **순/역전파 수행**: 마스크를 곱해 일부 노드를 끄고 순전파, 역전파를 수행함.
4. **추론시 스케일링**: 테스트 시에는 모든 가중치를 사용하되, 활성화 규모 차이를 맞추기 위해 p를 곱함.

> 요약: 학습 시 무작위 마스킹을 통해 파라미터를 갱신하고, 평가 시에는 스케일을 보정함.

## Ⅳ. 문제점
- **학습 시간 증가**: 매 스텝 구조가 바뀌므로 수렴하는 데 필요한 훈련 시간이 증가함.
- **정보 손실 우려**: 너무 높은 드롭아웃 비율을 설정하면 중요 특징을 잃어 과소적합이 발생함.

## Ⅴ. 개선방안
- **학습 시간 증가**: (단기) 학습률을 조정하거나 모멘텀 추가 / (장기) 사전 학습 모델 활용 필요.
- **정보 손실 우려**: (단기) 은닉층 위치별로 비율 차등 적용 / (장기) L2 정규화 등 타 규제 기법과 혼합 필요.

## Ⅵ. 전망
- 단순 뉴런 단위를 넘어, CNN의 Spatial Dropout 등 공간 구조를 반영한 변형 기법으로 발전하고 있음.
