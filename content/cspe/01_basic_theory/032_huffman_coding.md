## 미리 알고가기

- 가변 길이 부호: 기호별 발생 빈도에 따라 서로 다른 길이의 코드를 쓰는 방식임
- 접두 부호: 어떤 코드도 다른 코드의 앞부분이 아니어서 구분자 없이 순차 복호하는 코드임
- 엔트로피: 평균 정보량이며 무손실 압축률의 이론 하한임
- 최소 힙: 가장 작은 빈도 노드 두 개를 반복해 꺼내는 우선순위 큐임
- 코드북: 기호와 허프만 코드의 대응표임

## 작성 근거(검토용)

- 키워드의 본질이 빈도 기반 가변 길이 부호이므로 정의와 특징을 이 축으로 통일함
- 접두 부호를 별도 용어로 설명해 구분자 없이 복호되는 이유를 앞에서 정리함
- 비교표는 고정 길이 부호와 산술 코딩을 두어 부호 단위·복호 방식·부가 관리의 차이가 보이게 함
- 구성요소는 빈도표·힙·트리·코드북으로 실제 구현 순서를 따라 배치함
- 코드북 오버헤드와 분포 변화는 압축 알고리즘 선택을 바꾸는 핵심 조건임

## Ⅰ. 개요

- **정의/개념**: 허프만 코딩은 빈도가 높은 기호에 짧은 코드를 배정하는 접두 부호 기반 무손실 압축 알고리즘임
- **배경/필요성**: 데이터의 평균 비트 수를 줄이기 위해 빈도 편중을 반영하는 부호화가 필요함

## Ⅱ. 특징

- 빈도 기반 이진 트리로 평균 코드 길이를 줄임
- 접두 부호 조건으로 구분자 없이 순차 복호함
- 가장 낮은 빈도의 두 노드를 반복 결합하는 탐욕 구조임
- 기호 확률이 2의 거듭제곱 꼴에 가까울수록 엔트로피에 더 근접함

## Ⅲ. 종류 및 비교

| 판단 기준 | 고정 길이 부호 | 허프만 코딩 | 산술 코딩 |
|:---|:---|:---|:---|
| 부호화 단위·길이 | 기호별 동일 길이 코드 | 기호별 정수 길이 접두 코드 | 메시지 전체의 확률 구간 |
| 압축 기준 | 문자 집합 크기 | 기호 발생 빈도 | 누적 확률 구간 |
| 복호 방식 | 고정 비트 폭으로 나누어 복호함 | 접두 트리의 단말에 도달하면 기호를 확정함 | 구간 연산과 재정규화를 수행함 |
| 대표 적용 사례 | 고정 폭 식별자·상태 코드 | ZIP·JPEG 압축 | 확률 모델 기반 영상 엔트로피 부호화 |
| 부가 관리 | 고정 폭 코드 매핑 | 코드북·부호 트리 공유 | 확률 모델·유한 정밀도 구간 관리 |

> 요약: 허프만 코딩은 기호별 정수 길이 접두 코드를 사용하므로 코드북을 공유하면 트리 탐색으로 복호할 수 있음.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 빈도표 | 원본에서 각 기호의 출현 횟수를 집계함 |
| 최소 힙 | 가장 낮은 빈도 노드 두 개를 선택함 |
| 내부 노드 | 두 하위 노드의 빈도 합을 저장함 |
| 단말 노드 | 실제 기호를 저장하며 루트 경로가 코드가 됨 |
| 코드북 | 생성된 코드를 인코더와 디코더가 공유함 |

```text
빈도: A=5, B=2, C=1, D=1

결합: (C:1)+(D:1)->2
      (B:2)+(CD:2)->4
      (A:5)+(BCD:4)->9

경로: 왼쪽=0, 오른쪽=1
```

> 요약: 허프만 트리는 낮은 빈도 노드를 먼저 묶어 높은 빈도 기호가 짧은 경로를 갖게 함.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+   +----------+   +----------+   +----------+   +-------------+
| 빈도 집계 | -> | 힙 삽입  | -> | 노드 결합 | -> | 코드 생성 | -> | 비트열 치환   |
+----------+   +----------+   +----------+   +----------+   +-------------+
```

1. 원본 데이터를 스캔해 기호별 빈도를 계산함
2. 모든 기호를 빈도 기준 최소 힙에 넣음
3. 최저 빈도 노드 두 개를 꺼내 부모 노드로 결합함
4. 루트에서 단말까지의 0/1 경로를 코드북에 기록함
5. 원본 기호를 코드북 비트열로 치환함

> 요약: 최저 빈도 노드를 반복 결합하고 루트에서 단말까지의 경로를 코드로 정해 원본 기호를 치환함.

## Ⅵ. 실무 사례

1. 허프만 파일 압축기는 코드북 헤더를 포함한 압축 결과와 원본 크기를 비교해 저장 형식을 선택함
2. 스트림 압축기는 블록별 코드 트리를 갱신하고 압축률·부호화 지연을 확인함

## Ⅶ. 결론

- 허프만 코딩은 기호 빈도를 가변 길이 접두 부호로 바꾸어 구분자 없이 원본을 복원하는 무손실 압축 방식임
