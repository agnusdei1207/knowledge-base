## Ⅰ. 개요
- **정의**: 빈도 기반 가변 길이 코드를 할당하여 데이터를 압축하는 무손실 부호화 기법
- **배경/필요성**: 고정 길이 코드는 빈도가 낮은 기호에도 동일 비트를 할당하여 저장·전송 자원을 낭비함
- **비유**: 자주 쓰는 단어에는 짧은 약어를, 드문 단어에는 긴 철자를 쓰는 속기법

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 탐욕 알고리즘 기반 최적 접두어 코드 이해 | 이진 트리 구축 과정과 접두어 조건 | 최적성 증명 조건(접두어 코드 한정), 엔트로피(033 참조)와의 관계 |

> 요약: 빈도에 반비례하는 가변 길이 코드를 부여하여 평균 비트 수를 최소화하는 기법임

## Ⅱ. 구성요소
```text
  +------------+     빈도 분석     +-------------+
  | 기호 집합   |---------------->| 빈도 테이블  |
  +------------+                  +-------------+
                                       |
                                  최소 빈도 2개 병합
                                       v
                                 +-----------+
                                 | 허프만 트리 |
                                 +-----------+
                                       |
                                  좌=0, 우=1 할당
                                       v
                                 +-----------+
                                 | 코드 테이블 |
                                 +-----------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 빈도 테이블 | 각 기호의 출현 횟수를 집계한 매핑 | 단어 빈도 순위표 |
| 허프만 트리 | 빈도가 낮은 노드부터 병합하여 만든 이진 트리 | 토너먼트 대진표(약자끼리 먼저 배정) |
| 코드 테이블 | 트리 경로(좌=`0`, 우=`1`)로 생성된 기호별 이진 코드 | 속기 약어 사전 |

> 요약: 빈도 테이블 → 허프만 트리 → 코드 테이블 순으로 최적 접두어 코드를 생성함

## Ⅲ. 절차
```text
  빈도 집계       우선순위 큐     트리 구축        코드 할당
  (기호 카운트)  (최소힙 삽입)  (2개 병합 반복)  (경로→비트)
   |              |              |               |
   +---빈도------>+---최소 2개--->+---루트 완성--->+
  입력 스캔      노드 정렬      부모 노드 생성   좌0/우1 매핑
```
- 1단계: 입력 데이터를 스캔하여 각 기호의 출현 빈도를 집계함
- 2단계: 모든 기호를 빈도값 기준 최소 힙(우선순위 큐)에 삽입함
- 3단계: 빈도가 가장 낮은 노드 2개를 꺼내 합산 빈도의 부모 노드를 생성하고 다시 힙에 삽입하며, 노드가 1개 남을 때까지 반복함
- 4단계: 완성된 트리의 루트에서 리프까지 경로를 추적하여 좌=`0`, 우=`1`로 코드를 할당함

> 요약: 빈도 집계 → 최소힙 → 반복 병합 → 코드 할당의 탐욕적 절차임

## Ⅳ. 문제점
- 빈도 사전 전송 부담: 디코딩을 위해 코드 테이블 또는 트리를 함께 전송해야 하므로 소규모 데이터에서 오버헤드가 큼
- 정적 빈도 한계: 입력 전체를 2-패스로 스캔해야 하며 스트리밍 데이터에 실시간 적용이 곤란함
- 비트 단위 처리 비용: 가변 길이 코드의 비트 단위 읽기·쓰기가 바이트 정렬 연산 대비 처리 오버헤드를 유발함

> 요약: 사전 전송 부담·정적 빈도 의존·비트 단위 처리 비용이 실용상 제약임

## Ⅴ. 개선방안
1. 단기: 정규(Canonical) 허프만 코드를 사용하여 코드 테이블 크기를 비트 길이 배열로 축소
2. 중기: 적응적(Adaptive) 허프만 코딩으로 1-패스 스트리밍 압축 지원
3. 장기: 산술 부호화 등 엔트로피에 근접한 기법과 결합하여 압축률 한계를 극복

> 요약: 정규화·적응적 방식·산술 부호화 결합으로 한계를 단계적으로 해소함

## Ⅵ. 전망
- 발전 방향: DEFLATE(ZIP, PNG), JPEG 등 복합 압축 체계의 후단 부호화기로 지속 활용
- 기술사적 판단: 탐욕 알고리즘의 대표 응용이며 정보 이론(033 참조)과 알고리즘 설계를 연결하는 핵심 사례
- 기술사 제언: 엔트로피 하한과의 관계를 정량적으로 설명할 수 있도록 정보 이론 개념과 함께 학습할 필요
