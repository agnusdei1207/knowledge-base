# 허프만 코딩 (Huffman Coding)

## 1. 개요

- **정의/개념**: 허프만 코딩은 출현 빈도가 높은 기호에는 짧은 코드, 낮은 기호에는 긴 코드를 부여해 평균 코드 길이를 줄이는 무손실 압축 기법이다.
- **배경/필요성**: 데이터 기호의 발생 확률이 균등하지 않으면 고정 길이 코드가 비효율적이므로, 빈도 분포를 반영한 가변 길이 부호화가 필요하다.

허프만 코딩의 핵심은 압축률보다 먼저 접두사 코드(prefix code) 특성으로 복호 모호성을 없애는 것이다.

## 2. 특징 및 비교

| 구분 | 고정 길이 코드 | 허프만 코딩 | 산술 코딩 |
|---|---|---|---|
| 코드 길이 | 모든 기호 동일 | 빈도 기반 가변 길이 | 구간 기반 |
| 복호 모호성 | 없음 | 접두사 코드로 없음 | 모델 기반 복호 |
| 압축 효율 | 분포 편향 반영 어려움 | 기호 단위 최적 | 보통 더 높음 |
| 구현 복잡도 | 낮음 | 중간 | 높음 |

선택 기준은 기호 분포 편향, 모델 전송 오버헤드, 처리 속도, 복호 단순성이다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| Symbol | 압축 대상 기호 | 문자, 바이트 등 |
| Frequency | 기호별 출현 횟수 | 코드 길이 결정 |
| Priority Queue | 빈도 낮은 노드 선택 | 트리 구성 |
| Huffman Tree | 접두사 코드 생성 트리 | 좌우 간선 0/1 |
| Code Table | 기호별 비트열 매핑 | 인코딩·디코딩 |

```text
+----------+      +----------+      +----------+      +----------+
| 빈도계산 | ---> | 트리구성 | ---> | 코드표생성 | ---> | 비트열변환 |
+----------+      +----------+      +----------+      +----------+
```

빈도 분포가 코드 길이를 결정하므로, 데이터 분포 변화가 압축 효율과 코드표 오버헤드로 바로 이어진다.

## 4. 문제점 및 개선방안

1. **분포 변화에 취약**
   - 학습한 빈도와 실제 데이터 분포가 다르면 압축 효율이 떨어진다.
   - **개선방안**: 블록별 코드 생성, adaptive Huffman, 다른 압축 방식과 결합한다.

2. **코드표 오버헤드**
   - 작은 데이터에서는 코드표 저장 비용이 압축 이득보다 클 수 있다.
   - **개선방안**: 최소 블록 크기, canonical Huffman code를 적용한다.

3. **오류 전파**
   - 가변 길이 비트열이 손상되면 이후 복호 경계가 깨질 수 있다.
   - **개선방안**: 블록 경계, checksum, 오류 검출 코드를 함께 사용한다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| 파일 압축 | 기호 빈도 기반으로 가변 길이 코드 생성 | 압축률, 코드표 크기 |
| 이미지·멀티미디어 | JPEG 등에서 양자화 후 계수 부호화 | 비트율, 복원 품질 |
| 통신 데이터 | 반복 분포가 있는 메시지를 무손실 압축 | 지연, 전송량 |

## 6. 결론

허프만 코딩은 빈도 기반 접두사 코드로 평균 코드 길이를 줄이는 대표적인 무손실 압축 기법이다. 빈도 분포, 트리 구성, 코드표 오버헤드, 오류 전파가 같은 흐름으로 연결되어야 RLE·산술 코딩과의 선택 기준도 명확해진다.
