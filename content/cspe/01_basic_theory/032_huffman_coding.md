## 미리 알고가기

- 가변 길이 부호: 기호마다 서로 다른 길이의 비트를 부여하는 방식임
- prefix code: 어떤 코드도 다른 코드의 접두사가 되지 않는 부호임
- 빈도 기반 압축: 자주 나오는 기호에 짧은 코드를 부여함

## Ⅰ. 개요

- **정의/개념**: 허프만 코딩은 기호 발생 빈도를 기준으로 이진 트리를 구성해 평균 코드 길이를 최소화하는 대표적인 무손실 가변 길이 부호화 방식임
- **배경/필요성**: 고정 길이 코드는 드문 기호와 빈번한 기호를 같은 비용으로 저장하므로, 데이터 분포를 반영한 압축 방식이 필요함

## Ⅱ. 특징

- 빈도가 높을수록 짧은 코드를 부여해 평균 길이를 줄임
- prefix code라서 경계 구분자 없이도 복호 가능함
- 구현이 단순하고 범용 무손실 압축의 기본 블록으로 널리 쓰임
- 확률이 크게 치우치지 않거나 적응성이 필요할 때는 효율이 제한될 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | 고정 길이 부호 | 허프만 코딩 | 산술 코딩 |
|:---|:---|:---|:---|
| 코드 길이 | 동일 | 가변 | 구간 기반 |
| 복호 단순성 | 높음 | 높음 | 상대적으로 낮음 |
| 압축 효율 | 낮음 | 중간~높음 | 매우 높음 |
| 대표 적용 | 문자 집합 기본 인코딩 | ZIP, JPEG 일부 | 고효율 코덱 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 빈도표 | 각 기호 출현 횟수이며 트리 구성의 입력임 |
| 최소 힙 | 가장 낮은 빈도 노드를 선택하고 효율적 병합 구조임 |
| 허프만 트리 | 병합 결과로 생성되는 이진 트리이며 코드 길이를 결정함 |
| 코드북 | 기호별 비트열 매핑표이며 인코딩/디코딩 기준임 |

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 빈도계산 | --> | 노드병합 | --> | 트리생성 | --> | 코드부여 |
+----------+     +----------+     +----------+     +----------+
```

1. **빈도계산**: 입력 데이터의 기호 출현 빈도를 셈
2. **노드병합**: 가장 작은 두 노드를 반복 병합함
3. **트리생성**: 단일 루트가 남을 때까지 트리를 만듦
4. **코드부여**: 좌우 경로를 0과 1로 매겨 코드북을 생성함

## Ⅵ. 문제점 및 해결 방안

1. **동적 데이터 분포 변화에 약함**: 초기 빈도표가 맞지 않으면 효율이 떨어짐
   - **해결 방안**: 적응형 허프만 또는 블록 단위 재학습을 적용하고 평균 코드 길이로 검증함
2. **메타데이터 오버헤드가 발생함**: 코드북 저장 비용이 필요함
   - **해결 방안**: canonical Huffman으로 코드북 표현을 줄임 헤더 크기로 검증함
3. **확률 차이가 작으면 개선 폭이 제한됨**: 거의 균등 분포에서는 이점이 작음
   - **해결 방안**: 산술 코딩이나 다른 전처리와 결합하고 압축률로 검증함

## Ⅶ. 적용 사례

- 파일 압축기: 문자와 바이트 빈도 기반 무손실 압축을 수행함, 확인 지표는 압축률과 복호 속도임
- 이미지 코덱: 변환 계수의 빈도 분포를 이용해 추가 압축함, 확인 지표는 비트레이트임
- 임베디드 로그 저장: 반복 패턴이 있는 이벤트를 짧게 저장함, 확인 지표는 저장 공간 절감률임

## Ⅷ. 결론

허프만 코딩은 빈도 편향이 있는 데이터에서 가장 실용적인 기본 압축 방식이므로, 압축률뿐 아니라 코드북 오버헤드와 데이터 분포 안정성을 함께 봐야 함.
