## 미리 알고가기

- 가변 길이 부호: 기호별 발생 빈도에 따라 서로 다른 길이의 코드를 쓰는 방식임
- 접두 부호: 어떤 코드도 다른 코드의 앞부분이 아니어서 즉시 복호 가능한 코드임
- 엔트로피: 평균 정보량이며 무손실 압축률의 이론 하한임
- 최소 힙: 가장 작은 빈도 노드 두 개를 $O(\log n)$ 삭제 연산으로 꺼내는 자료구조임
- 코드북: 기호와 허프만 코드의 대응표임

## 작성 근거(검토용)

- 키워드의 본질이 빈도 기반 가변 길이 부호이므로 정의와 특징을 이 축으로 통일함
- 접두 부호를 별도 용어로 설명해 즉시 복호가 가능한 이유를 앞에서 정리함
- 비교표는 고정 길이와 산술 코딩을 두어 단순성·효율·복잡도 판단이 보이게 함
- 구성요소는 빈도표·힙·트리·코드북으로 실제 구현 순서를 따라 배치함
- 코드북 오버헤드와 분포 변화는 압축 알고리즘 선택을 바꾸는 핵심 조건임

## Ⅰ. 개요

- **정의/개념**: 허프만 코딩은 빈도가 높은 기호에 짧은 코드를 배정하는 접두 부호 기반 무손실 압축 알고리즘임
- **배경/필요성**: 데이터의 평균 비트 수를 줄이기 위해 빈도 편중을 반영하는 부호화가 필요함

## Ⅱ. 특징

- 빈도 기반 이진 트리로 평균 코드 길이를 줄임
- 접두 부호 조건으로 구분자 없이 순차 복호함
- 가장 낮은 빈도의 두 노드를 반복 결합하는 탐욕 구조임
- 기호 확률이 2의 거듭제곱 꼴에 가까울수록 엔트로피에 더 근접함

## Ⅲ. 종류 및 비교

| 구분 | 고정 길이 부호 | 허프만 코딩 | 산술 코딩 |
|:---|:---|:---|:---|
| 부호 길이 | 기호마다 동일 | 기호마다 가변 | 메시지 전체를 구간으로 표현 |
| 압축 기준 | 문자 집합 크기 | 기호 발생 빈도 | 누적 확률 구간 |
| 복호 특성 | 위치만 알면 복호 | 트리 탐색으로 즉시 복호 | 구간 연산 필요 |
| 부호화 단위 | 기호별 고정 폭 코드 | 기호별 정수 길이 접두 코드 | 메시지 전체의 확률 구간 |
| 대표 적용 사례 | 고정 폭 식별자·상태 코드 | ZIP·JPEG 압축 | 영상의 고압축 엔트로피 부호화 |
| 유의점 | 중복 제거 어려움 | 코드북 오버헤드 존재 | 계산 복잡도 높음 |

> 요약: 허프만 코딩은 빈도 편중이 있는 데이터에서 구현 부담 대비 압축 이득이 큼.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 빈도표 | 원본에서 각 기호의 출현 횟수를 집계함 |
| 최소 힙 | 가장 낮은 빈도 노드 두 개를 선택함 |
| 내부 노드 | 두 하위 노드의 빈도 합을 저장함 |
| 단말 노드 | 실제 기호를 저장하며 루트 경로가 코드가 됨 |
| 코드북 | 생성된 코드를 인코더와 디코더가 공유함 |

```text
빈도: A=5, B=2, C=1, D=1

결합: (C:1)+(D:1)->2
      (B:2)+(CD:2)->4
      (A:5)+(BCD:4)->9

경로: 왼쪽=0, 오른쪽=1
```

> 요약: 허프만 트리는 낮은 빈도 노드를 먼저 묶어 높은 빈도 기호가 짧은 경로를 갖게 함.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+   +----------+   +----------+   +----------+
| 빈도 집계 | -> | 힙 삽입  | -> | 노드 결합 | -> | 코드 생성 |
+----------+   +----------+   +----------+   +----------+
```

1. 원본 데이터를 스캔해 기호별 빈도를 계산함
2. 모든 기호를 빈도 기준 최소 힙에 넣음
3. 최저 빈도 노드 두 개를 꺼내 부모 노드로 결합함
4. 루트에서 단말까지의 0/1 경로를 코드북에 기록함
5. 원본 기호를 코드북 비트열로 치환함

> 요약: 빈도 집계에서 코드북 생성까지 완료되어야 압축과 복호가 같은 트리 기준을 공유함.

## Ⅵ. 실무 사례

1. 작은 파일은 코드북 헤더가 압축 이득을 넘으면 비효율적이므로 최소 크기 기준을 두고 압축 전후 크기로 확인함
2. 데이터 분포가 바뀌는 스트림은 정적 트리 효율이 떨어지므로 블록 단위 재학습이나 적응형 방식을 적용하고 압축률·부호화 지연으로 검증함

## Ⅶ. 결론

- 허프만 코딩은 빈도 편중을 접두 부호로 바꾸어 압축률과 복호 속도를 균형 있게 확보하는 대표 무손실 압축 방식임
