## 미리 알고가기

- 재귀(Recursion): 함수가 같은 문제의 더 작은 입력으로 자기 자신을 호출하는 방식임
- 종료 조건(Base Case): 재귀 호출을 멈추고 직접 결과를 반환하는 조건임
- 점화식(Recurrence): 입력 크기별 비용을 이전 비용으로 표현한 식임
- 분할 정복: 문제를 나누고 각각 해결한 뒤 결과를 합치는 전략임
- 마스터 정리: $T(n)=aT(n/b)+f(n)$에서 하위 문제와 결합 비용의 성장률을 비교해 점근 복잡도를 판정하는 정리임
- 마스터 정리 기호: $a$는 하위 문제 수, $b$는 축소 계수, $n/b$는 하위 문제 크기, $f(n)$은 분할·결합 비용, $\epsilon>0$은 성장률 차이를 나타내는 상수임
- 정규성 조건: Case 3에서 어떤 $c < 1$, $n_0$에 대해 $n \ge n_0$이면 $af(n/b) \le cf(n)$을 만족해야 한다는 조건임
- 점근 표기 $O$·$\Theta$·$\Omega$: 각각 복잡도의 상한·동일 성장률·하한을 나타내는 표기임
- 추상 구문 트리(AST): 프로그램의 문법 구조를 트리로 표현한 구조임

## 작성 근거(검토용)

- 개요는 재귀와 마스터 정리를 함께 정의해 구현 방식과 분석 도구를 연결함
- 특징은 자기 유사 호출 구조, 스택 비용, 지배 비용 비교, 적용 한계를 판단 기준으로 선정함
- Ⅲ은 세 케이스의 판정 조건, 비용 관계, 시간복잡도를 압축함
- 구조 도식은 $a$, $b$, $f(n)$의 의미가 마스터 정리 이해의 중심이므로 재귀 구조로 표시함
- Ⅴ는 점화식 수립부터 복잡도 결정까지 마스터 정리를 실제로 적용하는 순서를 다룸
- 스택 오버플로는 Ⅱ·Ⅵ에서, 마스터 정리 오적용(간극 구간)은 Ⅴ에서 재귀 분석의 대표 실패 조건으로 다룸

## Ⅰ. 개요

- **정의/개념**: 재귀 알고리즘은 동일 구조의 하위 문제를 반복 호출해 해결하며, 마스터 정리는 균등 분할 재귀의 시간복잡도를 판정함
- **배경/필요성**: 반복 분할 알고리즘의 성능 한계를 판단하기 위해 점화식 기반 복잡도 분석이 필요함

## Ⅱ. 특징

- 재귀는 자기 유사한 하위 문제를 함수 호출로 표현하며 호출마다 스택 공간을 사용함
- 종료 조건이 없거나 부정확하면 무한 호출과 스택 오버플로가 생김
- 마스터 정리는 하위 문제 비용과 결합 비용의 성장률을 비교함
- 불균등 분할이나 크기가 $n-1$로 줄어드는 재귀는 재귀 트리·대입법으로 분석함

## Ⅲ. 종류 및 비교

$$T(n)=aT(n/b)+f(n), \quad a \ge 1, b > 1$$

| 판단 기준 | Case 1 | Case 2 | Case 3 |
|:---|:---|:---|:---|
| 판정 조건 | $f(n)=O(n^{\log_b a-\epsilon})$ | $f(n)=\Theta(n^{\log_b a})$ | $f(n)=\Omega(n^{\log_b a+\epsilon})$, 정규성 충족 |
| 비용 관계 | 하위 문제 비용 지배 | 동일 차수 | 결합 비용 지배 |
| 결과 | $\Theta(n^{\log_b a})$ | $\Theta(n^{\log_b a}\log n)$ | $\Theta(f(n))$ |

> 요약: 마스터 정리는 하위 문제와 결합 비용의 상대 성장률로 재귀 시간복잡도를 판정함.

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 종료 조건 | 입력이 직접 답을 구할 수 있는 최소 처리 단위에 도달하면 추가 호출을 종료함 |
| 하위 문제 수 $a$ | 한 번의 함수 호출에서 생성하는 크기 $n/b$의 부분 문제 개수 |
| 축소 계수 $b$ | 하위 문제 크기 $n/b$의 분할 계수 |
| 결합 비용 $f(n)$ | 부분 해의 분할·병합·후처리에 추가로 소요되는 실행 시간 |
| 호출 스택 | 지역 변수·복귀 지점 저장 공간 |

```text
[ 재귀 구조 ]
문제 크기 n
  -> 크기 n/b인 하위 문제 a개
  -> 결합 비용 f(n)
```

> 요약: 재귀 비용은 하위 문제 수, 축소 계수, 결합 비용의 상대 성장으로 결정됨.

## Ⅴ. 마스터 정리 적용 절차

```text
점화식 수립 -> log_b(a) 계산 -> f(n)과 n^log_b(a) 비교 -> 케이스 판정 -> 복잡도 결정/예외 처리
```

1. **점화식 수립**: 분할 정복 구조에서 하위 문제 수 $a$, 축소 계수 $b$, 결합 비용 $f(n)$을 정의함
2. **기준 차수 계산**: $\log_b a$를 구해 하위 문제 비용의 점근 차수를 정함
3. **성장률 비교**: $f(n)$과 $n^{\log_b a}$의 점근 차수를 비교해 어느 항이 지배하는지 판단함
4. **케이스 판정**: 비교 결과를 Case 1·Case 2·Case 3 조건과 대조하고, Case 3이면 정규성 조건을 추가로 확인함
5. **복잡도 결정**: 판정된 케이스의 결과로 $T(n)$의 점근 복잡도를 확정함
6. **예외 처리**: 세 케이스 조건에 모두 해당하지 않으면 마스터 정리 대신 재귀 트리·대입법으로 분석함

> 요약: 점화식에서 $a$, $b$, $f(n)$을 정의한 뒤 $f(n)$과 $n^{\log_b a}$의 성장률을 비교해 케이스를 판정하고, 세 케이스에 모두 해당하지 않으면 재귀 트리·대입법으로 분석함.

## Ⅵ. 실무 사례

1. 재귀 AST 처리는 명시적 스택으로 전환하고 최대 깊이·메모리 사용량으로 검증함
2. 병합 정렬은 $T(n)=2T(n/2)+\Theta(n)$으로 모델링하고 입력 크기별 실행 시간 증가율로 검증함

## Ⅶ. 결론

- 재귀 알고리즘은 종료 조건을 보장하고 호출 깊이를 통제하며, 마스터 정리 적용 가능성을 먼저 확인해 복잡도를 판단함
