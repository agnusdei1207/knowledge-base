## 미리 알고가기

- 재귀식: 큰 문제를 더 작은 문제로 나누는 시간 복잡도 식임
- 분할 정복: 문제를 부분 문제로 나누고 결합하는 전략임
- 마스터 정리: $T(n)=aT(n/b)+f(n)$ 형태의 점화식을 해석하는 규칙임

## Ⅰ. 개요

- **정의/개념**: 재귀 알고리즘은 자기 자신을 더 작은 입력에 적용해 문제를 해결하는 방식이며, 마스터 정리는 대표 점화식의 시간 복잡도를 빠르게 판정하는 도구임
- **배경/필요성**: 병합정렬, 퀵정렬, 트리 탐색처럼 재귀 구조는 많지만, 성능을 감으로 판단하면 실제 확장성을 놓치기 쉬움

## Ⅱ. 특징

- 문제 구조가 계층적일 때 구현이 자연스럽고 명확함
- 종료 조건과 부분 문제 크기 감소가 올바름의 핵심임
- 마스터 정리는 분할 수, 축소 비율, 결합 비용의 관계를 비교함
- 모든 재귀식에 적용되지는 않으며 비정형 분할은 다른 기법이 필요함

## Ⅲ. 종류 및 비교

| 판단 기준 | 재귀 알고리즘 | 반복 알고리즘 |
|:---|:---|:---|
| 표현력 | 계층 구조에 자연스러움 | 단순 반복에 유리 |
| 메모리 | 호출 스택 사용 | 상대적으로 적음 |
| 분석 방식 | 점화식 중심 | 루프 반복 수 중심 |
| 대표 적용 | 트리, 분할정복 | 순차 처리, 스캔 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 종료 조건 | 재귀 중단 기준이며 무한 재귀 방지 장치임 |
| 부분 문제 | 더 작은 동일 형태 문제이며 올바른 축소가 중요함 |
| 결합 단계 | 부분 결과를 합치는 과정이며 전체 복잡도 좌우 요소임 |
| 점화식 | 실행 시간을 수식화하고 마스터 정리 입력임 |

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 문제분할 | --> | 재귀호출 | --> | 결과결합 | --> | 복잡도판단 |
+----------+     +----------+     +----------+     +----------+
```

1. **문제분할**: 입력을 더 작은 동일 유형 문제로 나눔
2. **재귀호출**: 각 부분 문제를 재귀적으로 해결함
3. **결과결합**: 부분 해를 합쳐 최종 답을 만듦
4. **복잡도판단**: 점화식을 세우고 마스터 정리로 해석함

## Ⅵ. 문제점 및 해결 방안

1. **호출 스택 오버헤드가 큼**: 깊은 재귀는 메모리 부담이 커짐
   - **해결 방안**: tail recursion 최적화나 반복문 변환을 검토하고 stack depth로 검증함
2. **마스터 정리 적용 범위를 오해할 수 있음**: 비균등 분할에는 직접 적용되지 않음
   - **해결 방안**: Akra-Bazzi나 재귀 트리 기법으로 보완하고 점화식 형태로 검증함
3. **종료 조건 누락이 치명적임**: 무한 재귀와 오동작이 발생함
   - **해결 방안**: base case 테스트를 우선 검증하고 boundary test pass로 검증함

## Ⅶ. 적용 사례

- 병합정렬: $T(n)=2T(n/2)+O(n)$으로 $O(n \log n)$을 도출함, 확인 지표는 실행시간 성장률임
- 트리 순회: 노드 구조를 재귀적으로 처리함, 확인 지표는 stack depth임
- 행렬 분할 알고리즘: 재귀 분할로 계산을 최적화함, 확인 지표는 subproblem size 균형임

## Ⅷ. 결론

재귀 알고리즘의 핵심은 코드 모양보다 문제 축소 구조에 있으므로, 구현 전에 점화식과 종료 조건부터 먼저 검증해야 함.
