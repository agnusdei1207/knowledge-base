## 미리 알고가기

- 재귀(Recursion): 함수가 같은 문제의 더 작은 입력으로 자기 자신을 호출하는 방식임
- 기저 조건(Base Case): 재귀 호출을 멈추고 직접 답을 반환하는 조건임
- 점화식(Recurrence): 입력 크기별 비용을 이전 비용으로 표현한 식임
- 분할 정복: 문제를 나누고 각각 해결한 뒤 결과를 합치는 전략임
- 마스터 정리: $T(n)=aT(n/b)+f(n)$ 형태의 점화식을 빠르게 해석하는 정리임

## Ⅰ. 개요

- **정의/개념**: 재귀 알고리즘은 동일 구조의 하위 문제를 반복 호출해 해결하며, 마스터 정리는 균등 분할 재귀의 시간복잡도를 판정함
- **배경/필요성**: 이진 탐색·병합 정렬처럼 반복 분할되는 알고리즘은 점화식 분석 없이는 성능 한계를 판단하기 어려움

## Ⅱ. 특징

- 재귀는 문제 구조를 단순하게 표현하지만 호출 스택 비용을 발생시킴
- 기저 조건이 없거나 약하면 무한 호출과 스택 오버플로가 생김
- 마스터 정리는 하위 문제 비용과 분할·결합 비용의 성장률을 비교함
- 불균등 분할이나 선형 재귀에는 재귀 트리·대입법 같은 별도 분석이 필요함

## Ⅲ. 종류 및 비교

$$T(n)=aT(n/b)+f(n), \quad a \ge 1, b > 1$$

| 판단 기준 | Case 1 | Case 2 | Case 3 |
|:---|:---|:---|:---|
| 성장 비교 | $f(n)$이 작음 | $f(n)$과 $n^{\log_b a}$가 같음 | $f(n)$이 큼 |
| 지배 비용 | 하위 문제 | 각 레벨 균형 | 분할·결합 작업 |
| 결과 | $\Theta(n^{\log_b a})$ | $\Theta(n^{\log_b a}\log n)$ | $\Theta(f(n))$ |
| 예시 | 이진 탐색 | 병합 정렬 | 큰 결합 비용 재귀 |

> 요약: 마스터 정리는 하위 문제 수와 결합 비용 중 무엇이 지배하는지 판정하는 도구임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 기저 조건 | 더 작은 문제로 나누지 않고 직접 해결하는 종료 조건임 |
| 하위 문제 수 $a$ | 한 단계에서 생성되는 재귀 호출 개수임 |
| 축소 비율 $b$ | 하위 문제 입력 크기가 줄어드는 비율임 |
| 결합 비용 $f(n)$ | 분할, 병합, 후처리에 드는 재귀 외 비용임 |
| 호출 스택 | 재귀 호출의 지역 변수와 복귀 지점을 저장함 |

```text
[ 재귀 구조 ]
Problem(n)
  -> a subproblems of size n/b
  -> combine cost f(n)
```

> 요약: 재귀 비용은 하위 문제 수, 축소 비율, 결합 비용의 상대 성장으로 결정됨.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 기저 확인 | --> | 문제 분할 | --> | 재귀 호출 | --> | 결과 결합 |
+----------+     +----------+     +----------+     +----------+
```

1. **기저 확인**: 입력이 충분히 작으면 직접 반환함
2. **문제 분할**: 원문제를 같은 형태의 하위 문제로 나눔
3. **재귀 호출**: 각 하위 문제를 같은 함수로 해결함
4. **결과 결합**: 하위 결과를 모아 원문제의 답을 만듦

> 요약: 재귀는 기저 조건이 종료를 보장하고 점화식이 호출 비용을 설명할 때 정확히 분석됨.

## Ⅵ. 실무 적용 및 유의점

1. 깊은 입력은 반복문이나 명시적 스택으로 바꾸고 최대 호출 깊이와 메모리 사용량으로 검증함
2. 마스터 정리 적용 전 $aT(n/b)+f(n)$의 균등 분할 형태인지 확인하고, 아니면 재귀 트리로 분석함

## Ⅶ. 결론

- 재귀 알고리즘은 종료 조건을 보장하고 호출 깊이를 통제하며, 마스터 정리 적용 가능성을 먼저 확인해 복잡도를 판단함

## 작성 근거(검토용)

- **개요 구성**: 재귀와 마스터 정리를 함께 정의해 구현 방식과 분석 도구를 연결함
- **특징 선정**: 표현 단순성, 스택 비용, 지배 비용 비교, 적용 한계가 실제 판단에 필요함
- **Ⅲ 비교축**: 세 케이스는 성장률 비교와 지배 비용이 핵심이라 결과와 예시까지 표로 압축함
- **구조 도식**: $a$, $b$, $f(n)$의 의미가 마스터 정리 이해의 중심이라 재귀 구조로 표시함
- **실무 유의점**: 스택 오버플로와 정리 오적용은 재귀 답안에서 가장 흔한 실패 조건이라 남김
