# 075. 재귀 알고리즘과 마스터 정리 (Recursive Algorithm Master Theorem)

## Ⅰ. 개요

- **정의/개념**: 재귀 알고리즘은 하나의 문제를 더 작은 동일한 형태의 하위 문제로 나누어 해결하는 방식이며, 마스터 정리는 이러한 재귀적 구조를 가진 분할 정복 알고리즘의 시간 복잡도를 공식화하여 계산하는 분석 도구임
- **배경/필요성**: 병합 정렬(Merge Sort)이나 이진 탐색(Binary Search) 등 분할 정복 모델의 성능을 매번 재귀 트리로 그리지 않고도, 공식 대입만으로 점근적 표기법(Big-O)을 도출하기 위해 필요함

## Ⅱ. 특징 및 비교

| 판단 기준 | 재귀 트리 방법 (Recursion Tree) | 마스터 정리 (Master Theorem) | 반복 대입법 (Iteration) |
|:---|:---|:---|:---|
| **분석 방식** | 각 층의 비용을 합산하여 시각화 | $T(n) = aT(n/b) + f(n)$ 공식 활용 | 재귀식을 일반식으로 반복 전개 |
| **장점** | 직관적이며 구조 파악 용이 | 가장 빠르고 간편한 계산 가능 | 모든 형태의 재귀식에 적용 가능 |
| **단점** | 복잡한 식에서 계산 실수 가능성 | 특정 형태($a, b$ 상수)에만 제한됨 | 계산 과정이 매우 번거로움 |

> 요약: 마스터 정리는 정형화된 분할 정복 재귀식의 복잡도를 단시간에 판정하는 '치트키' 역할을 수행함

## Ⅲ. 구성요소/구조

- **마스터 정리 공식**: $T(n) = aT(n/b) + f(n)$
  - **$a$ ($a \ge 1$)**: 하위 문제의 개수(분할된 개수)임
  - **$b$ ($b > 1$)**: 하위 문제의 크기 감소 비율임
  - **$f(n)$**: 문제를 분할하고 합치는데 드는 비용(overhead)임
- **시간 복잡도 판정 (3가지 Case)**:
  - **Case 1**: $f(n) = O(n^{\log_b a - \epsilon})$ 이면, $T(n) = \Theta(n^{\log_b a})$
  - **Case 2**: $f(n) = \Theta(n^{\log_b a})$ 이면, $T(n) = \Theta(n^{\log_b a} \log n)$
  - **Case 3**: $f(n) = \Omega(n^{\log_b a + \epsilon})$ 이면, $T(n) = \Theta(f(n))$

- **재귀 트리 구조도**:
```text
            T(n)              --- f(n)
           /    \
       T(n/b)  T(n/b)         --- a * f(n/b)
       /  \    /  \
     ...  ...  ...  ...       --- a^i * f(n/b^i)
```

## Ⅳ. 문제점 및 개선방안

1. **[적용 범위의 한계]**: $a$나 $b$가 상수가 아니거나, $f(n)$이 다항식이 아닌 경우(예: 지수함수) 마스터 정리를 사용할 수 없음
   - **개선방안**: 더 일반화된 공식인 Akra-Bazzi 정리를 사용하거나 직접 재귀 트리를 그려서 분석함 (확인: 공식 적합성)
2. **[스택 오버플로우 위험]**: 재귀 깊이가 너무 깊어지면 시스템의 호출 스택(Call Stack) 메모리를 초과하여 프로그램이 중단됨
   - **개선방안**: 꼬리 재귀 최적화(Tail Recursion Optimization)를 적용하거나, 스택 자료구조를 활용한 반복문(Iterative) 방식으로 전환함 (확인: 재귀 깊이 제한)
3. **[중복 연산으로 인한 비효율]**: 피보나치 수열과 같이 동일한 하위 문제를 반복해서 계산하는 경우 지수 시간 복잡도가 발생함
   - **개선방안**: 동적 계획법(DP)의 메모이제이션(Memoization) 기술을 결합하여 이미 계산된 결과는 재사용함 (확인: 시간 복잡도 개선 여부)

## Ⅴ. 실무 적용 사례

| 적용 영역 | 재귀식 ($T(n) = aT(n/b) + f(n)$) | 마스터 정리 결과 |
|:---|:---|:---|
| **이진 탐색 (Binary Search)** | $T(n) = T(n/2) + O(1)$ | $O(\log n)$ |
| **병합 정렬 (Merge Sort)** | $T(n) = 2T(n/2) + O(n)$ | $O(n \log n)$ |
| **행렬 곱셈 (Strassen)** | $T(n) = 7T(n/2) + O(n^2)$ | $O(n^{\log_2 7}) \approx O(n^{2.81})$ |

> 요약: 실무 개발 시 알고리즘의 성능 병목을 예측하기 위해 마스터 정리를 기반으로 한 복잡도 분석을 선행함

## Ⅵ. 결론

재귀 알고리즘은 복잡한 문제를 단순 명쾌하게 표현할 수 있는 강력한 도구이며, 마스터 정리는 이를 정량적으로 평가할 수 있는 논리적 잣대임. 단순히 공식을 암기하는 것보다 분할하는 개수($a$)와 줄어드는 크기($b$)가 전체 성능에 미치는 영향을 이해하는 것이 중요함. 최근에는 하드웨어의 병렬 처리를 고려하여 재귀 호출을 멀티코어 환경에서 분산 실행하는 병렬 알고리즘 분석으로 그 개념이 확장되고 있음.
