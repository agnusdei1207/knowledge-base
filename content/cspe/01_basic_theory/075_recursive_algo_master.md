# 재귀 알고리즘·마스터 정리 (Recursive Algorithm Master Theorem)

## 1. 개요

- **정의/개념**: 재귀 알고리즘은 문제를 더 작은 같은 형태의 문제로 나누어 해결하는 알고리즘이고, 마스터 정리는 특정 재귀식의 시간복잡도를 빠르게 구하는 분석 도구이다.
- **배경/필요성**: 분할 정복 알고리즘은 재귀 호출 수와 결합 비용이 성능을 결정하므로, 재귀식으로 비용을 모델링하고 점근 복잡도를 판단해야 한다.

재귀 분석의 핵심은 코드 모양보다 `T(n)=aT(n/b)+f(n)`에서 호출 수, 문제 축소 비율, 결합 비용을 읽는 것이다.

## 2. 특징 및 비교

| 구분 | 재귀 분석 | 마스터 정리 |
|---|---|---|
| 대상 | 모든 재귀 구조 | 특정 형태 재귀식 |
| 장점 | 일반적 | 빠른 차수 판정 |
| 필요 요소 | 기저 조건, 호출 관계 | `a`, `b`, `f(n)` |
| 한계 | 풀이 복잡 | 적용 조건 제한 |

선택 기준은 재귀식 형태, 부분 문제 크기 균등성, 결합 비용, 기저 조건이다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| Base Case | 재귀 종료 조건 | 무한 호출 방지 |
| Recursive Case | 자기 호출 구조 | 문제 축소 |
| a | 하위 문제 개수 | 분기 수 |
| b | 입력 크기 감소 비율 | 축소율 |
| f(n) | 분할·결합 비용 | 지배항 판단 |

```text
문제 -> 하위문제 a개 -> 크기 n/b -> 결합비용 f(n) -> T(n)
```

마스터 정리는 하위 문제 전체 비용과 결합 비용 중 무엇이 지배적인지 비교해 복잡도를 결정한다.

## 4. 문제점 및 개선방안

1. **적용 조건 오판**
   - 하위 문제 크기가 불균등하거나 형태가 맞지 않으면 마스터 정리를 바로 적용할 수 없다.
   - **개선방안**: recursion tree, substitution, Akra-Bazzi를 검토한다.

2. **기저 조건 누락**
   - 종료 조건이 불명확하면 알고리즘이 끝나지 않거나 stack overflow가 발생한다.
   - **개선방안**: 입력 최소 조건과 감소 보장을 명시한다.

3. **재귀 공간 비용 누락**
   - 시간복잡도만 보고 호출 스택 공간을 빠뜨릴 수 있다.
   - **개선방안**: 재귀 깊이와 stack space를 함께 산정한다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| 병합 정렬 분석 | `T(n)=2T(n/2)+O(n)`으로 `O(n log n)` 도출 | 시간복잡도 |
| 이진 탐색 분석 | `T(n)=T(n/2)+O(1)`로 `O(log n)` 도출 | 비교 횟수 |
| 재귀 코드 검토 | 종료 조건과 재귀 깊이 확인 | stack 사용량 |

## 6. 결론

재귀 알고리즘 분석은 기저 조건, 문제 축소, 결합 비용을 연결해 비용을 설명하는 과정이다. 마스터 정리는 빠른 도구이지만 적용 조건이 맞을 때만 유효하므로, 재귀식의 구조를 먼저 확인해야 한다.
