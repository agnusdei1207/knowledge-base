## Ⅰ. 개요
- **정의**: 해석적 풀이가 불가능한 수학 문제를 근사값으로 구하는 계산 기법
- **배경/필요성**: 비선형 방정식, 편미분방정식 등 닫힌 형태 해가 존재하지 않는 문제가 공학·과학 전반에 존재하므로 근사 해법이 필수임
- **비유**: 자를 대고 곡선 길이를 재듯, 복잡한 곡선을 짧은 직선 조각으로 쪼개어 합산하는 것과 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 근사 알고리즘의 수렴 조건 이해 | 오차 한계와 수렴 차수 구분 | 안정성과 수렴성을 혼동하지 않을 것 |

> 요약: 닫힌 해가 없는 문제를 반복 근사로 풀어내는 계산 기법임

## Ⅱ. 구성요소
```text
  Numerical Methods
        |
  +-----+-----+-----+-----+
  |     |     |     |     |
 근의  보간법  수치  수치  선형
 탐색        미분  적분  대수
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 근의 탐색 | 이분법·뉴턴법 등으로 f(x)=0의 근을 반복 축소하여 찾음 | 숫자 맞추기 게임에서 범위를 절반씩 줄이는 것 |
| 보간법 | 알려진 데이터 점 사이의 미지 값을 다항식으로 추정함 | 점 사이를 부드러운 곡선으로 잇는 것 |
| 수치 미분 | 미분을 차분 몫(difference quotient)으로 근사함 | 순간 속도를 짧은 구간 평균 속도로 대체하는 것 |
| 수치 적분 | 사다리꼴·심프슨 공식 등으로 정적분 값을 근사함 | 곡선 아래 면적을 직사각형 합으로 어림하는 것 |
| 선형 대수 | 가우스 소거·LU 분해 등으로 연립방정식을 풀음 | 미지수를 하나씩 소거해 답을 좁혀가는 것 |

> 요약: 근 탐색·보간·미적분 근사·선형 대수가 수치 해석의 5대 기둥임

## Ⅲ. 절차
```text
  모델 수립       이산화          반복 계산       오차 검증
  (연속 문제)    (격자/노드)     (근사값 갱신)   (수렴 판정)
    |               |               |               |
    +---변환------->+---대입------->+---비교------->+
  수학 모델       차분 방정식     갱신 공식       허용 오차
```
- 1단계: 물리·공학 문제를 수학 모델(방정식)로 정식화함
- 2단계: 연속 영역을 이산 격자·노드로 분할하여 차분 방정식을 구성함
- 3단계: 갱신 공식을 반복 적용하여 근사값을 점진 수렴시킴
- 4단계: 연속 반복 간 오차가 허용 범위 이내인지 검증 후 종료함

> 요약: 연속 문제를 이산화한 뒤 반복 계산으로 수렴을 확인하는 4단계 흐름임

## Ⅳ. 문제점
- 수렴 실패: 초기값 선택이 부적절하면 발산하거나 진동함 — 뉴턴법에서 도함수 0 근방 시작 시 발생
- 오차 누적: 부동소수점 연산의 라운딩 오차가 반복마다 전파됨 — 대규모 연립계에서 해의 신뢰도 저하
- 계산 비용: 격자 해상도를 높이면 정확도는 오르나 연산량이 지수적으로 증가함 — 3차원 문제에서 심각

> 요약: 수렴 실패·오차 누적·계산 비용이 수치 해석의 3대 리스크임

## Ⅴ. 개선방안
1. 단기: 적응적 초기값 선택과 다중 시작점 전략으로 수렴 실패 방지
2. 중기: 구간 연산(interval arithmetic)·보상 합산(Kahan summation) 적용으로 오차 전파 억제
3. 장기: 적응적 격자 세분화(AMR)와 병렬 솔버 도입으로 정확도-비용 트레이드오프 완화

> 요약: 초기값 전략·오차 보상·적응 격자로 각 문제를 대응함
