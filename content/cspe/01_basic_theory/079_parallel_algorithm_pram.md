## Ⅰ. 개요
- 정의: 다수의 프로세서가 공유 메모리를 통해 동시에 연산을 수행하는 알고리즘임.
- 배경: 단일 프로세서의 성능 한계를 극복하고 대규모 연산을 가속화하기 위함임.
- 출제 의도:
| 분류 | 상세 |
| --- | --- |
| 핵심요소 | PRAM, EREW, CREW, CRCW, 가속도(Speedup) |
| 주요특징 | 공유 메모리 접근 방식, 동기화 처리, 연산 효율 |

## Ⅱ. 구성요소
- ASCII 구조도
 [P1] [P2] ... [Pn] (Processors)
  |    |         |
 [   Shared Memory   ] (PRAM)
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| EREW | 배타적 읽기/쓰기 (가장 제한적) | 1인용 열람실 |
| CREW | 동시 읽기 가능, 배타적 쓰기 | 공동 열람, 1인 집필 |
| CRCW | 동시 읽기/쓰기 가능 (가장 강력) | 자유 게시판 |
> 요약: 다수 연산자가 메모리를 공유하며 협업하는 가상의 계산 모델임.

## Ⅲ. 절차
- ASCII 흐름도
[작업 분할] -> [프로세서 할당] -> [동시 수행] -> [결합/동기화]
- 4단계 설명
1. 태스크 분해: 전체 문제를 독립적으로 처리 가능한 조각으로 나눔.
2. 부하 분산(Balancing): 각 프로세서에 균등한 연산량을 배정함.
3. 병렬 연산: PRAM 모델의 읽기/쓰기 규칙에 따라 동시 실행함.
4. 브렌트의 정리 적용: 프로세서 수와 시간에 따른 효율성을 평가함.
> 요약: 작업을 쪼개어 동시에 처리하고 메모리 충돌 없이 결과를 합침.

## Ⅳ. 문제점
- 공유 메모리 경쟁(Contention)으로 인한 병목 및 동기화 오버헤드가 발생함.

## Ⅴ. 개선방안
- 단기: 메모리 접근 패턴을 분석하여 충돌이 적은 EREW 기반으로 재설계함.
- 중기: 상호 배제(Mutex) 및 원자적 연산을 최적화하여 지연을 줄임.
- 장기: 분산 메모리 모델(Message Passing)로의 확장을 고려함.

## Ⅵ. 전망
- 프로세서 간 통신 오버헤드를 최소화하는 메모리 접근 패턴 최적화가 핵심이며, 향후 엑사스케일 컴퓨팅 환경에서의 대규모 동기화 제어 및 이기종 멀티코어 최적화를 위한 PRAM 기반 병렬 프로그래밍 모델의 확장이 전망됨.
- 특히 GPU의 대규모 병렬 구조를 효율적으로 활용하기 위한 알고리즘 설계 지침으로서 딥러닝 가속기 및 대규모 과학 시뮬레이션 분야의 성능 최적화에 기여할 것임.
