## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 유한 상태와 전이 규칙으로 문자열을 인식하는 추상 기계로, 결정적(DFA)과 비결정적(NFA)으로 분류됨 |
| **배경/필요성** | 정규 표현식·어휘 분석기·프로토콜 검증 등에서 패턴 매칭과 형식 언어 인식의 이론적 기반이 필요함 |
| **출제 의도** | DFA·NFA의 동작 차이와 등가성, 정규 언어와의 관계를 설명할 수 있는지 평가함 |

## Ⅱ. 구성요소
```
+----------+     +----------+     +----------+
| 상태집합  | --> | 전이함수  | --> | 수락상태  |
|  (Q)     |     | (δ)      |     | (F)      |
+----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| 상태 집합(Q) | 오토마타가 가질 수 있는 유한 개의 상태임 | 신호등 상태(빨·노·초) |
| 전이 함수(δ) | 현재 상태와 입력 기호에 따라 다음 상태를 결정하는 규칙임 | 신호 변경 규칙 |
| 수락 상태(F) | 입력 처리 후 이 상태에 도달하면 문자열을 수락(인식)함 | 초록불(통과 허가) |

> 요약: 상태(Q) + 전이(δ) + 수락(F)으로 입력 문자열의 인식 여부를 판별함.

## Ⅲ. 절차
```
+------------+     +------------+
| 초기상태   | --> | 입력읽기   |
| (q0)       |     | (한 문자)  |
+------------+     +------------+
                        |
+------------+     +----+-------+
| 수락/거부  | <-- | 상태전이  |
| 판정       |     | δ(q, a)  |
+------------+     +------------+
```

1. 초기화: 시작 상태 q0에서 출발함
2. 입력 읽기: 입력 문자열의 기호를 하나씩 순서대로 읽음
3. 상태 전이: DFA는 δ(q, a)로 유일한 다음 상태를, NFA는 가능한 상태 집합을 전이함
4. 수락 판정: 모든 입력 처리 후 현재 상태가 수락 상태(F)에 포함되면 수락, 아니면 거부함

> 요약: 초기 상태 → 입력별 전이 → 수락/거부로 문자열 인식을 수행함.

## Ⅳ. 문제점
- DFA 상태 폭발: NFA를 DFA로 변환(부분집합 구성법) 시 상태 수가 2^n으로 폭발할 수 있음
- NFA 비결정성: 동시에 여러 경로를 추적해야 하여 구현 시 백트래킹 또는 상태 집합 관리가 필요함
- 정규 언어 한계: 유한 오토마타는 정규 언어만 인식하며, 괄호 짝 맞춤 등 문맥 자유 언어는 불가함

## Ⅴ. 개선방안
- (단기) Lazy DFA 구성: 전체 DFA를 미리 구성하지 않고, 필요한 상태만 동적으로 생성함
- (중기) 확장 오토마타: 푸시다운 오토마타(PDA)로 문맥 자유 언어를 인식하여 표현력을 확장함
- (장기) 형식 검증: 모델 체킹에서 오토마타 기반 상태 공간 탐색으로 시스템 정확성을 검증함

## Ⅵ. 전망
- 정규 표현식 엔진·네트워크 패킷 필터·하드웨어 제어기 설계에서 유한 오토마타가 핵심이며, 형식 검증·자동 코드 생성에서 오토마타 이론의 적용이 확대될 전망임
