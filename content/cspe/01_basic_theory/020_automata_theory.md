## Ⅰ. 개요
- **정의**: 입력 기호열을 읽으며 상태를 전이하여 언어를 인식하는 추상 계산 모델
- **배경/필요성**: 컴파일러 어휘 분석, 프로토콜 검증 등에서 패턴 매칭의 수학적 기초가 요구됨. 정규 언어(021 참조)를 인식하는 가장 단순한 계산 모델로서 상위 문법 이론의 출발점임
- **비유**: 지하철 개찰구가 승차권 유형에 따라 열림/닫힘 상태를 전환하는 것과 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| DFA·NFA 차이와 등가성 | 부분집합 구성(Subset Construction)으로 NFA를 DFA로 변환 | NFA가 DFA보다 "강력"한 것이 아님 — 인식 능력은 동일함 |

> 요약: DFA·NFA는 표현력이 동일하며 정규 언어를 인식하는 유한 상태 머신임

## Ⅱ. 구성요소
```text
입력 기호열
    |
    v
+----------+     전이 함수     +--------+
|  시작상태  | -------------> |  상태들  |
+----------+                 +--------+
                                  |
                                  v
                            +----------+
                            | 수락상태  |
                            +----------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 상태 집합(Q) | 오토마타가 가질 수 있는 유한개의 내부 상태 | 신호등의 빨강/노랑/초록 |
| 입력 알파벳(Sigma) | 오토마타가 읽을 수 있는 기호의 유한 집합 | 키보드에서 입력 가능한 글자 목록 |
| 전이 함수(delta) | 현재 상태와 입력 기호를 받아 다음 상태를 결정하는 규칙 | 신호등 타이머에 따른 색 전환 규칙 |
| 시작 상태(`q0`) | 입력 처리를 시작하는 초기 상태 (1개) | 게임 시작 화면 |
| 수락 상태 집합(F) | 입력을 모두 읽은 후 이 상태에 있으면 해당 문자열을 수락함 | 결승선 — 도달하면 통과 판정 |

> 요약: 5-튜플 (Q, Sigma, delta, `q0`, F)로 오토마타를 정의함

## Ⅲ. 절차
```text
정규식 정의 --> NFA 구성 --> DFA 변환 --> 최소화
     |              |            |            |
     v              v            v            v
  패턴 명세    Thompson    부분집합 구성   등가 상태
              구성법      (2^n 최악)      병합
```
- 1단계: 인식할 패턴을 정규식으로 명세함
- 2단계: 정규식으로부터 epsilon-전이를 포함하는 NFA를 구성함 (Thompson 구성법)
- 3단계: 부분집합 구성(Subset Construction)으로 NFA를 DFA로 변환함 — 최악 상태 수 $2^n$
- 4단계: DFA 상태 최소화(Hopcroft 알고리즘 등)로 등가 상태를 병합하여 최적 DFA를 도출함

> 요약: 정규식 → NFA → DFA → 최소 DFA 순서로 최적 인식기를 구축함

## Ⅳ. 문제점
- 상태 폭발: NFA를 DFA로 변환 시 상태 수가 $2^n$으로 증가할 수 있음 — 메모리 사용량이 지수적으로 팽창함
- 표현력 한계: 유한 상태 머신은 정규 언어만 인식 가능함 — 괄호 짝 맞춤 등 문맥 자유 언어(022 참조)는 처리 불가
- epsilon-전이 복잡성: NFA의 epsilon-전이가 많아질수록 부분집합 구성 시 epsilon-closure 연산 비용이 증가함 — 변환 시간이 길어짐

> 요약: 상태 폭발, 정규 언어 한정, epsilon-전이 비용이 주요 한계임

## Ⅴ. 개선방안
1. 단기: 지연 평가(lazy evaluation) 방식으로 DFA 상태를 필요 시에만 생성하여 상태 폭발을 완화함
2. 중기: 푸시다운 오토마타(PDA, 022 참조)로 확장하여 문맥 자유 언어까지 인식 범위를 넓힘
3. 장기: epsilon-제거(epsilon-removal) 전처리를 적용하여 변환 전 NFA를 단순화하고 구성 비용을 절감함

> 요약: 지연 생성, PDA 확장, epsilon 전처리로 각 문제를 대응함

## Ⅵ. 전망
- 발전 방향: 정규식 엔진이 DFA/NFA 하이브리드 전략을 채택하여 실용적 매칭 속도와 메모리 사이 균형을 최적화하는 추세임
- 기술사적 판단: 컴파일러·네트워크 패킷 필터링·로그 분석 등 패턴 매칭이 요구되는 시스템 설계 시 오토마타 모델 선택이 성능을 좌우함
- 기술사 제언: 정규식 복잡도가 높은 시스템에서는 DFA 상태 수 상한을 사전 산정하고, 임계치 초과 시 NFA 시뮬레이션 방식으로 전환하는 이중 전략을 수립할 것
