## Ⅰ. 개요
- 추상적인 계산 기계와 이를 통해 해결할 수 있는 문제의 수학적 모델임.
- 입력 문자열에 따른 상태 변화를 통해 언어의 수용 여부를 판별함.
- [표] 출제 의도: 형식 언어 인식 및 컴파일러 설계의 이론적 기초 검증.

## Ⅱ. 구성요소
- ASCII 구조도
  Input -> [ (Initial State) --Transition--> (Next State) ] -> Accept?

| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| DFA | 결정적 오토마타 (상태 전이 유일) | 명확한 매뉴얼 |
| NFA | 비결정적 오토마타 (여러 전이 가능) | 여러 선택지 존재 |
| Transition | 입력에 따른 상태 간의 이동 규칙 | 갈림길 이동 |

> 요약: 유한한 상태와 전이 규칙으로 계산 모델을 정의함.

## Ⅲ. 절차
- ASCII 흐름도
  Define States -> Set Alphabet -> Create Transitions -> Start/End

1. 기계가 가질 수 있는 모든 유한 상태(States)를 정의함.
2. 입력으로 사용될 문자열 집합(Alphabet)을 설정함.
3. 현재 상태와 입력에 따른 다음 상태 전이 함수를 작성함.
4. 시작 상태에서 출발하여 입력 종료 후 도달 상태의 수용 여부 확인함.

> 요약: 입력을 처리하며 상태를 변경하고 최종 결과를 도출함.

## Ⅳ. 문제점
- NFA는 구현 시 모든 경로 탐색으로 인해 백트래킹 오버헤드 발생함.
- 복잡한 정규 표현식의 경우 상태 수가 폭발적으로 증가할 수 있음.

## Ⅴ. 개선방안
- 단기: NFA를 등가의 DFA로 변환(Subset Construction)하여 구현 최적화함.
- 중기: 상태 최소화 알고리즘을 적용하여 오토마타 크기 감축함.
- 장기: 푸시다운 오토마타(PDA), 튜링 기계 등으로 모델링 범위 확장함.

## Ⅵ. 전망
- 컴파일러의 어휘 분석기(Lexer), 정규 표현식 엔진 개발에 필수임.
- 하드웨어 제어 로직 설계 및 네트워크 프로토콜 검증에 활용됨.
