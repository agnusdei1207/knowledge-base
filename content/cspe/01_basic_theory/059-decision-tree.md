## Ⅰ. 개요
- **정의**: 데이터 특징에 대한 질문을 트리 구조로 구성하여 데이터를 분류하거나 회귀하는 알고리즘임.
- **배경/필요성**: 모델의 의사결정 과정을 직관적으로 이해하고 설명(Interpretability)해야 하는 환경에서 쓰임.
- **출제 의도**: 정보 이득과 지니 불순도 개념, 그리고 가지치기의 중요성을 평가함.

## Ⅱ. 구성요소
```text
+------------------+       +------------------+       +------------------+
| Root Node        | ----> | Internal Nodes   | ----> | Leaf Nodes       |
| (Best Split)     |       | (Condition Test) |       | (Final Class)    |
+------------------+       +------------------+       +------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 루트/내부 노드 | 데이터를 나누는 분기점(조건식) | 스무고개 질문 |
| 리프 노드 | 분기가 완료된 최종 결과(클래스 또는 값) | 스무고개 정답 |
| 불순도 (Impurity)| 노드 내에 서로 다른 클래스가 섞여 있는 정도 | 오답이 섞인 비율 |

> 요약: 불순도가 낮아지는 최적의 기준을 찾아 재귀적으로 데이터를 분할하는 트리 구조임.

## Ⅲ. 절차
```text
+-------------+   +-------------+   +-------------+   +-------------+
| 1. 불순도   |-->| 2. 최적분할 |-->| 3. 트리     |-->| 4. 가지치기 |
|    계산     |   |    기준선택 |   |    성장     |   |    (Pruning)|
+-------------+   +-------------+   +-------------+   +-------------+
```
1. **불순도 계산**: 전체 데이터의 엔트로피나 지니 계수를 측정함.
2. **최적분할 기준선택**: 분할 시 정보 이득(불순도 감소량)이 최대인 속성을 선택함.
3. **트리 성장**: 선택된 조건으로 데이터를 나누고, 자식 노드에서 1~2번을 재귀 반복함.
4. **가지치기**: 트리가 과적합되지 않도록 정보 이득이 적은 말단 가지를 제한함.

> 요약: 정보 이득이 최대가 되는 질문으로 트리를 확장하고 가지치기로 과적합을 방지함.

## Ⅳ. 문제점
- **과적합 위험**: 깊이 제한이 없으면 훈련 데이터의 아주 미세한 노이즈까지 규칙화됨.
- **데이터 변화 취약**: 입력 데이터가 조금만 달라져도 최상단 분기 조건이 바뀌어 변동이 큼.

## Ⅴ. 개선방안
- **과적합 위험**: (단기) 트리 깊이 하이퍼파라미터 제한 / (장기) 사후 가지치기 적용 필요.
- **데이터 변화 취약**: (단기) 교차 검증을 통한 파라미터 탐색 / (장기) 앙상블 기법으로 전환 필요.

## Ⅵ. 전망
- 단일 트리 자체는 앙상블 모델(XGBoost, LightGBM)의 기본 약학습기 구성 요소로 핵심 역할을 수행함.
