## 미리 알고가기

- 노드: 데이터를 조건에 따라 나누는 트리의 지점임
- 루트 노드: 분할이 시작되는 최상위 노드임
- 리프 노드: 더 이상 분할하지 않고 예측 결과를 내는 끝 노드임
- 불순도: 한 노드 안에 서로 다른 클래스나 값이 얼마나 섞였는지 나타내는 기준임
- 가지치기: 과도하게 깊어진 트리를 줄여 일반화 성능을 높이는 방법임

## Ⅰ. 개요

- **정의**: 결정 트리는 입력 특징을 불순도 또는 예측 오차 감소 기준으로 반복 분할해 조건 경로를 예측 규칙으로 사용하는 지도학습 모델임
- **배경/필요성**: 분류·회귀 결과를 사람이 이해할 수 있는 조건 규칙으로 설명해야 하는 업무에서는 블랙박스 모델보다 의사결정 경로가 드러나는 모델이 필요함
- **비유**: 스무고개처럼 질문을 하나씩 던져 가능성을 좁혀 가며 마지막에 답을 정하는 과정과 같음

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 분할 기준 이해 | 엔트로피, 지니계수, 정보 이득 | 정보 이득과 불순도 혼동 |
| 해석 가능 모델 판단 | 규칙 경로, 가지치기, 과적합 | 랜덤 포레스트와 동일시 |

> 요약: 결정 트리는 특징 조건을 순차적으로 선택해 데이터를 나누고 각 경로를 해석 가능한 예측 규칙으로 만드는 모델임.

## Ⅱ. 특징/비교

| 판단 기준 | 선형 모델·앙상블 | 결정 트리 |
|:---|:---|:---|
| 의사결정 형태 | 선형 모델은 가중합, 앙상블은 다수 모델 집계로 판단함 | 조건 분기 경로가 그대로 규칙이 됨 |
| 전처리 요구 | 선형 모델은 스케일과 선형 관계에 민감할 수 있음 | 수치·범주 특징을 비교적 직관적으로 처리함 |
| 일반화 성능 | 단순 모델은 표현력이 낮고 앙상블은 성능은 좋으나 해석이 약함 | 단일 트리는 해석이 좋지만 과적합에 취약함 |
| 선택 조건 | 성능 극대화나 선형 해석이 목적일 때 대안이 적합함 | 규칙 설명과 빠른 기준선 모델이 필요할 때 적합함 |

> 요약: 결정 트리는 예측 성능보다 조건 기반 설명과 빠른 구조 파악이 중요한 상황에서 유용함.

- **입력 조건**: 특징 조건으로 데이터를 분할할 수 있고 결과 설명이 업무적으로 필요해야 함
- **평가 기준**: 검증 성능과 규칙 해석 가능성을 함께 확인함
- **선택 판단**: 설명 가능한 기준선 또는 규칙 추출이 필요할 때 우선 적용함

## Ⅲ. 구성요소

```text
+------------+      +------------+      +------------+
| 루트 노드   | ---> | 내부 노드   | ---> | 리프 노드   |
+------------+      +------------+      +------------+
       |                  |                  |
       v                  v                  v
+------------+      +------------+      +------------+
| 분할 기준   |      | 가지 경로   |      | 예측 결과   |
+------------+      +------------+      +------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 루트 노드 | 전체 데이터를 처음 나누는 시작 조건임 | 첫 질문 |
| 분할 기준 | 지니계수, 엔트로피, MSE 등으로 불순도 감소가 가장 큰 분기 조건을 선택함 | 질문 선택 기준 |
| 내부 노드 | 이전 조건을 통과한 데이터를 다시 하위 조건으로 나눔 | 추가 질문 |
| 리프 노드 | 최종 클래스, 평균값, 확률 등을 예측 결과로 반환함 | 최종 답 |
| 가지치기 | 깊이, 최소 샘플 수, 비용 복잡도 기준으로 불필요한 분기를 줄임 | 질문 줄이기 |

> 요약: 결정 트리는 불순도 감소가 큰 질문을 반복 선택해 데이터를 점점 순수한 리프 노드로 보내는 구조임.

## Ⅳ. 절차

```text
+------------+      +------------+      +------------+      +------------+
| 분할 후보   | ---> | 기준 평가   | ---> | 노드 확장   | ---> | 가지치기   |
+------------+      +------------+      +------------+      +------------+
```

1. **분할 후보 생성**: 각 특징의 임계값 또는 범주 조건을 후보로 만들고 데이터를 나눌 수 있는지 확인함
2. **기준 평가**: 불순도 감소, 정보 이득, MSE 감소를 계산해 목적 함수 개선이 가장 큰 분할을 선택함
3. **노드 확장**: 선택 조건으로 하위 노드를 만들고 종료 조건까지 반복 분할함
4. **가지치기·검증**: 최대 깊이, 최소 샘플, 비용 복잡도 기준으로 과도한 분기를 줄이고 검증 성능을 확인함

> 요약: 결정 트리 절차는 후보 조건을 평가해 가장 정보가 큰 분할을 반복하고 검증 성능 기준으로 트리 깊이를 통제하는 흐름임.

- **산출물**: 분기 조건, 리프 예측값, 변수 중요도, 가지치기 결과임
- **검증 기준**: 규칙이 검증 데이터에서도 유지되고 과도하게 깊지 않아야 함
- **운영 기록**: 최대 깊이, 최소 샘플 수, 분할 기준을 모델 버전으로 남겨야 함

## Ⅴ. 문제점

- **P1 과적합**: 트리가 깊어질수록 학습 데이터의 세부 잡음까지 규칙으로 만들어 검증 성능이 낮아질 수 있음
- **P2 분할 편향**: 값 종류가 많은 변수나 우연히 정보 이득이 큰 변수에 분할이 치우칠 수 있음
- **P3 구조 불안정**: 데이터가 조금만 바뀌어도 상위 분할이 달라져 전체 트리 구조와 설명이 크게 바뀔 수 있음

> 요약: 결정 트리의 핵심 위험은 해석 가능한 규칙이 학습 데이터의 우연한 패턴에 민감하게 만들어질 수 있다는 점임.

## Ⅵ. 개선방안

- **P1 대응**: 최대 깊이, 최소 리프 샘플, 사전·사후 가지치기, 교차 검증을 적용함 (확인: 학습·검증 성능 차이)
- **P2 대응**: 변수 전처리, gain ratio, permutation importance, 도메인 검토로 분할 편향을 점검함 (확인: 변수 중요도 안정성)
- **P3 대응**: bagging, Random Forest, 안정성 분석, seed별 트리 비교를 수행함 (확인: 반복 학습 시 규칙 변화 폭)

> 요약: 결정 트리 개선은 깊이와 분할 기준을 통제하고 필요할 때 앙상블로 불안정성을 낮추는 것임.

- **우선순위**: 트리 깊이와 학습·검증 성능 차이를 먼저 확인함
- **확인 지표**: accuracy/F1/RMSE, 트리 깊이, 리프 샘플 수, 변수 중요도를 함께 사용함
- **재평가 조건**: 데이터 샘플이 추가되거나 중요한 변수가 바뀌면 규칙 안정성을 다시 확인함

## Ⅶ. 전망

- **발전 방향**: 결정 트리는 설명 가능성이 높은 기준선 모델로 유지되며, 랜덤 포레스트와 그래디언트 부스팅 같은 강력한 앙상블의 기반 구조가 됨
- **기술사적 판단**: 기술사는 단일 트리의 규칙이 업무적으로 납득 가능한지와 검증 데이터에서도 유지되는지를 함께 확인해야 함
- **기술사 제언**: 향후 결정 트리는 설명 가능한 AI, 규칙 추출, 모델 감사, AutoML 후보 모델로 활용되며 성능 모델과 해석 모델을 연결하는 역할을 계속할 것임
