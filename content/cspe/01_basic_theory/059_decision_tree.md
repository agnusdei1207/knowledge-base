# 059. 결정 트리 (Decision Tree)

## Ⅰ. 개요

- **정의/개념**: 데이터에 내재되어 있는 패턴을 나무(Tree) 구조의 의사결정 규칙으로 나타내어 분류(Classification)와 회귀(Regression)를 수행하는 지도 학습 알고리즘임
- **배경/필요성**: 블랙박스 모델과 달리 결과 도출 과정을 사람이 직접 이해하고 설명할 수 있는 해석 가능성(Explainability)이 중요하며, 비선형 데이터와 수치형/범주형 변수를 동시에 처리하기 위해 필요함

## Ⅱ. 특징 및 비교

| 판단 기준 | 결정 트리 (Decision Tree) | 선형 회귀 (Linear Regression) | 랜덤 포레스트 (Random Forest) |
|:---|:---|:---|:---|
| **모델 구조** | 비선형 조건 분기 (If-Then) | 선형 결합 (Weighted Sum) | 여러 트리의 앙상블 (Voting) |
| **해석 가능성** | 매우 높음 | 높음 (계수 확인) | 낮음 |
| **데이터 전처리** | 스케일링 불필요 | 스케일링/정규화 필수 | 스케일링 불필요 |
| **과적합 위험** | 매우 높음 (깊은 트리) | 낮음 | 낮음 (배깅 효과) |

> 요약: 결정 트리는 직관적이지만 과적합에 취약하므로 가지치기나 앙상블 기법과의 병행이 필수적임

## Ⅲ. 구성요소/구조

- **구성요소**:
  - **Root Node**: 전체 데이터에서 시작되는 최상위 노드로, 변별력이 가장 큰 변수를 선택함
  - **Internal Node**: 데이터 분할 조건이 명시되는 중간 노드임
  - **Leaf (Terminal) Node**: 더 이상 분할되지 않는 최종 노드로, 예측 결과(클래스/값)를 담고 있음
  - **Split Criterion**: 노드를 나누는 기준으로 지니 지수(Gini), 엔트로피(Entropy), 정보 이득(Information Gain) 등을 사용함

- **구조도**:
```text
      [Root Node] -------- (Feature A <= 5?)
         |                     |
      (True)                (False)
         |                     |
  [Internal Node]       [Leaf Node: Class B]
  (Feature B == 'Red'?)
     |           |
  (True)      (False)
     |           |
[Leaf Node]  [Leaf Node]
(Class A)    (Class C)
```

## Ⅳ. 문제점 및 개선방안

1. **[과적합 (Overfitting)]**: 학습 데이터의 노이즈까지 학습하여 트리가 과하게 깊어지고 일반화 성능이 저하됨
   - **개선방안**: 가지치기(Pruning), 최대 깊이(Max Depth) 제한, 노드 분할을 위한 최소 샘플 수 설정을 수행함 (확인: Validation Accuracy)
2. **[높은 분산 (High Variance)]**: 데이터가 조금만 바뀌어도 트리 구조가 완전히 달라지는 불안정성 문제가 있음
   - **개선방안**: 여러 트리를 합치는 Bagging(Random Forest)이나 Boosting(XGBoost) 등 앙상블 기법을 적용함 (확인: 모델 안정성)
3. **[축 정렬 분할 (Axis-parallel)]**: 한 번에 하나의 변수만 고려하여 수직/수평으로만 나누므로 대각선 형태의 관계 표현에 한계가 있음
   - **개선방안**: 주성분 분석(PCA) 등으로 데이터 축을 회전시키거나 딥러닝 등 다른 모델을 검토함 (확인: 결정 경계 시각화)

## Ⅴ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| **대출 신용 승인** | 소득, 직업, 연체 이력을 기준으로 대출 가부 결정 및 사유 설명 | 정탐률, 규제 준수 여부 |
| **마케팅 타겟 선정** | 연령, 구매 성향 조건을 분기하여 이탈 가능성이 높은 고객군 식별 | Lift (향상도), 이탈률 감소 |
| **의료 진단 보조** | 증상 및 검사 수치 조건에 따른 질병 유무 1차 스크리닝 | 민감도(Sensitivity), 특이도 |

> 요약: 실무에서는 성능보다 '왜 그런 결과가 나왔는가'에 대한 설명이 중요한 규제 산업이나 초기 탐색적 분석에 주로 활용함

## Ⅵ. 결론

결정 트리는 화이트박스(White-box) 모델로서 데이터의 의사결정 과정을 시각화하고 직관적으로 이해할 수 있게 해주는 강력한 도구임. 비록 단일 모델로는 성능의 한계와 과적합 위험이 존재하지만, 가지치기 전략과 결합하거나 현대 머신러닝의 주류인 앙상블 기법의 기본 단위(Base Learner)로 활용됨으로써 데이터 사이언스 분야의 근간이 되는 알고리즘으로 평가받고 있음.
