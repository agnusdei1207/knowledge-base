## 미리 알고가기

- 분할 기준: 노드를 둘로 나누는 조건임
- 불순도: 클래스 혼합 정도를 나타내는 지표임
- 리프 노드: 최종 예측을 반환하는 말단 노드임

## Ⅰ. 개요

- **정의/개념**: 결정 트리는 입력 특징을 조건문 형태로 반복 분할해 예측 결과에 도달하는 계층적 모델로, 분류와 회귀에 모두 사용되는 해석 가능한 학습기임
- **배경/필요성**: 복잡한 수식보다 사람이 읽을 수 있는 규칙 기반 예측 모델이 필요할 때 결정 트리가 유용함

## Ⅱ. 특징

- 조건 분기 구조라 해석성과 설명력이 높음
- 수치형과 범주형 특징을 모두 다룰 수 있음
- 전처리가 비교적 적고 비선형 경계를 표현할 수 있음
- 깊이가 깊어지면 과적합과 분산이 커지기 쉽다

## Ⅲ. 종류 및 비교

| 판단 기준 | 결정 트리 | 선형 모델 | 랜덤 포레스트 |
|:---|:---|:---|:---|
| 해석성 | 높음 | 중간 | 낮음 |
| 비선형 표현 | 강함 | 약함 | 강함 |
| 과적합 위험 | 큼 | 중간 | 낮음 |
| 대표 용도 | 규칙 기반 예측 | 기준선 모델 | 안정적 고성능 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 루트 노드 | 첫 분할이 시작되는 지점이며 가장 큰 정보 이득을 가진다 |
| 내부 노드 | 특징 조건으로 데이터를 나눔 분기 규칙의 핵심임 |
| 리프 노드 | 최종 클래스나 값을 출력하고 예측 결과임 |
| 분할 지표 | Gini, entropy, MSE 등이며 트리 품질을 좌우함 |

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 루트 노드    | --> | 분할 지표    | --> | 내부 노드    | --> | 리프 노드    |
+-----------+     +-----------+     +-----------+     +-----------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 특징선택 | --> | 노드분할 | --> | 재귀확장 | --> | 리프결정 |
+----------+     +----------+     +----------+     +----------+
```

1. **특징선택**: 불순도 감소가 큰 특징을 고름
2. **노드분할**: 임계값 또는 범주 기준으로 데이터를 나눔
3. **재귀확장**: 각 하위 노드에서 같은 절차를 반복함
4. **리프결정**: 종료 조건을 만족하면 예측값을 저장함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 과적합이 쉽게 발생해 깊은 트리는 훈련 데이터를 외우기 쉬움
   - 해결방안: max_depth, min_samples_leaf, pruning을 적용하고 validation score로 검증함
2. 문제: 작은 데이터 변화에 구조가 크게 바뀜 분산이 높음
   - 해결방안: 앙상블 방법으로 안정화하고 fold 간 성능 분산로 검증함
3. 문제: 축 정렬 분할 한계가 있어 대각선 경계를 표현하려면 많은 분기가 필요함
   - 해결방안: feature engineering 또는 boosting을 병행하고 decision boundary quality로 검증함

## Ⅶ. 적용 사례

- 대출 심사에서는 승인 규칙을 트리 형태로 설명함, 확인 지표는 AUC와 설명 가능성임
- 장애 원인 분석에서는 로그 조건 분기로 원인 경로를 파악함, 확인 지표는 규칙 해석 시간임
- 제조 품질 예측에서는 공정 조건별 불량 분기를 탐색함, 확인 지표는 recall임

## Ⅷ. 결론

결정 트리의 핵심은 예측력보다 조건 규칙의 가독성에 있으므로, 성능과 함께 깊이와 규칙 복잡도를 통제해야 함.
