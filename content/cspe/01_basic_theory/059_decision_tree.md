# 📖 【암기용】 개념 완전 이해

> 목적: 결정 트리를 처음 보는 사람도 분기 규칙과 불순도 감소 원리를 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 데이터를 조건문으로 반복 분할해 예측하는 트리 기반 모델
- **왜 필요한가**:
  - 회귀·분류 문제에서 사람이 읽을 수 있는 규칙, 변수 중요도, 의사결정 경로가 필요함.
  - 결정 트리는 모델 설명 가능성을 제공함.
- **핵심 직관**: 질문을 하나씩 던져 데이터를 순수한 그룹으로 나누는 알고리즘임.

## 깊이 이해
- **배경·문제의식**:
  - 선형 모델은 변수와 목표의 직선 관계를 가정하지만, 실제 업무 데이터는 임계값·범주 조합에 따라 결과가 달라짐.
  - 결정 트리는 비선형 분기를 조건문으로 표현함.
- **작동 원리**:
  - 각 노드에서 정보이득, 지니 불순도, 분산 감소가 가장 큰 특성을 선택해 분기함.
  - 잎 노드는 다수 클래스 또는 평균값을 예측함.
- **비유**: 병원 문진표처럼 "발열 38도 이상인가", "기침이 있는가"를 순서대로 묻고 마지막에 진단 후보를 정하는 구조임.
- **구체 예시**: 고객 이탈 예측에서 `계약기간 < 6개월`, `월요금 > 8만원`, `불만접수 >= 2회` 같은 분기 규칙으로 이탈 확률을 산출함.
- **흔한 오해·주의점**:
  - 트리를 깊게 만들수록 훈련 데이터는 잘 맞지만 과적합이 증가함.
  - max_depth, min_samples_leaf, 가지치기 비용복잡도 매개변수가 필요함.

## 연결 개념
- 정보이득(Information Gain) — 분기 전후 엔트로피 감소량
- 지니 불순도(Gini Impurity) — CART 분류 트리의 분기 기준
- 랜덤 포레스트(Random Forest) — 여러 결정 트리를 앙상블한 모델

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 결정 트리는 특성 조건을 기준으로 데이터를 재귀 분할해 잎 노드에서 분류·회귀 값을 출력하는 모델임.
> 2. **가치**: 분기 규칙과 변수 중요도를 사람이 해석할 수 있어 신용평가·품질검사·이탈예측에 적용됨.
> 3. **판단 포인트**: 정보이득·지니 불순도, 과적합, 가지치기 조건을 함께 제시해야 함.

---

## Ⅰ. 개요 및 필요성

- 정의: 결정 트리는 조건 분기로 예측한다.
- 배경: 업무 의사결정은 임계값과 규칙 설명이 필요한 경우가 많아 해석 가능한 모델이 요구됨.
- 필요성: 트리 깊이와 잎 노드 조건을 통제하지 않으면 훈련셋 규칙 암기로 이어짐.

---

## Ⅱ. 구조 및 구성요소

```text
Dataset -> Root Node -> Internal Split -> Leaf Node -> Prediction
            +-> Impurity Measure -> Split Rule -> Pruning
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Root Node | 전체 데이터를 첫 분기 기준으로 나눔 | 정보이득 최대 특성 선택 |
| Internal Node | 조건문으로 하위 집합 생성 | 수치형 임계값, 범주형 분기 |
| Leaf Node | 최종 클래스·회귀값 출력 | 다수결, 평균값 |
| Pruning | 깊이·복잡도 제한 | max_depth, ccp_alpha |

> 요약: 결정 트리는 루트에서 잎까지 불순도 감소 기준으로 분기하고 가지치기로 복잡도를 제한함.

---

## Ⅲ. 동작원리 및 흐름도

```text
데이터 입력 -> 불순도 계산 -> 최적 분기 선택
-> 하위 노드 생성 -> 종료 조건 확인 -> 잎 예측
-> 가지치기 -> 검증 지표 확인
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 후보 특성별 엔트로피·지니 계산 | 정보이득, Gini 감소 |
| 2 | 불순도 감소 최대 분기 선택 | 분기 후 샘플 수 |
| 3 | 재귀 분할과 종료 조건 적용 | max_depth, min_samples_leaf |
| 4 | 검증셋 평가와 가지치기 | F1, RMSE, Train/Val Gap |

> 요약: 결정 트리는 불순도 감소가 큰 조건을 반복 선택하고 검증셋 기준으로 가지치기함.

---

## Ⅳ. 특징

| 구분 | 내용 | 판단 포인트 |
|:---|:---|:---|
| 장점 | 규칙 경로와 변수 중요도 해석 가능 | 규제·심사 업무 설명 요구 |
| 한계 | 깊은 트리는 과적합 발생 | max_depth 3~10, Gap 5%p 이하 |
| 비교 대상 | 로지스틱 회귀는 선형 경계, 트리는 비선형 분기 | 해석성·비선형성 기준 선택 |

> 요약: 결정 트리는 설명 가능한 비선형 규칙 모델이나 깊이 제한 없이는 과적합 위험이 큼.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존/대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | 선형 모델은 가중치 기반 | 트리는 조건문 기반 | 임계값 규칙 설명 필요 시 |
| 비용/성능 | 단일 트리는 학습·추론 비용 낮음 | O(n log n) 분할 탐색 | 실시간 규칙 엔진 적용 |
| 운영/위험 | 깊은 트리 관리 어려움 | 가지치기·깊이 제한 필요 | 과적합 지표 확인 |

> 요약: 규칙 설명과 낮은 추론 비용이 필요하면 단일 결정 트리, 예측 지표 우선이면 앙상블을 검토함.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 과적합 | 노드 수 과다, 잡음 분기 | max_depth, min_samples_leaf, pruning | Train/Val Gap |
| 데이터 편향 | 불균형 클래스 분기 | class_weight, 샘플링 | Recall, PR-AUC |
| 규칙 불안정 | 소량 데이터 변화에 분기 변경 | K-Fold, 앙상블 비교 | 분기 일치율 |

> 요약: 결정 트리 리스크는 깊이 제한, 불균형 보정, 교차검증으로 통제함.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 예측 품질 | F1 0.8 이상 또는 RMSE 기준선 대비 10% 감소 | Hold-out, K-Fold |
| 설명 가능성 | 주요 분기 5개 이내 업무 검토 완료 | Rule Export, SHAP |
| 운영/보안 | 모델 버전·분기 규칙 변경 이력 100% 기록 | 모델 레지스트리, 감사 로그 |

> 요약: 결정 트리 도입은 예측 지표와 규칙 검토 이력을 함께 확인해야 함.

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 — 단계별 또는 항목별):**
1. 분기 기준 설정: Gini 또는 Entropy를 선택하고 max_depth 3~10, min_samples_leaf 1~5%로 기준선을 학습.
2. 과적합 통제: 5-Fold 교차검증, ccp_alpha 가지치기, Train/Val Gap 5%p 초과 시 깊이 축소.
3. 설명 산출: Graphviz/Rule Export로 상위 5개 분기와 변수 중요도를 업무 담당자 검토표에 기록.

**결론 (2줄):**
- 기술사 판단: 설명 가능한 규칙이 요구되면 결정 트리, 예측 지표와 분산 감소가 우선이면 랜덤 포레스트를 선택함.
- 향후 방향: 단일 트리는 XAI 기준선으로 활용되고 운영 모델은 앙상블·GBDT와 함께 비교 검증됨.
