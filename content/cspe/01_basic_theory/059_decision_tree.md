## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 데이터의 특징을 특정 기준(불순도)에 따라 반복 분할하여 스무고개 하듯 의사결정 규칙을 생성하는 모델임 |
| 배경/필요성 | 블랙박스 모델(딥러닝)과 달리 결과 도출 과정의 높은 해석 가능성(Explainability) 요구 |
| 출제 의도 | 엔트로피 및 지니계수 등 불순도 지표의 원리, 트리 분할 과정, 가지치기(Pruning) 이해 평가 |

## Ⅱ. 구성요소
```text
+----------------+       +----------------+       +----------------+
| Root Node      |       | Internal Node  |       | Leaf Node      |
| (Full Data)    | ----> | (Split Rule)   | ----> | (Final Class)  |
+----------------+       +----------------+       +----------------+
```
| 루트/내부 노드 | 데이터를 분할하기 위한 특정 변수와 임계값의 조건 | 스무고개 질문 |
| 리프 노드 | 더 이상 분할되지 않는 종착점으로 최종 분류된 클래스 | 최종 정답 |
| 불순도 지표 | 데이터가 얼마나 섞여 있는지 측정(엔트로피, 지니) | 혼탁도 측정기 |
> 요약: 결정 트리는 분할 조건을 담은 내부 노드와 최종 결과를 담은 리프 노드로 구성됨

## Ⅲ. 절차
```text
+----------------+       +----------------+       +----------------+       +----------------+
| Impurity Calc  |       | Best Split     |       | Tree Grow      |       | Pruning        |
| (Gini/Entropy) | ----> | (Max Info Gain)| ----> | (Recursive)    | ----> | (Cut branches) |
+----------------+       +----------------+       +----------------+       +----------------+
```
1. 불순도 계산: 각 노드에서 데이터가 속한 클래스의 혼잡도(Gini, Entropy) 계산
2. 최적 분할: 정보 획득량(불순도 감소폭)이 가장 커지는 변수와 기준값을 찾아 데이터 분할
3. 반복 성장: 분할된 자식 노드에서도 동일한 분할 과정을 재귀적으로 반복 수행
4. 가지치기: 트리가 지나치게 복잡해지는 것을 막기 위해 하위 브랜치를 병합(Pruning)
> 요약: 불순도 감소가 최대가 되는 조건으로 데이터를 분할하며, 과적합 방지를 위해 가지치기함

## Ⅳ. 문제점
- 과적합 취약성: 트리가 깊어질수록 훈련 데이터 노이즈까지 학습하여 일반화 성능 급락
- 분산의 불안정성: 학습 데이터가 조금만 변경되어도 트리의 구조가 완전히 뒤바뀜
- 비선형 데이터 한계: 축에 수직(계단식)으로만 분할 공간을 만들어 대각선 패턴 파악에 취약

## Ⅴ. 개선방안
- 단기 방안: 트리의 최대 깊이(Max Depth) 제한 등 사전 가지치기를 통해 과적합 억제
- 중기 방안: 사후 가지치기(Post-pruning)로 데이터 분산에 강건한 최소 노드 유지
- 장기 방안: 단일 트리의 한계를 극복하기 위해 다수 트리를 결합하는 랜덤 포레스트 도입

## Ⅵ. 전망
- 단독 사용보다는 앙상블(XGBoost, LightGBM 등) 모델의 기본 분류기(Weak Learner)로 핵심 역할 수행
