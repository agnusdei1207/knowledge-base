## 미리 알고가기

- 불순도($Impurity$): 특정 집합 안에 서로 다른 클래스가 얼마나 섞여 있는지를 나타내는 척도임
- 지니 계수($Gini$ $Index$): 집합의 불순도를 측정하는 지표로, 0일 때 가장 순수(한 클래스만 존재)한 상태임
- 정보 이득($Information$ $Gain$): 데이터를 분할했을 때 엔트로피가 얼마나 감소했는지를 나타내는 값임
- 가지치기($Pruning$): 과적합을 방지하기 위해 트리의 일부 가지를 제거하여 모델을 단순화하는 기법임

## Ⅰ. 개요

- **정의/개념**: 결정 트리는 데이터를 가장 잘 구분할 수 있는 질문(조건)들을 계층적인 나무 구조로 배치하여 최종적인 분류나 회귀 값을 도출하는, '설명 가능한' 지도 학습 모델임
- **배경/필요성**: 블랙박스 형태의 딥러닝과 달리 의사결정의 근거를 사람이 직접 확인하고 검증해야 하는 금융 심사, 의료 진단 등에서 투명한 예측 규칙을 생성하기 위해 사용됨

## Ⅱ. 특징

- '만약 ~라면(If-Then)' 식의 조건 분기 구조를 가지므로 비전문가도 모델의 판단 과정을 쉽게 이해할 수 있으며, 데이터의 스케일링이나 정규화 같은 전처리의 영향이 거의 없음
- 수치형 데이터뿐만 아니라 범주형(문자열 등) 데이터도 별도의 복잡한 변환 없이 동시에 처리할 수 있어 활용 범위가 매우 넓음
- 학습 데이터의 미세한 변화에도 전체 트리 구조가 크게 바뀔 수 있는 '높은 분산($High$ $Variance$)' 특성을 가지며, 이는 단일 트리의 한계점으로 지적됨

## Ⅲ. 종류 및 비교

| 판단 기준 | 분류 트리 ($Classification$) | 회귀 트리 ($Regression$) |
|:---|:---|:---|
| **종속 변수** | 범주형 (A/B, 성공/실패) | 연속형 (가격, 온도, 수요량) |
| **분할 기준** | 지니 계수, 엔트로피 감소 최대화 | 잔차 제곱합($RSS$) 감소 최대화 |
| **리프 노드 값** | 해당 영역의 최빈값 (다수결) | 해당 영역의 평균값 |
| **주요 알고리즘** | $C4.5, CART$ | $CART$ |

> 요약: 분류는 '가장 많은 쪽'을 선택하고, 회귀는 '평균값'을 선택함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 루트 노드 | 최상단 노드로, 전체 데이터를 처음으로 나누는 가장 중요한 변수가 위치함 |
| 내부 노드 | 중간 단계의 질문 노드로, 특정 변수의 임계값을 기준으로 데이터를 분기함 |
| 리프 노드 | 더 이상 분할되지 않는 끝단 노드로, 최종 예측 클래스나 수치값이 담김 |
| 가지 ($Branch$) | 노드와 노드를 잇는 연결선으로, 조건의 '참/거짓' 여부를 나타냄 |

```text
[ 결정 트리 시각화 예시 ]
나이가 30세 초과인가?
  /       \
[예]      [아니오]
  |         |
연봉이...  승인(Leaf)
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 최적 특징 선정| --> | 데이터 분할  | --> | 재귀적 트리생성| --> | 가지치기(정돈)|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **최적 분기 탐색** — 현재 데이터셋에서 불순도를 가장 많이 낮출 수 있는(정보 이득이 가장 큰) 변수와 그 임계값을 모든 변수에 대해 전수 조사하여 선택함
2. **영역 분리** — 선택된 기준에 따라 데이터를 두 개 이상의 하위 집단으로 나누고, 나뉜 데이터가 충분히 순수해질 때까지 동일한 과정을 반복함
3. **종료 조건 확인** — 트리의 깊이가 최대치에 도달하거나, 노드 내 데이터 수가 너무 적어지면 분할을 멈추고 리프 노드에 예측 결과를 할당함
4. **모델 일반화** — 훈련 데이터에 너무 깊게 파고든 가지들을 잘라내는 가지치기를 수행하여, 새로운 데이터에 대해서도 잘 동작하는 범용적인 모델을 완성함

## Ⅵ. 실무 적용 및 유의점

1. 결정 트리는 조금만 깊게 학습해도 훈련 데이터를 통째로 외워버리는 과적합($Overfitting$)에 매우 취약하므로, 반드시 '최대 깊이($Max$ $Depth$)'를 제한하거나 하이퍼파라미터 튜닝을 통해 복잡도를 통제해야 함
2. 단일 트리의 불안정성과 성능 한계를 극복하기 위해 실무에서는 여러 개의 트리를 묶어서 사용하는 '랜덤 포레스트($Random$ $Forest$)'나 '그래디언트 부스팅($GBM$)'과 같은 앙상블 기법으로 확장하여 사용하는 것이 일반적임

## Ⅶ. 결론

- 결정 트리는 데이터 이면에 숨겨진 논리 체계를 시각화하는 지식 추출의 도구이며, 설계자는 모델의 해석 가능성과 예측 성능 사이의 균형을 유지하기 위해 엄격한 복잡도 제어와 앙상블 전략을 병행해야 함
