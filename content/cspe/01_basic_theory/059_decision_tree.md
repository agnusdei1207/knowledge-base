# 📖 【암기용】 개념 완전 이해

> 목적: 이 개념을 처음 보는 사람도 완벽히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 결정 트리는 **지도 학습(Supervised Learning)**에 속하는 분류·회귀 알고리즘으로, 데이터의 **불순도(Impurity)**를 가장 크게 낮추는 질문(분할 기준)을 반복 적용해 스무고개처럼 가지를 치며 정답을 찾아간다.
- **왜 필요한가**: 딥러닝·SVM과 달리 모델이 "왜 그런 결정을 내렸는지"를 사람이 눈으로 추적할 수 있는 화이트박스 구조라서, 설명 가능한 AI(XAI)의 가장 기본적인 형태이기 때문이다.
- **핵심 직관**: "날개가 있나? (예) → 깃털이 있나? (예) → 새"처럼, 불확실성(불순도)이 가장 크게 줄어드는 가장 좋은 질문을 먼저 던져 데이터를 쪼개 나간다.

## 핵심 용어 정리 (내부에 등장하는 것들)

| 용어 | 의미 | 비유 |
|:---|:---|:---|
| 지도 학습 (Supervised Learning) | 정답 라벨이 있는 데이터로 학습하는 상위 패러다임 — 결정 트리가 속한 분류 | 정답지를 보며 배우는 학습 방식 |
| 불순도 (Impurity) | 한 노드 안에 서로 다른 클래스가 얼마나 섞여 있는지의 정도 — 낮을수록 순수 | 바둑알 통 속 검은 알·흰 알의 뒤섞인 정도 |
| 지니 계수 (Gini Index) | 불순도를 수치화하는 대표 지표. $1-\sum p_i^2$로 계산 (CART가 사용) | "무작위로 두 개 뽑았을 때 다른 클래스일 확률" |
| 엔트로피 (Entropy) | 정보이론에서 온 불순도 지표. $-\sum p_i \log_2 p_i$로 계산 (C4.5가 사용) | "이 노드를 설명하는 데 필요한 질문(비트) 수" |
| 정보 획득량 (Information Gain) | 분할 전 불순도 − 분할 후 자식 노드 불순도의 가중 평균 | 질문 하나로 확실해진 정도 |
| 루트 노드 (Root Node) | 전체 데이터에서 시작하는 트리의 맨 위, 첫 번째 질문 | 첫 번째로 던지는 스무고개 질문 |
| 내부 노드 (Internal Node) | 데이터를 또 한 번 나누는 중간 질문 지점 | 스무고개의 두 번째, 세 번째 질문 |
| 리프 노드 (Leaf Node) | 더는 분할되지 않는 최종 결론 지점 | "정답: 새!"라는 최종 확정 |
| 가지치기 (Pruning) | 트리가 너무 깊어지지 않도록 분할을 중간에 멈추거나 자르는 규제 | 스무고개를 너무 세세하게 묻지 않도록 질문 수 제한 |
| 과적합 (Overfitting) | 훈련 데이터 하나하나까지 억지로 다 맞추도록 트리를 키워 새 데이터에는 못 맞는 상태 | 기출문제만 통째로 외워 새 문제엔 손도 못 대는 상태 |

## 깊이 이해

### 분할 기준을 숫자로 직접 계산해보기 — 지니 계수
- 10개 데이터가 있고 클래스 A가 6개, B가 4개인 노드가 있다고 하자. 지니 계수는 $1-(p_A^2+p_B^2) = 1-(0.6^2+0.4^2) = 1-(0.36+0.16) = 0.48$이다.
- 이 노드를 어떤 질문으로 분할해 왼쪽 자식(5개: A 5, B 0)과 오른쪽 자식(5개: A 1, B 4)으로 나눴다고 하자.
  - 왼쪽 지니: $1-(1.0^2+0^2)=0$ (완전히 순수 — A만 있으므로 불순도 0)
  - 오른쪽 지니: $1-(0.2^2+0.8^2)=1-(0.04+0.64)=0.32$
  - 분할 후 가중 평균 지니: $(5/10)\times0 + (5/10)\times0.32 = 0.16$
  - 정보 획득량(Information Gain) = 분할 전(0.48) − 분할 후(0.16) = **0.32**
- 이 값이 클수록 "좋은 질문"이다. 트리는 가능한 모든 특징(Feature)과 임계값 조합을 시뮬레이션해서, 정보 획득량이 가장 큰 조합을 그 노드의 분할 기준으로 채택한다. 이 과정을 각 자식 노드에서 재귀적으로 반복한다.
- 참고로 엔트로피로 같은 루트 노드를 계산하면 $-(0.6\log_2 0.6 + 0.4\log_2 0.4) \approx 0.971$이며, 지니 계수보다 계산에 로그 연산이 들어가 더 무겁다 — 그래서 사이킷런 등 현대 라이브러리는 기본값으로 지니 계수(CART)를 쓴다.

### 왜 "끝까지 쪼개면" 안 되는가 — 과적합을 수치로 보기
- 분할을 멈추지 않으면 리프 노드마다 데이터가 1개만 남을 때까지 쪼갤 수 있다. 이러면 훈련 정확도는 100%가 되지만, 새로운 데이터에서는 훈련 때 본 적 없는 사소한 노이즈까지 규칙으로 암기해버려 성능이 급락한다(예: 훈련 정확도 100% vs 검증 정확도 62% — 38%p의 과적합 격차). `max_depth`(최대 깊이 제한)나 `min_samples_split`(분할에 필요한 최소 샘플 수)으로 미리 멈추는 것이 사전 가지치기(Pre-pruning)다.

### 비유로 다시 정리
- 섞여 있는 검은 바둑알 50개, 흰 바둑알 50개를 나눌 때, "크기가 큰가?"로 나누면 여전히 반반 섞여 지니 계수가 거의 그대로지만, "색이 검은가?"로 나누면 한쪽은 검은 알만, 다른 쪽은 흰 알만 남아 지니 계수가 0으로 뚝 떨어진다. 이처럼 불순도를 가장 크게 떨어뜨리는 질문이 좋은 분할 기준이다.

### 실전 규칙 트리 예시
- 은행 대출 승인 모델에서 루트 노드 질문이 "연봉 5천만 원 이상인가?"이고, 그 다음 내부 노드가 "연체 이력이 있는가?"로 이어지는 계층적 규칙 트리가 만들어진다. 심사관은 이 트리를 그대로 따라가며 왜 승인·거절됐는지 고객에게 근거를 설명할 수 있다 — 이것이 결정 트리가 화이트박스인 이유다.

## 연결 개념
- 불순도 (Impurity) — 지니 계수나 엔트로피로 측정하며, 낮을수록 좋다
- 앙상블 (Ensemble) — 단일 트리의 과적합·불안정성 약점을 보완하기 위해 여러 트리를 모으는 상위 기법
- 랜덤 포레스트 (Random Forest) — 여러 개의 결정 트리를 배깅으로 만들어 다수결로 결론을 내는 발전형 알고리즘 (060에서 상세)

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 결정 트리는 데이터의 특징(Feature)을 기반으로 정보 획득량(Information Gain)이 최대화(불순도 최소화)되는 분할 규칙을 반복 적용하여 계층적 If-Then 구조를 만드는 알고리즘이다.
> 2. **가치**: 모델의 판단 근거가 화이트박스 형태로 시각화되어 강력한 설명력(Interpretability)을 제공하며, 스케일링(Scaling) 전처리 없이도 비선형 데이터 분류가 가능하다.
> 3. **판단 포인트**: 단일 트리는 훈련 데이터의 노이즈까지 분할하는 과적합 성향이 매우 강하므로, 실무에서는 깊이 제한(Pruning)을 필수 적용하거나 앙상블(Random Forest)의 기본 분류기(Weak Learner)로 쓴다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 의사결정 분할 기준의 수학적 원리 파악 | 지니 계수(Gini) 및 엔트로피(Entropy) 기반 불순도 감소(Information Gain) | If-Then 규칙이라는 겉모습만 쓰고 불순도(Impurity) 지표 생략 |
| 결정 트리의 구조적 한계와 극복 방안 | 트리의 과적합(Overfitting) 발생 원인과 사전/사후 가지치기(Pruning) | 가지치기를 단순 "트리를 자른다"고 표현 (파라미터 max_depth 명시) |
| 트리 기반 알고리즘의 발전 계보 이해 | 단일 Decision Tree → Bagging(RF) / Boosting(XGBoost)으로의 연결 | 결정 트리 단독으로 최상의 성능을 낸다고 단정 |

> 요약: 스무고개라는 직관적 구조 이면에 있는 '엔트로피와 지니 계수를 이용한 불순도 최소화' 수학 원리와, 치명적 단점인 과적합 제어 기법을 묻는다.

## Ⅰ. 개요 및 필요성

- 정의: 특징 공간을 재귀적으로 분할하여 데이터 군집의 불순도(Impurity)를 낮추는 의사결정 규칙을 트리(Tree) 그래프 형태로 모델링하는 지도 학습 알고리즘
- 배경: 인공신경망, SVM 등의 블랙박스 모델은 금융 심사, 의료 진단 등에서 예측 결과의 근거를 설명(Accountability)하지 못하는 한계 노출
- 필요성: 비선형 구조의 다차원 데이터를 정규화(Standardization) 없이 고속으로 처리하면서도 인간이 해석 가능한 명시적(White-box) 규칙 도출

## Ⅱ. 구조 및 구성요소

```text
       [Root Node (초기 전체 데이터)]  -- (분할 기준: x1 < 임계치, Information Gain 최대)
          /                    \
  [내부 노드 A]             [내부 노드 B] -- (분할 기준: x2 < 임계치)
    /      \                 /         \
[Leaf]   [Leaf]           [Leaf]     [Leaf (순도 100% 클래스 확정)]
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 루트/내부 노드 (Node) | 특징 공간을 2개 이상으로 분할하는 검사 조건 (If) | 정보 획득량이 가장 높은 피처가 상위에 위치 |
| 분기 (Branch/Edge) | 상위 노드의 조건에 따른 검사 결과 (Yes / No) | 데이터 세트의 부분집합 분리 경로 |
| 단말 노드 (Leaf/Terminal) | 더 이상 분할되지 않는 최종 군집, 최종 정답 할당 (Then) | 분류(다수결 클래스), 회귀(평균값) 결정 |

> 요약: 전체 데이터(Root)에서 시작해 불순도를 가장 크게 낮추는 질문으로 가지(Branch)를 치며, 최종 잎사귀(Leaf)에서 결론을 내린다.

## Ⅲ. 동작원리 및 흐름도 (학습 과정)

```text
데이터 불순도 평가 -> 정보 획득량(IG) 최대화 노드 분할 -> 재귀적 반복 -> 정지 조건(가지치기) -> Leaf 도출
```

| 단계 | 처리 내용 | 검증 기준 / 수식 |
|:---:|:---|:---|
| 1 | 부모 노드 데이터의 현재 불순도(Impurity) 계산 | Gini = $1 - \sum (P_i)^2$ 또는 Entropy 연산 |
| 2 | 모든 피처와 임계값을 시뮬레이션하여 분할 후 자식 노드의 불순도 계산 | 불순도의 가중 평균 도출 |
| 3 | 부모와 자식 간의 불순도 차이(Information Gain) 도출 | $IG = Impurity(Parent) - Impurity(Children)$ |
| 4 | IG가 최대가 되는 피처로 분할하고 정지 조건까지 재귀 반복 | `max_depth` 도달 시 분할 정지 |

> 요약: 노드를 분할하기 전과 후의 "섞인 정도(불순도)" 차이를 계산하여, 가장 깔끔하게 그룹을 찢어내는 기준을 탐욕적(Greedy)으로 찾아 분할한다.

## Ⅳ. 분할(불순도) 지표 및 알고리즘 특징

| 구분 (알고리즘) | 불순도 평가 지표 | 분할 특성 (가지 개수) | 적용 판단 포인트 |
|:---|:---|:---|:---|
| CART (분류/회귀) | 지니 계수 (Gini Index) | 이진 분할 (항상 2갈래 분기) | 연산이 빠르고 연속형 수치 처리에 강점 (현대 표준) |
| C4.5 / C5.0 | 엔트로피 (Entropy) / 정보 획득비 | 다자 분할 (범주 수만큼 분기) | $\log$ 연산 포함으로 연산량 큼, 이산형 데이터 유리 |
| CHAID | 카이제곱 통계량 (P-value) | 다자 분할 (통계적 유의성 기반) | 통계 분석 및 세분화(Segmentation) 목적 |

> 요약: 현대 머신러닝 패키지(Scikit-Learn 등)는 $\log$ 연산이 없어 속도가 빠르고 효율적인 지니 계수 기반의 이진 분할(CART) 알고리즘을 기본으로 사용한다.

## Ⅴ. 심화 비교 및 트레이드오프 판단

| 비교 축 | 결정 트리 (Decision Tree) | 로지스틱 회귀 (Logistic Regression) | 선택 기준 |
|:---|:---|:---|:---|
| 결정 경계 | 축에 수직인 계단형 (직교 분할) | 매끄러운 선형 평면 | 데이터의 선형 분리 가능 여부 |
| 데이터 스케일링 | 거리 연산이 없어 스케일링(정규화) 불필요 | 스케일링 및 이상치(Outlier)에 민감 | 전처리 리소스 한계 |
| 결과 해석력 | 조건문의 중첩(If-Then)으로 직관적 시각화 | 가중치(회귀 계수)의 크기와 부호로 해석 | 현장 실무자의 이해도 요구 수준 |

> 요약: 결정 트리는 이상치나 스케일에 강건하고 시각적 해석력이 압도적이지만, 선형적인 트렌드(대각선 경계)를 계단 모양으로 억지로 쪼개야 하는 약점이 있다.

| 리스크 | 발생 원인 | 대응 방안 (Pruning) | 확인 지표 |
|:---|:---|:---|:---|
| 과적합 (분산 증가) | 데이터를 단 1개만 남을 때까지 끝까지 분할 | 사전 가지치기: `max_depth`, `min_samples_split` 제한 | 훈련/검증 정확도 격차 |
| 불안정성 (노이즈 민감도) | 데이터가 하나만 변해도 최상단 루트 노드 기준이 바뀌어 전체 트리 구조 변동 | 단일 트리 포기 및 Random Forest 앙상블(Bagging) 전환 | 재훈련 시 트리 구조·피처 중요도 변동폭 |

> 요약: 트리의 꼬리를 끝까지 기르면 학습 데이터 100%를 맞추는 과적합 괴물이 되므로, 트리가 더 깊어지지 못하게 제약 파라미터(가지치기)를 반드시 걸어야 한다.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 금융권 대출/신용 평가 심사 (CSS): 딥러닝 대신 C4.5 계열 트리를 도입하여 "신용점수 700점 미만 & 연체 2회 이상"이라는 구체적 거절 사유를 금융 당국과 고객에게 명시적(White-box)으로 제출.
2. 제조 공정 불량 원인 추적 (EDA): 불량품과 양품 데이터를 타겟으로 단일 결정 트리를 깊이 3 수준(Depth=3)으로 가볍게 그려, 가장 최상단 루트 노드에 잡힌 공정 변수(예: 온도 > 85도)를 핵심 불량 유발 인자로 도출.
3. 앙상블 모델의 약한 학습기(Weak Learner) 활용: 단일 결정 트리의 노이즈 민감성(과적합) 한계를 역이용하여, XGBoost나 LightGBM 내부에서 약하게 학습된(Depth 3~7) 트리 1,000개를 직렬 연결하여 강력한 부스팅 모델 구성.

**결론 (2줄):**
- 기술사 판단: 결정 트리는 직관적 해석력과 전처리의 편리성을 갖춘 훌륭한 탐색 도구이나, 단독으로 배포하기에는 과적합과 데이터 노이즈에 대한 극도의 취약성(높은 분산)이 발목을 잡는다.
- 향후 방향: 현대 AI 실무에서 단일 결정 트리를 최종 예측 모델로 쓰는 경우는 거의 없으며, 데이터 특성 파악용 XAI 도구나 거대 앙상블 모델(Random Forest, XGBoost)을 구성하는 레고 블록으로 역할이 격상되었다.

### 🔀 문제 유형별 목차 전환 (이 키워드 출제 시)

| 유형 | 문제 신호어 | Ⅱ·Ⅲ 강조 | Ⅴ·Ⅵ 강조 |
|:---|:---|:---|:---|
| 포괄형 | "결정 트리의 구성 요소와 분할 알고리즘을 설명하시오" | Information Gain 공식과 불순도 감소 원리 | CART, C4.5의 차이 (지니 vs 엔트로피) |
| 요구사항 명시형 | "의사결정나무의 과적합 원인과 가지치기 기법, 그리고 다른 선형 분류기와 비교하시오" | 데이터를 끝까지 쪼갤 때 발생하는 노이즈 흡수 현상 | 사전/사후 Pruning 조건 및 로지스틱 회귀와의 장단점 비교표 (Ⅴ 강조) |
