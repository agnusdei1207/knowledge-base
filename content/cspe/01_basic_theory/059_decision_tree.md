## Ⅰ. 개요
- 정의: 데이터의 특성에 따라 질문을 던져 나무 구조로 분류나 회귀를 수행하는 알고리즘임
- 배경: 모델 결과에 대한 명확한 근거(White-box) 및 해석력 요구 증대
- 출제 의도:
| 구분 | 내용 |
| --- | --- |
| 핵심 | 엔트로피, 지니 계수, 정보 이득(Information Gain) |

## Ⅱ. 구성요소
- ASCII 구조도
    [Root Node]
     /      \
  [Node]  [Leaf]
   /  \
[Leaf][Leaf]
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 지니 계수 | 불순도를 나타내는 지표, 낮을수록 순수함 | 섞인정도 |
| 가지치기 | 과적합 방지를 위해 불필요한 가지를 제거함 | 전정작업 |
| 정보 이득 | 분할 전후의 불순도 감소량 | 유익함 |
> 요약: 정보 손실을 최소화하는 최적의 질문 순서를 찾아냄

## Ⅲ. 절차
- ASCII 흐름도
  [특성선택] -> [노드분할] -> [정지기준] -> [가지치기]
- 4단계 설명
1. 특성 선택: 불순도를 가장 많이 낮추는 최적의 질문 변수 찾음
2. 노드 분할: 선택된 기준으로 데이터를 자식 노드로 나눔
3. 정지 기준: 트리 깊이나 노드 최소 크기 도달 시 분할 멈춤
4. 가지치기: 사후 분석을 통해 일반화 성능 저해하는 가지 제거함
> 요약: 재귀적 분할을 통해 데이터의 클래스 순도를 높임

## Ⅳ. 문제점
- 훈련 데이터에 너무 민감하여 쉽게 과적합되는 경향이 있음
- 선형 구조의 데이터를 표현하는 데 효율적이지 못함

## Ⅴ. 개선방안
- (단기) 트리의 최대 깊이(Max Depth)를 제한하여 복잡도 조절함
- (중기) 앙상블 기법(Random Forest)으로 모델의 분산 낮춤
- (장기) 특성 스케일링 무관한 특성 살려 비정형 데이터와 혼용함

## Ⅵ. 전망
- SHAP, LIME 등 설명 가능한 AI(XAI) 분석 시 로컬 모델의 해석력을 제공하는 핵심 도구로서 위상이 더욱 강화될 것임
- 수식 발견을 위한 기호 회귀(Symbolic Regression)와 결합하여 물리 법칙이나 비즈니스 룰을 자동 추출하는 도구로 진화함
- 도메인 전문가의 지식을 트리 구조에 직접 주입(Knowledge Injection)하여 예측 신뢰도를 확보하는 것이 실무적 CSF임
