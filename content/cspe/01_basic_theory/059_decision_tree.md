## Ⅰ. 개요
- **정의**: 데이터의 특징을 불순도 기준으로 반복 분할하여 트리 형태의 의사결정 규칙을 생성하는 모델
- **배경/필요성**: 블랙박스 모델과 달리 분류·회귀 결과의 도출 근거를 직관적으로 설명할 수 있는 해석 가능 모델 요구
- **비유**: 스무고개 게임처럼 질문(조건)을 반복하여 정답(클래스)에 도달하는 과정

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 불순도 지표 원리 이해 | 엔트로피 vs 지니계수 계산 차이 | 정보 이득(IG)과 불순도 감소를 혼동 금지 |
| 과적합 방지 전략 | 사전·사후 가지치기 구분 | 앙상블(RF/XGBoost) 연계는 060번 참조 위임 |

> 요약: 결정 트리는 불순도 최소화 분할과 가지치기를 통해 해석 가능한 분류·회귀 규칙을 생성하는 모델임

## Ⅱ. 구성요소
```text
+----------------+       +----------------+       +----------------+
| Root Node      |       | Internal Node  |       | Leaf Node      |
| (Full Dataset) | ----> | (Split Rule)   | ----> | (Class/Value)  |
+----------------+       +------+---------+       +----------------+
                                |
                         Impurity Metric
                        (Gini / Entropy)
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 루트/내부 노드 | 특정 변수와 임계값으로 데이터를 이진 분할하는 조건 | 스무고개 질문 |
| 리프 노드 | 더 이상 분할되지 않는 종착점, 최종 클래스 또는 예측값 보유 | 최종 정답 |
| 불순도 지표 | 노드 내 클래스 혼합도 측정 (Gini: 1-Σpi², Entropy: -Σpi·log₂pi) | 순도 측정기 |

> 요약: 결정 트리는 분할 조건(내부 노드), 최종 결과(리프 노드), 분할 기준(불순도 지표)으로 구성됨

## Ⅲ. 절차
```text
+----------------+       +----------------+       +----------------+       +----------------+
| Impurity Calc  |       | Best Split     |       | Recursive Grow |       | Pruning        |
| (Gini/Entropy) | ----> | (Max IG)       | ----> | (Sub-trees)    | ----> | (Cut Branches) |
+----------------+       +----------------+       +----------------+       +----------------+
```

1. **불순도 계산** — 각 노드에서 클래스 분포의 Gini 계수 또는 Entropy 값 산출
2. **최적 분할 탐색** — 정보 이득(IG = 부모 불순도 - 자식 불순도 가중합)이 최대인 변수·임계값 선택
3. **재귀적 트리 성장** — 분할된 자식 노드에서 동일 과정을 재귀 반복하여 트리 확장
4. **가지치기(Pruning)** — 사전(max_depth 제한) 또는 사후(비용-복잡도 기준) 가지치기로 과적합 억제

> 요약: 불순도 감소 최대화 기준으로 재귀 분할한 후, 가지치기로 일반화 성능을 확보함

## Ⅳ. 문제점
- 과적합 취약: 트리가 깊어질수록 훈련 노이즈까지 학습하여 테스트 정확도가 급락 (깊이 20 이상 시 현저)
- 높은 분산: 훈련 데이터가 소량 변경되어도 트리 구조가 전면 재구성되어 예측 불안정
- 축 수직 분할 한계: 분할 경계가 축에 수직(직교)하여 대각선·곡선 패턴 포착에 비효율적

> 요약: 과적합·높은 분산·직교 분할 한계가 단일 결정 트리의 주요 약점임

## Ⅴ. 개선방안
1. 단기: max_depth, min_samples_split 등 사전 가지치기 하이퍼파라미터로 트리 복잡도 제한
2. 중기: 비용-복잡도 가지치기(CCP, α 파라미터)로 사후 브랜치 병합하여 분산 감소
3. 장기: 다수 트리를 결합하는 앙상블(Random Forest, Gradient Boosting)로 분산·편향 동시 개선 (-> 060번 참조)

- 과적합: 과도한 분할 -> max_depth ≤ 10 제한 (지표: Train-Test 정확도 갭 < 5%)
- 높은 분산: 데이터 민감도 -> 교차 검증 5-Fold로 안정성 확인 (지표: CV 표준편차)
- 직교 분할: 비선형 패턴 -> Oblique Tree 또는 커널 기반 분할 적용 (지표: AUC 개선율)

> 요약: 사전·사후 가지치기로 과적합을 억제하고, 앙상블 기법으로 단일 트리의 근본적 한계를 극복함

## Ⅵ. 전망
- 향후 발전 방향: 단독 사용보다 XGBoost·LightGBM·CatBoost 등 Gradient Boosting 앙상블의 기본 학습기(Weak Learner)로 활용이 표준화
- 기술사적 판단: 해석 가능성(Explainability) 요구가 높은 금융·의료 도메인에서 규제 준수용 모델로 단일 트리의 수요 지속
- 기술사 제언: XAI 요건이 있는 프로젝트에서는 트리 깊이를 제한한 얕은 트리 + SHAP 해석을 조합하여 설명력과 성능을 동시 확보할 것
