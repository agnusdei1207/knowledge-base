# 결정 트리 (Decision Tree)

## 1. 개요

- **정의/개념**: 결정 트리는 feature 조건을 기준으로 데이터를 반복 분할해 리프 노드에서 예측값이나 클래스를 결정하는 트리 기반 지도 학습 모델이다.
- **배경/필요성**: 업무 의사결정은 조건 분기 형태로 설명되는 경우가 많으므로, 예측과 해석을 동시에 제공하는 모델이 필요하다.

결정 트리의 핵심은 어떤 feature와 threshold로 데이터를 나눌 때 불순도가 가장 줄어드는지를 선택하는 것이다.

## 2. 특징 및 비교

| 구분 | 결정 트리 | 선형 모델 | 랜덤 포레스트 |
|---|---|---|---|
| 관계 표현 | 비선형·조건 분기 | 선형 관계 | 여러 트리 앙상블 |
| 해석성 | 높음 | 높음 | 중간 |
| 과적합 위험 | 높음 | 상대적으로 낮음 | 낮아짐 |
| 성능 | 단일 트리 한계 | 선형 문제 강함 | 안정적 |

선택 기준은 해석성 요구, 비선형 관계, 과적합 위험, 데이터 크기, 앙상블 필요성이다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| Root Node | 첫 분할 기준 | 가장 큰 정보 이득 |
| Internal Node | 중간 조건 분기 | feature threshold |
| Leaf Node | 최종 예측 | class/value |
| Split Criterion | 분할 품질 평가 | Gini, entropy, MSE |
| Pruning | 불필요한 가지 제거 | 과적합 방지 |

```text
+----------+      +----------+      +----------+
| 루트분할 | ---> | 조건분기 | ---> | 리프예측 |
+----------+      +----------+      +----------+
```

트리 깊이가 깊어질수록 학습 데이터에는 잘 맞지만 일반화 성능이 떨어질 수 있으므로 분할과 가지치기가 함께 관리된다.

## 4. 문제점 및 개선방안

1. **과적합**
   - 깊은 트리는 학습 데이터의 노이즈까지 분기 조건으로 학습할 수 있다.
   - **개선방안**: max depth, min samples leaf, pruning을 적용한다.

2. **분산이 큼**
   - 데이터가 조금 바뀌어도 트리 구조가 크게 달라질 수 있다.
   - **개선방안**: bagging, random forest, cross validation을 사용한다.

3. **분할 편향**
   - 고유값이 많은 feature가 정보 이득에서 유리하게 선택될 수 있다.
   - **개선방안**: gain ratio, feature 검증, 중요도 해석 보정을 적용한다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| 신용 심사 | 조건 분기로 위험 등급 산정 | AUC, 승인 기준 설명 |
| 장애 원인 분석 | 운영 지표 조건으로 장애 여부 예측 | recall, rule 해석 |
| 고객 이탈 예측 | 행동 feature 기준으로 이탈 가능성 분기 | lift, precision |

## 6. 결론

결정 트리는 조건 분기 구조로 예측과 설명을 동시에 제공하는 모델이다. 분할 기준, 트리 깊이, 가지치기, 과적합 관리를 연결해야 단일 트리의 장점과 랜덤 포레스트 같은 앙상블로 확장되는 이유가 분명해진다.
