## 미리 알고가기

- 노드: 데이터를 나누거나 예측값을 담는 트리의 기본 단위임
- 불순도: 한 노드 안에 서로 다른 클래스가 섞인 정도를 나타내는 값임
- 지니 계수: 무작위로 고른 샘플이 잘못 분류될 가능성을 이용한 불순도 지표임
- 정보 이득: 분할 전후 엔트로피 감소량이며 분할 기준의 품질을 나타냄
- 가지치기: 과도하게 깊어진 트리 일부를 줄여 일반화 성능을 높이는 절차임

## Ⅰ. 개요

- **정의/개념**: 결정 트리는 데이터를 조건 분기로 반복 분할해 리프 노드에서 분류 클래스나 회귀값을 산출하는 지도 학습 모델임
- **배경/필요성**: 예측 결과와 판단 경로를 함께 설명하기 위해 사람이 읽을 수 있는 규칙 기반 모델이 필요함

## Ⅱ. 특징

- if-then 형태의 경로가 그대로 예측 근거가 되어 모델 해석이 쉬움
- 수치형과 범주형 변수를 함께 다룰 수 있고 스케일링 영향이 작음
- 불순도 감소가 큰 분할을 재귀적으로 선택해 비선형 경계를 만듦
- 깊이 제한이 없으면 학습 데이터 변화에 민감해 과적합과 높은 분산이 발생함

## Ⅲ. 종류 및 비교

| 판단 기준 | 분류 트리 | 회귀 트리 |
|:---|:---|:---|
| 예측 대상 | 범주형 클래스 | 연속형 수치 |
| 분할 기준 | 지니 계수, 엔트로피 | 평균제곱오차, 분산 감소 |
| 리프 출력 | 다수 클래스 또는 클래스 확률 | 노드 내 평균값 |
| 평가 지표 | 정확도, F1, AUC | RMSE, MAE, $R^2$ |

> 요약: 분류 트리는 클래스를 고르고, 회귀 트리는 영역별 대표 수치를 산출함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 루트 노드 | 전체 데이터를 처음 나누는 최상위 조건이며 모델 경로의 시작점임 |
| 내부 노드 | 변수와 임계값을 기준으로 데이터를 계속 분할하는 판단 지점임 |
| 가지 | 조건 결과에 따라 다음 노드로 이동하는 경로임 |
| 리프 노드 | 더 이상 분할하지 않고 최종 예측값을 담는 끝 노드임 |
| 분할 기준 | 불순도나 오차 감소가 가장 큰 변수와 임계값을 선택하는 기준임 |

```text
+----------------+
| root condition |
+----------------+
       |
       +-- yes --> +-----------+ --> +----------+
       |           | node      |     | leaf A   |
       |
       +-- no  --> +----------+
                   | leaf B   |
                   +----------+
```

> 요약: 결정 트리는 루트에서 리프까지의 조건 경로가 그대로 예측 근거가 됨.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+      +----------+      +----------+      +----------+
| choose   | ---> | split    | ---> | recurse  | ---> | prune    |
+----------+      +----------+      +----------+      +----------+
```

1. **후보 탐색**: 모든 변수와 임계값 후보의 불순도 또는 오차 감소량을 계산함
2. **최적 분할**: 가장 큰 개선을 만드는 조건으로 데이터를 하위 노드로 나눔
3. **재귀 반복**: 노드가 충분히 순수하거나 종료 조건에 도달할 때까지 분할함
4. **복잡도 제어**: 최대 깊이, 최소 샘플 수, 가지치기로 과적합을 낮춤

> 요약: 결정 트리는 분할 이득을 높이되 깊이와 최소 샘플 수로 분산을 통제해야 함.

## Ⅵ. 실무 사례

1. 심사·진단처럼 설명이 필요한 업무는 깊이와 최소 샘플 수를 제한하고 경로 안정성과 혼동 행렬로 검증함
2. 고차원·노이즈 데이터는 단일 트리가 불안정하므로 Random Forest나 GBM과 비교하고 성능과 해석성을 함께 판단함

## Ⅶ. 결론

- 결정 트리는 설명 가능한 조건 분기 모델이며, 해석성 장점은 깊이와 분산을 통제할 때 유지됨

## 작성 근거(검토용)

- 개요는 조건 분기와 리프 예측을 함께 담아 결정 트리의 구조와 산출물을 명확히 함
- 특징은 해석성, 전처리 부담, 비선형 분할, 과적합 위험을 핵심으로 선별함
- 비교표는 분류와 회귀의 대상, 기준, 출력, 지표 차이를 정리함
- 구성요소는 노드와 가지의 역할을 예측 경로 관점에서 배열함
- 절차는 분할 후보 탐색부터 가지치기까지 트리 생성 흐름을 유지함
- 유의점은 설명 가능 업무와 단일 트리 불안정성을 실무 판단 축으로 선택함
