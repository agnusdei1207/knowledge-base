## Ⅰ. 개요
- **정의**: 다항식 시간 내 해답 검증은 가능하나 다항식 시간 해법이 알려지지 않은 결정 문제 집합
- **배경/필요성**: 문제의 계산 난이도를 분류해야 알고리즘 설계 시 해법 존재 여부를 판단할 수 있음. 자원 투입 전 문제 난이도를 사전 평가하는 이론적 틀이 요구됨
- **비유**: 자물쇠를 여는 열쇠 조합을 찾기는 어렵지만, 누군가 알려준 조합이 맞는지 확인하는 것은 한 번에 가능한 것과 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| P·NP·NP-Hard·NP-Complete 관계 구분 | 환원(reduction) 개념과 NP-Complete의 정의 조건 2가지 | NP를 "지수 시간"으로 오해하지 말 것 — NP는 검증 시간 기준 |

> 요약: 다항식 검증 가능 + 모든 NP 문제에서 환원 가능한 문제가 NP-Complete임

## Ⅱ. 구성요소
```text
        +------------------+
        |   모든 문제 공간   |
        +------------------+
               |
       +-------+-------+
       |               |
    +--+--+        +---+----+
    |  P  |        | NP-Hard |
    +--+--+        +---+----+
       |               |
       +-------+-------+
               |
        +------+------+
        | NP-Complete |
        +-------------+
            (P 교 NP-Hard 가 아닌,
             NP 교 NP-Hard 의 교집합)
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| P | 다항식 시간 내 풀이와 검증 모두 가능한 문제 집합 | 계산기로 즉시 답을 구할 수 있는 산술 문제 |
| NP | 다항식 시간 내 해답 검증이 가능한 문제 집합 (P 포함) | 정답지가 있으면 채점은 빠르게 가능한 시험 |
| NP-Hard | 모든 NP 문제를 다항식 시간에 환원할 수 있는 문제 (NP 소속 불필요) | 모든 퍼즐을 포함하는 '만능 퍼즐' — 풀면 나머지도 풀림 |
| NP-Complete | NP이면서 동시에 NP-Hard인 문제 (NP와 NP-Hard의 교집합) | 채점도 빠르고, 만능 퍼즐이기도 한 문제 |
| 환원(Reduction) | 문제 A를 다항식 변환으로 문제 B의 입력으로 바꾸는 기법 | 영어 문제를 한국어로 번역해서 푸는 것 |

> 요약: P ⊆ NP이며, NP-Complete = NP ∩ NP-Hard로 정의됨

## Ⅲ. 절차
```text
문제 정의 --> NP 소속 증명 --> 기지 NPC 문제 선택 --> 환원 증명
    |              |                  |                   |
    v              v                  v                   v
 결정 문제      다항식 시간        SAT 등 기존        다항식 변환
  형태 변환     검증기 제시       NPC 활용          정당성 증명
```
- 1단계: 대상 문제를 "예/아니오"로 답하는 결정 문제 형태로 변환함
- 2단계: 후보 해가 주어졌을 때 다항식 시간 내 검증 가능함을 증명하여 NP 소속을 확인함
- 3단계: 이미 NP-Complete로 증명된 기지 문제(SAT, 3-SAT 등)를 선택함
- 4단계: 기지 NPC 문제를 대상 문제로 다항식 시간에 환원할 수 있음을 증명하여 NP-Hard 조건을 충족함

> 요약: NP 소속 증명 + 기존 NPC 문제로부터의 환원 증명으로 NP-Complete를 입증함

## Ⅳ. 문제점
- 해법 부재 불확실성: P = NP 여부가 미해결(077 참조)이므로 다항식 해법 존재 자체를 확정할 수 없음 — 알고리즘 설계 시 최적해 보장 불가
- 환원 설계 난이도: 두 문제 간 다항식 환원 함수를 구성하는 것 자체가 고도의 수학적 통찰을 요구함 — 새 문제의 NPC 분류가 지연됨
- 실용 격차: 이론적 최악 복잡도와 실제 인스턴스 난이도 간 괴리가 존재함 — NPC 문제라도 특정 입력에서는 빠르게 풀리므로 분류만으로 실무 판단이 어려움

> 요약: 미해결 난제, 환원 설계 어려움, 이론-실무 격차가 주요 한계임

## Ⅴ. 개선방안
1. 단기: 근사 알고리즘·휴리스틱(탐욕, 유전 알고리즘 등)으로 실용적 준최적해를 확보함
2. 중기: 파라미터화 복잡도(FPT) 등 세분화 분류를 적용하여 특정 구조의 입력에 대해 다항식 해법을 도출함
3. 장기: 양자 컴퓨팅 등 새로운 계산 모델을 활용하여 탐색 공간 축소 가능성을 검증함

> 요약: 근사·파라미터화·새 계산 모델 순으로 NPC 문제의 실용적 해결 범위를 확대함

## Ⅵ. 전망
- 발전 방향: SAT 솔버 성능 향상으로 산업 규모 NPC 인스턴스의 실용적 풀이 범위가 확대되는 추세임
- 기술사적 판단: 시스템 설계 시 문제 복잡도 분류를 선행해야 자원 배분과 알고리즘 선택이 합리적으로 이루어짐
- 기술사 제언: 최적화 문제를 만나면 NPC 여부를 먼저 판별하고, 해당 시 근사 비율 보장이 있는 알고리즘을 우선 검토할 것
