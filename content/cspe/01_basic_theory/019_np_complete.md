# NP-완전 문제 (NP-Complete)

## 1. 개요

- **정의/개념**: NP-완전은 NP에 속하면서 모든 NP 문제가 다항 시간에 자신으로 환원될 수 있는 결정 문제 집합이다.
- **배경/필요성**: 다항 시간 해법이 알려지지 않은 문제들의 난이도를 개별적으로 증명하기 어렵기 때문에, 환원으로 문제 간 난이도를 연결해 분류할 기준이 필요하다.

NP-완전은 "절대 풀 수 없다"는 뜻이 아니라 일반적인 다항 시간 정확 해법이 알려지지 않은 난이도 분류이다.

## 2. 특징 및 비교

| 구분 | 의미 | 예 |
|---|---|---|
| P | 다항 시간에 풀 수 있는 결정 문제 | 최단 경로 결정형 |
| NP | 해가 주어지면 다항 시간에 검증 가능한 문제 | SAT, Hamiltonian Cycle |
| NP-hard | 모든 NP 문제가 환원되는 수준의 어려운 문제 | 최적화 TSP |
| NP-complete | NP이면서 NP-hard인 결정 문제 | SAT, 3-SAT, Clique |

NP-완전성을 보이려면 대상 문제가 NP에 속하고, 알려진 NP-완전 문제에서 대상 문제로 다항 시간 환원됨을 보여야 한다.

NP-완전 판단은 결정 문제 여부, 검증 가능성, 환원 방향, 입력 규모, 정확·근사·휴리스틱 선택 기준을 함께 본다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| 결정 문제 | Yes/No로 답하는 문제 형태 | NP-complete 판정 대상 |
| 검증기 | 후보 해를 다항 시간에 확인 | NP 소속 조건 |
| 환원 | 한 문제를 다른 문제로 다항 시간 변환 | 난이도 전달 |
| 환원 방향 | 알려진 NP-완전 -> 대상 문제 | 증명 핵심 |
| 실무 해법 | 정확·근사·휴리스틱·특수 사례 | 적용 전략 |

```text
결정 문제화 -> NP 소속 증명 -> 알려진 NP-완전 문제에서 환원 -> 해결 전략 선택
```

## 4. 문제점 및 개선방안

1. **환원 방향 오류**
   - 대상 문제에서 알려진 NP-완전 문제로 환원하면 대상의 어려움을 보이지 못한다.
   - **개선방안**: 알려진 NP-완전 문제에서 대상 문제로 가는 방향을 명확히 한다.

2. **실무 난이도 과대해석**
   - NP-완전이라는 이유로 작은 입력이나 특수 제약까지 포기할 수 있다.
   - **개선방안**: 입력 규모, 제약 조건, 허용 오차를 기준으로 정확 알고리즘·근사·휴리스틱을 선택한다.

3. **최적화 문제와 결정 문제 혼동**
   - 최적값을 구하는 문제는 보통 NP-hard이고, 결정 버전이 NP-complete일 수 있다.
   - **개선방안**: 문제 형식을 결정형과 최적화형으로 구분한다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| 스케줄링 | 작업 배치 문제를 NP-hard로 보고 휴리스틱 적용 | 실행 시간, 최적해 gap |
| 물류 경로 | TSP 계열 문제에 근사·메타휴리스틱 적용 | 비용 절감률, 제약 만족 |
| 보안·암호 | 난이도 가정에 기반한 문제 선택 | 키 크기, 공격 비용 |

## 6. 결론

NP-완전은 문제의 계산 난이도를 분류하고 해결 전략을 정하는 기준이다. NP, NP-hard, NP-complete를 구분하고 입력 규모, 허용 품질, 실행 시간 제약에 맞춰 정확·근사·휴리스틱 해법을 선택해야 한다.
