## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | NP에 속하면서 NP의 모든 문제가 다항 시간에 환원(Reduce)될 수 있는 문제 클래스로, 다항 시간 알고리즘이 알려져 있지 않은 최난 문제군임 |
| **배경/필요성** | 문제가 NP-완전임을 증명하면 다항 시간 해법 탐색을 중단하고 근사·휴리스틱 전략으로 전환할 수 있음 |
| **출제 의도** | P·NP·NP-완전·NP-난해의 관계와 다항 환원의 의미를 설명할 수 있는지 평가함 |

## Ⅱ. 구성요소
```
+----------+     +----------+     +----------+
|    P     | --> |   NP     | --> | NP-완전  |
| (다항해결)|     | (다항검증)|     | (NP최난) |
+----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| P | 결정론적 튜링머신에서 다항 시간에 풀 수 있는 문제 클래스임 | 쉬운 시험 문제 |
| NP | 비결정론적 튜링머신에서 다항 시간에 풀 수 있거나, 해의 검증이 다항 시간인 클래스임 | 답을 보면 맞는지 바로 확인 가능 |
| NP-완전 | NP에 속하면서 NP의 모든 문제가 환원 가능한 가장 어려운 문제(SAT·TSP 등)임 | NP의 대표 난제 |

> 요약: P ⊆ NP이며, NP-완전은 NP의 모든 문제가 환원 가능한 최난 클래스임.

## Ⅲ. 절차
```
+------------+     +------------+
| NP소속증명  | --> | 다항환원   |
| (검증다항) |     | (기존NPC→)|
+------------+     +------------+
                        |
+------------+     +----+-------+
| NPC확정    | <-- | 환원정당성 |
|            |     | 증명      |
+------------+     +------------+
```

1. NP 소속 증명: 해가 주어졌을 때 다항 시간에 검증할 수 있음을 보임
2. 기존 NPC 문제 선택: 이미 NP-완전으로 증명된 문제(SAT 등)를 선택함
3. 다항 환원: 기존 NPC 문제의 임의 인스턴스를 대상 문제의 인스턴스로 다항 시간에 변환함
4. 정당성 증명: 원래 문제가 Yes ⟺ 변환된 문제도 Yes임을 양방향으로 증명하여 NPC를 확정함

> 요약: NP 소속 증명 + 기존 NPC로부터의 다항 환원으로 NP-완전성을 증명함.

## Ⅳ. 문제점
- 다항 해법 부재: NP-완전 문제의 정확한 해를 구하려면 최악 지수 시간이 소요됨
- 실용적 규모 한계: 입력 크기가 수십 이상이면 정확 해법의 실행이 현실적으로 불가함
- P=NP 미해결: P≠NP인지 여부가 미해결이어서 다항 시간 해법의 존재 가능성이 열려 있음

## Ⅴ. 개선방안
- (단기) 근사 알고리즘: 다항 시간에 최적해의 일정 비율(근사비) 이내 해를 구함
- (중기) 매개변수화 알고리즘(FPT): 특정 매개변수 k가 작으면 O(f(k)·n^c)에 정확 해를 구함
- (장기) 양자 알고리즘: Grover 알고리즘으로 탐색 공간을 O(√N)으로 줄여 근사 가속함

## Ⅵ. 전망
- SAT 솔버·ILP 솔버의 발전으로 실용적 규모의 NP-완전 문제가 산업에서 해결되고 있으며, 양자 컴퓨팅의 QAOA(양자 근사 최적화)가 조합 최적화의 차세대 접근으로 부상할 전망임
