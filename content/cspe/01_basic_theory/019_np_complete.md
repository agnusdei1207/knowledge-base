## Ⅰ. 개요
- NP 문제 중 가장 어려운 집합으로, 다항 시간 내 해 도출이 미해결된 난제임.
- NP 문제이면서 모든 NP 문제를 다항 시간 내에 해당 문제로 환원 가능함.
- [표] 출제 의도: 계산 복잡도 계층 및 현실적 문제 해결 한계 이해 평가.

## Ⅱ. 구성요소
- ASCII 구조도
  [ P ] < [ NP ] < [ NP-Hard ]
              \ [ NP-Complete ] /

| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| P (Polynomial) | 다항 시간 내에 풀 수 있는 문제 | 숙련자의 암산 |
| NP (Non-poly) | 답이 주어지면 다항 시간 내 검산 가능 | 정답지 확인 |
| Reduction | 문제 A를 문제 B로 변형하여 해결함 | 번역기 사용 |

> 요약: 하나라도 다항 시간에 풀리면 모든 NP 문제가 풀리는 핵심 난제임.

## Ⅲ. 절차
- ASCII 흐름도
  Problem X -> Reduction -> NP-Complete Problem Y -> Solver

1. 주어진 문제 X가 NP에 속하는지(검산 가능성) 증명함.
2. 기존에 알려진 NP-완전 문제 Y를 선택함.
3. 문제 Y를 다항 시간 내에 문제 X로 변형(Reduction) 가능함을 보임.
4. X가 Y만큼 어렵다는 것을 입증하여 NP-완전성을 확정함.

> 요약: 환원 기법을 통해 문제의 난이도 등급을 증명함.

## Ⅳ. 문제점
- 현실 세계의 많은 최적화 문제가 NP-완전에 속해 정확한 해 도출이 불가함.
- 데이터 크기 증가 시 계산량이 기하급수적으로 폭증함.

## Ⅴ. 개선방안
- 단기: 최적해 대신 수용 가능한 수준의 근사 알고리즘(Heuristic) 사용함.
- 중기: 특정 제약 조건을 완화하여 다항 시간에 풀리는 부분 문제로 정의함.
- 장기: 양자 컴퓨팅 등 새로운 계산 모델을 통한 돌파구 모색함.

## Ⅵ. 전망
- 암호학(인수분해 기반), 물류 최적화 등 산업계 전반에 영향 미침.
- P vs NP 문제는 컴퓨터 과학의 최대 난제로 이론적 연구 지속됨.
