## Ⅰ. 개요
- **정의**: 정수론적 난제(소인수분해·이산대수)를 이용해 비대칭 키 암호를 구현하는 수학적 기반임
- **배경/필요성**: 공개 채널에서 키 교환과 인증을 안전하게 수행하려면 역산이 불가능한 일방향 함수가 필수임
- **비유**: 전화번호부에서 이름→번호 찾기는 쉽지만, 번호→이름 역추적은 어려운 것과 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| RSA·DH·ECC의 수학적 근거 구분 | 소인수분해 vs 이산대수 vs 타원곡선 난제 비교 | 세 난제를 혼동하면 감점 |
| 공개키 암호 체계 설계 원리 | 오일러 정리 기반 키 생성 절차 | 키 길이·보안 강도 매핑 누락 주의 |

> 요약: 정수론 난제의 계산 비대칭성을 활용해 공개키/비밀키 쌍을 생성하는 암호 수학 기반임

## Ⅱ. 구성요소
```text
+----------+     +-----------+     +----------+     +----------+
| Prime Gen| --> | Modular Op| --> | Key Pair | --> | Cipher Op|
+----------+     +-----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 소수 생성기 | 밀러-라빈 등 확률적 소수 판정으로 1024bit 이상 소수 p, q 생성 | 자물쇠 재료 |
| 모듈러 연산부 | $c = m^e \bmod N$ 형태의 거듭제곱 연산으로 암·복호 수행 | 일방향 문 |
| 키 쌍 관리 | 오일러 파이 함수 $\phi(N)$과 확장 유클리드로 공개키 e, 비밀키 d 도출 | 열쇠 세트 |
| 이산대수 모듈 | $g^x \equiv y \pmod{p}$ 에서 x 역산 불가 특성을 DH 키 교환에 활용 | 섞인 물감 |

> 요약: 소수 생성 → 모듈러 연산 → 키 쌍 도출 → 암호 연산의 4단계 구성으로 비대칭 암호를 실현함

## Ⅲ. 절차
```text
+----------+    +----------+    +----------+    +----------+
| Gen p, q | -> | Calc N,d | -> | Encrypt  | -> | Decrypt  |
+----------+    +----------+    +----------+    +----------+
```

1. **소수 생성** — 충분히 큰 두 소수 p, q를 확률적 소수 판정으로 선택함
2. **키 계산** — $N = p \times q$, $\phi(N) = (p-1)(q-1)$로부터 공개키 e와 비밀키 d 산출함
3. **암호화** — 송신자가 공개키 $(e, N)$으로 $c = m^e \bmod N$ 연산을 수행해 암호문 생성함
4. **복호화** — 수신자가 비밀키 d로 $m = c^d \bmod N$ 연산을 수행해 평문 복원함

> 요약: 소수 쌍 → 오일러 함수 기반 키 도출 → 모듈러 거듭제곱 암호화 → 비밀키 복호화 순서임

## Ⅳ. 문제점
- **양자 해독 위협**: 쇼어 알고리즘이 소인수분해·이산대수를 다항 시간에 풀어 기존 체계 무력화 가능
- **키 길이 비용 증가**: 보안 강도 유지 위해 RSA 3072bit 이상 필요, 엣지 기기에서 연산 지연 0.5초 이상 발생
- **난제 의존 구조 취약**: 수학적 난제가 깨지면 암호 체계 전체가 일시에 붕괴되는 단일 실패점 구조임

> 요약: 양자 컴퓨팅 위협, 키 길이 증가에 따른 연산 부담, 난제 의존 구조의 근본적 취약성이 3대 과제임

## Ⅴ. 개선방안
1. 단기: RSA/ECC 키 길이를 NIST 권고(RSA-3072, ECC-256) 이상으로 상향 적용
2. 중기: IoT·경량 디바이스에 ECC 전면 도입으로 동일 보안 강도 대비 키 크기 1/10 축소
3. 장기: CRYSTALS-Kyber 등 격자 기반 양자 내성 암호(PQC)로 선제적 마이그레이션

- **양자 해독 위협**: 수학적 근거 소멸 → PQC 표준(FIPS 203/204) 기반 이중 운용(Hybrid) (지표: PQC 전환율 ≥ 50%)
- **키 길이 비용 증가**: 연산량 증가 → ECC 대체 및 HW 가속기 탑재 (지표: 암호 연산 지연 < 100ms)
- **난제 의존 구조 취약**: 단일 난제 → 다중 난제 결합(하이브리드 암호) 설계 (지표: 2+ 난제 기반 구조 적용)

> 요약: 키 상향 → ECC 전환 → PQC 마이그레이션의 3단계 로드맵으로 양자 시대에 대비함

## Ⅵ. 전망
- **향후 발전 방향**: NIST PQC 표준(FIPS 203/204) 확정에 따라 TLS 1.3 + PQC 하이브리드 모드가 2027년 내 주류화 전망
- **기술사적 판단**: RSA/ECC는 향후 10년간 병행 운용되나, 격자·해시 기반 PQC로의 전환이 불가역적 추세임
- **기술사 제언**: Crypto-Agility(암호 민첩성) 아키텍처를 선제 도입하여 알고리즘 교체 비용을 최소화해야 함
