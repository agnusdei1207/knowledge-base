# 076. 암호 알고리즘 수학 — RSA·이산대수 (Cryptography Mathematics)

## Ⅰ. 개요

- **정의/개념**: 현대 암호학의 근간이 되는 수학적 원리로, 소인수분해의 난해함(RSA)이나 유한체 상의 이산대수 문제(DH, DSA)와 같이 계산적으로 풀기 어려운 '난제(Hard Problem)'를 이용하여 키의 안전성을 보장하는 기술임
- **배경/필요성**: 인터넷과 같은 개방된 네트워크 환경에서 안전하게 비밀키를 공유하거나 상대방의 신원을 확인(인증)하기 위해, 공개된 정보만으로는 개인키를 유추할 수 없는 수학적 일방향성(One-wayness)이 필요함

## Ⅱ. 특징 및 비교 (비대칭키 암호 난제별 분류)

| 판단 기준 | 소인수분해 기반 (RSA) | 이산대수 기반 (DH, DSA) | 타원곡선 기반 (ECC) |
|:---|:---|:---|:---|
| **기반 수학 문제** | 두 소수의 곱 $n=pq$의 역연산 | $g^x \equiv y \pmod p$에서 $x$ 구하기 | 타원곡선 점의 스칼라 곱 역연산 |
| **안전성 근거** | 큰 수의 소인수분해 복잡도 | 이산대수 문제의 계산 복잡도 | 타원곡선 이산대수 문제(ECDLP) |
| **키 길이 효율성** | 낮음 (2048~4096 bit 필요) | 보통 | 매우 높음 (256 bit로 RSA 3072급) |
| **주요 용도** | 암호화, 전자서명 | 키 교환, 전자서명 | 모바일/IoT 보안, 인증서 |

> 요약: RSA는 범용성이 좋으나 키가 크고, ECC는 적은 연산량으로 높은 안전성을 제공하여 현대 기술의 주류임

## Ⅲ. 구성요소/구조 (RSA 기준)

- **구성요소**:
  - **Modular Arithmetic (모듈러 연산)**: 특정 정수 $n$으로 나눈 나머지를 사용하는 시계 산술로, 암호학적 연산 공간의 기초임
  - **Euler's Totient Function ($\phi(n)$)**: $n$보다 작고 $n$과 서로소인 정수의 개수로, 개인키 산출의 핵심 수식임
  - **Public Key $(e, n)$**: 평문 $M$을 암호화할 때 사용하며 외부로 공개됨 ($C = M^e \pmod n$)
  - **Private Key $(d, n)$**: 암호문 $C$를 복호화할 때 사용하며 본인만 소유함 ($M = C^d \pmod n$)
- **키 생성 알고리즘**:
```text
1. 서로 다른 두 큰 소수 p, q를 선택
2. n = p * q 계산 (공개키 일부)
3. Φ(n) = (p-1) * (q-1) 계산
4. Φ(n)과 서로소인 공개키 e 선택 (보통 65537)
5. (e * d) mod Φ(n) = 1 을 만족하는 개인키 d 계산
```

## Ⅳ. 문제점 및 개선방안

1. **[연산 속도 및 오버헤드]**: 대칭키 암호(AES 등)에 비해 연산 속도가 수백~수천 배 느려 대용량 데이터 직접 암호화에 부적합함
   - **개선방안**: 비대칭키로는 대칭키(세션키)만 교환하고, 실제 데이터는 대칭키로 암호화하는 하이브리드 암호 방식을 사용함 (확인: 핸드셰이크 소요 시간)
2. **[패딩 없는 암호화 취약성]**: 동일한 평문을 동일한 키로 암호화하면 결과가 항상 같아지는 결정적(Deterministic) 취약점이 있음
   - **개선방안**: OAEP(Optimal Asymmetric Encryption Padding)와 같은 난수 패딩 기법을 적용하여 매번 다른 암호문이 생성되도록 함 (확인: 선택 평문 공격 대응)
3. **[양자 컴퓨팅 위협 (Shor's Algo)]**: 충분한 성능의 양자 컴퓨터 등장 시, 현재의 소인수분해 및 이산대수 기반 암호체계가 실시간으로 해독될 위험이 있음
   - **개선방안**: 격자(Lattice) 기반이나 코드 기반 암호 등 양자 내성 암호(PQC)로의 전환을 준비함 (확인: 암호 민첩성(Crypto Agility))

## Ⅴ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| **HTTPS (TLS)** | 서버의 RSA/ECC 공개키가 담긴 인증서를 통해 세션키 공유 및 서버 인증 | SSL Labs 스코어, 암호화 알고리즘 강도 |
| **전자서명 (Digital Signature)** | 개인키로 메시지 해시값을 서명하고 공개키로 검증하여 무결성/부인방지 보장 | 인증서 유효 기간, 폐기 여부 (CRL/OCSP) |
| **블록체인 (Blockchain)** | ECDSA(타원곡선 서명)를 사용하여 거래 소유권을 증명하고 지갑 주소 생성 | 개인키 노출 여부, 서명 생성 속도 |

> 요약: 실무에서는 안전성과 성능의 타협점인 2048비트 이상의 RSA나 256비트 이상의 ECC를 표준으로 권고함

## Ⅵ. 결론

암호 알고리즘 수학은 단순히 숫자를 꼬는 기교가 아니라, 수학적 불가능성을 보안의 장벽으로 치환하는 고도의 논리 체계임. 비록 양자 컴퓨팅이라는 거대한 도전에 직면해 있으나, 소인수분해와 이산대수의 원리를 이해하는 것은 정보 보안의 본질을 파악하는 첫걸음임. 향후에는 더욱 복잡한 수학 난제를 활용한 동형 암호(Homomorphic Encryption) 등 데이터 프라이버시를 완벽히 보호하는 기술로 발전할 전망임.
