## Ⅰ. 개요
- **정의**: 유한 개의 상태와 전이 규칙으로 입력 문자열의 수리·거부를 판정하는 추상 기계
- **배경/필요성**: 정규 언어를 인식하는 최소 계산 모델이 필요하며, 어휘 분석·패턴 매칭의 이론적 기반이 됨
- **비유**: 동전 투입에 따라 상태가 바뀌는 자판기처럼, 입력 하나마다 정해진 상태로 이동하는 기계임

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| DFA와 NFA의 차이·등가성을 설명할 수 있는지 확인 | 5-튜플 정의와 부분집합 구성법 | NFA가 DFA보다 인식 능력이 높다고 오해하지 말 것 |

> 요약: 유한 상태와 전이 함수로 정규 언어를 인식하는 추상 계산 모델임

## Ⅱ. 구성요소
```text
  입력 문자열: a b a
       |
       v
  [q0] --a--> [q1] --b--> [q2] --a--> [q3*]
  시작          중간         중간        수리
  상태          상태         상태        상태
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 상태 집합(`Q`) | 오토마톤이 가질 수 있는 유한 개의 상태 모음 | 자판기의 금액 표시 단계 |
| 입력 알파벳(`Sigma`) | 오토마톤이 읽을 수 있는 기호의 유한 집합 | 자판기에 넣을 수 있는 동전 종류 |
| 전이 함수(`delta`) | 현재 상태와 입력 기호에 따라 다음 상태를 결정하는 규칙 | 동전 투입 시 금액이 바뀌는 규칙표 |
| 시작 상태(`q0`) | 입력 처리를 시작하는 초기 상태 | 자판기 전원 켜짐 시 초기 화면 |
| 수리 상태(`F`) | 입력을 모두 읽은 뒤 이 상태에 있으면 문자열을 수리함 | 금액이 충족되어 상품이 나오는 상태 |

> 요약: 5-튜플(`Q`, `Sigma`, `delta`, `q0`, `F`)로 구성되어 입력을 순차 처리함

## Ⅲ. 절차
```text
  1.초기화         2.입력읽기       3.전이실행       4.수리판정
  (q0설정)        (기호1개소비)    (delta적용)      (F포함여부)
   |               |               |               |
   +---시작상태---->+---기호전달---->+---다음상태---->+
  상태초기화       테이프헤드이동   상태갱신        수리/거부결정
```
- 1단계: 오토마톤을 시작 상태 `q0`로 초기화하고 입력 테이프의 첫 기호를 가리킴
- 2단계: 테이프에서 기호를 1개 읽어 전이 함수에 전달함
- 3단계: `delta(현재상태, 입력기호)`를 적용하여 다음 상태로 전이함(NFA는 복수 상태 가능)
- 4단계: 입력을 모두 소비한 뒤 현재 상태가 `F`에 포함되면 수리, 아니면 거부함

> 요약: 초기화 → 입력 읽기 → 전이 실행 → 수리 판정의 4단계로 문자열을 판정함

## Ⅳ. 문제점
- 상태 폭발: NFA를 DFA로 변환(부분집합 구성법) 시 상태 수가 최대 $2^n$으로 증가할 수 있음
- 표현력 한계: 유한 오토마톤은 정규 언어만 인식 가능하여, 괄호 짝 맞춤 등 문맥 자유 언어는 처리 불가함
- 최소화 비용: DFA 상태 최소화 알고리즘의 수행 시간이 상태 수에 비례하여 대규모 오토마톤에서 부담이 됨

> 요약: 상태 폭발·표현력 한계·최소화 비용이 실용적 제약임

## Ⅴ. 개선방안
1. 단기: 지연 평가 기반 DFA 구성으로 실제 도달 상태만 생성하여 상태 폭발을 완화함
2. 중기: 푸시다운 오토마톤(PDA)으로 확장하여 문맥 자유 언어까지 인식 범위를 넓힘 (024 참조)
3. 장기: 상태 최소화에 Hopcroft 알고리즘($O(n \log n)$)을 적용하여 대규모 DFA 처리 효율을 확보함

> 요약: 지연 구성 → PDA 확장 → 효율적 최소화 알고리즘으로 한계를 극복함

## Ⅵ. 전망
- 발전 방향: 네트워크 패킷 필터·정규 표현식 엔진에서 하드웨어 가속 DFA 적용이 확대되는 추세임
- 기술사적 판단: 형식 언어 이론의 기초로서 컴파일러·보안·텍스트 처리 전반에 지속 활용됨
- 기술사 제언: DFA/NFA 등가성과 펌핑 보조정리를 통해 문제의 계산 복잡도를 정확히 분류해야 함
