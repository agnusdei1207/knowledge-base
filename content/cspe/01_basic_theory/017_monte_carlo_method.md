## Ⅰ. 개요
- 난수(Random Number)를 이용한 반복적 시행으로 확률적 결과를 도출하는 기법임.
- 결정론적 해결이 어려운 복잡한 시스템의 근사치를 구할 때 유용함.
- [표] 출제 의도: 확률 기반 수치 해석 및 불확실성 모델링 이해도 검증.

## Ⅱ. 구성요소
- ASCII 구조도
  Inputs -> [ Random Samples ] -> [ Simulator ] -> Average Result

| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| Sampling | 모집단에서 무작위 표본을 추출함 | 여론 조사 대상 선정 |
| Probability | 각 사건이 발생할 확률 모델 | 주사위 던지기 |
| Aggregation | 반복 시행 결과를 평균하여 해를 도출 | 투표 결과 합산 |

> 요약: 시행 횟수가 늘어날수록 참값에 수렴하는 대수의 법칙을 이용함.

## Ⅲ. 절차
- ASCII 흐름도
  Input Distribution -> Gen Random -> Compute Value -> Aggregate

1. 문제의 입력 변수에 대한 확률 분포를 정의함.
2. 정의된 분포에 따라 대량의 난수 표본을 생성함.
3. 각 표본에 대해 수치적 연산 또는 시뮬레이션을 수행함.
4. 결과값들을 통계적으로 분석하여 최종 기대치를 산출함.

> 요약: 무작위성을 반복하여 복잡한 적분이나 기댓값을 추정함.

## Ⅳ. 문제점
- 정확한 근사치를 얻기 위해 막대한 횟수의 반복 시행이 요구됨.
- 난수 발생기의 품질에 따라 결과의 신뢰성이 좌우됨.

## Ⅴ. 개선방안
- 단기: 분산 감소 기법(Variance Reduction)으로 수렴 속도 향상함.
- 중기: 병렬 컴퓨팅 자원을 활용해 시행 횟수를 획기적으로 증대함.
- 장기: Quasi-Monte Carlo 등 고품질 난수 수열 기법 도입함.

## Ⅵ. 전망
- 양자 컴퓨터의 무작위성 측정을 이용한 '양자 몬테카를로(QMC)' 기술이 화학 및 신소재 시뮬레이션의 계산 한계를 극복하는 핵심 기술이 될 것임.
- 딥러닝 모델의 불확실성을 측정하기 위한 '몬테카를로 드롭아웃(MC Dropout)' 기법이 의료 AI 및 자율주행 분야의 안전성 보증을 위한 CSF로 자리 잡을 것임.
- 디지털 트윈 환경에서 현실의 불확실성을 반영한 확률적 시나리오 분석 엔진으로서 통계적 샘플링 기법의 중요성이 지속적으로 확대될 전망임.
