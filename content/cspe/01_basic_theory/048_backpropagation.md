## 미리 알고가기

- 순전파(Forward Propagation): 입력이 각 층을 지나 예측값과 손실을 계산하는 과정임
- 연쇄 법칙(Chain Rule): 합성함수의 미분을 각 함수 미분의 곱으로 계산하는 규칙임
- 기울기(Gradient): 손실이 파라미터 변화에 얼마나 민감한지 나타내는 미분값임
- 계산 그래프(Computational Graph): 연산과 데이터 흐름을 노드와 간선으로 표현한 구조임
- 자동 미분: 계산 그래프의 연산별 도함수를 연결해 함수의 미분값을 계산하는 방식임
- He 초기화: ReLU 계열에서 활성값과 기울기 분산을 유지하도록 가중치 분산을 정하는 방식임
- 기울기 클리핑: 기울기 크기를 임계값 이하로 제한해 폭주를 억제하는 방식임
- 기울기 노름: 전체 기울기 벡터의 크기임
- 활성화 함수(Sigmoid·ReLU): 각각 출력을 0~1로 압축하거나 음수 입력을 0으로 바꾸는 함수임
- 최적화기: 역전파로 계산한 기울기를 사용해 모델 파라미터를 갱신하는 알고리즘임

## 작성 근거(검토용)

- 역전파를 가중치 갱신 자체가 아니라 기울기 계산 절차로 정의해 경사하강법과 역할을 분리함
- 수치 미분과 자동 미분의 계산 방식·기울기 산출 범위·중간값 저장 부담을 비교함
- 계산 그래프와 국소 도함수는 연쇄 법칙 적용 구조를 설명하는 핵심 요소라 구성요소에 포함함
- 기울기 소실과 폭주는 역전파의 대표 실패 조건이라 사례에 반영함
- 결론은 미분 가능성과 기울기 안정성으로 정리해 앞 절의 구조와 연결함

## Ⅰ. 개요

- **정의/개념**: 역전파는 출력 손실 기울기를 연쇄 법칙으로 역전달해 파라미터 기울기를 구하는 알고리즘임
- **배경/필요성**: 다층 신경망의 가중치 기울기를 연쇄 법칙과 중간값 재사용으로 계산하기 위해 역전파가 필요함

## Ⅱ. 특징

- 순전파에서 저장한 중간값을 재사용해 한 번의 역방향 계산으로 모든 파라미터의 기울기를 구함
- 각 층의 국소 도함수에 출력 방향에서 전달된 기울기를 곱해 입력 방향으로 누적함
- Sigmoid 포화나 분산을 고려 안 한 가중치 초기화는 기울기 소실·폭주를 유발함
- 실제 가중치 갱신은 역전파가 계산한 기울기를 경사하강법 계열 최적화기가 사용해 수행함

## Ⅲ. 종류 및 비교

| 판단 기준 | 수치 미분 | 순방향 자동 미분 | 역방향 자동 미분(역전파) |
|:---|:---|:---|:---|
| 미분 메커니즘 | 입력 변화량 기반 근사 | 입력 방향 도함수 전파 | 출력 손실의 역방향 전파 |
| 계산 범위 | 파라미터별 반복 계산 | 입력 방향별 반복 전파 | 스칼라 손실의 전체 기울기 산출 |
| 주요 리스크 | 근사 오차 | 고차원 입력 계산 증가 | 계산 그래프 메모리 증가 |

> 요약: 손실값이 각 파라미터에 미치는 기울기는 출력층에서 입력층으로 한 번에 역전파로 계산함.

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 계산 그래프 | 순전파 연산의 의존 관계와 중간값을 나타낸 방향 그래프 |
| 손실 함수 | 모델 출력과 정답의 차이를 수치화하여 역방향 미분의 시작값을 제공하는 함수 |
| 국소 도함수 | 연산 노드별 미분값 |
| 오차 기울기 | 출력층에서 입력층으로 누적되는 미분 신호 |
| 파라미터 기울기 | 가중치·편향별 손실 편미분 |

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 입력      | --> | 은닉층    | --> | 출력      | --> | 손실      |
+-----------+     +-----------+     +-----------+     +-----------+
      ^                 ^                 ^                 |
      |                 |                 |                 v
      +----------- 기울기 역방향 전파 <----------------------+
```

> 요약: 역전파는 계산 그래프의 국소 도함수를 역순 결합해 파라미터별 손실 기울기를 산출함.

## Ⅴ. 원리 및 절차 흐름도

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 순전파    | --> | 손실 계산 | --> | 기울기 역전파 | --> | 기울기 산출 |
+-----------+     +-----------+     +-----------+     +-----------+
```

1. **순전파**: 입력을 각 층의 가중합과 활성화 함수에 통과시켜 예측값을 계산함
2. **손실 계산**: 예측값과 정답을 손실 함수에 넣어 오차를 수치화함
3. **기울기 역전파**: 손실을 출력부터 입력 방향으로 미분하고 각 층의 국소 도함수를 곱함
4. **기울기 산출**: 각 가중치와 편향의 손실 기울기를 최적화기에 전달함

> 요약: 역전파는 기울기를 계산하고 최적화기는 그 기울기로 파라미터를 갱신함.

## Ⅵ. 실무 사례

1. 비전 모델 학습은 ReLU·He 초기화를 적용하고 층별 기울기 분포로 소실을 확인함
2. 로그 시퀀스 예측은 기울기 클리핑을 적용하고 기울기 노름·검증 손실로 폭주를 확인함

## Ⅶ. 결론

- 역전파는 손실 기울기를 계산하므로 미분 가능성과 기울기 소실·폭주를 관리해야 함
