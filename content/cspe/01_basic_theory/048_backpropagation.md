## 미리 알고가기

- 연쇄 법칙($Chain$ $Rule$): 합성함수의 미분은 각 합성된 함수의 미분값들의 곱으로 나타낼 수 있다는 수학적 원리임
- 순전파($Forward$ $Propagation$): 입력 데이터를 신경망의 각 층을 통과시켜 최종 출력값(예측값)을 계산하는 과정임
- 손실 함수($Loss$ $Function$): 모델의 예측값과 실제 정답 사이의 오차를 수치화한 함수(예: $MSE, Cross-Entropy$)임
- 경사하강법($Gradient$ $Descent$): 손실 함수의 기울기(미분값)를 따라 가중치를 조금씩 업데이트하여 오차를 최소화하는 최적화 기법임

## Ⅰ. 개요

- **정의/개념**: 역전파 알고리즘은 출력층에서 발생한 오차를 신경망의 반대 방향(입력층 방향)으로 전파하며, 연쇄 법칙을 이용해 각 층의 가중치가 오차에 기여한 정도(기울기)를 효율적으로 계산하여 업데이트하는 학습 알고리즘임
- **배경/필요성**: 다층 신경망($MLP$)에서는 수많은 가중치가 복잡하게 얽혀 있어 각 가중치를 얼마나 수정해야 오차가 줄어들지 직접 알기 어렵기 때문에, 출력부터 입력까지 계층적으로 미분값을 전달하는 체계적인 방식이 필요함

## Ⅱ. 특징

- 신경망의 모든 파라미터에 대한 편미분($Partial$ $Derivative$) 값을 한 번의 순전파와 역전파 과정을 통해 효율적으로 구할 수 있어 대규모 네트워크 학습이 가능함
- 각 노드에서의 국소적 미분($Local$ $Gradient$)과 상위 층에서 넘어온 오차 미분값을 곱하는 방식이므로, 중복 계산을 피하고 메모리와 연산 자원을 절약함
- 층이 깊어질수록 미분값이 0에 수렴하여 앞쪽 층의 학습이 안 되는 '기울기 소실'이나, 반대로 너무 커지는 '기울기 폭주' 문제가 발생할 수 있음을 유의해야 함

## Ⅲ. 종류 및 비교

| 판단 기준 | 수치 미분 (Numerical) | 역전파 (Analytic) |
|:---|:---|:---|
| **계산 방식** | 미분 정의에 따른 근사치 계산 | 연쇄 법칙에 따른 해석적 미분 |
| **정확도** | 반올림 오차 등 발생 가능 | 수학적으로 정확한 값 |
| **계산 속도** | 파라미터 수에 비례하여 매우 느림 | 매우 빠름 (순전파와 유사) |
| **주요 용도** | 역전파 알고리즘의 무결성 검증 | 실제 딥러닝 모델의 가중치 학습 |

> 요약: 수치 미분은 검증용이고, 역전파는 실제 학습용으로 최적화된 고속 알고리즘임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 국소 도함수 | 각 노드의 활성화 함수나 연산이 입력에 대해 가지는 고유한 미분값임 |
| 오차 기울기 | 출력층의 손실값에서 시작하여 가중치 방향으로 전달되는 미분 신호임 |
| 가중치 갱신 | 계산된 기울기에 학습률($Learning$ $Rate$)을 곱하여 파라미터를 수정하는 단계임 |
| 계산 그래프 | 연산의 흐름을 노드와 엣지로 도식화하여 미분값의 전파 경로를 관리하는 구조임 |

```text
[ 역전파 연쇄 법칙 표현 ]
∂Loss / ∂w = (∂Loss / ∂out) * (∂out / ∂net) * (∂net / ∂w)
- 각 단계의 미분값들을 곱하여 최종 가중치에 대한 손실의 변화율을 구함
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 순전파/손실계산| --> | 출력층 오차측정| --> | 연쇄법칙 오차역전| --> | 가중치/편향 갱신|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **순방향 전파** — 입력 데이터를 가중치와 곱하고 활성화 함수를 통과시키며 마지막 출력층까지 값을 전달하고, 정답과의 차이인 손실($Loss$)을 계산함
2. **역방향 시작** — 손실 함수를 출력 노드에 대해 미분하여, 각 노드가 결과 오차에 미친 영향력의 초기값을 확보함
3. **기울기 전파** — 출력층부터 입력층 방향으로 한 층씩 거슬러 올라가며, 현재 층의 미분값과 상위 층에서 넘어온 기울기를 곱하여($Chain$ $Rule$) 모든 가중치의 기울기를 산출함
4. **파라미터 최적화** — 산출된 기울기 정보와 학습률을 결합하여 경사하강법 등으로 가중치를 업데이트하고, 오차가 최소화될 때까지 전체 과정을 반복함

## Ⅵ. 실무 적용 및 유의점

1. 딥러닝 모델 설계 시 활성화 함수로 시그모이드를 사용하면 역전파 과정에서 기울기가 0에 수렴하는 '기울기 소실'이 발생하므로, $ReLU$와 같은 함수를 사용하여 깊은 망에서도 신호가 잘 전달되도록 해야 함
2. 가중치의 초깃값이 모두 0이거나 동일하면 역전파 시 모든 뉴런이 같은 값을 학습하게 되어 신경망의 다채로운 특징 추출이 불가능해지므로, 'Xavier' 또는 'He' 초기화 기법을 적용하여 대칭성을 깨뜨려야 함

## Ⅶ. 결론

- 역전파는 인공지능이 스스로 오류를 교정하며 지식을 축적하게 만드는 학습의 심장이며, 설계자는 연쇄 법칙의 수학적 흐름과 하드웨어 초기화 전략을 정밀하게 제어하여 신경망의 안정적인 학습과 높은 예측력을 달성해야 함
