## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 출력 오차를 신경망 출력층에서 입력층 방향으로 역전달하여 가중치를 갱신하는 알고리즘임 |
| 배경/필요성 | 다층 퍼셉트론(MLP)에서 방대한 파라미터(가중치)를 효율적으로 최적화할 수학적 방법 필요 |
| 출제 의도 | 순전파 및 역전파 개념, 오차 미분과 연쇄 법칙을 활용한 가중치 업데이트 원리 이해 평가 |

## Ⅱ. 구성요소
```text
+----------------+       +----------------+       +----------------+
| Output Error   |       | Chain Rule     |       | Weight Update  |
| Calculation    | ----> | Differentiation| ----> | (Gradients)    |
+----------------+       +----------------+       +----------------+
```
| 오차 함수 | 실제 정답과 모델 예측값 간의 차이 (Loss) | 성적표 오답 수 |
| 연쇄 법칙 | 합성함수의 미분을 계산하기 위한 수학 법칙 (Chain Rule) | 도미노 쓰러지기 |
| 기울기 (Grad)| 오차가 각 가중치에 미치는 영향력(편미분값) | 방향 지시등 |
> 요약: 역전파는 오차 함수, 연쇄 법칙, 기울기로 구성되어 가중치 업데이트 방향을 산출함

## Ⅲ. 절차
```text
+----------------+       +----------------+       +----------------+       +----------------+
| Forward Pass   |       | Error Calc     |       | Backpropagate  |       | Weight Update  |
| (Predict Y)    | ----> | (Loss Func)    | ----> | (Chain Rule)   | ----> | (Gradient Dsc) |
+----------------+       +----------------+       +----------------+       +----------------+
```
1. 순전파: 입력 데이터가 계층을 통과하며 최종 예측값 도출
2. 오차 계산: 예측값과 실제 정답 간의 손실(Loss) 계산
3. 역전파: 연쇄 법칙을 적용해 출력층부터 입력층으로 각 가중치의 오차 기울기 산출
4. 업데이트: 경사하강법을 통해 기울기의 반대 방향으로 가중치 갱신
> 요약: 순전파 후 오차를 계산하고, 연쇄 법칙으로 역전달하여 가중치를 갱신함

## Ⅳ. 문제점
- 연산 비용 급증: 신경망 층이 깊어질수록 체인룰 곱셈 연산이 기하급수적으로 증가
- 기울기 소실 문제: 미분값이 누적 곱셈되어 얕은 층까지 오차가 전달되지 않음
- 기울기 폭발 현상: 가중치 값이 커 미분값이 폭증하여 가중치가 오버플로우됨

## Ⅴ. 개선방안
- 단기 방안: 효율적인 행렬 연산을 위한 GPU/TPU 하드웨어 가속기 활용
- 중기 방안: 활성화 함수로 ReLU 계열을 도입하여 기울기 소실 문제 예방
- 장기 방안: 가중치 초기화(He 등) 및 그래디언트 클리핑 적용으로 기울기 폭발 제어

## Ⅵ. 전망
- 스파이킹 신경망(SNN) 등 비미분성 모델을 위한 대안적 역전파 메커니즘 연구가 진행됨
