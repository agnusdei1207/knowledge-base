## 미리 알고가기

- **연쇄 법칙 (Chain Rule)**: 합성함수의 미분은 각 합성된 함수의 미분들의 곱으로 나타낼 수 있다는 수학적 규칙. 역전파의 계산적 근간임
- **경사 (Gradient)**: 각 파라미터가 변할 때 손실 함수가 얼마나 변하는지를 나타내는 미분값의 벡터. 오차가 줄어드는 방향을 가리킴
- **순전파 (Forward Propagation)**: 입력 데이터를 신경망의 각 층에 통과시켜 최종 예측값을 산출하고 손실(Loss)을 계산하는 과정

## Ⅰ. 개요

- **정의/개념**: 역전파(Backpropagation)는 인공 신경망에서 출력층의 오차를 입력층 방향으로 거꾸로 전파하며, 연쇄 법칙을 이용해 각 층의 가중치(Weight)와 편향(Bias)에 대한 손실 함수의 기울기(Gradient)를 효율적으로 계산하는 알고리즘임
- **배경/필요성**: 다층 신경망(Deep Neural Network)은 수백만 개 이상의 파라미터를 가짐. 모든 파라미터에 대해 개별적으로 미분을 수행하는 것은 계산량이 너무 방대함. 역전파는 한 번의 역방향 패스(Pass)를 통해 모든 가중치의 미분값을 동시에 계산함으로써, 복잡한 신경망을 실질적인 시간 내에 학습시킬 수 있는 길을 열었음

## Ⅱ. 특징 및 비교

### 가. 순전파와 역전파의 단계별 대비

| 구분 | 순전파 (Forward) | 역전파 (Backward) |
|:---|:---|:---|
| 데이터 방향 | 입력층 → 은닉층 → 출력층 | 출력층(오차) → 은닉층 → 입력층 |
| 주요 연산 | 행렬 곱, 활성화 함수 적용 | 미분, 연쇄 법칙 (Chain Rule) |
| 산출 결과 | 예측값($\hat{y}$), 손실(Loss) | 파라미터별 기울기(Gradient) |
| 메모리 활용 | 입력 데이터 유지 | 순전파 시 저장한 활성값 활용 |
| 주요 역할 | 추론 및 오차 측정 | 학습 및 파라미터 갱신 정보 생성 |

> 요약: 순전파가 '문제 풀이'라면, 역전파는 '오답 노트를 보고 책임 소재를 파악'하는 과정임

### 나. 역전파의 핵심 메커니즘
- **계산 그래프 (Computational Graph)**: 연산 과정을 그래프로 표현하여 국소적 미분(Local Gradient)을 조립함
- **기여도 분석**: 출력 오차에 대해 각 뉴런의 가중치가 얼마나 기여했는지를 미분값을 통해 수치화함
- **자동 미분 (Autograd)**: 현대의 프레임워크는 사용자가 미분식을 직접 쓰지 않아도 그래프를 따라 역전파를 자동 수행함

## Ⅲ. 구성요소/구조

### 가. 역전파의 계산 및 전달 구조

```text
[오차 발생] -> [출력층 미분] -> [은닉층 미분 전파] -> [가중치 기울기 합산]

1. 출력층 오차: 손실 함수(MSE 등)를 예측값에 대해 미분하여 시작 신호 생성
2. 연쇄 법칙 적용: (전체 오차 / 현재 출력) * (현재 출력 / 입력 가중치) 형태의 곱 연산 수행
3. Local Gradient: 각 노드는 '자신의 미분값'과 '뒤에서 넘어온 미분값'을 곱해 '앞으로' 전달
4. 가중치 갱신 준비: 계산된 최종 Gradient를 옵티마이저(Optimizer)에게 전달
```

### 나. 주요 구성 요소 및 역할

| 구성요소 | 역할 및 설명 | 핵심 포인트 |
|:---|:---|:---|
| 손실 함수 (Loss) | 정답과 예측의 차이를 수치화한 출발점 | 미분 가능한 함수여야 함 (예: Cross-Entropy) |
| 연쇄 법칙 (Chain Rule) | 복잡하게 얽힌 층간 미분을 곱으로 연결 | 역전파를 가능하게 하는 수학적 뼈대 |
| 가중치 (Weights) | 오차 전파 시 미분값이 곱해지는 대상 | 학습의 결과로 최적화되는 변수 |
| 활성화 함수 미분 | 층을 지날 때 신호의 감쇄/증폭을 결정 | ReLU, Sigmoid 등의 미분 특성이 중요 |

> 요약: 출력에서 발생한 오차라는 에너지가 거꾸로 흐르며 각 파라미터에 '반성할 양(Gradient)'을 할당함

## Ⅳ. 문제점 및 개선방안

1. **기울기 소실(Vanishing Gradient)**: 층이 깊어질수록 1보다 작은 미분값이 계속 곱해져 입력층 근처에서는 기울기가 0이 되어 학습이 안 됨
   - **개선방안**: ReLU 활성화 함수를 사용하여 양수 영역 미분을 1로 유지하거나, ResNet의 스킵 연결(Skip Connection)로 신호 통로를 확보함

2. **기울기 폭주(Exploding Gradient)**: 1보다 큰 미분값이 계속 곱해져 가중치가 무한대로 발산하여 학습이 파괴됨
   - **개선방안**: 가중치 초깃값을 적절히 설정(Xavier, He 초기화)하거나, 기울기의 크기를 일정 수준으로 제한하는 '기울기 클리핑(Gradient Clipping)'을 적용함

3. **메모리 오버헤드**: 역전파 계산을 위해 순전파 때의 모든 중간 활성값(Activation)을 메모리에 보관해야 함
   - **개선방안**: 필요할 때만 다시 계산하는 '체크포인팅(Checkpointing)' 기법을 쓰거나 배치 크기를 조절하여 메모리 효율성을 높임

## Ⅴ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| 심층 신경망 학습 | 대규모 파라미터의 최적화를 위해 표준 학습 알고리즘으로 채택 | Loss 감소 추이, Gradient Norm |
| 강화 학습 | 정책 네트워크와 가치 네트워크의 오차를 역전파하여 에이전트 행동 개선 | 에피소드 보상, 수렴 속도 |
| 생성 모델 (GAN) | 생성자와 판별자 사이의 오차 신호를 역전파하여 정교한 이미지 생성 | FID 스코어, 학습 안정성 |

> 요약: 딥러닝이라 불리는 모든 인공지능 기술의 '엔진' 역할을 수행하며 모델을 진화시킴

## Ⅵ. 결론

역전파 알고리즘은 다층 신경망이 '학습'이라는 것을 가능하게 만든 결정적인 한 수이자 현대 AI 혁명의 수학적 토대임. 복잡한 문제를 잘게 쪼개어 부분적인 미분의 곱으로 전체의 해답을 찾아가는 연쇄 법칙의 응용은 컴퓨터 과학사에서 가장 효율적인 알고리즘 중 하나로 평가받음.

기술사는 역전파의 단순한 계산 과정을 넘어, 기울기 소실과 폭주라는 물리적 한계를 어떻게 극복할 것인지(활성화 함수, 초기화, 정규화 등)에 대한 통합적인 시각을 갖추어야 함. 또한, 모델의 깊이가 깊어질수록 발생하는 역전파의 성능 저하 문제를 아키텍처 관점에서 해결할 수 있는 설계 역량이 요구됨.
