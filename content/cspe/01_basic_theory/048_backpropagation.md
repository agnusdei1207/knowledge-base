# 📖 【암기용】 개념 완전 이해

> 목적: 역전파 알고리즘을 처음 봐도 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 설명이다.

## 한눈에
- **개요**: 출력 오차를 뒤에서 앞으로 전달해 가중치 기울기를 계산하는 알고리즘
- **왜 필요한가**: 수백만 개 가중치를 하나씩 바꿔 손실 변화를 측정하면 계산량이 폭증함
- 체인룰로 모든 가중치 미분을 한 번의 그래프 순회로 계산해야 함
- **핵심 직관**: 최종 오답 책임을 각 층의 가중치에 비율대로 배분하는 회계 절차임.

## 깊이 이해
- **배경·문제의식**: 딥러닝 학습은 손실 L을 최소화하는 가중치 W를 찾는 문제임
- 역전파는 `∂L/∂W`를 자동 계산해 경사하강법 입력으로 제공함
- **작동 원리**: 순전파에서 z, a 값을 저장하고, 손실에서 시작한 미분값을 체인룰에 따라 출력층 -> 은닉층 -> 입력층 방향으로 전파함.
- **비유**: 생산 라인 불량 원인을 마지막 검사 결과에서 시작해 공정별 기여율로 거슬러 계산하는 방식임.
- **구체 예시**: 3층 MLP에서 손실 0.8이 발생하면 출력층 δ를 먼저 계산하고, 이전 층 δ는 `W^Tδ * f'(z)`로 산출함.
- **흔한 오해·주의점**: 역전파는 최적화 알고리즘이 아니라 기울기 계산 절차임
- 실제 가중치 갱신은 SGD, Adam 등 옵티마이저가 수행함

## 연결 개념
- 체인룰(Chain Rule) — 합성함수 미분의 수학적 기반
- 경사하강법(Gradient Descent) — 역전파 기울기로 파라미터 갱신
- 자동미분(Automatic Differentiation) — 계산 그래프 기반 역전파 구현

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 역전파는 손실 함수의 기울기를 체인룰로 출력층에서 입력층 방향으로 계산하는 알고리즘임.
> 2. **가치**: 수백만~수십억 파라미터의 미분을 계산 그래프 한 번의 역방향 순회로 산출함.
> 3. **판단 포인트**: 순전파 캐시, 국소 미분, Gradient Norm, 소실·폭주 여부를 함께 점검함.

---

## Ⅰ. 개요 및 필요성

- 정의: 역전파는 출력 오차로부터 각 가중치의 기울기를 계산하는 알고리즘임
- 배경: 신경망 학습은 손실을 줄이는 방향의 파라미터 갱신이 필요하며, 이를 위해 각 가중치의 손실 기여도를 계산해야 함
- 필요성: 역전파는 체인룰을 이용해 모든 층의 기울기를 재사용 구조로 산출함

---

## Ⅱ. 구조 및 구성요소

```text
입력층 -> 은닉층1 -> 은닉층2 -> 출력층 -> 손실 L
손실 L -> 출력층 기울기 -> 은닉층2 기울기 -> 은닉층1 기울기 -> 입력층 방향 전파
각 층 캐시(z,a,W) -> 국소 미분 -> 체인룰 결합 -> dW/db 산출
```

| 구성요소 | 역할 | 산출값 |
|:---|:---|:---|
| 순전파 캐시 | z, a, W 등 중간값 저장 | 역전파 입력 |
| 손실 함수 | 예측값과 정답의 오차 계산 | ∂L/∂y |
| 국소 미분 | 각 연산의 미분값 계산 | ∂z/∂W, f'(z) |
| 체인룰 결합 | 뒤쪽 기울기와 국소 미분 곱 | ∂L/∂W |

> 요약: 역전파는 순전파 중간값과 국소 미분을 체인룰로 결합해 각 파라미터의 기울기를 계산함.

---

## Ⅲ. 동작원리 및 흐름도

```text
순전파 계산 -> 손실 산출 -> 출력층 δ 계산
      -> 은닉층 δ 전파 -> ∂W, ∂b 계산 -> Optimizer 갱신
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 입력부터 출력까지 순전파 수행 | Activation·Logit 차원 일치 |
| 2 | 손실 L 계산 | Cross-Entropy, MSE |
| 3 | 출력층 오차 δ 산출 | ∂L/∂z 값 확인 |
| 4 | 체인룰로 은닉층 기울기 계산 | Gradient Norm 1e-6~1e2 범위 점검 |
| 5 | 옵티마이저에 기울기 전달 | Loss 감소 추세 확인 |

> 요약: 역전파는 손실에서 시작한 기울기를 층별 국소 미분과 곱해 가중치 갱신 방향을 제공함.

---

## Ⅳ. 특징

| 구분 | 수치미분 | 역전파 | 수치 판단 |
|:---|:---|:---|:---|
| 계산 방식 | 파라미터별 미소 변화 측정 | 계산 그래프 역방향 순회 | Forward/Backward 시간 |
| 계산량 | 파라미터 N개면 O(N)회 평가 | 순전파와 같은 차수 | GPU 메모리 사용량 |
| 활용 | Gradient Check | 실제 학습 | 상대오차 1e-7 이하 |

> 요약: 실제 학습은 역전파를 사용하고, 수치미분은 구현 검증용 Gradient Check에 제한적으로 사용함.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존·대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | 수치미분으로 파라미터별 변화 측정 | 계산 그래프 역방향 순회 | 파라미터 N개 학습은 역전파 선택 |
| 비용/성능 | N개 파라미터별 N회 이상 평가 | Forward 대비 1~2배 수준 Backward | Gradient Check는 샘플·소형 모델 한정 |
| 운영/위험 | 기울기 계산과 갱신 혼동 | 역전파는 미분, Adam/SGD는 갱신 | 답안에서 역할 분리 서술 |

> 요약: 역전파는 대규모 파라미터의 미분 계산 정본이며 수치미분은 검증 목적으로 제한함.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 소실 기울기 | Sigmoid 포화, 깊은 체인룰 곱 | ReLU/GELU, Residual, LayerNorm 적용 | Gradient Norm 1e-6 이상 |
| 폭주 기울기 | 큰 가중치, 긴 시퀀스 누적 | Gradient Clipping 1.0, 초기화 조정 | Gradient Norm 1e2 이하 |
| 메모리 초과 | 순전파 Activation 캐시 누적 | Activation Checkpointing, Mixed Precision | GPU OOM 0건, 메모리 30~50% 절감 |

> 요약: 역전파 운영 위험은 기울기 범위와 Activation 메모리이며 Norm·OOM 로그로 통제함.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 미분 정확도 | Gradient Check 상대오차 1e-7~1e-5 | 소형 배치 수치미분 비교 |
| 학습 품질 | Loss NaN/Inf 0건, 검증 손실 감소 추세 | 학습 로그, 검증 곡선 |
| 운영/보안 | 실험 seed·데이터셋 해시·모델 버전 기록 | MLflow/W&B, 감사로그 |

> 요약: 도입 후에는 미분 정확도, 손실 추세, 실험 재현성 로그를 함께 확인함.

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 구현 검증: 작은 배치에서 수치미분 대비 상대오차 1e-7~1e-5 범위로 Gradient Check 수행
2. 학습 진단: Gradient Norm, NaN/Inf, Vanishing(<1e-6)·Exploding(>1e2) 조건을 로깅
3. 자원 관리: Activation Checkpointing으로 메모리 사용량을 30~50% 절감하되 재계산 시간 증가를 측정

**결론 (2줄):**
- 기술사 판단: 역전파는 미분 계산, 옵티마이저는 갱신 수행이므로 두 역할을 분리해 설명해야 함
- 향후 방향: 대규모 모델은 자동미분, 혼합정밀도, 체크포인팅을 결합해 학습 비용을 통제함
