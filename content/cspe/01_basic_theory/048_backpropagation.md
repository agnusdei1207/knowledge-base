## 미리 알고가기

- 순전파($Forward$ Propagation): 입력이 각 층을 지나 예측값과 손실을 계산하는 과정임
- 연쇄 법칙($Chain$ Rule): 합성함수의 미분을 각 함수 미분의 곱으로 계산하는 규칙임
- 기울기($Gradient$): 손실이 파라미터 변화에 얼마나 민감한지 나타내는 미분값임
- 계산 그래프($Computational$ Graph): 연산과 데이터 흐름을 노드와 간선으로 표현한 구조임
- 학습률($Learning$ Rate): 기울기 방향으로 파라미터를 얼마나 이동할지 정하는 보폭임

## 작성 근거(검토용)

- 역전파를 가중치 갱신 자체가 아니라 기울기 계산 절차로 정의해 경사하강법과 역할을 분리함
- 수치 미분과 자동 미분을 비교해 계산 비용·정확도·구현 관점의 차이를 드러냄
- 계산 그래프와 국소 도함수는 연쇄 법칙 적용 구조를 설명하는 핵심 요소라 구성요소에 포함함
- 기울기 소실과 폭주는 역전파의 대표 실패 조건이라 사례에 반영함
- 결론은 미분 가능성과 기울기 안정성으로 정리해 앞 절의 구조와 연결함

## Ⅰ. 개요

- **정의/개념**: 역전파는 출력층 손실에서 시작한 기울기를 연쇄 법칙으로 입력층 방향으로 전달해 각 파라미터의 손실 기울기를 계산하는 알고리즘임
- **배경/필요성**: 다층 신경망의 가중치를 효율적으로 갱신하기 위해 계층적 미분 전파가 필요함

## Ⅱ. 특징

- 순전파에서 저장한 중간값을 재사용해 모든 파라미터의 기울기를 한 번에 계산함
- 각 층은 자신의 국소 도함수와 상위 층 기울기만 알면 되므로 깊은 네트워크에 적용 가능함
- 활성화 함수와 가중치 초기화가 부적절하면 기울기 소실이나 폭주가 발생함
- 실제 가중치 갱신은 역전파가 계산한 기울기를 경사하강법 계열 최적화기가 사용해 수행함

## Ⅲ. 종류 및 비교

| 기준 | 수치 미분 | 순방향 자동 미분 | 역방향 자동 미분(역전파) |
|:---|:---|:---|:---|
| 계산 방식 | 작은 변화량으로 근사 | 입력 방향으로 도함수 전파 | 출력 손실에서 역방향 전파 |
| 적합 조건 | 소규모 기울기 검증 | 입력 수가 적은 함수 | 출력이 스칼라인 다변수 모델 |
| 정확도 | 근사·반올림 오차 존재 | 부동소수점 정밀도 내 정확 | 부동소수점 정밀도 내 정확 |
| 주요 용도 | 구현 검증 | 민감도 계산 | 신경망 학습 |
| 유의점 | 파라미터별 반복 비용 | 입력 방향마다 재계산 | 중간값 저장 메모리 필요 |

> 요약: 스칼라 손실과 다수 파라미터의 기울기는 역방향 자동 미분인 역전파가 효율적임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 계산 그래프 | 순전파 연산 순서를 저장해 역방향 기울기 경로를 제공함 |
| 손실 함수 | 예측값과 정답의 차이를 수치화해 역전파의 시작점을 만듦 |
| 국소 도함수 | 각 연산 노드가 입력 변화에 반응하는 미분값임 |
| 오차 기울기 | 출력층에서 입력층 방향으로 전달되는 누적 미분 신호임 |
| 최적화기 | 계산된 기울기와 학습률을 사용해 가중치와 편향을 갱신함 |

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 입력      | --> | 은닉층    | --> | 출력      | --> | 손실      |
+-----------+     +-----------+     +-----------+     +-----------+
      ^                 ^                 ^                 |
      |                 |                 |                 v
      +----------- 기울기 역방향 전파 <----------------------+
```

> 요약: 역전파는 순전파 중간값을 따라 손실 기울기를 출력층에서 입력층으로 되돌림.

## Ⅴ. 원리 및 절차 흐름도

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 순전파    | --> | 손실 계산 | --> | 기울기 역전파 | --> | 파라미터 갱신 |
+-----------+     +-----------+     +-----------+     +-----------+
```

1. **순전파** — 입력을 각 층의 가중합과 활성화 함수에 통과시켜 예측값을 계산함
2. **손실 계산** — 예측값과 정답을 손실 함수에 넣어 오차를 수치화함
3. **기울기 역전파** — 손실을 출력부터 입력 방향으로 미분하고 각 층의 국소 도함수를 곱함
4. **파라미터 갱신** — 산출된 기울기를 최적화기에 전달해 가중치와 편향을 수정함

> 요약: 역전파는 기울기를 계산하고 최적화기는 그 기울기로 파라미터를 갱신함.

## Ⅵ. 실무 사례

1. 깊은 신경망에서는 Sigmoid 포화로 기울기 소실 위험이 커지므로 ReLU 계열·적절한 초기화·배치 정규화를 적용하고 층별 기울기 분포를 확인함
2. 순환 신경망처럼 긴 의존성을 학습할 때 기울기 폭주가 발생하면 기울기 클리핑을 적용하고 손실 급등과 가중치 노름을 함께 감시함

## Ⅶ. 결론

- 역전파는 손실의 책임을 각 파라미터에 배분하는 절차이므로 미분 가능성·기울기 안정성·최적화기 연결을 함께 관리해야 함
