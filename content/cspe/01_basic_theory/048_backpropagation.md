## 미리 알고가기

- 순전파: 입력이 층을 통과해 예측값과 손실을 계산하는 과정임
- 손실 함수: 예측값과 실제값의 차이를 수치화해 최적화 목표로 사용하는 함수임
- 기울기: 손실을 줄이기 위해 각 가중치를 얼마나 바꿔야 하는지 나타내는 변화율임
- 연쇄 법칙: 합성 함수의 미분을 단계별 미분의 곱으로 계산하는 규칙임
- 옵티마이저: 계산된 기울기를 사용해 가중치를 갱신하는 알고리즘임

## Ⅰ. 개요

- **정의**: 역전파는 신경망의 출력 손실을 마지막 층에서 입력층 방향으로 전달하며 연쇄 법칙으로 각 파라미터의 기울기를 계산해 가중치 갱신에 사용하는 학습 알고리즘임
- **배경/필요성**: 다층 신경망은 파라미터가 많아 모든 가중치의 영향을 직접 계산하기 어렵기 때문에, 계산 그래프를 따라 효율적으로 미분을 재사용하는 방법이 필요함
- **비유**: 최종 채점 결과를 보고 마지막 풀이부터 처음 풀이까지 어느 단계에서 얼마나 틀렸는지 거꾸로 확인하는 것과 같음

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 신경망 학습 원리 | 순전파, 손실, 연쇄 법칙, 기울기 | 단순 오차 전달로만 설명 |
| 최적화 연결 | 가중치 갱신, 학습률, 옵티마이저 | 기울기 소실·폭발 누락 |

> 요약: 역전파는 손실이 각 가중치에 미친 영향을 효율적으로 계산해 신경망이 스스로 파라미터를 조정하게 하는 절차임.

## Ⅱ. 특징/비교

| 판단 기준 | 수치 미분·직접 계산 | 역전파 |
|:---|:---|:---|
| 계산 방식 | 파라미터마다 손실 변화를 따로 계산해 비용이 큼 | 중간 미분값을 재사용해 한 번의 역방향 통과로 계산함 |
| 적용 범위 | 작은 함수 검증에는 가능하지만 대규모 신경망에는 비효율적임 | 다층 신경망과 자동미분 프레임워크의 기본 학습 방식임 |
| 정확도·효율 | 근사 오차와 계산량 문제가 큼 | 해석적 미분 기반으로 효율과 정확도를 확보함 |
| 선택 조건 | 기울기 검증이나 교육용 예시에 적합함 | 실제 모델 학습과 대규모 파라미터 최적화에 적합함 |

> 요약: 역전파는 다층 신경망의 대규모 파라미터 기울기를 실용적으로 계산하기 위해 선택하는 방법임.

- **입력 조건**: 계산 그래프가 미분 가능하고 손실이 스칼라 목표로 정의되어야 함
- **평가 기준**: 기울기 존재 여부와 크기, 손실 감소 추세를 함께 확인함
- **선택 판단**: 다층 모델의 파라미터별 영향도를 효율적으로 구해야 할 때 사용함

## Ⅲ. 구성요소

```text
+------------+      +------------+      +------------+
| 순전파 값   | ---> | 손실 함수   | ---> | 역방향 기울기 |
+------------+      +------------+      +------------+
       |                  |                  |
       v                  v                  v
+------------+      +------------+      +------------+
| 계산 그래프 |      | 연쇄 법칙   |      | 가중치 갱신 |
+------------+      +------------+      +------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 계산 그래프 | 연산과 변수의 의존 관계를 저장해 미분 경로를 제공함 | 풀이 과정 기록지 |
| 순전파 값 | 각 층의 입력, 출력, 활성화 값을 저장해 역전파 계산에 재사용함 | 중간 계산 메모 |
| 손실 함수 | 최종 예측 오류를 하나의 스칼라 목표로 표현함 | 최종 점수 |
| 연쇄 법칙 | 층별 국소 미분을 곱해 각 파라미터의 전체 영향도를 계산함 | 책임 배분 규칙 |
| 옵티마이저 | 계산된 기울기와 학습률로 파라미터를 갱신함 | 수정 지시서 |

> 요약: 역전파는 순전파 중간값과 계산 그래프를 이용해 손실의 책임을 각 파라미터에 배분하는 구조임.

## Ⅳ. 절차

```text
+------------+      +------------+      +------------+      +------------+
| 순전파     | ---> | 손실 계산   | ---> | 기울기 전파 | ---> | 가중치 갱신 |
+------------+      +------------+      +------------+      +------------+
```

1. **순전파 수행**: 입력을 각 층에 통과시키며 예측값과 중간 활성화 값을 저장함
2. **손실 계산**: 예측값과 정답을 비교해 최적화할 스칼라 손실을 산출함
3. **역방향 미분**: 출력층부터 입력층까지 연쇄 법칙으로 파라미터별 기울기를 계산함
4. **가중치 갱신**: SGD, Adam 등 옵티마이저가 학습률과 기울기를 사용해 파라미터를 수정함

> 요약: 역전파 절차는 순전파로 계산한 손실을 역방향 미분으로 각 가중치 갱신량에 연결하는 흐름임.

- **산출물**: 파라미터별 gradient, 손실 곡선, 갱신된 가중치임
- **검증 기준**: 주요 파라미터에 gradient가 존재하고 NaN·Inf가 없어야 함
- **운영 기록**: 모델 그래프, 손실 함수, optimizer 설정을 실험 로그로 관리해야 함

## Ⅴ. 문제점

- **P1 기울기 소실·폭발**: 깊은 네트워크에서 작은 미분값이나 큰 미분값이 반복 곱해져 앞 층 학습이 멈추거나 불안정해질 수 있음
- **P2 계산 그래프 오류**: 텐서 shape, detach, in-place 연산, 비미분 연산이 섞이면 의도한 경로로 기울기가 전달되지 않음
- **P3 최적화 불안정**: 학습률, 초기화, 배치 구성에 따라 손실이 진동하거나 수렴하지 않을 수 있음

> 요약: 역전파는 수학적 절차가 명확해도 기울기 흐름과 구현 경로가 깨지면 학습이 실패함.

## Ⅵ. 개선방안

- **P1 대응**: 적절한 활성화 함수, Xavier/He 초기화, 정규화, gradient clipping을 적용함 (확인: 층별 기울기 norm)
- **P2 대응**: 자동미분 그래프를 점검하고 gradient check, shape 테스트, 단위 테스트를 수행함 (확인: 파라미터별 gradient 존재 여부)
- **P3 대응**: 학습률 스케줄링, Adam 계열 옵티마이저, 배치 크기 조정, warm-up을 적용함 (확인: 손실 곡선 안정성)

> 요약: 역전파 개선은 기울기 값의 크기와 전달 경로를 관측하고 최적화 설정을 안정화하는 것임.

- **우선순위**: gradient 흐름과 학습률 안정성을 먼저 점검함
- **확인 지표**: gradient norm, loss curve, parameter update ratio를 함께 사용함
- **재평가 조건**: 모델 깊이, 활성화 함수, optimizer가 바뀌면 gradient 흐름을 다시 확인함

## Ⅶ. 전망

- **발전 방향**: 역전파는 자동미분, 분산 학습, 체크포인팅, 저정밀 학습과 결합해 대규모 모델 학습 비용을 줄이는 핵심 알고리즘으로 유지됨
- **설계 관점**: 모델 깊이, 활성화 함수, 초기화, optimizer, 메모리 제약을 함께 고려해 기울기 전달 경로와 학습 전략을 설계해야 함
- **검증 관점**: gradient norm, loss curve, parameter update ratio, gradient check를 사용해 미분 경로와 계산 그래프가 의도대로 동작하는지 확인해야 함
- **운영 관점**: 학습 코드 변경, mixed precision 적용, 분산 학습 전환 시 손실 발산과 파라미터 갱신 비율을 실험 로그로 관리해야 함
- **적용 관점**: 딥러닝 학습의 표준 방식이지만 비미분 연산, 메모리 한계, 장기 의존 구조가 강한 문제에서는 보완 기법을 함께 적용해야 함
- **보안·신뢰 관점**: shape 오류, detach, in-place 연산, 비정상 입력이 기울기를 끊을 수 있으므로 단위 테스트와 경계 입력 테스트로 학습 신뢰성을 확보해야 함
- **기술사 제언**: 역전파는 수식 전개보다 기울기 흐름, 구현 그래프, 손실 안정성을 검증 가능한 운영 지표로 설명하는 것이 중요함
