## Ⅰ. 개요
- **정의**: 모델의 예측값과 실제 정답 간의 차이(오차)를 수치화하여 모델의 성능을 평가하는 함수임.
- **배경/필요성**: 신경망이 '얼마나 틀렸는지'를 정의해야 역전파를 통해 학습(가중치 갱신)할 수 있으므로 필수적임.
- **출제 의도**: 회귀용(MSE)과 분류용(Cross-Entropy) 손실 함수의 수식적 차이와 적절한 적용 상황을 구분하는지 평가함.

## Ⅱ. 구성요소
```text
+------------------+       +------------------+       +------------------+
| Model Prediction | ----> | Loss Function    | ----> | Error Scalar     |
| (y_hat)          |       | (MSE or CE)      |       | (Loss Value)     |
+------------------+       +------------------+       +------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 예측값 (y_hat) | 모델이 입력 데이터를 바탕으로 추론한 결과 | 학생의 답안 |
| 실제값 (y) | 데이터셋에 레이블링된 실제 정답 | 정답지 |
| 손실 값 (Loss) | 예측과 실제의 차이를 계산한 스칼라 값 | 오답에 대한 벌점 |

> 요약: 예측값과 실제값을 비교하여 모델이 최소화해야 할 오차 지표(Loss)를 제공함.

## Ⅲ. 절차
```text
+-------------+   +-------------+   +-------------+   +-------------+
| 1. 예측값   |-->| 2. 문제유형 |-->| 3. 손실     |-->| 4. 오차     |
|    출력     |   |    판단     |   |    계산     |   |    역전파   |
+-------------+   +-------------+   +-------------+   +-------------+
```
1. **예측값 출력**: 네트워크의 순전파를 통해 예측값을 얻음.
2. **문제유형 판단**: 과제가 연속값 예측(회귀)인지 카테고리 분류(분류)인지 식별함.
3. **손실 계산**: 회귀면 MSE, 분류면 Cross-Entropy 공식을 적용해 Loss를 산출함.
4. **오차 역전파**: 도출된 Loss 값을 기반으로 신경망에 역전파를 수행하여 업데이트함.

> 요약: 예측과 정답을 함수에 입력하여 Loss를 구하고 이를 역전파의 출발점으로 사용함.

## Ⅳ. 문제점
- **이상치 민감도(MSE)**: 제곱을 하므로 이상치의 오차값이 과도하게 커져 전체 손실이 왜곡됨.
- **클래스 불균형(CE)**: 다수 클래스의 쉬운 예제들이 Loss를 지배하여 소수 클래스 학습이 저해됨.

## Ⅴ. 개선방안
- **이상치 민감도**: (단기) 오차가 클 땐 선형인 Huber Loss로 대체 / (장기) 데이터 정제 고도화 필요.
- **클래스 불균형**: (단기) 클래스 가중치 부여 / (장기) 어려운 예제에 집중하는 Focal Loss 기법 도입 필요.

## Ⅵ. 전망
- 단순 오차 측정을 넘어, 자가지도 학습(Contrastive Loss) 등 복합 손실 함수 설계가 중요해지고 있음.
