## Ⅰ. 개요
- **정의**: 문제의 계산 복잡도를 다항식 시간 해결 가능성과 검증 가능성 기준으로 분류하는 복잡도 클래스 체계
- **배경/필요성**: 알고리즘 존재 여부와 효율적 풀이 한계를 판별해야 자원 배분과 근사 전략 수립이 가능함
- **비유**: P는 직접 풀 수 있는 시험 문제, NP는 답안지를 보면 맞는지 확인할 수 있는 문제, NPC는 그중 가장 어려운 대표 문제에 해당함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 복잡도 클래스 간 포함 관계와 환원 개념 이해 | P ⊆ NP, NPC 정의(NP이면서 모든 NP를 다항 환원 가능) | NP를 "풀 수 없는 문제"로 오해하지 말 것 — NP는 검증이 다항 시간인 클래스 |

> 요약: P·NP·NPC는 문제 풀이·검증·환원 가능성에 따른 복잡도 분류 체계임

## Ⅱ. 구성요소
```text
              +--- NP -------------------+
              |                          |
              |   +--- NPC ---+          |
              |   | SAT, TSP  |          |
              |   | 3-SAT ... |          |
              |   +-----------+          |
              |                          |
              |   +--- P -------+        |
              |   | 정렬, 최단경로|        |
              |   +-------------+        |
              +--------------------------+
              (P = NP ? 미해결)
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| P 클래스 | 결정적 튜링 머신에서 다항식 시간 O(n^k) 내에 해를 구할 수 있는 문제 집합 | 계산기로 바로 답을 구할 수 있는 문제 |
| NP 클래스 | 비결정적 튜링 머신에서 다항식 시간에 풀거나, 주어진 해를 다항식 시간에 검증 가능한 문제 집합 | 답을 보여주면 맞는지 빠르게 채점 가능한 문제 |
| NP-Complete | NP에 속하면서 모든 NP 문제가 다항 시간에 환원(reduce) 가능한 문제 | 이 문제 하나를 풀면 나머지 모든 NP 문제도 풀리는 대표 문제 |
| NP-Hard | 모든 NP 문제가 환원 가능하지만 자신은 NP에 속하지 않을 수도 있는 문제 | NPC보다 같거나 더 어려운 상위 난이도 범주 |

> 요약: P ⊆ NP 관계 위에서 NPC는 NP의 가장 어려운 부분집합, NP-Hard는 NP 이상의 난이도를 포괄함

## Ⅲ. 절차
```text
  문제 정의        NP 증명         환원 구성        NPC 판정
  (입력 형식화)   (검증기 제시)   (기존 NPC->신규) (결론 도출)
    |               |               |               |
    +--결정문제화-->+--다항검증기-->+--다항환원증명->+
  판정 문제로 변환  해 검증 O(n^k)  SAT등에서 변환   NPC 확정
```
- 1단계: 대상 문제를 "예/아니오"로 답하는 결정 문제(decision problem)로 형식화함
- 2단계: 주어진 해(certificate)를 다항식 시간에 검증하는 검증기를 제시하여 NP 소속을 증명함
- 3단계: 이미 NPC로 알려진 문제(예: SAT)를 다항 시간에 신규 문제로 환원하는 변환 함수를 구성함
- 4단계: NP 소속과 다항 환원이 모두 성립하면 해당 문제를 NP-Complete로 판정함

> 요약: 결정 문제화 → NP 증명 → 다항 환원 구성 → NPC 판정의 4단계로 복잡도를 분류함

## Ⅳ. 문제점
- P=NP 미해결: 두 클래스의 동치 여부가 증명되지 않아 NPC 문제의 다항 풀이 존재 여부를 확정할 수 없음
- 환원 구성 난이도: 문제 간 다항 환원을 설계하려면 두 문제의 구조적 대응을 정밀하게 파악해야 하므로 전문성이 요구됨
- 실용 괴리: 이론적 최악 복잡도와 실제 인스턴스 난이도 사이에 괴리가 있어, NPC 문제도 현실 입력에서는 빠르게 풀리는 경우가 존재함

> 요약: P=NP 미해결·환원 설계 난이도·이론과 실용 간 괴리가 주요 한계임

## Ⅴ. 개선방안
1. 단기: 근사 알고리즘(approximation)으로 최적해의 일정 비율 이내 해를 다항 시간에 산출함
2. 중기: 파라미터화 복잡도(FPT) 분석으로 입력의 특정 파라미터가 작을 때 다항 시간 풀이를 도출함
3. 장기: 양자 컴퓨팅 등 새로운 계산 모델 적용으로 특정 NP 문제 클래스의 탐색 공간을 구조적으로 축소함

> 요약: 근사·파라미터화·새 계산 모델로 NPC 문제의 실용적 풀이 가능 범위를 확장함

## Ⅵ. 전망
- 발전 방향: SAT 솔버 성능 향상과 양자 알고리즘 연구로 NPC 문제의 실질적 풀이 범위가 지속 확대될 전망
- 기술사적 판단: 알고리즘 한계 판별과 설계 전략 수립의 이론적 토대로서 출제 빈도가 높은 핵심 주제
- 기술사 제언: NP와 NP-Hard의 정확한 구분, 환원의 방향성(기존 NPC → 신규 문제)을 명확히 서술할 필요
