## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 실수를 부호(Sign)·지수(Exponent)·가수(Mantissa) 3개 필드로 분리하여 이진 표현하는 IEEE 국제 표준 부동소수점 규격임 |
| **배경/필요성** | 정수만으로는 실수 연산이 불가하며, 넓은 범위의 실수를 유한 비트로 표현하는 표준이 필요함 |
| **출제 의도** | 단정밀도(32비트)·배정밀도(64비트)의 구조와 정밀도 손실·특수값을 이해하는지 평가함 |

## Ⅱ. 구성요소
```
+----------+     +----------+     +----------+
| 부호(S)  | --> | 지수(E)  | --> | 가수(M)  |
| 1비트    |     | 8/11비트  |     | 23/52비트 |
+----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| 부호(S) | 0이면 양수, 1이면 음수를 나타내는 1비트 필드임 | +/− 부호 |
| 지수(E) | 바이어스(127/1023)를 더한 지수값으로, 수의 크기 범위를 결정함 | 과학적 표기의 10의 지수 |
| 가수(M) | 정규화된 `1.xxx...`의 소수 부분으로, 유효 자릿수(정밀도)를 결정함 | 유효숫자 |

> 요약: 값 = (-1)^S × 1.M × 2^(E-Bias)로, 부호·지수·가수 3필드로 실수를 표현함.

## Ⅲ. 절차
```
+------------+     +------------+
| 10진→2진   | --> | 정규화     |
| 실수변환   |     | 1.xxx형태  |
+------------+     +------------+
                        |
+------------+     +----+-------+
| 비트패킹   | <-- | 바이어스  |
| S|E|M      |     | 지수계산   |
+------------+     +------------+
```

1. 10진→2진 변환: 정수부는 나눗셈, 소수부는 곱셈으로 2진수를 구함
2. 정규화: `1.xxx × 2^n` 형태로 소수점을 이동하여 정규화함
3. 바이어스 지수 계산: 실제 지수 n에 바이어스(127/1023)를 더하여 E 필드를 산출함
4. 비트 패킹: S(1비트) | E(8/11비트) | M(23/52비트)을 연결하여 최종 비트열을 구성함

> 요약: 2진 변환 → 정규화 → 바이어스 지수 → 비트 패킹으로 IEEE 754 표현을 완성함.

## Ⅳ. 문제점
- 정밀도 손실: 유한 가수 비트로 인해 `0.1`을 정확히 표현할 수 없어 오차가 누적됨
- 특수값 처리: NaN·±Infinity·비정규화 수(Denormalized) 등 예외 처리가 필요함
- 비교 오류: 부동소수점 == 비교가 오차로 인해 기대와 다른 결과를 반환함

## Ⅴ. 개선방안
- (단기) 엡실론 비교: `|a - b| < ε` 방식으로 부동소수점 동치를 판별함
- (중기) 배정밀도·확장 정밀도: 64비트·128비트로 유효 자릿수를 확대하여 오차를 줄임
- (장기) Posit 수 체계: IEEE 754의 정밀도 분포 편향을 개선한 차세대 수 표현을 적용함

## Ⅵ. 전망
- AI 학습에서 FP16·BFloat16·FP8 등 저정밀 부동소수점이 확산되며, 연산 속도와 정밀도의 트레이드오프를 최적화하는 혼합 정밀도(Mixed Precision) 연산이 표준이 될 전망임
