## 미리 알고가기

- 부동소수점: 소수점 위치를 지수로 분리해 넓은 범위의 실수를 근사 표현하는 방식임
- 정규화: 유효숫자를 $1.x$ 형태로 맞추고 소수점 이동량을 지수로 저장하는 과정임
- 부호 비트: 양수와 음수를 구분하는 최상위 비트임
- 지수부: 소수점 이동량을 바이어스 값을 더해 저장하는 영역임
- 가수부: 정규화된 유효숫자의 소수 부분을 저장하는 영역임
- 특수값: 0, 무한대, NaN처럼 일반 정규화 수와 다르게 해석되는 값임

## Ⅰ. 개요

- **정의/개념**: IEEE 754 부동소수점은 실수를 부호, 지수, 가수로 나누어 제한된 비트 안에서 매우 작은 값부터 큰 값까지 근사 표현하는 표준 형식임
- **배경/필요성**: 과학 계산, 그래픽, 인공지능 연산은 값의 범위가 넓어 고정소수점만으로는 표현 범위와 저장 효율을 동시에 맞추기 어려움

## Ⅱ. 특징

- 지수를 분리해 같은 비트 수로 고정소수점보다 훨씬 넓은 범위를 표현함
- 10진 소수는 2진수에서 무한 반복되어 대부분의 실수 연산은 근사값을 사용함
- 반올림 모드, 오버플로, 언더플로, NaN을 표준화해 플랫폼 간 해석 차이를 줄임
- 정밀도와 범위는 비트 수에 비례하지만 메모리 사용량과 연산 비용도 함께 증가함

## Ⅲ. 종류 및 비교

| 형식 | 전체 비트 | 지수부 | 가수부 | 주요 활용 |
|:---|:---|:---|:---|:---|
| Half precision | 16 | 5 | 10 | 그래픽, 저정밀 추론 |
| Single precision | 32 | 8 | 23 | 일반 과학 계산, GPU 연산 |
| Double precision | 64 | 11 | 52 | 고정밀 시뮬레이션, 금융 검증 |
| Quad precision | 128 | 15 | 112 | 수치해석 검증, 고정밀 연구 |

> 요약: 비트 수가 커질수록 정밀도와 범위가 늘지만 저장 공간과 처리 비용도 증가함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 부호부 | 1비트로 양수와 음수를 구분해 최종 값의 방향을 정함 |
| 지수부 | 실제 지수에 바이어스를 더해 저장하며 표현 범위를 결정함 |
| 가수부 | 정규화된 유효숫자의 소수 부분을 저장해 정밀도를 결정함 |
| 반올림 규칙 | 저장 가능한 비트를 넘는 값을 표준 방식으로 근사함 |
| 예외 값 | 0, 비정규 수, 무한대, NaN을 별도 패턴으로 표현함 |

```text
+------+--------------+-----------------------+
| Sign | Exponent     | Fraction              |
+------+--------------+-----------------------+
  1 bit   range bits     precision bits
```

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| Convert   | --> | Normalize | --> | Encode    | --> | Assemble |
+----------+     +----------+     +----------+     +----------+
```

1. **이진 변환**: 입력 실수의 정수부와 소수부를 2진수로 바꿈
2. **정규화**: 값을 $1.f \times 2^e$ 형태로 맞추고 실제 지수 $e$를 구함
3. **지수 저장**: 실제 지수에 바이어스를 더해 지수부 비트로 인코딩함
4. **비트 조립**: 부호, 지수부, 가수부를 결합하고 필요한 경우 반올림함

## Ⅵ. 실무 적용 및 유의점

1. 금융 금액과 정산 로직은 이진 부동소수점 오차가 누적되므로 decimal 또는 정수 스케일을 쓰고 원 단위 차이와 반올림 규칙으로 검증함
2. 수치 계산은 오버플로, 언더플로, NaN 전파가 결과를 오염시키므로 입력 범위 제한과 예외 카운터로 연산 안정성을 확인함

## Ⅶ. 결론

- IEEE 754는 넓은 범위의 실수를 표준 비트열로 다루는 방식이므로, 정밀도 손실과 예외 값을 통제할 때 신뢰성 있는 수치 계산이 가능함

## 작성 근거(검토용)

- 개요는 부호·지수·가수 분해와 근사 표현을 함께 제시해 IEEE 754의 본질을 잡음
- 특징은 범위 확대, 근사 오차, 예외 표준화, 비용 증가를 선별해 실무 선택 기준으로 연결함
- Ⅲ은 주요 precision별 비트 구성을 비교해 정밀도와 저장 비용의 트레이드오프를 드러냄
- Ⅳ와 Ⅴ는 비트 구조와 인코딩 절차를 분리해 암기와 계산 문제 모두에 대응하게 함
- 실무 유의점은 금액 계산 오류와 NaN·오버플로 전파처럼 부동소수점의 대표 장애 원인을 중심으로 작성함
