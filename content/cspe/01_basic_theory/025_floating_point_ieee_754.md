## 미리 알고가기

- 부동소수점: 소수점 위치를 지수로 이동시켜 넓은 범위의 실수를 유한 비트로 표현하는 방식임
- IEEE 754: 부호, 지수, 가수 필드와 반올림, 예외, 특수값을 정의한 부동소수점 표준임
- 정규화: 유효숫자의 맨 앞 비트를 1로 맞추어 같은 값을 하나의 표준형으로 표현함
- 바이어스 지수: 음수 지수를 저장하기 위해 실제 지수에 고정값을 더해 저장하는 방식임
- 특수값: 0, subnormal, infinity, NaN처럼 일반 정규화 수와 다른 의미를 갖는 값임

## Ⅰ. 개요

- **정의**: IEEE 754 부동소수점은 실수를 부호, 바이어스 지수, 가수 필드로 나누어 이진 과학적 표기 기준으로 저장하는 표준이며, 제한된 비트로 넓은 범위의 실수 연산을 일관되게 처리하기 위해 사용함.
- **배경/필요성**: 과학 계산, 그래픽스, AI 연산은 정수보다 큰 동적 범위와 소수 표현이 필요하므로, 플랫폼마다 다른 실수 표현을 표준화해 재현성과 예외 처리를 보장해야 함.
- **비유**: 숫자를 `부호 x 유효숫자 x 10의 지수`로 적는 과학적 표기법을 2진 비트 필드로 고정한 형식과 같음.

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| IEEE 754 구조 설명 | 부호, 지수, 가수, 바이어스, 정규화 | 단순 실수 저장 방식으로만 설명 |
| 정밀도 한계 이해 | 반올림 오차, overflow/underflow, NaN/Inf | 10진 소수의 2진 표현 한계 누락 |

> 요약: IEEE 754는 실수의 범위와 정밀도를 비트 필드로 나누어 표준화하고, 정확히 표현되지 않는 값의 반올림과 예외를 함께 정의함.

## Ⅱ. 특징/비교

| 판단 기준 | 고정소수점 | IEEE 754 부동소수점 |
|:---|:---|:---|
| 소수점 위치 | 미리 정한 자리에서 고정됨 | 지수 필드로 소수점 위치가 이동함 |
| 표현 범위 | 정밀도는 일정하지만 범위가 좁음 | 매우 작은 값부터 큰 값까지 넓은 범위를 표현함 |
| 연산 위험 | 스케일 관리가 설계자 책임임 | 반올림, overflow, NaN 같은 표준 예외가 존재함 |
| 선택 기준 | 금융 금액처럼 고정 자리 정확성이 중요할 때 적합함 | 과학 계산과 ML처럼 동적 범위가 중요할 때 적합함 |

- **범위 기준**: 지수 비트가 많을수록 표현 가능한 최소·최대 값의 범위가 넓어짐.
- **정밀도 기준**: 가수 비트가 많을수록 인접 실수 사이 간격이 작아져 유효 자릿수가 늘어남.
- **재현성 기준**: 반올림 모드와 연산 순서가 다르면 같은 수식도 약간 다른 결과를 낼 수 있음.

> 요약: 부동소수점은 고정소수점보다 범위가 넓지만 정확한 10진 표현과 연산 재현성에는 별도 관리가 필요함.

## Ⅲ. 구성요소

```text
+------------+      +------------+      +------------+
| Sign       | ---> | Exponent   | ---> | Fraction   |
| 1 bit      |      | Biased     |      | Mantissa   |
+------------+      +------------+      +------------+
       |                   |                   |
       v                   v                   v
+------------+      +------------+      +------------+
| Positive   |      | Scale      |      | Precision  |
| Negative   |      | Range      |      | Digits     |
+------------+      +------------+      +------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 부호 비트 S | 0은 양수, 1은 음수를 나타내며 값의 방향을 결정함 | 플러스/마이너스 표지 |
| 지수 필드 E | 바이어스가 더해진 지수를 저장해 수의 크기 범위를 결정함 | 자릿수 이동 레버 |
| 가수 필드 M | 정규화된 유효숫자의 소수부를 저장해 정밀도를 결정함 | 유효숫자 칸 |
| 반올림 모드 | 표현 불가능한 값을 가장 가까운 표현값으로 매핑하는 기준임 | 눈금 맞춤 규칙 |
| 특수값 | 0, subnormal, infinity, NaN을 통해 예외와 극단값을 표준 표현함 | 예외 표지판 |

> 요약: IEEE 754는 부호로 방향, 지수로 범위, 가수로 정밀도를 나누고 반올림·특수값으로 유한 비트 표현의 예외를 통제함.

## Ⅳ. 절차

```text
+------------+      +------------+      +------------+      +------------+
| Convert    | ---> | Normalize  | ---> | Encode     | ---> | Round and  |
| to Binary  |      | 1.x * 2^e  |      | S E M      |      | Check      |
+------------+      +------------+      +------------+      +------------+
```

1. **이진 변환**: 10진 실수를 정수부와 소수부로 나누어 2진수로 변환함.
2. **정규화**: 값을 `1.x * 2^e` 형태로 맞추고 실제 지수 `e`를 구함.
3. **필드 인코딩**: 부호 비트, 바이어스 지수, 가수 비트를 각각 필드에 배치함.
4. **반올림·예외 확인**: 가수 비트 초과분을 반올림하고 0, subnormal, overflow, NaN 여부를 확인함.

> 요약: IEEE 754 인코딩은 2진 변환, 정규화, 필드 배치, 반올림·예외 확인 순서로 실수를 비트열로 바꿈.

## Ⅴ. 문제점

- **P1 표현 오차**: 0.1 같은 10진 소수는 2진 유한 비트로 정확히 표현되지 않아 누적 계산에서 오차가 발생함.
- **P2 비교 오류**: 반올림과 연산 순서 차이 때문에 실수값을 `==`로 직접 비교하면 의도와 다른 결과가 나올 수 있음.
- **P3 예외 전파**: overflow, underflow, NaN, infinity가 처리되지 않으면 후속 계산 전체로 비정상 값이 전파됨.

> 요약: 부동소수점의 핵심 위험은 유한 비트 표현 오차, 직접 비교 오류, 특수값 전파임.

## Ⅵ. 개선방안

- **P1 대응**: 허용 오차를 기준으로 계산하고 금융 금액은 decimal 또는 정수 스케일 고정소수점으로 처리함. (확인: 절대/상대 오차)
- **P2 대응**: `abs(a-b) < epsilon` 방식과 안정적인 연산 순서를 적용하고 테스트에 경계값을 포함함. (확인: 비교 실패 케이스)
- **P3 대응**: NaN/Inf 검사, 예외 플래그, overflow/underflow 경계 테스트를 계산 파이프라인에 넣음. (확인: 특수값 처리 로그)

> 요약: 부동소수점은 허용 오차, 자료형 선택, 특수값 검사를 설계에 포함해야 신뢰 가능한 수치 계산이 가능함.

## Ⅶ. 전망

- **향후 발전 방향**: AI 가속기와 GPU에서는 FP32, FP16, BF16, FP8처럼 범위와 정밀도를 조절하는 저정밀 형식이 확대될 전망임.
- **기술사적 판단**: 정확성이 핵심인 업무와 처리량이 핵심인 업무를 구분해 decimal, FP64, FP32, BF16 등을 선택해야 함.
- **기술사 제언**: 답안에서는 부호·지수·가수 구조와 함께 표현 오차와 특수값 대응을 제시해 실무 위험까지 연결해야 함.

답안 정리:
- **핵심 키워드**: 부호, 바이어스 지수, 가수, 정규화, NaN/Inf임.
- **연계 키워드**: 수 체계 변환, 수치해석, AI 저정밀 연산으로 연결함.
- **검증 관점**: 값 비교에는 허용 오차와 특수값 검사를 반드시 포함함.
