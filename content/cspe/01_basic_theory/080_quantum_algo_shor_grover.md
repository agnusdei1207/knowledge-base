## 미리 알고가기

- 큐비트(Qubit): 0과 1의 중첩 상태를 표현하는 양자 정보 단위임
- 중첩(Superposition): 여러 상태가 동시에 확률 진폭으로 존재하는 성질임
- 간섭(Interference): 정답 진폭은 키우고 오답 진폭은 줄이는 양자 효과임
- 오라클(Oracle): 그로버 알고리즘에서 정답 상태의 위상을 표시하는 함수임
- 양자 푸리에 변환(QFT): 양자 상태의 주기 정보를 주파수 성분으로 바꾸는 연산임
- 양자내성암호(PQC): 양자 알고리즘 공격을 고려해 설계한 공개키 암호 체계임
- 후보 수 $N$: 그로버 알고리즘이 탐색하는 비정렬 항목의 전체 개수임
- 모듈러 거듭제곱·최대공약수: 나머지 범위의 거듭제곱 연산과 두 수의 공통 약수 중 가장 큰 수임

## 작성 근거(검토용)

- **방향성**: 양자 알고리즘은 주기 찾기·오라클 탐색 구조가 있는 특정 문제에서만 계산 복잡도를 낮추므로, 이론적 속도만으로 도입을 판단하지 않고 큐비트 오류율·회로 깊이로 실증 범위를 제한하며 공개키 암호 자산은 양자 하드웨어 성숙을 기다리지 말고 PQC로 먼저 전환해야 함
- **Ⅰ. 개요 구성**: 양자 성질과 계산 복잡도 감소를 함께 정의해 단순 하드웨어 설명과 구분함
- **Ⅱ. 특징 선정**: 적용 문제, 계산량 변화, 큐비트 오류율, 회로 깊이를 양자 알고리즘 판단 기준으로 선정함
- **Ⅲ. 비교축 선정**: 쇼어·그로버는 소인수분해·이산 로그와 비정렬 탐색이라는 서로 다른 문제 영역을 담당해 같은 목적을 두고 대체 선택하는 관계가 아니므로 적용 기준 축을 두지 않고 동작 메커니즘·대상 문제·보안 영향으로 원리와 위협을 구분함
- **Ⅳ. 구조 선정**: 큐비트 레지스터·게이트·문제 함수 회로·간섭 연산·측정으로 두 알고리즘의 공통 구조를 제시함
- **Ⅴ. 절차 선정**: 쇼어의 주기 측정과 그로버의 진폭 증폭을 별도 흐름으로 나눠 고유 원리를 드러냄
- **Ⅵ·Ⅶ. 사례·결론 선정**: 고전 계산 대비 검증과 PQC 전환은 양자 알고리즘 답안에 필요한 운영 판단임
- **전수 검수**: 제목부터 결론까지 용어·표·도식·요약을 대조하고 절 간 판단축을 일치시킴

## Ⅰ. 개요

- **정의/개념**: 양자 알고리즘은 중첩·간섭을 이용해 특정 문제의 계산 복잡도를 낮추는 알고리즘임
- **배경/필요성**: 고전 계산 비용이 큰 소인수분해·비정렬 탐색을 가속하기 위해 양자 알고리즘이 필요함

### 쉽게 이해하기 (학습용)
- 여러 가능성을 동시에 겹쳐놓고 정답 쪽 신호는 서로 강해지게, 오답 쪽 신호는 서로 상쇄되게 만들어 특정 문제만 훨씬 빠르게 풂

## Ⅱ. 특징

- 양자 알고리즘은 모든 문제가 아니라 주기 찾기나 오라클 탐색 구조가 있는 문제에서 계산량을 줄임
- 쇼어 알고리즘은 주기 찾기를 이용해 소인수분해와 이산 로그를 입력 비트 수의 다항 시간에 해결함
- 그로버 알고리즘은 진폭 증폭으로 비정렬 탐색을 $O(N)$에서 $O(\sqrt{N})$ 수준으로 줄임
- 실제 성능은 큐비트 오류율, 회로 깊이, 오류 정정 비용에 좌우됨

### 쉽게 이해하기 (학습용)
- 아무 문제나 빨라지는 게 아니라, 숨은 주기가 있거나 정답을 표시해주는 장치(오라클)가 있는 문제에서만 효과가 있음
- 쇼어는 큰 수를 소수로 쪼개는 문제를, 그로버는 정렬 안 된 목록에서 하나를 찾는 문제를 각각 겨냥함
- 실제로 얼마나 빨라지는지는 이론상 속도뿐 아니라 하드웨어의 오류율과 회로 복잡도에 크게 좌우됨

## Ⅲ. 종류 및 비교

| 판단 기준 | 쇼어 알고리즘 | 그로버 알고리즘 |
|:---|:---|:---|
| 동작 메커니즘 | QFT 기반 주기 탐색 | 오라클 기반 진폭 증폭 |
| 대상 문제 | 소인수분해·이산 로그 | 비정렬 탐색 |
| 보안 영향 | RSA·ECC 등 공개키 암호 위협 | 대칭키 유효 보안 비트 반감 |

> 요약: 쇼어는 주기 탐색으로 소인수분해·이산 로그를 풀어 공개키 암호를 위협하고, 그로버는 진폭 증폭으로 대칭키의 유효 보안 비트를 반감시킴.

### 쉽게 이해하기 (학습용)
- 쇼어는 숨겨진 규칙적인 패턴(주기)을 찾아내 큰 수를 쪼개므로 지금의 공개키 암호를 위협하고, 그로버는 목록을 하나씩 뒤지는 대신 정답 쪽 확률을 키워 찾으므로 비밀번호처럼 무작위로 찾는 암호의 안전도를 절반 수준으로 낮춤

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 큐비트 레지스터 | 중첩 입력·계산 결과 저장 공간 |
| 양자 게이트 | 큐비트 상태 변환 연산 |
| 문제 함수 회로 | 쇼어의 모듈러 거듭제곱·그로버의 정답 오라클 |
| 간섭 연산 | 쇼어는 역 QFT로 주기 정보를 측정 확률 분포로 변환하고, 그로버는 확산 연산으로 정답 상태의 진폭을 증폭 |
| 측정 | 양자 상태의 고전 비트 확정 연산 |

> 요약: 쇼어는 간섭으로 주기 정보를 측정값에 드러내고, 그로버는 정답 상태의 측정 확률을 높인 뒤 결과를 측정함.

### 쉽게 이해하기 (학습용)
- 쇼어는 여러 후보를 겹쳐놓고 그 안에 숨은 패턴을 걸러내는 필터(간섭)를 거쳐 결과를 읽어내고, 그로버는 정답에 해당하는 후보의 신호만 계속 키워가다가 마지막에 확인함

## Ⅴ. 원리 및 절차 흐름도

```text
[쇼어]  중첩 생성 -> 모듈러 거듭제곱 -> 역 QFT -> 주기 측정 -> 인수 계산
[그로버] 중첩 생성 -> 오라클 위상 반전 -> 확산 연산 -> 반복·측정 -> 항목 확인
```

1. **쇼어 주기 함수 구성**: 입력 레지스터의 중첩 상태에서 모듈러 거듭제곱 함수값을 계산함
2. **쇼어 주기 추정**: 역 양자 푸리에 변환과 측정 결과로 함수의 주기를 추정하고 최대공약수로 인수를 구함
3. **그로버 정답 표시**: 오라클이 조건을 만족하는 상태의 위상을 반전함
4. **그로버 진폭 증폭**: 확산 연산을 반복해 표시 상태의 측정 확률을 높인 뒤 결과를 확인함

> 요약: 쇼어는 주기 찾기와 고전 후처리로 인수를 구하고, 그로버는 오라클과 확산 연산으로 정답 상태의 진폭을 증폭함.

### 쉽게 이해하기 (학습용)
- 쇼어는 후보들을 겹쳐놓고 계산한 뒤 숨은 패턴(주기)을 읽어내 그 정보로 계산기(고전 컴퓨터)가 답을 뽑아내고, 그로버는 정답 표시와 신호 증폭을 여러 번 반복해 정답이 나올 확률을 최대한 키운 뒤 확인함

## Ⅵ. 실무 사례

1. 양자 알고리즘 PoC는 쇼어·그로버 회로가 큐비트 수·깊이 한도를 넘으면 시뮬레이터에서 검증함
2. 암호 자산은 RSA 사용 위치를 목록화하고 중요도·만료일 순으로 양자내성암호로 교체함

### 쉽게 이해하기 (학습용)
- 아직 실제 장비가 다룰 수 있는 규모를 넘으면 흉내 내는 프로그램(시뮬레이터)으로 먼저 검증하고, 중요한 암호는 어디에 쓰이는지 목록을 만들어 우선순위대로 새 암호로 바꿔감

## Ⅶ. 결론

- 양자 알고리즘은 특정 난제를 가속하지만 오류 정정 자원과 암호 전환 범위를 함께 판단해야 함
- 단기에는 회로 깊이·오류율로 PoC 범위를 제한하고, 보안 자산은 양자 장비 성숙을 기다리지 말고 PQC 전환을 선행해야 함

### 쉽게 이해하기 (학습용)
- 특정 문제만 빨라진다는 장점만 보지 말고 오류를 바로잡는 데 드는 비용과 암호를 얼마나 바꿔야 하는지도 함께 따져야 하며, 장비가 완벽해지길 기다리지 말고 암호부터 먼저 바꿔둬야 함
