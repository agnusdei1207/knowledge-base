# 양자 알고리즘 - 쇼어·그로버 (Quantum Algorithm Shor Grover)

## 1. 개요

- **정의/개념**: 양자 알고리즘은 큐비트의 중첩, 얽힘, 간섭, 측정 특성을 이용해 특정 문제에서 고전 알고리즘보다 빠른 계산을 목표로 하는 알고리즘이다.
- **배경/필요성**: 소인수분해, 비정렬 탐색, 최적화 등 일부 문제는 고전 계산에서 비용이 크므로, 양자 계산 모델이 제공하는 속도 이점과 보안 영향을 이해할 필요가 있다.

양자 알고리즘의 핵심은 모든 문제를 빠르게 푸는 만능 기법이 아니라, 문제 구조가 양자 상태의 간섭으로 이득을 만들 때 효과가 있다는 점이다.

## 2. 특징 및 비교

| 구분 | 쇼어 알고리즘 | 그로버 알고리즘 |
|---|---|---|
| 대상 문제 | 소인수분해, 이산로그 | 비정렬 탐색 |
| 속도 이점 | 지수적 속도 향상 가능 | 제곱근 수준 속도 향상 |
| 핵심 원리 | 양자 푸리에 변환, 주기 찾기 | amplitude amplification |
| 보안 영향 | RSA, ECC 위협 | 대칭키 키 길이 영향 |
| 전제 | 오류 보정된 대규모 양자컴퓨터 | oracle 구조 |

선택 기준은 문제 구조, oracle 구성 가능성, 큐비트 수, 오류율, 고전 대안 대비 실제 비용이다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| Qubit | 0과 1의 중첩 상태 | 양자 정보 단위 |
| Superposition | 여러 상태 동시 표현 | 탐색 공간 표현 |
| Quantum Gate | 양자 상태 변환 | 회로 구성 |
| Interference | 정답 진폭 강화·오답 억제 | 속도 이점 근거 |
| Measurement | 양자 상태를 고전 결과로 관측 | 확률적 결과 |

```text
문제 인코딩 -> 중첩 상태 준비 -> 양자 게이트/간섭 -> 측정 -> 고전 후처리
```

양자 이득은 중첩 자체가 아니라 정답 가능성을 간섭으로 키우는 회로 설계에서 발생한다.

## 4. 문제점 및 개선방안

1. **오류와 decoherence**
   - 양자 상태는 외부 잡음에 민감해 계산 중 오류가 누적된다.
   - **개선방안**: 양자 오류 정정, fault-tolerant 설계, 짧은 회로 깊이를 고려한다.

2. **문제 적용 범위 제한**
   - 모든 문제에서 지수적 속도 향상이 보장되지 않는다.
   - **개선방안**: 쇼어·그로버처럼 검증된 문제 구조와 oracle 비용을 분리해 평가한다.

3. **암호 전환 리스크**
   - 대규모 양자컴퓨터가 가능해지면 RSA/ECC 기반 보안이 약화될 수 있다.
   - **개선방안**: PQC 전환, crypto agility, 장기 기밀 데이터 보호 전략을 수립한다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| 암호 영향 분석 | 쇼어 알고리즘에 따른 공개키 암호 위험 평가 | 전환 대상, 데이터 수명 |
| 탐색 문제 | 그로버 알고리즘으로 비정렬 탐색 이론 이점 분석 | oracle 비용, 반복 횟수 |
| 양자 소프트웨어 연구 | 양자 회로와 하이브리드 알고리즘 실험 | 회로 깊이, 오류율 |

## 6. 결론

양자 알고리즘은 중첩과 간섭을 이용해 특정 문제에서 고전 계산 대비 속도 이점을 제공할 수 있다. 쇼어는 공개키 암호에 구조적 위협을 주고, 그로버는 탐색 문제와 대칭키 보안 수준에 영향을 주므로 기술 가능성과 보안 전환 전략을 함께 판단해야 한다.
