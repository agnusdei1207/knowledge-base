## Ⅰ. 개요
- **정의**: 양자 중첩·간섭을 활용하여 소인수분해·비정렬 탐색을 고전 대비 지수/이차 가속하는 알고리즘임
- **배경/필요성**: RSA 2048 소인수분해에 고전 컴퓨터로 10^20년 소요, 양자 가속 시 수시간 내 해결 가능하므로 암호 체계 재설계가 시급함
- **비유**: 도서관에서 책 1권을 찾을 때 — 고전은 1권씩 넘기고(O(N)), 그로버는 √N번만에, 쇼어는 구조적 패턴으로 즉시 찾아내는 방식임

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 쇼어·그로버 복잡도 비교 | 쇼어 O((log N)^3) vs 그로버 O(√N) | 쇼어는 BQP, 그로버는 NP 완전 해결 아님 명시 |
| 양자 가속의 원리 구분 | 쇼어: QFT 기반 주기 탐색, 그로버: 진폭 증폭 | 두 알고리즘의 가속 유형(지수적/이차적) 혼동 금지 |

> 요약: 쇼어는 QFT로 주기를 탐색해 지수적 가속, 그로버는 진폭 증폭으로 이차적 가속을 달성하는 양자 알고리즘임

## Ⅱ. 구성요소
```text
+--------+    +---------+    +-----------+    +---------+
| Qubit  | -> | Quantum | -> | Quantum   | -> | Measure |
| Reg    |    | Gate    |    | Interfere |    | Readout |
+--------+    +---------+    +-----------+    +---------+
     |              |               |
     v              v               v
 Superposition  Entangle/QFT   Amp Amplify
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 큐비트 레지스터 | n개 큐비트가 2^n개 상태를 동시 표현하는 양자 정보 단위 | 동시에 모든 면이 보이는 주사위 |
| 양자 게이트 | Hadamard·CNOT·Toffoli 등으로 큐비트 상태 진폭을 조작하는 유니터리 연산 | 프리즘(빛의 방향 변환) |
| 양자 간섭 | 정답 경로의 확률 진폭을 보강 간섭으로 증폭, 오답은 상쇄 간섭으로 억제 | 파도의 보강·상쇄 |
| 측정(Readout) | 양자 상태를 고전 비트로 붕괴시켜 확률적 결과를 추출 | 동전 멈춤 — 앞/뒤 확정 |

> 요약: 큐비트 중첩 → 게이트 조작 → 간섭 증폭 → 측정의 4요소가 양자 알고리즘의 연산 파이프라인을 구성함

## Ⅲ. 절차
```text
+-----------+    +-----------+    +-----------+    +-----------+
| Init      | -> | Oracle    | -> | Amplify   | -> | Measure   |
| Superposi |    | / QFT     |    | / iQFT    |    | + Verify  |
+-----------+    +-----------+    +-----------+    +-----------+
```

1. **상태 초기화** — n큐비트에 Hadamard 게이트 적용, 2^n개 상태의 균등 중첩 생성함
2. **오라클/QFT 적용** — 쇼어: 모듈러 지수화 + QFT로 주기 r 추출, 그로버: 오라클이 정답 상태 위상 반전함
3. **진폭 증폭/역QFT** — 쇼어: 역QFT로 주기 정보를 측정 가능 상태로 변환, 그로버: Diffusion 연산자로 정답 진폭 O(√N)회 반복 증폭함
4. **측정 및 검증** — 양자 상태를 고전 비트로 측정, 쇼어는 연분수 전개로 r 확정, 그로버는 정답 여부를 고전 검증함

> 요약: 중첩 초기화 → 문제 인코딩(오라클/QFT) → 진폭 증폭 → 측정·검증의 4단계로 확률적 정답을 도출함

## Ⅳ. 문제점
- **결어긋남(Decoherence)**: 외부 열·전자기 노이즈로 양자 상태 유지 시간(T2)이 수십 μs 수준에 불과, 대규모 회로 실행 불가
- **물리 큐비트 오버헤드**: 논리 큐비트 1개에 물리 큐비트 1,000~10,000개 필요, RSA-2048 해독에 수백만 큐비트 요구됨
- **PQC 전환 지연**: 쇼어 알고리즘 실용화 시 기존 RSA·ECC 체계 무력화, 양자내성암호(PQC) 전환 미비 시 HNDL 공격 위험

> 요약: 결어긋남에 의한 연산 한계, 물리 큐비트 대량 요구, 공개키 암호 체계 붕괴 위험이 3대 과제임

## Ⅴ. 개선방안
1. 단기: NISQ 환경에서 VQE·QAOA 등 변분 양자 알고리즘으로 짧은 회로 깊이 내 실용 문제 해결
2. 중기: Surface Code 등 위상학적 오류 정정 코드 적용으로 논리 큐비트당 물리 큐비트 비율 100:1 이하 달성
3. 장기: 내결함성 범용 양자컴퓨터(FTQC) 확보 + NIST PQC 표준(ML-KEM·ML-DSA) 전면 적용

- **결어긋남**: 극저온(15mK) 제어 정밀도 향상 + 동적 디커플링 기법 (지표: T2 > 1ms)
- **물리 큐비트 오버헤드**: 위상학적 큐비트(Majorana) 연구로 오류율 10^-6 이하 달성 (지표: 물리/논리 비율 < 100)
- **PQC 전환 지연**: 크립토 민첩성(Crypto Agility) 아키텍처 선제 도입 (지표: PQC 전환율 > 80%)

> 요약: 변분 알고리즘 → 오류 정정 코드 → FTQC·PQC 표준화의 단계적 로드맵으로 실용화 장벽을 해소함

## Ⅵ. 전망
- **향후 발전 방향**: 2030년 1,000+ 논리 큐비트 FTQC 목표, 신약·소재 시뮬레이션·최적화 영역에서 양자 우위 실현 전망
- **기술사적 판단**: 쇼어 알고리즘은 공개키 암호 체계의 수명을 결정하는 변수이므로, IT 인프라 보안 설계 시 PQC 전환 시점을 역산해야 함
- **기술사 제언**: 양자 가속이 유효한 문제 클래스(BQP)를 정확히 식별하고, 고전-양자 하이브리드 아키텍처를 기본 설계 원칙으로 채택해야 함
