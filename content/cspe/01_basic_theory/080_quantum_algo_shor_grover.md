## 미리 알고가기

- 큐비트(Qubit): 0과 1의 중첩 상태를 표현하는 양자 정보 단위임
- 중첩(Superposition): 여러 상태가 동시에 확률 진폭으로 존재하는 성질임
- 간섭(Interference): 정답 진폭은 키우고 오답 진폭은 줄이는 양자 효과임
- 오라클(Oracle): 그로버 알고리즘에서 정답 상태의 위상을 표시하는 함수임
- 결맞음 상실(Decoherence): 외부 잡음으로 양자 상태가 깨지는 현상임

## 작성 근거(검토용)

- 개요는 양자 성질과 계산 복잡도 감소를 함께 정의해 단순 하드웨어 설명과 구분함
- 특징은 제한적 가속, 쇼어, 그로버, 오류율을 양자 알고리즘 선택과 현실성 판단 기준으로 선정함
- Ⅲ은 대상 문제, 원리, 속도 향상, 보안 영향으로 두 대표 알고리즘의 차이를 직접 드러냄
- 구조 도식은 중첩, 변환, 간섭, 측정 순서가 양자 계산의 직관을 제공하므로 배치함
- 고전 계산 대비 검증과 PQC 전환은 양자 알고리즘 답안에 필요한 운영 판단임

## Ⅰ. 개요

- **정의/개념**: 양자 알고리즘은 중첩·간섭·얽힘을 이용해 특정 문제의 계산 복잡도를 낮추는 알고리즘임
- **배경/필요성**: 고전 계산 비용이 큰 소인수분해·비정렬 탐색·양자계 시뮬레이션을 가속하기 위해 양자 알고리즘이 필요함

## Ⅱ. 특징

- 모든 문제를 빠르게 해결하지 않고 특정 수학 구조에서만 가속을 제공함
- 쇼어 알고리즘은 주기 찾기를 이용해 소인수분해와 이산 로그를 빠르게 해결함
- 그로버 알고리즘은 진폭 증폭으로 비정렬 탐색을 $O(N)$에서 $O(\sqrt{N})$ 수준으로 줄임
- 실제 성능은 큐비트 오류율, 회로 깊이, 오류 정정 비용에 좌우됨

## Ⅲ. 종류 및 비교

| 판단 기준 | 쇼어 알고리즘 | 그로버 알고리즘 |
|:---|:---|:---|
| 대상 문제 | 소인수분해, 이산 로그 | 비정렬 탐색 |
| 핵심 원리 | 양자 푸리에 변환, 주기 찾기 | 오라클, 진폭 증폭 |
| 속도 향상 | 지수적 가속 | 제곱근 수준 가속 |
| 보안 영향 | RSA·ECC 위협 | 대칭키 길이·해시 출력 길이 확대 필요 |
| 구현 난점 | 오류 정정 큐비트 대량 필요 | 반복 횟수와 오라클 구현 비용 |

> 요약: 쇼어는 공개키 암호 기반 난제를, 그로버는 비정렬 탐색 비용을 낮추는 대표 알고리즘임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 큐비트 레지스터 | 중첩 상태의 입력과 계산 결과를 담는 저장 공간임 |
| 양자 게이트 | 하다마드, 위상, 제어 연산으로 상태를 변환함 |
| 오라클 | 정답 조건을 만족하는 상태를 표시함 |
| 측정 | 양자 상태를 고전 비트 결과로 확정함 |
| 오류 정정 | 잡음으로 깨진 상태를 논리 큐비트 수준에서 보정함 |

```text
[ 양자 알고리즘 구조 ]
Initialize -> Superposition -> Oracle/Transform -> Interference -> Measure
```

> 요약: 양자 알고리즘은 중첩 상태를 변환하고 간섭으로 정답 진폭을 키운 뒤 측정함.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 상태 준비 | --> | 양자 변환 | --> | 진폭 조정 | --> | 측정 확정 |
+----------+     +----------+     +----------+     +----------+
```

1. **상태 준비**: 큐비트를 초기화하고 중첩 상태를 만듦
2. **양자 변환**: 문제 구조에 맞는 QFT 또는 오라클 연산을 적용함
3. **진폭 조정**: 간섭으로 정답 확률을 높이고 오답 확률을 낮춤
4. **측정 확정**: 측정 결과를 고전 값으로 읽고 필요한 후처리를 수행함

> 요약: 양자 가속은 문제 구조가 QFT나 오라클 기반 진폭 증폭에 맞을 때만 의미가 있음.

## Ⅵ. 실무 사례

1. 양자 도입 검토는 문제 구조가 쇼어·그로버형 가속에 맞는지 먼저 판정하고 고전 GPU 대비 시간·비용으로 검증함
2. 암호 자산은 쇼어 위협에 노출될 수 있으므로 PQC 전환과 대칭키 길이 확대를 추진하고 취약 자산 수·전환율로 확인함

## Ⅶ. 결론

- 양자 알고리즘은 특정 난제의 계산 한계를 바꾸지만 오류 정정과 암호 전환까지 포함해 현실성을 판단해야 함
