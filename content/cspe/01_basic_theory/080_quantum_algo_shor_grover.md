## 미리 알고가기

- 큐비트($Qubit$): 0과 1 상태뿐만 아니라, 이들이 동시에 존재할 수 있는 양자역학적 중첩 상태를 가지는 정보의 기본 단위임
- 양자 중첩($Superposition$): 여러 가지 서로 다른 물리 상태가 동시에 존재할 수 있는 양자역학적 현상으로, 연산의 대규모 병렬성을 제공함
- 양자 얽힘($Entanglement$): 둘 이상의 큐비트가 멀리 떨어져 있어도 서로 유기적인 상관관계를 유지하는 현상으로, 정보 전송과 처리를 돕는 연결 고리임
- 양자 결맞음 어긋남 ($Decoherence$): 외부 환경의 미세한 간섭으로 인해 양자 중첩 및 얽힘 상태가 붕괴하여 고전적인 상태로 돌아가 버리는 현상임

## Ⅰ. 개요

- **정의/개념**: 양자 알고리즘은 양자역학의 고유 성질인 중첩($Superposition$), 얽힘($Entanglement$), 그리고 간섭($Interference$) 현상을 컴퓨터 연산에 활용하여, 기존의 고전 컴퓨터로는 천문학적 시간이 걸리는 특정 문제들을 단시간에 해결하는 연산 절차임
- **배경/필요성**: 반도체 미세화의 한계로 고전 컴퓨터의 성능 향상이 물리적 벽에 부딪힘에 따라, 거대 분자 시뮬레이션, 대규모 비정렬 검색, 소인수분해 기반 암호 해독 등 지수적 연산이 필요한 난제를 해결하기 위해 탄생함

## Ⅱ. 특징

- 고전 컴퓨터가 0 또는 1의 상태를 하나씩 순차 연산하는 것과 달리, 양자 컴퓨터는 $N$개의 큐비트로 $2^N$개의 상태를 동시에 중첩 표현하여 한 번의 게이트 조작으로 대규모 병렬 연산을 가동함
- 쇼어($Shor$) 알고리즘은 '양자 푸리에 변환($QFT$)'을 사용해 수식의 주기를 초고속으로 탐색하여, 거대 정수의 소인수분해 성능을 지수적으로 가속($Exponential$ $Speedup$)시킴
- 그로버($Grover$) 알고리즘은 무작위 분포 데이터 중 타깃 값을 찾을 때, '진폭 증폭($Amplitude$ $Amplification$)' 기술을 이용해 탐색 속도를 통계적 제곱근 수준($Quadratic$ $Speedup$)으로 개선함

## Ⅲ. 양대 양자 알고리즘 비교

| 판단 기준 | 쇼어 알고리즘 (Shor's Algorithm) | 그로버 알고리즘 (Grover's Algorithm) |
|:---|:---|:---|
| **해결 타깃 문제** | 거대 정수의 소인수분해, 이산 로그 문제 | 구조화되지 않은 데이터베이스 탐색 |
| **핵심 양자 원리** | $QFT$ (양자 푸리에 변환)를 통한 주기 찾기 | 오라클($Oracle$)과 위상 반전, 진폭 증폭 |
| **속도 개선 강도** | 지수적 가속 ($Exponential$) | 다항/제곱근 가속 ($Quadratic$) |
| **고전 대비 복잡도** | $O(2^{\sqrt[3]{n}})$ $\rightarrow$ $O(n^3)$ | $O(N)$ $\rightarrow$ $O(\sqrt{N})$ |
| **주요 파급 영향** | 현대 대칭/비대칭 암호 시스템 무력화 | 해시 암호 키 무력화 방지(키 길이 확장 요구) |

> 요약: 쇼어는 암호학의 수학적 난제를 뚫는 창이고, 그로버는 무작위 탐색의 지름길을 여는 열쇠임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 하다마드 게이트 | 0과 1을 완벽히 반반 섞인 중첩 상태로 전이시키는 기본 양자 연산 장치임 |
| 양자 간섭 | 정답이 되는 파동은 보강 간섭으로 키우고, 오답인 파동은 상쇄 간섭으로 지워버리는 물리 통제임 |
| 오라클 ($Oracle$) | 그로버 알고리즘에서 탐색하려는 정답 데이터 상태의 부호(위상)만 음수로 반전시키는 표식기임 |
| 양자 오류 정정 | 환경 잡음으로 큐비트가 손상되는 것을 방지하기 위해 여러 큐비트를 묶는 논리 큐비트($Logical$ $Qubit$) 체계임 |

```text
[ 그로버 알고리즘의 진폭 증폭 과정 ]
1. 모든 상태 균등 중첩 -> 2. 오라클을 통한 정답 상태의 위상 반전(부호 -화) -> 3. 평균 기준 대칭 반사
- 위 과정을 약 ⎷N 번 반복 시, 정답의 확률 진폭(높이)이 극대화되어 측정 시 99% 확률로 정답이 관측됨
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 큐비트 중첩  | --> | 양자 변환연산| --> | 간섭/진폭증폭| --> | 고전 상태측정|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **상태 생성** — 레지스터에 정렬된 모든 큐비트에 하드웨어 게이트(하다마드)를 적용하여 모든 가용 상태가 동시에 섞여 있는 초중첩 상태를 만듦
2. **양자적 간섭** — 연산 회로를 통과시키며, 쇼어는 주기 함수를 중첩 대입하고, 그로버는 오라클을 가동해 타깃 데이터의 진폭 방향을 뒤집음
3. **진폭 증폭** — 평균 대칭 반사 연산 등을 지속 적용하여, 오답의 확률 진폭을 낮추고 오직 정답 상태의 관측 확률(진폭 제곱)만 100%에 가깝게 끌어올림
4. **붕괴 및 확정** — 증폭이 완료된 양자 상태를 관측(측정, $Measurement$)하여 중첩 상태를 붕괴시키고, 최종 고전 데이터 0 또는 1의 확정값을 출력함

## Ⅵ. 실무 적용 및 유의점

1. 실제 하드웨어 구현 시 외부 온도나 자기장의 미세한 요동으로 인해 큐비트의 정보가 날아가는 결맞음 어긋남($Decoherence$) 현상이 상시 발생하므로, 오류율이 0에 수렴하는 '무결함 양자 컴퓨터($FTQC$)'의 양산 시점을 냉정하게 관측하며 비즈니스 로드맵을 설계해야 함
2. 쇼어와 그로버 알고리즘은 양자 컴퓨터가 범용 연산 속도를 올려주는 요술 방망이가 아니라 '특정 패턴의 수학 문제'에 한해서만 가속을 제공함을 인지하고, 실무 최적화 적용 시 고전적 최적화($GPU$ 등)와 양자 연산을 결합하는 '하이브리드(NISQ 모델 등)' 접근법을 고려해야 함

## Ⅶ. 결론

- 양자 알고리즘은 물리적 한계를 양자역학의 수학적 미학으로 관통하는 계산 패러다임의 혁명이며, 설계자는 쇼어 위협에 대비한 대칭키 키 길이 확장 및 양자 내성 암호 전환을 선제 추진하고 하이브리드 연산 장치로의 실용 가능성을 타진해야 함
