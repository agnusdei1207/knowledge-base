## 미리 알고가기

- 큐비트: 0과 1의 중첩 상태를 확률 진폭으로 표현하는 양자 정보 단위임
- 중첩: 여러 계산 상태가 동시에 존재하는 양자 상태 표현임
- 간섭: 정답 경로의 진폭은 키우고 오답 경로의 진폭은 줄이는 양자 현상임
- QFT: 주기성을 진폭 분포로 드러내는 Quantum Fourier Transform임
- 오라클: 특정 후보가 정답인지 위상이나 진폭에 표시하는 양자 연산임
- 측정: 양자 상태를 고전 비트 결과로 관측해 확률적으로 하나의 결과를 얻는 과정임

## Ⅰ. 개요

- **정의**: 양자 알고리즘은 큐비트의 중첩, 얽힘, 간섭을 이용해 특정 계산 문제에서 고전 알고리즘보다 적은 단계로 해를 찾는 알고리즘이며, 쇼어와 그로버는 각각 주기 탐색과 비정렬 탐색을 대표함. 문제 구조가 양자 진폭 증폭이나 주기성 추출에 맞는지를 기준으로 암호 분석, 탐색, 최적화 가능성을 판단하기 위해 사용함
- **배경/필요성**: 고전 컴퓨터에서 어려운 소인수분해와 큰 탐색 공간 문제 일부는 양자 계산 모델에서 다른 복잡도를 가지므로 보안 체계와 알고리즘 전략을 재검토해야 함
- **비유**: 모든 후보를 무작정 하나씩 확인하는 대신, 파동의 보강·상쇄를 이용해 정답 후보가 관측될 가능성을 높이는 방식과 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 쇼어·그로버 차이 설명 | QFT 기반 주기 탐색, 진폭 증폭 | 두 알고리즘을 모두 지수 가속으로 서술 |
| 보안·복잡도 영향 설명 | RSA/ECC 위협, 탐색 이차 가속 | NP-Complete를 모두 쉽게 푼다고 오해 |

> 요약: 쇼어는 주기 구조를 이용한 지수적 가속, 그로버는 비정렬 탐색의 이차적 가속을 제공하는 대표 양자 알고리즘임

## Ⅱ. 특징/비교

| 판단 기준 | 쇼어 알고리즘 | 그로버 알고리즘 |
|:---|:---|:---|
| 대상 문제 | 소인수분해, 이산대수처럼 주기성으로 바꿀 수 있는 문제 | 정답 판별 오라클만 있는 비정렬 탐색 문제 |
| 핵심 원리 | 모듈러 지수화와 QFT로 주기를 찾음 | 오라클과 diffusion으로 정답 진폭을 증폭함 |
| 가속 유형 | 고전 대비 지수적 가속으로 알려짐 | `O(N)` 탐색을 `O(sqrt(N))`으로 줄이는 이차 가속 |
| 영향 영역 | 공개키 암호 안전성에 직접 영향 | 대칭키 탐색, 조합 탐색 일부의 보안 강도에 영향 |

> 요약: 쇼어는 구조가 있는 수론 문제를 빠르게 풀고, 그로버는 구조 없는 탐색을 제곱근 수준으로 줄이는 차이가 있음

- **복잡도 기준**: 양자 알고리즘이 모든 어려운 문제를 빠르게 푸는 것은 아니며 문제 구조가 맞아야 함
- **보안 기준**: 쇼어는 RSA/ECC 위협, 그로버는 대칭키 길이 선택에 영향을 주는 방식으로 다르게 작용함
- **운영 기준**: 현재의 오류율, 큐비트 수, 회로 깊이 제약 때문에 알고리즘과 물리 장비의 격차를 함께 봐야 함

## Ⅲ. 구성요소

```text
+-------------+      +-------------+      +-------------+
| Qubit       | ---> | Quantum     | ---> | Interference|
| Register    |      | Gates       |      | Amplitude   |
+------+------+      +------+------+      +------+------+
       |                    |                    |
       v                    v                    v
+-------------+      +-------------+      +-------------+
| Oracle /    | ---> | Measurement | ---> | Classical   |
| QFT         |      | Readout     |      | Verification|
+-------------+      +-------------+      +-------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 큐비트 레지스터 | 문제 상태를 양자 상태 공간에 표현하는 입력 저장소임 | 후보 공간 |
| 양자 게이트 | Hadamard, CNOT, phase gate 등으로 상태 진폭을 변환함 | 파동 조절기 |
| 오라클/QFT | 그로버는 정답을 표시하고, 쇼어는 주기를 드러내는 변환을 수행함 | 힌트 장치 |
| 간섭·증폭 | 정답 상태의 관측 확률을 높이고 오답 상태 확률을 낮춤 | 보강·상쇄 파도 |
| 측정·검증 | 양자 결과를 고전 비트로 읽고 후보 해의 타당성을 확인함 | 최종 확인 |

> 요약: 양자 알고리즘은 큐비트 상태를 게이트로 변환하고 오라클·QFT·간섭을 통해 정답 관측 확률을 높이는 구조임

## Ⅳ. 절차

```text
+-----------+     +-----------+     +-----------+     +-----------+
| Initialize| --> | Encode    | --> | Amplify / | --> | Measure   |
| Superpose |     | Problem   |     | QFT       |     | Verify    |
+-----------+     +-----------+     +-----------+     +-----------+
      |                 |                 |                 |
      v                 v                 v                 v
equal states       oracle/mod exp      useful amplitude  classical ans
```

1. **상태 초기화**: 큐비트에 Hadamard 등을 적용해 계산 후보 상태의 중첩을 구성함
2. **문제 인코딩**: 쇼어는 모듈러 지수화로 주기 정보를, 그로버는 오라클로 정답 후보 표시를 회로에 넣음
3. **간섭 활용**: 쇼어는 QFT로 주기 정보를 추출하고, 그로버는 diffusion 연산을 반복해 정답 진폭을 키움
4. **측정·고전 검증**: 측정 결과를 고전 후처리로 검증하고 실패 시 확률적 반복 수행으로 성공률을 높임

> 요약: 양자 알고리즘은 중첩 초기화, 문제 인코딩, 간섭 기반 진폭 조정, 측정 검증의 순서로 확률적 해를 얻음

## Ⅴ. 문제점

- **P1 오류와 결어긋남**: 큐비트가 외부 잡음에 민감해 회로가 길어질수록 상태가 무너지고 결과 신뢰도가 낮아짐
- **P2 오류 정정 오버헤드**: 유용한 논리 큐비트를 만들려면 다수의 물리 큐비트와 오류 정정 회로가 필요함
- **P3 적용 범위 오해**: 쇼어와 그로버의 가속은 특정 구조의 문제에 한정되며 모든 NP-Hard 문제의 다항 해결을 의미하지 않음

> 요약: 양자 알고리즘의 실용화는 물리 오류, 오류 정정 자원, 적용 가능한 문제 범위의 제한을 함께 관리해야 함

## Ⅵ. 개선방안

- **P1 대응**: 회로 깊이 축소, 오류 완화, 동적 디커플링, 안정적 제어 장치로 잡음 영향을 줄임 (확인: gate fidelity, coherence time)
- **P2 대응**: surface code 등 오류 정정, 논리 큐비트 아키텍처, fault-tolerant gate 설계를 단계적으로 적용함 (확인: logical error rate)
- **P3 대응**: 문제를 BQP, 탐색, 최적화, 시뮬레이션 영역으로 분류하고 고전-양자 하이브리드 알고리즘을 검토함 (확인: 고전 대비 speedup)

> 요약: 양자 알고리즘은 하드웨어 오류를 줄이고 오류 정정을 준비하며, 적용 문제를 정확히 분류해야 실질적 이점을 얻을 수 있음

## Ⅶ. 전망

- **발전 방향**: 단기에는 NISQ 기반 변분 알고리즘과 하이브리드 최적화가, 장기에는 오류 정정 기반 범용 양자 알고리즘이 발전할 전망임
- **설계 관점**: 문제 구조, 필요한 큐비트 수, 회로 깊이, 오류율, 고전 대비 이득을 기준으로 쇼어·그로버·하이브리드 알고리즘 적용을 판단해야 함
- **검증 관점**: gate fidelity, coherence time, logical error rate, 고전 대비 speedup을 함께 확인해야 양자 이점 주장을 검증할 수 있음
- **운영 관점**: 큐비트 보정, 잡음 완화, 실험 반복 수, 클라우드 QPU 비용을 관리해야 결과 신뢰도와 실행 비용을 통제할 수 있음
- **적용 관점**: 쇼어는 공개키 암호 전환 계획을, 그로버는 대칭키 보안 강도와 탐색 전략을 재평가하는 기준으로 우선 활용해야 함
- **보안·신뢰 관점**: 충분한 오류 정정 양자컴퓨터는 RSA/ECC 장기 기밀성을 약화시킬 수 있으므로 PQC 전환과 암호 자산 목록화가 필요함
- **기술사 제언**: 답안에서는 양자 가속을 일반론으로 쓰지 말고 쇼어의 주기 탐색과 그로버의 진폭 증폭, 적용 한계를 분리해 설명해야 함
