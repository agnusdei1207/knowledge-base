## Ⅰ. 개요
- **정의**: NP-Hard 문제에 대해 다항 시간 내 수학적으로 보장된 근사비(ρ) 이내의 차선해를 산출하는 알고리즘임
- **배경/필요성**: P≠NP가 유력한 상황에서 정확해 도출이 비현실적이므로, 오차 한계가 증명된 실용적 해법이 필수임
- **비유**: 100점 만점을 보장할 수 없을 때, 최소 80점 이상(근사비 1.25)을 수학적으로 약속하는 전략과 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 휴리스틱과 근사 알고리즘의 차이 | 근사비 ρ의 수학적 증명 유무가 본질적 차이 | 휴리스틱을 근사 알고리즘이라 부르면 감점 |
| PTAS/FPTAS 개념 | ε 값에 따라 근사비 조절 가능한 체계 | PTAS vs FPTAS 시간 복잡도 차이 명시 필요 |

> 요약: 휴리스틱과 달리 최적해 대비 오차 상한이 수학적으로 증명된 다항 시간 해법임

## Ⅱ. 구성요소
```text
+----------+     +-----------+     +-----------+     +----------+
| Obj Func | --> | Poly Algo | --> | Approx Sol| --> | Ratio Prf|
+----------+     +-----------+     +-----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 목적 함수 | 최소화/최대화할 비용·이익 수식(예: TSP 경로 길이) | 점수 기준 |
| 다항 시간 알고리즘 | Greedy·LP Relaxation·Primal-Dual 등 전략 | 풀이 도구 |
| 근사해 | 알고리즘이 산출한 차선해 값 ALG | 실제 점수 |
| 근사비 증명 | ALG/OPT ≤ ρ (최소화) 또는 OPT/ALG ≤ ρ (최대화) 보장 | 보증서 |

> 요약: 목적 함수 정의 → 다항 알고리즘 적용 → 근사해 산출 → 근사비 ρ 수학적 증명의 4요소임

## Ⅲ. 절차
```text
+----------+    +----------+    +----------+    +----------+
| Model    | -> | Solve    | -> | Get ALG  | -> | Prove rho|
+----------+    +----------+    +----------+    +----------+
```

1. **모델링** — NP-Hard 문제를 정수 계획법(ILP) 또는 그래프 형태로 정형화함
2. **이완/전략 적용** — LP 이완으로 하한(Lower Bound) 확보 후 라운딩, 또는 Greedy 전략 수행
3. **근사해 도출** — O(n^k) 시간 내에 차선해 ALG를 산출함
4. **근사비 증명** — ALG와 OPT 간 비율이 ρ 이내임을 수학적으로 증명하여 품질 보장함

> 요약: ILP 모델 → LP 이완/Greedy → 다항 시간 해 산출 → 근사비 증명의 4단계 절차임

## Ⅳ. 문제점
- **근사비 증명 난이도**: 특정 문제(예: 일반 TSP)는 P≠NP 가정 하 상수 근사비 알고리즘이 존재 불가함
- **대규모 입력 지연**: n > 10^6 규모에서 O(n^3) 이상 복잡도의 근사 알고리즘도 실시간 응답 불가
- **문제 특수성 종속**: 범용 근사 전략이 부재하여 문제마다 개별 알고리즘 설계·증명이 필요함

> 요약: 근사비 증명의 이론적 한계, 대규모 데이터 지연, 문제별 개별 설계 부담이 3대 문제점임

## Ⅴ. 개선방안
1. 단기: Greedy 기반 2-근사(Vertex Cover 등) 알고리즘으로 즉시 적용 가능한 해법 확보
2. 중기: PTAS/FPTAS 적용으로 ε 파라미터 조절을 통해 정밀도-속도 트레이드오프 최적화
3. 장기: 강화학습 기반 조합 최적화(RL-CO) 모델로 문제 구조를 자동 학습하여 범용 근사 해법 도출

- **근사비 증명 난이도**: 이론적 불가 → PTAS 적용 가능 문제 식별 후 ε 조절 (지표: ρ ≤ 1+ε)
- **대규모 입력 지연**: 단일 연산 → 분산 병렬 처리(MapReduce) 적용 (지표: 10^6 입력 10초 내 응답)
- **문제 특수성 종속**: 수작업 설계 → GNN 기반 자동 해법 생성 연구 (지표: 신규 문제 적용 시간 50% 단축)

> 요약: Greedy 즉시 적용 → PTAS 정밀 조절 → RL/GNN 자동화의 3단계로 근사 해법을 고도화함

## Ⅵ. 전망
- **향후 발전 방향**: GNN·Transformer 기반 Neural Combinatorial Optimization이 TSP 10^4 노드급에서 1% 이내 최적해 근사를 시연 중
- **기술사적 판단**: 수학적 근사비 보장과 ML 기반 자동 해법은 상호 보완적이며, 이론+실무 병행이 필수임
- **기술사 제언**: NP-Hard 문제 대면 시 먼저 근사비 존재 여부(이론적 한계)를 확인 후 전략을 선택해야 함
