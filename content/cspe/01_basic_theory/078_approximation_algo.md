## 미리 알고가기

- 최적해($Optimal$ $Solution$): 목적 함수의 값을 극대화하거나 극소화하는 가장 완벽한 유일무이한 해답임
- 근사 해($Approximated$ $Solution$): 최적해는 아니지만, 다항 시간 내에 효율적으로 구해진 상당히 정확하고 양호한 해답임
- 근사비($Approximation$ $Ratio$, $\rho$): 알고리즘이 찾아낸 해와 수학적 최적해 사이의 품질 비율로, 최악의 경우에도 이 비율 이하의 성능은 보장한다는 한계선임
- 선형 계획법 완화($LP$ $Relaxation$): 의사결정 변수가 정수여야 하는 어려운 정수 계획법($IP$) 문제를, 소수점 값을 허용하는 쉬운 선형 계획법($LP$) 문제로 변환하여 푸는 기법임

## Ⅰ. 개요

- **정의/개념**: 근사 알고리즘은 최적해를 찾는 것이 수학적으로 극히 어려운 $NP-hard$ 최적화 문제에 대해, 다항 시간($Polynomial$ $Time$) 내에 작동하면서 동시에 최종 품질이 최적해 대비 특정 오차 범위(근사비) 이내에 있음이 증증되는 합리적 대안 알고리즘임
- **배경/필요성**: 현실 산업의 화물 배차 스케줄링, 통신 기지국 최소 커버리지 배치 등은 모두 조합 최적화 난제들이며, 물리적 시간 한계를 극복하고 실행 가능한 시스템을 가동하기 위해 도입됨

## Ⅱ. 특징

- 단순히 감과 경험에 의존하여 성능을 보장할 수 없는 '휴리스틱($Heuristic$)'과 달리, 수학적 증명(예: 탐욕법의 한계 등)을 통해 최악의 경우에도 해의 품질이 보장되는 신뢰성이 존재함
- 다항 시간 복잡도($O(n^2), O(n \log n)$ 등)를 가지므로, 대규모의 실무 변수 입력 데이터셋이 주어지더라도 병목 없이 즉각적인 의사결정이 가능함
- 정수 제약을 실수 범위로 확장하는 선형 완화($LP$ $Relaxation$) 및 반올림($Rounding$), 탐욕 알고리즘($Greedy$) 등 정밀한 수학적 설계 기법들을 활용함

## Ⅲ. 종류 및 비교

| 판단 기준 | 정확 알고리즘 (Exact) | 근사 알고리즘 (Approximation) | 휴리스틱 (Heuristic) |
|:---|:---|:---|:---|
| **최적해 탐색** | 100% 최적해 보장함 | 최적해 보장 못 함 | 최적해 보장 못 함 |
| **품질 수학적 보장** | 완전함 | 수학적으로 증명된 한계 경계선($\rho$) 있음 | 보장 한계선 없음 (경험적 우수성) |
| **실행 시간 복잡도** | 지수 시간 이상 ($O(2^n)$) | 다항 시간 ($O(n^k)$) | 극도로 빠름 ($O(n)$ 수준 다수) |
| **대표 기법** | 동적 계획법, 분기 한정법 | $LP$ 라운딩, 탐욕적 할당 | 유전 알고리즘, 담금질 기법 |

> 요약: 정확 알고리즘은 성능만 보고, 휴리스틱은 속도만 보며, 근사 알고리즘은 수학적 보장 하에 둘의 조화를 꾀함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 목적 함수 | 알고리즘을 통해 최소화(예: 운송 거리)하거나 최대화(예: 선적 용량)하고자 하는 실질적 수치 지표임 |
| 근사비 ($\rho$) | $Optimal / Approx$ (또는 역수)로 정의되며, 1에 가까울수록 정밀도가 높은 알고리즘임 |
| 결정성 결정 규칙 | 매 단계마다 어떤 요소를 우선적으로 채택해 나갈지 규정하는 탐욕 지표임 |
| $PTAS$ | 사용자가 원하는 허용 오차 $\epsilon$을 주면 $O(n^{3/\epsilon})$ 등 다항 시간 내에 근사해를 찾아주는 체계임 |

```text
[ 외판원 문제 (TSP) 2-근사 알고리즘 작동 흐름 ]
1. 입력 그래프의 최소 신장 트리 (MST) 생성 -> 2. 트리 노드를 중복 없이 방문하는 오일러 경로 생성
- 이를 통해 도출된 경로는 최적 TSP 경로 길이의 최대 2배 이내임이 수학적으로 항상 보장됨
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 문제 수식화 | --> | 제약조건 완화| --> | 다항 해 계산| --> | 근사비 검증  |
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **상태 정의** — 최적화하려는 대상인 비용 함수와 제약 조건들을 수학적 관계식(정수 계획법 등)으로 정식 기술함
2. **연산 완화** — 변수를 실수 범위로 변경하는 선형 계획 완화(LP Relaxation)를 수행하여, 수학적으로 빠르게 풀 수 있는 상태로 난이도를 조정함
3. **해의 가공** — 완화된 연산 결과로 나온 소수점 값들을 인접 정수로 내림/올림하는 라운딩($Rounding$) 기법이나 탐욕 규칙을 적용하여 물리적으로 유효한 근사해를 도출함
4. **한계 증명** — 도출된 해가 어떤 입력 값에 대해서도 수학적 전역 최적해와 비교해 얼마의 오차비($\rho$) 이상 벌어지지 않음을 수학적으로 입증함

## Ⅵ. 실무 적용 및 유의점

1. 근사 알고리즘 설계 시 이론적 근사비가 아무리 우수해도, 선형 완화($LP$) 풀이 과정에서 고차원 행렬 연산 비용이 추가로 들어가면 단순 휴리스틱보다 연산 속도가 심각하게 지연될 수 있으므로, 실시간 대규모 트래픽 환경에서는 가벼운 '탐욕 기반 근사 모델'을 채택해야 함
2. 비즈니스 현실의 동적 제약 조건(예: 차량 주행 시간 법적 규제 등)이 추가되면 순수한 수학적 근사 모델이 작동하지 않으므로, 근사 알고리즘으로 대략적인 전역 가이드라인을 잡은 뒤 '지역 탐색($Local$ $Search$)' 휴리스틱을 붙여 세부 제약을 맞추는 하이브리드 조합이 권장됨

## Ⅶ. 결론

- 근사 알고리즘은 타협의 선을 수학의 논리로 규정하여 실질적 비즈니스를 작동하게 만드는 절제된 엔지니어링의 정수이며, 설계자는 이론적 품질 보장 강도와 계산 복잡도의 타협점을 통찰하여 최선의 지능 서비스를 현업에 배포해야 함
