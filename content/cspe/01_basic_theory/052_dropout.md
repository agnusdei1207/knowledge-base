# 📖 【암기용】 개념 완전 이해

## 한눈에
- **개요**: 딥러닝 모델 학습 시 무작위로 신경망의 일부 뉴런을 비활성화하여 과적합(Overfitting)을 방지하는 정규화(Regularization) 기법.
- **왜 필요한가**: 모델이 훈련 데이터의 특정 노드나 패턴에만 과도하게 의존하는 동조 현상(Co-adaptation)을 깨뜨리기 위해 필요.
- **핵심 직관**: 조별과제에서 매번 랜덤하게 팀원 1~2명을 빼고 발표를 시키면, 소수 에이스에만 의존하지 못하고 모든 팀원이 발표 실력을 골고루 키우게 되는 훈련법.

## 핵심 용어 정리

| 용어/표기 | 의미 | 비유·예 |
|:---|:---|:---|
| 보존 확률 (p) | 개별 뉴런이 비활성화되지 않고 살아남을 확률 (통상 0.5) | 조별과제에 참가할 팀원 출석 확률 |
| 동조 현상 (Co-adaptation) | 특정 가중치들끼리만 상호작용하며 복잡한 관계를 맺어 훈련 데이터에 억지로 맞추는 현상 | 에이스 한 명에게만 과제를 전담시키는 꼼수 |
| 기댓값 보정 (Scaling) | 추론(Test) 시에는 모든 뉴런을 켜므로, 출력값이 학습 때보다 p배 커지는 것을 맞추기 위해 출력을 보정하는 과정 | 실전에서 전원이 참가하면 화력이 세지니 비율을 맞추는 것 |

## 깊이 이해
- **배경·문제의식**: 심층 신경망은 파라미터가 매우 많아 훈련 데이터의 노이즈까지 암기해버리는 과적합에 취약함. 기존 L1, L2 정규화만으로는 복잡한 비선형 관계의 과적합을 막기 어려움.
- **작동 원리**: 매 미니배치 학습(Forward/Backward)마다 뉴런 단위로 베르누이 확률 분포(p)를 적용해 랜덤하게 0으로 만듦. 이로 인해 모델은 매번 다른 얇은 형태의 부분 신경망(Sub-network)을 학습하게 되며, 이 수많은 서브 네트워크들의 결과를 평균 내는 앙상블(Ensemble) 효과를 얻음.
- **비유**: 숲을 지날 때 한 가지 길(특정 특징)만 외워서 가면 길이 막혔을 때 길을 잃음. 드롭아웃은 매번 다른 길목을 무작위로 막아버려 전체 숲의 지형을 골고루 파악하게 강제함.
- **구체 예시**: 이미지 분류에서 호랑이를 판별할 때, 줄무늬에만 100% 의존하는 모델은 줄무늬가 가려지면 실패함. 줄무늬 노드를 드롭아웃하면 이빨, 꼬리 등 다른 특징도 어쩔 수 없이 학습하게 됨.
- **흔한 오해·주의점**: 드롭아웃은 '학습 단계'에서만 적용됨. 실 서비스(추론 단계)에서는 모든 뉴런을 활성화(확률 1.0)하여 예측해야 함. 이때 활성화된 뉴런이 늘어난 만큼 출력 스케일(Scale)을 보정해주어야 함.

## 연결 개념
- **앙상블 학습 (Ensemble Learning)**: 여러 모델의 예측을 합쳐 일반화 성능을 높이는 기법(랜덤 포레스트 등). 드롭아웃은 하나의 네트워크로 기하급수적인 수의 모델을 앙상블하는 효과.

# 📝 【답안용】 시험 답안 템플릿

## 핵심 인사이트 (3줄 요약)
> 1. **본질**: 학습 시 무작위 뉴런 비활성화를 통한 신경망 정규화(Regularization) 알고리즘
> 2. **가치**: 특정 노드 의존성(Co-adaptation) 파괴 및 기하급수적 서브 네트워크 앙상블 효과 달성
> 3. **판단 포인트**: 완전연결층(FC)의 과적합 방지에 탁월하나, 학습 시간 증가와 추론 시 스케일 보정 주의 필요

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 딥러닝 과적합 해결 방법과 앙상블 효과 이해 | 동조 현상 억제, 보존 확률(p), 추론 시 스케일링 복원 | 학습 시 누락 기법만 쓰고 추론(Test) 시 처리 누락 단정 |

> 요약: 무작위 노드 차단으로 가중치 분산을 유도하고, 앙상블 효과로 일반화 성능을 극대화하는 정규화 기술

---

## Ⅰ. 개요 및 필요성
- 개요: 심층 신경망 훈련 시 일정 확률(p)로 은닉층 노드를 무작위 비활성화하여 과적합을 방지하는 정규화 기법
- 배경: 과도한 파라미터로 인해 모델이 훈련 데이터의 지엽적 노이즈까지 암기하는 특정 특징 동조 현상(Co-adaptation) 심화
- 필요성: 강력한 정규화, 단일 네트워크로 다수 모델의 앙상블(Ensemble) 효과 창출, 일반화(Generalization) 성능 개선 필요

---

## Ⅱ. 구조 및 구성요소

```text
전체 신경망 유입 -> [베르누이 마스킹(p)] -> 서브 네트워크 구성 -> 순전파/역전파 -> 가중치 갱신
                                              |
                                              +-> 매 미니배치마다 구조 무작위 변경
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 베르누이 난수 생성 | 각 뉴런을 확률 p로 유지, (1-p)로 버림 결정 | 은닉층 통상 0.5, 입력층 통상 0.8 확률 사용 |
| 바이너리 마스크 | 생성된 난수에 따라 노드의 출력값을 0으로 치환 | 활성화 함수 통과 직후에 마스크 행렬 곱셈 적용 |
| 부분 신경망 (Sub-network) | 차단된 노드를 제외하고 구성된 얇은 네트워크 | 매 훈련 반복(Iteration) 시 서로 다른 구조 생성 |
| 스케일러 (Scaler) | 추론 시 모든 노드 활성화에 따른 기댓값 보정 | 출력값에 확률 p를 곱하거나 학습 시 미리 분할 |

> 요약: 매 학습마다 난수로 뉴런을 차단하여 서브 네트워크를 생성하고, 추론 시에는 출력을 보정하여 예측을 수행하는 구조

---

## Ⅲ. 동작원리 및 흐름도

```text
[학습 모드] 노드 난수(p) 선별 -> 가중치 연산 제외 -> 오차 역전파 -> [추론 모드] 노드 100% 활성화 -> 출력 기댓값 보정
```

- 1단계 [은닉 노드 차단]: 각 미니배치 순전파 단계에서 지정된 보존 확률(p)에 따라 0 또는 1의 마스크 생성
- 2단계 [서브넷 학습]: 비활성화(출력 0)된 노드는 순전파는 물론 역전파 가중치 업데이트에서도 배제
- 3단계 [구조 변경]: 다음 미니배치 유입 시 새로운 난수를 생성하여 완전히 다른 구조의 서브넷 반복 학습
- 4단계 [기댓값 보정 추론]: 실 배포 시에는 모든 노드를 사용하며, 출력값에 보존 확률 p를 곱해 훈련 시와 신호 강도 스케일링 유지

> 요약: 학습 시에는 랜덤 마스킹으로 앙상블 학습을 모사하고, 추론 시에는 모든 노드를 사용하여 기댓값을 동일하게 맞춤

---

## Ⅳ. 특징
- [동조 현상 회피]: 가중치가 특정 노드 조합에 편중되는 것을 막아 튼튼하고 독립적인 특징 추출 강제
- [앙상블 효과 달성]: 노드가 N개일 때 2^N 개의 모델을 훈련하여 결합하는 것과 유사한 일반화 효과 획득
- [학습 수렴 시간 증가]: 파라미터 업데이트 횟수가 분산되므로 Dropout 미적용 대비 학습 소요 시간 2~3배 증가
- [손실 함수 해석 난해]: 매번 네트워크가 변하므로 손실(Loss) 값이 단조 감소하지 않고 노이즈가 발생함

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | Dropout | L1 / L2 Regularization | Batch Normalization |
|:---|:---|:---|:---|
| 제어 방식 | 네트워크 노드(구조) 무작위 삭제 | 손실 함수에 가중치 페널티 항 추가 | 입력 데이터의 분포를 정규분포로 변환 |
| 과적합 방지 원리 | 동조 억제 및 앙상블 효과 | 가중치(Weight) 크기 최소화 | 노이즈 혼입 및 초기 분포 최적화 |
| 최적 적용 대상 | 파라미터가 많은 완전연결층(FC) | 모델 전반의 가중치 제한 | CNN, RNN 등 모델 깊이에 따른 수렴 개선 |

**리스크·대응:**
- [수렴 속도 지연]: 너무 낮은 p 확률 부여로 업데이트되는 파라미터 급감 → 초기에는 p를 높게 설정하고 에포크에 따라 점진적 감소 (지표: 에포크당 Train Loss 하락폭)
- [공간 정보 손실]: 합성곱 신경망(CNN)의 특성 맵에 일반 드롭아웃 적용 시 픽셀 단위 노이즈로 작용 → 채널(Channel) 전체를 끄는 Spatial Dropout 적용 (지표: 모델 검증 정확도)

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. [레이어별 확률 분리]: 피처 보존이 중요한 입력층은 p=0.8~0.9로 높게 설정하고, 과적합이 쉬운 완전연결층(FC)은 p=0.5를 부여하여 효율성 극대화
2. [MC Dropout 적용]: 자율주행이나 의료진단 등 불확실성 측정이 중요한 분야에서는 추론 시에도 드롭아웃을 켜서 분산을 측정(Monte Carlo Dropout)하여 신뢰도 확보
3. [대체 기법 혼합]: 최신 CNN 아키텍처(ResNet 등)에서는 완전연결층을 최소화하고, 드롭아웃 대신 Batch Normalization의 내재적 정규화 효과로 대체 설계

**결론:**
- 기술사 판단: 파라미터가 밀집된 구조에서는 핵심 과적합 방지책이나, CNN에서는 공간적 의미 보존을 위해 Spatial 버전을 쓰거나 배치 정규화로 대체하는 것이 효율적임
- 향후 방향: 정적 확률이 아닌 학습 진행도 및 노드 중요도를 스스로 판단하여 확률을 조절하는 Adaptive Dropout 기반으로 진화할 것
