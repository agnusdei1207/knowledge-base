## 미리 알고가기

- 정규화: 모델이 학습 데이터에 과하게 맞는 것을 줄이는 제약 기법임
- 드롭 확률: 훈련 중 뉴런 또는 연결을 비활성화할 확률임
- Inverted Dropout: 훈련 때 남은 출력값을 보정해 추론 시 별도 스케일 조정이 필요 없게 하는 방식임
- 공적응: 특정 뉴런들이 서로에게 과하게 의존해 일반화 성능이 낮아지는 현상임
- 앙상블 효과: 여러 부분 모델의 평균처럼 동작해 예측 변동을 줄이는 효과임

## Ⅰ. 개요

- **정의**: 드롭아웃은 훈련 단계에서 뉴런 또는 특징 연결을 확률 기준으로 임시 비활성화해 특정 경로 의존을 줄이고 일반화 성능을 높이는 신경망 정규화 기법임
- **배경/필요성**: 파라미터가 많은 신경망은 학습 데이터의 우연한 패턴과 노이즈까지 외우기 쉬우므로, 학습 중 다양한 부분 네트워크를 강제로 경험하게 할 필요가 있음
- **비유**: 매번 일부 팀원이 빠진 상태로도 일을 완수하게 훈련해 특정 사람에게만 의존하지 않게 하는 방식과 같음

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 과적합 억제 원리 | 확률적 비활성화, 공적응 방지 | 추론 시 동작 차이 누락 |
| 적용 조건 판단 | 드롭 확률, 네트워크 위치, BatchNorm 관계 | 무조건 성능 향상으로 설명 |

> 요약: 드롭아웃은 훈련 중 일부 뉴런을 무작위로 끄면서 모델이 더 분산된 특징 표현을 학습하게 하는 정규화 방법임.

## Ⅱ. 특징/비교

| 판단 기준 | L2·데이터 증강 | Dropout |
|:---|:---|:---|
| 제약 방식 | 가중치 크기나 입력 데이터 다양성에 제약을 줌 | 네트워크 내부 경로를 확률적으로 제거함 |
| 적용 효과 | 매끄러운 결정 경계와 입력 변화 견고성을 높임 | 뉴런 공적응을 줄이고 암묵적 앙상블 효과를 냄 |
| 적용 위치 | 대부분 모델과 데이터 전처리에 넓게 적용 가능함 | 완전연결층, 일부 CNN/RNN 구조에 신중히 적용함 |
| 선택 조건 | 데이터 변형이나 가중치 제약이 직접적일 때 적합함 | 파라미터가 많고 과적합이 확인된 신경망에 적합함 |

> 요약: Dropout은 입력이나 가중치가 아니라 학습 중 활성화 경로를 흔들어 과적합을 줄이는 방식임.

- **입력 조건**: 과적합 증거가 있고 모델이 일부 경로 제거를 견딜 만큼 충분한 용량을 가져야 함
- **평가 기준**: 학습·검증 손실 차이와 추론 안정성을 함께 확인함
- **선택 판단**: 완전연결층 또는 과적합이 강한 신경망에서 우선 비교함

## Ⅲ. 구성요소

```text
+------------+      +------------+      +------------+
| 층 출력 h   | ---> | 마스크 생성 | ---> | 일부 비활성 |
+------------+      +------------+      +------------+
       |                  |                  |
       v                  v                  v
+------------+      +------------+      +------------+
| 드롭 확률   |      | 스케일 보정 |      | 다음 층 입력 |
+------------+      +------------+      +------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 층 출력 | Dropout 적용 대상이 되는 뉴런 활성화 값임 | 참여 중인 팀원 |
| 드롭 확률 | 각 뉴런을 끌 확률로 정규화 강도를 조절함 | 결근 확률 |
| 무작위 마스크 | 훈련마다 다른 뉴런을 남기거나 제거하는 이진 패턴임 | 임시 근무표 |
| 스케일 보정 | 남은 활성화 값의 기대 크기가 유지되도록 조정함 | 업무량 재분배 |
| 추론 경로 | 추론 단계에서는 모든 뉴런을 사용해 안정적인 예측을 수행함 | 전체 인원 투입 |

> 요약: 드롭아웃은 드롭 확률과 무작위 마스크로 훈련 경로를 바꾸고 스케일 보정으로 출력 크기를 유지함.

## Ⅳ. 절차

```text
+------------+      +------------+      +------------+      +------------+
| 확률 설정   | ---> | 마스크 적용 | ---> | 가중치 학습 | ---> | 추론 전환   |
+------------+      +------------+      +------------+      +------------+
```

1. **확률 설정**: 층 위치와 과적합 정도를 보고 드롭 확률을 정함
2. **마스크 적용**: 훈련 배치마다 무작위 마스크를 생성해 일부 활성화를 0으로 만듦
3. **가중치 학습**: 남은 경로만으로 손실을 계산하고 역전파를 수행해 의존도를 분산함
4. **추론 전환**: 평가·운영 모드에서는 Dropout을 끄고 보정된 전체 네트워크로 예측함

> 요약: Dropout은 훈련 중에만 확률적으로 경로를 제거하고 추론 시에는 전체 경로를 사용하도록 전환해야 함.

- **산출물**: 무작위 마스크, 보정된 활성화 값, 추론 모드 예측값임
- **검증 기준**: 추론에서 동일 입력의 결과가 안정적으로 재현되어야 함
- **운영 기록**: 드롭 확률, 적용 층, train/eval 모드 전환 기준을 남겨야 함

## Ⅴ. 문제점

- **P1 과도한 정규화**: 드롭 확률이 높거나 작은 모델에 적용하면 필요한 표현까지 제거되어 과소적합이 발생함
- **P2 훈련·추론 모드 오류**: 추론 시 Dropout이 켜져 있거나 스케일 보정이 맞지 않으면 예측이 매번 달라지고 성능이 낮아짐
- **P3 구조별 부적합**: CNN 공간 구조나 RNN 시간 의존성을 무작위로 끊으면 중요한 패턴 학습이 방해될 수 있음

> 요약: Dropout은 과적합을 줄이지만 확률, 모드 전환, 적용 위치가 맞지 않으면 성능을 오히려 떨어뜨림.

## Ⅵ. 개선방안

- **P1 대응**: 검증 성능 기준으로 드롭 확률을 낮추거나 L2, 데이터 증강, 조기 종료와 비교함 (확인: 학습·검증 손실 동시 추세)
- **P2 대응**: train/eval 모드 전환과 Inverted Dropout 구현을 테스트함 (확인: 동일 입력 반복 추론 결과 안정성)
- **P3 대응**: CNN에는 Spatial Dropout, RNN에는 Variational Dropout처럼 구조를 보존하는 변형을 적용함 (확인: 구조별 검증 성능)

> 요약: Dropout 개선은 정규화 강도를 검증 데이터로 조절하고 모델 구조에 맞는 변형을 선택하는 것임.

- **우선순위**: 드롭 확률 과다 여부와 추론 모드 오류를 먼저 확인함
- **확인 지표**: 학습-검증 손실 차이, 반복 추론 변동, 층별 활성화 비율을 사용함
- **재평가 조건**: BatchNorm 추가, 모델 구조 변경, 데이터 규모 증가 시 적용 여부를 다시 판단함

## Ⅶ. 전망

- **발전 방향**: Dropout은 완전연결층과 작은 데이터 학습에서 여전히 유용하지만, 대규모 데이터와 정규화·증강 기법이 강한 구조에서는 선택적으로 사용됨
- **기술사적 판단**: 기술사는 Dropout 적용 여부를 관성적으로 정하지 않고 과적합 증거, 모델 크기, BatchNorm과의 상호작용을 확인해야 함
- **기술사 제언**: 향후 Dropout은 불확실성 추정, 베이지안 신경망 근사, 구조적 마스킹 기법과 결합해 정규화 이상의 역할로 활용될 것임
