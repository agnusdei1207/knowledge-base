## 미리 알고가기

- 뉴런 마스킹: 일부 뉴런 출력을 임의로 0으로 만드는 처리임
- ensemble effect: 여러 부분 모델을 평균 내는 효과임
- keep probability: 뉴런을 유지할 확률임

## Ⅰ. 개요

- **정의/개념**: 드롭아웃은 학습 중 일부 뉴런을 확률적으로 비활성화해 특정 연결에 대한 과도한 의존을 줄이고 일반화 성능을 높이는 정규화 기법임
- **배경/필요성**: 신경망이 훈련 데이터 세부 패턴에 지나치게 맞춰지는 과적합을 줄이기 위한 간단한 구조적 규제가 필요함

## Ⅱ. 특징

- 뉴런 공적응을 줄여 더 견고한 표현을 학습하게 함
- 구현이 단순하고 다양한 네트워크에 쉽게 적용 가능함
- 앙상블과 유사한 일반화 향상을 기대할 수 있음
- 과도한 비율은 학습을 느리게 하거나 표현력을 과도하게 낮춤

## Ⅲ. 종류 및 비교

| 판단 기준 | Dropout | Weight Decay | BatchNorm |
|:---|:---|:---|:---|
| 규제 방식 | 뉴런 무작위 제거 | 가중치 크기 제약 | 분포 안정화 |
| 주요 효과 | 과적합 완화 | 모델 단순화 | 학습 안정 |
| 추론 시 동작 | 비활성화 안 함 | 동일 | running stats 사용 |
| 대표 적용 | MLP, 일부 CNN | 범용 | 깊은 모델 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| dropout rate | 제거할 확률이며 규제 강도를 정함 |
| 마스크 | 뉴런 활성/비활성 여부이며 배치마다 새로 생성됨 |
| 스케일 보정 | 기대 출력 크기를 맞춤 학습-추론 일관성 유지 |
| 적용 위치 | 주로 은닉층이며 출력층 과도 적용은 주의함 |

```text
+---------------+     +-----------+     +-----------+     +-----------+
| dropout rate    | --> | 마스크      | --> | 스케일 보정  | --> | 적용 위치    |
+---------------+     +-----------+     +-----------+     +-----------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 활성계산 | --> | 마스크생성 | --> | 일부제거 | --> | 스케일보정 |
+----------+     +----------+     +----------+     +----------+
```

1. **활성계산**: 은닉층 활성값을 구함
2. **마스크생성**: keep probability에 따라 마스크를 뽑음
3. **일부제거**: 선택된 뉴런 출력을 0으로 만듦
4. **스케일보정**: 기대값이 유지되도록 출력을 보정함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 너무 큰 dropout은 underfitting을 유발해 표현력이 크게 줄어듦
   - 해결방안: 층별 비율을 조정하고 validation으로 찾음 train/val loss로 검증함
2. 문제: BatchNorm과 조합 시 효과가 약해질 수 있어 둘의 규제 방식이 충돌할 수 있음
   - 해결방안: 위치와 비율을 줄여 실험적으로 조정하고 accuracy delta로 검증함
3. 문제: 추론과 학습 모드 혼동이 발생해 eval 모드 누락 시 결과가 흔들림
   - 해결방안: 추론 파이프라인에서 dropout off를 강제하고 inference reproducibility로 검증함

## Ⅶ. 적용 사례

- MLP 분류기에서는 fully connected 층 과적합을 완화함, 확인 지표는 validation accuracy임
- NLP 모델에서는 embedding 또는 classifier head에 적용함, 확인 지표는 F1과 일반화 차이임
- 의료 영상 모델에서는 데이터 수가 적을 때 규제로 활용함, 확인 지표는 overfitting gap임

## Ⅷ. 결론

드롭아웃의 핵심은 모델을 약하게 만드는 것이 아니라 특정 연결 의존성을 분산시키는 데 있으므로, 비율은 항상 일반화 개선 기준으로 조정해야 함.
