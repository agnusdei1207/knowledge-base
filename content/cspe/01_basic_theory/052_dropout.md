# 052. 드롭아웃 (Dropout)

## Ⅰ. 개요

- **정의/개념**: 딥러닝 모델 학습 시 매 스텝마다 설정된 확률(p)에 따라 무작위로 일부 뉴런을 비활성화(출력을 0으로 설정)하여 특정 뉴런 조합에 대한 과도한 의존성을 배제하는 규제(Regularization) 기법임
- **배경/필요성**: 신경망의 파라미터가 방대해질수록 학습 데이터에만 과하게 적합되는 과적합(Overfitting)과 특정 뉴런들끼리 서로 동조하여 학습되는 공동 적응(Co-adaptation) 현상을 방지하고 일반화 성능을 높이기 위해 필수적임

## Ⅱ. 특징 및 비교

| 판단 기준 | Dropout | L2 Regularization (Weight Decay) | Data Augmentation |
|:---|:---|:---|:---|
| **작동 방식** | 뉴런 출력의 확률적 차단 | 손실 함수에 가중치 제곱합 추가 | 입력 데이터의 인위적 변형/증강 |
| **장점** | 앙상블 효과, 공동 적응 방지 | 가중치 크기 제어로 모델 단순화 | 데이터 부족 해결, 불변성 학습 |
| **단점** | 학습 시간 증가, 추론 시 모드 전환 필요 | 하이퍼파라미터(λ) 민감도 높음 | 도메인 지식 의존적, 노이즈 유입 가능 |
| **주요 위치** | Fully Connected Layer 뒤 | 손실 함수 계산 시 적용 | 모델 입력단(Input Layer) |

> 요약: 드롭아웃은 네트워크 구조 자체에 무작위성을 부여하여 강력한 규제 효과와 암묵적 앙상블 효과를 동시에 제공함

## Ⅲ. 구성요소/구조

- **구성요소**:
  - **Dropout Rate (p)**: 학습 시 비활성화할 뉴런의 비율(일반적으로 0.2~0.5 사용)임
  - **Bernoulli Mask**: 각 뉴런의 활성화 여부를 결정하는 0과 1로 구성된 무작위 행렬임
  - **Inverted Dropout**: 추론 시 전체 뉴런을 사용하되 학습 시 생존 확률(1-p)로 출력을 나누어 기댓값을 보정하는 방식임
  - **Train/Inference Mode**: 학습 시에는 마스크를 적용하고, 추론 시에는 모든 뉴런을 활성화하는 상태 전환 메커니즘임

- **구조도**:
```text
[학습 모드 (Training)]             [추론 모드 (Inference)]
   (O) (X) (O) (O)                    (O) (O) (O) (O)  <-- 전체 뉴런 활성
    \  /   /   /                       |   |   |   |
     \ /   /   /                       |   |   |   |
    (X) (O) (X) (O)  <-- 무작위 차단    (O) (O) (O) (O)
      \ |   /   /                      |   |   |   |
       \|  /   /                       |   |   |   |
       [Output]                       [Output * (1-p)] <-- 기댓값 보정
```

## Ⅳ. 문제점 및 개선방안

1. **[학습 속도 저하]**: 매 스텝마다 마스크를 생성하고 뉴런을 차단하므로 수렴까지 필요한 에포크 수가 증가함
   - **개선방안**: 학습 초기에는 낮은 p를 사용하다 점진적으로 높이거나, 배치 정규화(BN)를 병행하여 학습 안정성을 높임 (확인: 수렴 속도)
2. **[배치 정규화(BN)와의 조화]**: Dropout에 의한 뉴런 비활성화가 BN의 배치 통계량을 왜곡시켜 성능이 저하되는 'Disharmony' 현상 발생 가능
   - **개선방안**: BN 뒤에 Dropout을 배치하거나, 두 기능을 결합한 Gaussian Dropout 등을 검토함 (확인: 성능 지표 안정성)
3. **[불확실성 추정 한계]**: 일반적인 Dropout은 추론 시 결과가 고정되어 모델의 예측 불확실성을 알기 어려움
   - **개선방안**: 추론 시에도 Dropout을 적용하는 MC(Monte Carlo) Dropout을 사용하여 결과의 분산을 측정함 (확인: Uncertainty Score)

## Ⅴ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| **이미지 분류 (CNN)** | 마지막 Fully Connected Layer 직전에 적용하여 과적합 방지 | Train/Val Accuracy Gap |
| **자연어 처리 (BERT)** | Attention Weight 및 hidden layer 출력을 확률적으로 차단 | F1-Score, Perplexity |
| **안전 중심 AI (MC Dropout)** | 자율주행, 의료 진단 시 추론 단계에서 여러 번 수행하여 예측 신뢰도 측정 | Confidence Interval, 분산(Variance) |

> 요약: 실무에서는 모델의 깊이와 복잡도에 따라 적절한 Dropout 위치와 비율을 실험적으로 결정함

## Ⅵ. 결론

드롭아웃은 딥러닝 모델의 일반화 성능을 극대화하기 위한 가장 범용적인 규제 기법 중 하나로, 대규모 모델 학습의 필수 요소임. 최근에는 배치 정규화와의 상호작용 문제나 추론 시의 기댓값 보정 방식을 정밀하게 제어하며 사용되며, 특히 MC Dropout과 같은 기법을 통해 모델의 불확실성까지 측정하는 등 활용 범위가 넓어지고 있음.
