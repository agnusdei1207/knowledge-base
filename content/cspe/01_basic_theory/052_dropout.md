# 📖 【암기용】 개념 완전 이해

> 목적: 드롭아웃을 처음 보는 사람도 완전하게 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 학습 중 일부 뉴런을 확률적으로 끄는 과적합 억제 기법
- **왜 필요한가**:
  - 신경망이 훈련 데이터의 특정 패턴을 외우면 검증 데이터에서 오류율이 증가한다.
  - 드롭아웃은 매 학습 단계마다 다른 부분망을 학습시켜 단일 경로 의존을 줄인다.
- **핵심 직관**: 매번 다른 팀원 일부만 일하게 만들어도 결과를 맞히도록 훈련하면, 특정 뉴런 하나에 기대는 모델이 되기 어렵다.

## 깊이 이해
- **배경·문제의식**:
  - 파라미터가 수백만 개 이상인 MLP·CNN은 훈련 정확도 99%에도 검증 정확도 80% 수준으로 떨어질 수 있다.
  - 드롭아웃은 뉴런 공동적응(co-adaptation)을 줄여 일반화 오차를 낮춘다.
- **작동 원리**:
  - 학습 시 각 뉴런 출력에 베르누이 마스크를 곱한다.
  - 유지 확률이 0.5이면 평균적으로 절반의 뉴런만 활성화된다.
  - 추론 시에는 모든 뉴런을 사용하되 학습 중 스케일 보정을 적용한다.
- **비유**: 발표 준비 때 매번 다른 조원이 빠진 상태로 연습하면, 특정 한 명이 빠져도 전체 발표 구조가 유지되는 상황과 같다.
- **구체 예시**:
  - 은닉층 1,024개 뉴런에 dropout 0.5를 적용하면 한 step에서 약 512개 뉴런만 계산에 참여한다.
  - 입력층은 0.1~0.2, 은닉층은 0.3~0.5가 실무 초기값으로 쓰인다.
- **흔한 오해·주의점**:
  - 드롭아웃은 학습 단계 전용이다.
  - 추론 단계에서 드롭아웃을 켜면 요청마다 출력이 달라져 재현성이 깨진다.

## 연결 개념
- 과적합(Overfitting) — 드롭아웃이 억제하는 주요 문제
- 앙상블 학습(Ensemble Learning) — 여러 부분망 평균 효과와 관련
- L2 정규화 — 가중치 크기를 제한하는 보완 기법

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 드롭아웃(Dropout)은 학습 중 뉴런 출력을 확률적으로 제거해 부분망 앙상블 효과를 만드는 정규화 기법이다.
> 2. **가치**: 뉴런 공동적응을 줄여 훈련·검증 정확도 차이를 5%p 이하로 관리하는 일반화 통제 수단이다.
> 3. **판단 포인트**: 학습/추론 모드 분리, dropout rate, BatchNorm과의 배치 순서, 모델 구조별 적용 여부를 판단해야 한다.

---

## Ⅰ. 개요 및 필요성

- 정의: 드롭아웃은 일부 뉴런을 확률적으로 비활성화하는 기법이다.
- 배경: 대규모 신경망은 훈련 데이터를 외워 검증 오류가 커질 수 있으므로 일반화 통제가 필요하다.
- 필요성: 드롭아웃은 매 학습 step마다 다른 부분망을 만들어 과적합과 뉴런 공동적응을 줄인다.

---

## Ⅱ. 구조 및 구성요소

```text
입력/은닉 출력 -> 베르누이 마스크 생성 -> 뉴런 출력 제거
              -> 스케일 보정 -> 다음 층 전달
              +-> 추론 시 전체 뉴런 사용
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Dropout Rate | 제거할 뉴런 비율 지정 | 은닉층 0.3~0.5, 입력층 0.1~0.2 |
| 베르누이 마스크 | 뉴런별 0/1 샘플링 | 학습 step마다 새로 생성 |
| 스케일 보정 | 기대 출력 크기 유지 | Inverted Dropout은 학습 시 1/p 보정 |
| 모드 전환 | 학습과 추론 분리 | 추론 시 dropout 비활성 |

> 요약: 드롭아웃은 제거 확률, 무작위 마스크, 스케일 보정, 학습/추론 모드 분리로 구성된다.

---

## Ⅲ. 동작원리 및 흐름도

```text
학습 입력 -> 순전파 -> 마스크 적용 -> 손실 계산
-> 역전파 -> 가중치 갱신 -> 추론 시 dropout off
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | Dropout rate 설정 | validation gap 5%p 이하 목표 |
| 2 | 뉴런 출력에 마스크 적용 | 활성 뉴런 비율이 유지 확률과 일치 |
| 3 | 손실·기울기 계산 | 학습 loss 발산 0건 |
| 4 | 추론 모드 전환 | 동일 입력 출력 차이 0 또는 허용 오차 이내 |

> 요약: 드롭아웃은 학습 중 무작위 부분망으로 학습하고 추론 시 전체망으로 예측해 앙상블 평균 효과를 얻는다.

---

## Ⅳ. 특징

| 구분 | 기존 방식 | 본 기술 | 수치·판단 포인트 |
|:---|:---|:---|:---|
| 과적합 통제 | L2·Early Stopping 중심 | 뉴런 단위 무작위 제거 | 검증 gap 5%p 이하 |
| 앙상블 효과 | 여러 모델 별도 학습 | 부분망 다수 학습 효과 | 추가 모델 저장 0개 |
| 적용 비용 | 추론 비용 동일 | 학습 시 마스크 연산 추가 | GPU 이용률 변화 측정 |
| 한계 | 구조 영향 적음 | RNN·BatchNorm 조합 주의 | 순서와 위치 실험 필요 |

> 요약: 드롭아웃은 모델 추가 없이 부분망 앙상블 효과를 제공하지만 추론 모드와 구조별 위치 통제가 필요하다.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존/대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | L2는 가중치 크기 제한 | Dropout은 뉴런 출력 제거 | 과적합이 뉴런 공동적응이면 Dropout |
| 비용/성능 | 앙상블은 모델 N개 학습 | 단일 모델 내부 부분망 학습 | 저장공간·추론비용 제약 시 선택 |
| 운영/위험 | Early Stopping은 학습 중단 | Dropout은 추론 모드 전환 필요 | 재현성 테스트 필수 |

> 요약: 드롭아웃은 앙상블 비용을 줄이면서 과적합을 통제하지만 추론 재현성 검증을 함께 수행해야 한다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 과소학습 | dropout rate 과다 | 0.1 단위 탐색, 0.5 초과 제한 | train accuracy 하락 폭 |
| 추론 불일치 | dropout on 상태 배포 | eval 모드 자동 테스트 | 동일 입력 출력 편차 |
| BatchNorm 충돌 | 통계 추정 흔들림 | BatchNorm 뒤 위치 검증 | validation loss 변동률 |

> 요약: 제거 비율 과다, 추론 모드 누락, BatchNorm 통계 간섭이 드롭아웃 적용의 주요 리스크다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 일반화 | train-validation gap 5%p 이하 | 학습 로그 비교 |
| 재현성 | 동일 입력 추론 편차 0 또는 허용 오차 | 배포 전 회귀 테스트 |
| 모델 비용 | 추론 파라미터 증가 0개 | 모델 파일 크기, latency 측정 |

> 요약: 드롭아웃 도입 성공은 일반화 gap, 추론 재현성, 추론 비용 증가 여부로 판단한다.

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 — 단계별 또는 항목별):**
1. MLP 은닉층은 dropout 0.3~0.5 범위에서 탐색하고 검증 gap 5%p 이하를 목표로 조정함.
2. CNN은 Fully Connected 층 중심으로 적용하고 BatchNorm 포함 구간은 ablation test로 위치를 확정함.
3. 배포 전 `model.eval()` 고정, seed 관리, 동일 입력 10회 추론 편차를 자동 점검함.

**결론 (2줄):**
- 기술사 판단: 과적합이 크고 데이터가 제한되면 드롭아웃을 적용하고, 이미 대규모 데이터·강한 증강이 있으면 낮은 rate 또는 미적용을 선택함.
- 향후 방향: DropPath, Stochastic Depth처럼 뉴런 단위에서 블록·경로 단위 정규화로 확장됨.
