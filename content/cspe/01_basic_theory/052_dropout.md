## Ⅰ. 개요
- 정의: 학습 시 무작위로 일부 뉴런을 비활성화하여 특정 뉴런에 대한 의존도를 낮추는 정규화 기법임
- 배경: 복잡한 신경망에서 발생하는 과적합 방지 및 앙상블 효과 기대
- 출제 의도:
| 구분 | 내용 |
| --- | --- |
| 핵심 | 과적합 방지, 무작위 선택, 테스트 시 비활성화 |

## Ⅱ. 구성요소
- ASCII 구조도
  [O] [X] [O]
   |   |   |   (Training)
  [O] [O] [X]
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 드롭아웃 확률(p) | 뉴런을 끌 확률 (통상 0.5) | 결석률 |
| 마스크(Mask) | 활성/비활성을 결정하는 이진 행렬 | 가림막 |
| 스케일링 | 테스트 시 가중치에 p를 곱해 보정함 | 평균점수 |
> 요약: 특정 뉴런의 독점을 막고 다양한 특징을 고르게 학습하게 함

## Ⅲ. 절차
- ASCII 흐름도
  [확률설정] -> [뉴런선택] -> [학습진행] -> [테스트보정]
- 4단계 설명
1. 확률 설정: 비활성화할 뉴런의 비율 p를 정의함
2. 뉴런 선택: 매 배치마다 무작위로 학습에 참여할 뉴런 결정함
3. 학습 진행: 선택된 뉴런들로만 오차 역전파 수행함
4. 테스트 보정: 예측 시에는 모든 뉴런을 쓰되 출력값을 조정함
> 요약: 네트워크의 구조를 매번 바꿔 학습함으로써 강건성을 높임

## Ⅳ. 문제점
- 학습 시간이 평소보다 더 오래 걸리는 경향이 있음
- 적절한 드롭아웃 확률 p를 찾는 하이퍼파라미터 튜닝 필요함

## Ⅴ. 개선방안
- (단기) Fully Connected 층 뒤에 우선적으로 배치함
- (중기) DropConnect, Spatial Dropout 등 변형 기법 적용함
- (장기) Bayesian 딥러닝과 연계하여 불확실성 추정에 활용함

## Ⅵ. 전망
- 딥러닝의 필수 정규화 도구이며, 모델의 신뢰성 측정에 응용 중임
