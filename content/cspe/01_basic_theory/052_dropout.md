## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 학습 과정 중 미니배치마다 일정 비율의 뉴런을 무작위로 비활성화하여 과적합을 방지하는 기법임 |
| 배경/필요성 | 복잡한 딥러닝 모델이 훈련 데이터의 노이즈까지 암기하여 일반화 성능이 저하되는 문제 해결 필요 |
| 출제 의도 | 드롭아웃의 앙상블(Ensemble) 효과 및 특정 뉴런 공적응(Co-adaptation) 방지 원리 평가 |

## Ⅱ. 구성요소
```text
+----------------+       +----------------+       +----------------+
| Full Network   |       | Random Dropout |       | Thinned        |
| Nodes          | ----> | (Keep Prob p)  | ----> | Network        |
+----------------+       +----------------+       +----------------+
```
| 보존 확률 (p) | 뉴런이 활성화된 상태를 유지할 확률 (통상 0.5) | 생존율 |
| 비활성화 (Drop)| 뉴런의 출력을 강제로 0으로 만들어 연결 단절 | 일시 휴가 |
| 스케일 보상 | 추론 시 비활성화 비율만큼 출력값을 곱하여 보정 | 공백 채우기 |
> 요약: 드롭아웃은 확률 기반 뉴런 비활성화와 추론 시 스케일 보상 메커니즘으로 구성됨

## Ⅲ. 절차
```text
+----------------+       +----------------+       +----------------+       +----------------+
| Node Selection |       | Node Masking   |       | Forward/Back   |       | Inference Scale|
| (Draw random)  | ----> | (Zero Output)  | ----> | (Train Thin)   | ----> | (Multiply p)   |
+----------------+       +----------------+       +----------------+       +----------------+
```
1. 뉴런 선택: 훈련 미니배치마다 지정된 확률(p)에 따라 활성화할 뉴런 무작위 선택
2. 마스킹: 선택되지 않은 뉴런의 출력을 0으로 마스킹 처리
3. 학습 진행: 마스킹된 얇은 신경망에 대해서만 순전파 및 역전파 가중치 갱신
4. 추론 보정: 테스트 시 모든 뉴런을 활성화하되, 출력에 확률(p)을 곱하여 스케일 보정
> 요약: 무작위 뉴런 비활성화로 부분 신경망을 학습하고 추론 시 스케일 보정을 수행함

## Ⅳ. 문제점
- 훈련 시간 지연: 파라미터 업데이트가 분산되어 최종 수렴까지의 훈련 시간이 1.5~2배 증가
- 공간 정보 훼손(CNN): 픽셀 간 상관관계가 강한 CNN에서는 단순 랜덤 드롭이 비효율적
- 문맥 단절(RNN): 순환 신경망에 무작위 적용 시 이전 기억이 훼손되어 문맥 단절 발생

## Ⅴ. 개선방안
- 단기 방안: 에포크(Epoch) 수를 늘려 충분한 수렴 시간을 확보하여 모델 성능 보장
- 중기 방안: CNN 특화 채널/영역 단위 비활성화인 Spatial Dropout 적용
- 장기 방안: RNN 계열에는 타임스텝 간 동일 마스크를 유지하는 Variational Dropout 적용

## Ⅵ. 전망
- 파라미터 드롭아웃을 넘어 계층(Layer) 자체를 건너뛰는 DropPath(Stochastic Depth)로 진화함
