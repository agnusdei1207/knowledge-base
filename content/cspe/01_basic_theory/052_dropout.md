## 미리 알고가기

- 과적합: 모델이 훈련 데이터의 잡음까지 학습해 새 데이터에서 성능이 떨어지는 상태임
- 드롭 확률 $p$: 학습 중 뉴런 출력을 0으로 만들 확률이며 규제 강도를 정함
- 베르누이 마스크: 0 또는 1을 확률적으로 뽑아 뉴런 사용 여부를 정하는 이진 벡터임
- 인버티드 드롭아웃: 학습 시 남은 출력을 $1/(1-p)$로 조정해 추론 시 별도 크기 보정을 하지 않는 방식임
- 공적응: 여러 뉴런이 서로에게 과도하게 의존해 독립적인 특징을 못 배우는 현상임
- 가중치 감쇠: 손실 함수에 가중치 크기 패널티를 추가해 모델 복잡도를 제한하는 규제 기법임
- 데이터 증강: 라벨 의미를 유지하는 변환으로 학습 샘플을 늘리는 규제 기법임
- $h,m,\odot$: 각각 활성값, 베르누이 마스크, 원소별 곱을 나타내는 기호임

## 작성 근거(검토용)

- 개요는 마스킹과 경로 의존 완화를 함께 제시해 드롭아웃의 동작과 목적을 분리하지 않음
- 특징은 앙상블 효과, 공적응 억제, 모드 차이, 과소적합 위험을 핵심 축으로 선택함
- 드롭아웃·가중치 감쇠·데이터 증강의 규제 메커니즘·통제 범위·리스크를 비교함
- 구성요소는 $h$, $p$, $m$, 스케일링, 실행 모드로 실제 구현 단위를 일치시킴
- 확률 설정부터 실행 모드 전환까지 학습·추론 동작을 설명함
- 과도한 규제와 배치 정규화 병행은 드롭아웃 적용 시 확인할 대표 조건임

## Ⅰ. 개요

- **정의/개념**: 드롭아웃은 학습 중 뉴런 출력 일부를 확률적으로 0으로 마스킹해 특정 경로 의존을 낮추는 신경망 규제 기법임
- **배경/필요성**: 파라미터가 많은 신경망의 과적합을 줄이기 위해 부분망을 묵시적으로 학습하는 일반화 장치가 필요함

## Ⅱ. 특징

- 매 반복마다 다른 부분망을 학습해 단일 모델 안에서 앙상블과 유사한 효과를 냄
- 뉴런 간 공적응을 줄여 일부 특징에 의존한 불안정한 판단을 완화함
- 학습 시에는 무작위 마스크를 쓰고 추론 시에는 모든 뉴런을 사용해 기대 출력을 유지함
- 드롭 확률 $p$가 크면 규제가 강하지만 과하면 표현력이 부족해 과소적합 위험이 커짐

## Ⅲ. 종류 및 비교

| 판단 기준 | 드롭아웃 | 가중치 감쇠 | 데이터 증강 |
|:---|:---|:---|:---|
| 규제 메커니즘 | 뉴런 출력 무작위 마스킹 | 가중치 패널티 부과 | 의미 보존 입력 변환 |
| 통제 범위 | 은닉층 출력 경로 | 모델 가중치 | 학습 입력 표본 |
| 주요 리스크 | 고비율 마스킹 과소적합 | 과도한 감쇠 과소적합 | 라벨 의미 왜곡 |

> 요약: 드롭아웃은 학습할 때 일부 뉴런을 무작위로 제외하고, 가중치 감쇠는 파라미터 크기를 제한하며, 데이터 증강은 학습 입력을 다양화함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 활성값 $h$ | 무작위 제거 대상 |
| 드롭 확률 $p$ | 뉴런 제거 비율 |
| 마스크 $m$ | 베르누이 뉴런 선택값 |
| 스케일링 | $1/(1-p)$ 기대값 보정 |
| 실행 모드 | 학습 시 적용·추론 시 해제 |

> 요약: 드롭아웃은 학습 중 활성값 일부를 확률적으로 제거하고 남은 출력을 보정해 과적합을 줄임.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+      +----------+      +---------------+      +----------+
| 활성값 h | ---> | 마스크 m | ---> | m*h/(1-p)     | ---> | 다음 층   |
+----------+      +----------+      +---------------+      +----------+

추론: 활성값 h -------------------------------------------> 다음 층
```

1. **확률 설정**: 층별 과적합 위험에 따라 드롭 확률 $p$를 정함
2. **마스크 생성**: 베르누이 분포로 뉴런별 0 또는 1 값을 생성함
3. **마스킹·보정**: $\tilde{h} = m \odot h / (1-p)$로 남은 신호의 기대값을 맞춤
4. **실행 모드 분리**: 학습 모드에서만 마스크를 적용하고 평가 모드에서는 활성값을 그대로 전달함

> 요약: 드롭 확률은 일반화와 표현력 사이의 균형을 만들며 평가 모드에서는 마스크를 꺼야 함.

## Ⅵ. 실무 사례

1. 장애 분류 신경망은 드롭아웃을 적용하고 검증 손실과 학습·검증 오차의 격차로 $p$를 조정함
2. 배치 정규화 병행 모델은 드롭아웃 위치·비율별로 실험하고 검증 정확도로 선택함

## Ⅶ. 결론

- 드롭아웃은 검증 성능으로 드롭 확률을 정하고 학습·추론 모드의 마스크 적용 여부를 분리해야 함
