## Ⅰ. 개요
- **정의**: 훈련 시 뉴런을 확률적으로 비활성화하여 과적합을 방지하는 정규화 기법
- **배경/필요성**: 대규모 파라미터 모델이 훈련 데이터의 노이즈까지 암기하여 일반화 성능 저하 발생
- **비유**: 팀원을 매번 무작위로 교체하며 업무를 수행하여 특정 인물 의존도를 제거하는 것

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 과적합 억제 원리 | 암묵적 앙상블 효과(2^n개 서브넷 평균) | 추론 시 스케일 보정(Inverted Dropout) 누락 |
| 공적응 방지 이해 | 뉴런 간 상호 의존 차단으로 독립적 특징 학습 | CNN/RNN 특화 변형(Spatial/Variational) 구분 |

> 요약: 드롭아웃은 뉴런 무작위 비활성화로 암묵적 앙상블과 공적응 방지 효과를 달성하는 정규화 기법임

## Ⅱ. 구성요소
```text
+---------------+       +------------------+       +------------------+
| Full Network  |       | Random Mask      |       | Thinned Network  |
| (All Nodes)   | ----> | (keep prob = p)  | ----> | (Subset Active)  |
+---------------+       +------------------+       +------------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 보존 확률 p | 각 뉴런이 활성 상태를 유지할 확률, 통상 FC=0.5 / Conv=0.8 | 출근율 |
| 마스크 벡터 | 베르누이 분포에서 샘플링한 0/1 벡터로 뉴런 출력에 원소별 곱 | 출석 명단 |
| 스케일 보정 | 훈련 시 활성 출력을 1/p로 나누어 추론 시 별도 보정 불필요(Inverted) | 인원 보정 계수 |

> 요약: 보존 확률·마스크 벡터·스케일 보정 3요소로 부분 네트워크 학습을 수행함

## Ⅲ. 절차
```text
+---------------+       +---------------+       +---------------+       +---------------+
| Sample Mask   |       | Apply Mask    |       | Train Thin    |       | Infer Full    |
| (Bernoulli p) | ----> | (Zero nodes)  | ----> | (FW + BW)     | ----> | (No mask)     |
+---------------+       +---------------+       +---------------+       +---------------+
```

1. **마스크 생성** — 미니배치마다 보존 확률 p로 베르누이 마스크 벡터 샘플링
2. **마스킹 적용** — 마스크=0인 뉴런 출력을 0으로 설정, 활성 뉴런 출력은 1/p 스케일링
3. **부분망 학습** — 축소된 서브 네트워크에 대해 순전파·역전파 수행 및 가중치 갱신
4. **추론 수행** — 테스트 시 마스크 없이 전체 뉴런 활성화(Inverted 방식이면 보정 불필요)

> 요약: 마스크 생성 -> 적용 -> 부분망 학습 -> 전체망 추론의 4단계로 동작함

## Ⅳ. 문제점
- 수렴 지연: 매 반복 활성 파라미터가 변동하여 동일 에포크 대비 수렴 속도 1.5~2배 저하
- 공간 구조 파괴: CNN에서 인접 픽셀 상관관계를 무시한 랜덤 드롭은 특성맵 정보 훼손
- 시간 문맥 단절: RNN에서 타임스텝마다 독립 마스크 적용 시 은닉 상태 연속성 파괴

> 요약: 수렴 지연, CNN 공간 정보 훼손, RNN 문맥 단절이 구조별 주요 한계임

## Ⅴ. 개선방안
1. 단기: 에포크 수 증가 및 학습률 스케줄링으로 수렴 지연 보상
2. 중기: CNN에 채널·영역 단위 비활성화인 Spatial Dropout / DropBlock 적용
3. 장기: RNN에 타임스텝 간 동일 마스크를 유지하는 Variational Dropout 적용

- 시간 문맥 단절: 독립 마스크에 의한 은닉 상태 불연속 -> Variational Dropout 적용 (지표: Perplexity 감소율 > 5%)

> 요약: 수렴 보상 -> CNN 특화 드롭 -> RNN 특화 드롭으로 구조별 대응함

## Ⅵ. 전망
- 향후 발전 방향: 뉴런 단위를 넘어 계층·경로 단위를 건너뛰는 DropPath(Stochastic Depth)로 확장
- 기술사적 판단: 트랜스포머 대형 모델에서는 드롭아웃 비율을 0으로 두는 추세이나, 중소형 모델에서는 여전히 핵심 정규화 수단
- 기술사 제언: 모델 크기·데이터 규모에 따라 드롭아웃 vs Weight Decay vs Data Augmentation 조합 실험 필요
