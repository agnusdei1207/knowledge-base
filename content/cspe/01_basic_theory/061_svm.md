## 미리 알고가기

- 초평면: n차원 피처 공간에서 두 클래스를 나누는 n-1차원 경계임
- 마진: 결정 경계와 가장 가까운 학습 데이터 사이의 거리이며 일반화 성능 판단 기준임
- 서포트 벡터: 마진을 결정하는 경계 인접 데이터 포인트임
- 커널 함수: 고차원 매핑을 명시적으로 계산하지 않고 내적 결과만 계산하는 함수임
- 소프트 마진: 일부 오분류를 허용해 노이즈 데이터에 대한 과적합을 줄이는 방식임

## Ⅰ. 개요

- **정의**: SVM은 클래스 사이 마진이 최대가 되는 초평면을 찾아 분류·회귀 경계를 결정하는 지도학습 모델임
- **배경/필요성**: 표본 수는 적지만 피처 수가 많은 의료·텍스트 분류에서는 복잡한 모델보다 일반화 경계가 명확한 모델이 필요함
- **비유**: 두 마을 사이에 가장 넓은 완충 도로를 내어 새로 들어오는 집이 어느 마을에 속하는지 판단하는 방식과 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 마진 최대화 원리 설명 | 초평면, 마진, 서포트 벡터 관계 | 서포트 벡터가 경계를 결정한다는 점 누락 |
| 비선형 분류 방식 설명 | 커널 트릭과 C, gamma 조정 | 하드 마진과 소프트 마진 혼동 |

> 요약: SVM은 전체 데이터보다 경계 인접 데이터와 마진을 기준으로 결정 경계를 선택해 소규모 고차원 데이터의 일반화 성능을 확보하는 모델임

## Ⅱ. 특징/비교

| 판단 기준 | 로지스틱 회귀/트리 모델 | SVM |
|:---|:---|:---|
| 경계 선택 기준 | 손실 최소화나 분기 순도 개선을 우선함 | 클래스 간 마진을 최대화하는 경계를 선택함 |
| 비선형 대응 | 피처 조합을 직접 만들거나 트리 분기를 늘림 | 커널 함수로 고차원 유사도를 암묵적으로 계산함 |
| 데이터 규모 적합성 | 대규모 선형 데이터나 해석 중심 업무에 유리함 | 소규모·고차원·명확한 경계가 있는 데이터에 유리함 |
| 운영 트레이드오프 | 학습·추론이 비교적 단순함 | 커널 행렬과 파라미터 탐색 비용이 커질 수 있음 |

> 요약: SVM은 데이터 양보다 경계 품질이 중요하고 커널 기반 비선형 분리가 필요한 경우 선택 가치가 높음

- **선형 SVM 선택**: 샘플 수가 많고 피처가 희소한 텍스트 분류에서 학습 비용을 낮출 때 적합함
- **RBF 커널 선택**: 클래스 경계가 곡선형이고 피처 간 상호작용을 직접 설계하기 어려울 때 적합함
- **트리 계열 선택**: 범주형 변수와 결측치가 많거나 설명 가능한 분기 규칙이 필요한 경우 SVM보다 유리함

## Ⅲ. 구성요소

```text
+-------------+      +-------------+      +-------------+
| Train Data  | ---> | Kernel /    | ---> | QP Optimizer|
| x, y        |      | Inner Prod  |      | max margin  |
+-------------+      +------+------+      +------+------+
                              |                    |
                              v                    v
                       +-------------+      +-------------+
                       | Support     | ---> | Decision    |
                       | Vectors     |      | Function    |
                       +-------------+      +-------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 학습 데이터 | 클래스 레이블이 붙은 피처 벡터이며 초평면을 찾는 입력 자료임 | 지도 위 좌표 |
| 커널 함수 | 선형, RBF, 다항 커널로 데이터 간 유사도를 계산해 경계 형태를 결정함 | 렌즈 선택 |
| 서포트 벡터 | 결정 경계에 가장 가까워 마진 폭과 경계 위치를 좌우하는 핵심 표본임 | 경계 말뚝 |
| 최적화기 | 제약 조건을 만족하면서 마진을 최대화하는 이차계획 문제를 풂 | 설계 계산기 |
| 결정 함수 | 새 데이터가 초평면 어느 쪽에 있는지 부호와 거리로 예측함 | 판정 게이트 |

> 요약: SVM은 커널로 유사도 공간을 정하고, 서포트 벡터를 기준으로 최적화된 결정 함수를 만드는 구조임

## Ⅳ. 절차

```text
+-----------+     +-----------+     +-----------+     +-----------+
| Scale     | --> | Select    | --> | Optimize  | --> | Predict   |
| Features  |     | Kernel    |     | Margin    |     | by Sign   |
+-----------+     +-----------+     +-----------+     +-----------+
      |                 |                 |                 |
      v                 v                 v                 v
distance valid     linear/RBF       support vector      class label
```

1. **피처 스케일링**: 거리와 내적이 경계에 직접 영향을 주므로 표준화 또는 정규화로 변수 스케일을 맞춤
2. **커널·파라미터 선택**: 선형/RBF/다항 커널과 C, gamma 값을 데이터 분포와 검증 성능 기준으로 정함
3. **마진 최적화**: 오분류 허용 범위 안에서 서포트 벡터와 초평면 사이의 마진이 최대가 되도록 학습함
4. **예측·검증**: 결정 함수의 부호로 클래스를 정하고 정확도, F1, ROC-AUC 등으로 일반화 성능을 확인함

> 요약: SVM 적용은 스케일링으로 거리 기준을 맞춘 뒤 커널과 마진을 최적화하고 검증 지표로 경계 품질을 확인하는 흐름임

## Ⅴ. 문제점

- **P1 대규모 학습 비용**: 커널 SVM은 샘플 수가 증가할수록 커널 행렬과 최적화 비용이 커져 대용량 데이터 학습 시간이 급증함
- **P2 파라미터 민감성**: C와 gamma가 작거나 크면 과소적합 또는 과적합이 발생해 검증 성능 편차가 커짐
- **P3 해석 한계**: 비선형 커널은 원래 피처 공간에서 어떤 조건이 판단에 기여했는지 설명하기 어려움

> 요약: SVM은 경계 품질은 강하지만 데이터 규모, 파라미터 탐색, 비선형 판단 근거 설명에서 운영 부담이 발생함

## Ⅵ. 개선방안

- **P1 대응**: 대규모 선형 문제는 Linear SVM이나 SGD 기반 hinge loss 학습으로 전환함 (확인: 학습 시간, 메모리 사용량)
- **P2 대응**: 교차검증과 베이지안 탐색으로 C, gamma 후보를 제한하고 데이터 누수 없는 검증 파이프라인을 구성함 (확인: 검증 F1 변동폭)
- **P3 대응**: 선형 모델 우선 검토, SHAP·LIME 기반 설명, 서포트 벡터 사례 분석을 함께 제시함 (확인: 주요 피처 설명 일관성)

> 요약: 문제 원인별로 모델 형태, 탐색 체계, 설명 도구를 분리 적용해야 SVM의 실무 적용성이 높아짐

## Ⅶ. 전망

- **발전 방향**: SVM은 대규모 범용 모델보다 소규모 고차원 정형 데이터와 이상탐지의 강한 기준 모델로 지속 활용될 전망임
- **기술사적 판단**: 데이터가 충분히 크고 복잡하면 딥러닝이나 GBDT를 검토하되, 표본이 제한된 환경에서는 SVM을 우선 베이스라인으로 둘 수 있음
- **기술사 제언**: 답안에서는 커널 트릭만 설명하지 말고 마진, 서포트 벡터, 소프트 마진의 선택 기준을 함께 제시해야 함
