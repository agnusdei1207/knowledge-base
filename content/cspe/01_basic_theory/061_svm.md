## 미리 알고가기

- 초평면: 특징 공간에서 클래스를 나누는 결정 경계임
- 마진: 결정 경계와 가장 가까운 학습 데이터 사이의 거리임
- 서포트 벡터: 마진 폭과 결정 경계의 위치를 정하는 학습 표본임
- 커널 트릭: 고차원으로 직접 변환하지 않고 내적 계산만으로 비선형 경계를 형성함
- 규제 계수 $C$: 마진 확대와 오분류 허용 사이를 조절함
- 커널 감도 $\gamma$: RBF(Radial Basis Function, 방사 기저 함수) 커널에서 한 표본의 영향 범위를 조절함
- 슬랙 변수: 소프트 마진에서 표본의 마진 위반·오분류 정도를 나타냄
- 볼록 최적화: 모든 국소 최적해가 전역 최적해가 되는 목적 함수를 푸는 방식임

## 작성 근거(검토용)

- 개요는 SVM을 마진을 최대화하는 지도 학습 모델로 정의해 출제 키워드와 연결함
- 마진·서포트 벡터·커널·볼록 최적화는 SVM 고유 판단축임
- Ⅲ은 실무 선택에 필요한 하드 마진과 소프트 마진의 오차 허용 차이를 중심으로 구성함
- Ⅳ는 수식보다 경계 형성 요소를 우선해 초평면, 서포트 벡터, 커널, $C$의 관계를 드러냄
- 데이터 규모와 커널 튜닝은 SVM의 성능·비용을 가르는 조건임

## Ⅰ. 개요

- **정의/개념**: SVM은 클래스 사이의 마진을 최대화하는 초평면을 찾아 분류·회귀를 수행하는 지도 학습 모델임
- **배경/필요성**: 특징 차원이 표본 수보다 큰 데이터의 일반화 성능을 확보하기 위해 최대 마진 분류 기준이 필요함

### 쉽게 이해하기 (학습용)
- 두 편으로 나뉜 사람들 사이에 가장 널찍한 통로를 내어 편을 가르는 것과 같음

## Ⅱ. 특징

- 마진이 넓을수록 미학습 데이터에 대한 일반화 성능이 높아짐
- 서포트 벡터만 결정 경계에 직접 영향을 줌
- 커널 함수로 선형 분리가 어려운 데이터에 비선형 경계를 형성함
- 볼록 최적화로 전역 최적해를 찾는 구조임

### 쉽게 이해하기 (학습용)
- 통로가 넓을수록 처음 보는 사람이 와도 어느 편인지 헷갈리지 않음
- 통로 가장자리에 선 사람들만 통로 위치를 정하고, 뒤쪽 사람들은 위치를 바꿔도 영향이 없음
- 통로를 구부려야 하는 상황(커널)에도 항상 하나의 정답 배치가 나옴

## Ⅲ. 종류 및 비교

| 판단 기준 | 하드 마진 SVM | 소프트 마진 SVM |
|:---|:---|:---|
| 오차 처리 | 마진 위반 금지 | $C$ 기반 마진 위반 허용 |
| 적합 조건 | 완전 분리 데이터 | 잡음·클래스 중첩 |
| 주요 리스크 | 이상치 민감 | $C$ 튜닝 의존 |

> 요약: 하드 마진은 완전 분리 데이터에, 소프트 마진은 잡음이나 클래스 중첩이 있는 데이터에 적합함.

### 쉽게 이해하기 (학습용)
- 편 가르기가 깔끔하면 통로 침범을 절대 허용하지 않지만, 편이 살짝 섞여 있으면 약간의 침범은 봐주는 대신 어디까지 봐줄지 기준을 따로 정함

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 초평면 | $w \cdot x + b = 0$ 형태의 결정 경계 |
| 서포트 벡터 | 마진 폭과 경계 위치를 결정하는 표본 |
| 커널 함수 | 비선형 경계를 구성하는 내적 함수 |
| 규제 계수 $C$ | 마진 위반 비용의 조절 계수 |

> 요약: 초평면과 서포트 벡터가 경계를 만들고 커널과 $C$가 경계 형태와 오분류 허용 폭을 조절함.

```text
클래스 A         서포트 벡터
     o      o        o
-------------------------  마진 경계
=========================  결정 초평면
-------------------------  마진 경계
     x      x        x
클래스 B         서포트 벡터
```

### 쉽게 이해하기 (학습용)
- 통로의 경계선(초평면)과 경계에 딱 붙어 선 사람들(서포트 벡터)이 통로 모양을 정하고, 통로를 얼마나 엄격히 지킬지는 규제 계수가 조절함

## Ⅴ. 원리 및 절차 흐름도

```text
학습 데이터 -> 커널 선택·내적 계산 -> 마진 최적화 -> 서포트 벡터 확정 -> 결정 함수
```

1. 학습 데이터를 특징 벡터로 변환하고 비선형 경계에는 커널을 선택함
2. 클래스 간 마진이 최대가 되는 초평면을 최적화함
3. 마진에 닿는 서포트 벡터와 계수를 확정함
4. 신규 데이터는 결정 함수의 부호로 클래스를 판정함

> 요약: SVM은 커널 선택과 마진 최적화를 거쳐 서포트 벡터만으로 결정 경계를 정의함.

### 쉽게 이해하기 (학습용)
- 데이터를 정리하고, 통로가 가장 넓어지는 위치를 찾은 뒤, 경계에 걸린 사람만 기억해뒀다가 새 사람이 오면 어느 편에 서는지로 판정함

## Ⅵ. 실무 사례

1. 악성코드 분류기는 고차원 특징에 선형 SVM을 적용해 최대 마진 결정 경계를 학습함
2. 선형 분리가 어려운 데이터는 RBF 커널을 적용하고 $C$·$\gamma$를 교차 검증으로 선택함

### 쉽게 이해하기 (학습용)
- 특징이 많은 데이터는 곧은 통로(선형)로 가르고, 딱 갈라지지 않는 데이터는 통로를 구부린 뒤(커널) 여러 설정을 시험해 가장 잘 맞는 값을 고름

## Ⅶ. 결론

- SVM은 두 클래스 사이의 가장 넓은 경계를 찾으며, 오분류 허용 범위와 경계 복잡성의 균형을 조정해야 함
- 고차원·중소 규모 데이터에는 선형 SVM을 우선하고, 표본 증가로 커널 학습 비용이 커지면 선형 모델·근사 커널로 전환해야 함

### 쉽게 이해하기 (학습용)
- 두 무리를 가장 널찍하게 갈라 세우되, 너무 깐깐하게 굴면 계산이 무거워지므로 데이터 크기에 맞춰 곧은 통로와 구부린 통로 중 적당한 것을 고름
