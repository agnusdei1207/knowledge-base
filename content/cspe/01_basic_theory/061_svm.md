## 미리 알고가기

- 초평면($Hyperplane$): 다차원 공간에서 두 클래스를 가르는 수학적 경계(평면 또는 다차원 초평면)임
- 서포트 벡터($Support$ $Vector$): 결정 경계와 가장 가까운 거리에 위치하여, 실질적으로 결정 경계를 형성하는 중요 데이터 포인트들임
- 마진($Margin$): 결정 경계(초평면)와 서포트 벡터들 사이의 최단 거리를 뜻하며, 이 마진을 넓힐수록 모델의 일반화 능력이 우수해짐
- 커널 트릭($Kernel$ $Trick$): 데이터를 직접 고차원으로 변환하지 않고, 고차원에서의 내적 값을 쉽게 얻어내어 비선형 분리를 가능케 하는 수학적 기법임

## Ⅰ. 개요

- **정의/개념**: 서포트 벡터 머신(SVM)은 고차원 공간에서 서로 다른 클래스에 속한 데이터들 간의 마진($Margin$)을 최대화하는 최적의 결정 경계(초평면)를 설계하여 일반화 오류를 최소화하는 지도 학습 모델임
- **배경/필요성**: 데이터의 수가 적을 때 신경망 계열은 쉽게 과적합($Overfitting$)에 빠지므로, 수학적 이론을 바탕으로 경계 영역의 여유를 극한으로 늘려 예측 안정성을 담보하기 위해 제안됨

## Ⅱ. 특징

- 마진 최대화 전략을 사용하여 새로운 미지의 데이터에 대해 매우 뛰어난 일반화 성능을 발휘하며, 결정 경계 근처의 '서포트 벡터'들로만 판단을 내려 데이터 노이즈의 영향을 적게 받음
- 저차원 공간에서 선형 분류가 불가능한 복잡한 문제를 고차원($Hilbert$ $Space$)으로 매핑하는 커널 함수를 활용하여, 비선형 결정 경계를 효율적으로 그려낼 수 있음
- 학습 과정이 볼록 최적화($Convex$ $Optimization$) 문제로 정의되므로, 딥러닝과 달리 전역 최적해($Global$ $Optimum$)가 항상 보장된다는 수학적 강점을 가짐

## Ⅲ. 종류 및 비교

| 판단 기준 | 하드 마진 SVM (Hard Margin) | 소프트 마진 SVM (Soft Margin) |
|:---|:---|:---|
| **기본 가정** | 모든 데이터가 완벽히 선형 분리됨 | 데이터 내에 잡음이나 오차가 섞여 있음 |
| **이상치 허용** | 전혀 허용하지 않음 (오차 불가) | 파라미터 $C$에 따라 일부 오차 허용 |
| **과적합 위험** | 매우 높음 (이상치에 극도로 민감) | 낮음 (유연한 경계 설정 가능) |
| **실무 적합성** | 현실 데이터에 적용하기 어려움 | 대부분의 실무 데이터 분석에 표준으로 사용됨 |

> 요약: 하드 마진은 완전무결한 경계를, 소프트 마진은 현실적 타협을 통한 견고한 경계를 만듦.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 초평면 방정식 | $w^T x + b = 0$ 으로 표현되며, 가중치 벡터 $w$가 초평면의 기울기(방향)를 결정함 |
| 슬랙 변수 ($\xi$) | 소프트 마진에서 오분류된 데이터 포인트들의 오차 거리를 허용하는 임시 수치임 |
| 규제 매개변수 ($C$) | 마진 크기와 분류 오차 허용 간의 상충($Trade-off$)을 조절하는 제어값임 |
| $RBF$ 커널 | 무한 차원의 공간 매핑 효과를 내며 비선형 최적화에 가장 널리 쓰이는 방사기저 함수임 |

```text
[ SVM 결정 경계 구조 ]
   [Class A]    * (Support Vector)
----------------- (Boundary: w^T x + b = +1)
      ↑  Margin (d = 2 / ||w||)
================= (Decision Hyperplane: w^T x + b = 0)
      ↓  Margin
----------------- (Boundary: w^T x + b = -1)
   [Class B]    o (Support Vector)
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 데이터 입력  | --> | 커널 고차원사상| --> | 최적화 문제풀이| --> | 최종 결정경계|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **차원 매핑** — 입력 데이터를 커널 함수(예: Gaussian, Polynomial)를 사용해 선형 분리가 가능한 가상의 고차원 특징 공간으로 이동시킴
2. **라그랑주 공식화** — 초평면의 조건식을 라그랑주 승수를 도입하여 쌍대 문제($Dual$ $Problem$)로 전환하고, 수학적 풀이가 쉬운 2차 계획법($Quadratic$ $Programming$) 형태로 변환함
3. **가중치 최적화** — 오차 허용비용 $C$와 공간 매핑 범위 $\gamma$를 바탕으로, 마진 영역 내에 들어오는 서포트 벡터들을 식별하고 계수들을 계산함
4. **결정 경계 확정** — 학습된 계수를 기반으로 최종 초평면을 선언하고, 새로운 데이터 입력 시 평면 위아래의 부호를 식별하여 분류를 완료함

## Ⅵ. 실무 적용 및 유의점

1. SVM은 데이터 분리 성능이 매우 뛰어나지만, 데이터의 샘플 수($N$)가 커질수록 연산 시간이 $O(N^3)$ 수준으로 급격히 증가하여 빅데이터 처리에 병목이 될 수 있으므로, 대용량 정형 데이터에는 경량화된 솔버나 선형 SVM을 적용해야 함
2. 비선형 커널 사용 시 규제 계수($C$)와 감도($\gamma$)에 따라 성능이 크게 널뛰기하므로, $Grid$ $Search$나 $Random$ $Search$를 통해 교차 검증 성능이 가장 높은 최적의 조합을 반드시 찾아내야 함

## Ⅶ. 결론

- SVM은 기하학적 여유 공간의 미학을 바탕으로 데이터 간의 선을 긋는 모델이며, 설계자는 적절한 커널의 선택과 연산 효율성 및 제어 계수의 미세 튜닝을 통해 극한의 안전지대를 갖춘 판정 시스템을 구축해야 함
