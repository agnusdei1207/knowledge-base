## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 데이터를 분할하는 최적의 초평면(Hyperplane)을 찾아 마진(Margin)을 최대화하는 기계학습 분류 및 회귀 모델임. |
| 배경/필요성 | 비선형 데이터 분류 한계를 극복하고 모델의 오버피팅을 방지하여 일반화 성능을 높일 필요성 증가. |
| 출제 의도 | 기계학습 핵심 원리인 마진 최대화와 커널 트릭을 통한 비선형 데이터 처리 능력 평가. |

## Ⅱ. 구성요소
```text
+---------------+     +---------------+     +---------------+
|  Input Data   | --> | Kernel Trick  | --> | Optimal Margin|
+---------------+     +---------------+     +---------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 결정 경계(Hyperplane) | 클래스를 분리하는 기준 평면 | 국경선 |
| 서포트 벡터(Support Vector) | 결정 경계에 가장 가까운 데이터 | 최전방 초소 |
| 커널 함수(Kernel Function) | 데이터를 고차원으로 매핑하는 함수 | 돋보기 |

> 요약: 데이터를 커널 트릭으로 고차원 매핑하고, 서포트 벡터 기반 마진 최대화 결정 경계를 도출함.

## Ⅲ. 절차
```text
+----------+   +----------+   +----------+   +----------+
| Data Prep|-> | Mapping  |-> | Optimize |-> | Predict  |
+----------+   +----------+   +----------+   +----------+
```
1. 데이터 준비: 훈련 데이터를 수집하고 스케일링을 수행함.
2. 공간 매핑: 비선형 데이터일 경우 커널 함수로 고차원 사상함.
3. 파라미터 최적화: 마진을 최대화하는 초평면 파라미터 계산함.
4. 예측: 학습된 모델을 통해 새로운 입력의 클래스를 분류함.

> 요약: 데이터 전처리 후 공간 매핑을 수행하고 목적 함수 최적화를 거쳐 분류를 진행함.

## Ⅳ. 문제점
- 대규모 데이터 학습 시 메모리 소모 및 시간 복잡도 증가 문제 발생
- 비선형 커널 사용 시 최적 하이퍼파라미터(C, Gamma) 탐색의 어려움 존재
- 모델 내부 연산이 복잡하여 도출된 결과의 인과관계 설명력 부족 한계 노출

## Ⅴ. 개선방안
- [단기] 데이터 샘플링 및 청크 분할 처리를 통한 초기 학습 메모리 병목 해소
- [중기] 그리드 서치 및 베이지안 최적화 적용으로 하이퍼파라미터 자동 탐색
- [장기] LIME, SHAP 등 설명 가능한 AI(XAI) 방법론을 융합하여 모델 해석력 강화

## Ⅵ. 전망
- 소규모 정형 데이터 분석 영역에서 강력한 베이스라인으로 활용되며 금융/의료 시스템에 지속 적용될 전망임.
