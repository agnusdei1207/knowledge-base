# 061. SVM 서포트 벡터 머신 (Support Vector Machine)

## Ⅰ. 개요

- **정의/개념**: 두 클래스 간의 간격인 마진($Margin$)을 최대화하는 최적의 초평면($Hyperplane$)을 설계하여 데이터를 분류하는 공간 분할 기반의 지도 학습 알고리즘임
- **배경/필요성**: 단순히 훈련 데이터를 맞히는 것을 넘어, 구조적 위험 최소화($SRM$: $Structural$ $Risk$ $Minimization$) 원리에 따라 새로운 데이터에 대한 일반화 능력을 극대화하기 위함임

## Ⅱ. 특징 및 비교

### 1. 주요 특징 및 PPA (Power, Performance, Area)
- **Performance**: 마진 최대화를 통해 과적합을 억제하며, 고차원 데이터에서도 전역 최적해($Global$ $Optimum$)를 보장함
- **Power/Compute**: 데이터 수($n$)에 대해 $O(n^2 \sim n^3)$의 연산 복잡도를 가지므로 대규모 데이터셋에서는 학습 부하가 큼
- **Trade-offs**: 모델의 엄격함($Hard$ $Margin$)과 오차 허용($Soft$ $Margin$) 사이의 파라미터 $C$ 설정이 성능을 좌우함

### 2. 분류 알고리즘 비교

| 판단 기준 | $SVM$ | 로지스틱 회귀 | 결정 트리 |
|:---|:---|:---|:---|
| **결정 원리** | 기하적 마진 최대화 | 확률 기반 우도 최대화 | 정보 이득 기반 영역 분할 |
| **비선형 대응** | 커널 트릭 ($Kernel$ $Trick$) | 변수 상호작용항 추가 | 트리 깊이 증가 |
| **특징 공간** | 고차원 매핑에 최적화 | 저차원 설명력 우수 | 비선형 경계 추적 용이 |
| **최적화** | $Convex$ (전역 해) | $Convex$ (전역 해) | $Greedy$ (지역 해) |

> 요약: $SVM$은 수학적 견고함과 기하학적 명확성을 바탕으로 고차원 희소 데이터에서 탁월한 성능을 보임

## Ⅲ. 구성요소/구조

### 1. Architecture Insight: 커널 트릭과 쌍대성 (Duality)
- **Kernel Trick**: 저차원에서 선형 분리가 불가능한 데이터를 고차원 특징 공간($Feature$ $Space$)으로 직접 매핑하지 않고도, 내적 연산($Dot$ $Product$)만을 통해 비선형 경계를 찾는 기법임
- **Support Vectors**: 결정 경계를 결정짓는 극소수의 데이터 포인트들로, 이들만이 모델 파라미터 $w, b$ 계산에 관여하여 메모리 효율적임

### 2. 핵심 수식 및 알고리즘
- **Objective Function**: $\min \frac{1}{2}\|w\|^2$ subject to $y_i(w^T x_i + b) \ge 1$ (하드 마진 기준)
- **Soft Margin with Slack ($\xi$)**: $\min \frac{1}{2}\|w\|^2 + C \sum \xi_i$ (오분류 허용 강도 $C$ 도입)
- **Kernel Functions**:
  - $Linear$: $K(x_i, x_j) = x_i^T x_j$
  - $RBF$ ($Gaussian$): $K(x_i, x_j) = \exp(-\gamma \|x_i - x_j\|^2)$
  - $Polynomial$: $K(x_i, x_j) = (x_i^T x_j + c)^d$

## Ⅳ. 문제점 및 개선방안

### 1. 핵심 문제 및 대응
1. **[대용량 데이터 연산 부하]**: 데이터가 늘어날수록 $QP$($Quadratic$ $Programming$) 최적화 시간이 기하급수적으로 증가
   - **개선방안**: $SMO$($Sequential$ $Minimal$ $Optimization$) 알고리즘 적용 또는 확률적 경사하강법($SGD$) 기반의 선형 $SVM$ 활용
2. **[스케일 민감도]**: 변수 간 단위 차이가 크면 특정 변수가 마진 계산을 지배함
   - **개선방안**: 학습 전 $Standard$ $Scaler$ 등을 통한 데이터 정규화 필수
3. **[확률적 해석 부재]**: 결과값이 거리에 불과하여 직접적인 클래스 확률을 알 수 없음
   - **개선방안**: $Platt$ $Scaling$ (거리값을 시그모이드 함수에 통과)을 통해 확률값 산출

### 2. Real-world Troubleshooting
- **Overfitting ($\gamma, C$ 조절)**: $RBF$ 커널에서 $\gamma$가 너무 크면 결정 경계가 개별 데이터에 너무 유착됨($Wiggle$). $C$와 $\gamma$를 동시에 튜닝하는 그리드 서치($Grid$ $Search$)로 최적 균형점 도출 필요
- **Imbalanced Class**: 소수 클래스의 서포트 벡터가 무시될 수 있으므로 클래스별로 $C$값을 다르게 설정($Class$ $Weight$)하여 대응

## Ⅴ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| **텍스트/스팸 분류** | 고차원 $TF$-$IDF$ 벡터 공간에서 선형 $SVM$으로 고속 분류 | $F1$-$Score, Precision$ |
| **생체 인식 (얼굴/지문)** | 추출된 특징점 간의 비선형 경계를 $RBF$ 커널로 학습 | $EER$ ($Equal$ $Error$ $Rate$) |
| **보안 이상 탐지** | 정상 데이터의 분포만 학습하는 $One$-$Class$ $SVM$ 활용 | $False$ $Positive$ $Rate$ |

> 요약: 실제 시스템 구축 시 데이터 전처리와 커널 파라미터 선정에 전체 공수의 $70\%$ 이상을 집중해야 함

## Ⅵ. 결론

$SVM$은 기하학적 직관과 최적화 이론이 결합된 가장 우아한 머신러닝 모델 중 하나임. 기술사적 관점에서 볼 때, 단순한 라이브러리 활용을 넘어 커널 트릭을 통한 차원 확장 원리와 $C, \gamma$ 파라미터가 모델의 편향-분산에 미치는 영향을 제어하는 능력이 필수적이며, 이는 데이터가 적은 환경에서 신뢰할 수 있는 AI 시스템을 설계하는 데 있어 강력한 무기가 됨.
