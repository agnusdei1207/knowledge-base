## 미리 알고가기

- 마진: 두 클래스 경계와 가장 가까운 샘플 사이 거리임
- support vector: 결정 경계를 실제로 결정하는 경계 샘플임
- kernel trick: 고차원 공간 내적을 직접 계산하지 않고 비선형 분리를 가능하게 하는 기법임

## Ⅰ. 개요

- **정의/개념**: SVM은 클래스 간 마진을 최대화하는 결정 경계를 찾아 분류하거나 회귀를 수행하는 지도 학습 모델로, 커널을 통해 비선형 문제까지 확장 가능함
- **배경/필요성**: 데이터 수가 많지 않아도 일반화 성능이 좋은 분류기가 필요하고, 경계 중심의 해석 가능한 기준이 요구될 때 유용함

## Ⅱ. 특징

- 최대 마진 원리로 일반화 성능을 높임
- support vector만으로 경계가 정해져 모델이 비교적 간결함
- 커널을 쓰면 비선형 경계도 표현할 수 있음
- 대용량 데이터와 다중 클래스 확장에서는 계산 부담이 커질 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | 선형 SVM | 커널 SVM | 로지스틱 회귀 |
|:---|:---|:---|:---|
| 경계 형태 | 선형 | 비선형 | 선형 |
| 해석성 | 높음 | 낮음 | 높음 |
| 대용량 적합성 | 높음 | 낮음 | 높음 |
| 대표 적용 | 희소 텍스트 | 복잡 경계 분류 | 확률 분류 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 결정 경계 | 클래스 분할 초평면이며 예측 기준선임 |
| 마진 | 경계 여유 폭이며 일반화 품질 핵심임 |
| support vector | 경계 주변 핵심 샘플이며 모델을 실질적으로 결정함 |
| 커널 함수 | 고차원 특징 변환 효과를 냄 비선형 확장 장치임 |

```text
+-----------+     +-----------+     +----------------+     +-----------+
| 결정 경계    | --> | 마진        | --> | support vector | --> | 커널 함수    |
+-----------+     +-----------+     +----------------+     +-----------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 데이터입력 | --> | 경계탐색 | --> | 마진최대화 | --> | 예측판정 |
+----------+     +----------+     +----------+     +----------+
```

1. **데이터입력**: 특징과 라벨을 준비함
2. **경계탐색**: 후보 초평면을 설정함
3. **마진최대화**: support vector 기준으로 최적 경계를 찾음
4. **예측판정**: 새 샘플이 어느 쪽에 있는지 판단함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 커널과 하이퍼파라미터 선택이 어려워 $C$, gamma가 성능에 큰 영향 줌
   - 해결방안: 교차검증과 grid search를 사용하고 CV score로 검증함
2. 문제: 대용량 데이터에서 학습이 느려 샘플 수가 많으면 최적화 비용이 큼
   - 해결방안: 선형 SVM, 샘플링, approximate solver를 사용하고 training time로 검증함
3. 문제: 확률 해석이 직접적이지 않아 분류 점수를 확률로 보기 어렵다
   - 해결방안: Platt scaling 등 calibration을 적용하고 Brier score로 검증함

## Ⅶ. 적용 사례

- 문서 분류에서는 희소 고차원 텍스트를 분류함, 확인 지표는 F1임
- 이미지 분류 보조기에서는 CNN 특징 위에서 최종 분류기로 사용함, 확인 지표는 accuracy임
- 장애 패턴 분류에서는 정상/비정상 경계를 학습함, 확인 지표는 precision과 recall임

## Ⅷ. 결론

SVM의 핵심은 복잡한 모델보다 경계 여유를 최대로 확보하는 데 있으므로, 데이터 규모와 커널 복잡도를 함께 보고 선택해야 함.
