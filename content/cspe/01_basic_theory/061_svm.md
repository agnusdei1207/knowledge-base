# SVM 서포트 벡터 머신 (Support Vector Machine)

## 1. 개요

- **정의/개념**: SVM은 클래스 경계를 가장 넓은 마진으로 분리하는 초평면을 찾고, 경계 결정에 영향을 주는 서포트 벡터를 중심으로 학습하는 지도 학습 모델이다.
- **배경/필요성**: 고차원 데이터에서 단순 정확도보다 일반화 가능한 분류 경계를 찾는 것이 중요하므로, 마진 최대화 기반의 분류 기준이 필요하다.

SVM의 핵심은 모든 데이터를 똑같이 보는 것이 아니라 경계 근처의 서포트 벡터가 결정면을 좌우한다는 점이다.

## 2. 특징 및 비교

| 구분 | Logistic Regression | SVM | Decision Tree |
|---|---|---|---|
| 경계 기준 | 확률 모델 | 최대 마진 | 조건 분기 |
| 비선형 처리 | feature engineering | kernel trick | 트리 분할 |
| 강점 | 확률 해석 | 고차원·마진 | 해석 쉬움 |
| 약점 | 선형 한계 | 대규모 데이터 비용 | 과적합 |

선택 기준은 feature 차원, 샘플 수, 선형 분리 가능성, kernel 선택, 확률 출력 필요성이다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| Hyperplane | 클래스를 나누는 결정 경계 | 분류 기준 |
| Margin | 경계와 데이터 사이 거리 | 일반화 근거 |
| Support Vector | 경계에 가까운 핵심 샘플 | 모델 결정 |
| Kernel | 고차원 공간 내적 계산 | 비선형 분리 |
| C/Gamma | 오차 허용·kernel 영향 범위 | 튜닝 핵심 |

```text
데이터 -> kernel/feature space -> 최대마진 초평면 -> 분류
```

마진을 크게 하려면 일부 오류를 허용할 수 있으므로, soft margin 파라미터가 성능과 일반화의 균형을 결정한다.

## 4. 문제점 및 개선방안

1. **Kernel·파라미터 민감성**
   - kernel, C, gamma 선택에 따라 성능이 크게 달라진다.
   - **개선방안**: scaling 후 grid/random search와 교차 검증을 수행한다.

2. **대규모 데이터 비용**
   - 샘플 수가 많으면 학습 시간과 메모리 비용이 커진다.
   - **개선방안**: linear SVM, sampling, approximate kernel을 검토한다.

3. **확률 해석 부족**
   - 기본 SVM 출력은 확률이 아니라 decision score이다.
   - **개선방안**: Platt scaling, calibration, logistic model 대안을 고려한다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| 텍스트 분류 | TF-IDF 고차원 feature에 linear SVM 적용 | F1, 학습 시간 |
| 이미지 특징 분류 | 추출 feature를 kernel SVM으로 분류 | accuracy |
| 이상 탐지 | One-Class SVM으로 정상 영역 모델링 | 탐지율, 오탐률 |

## 6. 결론

SVM은 최대 마진 원리로 일반화 가능한 분류 경계를 찾는 모델이다. 마진, 서포트 벡터, soft margin, kernel 선택을 연결해 설명해야 고차원 데이터에서 강점과 대규모 학습 한계가 함께 드러난다.
