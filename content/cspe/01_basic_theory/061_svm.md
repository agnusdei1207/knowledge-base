## Ⅰ. 개요
- 정의: 데이터를 분류하기 위한 최적의 결정 경계(Hyperplane)를 찾는 지도학습 알고리즘임.
- 배경: 마진(Margin)을 최대화하여 미지의 데이터에 대한 일반화 성능을 높이기 위해 제안됨.
- 출제 의도:
| 분류 | 상세 |
| --- | --- |
| 핵심요소 | 서포트 벡터, 마진 최대화, 커널 트릭 |
| 주요특징 | 고차원 공간 매핑, 이상치(Outlier) 강건성 |

## Ⅱ. 구성요소
- ASCII 구조도
      [Class A]    / (Margin)
         *        /  <-- Decision Boundary
       * [SV] ---/--- [SV] *
                /           * [Class B]
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 서포트 벡터 | 결정 경계에 가장 가까운 데이터 포인트들 | 국경 수비대 |
| 마진(Margin) | 결정 경계와 서포트 벡터 사이의 거리 | 완충 지대 |
| 커널 트릭 | 저차원 데이터를 고차원으로 매핑하는 기법 | 입체 안경 |
> 요약: 마진을 극대화하는 서포트 벡터 기반의 공간 분리 알고리즘임.

## Ⅲ. 절차
- ASCII 흐름도
[데이터 입력] -> [공간 매핑] -> [마진 최적화] -> [분류 수행]
- 4단계 설명
1. 데이터 전처리: 특성 스케일링을 통해 데이터 범위를 정규화함.
2. 커널 선택: 선형, 다항식, RBF(가우시안) 중 적합한 커널을 결정함.
3. 마진 최대화: 경계와 데이터 간 거리를 최대화하는 가중치를 산출함.
4. 모델 평가: 교차 검증을 통해 일반화 오류를 측정함.
> 요약: 커널을 통한 차원 확장 후 최대 마진 경계를 산출하는 과정임.

## Ⅳ. 문제점
- 선형 불가분 데이터에 대한 과적합 위험 및 커널 선택의 어려움이 있음.

## Ⅴ. 개선방안
- 단기: 슬랙 변수(Soft Margin) 도입으로 일부 오차를 허용함.
- 중기: 하이퍼파라미터(C, Gamma) 튜닝 자동화 도구를 활용함.
- 장기: 딥러닝 기반의 자동 특성 추출 모델과 결합함.

## Ⅵ. 전망
- 신경망 기반 특성 추출기와 결합한 Hybrid-SVM 모델링이 핵심이며, 소량의 고차원 데이터(Bio/Medical) 분류 시 일반화 성능 보장을 위한 커널 파라미터 최적화 자동화(AutoML)가 전망됨.
- 특히 비선형 경계가 복잡한 제조 공정 데이터의 이상 탐지 분야에서 딥러닝 모델의 보완재로서 강력한 신뢰성을 제공할 것으로 기대됨.
