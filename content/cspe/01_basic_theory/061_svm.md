## Ⅰ. 개요
- **정의**: 데이터를 분류하는 최적 초평면을 찾아 마진을 최대화하는 지도학습 모델임
- **배경/필요성**: 고차원 소규모 데이터에서 과적합 없이 일반화 성능을 확보해야 할 필요성 대두
- **비유**: 두 그룹 사이에 가장 넓은 도로를 내어 경계를 긋는 도시계획사

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 마진 최대화 원리와 커널 트릭 이해 | 서포트 벡터가 결정 경계를 결정하는 구조 | 소프트 마진(C 파라미터)과 하드 마진 구분 누락 |

> 요약: 초평면 기반 마진 최대화 분류기로, 커널 트릭을 통해 비선형 데이터까지 처리 가능한 모델임

## Ⅱ. 구성요소
```text
+-----------+     +-----------+     +-----------+     +-----------+
| Input     | --> | Kernel    | --> | Quadratic | --> | Decision  |
| Features  |     | Mapping   |     | Optimize  |     | Boundary  |
+-----------+     +-----------+     +-----------+     +-----------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 초평면(Hyperplane) | 클래스 간 분리 기준이 되는 (n-1)차원 평면 | 국경선 |
| 서포트 벡터 | 초평면에 가장 가까운 양쪽 클래스의 데이터 포인트 | 최전방 초소 |
| 마진(Margin) | 서포트 벡터와 초평면 사이 거리의 2배 | 비무장지대 폭 |
| 커널 함수 | 내적 연산으로 고차원 매핑을 암묵적으로 수행하는 함수(RBF, Poly 등) | 차원 확장 렌즈 |

> 요약: 서포트 벡터가 결정하는 초평면의 마진을 최대화하며, 커널 함수로 비선형 분리를 수행함

## Ⅲ. 절차
```text
+-----------+     +-----------+     +-----------+     +-----------+
| Feature   | --> | Kernel    | --> | Margin    | --> | Class     |
| Scaling   |     | Transform |     | Optimize  |     | Predict   |
+-----------+     +-----------+     +-----------+     +-----------+
```

1. **피처 스케일링** — SVM은 거리 기반이므로 Min-Max 또는 Z-Score 정규화 필수
2. **커널 변환** — 선형 분리 불가 시 RBF·Poly 커널로 고차원 특징 공간에 매핑
3. **QP 최적화** — 라그랑주 승수법으로 마진 최대화 이중 문제(Dual Problem) 풀이
4. **분류 예측** — 새 데이터의 초평면 기준 부호(sign)로 클래스 결정

> 요약: 스케일링 후 커널 변환, 이차계획법(QP)으로 최적 초평면을 산출하여 분류를 수행함

## Ⅳ. 문제점
- **대규모 데이터 확장성 한계**: 학습 시간 복잡도가 O(n²)~O(n³)으로 10만건 초과 시 실용성 저하
- **하이퍼파라미터 민감성**: C(오분류 허용도)와 γ(커널 폭)의 조합에 따라 성능 편차가 큼
- **다중 클래스 비효율**: 기본적으로 이진 분류기이므로 OvO/OvR 전략 시 모델 수 급증

> 요약: 대규모 데이터의 연산 비용, 파라미터 튜닝 난도, 다중 클래스 확장 구조가 주요 제약임

## Ⅴ. 개선방안
1. 단기: SGD 기반 선형 SVM(LinearSVC) 적용으로 대규모 데이터셋 학습 시간을 O(n)으로 단축
2. 중기: Optuna 등 베이지안 최적화를 활용한 C·γ 자동 탐색 파이프라인 구축
3. 장기: SHAP 등 XAI 기법과 결합하여 서포트 벡터 기반 의사결정 근거의 설명력 확보

- **다중 클래스 비효율**: 클래스 수 증가 -> DAG-SVM 또는 Crammer-Singer 다중분류 알고리즘 적용 (지표: 모델 수 감소율)

> 요약: 선형 SVM 전환, 자동 튜닝 파이프라인, XAI 결합으로 실용성과 설명력을 동시에 확보함

## Ⅵ. 전망
- 향후 발전 방향: 소규모 고차원 정형 데이터(의료 진단, 이상탐지) 영역에서 경량 베이스라인으로 지속 활용
- 기술사적 판단: 딥러닝 대비 데이터 효율성이 높아 레이블 확보가 어려운 도메인에서 여전히 유효함
- 기술사 제언: 커널 선택 근거와 정규화 파라미터 설정의 정량적 기준을 답안에서 명시해야 차별화됨
