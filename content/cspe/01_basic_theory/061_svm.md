# 061. SVM 서포트 벡터 머신 (Support Vector Machine) [출제: 132회]

## 1. 개요

- **정의/개념**: 두 클래스 사이의 거리인 마진(Margin)을 최대화하는 최적의 초평면(Hyperplane)을 찾아 데이터를 분류하는 공간 분할 기반의 지도 학습 모델임
- **배경/필요성**: 단순히 데이터를 맞히는 것뿐만 아니라 새로운 데이터에 대한 일반화(Generalization) 능력을 극대화하기 위해, 경계면과 가장 가까운 데이터 포인트(Support Vector)들 사이의 여유 공간을 최대한 확보할 필요가 있음

## 2. 특징 및 비교

| 판단 기준 | SVM (Support Vector Machine) | 로지스틱 회귀 (Logistic Regression) | 결정 트리 (Decision Tree) |
|:---|:---|:---|:---|
| **분류 원리** | 마진 최대화 (기하적 접근) | 클래스 소속 확률 (통계적 접근) | 조건 분기 기반 영역 분할 |
| **비선형 처리** | 커널 트릭 (Kernel Trick) | 변수 변환/상호작용항 추가 | 트리 깊이 증가를 통한 분할 |
| **데이터 차원** | 고차원 데이터에 강함 | 차원이 많으면 과적합 위험 | 차원보다 데이터 수에 영향 |
| **주요 특징** | 전역 최적해(Convex) 보장 | 확률적 해석 용이 | 결과 해석(설명력) 탁월 |

> 요약: SVM은 고차원 공간에서도 마진 최대화를 통해 강력한 일반화 성능을 제공함

## 3. 구성요소/구조

- **구성요소**:
  - **Support Vectors**: 결정 경계(초평면)와 가장 가까이 위치하여 경계의 위치와 기울기를 결정하는 핵심 데이터들임
  - **Hyperplane**: n차원 공간에서 두 클래스를 나누는 (n-1)차원 부분 공간임
  - **Margin**: 초평면과 서포트 벡터 사이의 최단 거리로, Hard Margin과 Soft Margin 방식이 있음
  - **Kernel Function**: 저차원 데이터를 고차원 특징 공간으로 매핑하여 비선형 분리를 가능케 함 (Linear, RBF, Poly)
  - **Slack Variable ($\xi$)**: Soft Margin SVM에서 일부 오분류를 허용하여 과적합을 방지하기 위한 여유 변수임

- **구조도**:
```text
  [Class A]              [Class B]
      o      /        /      x
    o   o   /        /   x  x
 서포트벡터->[S1]  [S2]<-서포트벡터
          /   |    /
         /<-마진->/
        /   [H]  / 
           초평면
```

## 4. 문제점 및 개선방안

1. **[대용량 데이터 처리 한계]**: 데이터 수($n$)의 제곱~세제곱에 비례하는 연산 복잡도로 인해 수십만 건 이상의 데이터 학습 시 속도가 급격히 느려짐
   - **개선방안**: 점진적 학습이 가능한 Online SVM을 사용하거나 데이터 샘플링, 선형 커널 기반의 SGD 학습을 수행함 (확인: 학습 시간)
2. **[커널 및 파라미터 민감도]**: $C$(오차 허용 정도)와 $\gamma$(커널 영향력 범위) 값에 따라 성능 편차가 크고 최적값 탐색에 비용이 발생함
   - **개선방안**: 그리드 서치(Grid Search)와 교차 검증(K-Fold)을 병행하여 최적의 조합을 찾음 (확인: Validation Accuracy)
3. **[확률 해석의 부재]**: SVM 결과값은 경계로부터의 거리일 뿐 직접적인 확률값이 아님
   - **개선방안**: Platt Scaling 기법을 적용하여 거리를 시그모이드 함수를 통해 확률값으로 변환하여 활용함 (확인: Calibration Curve)

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| **텍스트 분류 (NLP)** | 문서의 TF-IDF 벡터를 고차원 특징으로 사용하여 스팸/카테고리 분류 | F1-Score, Precision |
| **생체 인식 (Image)** | 얼굴이나 지문의 추출된 특징 벡터를 비선형 커널 SVM으로 분류 | Recognition Rate (인식률) |
| **이상 탐지 (Security)** | One-Class SVM을 활용하여 정상 데이터의 경계를 학습하고 외곽 데이터를 탐지 | 탐지율(Recall), 오탐률(FPR) |

> 요약: SVM은 특히 피처의 차원이 샘플 수에 비해 많은 경우(High Dimensionality) 강력한 성능을 발휘함

## 6. 결론

SVM은 수학적으로 견고한 마진 최대화 이론을 바탕으로 안정적인 성능을 보장하는 대표적인 머신러닝 알고리즘임. 딥러닝이 주류가 된 현재에도 전역 최적해를 보장한다는 점과 적은 데이터로도 우수한 일반화 성능을 낸다는 이점 덕분에, 텍스트 분석이나 이상 탐지 등 정교한 경계 결정이 필요한 분야에서 여전히 필수적인 모델로 활용되고 있음.
