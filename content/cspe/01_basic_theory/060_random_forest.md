## Ⅰ. 개요
- **정의**: 다수의 결정 트리를 부트스트랩 샘플링과 변수 무작위화로 독립 생성한 후 예측을 집계하는 배깅 앙상블
- **배경/필요성**: 단일 결정 트리의 과적합·높은 분산 문제 해결(-> 059번 참조), 정형 데이터에서의 범용 베이스라인 확보 필요
- **비유**: 배심원단이 각자 독립 판단 후 다수결로 평결하는 재판 구조

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 배깅(Bagging) 원리 이해 | 부트스트랩 + 변수 무작위화 조합 | 배깅(RF)과 부스팅(XGBoost) 차이 혼동 금지 |
| 앙상블의 분산 감소 효과 | 개별 트리 간 상관관계 감소 메커니즘 | OOB(Out-of-Bag) 에러 개념 설명 필수 |

> 요약: 랜덤 포레스트는 부트스트랩 샘플링과 변수 무작위화를 결합하여 분산을 감소시키는 배깅 앙상블임

## Ⅱ. 구성요소
```text
+----------------+       +----------------+       +----------------+
| Bootstrap      |       | Random Feature |       | Majority Vote  |
| Sampling       | ----> | Decision Trees | ----> | / Averaging    |
| (N subsets)    |       | (N weak trees) |       | (Final Output) |
+----------------+       +----------------+       +----------------+
        |                        |
   복원 추출 N회          sqrt(p)개 변수만 사용
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 부트스트랩 샘플 | 원본 데이터에서 복원 추출로 생성한 N개 부분 데이터셋 (약 63.2% 고유 샘플 포함) | 변형 문제집 |
| 개별 트리(Weak Learner) | 무작위 샘플·무작위 변수로 학습된 완전 성장 결정 트리 | 배심원 개인 |
| 집계(Aggregation) | 분류->다수결 투표, 회귀->평균으로 최종 예측 산출 | 배심원단 평결 |

> 요약: 복원 추출 데이터와 무작위 변수로 다수 트리를 학습한 후, 다수결·평균으로 집계함

## Ⅲ. 절차
```text
+----------------+       +----------------+       +----------------+       +----------------+
| Bootstrap      |       | Feature Random |       | Tree Training  |       | Aggregation    |
| (Resample)     | ----> | (sqrt(p) pick) | ----> | (Grow Full)    | ----> | (Vote / Mean)  |
+----------------+       +----------------+       +----------------+       +----------------+
```

1. **부트스트랩 샘플링** — 전체 훈련 데이터에서 복원 추출로 N개 데이터셋 생성 (미추출 37%는 OOB 검증용)
2. **변수 무작위 선택** — 각 노드 분할 시 전체 변수 p개 중 sqrt(p)개만 후보로 추출하여 트리 간 상관 감소
3. **개별 트리 학습** — 각 부트스트랩 샘플로 가지치기 없이 완전 성장 결정 트리 병렬 학습
4. **결과 집계** — 분류 문제: 다수결 투표(Hard Voting), 회귀 문제: 예측값 산술 평균

> 요약: 복원 추출 -> 변수 무작위화 -> 완전 성장 트리 학습 -> 다수결/평균 집계 순서로 수행함

## Ⅳ. 문제점
- 해석력 저하: 수백 개 트리가 결합되어 개별 예측 근거를 직관적으로 설명 불가
- 추론 지연: 예측 시 N개 트리 전체를 순회해야 하므로 실시간 서빙(< 10ms) 요건 충족 곤란
- 고차원 희소 데이터 부적합: 텍스트·원핫 인코딩 등 희소 피처에서는 트리 분할 효율 저하

> 요약: 해석력·추론 속도·희소 데이터 처리가 랜덤 포레스트의 주요 약점임

## Ⅴ. 개선방안
1. 단기: Feature Importance(MDI/MDA) 기능으로 변수 기여도를 간접 해석하여 설명력 보완
2. 중기: n_estimators 튜닝 및 트리 병렬 추론(멀티스레드) 최적화로 추론 지연 감소
3. 장기: 희소 고차원 데이터는 임베딩 전처리 후 RF 적용, 또는 Gradient Boosting(XGBoost/LightGBM)으로 전환

- 해석력 저하: 다수 트리 블랙박스 -> SHAP TreeExplainer 적용 (지표: 변수별 SHAP 값)
- 추론 지연: N개 트리 순회 -> ONNX 변환 + 배치 추론 (지표: p99 latency < 50ms)
- 희소 데이터: 트리 분할 비효율 -> TF-IDF 축소 또는 임베딩 변환 (지표: AUC 비교)

> 요약: Feature Importance·추론 최적화·임베딩 전처리로 RF의 한계를 보완하거나 부스팅으로 전환함

## Ⅵ. 전망
- 향후 발전 방향: 정형(Tabular) 데이터에서 딥러닝(TabNet 등)보다 RF/GBDT 계열이 우세하다는 벤치마크 결과가 지속 보고됨
- 기술사적 판단: 배깅의 원리는 모델 앙상블의 기초이며, 부스팅(XGBoost, LightGBM)과의 비교·선택이 실무 설계의 핵심 의사결정
- 기술사 제언: 정형 데이터 ML 파이프라인 설계 시 RF를 초기 베이스라인으로 수립하고, OOB 에러 기반 조기 성능 검증 후 부스팅 전환 여부를 판단할 것
