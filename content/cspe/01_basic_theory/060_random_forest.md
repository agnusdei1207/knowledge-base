## 미리 알고가기

- 앙상블 학습: 여러 모델의 예측을 투표·평균·가중합으로 결합하는 방법임
- 배깅: 부트스트랩 표본으로 여러 모델을 독립 학습한 뒤 결과를 집계하는 방식임
- 부트스트랩: 원본 데이터에서 중복을 허용해 같은 크기의 표본을 무작위 추출하는 방법임
- 변수 무작위 선택: 각 분할에서 일부 변수만 후보로 사용해 트리 간 상관을 낮추는 방식임
- OOB 데이터: 부트스트랩에 뽑히지 않은 표본이며 내부 검증에 활용됨
- 분산: 학습 데이터 변화에 따라 모델 예측이 변동하는 정도임

## 작성 근거(검토용)

- 개요는 부트스트랩, 변수 무작위 선택, 집계를 포함해 랜덤 포레스트의 차이를 명확히 함
- 특징은 다양성 확보, 분산 감소, 병렬성, 자원 증가를 서로 다른 판단 축으로 둠
- 비교표는 단일 트리와 부스팅 사이에서 랜덤 포레스트의 위치를 보이게 구성함
- 구성요소는 표본 추출기, 변수 후보, 트리, 집계기, OOB 평가로 알고리즘 단위를 일치시킴
- 절차는 표본 생성부터 예측 집계까지 배깅 흐름을 단계화함
- 기준 모델 성능과 변수 중요도 편향은 랜덤 포레스트의 핵심 검증점임

## Ⅰ. 개요

- **정의/개념**: 랜덤 포레스트는 부트스트랩 데이터와 무작위 변수 선택으로 여러 결정 트리를 학습한 뒤 투표나 평균으로 예측을 집계하는 배깅 앙상블임
- **배경/필요성**: 단일 결정 트리의 분산과 과적합 위험을 줄이기 위해 서로 다른 트리의 예측을 결합해야 함

## Ⅱ. 특징

- 부트스트랩 표본과 변수 무작위 선택으로 서로 다른 트리를 만들어 상관을 낮춤
- 분류는 다수결, 회귀는 평균으로 집계해 단일 트리의 높은 분산을 줄임
- 트리들이 독립적으로 학습되어 병렬 처리와 OOB 기반 내부 검증이 가능함
- 더 많은 트리 예측을 평균하면 앙상블 예측의 분산은 줄어들지만 메모리와 추론 지연은 증가함

## Ⅲ. 종류 및 비교

| 판단 기준 | 결정 트리 | 랜덤 포레스트 | 부스팅 |
|:---|:---|:---|:---|
| 학습 방식 | 단일 트리 학습 | 독립 트리 병렬 학습 | 이전 오류를 순차 보정 |
| 예측 결합 | 하나의 트리 경로로 예측 | 부트스트랩 트리의 투표·평균 | 이전 모델의 잔차를 보정한 결과를 합산 |
| 오차 통제 | 깊이·가지치기로 과적합을 제한 | 표본·특징 무작위화로 트리 간 상관과 분산을 줄임 | 학습률·트리 수·깊이로 순차 보정 폭을 제한 |
| 적용 조건 | 단일 의사결정 규칙을 설명할 때 | 표 형식 데이터에서 단일 트리의 분산을 줄일 때 | 순차 잔차 보정과 하이퍼파라미터 검증이 가능할 때 |

> 요약: 랜덤 포레스트는 표본과 특징을 무작위로 선택한 여러 트리의 결과를 결합해 단일 트리의 분산을 줄임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 부트스트랩 표본 추출기 | 트리마다 다른 학습 데이터를 만들어 예측 다양성을 확보함 |
| 변수 후보 집합 | 각 노드에서 일부 변수만 비교해 트리 간 유사도를 낮춤 |
| 개별 결정 트리 | 각 부트스트랩 표본과 변수 후보로 학습하는 기본 예측기임 |
| 집계기 | 분류는 투표, 회귀는 평균으로 여러 예측을 하나로 결합함 |
| OOB 평가 | 각 트리의 부트스트랩 표본에 포함되지 않은 데이터로 일반화 성능을 내부 추정함 |

> 요약: 랜덤 포레스트는 다른 표본과 변수 후보로 만든 여러 트리의 예측을 집계함.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+      +----------+      +----------+      +----------+
| 표본 추출 | ---> | 변수 제한 | ---> | 트리 학습 | ---> | 예측 집계 |
+----------+      +----------+      +----------+      +----------+
```

1. **표본 생성**: 원본 데이터에서 트리 수만큼 부트스트랩 표본을 만듦
2. **변수 제한**: 각 노드 분할 시 전체 변수 중 일부만 후보로 사용함
3. **트리 학습**: 각 부트스트랩 표본과 변수 후보로 결정 트리를 독립적으로 학습함
4. **예측 집계**: 새 입력에 대한 모든 트리 예측을 투표나 평균으로 결합함

> 요약: 부트스트랩과 변수 무작위성이 트리 간 상관을 낮춰 집계 효과를 높임.

## Ⅵ. 실무 사례

1. 서버 장애 예측은 트리 수·깊이를 조정하고 OOB 점수·p95 지연으로 검증함
2. 데이터센터 장애 원인 분석은 순열 중요도·SHAP을 적용하고 폴드별 상위 변수 순위 일치율로 검증함

## Ⅶ. 결론

- 랜덤 포레스트는 무작위성과 집계로 결정 트리의 분산을 낮추는 앙상블이며, 분산 감소와 해석성·자원 비용의 균형이 핵심임
