# 060. 랜덤 포레스트 (Random Forest)

## Ⅰ. 개요

- **정의/개념**: 다수의 결정 트리(Decision Tree)를 배깅(Bagging) 기법을 이용해 병렬로 결합하고, 무작위로 선택된 변수 부분집합을 활용하여 예측 결과의 분산을 줄이는 앙상블(Ensemble) 학습 모델임
- **배경/필요성**: 단일 결정 트리는 학습 데이터에 민감하여 분산(Variance)이 높고 과적합되기 쉬우므로, 여러 개의 트리를 학습시키고 그 결과를 결합(Voting/Averaging)하여 모델의 안정성과 일반화 성능을 높이기 위해 필요함

## Ⅱ. 특징 및 비교

| 판단 기준 | 결정 트리 (Decision Tree) | 랜덤 포레스트 (Random Forest) | Gradient Boosting (XGBoost 등) |
|:---|:---|:---|:---|
| **학습 방식** | 단일 트리 구성 | 여러 트리 병렬 학습 (Bagging) | 트리 순차 보정 (Boosting) |
| **변수 선택** | 모든 변수 고려 | 무작위 변수 부분집합 선택 | 잔차를 줄이는 최적 변수 선택 |
| **주요 장점** | 해석 용이, 계산 빠름 | 과적합 방지 탁월, 노이즈 강함 | 예측 정확도 극대화 |
| **주요 단점** | 높은 분산, 과적합 위험 | 해석 어려움, 메모리 사용량 | 느린 학습 속도, 파라미터 민감 |

> 요약: 랜덤 포레스트는 배깅과 무작위 변수 선택을 통해 트리 간 상관관계를 낮추어 모델의 견고함을 확보함

## Ⅲ. 구성요소/구조

- **구성요소**:
  - **Bootstrap Sampling**: 원본 데이터에서 복원 추출을 통해 여러 개의 서로 다른 훈련 데이터셋을 생성함
  - **Random Feature Selection**: 각 노드 분할 시 전체 변수가 아닌 무작위로 추출된 변수군 내에서 최적의 분할점을 찾음
  - **Aggregation**: 각 트리의 예측치를 합산하여 다수결 투표(분류) 또는 평균(회귀)을 통해 최종 결과를 산출함
  - **OOB (Out-of-Bag) Error**: 부트스트랩 샘플링에서 제외된 데이터를 활용해 별도의 검증 세트 없이 모델 성능을 내부적으로 평가함

- **구조도**:
```text
[Original Dataset]
      |
      +---- (Bootstrap) ----> [Sample 1] ----> [Tree 1] ----+
      |                                                     |
      +---- (Bootstrap) ----> [Sample 2] ----> [Tree 2] ----+---> [Final Prediction]
      |                                                     |    (Voting/Average)
      +---- (Bootstrap) ----> [Sample N] ----> [Tree N] ----+
```

## Ⅳ. 문제점 및 개선방안

1. **[블랙박스화 및 해석 한계]**: 수백 개의 트리가 결합되어 단일 트리처럼 의사결정 경로를 직관적으로 파악하기 어려움
   - **개선방안**: 변수 중요도(Feature Importance) 산출이나 SHAP(Shapley Additive Explanations) 라이브러리를 활용해 변수별 기여도를 분석함 (확인: 중요도 일관성)
2. **[메모리 및 연산 비용]**: 트리의 개수가 늘어날수록 모델의 크기가 커지고 추론(Inference) 시간이 증가함
   - **개선방안**: 트리의 최대 개수와 깊이를 제한하거나, 중복되거나 영향력이 낮은 트리를 제거하는 가지치기(Pruning)를 수행함 (확인: 추론 지연 시간)
3. **[범주형 변수의 편향]**: 고유한 값(Cardinality)이 많은 범주형 변수가 변수 중요도 측정에서 과대평가되는 경향이 있음
   - **개선방안**: 순열 중요도(Permutation Importance)를 사용하거나 전처리를 통해 범주형 변수의 영향력을 정규화함 (확인: 변수별 중요도 분포)

## Ⅴ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| **부정 거래 탐지 (FDS)** | 다양한 거래 특징을 병렬 트리로 학습하여 이상 패턴 식별 | Recall, Precision, AUC |
| **고객 이탈 예측** | 고객 행동 로그를 기반으로 이탈 가능성이 높은 군집 분류 | F1-Score, Lift Chart |
| **중요 변수 스크리닝** | 모델 구축 초기 단계에서 영향력 있는 핵심 변수를 선별하는 용도 | Feature Importance Rank |

> 요약: 실무에서는 별도의 하이퍼파라미터 튜닝 없이도 안정적인 성능을 내므로, 베이스라인 모델로 가장 널리 쓰임

## Ⅵ. 결론

랜덤 포레스트는 배깅의 원리를 극대화하여 머신러닝의 고전적인 문제인 편향-분산 트레이드오프를 성공적으로 제어한 알고리즘임. 딥러닝과 부스팅 모델의 강세 속에서도 데이터 전처리에 대한 낮은 의존도, 우수한 일반화 성능, 변수 중요도 제공이라는 명확한 장점 덕분에 정형 데이터 분석 분야에서 여전히 'Must-have' 모델로서 강력한 위상을 유지하고 있음.
