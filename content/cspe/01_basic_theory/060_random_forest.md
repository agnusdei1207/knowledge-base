## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 다수의 결정 트리를 독립적으로 생성하고 그 예측을 취합하여 최종 결과를 도출하는 배깅(Bagging) 기반 앙상블 기법임 |
| 배경/필요성 | 단일 결정 트리의 고질적 한계인 과적합과 높은 분산 문제를 해결하여 안정적 예측 성능 확보 |
| 출제 의도 | 부트스트랩(Bootstrap) 샘플링 및 변수 무작위 추출을 통한 모델의 다양성 확보 원리 평가 |

## Ⅱ. 구성요소
```text
+----------------+       +----------------+       +----------------+
| Bootstrap      |       | Random Trees   |       | Majority Vote  |
| Samples        | ----> | (Weak Learners)| ----> | Final Predict  |
+----------------+       +----------------+       +----------------+
```
| 부트스트랩 샘플| 원본 데이터에서 복원 추출로 만든 다양한 부분 데이터셋 | 모의고사 변형 문제 |
| 개별 트리 (Tree)| 무작위 샘플과 무작위 변수 집합으로 학습된 결정 트리 | 배심원 개개인 |
| 투표 (Voting) | 여러 트리의 결과를 합산(다수결/평균)하는 집계 과정 | 배심원단 평결 |
> 요약: 랜덤 포레스트는 부트스트랩 샘플과 다수 트리, 집계 투표 과정으로 구성된 앙상블 모델임

## Ⅲ. 절차
```text
+----------------+       +----------------+       +----------------+       +----------------+
| Bootstrapping  |       | Feature Select |       | Tree Train     |       | Aggregation    |
| (Sample data)  | ----> | (Random Vars)  | ----> | (Grow Forest)  | ----> | (Voting/Mean)  |
+----------------+       +----------------+       +----------------+       +----------------+
```
1. 부트스트랩: 전체 훈련 데이터에서 중복을 허용하여 N개의 데이터셋 무작위 샘플링
2. 무작위 변수 선택: 트리 분할 시 전체 변수가 아닌 일부 무작위 변수 집합 내에서 최적 분할 탐색
3. 개별 트리 훈련: 생성된 각 샘플셋에 대해 완전히 성장한 결정 트리 N개 병렬 학습
4. 결과 취합: 개별 트리의 예측 결과를 다수결 투표(분류)나 평균(회귀)을 통해 최종 산출
> 요약: 데이터와 변수를 무작위로 추출하여 여러 트리를 학습한 후 예측 결과를 취합함

## Ⅳ. 문제점
- 모델 해석력 저하: 수백 개의 트리가 결합된 블랙박스가 되어 단일 트리 대비 직관적 해석 불가
- 예측 속도 저하: 추론 시 다수 트리의 결과를 모두 연산하고 취합해야 하므로 리얼타임에 불리함
- 고차원 희소 데이터 취약성: 텍스트 데이터 등 극도로 희소한 데이터에서는 SVM 등에 성능이 밀림

## Ⅴ. 개선방안
- 단기 방안: 변수 중요도(Feature Importance) 기능을 활용하여 간접적인 모델 해석력 보완
- 중기 방안: 시스템 리소스를 고려하여 트리 개수(n_estimators)를 최적화해 예측 지연 감소
- 장기 방안: 고차원 희소 데이터에는 선형 모델을 사용하거나 딥러닝 기반 임베딩 기법 병행 도입

## Ⅵ. 전망
- 정형(Tabular) 데이터 처리 영역에서 딥러닝에 버금가거나 우세한 성능을 내는 표준 베이스라인으로 확고함
