# 📖 【암기용】 개념 완전 이해

> 목적: 랜덤 포레스트를 처음 보는 사람도 여러 결정 트리를 묶어 분산을 줄이는 원리를 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 부트스트랩 데이터와 무작위 특성 선택으로 만든 여러 결정 트리의 앙상블
- **왜 필요한가**:
  - 단일 결정 트리는 데이터 변화에 분기 구조가 크게 바뀌는 고분산 모델임.
  - 랜덤 포레스트는 여러 트리의 투표·평균으로 예측 변동을 줄임.
- **핵심 직관**: 한 명의 의사결정보다 서로 다른 관점을 가진 여러 트리의 다수결을 쓰는 방식임.

## 깊이 이해
- **배경·문제의식**:
  - 결정 트리는 해석이 쉽지만 훈련 데이터 잡음에 민감함.
  - Bagging과 특성 무작위성을 결합하면 트리 간 상관을 낮추고 일반화 오차를 줄일 수 있음.
- **작동 원리**:
  - 원본 데이터에서 복원추출로 여러 학습셋을 만들고, 각 노드에서 전체 특성 중 일부만 후보로 분기함.
  - 분류는 다수결, 회귀는 평균값으로 출력함.
- **비유**:
  - 같은 사건을 여러 전문가가 일부 자료만 보고 판단한 뒤, 최종 결론은 투표로 정하는 구조임.
  - 개인 편향은 평균화되고 공통 신호가 남음.
- **구체 예시**: 100개 트리, max_features=sqrt(p), bootstrap=True로 학습하면 각 트리는 서로 다른 샘플과 특성 조합으로 분기함.
- **흔한 오해·주의점**:
  - 트리 수를 늘리면 분산은 줄지만 해석성과 추론 비용이 증가함.
  - OOB(Out-of-Bag) 오류, 변수 중요도 편향, 클래스 불균형을 함께 봐야 함.

## 연결 개념
- Bagging(Bootstrap Aggregating) — 복원추출 학습셋과 평균화 기법
- 결정 트리(Decision Tree) — 랜덤 포레스트의 기본 학습기
- Gradient Boosting — 순차적으로 오차를 보정하는 다른 트리 앙상블

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 랜덤 포레스트는 부트스트랩 샘플과 무작위 특성 선택으로 학습한 다수 결정 트리의 Bagging 앙상블임.
> 2. **가치**: 단일 트리의 과적합과 분산을 줄이고 변수 중요도, OOB 오류로 검증 정보를 제공함.
> 3. **판단 포인트**: n_estimators, max_features, OOB Error, 클래스 불균형, 해석성 저하를 함께 제시해야 함.

---

## Ⅰ. 개요 및 필요성

- 정의: 랜덤 포레스트는 여러 트리의 투표 모델이다.
- 배경: 단일 결정 트리는 작은 데이터 변화에도 분기 규칙이 달라져 운영 예측값이 흔들릴 수 있음.
- 필요성: 랜덤 포레스트는 샘플과 특성 무작위화로 트리 상관을 낮추고 일반화 오차를 관리함.

---

## Ⅱ. 구조 및 구성요소

```text
Dataset -> Bootstrap Samples -> Multiple Decision Trees -> Voting/Averaging -> Prediction
             +-> Random Feature Subset -> OOB Samples -> OOB Error
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Bootstrap Sampling | 복원추출로 트리별 학습셋 생성 | 약 63.2% 고유 샘플 포함 |
| Random Feature Subset | 노드별 후보 특성 일부 선택 | 분류는 sqrt(p) 관행 |
| Decision Trees | 독립 트리 다수 학습 | n_estimators 100~500 |
| Aggregation | 분류 다수결, 회귀 평균 | 클래스 확률 산출 가능 |
| OOB Evaluation | 미사용 샘플로 내부 검증 | 별도 검증셋 부족 시 참고 |

> 요약: 랜덤 포레스트는 샘플과 특성을 무작위화한 다수 트리를 결합해 분산을 줄임.

---

## Ⅲ. 동작원리 및 흐름도

```text
원본 데이터 -> 복원추출 -> 트리별 학습셋 생성
-> 노드별 특성 일부 선택 -> 트리 학습
-> 다수결/평균 -> OOB Error 확인 -> 최종 예측
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | Bootstrap으로 트리별 데이터 구성 | OOB 샘플 비율 약 36.8% |
| 2 | 각 노드에서 일부 특성으로 분기 | max_features=sqrt(p) |
| 3 | 다수 트리 학습 후 예측 결합 | n_estimators 수렴 곡선 |
| 4 | OOB·검증셋 지표로 모델 선택 | OOB Error, F1, RMSE |

> 요약: 랜덤 포레스트는 Bootstrap, 특성 무작위화, 앙상블 결합, OOB 검증 순서로 동작함.

---

## Ⅳ. 특징

| 구분 | 내용 | 판단 포인트 |
|:---|:---|:---|
| 장점 | 단일 트리 대비 분산 감소 | OOB Error, 검증 F1 |
| 한계 | 트리 수 증가 시 추론 지연·해석 부담 증가 | p95 추론 50ms 이하 목표 |
| 비교 대상 | GBDT는 순차 보정, RF는 병렬 Bagging | 데이터 잡음·학습 시간 기준 |

> 요약: 랜덤 포레스트는 병렬 트리 앙상블로 분산을 줄이나 해석성과 추론 비용을 함께 관리해야 함.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존/대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | 단일 트리는 하나의 분기 규칙 | 다수 트리 투표·평균 | 고분산 데이터면 RF |
| 비용/성능 | GBDT는 순차 학습 | RF는 트리 병렬 학습 | CPU 병렬 학습 환경 |
| 운영/위험 | 해석은 단일 트리가 우위 | RF는 변수 중요도 중심 | 규제 설명 요구 수준 |

> 요약: 분산 감소와 병렬 학습이 중요하면 랜덤 포레스트, 점수 최대화가 목표이면 GBDT를 비교함.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 추론 지연 | 트리 수 과다 | n_estimators 100~300, 모델 압축 | p95 추론 시간 |
| 중요도 편향 | 고카디널리티 변수 선호 | Permutation Importance, SHAP | 변수 중요도 순위 변화 |
| 클래스 불균형 | 다수 클래스 투표 우세 | class_weight, Balanced RF | Recall, PR-AUC |

> 요약: 랜덤 포레스트 운영 리스크는 트리 수, 변수 중요도 검증, 클래스 불균형 보정으로 통제함.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 예측 품질 | F1 0.85 이상 또는 RMSE 10% 감소 | Hold-out, OOB Error |
| 추론 비용 | p95 50ms 이하, 모델 크기 200MB 이하 | 벤치마크, APM |
| 운영/보안 | 모델·데이터 버전 100% 추적 | MLflow, 감사 로그 |

> 요약: 랜덤 포레스트는 예측 지표, 추론 지연, 모델 추적성을 함께 만족해야 배포 후보가 됨.

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 — 단계별 또는 항목별):**
1. 기준선 구성: n_estimators=100, max_features=sqrt(p), OOB=True로 학습하고 단일 트리 대비 F1 5%p 이상 차이를 확인.
2. 비용 통제: 트리 수 100/300/500별 p95 추론 시간과 OOB Error를 비교해 50ms 이하 조합을 선택.
3. 해석 보완: Permutation Importance와 SHAP 상위 10개 변수를 산출하고 업무 규칙과 충돌하는 변수는 제거 검토.

**결론 (2줄):**
- 기술사 판단: 단일 트리의 분산이 문제이면 랜덤 포레스트, 최고 예측 지표와 순위화가 목표이면 GBDT를 병행 평가함.
- 향후 방향: 트리 앙상블은 AutoML, Feature Store, XAI 도구와 결합해 표준 업무 예측 모델로 운영됨.
