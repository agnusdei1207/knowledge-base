## 미리 알고가기

- bagging: 복원추출한 여러 샘플로 모델을 병렬 학습하는 방식임
- bootstrap sample: 원본 데이터에서 중복 허용 추출한 학습셋임
- OOB: 특정 트리 학습에 사용되지 않은 검증용 샘플임

## Ⅰ. 개요

- **정의/개념**: 랜덤 포레스트는 다수의 결정 트리를 배깅과 무작위 특징 선택으로 학습한 뒤 평균 또는 다수결로 결합해 일반화 성능을 높이는 앙상블 모델임
- **배경/필요성**: 단일 결정 트리는 해석성은 좋지만 분산과 과적합이 커서, 이를 안정화한 실전형 트리 기반 모델이 필요함

## Ⅱ. 특징

- bootstrap과 feature randomness로 트리 간 상관관계를 줄임
- 튜닝 부담이 비교적 적고 기본 성능이 안정적임
- 비선형 관계와 변수 상호작용을 잘 포착함
- 모델 크기와 추론 비용이 증가하고 해석성은 떨어짐

## Ⅲ. 종류 및 비교

| 판단 기준 | 결정 트리 | 랜덤 포레스트 | 부스팅 계열 |
|:---|:---|:---|:---|
| 학습 방식 | 단일 트리 | 병렬 앙상블 | 순차 보정 |
| 과적합 위험 | 큼 | 낮음 | 데이터에 따라 다름 |
| 해석성 | 높음 | 중간~낮음 | 낮음 |
| 대표 강점 | 규칙 설명 | 안정성 | 최고 성능 추구 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| bootstrap 샘플 | 트리마다 다른 학습 데이터를 만듦 다양성 확보 장치임 |
| 개별 결정 트리 | 독립적으로 학습됨 기본 예측기임 |
| 무작위 특징 선택 | 각 분할 시 일부 특징만 고려하고 상관관계 감소 핵심임 |
| 앙상블 집계 | 평균 또는 다수결을 수행하고 분산 감소 효과를 냄 |

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 샘플추출 | --> | 트리학습 | --> | 예측집계 | --> | 성능평가 |
+----------+     +----------+     +----------+     +----------+
```

1. **샘플추출**: 트리마다 bootstrap 데이터를 만듦
2. **트리학습**: 무작위 특징 후보로 분할하며 독립 학습함
3. **예측집계**: 분류는 다수결, 회귀는 평균을 사용함
4. **성능평가**: OOB 또는 검증셋으로 일반화 성능을 확인함

## Ⅵ. 문제점 및 해결 방안

1. **모델이 커져 메모리 사용량이 증가함**: 트리 수와 깊이가 커질수록 비용이 늘어남
   - **해결 방안**: 트리 수와 깊이를 제한하고 중요 변수만 사용하고 model size, inference latency로 검증함
2. **해석성이 낮아짐**: 수백 개 트리를 직접 읽기 어렵다
   - **해결 방안**: feature importance와 SHAP으로 보조 설명하고 설명 일관성로 검증함
3. **고차원 희소 데이터에는 비효율적일 수 있음**: 텍스트처럼 희소 특징이 많으면 분할 효과가 낮다
   - **해결 방안**: 선형 모델이나 boosting과 비교 검토하고 CV score로 검증함

## Ⅶ. 적용 사례

- 금융 리스크 분류: 다양한 정형 데이터를 안정적으로 분류함, 확인 지표는 ROC-AUC임
- 제조 불량 예측: 변수 상호작용을 반영해 품질을 예측함, 확인 지표는 F1과 recall임
- 장애 예측 분석: OOB 평가로 빠르게 기준 모델을 구축함, 확인 지표는 OOB score임

## Ⅷ. 결론

랜덤 포레스트의 핵심은 단일 트리의 불안정을 평균화하는 데 있으므로, 해석성 일부를 포기하고 안정적 일반화를 얻는 선택으로 봐야 함.
