## Ⅰ. 개요
- 정의: 다수의 결정 트리를 생성하고 그 결과를 투표(Voting)하여 최종 결론을 내는 앙상블 기법임
- 배경: 단일 결정 트리의 과적합 한계 극복 및 고성능 범용 모델 필요
- 출제 의도:
| 구분 | 내용 |
| --- | --- |
| 핵심 | 배깅(Bagging), 부트스트랩, 무작위 특징 선택 |

## Ⅱ. 구성요소
- ASCII 구조도
  [Data] -> [Sample 1] -> [Tree 1] --\
         -> [Sample 2] -> [Tree 2] --> [Voting] -> Result
         -> [Sample 3] -> [Tree 3] --/
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 부트스트랩 | 중복 허용한 무작위 샘플링 데이터셋 | 복원추출 |
| 무작위 특징 | 각 노드 분할 시 변수 중 일부만 고려함 | 다양성 확보 |
| 다수결 투표 | 개별 트리들의 예측 중 가장 많은 것을 선택함 | 집단지성 |
> 요약: 무작위성을 부여한 여러 트리의 결합으로 일반화 성능 극대화함

## Ⅲ. 절차
- ASCII 흐름도
  [부트스트랩] -> [트리생성] -> [병렬학습] -> [결과취합]
- 4단계 설명
1. 부트스트랩: 전체 데이터에서 중복 허용하여 N개의 샘플셋 생성함
2. 트리 생성: 각 샘플셋마다 결정 트리를 독립적으로 구성함
3. 무작위 분할: 노드마다 임의의 특징 부분집합만 사용하여 분할함
4. 결과 취합: 분류는 다수결, 회귀는 평균값으로 최종 예측함
> 요약: 개별 트리의 오류를 상쇄시켜 강력한 예측 모델을 구축함

## Ⅳ. 문제점
- 트리 개수가 많아지면 모델 크기가 커지고 추론 속도 저하됨
- 개별 트리의 해석력이 결합 과정에서 희석될 수 있음

## Ⅴ. 개선방안
- (단기) 트리 개수(n_estimators)를 성능과 속도 타협점으로 튜닝함
- (중기) 특성 중요도(Feature Importance) 분석으로 주요 변수 파악함
- (장기) 그래디언트 부스팅(XGBoost, LightGBM)과 성능 비교 수행함

## Ⅵ. 전망
- Spark MLlib 등 대규모 분산 컴퓨팅 플랫폼을 통한 빅데이터 실시간 분석 및 사기 탐지(FDS) 분야의 핵심 엔진으로 활용됨
- 다차원 데이터의 특성 중요도를 정량화하여 딥러닝 모델의 특징 선택(Feature Selection) 가이드라인으로 기술 로드맵이 확장됨
- 훈련 데이터의 무작위 변동성에 강건한 모델 구조를 유지하면서도 대규모 변수를 효율적으로 처리하는 연산 최적화가 핵심 CSF임
