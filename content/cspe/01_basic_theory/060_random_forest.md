## 미리 알고가기

- 앙상블 학습: 여러 모델의 예측을 투표·평균·가중합으로 결합하는 방법임
- 부트스트랩: 원본 데이터에서 중복을 허용해 같은 크기의 표본을 무작위 추출하는 방법임
- 배깅: 부트스트랩 표본으로 여러 모델을 독립 학습한 뒤 결과를 집계하는 방식임
- 변수 무작위 선택: 각 분할에서 일부 변수만 후보로 사용해 트리 간 상관을 낮추는 방식임
- 미사용 표본(OOB 데이터): 부트스트랩에 뽑히지 않아 내부 검증에 쓰는 표본임
- 분산: 학습 데이터 변화에 따라 모델 예측이 변동하는 정도임
- 부스팅: 앞 모델의 오차를 다음 모델이 순차 보정하도록 여러 약한 모델을 결합하는 앙상블임
- 순열 중요도: 변수값을 섞었을 때 성능이 감소하는 정도로 변수 영향을 측정하는 방식임
- SHAP 값(SHapley Additive exPlanations): 샤플리 값으로 각 특성이 개별 예측에 기여한 정도를 배분한 값임

## 작성 근거(검토용)

- 개요는 부트스트랩, 변수 무작위 선택, 집계를 포함해 랜덤 포레스트의 차이를 명확히 함
- 특징은 다양성 확보, 분산 감소, 병렬성, 자원 증가를 서로 다른 판단 축으로 둠
- 비교표는 학습 메커니즘·예측 산출·주요 리스크로 세 모델의 위치를 구분함
- 구성요소는 부트스트랩 표본, 변수 후보, 개별 트리, 집계기로 알고리즘 단위를 일치시킴
- 절차는 표본 생성부터 예측 집계까지 배깅 흐름을 단계화함
- OOB 기준 성능과 변수 중요도 안정성은 랜덤 포레스트의 핵심 검증점임

## Ⅰ. 개요

- **정의/개념**: 랜덤 포레스트는 부트스트랩 데이터와 무작위 변수 선택으로 여러 결정 트리를 학습한 뒤 투표나 평균으로 예측을 집계하는 배깅 앙상블임
- **배경/필요성**: 단일 결정 트리의 분산과 과적합 위험을 줄이기 위해 서로 다른 트리의 예측을 결합해야 함

### 쉽게 이해하기 (학습용)
- 한 사람의 판단보다 여러 전문가에게 각기 다른 자료를 주고 따로 의견을 물은 뒤 다수결로 결론을 내리면 편향된 실수에 덜 흔들림

## Ⅱ. 특징

- 부트스트랩 표본과 변수 무작위 선택으로 서로 다른 트리를 만들어 상관을 낮춤
- 분류는 다수결, 회귀는 평균으로 집계해 단일 트리의 높은 분산을 줄임
- 트리들이 독립적으로 학습되어 병렬 처리와 OOB 기반 내부 검증이 가능함
- 더 많은 트리 예측을 평균하면 앙상블 예측의 분산은 줄어들지만 메모리와 추론 지연은 증가함

### 쉽게 이해하기 (학습용)
- 전문가마다 서로 다른 자료 뭉치와 질문 목록을 줘 의견이 겹치지 않게 하고, 다수결·평균으로 모아 한 사람의 실수를 상쇄함
- 전문가들은 서로 상관없이 따로 일할 수 있지만, 더 많이 부를수록 결론은 안정되는 대신 자리와 시간이 더 필요함

## Ⅲ. 종류 및 비교

| 판단 기준 | 결정 트리 | 랜덤 포레스트 | 부스팅 |
|:---|:---|:---|:---|
| 학습 메커니즘 | 단일 트리 학습 | 표본과 변수 무작위 학습 | 오류 순차 보완 |
| 예측 산출 | 단일 리프 값 | 다중 트리 집계 | 약한 학습기 가중 결합 |
| 주요 리스크 | 높은 예측 분산 | 다중 트리 자원 비용 | 노이즈 순차 증폭 |

> 요약: 랜덤 포레스트는 표본과 변수를 무작위로 선택한 여러 트리의 결과를 결합해 단일 트리의 분산을 줄임.

### 쉽게 이해하기 (학습용)
- 결정 트리는 전문가 한 명의 판단이고, 랜덤 포레스트는 각기 다른 자료를 받은 여러 전문가의 다수결이며, 부스팅은 앞 전문가가 놓친 부분을 다음 전문가가 이어서 보완하는 방식임

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 부트스트랩 표본 | 트리별 중복 허용 학습 집합 |
| 변수 후보 | 노드별 무작위 변수 부분집합 |
| 개별 결정 트리 | 독립 기본 예측기 |
| 집계기 | 분류 투표·회귀 평균 |

> 요약: 랜덤 포레스트는 무작위 표본·변수로 학습한 트리를 투표·평균해 예측 분산을 줄임.

### 쉽게 이해하기 (학습용)
- 전문가마다 서로 다른 자료 뭉치(부트스트랩 표본)와 참고할 질문 일부(변수 후보)를 받아 각자 판단(개별 트리)을 내리면, 마지막에 이를 모으는 사람(집계기)이 다수결이나 평균을 냄

## Ⅴ. 원리 및 절차 흐름도

```text
부트스트랩 표본 생성 → 노드별 무작위 특징 선택 → 트리 학습
                                               ↓
                         목표 트리 수까지 독립 반복
                                               ↓
                              분류 투표·회귀 평균으로 예측 집계
```

1. **표본 생성**: 원본 데이터에서 트리 수만큼 부트스트랩 표본을 만듦
2. **변수 제한**: 각 노드 분할 시 전체 변수 중 일부만 후보로 사용함
3. **트리 학습**: 각 부트스트랩 표본과 변수 후보로 결정 트리를 독립적으로 학습함
4. **예측 집계**: 새 입력에 대한 모든 트리 예측을 투표나 평균으로 결합함

> 요약: 부트스트랩과 변수 무작위성이 트리 간 상관을 낮춰 집계 효과를 높임.

### 쉽게 이해하기 (학습용)
- 자료 뭉치를 여러 벌 만들어 나눠주고, 각 전문가는 일부 질문만 참고해 따로 판단을 내리며, 이를 목표한 인원만큼 반복한 뒤 최종 의견을 모음

## Ⅵ. 실무 사례

1. 서버 장애 예측기는 부트스트랩 표본과 무작위 특징으로 여러 트리를 학습해 투표함
2. 데이터센터 장애 원인 분석은 순열 중요도로 예측에 영향을 준 지표를 찾음

### 쉽게 이해하기 (학습용)
- 서버 장애 예측은 여러 전문가에게 각기 다른 자료를 주고 투표로 결론을 내며, 장애 원인 분석은 어떤 자료를 가렸을 때 판단이 크게 흔들리는지를 봐서 중요한 단서를 찾아냄

## Ⅶ. 결론

- 랜덤 포레스트는 서로 다른 여러 트리의 결과를 합쳐 과적합을 줄이지만, 모델 크기와 추론 비용이 증가함
- 안정적인 표형 데이터 기준 모델로 사용하되 지연·메모리 한도를 넘으면 트리 수·깊이를 줄이거나 단일 모델로 전환해야 함

### 쉽게 이해하기 (학습용)
- 여러 전문가의 의견을 모으면 판단은 안정되지만 그만큼 사람을 더 불러야 하므로, 시간과 공간이 부족하면 전문가 수를 줄이거나 한 명의 판단으로 되돌아가야 함
