## 미리 알고가기

- 앙상블 학습($Ensemble$): 여러 개의 약한 학습기($Weak$ $Learner$)를 결합하여 하나의 강력한 학습기를 만드는 방법임
- 배깅($Bagging$): '부스트랩($Bootstrap$)' 샘플링으로 데이터를 여러 번 추출하여 모델들을 병렬로 학습시킨 뒤 결과를 합치는($Aggregating$) 방식임
- 부트스트랩($Bootstrap$): 원본 데이터셋에서 중복을 허용하여 무작위로 $N$개의 데이터를 뽑아내는 통계적 샘플링 기법임
- $OOB$($Out-Of-Bag$): 부트스트랩 샘플링 시 선택되지 않은 나머지 데이터로, 별도의 검증셋 없이도 모델 성능을 평가하는 데 활용됨

## Ⅰ. 개요

- **정의/개념**: 랜덤 포레스트는 수많은 결정 트리($Decision$ $Tree$)를 독립적으로 학습시킨 후, 이들의 예측 결과를 다수결(분류)이나 평균(회귀)으로 집계하여 과적합을 방지하고 예측 정확도를 극대화하는 앙상블 알고리즘임
- **배경/필요성**: 단일 결정 트리가 가진 '높은 분산'과 '과적합' 문제를 해결하기 위해, 여러 개의 나무($Tree$)가 모인 숲($Forest$)을 구축함으로써 모델의 안정성과 신뢰성을 확보하기 위해 탄생함

## Ⅱ. 특징

- 각 트리를 학습시킬 때 데이터 샘플뿐만 아니라 '변수($Feature$)'도 무작위로 선택하여 사용함으로써, 특정 변수에만 의존하지 않는 다양한 관점의 트리들을 생성하여 모델의 일반화 능력을 높임
- 하이퍼파라미터 튜닝 없이도 기본적으로 매우 우수한 성능을 보여주며, 데이터 내의 이상치($Outlier$)나 노이즈에 대해 단일 트리보다 훨씬 더 견고한($Robust$) 대응이 가능함
- 각 트리가 독립적으로 학습되므로 멀티코어 환경에서 병렬 처리가 매우 용이하여, 대용량 데이터를 처리할 때 시간 효율성이 뛰어남

## Ⅲ. 종류 및 비교

| 판단 기준 | 결정 트리 (Single Tree) | 랜덤 포레스트 (Random Forest) | 부스팅 (Boosting/XGBoost) |
|:---|:---|:---|:---|
| **학습 방식** | 단일 모델 생성 | 독립적 병렬 학습 (Bagging) | 순차적 보정 학습 (Boosting) |
| **모델 구조** | 단순하고 직관적임 | 수많은 트리의 집합체 | 오차를 보완하는 트리 사슬 |
| **과적합 위험** | 매우 높음 | 매우 낮음 | 높음 (데이터에 따라 다름) |
| **성능/안정성** | 낮음 | 매우 높음 (안정적) | 최상급 (정밀 튜닝 시) |

> 요약: 랜덤 포레스트는 '안정적인 고성능'을, 부스팅은 '한계치 성능'을 목표로 함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 부트스트랩 샘플러 | 원본 데이터에서 중복 허용 추출을 통해 트리마다 서로 다른 학습 환경을 조성함 |
| 무작위 변수 선택 | 노드 분할 시 모든 변수가 아닌 $m$개의 변수만 고려하여 트리 간 상관관계를 낮춤 |
| 개별 결정 트리 | 숲을 구성하는 기본 단위로, 보통 가지치기를 하지 않고 깊게 학습시켜 편향을 낮춤 |
| 보팅/에버리징 | 수천 개의 예측 결과를 하나로 모으는 최종 의사결정 방식임 |

```text
[ 랜덤 포레스트 동작 메커니즘 ]
Input -> [Bootstrap 1 -> Tree 1] --\
      -> [Bootstrap 2 -> Tree 2] ----> Voting/Average -> Final Result
      -> [Bootstrap N -> Tree N] --/
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 데이터 샘플링| --> | 변수 무작위선택| --> | 개별 트리 학습| --> | 결과 취합/도출|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **데이터 다양성 확보** — 원본 데이터에서 부트스트랩 샘플링을 수행하여 트리 개수만큼의 서로 다른 학습용 데이터셋을 생성함
2. **트리 생성** — 각 데이터셋에 대해 결정 트리를 학습시키되, 노드를 나눌 때마다 전체 변수 중 일부만을 무작위로 골라 최적의 분할 기준을 찾음
3. **독립적 병렬 연산** — 위 과정을 수십~수백 번 반복하여 풍성한 숲을 구축하며, 이때 각 트리는 서로 간섭 없이 독립적으로 생성됨
4. **집단 지성 활용** — 새로운 데이터가 들어오면 모든 트리가 각자 예측을 수행하고, 분류 문제라면 가장 많은 표를 얻은 클래스를, 회귀라면 평균값을 최종 결과로 출력함

## Ⅵ. 실무 적용 및 유의점

1. 랜덤 포레스트는 트리 개수가 많아질수록 성능이 수렴하고 과적합 위험은 줄어들지만, 비례해서 메모리 사용량과 추론 시간($Latency$)이 늘어나므로 실시간 서비스 적용 시에는 적절한 트리 개수와 깊이의 타협점을 찾아야 함
2. 수백 개의 트리가 얽혀 있어 판단 근거를 직접 확인하기 어려운 '블랙박스' 모델이므로, 실무에서는 '변수 중요도($Feature$ $Importance$)' 지표를 추출하여 어떤 변수가 모델의 결정에 기여했는지 간접적으로 해석하는 과정이 필수적임

## Ⅶ. 결론

- 랜덤 포레스트는 개별 나무의 불안정성을 숲의 집단 지성으로 승화시킨 앙상블의 정석이며, 설계자는 무작위성의 정도와 연산 자원 사이의 균형을 통제하여 현장의 다양한 난제들에 대해 가장 안정적이고 강력한 예측 솔루션을 제공해야 함
