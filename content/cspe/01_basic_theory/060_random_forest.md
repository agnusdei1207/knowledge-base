## 미리 알고가기

- 배깅: 여러 모델을 서로 다른 표본으로 학습한 뒤 예측을 평균·투표로 결합하는 앙상블 방식임
- 부트스트랩: 원본 데이터에서 복원추출로 학습 표본을 만드는 방법임
- 변수 무작위화: 각 노드 분할에서 일부 특징만 후보로 사용해 트리 간 다양성을 높이는 방법임
- Out-of-Bag(OOB): 부트스트랩 표본에 뽑히지 않은 데이터로 내부 검증에 활용되는 표본임
- 분산 감소: 여러 모델의 예측을 결합해 단일 모델의 흔들림을 줄이는 효과임

## Ⅰ. 개요

- **정의**: 랜덤 포레스트는 부트스트랩 표본과 변수 무작위화로 여러 결정 트리를 학습하고 예측을 집계하는 배깅 앙상블 모델임
- **배경/필요성**: 단일 결정 트리는 해석이 쉽지만 데이터 변화에 민감하고 과적합될 수 있으므로, 상관이 낮은 여러 트리의 판단을 결합해 분산을 낮출 필요가 있음
- **비유**: 한 명의 심사위원보다 서로 다른 자료를 본 여러 심사위원의 판단을 모아 최종 결론을 내리는 방식과 같음

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 배깅 앙상블 원리 | 부트스트랩, 변수 무작위화, 투표·평균 | 부스팅과 혼동 |
| 분산 감소 판단 | 트리 다양성, Out-of-Bag(OOB) error, feature importance | 단일 트리 설명력으로 과대평가 |

> 요약: 랜덤 포레스트는 여러 결정 트리를 표본·변수 무작위화로 다르게 만들고 집계해 예측 분산을 낮추는 모델임.

## Ⅱ. 특징/비교

| 판단 기준 | 단일 결정 트리·부스팅 | 랜덤 포레스트 |
|:---|:---|:---|
| 학습 방식 | 단일 트리는 하나의 규칙 경로, 부스팅은 이전 오류를 순차 보정함 | 여러 트리를 병렬로 학습해 예측을 집계함 |
| 과적합 대응 | 단일 트리는 깊이에 민감하고 부스팅은 튜닝에 민감함 | 트리 간 다양성과 평균 효과로 분산을 줄임 |
| 해석성 | 단일 트리는 경로 해석이 쉽고 부스팅은 성능 중심임 | 전체 모델은 덜 직관적이나 변수 중요도와 OOB 평가를 제공함 |
| 선택 조건 | 규칙 설명 또는 최고 지표 튜닝이 목표일 때 대안이 적합함 | 정형 데이터에서 낮은 분산 기준선과 튜닝 부담 완화가 필요할 때 적합함 |

> 요약: 랜덤 포레스트는 단일 트리의 불안정성을 낮추고 부스팅보다 튜닝 부담이 적은 정형 데이터 기준선 모델임.

- **입력 조건**: 여러 트리가 서로 다른 표본과 변수 조합을 학습할 만큼 데이터와 특징이 있어야 함
- **평가 기준**: OOB error, 검증 성능, 변수 중요도 안정성을 함께 확인함
- **선택 판단**: 단일 트리보다 예측 분산이 낮고 부스팅보다 튜닝 부담이 낮은 기준선이 필요할 때 적합함

## Ⅲ. 구성요소

```text
+-------------+      +-----------------+      +------------+
| 원본 데이터 | ---> | 부트스트랩 표본 | ---> | 다수 트리  |
+-------------+      +-----------------+      +------------+
       |                                             |
       v                                             v
+-------------+      +-----------------+      +------------+
| OOB 표본    |      | 변수 무작위화   |      | 투표·평균  |
+-------------+      +-----------------+      +------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 원본 데이터 | 여러 트리 학습의 출발점이 되는 전체 학습 데이터임 | 전체 자료철 |
| 부트스트랩 표본 | 복원추출로 만든 트리별 학습 데이터이며 표본 다양성을 만듦 | 심사위원별 자료 묶음 |
| 변수 무작위화 | 각 분할에서 일부 변수만 보게 해 트리 간 상관을 낮춤 | 질문 후보 제한 |
| 다수 결정 트리 | 서로 다른 표본과 변수 조건으로 학습된 예측기 집합임 | 여러 심사위원 |
| 투표·평균 집계 | 분류는 다수결, 회귀는 평균으로 최종 예측을 산출함 | 최종 판정 |

> 요약: 랜덤 포레스트는 표본과 변수를 무작위화해 상관이 낮은 트리를 만들고 그 예측을 집계하는 구조임.

## Ⅳ. 절차

```text
+------------+      +------------+      +------------+      +------------+
| 표본 생성  | ---> | 트리 학습  | ---> | 예측 집계  | ---> | OOB 평가   |
+------------+      +------------+      +------------+      +------------+
```

1. **표본 생성**: 각 트리마다 원본 데이터에서 부트스트랩 표본을 만들고 OOB 표본을 남김
2. **트리 학습**: 노드 분할 시 일부 변수만 후보로 사용해 결정 트리를 성장시킴
3. **예측 집계**: 분류는 투표, 회귀는 평균으로 개별 트리 예측을 결합함
4. **OOB 평가**: 각 샘플이 포함되지 않은 트리들의 예측으로 내부 검증 성능을 추정함

> 요약: 랜덤 포레스트 절차는 표본·변수 무작위화로 여러 트리를 만들고 집계 결과와 OOB 성능으로 모델을 평가하는 흐름임.

- **산출물**: 앙상블 예측값, OOB error, 변수 중요도, 트리별 예측 분포임
- **검증 기준**: 트리 수 증가에 따른 성능 개선이 포화되는 지점을 확인해야 함
- **운영 기록**: 트리 수, `max_features`, depth, seed, OOB 결과를 함께 관리함

## Ⅴ. 문제점 및 개선방안

- **P1 해석성 저하**: 수십~수백 개 트리를 집계하므로 단일 결정 트리처럼 예측 경로를 직접 설명하기 어려움
- **P1 대응**: permutation importance, SHAP(SHapley Additive exPlanations), partial dependence plot으로 예측 근거를 보완함 (확인: 주요 변수와 업무 해석 일치)
- **P2 트리 상관 증가**: 강한 예측 변수가 모든 트리에 반복 사용되면 트리 다양성이 줄어 분산 감소 효과가 약해짐
- **P2 대응**: `max_features`, 트리 깊이, 최소 샘플 수를 조정하고 상관 높은 변수 처리를 검토함 (확인: OOB error와 트리 간 예측 상관)
- **P3 자원 비용 증가**: 트리 수와 깊이가 커질수록 메모리 사용량, 학습 시간, 추론 지연이 증가함
- **P3 대응**: 트리 수 제한, pruning, 병렬 학습, 모델 압축 또는 경량 대체 모델을 적용함 (확인: 지연시간과 메모리 사용량)

> 요약: 랜덤 포레스트는 트리 다양성 확보, 설명 보완, 자원 제약 조정을 함께 수행해야 함.

- **우선순위**: OOB error와 트리 간 상관을 먼저 보고 다양성 부족을 확인함
- **확인 지표**: OOB error, validation score, feature importance stability, latency를 사용함
- **재평가 조건**: 특징 수, 데이터 분포, 지연시간 요구사항이 바뀌면 파라미터를 다시 조정함

## Ⅵ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| 정형 데이터 기준선 모델 | 범주·수치 특징이 섞인 업무에서 랜덤 포레스트를 빠른 기준선으로 만들고 Out-of-Bag(OOB) error로 검증셋 부족을 보완함 | OOB error, validation score, 트리 수별 성능 포화점 |
| 신용·보험 리스크 분류 | 변수 중요도와 SHAP(SHapley Additive exPlanations)으로 업무 해석을 보완하되 강한 변수가 트리 대부분을 지배하는지 `max_features`로 조정함 | feature importance stability, 트리 간 예측 상관, 민감도·특이도 |
| 실시간 배치 스코어링 | 트리 수와 깊이를 지연시간 예산에 맞추고 병렬 추론 또는 경량 모델 전환 조건을 운영 기준으로 둠 | p95 latency, 메모리 사용량, throughput, 정확도 감소폭 |

> 요약: 랜덤 포레스트 적용은 OOB 검증, 트리 다양성, 설명 보완, 지연시간 예산을 함께 관리할 때 효과가 안정적임.

## Ⅶ. 전망

- **발전 방향**: 랜덤 포레스트는 정형 데이터에서 빠르게 강한 기준선을 제공하는 모델로 유지되며, XGBoost·LightGBM 같은 부스팅 모델과 비교되는 기본 앙상블임
- **기술사적 판단**: 기술사는 정확도뿐 아니라 OOB error, 변수 중요도 안정성, 추론 비용, 설명 가능성을 기준으로 적용 여부를 판단해야 함
- **기술사 제언**: 향후 랜덤 포레스트는 AutoML, 모델 해석 도구, 데이터 품질 진단과 결합해 낮은 분산 기준선과 설명 보조 모델로 계속 활용될 것임
