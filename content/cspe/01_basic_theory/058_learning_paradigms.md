## 미리 알고가기

- 라벨: 입력 데이터에 대응하는 정답값이며 지도 학습의 직접 피드백이 됨
- 군집: 라벨 없이 유사한 데이터끼리 묶은 그룹이며 비지도 학습의 대표 산출물임
- 보상: 행동 결과에 대해 환경이 주는 점수이며 강화 학습의 학습 신호임
- 정책 $\pi$: 상태가 주어졌을 때 어떤 행동을 선택할지 정하는 강화 학습 전략임
- 탐험·활용: 새 행동을 시도하는 것과 현재 최선 행동을 쓰는 것 사이의 균형임

## 작성 근거(검토용)

- 개요는 세 패러다임을 학습 신호 기준으로 묶어 분류형 키워드의 기준을 먼저 제시함
- 특징은 지도, 비지도, 강화의 목적 차이와 평가 차이를 짧게 분리함
- 비교표는 학습 신호, 목표, 기법, 지표, 업무를 포함해 선택에 필요한 축을 완성함
- 구성요소는 데이터 피드백부터 운영 환경까지 패러다임 결정 구조를 보여줌
- 절차는 문제 진단에서 평가까지 이어져 실무 선택 흐름을 설명함
- 라벨 품질과 강화 학습의 안전 검증은 학습 패러다임 선택의 대표 조건임

## Ⅰ. 개요

- **정의/개념**: 학습 패러다임은 학습 신호의 형태에 따라 라벨 기반 지도 학습, 구조 탐색형 비지도 학습, 보상 기반 강화 학습으로 나누는 분류 체계임
- **배경/필요성**: 문제 목표와 데이터 피드백에 맞는 모델을 설계하기 위해 적합한 학습 방식을 고르는 기준이 필요함

## Ⅱ. 특징

- 지도 학습은 입력 $x$와 정답 $y$의 관계를 학습해 새로운 입력의 값을 예측함
- 비지도 학습은 라벨 없이 데이터의 유사성, 밀도, 저차원 구조를 찾음
- 강화 학습은 환경과 상호작용하며 장기 누적 보상을 최대화하는 행동 전략을 학습함
- 세 방식은 학습 신호가 달라 평가 지표와 데이터 수집 비용도 서로 다름

## Ⅲ. 종류 및 비교

| 판단 기준 | 지도 학습 | 비지도 학습 | 강화 학습 |
|:---|:---|:---|:---|
| 학습 신호 | 라벨·정답 | 데이터 구조 | 보상·상태 변화 |
| 주요 목표 | 예측 오차 최소화 | 패턴·군집 발견 | 누적 보상 최대화 |
| 대표 기법 | 회귀, 분류 | 군집화, 차원 축소 | $Q$-learning, 정책 경사 |
| 평가 기준 | 정확도, F1, RMSE | 실루엣, 재구성 오차 | 누적 보상, 성공률 |
| 적합 업무 | 수요 예측, 스팸 분류 | 고객 세분화, 특징 추출 | 게임, 로봇, 자율 제어 |

> 요약: 라벨이 있으면 지도, 구조를 찾으면 비지도, 행동 결과를 최적화하면 강화 학습을 우선 검토함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 데이터와 피드백 | 라벨, 무라벨 데이터, 보상 중 무엇을 얻을 수 있는지가 패러다임을 결정함 |
| 목적 함수 | 오차, 구조 보존, 누적 보상처럼 최적화 기준을 수식화함 |
| 학습 주체 | 모델 또는 에이전트가 입력을 받아 예측, 표현, 행동을 산출함 |
| 평가 지표 | 업무 목표와 학습 신호에 맞는 성능 판단 기준을 제공함 |
| 운영 환경 | 정적 데이터셋인지 상호작용 환경인지에 따라 검증 방식이 달라짐 |

```text
+-------------+
| problem     |
+-------------+
       |
       v
+-------------+      yes      +-------------+
| label exists| ------------> | supervised  |
+-------------+               +-------------+
       |
       no
       v
+-------------+      yes      +-------------+
| reward loop | ------------> | RL          |
+-------------+               +-------------+
       |
       no
       v
+-------------+
| unsupervised|
+-------------+
```

> 요약: 학습 패러다임은 라벨, 보상 루프, 무라벨 구조 중 어떤 피드백이 있는지로 갈림.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+      +----------+      +----------+      +----------+
| diagnose | ---> | select   | ---> | train    | ---> | evaluate |
+----------+      +----------+      +----------+      +----------+
```

1. **문제 진단**: 목표가 예측, 구조 발견, 의사결정 중 무엇인지 정의함
2. **피드백 확인**: 라벨, 무라벨 데이터, 보상 환경의 확보 가능성을 확인함
3. **알고리즘 선택**: 패러다임에 맞는 손실 함수, 모델, 탐색 전략을 정함
4. **성과 검증**: 정확도, 군집 품질, 누적 보상처럼 목적에 맞는 지표로 평가함

> 요약: 예측·구조 발견·행동 최적화 중 업무 목표를 먼저 정하고, 확보 가능한 라벨·무라벨 데이터·보상 신호에 맞춰 학습 방식을 선택함.

## Ⅵ. 실무 사례

1. 라벨 예측 업무는 지도 학습을 우선 적용하되 라벨 품질과 클래스 불균형을 점검하고 F1과 오류 유형으로 검증함
2. 실제 행동 비용이 큰 제어 문제는 탐색 실패가 사고로 이어질 수 있으므로 시뮬레이션·오프라인 평가를 거치고 제약 위반률로 검증함

## Ⅶ. 결론

- 학습 패러다임 선택은 데이터 피드백과 업무 목표의 정합성 판단이며, 잘못 선택하면 모델보다 평가 기준부터 불안정해짐
