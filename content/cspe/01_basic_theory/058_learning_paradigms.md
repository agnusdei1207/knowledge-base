## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 학습 데이터의 정답 유무와 환경과의 상호작용 방식(보상)에 따라 머신러닝 알고리즘을 구분하는 체계임 |
| 배경/필요성 | 해결하고자 하는 문제의 정의(예측, 군집화, 제어)에 따른 적합한 알고리즘 매핑 필요성 |
| 출제 의도 | 각 학습 패러다임의 명확한 정의, 특징, 적용 분야 및 대표 알고리즘 매칭 역량 평가 |

## Ⅱ. 구성요소
```text
+----------------+       +----------------+       +----------------+
| Supervised     |       | Unsupervised   |       | Reinforcement  |
| (With Labels)  | ----> | (No Labels)    | ----> | (Reward Based) |
+----------------+       +----------------+       +----------------+
```
| 지도 학습 | 정답(Label)이 포함된 데이터를 학습하여 미지의 값 예측 | 교사가 있는 학습 |
| 비지도 학습 | 정답 없이 데이터 자체의 구조와 패턴을 군집화, 압축 | 자율 탐구 학습 |
| 강화 학습 | 환경과 상호작용하며 누적 보상을 최대화하는 정책 학습 | 상벌 기반 훈련 |
> 요약: 머신러닝은 정답 유무 및 보상 체계에 따라 지도, 비지도, 강화 학습 패러다임으로 분류됨

## Ⅲ. 절차
```text
+----------------+       +----------------+       +----------------+       +----------------+
| Problem Define |       | Data Check     |       | Paradigm Select|       | Model Dev      |
| (Goal set)     | ----> | (Label avail)  | ----> | (Map Strategy) | ----> | (Train & Test) |
+----------------+       +----------------+       +----------------+       +----------------+
```
1. 문제 정의: 풀고자 하는 태스크가 분류, 회귀, 군집, 제어 중 무엇인지 판단
2. 데이터 점검: 보유한 데이터에 명시적인 정답(Label)이 구축되어 있는지 확인
3. 패러다임 선택: 정답 기반(지도), 데이터 탐색(비지도), 환경 상호작용(강화) 중 전략 선택
4. 모델 개발: 선택한 패러다임에 맞는 알고리즘(CNN, K-Means, DQN 등) 적용 및 최적화
> 요약: 문제 목표와 데이터 정답 여부를 파악한 뒤, 적합한 학습 패러다임을 선택해 모델을 개발함

## Ⅳ. 문제점
- 정답지 구축 비용(지도학습): 수백만 장의 데이터에 라벨을 다는 인건비와 시간이 막대함
- 평가의 주관성(비지도학습): 정답이 없기 때문에 도출된 군집/패턴의 타당성 검증이 어려움
- 학습 환경 한계(강화학습): 실제 물리 환경에서 수많은 시행착오 시 안전사고 및 비용 문제 발생

## Ⅴ. 개선방안
- 단기 방안: 소량의 라벨과 다량의 언라벨 데이터를 결합하는 준지도(Semi-supervised) 적용
- 중기 방안: 비지도 학습을 지도 학습의 전처리(차원 축소) 또는 피처 추출용으로 결합 활용
- 장기 방안: 실제 환경 대신 정교한 시뮬레이션(디지털 트윈)을 구축하여 강화학습을 수행

## Ⅵ. 전망
- 라벨 없이 데이터 자체를 정답으로 활용하는 자기지도 학습(Self-Supervised Learning)으로 수렴 중임
