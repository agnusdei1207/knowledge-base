## 미리 알고가기

- 라벨: 입력에 대한 정답 또는 목표 값임
- 보상: 행동 결과의 좋고 나쁨을 수치화한 신호임
- 정책: 상태에서 행동을 선택하는 규칙임

## Ⅰ. 개요

- **정의/개념**: 학습 패러다임은 데이터와 피드백 구조에 따라 지도 학습, 비지도 학습, 강화 학습으로 구분되며, 각 방식은 서로 다른 목표와 평가 기준을 가짐
- **배경/필요성**: 문제마다 정답 유무와 상호작용 구조가 다르므로, 동일한 학습 방법을 모든 상황에 적용할 수 없음

## Ⅱ. 특징

- 지도 학습은 라벨을 이용해 예측 정확도를 직접 최적화함
- 비지도 학습은 숨은 구조와 표현을 발견하는 데 초점이 있음
- 강화 학습은 환경 상호작용을 통해 장기 보상을 최적화함
- 데이터 준비 비용, 평가 방법, 실험 위험도가 패러다임마다 크게 다름

## Ⅲ. 종류 및 비교

| 판단 기준 | 지도 학습 | 비지도 학습 | 강화 학습 |
|:---|:---|:---|:---|
| 피드백 | 라벨 | 없음 | 보상 |
| 목표 | 예측 정확도 | 구조 발견 | 누적 보상 최대화 |
| 대표 기법 | 회귀, 분류 | 군집, 차원 축소 | Q-learning, policy gradient |
| 대표 적용 | 분류/예측 | 탐색/요약 | 제어/의사결정 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 데이터 형태 | 라벨, 비라벨, 상태-행동-보상이며 패러다임을 구분함 |
| 학습 목표 | 오차 최소화, 구조 발견, 보상 최대화이며 설계 축이 다름 |
| 평가 지표 | accuracy, silhouette, return 등이며 성공 기준이 다름 |
| 위험 요소 | 라벨 비용, 해석성, 탐험 비용 등이며 적용 난도를 좌우함 |

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 데이터 형태   | --> | 학습 목표    | --> | 평가 지표    | --> | 위험 요소    |
+-----------+     +-----------+     +-----------+     +-----------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 문제정의 | --> | 피드백확인 | --> | 학습방식선택 | --> | 성능검증 |
+----------+     +----------+     +----------+     +----------+
```

1. **문제정의**: 예측, 구조 발견, 제어 중 무엇인지 정함
2. **피드백확인**: 라벨, 비라벨, 보상 중 어떤 신호가 있는지 봄
3. **학습방식선택**: 패러다임에 맞는 모델과 알고리즘을 고름
4. **성능검증**: 목적에 맞는 지표로 평가함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 문제에 맞지 않는 학습 방식을 선택할 수 있어 라벨이 없는데 분류기부터 적용할 수 있음
   - 해결방안: 데이터와 피드백 구조부터 먼저 분석하고 적용 적합성로 검증함
2. 문제: 강화 학습은 탐험 비용이 커 실제 환경 실험이 위험하거나 비쌀 수 있음
   - 해결방안: 시뮬레이터와 offline RL을 활용하고 sample efficiency로 검증함
3. 문제: 비지도 학습 평가는 모호해 절대적 정답이 없어 비교가 어렵다
   - 해결방안: downstream task와 함께 검증하고 representation utility로 검증함

## Ⅶ. 적용 사례

- 고객 이탈 예측에서는 라벨이 있는 지도 학습을 사용함, 확인 지표는 ROC-AUC임
- 로그 패턴 탐색에서는 비지도 학습으로 이상 군집을 찾음, 확인 지표는 이상 탐지율임
- 로봇 제어에서는 강화 학습으로 행동 정책을 학습함, 확인 지표는 cumulative reward임

## Ⅷ. 결론

학습 패러다임의 핵심은 알고리즘이 아니라 피드백 구조에 있으므로, 문제를 풀기 전에 먼저 어떤 신호를 받을 수 있는지부터 판단해야 함.
