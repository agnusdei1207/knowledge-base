## 미리 알고가기

- 훈련 데이터($Training$ $Data$): 인공지능이 학습을 수행하는 데 사용되는 입력 데이터의 집합임
- 라벨($Label$)/타깃: 각 입력 데이터에 대해 인간이 미리 정의해 놓은 정답값임
- 에이전트($Agent$): 강화 학습에서 환경을 관찰하고 행동을 결정하는 주체임
- 에피소드: 강화 학습에서 시작 상태부터 종료 상태까지 이어지는 하나의 행동 시퀀스임

## Ⅰ. 개요

- **정의/개념**: 인공지능 학습 패러다임은 정답 유무와 피드백 방식에 따라 정답을 맞히는 지도 학습, 데이터의 구조를 찾는 비지도 학습, 시행착오를 통해 전략을 배우는 강화 학습으로 분류됨
- **배경/필요성**: 해결하고자 하는 비즈니스 과제마다 데이터의 성격과 목표가 다르므로, 각 상황에 가장 효율적으로 정보를 추출하고 지능을 형성할 수 있는 체계적인 학습 분류가 필요함

## Ⅱ. 특징

- 지도 학습($Supervised$ $Learning$)은 입력과 정답 사이의 매핑 함수($Y = f(X)$)를 학습하여, 새로운 입력에 대한 정확한 결과를 예측하는 데 최적화되어 있음
- 비지도 학습($Unsupervised$ $Learning$)은 정답 없이 데이터 간의 유사성이나 변수 간의 관계를 분석하여, 숨겨진 패턴이나 그룹 구조를 발견해내는 탐색적 성격이 강함
- 강화 학습($Reinforcement$ $Learning$)은 특정 상태에서 어떤 행동을 취했을 때 얻는 '보상($Reward$)'을 최대화하도록 학습하며, 동적인 환경에서의 최적의 의사결정 순서를 결정함

## Ⅲ. 종류 및 비교

| 판단 기준 | 지도 학습 | 비지도 학습 | 강화 학습 |
|:---|:---|:---|:---|
| **데이터 피드백** | 명시적 정답 (라벨) 제공 | 피드백 없음 | 행동에 따른 보상(지연 신호) |
| **학습 목표** | 오차(Error) 최소화 | 데이터의 본질적 구조 발견 | 누적 보상(Return) 최대화 |
| **핵심 기법** | 회귀, 분류, 앙상블 | 군집화, 차원 축소 | $Q$-학습, 정책 경사법 |
| **주요 활용** | 스팸 분류, 주가 예측 | 고객 세분화, 특징 추출 | 게임 AI, 자율주행, 로봇 제어 |

> 요약: 지도는 '정답'에, 비지도는 '구조'에, 강화는 '보상'에 집중하는 패러다임임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 손실 함수 ($Loss$) | 지도 학습에서 예측과 정답의 차이를 수치화한 지표임 |
| 거리/유사도 척도 | 비지도 학습에서 데이터 객체들이 얼마나 닮았는지 판단하는 기준임 |
| 상태-행동-보상 | 강화 학습의 기본 단위인 $SAR$($State, Action, Reward$) 삼중항임 |
| 정책 ($\pi$) | 강화 학습에서 특정 상태가 주어졌을 때 에이전트가 행동을 고르는 전략임 |

```text
[ 학습 방식 간의 관계 ]
- 반지도 학습 (Semi-supervised): 소량의 라벨 데이터와 대량의 비라벨 데이터 혼합
- 자기지도 학습 (Self-supervised): 데이터 자체에서 라벨을 생성 (최신 트렌드)
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 데이터 성격 파악| --> | 학습 패러다임 결정| --> | 모델 설계/학습| --> | 성능 평가/검증|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **데이터 진단** — 분석 대상 데이터에 정답 라벨이 존재하는지, 환경과 상호작용이 가능한지, 데이터가 정적인지 동적인지 분석함
2. **패러다임 매핑** — 예측 문제라면 지도 학습을, 데이터 그룹화나 특징 요약이 필요하면 비지도 학습을, 최적의 행동 시퀀스가 목적이면 강화 학습을 선택함
3. **알고리즘 구현** — 선택된 패러다임 내에서 적절한 손실 함수나 보상 체계를 설계하고, 데이터의 규모에 맞는 신경망 아키텍처를 구축하여 학습을 진행함
4. **목적 기반 평가** — 지도 학습은 정확도($Accuracy$)를, 비지도는 군집의 견고함($Silhouette$)을, 강화 학습은 목표 달성률과 보상 합계로 성능을 최종 검증함

## Ⅵ. 실무 적용 및 유의점

1. 지도 학습은 정밀도가 높지만 고품질의 라벨링 데이터 확보에 막대한 비용이 소요되므로, 최근에는 비지도 방식으로 먼저 학습한 뒤 소량의 라벨로 튜닝하는 '전이 학습'이나 '자기 지도 학습'이 실무에서 선호됨
2. 강화 학습은 최적의 정책을 찾기까지 수많은 '탐험($Exploration$)'이 필요하여 초기 학습이 매우 불안정하고 위험할 수 있으므로, 실제 환경 투입 전 시뮬레이션 환경에서 충분한 사전 검증을 거쳐야 함

## Ⅶ. 결론

- 학습 패러다임은 인공지능이 세상을 배우는 세 가지 근본적인 철학이며, 설계자는 해결하고자 하는 과제의 본질과 가용 자원을 통찰하여 가장 효율적인 학습 경로를 선택함으로써 지능적 성과를 극대화해야 함
