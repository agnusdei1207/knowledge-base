## Ⅰ. 개요
- 정의: 기계가 학습하는 방식과 데이터의 형태에 따른 3대 주요 학습 패러다임임
- 배경: 문제 정의 및 가용 데이터 자원에 최적화된 학습 전략 수립 필요
- 출제 의도:
| 구분 | 내용 |
| --- | --- |
| 핵심 | 레이블 유무, 보상 함수, 목표 지향성 |

## Ⅱ. 구성요소
- ASCII 구조도
  [Data] --(Label)--> [Supervised]
  [Data] ------------> [Unsupervised]
  [Env] ---(Reward)--> [Reinforcement]
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 지도 학습 | 문제와 정답(Label)이 주어진 상태에서 학습함 | 문제집 풀이 |
| 비지도 학습 | 정답 없이 데이터 자체의 구조나 패턴을 파악함 | 관찰/분류 |
| 강화 학습 | 행동에 대한 보상(Reward)을 통해 최적 정책 도출함 | 시행착오 |
> 요약: 목적에 따라 정답 추정, 구조 파악, 행동 최적화를 수행함

## Ⅲ. 절차
- ASCII 흐름도
  [문제정의] -> [데이터수집] -> [패러다임선택] -> [모델검증]
- 4단계 설명
1. 문제 정의: 해결하려는 비즈니스 목표를 명확히 정의함
2. 데이터 수집: 레이블링 여부 및 환경 상호작용 가능성 확인함
3. 패러다임 선택: 데이터 특성에 맞는 학습 방식 결정함
4. 모델 검증: 정확도, 군집도, 누적 보상 등의 지표로 평가함
> 요약: 가용한 자원을 분석하여 가장 효율적인 학습 경로를 설정함

## Ⅳ. 문제점
- 지도 학습은 양질의 레이블 확보에 막대한 비용이 소요됨
- 강화 학습은 학습 환경(Simulator) 구축이 어렵고 수렴이 느림

## Ⅴ. 개선방안
- (단기) 준지도 학습(Semi-supervised)으로 레이블 부족 보완함
- (중기) 자기지도 학습(Self-supervised)으로 대량 데이터 활용함
- (장기) 멀티모달 학습 등 패러다임 간 융합 모델 도입함

## Ⅵ. 전망
- 인간의 개입을 최소화하는 자율 학습 방향으로 진화 중임
