# 📖 【암기용】 개념 완전 이해

## 한눈에
- **개요**: 머신러닝이 데이터를 바탕으로 지식을 습득하고 문제를 해결하는 3대 근본 접근 방식 (정답의 유무와 보상 시스템에 따라 분류).
- **왜 필요한가**: 풀어야 할 문제의 성격(예측, 군집화, 행동 제어)과 수집된 데이터의 형태(레이블 유무)에 따라 가장 효율적인 학습 전략을 선택해야 하기 때문.
- **핵심 직관**: 
  - **지도 학습**: 교사가 정답지(Label)를 주고 기출문제를 반복해서 풀게 하는 방식.
  - **비지도 학습**: 정답지 없이 학생 혼자 수많은 곤충 사진을 보고 특징이 비슷한 것끼리 분류(군집)하게 냅두는 방식.
  - **강화 학습**: 정답은 안 알려주고, 자전거를 탈 때 넘어지면 벌점을, 앞으로 가면 상점(보상)을 주어 스스로 요령을 터득하게 하는 훈련 방식.

## 핵심 용어 정리

| 용어/표기 | 의미 | 비유·예 |
|:---|:---|:---|
| 레이블 (Label) | 지도 학습에서 입력 데이터(x)에 대응하는 정답/목표값(y) | 고양이 사진 파일의 이름("고양이.jpg") |
| 군집화 (Clustering) | 비지도 학습에서 정답 없이 데이터 간의 유사성을 바탕으로 그룹을 묶는 것 | 쇼핑몰 고객들을 구매 패턴이 비슷한 3개 그룹으로 쪼개기 |
| 에이전트와 보상 (Agent & Reward) | 강화 학습에서 행동하는 주체(Agent)와 그 행동의 결과로 받는 점수(Reward) | 미로를 탐험하는 쥐(에이전트)와 치즈(보상) |

## 깊이 이해
- **지도 학습 (Supervised Learning)**: 명확한 입력(X)과 정답(Y)의 쌍으로 모델을 훈련함. 정답이 이산적(스팸 메일 여부)이면 분류(Classification), 연속적(내일의 집값)이면 회귀(Regression) 문제로 나뉨. 정확도가 높지만, 인간이 일일이 정답을 매기는 레이블링 비용이 천문학적으로 듦.
- **비지도 학습 (Unsupervised Learning)**: 정답(Y) 없이 입력(X)만 주어짐. 데이터 안에 숨겨진 구조나 패턴을 스스로 발견함. 군집화, 차원 축소(PCA), 이상 탐지 등에 쓰임. 인간도 몰랐던 새로운 데이터의 특징을 발견할 수 있음.
- **강화 학습 (Reinforcement Learning)**: 정적 데이터가 아니라 동적인 '환경(Environment)'과 상호작용함. 에이전트가 어떤 상태(State)에서 행동(Action)을 취하면 환경이 상태를 업데이트하고 보상을 줌. 당장의 보상보다 '미래 보상의 총합'을 최대화하는 최적의 행동 정책(Policy)을 학습함 (알파고, 자율주행).
- **흔한 오해·주의점**: 세 가지 방식은 무 자르듯 나뉘지 않음. 최근에는 정답이 일부만 있는 준지도 학습(Semi-supervised), 비지도 학습으로 정답을 자체 생성해 학습하는 자가지도 학습(Self-supervised) 등으로 경계가 허물어지고 융합됨.

## 연결 개념
- **자가지도 학습 (Self-Supervised Learning)**: 정답이 없는 데이터에서 일부를 일부러 가리고(예: 문장의 빈칸) 그것을 맞추게 하여 스스로 정답(레이블)을 만들어 학습하는 기법 (BERT, GPT의 근간).

# 📝 【답안용】 시험 답안 템플릿

## 핵심 인사이트 (3줄 요약)
> 1. **본질**: 데이터의 정답 유무와 상호작용 방식에 따른 머신러닝의 3대 학습 패러다임
> 2. **가치**: 예측(지도), 패턴 탐색(비지도), 최적 행동 제어(강화) 등 문제 유형에 맞는 해결책 매핑
> 3. **판단 포인트**: 최근 실무는 고비용의 지도 학습 한계를 넘기 위해 비지도(자가지도) 기반 사전학습 후 지도 미세조정을 융합하는 추세임

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 문제 정의에 따른 AI 알고리즘 분류 능력 파악 | 정답(Label) 유무, 지도/비지도/강화의 명확한 목적, 대표 알고리즘 | 특정 모델(CNN, RNN) 구조 설명으로 빠져 패러다임 논점 일탈 |

> 요약: 레이블 존재 여부 및 보상 체계에 따라 데이터 패턴을 학습하는 세 가지 근본 프레임워크

---

## Ⅰ. 개요 및 필요성
- 개요: 인공지능이 주어진 환경이나 데이터로부터 지식과 규칙을 추출하는 방식을 정답 레이블(Label) 유무와 피드백 방식에 따라 3가지로 분류한 체계
- 배경: 비즈니스 도메인마다 보유한 데이터의 형태(정답 유무, 시계열, 시뮬레이션 환경)와 해결하고자 하는 문제(예측, 군집, 제어)가 상이함
- 필요성: 문제 정의에 최적화된 알고리즘 선택, 모델링 정확도 향상, 레이블링 비용 절감 전략 수립 필요

---

## Ⅱ. 구조 및 구성요소

```text
[머신러닝 패러다임]
      ├── 지도 학습   : (X, Y) 쌍 주입 -> 오차 최소화 매핑 f(x) 도출 (정답 O)
      ├── 비지도 학습 : (X) 만 주입    -> 내재적 구조/특성 발견 (정답 X)
      └── 강화 학습   : (상태, 행동)   -> 보상(Reward) 최대화 정책 학습 (환경 상호작용)
```

| 학습 패러다임 | 핵심 입력 요소 | 최종 목표 |
|:---|:---|:---|
| 지도 학습 | 입력 특성(Feature) + 정답 레이블(Label) | 미지의 데이터에 대한 정확한 정답 예측 (일반화) |
| 비지도 학습 | 입력 특성(Feature) (정답 없음) | 데이터 군집화, 차원 축소, 숨겨진 내재 속성 파악 |
| 강화 학습 | 에이전트, 상태(State), 행동(Action) | 환경과의 상호작용을 통한 누적 보상(Reward) 최대화 |

> 요약: 정답이 있으면 지도, 없으면 비지도, 환경 피드백이 있으면 강화 학습으로 과제를 정의함

---

## Ⅲ. 동작원리 및 흐름도

```text
문제 발생 -> 데이터 정답 여부 확인 -> 패러다임 선택 -> 알고리즘 적용 -> 목적 함수 최적화 -> 성능 평가
```

- 1단계 [지도 학습 원리]: Y = f(X) 모델을 가정하고, 실제 Y와 모델 예측 Y'의 차이(Loss)를 역전파하여 가중치 f를 지속 수정
- 2단계 [비지도 학습 원리]: 데이터 공간상에서 데이터 간의 거리(유클리드안 등)나 밀도를 계산하여 유사한 속성끼리 군집을 형성하거나 주요 축(PCA) 추출
- 3단계 [강화 학습 원리]: 에이전트가 상태 S_t에서 행동 A_t를 수행하면 환경이 보상 R_t와 다음 상태 S_{t+1}를 반환하며, 큐-함수(Q-Value)를 지속 갱신
- 4단계 [평가 및 융합]: 지도 학습은 정확도(Acc)로, 비지도는 군집 응집도(Silhouette)로, 강화 학습은 누적 보상 곡선으로 성능을 측정함

> 요약: 각 패러다임은 고유한 목적 함수(오차 최소화, 거리 최소화, 보상 최대화)를 바탕으로 파라미터를 최적화함

---

## Ⅳ. 특징
- [지도 학습 (고정밀, 고비용)]: 명확한 정답이 있어 상용 서비스 정확도가 가장 높으나, 대규모 휴먼 레이블링(Human Labeling) 비용 병목 발생
- [비지도 학습 (탐색적, 자율성)]: 비용 없이 막대한 로우(Raw) 데이터를 소화할 수 있으나, 결과물의 의미를 최종적으로 인간이 해석하고 라벨링해야 함
- [강화 학습 (동적 제어)]: 정답이 없는 연속적 의사결정 문제에 탁월하나, 현실 세계에 직접 적용 시 물리적 사고 리스크가 있어 시뮬레이터 필수
- [준지도/자가지도 학습 진화]: 소수의 레이블과 다수의 비레이블 데이터를 결합(Semi-supervised)하거나, 데이터 자체 구조로 임시 정답을 만들어 학습(Self-supervised)하는 융합형 진화

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 지도 학습 | 비지도 학습 | 강화 학습 |
|:---|:---|:---|:---|
| 세부 태스크 | 분류(Classification), 회귀(Regression) | 군집화(Clustering), 차원축소 | 정책 최적화, 최적 제어 |
| 대표 알고리즘 | SVM, 랜덤 포레스트, CNN, RNN | K-Means, PCA, 오토인코더 | Q-Learning, DQN, PPO |
| 대표 응용 | 스팸 필터, 질병 진단, 주가 예측 | 고객 세분화, 이상 탐지(FDS) | 로봇 제어, 알파고, 자율주행 |

**리스크·대응:**
- [지도 학습 편향]: 레이블링 데이터에 내재된 인간의 편견 학습 및 데이터 불균형 문제 → 오버샘플링(SMOTE) 및 정규화 기반 편향 통제 (지표: 클래스별 F1-Score)
- [비지도 해석 난해]: 군집화된 결과의 비즈니스적 의미 부여 난항 → 도메인 전문가의 사후 개입 및 설명 가능한 AI(XAI) 분석 병행 (지표: 실루엣 계수)

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. [복합 파이프라인 (이상 탐지)]: 비지도 학습(Autoencoder)으로 방대한 정상 데이터의 구조를 파악해 1차 이상징후를 걸러내고, 도출된 소수의 불량 데이터에 관리자가 정답을 매겨 지도 학습(Random Forest)으로 정밀 분류기 구축
2. [강화 학습 최적화]: 데이터 센터 온도 제어 및 전력망 최적화 시, 온도/전력량 상태(State)에서 냉각기 가동(Action) 시 전력 요금 절감(Reward)을 달성하는 RL 에이전트 도입
3. [자가지도 학습 전이]: LLM(거대 언어 모델) 구축 시, 비지도(자가지도) 방식으로 문장 다음 단어를 예측하는 사전학습을 거친 후, 인간의 지시를 따르도록 강화 학습(RLHF)으로 미세조정

**결론:**
- 기술사 판단: 단일 학습 패러다임만 고집하기보다, 레이블링 비용을 최소화하기 위해 비지도/자가지도 학습으로 특징을 찾고 지도 학습으로 마무리하는 융합(Hybrid) 전략이 필수임
- 향후 방향: 정답 생성 비용의 한계를 극복하기 위해, 모델이 스스로 정답과 보상 체계를 구축하는 자율 인공지능(AGI) 형태로 진화할 것
