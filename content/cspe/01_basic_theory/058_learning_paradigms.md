## 미리 알고가기

- 라벨: 입력 데이터에 대응하는 정답값이며 지도 학습의 직접 피드백이 됨
- 군집: 라벨 없이 유사한 데이터끼리 묶은 집합이며 비지도 학습의 대표 산출물임
- 보상: 행동 결과에 대해 환경이 주는 점수이며 강화 학습의 학습 신호임
- 정책 $\pi$: 상태가 주어졌을 때 어떤 행동을 선택할지 정하는 강화 학습 전략임

## 작성 근거(검토용)

- **방향성**: 학습 패러다임은 확보할 수 있는 학습 신호의 종류에 따라 갈리므로, 정답 라벨이 있으면 지도 학습, 라벨 없이 구조 탐색이 목적이면 비지도 학습, 보상 설계와 안전 검증이 가능하면 강화 학습을 선택해야 함
- **Ⅰ. 개요 구성**: 세 패러다임을 학습 신호 기준으로 묶어 분류형 키워드의 기준을 먼저 제시함
- **Ⅱ. 특징 선정**: 지도, 비지도, 강화의 목적 차이와 평가 차이를 짧게 분리함
- **Ⅲ. 비교축 선정**: 학습 신호 축이 곧 세 패러다임을 가르는 적용 기준이며 병렬 분류 관계라 별도 축 교체 없이 학습 목표·주요 리스크를 유지함
- **Ⅳ. 구조 선정**: 학습 데이터·신호·모델·학습 결과로 패러다임별 입력과 산출물을 연결함
- **Ⅴ. 절차 선정**: 지도·비지도·강화 학습은 학습 신호와 목표의 분류가 핵심이므로 일반 모델 개발 생명주기를 별도 절차로 두지 않음
- **Ⅵ. 사례 선정**: 라벨 품질과 강화 학습의 안전성은 학습 패러다임 선택의 대표 조건임
- **전수 검수**: 제목부터 결론까지 용어·표·도식·요약을 대조하고 절 간 판단축을 일치시킴

## Ⅰ. 개요

- **정의/개념**: 학습 패러다임은 학습 신호의 형태에 따라 라벨 기반 지도 학습, 구조 탐색형 비지도 학습, 보상 기반 강화 학습으로 나누는 분류 체계임
- **배경/필요성**: 문제 목표와 데이터 피드백에 맞는 모델을 설계하기 위해 적합한 학습 방식을 고르는 기준이 필요함

### 쉽게 이해하기 (학습용)
- 공부할 때 정답지를 보는지, 스스로 분류하는지, 시험 점수를 보고 전략을 고치는지에 따라 공부법이 갈리는 것과 같음

## Ⅱ. 특징

- 지도 학습은 입력 $x$와 정답 $y$의 관계를 학습해 새로운 입력의 값을 예측함
- 비지도 학습은 라벨 없이 유사한 데이터를 군집으로 묶거나 저차원 구조를 찾음
- 강화 학습은 환경과 상호작용하며 장기 누적 보상을 최대화하는 정책 $\pi$를 학습함
- 세 방식은 학습 신호가 달라 평가 지표와 데이터 수집 비용도 서로 다름

### 쉽게 이해하기 (학습용)
- 정답지를 보며 문제 푸는 법을 배우면 지도 학습, 정답 없이 비슷한 것끼리 스스로 묶으면 비지도 학습임
- 게임 점수를 보고 다음 전략을 고쳐나가면 강화 학습이고, 셋은 채점 방식이 달라 공부 자료를 모으는 방법도 서로 다름

## Ⅲ. 종류 및 비교

| 판단 기준 | 지도 학습 | 비지도 학습 | 강화 학습 |
|:---|:---|:---|:---|
| 학습 신호 | 정답 라벨 | 입력 데이터 자체 | 환경 보상 |
| 학습 목표 | 예측 오차 최소화 | 잠재 구조 발견 | 누적 보상 최대화 |
| 주요 리스크 | 라벨 편향 | 평가 기준 모호성 | 보상 함수 오설계 |

> 요약: 라벨이 있으면 지도, 구조를 찾으면 비지도, 행동 결과를 최적화하면 강화 학습을 우선 검토함.

### 쉽게 이해하기 (학습용)
- 지도 학습은 선생님이 채점해주는 시험이고, 비지도 학습은 채점 없이 스스로 정리하는 노트이며, 강화 학습은 게임하듯 점수를 보며 전략을 고쳐가는 방식임

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 학습 입력 | 지도·비지도 학습의 특징 데이터, 강화 학습의 상태·관측값 |
| 학습 신호 | 지도 학습의 정답 라벨, 비지도 학습의 별도 정답 없음, 강화 학습의 환경 보상 |
| 학습 모델 | 예측 모델·표현 학습 모델·정책 모델 |
| 학습 결과 | 예측 함수·데이터 표현·행동 정책 |

```text
+-------------+
| 학습 문제  |
+-------------+
       |
       v
+-------------------+     있음      +-------------+
| 보상 기반 상호작용? | ------------> | 강화 학습   |
+-------------------+               +-------------+
       |
      없음
       v
+-------------+     있음      +-------------+
| 라벨 있음? | ------------> | 지도 학습   |
+-------------+               +-------------+
       |
      없음
       v
+-------------+
| 비지도 학습 |
+-------------+
```

> 요약: 학습 패러다임은 정답 라벨·입력 자체·환경 보상에 따라 지도·비지도·강화 학습으로 구분함.

### 쉽게 이해하기 (학습용)
- 문제(입력)를 놓고 채점 기준(학습 신호)이 정답지냐, 없느냐, 게임 점수냐에 따라 서로 다른 방식(모델)으로 공부해 서로 다른 결과물(예측함수·정리노트·전략)을 얻음

## Ⅵ. 실무 사례

1. 장애 티켓 분류기는 담당자 라벨로 지도 학습하고 희소 장애 유형에 가중 손실을 적용함
2. 클라우드 오토스케일링은 시뮬레이터의 서비스 목표 위반과 자원 비용을 보상에 반영해 강화 학습 정책을 학습함

### 쉽게 이해하기 (학습용)
- 장애 티켓 분류는 담당자가 남긴 정답 라벨로 지도 학습하고 드문 장애 유형은 더 신경 써서 배우게 하며, 오토스케일링은 비용과 서비스 품질을 점수 삼아 게임하듯 정책을 훈련함

## Ⅶ. 결론

- 학습 패러다임과 평가 지표는 학습 신호와 업무 목표에 따라 선택해야 함
- 라벨 확보 비용·환경 피드백·오동작 위험을 먼저 평가하고, 보상 설계와 안전 검증이 어려우면 강화 학습을 배제해야 함

### 쉽게 이해하기 (학습용)
- 어떤 채점 기준을 쓸 수 있는지가 공부법을 정하므로, 정답지를 구하기 어렵거나 시험(보상 설계)이 위험하면 그 방식은 피해야 함
