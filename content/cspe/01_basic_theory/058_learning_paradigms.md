## 미리 알고가기

- 라벨: 입력 데이터에 부여된 정답값 또는 목표 출력임
- 보상: 강화학습에서 행동 결과가 목표에 얼마나 부합하는지 알려주는 신호임
- 에이전트: 환경을 관찰하고 행동을 선택하는 주체임
- 자기지도 학습: 데이터 자체에서 만든 목표로 표현을 사전학습하는 방식임
- 준지도 학습: 소량 라벨과 대량 무라벨 데이터를 함께 사용하는 방식임

## Ⅰ. 개요

- **정의**: 학습 패러다임은 라벨, 보상, 자기지도 목표 유무를 기준으로 머신러닝 문제와 알고리즘을 분류하는 체계임
- **배경/필요성**: 예측, 군집, 제어, 표현학습은 필요한 데이터와 평가 방식이 다르므로 문제 성격에 맞는 학습 방식을 먼저 선택해야 모델 설계와 운영 지표가 맞음
- **비유**: 정답지가 있는 수업, 스스로 분류해보는 자율 학습, 보상으로 배우는 훈련, 빈칸 맞히기 예습을 구분하는 것과 같음

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 패러다임 구분 | 지도, 비지도, 강화, 자기지도 | 라벨 유무만으로 강화학습 설명 |
| 알고리즘 매핑 | 분류·회귀, 군집·차원축소, 정책학습 | 준지도·자기지도 위치 누락 |

> 요약: 학습 패러다임은 데이터 신호와 학습 목표의 차이에 따라 알고리즘 선택 기준을 정리하는 분류 체계임.

## Ⅱ. 특징/비교

| 판단 기준 | 지도·비지도 학습 | 강화·자기지도 학습 |
|:---|:---|:---|
| 학습 신호 | 지도는 라벨, 비지도는 데이터 구조를 사용함 | 강화는 보상, 자기지도는 데이터에서 만든 목표를 사용함 |
| 대표 문제 | 분류·회귀, 군집·차원 축소가 중심임 | 제어·의사결정, 사전학습·표현학습이 중심임 |
| 평가 방식 | 정답 지표 또는 내부 구조 지표로 평가함 | 누적 보상, downstream 성능, 정책 안정성으로 평가함 |
| 선택 조건 | 라벨 확보 가능성과 구조 탐색 필요성으로 선택함 | 상호작용 비용, 보상 설계, 라벨 부족 상황을 고려해 선택함 |

> 요약: 학습 패러다임은 라벨, 보상, 자기 생성 목표 중 어떤 신호로 모델을 학습할 수 있는지에 따라 선택함.

- **입력 조건**: 사용할 수 있는 라벨, 보상, 무라벨 데이터, 상호작용 경로를 확인해야 함
- **평가 기준**: 패러다임별 지표가 업무 성과와 연결되는지 검증함
- **선택 판단**: 문제 목표보다 데이터 신호를 먼저 보면 패러다임 오선택을 줄일 수 있음

## Ⅲ. 구성요소

```text
+-------------+      +------------+      +---------------+
| 문제 요구   | ---> | 학습 신호  | ---> | 알고리즘 선택 |
+-------------+      +------------+      +---------------+
       |                    |                    |
       v                    v                    v
+-------------+      +------------+      +---------------+
| 데이터 조건 |      | 평가 지표  |      | 운영 피드백   |
+-------------+      +------------+      +---------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 문제 요구 | 예측, 분류, 군집, 제어, 생성 등 해결할 업무 목표임 | 수업 목표 |
| 데이터 조건 | 라벨 수, 무라벨 데이터 규모, 상호작용 가능성, 데이터 품질을 포함함 | 교재와 정답지 |
| 학습 신호 | 라벨, 구조, 보상, 자기 생성 목표처럼 모델이 배울 기준임 | 피드백 방식 |
| 알고리즘 선택 | 학습 신호에 맞춰 회귀, 군집, Q-learning, self-supervised 모델 등을 고름 | 학습법 선택 |
| 평가 지표 | 정확도, 실루엣, 누적 보상, downstream 성능 등 성공 기준임 | 성적표 |

> 요약: 학습 패러다임 선택은 문제 요구, 데이터 조건, 학습 신호, 평가 지표를 일관되게 맞추는 구조임.

## Ⅳ. 절차

```text
+------------+      +-------------+      +---------------+      +------------+
| 문제 정의  | ---> | 데이터 진단 | ---> | 패러다임 선택 | ---> | 평가 설계  |
+------------+      +-------------+      +---------------+      +------------+
```

1. **문제 정의**: 예측, 탐색, 제어, 생성 중 어떤 의사결정을 지원할지 명확히 함
2. **데이터 진단**: 라벨 여부, 보상 관측 가능성, 무라벨 데이터 규모, 상호작용 비용을 확인함
3. **패러다임 선택**: 지도, 비지도, 강화, 자기지도, 준지도 중 학습 신호가 가장 맞는 방식을 고름
4. **평가 설계**: 패러다임별 지표와 운영 검증 방식을 정해 모델 선택 기준을 고정함

> 요약: 학습 패러다임 절차는 문제와 데이터에서 사용 가능한 학습 신호를 파악하고 그에 맞는 평가 기준을 정하는 흐름임.

- **산출물**: 선택한 학습 방식, 후보 알고리즘, 데이터 요구사항, 평가 지표임
- **검증 기준**: 학습 신호와 운영 목표가 같은 방향으로 성능을 측정해야 함
- **운영 기록**: 라벨 정책, 보상 설계, 데이터 사용 범위를 의사결정 기록으로 남겨야 함

## Ⅴ. 문제점

- **P1 패러다임 오선택**: 라벨이 부족한 문제를 무리하게 지도학습으로 풀거나 보상 설계가 없는 문제를 강화학습으로 잡으면 성능과 비용이 악화됨
- **P2 평가 기준 불일치**: 비지도 지표나 누적 보상이 실제 업무 성과와 다르면 모델 지표가 높아도 현장 효과가 낮을 수 있음
- **P3 데이터·상호작용 비용**: 라벨링, 환경 시뮬레이션, 온라인 탐험 비용이 커서 학습 방식 자체가 현실적으로 어려울 수 있음

> 요약: 학습 패러다임의 핵심 문제는 알고리즘보다 문제 신호와 평가·비용 조건을 잘못 맞추는 데 있음.

## Ⅵ. 개선방안

- **P1 대응**: 문제 목표와 학습 신호 매트릭스를 작성하고 기준선 알고리즘을 비교함 (확인: 패러다임별 데이터 요구와 성능)
- **P2 대응**: 오프라인 지표와 업무 KPI, 사용자 검증, 시뮬레이션 결과를 함께 연결함 (확인: 지표 간 상관과 현장 피드백)
- **P3 대응**: Active learning, semi-supervised learning, offline RL, synthetic data로 데이터·상호작용 비용을 줄임 (확인: 라벨 비용과 안전 제약 충족)

> 요약: 개선은 학습 신호와 평가 지표를 업무 목적에 맞추고 데이터 확보 비용을 줄이는 보완 전략을 선택하는 것임.

- **우선순위**: 라벨·보상 확보 가능성과 안전한 평가 환경을 먼저 확인함
- **확인 지표**: 정확도, 실루엣, 누적 보상, downstream 성능을 패러다임별로 사용함
- **재평가 조건**: 라벨 비용, 보상 정의, 사용자 피드백 구조가 바뀌면 패러다임을 재선택함

## Ⅶ. 전망

- **발전 방향**: 학습 패러다임은 생성 AI와 자율 시스템 확산으로 지도·비지도·강화·자기지도 방식이 결합되는 혼합 구조로 발전하고 있음
- **기술사적 판단**: 기술사는 문제를 알고리즘 이름으로 시작하지 않고 사용 가능한 학습 신호, 데이터 책임, 평가 지표를 먼저 정의해야 함
- **기술사 제언**: 향후에는 자기지도 사전학습, 인간 피드백 강화학습, 준지도·능동학습이 결합되어 라벨 부족과 운영 비용을 줄이는 방향으로 확장될 것임
