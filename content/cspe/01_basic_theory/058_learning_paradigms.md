## Ⅰ. 개요
- **정의**: 학습 데이터의 정답(Label) 유무와 환경 상호작용 방식에 따라 ML 알고리즘을 분류하는 체계
- **배경/필요성**: 문제 유형(예측·군집·제어)에 따라 적합한 알고리즘 선택 기준 확립 필요
- **비유**: 정답지 유무로 수업 방식(교사 지도·자율 학습·시행착오 훈련)을 결정하는 것

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 3대 패러다임 정의·구분 | 정답 유무 + 보상 유무 기준 매트릭스 | 자기지도 학습(SSL)을 비지도로 오분류 금지 |
| 대표 알고리즘 매핑 능력 | 각 패러다임별 2~3개 알고리즘 | 준지도·자기지도의 위치 설명 필요 |

> 요약: 학습 패러다임은 정답·보상 유무 기준으로 지도·비지도·강화 학습을 분류하는 체계임

## Ⅱ. 구성요소
```text
+-------------------+     +-------------------+     +-------------------+
| Supervised        |     | Unsupervised      |     | Reinforcement     |
| (Label O)         |     | (Label X)         |     | (Reward Signal)   |
| - Classification  |     | - Clustering      |     | - Policy Learning |
| - Regression      |     | - Dimensionality  |     | - Value Function  |
+-------------------+     +-------------------+     +-------------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 지도 학습(Supervised) | 입력-정답 쌍으로 학습하여 미지의 값을 예측(분류·회귀) | 교사가 채점하는 학습 |
| 비지도 학습(Unsupervised) | 정답 없이 데이터 구조·패턴을 군집화·압축·연관 분석 | 자율 탐구 학습 |
| 강화 학습(Reinforcement) | 에이전트가 환경과 상호작용하며 누적 보상 최대화 정책 학습 | 게임 시행착오 |

> 요약: 정답 기반 예측(지도), 구조 탐색(비지도), 보상 최대화(강화)로 3대 패러다임이 구분됨

## Ⅲ. 절차
```text
+----------------+       +----------------+       +----------------+       +----------------+
| Problem Define |       | Data Inspect   |       | Paradigm Select|       | Model Build    |
| (Goal Setting) | ----> | (Label Check)  | ----> | (Map Strategy) | ----> | (Train & Eval) |
+----------------+       +----------------+       +----------------+       +----------------+
```

1. **문제 정의** — 태스크가 분류·회귀·군집·제어 중 어디에 해당하는지 판단
2. **데이터 점검** — 보유 데이터에 정답 레이블이 구축되어 있는지, 환경 시뮬레이션 가능 여부 확인
3. **패러다임 선택** — 정답 O→지도, 정답 X→비지도, 환경 보상→강화 기준으로 전략 결정
4. **모델 구축** — 선택 패러다임에 맞는 알고리즘(SVM/K-Means/DQN 등) 적용 후 평가

> 요약: 문제 유형과 데이터 레이블 여부를 기반으로 패러다임을 선택하고 알고리즘을 적용함

## Ⅳ. 문제점
- 레이블 구축 비용(지도): 수십만 건 데이터에 정답을 부여하는 인건비·시간이 전체 프로젝트 비용의 60% 이상 차지
- 평가 객관성 부재(비지도): 정답이 없어 군집·패턴의 타당성을 검증할 Gold Standard 부재
- 환경 구축 한계(강화): 실제 물리 환경에서의 시행착오는 안전사고·장비 파손 리스크 수반

> 요약: 레이블 비용, 비지도 평가 모호성, 강화학습 환경 리스크가 각 패러다임의 핵심 한계임

## Ⅴ. 개선방안
1. 단기: 액티브 러닝(Active Learning)으로 레이블링 대상을 최소화하여 비용 절감
2. 중기: 준지도 학습(Semi-supervised)·자기지도 학습(SSL)으로 소량 레이블 + 대량 비레이블 결합
3. 장기: 디지털 트윈 기반 시뮬레이션 환경 구축으로 강화학습의 실환경 리스크 제거

- 레이블 비용: 수동 태깅 부담 → 액티브 러닝 + SSL (지표: 레이블 건수 50% 이하 절감)
- 평가 모호성: Gold Standard 부재 → 실루엣 계수·Davies-Bouldin 등 내부 지표 활용 (지표: 실루엣 > 0.5)
- 환경 리스크: 실물 시행착오 → Sim-to-Real Transfer (지표: 시뮬-실환경 성능 갭 10% 이내)

> 요약: 액티브 러닝, SSL, 시뮬레이션 환경으로 각 패러다임 한계를 단계적으로 해소함

## Ⅵ. 전망
- 향후 발전 방향: 자기지도 학습(SSL)이 Foundation Model의 사전학습 표준으로 부상하며, 패러다임 경계 자체가 희미해지는 추세
- 기술사적 판단: 지도-비지도-강화의 엄격한 구분보다 멀티태스크·멀티모달 학습에서 패러다임을 혼합 적용하는 것이 실무 표준
- 기술사 제언: 프로젝트 초기 단계에서 데이터 레이블 가용성과 비용을 정량 산정하고, SSL/준지도 적용 가능성을 우선 검토할 것
