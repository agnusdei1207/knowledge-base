# 학습 패러다임 (Learning Paradigms: Supervised · Unsupervised · Reinforcement)

## 1. 개요

- **정의/개념**: 학습 패러다임은 데이터와 피드백 형태에 따라 지도 학습, 비지도 학습, 강화 학습으로 모델 학습 방식을 구분하는 기준이다.
- **배경/필요성**: 문제 해결 방식은 라벨 유무, 보상 구조, 목표 지표에 따라 달라지므로 업무 요구사항에 맞는 학습 패러다임을 먼저 선택해야 한다.

학습 패러다임 선택은 알고리즘 이름보다 데이터에 어떤 정답·구조·보상이 존재하는지 확인하는 과정이다.

## 2. 특징 및 비교

| 구분 | 지도 학습 | 비지도 학습 | 강화 학습 |
|---|---|---|---|
| 피드백 | 입력-정답 라벨 | 라벨 없음 | 행동 후 보상 |
| 목적 | 예측·분류 | 구조 발견 | 누적 보상 최대화 |
| 대표 기법 | 회귀, 분류 | 군집화, 차원 축소 | Q-learning, policy gradient |
| 평가 | accuracy, RMSE | silhouette, reconstruction | reward, success rate |

선택 기준은 라벨 확보 가능성, 목표 정의 명확성, 상호작용 환경, 평가 지표이다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| Data | 학습 입력 | 라벨·보상 여부 |
| Feedback | 정답, 구조, 보상 | 패러다임 구분 |
| Model | 패턴 학습 주체 | 문제별 선택 |
| Objective | 최적화 목표 | 손실·보상 |
| Evaluation | 성능 검증 기준 | 업무 지표 연결 |

```text
+----------+      +----------+      +----------+
| 문제정의 | ---> | 피드백형태 | ---> | 학습방식선택 |
+----------+      +----------+      +----------+
```

피드백 형태를 잘못 판단하면 이후 모델 구조와 평가 지표도 모두 어긋난다.

## 4. 문제점 및 개선방안

1. **라벨 품질 문제**
   - 지도 학습은 라벨 오류와 편향이 모델 성능을 직접 제한한다.
   - **개선방안**: 라벨 검수, active learning, weak supervision을 적용한다.

2. **비지도 결과 해석 어려움**
   - 군집이나 latent structure가 업무 의미와 다를 수 있다.
   - **개선방안**: 도메인 검증, 외부 지표, 시각화를 병행한다.

3. **강화 학습 안전성**
   - 탐험 과정에서 위험 행동이나 높은 비용이 발생할 수 있다.
   - **개선방안**: 시뮬레이터, offline RL, reward shaping, 안전 제약을 적용한다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| 신용 평가 | 라벨이 있는 연체 데이터로 지도 학습 | AUC, KS |
| 고객 세분화 | 라벨 없이 행동 패턴으로 군집화 | 군집 안정성 |
| 로봇 제어 | 행동 보상 기반으로 정책 학습 | 누적 보상, 실패율 |

## 6. 결론

학습 패러다임은 데이터 피드백 구조에 따라 문제 해결 방식을 정하는 상위 기준이다. 라벨, 구조, 보상 중 무엇을 학습 신호로 쓸 수 있는지 먼저 판단해야 모델 선택과 평가 지표가 일관되게 이어진다.
