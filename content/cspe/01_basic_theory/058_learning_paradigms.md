## 미리 알고가기

- 라벨: 입력 데이터에 대응하는 정답값이며 지도 학습의 직접 피드백이 됨
- 군집: 라벨 없이 유사한 데이터끼리 묶은 집합이며 비지도 학습의 대표 산출물임
- 보상: 행동 결과에 대해 환경이 주는 점수이며 강화 학습의 학습 신호임
- 정책 $\pi$: 상태가 주어졌을 때 어떤 행동을 선택할지 정하는 강화 학습 전략임

## 작성 근거(검토용)

- 개요는 세 패러다임을 학습 신호 기준으로 묶어 분류형 키워드의 기준을 먼저 제시함
- 특징은 지도, 비지도, 강화의 목적 차이와 평가 차이를 짧게 분리함
- 비교표는 학습 신호, 학습 목표, 주요 리스크로 선택 기준을 압축함
- 구성요소는 학습 입력·신호·목적 함수·학습 주체로 패러다임 결정 구조를 보여줌
- 지도·비지도·강화 학습은 학습 신호와 목표의 분류가 핵심이므로 일반 모델 개발 생명주기를 별도 절차로 두지 않음
- 라벨 품질과 강화 학습의 안전성은 학습 패러다임 선택의 대표 조건임

## Ⅰ. 개요

- **정의/개념**: 학습 패러다임은 학습 신호의 형태에 따라 라벨 기반 지도 학습, 구조 탐색형 비지도 학습, 보상 기반 강화 학습으로 나누는 분류 체계임
- **배경/필요성**: 문제 목표와 데이터 피드백에 맞는 모델을 설계하기 위해 적합한 학습 방식을 고르는 기준이 필요함

## Ⅱ. 특징

- 지도 학습은 입력 $x$와 정답 $y$의 관계를 학습해 새로운 입력의 값을 예측함
- 비지도 학습은 라벨 없이 데이터의 유사성, 밀도, 저차원 구조를 찾음
- 강화 학습은 환경과 상호작용하며 장기 누적 보상을 최대화하는 정책 $\pi$를 학습함
- 세 방식은 학습 신호가 달라 평가 지표와 데이터 수집 비용도 서로 다름

## Ⅲ. 종류 및 비교

| 판단 기준 | 지도 학습 | 비지도 학습 | 강화 학습 |
|:---|:---|:---|:---|
| 학습 신호 | 정답 라벨 | 입력 데이터 자체 | 환경 보상 |
| 학습 목표 | 예측 오차 최소화 | 잠재 구조 발견 | 누적 보상 최대화 |
| 주요 리스크 | 라벨 편향 | 평가 기준 모호성 | 보상 함수 오설계 |

> 요약: 라벨이 있으면 지도, 구조를 찾으면 비지도, 행동 결과를 최적화하면 강화 학습을 우선 검토함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 학습 입력 | 특징 데이터·환경 상태 |
| 학습 신호 | 정답 라벨·입력 자체·환경 보상 |
| 목적 함수 | 예측 오차·잠재 구조·누적 보상 |
| 학습 주체 | 예측 모델·행동 에이전트 |

```text
+-------------+
| 학습 문제  |
+-------------+
       |
       v
+-------------------+     있음      +-------------+
| 보상 기반 상호작용? | ------------> | 강화 학습   |
+-------------------+               +-------------+
       |
      없음
       v
+-------------+     있음      +-------------+
| 라벨 있음? | ------------> | 지도 학습   |
+-------------+               +-------------+
       |
      없음
       v
+-------------+
| 비지도 학습 |
+-------------+
```

> 요약: 학습 패러다임은 정답 라벨·입력 자체·환경 보상에 따라 지도·비지도·강화 학습으로 구분함.

## Ⅵ. 실무 사례

1. 장애 티켓 분류는 지도 학습으로 라벨을 예측하고 클래스별 재현율로 검증함
2. 클라우드 오토스케일링은 시뮬레이터에서 강화 학습 정책을 학습하고 서비스 목표 위반률·자원 비용으로 검증함

## Ⅶ. 결론

- 학습 패러다임과 평가 지표는 학습 신호와 업무 목표에 따라 선택해야 함
