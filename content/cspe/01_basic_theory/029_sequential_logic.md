## 미리 알고가기

- 순서 논리 회로: 현재 입력과 저장된 과거 상태로 다음 상태와 출력을 결정하는 회로임
- 상태: 플립플롭이나 레지스터에 저장되어 다음 동작을 결정하는 내부 값임
- 플립플롭: 클록 에지에서 1비트 값을 저장하는 동기식 기억 소자임
- 래치: 클록 레벨이 열려 있는 동안 입력이 출력으로 전달되는 기억 소자임
- 셋업·홀드 시간: 클록 에지 전후에 입력 데이터가 안정되어야 하는 최소 시간 조건임
- 메타안정성: 타이밍 조건 위반으로 출력이 한동안 0 또는 1로 확정되지 않는 현상임
- 정적 타이밍 분석(STA): 모든 경로의 셋업·홀드 여유를 계산해 클록 조건 충족 여부를 검증하는 방식임
- 클록 도메인 교차(CDC): 서로 다른 클록 영역 사이의 신호 전달과 메타안정성 위험을 다루는 검증 분야임

## 작성 근거(검토용)

- 개요는 조합 논리와 기억 소자의 결합을 명시해 028번 조합 논리와 대비되게 작성함
- 특징은 상태 의존성·클록 동기화·FSM 모델링·타이밍 제약을 핵심 판단축으로 선별함
- Ⅲ은 플립플롭·레지스터를 중심으로 래치·카운터·FSM까지 확장해 순서 논리 유형을 비교함
- Ⅳ와 Ⅴ는 피드백 구조와 클록 에지 갱신 절차를 연결해 동작 원리를 추적 가능하게 함
- 오동작의 주된 원인인 STA 위반과 CDC 문제를 검증 방법과 함께 남김

## Ⅰ. 개요

- **정의/개념**: 순서 논리 회로는 조합 논리와 기억 소자를 결합해 현재 입력과 이전 상태를 기준으로 다음 상태와 출력을 생성하는 디지털 회로임
- **배경/필요성**: 시간 순서와 실행 이력을 저장하기 위해 상태 기반 회로가 필요함

## Ⅱ. 특징

- 출력이 현재 입력뿐 아니라 저장된 상태에 의존하므로 시간 흐름을 표현함
- 클록 에지에 맞춰 상태를 갱신해 여러 회로 블록의 동작 시점을 맞춤
- 상태 전이표와 상태도로 FSM을 모델링해 복잡한 제어 흐름을 검증함
- 셋업·홀드 시간과 클록 스큐를 위반하면 논리식이 맞아도 오동작함

## Ⅲ. 종류 및 비교

| 유형 | 상태 갱신 기준 | 저장 단위 | 주요 활용 | 유의점 |
|:---|:---|:---|:---|:---|
| 래치 | 클록 레벨 | 1비트 | 임시 저장·저전력 설계 | 투명 구간 관리 필요 |
| 플립플롭 | 클록 에지 | 1비트 | 동기식 상태 저장 | 셋업·홀드 시간 필요 |
| 레지스터 | 클록 에지 | 여러 비트 | CPU 내부 데이터 보관 | 비트 폭과 리셋 정의 필요 |
| 카운터 | 클록 에지 | 연속 상태 | 순서 계수·타이머 | 오버플로 처리 필요 |
| FSM | 입력과 현재 상태 | 상태 집합 | 제어기·프로토콜 | 불법 상태 복구 필요 |

> 요약: 플립플롭은 1비트 상태를 만들고, 레지스터·카운터·FSM은 이를 묶어 순서 제어를 구현함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 상태 레지스터 | 현재 상태를 저장하고 클록 에지에서 다음 상태로 갱신함 |
| 다음 상태 논리 | 현재 상태와 입력을 조합해 다음 상태 값을 계산함 |
| 출력 논리 | 현재 상태 또는 입력을 기준으로 외부 출력 신호를 생성함 |
| 클록·리셋 | 갱신 시점과 초기 상태를 정해 회로 시작 조건을 통제함 |
| 피드백 경로 | 저장된 상태를 다시 조합 논리로 보내 순서 동작을 만듦 |

```text
입력 -> [다음 상태 논리] -> [상태 레지스터] -> 출력
             ^                         |
             +------- 피드백 ----------+
```

> 요약: 순서 논리는 저장된 상태를 피드백해 현재 입력과 함께 다음 상태를 계산함.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 현재 상태 유지 | --> | 다음 상태 계산 | --> | 클록 에지 샘플 | --> | 상태 갱신   |
+----------+     +----------+     +----------+     +----------+
```

1. **상태 유지**: 상태 레지스터가 이전 클록에서 저장한 현재 상태를 유지함
2. **다음 상태 계산**: 조합 논리가 입력과 현재 상태로 다음 값을 미리 계산함
3. **클록 샘플링**: 클록 에지에서 셋업·홀드 조건을 만족한 값을 저장함
4. **출력 갱신**: 새 상태가 출력 논리와 피드백 경로에 반영됨

> 요약: 상태 갱신은 클록 에지에서만 안전하며 셋업·홀드 조건이 결과 신뢰성을 좌우함.

## Ⅵ. 실무 사례

1. 고속 동기 회로는 셋업·홀드 시간 위반이 데이터 오류로 이어지므로 클록 주기·스큐를 조정하고 STA의 최악 경로 여유로 검증함
2. 외부 비동기 입력은 메타안정성 위험이 있으므로 2단 동기화기와 CDC 검증을 적용하고 구조 위반 수·메타안정성 평균 고장 간격으로 확인함

## Ⅶ. 결론

- 순서 논리 회로는 상태를 저장해 시간 흐름을 제어하는 구조이므로 상태 전이의 정확성과 클록 타이밍을 함께 검증해야 신뢰성 있는 동작이 가능함
