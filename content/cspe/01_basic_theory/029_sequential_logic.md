## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 기억 소자(플립플롭)를 포함하여 현재 입력과 이전 상태에 따라 출력이 결정되는 디지털 회로임 |
| **배경/필요성** | 데이터 저장·상태 유지·순차 제어가 필요하며, 레지스터·카운터·FSM의 기반이 됨 |
| **출제 의도** | SR·D·JK·T 플립플롭의 동작과 레지스터·카운터의 구성을 설명할 수 있는지 평가함 |

## Ⅱ. 구성요소
```
+----------+     +----------+     +----------+
| 래치     | --> | 플립플롭  | --> | 레지스터  |
| (비동기) |     | (클럭동기)|     | (다비트)  |
+----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| SR 래치 | Set·Reset 입력으로 1비트를 저장하는 비동기 기억 소자임 | ON/OFF 토글 스위치 |
| D 플립플롭 | 클럭 상승 에지에서 D 입력을 캡처하여 1비트를 저장함 | 클럭 신호에 맞춰 기록하는 메모장 |
| 레지스터 | n개의 플립플롭을 묶어 n비트 데이터를 동시에 저장·전달하는 회로임 | 메모장의 한 줄(여러 칸) |

> 요약: 래치(비동기) → 플립플롭(클럭 동기) → 레지스터(다비트)로 순서 논리를 구성함.

## Ⅲ. 절차
```
+------------+     +------------+
| 상태정의   | --> | 전이표작성  |
| (FSM)     |     | (상태전이) |
+------------+     +------------+
                        |
+------------+     +----+-------+
| 회로구현   | <-- | 플립플롭  |
| (배선)     |     | 선택·연결  |
+------------+     +------------+
```

1. 상태 정의: FSM의 상태와 입력·출력을 정의함(Mealy/Moore 구분)
2. 상태 전이표 작성: 현재 상태·입력 → 다음 상태·출력을 표로 정리함
3. 플립플롭 선택: D·JK·T 중 적합한 플립플롭을 선택하고 여기 테이블을 참조함
4. 조합 논리 설계·구현: 플립플롭 입력을 구동하는 조합 논리를 설계하고 배선함

> 요약: 상태 정의 → 전이표 → 플립플롭 선택 → 조합 논리 구현으로 순서 회로를 설계함.

## Ⅳ. 문제점
- 메타안정성: 셋업/홀드 시간 위반 시 플립플롭이 불확정 상태에 머무르는 메타안정성이 발생함
- 클럭 스큐: 플립플롭 간 클럭 도달 시간 차이로 타이밍 오류가 발생함
- 상태 폭발: FSM 상태 수 증가 시 설계·검증 복잡도가 급증함

## Ⅴ. 개선방안
- (단기) 동기화기(Synchronizer): 비동기 입력에 2단 플립플롭을 적용하여 메타안정성을 줄임
- (중기) 클럭 트리 합성(CTS): EDA 도구로 클럭 스큐를 최소화하는 클럭 분배 네트워크를 설계함
- (장기) GALS 설계: Globally Asynchronous Locally Synchronous 구조로 클럭 도메인 간 인터페이스를 관리함

## Ⅵ. 전망
- RISC-V·ARM 프로세서의 파이프라인 레지스터가 순서 논리의 핵심이며, 3D 적층 칩에서 다중 클럭 도메인 관리가 순서 논리 설계의 주요 과제가 될 전망임
