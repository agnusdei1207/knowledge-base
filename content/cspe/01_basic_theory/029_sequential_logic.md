## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 현재의 입력뿐만 아니라 과거의 상태(내부 메모리)에 의해서도 출력이 결정되는 논리 회로임 |
| 배경/필요성 | 데이터의 저장, 카운팅, 상태 유지 등 시간의 흐름에 따른 동적 시스템 제어를 위해 필요함 |
| 출제 의도 | 래치/플립플롭의 동작 원리와 클럭(Clock) 동기화, 레지스터 및 카운터의 설계 개념 평가 |

## Ⅱ. 구성요소
```text
+-------------------+       +-------------------+       +-------------------+
| Combinational     | ----> | Memory Elements   | ----> | Clock Signal      |
| Logic Block       |       | (Flip-Flops)      |       | (Synchronization) |
+-------------------+       +-------------------+       +-------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 조합 회로부 | 다음 상태와 출력을 계산하는 논리 연산 블록 | 두뇌 (계산기) |
| 기억 소자 | 플립플롭(SR, D, JK, T) 등 과거의 상태(1비트)를 저장하는 소자 | 메모장 |
| 클럭 신호 | 모든 소자가 일제히 상태를 갱신하도록 기준을 제공하는 주기적 신호 | 지휘자의 템포 신호 |
> 요약: 순서 논리 회로는 조합 회로, 상태를 저장하는 플립플롭, 그리고 클럭 신호로 구성됨

## Ⅲ. 절차
```text
+----------------+    +----------------+    +----------------+    +----------------+
| 1. 상태도 작성 | -> | 2. 상태표 작성 | -> | 3. 플립플롭 선택| -> | 4. 회로 구현   |
+----------------+    +----------------+    +----------------+    +----------------+
```
1. 상태도 작성: 시스템이 가질 수 있는 모든 상태와 입력에 따른 전이 과정을 다이어그램으로 그림
2. 상태표 작성: 현재 상태, 외부 입력, 다음 상태, 출력을 테이블 형태로 매핑함
3. 플립플롭 선택: 설계 목적에 맞는 플립플롭(예: D-FF, JK-FF)을 선택하고 여기표(Excitation table)를 작성함
4. 회로 구현: 상태표에 따라 조합 논리식을 간소화하고, 플립플롭과 조합 회로를 연결하여 구현함
> 요약: 상태의 변화를 모델링하고 이에 맞는 플립플롭을 배치하여 시간에 따라 제어되는 회로를 완성함

## Ⅳ. 문제점
- 클럭 스큐(Clock Skew): 회로 기판 내 물리적 거리 차이로 클럭 신호가 각 플립플롭에 동시에 도착하지 않아 오동작 유발
- 메타스테빌리티(Metastability): 클럭 엣지 부근에서 입력 신호가 변할 때, 출력이 0과 1 사이에서 불안정해짐

## Ⅴ. 개선방안
- 클럭 분배 최적화: 클럭 트리 합성(Clock Tree Synthesis) 기법을 사용하여 클럭 라인의 지연 시간을 균일하게 맞춤
- 동기화기(Synchronizer) 사용: 비동기 입력 신호 처리 시 두 개 이상의 D 플립플롭을 직렬 연결하여 불안정 상태를 회소화함

## Ⅵ. 전망
- 고성능 CPU 및 SoC에서 순서 논리 회로는 클럭리스(비동기식) 설계 기법과 융합되어 전력 소모를 줄이고 타이밍 제약의 한계를 극복하는 방향으로 발전할 것임
