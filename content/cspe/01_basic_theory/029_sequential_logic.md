## 미리 알고가기

- 상태: 플립플롭이나 레지스터에 저장되어 다음 동작을 결정하는 내부 값임
- 플립플롭: 클록 에지에서 1비트 값을 저장하는 동기식 기억 소자임
- 래치: 클록 레벨이 열려 있는 동안 입력이 출력으로 전달되는 기억 소자임
- 레지스터: 여러 플립플롭을 병렬로 묶어 다중 비트 값을 저장하는 회로임
- 유한 상태 머신(Finite State Machine, FSM): 현재 상태와 입력으로 다음 상태와 출력을 결정하는 제어 모델임
- 셋업·홀드 시간: 클록 에지 전후에 입력 데이터가 안정되어야 하는 최소 시간 조건임
- 메타안정성: 타이밍 조건 위반으로 출력이 한동안 0 또는 1로 확정되지 않는 현상임
- 클록 스큐: 같은 클록 에지가 레지스터별로 서로 다른 시점에 도달하는 시간 편차임
- 정적 타이밍 분석(STA): 모든 경로의 셋업·홀드 여유를 계산해 클록 조건 충족 여부를 검증하는 방식임
- 클록 도메인 교차(CDC): 서로 다른 클록 영역 사이의 신호 전달과 메타안정성 위험을 다루는 검증 분야임

## 작성 근거(검토용)

- 개요는 조합 논리와 기억 소자의 결합을 명시해 028번 조합 논리와 대비되게 작성함
- 특징은 상태 의존성·클록 동기화·FSM 모델링·타이밍 제약을 핵심 판단축으로 선별함
- Ⅲ은 래치·플립플롭·레지스터를 갱신 메커니즘·저장 단위·주요 제약으로 비교함
- Ⅳ와 Ⅴ는 피드백 구조와 클록 에지 갱신 절차를 연결해 동작 원리를 추적 가능하게 함
- 오동작의 주된 원인인 STA 위반과 CDC 문제를 검증 방법과 함께 남김

## Ⅰ. 개요

- **정의/개념**: 순서 논리 회로는 조합 논리와 기억 소자를 결합해 현재 입력과 이전 상태를 기준으로 다음 상태와 출력을 생성하는 디지털 회로임
- **배경/필요성**: 시간 순서와 실행 이력 저장을 위해 상태 기반 회로가 필요함

## Ⅱ. 특징

- 출력이 현재 입력뿐 아니라 저장된 상태에 의존하므로 시간 흐름을 표현함
- 클록 에지에 맞춰 상태를 갱신해 여러 회로 블록의 동작 시점을 맞춤
- 상태 전이표와 상태도로 FSM을 모델링해 복잡한 제어 흐름을 검증함
- 셋업·홀드 시간을 위반하거나 클록 스큐가 커지면 논리식이 맞아도 오동작함

## Ⅲ. 종류 및 비교

| 유형 | 갱신 메커니즘 | 저장 단위 | 주요 제약 |
|:---|:---|:---|:---|
| 래치 | 클록 레벨 감응 | 1비트 | 투명 구간 경합 |
| 플립플롭 | 클록 에지 감응 | 1비트 | 셋업·홀드 위반 |
| 레지스터 | 클록 에지 동시 갱신 | 다중 비트 | 클록 스큐 |

> 요약: 래치는 클록 레벨에서, 플립플롭과 레지스터는 클록 에지에서 각각 1비트와 다중 비트를 저장함.

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 상태 레지스터 | 클록 에지에서 확정한 현재 상태 저장소 |
| 다음 상태 논리 | 입력·현재 상태 기반 다음 상태 계산 회로 |
| 출력 논리 | 상태·입력 기반 외부 출력 회로 |
| 제어 신호 | 클록 갱신·리셋 초기화 신호 |

```text
입력 -----> [다음 상태 논리] -----> [상태 레지스터] -----> [출력 논리] -----> 출력
  |                ^                         |                    ^
  |                +------- 현재 상태 -------+                    |
  +--------------------------------------------------------------+
클록·리셋 --------------------------> [상태 레지스터]
```

> 요약: 순서 논리 회로는 다음 상태를 계산해 클록에 맞춰 저장하고 출력 신호를 생성함.

## Ⅴ. 원리 및 절차 흐름도

```text
현재 상태·입력 → 다음 상태 계산 → 셋업 시간 확보
                                  ↓
클록 에지에서 상태 저장 → 출력 갱신 → 다음 클록 반복
```

1. **상태 유지**: 상태 레지스터가 이전 클록에서 저장한 현재 상태를 유지함
2. **다음 상태 계산**: 조합 논리가 입력과 현재 상태로 다음 값을 미리 계산함
3. **클록 샘플링**: 클록 에지에서 셋업·홀드 조건을 만족한 값을 저장함
4. **출력 갱신**: 새 상태가 출력 논리와 피드백 경로에 반영됨

> 요약: 상태 레지스터는 클록 에지에서 값을 저장하므로 입력이 셋업·홀드 시간을 만족해야 함.

## Ⅵ. 실무 사례

1. 동기 회로는 클록 주기와 스큐 한계를 설정하고 정적 타이밍 분석의 최소 경로 여유가 타이밍 충족 여부를 좌우함
2. 단일 비트 CDC 제어 신호는 2단 동기화기를 적용하고 동기화 실패 횟수와 메타안정성 발생 간격으로 동기화 신뢰성을 가늠함

## Ⅶ. 결론

- 순서 논리 회로는 이전 상태를 기억해 다음 출력을 만들며, 상태 전이의 정확성과 클록 타이밍을 함께 보장해야 함
