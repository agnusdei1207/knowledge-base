## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 순서 논리 회로(Sequential Logic Circuit)는 **이전 상태를 기억**하여 현재 입력과 함께 출력을 결정하는 회로이다. 핵심 소자는 **플립플롭(Flip-Flop)**으로, 1비트를 저장하며 클록 신호에 동기화되어 상태를 전이한다.
> 2. **가치**: 레지스터(다수 플립플롭의 묶음), 카운터, 메모리(SRAM=6개 트랜지스터 플립플롭), 유한 상태 머신(FSM) 등 **상태를 저장하고 시간에 따라 동작하는 모든 디지털 시스템**의 기반이다. 조합 논리가 "계산"이라면 순서 논리는 "기억"이다.
> 3. **융합**: CPU(파이프라인 레지스터, 프로그램 카운터), 메모리(SRAM/DRAM), 네트워크(프로토콜 상태 머신), 보안(암호 상태 관리), 임베디드(타이머, PWM) 등 "시간에 따라 동작이 변하는" 모든 시스템에 순서 논리가 사용된다.

---

### 🔑 핵심 용어 정리

| 용어 | 뜻 | 비유 |
|:---|:---|:---|
| **래치(Latch)** | 레벨 트리거로 1비트를 저장하는 기본 기억 소자. SR 래치가 대표적 | "열린 문" |
| **플립플롭(Flip-Flop)** | 에지 트리거(클록 전이 순간)로 1비트를 저장하는 동기식 기억 소자 | "초인종 순간만 열리는 문" |
| **에지 트리거 vs 레벨 트리거** | 에지: 신호 전이(↑/↓) 순간에만 반응. 레벨: 신호가 높은/낮은 동안 계속 반응 | "찰칵 vs 계속 열림" |
| **FSM(Finite State Machine)** | 유한 개의 상태와 전이 규칙으로 동작을 기술하는 모델. Moore/Mealy 두 유형 | "엘리베이터 제어기" |
| **셋업/홀드 타임** | 플립플롭이 정확히 캡처하려면 클록 에지 전(셋업)·후(홀드)에 입력이 안정되어야 하는 시간 | "사진 찍을 때 가만히" |

## Ⅰ. 개요 및 필요성

- **개념**: 순서 논리 = 조합 논리 + 피드백(메모리). 출력의 일부가 입력으로 돌아가(피드백) 이전 상태를 유지한다. 래치(Latch)는 레벨 트리거(신호 높이에 반응), 플립플롭(Flip-Flop)은 에지 트리거(신호 전이 순간에만 반응)로 구분된다. 현대 동기식 디지털 설계는 플립플롭을 표준으로 사용한다.

- **필요성**: 조합 논리만으로는 "기억"이 불가능하다. 1+1=2를 계산할 수 있어도, "이전에 3을 저장했다"는 정보를 유지할 수 없다. 플립플롭이 비트를 저장하고, 이를 묶어 레지스터·메모리·카운터를 구성한다.

- **비유**: 순서 논리는 **엘리베이터**와 같다. 현재 층(상태)을 기억하고, 버튼 입력(현재 입력)에 따라 다음 층(다음 상태)으로 이동한다. 조합 논리(자판기)와 달리 "지금 어느 층인지"가 동작을 결정한다.

- **등장 배경 및 발전 과정**:
  1. **1918년**: Eccles-Jordan이 최초의 플립플롭(바이스테이블 멀티바이브레이터)을 발명했다.
  2. **1940~50년대**: 플립플롭이 컴퓨터 레지스터에 채택되어 프로그램 카운터(PC), 누산기(ACC) 등을 구현했다.
  3. **현대**: CPU의 파이프라인 스테이지 간 레지스터, GPU의 수천 개 레지스터 파일, SRAM 캐시가 모두 플립플롭 기반이다.

```text
+-----------------------------------------------------------------------+
|        래치 vs 플립플롭 — 트리거 방식의 차이                          |
+-----------------------------------------------------------------------+
|                                                                       |
|  [SR 래치 — 레벨 트리거]                                             |
|                                                                       |
|  S(Set)=1 → Q=1 (설정)                                              |
|  R(Reset)=1 → Q=0 (리셋)                                            |
|  S=R=0 → 이전 상태 유지                                             |
|  S=R=1 → ❌ 금지! (출력 불확정)                                     |
|                                                                       |
|  ┌──[NOR]──── Q                                                     |
|  R──┘     ┌───┘                                                      |
|           └───┐                                                      |
|  S──┐     └──[NOR]──── Q'                                           |
|  └──────────┘                                                        |
|                                                                       |
|  [D 플립플롭 — 에지 트리거 (가장 많이 사용)]                         |
|                                                                       |
|  CLK ↑ (상승 에지) 순간에만 D 입력을 Q로 전달                       |
|  CLK이 안정된 동안(0 또는 1 유지) → Q 불변                          |
|                                                                       |
|  타이밍:                                                              |
|  CLK:  ____|‾‾‾‾|____|‾‾‾‾|____                                     |
|  D:    ‾‾‾‾‾|_________|‾‾‾‾‾‾‾                                      |
|  Q:    _____|‾‾‾‾‾‾‾‾‾|_______  ← CLK↑ 순간의 D값 캡처             |
+-----------------------------------------------------------------------+
```

**[다이어그램 해설]** SR 래치는 S(Set)=1이면 Q=1로 설정, R(Reset)=1이면 Q=0으로 리셋하며, S=R=1은 금지 상태(출력 불확정)이다. D 플립플롭은 SR 래치의 문제를 해결한 것으로, 클록의 **상승 에지(↑)** 순간에만 D 입력을 Q로 캡처한다. 에지 트리거 방식은 글리치(입력 잡음)에 강하고, 동기식 설계에 필수이다. 현대 디지털 설계에서 D 플립플롭이 사실상 표준이다.

- **📢 섹션 요약 비유**: 래치는 "문이 열려 있는 동안 계속 들어올 수 있는 입구"이고, 플립플롭은 "초인종이 울리는 순간에만 문을 여는 입구"입니다. 플립플롭이 더 안전합니다.

## Ⅱ. 아키텍처 및 핵심 원리

### 구성 요소

| 요소명 | 역할 | 트리거 | 특징 | 비유 |
|:---|:---|:---|:---|:---|
| **SR 래치** | 1비트 저장 (원시) | 레벨 | S=R=1 금지 상태 | 원시적 기억 |
| **D 플립플롭** | 1비트 저장 (표준) | 에지 | 가장 널리 사용 | 순간 사진 |
| **JK 플립플롭** | 1비트 저장 (범용) | 에지 | J=K=1 → 토글 | 만능 스위치 |
| **T 플립플롭** | 토글 전용 | 에지 | T=1 → 반전 | 카운터 블록 |
| **레지스터** | N비트 저장 | 에지 | D-FF N개 병렬 | 메모장 |
| **시프트 레지스터** | 직렬↔병렬 변환 | 에지 | D-FF N개 직렬 | 컨베이어 벨트 |
| **카운터** | 순차 계수 | 에지 | T-FF N개 직렬/병렬 | 출석 번호기 |

### 유한 상태 머신(FSM) — Moore vs Mealy

```text
+-----------------------------------------------------------------------+
|        FSM: Moore vs Mealy 상태 머신                                  |
+-----------------------------------------------------------------------+
|                                                                       |
|  [Moore 머신] — 출력이 현재 상태에만 의존                            |
|                                                                       |
|  상태 → 출력 (상태에 출력이 묶임)                                    |
|       ┌──── "0" ────┐                                                |
|       v              |                                                |
|    [S0/출력0] ──1──> [S1/출력1] ──1──> [S2/출력1]                    |
|       ^                                   |                           |
|       └──────────── "0" ─────────────────┘                           |
|                                                                       |
|  [Mealy 머신] — 출력이 현재 상태 + 현재 입력에 의존                  |
|                                                                       |
|  상태 + 입력 → 출력 (전이에 출력이 묶임)                             |
|       ┌── 0/출력0 ──┐                                                |
|       v              |                                                |
|    [S0] ──1/출력1──> [S1] ──1/출력1──> [S2]                          |
|       ^                                   |                           |
|       └──────── 0/출력0 ─────────────────┘                           |
|                                                                       |
|  차이:                                                                |
|  Moore — 상태 수 더 많지만, 출력 안정적 (글리치 없음)                |
|  Mealy — 상태 수 적지만, 출력이 입력에 즉시 반응 (빠름)             |
+-----------------------------------------------------------------------+
```

**[다이어그램 해설]** FSM(유한 상태 머신)은 순서 논리의 설계 모델이다. Moore 머신은 출력이 현재 상태에만 의존하므로 클록 에지에서만 출력이 변한다(안정적). Mealy 머신은 출력이 상태+입력에 의존하므로 입력 변화에 즉시 반응한다(빠르지만 글리치 가능). 실무에서는 Moore가 더 안전하여 선호되지만, 상태 수가 적은 Mealy가 유리한 경우도 있다. 프로토콜 구현(TCP 상태 머신), 엘리베이터 제어, 신호등 제어 등이 FSM으로 설계된다.

- **📢 섹션 요약 비유**: Moore는 "미리 정해진 대사(상태에 묶인 출력)를 말하는 배우"이고, Mealy는 "상대방 대사(입력)에 따라 즉석에서 반응하는 즉흥 배우"입니다.

## Ⅲ. 비교 및 연결

### 비교 1: 플립플롭 4종

| 비교 항목 | SR-FF | D-FF | JK-FF | T-FF |
|:---|:---|:---|:---|:---|
| **입력** | S, R | D | J, K | T |
| **특수 동작** | S=R=1 금지 | — | J=K=1 → 토글 | T=1 → 반전 |
| **용도** | 교육용 | 레지스터, 메모리 | 범용, 카운터 | 카운터 |
| **SRAM과의 관계** | — | SRAM 1셀 ≈ 6T D래치 | — | — |

### 과목 융합 관점
- **CPU**: 파이프라인의 각 스테이지 사이에 레지스터(D-FF 묶음)가 위치하여 명령어를 한 클록씩 전달한다.
- **네트워크**: TCP는 11개 상태의 FSM(LISTEN, SYN_SENT, ESTABLISHED, FIN_WAIT 등)으로 동작한다.
- **메모리**: SRAM 셀 = 크로스-커플드 인버터 2개 + 접근 트랜지스터 2개 = 6T. DRAM 셀 = 커패시터 1개 + 트랜지스터 1개 = 1T1C(순서 논리가 아닌 전하 저장).

- **📢 섹션 요약 비유**: 플립플롭은 "1비트 메모장"이고, 레지스터는 "32칸 메모장"이고, SRAM은 "수백만 칸 메모장"입니다. 모두 플립플롭의 확장입니다.

## Ⅳ. 실무 적용 및 기술사 판단

### 실무 시나리오

1. **시나리오 — CPU 파이프라인 레지스터**: 5단계 파이프라인(IF-ID-EX-MEM-WB) 사이에 4개의 파이프라인 레지스터가 위치한다. 각 레지스터는 수백 비트의 D-FF 묶음으로, 클록 상승 에지마다 이전 스테이지의 결과를 다음 스테이지로 전달한다.

2. **시나리오 — 디지털 시계(카운터)**: 1Hz 클록 입력으로 T-FF 기반 BCD 카운터를 구성하여 초(0~59), 분(0~59), 시(0~23)를 순차적으로 세는 디지털 시계를 구현한다.

### 안티패턴
- **비동기식 설계**: 클록 없이 래치와 피드백으로 설계하면 레이스 컨디션(경쟁 상태)과 메타스테이빌리티(불확정 상태)가 발생한다. 반드시 동기식(클록 기반) 설계를 사용한다.
- **셋업/홀드 타임 위반**: 플립플롭은 클록 에지 전후로 입력이 안정되어야 한다(셋업 타임, 홀드 타임). 위반 시 메타스테이빌리티가 발생하여 출력이 0도 1도 아닌 중간 값에 머문다.

- **📢 섹션 요약 비유**: 셋업/홀드 타임은 "사진 찍을 때 가만히 있어야 하는 시간"입니다. 움직이면(입력 변화) 사진이 흐릿해지듯(메타스테이빌리티), 플립플롭 출력이 불확정됩니다.

### 📈 관련 키워드 및 발전 흐름도

```text
[논리 게이트 + 피드백]
    |
    v
[래치 → 플립플롭 (현재 개념)]
    |
    +---> [레지스터 / 레지스터 파일]
    +---> [카운터 / 타이머]
    +---> [FSM (Moore / Mealy)]
    +---> [SRAM 캐시]
```

### 👶 어린이를 위한 3줄 비유 설명

1. 플립플롭은 "전등 스위치"예요. 누르면(클록) 켜지거나 꺼진 상태를 기억해요.
2. 레지스터는 플립플롭 여러 개를 묶은 "숫자 메모장"이에요. CPU가 계산 중간 결과를 적어놔요.
3. 카운터는 플립플롭으로 만든 "숫자 세기 기계"예요. 1, 2, 3... 클록이 뛸 때마다 하나씩 올라가요!
