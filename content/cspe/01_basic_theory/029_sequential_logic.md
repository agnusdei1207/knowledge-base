# 📖 【암기용】 개념 완전 이해

## 한눈에
- **개요**: 순서 논리 회로(Sequential Logic)는 **현재 입력**과 **이전 상태(과거의 출력)**를 함께 고려하여 다음 상태와 출력을 결정하는 **기억력을 가진** 회로다.
- **왜 필요한가**: 조합 회로(028)는 연산은 잘하지만 '저장'을 못 한다. CPU가 프로그램의 진행 상황을 기억하고, 데이터를 임시 보관(레지스터)하려면 상태를 유지하는 능력이 필수다.
- **핵심 직관**: **"포스트잇"**과 같다. 연산 결과(입력)를 적어 붙여놓고(저장), 다음 연산 때 그 내용을 확인(피드백)하여 작업을 이어간다.

## 핵심 용어 정리

| 용어 | 의미 | 비유/핵심 |
|:---|:---|:---|
| **Feedback Loop** | 출력이 다시 입력으로 들어가는 구조 | 기억의 물리적 통로 |
| **Latch** | 레벨 트리거(Level-triggered). 클럭이 '켜져 있는 동안' 계속 변함 | 문이 열려 있는 동안 자유 출입 |
| **Flip-Flop (FF)** | 엣지 트리거(Edge-triggered). 클럭이 '변하는 순간'에만 캡처 | 찰나의 스냅샷 |
| **Clock (CLK)** | 회로 전체의 박자를 맞추는 주기적 신호 | 오케스트라 지휘자 |
| **Metastability** | 0과 1 사이에서 갈팡질팡하는 불안정한 상태 | 동전이 세로로 서 있는 상태 |

## 깊이 이해
- **배경 (왜 클럭을 쓰는가?)**: 피드백 루프는 제어가 안 되면 신호가 무한 루프에 빠져 진동(Oscillation)한다. 이를 방지하기 위해 **'박자(Clock)'**를 맞춰 정해진 시간에만 상태를 바꾸기로 약속한 것이다.
- **작동 원리 (FSM: Finite State Machine)**:
    - **Moore Machine**: 출력이 오직 '현재 상태'에 의해서만 결정됨 ($O = f(S)$)
    - **Mealy Machine**: 출력이 '현재 상태'와 '현재 입력' 모두에 의해 결정됨 ($O = f(S, I)$). 반응이 빠르지만 설계가 복잡하다.
- **기술적 밀도 (Timing Constraints)**:
    - **Setup Time ($t_{su}$)**: 클럭 엣지가 오기 **전**에 데이터가 안정되어야 하는 최소 시간.
    - **Hold Time ($t_h$)**: 클럭 엣지가 온 **후**에도 데이터가 유지되어야 하는 최소 시간.
    - 이를 위반하면 **메타스테빌리티**가 발생하여 시스템이 멈추거나 오동작한다.
- **구체 예시 (D Flip-Flop)**:
    - 입력 $D$를 클럭 엣지(0→1) 순간에 $Q$로 전달하고 다음 엣지까지 유지한다. CPU 레지스터의 1비트 기본 단위다.

## 연결 개념
- **028 조합 논리 회로**: 순서 회로 내부의 '다음 상태 결정 논리'를 담당.
- **031 CPU 파이프라인**: 스테이지 사이마다 플립플롭(레지스터)을 두어 연산 결과를 전달.
- **032 캐시 메모리**: 초고속 래치 구조(SRAM)를 활용한 메모리 계층.

# 📝 【답안용】 시험 답안 템플릿

## 핵심 인사이트 (3줄 요약)
> 1. **본질**: 피드백 루프를 통해 과거의 상태 정보를 보존하며, 클럭 동기화(Synchronous)를 통해 상태 전이를 제어하는 기억 소자 기반 회로.
> 2. **기술**: Metastability 방지를 위해 Setup/Hold Time 준수가 필수적이며, 목적에 따라 Latch(레벨)와 Flip-Flop(엣지)을 구분하여 설계함.
> 3. **가치**: CPU의 레지스터, 카운터, FSM 제어기 및 SRAM의 물리적 구현체로서 현대 컴퓨팅의 동기식 시스템을 구성함.

## Ⅰ. 순서 논리 회로의 정의 및 메커니즘
- **정의**: 현재 입력과 이전 상태(Past State)의 조합으로 다음 상태와 출력을 결정하는 논리 회로
- **동작 메커니즘**:
    - **조합 회로**: 현재 입력과 현재 상태를 연산하여 '다음 상태'를 결정
    - **기억 소자**: 클럭에 맞춰 결정된 '다음 상태'를 저장하여 '현재 상태'로 피드백
    - **출력 논리**: 현재 상태(Moore) 또는 상태+입력(Mealy)으로 최종 출력 생성

## Ⅱ. 주요 기억 소자 및 특징

### 1. 래치 (Latch) vs 플립플롭 (Flip-Flop)
- **Latch**: Level-sensitive. 인에이블 신호가 활성 구간일 때 입력 변화가 출력에 즉시 반영. 비동기 소자로 활용.
- **Flip-Flop**: Edge-triggered. 클럭의 상승/하강 엣지 시점에만 데이터를 캡처. 동기식 설계의 표준.

### 2. 플립플롭 종류별 기능
- **RS FF**: Set(1), Reset(0) 기능. $S=R=1$일 때 불확정 상태 발생 (단점)
- **D FF**: 입력 D를 엣지 시점에 그대로 저장. 가장 널리 쓰임 (Register용)
- **JK FF**: RS의 불확정 상태를 해결 ($J=K=1$ 시 반전/Toggle). 카운터용.
- **T FF**: 입력이 1일 때마다 현재 상태를 반전. 주파수 분주기용.

## Ⅲ. 순서 논리 회로의 타이밍 제약과 신뢰성

### 1. 타이밍 제약 (Timing Constraints)
- **Setup Time 위반**: 조합 회로의 지연이 너무 길어 클럭 엣지 전에 데이터가 도달하지 못함 → 클럭 주파수 하향 필요
- **Hold Time 위반**: 클럭 엣지 직후에 데이터가 너무 빨리 변함 → 버퍼 삽입 등을 통해 지연 추가 필요

### 2. 메타스테빌리티 (Metastability) 해결
- **발생**: 타이밍 위반으로 출력이 0과 1 사이에서 진동하며 안정화되지 않는 현상
- **해결 (Synchronizer)**: 2단 이상의 플립플롭을 직렬 연결(Multi-stage FF)하여 신호가 안정될 시간을 확보하는 MTBF(Mean Time Between Failures) 설계 기법 적용

## Ⅳ. 무어 머신(Moore) vs 밀리 머신(Mealy) 비교

| 항목 | Moore Machine | Mealy Machine |
|:---|:---|:---|
| **출력 결정** | 오직 현재 상태 ($O=f(S)$) | 현재 상태 + 현재 입력 ($O=f(S, I)$) |
| **상태 수** | 상대적으로 많음 | 상대적으로 적음 (효율적) |
| **반응 속도** | 클럭 동기화로 인한 1클럭 지연 발생 | 입력 변화에 즉시 출력 반응 가능 |
| **설계 복잡도** | 단순, 안전성 높음 | 복잡, 글리치(Glitch) 위험 존재 |

## Ⅴ. 기술적 심화: 클럭 스큐(Clock Skew)와 지터(Jitter)
- **Clock Skew**: 클럭 배선 길이 차이로 인해 플립플롭마다 클럭 도착 시간이 다른 현상. 타이밍 위반의 주요 원인.
- **Clock Jitter**: 클럭 엣지 발생 시간이 주기적으로 미세하게 변동하는 현상.
- **대응**: Clock Tree Synthesis(CTS)를 통해 클럭 신호의 균형을 맞추고, PLL/DLL을 이용해 정밀한 클럭 생성.

## Ⅵ. 실무 적용 및 향후 전망
- **SRAM 캐시 설계**: 6T-SRAM 셀은 래치 구조를 기반으로 하여 초고속 데이터 접근 가능
- **Low Power 설계**: 클럭이 필요 없는 부분의 전원을 차단하는 Clock Gating 기법 적용으로 전력 소모 최소화
- **결론**: 순서 논리는 현대 반도체 설계의 '타이밍 클로저(Timing Closure)' 달성을 위한 핵심 영역이며, 미세 공정화에 따른 지연 시간 제어가 설계의 승부처임

### 🔀 문제 유형별 목차 전환
- **FSM 중심**: Ⅰ(정의) → Ⅳ(Moore/Mealy 상세비교) → Ⅵ(제어기 설계 응용)
- **안정성 중심**: Ⅰ(정의) → Ⅲ(타이밍/메타스테빌리티) → Ⅴ(Skew/Jitter)
- **메모리 중심**: Ⅰ(정의) → Ⅱ(소자별 특징) → Ⅵ(SRAM 및 레지스터 응용)
