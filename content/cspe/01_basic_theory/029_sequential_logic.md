# 순서 논리 회로 - 플립플롭·레지스터 (Sequential Logic)

## 1. 개요

- **정의/개념**: 순서 논리 회로는 현재 입력과 저장된 이전 상태를 함께 사용해 출력을 결정하는 디지털 회로이다.
- **배경/필요성**: 카운터, 레지스터, 상태기계처럼 시간에 따라 값과 상태가 바뀌는 기능은 조합 논리만으로 표현할 수 없으므로 저장 요소와 클럭이 필요하다.

순서 논리의 핵심은 입력 계산이 아니라 상태 저장과 상태 전이이다.

## 2. 특징 및 비교

| 구분 | 조합 논리 | 순서 논리 |
|---|---|---|
| 출력 기준 | 현재 입력 | 현재 입력 + 현재 상태 |
| 저장 요소 | 없음 | 플립플롭, 래치, 레지스터 |
| 시간 기준 | 전파 지연 | 클럭, setup/hold |
| 대표 회로 | 가산기, MUX | 카운터, FSM, 레지스터 |
| 주요 위험 | glitch, 지연 | metastability, timing violation |

순서 논리 선택 기준은 상태 수, 클럭 주파수, setup/hold 시간, 동기화 방식, 상태 전이 검증이다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| Flip-Flop | 클럭 엣지에서 1비트 저장 | 상태 저장 |
| Register | 여러 플립플롭 묶음 | 데이터 보관 |
| Clock | 상태 갱신 기준 신호 | 동기화 |
| Next-State Logic | 다음 상태 계산 | 조합 논리 |
| Output Logic | 현재 상태와 입력 기반 출력 | Moore/Mealy 구분 |

```text
+----------+      +--------------+      +----------+
| 현재상태 | ---> | 다음상태 논리 | ---> | 플립플롭 |
+----------+      +--------------+      +----------+
      ^                                      |
      |                                      v
      +--------------- Clock ---------------+
```

구조상 조합 논리와 저장 요소가 순환하므로, 정확성은 상태 전이표와 타이밍 제약을 함께 만족할 때 확보된다.

## 4. 문제점 및 개선방안

1. **Timing Violation**
   - setup/hold 시간을 만족하지 못하면 잘못된 상태가 저장된다.
   - **개선방안**: static timing analysis, 파이프라이닝, 클럭 주파수 조정을 적용한다.

2. **Metastability**
   - 비동기 입력이 클럭 경계에서 들어오면 출력이 불안정해질 수 있다.
   - **개선방안**: 2단 플립플롭 동기화, CDC 검증을 수행한다.

3. **상태 전이 누락**
   - 정의되지 않은 상태에서 회로가 복구하지 못할 수 있다.
   - **개선방안**: reset, default transition, 상태 도달성 검증을 설계한다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| CPU 레지스터 | 연산 중간값과 명령 상태 저장 | 클럭 주파수, setup 여유 |
| FSM 제어기 | 프로토콜·장치 제어 상태 전이 구현 | 상태 도달성, 예외 복구 |
| 카운터·타이머 | 클럭마다 상태를 증가·감소 | 오버플로우, 정확도 |

## 6. 결론

순서 논리 회로는 시간에 따른 상태 변화를 다루는 디지털 시스템의 기본 구조이다. 조합 논리와 대비해 플립플롭, 레지스터, FSM, 타이밍 문제를 한 흐름으로 설명해야 실제 회로 설계 관점이 드러난다.
