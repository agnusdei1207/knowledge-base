## Ⅰ. 개요

- **정의**: 순서 논리 회로(Sequential Logic Circuit)는 클록 신호에 동기화되어 이전 상태를 저장하고, 현재 입력과 저장된 상태를 함께 반영해 출력을 결정하는 회로임.
- **배경/필요성**: 조합 논리(028)는 출력이 현재 입력에만 의존해 과거 연산 결과를 유지할 수 없으므로, CPU가 중간 계산값·프로그램 카운터를 다음 클록까지 보존하려면 별도의 저장 소자(플립플롭)와 저장 시점을 통제하는 클록 동기화 메커니즘이 필요함.
- **출제 의도**: 래치와 플립플롭의 트리거 차이 이해, 플립플롭 종류별 특성과 레지스터 구성 원리, 셋업/홀드 타임 위반에 따른 메타스테이빌리티 리스크 판단력을 확인함.
- **답안 방향**: 구조(플립플롭 4종+레지스터) → 동작(클록 에지 기반 상태 전이) → 특징(동기식 설계 이점) → 비교(플립플롭 종류별 선택 기준) → 실무 적용 순으로 전개함.

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 상태 저장 구조와 클록 동기화 원리 설명 요구 | 에지 트리거 정의, 플립플롭 종류별 입력-출력 관계, 셋업/홀드 타임 개념 | 래치·플립플롭 혼용, 조합 논리 재설명으로 분량 낭비, 메타스테이빌리티 원인 누락 |

> 요약: 순서 논리 답안은 "왜 저장이 필요한가"와 "클록 에지가 저장 시점을 어떻게 고정하는가"를 먼저 못 박고, 그 위에서 플립플롭 종류별 선택 기준을 논증해야 함.

## Ⅱ. 구조 및 구성요소

```text
[조합 논리 출력] -> [플립플롭 D 입력] -> (클록 상승 에지) -> [Q 출력, 다음 클록까지 유지]
                                              |
                                              +-> Q 출력이 다시 조합 논리 입력으로 피드백

레지스터(N비트) = D 플립플롭 N개를 공통 클록선으로 병렬 연결
  bit0 [D-FF] -> Q0
  bit1 [D-FF] -> Q1
  ...
  bitN [D-FF] -> QN
  (공통 클록 1개가 N개 FF에 동시 인가 -> 전 비트 동시 갱신)
```

| 구성요소 | 역할 | 산출물/비유 |
|:---|:---|:---|
| SR 래치 | 레벨 트리거로 1비트 저장, S=R=1은 금지 상태 | 열려 있는 동안 계속 드나드는 문 |
| D 플립플롭 | 클록 상승 에지 순간에만 D값을 Q로 캡처 | 초인종 울리는 순간에만 찍히는 사진 |
| JK 플립플롭 | D-FF 확장형, J=K=1일 때 Q를 토글 | 셋·리셋·토글 규칙을 하나로 묶은 범용 소자 |
| T 플립플롭 | T=1이면 매 클록마다 Q 반전, 카운터 전용 | 클록마다 눌리는 반전 스위치 |
| 레지스터 | D-FF N개를 공통 클록으로 묶어 N비트를 동시 저장 | N칸짜리 메모장, 한 번에 전체 갱신 |
| 시프트 레지스터 | D-FF N개를 직렬 연결, 매 클록마다 값이 한 칸씩 이동 | 컨베이어 벨트 위 데이터 |

> 요약: 래치는 레벨 트리거로 원시적 저장만 가능하고, 플립플롭은 에지 트리거로 저장 시점을 클록 한 순간에 고정하며, 레지스터는 이 플립플롭을 공통 클록으로 묶어 N비트를 동시에 갱신함.

## Ⅲ. 동작원리 및 흐름도

```text
[조합 논리로 다음 상태값(D) 계산] -> [클록 상승 에지 대기]
  -> 에지 도래: D 입력을 Q로 캡처(상태 갱신)
  -> 에지 미도래: Q 값 불변(이전 상태 유지)
-> 갱신된 Q가 조합 논리 입력으로 피드백 -> 다음 클록까지 위 과정 반복
```

- 1단계(다음 상태 계산): 현재 Q 출력과 입력을 조합 논리 회로에 통과시켜 다음 클록에서 저장할 값(D)을 미리 산출함.
- 2단계(에지 대기 및 캡처): 클록이 상승 에지(0에서 1로 전이)에 도달하는 순간에만 D값을 플립플롭 내부에 캡처함. 그 외 구간(클록이 0 또는 1로 안정된 구간)에는 Q가 불변함.
- 3단계(셋업/홀드 검증): 클록 에지 전 최소 셋업 타임, 에지 후 최소 홀드 타임 동안 D 입력이 안정되어야 정상 캡처가 보장됨. 이 시간을 위반하면 Q가 0도 1도 아닌 중간 전압(메타스테이빌리티)에 머무를 수 있음.
- 4단계(피드백 및 반복): 캡처된 Q가 다음 클록 주기의 조합 논리 입력으로 피드백되어 새 D값 계산에 사용되며, 이 순환이 클록마다 반복됨.

> 요약: 상태 전이는 클록 상승 에지 순간에만 발생하고, 그 순간의 셋업/홀드 타임 준수 여부가 캡처 성공을 좌우하며, 캡처된 Q는 다음 주기 입력으로 피드백됨.

## Ⅳ. 특징

- 상태 보존: 클록 에지 사이 구간에는 입력이 변해도 Q가 불변하므로, 조합 논리만으로는 불가능한 "이전 계산 결과 유지"가 가능함.
- 동기화 정확성: 에지 트리거는 클록 전이 순간에만 반응해 레벨 트리거(래치)보다 입력 잡음(글리치)에 강하고, 여러 플립플롭이 동일 클록선을 공유하면 전 비트가 같은 시점에 갱신되어 데이터 정합성이 보장됨.
- 타이밍 제약: 셋업/홀드 타임을 위반하면 메타스테이빌리티가 발생해 출력이 임계 전압 근처에 머물다 임의 값으로 안정되므로, 클록 주기는 최대 조합 논리 지연과 셋업 타임의 합 이상으로 설계해야 함.
- 구성 확장성: 동일한 D-FF를 병렬로 묶으면 레지스터, 직렬로 묶으면 시프트 레지스터, T-FF로 대체하면 카운터가 되어 하나의 기본 저장 소자로 다양한 저장 구조를 구성함.

> 요약: 플립플롭의 가치는 에지 트리거로 저장 시점을 정확히 고정하는 데 있으며, 이 정확성은 셋업/홀드 타임이라는 제약과 맞바꿔짐.

## Ⅴ. 심화 비교 및 적용 판단

| 비교 기준 | D 플립플롭 | JK 플립플롭 | T 플립플롭 |
|:---|:---|:---|:---|
| 입력 구성 | 1입력(D) | 2입력(J, K) | 1입력(T) |
| 특수 동작 | 없음, 입력값을 그대로 저장 | J=K=1 시 토글 | T=1 시 항상 토글 |
| 주 용도 | 레지스터, 데이터 저장 | 범용 순서 회로 설계 | 카운터 |
| 선택 기준 | 값 자체를 그대로 저장해야 할 때 | 셋·리셋·토글을 하나의 소자로 다뤄야 할 때 | 반전 동작만 필요해 회로를 최소화할 때 |

> 요약: 저장 대상이 임의값이면 D-FF, 토글 포함 다기능이 필요하면 JK-FF, 반전 전용이면 T-FF를 선택함.

**리스크·대응 (불릿):**
- 메타스테이빌리티: 비동기 입력이 셋업/홀드 타임을 위반하는 것이 원인 → 입력단에 동기화 플립플롭 2단(더블 플롭)을 직렬 배치해 불확정 확률을 낮춤.
- 클록 스큐: 배선 길이 차이로 동일 클록이 플립플롭마다 다른 시점에 도달하는 것이 원인 → 클록 트리 균등 배선과 정적 타이밍 분석(STA)으로 검증함.

**도입 후 점검 지표 (불릿):**
- 타이밍 여유: 정적 타이밍 분석(STA)에서 셋업/홀드 여유(slack)가 양수인지 확인함.
- 동기화 신뢰도: 비동기 입력 경로에 더블 플롭이 적용되었는지, 평균 무고장 시간(MTBF) 계산값이 목표치를 넘는지 확인함.

## Ⅵ. 실무 적용 및 결론

1. 단기: 설계 중인 회로에서 비동기 입력 경로를 식별하고 더블 플롭 동기화 적용 여부를 점검함.
2. 중기: 클록 주기와 최대 조합 논리 지연·셋업 타임의 관계를 정적 타이밍 분석으로 검증해 타이밍 위반 구간을 제거함.
3. 장기: 저장 구조(레지스터·시프트 레지스터·카운터) 선택 기준을 설계 표준으로 문서화하여 재사용함.

- 기술사적 판단: 저장이 필요한 설계는 비동기 래치 대신 에지 트리거 플립플롭 기반 동기식 설계를 원칙으로 하고, 예외는 STA로 검증된 경우로 한정함.
- 기술사 제언: 비동기 입력 동기화(더블 플롭)와 클록 스큐 관리를 설계 체크리스트에 명시해 메타스테이빌리티로 인한 간헐적 장애를 예방함.
