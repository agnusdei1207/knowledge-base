## Ⅰ. 개요
- **정의**: 두 데이터 포인트(벡터, 집합) 간의 거리나 유사한 정도를 정량화하는 기법임.
- **배경/필요성**: 검색, 추천 시스템, 클러스터링 등에서 데이터 간의 관계를 수치로 정의하기 위해 필요함.
- **출제 의도**: 유클리드 거리, 코사인 유사도, 자카드 유사도의 차이점과 적용 분야를 식별할 수 있는지 평가함.

## Ⅱ. 구성요소
```text
+------------------+       +------------------+       +------------------+
| Data Objects     | ----> | Similarity Func  | ----> | Similarity Score |
| (Vectors/Sets)   |       | (Cos, Jaccard..) |       | (0.0 ~ 1.0)      |
+------------------+       +------------------+       +------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 유클리드 거리 | 두 점 사이의 최단 직선 거리 (크기 민감) | 직선 줄자 |
| 코사인 유사도 | 두 벡터가 이루는 각도 (방향 민감) | 나침반 각도 |
| 자카드 유사도 | 두 집합 간의 교집합 크기 / 합집합 크기 | 벤 다이어그램 |

> 요약: 거리, 각도, 집합 등을 기준으로 두 데이터의 유사한 정도를 점수화함.

## Ⅲ. 절차
```text
+-------------+   +-------------+   +-------------+   +-------------+
| 1. 데이터   |-->| 2. 척도     |-->| 3. 수치화/  |-->| 4. 결과     |
|    표현     |   |    선택     |   |    계산     |   |    활용     |
+-------------+   +-------------+   +-------------+   +-------------+
```
1. **데이터 표현**: 텍스트를 벡터로 변환하거나, 특성들을 수치형 배열, 집합으로 표상함.
2. **척도 선택**: 데이터 특성에 맞춰 코사인(텍스트), 유클리드(좌표), 자카드(집합) 중 하나를 고름.
3. **수치화/계산**: 선택한 알고리즘(공식)에 따라 두 객체 간의 거리 또는 유사도 수치를 도출함.
4. **결과 활용**: 계산된 점수를 바탕으로 K-NN 분류, 추천 시스템 랭킹 등에 적용함.

> 요약: 데이터를 적절히 표현한 후 특성에 맞는 유사도 척도를 선택하여 점수를 계산하고 활용함.

## Ⅳ. 문제점
- **차원의 저주**: 고차원 공간에서는 유클리드 거리가 유의미한 변별력을 잃는 현상이 발생함.
- **스파스 데이터 문제**: 대부분의 값이 0일 경우, 공통 특성이 적어 유사도 측정의 왜곡이 발생함.

## Ⅴ. 개선방안
- **차원의 저주**: (단기) PCA 등을 통해 차원 축소 후 계산 / (장기) 고차원에 유리한 코사인 유사도 위주로 전환 필요.
- **스파스 데이터 문제**: (단기) Jaccard 유사도 등 집합 기반 접근 활용 / (장기) 임베딩 등 밀집(Dense) 벡터 변환 기법 적용 필요.

## Ⅵ. 전망
- LLM 등 텍스트 임베딩 기술의 발달로 고차원 밀집 벡터 기반의 코사인 유사도 연산 최적화(Vector DB)가 더욱 중요해질 것임.
