## 미리 알고가기

- 잠재 벡터 $z$: 생성자가 다양한 샘플을 만들도록 입력되는 무작위 저차원 벡터임
- 생성자 $G$: 잠재 벡터를 실제 데이터와 유사한 가짜 샘플로 변환하는 신경망임
- 판별자 $D$: 입력 샘플이 실제 데이터인지 생성 데이터인지 확률로 판단하는 신경망임
- 모드 붕괴: 생성자가 데이터 다양성을 잃고 일부 형태의 샘플만 반복 생성하는 현상임
- 변이형 오토인코더(VAE): 잠재 확률분포에서 벡터를 뽑아 디코더로 데이터를 생성하는 모델임
- 확산 모델(Diffusion Model): 노이즈가 섞인 데이터에서 잡음을 여러 단계에 걸쳐 제거하는 생성 모델임
- 생성 품질 거리(FID): 실제·생성 데이터의 특징 분포 간 거리를 측정하는 지표임
- 기울기 패널티 바서슈타인 GAN(WGAN-GP): 두 분포의 이동 거리에 기울기 제약을 더해 학습을 안정화하는 방식임
- 모드 커버리지: 실제 데이터의 다양한 유형을 생성 결과가 포함하는 비율임
- 최근접 샘플 거리: 생성 결과와 가장 가까운 학습 샘플 간 특징 거리를 측정하는 값임

## 작성 근거(검토용)

- 개요는 생성자·판별자 경쟁과 데이터 분포 학습을 함께 제시해 GAN의 본질을 고정함
- 특징은 우도 불필요, 교대 학습, 잠재 조작, 불안정성을 서로 다른 판단점으로 둠
- 비교표는 VAE와 Diffusion 대비 GAN의 생성 메커니즘·추론 단계·주요 리스크를 드러냄
- 구성요소는 $z$, $G$, 실제 데이터, $D$, 적대 손실의 경쟁 구조로 압축함
- 절차는 가짜 생성, 판별, 두 모델 갱신의 교대 흐름을 단순화함
- 생성 품질과 모드 붕괴는 GAN 적용의 핵심 검증 대상임

## Ⅰ. 개요

- **정의/개념**: GAN은 생성자와 판별자가 경쟁 학습을 수행해 실제 데이터 분포와 유사한 샘플을 생성하는 적대적 생성 모델임
- **배경/필요성**: 이미지 생성·스타일 변환·결측 복원을 수행하기 위해 실제와 유사한 데이터 분포를 학습하는 생성 모델이 필요함

## Ⅱ. 특징

- 명시적 우도 계산 없이 판별자의 피드백으로 생성 분포를 학습함
- 판별자는 진위를 분류하고 생성자는 판별자의 오판을 유도하는 상반된 목적을 교대로 최적화함
- 잠재 벡터를 조작해 샘플 다양성, 속성 변화, 보간 결과를 탐색함
- 생성자와 판별자의 갱신 균형이 깨지면 모드 붕괴, 발산, 판별자 우세가 발생함

## Ⅲ. 종류 및 비교

| 판단 기준 | VAE | GAN | Diffusion Model |
|:---|:---|:---|:---|
| 생성 메커니즘 | 잠재 분포 표본의 디코딩 | 생성자와 판별자의 경쟁 | 초기 노이즈 반복 제거 |
| 추론 단계 | 1회 디코딩 | 1회 생성 | 반복 제거 |
| 주요 리스크 | 잠재 변수 무시 | 모드 붕괴 | 생성 지연 |

> 요약: GAN은 한 번의 순전파로 샘플을 생성하지만 학습 균형이 무너지면 모드 붕괴나 발산이 발생함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 잠재 벡터 $z$ | 생성 입력의 무작위 표본 |
| 생성자 $G$ | 잠재 벡터 기반 가짜 샘플 생성 |
| 실제 데이터 $x$ | 실제 분포의 학습 표본 |
| 판별자 $D$ | 실제·가짜 샘플 구분 |
| 적대 손실 | 생성·판별의 상반된 학습 목표 |

```text
잠재 z ---> 생성자 G ---> 가짜 샘플 ---+
                                       +---> 판별자 D ---> 진위 확률
실제 샘플 -----------------------------+
```

> 요약: GAN은 생성·판별 모델의 경쟁 학습으로 실제 분포에 가까운 데이터를 생성함.

## Ⅴ. 원리 및 절차 흐름도

```text
잠재 z ---> 가짜 생성 ---> 진위 판별 ---> 판별자·생성자 교대 갱신
```

1. **가짜 생성**: 잠재 벡터 $z$를 생성자에 넣어 가짜 샘플 $G(z)$를 만듦
2. **진위 판별**: 판별자가 실제 샘플 $x$와 가짜 샘플을 구별함
3. **판별자 갱신**: $D(x)$는 1에, $D(G(z))$는 0에 가깝게 학습함
4. **생성자 갱신**: $G$는 $D(G(z))$가 1에 가깝게 나오도록 가중치를 조정함

> 요약: 판별자와 생성자를 교대로 갱신하며 한 모델이 다른 모델을 압도하면 모드 붕괴나 발산이 발생함.

## Ⅵ. 실무 사례

1. UI 테스트용 합성 이미지는 학습 이미지와 중복된 결과를 제외하고 FID·최근접 샘플 거리로 검증함
2. 학습 데이터 증강용 GAN은 WGAN-GP를 적용하고 모드 커버리지·최근접 샘플 거리로 검증함

## Ⅶ. 결론

- GAN은 생성자와 판별자의 경쟁으로 분포를 학습하므로 갱신 균형과 생성 다양성을 검증해야 함
