## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 생성자와 판별자가 적대적으로 경쟁하며 실제 데이터 분포와 유사한 가짜 데이터를 생성하는 모델임 |
| 배경/필요성 | 명시적 확률 분포 없이도 고해상도의 사실적인 합성 데이터 생성 및 데이터 증강 필요성 대두 |
| 출제 의도 | 적대적 학습(Adversarial Training)의 미니맥스(Minimax) 게임 원리 및 모드 붕괴 한계 평가 |

## Ⅱ. 구성요소
```text
+----------------+       +----------------+       +----------------+
| Random Noise   |       | Fake vs Real   |       | Minimax Game   |
| (Generator)    | ----> | (Discriminator)| ----> | Optimization   |
+----------------+       +----------------+       +----------------+
```
| 생성자 (Gen) | 무작위 노이즈로부터 실제와 유사한 가짜 데이터 생성 | 위조지폐범 |
| 판별자 (Disc) | 입력된 데이터가 실제인지 생성된 가짜인지 판별 | 경찰관 |
| 적대적 손실 | 서로 반대의 목표를 향해 학습하도록 유도하는 함수 | 게임 룰 |
> 요약: GAN은 가짜 데이터를 만드는 생성자와 이를 감별하는 판별자로 구성되어 경쟁 학습함

## Ⅲ. 절차
```text
+----------------+       +----------------+       +----------------+       +----------------+
| Gen Create     |       | Disc Evaluate  |       | Disc Update    |       | Gen Update     |
| (Fake Data)    | ----> | (Real vs Fake) | ----> | (Max Accuracy) | ----> | (Fool Disc)    |
+----------------+       +----------------+       +----------------+       +----------------+
```
1. 가짜 생성: 생성자가 잠재 벡터(노이즈)를 바탕으로 가짜 데이터를 생성
2. 판별 평가: 판별자가 실제 데이터와 가짜 데이터를 각각 입력받아 진위 여부 분류
3. 판별자 학습: 판별자는 진짜와 가짜를 정확히 구분하도록 가중치 업데이트
4. 생성자 학습: 생성자는 판별자가 가짜를 진짜로 속도록 가중치 업데이트
> 요약: 생성자는 속이려 하고 판별자는 맞추려 하며 두 신경망이 번갈아가며 학습함

## Ⅳ. 문제점
- 모드 붕괴(Mode Collapse): 생성자가 판별자를 속이기 쉬운 몇 가지 샘플만 반복 생성함
- 학습 불안정성: 두 모델의 균형이 깨지면 손실 함수가 발산하고 학습이 종료되지 않음
- 평가 기준 모호성: 생성된 데이터의 화질이나 다양성을 정량적으로 평가하기 매우 어려움

## Ⅴ. 개선방안
- 단기 방안: 미니배치 분산 특징(Mini-batch Discrimination) 추가로 다양성 확보
- 중기 방안: Wasserstein 거리 기반의 WGAN 적용으로 학습 불안정성 및 기울기 소실 해결
- 장기 방안: FID(Fréchet Inception Distance) 등 객관적 평가 지표 도입 및 확산(Diffusion) 모델 병행

## Ⅵ. 전망
- 고품질 이미지 생성에서는 확산 모델(Diffusion)에 밀렸으나, 실시간 렌더링 및 음성 합성에서 강세임
