## 미리 알고가기

- generator: 가짜 데이터를 생성하는 모델임
- discriminator: 진짜와 가짜를 구분하는 모델임
- mode collapse: 다양한 샘플을 만들지 못하고 일부 패턴만 반복 생성하는 현상임

## Ⅰ. 개요

- **정의/개념**: GAN은 생성자와 판별자가 서로 경쟁적으로 학습하면서 실제 데이터와 구별하기 어려운 샘플을 생성하도록 만드는 생성 모델임
- **배경/필요성**: 단순 재구성보다 실제 분포와 유사한 새로운 샘플을 생성하려면 생성 모델과 판별 기준을 함께 학습하는 구조가 필요함

## Ⅱ. 특징

- explicit likelihood 없이도 고품질 샘플을 생성할 수 있음
- 이미지 생성과 변환에서 날카로운 결과를 내는 편임
- 생성자와 판별자의 균형이 학습 성공을 좌우함
- 학습이 불안정하고 mode collapse, gradient 문제에 취약함

## Ⅲ. 종류 및 비교

| 판단 기준 | Autoencoder | GAN | Diffusion |
|:---|:---|:---|:---|
| 학습 목표 | 재구성 | 적대 학습 | 점진적 복원 |
| 샘플 품질 | 중간 | 높음 | 매우 높음 |
| 학습 안정성 | 높음 | 낮음 | 중간 |
| 대표 적용 | 압축, 이상탐지 | 생성, 변환 | 생성 모델 최신 추세 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 생성자 $G$ | 잠재 벡터를 샘플로 변환하고 분포 모사 역할임 |
| 판별자 $D$ | 진짜/가짜 확률을 출력하고 학습 신호 제공자임 |
| 잠재 공간 $z$ | 생성 입력 노이즈 공간이며 샘플 다양성을 좌우함 |
| 적대 손실 | $G$와 $D$의 경쟁 목표이며 전체 학습의 핵심임 |

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 잠재 공간 z  | --> | 생성자 G    | --> | 판별자 D    | --> | 적대 손실    |
+-----------+     +-----------+     +-----------+     +-----------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 노이즈입력 | --> | 가짜생성 | --> | 진위판별 | --> | 상호갱신 |
+----------+     +----------+     +----------+     +----------+
```

1. **노이즈입력**: 잠재 벡터를 생성자에 입력함
2. **가짜생성**: 생성자가 새로운 샘플을 만듦
3. **진위판별**: 판별자가 실제 데이터와 구분함
4. **상호갱신**: 판별자는 더 잘 구분하고 생성자는 더 잘 속이도록 학습함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 학습 불안정성이 커 생성자와 판별자 균형이 쉽게 무너짐
   - 해결방안: Wasserstein loss, spectral normalization, learning rate tuning을 적용하고 discriminator loss stability로 검증함
2. 문제: mode collapse가 발생해 샘플 다양성이 부족해짐
   - 해결방안: minibatch discrimination, unrolled GAN 등을 사용하고 sample diversity로 검증함
3. 문제: 평가가 어려워 loss만으로 생성 품질을 설명하기 힘듦
   - 해결방안: FID, IS, human evaluation을 병행하고 FID score로 검증함

## Ⅶ. 적용 사례

- 이미지 생성에서는 얼굴, 제품, 배경 이미지를 합성함, 확인 지표는 FID와 시각 품질임
- 데이터 증강에서는 부족한 학습 샘플을 보완함, 확인 지표는 downstream accuracy임
- 이미지 변환에서는 스타일 변환, 초해상도에 활용함, 확인 지표는 PSNR/SSIM과 품질 평가임

## Ⅷ. 결론

GAN의 핵심은 생성자 자체보다 판별자와의 균형 있는 경쟁에 있으므로, 모델 구조보다 학습 안정화 전략을 먼저 설계해야 함.
