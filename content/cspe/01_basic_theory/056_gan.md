## 미리 알고가기

- 생성 모델($Generative$ $Model$): 실제 데이터의 분포를 학습하여, 이와 유사한 새로운 데이터를 생성해낼 수 있는 통계 모델임
- 생성자($Generator$): 무작위 노이즈를 입력받아 실제 데이터와 유사한 가짜 데이터를 만들어내는 신경망임
- 판별자($Discriminator$): 입력받은 데이터가 실제 데이터인지 생성자가 만든 가짜 데이터인지 감별(0~1 확률)하는 신경망임
- 내쉬 균형($Nash$ $Equilibrium$): 두 경쟁자가 최선의 전략을 찾아내어, 상대방이 전략을 바꾸지 않는 한 서로 더 이상 전략을 수정하지 않는 안정 상태임

## Ⅰ. 개요

- **정의/개념**: 생성적 적대 신경망(GAN)은 가짜를 만드는 생성자($G$)와 진짜를 구별하는 판별자($D$)가 서로 경쟁(Minimax Game)하며 서로를 속이고 감별하는 과정을 통해, 실제 데이터의 확률 분포에 도달하여 고품질의 새로운 데이터를 창조하는 생성 모델임
- **배경/필요성**: 기존의 결정론적 분석 모델의 한계를 극복하고 가짜 이미지 생성, 스타일 변환, 누락 데이터 복원 등 창조 영역의 인공지능 작업을 고품질로 자동화하기 위해 제안됨

## Ⅱ. 특징

- 명시적인 데이터 확률 분포 수식($Likelihood$) 없이도, 판별자의 감별 기준 자체를 학습하는 '적대적 훈련' 방식을 통해 극도로 선명하고 실감 나는 이미지 생성을 달성함
- 생성자와 판별자가 서로의 실력을 끌어올리는 제로섬($Zero-sum$) 게임을 수행하며, 최종적으로 생성자가 진짜와 다름없는 완벽한 가짜를 만들어 판별자가 진위를 맞출 확률이 50%가 되는 균형점에 도달함
- 학습 과정이 매우 역동적이므로 정밀한 균형 조정이 실패할 경우, 한 모델이 다른 모델을 압도하여 학습이 멈추거나 특정 샘플만 반복 생성하는 등의 취약점이 존재함

## Ⅲ. 종류 및 비교

| 판단 기준 | 오토인코더 (Autoencoder) | 생성적 적대 신경망 (GAN) | 확산 모델 (Diffusion Model) |
|:---|:---|:---|:---|
| **동작 원리** | 입력의 압축 후 재구성 | 생성자와 판별자의 경쟁 학습 | 데이터에 노이즈를 더하고 제거 |
| **샘플 품질** | 비교적 흐릿함 ($Blurry$) | 매우 선명함 | 극도로 정교하고 다양함 |
| **학습 안정성** | 매우 안정적임 | 극도로 불안정함 | 안정적임 |
| **단점** | 단순 재구성 위주 | 모드 붕괴($Mode$ $Collapse$) | 생성 속도가 느림 (반복 연산) |

> 요약: 오토인코더는 복원에, GAN은 선명한 생성에, Diffusion은 고정밀 대규모 생성에 특화됨.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 생성망 ($G$) | 잠재 공간의 무작위 노이즈 $z$를 입력받아 데이터의 공간적 분포로 사상함 |
| 판별망 ($D$) | 실제 샘플 $x$와 가짜 샘플 $G(z)$의 유사도를 0(가짜)과 1(진짜) 사이로 판정함 |
| 미니맥스 목적함수 | $D$는 최대화하고, $G$는 최소화하려 경쟁하는 게임 이론 기반 수식임 |
| 잠재 공간 ($z$) | 다양한 가짜 데이터를 만들어낼 수 있도록 무작위 다양성을 주입하는 소스임 |

```text
[ GAN 미니맥스 수식 ]
min_G max_D V(D,G) = E_x[log D(x)] + E_z[log(1 - D(G(z)))]
- D는 진짜를 진짜(D(x) -> 1)로, 가짜를 가짜(D(G(z)) -> 0)로 판별하려 함
- G는 판별자가 속아 넘어가도록(D(G(z)) -> 1) 유도함
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 노이즈 입력  | --> | 가짜 데이터생성| --> | 진짜/가짜판별| --> | 역전파/동시갱신|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **가짜 제작** — 잠재 공간에서 임의의 가우스 노이즈($z$)를 추출하여 생성자($G$)의 입력으로 전달하고, 가짜 샘플 $G(z)$를 생성함
2. **감별 수행** — 판별자($D$)는 데이터베이스에서 가져온 실제 이미지($x$)와 생성자가 만든 가짜 이미지($G(z)$)를 무작위로 받아 진짜일 확률을 계산함
3. **오차 계산** — 판별자의 진위 판정 결과와 실제 클래스(진짜/가짜)의 차이를 계산하여 각각의 손실값을 도출함
4. **교대 학습** — 판별자는 구별 능력을 높이도록 가중치를 학습하고, 생성자는 판별자를 속이도록 가중치를 학습하는 과정을 번갈아 수행하며 실력을 키움

## Ⅵ. 실무 적용 및 유의점

1. 생성자가 다양한 이미지를 만들지 못하고 판별자를 속이기 가장 쉬운 특정 형태의 이미지(예: 한 숫자만 계속 생성)만 양산하는 '모드 붕괴($Mode$ $Collapse$)' 현상을 방지하기 위해, 미니배치 차별화 기법이나 Wasserstein Loss($WGAN$)를 적용해야 함
2. GAN의 손실 함수값은 생성 품질과 직접적인 상관관계가 낮아 모니터링하기 어려우므로, 실제 학습 품질을 정량 평가하기 위해 실제와 생성 이미지의 분포 거리를 계산하는 'FID($Fr\acute{e}chet$ $Inception$ $Distance$)' 점수를 평가지표로 활용해야 함

## Ⅶ. 결론

- GAN은 두 인공지능의 불꽃 튀는 경쟁을 통해 사실적 가치를 창조해내는 적대적 공생의 정점이며, 설계자는 생성자와 판별자의 세력 균형을 정밀하게 제어하고 모드 붕괴 방지 전략을 수립하여 실무에 사용 가능한 고품질 생성 시스템을 구현해야 함
