## Ⅰ. 개요
- **정의**: 생성자와 판별자가 적대적으로 경쟁하며 실제 분포에 근사한 데이터를 합성하는 모델
- **배경/필요성**: 명시적 확률 분포 가정 없이 고해상도 합성 데이터를 생성하여 데이터 증강·익명화 수요 충족 필요
- **비유**: 위조지폐범(생성자)과 감별사(판별자)가 서로 실력을 높이며 경쟁하는 구도

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 미니맥스 게임 원리 이해 | min_G max_D V(D,G) 수식 의미 | 모드 붕괴를 단순 과적합으로 혼동 금지 |
| 학습 불안정성 원인 분석 | D·G 균형 파괴 시 기울기 소실 | WGAN의 Lipschitz 제약 언급 필요 |

> 요약: GAN은 생성자-판별자 적대적 경쟁을 통해 명시적 분포 없이 데이터를 합성하는 생성 모델임

## Ⅱ. 구성요소
```text
+----------------+       +----------------+       +----------------+
| Random Noise z |       | Generator G    |       | Discriminator D|
| (Latent Space) | ----> | (Fake Data)    | ----> | (Real/Fake?)   |
+----------------+       +-------+--------+       +-------+--------+
                                 |                         |
                                 +--- Adversarial Loss <---+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 생성자(Generator) | 잠재 벡터 z를 입력받아 실제와 유사한 가짜 데이터 출력 | 위조지폐범 |
| 판별자(Discriminator) | 입력 데이터가 실제인지 생성된 가짜인지 확률값으로 분류 | 감별사 |
| 적대적 손실(Adversarial Loss) | G는 D를 속이고, D는 정확히 분류하도록 반대 방향 최적화 | 경쟁 규칙 |

> 요약: GAN은 잠재 벡터로부터 가짜를 만드는 G, 진위를 판별하는 D, 양자를 묶는 적대적 손실로 구성됨

## Ⅲ. 절차
```text
+----------------+       +----------------+       +----------------+       +----------------+
| Sample z       |       | D Evaluate     |       | D Weight Update|       | G Weight Update|
| G generates    | ----> | Real vs Fake   | ----> | max log D(x)   | ----> | min log(1-D)   |
+----------------+       +----------------+       +----------------+       +----------------+
```

1. **가짜 생성** — G가 잠재 벡터 z ~ N(0,1)을 입력받아 가짜 샘플 G(z) 출력
2. **판별 평가** — D가 실제 데이터 x와 가짜 G(z)를 각각 입력받아 진위 확률 산출
3. **판별자 학습** — D의 파라미터를 갱신하여 실제->1, 가짜->0 분류 정확도 극대화
4. **생성자 학습** — G의 파라미터를 갱신하여 D(G(z))->1이 되도록 속임 능력 극대화

> 요약: G-D를 번갈아 갱신하며, D는 진위 분류 극대화, G는 D의 오판 극대화를 목표로 학습함

## Ⅳ. 문제점
- 모드 붕괴(Mode Collapse): G가 D를 속이기 쉬운 소수 패턴만 반복 생성하여 다양성 상실
- 학습 불안정성: D가 너무 강하면 G에 유의미한 기울기가 전달되지 않아 학습 정체
- 평가 기준 모호: 생성 품질을 정량화할 표준 지표가 부재하여 모델 비교가 주관적

> 요약: 모드 붕괴·학습 불균형·정량 평가 부재가 GAN의 핵심 한계임

## Ⅴ. 개선방안
1. 단기: 미니배치 판별(Mini-batch Discrimination) 및 스펙트럼 정규화로 다양성 확보
2. 중기: Wasserstein 거리 기반 WGAN 적용, Gradient Penalty로 학습 안정성 확보
3. 장기: FID(Frechet Inception Distance)·IS(Inception Score) 등 객관적 평가 체계 정립

- 모드 붕괴: 생성자 다양성 부족 -> 미니배치 판별 + 레이블 스무딩 (지표: FID 분산)
- 학습 불안정성: D-G 균형 붕괴 -> WGAN-GP 도입 (지표: 손실 수렴 곡선 안정도)
- 평가 모호: 주관적 비교 -> FID < 10 등 정량 임계값 설정 (지표: FID/IS 수치)

> 요약: 단기 정규화, 중기 WGAN, 장기 평가 지표 표준화로 GAN의 3대 한계를 대응함

## Ⅵ. 전망
- 향후 발전 방향: 고해상도 이미지 생성은 Diffusion 모델로 대체 추세이나, 실시간 추론(1-step GAN), 음성·영상 합성, 데이터 익명화 영역에서 GAN 고유 강점 지속
- 기술사적 판단: 적대적 학습 프레임워크 자체는 AI 보안(Adversarial Attack/Defense)으로 확장 중이며, Diffusion과의 하이브리드(Consistency GAN 등) 연구 활발
- 기술사 제언: 생성 AI 프로젝트 설계 시 품질(FID)·속도(추론 지연)·다양성(모드 커버리지) 트레이드오프를 정량 기준으로 GAN/Diffusion 선택 근거를 수립할 것
