## 미리 알고가기

- 생성 모델: 학습 데이터의 분포를 배워 유사한 새 데이터를 생성하는 모델임
- 잠재 벡터 $z$: 생성자가 다양한 샘플을 만들도록 입력되는 무작위 저차원 벡터임
- 생성자 $G$: 잠재 벡터를 실제 데이터와 유사한 가짜 샘플로 변환하는 신경망임
- 판별자 $D$: 입력 샘플이 실제 데이터인지 생성 데이터인지 확률로 판단하는 신경망임
- 미니맥스 게임: 한 모델의 이득이 다른 모델의 손실이 되는 경쟁적 최적화 구조임
- 모드 붕괴: 생성자가 데이터 다양성을 잃고 일부 형태의 샘플만 반복 생성하는 현상임

## 작성 근거(검토용)

- 개요는 생성자·판별자 경쟁과 데이터 분포 학습을 함께 제시해 GAN의 본질을 고정함
- 특징은 우도 불필요, 교대 학습, 잠재 조작, 불안정성을 서로 다른 판단점으로 둠
- 비교표는 VAE와 Diffusion 대비 GAN의 생성 원리·학습 목적 함수·생성 절차를 드러냄
- 구성요소는 $G$, $D$, $z$, 손실, 평가 지표까지 포함해 실무 검증으로 연결함
- 절차는 가짜 생성, 판별, 두 모델 갱신의 교대 흐름을 단순화함
- 품질 평가와 모드 붕괴는 GAN 적용의 핵심 검증 조건임

## Ⅰ. 개요

- **정의/개념**: GAN은 생성자와 판별자가 경쟁 학습을 수행해 실제 데이터 분포와 유사한 샘플을 생성하는 적대적 생성 모델임
- **배경/필요성**: 이미지 생성·스타일 변환·결측 복원을 수행하기 위해 실제와 유사한 데이터 분포를 학습하는 생성 모델이 필요함

## Ⅱ. 특징

- 명시적 우도 계산 없이 판별자의 피드백으로 생성 분포를 학습함
- 생성자와 판별자를 번갈아 갱신하므로 두 모델의 학습 균형이 품질을 좌우함
- 잠재 벡터를 조작해 샘플 다양성, 속성 변화, 보간 결과를 탐색함
- 학습이 불안정해 모드 붕괴, 발산, 판별자 우세 같은 실패가 자주 발생함

## Ⅲ. 종류 및 비교

| 판단 기준 | VAE | GAN | Diffusion Model |
|:---|:---|:---|:---|
| 생성 원리 | 잠재 확률분포에서 복원 | 생성자·판별자 경쟁 | 노이즈 제거 과정을 반복 |
| 생성 결과 특성 | 분포를 넓게 학습하지만 복원이 흐릴 수 있음 | 선명하지만 모드 붕괴로 다양성이 줄 수 있음 | 서로 다른 초기 노이즈에서 샘플을 반복 복원함 |
| 학습 목적 함수 | 복원 오차와 KL 발산을 함께 최소화 | 생성자와 판별자의 최소·최대 목적을 교대로 최적화 | 시간 단계별 노이즈 예측 오차를 최소화 |
| 생성 절차 | 잠재 벡터를 디코더에서 한 번 복원 | 잠재 벡터를 생성자에서 한 번 변환 | 초기 노이즈를 여러 단계에 걸쳐 제거 |
| 대표 적용 사례 | 잠재 공간 분석·이상 탐지 | 이미지 합성·스타일 변환 | 고품질 이미지·영상 생성 |

> 요약: GAN은 생성자의 한 번의 순전파로 선명한 이미지를 생성하지만 생성자와 판별자의 학습 균형이 무너지면 모드 붕괴나 발산이 발생함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 잠재 분포 $p_z$ | 생성자의 입력 원천이며 샘플 다양성을 결정함 |
| 생성자 $G$ | $z$를 가짜 샘플 $G(z)$로 바꾸어 판별자를 속이도록 학습함 |
| 판별자 $D$ | 실제 샘플 $x$와 가짜 샘플 $G(z)$를 구별하는 기준을 학습함 |
| 적대 손실 | $D$는 진위를 맞히고 $G$는 $D$를 속이도록 반대 방향 목표를 만듦 |
| 평가 지표 | FID, 다양성, 인간 평가로 손실값만으로 부족한 생성 품질을 확인함 |

```text
+----------+      +-----------+      +-----------+
| noise z  | ---> | generator | ---> | fake data |
+----------+      +-----------+      +-----------+
                                      |
                                      v
+-----------+      +---------------+      +-----------+
| real data | ---> | discriminator | ---> | real/fake |
+-----------+      +---------------+      +-----------+
```

> 요약: GAN은 생성자가 만든 샘플과 실제 샘플을 판별자가 구분하는 경쟁 구조로 학습함.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+      +----------+      +----------+      +----------+
| sample z | ---> | make fake| ---> | judge    | ---> | update   |
+----------+      +----------+      +----------+      +----------+
```

1. **가짜 생성**: 잠재 벡터 $z$를 생성자에 넣어 가짜 샘플 $G(z)$를 만듦
2. **진위 판별**: 판별자가 실제 샘플 $x$와 가짜 샘플을 구별함
3. **판별자 갱신**: $D(x)$는 1에, $D(G(z))$는 0에 가깝게 학습함
4. **생성자 갱신**: $G$는 $D(G(z))$가 1에 가깝게 나오도록 가중치를 조정함

> 요약: 생성 품질은 생성자와 판별자의 교대 갱신 균형이 무너지지 않을 때 개선됨.

## Ⅵ. 실무 사례

1. 합성 이미지 생성은 학습 데이터 복제로 개인정보·저작권을 침해할 수 있으므로 중복 탐지와 필터링을 적용하고 FID·최근접 표본 거리로 검증함
2. 모드 붕괴가 발생하면 WGAN-GP·스펙트럴 정규화·데이터 증강을 적용하고 클래스별 생성 비율과 표본 간 거리로 다양성 회복 여부를 확인함

## Ⅶ. 결론

- GAN은 적대적 학습으로 선명한 샘플을 만드는 생성 모델이며, 생성 품질보다 먼저 학습 균형과 다양성 통제가 필요함
