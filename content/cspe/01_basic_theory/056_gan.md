## 미리 알고가기

- 생성자: 잠재 벡터에서 가짜 데이터를 만들어내는 신경망임
- 판별자: 입력 데이터가 실제인지 생성된 것인지 구분하는 신경망임
- 잠재 벡터: 생성자가 데이터를 만들 때 사용하는 무작위 입력임
- 미니맥스 게임: 생성자와 판별자가 서로 반대 목표를 최적화하는 구조임
- 모드 붕괴: 생성자가 다양한 데이터를 만들지 못하고 일부 패턴만 반복하는 문제임

## Ⅰ. 개요

- **정의**: GAN은 생성자와 판별자를 경쟁적으로 학습시켜 생성자가 실제 데이터 분포와 구분하기 어려운 샘플을 만들도록 하는 생성 모델 구조임
- **배경/필요성**: 명시적인 확률분포를 계산하기 어려운 이미지·음성·시뮬레이션 데이터에서도 실제와 유사한 합성 데이터를 생성해 증강, 익명화, 콘텐츠 생성에 활용할 필요가 있음
- **비유**: 위조품 제작자와 감별사가 서로 경쟁하면서 제작자는 더 진짜 같은 물건을 만들고 감별사는 더 정확한 판별 기준을 배우는 구조와 같음

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 적대적 학습 구조 이해 | 생성자, 판별자, 미니맥스 목적 | 단순 오토인코더와 혼동 |
| 학습 불안정성 분석 | 모드 붕괴, 균형 실패, WGAN | 모드 붕괴를 과적합으로 단순화 |

> 요약: GAN은 생성자와 판별자의 경쟁을 통해 실제 데이터 분포에 가까운 합성 데이터를 만들도록 학습하는 모델임.

## Ⅱ. 특징/비교

| 판단 기준 | VAE·Diffusion | GAN |
|:---|:---|:---|
| 생성 원리 | VAE는 잠재 분포 재구성, Diffusion은 점진적 노이즈 제거를 사용함 | 판별자를 속이는 적대적 학습으로 샘플 품질을 높임 |
| 샘플 품질 | VAE는 부드럽지만 흐릿할 수 있고 Diffusion은 품질이 높지만 추론 비용이 큼 | 선명한 샘플 생성에 강하지만 학습 안정성이 낮음 |
| 확률 해석 | VAE는 잠재 분포 해석이 있고 Diffusion은 생성 경로가 명확함 | 명시적 likelihood 계산이 어렵고 평가가 까다로움 |
| 선택 조건 | 안정적 학습이나 제어 가능한 생성이 중요할 때 대안이 적합함 | 빠른 생성과 고해상도 선명도가 중요할 때 적합함 |

> 요약: GAN은 샘플 선명도와 생성 속도에 강점이 있지만 학습 안정성과 평가 가능성을 별도로 관리해야 함.

- **입력 조건**: 실제 데이터 분포를 대표하는 학습 샘플과 충분한 다양성이 필요함
- **평가 기준**: 샘플 품질, 다양성, 안전성, 다운스트림 활용성을 함께 확인함
- **선택 판단**: 빠른 생성과 선명한 합성 결과가 중요할 때 우선 검토함

## Ⅲ. 구성요소

```text
+------------+      +------------+      +------------+
| 잠재 벡터 z | ---> | 생성자 G    | ---> | 생성 데이터 |
+------------+      +------------+      +------------+
                                            |
                                            v
+------------+      +------------+      +------------+
| 실제 데이터 | ---> | 판별자 D    | ---> | 진짜 확률   |
+------------+      +------------+      +------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 잠재 벡터 | 생성 데이터의 다양성을 만드는 무작위 입력 공간임 | 제작 재료 |
| 생성자 | 잠재 벡터를 실제와 유사한 데이터로 변환하는 신경망임 | 제작자 |
| 실제 데이터 | 판별자가 기준으로 삼는 학습 데이터 분포임 | 진품 표본 |
| 판별자 | 입력이 실제인지 생성인지 확률로 판단하는 신경망임 | 감별사 |
| 적대 손실 | 생성자와 판별자가 서로 반대 목표로 학습하게 하는 목적 함수임 | 경쟁 규칙 |

> 요약: GAN은 생성자와 판별자가 같은 데이터 분포를 두고 반대 목표를 학습하는 이중 네트워크 구조임.

## Ⅳ. 절차

```text
+------------+      +------------+      +------------+      +------------+
| 가짜 생성   | ---> | 판별자 학습 | ---> | 생성자 학습 | ---> | 품질 평가   |
+------------+      +------------+      +------------+      +------------+
```

1. **가짜 생성**: 잠재 벡터를 생성자에 입력해 합성 데이터를 만듦
2. **판별자 학습**: 실제 데이터와 생성 데이터를 구분하도록 판별자 가중치를 갱신함
3. **생성자 학습**: 판별자가 생성 데이터를 실제로 판단하도록 생성자 가중치를 갱신함
4. **품질 평가**: 샘플 다양성, FID, 시각 검수, 다운스트림 성능으로 생성 품질을 확인함

> 요약: GAN 학습은 판별자와 생성자를 번갈아 갱신하며 실제와 구분 어려운 샘플을 만들도록 균형을 맞추는 흐름임.

- **산출물**: 생성 샘플, 판별자 점수, 품질·다양성 평가 결과임
- **검증 기준**: 일부 모드만 반복하지 않고 실제 분포의 다양성을 반영해야 함
- **운영 기록**: 잠재 공간, 학습률, 판별자 갱신 횟수, 데이터 필터 기준을 남겨야 함

## Ⅴ. 문제점

- **P1 모드 붕괴**: 생성자가 데이터 분포의 일부 패턴만 반복하면 샘플은 그럴듯해도 다양성이 크게 떨어짐
- **P2 학습 불안정**: 판별자와 생성자의 균형이 깨지면 기울기 소실, 진동, 발산으로 수렴이 어려워짐
- **P3 평가·통제 어려움**: 생성 결과의 품질, 다양성, 편향, 유해성을 단일 지표로 판단하기 어렵고 원하는 속성 제어도 제한됨

> 요약: GAN의 운영 위험은 생성 품질이 좋아 보이더라도 다양성, 안정성, 통제 가능성이 함께 확보되지 않을 수 있다는 점임.

## Ⅵ. 개선방안

- **P1 대응**: mini-batch discrimination, feature matching, unrolled GAN, 데이터 다양성 보강을 적용함 (확인: 클래스·모드별 샘플 분포)
- **P2 대응**: WGAN-GP, spectral normalization, 학습률 균형, 판별자 갱신 횟수 조정을 적용함 (확인: 손실 진동과 FID 추세)
- **P3 대응**: FID, IS, 사람 검수, 조건부 GAN, 안전 필터를 함께 사용함 (확인: 품질 지표와 금지 속성 탐지 결과)

> 요약: GAN 개선은 생성자·판별자 균형을 안정화하고 샘플 다양성과 안전성을 별도 지표로 검증하는 것임.

- **우선순위**: 모드 붕괴와 학습 손실 진동 여부를 먼저 점검함
- **확인 지표**: FID, IS, 클래스별 샘플 수, 사람 검수 결과를 함께 사용함
- **재평가 조건**: 데이터 분포나 생성 목적이 바뀌면 품질·안전 기준을 다시 설정함

## Ⅶ. 전망

- **발전 방향**: GAN은 Diffusion 모델에 일부 영역을 내줬지만, 빠른 샘플 생성, 도메인 변환, 데이터 증강, 초해상도 분야에서 계속 활용될 수 있음
- **기술사적 판단**: 기술사는 생성 품질만 보지 않고 학습 안정성, 데이터 편향, 생성 결과의 검증·통제 체계를 함께 판단해야 함
- **기술사 제언**: 향후 GAN은 조건부 생성, 3D 생성, 시뮬레이션 데이터 합성, 프라이버시 보존 데이터 생성과 결합해 특정 도메인 맞춤형 생성 모델로 발전할 것임
