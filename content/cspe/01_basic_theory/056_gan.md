# GAN 생성적 적대 신경망 (Generative Adversarial Network)

## 1. 개요

- **정의/개념**: GAN은 생성자(Generator)와 판별자(Discriminator)가 적대적으로 학습하며 실제 데이터와 유사한 샘플을 생성하는 생성 모델이다.
- **배경/필요성**: 이미지·음성·데이터 증강처럼 실제와 유사한 샘플 생성이 필요한 문제에서는 확률분포를 직접 명시하기보다 학습을 통해 생성 분포를 맞추는 방식이 유용하다.

GAN의 핵심은 생성자가 속이고 판별자가 구분하는 경쟁 구조가 데이터 분포 근사로 이어진다는 점이다.

## 2. 특징 및 비교

| 구분 | GAN | VAE | Diffusion |
|---|---|---|---|
| 생성 방식 | 적대적 학습 | latent 확률 모델 | 노이즈 제거 반복 |
| 장점 | 선명한 샘플 | 안정적 latent | 품질 우수 |
| 약점 | 학습 불안정 | blur 가능성 | 추론 비용 큼 |
| 주요 지표 | FID, IS | ELBO, reconstruction | FID, sampling time |

선택 기준은 생성 품질, 학습 안정성, 다양성, 추론 속도, 데이터 규모이다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| Generator | noise에서 가짜 샘플 생성 | 분포 근사 |
| Discriminator | 진짜·가짜 판별 | 학습 신호 제공 |
| Latent Noise | 생성 시작 입력 | 다양성 |
| Adversarial Loss | 두 모델의 경쟁 목적 | 균형 필요 |
| Training Loop | G/D 교대 학습 | 안정성 핵심 |

```text
Noise -> Generator -> Fake Sample -> Discriminator -> 진짜/가짜 판별
Real Sample -----------------------> Discriminator
```

생성자와 판별자의 균형이 깨지면 생성 품질이나 다양성이 바로 무너지므로 학습 안정성이 핵심 문제로 이어진다.

## 4. 문제점 및 개선방안

1. **Mode Collapse**
   - 생성자가 일부 패턴만 반복 생성해 다양성이 부족해질 수 있다.
   - **개선방안**: WGAN, minibatch discrimination, diversity regularization을 적용한다.

2. **학습 불안정**
   - 판별자가 너무 강하거나 약하면 gradient가 유용하지 않다.
   - **개선방안**: learning rate 균형, gradient penalty, spectral normalization을 사용한다.

3. **평가 어려움**
   - 생성 품질은 정확도 하나로 평가하기 어렵다.
   - **개선방안**: FID, IS, human evaluation, downstream 성능을 함께 본다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| 이미지 생성 | 도메인 이미지를 학습해 합성 샘플 생성 | FID, 다양성 |
| 데이터 증강 | 부족한 클래스의 유사 데이터를 생성 | 모델 성능 개선 |
| 도메인 변환 | CycleGAN 등으로 스타일·도메인 변환 | 변환 품질, 보존성 |

## 6. 결론

GAN은 생성자와 판별자의 경쟁을 통해 데이터 분포를 근사하는 생성 모델이다. 생성 품질만이 아니라 학습 안정성, mode collapse, 다양성, 평가 지표를 함께 관리해야 실무 적용 판단이 가능하다.
