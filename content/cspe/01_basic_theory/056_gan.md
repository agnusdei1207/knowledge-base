# 056. GAN 생성적 적대 신경망 (Generative Adversarial Network) [출제: 122회]

## 1. 개요

- **정의/개념**: 실제 데이터와 유사한 데이터를 생성하는 생성자(Generator)와 데이터의 진위 여부를 판별하는 판별자(Discriminator)가 서로 경쟁(Adversarial)하며 학습하여 정교한 가짜 데이터를 만들어내는 신경망임
- **배경/필요성**: 데이터 부족 문제를 해결하기 위한 합성 데이터 생성, 이미지 고해상도 복원, 스타일 변환 등 실제와 구분하기 힘든 고품질의 데이터 생성이 필요한 분야에서 기존 통계적 방식의 한계를 극복하기 위해 제안됨

## 2. 특징 및 비교

| 판단 기준 | GAN (Generative Adversarial Network) | VAE (Variational Autoencoder) | Diffusion Model |
|:---|:---|:---|:---|
| **학습 방식** | 적대적 경쟁 학습 | 확률적 인코딩/디코딩 (ELBO 최적화) | 반복적 노이즈 제거 (Reverse Process) |
| **생성 품질** | 매우 선명하나 모드 붕괴 위험 | 상대적으로 흐릿함 (Blurry) | 가장 우수하고 다양함 |
| **학습 안정성** | 낮음 (G-D 균형 필수) | 높음 | 높음 |
| **추론 속도** | 빠름 (한 번의 연산) | 빠름 | 느림 (반복 연산 필요) |

> 요약: GAN은 학습이 까다롭지만 선명한 결과를 빠르게 생성할 수 있어 실시간 합성 분야에 강점이 있음

## 3. 구성요소/구조

- **구성요소**:
  - **Generator (G)**: 무작위 노이즈($z$)로부터 가짜 데이터($G(z)$)를 생성하여 판별자를 속이려 함
  - **Discriminator (D)**: 입력받은 데이터가 실제 데이터($x$)인지 가짜($G(z)$)인지 0~1 사이의 확률로 판별함
  - **Latent Space**: 생성의 원천이 되는 잠재적인 변수들이 존재하는 공간임
  - **Minimax Game**: $D$는 판별 정확도를 극대화하고, $G$는 $D$가 틀릴 확률을 극대화하는 목적 함수를 가짐

- **구조도**:
```text
[Latent Noise z] -> [Generator G] -> [Fake Data G(z)] ---+
                                                       |
                                                       v
[Real Data x] -----------------------------------> [Discriminator D] -> [Real(1) or Fake(0)]
                                                       |
                                        +--------------+--------------+
                                        |                             |
                          (Update G to fool D)          (Update D to catch G)
```

## 4. 문제점 및 개선방안

1. **[모드 붕괴 (Mode Collapse)]**: 생성자가 다양한 데이터를 만들지 못하고 특정 성공적인 패턴만 반복해서 생성하는 현상임
   - **개선방안**: WGAN(Wasserstein loss), Unrolled GAN, Minibatch Discrimination 등을 적용함 (확인: FID score)
2. **[학습 불안정성]**: $G$와 $D$ 중 어느 한쪽이 너무 강력해지면 학습 신호가 사라져 수렴하지 못함
   - **개선방안**: Spectral Normalization, Gradient Penalty를 적용하거나 학습률(LR)을 조절함 (확인: Loss curve 평형)
3. **[평가 지표의 부재]**: 생성 데이터의 품질을 수치화하기 어려워 주관적 판단에 의존함
   - **개선방안**: Inception Score(IS), Fréchet Inception Distance(FID) 등 객관적 평가지표를 활용함 (확인: FID 하락치)

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| **이미지 고해상도 복원** | SRGAN 등을 활용하여 저해상도 CCTV/의료 영상을 고해상도로 변환 | PSNR, SSIM (Structural Similarity) |
| **도메인 변환 (Image-to-Image)** | CycleGAN을 사용하여 낮 이미지를 밤으로, 스케치를 채색 이미지로 변환 | User Study Score, 도메인 적합도 |
| **데이터 증강 (Augmentation)** | 불량 제품 데이터가 부족한 스마트 팩토리에서 가상의 불량 이미지 생성 | 분류 모델의 Recall/mAP 향상도 |

> 요약: 실무에서는 생성 결과의 '선명도'와 '다양성' 사이의 트레이드오프를 조절하며 특정 태스크에 맞게 튜닝함

## 6. 결론

GAN은 인공지능이 수동적 분석을 넘어 능동적 창작의 영역으로 진입하게 한 혁신적인 모델임. 비록 최근 Diffusion 모델에 비해 학습 안정성이나 생성 다양성 측면에서 도전을 받고 있으나, 단 한 번의 연산으로 고품질 데이터를 얻을 수 있는 효율성 덕분에 실시간 서비스나 임베디드 환경에서는 여전히 핵심적인 생성 기술로 자리 잡고 있음.
