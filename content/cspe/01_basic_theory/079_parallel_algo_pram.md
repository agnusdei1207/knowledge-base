## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 복수의 프로세서가 공용 메모리에 접근하여 작업을 동시에 수행하는 추상적 병렬 계산 모델로, 병렬화 한계를 분석하는 기반임. |
| 배경/필요성 | 무어의 법칙 한계에 따른 멀티코어 시대로의 전환 및 대규모 데이터 분산 처리를 위한 알고리즘 설계 필요성. |
| 출제 의도 | 메모리 동시 접근 모델(EREW, CREW, CRCW)의 차이 및 병렬 알고리즘의 복잡도 개선율 평가. |

## Ⅱ. 구성요소
```text
+-----------+    +-----------+    +-----------+
| Shared Mem| -> | Mult Proc | -> | Mem Access|
+-----------+    +-----------+    +-----------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 공용 메모리(Shared Memory)| 모든 프로세서가 일관되게 접근 가능한 중앙 집중식 논리 메모리 | 칠판 |
| 다중 프로세서(Processor) | 동일한 클럭 사이클에 동기화되어 독립 연산을 수행하는 유닛 | 학생들 |
| 접근 제어 규칙 | 읽기/쓰기 동시 접근 허용 여부 규정(EREW, CREW, CRCW) | 발언 규칙 |

> 요약: 다중 프로세서가 공용 메모리 제어 규칙 하에 데이터를 나누어 병렬 연산을 동기화하여 수행함.

## Ⅲ. 절차
```text
+----------+   +----------+   +----------+   +----------+
| Split Dat|-> | Concur Op|-> | Sync Exec|-> | Merge Res|
+----------+   +----------+   +----------+   +----------+
```
1. 데이터 분할: 전체 연산 데이터를 개별 프로세서 단위로 나눔.
2. 동시 연산: 접근 제어 규칙(CRCW 등)에 따라 메모리에서 데이터를 읽고 씀.
3. 동기화 실행: 모든 프로세서가 한 단계(Step)를 마칠 때까지 클럭 단위 동기화함.
4. 결과 병합: 분산 처리된 임시 결과들을 공용 메모리에 다시 취합해 완성함.

> 요약: 데이터를 분할하여 프로세서에 할당하고 동기화된 메모리 접근과 병합을 거쳐 결과를 도출함.

## Ⅳ. 문제점
- 다중 프로세서 동시 접근 시 메모리 충돌 제어와 동기화(Synchronization) 오버헤드로 병렬화 이득 상쇄
- 순차적 코드 비율에 의해 전체 성능 향상 폭이 제한되는 암달의 법칙(Amdahl's Law) 한계 직면
- 추상적인 PRAM 모델은 네트워크 지연, 캐시 계층 구조 등 실제 물리적 특성을 반영하지 못함

## Ⅴ. 개선방안
- [단기] EREW(충돌 없는 읽기/쓰기) 모델 기반의 알고리즘 설계를 통해 메모리 병목 현상 최소화 유도
- [중기] 공유 메모리와 로컬 분산 메모리 환경을 융합한 하이브리드 아키텍처(MPI+OpenMP) 적용 검토
- [장기] GPU 중심의 스트림 프로세싱 등 비대칭 하드웨어 구조에 최적화된 자동 병렬화 컴파일러 연구 고도화

## Ⅵ. 전망
- 빅데이터 플랫폼(Spark 등) 및 인공지능(GPU 병렬화) 알고리즘 최적화를 위한 이론적 토대로 역할함.
