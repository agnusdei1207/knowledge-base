# 079. 병렬 알고리즘 — PRAM 모델 (Parallel Algorithm PRAM)

## Ⅰ. 개요

- **정의/개념**: 병렬 알고리즘은 다수의 프로세서가 데이터를 나누어 동시에 연산함으로써 전체 처리 시간을 단축하는 기법이며, PRAM(Parallel Random Access Machine)은 공유 메모리를 통해 프로세서들이 통신하는 이론적인 병렬 계산 모델임
- **배경/필요성**: 단일 코어의 클럭 속도 향상이 한계에 다다름에 따라, 빅데이터나 고성능 연산(HPC) 환경에서 계산 복잡도를 낮추기 위해 작업을 여러 단위로 쪼개어 병렬로 처리하는 효율적인 설계와 분석 모델이 필수적임

## Ⅱ. 특징 및 비교 (PRAM 메모리 접근 모델)

| 모델명 | 읽기 (Read) | 쓰기 (Write) | 특징 및 복잡도 |
|:---|:---|:---|:---|
| **EREW** | 배타적 (Exclusive) | 배타적 (Exclusive) | 가장 엄격한 모델, 구현이 까다로우나 충돌 없음 |
| **CREW** | 동시적 (Concurrent) | 배타적 (Exclusive) | 읽기는 공유하되 쓰기는 순차적, 가장 보편적임 |
| **ERCW** | 배타적 (Exclusive) | 동시적 (Concurrent) | 이론적으로는 가능하나 실무적으로는 거의 미사용 |
| **CRCW** | 동시적 (Concurrent) | 동시적 (Concurrent) | 가장 강력한 모델, 쓰기 충돌 해결 정책이 필수임 |

> 요약: PRAM은 실제 하드웨어의 통신 지연이나 캐시 문제를 배제하고 알고리즘의 순수한 병렬성을 분석하기 위한 도구임

## Ⅲ. 구성요소/구조

- **구성요소**:
  - **Shared Memory**: 모든 프로세서가 동일한 주소 공간을 공유하며 통신하는 매개체임
  - **Processors**: 각자 고유한 ID를 가지고 병렬적으로 명령어를 실행하는 연산 장치임
  - **Speedup (가속도)**: 단일 프로세서 시간 대비 병렬 처리를 통해 단축된 시간 비율임 ($S = T_1 / T_p$)
  - **Efficiency (효율성)**: 프로세서 한 개당 기여하는 성능 향상 정도임 ($E = S / p$)
  - **Cost (비용)**: 병렬 실행 시간과 프로세서 수의 곱으로, 순차 알고리즘과 비교함 ($C = T_p \times p$)

- **병렬 처리 아키텍처 흐름도**:
```text
[Input Data] -> [Work Decomposition] -> [Parallel Execution (P1, P2, ..., Pn)] -> [Result Merging]
      |                 |                             |                            |
  Task Queue      Load Balancing              Shared Memory Access            Final Output
```

## Ⅳ. 문제점 및 개선방안

1. **[메모리 경합 및 쓰기 충돌 (Conflict)]**: 여러 프로세서가 동시에 동일 메모리 주소에 기록하려 할 때 데이터 무결성 문제 발생
   - **개선방안**: CRCW 모델에서 Common(값이 같을 때만 허용), Arbitrary(임의 선택), Priority(우선순위) 등의 정책을 적용함 (확인: 데이터 일관성)
2. **[암달의 법칙 (Amdahl's Law)]**: 알고리즘 내에 병렬화할 수 없는 순차적인 부분이 존재할 경우, 프로세서 수를 늘려도 전체 성능 향상이 제한됨
   - **개선방안**: 순차 영역을 최소화하도록 알고리즘을 재설계하거나, 데이터 크기를 키워 병렬 효율을 높이는 구스타프슨의 법칙(Gustafson's Law) 관점에서 접근함 (확인: 병렬화 오버헤드)
3. **[이론과 실제의 괴리]**: PRAM 모델은 네트워크 지연이나 메모리 대역폭 한계를 고려하지 않아 실제 시스템에서의 성능과 차이가 남
   - **개선방안**: 실제 구현 시에는 통신 비용을 고려한 LogP 모델이나 BSP(Bulk Synchronous Parallel) 모델을 병행 참조함 (확인: 실제 Speedup)

## Ⅴ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| **GPU 가속 (CUDA/OpenCL)** | 수만 개의 스레드가 공유 메모리를 통해 행렬 연산을 병렬로 수행 (SIMT 구조) | TFLOPS (연산 성능), 대역폭 효율 |
| **분산 데이터 처리 (Spark)** | 데이터를 파티션 단위로 나누어 클러스터 노드에서 병렬 맵/리듀스 수행 | 처리 지연 시간, 확장성 (Scalability) |
| **멀티코어 정렬** | 병합 정렬이나 퀵 정렬의 분할 단계를 개별 코어에 할당하여 처리 | 병렬 효율성, 코어 점유율 |

> 요약: 현대의 고성능 컴퓨팅은 PRAM의 이론적 배경 위에 하드웨어의 물리적 제약을 극복하는 방식으로 설계됨

## Ⅵ. 결론

병렬 알고리즘은 전산학의 패러다임을 '순차적 사고'에서 '동시적 사고'로 전환시킨 핵심 기술임. PRAM 모델은 복잡한 하드웨어 변수 속에서도 알고리즘의 본질적인 한계를 짚어내게 하는 중요한 분석 틀을 제공함. 인공지능 학습이나 기상 예측과 같이 초거대 연산이 요구되는 미래 산업에서, 자원을 낭비하지 않고 병렬 효율을 극대화하는 알고리즘 설계 능력은 기술 경쟁력의 핵심이 될 것임.
