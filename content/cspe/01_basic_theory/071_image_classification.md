# 📖 【암기용】 개념 완전 이해

> 목적: 이 개념을 처음 보는 사람도 완벽히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 이미지 분류(Image Classification)는 **컴퓨터 비전** 과제 중 가장 기본형으로, 입력 이미지 전체가 어떤 범주(개, 자동차 등)에 속하는지 하나의 클래스로 판별하는 **CNN**(Convolutional Neural Network) 기반 기술이다.
- **왜 필요한가**: 픽셀을 단순히 나열해서는 "이것이 개다"라는 추상적 개념을 얻을 수 없다. 선·모서리 같은 저수준 특징을 계층적으로 종합해 고수준 개념(귀, 꼬리, 개)으로 끌어올릴 망이 필요하다.
- **핵심 직관**: 망을 단순히 깊게 쌓으면 신호가 옅어지므로(기울기 소실) 지름길을 뚫어주고(ResNet), 깊이·너비·해상도를 최적의 비율로 동시에 늘려 효율을 극대화(EfficientNet)한다.

## 핵심 용어 정리 (내부에 등장하는 것들)

| 용어 | 의미 | 비유 |
|:---|:---|:---|
| 컴퓨터 비전(Computer Vision) | 이미지·영상에서 의미 있는 정보를 뽑아내는 AI 분야 — 이미지 분류가 속하는 **상위 범주** | 기계에게 시각을 부여하는 학문 |
| CNN(Convolutional Neural Network) | 합성곱(Convolution) 연산으로 이미지의 공간적 특징을 추출하는 신경망 구조 — 이미지 분류의 **뼈대** | 사진 위에 작은 창을 움직이며 부분부분을 훑어보는 방식 |
| 합성곱(Convolution)·필터(Kernel) | 작은 크기의 가중치 행렬(필터)을 이미지 위에서 이동시키며 부분 영역과 곱-합 연산을 하는 것 | 스텐실(도장)을 이미지 곳곳에 대고 무늬를 찍어내는 것 |
| 특징 맵(Feature Map) | 합성곱 연산 결과로 나온, 어디에 어떤 패턴(선·모서리·질감)이 있는지 나타낸 값의 배열 | 원본 사진 위에 특징을 강조해 그린 투명 오버레이 |
| 기울기 소실(Vanishing Gradient) | 역전파 시 층을 거칠 때마다 기울기(gradient)가 1보다 작은 값끼리 반복 곱해져 0에 가까워지는 현상 | 긴 복도 끝에서 속삭인 말이 전달될수록 점점 안 들리는 것 |
| Skip Connection(잔차 연결) | 입력 $x$를 몇 개 층을 건너뛰어 출력에 그대로 더해주는 지름길 ($F(x)+x$) | 계단이 무너져도 비상 엘리베이터로 바로 위층에 도달하는 통로 |
| Residual Block(잔차 블록) | Skip Connection을 포함한 ResNet의 기본 단위 — 층은 원본과의 "차이" $F(x)$만 학습 | 원본은 그대로 두고 "고칠 부분"만 메모해 더하는 방식 |
| Compound Scaling(복합 스케일링) | 깊이(Depth)·너비(Width)·해상도(Resolution) 세 축을 정해진 비율 상수로 동시에 늘리는 EfficientNet의 확장 방식 | 건물을 지을 때 층수·폭·자재 두께를 정해진 황금비로 함께 키움 |
| 전이 학습(Transfer Learning) | 대규모 데이터(ImageNet 등)로 사전학습된 가중치를 가져와, 데이터가 적은 다른 도메인에 재활용하는 기법 | 한 분야 숙련자가 배운 감각을 다른 유사 분야에 그대로 가져다 씀 |

## 깊이 이해

### 합성곱을 수치로 이해하기 (3×3 필터가 5×5보다 유리한 이유)
- 5×5 필터 1개는 한 채널당 5×5=25개의 학습 파라미터를 쓴다. 반면 3×3 필터 2개를 연속으로 쌓으면 동일하게 5×5 영역을 "보게" 되지만(수용 영역, Receptive Field 동일), 파라미터는 3×3×2=18개로 28% 줄어든다.
- 게다가 층 사이에 비선형 활성화 함수(ReLU)가 하나 더 끼므로, 같은 수용 영역이라도 표현력(비선형성)은 3×3 두 겹이 더 높다. VGG가 3×3 필터만 고집한 이유가 이것이다.

### 기울기 소실을 수치로 이해하기
- 역전파는 각 층의 기울기를 연쇄법칙(체인룰)으로 계속 곱해가며 앞 층까지 전달한다. 만약 층마다 기울기가 평균 0.9배로 줄어든다면, 50개 층을 통과한 뒤 남는 기울기는 0.9⁵⁰ ≈ 0.005, 즉 원래의 약 0.5%만 남는다.
- 기울기가 이 정도로 작아지면 앞쪽 층의 가중치는 사실상 갱신되지 않는다 — 망을 깊게 쌓을수록(VGG처럼 19층, 34층으로) 오히려 학습이 안 되는 열화(Degradation) 문제가 나타난 이유다.

### Skip Connection이 기울기를 살리는 원리를 수치로 이해하기
- Residual Block의 출력은 $H(x) = F(x) + x$다. 이를 미분하면 $\frac{\partial H}{\partial x} = \frac{\partial F}{\partial x} + 1$이 되어, $F(x)$ 경로의 기울기가 아무리 작아져도 "+1"이라는 지름길 기울기가 항상 더해진다.
- 앞의 예로 다시 보면, 50개 층을 거쳐도 매 층마다 최소 1의 기울기가 보장되므로 0.9⁵⁰처럼 지수적으로 소멸하지 않는다. 이 덕분에 ResNet은 152층(ResNet-152)까지도 안정적으로 학습된다.

### EfficientNet의 Compound Scaling을 수치로 이해하기
- 깊이는 $\alpha^{\phi}$, 너비는 $\beta^{\phi}$, 해상도는 $\gamma^{\phi}$ 배로 늘리되, $\alpha \cdot \beta^2 \cdot \gamma^2 \approx 2$가 되도록 상수 $\alpha, \beta, \gamma$를 실험으로 고정한다($\alpha \approx 1.2, \beta \approx 1.1, \gamma \approx 1.15$). $\phi$ 하나만 키우면 세 축이 정해진 비율로 함께 커진다.
- 예: $\phi=0$이면 EfficientNet-B0(기본형), $\phi$를 키울수록 B1→B7로 이름이 붙으며 깊이·너비·해상도가 비례해서 커진다. 이렇게 하면 "일단 깊이만 2배로" 늘렸을 때보다 같은 연산량(FLOPs)에서 더 높은 정확도를 얻는다는 것이 실험으로 확인됐다.

### 연산량을 수치로 비교하기
- VGG-16: 약 15.3G FLOPs, 파라미터 약 1억 3,800만 개.
- ResNet-50: 약 3.8G FLOPs, 파라미터 약 2,500만 개 — VGG-16보다 연산량은 4분의 1 수준인데 ImageNet Top-1 정확도는 더 높다.
- EfficientNet-B0: 약 0.39G FLOPs, 파라미터 약 530만 개로 ResNet-50 대비 연산량 10분의 1 수준에서 비슷하거나 더 높은 정확도를 낸다 — Compound Scaling의 효율성을 보여주는 수치다.

### 비유와 흔한 오해
- 비유: VGG가 무작정 높은 탑을 쌓다 무너진 것이라면, ResNet은 층마다 비상계단(지름길)을 달아 붕괴를 막은 것이고, EfficientNet은 최적의 자재 비율로 지은 가성비 빌딩이다.
- 오해: ResNet은 입력 $x$를 그대로 복사해 넘기기만 하는 것이 아니다. 층이 실제로 학습하는 것은 목표 출력과 입력의 "차이"인 $F(x)$뿐이며, 이 차이가 0이어도 최소한 입력은 그대로 보존되므로 "더 깊게 쌓아도 최소한 손해는 안 본다"는 안전장치가 되는 것이다.

## 연결 개념
- CNN(Convolutional Neural Network) — 합성곱 연산으로 공간적 특징을 추출하는 딥러닝 구조.
- 객체 탐지(070) — 이미지 분류의 CNN Backbone(ResNet 등)을 그대로 가져와, 그 위에 위치 예측(Bounding Box)을 얹은 것.
- 전이 학습(Transfer Learning) — ImageNet으로 사전학습된 가중치를 가져와 데이터가 부족한 타 도메인(의료 등) 분류에 재활용하는 기법.

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.
> 핵심: CNN 아키텍처의 발전이 단순 깊이 증가(VGG)에서 잔차 연결(ResNet), 그리고 복합 스케일링(EfficientNet)으로 나아간 기술적 필연성을 논리적으로 전개한다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 딥러닝 기반 이미지 분류는 합성곱(CNN) 층을 적층하여 입력 픽셀에서 추상화된 특징(Feature)을 추출하고 클래스 확률을 할당하는 기술이다.
> 2. **가치**: ResNet의 Skip Connection으로 기울기 소실을 해결해 초심층 네트워크 구성을 가능하게 했고, EfficientNet은 스케일링 최적화로 정확도와 연산 비용 트레이드오프를 돌파했다.
> 3. **판단 포인트**: 실무 적용 시 무조건 파라미터가 큰 모델을 고르는 대신, 타겟 디바이스의 GPU 연산 한계(FLOPs)와 정확도 요구사항을 비교하여 백본을 선택해야 한다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| CNN 발전 흐름과 구조적 한계 이해 | VGG(깊이), ResNet(Skip Connection), EfficientNet(Compound Scaling) | 모델 명칭만 나열하고 구조적 극복 방안(잔차 학습 등) 서술 누락 |
| 심층 신경망의 고질적 한계 극복 원리 | 기울기 소실(Vanishing Gradient), 잔차 학습(Residual Learning) 메커니즘 | ResNet 도입 이유를 단순히 파라미터 확장으로만 오해 |
| 실무 아키텍처(백본) 선정 기준 검증 | 파라미터 연산량(FLOPs) 대비 분류 정확도(Top-1 Accuracy) 효율성 판단 | Edge 환경의 제약조건(메모리 풋프린트, FPS) 무시 |

> 요약: 망 깊이에 따른 기울기 소실 문제를 ResNet이 어떻게 해결했는지 밝히고, 컴퓨팅 연산 효율성을 EfficientNet이 어떻게 달성했는지 구조적으로 대조한다.

## Ⅰ. 개요 및 필요성

- 정의: 입력 이미지 픽셀 배열의 공간적 계층 구조를 분석하여 사전에 정의된 다수의 클래스 라벨로 매핑하는 비전 알고리즘
- 배경: 망이 깊어질수록 특징 표현력은 증가하지만, 기울기 소실(Vanishing Gradient)로 인해 오히려 최적화 오류가 급증하는 열화(Degradation) 문제 직면
- 필요성: 파라미터 크기와 연산량(FLOPs) 팽창을 억제하면서도 Top-1 정확도 80% 이상의 안정적 수렴을 보장하는 구조적 최적화 필수

## Ⅱ. 구조 및 구성요소 (ResNet 블록 중심)

```text
Input (x) -> [ Weight Layer ] -> ReLU -> [ Weight Layer ] -> (+) -> ReLU -> Output
      |                                                        ^
      +------------------- Skip Connection (x) ----------------+
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 3x3 Conv Layer (VGG 도입) | 작은 필터를 연속 겹쳐 사용하여 비선형성을 늘리고 파라미터는 감축 | $5\times5$ 1개보다 $3\times3$ 2개가 전체 연산량 더 저렴 |
| Skip Connection (ResNet) | 층 입력값 $x$를 층 출력 연산 결과 $F(x)$에 우회하여 더함 ($F(x) + x$) | 최소한 항등(Identity) 함수 매핑은 안정적으로 보장 |
| Residual Block (ResNet) | 원본 대신 잔차(목표와 입력의 차이인 $F(x)$)만을 학습하도록 목적 함수 튜닝 | 네트워크를 152층(ResNet-152) 이상 심층 적층 가능 |
| Compound Scaling (Efficient) | 망 깊이(Depth), 너비(Width), 입력 해상도(Resolution)의 확장 비율 고정 | 제한된 FLOPs 하에서 특징 추출 효율 극대화 |

> 요약: ResNet은 입력값을 우회시켜 기울기를 끝까지 보존하는 잔차 블록을 뼈대로 하며, EfficientNet은 모델 크기를 입체적으로 확장하는 규칙이다.

## Ⅲ. 동작원리 및 아키텍처 발전 흐름도

```text
AlexNet (대규모 CNN 등장) -> VGGNet (깊이 증가/3x3 고정) -> ResNet (잔차 학습/기울기 보존) -> EfficientNet (비율 기반 확장)
```

| 단계 | 아키텍처 | 발전 및 개선 기여도 |
|:---:|:---|:---|
| 1 | VGG (2014) | 3x3 합성곱 필터만을 일관되게 사용하여 네트워크 깊이를 16~19층 규모로 체계화 |
| 2 | ResNet (2015) | Skip Connection 추가로 층 깊이 증가에 따른 기울기 소실(Degradation) 근본적 회피 |
| 3 | MobileNet | Depthwise Separable Convolution 연산으로 모바일용 파라미터 대폭 감축 |
| 4 | EfficientNet (2019)| $\alpha, \beta, \gamma$ 상수 기반 3차원 동시 확장(Compound Scaling)으로 연산량 대비 SOTA 정확도 달성 |

> 요약: 이미지 분류 구조는 무조건 깊이를 늘리던 VGG의 한계를 ResNet의 우회로 설계로 돌파했고, 현재는 EfficientNet을 통해 컴퓨팅 자원 활용률을 최적화했다.

## Ⅳ. 심화 비교 (VGG vs ResNet vs EfficientNet)

| 비교 축 | VGGNet | ResNet | EfficientNet |
|:---|:---|:---|:---|
| 설계 철학 | 망의 깊이(Depth) 단순 무한 적층 | 지름길(Skip Connection) 구조 도입 | 스케일링 계수에 따른 균형 잡힌 다차원 확장 |
| 연산량 특성 | 매우 무거움 (~15.3B FLOPs) | 적정 수준 유지 (~3.8B, ResNet-50) | 가변적(B0~B7), 비용 대비 최고 가성비 |
| 해결한 문제점 | 큰 필터 사용으로 인한 파라미터 낭비 | 심층 역전파 시 기울기 소실(Vanishing Gradient) 차단 | 단일 차원(깊이 또는 너비) 확장에 따른 비효율 한계 극복 |

> 요약: 무거운 연산 비용을 감수하던 VGG를 넘어, ResNet이 깊이의 제약을 풀었고 EfficientNet이 인프라 자원 제약 내 연산 효율을 극대화했다.

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | CNN 계열 (ResNet/EfficientNet) | Transformer 계열 (ViT) | 선택 기준 |
|:---|:---|:---|:---|
| 귀납 편향 | 합성곱 커널의 지역성(Locality)·이동 불변성이 구조에 내재 | 전역 Self-Attention으로 이미지 전체 관계를 직접 학습, 귀납 편향 약함 | 학습 데이터 규모가 작으면 CNN, 대규모(수억 장)면 ViT 우세 |
| 데이터 요구량 | ImageNet(약 100만 장) 규모 학습으로도 안정적 수렴 | 초대형 데이터셋 사전학습 없이는 CNN 대비 성능 열세 | 도메인 데이터가 소량이면 CNN 전이학습이 안전 |
| 연산 특성 | 합성곱 연산은 하드웨어 가속·경량화(Depthwise 등) 생태계 성숙 | Self-Attention은 입력 길이 제곱에 비례한 연산량, 경량화 생태계 상대적으로 미성숙 | Edge 배포는 CNN, 서버 측 대규모 처리 여유 시 ViT 검토 |

> 요약: 데이터 규모와 배포 환경 제약이 크면 CNN 계열을, 대규모 데이터와 전역 문맥 학습이 필요하면 ViT 계열을 선택한다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 데이터 의존적 과적합 | 모델 파라미터(수천만 개) 대비 학습 이미지(수만 장) 수량 극도로 부족 | ImageNet으로 사전학습된 가중치 활용(Transfer Learning) 및 Data Augmentation | 타겟 도메인 Validation 정확도 급락 여부 |
| Edge 환경 메모리 초과 | 거대 모델 배포 시 타겟 디바이스(모바일 등)의 VRAM 허용치 한계 초과 | MobileNet 도입 또는 EfficientNet-B0를 TFLite/TensorRT 8bit 양자화(Quantization) 배포 | 피크 메모리 풋프린트(MB) 및 추론 FPS |

> 요약: 분류 모델 도입의 핵심 리스크는 과적합과 인프라 제약이므로, 전이 학습으로 데이터 부족을 메우고 양자화 경량화로 추론 메모리를 통제해야 한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 정확도 | 실서비스 요구수준 (Top-1 85% 이상) | 별도 분리된 검증(Test) 데이터셋으로 혼동 행렬(Confusion Matrix) 도출 |
| 추론 지연시간 (Latency) | 건당 추론 시간 50ms 이내 (실시간 요건) | NPU/GPU 타겟 환경에서 배치(Batch) 추론 속도 벤치마크 |

> 요약: 정확도뿐만 아니라 배치 추론 속도를 동시 검증하여 인프라 비용 한계를 충족하는지 판단한다.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 전이 학습(Transfer Learning) 적용: 의료 X-Ray 질병 분류 구축 시 바닥부터 학습하지 않고, ImageNet 사전학습 ResNet-50 가중치를 로드 후 출력층만 해당 도메인에 맞게 미세조정(Fine-Tuning)하여 과적합 방지
2. Edge AI 백본 적용: 스마트폰 탑재 불량품 판별 앱 개발을 위해, 연산량이 극도로 제한된 환경에 맞춰 EfficientNet-B0를 선택하고 8bit 정밀도로 양자화(Quantization)하여 지연시간 30ms 이내 달성
3. 복합 비전 태스크 백본 활용: 단순히 단일 이미지 분류에 그치지 않고, Faster R-CNN이나 분할(Segmentation) 네트워크의 특징 추출용 백본 모듈(Backbone)로 ResNet-101을 플러그인 결합하여 전체 파이프라인 성능 향상

**결론 (2줄):**
- 기술사 판단: 이미지 분류 모델은 단순히 SOTA(최고 성능)를 좇기보다, 배포 환경의 컴퓨팅 자원(Cloud vs Edge) 한계와 요구 FPS에 따라 VGG-ResNet-EfficientNet 중 최적 연산량(FLOPs)을 가진 구조를 선정해야 한다.
- 향후 방향: 최근 대규모 비전 태스크에서는 합성곱(CNN)의 지역적 한계를 넘어 자연어 처리에서 유래한 Attention 기반의 ViT(Vision Transformer)가 주도적 백본으로 부상하고 있다.
