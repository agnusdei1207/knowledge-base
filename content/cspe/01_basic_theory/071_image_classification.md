## Ⅰ. 개요
- **정의**: 입력 이미지를 사전 정의된 클래스 레이블에 매핑하는 CNN 기반 인식 기술임
- **배경/필요성**: 대량 시각 데이터의 수동 분류 한계 -> 자동화된 패턴 인식 체계 요구
- **비유**: 사진첩 속 사진에 태그를 자동으로 붙이는 분류기

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| CNN 계층별 특징 추출 원리 | Conv-Pool-FC 파이프라인 구조 | 분류와 탐지(070)의 출력 차이 명확 구분 |
| 깊은 망의 학습 최적화 | ResNet Skip Connection 원리 | 단순 "깊을수록 좋다"식 서술 금지 |

> 요약: CNN 기반으로 이미지의 시각적 특징을 계층적으로 추출하여 클래스를 판별하는 기술임

## Ⅱ. 구성요소
```text
+----------+     +----------+     +----------+     +----------+
| Input    | --> | Conv+Pool| --> | Flatten  | --> | Softmax  |
| (Image)  |     | (Feature)|     | (Vector) |     | (Class)  |
+----------+     +----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 합성곱 계층(Conv) | 3x3 등 커널 필터로 지역적 특징 맵을 추출, 계층이 깊어질수록 고수준 패턴 포착 | 확대경 |
| 풀링 계층(Pool) | Max/Average 연산으로 특징 맵 크기를 1/2~1/4로 축소, 위치 불변성 확보 | 요약 압축기 |
| 완전 연결 계층(FC) | 추출된 특징 벡터를 클래스 수 차원으로 변환, Softmax로 확률 분포 출력 | 최종 심판관 |

> 요약: Conv로 특징 추출, Pool로 차원 축소, FC+Softmax로 클래스 확률을 산출하는 3단 구조임

## Ⅲ. 절차
```text
+----------+    +----------+    +----------+    +----------+
| Resize   | -> | ConvBlock| -> | FC Layer | -> | Classify |
| & Norm   |    | x N      |    | + Drop   |    | Softmax  |
+----------+    +----------+    +----------+    +----------+
```

1. **전처리** — 이미지를 고정 크기(224x224 등)로 리사이즈하고 정규화(mean/std) 수행
2. **특징 추출** — Conv-BN-ReLU-Pool 블록을 N회 반복하여 다단계 특징 맵 생성
3. **벡터 변환** — Global Average Pooling 또는 Flatten으로 1D 특징 벡터 도출
4. **클래스 판별** — FC 계층과 Softmax를 거쳐 각 클래스 소속 확률 산출, argmax로 최종 분류

> 요약: 이미지 정규화 -> 다층 Conv 블록 반복 -> 벡터 평탄화 -> Softmax 분류의 4단계 파이프라인임

## Ⅳ. 문제점
- [기울기 소실]: 16층 이상 깊은 망에서 역전파 시 기울기가 0에 수렴하여 학습 정체 발생
- [데이터 의존]: ImageNet급(100만+) 레이블 데이터 미확보 시 과적합(Overfitting) 심화
- [연산 부하]: VGG-16 기준 15.5B FLOPs로 모바일/엣지 디바이스 실시간 추론 곤란

> 요약: 심층 학습 불안정, 대규모 데이터 종속성, 경량 환경 배포 한계가 3대 과제임

## Ⅴ. 개선방안
1. 단기: ResNet Skip Connection으로 잔차 학습 도입 -> 152층까지 기울기 소실 없이 학습 가능
2. 중기: 사전 학습 모델(ImageNet Pretrained) 기반 전이 학습(Transfer Learning)으로 소량 데이터 대응
3. 장기: NAS(Neural Architecture Search) 기반 EfficientNet으로 FLOPs 대비 정확도 파레토 최적 모델 자동 탐색

- [모델 경량화 실패]: 과도한 프루닝 -> 정확도 5%+ 하락 (지표: Top-1 Accuracy ≥ 원본 95%)

> 요약: 잔차 학습 -> 전이 학습 -> 구조 탐색 자동화 순으로 깊이·데이터·연산 문제를 단계적 해소함

## Ⅵ. 전망
- 향후 발전 방향: ViT(Vision Transformer) 계열이 CNN 대비 대규모 데이터에서 우위를 확보하며 하이브리드 모델(CoAtNet 등) 확산 전망
- 기술사적 판단: CNN 기반 분류는 의료·제조 등 도메인 특화 소규모 데이터셋에서 여전히 비용 대비 최적해로 유효함
- 기술사 제언: 분류 모델 선정 시 데이터 규모·추론 환경(클라우드/엣지)·정확도 요구 수준의 삼각 트레이드오프를 정량적으로 평가 후 결정 필요
