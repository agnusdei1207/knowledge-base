# 📖 【암기용】 개념 완전 이해

> 목적: 이미지 분류를 처음 봐도 완벽히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 입력 이미지를 미리 정한 클래스 중 하나로 판정하는 컴퓨터 비전 문제
- **왜 필요한가**: 제조 결함, 의료 영상, 보안 관제처럼 사람이 모든 이미지를 판독하면 비용과 판정 편차가 발생한다. 모델은 픽셀 패턴을 특징으로 바꾸어 클래스 확률을 산출한다.
- **핵심 직관**: 이미지를 작은 패턴부터 큰 물체 형태까지 단계적으로 요약한 뒤, 마지막에 가장 확률이 높은 라벨을 고르는 절차다.

## 깊이 이해
- **배경·문제의식**: 전통 방식은 SIFT, HOG 같은 수작업 특징을 설계했지만 조명, 회전, 배경 변화마다 별도 규칙이 필요했다. CNN은 필터를 학습해 엣지, 질감, 부품, 객체 형태를 계층적으로 추출한다.
- **작동 원리**: VGG는 3x3 합성곱을 깊게 쌓아 기본 구조를 단순화했고, ResNet은 스킵 연결로 50층 이상 학습의 기울기 소실을 줄였다. EfficientNet은 깊이, 폭, 해상도를 compound scaling으로 함께 조정해 FLOPs 대비 정확도 균형을 맞춘다.
- **비유**: 검사자가 사진 전체를 한 번에 보지 않고 모서리, 부품, 조립 상태 순서로 체크리스트를 좁혀 최종 품목을 판정하는 방식과 같다.
- **구체 예시**: 224x224 RGB 이미지를 ResNet-50에 넣으면 약 25.6M 파라미터가 특징을 추출하고, ImageNet 기준 1,000개 클래스에 대한 softmax 확률을 반환한다.
- **흔한 오해·주의점**: 학습 정확도 99%가 운영 정확도 99%를 의미하지 않는다. 촬영 장비, 조명, 배경이 바뀌면 데이터 분포가 달라져 Top-1 정확도와 F1-score를 별도 검증해야 한다.

## 연결 개념
- CNN — 이미지 분류의 기본 특징 추출기
- 전이 학습 — ImageNet 사전학습 가중치를 도메인 데이터에 재학습
- 객체 탐지 — 분류에 위치 정보와 bounding box를 추가한 문제

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 이미지 분류는 픽셀 배열을 특징 벡터로 변환한 뒤 미리 정한 클래스의 확률 분포를 산출하는 지도학습 문제임.
> 2. **가치**: 검사 자동화, 의료 판독 보조, 콘텐츠 필터링에서 Top-1 정확도, F1-score, 추론 지연시간으로 도입 효과를 검증함.
> 3. **판단 포인트**: VGG는 구조 단순성, ResNet은 깊은 네트워크 학습, EfficientNet은 FLOPs 대비 정확도 균형을 기준으로 선택함.

---

## Ⅰ. 개요 및 필요성

이미지 분류는 이미지를 클래스 확률로 변환하는 기술이다. 산업 현장은 초당 수십 장의 영상 판정, 의료 보조 판독, 유해 이미지 차단 요구가 존재한다. 모델 도입 시 데이터 편향, 설명 가능성, 추론 지연시간을 함께 검증해야 함.

---

## Ⅱ. 구조 및 구성요소

```text
이미지 입력 -> 전처리 -> 특징 추출 Backbone -> 분류 Head -> 클래스 확률
              +-> 학습 데이터/라벨
              +-> 평가 지표 Top-1/F1/Latency
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 전처리 | resize, normalization, augmentation 수행 | 224x224, mean/std 정규화 |
| Backbone | CNN/ViT로 계층 특징 추출 | VGG, ResNet-50, EfficientNet-B0 |
| 분류 Head | global pooling, fully connected, softmax | 클래스 수 N에 맞게 재학습 |
| 평가 지표 | 정확도와 운영 지연 측정 | Top-1, Top-5, F1, p95 latency |

> 요약: 이미지 분류는 전처리, 특징 추출, 분류 Head, 지표 검증으로 클래스 확률을 산출함.

---

## Ⅲ. 동작원리 및 흐름도

```text
데이터 수집 -> 라벨 검수 -> 모델 학습 -> 검증/튜닝 -> 배포 추론
              +-> 오분류 샘플 재학습
              +-> 운영 데이터 드리프트 감시
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 학습/검증/시험 데이터 분리 | train/val/test 7:2:1 또는 k-fold |
| 2 | CNN Backbone으로 특징 학습 | loss 감소, overfitting gap 5%p 이하 |
| 3 | Softmax로 클래스 확률 산출 | Top-1, F1-score, confusion matrix |
| 4 | 추론 서버 배포와 모니터링 | p95 latency 100ms, GPU 사용률 70% 이하 |

> 요약: 라벨 데이터로 특징 추출기를 학습하고, 시험셋 및 운영 지표로 오분류와 지연시간을 통제함.

---

## Ⅳ. 특징

| 구분 | 내용 | 판단 포인트 |
|:---|:---|:---|
| VGG | 3x3 합성곱 반복 구조 | 구조 설명 용이, VGG-16 약 138M 파라미터 |
| ResNet | residual connection으로 깊은 층 학습 | ResNet-50 약 25.6M 파라미터, 기울기 소실 완화 |
| EfficientNet | 폭/깊이/해상도 동시 스케일링 | B0 약 5.3M 파라미터, 모바일 추론 후보 |
| 한계 | 라벨 편향과 데이터 드리프트에 민감 | 월별 재평가, ECE calibration 점검 |

> 요약: 이미지 분류 모델은 정확도, 파라미터 수, 추론 지연시간, 운영 데이터 변화 기준으로 선택함.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존/대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 특징 설계 | SIFT/HOG 수작업 특징 | CNN 자동 특징 학습 | 조명·배경 변화가 크면 CNN 선택 |
| 비용/성능 | 대형 VGG | ResNet/EfficientNet | GPU 메모리 8GB 이하이면 EfficientNet-B0/B1 |
| 운영/위험 | 규칙 기반 판정 | 확률 기반 판정 | 임계값, human-in-the-loop 필요 |

> 요약: 변화가 큰 이미지 환경은 CNN 기반 분류를 선택하되, 장비 제약은 EfficientNet 계열로 조정함.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 오분류 | 클래스 불균형, 라벨 오류 | stratified split, 라벨 2인 검수 | macro F1 0.90 이상 |
| 드리프트 | 촬영 장비·조명 변경 | 월별 재학습, PSI/KL divergence 측정 | PSI 0.2 초과 알림 |
| 추론 지연 | 모델 파라미터와 입력 해상도 과다 | quantization, TensorRT, batch size 제한 | p95 100ms 이하 |

> 요약: 오분류, 드리프트, 지연시간은 데이터 검수, 재학습, 경량화 지표로 통제함.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 분류 품질 | Top-1 95%, macro F1 0.90 | 시험셋, confusion matrix |
| 추론 성능 | p95 100ms, 처리량 200 IPS | 벤치마크, APM |
| 운영 통제 | 드리프트 PSI 0.2 이하, 감사로그 90일 | 모니터링, 모델 레지스트리 |

> 요약: 도입 성공은 정확도, 지연시간, 드리프트 통제 지표를 동시에 충족하는지로 판단함.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 — 단계별 또는 항목별):**
1. 데이터: 클래스별 최소 1,000장 확보, 라벨 2인 검수, train/val/test 7:2:1 분리
2. 모델: ResNet-50 baseline 후 EfficientNet-B0 경량화, mixed precision 및 TensorRT 적용
3. 운영: Top-1, macro F1, p95 latency, PSI를 모델 레지스트리에 기록하고 월 1회 재평가

**결론 (2줄):**
- 기술사 판단: 판정 정확도 우선이면 ResNet 계열, 엣지 추론과 전력 제약이면 EfficientNet 계열 선택
- 향후 방향: CNN 분류는 Vision Transformer, self-supervised pretraining, MLOps 드리프트 관리와 결합 필요
