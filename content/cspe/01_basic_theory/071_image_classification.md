# 📖 【암기용】 개념 완전 이해

> 목적: 이미지 분류를 위한 CNN 발전사와 핵심 모델(ResNet, EfficientNet)의 직관을 완벽히 이해하게 만든다.

## 한눈에
- **개요**: 입력된 이미지가 어떤 범주(개, 자동차 등)에 속하는지 판별하는 컴퓨터 비전 태스크
- **왜 필요한가**: 픽셀 단순 나열로는 객체 형상을 파악할 수 없어, 특징(선, 모서리)을 추출하고 종합하여 추상적 개념으로 매핑할 딥러닝 망이 필요하다.
- **핵심 직관**: 망을 단순히 깊게 쌓으면 신호가 옅어지므로(기울기 소실) 지름길을 뚫어주고(ResNet), 깊이·너비·해상도를 최적의 비율로 동시에 늘려 효율을 극대화(EfficientNet)한다.

## 깊이 이해
- **배경·문제의식**: VGG는 3x3 필터를 깊게 쌓아 성능을 높였으나, 층이 깊어질수록 학습 오차가 0에 수렴하는 기울기 소실(Vanishing Gradient) 문제가 생겼다.
- **작동 원리 (ResNet)**: 입력 $x$를 층의 결과 $F(x)$에 더해주는 지름길(Skip Connection, $F(x)+x$)을 뚫었다. 층이 쓸모없어도 최소한 원본은 유지하므로 심층망을 안전하게 쌓을 수 있다.
- **작동 원리 (EfficientNet)**: 무작정 깊게(Depth) 쌓거나 필터 수를 늘리거나(Width) 해상도(Resolution)를 키우는 대신, 이 세 가지를 일정한 비율 상수로 함께 스케일업(Compound Scaling)하여 연산 효율을 극대화했다.
- **비유**: VGG가 무식하게 높은 탑을 쌓다 무너진 거라면, ResNet은 층마다 비상계단(지름길)을 달아 붕괴를 막은 것이고, EfficientNet은 최적의 자재 황금비율로 지은 가성비 빌딩이다.
- **흔한 오해·주의점**: ResNet은 '잔차(Residual)'를 학습하는 것이지 '원본'을 그대로 복사해 넘기기만 하는 것이 아니다. 모델이 목표치와의 차이인 $F(x)$만 0으로 맞추면 되므로 학습 난이도가 급락한다.

## 연결 개념
- CNN (Convolutional Neural Network) — 합성곱 연산을 통해 공간적 특징을 추출하는 딥러닝 구조
- Vanishing Gradient — 층이 깊어질수록 역전파되는 오차값이 점차 작아져 파라미터가 갱신되지 않는 현상
- Transfer Learning (전이 학습) — 방대한 ImageNet 데이터로 사전학습된 모델의 가중치를 가져와, 데이터가 부족한 타 도메인 분류(의료 등)에 재활용하는 기법

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.
> 핵심: CNN 아키텍처의 발전이 단순 깊이 증가(VGG)에서 잔차 연결(ResNet), 그리고 복합 스케일링(EfficientNet)으로 나아간 기술적 필연성을 논리적으로 전개한다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 딥러닝 기반 이미지 분류는 합성곱(CNN) 층을 적층하여 입력 픽셀에서 추상화된 특징(Feature)을 추출하고 클래스 확률을 할당하는 기술이다.
> 2. **가치**: ResNet의 Skip Connection으로 기울기 소실을 해결해 초심층 네트워크 구성을 가능하게 했고, EfficientNet은 스케일링 최적화로 정확도와 연산 비용 트레이드오프를 돌파했다.
> 3. **판단 포인트**: 실무 적용 시 무조건 파라미터가 큰 모델을 고르는 대신, 타겟 디바이스의 GPU 연산 한계(FLOPs)와 정확도 요구사항을 비교하여 백본을 선택해야 한다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| CNN 발전 흐름과 구조적 한계 이해 | VGG(깊이), ResNet(Skip Connection), EfficientNet(Compound Scaling) | 모델 명칭만 나열하고 구조적 극복 방안(잔차 학습 등) 서술 누락 |
| 심층 신경망의 고질적 한계 극복 원리 | 기울기 소실(Vanishing Gradient), 잔차 학습(Residual Learning) 메커니즘 | ResNet 도입 이유를 단순히 파라미터 확장으로만 오해 |
| 실무 아키텍처(백본) 선정 기준 검증 | 파라미터 연산량(FLOPs) 대비 분류 정확도(Top-1 Accuracy) 효율성 판단 | Edge 환경의 제약조건(메모리 풋프린트, FPS) 무시 |

> 요약: 망 깊이에 따른 기울기 소실 문제를 ResNet이 어떻게 해결했는지 밝히고, 컴퓨팅 연산 효율성을 EfficientNet이 어떻게 달성했는지 구조적으로 대조한다.

## Ⅰ. 개요 및 필요성

- 정의: 입력 이미지 픽셀 배열의 공간적 계층 구조를 분석하여 사전에 정의된 다수의 클래스 라벨로 매핑하는 비전 알고리즘
- 배경: 망이 깊어질수록 특징 표현력은 증가하지만, 기울기 소실(Vanishing Gradient)로 인해 오히려 최적화 오류가 급증하는 열화(Degradation) 문제 직면
- 필요성: 파라미터 크기와 연산량(FLOPs) 팽창을 억제하면서도 Top-1 정확도 80% 이상의 안정적 수렴을 보장하는 구조적 최적화 필수

---

## Ⅱ. 구조 및 구성요소 (ResNet 블록 중심)

```text
Input (x) -> [ Weight Layer ] -> ReLU -> [ Weight Layer ] -> (+) -> ReLU -> Output
      |                                                        ^
      +------------------- Skip Connection (x) ----------------+
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 3x3 Conv Layer (VGG 도입) | 작은 필터를 연속 겹쳐 사용하여 비선형성을 늘리고 파라미터는 감축 | $5\times5$ 1개보다 $3\times3$ 2개가 전체 연산량 더 저렴 |
| Skip Connection (ResNet) | 층 입력값 $x$를 층 출력 연산 결과 $F(x)$에 우회하여 더함 ($F(x) + x$) | 최소한 항등(Identity) 함수 매핑은 안정적으로 보장 |
| Residual Block (ResNet) | 원본 대신 잔차(목표와 입력의 차이인 $F(x)$)만을 학습하도록 목적 함수 튜닝 | 네트워크를 152층(ResNet-152) 이상 심층 적층 가능 |
| Compound Scaling (Efficient) | 망 깊이(Depth), 너비(Width), 입력 해상도(Resolution)의 확장 비율 고정 | 제한된 FLOPs 하에서 특징 추출 효율 극대화 |

> 요약: ResNet은 입력값을 우회시켜 기울기를 끝까지 보존하는 잔차 블록을 뼈대로 하며, EfficientNet은 모델 크기를 입체적으로 확장하는 규칙이다.

---

## Ⅲ. 동작원리 및 아키텍처 발전 흐름도

```text
AlexNet (대규모 CNN 등장) -> VGGNet (깊이 증가/3x3 고정) -> ResNet (잔차 학습/기울기 보존) -> EfficientNet (비율 기반 확장)
```

| 단계 | 아키텍처 | 발전 및 개선 기여도 |
|:---:|:---|:---|
| 1 | VGG (2014) | 3x3 합성곱 필터만을 일관되게 사용하여 네트워크 깊이를 16~19층 규모로 체계화 |
| 2 | ResNet (2015) | Skip Connection 추가로 층 깊이 증가에 따른 기울기 소실(Degradation) 근본적 회피 |
| 3 | MobileNet | Depthwise Separable Convolution 연산으로 모바일용 파라미터 대폭 감축 |
| 4 | EfficientNet (2019)| $\alpha, \beta, \gamma$ 상수 기반 3차원 동시 확장(Compound Scaling)으로 연산량 대비 SOTA 정확도 달성 |

> 요약: 이미지 분류 구조는 무조건 깊이를 늘리던 VGG의 한계를 ResNet의 우회로 설계로 돌파했고, 현재는 EfficientNet을 통해 컴퓨팅 자원 활용률을 최적화했다.

---

## Ⅳ. 심화 비교 (VGG vs ResNet vs EfficientNet)

| 비교 축 | VGGNet | ResNet | EfficientNet |
|:---|:---|:---|:---|
| 설계 철학 | 망의 깊이(Depth) 단순 무한 적층 | 지름길(Skip Connection) 구조 도입 | 스케일링 계수에 따른 균형 잡힌 다차원 확장 |
| 연산량 특성 | 매우 무거움 (~15.3B FLOPs) | 적정 수준 유지 (~3.8B, ResNet-50) | 가변적(B0~B7), 비용 대비 최고 가성비 |
| 해결한 문제점 | 큰 필터 사용으로 인한 파라미터 낭비 | 심층 역전파 시 기울기 소실(Vanishing Gradient) 차단 | 단일 차원(깊이 또는 너비) 확장에 따른 비효율 한계 극복 |

> 요약: 무거운 연산 비용을 감수하던 VGG를 넘어, ResNet이 깊이의 제약을 풀었고 EfficientNet이 인프라 자원 제약 내 연산 효율을 극대화했다.

## Ⅴ. 리스크 및 지표 기반 판단

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 데이터 의존적 과적합 | 모델 파라미터(수천만 개) 대비 학습 이미지(수만 장) 수량 극도로 부족 | ImageNet으로 사전학습된 가중치 활용(Transfer Learning) 및 Data Augmentation | 타겟 도메인 Validation 정확도 급락 여부 |
| Edge 환경 메모리 초과 | 거대 모델 배포 시 타겟 디바이스(모바일 등)의 VRAM 허용치 한계 초과 | MobileNet 도입 또는 EfficientNet-B0를 TFLite/TensorRT 8bit 양자화(Quantization) 배포 | 피크 메모리 풋프린트(MB) 및 추론 FPS |

> 요약: 분류 모델 도입의 핵심 리스크는 과적합과 인프라 제약이므로, 전이 학습으로 데이터 부족을 메우고 양자화 경량화로 추론 메모리를 통제해야 한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 정확도 | 실서비스 요구수준 (Top-1 85% 이상) | 별도 분리된 검증(Test) 데이터셋으로 혼동 행렬(Confusion Matrix) 도출 |
| 추론 지연시간 (Latency) | 건당 추론 시간 50ms 이내 (실시간 요건) | NPU/GPU 타겟 환경에서 배치(Batch) 추론 속도 벤치마크 |

> 요약: 정확도뿐만 아니라 배치 추론 속도를 동시 검증하여 인프라 비용 한계를 충족하는지 판단한다.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 전이 학습(Transfer Learning) 적용: 의료 X-Ray 질병 분류 구축 시 바닥부터 학습하지 않고, ImageNet 사전학습 ResNet-50 가중치를 로드 후 출력층만 해당 도메인에 맞게 미세조정(Fine-Tuning)하여 과적합 방지
2. Edge AI 백본 적용: 스마트폰 탑재 불량품 판별 앱 개발을 위해, 연산량이 극도로 제한된 환경에 맞춰 EfficientNet-B0를 선택하고 8bit 정밀도로 양자화(Quantization)하여 지연시간 30ms 이내 달성
3. 복합 비전 태스크 백본 활용: 단순히 단일 이미지 분류에 그치지 않고, Faster R-CNN이나 분할(Segmentation) 네트워크의 특징 추출용 백본 모듈(Backbone)로 ResNet-101을 플러그인 결합하여 전체 파이프라인 성능 향상

**결론 (2줄):**
- 기술사 판단: 이미지 분류 모델은 단순히 SOTA(최고 성능)를 좇기보다, 배포 환경의 컴퓨팅 자원(Cloud vs Edge) 한계와 요구 FPS에 따라 VGG-ResNet-EfficientNet 중 최적 연산량(FLOPs)을 가진 구조를 선정해야 한다.
- 향후 방향: 최근 대규모 비전 태스크에서는 합성곱(CNN)의 지역적 한계를 넘어 자연어 처리에서 유래한 Attention 기반의 ViT(Vision Transformer)가 주도적 백본으로 부상하고 있다.
