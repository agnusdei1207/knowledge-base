## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 입력된 이미지가 어떤 범주(Class)에 속하는지 합성곱 신경망(CNN)을 기반으로 식별하는 컴퓨터 비전 핵심 기술임. |
| 배경/필요성 | 시각적 패턴 인식의 복잡성을 해결하고 인간을 대체하여 대규모 영상 데이터를 자동으로 분류할 필요성. |
| 출제 의도 | CNN의 특징 추출 메커니즘과 깊은 신경망(ResNet 등)에서의 학습 최적화 원리 평가. |

## Ⅱ. 구성요소
```text
+-----------+    +-----------+    +-----------+
| Conv Net  | -> | Pool Net  | -> | Fully Con |
+-----------+    +-----------+    +-----------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 합성곱 계층(Conv) | 커널 필터를 적용하여 이미지의 지역적 특징 맵 추출 | 스케치 |
| 풀링 계층(Pool) | 특징 맵의 차원을 축소하여 불변성 및 연산량 감소 확보 | 압축기 |
| 완전 연결 계층 | 추출된 특징을 바탕으로 최종적인 클래스 확률 출력 | 판사 |

> 요약: 합성곱과 풀링을 반복하여 특징을 추출하고 완전 연결 계층을 통해 최종 클래스를 분류함.

## Ⅲ. 절차
```text
+----------+   +----------+   +----------+   +----------+
| Img Inpt |-> | Features |-> | Flatten  |-> | Softmax  |
+----------+   +----------+   +----------+   +----------+
```
1. 이미지 입력: 다양한 해상도의 이미지를 고정된 텐서로 변환함.
2. 특징 추출: Conv 및 Pooling을 거쳐 시각적 패턴을 점진적으로 추출함.
3. 평탄화(Flatten): 다차원 특징 맵을 1차원 벡터로 전개함.
4. 클래스 분류: Softmax 함수를 통해 각 클래스에 대한 소속 확률을 계산함.

> 요약: 이미지 입력 후 컨볼루션 연산을 통해 특징을 추출하고 확률 기반으로 최종 클래스를 도출함.

## Ⅳ. 문제점
- 네트워크 계층이 깊어질수록 역전파 시 기울기 소실(Vanishing Gradient)로 인해 학습이 정체됨
- 분류 모델 성능 확보를 위해 대규모 레이블링 데이터(ImageNet 등)가 필수적으로 요구됨
- 제한된 엣지 디바이스 환경에서 연산량(FLOPs)과 파라미터 수가 커서 모델을 실장하기 어려움

## Ⅴ. 개선방안
- [단기] ResNet의 스킵 커넥션(Skip Connection) 구조를 적용하여 기울기 소실 문제 우회 해결
- [중기] 기학습된 범용 모델 기반의 전이 학습(Transfer Learning)을 적용하여 데이터 부족 한계 극복
- [장기] NAS(신경망 구조 탐색)를 활용한 EfficientNet 기반 경량화 모델 파이프라인 자동화

## Ⅵ. 전망
- 의료, 자율주행, 보안 등 다양한 도메인에서 기초(Backbone) 망으로 결합되어 성능 향상의 중추 역할을 함.
