## 미리 알고가기

- 백본(Backbone): 이미지 특징을 추출하는 합성곱 신경망 본체임
- 특징 맵(Feature Map): 필터가 감지한 위치별 패턴 응답값임
- 잔차 연결(Residual Connection): 입력을 출력에 더해 깊은 층의 학습을 돕는 경로임
- 모바일 역병목 합성곱(MBConv): 채널별 합성곱과 역잔차 구조로 연산량을 줄이는 EfficientNet 블록임
- 컴파운드 스케일링(Compound Scaling): 깊이·폭·해상도를 함께 늘리는 EfficientNet 확장 방식임
- 양자화(Quantization): 가중치·연산의 수치 정밀도를 낮춰 모델 크기와 연산량을 줄이는 경량화 기법임

## 작성 근거(검토용)

- **방향성**: 이미지 분류는 백본 구조에 따라 정확도와 파라미터 수·활성값 메모리·연산량이 상충하므로, 가용 자원과 요구 정확도에 맞춰 백본을 선택하고 불량·위험 클래스는 재현율을 우선해야 함
- **Ⅰ. 개요 구성**: 특징 추출과 클래스 판정을 함께 정의해 이미지 분류의 처리 경계를 명확히 함
- **Ⅱ. 특징 선정**: 계층별 특징, 가중치 공유, 백본 선택, 임계값처럼 모델 품질과 운영 판단을 좌우하는 요소로 구성함
- **Ⅲ. 비교축 선정**: 특징 추출 메커니즘·확장 범위·자원 병목은 VGG·ResNet·EfficientNet의 고유 스펙이라 축은 유지하고, 자원·정확도 요구에 따른 선택 기준은 요약 문장의 구체적 분기 조건으로 명시함
- **Ⅳ. 구조 선정**: 입력 텐서부터 판정 규칙까지 추론 파이프라인 처리 순서대로 구성함
- **Ⅵ. 사례 선정**: 불량 클래스 가중치 조정과 엣지 배포는 정확도만으로 판단하면 실패하기 쉬운 대표 조건임
- **전수 검수**: 제목부터 결론까지 용어·표·도식·요약을 대조하고 미사용 용어(클래스 불균형·F1 점수·p95 추론 지연)를 정리했으며 절 간 판단축을 일치시킴

## Ⅰ. 개요

- **정의/개념**: 이미지 분류는 입력 이미지를 특징 벡터로 바꾼 뒤 가능성이 가장 높은 클래스를 판정하는 컴퓨터 비전 기법임
- **배경/필요성**: 이미지를 같은 기준으로 반복 판별하기 위해 자동 분류 모델이 필요함

### 쉽게 이해하기 (학습용)
- 사람이 사진마다 눈으로 보고 판단하는 대신, 사진을 숫자 요약으로 바꿔 그 요약만 보고 자동으로 이름표를 붙이는 것과 같음

## Ⅱ. 특징

- 얕은 층은 경계·색상, 깊은 층은 형태·객체 단서를 학습함
- 합성곱의 가중치 공유로 위치별 동일 패턴을 검출하고 풀링으로 특징 맵을 축소함
- 백본 구조에 따라 정확도, 파라미터 수, 추론 지연이 달라짐
- 분류 결과는 확률 점수로 나오므로 임계값과 오류 비용을 함께 정함

### 쉽게 이해하기 (학습용)
- 처음엔 윤곽선과 색만 보다가 점점 사물의 생김새까지 알아채듯, 층이 깊어질수록 더 복잡한 단서를 잡아냄
- 같은 무늬 탐지 도장을 사진 전체에 반복해서 찍고 결과를 압축하며, 어떤 도장 세트(백본)를 쓰느냐에 따라 속도와 정확도가 달라짐

## Ⅲ. 종류 및 비교

| 판단 기준 | VGG | ResNet | EfficientNet |
|:---|:---|:---|:---|
| 특징 추출 메커니즘 | 순차 $3 \times 3$ 합성곱 | 잔차 연결 | MBConv |
| 확장 범위 | 깊이 | 블록 깊이 | 컴파운드 스케일링(깊이·폭·해상도) |
| 자원 병목 | 파라미터 증가 | 활성값 메모리 | 해상도 연산량 |

> 요약: 단순 구조로 충분하면 VGG, 깊은 층에서 정확도를 안정적으로 높이려면 활성값 메모리 비용을 감수하고 ResNet, 제한된 연산·메모리 예산에서 정확도와 효율을 함께 얻으려면 EfficientNet을 적용함.

### 쉽게 이해하기 (학습용)
- VGG는 한 겹씩 순서대로 쌓아 보고, ResNet은 이전에 본 것을 계속 더해가며 잊지 않고, EfficientNet은 깊이·폭·해상도를 동시에 균형 있게 키움

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 입력 텐서 | 높이·너비·채널로 배열한 픽셀 값 |
| 특징 추출 백본 | VGG 합성곱·ResNet 잔차 블록·EfficientNet MBConv |
| 전역 풀링 | 공간 특징의 판정 벡터 압축층 |
| 분류 헤드 | 클래스별 점수·확률 출력층 |
| 판정 규칙 | 최대 확률·임계값 기반 클래스 선택 기준 |

> 요약: 이미지 분류는 입력 텐서에서 백본 특징을 추출하고 전역 풀링·분류 헤드로 클래스 확률을 산출함.

### 쉽게 이해하기 (학습용)
- 사진(입력)을 손질(백본)해 핵심만 추리고(풀링), 마지막에 저울(분류 헤드)로 확률을 매겨 이름표 하나를 고르는 조립 라인과 같음

## Ⅵ. 실무 사례

1. 제조 불량 이미지 분류는 불량 클래스에 더 큰 손실 가중치를 적용함
2. 엣지 비전 장비는 EfficientNet을 양자화해 단말에서 분류함

### 쉽게 이해하기 (학습용)
- 불량품 사진을 놓치면 손해가 크므로 그쪽에 더 신경 쓰게 하고, 작은 기기에서는 모델을 가볍게 압축해 돌림

## Ⅶ. 결론

- 이미지 분류는 백본 구조에 따라 정확도와 파라미터 수·활성값 메모리·연산량이 상충하므로, 가용 자원과 요구 정확도에 맞춰 백본을 선택해야 함
- 불량·위험 클래스는 전체 정확도보다 재현율을 우선하고, 입력 분포 변화가 감지되면 배포 모델을 재검증해야 함

### 쉽게 이해하기 (학습용)
- 무조건 잘 맞히는 모델보다 상황(가진 자원, 놓치면 안 되는 정도)에 맞는 모델을 고르고, 사진 경향이 달라지면 다시 점검함
