## 미리 알고가기

- 백본(Backbone): 이미지 특징을 추출하는 합성곱 신경망 본체임
- 특징 맵(Feature Map): 필터가 감지한 위치별 패턴 응답값임
- 잔차 연결(Residual Connection): 입력을 출력에 더해 깊은 층의 학습을 돕는 경로임
- MBConv: 깊이별 분리 합성곱과 역잔차 구조로 연산량을 줄이는 EfficientNet 블록임
- 컴파운드 스케일링: 깊이·폭·해상도를 함께 늘리는 EfficientNet 확장 방식임
- 클래스 불균형: 특정 범주 데이터가 적어 분류 성능과 실제 업무 성능이 어긋나는 상태임

## 작성 근거(검토용)

- 개요는 특징 추출과 클래스 판정을 함께 정의해 이미지 분류의 처리 경계를 명확히 함
- 특징은 계층별 특징, 가중치 공유, 백본 선택, 임계값처럼 모델 품질과 운영 판단을 좌우하는 요소로 구성함
- Ⅲ은 VGG·ResNet·EfficientNet의 구조와 배포 조건 차이를 비교해 대표 모델 선택 기준을 제시함
- Ⅴ는 입력 정규화부터 클래스 판정까지 추론 순서를 고유 단계로 드러냄
- 클래스 불균형과 엣지 배포는 정확도만으로 판단하면 실패하기 쉬운 대표 조건임

## Ⅰ. 개요

- **정의/개념**: 이미지 분류는 입력 이미지를 특징 벡터로 바꾼 뒤 가능성이 가장 높은 클래스를 판정하는 컴퓨터 비전 기법임
- **배경/필요성**: 이미지를 같은 기준으로 반복 판별하기 위해 자동 분류 모델이 필요함

## Ⅱ. 특징

- 얕은 층은 경계·색상, 깊은 층은 형태·객체 단서를 학습함
- 합성곱의 가중치 공유로 위치별 동일 패턴을 검출하고 풀링으로 특징 맵을 축소함
- 백본 구조에 따라 정확도, 파라미터 수, 추론 지연이 달라짐
- 분류 결과는 확률 점수로 나오므로 임계값과 오류 비용을 함께 정함

## Ⅲ. 종류 및 비교

| 판단 기준 | VGG | ResNet | EfficientNet |
|:---|:---|:---|:---|
| 계층 확장 구조 | $3 \times 3$ 합성곱을 순차 반복 | 잔차 연결로 입력·기울기 경로를 추가 | MBConv 잔차 블록의 깊이·폭·해상도를 함께 확장 |
| 자원 결정 요인 | 합성곱 채널과 완전연결층 파라미터 | 블록 수와 특징맵 크기 | 깊이·폭·입력 해상도 배율 |
| 적용 조건 | 순차 합성곱 구조를 기준 모델로 비교할 때 | 잔차 연결로 깊은 특징 추출기를 구성할 때 | 연산 예산에 맞춰 깊이·폭·해상도를 함께 조정할 때 |

> 요약: 순차 합성곱을 기준선으로 쓰면 VGG, 잔차 연결로 깊이를 늘리면 ResNet, 연산 예산에 맞춰 깊이·폭·해상도를 조정하면 EfficientNet을 선택함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 전처리/증강 | 크기·정규화·회전·크롭으로 입력 분포를 맞추고 과적합을 줄임 |
| 합성곱 블록 | 필터, 정규화, 활성화 함수로 지역 패턴을 특징 맵으로 변환함 |
| 전역 풀링 | 공간 특징을 클래스 판정용 벡터로 압축함 |
| 분류 헤드 | 특징 벡터를 클래스별 점수와 확률로 변환함 |

> 요약: 이미지 분류는 전처리된 이미지를 백본 특징과 분류 헤드로 연결해 클래스 확률을 산출함.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 입력 정규화 | --> | 특징 추출 | --> | 점수 계산 | --> | 클래스 판정 |
+----------+     +----------+     +----------+     +----------+
```

1. **입력 정규화**: 이미지 크기와 픽셀 분포를 학습 조건에 맞춤
2. **특징 추출**: 합성곱 블록이 경계·질감·형태 단서를 누적함
3. **점수 계산**: 풀링된 벡터를 클래스별 점수로 변환함
4. **클래스 판정**: 소프트맥스 확률에서 임계값이나 최댓값으로 클래스를 선택함

> 요약: 이미지 분류는 정규화된 입력에서 공간 특징과 클래스 점수를 계산한 뒤 확률 기준으로 클래스를 판정함.

## Ⅵ. 실무 사례

1. 제조 불량 이미지 분류는 클래스 가중치·재표본화를 적용하고 F1·불량 클래스 재현율로 검증함
2. 엣지 비전 장비는 EfficientNet·양자화를 적용하고 정확도·p95 추론 지연으로 검증함

## Ⅶ. 결론

- 이미지 분류는 파라미터 수·추론 지연에 따라 백본을 선택하고 클래스 불균형·장비 자원 한도를 정확도와 함께 검증해야 함
