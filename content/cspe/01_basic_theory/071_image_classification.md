## Ⅰ. 개요
- 정의: 입력 이미지가 어느 카테고리에 속하는지 확률적으로 결정하는 작업임.
- 배경: 컴퓨터 비전의 기초로서 딥러닝 성능 검증의 벤치마크 역할을 수행함.
- 출제 의도:
| 분류 | 상세 |
| --- | --- |
| 핵심요소 | CNN, 잔차 학습, 스케일링, 풀링 |
| 주요특징 | 깊은 층 구성, 전역 특성 추출, 고정밀 분류 |

## Ⅱ. 구성요소
- ASCII 구조도
 [In] -> [Conv] -> [Pool] -> [Skip Conn] -> [FC] -> [Out]
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| VGGNet | 3x3 작은 필터를 깊게 쌓아 비선형성 증대 | 촘촘한 그물 |
| ResNet | 지름길(Skip Connection)로 기울기 소실 해결 | 고속도로 |
| EfficientNet | 깊이, 너비, 해상도를 조화롭게 스케일링 | 균형 잡힌 설계 |
> 요약: 신경망 구조 혁신을 통해 이미지 인식 정확도를 높이는 모델군임.

## Ⅲ. 절차
- ASCII 흐름도
[이미지 입력] -> [특징 맵 생성] -> [차원 축소] -> [클래스 확률]
- 4단계 설명
1. 합성곱 연산: 필터를 이용해 이미지의 국소적 특징을 추출함.
2. 비선형 활성화: ReLU 등을 적용하여 복잡한 패턴을 학습함.
3. 풀링/스트라이드: 데이터 크기를 줄이며 중요한 정보만 유지함.
4. 소프트맥스: 최종 벡터를 클래스별 확률값으로 변환함.
> 요약: 계층적 특징 추출을 거쳐 최종 클래스를 할당함.

## Ⅳ. 문제점
- 모델의 거대화로 인한 연산 비용 상승 및 과적합 가능성이 존재함.

## Ⅴ. 개선방안
- 단기: Dropout, Weight Decay 등 규제 기법을 적극 활용함.
- 중기: MobileNet과 같은 경량 모델을 통해 모바일 환경에 대응함.
- 장기: Vision Transformer(ViT)를 활용해 CNN의 국소성 한계를 극복함.

## Ⅵ. 전망
- 데이터 편향성을 배제한 공정성(Fairness) 확보가 실무적 CSF이며, 향후 SSL(Self-Supervised Learning)을 통한 비지도 학습 효율화 및 설명 가능한 비전(XAI) 기술과의 결합으로 정밀 의료 진단 분야의 신뢰도를 확보할 전망임.
- 또한 연합 학습(Federated Learning)과 결합하여 개인정보 유출 없이 다양한 의료 기관의 데이터를 통합 학습하는 프라이버시 강화 분류 모델로 발전할 것임.
