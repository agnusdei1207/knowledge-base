## 미리 알고가기

- 이미지 분류: 입력 이미지 전체를 사전 정의된 클래스 중 하나 또는 여러 개로 판정하는 작업임
- CNN: 합성곱 필터로 지역 패턴을 추출하고 계층적으로 조합하는 신경망 구조임
- Feature Map: 필터가 추출한 엣지, 질감, 형태 같은 시각 특징의 2차원 표현임
- Softmax: 클래스별 점수를 확률처럼 정규화해 최종 클래스를 선택하는 함수임
- ResNet: skip connection으로 깊은 CNN의 기울기 소실 문제를 줄인 구조임
- EfficientNet: 깊이, 너비, 해상도를 함께 스케일링해 정확도와 연산량을 균형화한 구조임

## Ⅰ. 개요

- **정의**: 이미지 분류는 입력 이미지의 시각 특징을 추출하고 클래스별 확률을 계산해 이미지 전체의 범주를 판단하는 컴퓨터 비전 기술임
- **배경/필요성**: 대량 이미지 데이터를 사람이 직접 분류하기에는 비용과 일관성 한계가 있어, 반복 판정 업무를 자동화할 모델이 필요함
- **비유**: 사진 전체를 보고 `고양이`, `자동차`, `불량품` 같은 라벨을 자동으로 붙이는 검사원과 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| CNN 기반 분류 구조 설명 | Conv, Pool, FC, Softmax | 객체 탐지와 출력 차이 혼동 |
| 대표 모델 비교 | VGG, ResNet, EfficientNet | 깊을수록 무조건 좋다는 서술 |

> 요약: 이미지 분류는 한 장의 이미지에서 특징을 추출해 클래스 확률을 산출하는 기술이며, 위치보다 전체 범주 판단이 핵심임

## Ⅱ. 특징/비교

| 판단 기준 | VGG | ResNet | EfficientNet |
|:---|:---|:---|:---|
| 구조 특징 | 3x3 합성곱을 깊게 쌓은 단순 구조 | skip connection으로 잔차를 학습함 | 깊이·너비·해상도를 복합 스케일링함 |
| 강점 | 구조가 단순해 구현 복잡도가 낮음 | skip connection으로 깊은 층의 기울기 전달을 유지함 | 정확도 대비 FLOPs가 낮음 |
| 약점 | 파라미터와 연산량이 큼 | 구조가 깊어 추론 비용이 커질 수 있음 | 입력 해상도와 스케일링 설정이 중요함 |
| 선택 기준 | 교육·기준 모델 | 고정확도 범용 분류 | 엣지·클라우드 비용 균형 |

> 요약: 이미지 분류 모델은 정확도뿐 아니라 학습 안정성, 파라미터 수, 추론 환경을 기준으로 선택함

- **분류와 탐지 구분**: 분류는 이미지 전체 라벨을 출력하고, 객체 탐지는 위치 박스까지 출력함
- **전이 학습 기준**: 데이터가 적을수록 ImageNet 등 사전학습 가중치를 활용하는 것이 유리함
- **운영 기준**: Top-1 정확도 외에 클래스별 재현율, 추론 지연, 모델 크기를 함께 확인해야 함

## Ⅲ. 구성요소

```text
+-------------+      +-------------+      +-------------+
| Input Image | ---> | Conv Blocks | ---> | Feature     |
| pixels      |      | filters     |      | Maps        |
+------+------+      +------+------+      +------+------+
       |                    |                    |
       v                    v                    v
+-------------+      +-------------+      +-------------+
| Preprocess  |      | Pool / GAP  | ---> | Classifier  |
| resize norm |      | vectorize   |      | Softmax     |
+-------------+      +-------------+      +-------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 입력 이미지 | 분류 대상 픽셀 데이터이며 해상도와 색상 정규화가 모델 입력 조건임 | 검사 대상 |
| 합성곱 계층 | 작은 필터가 지역 패턴을 추출하고 깊은 층에서 고수준 특징을 만듦 | 확대경 |
| 활성화·정규화 | ReLU, BatchNorm으로 비선형성과 학습 안정성을 제공함 | 신호 정리기 |
| 풀링/GAP | 특징 맵 크기를 줄이고 위치 변화에 대한 강건성을 높임 | 요약 압축기 |
| 분류기 | 특징 벡터를 클래스 점수로 바꾸고 Softmax로 확률을 산출함 | 최종 판정대 |

> 요약: 이미지 분류기는 입력 전처리, 특징 추출, 특징 요약, 클래스 확률 계산을 연결한 구조임

## Ⅳ. 절차

```text
+-----------+     +-----------+     +-----------+     +-----------+
| Resize    | --> | Extract   | --> | Classify  | --> | Evaluate  |
| Normalize |     | Features  |     | Softmax   |     | Metrics   |
+-----------+     +-----------+     +-----------+     +-----------+
      |                 |                 |                 |
      v                 v                 v                 v
224x224 tensor     conv feature      class prob        accuracy/F1
```

1. **전처리**: 이미지를 고정 크기로 변환하고 채널별 평균·표준편차 기준으로 정규화함
2. **특징 추출**: Conv, BatchNorm, ReLU, Pooling 블록을 거치며 저수준에서 고수준 특징으로 변환함
3. **클래스 점수 산출**: GAP 또는 Flatten 후 FC 계층과 Softmax로 클래스별 확률을 계산함
4. **평가·배포**: 정확도, F1, confusion matrix, 추론 지연을 확인하고 요구사항에 맞게 배포함

> 요약: 이미지 분류 절차는 표준화된 입력을 CNN 특징으로 바꾸고 클래스 확률을 산출한 뒤 성능과 지연을 검증하는 과정임

## Ⅴ. 문제점

- **P1 깊은 망 학습 불안정**: 층이 깊어질수록 기울기 소실과 최적화 난도가 증가해 학습이 정체될 수 있음
- **P2 데이터 의존성과 과적합**: 라벨 데이터가 적거나 클래스 불균형이 크면 훈련 정확도만 높고 일반화 성능이 낮아짐
- **P3 엣지 추론 비용**: 고정확도 모델은 FLOPs와 파라미터가 커서 모바일·NPU 환경에서 지연과 전력 문제가 발생함

> 요약: 이미지 분류 모델은 깊이, 데이터 규모, 배포 자원 제약에서 주로 운영 문제가 발생함

## Ⅵ. 개선방안

- **P1 대응**: ResNet skip connection, BatchNorm, He/Xavier 초기화와 learning rate schedule을 적용함 (확인: 학습 손실 수렴)
- **P2 대응**: 전이 학습, 데이터 증강, 클래스 가중치, stratified validation으로 일반화를 높임 (확인: 클래스별 F1)
- **P3 대응**: EfficientNet, MobileNet, pruning, quantization으로 모델 크기와 연산량을 줄임 (확인: p95 지연, Top-1 유지율)

> 요약: 잔차 구조, 데이터 보강, 경량화 기법을 함께 적용해야 분류 정확도와 배포 가능성을 동시에 확보함

## Ⅶ. 전망

- **발전 방향**: CNN은 ViT 및 하이브리드 구조와 공존하며 제조·의료·엣지 비전에서 경량 고정확도 모델로 지속 활용될 전망임
- **기술사적 판단**: 위치 정보가 필요한 문제는 객체 탐지로, 이미지 전체 판정이면 분류로 문제를 명확히 구분해야 함
- **기술사 제언**: 답안에서는 대표 모델 이름보다 Conv-Pool-Classifier 구조와 모델 선택 기준을 먼저 설명해야 함
