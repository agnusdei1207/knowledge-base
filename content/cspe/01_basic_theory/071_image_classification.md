## 미리 알고가기

- 클래스 라벨: 이미지가 속하는 범주 정답임
- feature extractor: 시각 특징을 추출하는 백본 네트워크임
- top-k accuracy: 정답이 상위 $k$개 예측에 포함되는 비율임

## Ⅰ. 개요

- **정의/개념**: 이미지 분류는 입력 이미지가 어떤 클래스에 속하는지 예측하는 비전 과제로, ResNet, VGG, EfficientNet 같은 CNN 백본이 대표 구조임
- **배경/필요성**: 제품 식별, 품질 검사, 의료 판독처럼 이미지에서 의미 있는 범주를 빠르게 판별해야 하는 업무가 많음

## Ⅱ. 특징

- 시각 특징을 계층적으로 추출해 최종 클래스를 예측함
- VGG는 구조가 단순하고, ResNet은 깊은 학습에 강하며, EfficientNet은 효율 최적화에 강함
- 데이터 증강과 사전학습 효과가 매우 큼
- 클래스 불균형과 도메인 차이가 성능을 크게 흔들 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | VGG | ResNet | EfficientNet |
|:---|:---|:---|:---|
| 구조 특징 | 단순한 깊은 CNN | residual connection | 폭/깊이/해상도 동시 조정 |
| 장점 | 직관적 | 깊은 학습 안정성 | 효율성 |
| 단점 | 파라미터 많음 | 구조 복잡도 증가 | 튜닝 복잡 |
| 대표 적용 | 기준선, 교육용 | 범용 실전 | 모바일/효율형 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 입력 전처리 | 크기 조정, 정규화, 증강이며 데이터 품질 기반임 |
| 백본 네트워크 | 시각 특징을 추출하고 성능 핵심 축임 |
| 분류 헤드 | 특징을 클래스 확률로 변환하고 최종 예측부임 |
| 손실 함수 | 보통 cross-entropy를 사용하고 학습 목표임 |

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 이미지입력 | --> | 특징추출 | --> | 클래스점수 계산 | --> | 라벨예측 |
+----------+     +----------+     +----------+     +----------+
```

1. **이미지입력**: 전처리된 이미지를 모델에 입력함
2. **특징추출**: 백본이 에지, 패턴, 객체 수준 특징을 추출함
3. **클래스점수 계산**: 전역 특징을 클래스별 점수로 변환함
4. **라벨예측**: 가장 높은 확률 클래스를 선택함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 데이터 불균형이 성능을 왜곡해 다수 클래스 위주로 학습될 수 있음
   - 해결방안: class weighting, augmentation, re-sampling을 적용하고 macro-F1로 검증함
2. 문제: 도메인 차이로 일반화가 낮아질 수 있어 실제 현장 이미지가 학습셋과 다를 수 있음
   - 해결방안: transfer learning과 domain adaptation을 적용하고 domain gap로 검증함
3. 문제: 설명 가능성이 부족해 왜 해당 클래스로 분류했는지 파악이 어려움
   - 해결방안: Grad-CAM 등 시각화로 근거를 보조하고 explanation consistency로 검증함

## Ⅶ. 적용 사례

- 제조 검사에서는 제품 양품/불량을 분류함, 확인 지표는 accuracy와 recall임
- 의료 영상에서는 질환 여부를 판독함, 확인 지표는 sensitivity와 AUC임
- 콘텐츠 관리에서는 이미지 카테고리 자동 태깅을 수행함, 확인 지표는 top-1 accuracy임

## Ⅷ. 결론

이미지 분류의 핵심은 백본 선택보다 데이터 품질과 도메인 적합성에 있으므로, 모델 구조와 함께 증강과 전이 전략을 같이 설계해야 함.
