# 📖 【암기용】 개념 완전 이해

> 목적: 이 개념을 처음 보는 사람도 완벽히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 이미지 분류는 컴퓨터 비전의 핵심 문제로, 입력된 이미지 전체가 어떤 클래스(카테고리)에 속하는지 판별하는 딥러닝 기반 기술이다.
- **왜 필요한가**: 자율주행, 의료 영상 분석, 불량품 검출 등에서 사람의 눈을 대신하여 빠르고 정확하게 이미지를 식별하기 위해 필요하다.
- **핵심 직관**: 인간이 이미지를 볼 때 선, 면, 질감을 거쳐 사물을 인식하듯, CNN도 층이 깊어질수록 저수준(엣지)에서 고수준(의미) 특징을 추출하여 분류한다.

## 핵심 용어 정리

| 용어/표기 | 의미 | 비유·예 |
|:---|:---|:---|
| 이미지 분류 | 이미지 전체를 1개의 라벨로 판정 | "이 사진은 고양이다" |
| VGGNet | 3x3 작은 필터만 반복해 신경망을 깊게 쌓은 모델 | "기본 블록만으로 높게 쌓은 탑" |
| ResNet | 잔차 연결(Skip Connection)로 기울기 소실 문제를 해결해 초심층 학습을 가능케 한 모델 | "건너뛰는 샛길을 만들어 지름길 제공" |
| EfficientNet | 너비, 깊이, 해상도를 균형 있게 확장(Compound Scaling)하여 효율을 극대화한 모델 | "세로, 가로, 높이를 황금비율로 키운 상자" |

## 깊이 이해
- **배경·문제의식**: 초기 CNN 모델(AlexNet 등) 이후 정확도를 높이기 위해 층을 깊게 쌓았으나, 어느 순간 학습이 안 되는 기울기 소실(Vanishing Gradient) 문제가 발생했다.
- **작동 원리**: 
  - VGGNet은 필터 크기를 3x3으로 고정하고 층을 16/19층까지 늘려 특징 추출 성능을 입증했다. 
  - ResNet은 $H(x) = F(x) + x$ 라는 스킵 커넥션을 도입해 152층까지 깊이를 늘려도 기울기 소실을 막고 인간 수준의 인식률(Top-5 에러 3.57%)을 달성했다.
  - EfficientNet은 모델 크기를 무작정 키우지 않고, 깊이(Depth)·너비(Width)·해상도(Resolution)를 상수로 묶어 동시에 늘리는 Compound Scaling 규칙을 찾아내 최소 파라미터로 최대 성능을 냈다.
- **비유**: ResNet은 고속도로 옆에 샛길을 뚫어, 중간 휴게소가 막혀도 차가 계속 갈 수 있게 만든 설계다. EfficientNet은 자동차를 튜닝할 때 엔진만 키우지 않고, 바퀴와 차체도 황금비율로 같이 키워 밸런스를 맞춘 튜닝법이다.
- **구체 예시**: ImageNet 챌린지에서 ResNet-152는 60M 파라미터로 우승했고, EfficientNet-B7은 이보다 훨씬 적은 파라미터로 더 높은 정확도를 보여 모바일 환경 등에서도 활용 가능성을 열었다.
- **흔한 오해·주의점**: "층을 무조건 깊게 쌓으면 좋다"는 오해다. ResNet 같은 샛길(잔차 연결)이 없으면 오히려 성능이 떨어진다.

## 연결 개념
- CNN (합성곱 신경망) — 이미지 분류의 기본 구조
- 전이 학습 (Transfer Learning) — 미리 학습된 ResNet 등을 가져와 내 데이터에 맞게 재학습

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 이미지 분류 모델은 VGG(단순 깊이) → ResNet(잔차 연결) → EfficientNet(복합 스케일링)으로 발전하며 특징 추출 최적화 문제를 해결했다.
> 2. **가치**: 기울기 소실 방지와 자원 효율성(파라미터 수 대비 성능) 극대화를 통해 엣지 디바이스부터 클라우드까지 적용 범위를 넓혔다.
> 3. **판단 포인트**: 서비스의 가용 자원(지연시간·메모리)과 목표 정확도에 따라 적합한 모델 아키텍처와 스케일링 기법을 선택해야 한다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 이미지 분류 발전의 기술적 병목과 해결책 이해 | VGG(3x3), ResNet(Skip Connection), EfficientNet(Compound Scaling) | 모델명 나열, 해결 메커니즘 누락, "성능이 좋다" 식 빈 추상 표현 |

> 요약: 모델의 외형적 크기(깊이) 증가가 가져온 학습 저하 문제를 어떤 아키텍처 혁신으로 극복했는지 구체적 메커니즘을 제시해야 한다.

## Ⅰ. 개요 및 필요성

- 개요: 딥러닝 기반 이미지 분류는 픽셀 데이터에서 특징 패턴을 추출하여 이미지의 최종 클래스 확률을 예측하는 컴퓨터 비전 기술
- 배경: 망이 깊어질수록 특징 표현력은 증가하나, 파라미터 폭증과 기울기 소실(Vanishing Gradient)로 인해 최적화가 불가능해지는 한계 직면
- 필요성: 모바일·엣지 환경 적용을 위해 정확도(Top-1 Accuracy) 향상과 연산량(FLOPs) 절감을 동시에 만족하는 아키텍처 혁신 필수

---

## Ⅱ. 구조 및 구성요소

```text
Input Image -> [Convolutional Layers] -> [Pooling Layers] -> [Fully Connected] -> Class Probabilities
                 |                         |
                 +-> VGG/ResNet/EfficientNet의 핵심 블록 교체 적용
```

| 주요 모델 | 아키텍처 핵심 | 해결한 문제 |
|:---|:---|:---|
| VGGNet | 3x3 작은 필터 반복, 층 깊이(16~19단) 극대화 | 비선형성 증가 및 수용 영역(Receptive Field) 확보 |
| ResNet | 스킵 커넥션 $H(x) = F(x) + x$ | 심층망의 기울기 소실 방지 (152단 이상 학습 가능) |
| EfficientNet | 깊이·너비·해상도 Compound Scaling | 모델 크기 대비 정확도(파라미터 효율성) 극대화 |

> 요약: 이미지 분류 성능은 VGG의 깊이 확장, ResNet의 잔차 연결, EfficientNet의 복합 스케일링을 거치며 최적화 한계를 돌파했다.

---

## Ⅲ. 동작원리 및 흐름도

```text
이미지 전처리 -> 특징 추출 (Feature Extraction) -> 평탄화 (Flatten) -> 완전 연결 신경망 -> Softmax 분류
                  |
                  +-> ResNet: F(x)+x 연산으로 기울기 보존
                  +-> EfficientNet: 3차원 스케일 계수로 블록 크기 조정
```

- 1단계 [이미지 전처리]: 정규화 및 해상도 조정 (EfficientNet은 타겟 해상도로 변환)
- 2단계 [특징 추출]: 합성곱 블록을 통과하며 엣지·질감·형태 등 계층적 특징맵(Feature Map) 생성
- 3단계 [분류기 연산]: GAP(Global Average Pooling) 등으로 평탄화 후 완전 연결층 통과
- 4단계 [출력·분류]: Softmax 함수를 거쳐 클래스별 확률 분포(0~1) 산출 및 최종 라벨 결정

> 요약: 입력 이미지는 각 모델의 고유 합성곱 블록을 통과하며 고차원 특징으로 변환되고 최종 확률값으로 분류된다.

---

## Ⅳ. 특징
- [최적화 한계 돌파]: ResNet은 덧셈 연산 1개만 추가하여 추가 파라미터 없이 152층 이상의 초심층 학습 보장
- [자원 효율성 극대화]: EfficientNet-B7은 기존 GPipe 대비 파라미터 수를 8.4배 줄이면서도 정확도 84.3% 달성
- [전이 학습 용이성]: 사전 학습된 가중치(Pre-trained Weights)를 재사용해 소규모 데이터셋에서도 높은 분류 성능 확보

> 요약: 현대 이미지 분류 모델은 정확도 향상을 넘어, 제한된 연산 자원 내에서 추론 속도(Latency)와 메모리 사용량을 최소화하는 방향으로 발전했다.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | VGGNet | ResNet | EfficientNet | 선택 기준 |
|:---|:---|:---|:---|:---|
| 학습 깊이 | 16~19 층 | 50~152 층 이상 | 스케일(B0~B7)에 따라 가변 | 복잡성·정확도 요구사항 |
| 핵심 혁신 | 3x3 소형 필터 중첩 | Skip Connection | Compound Scaling | 파라미터 효율성 중시 여부 |
| 한계/단점 | 연산량(FLOPs) 과다 | 채널 수 증가 시 연산 부담 | 최적 스케일링 계수 탐색 비용 | 자원 제한(Edge vs Cloud) |

> 요약: 자원이 풍부한 서버 환경은 ResNet 기반 심층 모델을, 자원이 제한된 엣지 기기는 EfficientNet 기반 효율적 모델을 선택한다.

**리스크·대응:**
- [데이터 부족에 의한 과적합]: 데이터 편향 → Data Augmentation(CutMix, MixUp) 및 ImageNet 전이 학습 적용 (지표: 검증 데이터 오차율)
- [추론 지연(Latency) 증가]: 무거운 모델 구조 → Quantization(INT8), Pruning 적용 (지표: p99 지연 50ms 이하)

**도입 후 점검 지표:**
- 성능/효율: 추론 시간 10ms/장 이하 — 실측 TPS 및 FLOPs 모니터링
- 품질/운영: Top-1, Top-5 Accuracy 90% 이상 — 평가 데이터셋 기반 Confusion Matrix 측정

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. [기반 모델 선정]: 엣지 디바이스 검사기는 EfficientNet-B0를, 클라우드 정밀 분석 서버는 ResNet-152를 기본 백본(Backbone)으로 도입
2. [전이 학습 파인튜닝]: 마지막 완전 연결층(FC Layer)만 도메인 특화 클래스(예: 불량 유형)로 교체하여 재학습(Fine-tuning)
3. [경량화 배포]: ONNX 형식으로 변환 후 TensorRT를 적용하여 엣지 추론 속도를 3배 이상 가속

**결론:**
- 기술사 판단: 이미지 분류 모델 도입 시 무조건 깊고 복잡한 모델을 찾기보다, 목표 지연시간(Latency)과 가용 메모리(VRAM) 기준에 맞춰 ResNet과 EfficientNet을 취사선택해야 한다.
- 향후 방향: 최근에는 CNN 기반을 넘어, 전역적 문맥(Global Context) 파악에 유리한 Vision Transformer(ViT) 계열로 발전하고 있다.
