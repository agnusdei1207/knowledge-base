## 미리 알고가기

- 합성곱 백본($Backbone$): 이미지 분류를 위해 특징 추출의 뼈대가 되는 핵심 합성곱층들로 구성된 신경망임
- 잔차 연결($Residual$ $Connection$): 입력을 출력에 직접 더해주는($x + f(x)$) 숏컷(지름길) 구조로, 경사 소실 문제를 원천 차단함
- 채널/깊이/해상도: 이미지 분류 모델의 용량을 키우는 3대 축으로, 각각 필터 수, 레이어 개수, 입력 화소 해상도를 지칭함
- 컴파운드 스케일링($Compound$ $Scaling$): 성능 효율을 극대화하기 위해 네트워크의 채널 폭, 깊이, 이미지 해상도 비율을 일정 상수에 맞춰 함께 늘려주는 기법임

## Ⅰ. 개요

- **정의/개념**: 이미지 분류는 기계가 입력받은 2차원 픽셀 배열(이미지)을 컴퓨터 비전 아키텍처에 통과시켜 해당 이미지가 대표하는 고유한 범주(클래스)를 판정해내는 딥러닝 기법임
- **배경/필요성**: 제조업의 미세 결함 검출, 의료 X-ray 병변 고속 감지, 자율주행 도로 물체 정체 판별 등 대규모 시각 데이터를 빠르고 표준화된 정확도로 무인 판별해야 할 요구가 커져 등장함

## Ⅱ. 특징

- 인풋층에서 추출된 저수준 특징(점, 선)들이 깊은 합성곱층을 지나면서 고수준의 의미론적 개념(질감, 구체적 형상)으로 융합되는 계층적 공간 표상 능력을 지님
- 네트워크가 너무 깊어질 때 경사가 중간에 사라지는 기울기 소실($Gradient$ $Vanishing$) 문제를 해결하기 위해 $ResNet$의 지름길 연산이 비전의 표준 아키텍처가 됨
- 성능 효율에 극대화된 $EfficientNet$은 하드웨어 리소스가 제약된 온디바이스($On-device$) 환경에서도 대규모 모델과 유사한 분류 성능을 낼 수 있게 도움을 줌

## Ⅲ. 종류 및 비교

| 판단 기준 | VGGNet (초기 거대 모델) | ResNet (지름길 도입) | EfficientNet (복합 최적화) |
|:---|:---|:---|:---|
| **핵심 아키텍처** | $3 \times 3$ 소형 커널을 여러 층 중첩 | 잔차 연결 ($Skip$ $Connection$) | 컴파운드 스케일링 규칙 적용 |
| **최대 강점** | 구조가 단순하여 구현 및 튜닝 용이 | 100층 이상의 초고층 학습 가능 | 가벼운 파라미터 대비 압도적 정확도 |
| **한계점** | 파라미터 수 폭증 (메모리 낭비 심함) | 지름길 연산으로 연산 구조 다소 복잡 | 실시간 변형 적용 시 스케일 최적화 복잡 |
| **일반화 성능** | 중간 | 매우 높음 | 극도로 높음 |

> 요약: VGG는 직관적인 중첩을, ResNet은 잔차 지름길을, EfficientNet은 최적 비율의 스케일 조정을 대변함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 데이터 증강 ($Augmentation$) | 회전, 색감 변형, 크롭 등을 통해 이미지의 개수를 인위적으로 늘려 모델의 과적합을 방지함 |
| 컨볼루션 블록 | 합성곱, 배치 정규화($BN$), 활성화 함수($ReLU$)를 결합하여 공간적 패턴을 훑는 연산 블록임 |
| 글로벌 에버리지 풀링 | 공간 정보를 1개의 대표 평균값 벡터로 압축하여 완전연결층의 파라미터 폭증을 차단함 |
| 소프트맥스 분류 헤드 | 추출된 전역 특징 벡터를 각 분류 범주에 속할 확률값 분포로 전환함 |

```text
[ 이미지 분류 표준 아키텍처 ]
Input -> [Data Augmentation] -> [Conv/BN/ReLU Stack] -> [Global Average Pooling] -> [FC Head] -> Softmax Output
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 전처리/증강  | --> | 합성곱 특징추출| --> | 공간 벡터압축| --> | 확률분포 판정|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **입력 변형** — 들어온 이미지를 네트워크 표준 규격(예: $224 \times 224$)에 맞춰 리사이징하고 무작위 회전이나 노이즈 추가 증강을 실행함
2. **패턴 검출** — 백본 신경망의 컨볼루션 레이어들을 차례로 지나면서 국소 특징 맵($Feature$ $Map$)을 정밀하게 추출하고 채널을 늘려 나감
3. **전역 압축** — 고차원 특징 맵들을 전역 평균 풀링($GAP$)하여 채널별 의미 대표값을 모은 1차원 밀집 벡터로 고속 압축함
4. **오차 학습** — 분류 헤드가 이 벡터를 받아 클래스별 예상 스코어를 구하고, 실제 정답 분포와의 크로스 엔트로피 오차를 연산하여 신경망 전체를 갱신함

## Ⅵ. 실무 적용 및 유의점

1. 특정 클래스의 데이터 수가 너무 적어(예: 불량 제품 1% 미만) 편향적 학습이 일어날 경우, 단순 정확도는 높아 보이지만 불량을 잡지 못하므로 '클래스별 가중치($Class$ $Weight$)'를 주거나 정밀 오차를 판정하는 'F1-Score'를 검증 척도로 써야 함
2. 이미지 분류 모델의 판정 이유가 불명확한 블랙박스 문제를 완화하기 위해, 추론 결과 도출 시 어떤 픽셀 영역이 분류에 가장 큰 기여를 했는지 시각화해 주는 'Grad-CAM' 솔루션을 실무 인터페이스에 결합해야 함

## Ⅶ. 결론

- 이미지 분류는 픽셀의 단순 집합을 의미론적 정보로 해독하는 컴퓨터 시각 지능의 기본 뼈대이며, 설계자는 클래스 불균형에 대응하는 통계적 전략과 실무적 설명 가능성을 확보하여 현업에서 실제 작동 가능한 시각 판독기를 배치해야 함
