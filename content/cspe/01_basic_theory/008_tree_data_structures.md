# 트리 구조 - B-Tree·AVL·Red-Black (Tree Data Structures)

## 1. 개요

- **정의/개념**: 트리는 부모-자식으로 갈라지는 계층 구조이고, 검색 트리는 "왼쪽 < 나 < 오른쪽" 규칙으로 매 단계 후보의 절반을 버리며 값을 찾는 자료구조다.
- **배경/필요성**: 배열은 중간 삽입·삭제가 느리고 해시는 정렬·범위 검색을 못 하는데, 트리는 키를 정렬된 채 담아 이 빈틈을 메운다. 단, 편향되면 탐색이 `O(n)`으로 느려져 스스로 균형을 잡는 트리가 필요하다.

## 2. 특징 및 비교

세 트리 모두 최악에도 높이를 `O(log n)`으로 유지하지만, 균형을 잡는 강도와 대상 저장 매체가 다르다.

| 구분 | AVL | Red-Black | B-Tree |
|:---|:---|:---|:---|
| 균형 방식 | 좌우 높이차 ≤ 1 (엄격) | 색 규칙 (완화) | 노드당 다수 키 (다진) |
| 갱신 비용 | 회전 잦음 | 회전 적음 | 분할·병합 |
| 강점 | 조회 최적 | 조회·갱신 균형 | 디스크 I/O 최소 |
| 적용 | 조회 위주 메모리 | 범용 map/set | DB·파일시스템 인덱스 |

> 요약: 조회 위주면 AVL, 갱신이 섞이면 Red-Black, 디스크면 B-Tree.

AVL은 균형을 가장 엄격히 지켜 조회가 빠른 대신 갱신마다 회전이 잦고, Red-Black은 색 규칙으로 균형을 완화해 회전을 줄여 범용 컨테이너의 기본이 된다. B-Tree는 한 노드에 키를 여러 개 담아 트리를 낮게 만들어, 블록 단위로 읽는 디스크에서 접근 횟수를 최소화한다.

## 3. 구성요소/구조

```text
        [50]
       /    \
    [30]    [70]        왼쪽 < 부모 < 오른쪽
    /  \    /  \
 [20][40][60][80]       리프: 값의 끝, 범위 순회 지점
```

탐색은 루트에서 시작해 키 비교로 한쪽 가지만 따라 내려가므로 단계마다 후보가 절반으로 준다.

- **루트·키**: 탐색 시작점이자 "왼쪽 < 나 < 오른쪽" 정렬 기준
- **자식 포인터**: 키 비교 결과에 따라 한쪽 가지로만 분기
- **균형 정보**: 높이차·색·키 수로 편향을 억제해 높이를 제한
- **리프**: 값의 끝이자 범위 검색 시 순회 지점

트리 성능은 루트에서 리프까지의 높이가 좌우하며, 세 트리가 각자의 방식으로 지키려는 것은 결국 높이를 `log n`으로 제한하는 것이다.

## 4. 문제점 및 개선방안

1. **편향**: 균형 규칙이 없는 BST에 정렬된 키를 순서대로 넣으면 한 줄로 늘어져 탐색이 `O(n)`이 된다.
   - **개선방안**: 삽입·삭제마다 균형을 재조정하는 AVL·Red-Black·B-Tree 사용 (확인: 최악 높이 `O(log n)`)
2. **균형 유지 비용**: 회전·분할·병합이 갱신마다 따라오므로 갱신이 잦으면 부담이 된다.
   - **개선방안**: 조회 위주면 AVL, 갱신 혼재면 Red-Black으로 워크로드에 맞춤 (확인: 조회/갱신 지연)
3. **매체 불일치**: 디스크 인덱스에 이진 트리를 쓰면 노드마다 디스크 접근이 발생해 높이만큼 반복된다.
   - **개선방안**: 디스크·DB는 높이가 낮은 B-Tree/B+Tree 사용 (확인: 질의당 디스크 읽기 수)

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| DB 인덱스 | B+Tree로 정렬 출력·범위 질의 지원 | 트리 높이, 페이지 읽기 수 |
| 언어·커널 map/set | Red-Black으로 정렬 순회·로그 시간 갱신 | 조회·삽입 지연 |
| 파일시스템 | B-Tree 계열로 메타데이터·블록 위치 관리 | 디스크 I/O 횟수 |

> 요약: 정렬·범위는 트리, 디스크는 B계열, 메모리 범용은 Red-Black.

## 6. 결론

트리는 배열과 해시가 못 하는 정렬·범위 검색을 로그 시간에 제공하지만 균형이 깨지면 이점이 사라진다. 따라서 선택은 워크로드(조회/갱신 비율)와 저장 매체(메모리/디스크)에 맞춰 AVL·Red-Black·B-Tree 중 어느 균형 트리를 쓸지로 귀결된다.
