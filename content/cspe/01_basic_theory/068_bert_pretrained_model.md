## 미리 알고가기

- 트랜스포머 인코더: 입력 토큰 전체를 양방향 어텐션으로 표현하는 구조임
- 셀프 어텐션: 문장 내 토큰 간 중요도를 계산하는 연산임
- 마스크 언어 모델링(MLM): 일부 토큰을 마스킹하고 양방향 문맥으로 원래 토큰을 예측하는 사전학습 과제임
- 다음 문장 예측(NSP): 두 번째 문장이 첫 번째 문장 뒤에 실제로 이어지는지 예측하는 사전학습 과제임
- 파인튜닝: 사전학습 모델을 특정 업무 데이터로 미세 조정하는 과정임
- 서브워드 분절(WordPiece): 빈도가 높은 문자열 조각을 어휘로 구성하는 방식임
- 정적 단어 임베딩·자기회귀 언어 모델(Word2Vec·GPT): 단어별 고정 벡터를 학습하는 방식과 다음 토큰을 생성하는 모델임
- 문장 대표 벡터([CLS]): 입력 전체를 대표하도록 문장 분류에 사용하는 BERT의 첫 토큰 표현임
- 모델 경량화: 모델 크기와 연산량을 줄여 제한된 장치에서도 실행하도록 만드는 작업임
- 95백분위 지연(p95): 측정한 응답의 95%가 이 값 이하에 포함되는 지연 시간임

## 작성 근거(검토용)

- 개요는 BERT의 구조, 학습 방식, 활용 과제를 한 문장에 묶어 출제 키워드를 회수함
- 양방향 문맥·MLM·전이 활용·문맥별 임베딩은 BERT의 고유 판단축임
- Ⅲ은 Word2Vec·GPT와 비교해 정적 표현, 이해 모델, 생성 모델의 차이를 드러냄
- Ⅳ는 토큰·세그먼트·위치 임베딩과 인코더·출력 헤드의 관계를 보여주도록 구성함
- 입력 길이 제한과 추론 비용은 BERT 배포의 핵심 조건임

## Ⅰ. 개요

- **정의/개념**: BERT는 트랜스포머 인코더를 기반으로 양방향 문맥을 학습한 뒤 분류·독해·개체명 인식에 파인튜닝하는 사전학습 언어 모델임
- **배경/필요성**: 고정 벡터 모델과 단방향 생성 모델은 문맥에 따른 의미 변화를 반영하지 못하므로 양방향 사전학습 표현이 필요함

## Ⅱ. 특징

- 양방향 셀프 어텐션으로 좌우 문맥을 동시에 반영함
- 원형 BERT는 MLM으로 마스크 토큰을 복원하고 NSP로 문장 관계를 판정함
- 하나의 사전학습 백본을 여러 자연어 과제에 재사용함
- 문맥에 따라 같은 단어의 임베딩이 달라짐

## Ⅲ. 종류 및 비교

| 판단 기준 | Word2Vec | BERT | GPT |
|:---|:---|:---|:---|
| 문맥 메커니즘 | 고정 문맥 창 | 양방향 인코더 | 인과 디코더 |
| 출력 범위 | 고정 단어 벡터 | 문맥 토큰 벡터 | 다음 토큰 분포 |
| 주요 리스크 | 다의어 구분 불가 | 입력 길이 한계 | 사실 오류 생성 |

> 요약: Word2Vec은 고정 단어 벡터, BERT는 양방향 문맥 벡터, GPT는 다음 토큰 분포를 산출함.

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| WordPiece 토큰화 | 미등록어를 줄이는 서브워드 입력 |
| 입력 임베딩 | 토큰·세그먼트·위치 벡터의 합 |
| 인코더 스택 | 양방향 어텐션·피드포워드 반복 계층 |
| 출력 헤드 | 분류·독해·개체명 인식 출력층 |

> 요약: BERT는 WordPiece 입력에 토큰·세그먼트·위치 벡터를 더하고 인코더와 출력 헤드로 업무별 결과를 산출함.

```text
토큰 ID + 세그먼트 ID + 위치 ID
        -> 임베딩 합
        -> 트랜스포머 인코더 스택
        -> 문장 대표 벡터([CLS]) 또는 토큰 벡터
        -> 출력 헤드
```

## Ⅴ. 원리 및 절차 흐름도

```text
사전학습 말뭉치 -> MLM/NSP 학습 -> 문맥 임베딩 -> 파인튜닝 -> 업무 적용
```

1. 대규모 말뭉치를 WordPiece 토큰으로 변환함
2. 일부 토큰을 양방향 문맥으로 복원하고 두 문장의 연결 관계를 판정함
3. 사전학습된 인코더가 문맥 벡터를 생성함
4. 업무별 데이터로 출력 헤드를 붙여 파인튜닝함
5. 파인튜닝된 모델을 분류·독해·개체명 인식 업무에 적용함

> 요약: BERT는 사전학습 인코더를 출력 헤드와 결합해 문맥 이해 모델로 전이함.

## Ⅵ. 실무 사례

1. 장문 문서 분류는 문서를 겹치게 나누어 처리하고 정확도·추론 지연으로 검증함
2. 모바일 BERT 서비스는 모델 경량화를 적용하고 정확도·p95 추론 지연으로 검증함

## Ⅶ. 결론

- BERT는 양방향 문맥 표현을 활용하는 과제에 적용하고 입력 길이와 추론 비용을 서비스 지연 한도에 맞춰야 함
