## 미리 알고가기

- 트랜스포머 인코더($Transformer$ $Encoder$): 입력 시퀀스의 모든 토큰 간 관계(어텐션)를 양방향으로 동시에 고려하여 특징 벡터를 추출하는 아키텍처임
- 셀프 어텐션($Self-attention$): 입력 문장 내의 단어들이 서로 어떤 관계를 맺고 있는지 가중치를 계산하여 의미적 거리를 파악하는 기법임
- 마스크 언어 모델 ($MLM$): 문장 내의 임의의 단어를 가리고($[MASK]$), 주변 문맥 단어들을 통해 가려진 단어가 무엇인지 맞히도록 학습하는 방식임
- 다음 문장 예측 ($NSP$): 두 문장이 주어졌을 때, 두 번째 문장이 첫 번째 문장 바로 뒤에 이어지는 진짜 문장인지 맞히도록 이진 분류하는 학습임

## Ⅰ. 개요

- **정의/개념**: BERT는 트랜스포머의 인코더($Encoder$) 블록을 깊게 쌓은 구조로, 텍스트의 좌우 양방향 문맥을 동시에 반영하여 문맥 동적 임베딩을 수행하고, 파인 튜닝을 통해 다양한 다운스트림 자연어 태스크를 해결하는 사전학습($Pre-trained$) 모델임
- **배경/필요성**: 기존의 단방향 언어 모델은 뒤에 나오는 단어 정보를 읽지 못해 문장의 전체 맥락을 파악하는 데 명확한 한계가 있으므로, 텍스트의 전체 문맥을 완벽히 흡수하는 공통 인코더 백본이 필요해져 도입됨

## Ⅱ. 특징

- 마스크 언어 모델($MLM$) 기법을 최초로 도입하여, 이전 시점 단어만 학습 타깃으로 삼는 단방향 제약에서 벗어나 문장 중간에 구멍을 뚫어놓고 양방향 셀프 어텐션으로 단어를 유추하도록 학습함
- 대용량 말뭉치(위키피디아, 도서 등)로 먼저 일반 언어 지식을 학습시킨 뒤, 분류, 개체명 인식, 기계 독해 등 목표 과제에 맞게 상단 분류 레이어만 얹어서 가중치를 살짝 재튜닝($Fine-tuning$)하는 2단계 학습 방법론의 유행을 주도함
- 문장 속에서 단어의 상대적 위치를 표현하기 위해 '포지셔널 임베딩($Positional$ $Embedding$)'을 사용하며, 문맥을 반영하여 다의어 표현이 동적으로 변함

## Ⅲ. 종류 및 비교

| 판단 기준 | Word2Vec (정적) | BERT (인코더 중심) | GPT (디코더 중심) |
|:---|:---|:---|:---|
| **문맥 반영 방향** | 단어 주변 고정 범위 | 양방향 ($Bidirectional$) | 단방향 순방향 ($Causal$) |
| **모델 구조** | 단층 가중치 행렬 | 트랜스포머 인코더 스택 | 트랜스포머 디코더 스택 |
| **주요 학습 과제** | 문맥 단어 예측 | $MLM$ (마스킹), $NSP$ (문장 예측) | 다음 단어 자동 예측 ($Next$ $Token$) |
| **최적 적용 분야** | 가벼운 임베딩, 특징 추출 | 문서 분류, 감성 분석, 기계 독해 | 챗봇, 소설 작성, 문장 요약 |

> 요약: Word2Vec은 정적 단어 표현에, BERT는 양방향 문맥 이해에, GPT는 단방향 순차 생성에 특화됨.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 토큰 임베딩 | $WordPiece$ 방식으로 분절된 단어 토큰들을 정밀 벡터로 변환하는 입력부임 |
| 세그먼트 임베딩 | 두 문장이 입력되었을 때 첫 번째 문장($Sentence$ $A$)과 두 번째 문장($Sentence$ $B$)을 구분해 주는 신호임 |
| 포지션 임베딩 | 순차 구조가 없는 트랜스포머 모델을 위해 단어의 문장 내 위치 순서 정보를 주는 벡터임 |
| $[CLS]$ 토큰 | 문장 전체의 요약 의미 벡터를 담고 있어, 텍스트 분류 성능 평가의 기준점으로 사용됨 |

```text
[ BERT 입력 표현 결합 구조 ]
Input Token:  [CLS]    자     연    어    처리    는    [SEP]
Token Embed:   E_cls   E_자   E_연   E_어   E_처리  E_는   E_sep
Segment Embed: E_A     E_A    E_A    E_A    E_A     E_A    E_A
Position Embed:E_0     E_1    E_2    E_3    E_4     E_5    E_6
- 세 임베딩 벡터를 요소별 합산(Element-wise Sum)하여 최종 입력으로 사용함
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 텍스트 입력  | --> | MLM/NSP 학습 | --> | 의미 벡터표현| --> | 미세 조정학습|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **임베딩 주입** — 입력 텍스트를 토큰화하고 토큰, 세그먼트, 포지션 임베딩을 합산하여 트랜스포머 인코더 층으로 통과시킴
2. **양방향 연산** — 모든 토큰이 서로를 참조하는 멀티 헤드 셀프 어텐션($Multi-head$ $Self-attention$)을 여러 레이어에 걸쳐 수행함
3. **사전학습** — 임의로 15% 가려진 마스크 토큰의 원래 글자를 복원하고, 문장 $A$와 $B$가 이어지는 문장인지 동시에 학습시켜 기반 언어 지식을 적립함
4. **다운스트림 파인튜닝** — 완성된 BERT 백본 위에 스팸 분류용 시그모이드나 기계독해용 포인터 레이어를 붙인 후, 타깃 데이터셋으로 미세 조정함

## Ⅵ. 실무 적용 및 유의점

1. BERT는 입력 텍스트의 길이가 최대 512 토큰으로 고정되어 있어 수십 페이지에 달하는 긴 문서를 한 번에 인코딩하면 오류가 나거나 정보가 잘리므로, 슬라이딩 윈도우 방식으로 분할하거나 긴 시퀀스를 처리하는 '롱포머($Longformer$)' 모델을 도입해야 함
2. 실무 배포 시 BERT-Base 기준 파라미터가 1억 1천만 개에 달해 모바일 기기나 저성능 서버에서 추론 지연이 발생할 수 있으므로, 지식 증류($Knowledge$ $Distillation$)를 통해 모델 크기를 줄인 'DistilBERT'나 양자화($Quantization$)를 적용해야 함

## Ⅶ. 결론

- BERT는 자연어의 입체적인 맥락을 완벽히 흡수하여 기계 독해의 시대를 연 역사적 아키텍처이며, 설계자는 모델의 양방향 강점을 살려 문서의 의도와 감성을 파악하고, 경량화 필터링을 통해 서비스 가용성을 확보해야 함
