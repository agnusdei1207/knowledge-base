## 미리 알고가기

- 트랜스포머 인코더: 입력 토큰 전체를 양방향 어텐션으로 표현하는 구조임
- 셀프 어텐션: 문장 내 토큰 간 중요도를 계산하는 연산임
- MLM (Masked Language Model): 일부 토큰을 가리고 주변 문맥으로 복원하는 사전학습 과제임
- NSP (Next Sentence Prediction): 두 문장이 이어지는 관계를 판정하는 사전학습 과제임
- 파인튜닝: 사전학습 모델을 특정 업무 데이터로 미세 조정하는 과정임

## 작성 근거(검토용)

- 개요는 BERT의 구조, 학습 방식, 활용 과제를 한 문장에 묶어 출제 키워드를 회수함
- 양방향 문맥·MLM·전이 활용·동적 임베딩은 BERT의 고유 판단축임
- Ⅲ은 Word2Vec·GPT와 비교해 정적 표현, 이해 모델, 생성 모델의 차이를 드러냄
- Ⅳ는 입력 임베딩 3종과 인코더, 태스크 헤드를 나눠 구조 이해를 돕도록 구성함
- 입력 길이 제한과 추론 비용은 BERT 배포의 핵심 조건임

## Ⅰ. 개요

- **정의/개념**: BERT는 트랜스포머 인코더를 기반으로 양방향 문맥을 학습한 뒤 분류·독해·개체명 인식에 파인튜닝하는 사전학습 언어 모델임
- **배경/필요성**: 문장 전체 문맥을 반영하는 언어 이해를 위해 양방향 사전학습 표현 모델이 필요함

## Ⅱ. 특징

- 양방향 셀프 어텐션으로 좌우 문맥을 동시에 반영함
- MLM으로 문장 중간의 의미를 복원하며 언어 지식을 학습함
- 하나의 사전학습 백본을 여러 자연어 과제에 재사용함
- 문맥에 따라 같은 단어의 임베딩이 달라짐

## Ⅲ. 종류 및 비교

| 판단 기준 | Word2Vec | BERT | GPT |
|:---|:---|:---|:---|
| 표현 방식 | 정적 단어 벡터 | 양방향 문맥 벡터 | 순방향 생성 벡터 |
| 구조 | 얕은 예측 모델 | 트랜스포머 인코더 | 트랜스포머 디코더 |
| 학습 목표 | 주변 단어 예측 | 마스크 토큰 복원 | 다음 토큰 예측 |
| 강점 | 가볍고 빠름 | 문장 이해 과제 강함 | 생성 과제 강함 |
| 한계 | 다의어 취약 | 긴 문서와 추론 비용 | 환각과 검증 필요 |

> 요약: BERT는 정적 표현보다 문맥 이해에 강하고, GPT와 달리 생성보다 이해 과제에 적합함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| WordPiece 토큰 | 희소 단어를 서브워드로 나누어 입력함 |
| 토큰 임베딩 | 토큰 ID를 벡터로 변환함 |
| 세그먼트 임베딩 | 문장 A와 문장 B를 구분함 |
| 위치 임베딩 | 토큰 순서 정보를 입력에 더함 |
| 인코더 스택 | 양방향 어텐션과 피드포워드 계층을 반복함 |
| 태스크 헤드 | 분류, 독해, 개체명 인식 출력층을 담당함 |

> 요약: BERT 입력은 세 임베딩의 합으로 만들고 인코더와 태스크 헤드가 의미를 변환함.

```text
토큰 ID + 세그먼트 ID + 위치 ID
        -> 임베딩 합
        -> 트랜스포머 인코더 스택
        -> [CLS] 또는 토큰 벡터
        -> 태스크 헤드
```

## Ⅴ. 원리 및 절차 흐름도

```text
사전학습 말뭉치 -> MLM/NSP 학습 -> 문맥 임베딩 -> 파인튜닝 -> 태스크 적용
```

1. 대규모 말뭉치를 WordPiece 토큰으로 변환함
2. 일부 토큰을 가리고 양방향 문맥으로 원래 토큰을 맞힘
3. 사전학습된 인코더가 문맥 벡터를 생성함
4. 업무별 데이터로 출력 헤드를 붙여 파인튜닝함

> 요약: BERT는 사전학습 인코더를 태스크 헤드와 결합해 문맥 이해 모델로 전이함.

## Ⅵ. 실무 사례

1. 문서 분류와 질의응답에는 BERT가 강하지만 입력 길이 제한으로 긴 문서가 잘리므로 청크 분할과 슬라이딩 윈도우 성능을 확인함
2. BERT는 추론 비용이 크므로 모바일·실시간 서비스에는 경량 모델·지식 증류·양자화를 적용하고 지연 시간을 측정함

## Ⅶ. 결론

- BERT는 양방향 문맥 이해에 강한 사전학습 백본이며, 입력 길이와 추론 비용을 통제해야 실무 적용성이 확보됨
