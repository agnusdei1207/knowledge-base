## 미리 알고가기

- Transformer encoder: 입력 문맥을 양방향으로 인코딩하는 구조임
- MLM: 일부 토큰을 가리고 맞히게 하는 사전학습 과제임
- fine-tuning: 사전학습 표현을 특정 과제에 맞게 조정하는 단계임

## Ⅰ. 개요

- **정의/개념**: BERT는 Transformer encoder 기반 양방향 문맥 표현을 대규모 말뭉치로 사전학습한 언어 모델로, 다양한 NLP 과제에 전이 학습되는 범용 기반 모델임
- **배경/필요성**: 정적 단어 임베딩은 문맥에 따른 의미 변화를 반영하지 못하므로, 문장 전체 문맥을 반영한 표현 학습이 필요함

## Ⅱ. 특징

- 양방향 self-attention으로 좌우 문맥을 동시에 반영함
- 사전학습 후 미세조정으로 다양한 과제에 빠르게 적응함
- 문맥 기반 임베딩이라 다의어 처리 성능이 높음
- 추론 비용이 크고 생성 작업에는 encoder-only 구조 한계가 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | Word2Vec | BERT | GPT |
|:---|:---|:---|:---|
| 문맥 반영 | 없음 | 양방향 | 단방향 생성 중심 |
| 구조 | 정적 임베딩 | Encoder | Decoder |
| 강점 | 단순, 빠름 | 이해 과제 | 생성 과제 |
| 대표 적용 | 전통 NLP | 분류, 질의응답 | 생성, 대화 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 토큰 임베딩 | 단어와 위치 정보를 포함하고 입력 표현 기반임 |
| self-attention | 모든 토큰 관계를 계산하고 문맥 이해 핵심임 |
| encoder stack | 여러 층으로 표현을 정제하고 의미 계층을 형성함 |
| 사전학습 목표 | MLM, NSP 등이며 범용 언어지식 학습 장치임 |

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 토큰입력 | --> | 마스킹학습 | --> | 문맥표현 생성 | --> | 미세조정 |
+----------+     +----------+     +----------+     +----------+
```

1. **토큰입력**: subword와 위치 정보를 입력함
2. **마스킹학습**: 일부 토큰을 가리고 문맥으로 복원함
3. **문맥표현 생성**: encoder가 양방향 의미 벡터를 만듦
4. **미세조정**: 분류, QA 등 목표 과제에 맞게 조정함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 모델 크기와 추론 비용이 커 실시간 서비스 배포가 부담됨
   - 해결방안: DistilBERT, pruning, quantization을 적용하고 latency로 검증함
2. 문제: 긴 문서 처리에 제약이 있음 입력 길이 제한이 존재함
   - 해결방안: chunking, Longformer류 모델을 사용하고 context coverage로 검증함
3. 문제: 도메인 특화 용어에 약할 수 있어 일반 말뭉치와 분포 차이가 큼
   - 해결방안: domain adaptive pretraining을 수행하고 task F1로 검증함

## Ⅶ. 적용 사례

- 문서 분류에서는 계약서, 뉴스, 고객 문의를 분류함, 확인 지표는 macro-F1임
- 질의응답에서는 문서 문맥에서 답변 span을 찾음, 확인 지표는 EM/F1임
- 개체명 인식에서는 문맥을 반영한 태깅을 수행함, 확인 지표는 entity F1임

## Ⅷ. 결론

BERT의 핵심은 양방향 문맥 이해에 있으므로, 생성보다 이해 중심 과제에서 강점을 살리고 배포 시 비용 최적화를 함께 고려해야 함.
