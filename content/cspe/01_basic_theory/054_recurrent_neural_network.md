# 📖 【암기용】 개념 완전 이해

> 목적: 이 개념을 처음 보는 사람도 완벽히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: **순환(Recurrent) 구조**로 이전 시점의 은닉 상태(Hidden State)를 현재 입력과 함께 처리하여, 순서가 의미를 갖는 시퀀스 데이터(문장, 시계열)를 다루는 신경망
- **왜 필요한가**: 일반 신경망(FC·CNN)은 입력 데이터의 순서를 반영할 장치가 없다. "나는 밥을 먹었다"에서 '나는' 뒤에 '밥을'이 온다는 시간적(순차적) 맥락을 이해하려면 이전 상태를 기억하는 메모리가 필수적이다.
- **핵심 직관**: 책을 읽을 때 앞 문장의 내용을 머릿속(은닉 상태)에 기억해두고 현재 문장을 해석하는 것과 똑같다.

## 핵심 용어 정리 (내부에 등장하는 것들)

| 용어 | 의미 | 비유 |
|:---|:---|:---|
| 순환 구조 (Recurrent) | 이전 시점의 출력을 현재 시점의 입력으로 되먹임하는 구조 — 이 개념의 핵심 키워드 | 앞 문장을 기억한 채 다음 문장 읽기 |
| 은닉 상태 (Hidden State, $h_t$) | 시점 $t$까지 읽은 내용을 요약해 담고 있는 벡터(기억) | 지금까지 읽은 내용의 머릿속 요약 |
| 타임스텝 (Time Step, $t$) | 시퀀스를 한 칸씩 처리하는 시간 단위(단어 1개, 센서값 1개 등) | 페이지를 한 장씩 넘기는 순간 |
| BPTT (Backpropagation Through Time) | 시점 $t$에서 $t=1$까지 시간을 거슬러 올라가며 수행하는 역전파 | 오늘 실수의 원인을 며칠 전까지 되짚기 |
| 장기 의존성 (Long-Term Dependency) | 멀리 떨어진 과거 정보가 현재 판단에 영향을 못 미치는 문제 | 며칠 전 일을 까맣게 잊어버림 |
| 기울기 소실/폭주 (Vanishing/Exploding Gradient) | BPTT 중 같은 값을 반복 곱해 기울기가 0에 수렴하거나 무한히 커지는 현상 | 소문이 전달될수록 사라지거나 부풀려짐 |
| 셀 상태 (Cell State, $C_t$, LSTM) | 곱셈이 아닌 덧셈 위주로 갱신되는 별도의 장기 기억 통로 | 매일 들고 다니며 고쳐 쓰는 수첩 |
| Forget/Input/Output Gate (LSTM) | 각각 과거를 지우고·새 정보를 더하고·내보낼 정보를 거르는 0~1 조절 장치 | 수첩의 지우기·적기·보여주기 |
| Update/Reset Gate (GRU) | LSTM의 3게이트를 2개로 압축한 경량 버전의 조절 장치 | 지우기+적기를 하나로 합친 간소화 수첩 |

## 깊이 이해

### 왜 일반 신경망으로는 순서를 다루지 못하나
- FC·CNN은 고정 크기 입력만 받는다. "나는 밥을 먹었다"처럼 단어 수가 문장마다 다른 시퀀스는 입력 크기를 고정하기 어렵고, 설령 고정하더라도 "먹었다"가 "밥을" 뒤에 온다는 순서 정보를 반영할 장치가 없다.
- RNN은 시점 $t$의 은닉 상태 $h_t$를 계산할 때 현재 입력 $x_t$뿐 아니라 이전 시점의 은닉 상태 $h_{t-1}$도 함께 받는다: $h_t = \tanh(W_x x_t + W_h h_{t-1} + b)$. 이 $h_{t-1}$이 "지금까지 읽은 내용의 요약(기억)" 역할을 한다.

### 기울기 소실을 수치로 확인 (왜 바닐라 RNN은 장기 기억을 못 하나)
- BPTT는 $h_t$에서 $h_1$까지 거슬러 올라가며 매 시점 가중치 $W_h$를 반복해서 곱한다. 이 곱셈의 유효 계수가 0.9라면, 20단어 전 정보의 영향력은 $0.9^{20} \approx 0.12$(12%), 50단어 전이면 $0.9^{50} \approx 0.005$(0.5%), 100단어 전이면 $0.9^{100} \approx 0.00003$으로 사실상 0이 된다. 문장이 조금만 길어져도(10~20단어) 초반부 정보의 기울기가 0으로 사라져 학습에 반영되지 않는 것이 장기 의존성 문제다.
- 반대로 계수가 1보다 크면(예 1.1) $1.1^{50} \approx 117$로 기울기가 폭증하는 기울기 폭주가 발생한다. 두 현상 모두 "같은 값을 반복해서 곱한다"는 구조에서 비롯된다.

### LSTM이 곱셈을 덧셈으로 바꿔 문제를 푸는 방식
- LSTM은 $h_t$와 별도로 셀 상태 $C_t$라는 기억 통로를 둔다. $C_t$는 매 시점 곱셈이 아니라 **덧셈** 위주로 갱신된다: $C_t = (\text{Forget Gate} \times C_{t-1}) + (\text{Input Gate} \times \text{새 후보값})$. 곱셈이 반복 누적되지 않으므로 기울기가 지수적으로 사라지지 않는다.
- 세 게이트는 모두 0~1 사이 값을 내는 시그모이드로 "얼마나 통과시킬지"를 정한다. Forget Gate는 과거 정보 중 지울 부분을(0이면 완전히 잊고 1이면 그대로 유지), Input Gate는 현재 입력 중 새로 기억에 더할 부분을, Output Gate는 갱신된 $C_t$ 중 지금 당장 출력할 부분을 걸러 $h_t$로 내보낸다.
- 예: Forget Gate 값이 0.9로 학습되었다면, 중요한 정보는 매 시점 90%씩 유지되면서도 Input Gate를 통해 새 정보가 계속 더해지므로(덧셈 구조), 곱셈만 반복하는 바닐라 RNN처럼 100단계 뒤 정보가 완전히 소멸하지 않는다.

### GRU — 게이트를 3개에서 2개로 줄인 경량화
- GRU는 Cell State와 Hidden State를 하나로 합치고, 게이트도 Update Gate(Forget+Input 역할 통합)와 Reset Gate(과거 정보를 얼마나 무시할지) 2개로 줄였다. 게이트가 적은 만큼 가중치 행렬 수도 줄어 LSTM 대비 연산량이 약 25% 적으면서도 비슷한 장기 기억 성능을 낸다.

### 비유와 흔한 오해
- **비유**: RNN이 어제 일기장 전체를 오늘 일기 위에 덮어써서 예전 글씨가 점점 흐려지는 방식이라면, LSTM은 수첩(Cell State)을 들고 다니며 불필요한 줄은 지우고(Forget) 중요한 새 줄만 적어(Input) 다음 날로 넘기는(Output) 방식이다.
- **오해**: RNN 계열은 $t$시점 계산이 $t-1$ 결과를 필요로 하므로 문장 내 단어를 순서대로 하나씩만 처리할 수 있다. GPU의 강점인 병렬 연산을 살릴 수 없어 문장이 길어질수록 학습 시간이 순차적으로 늘어난다. 이 순차 처리 병목이 이후 병렬 처리가 가능한 Transformer 등장의 직접적 계기가 되었다.

## 연결 개념
- 기울기 소실 (Gradient Vanishing) — 과거 시점으로 역전파할 때 기울기가 0이 되어 장기 기억을 못 하는 현상
- 자연어 처리 (NLP) — 기계 번역, 음성 인식 등 순서가 핵심인 주요 적용 분야
- 트랜스포머 (Transformer) — RNN의 순차 연산 한계를 셀프 어텐션 병렬 처리로 극복한 현대 모델

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: RNN 계열(RNN/LSTM/GRU)은 은닉층의 출력값을 다음 시점(Time Step)의 입력으로 순환시켜 시퀀스(Sequence) 데이터의 시간적 종속성을 모델링하는 알고리즘이다.
> 2. **가치**: 바닐라 RNN의 장기 의존성(Long-term Dependency) 한계를 LSTM의 셀 상태(Cell State)와 게이트 메커니즘을 통해 구조적으로 극복했다.
> 3. **판단 포인트**: 시계열/자연어 처리에서 성능이 입증되었으나, 순차 연산 구조에 따른 병렬화 불가(학습 속도 저하) 한계로 인해 최근에는 Transformer 아키텍처로 대체되는 추세다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 장기 의존성(Long-term) 문제와 해결 원리 이해 | BPTT 역전파 시 기울기 소실 발생 원인과 LSTM의 덧셈 연산(Cell State) 극복 명시 | "기억력이 좋다"는 식의 작동 메커니즘 없는 추상 서술 |
| LSTM과 GRU의 구조적 차이 비교 | LSTM(3 게이트 + Cell) vs GRU(2 게이트, Cell 통합) 파라미터 경량화 | GRU가 항상 LSTM보다 우수하다고 단정 |
| 시퀀스 모델의 최신 발전 맥락 파악 | RNN의 순차 처리 한계와 병렬화 가능한 Attention/Transformer 한계 돌파 | RNN/LSTM 내에만 갇혀 한계점(속도)을 짚지 못함 |

> 요약: 시퀀스 데이터를 처리하기 위한 상태 전이(State Transition) 메커니즘을 묻고, 긴 시퀀스 학습 시 발생하는 미분 한계를 게이트 제어로 푼 구조적 혁신을 평가한다.

## Ⅰ. 개요 및 필요성

- 정의: 은닉층 노드가 순환하는 경로를 가져, 시점 $t$의 출력이 $t+1$의 은닉 상태(Hidden State) 계산에 재입력되는 인공 신경망
- 배경: 피드포워드 신경망(CNN, DNN)은 고정 크기 입출력만 지원하여 길이가 가변적인 문장이나 시계열 음성 신호 처리 불가
- 필요성: 과거의 맥락(Context)을 현재 의사결정에 반영하고, 연속된 데이터 시퀀스의 패턴(동향, 문법)을 맵핑하기 위함

---

## Ⅱ. 구조 및 구성요소 (LSTM 중심)

```text
       [Cell State (장기 기억 컨베이어 벨트) C_t-1 -> C_t]
             |                 |                 |
(망각) Forget Gate -> (저장) Input Gate -> (출력) Output Gate
             ^                 ^                 ^
             +-----------------+-----------------+
               | (입력 병합)
     [과거 Hidden State h_t-1] + [현재 Input x_t]
```

| 구성요소 | 역할 | 내부 메커니즘 / 수식 특징 |
|:---|:---|:---|
| 셀 상태 ($C_t$) | 정보가 왜곡 없이 흐르는 고속도로(메모리) | 주로 덧셈(+) 연산으로 기울기 소실 원천 방어 |
| 망각 게이트 (Forget) | 과거 정보 중 불필요한 부분을 0~1 사이로 버림 | Sigmoid 통과값 $\times C_{t-1}$ 연산 |
| 입력 게이트 (Input) | 현재 입력 중 셀 상태에 추가할 신규 정보 스케일링 | Sigmoid 활성화 및 Tanh(후보 값) 결합 |
| 출력 게이트 (Output) | 갱신된 셀 상태를 기반으로 다음 은닉 상태($h_t$) 결정 | Tanh 통과 후 필터링하여 $h_t$ 배출 |

> 요약: RNN의 단순 연산과 달리, LSTM은 정보 유지(Cell)와 조절(Gate)을 분리하여 장기 의존성(BPTT 시 기울기 소실)을 곱셈 대신 덧셈 패스로 극복한다.

## Ⅲ. 동작원리 및 흐름도

```text
데이터 시퀀스 입력 -> t=1 셀 연산(망각/입력) -> 상태 업데이트 -> t=2 로 전달 -> 최종 결과 산출
```

| 단계 | 처리 내용 | 검증 기준 / 효과 |
|:---:|:---|:---|
| 1 | $t$ 시점 데이터 $x_t$와 이전 은닉 상태 $h_{t-1}$ 연결 | 입력 벡터 크기 + 은닉 노드 크기 병합 |
| 2 | Forget / Input 게이트 연산 수행 (가중치 연산) | 활성화 함수 포화 방지 |
| 3 | 과거 $C_{t-1}$ 업데이트하여 새로운 $C_t$ 생성 | 과거 기억 보존 및 신규 특징 반영 |
| 4 | Output 게이트 통해 현재 시점 $h_t$ 추출 | $t+1$ 시점으로 전달 및 필요시 출력층 전달 |

> 요약: 각 시점마다 독립된 가중치 행렬을 재사용하여 상태를 갱신하며, 길이가 다른 시퀀스에 대해서도 유연하게 대응한다(Many-to-One 등).

## Ⅳ. RNN vs LSTM vs GRU 심화 비교

| 구분 | 기본 RNN (Vanilla) | LSTM (Long Short-Term Memory) | GRU (Gated Recurrent Unit) |
|:---|:---|:---|:---|
| 장기 기억력 | 문장 10단어 이상 시 기울기 0 소실 | 100단어 이상의 장기 맥락 유지 | LSTM과 유사한 장기 기억 성능 |
| 내부 구조 | 단순 가중치 행렬 1개 곱합 연산 | Cell State + 3 Gate (Input, Forget, Output) | Hidden State 통합 + 2 Gate (Update, Reset) |
| 파라미터 / 연산량 | 파라미터 최소, 연산 빠름 | 가중치 행렬 4배, 연산량 매우 무거움 | LSTM 대비 약 75% 수준으로 경량화 달성 |
| 적용 판단 포인트 | 단순 단기 시계열, 임베딩 초기화 | 복잡한 기계 번역, 장기 시계열 예측 | 자원 제약(에지) 환경, 소규모 데이터셋 |

> 요약: LSTM은 게이트 구조로 정확도를 높였으나 연산이 무겁고, GRU는 게이트를 2개로 압축하여 LSTM급 성능과 학습 속도 향상이라는 트레이드오프를 달성했다.

## Ⅴ. 한계점 및 최신 기술과의 비교 (적용 판단)

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 병렬 처리 불가(속도 지연) | $t$ 시점 연산을 위해 $t-1$ 결과를 기다려야 하는 순차 의존성 | Self-Attention 기반 Transformer로 전환, 시퀀스 전체를 O(1)에 동시 연산 | 1 epoch당 학습 소요 시간(RNN 대비 단축률) |
| 극단적 장기 문맥 소실 | LSTM도 500 토큰 이상이면 메모리 병목으로 과거 정보 희석 | 단어 간 거리를 직접 계산하는 Attention 구조 채택 | 장거리 의존 태스크의 Perplexity·정확도 |

> 요약: RNN 계열은 시퀀스 데이터 처리를 개척했으나 근본적인 순차 연산 구조 탓에 GPU 병렬화가 어려워, LLM 시대에는 Transformer 아키텍처로 대체되었다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| Sequence 길이 제약 | Truncated BPTT 길이 최적화 설정 | 시점(t) 50~100 단위 그래디언트 클리핑 |
| 기울기 폭주(Exploding) 제어 | 가중치 L2 Norm 1.0~5.0 이내 유지 | Gradient Clipping 임계값 모니터링 |

> 요약: Truncated BPTT 길이와 그래디언트 클리핑 임계값을 함께 관리해야 장기 시퀀스 학습에서 기울기 폭주·소실을 통제할 수 있다.

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 시계열 예측(Time-Series Forecasting): 금융 데이터나 IoT 센서 데이터에서 Transformer보다 가벼운 GRU를 사용하여 센서 주기성 패턴 추론 및 이상 징후 탐지.
2. 경량 음성 인식(Wake-Word Detection): "시리야", "알렉사" 등 항시 대기해야 하는 저전력 스마트 기기에서 파라미터가 적은 1D-CNN + GRU 하이브리드 구성 적용.
3. 양방향 맥락 파악 (Bi-LSTM): 개체명 인식(NER) 작업 시 단방향 문맥만으로 부족하므로, 정방향 역방향 은닉 상태를 결합한 Bi-LSTM을 배치하여 태깅 정확도 향상.

**결론 (2줄):**
- 기술사 판단: 순환 신경망은 게이트 제어(LSTM/GRU)를 통해 장기 의존성 문제를 해결한 시계열 처리의 핵심 모델이나, 순차 연산 병목으로 대용량 학습에는 부적합하다.
- 향후 방향: 거대 언어 모델(LLM) 환경에서는 Transformer로 주도권이 넘어갔으나, 리소스 제약이 극심한 모바일/IoT 에지 디바이스의 스트리밍 데이터 처리에서는 여전히 실용적인 가치를 지닌다.
