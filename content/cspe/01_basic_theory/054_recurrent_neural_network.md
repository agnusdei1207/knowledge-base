# 📖 【암기용】 개념 완전 이해

> 목적: 순환 신경망 RNN·LSTM·GRU를 처음 보는 사람도 완전하게 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 이전 시점의 은닉상태를 다음 시점 계산에 넘기는 시퀀스 모델
- **왜 필요한가**:
  - 문장, 음성, 센서 로그, 주가처럼 순서가 의미를 만드는 데이터는 현재 입력만으로 판단하기 어렵다.
  - RNN은 과거 정보를 은닉상태에 담아 현재 예측에 반영한다.
- **핵심 직관**: 같은 계산 셀을 시간축으로 반복 사용하면서 이전 기억을 다음 입력과 함께 처리하는 구조다.

## 깊이 이해
- **배경·문제의식**:
  - 일반 MLP는 입력 순서를 반영하지 못한다.
  - RNN은 시간 t의 출력이 시간 t-1의 은닉상태에 의존하도록 만들어 시퀀스 의존성을 학습한다.
- **작동 원리**:
  - 기본 RNN은 `h_t = f(Wx_t + Uh_{t-1})`로 계산한다.
  - LSTM은 입력·망각·출력 게이트와 셀 상태를 추가해 긴 의존성을 보존한다.
  - GRU는 업데이트·리셋 게이트로 LSTM보다 파라미터 수를 줄인다.
- **비유**:
  - 회의록을 한 줄씩 읽으며 메모장을 갱신하는 상황과 같다.
  - 기본 RNN은 짧은 메모만 남기고, LSTM은 중요한 항목을 오래 보관하는 별도 노트를 둔다.
- **구체 예시**:
  - 100단어 문장 감성분석에서 앞부분의 부정 표현이 뒤 문장 결론에 영향을 줄 수 있다.
  - LSTM은 forget gate로 불필요 단어를 버리고 cell state로 부정 표현을 유지한다.
- **흔한 오해·주의점**:
  - RNN은 모든 시퀀스 문제의 기본 답이 아니다.
  - 긴 문맥과 병렬 학습이 중요한 대규모 언어 모델에서는 Transformer가 학습 처리량과 문맥 포착 면에서 표준 선택이다.

## 연결 개념
- BPTT(Backpropagation Through Time) — 시간축으로 펼친 역전파
- 기울기 소실·폭주 — 긴 시퀀스 학습의 주요 한계
- Transformer — Attention 기반 시퀀스 모델 대안

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: RNN(Recurrent Neural Network)은 이전 은닉상태를 현재 입력과 결합해 순서 의존성을 학습하는 시퀀스 모델이다.
> 2. **가치**: LSTM·GRU 게이트 구조는 장기 의존성 보존과 기울기 소실 완화를 제공한다.
> 3. **판단 포인트**: 시퀀스 길이, 실시간 추론, 병렬 학습 요구, Transformer 대체 가능성을 기준으로 선택해야 한다.

---

## Ⅰ. 개요 및 필요성

- 개요: RNN은 시간 순서 데이터를 처리하는 신경망이다.
- 배경: 자연어·음성·센서 로그는 이전 입력이 현재 판단에 영향을 주므로 순서 정보를 유지하는 구조가 필요하다.
- 필요성: RNN·LSTM·GRU는 은닉상태와 게이트를 사용해 시퀀스 의존성을 모델링한다.

---

## Ⅱ. 구조 및 구성요소

```text
x_t 입력 -> RNN/LSTM/GRU 셀 -> h_t 은닉상태 -> 출력 y_t
              +-> h_t를 다음 시점 t+1로 전달
              +-> LSTM은 cell state 별도 유지
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 입력 시퀀스 x_t | 시간별 관측값 제공 | 토큰, 음성 프레임, 센서 값 |
| 은닉상태 h_t | 과거 정보 요약 | 기본 RNN의 기억 통로 |
| LSTM 게이트 | 입력·망각·출력 제어 | 장기 의존성 보존 |
| GRU 게이트 | 업데이트·리셋 제어 | LSTM 대비 파라미터 감소 |

> 요약: RNN 계열은 입력, 은닉상태, 게이트, 출력으로 구성되며 이전 시점 정보를 다음 계산에 전달한다.

---

## Ⅲ. 동작원리 및 흐름도

```text
시퀀스 입력 -> 시간축 펼침 -> 셀 반복 계산 -> 손실 누적
-> BPTT 역전파 -> 가중치 갱신 -> 시퀀스 출력
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 토큰·프레임 순서 입력 | padding·mask 정확성 |
| 2 | 은닉상태 갱신 | h_t 크기와 batch 차원 점검 |
| 3 | BPTT 수행 | gradient clipping 적용 |
| 4 | 출력 산출 | perplexity, CER, F1 측정 |

> 요약: RNN은 시간축으로 같은 셀을 반복 적용하고 BPTT로 전체 시퀀스 손실을 역전파한다.

---

## Ⅳ. 특징

| 구분 | 기존 방식 | 본 기술 | 수치·판단 포인트 |
|:---|:---|:---|:---|
| 순서 처리 | MLP는 순서 정보 없음 | h_t로 과거 정보 전달 | 시퀀스 길이 100 이하에서 적용 용이 |
| 장기 기억 | 기본 RNN은 기울기 소실 | LSTM·GRU 게이트 사용 | gradient norm 모니터링 |
| 병렬성 | CNN·Transformer 병렬 처리 | 시간 순차 계산 | 학습 처리량(tokens/sec) 비교 |
| 실시간성 | 전체 문맥 필요 모델 존재 | streaming 처리 가능 | 지연시간 100ms 이하 요구 시 검토 |

> 요약: RNN 계열은 순차 처리와 실시간 스트리밍에 적합하지만 긴 문맥·대규모 병렬 학습은 Transformer와 비교해야 한다.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존/대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | Transformer는 Attention 기반 | RNN은 은닉상태 반복 | 짧은 시퀀스·스트리밍이면 RNN |
| 비용/성능 | LSTM은 게이트 3개 | GRU는 게이트 2개 | 파라미터·지연 제약이면 GRU |
| 운영/위험 | MLP는 해석 단순 | RNN은 상태 관리 필요 | online inference 상태 초기화 점검 |

> 요약: RNN, LSTM, GRU, Transformer는 시퀀스 길이와 실시간 지연 요구에 따라 선택한다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 기울기 폭주 | 긴 BPTT | gradient clipping 1.0~5.0 적용 | gradient norm |
| 장기 의존 손실 | 기본 RNN 구조 | LSTM·GRU 선택 | long-range validation set |
| 상태 오염 | 세션 간 h_t 재사용 오류 | 배치·세션별 상태 초기화 | 요청별 오류율 |

> 요약: RNN 운영은 기울기 제어, 장기 의존성, 추론 상태 초기화가 핵심 리스크다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 예측 품질 | F1, CER, perplexity 목표 충족 | 검증 데이터 평가 |
| 학습 제어 | gradient norm 임계값 이내 | TensorBoard, 로그 |
| 추론 지연 | p95 latency 100ms 이하 | 온라인 벤치마크 |

> 요약: RNN 도입은 품질 지표, 기울기 안정성, 실시간 지연을 함께 측정해야 한다.

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 — 단계별 또는 항목별):**
1. 시퀀스 길이 100 이하의 센서·로그 예측은 GRU baseline을 구성하고 hidden size 128~512 범위에서 탐색함.
2. 긴 문맥 자연어 처리는 LSTM baseline과 Transformer를 함께 평가하고 perplexity·F1·tokens/sec를 비교함.
3. 운영 환경은 padding mask, hidden state 초기화, gradient clipping 1.0 적용 여부를 학습·추론 파이프라인에 점검함.

**결론 (2줄):**
- 기술사 판단: 짧은 시퀀스·스트리밍이면 GRU/LSTM, 긴 문맥·대규모 병렬 학습이면 Transformer를 선택함.
- 향후 방향: RNN 계열은 경량 스트리밍 모델과 Attention 혼합 구조로 실시간 AI 영역에 남는다.
