## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 데이터 간의 거리, 각도, 교집합 비율을 계산하여 객체 간의 비슷함 정도를 정량화하는 기법임 |
| 배경/필요성 | 추천 시스템, 텍스트 마이닝, 군집화 등에서 객체 간 관계성 평가 기준 필요성 증대 |
| 출제 의도 | 각 유사도 지표의 수학적 원리, 적용 데이터 유형, 장단점 분석 능력 평가 |

## Ⅱ. 구성요소
```text
+----------------+       +----------------+       +----------------+
| Target Objects |       | Distance/Angle |       | Similarity     |
| (Vectors/Sets) | ----> | Calculation    | ----> | Score Output   |
+----------------+       +----------------+       +----------------+
```
| 유클리드 거리 | 두 점 사이의 최단 물리적 직선 거리 | 지도상의 직선 거리 |
| 코사인 유사도 | 두 벡터 간 사이각의 코사인 값 (방향성 측정) | 목표를 향한 방향성 |
| 자카드 유사도 | 두 집합 간 교집합 비율 (교집합/합집합) | 공통 취향 비율 |
> 요약: 유사도 측정은 유클리드(거리), 코사인(방향), 자카드(집합)로 구성되어 관계성을 산출함

## Ⅲ. 절차
```text
+----------------+       +----------------+       +----------------+       +----------------+
| Data Repr.     |       | Measure Select |       | Value Comput.  |       | Result Applic. |
| (Vectorize)    | ----> | (Pick Method)  | ----> | (Run Formula)  | ----> | (Recommend)    |
+----------------+       +----------------+       +----------------+       +----------------+
```
1. 데이터 표현: 대상 객체를 벡터나 집합 등 계산 가능한 형태로 변환
2. 척도 선택: 데이터 특성(텍스트, 좌표, 범주형 등)에 맞는 유사도 측정 지표 선택
3. 값 계산: 선택한 공식(거리, 각도, 집합 연산)을 적용하여 유사도 점수 도출
4. 결과 활용: 도출된 유사도를 기반으로 추천, 군집, 분류 모델에 적용
> 요약: 데이터를 모델링하고 적합한 유사도 지표를 선택해 계산한 후 알고리즘에 적용함

## Ⅳ. 문제점
- 스케일 민감성: 유클리드 거리는 데이터의 크기나 단위 변화에 매우 취약함
- 크기 정보 무시: 코사인 유사도는 방향만 고려하므로 벡터의 실제 크기 차이 무시
- 희소 데이터 한계: 텍스트 등 매우 희소(Sparse)한 벡터 간에는 유사도 분별력 저하

## Ⅴ. 개선방안
- 단기 방안: 유클리드 거리 적용 전 데이터 정규화 및 표준화 수행
- 중기 방안: 코사인 유사도 적용 시 TF-IDF 등을 통해 중요도를 가중치로 보완
- 장기 방안: 차원 축소 기법(PCA) 또는 워드 임베딩으로 밀집 벡터화 후 유사도 계산

## Ⅵ. 전망
- 단순 통계적 계산에서 딥러닝(Siamese Network 등) 기반의 의미론적 유사도 측정으로 발전함
