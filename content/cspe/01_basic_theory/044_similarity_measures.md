## 미리 알고가기

- 거리: 값이 작을수록 두 데이터가 가깝다고 보는 불일치 척도임
- 유사도: 값이 클수록 두 데이터가 비슷하다고 보는 일치 척도임
- 벡터 크기: 벡터의 길이이며 빈도나 규모 정보를 반영함
- 희소 벡터: 대부분 값이 0인 벡터로 텍스트·추천 데이터에서 자주 나타남
- 집합 중첩: 두 집합이 공유하는 원소 비율을 비교하는 방식임

## Ⅰ. 개요

- **정의**: 유사도 측정은 두 데이터 객체를 거리·각도·집합 중첩 기준으로 비교해 같거나 다른 정도를 수치화하는 분석 기준임
- **배경/필요성**: 검색, 추천, 군집화, 중복 탐지에서는 객체 간 관계를 정량화해야 순위, 그룹, 매칭 여부를 일관되게 결정할 수 있음
- **비유**: 사람들의 취향을 음식, 영화, 구매 이력 같은 기준으로 점수화해 서로 얼마나 가까운지 재는 것과 같음

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 척도별 원리 구분 | 유클리드, 코사인, 자카드 | 크기·방향·집합 기준 혼동 |
| 데이터 유형별 선택 | 연속형, 텍스트, 범주형, 희소 데이터 | 스케일 정규화 필요성 누락 |

> 요약: 유사도 측정은 데이터 표현 방식에 맞는 비교 기준을 선택해 검색·추천·군집화의 판단 근거를 만드는 과정임.

## Ⅱ. 특징/비교

| 판단 기준 | 유클리드 거리 | 코사인·자카드 유사도 |
|:---|:---|:---|
| 비교 기준 | 좌표 간 직선 거리와 절대 크기 차이를 봄 | 코사인은 방향, 자카드는 집합 중첩을 봄 |
| 적합 데이터 | 동일 스케일의 연속형 수치 데이터에 적합함 | 텍스트, 클릭 집합, 희소 벡터에 적합함 |
| 전처리 요구 | 스케일 표준화 영향이 큼 | 토큰화, 정규화, 이진화 기준이 중요함 |
| 선택 조건 | 값의 크기 차이가 의미 있을 때 선택함 | 패턴 방향이나 포함 원소 비율이 중요할 때 선택함 |

> 요약: 유사도 척도는 데이터가 수치 좌표인지, 방향 패턴인지, 집합 원소인지에 따라 달라져야 함.

- **입력 조건**: 비교 대상이 동일한 표현 형식과 전처리 기준으로 준비되어야 함
- **평가 기준**: 가까운 샘플의 업무 의미와 오프라인 검색·추천 지표를 함께 확인함
- **선택 판단**: 크기 차이, 방향성, 원소 중첩 중 무엇이 중요한지 먼저 결정함

## Ⅲ. 구성요소

```text
+------------+      +------------+      +------------+
| 데이터 표현 | ---> | 전처리 기준 | ---> | 유사도 계산 |
+------------+      +------------+      +------------+
       |                  |                  |
       v                  v                  v
+------------+      +------------+      +------------+
| 벡터·집합   |      | 정규화     |      | 순위·판정   |
+------------+      +------------+      +------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 데이터 표현 | 객체를 벡터, 좌표, 집합, 확률 분포 등 계산 가능한 형태로 변환함 | 비교 대상의 프로필 |
| 전처리 기준 | 스케일, 토큰, 결측, 희소성을 조정해 비교가 같은 기준에서 수행되게 함 | 같은 단위의 줄자 |
| 척도 공식 | 유클리드, 맨해튼, 코사인, 자카드 등 비교 목적에 맞는 수식을 적용함 | 채점 방식 |
| 임계값·순위 | 유사도 점수로 가까운 객체를 정렬하거나 매칭 여부를 결정함 | 순위표 |
| 검증 지표 | 검색 정확도, 추천 클릭률, 군집 품질로 척도 선택의 적합성을 확인함 | 결과 검산 |

> 요약: 유사도 측정은 데이터 표현과 전처리를 먼저 맞춘 뒤 목적에 맞는 척도와 판정 기준을 적용하는 구조임.

## Ⅳ. 절차

```text
+------------+      +------------+      +------------+      +------------+
| 표현 설계   | ---> | 정규화     | ---> | 척도 계산   | ---> | 결과 활용   |
+------------+      +------------+      +------------+      +------------+
```

1. **표현 설계**: 비교할 객체의 속성을 수치 벡터, 토큰 집합, 이진 벡터 등으로 정의함
2. **전처리·정규화**: 스케일, 길이, 빈도, 희소성 처리를 통해 비교 기준을 균일하게 만듦
3. **척도 계산**: 데이터 유형에 맞는 거리 또는 유사도 공식을 적용해 점수를 산출함
4. **검증·활용**: 임계값, Top-K, 군집 품질, 검색 성능으로 실제 활용 가능성을 확인함

> 요약: 유사도 측정 절차는 표현을 정하고 같은 기준으로 정리한 뒤 척도를 계산해 순위나 판정에 연결하는 흐름임.

- **산출물**: 유사도 점수, Top-K 후보, 임계값 기반 매칭 결과임
- **검증 기준**: 샘플 검수 결과와 검색·추천 성능 지표가 일치해야 함
- **운영 기록**: 임베딩 모델, 정규화 방식, 인덱스 버전을 함께 관리해야 함

## Ⅴ. 문제점

- **P1 스케일 왜곡**: 변수 단위가 다르면 일부 속성이 거리 계산을 지배해 실제 유사한 객체가 멀게 평가될 수 있음
- **P2 고차원 희소성**: 텍스트·추천 데이터처럼 차원이 크고 0이 많으면 거리 차이가 희미해지고 가까운 이웃 탐색이 불안정해짐
- **P3 척도 부적합**: 크기가 중요한 문제에 코사인을 쓰거나 집합 중첩 문제에 유클리드를 쓰면 업무 의미와 점수가 어긋남

> 요약: 유사도 측정의 핵심 문제는 수치 점수 자체보다 점수가 데이터 의미를 제대로 반영하는지에 있음.

## Ⅵ. 개선방안

- **P1 대응**: 표준화, Min-Max 정규화, 가중치 조정을 적용하고 변수별 거리 기여도를 점검함 (확인: 속성별 영향도와 검색 결과 샘플)
- **P2 대응**: 차원 축소, 임베딩, 근사 최근접 탐색, 희소 데이터용 코사인 기준을 적용함 (확인: 검색 지연과 Top-K 재현율)
- **P3 대응**: 데이터 유형과 업무 목적별 후보 척도를 비교 실험하고 기준을 문서화함 (확인: 오프라인 지표와 사용자 평가 일치도)

> 요약: 유사도 개선은 데이터 표현, 전처리, 척도 선택을 함께 검증해 수학적 가까움과 업무적 가까움을 맞추는 것임.

- **우선순위**: 데이터 표현과 스케일 정규화를 먼저 맞춘 뒤 척도를 비교함
- **확인 지표**: Recall@K, Precision@K, 군집 품질, 샘플 검수 결과를 사용함
- **재평가 조건**: 속성 추가, 토큰화 변경, 임베딩 모델 교체 시 기준을 다시 검증함

## Ⅶ. 전망

- **발전 방향**: 유사도 측정은 벡터 검색, 추천 시스템, 중복 제거, RAG 검색 품질 관리에서 핵심 기준으로 계속 중요해질 것임
- **기술사적 판단**: 기술사는 수식 암기보다 데이터 표현 방식과 업무 판단 기준이 같은 방향인지 확인해야 함
- **기술사 제언**: 향후에는 도메인 임베딩, 멀티모달 벡터, 근사 검색 인덱스와 결합해 대규모 데이터에서 빠르고 의미 있는 유사도 계산이 요구될 것임
