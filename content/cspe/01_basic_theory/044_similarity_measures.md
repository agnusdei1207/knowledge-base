## Ⅰ. 개요

- **정의**: 두 데이터 벡터 간 거리·각도·집합 중첩도를 수치로 나타내는 척도임.
- **배경/필요성**: 고차원 데이터를 사람의 감각이 아닌 함수로 "가깝다/멀다"를 판정해야 군집화·추천·검색·이상 탐지 등 후속 알고리즘이 동작 가능하며, 데이터의 성질(연속형/희소 벡터/이진 집합)마다 같은 벡터 쌍도 척도별로 상반된 결과를 낼 수 있어 척도 선택 자체가 설계 판단임.
- **출제 의도**: 척도별 공식·기하학적 의미의 정확한 이해, 데이터 성질에 따른 척도 선택 근거 제시 역량을 확인함.
- **답안 방향**: 구조(벡터화-척도함수-점수) → 동작(척도별 계산 예시) → 특징(반영 정보 차이) → 척도 간 선택 기준 비교 → 실무 적용 순으로 전개함.

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 척도별 계산 원리와 적용 기준 설명 요구 | 유클리드·코사인·자카드 공식과 실제 계산값, 데이터 성질별 선택 근거 | 공식 없이 개념만 나열, 척도 간 우열 단정, 차원의 저주 언급 누락 |

> 요약: 유사도 답안은 척도별 공식을 실제 수치로 검증하고, 데이터 성질에 따른 선택 근거를 먼저 못 박아야 함.

## Ⅱ. 구조 및 구성요소

```text
원본 데이터(문서/이미지/거래 내역)
  |
  v
벡터화(Feature Vector): x = (x1, x2, ..., xn)
  |
  v
척도 함수 적용 -> 거리 함수(유클리드/맨해튼) 또는 유사도 함수(코사인/자카드)
  |
  v
스칼라 점수 산출 -> 임계값 판정 / 순위화(Top-K)
```

| 구성요소 | 역할 | 산출물/비유 |
|:---|:---|:---|
| 특징 벡터(Feature Vector) | 원본 데이터를 수치 좌표로 표현 | 숫자로 찍은 좌표 지도 |
| 정규화(Normalization) | 변수 간 단위·스케일 차이를 제거 | 저울 눈금을 통일 |
| 거리 함수(Distance Function) | 두 벡터 간 비유사도를 계산 | 자로 잰 물리적 간격 |
| 유사도 함수(Similarity Function) | 두 벡터 간 방향·중첩 일치도를 계산 | 각도계·겹침 비율계 |

> 요약: 원본 데이터를 정규화된 벡터로 표현한 뒤, 거리 또는 유사도 함수로 근접성을 계산해 스칼라 점수로 산출함.

## Ⅲ. 동작원리 및 흐름도

```text
데이터 벡터화 -> 척도 선택(데이터 성질 판단) -> 공식 적용 -> 점수 해석(임계값/순위)
```

- 1단계(벡터화): 문서·거래 내역 등을 n차원 벡터로 변환함. 예: 벡터 `A=(1,1)`, `B=(4,5)`.
- 2단계(유클리드 거리): $d(A,B) = \sqrt{\sum_i (a_i - b_i)^2}$ 로 직선 거리를 계산함. `A=(1,1)`, `B=(4,5)`이면 $d = \sqrt{(4-1)^2+(5-1)^2} = \sqrt{9+16} = 5$.
- 3단계(코사인 유사도): $\cos\theta = \dfrac{A \cdot B}{\|A\|\|B\|}$ 로 방향 일치도를 계산함. 같은 `A`, `B`에서 내적 `1*4+1*5=9`, $\|A\|=\sqrt{2}$, $\|B\|=\sqrt{41}$이므로 $\cos\theta = 9/\sqrt{82} \approx 0.994$. 거리는 5로 멀지만 두 벡터가 가리키는 방향은 거의 일치함.
- 4단계(자카드 유사도): $J(A,B) = |A \cap B| / |A \cup B|$ 로 집합 중첩 비율을 계산함. 예: 문서 A의 단어 집합 `{사과,바나나,포도}`, 문서 B `{사과,포도,딸기}`이면 교집합 `{사과,포도}`(2개), 합집합 4개이므로 $J = 2/4 = 0.5$.

> 요약: 같은 벡터 쌍이라도 유클리드 거리는 크기 차이를, 코사인 유사도는 방향 일치를, 자카드 유사도는 집합 중첩 비율을 각각 다른 값으로 산출함.

## Ⅳ. 특징

- 스케일 민감도: 유클리드·맨해튼 거리는 변수 단위에 따라 값이 왜곡되어, 정규화 없이 쓰면 값의 범위가 큰 변수 하나가 거리 계산을 지배함.
- 방향 vs 크기: 코사인 유사도는 벡터 길이를 무시하고 방향만 비교하므로, 문서 길이나 평가 개수가 달라도 패턴·성향의 일치도를 비교할 수 있음.
- 이산 집합 전용: 자카드 유사도는 원소의 존재 여부만 반영하고 등장 빈도를 무시하므로, 빈도 정보가 중요한 데이터에는 왜곡을 유발함.
- 차원 민감도: 차원이 증가하면 유클리드 거리 기반 척도는 모든 점 간 거리가 비슷해지는 차원의 저주가 발생해 변별력이 급락함.

> 요약: 척도마다 반영하는 정보(절대 크기/방향/집합 중첩)가 달라, 데이터 성질과 차원 수가 선택을 결정함.

## Ⅴ. 심화 비교 및 적용 판단

| 판단 기준 | 유클리드 거리 | 코사인 유사도 | 자카드 유사도 |
|:---|:---|:---|:---|
| 반영 정보 | 절대 크기 + 방향(직선 거리) | 방향(각도)만, 크기 무시 | 집합 교집합 비율, 빈도 무시 |
| 적합 데이터 | 연속형 저차원 수치(좌표, 센서값) | 고차원 희소 벡터(TF-IDF, 임베딩) | 이진/카테고리 집합(태그, 장바구니) |
| 값 범위 | 0 이상, 상한 없음 | -1~1(실무에서는 0~1이 흔함) | 0~1 |
| 선택 기준 | 변수 단위가 동일하고 절대 크기가 의미 있을 때 | 활동량·길이 차이를 배제하고 패턴만 비교할 때 | 원소 존재 여부만 의미 있고 빈도가 무관할 때 |

> 요약: 절대 크기가 의미 있으면 유클리드, 크기를 배제한 패턴 비교면 코사인, 이산 집합의 중첩 비율이면 자카드를 선택함.

**리스크·대응 (불릿):**
- 스케일 왜곡: 변수 단위 불일치가 원인 → Z-score 정규화 또는 Min-Max 스케일링을 선적용해 대응함 (지표: 정규화 전후 최근접 이웃 순위 변동 폭).
- 차원의 저주: 고차원에서 유클리드 거리 판별력 소실이 원인 → 차원 축소(PCA) 후 거리 계산하거나 코사인 유사도로 전환해 대응함 (지표: 차원 축소 전후 Top-K 순위 일치율).

**도입 후 점검 지표 (불릿):**
- 판별력: 무작위 쌍의 유사도 분포 분산으로 척도가 실제로 변별하는지 확인함.
- 정합성: 도메인 라벨과 유사도 상위 순위의 일치율(정밀도@K)로 확인함.

## Ⅵ. 실무 적용 및 결론

1. 단기: 데이터 유형(연속형/이진형/희소 벡터)을 진단해 척도 후보를 1차 선정하고, 소규모 샘플로 정규화 유무에 따른 결과 차이를 검증함.
2. 중기: 벡터 DB·검색 파이프라인에 선정 척도를 표준화하고, 차원 축소(PCA) 및 근사 최근접 이웃(ANN) 인덱스와 연계함.
3. 장기: 척도 선택 기준과 정규화 정책을 데이터 거버넌스 문서에 반영하고, 임베딩 모델 교체 시 척도 재검증 절차를 운영함.

- 기술사적 판단: 연속형 저차원 데이터는 유클리드, 고차원 희소 임베딩은 코사인, 이진 집합은 자카드를 기본 원칙으로 선택함.
- 기술사 제언: 척도 선정 전 스케일 정규화 여부와 차원 수를 먼저 확인해 차원의 저주로 인한 판별력 소실을 예방함.
