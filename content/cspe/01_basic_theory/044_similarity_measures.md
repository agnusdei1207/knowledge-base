## 미리 알고가기

- 특징 벡터($Feature$ Vector): 객체의 속성을 수치 좌표로 표현한 데이터 구조임
- 거리($Distance$): 두 객체의 차이를 수치화한 값이며 작을수록 더 가깝다고 판단함
- 정규화($Normalization$): 벡터 크기를 단위 노름이나 일정 범위로 맞추는 처리임
- 희소 벡터($Sparse$ Vector): 대부분의 값이 0인 고차원 벡터로 텍스트와 로그 데이터에 자주 나타남
- 임계값($Threshold$): 유사도 점수로 두 객체의 유사 여부를 나누는 기준값임
- Top-$k$: 유사도 점수가 높은 상위 $k$개 후보를 선택하는 기준임

## 작성 근거(검토용)

- 기출 키워드의 핵심인 코사인·자카드·유클리드를 비교표의 중심 대상으로 배치함
- 척도 선택이 결과 순위를 바꾼다는 점을 특징 첫 줄에 두어 암기식 수식 나열을 피함
- 스케일·희소성·제로 벡터는 척도 오적용을 만드는 조건이라 사례에 반영함
- 유클리드·코사인·자카드는 계산 대상과 수식이 다르므로 공통 처리 절차보다 척도별 입력·크기 영향·예외 조건을 중심으로 설명함
- 수식보다 데이터 형태와 적용 조건을 강조해 시험 답안의 선택 기준이 드러나게 함

## Ⅰ. 개요

- **정의/개념**: 유사도 측정은 두 데이터 객체의 거리, 각도, 집합 겹침을 계산해 서로 얼마나 가까운지 수치로 판단하는 기법임
- **배경/필요성**: 많은 후보를 관련성 순서로 정렬하기 위해 데이터 표현에 맞는 유사도 측정 기준이 필요함

## Ⅱ. 특징

- 같은 데이터라도 척도 선택에 따라 이웃 순위가 달라지므로 데이터 표현과 업무 목적이 먼저 정해져야 함
- 유클리드 거리는 좌표 간 절대 차이에 민감해 스케일 조정이 없으면 큰 단위 변수가 결과를 지배함
- 코사인 유사도는 벡터 크기보다 방향을 보므로 문서 길이가 다른 희소 텍스트 비교에 적합함
- 자카드 유사도는 원소 포함 여부의 겹침을 보므로 태그·구매 목록·권한 집합 비교에 적합함

## Ⅲ. 종류 및 비교

| 기준 | 유클리드 거리 | 코사인 유사도 | 자카드 유사도 |
|:---|:---|:---|:---|
| 계산 관점 | 좌표 간 직선 거리 | 벡터 방향의 각도 | 교집합과 합집합 비율 |
| 적합 데이터 | 연속형 수치 벡터 | 고차원 희소 벡터 | 집합·이진 속성 |
| 값의 크기 영향 | 좌표 단위와 값의 크기가 거리에 반영됨 | 양의 상수배에도 유사도가 유지됨(제로 벡터 제외) | 수치 크기보다 원소의 포함 여부를 반영함 |
| 주요 활용 | K-Means·센서 거리 | 문서 검색·임베딩 검색 | 중복 탐지·장바구니 유사성 |
| 예외·전처리 | 변수 표준화 | 제로 벡터 제외 | 빈 집합 결과 정의 |

> 요약: 유클리드는 값 차이, 코사인은 방향, 자카드는 겹침을 기준으로 유사성을 판단함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 데이터 표현 | 원본 객체를 수치 벡터나 집합으로 바꾸며 척도 선택의 출발점이 됨 |
| 전처리 | 표준화·정규화·불용어 제거로 거리 계산의 왜곡을 줄임 |
| 유사도 함수 | 선택한 수식으로 두 객체의 점수나 거리를 계산함 |
| 유사도 행렬 | 여러 객체 간 점수를 모아 검색·추천·군집화 입력으로 사용함 |
| 판정 기준 | 임계값 또는 Top-$k$로 최종 유사 대상을 결정함 |

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 원본 객체 | --> | 벡터/집합 | --> | 척도 계산 | --> | 순위/판정 |
+-----------+     +-----------+     +-----------+     +-----------+
```

> 요약: 유사도 계산은 원본 객체를 비교 가능한 표현으로 바꾼 뒤 척도별 점수를 산출함.

## Ⅵ. 실무 사례

1. 컨테이너 이미지 중복 탐지는 패키지 집합의 자카드 유사도를 계산하고 정밀도·재현율로 검증함
2. 문서 임베딩 검색은 제로 벡터를 제외하고 Recall@$k$·nDCG로 검색 순위를 검증함

## Ⅶ. 결론

- 유사도 측정은 데이터 표현에 맞는 척도를 고르는 문제이므로 스케일·희소성·판정 기준을 함께 통제해야 함
