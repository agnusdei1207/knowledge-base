## Ⅰ. 개요
- **정의**: 두 데이터 객체 간 거리·각도·집합 중첩을 계산하여 비슷한 정도를 정량화하는 기법
- **배경/필요성**: 추천 시스템·군집화·검색 순위 등에서 객체 간 관계 수치화 기준이 필요
- **비유**: 두 사람의 취향이 얼마나 겹치는지를 점수로 매기는 것

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 척도별 수학 공식 비교 | 유클리드(거리)·코사인(각도)·자카드(집합) | 코사인은 크기 무시·방향만 측정 명시 |
| 데이터 유형별 적합성 | 연속형 → 유클리드, 텍스트 → 코사인, 범주형 → 자카드 | 스케일 정규화 전처리 필요성 누락 주의 |

> 요약: 유사도 측정은 데이터 유형에 맞는 척도로 객체 간 관계를 수치화하는 기법임

## Ⅱ. 구성요소
```text
+------------+     +---------------+     +------------+
| Object A   |     | Measure Func  |     | Similarity |
| Object B   | --> | (Dist/Angle)  | --> | Score      |
+------------+     +---------------+     +------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 유클리드 거리 | 두 점 간 직선 거리 d = sqrt(sum((xi-yi)²)) | 지도 직선 거리 |
| 코사인 유사도 | 두 벡터 각도의 cos값, 1이면 동일 방향 | 나침반 방향 비교 |
| 자카드 계수 | 두 집합의 교집합/합집합 비율, 0~1 범위 | 공통 취미 비율 |

> 요약: 거리(유클리드)·각도(코사인)·집합 중첩(자카드)의 3대 척도로 유사도를 산출함

## Ⅲ. 절차
```text
+------------+     +------------+     +------------+     +------------+
| Data Repr  |     | Measure    |     | Score Calc |     | Apply      |
| (Vec/Set)  | --> | Selection  | --> | (Formula)  | --> | (Rank/KNN) |
+------------+     +------------+     +------------+     +------------+
```

1. **데이터 표현** — 대상을 벡터(수치형)·집합(범주형)·TF-IDF(텍스트) 등으로 변환
2. **척도 선택** — 데이터 특성에 맞는 유사도 함수 결정(연속 → 유클리드/코사인, 범주 → 자카드)
3. **점수 계산** — 선택된 공식에 두 객체를 대입하여 유사도/거리 스칼라 산출
4. **결과 활용** — 유사도 순위를 추천·KNN 분류·군집 할당 등 다운스트림 태스크에 적용

> 요약: 표현 → 척도 선택 → 점수 산출 → 태스크 적용의 4단계로 수행함

## Ⅳ. 문제점
- 스케일 민감(유클리드): 변수 단위가 다르면 큰 범위 변수가 거리를 지배
- 크기 무시(코사인): 벡터 방향만 비교하므로 절대 크기(빈도) 차이를 반영 못 함
- 희소 왜곡(자카드): 고차원 희소 벡터에서 교집합이 작아 분별력이 급감

> 요약: 스케일·크기 무시·희소성이 각 척도의 고유 약점임

## Ⅴ. 개선방안
1. 단기: 유클리드 적용 전 Min-Max 또는 Z-score 정규화로 변수 스케일 통일
2. 중기: 코사인 유사도에 TF-IDF 가중치를 결합하여 중요 단어의 영향력 반영
3. 장기: 워드 임베딩·오토인코더로 밀집 벡터화 후 코사인 유사도 적용

- 희소 데이터 분별력 저하: 교집합 과소 → LSH(Locality-Sensitive Hashing) 근사 검색 (지표: Recall@K ≥ 0.9)

> 요약: 정규화 → 가중치 보완 → 밀집 임베딩 전환으로 척도 약점을 보완함

## Ⅵ. 전망
- 향후 발전 방향: Sentence-BERT 등 사전학습 임베딩 기반 의미론적 유사도 측정으로 전환
- 기술사적 판단: 전통 척도는 경량·해석 가능 기준선으로 존속, 고정밀 시 학습 기반 유사도 병행
- 기술사 제언: 데이터 유형·차원·밀도에 따라 척도를 선택하고 정규화 전처리를 필수 적용 필요
