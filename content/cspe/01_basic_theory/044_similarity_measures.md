## 미리 알고가기

- 유사도($Similarity$): 두 객체나 데이터가 얼마나 비슷한지를 0에서 1 사이의 수치로 나타낸 지표임
- 거리 척도($Distance$): 두 데이터 사이의 차이를 수치화한 것으로, 거리가 멀수록 유사도는 낮아짐
- 특징 벡터($Feature$ $Vector$): 데이터의 속성을 수치화하여 다차원 공간상의 좌표로 표현한 것임
- 희소 데이터($Sparse$ $Data$): 대부분의 값이 0이고 극히 일부만 의미 있는 값을 가지는 데이터(예: 텍스트)임

## Ⅰ. 개요

- **정의/개념**: 유사도 측정은 다차원 공간에 매핑된 데이터 객체들 사이의 거리나 각도를 수학적으로 계산하여 서로의 닮음 정도를 정량화하는 기법이며, 코사인, 자카드, 유클리드 등이 대표적인 척도임
- **배경/필요성**: 검색 엔진의 문서 순위 결정, 추천 시스템의 사용자 매칭, 이상 탐지 등에서 수많은 데이터 중 가장 연관성 높은 항목을 빠르고 정확하게 식별하기 위해 필수적임

## Ⅱ. 특징

- 유클리드 거리는 두 점 사이의 절대적인 직선 거리를 측정하므로 데이터의 물리적 위치 차이를 가장 잘 반영하지만, 변수의 스케일에 매우 민감함
- 코사인 유사도는 벡터의 크기가 아닌 '방향성'의 일치도를 측정하므로, 문서의 길이에 상관없이 내용의 유사성을 판단하는 텍스트 마이닝 분야에 최적화되어 있음
- 자카드 유사도는 수치 데이터가 아닌 '집합' 간의 겹침 정도를 측정하므로, 공통으로 구매한 아이템이나 사용된 태그 등 이진($Binary$) 특징 비교에 강점이 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | 유클리드 거리 | 코사인 유사도 | 자카드 유사도 |
|:---|:---|:---|:---|
| **측정 방식** | 두 좌표 간 직선 거리 | 두 벡터 사이의 각도 | 교집합 / 합집합 비율 |
| **데이터 형태** | 연속형 수치 데이터 | 고차원 특징 벡터 | 범주형 집합 데이터 |
| **크기 영향** | 매우 큼 (민감함) | 없음 (방향만 고려) | 없음 (포함 여부만 고려) |
| **주요 활용** | 군집화($K-Means$), 센서 분석 | 문서 유사도, 임베딩 비교 | 추천 시스템, 텍스트 중복 검사 |

> 요약: 유클리드는 '차이'에, 코사인은 '패턴'에, 자카드는 '겹침'에 집중하는 척도임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 특징 행렬 | 비교 대상들의 속성값들을 행과 열로 정리한 수치 표임 |
| 내적 ($Dot$ $Product$) | 코사인 유사도 계산의 핵심이며, 두 벡터의 대응 원소 곱의 합임 |
| 정규화 ($Norm$) | 벡터의 크기를 1로 맞추어 크기 차이에 의한 왜곡을 제거하는 과정임 |
| 임계값 ($Threshold$) | 유사하다고 판단할 최소 기준치로, 시스템의 민감도를 조절함 |

```text
[ 주요 수식 모델 ]
- 유클리드: sqrt( Σ(xi - yi)² )
- 코사인: (A · B) / (||A|| ||B||)
- 자카드: |A ∩ B| / |A ∪ B|
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 데이터 벡터화| --> | 거리/유사도 계산| --> | 유사도 행렬 생성| --> | 순위 선정/추천|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **특징 추출** — 텍스트, 이미지 등의 비정형 데이터를 수치형 특징 벡터나 이진 집합 형태로 변환하여 연산 가능한 구조로 만듦
2. **척도 선택** — 데이터의 특성(희소성, 스케일 등)과 분석 목적에 가장 부합하는 수학적 거리 함수를 결정함
3. **수치 연산** — 정의된 공식을 적용하여 각 쌍별 유사도 점수를 산출하며, 대규모 처리 시 벡터화 연산($SIMD$)을 통해 속도를 높임
4. **결과 필터링** — 산출된 점수를 기준으로 내림차순 정렬하고, 설정된 임계값 이상의 상위 항목들을 최종 유사 객체로 확정함

## Ⅵ. 실무 적용 및 유의점

1. 유클리드 거리 기반 시스템 설계 시, 단위가 다른 변수(예: 나이와 연봉)가 섞여 있으면 큰 단위의 변수가 결과를 지배하므로 반드시 평균 0, 분산 1의 표준화 전처리를 선행해야 함
2. 고차원 희소 벡터 환경에서 코사인 유사도를 사용할 때, 모든 원소가 0인 벡터와의 비교 시 분모가 0이 되는 '제로 벡터' 문제를 방지하기 위한 예외 처리 로직을 반드시 포함해야 함

## Ⅶ. 결론

- 유사도 측정은 데이터 사이의 유대 관계를 수치로 증명하는 논리적 잣대이며, 설계자는 데이터의 물리적 분포와 비즈니스 문맥을 종합적으로 고려하여 정보의 본질적 닮음을 가장 잘 포착하는 척도를 선택해야 함
