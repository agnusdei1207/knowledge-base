## Ⅰ. 개요
- 정의: 두 객체 간의 거리나 각도를 수치화하여 얼마나 닮았는지 측정하는 지표임
- 배경: 추천 시스템, 검색 엔진, 클러스터링 알고리즘의 기초 판단 근거
- 출제 의도:
| 구분 | 내용 |
| --- | --- |
| 핵심 | 코사인 유사도, 자카드 유사도, 유클리드 거리 |

## Ⅱ. 구성요소
- ASCII 구조도
  A * B / (|A|*|B|) = Cosine
  |A n B| / |A u B| = Jaccard
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 코사인 유사도 | 두 벡터 사이의 각도 기반 유사도 | 방향성 |
| 자카드 유사도 | 두 집합 간 교집합 비율 기반 유사도 | 겹침정도 |
| 유클리드 거리 | 두 지점 사이의 직선 거리 측정 | 자 눈금 |
> 요약: 데이터의 속성(수치, 집합 등)에 따라 적합한 척도를 선택함

## Ⅲ. 절차
- ASCII 흐름도
  [특성추출] -> [지표선정] -> [수치계산] -> [유사도판단]
- 4단계 설명
1. 특성 추출: 객체를 벡터 또는 집합 형태로 변환함
2. 지표 선정: 데이터 도메인(텍스트, 수치 등)에 맞는 지표 결정함
3. 수치 계산: 정해진 수식에 따라 유사도 점수 산출함
4. 유사도 판단: 임계값 기준 또는 순위 기반으로 유사 여부 결정함
> 요약: 수학적 거리 개념을 활용하여 객체 간 연관성을 정량화함

## Ⅳ. 문제점
- 유클리드 거리는 차원이 높아질수록 거리가 멀어지는 현상 발생함
- 자카드 유사도는 빈도수 정보를 무시하는 경향 있음

## Ⅴ. 개선방안
- (단기) 고차원 데이터에는 코사인 유사도 우선 사용함
- (중기) 가중 자카드 유사도(Weighted Jaccard)로 빈도 반영함
- (장기) Mahalanobis 거리 등 상관관계 고려한 고차원 척도 도입함

## Ⅵ. 전망
- 그래프 데이터 증가에 따라 그래프 유사도 측정 기술로 발전 중임
