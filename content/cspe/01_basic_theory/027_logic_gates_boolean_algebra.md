# 📖 【암기용】 개념 완전 이해

> 목적: 논리 게이트와 부울 대수를 처음 보는 사람도 완벽히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 0과 1의 논리값을 AND·OR·NOT 등 연산으로 처리하는 디지털 회로의 기초
- **왜 필요한가**: CPU, 메모리, 통신 장비는 모든 판단과 제어를 논리식과 게이트 조합으로 구현한다.
- **핵심 직관**: 부울 대수는 조건문을 수식으로 바꾸고, 논리 게이트는 그 수식을 전기 신호 회로로 구현한다.

## 깊이 이해
- **배경·문제의식**: 디지털 시스템은 전압을 연속값이 아니라 0/1 상태로 해석한다. 복잡한 제어 조건을 회로로 만들려면 진리표, 논리식, 게이트 변환 규칙이 필요하다.
- **작동 원리**: 입력 조합별 출력을 진리표로 정리하고, 이를 SOP(곱의 합) 또는 POS(합의 곱) 논리식으로 변환한다. 드모르간 법칙으로 NAND/NOR 기반 회로 최적화가 가능하다.
- **비유**: 출입 통제에서 "사원증 AND 지문"은 AND, "카드 OR 모바일키"는 OR, "블랙리스트 NOT"은 NOT 조건과 같다.
- **구체 예시**: `F=A·B + ~C`는 A와 B가 모두 1이거나 C가 0이면 출력 1이다. 입력 3개면 진리표 행은 `2^3=8`개다.
- **흔한 오해·주의점**: XOR는 OR와 다르다. XOR는 입력이 서로 다를 때만 1이며, 패리티·가산기 sum 비트에 사용된다.

## 연결 개념
- 조합 논리 회로 — 부울식으로 가산기·멀티플렉서 구성
- 순서 논리 회로 — 게이트에 저장소를 결합해 상태 유지
- 카르노 맵 — 진리표 기반 논리식 간소화 도구


# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 논리 게이트와 부울 대수는 디지털 시스템의 조건 판단을 0/1 연산과 회로 구조로 표현하는 기반 기술이다.
> 2. **가치**: 진리표→논리식→게이트 회로 변환으로 CPU 제어, ALU, 메모리 주소 선택을 구현한다.
> 3. **판단 포인트**: 기능 구현뿐 아니라 게이트 수, 단계 지연, NAND/NOR 변환, 검증 가능한 진리표가 핵심이다.


## Ⅰ. 개요 및 필요성

논리 게이트는 디지털 회로의 최소 연산 단위이다.  
부울 대수는 0/1 명제를 AND·OR·NOT 연산으로 표현해 하드웨어 회로로 변환하는 수학 체계이다.  
복잡한 제어 로직을 검증하려면 진리표, 논리식, 회로도의 일관성이 필요하다.


## Ⅱ. 구조 및 구성요소

```text
┌──────────┐   ┌──────────┐   ┌──────────┐
│ 입력 A,B │──▶│ 부울 연산 │──▶│ 출력 F   │
└──────────┘   └────┬─────┘   └──────────┘
                    │
     ┌──────────────┼──────────────┐
     ▼              ▼              ▼
   AND/OR          NOT           XOR/NAND
```

| 구성요소 | 역할 | 대표 식 |
|:---|:---|:---|
| 기본 게이트 | AND, OR, NOT로 기본 논리 구현 | `A·B`, `A+B`, `~A` |
| 복합 게이트 | NAND, NOR, XOR로 회로 단계 축소 | `~(A·B)`, `A⊕B` |
| 진리표 | 입력 조합별 출력 검증 | 입력 n개 → `2^n`행 |
| 부울 법칙 | 식 간소화와 등가 변환 | 드모르간, 결합, 분배 |

> 요약: 논리 회로는 입력 조합, 부울 연산, 출력 검증을 진리표와 게이트 구조로 연결한다.


## Ⅲ. 동작원리 및 흐름도

```text
요구 조건 → 진리표 작성 → SOP/POS 도출 → 부울식 간소화
       → NAND/NOR 변환 → 게이트 회로 구현 → 출력 검증
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 요구 조건을 0/1 입력 변수로 분해 | 입력 변수 n개 식별 |
| 2 | 진리표 작성 | `2^n`개 조합 누락 없음 |
| 3 | SOP 또는 POS 논리식 도출 | 출력 1 또는 0 행 기준 |
| 4 | 부울 법칙으로 간소화 후 회로화 | 게이트 수·단계 수 비교 |

> 요약: 요구 조건은 진리표로 고정하고, 논리식 간소화 후 게이트 회로로 변환해 출력 일치를 검증한다.


## Ⅳ. 특징

| 구분 | 기본 논리식 구현 | NAND/NOR 중심 구현 | 판단 포인트 |
|:---|:---|:---|:---|
| 게이트 종류 | AND·OR·NOT 혼합 | NAND 또는 NOR 단일화 | 제조 셀 라이브러리 단순화 |
| 검증 방식 | 진리표 직접 비교 | 등가식 비교 필요 | 입력 n개면 `2^n`행 |
| 지연 요소 | 게이트 단계 수에 비례 | 변환 과정에서 단계 증가 가능 | critical path 산정 |
| 적용 영역 | 제어 조건, 비교기 | 표준 셀, FPGA LUT 매핑 | 면적·전력·지연 균형 |

> 요약: 부울 대수는 기능 등가성을 보장하고, NAND/NOR 변환은 구현 제약에 맞춰 게이트 구조를 조정한다.


## Ⅴ. 실무 적용 및 결론

**적용 방안 3개:**
1. RTL 설계: 조건문을 진리표로 먼저 검증하고 Verilog `assign F = (A & B) | ~C;`로 표현
2. 회로 최적화: 4입력 이하 조합 로직은 FPGA LUT 1개 매핑 여부를 확인해 단계 수 산정
3. 검증 자동화: 입력 n개가 8개 이하이면 `2^n` exhaustive test, 그 이상은 property 기반 검증 적용

**결론 (2줄):**
- 기술사 판단: 단순 조건 제어는 부울식 간소화, 면적 제약 회로는 NAND/NOR 변환, FPGA는 LUT 매핑 기준을 선택함
- 향후 방향: 저전력 SoC 설계는 논리식 등가성 검증(LEC)과 power gating 조건 검증을 함께 수행함
