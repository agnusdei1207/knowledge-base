## 핵심 답안

이진 탐색은 정렬된 데이터에서 중앙 원소와 목표 키를 비교해 탐색 범위를 매 단계 절반씩 줄이는 검색 알고리즘으로, 정렬성과 임의 접근성이 보장될 때 `O(log n)` 시간에 위치 또는 존재 여부를 판단함.

```text
정렬 데이터 + 목표 키 -> 중앙 비교 -> 좌/우 구간 선택 -> 반복 -> 위치/실패 반환
```

기술사 답안에서는 `O(log n)`보다 먼저 **정렬 전제**, **구간 경계**, **중복 키 처리**, **정렬 유지 비용**을 밝혀야 함.

## 핵심 조건

| 조건 | 의미 | 깨졌을 때 문제 |
|:---|:---|:---|
| 정렬성 | 키 기준으로 단조 순서가 유지되어야 함 | 절반 제거 논리가 성립하지 않음 |
| 임의 접근 | 중앙 위치를 즉시 읽을 수 있어야 함 | 연결 리스트에서는 중앙 접근 자체가 `O(n)` |
| 일관된 비교 | 정렬 기준과 탐색 비교 기준이 같아야 함 | 존재하는 키를 찾지 못할 수 있음 |
| 경계 규칙 | `[low, high]` 또는 `[low, high)`를 일관되게 써야 함 | 무한 루프, 누락, off-by-one 오류 |

이진 탐색은 검색 알고리즘이지만, 실제 설계에서는 정렬된 구조를 유지하는 비용까지 포함해 판단해야 함.

## 선형 탐색·해시와 비교

| 구분 | 선형 탐색 | 이진 탐색 | 해시 탐색 |
|:---|:---|:---|:---|
| 전제 | 없음 | 정렬 필요 | 해시 함수와 버킷 필요 |
| 비용 | `O(n)` | `O(log n)` | 평균 `O(1)`, 최악 `O(n)` |
| 강점 | 단순, 소규모 데이터 | 범위·순서 기반 검색 | 동등 검색 |
| 약점 | 대규모 반복 검색 비효율 | 갱신 시 정렬 유지 비용 | 정렬·범위 질의 약함 |
| 선택 상황 | 1회성, 작은 입력 | 읽기 중심 정렬 데이터 | 키 존재 여부 중심 |

정렬 배열에서 반복 검색이나 lower/upper bound가 필요하면 이진 탐색이 유리하지만, 삽입·삭제가 잦으면 균형 트리나 B-Tree가 더 적합할 수 있음.

## 구현 절차

1. **구간 초기화**: `low`, `high`를 배열 전체 범위로 설정하고 폐구간 또는 반개구간 규칙을 정함
2. **중앙 계산**: `mid = low + (high - low) / 2` 형태로 오버플로를 피하며 중앙 위치를 계산함
3. **키 비교**: `arr[mid]`와 목표 키를 비교해 발견, 왼쪽, 오른쪽 중 하나를 선택함
4. **구간 갱신**: 비교 결과에 따라 한쪽 구간을 제거하고 남은 구간에서 반복함
5. **종료 처리**: 발견 위치, 삽입 가능 위치, 실패 값을 정책에 따라 반환함

중복 키가 있으면 임의 위치, 첫 위치(lower bound), 마지막 위치(upper bound) 중 어떤 결과가 필요한지 명확히 해야 함.

## 변형과 활용

| 변형 | 목적 | 적용 사례 |
|:---|:---|:---|
| Lower Bound | 목표 이상이 처음 나오는 위치 | 삽입 위치, 범위 시작점 |
| Upper Bound | 목표보다 큰 값이 처음 나오는 위치 | 범위 끝점 |
| Parametric Search | 정답 후보 공간에서 조건 만족 경계 탐색 | 최소 용량, 최대 가능값 문제 |
| Binary Search on Answer | 배열이 아니라 답의 범위를 탐색 | 최적화 문제의 결정 문제화 |

이진 탐색은 배열 검색뿐 아니라 "조건이 단조적으로 참/거짓으로 나뉘는 문제"에도 적용 가능하므로, 단조성 증명이 중요한 선택 기준임.

## 오해와 감점 포인트

- **무정렬 데이터 적용**: 정렬 전제 없이 `O(log n)`이라고 쓰면 핵심 원리를 놓친 답안임
- **연결 리스트 적용**: 중앙 접근이 느린 구조에서는 탐색 전체가 효율적이지 않음
- **경계 조건 누락**: 빈 배열, 원소 1개, 중복 키, 찾는 값 없음 테스트가 빠지면 구현 신뢰성이 낮음
- **정렬 유지 비용 누락**: 검색만 `O(log n)`이고 삽입·삭제 후 정렬 유지 비용은 별도임
- **중복 키 반환 의미 누락**: 범위 질의에서는 단순 발견 위치가 아니라 시작·끝 경계가 필요함

## 답안 작성 포인트

1. 정의는 "정렬 데이터에서 중앙 비교로 후보 구간을 절반씩 줄이는 검색 알고리즘"으로 씀
2. 시간복잡도 `O(log n)`은 정렬성과 임의 접근성이 있을 때만 성립한다고 명시함
3. 절차는 구간 초기화, 중앙 계산, 비교, 구간 갱신, 종료 처리로 정리함
4. lower bound와 upper bound를 언급하면 범위 질의까지 확장된 답안이 됨
5. 결론은 "읽기 중심 정렬 데이터에는 강하지만 갱신이 많으면 트리·해시와 비교해야 한다"로 마무리함

> 기술사 관점에서 이진 탐색은 단순 검색 기법이 아니라 정렬 불변식과 경계 조건을 정확히 관리해야 성능 보장이 성립하는 알고리즘임.
