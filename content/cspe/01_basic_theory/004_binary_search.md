## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 정렬된 배열에서 중앙값과 목표값을 비교하여 탐색 범위를 절반씩 줄이는 O(log n) 탐색 알고리즘임 |
| **배경/필요성** | 선형 탐색 O(n)은 대규모 데이터에서 비효율적이며, 정렬 전제 하에 로그 시간 탐색이 필요함 |
| **출제 의도** | 이진 탐색의 종료 조건·경계 처리 오류와 변형(Lower/Upper Bound)을 이해하는지 평가함 |

## Ⅱ. 구성요소
```
+----------+     +----------+     +----------+
| 정렬배열  | --> | 중앙인덱스| --> | 범위축소  |
| (전제조건)|     |   mid    |     | (반복)   |
+----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| 정렬된 배열 | 오름차순 정렬이 보장된 데이터 집합(전제 조건)임 | 사전(가나다순 정렬) |
| 중앙 인덱스(mid) | `mid = (low + high) / 2`로 현재 탐색 범위의 중앙 위치를 계산함 | 사전 중간 페이지 펼치기 |
| 탐색 범위(low, high) | 목표값이 존재할 수 있는 구간의 양 끝 인덱스임 | 후보 페이지 범위 |

> 요약: 정렬 배열에서 mid를 기준으로 탐색 범위를 절반씩 축소하여 O(log n)에 탐색함.

## Ⅲ. 절차
```
+------------+     +------------+
| low, high  | --> | mid 계산   |
| 초기화     |     |            |
+------------+     +------------+
                        |
+------------+     +----+-------+
| 결과반환   | <-- | arr[mid]  |
| (찾음/없음)|     | 비교·축소  |
+------------+     +------------+
```

1. 초기화: `low = 0`, `high = n - 1`로 전체 배열을 탐색 범위로 설정함
2. mid 계산: `mid = low + (high - low) / 2`로 오버플로우를 방지하며 중앙 인덱스를 산출함
3. 비교·축소: `arr[mid] == target`이면 반환, `target < arr[mid]`이면 `high = mid - 1`, 아니면 `low = mid + 1`
4. 종료: `low > high`이면 탐색 실패를 반환함

> 요약: 초기화 → mid 계산 → 비교·범위 축소 → 종료로 O(log n) 탐색을 수행함.

## Ⅳ. 문제점
- 정렬 전제: 비정렬 데이터에는 적용 불가하며, 사전 정렬 비용 O(n log n)이 추가됨
- 경계 오류(Off-by-one): `mid ± 1` 처리를 잘못하면 무한 루프·원소 누락이 발생함
- 정수 오버플로우: `(low + high) / 2` 계산 시 정수 범위 초과 오류가 발생할 수 있음

## Ⅴ. 개선방안
- (단기) 오버플로우 방지: `mid = low + (high - low) / 2` 공식을 표준으로 사용함
- (중기) Lower/Upper Bound 변형: 중복 키가 있을 때 첫/마지막 위치를 찾는 변형을 적용함
- (장기) 보간 탐색: 데이터 분포가 균일할 때 `mid`를 비례 계산하여 O(log log n)으로 개선함

## Ⅵ. 전망
- B-Tree·B+Tree 등 디스크 기반 자료구조의 핵심 연산으로 이진 탐색 원리가 활용되며, 분산 시스템의 파티션 키 탐색에도 지속 적용될 전망임
