## 미리 알고가기

- 임의 접근(Random Access): 인덱스로 특정 원소를 $O(1)$에 읽는 성질임
- 하한(Lower Bound): 목표값 이상 원소가 처음 나타나는 위치임
- 상한(Upper Bound): 목표값 초과 원소가 처음 나타나는 위치임
- 정렬 보장: 오름차순·내림차순 중 하나로 일관된 필수 전제임
- 단조 조건: 기준값이 변해도 판단 결과가 한 방향으로만 바뀌는 성질임
- 파라메트릭 서치: 단조 조건의 답 범위를 이진 탐색으로 좁히는 기법임

## Ⅰ. 개요

- **정의/개념**: 이진 탐색은 정렬 배열에서 중앙값 비교로 후보 구간을 절반씩 줄이는 탐색 알고리즘임
- **배경/필요성**: 정렬 조회에서 선형 탐색은 입력 크기만큼 지연되므로 비교 횟수를 $O(\log n)$로 낮추는 탐색 방식이 필요함

## Ⅱ. 특징

- 후보 구간을 절반씩 버려 입력이 두 배여도 비교는 약 1회만 늘어남
- 중앙 원소를 반복 조회하므로 임의 접근 가능한 정렬 배열에 적합함
- 연결 리스트처럼 중간 접근이 $O(n)$이면 분할 효과가 상쇄됨
- 단조 조건의 최소·최대 경계값을 찾는 파라메트릭 서치로 확장 가능함

## Ⅲ. 종류 및 비교

| 판단 기준 | 이진 탐색 (Binary Search) | 선형 탐색 (Linear Search) | 해시 탐색 (Hash Search) |
|:---|:---|:---|:---|
| **사전 요건** | 정렬 데이터, 임의 접근 | 사전 정렬 불필요 | 해시 함수, 충분한 버킷 |
| **시간복잡도** | $O(\log n)$ | $O(n)$ | 평균 $O(1)$ |
| **탐색 방식** | 범위를 절반씩 좁힘 | 처음부터 끝까지 비교 | 키 해싱으로 위치 확인 |
| **장점** | 비교 횟수를 로그 수준으로 제한 | 구현 단순, 전제 조건 없음 | 평균 단건 조회 지연이 낮음 |
| **단점** | 삽입·삭제 시 정렬 유지 비용 | 데이터 증가만큼 지연 증가 | 범위 검색·정렬 결과에 부적합 |

> 요약: 정렬 대량 조회는 이진 탐색, 정렬 없는 소량 조회는 선형 탐색, 단건 키 조회는 해시 탐색이 적합함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 경계 변수 ($low, high$) | 현재 후보 구간의 시작·끝 인덱스이며 비교 결과로 갱신함 |
| 중앙점 ($mid$) | $low$와 $high$의 중간 인덱스이며 탐색 방향을 결정함 |
| 비교 논리 | $arr[mid]$와 목표값을 비교해 왼쪽·오른쪽 구간을 선택함 |
| 종료 조건 | 목표값 발견 또는 $low > high$ 시 탐색을 종료함 |

```text
[ 이진 탐색 구조 ]
정렬 배열 -> low/mid/high -> 중앙 비교 -> 왼쪽/오른쪽 선택
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 범위 초기화  | --> | 중앙 원소 비교 | --> | 탐색 범위 갱신 | --> | 종료/반환    |
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **범위 초기화**: 시작을 $low$, 끝을 $high$로 둠
2. **중앙 비교**: $mid$를 계산하고 목표값과 비교함
3. **범위 갱신**: 작으면 왼쪽, 크면 오른쪽 구간만 남김
4. **종료/반환**: 발견 시 인덱스, 구간 소멸 시 실패를 반환함

## Ⅵ. 실무 적용 및 유의점

1. 정적 배열은 생성 시 정렬을 검증하고 $mid = low + (high - low) / 2$로 오버플로를 막음
2. 하한·상한 구현은 구간 규칙을 고정하고 빈 배열·중복값·양끝값으로 검증함

## Ⅶ. 결론

- 이진 탐색은 정렬·임의 접근 전제에서 비교 비용을 낮추므로 정렬 유지와 경계 테스트가 필요함
