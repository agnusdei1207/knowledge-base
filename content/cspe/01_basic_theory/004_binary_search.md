## 미리 알고가기

- 정렬 전제: 탐색 대상이 일정한 순서로 정렬되어 있어야 함
- 임의 접근: 중간 위치의 값을 바로 읽을 수 있는 접근 방식임
- lower bound: 목표값 이상이 처음 나타나는 위치임
- upper bound: 목표값보다 큰 값이 처음 나타나는 위치임

## Ⅰ. 개요

- **정의/개념**: 이진 탐색은 정렬된 데이터에서 중간값을 확인하고, 목표값이 있을 수 없는 절반을 버리며 탐색 범위를 줄이는 알고리즘임
- **배경/필요성**: 정렬된 데이터를 반복 조회할 때 앞에서부터 모두 확인하면 입력 크기만큼 비교가 필요함. 이진 탐색은 정렬 상태를 이용해 비교 횟수를 빠르게 줄임

## Ⅱ. 특징

- 매 단계 탐색 범위를 절반으로 줄이므로 시간복잡도는 $O(\log n)$임
- 정렬된 배열과 같이 중간 위치를 바로 읽을 수 있는 구조에서 효과가 큼
- 값 존재 여부뿐 아니라 첫 위치, 마지막 위치, 조건을 만족하는 경계값도 찾을 수 있음
- 경계 갱신이 틀리면 무한 루프나 한 칸 차이 오류가 생기기 쉬움

## Ⅲ. 종류 및 비교

| 판단 기준 | 선형 탐색 | 이진 탐색 | 해시 탐색 |
|:---|:---|:---|:---|
| 전제 조건 | 없음 | 정렬과 임의 접근 | 해시 함수와 버킷 |
| 조회 방식 | 앞에서부터 순서대로 비교 | 중간값 비교로 절반 제거 | 키를 위치로 변환 |
| 범위 검색 | 비효율적 | 경계 위치 탐색에 유리 | 순서 정보가 없어 불리 |
| 적합한 상황 | 작은 입력 또는 1회 조회 | 정렬된 데이터 반복 조회 | 키 일치 조회 중심 업무 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 목표값 | 찾으려는 값이나 만족해야 하는 조건임 |
| $low$, $high$ | 현재 탐색 범위의 양 끝을 나타냄 |
| $mid$ | 이번 단계에서 비교할 중간 위치임 |
| 비교 규칙 | 목표값과 중간값을 비교해 어느 절반을 남길지 정함 |

```text
+-------------+     +----------+     +------------+
| low ~ high | --> | mid 비교 | --> | 절반 제거 |
+-------------+     +----------+     +------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 범위 설정 | --> | 중간 비교 | --> | 경계 갱신 | --> | 종료 판정 |
+-----------+     +-----------+     +-----------+     +-----------+
```

1. 정렬 방향에 맞게 시작 경계와 끝 경계를 둠
2. 중간 위치를 계산하고 목표값과 비교함
3. 목표값이 있을 수 없는 절반을 버림
4. 찾았거나 범위가 비면 종료함

## Ⅵ. 실무 적용 및 유의점

1. 정렬되지 않은 데이터에 이진 탐색을 적용하면 결과가 틀리므로, 정렬 보장 여부를 입력 계약이나 테스트로 확인해야 함
2. lower bound와 upper bound는 경계 조건이 중요하므로 빈 배열, 중복 값, 양끝 값을 별도 테스트해야 함

## Ⅶ. 결론

- 이진 탐색은 정렬과 임의 접근이 보장될 때 비교 횟수를 크게 줄이는 탐색 방식이며, 정확한 경계 갱신이 품질을 좌우함
