## Ⅰ. 개요
- **정의**: 정렬된 배열에서 탐색 범위를 절반씩 줄여 O(log N)에 목표 값을 찾는 알고리즘
- **배경/필요성**: 선형 탐색 O(N)은 데이터 규모가 커질수록 응답 시간이 비례 증가하므로, 정렬 전제 하에 로그 시간 탐색이 필요함
- **비유**: 사전에서 단어를 찾을 때 중간 페이지를 펴서 앞·뒤 절반을 버리는 방식과 동일함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 분할 정복 기반 탐색의 원리와 구현 능력 | 전제조건(정렬), `low`/`mid`/`high` 포인터 이동 로직 | 종료 조건(`low <= high`)과 `mid` 계산 시 오버플로 방지 |

> 요약: 정렬된 배열을 절반씩 줄여가는 O(log N) 탐색 기법임

## Ⅱ. 구성요소
```text
+----------+     +-----+     +-----------+
| 정렬 배열 | --> | mid | --> | 비교 판정  |
+----------+     +--+--+     +-----+-----+
                    |               |
               +----+----+    +----+----+
               | low 갱신 |    | high 갱신|
               +---------+    +---------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| `low` | 현재 탐색 범위의 시작 인덱스 | 책의 첫 페이지 위치 |
| `high` | 현재 탐색 범위의 끝 인덱스 | 책의 마지막 페이지 위치 |
| `mid` | `low + (high - low) / 2`로 산출한 중간 인덱스 | 책을 펼치는 지점 |
| 비교 판정 | `arr[mid]`와 목표 값을 비교하여 탐색 방향을 결정함 | 펼친 페이지가 목표보다 앞인지 뒤인지 판단 |

> 요약: `low`, `mid`, `high` 세 포인터와 비교 판정으로 범위를 축소함

## Ⅲ. 절차
```text
[low, high 초기화] --> mid 계산 --> 비교 --> 범위 축소 --> 반복/종료
```
- 1단계: `low = 0`, `high = N - 1`로 전체 배열을 탐색 범위로 설정함
- 2단계: `mid = low + (high - low) / 2`로 중간 인덱스를 계산함(오버플로 방지)
- 3단계: `arr[mid]`와 목표 값을 비교함
  - 일치: 탐색 종료, `mid` 반환
  - 목표 < `arr[mid]`: `high = mid - 1`로 왼쪽 절반 탐색
  - 목표 > `arr[mid]`: `low = mid + 1`로 오른쪽 절반 탐색
- 4단계: `low > high`이면 값 없음 판정, 아니면 2단계로 복귀함

> 요약: 초기화 → mid 계산 → 비교 → 범위 축소의 4단계를 반복함

## Ⅳ. 문제점
- 정렬 전제 미충족: 비정렬 배열에 적용하면 결과가 부정확함 — 사전 정렬 비용 O(N log N)이 추가됨(003 참조)
- 삽입·삭제 시 재정렬 부담: 배열 원소 변경 시마다 정렬 상태를 유지해야 함 — 동적 데이터에서 유지 비용이 O(N)임
- 경계 오류 발생 가능: `mid` 계산, 종료 조건, 포인터 갱신에서 Off-by-One 오류가 빈번함 — 변형(lower_bound, upper_bound)에서 특히 발생 빈도가 높음

> 요약: 정렬 전제, 동적 데이터 재정렬, 경계 오류가 주요 문제임

## Ⅴ. 개선방안
1. 단기: 탐색 전 정렬 여부를 검증하는 가드 로직 삽입으로 비정렬 입력 오작동을 방지함
2. 중기: 균형 이진 탐색 트리(AVL, Red-Black Tree) 또는 B-Tree 도입으로 삽입·삭제 시에도 O(log N) 탐색을 유지함
3. 장기: 표준 라이브러리의 검증된 구현(`lower_bound`, `upper_bound`, `bisect`)을 활용하여 경계 오류를 원천 차단함

> 요약: 가드 로직 → 균형 트리 → 표준 라이브러리 활용 순으로 문제를 해소함

## Ⅵ. 전망
- 발전 방향: 보간 탐색(Interpolation Search), 지수 탐색(Exponential Search) 등 분포 기반 탐색으로 확장됨
- 기술사적 판단: 이진 탐색은 분할 정복의 가장 기초적 적용이며, 트리·인덱스 설계의 근간이 되는 원리임
- 기술사 제언: 단순 배열 탐색을 넘어 DB 인덱스(B+Tree), 파일 시스템 탐색 등 실무 적용 관점에서 이해할 필요
