# 이진 탐색 (Binary Search)

## 1. 정의 및 개념

이진 탐색은 정렬된 데이터에서 중앙값을 기준으로 목표 키가 존재할 가능성이 없는 절반의 구간을 반복 제거하여 탐색 범위를 줄이는 검색 알고리즘이다.

| 구분 | 내용 |
|---|---|
| **전제 조건** | 데이터가 탐색 키 기준으로 정렬되어 있어야 함 |
| **핵심 원리** | 중앙값 비교 후 왼쪽 또는 오른쪽 절반만 남김 |
| **시간복잡도** | `O(log n)` |
| **공간복잡도** | 반복 구현 `O(1)`, 재귀 구현 `O(log n)` |
| **주요 용도** | 정렬 배열 검색, lower/upper bound, 조건 만족 경계 탐색 |

## 2. 구조 및 주요 연산

```text
low -------- mid -------- high
        arr[mid] ? target
```

1. `low`, `high`로 탐색 구간을 설정한다.
2. `mid = low + (high - low) / 2`로 중앙 위치를 계산한다.
3. `arr[mid]`와 목표 키를 비교한다.
4. 목표 키가 작으면 왼쪽 구간, 크면 오른쪽 구간만 남긴다.
5. 구간이 비거나 값을 찾을 때까지 반복한다.

중앙값 계산에서 `(low + high) / 2`는 큰 인덱스에서 오버플로우가 발생할 수 있으므로 안전한 계산식을 사용하는 것이 좋다.

## 3. 선형 탐색·해시 탐색과 비교

| 구분 | 선형 탐색 | 이진 탐색 | 해시 탐색 |
|---|---:|---:|---:|
| 전제 조건 | 없음 | 정렬 필요 | 해시 함수와 버킷 필요 |
| 평균 비용 | `O(n)` | `O(log n)` | 평균 `O(1)` |
| 범위 질의 | 비효율적 | lower/upper bound로 가능 | 기본 구조는 부적합 |
| 갱신 비용 | 낮음 | 정렬 유지 비용 필요 | 리사이즈·충돌 관리 필요 |
| 적합 상황 | 소규모·1회성 검색 | 읽기 중심 정렬 데이터 | 동등 검색 중심 |

이진 탐색은 검색 자체는 빠르지만 정렬 상태를 유지하는 비용이 별도로 존재한다.

## 4. 응용 분야

- 정렬 배열에서 특정 값 검색
- 사전·코드 테이블·정적 설정값 조회
- lower bound, upper bound를 이용한 범위 질의
- 삽입 위치 탐색
- 파라메트릭 서치(Parametric Search)
- 조건 만족 최소값·최대값 탐색
- 데이터베이스·파일 인덱스의 내부 탐색 원리

## 5. 심화 이슈 (기술사 포인트)

1. **정렬 전제**
   - 정렬되지 않은 데이터에는 이진 탐색을 적용할 수 없다.

2. **경계 조건 오류**
   - 폐구간 `[low, high]`와 반개구간 `[low, high)`를 혼용하면 무한 루프 또는 누락이 발생한다.

3. **중복 키 처리**
   - 임의 위치, 첫 위치(lower bound), 마지막 위치(upper bound) 중 반환 정책을 명확히 해야 한다.

4. **자료구조 부적합**
   - 연결 리스트는 중앙 접근이 `O(n)`이므로 이진 탐색의 장점이 사라진다.

5. **정렬 유지 비용**
   - 삽입·삭제가 잦은 환경에서는 정렬 배열보다 균형 트리, B-Tree, 해시 테이블을 검토해야 한다.

## 6. 결론

이진 탐색은 정렬성과 임의 접근성이 보장될 때 매우 효율적인 검색 알고리즘이다. 기술사 답안에서는 `O(log n)`만 강조하지 말고 정렬 전제, 경계 조건, 중복 키 처리, 정렬 유지 비용까지 포함해 적용 가능성을 판단해야 한다.
