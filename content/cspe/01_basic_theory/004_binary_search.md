## 미리 알고가기

- 임의 접근(Random Access): 배열과 같이 인덱스를 사용하여 특정 위치의 데이터를 $O(1)$의 시간복잡도로 즉시 읽는 성질임
- 하한(Lower Bound): 정렬된 배열에서 찾고자 하는 목표값 이상의 데이터가 처음 나타나는 위치임
- 상한(Upper Bound): 정렬된 배열에서 찾고자 하는 목표값을 초과하는 데이터가 처음 나타나는 위치임
- 정렬 보장: 이진 탐색을 수행하기 위해 데이터가 오름차순이나 내림차순으로 미리 정렬되어 있어야 하는 필수 전제 조건임

## Ⅰ. 개요

- **정의/개념**: 이진 탐색은 정렬된 배열에서 중앙 원소와 목표값을 비교해 남길 반쪽 구간을 선택하는 방식으로 목표 위치를 찾는 탐색 알고리즘이며, 탐색 시간은 $O(\log n)$임
- **배경/필요성**: 데이터가 이미 정렬된 조회 업무에서는 선형 탐색이 입력 크기에 비례해 지연되므로, 정렬 순서를 이용해 비교 횟수를 로그 수준으로 제한할 필요가 있음

## Ⅱ. 특징

- 매 단계에서 후보 구간의 절반을 제외하므로 입력이 두 배가 되어도 비교 횟수는 약 1회만 증가함
- 중앙 원소를 반복 조회하므로 임의 접근이 가능한 정렬 배열에서 비용이 낮고, 연결 리스트처럼 중간 접근이 $O(n)$인 구조에서는 장점이 사라짐
- 단조 조건을 만족하는 최소·최대 경계값을 찾는 파라메트릭 서치(Parametric Search)로 확장해 최적화 문제의 답 공간을 줄일 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | 이진 탐색 (Binary Search) | 선형 탐색 (Linear Search) | 해시 탐색 (Hash Search) |
|:---|:---|:---|:---|
| **사전 요건** | 정렬된 데이터, 임의 접근 가능 | 사전 정렬 불필요 | 해시 함수 및 충분한 버킷 공간 |
| **시간복잡도** | $O(\log n)$ | $O(n)$ | 평균 $O(1)$ |
| **탐색 방식** | 범위를 절반씩 분할하며 좁힘 | 처음부터 끝까지 순차적으로 비교 | 키를 해싱하여 즉시 위치 확인 |
| **장점** | 정렬 배열에서 비교 횟수를 로그 수준으로 제한 | 구현이 단순하고 전제 조건 없음 | 평균 단건 키 조회 지연이 낮음 |
| **단점** | 데이터 삽입·삭제 시 정렬 유지 비용 | 데이터 증가에 따라 선형적으로 지연 | 범위 검색이나 정렬된 결과 제공에는 별도 인덱스 또는 전체 스캔 필요 |

> 요약: 정렬된 상태의 대량 데이터에서는 이진 탐색이 효율적이며, 정렬되지 않은 소규모 데이터는 선형 탐색을, 키 매칭 위주는 해시 탐색을 사용함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 경계 변수 ($low, high$) | 탐색 중인 현재 구간의 시작과 끝 인덱스이며, 비교 결과에 따라 유동적으로 갱신됨 |
| 중앙점 ($mid$) | $low$와 $high$의 중간 인덱스로, 목표값과 대조하여 탐색 방향을 결정하는 핵심 기준점임 |
| 비교 논리 | 중앙 원소 $arr[mid]$가 목표값보다 큰지 작은지 판별하여 탐색 구간을 한쪽으로 축소함 |
| 종료 조건 | 목표값을 발견하거나, $low > high$가 되어 더 이상 탐색할 구간이 없을 때 제어를 종료함 |

```text
[ 이진 탐색 구조 ]
정렬 배열 -> low/mid/high 경계 -> 중앙 원소 비교 -> 왼쪽/오른쪽 후보 구간 선택
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 범위 초기화  | --> | 중앙 원소 비교 | --> | 탐색 범위 갱신 | --> | 종료/반환    |
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **범위 초기화** — 배열의 시작(0)을 $low$, 마지막 인덱스를 $high$로 설정하여 전체 구간을 탐색 대상으로 정의함
2. **중앙 원소 비교** — 중앙 인덱스 $mid$를 계산하고, 해당 위치의 데이터가 목표값과 일치하는지 확인함
3. **범위 갱신** — 목표값이 중앙 원소보다 작으면 $high = mid - 1$, 크면 $low = mid + 1$로 갱신하여 탐색 공간을 절반으로 줄임
4. **종료/반환** — 일치하는 값을 찾으면 해당 인덱스를 반환하고, 구간이 소멸할 때까지 못 찾으면 실패를 반환함

## Ⅵ. 실무 적용 및 유의점

1. 반복 조회가 많은 정적 배열에서는 정렬 상태를 입력 계약이나 생성 시점 검증으로 보장하고, 중간 인덱스는 $low + (high - low) / 2$로 계산해 정수 오버플로를 방지함
2. 하한(Lower Bound)과 상한(Upper Bound) 구현은 닫힌 구간과 반열린 구간을 혼용하면 한 칸 구간에서 종료하지 않을 수 있으므로, 구간 규칙과 종료 조건을 고정하고 빈 배열·중복값·양끝값 테스트로 검증함

## Ⅶ. 결론

- 이진 탐색은 정렬·임의 접근 전제가 충족될 때 선형 탐색의 비교 비용을 로그 수준으로 낮추는 알고리즘이므로, 반복 조회 시스템에서는 정렬 유지 비용과 경계 조건 테스트를 함께 설계해야 함
