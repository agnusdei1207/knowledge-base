# 이진 탐색 (Binary Search)

## 1. 개요

- **정의/개념**: 이진 탐색은 정렬된 데이터에서 중앙값과 목표 키를 비교해 탐색 범위를 절반씩 줄이는 검색 알고리즘이다.
- **배경/필요성**: 선형 탐색은 대규모 데이터에서 `O(n)` 비용이 누적되므로, 정렬성과 임의 접근성이 보장되는 경우 `O(log n)` 탐색으로 비교 횟수를 줄일 수 있다.

## 2. 특징 및 비교

| 구분 | 선형 탐색 | 이진 탐색 | 해시 탐색 |
|---|---:|---:|---:|
| 전제 조건 | 없음 | 정렬 필요 | 해시 함수 필요 |
| 평균 비용 | `O(n)` | `O(log n)` | 평균 `O(1)` |
| 범위 질의 | 비효율적 | lower/upper bound로 가능 | 기본 구조는 부적합 |
| 갱신 영향 | 낮음 | 정렬 유지 비용 필요 | 충돌·리사이즈 관리 |
| 적합 상황 | 소규모·1회성 | 읽기 중심 정렬 데이터 | 동등 검색 중심 |

이진 탐색은 검색 자체는 빠르지만, 데이터가 계속 삽입·삭제되면 정렬 유지 비용까지 포함해 판단해야 한다.

이진 탐색의 핵심 판단 차원은 정렬 전제, 임의 접근성, 조회/갱신 비율, 중복 키 처리, 경계 조건이다.

이 판단 차원은 `low`, `high`, `mid` 경계와 정렬 불변식으로 구현되므로 구조 설명이 곧 정확성 설명이다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| 정렬 데이터 | 키 기준 단조 순서가 보장된 배열·인덱스 | 전제 조건 |
| 목표 키 | 찾고자 하는 값 | 비교 기준 |
| 구간 경계 | `low`, `high` | 폐구간/반개구간 일관성 |
| 중앙 위치 | `mid` | 오버플로우 없는 계산 |
| 종료 조건 | 발견, 구간 소진, 삽입 위치 | 반환 정책 |

```text
low/high 설정 -> mid 계산 -> key 비교 -> 좌/우 구간 축소 -> 발견/실패 반환
```

이 흐름에서 정렬 전제나 경계 갱신이 깨지면 `O(log n)`이라는 장점보다 오답 위험이 먼저 발생한다.

## 4. 문제점 및 개선방안

1. **정렬 전제 위반**
   - 데이터가 정렬되지 않으면 절반 제거 논리가 성립하지 않는다.
   - **개선방안**: 정렬 불변식을 유지하고 탐색 전 정렬 기준을 검증한다.

2. **경계 조건 오류**
   - `low`, `high`, `mid` 갱신이 일관되지 않으면 무한 루프나 누락이 발생한다.
   - **개선방안**: 폐구간 또는 반개구간 템플릿을 표준화하고 빈 배열·중복 키 테스트를 수행한다.

3. **자료구조 부적합**
   - 연결 리스트처럼 중앙 접근이 느린 구조에서는 이점이 사라진다.
   - **개선방안**: 균형 트리, B-Tree, 해시 테이블 등 대체 구조를 비교한다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| 정적 코드 테이블 | 정렬 배열을 유지하고 이진 탐색으로 조회 | 조회 지연, 갱신 빈도 |
| 범위 검색 | lower bound와 upper bound로 시작·끝 위치 탐색 | 경계값 정확도 |
| 파라메트릭 서치 | 조건 만족 최소·최대 값을 이진 탐색으로 결정 | 단조성 검증, 반복 횟수 |

## 6. 결론

이진 탐색은 정렬 데이터에서 탐색 비용을 로그 수준으로 줄이는 핵심 알고리즘이다. `O(log n)` 성능은 정렬 전제, 임의 접근성, 경계 조건, 중복 키 처리, 정렬 유지 비용까지 맞을 때 의미가 있다.
