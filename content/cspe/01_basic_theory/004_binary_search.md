## 미리 알고가기

- 정렬 전제: 이진 탐색은 탐색 대상이 키 기준으로 정렬되어 있어야 성립함
- 탐색 구간: 현재 후보 범위를 나타내는 `low`, `high` 인덱스 구간임
- 중앙값: 후보 구간을 절반으로 나누기 위해 선택하는 위치 `mid`임
- 비교 결과: 찾는 키가 중앙 원소보다 작은지, 같은지, 큰지를 판단함
- 로그 시간: 매 단계 후보가 절반으로 줄어 `O(log n)` 비용이 됨

## Ⅰ. 개요

- **정의**: 이진 탐색은 정렬된 데이터에서 중앙값 비교를 반복해 탐색 범위를 절반씩 줄이며 목표 키의 존재와 위치를 찾는 검색 알고리즘임
- **배경/필요성**: 대규모 데이터에서 선형 탐색을 반복하면 검색마다 `O(n)` 비용이 누적되므로, 정렬 비용을 이미 지불했거나 정렬 상태가 유지되는 환경에서는 구간 절반 축소로 비교 횟수를 줄일 필요가 있음. 반대로 정렬되지 않은 데이터나 연결 리스트처럼 중앙 접근이 비싼 구조에는 그대로 적용하기 어려움.
- **비유**: 사전에서 단어를 찾을 때 처음부터 넘기지 않고 가운데를 펼쳐 앞쪽인지 뒤쪽인지 판단하며 범위를 줄이는 것과 같음.

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 정렬 기반 탐색 원리 확인 | 정렬 전제, 중앙 비교, 구간 축소, `O(log n)` | 무정렬 데이터 적용, 경계 조건 누락 |

> 요약: 이진 탐색은 정렬성과 임의 접근성을 전제로 비교 횟수를 로그 수준으로 줄이는 탐색 방식임.

## Ⅱ. 특징/비교

| 판단 기준 | 선형 탐색 | 이진 탐색 | 해시 탐색 |
|:---|:---|:---|:---|
| 전제 조건 | 정렬 불필요 | 키 기준 정렬 필요 | 해시 함수와 버킷 필요 |
| 평균/최악 비용 | `O(n)` | `O(log n)` | 평균 `O(1)`, 최악 `O(n)` |
| 접근 방식 | 처음부터 순차 확인 | 중앙 비교 후 구간 절반 제거 | 키를 버킷으로 직접 매핑 |
| 적합 상황 | 소규모, 1회성 검색 | 정렬 데이터의 반복 검색 | 동등 검색 중심의 동적 집합 |
| 한계 | 데이터가 크면 비교 횟수 증가 | 삽입·삭제 후 정렬 유지 필요 | 범위 검색과 순서 질의가 약함 |

> 요약: 이진 탐색은 정렬 유지 비용을 감당할 수 있고 범위·순서 기반 질의가 필요한 경우 선택 가치가 큼.

- 배열에서 중앙 인덱스를 즉시 계산할 수 있어야 `O(log n)` 장점이 유지됨
- 중복 키가 있으면 첫 위치, 마지막 위치, 임의 위치 중 어떤 결과가 필요한지 정해야 함
- 정렬 배열은 삽입·삭제마다 원소 이동이 `O(n)`이라, 갱신이 잦으면 `O(log n)`으로 정렬을 유지하는 균형 트리나 B-Tree(Balanced Tree)가 유리함

## Ⅲ. 구성요소

```text
+------------+      +------------+      +------------+
| 정렬 데이터| ---> | 중앙 비교  | ---> | 구간 갱신  |
+------------+      +------------+      +------------+
       |                    |                   |
       v                    v                   v
+------------+      +------------+      +------------+
| 목표 키    |      | 구간 경계  |      | 탐색 결과  |
+------------+      +------------+      +------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 정렬 데이터 | 키 기준으로 단조 순서가 보장된 배열 또는 인덱스 구조임 | 가나다순 사전 |
| 목표 키 | 찾고자 하는 값이며 비교 결과에 따라 탐색 방향을 결정함 | 찾는 단어 |
| 구간 경계 | `low`, `high`로 후보 범위를 표현하고 반복마다 좁힘 | 펼칠 수 있는 페이지 범위 |
| 중앙 원소 | 후보 구간의 중간 위치 값으로 비교 기준이 됨 | 가운데 페이지 |
| 종료 조건 | 키 발견, 구간 소진, lower/upper bound 도달 여부를 판단함 | 검색 종료 표시 |

> 요약: 이진 탐색은 정렬 데이터, 목표 키, 구간 경계, 중앙 비교가 결합되어 후보 범위를 절반씩 줄이는 구조임.

- `mid = low + (high - low) / 2` 형태는 큰 인덱스에서 오버플로를 피하는 구현 방식임
- 폐구간 `[low, high]`와 반개구간 `[low, high)` 중 하나를 선택해 끝까지 일관되게 써야 함
- lower bound와 upper bound는 같은 원리지만 종료 조건과 구간 갱신 규칙이 다름

## Ⅳ. 절차

```text
+----------+      +----------+      +----------+      +----------+
| 구간설정 | ---> | 중앙계산 | ---> | 키비교   | ---> | 결과/반복|
+----------+      +----------+      +----------+      +----------+
                                      |                  |
                                      v                  v
                                +----------+      +----------+
                                | 범위축소 |      | 종료판정 |
                                +----------+      +----------+
```

1. **입력/요구 식별** - 정렬 여부, 탐색 키, 중복 키 처리 방식, 반환할 위치의 의미를 확인함
2. **중앙 비교 수행** - 현재 구간에서 `mid`를 계산하고 `arr[mid]`와 목표 키를 비교함
3. **구간 갱신** - 목표 키가 작으면 왼쪽, 크면 오른쪽으로 후보 구간을 줄이고 동등하면 정책에 따라 반환하거나 계속 탐색함
4. **출력/효과 확인** - 발견 위치, 삽입 가능 위치, 실패 표시를 반환하고 경계 조건 테스트로 검증함

> 요약: 이진 탐색 절차는 중앙 비교 결과를 이용해 후보 구간을 반복 축소하고 종료 조건에서 위치를 확정하는 흐름임.

- 반복 구현은 호출 스택 프레임 오버헤드가 없고, 재귀 구현은 구간 분할 구조를 코드에 그대로 드러냄
- 정렬 기준과 비교 기준이 다르면 탐색 결과가 틀릴 수 있음
- 범위 검색은 두 번의 이진 탐색으로 시작 위치와 끝 위치를 각각 찾는 방식이 일반적임

## Ⅴ. 문제점 및 개선방안

- **P1 정렬 전제 위반**: 데이터가 정렬되어 있지 않거나 정렬 기준과 비교 기준이 다르면 절반 제거 판단이 성립하지 않음
- **P2 경계 조건 오류**: `low`, `high`, `mid` 갱신 규칙이 일관되지 않으면 무한 루프, 누락, 인덱스 오류가 발생함
- **P3 자료구조 부적합**: 연결 리스트나 순차 파일처럼 중앙 접근 비용이 `O(n)`이면 전체 탐색 이점이 사라짐

> 요약: 이진 탐색의 핵심 위험은 정렬성, 경계 갱신, 임의 접근성 중 하나가 깨질 때 발생함.

### 개선방안

- **P1 대응**: 삽입·갱신 시 정렬 불변식을 유지하고 탐색 전 샘플 검증 또는 인덱스 메타데이터를 확인함 (확인: 정렬 불변식 테스트)
- **P2 대응**: 구간 표현을 폐구간 또는 반개구간으로 표준화하고 lower/upper bound 템플릿을 분리함 (확인: 빈 배열, 1개 원소, 중복 키 테스트)
- **P3 대응**: 임의 접근이 어려운 데이터는 균형 트리, B-Tree, 해시 테이블 같은 구조로 전환함 (확인: 중앙 접근 비용 측정)

> 요약: 이진 탐색은 전제 조건을 코드 불변식으로 고정하고 경계 템플릿을 표준화해야 off-by-one 오류 없이 적용됨.

## Ⅵ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| 정렬 배열 조회 | 읽기 중심 설정값·코드 테이블을 정렬 배열로 유지하고 이진 탐색으로 조회함 | 조회 지연, 갱신 빈도 |
| 범위 질의 | lower bound와 upper bound를 분리해 특정 기간·가격·키 범위의 시작과 끝 위치를 찾음 | 경계값 정확도, 범위 조회 시간 |

> 요약: 이진 탐색은 정렬 불변식이 유지되는 읽기 중심 데이터와 범위 질의에서 실무 효율이 큼.

## Ⅶ. 전망

- **발전 방향**: 데이터베이스 인덱스, 검색 엔진, 표준 라이브러리의 범위 질의에서 이진 탐색 계열은 계속 핵심 보조 연산으로 사용됨
- **기술사적 판단**: 단일 검색 비용보다 정렬 유지 비용, 삽입·삭제 빈도, 범위 질의 필요성을 함께 평가해야 함
- **기술사 제언**: 답안에서는 `O(log n)`만 쓰지 말고 정렬 전제와 구간 갱신 규칙을 함께 제시해야 함
