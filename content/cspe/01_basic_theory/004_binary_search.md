## 미리 알고가기

- 정렬 전제: 탐색 대상은 오름차순 또는 내림차순으로 정렬되어 있어야 함
- 임의 접근: 중간 원소에 즉시 접근할 수 있어야 하므로 배열 기반 구조가 유리함
- 단조성: 조건이 한 방향으로만 바뀌는 성질이며 파라메트릭 서치의 근거가 됨

## Ⅰ. 개요

- **정의/개념**: 이진 탐색은 정렬된 데이터에서 중간값과 목표값을 비교해 탐색 구간을 절반씩 줄이며 원하는 값을 찾는 $O(\log n)$ 탐색 알고리즘임
- **배경/필요성**: 대량 데이터에서 선형 탐색은 응답시간이 입력 크기에 비례해 증가하므로, 정렬 상태를 활용해 비교 횟수를 로그 차수로 줄이는 방식이 필요함

## Ⅱ. 특징

- 탐색 범위를 매 단계 절반으로 줄이므로 비교 횟수가 적고 규모가 커질수록 효과가 커짐
- 정렬과 임의 접근이 전제되므로 연결 리스트나 비정렬 입력에는 직접 적용하기 어렵음
- 동일 원소 존재 여부 확인뿐 아니라 lower bound, upper bound, 파라메트릭 서치로 확장 가능함
- 구현은 단순하지만 경계 조건 처리 오류가 잦아 실무에서는 종료 조건과 중앙값 계산이 중요함

## Ⅲ. 종류 및 비교

| 판단 기준 | 선형 탐색 | 이진 탐색 | 해시 탐색 |
|:---|:---|:---|:---|
| 전제 조건 | 없음 | 정렬 + 임의 접근 | 해시 함수, 추가 메모리 |
| 시간복잡도 | $O(n)$ | $O(\log n)$ | 평균 $O(1)$ |
| 범위 검색 | 비효율적 | 유리함 | 불리함 |
| 데이터 순서 활용 | 하지 않음 | 적극 활용 | 하지 않음 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| $low$ | 탐색 구간의 시작 인덱스이며 갱신 누락 시 무한 반복 위험 |
| $high$ | 탐색 구간의 끝 인덱스이며 종료 조건 판단에 사용함 |
| $mid$ | 현재 비교 대상 중간 인덱스이며 오버플로우 방지 계산 필요 |
| 비교 규칙 | 목표값과 중간값의 대소 비교이며 정렬 방향과 일치해야 함 |

```text
+---------+     +---------+     +-----------+     +-----------+
| low/high | --> | mid 계산  | --> | 대소 비교    | --> | 구간 축소    |
+---------+     +---------+     +-----------+     +-----------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 범위설정 | --> | 중간비교 | --> | 절반선택 | --> | 종료판정 |
+----------+     +----------+     +----------+     +----------+
```

1. **범위설정**: 전체 구간을 $low$와 $high$로 초기화함
2. **중간비교**: $mid = low + (high - low)/2$로 중간값을 계산해 비교함
3. **절반선택**: 목표값이 더 작으면 왼쪽, 더 크면 오른쪽 구간만 남김
4. **종료판정**: 값을 찾거나 $low > high$가 되면 탐색을 종료함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 정렬 전제를 놓쳐 비정렬 데이터에 적용하면 결과가 보장되지 않음
   - 해결방안: 탐색 전에 정렬 보장 여부를 계약 조건으로 명시하고 입력 정렬 상태로 검증함
2. 문제: 경계 조건 오류가 발생해 중복 값, 첫 원소, 마지막 원소에서 off-by-one 오류가 자주 생김
   - 해결방안: lower bound와 upper bound 테스트 케이스를 별도로 두고 경계값 테스트 통과로 검증함
3. 문제: 연결 리스트에 잘못 적용해 중간 원소 접근 비용 때문에 실제 성능 이점이 사라짐
   - 해결방안: 임의 접근 구조가 아니면 다른 탐색 구조를 선택하고 자료구조 적합성으로 검증함

## Ⅶ. 적용 사례

- 사전식 문자열 검색에서는 정렬된 사전 목록에서 빠르게 범위를 찾으며, 평균 비교 횟수와 응답시간으로 결과를 확인함
- 용량 계획 문제에서는 가능한 값의 범위에서 조건 만족 최소값을 찾는 파라메트릭 서치에 적용하며, 반복 횟수와 판정 함수 비용으로 결과를 확인함
- 데이터베이스 보조 인덱스에서는 정렬된 페이지 내 위치 탐색에 사용하며, 페이지 탐색 시간과 범위 조회 성능으로 결과를 확인함

## Ⅷ. 결론

이진 탐색은 정렬과 임의 접근이라는 전제가 만족될 때 가장 간결하게 로그 차수 성능을 확보하는 기본 탐색 기법임.
