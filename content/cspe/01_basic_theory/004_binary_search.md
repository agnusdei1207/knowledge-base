## 미리 알고가기

- 임의 접근(Random Access): 배열과 같이 인덱스를 사용하여 특정 위치의 데이터를 $O(1)$의 시간복잡도로 즉시 읽는 성질임
- 하한(Lower Bound): 정렬된 배열에서 찾고자 하는 목표값 이상의 데이터가 처음 나타나는 위치임
- 상한(Upper Bound): 정렬된 배열에서 찾고자 하는 목표값을 초과하는 데이터가 처음 나타나는 위치임
- 정렬 보장: 이진 탐색을 수행하기 위해 데이터가 오름차순이나 내림차순으로 미리 정렬되어 있어야 하는 필수 전제 조건임

## Ⅰ. 개요

- **정의/개념**: 이진 탐색은 정렬된 배열에서 중간값과 목표값을 비교하여 탐색 범위를 매번 절반으로 줄여나가며 원하는 값을 찾는 시간복잡도 $O(\log n)$의 탐색 알고리즘임
- **배경/필요성**: 데이터 규모가 방대한 시스템에서 전체 데이터를 순차적으로 확인하는 선형 탐색($O(n)$)은 응답 지연을 초래하므로, 정렬된 상태를 활용하여 탐색 비용을 획기적으로 낮추는 최적화 절차가 필요함

## Ⅱ. 특징

- 매 단계에서 탐색 대상 구간을 1/2로 제거하므로 데이터가 기하급수적으로 늘어나도 연산 횟수는 매우 느리게 증가하여 대용량 처리에 유리함
- 배열의 중간 인덱스로 직접 접근해야 하므로, 데이터가 선형 메모리에 연속적으로 배치된 배열 구조에서 최적의 성능을 발휘함
- 단순한 데이터 검색을 넘어 특정 범위를 만족하는 경계값을 찾는 파라메트릭 서치(Parametric Search)로 확장하여 최적화 문제 해결에 활용할 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | 이진 탐색 (Binary Search) | 선형 탐색 (Linear Search) | 해시 탐색 (Hash Search) |
|:---|:---|:---|:---|
| **사전 요건** | 정렬된 데이터, 임의 접근 가능 | 사전 정렬 불필요 | 해시 함수 및 충분한 버킷 공간 |
| **시간복잡도** | $O(\log n)$ | $O(n)$ | 평균 $O(1)$ |
| **탐색 방식** | 범위를 절반씩 분할하며 좁힘 | 처음부터 끝까지 순차적으로 비교 | 키를 해싱하여 즉시 위치 확인 |
| **장점** | 대규모 데이터에서 매우 빠름 | 구현이 단순하고 전제 조건 없음 | 특정 키 조회 속도가 가장 빠름 |
| **단점** | 데이터 삽입·삭제 시 정렬 유지 비용 | 데이터 증가에 따라 선형적으로 지연 | 범위 검색이나 정렬된 결과 불가 |

> 요약: 정렬된 상태의 대량 데이터에서는 이진 탐색이 효율적이며, 정렬되지 않은 소규모 데이터는 선형 탐색을, 키 매칭 위주는 해시 탐색을 사용함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 경계 변수 ($low, high$) | 탐색 중인 현재 구간의 시작과 끝 인덱스이며, 비교 결과에 따라 유동적으로 갱신됨 |
| 중앙점 ($mid$) | $low$와 $high$의 중간 인덱스로, 목표값과 대조하여 탐색 방향을 결정하는 핵심 기준점임 |
| 비교 논리 | 중간값($arr[mid]$)이 목표값보다 큰지 작은지 판별하여 탐색 구간을 한쪽으로 축소함 |
| 종료 조건 | 목표값을 발견하거나, $low > high$가 되어 더 이상 탐색할 구간이 없을 때 제어를 종료함 |

```text
[ 이진 탐색 구조 ]
Step 1: [low ....... mid ....... high]  (mid와 비교)
Step 2: [low ... high] (왼쪽)  또는  [low ... high] (오른쪽)으로 범위 축소
Step 3: 구간이 1개가 되거나 교차할 때까지 반복
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 범위 초기화  | --> | 중앙값 비교   | --> | 탐색 범위 갱신 | --> | 종료/반환    |
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **범위 초기화** — 배열의 시작(0)을 $low$, 마지막 인덱스를 $high$로 설정하여 전체 구간을 탐색 대상으로 정의함
2. **중앙값 비교** — 중앙 인덱스 $mid$를 계산하고, 해당 위치의 데이터가 목표값과 일치하는지 확인함
3. **범위 갱신** — 목표값이 작으면 $high = mid - 1$, 크면 $low = mid + 1$로 갱신하여 탐색 공간을 절반으로 줄임
4. **종료/반환** — 일치하는 값을 찾으면 해당 인덱스를 반환하고, 구간이 소멸할 때까지 못 찾으면 실패를 반환함

## Ⅵ. 실무 적용 및 유의점

1. 구현 시 중간 인덱스 계산($mid = (low + high) / 2$)에서 정수 오버플로가 발생할 수 있으므로 $low + (high - low) / 2$ 방식을 적용하고, 정렬되지 않은 입력에 대비하여 수행 전 사전 정렬 상태를 검증하거나 전처리 절차를 둬야 함
2. 특정 값보다 크거나 같은 첫 위치를 찾는 $Lower Bound$나 초과하는 첫 위치를 찾는 $Upper Bound$를 활용할 때는 경계 조건($high$의 초기값 설정 등)에 따른 무한 루프 가능성을 통제하고 실제 경계 데이터로 검증해야 함

## Ⅶ. 결론

- 이진 탐색은 정렬된 대규모 데이터 처리에서 성능 병목을 해결하는 핵심 알고리즘이며, 실제 시스템 적용 시에는 데이터의 정렬 상태 유지 비용과 탐색 범위의 경계 조건 처리를 완벽하게 관리해야 함
