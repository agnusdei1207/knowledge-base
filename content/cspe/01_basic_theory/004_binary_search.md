## 미리 알고가기

- 정렬 전제: 탐색 대상은 오름차순 또는 내림차순으로 정렬되어 있어야 함
- 임의 접근: 중간 원소에 즉시 접근할 수 있어야 하므로 배열 기반 구조가 유리함
- lower bound: 목표값 이상이 처음 나타나는 위치를 찾는 방식임
- upper bound: 목표값을 초과하는 값이 처음 나타나는 위치를 찾는 방식임
- 단조성: 조건이 한 방향으로만 바뀌는 성질이며 파라메트릭 서치의 근거가 됨

## Ⅰ. 개요

- **정의/개념**: 이진 탐색은 정렬된 데이터에서 중간값과 목표값을 비교해 탐색 구간을 절반씩 줄이면서 원하는 값이나 경계 위치를 찾는 탐색 알고리즘임
- **배경/필요성**: 대량 데이터에서 선형 탐색은 비교 횟수가 입력 크기에 비례해 늘어나므로, 정렬 상태를 활용해 비교 횟수를 $O(\log n)$으로 줄이는 방식이 필요함

## Ⅱ. 특징

- 탐색 범위를 매 단계 절반으로 줄이므로 데이터가 커질수록 비교 횟수 절감 효과가 뚜렷해짐
- 중간 원소에 즉시 접근할 수 있어야 하므로 배열이나 인덱스 기반 페이지 구조와 잘 맞음
- 값의 존재 확인뿐 아니라 첫 위치, 마지막 위치, 조건을 만족하는 최소값 탐색으로 확장할 수 있음
- 구현은 짧지만 경계 갱신이 틀리면 무한 루프나 첫 위치 오류가 생기기 쉬워 세밀한 테스트가 필요함

## Ⅲ. 종류 및 비교

| 판단 기준 | 선형 탐색 | 이진 탐색 | 해시 탐색 |
|:---|:---|:---|:---|
| 전제 조건 | 별도 전제 없이 앞에서부터 차례로 비교하면 됨 | 정렬된 데이터와 중간 원소에 바로 접근할 수 있는 구조가 전제됨 | 해시 함수와 추가 메모리가 준비돼 있어야 함 |
| 조회 방식 | 값을 찾을 때까지 모든 원소를 순서대로 확인함 | 중간값 비교만으로 남길 구간을 절반씩 줄여 나감 | 키를 버킷으로 바로 매핑해 원하는 위치를 찾음 |
| 범위 검색 | 범위를 찾을 수는 있지만 비교 횟수가 많이 듦 | 시작 위치와 끝 위치를 함께 찾기 쉬워 범위 검색에 유리함 | 순서 정보가 없어 범위 검색에 불리함 |
| 적합한 상황 | 입력이 작거나 정렬되지 않은 데이터를 한 번만 확인할 때 적합함 | 정렬된 데이터를 반복 조회하거나 경계 위치를 찾아야 할 때 적합함 | 정확한 키 일치 조회를 아주 자주 수행할 때 적합함 |

> 요약: 이진 탐색은 정렬과 임의 접근이 필요하지만 범위 탐색과 경계 탐색까지 처리할 수 있어 반복 조회 환경에서 강함

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 목표값 $target$ | 찾으려는 값이나 만족해야 하는 조건이 분명해야 어느 절반을 버릴지 정확히 결정할 수 있음 |
| $low$와 $high$ | 탐색 구간의 시작과 끝을 나타내며 두 경계가 올바르게 갱신돼야 같은 구간을 반복하지 않음 |
| $mid$ | 현재 비교할 중간 인덱스이므로 큰 배열에서는 오버플로우를 피하는 방식으로 계산해야 함 |
| 비교 규칙 | 목표값과 중간값의 대소 관계를 해석하는 기준이며 정렬 방향과 맞지 않으면 잘못된 절반을 남기게 됨 |

> 요약: 이진 탐색은 목표값, 좌우 경계, 중앙값, 비교 규칙이 맞물려야 절반 제거가 정확하게 동작함

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 범위설정 | --> | 중간비교 | --> | 절반선택 | --> | 종료판정 |
+----------+     +----------+     +----------+     +----------+
```

1. **범위 초기화**: 전체 구간을 $low$와 $high$로 잡고 목표값을 정함
2. **중간 계산**: $mid = low + \frac{high - low}{2}$로 현재 비교할 위치를 계산함
3. **절반 선택**: 목표값이 더 작으면 왼쪽 구간만 남기고 더 크면 오른쪽 구간만 남김
4. **반복 종료**: 값을 찾거나 $low > high$가 되면 탐색을 끝내고 필요하면 경계 위치를 반환함

## Ⅵ. 실무 적용 및 유의점

1. 정렬된 사전 목록 검색에서는 이진 탐색으로 비교 횟수를 줄이되 입력이 정렬돼 있는지 먼저 보장하고 평균 비교 횟수와 응답시간으로 확인함
2. 조건을 만족하는 최소값을 찾는 용량 계획 문제에서는 경계 갱신이 틀리면 답이 어긋나므로 처음 조건을 만족하는 위치를 찾는 형태로 구현하고 반복 횟수와 예제 정답률로 확인함

## Ⅶ. 결론

이진 탐색은 정렬과 임의 접근이라는 전제가 맞을 때 비교 횟수를 $O(\log n)$으로 줄이는 가장 기본적인 탐색 기법이므로, 범위 탐색과 조건 판정 문제에서 우선 검토할 가치가 큼.
