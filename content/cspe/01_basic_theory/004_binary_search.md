## 미리 알고가기

- 정렬 전제: 이진 탐색은 탐색 대상이 단조 증가 또는 단조 감소 순서로 정렬되어 있어야 함
- 탐색 구간: `low`와 `high`가 현재 후보 범위를 나타내며 반복마다 절반으로 줄어듦
- 하한·상한 탐색: Lower Bound는 처음으로 조건을 만족하는 위치, Upper Bound는 조건을 초과하는 첫 위치를 찾음

## Ⅰ. 개요

- **정의**: 정렬된 자료에서 탐색 범위를 절반씩 줄이는 탐색 알고리즘임
- **배경/필요성**: 선형 탐색은 입력 크기만큼 비교가 필요하므로, 정렬된 데이터에서는 로그 시간으로 후보 범위를 줄이는 방식이 필요함
- **비유**: 사전에서 가운데 페이지를 펼치고 찾는 단어가 앞인지 뒤인지 판단해 절반씩 버리는 방식임

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 로그 시간 탐색의 전제와 경계 처리 이해 확인 | 정렬 전제, `low/mid/high`, 종료 조건, `O(log n)` | 정렬 전제 누락, off-by-one 오류 |

> 요약: 이진 탐색은 정렬 전제와 경계 불변식을 지켜야 `O(log n)` 탐색이 성립함.

## Ⅱ. 특징/비교

| 판단 기준 | 선형 탐색 | 이진 탐색 |
|:---|:---|:---|
| 전제 조건 | 정렬 불필요 | 정렬 또는 단조 조건 필요 |
| 시간복잡도 | `O(n)` | `O(log n)` |
| 접근 방식 | 처음부터 순차 비교 | 중앙 기준으로 후보 절반 제거 |

> 요약: 이진 탐색은 정렬 비용을 감수하고 반복 탐색의 비교 횟수를 로그 수준으로 줄이는 선택임.

- 배열처럼 임의 접근이 가능한 자료구조에서 효과가 큼
- 한 번 찾고 끝나는 소량 데이터보다 정렬된 데이터에 반복 질의가 많은 경우에 적합함
- Lower/Upper Bound, 파라메트릭 서치처럼 "조건을 만족하는 경계"를 찾는 문제로 확장됨

## Ⅲ. 구성요소

```text
+----------+      +----------+      +----------+
| 정렬자료 | ---> | 중앙값   | ---> | 구간축소 |
+----------+      +----------+      +----------+
     |                                      |
     v                                      v
+----------+                         +----------+
| 목표값   |                         | 종료조건 |
+----------+                         +----------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 정렬 자료 | 탐색 대상이 순서대로 배치된 배열 또는 단조 함수 범위임 | 가나다순 사전 |
| 중앙 인덱스 | `low + (high - low) / 2`로 계산하는 비교 기준 위치임 | 펼친 가운데 페이지 |
| 탐색 구간 | 목표값이 존재할 수 있는 후보 범위임 | 남겨 둔 페이지 범위 |
| 종료 조건 | 값 발견, 구간 소진, 경계 수렴을 판단하는 조건임 | 더 볼 페이지가 없는 상태 |

> 요약: 이진 탐색은 정렬 자료, 중앙 비교, 구간 축소, 종료 조건으로 구성됨.

## Ⅳ. 절차

```text
+----------+      +----------+      +----------+      +----------+
| 범위설정 | ---> | 중앙비교 | ---> | 절반제거 | ---> | 종료판단 |
+----------+      +----------+      +----------+      +----------+
```

1. **범위 설정**: `low = 0`, `high = n - 1`처럼 탐색 가능한 전체 구간을 잡음
2. **중앙 비교**: `mid` 위치 값과 목표값을 비교함
3. **절반 제거**: 목표값이 작으면 오른쪽, 크면 왼쪽 후보를 제거함
4. **종료 판단**: 목표값 발견 또는 `low > high` 조건으로 실패를 반환함

> 요약: 매 반복마다 중앙을 기준으로 목표값이 없는 절반을 제거해 탐색 범위를 축소함.

## Ⅴ. 문제점

- **P1 경계 조건 오류**: `low < high`와 `low <= high` 선택이 일관되지 않으면 무한 루프 또는 마지막 원소 누락이 발생함
- **P2 정렬 불변식 위반**: 데이터가 정렬되지 않았거나 탐색 중 변경되면 중앙 비교 결과가 후보 제거 근거가 되지 않음
- **P3 접근 비용 간과**: 연결 리스트, 원격 API, 디스크 랜덤 접근에서는 중앙 위치 접근 비용이 커져 로그 비교 이점이 줄어듦

> 요약: 이진 탐색의 오류는 대부분 정렬 전제, 구간 불변식, 접근 비용을 확인하지 않아 발생함.

## Ⅵ. 개선방안

1. **단기**: `low`, `mid`, `high` 갱신 규칙과 종료 조건을 코드 리뷰 체크리스트로 고정함
2. **중기**: Lower/Upper Bound 템플릿을 표준화하고 중복 값·빈 배열·단일 원소 테스트를 자동화함
3. **장기**: 반복 질의가 많은 데이터는 정렬 유지, 인덱스, B-Tree 등 검색 구조로 운영함

- **P1 대응**: 구간 불변식과 경계 테스트를 명시함 (확인: 빈 배열, 첫/끝 원소, 미존재 값 테스트)
- **P2 대응**: 탐색 전 정렬 상태 또는 단조 조건을 검증함 (확인: 정렬 검증, 변경 잠금)
- **P3 대응**: 임의 접근 비용이 큰 매체는 B-Tree, 해시, 캐시 인덱스를 검토함 (확인: I/O 횟수, 질의 지연)

> 요약: 이진 탐색은 템플릿 암기보다 불변식 검증과 자료구조 선택이 품질을 좌우함.

## Ⅶ. 전망

- 이진 탐색은 단순 배열 탐색을 넘어 임계값 결정, 용량 산정, 최적화 문제의 파라메트릭 서치로 계속 활용됨
- 대규모 저장소에서는 이진 탐색 원리가 B-Tree, LSM Tree, 인덱스 탐색과 결합되어 I/O 절감 기준이 됨
- 기술사는 `O(log n)`만 쓰지 말고 정렬 유지 비용과 접근 매체 비용까지 포함해 설계 판단을 제시해야 함
