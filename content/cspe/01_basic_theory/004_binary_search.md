## Ⅰ. 개요
- 정렬된 데이터에서 탐색 범위를 절반씩 좁혀가며 대상을 찾는 기법임.
- O(log n)의 시간복잡도를 가지며 대규모 데이터 탐색에 효율적임.
- [표] 출제 의도: 분할 정복 기반의 고속 탐색 알고리즘 이해도 측정.

## Ⅱ. 구성요소
- ASCII 구조도
  [ Low |...| Mid |...| High ]
            ^ Compare Target

| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| Mid Index | 탐색 범위의 중앙 위치값 | 책 중간 펼치기 |
| Sorted Array | 반드시 정렬되어 있어야 하는 데이터셋 | 사전 (Dictionary) |
| Target | 찾고자 하는 데이터의 키값 | 찾는 단어 |

> 요약: 정렬을 전제로 범위 축소를 통해 탐색 횟수를 획기적으로 줄임.

## Ⅲ. 절차
- ASCII 흐름도
  Init(Low, High) -> Check Mid -> Adjust Boundary -> Repeat/End

1. 탐색 범위의 시작(Low)과 끝(High) 인덱스를 설정함.
2. 중앙값(Mid)과 대상(Target)을 비교함.
3. 대상이 작으면 High를, 크면 Low를 조정하여 범위를 절반으로 줄임.
4. 값을 찾거나 범위가 역전될 때까지 반복 수행함.

> 요약: 반복적 분할을 통해 탐색 공간을 로그 단위로 축소함.

## Ⅳ. 문제점
- 데이터가 사전에 정렬되어 있지 않으면 적용이 불가능함.
- 잦은 삽입과 삭제가 발생하는 데이터셋에서는 정렬 유지 비용이 큼.

## Ⅴ. 개선방안
- 단기: 삽입/삭제 시 정렬 상태를 유지하는 이진 탐색 트리 고려함.
- 중기: 데이터 변경 주기에 따른 일괄 정렬 및 탐색 전략 수립함.
- 장기: 해시 기반 탐색과 결합하여 동적 환경 대응력 강화함.

## Ⅵ. 전망
- 머신러닝을 활용해 데이터의 누적 분포 함수(CDF)를 학습하고 탐색 위치를 예측하는 '학습된 인덱스(Learned Index)' 구조가 전통적 이진 탐색을 보완할 것임.
- NewSQL 및 시계열 데이터베이스(TSDB)에서 고속 데이터 검색을 위해 하드웨어 트랜잭션 메모리(HTM)와 결합된 병렬 탐색 기법이 CSF로 도입될 전망임.
- 비휘발성 메모리(NVM) 환경에 최적화된 저지연 탐색 알고리즘이 엣지 컴퓨팅의 데이터 처리 속도를 혁신하는 핵심 기술이 될 것임.
