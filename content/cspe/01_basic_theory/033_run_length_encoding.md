## Ⅰ. 개요
- 정의: 연속적으로 반복되는 데이터를 (반복 횟수, 데이터 값)의 쌍으로 표현하는 기법임
- 배경/필요성: 동일한 값이 길게 나열되는 데이터(이미지 배경 등)의 크기를 획기적으로 줄임
- 출제 의도: RLE의 동작 원리 및 압축 효율이 극대화되는 케이스 이해

## Ⅱ. 구성요소
- ASCII 구조도
  Original: A A A A A B B B C C D
            \___ ___/ \_ _/ \_/ |
  Encoded : (5, A) (3, B) (2, C) (1, D)

- 구성요소 표
| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| 런 (Run) | 동일한 데이터가 연속되는 구간 | 줄서기 |
| 런 길이 (Length) | 해당 구간에서 반복된 횟수 | 인원수 |
| 제어 문자 (Escape) | RLE 시작을 알리는 특수 문자(선택사항) | 신호탄 |
| 무손실성 | 압축 해제 시 원본 데이터와 100% 일치함 | 완전 복구 |
> 요약: 데이터의 중복성을 수량화하여 표현하는 가장 단순한 압축 방식임

## Ⅲ. 절차
- ASCII 흐름도
  [Input Stream] -> [Compare Current/Next] -> [Count Run] -> [Output Pair]

1. 순차 읽기: 입력 데이터를 첫 번째 요소부터 순서대로 스캔함
2. 반복 확인: 현재 문자와 다음 문자가 동일한지 비교함
3. 카운팅: 동일한 문자가 나오는 동안 카운트를 1씩 증가시킴
4. 출력 생성: 문자가 바뀌거나 카운트 상한 도달 시 '개수+문자' 형태로 기록함
> 요약: "AAAAA"를 "5A"로 바꾸는 직관적인 변환 절차를 가짐

## Ⅳ. 문제점
- 데이터 확산: 반복이 거의 없는 데이터(ABCDE)는 오히려 크기가 커질 수 있음(1A1B...)
- 효율 편차: 데이터의 특성에 따라 압축률의 변동폭이 매우 큼

## Ⅴ. 개선방안
- 전처리 수행: BWT(Burrows-Wheeler Transform) 등을 통해 유사 데이터를 인접시킴
- 하이브리드 방식: 반복 구간만 RLE를 적용하고 나머지는 그대로 두는 방식을 혼용함

## Ⅵ. 전망
- 엣지 비전 가속: 제한된 자원의 IoT 카메라 환경에서 배경 차분(Background Subtraction) 후 발생하는 희소(Sparse) 데이터의 초고속 전송을 위한 1차 압축 표준으로 재조명됨
- 특화 데이터 압축: 유전체 시퀀싱(Genome Sequencing)이나 단순 반복 패턴이 지배적인 원격 탐사 데이터의 실시간 아카이빙 효율화를 위해 하이브리드 압축 체인의 선행 단계로 활용됨
- CSF: 런(Run)의 길이가 짧은 노이즈 데이터에서 오히려 크기가 증가하는 문제를 방지하기 위한 임계치 기반 조건부 인코딩 로직의 설계가 실무적 핵심임
