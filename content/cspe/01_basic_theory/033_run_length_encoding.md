## 미리 알고가기

- 런($Run$): 데이터 스트림에서 동일한 값이 연속적으로 나타나는 구간임
- 무손실 압축($Lossless$): 압축된 데이터를 복호화했을 때 원본 데이터와 100% 일치하도록 복원되는 방식임
- 중복성($Redundancy$): 데이터 내에서 불필요하게 반복되는 정보이며, 압축의 대상임
- 팩스 전송 표준: RLE가 최초로 대규모 적용된 분야로, 흰색과 검은색 픽셀의 긴 반복을 압축함

## Ⅰ. 개요

- **정의/개념**: 런랭스 인코딩(RLE)은 동일한 데이터가 연속해서 나타날 때 이를 '데이터 값'과 '반복 횟수'의 쌍으로 치환하여 전체 데이터의 크기를 줄이는 가장 단순한 형태의 무손실 압축 기법임
- **배경/필요성**: 비트맵 이미지의 배경이나 팩스 문서처럼 특정 값이 길게 반복되는 성질($Spatial$ $Redundancy$)을 가진 데이터에서, 원본을 모두 저장하는 비효율을 제거하고 전송 및 저장 효율을 극대화하기 위해 도입됨

## Ⅱ. 특징

- 인코딩과 디코딩 알고리즘이 매우 직관적이고 단순하여 CPU 연산 자원이 부족한 임베디드 시스템이나 실시간 전송 환경에서도 지연 없이 동작함
- 데이터의 반복 횟수가 많고 연속적일수록 압축률이 비약적으로 상승하지만, 반대로 데이터의 변화가 잦고 반복이 없는 경우 오히려 원본보다 크기가 커지는 오버헤드가 발생함
- 단독으로 쓰이기보다는 $JPEG$의 $AC$ 계수 압축이나 $TIFF$ 파일 포맷 등에서 다른 복합 압축 알고리즘의 최종 단계 전처리 기법으로 널리 활용됨

## Ⅲ. 종류 및 비교

| 판단 기준 | 런랭스 인코딩 (RLE) | 허프만 코딩 (Huffman) | 산술 코딩 (Arithmetic) |
|:---|:---|:---|:---|
| **압축 원리** | 연속된 반복 횟수 활용 | 통계적 발생 빈도 활용 | 확률 구간의 수치화 활용 |
| **적합 데이터** | 동일 값의 긴 연속 | 기호별 편중된 분포 | 고압축이 필요한 모든 데이터 |
| **구현 복잡도** | 매우 낮음 | 낮음 | 높음 |
| **압축 성능** | 패턴 의존적 (극단적) | 안정적 (엔트로피 근접) | 매우 높음 (최적) |

> 요약: RLE는 '연속성'에, 허프만은 '빈도'에 초점을 맞춘 압축 방식임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 데이터 기호 ($Symbol$) | 반복되는 실제 정보 값(예: 문자 'A', 픽셀값 '0')임 |
| 반복 횟수 ($Length$) | 해당 기호가 연속해서 나타난 개수이며, 카운터 비트 수에 의해 최대 표현 가능 길이가 제한됨 |
| 이스케이프 부호 | 반복되지 않는 데이터와 RLE 압축 데이터를 구분하기 위해 사용하는 특수 식별자임 |
| 인코더/디코더 | 스트림을 순차적으로 읽으며 런을 식별하고 쌍($Symbol, Length$)으로 변환하거나 복원하는 로직임 |

```text
[ RLE 압축 예시 ]
Original: AAAAAABBBCCCCCDD (16자)
RLE: A6B3C5D2 (8자)
=> 압축률: 50%
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 데이터 스캔  | --> | 동일 값 카운트| --> | 값/횟수 쌍 생성| --> | 압축 스트림 출력|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **스트림 읽기** — 입력 데이터 스트림의 첫 번째 기호를 읽어 현재 기준값으로 설정하고 카운터를 1로 초기화함
2. **반복 확인** — 다음 기호를 읽어 기준값과 일치하면 카운터를 증가시키고, 다를 때까지 이 과정을 반복함
3. **토큰 생성** — 기준값과 최종 카운트 값을 하나의 토큰(예: `6A`)으로 변환하여 출력 버퍼에 기록함
4. **포인터 이동** — 값이 달라진 지점을 새로운 기준값으로 설정하고, 전체 스트림이 종료될 때까지 과정을 되풀이함

## Ⅵ. 실무 적용 및 유의점

1. 반복이 거의 없는 텍스트나 고해상도 자연물 사진에 RLE를 직접 적용하면, 각 기호마다 '1'이라는 횟수 정보가 붙어 용량이 2배로 늘어날 수 있으므로, 일정 횟수 이상 반복될 때만 RLE를 적용하는 '조건부 인코딩' 전략을 수립해야 함
2. 이미지 처리 시 행($Row$) 단위로만 RLE를 적용하기보다 지그재그 스캔($Zig-zag$ $Scan$) 등을 통해 유사한 값들이 최대한 연속되도록 데이터를 재배치($Transform$)한 후 RLE를 적용하여 압축 효율을 극대화해야 함

## Ⅶ. 결론

- RLE는 데이터의 국소적 반복성을 활용하는 가장 효율적인 기초 압축 기술이며, 설계자는 원본 데이터의 통계적 특성을 분석하여 RLE 단독 사용보다는 적절한 전처리 및 복합 알고리즘과의 결합을 통해 최적의 압축 성능을 도출해야 함
