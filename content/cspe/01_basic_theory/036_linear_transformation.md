# 036. 선형 변환 (Linear Transformation)

## Ⅰ. Overview

선형 변환($Linear$ $Transformation$)은 두 벡터 공간 사이에서 벡터의 연산 구조를 보존하는 사상($Mapping$)임. 다차원 공간의 기하학적 변형을 행렬 연산으로 정형화하여 처리할 수 있게 함.

### 가. 핵심 개념 정의
1.  **선형성 ($Linearity$):** 다음 두 조건을 만족하는 성질임.
    - 중첩의 원리 ($Superposition$): $T(u + v) = T(u) + T(v)$
    - 균일성 ($Homogeneity$): $T(cu) = cT(u)$
2.  **기저 ($Basis$):** 벡터 공간을 생성하는 독립적인 벡터들의 집합임. 선형 변환은 기저 벡터들의 이동 결과만 알면 모든 벡터의 변환을 정의할 수 있음.
3.  **사상 ($Mapping$):** 집합 $V$의 원소를 집합 $W$의 원소로 대응시키는 규칙임.

## Ⅱ. Features

### 가. 선형 변환과 비선형 변환의 비교

| 항목 | 선형 변환 ($Linear$) | 비선형 변환 ($Non$-$linear$) |
| :--- | :--- | :--- |
| **연산 보존** | 덧셈 및 스칼라 곱 유지 | 선형 결합 관계 깨짐 |
| **수학적 표현** | 행렬 $A$와 벡터 $x$의 곱 ($Ax$) | 고차항, 초월함수, 활성화 함수 |
| **기하학적 형태** | 격자 및 원점 고정, 직선성 유지 | 곡선 왜곡, 원점 이동 가능 |
| **예시** | 회전, 크기 조절, 전단($Shear$) | $ReLU$, $Sigmoid$, 다항식 변환 |
| **해석 용이성** | 기저 이동으로 완벽히 설명됨 | 국소적 변화에 따른 해석 복잡 |

### 나. 선형 변환의 기하학적 특성
- **직선성 보존:** 직선은 변환 후에도 직선(또는 점)의 형태를 유지함.
- **평행성 보존:** 평행한 두 직선은 변환 후에도 평행함.
- **격자 균일성:** 공간 전체의 격자 간격이 일정하게 유지됨.

## Ⅲ. Architecture Insight

### 가. 표준 행렬 ($Standard$ $Matrix$)의 구성
모든 선형 변환 $T: \mathbb{R}^n \rightarrow \mathbb{R}^m$은 행렬 $A$로 표현 가능함.
1.  표준 기저 벡터 $e_1, e_2, \dots, e_n$을 변환하여 얻은 이미지 $T(e_1), T(e_2), \dots, T(e_n)$를 구함.
2.  이 이미지들을 열($Column$)로 나열하여 행렬 $A = [T(e_1) T(e_2) \dots T(e_n)]$를 구성함.
3.  이제 임의의 벡터 $x$에 대한 변환은 행렬 곱 $Ax$로 계산됨.

### 나. 변환 파이프라인 (Transformation Pipeline)
여러 변환을 순차적으로 적용할 경우, 행렬 곱의 결합 법칙을 활용하여 하나의 합성 행렬($Composite$ $Matrix$)로 통합함.
$$y = A_3 (A_2 (A_1 x)) = (A_3 A_2 A_1) x$$
이로 인해 수많은 정점에 대해 반복 연산을 수행할 때 연산량을 획기적으로 줄일 수 있음.

## Ⅳ. PPA & Trade-offs

### 가. PPA (Power, Performance, Area) 관점 분석
- **Power:** 복잡한 비선형 연산 대비 행렬 곱 기반의 선형 변환은 $FPU/GPU$에서 저전력 고효율 처리가 가능함.
- **Performance:** 대규모 벡터 데이터에 대해 동일한 행렬을 곱하는 과정은 $SIMD$ 및 병렬 가속에 매우 최적화되어 있음.
- **Area:** 4x4 행렬 연산 장치 등 특정 차원에 특화된 하드웨어 설계로 면적 효율성을 극대화함.

### 나. 주요 Trade-offs
- **Linearity vs Expressivity:** 선형 변환은 계산이 빠르지만 표현력이 제한적임. 복잡한 현실 세계를 모사하기 위해 비선형 함수를 추가하면 연산 비용이 상승함.
- **Precision vs Artifacts:** 변환 행렬의 수치 정밀도가 낮으면 반복적인 변환(예: 회전 누적) 시 형태가 왜곡되는 $Artifact$가 발생함.

## Ⅴ. Real-world Troubleshooting

### 가. 차원 유실과 특이 행렬 (Singularity)
- **현상:** 투영($Projection$) 변환 시 일부 정보가 영구히 소멸되어 역변환이 불가능해짐 ($det(A) = 0$).
- **해결:** 차원 축소가 필요한 경우 주성분 분석($PCA$)을 통해 정보 손실을 최소화하는 축을 선택하거나, 유사 역행렬($Pseudo$-$inverse$)을 사용함.

### 나. 아핀 변환 (Affine Transform)의 원점 이동 문제
- **현상:** 선형 변환은 반드시 원점을 고정해야 하므로 '이동($Translation$)'을 직접 표현할 수 없음.
- **해결:** **동차 좌표계($Homogeneous$ $Coordinates$)**를 도입하여 $n$차원 공간의 이동을 $n+1$차원의 선형 변환(행렬 곱)으로 환원하여 해결함.

## Ⅵ. Professional Insight

선형 변환은 데이터의 형태를 바꾸되 그 기저의 '논리적 관계'를 유지하는 가장 정교한 수학적 장치임. 기술사는 복잡한 물리적 변화를 행렬 연산으로 모델링할 수 있어야 하며, 특히 고차원 데이터 처리 시 발생할 수 있는 정보 유실(랭크 부족) 문제를 행렬식과 고유값 관점에서 분석할 수 있어야 함.

최근의 인공지능 아키텍처(예: $Transformer$)는 거대한 선형 변환 레이어들 사이에 전략적으로 비선형성을 배치하여 지능을 구현함. 이 과정에서 행렬의 가역성과 수치적 안정성을 확보하는 것이 모델의 학습 성패를 결정하는 핵심 요소임을 이해해야 함.
