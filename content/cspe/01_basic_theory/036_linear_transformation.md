## 미리 알고가기

- 벡터 공간: 벡터 덧셈과 스칼라 곱이 닫혀 있는 집합임
- 선형성: $T(u+v)=T(u)+T(v)$와 $T(cu)=cT(u)$를 모두 만족하는 성질임
- 기저: 벡터 공간의 모든 벡터를 표현하는 독립 벡터 집합임
- 표준 행렬: 선형 변환을 행렬 곱 $Ax$로 표현한 행렬임
- 직교 행렬: $A^TA=I$를 만족해 벡터의 길이와 각도를 보존하는 행렬임
- 멱등 행렬: $A^2=A$를 만족해 같은 변환을 반복해도 결과가 달라지지 않는 행렬임
- 아핀 변환: 선형 변환에 이동을 더한 변환이며 이동이 있으면 원점을 보존하지 않음
- 핵·치역: 각각 0으로 사상되는 입력 집합과 실제로 도달하는 출력 집합임
- 동차 좌표: 이동을 행렬 곱에 포함하도록 좌표 차원을 하나 늘린 표현임
- $e_1,e_2$: 표준 행렬의 각 열을 결정하는 입력 공간의 기저 벡터임

## 작성 근거(검토용)

- 정의는 덧셈과 스칼라 곱 보존 조건을 먼저 제시해 아핀 변환과 구분되게 함
- 선형 변환의 핵심 조건인 덧셈 보존과 스칼라 곱 보존을 미리 알고가기에 배치함
- 비교표는 크기·각도·기울기·차원에 서로 다른 변화를 만드는 확대·회전·전단·투영으로 한정함
- 구성요소는 정의역·공역·핵·치역을 포함해 선형 변환의 정보 손실 판단을 보이게 함
- 아핀 변환과 PCA는 선형 변환 원리가 실제 계산 조건으로 이어지는 대표 사례임

## Ⅰ. 개요

- **정의/개념**: 선형 변환은 벡터의 덧셈과 스칼라 곱 관계를 보존하는 공간 간 변환임
- **배경/필요성**: 좌표 변환과 선형 결합을 행렬 곱으로 계산할 선형 변환이 필요함

## Ⅱ. 특징

- 0 벡터를 0 벡터로 보내고 벡터의 선형 결합 관계를 보존함
- 기저 벡터의 사상 결과만 알면 전체 변환을 결정함
- 유한차원 벡터 공간의 선형 변환은 기저를 정하면 행렬과 벡터 곱으로 표현함
- 변환 합성은 행렬 곱으로 처리되어 사전 계산이 가능함

## Ⅲ. 종류 및 비교

| 변환 | 기하 의미 | 행렬 특성 | 활용 |
|:---|:---|:---|:---|
| 확대·축소 | 축별 크기 변경 | 대각 성분 조정 | 정규화·크기 조정 |
| 회전 | 원점 기준 각도 변경 | 직교 행렬 | 그래픽스·로봇 자세 |
| 전단 | 한 축 방향으로 기울임 | 비대각 성분 사용 | 이미지 왜곡·폰트 |
| 투영 | 낮은 차원으로 사상 | $A^2=A$ | 그림자·차원 축소 |

> 요약: 확대·축소는 대각 성분, 회전은 직교 행렬, 전단은 비대각 성분, 투영은 $A^2=A$인 행렬로 표현함.

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 정의역 | 변환 전 벡터 공간 |
| 공역 | 변환 결과의 목표 공간 |
| 핵 | 0 벡터로 사상되는 입력 집합 |
| 치역 | 실제 도달 가능한 출력 집합 |
| 표준 행렬 | 변환 기저 벡터의 열 행렬 |

```text
기저:
e1 -> T(e1)
e2 -> T(e2)

표준 행렬:
A = [ T(e1)  T(e2) ]
T(x) = A * x
```

> 요약: 선형 변환은 기저 벡터의 사상으로 표준 행렬을 구성하고 핵과 치역으로 소실되는 입력 방향과 도달 가능한 출력을 구분함.

## Ⅵ. 실무 사례

1. 그래픽 엔진은 동차 좌표로 선형 변환과 이동을 아핀 변환 행렬로 합성하며 좌표 오차가 합성 정확도를 가늠함
2. PCA 기반 차원 축소는 데이터 분산을 보존하는 투영 축을 선택하며 복원 오차가 축소 폭의 한계를 정함

## Ⅶ. 결론

- 선형 변환은 덧셈과 스칼라 곱을 보존하며 기저 벡터의 사상 결과로 전체 변환을 결정함
