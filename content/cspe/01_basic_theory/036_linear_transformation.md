## Ⅰ. 개요
- **정의**: 벡터 공간 사이에서 덧셈과 스칼라 곱을 보존하는 함수 $f(ax+by) = af(x)+bf(y)$
- **배경/필요성**: 좌표 회전, 이미지 변환, 신호 처리 등에서 벡터 간 관계를 구조적으로 유지하면서 변환하려면 선형성 보장이 필수임
- **비유**: 고무판 위의 격자를 늘이거나 회전시켜도 격자선이 곡선 없이 평행·직선을 유지하는 변환

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 선형성 조건 이해 | 가법성 $f(x+y)=f(x)+f(y)$ + 동차성 $f(cx)=cf(x)$ | 이동(translation)은 선형 변환이 아님 |
| 행렬 표현과의 관계 | 유한 차원 선형 변환은 행렬과 1:1 대응 | 기저 선택에 따라 행렬 표현이 달라짐 |
| 커널·상·랭크 관계 | 랭크-널리티 정리: rank + nullity = dim(V) | 커널={0}이면 단사, 상=W이면 전사 |

> 요약: 선형 변환은 벡터 공간의 구조를 보존하는 함수로, 행렬·커널·랭크로 완전히 분석 가능함

## Ⅱ. 구성요소
```text
          +---------------+
          | 선형 변환 T   |
          +-------+-------+
                  |
    +-------------+-------------+
    |             |             |
    v             v             v
+--------+  +---------+  +-----------+
| 정의역 |  | 변환    |  | 공역/상   |
| (V)    |  | 행렬(A) |  | (W)      |
+--------+  +---------+  +-----------+
    |             |             |
    v             v             v
 기저 선택    연산 수행     커널/상 분석
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 정의역(V) | 입력 벡터가 속하는 벡터 공간 | 변환 전 무대 |
| 공역(W) | 출력 벡터가 속하는 벡터 공간 | 변환 후 무대 |
| 변환 행렬(A) | 기저에 대해 T를 수치로 표현한 m x n 행렬 (035 참조) | 변환 레시피가 적힌 카드 |
| 커널(Ker T) | T(v) = 0을 만족하는 v의 집합(null space) | 변환기에 넣으면 사라지는 입력들 |
| 상(Im T) | T로 도달 가능한 출력 벡터 전체 집합(range) | 변환기가 만들 수 있는 출력의 범위 |
| 랭크(rank) | 상의 차원, 변환이 전달하는 독립 정보의 수 | 파이프의 유효 통로 수 |
| 널리티(nullity) | 커널의 차원, 변환 과정에서 소실되는 정보의 수 | 파이프에서 막힌 통로 수 |

> 요약: 정의역·공역·행렬·커널·상이 선형 변환의 구조와 정보 손실을 결정함

## Ⅲ. 절차
```text
기저 선택 --> 행렬 구성 --> 변환 적용 --> 커널/상 분석
    |             |             |              |
    v             v             v              v
 V의 기저     열벡터 배치    y = Ax 계산   rank+nullity 검증
```
- 1단계: **기저 선택** — 정의역 V와 공역 W의 기저를 정하여 벡터를 좌표로 표현할 준비를 함
- 2단계: **행렬 구성** — 각 기저 벡터에 T를 적용한 결과를 열벡터로 배치하여 변환 행렬 A를 구성함
- 3단계: **변환 적용** — 입력 벡터 x에 대해 $y = Ax$를 계산하여 출력 벡터를 얻음 (행렬 곱 절차는 035 참조)
- 4단계: **커널/상 분석** — A를 행 사다리꼴(RREF)로 변환하여 커널·상·랭크를 구하고, 랭크-널리티 정리 rank(A) + nullity(A) = n 으로 검증함

> 요약: 기저 설정 → 행렬화 → 연산 → 구조 분석의 순서로 선형 변환을 완전히 파악함

## Ⅳ. 문제점
- **기저 의존성**: 기저 선택에 따라 같은 변환의 행렬 표현이 달라져 해석·비교가 어려움
- **정보 손실**: 커널이 비자명(nullity > 0)이면 변환 과정에서 입력 정보가 소실되어 역변환이 불가능함
- **고차원 연산 부담**: 차원이 높아지면 행렬 크기가 $n^2$으로 증가하여 저장·연산 비용이 급증함

> 요약: 기저 의존·정보 손실·고차원 비용이 선형 변환 활용의 주요 제약임

## Ⅴ. 개선방안
1. **단기**: 기저 변환 행렬 $P^{-1}AP$를 활용하여 표준 기저·직교 기저로 정규화함으로써 기저 의존성을 해소함
2. **중기**: 의사역행렬(pseudo-inverse) 및 최소제곱법을 적용하여 커널이 존재하는 경우에도 근사 역변환을 수행함
3. **장기**: 고유값 분해(037 참조)·SVD를 통해 차원 축소 후 핵심 성분만 연산하여 고차원 비용을 절감함

> 요약: 기저 정규화 → 근사 역변환 → 차원 축소 순으로 선형 변환의 한계를 단계적으로 극복함

## Ⅵ. 전망
- **발전 방향**: 비선형 변환을 국소 선형 근사하는 기법(야코비안 등)과 결합하여 딥러닝·로보틱스 분야 적용이 확대되고 있음
- **기술사적 판단**: 데이터 차원이 증가할수록 선형 변환 기반 차원 축소(PCA, SVD)의 중요성이 높아지고 있음
- **기술사 제언**: 행렬 연산(035 참조)과 고유값 분해(037 참조)를 연계하여 변환의 기하학적 의미까지 설명할 수 있는 통합 역량이 필요함
