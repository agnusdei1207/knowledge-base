## 미리 알고가기

- 벡터 공간: 벡터 덧셈과 스칼라 곱이 정의된 공간임
- 선형성: `T(u+v)=T(u)+T(v)`, `T(cu)=cT(u)`를 만족하는 성질임
- 행렬 표현: 선형 변환을 기준 벡터의 변환 결과로 구성한 행렬 곱으로 나타내는 방식임
- 기저: 벡터 공간의 모든 벡터를 표현할 수 있는 독립 벡터 집합임
- 커널/이미지: 0으로 가는 입력 집합과 변환 결과가 도달하는 출력 부분공간임

## Ⅰ. 개요

- **정의**: 선형 변환은 벡터 덧셈과 스칼라 곱을 보존하는 함수를 행렬 곱으로 표현해 구조가 유지되는 변환을 계산하는 방법임
- **배경/필요성**: 복잡한 데이터와 좌표 조작을 행렬 하나로 표현하면 변환 합성, 역변환, 차원 축소를 일관된 선형대수 연산으로 처리할 수 있음.
- **비유**: 고무판 위의 점들을 원점은 고정한 채 같은 규칙으로 늘리거나 돌려 전체 격자 구조를 유지하는 작업과 같음.

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 선형 변환 정의 설명 | 가산성, 동차성, 행렬 표현 | 단순 좌표 변환으로만 설명 |
| 응용과 한계 판단 | 회전, 스케일링, 전단, 랭크 | 평행이동을 선형 변환으로 오해 |

> 요약: 선형 변환은 벡터 공간의 덧셈과 스칼라 배 구조를 보존하는 변환을 행렬로 표현해 계산하는 방법임.

## Ⅱ. 특징/비교

| 판단 기준 | 선형 변환 | 비선형/아핀 변환 |
|:---|:---|:---|
| 보존 성질 | 덧셈과 스칼라 곱을 보존하고 원점을 원점으로 보냄 | 원점 이동이나 곡선 변환으로 선형성이 깨질 수 있음 |
| 표현 방식 | 행렬 곱 `y = A x`로 표현함 | `y = A x + b` 또는 비선형 함수가 필요함 |
| 합성 처리 | 행렬 곱으로 변환 합성이 가능함 | 편향이나 비선형 항을 별도 처리해야 함 |
| 선택 기준 | 회전, 확대, 투영, 필터처럼 구조 보존 변환에 적합함 | 평행이동, 활성화 함수, 복잡 경계 표현에 적합함 |

- **검증 기준**: 임의 벡터에 대해 가산성과 동차성이 모두 성립해야 선형 변환임.
- **기하 기준**: 직선과 원점, 평행성 같은 구조가 보존되는지로 직관적 판단이 가능함.
- **확장 기준**: 평행이동은 동차 좌표를 사용하면 행렬 곱 형태로 함께 처리할 수 있음.

> 요약: 선형 변환은 행렬 곱으로 합성 가능한 구조 보존 변환이며, 원점 이동이나 비선형 효과는 별도 확장이 필요함.

## Ⅲ. 구성요소

```text
+------------+      +------------+      +------------+
| Input      | ---> | Matrix A   | ---> | Output     |
| Vector x   |      | Transform  |      | Vector y   |
+------------+      +------------+      +------------+
       |                   |                   |
       v                   v                   v
+------------+      +------------+      +------------+
| Basis      |      | Rank       |      | Image /    |
| Vectors    |      | Property   |      | Kernel     |
+------------+      +------------+      +------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 입력 벡터 x | 변환 전 좌표나 데이터이며 벡터 공간의 원소임 | 이동 전 위치 |
| 변환 행렬 A | 기준 벡터가 어디로 이동하는지 담아 전체 변환 규칙을 표현함 | 변환 규칙표 |
| 출력 벡터 y | `y = A x` 계산으로 얻는 변환 후 좌표나 데이터임 | 이동 후 위치 |
| 기저 | 행렬 표현의 기준이 되는 독립 벡터 집합임 | 좌표축 |
| 커널/이미지 | 0으로 사라지는 입력과 실제로 도달 가능한 출력 공간을 설명함 | 사라지는 길과 도착 영역 |

> 요약: 선형 변환은 입력 벡터를 변환 행렬에 곱해 출력 벡터를 만들고, 기저·랭크·커널·이미지로 구조적 성질을 판단함.

## Ⅳ. 절차

```text
+------------+      +------------+      +------------+      +------------+
| Verify     | ---> | Build      | ---> | Multiply   | ---> | Interpret  |
| Linearity  |      | Matrix A   |      | y = A x    |      | Geometry   |
+------------+      +------------+      +------------+      +------------+
```

1. **선형성 검증**: 대상 변환이 가산성과 동차성을 만족하는지 확인함.
2. **행렬 구성**: 기저 벡터의 변환 결과를 열 벡터로 배치해 변환 행렬을 만듦.
3. **변환 계산**: 입력 벡터에 행렬을 곱해 출력 벡터를 구하고 필요하면 변환을 합성함.
4. **성질 해석**: 랭크, 행렬식, 고유값, 커널을 확인해 축소, 회전, 투영, 역변환 가능성을 판단함.

> 요약: 선형 변환은 선형성을 확인한 뒤 기저 변환 결과로 행렬을 만들고, 행렬 곱과 구조 해석으로 결과를 판단함.

## Ⅴ. 문제점

- **P1 비선형 효과 표현 한계**: 평행이동, 임계값, 곡선 변환은 순수한 `A x` 형태로 표현되지 않음.
- **P2 랭크 손실**: 투영이나 차원 축소처럼 랭크가 줄어드는 변환은 정보를 잃어 역변환이 불가능함.
- **P3 수치 조건 악화**: 거의 종속인 기저나 조건수가 큰 행렬은 계산 오차를 크게 증폭함.

> 요약: 선형 변환은 표현 가능한 범위, 정보 손실, 수치 안정성 한계를 함께 고려해야 함.

## Ⅵ. 개선방안

- **P1 대응**: 평행이동은 동차 좌표로 확장하고 비선형 관계는 커널 방법이나 신경망 활성화로 분리함. (확인: 선형성 테스트)
- **P2 대응**: 랭크와 특잇값을 확인해 손실 차원을 명시하고 필요하면 의사역행렬로 최소제곱 복원을 수행함. (확인: rank와 reconstruction error)
- **P3 대응**: 정규직교 기저, QR/SVD 분해, 정규화를 사용해 조건수와 오차 증폭을 낮춤. (확인: condition number)

> 요약: 선형 변환은 동차 좌표 확장, 랭크 관리, QR/SVD 등 수치 오차가 작은 분해법을 통해 실무 적용 한계를 완화할 수 있음.

## Ⅶ. 전망

- **발전 방향**: 그래픽스, 로봇, 신호처리, 딥러닝에서 선형 변환은 고차원 데이터 조작의 기본 연산으로 계속 쓰일 전망임.
- **기술사적 판단**: 선형 모델로 충분한 구조와 비선형 모델이 필요한 구조를 구분하는 것이 모델 선택과 성능 해석의 출발점임.
- **기술사 제언**: 답안에서는 선형성 조건, 행렬 표현, 정보 손실과 역변환 가능성을 함께 설명해야 함.
