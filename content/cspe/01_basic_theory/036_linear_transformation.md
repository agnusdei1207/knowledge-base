## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 벡터 공간에서 벡터 공간으로 매핑 함수 중 덧셈(가산성)과 스칼라 곱(동차성)이 보존되는 수학적 변환임 |
| 배경/필요성 | 이미지 회전/크기 조절, 데이터 차원 축소, 신경망 가중치 적용 등 기하학적 매핑을 일관되게 처리하기 위해 필요함 |
| 출제 의도 | 선형 변환의 기하학적 의미와 이를 나타내는 변환 행렬 구성 능력 평가 |

## Ⅱ. 구성요소
```text
+-------------------+       +-------------------+       +-------------------+
|  Input Vector     | ----> | Transform Matrix  | ----> |  Output Vector    |
|  (Original state) |       | (Linear Mapping)  |       |  (Mapped state)   |
+-------------------+       +-------------------+       +-------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 입력 벡터 | 변환의 대상이 되는 원본 데이터 또는 좌표 (기저 벡터의 조합) | 찰흙 덩어리 |
| 변환 행렬 | 선형 변환 규칙을 담은 행렬 (스케일링, 회전, 전단 등) | 찰흙 틀 (몰드) |
| 출력 벡터 | 변환 행렬을 통과하여 새로운 기저 상에 놓인 결과 좌표 | 완성된 조각품 |
> 요약: 선형 변환은 입력 벡터 공간을 원점을 고정한 채 선형적(직선 유지)으로 늘리거나 회전시키는 규칙임

## Ⅲ. 절차
```text
+----------------+    +----------------+    +----------------+    +----------------+
| 1. 변환 정의   | -> | 2. 행렬 구성   | -> | 3. 행렬-벡터 곱| -> | 4. 결과 해석   |
+----------------+    +----------------+    +----------------+    +----------------+
```
1. 변환 정의: 데이터를 스케일링, 회전(Rotation), 반사(Reflection)할 기하학적 목적을 설정함
2. 행렬 구성: 표준 기저 벡터가 변환 후 어디에 위치하는지 계산하여 이를 열벡터로 삼아 변환 행렬을 구성함
3. 행렬-벡터 곱: 구성된 변환 행렬과 입력 벡터를 행렬 곱셈하여 좌표를 매핑함
4. 결과 해석: 출력 벡터의 위치를 통해 공간이 어떻게 찌그러지거나 확장되었는지 기하학적으로 해석함
> 요약: 기저 벡터의 변환 결과를 행렬로 만들고, 이를 원본 벡터에 곱하여 새로운 공간 좌표를 획득함

## Ⅳ. 문제점
- 평행 이동 불가능: 순수한 선형 변환은 원점(0,0)을 무조건 원점으로 매핑해야 하므로 평행 이동(Translation)을 표현할 수 없음
- 차원의 저주: 고차원 데이터 공간에서 선형 변환을 무작정 적용 시 유의미한 패턴을 찾기 어렵고 연산량만 폭증함

## Ⅴ. 개선방안
- 동차 좌표계 도입: 3D 그래픽스 등에서는 차원을 1 늘린 동차 좌표계(Homogeneous Coordinates)를 사용하여 평행 이동까지 행렬 곱 하나로 처리함
- 차원 축소 기법 적용: 주성분 분석(PCA) 등 데이터의 분산을 최대로 유지하는 축으로 사영(Projection)시키는 특수한 선형 변환으로 효율성을 높임

## Ⅵ. 전망
- 인공지능의 핵심인 활성화 함수 전 단계의 가중치 합 연산이 본질적으로 선형 변환이므로, 이를 하드웨어에서 초고속 처리하는 뉴럴 엔진 아키텍처 연구가 지속될 것임
