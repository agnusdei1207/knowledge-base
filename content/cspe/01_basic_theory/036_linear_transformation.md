# 선형 변환 (Linear Transformation)

## 1. 개요

- **정의/개념**: 선형 변환은 벡터의 덧셈과 스칼라 곱을 보존하며 입력 벡터를 다른 벡터 공간으로 사상하는 함수이다.
- **배경/필요성**: 회전, 확대, 투영, 특징 변환처럼 많은 계산은 행렬 곱으로 표현 가능한 선형 변환으로 모델링되므로 구조와 한계를 이해해야 한다.

선형 변환의 핵심은 변환 후에도 선형 결합 관계가 유지된다는 점이다.

## 2. 특징 및 비교

| 구분 | 선형 변환 | 비선형 변환 |
|---|---|---|
| 성질 | 덧셈·스칼라 곱 보존 | 선형성 보장 없음 |
| 표현 | 행렬 곱으로 표현 가능 | 일반 함수·신경망 등 |
| 해석성 | 기저 벡터 변화로 설명 가능 | 구조 해석이 어려울 수 있음 |
| 대표 예 | 회전, 스케일, 투영 | ReLU, sigmoid, 곡선 변환 |

선형 변환을 선택할 때는 선형성 조건, 차원 변화, 정보 손실, 역변환 가능성을 함께 판단한다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| Vector Space | 입력·출력 벡터의 공간 | 차원과 기저 |
| Basis | 공간을 생성하는 기준 벡터 | 변환 해석 |
| Matrix | 선형 변환의 표현 | 계산 구현 |
| Rank | 출력 공간의 독립 차원 | 정보 손실 판단 |
| Kernel | 0으로 매핑되는 입력 집합 | 비가역성 원인 |

```text
+----------+      +----------+      +----------+
| 입력벡터 | ---> | 변환행렬 | ---> | 출력벡터 |
+----------+      +----------+      +----------+
```

행렬은 기저 벡터가 어디로 이동하는지 모아 둔 표현이므로, rank와 kernel이 정보 보존 여부를 설명한다.

## 4. 문제점 및 개선방안

1. **선형성 오판**
   - 모든 행렬 기반 처리가 문제의 비선형 구조를 충분히 표현하는 것은 아니다.
   - **개선방안**: 잔차 분석, 비선형 특성 확인, 커널·신경망 모델을 검토한다.

2. **차원 축소에 따른 정보 손실**
   - 투영·압축 과정에서 중요한 성분이 사라질 수 있다.
   - **개선방안**: rank, 설명 분산, 복원 오차를 확인한다.

3. **역변환 불가능**
   - rank가 부족하면 서로 다른 입력이 같은 출력으로 매핑된다.
   - **개선방안**: 가역 조건을 확인하고 pseudo-inverse 또는 정규화를 적용한다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| 그래픽스 | 회전·스케일·투영을 행렬로 합성 | 좌표 오차, 렌더링 시간 |
| 데이터 분석 | 특징 공간 변환과 차원 축소 | 설명 분산, 복원 오차 |
| 신호 처리 | 필터와 변환을 선형 연산으로 표현 | SNR, 왜곡률 |

## 6. 결론

선형 변환은 복잡한 계산을 행렬 곱으로 표현하게 해 주는 핵심 개념이다. 선형성 조건, 행렬 표현, 정보 손실, 역변환 가능성을 함께 설명해야 단순 수식이 아니라 시스템 설계 판단으로 연결된다.
