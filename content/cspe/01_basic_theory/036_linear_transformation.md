## 미리 알고가기

- 벡터 공간: 벡터 덧셈과 스칼라 곱이 정의된 공간임
- 선형성: 가법성과 동차성을 동시에 만족하는 성질임
- 기저: 공간을 생성하는 독립 벡터 집합임

## Ⅰ. 개요

- **정의/개념**: 선형 변환은 두 벡터 공간 사이에서 덧셈과 스칼라 곱을 보존하는 함수로, 기하학적 변환과 데이터 투영을 행렬 형태로 표현하는 핵심 개념임
- **배경/필요성**: 회전, 확대, 투영, 특징 추출 같은 다양한 계산을 통일된 수식으로 다루려면 선형성을 가진 변환 모델이 필요함

## Ⅱ. 특징

- $T(u+v)=T(u)+T(v)$, $T(cu)=cT(u)$를 만족해 조합 가능성이 높음
- 적절한 기저를 선택하면 행렬 곱으로 구현 가능함
- kernel과 image를 통해 정보 손실과 차원 축소를 해석할 수 있음
- 비선형 현상은 직접 표현하지 못해 근사나 확장이 필요함

## Ⅲ. 종류 및 비교

| 판단 기준 | 선형 변환 | 비선형 변환 |
|:---|:---|:---|
| 가법성/동차성 | 유지 | 일반적으로 불가 |
| 표현 방식 | 행렬 | 함수, 커널, 신경망 등 |
| 해석 가능성 | 높음 | 상대적으로 낮음 |
| 대표 적용 | PCA, 회전, 필터 | 활성화 함수, 왜곡 보정 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 정의역/공역 | 입력과 출력 공간이며 차원과 의미를 결정함 |
| 변환 행렬 | 선형 관계를 수치화하고 실제 구현 단위임 |
| kernel | 0으로 사라지는 벡터 집합이며 정보 손실 정도를 보여줌 |
| image | 변환으로 도달 가능한 출력 공간이며 표현 가능한 범위를 뜻함 |

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 정의역      | --> | 변환 행렬    | --> | kernel    | --> | image     |
+-----------+     +-----------+     +-----------+     +-----------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 기저선정 | --> | 행렬구성 | --> | 벡터변환 | --> | 의미해석 |
+----------+     +----------+     +----------+     +----------+
```

1. **기저선정**: 입력과 출력 공간의 기준 벡터를 정함
2. **행렬구성**: 기저 벡터의 변환 결과로 행렬을 만듦
3. **벡터변환**: 행렬 곱으로 실제 데이터를 변환함
4. **의미해석**: 크기 변화, 방향 변화, 차원 감소를 해석함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 비선형 관계를 충분히 설명하지 못해 실제 데이터는 곡선 구조를 가질 수 있음
   - 해결방안: kernel trick이나 비선형 모델로 확장하고 설명 분산로 검증함
2. 문제: 기저 선택이 해석성에 영향을 줘 좌표계가 부적절하면 의미가 흐려짐
   - 해결방안: 정규직교 기저나 도메인 기저를 사용하고 해석 가능성로 검증함
3. 문제: 수치 오차가 누적될 수 있어 반복 변환 시 왜곡이 커질 수 있음
   - 해결방안: 정규화와 안정한 분해 기법을 사용하고 reconstruction error로 검증함

## Ⅶ. 적용 사례

- 컴퓨터 그래픽스에서는 좌표 회전, 확대, 투영을 행렬로 처리함, 확인 지표는 렌더링 정확도임
- 머신러닝 특징 추출에서는 PCA와 선형 투영으로 차원을 줄임, 확인 지표는 설명 분산 비율임
- 통신/신호 처리에서는 필터와 채널 변환을 선형 시스템으로 모델링함, 확인 지표는 잡음 제거 성능임

## Ⅷ. 결론

선형 변환은 복잡한 구조를 행렬 연산으로 다루게 해주는 기본 언어이므로, 정보가 얼마나 보존되고 무엇이 사라지는지 kernel과 image 관점으로 함께 판단해야 함.
