## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 벡터 공간에서 덧셈과 스칼라 곱을 보존하는 함수 T: V→W로, 행렬 곱 y=Ax로 표현되는 변환임 |
| **배경/필요성** | 3D 그래픽스의 회전·크기 변환, 신경망의 선형 레이어, 신호 처리의 필터링이 모두 선형 변환으로 모델링됨 |
| **출제 의도** | 선형 변환의 성질(가산성·동차성)과 행렬 표현, 기하학적 의미를 이해하는지 평가함 |

## Ⅱ. 구성요소
```
+----------+     +----------+     +----------+
| 입력벡터  | --> | 변환행렬  | --> | 출력벡터  |
|  (x)     |     |  (A)     |     |  (y=Ax) |
+----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| 입력 벡터(x) | 변환 전 원래 좌표·데이터임 | 이동 전 위치 |
| 변환 행렬(A) | 선형 변환을 표현하는 m×n 행렬로, 회전·확대·전단 등을 포함함 | 변환 규칙서 |
| 출력 벡터(y) | 변환 후 결과 좌표·데이터(y=Ax)임 | 이동 후 위치 |

> 요약: 입력 x에 변환 행렬 A를 곱하여 출력 y=Ax를 구하며, 회전·확대·전단 등을 통합 표현함.

## Ⅲ. 절차
```
+------------+     +------------+
| 변환정의   | --> | 행렬구성   |
| (회전/확대)|     | (기저변환) |
+------------+     +------------+
                        |
+------------+     +----+-------+
| 결과적용   | <-- | 행렬곱    |
| (좌표변환) |     | y = Ax    |
+------------+     +------------+
```

1. 변환 정의: 수행할 기하 변환(회전 θ, 확대 s 등)을 정의함
2. 행렬 구성: 변환에 대응하는 행렬을 구성함(2D 회전: [[cosθ, -sinθ], [sinθ, cosθ]])
3. 행렬 곱: 입력 벡터에 변환 행렬을 곱하여 출력 벡터를 계산함
4. 결과 적용: 변환된 좌표를 화면·모델에 적용함(합성 변환은 행렬 곱의 연쇄)

> 요약: 변환 정의 → 행렬 구성 → 행렬 곱 → 결과 적용으로 기하 변환을 수행함.

## Ⅳ. 문제점
- 이동 변환 미포함: 순수 선형 변환은 평행 이동을 표현 못 하여 동차 좌표가 필요함
- 수치 누적 오차: 변환 행렬의 반복 곱에서 부동소수점 오차가 누적됨
- 비선형 변환 한계: 곡면 변형·렌즈 왜곡 등 비선형 변환은 선형 변환으로 표현 불가함

## Ⅴ. 개선방안
- (단기) 동차 좌표: (n+1)차원 행렬로 이동을 포함한 아핀 변환을 통합 표현함
- (중기) 쿼터니언: 3D 회전에서 짐벌 락 없이 회전을 보간하는 쿼터니언을 사용함
- (장기) 미분 가능 렌더링: 신경망과 결합한 미분 가능 선형 변환으로 3D 복원을 수행함

## Ⅵ. 전망
- GPU 셰이더·AI 추론에서 선형 변환(행렬 곱)이 핵심 연산이며, 미분 가능 렌더링·Neural Radiance Fields(NeRF)에서 선형 변환의 새로운 활용이 확산될 전망임
