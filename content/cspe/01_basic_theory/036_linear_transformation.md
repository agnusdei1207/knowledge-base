# 📖 【암기용】 개념 완전 이해

> 목적: 선형 변환을 처음 보는 사람도 완벽히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 선형 변환은 **벡터 공간(Vector Space)**의 원소(데이터)를 특정 규칙에 따라 다른 공간으로 이동시키는 **함수(사상, Mapping)**다. 단, 원점은 원점에 그대로 있어야 하고 직선은 변환 후에도 직선이어야 한다.
- **왜 필요한가**: 복잡한 다차원 데이터를 회전·확대/축소·투영해서 분석하기 쉬운 새로운 좌표계로 옮기기 위해서다.
- **핵심 직관**: 모든 선형 변환은 하나의 행렬로 완벽하게 표현된다. 즉 행렬을 곱한다는 것은 곧 공간을 찌그러뜨리거나 회전시키는 선형 변환을 수행한다는 뜻이다.

## 핵심 용어 정리 (내부에 등장하는 것들)

| 용어 | 의미 | 비유 |
|:---|:---|:---|
| 벡터 공간 (Vector Space) | 벡터들의 덧셈과 스칼라 곱이 정의된 집합 — 선형 변환이 다루는 무대 | 화살표(벡터)들이 자유롭게 움직이는 판 |
| 사상/함수 (Mapping) | 한 공간의 원소를 다른 공간의 원소로 대응시키는 규칙 | 입력을 넣으면 출력이 나오는 블랙박스 |
| 가산성 (Additivity) | $f(x+y) = f(x)+f(y)$ — 덧셈 후 변환한 것과 변환 후 더한 것이 같음 | 따로 배달시켜 합치나, 합쳐서 배달시키나 결과가 같음 |
| 동차성 (Homogeneity) | $f(cx) = c \cdot f(x)$ — 크기를 $c$배 한 뒤 변환한 것과 변환 후 $c$배 한 것이 같음 | 사진을 2배로 확대한 후 회전하나, 회전 후 2배로 확대하나 같은 결과 |
| 기저 벡터 (Basis Vector) | 공간을 표현하는 기준 축 단위 벡터 (예: x축의 $(1,0)$, y축의 $(0,1)$) | 지도의 위/아래, 좌/우 기준선 |
| 변환 행렬 ($T$) | 선형 변환의 규칙을 압축한 행렬 — 기저 벡터가 어디로 이동하는지로 결정됨 | 변환 규칙을 적어둔 설명서 |
| 원점 보존 | $T(0) = 0$이 항상 성립해야 하는 선형 변환의 필수 조건 | 지도의 중심(0,0)은 어떤 변환을 해도 그대로 중심 |
| 아핀 변환 (Affine Transformation) | 선형 변환에 평행이동(편향 $b$)을 더한 것 ($f(x)=Wx+b$) — 원점이 이동해 순수 선형 변환은 아님 | 회전시킨 뒤 통째로 옆으로 밀기 |

## 깊이 이해

### 왜 선형 변환이 필요했나 (배경)
- 데이터의 원래 축(X, Y)이 항상 분석하기 좋은 기준은 아니다. 예를 들어 키와 몸무게 데이터를 원래 축 그대로 보면 상관관계가 비스듬히 걸쳐 있는데, 이 데이터를 회전시켜 새로운 축으로 옮기면 패턴이 한 축에 정렬되어 훨씬 선명하게 보인다. 이렇게 "공간의 구조는 유지하면서 관점만 바꾸는" 도구가 선형 변환이다.

### 선형성 조건을 수치로 확인하기
- $f(x,y) = (2x, 3y)$라는 변환이 있다고 하자. 가산성을 확인해보면: 벡터 $u=(1,2)$, $v=(3,1)$일 때 $f(u+v) = f(4,3) = (8,9)$이고, $f(u)+f(v) = (2,6)+(6,3) = (8,9)$로 정확히 같다.
- 동차성도 확인해보면: $f(2u) = f(2,4) = (4,12)$이고, $2\cdot f(u) = 2\times(2,6) = (4,12)$로 같다. 두 조건을 모두 만족하므로 $f(x,y)=(2x,3y)$는 선형 변환이다.
- 반면 $g(x,y) = (2x+1, 3y)$처럼 상수 1이 더해지면, $g(0,0) = (1,0) \neq (0,0)$이 되어 원점 보존 조건을 어기므로 선형 변환이 아니라 아핀 변환이다.

### 기저 벡터만 알면 전체를 알 수 있는 이유
- 선형성(가산성+동차성) 덕분에, 임의의 벡터 $v=(x,y)$는 기저 벡터의 조합 $v = x\cdot(1,0) + y\cdot(0,1)$로 항상 쓸 수 있다.
- 따라서 $T(v) = T(x\cdot(1,0)+y\cdot(0,1)) = x\cdot T(1,0) + y\cdot T(0,1)$이 성립한다 — 즉 기저 벡터 $(1,0)$과 $(0,1)$이 변환 후 어디로 가는지만 알면, 공간 전체의 모든 점이 어디로 이동하는지 계산할 수 있다. 이것이 변환 행렬의 열(column)이 "기저 벡터의 이동한 좌표"로 구성되는 이유다.

### 90도 회전을 수치로 계산하기
- 변환 행렬 $T = \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}$을 점 $(1,0)$에 곱하면: $(0\times1 + (-1)\times0,\ 1\times1 + 0\times0) = (0, 1)$. 즉 x축 위의 점 $(1,0)$이 y축 위의 점 $(0,1)$로 이동했다 — 반시계 방향으로 정확히 90도 회전한 것이다.
- 같은 행렬을 $(0,1)$에 곱하면 $(0\times0+(-1)\times1,\ 1\times0+0\times1) = (-1, 0)$이 되어, y축 위의 점이 x축의 음수 방향으로 이동한다. 두 기저 벡터가 각각 90도씩 회전한 자리로 이동했으므로, 이 행렬은 평면 전체를 원점 기준으로 90도 회전시키는 변환이다.

### 비유와 흔한 오해
- **비유**: 격자무늬가 그려진 고무판을 당기거나 돌리는 것과 같다. 고무판이 아무리 늘어나도 원점은 그대로고, 원래 평행했던 격자선들은 변환 후에도 계속 평행을 유지한다.
- **오해**: 신경망의 $y = Wx + b$ 연산은 편향 $b$가 원점을 이동시키므로 순수한 선형 변환이 아니라 아핀 변환이다. 또한 순수 선형 변환만 여러 층 쌓아도 결국 하나의 행렬 곱(하나의 선형 변환)으로 합쳐지므로, 신경망이 복잡한 패턴을 학습하려면 층 사이에 비선형 활성화 함수(ReLU 등)가 반드시 필요하다.

## 연결 개념
- 행렬 연산 (035) — 선형 변환을 실제로 계산하는 수단(행렬 곱)
- 아핀 변환(Affine Transformation) — 선형 변환에 평행 이동(편향 $b$ 덧셈)을 더한 것
- 고유값·고유벡터 (037) — 선형 변환을 겪어도 방향이 바뀌지 않는 특별한 벡터를 찾는 기법

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 선형 변환은 가산성과 동차성을 만족하며, 다차원 벡터 공간을 보존한 채 데이터를 새로운 좌표계로 사상(Mapping)하는 함수다.
> 2. **가치**: 딥러닝 레이어의 본질적인 데이터 맵핑 메커니즘이며, 행렬 곱 연산만으로 크기 변환, 회전, 전단(Shear) 등을 $O(N)$ 병렬로 수행할 수 있다.
> 3. **판단 포인트**: 순수 선형 변환은 다중 층으로 쌓아도 하나의 선형 변환으로 붕괴하므로, 신경망에서는 반드시 비선형 활성화 함수(ReLU 등)와 결합해야 한다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 선형 변환의 수학적 정의와 딥러닝에서의 역할 | 선형성 2조건(가산성, 동차성), 변환 행렬($T$) 매칭 | 단순 행렬 곱 계산법만 쓰면 안 됨 |
| 딥러닝에서 선형 변환만으로 부족한 이유 | 층 붕괴(Layer Collapse) 방지를 위한 비선형 활성화 함수 필요성 | 아핀 변환(편향 $b$)과의 차이 누락 주의 |

> 요약: 선형 변환이 공간의 구조를 어떻게 맵핑하는지 기하학적으로 설명하고, 신경망 뼈대 설계 시 비선형 함수와의 결합 당위성을 지적해야 한다.

## Ⅰ. 개요 및 필요성

- 정의: 벡터 공간 $V$에서 $W$로의 함수 중 덧셈(가산성)과 스칼라 곱(동차성)을 보존하는 사상(Mapping)
- 배경: 고차원 데이터의 군집이나 회귀 패턴은 원본 좌표계보다 회전/투영된 공간에서 더 선명하게 구분됨
- 필요성: 모든 선형 변환은 유일한 행렬 곱으로 표현되므로, GPU를 통한 대규모 병렬 텐서 연산을 가능하게 함

---

## Ⅱ. 구조 및 구성요소

```text
원본 데이터 벡터(v) -> 기저 벡터(Basis) 재정의 -> 변환 행렬(T) 결합 -> 행렬 곱 연산(T*v) -> 변환된 공간 벡터(v')
                                                +-> 선형성 보존 검증
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 변환 대상 벡터 ($v$) | 다차원 공간의 데이터 포인트 | 특징 공간(Feature Space) 상의 위치 |
| 변환 행렬 ($T$) | 선형 변환의 규칙을 압축한 연산자 | 기저 벡터의 도착지 좌표로 구성됨 |
| 가산성 (Additivity) | $T(u + v) = T(u) + T(v)$ | 선형 결합을 유지하는 1번 성질 |
| 동차성 (Homogeneity) | $T(cv) = cT(v)$ | 스칼라 배율을 유지하는 2번 성질 |

> 요약: 선형 변환은 가산성과 동차성을 만족하는 규칙 아래, 변환 행렬 $T$를 통해 입력 벡터 $v$의 차원과 공간을 재구성한다.

---

## Ⅲ. 동작원리 및 흐름도

```text
변환 목적 식별 -> 기저 벡터의 변환 좌표 도출 -> 변환 행렬 T 생성 -> 입력 행렬 X와 곱 연산 -> Y 맵핑
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 기저 벡터(예: $\hat{i}$, $\hat{j}$)의 변환 후 목적지 결정 | 선형 독립성 유지 여부 |
| 2 | 목적지 벡터를 열로 삼아 변환 행렬 도출 | 정방 또는 비정방 행렬 구성 |
| 3 | 다중 입력 데이터(배치 단위)와의 행렬 곱 | $Y = TX$ |
| 4 | 차원 축소/확장 및 공간 사상 검증 | 랭크(Rank) 붕괴 여부 |

> 요약: 기저 벡터가 어떻게 움직이는지만 행렬로 정의하면, 공간 내의 모든 데이터는 동일한 변환 규칙을 따라 이동한다.

## Ⅳ. 특징

| 구분 | 내용 | 판단 포인트 |
|:---|:---|:---|
| 합성의 용이성 | 여러 선형 변환을 연달아 수행해도 하나의 행렬 곱으로 표현됨 ($T_2(T_1(x)) = (T_2 T_1)x$) | 연산 복잡도 최적화(행렬 병합) |
| 원점 보존 | $T(0) = 0$ 이 항상 성립해야 함 | 편향이 포함되면 아핀 변환으로 분류 |
| 구조 보존 | 평행한 직선은 변환 후에도 여전히 평행함 | 기하학적 왜곡 방지 |

> 요약: 선형 변환은 복잡한 공간 변환을 단일 행렬 곱으로 묶어주어 연산 효율을 극대화하지만 원점이 이동하지 않는 한계가 있다.

---

## Ⅴ. 심화 비교 및 적용 판단

| 구분 | 순수 선형 변환 | 아핀 변환 (Affine) | 비선형 변환 (Non-linear) | 선택 기준 |
|:---|:---|:---|:---|:---|
| 구성 | $f(x) = Wx$ | $f(x) = Wx + b$ | $f(x) = \text{ReLU}(Wx+b)$ | 풀고자 하는 문제의 복잡도 |
| 원점 보존 | 보존됨 ($0 \rightarrow 0$) | 이동함 ($0 \rightarrow b$) | 함수에 따라 다름 | 평행 이동 필요 여부 |
| 합성 결과 | 단일 선형 변환으로 붕괴 | 단일 아핀 변환으로 붕괴 | 다중 층 구성 시 복잡도 증가 | 딥러닝 다층 신경망(MLP) 구성 시 |

> 요약: 단순 투영이나 회전은 선형 변환으로 충분하나, 복잡한 인공지능 학습을 위해서는 아핀 변환 후 비선형 활성화가 필수적이다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 신경망의 층 붕괴 | 비선형 활성화 함수 없이 선형 층(Dense)만 연속 배치 | ReLU, GELU 등의 Non-linear Activation 추가 | 모델 수렴도 및 비선형 경계 생성 |
| 차원 축소에 의한 정보 손실 | 변환 행렬의 Rank가 입력 차원보다 작을 때 특이점 발생 | 필요 시 SVD를 통해 분산 보존율 높은 축만 선별 | 변환 전후 분산 설명력(Explained Variance) |
| 부동소수점 누적 오차 | 다수의 행렬 합성에 의한 소수점 절사 오류 | 정밀도 유지(FP32) 또는 텐서 코어 혼합 정밀도 | 연산 오차율 |

> 요약: 선형 변환만으로 딥러닝 모델을 구성하면 단일 층과 같아지므로, 반드시 비선형 함수를 교차 설계하여 층 붕괴를 막는다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 행렬 병합 최적화 | 추론 시 연속된 선형 층은 1개 행렬로 사전 병합 | 모델 파라미터 수 및 추론 지연시간 |
| Rank 유지 여부 | 변환 행렬이 풀 랭크(Full Rank)를 유지 | SVD를 통한 특이값 개수 측정 |
| 텐서 연산 가속 | 변환 연산 시 GPU 가동률 80% 이상 | Nsight Systems 연산 프로파일링 |

> 요약: 선형 변환 로직 배포 시에는 연달아 있는 행렬들을 수학적으로 병합하여 추론 지연시간을 단축해야 한다.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 — 단계별 또는 항목별):**
1. 신경망 추론 최적화(Quantization): 모델 배포 시 연속된 선형 층(가중치 곱)을 단일 행렬로 병합하고 편향을 더하는 아핀 변환으로 압축하여 추론 속도를 2배 이상 높인다.
2. 이미지 데이터 기하 변환: 자율주행 데이터 Augmentation 시, 회전(Rotation), 크기 조절(Scaling), 전단(Shearing) 등의 선형 변환 행렬을 결합해 GPU 내에서 이미지 증강을 실시간 처리한다.
3. 차원 축소 파이프라인: 다변량 로그 데이터를 시각화하기 위해 PCA 기반의 직교 선형 변환 행렬을 도출하여 100차원의 데이터를 정보 손실 없이 3차원으로 맵핑한다.

**결론 (2줄):**
- 기술사 판단: 선형 변환은 딥러닝 텐서 연산과 컴퓨터 그래픽스의 근간으로, 복잡한 기하학적 맵핑을 행렬 곱 하나로 치환하여 GPU 병렬화의 이점을 극대화한다.
- 향후 방향: 최근 LLM의 어텐션 메커니즘에서는 $Q, K, V$ 맵핑 시 저대역(Low-Rank) 선형 변환 행렬(LoRA)을 적용해 초거대 파라미터 훈련 비용을 획기적으로 낮추고 있다.
