# 📖 【암기용】 개념 완전 이해

> 목적: 선형 변환을 처음 봐도 완전히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 벡터를 행렬로 사상하되 덧셈과 스칼라배 구조를 보존하는 변환
- **왜 필요한가**: 회전·확대·투영·좌표변환을 하나의 행렬 곱으로 표현해 그래픽스, ML, 신호처리 계산을 통일함
- **핵심 직관**: 공간의 격자를 휘지 않고 밀거나 돌리거나 눌러도 원점과 직선성은 유지하는 규칙임

## 깊이 이해
- **배경·문제의식**: 점마다 별도 공식을 쓰면 3D 좌표 100만 개 변환에 100만 개 규칙이 필요함. 선형 변환은 행렬 1개로 전체 공간 변환을 표현함.
- **작동 원리**: 기저벡터가 어디로 이동하는지만 알면 모든 벡터의 이동이 결정됨. 2차원에서 `e1`, `e2`의 변환 결과를 열벡터로 쌓으면 2x2 변환 행렬이 됨.
- **비유**: 투명 필름 위 격자를 잡아당길 때, 한 칸짜리 x축·y축 화살표의 이동만 알면 필름 위 모든 점의 이동을 예측할 수 있음.
- **구체 예시**: `[[2,0],[0,3]]`은 x좌표 2배, y좌표 3배 확대. `(1,2)`는 `(2,6)`으로 이동하며 면적은 행렬식 6배가 됨.
- **흔한 오해·주의점**: 평행이동은 원점을 옮기므로 순수 선형 변환이 아님. 3D 그래픽스에서는 동차좌표 4x4 행렬로 평행이동을 함께 표현함.

## 연결 개념
- 행렬 연산: 선형 변환의 계산 표현
- 고유값·고유벡터: 변환 후 방향이 바뀌지 않는 축
- PCA: 공분산 행렬의 선형 변환 축을 이용한 차원 축소

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 선형 변환은 `T(ax+by)=aT(x)+bT(y)`를 만족하는 벡터공간 간 사상이다.
> 2. **가치**: 회전·확대·투영을 행렬 곱 1회로 표현해 그래픽스, ML, 신호처리 파이프라인의 공통 계산 단위가 됨.
> 3. **판단 포인트**: 원점 보존, 차원 변화, 행렬식, 랭크로 변환의 보존·축소·특이성을 판단함.

---

## Ⅰ. 개요 및 필요성

선형 변환은 벡터공간 구조를 보존하는 행렬 기반 사상이다. 좌표계 변환, 영상 회전, 데이터 투영은 입력 벡터를 다른 벡터로 바꾸는 공통 문제이다. 선형 변환을 쓰면 `n x m` 행렬과 벡터 곱으로 대량 데이터를 같은 규칙으로 처리할 수 있다.

---

## Ⅱ. 구조 및 구성요소

```text
입력 벡터 x -> 변환 행렬 A -> 출력 벡터 y=Ax
벡터공간 V -> 기저벡터 사상 -> 벡터공간 W
```

| 구성요소 | 역할 | 판단 기준 |
|:---|:---|:---|
| 입력 벡터 | 변환 대상 좌표 | 차원 n, 기저 선택 |
| 변환 행렬 | 기저벡터 이동 규칙 저장 | 행렬 크기 m x n, 랭크 |
| 출력 벡터 | 변환 결과 좌표 | 차원 m, 보존 특성 |
| 행렬식 | 면적·부피 변화율 | `det(A)=0`이면 정보 손실 |

> 요약: 선형 변환은 입력 벡터, 변환 행렬, 출력 벡터, 행렬식으로 구조·차원·정보 손실 여부를 판정함.

---

## Ⅲ. 동작원리 및 흐름도

```text
기저 선택 -> 행렬 구성 -> 벡터 곱 계산 -> 랭크/행렬식 검증 -> 변환 결과 해석
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 입력 공간의 기저벡터 결정 | 독립 벡터 n개 |
| 2 | 기저벡터의 변환 결과를 행렬 열로 배치 | m x n 행렬 완성 |
| 3 | `y=Ax`로 좌표 일괄 변환 | 곱셈 차원 일치 |
| 4 | 랭크·행렬식·커널 확인 | `rank(A)`, `det(A)` |

> 요약: 기저벡터 사상만 행렬로 저장하면 모든 벡터 변환은 행렬 곱과 랭크 검증으로 처리됨.

---

## Ⅳ. 특징

| 구분 | 일반 함수 | 선형 변환 | 수치·판단 포인트 |
|:---|:---|:---|:---|
| 보존 성질 | 입력별 임의 규칙 | 덧셈·스칼라배 보존 | `T(ax+by)=aT(x)+bT(y)` |
| 계산 방식 | 조건문·비선형식 가능 | 행렬 곱 중심 | `O(mn)` 곱셈 |
| 정보 손실 | 함수별 별도 분석 | 랭크·행렬식으로 판정 | `det(A)=0` 특이 |
| 적용 영역 | 개별 모델 의존 | 좌표·투영·회전 공통 | 2D 2x2, 3D 3x3 |

> 요약: 선형 변환은 보존 성질을 만족할 때 행렬식·랭크로 변환 품질과 정보 손실을 정량 판정함.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존/대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | 일반 함수 | 선형 변환 | 가산성·동차성·원점 보존 성립 |
| 비용/성능 | 점별 변환 | 행렬 곱 배치 처리 | 좌표 100만 개 이상 일괄 처리 |
| 운영/위험 | 비선형 변형 포함 | 랭크·행렬식 검증 | 정보 손실·특이행렬 여부 판단 |

> 요약: 선형 변환은 보존 성질이 성립하고 행렬식·랭크로 손실을 판단할 수 있을 때 선택함

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 정보 손실 | `rank(A)<n`, `det(A)=0` | 차원 축소 목적 명시, 역변환 금지 | rank, determinant |
| 모델 오용 | 평행이동을 선형으로 처리 | 동차좌표 4x4 사용 | 원점 보존 테스트 |
| 수치 오차 | 반복 행렬 곱 | 정규화, FP64 검증 | 좌표 오차 RMS |

> 요약: 선형 변환 리스크는 랭크 손실, 평행이동 오용, 누적 오차이며 행렬 지표로 통제함

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 보존 성질 | `T(ax+by)=aT(x)+bT(y)` 통과 | 샘플 벡터 테스트 |
| 손실 판단 | rank·determinant 기준 충족 | 선형대수 라이브러리 |
| 처리량 | 배치 곱 처리시간 목표 충족 | BLAS/GPU 벤치마크 |

> 요약: 선형 변환 적용 효과는 보존 성질, 손실 지표, 배치 처리량으로 판단함

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 3D 렌더링: 회전 3x3, 동차좌표 4x4 행렬을 분리해 카메라 변환과 월드 변환을 체인 곱으로 구성
2. ML 전처리: 표준화 후 PCA 투영행렬로 100차원 특징을 누적분산 95% 기준 차원으로 축소
3. 신호처리: DCT·FFT 변환 행렬로 시간영역 데이터를 주파수영역으로 투영하고 에너지 보존 여부 확인

**결론 (2줄):**
- 기술사 판단: 원점 보존·가산성·동차성이 성립하면 선형 변환으로 모델링하고, 평행이동 포함 시 동차좌표를 적용함
- 향후 방향: 대규모 ML·그래픽스에서는 행렬 연산을 GPU BLAS와 텐서코어 단위로 배치 처리하는 방향이 적합함
