## Ⅰ. 개요
- 정의: 벡터 공간 사이에서 가산성과 동차성을 유지하며 벡터를 옮기는 함수임
- 배경/필요성: 좌표계 변환, 이미지 회전/크기 조정 등 기하학적 조작을 수학적으로 정의함
- 출제 의도: 선형성 조건(T(u+v)=T(u)+T(v), T(cu)=cT(u)) 및 변환 행렬 이해

## Ⅱ. 구성요소
- ASCII 구조도
  Vector x ----[ Matrix A ]----> Vector b (Ax = b)
   (Input)     (Transformation)     (Output)

- 구성요소 표
| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| 표준 행렬 | 선형 변환을 행렬 형태로 표현한 것 | 변환 도구 |
| 커널 (Kernel) | 변환 결과가 영벡터가 되는 입력들의 집합 | 소멸 영역 |
| 치역 (Range) | 변환을 통해 도달할 수 있는 모든 결과 벡터 | 도달 범위 |
| 기저 (Basis) | 공간을 구성하는 기본 축 벡터들의 집합 | 좌표축 |
> 요약: 선형 변환은 행렬 곱셈을 통해 공간의 형태를 변형시키거나 회전시킴

## Ⅲ. 절차
- ASCII 흐름도
  [Domain Vector] -> [Apply Matrix] -> [Transformed Vector]

1. 선형성 확인: 가산성과 동차성 두 가지 조건을 만족하는지 검증함
2. 변환 행렬 구성: 기저 벡터들이 어떻게 변하는지 추적하여 행렬의 열로 배치함
3. 연산 수행: 입력 벡터에 변환 행렬을 곱하여 결과 벡터를 산출함
4. 역변환 검토: 역행렬이 존재할 경우 원래 상태로 되돌리는 변환을 정의함
> 요약: 행렬을 함수로 간주하여 벡터를 다른 위치나 차원으로 매핑함

## Ⅳ. 문제점
- 차원 축소: 가역적이지 않은 변환 시 정보가 소실되어 원복 불가능함
- 연산 정밀도: 연속적인 변환 행렬 곱 적용 시 부동소수점 오차가 누적될 수 있음

## Ⅴ. 개선방안
- 동차 좌표계: 3D 변환을 위해 4x4 행렬을 사용하여 이동 변환까지 선형으로 통합함
- 특이값 분해 (SVD): 복잡한 변환을 회전과 크기 조정의 기본 단위로 분해하여 분석함

## Ⅵ. 전망
- 신경망 표현 학습: 딥러닝의 각 레이어가 수행하는 고차원 특징 공간에서의 선형 변환과 비선형 활성화 함수의 결합을 통해, 복잡한 데이터의 잠재 공간(Latent Space) 투영을 최적화함
- 가상현실 및 로보틱스: 다중 센서 융합 환경에서 서로 다른 좌표계 간의 실시간 선형 변환(Affine/Projective)을 통해 정밀한 SLAM 및 디지털 트윈 가시화 품질을 확보함
- CSF: 연속적인 변환 행렬 곱 적용 시 발생하는 부동소수점 오차 누적 방지를 위한 수치 안정화 기법과 GPU 하드웨어 가속을 위한 연산 구조 최적화가 필수적임
