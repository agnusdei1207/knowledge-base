## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 선형 변환(Linear Transformation)은 벡터 공간 간 **구조를 보존하는 함수** $T: V \to W$이다. 두 가지 성질 — **가법성** $T(u+v) = T(u) + T(v)$과 **동차성** $T(cv) = cT(v)$— 을 만족하는 함수를 선형이라 한다. 핵심은 **모든 선형 변환은 행렬로 표현 가능**하다는 점이다.
> 2. **가치**: 3D 그래픽의 회전·크기 변환, 머신러닝의 은닉층 연산($Y = WX + b$), 이미지 처리의 필터링, 로봇공학의 좌표 변환 등 모든 '직선을 직선으로 보내는' 변환이 선형 변환이다.
> 3. **융합**: 컴퓨터 그래픽스(MVP 행렬), AI(완전연결층 = 선형 변환 + 비선형 활성화), 제어공학(상태 공간 모델), 양자 컴퓨팅(유니터리 변환), 통계(PCA = 고유벡터 방향으로의 선형 변환) 등 CS 전 분야에서 사용된다.

### 🔑 핵심 용어 정리

| 용어 | 뜻 | 비유 |
|:---|:---|:---|
| **선형 변환** | 벡터의 덧셈과 스칼라 곱을 보존하는 함수. 행렬 곱 $T(x) = Ax$로 표현 | "직선을 직선으로 보내는 변환" |
| **핵(Kernel, Null Space)** | $T(v) = 0$을 만족하는 모든 벡터의 집합. 차원 = nullity | "사라지는 벡터들의 모임" |
| **치역(Range, Image)** | $T$가 출력할 수 있는 모든 벡터의 집합. 차원 = rank | "갈 수 있는 목적지" |
| **랭크-널리티 정리** | $\text{rank}(T) + \text{nullity}(T) = \dim(V)$. 정보 보존 + 소실의 총합 = 원래 차원 | "빛 + 그림자 = 전체" |
| **아핀 변환(Affine Transform)** | 선형 변환 + 이동(Translation). $T(x) = Ax + b$. 동차 좌표로 행렬 곱 하나로 통합 | "밀고 돌리기" |
| **동차 좌표(Homogeneous Coord.)** | $n$차원 점을 $(n+1)$차원으로 확장하여 이동까지 행렬 곱으로 표현. 3D에서 $4 \times 4$ 행렬 사용 | "차원 하나 더 추가" |

## Ⅰ. 개요 및 필요성

- **개념**: 선형 변환은 두 가지 성질을 만족하는 함수이다:

$$
T(u + v) = T(u) + T(v) \quad \text{(가법성)}
$$
$$
T(cv) = cT(v) \quad \text{(동차성)}
$$

$n$차원에서 $m$차원으로의 모든 선형 변환은 $m \times n$ 행렬 $A$로 표현된다: $T(x) = Ax$.

- **필요성**: 3D 게임에서 캐릭터를 45° 회전하려면? 회전 행렬 $R(\theta)$를 정점 좌표에 곱하면 된다. 이미지를 2배 확대하려면? 스케일 행렬 $S$를 곱하면 된다. 연속으로 회전→크기→이동을 적용하려면? 행렬 곱의 연쇄 $M = T \cdot S \cdot R$로 합성할 수 있다. 이것이 선형 변환의 위력이다.

- **비유**: 선형 변환은 **"격자 종이의 변형"**이다. 격자 종이 위의 점들이 직선 위에 있었다면, 선형 변환 후에도 직선 위에 있고, 원점은 그대로이다(이동 없이). 종이를 잡아당기거나, 돌리거나, 찌그러뜨릴 수 있지만, 직선이 곡선으로 바뀌지는 않는다.

```text
+-----------------------------------------------------------------------+
|        2D 선형 변환의 시각적 분류                                     |
+-----------------------------------------------------------------------+
|                                                                       |
|  [원본]    [회전]     [크기변환]   [전단(Shear)]  [반사]               |
|   □         ◇         ⬜           ▱              □(좌우뒤집힘)       |
|                                                                       |
|  회전 행렬:                  크기변환:          전단:                  |
|  ┌ cos θ  -sin θ ┐    ┌ sx  0 ┐        ┌ 1  k ┐                     |
|  └ sin θ   cos θ ┘    └ 0  sy ┘        └ 0  1 ┘                     |
|                                                                       |
|  ★ 모든 변환은 행렬 곱 하나로 표현됨                                 |
|  ★ 합성 = 행렬 곱의 연쇄: M = T · S · R                             |
+-----------------------------------------------------------------------+
```

**[다이어그램 해설]** 2D 선형 변환의 4가지 기본 유형을 보여준다. 회전은 $\begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix}$, 크기 변환은 대각 행렬, 전단은 비대각 원소를 가진 행렬이다. 모든 변환이 $2 \times 2$ 행렬 하나로 표현되며, 여러 변환의 합성은 행렬 곱의 연쇄이다.

- **📢 섹션 요약 비유**: 선형 변환은 "격자 종이를 늘이거나 돌리는 것"입니다. 직선은 직선으로 유지되고, 원점은 움직이지 않습니다.

## Ⅱ. 아키텍처 및 핵심 원리

### 구성 요소

| 요소명 | 행렬 표현 | 효과 | 응용 | 비유 |
|:---|:---|:---|:---|:---|
| **회전(Rotation)** | $R(\theta)$ 직교 행렬 | 각도 $\theta$만큼 회전 | 3D 게임, 로봇 | 핸들 돌리기 |
| **크기(Scaling)** | $\text{diag}(s_x, s_y, s_z)$ | 축별 확대/축소 | 이미지 리사이징 | 줌 인/아웃 |
| **전단(Shear)** | 비대각 원소 | 한 축을 기울임 | 기울임 효과 | 카드 밀기 |
| **반사(Reflection)** | 축 기준 부호 반전 | 거울 대칭 | 이미지 뒤집기 | 거울 |
| **투영(Projection)** | 랭크 부족 행렬 | 차원 축소 | PCA, 그림자 | 그림자 투영 |

### 신경망에서의 선형 변환

신경망의 완전연결층(Fully Connected Layer)은 본질적으로 **선형 변환 + 비선형 활성화**이다:

$$
h = \sigma(Wx + b)
$$

$W$가 선형 변환(행렬 곱), $b$가 이동(아핀), $\sigma$가 비선형 활성화(ReLU, Sigmoid)이다. 만약 $\sigma$가 없다면 여러 층을 쌓아도 하나의 행렬 곱과 동치($W_2 W_1 x = W' x$)이므로, 비선형 활성화가 필수이다.

- **📢 섹션 요약 비유**: 신경망은 "선형 변환(행렬 곱)과 비선형 꺾기(활성화)의 반복"입니다. 선형만으로는 직선밖에 못 그리지만, 꺾기를 추가하면 모든 곡선을 그릴 수 있습니다.

## Ⅲ. 비교 및 연결

### 비교 1: 선형 변환 vs 아핀 변환

| 비교 항목 | 선형 변환 | 아핀 변환 |
|:---|:---|:---|
| **수식** | $T(x) = Ax$ | $T(x) = Ax + b$ |
| **원점 보존** | 항상 원점 → 원점 | 원점이 $b$로 이동 |
| **행렬 크기 (3D)** | $3 \times 3$ | $4 \times 4$ (동차 좌표) |
| **포함 관계** | $b = 0$인 아핀 | 선형의 상위 집합 |
| **실무** | 회전, 크기, 반사 | 이동 포함 3D 변환 전체 |

### 과목 융합 관점
- **3D 그래픽스**: Model-View-Projection 파이프라인은 3단계 $4 \times 4$ 행렬 곱이다. 모든 정점에 $M_{MVP}$를 곱하면 3D 세계 좌표 → 2D 화면 좌표로 변환된다.
- **PCA**: 데이터를 고유벡터 방향으로 선형 변환(투영)하여 분산이 최대인 축을 찾는다.

- **📢 섹션 요약 비유**: 선형 변환이 "제자리에서 돌리기"라면, 아핀 변환은 "돌리고 + 밀기"입니다.

## Ⅳ. 실무 적용 및 기술사 판단

### 실무 시나리오

1. **시나리오 — WebGL 3D 렌더링**: 웹 브라우저에서 3D 물체를 렌더링할 때, 정점 셰이더가 각 정점에 $4 \times 4$ MVP 행렬을 곱하여 화면 좌표로 변환한다. 이 연산은 GPU에서 수백만 정점에 대해 병렬로 수행된다.

### 안티패턴
- **행렬 곱 순서 오류**: 행렬 곱은 비교환적이므로 $R \cdot S \neq S \cdot R$이다. 3D 변환에서 크기→회전→이동 순서를 지키지 않으면 결과가 완전히 달라진다.

- **📢 섹션 요약 비유**: 행렬 곱 순서를 바꾸면 "먼저 옷 입고 양말 신기 vs 양말 먼저 신기"처럼 결과가 달라집니다.
