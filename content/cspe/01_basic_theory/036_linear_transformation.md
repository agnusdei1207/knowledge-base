## 미리 알고가기

- 벡터 공간(Vector Space): 벡터 덧셈과 스칼라 곱이 닫혀 있는 집합임
- 선형성(Linearity): $T(u+v)=T(u)+T(v)$와 $T(cu)=cT(u)$를 모두 만족하는 성질임
- 기저(Basis): 벡터 공간의 모든 벡터를 표현하는 독립 벡터 집합임
- 표준 행렬(Standard Matrix): 선형 변환을 행렬 곱 $Ax$로 표현한 행렬임
- 직교 행렬(Orthogonal Matrix): $A^TA=I$를 만족해 벡터의 길이와 각도를 보존하는 행렬임
- 멱등 행렬(Idempotent Matrix): $A^2=A$를 만족해 같은 변환을 반복해도 결과가 달라지지 않는 행렬임
- 아핀 변환(Affine Transformation): 선형 변환에 이동을 더한 변환이며 이동이 있으면 원점을 보존하지 않음
- 핵·치역(Kernel and Range): 각각 0으로 사상되는 입력 집합과 실제로 도달하는 출력 집합임
- 동차 좌표(Homogeneous Coordinates): 이동을 행렬 곱에 포함하도록 좌표 차원을 하나 늘린 표현임
- $e_1,e_2$: 표준 행렬의 각 열을 결정하는 입력 공간의 기저 벡터임

## 작성 근거(검토용)

- **개요 구성**: 덧셈과 스칼라 곱 보존 조건을 먼저 제시해 아핀 변환과 구분되게 하고, 이 핵심 조건을 미리 알고가기에도 배치함
- **Ⅱ. 특징 선정**: 원점 보존·기저 사상 결정·합성 사전 계산을 선별해 보존 조건이 만드는 실질적 이점을 드러냄
- **Ⅲ. 비교축 선정**: 크기·각도·기울기·차원에 서로 다른 변화를 만드는 확대·회전·전단·투영으로 한정함
- **Ⅳ. 구조 선정**: 정의역·공역·핵·치역을 포함해 선형 변환의 정보 손실 판단을 보이게 함
- **Ⅵ·Ⅶ. 사례·결론 선정**: 아핀 변환과 PCA는 선형 변환 원리가 실제 계산 조건으로 이어지는 대표 사례임
- **전수 검수**: 제목부터 결론까지 용어·표·도식·요약을 대조하고 덧셈·스칼라 곱 보존 정의와 절 간 판단축을 일치시킴

## Ⅰ. 개요

- **정의/개념**: 선형 변환은 벡터의 덧셈과 스칼라 곱 관계를 보존하는 공간 간 변환임
- **배경/필요성**: 좌표 변환과 선형 결합을 행렬 곱으로 계산할 선형 변환이 필요함

### 쉽게 이해하기 (학습용)
- 사진을 확대·회전해도 사진 속 물체들의 상대적 위치 관계는 그대로 유지되는 규칙적인 변형과 같음

## Ⅱ. 특징

- 0 벡터를 0 벡터로 보내고 벡터의 선형 결합 관계를 보존함
- 기저 벡터의 사상 결과만 알면 전체 변환을 결정함
- 유한차원 벡터 공간의 선형 변환은 기저를 정하면 행렬과 벡터 곱으로 표현함
- 변환 합성은 행렬 곱으로 처리되어 사전 계산이 가능함

### 쉽게 이해하기 (학습용)
- 원점은 항상 제자리에 남고, 기준이 되는 몇 개의 화살표가 어디로 가는지만 알면 나머지 모든 점의 이동을 계산으로 알 수 있음
- 변환을 여러 번 거치는 것도 미리 곱셈 하나로 합쳐 준비해둘 수 있음

## Ⅲ. 종류 및 비교

| 변환 | 기하 의미 | 행렬 특성 | 활용 |
|:---|:---|:---|:---|
| 확대·축소 | 축별 크기 변경 | 대각 성분 조정 | 정규화·크기 조정 |
| 회전 | 원점 기준 각도 변경 | 직교 행렬 | 그래픽스·로봇 자세 |
| 전단 | 한 축 방향으로 기울임 | 비대각 성분 사용 | 이미지 왜곡·폰트 |
| 투영 | 낮은 차원으로 사상 | $A^2=A$ | 그림자·차원 축소 |

> 요약: 확대·축소는 대각 성분, 회전은 직교 행렬, 전단은 비대각 성분, 투영은 $A^2=A$인 행렬로 표현함.

### 쉽게 이해하기 (학습용)
- 사진을 늘리기(확대·축소), 돌리기(회전), 비스듬히 밀기(전단), 그림자처럼 납작하게 눌러 찍기(투영)라는 네 가지 서로 다른 변형 방식임

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 정의역 | 변환 전 벡터 공간 |
| 공역 | 변환 결과의 목표 공간 |
| 핵 | 0 벡터로 사상되는 입력 집합 |
| 치역 | 실제 도달 가능한 출력 집합 |
| 표준 행렬 | 변환 기저 벡터의 열 행렬 |

```text
기저:
e1 -> T(e1)
e2 -> T(e2)

표준 행렬:
A = [ T(e1)  T(e2) ]
T(x) = A * x
```

> 요약: 선형 변환은 기저 벡터의 사상으로 표준 행렬을 구성하고 핵과 치역으로 소실되는 입력 방향과 도달 가능한 출력을 구분함.

### 쉽게 이해하기 (학습용)
- 변환 전 세상(정의역)과 변환 후 세상(공역)이 있고, 어떤 점들은 변환 후 완전히 사라져 원점에 뭉개지며(핵), 실제로 도달 가능한 자리만 모은 것(치역)임

## Ⅵ. 실무 사례

1. 그래픽 엔진은 동차 좌표를 사용해 회전·크기 조정·이동을 하나의 행렬로 합성함
2. 차원 축소 파이프라인은 데이터 분산을 많이 보존하는 축으로 입력을 투영함

### 쉽게 이해하기 (학습용)
- 게임 캐릭터를 돌리고 키우고 옮기는 동작을 한 번의 계산으로 합쳐 처리하고, 데이터를 그림자처럼 눌러 찍을 때 특징이 가장 잘 드러나는 각도를 고르는 것과 같음

## Ⅶ. 결론

- 선형 변환은 덧셈과 스칼라 곱을 보존하며 기저 벡터의 사상 결과로 전체 변환을 결정함
- 좌표 변환 파이프라인은 기저·단위·행렬 적용 순서를 계약으로 고정하고, 비선형 관계는 선형 모델에 억지로 포함하지 말아야 함

### 쉽게 이해하기 (학습용)
- 몇 개의 기준 화살표만 정해두면 전체 변환을 예측할 수 있지만, 애초에 직선으로 설명되지 않는 휘어진 움직임까지 억지로 끼워 맞추면 안 됨
