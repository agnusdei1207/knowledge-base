## 미리 알고가기

- 벡터 공간: 벡터 덧셈과 스칼라 곱이 닫혀 있는 집합임
- 선형성: $T(u+v)=T(u)+T(v)$와 $T(cu)=cT(u)$를 모두 만족하는 성질임
- 기저: 벡터 공간의 모든 벡터를 표현하는 독립 벡터 집합임
- 표준 행렬: 선형 변환을 행렬 곱 $Ax$로 표현한 행렬임
- 아핀 변환: 선형 변환에 이동을 더한 변환이며 이동이 있으면 원점을 보존하지 않음

## Ⅰ. 개요

- **정의/개념**: 선형 변환은 벡터의 덧셈과 스칼라 배 관계를 보존하는 공간 간 변환임
- **배경/필요성**: 좌표 변환, 차원 축소, 신호 처리처럼 입력 구조를 유지한 계산을 행렬 곱으로 단순화할 때 필요함

## Ⅱ. 특징

- 원점은 원점으로 이동하고 직선성은 유지됨
- 기저 벡터의 이동 결과만 알면 전체 변환을 결정함
- 모든 선형 변환은 표준 행렬과 벡터 곱으로 표현 가능함
- 변환 합성은 행렬 곱으로 처리되어 사전 계산이 가능함

## Ⅲ. 종류 및 비교

| 변환 | 기하 의미 | 행렬 특성 | 활용 |
|:---|:---|:---|:---|
| 확대·축소 | 축별 크기 변경 | 대각 성분 조정 | 정규화, 리사이징 |
| 회전 | 원점 기준 각도 변경 | 직교 행렬 | 그래픽스, 로봇 자세 |
| 전단 | 한 축 방향으로 기울임 | 비대각 성분 사용 | 이미지 왜곡, 폰트 |
| 투영 | 낮은 차원으로 사상 | $A^2=A$ | 그림자, 차원 축소 |

> 요약: 선형 변환은 기저 벡터를 어디로 보내는지가 곧 전체 공간의 변환 방식임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 정의역 | 변환 전 벡터가 속한 공간임 |
| 공역 | 변환 결과가 속하도록 정한 목표 공간임 |
| 핵 | 0 벡터로 사상되는 입력 집합이며 손실 방향을 보임 |
| 치역 | 실제 변환으로 도달 가능한 출력 공간임 |
| 표준 행렬 | 변환된 기저 벡터를 열로 모아 만든 행렬임 |

```text
basis:
e1 -> T(e1)
e2 -> T(e2)

matrix:
A = [ T(e1)  T(e2) ]
T(x) = A * x
```

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+   +----------+   +----------+   +----------+
| 기저 선택 | -> | 기저 변환 | -> | 행렬 구성 | -> | 벡터 변환 |
+----------+   +----------+   +----------+   +----------+
```

1. 변환할 공간의 기저 벡터를 정함
2. 각 기저 벡터가 변환 후 어디로 가는지 계산함
3. 변환된 기저 벡터를 열로 배치해 표준 행렬을 만듦
4. 임의의 입력 벡터에 표준 행렬을 곱해 결과를 얻음

## Ⅵ. 실무 적용 및 유의점

1. 그래픽스의 이동은 순수 선형 변환이 아니므로 동차 좌표를 써서 회전·확대·이동을 4x4 행렬로 통합함
2. PCA 차원 축소는 분산 보존이 목적이므로 투영 행렬을 고유값 크기와 재구성 오차로 검증함

## Ⅶ. 결론

- 선형 변환은 기저의 이동을 행렬 곱으로 일반화해 공간 구조를 보존하며 계산하는 핵심 선형대수 도구임

## 작성 근거(검토용)

- 기존 파일에 같은 문서가 중복되어 지정 파일 안에서 단일 정본 구조로 정리함
- 선형 변환의 핵심 조건인 덧셈 보존과 스칼라 곱 보존을 미리 알고가기에 배치함
- 비교표는 그래픽스와 데이터 분석에서 자주 쓰는 확대, 회전, 전단, 투영으로 한정함
- 구성요소는 정의역, 공역, 핵, 치역을 포함해 선형 변환의 정보 손실 판단을 보이게 함
- 실무 절은 아핀 변환과 PCA를 넣어 순수 이론이 실제 계산 조건으로 이어지게 함
