## 미리 알고가기

- 일반화($Generalization$): 학습에 쓰지 않은 데이터에서도 모델이 성능을 유지하는 능력임
- 편향($Bias$): 모델 가정이 단순하거나 잘못되어 평균 예측이 실제값에서 벗어나는 오차임
- 분산($Variance$): 학습 데이터가 조금 바뀔 때 모델 예측이 얼마나 변동하는지 나타내는 오차임
- 모델 용량($Capacity$): 모델이 표현 가능한 함수의 복잡도 수준임
- 검증 곡선($Validation$ Curve): 모델 복잡도 변화에 따른 훈련·검증 성능 변화를 보는 그래프임

## 작성 근거(검토용)

- 세 개념을 따로 설명하지 않고 훈련 오차·검증 오차·모델 용량의 관계로 통합함
- 편향-분산 트레이드오프는 추상어가 되기 쉬워 검증 곡선과 오차 격차로 판단 기준을 구체화함
- 규제와 조기 종료는 과적합 대응의 대표 수단이라 구조와 사례에 배치함
- 테스트 세트 재사용은 성능 과대평가를 만들 수 있어 사례의 검증 조건에 포함함
- 결론은 일반화 성능 중심으로 정리해 앞 절의 검증 기준과 연결함

## Ⅰ. 개요

- **정의/개념**: 과적합은 모델이 훈련 데이터의 잡음까지 학습한 상태이고 과소적합은 기본 패턴도 학습하지 못한 상태이며, 편향-분산 트레이드오프는 두 오차의 균형을 맞추는 기준임
- **배경/필요성**: 실제 환경의 일반화 성능을 확보하기 위해 모델 복잡도에 따른 검증 오차를 판단해야 함

## Ⅱ. 특징

- 과소적합은 모델 용량이 낮아 훈련 오차와 검증 오차가 모두 높게 나타남
- 과적합은 훈련 오차는 낮지만 검증 오차가 높아 두 오차 간 격차가 커짐
- 모델 복잡도가 증가하면 편향은 낮아지지만 분산이 커져 검증 성능이 다시 악화됨
- 모델 복잡도는 훈련 성능이 가장 높은 지점이 아니라 검증 오차가 가장 낮은 구간을 기준으로 선택함

## Ⅲ. 종류 및 비교

| 기준 | 과소적합 | 적정 적합 | 과적합 |
|:---|:---|:---|:---|
| 모델 용량 | 데이터 패턴을 표현하기 부족 | 검증 오차가 최소인 수준 | 훈련 데이터의 잡음까지 표현 |
| 오차 패턴 | 훈련·검증 오차가 모두 높음 | 검증 오차가 최소이고 두 오차의 격차가 통제됨 | 훈련 오차만 낮아 두 오차의 격차가 커짐 |
| 주요 오차 | 고편향 | 편향·분산 균형 | 고분산 |
| 조정 방향 | 특징 추가·모델 확장 | 현재 복잡도 유지 | 규제·데이터 증강·조기 종료 |

> 요약: 훈련·검증 오차가 모두 높으면 과소적합, 검증 오차가 최소이고 격차가 통제되면 적정 적합, 훈련 오차만 낮아 격차가 커지면 과적합으로 판단함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 모델 용량 | 파라미터 수·깊이·특징 수로 결정되며 편향과 분산을 동시에 바꿈 |
| 훈련 오차 | 학습 데이터에 대한 오차로 모델이 훈련 표본에 맞춰진 정도를 보여줌 |
| 검증 오차 | 미사용 데이터에 대한 오차로 일반화 성능 판단의 기준이 됨 |
| 규제 | $L1$, $L2$, 드롭아웃으로 모델 자유도를 제한해 분산을 낮춤 |
| 조기 종료 | 검증 오차가 다시 커지기 전 학습을 멈춰 과적합을 줄임 |

```text
복잡도 증가:  낮음 -------- 적정 -------- 높음
훈련 오차:    높음 -------- 낮음 -------- 검증 오차보다 낮음
검증 오차:    높음 -------- 낮음 -------- 훈련 오차보다 높음
상태:         과소적합 ---- 균형 -------- 과적합
```

> 요약: 훈련 오차와 검증 오차의 절대값과 격차가 적합 상태를 구분하는 기준임.

## Ⅴ. 원리 및 절차 흐름도

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 학습 수행 | --> | 오차 비교 | --> | 상태 진단 | --> | 복잡도 조정 |
+-----------+     +-----------+     +-----------+     +-----------+
```

1. **학습 수행** — 데이터를 훈련·검증·테스트 세트로 나누고 모델 학습 과정을 기록함
2. **오차 비교** — 훈련 오차와 검증 오차의 절대값과 격차를 함께 확인함
3. **상태 진단** — 두 오차가 모두 높으면 과소적합, 격차가 크면 과적합, 모두 낮으면 균형 상태로 판단함
4. **복잡도 조정** — 모델 용량·규제 강도·데이터 양·학습 종료 시점을 조절해 검증 오차를 낮춤

> 요약: 모델 복잡도 조정은 훈련 성능이 아니라 검증 오차가 낮아지는 방향으로 판단함.

## Ⅵ. 실무 사례

1. 장애 티켓 분류는 교차 검증과 $L2$ 규제를 적용하고 Macro-F1의 평균·표준편차로 확인함
2. 이미지 분류 신경망은 조기 종료·드롭아웃을 적용하고 학습·검증 오차 격차로 과적합을 확인함

## Ⅶ. 결론

- 과적합과 과소적합 제어는 훈련 성능이 아니라 검증 성능의 안정성을 기준으로 모델 복잡도를 선택하는 문제임
