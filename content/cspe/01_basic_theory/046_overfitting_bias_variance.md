## 미리 알고가기

- 일반화($Generalization$): 학습에 쓰지 않은 데이터에서도 모델이 성능을 유지하는 능력임
- 편향($Bias$): 모델 가정이 단순하거나 잘못되어 평균 예측이 실제값에서 벗어나는 오차임
- 분산($Variance$): 학습 데이터가 조금 바뀔 때 모델 예측이 얼마나 흔들리는지 나타내는 오차임
- 모델 용량($Capacity$): 모델이 표현 가능한 함수의 복잡도 수준임
- 검증 곡선($Validation$ $Curve$): 모델 복잡도 변화에 따른 훈련·검증 성능 변화를 보는 그래프임

## Ⅰ. 개요

- **정의/개념**: 과적합은 모델이 훈련 데이터의 잡음까지 학습한 상태이고 과소적합은 기본 패턴도 학습하지 못한 상태이며, 편향-분산 트레이드오프는 두 오차를 균형화하는 기준임
- **배경/필요성**: 훈련 오차만 줄이면 실제 환경 성능이 나빠지므로 모델 복잡도와 일반화 성능을 함께 통제해야 함

## Ⅱ. 특징

- 과소적합은 모델 용량이 낮아 훈련 오차와 검증 오차가 모두 높게 나타남
- 과적합은 훈련 오차는 낮지만 검증 오차가 높아 두 오차 간 격차가 커짐
- 모델 복잡도가 증가하면 편향은 낮아지지만 분산이 커져 검증 성능이 다시 악화됨
- 최적 지점은 훈련 성능 최대가 아니라 검증 오차가 가장 낮고 안정적인 구간임

## Ⅲ. 종류 및 비교

| 기준 | 과소적합 | 적정 적합 | 과적합 |
|:---|:---|:---|:---|
| 모델 용량 | 낮음 | 데이터 복잡도와 균형 | 과도하게 높음 |
| 훈련 오차 | 높음 | 낮음 | 매우 낮음 |
| 검증 오차 | 높음 | 낮음 | 높음 |
| 주요 오차 | 고편향 | 편향·분산 균형 | 고분산 |
| 대응 | 특징 추가, 모델 확장 | 모니터링 유지 | 규제, 데이터 증강, 조기 종료 |

> 요약: 과소적합은 표현 부족, 과적합은 잡음 학습, 적정 적합은 검증 성능 균형으로 판단함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 모델 용량 | 파라미터 수, 깊이, 특징 수로 결정되며 편향과 분산을 동시에 바꿈 |
| 훈련 오차 | 학습 데이터에 대한 오차로 모델이 패턴을 얼마나 외웠는지 보여줌 |
| 검증 오차 | 미사용 데이터에 대한 오차로 일반화 성능 판단의 기준이 됨 |
| 규제 | $L1$, $L2$, 드롭아웃으로 모델 자유도를 제한해 분산을 낮춤 |
| 조기 종료 | 검증 오차가 다시 커지기 전 학습을 멈춰 과적합을 줄임 |

```text
복잡도 증가:  낮음 -------- 적정 -------- 높음
훈련 오차:    높음 -------- 낮음 -------- 매우 낮음
검증 오차:    높음 -------- 낮음 -------- 다시 높음
상태:         과소적합 ---- 균형 -------- 과적합
```

> 요약: 훈련 오차와 검증 오차의 절대값과 격차가 적합 상태를 구분하는 기준임.

## Ⅴ. 원리 및 절차 흐름도

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 학습 수행 | --> | 오차 비교 | --> | 상태 진단 | --> | 복잡도 조정 |
+-----------+     +-----------+     +-----------+     +-----------+
```

1. **학습 수행** — 데이터를 훈련, 검증, 테스트로 나누고 모델 학습 과정을 기록함
2. **오차 비교** — 훈련 오차와 검증 오차의 절대값과 격차를 함께 확인함
3. **상태 진단** — 둘 다 높으면 과소적합, 격차가 크면 과적합, 둘 다 낮으면 균형 상태로 판단함
4. **복잡도 조정** — 모델 용량, 규제 강도, 데이터 양, 학습 종료 시점을 조절해 검증 오차를 낮춤

> 요약: 모델 복잡도 조정은 훈련 성능이 아니라 검증 오차가 낮아지는 방향으로 판단함.

## Ⅵ. 실무 적용 및 유의점

1. 데이터가 적은 분류 모델에서는 과적합이 쉽게 발생하므로 교차 검증과 데이터 증강을 적용하고 검증 점수의 평균과 표준편차를 함께 확인함
2. 딥러닝 학습에서는 검증 오차가 상승하기 시작하면 조기 종료와 드롭아웃을 적용하고 최종 테스트 세트는 모델 선택 후 한 번만 사용함

## Ⅶ. 결론

- 과적합과 과소적합 제어는 훈련 성능이 아니라 검증 성능의 안정성을 기준으로 모델 복잡도를 선택하는 문제임

## 작성 근거(검토용)

- 세 개념을 따로 설명하지 않고 훈련 오차, 검증 오차, 모델 용량의 관계로 통합함
- 편향-분산 트레이드오프는 추상어가 되기 쉬워 검증 곡선과 오차 격차로 판단 기준을 구체화함
- 규제와 조기 종료는 과적합 대응의 대표 수단이라 구조와 실무 항목에 배치함
- 테스트 세트 재사용은 성능 과대평가를 만들 수 있어 실무 유의점에 포함함
- 결론은 일반화 성능 중심으로 회수해 앞 절의 검증 기준과 연결함
