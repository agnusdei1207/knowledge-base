## 미리 알고가기

- 편향: 모델 가정이 단순해서 생기는 체계적 오차임
- 분산: 학습 데이터 변화에 따라 예측이 흔들리는 정도임
- 일반화 오차: 보지 않은 데이터에서의 실제 오차임

## Ⅰ. 개요

- **정의/개념**: 과적합은 학습 데이터의 잡음까지 외워 일반화가 나빠진 상태이고, 과소적합은 모델이 너무 단순해 기본 패턴도 설명하지 못하는 상태이며, 둘의 균형을 편향-분산 trade-off로 설명함
- **배경/필요성**: 모델 복잡도를 무작정 높이거나 낮추면 예측 성능이 깨지므로, 일반화 성능을 기준으로 적절한 균형점을 찾아야 함

## Ⅱ. 특징

- 과적합은 학습 성능은 높지만 검증 성능이 낮음
- 과소적합은 학습과 검증 모두 성능이 낮음
- 복잡도 증가로 편향은 줄고 분산은 커지는 경향이 있음
- 정규화, 데이터 확대, 조기 종료가 균형 조절의 핵심 수단임

## Ⅲ. 종류 및 비교

| 판단 기준 | 과소적합 | 적정 적합 | 과적합 |
|:---|:---|:---|:---|
| 모델 복잡도 | 낮음 | 적절함 | 높음 |
| 학습 오차 | 높음 | 중간 | 매우 낮음 |
| 검증 오차 | 높음 | 낮음 | 다시 증가 |
| 원인 | 표현력 부족 | 균형 확보 | 잡음 학습 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 모델 복잡도 | 파라미터 수와 구조 깊이이며 편향/분산을 좌우함 |
| 학습 데이터 | 양과 품질이 중요하고 분산 감소에 기여함 |
| 정규화 장치 | L1/L2, dropout, pruning 등이며 과적합 억제 수단임 |
| 평가 지표 | train/val gap, learning curve이며 상태 진단 도구임 |

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 모델학습 | --> | 성능비교 | --> | 원인판단 | --> | 복잡도조정 |
+----------+     +----------+     +----------+     +----------+
```

1. **모델학습**: 학습셋으로 모델을 적합시킴
2. **성능비교**: 학습/검증 오차를 동시에 확인함
3. **원인판단**: 편향이 큰지 분산이 큰지 구분함
4. **복잡도조정**: 모델 구조와 규제를 조정함

## Ⅵ. 문제점 및 해결 방안

1. **데이터 부족으로 과적합이 심해짐**: 분산이 커짐
   - **해결 방안**: 데이터 증강, 교차검증, 사전학습을 활용하고 validation gap로 검증함
2. **모델이 너무 단순해 핵심 패턴을 놓침**: 성능 상한이 낮다
   - **해결 방안**: 특징 추가, 비선형 모델, 깊이 증가를 적용하고 train error로 검증함
3. **하이퍼파라미터 탐색이 불충분함**: 균형점 탐색에 실패함
   - **해결 방안**: learning curve와 정규화 세기를 체계적으로 조정하고 best CV score로 검증함

## Ⅶ. 적용 사례

- 딥러닝 학습: dropout과 early stopping으로 일반화를 높임, 확인 지표는 validation loss임
- 탭уляр 데이터 모델링: 트리 깊이와 leaf 수를 제한함, 확인 지표는 CV score임
- 추천 시스템: 희소 데이터에 정규화를 적용함, 확인 지표는 offline-online 성능 차이임

## Ⅷ. 결론

과적합과 과소적합의 핵심은 모델 복잡도보다 일반화 오차에 있으므로, 학습 점수가 아니라 검증 곡선으로 편향과 분산의 균형을 판단해야 함.
