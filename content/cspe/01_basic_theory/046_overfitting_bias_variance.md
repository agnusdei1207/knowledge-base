## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 모델의 복잡도에 따라 발생하는 예측 오차(편향/분산) 간 상충 관계 및 최적점 탐색 이론임 |
| 배경/필요성 | 학습 데이터에 치중하거나(과적합), 학습이 부족한(과소적합) 문제 해결 필요 |
| 출제 의도 | 모델 복잡도와 일반화 성능 간 관계 및 정규화(Regularization) 기반 모델 튜닝 역량 평가 |

## Ⅱ. 구성요소
```text
+----------------+       +----------------+       +----------------+
| Model Error    |       | Bias (Underfit)|       | Variance       |
| Minimization   | ----> | Trade-off      | <---- | (Overfitting)  |
+----------------+       +----------------+       +----------------+
```
| 편향 (Bias) | 예측값과 정답의 차이, 모델이 너무 단순해서 발생 | 고정관념 |
| 분산 (Variance) | 데이터 변동에 따른 예측값 흩어짐, 복잡성으로 발생 | 줏대 없음 |
| 트레이드오프 | 편향과 분산이 반비례하는 상충 관계 | 시소 게임 |
> 요약: 해당 이론은 편향과 분산 간의 상충 관계로 과소적합과 과적합 문제를 설명함

## Ⅲ. 절차
```text
+----------------+       +----------------+       +----------------+       +----------------+
| Error Decomp   |       | Complexity Set |       | Train & Val    |       | Sweet Spot     |
| (Bias/Var/Noise| ----> | (Param Tune)   | ----> | (Loss Monitor) | ----> | (Optimum Find) |
+----------------+       +----------------+       +----------------+       +----------------+
```
1. 오차 분해: 모델 예측 오차를 편향(Bias), 분산(Variance), 노이즈로 분해 분석
2. 복잡도 조절: 파라미터 수 및 정규화 계수 조절로 모델 복잡도(Capacity) 변경
3. 훈련 및 검증: 훈련 오차와 검증 오차의 추이를 지속 모니터링하며 학습
4. 최적점 탐색: 검증 오차가 최소화되는 편향-분산 타협점(Sweet Spot) 도출
> 요약: 오차를 분석하고 복잡도를 조절하여 검증 오차가 최소화되는 최적점을 탐색함

## Ⅳ. 문제점
- 과소적합 (High Bias): 모델이 단순하여 훈련 데이터의 기본 패턴조차 파악 불가
- 과적합 (High Variance): 모델이 복잡하여 노이즈까지 암기, 새로운 데이터 예측 실패
- 동시 감소 불가 문제: 모델 복잡도를 높이면 편향은 줄지만 분산이 필연적으로 증가함

## Ⅴ. 개선방안
- 단기 방안: 과소적합 시 더 복잡한 모델 적용 및 다항 특성(Feature) 추가
- 중기 방안: 과적합 방지를 위해 드롭아웃, 조기 종료, L1/L2 정규화 기법 적용
- 장기 방안: 앙상블 기법(Bagging, Boosting)을 활용하여 편향과 분산을 독립적으로 감소

## Ⅵ. 전망
- 파라미터가 극도로 많을 때 일반화 성능이 향상되는 이중 하강(Double Descent) 현상 연구가 활발함
