## 미리 알고가기

- 일반화($Generalization$): 훈련 과정에서 보지 못한 새로운 데이터에 대해 모델이 정확한 예측을 수행하는 능력임
- 편향($Bias$): 모델의 가정이 잘못되어 실제값과 예측값의 평균적인 차이가 크게 발생하는 체계적 오차임
- 분산($Variance$): 훈련 데이터의 작은 변동에 모델의 예측값이 민감하게 흔들리는 정도임
- 총 오차 ($Total$ $Error$): $Bias^2 + Variance + Irreducible$ $Error$(노이즈)의 합으로 구성됨

## Ⅰ. 개요

- **정의/개념**: 과적합(Overfitting)은 모델이 훈련 데이터의 잡음까지 학습하여 일반화 성능이 떨어진 상태이고, 과소적합(Underfitting)은 모델이 너무 단순해 데이터의 기본 패턴조차 파악하지 못한 상태이며, 이 둘 사이의 균형 관계를 '편향-분산 트레이드오프'라 함
- **배경/필요성**: 모델의 복잡도와 성능 사이에는 상충 관계가 존재하므로, 단순히 훈련 오차를 줄이는 것에 그치지 않고 새로운 데이터에 대한 예측력을 극대화할 수 있는 최적의 복잡도 지점을 찾아야 함

## Ⅱ. 특징

- 모델이 복잡해질수록 훈련 데이터에 대한 '편향'은 줄어들지만, 데이터의 미세한 변동에 민감하게 반응하여 '분산'이 커지는 경향을 보임
- 과적합 상태에서는 훈련 데이터에 대한 손실($Loss$)은 매우 낮으나 검증 데이터에 대한 손실이 다시 증가하는 'U자형' 오차 곡선이 나타남
- 과소적합 상태에서는 훈련과 검증 데이터 모두에서 높은 오차를 보이며, 이는 모델의 표현력($Capacity$)이 데이터의 복잡도를 감당하지 못함을 의미함

## Ⅲ. 종류 및 비교

| 판단 기준 | 과소적합 (Underfitting) | 적정 적합 (Good Fit) | 과적합 (Overfitting) |
|:---|:---|:---|:---|
| **모델 복잡도** | 매우 낮음 | 적절함 | 매우 높음 |
| **편향 (Bias)** | 높음 (High Bias) | 낮음 | 매우 낮음 |
| **분산 (Variance)** | 낮음 | 낮음 | 높음 (High Variance) |
| **주요 특징** | 패턴 학습 부족 | 일반화 능력 극대화 | 잡음(Noise)까지 학습 |
| **해결 전략** | 파라미터 추가, 복잡도 증대 | 현 상태 유지 및 미세 튜닝 | 규제 적용, 데이터 증강 |

> 요약: 과소적합은 '단순함'이 문제이고, 과적합은 '지나친 예민함'이 문제임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 모델 복잡도 | 파라미터의 수나 딥러닝의 층 수로 결정되며, 높을수록 분산이 커짐 |
| 훈련 곡선 ($Learning$ $Curve$) | 데이터 양에 따른 훈련/검증 오차 변화를 시각화하여 적합 상태를 진단함 |
| 규제 ($Regularization$) | $L1, L2$ 제약 등을 통해 모델의 가중치가 비대해지는 것을 막는 장치임 |
| 조기 종료 ($Early$ $Stopping$) | 검증 오차가 다시 커지기 직전의 시점에서 학습을 멈추는 기법임 |

```text
[ 오차 분해 수식 ]
Total Error = Bias² + Variance + Noise
- 편향(Bias)이 낮으면 정확도가 높음
- 분산(Variance)이 낮으면 정밀도(일관성)가 높음
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 모델 학습 수행| --> | 훈련/검증 오차비교| --> | 적합 상태 진단| --> | 복잡도/규제 조정|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **학습 모니터링** — 전체 데이터를 훈련/검증/테스트셋으로 나누고, 학습이 진행됨에 따라 각 세트의 손실값 변화를 실시간으로 관찰함
2. **오차 분석** — 훈련 오차는 낮으나 검증 오차가 높다면 '과적합(고분산)'으로, 둘 다 높다면 '과소적합(고편향)'으로 판단함
3. **하이퍼파라미터 튜닝** — 과적합 시에는 드롭아웃($Dropout$) 비율을 높이거나 규제 강도를 세게 하고, 과소적합 시에는 모델의 층을 깊게 하거나 특징($Feature$)을 추가함
4. **일반화 성능 확정** — 검증 오차가 최소가 되는 최적의 지점($Sweet$ $Spot$)에서 학습을 종료하고 최종 테스트셋으로 모델의 신뢰성을 검증함

## Ⅵ. 실무 적용 및 유의점

1. 데이터의 양이 절대적으로 부족한 경우 분산이 커져 과적합이 쉽게 발생하므로, '교차 검증($K-Fold$)'을 통해 평가의 안정성을 높이거나 '데이터 증강($Augmentation$)'으로 훈련 데이터의 다양성을 확보해야 함
2. 딥러닝 모델에서 과적합을 방지하기 위해 사용되는 $L2$ 규제(가중치 감쇠)는 가중치들의 제곱합을 손실 함수에 더해 특정 가중치가 너무 커지지 않게 제한하며, 이는 모델의 실질적인 자유도를 낮추는 효과가 있음

## Ⅶ. 결론

- 과적합과 과소적합의 제어는 기계 학습 모델의 성능을 결정짓는 핵심적인 엔지니어링 과정이며, 설계자는 편향-분산의 조화로운 균형점을 도출하여 복잡한 현실 데이터에서도 흔들림 없는 강건한 인공지능 시스템을 구축해야 함
