# 과적합·과소적합·편향-분산 트레이드오프 (Overfitting Bias-Variance Tradeoff)

## 1. 개요

- **정의/개념**: 과적합은 모델이 학습 데이터의 잡음까지 외워 일반화 성능이 떨어지는 현상이고, 과소적합은 모델이 데이터의 기본 패턴도 충분히 학습하지 못하는 현상이다.
- **배경/필요성**: 머신러닝 모델은 학습 성능보다 미지 데이터 성능이 중요하므로, 편향과 분산의 균형을 통해 일반화 오류를 관리해야 한다.

과적합과 과소적합은 모델 복잡도와 데이터 양, 정규화, 평가 절차가 함께 만든 결과이다.

## 2. 특징 및 비교

| 구분 | 과소적합 | 적정 적합 | 과적합 |
|---|---|---|---|
| 학습 오류 | 높음 | 낮음 | 매우 낮음 |
| 검증 오류 | 높음 | 낮음 | 높음 |
| 원인 | 모델 단순, feature 부족 | 복잡도 균형 | 모델 과복잡, 데이터 부족 |
| 대응 | 모델 복잡도 증가 | 유지·모니터링 | 정규화, 데이터 증가 |

판단 기준은 train/validation gap, 모델 복잡도, 데이터 규모, 노이즈, 정규화 강도이다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| Bias | 모델 가정이 만드는 구조적 오차 | 과소적합과 연결 |
| Variance | 학습 데이터 변화에 대한 민감도 | 과적합과 연결 |
| Model Complexity | 파라미터 수·깊이·규칙 수 | 균형 조정 |
| Regularization | 복잡도 제약 | L1, L2, dropout |
| Validation Curve | 학습·검증 성능 추세 | 진단 근거 |

```text
+----------+      +----------+      +----------+
| 복잡도낮음 | ---> | 균형점   | ---> | 복잡도높음 |
+----------+      +----------+      +----------+
 과소적합            일반화            과적합
```

편향을 줄이면 분산이 증가할 수 있고, 분산을 줄이면 편향이 증가할 수 있으므로 하나의 지표만으로 판단하지 않는다.

## 4. 문제점 및 개선방안

1. **학습 성능만 보고 판단**
   - 학습 정확도만 높으면 과적합을 놓칠 수 있다.
   - **개선방안**: validation/test 성능과 gap을 함께 본다.

2. **데이터 누수**
   - 검증 데이터 정보가 학습에 섞이면 일반화 성능이 과대평가된다.
   - **개선방안**: pipeline 분리, 교차 검증, 독립 test set을 운영한다.

3. **무조건 복잡도 증가**
   - 성능이 낮다고 모델을 키우기만 하면 노이즈 학습이 심해질 수 있다.
   - **개선방안**: feature 개선, 정규화, early stopping, 데이터 증강을 함께 적용한다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| 딥러닝 학습 | train/validation loss curve로 과적합 감지 | loss gap, early stop |
| 신용 평가 | 모델 복잡도와 규제 요구 해석성 균형 | AUC, 안정성 |
| 추천 모델 | 사용자 행동 노이즈에 대한 일반화 확인 | offline metric, online CTR |

## 6. 결론

과적합·과소적합은 모델의 일반화 성능을 설명하는 핵심 진단 개념이다. 편향-분산 트레이드오프는 학습 오류와 검증 오류를 함께 보며, 복잡도·데이터·정규화·평가 절차를 같은 축에서 조정해야 한다.
