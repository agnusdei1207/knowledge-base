## 미리 알고가기

- 일반화(Generalization): 학습에 쓰지 않은 데이터에서도 모델이 성능을 유지하는 능력임
- 편향(Bias): 모델 가정이 단순하거나 잘못되어 평균 예측이 실제값에서 벗어나는 오차임
- 분산(Variance): 학습 데이터가 조금 바뀔 때 모델 예측이 얼마나 변동하는지 나타내는 오차임
- 모델 용량(Capacity): 모델이 표현 가능한 함수의 복잡도 수준임
- 검증 곡선(Validation Curve): 모델 복잡도 변화에 따른 훈련·검증 성능 변화를 보는 그래프임
- 가중치 규제(Weight Regularization): 손실에 가중치 크기 벌점을 추가해 모델 복잡도를 제한하는 방식임
- 조기 종료(Early Stopping): 검증 오차가 악화되면 학습을 중단해 과적합을 줄이는 방식임

## 작성 근거(검토용)

- **방향성**: 과적합·과소적합·편향-분산 트레이드오프는 모델 복잡도가 커질수록 편향은 줄고 분산은 커지는 상충 관계이므로, 훈련 오차가 아니라 검증 오차가 최소인 지점을 기준으로 복잡도와 규제 강도를 결정해야 함
- **개요 구성**: 세 개념을 따로 설명하지 않고 오차 패턴·편향과 분산·개선 방향의 관계로 통합함
- **Ⅱ·Ⅳ. 특징·구조 선정**: 편향-분산 트레이드오프는 추상어가 되기 쉬워 검증 곡선과 오차 격차로 판단 기준을 구체화함
- **Ⅲ. 비교축 선정**: 훈련·검증 오차, 편향·분산 상태, 개선 방향으로 과소적합·적정 적합·과적합의 판단 기준을 구분함. 세 상태는 상호 배타적 기술 선택이 아니라 복잡도 연속선상의 진단 분류라 적용 기준 축을 강제하지 않고, 개선 방향 축으로 상태별 조치를 대신함
- **Ⅴ절 생략 근거**: 트레이드오프의 핵심은 반복 절차가 아니라 복잡도별 오차 상태 비교이므로 검증 곡선을 Ⅳ 구조에 포함하고 별도 절차 절을 두지 않음
- **Ⅵ. 사례 선정**: 규제와 조기 종료는 과적합 대응의 대표 수단이라 사례에 배치함
- **Ⅶ. 결론 선정**: 결론은 일반화 성능 중심으로 정리해 앞 절의 검증 기준과 연결함
- **전수 검수**: 제목부터 결론까지 용어·표·도식·요약을 대조하고 편향·분산 정의와 절 간 판단축을 일치시킴

## Ⅰ. 개요

- **정의/개념**: 과적합은 잡음까지 학습하고 과소적합은 패턴도 못 배운 상태이며 트레이드오프는 균형 기준임
- **배경/필요성**: 실제 환경의 일반화 성능을 확보하기 위해 모델 복잡도에 따른 검증 오차를 판단해야 함

### 쉽게 이해하기 (학습용)
- 새 옷을 만들 때 몸의 흉터까지 그대로 본떠 재단하면 다른 몸에는 안 맞고(과적합), 대충 재서 만들면 그 몸에도 안 맞으며(과소적합), 그 사이 딱 맞는 재단선을 찾는 것과 같음

## Ⅱ. 특징

- 과소적합은 모델 용량이 낮아 훈련 오차와 검증 오차가 모두 높게 나타남
- 과적합은 훈련 오차는 낮지만 검증 오차가 높아 두 오차 간 격차가 커짐
- 모델 복잡도가 증가하면 편향은 낮아지지만 분산이 커져 검증 성능이 다시 악화됨
- 모델 복잡도는 훈련 성능이 아니라 검증 오차가 최소인 구간을 기준으로 선택함

### 쉽게 이해하기 (학습용)
- 재단이 대충이면 이 몸도 저 몸도 안 맞고, 너무 정교하게 뜨면 이 몸엔 완벽해도 다른 몸엔 전혀 안 맞아 격차가 커지며, 정교함을 높일수록 이 몸에 맞는 정도(편향)는 좋아져도 다른 몸과의 격차(분산)는 점점 벌어짐

## Ⅲ. 종류 및 비교

| 판단 기준 | 과소적합 | 적정 적합 | 과적합 |
|:---|:---|:---|:---|
| 훈련·검증 오차 | 모두 높음 | 모두 낮음 | 훈련 오차는 낮고 검증 오차는 높음 |
| 편향·분산 상태 | 고편향·저분산 | 편향·분산 균형 | 저편향·고분산 |
| 개선 방향 | 모델 용량·특징 표현 확대 | 검증 성능 기준 유지 | 규제·데이터 확대·조기 종료 |

> 요약: 두 오차가 모두 높으면 과소적합, 격차가 크면 과적합, 최소이면 적정 적합임.

### 쉽게 이해하기 (학습용)
- 헐렁한 옷, 딱 맞는 옷, 그 사람 몸에만 맞춰 다른 사람은 절대 못 입는 옷, 이 세 가지 재단 상태를 놓고 비교하는 것과 같음

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 모델 용량 | 표현 가능한 함수 복잡도 |
| 훈련 오차 | 학습 데이터의 정답과 모델 예측값 간 차이 |
| 검증 오차 | 학습에 사용하지 않은 데이터의 정답과 모델 예측값 간 차이 |
| 편향 | 단순 가정의 체계적 오차 |
| 분산 | 데이터 변화에 따른 예측 변동 |

검증 곡선은 모델 용량 변화에 따른 훈련·검증 오차 추이를 다음과 같이 나타냄.

```text
복잡도 증가:  낮음 -------- 적정 -------- 높음
훈련 오차:    높음 -------- 낮음 -------- 검증 오차보다 낮음
검증 오차:    높음 -------- 낮음 -------- 훈련 오차보다 높음
상태:         과소적합 ---- 균형 -------- 과적합
```

> 요약: 편향-분산 트레이드오프는 모델 용량별 훈련·검증 오차로 적정 복잡도를 선택함.

### 쉽게 이해하기 (학습용)
- 재단 도구의 정교함(모델 용량)에 따라 첫 손님의 만족도(훈련 오차)와 새 손님의 만족도(검증 오차)가 다르게 나오는 것을 표로 정리한 것과 같음

## Ⅵ. 실무 사례

1. 장애 티켓 분류기는 가중치 규제로 훈련 데이터에만 맞는 복잡한 경계를 줄임
2. 이미지 분류 신경망은 검증 오차가 다시 커지기 시작하면 학습을 중단함

### 쉽게 이해하기 (학습용)
- 재단선을 너무 세밀하게 그리지 않도록 자를 무디게 쓰거나, 새 손님의 만족도가 떨어지기 시작하면 재단 작업을 바로 멈추는 것과 같음

## Ⅶ. 결론

- 과적합·과소적합 제어는 훈련 성능이 아닌 검증 안정성 기준으로 복잡도를 선택하는 문제임
- 훈련 오차만 낮으면 규제·데이터로 과적합을 줄이고, 훈련·검증 오차가 모두 높으면 특징과 모델 용량을 보강해야 함

### 쉽게 이해하기 (학습용)
- 첫 손님 반응만 보고 옷을 계속 고치지 말고 새 손님 반응으로 재단을 조정하되, 새 손님도 다 안 맞으면 아예 재단 방식을 바꿔야 함
