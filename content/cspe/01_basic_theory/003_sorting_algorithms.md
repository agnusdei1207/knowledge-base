## 미리 알고가기

- 안정 정렬(Stable Sort): 동일 키 원소의 입력 순서가 정렬 후에도 유지되는 성질임
- 제자리 정렬(In-place Sort): 입력 배열 외 대규모 보조 메모리를 쓰지 않는 성질임
- 피벗(Pivot): 퀵 정렬에서 작은 값과 큰 값을 나누는 기준 원소임
- 힙(Heap): 부모 키가 자식 키보다 크거나 작은 완전 이진 트리형 우선순위 구조임
- 외부 정렬: 메모리에 한 번에 올리지 못하는 데이터를 디스크 블록 단위로 정렬·병합하는 방식임

## Ⅰ. 개요

- **정의/개념**: 정렬 알고리즘은 원소를 키 기준 순서로 재배열해 탐색·병합·집계 같은 후속 연산의 기준 순서를 만드는 알고리즘 군임
- **배경/필요성**: 입력 조건별 지연과 결과 안정성을 확보하기 위해 정렬 방식 선택 기준이 필요함

## Ⅱ. 특징

- 비교 기반 정렬은 키 비교만으로 순서를 정하며 대규모 정렬은 보통 $O(n \log n)$을 목표로 함
- 안정 정렬은 동일 키의 입력 순서를 보존해 다중 키 정렬 결과를 예측 가능하게 함
- 제자리 정렬은 보조 공간을 줄이지만 데이터 이동과 최악 시간 조건을 함께 봐야 함
- 입력의 초기 순서와 피벗 편향은 같은 알고리즘의 실제 지연을 크게 바꿈

## Ⅲ. 종류 및 비교

| 판단 기준 | 퀵 정렬 (Quick) | 병합 정렬 (Merge) | 힙 정렬 (Heap) | 버블 정렬 (Bubble) |
|:---|:---|:---|:---|:---|
| **처리 방식** | 피벗 기준 분할 | 반분할 후 병합 | 힙 구성 후 루트 추출 | 인접 원소 교환 |
| **평균 시간** | $O(n \log n)$ | $O(n \log n)$ | $O(n \log n)$ | $O(n^2)$ |
| **최악 시간** | $O(n^2)$ | $O(n \log n)$ | $O(n \log n)$ | $O(n^2)$ |
| **안정성** | 불안정 ($Unstable$) | 안정 ($Stable$) | 불안정 ($Unstable$) | 안정 ($Stable$) |
| **보조 공간** | 평균 $O(\log n)$ 스택 | $O(n)$ 배열 | $O(1)$ 제자리 | $O(1)$ 제자리 |
| **적합 조건** | 평균 처리량 중시 | 안정성·외부 정렬 | 메모리 제약 | 소규모 확인용 |

> 요약: 퀵은 평균 처리, 병합은 안정성, 힙은 공간 제약, 버블은 소규모 확인에 맞음.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 비교 함수 | 키·정렬 방향·다중 키 우선순위를 정해 모든 원소의 상대 순서를 판단함 |
| 분할·선택 구조 | 피벗·중간점·힙처럼 다음 처리 범위를 줄이는 기준을 제공함 |
| 이동 연산 | 스왑($Swap$)·복사·병합으로 원소 위치를 바꾸며 실제 메모리 비용을 만듦 |
| 임시 저장소 | 재귀 스택이나 보조 배열로 중간 상태를 보관해 안정성·공간 비용에 영향을 줌 |
| 종료 조건 | 더 나눌 구간이 없거나 힙이 비면 정렬 완료를 판단함 |

```text
[ 정렬 처리 구조 ]
+----------+      +----------+      +----------+      +----------+
| 입력 원소 | ---> | 키 비교  | ---> | 이동/병합 | ---> | 정렬 결과 |
+----------+      +----------+      +----------+      +----------+
                       |
                       v
                 안정성·공간 제약
```

> 요약: 정렬은 비교 기준과 이동 방식이 안정성·공간 비용을 결정함.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 기준 설정 | --> | 비교/분할 | --> | 위치 확정 | --> | 결과 반환 |
+----------+     +----------+     +----------+     +----------+
```

1. **기준 설정**: 정렬 키, 방향, 안정성, 메모리 제약을 정함
2. **범위 축소**: 퀵은 피벗, 병합은 중간점, 힙은 루트 기준으로 처리 범위를 줄임
3. **위치 확정**: 스왑·병합·루트 추출로 일부 원소의 최종 위치를 고정함
4. **완료 검증**: 모든 구간과 힙이 정렬 조건을 만족하는지 확인함

> 요약: 정렬 절차는 기준 설정, 범위 축소, 위치 확정, 완료 검증으로 수렴함.

## Ⅵ. 실무 적용 및 유의점

1. 대용량 인메모리 배열은 퀵 정렬을 쓰되 피벗 편향을 랜덤화로 줄이고 재귀 깊이·p95 지연을 확인함
2. 다중 키 정렬은 안정성이 깨지면 결과 순서가 바뀌므로 병합 정렬을 우선 검토하고 최대 메모리로 검증함

## Ⅶ. 결론

- 정렬은 입력 분포·안정성·보조 공간·최악 시간을 함께 보아 선택하며, 단순 교환형은 소규모 검증용에 한정함

## 작성 근거(검토용)

- **개요 구성**: 정렬 결과가 후속 연산의 기준 순서가 된다는 점을 넣어 단순 재배열 설명을 피함
- **특징 선정**: 비교 기반 한계, 안정성, 보조 공간, 입력 분포가 알고리즘 선택을 직접 바꿈
- **Ⅲ 비교축**: 처리 방식·평균/최악 시간·안정성·보조 공간이 네 정렬의 선택 기준을 가름
- **버블 정렬 위치**: 비교 대상에는 포함하되 대규모 실무 적용성은 낮아 소규모 확인용으로 제한함
- **실무 유의점**: 피벗 랜덤화와 안정 정렬 선택은 성능·결과 순서·메모리 검증을 연결함
