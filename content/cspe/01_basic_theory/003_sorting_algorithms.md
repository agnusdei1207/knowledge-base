## 미리 알고가기

- 안정 정렬(Stable Sort): 동일 키 원소의 입력 순서가 정렬 후에도 유지되는 성질임
- 제자리 정렬(In-place Sort): 입력 배열 외 대규모 보조 메모리를 쓰지 않는 성질임
- 피벗(Pivot): 퀵 정렬에서 기준값으로 삼아 데이터를 좌우로 분할하는 원소임
- 힙(Heap): 부모 노드의 키가 자식보다 크거나 작은 완전 이진 트리 기반의 자료구조임

## Ⅰ. 개요

- **정의/개념**: 정렬은 원소를 키 기준 순서로 재배열해 탐색·병합·집계 비용을 낮추는 알고리즘 군임
- **배경/필요성**: 정렬되지 않은 데이터는 이진 탐색과 순차 병합이 어려우므로 입력 규모·안정성·메모리 제약별 알고리즘 선택이 필요함

## Ⅱ. 특징

- 비교 기반 정렬은 보통 $O(n \log n)$ 수준을 목표로 함
- 단순 교환형은 중첩 비교로 $O(n^2)$까지 커질 수 있음
- 동일 키 순서 보존 여부에 따라 안정·불안정 정렬이 나뉨
- 초기 정렬 상태와 피벗 편향이 실제 수행 시간을 좌우함

## Ⅲ. 종류 및 비교

| 판단 기준 | 퀵 정렬 (Quick) | 병합 정렬 (Merge) | 힙 정렬 (Heap) | 버블 정렬 (Bubble) |
|:---|:---|:---|:---|:---|
| **처리 방식** | 피벗 기준 분할 | 반분할 후 병합 | 힙 구성 후 루트 추출 | 인접 원소 교환 |
| **평균 시간** | $O(n \log n)$ | $O(n \log n)$ | $O(n \log n)$ | $O(n^2)$ |
| **최악 시간** | $O(n^2)$ | $O(n \log n)$ | $O(n \log n)$ | $O(n^2)$ |
| **안정성** | 불안정 ($Unstable$) | 안정 ($Stable$) | 불안정 ($Unstable$) | 안정 ($Stable$) |
| **보조 공간** | 평균 $O(\log n)$ 스택 | $O(n)$ 배열 | $O(1)$ 제자리 | $O(1)$ 제자리 |
| **적합 조건** | 평균 처리량 중시 | 안정성·외부 정렬 | 메모리 제약 | 소규모 확인용 |

> 요약: 퀵은 평균 처리, 병합은 안정성, 힙은 공간 제약, 버블은 소규모 확인에 맞음.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 비교 함수 | 키·정렬 방향·다중 키 우선순위를 정의함 |
| 분할/선택 구조 | 피벗·중간점·힙으로 처리 범위를 나눔 |
| 교환/이동 연산 | 원소를 스왑($Swap$)하거나 보조 배열에 복사함 |
| 임시 저장소 | 재귀 스택·보조 배열로 중간 상태를 유지함 |
| 안정성 조건 | 동일 키의 기존 순서를 보존할지 결정함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 기준 설정 | --> | 비교/분할 | --> | 위치 확정 | --> | 결과 반환 |
+----------+     +----------+     +----------+     +----------+
```

1. **기준 설정**: 키, 방향, 안정성, 메모리 제약을 정함
2. **비교/분할**: 퀵은 피벗, 병합은 중간점, 힙은 루트 기준으로 처리함
3. **위치 확정**: 스왑·병합·루트 추출로 부분 순서를 고정함
4. **결과 반환**: 모든 구간이 확정되면 키 기준 결과를 반환함

## Ⅵ. 실무 적용 및 유의점

1. 대용량 배열은 퀵 정렬을 쓰되 피벗을 랜덤화하고 재귀 깊이·p95 지연을 확인함
2. 다중 키는 병합 정렬로 순서를 보존하고, 메모리 제한은 힙 정렬과 최대 메모리로 대응함

## Ⅶ. 결론

- 정렬은 입력 분포·안정성·보조 공간·최악 시간을 기준으로 선택하고, 버블은 소규모 확인용에 한정함

## 작성 근거(검토용)

- **개요 구성**: 정렬을 탐색·병합·집계 전처리로 설명해 단순 순서 변경 이상의 필요성을 보임
- **특징 선정**: 시간 차수, 안정성, 입력 상태, 피벗 편향은 정렬 선택을 실제로 바꾸는 요소라 남김
- **Ⅲ 비교축**: 처리 방식·평균/최악 시간·안정성·보조 공간이 네 알고리즘의 선택 기준을 가름
- **버블 정렬 위치**: 시험 범위 비교 대상이지만 실무 적용성은 낮아 소규모 확인용으로 제한함
- **실무 유의점**: 피벗 랜덤화와 병합/힙 선택은 성능·안정성·메모리 제약을 운영 지표로 연결함
