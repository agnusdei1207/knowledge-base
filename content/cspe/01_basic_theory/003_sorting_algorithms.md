## Ⅰ. 개요
- 데이터를 특정 순서(오름차순, 내림차순)로 재배열하는 기법임.
- 효율적인 탐색과 데이터 처리를 위한 필수적인 전처리 과정임.
- [표] 출제 의도: 상황별 최적 정렬 알고리즘 선택 및 구현 능력 검증.

## Ⅱ. 구성요소
- ASCII 구조도
  [ Quick: Pivot ] -> [ Merge: Divide ] -> [ Heap: Tree ]

| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| Pivot | 퀵 정렬에서 분할의 기준이 되는 값 | 반장 선출 |
| Divide | 문제를 작은 단위로 쪼개는 과정 | 업무 분담 |
| Heap Tree | 힙 정렬에 사용되는 완전 이진 트리 | 서열 정리 |

> 요약: 방식에 따라 시간복잡도와 안정성(Stability)이 결정됨.

## Ⅲ. 절차
- ASCII 흐름도
  Input -> Choose Method -> Sorting -> Sorted Data

1. 데이터의 크기와 정렬 상태를 파악하여 방식 선정함.
2. 선택된 기법(퀵, 병합 등)에 따라 분할 또는 비교 수행함.
3. 정렬된 서브 리스트를 합치거나 전체 구조를 유지함.
4. 최종 정렬 여부를 검토하고 결과 리스트를 반환함.

> 요약: 정렬 전략에 따라 연산의 흐름과 메모리 사용 방식이 달라짐.

## Ⅳ. 문제점
- Quick 정렬은 Pivot 선정 실패 시 O(n^2)으로 성능이 저하됨.
- Merge 정렬은 병합 과정에서 추가적인 메모리 공간이 필요함.

## Ⅴ. 개선방안
- 단기: 데이터 특성에 맞춰 힙 정렬 등 안정적 복잡도 기법 적용함.
- 중기: Pivot 선택 시 중앙값(Median) 기법 도입으로 성능 방어함.
- 장기: Tim Sort와 같은 하이브리드 정렬 도입으로 평균 성능 극대화함.

## Ⅵ. 전망
- NVMe SSD와 같은 고속 저장장치의 특성을 반영한 캐시 망각(Cache-oblivious) 정렬 알고리즘이 대규모 데이터베이스 엔진의 핵심 성능 요소가 될 것임.
- GPU의 수만 개 스레드를 활용한 병렬 정렬(Bitonic Sort 등)이 데이터 분석 가속기의 CSF로 작용하며 실시간 빅데이터 처리를 주도할 전망임.
- 데이터의 분포 특성을 스스로 학습하여 정렬 방식을 결정하는 Learned Sorting 기법이 인공지능 인프라와 결합하여 효율성을 극대화할 것임.
