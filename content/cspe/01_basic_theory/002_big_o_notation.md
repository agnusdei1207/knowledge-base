## Ⅰ. 개요
- **정의**: 입력 크기 `n`이 충분히 클 때 함수의 증가율 상한·하한·정확한 차수를 표현하는 수학적 표기법
- **배경/필요성**: 복잡도 함수(001 참조)의 상수·저차항을 제거하여 알고리즘 간 증가율을 일관되게 비교할 수단이 필요함
- **비유**: 자동차 속도를 "시속 약 100km급"으로 묶어 표현하듯, 세부 계수를 버리고 증가 추세만 비교하는 것임

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 표기법 3종 구분 능력 | O=상한, Omega=하한, Theta=상한+하한 동시 | O(n)과 Theta(n) 혼용 금지, 각 의미 구분 |

> 요약: 알고리즘 복잡도의 증가율을 상한·하한·정확한 차수로 분류하여 비교하는 표기 체계임

## Ⅱ. 구성요소
```text
                  +--- O(g(n))  --- 상한 (최악 이하)
                  |
  점근적 표기법 ---+--- Omega(g(n)) --- 하한 (최선 이상)
                  |
                  +--- Theta(g(n)) --- 상한+하한 동시 (정확한 차수)
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| Big-O `O(g(n))` | `T(n) <= c * g(n)` (n >= n0)을 만족하는 상한 함수 | 택배 도착 보장 시간(최대 3일) |
| Big-Omega `Omega(g(n))` | `T(n) >= c * g(n)` (n >= n0)을 만족하는 하한 함수 | 최소 소요 시간(최소 1일) |
| Big-Theta `Theta(g(n))` | 상한과 하한이 같은 차수로 일치하는 정확한 증가율 | 평균 배송 기간(1~3일 범위 확정) |
| 증가율 계층 | `O(1) < O(log n) < O(n) < O(n log n) < O(n^2) < O(2^n)` 순서 | 걷기 < 자전거 < 자동차 < 비행기 순 속도 등급 |

> 요약: 세 표기법은 함수 증가율의 상한·하한·정확한 범위를 각각 수학적으로 한정함

## Ⅲ. 절차
```text
  복잡도 함수 도출    최고차항 추출      계수 제거         표기법 선택
  (T(n) 산출)       (지배항 식별)     (상수 c 분리)     (O/Omega/Theta)
   |                 |                 |                 |
   +----산출-------->+----추출-------->+----제거-------->+
  루프/재귀 분석    n^2+3n -> n^2     3n^2 -> n^2      분석 목적에 부합
```
- 1단계: 복잡도 함수 `T(n)`을 산출함 — 기본 연산 횟수를 `n`의 다항식·지수 등으로 표현(001 참조)
- 2단계: 최고차항을 추출함 — `3n^2 + 5n + 7`에서 지배항 `n^2`를 식별
- 3단계: 계수를 제거함 — 상수 `c`를 분리하여 `3n^2`를 `n^2`로 단순화
- 4단계: 표기법을 선택함 — 상한 분석이면 `O(n^2)`, 하한이면 `Omega(n^2)`, 양쪽 일치 시 `Theta(n^2)`

> 요약: T(n) 산출 → 최고차항 추출 → 계수 제거 → 목적에 맞는 표기법 선택 순으로 적용함

## Ⅳ. 문제점
- 상한 남용: 모든 분석에 Big-O만 사용하면 하한 정보가 누락되어 알고리즘의 최선 성능을 평가하지 못함
- 소규모 입력 부정확: `n`이 작을 때 저차항·상수의 영향이 커서 점근 표기가 실제 성능을 반영하지 못함
- 동일 차수 내 구분 불가: 같은 `O(n log n)`이라도 상수 계수 차이로 실행 시간이 수 배 차이 날 수 있음

> 요약: 점근 표기의 추상화 수준이 높아 세밀한 성능 차이를 포착하지 못하는 한계가 있음

## Ⅴ. 개선방안
1. 단기: O·Omega·Theta를 목적에 맞게 구분하여 상한 남용을 방지함
2. 중기: 소규모 입력 구간에서는 상수 포함 실측 비교를 병행하여 점근 표기의 한계를 보완함
3. 장기: 동일 차수 알고리즘 간 상수 계수·캐시 효율까지 포함한 정밀 비교 모델을 적용함

> 요약: 표기법 구분 사용, 실측 병행, 정밀 비교 모델 적용으로 점근 분석의 실효성을 높임

## Ⅵ. 전망
- 발전 방향: 메모리 계층·병렬 처리를 반영한 다차원 복잡도 표기로 확장됨
- 기술사적 판단: 알고리즘 선택·설계 근거의 공용어이므로 정확한 사용이 기술적 소통의 기반임
- 기술사 제언: 점근 표기와 실측 데이터를 함께 제시하여 이론-실무 간 격차를 줄일 필요
