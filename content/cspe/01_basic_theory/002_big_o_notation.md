## 미리 알고가기

- 점근 분석: 입력 $n$이 충분히 커졌을 때 비용 증가율만 비교하는 방법임
- 상한(Upper Bound): 비용 함수가 기준 함수의 상수배 아래에 묶이는 한계임
- 기준점 $n_0$: 상한 관계가 성립하기 시작하는 입력 크기임
- 지배항: 큰 입력에서 비용 증가율을 결정하는 항임
- 비용 함수 $T(n)$·점근 상한 함수 $f(n)$: 실제 비용과 증가율 상한을 각각 나타내는 함수임
- 상수 $c$: $n_0$ 이후 비용 함수를 기준 함수의 상수배로 묶는 양수임
- 빅세타·빅오메가: $\Theta$는 점근적 정확 차수, $\Omega$는 점근 하한을 나타냄

## 작성 근거(검토용)

- **개요 구성**: $T(n)$, $f(n)$, 상수배 상한을 모두 넣어 빅오를 단순 지배항 표기가 아니라 상한 관계로 정의함
- **특징 선정**: 지배항, $n_0$, 후보 선별, 같은 차수 한계가 빅오 사용 시 필요한 판단 근거임
- **동일 차수 문장**: 빅오만으로 선택하면 구현 상수와 I/O 병목을 놓치므로 프로파일링 검증을 연결함
- **Ⅲ. 비교축 선정**: 상한·점근적 정확 차수·하한의 목적 차이가 표기 선택을 가르므로 비교표로 압축함
- 후보 선별과 동일 차수 비교 사례는 점근 상한과 실제 지연 검증의 연결을 보여줌

## Ⅰ. 개요

- **정의/개념**: 빅오 표기법은 입력 크기 증가 시 비용 함수 $T(n)$이 기준 함수 $f(n)$의 상수배 상한 안에 머무름을 $O(f(n))$으로 표현하는 점근 표기임
- **배경/필요성**: 입력 증가에 따른 자원 상한을 판단하기 위해 하드웨어·언어와 무관한 점근 증가율 기준이 필요함

## Ⅱ. 특징

- 하위 항과 상수 계수를 제거해 큰 입력에서 남는 증가 차수를 비교함
- $n_0$ 이후 $T(n) \le c \cdot f(n)$ 관계가 성립해야 상한으로 인정됨
- 분석 대상 비용의 점근 상한으로 입력 규모에 맞지 않는 후보를 먼저 제외함
- 같은 빅오 차수라도 캐시·I/O·구현 상수에 따라 실제 지연이 달라짐

## Ⅲ. 종류 및 비교

| 판단 기준 | 빅오 ($O$) | 빅세타 ($\Theta$) | 빅오메가 ($\Omega$) |
|:---|:---|:---|:---|
| **표현 의미** | 점근 상한 | 점근적 정확 차수 | 점근 하한 |
| **성립 조건** | $n \ge n_0$에서 $T(n) \le c \cdot f(n)$ | $n \ge n_0$에서 $c_1 \cdot f(n) \le T(n) \le c_2 \cdot f(n)$ | $n \ge n_0$에서 $T(n) \ge c \cdot f(n)$ |
| **주요 활용** | 자원 증가 상한 판단 | 알고리즘 증가율 비교 | 계산 복잡도 하한 증명 |

> 요약: 빅오는 점근 상한, 빅세타는 점근적 정확 차수, 빅오메가는 점근 하한을 표현함.

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 비용 함수 $T(n)$ | 입력 크기별 실제 자원 비용 함수 |
| 기준 함수 $f(n)$ | 점근 상한과 비교할 기준 차수 |
| 상수 $c$ | 기준 함수를 비용 상한으로 만드는 배율 |
| 기준점 $n_0$ | 점근 상한 관계가 시작되는 입력값 |

```text
[ 빅오 성립 관계 ]
비용
 ^
 |          / c * f(n)  상한선
 |         /
 |        /  T(n)      실제 비용
 |       /
 +------|--------------> 입력 n
        n0
```

> 요약: 빅오는 $n_0$ 이후 $T(n) \le c \cdot f(n)$ 관계로 비용 함수의 점근 상한을 표현함.

## Ⅴ. 원리 및 절차 흐름도

```text
비용 함수 도출 → 지배항 선택
                       ↓
$n_0$ 이후 상한 확인 → 계수·낮은 차수 흡수 → $O(f(n))$ 표기
```

1. **비용 도출**: 반복문·재귀·자료구조 접근을 $T(n)$으로 계산함
2. **지배항 선택**: 큰 입력에서 비용 증가를 결정하는 항만 남김
3. **상수 흡수**: 차수와 무관한 계수는 상수 $c$로 흡수하고 작은 입력은 $n_0$ 이전 예외로 둠
4. **상한 표기**: 기준 함수를 정해 $O(f(n))$으로 자원 상한을 표시함

> 요약: 비용 함수에서 지배항을 고르고 계수를 상수로 흡수해 상한을 표기함.

## Ⅵ. 실무 사례

1. API 게이트웨이는 라우팅 규칙 증가에 따른 선형 검색·트라이 검색의 지연 증가율과 메모리 사용량을 비교해 조회 구조를 선택함

## Ⅶ. 결론

- 빅오는 자원 증가 상한을 비교하는 표기이며, 최종 선택은 차수·구현 상수·입력 분포를 함께 보아야 함
