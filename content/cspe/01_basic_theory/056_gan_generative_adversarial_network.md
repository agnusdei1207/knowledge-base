## Ⅰ. 개요
- 정의: 생성자와 판별자가 서로 경쟁하며 가짜 데이터를 진짜처럼 정교하게 만드는 신경망임
- 배경: 고품질의 합성 데이터 생성 및 창의적 AI 응용 분야 확대
- 출제 의도:
| 구분 | 내용 |
| --- | --- |
| 핵심 | 생성자(Generator), 판별자(Discriminator), 게임 이론 |

## Ⅱ. 구성요소
- ASCII 구조도
  [Noise] -> [G] -> [Fake] --\
                             [D] -> [Real/Fake]
             [Real] ---------/
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 생성자(G) | 노이즈로부터 가짜 데이터를 정교하게 만듦 | 위조지폐범 |
| 판별자(D) | 입력된 데이터가 진짜인지 가짜인지 구별함 | 경찰 |
| 손실 함수 | 서로의 목적이 반대인 Minimax Loss 사용 | 대결 |
> 요약: 두 네트워크의 적대적 경쟁을 통해 데이터 분포를 학습함

## Ⅲ. 절차
- ASCII 흐름도
  [G데이터생성] -> [D판별수행] -> [D가중치학습] -> [G가중치학습]
- 4단계 설명
1. 가짜 생성: 생성자가 임의의 노이즈를 입력받아 샘플 만듦
2. 판별 수행: 판별자가 실제 데이터와 가짜를 번갈아 평가함
3. 판별자 학습: 진짜는 진짜로, 가짜는 가짜로 구분토록 훈련함
4. 생성자 학습: 판별자가 가짜를 진짜로 착각하도록 훈련함
> 요약: 생성자는 더 정교하게, 판별자는 더 날카롭게 발전함

## Ⅳ. 문제점
- 학습이 불안정하여 한쪽으로 쏠리는 모드 붕괴(Mode Collapse) 발생함
- 생성자와 판별자 사이의 학습 균형을 맞추기 극도로 어려움

## Ⅴ. 개선방안
- (단기) Wasserstein GAN(WGAN) 등 손실 함수 개선 기법 적용함
- (중기) 스타일 전이(StyleGAN) 등 구조 고도화로 해상도 증대함
- (장기) Diffusion 모델 등 최신 생성 알고리즘과 장단점 비교 활용함

## Ⅵ. 전망
- 딥페이크 방지, 의료 데이터 증강 등 생성 AI 시장의 주축임
