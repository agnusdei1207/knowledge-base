## 미리 알고가기

- 루트(Root): 현재 방문 또는 분기의 기준이 되는 노드임
- 서브트리(Subtree): 전체 트리의 일부분을 형성하는 하위 트리 구조임
- 재귀 호출(Recursion): 하나의 문제를 동일한 구조의 작은 하위 문제로 나누어 해결하는 방식임
- 방문(Visit): 노드에 접근하여 출력, 데이터 갱신, 삭제 등의 실질적인 연산을 수행하는 행위임

## Ⅰ. 개요

- **정의/개념**: 이진트리 순회는 트리의 모든 노드를 중복 없이 한 번씩 방문하는 체계적인 절차이며, 기준 노드(Root)를 방문하는 시점에 따라 전위, 중위, 후위 순회로 구분함
- **배경/필요성**: 비선형 자료구조인 트리는 선형 데이터와 달리 방문 순서에 따라 처리 결과(데이터 정렬, 수식 연산, 구조 복제 등)가 완전히 달라지므로, 업무 목적에 부합하는 순회 규칙을 정의해야 함

## Ⅱ. 특징

- 모든 순회 방식은 전체 노드($n$)를 각각 한 번씩 거치므로 시간복잡도는 $O(n)$으로 동일하지만, 방문한 노드 데이터를 메모리에 쌓는 방식에 따라 공간복잡도가 달라질 수 있음
- 전위 순회는 부모 노드를 자식보다 먼저 처리하므로 계층 구조를 그대로 직렬화($Serialization$)하여 외부 저장소에 기록하거나 복제하는 데 최적화됨
- 중위 순회는 이진 탐색 트리($BST$)의 특성을 활용해 데이터를 오름차순으로 정렬하여 읽어낼 수 있으며, 후위 순회는 하위 결과물을 집계하여 상위로 전달하는 수식 계산이나 노드 삭제 작업에 유리함

## Ⅲ. 종류 및 비교

| 판단 기준 | 전위 순회 (Pre-order) | 중위 순회 (In-order) | 후위 순회 (Post-order) |
|:---|:---|:---|:---|
| **방문 순서** | 루트 $\rightarrow$ 왼쪽 $\rightarrow$ 오른쪽 | 왼쪽 $\rightarrow$ 루트 $\rightarrow$ 오른쪽 | 왼쪽 $\rightarrow$ 오른쪽 $\rightarrow$ 루트 |
| **핵심 목적** | 트리 구조 복사, 직렬화 | 정렬된 데이터 인출 | 수식 계산, 파일 시스템 삭제 |
| **표기법 활용** | 전위 표기법 ($+AB$) | 중위 표기법 ($A+B$) | 후위 표기법 ($AB+$) |
| **특이 사항** | 자식보다 부모가 항상 우선 | $BST$ 순회 시 오름차순 보장 | 모든 자식 처리 후 부모 삭제 |

> 요약: 구조 전체의 기록이 필요하면 전위, 정렬된 결과가 필요하면 중위, 하위 결과의 집계나 삭제가 필요하면 후위 순회를 사용함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 현재 노드 | 순회의 재귀적 호출 단계에서 방문 여부를 결정해야 할 기준 단위임 |
| 왼쪽 부분 트리 | 현재 노드를 기준으로 왼쪽에 연결된 모든 하위 노드들의 집합임 |
| 오른쪽 부분 트리 | 현재 노드를 기준으로 오른쪽에 연결된 모든 하위 노드들의 집합임 |
| 스택/재귀 엔진 | 다음 순회 지점을 기억하고 이전 노드로 복귀하기 위한 논리적 저장 메커니즘임 |

```text
[ 이진트리 순회 모델 ]
      (Root)
     /      \
 (Left)    (Right)

1. Pre:  Root -> Left -> Right
2. In:   Left -> Root -> Right
3. Post: Left -> Right -> Root
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 진입점 설정  | --> | 재귀 규칙 적용 | --> | 방문 연산 수행 | --> | 하위 전이/복귀|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **진입 설정** — 트리의 루트 노드를 순회 알고리즘의 첫 번째 인자로 전달하여 시작함
2. **규칙 적용** — 선택한 순회 방식(전위/중위/후위)에 따라 방문과 재귀 호출의 실행 순서를 결정함
3. **방문 수행** — 해당 노드에 접근하여 출력하거나 가공하는 실질적인 비즈니스 로직을 실행함
4. **전이 및 복귀** — 왼쪽과 오른쪽 자식 노드에 대해 동일한 순회 함수를 재귀적으로 호출하고, 모든 자식 방문이 끝나면 부모 노드로 제어권을 복귀시킴

## Ⅵ. 실무 적용 및 유의점

1. 이진 탐색 트리에서 중위 순회를 통해 데이터를 정렬된 상태로 읽어올 때는 트리의 균형이 깨져 있을 경우 순회 효율이 저하될 수 있으므로, 자가 균형 트리($AVL$, $RB$)를 병행 적용하여 탐색 깊이를 통제해야 함
2. 트리 깊이가 매우 깊은 대용량 데이터를 재귀 방식으로 순회하면 $Stack$ $Overflow$가 발생할 수 있으므로, 명시적인 스택 자료구조를 사용하는 반복문($Iterative$) 기반 순회로 전환하고 최대 메모리 사용량을 모니터링해야 함

## Ⅶ. 결론

- 이진트리 순회는 데이터의 계층적 구조를 선형적인 처리 흐름으로 변환하는 핵심 절차이며, 설계자는 출력 형태와 작업 성격에 맞는 순회 규칙을 선별하여 데이터 처리의 일관성과 정확성을 확보해야 함
