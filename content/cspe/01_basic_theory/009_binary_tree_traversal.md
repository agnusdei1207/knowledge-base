# 009. 이진트리 순회 (Binary Tree Traversal) [출제: 126회]

## Ⅰ. 개요

- **정의/개념**: 이진트리 순회는 모든 노드를 한 번씩 방문하되, 루트를 좌·우 자식보다 언제 처리하느냐에 따라 계층 구조를 선형 순서로 변환하는 방법임
  - **전위 순회 (Preorder)**: 루트 → 좌 → 우 순서로 방문함
  - **중위 순회 (Inorder)**: 좌 → 루트 → 우 순서로 방문함
  - **후위 순회 (Postorder)**: 좌 → 우 → 루트 순서로 방문함
- **배경/필요성**: 동일한 트리라도 루트 방문 시점에 따라 정렬 출력, 구조 복원, 자원 해제, 수식 계산 결과가 달라지므로 목적에 부합하는 순회 방식 선택이 필수적임

## Ⅱ. 특징 및 비교

순회의 유형은 루트 노드의 처리 시점에 의해 결정되며, 자식 노드는 원칙적으로 왼쪽부터 방문함.

| 순회 방식 | 방문 순서 | 주요 용도 및 특징 |
|:---|:---|:---|
| **전위 (Preorder)** | 루트 → 좌 → 우 | 트리 복사, 직렬화, 디렉토리 구조 출력 |
| **중위 (Inorder)** | 좌 → 루트 → 우 | $BST$에서 키 값의 오름차순 정렬 출력 |
| **후위 (Postorder)** | 좌 → 우 → 루트 | 노드 삭제, 후위 표기식 변환 및 수식 계산 |
| **레벨 (Level)** | 층별 (BFS) | 계층별 노드 출력, 최단 경로 탐색 기초 |

> 요약: 루트를 처음에 두면 전위, 중간에 두면 중위, 마지막에 두면 후위 순회임.

## Ⅲ. 구성요소/구조

- **순회 예시**:

```text
        A
       / \
      B   C

전위: A-B-C / 중위: B-A-C / 후위: B-C-A
```

- **분석 지표**:
  - **시간 복잡도**: 모든 노드를 1회 방문하므로 $O(n)$임
  - **공간 복잡도**: 재귀 호출에 따른 콜 스택 깊이가 트리 높이 $h$에 비례하여 $O(h)$임
  - **구성요소**: 처리 대상인 루트, 재귀 적용 단위인 좌·우 서브트리, 복귀 경로 저장소인 콜 스택

## Ⅳ. 문제점 및 개선방안

1. **순회 방식 오적용에 따른 논리 오류**: 데이터 정렬이 필요한 $BST$ 출력에 전위 순회를 적용할 경우 정렬 순서가 보장되지 않음
   - **개선방안**: 출력 목적(정렬, 해제, 복사)과 순회 방식을 사전에 매핑하여 설계함 (확인: 목적별 출력 리스트 정합성)

2. **재귀 깊이 초과 (Stack Overflow)**: 편향 트리 구조에서 노드 수 $n$이 많을 경우 콜 스택 한계를 초과할 수 있음
   - **개선방안**: 명시적 스택 자료구조를 활용한 반복문 순회(Iterative Traversal)로 전환함 (확인: 최대 트리 높이 대비 스택 가용량)

3. **구조 복원의 모호성**: 단일 순회 결과만으로는 원래의 이진트리 구조를 유일하게 재구성할 수 없음
   - **개선방안**: 전위-중위 또는 후위-중위 조합의 결과를 함께 저장하거나, 단말 노드에 널 마커(Null Marker)를 포함함 (확인: 복원된 트리와 원본의 일치 여부)

## Ⅴ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| 컴파일러 구문 트리 | 후위 순회로 피연산자를 먼저 평가하여 기계어 코드 생성 | 연산 우선순위 준수 여부 |
| 데이터베이스 질의 최적화 | $BST$ 기반 인덱스를 중위 순회하여 범위 검색 결과 도출 | 데이터 정렬 정확도 |
| 메모리/자원 관리 | 후위 순회로 자식 노드의 자원을 먼저 해제한 후 부모 노드 제거 | 메모리 누수 발생 여부 |

> 요약: 계층 복사는 전위, 순서 정렬은 중위, 자원 해제는 후위 순회를 활용함.

## Ⅵ. 결론

이진트리 순회는 계층적 데이터를 처리하기 위한 가장 기본적이면서도 핵심적인 알고리즘임. 기술사는 단순히 방문 순서를 외우는 것을 넘어, 워크로드의 특성에 맞는 순회 방식을 선택하고 대규모 데이터 환경에서의 스택 오버헤드를 제어할 수 있는 구현 역량을 갖추어야 함.

특히 트리 구조의 직렬화와 역직렬화 과정에서 발생할 수 있는 정보 손실을 방어하기 위한 추가 메타데이터 설계 능력이 요구되며, 이는 분산 환경에서의 데이터 교환과 영속성 보장을 위한 필수 기반 기술임.
