## 미리 알고가기

- 루트: 현재 부분 트리의 기준 노드임
- 전위 순회: 루트를 먼저 방문하는 순회 방식임
- 중위 순회: 왼쪽, 루트, 오른쪽 순서로 방문하는 방식임
- 후위 순회: 자식 노드를 모두 방문한 뒤 루트를 방문하는 방식임
- 이진 탐색 트리: 왼쪽은 작은 키, 오른쪽은 큰 키를 두는 이진트리임

## Ⅰ. 개요

- **정의/개념**: 이진트리 순회는 트리의 모든 노드를 한 번씩 방문하는 절차이며, 루트를 언제 처리하느냐에 따라 전위, 중위, 후위로 나뉨
- **배경/필요성**: 같은 트리라도 방문 순서에 따라 출력, 계산, 삭제 결과가 달라짐. 따라서 목적에 맞는 순회 순서를 정해야 함

## Ⅱ. 특징

- 전위 순회는 부모를 먼저 처리하므로 구조 복사와 직렬화에 적합함
- 중위 순회는 이진 탐색 트리에서 키를 정렬된 순서로 읽을 수 있음
- 후위 순회는 자식을 먼저 처리하므로 수식 계산이나 노드 삭제에 적합함
- 세 방식은 모든 노드를 한 번씩 방문하므로 시간복잡도는 모두 $O(n)$임

## Ⅲ. 종류 및 비교

| 판단 기준 | 전위 순회 | 중위 순회 | 후위 순회 |
|:---|:---|:---|:---|
| 방문 순서 | 루트, 왼쪽, 오른쪽 | 왼쪽, 루트, 오른쪽 | 왼쪽, 오른쪽, 루트 |
| 적합한 목적 | 구조 기록, 트리 복사 | 정렬 출력 | 자식 결과 집계, 삭제 |
| 대표 용도 | 직렬화, 전위 표기 | BST 정렬 순회 | 후위 표기 계산, 파일 트리 삭제 |
| 주의점 | 정렬 순서를 보장하지 않음 | BST가 아니면 정렬 의미가 없음 | 부모 처리가 가장 늦음 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 현재 노드 | 이번 단계에서 처리할 기준 노드임 |
| 왼쪽 부분 트리 | 현재 노드의 왼쪽 하위 구조임 |
| 오른쪽 부분 트리 | 현재 노드의 오른쪽 하위 구조임 |
| 방문 연산 | 출력, 계산, 삭제 등 노드에서 수행할 작업임 |

```text
전위: Root -> Left -> Right
중위: Left -> Root -> Right
후위: Left -> Right -> Root
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-----------+     +-----------+     +-----------+
| 왼쪽 처리 | <-> | 루트 처리 | <-> | 오른쪽 처리 |
+-----------+     +-----------+     +-----------+
```

1. 순회 방식에 따라 루트 처리 위치를 정함
2. 같은 규칙을 왼쪽 부분 트리에 적용함
3. 같은 규칙을 오른쪽 부분 트리에 적용함
4. 모든 노드가 한 번씩 처리되면 종료함

## Ⅵ. 실무 적용 및 유의점

1. BST에서 정렬 결과가 필요하면 중위 순회를 사용하고, 일반 이진트리에는 정렬 의미가 없음을 확인해야 함
2. 트리 깊이가 계속 깊어지면 재귀 호출이 시스템 한계를 넘을 수 있으므로 깊은 입력은 반복 순회로 바꾸고 최대 깊이를 테스트해야 함

## Ⅶ. 결론

- 이진트리 순회는 루트 처리 시점으로 목적이 갈리며, 정렬 출력은 중위, 구조 기록은 전위, 하위 결과 처리는 후위가 적합함
