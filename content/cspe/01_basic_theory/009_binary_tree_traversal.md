## 미리 알고가기

- 루트(Root): 현재 순회 단계에서 방문 시점의 기준이 되는 노드임
- 서브트리(Subtree): 한 노드와 그 자손으로 이루어진 하위 트리임
- 재귀 호출(Recursion): 같은 순회 규칙을 왼쪽·오른쪽 하위 트리에 반복 적용하는 방식임
- 방문(Visit): 노드의 값을 출력·계산·삭제·직렬화하는 처리 행위임
- 이진 탐색 트리(BST): 왼쪽 키 $<$ 루트 키 $<$ 오른쪽 키 조건으로 중위 순회 시 정렬 결과를 내는 트리임

## 작성 근거(검토용)

- **개요 구성**: 루트와 좌·우 서브트리의 방문 순서를 정의해 전위·중위·후위 구분 기준을 바로 드러냄
- **특징 선정**: 방문 시점, $O(n)$ 처리, 높이 기반 공간, 편향 위험이 순회 방식의 공통 비용과 차이를 설명함
- **Ⅲ 비교축**: 전위·중위·후위의 방문 순서와 활용 목적이 직접 대응되므로 표로 압축함
- **BST 조건 명시**: 중위 순회가 항상 정렬을 보장하지 않고 BST에서만 성립하므로 비교표에 조건을 명시함
- 편향 트리와 복원 정보 누락은 순회 구현 실패 조건이라 메모리·복원 테스트와 연결함

## Ⅰ. 개요

- **정의/개념**: 이진트리 순회는 루트와 좌·우 서브트리의 방문 순서를 정해 모든 노드를 중복 없이 처리하는 절차임
- **배경/필요성**: 직렬화·정렬 출력·하위 집계 결과를 맞추기 위해 목적별 순회 규칙이 필요함

## Ⅱ. 특징

- 루트 방문 시점이 앞·중간·뒤 어디인지가 결과 의미를 결정함
- 각 노드를 한 번씩 처리하므로 시간복잡도는 $O(n)$임
- 재귀·명시 스택의 보조 공간은 트리 높이 $h$에 비례함
- 편향 트리는 $h=n$이 되어 재귀 깊이와 메모리 위험이 커짐

## Ⅲ. 종류 및 비교

| 판단 기준 | 전위 순회 (Pre-order) | 중위 순회 (In-order) | 후위 순회 (Post-order) |
|:---|:---|:---|:---|
| **방문 순서** | 루트 $\rightarrow$ 왼쪽 $\rightarrow$ 오른쪽 | 왼쪽 $\rightarrow$ 루트 $\rightarrow$ 오른쪽 | 왼쪽 $\rightarrow$ 오른쪽 $\rightarrow$ 루트 |
| **주요 활용** | 트리 구조 복사·직렬화 | 정렬된 데이터 인출 | 수식 계산·파일 시스템 삭제 |
| **수식 트리 활용** | 전위 표기법 ($+AB$) | 중위 표기법 ($A+B$) | 후위 표기법 ($AB+$) |
| **주의점** | 복원 시 공백 자식 정보 필요 | BST 조건에서만 정렬 보장 | 부모 처리가 가장 늦음 |

> 요약: 구조 기록은 전위, 정렬 출력은 중위, 하위 집계·삭제는 후위가 적합함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 현재 노드 | 루트 방문 시점을 결정하는 기준 노드이며 처리 결과의 위치를 정함 |
| 왼쪽 서브트리 | 현재 노드보다 먼저 또는 나중에 처리될 하위 문제임 |
| 오른쪽 서브트리 | 왼쪽 처리 후 방문 순서에 따라 이어지는 하위 문제임 |
| 호출 스택·명시 스택 | 복귀 위치와 아직 방문하지 않은 노드를 저장해 재귀 흐름을 유지함 |

```text
[ 이진트리 순회 모델 ]
      (Root)
     /      \
 (Left)    (Right)

1. Pre:  Root -> Left -> Right
2. In:   Left -> Root -> Right
3. Post: Left -> Right -> Root
```

> 요약: 순회 방식은 루트 방문 시점만 달라지며 그 차이가 결과 의미를 바꿈.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------------+     +----------------+     +----------------+     +-------------+
| 현재 노드 확인 | --> | 순회 규칙 선택 | --> | 규칙 순서 실행 | --> | 결과 반환    |
+----------------+     +----------------+     +----------------+     +-------------+
```

1. **현재 노드 확인**: 루트를 시작점으로 현재 노드와 빈 자식 여부를 확인함
2. **규칙 선택**: 직렬화·정렬 출력·집계 목적에 맞춰 루트 방문 위치를 정함
3. **규칙 실행**: 선택한 순서대로 현재 노드와 좌·우 서브트리를 방문함
4. **복귀·반환**: 자식 방문이 끝나면 부모 노드로 복귀해 다음 분기를 처리함

> 요약: 순회 목적을 먼저 정해야 전위·중위·후위 중 올바른 루트 방문 위치를 선택함.

## Ⅵ. 실무 사례

1. BST 정렬 출력은 중위 순회가 적합하지만 편향 트리는 재귀 깊이가 커지므로 반복 순회로 전환하고 최대 메모리로 확인함
2. 트리 직렬화·복원은 전위 순회만으로 구조가 모호할 수 있으므로 NULL 자식 표식을 기록하거나 고유 키의 중위 순회를 함께 저장하고 복원 테스트로 검증함

## Ⅶ. 결론

- 이진트리 순회는 계층 구조를 선형 처리 순서로 바꾸는 절차이므로 루트 방문 시점을 처리 목적에 맞춰 선택해야 함
