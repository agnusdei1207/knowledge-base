## 미리 알고가기

- 루트: 현재 서브트리의 기준 노드임
- 재귀 순회: 같은 규칙을 좌우 서브트리에 반복 적용하는 방식임
- 직렬화: 트리 구조를 선형 데이터로 바꾸는 과정임

## Ⅰ. 개요

- **정의/개념**: 이진트리 순회는 모든 노드를 한 번씩 방문하되 루트를 처리하는 시점에 따라 전위, 중위, 후위 순서로 선형화하는 기본 알고리즘임
- **배경/필요성**: 같은 트리라도 언제 루트를 처리하느냐에 따라 정렬, 복사, 삭제, 계산 결과가 달라지므로, 목적에 맞는 순회 전략 선택이 필수적임

## Ⅱ. 특징

- 전위 순회는 부모 정보를 먼저 내보내므로 구조 복사와 직렬화에 유리함
- 중위 순회는 이진 탐색 트리에서 정렬된 결과를 얻는 기준이 됨
- 후위 순회는 자식 처리가 끝난 뒤 부모를 다뤄야 하는 삭제와 계산에 적합함
- 세 방식 모두 시간복잡도는 같지만 처리 시점이 다르므로 업무 의미가 완전히 달라짐

## Ⅲ. 종류 및 비교

| 판단 기준 | 전위 순회 | 중위 순회 | 후위 순회 |
|:---|:---|:---|:---|
| 처리 순서 | 루트-좌-우 | 좌-루트-우 | 좌-우-루트 |
| 핵심 목적 | 구조 보존 출력 | 정렬 순서 확보 | 하위 결과 집계 |
| 대표 용도 | 직렬화, 복사 | BST 정렬 출력 | 삭제, 수식 계산 |
| 설계 포인트 | 부모 선행 | 루트 중간 배치 | 자식 선행 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 현재 노드 | 이번 단계의 처리 기준이며 처리 시점이 순회 종류를 결정함 |
| 좌우 서브트리 | 재귀적으로 같은 규칙이 적용되는 영역이며 분할 단위가 명확함 |
| 콜 스택 | 복귀 경로와 상태를 유지하고 트리 높이에 따라 공간이 늘어남 |
| 방문 연산 | 출력, 계산, 삭제 등 실제 작업이며 순회 목적과 직접 연결됨 |

```text
+-----------+     +-----------+     +-----------+
| 현재 노드    | --> | 좌 서브트리   | --> | 우 서브트리   |
+-----------+     +-----------+     +-----------+
      |
      v
+-----------+
| 방문 시점    |
+-----------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 노드진입 | --> | 루트처리 | --> | 좌우순회 | --> | 복귀완료 |
+----------+     +----------+     +----------+     +----------+
```

1. **노드진입**: 현재 노드가 비어 있으면 종료함
2. **루트처리**: 전위는 먼저, 중위는 좌측 뒤, 후위는 마지막에 처리함
3. **좌우순회**: 좌측과 우측 서브트리에 같은 규칙을 적용함
4. **복귀완료**: 상위 호출로 돌아가 다음 작업을 진행함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 순회 목적과 방식이 어긋나 삭제 작업에 전위를 쓰면 하위 노드 정리가 꼬일 수 있음
   - 해결방안: 업무 목적을 먼저 정하고 그에 맞는 처리 시점을 선택하고 처리 순서 테스트로 검증함
2. 문제: 깊은 편향 트리에서 재귀 한계가 발생해 트리 높이가 크면 스택 오버플로우 위험이 있음
   - 해결방안: 명시적 스택 기반 반복 순회로 전환하고 최대 깊이 입력 테스트로 검증함
3. 문제: 구조 복원이 불완전해 순회 결과 하나만 저장하면 원래 트리를 복원하지 못할 수 있음
   - 해결방안: 전위와 중위 조합 또는 널 마커 포함 직렬화를 사용하고 역직렬화 일치율로 검증함

## Ⅶ. 적용 사례

- 컴파일러 구문 트리에서는 후위 순회로 하위 식 계산 결과를 먼저 결합하며, 평가 정확도와 스택 사용량으로 결과를 확인함
- 검색 트리 출력에서는 중위 순회로 키를 정렬된 순서로 내보내며, 정렬 정확도와 순회 시간으로 결과를 확인함
- 백업 직렬화에서는 전위 순회와 널 마커로 구조를 보존하며, 복원 성공률과 데이터 크기로 결과를 확인함

## Ⅷ. 결론

이진트리 순회의 핵심은 성능 차이가 아니라 루트 처리 시점의 의미 차이이므로, 출력, 계산, 삭제 중 무엇을 먼저 보장해야 하는지에 맞춰 전위, 중위, 후위를 선택해야 함.
