## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 이진트리의 모든 노드를 체계적으로 방문하는 방법으로, 루트 방문 순서에 따라 전위·중위·후위·레벨 순회로 분류됨 |
| **배경/필요성** | 트리 데이터의 직렬화·수식 표현·검색 등 다양한 연산이 순회 순서에 의존하며, 올바른 순회 선택이 필수임 |
| **출제 의도** | 각 순회의 방문 순서와 활용 사례를 구분하고, 재귀·반복 구현을 설명할 수 있는지 평가함 |

## Ⅱ. 구성요소
```
+----------+     +----------+     +----------+
| 전위     | --> | 중위     | --> | 후위     |
| (Root→L→R)|    | (L→Root→R)|    | (L→R→Root)|
+----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| 전위 순회(Pre) | 루트 → 왼쪽 → 오른쪽 순으로 방문하며, 트리 복사·직렬화에 사용됨 | 상사 지시 → 부서 순회 |
| 중위 순회(In) | 왼쪽 → 루트 → 오른쪽 순으로 방문하며, BST에서 정렬 순서 출력에 사용됨 | 작은값부터 순서대로 |
| 후위 순회(Post) | 왼쪽 → 오른쪽 → 루트 순으로 방문하며, 메모리 해제·후위 표기식 계산에 사용됨 | 하위부터 정리 후 상위 처리 |

> 요약: 루트 방문 시점(전·중·후)에 따라 순회가 구분되며, 용도에 맞는 순회를 선택함.

## Ⅲ. 절차
```
+------------+     +------------+
| 루트방문   | --> | 왼쪽재귀   |
| (전위기준) |     | (Left)    |
+------------+     +------------+
                        |
+------------+     +----+-------+
| 순회완료   | <-- | 오른쪽재귀 |
|            |     | (Right)   |
+------------+     +------------+
```

1. 루트 방문: 전위는 방문 즉시 처리, 중위·후위는 자식 순회 후 처리함
2. 왼쪽 서브트리 재귀: 왼쪽 자식을 루트로 동일 순회를 재귀 호출함
3. 오른쪽 서브트리 재귀: 오른쪽 자식을 루트로 동일 순회를 재귀 호출함
4. 종료: 노드가 NULL이면 재귀를 종료하고 호출 스택을 되감음

> 요약: 루트 방문 → 좌측 재귀 → 우측 재귀의 순서만 변경하여 전위·중위·후위를 구현함.

## Ⅳ. 문제점
- 재귀 스택 오버플로우: 트리 깊이가 깊으면(편향 트리 O(n)) 호출 스택 초과가 발생함
- 순회 결과 모호성: 전위·후위 결과만으로는 원래 트리 구조를 유일하게 복원할 수 없음
- 반복 구현 복잡성: 중위·후위 순회의 반복(스택 기반) 구현이 재귀 대비 코드가 복잡함

## Ⅴ. 개선방안
- (단기) 스택 기반 반복 구현: 명시적 스택을 사용하여 재귀 없이 순회하여 스택 오버플로우를 방지함
- (중기) Morris 순회: 스레디드 트리 기법으로 O(1) 추가 공간에서 중위 순회를 수행함
- (장기) 레벨 순회 활용: BFS 기반 레벨 순회를 직렬화·역직렬화의 표준 방식으로 채택함

## Ⅵ. 전망
- 컴파일러 AST 분석·XML/JSON 트리 파싱·파일시스템 탐색에서 트리 순회가 핵심 연산으로 활용되며, 대규모 트리의 병렬 순회(Work-Stealing) 기법이 확산될 전망임
