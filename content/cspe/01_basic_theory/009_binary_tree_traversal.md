## 미리 알고가기

- 루트(Root): 현재 방문 또는 분기의 기준이 되는 노드임
- 서브트리(Subtree): 한 노드와 모든 자손으로 이루어진 하위 트리임
- 재귀 호출(Recursion): 같은 구조의 작은 하위 문제를 다시 호출하는 방식임
- 방문(Visit): 노드에 접근해 출력, 갱신, 삭제를 수행하는 행위임
- 이진 탐색 트리($BST$): 왼쪽 키 $<$ 루트 키 $<$ 오른쪽 키 조건을 만족하는 이진트리임

## Ⅰ. 개요

- **정의/개념**: 이진트리 순회는 모든 노드를 중복 없이 한 번씩 방문하며 루트 방문 시점으로 전위·중위·후위를 구분하는 절차임
- **배경/필요성**: 트리는 방문 순서에 따라 정렬, 수식 계산, 삭제 결과가 달라지므로 처리 목적별 순회 규칙이 필요함

## Ⅱ. 특징

- 모든 방식은 각 노드를 한 번 방문함
- 시간복잡도는 $O(n)$임
- 보조 공간은 트리 높이 $h$에 비례함
- 방문 시점이 결과 의미를 결정함

## Ⅲ. 종류 및 비교

| 판단 기준 | 전위 순회 (Pre-order) | 중위 순회 (In-order) | 후위 순회 (Post-order) |
|:---|:---|:---|:---|
| **방문 순서** | 루트 $\rightarrow$ 왼쪽 $\rightarrow$ 오른쪽 | 왼쪽 $\rightarrow$ 루트 $\rightarrow$ 오른쪽 | 왼쪽 $\rightarrow$ 오른쪽 $\rightarrow$ 루트 |
| **핵심 목적** | 트리 구조 복사, 직렬화 | 정렬된 데이터 인출 | 수식 계산, 파일 시스템 삭제 |
| **표기법 활용** | 전위 표기법 ($+AB$) | 중위 표기법 ($A+B$) | 후위 표기법 ($AB+$) |
| **주의점** | 복원 시 공백 자식 정보 필요 | $BST$ 조건에서만 정렬 보장 | 부모 처리가 가장 늦음 |

> 요약: 구조 기록은 전위, 정렬 출력은 중위, 하위 집계·삭제는 후위가 적합함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 현재 노드 | 방문 시점을 결정하는 기준 노드임 |
| 왼쪽 서브트리 | 현재 노드의 왼쪽 하위 구조임 |
| 오른쪽 서브트리 | 현재 노드의 오른쪽 하위 구조임 |
| 호출 스택/명시 스택 | 다음 노드와 복귀 위치를 저장함 |

```text
[ 이진트리 순회 모델 ]
      (Root)
     /      \
 (Left)    (Right)

1. Pre:  Root -> Left -> Right
2. In:   Left -> Root -> Right
3. Post: Left -> Right -> Root
```

## Ⅴ. 원리 및 절차 흐름도

```text
+----------------+     +----------------+     +----------------+     +-------------+
| 현재 노드 확인 | --> | 순회 규칙 선택 | --> | 규칙 순서 실행 | --> | 결과 반환    |
+----------------+     +----------------+     +----------------+     +-------------+
```

1. **현재 노드 확인**: 루트를 시작점으로 현재 노드를 확인함
2. **순회 규칙 선택**: 목적에 맞춰 루트 방문 위치를 정함
3. **규칙 실행**: 현재 노드와 좌·우 서브트리를 방문함
4. **결과 반환**: 자식 방문 후 부모 노드로 복귀함

## Ⅵ. 실무 적용 및 유의점

1. $BST$ 정렬 출력은 중위 순회가 적합하며, 편향 트리는 반복 순회로 스택 사용량을 통제함
2. 깊은 트리의 재귀 순회는 명시 스택으로 전환하고 최대 메모리를 확인함

## Ⅶ. 결론

- 이진트리 순회는 계층 구조를 선형 처리 순서로 바꾸므로 전위·중위·후위를 처리 목적에 맞춰 선택함

## 작성 근거(검토용)

- **개요 구성**: 모든 노드를 한 번 방문한다는 공통점과 루트 방문 시점 차이를 정의에 함께 넣음
- **특징 선정**: 시간복잡도, 보조 공간, 방문 시점은 순회 방식의 공통 비용과 차이를 설명함
- **Ⅲ 비교축**: 전위·중위·후위의 방문 순서와 활용 목적이 직접 대응되므로 표로 압축함
- **BST 조건 명시**: 중위 순회가 항상 정렬을 보장하는 것이 아니라 $BST$에서만 성립하므로 주의점에 둠
- **실무 유의점**: 편향 트리와 깊은 재귀는 순회 구현의 주요 실패 조건이라 반복 순회와 메모리 확인을 연결함
