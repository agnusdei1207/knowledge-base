# 이진트리 순회 - 전위·중위·후위 (Binary Tree Traversal)

## 1. 개요

- **정의/개념**: 이진트리 순회는 루트, 왼쪽 서브트리, 오른쪽 서브트리를 어떤 순서로 방문할지 정해 계층 구조를 선형 처리 순서로 변환하는 방법이다.
- **배경/필요성**: 같은 트리라도 루트를 언제 처리하는지에 따라 정렬 출력, 구조 복원, 삭제, 계산 결과가 달라지므로 목적에 맞는 순회 방식이 필요하다.

## 2. 특징 및 비교

| 구분 | 방문 순서 | 의미 | 대표 활용 |
|---|---|---|---|
| 전위 순회 | Root -> Left -> Right | 루트 먼저 처리 | 트리 복사, 직렬화, prefix |
| 중위 순회 | Left -> Root -> Right | 왼쪽과 오른쪽 사이에 루트 처리 | BST 정렬 출력 |
| 후위 순회 | Left -> Right -> Root | 자식 먼저 처리 | 트리 삭제, postfix 계산 |
| 레벨 순회 | 깊이 순서 | 가까운 레벨부터 처리 | BFS, 계층 출력 |

중위 순회가 정렬 결과를 제공하는 것은 이진 탐색 트리(Binary Search Tree, BST)일 때이다.

## 3. 구성요소/구조

```text
        A
       / \
      B   C

Preorder : A B C
Inorder  : B A C
Postorder: B C A
```

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| Root | 현재 서브트리의 기준 노드 | 방문 위치가 순회 종류 결정 |
| Left Subtree | 왼쪽 하위 구조 | 재귀적 동일 규칙 적용 |
| Right Subtree | 오른쪽 하위 구조 | 왼쪽 처리 후 또는 전후 방문 |
| Call Stack | 재귀 복귀 경로 저장 | 높이 `h`만큼 공간 사용 |

모든 노드를 한 번씩 방문하므로 시간복잡도는 `O(n)`이고, 재귀 공간은 트리 높이 `h`에 따라 `O(h)`이다.

## 4. 문제점 및 개선방안

1. **순회 목적 불일치**
   - BST 정렬 출력에 전위 순회를 쓰면 결과 의미가 틀어진다.
   - **개선방안**: 목적별 순회 방식을 표준 매핑하고 대표 트리로 검증한다.

2. **재귀 스택 초과**
   - 편향 트리에서는 재귀 깊이가 노드 수에 가까워진다.
   - **개선방안**: 명시적 스택 기반 반복 순회 또는 균형 트리를 사용한다.

3. **직렬화 모호성**
   - null 자식 표시나 중복 키 정책이 없으면 트리 복원이 모호하다.
   - **개선방안**: null 마커와 중복 키 정책을 명시한다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| 컴파일러 AST | 전위·후위 순회로 구문 출력, 최적화, 코드 생성 수행 | 방문 순서, 스택 깊이 |
| BST 인덱스 | 중위 순회로 키를 정렬 순서로 출력 | 정렬 정확도 |
| 리소스 해제 | 후위 순회로 자식 노드 처리 후 부모 제거 | 누수 여부, 참조 오류 |

## 6. 결론

이진트리 순회는 트리의 계층 구조를 목적에 맞는 선형 처리 순서로 바꾸는 기본 기법이다. 전위·중위·후위는 루트 처리 위치로 구분하며, 적용 목적과 트리 성질을 함께 설명해야 한다.
