## 미리 알고가기

- 루트(Root): 현재 방문 또는 분기의 기준이 되는 노드임
- 서브트리(Subtree): 한 노드와 그 노드의 모든 자손으로 이루어진 하위 트리임
- 재귀 호출(Recursion): 하나의 문제를 동일한 구조의 작은 하위 문제로 나누어 해결하는 방식임
- 방문(Visit): 노드에 접근하여 출력, 데이터 갱신, 삭제 등의 실질적인 연산을 수행하는 행위임

## Ⅰ. 개요

- **정의/개념**: 이진트리 순회는 트리의 모든 노드를 중복 없이 한 번씩 방문하는 절차이며, 각 서브트리의 기준 노드를 방문하는 시점에 따라 전위, 중위, 후위 순회로 구분함
- **배경/필요성**: 비선형 자료구조인 트리는 선형 데이터와 달리 방문 순서에 따라 처리 결과(데이터 정렬, 수식 연산, 구조 복제 등)가 완전히 달라지므로, 업무 목적에 부합하는 순회 규칙을 정의해야 함

## Ⅱ. 특징

- 모든 순회 방식의 시간복잡도는 $O(n)$이며, 보조 공간은 재귀 호출 스택 또는 명시 스택 때문에 트리 높이 $h$에 비례함
- 전위 순회는 부모를 먼저 기록하므로 구조 복제와 직렬화의 시작 순서를 잡기 쉽지만, 정확한 복원에는 자식 부재 정보를 함께 저장해야 함
- 중위 순회는 키 정렬 조건을 만족하는 BST에서 오름차순 결과를 얻는 데 적합함
- 후위 순회는 자식 결과를 먼저 확보한 뒤 부모를 처리하므로 수식 계산과 노드 삭제에 적합함

## Ⅲ. 종류 및 비교

| 판단 기준 | 전위 순회 (Pre-order) | 중위 순회 (In-order) | 후위 순회 (Post-order) |
|:---|:---|:---|:---|
| **방문 순서** | 루트 $\rightarrow$ 왼쪽 $\rightarrow$ 오른쪽 | 왼쪽 $\rightarrow$ 루트 $\rightarrow$ 오른쪽 | 왼쪽 $\rightarrow$ 오른쪽 $\rightarrow$ 루트 |
| **핵심 목적** | 트리 구조 복사, 직렬화 | 정렬된 데이터 인출 | 수식 계산, 파일 시스템 삭제 |
| **표기법 활용** | 전위 표기법 ($+AB$) | 중위 표기법 ($A+B$) | 후위 표기법 ($AB+$) |
| **특이 사항** | 자식보다 부모가 항상 우선 | $BST$ 순회 시 오름차순 보장 | 모든 자식 처리 후 부모 삭제 |

> 요약: 구조 전체의 기록이 필요하면 전위, 정렬된 결과가 필요하면 중위, 하위 결과의 집계나 삭제가 필요하면 후위 순회를 사용함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 현재 노드 | 순회의 재귀적 호출 단계에서 방문 여부를 결정해야 할 기준 단위임 |
| 왼쪽 부분 트리 | 현재 노드를 기준으로 왼쪽에 연결된 모든 하위 노드들의 집합임 |
| 오른쪽 부분 트리 | 현재 노드를 기준으로 오른쪽에 연결된 모든 하위 노드들의 집합임 |
| 재귀 호출 스택/명시 스택 | 다음에 방문할 노드와 복귀 위치를 저장해 깊이 우선 순회를 지속하게 하는 보조 저장 구조임 |

```text
[ 이진트리 순회 모델 ]
      (Root)
     /      \
 (Left)    (Right)

1. Pre:  Root -> Left -> Right
2. In:   Left -> Root -> Right
3. Post: Left -> Right -> Root
```

## Ⅴ. 원리 및 절차 흐름도

```text
+----------------+     +----------------+     +----------------+     +-------------+
| 현재 노드 확인 | --> | 순회 규칙 선택 | --> | 규칙 순서 실행 | --> | 결과 반환    |
+----------------+     +----------------+     +----------------+     +-------------+
```

1. **현재 노드 확인** — 트리의 루트 노드를 순회 시작점으로 설정하고, 이후 각 재귀 단계의 현재 노드를 확인함
2. **순회 규칙 선택** — 전위, 중위, 후위 중 목적에 맞는 순회 방식을 선택하고 방문 위치를 결정함
3. **규칙 순서 실행** — 선택한 순서에 따라 현재 노드 방문과 왼쪽·오른쪽 서브트리 순회를 수행함
4. **결과 반환** — 모든 자식 방문이 끝나면 부모 노드로 제어권을 복귀시키고 순회 결과를 반환함

## Ⅵ. 실무 적용 및 유의점

1. BST의 중위 순회는 균형 여부와 무관하게 전체 출력 시간이 $O(n)$이지만, 편향 트리에서는 호출 깊이가 $O(n)$까지 증가하므로 반복 순회나 자가 균형 트리로 스택 사용량과 검색 지연을 통제해야 함
2. 트리 깊이가 매우 깊은 데이터를 재귀 방식으로 순회하면 스택 오버플로(Stack Overflow)가 발생할 수 있으므로, 명시 스택을 사용하는 반복 순회로 전환하고 최대 메모리 사용량을 확인해야 함

## Ⅶ. 결론

- 이진트리 순회는 계층 구조를 선형 처리 순서로 바꾸는 절차이므로, 정렬 출력은 중위, 구조 기록은 전위, 하위 결과 집계와 삭제는 후위 순회로 선택해야 함
