## Ⅰ. 개요
- 이진 트리의 모든 노드를 빠짐없이 특정 규칙에 따라 방문하는 과정임.
- 전위, 중위, 후위 순회를 통해 데이터의 선형적 나열 방식을 결정함.
- [표] 출제 의도: 트리의 계층 구조를 선형화하는 논리적 사고력 평가.

## Ⅱ. 구성요소
- ASCII 구조도
      (1)
     /   \
   (2)   (3)

| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| Pre-order | 루트 -> 왼쪽 -> 오른쪽 (전위) | 대장 먼저 출발 |
| In-order | 왼쪽 -> 루트 -> 오른쪽 (중위) | 순차적 줄서기 |
| Post-order | 왼쪽 -> 오른쪽 -> 루트 (후위) | 부하 먼저 퇴근 |

> 요약: 루트 노드의 방문 순서에 따라 기법이 구분됨.

## Ⅲ. 절차
- ASCII 흐름도
  Visit Node -> Go Left -> Go Right (Recursive Style)

1. 현재 노드를 방문할 시점을 결정(전/중/후)함.
2. 왼쪽 서브 트리에 대해 재귀적으로 순회를 호출함.
3. 오른쪽 서브 트리에 대해 재귀적으로 순회를 호출함.
4. 모든 노드를 방문하면 호출 스택을 반환하며 종료함.

> 요약: 재귀적 구조를 통해 전체 트리의 노드를 체계적으로 방문함.

## Ⅳ. 문제점
- 트리의 깊이가 깊을 경우 재귀 호출로 인한 스택 오버플로우 위험함.
- 비재귀(Iterative) 방식 구현 시 별도의 스택 관리가 복잡해짐.

## Ⅴ. 개선방안
- 단기: 꼬리 재귀 최적화 또는 반복문 기반 스택 순회 구현함.
- 중기: 노드 내에 순회 경로를 미리 저장하는 스레드 트리 활용함.
- 장기: 레벨 순회(BFS) 도입으로 계층별 데이터 처리 보완함.

## Ⅵ. 전망
- 그래프 신경망(GNN)의 전처리 단계에서 트리 기반의 계층 구조를 효율적으로 벡터화하기 위한 병렬 순회 및 샘플링 기법이 AI 모델 성능의 CSF로 작용함.
- SIMD(Single Instruction Multiple Data) 명령어를 활용하여 여러 노드를 동시에 순회하는 벡터화 순회 기법이 고성능 수식 연산 엔진에 적용될 것임.
- 비휘발성 메모리(PMM) 환경에서 순회 도중 시스템 장애 발생 시에도 일관성을 보장하는 쓰기 방지(Write-ahead) 순회 프로토콜이 중요 기술로 부각될 전망임.
