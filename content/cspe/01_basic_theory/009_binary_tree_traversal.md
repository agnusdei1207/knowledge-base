# 이진트리 순회 - 전위·중위·후위 (Binary Tree Traversal)

## 1. 정의 및 개념

이진트리 순회는 각 노드가 최대 두 개의 자식을 갖는 트리에서 루트, 왼쪽 서브트리, 오른쪽 서브트리를 어떤 순서로 방문할지 정하는 방법이다.

| 구분 | 방문 순서 | 의미 |
|---|---|---|
| **전위 순회(Preorder)** | Root -> Left -> Right | 루트를 먼저 처리 |
| **중위 순회(Inorder)** | Left -> Root -> Right | 왼쪽과 오른쪽 사이에 루트 처리 |
| **후위 순회(Postorder)** | Left -> Right -> Root | 자식을 먼저 처리 |
| **레벨 순회(Level-order)** | 깊이 순서 | 큐 기반 너비 우선 방문 |

## 2. 구조 및 주요 연산

```text
        A
       / \
      B   C
```

- 전위 순회: A, B, C
- 중위 순회: B, A, C
- 후위 순회: B, C, A

모든 노드를 한 번씩 방문하므로 시간복잡도는 `O(n)`이다. 재귀 구현 시 공간복잡도는 트리 높이 `h`에 따라 `O(h)`가 된다.

## 3. 순회 방식별 활용

| 순회 방식 | 주요 활용 | 이유 |
|---|---|---|
| 전위 순회 | 트리 복사, 직렬화, prefix 수식 | 루트 정보를 먼저 기록 |
| 중위 순회 | BST 정렬 출력, 범위 검색 | 왼쪽 < 루트 < 오른쪽 불변식 활용 |
| 후위 순회 | 트리 삭제, postfix 계산, 하위 결과 집계 | 자식 처리 후 부모 처리 |
| 레벨 순회 | 계층 출력, 최단 레벨 탐색 | 가까운 깊이부터 방문 |

중위 순회가 정렬 결과를 제공하는 것은 이진 탐색 트리(Binary Search Tree, BST)일 때이며, 일반 이진트리에서는 정렬 의미가 없다.

## 4. 구현 방식 비교

| 구현 | 장점 | 단점 |
|---|---|---|
| 재귀 기반 | 코드 간결, 정의와 일치 | 깊은 트리에서 스택 오버플로우 |
| 명시적 스택 | 재귀 제한 회피 | 방문 상태 관리 필요 |
| Morris 순회 | 추가 공간 `O(1)` 가능 | 임시 링크 변경으로 구현 복잡 |
| 큐 기반 레벨 순회 | 깊이별 방문 가능 | 넓은 레벨에서 큐 메모리 증가 |

후위 순회는 루트를 가장 나중에 처리하므로 메모리 해제나 하위 결과 집계에 적합하다.

## 5. 심화 이슈 (기술사 포인트)

1. **BST와 일반 트리 구분**
   - 중위 순회의 정렬 효과는 BST의 키 순서 불변식이 있을 때만 성립한다.

2. **재귀 스택 위험**
   - 편향 트리에서는 높이가 `n`이 되어 재귀 호출 스택이 초과될 수 있다.

3. **트리 복원**
   - 전위+중위 또는 후위+중위 순회 결과로 트리 복원이 가능하지만, 중복 키가 있으면 모호성이 생긴다.

4. **직렬화와 null 표현**
   - 트리 저장·복원 시 null 자식 표시 정책이 없으면 원래 구조를 정확히 복원하기 어렵다.

5. **반복 구현**
   - 시스템 환경에서 재귀 제한이 있는 경우 명시적 스택으로 순회를 구현한다.

## 6. 결론

이진트리 순회는 계층 구조를 선형 처리 순서로 바꾸는 기본 방법이다. 기술사 답안에서는 전위·중위·후위 순서를 암기하는 데 그치지 말고, 루트 처리 위치가 정렬 출력, 구조 복원, 삭제, 계산 결과에 어떤 의미를 갖는지 연결해 설명해야 한다.
