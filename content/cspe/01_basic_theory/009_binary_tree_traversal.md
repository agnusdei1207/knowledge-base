## 미리 알고가기

- 루트(Root): 트리나 하위 트리에서 가장 위에 있는 기준 노드임
- 하위 트리(Subtree): 한 노드와 그 자손으로 이루어진 트리임
- 재귀 호출(Recursion): 같은 순회 규칙을 왼쪽·오른쪽 하위 트리에 반복 적용하는 방식임
- 방문(Visit): 노드의 값을 출력·집계하거나 노드를 삭제·직렬화하는 처리 행위임
- 이진 탐색 트리(BST): 왼쪽 키 $<$ 루트 키 $<$ 오른쪽 키 조건으로 중위 순회 시 정렬 결과를 내는 트리임
- 노드 수 $n$·트리 높이 $h$: $n$은 전체 노드 수, $h$는 루트에서 가장 깊은 노드까지의 깊이임
- 직렬화·NULL 표식: 트리 구조를 저장 가능한 순서로 바꾸고 빈 자식 위치를 NULL로 기록하는 방식임
- 편향 트리: 모든 노드가 한쪽으로 이어져 트리 높이가 노드 수와 같아진 구조임

## 작성 근거(검토용)

- **방향성**: 이진 트리 순회는 루트를 언제 방문하는지에 따라 같은 트리에서도 전혀 다른 처리 순서가 나오므로, 목적(직렬화·정렬 출력·집계)에 맞는 순회를 고르고 트리가 깊으면 재귀 대신 반복형으로 전환해 호출 스택 초과를 막아야 함
- **개요 구성**: 루트와 좌·우 하위 트리의 방문 순서를 전위·중위·후위의 구분 기준으로 제시함
- **Ⅱ. 특징 선정**: 방문 시점, $O(n)$ 처리, 높이 기반 공간, 편향 위험은 순회 방식의 공통 비용과 차이를 설명함
- **Ⅲ. 비교축 선정**: 방문 순서, 대표 활용, 활용 전제는 세 순회 방식의 결과 차이를 보여줌
- **Ⅳ. 구조 선정**: 현재 노드·좌우 하위 트리·순회 스택은 재귀 호출이 되돌아갈 위치를 추적하는 데 필요한 최소 구성임
- **Ⅴ. 절차 선정**: NULL 확인·방문·재귀 실행·상위 복귀는 재귀가 방문 순서를 만드는 상태 전이를 설명함
- **BST 조건 명시**: 중위 순회가 항상 정렬을 보장하지 않고 BST에서만 성립하므로 비교표에 조건을 명시함
- **Ⅵ. 실무 사례 선정**: 편향 트리와 복원 정보 누락은 순회 구현 실패 조건이라 메모리·복원 테스트와 연결함
- **전수 검수**: 제목부터 결론까지 용어·표·도식·요약을 대조하고 방문 시점·재귀 깊이 판단축을 일치시킴

## Ⅰ. 개요

- **정의/개념**: 이진 트리 순회는 루트와 좌·우 하위 트리의 방문 순서를 정해 모든 노드를 중복 없이 처리하는 절차임
- **배경/필요성**: 직렬화·정렬 출력·하위 집계 결과를 맞추기 위해 목적별 순회 규칙이 필요함

### 쉽게 이해하기 (학습용)
- 가족 모임에서 부모에게 언제 인사하는지(자녀 만나기 전·사이·후)에 따라 인사 순서가 달라지는 것과 같음

## Ⅱ. 특징

- 루트를 좌·우 하위 트리 처리 전·중간·후 중 언제 방문하는지가 처리 순서를 결정함
- 각 노드를 한 번씩 처리하므로 시간복잡도는 $O(n)$임
- 재귀·명시 스택의 보조 공간은 트리 높이 $h$에 비례함
- 편향 트리는 $h=n$이 되어 재귀 깊이와 메모리 위험이 커짐

### 쉽게 이해하기 (학습용)
- 부모에게 인사하는 타이밍만 바꾸면 전체 방문 순서가 통째로 달라짐
- 가족 한 명 한 명을 딱 한 번씩만 만나므로 인원수만큼만 시간이 걸림
- 줄줄이 한 방향으로만 자식이 이어진 가계도라면 맨 끝까지 갔다 오는 길이 가족 수만큼 길어짐

## Ⅲ. 종류 및 비교

| 판단 기준 | 전위 순회 (Pre-order) | 중위 순회 (In-order) | 후위 순회 (Post-order) |
|:---|:---|:---|:---|
| **방문 순서** | 루트 $\rightarrow$ 왼쪽 $\rightarrow$ 오른쪽 | 왼쪽 $\rightarrow$ 루트 $\rightarrow$ 오른쪽 | 왼쪽 $\rightarrow$ 오른쪽 $\rightarrow$ 루트 |
| **대표 활용** | 트리 구조 직렬화 | BST 오름차순 출력 | 하위 결과 집계 |
| **활용 전제** | NULL 자식 표식 | BST 키 순서 | 자식 결과 선계산 |

> 요약: 직렬화는 전위, BST 오름차순 출력은 중위, 하위 결과 집계는 후위가 적합함.

### 쉽게 이해하기 (학습용)
- 부모부터 인사하는 방식(전위)은 구조를 그대로 옮겨 적기 좋고, 왼쪽부터 훑고 부모를 거쳐 오른쪽으로 가는 방식(중위)은 순서대로 정렬해 보여주기 좋고, 자식들 인사를 다 받고 마지막에 부모에게 가는 방식(후위)은 아래에서 올라온 결과를 모아 정리하기 좋음

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 현재 노드 | 방문 시점을 결정하는 기준 노드 |
| 왼쪽 하위 트리 | 먼저 순회하는 하위 처리 범위 |
| 오른쪽 하위 트리 | 왼쪽 순회 후 처리하는 하위 범위 |
| 순회 스택 | 복귀 위치와 미방문 노드 저장소 |

```text
[ 이진 트리 구조 모델 ]
      (Root)
     /      \
 (Left)    (Right)
```

> 요약: 현재 노드는 좌·우 하위 트리와 연결되며 순회 스택은 재귀 복귀 위치를 저장함.

### 쉽게 이해하기 (학습용)
- 지금 인사할 사람(현재 노드)을 기준으로 왼쪽 가족과 오른쪽 가족을 순서대로 만나고, 다시 돌아갈 자리를 기억해두는 메모(순회 스택)를 들고 다니는 것과 같음

## Ⅴ. 원리 및 절차 흐름도

```text
현재 노드 확인
├─ NULL → 상위 호출로 복귀
└─ 노드 존재 → 순회 규칙에 따라 방문·좌우 호출 → 상위 복귀
```

1. **NULL 확인**: 현재 노드가 없으면 처리를 끝내고 호출한 상위 노드로 복귀함
2. **방문·재귀 실행**: 순회 방식별로 정해진 위치에서 방문을 좌·우 재귀 호출 사이에 끼워 넣음
3. **상위 복귀**: 좌·우 재귀 호출이 모두 끝나면 상위 호출로 복귀해 남은 처리를 이어감

> 요약: 방문을 좌·우 재귀 호출 사이 어디에 두는지가 전위·중위·후위 순서를 정함.

### 쉽게 이해하기 (학습용)
- 만날 사람이 없으면 그 자리에서 돌아서고, 사람이 있으면 정해진 타이밍에 인사하며 왼쪽·오른쪽을 차례로 찾아간 뒤, 다 끝나면 원래 부르러 온 자리로 돌아가는 순서임

## Ⅵ. 실무 사례

1. 인메모리 주문 색인의 범위 출력은 반복형 중위 순회로 키 순서를 보존함
2. 분산 캐시의 트리 상태 스냅샷은 전위 순회에 NULL 자식 표식을 기록해 원래 구조를 복원함

### 쉽게 이해하기 (학습용)
- 정렬된 순서로 목록을 훑어 보여주거나, 가계도를 종이에 통째로 옮겨 적어뒀다가 나중에 그대로 다시 그릴 수 있게 기록해두는 것과 같음

## Ⅶ. 결론

- 이진 트리 순회는 계층 구조를 선형 처리 순서로 바꾸므로 루트 방문 시점을 처리 목적에 맞춰 선택해야 함
- 트리 깊이가 제한되지 않으면 반복형 순회로 호출 스택 초과를 피하고, 출력·삭제·복원 목적에 따라 방문 순서를 고정해야 함

### 쉽게 이해하기 (학습용)
- 큰 가계도를 한 줄로 나열해 적어야 할 때 언제 부모에게 인사할지 미리 정해두면 되지만, 가족이 너무 많으면 종이에 적어가며 도는 방식으로 바꿔야 함
