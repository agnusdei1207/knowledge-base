## Ⅰ. 개요
- **정의**: 다수의 결정 트리를 학습시키고 예측 결과를 취합하여 최종 결과를 도출하는 앙상블 알고리즘임.
- **배경/필요성**: 단일 결정 트리의 문제인 높은 분산(과적합)을 줄이고, 안정적이고 높은 성능을 확보하기 위함.
- **출제 의도**: 부트스트랩 샘플링 원리와 특성 무작위 선택, 앙상블 투표 방식을 평가함.

## Ⅱ. 구성요소
```text
+------------------+       +------------------+       +------------------+
| Bootstrap Data   | ----> | Multiple Trees   | ----> | Majority Vote  |
| (Subset 1..N)    |       | (Random Sub-feat)|       | (Final Output)   |
+------------------+       +------------------+       +------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 부트스트랩 샘플 | 원본 데이터에서 복원 추출하여 만든 여러 훈련 부분집합 | 다양한 연습문제 |
| 무작위 특성 선택| 노드 분기 시 전체 변수 중 일부 변수만 무작위 고려 | 제한된 힌트 제공 |
| 집계 (Aggregate)| 여러 트리의 예측을 다수결 또는 평균으로 결합 | 집단 지성 투표 |

> 요약: 무작위로 샘플링된 데이터와 변수로 여러 트리를 생성하고 결과를 다수결로 결합함.

## Ⅲ. 절차
```text
+-------------+   +-------------+   +-------------+   +-------------+
| 1. 데이터   |-->| 2. 트리별   |-->| 3. 개별     |-->| 4. 앙상블   |
|    샘플링   |   |    특성선택 |   |    학습     |   |    집계결합 |
+-------------+   +-------------+   +-------------+   +-------------+
```
1. **데이터 샘플링**: 원본 데이터셋에서 N개의 부트스트랩 데이터셋을 생성함.
2. **트리별 특성선택**: 각 트리 분할 시 전체 M개 특성 중 무작위 일부만 고려함.
3. **개별 학습**: 생성된 데이터와 특성을 바탕으로 가지치기 없이 트리를 성장시킴.
4. **앙상블 집계결합**: 새 데이터 입력 시 N개 트리 예측을 수합해 다수결로 최종 도출함.

> 요약: 복원 추출된 데이터와 일부 변수만으로 다양한 트리를 훈련한 후 예측을 취합함.

## Ⅳ. 문제점
- **해석력 저하**: 수백 개의 트리가 결합된 포레스트는 블랙박스 모델에 가까워 직관적 해석이 어려움.
- **예측 비용 증가**: 트리 개수가 많아질수록 훈련 시간, 메모리 사용량, 추론 속도가 증가함.

## Ⅴ. 개선방안
- **해석력 저하**: (단기) 변수 중요도(Feature Importance) 확인 / (장기) SHAP 같은 XAI 도구 적용 필요.
- **예측 비용 증가**: (단기) 트리 개수 타협점 모색 / (장기) 병렬 처리 극대화 및 부스팅 전환 필요.

## Ⅵ. 전망
- 정형 데이터 분류/회귀 문제에서 베이스라인 모델로 가장 먼저 시도되는 강력한 알고리즘 지위를 유지할 것임.
