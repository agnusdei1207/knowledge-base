## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 경사 하강법(Gradient Descent)은 **손실 함수 $L(\theta)$의 기울기(Gradient) $\nabla L$의 반대 방향으로 파라미터 $\theta$를 반복 갱신**하여 손실을 최소화하는 최적화 알고리즘이다. $\theta_{t+1} = \theta_t - \eta \nabla L(\theta_t)$. 딥러닝의 학습(Training) = 경사 하강법으로 가중치를 조정하는 과정이다.
> 2. **가치**: 수억 개의 파라미터를 가진 GPT, ResNet 등 현대 AI 모델의 학습은 모두 경사 하강법 변형(Adam, SGD+Momentum)으로 이루어진다. 역전파(Backpropagation)와 결합하여 연쇄 법칙으로 기울기를 계산한다.
> 3. **융합**: 딥러닝(모든 신경망 학습), 추천 시스템(행렬 분해 최적화), 강화학습(정책 경사), 컴퓨터 비전(CNN 학습), NLP(트랜스포머 학습) 등 ML 전 분야의 공통 기반이다.

---

### 🔑 핵심 용어 정리

| 용어 | 뜻 | 비유 |
|:---|:---|:---|
| **손실 함수($L(\theta)$)** | 모델의 예측과 실제값 사이의 차이를 수치화한 함수. MSE, 교차 엔트로피 등 | "시험 오답 수" |
| **기울기($\nabla L$)** | 손실 함수의 편미분 벡터. 각 파라미터 방향으로 손실이 얼마나 변하는지 | "산의 경사도와 방향" |
| **학습률($\eta$)** | 한 번의 갱신에서 이동하는 보폭. 너무 크면 발산, 너무 작으면 수렴 느림 | "걸음의 크기" |
| **SGD(Stochastic GD)** | 전체 데이터 대신 미니배치(랜덤 부분 집합)로 기울기를 추정하여 갱신 | "샘플 몇 개만 보고 방향 결정" |
| **모멘텀(Momentum)** | 이전 기울기의 방향을 관성으로 유지하여 진동을 줄이는 기법 | "공이 굴러가는 관성" |
| **Adam** | 적응적 학습률 + 모멘텀. 파라미터별로 학습률을 자동 조절 | "지형에 맞춰 보폭 조절" |
| **역전파(Backpropagation)** | 연쇄 법칙(Chain Rule)으로 출력→입력 방향으로 기울기를 계산하는 알고리즘 | "오류를 거꾸로 전달" |

## Ⅰ. 개요 및 필요성

- **개념**: 파라미터 $\theta$에 대한 손실 함수 $L(\theta)$의 최솟값을 찾기 위해:

$$
\theta_{t+1} = \theta_t - \eta \nabla_\theta L(\theta_t)
$$

기울기 $\nabla L$은 손실이 가장 가파르게 증가하는 방향이므로, 그 반대 방향($-\nabla L$)으로 이동하면 손실이 줄어든다.

- **필요성**: 선형 회귀는 OLS로 닫힌 형태의 해 $\hat{\beta} = (X^T X)^{-1} X^T y$를 구할 수 있지만, 신경망은 비선형이고 파라미터가 수억 개이므로 닫힌 해가 존재하지 않는다. 경사 하강법이 유일한 실용적 최적화 방법이다.

- **비유**: 경사 하강법은 **"안개 낀 산에서 가장 낮은 곳(계곡)을 찾는 것"**이다. 앞이 보이지 않으므로, 발밑의 경사(기울기)를 느끼고 가장 가파르게 내려가는 방향으로 한 걸음(학습률)씩 이동한다.

```text
+-----------------------------------------------------------------------+
|        경사 하강법의 시각적 이해 (2D 손실 곡면)                       |
+-----------------------------------------------------------------------+
|                                                                       |
|  L(θ)                                                                |
|   │  *  ← 시작점 (랜덤 초기화)                                      |
|   │   \                                                              |
|   │    \  ← 기울기 방향으로 이동                                     |
|   │     \                                                            |
|   │      *                                                           |
|   │       \                                                          |
|   │        \                                                         |
|   │         *    ← 학습률(η)이 보폭                                 |
|   │          \                                                       |
|   │           \_____*  ← 수렴 (기울기 ≈ 0)                          |
|   │                                                                   |
|   └──────────────────────────→ θ                                     |
|                                                                       |
|  θₜ₊₁ = θₜ - η · ∇L(θₜ)                                          |
|                                                                       |
|  ★ η 너무 크면: 계곡을 넘어 발산                                    |
|  ★ η 너무 작으면: 수렴 속도 극도로 느림                             |
|  ★ 지역 최솟값(local min)에 갇힐 수 있음                            |
+-----------------------------------------------------------------------+
```

**[다이어그램 해설]** 손실 곡면에서 랜덤 초기점부터 기울기 반대 방향으로 이동하여 최솟값에 수렴하는 과정이다. 학습률 $\eta$가 보폭을 결정하며, 너무 크면 최솟값을 건너뛰고(발산), 너무 작으면 학습이 지나치게 느려진다.

- **📢 섹션 요약 비유**: 경사 하강법은 "눈 감고 산 내려가기"입니다. 발밑의 기울기(기울기)를 느끼고 가장 가파른 방향으로 한 걸음(학습률)씩 내려갑니다.

## Ⅱ. 아키텍처 및 핵심 원리

### 변형 알고리즘 비교

| 알고리즘 | 갱신 규칙 | 특징 | 비유 |
|:---|:---|:---|:---|
| **Batch GD** | $\theta -= \eta \nabla L_{\text{전체}}$ | 전체 데이터로 정확한 기울기. 느림 | "모든 학생 답안 채점 후 수정" |
| **SGD** | $\theta -= \eta \nabla L_{\text{미니배치}}$ | 랜덤 부분 집합으로 근사. 빠르지만 노이즈 | "몇 명만 채점하고 방향 조정" |
| **Momentum** | $v_t = \gamma v_{t-1} + \eta \nabla L$ | 관성으로 진동 감소, 좁은 계곡 통과 | "공 굴리기" |
| **RMSProp** | 기울기 제곱의 이동 평균으로 학습률 적응 | 파라미터별 학습률 조절 | "경사가 급한 곳은 조심히" |
| **Adam** | Momentum + RMSProp | 가장 널리 사용, 기본 설정으로도 우수 | "자동 보폭 조절 + 관성" |

### 역전파와의 관계

신경망에서 기울기 $\nabla_\theta L$을 구하려면 연쇄 법칙(Chain Rule)으로 출력→입력 방향으로 계산한다:

$$
\frac{\partial L}{\partial w_1} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial h} \cdot \frac{\partial h}{\partial w_1}
$$

이것이 역전파(Backpropagation)이며, 1986년 Rumelhart가 재발견한 이후 딥러닝의 핵심 알고리즘이 되었다.

- **📢 섹션 요약 비유**: Adam은 "지형에 맞춰 걸음 크기를 자동 조절하는 등산화"입니다. 급경사에서는 조심히, 평지에서는 빠르게 걸어갑니다.

## Ⅲ. 비교 및 연결

### 비교 1: Batch GD vs SGD vs Mini-batch SGD

| 비교 항목 | Batch GD | SGD (1개) | Mini-batch SGD |
|:---|:---|:---|:---|
| **기울기 정확도** | 정확 | 노이즈 큼 | 중간 |
| **수렴 속도** | 느림 | 빠르지만 불안정 | 실용적 최적 |
| **메모리** | 전체 데이터 로드 | $O(1)$ | 배치 크기만큼 |
| **병렬화** | GPU 활용 어려움 | 불가 | ✅ GPU 최적화 |
| **실무 사용** | 드묾 | 드묾 | **기본 선택** |

### 과목 융합 관점
- **딥러닝**: PyTorch의 `loss.backward()` = 역전파, `optimizer.step()` = 경사 하강법 1회
- **강화학습**: 정책 경사(Policy Gradient)는 보상의 기대값에 대한 기울기로 정책을 갱신한다
- **분산 학습**: 데이터 병렬(Data Parallel)은 여러 GPU에서 미니배치를 나눠 기울기를 계산한 뒤 AllReduce로 평균한다

## Ⅳ. 실무 적용 및 기술사 판단

### 실무 시나리오

1. **시나리오 — GPT 학습**: GPT-4는 수조 토큰의 텍스트로 수천억 파라미터를 학습한다. Adam 옵티마이저 + 코사인 학습률 스케줄 + 미니배치 크기 수백만으로, 수천 GPU에서 분산 경사 하강법을 수행한다.

2. **시나리오 — 학습률 스케줄링**: 초기 $\eta = 10^{-3}$에서 시작하여 워밍업(linear warmup) → 코사인 감쇠로 $\eta$를 점차 줄인다. 이 방식이 고정 학습률보다 최종 성능을 1~3% 향상시킨다.

### 안티패턴
- **학습률 고정**: $\eta$가 처음부터 끝까지 같으면, 초기에는 느리고(너무 작음) 후기에는 진동한다(너무 큼). 반드시 스케줄링이 필요하다.
- **기울기 소실/폭발**: 깊은 신경망에서 기울기가 층을 거칠수록 0에 수렴(소실)하거나 무한대(폭발)로 발산한다. BatchNorm, 잔차 연결(Skip Connection), 기울기 클리핑으로 대응한다.

### 참고 표준
- **Cauchy (1847)**: 경사 하강법 최초 제안
- **Kingma & Ba (2015)**: "Adam: A Method for Stochastic Optimization" — 가장 인용이 많은 옵티마이저 논문

경사 하강법은 현대 AI의 "엔진"이다. GPT, DALL-E, AlphaFold — 모든 혁신적 모델은 경사 하강법으로 학습되었으며, 학습률·옵티마이저·스케줄링의 선택이 모델 성능을 좌우한다.
