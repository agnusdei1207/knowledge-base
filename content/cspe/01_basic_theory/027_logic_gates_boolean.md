## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 이진 입력에 대해 논리 연산(AND·OR·NOT 등)을 수행하는 기본 회로 소자이며, 부울 대수는 이를 수학적으로 기술하는 체계임 |
| **배경/필요성** | 모든 디지털 회로의 기본 구성 단위이며, 부울 대수를 통한 논리식 간소화가 회로 최적화의 핵심임 |
| **출제 의도** | 기본 게이트의 동작과 부울 대수 법칙을 활용한 논리식 간소화를 수행할 수 있는지 평가함 |

## Ⅱ. 구성요소
```
+----------+     +----------+     +----------+
|   AND    | --> |   OR     | --> |   NOT    |
| (논리곱) |     | (논리합) |     | (부정)   |
+----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| AND 게이트 | 모든 입력이 1일 때만 출력 1임(논리곱) | 직렬 스위치 |
| OR 게이트 | 입력 중 하나라도 1이면 출력 1임(논리합) | 병렬 스위치 |
| NOT 게이트 | 입력을 반전하여 출력함(인버터) | 반대로 뒤집기 |

> 요약: AND·OR·NOT 3개 기본 게이트로 모든 논리 함수를 구성할 수 있음(기능적 완전성).

## Ⅲ. 절차
```
+------------+     +------------+
| 진리표작성  | --> | 부울식도출 |
| (입출력)   |     | (SOP/POS) |
+------------+     +------------+
                        |
+------------+     +----+-------+
| 회로구현   | <-- | 간소화    |
| (게이트연결)|    | (카르노맵) |
+------------+     +------------+
```

1. 진리표 작성: 모든 입력 조합에 대한 출력값을 나열함
2. 부울식 도출: 출력이 1인 행을 AND로 묶어 SOP(Sum of Products) 형태를 구함
3. 간소화: 카르노 맵·퀸-맥클러스키 알고리즘으로 최소 항 논리식을 도출함
4. 회로 구현: 간소화된 부울식을 게이트로 변환하여 디지털 회로를 설계함

> 요약: 진리표 → SOP/POS → 간소화 → 게이트 구현으로 논리 회로를 설계함.

## Ⅳ. 문제점
- 카르노 맵 한계: 5변수 이상에서 시각적 간소화가 어려움
- 게이트 지연: 게이트 단수가 많아지면 전파 지연(Propagation Delay)이 증가함
- 팬아웃 제한: 하나의 게이트 출력이 구동할 수 있는 입력 수에 물리적 한계가 있음

## Ⅴ. 개선방안
- (단기) 퀸-맥클러스키: 5변수 이상의 논리식도 체계적으로 간소화하는 알고리즘을 적용함
- (중기) NAND/NOR 변환: 모든 게이트를 NAND 또는 NOR만으로 구현하여 제조를 단순화함
- (장기) EDA 도구: 합성(Synthesis) 도구가 자동으로 최적 게이트 네트리스트를 생성함

## Ⅵ. 전망
- FPGA·ASIC 설계에서 EDA 기반 자동 합성이 표준이며, AI 기반 논리 합성 최적화가 차세대 칩 설계의 핵심 기술로 부상할 전망임
