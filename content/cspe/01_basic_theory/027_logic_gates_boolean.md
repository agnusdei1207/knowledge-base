## 미리 알고가기

- 부울 변수: 0 또는 1의 두 값만 갖는 논리 변수임
- 진리표: 모든 입력 조합과 출력 결과를 표로 나열한 논리 명세임
- 기본 게이트: AND, OR, NOT처럼 부울 연산을 회로로 구현한 소자임
- 범용 게이트: NAND 또는 NOR만으로 모든 논리 함수를 구현할 수 있는 게이트임
- 드모르간 법칙: 논리곱과 논리합의 부정을 서로 변환하는 부울 대수 법칙임
- 카르노 맵: 진리표의 인접 항을 묶어 논리식을 최소화하는 도구임

## Ⅰ. 개요

- **정의/개념**: 논리 게이트와 부울 대수는 0과 1의 논리 관계를 수식과 회로로 표현해 디지털 시스템의 판단 조건을 구현하는 기초 체계임
- **배경/필요성**: 논리를 물리 회로로 단순하게 변환하기 위해 불 대수와 논리 게이트 체계가 필요함

## Ⅱ. 특징

- 디지털 판단 조건은 부울 변수와 진리표로 명세함
- 부울 대수 법칙을 적용하면 같은 기능을 더 적은 게이트로 구현함
- NAND와 NOR는 범용 게이트이므로 공정 라이브러리와 회로 최적화에 유리함
- 논리식이 같아도 실제 회로에서는 전파 지연과 글리치가 출력 신뢰성을 좌우함

## Ⅲ. 종류 및 비교

| 게이트 | 논리식 | 출력 조건 | 주요 활용 |
|:---|:---|:---|:---|
| AND | $Y = A \cdot B$ | 모든 입력이 1일 때 1 | 조건 동시 만족 |
| OR | $Y = A + B$ | 하나 이상 1일 때 1 | 조건 중 하나 만족 |
| NOT | $Y = \overline{A}$ | 입력을 반전함 | 신호 반전 |
| NAND | $Y = \overline{A \cdot B}$ | AND 결과를 반전함 | 범용 게이트 구현 |
| NOR | $Y = \overline{A + B}$ | OR 결과를 반전함 | 범용 게이트 구현 |
| XOR | $Y = A \oplus B$ | 입력이 서로 다를 때 1 | 덧셈, 패리티 |

> 요약: 기본 게이트는 논리 의미를 만들고, 범용 게이트는 실제 회로 구현의 표준 단위가 됨.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 입력 변수 | 회로가 판단할 0 또는 1의 조건 신호임 |
| 진리표 | 요구 기능을 모든 입력 조합별 출력으로 고정함 |
| 부울식 | 진리표를 SOP 또는 POS 형태의 수식으로 표현함 |
| 최소화 도구 | 부울 법칙이나 카르노 맵으로 중복 항을 제거함 |
| 게이트 네트워크 | 최소화된 식을 실제 게이트 연결로 구현함 |

```text
+----------+     +----------+     +----------+     +----------+
| 기능 명세  | --> | 진리표 작성  | --> | 부울식 도출 | --> | 게이트 구현 |
+----------+     +----------+     +----------+     +----------+
```

> 요약: 요구 기능은 진리표와 부울식을 거쳐 실제 게이트 네트워크로 구현됨.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 조건 정의  | --> | 수식 도출  | --> | 논리 최소화 | --> | 셀 매핑    |
+----------+     +----------+     +----------+     +----------+
```

1. **사양 정의**: 입력 조건과 원하는 출력값을 모든 조합별로 정리함
2. **수식 도출**: 출력이 1인 항은 SOP, 0인 항은 POS 형태로 표현함
3. **논리 최소화**: 부울 대수와 카르노 맵으로 불필요한 항을 제거함
4. **회로 매핑**: 표준 셀과 범용 게이트로 구현하고 지연을 검토함

> 요약: 논리 설계는 기능 명세뿐 아니라 최소화와 회로 지연 검토까지 포함해야 함.

## Ⅵ. 실무 적용 및 유의점

1. 반도체 설계는 논리식을 직접 배치하지 않고 표준 셀로 합성하므로 면적, 전력, 지연 제약을 함께 주고 타이밍 리포트로 결과를 확인함
2. 다단 게이트는 경로 지연 차이로 글리치 위험이 커지므로 해저드 항을 보강하거나 레지스터로 샘플링하고 파형 시뮬레이션으로 검증함

## Ⅶ. 결론

- 논리 게이트와 부울 대수는 디지털 판단을 회로로 바꾸는 언어이므로, 수식 최소화와 물리적 타이밍을 함께 검토해야 정확한 하드웨어 구현이 가능함

## 작성 근거(검토용)

- 개요는 논리 수식과 물리 게이트의 연결을 먼저 제시해 회로 구현 관점으로 정리함
- 특징은 명세, 최소화, 범용 게이트, 물리 지연을 순서대로 배치해 추상 논리와 실제 회로의 차이를 드러냄
- Ⅲ은 AND/OR/NOT과 NAND/NOR/XOR를 함께 비교해 기본 의미와 구현 가치를 동시에 보여줌
- Ⅳ와 Ⅴ는 요구 사양이 진리표, 수식, 게이트로 변환되는 흐름을 답안지 구조에 맞춤
- 실무 유의점은 표준 셀 합성과 글리치 검증처럼 논리식만으로 놓치기 쉬운 물리 조건을 남김
