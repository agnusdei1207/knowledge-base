## Ⅰ. 개요
- **정의**: 레이블이 없는 데이터들을 특징이 유사한 그룹(클러스터)으로 묶는 비지도 학습 기법임.
- **배경/필요성**: 고객 세분화, 이상 탐지 등 데이터 내의 숨겨진 패턴과 구조를 파악하기 위해 필요함.
- **출제 의도**: 거리 기반(K-Means)과 밀도 기반(DBSCAN) 군집화의 원리와 각각의 장단점을 구분할 수 있는지 평가함.

## Ⅱ. 구성요소
```text
+------------------+       +------------------+       +------------------+
| Raw Data Points  | ----> | Clustering Algo  | ----> | Formed Clusters  |
| (Unlabeled)      |       | (K-Means/DBSCAN) |       | (Group A, B, C)  |
+------------------+       +------------------+       +------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 데이터 포인트 | 군집화의 대상이 되는 개별 객체들 | 밤하늘의 별들 |
| 유사도 척도 | 유사성을 판단하는 기준 (거리, 밀도 등) | 별자리 잇는 기준 |
| 클러스터 (군집) | 유사한 특성을 가진 데이터들의 집합 | 별자리 |

> 요약: 유사도 척도(거리/밀도)를 기준으로 레이블 없는 데이터들을 여러 군집으로 분류함.

## Ⅲ. 절차
```text
+-------------+   +-------------+   +-------------+   +-------------+
| 1. 데이터   |-->| 2. 알고리즘 |-->| 3. 군집화   |-->| 4. 결과     |
|    입력     |   |    선택     |   |    수행     |   |    평가     |
+-------------+   +-------------+   +-------------+   +-------------+
```
1. **데이터 입력**: 군집화할 원시 데이터를 수집하고 스케일링 등 전처리를 수행함.
2. **알고리즘 선택**: 데이터 분포(원형, 비정형)에 따라 K-Means, DBSCAN 등을 선택함.
3. **군집화 수행**: 중심점 이동(K-Means) 또는 밀도 연결(DBSCAN)을 통해 클러스터를 형성함.
4. **결과 평가**: 실루엣 점수(Silhouette Score) 등을 활용하여 군집의 응집도와 분리도를 평가함.

> 요약: 데이터 전처리 후 적절한 알고리즘을 적용하여 클러스터를 생성하고 품질을 평가함.

## Ⅳ. 문제점
- **K-설정 문제 (K-Means)**: 최적의 군집 수(K)를 사전에 알기 어려우며, K값에 따라 결과가 크게 달라짐.
- **밀도 차이 문제 (DBSCAN)**: 데이터 밀도가 클러스터마다 크게 다를 경우 군집화 성능이 저하됨.

## Ⅴ. 개선방안
- **K-설정 문제**: (단기) 엘보우 메서드(Elbow Method)로 적정 K 탐색 / (장기) 계층적 군집화 등 사전 K 설정이 불필요한 방식 도입 필요.
- **밀도 차이 문제**: (단기) 파라미터(eps, minPts) 미세조정 / (장기) OPTICS 알고리즘 등 다양한 밀도에 강건한 기법 적용 필요.

## Ⅵ. 전망
- 추천 시스템과 고객 분석 등에서 지속 활용되며, 딥러닝 임베딩과 결합한 심층 클러스터링으로 발전할 것임.
