## Ⅰ. 개요
- **정의**: 이전 스텝의 은닉 상태를 다음 스텝의 입력으로 다시 순환시켜 시계열 데이터를 처리하는 모델임.
- **배경/필요성**: 자연어, 음성 등 연속된 입력 데이터의 순서와 문맥적 맥락(Context)을 기억하기 위해 필요함.
- **출제 의도**: 기본 RNN의 장기 의존성 문제와 이를 해결하기 위한 LSTM/GRU의 게이트 메커니즘을 평가함.

## Ⅱ. 구성요소
```text
+------------------+       +------------------+       +------------------+
| Input x_t        | ----> | RNN Cell         | ----> | Output y_t       |
| Prev Hidden h_t-1|       | (Tanh / Gates)   |       | Next Hidden h_t  |
+------------------+       +------------------+       +------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 은닉 상태 (h_t) | 과거 시점부터 현재까지의 정보를 요약한 벡터 | 기억 메모리 |
| LSTM 게이트 | 정보의 유지, 삭제, 추가를 제어 | 지능형 메모리 밸브 |
| GRU | LSTM을 경량화하여 업데이트/리셋 게이트만 사용 | 간소화된 밸브 |

> 요약: 내부 상태를 통해 과거 정보를 유지하며, LSTM/GRU는 게이트를 통해 기억을 제어함.

## Ⅲ. 절차
```text
+-------------+   +-------------+   +-------------+   +-------------+
| 1. t시점    |-->| 2. 이전상태 |-->| 3. 셀 연산  |-->| 4. 상태/    |
|    입력     |   |    결합     |   |    (게이트) |   |    출력갱신 |
+-------------+   +-------------+   +-------------+   +-------------+
```
1. **t시점 입력**: 문장의 단어나 시계열의 현재 스텝 데이터(x_t)를 입력 받음.
2. **이전상태 결합**: 직전 스텝에서 전달된 은닉 상태(h_t-1)와 현재 입력을 결합함.
3. **셀 연산(게이트)**: 게이트 연산을 통해 불필요한 과거는 잊고 새 정보를 추가함.
4. **상태/출력갱신**: 업데이트된 은닉 상태(h_t)를 다음 스텝으로 넘기고 출력(y_t)을 반환함.

> 요약: 순차적 입력을 이전 상태와 결합하여 내부 상태를 갱신하며 전체 시퀀스를 처리함.

## Ⅳ. 문제점
- **장기 의존성 문제**: 시퀀스가 길어지면 초기 정보가 역전파를 거치며 소실됨.
- **병렬 처리 불가**: 이전 스텝의 계산이 끝나야 다음을 진행할 수 있어 속도가 느림.

## Ⅴ. 개선방안
- **장기 의존성 문제**: (단기) LSTM이나 GRU 구조 사용 / (장기) Attention 메커니즘 추가 필요.
- **병렬 처리 불가**: (단기) 시퀀스 길이를 잘라 학습 / (장기) 트랜스포머 아키텍처로 대체 필요.

## Ⅵ. 전망
- 자연어 처리 주류에서는 트랜스포머에 밀렸으나, 스트리밍 환경 등 저지연 분야에서는 유효함.
