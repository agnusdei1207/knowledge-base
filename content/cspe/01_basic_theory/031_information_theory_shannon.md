## Ⅰ. 개요
- **정의**: 메시지의 불확실성을 정량화하고, 채널이 전달할 수 있는 정보량의 상한을 규정하는 수학적 체계
- **배경/필요성**: 통신 시스템 설계 시 "얼마나 압축할 수 있는가"와 "얼마나 빠르게 보낼 수 있는가"의 한계를 모르면 자원을 과잉·과소 할당하게 됨
- **비유**: 주사위 눈을 맞추는 퀴즈에서, 면이 많을수록(불확실성↑) 정답을 알려주는 데 더 많은 질문(비트)이 필요한 것과 같음

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 엔트로피 공식의 의미 이해 | H = -Σ p(x) log₂ p(x) 가 "평균 정보량"임을 서술 | log 밑이 2일 때 단위가 bit임을 명시 |
| 소스 코딩과 채널 코딩 구분 | 소스 코딩 정리 → 압축 한계, 채널 코딩 정리 → 전송 한계 | 두 정리를 혼동하지 않도록 분리 기술 |
| 채널 용량 C의 정의 | C = max I(X;Y), 노이즈 채널에서도 오류 0 전송 가능 조건 | R < C 조건을 빠뜨리지 않을 것 |

> 요약: 정보 엔트로피로 불확실성을 측정하고, 채널 용량으로 신뢰성 있는 전송의 상한을 규정하는 이론임

## Ⅱ. 구성요소
```text
정보원(Source)
    |
    v
소스 코딩(압축) --- 엔트로피 H가 압축 한계
    |
    v
채널 코딩(오류제어) --- 채널 용량 C가 전송 한계 (034 참조)
    |
    v
채널(Channel) --- 노이즈 추가
    |
    v
복호기(Decoder)
    |
    v
수신자(Sink)
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 정보 엔트로피 H | H = -Σ p(x) log₂ p(x), 확률 분포의 평균 불확실성(bit) | 동전 던지기(공정)의 H = 1 bit |
| 상호 정보량 I(X;Y) | 수신 신호 Y가 원본 X에 대해 제공하는 정보량 | 힌트를 들었을 때 줄어드는 불확실성 |
| 채널 용량 C | C = max I(X;Y), 입력 분포를 최적화했을 때 달성 가능한 최대 상호 정보량 | 도로의 최대 차선 수 |
| 소스 코딩 정리 | 평균 부호 길이의 하한이 H임을 보장 (032 참조) | 짐을 H보다 더 작은 가방에 넣을 수 없음 |
| 채널 코딩 정리 | R < C이면 오류 확률을 0에 수렴시키는 부호가 존재함 | 속도 제한 이하로 달리면 사고 없이 도착 가능 |

> 요약: 엔트로피·상호 정보량·채널 용량이 압축과 전송의 이론적 한계를 결정함

## Ⅲ. 절차
```text
1.확률 모델링 --> 2.엔트로피 계산 --> 3.채널 모델링 --> 4.부호 설계
```
- 1단계: **확률 모델링** — 정보원의 심볼별 출현 확률 p(x)를 추정함
- 2단계: **엔트로피 계산** — H = -Σ p(x) log₂ p(x)로 평균 정보량을 산출, 소스 코딩 한계를 확인함
- 3단계: **채널 모델링** — 노이즈 특성을 조건부 확률 p(y|x)로 모델링하고 채널 용량 C를 산출함
- 4단계: **부호 설계** — 소스 코딩(032 허프만 등)으로 H에 근접하게 압축하고, 채널 코딩(030 해밍 등)으로 R < C 조건 하에 오류를 제어함

> 요약: 확률 추정 → 엔트로피/용량 산출 → 한계 이내에서 부호를 설계하는 순서임

## Ⅳ. 문제점
- **엔트로피 추정 오차**: 실측 확률 분포가 정보원의 실제 분포와 다를 경우 압축 한계를 과대·과소 추정하여 부호 효율이 저하됨
- **채널 모델 불일치**: 실제 채널의 노이즈가 시변(time-varying)이면 고정 모델 기반 용량 C가 현실을 반영하지 못해 오류율이 증가함
- **부호 길이 유한성**: 이론은 무한 블록 길이를 가정하나 실제 시스템은 유한 길이를 사용하므로 이론적 한계와 실제 성능 사이에 갭이 발생함

> 요약: 확률 추정 오차, 채널 모델 변동, 유한 블록 길이가 이론과 실제 간 괴리를 만듦

## Ⅴ. 개선방안
1. 단기: 적응형 확률 추정(슬라이딩 윈도우 기반) 도입으로 엔트로피 추정 정확도를 향상시킴
2. 중기: 적응형 변조·코딩(AMC) 적용으로 시변 채널에 실시간 대응하여 용량 활용률을 높임
3. 장기: Polar Code·LDPC 등 용량 달성 부호를 활용하여 유한 블록 길이에서도 이론적 한계에 근접시킴

> 요약: 적응형 추정, 적응형 채널 코딩, 용량 달성 부호 순서로 이론-실제 갭을 축소함

## Ⅵ. 전망
- 발전 방향: 양자 정보이론으로 확장되어 큐비트 채널의 용량 한계를 규정하는 연구가 진행 중임
- 기술사적 판단: 5G/6G 통신에서 채널 용량에 근접하는 부호 설계가 핵심 경쟁력이며, 정보이론은 시스템 설계의 판단 기준으로 지속 활용됨
- 기술사 제언: 소스 코딩 한계와 채널 코딩 한계를 분리하여 각각의 최적화 목표를 명확히 설정할 것을 권고함
