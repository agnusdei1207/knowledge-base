## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 정보이론(Information Theory)은 Claude Shannon이 1948년에 창시한 수학적 체계로, **정보량을 엔트로피(Entropy)**로 측정하고, 잡음 있는 채널에서 **오류 없이 전송할 수 있는 최대 전송률(채널 용량, Channel Capacity)**을 증명했다. 섀넌 한계는 "이 이상은 물리적으로 불가능하다"는 이론적 상한이다.
> 2. **가치**: 데이터 압축(무손실 압축의 이론적 한계 = 엔트로피), 채널 코딩(오류 정정 코드의 성능 한계 = 채널 용량), 암호학(완전 비밀의 조건), 머신러닝(교차 엔트로피 손실함수) 등 CS 전 분야의 **이론적 기초**를 제공한다.
> 3. **융합**: 통신(5G 채널 코딩은 섀넌 한계의 99% 달성), 압축(허프만/산술 코딩), 보안(OTP 완전 비밀 증명), AI(정보 이득, KL 발산, 교차 엔트로피), 생물학(DNA 정보 용량) 등 정보를 다루는 모든 분야에 적용된다.

---

## Ⅰ. 개요 및 필요성

- **개념**: 엔트로피 H(X) = -Σ p(x) log₂ p(x)는 확률 변수 X의 **평균 정보량(비트)**이다. 동전 던지기(H=1비트)부터 영어 알파벳(H≈4.7비트)까지, 예측 가능성이 낮을수록 엔트로피가 높다. 채널 용량 C = max I(X;Y) = B log₂(1 + SNR) (Shannon-Hartley)는 대역폭 B(Hz)와 신호 대 잡음비(SNR)로 결정되는 이론적 최대 전송률(bps)이다.

- **필요성**: 엔트로피는 **무손실 압축의 이론적 한계**이다. 영어 텍스트의 엔트로피가 글자당 약 1.5비트이므로, ASCII(8비트)보다 5배 이상 압축 가능함을 알 수 있다. 채널 용량은 통신 시스템 설계의 목표치를 제시한다.

- **비유**: 엔트로피는 **"놀라움의 평균"**이다. 매일 해가 뜨는 것(놀라움 낮음, 정보량 낮음)과 6면 주사위의 결과(놀라움 중간)와 로또 당첨(놀라움 극대, 정보량 극대)을 비교하면, 예측이 어려울수록 정보량이 크다.

- **등장 배경 및 발전 과정**:
  1. **1928년**: Ralph Hartley가 정보량의 로그 척도(Hartley 함수)를 제안했다.
  2. **1948년**: Claude Shannon이 "A Mathematical Theory of Communication"을 발표하여 정보이론을 창시했다. 엔트로피, 채널 용량, 소스 코딩/채널 코딩 정리를 증명했다.
  3. **현대**: 5G NR의 LDPC/Polar 코드는 섀넌 한계의 99%에 도달했다. 양자 정보이론이 양자 통신·양자 암호의 기초를 제공한다.

```text
+-----------------------------------------------------------------------+
|        엔트로피 — 정보량의 수학적 정의                                |
+-----------------------------------------------------------------------+
|                                                                       |
|  H(X) = -Σ p(xᵢ) × log₂ p(xᵢ)  (비트 단위)                        |
|                                                                       |
|  예시 1: 공정한 동전 (앞/뒤 각 50%)                                  |
|  H = -(0.5 × log₂ 0.5 + 0.5 × log₂ 0.5) = 1 비트                  |
|  → 1비트로 결과를 완전히 표현 가능                                   |
|                                                                       |
|  예시 2: 편향된 동전 (앞 90%, 뒤 10%)                                |
|  H = -(0.9 × log₂ 0.9 + 0.1 × log₂ 0.1) ≈ 0.47 비트               |
|  → 예측 가능성↑ → 정보량↓ → 압축 가능                              |
|                                                                       |
|  예시 3: 6면 주사위 (각 1/6)                                         |
|  H = -6 × (1/6 × log₂ 1/6) = log₂ 6 ≈ 2.58 비트                   |
|                                                                       |
|  ★ 엔트로피 최대 = 모든 결과가 동일 확률일 때                       |
|  ★ 엔트로피 = 무손실 압축의 이론적 하한                             |
+-----------------------------------------------------------------------+
```

**[다이어그램 해설]** 엔트로피는 확률 분포의 "불확실성 측도"이다. 공정한 동전은 결과가 완전히 불확실하므로 H=1비트(최대). 편향된 동전(90/10)은 거의 앞면이 나올 것을 예측할 수 있으므로 H≈0.47비트. 이는 편향된 동전의 결과를 평균 0.47비트로 표현(압축)할 수 있다는 의미이다. 허프만 코딩은 이 엔트로피에 근접하는 압축을 달성한다.

- **📢 섹션 요약 비유**: 엔트로피는 "퀴즈의 난이도"입니다. 정답이 뻔한 퀴즈(편향 동전)는 정보량이 적고, 정답을 전혀 모르는 퀴즈(공정 주사위)는 정보량이 큽니다.

## Ⅱ. 아키텍처 및 핵심 원리

### 구성 요소

| 요소명 | 수식 | 의미 | 응용 | 비유 |
|:---|:---|:---|:---|:---|
| **엔트로피 H(X)** | -Σ p log₂ p | 평균 정보량 | 압축 한계 | 놀라움의 평균 |
| **조건부 엔트로피 H(X\|Y)** | -Σ p(x,y) log₂ p(x\|y) | Y를 알 때 X의 불확실성 | 채널 잡음 | 힌트 후 놀라움 |
| **상호 정보량 I(X;Y)** | H(X) - H(X\|Y) | X와 Y가 공유하는 정보 | 채널 용량 | 힌트의 가치 |
| **채널 용량 C** | max I(X;Y) | 오류 없는 최대 전송률 | 통신 설계 목표 | 도로 최대 차선 |
| **KL 발산 D(P\|\|Q)** | Σ p log(p/q) | 두 분포 간 거리 | ML 손실함수 | 예측 오차 |

### 섀넌 정리 — 소스 코딩과 채널 코딩

```text
+-----------------------------------------------------------------------+
|        섀넌의 두 가지 근본 정리                                       |
+-----------------------------------------------------------------------+
|                                                                       |
|  [소스 코딩 정리 (제1정리)]                                          |
|  무손실 압축의 평균 코드 길이 ≥ 엔트로피 H(X)                       |
|  → H(X) 미만으로는 절대 압축 불가                                   |
|  → 허프만/산술 코딩이 H(X)에 근접                                   |
|                                                                       |
|  [채널 코딩 정리 (제2정리)]                                          |
|  전송률 R < C(채널 용량)이면, 적절한 코딩으로                        |
|  오류 확률을 원하는 만큼 낮출 수 있다                                |
|  R > C이면, 오류 없는 전송은 불가능                                  |
|                                                                       |
|  채널 용량 (AWGN 채널):                                               |
|  C = B × log₂(1 + SNR) [bps]                                        |
|                                                                       |
|  예시: B=20MHz, SNR=100(20dB)                                        |
|  C = 20×10⁶ × log₂(101) ≈ 133 Mbps                                 |
|  → 이론적으로 133Mbps까지 오류 없이 전송 가능                       |
+-----------------------------------------------------------------------+
```

**[다이어그램 해설]** 소스 코딩 정리는 "압축의 한계"를 정하고, 채널 코딩 정리는 "전송의 한계"를 정한다. 두 정리 모두 존재 정리(가능성을 증명)이지 구성 정리(방법을 제시)가 아니다. 허프만 코딩은 소스 코딩 정리의 한계에 근접하고, LDPC/Polar 코드는 채널 코딩 정리의 한계(섀넌 한계)에 근접한다.

- **📢 섹션 요약 비유**: 소스 코딩 정리는 "이 가방(데이터)은 최소 이 크기(엔트로피)까지만 줄일 수 있다"이고, 채널 코딩 정리는 "이 도로(채널)에 최대 이 차량(데이터)까지만 오류 없이 통과 가능하다"입니다.

## Ⅲ. 비교 및 연결

### 비교 1: 소스 코딩 vs 채널 코딩

| 비교 항목 | 소스 코딩 (압축) | 채널 코딩 (오류 정정) |
|:---|:---|:---|
| **목적** | 중복 제거 → 크기 줄이기 | 중복 추가 → 오류 극복 |
| **방향** | 중복 감소 | 중복 증가 (의도적) |
| **한계** | 엔트로피 (H) | 채널 용량 (C) |
| **예시** | 허프만, LZW, gzip | 해밍, RS, LDPC, Turbo |
| **비유** | 짐 압축 | 보험 가입 |

### 과목 융합 관점
- **AI/ML**: 교차 엔트로피(Cross-Entropy) 손실함수는 모델 예측 분포 Q와 실제 분포 P 사이의 엔트로피이다. H(P,Q) = -Σ p log q. KL 발산은 H(P,Q) - H(P)이다.
- **보안**: Shannon의 완전 비밀(Perfect Secrecy) 정리: 키 길이 ≥ 메시지 길이일 때만 정보이론적으로 해독 불가능하다(OTP).
- **데이터베이스**: 정보 이득(Information Gain = 엔트로피 감소)이 의사결정 트리의 분기 기준이다.

- **📢 섹션 요약 비유**: 소스 코딩은 "짐을 최대한 압축하기"이고, 채널 코딩은 "깨질 수 있는 짐에 뽁뽁이(보호재)를 감싸기"입니다. 둘은 정반대 방향이지만 같은 이론(정보이론)에서 나옵니다.

## Ⅳ. 실무 적용 및 기술사 판단

### 실무 시나리오

1. **시나리오 — 5G NR 채널 코딩**: 5G 데이터 채널은 LDPC 코드, 제어 채널은 Polar 코드를 사용한다. 두 코드 모두 섀넌 한계의 99% 이상에 도달하여 주어진 대역폭에서 이론적 최대에 가까운 전송률을 달성한다.

2. **시나리오 — 동영상 압축(H.265)**: 프레임 간 차이(잔차)의 엔트로피가 낮을수록 압축률이 높아진다. 움직임 보상(Motion Compensation)은 잔차의 엔트로피를 낮추는 기법이다.

### 안티패턴
- **엔트로피 미만 압축 시도**: ZIP으로 이미 압축된 파일을 다시 ZIP하면 크기가 줄지 않는다. 이미 엔트로피에 근접했기 때문이다.

- **📢 섹션 요약 비유**: 이미 말린 빨래를 다시 건조기에 넣어도 더 마르지 않는 것처럼, 엔트로피까지 압축된 데이터는 더 줄일 수 없습니다.

| 구분 | 정보이론 미적용 | 정보이론 적용 | 개선 효과 |
|:---|:---|:---|:---|

| **정성** | "이 압축이 최선인가?" | "엔트로피 대비 95%이므로 거의 최적" | 설계 확신 |

### 참고 표준
- **Shannon, C.E. (1948)**: "A Mathematical Theory of Communication" — 정보이론 원논문
- **3GPP TS 38.212**: 5G NR 채널 코딩 사양

정보이론은 "정보를 측정하고, 압축하고, 전송하는 것의 이론적 한계"를 제시한다. 엔트로피와 채널 용량이라는 두 축으로 모든 통신·압축·암호 시스템의 성능 상한을 정의하며, 현대 기술은 이 한계에 계속 근접하고 있다.

### 👶 어린이를 위한 3줄 비유 설명

1. 정보이론은 "놀라움을 숫자로 재는 것"이에요. 해가 뜨는 건 안 놀라우니까 정보량이 적고, 로또 당첨은 엄청 놀라우니까 정보량이 크대요.
2. 엔트로피는 "평균 놀라움"이에요. 동전 던지기는 1비트, 주사위는 약 2.6비트의 평균 놀라움이 있어요.
3. 섀넌 아저씨가 "이 전화선으로 초당 최대 이만큼의 놀라움(정보)만 보낼 수 있다"는 한계를 알려줬어요!
