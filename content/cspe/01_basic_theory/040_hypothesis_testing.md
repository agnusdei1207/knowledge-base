## 미리 알고가기

- 귀무가설 H0: 차이 또는 효과가 없다고 두는 기본 가설임
- 대립가설 H1: 연구자가 확인하려는 차이 또는 효과가 있다는 가설임
- 유의수준 alpha: H0가 참인데도 기각할 허용 오류 확률임
- p-value: H0가 참일 때 관측값 이상으로 극단적인 결과가 나올 확률임
- 신뢰구간: 반복 표본 추출에서 일정 비율로 참 모수를 포함하도록 만든 추정 구간임

## Ⅰ. 개요

- **정의**: 가설 검정은 표본 데이터가 귀무가설 하에서 얼마나 극단적인지 p-value와 유의수준 기준으로 판단하는 통계 추론 절차이고, 신뢰 구간은 표본으로부터 모수가 있을 법한 범위를 제시해 효과의 크기와 불확실성을 함께 판단하기 위해 사용함.
- **배경/필요성**: A/B 테스트, 품질 관리, 성능 개선 실험에서는 관측 차이가 우연인지 실제 효과인지 구분해야 하므로 검정 절차와 추정 구간을 함께 제시해야 함.
- **비유**: 피고인의 무죄를 기본값으로 두고 증거가 충분히 이례적인지 판단하면서, 손해 규모의 가능 범위까지 함께 제시하는 재판 과정과 같음.

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 가설 검정 절차 설명 | H0/H1, 검정통계량, p-value, alpha | p-value를 H0가 참일 확률로 오해 |
| 신뢰 구간과 오류 이해 | 1종/2종 오류, 검정력, 효과크기 | 유의성만 보고 실무 효과 판단 |

> 요약: 가설 검정은 우연 가능성을 기준으로 의사결정을 하고, 신뢰 구간은 효과 크기의 불확실한 범위를 제시하는 통계 추론 도구임.

## Ⅱ. 특징/비교

| 판단 기준 | 가설 검정 | 신뢰 구간 |
|:---|:---|:---|
| 핵심 질문 | 관측 차이가 우연으로 보기 어려운가 | 모수나 효과 크기가 어느 범위에 있는가 |
| 주요 산출물 | p-value, 기각/채택 여부 | 하한과 상한, 추정값 |
| 판단 기준 | p-value와 유의수준 alpha 비교 | 구간이 기준값을 포함하는지와 폭이 충분한지 |
| 선택 기준 | 명확한 의사결정이 필요할 때 | 효과 크기와 불확실성 설명이 필요할 때 |

- **오류 기준**: 1종 오류는 참인 H0를 기각하는 오류이고, 2종 오류는 거짓 H0를 기각하지 못하는 오류임.
- **검정력 기준**: 표본 수, 효과 크기, 분산, 유의수준이 검정력을 결정함.
- **해석 기준**: 통계적 유의성은 실무적 중요성을 자동으로 보장하지 않으므로 효과 크기를 함께 봐야 함.

> 요약: 가설 검정은 결정 중심, 신뢰 구간은 추정 중심이며 둘 다 오류 확률과 효과 크기 해석이 함께 필요함.

## Ⅲ. 구성요소

```text
+------------+      +------------+      +------------+
| Hypothesis | ---> | Test       | ---> | p-value    |
| H0 / H1    |      | Statistic  |      | Decision   |
+------------+      +------------+      +------------+
       |                   |                   |
       v                   v                   v
+------------+      +------------+      +------------+
| alpha      |      | Sampling   |      | Confidence |
| Error Risk |      | Dist       |      | Interval   |
+------------+      +------------+      +------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 귀무/대립 가설 | 기본 주장과 검증하려는 주장을 명확히 나눈 문장임 | 무죄와 유죄 주장 |
| 검정통계량 | 표본 결과를 표준화해 귀무가설 하 분포와 비교할 값임 | 증거 점수 |
| 유의수준 alpha | 1종 오류를 허용하는 사전 기준이며 기각 임계값을 정함 | 판결 기준선 |
| p-value | H0가 참일 때 현재보다 극단적인 결과가 나올 확률임 | 이례성 지표 |
| 신뢰 구간 | 추정값 주변의 불확실성 범위를 나타내 효과 크기 판단을 돕는 구간임 | 가능한 손해 범위 |

> 요약: 가설 검정은 가설, 검정통계량, 유의수준, p-value로 결정을 내리고 신뢰 구간으로 효과 크기와 불확실성을 보완함.

## Ⅳ. 절차

```text
+------------+      +------------+      +------------+      +------------+
| Set H0/H1  | ---> | Compute    | ---> | Compare    | ---> | Report     |
| and alpha  |      | Statistic  |      | p vs alpha |      | CI/Effect  |
+------------+      +------------+      +------------+      +------------+
```

1. **가설·기준 설정**: H0/H1, 단측·양측 검정, 유의수준 alpha, 필요한 표본 수를 사전에 정함.
2. **검정통계량 계산**: 데이터 분포와 표본 조건에 맞는 z, t, chi-square, F 통계량을 계산함.
3. **의사결정**: p-value를 alpha와 비교하거나 임계값과 검정통계량을 비교해 H0 기각 여부를 판단함.
4. **결과 보고**: 신뢰 구간, 효과 크기, 검정력, 가정 위반 여부를 함께 제시함.

> 요약: 가설 검정은 사전 기준 설정, 통계량 계산, 유의성 판단, 신뢰 구간과 효과 크기 보고 순서로 수행함.

## Ⅴ. 문제점

- **P1 p-value 오해**: p-value를 H0가 참일 확률이나 효과가 클 확률로 해석하면 결론이 왜곡됨.
- **P2 다중 검정 오류**: 여러 가설을 반복 검정하면 우연히 유의한 결과가 나올 확률이 증가함.
- **P3 검정력 부족**: 표본 수가 작거나 효과 크기가 작으면 실제 차이가 있어도 H0를 기각하지 못할 수 있음.

> 요약: 가설 검정은 p-value 해석, 반복 검정, 검정력 부족을 관리하지 않으면 통계적으로 그럴듯하지만 실무적으로 잘못된 결론을 낼 수 있음.

## Ⅵ. 개선방안

- **P1 대응**: p-value 정의를 H0 조건부 확률로 명시하고 신뢰 구간과 효과 크기를 함께 보고함. (확인: p-value 해석 문구)
- **P2 대응**: Bonferroni, Holm, FDR 보정과 사전 분석 계획으로 다중 검정의 1종 오류 증가를 통제함. (확인: adjusted p-value)
- **P3 대응**: 사전 power analysis로 표본 수를 산정하고 최소 검출 효과를 명확히 함. (확인: power >= 0.8)

> 요약: 가설 검정은 해석 문구 표준화, 다중 검정 보정, 검정력 설계를 통해 의사결정 오류를 줄여야 함.

## Ⅶ. 전망

- **발전 방향**: 실험 플랫폼, MLOps, 제품 분석에서는 p-value 중심 보고에서 효과 크기, 신뢰 구간, 베이지안 의사결정을 함께 쓰는 방향으로 발전할 전망임.
- **기술사적 판단**: 통계적으로 유의한지보다 시스템 성능, 비용, 사용자 영향에서 의미 있는 효과인지가 최종 선택 기준이 되어야 함.
- **기술사 제언**: 답안에서는 H0/H1 절차와 p-value 정의를 정확히 쓰고, 신뢰 구간과 검정력으로 실무 판단을 보완해야 함.
