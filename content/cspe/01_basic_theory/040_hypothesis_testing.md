## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 표본 데이터로부터 모집단에 대한 가설의 참·거짓을 통계적으로 판정(가설 검정)하고, 모수의 추정 범위를 확률적으로 제시(신뢰 구간)하는 통계 추론 기법임 |
| **배경/필요성** | 실험·AB 테스트·품질 관리에서 관측 차이가 우연인지 유의한지를 체계적으로 판단하는 도구가 필요함 |
| **출제 의도** | 귀무/대립 가설·유의수준·p-값·1종/2종 오류의 관계를 이해하는지 평가함 |

## Ⅱ. 구성요소
```
+----------+     +----------+     +----------+
| 귀무가설  | --> | 검정통계량| --> | p-값     |
| (H₀)    |     | (t/z/χ²) |     | 판정     |
+----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| 귀무 가설(H₀) | 차이가 없다(효과가 없다)는 기본 가설임 | 피고인은 무죄(기본 전제) |
| 대립 가설(H₁) | 차이가 있다(효과가 있다)는 연구 가설임 | 피고인은 유죄(증명 대상) |
| p-값 | H₀이 참일 때 관측된 검정 통계량 이상의 극단값이 나올 확률임 | 무죄인데 이 정도 증거가 나올 확률 |

> 요약: H₀ 설정 → 검정 통계량 계산 → p-값과 유의수준(α) 비교로 가설을 판정함.

## Ⅲ. 절차
```
+------------+     +------------+
| 가설설정   | --> | 통계량계산  |
| (H₀, H₁)  |     | (t/z/χ²)  |
+------------+     +------------+
                        |
+------------+     +----+-------+
| 결론도출   | <-- | p-값비교  |
| (채택/기각)|     | (α=0.05) |
+------------+     +------------+
```

1. 가설 설정: 귀무 가설(H₀: μ₁=μ₂)과 대립 가설(H₁: μ₁≠μ₂)을 수립함
2. 검정 통계량 계산: 표본 평균·표준편차로 t/z/χ² 통계량을 산출함
3. p-값 산출: 검정 통계량에 대응하는 p-값을 분포표·소프트웨어로 계산함
4. 결론 도출: p < α(0.05)이면 H₀을 기각하고 유의한 차이가 있다고 판정함

> 요약: 가설 → 통계량 → p-값 → 판정으로 통계적 유의성을 검증함.

## Ⅳ. 문제점
- 1종 오류(α): H₀이 참인데 기각하는 오류(위양성)의 위험이 항상 존재함
- 2종 오류(β): H₀이 거짓인데 기각하지 못하는 오류(위음성)로, 검정력(1-β)이 부족할 수 있음
- p-값 오해: p-값이 H₀의 참일 확률이 아님에도 그렇게 해석하는 오류가 빈발함

## Ⅴ. 개선방안
- (단기) 효과 크기·신뢰 구간 병행: p-값만이 아닌 효과 크기와 95% 신뢰 구간을 함께 보고함
- (중기) 다중 검정 보정: Bonferroni·FDR 보정으로 다수 검정 시 1종 오류 누적을 제어함
- (장기) 베이지안 검정: 사후 확률 기반 가설 비교로 p-값 의존을 줄이고 의사결정을 개선함

## Ⅵ. 전망
- AB 테스트·임상 시험·품질 관리에서 가설 검정이 필수이며, 베이지안 AB 테스트와 순차 검정(Sequential Testing)이 온라인 실험의 차세대 표준으로 확산될 전망임
