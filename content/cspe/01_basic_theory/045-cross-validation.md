## Ⅰ. 개요
- **정의**: 데이터셋을 K개의 폴드(Fold)로 나누어 학습과 검증을 반복 수행하는 모델 평가 방법임.
- **배경/필요성**: 한정된 데이터로 인한 과적합을 막고, 모델의 일반화 성능을 객관적으로 측정하기 위해 필요함.
- **출제 의도**: K-Fold 교차 검증의 원리를 이해하고, 데이터 분할에 따른 성능 평가 왜곡 방지법을 아는지 평가함.

## Ⅱ. 구성요소
```text
+------------------+       +------------------+       +------------------+
| Full Dataset     | ----> | Split into       | ----> | Train & Validate |
| (100%)           |       | K Folds          |       | (Iterate K times)|
+------------------+       +------------------+       +------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 전체 데이터 | 학습 및 검증을 위해 주어진 전체 샘플 | 전체 시험 범위 |
| Fold (폴드) | 데이터를 일정한 크기로 나눈 부분 집합 | 분할된 단원들 |
| 평균 성능 | K번의 검증 결과를 평균 내어 도출한 최종 성능 | 모의고사 평균점수 |

> 요약: 데이터를 K개로 분할하여 각각을 한 번씩 검증 셋으로 사용하고 나머지를 학습 셋으로 씀.

## Ⅲ. 절차
```text
+-------------+   +-------------+   +-------------+   +-------------+
| 1. 데이터   |-->| 2. K개로    |-->| 3. 반복     |-->| 4. 평균     |
|    준비     |   |    분할     |   |    학습/평가|   |    성능산출 |
+-------------+   +-------------+   +-------------+   +-------------+
```
1. **데이터 준비**: 모델을 평가할 전체 데이터셋을 수집하고 무작위로 섞음.
2. **K개로 분할**: 데이터를 겹치지 않는 K개의 균등한 부분 집합(Fold)으로 나눔.
3. **반복 학습/평가**: 매번 1개 폴드를 검증용으로, K-1개를 학습용으로 사용해 모델을 훈련/평가함.
4. **평균 성능산출**: K번의 평가 지표(정확도 등)를 평균 내어 모델의 최종 일반화 성능을 도출함.

> 요약: 데이터를 K개로 나누고 교대로 검증 셋을 바꾸어가며 K번 학습/평가 후 평균 성능을 냄.

## Ⅳ. 문제점
- **연산 비용 증가**: 모델 학습 및 검증 과정을 K번 반복해야 하므로 훈련 시간이 K배 증가함.
- **클래스 불균형 무시**: 무작위 분할 시 특정 Fold에 소수 클래스가 쏠리거나 누락될 수 있음.

## Ⅴ. 개선방안
- **연산 비용 증가**: (단기) K값을 줄이거나 병렬 처리 도입 / (장기) 데이터 샘플링 최적화 및 경량 모델로 사전 검증 필요.
- **클래스 불균형 무시**: (단기) Stratified K-Fold를 사용하여 클래스 비율 유지 / (장기) 오버샘플링(SMOTE) 적용 필요.

## Ⅵ. 전망
- 초매개변수 튜닝(GridSearch 등)과 결합하여 신뢰성 있는 AI 모델 개발 파이프라인의 핵심 표준 검증 절차로 계속 유지됨.
