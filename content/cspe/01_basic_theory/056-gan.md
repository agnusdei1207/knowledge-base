## Ⅰ. 개요
- **정의**: 가짜를 생성하는 모델과 진짜/가짜를 판별하는 모델이 서로 경쟁하며 학습하여 실제 같은 데이터를 생성하는 기법임.
- **배경/필요성**: 명시적인 확률 분포 모델링 없이 고해상도 이미지 등 복잡한 데이터를 생성하기 위해 등장함.
- **출제 의도**: 생성자와 판별자의 적대적 학습 원리와 손실 함수의 Minimax 게임 특성을 평가함.

## Ⅱ. 구성요소
```text
+------------------+       +------------------+       +------------------+
| Random Noise (z) | ----> | Generator (G)    | ----> | Discriminator(D) |
|                  |       | (Fake Image)     |       | (Real or Fake?)  |
+------------------+       +------------------+       +------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 생성자 (G) | 무작위 노이즈로부터 실제와 유사한 가짜를 생성 | 위조지폐범 |
| 판별자 (D) | 입력된 데이터가 실제인지 가짜인지 분류 | 경찰 |
| 적대적 손실 | G는 속이려 하고, D는 정확히 구별하려는 함수 | 쫓고 쫓기는 게임 |

> 요약: 생성자는 판별자를 속이도록, 판별자는 생성물을 감별하도록 교대로 학습함.

## Ⅲ. 절차
```text
+-------------+   +-------------+   +-------------+   +-------------+
| 1. 노이즈   |-->| 2. 판별자   |-->| 3. 생성자   |-->| 4. 교대     |
|    입력     |   |    학습     |   |    학습     |   |    학습반복 |
+-------------+   +-------------+   +-------------+   +-------------+
```
1. **노이즈 입력**: 생성자가 잠재 공간의 무작위 노이즈 벡터를 받아 가짜를 만듦.
2. **판별자 학습**: 실제 데이터와 가짜 데이터를 판별자에게 주어 분류기를 학습시킴.
3. **생성자 학습**: 판별자를 고정한 채 가짜를 1로 판별하도록 생성자 가중치를 업데이트함.
4. **교대 학습반복**: 두 네트워크가 균형을 이루며 구별할 수 없을 때까지 반복함.

> 요약: 판별자는 진위 구별 능력을 키우고, 생성자는 판별자를 속이는 능력을 키우며 경쟁함.

## Ⅳ. 문제점
- **모드 붕괴**: 생성자가 판별자를 쉽게 속이는 특정 이미지만 생성하고 다양성을 잃음.
- **학습 불안정성**: 두 모델의 밸런스가 무너지면 생성자의 기울기가 소실되어 중단됨.

## Ⅴ. 개선방안
- **모드 붕괴**: (단기) 미니배치 다양성 검사 / (장기) WGAN 등 손실 함수 거리 척도 변경 필요.
- **학습 불안정성**: (단기) 학습률 조정 / (장기) Spectral Normalization 등 판별자 규제 필요.

## Ⅵ. 전망
- Diffusion 모델 부상으로 비중이 줄었으나, 이미지 번역 및 실시간 렌더링 분야에서 핵심임.
