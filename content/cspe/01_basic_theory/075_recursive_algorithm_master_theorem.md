# 📖 【암기용】 개념 완전 이해

> 목적: 재귀 알고리즘과 마스터 정리를 처음 봐도 완벽히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 문제를 같은 형태의 작은 문제로 나누어 풀고 결합하는 알고리즘과 그 시간복잡도 해석법
- **왜 필요한가**: 병합정렬, 이진탐색, 퀵정렬, 분할정복 알고리즘은 반복문 횟수만 세면 복잡도를 산출하기 어렵다. 점화식과 마스터 정리로 성장률을 계산한다.
- **핵심 직관**: 큰 일을 여러 하위 일로 쪼갠 뒤, 각 층의 작업량이 위쪽·아래쪽·모든 층 중 어디에 몰리는지 보는 방법이다.

## 깊이 이해
- **배경·문제의식**: 재귀는 코드가 간결하지만 호출 깊이, 중복 계산, 스택 사용량을 만들 수 있다. 시간복잡도는 보통 `T(n)=aT(n/b)+f(n)` 형태로 나타난다.
- **작동 원리**: `a`는 하위 문제 개수, `n/b`는 하위 문제 크기, `f(n)`은 분할과 결합 비용이다. `n^log_b a`와 `f(n)`을 비교해 Case 1, 2, 3 중 하나로 시간복잡도를 결정한다.
- **비유**: 조직장이 업무를 여러 팀에 나누고 마지막에 보고서를 합치는 상황과 같다. 팀 수, 팀별 업무 크기, 취합 비용 중 어느 쪽이 지배적인지 보는 것이다.
- **구체 예시**: 병합정렬은 `T(n)=2T(n/2)+O(n)`이고 `n^log_2 2=n`이므로 Case 2, 시간복잡도 `O(n log n)`이다.
- **흔한 오해·주의점**: 모든 재귀 점화식에 마스터 정리를 적용할 수는 없다. `T(n)=T(n-1)+n`, 불균등 분할, regularity condition 불만족 식은 반복 대입, 재귀 트리, Akra-Bazzi 등을 검토해야 한다.

## 연결 개념
- 분할정복 — 재귀 알고리즘의 대표 설계 패턴
- 시간복잡도 — 알고리즘 선택 기준
- 동적 계획법 — 중복 재귀를 메모이제이션으로 제거

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 재귀 알고리즘은 동일 구조의 하위 문제로 분해하고, 마스터 정리는 `T(n)=aT(n/b)+f(n)` 점화식의 점근 복잡도를 산출함.
> 2. **가치**: 병합정렬, 이진탐색, 분할정복 알고리즘의 시간복잡도와 스택 공간을 정량 비교하게 함.
> 3. **판단 포인트**: `n^log_b a`와 `f(n)` 비교, 적용 조건, 중복 계산 여부, 호출 깊이를 함께 판단해야 함.

---

## Ⅰ. 개요 및 필요성

재귀 알고리즘은 문제를 자기와 같은 형태의 하위 문제로 분할한다. 반복문 기반 분석만으로는 분할정복의 전체 비용을 계산하기 어렵다. 마스터 정리는 표준 점화식의 시간복잡도를 Case 1~3으로 판정하는 기준을 제공함.

---

## Ⅱ. 구조 및 구성요소

```text
원문제 T(n) -> 하위 문제 a개 T(n/b) -> 분할/결합 비용 f(n) -> 전체 복잡도
              +-> 재귀 종료 조건
              +-> 호출 깊이 log_b n
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 종료 조건 | 재귀 호출 중단 | n=1, empty input |
| 분할 계수 a | 하위 문제 개수 | 병합정렬 a=2 |
| 축소 계수 b | 하위 문제 크기 비율 | 병합정렬 b=2 |
| 결합 비용 f(n) | 분할·병합·비재귀 작업 | merge O(n), binary search O(1) |

> 요약: 재귀 비용은 하위 문제 수, 크기 감소율, 비재귀 작업량, 종료 조건으로 결정됨.

---

## Ⅲ. 동작원리 및 흐름도

```text
알고리즘 식별 -> 점화식 도출 -> n^log_b a 계산 -> f(n) 비교 -> Case 판정
                 +-> 적용 조건 확인
                 +-> 시간/공간 복잡도 산출
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 재귀 호출 개수와 입력 크기 확인 | a>=1, b>1 |
| 2 | 비재귀 비용 f(n) 산정 | 분할·결합 코드 라인 기준 |
| 3 | `n^log_b a`와 `f(n)` 비교 | polynomial gap 또는 log factor 확인 |
| 4 | Case 1~3 적용과 예외 검토 | regularity condition, 균등 분할 여부 |

> 요약: 점화식을 도출한 뒤 기준항과 결합 비용의 성장률 비교로 시간복잡도를 결정함.

---

## Ⅳ. 특징

| 구분 | 내용 | 판단 포인트 |
|:---|:---|:---|
| Case 1 | `f(n)=O(n^(log_b a - e))` | 하위 문제 비용 지배, 결과 `Theta(n^log_b a)` |
| Case 2 | `f(n)=Theta(n^log_b a log^k n)` | 각 층 비용 균형, 결과 `Theta(n^log_b a log^(k+1) n)` |
| Case 3 | `f(n)=Omega(n^(log_b a + e))` | 결합 비용 지배, regularity 필요 |
| 한계 | 비표준 점화식 제외 | `T(n-1)`, 불균등 분할, 중복 재귀 |

> 요약: 마스터 정리는 균등 분할 점화식에 대해 기준항과 f(n)의 성장률 차이로 3가지 결과를 산출함.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존/대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 분석 방법 | 반복문 카운트 | 점화식/마스터 정리 | 분할정복 재귀는 점화식 사용 |
| 예외 처리 | 마스터 정리 단독 | 재귀 트리/대입법/Akra-Bazzi | 불균등 분할은 대안 적용 |
| 구현 판단 | 단순 재귀 | 메모이제이션/반복 변환 | 중복 호출 또는 깊이 n이면 변환 검토 |

> 요약: 표준 분할정복은 마스터 정리, 비균등·중복 재귀는 재귀 트리나 DP 변환으로 분석함.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 스택 오버플로 | 재귀 깊이 O(n) | tail recursion, 반복문 변환 | 최대 depth 10,000 이하 |
| 중복 계산 | 피보나치형 분기 재귀 | memoization, bottom-up DP | 호출 수 O(2^n)에서 O(n)으로 감소 |
| 오판정 | 적용 조건 미확인 | a, b, f(n), regularity 점검 | Case 판정 근거 4항목 기록 |

> 요약: 재귀 위험은 호출 깊이, 중복 계산, 정리 적용 조건을 수치로 확인해 통제함.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 시간복잡도 | Big-O/Theta 근거 명시 | 점화식, 재귀 트리 |
| 공간복잡도 | 호출 스택 O(log n) 또는 O(n) 산출 | depth profiling |
| 구현 검증 | 입력 10^5 규모 시간/스택 통과 | benchmark, unit test |

> 요약: 재귀 알고리즘은 시간복잡도뿐 아니라 호출 스택과 대형 입력 실행 결과까지 점검해야 함.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 — 단계별 또는 항목별):**
1. 분석: 코드에서 `a`, `b`, `f(n)`을 추출하고 `n^log_b a`와 비교한 근거를 설계서에 기록
2. 구현: 호출 깊이 O(n) 재귀는 반복문 또는 tail-call 변환, 중복 재귀는 memoization 적용
3. 검증: 입력 10^5, recursion limit, peak memory, p95 실행시간을 CI 벤치마크로 측정

**결론 (2줄):**
- 기술사 판단: 균등 분할정복은 마스터 정리, 비균등 분할과 중복 재귀는 재귀 트리·DP 변환으로 판단
- 향후 방향: 대형 데이터 알고리즘은 복잡도 분석과 스택·메모리 관측을 결합한 검증 체계 필요
