## Ⅰ. 개요
- 정의: 자기 자신을 호출하는 알고리즘과 그 복잡도를 계산하는 수학적 정리임.
- 배경: 분할 정복(Divide & Conquer) 전략의 시간 복잡도를 직관적으로 파악하기 위함임.
- 출제 의도:
| 분류 | 상세 |
| --- | --- |
| 핵심요소 | 점화식, T(n) = aT(n/b) + f(n), 재귀 트리 |
| 주요특징 | 빠른 복잡도 계산, 문제 분할 구조 분석 |

## Ⅱ. 구성요소
- ASCII 구조도
 T(n) = a*T(n/b) + f(n)
        |     |      |
      (자식수) (분할) (병합비용)
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 기저 조건 | 재귀 호출이 멈추는 최소 단위 조건 | 탈출구 |
| 점화식 | 문제의 크기를 줄여나가는 관계식 | 릴레이 경주 |
| 마스터 정리 | 세 가지 케이스로 나누어 복잡도를 즉시 판별 | 공식 암기법 |
> 요약: 반복되는 구조의 연산량을 정형화된 수식으로 평가함.

## Ⅲ. 절차
- ASCII 흐름도
[문제 정의] -> [a, b, f(n) 추출] -> [케이스 분류] -> [O(g(n)) 도출]
- 4단계 설명
1. 변수 식별: 분할 횟수(a)와 문제 축소 비율(b)을 확인함.
2. 비교 함수 설정: n^log_b(a)와 추가 비용 f(n)을 비교함.
3. 케이스 판정: f(n)이 더 큰지, 작은지, 같은지를 확인함.
4. 복잡도 확정: 마스터 정리의 결과값(Big-O)을 선택함.
> 요약: 정해진 매개변수를 공식에 대입하여 상한 복잡도를 산출함.

## Ⅳ. 문제점
- b가 일정하지 않거나 f(n)이 다항식이 아닌 경우 적용이 불가함.

## Ⅴ. 개선방안
- 단기: 마스터 정리 적용 불가 시 재귀 트리(Recursive Tree)를 직접 그림.
- 중기: 반복 대입법(Substitution Method)으로 직접 점화식을 품.
- 장기: 아크라-바지(Akra-Bazzi) 정리 등 보다 일반화된 공식을 활용함.

## Ⅵ. 전망
- 재귀적 분할 정복 알고리즘의 복잡도 예측을 넘어 실질적 캐시 효율성을 고려한 알고리즘 분석이 필수적이며, 향후 대규모 병렬 처리 및 분산 컴퓨팅 환경에서의 동적 복잡도 분석 모델로 확장될 것임.
- 특히 빅데이터 처리 프레임워크의 연산 비용 예측 알고리즘에 적용되어 리소스 할당 최적화 및 쿼리 플래너의 성능 지표로 중요한 역할을 수행할 전망임.
