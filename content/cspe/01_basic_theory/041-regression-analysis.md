## Ⅰ. 개요
- **정의**: 독립변수(X)와 종속변수(Y) 간의 관계를 모델링하여 연속적인 값을 예측하는 통계적 분석 기법임.
- **배경/필요성**: 데이터 간의 상관관계를 파악하고, 미래 값을 예측하거나 변수 간 영향력을 분석하기 위해 필요함.
- **출제 의도**: 단순/다중/로지스틱 회귀의 차이, 회귀계수의 의미 및 오차항 가정을 이해하는지 평가함.

## Ⅱ. 구성요소
```text
+------------------+       +------------------+
| Independent (X)  | ----> | Regression Model |
| Variables Input  |       | y = Wx + b       |
+------------------+       +------------------+
                                  |
                                  v
                           +------------------+
                           | Dependent (Y)    |
                           | Predicted Value  |
                           +------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 독립 변수 (X) | 모델에 입력되는 원인 변수 | 재료 |
| 종속 변수 (Y) | 모델이 예측하고자 하는 결과 변수 | 완성품 |
| 회귀 계수 (W) | 독립 변수가 종속 변수에 미치는 영향력 크기 | 레시피 비율 |

> 요약: 독립 변수에 가중치(회귀 계수)를 곱하여 종속 변수를 예측하는 구조임.

## Ⅲ. 절차
```text
+-------------+   +-------------+   +-------------+   +-------------+
| 1. 데이터   |-->| 2. 모델     |-->| 3. 계수     |-->| 4. 모델     |
|    수집/전처|   |    설정     |   |    추정     |   |    평가     |
+-------------+   +-------------+   +-------------+   +-------------+
```
1. **데이터 수집/전처리**: 분석 목적에 맞는 변수를 선정하고 결측치 및 이상치를 처리함.
2. **모델 설정**: 선형, 비선형 등 데이터 특성에 적합한 회귀 모델 함수를 설정함.
3. **계수 추정**: 최소제곱법(OLS) 등을 활용하여 오차를 최소화하는 회귀 계수를 계산함.
4. **모델 평가**: R-squared, MSE 등을 통해 모델의 설명력 및 예측 성능을 검증함.

> 요약: 데이터를 전처리하고 모델을 설정한 뒤, 오차를 최소화하는 계수를 찾아 성능을 평가함.

## Ⅳ. 문제점
- **다중공선성**: 독립 변수들 간에 강한 상관관계가 존재하여 계수 추정이 불안정해지는 문제임.
- **이상치 민감도**: 극단적인 이상치가 존재할 경우 전체 회귀선이 크게 왜곡되는 문제임.

## Ⅴ. 개선방안
- **다중공선성**: (단기) 상관성이 높은 변수 중 일부 제거 / (장기) Ridge, Lasso 등 규제화 모델 도입 필요.
- **이상치 민감도**: (단기) 이상치 제거 또는 변환 / (장기) 로버스트 회귀(Robust Regression) 등 강건한 모델 사용 필요.

## Ⅵ. 전망
- 전통적 통계 기법을 넘어 머신러닝 최적화 알고리즘과 결합하여, 해석 가능한 AI(XAI)의 기초 모델로 활용도가 확대될 것임.
