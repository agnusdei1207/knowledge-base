## 미리 알고가기

- **차원의 저주 ($Curse$ $of$ $Dim.$)**: 차원이 증가함에 따라 공간 부피가 급증하여 데이터 밀도가 희소해지고 모델 성능이 저하되는 현상
- **고유분해 ($Eigen-Decomposition$)**: 정방 행렬을 고유값($Eigenvalue$)과 고유벡터($Eigenvector$)의 곱으로 분해하는 선형 대수 기법
- **공분산 행렬 ($\Sigma$)**: 여러 변수 간 상관관계와 분산 구조를 나타내는 행렬 ($\Sigma = E[(X-\mu)(X-\mu)^T]$)

## Ⅰ. 개요

- **정의/개념**: 고차원의 데이터셋을 정보 손실을 최소화하면서 서로 직교하는($Orthogonal$) 저차원의 새로운 축(주성분)으로 사상($Projection$)하는 선형 차원 축소 기법임
- **배경/필요성**: 변수 간 강한 상관관계($Multicollinearity$)로 인한 정보 중복을 제거하고 핵심 데이터 구조만을 보존하기 위함임. 연산 비용 절감, 데이터 가독성 증대, 노이즈 필터링 및 과적합($Overfitting$) 방지가 필수적인 빅데이터 환경에서 핵심 전처리 기술로 활용됨

## Ⅱ. 특징 및 비교

### 가. 차원 축소 및 특징 추출 기법 비교

| 구분 | 주성분 분석 ($PCA$) | 선형 판별 분석 ($LDA$) | 오토인코더 ($Autoencoder$) |
|:---|:---|:---|:---|
| 학습 유형 | 비지도 학습 ($Unsupervised$) | 지도 학습 ($Supervised$) | 비지도 학습 ($Deep$ $Learning$) |
| 최적화 목표 | 전체 데이터 분산 최대화 | 클래스 간 분리능 최대화 | 입력 데이터의 비선형 재구성 |
| 변환 방식 | 선형 변환 (직교 투영) | 선형 변환 (분류 기준) | 비선형 변환 ($Activation$) |
| 주요 강점 | 데이터 일반 구조 보존 | 분류 성능 최적화 | 복잡한 비선형 패턴 추출 |
| 수학적 기반 | 고유값 분해, $SVD$ | 클래스 내/간 분산 행렬 | 역전파 알고리즘 ($Backprop$) |

> 요약: 데이터의 전체 형상을 보존하며 차원을 축소하려면 $PCA$, 분류 경계 확보가 목적이면 $LDA$를 사용함

### 나. PCA의 핵심 기술적 성질 (PPA 관점)
- **분산 최대화 ($Variance$ $Max$)**: 첫 번째 주성분($PC1$)이 전체 데이터의 변동성을 가장 많이 설명하도록 설계 ($Energy$ $Compaction$)
- **독립성 ($Independency$)**: 주성분 축들은 서로 직교하며, 주성분 간 상관관계는 $0$임 (다중공선성 완전 제거)
- **정보 압축 ($Compression$)**: 소수의 주성분으로 원본 데이터의 정보를 $70\sim90\%$ 이상 유지 가능

### 나. 주요 구성 요소 및 역할

| 구성요소 | 역할 및 설명 | 핵심 포인트 (Trade-off) |
|:---|:---|:---|
| 주성분 ($PC$) | 원본 변수들의 선형 결합 변수 | $PC_i = \sum w_{ij}X_j$ (새로운 기저) |
| 고유값 ($\lambda$) | 주성분이 설명하는 분산의 크기 | $\sum \lambda_i / Total$ $Var$ = 설명된 비율 |
| 고유벡터 ($v$) | 주성분 축이 향하는 공간상 방향 | 데이터 사상($Projection$)의 기준선 |
| 공분산 행렬 ($\Sigma$) | 변수 간 선형 연관성 정보 저장 | $PCA$ 연산을 위한 핵심 입력 텐서 |
| 기여도 ($Loading$) | 원본 변수가 주성분에 미치는 영향력 | 주성분의 비즈니스적 해석 근거로 활용 |

> 요약: 공분산 행렬의 스펙트럼 분석을 통해 분산이 큰 방향으로 차원을 재구성하여 정보를 압축하는 구조임

## Ⅳ. 절차/동작 원리

1. **데이터 정규화**: 평균을 $0$으로 맞추는 $Zero-centering$ 및 분산을 $1$로 조정하는 $Scaling$ 수행
2. **공분산 행렬 산출**: 변수 간의 관계를 나타내는 공분산 행렬 $\Sigma$를 계산함
3. **고유치/고유벡터 추출**: $\Sigma v = \lambda v$를 만족하는 고유값($\lambda$)과 고유벡터($v$)를 구함
4. **주성분 선택 및 투영**: 고유값이 큰 상위 $k$개의 고유벡터를 선택하여 데이터를 새로운 좌표계로 투영함

## Ⅴ. 문제점 및 개선방안

1. **선형성 가정의 한계**: 실제 데이터가 복잡한 곡면($Manifold$) 구조일 경우 정보 손실이 심각함
   - **개선방안**: 커널 함수를 도입한 $Kernel$ $PCA$ 적용 또는 $t-SNE$, $UMAP$ 등 비선형 기법 검토
2. **스케일 편향 ($Scale$ $Bias$)**: 단위가 큰 변수가 고유값 계산을 지배하여 주성분 방향을 왜곡함
   - **개선방안**: 분석 전 반드시 표준화($Standardization$)를 수행하여 모든 변수의 가중치를 동등화함
3. **결과 해석의 난해성**: 새로운 축($PC$)은 원본 변수들의 조합이므로 구체적인 의미 정의가 어려움
   - **개선방안**: 주성분 로딩($Loading$) 분석을 통해 기여도가 높은 원본 특징을 식별하여 의미 부여

## Ⅵ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 (Metrics) |
|:---|:---|:---|
| 시각화 및 $EDA$ | 고차원 데이터를 $2D/3D$로 투영하여 군집 구조 파악 | 누적 분산 비율 ($Cumulative$ $\%$) |
| 모델 성능 최적화 | 다중공선성 제거 및 입력 차원 축소로 학습 속도 가속 | $Latency$, $Reconstruction$ $Error$ |
| 이미지 처리 | $Eigenface$ 추출을 통한 얼굴 특징 벡터 생성 | $MSE$, $Compression$ $Ratio$ |

> 요약: 정보 중복을 배제하고 핵심 패턴을 추출하여 분석 효율성을 극대화하는 정석 기법으로 활용됨

## Ⅶ. 결론

$PCA$는 차원의 저주를 극복하고 데이터의 본질적 구조를 규명하는 데이터 엔지니어링의 정석임. 단순한 압축을 넘어 노이즈 필터링과 변수 간 독립성 확보를 통해 후행 분석 모델의 신뢰성($Reliability$)을 보장함.

기술사는 정보 손실량과 연산 자원 사이의 트레이드오프를 누적 분산 비율을 통해 정량적으로 관리해야 함. 또한 최신 아키텍처에서는 단순 선형 $PCA$를 넘어 오토인코더($Autoencoder$) 등 딥러닝 기반의 차원 축소와 연계하여 비정형 데이터의 특징 추출(Embedding) 역량을 강화해야 함.
