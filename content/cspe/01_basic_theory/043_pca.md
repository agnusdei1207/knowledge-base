## Ⅰ. 개요
- 정의: 고차원의 데이터를 정보 손실을 최소화하며 저차원으로 축소하는 비지도 학습 기법임
- 배경: 차원의 저주 해결 및 데이터 시각화, 연산 효율성 증대 필요
- 출제 의도:
| 구분 | 내용 |
| --- | --- |
| 핵심 | 고유값(Eigenvalue), 고유벡터, 분산 보존 |

## Ⅱ. 구성요소
- ASCII 구조도
  [X1, X2, X3] --(Rotation)--> [PC1, PC2]
     (High Dim)                (Low Dim)
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 공분산 행렬 | 변수 간 상관관계를 나타내는 행렬 | 관계도 |
| 고유벡터 | 데이터 분산이 가장 큰 방향 벡터 | 축 |
| 고유값 | 고유벡터 방향의 분산 크기 | 중요도 |
> 요약: 분산을 최대로 보존하는 새로운 축을 찾아 데이터를 투영함

## Ⅲ. 절차
- ASCII 흐름도
  [정규화] -> [공분산계산] -> [고유값추출] -> [투영]
- 4단계 설명
1. 데이터 정규화: 평균 0, 분산 1로 스케일링 수행함
2. 공분산 행렬 계산: 변수들 사이의 관계를 행렬화함
3. 고유값 분해: 고유값과 고유벡터를 추출하여 주성분 결정함
4. 데이터 투영: 선택된 상위 주성분으로 데이터를 변환함
> 요약: 정보의 변동성을 가장 잘 설명하는 성분으로 차원을 축소함

## Ⅳ. 문제점
- 선형 변환 기반으로 비선형 구조 반영에 한계 있음
- 축소된 주성분의 실제 물리적 의미 해석이 어려움

## Ⅴ. 개선방안
- (단기) Kernel PCA를 적용하여 비선형 차원 축소 수행함
- (중기) 로드맵(Loading) 분석을 통해 주성분 의미 역추적함
- (장기) Autoencoder 등 딥러닝 기반 비선형 축소 기법 혼용함

## Ⅵ. 전망
- 유전체 분석(Genomics) 등 초고차원 데이터의 특징 공학(Feature Engineering) 도구로 필수 활용됨
- 매니폴드 학습(Manifold Learning)과 결합하여 데이터의 내재된 기하학적 구조 추출 기술로 발전함
- 분석 속도와 해석력 사이의 트레이드오프를 고려한 주성분 개수 선정이 실무적 CSF임
