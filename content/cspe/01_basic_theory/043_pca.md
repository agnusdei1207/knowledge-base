## 미리 알고가기

- **차원의 저주 (Curse of Dimensionality)**: 변수가 늘어날수록 데이터 밀도가 급격히 낮아지고 연산량이 폭증하며 모델의 일반화 성능이 떨어지는 현상
- **공분산 행렬 (Covariance Matrix)**: 여러 변수들 사이의 상관관계를 나타내는 정방 행렬. PCA는 이 행렬의 구조를 분석함
- **고유값 분해 (Eigen-Decomposition)**: 공분산 행렬을 고유값(분산의 크기)과 고유벡터(주성분 방향)로 분해하는 수학적 과정

## 1. 개요

- **정의/개념**: 주성분 분석(PCA, Principal Component Analysis)은 고차원의 데이터셋을 정보 손실을 최소화하면서 서로 독립적인(직교하는) 저차원의 새로운 축(주성분)으로 투영하는 선형 차원 축소 기법임
- **배경/필요성**: 현대의 데이터는 수많은 변수를 포함하지만, 그중 상당수는 서로 강한 상관관계를 가지며 중복된 정보를 담고 있음. 이를 그대로 머신러닝 모델에 넣으면 다중공선성 문제가 발생하고 학습 속도가 느려짐. PCA는 데이터의 흩어짐(분산)이 가장 큰 방향을 찾아 이를 새로운 변수로 치환함으로써, 핵심적인 구조만 남기고 노이즈를 제거하여 데이터 시각화 및 모델 효율성 향상을 도모함

## 2. 특징 및 비교

### 가. 차원 축소 및 특징 추출 기법 비교

| 구분 | 주성분 분석 (PCA) | 선형 판별 분석 (LDA) | 오토인코더 (Autoencoder) |
|:---|:---|:---|:---|
| 학습 유형 | 비지도 학습 (Unsupervised) | 지도 학습 (Supervised) | 비지도 학습 (Deep Learning) |
| 핵심 목표 | 전체 데이터의 분산 최대화 | 클래스 간 분리능 최대화 | 입력 데이터의 비선형 재구성 |
| 변환 특성 | 선형 변환 (직교 투영) | 선형 변환 (분류 기준) | 비선형 변환 가능 (활성화 함수) |
| 주요 활용 | 차원 축소, 노이즈 제거 | 분류 전처리, 특징 추출 | 이미지 압축, 비선형 차원 축소 |
| 데이터 라벨 | 필요 없음 | 필수 (Label) | 필요 없음 |

> 요약: 전체적인 데이터의 '모양'을 보존하며 축소하려면 PCA, '정답 구분'에 초점을 맞추려면 LDA를 사용함

### 나. PCA의 주요 성질
- **직교성**: 모든 주성분은 서로 90도 직각을 이루어 상관관계가 0임 (상관성 제거)
- **분산의 순서**: 첫 번째 주성분이 가장 큰 분산을 가지며, 뒤로 갈수록 정보량이 급감함
- **가역성 (근사)**: 선택된 주성분들을 다시 역산하면 완벽하지는 않지만 원본 데이터와 유사하게 복원 가능함

## 3. 구성요소/구조

### 가. PCA 수행 5단계 프로세스

```text
[데이터 표준화] -> [공분산 행렬 계산] -> [고유값/고유벡터 도출] -> [주성분 선택] -> [데이터 투영]

1. 표준화(Standardization): 평균 0, 분산 1로 정규화하여 스케일 편향 제거
2. 공분산 행렬: 변수들 간의 연관성(Covariance) 구조 파악
3. 고유분해: 공분산 행렬을 분해하여 주축(고유벡터)과 분산량(고유값) 도출
4. 축 선택: 설명된 분산량(Explained Variance)의 누적 합을 보고 상위 K개 선택
5. 투영(Projection): 원 데이터를 선택된 주성분 평면으로 사상하여 차원 축소 완료
```

### 나. 주요 구성 요소 및 역할

| 구성요소 | 역할 및 설명 | 핵심 포인트 |
|:---|:---|:---|
| 주성분 (PC) | 원본 변수들의 선형 결합으로 만들어진 새 변수 | $PC1 = a_1X_1 + a_2X_2 + \dots$ |
| 고유값 (Eigenvalue) | 각 주성분이 설명하는 데이터의 분산량 | 주성분의 중요도를 나타내는 지표 |
| 고유벡터 (Eigenvector) | 주성분 축이 향하는 공간상의 방향 | 원본 공간에서의 주성분 가중치 조합 |
| 스크리 플롯 (Scree Plot) | 주성분별 고유값을 그래프로 나타낸 것 | 'Elbow' 지점을 찾아 최적 차원 결정 |

> 요약: 데이터의 에너지가 가장 집중된 방향을 찾아 이를 새로운 좌표축으로 삼는 구조임

## 4. 문제점 및 개선방안

1. **선형성 가정의 한계**: 데이터가 비선형적인 곡선 형태로 분포하는 경우, 선형 투영인 PCA는 구조를 제대로 파악하지 못함
   - **개선방안**: 커널 함수를 도입하여 고차원 공간으로 보낸 뒤 PCA를 수행하는 '커널 PCA(Kernel PCA)'나 t-SNE, UMAP 같은 비선형 기법을 활용함

2. **변수 스케일에 대한 극심한 민감도**: 단위가 큰 변수가 주성분 방향을 지배하여 분석 결과가 왜곡됨
   - **개선방안**: 분석 전 반드시 Z-Score 정규화를 통해 모든 변수의 기여도를 대등하게 맞춤

3. **결과 해석의 난해함**: 생성된 주성분은 여러 변수가 섞인 형태이므로 도메인 전문가가 그 의미를 직관적으로 이해하기 어려움
   - **개선방안**: 각 주성분과 원본 변수 간의 상관계수인 로딩(Loading) 값을 분석하여, 주성분이 어떤 의미(예: 신체 사이즈, 경제 지표 등)를 갖는지 해석 보완

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| 고차원 데이터 시각화 | 수십 개의 특징을 2차원 또는 3차원 PCA로 축소하여 산점도 시각화 | 설명된 분산 비율(Cumulative Variance) |
| 머신러닝 전처리 | 다중공선성이 높은 변수들을 주성분으로 통합하여 모델 안정성 확보 | 학습 시간 단축, 과적합 방지 |
| 이미지 처리/압축 | 얼굴 이미지의 고유 얼굴(Eigenface)을 추출하여 데이터 압축 및 인식 | 재구성 오차(Reconstruction Error) |

> 요약: 정보의 중복을 제거하고 핵심 패턴만을 남겨 데이터의 복잡도를 획기적으로 낮추는 용도로 활용함

## 6. 결론

PCA는 차원의 저주를 극복하고 고차원 데이터의 본질을 꿰뚫어 보게 해주는 데이터 과학의 망원경과 같은 기술임. 데이터의 손실을 최소화하면서 계산 효율을 극대화하는 선형 최적화의 정수를 보여줌.

기술사는 단순히 주성분을 뽑는 것을 넘어, '설명된 분산 비율'을 통해 정보 손실과 차원 축소 사이의 트레이드오프를 정량적으로 관리할 수 있어야 함. 또한, 데이터의 선형성 여부를 판단하여 PCA가 적절한 도구인지 검토하고, 분석 결과인 주성분이 비즈니스 맥락에서 어떤 의미를 가지는지 설명할 수 있는 통찰력을 갖추어야 함.
