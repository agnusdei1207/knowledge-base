## Ⅰ. 개요
- **정의**: 고차원 데이터의 분산을 최대 보존하는 직교 축(주성분)으로 투영하여 차원을 축소하는 기법
- **배경/필요성**: 차원의 저주로 인한 모델 성능 저하와 계산 비용 증가를 해결할 차원 축소 필요
- **비유**: 3D 물체를 가장 정보가 많이 보이는 각도에서 2D 사진으로 찍는 것

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 고유값 분해 수학 원리 | 공분산 행렬 → 고유벡터·고유값 추출 | 표준화 전처리 누락 감점 |
| 정보 손실 최소화 논리 | 누적 설명 분산비(≥ 95%) 기준 K 결정 | 비선형 데이터 한계 미언급 |

> 요약: PCA는 분산 최대 축으로 투영하여 정보 손실을 최소화하면서 차원을 축소하는 기법임

## Ⅱ. 구성요소
```text
+------------+     +--------------+     +------------+
| High-Dim   |     | Covariance   |     | Low-Dim    |
| Data (d)   | --> | Eigen Decomp | --> | Data (k)   |
+------------+     +--------------+     +------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 공분산 행렬 | 변수 쌍 간 상관 크기를 나타내는 d x d 정방행렬 | 관계 지도 |
| 고유벡터 | 데이터 분산이 최대인 방향 축(주성분 방향) | 최적 카메라 각도 |
| 고유값 | 해당 고유벡터 방향의 분산 크기(정보량 지표) | 사진 선명도 |

> 요약: 공분산 행렬 → 고유벡터(방향) + 고유값(정보량) → 상위 K축 선택으로 구성됨

## Ⅲ. 절차
```text
+------------+     +------------+     +------------+     +------------+
| Standardize|     | Cov Matrix |     | Eigen      |     | Project    |
| (mean=0)   | --> | Calc       | --> | Decompose  | --> | to Top-K   |
+------------+     +------------+     +------------+     +------------+
```

1. **표준화** — 변수 간 단위 차이 제거를 위해 평균 0·분산 1로 정규화
2. **공분산 계산** — 표준화된 데이터의 d x d 공분산 행렬 산출
3. **고유값 분해** — 공분산 행렬에서 고유벡터·고유값 추출 후 고유값 내림차순 정렬
4. **사영(Projection)** — 누적 설명 분산비 ≥ 95% 되는 상위 K개 축에 원본 데이터 투영

> 요약: 표준화 → 공분산 → 고유값 분해 → 상위 K축 투영의 4단계로 차원을 축소함

## Ⅳ. 문제점
- 비선형 무력: 선형 변환이므로 매니폴드·곡면 구조의 비선형 패턴 포착 불가
- 해석력 저하: 주성분이 원본 변수의 선형 결합이라 물리적 의미 해석이 어려움
- 이상치 왜곡: 분산 최대화 기준이므로 극단값이 주성분 방향 자체를 왜곡

> 요약: 비선형 한계·해석 어려움·이상치 민감이 PCA의 3대 약점임

## Ⅴ. 개선방안
1. 단기: Kernel PCA(RBF/Poly 커널)로 비선형 구조를 고차원 공간에서 분리
2. 중기: Sparse PCA로 주성분 내 0이 아닌 변수를 제한하여 해석력 확보
3. 장기: Robust PCA(저랭크+희소 분해)로 이상치·노이즈를 분리 처리

- 대규모 행렬 연산: d가 수만일 때 O(d³) → Randomized SVD로 근사 (지표: 시간 O(dk²))

> 요약: Kernel PCA → Sparse PCA → Robust PCA로 한계를 단계별 극복함

## Ⅵ. 전망
- 향후 발전 방향: t-SNE·UMAP 등 비선형 매니폴드 기법과 PCA 전처리를 결합한 하이브리드 파이프라인
- 기술사적 판단: PCA 자체는 기초 도구이나 고차원 데이터 전처리의 표준으로 존속
- 기술사 제언: 축소 차원 수(K) 결정 시 누적 설명 분산비와 다운스트림 태스크 성능을 동시 고려 필요
