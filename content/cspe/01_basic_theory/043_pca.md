## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 고차원 데이터의 분산을 보존하면서 직교하는 주성분으로 변환해 차원을 축소하는 기법임 |
| 배경/필요성 | 차원의 저주 해결, 모델 학습 시간 단축, 데이터 시각화 및 다중공선성 제거 필요 |
| 출제 의도 | 고유값/고유벡터를 이용한 정보 손실 최소화 및 차원 축소의 수학적 원리 평가 |

## Ⅱ. 구성요소
```text
+----------------+       +----------------+       +----------------+
| High-Dim       |       | Covariance &   |       | Reduced        |
| Data Input     | ----> | Eigenvectors   | ----> | Dimension Data |
+----------------+       +----------------+       +----------------+
```
| 공분산 행렬 | 변수들 간의 상호 상관관계를 나타내는 정방행렬 | 관계 지형도 |
| 고유벡터 | 데이터 분산이 가장 큰 방향을 나타내는 축 | 새로운 시점(각도) |
| 고유값 | 각 고유벡터 방향으로의 데이터 분산 크기 | 정보의 중요도 |
> 요약: PCA는 공분산 행렬과 고유벡터, 고유값으로 구성되어 주요 정보 축을 도출함

## Ⅲ. 절차
```text
+----------------+       +----------------+       +----------------+       +----------------+
| Data Scaling   |       | Cov Matrix     |       | Eigendecomp    |       | Projection     |
| (Standardize)  | ----> | (Relation Calc)| ----> | (Vector Extr)  | ----> | (Dim Reduce)   |
+----------------+       +----------------+       +----------------+       +----------------+
```
1. 데이터 스케일링: 변수 간 단위 차이를 없애기 위해 평균 0, 분산 1로 표준화
2. 공분산 계산: 변수들 사이의 상관관계 및 분산 정보를 담은 행렬 도출
3. 고유값 분해: 공분산 행렬에서 고유벡터와 그에 대응하는 고유값 추출 및 정렬
4. 데이터 사영: 상위 K개의 고유벡터를 기저로 하여 원본 데이터를 투영
> 요약: 데이터 표준화 후 공분산 행렬의 고유값 분해를 통해 주성분 축에 데이터를 사영함

## Ⅳ. 문제점
- 비선형 변환 한계: 선형 변환 기반이므로 비선형 구조의 데이터 특징 추출 불가
- 설명력 저하 문제: 변환된 주성분이 원본 변수들의 조합이므로 결과 해석이 비직관적임
- 이상치 왜곡 발생: 분산 최대화 방식이므로 소수의 이상치에 의해 주성분 축이 왜곡됨

## Ⅴ. 개선방안
- 단기 방안: Kernel PCA를 활용하여 비선형 데이터의 차원 축소 수행
- 중기 방안: 변수 중요도 분석 병행 또는 Sparse PCA를 통해 변환 결과의 해석력 보완
- 장기 방안: Robust PCA를 적용하여 이상치의 영향을 최소화하는 강건한 모델 구축

## Ⅵ. 전망
- 오토인코더 및 t-SNE, UMAP 등과 결합하여 비선형 매니폴드 학습의 초석으로 활용됨
