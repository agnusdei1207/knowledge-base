## 미리 알고가기

- 차원: 데이터가 가진 변수 또는 특징의 개수임
- 공분산: 두 변수가 함께 변하는 방향과 크기를 나타내는 값임
- 고유벡터: 데이터 분산이 큰 방향을 나타내는 축임
- 고유값: 해당 축이 보존하는 분산의 크기임
- 설명 분산비: 선택한 주성분이 전체 정보량 중 얼마나 설명하는지 나타내는 비율임

## Ⅰ. 개요

- **정의**: PCA는 고차원 데이터를 분산이 큰 직교 축인 주성분 기준으로 새 좌표계에 투영해 정보 손실을 관리하면서 차원을 줄이는 선형 차원 축소 기법임
- **배경/필요성**: 변수가 많으면 계산 비용, 다중공선성, 시각화 어려움, 차원의 저주가 발생하므로 핵심 변동을 보존하는 축만 남길 기준이 필요함
- **비유**: 입체 물체를 가장 많은 모양 정보가 보이는 각도에서 사진으로 찍어 평면에 요약하는 것과 같음

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 차원 축소 원리 이해 | 공분산 행렬, 고유벡터, 고유값 | 표준화 전처리 누락 |
| 정보 보존 판단 역량 | 설명 분산비, 누적 설명 분산비 | 비선형 구조 한계 누락 |

> 요약: PCA는 데이터의 큰 변동 방향을 찾아 적은 축으로 투영함으로써 계산량과 중복 변수를 줄이는 기법임.

## Ⅱ. 특징/비교

| 판단 기준 | 변수 선택·비선형 축소 | PCA |
|:---|:---|:---|
| 차원 감소 방식 | 기존 변수 일부 선택 또는 복잡한 비선형 변환을 사용함 | 기존 변수의 선형 결합으로 새 축을 만듦 |
| 정보 기준 | 도메인 중요도, 예측 성능, 국소 구조 중심임 | 전체 분산 보존량과 직교성 중심임 |
| 해석 가능성 | 선택 변수는 해석이 쉽고 비선형 축소는 해석이 어려움 | 주성분 로딩을 통해 기여 변수를 제한적으로 해석함 |
| 선택 조건 | 원변수 유지나 비선형 시각화가 중요할 때 적합함 | 공선성 완화와 선형 정보 압축이 필요할 때 적합함 |

> 요약: PCA는 원변수 해석력보다 중복 제거와 선형 정보 보존을 우선할 때 선택하는 차원 축소 방법임.

- **입력 조건**: 수치형 변수의 스케일이 맞고 선형 상관 구조가 의미 있어야 함
- **평가 기준**: 누적 설명 분산비와 후속 모델 성능을 함께 확인함
- **선택 판단**: 변수 중복을 줄이되 큰 변동 방향을 보존해야 할 때 우선 검토함

## Ⅲ. 구성요소

```text
+------------+      +------------+      +------------+
| 표준화 데이터 | ---> | 공분산 행렬 | ---> | 주성분 축   |
+------------+      +------------+      +------------+
       |                  |                  |
       v                  v                  v
+------------+      +------------+      +------------+
| 변수 스케일 |      | 고유분해    |      | 투영 데이터 |
+------------+      +------------+      +------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 표준화 데이터 | 변수 단위 차이를 제거해 큰 단위 변수가 주성분을 지배하지 않게 함 | 같은 눈금의 지도 |
| 공분산 행렬 | 변수들이 함께 변하는 패턴을 행렬로 표현해 축 탐색의 입력으로 사용함 | 바람 방향 기록 |
| 고유분해·SVD | 분산이 큰 방향과 그 크기를 계산해 주성분 후보를 산출함 | 가장 긴 그림자 찾기 |
| 주성분 축 | 서로 직교하면서 데이터 분산을 큰 순서로 보존하는 새 좌표축임 | 새 기준선 |
| 투영 데이터 | 원데이터를 선택한 주성분 축에 매핑한 저차원 표현임 | 압축 사진 |

> 요약: PCA는 표준화된 데이터의 공분산 구조를 분해해 분산 보존 축을 만들고 그 축으로 데이터를 투영함.

## Ⅳ. 절차

```text
+------------+      +------------+      +------------+      +------------+
| 표준화     | ---> | 축 계산     | ---> | 축 선택     | ---> | 데이터 투영 |
+------------+      +------------+      +------------+      +------------+
```

1. **데이터 표준화**: 평균과 분산을 맞춰 변수 단위 차이가 공분산 구조를 왜곡하지 않게 함
2. **공분산 계산**: 변수 간 함께 변하는 정도를 행렬로 계산하고 주성분 계산의 입력으로 사용함
3. **주성분 선택**: 고유값 또는 설명 분산비를 기준으로 필요한 축 개수를 결정함
4. **투영·검증**: 데이터를 선택 축으로 변환하고 재구성 오차, 예측 성능, 시각화 품질을 확인함

> 요약: PCA 절차는 표준화 후 분산 방향을 계산하고 누적 설명 분산비 기준으로 축을 골라 데이터를 압축하는 흐름임.

- **산출물**: 주성분 축, 설명 분산비, 투영 데이터, 로딩 값임
- **검증 기준**: 선택 축이 충분한 분산을 설명하고 후속 성능을 해치지 않아야 함
- **운영 기록**: 표준화 파라미터와 선택 주성분 수를 동일하게 재사용해야 함

## Ⅴ. 문제점

- **P1 스케일·이상치 민감성**: PCA는 분산이 큰 방향을 우선하므로 단위가 큰 변수나 극단값이 주성분을 왜곡할 수 있음
- **P2 선형 구조 한계**: 곡선형 매니폴드나 복잡한 군집 구조는 직선 축 투영만으로 충분히 보존되지 않음
- **P3 해석력 저하**: 주성분은 여러 변수의 선형 결합이므로 원변수 하나의 의미로 바로 설명하기 어려움

> 요약: PCA의 핵심 위험은 분산 기준이 데이터 품질과 선형 가정에 민감하고 결과 축의 의미가 약해질 수 있다는 점임.

## Ⅵ. 개선방안

- **P1 대응**: Robust scaling, 이상치 점검, 변수 변환을 먼저 수행함 (확인: 주성분 로딩 변화와 설명 분산비 안정성)
- **P2 대응**: 비선형 구조가 강하면 Kernel PCA, t-SNE, UMAP, 오토인코더를 후보로 비교함 (확인: 이웃 보존도와 후속 모델 성능)
- **P3 대응**: 로딩 값 상위 변수를 추적하고 주성분별 의미 라벨을 도메인 검토로 부여함 (확인: 주성분 설명 문서와 변수 기여도)

> 요약: PCA 개선은 전처리로 분산 왜곡을 줄이고, 선형 축이 맞는지 검증하며, 로딩 기반 해석을 보강하는 것임.

- **우선순위**: 표준화와 이상치 처리를 먼저 확인한 뒤 축 수를 조정함
- **확인 지표**: 누적 설명 분산비, 재구성 오차, downstream 성능을 함께 사용함
- **재평가 조건**: 변수 추가, 단위 변경, 데이터 분포 변화가 있으면 주성분을 재계산함

## Ⅶ. 전망

- **발전 방향**: PCA는 고차원 정형 데이터의 기준선 차원 축소, 시각화 사전 처리, 공선성 완화 방법으로 계속 활용될 것임
- **기술사적 판단**: 기술사는 누적 설명 분산비만 보지 않고 축 선택이 업무 해석과 후속 모델 성능에 미치는 영향을 함께 판단해야 함
- **기술사 제언**: 향후 PCA는 임베딩, 오토인코더, 대규모 행렬 분해와 함께 사용되어 고차원 데이터의 압축·탐색·품질 진단 단계에서 기본 도구 역할을 할 것임
