## 미리 알고가기

- 차원 축소(Dimension Reduction): 정보 손실을 제한하면서 변수 수를 줄이는 기법임
- 분산(Variance): 데이터가 평균에서 퍼진 정도이며 PCA에서는 보존할 정보량으로 봄
- 공분산 행렬: 변수 간 함께 변하는 정도를 행렬로 표현한 구조임
- 고유값($Eigenvalue$): 주성분 축이 설명하는 분산의 크기임
- 고유벡터($Eigenvector$): 원본 변수를 새 축으로 바꾸는 방향 벡터임
- 주성분 로딩: 각 원본 변수가 주성분 축을 구성하는 가중치임

## 작성 근거(검토용)

- PCA의 판단 축을 분산 보존과 선형 투영으로 제한해 차원 축소 일반론으로 흐르지 않게 함
- LDA와 t-SNE·UMAP을 비교 대상으로 두어 라벨 사용 여부와 비선형 시각화 차이를 드러냄
- 변수 단위가 다르면 큰 단위의 변수가 주성분을 지배하므로 표준화 조건을 특징·절차·사례에 반영함
- 고유값·고유벡터는 주성분 선택의 핵심 요소라 구성요소 표에 포함함
- 설명 분산과 해석 가능성의 충돌은 PCA 선택 기준이므로 결론과 사례에 반영함

## Ⅰ. 개요

- **정의/개념**: PCA는 고차원 데이터를 분산이 큰 직교 축으로 선형 투영해 정보 손실을 줄이면서 차원을 낮추는 기법임
- **배경/필요성**: 고차원 데이터의 계산량과 다중공선성을 줄이고 시각화하기 위해 설명 분산을 기준으로 유지할 차원을 선택해야 함

## Ⅱ. 특징

- 라벨을 사용하지 않고 입력 데이터의 공분산 구조만으로 새 축을 찾는 비지도 기법임
- 첫 번째 주성분은 가장 큰 분산을 설명하고 이후 주성분은 서로 직교하며 남은 분산을 설명함
- 변수 스케일이 다르면 큰 단위 변수가 주성분을 지배하므로 목적에 따라 표준화해야 함
- 주성분은 원본 변수의 선형 결합이므로 차원을 줄일 수 있지만 개별 변수의 의미는 직접 해석하기 어려움

## Ⅲ. 종류 및 비교

| 기준 | PCA | LDA | t-SNE·UMAP |
|:---|:---|:---|:---|
| 학습 방식 | 비지도 학습 | 지도 학습 | 비지도 비선형 축소 |
| 최적화 목표 | 전체 분산 보존 | 클래스 분리도 극대화 | 이웃 관계 보존 |
| 변환 성격 | 선형 투영 | 선형 판별 축 | 비선형 임베딩 |
| 주요 활용 | 압축·시각화·전처리 | 분류 전처리 | 고차원 데이터 시각화 |
| 유의점 | 주성분에서 원본 변수의 의미가 희석됨 | 클래스 라벨 필요 | 임베딩의 전역 거리를 원본 거리로 해석하기 어려움 |

> 요약: PCA는 분산 보존, LDA는 클래스 분리, t-SNE·UMAP은 시각적 이웃 구조에 초점을 둠.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 표준화 데이터 $X$ | 변수 단위를 맞춘 입력 행렬이며 분산 비교의 기준이 됨 |
| 공분산 행렬 | 변수 간 변동 관계를 담아 주성분 방향을 계산하는 기반이 됨 |
| 고유값·고유벡터 | 주성분의 중요도와 방향을 결정해 투영 행렬을 구성함 |
| 설명 분산 비율 | 선택한 주성분이 전체 변동 중 얼마를 보존하는지 보여줌 |
| 투영 데이터 $Z$ | $Z = XW$로 변환된 저차원 데이터이며 후속 분석에 사용됨 |

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 원본 행렬 | --> | 공분산    | --> | 주성분 축 | --> | 저차원 Z  |
+-----------+     +-----------+     +-----------+     +-----------+
```

> 요약: PCA는 공분산 구조에서 분산이 큰 직교 축을 찾아 저차원 좌표를 만듦.

## Ⅴ. 원리 및 절차 흐름도

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 표준화    | --> | 분해 수행 | --> | 축 선택   | --> | 데이터 투영 |
+-----------+     +-----------+     +-----------+     +-----------+
```

1. **중심화·스케일 조정** — 변수 평균을 0으로 맞추고 단위가 다르면 표준화해 분산 왜곡을 줄임
2. **분해 수행** — 공분산 행렬의 고유값 분해나 $SVD$로 주성분 방향을 계산함
3. **축 선택** — 고유값이 큰 순서로 정렬하고 누적 설명 분산 비율로 유지 차원 $k$를 정함
4. **데이터 투영** — 상위 $k$개 고유벡터 행렬에 원본 데이터를 곱해 저차원 좌표를 생성함

> 요약: 변수 단위가 다르면 먼저 표준화하고, 누적 설명 분산이 목표 수준에 이르는 주성분 수를 선택해야 주요 정보를 보존할 수 있음.

## Ⅵ. 실무 사례

1. 데이터센터 성능 지표 압축은 CPU·메모리·I/O를 표준화하고 누적 설명 분산으로 차원을 선택함
2. 서버 이상 탐지는 PCA 재구성 오차 임계값을 적용하고 오탐률·미탐률로 검증함

## Ⅶ. 결론

- PCA는 고차원 데이터의 분산을 보존해 차원을 낮추는 방법이므로 표준화·설명 분산·해석 가능성을 함께 판단해야 함
