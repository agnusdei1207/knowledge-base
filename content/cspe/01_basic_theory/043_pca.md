## 미리 알고가기

- 분산(Variance): 데이터가 평균에서 퍼진 정도이며 PCA에서는 보존할 정보량으로 봄
- 공분산 행렬(Covariance Matrix): 변수 간 함께 변하는 정도를 행렬로 표현한 구조임
- 고유값(Eigenvalue): 주성분 축이 설명하는 분산의 크기임
- 고유벡터(Eigenvector): 원본 변수를 새 축으로 바꾸는 방향 벡터임
- 선형 판별 분석(LDA): 클래스 라벨을 사용해 클래스 간 분리가 큰 선형 축을 찾는 기법임
- 비선형 차원 축소(t-SNE·UMAP): 고차원 데이터의 이웃 관계를 저차원에 표현하는 기법임
- 특이값 분해(Singular Value Decomposition, SVD): 행렬을 특이벡터와 특이값으로 분해해 주성분을 구하는 방법임
- 누적 설명 분산(Cumulative Explained Variance): 선택한 주성분이 설명하는 분산 비율의 합임
- 재구성 오차(Reconstruction Error): 저차원 데이터를 복원했을 때 원본과 생기는 차이임

## 작성 근거(검토용)

- **개요 구성**: PCA의 판단 축을 분산 보존과 선형 투영으로 제한해 차원 축소 일반론으로 흐르지 않게 함
- **Ⅲ. 비교축 선정**: LDA와 비선형 차원 축소를 비교해 축 생성 기준과 선형·비선형 변환 차이를 드러냄
- **Ⅱ·Ⅴ. 특징·절차 선정**: 변수 단위가 다르면 큰 단위의 변수가 주성분을 지배하므로 표준화 조건을 특징·절차에 반영함
- **Ⅳ. 구조 선정**: 고유값·고유벡터는 주성분 선택의 핵심 요소라 구성요소 표에 포함함
- **Ⅵ·Ⅶ. 사례·결론 선정**: 설명 분산과 해석 가능성의 충돌은 PCA 선택 기준이므로 결론과 사례에 반영함
- **전수 검수**: 제목부터 결론까지 용어·표·도식·요약을 대조하고 고유값·고유벡터 정의와 절 간 판단축을 일치시킴

## Ⅰ. 개요

- **정의/개념**: PCA는 분산이 큰 직교 축으로 데이터를 선형 투영해 차원을 낮추는 기법임
- **배경/필요성**: 고차원 데이터의 계산량·다중공선성을 줄이고 시각화하기 위해 차원 축소 기준이 필요함

### 쉽게 이해하기 (학습용)
- 여러 서랍에 나눠 넣은 물건들을 특징이 가장 잘 드러나는 큰 서랍 몇 개로 정리해 옮기는 것과 같음

## Ⅱ. 특징

- 라벨을 사용하지 않고 입력 데이터의 공분산 구조만으로 새 축을 찾는 비지도 기법임
- 첫 번째 주성분은 가장 큰 분산을 설명하고 이후 주성분은 서로 직교하며 남은 분산을 설명함
- 변수 스케일이 다르면 큰 단위 변수가 주성분을 지배하므로 목적에 따라 표준화해야 함
- 주성분은 원본 변수의 선형 결합이라 차원은 줄지만 개별 변수 의미는 해석하기 어려움

### 쉽게 이해하기 (학습용)
- 정답 없이 데이터가 가장 넓게 퍼진 방향부터 순서대로 사진을 찍되, 단위가 다른 자를 쓰면 큰 눈금 쪽이 사진을 지배하고, 여러 요소를 합성한 사진이라 개별 요소는 알아보기 어려움

## Ⅲ. 종류 및 비교

| 판단 기준 | PCA | LDA | 비선형 차원 축소 |
|:---|:---|:---|:---|
| 축 생성 기준 | 전체 분산 | 클래스 분리도 | 이웃 관계 |
| 변환 메커니즘 | 직교 선형 투영 | 선형 판별 투영 | 비선형 임베딩 |
| 주요 리스크 | 저분산 정보 손실 | 공분산 가정 위반 | 전역 거리 왜곡 |

> 요약: PCA는 분산 보존, LDA는 클래스 분리, t-SNE·UMAP은 이웃 구조 보존에 초점을 둠.

### 쉽게 이해하기 (학습용)
- PCA는 전체가 가장 잘 보이는 각도를 찾는 것, LDA는 두 그룹이 가장 잘 갈라져 보이는 각도를 찾는 것, 비선형 축소는 가까운 이웃끼리 사진에서도 가깝게 두는 것임

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 입력 행렬 $X$ | 중심화·선택적 표준화 데이터 |
| 공분산 행렬 | 변수 간 변동 관계 |
| 고유벡터 | 분산이 큰 직교 축 |
| 고유값 | 축별 설명 분산 |
| 투영 데이터 $Z$ | 상위 축의 저차원 좌표 |

> 요약: PCA는 공분산 행렬의 고유벡터를 분산 순으로 선택해 고차원 데이터를 저차원으로 투영함.

### 쉽게 이해하기 (학습용)
- 원재료 목록(입력 행렬)에서 무엇이 함께 움직이는지 표(공분산)를 만들고, 가장 크게 흔들리는 방향(고유벡터)과 그 크기(고유값)를 찾아 그 방향으로만 옮겨 적는 것과 같음

## Ⅴ. 원리 및 절차 흐름도

```text
중심화·스케일 조정 → 공분산 행렬·SVD 분해
                              ↓
                     고유값 내림차순 정렬
                              ↓
누적 설명 분산으로 축 선택 → 선택 축에 데이터 투영
```

1. **중심화·스케일 조정**: 변수 평균을 0으로 맞추고 단위가 다르면 표준화해 분산 왜곡을 줄임
2. **분해 수행**: 공분산 행렬의 고유값 분해나 SVD로 주성분 방향을 계산함
3. **축 선택**: 고유값이 큰 순서로 정렬하고 누적 설명 분산 비율로 유지 차원 $k$를 정함
4. **데이터 투영**: 상위 $k$개 고유벡터 행렬에 원본 데이터를 곱해 저차원 좌표를 생성함

> 요약: 변수 단위가 다르면 표준화하고 누적 설명 분산으로 주성분 수를 선택함.

### 쉽게 이해하기 (학습용)
- 기준점을 맞추고, 흔들림이 큰 방향부터 순서를 매긴 뒤, 필요한 만큼만 골라 그 방향으로 옮겨 그리는 절차임

## Ⅵ. 실무 사례

1. 데이터센터 지표 압축은 CPU·메모리·I/O를 표준화하고 주요 변동을 보존하는 축만 유지함
2. 서버 이상 탐지는 정상 지표의 PCA 재구성 오차보다 큰 관측값을 이상으로 분류함

### 쉽게 이해하기 (학습용)
- 여러 계기판 수치를 몇 개 핵심 그래프로 압축해 보거나, 평소와 다르게 복원이 잘 안 되는 상태를 이상 신호로 보는 것과 같음

## Ⅶ. 결론

- PCA는 데이터의 주요 변동을 보존하며 차원을 줄이고, 정보 손실과 결과 해석의 어려움을 함께 고려해야 함
- 모델 입력 압축에는 학습 데이터로만 축을 구해 누수를 막고, 설명 분산보다 재구성 오차·후속 모델 성능으로 유지 차원을 정해야 함

### 쉽게 이해하기 (학습용)
- 요약본을 만들 때 원본에서만 요약 기준을 정해야 하고, 요약이 얼마나 원본을 잘 되살리는지로 요약 분량을 정해야 함
