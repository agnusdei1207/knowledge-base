## 미리 알고가기

- 분산: 데이터가 퍼져 있는 정도임
- 공분산 행렬: 변수 간 함께 변하는 정도를 담은 행렬임
- 주성분: 분산을 가장 많이 설명하는 새로운 축임

## Ⅰ. 개요

- **정의/개념**: PCA는 고차원 데이터의 공분산 구조를 분석해 분산을 가장 많이 설명하는 직교 축으로 투영함으로써 차원을 줄이는 선형 변환 기법임
- **배경/필요성**: 변수 수가 많으면 계산량, 노이즈, 다중공선성이 커지므로 핵심 정보만 남기는 축소 기법이 필요함

## Ⅱ. 특징

- 분산이 큰 방향을 우선 보존해 정보 손실을 최소화함
- 직교 축을 사용해 중복 상관관계를 줄임
- 시각화, 전처리, 노이즈 완화에 효과적임
- 선형 구조만 반영하므로 비선형 데이터에는 한계가 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | PCA | LDA | t-SNE/UMAP |
|:---|:---|:---|:---|
| 학습 방식 | 비지도 | 지도 | 비지도 |
| 목표 | 분산 최대화 | 클래스 분리 | 국소 구조 시각화 |
| 선형성 | 선형 | 선형 | 비선형 |
| 대표 용도 | 전처리, 압축 | 분류 전처리 | 시각화 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 표준화된 데이터 | 평균과 스케일을 맞춘 입력이며 큰 단위 변수 왜곡을 막음 |
| 공분산 행렬 | 변수 관계를 요약하고 주성분 계산의 기반임 |
| 고유값/고유벡터 | 축의 중요도와 방향이며 설명 분산을 결정함 |
| 투영 행렬 | 선택된 축으로 이루어진 행렬이며 차원 축소 결과를 만듦 |

```text
+---------------+     +---------------+     +-------------------+     +-----------+
| 표준화된 데이터   | --> | 공분산 행렬       | --> | 고유값/고유벡터       | --> | 투영 행렬    |
+---------------+     +---------------+     +-------------------+     +-----------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 표준화 | --> | 공분산계산 | --> | 축선택 | --> | 투영변환 |
+----------+     +----------+     +----------+     +----------+
```

1. **표준화**: 변수 평균을 맞추고 스케일을 정규화함
2. **공분산계산**: 변수 간 분산 구조를 계산함
3. **축선택**: 큰 고유값을 가진 주성분을 선택함
4. **투영변환**: 원 데이터를 선택한 축으로 변환함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 주성분 해석이 직관적이지 않을 수 있어 여러 변수 혼합 축이 생김
   - 해결방안: loading 분석과 변수 기여도를 함께 제시하고 component loading로 검증함
2. 문제: 중요한 소수 클래스 정보가 분산이 작아 제거될 수 있어 분산 중심 기준의 한계임
   - 해결방안: 목적이 분류면 LDA나 supervised 방법과 비교하고 downstream accuracy로 검증함
3. 문제: 비선형 구조를 보존하지 못해 manifold 형태 데이터가 뭉개질 수 있음
   - 해결방안: kernel PCA나 UMAP을 검토하고 neighborhood preservation로 검증함

## Ⅶ. 적용 사례

- 머신러닝 전처리에서는 특징 수를 줄여 학습 안정성을 높임, 확인 지표는 설명 분산 비율과 학습시간임
- 시각화에서는 고차원 데이터를 2D/3D로 투영함, 확인 지표는 군집 분리도임
- 센서 데이터 압축에서는 상관 높은 신호를 축약함, 확인 지표는 재구성 오차임

## Ⅷ. 결론

PCA의 핵심은 차원을 줄이면서 분산을 최대한 보존하는 데 있으므로, 해석성과 정보 보존률을 함께 보고 주성분 수를 정해야 함.
