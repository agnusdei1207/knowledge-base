# 주성분 분석 PCA (Principal Component Analysis)

## 1. 개요

- **정의/개념**: PCA는 원 데이터의 분산을 가장 많이 설명하는 직교 축을 찾아 고차원 데이터를 저차원으로 투영하는 차원 축소 기법이다.
- **배경/필요성**: 변수 수가 많고 상관이 높은 데이터는 해석과 학습이 어려우므로, 정보 손실을 제한하면서 핵심 구조를 낮은 차원으로 요약할 필요가 있다.

PCA는 라벨을 고려하지 않고 분산 보존을 기준으로 축을 찾으므로, 예측 성능 향상과 항상 같은 목표는 아니다.

## 2. 특징 및 비교

| 구분 | PCA | Feature Selection | Autoencoder |
|---|---|---|---|
| 방식 | 새 축으로 선형 투영 | 기존 변수 일부 선택 | 비선형 압축 가능 |
| 기준 | 분산 최대화 | 중요 변수 선택 | 재구성 오차 |
| 해석성 | 주성분 해석 필요 | 상대적으로 높음 | 낮을 수 있음 |
| 전제 | 선형 구조 | 변수 중요도 정의 | 학습 데이터 필요 |

선택 기준은 선형성, 설명 분산, 해석 가능성, 스케일 민감도, 재구성 오차이다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| Standardization | 변수 스케일 보정 | 분산 왜곡 방지 |
| Covariance Matrix | 변수 간 공분산 구조 | 상관 정보 |
| Eigenvector | 주성분 방향 | 새 축 |
| Eigenvalue | 주성분 설명 분산 | 축 선택 기준 |
| Projection | 원 데이터를 주성분 축에 투영 | 차원 축소 |

```text
+----------+      +----------+      +----------+      +----------+
| 표준화   | ---> | 공분산   | ---> | 고유분해 | ---> | 저차원투영 |
+----------+      +----------+      +----------+      +----------+
```

분산을 보존하는 축을 찾는 구조이므로, 설명 분산 비율이 정보 손실 판단의 핵심 지표가 된다.

## 4. 문제점 및 개선방안

1. **스케일 민감성**
   - 변수 단위가 다르면 큰 단위 변수가 주성분을 지배할 수 있다.
   - **개선방안**: 표준화 또는 정규화를 먼저 수행한다.

2. **해석성 저하**
   - 주성분은 기존 변수의 선형 결합이므로 도메인 의미가 약해질 수 있다.
   - **개선방안**: loading 분석과 원 변수 기여도 해석을 병행한다.

3. **비선형 구조 한계**
   - 데이터 구조가 비선형이면 PCA 축이 핵심 패턴을 놓칠 수 있다.
   - **개선방안**: kernel PCA, t-SNE, UMAP, autoencoder를 검토한다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| 시각화 | 고차원 데이터를 2~3차원으로 투영 | 설명 분산, 군집 분리 |
| 전처리 | 상관 높은 변수를 축소해 모델 입력 구성 | 학습 시간, 성능 변화 |
| 이상 탐지 | 주성분 복원 오차로 이상 패턴 탐지 | 재구성 오차 |

## 6. 결론

PCA는 분산을 최대한 보존하며 차원을 줄이는 선형 차원 축소 기법이다. 표준화, 공분산, 고유값·고유벡터, 설명 분산 비율이 한 흐름으로 연결되어야 정보 손실과 해석 가능성을 함께 판단할 수 있다.
