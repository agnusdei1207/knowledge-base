## 미리 알고가기

- 차원 축소($Dimension$ $Reduction$): 데이터의 핵심 특징은 유지하면서 변수의 개수를 줄여 모델의 복잡도를 낮추는 기법임
- 분산($Variance$): 데이터가 퍼져 있는 정도이며, PCA에서는 이를 정보량의 크기로 간주함
- 공분산 행렬($Covariance$ $Matrix$): 여러 변수들 간의 상관관계를 한눈에 보여주는 정방행렬임
- 주성분($Principal$ $Component$): 원래 변수들의 선형 결합으로 만들어진, 서로 직교하면서 분산을 최대화하는 새로운 축임

## Ⅰ. 개요

- **정의/개념**: 주성분 분석(PCA)은 고차원 데이터의 분산을 가장 잘 설명하는 새로운 기저(주성분)를 찾아 데이터를 낮은 차원의 공간으로 투영함으로써, 정보 손실을 최소화하며 변수 간의 상관관계를 제거하는 대표적인 선형 차원 축소 기법임
- **배경/필요성**: 데이터의 변수가 너무 많으면 연산 비용이 급증하고 모델 성능이 떨어지는 '차원의 저주'와 '다중공선성' 문제가 발생하므로, 핵심 정보만을 추출하여 모델의 효율성과 시각화 가능성을 높이기 위해 사용됨

## Ⅱ. 특징

- 데이터의 변동성이 가장 큰 방향을 첫 번째 주성분($PC1$)으로 설정하고, 이와 직교하면서 다음으로 큰 변동성을 가진 축을 순차적으로 찾아내는 직교 변환 방식임
- 비지도 학습($Unsupervised$ $Learning$) 기법이므로 데이터의 라벨(정답)과 상관없이 오직 입력 데이터의 통계적 분포(공분산)만을 기준으로 차원을 축소함
- 고차원 공간에서 겹쳐 보였던 군집 구조를 주성분 축으로 투영하면 명확하게 분리되어 보일 수 있어, 데이터 시각화 및 클러스터링의 전처리 과정으로 매우 유용함

## Ⅲ. 종류 및 비교

| 판단 기준 | PCA (주성분 분석) | LDA (선형 판별 분석) |
|:---|:---|:---|
| **학습 방식** | 비지도 학습 (라벨 미사용) | 지도 학습 (라벨 사용) |
| **최적화 목표** | 데이터의 전체 분산 최대화 | 클래스 간 분리도 최대화 |
| **핵심 기법** | 공분산 행렬의 고유값 분해 | 클래스 내/간 분산 행렬 분석 |
| **주요 용도** | 특징 추출, 데이터 압축, 시각화 | 분류 전처리, 변별력 강화 |

> 요약: PCA는 정보의 '보존'에, LDA는 클래스 간 '변별'에 초점을 맞춘 차원 축소 기법임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 정규화된 데이터 | 각 변수의 평균을 0, 분산을 1로 맞춘 데이터로, 스케일 차이에 의한 왜곡을 방지함 |
| 고유값 ($\lambda$) | 각 주성분 축이 설명하는 분산의 크기이며, 주성분의 중요도를 결정함 |
| 고유벡터 ($v$) | 주성분 축의 방향을 나타내며, 원래 변수 공간에서 새로운 축으로의 변환 계수임 |
| 누적 설명 분산 | 선택된 주성분들이 전체 데이터의 정보량을 몇 %나 보존하는지 나타내는 지표임 |

```text
[ PCA 수행 수식 모델 ]
Z = X * W
- X: (n x d) 원본 데이터 행렬
- W: (d x k) 상위 k개 고유벡터 행렬
- Z: (n x k) 차원 축소된 데이터 행렬
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 데이터 정규화| --> | 공분산 행렬 산출| --> | 고유값/벡터 분해| --> | 주성분 선택/투영|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **전처리 수행** — 데이터의 스케일이 다르면 분산이 큰 변수에 주성분이 편향되므로, 반드시 표준화($Standard$ $Scaling$)를 통해 모든 변수의 기여도를 평등하게 맞춤
2. **공분산 행렬 분석** — 변수들 간의 연관성을 담은 공분산 행렬을 생성하고, 선형 대수학의 '고유값 분해' 또는 '특이값 분해($SVD$)'를 통해 주축을 추출함
3. **주성분 선별** — 계산된 고유값이 큰 순서대로 주성분을 정렬하고, 누적 설명 분산 비율(보통 80~90% 이상)을 확인하여 유지할 차원의 수($k$)를 결정함
4. **데이터 투영** — 선택된 $k$개의 고유벡터로 구성된 행렬을 원본 데이터에 곱하여, 새로운 저차원 좌표계로 데이터를 변환함

## Ⅵ. 실무 적용 및 유의점

1. PCA로 생성된 새로운 변수(주성분)들은 원래 변수들의 복잡한 선형 결합으로 이루어져 있어, 모델의 성능은 좋아질 수 있으나 각 주성분이 물리적으로 무엇을 의미하는지 해석하기 어렵다는 '설명력의 한계'를 인지해야 함
2. 데이터의 분포가 직선이 아닌 곡선 형태(비선형)를 띠고 있을 경우, 선형 투영 방식인 PCA는 정보 손실이 매우 클 수 있으므로 '커널 PCA($Kernel$ $PCA$)'나 't-SNE', 'UMAP' 등 비선형 차원 축소 기법을 검토해야 함

## Ⅶ. 결론

- PCA는 정보의 핵심 정수만을 추출하여 복잡한 시스템을 효율적으로 관리하게 해주는 차원 축소의 표준이며, 설계자는 정보 보존율과 계산 효율성 사이의 균형을 고려하여 최적의 주성분 개수를 도출해야 함
