## Ⅰ. 개요
- **정의**: 머신러닝 알고리즘을 데이터 정답 유무와 상호작용 방식에 따라 3가지 패러다임으로 분류한 체계임.
- **배경/필요성**: 해결하고자 하는 문제 특성과 수집된 데이터 형태에 맞는 최적의 알고리즘을 선택하기 위해 필수적임.
- **출제 의도**: 각 학습 방식의 입력 조건, 목표, 대표 알고리즘을 명확하게 구분할 수 있는지 평가함.

## Ⅱ. 구성요소
```text
+------------------+       +------------------+       +------------------+
| Supervised (L)   |       | Unsupervised (U) |       | Reinforcement(R) |
| Data + Label     |       | Data Only        |       | State -> Action  |
+------------------+       +------------------+       +------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 지도 학습 (L) | 입력(X)과 정답(Y)이 주어져 예측 모델을 학습 | 선생님이 정답 제공 |
| 비지도 학습 (U) | 정답 없이 데이터 숨은 패턴과 구조를 스스로 학습 | 학생 스스로 유사점 탐색 |
| 강화 학습 (R) | 에이전트가 환경과 상호작용하며 보상을 최대화 | 자전거 타며 넘어지며 배움 |

> 요약: 정답 유무에 따라 지도/비지도로 나뉘며, 행동 보상 체계에 따라 강화학습으로 구분됨.

## Ⅲ. 절차
```text
+-------------+   +-------------+   +-------------+   +-------------+
| 1. 문제     |-->| 2. 데이터   |-->| 3. 패러다임 |-->| 4. 알고리즘 |
|    정의     |   |    확인     |   |    선택     |   |    적용     |
+-------------+   +-------------+   +-------------+   +-------------+
```
1. **문제 정의**: 스팸 분류, 고객 군집화 등 해결할 과제의 목표를 설정함.
2. **데이터 확인**: 정답 레이블이 있는지, 피드백을 줄 수 있는 환경이 있는지 확인함.
3. **패러다임 선택**: 조건에 맞추어 지도, 비지도, 강화학습 중 결정함.
4. **알고리즘 적용**: 지도(결정 트리), 비지도(K-Means), 강화(DQN) 모델을 학습시킴.

> 요약: 데이터 형태와 목표에 맞춰 지도, 비지도, 강화 학습 패러다임을 선택하고 적용함.

## Ⅳ. 문제점
- **레이블링 비용(지도)**: 고품질 정답 데이터를 구축하는 데 막대한 비용이 소모됨.
- **평가 모호성(비지도)**: 정답이 없으므로 군집화 결과가 유의미한지 객관적 입증이 어려움.

## Ⅴ. 개선방안
- **레이블링 비용**: (단기) 전이 학습 활용 / (장기) 준지도 학습 및 능동 학습 도입 필요.
- **평가 모호성**: (단기) 내부 평가 지표 활용 / (장기) 도메인 전문가 정성적 검증 필요.

## Ⅵ. 전망
- 최근에는 지도/비지도의 경계가 허물어지는 자가지도 학습이 대규모 훈련의 핵심으로 부상함.
