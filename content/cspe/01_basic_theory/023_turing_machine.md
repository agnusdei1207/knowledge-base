## Ⅰ. 개요
- 정의: 무한한 테이프와 헤드를 가진 가상의 기계로, 현대 컴퓨터의 수학적 모델임
- 배경/필요성: 계산 가능성(Computability)과 알고리즘의 한계를 정의하기 위해 고안됨
- 출제 의도: 계산 모델의 이해, 정지 문제(Halting Problem), 촘스키 계층 연관성 확인

## Ⅱ. 구성요소
- ASCII 구조도
   Tape: | a | b | c | B | B | ...
           ^ (Head)
   +-----------------------+
   | Finite State Control  |
   +-----------------------+

- 구성요소 표
| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| 테이프 | 무한한 길이를 가진 데이터 저장 공간 | 메모리(RAM) |
| 헤드 | 테이프의 심볼을 읽거나 쓰는 장치 | CPU 코어 |
| 상태 천이 함수 | 현재 상태와 심볼에 따른 다음 동작 정의 | 명령어 세트 |
| 정지 상태 | 계산이 완료되어 멈추는 최종 상태 | 프로그램 종료 |
> 요약: 튜링 머신은 상태, 심볼, 이동 방향의 조합으로 모든 계산 과정을 추상화함

## Ⅲ. 절차
- ASCII 흐름도
  [Input] -> [Read Symbol] -> [Write/Move] -> [State Change] -> [Halt?]

1. 초기 설정: 테이프에 입력을 기록하고 시작 상태에서 출발함
2. 심볼 스캔: 현재 헤드 위치의 기호를 읽어 천이 규칙을 참조함
3. 연산 수행: 테이프에 기호를 쓰거나 헤드를 좌/우로 1칸 이동함
4. 상태 전이: 다음 상태로 전이하며 정지 상태 도달 시 결과를 출력함
> 요약: 단순한 동작의 반복을 통해 복잡한 알고리즘을 수행하는 절차적 모델임

## Ⅳ. 문제점
- 정지 문제: 임의의 프로그램이 종료될지 여부를 판단할 수 없는 결정 불가능성 존재함
- 자원 무한성: 실제 하드웨어와 달리 무한한 메모리를 전제로 하는 이론적 한계임

## Ⅴ. 개선방안
- 범용 튜링 머신(UTM): 임의의 튜링 머신을 시뮬레이션하는 현대 컴퓨터의 모태가 됨
- 폰 노이만 구조: 실제 물리적 제약 내에서 계산을 구현하기 위한 아키텍처로 발전함

## Ⅵ. 전망
- 양자 계산 모델: 기존 튜링 머신을 넘어 큐비트 중첩과 얽힘을 이용한 양자 튜링 머신(QTM) 연구가 슈퍼컴퓨팅의 한계 돌파를 주도함
- 계산 복잡도 혁신: P vs NP 등 난제 해결을 위한 수학적 도구로서, AI 알고리즘의 효율성 한계를 규명하는 이론적 이정표 역할을 지속함
- CSF: 물리적 하드웨어의 제약 조건을 반영한 자원 유한 튜링 머신 모델링과 실제 알고리즘의 시간/공간 복잡도 최적화가 실무적 관건임
