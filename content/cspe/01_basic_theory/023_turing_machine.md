## Ⅰ. 개요
- **정의**: 무한 테이프, 헤드, 상태 전이 함수로 구성된 추상 계산 모델
- **배경/필요성**: "계산 가능하다"의 의미를 수학적으로 정의할 기준 모델이 필요함. 모든 알고리즘의 이론적 한계를 판별하는 기반 도구로 활용됨
- **비유**: 무한히 긴 종이 테이프 위를 한 칸씩 이동하며 규칙표대로 글자를 읽고 쓰는 자동 필기 로봇

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 계산 가능성 이론의 기초 모델 이해 | 7-튜플 구성, 정지 문제 비결정성, Church-Turing 논제 | 결정적 vs 비결정적 TM 구분, 만능 TM 개념 누락 주의 |

> 요약: 튜링 머신은 알고리즘이 풀 수 있는 문제의 이론적 경계를 정의하는 기초 계산 모델임

## Ⅱ. 구성요소
```text
[입력 문자열]
     |
     v
+------------+     +---------------------------+
| 유한 제어기 |---->| 무한 테이프 (셀 배열)      |
| (상태 집합) |     | ... | a | b | _ | c | ... |
+------------+     +---------------------------+
     |                        ^
     v                        |
+------------------+          |
| 전이 함수 delta  |----------+
| (읽기/쓰기/이동) |   헤드 (R/L/S)
+------------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 테이프(Tape) | 무한 길이의 셀 배열로, 각 셀에 기호 1개를 저장함 | 끝없이 이어진 모눈종이 한 줄 |
| 헤드(Head) | 현재 셀을 읽고 쓰며 좌/우로 한 칸씩 이동함 | 모눈종이 위의 연필 커서 |
| 상태 집합(Q) | 유한 개의 내부 상태로 현재 동작 맥락을 표현함 | 로봇의 현재 기분(모드) |
| 전이 함수(delta) | (현재 상태, 읽은 기호) → (다음 상태, 쓸 기호, 이동 방향) 매핑 | 규칙표(매뉴얼) |
| 시작 상태(`q0`) | 계산 시작 시 초기 상태 | 전원 켜진 직후 상태 |
| 수락/거부 상태 | 입력 문자열의 수락 또는 거부를 결정하는 종료 상태 | 합격/불합격 판정 램프 |

> 요약: 테이프·헤드·유한 상태·전이 함수 4가지가 튜링 머신의 핵심 구성임

## Ⅲ. 절차
```text
초기화 --> 읽기 --> 전이 적용 --> 종료 판정
  |                    |              |
  v                    v              v
테이프에 입력 배치   쓰기+이동     수락/거부/무한루프
```
- 1단계: 입력 문자열을 테이프 셀에 배치하고, 헤드를 첫 셀, 상태를 `q0`으로 설정함
- 2단계: 헤드가 현재 셀의 기호를 읽고, 전이 함수 `delta(q, a)`를 조회함
- 3단계: 조회 결과에 따라 셀에 기호를 쓰고, 헤드를 좌/우로 이동하며, 상태를 전이함
- 4단계: 수락 상태 도달 시 수락, 거부 상태 도달 시 거부, 어느 쪽도 아니면 2단계로 복귀함(정지하지 않을 수 있음)

> 요약: 읽기-전이-쓰기-이동을 반복하며 종료 상태 도달 여부로 계산 결과를 판정함

## Ⅳ. 문제점
- 정지 문제(Halting Problem): 전이 함수가 종료 상태에 도달하지 못하는 입력이 존재함 — 임의의 TM과 입력에 대해 정지 여부를 판별하는 일반 알고리즘이 존재하지 않음
- 공간 비효율: 테이프가 무한 길이를 전제함 — 실제 물리 메모리는 유한하므로 직접 구현 불가능함
- 비결정적 분기 폭발: 비결정적 TM(NTM)은 한 상태에서 복수 전이가 허용됨 — 탐색 경로가 지수적으로 증가하여 결정적 시뮬레이션 비용이 큼

> 요약: 정지 불가판별·무한 자원 전제·비결정 분기 폭발이 이론적·실용적 한계임

## Ⅴ. 개선방안
1. 단기: 제한된 테이프(Linear Bounded Automaton)를 적용하여 유한 메모리 환경에서 문맥 의존 언어 인식에 활용함
2. 중기: 오라클 TM·확률적 TM 등 확장 모델을 도입하여 특정 문제 클래스의 계산 복잡도를 세분화함
3. 장기: 양자 튜링 머신(QTM) 모델을 통해 중첩·얽힘 기반 병렬 탐색으로 비결정적 분기 비용을 저감함

> 요약: 유한 자원 제한 → 확장 모델 세분화 → 양자 모델 순으로 한계를 보완함

## Ⅵ. 전망
- 발전 방향: 양자 컴퓨팅·DNA 컴퓨팅 등 비전통 계산 모델이 TM 등가성 기준으로 평가됨
- 기술사적 판단: Church-Turing 논제는 "효과적으로 계산 가능한 함수 = TM이 계산 가능한 함수"라는 합의로, 모든 계산 모델 비교의 기준선 역할을 유지함
- 기술사 제언: 알고리즘 설계 시 문제의 결정 가능성(decidability)을 먼저 판별하고, 비결정 문제는 근사·휴리스틱 전략을 수립할 필요가 있음
