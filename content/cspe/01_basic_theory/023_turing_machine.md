## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 무한 테이프·읽기/쓰기 헤드·유한 상태 제어기로 구성된 추상 계산 모델로, 계산 가능한 모든 함수를 계산할 수 있는 보편 기계임 |
| **배경/필요성** | "계산 가능하다"의 수학적 정의가 필요하며, 모든 알고리즘의 한계(정지 문제 등)를 분석하는 이론적 기반임 |
| **출제 의도** | 튜링 머신의 동작 원리와 처치-튜링 논제, 정지 문제의 비결정성을 이해하는지 평가함 |

## Ⅱ. 구성요소
```
+----------+     +----------+     +----------+
| 무한테이프| --> | 헤드     | --> | 상태제어기|
| (입력저장)|     | (R/W)    |     | (유한상태)|
+----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| 무한 테이프 | 셀로 구분된 무한 길이 테이프에 입력 기호와 공백이 저장됨 | 무한 줄노트 |
| 읽기/쓰기 헤드 | 현재 셀의 기호를 읽고, 새 기호를 쓰고, 좌·우로 이동함 | 연필·지우개가 달린 손가락 |
| 상태 제어기 | 유한 상태 집합과 전이 함수 δ(q, a) = (q', b, D)로 동작을 결정함 | 규칙표에 따라 행동하는 사람 |

> 요약: 테이프(저장) + 헤드(읽기/쓰기/이동) + 제어기(상태 전이)로 모든 계산을 모델링함.

## Ⅲ. 절차
```
+------------+     +------------+
| 초기상태   | --> | 기호읽기   |
| 테이프세팅 |     | (헤드위치) |
+------------+     +------------+
                        |
+------------+     +----+-------+
| 수락/거부  | <-- | 전이수행  |
| /무한루프  |     | 쓰기·이동  |
+------------+     +------------+
```

1. 초기화: 입력 문자열을 테이프에 쓰고, 헤드를 첫 셀에, 상태를 초기 상태 q0으로 설정함
2. 기호 읽기: 헤드 위치의 셀에서 현재 기호를 읽음
3. 전이 수행: δ(현재 상태, 읽은 기호)에 따라 기호를 쓰고, 헤드를 이동하고, 상태를 전이함
4. 종료 판정: 수락 상태에 도달하면 수락, 거부 상태면 거부, 도달하지 못하면 무한 루프함

> 요약: 초기화 → 읽기 → 전이(쓰기·이동) → 종료/무한루프로 계산을 수행함.

## Ⅳ. 문제점
- 정지 문제 비결정: 임의의 TM이 정지하는지 판별하는 알고리즘이 존재하지 않음(비결정 문제)
- 실용성 부재: 실제 컴퓨터의 유한 메모리·시간 제약을 반영하지 못하는 추상 모델임
- 복잡도 분석 한계: TM 단계 수 기반 분석이 실제 CPU 성능과 괴리가 있음

## Ⅴ. 개선방안
- (단기) 다중 테이프 TM: 테이프를 여러 개 사용하여 시뮬레이션 효율을 개선함(계산력은 동일)
- (중기) RAM 모델: 임의 접근 메모리 모델로 실제 컴퓨터에 가까운 복잡도 분석을 수행함
- (장기) 양자 튜링 머신: 중첩·얽힘을 활용하는 양자 TM으로 특정 문제의 복잡도를 줄임

## Ⅵ. 전망
- 처치-튜링 논제가 계산 이론의 기초로 유지되며, 양자 TM·DNA 컴퓨팅 등 비전통적 계산 모델이 튜링 계산 한계를 넘는지에 대한 연구가 지속될 전망임
