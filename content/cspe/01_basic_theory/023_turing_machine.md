## 미리 알고가기

- 테이프: 읽기/쓰기 가능한 무한 길이 저장 공간 모델임
- 헤드: 테이프의 현재 셀을 읽고 쓰며 이동하는 장치임
- 상태 전이: 현재 상태와 입력 기호에 따라 다음 행동을 결정함

## Ⅰ. 개요

- **정의/개념**: 튜링 머신은 유한 제어기, 무한 테이프, 읽기/쓰기 헤드로 구성되어 알고리즘적 계산 가능성을 추상화한 계산 모델임
- **배경/필요성**: 어떤 문제가 절차적으로 계산 가능한지, 계산 자원과 한계가 무엇인지 정의하려면 보편적인 계산 기준 모델이 필요함

## Ⅱ. 특징

- 조건 분기, 반복, 메모리 갱신을 모두 표현할 수 있어 범용 계산 모델이 됨
- 단순한 규칙 집합으로 현대 컴퓨터의 계산 본질을 설명할 수 있음
- 결정 가능성과 계산 불가능성을 구분하는 이론적 기준을 제공함
- 실제 하드웨어보다 비효율적이지만 계산 가능성 정의에는 가장 강력한 기준임

## Ⅲ. 종류 및 비교

| 판단 기준 | 유한 오토마타 | 푸시다운 오토마타 | 튜링 머신 |
|:---|:---|:---|:---|
| 기억 구조 | 상태만 | 상태 + 스택 | 상태 + 무한 테이프 |
| 표현력 | 정규 언어 | 문맥 자유 언어 | 재귀 열거 가능 언어 |
| 대표 한계 | 장거리 의존성 불가 | 임의 위치 수정 불가 | 계산 불가능성만 남음 |
| 의미 | 패턴 인식 | 구문 인식 | 범용 계산 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 상태 집합 $Q$ | 제어 로직을 표현하고 알고리즘 분기를 담당함 |
| 테이프 기호 $\Gamma$ | 저장 가능한 심볼 집합이며 작업 메모리 역할임 |
| 전이 함수 $\delta$ | 읽기, 쓰기, 이동을 지정하고 실제 계산 규칙임 |
| 수용/거부 상태 | 계산 종료 조건이며 문제 판정 결과임 |

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 기호읽기 | --> | 규칙선택 | --> | 쓰기/이동 | --> | 종료판정 |
+----------+     +----------+     +----------+     +----------+
```

1. **기호읽기**: 헤드가 현재 테이프 셀의 기호를 읽음
2. **규칙선택**: 현재 상태와 기호에 맞는 전이 규칙을 찾음
3. **쓰기/이동**: 새 기호를 기록하고 좌우로 이동함
4. **종료판정**: 수용 또는 거부 상태면 계산을 끝냄

## Ⅵ. 문제점 및 해결 방안

1. 문제: 실행 효율이 낮아 실제 컴퓨터 구조보다 지나치게 추상적임
   - 해결방안: 성능 분석은 RAM 모델, 회로 모델 등으로 보완하고 복잡도 추정 일관성로 검증함
2. 문제: 정지 여부를 일반적으로 판정할 수 없음 정지 문제는 결정 불가능함
   - 해결방안: 입력 범위를 제한하거나 완전성보다 근사 판정을 선택하고 검증 가능한 입력 비율로 검증함
3. 문제: 이론과 구현의 간격이 커 모델 이해가 실무 설계로 직접 이어지지 않을 수 있음
   - 해결방안: 계산 가능성, 환원, 복잡도 증명 도구로 활용 범위를 명확히 하고 문제 분류 정확도로 검증함

## Ⅶ. 적용 사례

- 계산 이론 교육에서는 알고리즘과 계산 가능성의 기준 모델로 사용함, 확인 지표는 환원 및 증명 가능성임
- 컴파일러와 언어 설계에서는 언어 표현력 상한을 설명하는 근거로 활용함, 확인 지표는 언어 클래스 분류 정확도임
- 복잡도 이론 연구에서는 P, NP, 결정 불가능 문제를 정의함, 확인 지표는 문제 환원 타당성임

## Ⅷ. 결론

튜링 머신의 핵심 가치는 실행 속도가 아니라 계산 가능성의 경계를 정의하는 데 있으므로, 문제를 풀기 전에 먼저 계산 가능한지부터 판단하는 기준으로 써야 함.
