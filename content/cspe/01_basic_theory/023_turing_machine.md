## 미리 알고가기

- 테이프: 기호를 저장하는 무한한 칸의 열이며 추상 메모리 역할을 함
- 헤드: 현재 칸의 기호를 읽고 쓰며 좌우로 이동하는 장치임
- 상태 집합($Q$): 제어부가 가질 수 있는 유한한 내부 상태의 집합임
- 전이 함수($\delta$): 현재 상태와 기호를 다음 상태, 기록 기호, 헤드 이동 방향 $L/R$로 바꾸는 규칙임
- 공백 기호($B$): 입력이 기록되지 않은 테이프 칸을 나타내는 기호임
- 유한 오토마타: 현재 상태만 기억하며 정규 언어를 인식하는 계산 모델임
- 푸시다운 오토마타: 유한 상태와 스택으로 문맥 자유 언어를 인식하는 계산 모델임
- 재귀 열거 언어: 속한 문자열은 튜링 머신이 수용하지만 속하지 않은 입력에서는 정지하지 않을 수 있는 언어임
- 튜링 완전: 튜링 머신과 같은 계산 능력을 가진 언어나 시스템의 성질임
- 정지 문제: 임의의 프로그램이 멈출지 일반적으로 판정 불가능한 문제임

## 작성 근거(검토용)

- 기출 키워드이므로 정의에서 계산 가능성의 경계와 추상 기계 구성을 동시에 제시함
- 특징은 범용성·기억 능력·언어 계층·결정 불가능성을 순서대로 배치해 이론적 의의를 드러냄
- Ⅲ은 처리 메커니즘, 인식 범위, 주요 한계로 FA·PDA·TM의 계산 능력을 비교함
- Ⅳ와 Ⅴ는 전이 함수 한 단계가 전체 계산으로 반복되는 구조를 답안지에서 추적 가능하게 작성함
- 튜링 완전성이 보안·가용성 문제로 이어지는 지점을 자원 제한과 검증 지표로 연결함

## Ⅰ. 개요

- **정의/개념**: 튜링 머신은 유한 상태 제어부·무한 테이프·읽기·쓰기 헤드로 계산 절차를 모델링해 알고리즘으로 계산 가능한 범위를 정의하는 추상 기계임
- **배경/필요성**: 계산 가능성과 불가능성의 경계 설명을 위해 구현과 무관한 계산 모델이 필요함

## Ⅱ. 특징

- 읽기·쓰기·좌우 이동·상태 전이의 네 동작을 반복해 알고리즘적 계산을 표현함
- 무한 테이프를 가정해 유한 오토마타와 푸시다운 오토마타보다 큰 기억 능력을 가짐
- 재귀 열거 언어를 인식하며 범용 프로그래밍 언어의 계산 능력 기준이 됨
- 정지 문제처럼 어떤 문제는 계산 자원을 늘려도 일반 해법이 없음을 보임

## Ⅲ. 종류 및 비교

| 판단 기준 | 유한 오토마타 | 푸시다운 오토마타 | 튜링 머신 |
|:---|:---|:---|:---|
| 처리 메커니즘 | 현재 상태로 입력을 단방향 처리 | 스택으로 입력을 단방향 처리 | 테이프를 읽고 쓰며 양방향 이동 |
| 인식 범위 | 정규 언어 | 문맥 자유 언어 | 재귀 열거 언어 |
| 주요 한계 | 같은 수의 기호 대응 불가 | 범용 계산 표현 불가 | 일반 정지 여부 판정 불가 |

> 요약: 기억 구조가 확장될수록 인식 범위가 넓어지지만 임의 프로그램의 정지 여부는 일반적으로 판정할 수 없음.

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 상태 제어부 | 현재 상태 저장·다음 동작 선택 |
| 테이프 | 입력·중간값·출력의 추상 저장소 |
| 헤드 | 기호 읽기·쓰기·좌우 이동 |
| 전이 함수 | $(q, a) \rightarrow (q', b, L/R)$ 상태·기호·이동 규칙 |
| 정지 상태 | 수용·거부 결과를 확정하는 종료 상태 |

```text
+----------------+
| 상태 제어부     |
+----------------+
        |
        v
... [B] [0] [1] [B] [B] ...
            ^
            |
            헤드
```

> 요약: 튜링 머신은 전이 함수로 테이프 읽기와 쓰기를 반복하고 정지 상태에서 결과를 확정함.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 초기화    | --> | 기호 판독  | --> | 상태 전이  | --> | 정지 판정  |
+----------+     +----------+     +----------+     +----------+
```

1. **초기화**: 입력을 테이프에 쓰고 헤드를 시작 위치에 둔 뒤 초기 상태로 설정함
2. **기호 판독**: 현재 상태와 헤드가 가리키는 기호를 전이 함수 입력으로 사용함
3. **상태 전이**: 새 기호를 기록하고 헤드를 이동하며 다음 상태로 바꿈
4. **정지 판정**: 수용·거부 상태에 도달하면 멈추고, 아니면 전이를 반복함

> 요약: 한 단계 전이 규칙을 반복해 계산을 진행하고 정지 상태에서 결과를 확정함.

## Ⅵ. 실무 사례

1. 규칙 실행 플랫폼은 튜링 완전 스크립트에 실행 시간·메모리 한도를 적용하고 제한 위반 건수를 확인함
2. 정적 분석 도구는 무한 반복 가능 경로를 탐지하고 종료 조건 누락 경고 수를 확인함

## Ⅶ. 결론

- 튜링 머신은 계산 가능성의 기준이며, 튜링 완전한 규칙 언어를 허용하는 시스템은 실행 시간·메모리·종료 조건을 통제해야 함
