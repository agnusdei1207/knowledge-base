## 미리 알고가기

- 조합 논리 회로: 출력이 현재 입력 조합으로만 결정되고 내부 상태를 저장하지 않는 회로임
- 전가산기: 두 입력 비트와 하위 자리 캐리까지 더해 합과 상위 캐리를 출력하는 회로임
- 멀티플렉서($MUX$): 여러 입력 중 선택 신호가 지정한 하나를 출력하는 데이터 선택기임
- 디코더: $n$비트 입력을 $2^n$개 출력 중 하나로 펼치는 회로임
- 전파 지연: 입력 변화가 출력에 안정적으로 반영될 때까지 걸리는 시간임
- 크리티컬 패스: 회로에서 가장 긴 지연을 갖는 경로이며 최대 동작 속도를 제한함

## 작성 근거(검토용)

- 개요는 상태 저장이 없고 현재 입력만 본다는 조합 논리의 경계를 먼저 제시함
- 특징은 결정성·전파 지연·최소화·샘플링 조건을 선별해 순서 논리와 자연스럽게 대비되게 함
- Ⅲ은 _keywords.md의 가산기·멀티플렉서를 중심으로 디코더와 비교기를 보조 유형으로 배치함
- Ⅳ와 Ⅴ는 게이트 연결과 지연 흐름을 나누어 회로 구조와 동작 시간을 함께 설명함
- 고속 가산기 병목과 MUX 글리치처럼 실제 설계 검증에서 자주 보는 위험을 남김

## Ⅰ. 개요

- **정의/개념**: 조합 논리 회로는 기억 소자 없이 논리 게이트의 연결만으로 현재 입력에 대응하는 출력을 전파 지연 후 생성하는 디지털 회로임
- **배경/필요성**: ALU 연산·주소 해독·데이터 선택을 현재 입력만으로 처리하기 위해 조합 논리 블록이 필요함

## Ⅱ. 특징

- 같은 입력 조합에는 항상 같은 출력이 나오는 결정적 회로임
- 내부 상태가 없으므로 클록이 아니라 게이트 전파 지연이 동작 속도를 제한함
- 부울식 최소화로 게이트 수·면적·전력 소모를 줄임
- 출력 안정 전 샘플링하면 잘못된 값이 저장되므로 다음 순서 회로의 샘플링 타이밍과 맞아야 함

## Ⅲ. 종류 및 비교

| 회로 | 입력·출력 | 핵심 기능 | 주요 활용 |
|:---|:---|:---|:---|
| 반가산기 | 2입력·합·자리올림 | 두 비트 합산 | 단순 비트 연산 |
| 전가산기 | 3입력·합·자리올림 | 자리올림 포함 합산 | ALU·다비트 가산기 |
| 멀티플렉서 | 다중 입력·단일 출력 | 입력 중 하나 선택 | 데이터 경로 선택 |
| 디코더 | $n$입력·$2^n$출력 | 코드 해독 | 주소 선택·명령 해독 |
| 비교기 | 두 입력·비교 결과 | 크기·동등성 판정 | 분기·정렬 하드웨어 |

> 요약: 가산기는 계산을 담당하고, MUX·디코더·비교기는 데이터 흐름과 제어 조건을 결정함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 입력선 | 데이터 비트와 선택 신호를 회로 내부 게이트로 전달함 |
| 논리 게이트 | AND, OR, XOR, NOT 조합으로 목표 논리식을 구현함 |
| 캐리 경로 | 가산기에서 하위 비트 결과를 상위 비트 계산에 전달함 |
| 선택 신호 | MUX나 디코더에서 어떤 데이터 경로를 열지 결정함 |
| 출력선 | 게이트 지연 후 안정된 계산 결과를 다음 회로로 전달함 |

```text
전가산기

A -----+
       +--> [ XOR ] ----+
B -----+                +--> Sum
Cin --------------------+

A,B,Cin --> [ 캐리 로직 ] --> Cout
```

> 요약: 조합 논리 회로는 게이트 연결로 현재 입력의 계산 결과를 상태 저장 없이 산출함.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 입력 확정  | --> | 게이트 계산 | --> | 지연 통과  | --> | 출력 확정  |
+----------+     +----------+     +----------+     +----------+
```

1. **입력 안정**: 데이터와 선택 신호가 입력단에 도달하고 전압 레벨이 고정됨
2. **논리 평가**: 각 게이트가 입력 조합에 맞는 중간 결과를 병렬로 계산함
3. **지연 통과**: 캐리 경로나 선택 경로의 전파 지연이 끝날 때까지 기다림
4. **출력 확정**: 최종 출력이 안정되면 다음 순서 회로나 외부 블록이 값을 사용함

> 요약: 논리식이 맞아도 전파 지연 뒤에만 다음 회로가 출력을 안전하게 사용할 수 있음.

## Ⅵ. 실무 사례

1. 다비트 가산기는 리플 캐리 지연이 클록 주기를 제한하므로 캐리 선견이나 병렬 프리픽스 구조를 적용하고 크리티컬 패스 지연으로 검증함
2. MUX 선택 신호가 바뀔 때 글리치 위험이 커지므로 선택 신호 타이밍을 제한하거나 출력 레지스터를 두고 파형 시뮬레이션으로 확인함

## Ⅶ. 결론

- 조합 논리 회로는 현재 입력을 빠르게 계산하는 하드웨어 블록이므로 논리 최소화와 전파 지연을 함께 검토해야 다음 순서 회로가 올바른 값을 샘플링함
