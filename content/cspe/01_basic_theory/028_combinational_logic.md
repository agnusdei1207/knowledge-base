## 미리 알고가기

- 조합 논리(Combinational Logic): 회로 내부에 이전 상태를 기억하는 요소가 없어서, 지금 들어온 입력 조합만 보고 출력이 그 자리에서 정해지는 회로임. 계산기가 숫자를 누르는 즉시 결과를 보여주듯, 과거 입력을 몰라도 지금 입력만 알면 출력을 그대로 예측할 수 있음
- 전파 지연(Propagation Delay): 입력 신호가 바뀐 순간부터 그 변화가 게이트를 통과해 출력에 실제로 나타나기까지 걸리는 시간임. 여러 사람이 줄지어 말을 전달하는 전달 게임처럼, 게이트를 하나씩 거칠 때마다 신호 전달에 시간이 쌓임
- 선택 신호(Select Signal): 여러 입력 후보 중 하나를 골라 출력으로 내보내라고 지정하는 제어 비트임. 리모컨의 채널 버튼처럼, 어떤 값을 통과시킬지 지정하는 역할을 함
- fan-in: 게이트 하나에 동시에 들어오는 입력선의 개수임. 입력선이 많아질수록 게이트가 판단해야 할 조합 수가 늘어나 지연과 전력 소모가 함께 커짐
- ALU(Arithmetic Logic Unit): 산술 연산과 논리 연산을 실제로 수행하는 하드웨어 연산 장치이며, 가산기가 그 핵심 구성 요소임
- MUX(Multiplexer): 여러 입력 중 선택 신호가 지정한 하나만 출력으로 내보내는 선택 회로이며, 본문에서는 멀티플렉서로 부름

## Ⅰ. 개요

- **정의/개념**: 조합 논리 회로는 플립플롭 같은 기억 소자 없이 현재 입력 조합만으로 출력값이 그 자리에서 정해지는 디지털 회로이며, 가산기·인코더·디코더·멀티플렉서(MUX)가 대표적인 구현 형태임
- **배경/필요성**: CPU의 ALU 연산, 버스의 경로 선택, 메모리 주소 해석처럼 이전 상태를 참고할 필요 없이 매 순간 입력에 즉시 반응해야 하는 기능은, 상태를 저장하고 갱신하는 순차 회로 대신 입력과 출력의 대응 관계만 정의하는 함수형 회로 설계가 필요함

## Ⅱ. 특징

- 무상태 재현성이 있어, 같은 입력 조합이 들어오면 그 전에 어떤 값이 들어왔었는지와 무관하게 항상 같은 출력이 나옴
- 지연과 게이트 수는 논리식 최소화 수준에 따라 함께 줄어듦. 카르노맵이나 부울 대수로 중복 항을 제거하면 게이트 단수가 줄어 신호가 통과하는 경로도 짧아짐
- 가산기와 멀티플렉서는 ALU, 데이터 버스, 제어기 내부에서 반복적으로 재사용되는 기본 연산 블록이며, 더 복잡한 회로는 이 기본 블록을 계층적으로 쌓아 구성함
- fan-in이 커지면 게이트 하나가 판단해야 할 입력 조합 수가 늘어나, 회로 깊이와 전력 소모가 함께 증가함

## Ⅲ. 종류 및 비교

- **가산기(Adder)**: 두 비트열과 자리올림(carry) 입력을 받아 합과 다음 자리올림을 계산하는 회로임. 반가산기는 자리올림 입력 없이 두 비트만 더하고, 전가산기는 이전 자리에서 넘어온 자리올림까지 받아 여러 자리를 연쇄로 연결할 수 있음
- **멀티플렉서(MUX)**: 여러 데이터 입력 중 선택 신호가 지정한 하나만 출력으로 통과시키는 회로임. 갈림길마다 신호등이 한 방향만 열어주듯, 여러 데이터 경로를 하나로 좁혀 전달함
- **디코더(Decoder)**: 압축된 코드나 주소 입력을 받아, 그 값에 해당하는 출력선 하나만 활성화하는 회로임. 우편번호 하나가 특정 배송 구역 하나를 가리키듯, 입력 코드 하나가 출력 회선 하나를 지정함

| 판단 기준 | 가산기 | 멀티플렉서(MUX) | 디코더 |
|:---|:---|:---|:---|
| 핵심 역할 | 비트열과 자리올림을 더해 합과 다음 자리올림을 계산함 | 여러 데이터 중 선택 신호가 지정한 하나만 출력으로 통과시킴 | 코드나 주소 입력에 대응하는 출력선 하나만 활성화함 |
| 입력 구성 | 더할 비트열과 이전 자리올림 | 데이터 입력 여러 개와 선택 신호 | 압축된 코드 또는 주소 비트 |
| 출력 구성 | 합과 다음 자리올림 | 선택된 데이터 값 1개 | 활성화된 출력선 1개(나머지는 비활성) |
| 대표 적용 | ALU의 정수 연산 | 버스의 데이터 경로 제어 | 메모리 행/열 선택 |

> 요약: 가산기는 값을 계산하고 멀티플렉서는 경로를 좁히며 디코더는 코드를 하나의 신호로 펼쳐낸다는 점에서, 셋은 조합 논리의 서로 다른 대표 역할을 나눠 맡음.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 반가산기(Half Adder) | XOR 게이트로 합을, AND 게이트로 자리올림을 동시에 만들지만 하위 자리에서 넘어오는 자리올림 입력을 받지 않아 최하위 비트 계산에만 단독으로 쓰임 |
| 전가산기(Full Adder) | 반가산기 2개와 OR 게이트 1개를 결합해 이전 자리올림($C_{in}$)까지 받아 합과 다음 자리올림($C_{out}$)을 함께 내고, $C_{out}$을 다음 자리 전가산기로 넘겨 여러 비트를 연쇄로 확장함 |
| 리플 캐리 가산기(Ripple Carry Adder) | 전가산기를 비트 수만큼 직렬로 이어 붙인 구조이며, 자리올림이 최하위에서 최상위로 한 자리씩 순서대로 전파되므로 비트 폭이 넓을수록 전파 지연이 누적됨 |
| MUX 게이팅 회로 | 데이터 입력선마다 AND 게이트를 하나씩 배치하고 선택 신호를 디코딩해 지정된 입력의 AND 게이트만 열며, 열린 게이트의 출력만 OR 게이트로 묶어 하나의 출력으로 내보냄 |

```text
D0 -> +-----+
      | AND |--+
S  -> +-----+  |     +----+
                +--> | OR | --> Y
D1 -> +-----+  |     +----+
      | AND |--+
S  -> +-----+
```

> 요약: 가산기는 반가산기와 전가산기를 순서대로 이어 붙여 자리올림을 전파시키는 구조이고, MUX는 선택 신호로 게이트 하나만 열어 값을 골라내는 구조임.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+      +----------+      +----------+      +----------+
| 비트별   | ---> | 전가산기 | ---> | 자리올림 | ---> | 합 비트  |
| 입력 정렬|      | 병렬 계산|      | 순차 전파|      | 확정     |
+----------+      +----------+      +----------+      +----------+
```

1. **비트별 입력 정렬**: 더할 두 비트열을 최하위 비트부터 각 자리 전가산기에 배치하고, 최하위 자리의 자리올림 입력은 0으로 고정함
2. **전가산기 병렬 계산**: 각 자리의 전가산기가 자신의 두 비트와 하위 자리에서 넘어온 자리올림을 XOR·AND·OR 게이트로 동시에 계산함
3. **자리올림 순차 전파**: 하위 자리의 자리올림 출력이 상위 자리 전가산기의 자리올림 입력으로 이어지며, 게이트를 하나씩 통과할 때마다 전파 지연이 누적됨
4. **합 비트 확정**: 모든 자리의 합 비트와 최상위 자리올림이 확정되면 이를 최종 연산 결과와 오버플로 판정 신호로 반환함

## Ⅵ. 실무 적용 및 유의점

1. ALU의 정수 가산 경로에 리플 캐리 가산기를 그대로 쓰면 자리올림이 하위 자리부터 순차로 전파돼 비트 폭이 넓어질수록 지연이 선형으로 누적되므로, 클럭 주기가 촉박한 연산기는 자리올림을 병렬로 미리 계산하는 캐리 선견 가산기(Carry Lookahead Adder)로 바꾸고 최대 전파 지연과 늘어난 게이트 수로 교체 타당성을 확인함
2. 버스의 데이터 경로 제어에 MUX를 여러 단으로 확장할 때 선택선 수가 늘면 게이트 하나의 fan-in이 함께 커져 지연과 전력 소모가 증가하므로, 데이터 폭이 넓은 다중화는 작은 MUX를 트리 구조로 계층화해 개별 게이트의 fan-in을 낮추고 최대 전파 지연과 소비 전력으로 개선 효과를 확인함

## Ⅶ. 결론

가산기는 자리올림의 순차 전파 지연을, 멀티플렉서는 선택선 증가에 따른 fan-in 지연을 각자의 병목으로 다스려야 하므로, 두 회로 모두 어떤 지연 요인을 줄이는 구조로 재설계할지가 조합 논리 회로 설계의 핵심 판단 기준임.
