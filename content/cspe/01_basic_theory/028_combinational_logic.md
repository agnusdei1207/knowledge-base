## 미리 알고가기

- 조합 논리 회로: 출력값이 오직 현재의 입력 조합에 의해서만 결정되는 회로이며, 상태를 기억하는 능력이 없음
- 전가산기($Full$ $Adder$): 두 개의 비트와 하위 자리에서 올라온 캐리($C_{in}$)까지 포함하여 총 3개의 비트를 더하는 장치임
- 멀티플렉서($MUX$): 여러 개의 데이터 입력 중 선택 신호($Select$)가 지정한 하나만을 출력으로 내보내는 데이터 선택기임
- 전파 지연($Propagation$ $Delay$): 신호가 입력 게이트를 거쳐 최종 출력에 도달할 때까지 소요되는 물리적인 시간차임
- 리플 캐리 가산기($Ripple$ $Carry$ $Adder$): 전가산기들을 직렬로 연결하여 캐리가 하위에서 상위로 파도치듯 전달되는 방식임

## Ⅰ. 개요

- **정의/개념**: 조합 논리 회로는 내부 기억 소자 없이 기본 논리 게이트들의 조합만으로 구성되어, 입력 신호가 변하는 즉시 정해진 논리 함수에 따라 결과가 도출되는 디지털 회로임
- **배경/필요성**: 산술 연산($ALU$), 데이터 경로 제어, 주소 해독 등 매 순간의 입력 조건에 대해 지연 시간을 최소화하며 즉각적인 계산 결과를 얻어야 하는 핵심 논리 블록을 구현하기 위해 필요함

## Ⅱ. 특징

- 과거의 입력 이력이나 현재의 상태값을 보관하지 않으므로 동일한 입력에 대해 항상 동일한 출력 결과를 보장하는 결정론적 특성을 가짐
- 회로의 동작 속도는 신호가 통과하는 가장 긴 경로(Critical Path) 상에 배치된 논리 게이트들의 전파 지연 시간의 합에 의해 결정됨
- 복잡한 논리 함수를 카르노 맵 등을 통해 최소화함으로써 게이트의 개수와 회로 면적, 전력 소모를 최적화할 수 있는 수치적 분석이 용이함

## Ⅲ. 종류 및 비교

| 종류 | 핵심 기능 | 입/출력 구성 | 주요 활용 분야 |
|:---|:---|:---|:---|
| **가산기** | 이진수의 합산 연산 수행 | (입) A, B, Cin / (출) Sum, Cout | $ALU$, 주소 계산기 |
| **멀티플렉서 (MUX)** | 다중 입력 중 하나 선택 | (입) $2^n$ Data, $n$ Select / (출) 1 Out | 데이터 선택, 병렬-직렬 변환 |
| **디멀티플렉서 (DEMUX)** | 단일 입력을 여러 출력 중 하나로 분배 | (입) 1 Data, $n$ Select / (출) $2^n$ Out | 데이터 분배, 직렬-병렬 변환 |
| **디코더 (Decoder)** | $n$비트 코드를 $2^n$개 신호로 해독 | (입) $n$ In / (출) $2^n$ Out | 메모리 주소 지정, 명령어 해독 |

> 요약: 가산기는 연산의 핵심이며, MUX와 Decoder는 데이터의 흐름과 주소를 제어하는 조합 논리의 기본 요소임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 반가산기 ($Half$ $Adder$) | 2개의 비트를 더하여 합($S = A \oplus B$)과 캐리($C = A \cdot B$)를 생성함 |
| 전가산기 ($Full$ $Adder$) | 반가산기 2개와 OR 게이트를 조합하여 이전 자리의 올림수까지 함께 처리함 |
| 4-to-1 MUX | 2비트의 선택 신호($S_1, S_0$)를 통해 4개의 입력 데이터 중 하나를 골라 출력함 |
| 병렬 가산기 | 여러 개의 전가산기를 연결하여 다비트($n-bit$) 연산을 수행하는 구조임 |

```text
[ 전가산기(FA) 논리 구조 ]
Sum = A ⊕ B ⊕ Cin
Cout = (A · B) + (Cin · (A ⊕ B))
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 입력 데이터 인가| --> | 게이트 논리 연산| --> | 신호 전파/지연 | --> | 최종 출력 확정|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **신호 수신** — 외부 데이터와 제어 신호가 회로의 입력 핀에 도달하며, 전압 레벨이 안정화될 때까지 대기함
2. **게이트 전이** — 입력 신호가 회로 내부의 첫 번째 단 게이트부터 차례대로 논리 연산(AND, OR 등)을 수행하며 상태를 바꿈
3. **캐리 전파** — 가산기의 경우 하위 비트의 결과가 상위 비트의 입력으로 전달되는 물리적 전파 과정을 거침 (Ripple Carry)
4. **출력 안정** — 모든 게이트의 전파 지연이 종료되고 최종 출력 단의 신호가 0 또는 1로 고정되면 연산 결과를 확정함

## Ⅵ. 실무 적용 및 유의점

1. 대규모 가산 회로 설계 시 리플 캐리 방식의 지연 시간이 전체 시스템 클록의 병목이 될 수 있으므로, 캐리를 병렬로 미리 계산하는 '캐리 선견 가산기($Carry$ $Look-ahead$ $Adder$)'를 도입하여 연산 속도를 획기적으로 개선해야 함
2. 멀티플렉서의 선택 신호 전환 시 서로 다른 경로의 지연 차이로 인해 출력이 일시적으로 흔들리는 '글리치($Glitch$)'가 발생하여 오동작을 유발할 수 있으므로, 해저드 방지 논리를 추가하거나 동기식 설계를 통해 출력 안정성을 확보해야 함

## Ⅶ. 결론

- 조합 논리 회로는 디지털 연산 장치의 물리적 근간을 이루는 핵심 기술이며, 설계자는 수식의 수학적 최소화를 넘어 신호의 전파 지연과 전력 효율을 고려한 하드웨어 아키텍처를 도출해야 함
