## 미리 알고가기

- 조합 논리: 현재 입력만으로 출력이 결정되는 회로임
- 전파 지연: 입력 변화가 출력에 반영되기까지 걸리는 시간임
- 선택 신호: 여러 입력 중 하나를 고르는 제어 비트임

## Ⅰ. 개요

- **정의/개념**: 조합 논리 회로는 기억 요소 없이 현재 입력 조합만으로 출력을 생성하는 회로로, 가산기, 디코더, 인코더, 멀티플렉서가 대표 구조임
- **배경/필요성**: 산술 연산, 데이터 선택, 주소 해석처럼 즉시 반응해야 하는 디지털 기능은 상태 저장보다 입력-출력 함수 구현이 핵심임

## Ⅱ. 특징

- 내부 상태가 없어 동일 입력이면 항상 동일 출력이 나옴
- 논리식 최소화에 따라 게이트 수와 지연이 직접 줄어듦
- 가산기와 멀티플렉서는 ALU, 버스, 제어기의 기본 블록임
- fan-in이 커지면 회로 깊이와 전력 소모가 증가함

## Ⅲ. 종류 및 비교

| 판단 기준 | 가산기 | 멀티플렉서 | 디코더 |
|:---|:---|:---|:---|
| 역할 | 산술 합 계산 | 입력 선택 | 코드 해석 |
| 입력 특성 | 비트열 + carry | 데이터 + select | 주소/코드 |
| 출력 특성 | sum, carry | 선택된 값 1개 | 다수 enable |
| 대표 적용 | ALU | 버스 경로 제어 | 메모리 선택 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 입력선 | 데이터와 제어 비트가 들어옴 논리 함수의 원천임 |
| 게이트 네트워크 | AND, OR, XOR 등으로 구성됨 지연시간을 결정함 |
| 선택/전달 경로 | 멀티플렉서, 디코더 구조이며 데이터 흐름을 통제함 |
| 출력선 | 산술 결과나 제어 신호를 내보냄 다음 단계 입력이 됨 |

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 입력수집 | --> | 논리결합 | --> | 선택/연산 | --> | 출력전달 |
+----------+     +----------+     +----------+     +----------+
```

1. **입력수집**: 데이터 비트와 제어 비트를 받음
2. **논리결합**: 게이트가 부분 결과를 생성함
3. **선택/연산**: 가산 또는 경로 선택 기능을 수행함
4. **출력전달**: 최종 신호를 다음 회로로 전달함

## Ⅵ. 문제점 및 해결 방안

1. **회로 깊이가 깊어지면 지연이 증가함**: 리플 구조는 속도 병목이 큼
   - **해결 방안**: carry lookahead, 계층 MUX 구조를 적용하고 critical path로 검증함
2. **입력 전이 시 글리치가 발생함**: 비동기 입력 조합에서 순간 오출력이 생김
   - **해결 방안**: hazard 제거와 동기식 샘플링을 사용하고 glitch count로 검증함
3. **규모 확장 시 배선 복잡도가 증가함**: fan-out과 배치가 어려워짐
   - **해결 방안**: 계층화와 모듈 재사용으로 구조를 분리하고 배선 자원 사용량로 검증함

## Ⅶ. 적용 사례

- CPU ALU: 반가산기와 전가산기로 정수 연산을 구성함, 확인 지표는 연산 지연시간임
- SoC 버스 선택: MUX로 데이터 경로를 스위칭함, 확인 지표는 제어 정확도와 전력임
- 메모리 주소 해석: 디코더로 특정 행과 열을 선택함, 확인 지표는 접근 지연시간임

## Ⅷ. 결론

조합 논리 회로는 기능보다 경로 지연이 성능을 좌우하므로, 설계의 핵심은 논리 정확성과 함께 critical path를 얼마나 짧게 만드는지에 있음.
