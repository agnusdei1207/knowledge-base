# 조합 논리 회로 - 가산기·멀티플렉서 (Combinational Logic)

## 1. 개요

- **정의/개념**: 조합 논리 회로는 현재 입력 값만으로 출력이 결정되는 디지털 회로이며, 내부 상태나 과거 입력을 저장하지 않는다.
- **배경/필요성**: 산술 연산, 데이터 선택, 코드 변환처럼 즉시 계산되는 디지털 기능은 상태 저장 없이 논리 게이트 조합으로 구현하는 것이 단순하고 빠르다.

조합 논리는 "현재 입력 -> 즉시 출력" 구조이므로, 순서 논리와 달리 클럭이나 메모리 상태가 핵심이 아니다.

## 2. 특징 및 비교

| 구분 | 조합 논리 | 순서 논리 |
|---|---|---|
| 출력 결정 | 현재 입력 | 현재 입력 + 이전 상태 |
| 저장 요소 | 없음 | 플립플롭, 레지스터 |
| 시간 기준 | 전파 지연 | 클럭, 상태 전이 |
| 대표 회로 | 가산기, MUX, 디코더 | 카운터, FSM |
| 주요 검증 | 진리표, 지연 | 타이밍, 상태 도달성 |

조합 논리 설계는 기능 정확성, 게이트 수, 전파 지연, fan-in/fan-out을 핵심 차원으로 판단한다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| Input Signal | 회로 입력 | 현재 값만 사용 |
| Logic Gates | AND, OR, NOT, XOR 등 | 기능 구현 |
| Boolean Function | 출력 논리식 | 설계 명세 |
| Propagation Delay | 입력 변화 후 출력 안정 시간 | 성능 한계 |
| Output Signal | 계산 결과 | 즉시 출력 |

```text
+----------+      +----------+      +----------+
| 입력신호 | ---> | 게이트망 | ---> | 출력신호 |
+----------+      +----------+      +----------+
                  지연시간 발생
```

가산기는 XOR와 carry 논리를 결합하고, 멀티플렉서는 선택 신호에 따라 입력 중 하나를 출력하므로 모두 입력-출력 논리식으로 설명할 수 있다.

## 4. 문제점 및 개선방안

1. **전파 지연 누적**
   - 게이트 단계가 깊어지면 출력 안정 시간이 길어진다.
   - **개선방안**: 논리식 단순화, carry lookahead, 병렬 구조를 적용한다.

2. **Hazard 발생**
   - 입력 변화 중 일시적으로 잘못된 출력 glitch가 발생할 수 있다.
   - **개선방안**: hazard-free 설계, 동기화, 여유항 추가를 검토한다.

3. **입력 조합 누락**
   - 진리표의 일부 조합을 고려하지 않으면 예외 입력에서 오동작한다.
   - **개선방안**: 전체 입력 조합 검증과 don't care 조건 명시를 수행한다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| 산술 연산기 | 반가산기·전가산기로 덧셈 회로 구성 | 지연 시간, carry 처리 |
| 데이터 선택 | MUX로 버스 입력 중 하나를 선택 | 선택 정확도, fan-out |
| 주소 디코딩 | 디코더로 메모리·장치 선택 신호 생성 | 충돌 여부, 타이밍 |

## 6. 결론

조합 논리 회로는 현재 입력만으로 출력을 만드는 디지털 기능의 기본 구조이다. 조합/순서 논리 차이를 먼저 잡아야 가산기·MUX 같은 대표 회로의 동작과 지연 개선 방안이 자연스럽게 연결된다.
