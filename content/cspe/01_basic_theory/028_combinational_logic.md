## 미리 알고가기

- 조합 논리 회로: 출력이 현재 입력 조합으로만 결정되고 내부 상태를 저장하지 않는 회로임
- 전가산기: 두 입력 비트와 하위 자리올림을 더해 합과 상위 자리올림을 출력하는 회로임
- 멀티플렉서(Multiplexer, MUX): 여러 입력 중 선택 신호가 지정한 하나를 출력하는 데이터 선택기임
- 디코더: $n$비트 입력을 $2^n$개 출력 중 하나로 펼치는 회로임
- 전파 지연: 입력 변화가 출력에 안정적으로 반영될 때까지 걸리는 시간임
- 크리티컬 패스: 회로에서 가장 긴 지연을 갖는 경로이며 최대 동작 속도를 제한함
- 반가산기: 두 입력 비트의 합과 자리올림을 계산하는 회로임
- 비교기: 두 입력값의 크기와 동등 여부를 판정하는 회로임
- 글리치: 입력 도달 시간 차이로 출력에 순간적으로 발생하는 잘못된 신호임
- $A,B,Cin,Sum,Cout$: 가산기 도식의 두 입력, 하위 자리올림, 합, 상위 자리올림을 나타냄

## 작성 근거(검토용)

- 개요는 상태 저장이 없고 현재 입력만 본다는 조합 논리의 경계를 먼저 제시함
- 특징은 결정성·전파 지연·최소화·샘플링 조건을 선별해 순서 논리와 자연스럽게 대비되게 함
- Ⅲ은 _keywords.md의 가산기·멀티플렉서를 중심으로 디코더와 비교기를 보조 유형으로 배치함
- Ⅳ와 Ⅴ는 게이트 연결과 지연 흐름을 나누어 회로 구조와 동작 시간을 함께 설명함
- 다비트 가산기의 자리올림 전달 지연과 MUX 글리치처럼 실제 설계에서 검증해야 할 위험을 남김

## Ⅰ. 개요

- **정의/개념**: 조합 논리 회로는 기억 소자 없이 논리 게이트의 연결만으로 현재 입력에 대응하는 출력을 전파 지연 후 생성하는 디지털 회로임
- **배경/필요성**: 산술·논리 연산, 주소 해독, 데이터 선택을 현재 입력만으로 처리할 조합 논리 블록이 필요함

## Ⅱ. 특징

- 같은 입력 조합에는 항상 같은 출력이 나오는 결정적 회로임
- 내부 상태가 없으므로 클록이 아니라 게이트 전파 지연이 동작 속도를 제한함
- 부울식 최소화로 게이트 수·면적·전력 소모를 줄임
- 출력 안정 전 샘플링하면 잘못된 값이 저장되므로 다음 순서 회로의 샘플링 타이밍과 맞아야 함

## Ⅲ. 종류 및 비교

| 회로 | 입력 | 산출 결과 | 대표 적용 사례 |
|:---|:---|:---|:---|
| 반가산기 | 두 입력 비트 | 합 비트와 자리올림 비트 | 입력 자리올림이 없는 최하위 비트 가산 |
| 전가산기 | 두 입력 비트와 하위 자리올림 | 합 비트와 상위 자리올림 비트 | 산술 논리 장치·다비트 가산기 |
| 멀티플렉서 | 여러 데이터와 선택 신호 | 선택 신호가 지정한 단일 데이터 | 데이터 경로 선택 |
| 디코더 | $n$비트 코드 | 입력 코드에 대응해 활성화된 단일 출력선 | 주소 선택·명령 해독 |
| 비교기 | 두 입력값 | 대소·동등 관계를 나타내는 신호 | 분기·정렬 하드웨어 |

> 요약: 가산기는 합·자리올림, MUX는 데이터 선택, 디코더는 출력 활성화, 비교기는 크기·동등성을 담당함.

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 입력 신호 | 데이터 비트·선택 정보 |
| 논리 게이트 | 부울식의 논리 연산 수행 |
| 데이터 경로 | 게이트 기반 산술·입력 선택 경로 |
| 출력 신호 | 전파 지연 후 확정된 계산 결과 |

```text
전가산기

A -----+
       +--> [ XOR ] ---> [ XOR ] ---> Sum
B -----+                    ^
                            |
Cin ------------------------+

A,B,Cin --> [ 자리올림 로직 ] --> Cout
```

> 요약: 조합 논리 회로는 현재 입력을 논리 게이트와 데이터 경로로 계산하고 전파 지연 후 출력을 확정함.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 입력 확정  | --> | 게이트 계산 | --> | 지연 통과  | --> | 출력 확정  |
+----------+     +----------+     +----------+     +----------+
```

1. **입력 안정**: 데이터와 선택 신호가 입력단에 도달하고 전압 레벨이 고정됨
2. **논리 평가**: 각 게이트가 입력 조합에 맞는 중간 결과를 병렬로 계산함
3. **지연 통과**: 자리올림 경로나 선택 경로의 전파 지연이 끝날 때까지 기다림
4. **출력 확정**: 최종 출력이 안정되면 다음 순서 회로나 외부 블록이 값을 사용함

> 요약: 논리식이 맞아도 전파 지연이 끝난 뒤에 다음 회로가 출력을 샘플링해야 함.

## Ⅵ. 실무 사례

1. CPU 가산기는 자리올림을 병렬 계산해 지연을 줄이고 크리티컬 패스 지연을 확인함
2. MUX 경로는 선택 신호의 도착 시간을 맞추고 출력 레지스터를 배치해 글리치 발생 여부를 확인함

## Ⅶ. 결론

- 조합 논리 회로는 현재 입력으로 출력을 계산하므로 논리 최소화와 전파 지연을 함께 검토해야 함
