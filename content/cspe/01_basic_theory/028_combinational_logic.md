## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 현재의 입력값에 의해서만 현재의 출력이 결정되는(기억 소자가 없는) 디지털 논리 회로임 |
| 배경/필요성 | 산술 연산, 데이터 라우팅, 코드 변환 등 CPU 내부의 즉각적인 데이터 처리를 위해 필요함 |
| 출제 의도 | 반가산기/전가산기의 원리 및 먹스(MUX)/디먹스(DEMUX)의 기능과 진리표 작성 능력 평가 |

## Ⅱ. 구성요소
```text
+-------------------+       +-------------------+       +-------------------+
|     Adders        | ----> |   Multiplexers    | ----> |    Encoders/      |
|  (Half/Full Add)  |       |   (MUX/DEMUX)     |       |    Decoders       |
+-------------------+       +-------------------+       +-------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 가산기 | 두 이진수의 합과 자리올림(Carry)을 계산하는 연산 회로 | 전자 계산원 |
| 멀티플렉서(MUX) | 여러 입력 중 선택 제어 신호에 따라 하나의 출력을 내보내는 장치 | 철도 선로 변환기 |
| 인코더/디코더 | 특정 코드를 다른 코드로 변환하거나 특정 출력을 활성화하는 회로 | 번역가 / 암호해독기 |
> 요약: 조합 논리 회로는 가산기, 멀티플렉서, 디코더 등으로 구성되어 연산과 신호 제어를 담당함

## Ⅲ. 절차
```text
+----------------+    +----------------+    +----------------+    +----------------+
| 1. 기능 명세   | -> | 2. 입출력 정의 | -> | 3. 진리표/논리식| -> | 4. 회로 조립   |
+----------------+    +----------------+    +----------------+    +----------------+
```
1. 기능 명세: 구현할 산술 연산이나 데이터 선택 기능의 목적을 명확히 함
2. 입출력 정의: 회로에 필요한 입력 변수(데이터, 선택 신호 등)와 출력 변수의 수를 확정함
3. 진리표/논리식: 모든 입력 조합에 대한 출력을 진리표로 만들고 카르노 맵으로 논리식을 최적화함
4. 회로 조립: AND, OR, XOR 등 기본 게이트를 조합하여 설계된 논리식을 하드웨어로 구현함
> 요약: 요구 기능을 진리표와 논리식으로 최적화한 후 게이트 간의 연결로 즉각적 반응 회로를 만듦

## Ⅳ. 문제점
- 파문 지연(Ripple Delay): 병렬 가산기에서 하위 비트의 캐리가 상위 비트로 순차 전달되며 처리 지연이 발생함
- 글리치(Glitch) 현상: 게이트마다 신호 전달 시간이 달라 출력이 원치 않게 잠시 튀는 현상이 생김

## Ⅴ. 개선방안
- 올림수 예측기 적용: 캐리 예측 가산기(Carry-Lookahead Adder)를 사용하여 병렬로 캐리를 계산해 지연을 방지함
- 해저드 제거 설계: 논리식 최적화 시 잉여 항(Redundant term)을 추가하여 신호 전파 차이로 인한 글리치를 억제함

## Ⅵ. 전망
- 조합 논리 회로는 지속적으로 소형화, 고속화될 것이며, AI 가속기와 같은 특정 연산에 최적화된 대규모 병렬 조합 회로의 수요가 증가할 것임
