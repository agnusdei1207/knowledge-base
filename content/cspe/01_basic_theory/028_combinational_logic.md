## Ⅰ. 개요
- 정의: 출력 값이 현재의 입력 값에 의해서만 결정되는 논리 회로임
- 배경/필요성: 상태 저장이 필요 없는 순수 연산 및 데이터 경로 제어에 사용됨
- 출제 의도: 가산기(Adder), MUX/DEMUX, 디코더의 구조와 동작 이해도 측정

## Ⅱ. 구성요소
- ASCII 구조도 (2x1 MUX)
  I0 --\
        |--[ MUX ]--> Y
  I1 --/      |
           S (Select)

- 구성요소 표
| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| 가산기 (Adder) | 반가산기(2비트), 전가산기(3비트) 합산 장치 | 계산기 |
| 멀티플렉서 (MUX) | 여러 입력 중 하나를 선택하여 출력함 | 선택 스위치 |
| 디코더 (Decoder) | n비트 코드를 2^n개 출력 중 하나로 활성화함 | 번역기 |
| 비교기 (Comparator) | 두 입력의 크기를 비교하여 결과 출력함 | 판독기 |
> 요약: 메모리 요소 없이 게이트의 조합만으로 즉각적인 결과를 도출하는 회로임

## Ⅲ. 절차
- ASCII 흐름도
  [Input] -> [Logic Gates Combinations] -> [Result Output]

1. 요구사항 정의: 입력 비트 수와 원하는 연산 기능을 확정함
2. 진리표 작성: 모든 입력 조합에 대한 출력 기댓값을 명시함
3. 논리식 최적화: 카르노 맵 등을 사용하여 게이트 수를 최소화함
4. 레이아웃 설계: 최적화된 식을 바탕으로 하드웨어 배선을 설계함
> 요약: 입력의 변화가 전파 지연 시간 후 즉시 출력에 반영되는 구조임

## Ⅳ. 문제점
- 상태 부재: 과거의 입력을 기억할 수 없어 순차적인 제어가 불가능함
- 글리치(Glitch): 신호 전달 경로 차이로 인해 일시적인 오작동(잡음) 발생함

## Ⅴ. 개선방안
- 순서 논리 결합: 플립플롭을 추가하여 상태를 유지하는 순서 회로로 확장함
- 파이프라이닝: 조합 회로 사이에 레지스터를 두어 처리 속도를 향상시킴

## Ⅵ. 전망
- 고성능 연산 유닛: 64비트 이상의 고속 가산기 설계를 위해 CLA(Carry Look-ahead Adder) 등 병렬 처리 구조가 도입되어 프로세서의 클록 주파수 한계 극복에 기여함
- 가상화 및 보안: MUX/디코더 기술은 하드웨어 수준의 리소스 격리 및 가상화 제어 유닛 설계의 핵심으로 활용되어 보안성 높은 클라우드 인프라 구축의 기반이 됨
- CSF: 전파 지연(Propagation Delay)을 최소화하기 위한 임계 경로(Critical Path) 최적화와 대규모 팬인/팬아웃(Fan-in/Fan-out) 관리 기술의 정교한 적용이 실무적 성공 요인임
