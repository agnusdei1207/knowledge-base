# 028. 조합 논리 회로 — 가산기·멀티플렉서 (Combinational Logic) [출제: -]

## 미리 알고가기

- **전파 지연(Propagation Delay)**: 입력 신호가 변화한 시점부터 출력이 안정된 값으로 확정될 때까지 걸리는 시간. 게이트의 단수가 많아질수록 누적됨
- **글리치(Glitch/Hazard)**: 신호 전달 경로의 지연 차이로 인해 출력값이 최종 상태로 가기 전 일시적으로 튀는 현상. 조합 논리 회로의 신뢰성을 위협하는 주요 요인임
- **Don't Care 조건**: 특정 입력 조합이 절대 발생하지 않거나 출력값이 상관없는 경우. 카르노 맵 등에서 논리식 최소화를 위해 활용함

## Ⅰ. 개요

- **정의/개념**: 조합 논리 회로(Combinational Logic Circuit)는 현재의 입력 값만으로 출력이 결정되는 논리 회로임. 내부적인 상태(State)나 과거의 입력 이력을 저장하는 메모리 소자가 없으며, 입력이 게이트망을 통과하는 즉시(전파 지연 포함) 결과가 산출됨
- **배경/필요성**: 디지털 시스템에서 데이터의 산술 연산(덧셈, 뺄셈), 데이터 선택(Multiplexing), 신호 변환(Encoding/Decoding) 등은 이전 상태와 무관하게 현재 주어진 재료만으로 처리할 수 있는 작업들임. 이러한 기능을 순서 논리(Sequential Logic)로 구현하면 불필요한 메모리 소자와 클록 동기화 오버헤드가 발생함. 따라서 기억이 필요 없는 순수 연산 영역을 조합 논리로 분리하여 하드웨어 자원을 최적화하고 응답 속도를 극대화해야 함

## Ⅱ. 특징 및 비교

### 가. 조합 논리 회로와 순서 논리 회로의 핵심 차이

| 구분 | 조합 논리 회로 (Combinational) | 순서 논리 회로 (Sequential) |
|:---|:---|:---|
| 출력 결정 요인 | 현재의 입력 (Current Input Only) | 현재 입력 + 이전 상태 (Current + State) |
| 기억 소자 | 없음 (No Storage) | 있음 (Flip-Flops, Registers) |
| 피드백 경로 | 없음 (Feed-forward) | 있음 (Feedback from Output to Input) |
| 타이밍 기준 | 게이트 전파 지연 (Gate Delay) | 시스템 클록 (System Clock) |
| 주요 구성 예시 | 가산기, MUX, 디코더, 비교기 | 카운터, 레지스터, FSM, CPU 제어부 |

> 요약: 조합 논리는 기억 없이 입력 즉시 연산하며, 순서 논리는 클록에 맞춰 상태를 갱신하며 기억함

### 나. 조합 논리의 설계 판단 지표
- **기능적 정합성**: 진리표(Truth Table)에 명시된 모든 입력 조합에 대해 정확한 논리값이 출력되는지 검증
- **시간적 제약**: 입력부터 출력까지의 최대 지연 시간(Critical Path Delay)이 시스템의 요구 성능을 만족하는지 확인
- **자원 효율성**: 사용된 게이트의 총 개수와 유형(NAND/NOR 선호)을 고려하여 면적 및 전력 최적화

## Ⅲ. 구성요소/구조

### 가. 조합 논리의 기본 구성 및 흐름도

```text
[입력 신호] -> [논리 게이트망 (Combinatorial Cloud)] -> [출력 신호]

1. 입력 신호: n개의 이진 데이터 입력
2. 게이트망: AND, OR, NOT, XOR 등이 계층적으로 연결된 비순환 경로
3. 출력 신호: 입력과 게이트 연산의 조합으로 결정된 m개의 출력
```

### 나. 주요 대표 회로 및 역할

| 구성요소 | 기능 및 원리 | 실무적 의의 |
|:---|:---|:---|
| 반가산기 (HA) | $1$비트 두 수의 합($S$)과 캐리($C$)를 구함 | 덧셈의 가장 기초적인 단위 블록 |
| 전가산기 (FA) | 아랫자리 캐리($C_{in}$)까지 포함해 세 비트를 가산 | 여러 비트 병렬 가산기 구성의 핵심 |
| 멀티플렉서 (MUX) | 여러 입력 중 선택 신호에 따라 하나를 골라 출력 | 데이터 버스 선택 및 전송 경로 제어 |
| 디코더 (Decoder) | $n$비트 입력을 $2^n$개 중 하나의 활성화 신호로 변환 | 메모리 주소 지정 및 장치 선택 신호 생성 |
| 비교기 (Comparator) | 두 이진수의 크기를 비교 ($A > B, A = B, A < B$) | 조건 분기 및 정렬 로직의 기반 |

> 요약: 가산기는 연산의 중추이며, MUX와 디코더는 데이터 흐름과 선택의 중추 역할을 수행함

## Ⅳ. 문제점 및 개선방안

1. **리플 캐리(Ripple Carry) 지연**: $n$비트 가산기에서 아랫자리의 캐리가 윗자리로 전달될 때까지 기다려야 하므로, 비트 수가 늘어날수록 전파 지연이 선형적으로 증가함
   - **개선방안**: 캐리를 미리 예측하여 병렬로 생성하는 '캐리 예측 가산기(CLA, Carry Look-ahead Adder)' 구조를 채택하여 지연 시간을 로그 수준으로 단축함

2. **논리적 해저드(Static/Dynamic Hazard)**: 입력 값이 바뀌는 순간 게이트별 지연 차이로 인해 출력에 불필요한 '글리치'가 발생함
   - **개선방안**: 카르노 맵에서 인접한 항을 덮는 중복 논리(Redundant Logic)를 추가하여 신호 경로의 연속성을 보장하거나, 출력단에 래치(Latch)를 두어 안정화된 후에만 값을 읽음

3. **게이트 단수 증가에 따른 소비 전력 증가**: 회로가 깊어질수록 스위칭 손실이 커짐
   - **개선방안**: 부울 대수의 분배 법칙과 흡수 법칙을 활용해 논리식을 최소화(Optimization)하고, 지연이 허용되는 범위 내에서 저전력 게이트 라이브러리를 활용함

## Ⅴ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| CPU 정수 연산부 | ALU 내부에 전가산기와 CLA를 배치하여 초고속 산술 연산 수행 | 연산 지연($ns$), 최대 클록 주파수($GHz$) |
| 통신 스위칭 장비 | 수많은 입력 포트 중 하나를 골라 출력 포트로 연결할 때 MUX 트리 구성 | 스위칭 정확도, 포트 간 간섭(Cross-talk) |
| 메모리 컨트롤러 | CPU의 주소 버스 신호를 디코딩하여 특정 뱅크/행을 선택(Select) | 디코딩 속도, 어드레싱 가능 범위 |

> 요약: 하드웨어의 모든 즉각적인 판단과 계산은 최적화된 조합 논리 회로를 통해 실시간으로 처리됨

## Ⅵ. 결론

조합 논리 회로는 디지털 시스템의 연산과 선택 기능을 담당하는 근간 기술로, 기억 장치가 없는 순수 함수적 동작을 하드웨어로 구현한 결과물임. 설계의 핵심은 단순히 기능을 맞추는 것을 넘어, 전파 지연을 최소화하여 성능 병목을 제거하고 글리치를 방지하여 신뢰성을 확보하는 데 있음.

기술사는 시스템 아키텍처 설계 시 가산기나 MUX 같은 기본 모듈의 특성을 정확히 파악하여, Critical Path가 전체 시스템 속도를 제약하지 않도록 논리 계층을 설계하고 최적화 기법을 적용할 수 있어야 함. 또한 복잡한 조합 논리는 향후 FPGA나 ASIC 합성 도구와의 연계를 고려하여 HDL 수준에서의 정교한 명세가 필요함.
