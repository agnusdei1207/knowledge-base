## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 현재 입력만으로 출력이 결정되는 기억 소자 없는 디지털 회로로, 가산기·디코더·멀티플렉서 등이 대표적임 |
| **배경/필요성** | ALU·주소 디코딩·데이터 선택 등 CPU의 핵심 연산 경로가 조합 논리 회로로 구성됨 |
| **출제 의도** | 반가산기·전가산기의 구성과 멀티플렉서·디코더의 동작 원리를 설명할 수 있는지 평가함 |

## Ⅱ. 구성요소
```
+----------+     +----------+     +----------+
| 반가산기  | --> | 전가산기  | --> | 리플캐리  |
| (HA)     |     | (FA)     |     | 가산기   |
+----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| 반가산기(HA) | 2비트를 더하여 합(S=A⊕B)과 캐리(C=A·B)를 출력하는 최소 가산 회로임 | 받아올림 없는 한 자리 덧셈 |
| 전가산기(FA) | 이전 캐리를 포함한 3비트를 더하여 합과 캐리를 출력함 | 받아올림 있는 한 자리 덧셈 |
| 멀티플렉서(MUX) | 선택 신호에 따라 2^n개 입력 중 하나를 출력으로 전달하는 데이터 선택기임 | TV 채널 선택 리모컨 |

> 요약: HA(2비트 합) → FA(캐리 포함 합) → MUX(데이터 선택)로 조합 논리의 핵심을 구성함.

## Ⅲ. 절차
```
+------------+     +------------+
| 진리표정의  | --> | 부울식도출 |
| (입출력관계)|    | (SOP)     |
+------------+     +------------+
                        |
+------------+     +----+-------+
| 회로배치   | <-- | 게이트구현 |
| (배선연결) |     | (AND/OR)  |
+------------+     +------------+
```

1. 진리표 정의: 모든 입력 조합에 대한 출력(합·캐리 등)을 진리표로 정의함
2. 부울식 도출: SOP 형태의 부울 표현식을 도출하고 간소화함
3. 게이트 구현: 부울식을 AND·OR·XOR 게이트로 변환함
4. 회로 배치·배선: 게이트를 연결하여 전체 조합 회로를 완성함

> 요약: 진리표 → 부울식 → 게이트 구현 → 배선으로 조합 논리 회로를 설계함.

## Ⅳ. 문제점
- 리플 캐리 지연: n비트 리플 캐리 가산기는 캐리가 순차 전파되어 지연이 O(n)으로 증가함
- 팬아웃 제한: 다수 게이트를 구동할 때 신호 품질이 저하됨
- 글리치: 게이트 지연 차이로 일시적 잘못된 출력(Glitch)이 발생함

## Ⅴ. 개선방안
- (단기) 캐리 룩어헤드(CLA): 캐리를 병렬 계산하여 지연을 O(log n)으로 줄임
- (중기) 캐리 세이브 가산기(CSA): 멀티 피연산자 덧셈에서 캐리를 분리 처리하여 파이프라인에 활용함
- (장기) EDA 자동 합성: HDL로 동작을 기술하면 EDA 도구가 최적 회로를 자동 생성함

## Ⅵ. 전망
- AI 가속기·NPU에서 MAC(Multiply-Accumulate) 연산의 핵심이 조합 논리 가산기이며, 3nm 이하 공정에서 전력 최적화된 저전력 가산기 아키텍처가 확산될 전망임
