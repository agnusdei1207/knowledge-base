# 📖 【암기용】 개념 완전 이해

## 한눈에
- **개요**: 조합 논리 회로(Combinational Logic)는 **현재 입력값의 조합만으로** 출력이 결정되는 **기억 없는(Memory-less)** 논리 회로이며, 피드백 루프가 없는 것이 특징이다.
- **왜 필요한가**: CPU의 ALU(연산), MUX(데이터 선택), Decoder(주소 해독) 등 컴퓨터 시스템의 **'의사결정 및 데이터 가공'**의 가장 기본 단위이기 때문이다.
- **핵심 직관**: **"거울"**과 같다. 거울 앞에 서면(입력) 즉시 내 모습이 비치고(출력), 내가 떠나면 거울은 내 모습을 기억하지 못한다.

## 핵심 용어 정리

| 용어 | 의미 | 비유/핵심 |
|:---|:---|:---|
| **Memory-less** | 과거의 상태나 입력을 보관하지 않는 성질 | 단기 기억 상실증 |
| **반가산기(HA)** | 2개의 비트를 더해 합(S)과 자리올림(C)을 출력 | 일의 자리 덧셈 |
| **전가산기(FA)** | 하위 비트의 자리올림(Cin)까지 포함해 3비트를 연산 | 받아올림 있는 덧셈 |
| **MUX (Multiplexer)** | 여러 입력 중 하나를 선택해 출력 (n select -> 2^n inputs) | 데이터 선택기/스위치 |
| **Decoder** | 코딩된 n비트 입력을 2^n개의 출력 중 하나로 변환 | 주소 번지 해독기 |

## 깊이 이해
- **배경 (추상화의 계층)**: 개별 논리 게이트(AND, OR, NOT)는 너무 원자적이다. 이를 유의미한 기능을 수행하는 **'블록'**으로 묶은 것이 조합 회로다.
- **동작 원리 (부울 대수의 실체화)**:
    - 모든 조합 회로는 **진리표(Truth Table)**로 표현 가능하며, 이는 곧 **부울 함수**로 치환된다.
    - **가산기(Adder)**: ALU의 핵심. RCA(Ripple Carry Adder)는 구조가 단순하나 캐리 전파 지연(O(N))이 병목이다. 이를 해결하기 위해 **CLA(Carry Lookahead Adder)**는 캐리 생성(G)과 전파(P)를 병렬로 미리 계산하여 O(log N)의 속도를 달성한다.
    - **MUX**: 여러 버스(Bus) 데이터 중 하나를 선택해 레지스터로 보낼 때 사용된다. 데이터 통로의 '교차로 신호등' 역할을 수행한다.
- **기술적 밀도 (Glitches & Hazards)**:
    - 조합 회로의 치명적 결함은 **글리치(Glitch)**다. 입력 신호가 게이트를 통과하는 시간이 달라 일시적으로 원치 않는 신호가 튀는 현상이다. 이를 방지하기 위해 **Hazard Free** 설계(K-map에서 인접 묶음 공유)가 필수적이다.
- **구체 예시**:
    - **7-Segment Decoder**: 숫자 0~9를 입력받아 LED 7개를 켜서 숫자를 표시하는 회로. 전형적인 n to 2^n 변환 구조다.

## 연결 개념
- **027 논리 게이트**: 조합 회로의 구성 원자.
- **029 순서 논리 회로**: 조합 회로에 '기억(플립플롭)'을 더해 상태(State)를 갖게 한 상위 단계.
- **031 정보 이론**: 데이터 압축(인코딩)과 해독(디코딩)의 논리적 배경.

# 📝 【답안용】 시험 답안 템플릿

## 핵심 인사이트 (3줄 요약)
> 1. **본질**: 현재 입력에 의해서만 출력이 결정되는 무기억(Memory-less) 회로로, 진리표와 부울 대수로 완벽하게 정의됨.
> 2. **기술**: 전파 지연(Propagation Delay) 최소화를 위해 RCA 대신 CLA를 사용하며, 글리치 방지를 위한 Hazard-Free 설계가 품질의 핵심임.
> 3. **가치**: CPU 데이터 패스의 ALU(가산기), 제어 유닛(디코더), 버스 제어(MUX)를 구성하는 디지털 컴퓨팅의 연산 기초.

## Ⅰ. 조합 논리 회로의 정의 및 특징
- **정의**: 임의의 시점에서의 출력이 그 시점의 입력에 의해서만 결정되는 논리 회로 (No Feedback)
- **특징**:
    - **무기억성**: 과거의 상태를 유지하지 않으며 기억 소자(플립플롭 등)를 포함하지 않음
    - **전파 지연**: 입력 변화가 출력에 반영되기까지 논리 게이트의 물리적 지연(Latency)이 존재함
    - **수학적 명확성**: 진리표(Truth Table)와 부울 대수식을 통해 1:1 매핑 설계 가능

## Ⅱ. 주요 구성요소 및 동작 원리

### 1. 연산 유닛 (Adders)
- **반가산기(HA)**: $S = A \oplus B$, $C = A \cdot B$. 두 비트의 합과 올림수 처리
- **전가산기(FA)**: $Cin$을 포함한 3비트 연산. $S = A \oplus B \oplus Cin$
- **CLA(Carry Lookahead)**: 캐리 예측 논리 ($G_i = A_i B_i$, $P_i = A_i \oplus B_i$)를 통해 고속 연산 구현

### 2. 제어 및 변환 유닛 (Selector/Decoder)
- **MUX (Multiplexer)**: $2^n$개의 입력 중 선택 신호에 따라 1개를 출력 ($N:1$ 데이터 선택)
- **Decoder**: $n$비트 이진 정보를 $2^n$개의 고유한 출력 신호로 해독 (주소 지정의 핵심)
- **Encoder**: 활성화된 $2^n$개의 입력 중 하나를 $n$비트 이진 코드로 압축 (인터럽트 처리)

## Ⅲ. 조합 논리 회로의 설계 최적화 및 문제점 해결

### 1. 설계 최적화 (Optimization)
- **K-Map (Karnaugh Map)**: 변수가 적을 때 시각적으로 최소항을 묶어 게이트 수 최소화
- **Quine-McCluskey**: 변수가 많을 때 컴퓨터 알고리즘으로 논리식 최적화

### 2. 신뢰성 확보 (Hazard & Glitch 대응)
- **Static Hazard**: 입력 변화 시 출력에 짧은 펄스(Glitch) 발생
- **대응 방안**: K-Map 설계 시 인접한 1의 묶음들이 겹치도록 중복 항(Redundant Prime Implicant)을 추가하여 전이 과정의 안정성 확보

## Ⅳ. 조합 논리 회로 vs 순서 논리 회로 비교

| 항목 | 조합 논리 회로 (Combinational) | 순서 논리 회로 (Sequential) |
|:---|:---|:---|
| **출력 결정** | 현재 입력 ($O = f(I)$) | 현재 입력 + 과거 상태 ($O = f(I, S)$) |
| **기억 소자** | 없음 | 있음 (Flip-Flop, Latch, Register) |
| **피드백** | 없음 | 있음 (Feedback Loop 존재) |
| **대표 회로** | 가산기, MUX, 디코더, ALU | 카운터, 레지스터, CPU 제어기 |

## Ⅴ. 기술적 심화: RCA vs CLA 성능 분석
- **RCA (Ripple Carry Adder)**: 캐리가 하위에서 상위로 전파될 때까지 대기. 지연시간 $T \propto N$ (비효율)
- **CLA (Carry Lookahead Adder)**: 모든 비트의 캐리를 동시에 계산. 지연시간 $T \propto \log N$ (고성능)
- **적용**: 현대의 High-performance CPU는 고클럭 유지를 위해 CLA 또는 Parallel Prefix Adder 구조를 채택함

## Ⅵ. 실무 적용 및 향후 전망
- **FPGA 기반 설계**: LUT(Look-Up Table)를 사용하여 복잡한 조합 논리를 하드웨어적으로 고속 구현
- **Approximate Computing**: 딥러닝 연산 등에서 전력 효율을 위해 LSB(하위 비트) 가산기의 정밀도를 의도적으로 낮추는 연구 활발
- **결론**: 조합 논리는 단순한 부품을 넘어, 데이터 패스의 지연(Timing)을 결정하는 핵심 요소이며, 타이밍 분석(Static Timing Analysis)을 통한 검증이 설계의 핵심임

### 🔀 문제 유형별 목차 전환
- **원리 중심**: Ⅱ(구성요소) → Ⅲ(설계 최적화) → Ⅴ(RCA/CLA 심화)
- **비교 중심**: Ⅰ(정의) → Ⅳ(순서회로 비교) → Ⅴ(가산기 성능 비교)
- **최신 동향**: Ⅰ(정의) → Ⅱ(주요회로) → Ⅵ(저전력/근사 컴퓨팅 응용)
