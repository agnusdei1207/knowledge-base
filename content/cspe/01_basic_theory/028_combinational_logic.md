# 📖 【암기용】 개념 완전 이해

## 한눈에
- **개요**: 조합 논리 회로(Combinational Logic)는 **현재 입력값의 조합만으로** 출력이 결정되는 **기억 없는(Memory-less)** 논리 회로이며, 가산기(Adder)·멀티플렉서(MUX)·디코더(Decoder)가 대표적이다.
- **왜 필요한가**: CPU의 ALU에서 산술·논리 연산을 수행하고, 메모리 주소를 해독하며, 데이터 경로를 선택하는 **연산·선택 블록**을 표준화된 모듈로 제공하기 위해서다.
- **핵심 직관**: 커피 자판기의 계산기와 같다 — 지금 누른 버튼(입력)에 맞춰 바로 커피(출력)가 나오며, 이전에 누가 무슨 버튼을 눌렀는지(과거 상태)는 전혀 관여하지 않는다.

## 핵심 용어 정리 (내부에 등장하는 것들)

조합 논리 회로의 핵심 모듈을 세운다. 이를 구성하는 논리 게이트 기초는 027 참조, 기억력이 추가된 순서 논리 회로는 029 참조.

| 용어/표기 | 의미 | 비유·예 |
|:---|:---|:---|
| 조합 논리 회로 (상위 키워드) | 피드백 루프·기억 소자 없이 현재 입력만으로 출력이 결정되는 회로 | 기억력 없는 계산기 |
| 반가산기 (Half Adder, HA) | 2비트(A, B)를 더해 합(Sum)과 캐리(Carry)를 출력 | 일의 자리 두 수 더하기 |
| 전가산기 (Full Adder, FA) | HA 2개 + OR 1개로 3비트(A, B, Cin)를 더해 Sum과 Cout 출력 | 십의 자리 덧셈 (아랫자리 올림 포함) |
| 리플 캐리 가산기 (RCA) | FA를 N개 직렬 연결한 다중 비트 가산기 — 캐리가 LSB→MSB로 순차 전파 | 자릿수별 순차 덧셈 |
| CLA (Carry Lookahead Adder) | 캐리를 병렬 예측해 전파 지연을 O(1)로 축소한 고속 가산기 | 전 자릿수 캐리를 한 번에 미리 계산 |
| 멀티플렉서 (MUX) | 2^n개 입력 중 n개 선택선(Select)으로 1개를 선택·출력 | TV 방송국 감독의 카메라 전환 스위치 |
| 디멀티플렉서 (DEMUX) | 1개 입력을 선택선에 따라 2^n개 출력 중 1개로 분배 | MUX의 역방향 |
| 디코더 (Decoder) | n비트 입력을 해독해 2^n개 출력 중 1개만 활성화 | 비밀번호 → 특정 사물함 1개 열림 |
| 인코더 (Encoder) | 2^n개 입력 중 활성화된 1개를 n비트로 압축 | 우선순위 인터럽트 번호 산출 |

## 깊이 이해
- **배경·문제의식**: 논리 게이트(027) 한두 개로는 의미 있는 연산이 불가능하다. 덧셈·선택·해독을 수행하려면 여러 게이트를 모듈(부품) 단위로 규격화해야 한다.
- **작동 원리**:
  - **반가산기(HA)**: Sum = A ⊕ B (XOR), Carry = A · B (AND). 2개의 게이트로 1비트 덧셈을 수행한다.
  - **전가산기(FA)**: HA 2개를 직렬 연결하고 캐리를 OR로 합쳐 Cin까지 포함한 3비트 덧셈을 수행한다. 이 FA를 N개 이어 붙이면 N비트 RCA(리플 캐리 가산기)가 된다.
  - **RCA의 병목**: LSB의 캐리가 MSB까지 전파되어야 최종 결과가 확정되므로, 전파 지연이 O(N)으로 증가한다.
  - **CLA 해결**: 캐리 생성(Generate, G=A·B)과 전파(Propagate, P=A⊕B) 신호를 별도 추출해 모든 비트의 캐리를 병렬로 한 번에 계산하면 지연이 O(log N)으로 감소한다.
  - **MUX**: n개 선택선(Select)이 AND 배열을 필터링해 2^n개 입력 중 정확히 1개만 출력으로 통과시킨다.
  - **디코더**: n비트 주소를 AND 게이트 트리로 해독해 2^n개 출력선 중 1개만 활성화한다 — 메모리 주소 해석의 핵심 회로.
- **비유 (MUX)**: 4대 카메라가 있고 방송 화면은 1개다. 감독이 선택 스위치 2개(00→1번, 11→4번)를 조작해 1개 화면만 송출하는 장치이다.
- **구체 예시**: 3×8 디코더 — 입력 101₂(=5)를 넣으면 8개 출력선 중 5번 선만 활성화(1)되어 해당 메모리 셀을 선택한다.
- **흔한 오해·주의점**:
  - **"가산기가 값을 저장한다"**: 조합 회로에는 기억 소자가 없어 전기가 끊기면 결과가 즉시 사라진다. 저장은 순서 논리 회로(레지스터, 029)의 역할이다.
  - **디코더와 MUX 혼동**: 디코더는 n→2^n(주소 해독·분배), MUX는 2^n→1(데이터 선택·집중)으로 방향이 반대이다.

## 연결 개념
- **논리 게이트·부울 대수 (027)**: 조합 회로를 구성하는 기본 게이트와 최적화 이론.
- **순서 논리 회로 (029)**: 조합 회로에 피드백(플립플롭)을 추가해 기억력을 부여한 상위 회로.
- **2의 보수 (026)**: 전가산기 + NOT 게이트 + Cin=1로 가감산을 통합 구현하는 응용.
- **CPU 아키텍처 (031 등)**: ALU·데이터 패스·메모리 컨트롤러에서 조합 회로가 배치되는 상위 구조.

# 📝 【답안용】 시험 답안 템플릿

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 조합 논리 회로는 피드백·기억 소자 없이 현재 입력 조합만으로 출력이 결정되는 무기억 회로이며, 가산기(ALU)·MUX(데이터 선택)·디코더(주소 해독)가 CPU 데이터 패스를 구성함.
> 2. **가치**: FA를 직렬 연결한 RCA로 다중 비트 연산이 가능하며, CLA로 캐리 전파 지연을 O(log N)으로 축소해 클럭 사이클 내 연산 완료를 보장함.
> 3. **판단 포인트**: RCA의 O(N) 캐리 전파 지연이 전체 시스템 클럭을 제약하므로, CLA 적용 여부가 프로세서 성능 설계의 핵심 결정점임.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 기억 소자 유무에 따른 회로 분류 | 현재 입력에만 의존, 피드백 없음, 지연만 존재 | "상태 유지" 등 순서 논리 서술과 혼동 |
| 대표 조합 회로의 구조·역할 매핑 | HA/FA(가산), MUX(선택), 디코더(해독) | 디코더(n→2^n)와 MUX(2^n→1) 방향 혼동 |
| 가산기 성능 병목과 해결 | RCA의 O(N) 지연, CLA의 G/P 병렬 캐리 예측 | CLA 원리 없이 "빠른 가산기"로만 서술 |

> 요약: 무기억성 정의를 명확히 하고, 가산기·MUX·디코더의 CPU 배치와 RCA→CLA 성능 개선을 연결해야 함.

## Ⅰ. 개요 및 필요성
- 개요: 피드백·기억 소자 없이 현재 입력 신호 조합만으로 즉시 출력이 결정되는 논리 게이트의 모듈화된 블록임
- 배경: CPU 내부의 연산·선택·해독 기능을 수행하려면 게이트들을 표준화된 모듈로 규격화해야 함
- 필요성: 가산기(ALU 연산)·MUX(데이터 경로 선택)·디코더(메모리 주소 해독)를 블록화해 프로세서 설계 복잡도를 낮추고 재사용성을 극대화함

## Ⅱ. 구조 및 구성요소
선형 구조도 (CPU 데이터 패스 내 조합 회로 배치):

    명령어 주소 -> [디코더] -> 제어 신호
    데이터 버스 -> [MUX: 레지스터 선택] -> [전가산기(ALU)] -> 연산 결과 -> [순서 논리(029)로 저장]

| 회로 모듈 | 구성 | CPU 내 역할 |
|:---|:---|:---|
| 전가산기 (FA) | HA 2개 + OR 1개 (A, B, Cin → Sum, Cout) | ALU의 가감산 기본 단위 |
| 멀티플렉서 (MUX) | 2^n 입력, n 선택선, 1 출력 | 레지스터·메모리 중 1개를 선택해 버스로 송출 |
| 디코더 (Decoder) | n 입력, 2^n 출력 | N비트 주소를 해독해 특정 메모리 셀 1개 활성화 |
| 인코더 (Encoder) | 2^n 입력, n 출력 | 인터럽트 우선순위 압축(Priority Encoder) |

> 요약: 가산기는 데이터를 가공하고, MUX·디코더는 데이터의 경로를 열어주는 트래픽 컨트롤러 역할을 함.

## Ⅲ. 동작원리 및 흐름도
선형 흐름도 (전가산기 다중 비트 확장 — RCA):

    LSB(A0, B0) -> FA0: Sum0, Cout0 -> Cout0을 FA1의 Cin으로 -> FA1: Sum1, Cout1 -> ... -> MSB 도달

1. 하위 연산: 최하위 비트(LSB)의 A0, B0를 FA0으로 가산해 Sum0과 Cout0을 생성함
2. 캐리 전파: Cout0이 다음 FA1의 Cin으로 전달되어 A1, B1, Cin1을 가산함
3. 순차 반복: 이 과정이 MSB까지 N번 반복되어 전체 Sum[N-1:0]과 최종 Cout이 확정됨
4. MUX/디코더: MUX는 선택선 AND 배열로 입력 1개를 필터링하고, 디코더는 주소 AND 트리로 출력선 1개를 활성화함

> 요약: RCA는 캐리가 LSB→MSB로 순차 전파되어 O(N) 지연이 발생하며, CLA는 G/P 신호로 캐리를 병렬 예측해 O(log N)으로 단축함.

## Ⅳ. 특징
- 무기억성(Memory-less): 피드백 루프가 없어 과거 상태를 알지 못하며, 입력이 변하면 게이트 지연 후 즉시 출력이 갱신됨
- 시간 독립성: 클럭 동기화 없이 입력 변화가 전파 지연(Propagation Delay)만큼의 물리적 시간 후 출력에 반영됨
- 설계 투명성: 모든 입출력 관계를 진리표로 나열할 수 있어 K-Map(027) 기반의 수학적 최소화 설계가 보장됨
- CLA 병렬화: RCA의 O(N) 순차 캐리 지연을 Generate/Propagate 병렬 예측으로 O(log N)에 축소 가능함

## Ⅴ. 심화 비교 및 적용 판단

| 구분 | 조합 논리 회로 | 순서 논리 회로 (029) | 선택 기준 |
|:---|:---|:---|:---|
| 출력 결정 요인 | 현재 입력만 | 현재 입력 + 과거 상태(기억) | 연산인가, 저장인가 |
| 기억 소자 | 없음 | 플립플롭 (Flip-Flop) | 상태 보존 필요 여부 |
| 클럭 의존 | 비동기 (전파 지연만) | 클럭 동기 (Edge-triggered) | 타이밍 제어 필요 여부 |
| 적용 | ALU·디코더·MUX | 레지스터·카운터·메모리 | 데이터 가공 vs 보관 |

> 요약: 조합 회로(연산·선택)와 순서 회로(기억·카운트)가 결합되어야 상태 머신(CPU)이 완성됨.

**리스크·대응:**
- 리플 캐리 지연: N비트 RCA에서 캐리가 MSB까지 전파되는 데 O(N) 게이트 지연 → CLA(Carry Lookahead) 적용으로 O(log N) 단축 (지표: 임계 경로 지연 시간)
- 디코더 글리치: 주소 버스 전환 시 글리치로 다수 셀 동시 활성화 위험 → Enable(EN) 핀으로 주소 안정화 후 활성화 (지표: 다중 활성화 에러율 0)

**점검 지표:**
- 임계 경로 지연: 가산기 최장 전파 경로가 1 클럭 사이클 내 완료되는지 — 타이밍 분석(STA) 검증
- 게이트 카운트: MUX·디코더의 입력 수 대비 게이트 수가 최적인지 — 합성 보고서 확인

## Ⅵ. 실무 적용 및 결론

**적용 방안:**
1. CPU ALU 고속 설계: 32/64비트 가산기를 CLA 기반으로 병렬 설계해 EX(실행) 스테이지 1 사이클 내 연산 완료를 보장하고 임계 경로를 단축함
2. FPGA LUT 기반 라우팅: MUX 트리를 대량 배치해 프로그래머블 로직 셀 간 데이터 흐름을 동적으로 재구성하는 룩업 테이블(LUT) 구조를 형성함
3. 메모리 주소 해독: 디코더를 메모리 컨트롤러에 배치해 32비트 주소의 상위 비트로 뱅크를, 하위 비트로 행/열을 즉시 해독해 읽기/쓰기를 활성화함

**결론:**
- 기술사 판단: 조합 논리 회로는 진리표를 물리 회로로 변환한 연산의 심장이며, CLA에 의한 캐리 지연 통제가 전체 시스템 클럭 속도를 좌우하는 핵심 설계 포인트임
- 향후 방향: AI 가속기에서 MAC(Multiply-Accumulate) 조합 유닛의 초집적화가 진행되며, 근사 컴퓨팅(Approximate Computing)으로 가산기 정밀도를 의도적으로 낮춰 전력·면적을 절감하는 설계가 확산되고 있음
