## 미리 알고가기

- 조합 논리 회로(Combinational Logic): 출력이 현재 입력 조합으로만 결정되고 내부 상태를 저장하지 않는 회로임
- 전가산기(Full Adder): 두 입력 비트와 하위 자리올림을 더해 합과 상위 자리올림을 출력하는 회로임
- 멀티플렉서(Multiplexer, MUX): 여러 입력 중 선택 신호가 지정한 하나를 출력하는 데이터 선택기임
- 디코더(Decoder): $n$비트 입력을 $2^n$개 출력 중 하나로 펼치는 회로임
- 전파 지연(Propagation Delay): 입력 변화가 출력에 안정적으로 반영될 때까지 걸리는 시간임
- 크리티컬 패스(Critical Path): 회로에서 가장 긴 지연을 갖는 경로이며 최대 동작 속도를 제한함
- 반가산기(Half Adder): 두 입력 비트의 합과 자리올림을 계산하는 회로임
- 비교기(Comparator): 두 입력값의 크기와 동등 여부를 판정하는 회로임
- 글리치(Glitch): 입력 도달 시간 차이로 출력에 순간적으로 발생하는 잘못된 신호임
- $A,B,Cin,Sum,Cout$: 가산기 도식의 두 입력, 하위 자리올림, 합, 상위 자리올림을 나타냄

## 작성 근거(검토용)

- **개요 구성**: 상태 저장이 없고 현재 입력만 본다는 조합 논리의 경계를 먼저 제시함
- **Ⅱ. 특징 선정**: 결정성·전파 지연·최소화·샘플링 조건을 선별해 순서 논리와 자연스럽게 대비되게 함
- **Ⅲ. 비교축 선정**: _keywords.md의 가산기·멀티플렉서를 중심으로 디코더와 비교기를 보조 유형으로 배치함
- **Ⅳ·Ⅴ. 구조·절차 선정**: 게이트 연결과 지연 흐름을 나누어 회로 구조와 동작 시간을 함께 설명함
- **Ⅵ·Ⅶ. 사례·결론 선정**: 다비트 가산기의 자리올림 전달 지연과 MUX 글리치처럼 실제 설계에서 검증해야 할 위험을 남김
- **전수 검수**: 제목부터 결론까지 용어·표·도식·요약을 대조하고 가산기·MUX 정의와 절 간 판단축을 일치시킴

## Ⅰ. 개요

- **정의/개념**: 조합 논리 회로는 기억 소자 없이 논리 게이트의 연결만으로 현재 입력에 대응하는 출력을 전파 지연 후 생성하는 디지털 회로임
- **배경/필요성**: 산술·논리 연산, 주소 해독, 데이터 선택을 현재 입력만으로 처리할 조합 논리 블록이 필요함

### 쉽게 이해하기 (학습용)
- 동전을 넣고 버튼을 누르면 그 순간의 입력만으로 바로 음료가 나오는 자판기와 같이, 과거 기록 없이 지금 누른 버튼에만 반응함

## Ⅱ. 특징

- 같은 입력 조합에는 항상 같은 출력이 나오는 결정적 회로임
- 내부 상태가 없으므로 클록이 아니라 게이트 전파 지연이 동작 속도를 제한함
- 부울식 최소화로 게이트 수·면적·전력 소모를 줄임
- 출력 안정 전 샘플링하면 잘못된 값이 저장되므로 다음 순서 회로의 샘플링 타이밍과 맞아야 함

### 쉽게 이해하기 (학습용)
- 똑같은 버튼을 누르면 언제나 똑같은 음료가 나오고, 회로 안에 따로 기억하는 장치가 없어서 신호가 통과하는 시간만큼만 출력이 늦어짐
- 음료가 완전히 나오기 전에 성급하게 집어가면 엉뚱한 걸 받게 되듯, 출력이 안정되기 전에 값을 읽으면 오류가 남

## Ⅲ. 종류 및 비교

| 회로 | 입력 | 산출 결과 | 대표 적용 사례 |
|:---|:---|:---|:---|
| 반가산기 | 두 입력 비트 | 합 비트와 자리올림 비트 | 입력 자리올림이 없는 최하위 비트 가산 |
| 전가산기 | 두 입력 비트와 하위 자리올림 | 합 비트와 상위 자리올림 비트 | 산술 논리 장치·다비트 가산기 |
| 멀티플렉서 | 여러 데이터와 선택 신호 | 선택 신호가 지정한 단일 데이터 | 데이터 경로 선택 |
| 디코더 | $n$비트 코드 | 입력 코드에 대응해 활성화된 단일 출력선 | 주소 선택·명령 해독 |
| 비교기 | 두 입력값 | 대소·동등 관계를 나타내는 신호 | 분기·정렬 하드웨어 |

> 요약: 가산기는 합·자리올림, MUX는 데이터 선택, 디코더는 출력 활성화, 비교기는 크기·동등성을 담당함.

### 쉽게 이해하기 (학습용)
- 반가산기는 두 숫자만 더하는 간이 계산기, 전가산기는 이월된 값까지 함께 더하는 계산기, 멀티플렉서는 여러 채널 중 하나를 고르는 선택 버튼, 디코더는 암호 하나로 해당 서랍만 여는 장치, 비교기는 두 값 중 어느 게 큰지 저울질하는 장치임

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 입력 조합 | 연산 데이터·선택 신호의 현재 비트 조합 |
| 부울 함수 | 입력 조합과 출력의 대응 관계를 정의하는 논리식 |
| 게이트 네트워크 | 부울 함수를 산술·선택·해독 기능으로 구현하는 연결 구조 |
| 크리티컬 패스 | 입력에서 출력까지 누적 지연이 가장 길어 최대 동작 속도를 제한하는 경로 |

```text
전가산기

A -----+
       +--> [ XOR ] ---> [ XOR ] ---> Sum
B -----+                    ^
                            |
Cin ------------------------+

A,B,Cin --> [ 자리올림 로직 ] --> Cout
```

> 요약: 조합 논리 회로는 현재 입력의 부울 함수를 게이트 네트워크로 구현하며 크리티컬 패스가 최대 동작 속도를 결정함.

### 쉽게 이해하기 (학습용)
- 입력 조합은 지금 누른 버튼들, 부울 함수는 버튼 조합과 결과를 잇는 규칙, 게이트 네트워크는 그 규칙을 구현한 실제 배선이고, 크리티컬 패스는 신호가 지나가는 가장 긴 길이라 전체 속도를 좌우함

## Ⅴ. 원리 및 절차 흐름도

```text
입력 조합 변경 → 게이트별 논리값 전파
                          ↓
              크리티컬 패스 지연 경과
                          ↓
                   안정된 출력 확정
```

1. **입력 안정**: 데이터와 선택 신호가 입력단에 도달하고 전압 레벨이 고정됨
2. **논리 평가**: 각 게이트가 입력 조합에 맞는 중간 결과를 병렬로 계산함
3. **지연 통과**: 자리올림 경로나 선택 경로의 전파 지연이 끝날 때까지 기다림
4. **출력 확정**: 최종 출력이 안정되면 다음 순서 회로나 외부 블록이 값을 사용함

> 요약: 논리식이 맞아도 전파 지연이 끝난 뒤에 다음 회로가 출력을 샘플링해야 함.

### 쉽게 이해하기 (학습용)
- 버튼을 누르고 손을 떼면 내부 배선을 따라 신호가 퍼져나가다가, 가장 긴 경로까지 신호가 다 도착한 뒤에야 비로소 최종 결과가 확정됨

## Ⅵ. 실무 사례

1. CPU 가산기는 자리올림을 병렬 계산해 연산 경로를 줄임
2. MUX 경로는 선택 신호의 도착 시간을 맞추고 출력 레지스터로 글리치를 차단함

### 쉽게 이해하기 (학습용)
- CPU 안 덧셈 회로가 자리올림을 여러 갈래로 동시에 계산해 기다리는 시간을 줄이는 것과 같음

## Ⅶ. 결론

- 조합 논리 회로는 현재 입력으로 출력을 계산하므로 논리 최소화와 전파 지연을 함께 검토해야 함
- 크리티컬 패스가 클록 목표를 넘으면 논리식 축약만 반복하지 말고 파이프라인 분할이나 병렬 자리올림 구조를 선택해야 함

### 쉽게 이해하기 (학습용)
- 신호가 지나가는 가장 긴 길이 목표 속도를 못 맞추면, 수식을 더 줄이려 애쓰기보다 아예 길을 여러 단계로 나누거나 갈래를 늘리는 방법을 써야 함
