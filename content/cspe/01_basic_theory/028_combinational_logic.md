## 미리 알고가기

- 조합 논리: 현재 입력 조합만으로 출력이 결정되고 내부 상태를 저장하지 않는 회로임
- 반가산기: 두 입력 비트의 합과 carry를 계산하는 최소 가산 회로임
- 전가산기: 두 입력 비트와 이전 자리 carry를 함께 더하는 1비트 가산 회로임
- 멀티플렉서: 선택 신호에 따라 여러 입력 중 하나를 출력으로 전달하는 회로임
- 전파 지연: 입력 변화가 출력에 반영되기까지 걸리는 회로 지연 시간임

## Ⅰ. 개요

- **정의**: 조합 논리 회로는 저장 소자 없이 현재 입력값과 논리 함수 기준으로 출력이 즉시 결정되는 디지털 회로이며, 산술 연산, 데이터 선택, 주소 해석 같은 CPU 데이터 경로를 구현하기 위해 사용함.
- **배경/필요성**: ALU, 디코더, 인코더, 멀티플렉서는 시스템 성능의 핵심 경로에 놓이므로 논리식의 기능뿐 아니라 지연과 게이트 비용을 함께 설계해야 함.
- **비유**: 현재 들어온 재료만 보고 즉석에서 결과를 내는 계산기나 분류기와 같음.

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 조합 논리와 순서 논리 구분 | 현재 입력만으로 출력 결정, 기억 소자 없음 | 플립플롭·상태 저장과 혼동 |
| 대표 회로 동작 설명 | 반가산기, 전가산기, MUX, 디코더 | 회로 용도 나열에 그침 |

> 요약: 조합 논리 회로는 입력 조합을 논리식으로 변환해 저장 없이 즉시 출력하는 회로이며, 연산과 데이터 선택의 기본 경로가 됨.

## Ⅱ. 특징/비교

| 판단 기준 | 조합 논리 회로 | 순서 논리 회로 |
|:---|:---|:---|
| 출력 결정 기준 | 현재 입력만으로 결정됨 | 현재 입력과 이전 상태로 결정됨 |
| 구성 소자 | 게이트, 가산기, MUX, 디코더 중심임 | 플립플롭, 레지스터, 카운터가 포함됨 |
| 설계 핵심 | 논리식 간소화와 전파 지연 최소화임 | 클럭, 상태 전이, setup/hold 관리임 |
| 선택 기준 | 즉시 계산과 선택이 필요할 때 사용함 | 상태 저장과 순차 제어가 필요할 때 사용함 |

- **성능 기준**: critical path에 있는 게이트 단계 수가 최대 동작 속도를 좌우함.
- **기능 기준**: 진리표와 논리식이 설계 요구 출력을 정확히 표현해야 함.
- **구조 기준**: 큰 회로는 반가산기, 전가산기, MUX 같은 모듈을 조합해 계층적으로 설계함.

> 요약: 조합 논리는 상태를 저장하지 않는 대신 전파 지연과 논리식 최적화가 품질 기준이 됨.

## Ⅲ. 구성요소

```text
+------------+      +------------+      +------------+
| Inputs     | ---> | Logic      | ---> | Outputs    |
| A, B, Cin  |      | Network    |      | S, Cout    |
+------------+      +------------+      +------------+
       |                   |
       v                   v
+------------+      +------------+
| Selector   |      | Delay      |
| Signals    |      | Path       |
+------------+      +------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 입력 신호 | 회로가 처리할 현재 비트 조합이며 출력의 유일한 근거가 됨 | 계산 문제의 숫자 |
| 논리 네트워크 | 게이트 조합으로 진리표 또는 논리식을 물리적으로 구현함 | 계산 규칙 묶음 |
| 반가산기 | 두 비트의 합과 carry를 계산하지만 이전 carry는 고려하지 않음 | 받아올림 없는 한 자리 덧셈 |
| 전가산기 | 이전 carry까지 포함해 합과 다음 carry를 계산함 | 받아올림 있는 한 자리 덧셈 |
| 멀티플렉서 | 선택 신호로 여러 입력 중 하나를 출력에 연결함 | 채널 선택기 |

> 요약: 조합 논리는 입력 신호를 논리 네트워크에 통과시켜 합, carry, 선택 출력 같은 즉시 결과를 만드는 구조임.

## Ⅳ. 절차

```text
+------------+      +------------+      +------------+      +------------+
| Define     | ---> | Truth      | ---> | Simplify   | ---> | Map to     |
| Outputs    |      | Table      |      | Logic      |      | Gates      |
+------------+      +------------+      +------------+      +------------+
```

1. **출력 조건 정의**: 입력 조합별로 필요한 출력과 선택 신호의 의미를 정함.
2. **진리표 작성**: 모든 입력 조합에 대해 합, carry, 선택 출력 등을 표로 채움.
3. **논리식 도출**: SOP/POS 또는 카르노 맵으로 출력별 논리식을 간소화함.
4. **게이트 매핑**: 간소화식을 게이트 또는 표준 모듈로 구현하고 전파 지연을 계산함.

> 요약: 조합 회로 설계는 출력 조건을 진리표로 고정하고 논리식 간소화 후 게이트 지연을 검증하는 과정임.

## Ⅴ. 문제점

- **P1 전파 지연 누적**: 리플 캐리 가산기처럼 carry가 단계별로 전달되면 비트 수가 늘수록 critical path가 길어짐.
- **P2 글리치 발생**: 입력이 동시에 변하지 않거나 경로 지연이 다르면 짧은 순간 잘못된 출력이 생길 수 있음.
- **P3 규모 증가 복잡도**: 입력 수가 증가하면 진리표와 게이트 조합이 급증해 수작업 설계가 어려워짐.

> 요약: 조합 논리의 핵심 문제는 지연, 순간 오류, 규모 증가에 따른 설계 복잡도임.

## Ⅵ. 개선방안

- **P1 대응**: carry lookahead, carry select, parallel prefix 가산기를 사용해 carry 전파 경로를 줄임. (확인: critical path delay)
- **P2 대응**: 동기식 샘플링, hazard-free 논리, 타이밍 여유 분석으로 글리치가 래치되지 않게 함. (확인: STA와 시뮬레이션)
- **P3 대응**: HDL 모듈화, EDA 합성, 계층 설계로 회로 규모와 검증 범위를 관리함. (확인: 합성 리포트와 테스트벤치)

> 요약: 조합 회로는 빠른 가산 구조, 타이밍 검증, HDL 기반 계층 설계로 성능과 신뢰성을 확보함.

## Ⅶ. 전망

- **발전 방향**: AI 가속기, 네트워크 프로세서, 암호 모듈에서 조합 논리 최적화는 처리량과 전력 효율의 핵심으로 남을 전망임.
- **기술사적 판단**: 기능 정합성뿐 아니라 critical path, 전력, 면적 제약을 함께 보는 설계 판단이 필요함.
- **기술사 제언**: 답안에서는 조합/순서 논리 구분, 대표 회로 동작, 지연 개선 방안을 함께 정리해야 함.
