## 미리 알고가기

- 중복 부분 문제: 같은 부분 문제가 여러 경로에서 반복 등장하는 성질임
- 최적 부분 구조: 최적화 문제의 전체 최적해를 부분 문제의 최적해로 구성할 수 있는 성질임
- 상태(State): 부분 문제를 유일하게 식별하는 입력 위치·남은 자원 등의 최소 변수 조합임
- 상태값: 각 상태에서 구하려는 최솟값·최댓값·경우의 수·가능 여부임
- 점화식: 하위 상태값과 결합 연산으로 현재 상태값을 계산하는 식임
- 계단 예시: 마지막 선택이 1칸·2칸 오르기 두 가지이므로 $n$번째 계단까지의 경우의 수는 $dp[n]=dp[n-1]+dp[n-2]$임
- 기저 상태(Base State): 점화식 없이 답이 정해진 시작 상태이며, 위 계단 문제는 $dp[0]=1$, $dp[1]=1$에서 시작함
- 메모이제이션: 재귀 호출로 필요한 상태를 계산·저장하고 같은 상태가 다시 호출되면 저장값을 반환하는 방식임
- 타뷸레이션: 기저 상태부터 의존 순서대로 상태값을 표에 저장해 목표 상태까지 계산하는 방식임

## 작성 근거(검토용)

- **개요 구성**: 정의는 성립 조건과 저장·재사용 메커니즘을 담고, 배경은 중복 상태의 반복 계산 비용을 담아 문제에서 해법으로 이어지게 함
- **Ⅱ. 특징 선정**: 동일 상태의 동일 답, 최적 부분 구조, 점화식, 저장 재사용이 DP 성립을 가르는 핵심 조건임
- **Ⅲ 비교축 선정**: 하향식과 상향식의 수행 방식·계산 범위·주요 리스크만 남겨 시험 답안에 필요한 차이를 압축함
- **Ⅳ 구조 선정**: 상태·상태값·점화식·기저 상태·저장소만 남겨 DP의 필수 구조를 압축함

## Ⅰ. 개요

- **정의/개념**: 동적 계획법은 중복 부분 문제를 상태로 정의하고 최적 부분 구조에 따라 점화식을 세워 상태값을 저장·재사용하는 알고리즘 설계 기법임
- **배경/필요성**: 중복 부분 문제를 반복 계산하면 계산량이 급증하므로, 같은 상태의 재계산을 제거해야 함

## Ⅱ. 특징

- 같은 상태는 어떤 경로로 도달해도 같은 답을 가져야 저장값을 재사용할 수 있음
- 최적화 문제는 부분 문제의 최적해로 전체 최적해를 구성할 수 있어야 함
- 점화식은 문제의 선택 규칙에 따라 하위 상태값을 결합해 현재 상태값을 계산함
- 메모이제이션이나 타뷸레이션으로 계산한 상태값을 저장해 중복 계산을 제거함

## Ⅲ. 종류 및 비교

| 판단 기준 | 하향식 (Top-down) | 상향식 (Bottom-up) |
|:---|:---|:---|
| 수행 방식 | 재귀(Recursive) + 메모이제이션 | 반복문(Iterative) + 타뷸레이션 |
| 계산 범위 | 필요한 상태만 선택적 계산 | 전체 상태 공간 전수 계산 |
| 주요 리스크 | 스택 오버플로 | 불필요한 상태 계산 |

> 요약: 목표 상태에서 필요한 상태만 따라가면 하향식, 기저 상태부터 의존 순서대로 상태를 채우면 상향식임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 핵심 설명 |
|:---|:---|
| 상태(State) | 부분 문제를 식별하는 최소 변수 조합 |
| 상태값(Value) | 각 상태에서 구하는 최적값·경우의 수·가능 여부 |
| 점화식(Recurrence) | 하위 상태값으로 현재 상태값을 계산하는 식 |
| 기저 상태(Base State) | 점화식 없이 값이 정해진 시작 상태 |
| 저장소(Memo/Table) | 계산한 상태값을 보관하는 캐시·DP 테이블 |

> 요약: 부분 문제를 상태로 정의하고 기저 상태와 점화식으로 상태값을 계산·저장해 동일 상태의 중복 계산을 제거함.

## Ⅴ. 상태 설계 및 계산 절차

```text
하향식: 목표 상태 요청 -> 기저 상태·저장값 확인 -> 미계산 하위 상태 호출 -> 점화식 계산 -> 저장·반환
상향식: 기저 상태 저장 -> 의존 순서로 상태 순회 -> 점화식 계산·저장 -> 목표값 반환
```

1. **상태 정의**: 부분 문제의 답을 결정하는 최소 변수만 상태에 포함함
2. **상태값 정의**: 각 상태에서 구할 최적값·경우의 수·가능 여부를 정함
3. **점화식 수립**: 현재 상태값을 계산할 하위 상태와 결합 연산을 식으로 정의함
4. **기저 상태 설정**: 점화식 없이 답이 정해진 시작 상태를 확정함
5. **계산·검증**: 목표값을 구해 작은 입력의 완전 탐색 결과와 대조함

> 요약: 하향식은 필요한 상태를 재귀로 확정하고 상향식은 기저 상태부터 의존 순서대로 상태값을 저장함.

## Ⅵ. 실무 사례

1. 문자열 유사도 서비스는 공간 최적화를 위해 이전 행과 현재 행만 유지함. 전체 DP 테이블과 거리값을 대조하고 최대 메모리 사용량을 확인함
2. 빌드 작업 스케줄러는 하향식 메모이제이션으로 완료 시간을 계산하고 계산 상태 수를 확인함

## Ⅶ. 결론

- 동적 계획법은 중복 부분 문제와 최적 부분 구조가 성립할 때 적용하고 상태·점화식·기저 상태를 작은 입력 결과와 대조해야 함
