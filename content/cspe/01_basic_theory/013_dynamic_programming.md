## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 큰 문제를 겹치는 부분 문제로 분할하고, 결과를 메모이제이션하여 중복 계산을 제거하는 최적화 기법임 |
| **배경/필요성** | 분할 정복에서 동일 부분 문제가 반복 계산되면 지수 시간이 소요되며, 다항 시간으로 줄이는 기법이 필요함 |
| **출제 의도** | DP의 두 조건(최적 부분 구조·중복 부분 문제)과 Top-Down/Bottom-Up 구현을 설명할 수 있는지 평가함 |

## Ⅱ. 구성요소
```
+----------+     +----------+     +----------+
| 최적부분  | --> | 중복부분  | --> | 메모이   |
| 구조     |     | 문제     |     | 제이션   |
+----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| 최적 부분 구조 | 전체 최적해가 부분 문제의 최적해 조합으로 구성되는 성질임 | 최단 경로의 부분 경로도 최단 |
| 중복 부분 문제 | 동일한 부분 문제가 재귀 트리에서 여러 번 반복 등장함 | 피보나치 fib(3)이 여러 번 호출 |
| 메모이제이션 | 계산된 부분 문제 결과를 테이블에 저장하여 재사용함 | 계산 결과 메모장에 기록 |

> 요약: 최적 부분 구조 + 중복 부분 문제를 만족하면 메모이제이션으로 다항 시간에 해결함.

## Ⅲ. 절차
```
+------------+     +------------+
| 점화식정의  | --> | 기저조건   |
| (상태전이)  |     | 설정       |
+------------+     +------------+
                        |
+------------+     +----+-------+
| 최적해추출  | <-- | 테이블채움 |
| (역추적)   |     | (Bottom-Up)|
+------------+     +------------+
```

1. 점화식 정의: 문제의 상태를 정의하고 상태 전이 관계식을 수립함(예: `dp[i] = dp[i-1] + dp[i-2]`)
2. 기저 조건 설정: 재귀의 종료 조건에 해당하는 초기값을 설정함(예: `dp[0]=0, dp[1]=1`)
3. 테이블 채움: Bottom-Up으로 작은 부분 문제부터 순서대로 테이블을 채움
4. 최적해 추출: 테이블의 최종 값에서 답을 읽고, 필요 시 역추적으로 경로를 복원함

> 요약: 점화식 → 기저 조건 → 테이블 채움 → 최적해 추출로 DP를 수행함.

## Ⅳ. 문제점
- 상태 공간 폭발: 상태 변수가 많으면 테이블 크기가 기하급수적으로 증가함
- 점화식 도출 난이도: 문제마다 상태 정의·전이식이 다르며, 패턴 인식이 어려움
- 메모리 사용: 전체 테이블 저장에 O(n²) 이상의 메모리가 필요한 경우가 많음

## Ⅴ. 개선방안
- (단기) 공간 최적화: 이전 행만 저장하는 롤링 배열로 메모리를 O(n)으로 절감함
- (중기) 비트마스크 DP: 상태를 비트마스크로 압축하여 조합 문제의 상태 공간을 줄임
- (장기) 분할-DP 최적화: Knuth·Divide-and-Conquer 최적화로 O(n³) → O(n² log n)으로 개선함

## Ⅵ. 전망
- 강화 학습(Value Iteration)·바이오인포매틱스(시퀀스 정렬)·경제학(최적 제어) 등에서 DP 원리가 핵심이며, 대규모 상태 공간의 근사 DP(ADP)가 실용적 대안으로 확산될 전망임
