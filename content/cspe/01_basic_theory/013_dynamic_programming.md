## Ⅰ. 개요
- **정의**: 중복 부분 문제의 결과를 저장하여 재계산을 제거하는 최적화 기법
- **배경/필요성**: 최적 부분 구조를 가진 문제에서 재귀 호출이 동일 하위 문제를 반복 계산하면 지수 시간이 소요되므로, 한 번 계산한 결과를 기억해 다항 시간으로 줄일 수단이 필요함
- **비유**: 계산기에 중간 결과를 메모해 두고, 같은 계산이 나오면 다시 누르지 않고 메모를 보는 것과 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 두 가지 적용 조건 구분 능력 | 최적 부분 구조 + 중복 부분 문제 동시 충족 | 탐욕(015 참조)·분할 정복(014 참조)과 적용 조건 차이를 혼동하지 않을 것 |

> 요약: 중복 계산 제거를 통해 지수 시간 문제를 다항 시간으로 전환하는 알고리즘 설계 기법임

## Ⅱ. 구성요소
```text
+---------------------------+
|   원본 문제 (Problem)     |
+---------------------------+
      |           |
      v           v
+----------+ +----------+
| 부분문제 | | 부분문제 |  <-- 중복 발생 구간
+----------+ +----------+
      |           |
      v           v
+---------------------------+
|  메모 테이블 (DP Table)   |
+---------------------------+
      |
      v
+---------------------------+
|   최적해 (Optimal Sol.)   |
+---------------------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 최적 부분 구조 | 전체 최적해가 부분 문제의 최적해로 구성되는 성질 | 전체 최단 경로가 부분 경로의 최단으로 이루어지는 것과 같음 |
| 중복 부분 문제 | 동일 하위 문제가 여러 번 호출되는 구조 | 피보나치에서 `fib(3)`이 여러 경로로 반복 호출되는 현상 |
| 메모 테이블 | 계산된 부분 문제 결과를 저장하는 배열 또는 해시맵 | 시험 중 풀이 과정을 연습장에 적어 두는 것과 유사함 |
| 점화식 | 부분 문제 간 관계를 수학적으로 정의한 재귀 관계식 | `dp[i] = dp[i-1] + dp[i-2]` 같은 규칙표 |

> 요약: 최적 부분 구조와 중복 부분 문제를 점화식으로 표현하고, 메모 테이블에 저장하여 중복 계산을 제거함

## Ⅲ. 절차
```text
문제 분석 --> 점화식 정의 --> 구현 방식 선택 --> 최적해 추출
```
- 1단계: **문제 분석** — 최적 부분 구조·중복 부분 문제 두 조건을 만족하는지 확인함
- 2단계: **점화식 정의** — 부분 문제 간 재귀 관계와 기저 조건(base case)을 수식으로 정의함
- 3단계: **구현 방식 선택** — Top-Down(재귀 + 메모이제이션) 또는 Bottom-Up(반복문 + 타벨레이션) 중 선택함
  - Top-Down: 필요한 부분 문제만 계산하므로 상태 공간이 희소할 때 유리함
  - Bottom-Up: 재귀 호출 오버헤드가 없고 스택 오버플로 위험이 없음
- 4단계: **최적해 추출** — 테이블의 최종 셀에서 답을 읽거나, 역추적으로 실제 해를 복원함

> 요약: 조건 확인 → 점화식 → 메모 방식 선택 → 해 추출의 4단계로 진행함

## Ⅳ. 문제점
- **상태 공간 폭발**: 차원이 늘어나면 테이블 크기가 지수적으로 증가하여 메모리가 부족해짐
- **점화식 도출 난이도**: 문제마다 고유한 재귀 관계를 찾아야 하므로 설계 자체가 어려움
- **역추적 복잡성**: 최적값만 저장하면 실제 해 경로를 복원하기 위해 별도 추적 구조가 필요함

> 요약: 메모리 폭발, 점화식 설계 난이도, 해 복원 부담이 주요 한계임

## Ⅴ. 개선방안
1. 단기: **공간 최적화** — 슬라이딩 윈도우 기법으로 이전 행만 유지하여 $O(n)$ 메모리로 축소함 (예: 피보나치에서 변수 2개만 사용)
2. 중기: **패턴 라이브러리 구축** — LCS, 배낭, 최장 증가 부분 수열 등 대표 점화식 유형을 분류·축적하여 설계 시간을 단축함
3. 장기: **역추적 자동화** — 테이블 구성 시 선택 경로를 함께 기록하는 프레임워크를 적용하여 해 복원 로직을 자동 생성함

> 요약: 공간 절감, 점화식 패턴화, 역추적 자동화로 DP의 실용성을 높일 수 있음

## Ⅵ. 전망
- 발전 방향: 근사 DP, 강화학습의 가치 함수 추정 등 확률적·연속 상태 공간으로 확장이 진행 중임
- 기술사적 판단: 알고리즘 설계의 핵심 패러다임으로, 분할 정복(014 참조)·탐욕(015 참조)과 함께 문제 유형별 선택 기준을 숙지해야 함
- 기술사 제언: 점화식 도출 → 시간·공간 복잡도 분석 → 개선 기법 적용의 3단 논술 구조로 답안을 구성할 것을 권장함
