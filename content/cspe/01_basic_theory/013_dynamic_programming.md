## Ⅰ. 개요
- **정의**: 중복 부분 문제의 결과를 저장하여 재계산을 방지하는 최적화 기법
- **배경/필요성**: 재귀적 풀이에서 동일 부분 문제가 반복 계산되어 지수 시간이 소요되므로, 결과를 캐싱하여 다항 시간으로 줄여야 함
- **비유**: 같은 계산을 반복하는 대신 메모장에 답을 적어두고 꺼내 쓰는 것

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| DP 적용 조건과 Top-down/Bottom-up 비교 | 최적 부분 구조 + 중복 부분 문제 | 분할 정복(014)과의 차이: 부분 문제 중복 유무 |

> 요약: 최적 부분 구조와 중복 부분 문제를 만족할 때 재계산을 제거하여 시간 복잡도를 줄이는 기법임

## Ⅱ. 구성요소
```text
  +---------------------+
  | Dynamic Programming  |
  +---------+-----------+
            |
    +-------+-------+
    |               |
    v               v
  Top-down        Bottom-up
  (메모이제이션)  (타뷸레이션)
  재귀+캐시      반복+테이블
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 최적 부분 구조 | 큰 문제의 최적해가 부분 문제의 최적해로 구성됨 | 최단 경로의 중간 경유지까지도 최단인 성질 |
| 중복 부분 문제 | 동일 부분 문제가 여러 번 호출됨 | 피보나치 `fib(3)`이 트리의 여러 가지에서 반복 등장함 |
| 점화식 | 부분 문제 간 관계를 수식으로 정의함 | $dp[i] = dp[i-1] + dp[i-2]$ 같은 재귀 관계식 |

> 요약: 최적 부분 구조와 중복 부분 문제가 DP 적용의 두 전제 조건이며, 점화식이 풀이의 핵심임

## Ⅲ. 절차
```text
  문제 분석        점화식 설계      테이블 구성       결과 추출
  (구조 파악)     (관계 정의)     (값 채움)        (최적해 역추적)
   |               |               |               |
   +---부분문제--->+---수식화------>+---순서대로---->+
  부분 구조 확인  dp[i]=f(dp[..]) base case부터    dp[n] 반환
```
- 1단계: 문제가 최적 부분 구조와 중복 부분 문제를 만족하는지 분석함
- 2단계: 부분 문제 간 관계를 점화식으로 정의하고 기저 조건(base case)을 설정함
- 3단계: Top-down은 재귀+메모 배열, Bottom-up은 기저부터 반복으로 테이블을 채움
- 4단계: 테이블의 최종 값을 반환하거나, 역추적으로 최적해 경로를 복원함

> 요약: 문제 분석 후 점화식을 설계하고 테이블을 채워 최적해를 구하는 4단계 절차임

## Ⅳ. 문제점
- 상태 공간 폭발: 차원이 늘어나면 테이블 크기가 기하급수적으로 증가하여 메모리가 부족해짐
- 점화식 설계 난이도: 문제마다 고유한 점화식을 도출해야 하므로 일반화된 설계 절차가 없음
- 역추적 복잡성: 최적 값만으로는 해의 구성 경로를 알 수 없어 별도 역추적 로직이 필요함

> 요약: 상태 공간 크기, 점화식 도출 어려움, 역추적 부담이 주요 한계임

## Ⅴ. 개선방안
1. 단기: 슬라이딩 윈도우·롤링 배열로 이전 행만 유지하여 메모리 사용량을 O(n)으로 줄임
2. 중기: 문제 유형별 점화식 패턴(배낭, LCS, LIS 등)을 분류하여 설계 시간을 단축함
3. 장기: 상태 압축 DP(비트마스크)·Knuth 최적화 등 고급 기법으로 고차원 문제에 대응함

> 요약: 메모리 최적화, 패턴 분류, 고급 최적화 기법으로 한계를 극복함

## Ⅵ. 전망
- 발전 방향: 강화학습의 가치 함수 근사, 조합 최적화 문제 해결에 DP 원리가 지속 활용됨
- 기술사적 판단: 점화식 설계 능력이 알고리즘 문제 해결의 핵심 역량이며, 분할 정복(014)과의 차이를 명확히 구분해야 함
- 기술사 제언: 문제 유형별 점화식 패턴을 체계화하고, 메모리 최적화 기법을 함께 숙지할 것을 권고함
