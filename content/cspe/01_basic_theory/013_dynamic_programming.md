## 미리 알고가기

- 중복 부분 문제: 같은 부분 문제가 여러 경로에서 반복 등장하는 성질임
- 최적 부분 구조: 작은 문제의 최적해로 큰 문제의 최적해를 만들 수 있는 성질임
- 상태(State): 부분 문제를 구분하는 변수 조합임
- 점화식: 현재 상태값을 이전 상태값으로 계산하는 관계식임
- 메모이제이션: 계산한 상태값을 저장해 재귀 호출에서 재사용하는 방식임
- 타뷸레이션: 작은 상태부터 표를 채워 목표 상태까지 계산하는 방식임

## 작성 근거(검토용)

- **개요 구성**: DP의 핵심은 상태 저장과 재사용이므로 중복 부분 문제와 상태 수 통제를 정의에 반영함
- **Ⅱ. 특징 선정**: 중복 제거, 상태 폭발, 점화식, 초기값은 DP 성공과 실패를 가르는 직접 요인임
- **Ⅲ 비교축 선정**: 하향식과 상향식은 상태 계산 방식·계산 범위·실패 조건·적용 사례가 달라 선택 기준을 표로 분리함
- **Ⅳ 구조 선정**: 상태·점화식·기저 사례·저장소·계산 순서는 DP 구현의 최소 구성이라 남김
- 상태 공간 축소와 점화식 검증은 DP 오답·메모리 초과를 방지하는 핵심 관리점임

## Ⅰ. 개요

- **정의/개념**: 동적 계획법은 중복 부분 문제를 상태로 정의하고 계산한 상태값을 저장해 재사용하는 알고리즘 설계 기법임
- **배경/필요성**: 중복 상태 계산의 시간을 줄이기 위해 상태 수와 전이 비용으로 계산량을 통제하는 방식이 필요함

## Ⅱ. 특징

- 같은 상태를 한 번만 계산해 중복 계산 비용을 줄임
- 상태 변수와 범위가 시간·공간 복잡도를 함께 결정함
- 점화식은 상태 간 의존 관계와 계산 순서를 고정함
- 초기값이 틀리면 모든 후속 상태값이 함께 왜곡됨

## Ⅲ. 종류 및 비교

| 판단 기준 | 하향식 ($Top-down$) | 상향식 ($Bottom-up$) |
|:---|:---|:---|
| 상태 계산 | 목표 상태에서 필요한 하위 상태를 재귀 호출하고 메모이제이션 | 의존 순서에 따라 작은 상태부터 타뷸레이션 |
| 계산 범위 | 도달 상태만 계산 가능 | 정의한 상태 공간을 순서대로 계산 |
| 실패 조건 | 재귀 깊이 초과·호출 비용 증가 | 사용하지 않는 상태까지 계산 |
| 대표 적용 사례 | 게임 상태·희소 상태 탐색 | 배낭 최적화·문자열 편집 거리 계산 |

> 요약: 필요한 상태만 재귀로 계산하면 하향식, 정의한 상태 공간을 의존 순서대로 계산하면 상향식을 선택함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 상태 | 부분 문제를 유일하게 식별하고 저장소 인덱스가 됨 |
| 점화식 | 현재 상태값을 이전 상태값 조합으로 계산함 |
| 기저 사례 | 더 이상 나뉘지 않는 시작 상태의 확정값임 |
| 저장소 | 계산된 상태값을 캐시나 테이블로 보관함 |
| 계산 순서 | 참조 상태가 먼저 계산되도록 순서를 정함 |

> 요약: 상태 범위, 점화식의 참조 순서, 초기값, 저장 위치가 서로 맞아야 이미 계산한 값을 재사용할 수 있음.

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 상태 정의    | --> | 점화식 수립   | --> | 초기값 설정   | --> | 상태값 계산  |
| (부분 문제)  |     | (전이 관계)  |     | (경계 조건)  |     | (저장·재사용)|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **상태 정의**: 답을 구하는 데 필요한 최소 변수를 정함
2. **점화식 수립**: 현재 상태를 이전 상태 조합으로 표현함
3. **초기값 설정**: 경계 상태의 확정값을 먼저 저장함
4. **상태값 계산**: 하향식 또는 상향식으로 저장소를 채우고 목표값을 읽음

> 요약: 상태가 무엇을 뜻하는지 먼저 정하고 점화식이 저장된 이전 상태만 참조해야 중복 계산을 줄일 수 있음.

## Ⅵ. 실무 사례

1. 문서 유사도 계산의 편집 거리는 상태 공간이 커질 수 있으므로 필요한 행만 남기는 슬라이딩 윈도우를 적용하고 최대 메모리 사용량이 허용 한도 이내인지 확인함
2. 일정 최적화의 점화식은 경계 조건이 틀리기 쉬우므로 작은 입력의 완전 탐색 결과와 대조하고 계산 상태 수·캐시 적중률로 검증함

## Ⅶ. 결론

- 동적 계획법은 중복 부분 문제를 상태 수와 전이 비용으로 통제하는 기법이므로 상태 정의·점화식·저장 방식을 함께 검증해야 함
