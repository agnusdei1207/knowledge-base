## Ⅰ. 개요
- 큰 문제를 작은 하위 문제로 나누어 풀고, 결과를 저장하여 재사용하는 기법임.
- 중복 계산을 방지하여 실행 속도를 비약적으로 향상시킴.
- [표] 출제 의도: 최적 부분 구조 파악 및 메모이제이션 설계 역량 검증.

## Ⅱ. 구성요소
- ASCII 구조도
  Problem -> [ Sub1 ] + [ Sub2 ] -> [ Memo Table ]

| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| Memoization | 계산된 결과를 배열 등에 저장함 | 계산 결과 받아적기 |
| Optimal Substructure | 부분 문제의 최적해가 전체의 최적해임 | 조립식 가구 |
| Overlapping Sub | 동일한 하위 문제가 반복해서 나타남 | 반복 학습 |

> 요약: 기억하며 풀기(Memoization)를 통해 중복을 제거함.

## Ⅲ. 절차
- ASCII 흐름도
  Define Subprob -> Relation(Recurrence) -> Base Case -> Solve

1. 문제를 하위 문제들의 점화식 형태로 정의함.
2. 결과를 저장할 자료구조(Table)를 초기화함.
3. Top-down(재귀+메모) 또는 Bottom-up(반복문) 방식으로 계산함.
4. 저장된 값을 참조하여 최종 해답을 도출함.

> 요약: 작은 문제부터 차근차근 해결하여 결과를 축적함.

## Ⅳ. 문제점
- 많은 하위 문제의 결과를 저장하기 위해 메모리 사용량이 급증함.
- 점화식 도출 자체가 매우 까다로운 경우가 많음.

## Ⅴ. 개선방안
- 단기: 공간 최적화(Sliding Window)를 통해 이전 항만 유지함.
- 중기: 재귀 깊이 제한을 위해 Bottom-up 방식 적용 권장함.
- 장기: 분할 정복과 차이점을 명확히 인지하고 적용 적합성 판단함.

## Ⅵ. 전망
- 강화학습의 Bellman Equation과 결합하여 동적 환경에서의 의사결정 최적화를 수행하는 '심층 동적 프로그래밍'이 지능형 자율 에이전트의 CSF로 작용할 것임.
- 고성능 컴퓨팅(HPC) 환경에서 유전자 서열 분석(Smith-Waterman 등) 속도를 극대화하기 위해 FPGA 가속기를 이용한 DP 연산 하드웨어화가 보편화될 전망임.
- 함수형 언어의 이점을 살려 하위 문제의 독립성을 보장하고 병렬 처리를 자동화하는 선언적 DP 프레임워크가 소프트웨어 생산성 향상의 핵심이 될 것임.
