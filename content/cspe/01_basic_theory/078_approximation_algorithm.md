## Ⅰ. 개요
- 정의: NP-완전 문제처럼 최적해를 찾기 어려운 경우, 유사한 해를 구하는 방법임.
- 배경: 실생활의 복잡한 최적화 문제를 현실적인 시간 내에 해결하기 위해 필요함.
- 출제 의도:
| 분류 | 상세 |
| --- | --- |
| 핵심요소 | 근사 비율(Ratio), 다항 시간, 휴리스틱 |
| 주요특징 | 정밀도와 속도의 트레이드오프, 성능 보장 범위 존재 |

## Ⅱ. 구성요소
- ASCII 구조도
 [Optimum Sol.] <--- (Gap) ---> [Approximate Sol.]
    (Unknown)                   (Calculated)
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 근사 비율 | 최적해와 근사해 사이의 최대 오차 비율 | 오차 범위 |
| 탐욕법(Greedy) | 매 순간 최선의 선택을 하여 해를 구성함 | 눈앞의 이익 |
| 하한값(Lower Bound) | 최적해가 가질 수 있는 최소 수치 | 마지노선 |
> 요약: 다항 시간 내에 최적해에 근접한 결과를 보장하는 알고리즘임.

## Ⅲ. 절차
- ASCII 흐름도
[문제 분석] -> [근사 전략 수립] -> [다항 시간 수행] -> [품질 검증]
- 4단계 설명
1. 문제 환원: 해결하고자 하는 NP-완전 문제를 수치화함.
2. 알고리즘 설계: Greedy나 선형 계획법(LP) 완화를 사용함.
3. 해 산출: 설계된 로직에 따라 실행 가능한 해를 빠르게 구함.
4. 성능 증명: 결과값이 최적해의 일정 배수(k) 이내임을 수학적으로 보임.
> 요약: 속도를 위해 완벽함을 포기하되, 품질의 하한선을 지키는 과정임.

## Ⅳ. 문제점
- 특정 문제에서는 근사 비율을 낮추는 것 자체가 다시 NP-난제가 됨.

## Ⅴ. 개선방안
- 단기: PTAS(Polynomial-time Approx. Scheme)를 활용해 정밀도를 조정함.
- 중기: 유전 알고리즘 등 메타 휴리스틱을 결합하여 해의 품질을 높임.
- 장기: 문제의 특성을 깊게 파악하여 상수 근사 비율이 낮은 모델을 개발함.

## Ⅵ. 전망
- 물류 경로 최적화, 네트워크 설계 등 대규모 자원 배분 문제에 필수적임.
