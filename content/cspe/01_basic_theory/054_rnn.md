## Ⅰ. 개요
- **정의**: 은닉 상태를 순환적으로 재입력하여 시퀀스 데이터의 시간적 의존성을 학습하는 신경망
- **배경/필요성**: 텍스트·음성 등 길이 가변·순서 의존적 데이터를 고정 길이 입력 모델로 처리 불가
- **비유**: 이전 장면의 기억을 유지하며 영화를 시청하는 관객의 이해 과정

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 순환 구조 원리 | h_t = f(W_h·h_{t-1} + W_x·x_t) 상태 전이식 | BPTT 시 기울기 소실/폭발 메커니즘 |
| LSTM 구조 이해 | Forget·Input·Output 3-Gate + Cell State | GRU(2-Gate)와의 구조적 차이 혼동 주의 |

> 요약: RNN은 은닉 상태 순환으로 시간 의존성을 학습하며, LSTM은 게이트로 장기 기억을 보존하는 모델임

## Ⅱ. 구성요소
```text
+---------------+       +------------------+       +------------------+
| Input x_t     |       | Recurrent Cell   |       | Output y_t       |
| (Time step t) | ----> | (h_t = f(h,x))   | ----> | + h_t -> (t+1)   |
+---------------+       +------------------+       +------------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 은닉 상태 h_t | 과거 정보를 압축하여 다음 타임스텝에 전달하는 벡터 | 메모 장부 |
| BPTT | 시간축으로 펼친 후 각 타임스텝의 기울기를 역전파하는 학습 방법 | 과거 되짚기 |
| 게이트(LSTM) | Forget·Input·Output 게이트로 셀 상태의 기억·망각 비율 제어 | 정보 수문장 |

> 요약: 은닉 상태·BPTT·게이트 메커니즘이 RNN/LSTM의 핵심 구성요소임

## Ⅲ. 절차
```text
+---------------+       +---------------+       +---------------+       +---------------+
| Receive x_t   |       | Gate Control  |       | State Update  |       | Pass h_t      |
| + h_(t-1)     | ----> | (F/I/O gate)  | ----> | (Cell + h_t)  | ----> | to (t+1)      |
+---------------+       +---------------+       +---------------+       +---------------+
```

1. **입력 수신** — 현재 타임스텝 입력 x_t와 이전 은닉 상태 h_(t-1)을 수신
2. **게이트 연산** — Forget 게이트(삭제 비율), Input 게이트(저장 비율), Output 게이트(출력 비율) 산출
3. **상태 갱신** — 셀 상태 C_t를 망각·입력 비율로 갱신하고 tanh 적용 후 은닉 상태 h_t 생성
4. **순환 전달** — 갱신된 h_t를 출력으로 내보내고 동시에 다음 타임스텝(t+1)의 입력으로 전달

> 요약: 입력 수신 -> 게이트 제어 -> 상태 갱신 -> 순환 전달의 반복으로 시퀀스를 처리함

## Ⅳ. 문제점
- 기울기 소실: BPTT 시 시퀀스 길이에 비례하여 기울기가 지수적으로 감쇠(∏W_h 곱셈 체인)
- 장기 의존성 한계: 기울기 소실로 100+ 타임스텝 이전 정보의 영향력이 사실상 소멸
- 순차 연산 병목: h_t 계산이 h_(t-1)에 의존하여 GPU 병렬 연산 불가, 학습 처리량 제한

> 요약: 기울기 소실 -> 장기 기억 상실 -> 순차 연산 병목이 RNN의 3대 한계임

## Ⅴ. 개선방안
1. 단기: Gradient Clipping(임계값 제한)으로 기울기 폭발 방지, ReLU 활성화로 소실 완화
2. 중기: LSTM(3-Gate + Cell State) 또는 GRU(2-Gate)로 장기 의존성 보존 능력 확보
3. 장기: 어텐션 메커니즘 기반 트랜스포머로 전환, 순차 의존성 제거 및 완전 병렬 처리

- 순차 연산 병목: h_t -> h_(t+1) 직렬 체인 -> Mamba/RWKV 등 선형 순환 모델로 병렬화 (지표: 처리 토큰/초)

> 요약: 클리핑 -> LSTM/GRU -> 트랜스포머·선형 순환 모델로 단계적 전환함

## Ⅵ. 전망
- 향후 발전 방향: Mamba(선택적 상태 공간), RWKV(선형 어텐션) 등 병렬 가능한 순환 구조 재부상
- 기술사적 판단: 순수 RNN/LSTM은 트랜스포머에 주류를 내주었으나, 메모리·연산 효율이 중요한 엣지·실시간 환경에서 재조명
- 기술사 제언: 시퀀스 태스크 설계 시 트랜스포머(정확도) vs 선형 순환(효율) 간 트레이드오프 분석 선행 필요
