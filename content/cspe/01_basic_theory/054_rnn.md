## 미리 알고가기

- 시퀀스 데이터: 텍스트, 음성, 센서값처럼 순서와 시간 흐름이 의미를 갖는 데이터임
- 은닉 상태 $h_t$: 이전 시점 정보를 압축해 현재 시점 계산에 전달하는 내부 상태임
- 셀 상태 $c_t$: LSTM에서 망각 게이트로 유지 비율을 조절하며 장기 정보를 전달하는 기억 경로임
- BPTT: 순환 구조를 시간축으로 펼쳐 각 시점의 오차를 역전파하는 학습 방식임
- 장기 의존성: 먼 과거 정보가 이후 시점의 예측에 필요하지만 전달이 약해지는 문제임
- 게이트: 입력·망각·출력 또는 갱신·리셋 비율을 학습해 정보 흐름을 제어하는 장치임

## 작성 근거(검토용)

- 개요는 RNN과 LSTM·GRU를 한 문장에 묶어 키워드 제목의 복합성을 반영함
- 특징은 가중치 공유, 은닉 상태, BPTT 한계, 게이트 보완으로 논리를 전개함
- 비교표는 기억 구조와 상태 갱신 연산을 중심으로 세 모델의 선택 기준을 드러냄
- 구성요소와 도식은 $x_t$, $h_t$, $y_t$를 배치해 현재 입력과 다음 시점의 상태 전달 관계를 보여줌
- 시퀀스 길이와 순차 연산 비용은 RNN 계열 선택을 바꾸는 대표 조건임

## Ⅰ. 개요

- **정의/개념**: RNN은 이전 은닉 상태를 현재 입력과 함께 처리해 순서 정보를 반영하며, LSTM·GRU는 게이트로 기억 유지와 삭제를 제어하는 시퀀스 모델임
- **배경/필요성**: 자연어·음성·시계열의 앞뒤 맥락을 반영하기 위해 시간 의존성을 저장하는 구조가 필요함

## Ⅱ. 특징

- 같은 가중치를 모든 시점에 공유해 길이가 다른 시퀀스도 동일 구조로 처리함
- 은닉 상태가 이전 정보를 현재 계산에 연결해 문맥과 시간 흐름을 모델 내부에 보존함
- BPTT로 시간축 오차를 학습하지만 긴 시퀀스에서는 기울기 소실·폭주가 발생함
- LSTM과 GRU는 게이트로 중요한 정보만 남겨 바닐라 RNN의 장기 의존성 한계를 줄임

## Ⅲ. 종류 및 비교

| 판단 기준 | RNN | LSTM | GRU |
|:---|:---|:---|:---|
| 기억 구조 | 은닉 상태만 사용 | 셀 상태와 3개 게이트 | 은닉 상태와 2개 게이트 |
| 장기 정보 | 반복 전파 중 기울기 소실 가능 | 셀 상태와 게이트로 정보 보존 | 두 게이트로 은닉 상태 보존 |
| 상태 갱신 연산 | 은닉 상태 후보를 한 번 계산 | 입력·망각·출력 게이트와 셀 후보를 계산 | 갱신·리셋 게이트와 은닉 상태 후보를 계산 |
| 적용 조건 | 짧은 의존 관계를 갖는 시퀀스 | 장기 의존성과 셀 상태 제어가 필요한 시퀀스 | 셀 상태를 분리하지 않고 장기 정보를 처리할 시퀀스 |

> 요약: 기본 RNN은 은닉 상태만 갱신하고, LSTM은 세 게이트와 셀 상태를 사용하며, GRU는 두 게이트로 상태 갱신 구조를 줄임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 입력 $x_t$ | 시점 $t$의 단어, 음성 프레임, 센서값처럼 현재 관측값을 제공함 |
| 은닉 상태 $h_t$ | 과거와 현재 입력을 합친 요약값이며 다음 시점으로 전달됨 |
| 게이트(LSTM·GRU) | LSTM은 입력·망각·출력, GRU는 갱신·리셋 비율을 학습해 기억 흐름을 제어함 |
| 출력 $y_t$ | 현재 시점 예측값이거나 전체 시퀀스의 최종 판단값임 |
| 손실 함수 | 시점별 또는 전체 시퀀스 오차를 계산해 BPTT의 기준이 됨 |

```text
+-------+      +----------+      +---------+      +-------+
| x_t   | ---> | 순환 셀  | ---> | h_t     | ---> | y_t   |
+-------+      +----------+      +---------+      +-------+
                   ^                |
                   |                v
                +---------+      다음 시점
                | h_{t-1} |
                +---------+
```

> 요약: RNN 계열은 이전 은닉 상태를 현재 입력과 결합해 시간 정보를 다음 시점으로 전달함.

## Ⅵ. 실무 사례

1. 서버 장애 로그 예측은 LSTM·GRU를 적용하고 검증 손실·기울기 노름으로 검증함
2. 장기 로그 시퀀스 분류는 Transformer와 비교하고 Macro-F1·p95 추론 지연으로 구조를 선택함

## Ⅶ. 결론

- RNN 계열은 순서 의존성을 은닉 상태로 전달하는 모델이며, 시퀀스 길이와 장기 기억 요구가 구조 선택 기준임
