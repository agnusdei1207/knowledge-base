# 054. 순환 신경망 RNN·LSTM·GRU (Recurrent Neural Network) [출제: 121회]

## 1. 개요

- **정의/개념**: 입력과 출력을 시퀀스(Sequence) 단위로 처리하며, 이전 시점의 은닉 상태(Hidden State)를 다음 시점의 입력으로 다시 사용하는 재귀적 구조의 신경망임
- **배경/필요성**: 자연어, 음성, 시계열 데이터와 같이 데이터 간의 순서와 문맥(Context)이 중요한 데이터에서 과거의 정보를 현재의 결정에 반영하기 위해 필수적임

## 2. 특징 및 비교

| 판단 기준 | Vanilla RNN | LSTM (Long Short-Term Memory) | GRU (Gated Recurrent Unit) |
|:---|:---|:---|:---|
| **핵심 구조** | 단순 순환 피드백 | 3개 게이트(Forget, Input, Output) | 2개 게이트(Update, Reset) |
| **메모리 유지** | 단기 기억 중심 | 장기 의존성(Long-term Dependency) 해결 | LSTM과 유사한 성능, 효율성 개선 |
| **장점** | 구조 단순, 계산량 적음 | 기울기 소실 방지 탁월 | 파라미터 적음, 학습 속도 빠름 |
| **단점** | 기울기 소실(Vanishing Gradient) | 구조 복잡, 계산 비용 높음 | 데이터에 따라 LSTM보다 성능 저조 |

> 요약: Vanilla RNN의 장기 기억 상실 문제를 해결하기 위해 게이트 구조를 도입한 LSTM과 이를 간소화한 GRU가 주로 사용됨

## 3. 구성요소/구조

- **구성요소**:
  - **Hidden State ($h_t$)**: 현재 시점의 입력과 이전 시점의 상태를 조합하여 요약된 과거 정보를 담고 있는 벡터임
  - **Cell State ($C_t$)**: (LSTM) 컨베이어 벨트 역할로, 게이트를 통해 정보를 제어하며 긴 시간 동안 정보를 전달함
  - **Gates**: 시그모이드 함수를 이용해 어떤 정보를 버리고($Forget$), 저장하고($Input$), 내보낼지($Output$) 결정함
  - **BPTT (Backpropagation Through Time)**: 시점(Time Step)을 거슬러 올라가며 가중치를 업데이트하는 역전파 알고리즘임

- **원리/구조도 (LSTM 기준)**:
```text
[ 이전 Cell State C_t-1 ] ------------ (+) ------------> [ 현재 Cell State C_t ]
                           |            |           |
                           |    (Forget Gate) (Input Gate)  |
                           v            v           v       |
[ 이전 Hidden h_t-1 ] -> [ LSTM Cell ] ----------------------> [ 현재 Hidden h_t ]
          |                ^
[ 현재 입력 x_t ] ---------|
```

## 4. 문제점 및 개선방안

1. **[기울기 소실/폭주]**: 시퀀스가 길어질수록 역전파 시 가중치가 0으로 수렴하거나 무한히 커짐
   - **개선방안**: LSTM/GRU의 게이트 구조를 활용하거나, Gradient Clipping 기법을 적용함 (확인: Gradient Norm)
2. **[병렬 처리 한계]**: 데이터가 순차적으로 처리되어야 하므로 GPU를 활용한 대규모 병렬 연산이 어려움
   - **개선방안**: 시퀀스 전체를 한 번에 처리하는 어텐션(Attention) 기반의 Transformer 구조로 전환함 (확인: 학습 시간)
3. **[장기 의존성 한계]**: 게이트 구조가 있더라도 수천 시점 이전의 정보를 완벽히 보존하는 데는 한계가 있음
   - **개선방안**: 필요한 시점의 정보를 직접 참조하는 Attention 메커니즘을 결합함 (확인: BLEU Score)

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| **기계 번역 (Seq2Seq)** | 인코더-디코더 구조로 문장의 문맥을 파악해 번역 수행 | BLEU Score, METEOR |
| **주가/날씨 예측** | 과거 시계열 데이터를 학습하여 미래 수치를 회귀 분석 | RMSE, MAE (Mean Absolute Error) |
| **텍스트 감성 분석** | 문장 내 단어들의 순차적 의미를 파악해 긍정/부정 분류 | F1-Score, Precision/Recall |

> 요약: 실무에서는 시퀀스의 길이와 요구되는 정확도에 따라 RNN 변체와 Attention 기법을 조합하여 사용함

## 6. 결론

RNN 계열 알고리즘은 시퀀스 데이터 처리에 최적화된 구조로, 게이트 메커니즘을 통해 장기 의존성 문제를 극복하며 발전해 왔음. 비록 최근 전역 문맥 파악이 용이한 Transformer에 많은 자리를 내주었으나, 실시간 스트리밍 시계열 예측이나 연산 자원이 한정된 엣지 디바이스 환경에서는 여전히 GRU와 같은 경량 RNN 모델이 유효한 대안으로 활용되고 있음.
