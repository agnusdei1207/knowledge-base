## 미리 알고가기

- 시퀀스 데이터($Sequence$ $Data$): 데이터의 값이 독립적이지 않고 순서나 시간적 흐름에 의미가 있는 데이터(예: 텍스트, 주가)임
- 은닉 상태($Hidden$ $State$): 이전 시점의 입력 정보를 압축하여 가지고 있는 신경망의 내부 메모리임
- 장기 의존성($Long-term$ $Dependency$): 입력 시퀀스가 길어질 때, 앞부분의 정보가 뒷부분까지 충분히 전달되지 못하는 현상임
- 기울기 소실($Vanishing$ $Gradient$): 역전파 시 시점($Time-step$)을 거듭할수록 미분값이 0에 가까워져 학습이 중단되는 문제임

## Ⅰ. 개요

- **정의/개념**: 순환 신경망(RNN)은 뉴런의 출력이 다시 입력으로 들어가는 재귀적 구조를 통해 과거의 정보를 현재의 연산에 반영하는 신경망이며, 이를 보완한 LSTM과 GRU는 게이트($Gate$) 구조를 통해 중요한 정보를 오래 유지함
- **배경/필요성**: 자연어 처리, 음성 인식, 시계열 예측 등 데이터의 전후 맥락($Context$) 파악이 필수적인 분야에서 고정된 크기의 입력만을 처리하는 일반 신경망의 한계를 극복하기 위해 도입됨

## Ⅱ. 특징

- 동일한 가중치를 모든 시점($Time-step$)에서 공유하므로 입력 데이터의 길이에 상관없이 처리할 수 있으며, 이전 시점의 연산 결과가 다음 시점의 입력과 결합되어 누적된 기억을 형성함
- $BPTT$($Backpropagation$ $Through$ $Time$) 알고리즘을 사용하여 시간에 따른 역전파를 수행하며, 이를 통해 시퀀스 전체의 오차를 최소화하는 방향으로 학습함
- 연산이 순차적으로 이루어지므로 병렬화 처리가 어렵고, 바닐라 RNN의 경우 문장이 길어질수록 앞쪽 단어를 잊어버리는 치명적인 장기 의존성 문제를 가짐

## Ⅲ. 종류 및 비교

| 판단 기준 | RNN (Vanilla) | LSTM (Long Short-Term Memory) | GRU (Gated Recurrent Unit) |
|:---|:---|:---|:---|
| **내부 구조** | 매우 단순함 | 셀 상태($Cell$ $State$)와 3개 게이트 | 2개의 게이트 (Update, Reset) |
| **장기 기억** | 불가능 (정보 유실) | 탁월함 (정보 선별 유지) | 효율적임 (LSTM과 유사 성능) |
| **연산량** | 매우 낮음 | 높음 (복잡한 게이트 연산) | 낮음 (파라미터 수 감소) |
| **주요 특징** | 기울기 소실에 취약 | 장기 의존성 문제의 해결책 | LSTM의 경량화 버전 |

> 요약: RNN은 기본 모델, LSTM은 강력한 기억력, GRU는 효율성에 각각 강점이 있음.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 은닉 상태 ($h_t$) | 시점 $t$에서의 내부 기억으로, 다음 시점 $t+1$로 전달되는 핵심 정보임 |
| 망각 게이트 ($Forget$) | 과거의 정보 중 버릴 것과 남길 것을 결정하여 셀 상태를 관리함 |
| 입력 게이트 ($Input$) | 현재 시점의 새로운 정보를 얼마나 기억에 반영할지 결정함 |
| 출력 게이트 ($Output$) | 갱신된 기억 중 어떤 부분을 최종 출력으로 내보낼지 결정함 |

```text
[ RNN 연산 구조 ]
h_t = activation( W_hh * h_{t-1} + W_xh * x_t + b )
- h_{t-1}: 이전 시점의 은닉 상태
- x_t: 현재 시점의 입력 데이터
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 현재 입력 수립| --> | 이전 은닉 결합| --> | 게이트 제어/갱신| --> | 결과 출력/전달|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **상태 집계** — 현재 시점의 입력 데이터($x_t$)와 바로 전 시점의 은닉 상태($h_{t-1}$)를 가중치와 함께 연산하여 새로운 상태의 후보를 만듦
2. **정보 선별** — (LSTM 기준) 망각 게이트를 통해 불필요한 과거 기억을 삭제하고, 입력 게이트를 통해 현재의 유의미한 정보를 셀 상태($c_t$)에 추가함
3. **기억 업데이트** — 선별된 결과들을 조합하여 장기 기억 장치인 셀 상태를 갱신하고, 이를 바탕으로 최종적인 현재 시점의 은닉 상태($h_t$)를 결정함
4. **시퀀스 전파** — 결정된 은닉 상태를 다음 시점으로 넘겨주는 과정을 시퀀스의 끝까지 반복하며, 전체 흐름의 맥락이 담긴 최종 출력을 도출함

## Ⅵ. 실무 적용 및 유의점

1. 아주 긴 텍스트나 시계열 데이터를 처리할 때 RNN 계열은 여전히 정보 소실이나 연산 병목 문제를 겪으므로, 특정 시점의 정보에 가중치를 두는 '어텐션($Attention$)' 메커니즘을 결합하거나 '트랜스포머($Transformer$)' 구조로의 대체를 검토해야 함
2. 기울기 폭주($Exploding$ $Gradient$) 현상이 발생하여 학습이 불안정해질 경우, 기울기의 절댓값이 일정 수준을 넘지 못하도록 강제로 제한하는 '그래디언트 클리핑($Gradient$ $Clipping$)' 기술을 적용하여 학습의 안정성을 확보해야 함

## Ⅶ. 결론

- RNN 계열은 데이터의 시간적 질서와 인과관계를 이해하는 지능의 근간이며, 설계자는 장기 의존성 극복을 위한 게이트 구조와 병렬 연산 효율성 사이의 균형을 고려하여 최적의 시퀀스 모델을 구축해야 함
