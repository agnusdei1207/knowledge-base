## 미리 알고가기

- hidden state: 이전 시점 정보를 담는 내부 상태임
- 시퀀스 데이터: 시간 순서가 중요한 입력 데이터임
- gate: 정보 유지와 삭제를 제어하는 구조임

## Ⅰ. 개요

- **정의/개념**: RNN은 이전 시점의 상태를 현재 계산에 반영해 순차 데이터를 처리하는 신경망이며, LSTM과 GRU는 장기 의존성 문제를 개선한 게이트 기반 변형임
- **배경/필요성**: 텍스트, 음성, 로그, 시계열은 현재 값만으로 설명되지 않고 과거 맥락이 중요하므로 상태를 가진 모델이 필요함

## Ⅱ. 특징

- 시퀀스 길이에 따라 정보를 누적해 문맥을 반영함
- LSTM, GRU는 gate로 중요한 정보를 오래 유지함
- 시계열 예측과 자연어 처리의 기본 구조로 널리 사용됨
- 순차 계산 특성상 병렬화가 어렵고 긴 문맥에서는 한계가 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | RNN | LSTM | GRU |
|:---|:---|:---|:---|
| 구조 복잡도 | 낮음 | 높음 | 중간 |
| 장기 의존성 | 약함 | 강함 | 강함 |
| 파라미터 수 | 적음 | 많음 | 비교적 적음 |
| 대표 적용 | 짧은 시퀀스 | 장문맥 시계열 | 경량 시퀀스 모델 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 입력 $x_t$ | 현재 시점 데이터이며 순차 정보의 원천임 |
| 은닉 상태 $h_t$ | 과거 정보를 전달하고 문맥 유지 핵심임 |
| 셀 상태 $c_t$ | LSTM의 장기 기억 경로이며 장기 의존성 완화 장치임 |
| 게이트 | 입력/망각/출력 조절기이며 정보 흐름을 통제함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 시점입력 | --> | 상태갱신 | --> | 게이트제어 | --> | 출력생성 |
+----------+     +----------+     +----------+     +----------+
```

1. **시점입력**: 현재 입력과 이전 상태를 받음
2. **상태갱신**: 내부 가중치로 새로운 상태 후보를 계산함
3. **게이트제어**: 유지할 정보와 버릴 정보를 선택함
4. **출력생성**: 현재 시점 결과와 다음 상태를 전달함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 긴 시퀀스에서 gradient 소실이 발생해 초기 정보가 뒤로 갈수록 사라짐
   - 해결방안: LSTM/GRU, gradient clipping을 적용하고 long-horizon accuracy로 검증함
2. 문제: 병렬화가 어려워 학습이 느려 시점 의존성이 강함
   - 해결방안: truncated BPTT, Transformer 대체를 검토하고 tokens/sec로 검증함
3. 문제: 시퀀스 길이 변동과 노이즈에 민감해 상태 누적 오류가 생길 수 있음
   - 해결방안: attention, masking, 정규화를 병행하고 validation loss로 검증함

## Ⅶ. 적용 사례

- 시계열 예측: 수요, 센서, 트래픽 흐름을 예측함, 확인 지표는 MAE와 RMSE임
- 자연어 처리: 문장 시퀀스를 인코딩함, 확인 지표는 perplexity 또는 F1임
- 음성 처리: 프레임 단위 정보를 누적 분석함, 확인 지표는 WER임

## Ⅷ. 결론

RNN 계열의 핵심은 순서 정보 누적에 있으므로, 시퀀스 길이와 병렬화 한계를 고려해 LSTM/GRU 또는 대체 구조를 선택해야 함.
