## 미리 알고가기

- 시퀀스 데이터와 $t,x_t,y_t$: 순서가 의미를 갖는 데이터와 현재 시점·입력·출력을 나타내는 표기임
- 은닉 상태 $h_t$: 이전 시점 정보를 압축해 시점 $t$의 계산에 전달하는 내부 상태임
- 셀 상태 $c_t$: LSTM에서 망각 게이트로 유지 비율을 조절하며 장기 정보를 전달하는 기억 경로임
- 시간축 역전파(BPTT): 순환 구조를 시간축으로 펼쳐 각 시점의 오차를 역전파하는 학습 방식임
- 장기 의존성: 먼 과거 정보가 이후 시점의 예측에 필요하지만 전달이 약해지는 문제임
- 게이트: 입력·망각·출력 또는 갱신·리셋 비율을 학습해 정보 흐름을 제어하는 장치임
- 순환 신경망(RNN): 이전 은닉 상태와 현재 입력 $x_t$로 출력 $y_t$를 계산하는 구조임
- 장단기 메모리(LSTM): 셀 상태와 입력·망각·출력 게이트로 장기 정보를 전달하는 순환 구조임
- 게이트 순환 유닛(GRU): 갱신·리셋 게이트로 LSTM의 상태 구조를 단순화한 순환 구조임
- 기울기 소실·폭주: 시간축 역전파에서 기울기가 지나치게 작아지거나 커지는 현상임

## 작성 근거(검토용)

- 개요는 RNN 계열이라는 상위 개념으로 정의를 통합하고 Ⅲ에서 LSTM·GRU의 개별 특성을 비교함
- 특징은 가중치 공유, 은닉 상태, BPTT 한계, 게이트 보완으로 논리를 전개함
- 비교표는 기억 메커니즘·처리 범위·주요 제약으로 세 모델의 선택 기준을 드러냄
- 구성요소는 $x_t$, $h_t$, $c_t$, 게이트, $y_t$로 순환 구조의 단위를 일치시킴
- 절차와 도식은 상태 갱신부터 시간축 역전파까지 시점 간 전달 관계를 단계화함
- 시퀀스 길이와 순차 연산 비용은 RNN 계열 선택을 바꾸는 대표 조건임

## Ⅰ. 개요

- **정의/개념**: RNN 계열은 이전 은닉 상태와 현재 입력을 결합해 순서 정보를 반영하는 시퀀스 모델임
- **배경/필요성**: 자연어·음성·시계열의 앞뒤 맥락을 반영하기 위해 시간 의존성을 저장하는 구조가 필요함

## Ⅱ. 특징

- 같은 가중치를 모든 시점에 공유해 길이가 다른 시퀀스도 동일 구조로 처리함
- 은닉 상태가 이전 정보를 현재 계산에 연결해 문맥과 시간 흐름을 모델 내부에 보존함
- BPTT로 시간축 오차를 학습하지만 긴 시퀀스에서는 기울기 소실·폭주가 발생함
- LSTM과 GRU는 게이트로 중요한 정보만 남겨 기본 RNN의 장기 의존성 한계를 줄임

## Ⅲ. 종류 및 비교

| 판단 기준 | RNN | LSTM | GRU |
|:---|:---|:---|:---|
| 기억 메커니즘 | 단일 은닉 상태 | 셀 상태와 세 게이트 | 은닉 상태와 두 게이트 |
| 처리 적합 범위 | 단기 의존 시퀀스 | 장기 의존 시퀀스 | 장기 의존 시퀀스 |
| 주요 제약 | 기울기 소실 | 게이트 연산 비용 | 독립 셀 상태 부재 |

> 요약: 기본 RNN은 은닉 상태만 갱신하고, LSTM은 세 게이트와 셀 상태를 사용하며, GRU는 두 게이트로 상태 갱신 구조를 줄임.

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 입력 $x_t$ | 시점 $t$의 관측값 |
| 은닉 상태 $h_t$ | 과거·현재 정보 요약 |
| 셀 상태 $c_t$(LSTM) | 장기 기억 전달 경로 |
| 게이트(LSTM·GRU) | 입력·망각·출력 또는 갱신·리셋 게이트를 통한 정보 흐름 조절 |
| 출력 $y_t$ | 시점별·시퀀스 예측값 |

> 요약: RNN 계열은 시점마다 입력과 이전 상태를 순환 셀에 결합해 은닉 상태와 출력을 만드는 구조임.

## Ⅴ. 원리 및 절차 흐름도

```text
+-------+      +----------+      +---------+      +-------+
| x_t   | ---> | 순환 셀  | ---> | h_t     | ---> | y_t   |
+-------+      +----------+      +---------+      +-------+
                   ^                |
                   |                v
                +---------+      다음 시점
                | h_{t-1} |
                +---------+
```

1. **입력·이전 상태 수신**: 시점 $t$의 입력 $x_t$와 이전 은닉 상태 $h_{t-1}$을 순환 셀에 전달함
2. **상태 갱신**: 기본 RNN은 $h_t = \tanh(W_h h_{t-1} + W_x x_t)$로 갱신하고, LSTM·GRU는 게이트로 유지·삭제 비율을 조절해 $h_t$(LSTM은 $c_t$ 포함)를 갱신함
3. **출력 계산**: 갱신된 $h_t$로 시점별 출력 $y_t$를 산출함
4. **시간축 오차 역전파**: BPTT로 전체 시퀀스의 오차를 각 시점 가중치에 전파해 기울기 소실·폭주를 관리함

> 요약: 순환 셀이 시점마다 이전 상태와 입력을 결합해 상태·출력을 갱신하고 BPTT로 시퀀스 오차를 학습함.

## Ⅵ. 실무 사례

1. 서버 장애 로그 예측은 LSTM·GRU를 적용하고 검증 손실·기울기 크기로 학습 안정성을 가늠함
2. 장기 로그 시퀀스 분류는 RNN·LSTM·GRU의 분류 성능·p95 추론 지연을 비교해 구조를 선택함

## Ⅶ. 결론

- RNN 계열은 순서 의존성을 은닉 상태로 전달하는 모델이며, 시퀀스 길이와 장기 기억 요구가 구조 선택 기준임
