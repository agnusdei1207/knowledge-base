# 순환 신경망 RNN·LSTM·GRU (Recurrent Neural Network)

## 1. 개요

- **정의/개념**: RNN은 이전 시점의 hidden state를 다음 시점 계산에 전달해 순차 데이터의 시간적 의존성을 학습하는 신경망 구조이다.
- **배경/필요성**: 텍스트, 음성, 센서 시계열처럼 순서와 과거 문맥이 중요한 데이터는 독립 샘플로 처리하면 정보가 손실되므로 상태를 누적하는 구조가 필요하다.

RNN의 핵심은 같은 셀을 시간축으로 반복 적용하고, hidden state가 과거 정보를 전달한다는 점이다.

## 2. 특징 및 비교

| 구분 | Vanilla RNN | LSTM | GRU |
|---|---|---|---|
| 구조 | 단순 순환 | input/forget/output gate | update/reset gate |
| 장점 | 구현 단순 | 장기 의존성 보존 | LSTM보다 단순 |
| 약점 | gradient 소실 | 계산 비용 큼 | 표현력은 문제별 차이 |
| 활용 | 짧은 시퀀스 | 긴 문맥 | 실시간·경량 시퀀스 |

선택 기준은 시퀀스 길이, 장기 의존성, 계산 비용, 실시간성, 데이터 규모이다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| Input Sequence | 시간 순서가 있는 입력 | 순서 보존 |
| Hidden State | 과거 정보 요약 | 문맥 전달 |
| Recurrent Cell | 시점별 반복 계산 | 공유 가중치 |
| Gate | 정보 유지·삭제 제어 | LSTM/GRU 핵심 |
| Output | 시점별 또는 전체 예측 | task 형태 |

```text
x1 -> [Cell] -> h1 -> [Cell] -> h2 -> [Cell] -> h3
        ^             ^             ^
        |             |             |
       input         input         input
```

hidden state가 정보 전달 경로이므로 gradient 소실과 장기 의존성 문제가 구조적으로 발생한다.

## 4. 문제점 및 개선방안

1. **장기 의존성 학습 어려움**
   - 긴 시퀀스에서 gradient가 사라져 먼 과거 정보를 학습하기 어렵다.
   - **개선방안**: LSTM, GRU, attention, Transformer를 검토한다.

2. **순차 처리 비용**
   - 시간 순서대로 계산해야 하므로 병렬화가 제한된다.
   - **개선방안**: sequence batching, truncated BPTT, Transformer 대안을 사용한다.

3. **상태 초기화와 길이 처리**
   - padding, hidden state 초기화가 잘못되면 결과가 왜곡된다.
   - **개선방안**: mask 처리, sequence length 관리, 상태 reset 정책을 명확히 한다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| 시계열 예측 | 과거 센서값 hidden state로 요약 | RMSE, 예측 지연 |
| 음성·텍스트 처리 | 순차 입력의 문맥 반영 | WER, F1 |
| 이상 탐지 | 정상 시퀀스 패턴과 예측 오차 비교 | 탐지율, 오탐률 |

## 6. 결론

RNN·LSTM·GRU는 순차 데이터의 시간 의존성을 hidden state로 모델링하는 구조이다. 장기 의존성, gradient 안정성, 순차 처리 비용을 함께 판단해야 Transformer 등 대안과의 선택 기준도 분명해진다.
