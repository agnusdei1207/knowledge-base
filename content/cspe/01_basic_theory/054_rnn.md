## 미리 알고가기

- 시퀀스 데이터와 $t,x_t,y_t$: 순서가 의미를 갖는 데이터와 현재 시점·입력·출력을 나타내는 표기임
- 은닉 상태 $h_t$: 이전 시점 정보를 압축해 시점 $t$의 계산에 전달하는 내부 상태임
- 셀 상태 $c_t$: LSTM에서 망각 게이트로 유지 비율을 조절하며 장기 정보를 전달하는 기억 경로임
- 시간축 역전파(BPTT): 순환 구조를 시간축으로 펼쳐 각 시점의 오차를 역전파하는 학습 방식임
- 장기 의존성: 먼 과거 정보가 이후 시점의 예측에 필요하지만 전달이 약해지는 문제임
- 게이트: 입력·망각·출력 또는 갱신·리셋 비율을 학습해 정보 흐름을 제어하는 장치임
- 순환 신경망(Recurrent Neural Network, RNN): 이전 은닉 상태와 현재 입력 $x_t$로 출력 $y_t$를 계산하는 구조임
- 장단기 메모리(Long Short-Term Memory, LSTM): 셀 상태와 입력·망각·출력 게이트로 장기 정보를 전달하는 순환 구조임
- 게이트 순환 유닛(Gated Recurrent Unit, GRU): 갱신·리셋 게이트로 LSTM의 상태 구조를 단순화한 순환 구조임
- 기울기 소실·폭주: 시간축 역전파에서 기울기가 지나치게 작아지거나 커지는 현상임

## 작성 근거(검토용)

- **방향성**: RNN 계열은 은닉 상태로 순서 정보를 압축해 전달하는 대신, 시퀀스가 길어질수록 장기 의존 정보가 약해지고 순차 계산 비용이 커지므로 시퀀스 길이와 장기 기억 요구에 맞춰 RNN·LSTM·GRU 중 구조를 선택해야 함
- **개요 구성**: RNN 계열이라는 상위 개념으로 정의를 통합하고 Ⅲ에서 LSTM·GRU의 개별 특성을 비교함
- **Ⅱ. 특징 선정**: 가중치 공유, 은닉 상태, BPTT 한계, 게이트 보완으로 논리를 전개함
- **Ⅲ. 비교축 선정**: 기억 메커니즘·처리 적합 범위·주요 제약은 세 구조의 고유 스펙이라 축은 유지하고, 시퀀스 길이·연산 비용에 따른 선택 기준은 요약 문장의 구체적 분기 조건으로 명시함
- **Ⅳ. 구조 선정**: $x_t$, $h_t$, $c_t$, 게이트, $y_t$로 순환 구조의 단위를 일치시킴
- **Ⅴ. 절차 선정**: 상태 갱신부터 시간축 역전파까지 시점 간 전달 관계를 단계화함
- **Ⅵ. 사례 선정**: 시퀀스 길이와 순차 연산 비용은 RNN 계열 선택을 바꾸는 대표 조건임
- **전수 검수**: 제목부터 결론까지 용어·표·도식·요약을 대조하고 RNN·LSTM·GRU 정의와 절 간 판단축을 일치시킴

## Ⅰ. 개요

- **정의/개념**: RNN 계열은 이전 은닉 상태와 현재 입력을 결합해 순서 정보를 반영하는 시퀀스 모델임
- **배경/필요성**: 자연어·음성·시계열의 앞뒤 맥락을 반영하기 위해 시간 의존성을 저장하는 구조가 필요함

### 쉽게 이해하기 (학습용)
- 드라마를 정주행할 때 이전 화 내용을 기억한 채로 다음 화를 보며 이해하듯, 이전 시점 정보를 이어받아 현재 입력을 해석하는 구조임

## Ⅱ. 특징

- 같은 가중치를 모든 시점에 공유해 길이가 다른 시퀀스도 동일 구조로 처리함
- 은닉 상태가 이전 정보를 현재 계산에 연결해 문맥과 시간 흐름을 모델 내부에 보존함
- BPTT로 시간축 오차를 학습하지만 긴 시퀀스에서는 기울기 소실·폭주가 발생함
- LSTM과 GRU는 게이트로 중요한 정보만 남겨 기본 RNN의 장기 의존성 한계를 줄임

### 쉽게 이해하기 (학습용)
- 매회 같은 진행 방식(가중치)으로 방송하니 화 수가 달라도 같은 틀로 볼 수 있고, 지난 화 요약(은닉 상태)을 계속 이어붙이지만 화가 너무 많아지면 초반 내용을 점점 잊어버림
- LSTM·GRU는 중요한 장면만 골라 기억하는 메모장(게이트)을 따로 둬 오래 기억함

## Ⅲ. 종류 및 비교

| 판단 기준 | RNN | LSTM | GRU |
|:---|:---|:---|:---|
| 기억 메커니즘 | 단일 은닉 상태 | 셀 상태와 세 게이트 | 은닉 상태와 두 게이트 |
| 처리 적합 범위 | 단기 의존 시퀀스 | 장기 의존 시퀀스 | 장기 의존 시퀀스 |
| 주요 제약 | 기울기 소실 | 게이트 연산 비용 | 독립 셀 상태 부재 |

> 요약: 짧은 시퀀스나 연산 자원이 매우 제한되면 RNN, 긴 시퀀스에서 정교한 장기 의존 학습이 필요하면 LSTM, 장기 의존을 다루되 연산·파라미터 비용을 줄이려면 GRU를 적용함.

### 쉽게 이해하기 (학습용)
- RNN은 머릿속 기억 하나로만 버티고, LSTM은 별도 기억노트(셀 상태)와 세 개의 필터로 정보를 고르며, GRU는 필터 두 개로 간소화한 방식임

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 입력 $x_t$ | 시점 $t$의 관측값 |
| 은닉 상태 $h_t$ | 과거·현재 정보 요약 |
| 셀 상태 $c_t$(LSTM) | 장기 기억 전달 경로 |
| 게이트(LSTM·GRU) | 입력·망각·출력 또는 갱신·리셋 게이트를 통한 정보 흐름 조절 |
| 출력 $y_t$ | 시점별·시퀀스 예측값 |

> 요약: RNN 계열은 시점마다 입력과 이전 상태를 순환 셀에 결합해 은닉 상태와 출력을 만드는 구조임.

### 쉽게 이해하기 (학습용)
- 매 순간 들어오는 정보(xt)와 그동안의 요약(ht)을 합쳐 다음 요약을 만들고, LSTM은 별도 기억노트(ct)와 문지기(게이트)를 더 둬 결과(yt)를 냄

## Ⅴ. 원리 및 절차 흐름도

```text
$x_t$와 $h_{t-1}$ 입력 → 순환 셀 → $h_t$·$y_t$ 계산
                                      ├─ 다음 시점 있음 → $h_t$를 재입력
                                      └─ 시퀀스 종료 → 시점별 손실을 BPTT로 역전파
```

1. **입력·이전 상태 수신**: 시점 $t$의 입력 $x_t$와 이전 은닉 상태 $h_{t-1}$을 순환 셀에 전달함
2. **상태 갱신**: 기본 RNN은 $h_t = \tanh(W_h h_{t-1} + W_x x_t)$로 갱신하고, LSTM·GRU는 게이트로 유지·삭제 비율을 조절해 $h_t$(LSTM은 $c_t$ 포함)를 갱신함
3. **출력 계산**: 갱신된 $h_t$로 시점별 출력 $y_t$를 산출함
4. **시간축 오차 역전파**: BPTT로 전체 시퀀스의 오차를 각 시점 가중치에 전파해 기울기 소실·폭주를 관리함

> 요약: 순환 셀이 시점마다 이전 상태와 입력을 결합해 상태·출력을 갱신하고 BPTT로 시퀀스 오차를 학습함.

### 쉽게 이해하기 (학습용)
- 새 소식과 이전 요약을 합쳐 다음 요약과 결과를 만들고 이를 계속 반복하다가, 끝나면 처음부터 되짚어보며 어디서 헷갈렸는지 고쳐 나감

## Ⅵ. 실무 사례

1. 서버 장애 징후 탐지기는 LSTM·GRU로 시간 순서에 따른 로그 변화를 학습함
2. 사용자 세션 예측기는 세션 종료 시 은닉 상태를 초기화해 다른 사용자의 문맥이 섞이지 않게 함

### 쉽게 이해하기 (학습용)
- 서버 이상 감지는 로그를 시간 순서대로 훑어 흐름을 파악하고, 사용자 세션 예측은 세션이 끝나면 기억을 깨끗이 지워 다른 사용자와 섞이지 않게 함

## Ⅶ. 결론

- RNN 계열은 순서 의존성을 은닉 상태로 전달하는 모델이며, 시퀀스 길이와 장기 기억 요구가 구조 선택 기준임
- 상태 보존 경계가 불명확한 서비스는 세션 초기화 규칙을 먼저 정하고, 순차 계산 비용이 감당 안 될 만큼 시퀀스가 길어지면 병렬 처리가 가능한 다른 구조로 전환을 검토해야 함

### 쉽게 이해하기 (학습용)
- 순서를 기억해가며 판단하는 방식이므로, 기억을 어디서 끊을지 규칙을 정하고 문맥이 아주 길어져 한 줄로 계산하기 버거워지면 다른 방식으로 갈아타야 함
