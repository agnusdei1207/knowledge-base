## 미리 알고가기

- 시퀀스 데이터: 시간 또는 순서에 따라 의미가 달라지는 데이터임
- 은닉 상태: 이전 시점 정보를 압축해 다음 시점 계산에 전달하는 내부 상태임
- BPTT: 시간을 펼친 RNN 구조에 역전파를 적용하는 학습 방식임
- 게이트: 정보의 유지, 삭제, 출력을 조절하는 학습 가능한 문 역할임
- 셀 상태: LSTM에서 장기 기억을 보존하기 위한 별도 상태 경로임

## Ⅰ. 개요

- **정의**: RNN은 현재 입력과 이전 은닉 상태를 함께 사용해 시점별 상태를 갱신함으로써 텍스트, 음성, 센서 로그처럼 순서 의존성이 있는 데이터를 학습하는 신경망 구조임
- **배경/필요성**: 일반 신경망은 입력 간 순서와 과거 문맥을 직접 기억하지 못하므로, 길이가 변하고 이전 정보가 현재 의미에 영향을 주는 데이터를 처리할 순환 구조가 필요함
- **비유**: 책을 한 문장씩 읽으면서 앞 문장의 내용을 기억해 다음 문장의 의미를 해석하는 과정과 같음

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 순환 구조 이해 | 은닉 상태, 시점 전개, BPTT | 단순 피드포워드와 혼동 |
| LSTM·GRU 개선 원리 | 게이트, 셀 상태, 기울기 소실 완화 | LSTM과 GRU 구조 차이 누락 |

> 요약: RNN 계열은 이전 상태를 다음 계산에 반영해 순서와 문맥을 학습하는 시퀀스 처리 모델임.

## Ⅱ. 특징/비교

| 판단 기준 | 기본 RNN | LSTM·GRU |
|:---|:---|:---|
| 기억 구조 | 하나의 은닉 상태에 과거 정보를 압축함 | 게이트와 별도 상태 경로로 정보 유지·삭제를 조절함 |
| 장기 의존성 | 시점이 길어질수록 기울기 소실이 쉽게 발생함 | 장기 기억과 기울기 흐름을 상대적으로 잘 보존함 |
| 계산 복잡도 | 구조가 단순하고 파라미터가 적음 | 게이트 연산으로 계산량과 파라미터가 증가함 |
| 선택 조건 | 짧은 시퀀스와 단순 패턴에 적합함 | 긴 문맥, 음성, 시계열 예측처럼 장기 의존성이 중요할 때 적합함 |

> 요약: RNN 계열 선택은 시퀀스 길이, 장기 의존성, 계산 비용의 균형으로 판단해야 함.

- **입력 조건**: 데이터의 순서가 의미를 가지며 이전 상태가 현재 예측에 영향을 주어야 함
- **평가 기준**: 길이별 성능, 지연시간, 기울기 안정성을 함께 확인함
- **선택 판단**: 실시간 순차 처리나 작은 시계열 모델이 필요할 때 우선 검토함

## Ⅲ. 구성요소

```text
+------------+      +------------+      +------------+
| 현재 입력 x | ---> | 순환 셀     | ---> | 출력 y      |
+------------+      +------------+      +------------+
       |                  |                  |
       v                  v                  v
+------------+      +------------+      +------------+
| 이전 상태 h |      | 게이트·상태 |      | 다음 상태 h |
+------------+      +------------+      +------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 현재 입력 | 현재 시점의 단어, 음성 프레임, 센서값 등 처리 대상임 | 지금 읽는 문장 |
| 이전 은닉 상태 | 과거 시점 정보를 압축해 현재 계산에 전달하는 값임 | 이전 맥락 기억 |
| 순환 셀 | 입력과 상태를 결합해 현재 출력과 다음 상태를 계산하는 핵심 연산임 | 문맥 해석기 |
| 게이트·셀 상태 | LSTM·GRU에서 정보 유지, 삭제, 출력을 조절하는 장치임 | 기억문 |
| 출력층 | 시점별 라벨, 다음 값, 전체 시퀀스 분류 결과로 변환함 | 답안 작성 |

> 요약: RNN은 현재 입력과 과거 상태를 순환 셀에서 결합해 출력과 다음 기억 상태를 함께 생성함.

## Ⅳ. 절차

```text
+------------+      +------------+      +------------+      +------------+
| 시퀀스 입력 | ---> | 상태 갱신   | ---> | 출력 계산   | ---> | BPTT 학습   |
+------------+      +------------+      +------------+      +------------+
```

1. **시퀀스 준비**: 토큰화, 패딩, 정렬, 윈도잉 등으로 순서 데이터를 학습 가능한 형태로 만듦
2. **상태 갱신**: 각 시점에서 현재 입력과 이전 상태를 결합해 새 은닉 상태를 계산함
3. **출력 계산**: 시점별 출력 또는 마지막 상태를 사용해 분류·예측 결과를 산출함
4. **BPTT 학습**: 시간축으로 펼친 계산 그래프에서 손실 기울기를 역전파해 가중치를 갱신함

> 요약: RNN 절차는 순서 데이터를 시점별로 처리하며 상태를 갱신하고 시간축 역전파로 학습하는 흐름임.

- **산출물**: 시점별 출력, 최종 상태, 예측 시퀀스 또는 클래스임
- **검증 기준**: 긴 시퀀스에서도 오류 누적과 기울기 문제가 허용 범위여야 함
- **운영 기록**: 시퀀스 길이, 패딩, hidden size, BPTT 길이를 설정으로 남겨야 함

## Ⅴ. 문제점

- **P1 기울기 소실·폭발**: 긴 시퀀스를 학습할 때 반복 곱셈으로 기울기가 사라지거나 커져 장기 의존성 학습이 어려움
- **P2 순차 계산 병목**: 이전 상태가 있어야 다음 시점을 계산하므로 Transformer보다 병렬화가 어렵고 학습 시간이 길어짐
- **P3 노출 편향**: 학습 때는 정답 이전 토큰을 사용하지만 추론 때는 모델 예측을 사용해 오류가 누적될 수 있음

> 요약: RNN의 핵심 한계는 긴 문맥의 기울기 흐름, 순차 처리 비용, 학습·추론 조건 차이에서 발생함.

## Ⅵ. 개선방안

- **P1 대응**: LSTM·GRU, gradient clipping, 적절한 초기화, truncated BPTT를 적용함 (확인: 기울기 norm과 장기 의존 태스크 성능)
- **P2 대응**: 배치화, 시퀀스 길이 제한, CNN·Transformer 대안을 비교해 병렬 처리 가능성을 확보함 (확인: 학습 시간과 지연시간)
- **P3 대응**: scheduled sampling, beam search, validation rollout으로 추론 조건을 반영함 (확인: 길이별 오류 누적률)

> 요약: RNN 개선은 게이트 구조와 학습 안정화 기법으로 장기 의존성을 보완하고 필요 시 병렬 모델로 대체하는 것임.

- **우선순위**: 장기 의존성과 순차 처리 지연을 먼저 평가함
- **확인 지표**: 길이별 정확도, perplexity, gradient norm, 추론 지연을 사용함
- **재평가 조건**: 시퀀스 길이 증가나 실시간 요구사항 변경 시 구조를 다시 비교함

## Ⅶ. 전망

- **발전 방향**: RNN 계열은 Transformer에 많은 영역을 넘겼지만 경량 엣지 모델, 상태공간 모델, 스트리밍 추론 구조와 결합해 비용 효율형 순차 처리로 발전함
- **설계 관점**: 시퀀스 길이, 장기 의존성, 실시간성, 병렬화 요구, 하드웨어 제약을 기준으로 RNN·LSTM·GRU·Transformer를 비교해야 함
- **검증 관점**: 길이별 정확도, perplexity, gradient norm, 추론 지연을 확인해 장기 의존성 학습과 순차 계산 병목을 검증해야 함
- **운영 관점**: 입력 길이 증가, 지연시간 요구 변경, 온라인 추론 전환 시 truncated BPTT, hidden state 관리, rollout 검증 기준을 재점검해야 함
- **적용 관점**: 저지연 스트리밍, 작은 모델, 단순 시계열 예측에는 실용적이지만 긴 문맥 이해나 대규모 병렬 학습에는 Transformer 계열이 유리함
- **보안·신뢰 관점**: 비정상 길이 입력이나 반복 패턴이 hidden state를 오염시켜 오류를 누적할 수 있으므로 길이 제한, 상태 초기화, 경계 입력 테스트가 필요함
- **기술사 제언**: RNN은 구식 여부가 아니라 순차성, 지연시간, 장기 의존성 요구를 기준으로 대안 구조와 비교해 선택해야 함
