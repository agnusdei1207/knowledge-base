## 미리 알고가기

- 시퀀스 데이터: 텍스트, 음성, 센서값처럼 순서와 시간 흐름이 의미를 갖는 데이터임
- 은닉 상태 $h_t$: 이전 시점 정보를 압축해 현재 시점 계산에 전달하는 내부 상태임
- 셀 상태 $c_t$: LSTM에서 장기 정보를 비교적 안정적으로 보존하는 별도 기억 경로임
- BPTT: 순환 구조를 시간축으로 펼쳐 각 시점의 오차를 역전파하는 학습 방식임
- 장기 의존성: 먼 과거 정보가 뒤 시점의 예측에 필요하지만 전달이 약해지는 문제임
- 게이트: 입력, 삭제, 출력 비율을 학습해 정보 흐름을 선택적으로 제어하는 장치임

## Ⅰ. 개요

- **정의/개념**: RNN은 이전 은닉 상태를 현재 입력과 함께 처리해 순서 정보를 반영하며, LSTM·GRU는 게이트로 기억 유지와 삭제를 제어하는 시퀀스 모델임
- **배경/필요성**: 자연어, 음성, 시계열은 현재 값만으로 판단하기 어렵고 앞뒤 맥락이 결과를 바꾸므로 시간 의존성을 저장하는 구조가 필요함

## Ⅱ. 특징

- 같은 가중치를 모든 시점에 공유해 길이가 다른 시퀀스도 동일 구조로 처리함
- 은닉 상태가 이전 정보를 현재 계산에 연결해 문맥과 시간 흐름을 모델 내부에 보존함
- BPTT로 시간축 오차를 학습하지만 긴 시퀀스에서는 기울기 소실·폭주가 발생할 수 있음
- LSTM과 GRU는 게이트로 중요한 정보만 남겨 바닐라 RNN의 장기 의존성 한계를 줄임

## Ⅲ. 종류 및 비교

| 판단 기준 | RNN | LSTM | GRU |
|:---|:---|:---|:---|
| 기억 구조 | 은닉 상태만 사용 | 셀 상태와 3개 게이트 | 은닉 상태와 2개 게이트 |
| 장기 정보 | 짧은 구간 중심 | 장기 의존성에 강함 | LSTM보다 단순하게 보존 |
| 연산 비용 | 가장 낮음 | 가장 높음 | 중간 |
| 적합 조건 | 짧은 시퀀스 | 긴 문맥·복잡한 시계열 | 속도와 성능 균형 필요 |

> 요약: RNN은 단순성, LSTM은 기억력, GRU는 경량성과 성능 균형이 선택 기준임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 입력 $x_t$ | 시점 $t$의 단어, 음성 프레임, 센서값처럼 현재 관측값을 제공함 |
| 은닉 상태 $h_t$ | 과거와 현재 입력을 합친 요약값이며 다음 시점으로 전달됨 |
| 게이트 | 보존, 삭제, 출력할 정보 비율을 학습해 기억 흐름을 제어함 |
| 출력 $y_t$ | 현재 시점 예측값이거나 전체 시퀀스의 최종 판단값임 |
| 손실 함수 | 시점별 또는 전체 시퀀스 오차를 계산해 BPTT의 기준이 됨 |

```text
+-------+      +---------+      +---------+      +-------+
| x_t   | ---> | RNN cell| ---> | h_t     | ---> | y_t   |
+-------+      +---------+      +---------+      +-------+
                   ^                |
                   |                v
                +---------+      next time
                | h_{t-1} |
                +---------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+      +----------+      +----------+      +----------+
| x_t      | ---> | combine  | ---> | gate     | ---> | h_t,y_t  |
+----------+      +----------+      +----------+      +----------+
```

1. **현재 입력 수신**: 시점 $t$의 입력 $x_t$와 이전 은닉 상태 $h_{t-1}$를 함께 받음
2. **상태 후보 계산**: 공유 가중치로 현재 입력과 과거 상태를 결합해 새 상태 후보를 만듦
3. **정보 흐름 제어**: LSTM·GRU는 게이트로 유지할 정보와 버릴 정보를 선택함
4. **상태 전달**: 새 은닉 상태 $h_t$와 출력 $y_t$를 만들고 다음 시점으로 전달함

## Ⅵ. 실무 적용 및 유의점

1. 센서 로그와 짧은 시계열 예측은 LSTM·GRU를 적용하되 기울기 클리핑과 검증 손실로 학습 안정성을 확인함
2. 긴 문서와 고처리량 추론은 순차 연산 병목이 커지므로 Attention·Transformer와 비교하고 지연과 정확도로 선택함

## Ⅶ. 결론

- RNN 계열은 순서 의존성을 은닉 상태로 전달하는 모델이며, 시퀀스 길이와 장기 기억 요구가 구조 선택 기준임

## 작성 근거(검토용)

- 개요는 RNN과 LSTM·GRU를 한 문장에 묶어 키워드 제목의 복합성을 반영함
- 특징은 가중치 공유, 은닉 상태, BPTT 한계, 게이트 보완으로 논리를 전개함
- 비교표는 기억 구조와 연산 비용을 중심으로 세 모델의 선택 기준을 드러냄
- 구성요소는 시점 입력과 상태 전달 관계를 보여주도록 $x_t$, $h_t$, $y_t$를 배치함
- 절차는 현재 입력에서 다음 시점 전달까지 시간 순서를 유지함
- 유의점은 짧은 시계열 적용과 긴 문맥 대체 검토를 대표 실무 판단으로 선정함
