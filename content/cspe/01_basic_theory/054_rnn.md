## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 은닉층 뉴런의 출력이 다시 자신의 입력으로 들어가는 순환 구조를 통해 시계열 데이터를 처리하는 모델임 |
| 배경/필요성 | 텍스트, 음성 등 길이가 가변적이고 전후 문맥(순서)을 기억해야 하는 시퀀스 데이터 학습 필요 |
| 출제 의도 | 순환 구조 기반 BPTT 학습 원리, 장기 의존성(Long-Term Dependency) 문제 및 LSTM 구조 이해 평가 |

## Ⅱ. 구성요소
```text
+----------------+       +----------------+       +----------------+
| Sequence Input |       | Recurrent      |       | Output / State |
| (Time t)       | ----> | Hidden Layer   | ----> | (Time t, t+1)  |
+----------------+       +----------------+       +----------------+
```
| 순환 상태 (State)| 과거 정보를 담아 다음 타임스텝으로 전달하는 은닉 상태 | 기억장치 |
| BPTT 알고리즘 | 시간을 거슬러 올라가며 오차를 역전파하는 학습 방법 | 과거로의 피드백 |
| 게이트 (Gate) | LSTM/GRU에서 정보의 저장/삭제 비율을 조절하는 구조 | 정보 수문장 |
> 요약: RNN은 은닉 상태의 순환 구조와 장기 기억을 통제하는 게이트(LSTM)로 구성됨

## Ⅲ. 절차
```text
+----------------+       +----------------+       +----------------+       +----------------+
| Input Feed (t) |       | State Update   |       | Output Calc    |       | Pass to (t+1)  |
| (Current data) | ----> | (Use prev h)   | ----> | (Return y_t)   | ----> | (Recurse)      |
+----------------+       +----------------+       +----------------+       +----------------+
```
1. 입력 수신: 현재 타임스텝(t)의 데이터와 이전 스텝(t-1)의 은닉 상태값 수신
2. 상태 갱신: 두 입력을 가중합하고 활성화 함수(Tanh 등)를 통과시켜 새 은닉 상태 생성
3. 출력 계산: 갱신된 은닉 상태를 바탕으로 현재 스텝의 출력값 도출(필요 시)
4. 순환 전달: 새 은닉 상태를 다음 타임스텝(t+1) 연산의 입력으로 전달
> 요약: 현재 입력과 과거 상태를 결합하여 새 상태를 갱신하고 다음 스텝으로 전달함

## Ⅳ. 문제점
- 기울기 소실(Vanishing): 시퀀스가 길어지면 과거로 갈수록 기울기가 0으로 소실됨
- 장기 의존성 문제: 위 원인으로 인해 아주 오래전 발생한 중요 정보를 기억하지 못함
- 병렬 처리 불가: 이전 스텝 연산이 끝나야 다음 스텝 계산이 가능해 GPU 병렬 연산 불가

## Ⅴ. 개선방안
- 단기 방안: ReLU 계열 활성화 함수 사용 또는 기울기 클리핑으로 소실/폭발 방지 시도
- 중기 방안: 망각/입력 게이트를 갖춘 LSTM이나 구조가 단순한 GRU로 장기 의존성 해결
- 장기 방안: 순차 연산을 버리고 어텐션(Attention) 기법을 기반으로 한 트랜스포머 아키텍처 도입

## Ⅵ. 전망
- 순수 RNN은 감소 추세이나 Mamba, RWKV 등 병렬 처리를 지원하는 새로운 순환 구조로 재조명됨
