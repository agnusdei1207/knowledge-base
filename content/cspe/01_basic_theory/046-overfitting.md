## Ⅰ. 개요
- **정의**: 모델의 복잡도에 따라 발생하는 학습 데이터 암기(과적합)와 학습 부족(과소적합) 간의 균형 원리임.
- **배경/필요성**: 새로운 데이터(테스트 셋)에 대해 잘 작동하는 높은 일반화 성능을 얻기 위해 이 개념의 이해가 필수적임.
- **출제 의도**: 편향(Bias)과 분산(Variance)의 개념을 이해하고, 정규화 등을 통해 과적합을 방지하는 전략을 평가함.

## Ⅱ. 구성요소
```text
+------------------+       +------------------+       +------------------+
| Underfitting     |       | Optimal Capacity |       | Overfitting      |
| High Bias        | <---> | (Sweet Spot)     | <---> | High Variance    |
+------------------+       +------------------+       +------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 편향 (Bias) | 실제값과 예측값 간의 차이 (오차의 체계적 경향) | 과녁의 중심 이탈 |
| 분산 (Variance) | 예측값들이 서로 흩어져 있는 정도 (모델 민감도) | 화살들의 흩어짐 |
| 복잡도 (Capacity)| 모델이 데이터의 패턴을 학습할 수 있는 수용력 | 두뇌(암기력) 크기 |

> 요약: 모델 복잡도가 낮으면 편향이 커지고(과소적합), 높으면 분산이 커짐(과적합).

## Ⅲ. 절차
```text
+-------------+   +-------------+   +-------------+   +-------------+
| 1. 데이터   |-->| 2. 모델     |-->| 3. 오차     |-->| 4. 파라미터 |
|    학습     |   |    평가     |   |    분석     |   |    조절     |
+-------------+   +-------------+   +-------------+   +-------------+
```
1. **데이터 학습**: 훈련 데이터로 초기 모델을 학습시킴.
2. **모델 평가**: 훈련 셋과 검증 셋에서의 성능(오차)을 각각 측정함.
3. **오차 분석**: 훈련 오차가 크면 과소적합, 검증 오차만 크면 과적합으로 진단함.
4. **파라미터 조절**: 정규화 기법, 조기 종료, 트리 깊이 제한 등을 통해 최적의 균형점을 찾음.

> 요약: 학습 및 검증 오차를 비교하여 편향-분산 상태를 진단하고 하이퍼파라미터를 튜닝함.

## Ⅳ. 문제점
- **트레이드오프 딜레마**: 편향을 줄이려 모델을 복잡하게 하면 분산이 증가하여 동시 감소가 어려움.
- **훈련 데이터 부족**: 데이터가 적으면 모델이 노이즈까지 외워버려 과적합에 극도로 취약해짐.

## Ⅴ. 개선방안
- **트레이드오프 딜레마**: (단기) L1/L2 정규화 적용 / (장기) 앙상블 기법(Bagging, Boosting) 도입으로 편향·분산 동시 개선 필요.
- **훈련 데이터 부족**: (단기) 데이터 증강 기법 사용 / (장기) 전이 학습으로 사전 지식 활용 필요.

## Ⅵ. 전망
- 딥러닝에서는 'Double Descent' 현상 등 전통적인 트레이드오프를 뛰어넘는 새로운 일반화 이론 연구가 활발히 진행 중임.
