## Ⅰ. 개요
- **정의**: 합성곱·풀링 연산으로 데이터의 공간적 특징을 계층적으로 추출하는 신경망
- **배경/필요성**: 완전연결층(FCN)은 2D 공간 구조를 무시하고 파라미터가 O(n²)으로 증가하여 비실용적
- **비유**: 작은 돋보기(필터)를 이미지 위에서 이동시키며 패턴을 찾는 탐정

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 합성곱 연산 원리 | 파라미터 공유·지역 연결로 파라미터 수 대폭 감소 | 출력 크기 공식 (W-F+2P)/S+1 누락 |
| 계층적 특징 추출 | 저수준(에지) -> 고수준(객체) 점진적 추상화 | 풀링의 이동 불변성 vs 위치 정보 손실 트레이드오프 |

> 요약: CNN은 필터 파라미터 공유와 계층적 합성곱으로 공간 특징을 추출하는 딥러닝 모델임

## Ⅱ. 구성요소
```text
+---------------+       +------------------+       +------------------+
| Input Image   |       | Conv + Pool      |       | FC Layer         |
| (H x W x C)  | ----> | (Feature Maps)   | ----> | (Classification) |
+---------------+       +------------------+       +------------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 필터(Kernel) | F x F 크기의 가중치 행렬, 입력 위를 슬라이딩하며 내적 연산 | 패턴 탐지기 |
| 합성곱 층 | 필터와 입력의 지역적 내적으로 특성맵(Feature Map) 생성 | 도장 찍기 |
| 풀링 층 | Max/Avg 풀링으로 특성맵 공간 차원 축소 및 이동 불변성 부여 | 축소 스캔 |

> 요약: 필터(커널) -> 합성곱 층(특성맵 생성) -> 풀링 층(차원 축소)의 3요소로 구성됨

## Ⅲ. 절차
```text
+---------------+       +---------------+       +---------------+       +---------------+
| Padding       |       | Convolution   |       | Activation    |       | Pooling       |
| (Border add)  | ----> | (Filter slide)| ----> | (ReLU apply)  | ----> | (Subsample)   |
+---------------+       +---------------+       +---------------+       +---------------+
```

1. **패딩** — 입력 경계에 0-패딩을 추가하여 출력 크기 보존 및 가장자리 정보 손실 방지
2. **합성곱** — 필터를 스트라이드 간격으로 이동하며 지역 수용 영역의 가중합 산출
3. **활성화** — ReLU 등 비선형 함수 적용으로 선형 연산의 표현 한계 극복
4. **풀링** — Max/Avg Pooling으로 공간 해상도를 1/2~1/4로 축소, 연산량 감소 및 불변성 획득

> 요약: 패딩 -> 합성곱 -> 활성화 -> 풀링을 반복 적층하여 계층적 특성맵을 생성함

## Ⅳ. 문제점
- 고정 수용 영역: 단일 크기 필터로는 다양한 스케일의 객체를 동시 검출 불가
- 위치 정보 손실: Max Pooling이 최댓값만 보존하여 객체의 정밀 위치·자세 정보 소실
- 전역 문맥 부재: 지역적 연산 특성상 입력 내 원거리 픽셀 간 관계 파악에 깊은 층 필요

> 요약: 고정 스케일·위치 손실·전역 문맥 부재가 CNN의 구조적 한계임

## Ⅴ. 개선방안
1. 단기: 다중 크기 커널 병렬 적용(Inception 모듈)으로 멀티스케일 특징 추출
2. 중기: 풀링 대신 스트라이드 합성곱 또는 Deformable Conv로 위치 정보 보존
3. 장기: ViT(Vision Transformer)의 셀프 어텐션과 결합하여 전역 문맥 인지 능력 확보

- 전역 문맥 부재: 지역 연산 한계 -> CNN-Transformer 하이브리드 적용 (지표: ImageNet Top-1 정확도 비교)

> 요약: 멀티스케일 -> 위치 보존 합성곱 -> ViT 하이브리드로 구조적 한계를 해소함

## Ⅵ. 전망
- 향후 발전 방향: EfficientNet·ConvNeXt 등 CNN 재설계와 ViT 하이브리드 아키텍처 공존
- 기술사적 판단: 엣지 디바이스에서는 CNN의 연산 효율(O(k²·C) 고정)이 트랜스포머 대비 우위 유지
- 기술사 제언: 배포 환경(클라우드 vs 엣지)에 따라 CNN/ViT/하이브리드 아키텍처 선택 기준 수립 필요
