## 미리 알고가기

- 합성곱($Convolution$): 커널(필터)이 입력 데이터 위를 이동하며 원소별 곱셈과 합을 통해 국소 특징을 추출하는 연산임
- 수용 영역($Receptive$ $Field$): 특정 뉴런이 입력 이미지에서 어느 정도 면적의 정보를 반영하고 있는지를 나타내는 범위임
- 채널($Channel$): 이미지는 $RGB$ 3개의 채널로 구성되며, 은닉층으로 갈수록 필터 개수만큼 채널(특징 맵)이 늘어남
- 스트라이드($Stride$)와 패딩($Padding$): 필터의 이동 간격과 이미지 경계의 0 채우기 방식으로, 출력 데이터의 크기를 결정함

## Ⅰ. 개요

- **정의/개념**: 합성곱 신경망(CNN)은 이미지의 공간 정보를 유지한 채 필터를 이용해 국소적인 패턴(선, 면, 특징)을 계층적으로 추출하고, 가중치 공유를 통해 파라미터를 획기적으로 줄인 신경망 구조임
- **배경/필요성**: 기존의 완전연결 신경망($DNN$)은 2차원 이미지를 1차원으로 펼쳐야 하므로 픽셀 간의 공간적 상관관계가 파괴되고 파라미터가 폭증하는 문제가 있어, 이를 해결하기 위해 시각 지능 모델로 고안됨

## Ⅱ. 특징

- 지역 연결성($Local$ $Connectivity$)과 가중치 공유($Weight$ $Sharing$)를 통해 특정 지역의 특징을 찾는 필터를 이미지 전체에 적용함으로써 학습 효율과 성능을 동시에 확보함
- 하위 층에서는 점, 선과 같은 기본 기하학적 특징을 추출하고, 상위 층으로 갈수록 이들이 조합되어 객체의 형상과 같은 고수준 추상 정보를 인식하는 계층적 학습 구조를 가짐
- 풀링($Pooling$) 연산을 통해 이동이나 회전에 대한 불변성($Invariance$)을 어느 정도 확보하여, 사물의 위치가 조금 바뀌어도 동일한 객체로 인식하는 강건함을 제공함

## Ⅲ. 종류 및 비교

| 판단 기준 | 완전연결 신경망 ($DNN$) | 합성곱 신경망 ($CNN$) |
|:---|:---|:---|
| **입력 형태** | 1차원 벡터 | 3차원 텐서 ($H, W, C$) |
| **특징 추출** | 전체 노드가 서로 연결됨 | 필터를 이용한 국소 패턴 추출 |
| **공간 정보** | 공간적 구조 정보 소실 | 공간적 구조 정보 보존 |
| **파라미터 수** | 입력 크기에 비례해 급격히 증가 | 필터 크기에 고정되어 매우 효율적 |
| **주요 활용** | 일반 정형 데이터 분석 | 이미지 분류, 객체 탐지, 영상 처리 |

> 요약: DNN은 모든 변수 간의 관계에, CNN은 인접한 픽셀 간의 공간적 관계에 집중함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 컨볼루션 레이어 | 입력 데이터에 커널을 적용하여 특징 맵($Feature$ $Map$)을 생성하는 핵심 층임 |
| 커널/필터 | 특징을 찾아내는 가중치 묶음으로, 학습을 통해 최적의 특징 추출기를 형성함 |
| 풀링 레이어 | 특징 맵의 가로세로 크기를 줄여 연산량을 감소시키고 주요 신호를 강조($Max/Average$)함 |
| 완전연결 레이어 | 추출된 2차원 특징들을 1차원으로 펼쳐($Flatten$) 최종 클래스 분류를 수행함 |

```text
[ CNN 기본 아키텍처 ]
Input -> [Conv -> ReLU -> Pooling] * N -> Flatten -> Fully Connected -> Output
- 특징 추출부: Conv와 Pooling의 반복으로 공간 정보 압축
- 분류부: 추출된 특징을 바탕으로 최종 판단
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 이미지 입력  | --> | 특징 맵 추출  | --> | 공간 크기 압축| --> | 분류 및 결과|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **국소 연산** — 학습 가능한 필터가 이미지를 훑으며 픽셀값과 필터 가중치의 내적을 계산하여 고유한 시각 특징을 담은 특징 맵을 생성함
2. **비선형 활성화** — 합성곱 결과에 $ReLU$ 등을 적용하여 복잡한 시각적 패턴을 표현할 수 있는 비선형성을 부여함
3. **다운 샘플링** — 풀링 층을 통해 데이터의 해상도를 낮추어 작은 위치 변화에 둔감하게 만들고, 이어지는 층의 계산 부담을 줄임
4. **전역 판단** — 충분히 압축된 고차원 특징들을 일렬로 세워 소프트맥스 층에 전달하고, 각 클래스에 속할 확률을 계산하여 최종 분류를 수행함

## Ⅵ. 실무 적용 및 유의점

1. CNN 모델 설계 시 층이 깊어질수록 특징 맵의 크기는 줄어들고 채널 수는 늘리는 것이 일반적이며, $1 \times 1$ 컨볼루션을 활용하여 연산량을 획기적으로 줄이면서도 층을 깊게 쌓는 전략($ResNet, GoogLeNet$)이 권장됨
2. 이미지 데이터가 부족할 경우 과적합이 발생하기 쉬우므로, 원본 이미지를 회전, 대칭, 확대/축소하는 '데이터 증강($Augmentation$)'을 통해 모델의 범용적인 시각 인식 능력을 확보해야 함

## Ⅶ. 결론

- CNN은 공간의 질서를 이해하는 시각 인공지능의 표준이며, 설계자는 필터의 크기와 스트라이드, 패딩의 조화를 통해 데이터의 본질적 특징을 가장 잘 포착하는 최적의 수용 영역을 구축해야 함
