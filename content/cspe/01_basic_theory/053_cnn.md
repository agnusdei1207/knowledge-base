## 미리 알고가기

- 합성곱: 커널이 입력 위를 이동하며 원소별 곱과 합으로 국소 패턴을 계산하는 연산임
- 커널·필터: 이미지의 선, 모서리, 질감 같은 특징을 찾도록 학습되는 작은 가중치 행렬임
- 특징 맵: 필터가 입력에서 찾은 패턴의 위치와 강도를 담은 출력 텐서임
- 스트라이드·패딩: 필터 이동 간격과 경계 보정 방식이며 출력 크기를 결정함
- 수용 영역: 한 뉴런이 입력 이미지에서 실제로 바라보는 공간 범위임
- 풀링: 특징 맵 크기를 줄여 연산량을 낮추고 작은 위치 변화에 둔감하게 만드는 연산임

## 작성 근거(검토용)

- 개요는 공간 구조 보존과 공유 필터를 함께 제시해 CNN의 차별점을 먼저 고정함
- 특징은 지역 연결, 가중치 공유, 계층 표현, 위치 둔감성을 서로 다른 성질로 분리함
- 비교표는 DNN과 Vision Transformer 사이에서 CNN의 적용 조건을 판단하게 구성함
- 구성요소는 입력 텐서부터 출력까지 실제 CNN 블록 순서대로 배치함
- 구성도는 합성곱, 활성화, 풀링, 출력의 계층 구조만 남겨 구성요소 표와 연결함
- 데이터 부족과 실시간 지연은 CNN 적용을 바꾸는 대표 조건임

## Ⅰ. 개요

- **정의/개념**: CNN은 이미지의 공간 구조를 유지한 채 공유 필터로 국소 특징을 계층적으로 추출하는 신경망 구조임
- **배경/필요성**: 이미지의 인접 픽셀 관계를 보존하고 파라미터를 줄이기 위해 공간 정보 처리 구조가 필요함

## Ⅱ. 특징

- 지역 연결로 인접 픽셀 관계를 보존해 이미지의 공간 패턴을 직접 학습함
- 가중치 공유로 같은 필터를 전체 위치에 적용해 파라미터 수와 과적합 위험을 줄임
- 하위 층은 선·모서리를, 상위 층은 객체 일부와 전체 형상을 계층적으로 학습함
- 풀링과 스트라이드로 위치 변화에 대한 민감도를 낮추고 계산량을 조절함

## Ⅲ. 종류 및 비교

| 판단 기준 | 완전연결 신경망 | CNN | Vision Transformer |
|:---|:---|:---|:---|
| 입력 처리 | 1차원 벡터로 펼침 | 2차원·3차원 텐서 유지 | 패치 단위 토큰으로 분할 |
| 공간 관계 | 입력 위치 간 인접성을 별도로 사용하지 않음 | 커널 범위의 인접 관계를 반영 | 어텐션으로 패치 간 전역 관계를 학습 |
| 주요 연산 제약 | 픽셀을 펼치면 입력 차원에 따라 가중치 수가 증가 | 해상도·채널 수에 따라 합성곱 연산량이 증가 | 패치 수에 따라 어텐션 연산량이 제곱으로 증가 |
| 적합 업무 | 정형 데이터 예측 | 이미지 분류·탐지·분할 | 전역 문맥을 다루는 비전·멀티모달 모델 |

> 요약: CNN은 인접 픽셀의 국소 패턴과 위치 관계가 중요한 이미지에서 가중치를 공유해 파라미터 수를 줄임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 입력 텐서 | 높이, 너비, 채널을 가진 이미지 데이터이며 공간 관계를 유지함 |
| 합성곱 층 | 필터를 이동 적용해 위치별 특징 맵을 생성함 |
| 활성화 함수 | 합성곱 결과에 비선형성을 부여해 복잡한 패턴을 표현함 |
| 풀링 층 | 특징 맵 크기를 줄여 연산량과 작은 위치 변화의 영향을 낮춤 |
| 분류 층 | 추출된 특징을 클래스 점수나 회귀값으로 변환함 |

```text
+--------+      +---------+      +--------+      +---------+      +--------+
| 이미지 | ---> | 합성곱  | ---> | ReLU   | ---> | 풀링    | ---> | 출력   |
+--------+      +---------+      +--------+      +---------+      +--------+
```

> 요약: CNN은 합성곱으로 국소 특징을 추출하고 풀링으로 공간 크기와 위치 민감도를 줄임.

## Ⅵ. 실무 사례

1. 이미지 분류는 데이터 증강·전이 학습을 적용하고 검증 정확도·혼동 행렬로 확인함
2. 실시간 비전 추론은 입력 해상도·채널 수를 조정하고 정확도·p95 지연으로 검증함

## Ⅶ. 결론

- CNN은 공간 지역성과 가중치 공유로 동일한 입력을 처리하는 완전연결층보다 적은 파라미터로 이미지 특징을 학습하므로 필터 크기와 해상도를 함께 조정해야 함
