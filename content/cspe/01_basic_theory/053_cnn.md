## 미리 알고가기

- 합성곱: 커널이 입력 위를 이동하며 원소별 곱과 합으로 국소 패턴을 계산하는 연산임
- 커널·필터: 이미지의 선, 모서리, 질감 같은 특징을 찾도록 학습되는 작은 가중치 행렬임
- 특징 맵: 필터가 입력에서 찾은 패턴의 위치와 강도를 담은 출력 텐서임
- 스트라이드·패딩: 필터 이동 간격과 경계 보정 방식이며 출력 크기를 결정함
- 수용 영역: 한 뉴런이 입력 이미지에서 실제로 바라보는 공간 범위임
- 풀링: 특징 맵 크기를 줄여 연산량을 낮추고 작은 위치 변화에 둔감하게 만드는 연산임
- 비전 트랜스포머(Vision Transformer): 이미지를 작은 조각으로 나누고 조각 간 중요도를 계산하는 모델임
- 완전연결 신경망(Fully Connected Network): 각 뉴런이 이전 층의 모든 출력과 연결되는 신경망임
- 텐서: 높이·너비·채널처럼 여러 축을 갖는 다차원 배열임
- 활성화 함수: 합성곱 결과를 비선형 변환해 복잡한 특징을 표현하는 함수임

## 작성 근거(검토용)

- **방향성**: CNN은 지역 연결과 가중치 공유로 이미지의 국소 특징을 적은 파라미터로 학습하는 대신, 입력 해상도와 채널 수가 늘수록 연산·메모리 비용이 커지므로 정확도와 추론 자원 제약 사이에서 구조를 조정해야 함
- **개요 구성**: 공간 구조 보존과 공유 필터를 함께 제시해 CNN의 차별점을 먼저 고정함
- **Ⅱ. 특징 선정**: 지역 연결, 가중치 공유, 계층 표현, 위치 둔감성을 서로 다른 성질로 분리함
- **Ⅲ. 비교축 선정**: 입력 처리·관계 처리 범위·주요 계산 비용은 세 구조의 고유 스펙이라 축은 유지하고, 이미지 구조 처리 요구에 따른 선택 기준은 요약 문장의 구체적 분기 조건으로 명시함
- **Ⅳ. 구조 선정**: 입력 텐서부터 출력까지 실제 CNN 블록 순서대로 배치함
- **Ⅴ. 절차 선정**: 합성곱, 활성화, 풀링, 출력의 순전파 흐름을 단계화해 구성요소 표와 연결함
- **Ⅵ. 사례 선정**: 데이터 부족과 실시간 지연은 CNN 적용을 바꾸는 대표 조건임
- **전수 검수**: 제목부터 결론까지 용어·표·도식·요약을 대조하고 수용 영역·완전연결 신경망 정의와 절 간 판단축을 일치시킴

## Ⅰ. 개요

- **정의/개념**: CNN은 이미지의 공간 구조를 유지한 채 공유 필터로 국소 특징을 계층적으로 추출하는 신경망 구조임
- **배경/필요성**: 이미지의 인접 픽셀 관계를 보존하고 파라미터를 줄이기 위해 공간 정보 처리 구조가 필요함

### 쉽게 이해하기 (학습용)
- 사진 전체를 한 번에 보지 않고 작은 창(공유 필터)을 들고 구석구석 옮겨가며 같은 방식으로 훑어보는 것과 같음

## Ⅱ. 특징

- 지역 연결로 인접 픽셀 관계를 보존해 이미지의 공간 패턴을 직접 학습함
- 가중치 공유로 같은 필터를 전체 위치에 적용해 파라미터 수와 과적합 위험을 줄임
- 하위 층은 선·모서리를, 상위 층은 객체 일부와 전체 형상을 계층적으로 학습함
- 풀링과 스트라이드로 위치 변화에 대한 민감도를 낮추고 계산량을 조절함

### 쉽게 이해하기 (학습용)
- 옆 픽셀끼리만 비교해 사진의 국소 모양을 직접 살피고, 같은 창을 사진 전체에 재사용해 도구 개수를 아낌
- 처음엔 선·모서리 같은 작은 조각을, 나중엔 조각을 모아 전체 형태를 알아보며, 조금씩 축소해가도 웬만한 위치 변화는 잘 알아챔

## Ⅲ. 종류 및 비교

| 판단 기준 | 완전연결 신경망 | CNN | Vision Transformer |
|:---|:---|:---|:---|
| 입력 처리 | 벡터 평탄화 | 공간 텐서 유지 | 패치 토큰화 |
| 관계 처리 범위 | 입력 위치별 독립 가중치 | 수용 영역 내 국소 관계 | 어텐션 기반 전역 관계 |
| 주요 계산 비용 | 입력·출력 차원 곱 연산 | 출력 위치·커널·채널 곱 연산 | 패치 수 제곱 연산 |

> 요약: 입력 위치 관계를 무시해도 되는 작은 입력은 완전연결 신경망, 인접 픽셀의 국소 패턴을 적은 파라미터로 학습하려면 CNN, 패치 간 전역 관계까지 반영하려면 Vision Transformer를 적용함.

### 쉽게 이해하기 (학습용)
- 완전연결 신경망은 사진을 한 줄로 펼쳐 낱개로 보고, CNN은 사진 형태 그대로 돋보기로 부분을 훑으며, Vision Transformer는 사진을 조각내 조각끼리 서로 얼마나 관련있는지를 비교함

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 입력 텐서 | 높이×너비×채널 공간 데이터 |
| 합성곱 계층 | 공유 커널과 스트라이드·패딩으로 국소 특징 맵을 생성하는 계층 |
| 활성화 함수 | 특징 맵에 비선형성을 부여하는 변환 |
| 풀링 계층 | 특징 맵의 공간 크기와 위치 변화 민감도를 줄이는 계층 |
| 출력층 | 클래스 점수·회귀값 산출 |

> 요약: CNN은 합성곱으로 국소 특징을 추출하고 활성화·풀링으로 비선형 표현을 압축해 출력층에서 예측값을 산출함.

### 쉽게 이해하기 (학습용)
- 원본 사진(입력 텐서)을 돋보기(합성곱 계층)로 훑어 특징을 찾고, 비틀어 강조(활성화)한 뒤 축소(풀링)해 마지막에 정답을 고름(출력층)

## Ⅴ. 원리 및 절차 흐름도

```text
입력 영역과 커널의 곱·합 → 특징 맵 생성 → 비선형 활성화
                                         ↓
                                  풀링·다음 계층 입력
                              ├─ 계층 남음 → 합성곱 반복
                              └─ 최종 계층 → 예측값 산출
```

1. **합성곱 연산**: 커널이 입력 위를 이동하며 국소 영역의 원소별 곱과 합으로 특징 맵을 계산함
2. **비선형 활성화**: 특징 맵에 활성화 함수를 적용해 선형 결합만으로는 표현하지 못하는 패턴을 학습함
3. **풀링**: 특징 맵 크기를 줄여 연산량을 낮추고 작은 위치 변화에 대한 민감도를 낮춤
4. **분류·회귀 산출**: 풀링 결과를 출력층에 전달해 클래스 점수나 회귀값을 산출함

> 요약: 합성곱과 풀링을 반복해 국소 특징을 계층적으로 압축한 뒤 출력층에서 최종 예측값을 산출함.

### 쉽게 이해하기 (학습용)
- 돋보기로 부분을 훑어 특징을 찾고, 강조하고, 줄여가는 과정을 반복하다가 마지막 단계에서 최종 판단을 내림

## Ⅵ. 실무 사례

1. PCB 불량 검사기는 합성곱 필터로 표면의 균열·누락 패턴을 추출함
2. CCTV 이벤트 탐지기는 채널 수와 특징 맵 크기를 줄여 엣지 장비에서 추론함

### 쉽게 이해하기 (학습용)
- 회로기판 검사기는 돋보기로 표면의 흠집·빠진 부분을 찾아내고, CCTV 탐지기는 작은 장비에서도 돌아가도록 돋보기와 사진 크기를 줄여서 씀

## Ⅶ. 결론

- CNN은 공유 필터로 이미지의 지역 특징을 계층적으로 찾으며, 입력 해상도와 추론 비용의 균형을 고려해야 함
- 실시간·엣지 시스템은 정확도만으로 모델을 고르지 말고 해상도·채널 수를 지연·메모리 예산에 맞춰 공동 조정해야 함

### 쉽게 이해하기 (학습용)
- CNN은 부분부분을 훑어 형태를 알아내는 방식이므로, 사진 화질을 얼마나 쓸지는 처리 속도와 저장 공간 사정을 함께 고려해 정해야 함
