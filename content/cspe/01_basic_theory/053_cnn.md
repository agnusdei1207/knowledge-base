## 미리 알고가기

- 커널: 입력 위를 이동하며 특징을 추출하는 작은 필터임
- feature map: 합성곱 결과로 생성된 특징 표현임
- pooling: 공간 크기를 줄이며 중요한 특징을 유지하는 연산임

## Ⅰ. 개요

- **정의/개념**: CNN은 합성곱 필터와 풀링을 이용해 이미지나 격자형 데이터의 국소 패턴을 계층적으로 추출하는 대표 딥러닝 구조임
- **배경/필요성**: 픽셀 간 공간 인접성이 중요한 데이터는 완전연결망보다 지역 연결과 가중치 공유가 훨씬 효율적임

## Ⅱ. 특징

- 국소 수용영역과 가중치 공유로 파라미터 수를 줄임
- 저수준 특징에서 고수준 특징으로 계층적 표현을 학습함
- 이동에 대한 부분적 불변성을 확보해 이미지 처리에 강함
- 장거리 의존성 표현은 한계가 있어 깊은 구조나 attention 보완이 필요함

## Ⅲ. 종류 및 비교

| 판단 기준 | MLP | CNN | Vision Transformer |
|:---|:---|:---|:---|
| 입력 구조 반영 | 약함 | 강함 | 강함 |
| 파라미터 효율 | 낮음 | 높음 | 데이터 의존적 |
| 지역 패턴 추출 | 약함 | 강함 | patch 단위 |
| 대표 적용 | 일반 표형 데이터 | 이미지, 영상 | 대규모 비전 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 합성곱 층 | 커널로 지역 특징을 추출하고 표현의 핵심 블록임 |
| 활성화 함수 | 비선형성을 부여하고 표현력을 높임 |
| 풀링 층 | 공간 크기를 축소하고 계산량과 과적합을 줄임 |
| 분류기 헤드 | 추출 특징을 최종 예측으로 연결하고 task-specific 출력부임 |

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 이미지입력 | --> | 합성곱추출 | --> | 풀링/압축 | --> | 분류/예측 |
+----------+     +----------+     +----------+     +----------+
```

1. **이미지입력**: 픽셀 또는 feature tensor를 입력받음
2. **합성곱추출**: 커널이 지역 패턴을 탐색함
3. **풀링/압축**: 특징 맵 크기를 줄이며 요약함
4. **분류/예측**: 최종 특징을 클래스나 값으로 변환함

## Ⅵ. 문제점 및 해결 방안

1. **깊은 네트워크는 학습이 어려움**: gradient 소실과 최적화 난도가 큼
   - **해결 방안**: residual block, batch norm을 적용하고 training loss로 검증함
2. **데이터와 연산 비용이 큼**: 고해상도 입력은 메모리 사용량이 커짐
   - **해결 방안**: data augmentation, mixed precision, 경량 모델을 사용하고 throughput로 검증함
3. **장거리 관계 표현이 약함**: 멀리 떨어진 패턴 상호작용 파악이 제한됨
   - **해결 방안**: larger receptive field, attention, hybrid 구조를 도입하고 task accuracy로 검증함

## Ⅶ. 적용 사례

- 이미지 분류: 객체 종류를 예측함, 확인 지표는 top-1/top-5 accuracy임
- 객체 탐지: 특징 맵 위에서 위치와 클래스를 함께 추정함, 확인 지표는 mAP임
- 의료 영상 판독: 병변 특징을 추출함, 확인 지표는 sensitivity와 specificity임

## Ⅷ. 결론

CNN의 핵심은 공간 구조를 파라미터 효율적으로 학습하는 데 있으므로, 모델 깊이보다 수용영역과 계산 비용 균형을 함께 설계해야 함.
