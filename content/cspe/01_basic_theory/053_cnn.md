# 053. 합성곱 신경망 CNN (Convolutional Neural Network) [출제: 120, 128회]

## Ⅰ. 개요

- **정의/개념**: 데이터의 공간 정보를 유지하면서 인접 픽셀 간의 상관관계를 추출하기 위해 합성곱(Convolution) 필터를 사용하여 특징 맵(Feature Map)을 생성하고 학습하는 신경망 구조임
- **배경/필요성**: 기존 MLP(Multi-Layer Perceptron)는 이미지 데이터를 1차원 벡터로 변환하는 과정에서 공간 정보가 손실되고 파라미터가 급증하는 문제가 있어, 지역 수용영역(Local Receptive Field)과 가중치 공유(Weight Sharing)를 활용한 효율적 구조가 필요함

## Ⅱ. 특징 및 비교

| 판단 기준 | MLP (Multi-Layer Perceptron) | CNN (Convolutional Neural Network) | Vision Transformer (ViT) |
|:---|:---|:---|:---|
| **입력 데이터** | 1차원 벡터 (Flatten) | 2/3차원 격자 데이터 (Image) | 패치(Patch) 시퀀스 |
| **핵심 연산** | 행렬 곱 (Fully Connected) | 합성곱 (Convolution) | 셀프 어텐션 (Self-Attention) |
| **특징 추출** | 전역적 가중치 학습 | 지역 패턴 탐지 및 가중치 공유 | 전역적 상관관계 학습 |
| **데이터 효율** | 낮음 (파라미터 과다) | 높음 (공간적 불변성 활용) | 매우 낮음 (대량 데이터 필수) |

> 요약: CNN은 가중치 공유를 통해 파라미터를 획기적으로 줄이면서도 이미지의 지역적 특징을 효과적으로 학습함

## Ⅲ. 구성요소/구조

- **구성요소**:
  - **Convolution Layer**: 커널(필터)이 스트라이드(Stride) 간격으로 이동하며 특징(Feature)을 추출함
  - **Activation Function (ReLU)**: 비선형성을 부여하여 복잡한 패턴 학습을 가능하게 함
  - **Pooling Layer**: 특징 맵의 크기를 줄여(Sub-sampling) 계산량을 감소시키고 위치 변화에 대한 견고성을 높임
  - **Fully Connected Layer**: 추출된 특징들을 종합하여 최종 분류(Classification) 또는 회귀를 수행함

- **구조도**:
```text
[Input Image] -> [Convolution] -> [ReLU] -> [Pooling] -> [Convolution] -> [ReLU] -> [Pooling] -> [Flatten] -> [Fully Connected] -> [Softmax]
      |               |             |          |                                                   |               |
   (32x32x3)       (Filter)     (Non-linear) (Downsample)                                        (Vector)      (Class Prob)
```

## Ⅳ. 문제점 및 개선방안

1. **[공간 정보 손실]**: 풀링(Pooling) 과정에서 세밀한 위치 정보가 사라져 정밀한 객체 탐지나 세그멘테이션에 불리함
   - **개선방안**: Dilated Convolution을 사용하거나 Skip Connection(ResNet)을 통해 저수준 특징을 보존함 (확인: IoU 지표)
2. **[데이터 부족 시 과적합]**: 복잡한 필터를 학습하기 위해 많은 양의 데이터가 필요하며, 부족 시 훈련 데이터에 편향됨
   - **개선방안**: Data Augmentation(회전, 대칭 등) 및 Transfer Learning(Pre-trained 모델 활용)을 적용함 (확인: Val-Loss)
3. **[고정된 수용 영역]**: 필터 크기가 고정되어 있어 다양한 크기의 객체를 동시에 인식하는 데 한계가 있음
   - **개선방안**: Inception 모듈과 같은 Multi-scale 필터나 Feature Pyramid Network(FPN)를 도입함 (확인: mAP)

## Ⅴ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| **이미지 분류 (Classification)** | ResNet, VGG 등을 백본으로 사용하여 사물 범주 식별 | Top-1/Top-5 Accuracy |
| **객체 탐지 (Object Detection)** | YOLO, Faster R-CNN 등에서 특징 추출기(Backbone)로 활용 | mAP (mean Average Precision) |
| **의료 영상 분석** | CT/MRI 이미지에서 병변 부위 자동 검출 및 분할(Segmentation) | Dice Coefficient, Precision/Recall |

> 요약: 실무에서는 해결하려는 태스크의 복잡도와 실시간성 요구사항에 따라 적절한 CNN 아키텍처를 선택함

## Ⅵ. 결론

CNN은 이미지 처리 분야의 혁신을 이끈 핵심 기술로, 공간 계층 구조(Spatial Hierarchy)를 통해 단순한 선에서 복잡한 형체까지 단계적으로 학습하는 능력이 탁월함. 최근에는 Transformer 기법과 결합하거나 MobileNet과 같이 경량화된 구조로 발전하고 있으며, 단순한 분류를 넘어 생성형 AI(GAN, Diffusion)의 기저 기술로도 광범위하게 활용되고 있음.
