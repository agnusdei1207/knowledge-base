## 미리 알고가기

- 합성곱 커널: 입력의 작은 영역을 훑으며 패턴을 추출하는 가중치 필터임
- 채널: 이미지의 색상 또는 특징 맵의 깊이 방향 축임
- 스트라이드: 커널이 이동하는 간격임
- 패딩: 입력 가장자리에 값을 추가해 출력 크기와 경계 정보를 조정하는 방법임
- 수용 영역: 출력 한 점이 참조하는 입력 영역의 크기임

## Ⅰ. 개요

- **정의**: CNN은 합성곱 커널을 지역 영역에 반복 적용하고 파라미터를 공유해 이미지·영상처럼 공간 구조가 있는 데이터에서 계층적 특징을 추출하는 신경망 구조임
- **배경/필요성**: 완전연결층은 이미지의 위치 관계를 반영하지 못하고 입력 크기에 따라 파라미터가 급증하므로, 지역 패턴과 위치 이동을 효율적으로 다루는 구조가 필요함
- **비유**: 작은 돋보기를 이미지 위에서 옮기며 모서리, 무늬, 객체 부분을 차례로 찾아내는 작업과 같음

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 합성곱 구조 이해 | 지역 연결, 파라미터 공유, 특징 맵 | 완전연결층과 차이 누락 |
| 영상 모델 설계 판단 | 커널, stride, padding, pooling | 출력 크기와 정보 손실 무시 |

> 요약: CNN은 공간적으로 가까운 픽셀의 패턴을 공유 커널로 추출해 파라미터 수를 줄이고 계층적 특징을 학습하는 모델임.

## Ⅱ. 특징/비교

| 판단 기준 | 완전연결 신경망·Transformer | CNN |
|:---|:---|:---|
| 공간 구조 활용 | 완전연결층은 위치 관계를 약하게 반영하고 Transformer는 attention 비용이 큼 | 지역 연결로 인접 패턴을 직접 활용함 |
| 파라미터 수 | 입력 크기가 커지면 파라미터가 크게 증가함 | 커널 공유로 파라미터 수를 효율적으로 유지함 |
| 위치 변화 대응 | 별도 설계가 없으면 작은 이동에도 민감할 수 있음 | 합성곱과 풀링으로 제한적 이동 견고성을 가짐 |
| 선택 조건 | 전역 관계나 대규모 사전학습이 중요할 때 대안이 적합함 | 이미지·영상의 지역 패턴 추출과 계산 효율이 중요할 때 적합함 |

> 요약: CNN은 지역 패턴과 파라미터 효율을 우선하는 영상·공간 데이터 처리에 적합함.

- **입력 조건**: 입력에 지역적 인접성, 채널 구조, 위치 기반 패턴이 존재해야 함
- **평가 기준**: 정확도와 함께 해상도, 지연시간, 작은 객체 성능을 확인함
- **선택 판단**: 지역 패턴 추출과 추론 효율이 전역 관계보다 중요할 때 적합함

## Ⅲ. 구성요소

```text
+------------+      +------------+      +------------+
| 입력 이미지 | ---> | 합성곱 층   | ---> | 특징 맵     |
+------------+      +------------+      +------------+
       |                  |                  |
       v                  v                  v
+------------+      +------------+      +------------+
| 커널·패딩   |      | 활성화·풀링 |      | 분류·회귀 헤드 |
+------------+      +------------+      +------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 입력 이미지 | 높이, 너비, 채널을 가진 공간 데이터이며 합성곱의 대상임 | 사진 원본 |
| 합성곱 커널 | 작은 영역을 이동하며 에지, 질감, 형태 같은 지역 패턴을 검출함 | 돋보기 필터 |
| 특징 맵 | 커널이 감지한 패턴의 위치별 반응값을 저장한 결과임 | 표시된 단서 지도 |
| 활성화·풀링 | 비선형성을 부여하고 공간 크기를 줄여 강한 특징을 요약함 | 단서 압축 |
| 분류·회귀 헤드 | 추출된 특징을 클래스, 위치, 값 예측으로 변환함 | 최종 판정기 |

> 요약: CNN은 커널로 특징 맵을 만들고 활성화·풀링으로 요약한 뒤 헤드에서 업무 목적의 예측을 수행함.

## Ⅳ. 절차

```text
+------------+      +------------+      +------------+      +------------+
| 입력 전처리 | ---> | 특징 추출   | ---> | 특징 요약   | ---> | 예측 출력   |
+------------+      +------------+      +------------+      +------------+
```

1. **입력 전처리**: 이미지 크기, 채널, 정규화, 데이터 증강 방식을 맞춤
2. **특징 추출**: 여러 합성곱 층이 저수준 에지에서 고수준 객체 부분까지 특징을 학습함
3. **특징 요약**: 풀링, stride, global average pooling으로 공간 크기와 계산량을 줄임
4. **예측 출력**: 분류, 탐지, 분할, 회귀 목적에 맞는 출력층과 손실 함수를 적용함

> 요약: CNN 절차는 이미지 입력을 계층적 특징으로 바꾸고 요약된 표현을 업무 목적의 예측으로 연결하는 흐름임.

- **산출물**: 특징 맵, 클래스 확률, 탐지 박스, 분할 마스크 등 업무별 출력임
- **검증 기준**: 도메인별 이미지 변화에도 성능이 유지되어야 함
- **운영 기록**: 입력 크기, 전처리, 증강, 모델 경량화 설정을 버전으로 관리함

## Ⅴ. 문제점

- **P1 공간 정보 손실**: 과도한 pooling이나 큰 stride는 위치 정보와 작은 객체 특징을 잃게 만들 수 있음
- **P2 데이터 편향·변형 취약성**: 학습 데이터에 없는 조명, 회전, 배경, 촬영 장비 변화가 있으면 특징 맵 반응이 달라질 수 있음
- **P3 계산·메모리 부담**: 고해상도 입력과 깊은 CNN은 합성곱 연산량과 메모리 사용량이 커져 실시간 처리에 부담이 됨

> 요약: CNN은 공간 특징 추출에 강하지만 위치 정보, 데이터 변형, 연산 비용을 관리하지 않으면 운영 성능이 흔들림.

## Ⅵ. 개선방안

- **P1 대응**: 적절한 padding, skip connection, FPN, dilated convolution을 적용해 해상도 정보를 보존함 (확인: 작은 객체·경계 성능)
- **P2 대응**: 데이터 증강, 도메인 적응, 사전학습 모델 fine-tuning으로 변형 견고성을 높임 (확인: 환경별 검증 성능)
- **P3 대응**: 경량 CNN, depthwise separable convolution, pruning, quantization을 적용함 (확인: 지연시간, FPS, 메모리 사용량)

> 요약: CNN 개선은 공간 해상도 보존, 데이터 다양성 확보, 모델 경량화를 함께 고려해야 함.

- **우선순위**: 입력 해상도와 데이터 증강 기준을 먼저 점검함
- **확인 지표**: accuracy, mAP, IoU, FPS, 메모리 사용량을 함께 사용함
- **재평가 조건**: 카메라, 조명, 해상도, 클래스 구성이 바뀌면 재검증함

## Ⅶ. 전망

- **발전 방향**: CNN은 Vision Transformer와 경쟁·결합하면서도 엣지 비전, 산업 검사, 의료 영상처럼 지역 패턴이 중요한 분야에서 계속 활용될 것임
- **기술사적 판단**: 기술사는 모델 정확도뿐 아니라 입력 해상도, 추론 지연, 데이터 증강, 운영 환경 변화를 함께 검토해야 함
- **기술사 제언**: 향후 CNN은 Transformer, 멀티모달 모델, 신경망 압축 기술과 결합해 고성능과 실시간성을 동시에 요구하는 영상 시스템에서 발전할 것임
