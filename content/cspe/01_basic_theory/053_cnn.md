## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 합성곱(Convolution)과 풀링(Pooling) 연산을 통해 데이터의 공간적 특징을 추출하는 딥러닝 모델임 |
| 배경/필요성 | 기존 완전연결층(FCN)이 2D 이미지의 공간 정보를 무시하고 파라미터를 과다 소모하는 문제 해결 |
| 출제 의도 | 필터, 스트라이드, 패딩 등 합성곱 연산의 주요 파라미터 및 공간 계층적 특징 추출 원리 평가 |

## Ⅱ. 구성요소
```text
+----------------+       +----------------+       +----------------+
| Input Image    |       | Conv + Pooling |       | Fully Connect  |
| (Pixels/RGB)   | ----> | (Feature Maps) | ----> | (Classification)|
+----------------+       +----------------+       +----------------+
```
| 필터 (Kernel) | 이미지 위를 순회하며 특징을 추출하는 가중치 행렬 | 특징 탐지기 |
| 합성곱 (Conv) | 필터와 입력 데이터 간 곱셈합을 통한 공간 특징 추출 | 도장 찍기 |
| 풀링 (Pooling)| 특성맵 크기를 줄여 연산량을 감소시키고 주요 정보 요약 | 축소 스캔 |
> 요약: CNN은 필터를 이용한 합성곱 층과 차원을 축소하는 풀링 층으로 구성됨

## Ⅲ. 절차
```text
+----------------+       +----------------+       +----------------+       +----------------+
| Padding Set    |       | Convolution    |       | Activation     |       | Pooling        |
| (Add border)   | ----> | (Extract feat) | ----> | (ReLU Apply)   | ----> | (Sub-sample)   |
+----------------+       +----------------+       +----------------+       +----------------+
```
1. 패딩 설정: 특성맵 크기 보존 및 가장자리 정보 손실 방지를 위해 패딩 추가
2. 합성곱 연산: 필터를 지정된 스트라이드 간격으로 이동시키며 지역적 특징 추출
3. 활성화 함수: 추출된 특성맵에 비선형성(ReLU 등)을 부여하여 표현력 강화
4. 풀링 연산: Max Pooling 등을 통해 공간 차원을 축소하고 이동 불변성 획득
> 요약: 합성곱 연산으로 특징을 추출하고, 활성화 및 풀링을 통해 계층적 특성맵을 생성함

## Ⅳ. 문제점
- 고정된 수용 영역: 고정 크기 필터는 객체 스케일 변화에 유연하게 대응하지 못함
- 공간적 계층 무시: Max Pooling 과정에서 위치 및 자세(Pose) 관련 세부 정보가 손실됨
- 비지역성(Non-local) 탐지 취약: 멀리 떨어진 픽셀 간의 연관성을 파악하기 어려움

## Ⅴ. 개선방안
- 단기 방안: 다양한 크기의 커널(Inception 모듈)을 병렬 적용하여 스케일 변화 대응
- 중기 방안: 위치 정보 보존을 위해 풀링 대신 캡슐 네트워크(CapsNet) 또는 스트라이드 컨볼루션 활용
- 장기 방안: 비전 트랜스포머(ViT)의 셀프 어텐션 메커니즘을 융합하여 전역적(Global) 문맥 파악

## Ⅵ. 전망
- CNN의 연산 효율성과 트랜스포머의 전역 인지 능력을 결합한 하이브리드 아키텍처로 발전함
