# 합성곱 신경망 CNN (Convolutional Neural Network)

## 1. 개요

- **정의/개념**: CNN은 합성곱 필터로 지역적 패턴을 추출하고 계층적으로 조합해 이미지·영상 같은 격자형 데이터의 특징을 학습하는 신경망 구조이다.
- **배경/필요성**: 이미지는 인접 픽셀 간 공간 구조가 중요하므로, 모든 픽셀을 완전연결로 처리하기보다 지역 수용영역과 가중치 공유를 활용하는 구조가 효율적이다.

CNN의 핵심은 필터가 위치를 이동하며 같은 패턴을 탐지한다는 점이며, 이 구조가 파라미터 효율과 공간 특징 학습으로 이어진다.

## 2. 특징 및 비교

| 구분 | MLP | CNN | Vision Transformer |
|---|---|---|---|
| 입력 구조 | 벡터 | 격자형 공간 데이터 | patch sequence |
| 주요 연산 | 완전연결 | convolution, pooling | self-attention |
| 강점 | 단순 | 지역 패턴, 가중치 공유 | 전역 관계 |
| 약점 | 공간 구조 약함 | 장거리 관계 한계 | 데이터·비용 요구 큼 |

선택 기준은 공간 구조, 데이터 규모, 계산 비용, 해석 가능성, 실시간 요구이다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| Convolution Filter | 지역 패턴 추출 커널 | 가중치 공유 |
| Feature Map | 필터 적용 결과 | 특징 위치 보존 |
| Pooling | 공간 크기 축소 | 위치 변화 견고성 |
| Activation | 비선형성 부여 | 표현력 |
| Classifier Head | 추출 특징으로 분류·회귀 | task output |

```text
+-------+      +------+      +--------+      +----------+
| Image | ---> | Conv | ---> | Pooling | ---> | Classifier |
+-------+      +------+      +--------+      +----------+
```

Conv-Pooling-Classifier 흐름이 명확해야 CNN이 단순 이미지 분류 모델이 아니라 특징 추출 구조임을 설명할 수 있다.

## 4. 문제점 및 개선방안

1. **과적합**
   - 데이터가 적고 모델이 크면 훈련 이미지에 과도하게 맞춰질 수 있다.
   - **개선방안**: data augmentation, dropout, weight decay, transfer learning을 적용한다.

2. **공간 해상도 손실**
   - pooling과 stride로 위치 정보가 사라져 작은 객체 탐지가 어려울 수 있다.
   - **개선방안**: feature pyramid, skip connection, 적절한 stride 설계를 사용한다.

3. **계산 비용**
   - 고해상도 입력과 깊은 모델은 추론 지연이 크다.
   - **개선방안**: depthwise convolution, pruning, quantization을 적용한다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| 이미지 분류 | Conv backbone으로 특징 추출 후 class 예측 | accuracy, latency |
| 결함 검사 | 제조 이미지에서 표면 결함 패턴 탐지 | recall, false alarm |
| 의료 영상 | 병변 후보 영역 특징 학습 | 민감도, 특이도 |

## 6. 결론

CNN은 공간 구조를 가진 데이터에서 지역 패턴을 효율적으로 학습하는 대표 신경망이다. 필터, feature map, pooling, classifier 흐름과 함께 과적합·해상도·추론 비용을 연결해 설명해야 모델 선택 기준이 명확해진다.
