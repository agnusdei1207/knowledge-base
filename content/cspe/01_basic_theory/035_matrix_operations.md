## 미리 알고가기

- 스칼라/벡터/행렬: 각각 단일 값, 일차원 배열, 이차원 배열 형태의 수치 데이터 구조임
- 전치($Transpose$): 행과 열의 위치를 서로 바꾸어 $A_{ij}$를 $A_{ji}$로 변환한 행렬임
- 단위 행렬($Identity$ $Matrix$): 대각 성분이 모두 1이고 나머지는 0인 정방행렬로, 곱셈의 항등원 역할을 함
- 역행렬($Inverse$): 원래 행렬과 곱했을 때 단위 행렬이 되는 행렬로, 나눗셈의 개념을 행렬에 도입한 것임

## Ⅰ. 개요

- **정의/개념**: 행렬 연산은 수치를 격자 형태로 배열한 행렬들 사이에서 정의된 덧셈, 곱셈, 전치, 역행렬 등의 산술적 절차이며, 다차원 데이터의 선형적 변화를 일괄 처리하는 수학적 도구임
- **배경/필요성**: 현대의 컴퓨터 그래픽스, 인공지능(AI), 신호 처리 등에서 대규모 데이터를 동시에 변환하고 연립방정식의 해를 효율적으로 구하기 위해 표준화된 행렬 연산 체계가 필수적임

## Ⅱ. 특징

- 행렬 곱($Matrix$ $Product$)은 앞 행렬의 열 개수와 뒤 행렬의 행 개수가 일치해야 연산이 가능하며, 결합 법칙은 성립하지만 교환 법칙은 일반적으로 성립하지 않음
- 행렬 연산을 통해 기하학적 변환(회전, 확대, 이동)을 하나의 연산으로 합성할 수 있어, 복잡한 3D 렌더링 과정을 단순화된 수식으로 제어 가능함
- 행렬의 '가역성($Invertibility$)'은 판별식($Determinant$)이 0이 아닐 때만 존재하며, 이는 해당 시스템의 해가 유일하게 존재하는지를 판단하는 기준이 됨

## Ⅲ. 종류 및 비교

| 연산 종류 | 주요 수식 | 연산 특징 | 주요 활용 |
|:---|:---|:---|:---|
| **행렬 곱** | $C = AB$ | 행과 열의 내적 결합 | 신경망 연산, 그래픽 변환 |
| **전치 (Aᵀ)** | $(A^T)_{ij} = A_{ji}$ | 행과 열의 축 대칭 변경 | 데이터 재정렬, 공분산 계산 |
| **역행렬 (A⁻¹)** | $AA^{-1} = I$ | 선형 시스템의 역변환 | 연립방정식 풀이, 최적화 |
| **행렬 분해** | $A = LU, QR$ | 행렬을 특수 행렬들로 분리 | 수치 해석, 압축, 특징 추출 |

> 요약: 곱셈은 변화를 합성하고, 전치는 관점을 바꾸며, 역행렬은 원래 상태로 되돌리는 역할을 함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 차원 ($Dimension$) | 행($m$)과 열($n$)의 크기이며, 연산 가능 여부와 결과 행렬의 형태를 결정함 |
| 원소 ($Element$) | 행렬 내의 개별 수치 데이터로, 연산의 최소 단위임 |
| 판별식 ($Det$) | 역행렬 존재 여부와 선형 변환의 부피 변화율을 나타내는 지표임 |
| 블록 행렬 | 대규모 행렬을 작은 단위로 쪼갠 구조로, 메모리 캐시 효율을 높이기 위해 사용함 |

```text
[ 행렬 곱셈 연산 구조 ]
| a b | x | e f | = | (ae+bg) (af+bh) |
| c d |   | g h |   | (ce+dg) (cf+dh) |
- 앞 행렬의 행 벡터와 뒤 행렬의 열 벡터의 내적
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 연산 가능 확인| --> | 원소별 연산 수행| --> | 결과 차원 확정| --> | 수치 안정성 검증|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **적합성 검토** — 행렬 곱이나 덧셈 등 수행하려는 연산의 정의에 맞게 피연산자들의 행과 열 차원이 일치하는지 확인함
2. **원소 연산** — 정의된 연산 규칙(내적, 전치 등)에 따라 각 위치의 원소값들을 계산하며, 대규모 연산 시 병렬 처리 유닛($GPU$)을 활용함
3. **구조 재구성** — 계산된 원소들을 결과 행렬의 차원에 맞춰 올바른 위치에 배치하여 최종 출력 행렬을 형성함
4. **품질 검증** — 역행렬이나 분해 연산의 경우 수치적 오차가 발생할 수 있으므로, 결과값의 잔차($Residual$)를 확인하여 정확도를 보정함

## Ⅵ. 실무 적용 및 유의점

1. 대규모 인공지능 모델의 학습이나 추론 시 행렬 곱셈($GEMM$) 연산이 병목이 되므로, 일반 CPU보다 병렬 연산에 최적화된 $GPU$나 $NPU$를 활용하고 메모리 접근 패턴을 개선하는 '타일링($Tiling$)' 기법을 적용하여 연산 속도를 높여야 함
2. 부동소수점 오차가 누적되기 쉬운 행렬 연산에서는 판별식이 거의 0에 가까운 '조건이 나쁜($Ill-conditioned$)' 행렬을 다룰 때 결과가 크게 왜곡될 수 있으므로, 직접적인 역행렬 계산보다는 $LU$ 분해나 $QR$ 분해와 같은 안정적인 수치 해석 기법을 권장함

## Ⅶ. 결론

- 행렬 연산은 다차원 정보를 효율적으로 처리하기 위한 표준적인 산술 체계이며, 설계자는 연산의 수학적 의미와 함께 물리적인 메모리 접근 효율 및 수치적 안정성을 종합적으로 고려하여 시스템을 설계해야 함
