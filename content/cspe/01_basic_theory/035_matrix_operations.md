## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 다수의 숫자 데이터를 직사각형 배열로 나열한 행렬 간의 덧셈, 곱셈, 전치 및 역행렬을 구하는 대수적 연산임 |
| 배경/필요성 | 선형 연립방정식의 해법, 3D 컴퓨터 그래픽스의 객체 변환, 기계학습 모델의 파라미터 최적화를 위해 필요함 |
| 출제 의도 | 행렬 곱의 조건(차원 일치)과 비가환성, 역행렬 존재 조건 및 전치의 성질에 대한 이해 평가 |

## Ⅱ. 구성요소
```text
+-------------------+       +-------------------+       +-------------------+
|  Matrix Multiply  | ----> |  Transpose (T)    | ----> |  Inverse (^-1)    |
| (Dot Product sum) |       | (Row-Col Swap)    |       | (Identity Maker)  |
+-------------------+       +-------------------+       +-------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 행렬 곱 | 앞 행렬의 행과 뒤 행렬의 열의 내적 합으로 새로운 행렬을 생성 | 재료와 레시피의 결합 |
| 전치 행렬 | 주대각선을 기준으로 행과 열의 위치를 서로 맞바꾼 행렬 | 거울에 비친 반전 형태 |
| 역행렬 | 원본 행렬과 곱했을 때 단위행렬(I)이 되게 하는 행렬 (행렬식 != 0 필요) | 곱셈의 역원(나눗셈 역할) |
> 요약: 행렬 연산은 선형 대수학의 핵심으로 차원 변환(곱), 구조 반전(전치), 연산 역변환(역행렬)을 수행함

## Ⅲ. 절차
```text
+----------------+    +----------------+    +----------------+    +----------------+
| 1. 차원 검증   | -> | 2. 연산 수행   | -> | 3. 행렬식 확인 | -> | 4. 역행렬 산출 |
+----------------+    +----------------+    +----------------+    +----------------+
```
1. 차원 검증: 행렬 곱(AB)의 경우 A의 열 개수와 B의 행 개수가 일치하는지 먼저 확인함
2. 연산 수행: 각 요소의 내적을 통해 곱셈을 수행하거나, 행과 열을 맞바꾸어 전치 행렬을 만듦
3. 행렬식 확인: 역행렬을 구하기 전 정방행렬인지, 그리고 행렬식(Determinant)이 0이 아닌지 점검함
4. 역행렬 산출: 가우스-조단 소거법이나 수반행렬을 이용하여 원본 데이터를 되돌리는 역행렬을 도출함
> 요약: 차원을 확인하여 곱과 전치를 수행하며, 행렬식 검사 후 연립방정식을 풀기 위한 역행렬을 구함

## Ⅳ. 문제점
- 높은 시간 복잡도: N x N 행렬 곱은 기본적으로 O(N^3)의 연산량이 필요하여 데이터가 커지면 병목 현상이 발생함
- 역행렬 미존재(Singular): 행렬식이 0인 특이 행렬의 경우 역행렬을 구할 수 없어 선형 시스템의 해를 유일하게 정할 수 없음

## Ⅴ. 개선방안
- 고속 알고리즘 및 병렬 처리: 스트라센(Strassen) 알고리즘으로 복잡도를 줄이고, GPU 코어(CUDA)를 활용해 행렬 곱을 대규모 병렬 처리함
- 유사 역행렬 적용: 정방행렬이 아니거나 특이 행렬인 경우 무어-펜로즈 유사 역행렬(Pseudo-inverse)을 통해 최적 근사해(최소제곱해)를 구함

## Ⅵ. 전망
- 딥러닝과 트랜스포머 모델의 성장에 따라 행렬 연산 전용 하드웨어(TPU, NPU)의 중요성이 극대화되며, 희소 행렬(Sparse Matrix) 연산 최적화 기술이 발전할 것임
