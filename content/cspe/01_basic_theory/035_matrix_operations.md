## 미리 알고가기

- 행렬: 수치를 행과 열의 2차원 배열로 배치한 자료 표현임
- 전치: 행과 열을 서로 바꾸는 연산이며 $A^T$로 표현함
- 단위 행렬: 행렬 곱의 항등원이며 대각 원소는 1이고 나머지 원소는 0임
- 역행렬: $AA^{-1}=I$를 만족하는 행렬이며 역변환을 나타냄
- 행렬식: 정방행렬의 가역 여부와 선형 변환의 부피 변화율을 나타내는 스칼라값임
- 삼각·직교 행렬 분해(LU·QR 분해): 행렬을 삼각 행렬이나 직교·상삼각 행렬로 나누어 연립방정식을 푸는 방식임
- 잔차: 계산한 해를 원래 방정식에 대입했을 때 남는 오차값임
- 그래픽 처리 장치(GPU) 타일링: 행렬을 작은 블록으로 나누어 병렬 처리량과 메모리 재사용률을 높이는 방식임

## 작성 근거(검토용)

- 행렬 곱·전치·역행렬이 키워드에 명시되어 세 연산을 비교표와 구성요소에 모두 반영함
- 특징은 행렬 곱의 차원 조건과 교환 법칙 불성립을 먼저 제시해 연산 가능 여부와 순서 영향을 구분함
- 구조 절은 내적 기반 곱셈 도식을 사용해 수식 없이 연산 의미를 보이게 함
- 덧셈·곱셈·전치·역행렬의 원리가 서로 달라 하나의 공통 절차로 묶지 않고 연산 조건과 활용을 비교함
- 행렬 계산은 데이터 이동량과 수치 안정성을 함께 검증해야 하므로 두 조건을 실무 사례에 반영함

## Ⅰ. 개요

- **정의/개념**: 행렬 연산은 행과 열로 배열한 수치를 덧셈·곱셈·전치·역행렬 등으로 계산하는 선형대수 체계임
- **배경/필요성**: 여러 벡터 변환의 반복 처리를 위해 행렬 기반 일괄 계산이 필요함

## Ⅱ. 특징

- 행렬 곱은 앞 행렬의 열 수와 뒤 행렬의 행 수가 맞아야 함
- 행렬 곱은 결합 법칙은 성립하지만 일반적으로 교환 법칙은 성립하지 않음
- 전치와 역행렬은 데이터 축 변경과 역변환을 수학적으로 표현함
- 행렬 연산은 원소 재사용률과 연속 접근 여부에 따라 메모리 전송량이 달라짐

## Ⅲ. 종류 및 비교

| 연산 | 핵심 의미 | 주요 조건 | 활용 |
|:---|:---|:---|:---|
| 덧셈 | 같은 위치 원소를 더함 | 행과 열 크기 동일 | 행렬 누적·오차 보정 |
| 곱셈 | 행 벡터와 열 벡터의 내적 | 내부 차원 일치 | 신경망·좌표 변환 |
| 전치 | 행과 열의 축을 바꿈 | 모든 행렬 가능 | 공분산·데이터 재배열 |
| 역행렬 | 변환을 되돌림 | 정방행렬·$\det(A)\neq 0$ | 연립방정식·보정 |

> 요약: 덧셈은 동일 차원, 곱셈은 내부 차원 일치, 역행렬은 가역 정방행렬 조건이 필요함.

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 차원 | 연산 가능 여부를 정하는 행·열 크기 |
| 원소 | 행렬의 개별 계산 수치 |
| 행과 열 벡터 | 곱셈 내적의 기본 단위 |
| 행렬식 | 역행렬 존재 판정 기준·부피 변화율 값 |
| 단위 행렬 | 곱셈 항등원·역행렬 검증 기준 |

```text
행렬 곱:

| a b |   | e f |   | ae+bg  af+bh |
| c d | * | g h | = | ce+dg  cf+dh |
```

> 요약: 행렬 연산은 차원에 맞춰 원소와 벡터를 계산하고 행렬식과 단위 행렬로 역연산을 검증함.

## Ⅵ. 실무 사례

1. AI 학습 플랫폼은 GPU 타일링으로 행렬 곱을 처리하고 처리량·메모리 대역폭을 확인함
2. 수치해석 라이브러리는 역행렬 대신 LU·QR 분해를 적용하고 원래 식의 잔차를 확인함

## Ⅶ. 결론

- 행렬 연산은 차원 조건을 먼저 확인하고 메모리 전송량과 수치 오차를 함께 검증해야 함
