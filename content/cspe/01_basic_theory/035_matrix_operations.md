## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 행렬 연산(Matrix Operations)은 2차원 배열 형태의 수를 더하고, 곱하고, 뒤집는(전치·역행렬) 선형대수의 기본 도구이다. 행렬 곱 $C = AB$에서 $C_{ij} = \sum_k A_{ik} B_{kj}$이며, 시간 복잡도는 단순 곱셈 $O(N^3)$, Strassen $O(N^{2.807})$이다.
> 2. **가치**: 3D 그래픽(모델 변환), AI/ML(가중치 행렬 곱 = 신경망의 핵심 연산), 데이터 과학(PCA, SVD), 물리 시뮬레이션(유한 요소법), 네트워크(인접 행렬 경로 탐색) 등 CS 전 분야의 계산 기반이다. GPU의 존재 이유 자체가 대규모 행렬 연산 가속이다.
> 3. **융합**: GPU/TPU 설계(GEMM 가속), 딥러닝(텐서 연산), 컴퓨터 그래픽스(MVP 변환 행렬), 추천 시스템(행렬 분해), 양자 컴퓨팅(유니터리 행렬) 등 행렬을 모르면 현대 CS를 이해할 수 없다.

### 🔑 핵심 용어 정리

| 용어 | 뜻 | 비유 |
|:---|:---|:---|
| **행렬(Matrix)** | $m \times n$ 크기의 2차원 수 배열. 선형 변환을 표현하는 도구 | "숫자 격자판" |
| **전치 행렬($A^T$)** | 행과 열을 뒤집은 행렬. $(A^T)_{ij} = A_{ji}$ | "엑셀 행↔열 바꾸기" |
| **역행렬($A^{-1}$)** | $A \cdot A^{-1} = I$(단위 행렬)를 만족하는 행렬. $\det(A) \neq 0$일 때만 존재 | "되돌리기(Undo)" |
| **행렬식(Determinant, $\det$)** | 정사각 행렬의 스칼라 값. 0이면 역행렬이 존재하지 않음(특이 행렬) | "넓이/부피의 스케일 팩터" |
| **단위 행렬($I$)** | 대각 원소가 1, 나머지 0인 정사각 행렬. $AI = IA = A$ | "곱셈의 1" |
| **GEMM** | General Matrix Multiply. GPU의 행렬 곱 연산 커널. 딥러닝 학습의 핵심 | "GPU의 주력 업무" |
| **희소 행렬(Sparse Matrix)** | 대부분의 원소가 0인 행렬. CSR/CSC 포맷으로 메모리 절약 | "빈 칸이 많은 표" |

## Ⅰ. 개요 및 필요성

- **개념**: 행렬은 $m \times n$ 크기의 2차원 수 배열이다. 행렬 곱 $C = AB$는 $A$가 $m \times p$, $B$가 $p \times n$일 때 $C$는 $m \times n$이며:

$$
C_{ij} = \sum_{k=1}^{p} A_{ik} \cdot B_{kj}
$$

이는 $A$의 $i$번째 행 벡터와 $B$의 $j$번째 열 벡터의 내적이다.

- **필요성**: 딥러닝의 순전파(Forward Pass)는 본질적으로 거대한 행렬 곱이다. ResNet-50 한 번 추론에 약 40억 회의 곱셈-덧셈(FMA)이 필요하며, 이것이 GPU/TPU가 행렬 곱 가속에 특화된 이유이다.

- **비유**: 행렬 곱은 **"모든 학생이 모든 과목을 시험 보는 것"**과 같다. $m$명의 학생(행)이 각각 $n$개의 과목(열)을 보되, 각 과목의 점수는 $p$개의 평가 항목(내적의 차원)을 합산하여 결정된다.

- **등장 배경 및 발전 과정**:
  1. **19세기**: Arthur Cayley가 행렬 대수를 체계화했다.
  2. **1969년**: Strassen이 행렬 곱을 $O(N^{2.807})$으로 줄이는 알고리즘을 발표했다.
  3. **현대**: NVIDIA Tensor Core는 $4 \times 4$ 행렬 곱을 1클록에 수행한다. Google TPU는 행렬 곱 전용 ASIC이다.

```text
+-----------------------------------------------------------------------+
|        행렬 곱 $C = AB$의 시각적 이해                                 |
+-----------------------------------------------------------------------+
|                                                                       |
|       B (p×n)                                                        |
|       ┌─────────┐                                                    |
|       │ b₁₁ b₁₂│                                                    |
|       │ b₂₁ b₂₂│                                                    |
|       │ b₃₁ b₃₂│                                                    |
|       └─────────┘                                                    |
|  A (m×p)         C (m×n)                                             |
|  ┌───────┐       ┌─────────┐                                        |
|  │a₁₁a₁₂a₁₃│    │ c₁₁ c₁₂│  c₁₁ = a₁₁·b₁₁ + a₁₂·b₂₁ + a₁₃·b₃₁  |
|  │a₂₁a₂₂a₂₃│    │ c₂₁ c₂₂│  → A의 행 · B의 열 = 내적(dot product) |
|  └───────┘       └─────────┘                                        |
|                                                                       |
|  연산 횟수: m × n × p 회의 곱셈 + 덧셈                              |
|  시간 복잡도: O(N³) (정사각 N×N 행렬 기준)                           |
+-----------------------------------------------------------------------+
```

**[다이어그램 해설]** 행렬 곱 $C_{ij}$는 $A$의 $i$번째 행과 $B$의 $j$번째 열의 내적이다. $N \times N$ 정사각 행렬 곱의 시간 복잡도는 $O(N^3)$이며, Strassen 알고리즘은 $2 \times 2$ 블록 분할에서 곱셈 8회를 7회로 줄여 $O(N^{2.807})$을 달성한다. 현재 이론적 하한은 $O(N^2)$이고, 최적 알고리즘은 $O(N^{2.373})$(Alman-Williams, 2021)이다.

- **📢 섹션 요약 비유**: 행렬 곱은 "전교생의 전과목 성적표를 만드는 것"입니다. 학생 수(행) × 과목 수(열) × 평가 항목(내적 차원)만큼의 계산이 필요합니다.

## Ⅱ. 아키텍처 및 핵심 원리

### 구성 요소

| 요소명 | 수식 | 시간 복잡도 | 용도 | 비유 |
|:---|:---|:---|:---|:---|
| **행렬 덧셈** | $C = A + B$ | $O(N^2)$ | 신경망 바이어스 합산 | 표 합치기 |
| **행렬 곱** | $C_{ij} = \sum A_{ik} B_{kj}$ | $O(N^3)$ | 신경망 순전파, 3D 변환 | 성적표 계산 |
| **전치** | $(A^T)_{ij} = A_{ji}$ | $O(N^2)$ | 공분산 행렬, CNN 재배치 | 행↔열 뒤집기 |
| **역행렬** | $A^{-1}$: $AA^{-1} = I$ | $O(N^3)$ | 연립방정식 풀기, 칼만 필터 | Undo 버튼 |
| **행렬식** | $\det(A)$ | $O(N^3)$ | 역행렬 존재 여부, 면적/부피 | 스케일 팩터 |

### Strassen 알고리즘 — 곱셈 횟수 줄이기

$2 \times 2$ 행렬 곱에서 단순 방법은 곱셈 8회가 필요하지만, Strassen은 7개의 중간값 $M_1 \ldots M_7$을 영리하게 정의하여 곱셈 7회 + 덧셈 18회로 줄인다:

$$
T(N) = 7T(N/2) + O(N^2) \quad \Rightarrow \quad T(N) = O(N^{\log_2 7}) \approx O(N^{2.807})
$$

- **📢 섹션 요약 비유**: Strassen은 "8번 곱할 것을 영리한 변환으로 7번만 곱하기"입니다. 1번의 절약이 재귀적으로 쌓이면 전체 복잡도가 $N^3$에서 $N^{2.807}$로 줄어듭니다.

## Ⅲ. 비교 및 연결

### 비교 1: 밀집 행렬 vs 희소 행렬

| 비교 항목 | 밀집 행렬(Dense) | 희소 행렬(Sparse) |
|:---|:---|:---|
| **0의 비율** | 적음 | 대부분 0 (99%↑) |
| **저장 방식** | 2차원 배열 | CSR, CSC, COO |
| **메모리** | $O(N^2)$ | $O(\text{nnz})$ (비영 원소 수) |
| **연산 속도** | GPU GEMM 최적화 | 희소 행렬 전용 라이브러리 |
| **대표 용도** | 딥러닝 가중치 | 그래프 인접 행렬, 추천 시스템 |

### 과목 융합 관점
- **3D 그래픽스**: Model-View-Projection 변환은 $4 \times 4$ 행렬 곱의 연쇄이다. 이동(Translation), 회전(Rotation), 크기 변환(Scaling)이 각각 행렬이며, 합성은 행렬 곱이다.
- **딥러닝**: 순전파 $Y = WX + b$에서 $W$가 가중치 행렬, $X$가 입력 행렬이다. 역전파는 $\nabla W = \delta X^T$로 전치 행렬이 사용된다.
- **양자 컴퓨팅**: 양자 게이트는 유니터리 행렬($U^{\dagger}U = I$)이며, 양자 상태 벡터에 행렬 곱을 적용하는 것이 양자 연산이다.

- **📢 섹션 요약 비유**: 행렬은 CS의 "만국 공통어"입니다. 3D 그래픽, AI, 양자 컴퓨팅 — 분야는 달라도 모두 행렬 곱으로 계산합니다.

## Ⅳ. 실무 적용 및 기술사 판단

### 실무 시나리오

1. **시나리오 — 딥러닝 학습 가속**: ResNet-50 학습에서 $O(N^3)$ 행렬 곱이 전체 연산의 90% 이상을 차지한다. NVIDIA A100 GPU의 Tensor Core는 FP16 GEMM을 312 TFLOPS로 수행하여, CPU 대비 100배 이상의 학습 속도 향상을 제공한다.

2. **시나리오 — 추천 시스템의 행렬 분해**: Netflix 추천 시스템은 사용자×영화 평점 행렬(수백만×수만, 99% 이상 결측)을 SVD 또는 ALS(Alternating Least Squares)로 분해하여 잠재 요인(latent factor)을 추출한다.

### 안티패턴
- **역행렬 직접 계산**: 연립방정식 $Ax = b$를 $x = A^{-1}b$로 풀면 수치적으로 불안정하고 느리다. 실무에서는 LU 분해, QR 분해, 또는 반복법(CG)을 사용한다.

- **📢 섹션 요약 비유**: 역행렬 직접 계산은 "나사를 망치로 박는 것"입니다. 드라이버(LU 분해)가 더 정확하고 빠릅니다.

## Ⅴ. 기대효과 및 결론

### 정량/정성 기대효과

| 구분 | CPU 행렬 곱 | GPU Tensor Core | 개선 효과 |
|:---|:---|:---|:---|
| **정량** | FP32 1 TFLOPS | FP16 312 TFLOPS | **300배↑** 처리량 |
| **정량** | ResNet-50 학습 1주일 | 8시간 | **20배** 빠른 학습 |
| **정성** | 행렬 곱 = 병목 | 하드웨어 가속으로 제거 | AI 연구 가속 |

### 참고 표준
- **Strassen (1969)**: $O(N^{2.807})$ 행렬 곱 알고리즘
- **BLAS (Basic Linear Algebra Subprograms)**: 행렬 연산 표준 API (Level 1~3)
- **cuBLAS / cuDNN**: NVIDIA GPU 행렬 연산 라이브러리

행렬 연산은 현대 CS의 "원자 연산"이다. 딥러닝, 그래픽스, 과학 계산, 양자 컴퓨팅 — 모두 행렬 곱의 효율에 의존하며, GPU/TPU는 이 연산을 가속하기 위해 탄생했다.
