## 미리 알고가기

- 행렬(Matrix): 수치를 행과 열의 2차원 배열로 배치한 자료 표현임
- 전치(Transpose): 행과 열을 서로 바꾸는 연산이며 $A^T$로 표현함
- 단위 행렬(Identity Matrix): 행렬 곱의 항등원이며 대각 원소는 1이고 나머지 원소는 0임
- 역행렬(Inverse Matrix): $AA^{-1}=I$를 만족하는 행렬이며 역변환을 나타냄
- 행렬식(Determinant): 정방행렬의 가역 여부와 선형 변환의 부피 변화율을 나타내는 스칼라값임
- LU 분해·QR 분해(LU and QR Decomposition): 행렬을 하·상삼각 행렬 또는 직교·상삼각 행렬로 분해하는 수치해석 기법임
- 잔차(Residual): 계산한 해를 원래 방정식에 대입했을 때 남는 오차값임
- 그래픽 처리 장치(GPU) 타일링: 행렬을 작은 블록으로 나누어 병렬 처리량과 메모리 재사용률을 높이는 방식임

## 작성 근거(검토용)

- **개요 구성**: 행렬 곱·전치·역행렬이 키워드에 명시되어 세 연산을 비교표와 구성요소에 모두 반영함
- **Ⅱ. 특징 선정**: 행렬 곱의 차원 조건과 교환 법칙 불성립을 먼저 제시해 연산 가능 여부와 순서 영향을 구분함
- **Ⅲ. 비교축 선정**: 덧셈·곱셈·전치·역행렬의 원리가 서로 달라 하나의 공통 절차로 묶지 않고 연산 조건과 활용을 비교함
- **Ⅳ. 구조 선정**: 내적 기반 곱셈 도식을 사용해 수식 없이 연산 의미를 보이게 함
- **Ⅵ·Ⅶ. 사례·결론 선정**: 행렬 계산은 데이터 이동량과 수치 안정성을 함께 검증해야 하므로 두 조건을 실무 사례에 반영함
- **전수 검수**: 제목부터 결론까지 용어·표·도식·요약을 대조하고 차원 조건 정의와 절 간 판단축을 일치시킴

## Ⅰ. 개요

- **정의/개념**: 행렬 연산은 행과 열로 배열한 수치를 덧셈·곱셈·전치·역행렬 등으로 계산하는 선형대수 체계임
- **배경/필요성**: 여러 벡터 변환의 반복 처리를 위해 행렬 기반 일괄 계산이 필요함

### 쉽게 이해하기 (학습용)
- 여러 사람의 성적을 한 명씩 계산하지 않고 표 전체를 한 번에 계산기에 넣어 처리하는 것과 같음

## Ⅱ. 특징

- 행렬 곱은 앞 행렬의 열 수와 뒤 행렬의 행 수가 맞아야 함
- 행렬 곱은 결합 법칙은 성립하지만 일반적으로 교환 법칙은 성립하지 않음
- 전치와 역행렬은 데이터 축 변경과 역변환을 수학적으로 표현함
- 행렬 연산은 원소 재사용률과 연속 접근 여부에 따라 메모리 전송량이 달라짐

### 쉽게 이해하기 (학습용)
- 두 사람이 손을 맞잡으려면 손의 개수가 맞아야 하듯 행렬 곱도 크기가 맞아야 하고, 순서를 바꿔 잡으면 다른 모양이 되는 것과 같음
- 표를 어떤 순서로 훑어 읽느냐에 따라 계산이 빨라지기도 느려지기도 함

## Ⅲ. 종류 및 비교

| 연산 | 핵심 의미 | 주요 조건 | 활용 |
|:---|:---|:---|:---|
| 덧셈 | 같은 위치 원소를 더함 | 행과 열 크기 동일 | 행렬 누적·오차 보정 |
| 곱셈 | 행 벡터와 열 벡터의 내적 | 내부 차원 일치 | 신경망·좌표 변환 |
| 전치 | 행과 열의 축을 바꿈 | 모든 행렬 가능 | 공분산·데이터 재배열 |
| 역행렬 | 변환을 되돌림 | 정방행렬·$\det(A)\neq 0$ | 연립방정식·보정 |

> 요약: 덧셈은 동일 차원, 곱셈은 내부 차원 일치, 역행렬은 가역 정방행렬 조건이 필요함.

### 쉽게 이해하기 (학습용)
- 표를 같은 자리끼리 더하기(덧셈), 줄과 칸을 짝지어 곱하기(곱셈), 가로세로 뒤집기(전치), 원래대로 되돌리기(역행렬)라는 네 가지 서로 다른 작업으로 구분한 것임

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 차원 | 연산 가능 여부를 정하는 행·열 크기 |
| 원소 | 행렬의 개별 계산 수치 |
| 행과 열 벡터 | 곱셈 내적의 기본 단위 |
| 행렬식 | 역행렬 존재 판정 기준·부피 변화율 값 |
| 단위 행렬 | 곱셈 항등원·역행렬 검증 기준 |

```text
행렬 곱:

| a b |   | e f |   | ae+bg  af+bh |
| c d | * | g h | = | ce+dg  cf+dh |
```

> 요약: 행렬 연산은 차원에 맞춰 원소와 벡터를 계산하고 행렬식과 단위 행렬로 역연산을 검증함.

### 쉽게 이해하기 (학습용)
- 표의 크기(차원)가 맞는지 먼저 보고, 칸 하나하나(원소)를 줄·칸 단위(벡터)로 계산하며, 뒤집을 수 있는지는 특수한 값(행렬식)으로, 기준 표(단위 행렬)와 비교해 확인함

## Ⅵ. 실무 사례

1. AI 학습 플랫폼은 행렬을 GPU 공유 메모리 크기에 맞는 타일로 나눠 곱셈함
2. 수치해석 라이브러리는 역행렬을 직접 구하지 않고 LU·QR 분해로 연립방정식을 풂

### 쉽게 이해하기 (학습용)
- 큰 표를 한 번에 다 못 옮기니 작은 조각으로 나눠 계산하고, 열쇠를 새로 깎기보다 이미 있는 분해된 부품으로 문제를 푸는 것과 같음

## Ⅶ. 결론

- 행렬 연산은 여러 값의 관계와 변환을 한 번에 표현하며, 차원 일치와 수치 오차를 함께 확인해야 함
- 대규모 계산은 역행렬을 직접 구하기보다 분해·희소 연산을 선택하고, 잔차와 조건수로 결과 신뢰도를 판단해야 함

### 쉽게 이해하기 (학습용)
- 계산기를 무작정 돌리지 말고 크기가 맞는지, 오차가 얼마나 남는지 항상 검산해야 하며, 큰 문제일수록 지름길(분해) 계산법을 쓰는 것과 같음
