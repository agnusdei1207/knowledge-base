## Ⅰ. 개요
- 정의: 수나 기호를 직사각형 형태로 배열한 행렬에 대한 산술적 처리 기법임
- 배경/필요성: 대규모 선형 방정식을 풀거나 그래픽 변환, 딥러닝 연산의 핵심 도구임
- 출제 의도: 행렬 곱의 조건, 역행렬 존재 여부(행렬식), 전치의 정의 숙지 확인

## Ⅱ. 구성요소
- ASCII 구조도 (Matrix Multi)
  [ m x n ] * [ n x p ] = [ m x p ]
    (A)         (B)         (C)
  *조건: A의 열 수 == B의 행 수*

- 구성요소 표
| 연산 종류 | 설명 | 비유 |
| :--- | :--- | :--- |
| 행렬 곱 | 앞 행렬의 행과 뒤 행렬의 열을 내적함 | 결합 연산 |
| 역행렬 | 원래 행렬과 곱했을 때 단위 행렬(I)이 됨 | 나눗셈의 역수 |
| 전치 (Transpose) | 행과 열의 위치를 서로 맞바꿈 | 뒤집기 |
| 행렬식 (Det) | 역행렬 존재 여부를 판별하는 스칼라 값 | 판별자 |
> 요약: 행렬은 데이터를 구조화하여 다차원 공간에서의 연산을 가능케 함

## Ⅲ. 절차
- ASCII 흐름도
  [Input Matrices] -> [Check Dimensions] -> [Perform Op] -> [Result]

1. 차원 검사: 수행하려는 연산이 수학적으로 가능한 크기인지 확인함
2. 행렬 곱: Sum(A[i][k] * B[k][j]) 공식을 적용하여 각 원소를 계산함
3. 가우스 소거법: 역행렬을 구하기 위해 첨가 행렬을 사용하여 행 연산을 수행함
4. 전치 수행: A[i][j] 원소를 A[j][i] 위치로 이동시켜 새로운 행렬을 구성함
> 요약: 규칙에 따른 반복적 산술 연산을 통해 최종 결과 행렬을 도출함

## Ⅳ. 문제점
- 연산량 폭증: 행렬 크기 N에 대해 곱셈은 O(N^3)의 복잡도를 가져 대형 행렬 처리 시 부하 심함
- 수치적 불안정: 행렬식이 0에 가까울 경우(Singular) 역행렬 계산 시 오차가 커짐

## Ⅴ. 개선방안
- 스트라센 알고리즘: 분할 정복을 통해 행렬 곱의 복잡도를 줄임
- GPU 병렬 처리: 수만 개의 코어를 활용하여 행렬 연산을 동시에 수행(CUDA 등)함

## Ⅵ. 전망
- 인공지능: 딥러닝의 텐서 연산은 본질적으로 대규모 행렬 연산의 집합임
- 그래픽스: 3D 모델의 이동, 회전, 투영 등 모든 변환이 4x4 행렬 곱으로 처리됨
