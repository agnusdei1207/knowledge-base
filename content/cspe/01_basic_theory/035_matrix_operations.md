## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 행렬의 덧셈·곱셈·전치·역행렬 등 선형대수 기본 연산으로, 그래픽스·ML·신호처리의 핵심 수학 도구임 |
| **배경/필요성** | 연립방정식 풀이·좌표 변환·신경망 가중치 연산 등이 행렬 연산으로 표현되며, 효율적 계산이 필수임 |
| **출제 의도** | 행렬 곱의 O(n³) 복잡도와 역행렬·전치 연산의 의미를 이해하는지 평가함 |

## Ⅱ. 구성요소
```
+----------+     +----------+     +----------+
| 행렬곱   | --> | 역행렬   | --> | 전치행렬  |
| (A×B)    |     | (A⁻¹)   |     | (Aᵀ)    |
+----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| 행렬 곱(A×B) | A의 행과 B의 열의 내적으로 결과 행렬을 구하며, O(n³)이 기본 복잡도임 | 두 표를 교차 참조하여 합산 |
| 역행렬(A⁻¹) | AA⁻¹ = I를 만족하는 행렬로, 연립방정식 Ax=b의 해 x=A⁻¹b를 구함 | 곱하면 원래대로 되돌리는 변환 |
| 전치행렬(Aᵀ) | 행과 열을 교환한 행렬로, aᵢⱼ → aⱼᵢ 변환임 | 표의 행·열 뒤집기 |

> 요약: 행렬 곱(변환 합성) + 역행렬(역변환) + 전치(축 교환)가 선형대수의 3대 기본 연산임.

## Ⅲ. 절차
```
+------------+     +------------+
| 행렬정의   | --> | 연산선택   |
| (차원확인) |     | (곱/역/전치)|
+------------+     +------------+
                        |
+------------+     +----+-------+
| 결과행렬   | <-- | 연산수행  |
| 출력       |     | (내적등)   |
+------------+     +------------+
```

1. 행렬 정의: 입력 행렬의 차원(m×n)을 확인하고 연산 적합성을 검증함(곱: A(m×k) × B(k×n))
2. 연산 선택: 곱·역·전치 등 필요한 연산을 결정함
3. 연산 수행: 행렬 곱은 행·열 내적, 역행렬은 가우스 소거법, 전치는 인덱스 교환으로 수행함
4. 결과 출력: 결과 행렬을 반환하고 필요 시 검증(AA⁻¹=I 등)을 수행함

> 요약: 차원 확인 → 연산 선택 → 수행 → 결과 검증으로 행렬 연산을 수행함.

## Ⅳ. 문제점
- O(n³) 복잡도: 기본 행렬 곱이 n³ 연산으로 대규모 행렬에서 시간이 급증함
- 수치 불안정: 역행렬 계산 시 부동소수점 오차가 누적되어 결과 정확도가 저하됨
- 메모리 사용: 대규모 밀집 행렬의 저장에 O(n²) 메모리가 필요함

## Ⅴ. 개선방안
- (단기) BLAS 활용: 하드웨어 최적화된 BLAS 라이브러리(Intel MKL·cuBLAS)를 사용함
- (중기) Strassen 알고리즘: O(n^2.807)으로 대규모 행렬 곱을 가속함
- (장기) 희소 행렬 기법: CSR·CSC 포맷으로 0이 아닌 원소만 저장·연산하여 메모리·시간을 절감함

## Ⅵ. 전망
- GPU·TPU에서 행렬 곱이 AI 학습·추론의 핵심 연산이며, Tensor Core 등 행렬 전용 하드웨어 가속기가 차세대 프로세서의 표준이 될 전망임
