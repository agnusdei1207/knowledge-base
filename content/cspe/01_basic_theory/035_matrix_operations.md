## Ⅰ. 개요
- **정의**: 행렬 간 덧셈·곱셈·전치·역행렬 등을 수행하는 선형대수 기본 연산 체계
- **배경/필요성**: 연립방정식 풀이, 좌표 변환, 데이터 변환 등 공학 전 분야에서 벡터 공간의 관계를 수치로 다루려면 행렬 연산이 필수임
- **비유**: 행렬 곱셈은 두 변환기를 직렬 연결하는 것과 같음 — 입력이 첫 변환기를 거쳐 나온 결과가 두 번째 변환기에 들어가 최종 출력을 만듦

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 행렬 곱의 조건과 복잡도 이해 | 행×열 차원 일치 조건, O(N^3) 복잡도 | 곱셈 교환법칙 불성립 명시 |
| 역행렬 존재 조건과 계산법 | det(A) ≠ 0, 가우스 소거·LU 분해 | 특이행렬(singular)일 때 역행렬 없음 |
| 대규모 연산 최적화 방안 | 스트라센 알고리즘, 희소 행렬, 병렬화 | 스트라센의 실제 적용 한계(수치 안정성) |

> 요약: 행렬 연산은 선형대수의 핵심 도구로, 차원 조건·복잡도·수치 안정성을 함께 고려해야 함

## Ⅱ. 구성요소
```text
        +-------------+
        | 행렬 연산    |
        +------+------+
               |
   +-----------+-----------+
   |           |           |
   v           v           v
+------+  +-------+  +--------+
| 기본 |  | 분해  |  | 최적화 |
| 연산 |  | 기법  |  | 기법   |
+------+  +-------+  +--------+
  |          |            |
  v          v            v
덧셈      LU 분해     스트라센
곱셈      QR 분해     희소 저장
전치      촐레스키     병렬 연산
역행렬
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 덧셈/뺄셈 | 같은 크기 행렬의 대응 원소끼리 연산, O(N^2) | 같은 크기 격자판 두 장을 겹쳐 값을 합산 |
| 곱셈 | A(m x n) · B(n x p) = C(m x p), 행과 열의 내적으로 계산, O(N^3) | 행 벡터와 열 벡터가 악수하여 하나의 값을 생성 |
| 전치 | 행과 열을 교환하여 A^T 생성, `a[i][j]` -> `a[j][i]` | 표의 가로·세로 축을 뒤집는 것 |
| 역행렬 | AA^{-1} = I를 만족하는 행렬, det(A) ≠ 0일 때만 존재 | 자물쇠(A)에 대응하는 열쇠(A^{-1}) |
| LU 분해 | 행렬을 하삼각(L)·상삼각(U)으로 분리하여 연산 효율화 | 복잡한 계산을 두 단계 간단한 계산으로 나눔 |
| 스트라센 알고리즘 | 곱셈을 분할정복하여 O(N^{2.807})로 감소 | 8번 곱할 것을 7번으로 줄이는 트릭 |
| 희소 행렬 저장 | 0이 아닌 원소만 저장(CSR, CSC 등)하여 메모리·연산 절감 | 빈 칸이 많은 표에서 채워진 칸만 기록 |

> 요약: 기본 연산·분해 기법·최적화 기법이 계층적으로 구성되어 규모별 요구에 대응함

## Ⅲ. 절차
```text
문제 정의 --> 행렬 구성 --> 연산 선택/실행 --> 결과 검증
    |             |              |                 |
    v             v              v                 v
 방정식/변환   차원 결정     곱셈/역행렬/분해    차원·수치 확인
```
- 1단계: **문제 정의** — 연립방정식, 좌표 변환 등 풀어야 할 문제를 행렬 형태(Ax = b 등)로 모델링함
- 2단계: **행렬 구성** — 입력 데이터로부터 행렬 차원과 원소를 결정하고, 희소성 여부를 판단함
- 3단계: **연산 선택/실행** — 문제 유형에 따라 곱셈·역행렬·LU 분해 등 적합한 연산을 선택하고 수행함
- 4단계: **결과 검증** — 출력 행렬의 차원 정합성, 수치 오차 범위, 역행렬이면 AA^{-1} ≈ I 여부를 확인함

> 요약: 문제 모델링부터 결과 검증까지 차원 정합성과 수치 안정성을 매 단계 확인함

## Ⅳ. 문제점
- **O(N^3) 시간복잡도**: 행렬 크기가 커질수록 곱셈·역행렬 연산 시간이 급격히 증가하여 대규모 데이터 처리에 병목 발생
- **수치 불안정성**: 부동소수점 반올림 오차가 연산 과정에서 누적되어 역행렬·연립방정식 해의 정확도가 저하됨
- **메모리 비효율**: 대부분 원소가 0인 희소 행렬을 밀집 형태로 저장하면 불필요한 메모리를 소비함

> 요약: 대규모 행렬에서 연산 시간, 수치 오차, 메모리 낭비가 동시에 발생함

## Ⅴ. 개선방안
1. **단기**: 스트라센 알고리즘(O(N^{2.807})) 적용 및 BLAS/LAPACK 등 최적화 라이브러리를 활용하여 연산 속도 개선
2. **중기**: 피벗팅(partial/full pivoting) 적용과 조건수(condition number) 기반 사전 검증으로 수치 안정성 확보
3. **장기**: CSR/CSC 희소 행렬 포맷 도입 및 GPU 병렬 연산(cuBLAS 등)으로 메모리·연산 효율을 동시에 확보

> 요약: 알고리즘 개선 → 수치 안정화 → 하드웨어 병렬화 순으로 단계적 최적화를 추진함

## Ⅵ. 전망
- **발전 방향**: 텐서 연산 확장, 양자 선형대수 알고리즘(HHL 등)에 의한 지수적 속도 향상 연구가 진행 중임
- **기술사적 판단**: 딥러닝·시뮬레이션·그래프 분석 등 행렬 연산 수요가 지속 증가하여 하드웨어·소프트웨어 공동 최적화가 핵심 과제임
- **기술사 제언**: 선형 변환(036 참조)·고유값 분해(037 참조)와 연계하여 행렬 연산을 전체 선형대수 체계 내에서 설계·평가할 역량이 필요함
