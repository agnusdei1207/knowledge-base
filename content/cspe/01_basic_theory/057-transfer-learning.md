## Ⅰ. 개요
- **정의**: 대규모 데이터로 미리 훈련된 모델의 지식을 추출하여 연관된 새로운 작업에 재사용하는 기법임.
- **배경/필요성**: 새로운 문제마다 밑바닥부터 학습하는 시간과 자원을 절약하고 적은 데이터로 높은 성능을 내기 위함.
- **출제 의도**: 사전 학습 모델의 가중치 동결과 미세 조정(Fine-Tuning)의 차이 및 적용 전략을 평가함.

## Ⅱ. 구성요소
```text
+------------------+       +------------------+       +------------------+
| Pre-trained Task | ----> | Extract Weights  | ----> | Target Task      |
| (Big Data: Image)|       | (Base Network)   |       | (Small Data: Dog)|
+------------------+       +------------------+       +------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 사전 학습 모델 | 대형 데이터로 훈련되어 범용적 특징을 지닌 모델 | 대학 전공자 |
| 가중치 동결 | 하위 층의 가중치를 고정하여 일반적 특징 파괴 방지 | 기본기 보존 |
| 파인 튜닝 | 최상단 분류기를 교체하고 전체 또는 일부를 재학습 | 실무 특화 교육 |

> 요약: 기존에 학습된 범용 가중치를 가져와 새로운 문제의 목적에 맞게 일부만 변경하여 학습함.

## Ⅲ. 절차
```text
+-------------+   +-------------+   +-------------+   +-------------+
| 1. 사전학습 |-->| 2. 분류기   |-->| 3. 가중치   |-->| 4. 파인     |
|    모델로드 |   |    교체     |   |    동결/해제|   |    튜닝     |
+-------------+   +-------------+   +-------------+   +-------------+
```
1. **사전학습 모델로드**: 대규모 데이터로 훈련된 백본 네트워크를 불러옴.
2. **분류기 교체**: 모델 최상단의 기존 연결 층을 제거하고 새 클래스 수에 맞는 헤드를 부착함.
3. **가중치 동결/해제**: 보유 데이터 양과 유사성에 따라 백본 가중치 업데이트 여부를 결정함.
4. **파인 튜닝**: 작은 학습률을 적용하여 새로운 데이터셋으로 네트워크를 재학습함.

> 요약: 미리 훈련된 백본에 새 분류기를 달고, 필요에 따라 가중치를 고정하거나 미세 조정함.

## Ⅳ. 문제점
- **도메인 불일치**: 원본 데이터와 타겟 데이터의 성격이 너무 다르면 전이 효과가 떨어짐.
- **치명적 망각**: 파인 튜닝 과정에서 기존 유용한 범용 지식을 잃어버릴 수 있음.

## Ⅴ. 개선방안
- **도메인 불일치**: (단기) 백본 상위 층 해제 / (장기) 도메인 적응 기법 적용 필요.
- **치명적 망각**: (단기) 파인 튜닝 시 학습률 최소화 / (장기) 지식 증류(Knowledge Distillation) 병행 필요.

## Ⅵ. 전망
- LLM 시대에 접어들며 프롬프트 엔지니어링, PEFT(LoRA 등) 등 효율적인 전이 학습으로 발전 중임.
