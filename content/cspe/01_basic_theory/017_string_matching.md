## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 긴 본문 텍스트 내에서 특정 패턴 문자열이 존재하는 위치를 빠르고 정확하게 찾아내는 알고리즘 기법임 |
| **배경/필요성** | 에디터 검색, 웹 크롤링, 생물정보학(DNA 서열 비교) 등 텍스트 처리의 성능 병목을 해결하기 위함 |
| **출제 의도** | 중복 검사를 회피하는 KMP의 접두사/접미사 배열과 Boyer-Moore의 후위 매칭 점프 원리를 평가함 |

## Ⅱ. 구성요소
+-------------------+      +-------------------+
|    LPS 배열(KMP)    | ---> |   Skip 테이블(BM)    |
+-------------------+      +-------------------+
           |                         |
           v                         v
+-------------------+      +-------------------+
|      비교 방향성       | <--- |   Core Mechanism  |
+-------------------+      +-------------------+

| 구성요소 | 설명 | 비유 |
|---|---|---|
| LPS 배열(KMP) | 패턴 내 가장 긴 진부분 접두사와 접미사 길이를 저장한 테이블임 | 패턴 반복 구간 메모장 |
| Skip 테이블(BM) | 불일치 발생 시 문자에 따라 건너뛸 길이를 지정하는 배열임 | 틀린 글자 전용 점프 가이드 |
| 비교 방향성 | KMP는 앞에서부터, BM은 뒤에서부터 패턴을 비교함 | 정방향 읽기와 역방향 읽기 |

> 요약: 문자열 매칭은 KMP의 LPS 배열이나 BM의 Skip 테이블을 통해 비교 방향성에 맞춰 중복 탐색을 배제함.

## Ⅲ. 절차
+-------------------+      +-------------------+
|      Step 1       | ---> |      Step 2       |
+-------------------+      +-------------------+
                                     |
+-------------------+      +---------+---------+
|      Step 4       | <--- |      Step 3       |
+-------------------+      +-------------------+

1. 전처리 테이블 생성: 패턴을 분석하여 LPS 또는 Skip 테이블을 구축함
2. 본문-패턴 정렬: 본문과 패턴의 시작 위치를 맞추어 비교를 준비함
3. 문자 비교: 정해진 방향(정방향/역방향)으로 문자를 순차 비교함
4. 건너뛰기(Shift): 불일치 시 테이블을 참조하여 탐색 인덱스를 대폭 이동시킴

> 요약: 패턴 전처리 및 테이블 생성, 초기 정렬, 문자 비교 수행, 불일치 시 스마트 점프 이동 반복임.

## Ⅳ. 문제점
- 전처리 오버헤드: 패턴이 매우 길거나 본문이 짧을 경우, 테이블 생성 비용이 매칭 비용보다 큼
- 다중 패턴 한계: 위 알고리즘들은 단일 패턴 검색용이므로 여러 키워드 동시 검색 시 비효율적임
- 문자 집합 크기(BM): 알파벳이나 유니코드처럼 문자 집합이 크면 Skip 테이블 메모리 낭비 심화

## Ⅴ. 개선방안
- (단기) 상황별 알고리즘 선택: 본문이 짧을 땐 Brute Force, 일반적으론 BM, 패턴 반복이 많으면 KMP 사용
- (중기) 다중 패턴 처리 도입: 여러 문자열 동시 탐색 시 Aho-Corasick 알고리즘(트라이 결합)으로 대체함
- (장기) 라빈-카프 병행: 해시 값을 활용한 라빈-카프 알고리즘을 혼합하여 대규모 데이터 병렬 검사 최적화

## Ⅵ. 전망
- 자연어 처리 및 대규모 바이러스 시그니처 탐지(IDS/IPS) 등에서 실시간 패턴 분석 속도를 극대화할 것임
