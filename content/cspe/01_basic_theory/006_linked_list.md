## Ⅰ. 개요
- 각 노드가 데이터와 다음 노드를 가리키는 포인터를 포함하는 선형 구조임.
- 메모리의 비연속적인 공간을 활용하여 동적 크기 조절이 용이함.
- [표] 출제 의도: 포인터 조작을 통한 동적 자료구조 운용 능력 검증.

## Ⅱ. 구성요소
- ASCII 구조도
  [ Data | Next ] -> [ Data | Next ] -> [ Data | NULL ]

| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| Node | 데이터 필드와 링크 필드의 결합체 | 기차 칸 |
| Pointer | 다음 노드의 메모리 주소 정보 | 연결 고리 |
| Head | 리스트의 첫 번째 노드를 가리킴 | 기관차 |

> 요약: 노드 간의 링크를 통해 논리적인 순서를 유지함.

## Ⅲ. 절차
- ASCII 흐름도
  Find Pos -> Create Node -> Link Change -> Memory Alloc

1. 삽입 또는 삭제할 위치를 순차적으로 탐색함.
2. 새 노드를 생성하고 데이터를 할당함.
3. 이전 노드의 Next 포인터를 새 노드로, 새 노드는 다음을 가리킴.
4. 삭제 시에는 링크를 건너뛰게 하고 해제된 노드 메모리를 반환함.

> 요약: 링크 수정만으로 구조 변경이 가능하나 탐색은 O(n)임.

## Ⅳ. 문제점
- 특정 노드에 접근하기 위해 Head부터 순회해야 하는 오버헤드 존재함.
- 포인터 저장을 위한 추가적인 메모리 공간이 소요됨.

## Ⅴ. 개선방안
- 단기: 양방향 리스트(Doubly Linked)로 역방향 탐색 효율 개선함.
- 중기: 원형 리스트(Circular) 도입으로 마지막 노드 처리 간소화함.
- 장기: 인덱싱 정보를 담은 Skip List 활용으로 탐색 속도 향상함.

## Ⅵ. 전망
- 멀티코어 환경에서 락(Lock) 경합을 제거한 비차단(Lock-free) 연결 리스트 자료구조가 고성능 병렬 시스템 구축의 핵심 성공 요인(CSF)이 될 것임.
- 메모리 파편화를 방지하기 위해 정적 풀링(Pooling) 기법과 연결 리스트를 결합한 커스텀 할당기(Allocator)가 실시간 임베디드 소프트웨어의 표준이 될 전망임.
- 데이터의 시간적/공간적 지역성을 극대화하기 위해 배열의 연속성과 리스트의 동적 연결성을 결합한 하이브리드 리스트 구조가 확대 적용될 것임.
