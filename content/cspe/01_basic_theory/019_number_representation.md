## Ⅰ. 개요
- **정의**: 정수·실수 등 수치 데이터를 이진 비트열로 변환하여 컴퓨터 내부에 저장·연산하는 표현 체계
- **배경/필요성**: 유한한 비트 폭으로 수를 표현하므로 부호 처리·범위·정밀도에 대한 표준화된 규칙이 필요함
- **비유**: 정해진 칸 수의 주판에서 음수와 소수를 표현하기 위해 칸 배치 규칙을 정하는 것과 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 보수 표현의 원리와 오버플로 판별 능력 | 2의 보수 연산 과정, 표현 범위 공식 | 1의 보수의 -0 문제와 2의 보수의 비대칭 범위를 혼동하지 말 것 |

> 요약: 유한 비트 내 부호·크기·소수 표현 규칙을 정의하는 수치 인코딩 체계임

## Ⅱ. 구성요소
```text
  Number Representation
        |
   +----+----+----+
   |         |         |
  정수 표현   실수 표현   코드 표현
   |         |         |
   +--+--+   |         |
   |  |  |   |         |
  부호 1의 2의 IEEE754  BCD
  절대 보수 보수 (020참조)
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 부호-절대값 | MSB를 부호 비트, 나머지를 크기로 사용하는 표현 — -0이 존재함 | 부호란에 +/- 기호를 적는 방식 |
| 1의 보수 | 양수의 모든 비트를 반전하여 음수를 표현 — -0이 존재하고 순환 자리올림 필요 | 거울에 비친 숫자로 음수를 나타냄 |
| 2의 보수 | 1의 보수에 1을 더해 음수를 표현 — -0 없이 하나의 덧셈기로 가감산 처리 가능 | 시계 반대 방향으로 음수를 세는 원형 수직선 |
| BCD | 십진 한 자릿수를 4비트로 인코딩하는 표현 — 금융·계측 분야에서 십진 정확도 유지에 사용 | 각 자릿수에 전용 칸 4개를 배정하는 방식 |

> 요약: 부호-절대값·1의 보수·2의 보수·BCD가 정수 및 십진 표현의 핵심 방식임

## Ⅲ. 절차
```text
  값 입력         부호 결정       크기 변환        보수 적용
  (10진수)       (양/음 판별)    (2진 변환)      (음수 처리)
    |               |               |               |
    +--10진 입력-->+--MSB 결정--->+--나눗셈 반복-->+
  십진 정수       부호 비트 설정  몫이 0될 때까지  1의/2의 보수 변환
```
- 1단계: 표현할 십진 정수를 입력받고 양수·음수를 판별함
- 2단계: 양수이면 MSB를 0, 음수이면 MSB를 1로 설정함
- 3단계: 절대값을 2로 반복 나누어 이진 크기 부분을 생성함
- 4단계: 음수의 경우 선택된 표현 방식(1의 보수: 비트 반전, 2의 보수: 비트 반전 후 +1)을 적용함

> 요약: 부호 판별 → MSB 설정 → 이진 변환 → 보수 적용의 4단계로 정수를 비트열로 인코딩함

## Ⅳ. 문제점
- 오버플로: n비트 표현 범위(`-2^(n-1)` ~ `2^(n-1)-1`)를 초과하는 연산 결과가 잘못된 값으로 저장됨
- 정밀도 손실: 고정 비트 폭의 정수 표현으로는 실수·무한소수를 표현할 수 없어 별도 부동소수점 체계가 필요함(020 참조)
- BCD 공간 비효율: 4비트 중 6개 코드(1010~1111)를 사용하지 않아 이진 대비 약 20% 저장 공간이 낭비됨

> 요약: 오버플로·실수 표현 한계·BCD 공간 낭비가 정수 표현 체계의 주요 문제임

## Ⅴ. 개선방안
1. 단기: 오버플로 검출 플래그(캐리·오버플로 비트)를 연산기에 내장하여 이상 결과를 즉시 감지함
2. 중기: 임의 정밀도 정수(BigInteger) 라이브러리를 적용하여 비트 폭 제한 없이 정수를 처리함
3. 장기: 하드웨어 수준에서 가변 폭 데이터패스를 지원하여 연산 대상에 따라 비트 폭을 동적 조정함

> 요약: 오버플로 검출·임의 정밀도 라이브러리·가변 폭 하드웨어로 표현 한계를 극복함

## Ⅵ. 전망
- 발전 방향: AI 연산에서 INT4/INT8 등 저비트 양자화와 함께 새로운 정수 표현 포맷이 부상하고 있음
- 기술사적 판단: 2의 보수 원리와 오버플로 판별은 컴퓨터 구조 기초로서 지속 출제가 예상됨
- 기술사 제언: 부동소수점(020 참조)과의 차이·연계를 함께 서술하여 수치 표현 전체 체계를 조망할 필요
