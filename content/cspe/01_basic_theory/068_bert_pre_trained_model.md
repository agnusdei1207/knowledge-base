## Ⅰ. 개요
- 정의: 트랜스포머의 인코더 구조를 활용하여 문맥을 양방향으로 이해하는 사전학습 모델임.
- 배경: 단방향 학습의 한계를 극복하고 문장의 심층적 의미를 파악하기 위해 등장함.
- 출제 의도:
| 분류 | 상세 |
| --- | --- |
| 핵심요소 | Transformer Encoder, MLM, NSP, Fine-tuning |
| 주요특징 | 양방향 문맥 파악, 전이 학습(Transfer Learning) |

## Ⅱ. 구성요소
- ASCII 구조도
 [T1] [T2] [T3]  (Output)
   |    |    |
 [Bidirectional Transformer]
   |    |    |
 [E1] [E2] [E3]  (Input)
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| MLM | 문장의 일부를 마스킹하고 맞추는 학습 | 구멍 뚫린 독서 |
| NSP | 두 문장이 이어지는 관계인지 예측 학습 | 선후 관계 파악 |
| 어텐션 | 단어 간의 상관관계를 수치화하여 집중 | 핵심 파악 |
> 요약: 양방향 셀프 어텐션을 통해 고성능 언어 이해를 수행함.

## Ⅲ. 절차
- ASCII 흐름도
[대량 코퍼스] -> [Pre-training] -> [Downstream Task] -> [Fine-tuning]
- 4단계 설명
1. 사전 학습: 위키피디아 등 대규모 데이터로 언어 일반 특성 학습함.
2. 마스킹 적용: 입력 문장의 15%를 [MASK] 토큰으로 대체함.
3. 미세 조정: 특정 목적(질의응답, 분류)에 맞춰 소량 데이터로 재학습함.
4. 결과 도출: 최종 태스크에 최적화된 성능을 확보함.
> 요약: 범용 언어 지식 학습 후 특정 업무에 맞게 조정하는 과정임.

## Ⅳ. 문제점
- 모델 파라미터가 매우 많아 연산 자원 소모가 크고 추론 속도가 느림.

## Ⅴ. 개선방안
- 단기: DistilBERT, ALBERT 등 모델 경량화 기법을 적용함.
- 중기: 지식 증류(Knowledge Distillation)를 통해 작은 모델로 전이함.
- 장기: 도메인 특화 데이터(BioBERT 등)로 사전 학습 성능을 개선함.

## Ⅵ. 전망
- 연산 효율을 극대화한 경량화(Distillation) 모델링이 실무적 CSF이며, 도메인 지식(Knowledge Graph)을 주입한 지식 증강형 BERT(K-BERT) 모델을 통해 산업 특화 인공지능의 백본(Backbone)으로 자리매김할 것임.
- 특히 검색 증강 생성(RAG) 파이프라인에서 정밀한 정보 검색 및 필터링(Retrieval) 성능을 좌우하는 핵심 인코더로서 활용 범위가 더욱 확대될 전망임.
