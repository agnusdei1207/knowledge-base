## Ⅰ. 개요
- **정의**: 데이터를 K개 폴드로 나누어 K회 훈련·검증을 교대 반복한 뒤 성능 평균을 산출하는 검증 기법
- **배경/필요성**: Hold-out 1회 분할의 데이터 편향 문제를 해결하고 일반화 성능을 신뢰 있게 추정할 필요
- **비유**: 시험을 K번 치르되 매번 다른 범위를 모의고사로 내어 실력 평균을 구하는 것

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 데이터 분할·평가 설계 능력 | K-1 훈련 + 1 검증의 K회 순환 구조 | Stratified K-Fold 미언급 감점 |
| 과적합 방지 원리 이해 | 모든 데이터가 검증에 1회씩 참여 | 시계열 데이터 미래 참조 문제 언급 필요 |

> 요약: K-Fold CV는 K회 교대 검증으로 데이터 편향 없이 일반화 성능을 추정하는 기법임

## Ⅱ. 구성요소
```text
+------------+     +---------------+     +------------+
| Full Data  |     | K-Fold Split  |     | Avg Score  |
| (N rows)   | --> | (K rotations) | --> | (Mean Acc) |
+------------+     +---------------+     +------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 폴드(Fold) | 전체 데이터를 K등분한 부분 집합 | 시험 범위 단원 |
| 훈련 세트 | K-1개 폴드를 합쳐 모델 학습에 사용하는 집합 | 공부 범위 |
| 검증 세트 | 나머지 1개 폴드로 성능을 측정하는 집합 | 모의고사 |

> 요약: 폴드·훈련 세트·검증 세트의 교대 조합으로 K회 반복 평가함

## Ⅲ. 절차
```text
+------------+     +------------+     +------------+     +------------+
| Split K    |     | Train on   |     | Validate   |     | Average    |
| Folds      | --> | K-1 Folds  | --> | on 1 Fold  | --> | K Scores   |
+------------+     +------------+     +------------+     +------------+
```

1. **분할** — 전체 데이터를 크기 균등한 K개 폴드로 무작위 분할(통상 K=5 또는 10)
2. **훈련** — i번째 반복에서 i번 폴드를 제외한 K-1개 폴드로 모델 학습
3. **검증** — 제외된 i번 폴드로 예측 후 정확도·F1 등 평가 지표 산출
4. **종합** — K회 반복 결과의 평균과 표준편차를 계산하여 최종 성능 보고

> 요약: K등분 → 교대 훈련·검증 → K회 평균으로 일반화 성능을 추정함

## Ⅳ. 문제점
- 연산 비용 K배: 모델을 K회 재학습하므로 대규모 모델에서 시간·자원 부담
- 클래스 편중 위험: 단순 무작위 분할 시 특정 폴드에 소수 클래스가 누락 가능
- 시계열 누출: 무작위 셔플이 시간 순서를 무시하여 미래 데이터로 과거를 예측하는 오류

> 요약: K배 연산·클래스 편중·시계열 누출이 K-Fold CV의 3대 약점임

## Ⅴ. 개선방안
1. 단기: 폴드별 학습을 멀티프로세스로 병렬화하여 총 훈련 시간 단축
2. 중기: Stratified K-Fold로 각 폴드 내 클래스 비율을 원본과 동일하게 유지
3. 장기: TimeSeriesSplit으로 시간 순서를 보존한 확장 윈도우 검증 적용

- 하이퍼파라미터 튜닝 과적합: CV 점수로 반복 탐색 → Nested CV(내부 CV + 외부 CV) 적용 (지표: 외부 CV 표준편차 < 2%p)

> 요약: 병렬화 → Stratified → TimeSeriesSplit으로 약점을 단계별 해소함

## Ⅵ. 전망
- 향후 발전 방향: AutoML 파이프라인의 기본 평가 프레임워크로 K-Fold·Nested CV 자동 적용
- 기술사적 판단: Hold-out 대비 신뢰도가 높아 학술·산업 표준 검증법으로 존속
- 기술사 제언: 데이터 특성(시계열·불균형 등)에 맞는 분할 전략을 반드시 선행 설계 필요
