## 미리 알고가기

- 일반화 성능: 학습에 쓰지 않은 데이터에서의 성능임
- fold: 전체 데이터를 나눈 부분집합 하나임
- 데이터 누수: 평가 시점에 학습하면 안 되는 정보가 섞이는 문제임

## Ⅰ. 개요

- **정의/개념**: K-Fold 교차 검증은 데이터를 $K$개 부분으로 나누고, 각 부분을 한 번씩 검증셋으로 사용해 모델의 일반화 성능을 반복 평가하는 방법임
- **배경/필요성**: 데이터가 적을 때 단일 train/test 분할만으로는 평가 분산이 커서 모델 선택이 불안정하므로 반복 검증이 필요함

## Ⅱ. 특징

- 제한된 데이터로 학습과 평가를 균형 있게 수행할 수 있음
- 특정 분할에 따른 우연한 성능 편차를 줄일 수 있음
- 모델 비교와 하이퍼파라미터 선택에 유용함
- 계산량이 $K$배 증가하고 시계열 데이터에는 그대로 적용하기 어렵다

## Ⅲ. 종류 및 비교

| 판단 기준 | Hold-out | K-Fold | Stratified K-Fold |
|:---|:---|:---|:---|
| 평가 반복 | 1회 | $K$회 | $K$회 |
| 클래스 비율 유지 | 보장 안 됨 | 보장 안 됨 | 보장됨 |
| 계산 비용 | 낮음 | 중간 | 중간 |
| 대표 적용 | 대용량 데이터 | 일반 모델 평가 | 불균형 분류 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 데이터 분할기 | fold를 생성하고 재현성과 공정성을 좌우함 |
| 학습 루프 | 각 fold에서 모델을 다시 학습하고 계산 비용의 원인임 |
| 평가 지표 | accuracy, F1, RMSE 등이며 평균과 분산을 함께 봐야 함 |
| 누수 방지 절차 | 스케일링, 인코딩을 fold 내부에서 수행하고 평가 신뢰성 핵심임 |


## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 데이터분할 | --> | 반복학습 | --> | 반복평가 | --> | 평균산출 |
+----------+     +----------+     +----------+     +----------+
```

1. **데이터분할**: 전체 데이터를 $K$개 fold로 나눔
2. **반복학습**: 한 fold를 제외한 나머지로 모델을 학습함
3. **반복평가**: 남겨둔 fold로 성능을 측정함
4. **평균산출**: $K$회 결과의 평균과 분산을 구함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 데이터 누수가 발생할 수 있어 전처리를 전체 데이터에 먼저 하면 평가가 부풀려짐
   - 해결방안: pipeline으로 fold 내부 전처리를 강제하고 validation gap로 검증함
2. 문제: 시간 순서 데이터에 부적합해 미래 정보가 과거 학습에 섞일 수 있음
   - 해결방안: time-series split을 사용하고 temporal leakage 여부로 검증함
3. 문제: 계산 비용이 커 대규모 모델은 학습 시간이 길어짐
   - 해결방안: stratified sampling, early stopping, subset tuning을 적용하고 total training time로 검증함

## Ⅶ. 적용 사례

- 모델 선택에서는 여러 알고리즘의 평균 성능을 비교하며, mean score와 std로 결과를 확인함
- 하이퍼파라미터 탐색에서는 grid/random search와 결합하며, best CV score로 결과를 확인함
- 불균형 데이터 분류에서는 stratified K-Fold로 클래스 비율을 유지하며, F1과 ROC-AUC로 결과를 확인함

## Ⅷ. 결론

K-Fold의 핵심은 점수 하나보다 평가의 안정성을 확보하는 데 있으므로, 평균 성능과 함께 분산과 누수 여부를 같이 봐야 함.
