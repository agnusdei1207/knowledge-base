## 미리 알고가기

- 일반화 성능(Generalization): 학습에 쓰지 않은 데이터에서 모델이 보이는 예측 성능임
- 홀드아웃(Hold-out): 데이터를 훈련용과 검증용으로 한 번만 나누는 평가 방식임
- 폴드(Fold): 전체 데이터를 $K$개로 나눈 부분 집합 하나임
- 데이터 누수(Data Leakage): 검증 데이터 정보가 학습 과정에 섞여 평가가 부풀려지는 현상임
- 층화 추출(Stratification): 분류 데이터의 클래스 비율을 각 폴드에 비슷하게 유지하는 방식임
- 평균제곱근오차(RMSE): 예측 오차 제곱의 평균에 제곱근을 적용한 회귀 평가 지표임
- 시계열 분할: 과거 데이터로 학습하고 이후 데이터로 검증해 시간 순서를 보존하는 방식임

## 작성 근거(검토용)

- 기출 키워드의 핵심을 일반화 성능 평가로 정의해 모델 학습 기법과 구분함
- 홀드아웃·층화 K-Fold·시계열 분할을 비교해 실제 선택 조건을 드러냄
- 데이터 누수는 교차 검증의 대표 실패 원인이므로 선행 용어·특징·사례에 반영함
- 평균만 사용하면 안정성을 놓치므로 표준편차와 최저 점수를 집계 지표에 포함함
- 시계열은 무작위 분할을 적용하면 안 되는 대표 사례라 별도 제시함

## Ⅰ. 개요

- **정의/개념**: K-Fold 교차 검증은 데이터를 $K$개 폴드로 나눠 순환 검증하는 일반화 성능 평가 기법임
- **배경/필요성**: 데이터가 적거나 분할별 성능 편차가 클 때 일반화 성능을 판단하기 위해 반복 검증이 필요함

## Ⅱ. 특징

- 모든 표본이 학습과 검증에 모두 참여하므로 특정 분할에 따른 성능 편차를 줄임
- $K$번의 점수 평균과 표준편차를 함께 보아 성능 수준과 안정성을 동시에 판단함
- 학습을 $K$번 반복하므로 단순 홀드아웃보다 계산 비용이 높음
- 전처리·하이퍼파라미터를 전체 데이터에서 미리 추정하면 데이터 누수로 검증 점수가 과대평가됨

## Ⅲ. 종류 및 비교

| 판단 기준 | 홀드아웃 | K-Fold | 층화 K-Fold | 시계열 분할 |
|:---|:---|:---|:---|:---|
| 분할 메커니즘 | 단일 훈련-검증 분할 | 검증 폴드 순환 | 클래스 비율 유지 순환 | 과거 학습 후 미래 검증 |
| 학습 반복 범위 | 1회 학습 | $K$회 반복 학습 | $K$회 비율 유지 학습 | 시간 구간별 반복 학습 |
| 주요 리스크 | 분할 편향 | 전처리 누수 | 동일 개체 누수 | 미래 정보 누수 |

> 요약: 분할 횟수, 클래스 비율, 시간 순서를 기준으로 검증 방식을 선택함.

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 폴드 집합 | 서로 겹치지 않는 $K$개 표본 묶음 |
| 훈련 폴드 | $K-1$개 학습 데이터 |
| 검증 폴드 | 회차별 1개 평가 데이터 |
| 회차별 점수 | 검증 폴드의 일반화 성능 |
| 집계 지표 | $K$개 점수 평균·표준편차 |

```text
1회차: [검증] [학습] [학습] [학습] [학습]
2회차: [학습] [검증] [학습] [학습] [학습]
3회차: [학습] [학습] [검증] [학습] [학습]
4회차: [학습] [학습] [학습] [검증] [학습]
5회차: [학습] [학습] [학습] [학습] [검증]
```

> 요약: K-Fold는 검증 폴드를 순환해 모든 표본을 평가하고 점수를 평균·표준편차로 집계함.

## Ⅴ. 원리 및 절차 흐름도

```text
데이터를 $K$개 폴드로 분할 → 검증 폴드 1개 선택
                                  ↓
나머지 폴드로 학습 → 검증 점수 저장
                         ├─ 미평가 폴드 있음 → 검증 폴드 교체
                         └─ $K$회 완료 → 평균·표준편차 집계
```

1. **데이터 분할**: 독립 표본은 셔플해 $K$개 폴드로 나누고, 시계열은 시간 순서를 유지함
2. **반복 학습**: 한 폴드를 검증용으로 남기고 나머지 폴드에서 전처리와 모델 학습을 수행함
3. **반복 평가**: 검증 폴드를 바꿔가며 $K$번 성능을 측정하고 각 점수를 기록함
4. **점수 집계**: 평균·표준편차·최저 점수로 모델을 선택함

> 요약: 교차 검증 점수는 평균뿐 아니라 표준편차와 최저 성능을 함께 보아야 안정성을 판단함.

## Ⅵ. 실무 사례

1. 장애 티켓 분류 파이프라인은 폴드 내부에서 전처리를 학습하고, 클래스별 F1의 평균·표준편차로 모델 배포 여부를 정함
2. 서버 부하 예측기는 시간 순서 분할을 적용하고, 구간별 RMSE와 과소 예측률로 오토스케일링 여유 용량을 조정함

## Ⅶ. 결론

- K-Fold는 분할 편차를 줄이는 검증 기법이므로 계산 비용·데이터 누수를 고려해야 함
- 시간·사용자·장비 단위의 상관이 있으면 무작위 분할을 배제하고 실제 배포 경계를 보존하는 검증 방식으로 바꿔야 함
