## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 전체 데이터를 K개의 폴드로 나누어 번갈아 가며 훈련과 검증을 반복해 성능을 평가하는 기법임 |
| 배경/필요성 | 한정된 데이터로 인한 과적합 방지 및 모델 평가 결과의 일반화 성능 확보 필요 |
| 출제 의도 | 데이터 분할 방식의 이해와 모델의 통계적 성능 편차를 줄이는 검증 기법 적용 능력 평가 |

## Ⅱ. 구성요소
```text
+----------------+       +----------------+       +----------------+
| Full Dataset   |       | K Folds Split  |       | Train & Val    |
| (N records)    | ----> | (K-1 Train)    | ----> | Iterations     |
+----------------+       +----------------+       +----------------+
```
| Fold (폴드) | 전체 데이터를 K개로 나눈 각 부분집합 | 분임 토의 조 |
| 훈련 세트 | K-1개의 Fold로 구성되어 모델 학습에 사용 | 예습 및 연습 |
| 검증 세트 | 1개의 Fold로 구성되어 모델 성능 평가에 사용 | 실전 모의고사 |
> 요약: K-Fold는 전체 데이터를 폴드로 분할하고, 훈련과 검증 세트를 교대하며 구성됨

## Ⅲ. 절차
```text
+----------------+       +----------------+       +----------------+       +----------------+
| Data Splitting |       | Model Training |       | Validation     |       | Average Perf.  |
| (K subsets)    | ----> | (On K-1 folds) | ----> | (On 1 fold)    | ----> | (Final Score)  |
+----------------+       +----------------+       +----------------+       +----------------+
```
1. 분할: 전체 데이터셋을 크기가 같은 K개의 폴드(Fold)로 무작위 분할
2. 훈련: K-1개의 폴드를 합쳐 훈련 데이터로 사용하여 모델 학습
3. 검증: 나머지 1개의 폴드를 검증 데이터로 사용하여 성능 평가 지표 측정
4. 종합: 위 2~3 과정을 K번 반복한 후, K개의 성능 지표 평균을 내어 산출
> 요약: 데이터를 K개로 분할하고 학습/평가를 K회 반복한 후 성능 평균을 도출함

## Ⅳ. 문제점
- 연산 비용 증가: 모델 학습을 K번 반복해야 하므로 훈련 시간이 K배로 소요됨
- 클래스 불균형 무시: 무작위 분할 시 특정 폴드에 클래스가 편중될 위험 존재
- 시계열 분할 제약: 시계열 데이터에서는 순서가 무작위로 섞여 미래 참조 발생 가능

## Ⅴ. 개선방안
- 단기 방안: 병렬 처리(Multiprocessing)를 통해 K개의 폴드 학습을 동시 수행
- 중기 방안: 층화 추출을 적용한 Stratified K-Fold를 사용하여 클래스 비율 유지
- 장기 방안: Time Series Split 방식 등 데이터 순서를 보존하는 검증 기법 도입

## Ⅵ. 전망
- AutoML의 핵심 평가 기준으로 정착하였으며 Hold-out 방식과 결합한 하이브리드 검증으로 사용됨
