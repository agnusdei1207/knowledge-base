## 미리 알고가기

- 일반화 성능($Generalization$): 학습에 쓰지 않은 데이터에서 모델이 보이는 예측 성능임
- 홀드아웃($Hold-out$): 데이터를 훈련용과 검증용으로 한 번만 나누는 평가 방식임
- 폴드($Fold$): 전체 데이터를 $K$개로 나눈 부분 집합 하나임
- 데이터 누수($Data$ $Leakage$): 검증 데이터 정보가 학습 과정에 섞여 평가가 부풀려지는 현상임
- 층화 추출($Stratification$): 분류 데이터의 클래스 비율을 각 폴드에 비슷하게 유지하는 방식임

## Ⅰ. 개요

- **정의/개념**: K-Fold 교차 검증은 데이터를 $K$개 폴드로 나누고 각 폴드를 한 번씩 검증 세트로 사용해 모델의 일반화 성능을 평균 평가하는 검증 기법임
- **배경/필요성**: 작은 데이터와 분할 편차에서도 모델 성능을 신뢰하기 위해 반복 검증 기준이 필요함

## Ⅱ. 특징

- 모든 샘플이 학습과 검증에 모두 참여하므로 특정 분할에 따른 성능 편차를 줄임
- $K$번의 점수 평균과 표준편차를 함께 보아 성능 수준과 안정성을 동시에 판단함
- 학습을 $K$번 반복하므로 단순 홀드아웃보다 계산 비용이 높음
- 전처리와 튜닝이 폴드 밖에서 수행되면 데이터 누수로 검증 점수가 과대평가됨

## Ⅲ. 종류 및 비교

| 기준 | 홀드아웃 | K-Fold | Stratified K-Fold | Time Series Split |
|:---|:---|:---|:---|:---|
| 평가 횟수 | 1회 | $K$회 | $K$회 | 시간 구간 수만큼 반복 |
| 데이터 활용 | 일부 검증 고정 | 모든 데이터 검증 참여 | 클래스 비율 유지 | 과거로 미래 검증 |
| 적합 조건 | 대용량 데이터 | 중소규모 데이터 | 클래스 불균형 분류 | 시계열 데이터 |
| 주요 위험 | 분할 편차 영향 | 계산 비용 증가 | 누수 시 비율 유지 무의미 | 무작위 셔플 금지 |

> 요약: 데이터 규모, 클래스 비율, 시간 순서에 따라 검증 분할 방식을 달리 선택함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 전체 데이터 | 폴드로 나뉘는 원천 데이터이며 중복과 누수를 먼저 제거해야 함 |
| 훈련 폴드 | 각 반복에서 $K-1$개 폴드가 모델 학습에 사용됨 |
| 검증 폴드 | 각 반복에서 1개 폴드가 성능 측정에 사용됨 |
| 파이프라인 | 전처리, 특징 추출, 모델 학습을 폴드 내부에서 동일하게 수행함 |
| 집계 지표 | $K$개 점수의 평균과 표준편차로 최종 성능을 요약함 |

```text
1회차: [검증] [학습] [학습] [학습] [학습]
2회차: [학습] [검증] [학습] [학습] [학습]
3회차: [학습] [학습] [검증] [학습] [학습]
4회차: [학습] [학습] [학습] [검증] [학습]
5회차: [학습] [학습] [학습] [학습] [검증]
```

> 요약: K-Fold는 검증 폴드를 순환시켜 모든 샘플이 한 번씩 일반화 평가에 쓰이게 함.

## Ⅴ. 원리 및 절차 흐름도

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 데이터 분할 | --> | 반복 학습 | --> | 반복 평가 | --> | 점수 집계 |
+-----------+     +-----------+     +-----------+     +-----------+
```

1. **데이터 분할** — 전체 데이터를 셔플한 뒤 $K$개 폴드로 나누고 재현성을 위해 난수 시드를 고정함
2. **반복 학습** — 한 폴드를 검증용으로 남기고 나머지 폴드에서 전처리와 모델 학습을 수행함
3. **반복 평가** — 검증 폴드를 바꿔가며 $K$번 성능을 측정하고 각 점수를 기록함
4. **점수 집계** — 평균, 표준편차, 최저 점수를 함께 확인해 모델 선택과 튜닝 기준으로 사용함

> 요약: 교차 검증 점수는 평균뿐 아니라 분산과 최저 성능을 함께 보아야 안정성을 판단함.

## Ⅵ. 실무 적용 및 유의점

1. 스케일링, 결측치 대체, 특징 선택을 전체 데이터에 먼저 적용하면 데이터 누수가 생기므로 각 폴드 내부 파이프라인에서만 학습 기준을 계산함
2. 시계열 수요 예측에서는 미래 정보가 과거 학습에 섞이면 안 되므로 무작위 K-Fold 대신 시간 순서를 유지하는 분할로 검증함

## Ⅶ. 결론

- K-Fold 교차 검증은 분할 편차를 줄이는 평가 기법이므로 계산 비용과 데이터 누수 통제를 함께 고려해야 함

## 작성 근거(검토용)

- 기출 키워드의 핵심을 일반화 성능 평가로 정의해 모델 학습 기법과 구분함
- 홀드아웃, 층화 K-Fold, 시계열 분할을 비교해 실제 선택 조건을 드러냄
- 데이터 누수는 교차 검증의 대표 실패 원인이므로 미리 알고가기, 특징, 유의점에 반복 반영함
- 평균만 사용하면 안정성을 놓치므로 표준편차와 최저 점수를 집계 지표에 포함함
- 시계열은 무작위 분할을 적용하면 안 되는 대표 사례라 실무 유의점에 별도 제시함
