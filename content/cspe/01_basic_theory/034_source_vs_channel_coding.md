## 미리 알고가기

- 소스 코딩(Source Coding): 정보원의 중복을 제거해 전송 비트 수를 줄이는 부호화임
- 채널 코딩(Channel Coding): 잡음 오류를 검출·정정하도록 중복 비트를 추가하는 부호화임
- 엔트로피(Entropy): 소스 코딩이 도달하려는 평균 비트 수의 하한임
- 채널 용량(Channel Capacity): 주어진 채널에서 오류 확률을 충분히 낮춰 전송할 수 있는 정보율 상한임
- 코드율(Code Rate): 전체 코드 비트 중 실제 정보 비트가 차지하는 비율임

## 작성 근거(검토용)

- **개요 구성**: 129회 기출 비교 키워드이므로 두 기술의 목적·중복 처리·이론 한계를 같은 축으로 배열함
- **Ⅱ·Ⅲ. 특징·비교축 선정**: 031번 정보이론과 겹치지 않도록 실제 부호화 계층과 송수신 순서를 중심으로 작성하고, 압축과 오류 정정의 상충은 비교표의 판단 기준을 운영 조건으로 연결함
- **Ⅳ. 구조 선정**: 송신·수신 파이프라인을 따라 배치해 부호화와 복호 순서가 보이게 함
- **Ⅶ. 결론 선정**: 두 기술 중 우열이 아니라 압축 이득과 오류 보호 비용의 조정이라는 출제 의도를 정리함
- **전수 검수**: 제목부터 결론까지 용어·표·도식·요약을 대조하고 소스·채널 코딩 정의와 절 간 판단축을 일치시킴

## Ⅰ. 개요

- **정의/개념**: 소스 코딩은 중복 제거로 비트 수를 줄이고 채널 코딩은 중복 비트 추가로 오류를 검출·정정하는 부호화 계층임
- **배경/필요성**: 제한된 대역폭에서 전송 효율과 복원 신뢰성 확보를 위해 압축과 오류 제어 부호화가 필요함

### 쉽게 이해하기 (학습용)
- 편지를 짧게 줄여 쓰는 일과 그 편지가 비에 젖지 않도록 비닐로 감싸는 일이 순서대로 함께 필요한 것과 같음

## Ⅱ. 특징

- 소스 코딩은 불필요한 중복을 제거해 평균 비트 수를 낮춤
- 채널 코딩은 의도적 중복을 추가해 오류를 검출·정정함
- 두 방식의 이론 기준은 각각 엔트로피와 채널 용량임
- 압축률과 코드율은 종단 지연과 처리량 조건에 맞춰 조정해야 함

### 쉽게 이해하기 (학습용)
- 한쪽은 짐을 최대한 가볍게 줄이는 역할, 다른 쪽은 일부러 완충재를 더 넣어 무겁게 만드는 역할로 서로 반대 방향의 일을 함
- 배송 시간과 트럭 크기 같은 상황에 따라 얼마나 줄이고 얼마나 감쌀지 조절함

## Ⅲ. 종류 및 비교

| 판단 기준 | 소스 코딩 | 채널 코딩 |
|:---|:---|:---|
| 처리 목적 | 전송 비트 수 감소 | 전송 오류 제어 |
| 중복 처리 | 통계적 중복 제거 | 오류 복구용 중복 추가 |
| 이론 한계 | 엔트로피 기반 평균 코드 길이 하한 | 채널 용량 기반 정보율 상한 |

> 요약: 소스 코딩은 비트를 줄이고, 채널 코딩은 남은 비트를 보호함.

### 쉽게 이해하기 (학습용)
- 짐 줄이기 담당과 포장 보강 담당이 서로 다른 목표(가볍게 vs 안전하게)와 다른 기준(최소 크기 vs 최대 보호)으로 일하는 것과 같음

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 정보원 | 통계적 중복을 가진 원본 메시지 |
| 소스 부호기 | 정보원의 통계적 중복을 제거해 전송 비트 수를 줄이는 부호기 |
| 채널 부호기 | 전송 오류 검출·정정을 위한 중복 비트를 생성하는 부호기 |
| 잡음 채널 | 전송 오류를 만드는 잡음 매체 |
| 복호 체인 | 채널 오류 정정·소스 압축 해제 경로 |

```text
송신: 정보원 -> 소스 부호기 -> 채널 부호기 -> 잡음 채널
수신: 수신기 <- 소스 복호기 <- 채널 복호기 <- 수신 신호
```

> 요약: 송신 측은 압축·오류 보호 후 전송하고 수신 측은 역순으로 원본을 복원함.

### 쉽게 이해하기 (학습용)
- 짐을 싸는 사람(소스 부호기)과 포장을 보강하는 사람(채널 부호기)이 순서대로 일한 뒤 험한 배송길(잡음 채널)을 거치고, 받는 쪽은 반대 순서로 다시 풀어보는 것과 같음

## Ⅵ. 실무 사례

1. 객체 스토리지는 원본 데이터를 압축한 뒤 복구용 이레이저 코딩 블록을 추가함
2. 실시간 미디어 플랫폼은 영상을 압축하고 손실 구간 복구를 위한 FEC 패킷을 덧붙임

### 쉽게 이해하기 (학습용)
- 저장소는 파일을 줄인 뒤 복구용 여분 조각을 따로 보관하고, 화상통화는 영상을 압축한 뒤 끊김에 대비한 보충 데이터를 함께 보내는 것과 같음

## Ⅶ. 결론

- 소스 코딩은 중복을 줄이고 채널 코딩은 오류 복구용 중복을 더하며, 전송 환경에 맞춰 두 비율을 조정해야 함
- 종단 서비스는 압축률·코드율을 개별 튜닝하지 말고 대역폭·복구율·지연 SLA를 하나의 예산으로 관리해야 함

### 쉽게 이해하기 (학습용)
- 짐을 얼마나 줄이고 포장을 얼마나 보강할지 따로 정하지 말고, 트럭 용량과 배송 시간이라는 하나의 예산 안에서 함께 맞추는 것과 같음
