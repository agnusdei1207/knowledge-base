## 미리 알고가기

- 소스 코딩($Source$ $Coding$): 데이터의 중복을 제거하여 압축하는 과정이며, 전송할 비트 수를 줄이는 것이 목적임
- 채널 코딩($Channel$ $Coding$): 전송 중 발생하는 오류를 복구하기 위해 의도적으로 중복 정보를 추가하는 과정임
- 중복성($Redundancy$): 데이터 내의 불필요한 정보(소스 코딩 대상) 또는 오류 정정을 위해 추가된 정보(채널 코딩 결과)임
- 분리 정리($Separation$ $Theorem$): 섀넌이 증명한 정리로, 소스 코딩과 채널 코딩을 각각 독립적으로 설계해도 최적의 효율을 얻을 수 있음을 의미함

## Ⅰ. 개요

- **정의/개념**: 소스 코딩은 정보원이 생성한 메시지의 엔트로피에 맞춰 불필요한 데이터를 제거하는 '압축' 기술이며, 채널 코딩은 채널의 잡음에 대비하여 수신 측에서 오류를 정정할 수 있도록 비트를 추가하는 '보호' 기술임
- **배경/필요성**: 한정된 통신 자원(대역폭, 전력) 하에서 데이터를 최대한 많이 보내면서도(효율성), 전송 과정에서의 손실 없이 정확하게 복원(신뢰성)하기 위한 이율배반적인 문제를 해결하기 위해 두 단계의 부호화 과정이 필요함

## Ⅱ. 특징

- 소스 코딩은 데이터의 통계적 특성(빈도)이나 지각적 특성(손실 압축)을 이용하여 비트당 평균 정보량을 최소화하며, 이론적 한계는 엔트로피임
- 채널 코딩은 코드워드 사이의 해밍 거리를 넓혀 전송률($R$)을 채널 용량($C$) 이내로 유지하며 오류 정정 능력을 부여하며, 이론적 한계는 섀넌 한계임
- 두 코딩은 정보의 '중복 제거'와 '중복 추가'라는 정반대의 메커니즘을 가지지만, 전체 시스템의 '굿풋($Goodput$)'을 극대화한다는 공통의 목표를 지님

## Ⅲ. 종류 및 비교

| 판단 기준 | 소스 코딩 (Source) | 채널 코딩 (Channel) |
|:---|:---|:---|
| **주요 목적** | 데이터 압축 (효율성) | 오류 제어 (신뢰성) |
| **중복성 처리** | 불필요한 중복 제거 | 인위적인 중복 추가 |
| **핵심 지표** | 압축률, 신호대 왜곡비 ($SNR$) | 비트 오류율 ($BER$), 부호 이득 |
| **이론적 한계** | 엔트로피 ($H$) | 채널 용량 ($C$) |
| **대표 기술** | Huffman, Arithmetic, MPEG | Hamming, LDPC, Polar, Reed-Solomon |

> 요약: 소스 코딩은 정보를 가볍게 만들고, 채널 코딩은 정보에 갑옷을 입히는 과정임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 정보원 ($Source$) | 메시지를 생성하는 원천이며, 통계적 규칙성을 가질수록 소스 코딩의 이득이 커짐 |
| 소스 부호기 | 중복 데이터를 제거하여 비트 스트림을 엔트로피 한계까지 압축함 |
| 채널 부호기 | 압축된 데이터에 패리티 또는 검사 비트를 추가하여 부호의 최소 거리를 확보함 |
| 복호기 (분리 구조) | 수신 측에서 먼저 채널 복호로 오류를 잡고, 그 다음 소스 복호로 원본을 복원함 |

```text
[ 통신 시스템의 부호화 계층 ]
(송신) 정보원 -> [소스 부호기] -> [채널 부호기] -> 전송로
(수신) 복원원 <- [소스 복호기] <- [채널 복호기] <- 수신로
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 데이터 압축  | --> | 잉여 비트 추가| --> | 잡음 채널 통과| --> | 오류 정정/복원|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **소스 인코딩** — 데이터의 발생 확률을 분석하여 자주 나타나는 기호에는 짧은 비트를 부여하는 등의 방식으로 중복을 제거함
2. **채널 인코딩** — 압축된 비트 스트림에 채널 특성(잡음 등)을 고려한 오류 정정 부호($FEC$)를 결합하여 코드워드를 생성함
3. **전송 및 감지** — 변조 과정을 거쳐 채널로 전송되며, 수신 측은 들어온 신호에서 신드롬 등을 계산하여 오류 발생 지점을 포착함
4. **계층적 복호** — 채널 복호기가 물리적 오류를 수정하면, 소스 복호기가 압축을 풀어 최종적인 원본 메시지를 수신자에게 전달함

## Ⅵ. 실무 적용 및 유의점

1. 압축률을 극대화한 소스 코딩 데이터는 비트 하나만 틀려도 전체 프레임이 깨지는 '오류 전파($Error$ $Propagation$)'에 취약하므로, 반드시 강력한 채널 코딩(예: 5G의 $LDPC$)을 병행하여 전송 안정성을 담보해야 함
2. 실시간성이 중요한 음성/영상 통화 서비스에서는 지연 시간을 줄이기 위해 소스 코딩과 채널 코딩을 개별적으로 최적화하기보다, 네트워크 상황에 따라 압축률과 오류 정정 강도를 동시에 조절하는 '결합 소스-채널 코딩($JSCC$)' 기법을 고려해야 함

## Ⅶ. 결론

- 소스 코딩과 채널 코딩은 현대 디지털 통신의 효율성과 신뢰성을 지탱하는 두 개의 기둥이며, 설계자는 섀넌의 분리 정리에 기반한 개별 최적화와 실제 환경의 제약을 고려한 결합 설계를 적절히 안배하여 최적의 통신 품질을 달성해야 함
