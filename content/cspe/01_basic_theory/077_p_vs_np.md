## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 다항 시간 내에 '해결'할 수 있는 문제 집합(P)과, 다항 시간 내에 답을 '검증'할 수 있는 문제 집합(NP)의 일치 여부를 묻는 핵심 난제임. |
| 배경/필요성 | 어떤 문제가 근본적으로 컴퓨터로 빠르게 풀 수 있는지 한계를 규명하고 효율적 알고리즘 설계의 기준 제시. |
| 출제 의도 | 결정론적 알고리즘(P)과 비결정론적 알고리즘(NP)의 차이 및 NP-완전성(NP-Complete) 개념 평가. |

## Ⅱ. 구성요소
```text
+-----------+    +-----------+    +-----------+
|  P Class  | -> | NP Class  | -> | NP Complet|
+-----------+    +-----------+    +-----------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| P 클래스 문제 | 결정론적 튜링 기계로 다항 시간(Polynomial Time) 내에 해결 가능 | 쉬운 문제 |
| NP 클래스 문제 | 비결정론적 튜링 기계로 다항 시간 내에 정답 여부를 검증 가능 | 증명 가능한 문제 |
| NP-완전성 | 모든 NP 문제가 다항 시간 내에 환원될 수 있는 가장 어려운 문제군 | 최종 보스 |

> 요약: 문제의 계산 복잡도를 다항 시간 해결성과 검증 가능성을 기준으로 분류하여 한계를 모델링함.

## Ⅲ. 절차
```text
+----------+   +----------+   +----------+   +----------+
| Reduction|-> | Poly Verf|-> | NP Cmp Pr|-> | Approx Sl|
+----------+   +----------+   +----------+   +----------+
```
1. 문제 환원: 새로운 문제를 이미 알려진 NP-완전 문제(예: SAT)로 다항 시간 내에 환원함.
2. 정답 검증: 주어진 해(예: 경로)가 정답인지 다항 시간 내에 참/거짓을 판별함.
3. 완전성 증명: 해당 문제가 NP에 속하며, 다른 모든 NP 문제를 포함함을 증명함.
4. 근사 해법: P=NP가 아님이 유력하므로 최적해 대신 근사 알고리즘으로 타협함.

> 요약: 문제를 다른 문제로 환원하고 다항 시간 내 검증을 거쳐 NP-완전성을 규명하고 해법을 전환함.

## Ⅳ. 문제점
- NP-완전 문제는 입력 크기가 증가함에 따라 최적해 탐색 시간이 지수적으로 증가하여 현실적 해결 불가
- 모든 NP-완전 문제가 P에 속하는지 여부가 수학적으로 증명되지 않아 알고리즘 설계의 한계점 상존
- 산업의 고도화로 물류, 회로 설계 등 대규모 복합 최적화(NP-Hard) 문제 해결 요구 급증

## Ⅴ. 개선방안
- [단기] 백트래킹 및 분기 한정(Branch & Bound) 알고리즘을 통해 불필요한 탐색 공간을 조기 가지치기
- [중기] 엄밀한 최적해 대신 허용 오차 범위 내의 해를 다항 시간 안에 도출하는 근사 알고리즘 집중 적용
- [장기] 유전 알고리즘 등 메타 휴리스틱 및 양자 어닐링 기법을 활용한 차세대 해법 모색

## Ⅵ. 전망
- 암호학의 안전성을 보장하는 기반 이론이며, 휴리스틱과 양자 컴퓨팅의 발전을 견인하는 궁극적 목표임.
