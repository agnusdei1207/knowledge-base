# P vs NP 문제 (P vs NP Problem)

## 1. 개요

- **정의/개념**: P vs NP 문제는 다항 시간에 해를 검증할 수 있는 모든 문제가 다항 시간에 풀 수도 있는지 묻는 계산복잡도 이론의 핵심 미해결 문제이다.
- **배경/필요성**: 많은 최적화·스케줄링·암호 문제의 난이도와 해결 전략이 P와 NP 관계에 영향을 받으므로 계산 가능성과 효율 가능성을 구분해야 한다.

NP는 "풀 수 없음"이 아니라 "후보 해가 주어지면 빠르게 검증 가능"하다는 의미이다.

## 2. 특징 및 비교

| 구분 | P | NP | NP-Complete | NP-Hard |
|---|---|---|---|---|
| 의미 | 다항 시간 풀이 가능 | 다항 시간 검증 가능 | NP이면서 NP-hard | NP 이상으로 어려움 |
| 예 | 최단 경로 결정형 | SAT | 3-SAT, Clique | TSP 최적화 |
| 핵심 | 효율적 알고리즘 존재 | 검증 가능성 | 환원 기준 | NP 소속 불필요 |
| 실무 대응 | 정확 알고리즘 | 문제별 판단 | 근사·휴리스틱 고려 | 특수 제약 활용 |

판단 기준은 결정 문제화, 검증 가능성, 환원 방향, 입력 규모, 허용 오차이다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| Decision Problem | Yes/No 형태 문제 | P/NP 분류 대상 |
| Polynomial Time | 입력 크기 다항식 시간 | 효율성 기준 |
| Verifier | 후보 해 검증 알고리즘 | NP 조건 |
| Reduction | 문제 간 변환 | 난이도 전달 |
| Complete Class | 대표 난제 집합 | 전략 선택 기준 |

```text
문제 정의 -> 결정 문제화 -> 검증 가능성 확인 -> 환원 관계 -> 해결 전략
```

난이도 분류는 실무 포기가 아니라 정확·근사·휴리스틱·특수 조건 중 무엇을 택할지 정하는 출발점이다.

## 4. 문제점 및 개선방안

1. **NP 의미 오해**
   - NP를 "풀 수 없는 문제"로 단정하면 실무 전략을 놓친다.
   - **개선방안**: 검증 가능성과 풀이 가능성을 분리해 설명한다.

2. **환원 방향 오류**
   - 어려움을 보이려면 알려진 NP-Complete 문제에서 대상 문제로 환원해야 한다.
   - **개선방안**: 환원 방향과 다항 시간 변환 조건을 명시한다.

3. **실무 대응 부재**
   - 난이도 분류만 하고 해결 전략을 제시하지 않으면 답안이 끊긴다.
   - **개선방안**: 입력 규모별 정확 알고리즘, 근사, 휴리스틱, ILP 등을 연결한다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| 스케줄링 | NP-hard 문제로 보고 휴리스틱·제약완화 적용 | 실행 시간, 품질 gap |
| 보안·암호 | 특정 계산 난제에 기반해 안전성 가정 | 공격 비용 |
| 최적화 시스템 | 입력 규모에 따라 exact/approx 전략 선택 | 최적성, SLA |

## 6. 결론

P vs NP는 검증 가능한 문제가 모두 효율적으로 풀 수 있는지 묻는 계산복잡도 핵심 문제이다. P, NP, NP-Complete, NP-Hard를 구분하고 환원과 해결 전략까지 연결해야 이론 분류가 실무 판단으로 이어진다.
