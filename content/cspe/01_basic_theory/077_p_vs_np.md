## Ⅰ. 개요
- **정의**: 다항 시간 내 해결 가능한 문제 집합(P)과 다항 시간 내 검증 가능한 문제 집합(NP)의 동치 여부를 묻는 미해결 난제임
- **배경/필요성**: 문제의 본질적 난이도 한계를 규명해야 알고리즘 설계 전략(정확해 vs 근사해)을 결정할 수 있음
- **비유**: 스도쿠를 직접 푸는 것(P)과 완성된 답이 맞는지 확인하는 것(NP)의 난이도 차이와 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| P, NP, NP-Hard, NP-Complete 관계 | NP-Complete = NP ∩ NP-Hard | NP를 "풀 수 없는 문제"로 오해하면 감점 |
| NP-완전성 증명 절차 | 다항 환원(Reduction) + NP 소속 2단계 | 환원 방향(A→B) 혼동 주의 |

> 요약: P⊆NP는 자명하나, NP⊆P 여부가 미해결이며, NP-Complete가 그 경계의 핵심 문제군임

## Ⅱ. 구성요소
```text
+-------------------------------------------+
|              NP                            |
|   +------------------+                     |
|   |   NP-Complete    |   +-----------+     |
|   |  (SAT, TSP-D,..) |   | NP-Hard   |     |
|   +------------------+   | (Halting,  |     |
|   +------+               |  TSP-Opt)  |     |
|   |  P   |               +-----------+     |
|   +------+                                 |
+-------------------------------------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| P 클래스 | 결정론적 튜링 기계로 O(n^k) 시간 내 해결 가능한 문제 | 쉬운 시험 |
| NP 클래스 | 답이 주어지면 다항 시간 내 참/거짓 검증 가능한 문제 | 채점 가능 시험 |
| NP-Complete | NP이면서 모든 NP 문제가 다항 환원 가능한 최난 부분 집합 | 관문 보스 |
| NP-Hard | 모든 NP 문제가 환원 가능하나, 자신이 NP에 속할 필요 없는 문제 | 난외 문제 |

> 요약: P ⊆ NP ⊆ NP-Hard 관계에서 NP-Complete는 NP와 NP-Hard의 교집합으로 핵심 경계점임

## Ⅲ. 절차
```text
+----------+    +----------+    +----------+    +----------+
| Prob Def | -> | NP Check | -> | Reduce   | -> | Strategy |
+----------+    +----------+    +----------+    +----------+
```

1. **문제 정의** — 주어진 최적화/결정 문제를 형식적으로 정의하고 입력 크기 n을 명확히 함
2. **NP 소속 확인** — 후보 해가 주어졌을 때 다항 시간 O(n^k) 내에 검증 가능함을 증명함
3. **다항 환원** — 기존 NP-Complete 문제(예: SAT, 3-SAT)를 현재 문제로 다항 변환하여 난이도 하한 증명함
4. **해법 전략 결정** — NP-Complete 확정 시 정확해 포기 후 근사 알고리즘·휴리스틱 전략을 선택함

> 요약: 문제 정의 → NP 소속 증명 → 기존 난제로부터 환원 → 해법 전략 결정의 4단계 분류 절차임

## Ⅳ. 문제점
- **지수적 탐색 비용**: NP-Complete 문제의 입력 n 증가 시 탐색 공간이 2^n 규모로 폭증하여 정확해 도출 불가
- **P=NP 미해결**: 수학적 증명이 부재하여 특정 문제에 다항 알고리즘이 존재하는지 보장할 수 없음
- **실무 최적화 수요 급증**: 물류 경로·회로 배치·스케줄링 등 NP-Hard 문제의 산업 규모가 n > 10^6 수준으로 확대

> 요약: 탐색 공간 폭증, 이론적 한계 미증명, 산업 규모 확대로 인한 실무 격차가 3대 문제점임

## Ⅴ. 개선방안
1. 단기: 분기 한정법(Branch & Bound)·가지치기로 불필요 탐색 공간 조기 제거하여 실행 시간 축소
2. 중기: 근사 알고리즘(078 참조) 적용으로 다항 시간 내 근사비 ρ ≤ 1.5 수준의 준최적 해 도출
3. 장기: 양자 어닐링(D-Wave)·양자 게이트(080 참조) 활용으로 탐색 공간을 제곱근 수준으로 축소

- **지수적 탐색 비용**: 전수 탐색 → 분기 한정 + 가지치기 (지표: 탐색 노드 수 90% 감소)
- **P=NP 미해결**: 정확해 고집 → 근사비 보장 근사 알고리즘 전환 (지표: 근사비 ρ ≤ 2)
- **실무 최적화 수요**: 단일 머신 → 분산 메타 휴리스틱(GA, SA) 병렬화 (지표: 10^6 변수 1분 내 수렴)

> 요약: 가지치기 → 근사 알고리즘 → 양자 컴퓨팅 3단계로 NP-Hard 문제 실무 해결력을 확보함

## Ⅵ. 전망
- **향후 발전 방향**: 양자 근사 최적화 알고리즘(QAOA)이 NISQ 장비에서 조합 최적화 문제의 실용적 가속을 시연 중
- **기술사적 판단**: P≠NP가 유력하므로 근사·확률적 해법의 이론적 정교화가 지속 필요함
- **기술사 제언**: 문제 분류(P/NP-C/NP-H) 역량을 기반으로 정확해·근사해·휴리스틱 중 적합 전략을 판단하는 것이 기술사의 핵심 역할임
