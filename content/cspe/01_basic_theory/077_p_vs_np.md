## 미리 알고가기

- 결정 문제($Decision$ $Problem$): 예($Yes$) 또는 아니오($No$)로 답할 수 있는 수학적 문제 형식임
- 다항 시간($Polynomial$ $Time$): 알고리즘 수행 시간이 입력 크기 $n$에 대해 $O(n^k)$ 이하인 경우로, 컴퓨터가 실시간 내에 풀 수 있는 현실적인 연산 범위를 뜻함
- 비결정적 튜링 머신($NTM$): 한 상태에서 여러 개의 선택지를 동시에 병렬 탐색할 수 있는 가상의 초월적 계산 모델임
- 다항 시간 다대일 환원($Reduction$): 문제 $A$의 입력을 문제 $B$의 입력으로 다항 시간 내에 변환하여, $B$를 풀 수 있다면 $A$도 풀 수 있음을 증명하는 도구임

## Ⅰ. 개요

- **정의/개념**: P vs NP 문제는 컴퓨터 과학의 최대 난제 중 하나로, 기계가 답을 스스로 찾는 시간 복잡도 집합(P)과 타인이 제시한 답이 옳은지 검증하는 데 걸리는 시간 복잡도 집합(NP)이 본질적으로 같은 컴퓨터 계산 능력을 갖는가에 대한 근본적인 의문임
- **배경/필요성**: 현실 세계의 암호 해독, 최적화 경로 탐색, 네트워크 회로 스케줄링 등 수많은 난문제들이 '컴퓨터의 한계 안에서 물리적 시간 내에 완벽히 해결될 수 있는가'를 분류하고 대안을 수립하기 위해 연구됨

## Ⅱ. 특징

- P 집합은 결정론적 튜링 머신($DTM$)으로 다항 시간 내에 풀 수 있는 비교적 쉬운 문제(예: 최단 경로)들의 집합임
- NP 집합은 비결정론적 튜링 머신($NTM$)으로 다항 시간 내에 풀 수 있거나, 답이 주어졌을 때 결정론적으로 맞는지 검증(Verify)만 다항 시간 내에 할 수 있는 문제(예: 스도쿠, 암호 열쇠 맞추기)들의 집합임
- $P = NP$ 임이 증명된다면, 모든 검증 가능한 문제(보안 암호 해독 등)를 스스로 고속으로 다항 시간 내에 풀 수 있는 수식이 존재함을 의미하므로, 현대 보안 체계의 붕괴를 초래할 수 있음

## Ⅲ. 계산 복잡도 클래스의 관계 및 비교

| 클래스 명칭 | 수학적 정의 | 해의 탐색 복잡도 | 해의 검증 복잡도 | 대표적인 문제 사례 |
|:---|:---|:---|:---|:---|
| **P** | 결정론적 다항 시간 해결 가능 | 다항 시간 ($O(n^k)$) | 다항 시간 | 최소 스패닝 트리 ($MST$), 정렬, 최단 경로 |
| **NP** | 비결정론적 다항 시간 해결 가능 | 지수 시간 ($O(2^n)$) 이상 추정 | 다항 시간 ($O(n^k)$) | 외판원 문제($TSP$) 결정형, $SAT$ (충족성 문제) |
| **NP-완전 (Complete)** | 모든 NP 문제를 환원시킬 수 있는 NP 최상위 문제 | 가장 어려움 (지수 시간) | 다항 시간 | $3-SAT$, 해밀턴 경로 문제, 배낭 채우기 ($Knapsack$) |
| **NP-난해 (Hard)** | 모든 NP 문제보다 어렵거나 같음 (NP에 안 속할 수 있음) | 지수 시간 또는 풀 수 없음 | 불가능 또는 지수 시간 | $TSP$ 최적화형, 정지 문제 ($Halting$ $Problem$) |

> 요약: P는 풀기 쉽고, NP는 검증하기 쉬우며, NP-완전은 NP 중 가장 어려운 정수이고, NP-난해는 그 이상의 복잡도를 뜻함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 결정론적 튜링 머신 | 현재 상태와 입력에 의해 오직 하나의 전이(동작) 경로만 존재하는 일반적인 컴퓨터 모델임 |
| 비결정론적 튜링 머신 | 하나의 전이에 여러 병렬 상태 전이가 허용되어, 마치 수많은 우주에서 동시에 분기 탐색하는 가상의 모델임 |
| 다항 시간 환원 ($P-Reduction$) | 어려운 문제 $A$를 이미 알고 있는 문제 $B$로 변환하여 문제의 본질적 난도가 같음을 입증하는 다리임 |
| 쿡-레빈 정리 | 최초로 $SAT$(충족성 문제)가 NP-완전($NP-Complete$)임을 수학적으로 엄밀히 증명해 낸 이론적 정초임 |

```text
[ 복잡도 클래스의 추정 영역도 (P ≠ NP 가정 시) ]
+-------------------------------------------------+
|                  NP-Hard (난해)                 |
|       +---------------------------------+       |
|       |         NP-Complete (완전)      |       |
|       +---------------------------------+       |
|       |              NP                 |       |
|       |     +---------------------+     |       |
|       |     |          P          |     |       |
|       |     +---------------------+     |       |
|       +---------------------------------+       |
+-------------------------------------------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 문제형식 정의| --> | 다항검증 증명| --> | 다항환원(Map)| --> | 난도클래스 결정|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **결정형 전환** — 최적의 비용을 구하는 함수형 문제를 "비용이 $K$ 이하인가?"처럼 예/아니오로 대답할 수 있는 결정 문제($Decision$ $Problem$) 형태로 변환함
2. **다항 검증** — 임의의 정답 후보(인증서, $Certificate$)가 입력되었을 때, 이 후보가 유효한지 다항 시간 내에 판정하는 검증 식($Verification$ $Algorithm$)을 설계하여 NP에 속함을 보임
3. **난도 환원** — 기존에 알려진 대표적인 NP-완전 문제(예: 3-SAT)의 모든 인스턴스를 다항 시간 내에 해결 대상 문제의 인스턴스로 변환하는 사상 규칙($Reduction$)을 도출함
4. **위계 판정** — 환원이 성공하면 대상 문제를 NP-완전(또는 NP-난해)으로 공식 명명하고, 정확한 수식을 찾는 것이 현실 컴퓨터로 불가능에 가까움을 선포함

## Ⅵ. 실무 적용 및 유의점

1. 실무에서 다루는 자원 최적화 스케줄링이나 물류 차량 경로 탐색($TSP$) 등은 대부분 NP-난해/완전 범주에 속하므로, 슈퍼컴퓨터를 동원해도 정확한 전역 최적해($Optimal$ $Solution$)를 구하는 것은 시간적으로 불가능함을 빠르게 인정하고, 95% 이상의 준수한 해를 즉시 도출하는 '근사 알고리즘($Approximation$)'이나 '메타 휴리스틱(유전 알고리즘 등)'을 도입해야 함
2. 현대 금융 및 보안 인프라의 핵심인 공개키 암호(RSA 등)는 $P \neq NP$ 가설에 안전성 기반을 두고 있으므로(암호 해독은 NP에 속하지만 P에는 속하지 않는다고 가정), 만에 하나 학계에서 $P = NP$가 증명되거나 이에 준하는 고속 소인수분해 알고리즘이 발견될 경우를 대비한 대체 암호 자산 목록을 정기 점검해야 함

## Ⅶ. 결론

- P vs NP 문제는 전산학의 극한 한계를 규정하는 나침반이며, 설계자는 비즈니스 요건이 정확한 최적화인지 현실적 시간 타협인지 분별하여 난해 문제에 대해 시간 낭비 없이 기하학적 근사해와 완화 조건을 결합해 실 작동 가능한 지능 시스템을 배포해야 함
