## 미리 알고가기

- 베이즈 정리: 원인과 결과의 조건부 확률을 뒤집어 계산하는 규칙임
- 사전 확률: 데이터를 보기 전 클래스가 나타날 기본 확률임
- 우도: 특정 클래스에서 입력 특징이 관측될 조건부 확률 또는 확률밀도임
- 사후 확률: 입력 특징을 본 뒤 입력이 특정 클래스에 속할 확률임
- 라플라스 스무딩: 이산형 나이브 베이즈에서 미관측 특징의 확률이 0이 되는 문제를 보정함
- 최대 사후 확률(MAP): 사후 확률이 가장 큰 클래스를 선택하는 판정 기준임
- 확률 교정 오차(Calibration Error): 예측 확률과 실제 정답 비율의 차이를 측정하는 지표임
- ROC 곡선 아래 면적(AUC): 분류 임계값을 바꾸며 양성·음성을 구분하는 성능을 종합한 지표임

## 작성 근거(검토용)

- 개요는 베이즈 정리보다 분류 판정 방식과 독립 가정을 앞세워 알고리즘 정체성을 명확히 함
- 희소 데이터 처리·제한된 학습 매개변수·출력 확률 보정은 나이브 베이즈의 선택 기준임
- Ⅲ은 연속값·빈도·이진값의 입력 분포에 따라 나이브 베이즈 유형을 구분함
- Ⅳ는 확률 계산에 필요한 사전 확률, 우도, 스무딩, MAP 판정을 순서대로 배치함
- 0 확률과 독립 가정 위반은 적용 조건과 검증 기준을 연결하는 핵심 위험임

## Ⅰ. 개요

- **정의/개념**: 나이브 베이즈는 특징들이 클래스 조건에서 서로 독립이라는 가정으로 사후 확률이 가장 큰 클래스를 선택하는 확률 분류기임
- **배경/필요성**: 고차원 희소 데이터를 빈도 집계로 분류하기 위해 특징별 조건부 확률을 결합하는 기준이 필요함

### 쉽게 이해하기 (학습용)
- 이메일 속 여러 단서(단어)를 서로 상관없다고 치고 각 단서가 스팸일 확률을 곱해 최종 판정을 내리는 것과 같음

## Ⅱ. 특징

- 조건부 독립 가정으로 결합 확률 계산을 단순화하고 추정할 매개변수를 제한함
- 특징별 빈도와 확률만 집계하므로 특징 수가 많은 희소 텍스트에도 매개변수 폭증 없이 적용함
- 사후 확률을 출력하지만 독립 가정이 어긋나면 확률 보정이 필요함
- 특징 우도를 직접 곱하면 언더플로가 발생할 수 있어 로그 우도의 합으로 계산함

### 쉽게 이해하기 (학습용)
- 단서끼리 관련이 없다고 치니 계산이 단순해지고, 단서가 아무리 많아도 다뤄야 할 값의 개수가 폭발하지 않음
- 확률이 너무 작아지면 숫자가 사라질 수 있어, 곱셈 대신 덧셈(로그)으로 바꿔 계산함

## Ⅲ. 종류 및 비교

| 판단 기준 | 가우시안 NB | 다항 NB | 베르누이 NB |
|:---|:---|:---|:---|
| 확률 모델 | 정규분포 | 다항분포 | 베르누이분포 |
| 입력 범위 | 연속형 수치 | 비음수 빈도 | 이진 출현값 |
| 주요 리스크 | 정규성 가정 위반 | 미관측 특징의 0 우도 | 빈도 정보 손실 |

> 요약: 연속값이 클래스별 정규분포를 따르면 가우시안, 빈도면 다항, 존재 여부면 베르누이를 선택함.

### 쉽게 이해하기 (학습용)
- 키·몸무게처럼 연속된 숫자면 가우시안, 단어가 몇 번 나왔는지 세는 거면 다항, 단어가 있는지 없는지만 보면 베르누이를 씀

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 사전 확률 | 학습 데이터의 클래스 비율 |
| 특징 우도 | 클래스별 특징의 조건부 확률·확률밀도 |
| 스무딩 계수 | 미관측 특징의 0 우도 보정값 |
| 최대 사후 확률(MAP) | 사후 확률이 가장 큰 클래스 판정 |

> 요약: 나이브 베이즈는 사전 확률과 특징 우도를 결합하고 0 우도를 보정해 최대 사후 확률의 클래스를 선택함.

### 쉽게 이해하기 (학습용)
- 원래 알고 있던 각 클래스의 비율(사전 확률)에, 단서마다 얼마나 그 클래스다운지(우도)를 곱해가며 점수를 매기고 가장 높은 클래스를 고름
- 한 번도 못 본 단서 때문에 점수가 통째로 0이 되지 않도록 아주 작은 값을 미리 얹어둠

## Ⅴ. 원리 및 절차 흐름도

```text
학습 데이터 -> 클래스/특징 집계 -> 확률 추정 -> 입력 점수 계산 -> 클래스 선택
```

1. 학습 데이터에서 클래스별 표본 수와 특징 빈도를 집계함
2. 사전 확률과 클래스별 특징 우도를 계산함
3. 신규 입력의 특징별 로그 우도와 로그 사전 확률을 합산함
4. 사후 확률 점수가 가장 큰 클래스를 출력함

> 요약: 나이브 베이즈는 로그 우도와 로그 사전 확률의 합이 가장 큰 클래스를 출력함.

### 쉽게 이해하기 (학습용)
- 지난 사례를 세어 기준표를 만들고, 새로 들어온 것의 단서 점수를 기준표와 하나씩 맞춰 더한 뒤, 합산 점수가 제일 높은 쪽으로 판정함

## Ⅵ. 실무 사례

1. 스팸 분류기는 다항 나이브 베이즈에 라플라스 스무딩을 적용해 처음 본 단어의 확률이 0이 되지 않게 함
2. 장애 로그 분류기는 나이브 베이즈가 과신한 출력 확률을 별도 검증 데이터로 교정함

### 쉽게 이해하기 (학습용)
- 처음 보는 단어가 나와도 확률이 0이 되지 않게 미리 여유분을 넣어 스팸을 거르고, 너무 자신만만한 점수는 실제 결과와 비교해 다시 다듬어 씀

## Ⅶ. 결론

- 나이브 베이즈는 사전 지식과 특징별 증거를 결합해 분류하며, 특징 독립 가정에 따른 확률 과신을 고려해야 함
- 빠른 기준 모델과 온라인 갱신에는 적합하지만 확률을 의사결정에 직접 쓰면 교정 오차를 측정하고 임계값을 보정해야 함

### 쉽게 이해하기 (학습용)
- 단서들이 서로 무관하다고 가정하고 빠르게 점수를 매기는 방식이라, 그 점수 자체를 곧이곧대로 믿기보다는 실제 결과와 맞춰보며 보정해서 써야 함
