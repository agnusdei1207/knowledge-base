# 062. 나이브 베이즈 분류 (Naive Bayes Classifier)

## Ⅰ. 개요

- **정의/개념**: 베이즈 정리($Bayes'$ $Theorem$)를 기반으로, 모든 특징($Feature$)들이 서로 조건부 독립($Conditional$ $Independent$)이라는 '나이브($Naive$)'한 가정하에 사후 확률을 계산하여 분류하는 확률적 지도 학습 모델임
- **배경/필요성**: 데이터의 차원이 커질수록 확률 추정에 필요한 샘플 수가 급격히 늘어나는 '차원의 저주' 문제를 독립성 가정을 통해 회피하고, 실시간성 및 고성능 베이스라인을 확보하기 위함임

## Ⅱ. 특징 및 비교

### 1. 주요 특징 및 PPA (Power, Performance, Area)
- **Performance**: 특징 간 독립성 가정이 어느 정도 유지되는 도메인(스팸 메일 등)에서 놀라울 정도로 우수한 분류 성능을 보임
- **Power/Speed**: 별도의 반복적 최적화($Iteration$) 없이 단일 데이터 스캔($Scan$)만으로 학습이 완료($O(N \cdot D)$)되어 연산 비용이 극히 낮음
- **Trade-offs**: 모델의 단순성($Bias$)으로 인한 계산 이점과 특징 간 상관관계 무시($Variance$) 사이의 트레이드오프가 존재함

### 2. 생성 모델 vs 판별 모델 비교

| 판단 기준 | 나이브 베이즈 ($NB$) | 로지스틱 회귀 ($LR$) | $SVM$ |
|:---|:---|:---|:---|
| **모델 유형** | 생성 모델 ($Generative$) | 판별 모델 ($Discriminative$) | 판별 모델 ($Discriminative$) |
| **학습 목표** | $P(x, y)$ (결합 확률) | $P(y|x)$ (조건부 확률) | 결정 경계 ($Margin$) 최적화 |
| **데이터 요구량** | 적은 데이터로도 수렴 빠름 | 많은 데이터 필요 | 중간 ($Support$ $Vector$ 위주) |
| **특징 처리** | 독립성 가정 필수 | 변수 간 상관관계 허용 | 커널 기반 비선형 매핑 |

> 요약: $NB$는 데이터가 부족하거나 초고속 처리가 필요한 환경에서 가장 먼저 고려되는 실용적 모델임

## Ⅲ. 구성요소/구조

### 1. Architecture Insight: 독립성 가정을 통한 확률의 곱 연산
- **조건부 독립**: 클래스 $C$가 주어졌을 때, 특징 $x_1, x_2$가 서로 영향을 주지 않는다고 가정함에 따라 복잡한 다변량 결합 확률을 개별 특징 확률의 곱으로 단순화함
- **매커니즘**: 사후 확률($Posterior$)은 사전 확률($Prior$)과 우도($Likelihood$)의 곱에 비례한다는 원리를 이용함

### 2. 핵심 알고리즘 및 수식
- **Bayes Rule**: $P(C_k|x) = \frac{P(x|C_k)P(C_k)}{P(x)}$
- **Naive Formula**: $P(C_k|x_1, \dots, x_n) \propto P(C_k) \prod_{i=1}^n P(x_i|C_k)$
- **Laplace Smoothing**: $\hat{P}(x_i|C_k) = \frac{count(x_i, C_k) + \alpha}{count(C_k) + \alpha |V|}$ (빈도가 $0$인 경우 사후 확률이 $0$이 되는 문제 방지)

## Ⅳ. 문제점 및 개선방안

### 1. 핵심 문제 및 대응
1. **[제로 확률 문제 (Zero Probability)]**: 학습 데이터에 존재하지 않는 특징이 입력되면 전체 확률이 $0$이 됨
   - **개선방안**: 모든 빈도에 소량의 상수를 더해주는 라플라스 스무딩($\alpha=1$) 적용
2. **[특징 간 강한 상관관계]**: 변수들이 서로 밀접하게 연관된 경우 확률 값이 과대/과소 추정됨
   - **개선방안**: $PCA$를 통한 특징 축소 또는 상관관계가 높은 변수 제거($Feature$ $Selection$)
3. **[언더플로우 (Underflow)]**: 수많은 확률($0 \sim 1$)을 곱하다 보면 컴퓨터가 표현할 수 있는 하한선을 벗어남
   - **개선방안**: 모든 확률에 로그($Log$)를 취해 덧셈 연산으로 변환하여 계산

### 2. Real-world Troubleshooting
- **Continuous Feature Handling**: 수치형 변수의 경우 정규 분포를 가정하는 $Gaussian$ $NB$를 사용하거나, 범주화($Binning$)를 통해 이산형으로 변환하여 처리함
- **Calibration Issues**: $NB$의 결과 확률값은 독립성 가정으로 인해 양 극단($0$ 또는 $1$)으로 쏠리는 경향이 있음. 확률 자체를 신뢰해야 할 경우 $Isotonic$ $Regression$ 등으로 보정($Calibration$)이 필요함

## Ⅴ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| **스팸 필터링 (Spam)** | 메일 제목/본문의 단어 빈도를 기반으로 스팸 확률 계산 | $Precision, Recall$ |
| **뉴스 카테고리 자동 분류** | 대량의 텍스트 데이터에서 $Multinomial$ $NB$를 통한 초고속 분류 | $F1$-$Score$ |
| **실시간 감성 분석** | 스트리밍 소셜 데이터의 긍정/부정 확률을 지연 시간 없이 판단 | $Throughput, Accuracy$ |

> 요약: 실제 시스템 아키텍처에서 $NB$는 저비용·고효율의 필터링 엔진 또는 앙상블의 구성 요소로 가치가 높음

## Ⅵ. 결론

나이브 베이즈는 '단순함이 복잡함을 이긴다'는 격언을 머신러닝에서 증명한 대표적 사례임. 기술사적 관점에서 볼 때, 베이즈 정리의 수리적 의미와 독립성 가정의 트레이드오프를 명확히 이해하는 것이 중요하며, 특히 텍스트 데이터의 폭증으로 인해 연산 효율이 강조되는 최신 분산 처리 환경에서 경량 분류 엔진으로서의 활용 가치를 재조명할 필요가 있음.
