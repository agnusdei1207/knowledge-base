## 미리 알고가기

- 조건부 독립 가정: 특징들이 클래스가 주어지면 서로 독립이라고 보는 가정임
- 사전확률: 클래스의 기본 발생 확률임
- 우도: 특정 클래스에서 관측 특징이 나타날 확률임

## Ⅰ. 개요

- **정의/개념**: 나이브 베이즈는 특징 간 조건부 독립을 가정하고 베이즈 정리로 각 클래스의 사후확률을 계산해 분류하는 확률 기반 모델임
- **배경/필요성**: 적은 데이터와 높은 차원의 희소 특징에서도 빠르고 안정적인 기준선 분류기가 필요함

## Ⅱ. 특징

- 학습과 추론 속도가 매우 빠르고 구현이 단순함
- 텍스트처럼 고차원 희소 데이터에서 강한 기준선 성능을 보임
- 확률 기반이라 결과 해석이 비교적 직관적임
- 독립 가정이 강해 상호작용이 큰 데이터에서는 한계가 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | Gaussian NB | Multinomial NB | Bernoulli NB |
|:---|:---|:---|:---|
| 입력 형태 | 연속형 | 카운트형 | 이진형 |
| 대표 적용 | 센서, 수치 데이터 | 문서 단어 빈도 | 단어 존재 여부 |
| 가정 | 정규 분포 | 다항 분포 | 베르누이 분포 |
| 장점 | 단순 | 텍스트 강함 | 희소 이진 특징 적합 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 클래스 사전확률 | 각 클래스 기본 비율이며 희귀 클래스 반영 요소임 |
| 특징 우도 | 클래스별 특징 분포이며 예측 근거를 형성함 |
| 독립 가정 | 계산 단순화 가정이며 속도의 원천이자 한계임 |
| 사후확률 | 최종 분류 기준이며 가장 큰 값을 선택함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 확률추정 | --> | 우도계산 | --> | 사후확률 계산 | --> | 클래스선택 |
+----------+     +----------+     +----------+     +----------+
```

1. **확률추정**: 학습 데이터에서 클래스 비율과 특징 확률을 계산함
2. **우도계산**: 입력 특징이 각 클래스에서 나타날 가능성을 구함
3. **사후확률 계산**: 베이즈 정리로 클래스별 확률을 계산함
4. **클래스선택**: 가장 큰 사후확률 클래스를 선택함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 독립 가정이 현실과 다를 수 있어 상관 높은 특징에서 성능이 떨어질 수 있음
   - 해결방안: 특징 선택이나 상관 축소 전처리를 적용하고 validation accuracy로 검증함
2. 문제: 0빈도 문제가 발생해 학습에 없던 특징이 확률 0을 만들 수 있음
   - 해결방안: Laplace smoothing을 적용하고 unseen feature robustness로 검증함
3. 문제: 확률 calibration이 부정확할 수 있어 점수는 맞지만 확률 해석이 약할 수 있음
   - 해결방안: calibration 후 사용하고 log loss로 검증함

## Ⅶ. 적용 사례

- 스팸 메일 분류: 단어 출현 확률로 메일을 분류함, 확인 지표는 precision과 recall임
- 문서 주제 분류: 희소 단어 벡터에 적용함, 확인 지표는 macro-F1임
- 간단한 이상분류 기준선: 빠른 초기 모델로 활용함, 확인 지표는 학습 시간과 정확도임

## Ⅷ. 결론

나이브 베이즈의 핵심은 단순한 가정으로 빠른 확률 분류를 제공하는 데 있으므로, 복잡한 모델 전 단계 기준선과 희소 데이터 문제에 특히 유효함.
