## Ⅰ. 개요
- **정의**: 베이즈 정리와 특징 독립 가정을 기반으로 사후 확률을 계산하여 분류하는 확률적 모델임
- **배경/필요성**: 고차원 텍스트 데이터에서 적은 연산으로 빠른 확률적 분류를 수행해야 할 필요성 존재
- **비유**: 각 단서를 독립적으로 평가해 범인을 추리하는 탐정

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 조건부 확률 기반 분류 원리 이해 | P(C|X) ∝ P(X|C)·P(C) 수식 전개 | 독립 가정의 한계와 스무딩 기법 누락 시 감점 |

> 요약: 베이즈 정리로 사후 확률을 산출하는 경량 분류기로, 텍스트 분류에서 강력한 베이스라인임

## Ⅱ. 구성요소
```text
+-----------+     +-----------+     +-----------+
|  Prior    | --> | Likelihood| --> | Posterior |
|  P(C)     |     | P(X|C)    |     | P(C|X)    |
+-----------+     +-----------+     +-----------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 사전 확률 P(C) | 관측 전 각 클래스의 기본 발생 비율 | 기본 확률 |
| 우도 P(X|C) | 특정 클래스 조건 하에서 피처 X가 관측될 확률 | 증거 가중치 |
| 사후 확률 P(C|X) | 피처를 관측한 후 갱신된 클래스별 확률 | 최종 판정 |
| 독립 가정 | 모든 피처가 상호 독립이라는 단순화 가정 | 단서 분리 평가 |

> 요약: 사전 확률과 우도의 곱으로 사후 확률을 산출하며, 독립 가정으로 연산량을 대폭 절감함

## Ⅲ. 절차
```text
+-----------+     +-----------+     +-----------+     +-----------+
| Data      | --> | Frequency | --> | Bayes     | --> | Class     |
| Input     |     | Count     |     | Calculate |     | Assign    |
+-----------+     +-----------+     +-----------+     +-----------+
```

1. **데이터 입력** — 텍스트 또는 피처 벡터를 입력받아 전처리 수행
2. **빈도 집계** — 클래스별 각 피처의 출현 빈도를 카운팅하여 우도 테이블 구성
3. **베이즈 연산** — P(C|X) ∝ P(C) × ∏P(xi|C) 수식으로 클래스별 사후 확률 산출
4. **클래스 할당** — argmax로 가장 높은 사후 확률을 가진 클래스를 최종 결과로 선택

> 요약: 피처 빈도 기반 우도를 집계한 후 베이즈 정리를 적용하여 최적 클래스를 결정함

## Ⅳ. 문제점
- **제로 확률 문제**: 학습 데이터에 미출현한 피처가 있으면 전체 사후 확률이 0으로 소멸
- **독립 가정 위배**: 실제 피처 간 상관관계가 존재하여 확률 추정에 체계적 오차 발생
- **수치 표현 한계**: 연속형 변수의 경우 가우시안 분포 가정이 불일치할 때 분류 정확도 하락

> 요약: 제로 확률, 독립 가정 위배, 연속형 변수 분포 불일치가 핵심 제약 사항임

## Ⅴ. 개선방안
1. 단기: 라플라스 스무딩(α=1) 적용으로 미출현 피처에 최소 확률값을 보장하여 제로 확률 방지
2. 중기: 피처 간 의존성을 부분 허용하는 TAN(Tree Augmented Naive Bayes) 구조로 확장
3. 장기: 커널 밀도 추정(KDE)을 우도 산출에 적용하여 연속형 변수의 비정규 분포 대응

- **독립 가정 위배**: 피처 상관 → 피처 선택(Chi-Square 등)으로 상관 피처 제거 (지표: 분류 F1-Score)

> 요약: 스무딩, TAN 확장, KDE 적용으로 나이브 가정의 한계를 단계적으로 보완함

## Ⅵ. 전망
- 향후 발전 방향: 실시간 스팸 필터링, 감성 분석 등 속도 우선 분류 파이프라인의 1차 필터로 지속 활용
- 기술사적 판단: 딥러닝 분류기 대비 학습 데이터 1,000건 이하 환경에서 오히려 우위를 보이는 경량 모델임
- 기술사 제언: 답안에서 독립 가정의 한계를 명시하고 스무딩 기법까지 언급해야 완결된 서술임
