## 미리 알고가기

- 베이즈 정리: 원인과 결과의 조건부 확률을 뒤집어 계산하는 규칙임
- 사전 확률: 데이터를 보기 전 클래스가 나타날 기본 확률임
- 우도: 특정 클래스에서 입력 특징이 관측될 확률임
- 사후 확률: 입력 특징을 본 뒤 입력이 특정 클래스에 속할 확률임
- 라플라스 스무딩: 미관측 특징의 확률 0 문제를 완화함

## 작성 근거(검토용)

- 개요는 베이즈 정리보다 분류 판정 방식과 독립 가정을 앞세워 알고리즘 정체성을 명확히 함
- 학습 비용·희소 데이터·소량 데이터 성능은 나이브 베이즈의 선택 기준임
- Ⅲ은 입력 자료형에 따라 모델을 선택하는 구조라 실무 비교가 쉬움
- Ⅳ는 확률 계산에 필요한 사전 확률, 우도, 스무딩, MAP 판정을 순서대로 배치함
- 0 확률과 독립 가정 위반은 적용 조건과 검증 기준을 연결하는 핵심 위험임

## Ⅰ. 개요

- **정의/개념**: 나이브 베이즈는 특징들이 클래스 조건에서 서로 독립이라는 가정으로 사후 확률이 가장 큰 클래스를 선택하는 확률 분류기임
- **배경/필요성**: 고차원 희소 데이터를 적은 학습 비용으로 빠르게 분류하기 위해 단순한 확률 기반 모델이 필요함

## Ⅱ. 특징

- 조건부 독립 가정으로 결합 확률 계산을 단순화함
- 학습은 빈도 집계 중심이라 속도가 빠름
- 텍스트처럼 특징 수가 많은 희소 데이터에 강함
- 학습 데이터가 적어도 기본 분류 성능을 확보하기 쉬움

## Ⅲ. 종류 및 비교

| 판단 기준 | 가우시안 NB | 다항 NB | 베르누이 NB |
|:---|:---|:---|:---|
| 입력 | 연속형 수치 | 빈도·카운트 | 존재·부재 |
| 확률 가정 | 정규분포 | 다항분포 | 베르누이분포 |
| 대표 적용 | 센서·측정값 | 문서 단어 빈도 | 키워드 출현 여부 |
| 장점 | 수치 특징 처리 | 텍스트 분류에 적합 | 이진 특징이 명확함 |
| 주의점 | 정규성 가정 필요 | 빈도 0 보정 필요 | 빈도 크기를 반영하지 못함 |

> 요약: 입력 분포가 수치면 가우시안, 빈도면 다항, 존재 여부면 베르누이를 선택함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 클래스 집합 | 분류 대상이 되는 가능한 라벨 목록임 |
| 사전 확률 | 학습 데이터의 클래스 비율로 계산함 |
| 특징 우도 | 클래스별 특징 출현 확률을 저장함 |
| 스무딩 계수 | 미관측 특징의 확률 0을 방지함 |
| MAP 판정 | 사후 확률이 최대인 클래스를 선택함 |

> 요약: 사전 확률과 우도를 결합하고 스무딩으로 예외 확률을 보정함.

```text
입력 특징
  -> 사전 확률 P(y)
  -> 우도 곱 P(x1|y) * ... * P(xn|y)
  -> 사후 점수
  -> 최대 점수 클래스
```

## Ⅴ. 원리 및 절차 흐름도

```text
학습 데이터 -> 클래스/특징 집계 -> 확률 추정 -> 입력 점수 계산 -> 클래스 선택
```

1. 학습 데이터에서 클래스별 표본 수와 특징 빈도를 집계함
2. 사전 확률과 클래스별 특징 우도를 계산함
3. 신규 입력의 특징 우도 곱과 사전 확률을 결합함
4. 사후 확률 점수가 가장 큰 클래스를 출력함

> 요약: 나이브 베이즈는 특징 우도 곱이 0이 되지 않게 보정한 뒤 최대 사후 점수를 선택함.

## Ⅵ. 실무 사례

1. 스팸 분류와 문서 분류에는 다항 NB가 빠르지만 미관측 단어가 확률을 0으로 만들므로 라플라스 스무딩을 적용하고 검증 정확도를 확인함
2. 특징 간 상관이 강하면 독립 가정이 깨져 확률값이 왜곡되므로 확률 보정을 적용하고 교정 오차·순위 정확도로 검증함

## Ⅶ. 결론

- 나이브 베이즈는 독립 가정의 단순성을 속도와 안정성으로 바꾸는 모델이며, 데이터 희소성과 확률 보정 필요성을 함께 판단해야 함
