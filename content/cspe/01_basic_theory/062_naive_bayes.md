## 미리 알고가기

- 사전 확률: 데이터를 보기 전 특정 클래스가 나타날 기본 확률임
- 우도: 특정 클래스라고 가정했을 때 입력 피처가 관측될 확률임
- 사후 확률: 입력 피처를 본 뒤 클래스별 가능성을 갱신한 확률임
- 조건부 독립 가정: 클래스가 주어지면 각 피처가 서로 독립이라고 단순화하는 가정임
- 스무딩: 학습 데이터에 없는 피처가 전체 확률을 0으로 만드는 문제를 완화하는 기법임

## Ⅰ. 개요

- **정의**: 나이브 베이즈는 베이즈 정리와 피처 독립 가정을 이용해 클래스별 사후 확률이 가장 큰 클래스를 선택하는 확률 분류기임
- **배경/필요성**: 스팸 필터나 문서 분류처럼 단어 수는 많지만 학습 데이터와 계산 시간이 제한된 환경에서 빈도 집계만으로 학습되는 기준 모델이 필요함
- **비유**: 여러 단서를 각각 독립 증거로 보고 어느 범주가 가장 그럴듯한지 확률로 판단하는 방식과 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 조건부 확률 분류 원리 설명 | `P(C\|X) ∝ P(C) * ΠP(xi\|C)` | 사전 확률과 우도 역할 혼동 |
| 단순하지만 강한 이유 설명 | 독립 가정으로 연산량 절감 | 독립 가정의 한계와 스무딩 누락 |

> 요약: 나이브 베이즈는 독립 가정으로 확률 계산을 단순화해 클래스별 가능성을 선형 연산량으로 비교하는 경량 분류기임

## Ⅱ. 특징/비교

| 판단 기준 | 로지스틱 회귀/트리 모델 | 나이브 베이즈 |
|:---|:---|:---|
| 학습 방식 | 손실 최소화나 분기 학습으로 파라미터를 반복 갱신함 | 클래스별 빈도와 조건부 확률을 집계함 |
| 데이터 적합성 | 충분한 표본과 피처 상호작용 학습이 필요함 | 희소한 단어 벡터와 소량 데이터에서도 동작함 |
| 예측 산출물 | 결정 경계 또는 규칙 기반 점수를 출력함 | 클래스별 사후 확률을 직접 비교함 |
| 주요 위험 | 과적합, 튜닝 부담, 계산 비용이 커질 수 있음 | 독립 가정 위배와 제로 확률 문제가 발생함 |

> 요약: 나이브 베이즈는 피처 관계를 정교하게 학습하기보다 확률 집계 속도와 해석 가능성을 우선할 때 적합함

- **Multinomial 선택**: 단어 등장 횟수 기반 문서 분류처럼 카운트 피처가 핵심일 때 적합함
- **Bernoulli 선택**: 단어 출현 여부처럼 0/1 피처가 의미 있는 경우 적합함
- **Gaussian 선택**: 연속형 수치 피처가 정규분포에 가깝다고 볼 수 있을 때 적합함

## Ⅲ. 구성요소

```text
+-------------+      +-------------+      +-------------+
| Training    | ---> | Prior       | ---> | Posterior   |
| Samples     |      | P(C)        |      | P(C|X)      |
+------+------+      +------+------+      +------+------+
       |                    |                    |
       v                    v                    v
+-------------+      +-------------+      +-------------+
| Feature     | ---> | Likelihood  | ---> | Class       |
| Counts      |      | P(X|C)      |      | Decision    |
+-------------+      +-------------+      +-------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 클래스 사전 확률 | 각 클래스가 전체 학습 데이터에서 차지하는 기본 비율임 | 출발 점수 |
| 피처 우도 | 특정 클래스에서 피처가 나타날 가능성을 빈도나 분포로 추정함 | 증거 무게 |
| 독립 가정 | 복수 피처의 결합 확률을 개별 확률 곱으로 단순화함 | 단서 분리 |
| 스무딩 계수 | 미출현 피처에도 작은 확률을 부여해 확률 소멸을 방지함 | 안전 여유 |
| 결정 규칙 | 사후 확률이 가장 큰 클래스를 선택하는 argmax 규칙임 | 최종 판정 |

> 요약: 나이브 베이즈는 클래스 비율, 피처별 우도, 스무딩을 결합해 클래스별 사후 확률을 계산하는 구조임

## Ⅳ. 절차

```text
+-----------+     +-----------+     +-----------+     +-----------+
| Preprocess| --> | Count     | --> | Compute   | --> | Select    |
| Features  |     | by Class  |     | Posterior |     | Argmax    |
+-----------+     +-----------+     +-----------+     +-----------+
      |                 |                 |                 |
      v                 v                 v                 v
tokens/values       prior, likelihood   log probability   label
```

1. **피처 전처리**: 텍스트 토큰, 단어 빈도, 이진 출현값, 연속형 변수 등 모델 유형에 맞는 입력을 구성함
2. **확률 추정**: 클래스별 빈도를 기반으로 사전 확률과 피처 우도를 계산하고 스무딩을 적용함
3. **사후 확률 계산**: 입력 피처에 대해 클래스별 로그 확률 합을 구해 언더플로우를 방지함
4. **클래스 선택**: 가장 큰 사후 확률을 가진 클래스를 결과로 선택하고 혼동행렬, 정밀도, 재현율로 검증함

> 요약: 피처를 정리한 뒤 클래스별 확률표를 만들고, 입력별 로그 사후 확률을 비교해 최종 클래스를 선택함

## Ⅴ. 문제점 및 개선방안

- **P1 제로 확률 문제**: 학습 데이터에 없는 피처가 등장하면 우도 값이 0이 되어 해당 클래스의 사후 확률 전체가 사라짐
- **P1 대응**: 라플라스 또는 Lidstone 스무딩으로 미출현 피처에 최소 확률을 부여함 (확인: 미등록어(Out-of-Vocabulary, OOV) 피처 포함 문서의 확률 0 발생 여부)
- **P2 독립 가정 위배**: 실제 단어와 변수는 상관관계를 가지므로 결합 확률을 과도하게 단순화해 오분류가 발생함
- **P2 대응**: 상관이 큰 피처를 제거하거나 TAN 같은 의존성 완화 모델을 적용함 (확인: 검증 F1, 상관 피처 제거 전후 성능)
- **P3 연속형 분포 불일치**: Gaussian 모델에서 피처 분포가 정규분포와 다르면 우도 추정이 왜곡됨
- **P3 대응**: 분위수 변환, 커널 밀도 추정, 구간화로 연속형 우도 추정을 보정함 (확인: 분포 적합도와 곡선하면적(Area Under the Curve, AUC))

> 요약: 스무딩, 피처 선택, 분포 보정을 통해 나이브 베이즈의 단순 가정에서 생기는 오류를 완화함

## Ⅵ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| 고객 문의 자동 분류 | 단어 등장 횟수가 핵심이고 라벨이 적을 때 다항분포 나이브 베이즈(Multinomial Naive Bayes)를 기준 모델로 적용하고 클래스별 단어 우도를 점검함 | 거시 F1 점수(Macro F1 Score, Macro-F1), 클래스별 재현율 |
| 스팸·피싱 1차 필터 | 신규 단어가 계속 생기는 환경에서 라플라스 스무딩과 도메인 차단어 사전을 함께 적용해 확률 0을 방지함 | 미등록어(Out-of-Vocabulary, OOV) 포함 메시지 확률 0 발생률, 피싱 재현율 |
| 센서 이벤트 분류 | 연속형 센서값의 분포를 먼저 확인한 뒤 Gaussian 모델을 쓰고, 정규분포와 다르면 구간화 또는 커널 밀도 추정으로 전환함 | 분포 적합도, 수신자 조작 특성-곡선하면적(Receiver Operating Characteristic-Area Under Curve, ROC-AUC) |

> 요약: 나이브 베이즈는 빠른 확률 기준선이 필요한 분류에서 피처 형태와 분포 가정이 맞는지 먼저 검증하고 적용함

## Ⅶ. 전망

- **발전 방향**: 대규모 딥러닝 모델의 전처리 필터, 스팸·이상 이벤트의 1차 탐지 모델로 계속 활용될 전망임
- **기술사적 판단**: 정확도만 최고로 요구되는 문제보다 선형 시간 학습, 확률 설명, 제한된 데이터가 중요한 업무에 적합함
- **기술사 제언**: 답안에서는 공식만 쓰지 말고 독립 가정과 스무딩을 함께 제시해 실무 한계를 알고 있음을 보여야 함
