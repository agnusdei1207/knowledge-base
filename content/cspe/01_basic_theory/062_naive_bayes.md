## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 베이즈 정리를 기반으로 각 특징이 상호 독립적이라는 가정 하에 확률을 계산하여 분류하는 통계적 기계학습 모델임. |
| 배경/필요성 | 스팸 필터링, 문서 분류 등 고차원 텍스트 데이터에서 빠르고 효율적인 확률적 분류 도구 필요성 증대. |
| 출제 의도 | 조건부 확률 기반의 통계적 추론 능력 및 베이즈 정리의 실무적 적용 한계 이해도 평가. |

## Ⅱ. 구성요소
```text
+--------------+    +--------------+    +--------------+
|    Prior     | -> |  Likelihood  | -> |  Posterior   |
+--------------+    +--------------+    +--------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 사전 확률 (Prior) | 데이터 관측 전 발생 확률 | 기본 선입견 |
| 우도 (Likelihood) | 특정 조건 하에서 관측될 확률 | 증거 가중치 |
| 사후 확률 (Posterior) | 증거를 반영한 최종 분류 확률 | 최종 결론 |

> 요약: 사전 확률과 우도를 결합하여 새로운 데이터가 특정 클래스에 속할 사후 확률을 산출함.

## Ⅲ. 절차
```text
+----------+   +----------+   +----------+   +----------+
|  Input   |-> | Frequency|-> | Bayes Eq |-> | Classify |
+----------+   +----------+   +----------+   +----------+
```
1. 데이터 입력: 분류 대상 텍스트 또는 피처 데이터를 입력받음.
2. 빈도 계산: 클래스별 각 피처의 출현 빈도 기반 우도를 계산함.
3. 베이즈 정리: 사전 확률과 우도를 곱하여 사후 확률을 도출함.
4. 예측: 가장 높은 사후 확률을 가진 클래스로 최종 분류함.

> 요약: 데이터 입력 후 피처의 조건부 확률을 계산하고 베이즈 정리를 적용해 최적 클래스를 분류함.

## Ⅳ. 문제점
- 특정 조건의 확률이 0이 되면 전체 사후 확률이 0이 되는 제로 확률 문제 발생
- 모든 특징(Feature)이 상호 독립적이라는 비현실적 가정에 의존하여 오차 유발
- 복잡한 문맥이나 비선형 관계가 얽힌 텍스트 데이터의 세밀한 의미 분석 한계

## Ⅴ. 개선방안
- [단기] 라플라스 스무딩(Laplace Smoothing)을 적용하여 최소 확률값 보장
- [중기] 특징 간 의존성을 일부 허용하는 베이지안 빌리프 네트워크(BBN)로 확장
- [장기] 딥러닝 기반 임베딩 기법과 결합하여 다차원적 문맥 이해력 보강

## Ⅵ. 전망
- 연산 속도가 매우 빨라 실시간 스팸 필터링 및 대용량 문서 분류의 강력한 베이스라인으로 지속 활용됨.
