## 미리 알고가기

- 베이즈 정리($Bayes'$ $Theorem$): 조건부 확률을 계산하는 수학 공식으로, 어떤 사건이 일어난 사전 지식을 바탕으로 사후 확률을 추정함
- 조건부 독립($Conditional$ $Independence$): 클래스가 주어졌을 때, 하나의 특징($Feature$)이 나타날 확률이 다른 특징의 존재 여부와 무관하다고 가정하는 것임
- 사후 확률($Posterior$ $Probability$): 새로운 사건이나 데이터(원인)가 관측된 후에, 그것이 특정 클래스(결과)에 속할 최종 확률임
- 라플라스 스무딩($Laplace$ $Smoothing$): 학습 데이터에 없던 새로운 특징이 등장해 확률이 0이 되는 현상을 방지하기 위해 최소한의 확률 값을 더해주는 기법임

## Ⅰ. 개요

- **정의/개념**: 나이브 베이즈 분류기는 모든 입력 특징($Feature$)들이 서로 조건부 독립이라는 가정을 바탕으로, 베이즈 정리를 적용하여 새로운 데이터가 특정 클래스에 속할 사후 확률을 계산하는 확률적 분류 알고리즘임
- **배경/필요성**: 데이터의 차원이 매우 높고(예: 텍스트 단어 주머니) 데이터 개수가 한정적일 때, 복잡한 인공신경망의 연산 병목을 극복하고 가볍고 빠른 고속 판정을 달성하기 위해 설계됨

## Ⅱ. 특징

- 모든 특징이 서로 영향을 주지 않는다는 단순한('Naive') 가정을 채택하여 사후 확률의 분모와 분자를 결합 확률의 단순 곱셈 연산으로 치환하므로 연산 속도가 극도로 빠름
- 텍스트 데이터의 스팸 메일 여부, 문서 카테고리 분류 등 희소($Sparse$) 고차원 데이터에서 매우 뛰어난 기본 분류 성능($Baseline$)을 나타냄
- 훈련 데이터가 적을 때도 파라미터 추정이 비교적 안정적이며, 새로운 데이터가 추가되었을 때 기존 파라미터를 점진적으로 온라인 갱신($Online$ $Learning$)하기에 유리함

## Ⅲ. 종류 및 비교

| 판단 기준 | 가우시안 나이브 베이즈 | 다항 분포 나이브 베이즈 | 베르누이 나이브 베이즈 |
|:---|:---|:---|:---|
| **입력 데이터** | 연속형 수치 데이터 | 이산형 빈도수 (카운트) | 이진수 (0 또는 1, 존재 여부) |
| **확률 모델** | 정규 분포 기반 우도 추정 | 다항 분포 기반 우도 추정 | 베르누이 분포 기반 우도 추정 |
| **대표 적용** | 센서 데이터 분석, 키/몸무게 | 문서 내 단어 빈도 분석 (TF) | 문서 내 단어 출현 여부 (이진 TF) |
| **수학적 가정** | 연속형 값의 정규성 분포 가정 | 단어가 여러 번 나타날 확률 | 단어의 유무 확률 |

> 요약: 수치 데이터는 가우시안을, 단어 빈도는 다항 분포를, 유무 판단은 베르누이를 선택함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 사전 확률 ($Prior$) | 새로운 데이터를 보기 전, 이미 전체 학습셋에 존재하던 클래스 자체의 발생 빈도 확률임 |
| 우도 ($Likelihood$) | 특정 클래스가 주어졌을 때, 입력 특징 $x_i$가 나타날 조건부 확률 $P(x_i | y)$임 |
| 사후 확률 ($Posterior$) | 사전 확률과 우도의 곱을 기반으로 도출된 최적의 최종 클래스 확률인 $P(y | x)$임 |
| 정규화 상수 | 사후 확률의 합이 1이 되도록 나누어 주는 분모 항으로, 분류 판정 시에는 비교 대상에서 생략 가능함 |

```text
[ 나이브 베이즈 사후 확률 수식 ]
P(y | x1, x2, ..., xn) ∝ P(y) * ∏ P(xi | y)
- P(y): 사전 확률
- ∏ P(xi | y): 특징들의 조건부 독립 하의 우도 곱
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 데이터 입력  | --> | 클래스빈도계산| --> | 개별 우도 연산| --> | 사후확률 비교|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **사전 지식 학습** — 훈련 데이터 전체를 검토하여 스팸($Y=1$)과 일반($Y=0$)의 비율을 파악해 각각의 사전 확률 $P(y)$를 구해 둠
2. **독립적 우도 추정** — 훈련 셋의 각 단어(특징)가 스팸 메일과 일반 메일에 각각 몇 번 등장했는지 세어서 개별 우도 $P(x_i | y)$를 모두 계산함
3. **결합 사후 계산** — 테스트 메일이 들어오면 포함된 단어들의 개별 우도를 모두 곱한 뒤, 클래스 사전 확률과 다시 곱하여 사후 확률의 비례치를 산출함
4. **최적 클래스 결정** — 계산된 사후 확률 분자값들 중 가장 큰 값을 가진 클래스를 최종 분류 결과($MAP$ 판정)로 선언함

## Ⅵ. 실무 적용 및 유의점

1. 학습 데이터에 한 번도 등장하지 않은 단어가 테스트 시 포함되어 있으면 우도가 0이 되어 전체 확률 곱이 0이 되므로, 모든 빈도에 1을 더해 확률을 보정하는 '라플라스 스무딩($Laplace$ $Smoothing$)'을 필수적으로 적용해야 함
2. 변수 간의 상관관계가 매우 강한 데이터(예: 키와 몸무게)에 조건부 독립 가정을 강제하면 사후 확률의 절댓값이 왜곡될 수 있으므로, 최종 확률 자체를 업무 스코어로 활용하려면 Platt 스케일링 등 확률 보정 작업을 수행해야 함

## Ⅶ. 결론

- 나이브 베이즈는 가장 단순한 가정을 통해 베이즈 정리의 확률적 예측력을 극대화한 실용적인 알고리즘이며, 설계자는 라플라스 스무딩을 통한 예외 처리와 변수 간 독립성 수준을 고려하여 시스템의 판정 신뢰도를 높여야 함
