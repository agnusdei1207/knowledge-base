# 062. 나이브 베이즈 분류 (Naive Bayes Classifier)

## Ⅰ. 개요

- **정의/개념**: 베이즈 정리(Bayes' Theorem)를 기반으로, 모든 특징(Feature)들이 서로 독립(Independent)이라는 가정하에 데이터가 특정 클래스에 속할 사후 확률을 계산하여 분류하는 확률적 지도 학습 알고리즘임
- **배경/필요성**: 특징의 수가 많고 데이터셋이 큰 경우에도 계산 복잡도가 낮아 매우 빠르게 학습 및 예측이 가능하며, 텍스트 분류와 같이 고차원 희소 데이터(Sparse Data) 처리에 효율적임

## Ⅱ. 특징 및 비교

| 판단 기준 | 나이브 베이즈 (Naive Bayes) | 로지스틱 회귀 (Logistic Regression) | 결정 트리 (Decision Tree) |
|:---|:---|:---|:---|
| **기본 가정** | 특징 간의 조건부 독립 | 선형 결합 및 오차 독립성 | 비선형적 계층 구조 |
| **모델 유형** | 생성 모델 (Generative) | 판별 모델 (Discriminative) | 판별 모델 (Discriminative) |
| **학습 속도** | 매우 빠름 (빈도 계산 중심) | 보통 (반복 최적화 필요) | 보통 (트리 성장 비용) |
| **데이터 요구량** | 적은 데이터로도 우수한 성능 | 많은 데이터 필요 | 중간 |

> 요약: 나이브 베이즈는 '독립성'이라는 강력한 가정을 통해 계산 효율성을 극대화한 알고리즘임

## Ⅲ. 구성요소/구조

- **구성요소**:
  - **Prior (사전 확률)**: 데이터가 주어지기 전, 각 클래스가 발생할 근본적인 확률($P(C)$)임
  - **Likelihood (우도)**: 특정 클래스($C$) 내에서 특징($x$)이 나타날 확률($P(x|C)$)임
  - **Posterior (사후 확률)**: 특징($x$)이 주어졌을 때, 해당 클래스($C$)에 속할 확률($P(C|x)$)로 최종 예측의 기준임
  - **Independence Assumption**: 모든 특징 $x_i, x_j$는 $C$가 주어졌을 때 서로 독립임 ($P(x|C) = \prod P(x_i|C)$)
  - **Laplace Smoothing**: 학습 데이터에 없는 특징이 나타나 확률이 0이 되는 것을 방지하기 위해 빈도에 상수를 더함

- **원리/수식**:
  - $P(C|x) = \frac{P(x|C)P(C)}{P(x)}$
  - 실제 분류 시 분모($P(x)$)는 상수이므로 분자($P(x|C)P(C)$)의 최대값을 구함

- **구조도**:
```text
[Input Features x1, x2, ..., xn]
      |
      v
[Class Prior P(Ci)]  x  [Feature Likelihood P(x1|Ci) * P(x2|Ci) * ...]
      |
      v
[Posterior Probability P(Ci|x)]
      |
      v
[Argmax over Classes] -> [Final Predicted Class]
```

## Ⅳ. 문제점 및 개선방안

1. **[조건부 독립 가정의 비현실성]**: 실제 데이터에서 특징 간의 상관관계가 있는 경우 확률 추정치가 왜곡될 수 있음
   - **개선방안**: 특징 선택(Feature Selection)을 통해 중복되거나 상관관계가 높은 변수를 제거함 (확인: 상관계수 행렬)
2. **[제로 빈도 (Zero Frequency)]**: 훈련 데이터에 특정 특징 조합이 한 번도 나타나지 않으면 사후 확률이 0이 되어 분류가 불가능함
   - **개선방안**: 모든 빈도에 소량의 값을 더해주는 라플라스 스무딩(Laplace Smoothing)을 필수 적용함 (확인: 스무딩 파라미터 α)
3. **[연속형 변수 처리 한계]**: 기본적으로 이산형 변수에 적합하며, 연속형 변수는 특정 분포(정규 분포 등)를 가정해야 함
   - **개선방안**: Gaussian Naive Bayes를 사용하거나 연속형 변수를 구간화(Binning)하여 이산형으로 변환함 (확인: 변수 분포 적합성)

## Ⅴ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| **스팸 메일 필터링** | 특정 단어들의 출현 빈도를 기반으로 스팸 여부를 확률적으로 판별 | Precision, Recall, F1 |
| **뉴스 카테고리 분류** | 기사 본문의 단어 분포를 통해 정치, 경제, 스포츠 등 분류 | Accuracy, Confusion Matrix |
| **감성 분석 (Sentiment Analysis)** | 긍정/부정 단어 사전을 기반으로 텍스트의 감성 지수 측정 | F1-Score, AUC |

> 요약: 실무에서는 텍스트 데이터의 초기 필터링이나 베이스라인 모델로 매우 선호됨

## Ⅵ. 결론

나이브 베이즈 분류기는 단순한 가정과 계산 과정을 통해 놀라울 정도로 효과적인 분류 성능을 제공하는 '가성비' 높은 모델임. 비록 특징 간 독립성이라는 제약이 실생활 데이터와는 차이가 있을 수 있으나, 대량의 텍스트 데이터를 실시간으로 처리해야 하는 환경이나 하드웨어 자원이 제한된 시스템에서는 여전히 최우선적으로 고려되는 실용적인 알고리즘임.
