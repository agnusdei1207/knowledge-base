## Ⅰ. 개요
- **정의**: 텍스트를 모델이 처리 가능한 최소 의미 단위(Token)로 분절하는 NLP 전처리 기법
- **배경/필요성**: 비정형 텍스트를 수치 벡터로 변환하려면 일관된 분절 기준이 필수이며, 교착어(한국어)는 형태소 경계가 모호하여 별도 처리 필요
- **비유**: 문장을 레고 블록 크기로 잘라 조립 가능하게 만드는 절단기

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 서브워드 분절 원리 비교 | BPE·WordPiece·SentencePiece 차이 | OOV 해결 메커니즘 누락 시 감점 |

> 요약: 텍스트를 일관된 최소 단위로 분절하여 후속 임베딩·모델 입력의 기반을 마련하는 기법임.

## Ⅱ. 구성요소
```text
+------------+     +------------+     +------------+
| Raw Text   |---->| Tokenizer  |---->| Token IDs  |
+----+-------+     +------+-----+     +------+-----+
     |                    |                  |
     v                    v                  v
+------------+     +------------+     +------------+
| Normalizer |     | Vocab Dict |     | Attention  |
+------------+     +------------+     +   Mask     +
                                      +------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 정규화기(Normalizer) | 대소문자 통일·특수문자 제거 등 텍스트 정제 수행 | 식재료 세척 |
| 토크나이저(Tokenizer) | BPE·WordPiece 등 알고리즘으로 텍스트를 서브워드 단위 분절 | 절단기 |
| 어휘 사전(Vocabulary) | 분절된 토큰과 정수 ID를 1:1 매핑하는 고정 크기 사전 | 단어장 |

> 요약: 정규화 후 토크나이저가 서브워드 분절을 수행하고, 어휘 사전을 통해 정수 ID로 변환함.

## Ⅲ. 절차
```text
+----------+   +----------+   +----------+   +----------+
| Raw Text |-->| Normalize|-->| Tokenize |-->| Encoding |
+----------+   +----------+   +----------+   +----------+
```

1. **텍스트 수집** — 코퍼스에서 원시 텍스트를 획득하고 불용어·특수문자를 제거함
2. **정규화** — 유니코드 정규화(NFC/NFD), 소문자 변환 등 표기 통일 수행
3. **서브워드 분절** — BPE 병합 규칙 또는 Unigram LM 확률로 최적 토큰 경계 결정
4. **인덱싱** — 어휘 사전을 참조하여 각 토큰을 정수 ID로 변환, [UNK] 토큰으로 미등록어 처리

> 요약: 정규화->분절->인덱싱 순서로 텍스트를 수치 시퀀스로 변환하는 파이프라인임.

## Ⅳ. 문제점
- **OOV 발생**: 고정 어휘 사전 크기 한계로 신조어·전문 용어가 [UNK]로 매핑되어 정보 손실
- **교착어 분절 모호성**: 한국어 조사·어미 결합이 복잡하여 형태소 경계 오류율 5~15% 수준
- **어휘 사전 크기 트레이드오프**: 사전이 크면 희소 토큰 증가, 작으면 시퀀스 길이 과다 팽창

> 요약: OOV·교착어 모호성·사전 크기 트레이드오프가 핵심 문제임.

## Ⅴ. 개선방안
1. 단기: BPE 병합 횟수를 도메인별 코퍼스로 재훈련하여 OOV율 1% 이하로 억제
2. 중기: SentencePiece 등 언어 무관(Language-Agnostic) 토크나이저로 다국어 통합 분절
3. 장기: 바이트 수준 토크나이징(ByT5)으로 어휘 사전 의존성 자체를 제거

- **OOV**: 고정 사전 한계 -> BPE 재훈련 + 사용자 사전 병합 (지표: OOV율 < 1%)
- **교착어 모호성**: 형태소 경계 불명확 -> 형태소 분석기 사전 결합 (지표: F1 > 0.95)
- **사전 크기**: 희소 vs 길이 -> 도메인별 최적 Vocab 크기 탐색 (지표: 평균 시퀀스 길이 비교)

> 요약: 서브워드 재훈련·다국어 통합·바이트 수준 분절로 단계적 개선함.

## Ⅵ. 전망
- 향후 발전 방향: LLM 시대에도 토크나이저 품질이 모델 성능의 하한선을 결정하므로, 바이트 수준·멀티모달 토크나이저로 진화 예상
- 기술사적 판단: 067 임베딩, 068 BERT 등 후속 기법의 입력 품질을 좌우하는 필수 전처리 모듈
- 기술사 제언: 도메인 특화 서비스 구축 시 범용 토크나이저 그대로 사용하지 말고, 해당 도메인 코퍼스로 BPE 재훈련 수행을 권고함
