## 미리 알고가기

- 코퍼스: 토크나이저 학습과 평가에 쓰는 텍스트 말뭉치임
- 토큰: 모델이 처리하는 최소 입력 단위임
- 형태소: 뜻을 가진 가장 작은 언어 단위임
- 서브워드: 단어보다 작은 문자열 단위로 미등록어를 여러 조각으로 표현함
- 미등록어(OOV): 학습 사전에 없어 직접 표현하기 어려운 단어임
- 어휘 사전: 토큰 문자열과 정수 ID를 연결한 목록임
- 바이트 쌍 인코딩(BPE): 빈도가 높은 인접 문자열 쌍을 반복 병합해 서브워드 어휘를 만드는 방식임
- WordPiece 토크나이징: 학습 말뭉치의 가능도를 높이는 서브워드 단위로 텍스트를 분절하는 방식임
- 정규화: 문자 형식·공백을 같은 기준으로 바꾸어 분절 입력을 일관되게 만드는 처리임

## 작성 근거(검토용)

- 개요는 토크나이징과 형태소 분석을 구분해 키워드의 복합 성격을 명확히 함
- 한국어 처리·OOV·토큰 수 비용은 모델 성능에 직접 영향을 주는 요소임
- Ⅲ은 형태소·서브워드·문자 분절을 비교해 언어와 모델별 선택 기준을 제시함
- Ⅳ는 정규화부터 ID 매핑까지 입력 파이프라인의 구성요소를 순서 있게 배치함
- 문장당 토큰 수와 사용자 사전은 한국어 토큰화 품질을 가르는 운영 조건임

## Ⅰ. 개요

- **정의/개념**: 토크나이징은 원문을 모델 입력 토큰으로 나누고, 형태소 분석은 단어를 의미 단위와 품사로 분해하는 전처리임
- **배경/필요성**: 불규칙한 띄어쓰기와 다양한 어미·신조어를 모델에 입력하기 위해 일관된 분절 기준이 필요함

### 쉽게 이해하기 (학습용)
- 긴 문장을 정해진 조각 단위로 잘게 썰고(토크나이징), 그 조각의 뜻과 역할까지 나눠보는(형태소 분석) 두 단계 손질임

## Ⅱ. 특징

- 텍스트를 정수 ID 시퀀스로 바꾸는 첫 단계임
- 한국어 형태소 분석은 조사와 어미의 분리 결과가 토큰 의미를 좌우함
- 서브워드는 미등록 단어를 줄이고 어휘 사전 크기를 조절함
- 토큰 수가 늘면 어텐션 연산량과 입력 비용이 증가하고 같은 문맥 창에 담기는 원문 길이가 줄어듦

### 쉽게 이해하기 (학습용)
- 글자를 그대로 두지 않고 숫자 번호표로 바꿔 붙이는 첫 관문임
- 한국어는 조사·어미를 어디서 끊느냐에 따라 같은 단어도 뜻이 달라 보임
- 처음 보는 단어는 통째로 모르는 게 아니라 아는 조각들로 쪼개 표현해 사전 크기를 아낌
- 조각을 잘게 썰수록 문장 하나가 더 많은 번호표로 늘어나 다룰 수 있는 글 길이가 줄어듦

## Ⅲ. 종류 및 비교

| 판단 기준 | 형태소 분석 | 서브워드 분절 | 문자 분절 |
|:---|:---|:---|:---|
| 분절 기준 | 형태소 사전·문법 규칙 | 말뭉치 통계 | 개별 문자 |
| 미등록어 처리 | 사용자 사전 갱신 | 서브워드 분해 | 문자 직접 표현 |
| 주요 리스크 | 사전 노후화 | 의미 경계 손실 | 시퀀스 길이 증가 |

> 요약: 형태소 분석은 사전·문법 규칙, 서브워드는 말뭉치 통계, 문자 분절은 개별 문자를 기준으로 텍스트를 나눔.

### 쉽게 이해하기 (학습용)
- 형태소 분석은 문법 사전을 펼쳐 놓고 규칙대로 단어를 자르는 것, 서브워드 분절은 많이 같이 나온 조각들을 통계로 묶어 자르는 것, 문자 분절은 아예 한 글자씩 낱개로 자르는 것임(사전에 없는 신조어는 형태소 분석에서 골칫거리가 됨)

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 정규화 | 유니코드·대소문자·공백 통일 |
| 분절 알고리즘 | 형태소·BPE·WordPiece 경계 규칙 |
| 어휘 사전 | 토큰 문자열과 정수 ID의 매핑 |
| 특수 토큰 | 시작·분리·패딩·미등록 표식 |
| 디코더 | 토큰 ID를 토큰 문자열로 변환 |

> 요약: 토크나이저는 텍스트를 정규화·분절해 사전 ID로 매핑하고 필요할 때 ID를 토큰 문자열로 변환함.

### 쉽게 이해하기 (학습용)
- 글자 모양을 통일하고(정규화), 정해진 규칙으로 자른 뒤(분절 알고리즘), 각 조각을 사전에서 번호로 찾아 붙이고(어휘 사전), 필요하면 번호를 다시 글자로 되돌리는(디코더) 순서로 이어지는 조립 라인임

## Ⅴ. 원리 및 절차 흐름도

```text
[학습] 코퍼스 -> 정규화 -> 분절 규칙·어휘 사전 학습
[인코딩] 입력 문장 -> 동일 정규화·분절 -> 토큰 ID 인코딩
```

1. 코퍼스의 문자 형식과 공백을 정규화함
2. 언어 특성과 모델 목적에 맞는 분절 규칙과 어휘 사전을 학습함
3. 입력 문장에 학습과 같은 정규화·분절 규칙을 적용함
4. 분절한 토큰을 사전의 ID로 변환해 임베딩 계층에 전달함

> 요약: 정규화·분절 기준·어휘 사전은 의미 보존 수준과 입력 토큰 수를 결정함.

### 쉽게 이해하기 (학습용)
- 학습 때는 대량의 글을 모아 자르는 규칙과 사전을 먼저 만들어 두고, 실제 문장이 들어오면 똑같은 규칙으로 잘라 그 사전의 번호표를 붙이는 두 단계로 나뉨

## Ⅵ. 실무 사례

1. 한국어 검색은 형태소 분석으로 조사·어미를 분리하고 미등록 단어는 서브워드로 나눔
2. 상품 검색은 신조어·브랜드명을 사용자 사전에 등록해 하나의 검색어로 인식함

### 쉽게 이해하기 (학습용)
- 검색어에서 조사·어미를 떼어 핵심 단어만 남기고, 새로 생긴 유행어나 상품명은 미리 사전에 등록해 여러 조각으로 쪼개지지 않고 한 단어로 인식되게 함

## Ⅶ. 결론

- 토크나이징은 자연어 모델의 입력 품질을 결정하는 전처리이며, 언어 구조와 비용 제약에 맞는 분절 기준을 선택해야 함
- 토크나이저는 모델 입력 계약이므로 사전·정규화 규칙을 모델과 함께 버전 관리하고 변경 시 전체 학습·검색 색인을 재검증해야 함

### 쉽게 이해하기 (학습용)
- 문장을 어떻게 써느냐가 이후 모든 이해의 출발점이므로 언어와 비용 사정에 맞는 방식을 고르고, 자르는 규칙을 바꾸면 이전에 만든 사전·검색 결과와 어긋나므로 함께 버전을 맞춰 다시 점검해야 함
