## Ⅰ. 개요
- **정의**: 출력층의 오차를 입력층 방향으로 역방향 전파하며, 연쇄 법칙을 이용해 가중치의 기울기를 구하는 학습 알고리즘임.
- **배경/필요성**: 다층 퍼셉트론에서 수많은 가중치를 손실이 최소화되는 방향으로 효율적으로 업데이트하기 위해 필요함.
- **출제 의도**: 순전파와 역전파의 흐름, 미분의 연쇄 법칙(Chain Rule) 원리를 정확히 이해하고 있는지 평가함.

## Ⅱ. 구성요소
```text
+------------------+       +------------------+       +------------------+
| Output Error     | ----> | Chain Rule       | ----> | Gradient Calc    |
| (Loss Func)      |       | (Derivatives)    |       | & Weight Update  |
+------------------+       +------------------+       +------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 오차 (Error) | 정답과 신경망 출력값 간의 차이 | 성적표의 감점 |
| 연쇄 법칙 | 합성 함수의 미분법, 이전 층으로 오차를 분배하는 원리 | 책임 소재 추적 |
| 가중치 갱신 | 계산된 기울기에 학습률을 곱해 가중치를 조정 | 오답 노트 기반 수정 |

> 요약: 출력 오차를 연쇄 법칙으로 미분하여 각 가중치가 오차에 미친 기여도를 구함.

## Ⅲ. 절차
```text
+-------------+   +-------------+   +-------------+   +-------------+
| 1. 순전파   |-->| 2. 오차     |-->| 3. 기울기   |-->| 4. 가중치   |
|    수행     |   |    계산     |   |    계산(역전)|   |    업데이트 |
+-------------+   +-------------+   +-------------+   +-------------+
```
1. **순전파 수행**: 입력 데이터를 네트워크에 통과시켜 최종 예측값을 산출함.
2. **오차 계산**: 예측값과 실제 타깃값 간의 차이를 손실 함수로 계산함.
3. **기울기 계산**: 연쇄 법칙을 적용하여 은닉층 방향으로 가중치의 손실에 대한 편미분(기울기)을 구함.
4. **가중치 업데이트**: 경사하강법 옵티마이저를 사용하여 기울기 반대 방향으로 가중치를 갱신함.

> 요약: 순전파로 예측 후 오차를 구하고, 역방향으로 연쇄 법칙을 적용해 가중치를 업데이트함.

## Ⅳ. 문제점
- **기울기 문제**: 층이 깊어질수록 역전파 중 기울기가 소실되거나 폭발하는 현상이 발생함.
- **메모리 소비**: 역전파 시 연쇄 법칙 계산을 위해 순전파 때의 모든 중간 활성화 값을 저장해야 함.

## Ⅴ. 개선방안
- **기울기 문제**: (단기) 적절한 활성화 함수(ReLU) 및 초기화(He) 사용 / (장기) 잔차 연결(ResNet) 도입 필요.
- **메모리 소비**: (단기) 배치 크기 조절 및 Gradient Checkpointing / (장기) 분산 학습 시스템 구축 필요.

## Ⅵ. 전망
- 딥러닝의 핵심 학습 엔진으로 계속 사용되며, 메모리 절약을 위한 다양한 하드웨어 최적화 기법이 발전할 것임.
