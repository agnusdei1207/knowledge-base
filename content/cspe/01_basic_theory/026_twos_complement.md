## 미리 알고가기

- 보수(Complement): 어떤 기점이 되는 수로부터 부족한 값을 의미하며, 디지털 회로에서 뺄셈을 덧셈으로 구현하기 위해 사용함
- 1의 보수: 이진수의 각 비트를 반전($0 \rightarrow 1, 1 \rightarrow 0$)시킨 형태임
- 2의 보수: 1의 보수에 최하위 비트($LSB$) 1을 더한 형태로, 현대 컴퓨터의 표준적인 정수 표현 방식임
- 부호 비트($MSB$): 비트열의 가장 왼쪽 비트로, 0은 양수($+$), 1은 음수($-$)를 나타냄
- 오버플로(Overflow): 연산 결과가 표현 가능한 비트 범위를 초과하여 잘못된 값이 출력되는 현상임

## Ⅰ. 개요

- **정의/개념**: 2의 보수는 모든 비트를 반전시킨 후 1을 더하여 음수를 표현하는 방식이며, 이를 통해 별도의 뺄셈 회로 없이 가산기($Adder$)만으로 모든 사칙 연산의 기초인 덧셈과 뺄셈을 통합 처리할 수 있게 함
- **배경/필요성**: '부호와 절댓값' 방식이나 '1의 보수' 방식은 $+0$과 $-0$이 중복 존재하여 0의 판정이 복잡하고 연산 결과의 보정 과정이 추가로 필요하므로, 하드웨어 구조를 단순화하고 수치 표현의 일관성을 확보하기 위해 도입됨

## Ⅱ. 특징

- 덧셈 회로 하나만으로 뺄셈을 수행할 수 있어 $ALU$(산술논리연산치) 내부의 하드웨어 복잡도를 획기적으로 줄이고 전력 소모와 칩 면적을 최적화할 수 있음
- 모든 비트가 0인 상태를 유일한 0으로 정의하므로 0의 표현이 하나만 존재하며, 이는 논리 연산에서 0인지 여부를 판단하는 분기 지연을 최소화함
- $n$비트 시스템에서 $-2^{n-1}$부터 $2^{n-1}-1$까지의 정수 범위를 표현하며, 1의 보수 방식보다 음수 한 영역을 더 넓게 표현할 수 있어 수치 효율성이 높음

## Ⅲ. 종류 및 비교

| 판단 기준 | 부호와 절댓값 | 1의 보수 (1's) | 2의 보수 (2's) |
|:---|:---|:---|:---|
| **음수 생성** | $MSB$만 1로 변경 | 모든 비트 반전 | 모든 비트 반전 + 1 |
| **0의 표현** | $+0, -0$ (2가지) | $+0, -0$ (2가지) | 유일한 0 (1가지) |
| **연산 방식** | 부호/절댓값 별도 처리 | 덧셈 후 올림수($Carry$) 보정 | 덧셈만으로 즉시 완료 |
| **장치 복잡도** | 매우 높음 | 중간 | 낮음 (최적화) |
| **표현 범위** | $-(2^{n-1}-1) \sim 2^{n-1}-1$ | $-(2^{n-1}-1) \sim 2^{n-1}-1$ | $-2^{n-1} \sim 2^{n-1}-1$ |

> 요약: 하드웨어 구현의 효율성과 0의 유일성 때문에 현대 전산 시스템은 2의 보수 방식을 표준으로 채택함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 비트 반전기 ($Inverter$) | 뺄셈 연산 시 피감수의 모든 비트를 0은 1로, 1은 0으로 뒤집어 1의 보수를 형성함 |
| 전가산기 ($Full$ $Adder$) | 두 비트와 하위 자리의 올림수($Carry$)를 합산하여 합($Sum$)과 새로운 올림수를 생성함 |
| 캐리 제어 논리 | 2의 보수 형성을 위해 뺄셈 시 최하위 가산기에 초기 캐리 입력($C_{in}$)을 1로 제공함 |
| 오버플로 검출기 | 연산 과정에서 최상위 비트($MSB$)로 들어오는 캐리와 나가는 캐리를 비교하여 오류 여부를 판별함 |

```text
[ 2의 보수 뺄셈 구조 (A - B) ]
A (Binary) ----> [ Add/Sub Control ]
B (Binary) ----> [ Bit Inverter ] ----> (A + ~B + 1) ----> Result (Sum)
                                           ^
                                           | (Carry In = 1)
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 피연산자 입력| --> | 2의 보수 변환 | --> | 이진 가산 수행| --> | 오버플로 체크 |
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **입력 및 판단** — 덧셈($A+B$)과 뺄셈($A-B$) 여부를 판단하고, 뺄셈일 경우 $B$를 보수화 대상(피감수)으로 선정함
2. **보수화 실행** — 피감수 $B$의 모든 비트를 반전시켜 1의 보수를 만들고, 연산기에 전달 시 최하위 비트에 1을 추가함 ($~B + 1$)
3. **병렬 가산** — 가산기 회로를 통해 $A$와 변환된 보수값을 비트 단위로 합산하며 발생하는 캐리를 다음 자리로 전파함
4. **결과 검증** — 연산 완료 후 $MSB$에서 발생한 캐리의 불일치 여부를 확인하여 오버플로 발생을 감지하고 최종 결과값을 출력함

## Ⅵ. 실무 적용 및 유의점

1. 시스템 개발 시 서로 다른 데이터 타입(예: 16비트 $short$ $\rightarrow$ 32비트 $int$) 간의 형변환이 일어날 때, 음수 값의 부호를 유지하기 위해 상위 비트를 부호 비트와 동일한 값으로 채우는 '부호 확장($Sign$ $Extension$)'을 명시적으로 관리해야 함
2. 정수 연산 중 발생하는 오버플로는 조용히 랩어라운드($Wrap-around$)되어 의도치 않은 대규모 음수로 바뀔 수 있으므로, 금융 및 제어 알고리즘에서는 포화 연산($Saturating$ $Arithmetic$)이나 예외 처리 코드를 삽입하여 수치 안정성을 확보해야 함

## Ⅶ. 결론

- 2의 보수는 디지털 계산 시스템의 물리적 설계를 단순화하고 연산 속도를 극대화하는 수 체계의 혁신이며, 설계자는 비트 단위의 연산 원리와 오차 발생 가능성을 철저히 관리하여 시스템의 산술적 신뢰성을 유지해야 함
