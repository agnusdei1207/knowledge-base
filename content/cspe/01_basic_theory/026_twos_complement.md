## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 음수를 이진수로 표현하는 방식으로, 양수의 모든 비트를 반전(1의 보수)한 후 1을 더하여 음수를 나타내는 체계임 |
| **배경/필요성** | 부호-크기 표현의 +0/-0 이중 표현과 뺄셈 회로 별도 필요 문제를 해결하기 위해 가감산을 단일 가산기로 처리하는 표현이 필요함 |
| **출제 의도** | 2의 보수 변환 과정과 오버플로우 탐지 원리를 이해하는지 평가함 |

## Ⅱ. 구성요소
```
+----------+     +----------+     +----------+
| 부호크기  | --> | 1의보수   | --> | 2의보수   |
| (SM)     |     | (반전)   |     | (반전+1) |
+----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| 부호-크기(SM) | MSB가 부호, 나머지가 크기를 나타냄. +0/-0 이중 표현 문제가 있음 | 양수·음수 표지판 |
| 1의 보수 | 모든 비트를 반전하여 음수를 표현함. +0/-0 문제가 여전히 존재함 | 거울 반사 |
| 2의 보수 | 1의 보수에 1을 더하여 음수를 표현함. 0이 유일하고 가감산이 동일 회로로 처리됨 | 시계 역회전(12-n) |

> 요약: 2의 보수는 반전+1로 음수를 표현하며, 0이 유일하고 가산기 하나로 가감산을 처리함.

## Ⅲ. 절차
```
+------------+     +------------+
| 양수이진   | --> | 비트반전   |
| 표현       |     | (1의보수)  |
+------------+     +------------+
                        |
+------------+     +----+-------+
| 2의보수    | <-- | +1 가산   |
| 완성       |     |           |
+------------+     +------------+
```

1. 양수 이진 표현: 표현할 양수의 절대값을 n비트 이진수로 변환함
2. 비트 반전: 모든 비트를 0→1, 1→0으로 반전하여 1의 보수를 구함
3. +1 가산: 반전된 값에 1을 더하여 2의 보수를 완성함
4. 검증: 원래 양수와 2의 보수를 더하면 2^n이 되어(캐리 발생) 0이 됨을 확인함

> 요약: 양수 → 비트 반전 → +1 가산으로 2의 보수를 구하고, 가산으로 뺄셈을 수행함.

## Ⅳ. 문제점
- 비대칭 범위: n비트에서 양수 최대 2^(n-1)-1, 음수 최소 -2^(n-1)로 범위가 비대칭임
- 오버플로우: 같은 부호의 두 수를 더할 때 결과 부호가 반전되면 오버플로우가 발생함
- 부호 확장 실수: 비트 수를 확장할 때 MSB(부호 비트)를 복제하지 않으면 값이 변경됨

## Ⅴ. 개선방안
- (단기) 오버플로우 탐지: 캐리 인·캐리 아웃 XOR이 1이면 오버플로우로 판단함
- (중기) 부호 확장 자동화: 컴파일러·ISA가 자동 부호 확장(Sign Extension)을 수행함
- (장기) 임의 정밀도: BigInteger로 고정 비트 제약 없이 정수를 처리함

## Ⅵ. 전망
- 모든 현대 CPU가 2의 보수를 정수 표현 표준으로 채택하고 있으며, RISC-V ISA 등 차세대 프로세서에서도 2의 보수 기반 정수 연산이 유지될 전망임
