# 📖 【암기용】 개념 완전 이해

> 목적: GAN을 처음 보는 사람도 생성 모델의 경쟁 학습 구조를 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 생성자와 판별자가 경쟁하며 실제 같은 데이터를 만드는 신경망
- **왜 필요한가**:
  - 라벨이 부족한 이미지·음성·시계열 영역에서 데이터 생성, 증강, 변환이 필요함.
  - GAN은 실제 분포를 명시적으로 계산하지 않고 샘플 생성기를 학습함.
- **핵심 직관**: 위조범은 더 그럴듯한 샘플을 만들고 감별사는 더 정확히 구별하면서 둘 다 학습되는 구조임.

## 깊이 이해
- **배경·문제의식**:
  - 기존 지도학습은 입력과 정답 쌍이 필요하지만, 생성 문제는 "새로운 샘플" 자체가 목표임.
  - GAN은 확률분포 수식 대신 두 네트워크의 게임으로 데이터 분포를 근사함.
- **작동 원리**:
  - 생성자(Generator)는 난수 z를 받아 가짜 샘플을 만들고, 판별자(Discriminator)는 실제 샘플과 가짜 샘플을 0~1 확률로 구분함.
  - 학습은 Minimax 목적함수로 진행됨.
- **비유**:
  - 지폐 위조범과 감정사가 같은 훈련장에 있는 구조임.
  - 감정사가 잡아내면 위조범은 패턴을 고치고, 위조범이 속이면 감정사는 판별 기준을 갱신함.
- **구체 예시**: 64x64 이미지 GAN에서 z=100차원 난수를 입력하면 생성자는 RGB 64x64x3 텐서를 만들고, 판별자는 실제 확률 0.0~1.0을 출력함.
- **흔한 오해·주의점**:
  - GAN은 학습이 자동으로 수렴하지 않음.
  - Mode Collapse, Gradient Vanishing, 데이터 편향 재현이 발생하므로 WGAN-GP, Spectral Normalization, FID 점검이 필요함.

## 연결 개념
- VAE(Variational Autoencoder) — 잠재공간을 확률적으로 모델링하는 대안 생성 모델
- 데이터 증강(Data Augmentation) — 소수 클래스 샘플 보강 적용처
- FID(Fréchet Inception Distance) — 생성 이미지 품질 평가 지표

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: GAN은 생성자와 판별자의 적대적 Minimax 학습으로 실제 데이터 분포를 근사하는 생성 모델임.
> 2. **가치**: 이미지 생성·초해상도·도메인 변환·소수 클래스 증강에서 라벨 비용을 샘플 생성으로 보완함.
> 3. **판단 포인트**: 수렴 불안정, Mode Collapse, FID·IS 평가를 함께 제시해야 답안 밀도가 확보됨.

---

## Ⅰ. 개요 및 필요성

- 정의: GAN은 두 신경망의 경쟁으로 데이터를 생성한다.
- 배경: 실제 데이터 확보가 제한되는 의료·제조·보안 로그 영역에서 합성 데이터와 도메인 변환 요구가 증가함.
- 필요성: 단순 복제보다 분포 학습이 핵심이므로 생성 품질과 다양성 지표를 함께 관리해야 함.

---

## Ⅱ. 구조 및 구성요소

```text
Noise z -> Generator -> Fake Sample -> Discriminator -> Real/Fake Score
Real Data ----------------------------> Discriminator -> Loss
Loss -> G Update / D Update -> Generated Data
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Generator | 난수 z를 이미지·음성·시계열 샘플로 변환 | ConvTranspose, Upsampling 사용 |
| Discriminator | 실제/생성 샘플을 0~1 확률로 판별 | CNN 기반 이진 분류기 |
| Adversarial Loss | G는 속이고 D는 구별하는 손실 | Minimax, BCE, Wasserstein Loss |
| Evaluation | 생성 품질과 다양성 측정 | FID 50 이하, IS, Precision/Recall |

> 요약: GAN은 생성자·판별자·적대 손실·평가 지표가 반복 갱신되며 실제 분포에 가까운 샘플을 생성함.

---

## Ⅲ. 동작원리 및 흐름도

```text
실제 데이터 수집 -> Noise Sampling -> 가짜 샘플 생성
-> 실제/가짜 판별 -> D 손실 계산 -> G 손실 계산
-> 교대 학습 -> FID/다양성 점검
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 실제 데이터와 z~N(0,1) 난수 준비 | 클래스 불균형 비율, 샘플 수 |
| 2 | Generator가 가짜 샘플 생성 | 해상도, 값 범위 0~1 |
| 3 | Discriminator가 실제/가짜 판별 | D Accuracy 60~80% 구간 |
| 4 | G/D 교대 갱신 후 평가 | FID, Mode 수, 손실 발산 여부 |

> 요약: GAN은 생성과 판별을 교대로 갱신하며, 판별 정확도와 FID를 함께 봐야 수렴 상태를 판단함.

---

## Ⅳ. 특징

| 구분 | 내용 | 판단 포인트 |
|:---|:---|:---|
| 장점 | 명시적 확률분포 없이 고차원 샘플 생성 | 64x64 이상 이미지 생성, 라벨 미사용 가능 |
| 한계 | Mode Collapse로 일부 패턴만 반복 | 클래스별 생성 비율, Recall 지표 확인 |
| 비교 대상 | VAE는 잠재공간 해석, GAN은 샘플 선명도 중심 | FID·잠재공간 연속성으로 선택 |

> 요약: GAN은 샘플 생성 표현력이 핵심이나 수렴과 다양성 관리 없이는 시험 답안에서 한계 분석이 빠짐.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존/대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | VAE는 인코더·디코더 확률 모델 | G/D 적대 학습 | 선명한 이미지 생성이면 GAN |
| 비용/성능 | 직접 촬영·라벨링은 건당 비용 발생 | 학습 후 대량 샘플 생성 | GPU 1~8장, FID 목표 충족 |
| 운영/위험 | 원본 데이터 편향 그대로 학습 | 편향·위조 악용 가능 | 데이터 출처·워터마킹 필요 |

> 요약: 선명한 합성 샘플이 목표이면 GAN, 잠재공간 해석과 재구성이 목표이면 VAE를 선택함.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| Mode Collapse | G가 일부 패턴만 학습 | Minibatch Discrimination, WGAN-GP | 클래스별 생성 분포 |
| 학습 발산 | G/D 균형 붕괴 | Learning Rate 1e-4, Spectral Norm | 손실 NaN, D Accuracy |
| 윤리·보안 악용 | Deepfake·개인정보 재현 | 워터마킹, 데이터 익명화, 사용 로그 | 탐지율, 감사 로그 |

> 요약: GAN 운영은 수렴 실패와 악용 가능성을 손실·FID·감사 지표로 통제해야 함.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 생성 품질 | FID 50 이하, IS 기준선 대비 10% 이상 | 검증셋 기반 FID 계산 |
| 다양성 | 클래스별 생성 비율 편차 10% 이하 | 샘플링 통계, Recall |
| 운영/보안 | 원본 재식별 0건, 생성물 워터마크 100% | 유사도 검색, 감사 로그 |

> 요약: GAN 도입 후 성공 여부는 FID, 다양성, 원본 재식별 지표로 판단함.

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 — 단계별 또는 항목별):**
1. 데이터 기준 수립: 원본 1만 건 이상, 클래스별 최소 500건, 개인정보 비식별 검증 후 학습셋 구성.
2. 모델 학습 통제: DCGAN 기준선 후 WGAN-GP 적용, Learning Rate 1e-4, FID 50 이하에서 후보 모델 고정.
3. 운영 검증: 생성물 워터마크, 원본 유사도 Top-1 0.95 초과 샘플 차단, 월 1회 편향 리포트 작성.

**결론 (2줄):**
- 기술사 판단: 이미지·음성 합성이 목표이면 GAN, 재구성·잠재공간 해석이 목표이면 VAE를 우선 검토함.
- 향후 방향: 생성 모델은 GAN 단독보다 Diffusion·Transformer 기반 모델과 평가 지표 거버넌스로 발전함.
