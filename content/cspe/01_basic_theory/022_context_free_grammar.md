## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 생성 규칙의 좌변이 단일 비단말 기호인 형식 문법(Type-2)으로, 프로그래밍 언어 구문과 괄호 구조를 기술하는 언어 클래스임 |
| **배경/필요성** | 정규 문법으로 표현 불가한 중첩 구조(괄호 짝, if-else)를 기술하기 위해 상위 표현력의 문법이 필요함 |
| **출제 의도** | CFG의 생성 규칙과 파스 트리, 모호성의 의미를 설명할 수 있는지 평가함 |

## Ⅱ. 구성요소
```
+----------+     +----------+     +----------+
| 비단말   | --> | 생성규칙  | --> | 파스트리  |
| (Variable)|    | (A→αβ)  |     | (유도)   |
+----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| 비단말 기호(V) | 생성 규칙의 좌변에 올 수 있는 변수(S, A, B 등)임 | 문장 구조 틀(주어·서술어) |
| 단말 기호(T) | 실제 문자열을 구성하는 최종 기호(a, b, +, if 등)임 | 실제 단어 |
| 생성 규칙 | `A → αβ` 형태로 비단말을 단말·비단말 조합으로 치환하는 규칙임 | 문장 확장 규칙 |

> 요약: 비단말(V) + 단말(T) + 생성 규칙(P) + 시작 기호(S)의 4-튜플 G=(V,T,P,S)로 문맥 자유 언어를 정의함.

## Ⅲ. 절차
```
+------------+     +------------+
| 시작기호   | --> | 생성규칙   |
| (S)        |     | 적용       |
+------------+     +------------+
                        |
+------------+     +----+-------+
| 문자열생성  | <-- | 반복유도  |
| (단말만남음)|     | (좌/우유도)|
+------------+     +------------+
```

1. 시작 기호 설정: 시작 비단말 S에서 유도를 시작함
2. 생성 규칙 적용: 비단말 하나를 선택하여 대응 규칙의 우변으로 치환함
3. 반복 유도: 비단말이 남아있으면 2단계를 반복함(좌측 유도 또는 우측 유도)
4. 문자열 생성: 모든 기호가 단말이 되면 유도가 완료되고 문자열이 생성됨

> 요약: S에서 시작 → 규칙 적용 → 반복 유도 → 단말 문자열 생성으로 언어를 정의함.

## Ⅳ. 문제점
- 모호 문법: 동일 문자열에 대해 2개 이상의 파스 트리가 존재하면 의미 해석이 불확정됨
- 좌재귀: `A → Aα` 형태의 좌재귀는 Top-Down 파서에서 무한 루프를 유발함
- 파싱 복잡도: 임의 CFG의 파싱은 CYK 알고리즘으로 O(n³)이 소요됨

## Ⅴ. 개선방안
- (단기) 모호성 제거: 연산자 우선순위·결합 규칙으로 문법을 재작성하여 모호성을 제거함
- (중기) 좌재귀 제거: `A → βA'`, `A' → αA' | ε`로 변환하여 LL 파서에 적합하게 만듦
- (장기) GLR 파서: 모호 문법도 처리 가능한 Generalized LR 파서를 적용함

## Ⅵ. 전망
- 컴파일러 구문 분석·XML/JSON 스키마·자연어 구문 분석에서 CFG가 핵심이며, 신경망 기반 파서(Neural Parser)가 자연어 CFG 파싱의 차세대 접근으로 확산될 전망임
