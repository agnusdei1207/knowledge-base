## Ⅰ. 개요
- **정의**: 불확실한 사건의 발생 가능성을 수치화하고 데이터로부터 규칙을 추론하는 수학 분야
- **배경/필요성**: 시스템 장애 예측, 품질 관리, 의사결정 등에서 불확실성을 정량적으로 다루어야 함
- **비유**: 주사위를 던지기 전에 각 눈이 나올 비율을 미리 계산해 두는 체계와 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 확률 분포와 통계적 추론 원리 이해 | 조건부 확률, 기대값, 분산, 가설검정 | 표본 분포와 모집단 분포 혼동 주의 |

> 요약: 불확실성을 수치로 표현하고 데이터에서 의미를 추출하는 기초 체계임

## Ⅱ. 구성요소
```text
  확률-통계 체계
       |
  +----+----+----+----+
  |    |    |    |    |
 표본  확률  확률  통계량 추정/
 공간  변수  분포  (평균등) 검정
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 표본 공간 | 실험에서 가능한 모든 결과의 집합 | 주사위의 눈 {1,2,3,4,5,6} |
| 확률 변수 | 표본 공간의 원소를 실수로 대응시키는 함수 | 주사위 눈을 점수로 변환하는 규칙 |
| 확률 분포 | 확률 변수가 특정 값을 가질 가능성의 분배 패턴 | 히스토그램의 막대 높이 비율 |
| 통계량 | 평균·분산·표준편차 등 데이터 특성을 요약하는 수치 | 성적표의 평균·편차 란 |
| 추정·검정 | 표본에서 모수를 추정하고 가설의 채택·기각을 판단하는 절차 | 시식 후 전체 음식 맛을 판단하는 과정 |

> 요약: 표본 공간, 확률 변수·분포, 통계량, 추정·검정이 핵심 요소임

## Ⅲ. 절차
```text
  1.데이터수집     2.기술통계      3.확률모형화     4.추론/검정
  (표본추출)      (요약통계량)    (분포가정)      (가설판단)
     |               |              |              |
     +---정리------->+---모형화---->+---검정------->+
  모집단에서       평균,분산,     정규/이항/     신뢰구간,
  표본추출        시각화계산     포아송등적합    p-value산출
```
- 1단계: 모집단에서 대표성 있는 표본을 무작위 추출함
- 2단계: 평균·분산·히스토그램 등 기술 통계로 데이터 특성을 요약함
- 3단계: 데이터에 적합한 확률 분포(정규, 이항, 포아송 등)를 가정하고 모수를 추정함
- 4단계: 귀무가설을 설정하고 p-value·신뢰구간으로 가설을 채택 또는 기각함

> 요약: 수집 → 요약 → 모형화 → 추론의 4단계로 통계 분석을 수행함

## Ⅳ. 문제점
- 표본 편향: 비대표적 표본 추출 시 모집단 특성과 괴리가 발생하여 추론 결과가 왜곡됨
- 분포 오가정: 데이터에 맞지 않는 분포를 가정하면 모수 추정 오차가 증가함
- 다중 검정 오류: 동일 데이터에 검정을 반복하면 1종 오류 확률이 누적 상승함

> 요약: 표본 편향, 분포 오가정, 다중 검정 오류가 주요 문제임

## Ⅴ. 개선방안
1. 단기: 층화·군집 표본 추출법을 적용하여 표본 대표성을 확보함
2. 중기: 적합도 검정(카이제곱, K-S 검정)으로 분포 가정의 타당성을 사전 검증함
3. 장기: 본페로니 보정, FDR 제어 등 다중 비교 보정 기법을 적용함

> 요약: 표본 설계 개선, 분포 검증, 다중 비교 보정으로 각 문제를 해결함

## Ⅵ. 전망
- 발전 방향: 머신러닝·A/B 테스트 등에서 통계적 추론 수요가 지속 확대됨
- 기술사적 판단: 베이즈 통계와 빈도주의 통계의 융합 활용이 확산되는 추세임
- 기술사 제언: 데이터 규모에 맞는 표본 설계와 검정력 분석을 사전에 수행해야 함
