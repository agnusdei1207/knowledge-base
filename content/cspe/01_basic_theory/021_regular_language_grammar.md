## Ⅰ. 개요
- 정의: 촘스키 계층의 Type 3 문법으로, 유한 오토마타(FA)에 의해 수용 가능한 언어임
- 배경/필요성: 컴파일러의 어휘 분석(Lexical Analysis), 문자열 패턴 매칭의 핵심 이론임
- 출제 의도: 정규 표현식, FA 간의 변환 및 펌핑 레마를 통한 정규성 판별 능력 검증

## Ⅱ. 구성요소
- ASCII 구조도
  +----------+       (Input)       +--------------+
  |  Regex   | ------------------> | Finite State |
  | (Pattern)| <------------------ |   Automata   |
  +----------+      (Accept/Reject)+--------------+

- 구성요소 표
| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| 터미널 기호 | 실제 문자열을 구성하는 기본 단위 | 단어 |
| 논터미널 기호 | 문법 규칙 내의 중간 상태 변수 | 품사 |
| 생성 규칙 | A -> aB 또는 A -> a 형태의 치환 규칙 | 문법 규칙 |
| 시작 기호 | 문장 생성이 시작되는 루트 기호 | 문장 시작 |
> 요약: 정규 문법은 유한한 상태 변화를 통해 패턴을 정의하는 가장 단순한 형식 언어임

## Ⅲ. 절차
- ASCII 흐름도
  [RE] -> (Thompson) -> [NFA] -> (Subset Const) -> [DFA] -> [Min-DFA]

1. 정규 표현식 설계: 찾고자 하는 문자열 패턴을 RE로 정의함
2. NFA 변환: 엡실론 전이를 포함한 비결정적 유한 오토마타 생성함
3. DFA 결정화: 상태 집합 구성을 통해 결정적 유한 오토마타로 변환함
4. 최소화: 중복 상태를 제거하여 가장 효율적인 상태 천이도로 최적화함
> 요약: RE에서 DFA 최소화에 이르는 과정은 컴파일러 어휘 분석기의 자동 생성 원리임

## Ⅳ. 문제점
- 메모리 부재: 중첩된 괄호나 동일 개수 카운팅(a^n b^n) 표현 불가함
- 펌핑 레마 한계: 특정 언어가 정규 언어가 아님을 증명할 뿐, 정규성 자체 증명은 부족함

## Ⅴ. 개선방안
- CFG 도입: 재귀적 구조 표현을 위해 문맥 자유 문법(Type 2)을 사용함
- PDA 활용: 스택 메모리를 갖춘 푸시다운 오토마타로 인지 범위를 확장함

## Ⅵ. 전망
- 지능형 패턴 매칭: LLM의 출력 구조를 특정 스키마(JSON 등)로 강제하는 Constrained Decoding 기술의 핵심 이론으로 재부각됨
- 보안 가속화: 고성능 IDS/IPS에서 대규모 트래픽의 실시간 필터링을 위한 FPGA 기반 정규 표현식 하드웨어 가속기 설계의 근간이 됨
- CSF: 정규 언어의 한계를 명확히 인지하고, 상태 폭발 문제를 방지하기 위한 효율적인 DFA 최소화 및 최적화 기법의 적용이 필수적임
