## Ⅰ. 개요
- 정의: 데이터의 효율적 표현(소스)과 전송 오류에 대한 내성 확보(채널)를 위한 기법임
- 배경/필요성: 한정된 대역폭 내에서 데이터를 최대한 압축하고 신뢰성 있게 전달해야 함
- 출제 의도: 두 코딩 방식의 목적, 특징 및 대표적 알고리즘 비교 분석

## Ⅱ. 구성요소
- ASCII 구조도
  [Source] -> [Source Encoder] -> [Channel Encoder] -> (Channel)
               (압축/제거)          (중복/추가)

- 구성요소 표
| 구분 | 소스 코딩 (Source Coding) | 채널 코딩 (Channel Coding) |
| :--- | :--- | :--- |
| 주요 목적 | 데이터 압축 (효율성) | 오류 검출 및 정정 (신뢰성) |
| 핵심 원리 | 불필요한 정보(Redundancy) 제거 | 의도적 중복(Redundancy) 추가 |
| 대표 사례 | Huffman, JPEG, MP3, MPEG | Hamming, CRC, Turbo, LDPC |
> 요약: 소스 코딩은 '살 빼기'이고, 채널 코딩은 '보호 장구 착용'임

## Ⅲ. 절차
- ASCII 흐름도
  [Original] -> (Src Enc) -> [Compact] -> (Ch Enc) -> [Robust] -> (Trans)

1. 소스 분석: 정보원(Source)의 통계적 특성과 중복성을 분석함
2. 압축 수행: 엔트로피에 가깝게 비트 수를 최소화하여 소스 코딩함
3. 보호 비트 추가: 전송 환경의 노이즈를 고려하여 패리티 등 추가 비트를 삽입함
4. 전송 및 복호: 수신측에서 채널 복호(오류 수정) 후 소스 복호(압축 해제)를 수행함
> 요약: 효율성과 신뢰성이라는 상충되는 목표를 단계별로 달성함

## Ⅳ. 문제점
- 상충 관계: 과도한 압축은 오류에 취약하게 만들고, 과도한 채널 코딩은 전속 속도를 저하시킴
- 연산 부하: 고성능 코딩 알고리즘일수록 복잡한 연산과 지연(Latency)이 발생함

## Ⅴ. 개선방안
- 결합 소스-채널 코딩 (JSCC): 두 과정을 통합 최적화하여 전체 성능을 극대화함
- 적응형 코딩: 채널 상태(SNR)에 따라 압축률과 오류 정정 능력을 실시간으로 조절함

## Ⅵ. 전망
- 5G/6G 통신: LDPC, 폴라 코드 등 고성능 채널 코딩이 통신 품질의 핵심임
- 차세대 미디어: AI 기반 소스 코딩(Deep Compression)으로 초고화질 영상 전송 실현됨
