# 📖 【암기용】 개념 완전 이해

> 목적: PCA를 처음 봐도 완전히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 여러 변수의 분산을 가장 많이 보존하는 새 축으로 데이터를 축소하는 차원 축소 기법
- **왜 필요한가**: 변수 수가 많으면 시각화, 학습, 해석이 복잡해지고 다중공선성으로 모델 계수가 흔들릴 수 있음
- **핵심 직관**: 데이터 구름을 가장 길게 펼친 방향부터 새 좌표축으로 잡아 정보 손실을 계산하며 차원을 줄임

## 깊이 이해
- **배경·문제의식**: 100개 지표를 모두 쓰면 노이즈와 중복 정보가 모델에 들어간다. PCA는 공분산 구조를 보고 서로 겹치는 정보를 소수의 주성분으로 압축함.
- **작동 원리**: 데이터를 표준화하고 공분산 행렬의 고유값·고유벡터를 구함. 고유값이 큰 축부터 선택하며 누적 설명분산비 90~95%를 기준으로 차원을 정함.
- **비유**: 3차원 물체의 그림자를 가장 정보가 많이 보이는 방향으로 비추어 2차원 사진으로 남기는 과정과 유사함.
- **구체 예시**: 서버 지표 40개를 PCA로 5개 주성분까지 줄였을 때 누적 설명분산비가 92%라면, 대시보드와 이상 탐지 입력을 5차원으로 구성함.
- **흔한 오해·주의점**: PCA 주성분은 원래 변수의 단순 선택이 아니라 선형 결합임. 단위가 다른 변수는 표준화하지 않으면 큰 단위 변수가 주성분을 지배함.

## 연결 개념
- 고유값·고유벡터: 주성분 방향과 분산 크기 계산 기반
- 클러스터링: PCA 축소 후 군집 시각화에 활용
- 회귀 분석: 다중공선성 완화와 PCR에 연결

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: PCA는 공분산 행렬의 고유벡터를 이용해 분산 보존이 큰 축으로 데이터를 투영하는 선형 차원 축소 기법임.
> 2. **가치**: 고차원 데이터의 시각화, 저장량 축소, 노이즈 감소, 다중공선성 완화에 활용됨.
> 3. **판단 포인트**: 표준화 여부, 누적 설명분산비 90~95%, 주성분 해석성, 선형성 가정이 적용 가능성을 좌우함.

---

## Ⅰ. 개요 및 필요성

PCA는 분산 보존형 차원 축소 기법이다. 고차원 데이터는 중복 변수와 노이즈로 분석 비용과 모델 변동성을 키운다. PCA는 주요 변동 축을 선택해 정보 손실률을 수치로 관리한다.

---

## Ⅱ. 구조 및 구성요소

```text
원본 변수 X -> 표준화 Z -> 공분산 행렬 -> 고유분해 -> 주성분 점수
              / 고유값·고유벡터·설명분산비 산출
```

| 구성요소 | 역할 | 판단 기준 |
|:---|:---|:---|
| 표준화 데이터 | 단위 차이 제거 | 평균 0, 분산 1 |
| 공분산 행렬 | 변수 간 동시 변동 구조 표현 | 대칭 행렬 |
| 고유벡터 | 새 축 방향 | 주성분 로딩 |
| 고유값 | 축별 분산 크기 | 설명분산비 |

> 요약: PCA는 표준화된 데이터의 공분산 구조를 고유분해해 분산이 큰 축부터 주성분으로 선택함.

---

## Ⅲ. 동작원리 및 흐름도

```text
데이터 표준화 -> 공분산 계산 -> 고유분해 -> 주성분 선택 -> 저차원 투영
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 결측 처리와 표준화 수행 | 변수 단위 제거 |
| 2 | 공분산 또는 상관행렬 계산 | 변수 간 선형 관계 |
| 3 | 고유값·고유벡터 산출 | 고유값 내림차순 |
| 4 | 누적 설명분산 기준 차원 선택 | 90~95% 보존 |

> 요약: PCA는 고유값 순서대로 주성분을 고르고, 누적 설명분산비로 정보 보존 수준을 결정함.

---

## Ⅳ. 특징

| 구분 | 원본 변수 분석 | PCA 적용 | 수치·판단 포인트 |
|:---|:---|:---|:---|
| 차원 | 변수 전체 사용 | 주성분 k개 사용 | 누적 설명분산 90~95% |
| 변수 관계 | 다중공선성 영향 | 직교 축으로 변환 | PC 간 상관 0 |
| 해석 | 원 변수 의미 명확 | 로딩 해석 필요 | 로딩 절댓값 0.5 이상 주목 |
| 한계 | 고차원 노이즈 포함 | 비선형 구조 표현 제한 | Kernel PCA 대안 |

> 요약: PCA는 분산 보존과 직교 변환으로 고차원을 압축하지만, 주성분 해석성과 비선형 구조 표현 한계를 함께 검토해야 함.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존·대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | 원본 변수 선택은 일부 변수만 유지 | PCA는 모든 변수의 선형 결합으로 새 축 생성 | 중복 변수·공선성 완화 필요 시 선택 |
| 비용/성능 | 전체 변수 학습은 차원 증가로 학습시간 증가 | k개 주성분으로 저장량·연산량 축소 | 누적 설명분산 90~95% 기준 |
| 운영/위험 | 원 변수는 설명 용이 | PCA는 로딩 해석과 재학습 관리 필요 | 로딩 절댓값 0.5 이상 변수 해석 |

> 요약: PCA는 차원과 공선성을 줄이는 대신 주성분 해석 비용이 생기므로 설명분산과 로딩을 함께 제시함.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 정보 손실 | 주성분 수 과소 선택 | Scree plot, 누적 설명분산 90~95% 적용 | 설명분산비, 재구성 오차 |
| 해석 저하 | 원 변수 의미가 선형 결합으로 변환 | 로딩 상위 변수 3개 표시, 원 변수 모델 병행 | 로딩 값, SHAP 비교 |
| 스케일 지배 | 표준화 누락 | 평균 0·분산 1 표준화 후 PCA 수행 | 변수 분산, PC1 로딩 편중 |

> 요약: PCA 리스크는 정보 손실·해석 저하·스케일 편향이며, 설명분산·로딩·표준화로 통제함.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 정보 보존 | 누적 설명분산 90~95% | Explained variance ratio |
| 차원 축소 효과 | 변수 40개 -> 주성분 5~8개 | 차원 수, 학습시간 비교 |
| 모델 영향 | 검증 RMSE·F1 저하 3%p 이내 | PCA 전후 교차 검증 |

> 요약: PCA 적용 성패는 설명분산 보존, 차원 감소 폭, downstream 모델 지표 변화로 판단함.

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 운영 지표 축소: CPU·메모리·I/O·네트워크 40개 지표를 누적 설명분산 95% 기준 5~8개 주성분으로 변환
2. 시각화: PCA 2D/3D 투영으로 군집 겹침과 이상치 위치를 확인하고 Silhouette 지표와 대조
3. 모델 전처리: VIF 10 초과 변수군은 PCA 또는 Ridge 회귀로 대체해 계수 변동성 통제

**결론 (2줄):**
- 기술사 판단: 변수 해석이 우선이면 원 변수 선택, 차원 축소와 공선성 통제가 우선이면 PCA를 선택함
- 향후 방향: 비선형 데이터는 t-SNE, UMAP, Autoencoder와 비교해 시각화 목적과 예측 목적을 분리해야 함
