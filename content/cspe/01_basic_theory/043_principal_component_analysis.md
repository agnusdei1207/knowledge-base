# 📖 【암기용】 개념 완전 이해

> 목적: 주성분 분석(PCA)을 처음 보는 사람도 완벽히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: **차원 축소**(Dimensionality Reduction)를 수행하는 대표적인 **비지도학습**(Unsupervised Learning) 기법 — 여러 변수(차원)로 흩어진 데이터를, 원래의 분산(정보)을 가장 많이 보존하는 소수의 새로운 축(주성분)으로 요약해 표현한다.
- **왜 필요한가**: 변수(피처)가 많아질수록 데이터 공간이 기하급수적으로 희박해져 모델이 패턴을 학습하기 어려워지고(차원의 저주), 연산량과 저장 비용도 함께 커진다. 서로 상관된 변수들을 몇 개의 독립적인 축으로 압축하면 이 문제를 동시에 완화할 수 있다.
- **핵심 직관**: 데이터가 가장 넓게 퍼진 방향(분산이 가장 큰 축)에는 데이터를 구분 짓는 정보가 가장 많이 담겨 있다. 그 방향을 1번 축으로 삼고, 거기 직교하면서 그다음으로 많이 퍼진 방향을 2번 축으로 삼는 식으로 좌표축을 새로 뽑는 것이 PCA다.

## 핵심 용어 정리 (내부에 등장하는 것들)

| 용어 | 의미 | 비유 |
|:---|:---|:---|
| 차원 축소 | 변수(차원) 개수를 줄이면서 데이터의 핵심 정보는 최대한 유지하는 작업 — PCA가 하는 일 자체 | 고화질 사진을 화질 손실 최소로 압축 |
| 비지도학습 | 정답(label) 없이 데이터 자체의 구조(분산·분포)만 보고 패턴을 찾는 학습 방식 | 정답지 없이 스스로 분류 기준을 세움 |
| 분산(variance) | 데이터가 평균에서 얼마나 넓게 퍼져 있는지의 정도 — PCA가 최대화하려는 대상 | 과녁에서 화살들이 흩어진 정도 |
| 공분산 행렬(covariance matrix) | 변수쌍마다 "함께 변하는 정도"를 정리한 정방 대칭 행렬 | 변수들 간 궁합표 |
| 고유벡터(eigenvector) | 공분산 행렬을 분해했을 때 나오는, 데이터가 늘어선 새로운 방향(축) | 사진을 찍을 각도 |
| 고유값(eigenvalue) | 그 고유벡터 방향으로 데이터가 퍼진 정도(분산의 크기) | 그 각도에서 보이는 피사체의 크기 |
| 주성분(principal component) | 고유값이 큰 순서로 채택된 고유벡터들 — PC1, PC2, ... | 가장 특징이 잘 보이는 촬영 각도 1순위, 2순위 |
| 설명분산비율(explained variance ratio) | 특정 주성분의 고유값이 전체 고유값 합에서 차지하는 비중 | 그 각도 하나로 피사체를 몇 % 설명하는지 |
| 표준화(standardization) | 변수마다 단위·스케일이 다른 문제를 없애기 위해 평균 0, 표준편차 1로 맞추는 전처리 | 다른 저울로 잰 몸무게를 같은 단위로 환산 |
| 직교(orthogonal) | 두 축(벡터)이 서로 수직이라 완전히 독립적인 정보를 담는 상태 | 지도의 가로축과 세로축처럼 서로 안 겹침 |

## 깊이 이해

### 왜 PCA가 필요했나 (배경)
- 변수가 2~3개면 산점도로 눈으로 직접 패턴을 볼 수 있지만, 실무 데이터는 수십~수만 차원(예: 유전자 발현 데이터, 이미지 픽셀, 텍스트 임베딩)인 경우가 흔하다. 차원이 늘어날수록 같은 개수의 데이터 포인트가 공간에 훨씬 희박하게 흩어지고("차원의 저주"), 변수들끼리도 서로 상관관계를 가지며 중복 정보를 나른다.
- 예를 들어 국어·영어·수학·과학 4과목 점수가 있을 때, 국어와 영어 점수는 대체로 같이 오르내리고(문과 성향) 수학과 과학도 같이 오르내린다(이과 성향). 이 상관관계를 무시하고 4차원을 그대로 다루면 사실상 2가지 독립적인 정보를 4배로 부풀려 쓰는 셈이다. PCA는 이런 중복을 수학적으로 찾아내 "문과 성향 축", "이과 성향 축" 같은 소수의 독립 축으로 요약한다.

### 작동 원리 — 수치로 이해
1. **평균 중심화**: 각 변수에서 평균을 빼서 원점이 0이 되도록 이동시킨다. (분산·공분산은 평균을 기준으로 계산되므로 이 단계가 선행되어야 한다.)
2. **공분산 행렬 계산**: 예를 들어 두 과목 점수(편차값 기준)의 공분산 행렬이 다음과 같이 나왔다고 하자.

  $$\Sigma = \begin{bmatrix} 3 & 2 \\ 2 & 3 \end{bmatrix}$$

  대각 원소(3, 3)는 각 변수 자신의 분산이고, 비대각 원소(2)는 두 변수의 공분산이다. 공분산이 양수(2)라는 것은 두 과목 점수가 같은 방향으로 함께 움직인다는 뜻이다.
3. **고유값 분해**: $\det(\Sigma - \lambda I) = 0$ 을 풀면 $(3-\lambda)^2 - 2^2 = 0 \Rightarrow 3-\lambda = \pm 2 \Rightarrow \lambda = 5 \text{ 또는 } 1$. 두 고유값의 합(5+1=6)은 정확히 원래 두 변수의 분산 합(3+3=6)과 같다 — 고유값 분해는 총 분산을 재배분할 뿐 새로 만들거나 없애지 않는다.
   - $\lambda=5$에 대응하는 고유벡터는 $(1,1)/\sqrt2$ 방향이다(두 과목이 같이 오를 때의 방향). $\lambda=1$에 대응하는 고유벡터는 $(1,-1)/\sqrt2$ 방향이다(한쪽만 유독 오르내리는 잔여 패턴).
   - 이 둘은 내적이 $\frac{1}{\sqrt2}\cdot\frac{1}{\sqrt2} + \frac{1}{\sqrt2}\cdot(-\frac{1}{\sqrt2}) = 0$ 이라 서로 직교한다.
4. **설명분산비율 계산**: PC1(λ=5)의 설명분산비율 $= 5/(5+1) = 83.3\%$, PC2(λ=1)는 $1/6 = 16.7\%$. 즉 두 과목의 공분산행렬 기준 2차원짜리 정보 중 PC1 하나만 남겨도 전체 분산의 83.3%를 그대로 보존한다.
5. **투영**: 상위 K개(여기선 PC1 하나)의 고유벡터로 원본 데이터를 내적해 새로운 좌표값(주성분 점수)을 얻는다. $Z = XW$ ($W$는 선택된 고유벡터를 열로 쌓은 행렬).

### 표준화가 왜 필요한가
- 공분산·분산은 측정 단위에 따라 값의 크기가 완전히 달라진다. 예를 들어 키를 cm로 재면 분산이 약 100(표준편차 10cm) 정도지만, 몸무게를 g 단위로 재면 분산이 수천만 단위로 튀어 오른다.
- 표준화 없이 PCA를 돌리면, 공분산 행렬의 대각 원소가 단위 때문에 큰 변수(몸무게-g)가 압도적으로 커지고, 고유값 분해 결과 PC1이 실제 상관관계와 무관하게 그 변수 방향으로 쏠려버린다. 즉 "정보가 많아서"가 아니라 "숫자가 커서" 1등 축이 되는 왜곡이 생긴다.
- 그래서 PCA 실행 전에는 모든 변수를 평균 0, 표준편차 1로 맞추는 표준화(Z-score)를 적용해, 공분산 행렬이 사실상 상관계수 행렬처럼 단위 독립적으로 작동하게 만든다.

### 왜 분산이 최대인 방향을 고르면 정보 손실이 적은가
- 데이터 전체의 총 분산(각 변수 분산의 합, 즉 공분산 행렬의 대각합 trace)은 어떤 축을 고르든 변하지 않는 고정값이다. 데이터를 특정 축에 투영하면, 피타고라스 정리에 의해 "원래 총 분산 = 그 축 방향으로 보존된 분산 + 그 축과 수직 방향으로 버려진 분산(재구성 오차)"으로 정확히 나뉜다.
- 따라서 "투영 후 보존되는 분산을 최대화"하는 것과 "투영 후 원본과의 거리(재구성 오차)를 최소화"하는 것은 수학적으로 완전히 동일한 목표다. 분산이 가장 큰 방향을 고르는 이유는 그 방향이 곧 정보 손실(재구성 오차)이 가장 작은 방향이기 때문이다.

### 코드로 보면
```python
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

X_scaled = StandardScaler().fit_transform(X)   # 1) 표준화
pca = PCA(n_components=2)
Z = pca.fit_transform(X_scaled)                 # 2~5) 공분산행렬~투영을 한 번에 수행
print(pca.explained_variance_ratio_)            # 예: [0.833, 0.167]
```

### 비유·오해
- **비유**: 3차원 주전자를 카메라로 찍어 2차원 사진에 담을 때, 손잡이와 주둥이가 가장 잘 드러나는 각도(분산이 최대인 축)에서 찍어야 정보 손실이 적다. 위에서 수직으로 내려찍으면(분산이 작은 축) 둥근 원 하나로만 보여 형체 정보가 대부분 사라진다.
- **흔한 오해**: "PCA는 변수를 그냥 몇 개 골라서 버리는 것"이라는 오해가 많다. 실제로는 기존 변수를 선택/삭제하는 게 아니라, 기존 변수들을 선형 결합해 완전히 새로운 축(주성분)을 만들어내는 것이다. 그래서 PC1이 구체적으로 무엇을 의미하는지 원래 변수 이름으로 곧바로 설명하기 어려운 경우가 많다.
- **또 다른 오해**: PCA는 분산(선형 관계)만 본다. 데이터가 태극 문양이나 스위스 롤처럼 비선형으로 꼬여 있으면, 분산이 최대인 방향을 아무리 찾아도 그 꼬인 구조를 풀어내지 못한다(이때는 커널 PCA, t-SNE, UMAP 같은 비선형 기법이 필요하다).

## 연결 개념
- 고유값·고유벡터(Eigenvalue/Eigenvector) — PCA가 새로운 축을 찾을 때 사용하는 선형대수학의 뼈대
- 차원의 저주(Curse of Dimensionality) — 변수가 많아질수록 데이터 공간이 희박해져 학습 성능이 떨어지는 현상, PCA가 완화하려는 문제
- 표준화/정규화(Standardization) — PCA를 실행하기 전 반드시 거쳐야 하는 전처리 단계
- t-SNE·커널 PCA — 선형 축소인 PCA의 한계(비선형 구조)를 보완하는 기법
- 044 유사도 측정 — PCA로 축소된 저차원 공간에서 유클리드/코사인 유사도를 계산하면 연산이 훨씬 가벼워짐

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: PCA는 데이터의 공분산 행렬을 고유값 분해하여, 가장 높은 분산(정보량)을 가지는 서로 직교하는 새로운 기저(Principal Component)로 데이터를 선형 투영하는 차원 축소 기법이다.
> 2. **가치**: 차원의 저주(Curse of Dimensionality)를 해소하고 다중공선성을 제거하여, 딥러닝/머신러닝의 연산 복잡도를 낮추고 모델의 과적합을 방지한다.
> 3. **판단 포인트**: 정보 손실을 최소화하기 위해 '누적 기여율(Cumulative Explained Variance)'이 85~95%에 달하는 지점에서 주성분 개수를 절단(Truncation)해야 한다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| PCA의 수학적 도출 원리 이해 | 공분산 행렬, 고유벡터(주축), 고유값(분산 크기) 매칭 | 단순 "차원을 줄인다" 식의 추상 서술 절대 금지 |
| 차원 축소에 따른 정보 손실 검증 지표 | 누적 기여율 산출 공식과 주성분 개수($K$) 선택 기준 | "정보 손실이 없다"는 오개념 사용 주의 |

> 요약: 공분산 행렬의 분해를 통해 직교하는 축을 찾는 수리적 과정을 명시하고, 비선형 한계와 이를 평가하는 정량적 지표를 제시해야 한다.

## Ⅰ. 개요 및 필요성

- 정의: 다차원 데이터의 분산을 최대한 보존하면서, 서로 직교하는 소수의 새로운 변수(주성분)들의 선형 결합으로 데이터를 압축하는 기법
- 배경: 머신러닝 피처(Feature)가 늘어날수록 빈 공간이 기하급수적으로 커지는 차원의 저주로 인해 모델 성능이 급락함
- 필요성: 연관성(상관관계)이 높은 변수들을 하나의 주축으로 병합해 다중공선성을 제거하고 시스템 연산량을 최적화해야 함

## Ⅱ. 구조 및 구성요소

```text
원본 데이터(X) -> 중앙화(Mean 0) -> 공분산 행렬(Σ) 생성 -> 고유 분해(Eigen Decomposition) -> 축 선택 및 투영(Z)
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 데이터 스케일링 | 변수 간 단위 차이가 분산 계산을 왜곡하는 것 방지 | StandardScaler (평균 0, 분산 1) 필수 |
| 공분산 행렬 ($\Sigma$) | 각 변수 간의 선형 상관관계(퍼짐 정도)를 수치화 | $\Sigma = \frac{1}{n-1} X^T X$ (정방 대칭 행렬) |
| 고유벡터 ($V$) | 데이터의 분산이 최대가 되는 새로운 직교 좌표축 (주성분) | $V_1, V_2, \dots$ (서로 수직, 내적=0) |
| 고유값 ($\lambda$) | 각 고유벡터(주축)가 설명하는 데이터의 분산 크기 | 크기순 정렬을 통해 차원 절단(Truncation) 기준 제공 |

> 요약: PCA는 스케일링된 데이터의 공분산 행렬에서 직교하는 고유벡터를 도출하여, 정보량이 가장 큰 축 순서대로 좌표계를 재정렬한다.

---

## Ⅲ. 동작원리 및 흐름도

```text
표준화 적용 -> 공분산 행렬 산출 -> det(Σ - λI)=0 수식 해 도출 -> 고유값 크기순 정렬 -> 누적 기여율 기반 K차원 투영
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 변수 간 스케일 표준화 (Standardization) | 특성 간 분산 스케일 1로 통일 |
| 2 | 공분산 행렬 도출 및 고유 분해 수행 | $\Sigma v = \lambda v$ 유도 |
| 3 | 고유값 $\lambda_i$ 크기 내림차순 정렬 및 누적합 계산 | 설명된 분산 비율(Explained Variance Ratio) |
| 4 | 상위 $K$개 고유벡터 행렬($W$)을 이용해 원본 투영 | 압축 데이터 $Z = XW$ 산출 |

> 요약: 공분산 행렬의 고유 분해를 통해 분산이 큰 주성분 순으로 랭킹을 매기고, 목표하는 정보 보존율에 맞춰 하위 차원을 버린다.

---

## Ⅳ. 특징

| 구분 | 내용 | 판단 포인트 |
|:---|:---|:---|
| 직교성 (Orthogonality) | 추출된 모든 주성분(PC1, PC2)은 서로 직교함 (상관관계 0) | 다중공선성(Multicollinearity) 완벽 제거 보장 |
| 차원 절단 가능성 | 고유값이 작을수록 노이즈일 확률이 높아 과감히 버릴 수 있음 | 데이터 압축 및 시각화(2D/3D) 용이 |
| 해석의 난해함 | 주성분은 기존 변수들의 혼합이므로, PC1 자체가 무엇인지 인간이 해석하기 어려움 | 변수 중요도 파악 시 제약 존재 |

> 요약: 직교 변환을 통해 다중공선성을 제거하는 압도적 이점이 있으나, 변환된 축의 직관적 해석이 어렵고 비선형 관계는 잡아내지 못한다.

## Ⅴ. 심화 비교 및 적용 판단

| 구분 | 선형 PCA | 커널 PCA (Kernel PCA) | t-SNE | 선택 기준 |
|:---|:---|:---|:---|:---|
| 맵핑 원리 | 선형 투영 (행렬 곱) | 커널 트릭을 통한 고차원 비선형 투영 | 확률 분포 간 KL-Divergence 최소화 | 데이터의 기하학적 분포 특성 |
| 전역/지역 | 데이터의 전역(Global) 구조 보존 | 비선형 전역 구조 보존 | 지역(Local) 이웃 구조 보존(시각화 특화) | 분류 모델 투입 전처리 vs 차원 시각화 |
| 연산 복잡도 | $O(D^3)$ (고유분해 기준) | 커널 행렬 계산으로 $O(N^3)$ | 매우 높음 (대규모 데이터 직접 투입 불가) | 실시간 처리 및 대용량 배치 처리 여부 |

> 요약: 머신러닝 전처리와 속도 최적화가 목적이면 선형 PCA를, 복잡한 군집의 2차원 정밀 시각화가 목적이면 t-SNE를 사용한다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 스케일 미통일 왜곡 | 측정 단위가 큰 변수(예: 가격)가 첫 번째 주성분(PC1)을 독식함 | PCA 수행 직전 반드시 Z-Score 정규화(StandardScaler) 필수 적용 | 각 변수의 평균 및 표준편차 |
| 선형 한계 | 스위스 롤(Swiss Roll)처럼 꼬인 비선형 데이터 투영 시 붕괴 | 비선형 매니폴드 학습(t-SNE, UMAP, Kernel PCA)으로 전환 | PCA 후 군집간 분리도 저하 (실루엣 하락) |
| 정보 손실 | 차원을 너무 많이 줄여 핵심 분류 신호까지 소실됨 | Scree Plot을 통한 Elbow 지점 탐색, 누적 기여율 임계치 설정 | 누적 기여율(Cumulative Explained Variance) |

> 요약: 스케일링 누락은 PCA의 가장 흔한 치명적 실수이므로 파이프라인에 강제 적용하고, 비선형 구조 발견 시 매니폴드 기법으로 우회한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 차원 압축률 | 기존 차원 대비 파라미터 수 50% 이상 감소 | 압축 전/후 Feature 컬럼 수 비교 |
| 누적 분산 보존율 | 주성분 K개가 원본 분산의 85~95% 이상 설명 | Scree Plot 꺾임점(Elbow) 확인 |
| 다운스트림 성능 | PCA 적용 후에도 최종 모델 정확도(F1) 하락폭 2% 이내 | 모델 Train/Validation 검증 |

> 요약: 성공적인 PCA는 목표 분산(90% 이상)을 유지하면서도 모델의 훈련 및 추론 속도를 획기적으로 개선해야 한다.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 — 단계별 또는 항목별):**
1. 이미지 인식 압축: 1만 차원의 고해상도 얼굴 이미지(Eigenface) 학습 시, PCA로 상위 100개의 주축(PC)만 추출하여 분류 모델의 메모리 소모를 줄이고 과적합을 방지한다.
2. 금융 지표 다중공선성 제거: 금리, 물가, 환율 등 연관성이 매우 높은 거시 경제 지표 50개를 넣기 전, PCA를 돌려 서로 직교하는 5개의 독립 주성분으로 변환해 회귀 분석의 안정성을 높인다.
3. 고차원 클러스터링 시각화: 300차원의 텍스트 임베딩 모델(Word2Vec)을 클러스터링한 후 경영진 보고를 위해, 상위 2개의 주성분(PC1, PC2)만 추출하여 2D 평면 산점도로 시각화한다.

**결론 (2줄):**
- 기술사 판단: PCA는 "데이터의 가장 중요한 특징(분산)만 남기고 노이즈는 버린다"는 직관을 수학적 행렬 분해로 완벽히 구현한 차원 축소의 절대적 베이스라인이다.
- 향후 방향: 최근엔 단순 선형 PCA를 넘어, 딥러닝 기반의 비선형 차원 축소인 오토인코더(Autoencoder)가 대규모 복잡계 데이터의 특징 추출(Feature Extraction)을 대체하고 있다.
