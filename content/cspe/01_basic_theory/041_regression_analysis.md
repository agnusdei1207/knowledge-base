## 미리 알고가기

- 회귀($Regression$): 평균으로 돌아간다는 뜻으로, 변수들 사이의 경향성을 찾아 수식으로 정립하는 과정임
- 독립 변수($X$): 원인이 되는 변수로, 종속 변수의 값을 결정하거나 설명하는 변수임
- 종속 변수($Y$): 결과가 되는 변수로, 독립 변수의 변화에 따라 값이 변하는 관찰 대상임
- 결정 계수($R^2$): 모델이 실제 데이터를 얼마나 잘 설명하는지를 나타내는 지표(0~1 사이)임

## Ⅰ. 개요

- **정의/개념**: 회귀 분석은 하나 이상의 독립 변수($X$)와 연속형 종속 변수($Y$) 사이의 상관관계를 통계적으로 분석하여 수학적 모델(회귀식)을 도출하고, 이를 통해 새로운 데이터에 대한 예측이나 변수 간의 영향력을 평가하는 기법임
- **배경/필요성**: 과거의 데이터를 바탕으로 향후의 매출 예측, 비용 산정, 성능 지표 분석 등 비즈니스 및 공학적 현상의 인과관계를 정량화하고 미래 수치를 추정하기 위해 필수적임

## Ⅱ. 특징

- 독립 변수의 개수에 따라 단순 회귀($X$ 1개)와 다중 회귀($X$ 2개 이상)로 구분되며, 독립 변수가 늘어날수록 모델의 설명력은 높아지나 과적합($Overfitting$)의 위험도 함께 증가함
- 종속 변수가 연속된 수치가 아닌 범주형(성공/실패 등)일 경우, 시그모이드 함수를 적용한 '로지스틱 회귀'를 사용하여 발생 확률을 예측하는 분류 모델로 확장 가능함
- 도출된 회귀 계수($\beta$)를 통해 특정 변수가 결과에 미치는 영향의 방향과 크기를 직접적으로 해석할 수 있어, 모델의 '설명 가능성'이 매우 높음

## Ⅲ. 종류 및 비교

| 판단 기준 | 선형 회귀 (Linear) | 로지스틱 회귀 (Logistic) | 다항 회귀 (Polynomial) |
|:---|:---|:---|:---|
| **종속변수 유형** | 연속형 수치 | 범주형 (이진/다중) | 연속형 수치 |
| **관계 형태** | 직선 ($Y = AX + B$) | $S$자 곡선 (확률) | 고차 곡선 ($Y = AX^2 + BX + C$) |
| **핵심 목적** | 수치값 예측 | 특정 클래스 소속 확률 예측 | 비선형적 수치 경향 분석 |
| **주요 활용** | 아파트 가격, 기온 예측 | 스팸 분류, 암 진단 | 복잡한 물리 현상 모델링 |

> 요약: 선형은 수치에, 로지스틱은 분류에, 다항은 곡선 형태의 복잡한 경향성에 특화됨.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 회귀 계수 ($\beta$) | 독립 변수의 변화량이 종속 변수에 미치는 가중치(기울기)임 |
| 절편 ($\beta_0$) | 모든 독립 변수가 0일 때의 종속 변수 기본값임 |
| 잔차 ($Residual$) | 실제 관측값과 모델이 예측한 값 사이의 차이로, 최소화해야 할 대상임 |
| 손실 함수 | 잔차의 제곱합($RSS$) 등을 사용하여 모델의 오차를 정의하는 수식임 |

```text
[ 다중 선형 회귀식 ]
Y = β0 + β1X1 + β2X2 + ... + βnXn + ε
- ε: 오차항 (설명되지 않는 변동분)
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 데이터 수집  | --> | 모델 학습(최소제곱)| --> | 유의성 검정  | --> | 모델 평가/예측|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **상관 분석** — 산점도($Scatter$ $plot$)나 상관 계수($r$)를 통해 변수들 사이에 선형적인 관계가 있는지 사전 확인하고 이상치를 정제함
2. **파라미터 추정** — 잔차의 제곱합을 최소화하는 '최소제곱법($OLS$)'이나 확률적 '경사하강법'을 사용하여 최적의 회귀 계수를 도출함
3. **가정 검증** — 잔차의 독립성, 등분산성, 정규성 가정을 만족하는지 확인하고, 변수 간 상관관계가 너무 높은 '다중공선성' 여부를 점검함
4. **신뢰도 평가** — 결정 계수($R^2$)와 $F$-검정을 통해 모델 전체의 유의성을 판단하고, 실제 서비스의 예측 성능 지표($RMSE, MAE$)를 확인하며 최적화함

## Ⅵ. 실무 적용 및 유의점

1. 다중 회귀 모델링 시 독립 변수들끼리 서로 강한 상관관계를 가지는 '다중공선성($Multicollinearity$)'이 발생하면 회귀 계수의 신뢰도가 급격히 떨어지므로, $VIF$ 지수를 확인하여 변수를 선택하거나 주성분 분석($PCA$)을 통한 차원 축소를 병행해야 함
2. 모델의 복잡도가 너무 높으면 훈련 데이터에는 잘 맞지만 실제 환경에서는 성능이 떨어지는 과적합이 발생하므로, 회귀 계수의 크기를 제약하는 '리지($Ridge$)'나 '라쏘($Lasso$)'와 같은 규제($Regularization$) 기법을 적용하여 범용성을 확보해야 함

## Ⅶ. 결론

- 회귀 분석은 데이터 이면의 숨겨진 인과관계를 수치로 정립하는 선형 모델의 근간이며, 분석가는 모델의 예측력 확보와 동시에 통계적 가정의 무결성을 검증하여 결과의 해석적 신뢰성을 달성해야 함
