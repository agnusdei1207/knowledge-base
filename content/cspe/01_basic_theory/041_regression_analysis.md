## 미리 알고가기

- 종속 변수($Y$): 모델이 예측하거나 설명하려는 연속형 결과값임
- 독립 변수($X$): 종속 변수의 변화를 설명하는 변수임
- 회귀 계수($\beta$): 독립 변수 변화가 종속 변수에 주는 영향의 방향과 크기임
- 잔차($Residual$): 실제값과 예측값의 차이이며 모델이 줄여야 할 오차임
- 다중공선성: 독립 변수끼리 강하게 상관되어 계수 해석이 불안정해지는 현상임
- 분산 팽창 계수(VIF): 독립 변수 간 상관으로 회귀 계수 분산이 얼마나 커지는지 나타내는 지표임

## 작성 근거(검토용)

- 회귀의 핵심을 연속형 값 예측과 계수 해석으로 정의해 분류 모델과의 경계를 분명히 함
- 잔차와 회귀 계수를 반복 축으로 배치해 구조·절차·사례가 같은 판단 기준을 따르게 함
- 로지스틱 회귀는 이름과 실제 용도가 혼동되므로 비교표에서 분류 모델임을 명시함
- 다중공선성은 회귀 계수 해석을 흔드는 요소라 선행 용어와 사례에 포함함
- 평가 지표는 설명력($R^2$)과 예측 오차($RMSE$, $MAE$)를 분리해 과도한 단일 지표 의존을 줄임

## Ⅰ. 개요

- **정의/개념**: 회귀 분석은 독립 변수와 연속형 종속 변수의 관계를 함수로 추정해 예측값과 변수 영향도를 함께 판단하는 통계 모델링 기법임
- **배경/필요성**: 수요·비용·성능처럼 연속형 값을 예측하기 위해 변수별 영향과 오차를 설명하는 회귀 모델이 필요함

## Ⅱ. 특징

- 연속형 값을 예측하므로 분류보다 오차 크기와 잔차 패턴이 핵심 판단 기준임
- 회귀 계수의 부호와 크기로 독립 변수가 결과에 미치는 방향과 민감도를 해석함
- 독립 변수와 종속 변수의 선형 관계, 잔차의 등분산성·독립성 가정이 깨지면 회귀 계수 해석의 신뢰도가 낮아짐
- 변수를 추가하면 $R^2$는 감소하지 않지만 불필요한 변수는 다중공선성과 과적합 위험을 높일 수 있음

## Ⅲ. 종류 및 비교

| 기준 | 선형 회귀 | 다항 회귀 | 로지스틱 회귀 |
|:---|:---|:---|:---|
| 종속 변수 | 연속형 수치 | 연속형 수치 | 범주형 라벨 |
| 관계 형태 | 독립 변수의 선형 결합 | 독립 변수의 다항 결합 | 선형 결합을 범주 확률로 변환 |
| 주요 목적 | 값 예측과 계수 해석 | 비선형 추세 근사 | 분류 확률 산출 |
| 유의점 | 선형 가정 검증 필요 | 차수 증가 시 과적합 위험 | 이름과 달리 분류 모델임 |

> 요약: 회귀 방식은 종속 변수와 관계 형태에 따라 선택함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 독립 변수 $X$ | 종속 변수의 변동을 설명하는 관측값이며 불필요한 변수가 많으면 다중공선성과 과적합 위험이 커짐 |
| 회귀식 | $Y = \beta_0 + \beta_1X_1 + \cdots + \beta_nX_n + \epsilon$ 형태로 관계를 표현함 |
| 잔차 | 모델이 설명하지 못한 차이이며 가정 검증과 이상치 판단의 근거가 됨 |
| 손실 함수 | 잔차 제곱합이나 평균제곱오차로 계수 추정의 목표를 정의함 |
| 평가 지표 | $R^2$, $RMSE$, $MAE$로 설명력과 예측 오차를 나누어 확인함 |

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 독립 변수 | --> | 회귀식    | --> | 예측값    | --> | 잔차 평가 |
+-----------+     +-----------+     +-----------+     +-----------+
      |                                                   |
      +---------------- 계수 해석 / 가정 검증 ------------+
```

> 요약: 회귀식으로 수치를 예측하고 잔차와 회귀 가정을 검증해 계수 해석의 타당성을 판단함.

## Ⅴ. 원리 및 절차 흐름도

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 변수 선정 | --> | 계수 추정 | --> | 잔차 진단 | --> | 예측 활용 |
+-----------+     +-----------+     +-----------+     +-----------+
```

1. **변수 선정** — 예측 대상과 설명 변수를 정하고 이상치·결측치·단위 차이를 정리함
2. **계수 추정** — 최소제곱법이나 경사하강법으로 손실 함수가 작아지는 계수를 찾음
3. **잔차 진단** — 잔차 패턴·다중공선성·설명력을 확인해 모델 가정 위반을 찾음
4. **예측 활용** — 검증 오차가 업무 허용 기준 이내인지 확인하고 계수 해석이 타당할 때 수치 예측에 적용함

> 요약: 회귀 계수를 추정한 뒤 잔차가 특정 패턴 없이 분포하고 검증 오차가 업무 기준 이내인지 확인해야 예측에 사용할 수 있음.

## Ⅵ. 실무 사례

1. 클라우드 자원 수요 예측은 CPU·메모리·요청량을 표준화하고 $RMSE$·$MAE$로 검증함
2. 애플리케이션 지연 예측은 릿지·라쏘로 다중공선성 영향을 완화하고 검증 오차·계수 변동성을 확인함

## Ⅶ. 결론

- 회귀 분석은 수치 예측과 영향도 해석을 동시에 제공하므로 관계 가정·잔차·다중공선성을 함께 검증해야 함
