## 미리 알고가기

- 종속변수: 예측하거나 설명하려는 대상 값임
- 독립변수: 종속변수에 영향을 주는 입력 변수임
- 잔차: 실제값과 예측값의 차이임

## Ⅰ. 개요

- **정의/개념**: 회귀 분석은 하나 이상의 독립변수와 연속형 종속변수 사이의 관계를 수식으로 모델링해 값 예측과 영향도 해석을 수행하는 통계 기법임
- **배경/필요성**: 비용, 수요, 성능 지표처럼 연속 값을 설명하고 예측하려면 변수 간 관계를 정량화할 수 있는 기본 모델이 필요함

## Ⅱ. 특징

- 변수 영향 방향과 크기를 계수로 해석할 수 있음
- 선형 회귀는 단순하고 빠르며 기준선 모델로 적합함
- 잔차 분석을 통해 모델 적합성과 가정을 점검할 수 있음
- 비선형 관계나 다중공선성이 크면 해석과 예측력이 저하될 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | 선형 회귀 | 다항 회귀 | 로지스틱 회귀 |
|:---|:---|:---|:---|
| 예측 대상 | 연속형 | 연속형 | 범주형 확률 |
| 관계 형태 | 직선 | 곡선 근사 | 시그모이드 |
| 해석성 | 높음 | 중간 | 높음 |
| 대표 적용 | 매출, 부하 예측 | 곡선 추세 | 이탈 여부 예측 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 입력 변수 $X$ | 설명 변수 행렬이며 모델 품질의 기반임 |
| 계수 $\beta$ | 영향도와 방향을 나타냄 해석의 중심임 |
| 오차항 $\epsilon$ | 설명되지 않는 변동이며 가정 검증 대상임 |
| 예측값 $\hat{y}$ | 모델이 산출한 결과이며 성능 평가 대상임 |

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 입력 변수 X  | --> | 계수 beta  | --> | 예측값 yhat | --> | 오차항 eps  |
+-----------+     +-----------+     +-----------+     +-----------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 변수선정 | --> | 계수학습 | --> | 잔차분석 | --> | 예측적용 |
+----------+     +----------+     +----------+     +----------+
```

1. **변수선정**: 의미 있는 설명 변수를 정의하고 정제함
2. **계수학습**: 최소제곱 등으로 계수를 추정함
3. **잔차분석**: 선형성, 등분산성, 독립성을 점검함
4. **예측적용**: 새로운 입력에 대해 값을 예측함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 다중공선성이 발생해 계수 해석이 불안정해짐
   - 해결방안: VIF 점검, 변수 제거, Ridge/Lasso를 사용하고 VIF로 검증함
2. 문제: 이상치가 모델을 왜곡해 회귀선이 크게 흔들릴 수 있음
   - 해결방안: robust regression, 로그 변환, 이상치 검토를 수행하고 Cook's distance로 검증함
3. 문제: 비선형 관계를 놓칠 수 있어 단순 선형식은 설명력이 부족함
   - 해결방안: 상호작용항, 다항항, 트리 계열과 비교하고 RMSE, residual pattern로 검증함

## Ⅶ. 적용 사례

- 용량 계획에서는 사용자 수와 자원 사용량 관계를 예측하며, MAPE와 RMSE로 결과를 확인함
- 금융 예측에서는 금리와 수익률 관계를 해석하며, 설명력 $R^2$로 결과를 확인함
- 품질 관리에서는 공정 변수와 불량 정도 관계를 분석하며, 잔차 안정성으로 결과를 확인함

## Ⅷ. 결론

회귀 분석의 핵심은 예측 정확도만이 아니라 변수 관계를 해석 가능한 형태로 남기는 데 있으므로, 계수 의미와 잔차 품질을 함께 봐야 함.
