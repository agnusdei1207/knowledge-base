## Ⅰ. 개요

- **정의**: 회귀 분석은 독립변수 $X$와 종속변수 $Y$의 관계를 함수식으로 추정해 예측·설명하는 지도 학습 기법임.
- **배경/필요성**: "광고비를 늘리면 매출이 얼마나 증가하는가"처럼 변수 간 영향력을 수치로 확인하려면, 두 변수의 관계를 직선(또는 곡선)으로 근사하고 오차를 최소화하는 계수 추정 방법이 필요함. 라벨($Y$)이 있는 데이터로 관계를 학습한다는 점에서, 라벨 없이 유사도로 데이터를 묶는 군집화(042)와 학습 방식이 구분됨.
- **출제 의도**: 최소제곱법의 수식적 도출 과정, 잔차·결정계수($R^2$)의 의미와 한계, 다중공선성·정규화 판단력을 확인함.
- **답안 방향**: 구조(회귀식 구성요소) -> 원리(최소제곱법 도출과 수치 예시) -> 특징(OLS의 가정과 한계) -> 비교(정규화 회귀 선택 기준) -> 실무 적용 순으로 전개함.

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 최소제곱법 도출과 모델 적합도 평가 요구 | $\beta_0$·$\beta_1$ 추정식, 잔차 $e_i$, 결정계수 $R^2$ 정의 | 결정계수만으로 모델 우수성 단정, 상관과 인과 혼동 |

> 요약: 회귀 분석 답안은 최소제곱법의 계수 도출 과정과 $R^2$의 의미·한계를 함께 짚어야 함.

## Ⅱ. 구조 및 구성요소

```text
독립변수 X(입력) -> 회귀식 y_hat = β0 + β1*X(모델) -> 잔차 e = y - y_hat(오차) -> 결정계수 R^2(적합도)
```

| 구성요소 | 역할 | 산출물/비유 |
|:---|:---|:---|
| 독립변수 $X$ | 설명·예측에 사용하는 입력 변수 | 원인 후보 |
| 회귀계수 $\beta_1$ | $X$가 1단위 증가할 때 $Y$의 변화량 | 직선의 기울기 |
| 절편 $\beta_0$ | $X=0$일 때 $Y$의 기준값 | 직선의 시작점 |
| 잔차 $e_i$ | 관측값과 예측값의 차이 $y_i - \hat{y}_i$ | 예측이 빗나간 정도 |
| 결정계수 $R^2$ | 전체 분산 중 모델이 설명하는 비율 | 모델의 설명력 점수 |

> 요약: 회귀식은 $X$를 입력으로 $\beta_0$·$\beta_1$이 관계를 정하고, 잔차와 $R^2$로 적합도를 사후 평가함.

## Ⅲ. 동작원리 및 흐름도

```text
데이터 관찰(x_i, y_i) -> 모델 설정(y_hat=β0+β1*x) -> 최소제곱법으로 β0·β1 추정 -> 잔차·R^2로 적합도 검증
```

- 1단계(데이터 관찰): 산점도로 $X$-$Y$ 간 선형 관계 여부를 확인함. 예: 공부 시간 $x = [1,2,3,4,5]$, 점수 $y = [2,4,5,4,5]$.
- 2단계(편차 계산): 평균 $\bar{x}=3$, $\bar{y}=4$를 구하고 각 편차 $(x_i-\bar{x})$, $(y_i-\bar{y})$의 곱과 제곱을 누적함. $\sum (x_i-\bar{x})(y_i-\bar{y}) = 6$, $\sum (x_i-\bar{x})^2 = 10$.
- 3단계(계수 추정): 최소제곱법으로 $\beta_1 = \frac{6}{10} = 0.6$, $\beta_0 = \bar{y}-\beta_1\bar{x} = 4-1.8 = 2.2$를 구해 회귀식 $\hat{y}=2.2+0.6x$를 확정함.
- 4단계(적합도 평가): 잔차 제곱합 $SS_{res}=\sum e_i^2 = 2.4$, 총 편차 제곱합 $SS_{tot}=\sum (y_i-\bar{y})^2 = 6$에서 $R^2 = 1-\frac{SS_{res}}{SS_{tot}} = 0.6$을 산출함(분산의 60% 설명). 계수의 통계적 유의성은 t-검정(040 참조)으로 별도 확인함.

> 요약: 편차의 곱과 제곱합 비율로 계수를 추정하고, 잔차 제곱합 대비 총 편차 제곱합으로 설명력($R^2$)을 평가함.

## Ⅳ. 특징

- 최적성: 오차가 등분산·무상관이면 가우스-마르코프 정리에 의해 OLS가 BLUE(Best Linear Unbiased Estimator)가 됨.
- $R^2$ 증가 편향: 독립변수를 추가할수록 $R^2$는 항상 유지되거나 증가하므로, 다중 회귀에서는 자유도를 보정한 조정된 $R^2$로 판단해야 함.
- 다중공선성 취약: 독립변수 간 상관이 높으면(분산팽창지수 VIF > 10) 계수 추정이 불안정해져 부호까지 바뀔 수 있음.
- 선형성 가정: $X$-$Y$ 관계가 실제로 비선형이면 다항 회귀나 변수 변환 없이는 과소적합이 발생함.

> 요약: OLS는 오차 가정 충족 시 최적이나, 다중공선성·비선형 관계·$R^2$ 증가 편향을 항상 함께 점검해야 함.

## Ⅴ. 심화 비교 및 적용 판단

| 다중공선성 대응 | OLS(정규화 없음) | 정규화 회귀(Ridge/Lasso) | 선택 기준 |
|:---|:---|:---|:---|
| 계수 안정성 | 상관 높은 변수 존재 시 계수 분산 폭발 | 패널티항으로 계수 크기를 억제해 안정화 | 변수 간 상관이 높으면 정규화 회귀 선택 |
| 변수 선택 | 모든 변수 유지(선택 없음) | Lasso(L1)는 계수를 0으로 만들어 자동 선택, Ridge(L2)는 축소만 수행 | 변수 선택이 필요하면 Lasso, 다중공선성만 해결하려면 Ridge |
| 해석 용이성 | 계수를 그대로 해석 가능 | 패널티로 축소된 계수라 크기 해석에 주의 필요 | 해석력이 중요한 보고서용은 OLS를 우선 검토 |

> 요약: 다중공선성이나 변수 수가 많을 때만 정규화 회귀를 선택하고, 해석력이 중요하면 OLS를 우선 검토함.

**리스크·대응 (기본은 불릿):**
- 다중공선성: 독립변수 간 높은 상관이 원인 → VIF 진단 후 변수 제거 또는 Ridge 정규화로 대응함 (지표: VIF 10 이하 유지)
- 과적합: 표본 대비 변수 수가 많은 것이 원인 → 정규화 또는 교차 검증으로 대응함 (지표: 학습/검증 $R^2$ 차이)

**도입 후 점검 지표 (기본은 불릿):**
- 설명력: 조정된 $R^2$ 목표치 대비 실측치로 확인함
- 잔차 진단: 잔차 플롯에서 등분산성·정규성 위반 여부로 확인함

## Ⅵ. 실무 적용 및 결론

1. 단기: 산점도·상관계수로 선형성을 확인하고 단순/다중 회귀 적용 여부를 결정함
2. 중기: VIF로 다중공선성을 점검하고 Ridge/Lasso 정규화 도입 여부를 판단함
3. 장기: 비선형성이 심화되면 다항 회귀 또는 트리·신경망 기반 모델로 전환함

- 기술사적 판단: 다중공선성과 표본 크기, 해석력 요구 수준에 따라 OLS/정규화 회귀를 선택함
- 기술사 제언: 회귀계수의 유의성은 t-검정(040 참조)으로 별도 검증하고, $R^2$만으로 모델 적합도를 단정하지 않음
