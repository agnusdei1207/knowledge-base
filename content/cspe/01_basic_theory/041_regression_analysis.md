## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 회귀 분석(Regression Analysis)은 독립 변수 $X$와 종속 변수 $Y$ 사이의 관계를 수학적 함수로 모델링하는 통계 기법이다. 단순 선형 회귀 $Y = \beta_0 + \beta_1 X + \epsilon$에서 최소제곱법(OLS)으로 오차 제곱합 $\sum (y_i - \hat{y}_i)^2$을 최소화하는 $\beta_0, \beta_1$을 구한다.
> 2. **가치**: 주가 예측, 매출 예측, 의학(용량-반응 관계), A/B 테스트(효과 크기 추정), 머신러닝(선형 회귀 = 가장 기본적인 지도 학습) 등 예측과 인과 추론의 기초 도구이다.
> 3. **융합**: 딥러닝(선형 회귀 = 1층 신경망, 경사하강법의 원형), 경제학(계량경제학), 품질공학(실험 계획법), 추천 시스템(행렬 분해의 최적화 목표), 시계열 분석(ARIMA) 등.

---

### 🔑 핵심 용어 정리

| 용어 | 뜻 | 비유 |
|:---|:---|:---|
| **최소제곱법(OLS)** | 잔차(오차) 제곱합 $\sum (y_i - \hat{y}_i)^2$을 최소화하는 계수 추정법 | "데이터 점들과 직선 사이 거리를 최소로" |
| **계수($\beta$)** | 독립 변수가 1단위 증가할 때 종속 변수의 변화량 | "기울기 = 영향력" |
| **결정 계수($R^2$)** | 모델이 데이터 분산의 몇 %를 설명하는지. $R^2 = 1 - \frac{SS_{res}}{SS_{tot}}$ | "모델의 설명력 점수 (0~1)" |
| **잔차(Residual)** | 관측값 - 예측값. $e_i = y_i - \hat{y}_i$ | "예측이 빗나간 정도" |
| **다중 공선성** | 독립 변수 간 높은 상관으로 계수 추정이 불안정해지는 현상 | "두 자가 같은 것을 재서 혼란" |
| **정규화(Regularization)** | 계수 크기에 패널티를 부여하여 과적합 방지. L1(Lasso), L2(Ridge) | "과도한 복잡성에 벌금" |

## Ⅰ. 개요 및 필요성

- **개념**: 단순 선형 회귀는 데이터 $(x_i, y_i)$에 가장 잘 맞는 직선을 찾는다:

$$
\hat{y} = \beta_0 + \beta_1 x
$$

OLS 추정량:

$$
\beta_1 = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sum (x_i - \bar{x})^2}, \quad \beta_0 = \bar{y} - \beta_1 \bar{x}
$$

다중 회귀는 $p$개의 독립 변수를 사용: $\hat{y} = \beta_0 + \beta_1 x_1 + \ldots + \beta_p x_p$. 행렬 표현: $\hat{\beta} = (X^T X)^{-1} X^T y$.

- **필요성**: "광고비를 10% 늘리면 매출이 얼마나 오르는가?"라는 질문에 답하려면, 광고비($X$)와 매출($Y$)의 관계를 회귀 모델로 추정하고 $\beta_1$(광고비 1단위당 매출 변화)을 계산해야 한다.

- **비유**: 회귀 분석은 **"점들 사이에 가장 잘 맞는 직선(또는 곡선) 긋기"**이다. 학생들의 공부 시간(X)과 시험 점수(Y) 데이터에 직선을 그으면, 새 학생의 공부 시간으로 점수를 예측할 수 있다.

```text
+-----------------------------------------------------------------------+
|        단순 선형 회귀 — 최소제곱법의 시각적 이해                      |
+-----------------------------------------------------------------------+
|                                                                       |
|  y │                                    *                             |
|    │                                 *                                |
|    │                             *  /                                 |
|    │                          * / *                                   |
|    │                       * / *                                      |
|    │                    * / *      ← 회귀선: ŷ = β₀ + β₁x            |
|    │                 * / *                                            |
|    │              * / *                                               |
|    │           * / *    ↕ 잔차 eᵢ = yᵢ - ŷᵢ                         |
|    │        * / *                                                     |
|    │     * / *                                                        |
|    │──────/─────────────────────────────────→ x                       |
|                                                                       |
|  OLS 목표: Σ eᵢ² = Σ (yᵢ - ŷᵢ)² → 최소화                         |
+-----------------------------------------------------------------------+
```

**[다이어그램 해설]** 데이터 점(*)과 회귀선 사이의 수직 거리(잔차 $e_i$)의 제곱합을 최소화하는 직선을 찾는 것이 OLS이다. $R^2$는 총 분산 중 모델이 설명하는 비율이며, 1에 가까울수록 모델이 데이터를 잘 설명한다.

- **📢 섹션 요약 비유**: 회귀 분석은 "산점도에 가장 잘 맞는 직선 긋기"입니다. 직선에서 멀리 벗어난 점(잔차)이 적을수록 좋은 모델입니다.

## Ⅱ. 아키텍처 및 핵심 원리

### 회귀 모델의 종류

| 모델 | 수식 | 특징 | 응용 |
|:---|:---|:---|:---|
| **단순 선형** | $\hat{y} = \beta_0 + \beta_1 x$ | 1개 변수, 직선 | 기초 예측 |
| **다중 선형** | $\hat{y} = X\beta$ | $p$개 변수, 초평면 | 매출 예측 |
| **다항 회귀** | $\hat{y} = \beta_0 + \beta_1 x + \beta_2 x^2$ | 곡선 관계 모델링 | 비선형 트렌드 |
| **Ridge ($L_2$)** | $\min \|y - X\beta\|^2 + \lambda\|\beta\|^2$ | 다중 공선성 해결 | 안정적 추정 |
| **Lasso ($L_1$)** | $\min \|y - X\beta\|^2 + \lambda\|\beta\|_1$ | 변수 선택(희소화) | 피처 선택 |
| **로지스틱** | $P(y=1) = \sigma(\beta^T x)$ | 분류 문제 (이진) | 스팸/질병 여부 |

### 신경망과의 연결

1층 신경망(활성화 없음)은 다중 선형 회귀와 동치이다:

$$
\hat{y} = Wx + b \quad \text{(선형 회귀)} = \hat{y} = \sigma(Wx + b) \quad \text{(로지스틱/신경망)}
$$

경사하강법(Gradient Descent)은 OLS의 반복적(iterative) 대안이며, 데이터가 메모리에 다 안 들어올 때(SGD) 사용된다.

- **📢 섹션 요약 비유**: 선형 회귀가 "자로 직선 긋기"라면, Ridge/Lasso는 "너무 급한 기울기에 브레이크 걸기"이고, 로지스틱 회귀는 "합격/불합격을 판별하는 경계선 긋기"입니다.

## Ⅲ. 비교 및 연결

### 비교 1: 선형 회귀 vs 로지스틱 회귀

| 비교 항목 | 선형 회귀 | 로지스틱 회귀 |
|:---|:---|:---|
| **출력** | 연속값 ($-\infty$ ~ $\infty$) | 확률 (0~1) |
| **문제 유형** | 회귀 (예측) | 분류 (이진/다중) |
| **손실 함수** | MSE $\sum (y - \hat{y})^2$ | 교차 엔트로피 $-\sum y \log \hat{y}$ |
| **활성화** | 없음 (항등) | 시그모이드 $\sigma(z) = 1/(1+e^{-z})$ |

### 과목 융합 관점
- **딥러닝**: 선형 회귀 = 1층 신경망. 다층 신경망은 비선형 회귀의 일반화이다.
- **데이터베이스**: 쿼리 옵티마이저가 실행 비용을 추정할 때 회귀 모델을 사용한다.
- **품질공학**: 실험 계획법(DoE)에서 요인 효과를 회귀 분석으로 정량화한다.

## Ⅳ. 실무 적용 및 기술사 판단

### 실무 시나리오

1. **시나리오 — 매출 예측**: 광고비, 계절, 경쟁사 가격 등 $p=10$개 변수로 월 매출을 예측하는 다중 회귀 모델을 구축한다. $R^2 = 0.85$이면 매출 변동의 85%를 설명할 수 있다.

2. **시나리오 — A/B 테스트 효과 크기**: 전환율에 영향을 주는 교란 변수(디바이스, 시간대)를 통제하기 위해 로지스틱 회귀에 공변량으로 포함하여 순수한 실험 효과를 추정한다.

### 안티패턴
- **상관 ≠ 인과**: 아이스크림 판매($X$)와 익사 사고($Y$)는 상관이 높지만, 인과 관계가 아니다(교란 변수 = 여름 기온). 회귀 분석만으로 인과를 주장할 수 없다.

### 정량/정성 기대효과

| 구분 | 직감 예측 | 회귀 분석 적용 | 개선 효과 |
|:---|:---|:---|:---|
| **정량** | "매출이 오를 것 같다" | $R^2 = 0.85$, MAPE 8% | **예측 오차 80%↓** |
| **정성** | 변수 간 관계 불명확 | $\beta_i$로 각 변수의 영향력 정량화 | **의사결정 근거 확보** |

### 참고 표준
- **Gauss (1809)**: 최소제곱법 원논문
- **Tibshirani (1996)**: Lasso 정규화

회귀 분석은 "데이터에서 관계를 찾고 미래를 예측하는" 가장 기본적인 도구이다. 딥러닝도 결국 비선형 회귀의 확장이며, 회귀의 원리(최적화, 과적합, 정규화)를 이해하면 모든 ML 모델의 기초가 된다.
