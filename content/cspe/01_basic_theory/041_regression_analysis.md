## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 독립변수와 종속변수 간의 관계를 수학적 모델로 추정하여 미래값을 예측하는 통계 분석 기법임 |
| 배경/필요성 | 데이터 기반 예측 필요성 증가, 원인과 결과 간의 관계 분석 및 최적화 요구 증대 |
| 출제 의도 | 선형/비선형 회귀 모델의 원리 이해 및 평가 지표(R-square 등) 활용 능력 평가 |

## Ⅱ. 구성요소
```text
+----------------+       +----------------+       +----------------+
|  Independent   |       |   Regression   |       |   Dependent    |
|   Variables    | ----> |     Model      | ----> |    Variable    |
+----------------+       +----------------+       +----------------+
```
| 독립변수 (X) | 예측에 사용되는 원인 변수, 설명 변수 | 원인 제공자 |
| 종속변수 (Y) | 예측하고자 하는 결과 변수, 반응 변수 | 결과 수용자 |
| 회귀계수 | 독립변수가 종속변수에 미치는 영향력 크기 | 가중치 |
> 요약: 회귀 분석은 독립변수, 종속변수, 회귀계수로 구성되어 변수 간 인과관계를 모형화함

## Ⅲ. 절차
```text
+----------------+       +----------------+       +----------------+       +----------------+
| Data Pre-      |       | Model          |       | Parameter      |       | Model          |
| processing     | ----> | Specification  | ----> | Estimation     | ----> | Evaluation     |
+----------------+       +----------------+       +----------------+       +----------------+
```
1. 데이터 전처리: 결측치 제거, 이상치 처리 및 변수 스케일링 수행
2. 모델 설정: 선형/비선형 등 데이터 특성에 맞는 회귀 모형 선택
3. 모수 추정: 최소제곱법(OLS) 등을 통해 최적의 회귀계수 도출
4. 모델 평가: 결정계수($R^2$), MSE 등을 활용하여 모델 적합도 검증
> 요약: 데이터 전처리 후 모델을 설정하고, 최적 파라터를 추정하여 적합도를 평가함

## Ⅳ. 문제점
- 이상치 민감성: 극단적인 이상치(Outlier)로 인해 회귀선의 왜곡 발생 가능성
- 다중공선성 문제: 독립변수들 간의 강한 상관관계로 인해 회귀계수 추정의 불안정성 발생
- 비선형성 한계: 단순 선형 회귀 모델로는 복잡한 비선형 관계를 설명하기 어려움

## Ⅴ. 개선방안
- 단기 방안: 이상치 탐지 및 제거(Z-score, IQR 등) 또는 로버스트 회귀 모델 적용
- 중기 방안: 상관분석(VIF)을 통한 다중공선성 확인 후 변수 제거 또는 주성분 분석(PCA) 활용
- 장기 방안: 다항 회귀(Polynomial), SVR, 의사결정나무 등 비선형 모델 도입 검토

## Ⅵ. 전망
- 전통적 통계 모델에서 딥러닝 기반 회귀 예측 기법으로 발전 중이며, 신뢰성 높은 AI(XAI)와 결합됨
