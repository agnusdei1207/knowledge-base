# 📖 【암기용】 개념 완전 이해

> 목적: 회귀 분석을 처음 봐도 완전히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 독립변수로 종속변수 값을 예측하고 영향 크기를 추정하는 통계 모델
- **왜 필요한가**: 장애 건수, 응답시간, 매출, 전력 사용량처럼 연속값을 예측하고 어떤 요인이 결과를 바꾸는지 설명해야 함
- **핵심 직관**: 흩어진 점들 사이에 오차 제곱합이 최소가 되는 선이나 곡선을 그어 미래 값을 읽는 방식임

## 깊이 이해
- **배경·문제의식**: 평균만 보면 변수 간 관계를 설명하지 못함. 회귀는 `y = beta0 + beta1*x + error`로 관계를 수식화해 예측값과 영향도를 함께 제공함.
- **작동 원리**: 최소제곱법(OLS)은 실제값과 예측값 차이의 제곱합(SSE)을 최소화하는 계수를 찾음. 다중회귀는 변수를 여러 개 두고, 정규화 회귀는 L1/L2 패널티로 과적합을 통제함.
- **비유**: 지도 위 여러 매장 매출 점을 보고 임대료와 유동인구가 매출에 미치는 기울기를 찾는 작업과 유사함.
- **구체 예시**: CPU 사용률 70%, 동시접속 1,000명일 때 p95 지연시간을 180ms로 예측하고, 동시접속 100명 증가마다 12ms 증가 계수를 산출함.
- **흔한 오해·주의점**: 상관관계가 인과관계를 뜻하지 않음. 다중공선성(VIF>10), 이상치, 잔차 비정규성이 있으면 계수 해석이 왜곡됨.

## 연결 개념
- 상관 분석: 변수 간 선형 관계 강도 측정
- 가설 검정: 회귀계수 유의성 판단
- 교차 검증: 예측 모델의 일반화 오차 평가

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 회귀 분석은 입력 변수와 연속형 출력 변수의 관계를 계수와 예측식으로 표현하는 통계 모델임.
> 2. **가치**: 수요예측, 성능 용량계획, 장애 원인 분석에서 예측값·영향도·신뢰구간을 함께 제시함.
> 3. **판단 포인트**: RMSE, MAE, R2, p-value, VIF, 잔차 패턴으로 예측력과 해석 가능성을 동시에 검증함.

---

## Ⅰ. 개요 및 필요성

회귀 분석은 연속값 예측 모델이다. 시스템 운영에서는 부하와 응답시간, 결함수와 개발공수처럼 변수 간 관계를 수치화해야 한다. 계수·오차·신뢰구간을 함께 제시하면 예측과 원인 설명을 한 답안에서 처리할 수 있다.

---

## Ⅱ. 구조 및 구성요소

```text
관측 데이터 X,y -> 전처리 -> 회귀식 f(X)=beta0+betaX -> 예측값 y_hat
                    / 계수 추정·잔차 e=y-y_hat·규제항 선택
```

| 구성요소 | 역할 | 판단 기준 |
|:---|:---|:---|
| 독립변수 X | 예측에 사용하는 설명 변수 | 상관, 결측률, 스케일 |
| 종속변수 y | 예측 대상 연속값 | 분포, 이상치, 단위 |
| 회귀계수 beta | 변수 1단위 변화의 영향 | p-value<0.05, 신뢰구간 |
| 잔차 e | 실제값과 예측값 차이 | 평균 0, 등분산성 |

> 요약: 회귀는 변수·계수·잔차 구조로 예측식을 만들고, 잔차와 계수 유의성으로 모델 타당성을 판단함.

---

## Ⅲ. 동작원리 및 흐름도

```text
데이터 수집 -> 전처리 -> 계수 추정 -> 잔차 진단 -> 예측/해석
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 결측·이상치 처리, 변수 스케일 조정 | 결측률 5% 이하 관리 |
| 2 | OLS, Ridge, Lasso 모델 선택 | 변수 수, 다중공선성 |
| 3 | 학습 데이터로 계수 추정 | SSE 최소화, 규제항 |
| 4 | 테스트 데이터 예측과 잔차 분석 | RMSE, MAE, R2, VIF |

> 요약: 회귀는 전처리 후 계수를 추정하고, 독립성·등분산성·오차지표로 예측식의 사용 가능성을 검증함.

---

## Ⅳ. 특징

| 구분 | 선형 회귀 | 규제 회귀 | 수치·판단 포인트 |
|:---|:---|:---|:---|
| 목적 | 해석 중심 | 과적합 통제 | Ridge L2, Lasso L1 |
| 장점 | 계수 해석 용이 | 변수 선택·분산 축소 | VIF 10 초과 시 점검 |
| 한계 | 비선형 관계 표현 제한 | 패널티 값 선택 필요 | k-fold CV로 alpha 선택 |
| 평가 | RMSE, MAE, R2 | 검증 RMSE 최소 | R2만 단독 사용 금지 |

> 요약: 설명력이 중요하면 선형 회귀, 변수 수가 많고 과적합 위험이 있으면 Ridge/Lasso와 교차 검증을 병행함.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존·대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | 상관 분석은 변수 간 동행성만 측정 | 회귀식은 계수·절편·잔차로 영향도 산출 | 영향 크기 설명 필요 시 회귀 선택 |
| 비용/성능 | 단일 평균 예측은 계산 단순, 원인 설명 제한 | RMSE·MAE·R2로 예측오차 정량화 | RMSE 20ms 이하 등 업무 허용오차 기준 |
| 운영/위험 | 규칙 기반 임계값은 환경 변화 반영 제한 | 재학습·잔차 모니터링으로 계수 변화 추적 | p-value<0.05, VIF<10, 잔차 평균 0 확인 |

> 요약: 회귀는 평균·상관보다 예측식과 영향도를 함께 제공하므로 오차 기준과 계수 진단을 동시에 둔다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 과적합 | 변수 수 과다, 표본 수 부족 | Ridge/Lasso, k-fold CV 적용 | 검증 RMSE와 학습 RMSE 차이 |
| 계수 왜곡 | 다중공선성, 이상치 | VIF>10 변수 제거, Cook's distance 점검 | VIF, 레버리지, 잔차 플롯 |
| 인과 오해 | 관측 데이터 기반 상관 해석 | 실험 설계, 통제변수, 신뢰구간 병기 | 95% CI, p-value, 도메인 검토 |

> 요약: 회귀 리스크는 과적합·공선성·인과 오해이며, 규제·진단지표·통제변수로 답안 신뢰도를 확보함.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 예측 오차 | RMSE 업무 허용오차 이하, MAE 병기 | hold-out, k-fold CV |
| 해석 타당성 | p-value<0.05, VIF<10 | 계수 검정, 공선성 진단 |
| 운영 감시 | 잔차 평균 0, 데이터 드리프트 PSI<0.2 | 잔차 모니터링, 분포 비교 |

> 요약: 도입 후 성공 여부는 예측오차, 계수 유의성, 잔차·분포 드리프트를 함께 측정해 판단함.

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 용량계획: 동시접속·CPU·I/O를 입력으로 p95 지연시간을 예측하고 RMSE 20ms 이하 기준 수립
2. 장애 원인 분석: 배포횟수·변경라인수·테스트커버리지로 결함수를 회귀분석하고 VIF 10 초과 변수 제거
3. 수요예측: 주별 트래픽을 다중회귀로 예측하고 95% 예측구간으로 클라우드 예약 용량 산정

**결론 (2줄):**
- 기술사 판단: 해석이 목표면 선형 회귀, 예측 오차 축소가 목표면 규제 회귀와 교차 검증을 선택함
- 향후 방향: 회귀 모델은 SHAP, PDP와 결합해 예측값뿐 아니라 변수 영향 설명까지 제공해야 함
