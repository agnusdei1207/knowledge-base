# 회귀 분석 (Regression Analysis)

## 1. 개요

- **정의/개념**: 회귀 분석은 독립변수와 종속변수 사이의 관계를 함수로 모델링해 값을 예측하거나 변수 영향도를 해석하는 통계·머신러닝 기법이다.
- **배경/필요성**: 업무 데이터에서 수요, 비용, 위험, 성능을 설명하고 예측하려면 변수 간 관계를 정량화하고 검증할 수 있는 모델이 필요하다.

회귀 분석은 예측 정확도와 해석 가능성을 함께 다루므로, 모델 선택과 전제 검증이 같은 흐름으로 이어져야 한다.

## 2. 특징 및 비교

| 구분 | 선형 회귀 | 로지스틱 회귀 | 비선형 회귀 |
|---|---|---|---|
| 대상 | 연속값 예측 | 범주·확률 예측 | 비선형 관계 |
| 출력 | 실수 값 | 0~1 확률 | 모델별 상이 |
| 해석성 | 높음 | 계수 해석 가능 | 낮아질 수 있음 |
| 주요 지표 | RMSE, R2 | AUC, log loss | 문제별 지표 |

회귀 모델 선택 기준은 종속변수 유형, 관계 형태, 해석 필요성, 이상치, 다중공선성이다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| Feature X | 설명 변수 | 스케일·상관성 |
| Target y | 예측 대상 | 연속·범주 구분 |
| Coefficient | 변수 영향도 | 해석 가능성 |
| Loss Function | 예측 오차 측정 | MSE, log loss |
| Residual | 실제값과 예측값 차이 | 전제 진단 |

```text
+----------+      +----------+      +----------+      +----------+
| 데이터   | ---> | 모델적합 | ---> | 잔차진단 | ---> | 예측/해석 |
+----------+      +----------+      +----------+      +----------+
```

잔차가 무작위적으로 남지 않으면 회귀식이 변수 관계를 충분히 설명하지 못한다는 신호이다.

## 4. 문제점 및 개선방안

1. **선형성 가정 오류**
   - 실제 관계가 비선형인데 선형 모델을 적용하면 편향이 커진다.
   - **개선방안**: 잔차 플롯, 다항항, spline, 트리 기반 모델을 검토한다.

2. **다중공선성**
   - 독립변수 간 상관이 높으면 계수 해석이 불안정해진다.
   - **개선방안**: VIF 확인, 변수 제거, 정규화 회귀를 적용한다.

3. **이상치 영향**
   - 일부 극단값이 회귀선을 크게 왜곡할 수 있다.
   - **개선방안**: robust regression, 이상치 분석, 변환을 수행한다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| 수요 예측 | 가격·계절·마케팅 변수로 판매량 예측 | RMSE, MAPE |
| 위험 평가 | 고객 특성으로 연체 확률 추정 | AUC, calibration |
| 성능 분석 | 시스템 부하와 응답시간 관계 모델링 | R2, 잔차 패턴 |

## 6. 결론

회귀 분석은 변수 관계를 예측과 해석으로 연결하는 기본 분석 기법이다. 변수 유형, 손실 함수, 잔차 진단, 해석 가능성을 함께 관리해야 단순 예측식이 아니라 의사결정 가능한 모델이 된다.
