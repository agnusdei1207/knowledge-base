## 미리 알고가기

- 종속 변수(Dependent Variable, $Y$)·독립 변수(Independent Variable, $X$): 종속 변수는 모델의 결과값이고 독립 변수는 그 변화를 설명하는 입력값임
- 회귀 계수(Regression Coefficient, $\beta$): 독립 변수 변화가 종속 변수에 주는 영향의 방향과 크기임
- 잔차(Residual): 실제값과 예측값의 차이이며 모델이 줄여야 할 오차임
- 선형 회귀(Linear Regression): 독립 변수의 선형 결합으로 연속형 값을 예측하는 회귀 모델임
- 다항 회귀(Polynomial Regression): 독립 변수의 거듭제곱 항을 추가해 비선형 추세를 근사하는 회귀 모델임
- 로지스틱 회귀(Logistic Regression): 선형 결합을 확률로 변환해 범주를 분류하는 모델임
- 다중공선성(Multicollinearity): 독립 변수끼리 강하게 상관되어 계수 해석이 불안정해지는 현상임
- 결정 계수(Coefficient of Determination, $R^2$): 종속 변수 변동 중 회귀식이 설명하는 비율임
- 평균제곱근오차(RMSE)·평균절대오차(MAE): 각각 오차 제곱 평균의 제곱근과 오차 절댓값 평균임
- 릿지 회귀(Ridge Regression): 회귀 계수 제곱에 벌점을 부여해 계수 변동과 과적합을 줄이는 방식임

## 작성 근거(검토용)

- **방향성**: 회귀 분석은 회귀 계수로 변수 영향을 해석하고 값을 예측하는 대신, 선형성 가정이 깨지거나 오차 분산이 고르지 않거나 다중공선성이 있으면 계수를 인과관계로 잘못 해석하게 되므로 잔차 진단으로 가정 위반을 확인하고 데이터 분포가 바뀌면 재학습·교체해야 함
- **개요 구성**: 회귀 분석은 독립 변수로 종속 변수 값·확률을 예측하고 영향도를 해석하는 기법이라는 정의를 먼저 제시함
- **Ⅱ. 특징 선정**: 평가 지표는 설명력($R^2$)과 예측 오차(RMSE, MAE)를 분리해 과도한 단일 지표 의존을 줄이고 특징의 판단 근거로 씀
- **Ⅲ. 비교축 선정**: 선형·다항·로지스틱 회귀의 관계 표현과 출력 차이를 비교표에 반영하고, 로지스틱 회귀는 이름과 실제 용도가 혼동되므로 분류 모델임을 명시함
- **Ⅳ·Ⅴ. 구조·절차 선정**: 잔차와 회귀 계수를 반복 축으로 배치해 구조·절차가 같은 판단 기준을 따르게 하고, 다중공선성은 회귀 계수 해석을 흔드는 요소라 잔차 진단 절차에 포함함
- **Ⅵ·Ⅶ. 사례·결론 선정**: 오토스케일링 용량 예측과 API 지연 예측처럼 실제 적용에서 인과 오해 방지와 재학습 필요성을 사례·결론으로 연결함
- **전수 검수**: 제목부터 결론까지 용어·표·도식·요약을 대조하고 회귀 계수·잔차 정의와 절 간 판단축을 일치시킴

## Ⅰ. 개요

- **정의/개념**: 회귀 분석은 독립 변수로 종속 변수 값·확률을 예측하고 영향도를 해석하는 통계 기법임
- **배경/필요성**: 수요·비용처럼 연속형 값 예측을 위해 변수별 영향과 오차를 설명하는 모델이 필요함

### 쉽게 이해하기 (학습용)
- 여러 재료를 넣고 요리 맛이 어떻게 나올지 미리 가늠하는 것과 같음

## Ⅱ. 특징

- 선형·다항 회귀는 연속형 값을 예측하므로 오차 크기와 잔차 패턴이 핵심 판단 기준임
- 회귀 계수의 부호와 크기로 독립 변수가 결과에 미치는 방향과 민감도를 해석함
- 선형 회귀는 선형 관계·오차의 고른 분산·독립성을 가정하며 위반 시 계수 해석 신뢰도가 낮아짐
- 변수를 추가하면 $R^2$는 감소하지 않지만 불필요한 변수는 다중공선성·과적합 위험을 높임

### 쉽게 이해하기 (학습용)
- 저울에 재료를 하나씩 더 올릴 때 눈금이 얼마나 움직이는지로 그 재료의 영향력을 읽되, 비슷한 재료를 여러 개 함께 올리면 어느 것 때문인지 헷갈리는 것과 같음

## Ⅲ. 종류 및 비교

| 판단 기준 | 선형 회귀 | 다항 회귀 | 로지스틱 회귀 |
|:---|:---|:---|:---|
| 예측 대상 | 연속형 수치 | 연속형 수치 | 범주 확률 |
| 동작 메커니즘 | 독립 변수의 선형 결합 | 거듭제곱 항의 선형 결합 | 선형 결합의 확률 변환 |
| 주요 리스크 | 선형성 가정 위반 | 고차수 과적합 | 클래스 불균형 |

> 요약: 종속 변수가 연속형이고 직선 추세면 선형 회귀, 곡선 추세면 다항 회귀, 종속 변수가 범주형이면 로지스틱 회귀를 적용함.

### 쉽게 이해하기 (학습용)
- 직선 자로 잴지, 구불구불한 곡선 자로 잴지, 아니면 예/아니오만 답하는 저울로 잴지 상황에 맞는 도구를 고르는 것과 같음

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 독립 변수 $X$ | 종속 변수의 변화를 설명하는 입력 변수 |
| 종속 변수 $Y$ | 독립 변수로 설명·예측하려는 결과 변수 |
| 회귀 계수 $\beta$ | 변수별 영향 방향·크기 |
| 회귀식 | 독립 변수와 회귀 계수로 예측값을 계산하는 수식 |
| 잔차 | 실제값과 예측값의 차이 |

> 요약: 회귀 분석은 독립 변수와 회귀 계수로 결과 변수를 예측하고 잔차로 오차를 검증함.

### 쉽게 이해하기 (학습용)
- 재료(독립 변수)와 배합 비율(계수)로 완성 요리(종속 변수)의 맛을 정하는 레시피이며, 실제 맛과 예상 맛의 차이가 잔차임

## Ⅴ. 원리 및 절차 흐름도

```text
변수·데이터 정리 → 회귀 계수 추정 → 잔차 진단
                                      ├─ 가정 위반 → 변수·모형 재설정
                                      └─ 가정 충족 → 검증 오차 확인 → 예측 적용
```

1. **변수 선정**: 예측 대상과 설명 변수를 정하고 이상치·결측치·단위 차이를 정리함
2. **계수 추정**: 손실 함수가 작아지는 회귀 계수를 찾음
3. **잔차 진단**: 잔차 패턴·다중공선성·설명력을 확인해 모델 가정 위반을 찾음
4. **예측 활용**: 검증 오차와 계수 타당성을 확인해 업무 예측에 적용함

> 요약: 회귀 계수 추정 후 잔차 패턴과 검증 오차를 확인해 예측 적용 여부를 판단함.

### 쉽게 이해하기 (학습용)
- 재료를 다듬고, 최적 배합 비율을 찾고, 시식해서 이상하면 레시피를 고치고, 괜찮으면 손님상에 내는 과정과 같음

## Ⅵ. 실무 사례

1. 오토스케일링 용량 예측기는 요청량으로 필요한 CPU·메모리 용량을 예측함
2. API 지연 예측기는 릿지 회귀로 요청량·DB 호출 수와 응답 지연의 관계를 모델링함

### 쉽게 이해하기 (학습용)
- 주문량을 보고 필요한 조리대 수를 미리 어림잡거나, 주문 폭주가 대기 시간에 얼마나 영향을 주는지 미리 계산해 두는 것과 같음

## Ⅶ. 결론

- 회귀 분석은 변수 사이의 관계로 결과를 예측하고 영향도를 설명하며, 관계 가정과 예측 오차를 함께 검증해야 함
- 회귀 계수를 인과관계로 해석하지 말고 잔차·계수 변화를 감시해 데이터 분포가 바뀌면 재학습하거나 모델을 교체해야 함

### 쉽게 이해하기 (학습용)
- 레시피의 배합 비율을 절대적인 인과로 믿지 말고, 손님 반응(잔차)이 달라지면 레시피를 다시 조정하거나 새로 짜야 함
