## Ⅰ. 개요
- **정의**: 독립변수와 종속변수 간 함수적 관계를 수식으로 모델링하는 통계 기법
- **배경/필요성**: 변수 간 인과 관계를 정량화해야 예측·의사결정이 가능하며, 데이터로부터 패턴을 추출해 미래 값을 추정할 수단이 필요함
- **비유**: 산점도 위에 자를 대고 점들과의 거리가 가장 짧은 직선을 긋는 행위

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| OLS 원리와 평가 지표 이해 | 최소제곱법의 목적함수, R^2 해석 | 잔차 가정(정규성·등분산) 누락 시 감점 |

> 요약: 독립변수로 종속변수를 예측하는 함수 관계를 데이터로부터 추정하는 기법임

## Ⅱ. 구성요소
```text
독립변수(X) ---> 회귀 모델(f) ---> 종속변수(Y_hat)
                     |
                     v
              잔차(e = Y - Y_hat)
                     |
                     v
              평가 지표(R^2, MSE)
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 독립변수(X) | 결과에 영향을 주는 입력 변수 | 레시피의 재료 투입량 |
| 종속변수(Y) | 예측 대상이 되는 출력 변수 | 완성된 요리의 맛 점수 |
| 회귀 계수 | X가 Y에 미치는 영향의 크기와 방향 | 재료 1g 추가 시 맛 변화량 |
| 잔차(e) | 실제값과 예측값의 차이 | 예상 맛과 실제 맛의 오차 |
| 결정계수($R^2$) | 모델이 설명하는 분산 비율(0~1) | 맛 변동 중 레시피로 설명 가능한 비율 |

> 요약: 입력·출력·계수·잔차·평가지표로 구성되며, 각 요소가 모델의 적합도를 결정함

## Ⅲ. 절차
```text
데이터 수집 --> 모델 선택 --> 계수 추정(OLS) --> 모델 평가
     |                                              |
     +---------- 잔차 분석 후 재조정 <--------------+
```
- 1단계: 데이터 수집 및 탐색 — 산점도로 변수 간 관계 패턴을 시각적으로 확인함
- 2단계: 모델 선택 — 단순 선형(`y = ax + b`), 다중 선형(`y = b0 + b1*x1 + ... + bn*xn`), 다항 회귀 중 패턴에 맞는 형태를 선정함
- 3단계: 계수 추정(OLS) — 잔차 제곱합 $\sum(y_i - \hat{y}_i)^2$을 최소화하는 계수를 산출함
- 4단계: 모델 평가 — $R^2$, MSE로 적합도를 측정하고, 잔차의 정규성·등분산·독립성을 검증함

> 요약: 데이터 탐색 후 모델을 선택하고, OLS로 계수를 추정한 뒤 잔차 분석으로 타당성을 검증함

## Ⅳ. 문제점
- 다중공선성: 독립변수 간 상관이 높으면 계수 추정이 불안정해져 해석 신뢰도가 저하됨
- 과적합: 변수나 차수를 과도하게 늘리면 훈련 데이터에만 맞고 새 데이터에서 예측 오차가 급증함 (046 참조)
- 잔차 가정 위반: 이분산·자기상관이 존재하면 OLS 추정량의 표준오차가 왜곡되어 통계적 추론이 부정확해짐

> 요약: 공선성·과적합·가정 위반이 회귀 모델의 신뢰성을 저하시키는 주요 원인임

## Ⅴ. 개선방안
1. 단기: VIF(분산팽창인수)로 다중공선성을 진단하고, 상관 높은 변수를 제거하거나 PCA로 차원을 축소함 (043 참조)
2. 중기: 정규화(Ridge, Lasso) 기법으로 계수 크기를 제약하여 과적합을 억제함
3. 장기: 가중최소제곱법(WLS), 로버스트 회귀 등으로 이분산·이상치에 강건한 추정 체계를 구축함

> 요약: 공선성 진단, 정규화, 강건 추정 순으로 회귀 모델의 안정성과 일반화 능력을 확보함

## Ⅵ. 전망
- 발전 방향: 자동 특성 선택(AutoML)과 결합하여 최적 변수·모델 구조를 자동 탐색하는 흐름이 확대됨
- 기술사적 판단: 회귀 분석은 해석 가능성이 높아 규제 산업(금융·의료)에서 블랙박스 모델 대비 지속적 수요가 존재함
- 기술사 제언: 예측 정확도와 모델 해석 가능성 간 균형을 고려하여 문제 특성에 맞는 회귀 기법을 선정해야 함
