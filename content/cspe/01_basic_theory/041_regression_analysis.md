## 미리 알고가기

- **결정계수 ($R^2$)**: 회귀 모델이 종속 변수의 전체 변동 중 얼마나 설명하는지를 나타내는 지표. 1에 가까울수록 모델의 설명력이 높음
- **최소자승법 (OLS)**: 잔차(실제값-예측값)의 제곱합을 최소화하는 회귀 계수를 찾는 가장 일반적인 최적화 방법
- **다중공선성 (Multicollinearity)**: 독립 변수들 사이에 강한 상관관계가 존재하여 회귀 계수 추정의 신뢰성을 떨어뜨리는 현상

## Ⅰ. 개요

- **정의/개념**: 회귀 분석(Regression Analysis)은 하나 이상의 독립 변수($X$)와 종속 변수($Y$) 사이의 인과 관계를 수학적 함수 모델로 정형화하여, 새로운 데이터에 대한 값을 예측하거나 변수 간의 영향력을 분석하는 통계 및 머신러닝 기법임
- **배경/필요성**: 현대 비즈니스 환경에서는 수많은 요인이 결과에 복합적으로 영향을 미침. 예를 들어, 광고비 지출이 매출에 미치는 순수한 기여도를 파악하거나, 서버 부하량에 따른 응답 지연 시간을 예측하기 위해서는 단순 상관관계를 넘어선 '함수적 모델링'이 필요함. 회귀 분석은 이러한 데이터 뒤에 숨겨진 추세(Trend)를 선형 또는 비선형 수식으로 도출하여 합리적인 의사결정 근거를 제공함

## Ⅱ. 특징 및 비교

### 가. 회귀 모델의 주요 유형 비교

| 구분 | 단순 선형 회귀 | 다중 선형 회귀 | 로지스틱 회귀 |
|:---|:---|:---|:---|
| 독립 변수 수 | 1개 | 2개 이상 | 1개 이상 |
| 종속 변수 형태 | 연속형 (실수) | 연속형 (실수) | 범주형 (0 또는 1) |
| 관계식 형태 | $y = ax + b$ | $y = \beta_0 + \beta_1x_1 + \dots$ | Sigmoid 함수 활용 |
| 주요 목적 | 한 변수 간의 선형 관계 파악 | 여러 변수의 복합 영향 분석 | 특정 사건의 발생 확률 예측 |
| 해석 지표 | 기울기 (Scale) | 편회귀 계수, VIF | 오즈 비 (Odds Ratio), AUC |

> 요약: 값 자체를 예측하면 선형 회귀, 발생 확률을 예측하여 분류하면 로지스틱 회귀를 사용함

### 나. 선형 회귀의 4대 기본 가정
- **선형성**: 독립 변수와 종속 변수 간에 직선적인 관계가 존재해야 함
- **독립성**: 잔차들 사이에 상관관계가 없어야 함 (자기상관성 부재)
- **등분산성**: 잔차의 분산이 모든 독립 변수 값에 대해 일정해야 함
- **정규성**: 잔차의 분포가 평균이 0인 정규 분포를 따라야 함

## Ⅲ. 구성요소/구조

### 가. 회귀 분석의 실행 프로세스

```text
[데이터 수집/전처리] -> [가설 설정] -> [모델 학습(OLS)] -> [가정 검증] -> [해석 및 예측]

1. 전처리: 이상치 제거, 스케일링, 다중공선성 확인(VIF)
2. 모델링: 비용 함수(MSE)를 최소화하는 가중치(Weights) 도출
3. 검증: 결정계수 확인 및 잔차 분석(Q-Q Plot, Residual Plot)
4. 해석: 계수의 유의성(p-value) 확인 후 변수 중요도 판단
```

### 나. 주요 구성 요소 및 역할

| 구성요소 | 역할 및 설명 | 핵심 포인트 |
|:---|:---|:---|
| 독립 변수 (Feature) | 종속 변수에 영향을 주는 원인 변수 | 변수 선택(Selection)이 모델 성능 좌우 |
| 종속 변수 (Target) | 예측하고자 하는 결과 변수 | 데이터의 노이즈와 이상치에 민감함 |
| 회귀 계수 (Coefficient) | 변수 1단위 변화 시 결과의 변화량 | 부호와 크기로 영향력의 방향/강도 파악 |
| 절편 (Intercept) | 모든 독립 변수가 0일 때의 기본값 | 모델의 편향(Bias)을 조절 |
| 잔차 (Residual) | 실제 데이터와 회귀선 사이의 수직 거리 | 모델이 설명하지 못한 나머지 영역 |

> 요약: 독립 변수의 가중합에 절편을 더해 종속 변수를 근사하는 선형 결합 구조임

## Ⅳ. 문제점 및 개선방안

1. **다중공선성으로 인한 해석 왜곡**: 밀접하게 연관된 변수가 동시에 포함되면 개별 계수의 의미가 상실됨
   - **개선방안**: VIF(분산팽창지수)가 10 이상인 변수를 제거하거나, 주성분 분석(PCA)으로 변수를 통합하고 라쏘(Lasso)/릿지(Ridge) 규제를 적용함

2. **이상치(Outlier)의 과도한 영향**: 최소자승법은 오차의 제곱을 사용하므로 한두 개의 극단값이 전체 회귀선을 크게 뒤흔듬
   - **개선방안**: 이상치에 둔감한 로버스트 회귀(Robust Regression)를 사용하거나, 절대 오차를 사용하는 MAE 손실 함수를 검토함

3. **비선형 관계의 선형 모델 강제 적용**: 곡선 형태의 데이터를 직선으로 모델링하여 예측력이 저하됨
   - **개선방안**: 독립 변수에 제곱항이나 교차항을 추가하는 다항 회귀(Polynomial)를 수행하거나, 로그 변환을 통해 관계를 선형화함

## Ⅴ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| 수요 및 매출 예측 | 과거 판촉비, 기온, 경쟁사 가격을 변수로 판매량 예측 | MAE, MAPE, 결정계수 |
| 신용 점수 산정 | 수입, 부채 비율, 연체 이력으로 대출 상환 확률 계산 (로지스틱) | AUC-ROC, 정밀도-재현율 |
| 공정 품질 제어 | 온도, 압력, 시간과 제품 강도 사이의 상관관계 도출 및 최적화 | 회귀 계수의 유의성, 잔차 분석 |

> 요약: 원인과 결과가 분명한 데이터셋에서 정량적 수치를 산출하고 미래를 시뮬레이션할 때 사용됨

## Ⅵ. 결론

회귀 분석은 데이터 과학에서 가장 역사가 깊으면서도 강력한 설명력을 가진 핵심 분석 기법임. 단순히 값을 맞추는 것을 넘어, '왜 그런 결과가 나왔는가'라는 원인을 파악할 수 있다는 점에서 머신러닝의 블랙박스 모델들과 차별화되는 강력한 강점을 가짐.

기술사는 회귀 모델 설계 시 데이터의 통계적 가정(선형성, 등분산성 등)을 엄격히 진단해야 하며, 특히 다중공선성과 과적합 문제를 해결하기 위해 정규화(Regularization)와 변수 선택 기법을 유연하게 적용할 수 있어야 함. 결국 좋은 회귀 모델은 높은 예측 정확도와 함께 실무자가 납득할 수 있는 논리적 해석력을 동시에 갖춘 모델임.
