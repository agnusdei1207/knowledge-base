## 미리 알고가기

- **결정계수 ($R^2$)**: 회귀 모델이 종속 변수의 전체 변동 중 얼마나 설명하는지를 나타내는 지표. $1$에 가까울수록 모델의 설명력이 높음
- **최소자승법 ($OLS$, Ordinary Least Squares)**: 잔차(실제값-예측값)의 제곱합을 최소화하는 회귀 계수를 찾는 가장 일반적인 최적화 방법
- **다중공선성 ($Multicollinearity$)**: 독립 변수들 사이에 강한 상관관계가 존재하여 회귀 계수 추정의 신뢰성을 떨어뜨리는 현상

## Ⅰ. 개요

- **정의/개념**: 하나 이상의 독립 변수($X$)와 종속 변수($Y$) 사이의 인과 관계를 수학적 함수 모델($y = f(x)$)로 정형화하여, 미측정 데이터의 값을 예측하거나 변수 간 영향력을 정량적으로 분석하는 통계적 모델링 기법임
- **배경/필요성**: 복잡한 비즈니스 환경에서 변수 간 단순 상관관계를 넘어선 '원인-결과'의 함수적 규명이 필수적임. 광고비 지출에 따른 매출 기여도 파악, 시스템 부하에 따른 응답 지연 시간($Latency$) 예측 등 합리적인 의사결정 근거를 확보하기 위해 데이터의 추세($Trend$)를 선형·비선형 수식으로 도출함

## Ⅱ. 특징 및 비교

### 가. 회귀 모델의 주요 유형 비교 및 선택 기준

| 구분 | 단순 선형 회귀 ($Simple$) | 다중 선형 회귀 ($Multiple$) | 로지스틱 회귀 ($Logistic$) |
|:---|:---|:---|:---|
| 독립 변수 수 | $1$개 | $2$개 이상 | $1$개 이상 |
| 종속 변수 형태 | 연속형 실수 ($Continuous$) | 연속형 실수 ($Continuous$) | 범주형 ($Binary/Multinomial$) |
| 관계식 형태 | $y = \beta_1x + \beta_0$ | $y = \sum \beta_i x_i + \beta_0$ | $P = \frac{1}{1+e^{-z}}$ ($Sigmoid$) |
| 주요 목적 | 단일 변수의 선형 관계 파악 | 복합 변수의 영향력 분석 | 특정 사건의 발생 확률 예측 |
| 해석 지표 | 기울기 ($Slope$) | 편회귀 계수, $VIF$ | 오즈 비 ($Odds Ratio$), $AUC$ |

> 요약: 예측값의 연속성 여부에 따라 선형 회귀와 로지스틱 회귀를 선택하며, 복합 요인 분석 시 다중 회귀를 사용함

### 나. 선형 회귀의 4대 기본 가정 (BLUE 성립 요건)
- **선형성 ($Linearity$)**: 독립 변수($X$)와 종속 변수($Y$) 간에 직선적인 관계가 존재해야 함
- **독립성 ($Independence$)**: 잔차($Residual$)들 사이에 상관관계가 없어야 함 (Durbin-Watson 검정)
- **등분산성 ($Homoscedasticity$)**: 잔차의 분산이 모든 독립 변수 범위에서 일정해야 함
- **정규성 ($Normality$)**: 잔차의 분포가 평균이 $0$인 정규 분포($Gaussian$)를 따라야 함 (Q-Q Plot 확인)

## Ⅲ. 구성요소/구조

### 가. 회귀 분석 아키텍처 인사이트 ($Architecture Insight$)

```text
   [Feature Eng.]       [Model Optimization]      [Model Validation]       [Model Serving]
  +----------------+    +------------------+    +------------------+    +------------------+
  |  Input Vector  | -> |  Loss Minimizer  | -> |   Performance    | -> |    Inference     |
  | (Independent X)|    |    (MSE, OLS)    |    |  (R^2, p-value)  |    |   (Target Y')    |
  +----------------+    +------------------+    +------------------+    +------------------+
          |                      |                       |                       |
     Scaling/PCA         Parameter Update        Residual Analysis       Real-time Pred.
```

### 나. 주요 구성 요소 및 역할

| 구성요소 | 역할 및 설명 | 핵심 포인트 (PPA/Trade-off) |
|:---|:---|:---|
| 독립 변수 ($Feature$) | 종속 변수에 영향을 주는 원인 변수 | 다중공선성($VIF$) 제어 및 변수 선택 중요 |
| 종속 변수 ($Target$) | 예측하고자 하는 결과 변수 | 아웃라이어($Outlier$)에 의한 모델 왜곡 주의 |
| 회귀 계수 ($\beta$) | 독립 변수의 변화에 따른 영향력 크기 | 표준화 계수를 통한 변수별 중요도 비교 가능 |
| 잔차 ($Residual$) | 실제값과 예측값의 차이 ($e = y - \hat{y}$) | 잔차 분석을 통해 모델의 가정 위반 여부 진단 |
| 비용 함수 ($Loss$) | 오차의 크기를 측정하는 함수 | $MSE$(민감도↑) vs $MAE$(견고성↑) 선택 |

> 요약: 독립 변수의 선형 결합을 통해 비용 함수를 최소화하는 최적 가중치($\beta$)를 산출하여 인과 관계를 구조화함

## Ⅳ. 절차/동작 원리

1. **데이터 수집 및 전처리**: 결측치 처리, 이상치 제거, 스케일링($Standardization$) 및 변수 변환 수행
2. **가정 검증 및 변수 선택**: 상관관계 분석, $VIF$ 확인을 통해 다중공선성을 제거하고 유의미한 변수 선정
3. **모델 학습 및 최적화**: $OLS$ 또는 경사하강법($Gradient$ $Descent$)을 통해 비용 함수를 최소화하는 계수($\beta$) 산출
4. **결과 해석 및 성능 평가**: $R^2$, $F$-검정, $p$-value를 통해 모델의 유의성을 판단하고 잔차 분석 수행

## Ⅴ. 문제점 및 개선방안

1. **다중공선성 ($Multicollinearity$)**: 독립 변수 간 강한 상관관계로 인해 계수 추정치가 불안정해지고 해석이 왜곡됨
   - **개선방안**: $VIF > 10$인 변수 제거, $PCA$를 통한 차원 축소, $Ridge/Lasso$ 규제($Regularization$) 적용
2. **이상치 ($Outlier$) 영향**: 최소자승법($OLS$)은 오차 제곱을 사용하므로 극단값에 의해 회귀선이 크게 이동함
   - **개선방안**: 로버스트 회귀($Robust$ $Regression$) 도입, $MAE$ 손실 함수 사용, 하차(Winsorizing) 처리
3. **과적합 ($Overfitting$)**: 학습 데이터에 과하게 최적화되어 실제 환경에서의 일반화 성능이 저하됨
   - **개선방안**: 교차 검증($Cross$ $Validation$) 수행, 정규화($Penalty$) 항 추가, 변수 개수 제한

## Ⅵ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 (Validation) |
|:---|:---|:---|
| 비즈니스 매출 예측 | 마케팅 채널별 투자비($X$)에 따른 매출액($Y$) 기여도 분석 | $MAPE$, $R^2$ (설명력 확인) |
| 핀테크 신용 평가 | 소득, 자산, 연체 이력을 기반으로 대출 승인 확률 예측 | $AUC-ROC$, $F1$-Score |
| 제조 공정 품질 관리 | 온도, 압력 등 공정 변수와 불량률 간의 상관관계 규명 | $p$-value, 계수($\beta$) 유의성 |

> 요약: 정량적 예측이 필요한 전 산업 분야에서 인과 관계 규명과 미래 가치 추정을 위한 기저 모델로 활용됨

## Ⅶ. 결론

회귀 분석은 머신러닝의 블랙박스 모델과 대비하여 높은 **설명력($Explainability$)**을 제공하는 강력한 통계적 도구임. 단순히 값을 맞추는 것을 넘어 '어떤 요인이 결과에 지대한 영향을 주는가'를 정량적으로 제시함으로써 의사결정의 객관성을 보장함.

기술사는 모델 설계 시 데이터의 통계적 기본 가정을 엄격히 준수해야 하며, 특히 고차원 데이터셋에서는 다중공선성과 과적합 문제를 해결하기 위해 정규화 기법을 적극 활용해야 함. 향후 실시간 스트리밍 데이터 기반의 온라인 회귀 분석(Online Regression)으로 확장하여 변동성 높은 환경에 대응하는 역량이 요구됨.
