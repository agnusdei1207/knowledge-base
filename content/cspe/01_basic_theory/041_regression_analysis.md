## Ⅰ. 개요
- **정의**: 독립변수(X)와 종속변수(Y) 간 함수 관계를 추정하여 연속값을 예측하는 통계 기법
- **배경/필요성**: 수요 예측·품질 관리 등에서 변수 간 인과·상관 관계를 수학적으로 모형화할 필요
- **비유**: 점들이 흩어진 그래프에 가장 잘 맞는 직선(또는 곡선)을 긋는 작업

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| OLS 최적화 원리 이해 | 잔차 제곱합 최소화 조건 | 상관 ≠ 인과 혼동 주의 |
| 평가 지표 활용 능력 | R², MSE, MAE 해석 | 다중공선성(VIF) 미언급 감점 |

> 요약: 회귀 분석은 변수 간 관계를 모형화하여 연속값을 예측하는 지도 학습의 기본 기법임

## Ⅱ. 구성요소
```text
+----------------+       +----------------+       +----------------+
| Independent    |       | Regression     |       | Dependent      |
| Variables (X)  | ----> | Model (f)      | ----> | Variable (Y)   |
+----------------+       +----------------+       +----------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 독립변수(X) | 예측에 사용하는 입력 특성(설명 변수) | 원인 제공자 |
| 회귀계수(β) | 각 독립변수가 종속변수에 미치는 영향 크기 | 레시피 비율 |
| 잔차(ε) | 실제값과 예측값의 차이, 모형이 설명 못 한 오차 | 측정 오차 |

> 요약: X·β·ε 세 요소로 Y = Xβ + ε 관계를 모형화함

## Ⅲ. 절차
```text
+------------+     +------------+     +------------+     +------------+
| Data Prep  |     | Model Spec | --> | Param Est  |     | Evaluation |
| (Scale/NA) | --> | (Lin/Poly) |     | (OLS/MLE)  | --> | (R2/MSE)   |
+------------+     +------------+     +------------+     +------------+
```

1. **데이터 전처리** — 결측치 제거, 이상치 탐지(IQR), 변수 스케일링 수행
2. **모형 설정** — 선형/다항/릿지 등 데이터 분포에 적합한 모형 선택
3. **모수 추정** — 잔차 제곱합(RSS) 최소화 조건으로 β를 OLS 또는 MLE로 산출
4. **모형 평가** — R²(설명력), MSE(평균 제곱 오차), 잔차 정규성 검정으로 적합도 검증

> 요약: 전처리 → 모형 선택 → OLS 추정 → R²·MSE 평가의 4단계로 수행함

## Ⅳ. 문제점
- 다중공선성: 독립변수 간 강한 상관(VIF > 10)으로 회귀계수 추정이 불안정
- 이상치 민감: 잔차 제곱 방식이므로 극단값 1개가 회귀선 전체를 왜곡
- 비선형 한계: 선형 모형으로 곡선 관계를 포착하지 못해 편향 오차 증가

> 요약: 공선성·이상치·비선형 한계가 회귀 분석의 3대 약점임

## Ⅴ. 개선방안
1. 단기: VIF 점검 후 상관 변수 제거 또는 릿지/라쏘(L2/L1) 정규화 적용
2. 중기: 로버스트 회귀(Huber Loss) 또는 RANSAC으로 이상치 영향 억제
3. 장기: 다항 회귀·커널 회귀·신경망 회귀 등 비선형 모형 전환

- 과적합 위험: 변수 과다 투입 → AIC/BIC 기반 변수 선택 (지표: Adj-R² 변화 < 0.01)

> 요약: 정규화 → 로버스트 회귀 → 비선형 전환 로드맵으로 한계를 극복함

## Ⅵ. 전망
- 향후 발전 방향: XAI 결합으로 회귀 계수의 해석 가능성을 유지하면서 비선형 표현력 확보
- 기술사적 판단: 단순 OLS는 감소 추세이나, 정규화 회귀(Ridge/Lasso)는 피처 선택의 표준 도구로 존속
- 기술사 제언: 예측 정확도와 해석 가능성 간 트레이드오프를 과제 요구사항에 따라 판단 필요
