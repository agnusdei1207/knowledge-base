## 미리 알고가기

- 종속 변수($Y$): 모델이 예측하거나 설명하려는 연속형 결과값임
- 독립 변수($X$): 종속 변수의 변화를 설명하는 입력 변수임
- 회귀 계수($\beta$): 독립 변수 변화가 종속 변수에 주는 방향과 크기임
- 잔차($Residual$): 실제값과 예측값의 차이이며 모델이 줄여야 할 오차임
- 다중공선성: 독립 변수끼리 강하게 상관되어 계수 해석이 흔들리는 현상임

## Ⅰ. 개요

- **정의/개념**: 회귀 분석은 독립 변수와 연속형 종속 변수의 관계를 함수로 추정해 예측값과 변수 영향도를 함께 판단하는 통계 모델링 기법임
- **배경/필요성**: 수요, 비용, 성능처럼 수치 결과를 예측해야 할 때 입력 변수별 영향과 오차 수준을 함께 설명할 기준이 필요함

## Ⅱ. 특징

- 연속형 값을 예측하므로 분류보다 오차 크기와 잔차 패턴이 핵심 판단 기준임
- 회귀 계수의 부호와 크기로 입력 변수가 결과에 미치는 방향과 민감도를 해석함
- 잔차의 선형성, 등분산성, 독립성 가정이 깨지면 예측보다 해석 신뢰도가 먼저 낮아짐
- 변수 수가 늘면 설명력은 높아지지만 다중공선성과 과적합 통제가 필요함

## Ⅲ. 종류 및 비교

| 기준 | 선형 회귀 | 다항 회귀 | 로지스틱 회귀 |
|:---|:---|:---|:---|
| 대상 값 | 연속형 수치 | 곡선형 연속 수치 | 범주 발생 확률 |
| 관계 형태 | 직선 관계 | 고차 곡선 관계 | 시그모이드 확률 |
| 주요 목적 | 값 예측과 계수 해석 | 비선형 추세 근사 | 분류 확률 산출 |
| 유의점 | 선형 가정 검증 필요 | 차수 증가 시 과적합 위험 | 회귀 이름이나 분류 모델임 |

> 요약: 회귀 방식은 종속 변수 형태와 관계 모양에 따라 선택함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 입력 변수 $X$ | 종속 변수의 변동을 설명하는 관측값이며 변수 선택 품질이 예측력을 좌우함 |
| 회귀식 | $Y = \beta_0 + \beta_1X_1 + ... + \beta_nX_n + \epsilon$ 형태로 관계를 표현함 |
| 잔차 | 모델이 설명하지 못한 차이이며 가정 검증과 이상치 판단의 근거가 됨 |
| 손실 함수 | 잔차 제곱합이나 평균제곱오차로 계수 추정의 목표를 정의함 |
| 평가 지표 | $R^2$, $RMSE$, $MAE$로 설명력과 예측 오차를 나누어 확인함 |

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 입력 변수 | --> | 회귀식    | --> | 예측값    | --> | 잔차 평가 |
+-----------+     +-----------+     +-----------+     +-----------+
      |                                                   |
      +---------------- 계수 해석 / 가정 검증 ------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 변수 선정 | --> | 계수 추정 | --> | 잔차 진단 | --> | 예측 활용 |
+-----------+     +-----------+     +-----------+     +-----------+
```

1. **변수 선정** — 예측 대상과 설명 변수를 정하고 이상치, 결측치, 단위 차이를 정리함
2. **계수 추정** — 최소제곱법이나 경사하강법으로 손실 함수가 작아지는 계수를 찾음
3. **잔차 진단** — 잔차 패턴, 다중공선성, 설명력을 확인해 모델 가정 위반을 찾음
4. **예측 활용** — 검증 데이터 오차와 해석 가능성을 함께 확인한 뒤 수치 예측에 적용함

## Ⅵ. 실무 적용 및 유의점

1. 가격·수요 예측에서는 변수 단위와 이상치가 계수를 왜곡하므로 표준화와 영향점 분석을 수행하고 $RMSE$와 $MAE$를 함께 확인함
2. 다중 회귀에서는 독립 변수 간 상관이 높으면 계수 부호가 흔들리므로 $VIF$로 다중공선성을 확인하고 변수 제거, 릿지, 라쏘를 적용함

## Ⅶ. 결론

- 회귀 분석은 수치 예측과 영향도 해석을 동시에 제공하므로 관계 가정, 잔차, 변수 안정성을 함께 검증해야 함

## 작성 근거(검토용)

- 회귀의 핵심을 연속형 값 예측과 계수 해석으로 잡아 분류 모델과의 경계를 분명히 함
- 잔차와 회귀 계수를 반복 축으로 배치해 구조, 절차, 실무 유의점이 같은 판단 기준을 따르게 함
- 로지스틱 회귀는 이름과 실제 용도가 혼동되므로 비교표에서 분류 모델임을 명시함
- 다중공선성은 회귀 해석 신뢰도를 직접 흔드는 요소라 미리 알고가기와 실무 항목에 포함함
- 평가 지표는 설명력($R^2$)과 예측 오차($RMSE$, $MAE$)를 분리해 과도한 단일 지표 의존을 줄임
