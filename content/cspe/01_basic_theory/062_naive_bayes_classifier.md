## Ⅰ. 개요
- 정의: 베이즈 정리를 기반으로 모든 특성이 독립적이라고 가정하는 확률적 분류기임.
- 배경: 대용량 데이터에서 계산 복잡도를 줄이고 빠른 예측을 수행하기 위해 사용됨.
- 출제 의도:
| 분류 | 상세 |
| --- | --- |
| 핵심요소 | 베이즈 정리, 조건부 독립, 사후 확률 |
| 주요특징 | 스팸 필터링, 실시간 분류, 학습 속도 빠름 |

## Ⅱ. 구성요소
- ASCII 구조도
 P(C|X) = [P(X|C) * P(C)] / P(X)
 (사후확률)  (우도)  (사전확률) (증거)
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 사전 확률 | 데이터 확인 전의 클래스 확률 | 과거 통계 |
| 우도(Likelihood) | 특정 클래스에서 데이터가 나타날 확률 | 목격 증언 |
| 조건부 독립 | 모든 속성이 서로 영향이 없다는 가정 | 각자도생 |
> 요약: 독립 변수 가정을 통해 사후 확률을 계산하는 통계적 모델임.

## Ⅲ. 절차
- ASCII 흐름도
[데이터 학습] -> [사전확률 산출] -> [우도 계산] -> [클래스 결정]
- 4단계 설명
1. 데이터 토큰화: 입력 데이터를 개별 특성 단위로 분리함.
2. 통계값 추출: 각 클래스별 특성 출현 빈도를 계산함.
3. 확률 곱 연산: 베이즈 정리에 따라 전체 확률을 계산함.
4. 최대값 선정: 계산된 확률 중 가장 높은 클래스를 선택함.
> 요약: 빈도 기반 확률 계산 후 최대 확률 클래스로 분류하는 방식임.

## Ⅳ. 문제점
- '나이브'한 독립성 가정으로 인해 실제 변수 간 상관관계를 무시함.

## Ⅴ. 개선방안
- 단기: 라플라스 스무딩 적용으로 확률 0 문제를 해결함.
- 중기: 가우시안 나이브 베이즈 등 데이터 분포 맞춤형 모델을 선택함.
- 장기: 신경망 모델과의 앙상블을 통해 표현력을 보강함.

## Ⅵ. 전망
- 엣지 컴퓨팅 환경에서의 초경량 실시간 스팸/이상 탐지 엔진으로 재조명받고 있으며, 데이터 편향 해소를 위한 라플라스 스무딩 고도화와 확률 기반 앙상블 모델의 기저 학습기로 활용성이 확대될 것임.
- 향후 온디바이스(On-device) AI 환경에서 최소 자원으로 텍스트 분류를 수행하는 핵심 모듈로 적용될 것으로 전망됨.
