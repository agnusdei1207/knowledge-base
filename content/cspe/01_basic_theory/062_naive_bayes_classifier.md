# 📖 【암기용】 개념 완전 이해

> 목적: 나이브 베이즈 분류를 처음 보는 사람도 완벽히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 나이브 베이즈는 조건부 확률로 클래스를 고르는 분류기이다.
- **왜 필요한가**: 스팸·문서·감성 분류처럼 단어 수가 많고 학습 데이터가 적은 경우 복잡한 모델보다 확률 집계 기반 모델이 CPU 학습 10분 이하 기준선을 제공한다.
- **핵심 직관**: 어떤 문서가 스팸인지 판단할 때 문서 안 단어들이 각자 독립적으로 스팸 가능성에 기여한다고 가정하고 확률을 곱한다.

## 깊이 이해
- **배경·문제의식**: 베이즈 정리는 원인(클래스)이 주어졌을 때 관측값(특징)이 나타날 확률을 이용해 관측값으로부터 클래스를 추정한다. 모든 특징 간 결합확률을 계산하려면 표본이 폭증하므로 조건부 독립을 가정한다.
- **작동 원리**: 클래스별 사전확률과 특징별 조건부확률을 학습한다. 예측 시 각 클래스의 로그 확률 합을 계산해 값이 큰 클래스를 선택한다.
- **비유**: 여러 증거를 각각 독립 목격담으로 보고, 클래스별로 증거 점수를 더해 가장 그럴듯한 결론을 고르는 방식이다.
- **구체 예시**: 스팸 메일 10,000건에서 "무료", "당첨" 단어가 스팸에서 각각 12%, 8% 나오면, 새 메일에 두 단어가 있을 때 스팸 로그 확률이 증가한다.
- **흔한 오해·주의점**: 독립 가정은 현실과 다르다. 그러나 텍스트 분류처럼 희소 특징이 많은 문제에서는 Multinomial Naive Bayes가 기준 모델로 유효하다.

## 연결 개념
- 베이즈 정리: 사전확률과 가능도 기반 추론
- 라플라스 스무딩: 0 확률 문제 방지
- TF-IDF·Bag of Words: 문서 특징 표현 방식

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 나이브 베이즈는 베이즈 정리와 특징 조건부 독립 가정을 이용한 확률 분류기이다.
> 2. **가치**: 문서 분류·스팸 탐지에서 수천~수만 차원 희소 특징을 낮은 학습 비용으로 처리한다.
> 3. **판단 포인트**: 특징 분포가 이산·연속·이진인지에 따라 Multinomial, Gaussian, Bernoulli 모델을 선택한다.

---

## Ⅰ. 개요 및 필요성

나이브 베이즈는 확률 기반 분류기이다. 데이터가 적고 특징 수가 많은 문서 분류에서는 복잡한 모델 학습보다 클래스별 단어 확률 추정이 실용적이다. 독립 가정을 두어 계산량을 줄이고, 라플라스 스무딩으로 미출현 단어의 0 확률 문제를 방지한다.

---

## Ⅱ. 구조 및 구성요소

```text
학습 문서 -> 특징 추출 -> 사전확률 계산 -> 조건부확률 계산 -> 클래스 예측
                         +-> 스무딩 -> 0 확률 방지
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 사전확률 P(C) | 클래스 출현 비율 계산 | 클래스 불균형 반영 |
| 가능도 P(X|C) | 클래스별 특징 출현 확률 계산 | 단어 빈도·연속값 분포 |
| 독립 가정 | 결합확률을 특징별 곱으로 단순화 | 계산량 감소, 상관관계 왜곡 |
| 스무딩 | 미출현 특징의 0 확률 방지 | Laplace alpha=1 기준 |

> 요약: 나이브 베이즈는 사전확률, 가능도, 독립 가정, 스무딩으로 클래스별 사후확률을 계산한다.

---

## Ⅲ. 동작원리 및 흐름도

```text
데이터 분리 -> 특징 벡터화 -> 클래스별 확률 학습 -> 로그확률 합산 -> 예측
              +-> alpha 조정 -> 검증 지표 확인
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 학습/검증 데이터 분리 | stratified 8:2 |
| 2 | CountVectorizer 또는 이진 특징 생성 | vocabulary 크기, 희소도 |
| 3 | 클래스별 사전확률·조건부확률 학습 | alpha=0.1~1.0 탐색 |
| 4 | 로그 사후확률 최대 클래스 선택 | Accuracy, Macro F1, PR-AUC |

> 요약: 나이브 베이즈는 벡터화된 특징의 로그 조건부확률을 클래스별로 합산해 가장 큰 사후확률을 선택한다.

---

## Ⅳ. 특징

| 구분 | 내용 | 판단 포인트 |
|:---|:---|:---|
| 장점 | 학습 비용이 특징 수에 선형 비례 | 문서 100,000건 기준 CPU 학습 가능 |
| 한계 | 특징 상관관계 반영 제한 | 단어 순서·문맥 의미 손실 |
| 비교 대상 | 로지스틱 회귀, SVM | 기준 모델·실시간 분류 후보 |
| 수치 기준 | alpha=0.1~1.0, min_df=2 이상 | 5-fold Macro F1 기준 |

> 요약: 나이브 베이즈는 희소 문서 분류 기준 모델로 적합하며, 특징 상관관계가 큰 문제는 선형 모델과 비교해야 한다.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존/대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | 규칙 기반은 키워드 목록 의존 | 확률 기반 자동 학습 | 라벨 데이터 1,000건 이상 |
| 비용/성능 | SVM은 마진 최적화 비용 존재 | 확률 집계로 학습 비용 낮음 | 실시간 재학습 요구 |
| 운영/위험 | 딥러닝은 문맥 표현 가능 | 해석 가능한 단어 확률 제공 | 감사·설명 요구 |

> 요약: CPU 학습 10분 이하 기준 모델과 설명 가능한 단어 확률이 필요하면 나이브 베이즈를 우선 적용한다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 0 확률 | 학습 데이터에 없는 단어 | 라플라스 스무딩 적용 | 미등록 단어 비율 5% 이하 |
| 정확도 저하 | 단어 상관관계·문맥 무시 | n-gram, 로지스틱 회귀 비교 | Macro F1 차이 3%p 이하 |
| 클래스 불균형 | 사전확률 편향 | class prior 보정, 임계값 조정 | 소수 클래스 Recall 80% 이상 |

> 요약: 스무딩, n-gram, 임계값 조정으로 확률 분류의 주요 위험을 통제한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 분류 품질 | Macro F1 0.80 이상, PR-AUC 0.85 이상 | 교차검증, 혼동행렬 |
| 처리 비용 | 학습 10분 이하, 예측 p95 20ms 이하 | 배치 로그, API 측정 |
| 설명 가능성 | 클래스별 상위 단어 20개 검토 | 확률 테이블, SHAP 보조 |

> 요약: 나이브 베이즈는 품질·처리비용·설명가능성을 함께 측정해야 운영 기준 모델로 쓸 수 있다.

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 — 단계별 또는 항목별):**
1. 스팸·문서 분류는 CountVectorizer 1~2gram + MultinomialNB alpha=1.0으로 기준 모델 구축함
2. 클래스 불균형은 stratified split, prior 보정, 임계값 조정으로 Recall 80% 이상 확보함
3. 운영은 월 1회 단어 확률 재학습, 미등록 단어 비율 5% 초과 시 vocabulary 갱신함

**결론 (2줄):**
- 기술사 판단: 희소 텍스트·CPU 학습 10분 이하 기준선이면 나이브 베이즈, 문맥·상관관계 반영이면 SVM·BERT 계열을 선택함
- 향후 방향: 나이브 베이즈는 경량 분류와 설명 가능한 기준 모델로 AutoML 파이프라인의 첫 단계에 배치됨
