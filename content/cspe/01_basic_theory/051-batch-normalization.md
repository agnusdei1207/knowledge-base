## Ⅰ. 개요
- **정의**: 신경망의 각 은닉층에 들어가는 입력을 미니배치 단위로 평균 0, 분산 1로 정규화하는 기법임.
- **배경/필요성**: 내부 공변량 변화를 완화하여 학습 속도를 높이고 가중치 초기화의 민감도를 줄이기 위해 도입됨.
- **출제 의도**: 배치 정규화의 위치, 스케일과 시프트 파라미터의 역할을 명확히 이해하는지 평가함.

## Ⅱ. 구성요소
```text
+------------------+       +------------------+       +------------------+
| Mini-batch Input | ----> | Normalize        | ----> | Scale & Shift    |
| (z = Wx + b)     |       | (Mean=0, Var=1)  |       | (Gamma, Beta)    |
+------------------+       +------------------+       +------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 배치 통계량 | 현재 배치 데이터의 분포를 파악하는 평균 및 분산 | 학생들 평균 점수 |
| 정규화 (Norm) | 입력을 일정한 분포(표준정규분포)로 변환 | 표준점수 변환 |
| 스케일/시프트 | 정규화된 데이터에 곱(Gamma)과 합(Beta)을 적용해 표현력 복원 | 가산점 재조정 |

> 요약: 은닉층 입력을 정규화한 뒤, 학습 가능한 파라미터로 변환하여 표현력을 유지함.

## Ⅲ. 절차
```text
+-------------+   +-------------+   +-------------+   +-------------+
| 1. 평균/분산|-->| 2. 데이터   |-->| 3. 스케일/  |-->| 4. 활성화   |
|    계산     |   |    정규화   |   |    시프트   |   |    함수전달 |
+-------------+   +-------------+   +-------------+   +-------------+
```
1. **평균/분산 계산**: 하나의 미니배치 내에서 각 피처별로 평균과 분산을 구함.
2. **데이터 정규화**: 입력값에서 평균을 빼고 표준편차로 나누어 정규화 수행.
3. **스케일/시프트**: 학습 파라미터인 Gamma와 Beta를 적용해 원래 분포의 표현력을 일부 복원함.
4. **활성화 함수전달**: 정규화된 값을 ReLU 등의 활성화 함수로 넘겨 비선형성을 추가함.

> 요약: 배치 통계량으로 정규화하고 파라미터로 보정한 후 활성화 함수에 입력함.

## Ⅳ. 문제점
- **배치 크기 의존성**: 배치 크기가 너무 작으면 평균과 분산 추정치가 극도로 불안정해져 성능이 하락함.
- **RNN 적용 곤란**: 시퀀스 길이가 가변적인 순환 신경망에서는 배치 내 통계량을 계산하기 어려움.

## Ⅴ. 개선방안
- **배치 크기 의존성**: (단기) Group Normalization 적용 / (장기) 통계량을 동기화하는 SyncBN 활용 필요.
- **RNN 적용 곤란**: (단기) Layer Normalization으로 대체 / (장기) 트랜스포머 아키텍처로 전환 필요.

## Ⅵ. 전망
- CNN에서는 기본 정규화 기법으로 쓰이나, 트랜스포머 확산에 따라 LayerNorm 계열이 주류로 함께 쓰이고 있음.
