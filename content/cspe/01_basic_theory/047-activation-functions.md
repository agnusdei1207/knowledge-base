## Ⅰ. 개요
- **정의**: 인공 신경망의 은닉층에서 입력 신호의 총합을 출력 신호로 변환하는 비선형 함수임.
- **배경/필요성**: 신경망에 비선형성을 부여하여, 다층 구조가 단순한 선형 회귀로 붕괴되는 것을 막기 위해 필요함.
- **출제 의도**: Sigmoid, Tanh, ReLU 함수의 수식적 특징과 기울기 소실 문제 등 장단점을 파악하고 있는지 평가함.

## Ⅱ. 구성요소
```text
+------------------+       +------------------+       +------------------+
| Weighted Sum     | ----> | Activation Func  | ----> | Output Signal    |
| (z = WX + b)     |       | (Non-linear)     |       | (a = f(z))       |
+------------------+       +------------------+       +------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| Sigmoid | 입력을 0~1 사이로 압축 (이진 분류 출력층에 주로 사용) | S자 곡선 스위치 |
| Tanh | 입력을 -1~1 사이로 압축 (Sigmoid 중심 이동 개선) | 확장된 스위치 |
| ReLU | 양수는 그대로, 음수는 0으로 반환 (은닉층 표준) | 꺾인 직선 스위치 |

> 요약: 신경망에 비선형성을 추가하기 위해 선형 결합 결과값에 활성화 함수를 적용함.

## Ⅲ. 절차
```text
+-------------+   +-------------+   +-------------+   +-------------+
| 1. 입력합   |-->| 2. 함수     |-->| 3. 비선형   |-->| 4. 다음층   |
|    계산     |   |    적용     |   |    변환     |   |    전달     |
+-------------+   +-------------+   +-------------+   +-------------+
```
1. **입력합 계산**: 이전 층의 출력값들에 가중치를 곱하고 편향을 더해 선형 결합(z)을 구함.
2. **함수 적용**: 선형 결합 결과값(z)을 ReLU, Sigmoid 등 활성화 함수에 입력으로 넣음.
3. **비선형 변환**: 함수 로직에 따라 값을 압축하거나 특정 임계값을 기준으로 변환(a)함.
4. **다음층 전달**: 변환된 결과값을 활성화 값(a)으로 삼아 다음 층의 입력으로 전달함.

> 요약: 노드의 가중치 합을 활성화 함수로 비선형 변환하여 다음 계층으로 전달함.

## Ⅳ. 문제점
- **기울기 소실**: Sigmoid, Tanh는 양극단에서 미분값이 0에 가까워져 역전파 시 학습이 정지됨.
- **Dying ReLU**: ReLU는 음수 입력 시 기울기가 0이 되어, 가중치가 갱신되지 않는 현상이 발생함.

## Ⅴ. 개선방안
- **기울기 소실**: (단기) 은닉층에 가급적 ReLU 계열 사용 / (장기) 배치 정규화, 스킵 커넥션 기법 병행 도입 필요.
- **Dying ReLU**: (단기) Leaky ReLU, PReLU 등 사용 / (장기) GELU, Swish 등 부드러운 곡선 함수 활용 필요.

## Ⅵ. 전망
- LLM 등 최신 아키텍처에서는 GELU, Swish와 같은 연속적이고 부드러운 활성화 함수들이 성능 극대화를 위해 표준으로 채택되고 있음.
