## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 게임 트리에서 선택·확장·시뮬레이션·역전파 4단계를 반복하여 최적 행동을 탐색하는 확률적 트리 탐색 알고리즘임 |
| **배경/필요성** | 바둑·체스 등 상태 공간이 방대한 게임에서 완전 탐색이 불가능하며, 표본 기반 최적 행동 추정이 필요함 |
| **출제 의도** | MCTS 4단계와 UCB(Upper Confidence Bound) 공식의 탐색-활용 균형을 이해하는지 평가함 |

## Ⅱ. 구성요소
```
+----------+     +----------+     +----------+
| 선택     | --> | 확장     | --> | 시뮬레이션|
| (Select) |     | (Expand) |     | (Rollout)|
+----------+     +----------+     +----------+
                                       |
                                  +----+-------+
                                  | 역전파    |
                                  | (Backprop)|
                                  +------------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| 선택(Select) | 루트부터 UCB1 공식으로 가장 유망한 자식 노드를 선택하여 리프까지 내려감 | 가장 유망한 갈림길 선택 |
| 확장(Expand) | 리프 노드에서 미탐색 자식 노드를 하나 추가함 | 새 갈래길 개척 |
| 시뮬레이션(Rollout) | 추가된 노드에서 무작위 게임을 종료까지 수행하여 승패를 판정함 | 주사위로 끝까지 시뮬레이션 |
| 역전파(Backprop) | 시뮬레이션 결과(승/패)를 루트까지 거슬러 올라가며 승률을 갱신함 | 결과를 상위에 보고 |

> 요약: 선택 → 확장 → 시뮬레이션 → 역전파를 반복하여 최적 행동을 점진적으로 추정함.

## Ⅲ. 절차
```
+------------+     +------------+
| UCB1선택   | --> | 리프확장   |
| (탐색-활용)|     | (새노드)  |
+------------+     +------------+
                        |
+------------+     +----+-------+
| 통계갱신   | <-- | 랜덤플레이 |
| (역전파)   |     | (승패결정) |
+------------+     +------------+
```

1. 선택: UCB1 = 승률 + C × √(ln(부모방문수)/자식방문수)로 탐색-활용을 균형 있게 선택함
2. 확장: 선택된 리프 노드의 미탐색 자식을 하나 트리에 추가함
3. 시뮬레이션: 추가된 노드에서 랜덤 정책으로 게임 종료까지 플레이아웃을 수행함
4. 역전파: 승/패 결과를 경로상 모든 노드의 방문 수·승리 수에 반영함

> 요약: UCB1 선택 → 확장 → 랜덤 플레이아웃 → 역전파로 게임 트리의 가치를 추정함.

## Ⅳ. 문제점
- Rollout 품질: 무작위 시뮬레이션은 실제 최적 플레이와 괴리가 있어 추정 정확도가 제한됨
- 수렴 속도: 방대한 상태 공간에서 충분한 시뮬레이션 횟수가 필요하여 시간이 소요됨
- UCB 상수 튜닝: 탐색-활용 균형 상수 C의 최적값이 문제에 따라 달라짐

## Ⅴ. 개선방안
- (단기) 도메인 지식 활용: 랜덤 대신 휴리스틱 기반 Rollout 정책을 적용하여 추정 품질을 개선함
- (중기) 신경망 결합(AlphaGo): Policy·Value 네트워크로 선택·시뮬레이션을 가이드함
- (장기) AlphaZero 자기 대국: Rollout 없이 Value 네트워크만으로 평가하여 수렴 속도를 획기적으로 개선함

## Ⅵ. 전망
- AlphaGo·MuZero에서 MCTS+딥러닝 결합이 입증되었으며, 로봇 제어·약물 설계·자율주행 의사결정에서 MCTS 기반 계획 알고리즘이 확산될 전망임
