## 미리 알고가기

- **게임 트리 ($Game$ $Tree$)**: 게임의 모든 가능한 상태($State$)와 전이($Transition$)를 나타낸 계층적 구조임
- **$UCT$ ($Upper$ $Confidence$ $Bound$ $applied$ $to$ $Trees$ )**: 탐색($Exploration$)과 활용($Exploitation$)의 균형을 맞추기 위한 노드 선택 공식임
- **롤아웃 ($Rollout$)**: 특정 노드에서 게임의 종료 시점까지 무작위로 진행하는 시뮬레이션 과정임

## Ⅰ. 개요

- **정의/개념**: 방대한 탐색 공간을 가진 문제에서 무작위 시뮬레이션을 통해 얻은 승률 통계를 기반으로, 가장 유망한 경로를 집중적으로 탐색하여 최적의 의사결정을 수행하는 알고리즘임
- **배경/필요성**: 바둑($Go$)과 같이 상태 공간이 극도로 넓고 정밀한 평가 함수($Evaluation$ $Function$) 설계가 불가능한 도메인에서, 전통적인 미니맥스($Minimax$) 탐색의 한계를 극복하고 실전적인 해를 도출하기 위해 사용함

## Ⅱ. 특징 및 비교

### 가. 게임 탐색 알고리즘 기술 비교

| 비교 항목 | 미니맥스 ($Minimax$) | 몬테카를로 트리 탐색 ($MCTS$) |
|:---|:---|:---|
| **판단 근거** | 결정론적 평가 함수 점수 | **확률적 시뮬레이션 승률 통계** |
| **탐색 방식** | 고정 깊이 전수 조사 | **유망 경로 집중 탐색 ($Selective$)** |
| **성능 특징** | 평가 함수 설계 능력에 의존 | **시뮬레이션 횟수에 비례하여 향상** |
| **중단 시점** | 탐색 완료 전까지 해답 불완전 | **언제든 현재 최적해 반환 ($Anytime$)** |
| **적합 도메인** | 체스, 오목 (상태 공간 작음) | **바둑, 실시간 전략 게임 ($RTS$)** |

> 요약: 정형화된 규칙은 미니맥스가 정교하나, 불확실성이 크고 공간이 방대하면 $MCTS$의 통계적 접근이 우월함.

### 나. 아키텍처 인사이트: $Anytime$ $Algorithm$

- **동적 시간 관리**: 주어진 시간이 짧으면 얕은 탐색을, 길면 깊은 탐색을 수행하여 항상 최선의 답을 내놓는 유연한 구조임
- **비대칭 트리 성장**: 모든 형제 노드를 동일하게 확장하지 않고, 승률이 높은 유망 노드 위주로 깊게 파고들어 탐색 효율을 극대화함

## Ⅲ. 구성요소/구조

### 가. $MCTS$ 4단계 순환 아키텍처

1. **선택 ($Selection$)**: 루트부터 $UCT$ 공식이 최대인 자식 노드를 선택하며 리프($Leaf$) 노드까지 이동
2. **확장 ($Expansion$)**: 도달한 리프 노드에서 방문하지 않은 새로운 자식 노드를 트리에 추가
3. **시뮬레이션 ($Simulation$)**: 확장된 노드에서 게임 종료 시점까지 무작위($Rollout$)로 대국 진행
4. **역전파 ($Backpropagation$)**: 승패 결과를 루트까지 거슬러 올라가며 경로 상 모든 노드의 방문 횟수($n$)와 승리 횟수($w$) 갱신

### 나. 노드 선택 공식: $UCT$ (Upper Confidence Bound)

- **수식**: $UCT = \frac{w_i}{n_i} + c \sqrt{\frac{\ln N}{n_i}}$
  - $\frac{w_i}{n_i}$: 현재까지의 승률 (**활용**, $Exploitation$)
  - $c \sqrt{\frac{\ln N}{n_i}}$: 방문 횟수가 적은 노드에 부여하는 가중치 (**탐색**, $Exploration$)
  - $c$: 탐색의 강도를 조절하는 상수

## Ⅳ. 문제점 및 개선방안

1. **무작위 롤아웃의 통계적 왜곡**: 완전 무작위 대국은 실제 고수들의 착수 양상과 달라 승률 추정의 정확도가 낮음
   - **개선방안**: 딥러닝 **정책망 ($Policy$ $Network$)**을 도입하여 유망한 수 위주로 시뮬레이션하거나 가치망으로 대체
2. **실시간성 확보를 위한 연산 부하**: 수만 번의 시뮬레이션 수행 시 지연 시간 발생
   - **개선방안**: **트리 재사용 ($Tree$ $Reuse$)** 및 멀티 코어 기반의 병렬 시뮬레이션($Root/Leaf$ $Parallelism$) 아키텍처 적용
3. **함정 수 ($Trap$ $Node$) 취약성**: 깊은 곳에 단 하나의 패배 수가 숨겨진 경우 평균 승률 기반의 $MCTS$는 이를 인지하지 못할 위험 존재
   - **개선방안**: 탐색 계수 $c$의 동적 조절 또는 특정 깊이에서 결정론적 탐색 알고리즘 혼용

## Ⅴ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| **AlphaGo / AlphaZero** | $MCTS$와 심층 신경망($CNN$)의 결합 | 프로 기사 승률, 탐색 효율성 |
| **자율주행 경로 계획** | 주변 차량의 이동 시나리오 시뮬레이션 | 사고 발생률, 급제동 빈도 |
| **복잡한 공정 관리** | 생산 스케줄링의 방대한 조합 탐색 | 공정 완료 시간($Makespan$), 가동률 |
| **금융 포트폴리오** | 시장 변동 시나리오 기반 최적 자산 배분 | 위험 대비 수익률($Sharpe$ $Ratio$) |

## Ⅵ. 결론

$MCTS$는 **'무지($Ignorance$)로부터 통계적 통찰을 이끌어내는'** 현대 지능형 알고리즘의 정수임. 기술사는 단순히 시뮬레이션 횟수를 늘리는 것에 그치지 않고, **탐색과 활용의 균형($UCT$)**을 도메인에 맞게 정교하게 설계해야 함. 특히 향후 **심층 강화학습**과의 결합을 통해 직관(신경망)과 논리(트리 탐색)가 통합된 고도의 의사결정 아키텍처를 구축하는 역량이 필수적임.
