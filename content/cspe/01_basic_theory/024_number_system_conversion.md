## 미리 알고가기

- 기수($r$): 각 자리에 허용된 기호 개수이며 진법을 결정함
- 위치 가중치: 자리 위치에 따라 $r^i$가 곱해지는 자리값 기준임
- 비트 그룹화: 2진수를 3비트나 4비트씩 묶어 8진수·16진수로 바꾸는 방식임
- 정수부 변환: 목표 기수로 반복 나눗셈을 수행하고 나머지를 역순으로 읽음
- 소수부 변환: 목표 기수를 반복 곱하고 정수 부분을 순서대로 읽음
- 정밀도 손실: 유한 자리로 표현하지 못하는 소수가 잘리거나 반올림되는 현상임

## Ⅰ. 개요

- **정의/개념**: 수 체계 변환은 같은 수치값을 서로 다른 기수의 자리값 표현으로 바꾸어 컴퓨터 내부 표현과 사람이 읽는 표현을 연결하는 절차임
- **배경/필요성**: 주소·명령·권한·색상 값을 정확히 해석하기 위해 진법 간 변환 기준이 필요함

## Ⅱ. 특징

- 변환 전후의 수치값은 같고, 달라지는 것은 기수와 자리 기호의 표현 방식임
- 8진수와 16진수는 2진수와 각각 $2^3$, $2^4$ 관계라 비트 묶음만으로 직접 변환함
- 10진수가 포함되면 위치 가중치 합산이나 반복 나눗셈·곱셈을 사용함
- 소수부는 반복 패턴이 생길 수 있어 자리수 제한과 반올림 기준이 필요함

## Ⅲ. 종류 및 비교

| 진법 | 사용 기호 | 2진수 대응 | 주요 활용 |
|:---|:---|:---|:---|
| 2진수 | 0, 1 | 1비트 | 회로 신호, 내부 연산 |
| 8진수 | 0-7 | 3비트 묶음 | 권한 표기, 과거 시스템 표기 |
| 10진수 | 0-9 | 직접 묶음 없음 | 사람 중심 수치 표현 |
| 16진수 | 0-9, A-F | 4비트 묶음 | 메모리 주소, 색상, 패킷 분석 |

> 요약: 2·8·16진수는 비트 묶음으로 빠르게 변환하고, 10진수는 가중치 계산이 필요함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 원본 수 | 변환 전 값이며 기수와 소수점 위치를 함께 식별해야 함 |
| 목표 기수 | 결과 표현에 사용할 자리 기호와 가중치 체계를 결정함 |
| 자리값 계산 | 각 자리 기호에 $r^i$를 곱해 같은 수치값을 유지함 |
| 그룹 변환표 | 2진수와 8·16진수 사이의 고정 매핑을 제공함 |
| 검증 절차 | 역변환이나 가중치 합산으로 값 보존 여부를 확인함 |

```text
+-------------+     +-------------+     +-------------+
| 원본 진법    | --> | 자리값 계산   | --> | 목표 진법    |
+-------------+     +-------------+     +-------------+
        |                                     |
        +------------ 값 보존 확인 ------------+
```

> 요약: 진법 변환은 원본과 목표 기수가 달라도 자리값 계산으로 같은 수치값을 보존함.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 진법 식별  | --> | 정수/소수 분리 | --> | 변환 수행  | --> | 값 검증   |
+----------+     +----------+     +----------+     +----------+
```

1. **진법 식별**: 원본 기수와 목표 기수를 확인하고 직접 묶음 가능 여부를 판단함
2. **부분 분리**: 정수부와 소수부를 나누어 서로 다른 변환 규칙을 적용함
3. **변환 수행**: 정수부는 나눗셈, 소수부는 곱셈, 2·8·16진수는 비트 묶음으로 처리함
4. **값 검증**: 결과를 역변환하거나 가중치 합산으로 원래 값과 비교함

> 요약: 정수부·소수부 규칙을 분리하고 역변환으로 값 보존 여부를 확인함.

## Ⅵ. 실무 적용 및 유의점

1. 메모리 주소와 패킷 필드는 16진수로 표시하되 바이트 경계를 맞추기 위해 앞자리 0을 보존하고 역변환 결과로 표기 오류를 확인함
2. 소수 변환은 유한 비트로 끝나지 않는 경우가 있으므로 표시 자리수와 반올림 방식을 명시하고 허용 오차로 계산 결과를 검증함

## Ⅶ. 결론

- 수 체계 변환은 값 보존을 전제로 표현만 바꾸는 절차이므로, 비트 묶음 가능성과 정밀도 손실을 기준으로 변환 방식을 선택해야 함

- 특징은 값 보존, 직접 변환, 10진수 경유, 소수 정밀도라는 실무 오류 지점을 중심으로 선별함
