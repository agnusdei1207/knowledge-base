## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 10진수·2진수·8진수·16진수 등 서로 다른 기수(Base) 체계 간 수를 변환하는 연산 기법임 |
| **배경/필요성** | 컴퓨터는 2진수로 동작하며, 사람은 10진수·16진수를 사용하므로 수 체계 간 변환이 필수임 |
| **출제 의도** | 기수 변환 알고리즘과 소수점 이하 변환, 보수 표현과의 관계를 이해하는지 평가함 |

## Ⅱ. 구성요소
```
+----------+     +----------+     +----------+
| 10진수   | --> | 2진수    | --> | 8/16진수  |
| (Base10) |     | (Base2)  |     | (Base8/16)|
+----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| 10진법 | 0~9 숫자로 표현하며, 사람의 기본 수 체계임 | 일상 계산 |
| 2진법 | 0·1만 사용하며, 디지털 회로의 기본 표현임 | 스위치 ON/OFF |
| 16진법 | 0~9·A~F(10~15)로 표현하며, 2진 4자리를 1자리로 축약함 | 메모리 주소 표기 |

> 요약: 10진(인간) ↔ 2진(기계) ↔ 8·16진(축약 표기) 간 변환을 수행함.

## Ⅲ. 절차
```
+------------+     +------------+
| 정수부분   | --> | 나머지역순  |
| 기수나눗셈 |     | 배열       |
+------------+     +------------+
                        |
+------------+     +----+-------+
| 최종합산   | <-- | 소수부분  |
|            |     | 기수곱셈   |
+------------+     +------------+
```

1. 정수 부분 변환: 10진 정수를 목표 기수로 반복 나누어 나머지를 역순으로 배열함
2. 소수 부분 변환: 10진 소수를 목표 기수로 반복 곱하여 정수 부분을 순서대로 취함
3. 2진 ↔ 8진: 2진수를 3비트씩 묶어 8진 1자리로 변환함
4. 2진 ↔ 16진: 2진수를 4비트씩 묶어 16진 1자리로 변환함

> 요약: 정수(나눗셈·역순) + 소수(곱셈·순서) + 비트 그룹핑으로 기수 변환을 수행함.

## Ⅳ. 문제점
- 소수 무한 반복: 10진 소수가 2진으로 정확히 표현되지 않아 무한 순환 소수가 발생함(예: 0.1₁₀)
- 오버플로우: 큰 수의 변환 시 비트 수 제한으로 표현 범위를 초과할 수 있음
- 변환 실수: 수동 계산 시 나머지 역순 배열·비트 그룹핑에서 오류가 빈발함

## Ⅴ. 개선방안
- (단기) 비트 그룹핑 활용: 2진 ↔ 8진·16진 변환은 나눗셈 대신 3/4비트 그룹핑으로 간편히 수행함
- (중기) IEEE 754 이해: 부동소수점 표현의 변환 원리를 함께 학습하여 정밀도 손실을 인식함
- (장기) 임의 정밀도 연산: BigInteger·BigDecimal 라이브러리로 오버플로우 없이 변환함

## Ⅵ. 전망
- 메모리 주소·MAC 주소·IPv6 등에서 16진 표기가 표준이며, 양자 컴퓨팅의 큐비트 상태 표현에서 새로운 수 체계 활용이 연구되고 있음
