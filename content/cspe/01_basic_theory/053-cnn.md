## Ⅰ. 개요
- **정의**: 이미지나 격자 형태의 데이터에서 지역적 특징(Feature)을 추출하는 데 특화된 딥러닝 아키텍처임.
- **배경/필요성**: 전결합층의 위치 정보 손실 및 막대한 파라미터 문제를 해결하기 위해 시각 피질 원리를 모방함.
- **출제 의도**: 합성곱 연산, 풀링의 원리, 파라미터 공유 및 지역 수용 영역의 개념을 평가함.

## Ⅱ. 구성요소
```text
+------------------+       +------------------+       +------------------+
| Input Image      | ----> | Conv + ReLU      | ----> | Pooling Layer    |
| (Pixels)         |       | (Feature Maps)   |       | (Down-sampling)  |
+------------------+       +------------------+       +------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 합성곱 층 (Conv) | 필터를 이동시키며 공간적 특징(에지 등)을 추출 | 돋보기로 부분 관찰 |
| 풀링 층 (Pool) | 공간 차원을 축소하여 불변성 확보 및 연산량 감소 | 이미지 해상도 축소 |
| 완전 연결 층 (FC)| 추출된 고차원 특징을 평탄화하여 최종 분류 | 종합적 결론 도출 |

> 요약: 필터(가중치 공유)를 사용해 특징을 추출하고 크기를 줄인 뒤 최종 분류를 수행함.

## Ⅲ. 절차
```text
+-------------+   +-------------+   +-------------+   +-------------+
| 1. 이미지   |-->| 2. 합성곱   |-->| 3. 풀링     |-->| 4. 평탄화/  |
|    입력     |   |    연산     |   |    축소     |   |    분류     |
+-------------+   +-------------+   +-------------+   +-------------+
```
1. **이미지 입력**: 다채널(RGB 등)의 격자형 이미지 데이터를 네트워크에 전달함.
2. **합성곱 연산**: 커널(필터)을 이동하며 합성곱 연산 및 패딩을 적용함.
3. **풀링 축소**: Max Pooling 등을 통해 특징만 남기고 피처 맵의 차원을 축소함.
4. **평탄화/분류**: 마지막 피처 맵을 1차원 벡터로 변환한 후 완전 연결 층을 거쳐 분류함.

> 요약: 합성곱과 풀링을 반복해 위치 불변 특징을 추출하고 이미지를 분류함.

## Ⅳ. 문제점
- **고정된 수용 영역**: 지정된 크기로만 연산하여 글로벌(전역) 문맥을 파악하기 어려움.
- **기하학적 변환 취약**: 이미지 회전이나 심한 크기 변화에 대해 불변성을 보장하지 못함.

## Ⅴ. 개선방안
- **고정된 수용 영역**: (단기) 팽창된 합성곱 활용 / (장기) Vision Transformer(ViT) 혼용 필요.
- **기하학적 변환 취약**: (단기) 데이터 증강 적용 / (장기) 공간 변환 네트워크(STN) 도입 필요.

## Ⅵ. 전망
- 이미지를 넘어 음성/시계열 분석에 쓰이며, 경량화(MobileNet 등) 기술이 지속 연구됨.
