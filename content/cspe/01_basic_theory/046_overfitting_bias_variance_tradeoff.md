# 📖 【암기용】 개념 완전 이해

> 목적: 과적합·과소적합과 편향-분산 관계를 처음 봐도 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 설명이다.

## 한눈에
- **개요**: 모델 복잡도와 일반화 오차의 균형 문제
- **왜 필요한가**: 학습 데이터 점수만 보면 운영 데이터 오차를 판단할 수 없음
- 훈련·검증 오차 차이를 보아 모델 복잡도를 조정해야 함
- **핵심 직관**: 외운 학생은 기출은 맞히나 변형 문제를 틀리고, 덜 배운 학생은 기출·변형 모두 틀림.

## 깊이 이해
- **배경·문제의식**: 머신러닝 목표는 훈련 데이터 암기가 아니라 미관측 데이터 예측임
- 모델 복잡도가 낮으면 패턴을 못 잡고, 높으면 잡음까지 학습함
- **작동 원리**: 과소적합은 편향(Bias)이 커서 훈련·검증 오차가 모두 큼
- 과적합은 분산(Variance)이 커서 훈련 오차는 낮고 검증 오차는 큼
- **비유**: 문제집 답안을 통째로 외운 학생은 같은 문제 100점, 숫자만 바뀐 문제 60점임
- 원리를 모르면 두 시험 모두 60점 이하임
- **구체 예시**: 10차 다항회귀가 훈련 MSE 0.01, 검증 MSE 2.40이면 과적합임
- 1차 회귀가 훈련 MSE 1.80, 검증 MSE 1.95이면 과소적합 가능성이 큼
- **흔한 오해·주의점**: 훈련 정확도 99%는 배포 품질 보장이 아님
- 검증·테스트 분리, 교차검증, 데이터 누수 점검이 함께 필요함

## 연결 개념
- 정규화(L1/L2) — 과적합 분산을 가중치 제약으로 축소
- 교차검증(Cross Validation) — 검증 오차 추정 편차 완화
- 조기 종료(Early Stopping) — 검증 오차 상승 시 학습 중단

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 과적합·과소적합은 모델 복잡도와 일반화 오차의 불균형 현상임.
> 2. **가치**: 편향-분산 분해로 훈련 오차와 검증 오차의 원인을 구분함.
> 3. **판단 포인트**: 검증 MSE, K-Fold 평균·표준편차, Train-Test Gap으로 복잡도·규제를 선택함.

---

## Ⅰ. 개요 및 필요성

- 정의: 과적합·과소적합은 모델 복잡도와 일반화 오차의 균형 문제임
- 배경: 모델은 훈련 데이터뿐 아니라 미관측 데이터에서 오차를 낮춰야 함
- 필요성: 과소적합은 패턴 미학습, 과적합은 잡음 학습이므로 검증 기반 복잡도 조절이 필요함

---

## Ⅱ. 구조 및 구성요소

```text
데이터 -> 모델 복잡도 -> 훈련 오차 -> 검증 오차 -> 일반화 판단
          +-> 편향(Bias) 평가
          +-> 분산(Variance) 평가
          +-> 규제/복잡도 조정
```

| 구성요소 | 역할 | 판단 지표 |
|:---|:---|:---|
| 편향(Bias) | 단순 모델의 체계적 오차 | 훈련·검증 오차 모두 높음 |
| 분산(Variance) | 데이터 변화에 대한 예측 변동 | 훈련-검증 오차 차이 큼 |
| 규제/복잡도 | L1/L2, 트리 깊이, 파라미터 수 조정 | 검증 MSE 최소점 |

> 요약: 편향은 과소적합, 분산은 과적합을 설명하며 복잡도·규제가 일반화 오차를 조절함.

---

## Ⅲ. 동작원리 및 흐름도

```text
학습 데이터 분할 -> 훈련 오차 측정 -> 검증 오차 측정
        -> Gap 분석 -> 복잡도/규제 조정 -> 테스트 확정
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | Train/Validation/Test를 70/15/15 등으로 분리 | 데이터 누수 0건 |
| 2 | 모델 복잡도별 학습 | 훈련 MSE 또는 Accuracy |
| 3 | 검증 오차와 Gap 산출 | Gap 10%p 이상이면 과적합 의심 |
| 4 | 규제·복잡도 조정 후 테스트 | Test MSE, F1, AUC 최종 보고 |

> 요약: 훈련 점수와 검증 점수의 차이를 수치화한 뒤 복잡도·규제를 반복 조정함.

---

## Ⅳ. 특징

| 구분 | 과소적합 | 과적합 | 수치 판단 |
|:---|:---|:---|:---|
| 원인 | 낮은 복잡도, 특징 부족 | 높은 복잡도, 잡음 학습 | Train/Test Gap |
| 오차 패턴 | 훈련·검증 모두 큼 | 훈련 낮음, 검증 큼 | MSE, AUC, F1 |
| 대응 | 특징 추가, 모델 용량 증가 | L1/L2, Dropout, Early Stopping | 검증 오차 최소점 |

> 요약: 과소적합은 편향 축소, 과적합은 분산 축소가 처방이며 검증 지표로 선택함.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존·대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | 훈련 정확도 중심 선택 | Train/Validation/Test Gap 기반 선택 | Gap 10%p 이상이면 분산 통제 |
| 비용/성능 | 단일 Hold-out 평가 | 5-Fold CV 평균·표준편차 산출 | 표준편차가 평균의 20% 초과 시 데이터 재분할 |
| 운영/위험 | 배포 후 오류 원인 추적 | PSI·KS 기반 드리프트와 일반화 오차 분리 | PSI 0.2 초과 시 재학습 후보 |

> 요약: 모델 선택은 훈련 점수가 아니라 검증 Gap, 교차검증 편차, 드리프트 지표를 함께 사용함.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 과적합 | 파라미터 과다, 잡음 학습 | L2 λ=0.001~0.1, Dropout 0.2~0.5, Early Stopping | Train-Test Gap 10%p 이하 |
| 과소적합 | 특징 부족, 모델 용량 부족 | 특징 추가, 트리 깊이 3->10 탐색, 은닉 유닛 확대 | 훈련·검증 오차 동시 감소 |
| 데이터 누수 | 전처리·스케일링을 전체 데이터에 적용 | Pipeline 분리, 시간순 Split, Feature Store 권한 분리 | 누수 점검 0건, CV 재현성 |

> 요약: 과적합은 규제, 과소적합은 용량 확대, 데이터 누수는 분리 검증으로 통제함.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 일반화 | Train-Test Gap 10%p 이하, CV 표준편차 20% 이하 | K-Fold CV, Hold-out 테스트 |
| 품질/정확도 | F1·AUC·RMSE 목표값 충족 | 검증 데이터, 블라인드 테스트 |
| 운영/보안 | PSI 0.2 이하, 모델 버전·데이터셋 해시 기록 | MLOps 대시보드, 감사로그 |

> 요약: 도입 후 성공 여부는 Gap, 검증 지표, 드리프트 지표, 재현성 로그로 판단함.

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 데이터 분리: Train/Validation/Test 70/15/15 또는 5-Fold CV 적용, 검증 평균과 표준편차 동시 보고
2. 규제 적용: L2 λ=0.001~0.1 탐색, Dropout 0.2~0.5, 트리 max_depth 3~10 범위 튜닝
3. 모니터링: 배포 후 월 1회 데이터 드리프트 PSI 0.2 초과 시 재학습 후보 등록

**결론 (2줄):**
- 기술사 판단: 훈련·검증 오차가 모두 크면 모델 용량 확대, Gap이 크면 규제·데이터 확대를 선택함
- 향후 방향: AutoML·MLOps는 교차검증, 드리프트 감지, 재학습 승인을 파이프라인으로 관리함
