## Ⅰ. 개요
- 정의: 모델의 복잡도와 오차 사이의 역관계를 이해하여 최적 지점을 찾는 원리임
- 배경: 학습 데이터에는 완벽하나 실제 데이터에서 성능이 급락하는 현상 해결 필요
- 출제 의도:
| 구분 | 내용 |
| --- | --- |
| 핵심 | 과적합(Overfitting), 편향(Bias), 분산(Variance) |

## Ⅱ. 구성요소
- ASCII 구조도
  Error ^  / \ (Total Error)
        | /   \   _
        |/     \_/ (Min point)
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 편향(Bias) | 실제값과 예측값 평균 사이의 차이 | 과녁 중심 |
| 분산(Variance) | 다양한 학습 데이터에 대한 예측 변동성 | 탄착군 형성 |
| 과적합 | 복잡도가 너무 높아 노이즈까지 학습함 | 암기식 공부 |
> 요약: 낮은 편향과 낮은 분산을 동시에 달성하기는 어려움(Trade-off)

## Ⅲ. 절차
- ASCII 흐름도
  [모델복잡도] -> [오차측정] -> [곡선분석] -> [지점도출]
- 4단계 설명
1. 모델 설정: 간단한 모델부터 복잡한 모델까지 구성함
2. 오차 측정: 학습 오차와 검증 오차를 각각 기록함
3. 곡선 분석: 검증 오차가 다시 증가하기 시작하는 지점 포착함
4. 지점 도출: 학습 오차와 검증 오차의 차이가 최소인 지점 선택함
> 요약: 모델 복잡도를 조절하여 일반화 오차를 최소화함

## Ⅳ. 문제점
- 데이터가 부족한 경우 높은 편향이 발생하기 쉬움
- 특징(Feature)이 너무 많으면 고분산으로 인한 과적합 발생함

## Ⅴ. 개선방안
- (단기) 더 많은 데이터를 확보하거나 특징 선택(Selection) 수행함
- (중기) 정규화(L1, L2) 또는 조기 종료(Early Stopping) 적용함
- (장기) 앙상블 기법을 활용하여 편향과 분산을 동시 제어함

## Ⅵ. 전망
- 초거대 모델 시대의 Double Descent(이중 하강) 현상 분석을 통한 모델 규모 최적화 연구로 확장됨
- 앙상블 모델의 지식 증류(Distillation) 시 편향-분산 제어를 통한 경량 모델 일반화가 핵심 CSF임
- AI 모델의 신뢰성 및 강건성 평가를 위한 정량적 오차 분해 프레임워크 도입이 가속화될 것임
