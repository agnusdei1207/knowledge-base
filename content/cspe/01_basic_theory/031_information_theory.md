## 미리 알고가기

- 엔트로피($Entropy$): 정보원으로부터 발생하는 평균 정보량이며, 데이터 압축이 가능한 이론적 하한을 의미함
- 채널 용량($Channel$ $Capacity$): 특정 채널을 통해 오류 없이 전송할 수 있는 정보의 최대 전송률임
- 섀넌의 정리($Shannon's$ $Theorem$): 잡음이 있는 채널에서도 적절한 부호화를 통해 채널 용량 이내라면 무오류 전송이 가능함을 증명한 정리임
- 상호정보량($Mutual$ $Information$): 수신된 정보를 통해 송신된 정보에 대해 알 수 있는 정보의 양임

## Ⅰ. 개요

- **정의/개념**: 정보이론은 정보의 발생, 전달, 저장 과정을 확률론적으로 정량화하여 데이터의 압축 한계(소스 부호화)와 전송 한계(채널 부호화)를 제시하는 수학적 이론임
- **배경/필요성**: 한정된 주파수 대역폭과 전력 자원 하에서, 잡음과 간섭이 존재하는 실제 통신 환경의 기술적 성능 한계를 정의하고 이를 극복하기 위한 최적의 부호화 설계를 위해 도입됨

## Ⅱ. 특징

- 정보의 의미론적 가치가 아닌, 발생 확률의 불확실성을 수치화한 '자기 정보량($-\log P(x)$)'을 기초로 하여 객관적이고 정밀한 시스템 설계가 가능함
- 잡음이 있는 채널($AWGN$)에서도 신호 전력($S$)과 잡음 전력($N$), 대역폭($W$) 사이의 관계식($C = W \log_2(1+S/N)$)을 통해 달성 가능한 최대 전송 속도를 명확히 제시함
- 이론적 한계값인 '섀넌 한계'를 기준으로 실제 구현된 시스템의 효율성을 정량적으로 비교 평가할 수 있는 벤치마크 지표를 제공함

## Ⅲ. 종류 및 비교

| 판단 기준 | 소스 부호화 (Source Coding) | 채널 부호화 (Channel Coding) |
|:---|:---|:---|
| **핵심 목표** | 데이터 압축 (중복 제거) | 신뢰성 확보 (오류 정정) |
| **이론적 기준** | 엔트로피 ($Entropy$) | 채널 용량 ($Capacity$) |
| **처리 방식** | 빈도가 높은 데이터에 짧은 부호 할당 | 검사 비트 추가로 중복성 부여 |
| **대표 기술** | Huffman, Run-Length, JPEG | LDPC, Polar, Turbo Code |
| **주요 활용** | 파일 압축, 멀티미디어 스트리밍 | 무선 통신(5G), 위성, 저장장치 |

> 요약: 소스 부호화는 정보를 최소화하고, 채널 부호화는 의도적 중복을 통해 정보의 정확성을 지킴.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 정보원 ($Source$) | 메시지를 생성하는 확률 모델이며, 기호별 발생 확률의 분포에 따라 엔트로피가 결정됨 |
| 소스 부호기 | 원본 메시지에서 불필요한 중복을 제거하여 최소한의 비트로 표현하는 압축 장치임 |
| 채널 부호기 | 전송 중 발생하는 잡음에 대비하여 오류를 검출/정정할 수 있는 여분의 비트를 추가함 |
| 통신 채널 | 신호가 전달되는 물리적 매체로, 대역폭과 신호대 잡음비($SNR$)에 의해 용량이 제한됨 |

```text
[ 섀넌-하틀리 정리 모델 ]
C = W * log2(1 + S/N)
- C: 채널 용량 (bps)
- W: 대역폭 (Hz)
- S/N: 신호대 잡음비 (SNR)
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 확률 분포 분석| --> | 정보 엔트로피 산출| --> | 채널 용량 계산| --> | 최적 부호 설계|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **모델링** — 송신할 기호들의 발생 확률과 채널의 잡음 특성($SNR$, 대역폭)을 사전에 정의하고 확률 밀도 함수를 도출함
2. **정보량 산출** — 기호당 평균 정보량인 엔트로피를 계산하여 데이터 압축이 가능한 최저 비트 수를 파악함
3. **용량 분석** — 섀넌-하틀리 정리를 적용하여 해당 채널 환경에서 물리적으로 가능한 최대 전송률 상한선을 도출함
4. **부호 적용** — 산출된 한계값 이내에서 전송 효율을 극대화할 수 있는 소스/채널 부호화 기법을 선택하고 시스템에 구현함

## Ⅵ. 실무 적용 및 유의점

1. 무선 통신(5G/6G) 시스템 설계 시, 주파수 대역폭을 늘리거나 전력을 높여 $SNR$을 개선함으로써 채널 용량을 확장할 수 있지만, 물리적 자원의 한계가 있으므로 $LDPC$나 $Polar$ 부호와 같은 최신 부호화 기법을 통해 섀넌 한계에 근접한 전송 효율을 달성해야 함
2. 실시간 멀티미디어 서비스에서는 엔트로피 기반의 고압축 소스 부호화를 통해 데이터량을 줄여야 하지만, 압축률이 높아질수록 채널 오류에 의한 품질 저하가 심각해지므로 적응형 변복조($AMC$)와 오류 정정($FEC$) 기술을 결합하여 서비스 가용성을 확보해야 함

## Ⅶ. 결론

- 정보이론은 디지털 문명을 지탱하는 전송과 압축 기술의 이론적 등대이며, 설계자는 섀넌이 제시한 극한의 물리적 한계를 명확히 이해하고 하드웨어 자원의 효율성과 전송의 신뢰성 사이의 최적 균형점을 도출해야 함
