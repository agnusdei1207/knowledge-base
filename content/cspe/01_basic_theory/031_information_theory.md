# 031. 정보이론 (Information Theory)

## Ⅰ. Overview

정보이론($Information$ $Theory$)은 정보의 정량화, 압축, 전송 및 저장을 다루는 수학적 기초 이론임. $1948$년 클로드 섀넌($Claude$ $Shannon$)에 의해 정립되었으며, 현대 디지털 통신의 물리적 한계를 규정함.

### 가. 핵심 개념 정의
1.  **엔트로피 ($Entropy$, $H$):** 정보원($Source$)이 발생하는 평균 정보량 또는 불확실성의 척도임. $H(X) = -\sum P(x) \log_2 P(x)$로 정의됨.
2.  **채널 용량 ($Channel$ $Capacity$, $C$):** 잡음이 존재하는 통신 채널을 통해 오류 없이 전송 가능한 최대 정보 전송률($bps$)임.
3.  **섀넌 한계 ($Shannon$ $Limit$):** 특정 대역폭과 신호 대 잡음비($SNR$) 환경에서 이론적으로 도달 가능한 극한의 전송 효율임.

## Ⅱ. Features

### 가. 엔트로피와 채널 용량의 비교

| 항목 | 엔트로피 ($Entropy$) | 채널 용량 ($Channel$ $Capacity$) |
| :--- | :--- | :--- |
| **관점** | 소스($Source$) 측면 | 채널($Channel$) 측면 |
| **핵심 정리** | 섀넌의 제$1$정리 (소스 코딩 정리) | 섀넌의 제$2$정리 (채널 코딩 정리) |
| **물리적 의미** | 데이터 압축의 하한선 ($Floor$) | 데이터 전송 속도의 상한선 ($Ceiling$) |
| **최적화 목표** | 중복성($Redundancy$) 제거 (효율성) | 중복성($Redundancy$) 추가 (신뢰성) |
| **결정 요인** | 심볼 발생 확률 분포 | 대역폭($W$), 신호 전력($S$), 잡음 전력($N$) |

### 나. 정보량의 수학적 특성
- 발생 확률 $P(x)$가 낮을수록 정보량 $I(x)$는 증가함 (반비례 관계).
- 모든 사건의 확률이 균등할 때 엔트로피 $H(X)$는 최댓값을 가짐.

## Ⅲ. Architecture Insight

### 가. 통신 시스템의 논리적 계층 구조
정보이론은 소스 코딩과 채널 코딩을 분리하여 설계해도 최적의 성능을 낼 수 있다는 '분리 정리($Separation$ $Theorem$)'에 기반함.

1.  **Source Encoder:** 엔트로피 한계까지 중복을 제거하여 데이터를 압축함 ($Huffman$, $Arithmetic$ $Coding$).
2.  **Channel Encoder:** 채널 용량 범위 내에서 오류 정정을 위해 의도적 중복을 추가함 ($LDPC$, $Turbo$ $Code$, $Polar$ $Code$).
3.  **Modulator:** 디지털 비트를 물리적 신호로 변환하여 대역폭 효율을 극대화함.

### 나. Shannon-Hartley 정리의 응용
$$C = W \log_2 (1 + \frac{S}{N})$$
- $W$ (Bandwidth)를 늘리면 $C$는 선형적으로 증가하지만, 잡음 전력($N=N_0 W$)도 함께 증가하여 로그함수적 수렴 한계에 부딪힘.
- 전송 전력($S$)을 높이면 $SNR$이 개선되나, 인접 채널 간섭($Co$-channel $Interference$)을 유발함.

## Ⅳ. PPA & Trade-offs

### 가. PPA (Power, Performance, Area) 관점 분석
- **Power:** 높은 $SNR$을 유지하기 위한 송신 전력 소모와 복잡한 오류 정정 알고리즘($LDPC$ 등) 수행을 위한 연산 전력 간의 균형이 필요함.
- **Performance:** 섀넌 한계에 근접할수록 비트 오류율($BER$)은 낮아지지만, 복호화 지연($Latency$)이 증가하는 $Trade$-off가 발생함.
- **Area:** 강력한 알고리즘 구현을 위해 모뎀 $IP$의 로직 게이트 수와 메모리 점유 면적이 증가함.

### 나. 주요 Trade-off
- **Bandwidth vs SNR:** 동일한 채널 용량 $C$를 달성하기 위해 대역폭을 넓히고 전력을 낮추거나, 대역폭을 좁히고 전력을 높이는 설계 선택이 가능함.
- **Complexity vs Capacity:** 섀넌 한계의 $99\%$에 도달하기 위해서는 기하급수적인 연산 복잡도 상승을 감수해야 함.

## Ⅴ. Real-world Troubleshooting

### 가. 비트 오류율 (BER) 급증 현상
- **현상:** 전송 속도가 채널 용량 $C$를 초과하는 순간, 오류율이 통제 불능 상태로 급증함 ($Waterfall$ 현상).
- **해결:** 적응형 변조 및 부호화($AMC$, $Adaptive$ $Modulation$ $and$ $Coding$)를 통해 실시간 채널 상황에 맞춰 전송 속도를 $C$ 이하로 조절함.

### 나. 압축 효율 저하 (Entropy Mismatch)
- **현상:** 데이터의 실제 확률 분포가 인코더가 가정하는 분포와 다를 때 압축률이 급격히 하락함.
- **해결:** 고정된 사전을 사용하는 방식 대신 데이터 스트림을 실시간 학습하는 적응형($Adaptive$) 압축 기법을 적용함.

## Ⅵ. Professional Insight

정보이론은 단순한 수학적 유희를 넘어 디지털 문명의 설계 도면 역할을 수행함. 기술사는 시스템 설계 시 섀넌 한계라는 '물리적 마지노선'을 정확히 인식하고, 주어진 자원(대역폭, 전력, 시간) 하에서 최적의 소스/채널 코딩 조합을 도출해야 함.

특히 $5G/6G$ 이동통신에서는 섀넌 한계에 극도로 근접한 $LDPC$와 $Polar$ $Code$를 채택하고 있으며, 이제는 하드웨어 연산 능력($PPA$)과의 타협점이 핵심 경쟁력이 되고 있음. 향후 양자 정보이론과 결합하여 고전적 한계를 극복하려는 시도에 주목할 필요가 있음.
