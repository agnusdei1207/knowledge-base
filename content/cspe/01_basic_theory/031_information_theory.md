## 미리 알고가기

- 엔트로피 $H(X)$: 정보원의 평균 불확실성 크기임
- 상호정보량 $I(X;Y)$: 입력과 출력이 공유하는 정보량임
- 채널 용량 $C$: 오류를 허용 범위 내로 유지하며 보낼 수 있는 최대 정보율임

## Ⅰ. 개요

- **정의/개념**: 정보이론은 정보의 불확실성, 압축 한계, 전송 한계를 확률 기반으로 정량화하는 이론으로, 엔트로피와 채널 용량이 핵심 축임
- **배경/필요성**: 저장 공간과 통신 대역폭은 제한되어 있으므로, 얼마까지 압축 가능하고 어떤 속도까지 신뢰성 있게 전송 가능한지 계산 기준이 필요함

## Ⅱ. 특징

- 정보량을 확률 분포로 정의해 직관이 아닌 수치로 비교 가능함
- 소스 부호화와 채널 부호화의 이론적 하한과 상한을 제시함
- 잡음 채널에서도 오류율과 전송률의 trade-off를 계산할 수 있음
- 확률 모델이 부정확하면 이론값과 실제 성능 차이가 커질 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | 엔트로피 | 채널 용량 | 섀넌 한계 |
|:---|:---|:---|:---|
| 의미 | 압축 가능 하한 | 신뢰 전송 가능 상한 | 이론적 극한 |
| 대상 | 정보원 | 통신 채널 | 시스템 전체 |
| 핵심 질문 | 얼마나 줄일 수 있는가 | 얼마나 보낼 수 있는가 | 어디까지 가능한가 |
| 대표 적용 | 코덱, 압축 | 링크 설계 | 변복조, 코딩 설계 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 정보원 | 기호와 발생 확률을 가짐 엔트로피 계산의 출발점임 |
| 부호기 | 기호를 비트열로 매핑하고 압축 효율을 좌우함 |
| 채널 | 잡음과 왜곡이 존재하는 전달 경로이며 신뢰도 한계를 결정함 |
| 복호기 | 수신 정보를 복원하고 오류 정정 성능이 중요함 |

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 정보원      | --> | 부호기      | --> | 채널        | --> | 복호기      |
+-----------+     +-----------+     +-----------+     +-----------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 확률모델 | --> | 정보량계산 | --> | 부호설계 | --> | 한계검증 |
+----------+     +----------+     +----------+     +----------+
```

1. **확률모델**: 기호 분포와 채널 특성을 정의함
2. **정보량계산**: $H(X)$, $I(X;Y)$, $C$를 산출함
3. **부호설계**: 압축 또는 오류 정정 코드를 설계함
4. **한계검증**: 실제 비트율과 오류율이 이론 범위 안인지 확인함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 확률 분포 추정이 틀릴 수 있어 실제 트래픽과 모델이 다르면 성능 예측이 어긋남
   - 해결방안: 적응형 모델과 실측 데이터로 재추정하고 KL divergence로 검증함
2. 문제: 이론 한계를 실제 시스템이 곧바로 달성하지 못해 계산량과 지연 제약이 큼
   - 해결방안: LDPC, Turbo, Polar 같은 근사 최적 코드를 사용하고 gap to capacity로 검증함
3. 문제: 채널 환경이 시간에 따라 변해 고정 코딩률은 비효율적일 수 있음
   - 해결방안: AMC와 HARQ를 적용하고 throughput, BLER로 검증함

## Ⅶ. 적용 사례

- 무선통신 설계에서는 SNR 기준으로 코딩률과 변조 방식을 결정함, 확인 지표는 spectral efficiency임
- 데이터 압축에서는 엔트로피를 기준으로 코드 길이를 최적화함, 확인 지표는 압축률과 복원 정확도임
- 저장장치 ECC에서는 채널 특성에 맞는 정정 강도를 선택함, 확인 지표는 UBER임

## Ⅷ. 결론

정보이론의 핵심은 시스템 성능을 감으로 정하지 않고 한계로 설계하는 데 있으므로, 압축과 전송은 항상 엔트로피와 채널 용량의 범위 안에서 판단해야 함.
