## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 정보의 양을 엔트로피로 정량화하고, 채널 용량(Shannon Limit)으로 오류 없는 최대 전송률을 이론적으로 규정하는 수학적 체계임 |
| **배경/필요성** | 데이터 압축·통신 채널 설계·암호학의 이론적 하한과 상한을 정의하는 기반이 필요함 |
| **출제 의도** | 엔트로피·채널 용량의 수학적 의미와 소스/채널 코딩 정리를 이해하는지 평가함 |

## Ⅱ. 구성요소
```
+----------+     +----------+     +----------+
| 엔트로피  | --> | 상호정보  | --> | 채널용량  |
| H(X)     |     | I(X;Y)   |     | C        |
+----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| 엔트로피 H(X) | 확률 변수 X의 불확실성(정보량)을 비트 단위로 측정함: H(X) = -Σp(x)log₂p(x) | 주사위 결과의 예측 불확실성 |
| 상호 정보 I(X;Y) | 채널 출력 Y를 관찰하여 입력 X에 대해 얻는 정보량임 | 단서로 범인을 좁히는 정보 |
| 채널 용량 C | 상호 정보의 최대값으로, 오류 없이 전송 가능한 최대 비트율임: C = B·log₂(1+SNR) | 도로의 최대 차량 처리량 |

> 요약: 엔트로피(정보량) → 상호 정보(전달량) → 채널 용량(최대 전송률)으로 정보의 한계를 정의함.

## Ⅲ. 절차
```
+------------+     +------------+
| 소스분석   | --> | 엔트로피   |
| 확률분포   |     | H(X) 계산  |
+------------+     +------------+
                        |
+------------+     +----+-------+
| 코딩설계   | <-- | 채널용량  |
| (소스/채널)|     | C 계산    |
+------------+     +------------+
```

1. 소스 분석: 데이터 소스의 심볼별 출현 확률을 분석함
2. 엔트로피 계산: H(X) = -Σp(x)log₂p(x)로 소스의 평균 정보량을 산출함
3. 채널 용량 계산: C = B·log₂(1+SNR)으로 채널의 이론적 최대 전송률을 산출함
4. 코딩 설계: 소스 코딩(압축)은 엔트로피에, 채널 코딩(오류 정정)은 채널 용량에 접근하도록 설계함

> 요약: 소스 분석 → 엔트로피 → 채널 용량 → 코딩 설계로 정보 전송을 최적화함.

## Ⅳ. 문제점
- 이론적 한계: 섀넌 한계는 이론적 상한이며, 실제 코드가 도달하기 어려움
- 무한 블록 가정: 섀넌 정리는 블록 길이 무한대를 가정하여 실제 유한 블록에서 성능이 저하됨
- 채널 모델 가정: 이상적 AWGN 채널 가정이 실제 페이딩·간섭 환경과 다름

## Ⅴ. 개선방안
- (단기) 실용적 코드: Turbo·LDPC 코드가 섀넌 한계의 0.1dB 이내까지 접근함
- (중기) Polar 코드: 유한 블록에서도 채널 용량을 달성하는 것이 이론적으로 증명된 코드를 적용함
- (장기) 의미적 통신: 비트 전달을 넘어 의미(Semantic)를 전달하는 차세대 정보 이론을 연구함

## Ⅵ. 전망
- 5G에서 LDPC·Polar 코드가 채널 코딩 표준으로 채택되었으며, 6G에서는 의미적 통신(Semantic Communication)이 섀넌 이론을 확장하는 차세대 패러다임으로 연구되고 있음
