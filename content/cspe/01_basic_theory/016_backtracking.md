## Ⅰ. 개요
- **정의**: 해 탐색 트리를 DFS로 순회하며 유망하지 않은 부분 트리를 가지치기하는 탐색 기법
- **배경/필요성**: 모든 경우의 수를 완전 탐색하면 지수적 시간이 소요되므로, 조기에 불가능한 경로를 배제하여 탐색 공간을 축소할 필요가 있음
- **비유**: 미로에서 막다른 길에 도달하면 되돌아가 다른 갈림길을 시도하는 것과 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| DFS 기반 탐색과 가지치기 원리 이해 | 유망 함수(promising)와 상태 공간 트리 개념 | 단순 DFS(010 참조)와 혼동하지 말 것 — 제약조건 검사가 핵심 차이 |

> 요약: 상태 공간 트리에서 제약조건 위반 노드를 조기 배제하여 탐색 효율을 높이는 기법임

## Ⅱ. 구성요소
```text
        State Space Tree
              |
   +----------+----------+
   |          |          |
  Node      Node      Node
  (상태)    (상태)    (상태)
   |          |          |
  promising? promising? promising?
   |          X(가지치기) |
   v                     v
  Child                Child
  Nodes                Nodes
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 상태 공간 트리 | 가능한 모든 선택 경로를 트리로 표현한 구조 | 갈림길이 있는 미로 전체 지도 |
| 유망 함수 | 현재 노드가 해로 이어질 가능성이 있는지 판별하는 조건 검사 | 막다른 길 표지판 확인 |
| 가지치기(Pruning) | 유망하지 않은 노드의 하위 트리 탐색을 중단하는 동작 | 막힌 통로를 건너뜀 |
| 해(Solution) | 모든 제약조건을 만족하는 리프 노드 또는 경로 | 미로 출구 도달 |

> 요약: 상태 공간 트리·유망 함수·가지치기·해의 네 요소가 결합하여 탐색 범위를 축소함

## Ⅲ. 절차
```text
  초기 상태       확장            검증            판정
  (루트 생성)    (자식 생성)    (유망성 검사)   (해/백트랙)
    |              |              |              |
    +---DFS 진입-->+---노드 선택-->+---제약 확인-->+
  빈 트리       다음 선택지     유망 함수 호출  해 발견 or 되돌아감
```
- 1단계: 루트 노드에서 탐색을 시작하고, 깊이 우선 순서로 첫 번째 자식 노드를 선택함
- 2단계: 선택한 노드에 대해 유망 함수를 호출하여 제약조건 위반 여부를 검사함
- 3단계: 유망하지 않으면 해당 부분 트리를 가지치기하고 부모 노드로 되돌아감(백트랙)
- 4단계: 유망하면 다음 깊이로 확장하며, 리프 노드에서 모든 조건을 만족하면 해로 기록함

> 요약: DFS 진입 → 자식 확장 → 유망성 검증 → 해 기록 또는 백트랙의 순환 구조로 동작함

## Ⅳ. 문제점
- 최악 시간 복잡도: 가지치기 효과가 낮은 입력에서 완전 탐색과 동일한 지수적 시간이 소요됨
- 유망 함수 설계 난이도: 제약조건이 복잡할수록 정확하고 빠른 유망 함수 구현이 어려움
- 메모리 사용량: 재귀 호출 깊이가 깊어지면 스택 오버플로 위험이 증가함

> 요약: 최악 시간 복잡도·유망 함수 설계 난이도·깊은 재귀에 의한 메모리 부담이 주요 한계임

## Ⅴ. 개선방안
1. 단기: 제약 전파(Constraint Propagation) 기법으로 탐색 전 변수 도메인을 사전 축소하여 가지치기 효과를 높임
2. 중기: 분기 한정법(Branch and Bound)으로 한계값(bound)을 추가하여 최적화 문제에서 탐색 범위를 추가 축소함
3. 장기: 병렬 탐색 구조를 적용하여 독립적 부분 트리를 다중 스레드로 분할 처리함

> 요약: 제약 전파·분기 한정·병렬 탐색으로 가지치기 효과와 탐색 속도를 단계적으로 향상함

## Ⅵ. 전망
- 발전 방향: SAT 솔버·CSP 솔버 내부에서 학습 기반 가지치기와 결합하여 대규모 탐색 문제에 적용 확대
- 기술사적 판단: N-Queen·스도쿠 등 제약 충족 문제의 기본 풀이 전략으로서 알고리즘 설계 역량 평가에 지속 출제 가능
- 기술사 제언: 단순 DFS(010 참조)와의 차이, 분기 한정법과의 비교를 명확히 구분하여 답안을 구성할 필요
