# 📖 【암기용】 개념 완전 이해

## 한눈에
- **정의**: 모든 가능한 해를 탐색하는 완전 탐색(Brute-force)의 일종이나, 탐색 과정에서 **해결책이 될 가망이 없는 경로를 미리 차단(Pruning)**하여 효율을 높이는 기법.
- **핵심 메커니즘**:
  - **DFS (깊이 우선 탐색)**: 상태 공간 트리(State-Space Tree)를 바닥까지 탐색.
  - **유망성 (Promising)**: 현재 노드에서 정답을 찾을 수 있는지 판별.
  - **가지치기 (Pruning)**: 유망하지 않은 노드 아래의 서브트리는 아예 탐색하지 않고 되돌아옴(Backtrack).
- **핵심 직관**: "가다가 길이 막히면(오답이면), 끝까지 가지 말고 즉시 유턴해서 다른 길로 간다."

## 핵심 용어 정리

| 용어 | 의미 | 비유/예시 |
|:---|:---|:---|
| **상태 공간 트리** | 모든 선택 가능한 후보들을 노드로 표현한 트리 | 의사결정의 지도 |
| **유망성 검사** | 현재 경로가 해가 될 가능성이 있는지 검사 | 싹수가 노란지 확인하기 |
| **가지치기 (Pruning)** | 가능성 없는 경로를 통째로 잘라냄 | 죽은 나뭇가지 쳐내기 |
| **백트랙 (Backtrack)** | 현재 경로를 포기하고 직전의 분기점으로 복귀 | "이 길이 아닌가벼" 하고 되돌아가기 |
| **제약 충족 문제 (CSP)** | 정해진 제약 조건을 모두 만족하는 해를 찾는 문제 | 스도쿠, N-Queen, 시간표 짜기 |

## 깊이 이해

- **완전 탐색과의 차이**: 
  단순 완전 탐색은 지수 시간($O(2^n)$) 혹은 계승 시간($O(n!)$)이 걸려 금방 터져버립니다. 백트래킹은 "어? 이미 첫 번째 칸에 퀸을 놨는데 두 번째 칸에 퀸을 놓으면 대각선 공격이네? 그럼 그 아래는 볼 필요도 없지!" 하고 쳐냄으로써 **실제 탐색 범위**를 드라마틱하게 줄입니다.

- **N-Queen 문제**: 
  $N \times N$ 체스판에 $N$개의 퀸을 서로 공격하지 못하게 배치하는 문제. 백트래킹의 가장 상징적인 예제입니다. 각 행마다 퀸을 놓으며, '같은 열'이나 '대각선'에 퀸이 있는지 유망성을 검사합니다.

- **스도쿠(Sudoku)**: 
  숫자를 채우다가 규칙(가로, 세로, 3x3 박스)에 어긋나면 즉시 이전 빈칸으로 돌아가 다른 숫자를 시도합니다. 이것이 전형적인 백트래킹의 동작 방식입니다.

- **DFS와의 관계**: 
  백트래킹은 DFS의 '응용'입니다. DFS는 모든 노드를 방문하는 것이 목적이라면, 백트래킹은 **해를 찾기 위해 불필요한 노드를 안 가는 것**이 목적입니다.

- **일상 비유 (미로 찾기)**: 
  미로를 헤매다가 벽이 나오면 그 벽 뒤에 길이 있을까 고민하며 벽을 뚫으려 하지 않고, 바로 직전 갈림길로 돌아가서 다른 길을 찾는 것과 같습니다.

# 📝 【답안용】 시험 답안 템플릿

## 핵심 인사이트 (3줄 요약)
> 1. **본질**: 상태 공간 트리를 DFS로 탐색하며, **유망성(Promising)** 검사를 통해 비효율적인 경로를 **가지치기(Pruning)**하는 지능적 전수 탐색 기법임.
> 2. **가치**: 지수적으로 폭발하는 탐색 공간($O(2^n), O(n!)$)을 실질적으로 제어하여, 현실적인 시간 내에 제약 충족 문제(CSP)의 해를 구함.
> 3. **전략**: 해가 될 가능성이 없는 경로를 조기에 차단하는 **Bounding Function** 설계 능력이 알고리즘 성능의 핵심임.

## Ⅰ. 지능형 가지치기의 전략, 백트래킹(Backtracking)의 개요
### 1. 정의
- 해를 찾아가는 도중 막히면(제약 조건 위반 시) 다시 돌아가서 다른 경로를 탐색하는 알고리즘 설계 패러다임.
### 2. 핵심 철학: 유망성과 가지치기
- **유망성 (Promising)**: 현재 노드를 포함한 경로가 해가 될 가능성이 있는지 판별.
- **가지치기 (Pruning)**: 유망하지 않은 노드를 방문하지 않고 부모 노드로 되돌아감.

## Ⅱ. 백트래킹의 동작 프로세스 및 도식화
### 1. 탐색 단계
- **[Step 1]** 상태 공간 트리를 DFS 방식으로 깊이 탐색.
- **[Step 2]** 각 노드에서 유망성(Promising) 함수 호출.
- **[Step 3]** 유망하면 자식 노드로 진행, 유망하지 않으면 부모 노드로 백트랙(Backtrack).
- **[Step 4]** 해를 찾거나 모든 공간을 탐색할 때까지 반복.

### 2. 상태 공간 트리 예시 (N-Queen)
```
          [Root]
        /   |    \
     (1,1) (1,2)  (1,3) ... (1,행 선택)
      /      X (가지치기: 열/대각선 충돌)
   (2,3)
    /
 (3,5) -> Success!
```

## Ⅲ. 백트래킹 vs 분기 한정 (Branch & Bound) 비교
| 구분 | 백트래킹 (Backtracking) | 분기 한정 (Branch & Bound) |
|:---:|:---|:---|
| **기반 탐색** | **DFS (깊이 우선)** | **BFS (너비 우선) / 최선 우선** |
| **가지치기 기준** | 제약 조건 만족 여부 (유망성) | **한계치(Bound)**와의 비교 (최적성) |
| **메모리 소모** | 상대적으로 적음 (재귀 스택) | 많음 (큐/우선순위 큐에 노드 저장) |
| **주 목적** | **모든 해** 또는 **첫 번째 해** 탐색 | **최적해(Min/Max)** 탐색 |
| **응용 사례** | N-Queen, 스도쿠 | 외판원 문제(TSP), 배낭 문제 |

## Ⅳ. 백트래킹의 대표적 응용 분야
### 1. 제약 충족 문제 (Constraint Satisfaction Problem)
- 스케줄링, 인력 배치, 지도 색칠(Graph Coloring) 문제.
### 2. 퍼즐 및 게임 AI
- 미로 찾기, 체스, 오목 등의 다음 수 탐색 및 유망성 분석.
### 3. 정규 표현식 매칭
- 복잡한 패턴 매칭 시 백트래킹을 통해 최적의 매칭 경로 탐색.

## Ⅴ. 기술사 관점의 성능 최적화 전략
### 1. 효율적인 Bounding Function 설계
- 유망성 검사가 너무 복잡하면 탐색보다 검사 비용이 커짐. **최소한의 연산**으로 가망 없는 가지를 쳐낼 수 있는 로직이 필수.
### 2. 탐색 순서의 최적화 (Variable Ordering)
- 제약 조건이 가장 까다로운 변수(노드)를 먼저 탐색하면, 초기 단계에서 대규모 가지치기가 발생하여 성능이 획기적으로 개선됨.
### 3. 대칭성 제거 (Symmetry Breaking)
- 회전이나 대칭 시 동일한 결과가 나오는 경우들을 미리 배제하여 중복 탐색 방지.

## Ⅵ. 기술사 관점의 결론: "실패를 빨리 인정하는 것이 속도다"
- 백트래킹은 불가능한 미래를 조기에 포기함으로써 **탐색 효율의 극대화**를 실현하는 실용적 알고리즘임.
- 아키텍트는 비즈니스 로직의 제약 조건이 복잡해질수록 이를 정교한 **유망성 함수**로 치환하여, 시스템의 응답성과 정확도를 동시에 확보해야 함.
