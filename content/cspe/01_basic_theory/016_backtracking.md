# 📖 【암기용】 개념 완전 이해

## 한눈에
- **개요**: 백트래킹은 **알고리즘 설계 기법(013~015 참조)** 중 하나로, 해를 후보들의 순차적 선택으로 만들어 가되(상태공간 트리를 DFS로 내려가되), 현재 부분해가 제약을 위반해 **정답이 될 가망이 없으면 즉시 되돌아가(backtrack)** 다른 선택으로 넘어가는 완전탐색 최적화 기법이다.
- **왜 필요한가**: 조합·순열 문제를 아무 가지치기 없이 DFS로 전수 조사하면 O(N!)·O(2^N)로 폭발하므로, **가망 없는 부분 트리를 통째로 잘라내(가지치기)** 실제 탐색량을 크게 줄이기 위해서다.
- **핵심 직관**: "**한 걸음 내려가 보고, 막히면 즉시 그 갈래를 접고 되돌아온다**" — 완전탐색의 정확성은 유지하면서 유망성 검사(promising)로 탐색 공간을 쳐낸다.

## 핵심 용어 정리 (내부에 등장하는 것들)

답안용 Ⅰ~Ⅵ·표에 나오는 백트래킹 고유 표기를 비유와 함께 먼저 세운다(DFS 원리는 010, 복잡도 의미는 001·002 참조). 맨 위는 상위 핵심 키워드다.

| 용어/표기 | 의미 | 비유·예 |
|:---|:---|:---|
| 백트래킹 (상위 키워드) | 상태공간 트리를 DFS로 탐색하며 가망 없는 갈래를 되돌아 잘라내는 완전탐색 | 미로에서 막다른 길이면 갈림길로 되돌아옴 |
| 상태공간 트리 (State-Space Tree) | 부분해가 한 단계씩 확장되며 이루는 후보 전체의 트리 | 각 칸에 말을 놓는 모든 경우의 갈래 |
| 부분해 (Partial Solution) | 아직 완성되지 않은, 일부 변수만 정해진 해 | N-Queen에서 3행까지만 놓은 상태 |
| 유망성 검사 (Promising / Bounding) | 현재 부분해가 제약을 지켜 완성 가능성이 있는지 판정 | 이미 같은 열에 퀸이 있으면 가망 없음 |
| 가지치기 (Pruning) | 유망하지 않은 부분 트리를 통째로 탐색 제외 | 막힌 갈래는 그 아래를 아예 안 봄 |
| 백트랙 (Backtrack) | 막힌 선택을 취소하고 이전 분기점으로 복귀 | 놓았던 퀸을 거두고 이전 행으로 |
| 완전탐색 (Brute-Force) | 가지치기 없이 모든 후보를 전수 조사 | 모든 배치를 빠짐없이 다 놓아 봄 |
| 분기한정 (Branch & Bound) | 한계값(bound)으로 최적화 문제 가지를 쳐내는 확장 기법 | 지금까지 최선보다 나쁠 갈래는 버림 |

## 깊이 이해
- **배경·문제의식**: N-Queen·부분집합합·미로처럼 **후보를 하나씩 선택해 조합하는 문제**는 후보 수가 지수·계승으로 폭증한다. 단순 DFS 전수 조사는 정확하나 느리다. 백트래킹은 "부분해가 이미 제약을 어겼다면 그 아래를 더 볼 필요가 없다"는 관찰로 탐색 공간을 실제로 줄인다.
- **작동 원리 (어떻게+왜)**:
  - **상태공간 트리 + DFS**: 해를 단계별 선택의 나열로 보고, 각 단계의 선택지를 자식 노드로 두어 트리를 이룬 뒤 DFS로 깊이 내려간다(010의 DFS를 해 탐색에 적용).
  - **유망성 검사와 가지치기**: 노드마다 "이 부분해로 완성 가능한가"를 검사해, 불가능하면 그 서브트리 전체를 건너뛴다. 이 한 번의 컷이 지수 개의 후보를 한꺼번에 제거해 실제 탐색량을 줄인다.
  - **되돌아감(복원)**: 한 선택을 시도(변수 설정)한 뒤 재귀 호출하고, 실패하면 **그 선택을 취소(상태 복원)**하고 다음 선택지로 넘어간다. 이 시도-복원 대칭이 백트래킹의 뼈대다.
  - **왜 최악은 여전히 지수인가**: 가지치기가 평균적으로 강력하지만, 제약이 느슨하면 잘리는 가지가 적어 최악 시간은 여전히 O(N!)·O(2^N)이다. 즉 정확성은 보장하되 성능은 문제 구조에 의존한다.
- **비유**: 미로에서 갈림길마다 한 방향으로 들어가 보고, 막다른 길을 만나면 실을 되감아 갈림길로 돌아와 다른 방향을 택한다. 벽에 막힌 순간 그 안쪽을 더 헤매지 않는 것이 가지치기다.
- **구체 예시(수치·사례)**: 8-Queen은 순진한 배치가 8^8≈1670만 경우지만, "같은 열·대각선 금지"를 부분해마다 검사하면 실제 방문 노드가 수천 수준으로 줄어 해 92개를 빠르게 찾는다. 스도쿠 solver, 부분집합합, 순열·조합 생성, 그래프 색칠, 정규식 백트래킹 엔진이 대표 사례다.
- **흔한 오해·주의점**:
  - **"백트래킹이면 항상 빠르다"는 오해** — 가지치기가 없거나 약하면 완전탐색과 동일한 지수 시간이다. 성능은 유망성 검사의 강도에 달렸다.
  - **DFS와 동일시** — DFS는 순회 방법, 백트래킹은 그 위에 **유망성 검사·상태 복원**을 얹은 해 탐색 전략이다.
  - **분기한정과 혼동** — 백트래킹은 주로 제약충족(feasibility) 가지치기, 분기한정은 최적화 문제에서 한계값(bound)으로 가지를 치는 확장 개념이다.

## 연결 개념
- **깊이 우선 탐색 (010)**: 백트래킹이 상태공간 트리를 내려갈 때 쓰는 순회 골격으로, 여기에 가지치기·복원을 더한 것이 백트래킹임.
- **동적 프로그래밍 (013)**: 둘 다 지수 탐색을 줄이나, DP는 부분 문제 중복을 메모이제이션으로, 백트래킹은 가망 없는 갈래를 가지치기로 줄이는 대비 기법.
- **분기한정·NP-완전 (019·077)**: 최적화 백트래킹에 한계값을 더한 분기한정은 NP-난해 최적화의 실전 정확해 탐색에 쓰임.

# 📝 【답안용】 시험 답안 템플릿

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 백트래킹은 상태공간 트리를 DFS로 탐색하며 가망 없는 부분해를 가지치기로 되돌아 잘라내는 완전탐색 기법임.
> 2. **가치**: N-Queen·스도쿠·조합 최적화 등 지수·계승 탐색 공간을 유망성 검사로 실제 방문량만큼 줄여 정확해를 얻음.
> 3. **판단 포인트**: 최악 시간은 여전히 지수이므로 가지치기 강도가 핵심이며, 최적화 문제는 분기한정, 부분 문제 중복형은 DP로 전환해야 함.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 백트래킹 원리 | 상태공간 트리·유망성 검사·가지치기·복원 | DFS와 동일하다고 단정 |
| 완전탐색 대비 이점 | 지수 후보를 가지치기로 실제 탐색량 축소 | 항상 다항 시간이라고 단정 |
| 응용·한계 인식 | N-Queen·스도쿠 응용과 최악 지수 복잡도 | 가지치기 강도 의존성 누락 |

> 요약: 상태공간 트리 DFS + 유망성 검사·가지치기·복원 4요소와 대표 응용, 최악 지수 복잡도·분기한정 확장을 짚어야 함.

## Ⅰ. 개요 및 필요성
- 개요: 상태공간 트리를 DFS로 탐색하며 가망 없는 부분해를 되돌아 잘라내는 완전탐색 기법임
- 배경: 조합·순열형 문제의 후보가 O(N!)·O(2^N)로 폭증해 순진한 전수 조사는 비현실적임
- 필요성: 부분해 단계마다 유망성을 검사해 지수 개의 무의미한 후보를 한 번에 제거할 필요가 있음
- 차별성: 정확해를 포기하는 근사·난수 기법(017)과 달리 최적·정확해를 보장하되 탐색량만 줄임

## Ⅱ. 구조 및 구성요소
선형 구조도 (상태공간 트리의 시도-복원 반복):

    루트(빈 부분해) -> 다음 변수의 선택지 하나 시도 -> 유망성 검사 -> 유망하면 재귀로 한 단계 깊이 진행 / 유망하지 않으면 가지치기(서브트리 제외) -> 완성이면 해 기록 -> 선택 취소(복원) 후 다음 선택지 반복
      / 유망 : 부분해 확장 -> 더 깊은 노드로 하강
      / 미유망 : 백트랙 -> 이전 분기점으로 복귀

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 상태공간 트리 | 부분해 확장으로 이뤄지는 후보 전체 구조 | 명시적으로 저장 않고 재귀로 암묵 생성 |
| 유망성 검사(bounding) | 부분해의 완성 가능성 판정 | 검사 강도가 성능 좌우 |
| 가지치기(pruning) | 미유망 서브트리 탐색 제외 | 지수 개 후보를 한 번에 제거 |
| 상태 복원(백트랙) | 시도한 선택을 취소하고 복귀 | 시도-복원 대칭이 정확성 보장 |

> 요약: 상태공간 트리를 재귀로 암묵 생성하며 유망성 검사·가지치기·복원 4요소로 정확성 유지하며 탐색량을 줄임.

## Ⅲ. 동작원리 및 흐름도
선형 흐름도 (N-Queen 기준):

    빈 보드에서 시작 -> k번째 행에 퀸 위치 하나 선택 -> 열·대각선 충돌 검사 -> 충돌 없으면 k+1행으로 재귀 / 충돌이면 다음 위치 -> 마지막 행 도달 시 해 기록 -> 퀸 회수 후 다음 위치 시도

1. 확장: 알고리즘이 현재 부분해에 다음 변수(k행 퀸)의 한 선택지를 시도해 부분해를 확장함
2. 검사: 알고리즘이 확장된 부분해가 제약(같은 열·대각선 금지)을 지키는지 유망성을 판정함
3. 분기: 유망하면 다음 단계로 재귀 하강하고, 미유망하면 그 서브트리를 가지치기하고 다음 선택지로 넘어감
4. 복원: 한 선택의 모든 하위 탐색이 끝나면 알고리즘이 그 선택을 취소(퀸 회수)하고 이전 분기점으로 백트랙함

> 요약: 부분해를 한 단계 확장·검사해 유망하면 하강·아니면 가지치기하며, 탐색 종료 후 선택을 복원해 다음 갈래로 되돌아감.

## Ⅳ. 특징
- 정확성 보장: 완전탐색의 일종으로 가지치기가 정답 후보를 배제하지 않아 항상 정확·최적해를 찾음
- 공간 효율: 상태공간 트리를 명시적 저장 없이 재귀 스택으로 암묵 표현해 메모리는 트리 깊이 O(N)급임
- 가지치기 의존 성능: 실제 속도는 유망성 검사 강도에 좌우되며 검사가 약하면 완전탐색과 동일해짐
- 최악 지수 복잡도: 제약이 느슨하면 잘리는 가지가 적어 최악 시간은 여전히 O(N!)·O(2^N)임
- 시도-복원 대칭: 선택 후 재귀, 실패 시 상태 복원이라는 대칭 구조가 구현·정확성의 핵심임

## Ⅴ. 심화 비교 및 적용 판단

정확해 탐색 계열 세 기법을 탐색 방식·가지치기 기준·대상 문제 축에서 대조함(DP와의 대비는 013 참조).

| 구분 | 백트래킹 | 완전탐색(Brute-Force DFS) | 분기한정(Branch & Bound) |
|:---|:---|:---|:---|
| 탐색 방식 | DFS + 유망성 가지치기 | 모든 후보 전수 조사 | BFS/최선우선 + 한계값 가지치기 |
| 가지치기 기준 | 제약 위반(feasibility) | 없음 | 목적값 한계(bound) 초과 |
| 주 대상 | 제약충족·조합 문제 | 소규모 전수 검증 | 최적화(최소·최대) 문제 |
| 최악 복잡도 | 지수(가지치기로 평균 완화) | 지수(항상) | 지수(bound로 평균 완화) |

> 요약: 백트래킹은 제약 위반으로, 분기한정은 목적값 한계로 가지를 치며, 완전탐색은 가지치기가 없어 셋 중 가장 느림.

**리스크·대응:**
- 약한 가지치기 — 검사가 느슨해 지수 폭발 → 문제별 강한 제약(대칭 제거·정렬·도미넌스) 도입
- 깊은 재귀 — 스택 오버플로 위험 → 반복형 변환 또는 명시적 스택 사용
- 최적화 부적합 — 단순 백트래킹은 최적값 컷 부재 → 분기한정으로 한계값 가지치기 추가

**점검 지표:**
- 탐색 효율 — 실제 방문 노드 수 « 전체 후보 수 — 방문 카운터로 가지치기율 측정
- 정확성 — 백트래킹 해 = 소입력 완전탐색 해 — 반례 검증으로 확인

## Ⅵ. 실무 적용 및 결론

**적용 방안:**
1. 제약충족 문제(CSP) 해결: 스도쿠·시간표·지도 색칠에서 도메인 축소·전방 검사(forward checking)로 유망성 검사를 강화해 정확해 산출
2. 조합 최적화 정확해: 배낭·외판원(TSP)의 소·중 규모 인스턴스를 분기한정(019·077 참조)으로 최적값 한계 가지치기하며 정확 최적해 확보
3. 패턴·파싱 엔진: 정규식 백트래킹 매처·구문 분석(074)에서 실패 시 대안 규칙으로 되돌아가며 매칭 경로 탐색

**결론:**
