## 미리 알고가기

- 상태 공간 트리(State Space Tree): 해를 찾기 위해 거치는 모든 선택 경로를 노드와 간선으로 표현한 트리 구조임
- 유망성(Promising): 현재 탐색 중인 경로가 최종 해(Solution)로 연결될 가능성이 있는지 판단하는 성질임
- 가지치기(Pruning): 유망하지 않은 경로를 조기에 차단하여 탐색 범위를 획기적으로 줄이는 최적화 기법임
- 제약 충족 문제(CSP): 여러 제약 조건을 동시에 만족하는 변수의 값들을 찾아내는 문제 유형임

## Ⅰ. 개요

- **정의/개념**: 백트래킹은 모든 가능한 해를 탐색하는 도중 현재 경로가 정답이 될 가능성이 없다고 판단되면, 즉시 탐색을 중단하고 이전 단계로 되돌아가($Back$) 다른 경로를 시도하는 전략적 탐색 기법임
- **배경/필요성**: 순열, 조합, 미로 찾기 등 경우의 수가 지수적으로 증가하는 문제에서 모든 경로를 끝까지 확인하는 완전 탐색은 시간적으로 불가능하므로, 실패가 자명한 영역을 조기에 제거하여 탐색 효율을 극대화해야 함

## Ⅱ. 특징

- 깊이 우선 탐색($DFS$)의 기본 형식을 따르지만, 리프 노드에 도달하기 전이라도 제약 조건을 위반하면 부모 노드로 복귀하여 불필요한 하위 탐색을 차단함
- 유망성 검사($Promising$ $Check$)를 통해 탐색 공간($Search$ $Space$)을 능동적으로 제어하며, 제약 조건이 까다로울수록 가지치기 효율이 높아져 실행 속도가 비약적으로 개선됨
- 모든 경우를 고려해야 하는 지수 시간복잡도($Exponential$ $Time$) 문제에 대해 현실적인 시간 내에 해를 찾을 수 있는 가능성을 제공하는 대표적인 휴리스틱 탐색 기법임

## Ⅲ. 종류 및 비교

| 판단 기준 | 완전 탐색 (Brute-force) | 백트래킹 (Backtracking) | 분기 한정 (Branch & Bound) |
|:---|:---|:---|:---|
| **중단 시점** | 중단 없이 모든 경로 스캔 | 제약 조건 위반 즉시 중단 | 현재 비용이 최적 경계를 넘을 때 |
| **탐색 방식** | 전수 조사 | $DFS$ 기반의 가지치기 | $BFS$/우선순위 기반 가지치기 |
| **적합 문제** | 입력이 극히 작은 경우 | 제약 충족 문제 ($N-Queen$) | 최적화 문제 (배낭, $TSP$) |
| **핵심 기법** | 반복문, 단순 재귀 | 유망성 검사, 복귀 ($Pop$) | 한계값 ($Bound$) 계산 및 비교 |

> 요약: 정답 가능성이 없으면 즉시 되돌아가는 것은 백트래킹, 현재까지의 비용이 이미 최악이면 가지를 치는 것은 분기 한정임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 선택 리스트 | 현재 노드에서 분기할 수 있는 모든 가능한 후보 값들의 집합임 |
| 제약 함수 | 현재까지의 선택이 문제의 규칙을 준수하고 있는지 판별하는 논리적 유망성 검사기임 |
| 상태 복구 | 실패 시 이전 단계로 돌아가기 위해 현재 노드에서 가한 변경 사항을 취소하는 작업임 |
| 정답 판정 | 모든 변수의 값이 할당되고 제약을 모두 통과하여 최종 해가 완성되었는지 확인하는 로직임 |

```text
[ 백트래킹 탐색 트리 ]
       (Start)
      /   |   \
    (A)  (B*)  (C)  <-- B가 유망하지 않으면(Pruning)
   /  \    X    / \      B 하위 노드는 일절 탐색하지 않음
 (D) (E)      (F) (G)
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 현재 노드 진입| --> | 유망성 검사   | --> | 하위 경로 재귀| --> | 상태 복구/이동|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **상태 진입** — 상태 공간 트리의 현재 노드에 방문하여 부분 해(Partial Solution)를 구성함
2. **유망 검사** — 해당 노드가 문제의 제약 조건을 만족하는지(유망한지) 확인하고, 유망하지 않으면 즉시 탐색을 종료하고 부모 노드로 복귀함
3. **재귀 탐색** — 유망하다면 자식 노드들로 깊이 우선 탐색을 지속하여 해를 구체화해 나감
4. **상태 복구** — 자식 탐색이 끝나거나 실패하여 돌아올 때, 현재 노드에서 시도했던 선택을 취소하고 다음 형제 노드로 이동할 준비를 함

## Ⅵ. 실무 적용 및 유의점

1. 유망성 검사 로직 자체가 너무 복잡하면 가지치기로 얻는 이득보다 검사 비용이 더 커질 수 있으므로, 단순하고 명확한 부등호나 비트 연산으로 제약을 먼저 확인하고 복잡한 검증은 뒤로 미루는 최적화가 필요함
2. 변수를 선택하는 순서($Ordering$)에 따라 탐색 트리의 모양과 가지치기 횟수가 극명하게 달라지므로, 제약이 가장 강한 변수(선택지가 가장 적은 것)를 우선적으로 배치하여 탐색 공간을 초기에 대폭 축소해야 함

## Ⅶ. 결론

- 백트래킹은 불가능한 경로를 지능적으로 포기함으로써 탐색 효율을 극대화하는 기법이며, 설계자는 정교한 유망성 함수와 효율적인 상태 복구 메커니즘을 구축하여 시스템의 성능 임계치를 극복해야 함
