## 미리 알고가기

- 상태 공간 트리: 가능한 선택 경로를 트리로 표현한 구조임
- 유망성 검사: 현재 경로가 답으로 이어질 가능성이 있는지 판단하는 조건임
- 가지치기: 답이 될 수 없는 경로의 탐색을 중단하는 기법임
- 분기 한정: 비용 경계값으로 불리한 경로를 중단하는 최적화 탐색 방식임

## Ⅰ. 개요

- **정의/개념**: 백트래킹은 후보 해를 단계적으로 만들다가 현재 경로가 조건을 어기면 직전 단계로 돌아가 다른 후보를 시도하는 탐색 기법임
- **배경/필요성**: 조합, 순열, 제약 충족 문제는 경우의 수가 빠르게 늘어남. 모든 경로를 끝까지 보는 대신 실패가 분명한 경로를 중간에 버려야 함

## Ⅱ. 특징

- 깊이 우선으로 탐색하되 각 단계에서 제약을 확인함
- 답 후보를 완성한 뒤가 아니라 만드는 도중에 실패 경로를 제거함
- 변수 선택 순서와 유망성 검사가 실제 탐색량을 크게 바꿈
- 최악의 경우 지수 시간이지만 제약이 강하면 방문 노드 수를 많이 줄일 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | 완전 탐색 | 백트래킹 | 분기 한정 |
|:---|:---|:---|:---|
| 탐색 방식 | 모든 경로를 끝까지 확인 | 조건 위반 시 되돌아감 | 비용 경계로 가지를 버림 |
| 중단 기준 | 리프 도달 | 제약 위반 | 현재 최선보다 불리함 |
| 적합한 문제 | 작은 입력 | 제약 충족 문제 | 최적화 문제 |
| 장점 | 구현이 단순함 | 불필요한 경로를 줄임 | 최적해 탐색을 줄임 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 상태 | 현재까지 선택한 부분 해임 |
| 후보 생성 | 다음 단계에서 선택할 수 있는 값을 나열함 |
| 유망성 검사 | 현재 상태가 제약을 만족하는지 확인함 |
| 되돌아가기 | 실패한 선택을 취소하고 다른 후보를 시도함 |

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 후보 선택 | --> | 제약 검사 | --> | 다음 단계 | --> | 실패 시 복귀 |
+-----------+     +-----------+     +-----------+     +-----------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 상태 진입 | --> | 후보 생성 | --> | 유망성 검사 | --> | 재귀/복귀 |
+-----------+     +-----------+     +-----------+     +-----------+
```

1. 현재 상태에서 가능한 후보를 생성함
2. 후보를 하나 선택해 부분 해에 넣음
3. 제약을 어기면 선택을 취소함
4. 조건을 만족하면 다음 단계로 내려감

## Ⅵ. 실무 적용 및 유의점

1. 제약 검사를 늦게 하면 완전 탐색과 차이가 줄어들므로 후보를 넣는 즉시 유망성을 확인해야 함
2. 후보 순서가 탐색량을 크게 바꾸므로 어려운 조건을 먼저 배치하고 방문 노드 수로 효과를 확인해야 함

## Ⅶ. 결론

- 백트래킹은 제약 위반 경로를 즉시 버리는 탐색 방식이며, 유망성 검사 품질이 성능을 좌우함
