## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 해 공간을 상태 공간 트리로 구성하고, 유망하지 않은 가지를 가지치기(Pruning)하여 탐색 범위를 줄이는 완전 탐색 최적화 기법임 |
| **배경/필요성** | 브루트포스 탐색의 지수적 시간 복잡도를 줄이기 위해, 조기에 불가능한 경로를 배제하는 전략이 필요함 |
| **출제 의도** | 백트래킹의 가지치기 원리와 N-Queens 등 적용 사례를 설명할 수 있는지 평가함 |

## Ⅱ. 구성요소
```
+----------+     +----------+     +----------+
| 상태공간  | --> | 유망함수  | --> | 가지치기  |
| 트리     |     | (Promising)|   | (Pruning)|
+----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| 상태 공간 트리 | 모든 가능한 선택을 트리 형태로 나타낸 탐색 공간임 | 미로의 모든 갈래길 지도 |
| 유망 함수 | 현재 노드에서 해에 도달할 가능성이 있는지 판별하는 조건 함수임 | 막다른 길 사전 감지 |
| 가지치기 | 유망하지 않은 노드의 하위 트리를 탐색하지 않고 건너뜀 | 막다른 길 진입 차단 |

> 요약: 상태 공간 트리에서 유망 함수로 불필요한 가지를 잘라내어 탐색 효율을 높임.

## Ⅲ. 절차
```
+------------+     +------------+
| 선택       | --> | 유망성검사  |
| (후보배치) |     | (제약조건) |
+------------+     +------------+
                        |
+------------+     +----+-------+
| 되돌아감   | <-- | 재귀탐색  |
| (Backtrack)|     | (다음단계) |
+------------+     +------------+
```

1. 선택: 현재 단계에서 가능한 후보 중 하나를 선택하여 배치함
2. 유망성 검사: 선택이 제약 조건을 만족하는지(유망한지) 검사함
3. 재귀 탐색: 유망하면 다음 단계로 재귀 진행하고, 해를 찾으면 반환함
4. 되돌아감: 유망하지 않거나 하위에서 해를 못 찾으면 선택을 취소하고 다른 후보를 시도함

> 요약: 선택 → 유망성 검사 → 재귀 → 되돌아감으로 가지치기 기반 탐색을 수행함.

## Ⅳ. 문제점
- 최악 시간 지수적: 가지치기가 효과적이지 않으면 브루트포스와 동일한 시간이 소요됨
- 유망 함수 설계 난이도: 문제별로 가지치기 조건을 적절히 설계해야 성능이 확보됨
- 최적해 미보장(근사): 첫 번째 해를 찾으면 종료하는 경우 최적해가 아닐 수 있음

## Ⅴ. 개선방안
- (단기) 강한 가지치기: 제약 전파(Constraint Propagation)로 가지치기 효과를 극대화함
- (중기) 분기 한정(B&B): 상한·하한을 계산하여 최적 가능성이 없는 분기를 조기 제거함
- (장기) 메모이제이션 결합: 중복 상태를 캐싱하여 동일 부분 문제의 재탐색을 방지함

## Ⅵ. 전망
- CSP(제약 만족 문제)·SAT 솔버·퍼즐 해결에서 백트래킹이 핵심이며, CDCL(충돌 주도 절 학습) 등 지능형 가지치기가 산업용 SAT 솔버의 표준이 될 전망임
