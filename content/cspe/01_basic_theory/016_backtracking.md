## 미리 알고가기

- 상태 공간 트리: 선택 가능한 모든 경로를 노드와 간선으로 표현한 탐색 구조임
- 부분해: 아직 완성 전이지만 현재까지 선택한 값들의 집합임
- 유망성(Promising): 현재 부분해가 최종 해로 이어질 가능성이 있는지 보는 기준임
- 가지치기(Pruning): 유망하지 않은 경로를 더 내려가지 않고 중단하는 처리임
- 제약 충족 문제(CSP): 여러 제약을 동시에 만족하는 변수 값을 찾는 문제 유형임

## Ⅰ. 개요

- **정의/개념**: 백트래킹은 부분해를 깊이 우선으로 확장하다가 제약 위반이 확인되면 이전 선택으로 돌아가 다른 경로를 탐색하는 기법임
- **배경/필요성**: 순열·조합·제약 충족 문제는 후보가 지수적으로 늘어나므로 실패 경로를 조기에 버리는 탐색 통제가 필요함

## Ⅱ. 특징

- DFS 순서를 따르지만 리프 전에도 제약 위반이면 즉시 되돌아감
- 유망성 검사가 탐색 공간 크기와 실행 시간을 좌우함
- 상태 복구가 정확해야 다음 형제 경로가 이전 선택의 영향을 받지 않음
- 최악 시간은 지수적일 수 있어 가지치기 효과를 입력별로 확인해야 함

## Ⅲ. 종류 및 비교

| 판단 기준 | 완전 탐색 (Brute-force) | 백트래킹 (Backtracking) | 분기 한정 (Branch & Bound) |
|:---|:---|:---|:---|
| 중단 기준 | 모든 후보 확인 후 종료 | 제약 위반 시 중단 | 현재 비용이 경계를 넘으면 중단 |
| 탐색 방식 | 전수 열거 | DFS 기반 가지치기 | 우선순위 또는 BFS 기반 가지치기 |
| 적합 문제 | 입력이 매우 작은 문제 | $N$-Queen, 순열, 조합 | 배낭, $TSP$ 같은 최적화 문제 |
| 핵심 상태 | 후보 목록 | 부분해, 제약 함수, 복구 상태 | 현재 비용, 하한·상한 |

> 요약: 제약 위반으로 경로를 버리면 백트래킹, 비용 경계로 경로를 버리면 분기 한정임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 선택 목록 | 현재 깊이에서 시도할 후보 값을 제공함 |
| 부분해 | 지금까지 선택한 값과 제약 상태를 담음 |
| 제약 함수 | 부분해의 해 확장 가능성을 검사함 |
| 상태 복구 | 선택 전 상태로 되돌려 다음 후보를 독립적으로 검사함 |
| 정답 판정 | 모든 선택이 완료되고 제약을 만족하는지 확인함 |

```text
[ 백트래킹 구조 ]
Choose -> Check Constraint -> Recur
                 |
                 v
              Prune/Return
```

> 요약: 백트래킹은 선택, 제약 검사, 재귀, 복구가 한 반복 단위로 묶임.

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 후보 선택   | --> | 유망성 검사 | --> | 재귀 확장   | --> | 상태 복구   |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **후보 선택**: 현재 깊이에서 아직 시도하지 않은 후보를 부분해에 추가함
2. **유망성 검사**: 제약 위반이면 해당 경로를 중단함
3. **재귀 확장**: 유망하면 다음 깊이로 내려가 부분해를 확장함
4. **상태 복구**: 반환 후 선택을 취소하고 다음 후보를 검사함

## Ⅵ. 실무 적용 및 유의점

1. 유망성 검사가 비싸면 가지치기 이득이 줄어드므로 단순 제약을 먼저 검사하고 방문 노드 수와 검사 시간을 함께 확인함
2. 변수 선택 순서가 탐색 폭을 바꾸므로 후보 수가 적은 변수를 먼저 배치하고 최대 깊이와 가지치기 비율로 검증함

## Ⅶ. 결론

- 백트래킹은 제약 위반 경로를 조기에 버리는 DFS 기반 탐색이므로 유망성 검사 비용과 상태 복구 정확성을 함께 통제해야 함

## 작성 근거(검토용)

- **개요 구성**: 백트래킹은 DFS 확장과 제약 위반 시 복귀가 핵심이라 정의에 두 동작을 함께 넣음
- **Ⅱ. 특징 선정**: 유망성 검사, 상태 복구, 최악 지수 시간은 성능과 정답성을 좌우해 특징으로 남김
- **Ⅲ 비교축 선정**: 완전 탐색·분기 한정과의 차이는 중단 기준과 탐색 방식에서 가장 선명하게 드러남
- **Ⅳ 구조 선정**: 선택 목록, 부분해, 제약 함수, 복구 상태는 백트래킹 구현의 필수 상태라 표로 정리함
- **Ⅵ 적용 선정**: 검사 비용과 변수 순서는 가지치기 효과를 실제로 바꾸므로 운영 확인 지표와 연결함
