## Ⅰ. 개요
- **정의**: 해 공간 트리를 DFS로 탐색하되 유망하지 않은 가지를 조기에 잘라내어 해를 찾는 기법
- **배경/필요성**: 완전 탐색(brute-force)은 해 공간 전체를 순회하므로 지수적 시간이 소요됨. 탐색 도중 해가 될 수 없는 경로를 조기에 식별하면 실제 방문 노드 수를 대폭 줄일 수 있음
- **비유**: 미로에서 막다른 길에 도달하면 즉시 되돌아와 다른 갈림길을 시도하는 방식과 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 상태 공간 트리 탐색과 가지치기 원리 이해 확인 | 유망 함수 설계가 성능을 좌우함을 서술 | 최악 시간복잡도가 완전 탐색과 동일할 수 있음을 언급할 것 |

> 요약: DFS + 유망성 판단으로 탐색 공간을 축소하여 조합 최적화 문제를 풀되, 최악 성능은 지수적임

## Ⅱ. 구성요소
```text
              상태 공간 트리 (루트)
              /        |        \
           선택1     선택2     선택3
           /   \       |
        선택a  선택b  (가지치기 X)
         |
      (유망 -> 확장)
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 상태 공간 트리 | 가능한 선택 순서를 트리 노드로 표현한 탐색 구조 | 미로 전체 지도 |
| 유망 함수 | 현재 노드에서 해에 도달할 가능성이 있는지 판단하는 함수 | 막다른 길 표지판 |
| 가지치기(pruning) | 유망하지 않은 노드의 하위 트리 전체를 탐색에서 제외하는 연산 | 막힌 통로 차단 |
| DFS 탐색기 | 깊이 우선으로 트리를 순회하며 선택-검사-되돌림을 반복하는 제어 흐름 | 미로를 한 방향으로 끝까지 가보는 탐험가 |
| 해 조건 | 리프 또는 특정 깊이에서 문제의 제약을 모두 만족하는지 판정하는 조건 | 미로 출구 도착 확인 |
| 되돌림(backtrack) | 현재 선택을 취소하고 부모 노드로 복귀하여 다음 선택지를 시도하는 연산 | 갈림길까지 뒤로 걷기 |

> 요약: 상태 공간 트리를 DFS로 순회하면서 유망 함수와 가지치기가 탐색 범위를 줄이고, 해 조건 충족 시 종료함

## Ⅲ. 절차
```text
루트 노드 진입 --> 유망 함수 평가 --[유망]--> 자식 확장(DFS)
                        |                         |
                   [비유망]                   해 조건 충족?
                        |                    /          \
                        v                 [예]         [아니오]
                   가지치기(pruning)     해 반환      다음 자식으로
                        |                             이동 또는 되돌림
                        v
                   부모로 되돌림
```
- 1단계: **노드 진입** — 루트에서 시작하여 현재 깊이의 선택지를 하나 적용함
- 2단계: **유망성 평가** — 유망 함수로 현재 상태가 해에 도달 가능한지 판단함. 비유망이면 가지치기 후 되돌림
- 3단계: **자식 확장** — 유망하면 다음 깊이로 DFS를 진행하여 추가 선택을 적용함
- 4단계: **해 판정 및 되돌림** — 해 조건 충족 시 해를 반환하고, 아니면 형제 노드 또는 부모로 되돌려 탐색을 계속함

> 요약: 선택 → 유망성 평가 → 확장 또는 가지치기 → 해 판정의 재귀적 반복으로 해 공간을 효율적으로 탐색함

## Ⅳ. 문제점
- 최악 지수 시간: 유망 함수의 판별력이 낮으면 가지치기 효과가 미미하여 완전 탐색과 동일한 O(b^d) 시간이 소요됨 — b는 분기 수, d는 깊이
- 유망 함수 설계 어려움: 문제마다 유효한 유망 함수를 설계해야 하며, 과도한 판별 조건은 오히려 유효 해를 누락시킬 수 있음 — 설계 비용과 정확성 간 트레이드오프 존재
- 메모리 부담: 재귀 호출 스택이 트리 깊이에 비례하여 증가하므로 깊이가 큰 문제에서 스택 오버플로 위험이 있음 — N이 큰 경우 실용성 저하

> 요약: 유망 함수 품질에 성능이 종속되고, 최악 시 지수 시간·깊은 재귀 스택이 실용성을 제한함

## Ⅴ. 개선방안
1. 단기: 제약 전파(constraint propagation)를 유망 함수에 결합하여 가지치기 판별력을 높이고 탐색 노드 수를 줄임
2. 중기: 반복 심화(iterative deepening)를 적용하여 깊이 제한을 점진적으로 확대함으로써 메모리 사용량을 O(d)로 유지함
3. 장기: 몬테카를로 트리 탐색(018 참조)·확률적 탐색과 결합하여 대규모 해 공간에서도 실용적인 근사해를 탐색할 수 있도록 확장함

> 요약: 제약 전파로 가지치기 강화 → 반복 심화로 메모리 절약 → 확률적 탐색 결합으로 대규모 문제 대응

## Ⅵ. 전망
- 발전 방향: SAT 솔버, CSP 솔버 등 제약 만족 엔진의 핵심 탐색 전략으로 지속 활용되며, 병렬 백트래킹 연구가 확대됨
- 기술사적 판단: 탐욕(015 참조)으로 해결 불가한 조합 문제에서 정확해를 보장하는 기본 기법으로, 분기 한정(branch and bound)의 기초가 됨
- 기술사 제언: 문제 규모와 제약 구조를 먼저 분석하여 백트래킹 단독 적용이 실용적인지 판단하고, 대규모 문제에서는 메타휴리스틱(017 참조)과의 조합을 검토할 것
