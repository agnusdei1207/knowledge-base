## 미리 알고가기

- 원-핫 인코딩: 단어 하나만 1이고 나머지는 0인 희소 벡터 표현임
- 밀집 벡터: 낮은 차원의 실수값으로 의미를 표현하는 벡터임
- 분포 가설: 비슷한 문맥에 나오는 단어는 의미도 비슷하다는 가정임
- 코사인 유사도: 두 벡터 방향의 가까움을 측정하는 지표임
- 정적 임베딩: 한 단어가 문맥과 무관하게 하나의 벡터만 갖는 방식임

## Ⅰ. 개요

- **정의/개념**: 단어 임베딩은 단어의 의미와 관계를 보존하도록 단어를 낮은 차원의 밀집 벡터로 표현하는 자연어 표현 기법임
- **배경/필요성**: 원-핫 인코딩은 차원이 크고 단어 간 유사도를 표현하지 못하므로 의미 기반 연산이 가능한 벡터 표현이 필요함

## Ⅱ. 특징

- 단어 사이 의미 유사도를 벡터 거리로 계산함
- 희소 벡터를 밀집 벡터로 바꿔 차원 부담을 줄임
- 단어 관계를 벡터 덧셈과 뺄셈으로 일부 표현함
- 정적 임베딩은 다의어를 문맥별로 구분하지 못함

## Ⅲ. 종류 및 비교

| 구분 | Word2Vec | GloVe | FastText |
|:---|:---|:---|:---|
| 학습 기준 | 주변 단어 예측 | 전역 동시 출현 통계 | 서브워드 n-gram |
| 강점 | 빠르고 구현이 단순함 | 말뭉치 전체 통계 반영 | OOV와 오타에 강함 |
| 한계 | 전역 통계 반영 약함 | 행렬 구성 비용 큼 | 학습·메모리 비용 증가 |
| 대표 방식 | CBOW, Skip-gram | 동시 출현 행렬 근사 | 문자 조각 벡터 합산 |
| 적합 상황 | 일반 의미 유사도 | 대규모 말뭉치 통계 | 형태 변화가 많은 언어 |

> 요약: Word2Vec은 예측, GloVe는 통계, FastText는 서브워드 정보에 기반함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 말뭉치 | 임베딩이 학습할 언어 사용 범위를 결정함 |
| 토큰 사전 | 벡터를 가질 단어 목록을 정의함 |
| 문맥 창 | 중심 단어 주변을 어느 범위까지 볼지 정함 |
| 학습 목표 | 중심 단어와 주변 단어의 관계를 예측함 |
| 임베딩 행렬 | 단어 ID별 최종 벡터를 저장함 |

> 요약: 말뭉치와 문맥 창이 학습 신호를 만들고 임베딩 행렬이 최종 산출물임.

```text
말뭉치 토큰
  -> 문맥 창
  -> 단어-문맥 쌍
  -> 예측/통계 모델 학습
  -> 임베딩 행렬
```

## Ⅴ. 원리 및 절차 흐름도

```text
말뭉치 토큰화 -> 쌍/통계 구축 -> 벡터 학습 -> 유사도 측정 -> 재사용
```

1. 말뭉치를 토큰화하고 저빈도 단어를 정리함
2. 문맥 창으로 중심 단어와 주변 단어 관계를 수집함
3. 예측 기반 또는 통계 기반 목표를 최적화함
4. 학습된 벡터를 분류, 검색, 군집화 입력으로 사용함

> 요약: 임베딩 학습은 말뭉치 문맥 관계를 벡터 공간 거리로 옮기는 과정임.

## Ⅵ. 실무 적용 및 유의점

1. 검색 확장과 유사어 추천에는 정적 임베딩이 가볍지만 다의어가 많은 도메인은 문맥 임베딩과 비교해 정확도 차이를 확인함
2. 임베딩은 학습 말뭉치의 사회적 편향을 그대로 반영하므로 민감 단어 평가셋을 구축하고 편향 완화 절차를 운영함

## Ⅶ. 결론

- 단어 임베딩은 단어 의미를 계산 가능한 공간으로 옮기는 표현 기법이며, 말뭉치 품질과 문맥 구분 필요성을 함께 판단해야 함
