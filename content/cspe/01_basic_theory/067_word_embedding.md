## 미리 알고가기

- 원핫 인코딩: 단어 하나를 어휘 크기만큼의 희소 벡터로 표현하는 방식임
- 분산 표현: 단어 의미를 여러 차원의 실수값에 나누어 담는 표현 방식임
- 문맥 창: 중심 단어 주변 몇 개 단어를 학습에 사용할지 정하는 범위임
- CBOW: 주변 단어로 중심 단어를 예측하는 Word2Vec 학습 방식임
- Skip-gram: 중심 단어로 주변 단어를 예측하는 Word2Vec 학습 방식임
- 코사인 유사도: 두 벡터의 방향 유사성으로 의미적 가까움을 계산하는 지표임

## Ⅰ. 개요

- **정의**: 단어 임베딩은 단어를 의미와 문맥 유사성이 보존되는 저차원 실수 벡터로 변환하는 자연어 표현 기법임. 단어 간 거리와 방향을 기준으로 유사도, 분류, 검색, 추천 같은 후속 연산을 가능하게 하기 위해 사용함
- **배경/필요성**: 원핫 인코딩은 차원이 크고 모든 단어 쌍의 유사도가 0에 가까워 의미 관계를 학습 모델에 전달하기 어렵음
- **비유**: 단어를 사전 순서가 아니라 의미 지도 위 좌표로 배치해 가까운 단어끼리 비슷한 위치에 놓는 방식과 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 분산 표현 원리 설명 | 희소 벡터에서 밀집 벡터로 변환 | 원핫 인코딩과 차이 누락 |
| Word2Vec·GloVe 비교 | 예측 기반, 통계 기반 학습 차이 | 정적 임베딩 한계 누락 |

> 요약: 단어 임베딩은 문자열 단어를 의미 공간의 수치 벡터로 바꾸어 유사도와 기계학습 입력으로 활용하게 하는 표현 기법임

## Ⅱ. 특징/비교

| 판단 기준 | 원핫 인코딩 | 정적 임베딩 | 문맥 임베딩 |
|:---|:---|:---|:---|
| 표현 방식 | 어휘 크기만큼의 희소 벡터 | 고정 차원의 밀집 벡터 | 문장 문맥에 따라 달라지는 벡터 |
| 의미 유사도 | 단어 간 관계를 거의 표현하지 못함 | 코사인 거리로 유사 단어를 표현함 | 동음이의어와 문맥 의미를 구분함 |
| 계산 비용 | 단순하지만 차원이 매우 큼 | 경량이며 검색·추천에 활용 쉬움 | 모델 비용이 크지만 표현력이 높음 |
| 선택 조건 | 단순 범주 표현 | 경량 NLP, 검색, 추천 | 문서 이해, 질의응답, 생성 모델 |

> 요약: 단어 임베딩은 원핫보다 의미 표현력이 높고 문맥 임베딩보다 가벼워 경량 NLP 표현으로 적합함

- **Word2Vec 선택**: 대규모 코퍼스에서 주변 문맥 예측으로 단어 관계를 빠르게 학습할 때 적합함
- **GloVe 선택**: 단어 동시출현 행렬 같은 전역 통계 정보를 임베딩에 반영하고 싶을 때 적합함
- **FastText 선택**: 서브워드 n-gram을 활용해 신조어와 OOV에 대응해야 할 때 적합함

## Ⅲ. 구성요소

```text
+-------------+      +-------------+      +-------------+
| Corpus      | ---> | Context     | ---> | Training    |
| Tokens      |      | Window      |      | Objective   |
+------+------+      +------+------+      +------+------+
       |                    |                    |
       v                    v                    v
+-------------+      +-------------+      +-------------+
| Embedding   | <--- | Vector      | ---> | Similarity  |
| Matrix      |      | Lookup      |      | Measure     |
+-------------+      +-------------+      +-------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 토큰 코퍼스 | 학습 대상 문장을 토큰화한 데이터이며 문맥 관계의 원천임 | 독서 자료 |
| 문맥 창 | 중심 단어와 주변 단어를 묶어 학습 샘플을 만드는 범위임 | 관찰 창 |
| 학습 목적 | CBOW, Skip-gram, co-occurrence factorization 등 벡터를 조정하는 기준임 | 훈련 과제 |
| 임베딩 행렬 | 어휘 수와 차원 수로 구성된 벡터 lookup 테이블임 | 좌표 표 |
| 유사도 계산 | 코사인 유사도, 내적, 거리로 단어 간 관계를 측정함 | 거리 자 |

> 요약: 단어 임베딩은 토큰 코퍼스의 문맥 관계를 학습 목적에 맞춰 행렬로 저장하고 유사도 계산에 활용하는 구조임

## Ⅳ. 절차

```text
+-----------+     +-----------+     +-----------+     +-----------+
| Tokenize  | --> | Build     | --> | Train     | --> | Use       |
| Corpus    |     | Pairs     |     | Vectors   |     | Embedding |
+-----------+     +-----------+     +-----------+     +-----------+
      |                 |                 |                 |
      v                 v                 v                 v
words/subwords     center-context     dense matrix      NLP feature
```

1. **코퍼스 준비**: 문장을 토큰화하고 빈도 기준으로 어휘 사전을 구성해 저빈도 노이즈를 줄임
2. **문맥 샘플 생성**: 슬라이딩 윈도우로 중심 단어와 주변 단어 쌍 또는 동시출현 통계를 만듦
3. **벡터 학습**: CBOW, Skip-gram, GloVe 손실을 최소화하며 임베딩 행렬의 가중치를 갱신함
4. **후속 활용**: 학습된 벡터를 분류, 검색, 군집화, 추천 모델의 입력 피처로 사용하고 유사도 품질을 검증함

> 요약: 임베딩 절차는 코퍼스에서 문맥 관계를 추출하고 이를 저차원 벡터 행렬로 학습해 후속 모델에 공급하는 과정임

## Ⅴ. 문제점

- **P1 정적 의미 한계**: 하나의 단어가 항상 같은 벡터를 가져 `배`처럼 문맥에 따라 의미가 달라지는 단어를 구분하기 어려움
- **P2 편향 전이**: 학습 코퍼스의 성별, 직업, 지역 편향이 벡터 공간의 방향과 유사도에 그대로 반영될 수 있음
- **P3 OOV 취약성**: 사전에 없는 신조어, 오탈자, 전문 용어는 벡터 lookup 자체가 불가능하거나 품질이 낮아짐

> 요약: 정적 임베딩은 가볍지만 문맥 의미, 사회적 편향, 사전 밖 단어 처리에서 한계를 가짐

## Ⅵ. 개선방안

- **P1 대응**: ELMo, BERT 같은 문맥 임베딩을 적용하거나 단어 의미별 센스 임베딩을 분리함 (확인: WSD 정확도)
- **P2 대응**: 편향 방향 제거, 균형 코퍼스 재학습, WEAT 등 편향 지표 모니터링을 수행함 (확인: 편향 점수 변화)
- **P3 대응**: FastText 서브워드 임베딩, 도메인 사전 확장, 오탈자 정규화를 적용함 (확인: OOV율과 검색 재현율)

> 요약: 문맥화, 편향 완화, 서브워드 처리를 결합해야 단어 임베딩의 표현 한계를 줄일 수 있음

## Ⅶ. 전망

- **발전 방향**: 독립 Word2Vec 활용은 줄어도 검색, 추천, 벡터 DB, 경량 분류의 기본 표현으로 계속 쓰일 전망임
- **기술사적 판단**: 고성능 NLU에는 문맥 임베딩이 적합하지만, 지연과 비용이 제한된 시스템에는 정적 임베딩이 실용적일 수 있음
- **기술사 제언**: 답안에서는 밀집 벡터의 의미와 정적 임베딩의 한계를 함께 제시해 BERT 계열로의 발전 흐름을 연결해야 함
