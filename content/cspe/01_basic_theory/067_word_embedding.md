## 미리 알고가기

- one-hot vector: 단어를 희소 벡터로 표현한 방식임
- 임베딩 벡터: 단어 의미를 저차원 밀집 벡터로 나타낸 것임
- 분포 가설: 비슷한 문맥에 나타나는 단어는 의미도 비슷하다는 가정임

## Ⅰ. 개요

- **정의/개념**: 단어 임베딩은 단어를 의미와 문맥 유사성이 반영된 밀집 벡터 공간에 매핑하는 표현 방식이며, Word2Vec과 GloVe가 대표 전통 기법임
- **배경/필요성**: one-hot 표현은 차원이 크고 단어 간 의미 관계를 담지 못하므로, 의미적 거리를 학습한 벡터 표현이 필요함

## Ⅱ. 특징

- 의미가 유사한 단어가 벡터 공간에서 가깝게 배치됨
- 희소 표현보다 메모리 효율이 높고 일반화에 유리함
- Word2Vec은 지역 문맥, GloVe는 전역 동시출현 정보를 활용함
- 문맥 독립 표현이라 다의어 처리에는 한계가 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | Word2Vec | GloVe | Contextual Embedding |
|:---|:---|:---|:---|
| 학습 정보 | 주변 문맥 | 전역 공기빈도 | 문장 전체 문맥 |
| 의미 표현 | 정적 | 정적 | 동적 |
| 장점 | 단순, 빠름 | 전역 통계 반영 | 다의어 처리 |
| 대표 적용 | 전통 NLP | 전통 NLP | BERT, GPT |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 어휘집합 | 임베딩 대상 단어 목록이며 vocab 크기를 결정함 |
| 문맥 창 | 주변 단어 범위이며 의미 관계 학습 범위를 정함 |
| 임베딩 행렬 | 단어별 벡터 저장소이며 최종 표현 공간임 |
| 학습 목표 | 예측 기반 또는 동시출현 기반이며 알고리즘 차이를 만듦 |

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 어휘집합    | --> | 문맥 창      | --> | 임베딩 행렬  | --> | 학습 목표    |
+-----------+     +-----------+     +-----------+     +-----------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 말뭉치입력 | --> | 문맥추출 | --> | 벡터학습 | --> | 유사도활용 |
+----------+     +----------+     +----------+     +----------+
```

1. **말뭉치입력**: 대량 텍스트를 준비함
2. **문맥추출**: 각 단어 주변 문맥이나 공기빈도를 수집함
3. **벡터학습**: 예측 오차를 줄이도록 임베딩을 갱신함
4. **유사도활용**: 분류, 검색, 추천 등 downstream task에 사용함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 다의어를 하나의 벡터로 표현해 문맥별 의미 구분이 약함
   - 해결방안: contextual embedding으로 전환하고 word sense accuracy로 검증함
2. 문제: 희귀 단어 표현이 약해 충분한 문맥을 못 배우면 품질이 낮음
   - 해결방안: subword embedding과 대규모 말뭉치를 사용하고 rare-word similarity로 검증함
3. 문제: 편향이 학습될 수 있어 말뭉치의 사회적 편향이 반영됨
   - 해결방안: bias audit와 debiasing 기법을 적용하고 bias metric로 검증함

## Ⅶ. 적용 사례

- 검색 확장에서는 유사 단어를 활용해 질의를 확장함, 확인 지표는 검색 recall임
- 문서 분류에서는 평균 임베딩이나 시퀀스 모델 입력으로 활용함, 확인 지표는 F1임
- 추천/태그 유사도에서는 아이템 설명 텍스트 벡터화를 수행함, 확인 지표는 semantic match rate임

## Ⅷ. 결론

단어 임베딩의 핵심은 단어를 ID가 아니라 의미 공간의 점으로 바꾸는 데 있으므로, 표현 단위와 문맥 범위를 목적에 맞게 선택해야 함.
