# 067. 단어 임베딩 — Word2Vec·GloVe (Word Embedding)

## Ⅰ. 개요

- **정의/개념**: 단어를 고정된 크기의 저차원 밀집 벡터(Dense Vector)로 매핑하여, 단어 간의 유의미한 유사성과 문맥적 관계를 수학적으로 표현하는 자연어 처리 기술임
- **배경/필요성**: 기존 원-핫 인코딩(One-hot Encoding)은 단어 수가 많아질수록 차원이 폭발하며 단어 간의 의미적 관계를 전혀 표현하지 못하는 한계가 있어, 분포 가설(Distributional Hypothesis)에 기반한 효율적인 벡터 표현이 필요함

## Ⅱ. 특징 및 비교

| 판단 기준 | 원-핫 인코딩 (One-hot) | Word2Vec | GloVe |
|:---|:---|:---|:---|
| **벡터 형태** | 고차원 희소 벡터 (Sparse) | 저차원 밀집 벡터 (Dense) | 저차원 밀집 벡터 (Dense) |
| **의미 유사도** | 반영 불가 | 반영 가능 (코사인 유사도 등) | 반영 가능 (전역 통계 활용) |
| **학습 방식** | 단순 인덱싱 | 주변 단어 예측 (Local Context) | 단어 공출현 빈도 (Global Stat) |
| **장점** | 구현이 매우 단순함 | 유추 연산(King-Man+Woman) 가능 | 전역 문맥 반영, 학습 효율 우수 |
| **단점** | 차원의 저주, 의미 실종 | 전역적인 통계 정보 무시 | 코퍼스 크기에 따른 메모리 부담 |

> 요약: Word2Vec은 국소적 문맥 예측에, GloVe는 전역적 공출현 통계에 강점이 있으며 둘 다 정적 임베딩의 대표 주자임

## Ⅲ. 구성요소/구조

- **구성요소**:
  - **Embedding Layer**: 단어 인덱스를 해당 임베딩 벡터로 변환해주는 룩업 테이블(Look-up Table)임
  - **Cosine Similarity**: 두 임베딩 벡터 사이의 각도를 이용해 단어 간의 유사도를 측정함
  - **CBOW (Word2Vec)**: 주변 단어들을 이용해 중간에 있는 핵심 단어를 예측하는 방식임
  - **Skip-gram (Word2Vec)**: 핵심 단어 하나를 보고 주변에 올 단어들을 예측하는 방식으로, 성능이 대체로 우수함
  - **Co-occurrence Matrix (GloVe)**: 전체 말뭉치에서 단어 쌍이 동시에 나타나는 빈도를 기록한 행렬임

- **Word2Vec (Skip-gram) 구조도**:
```text
[Input Word] -> [Input Layer] -> [Hidden Layer] -> [Output Layer] -> [Output Context]
      |               |                |                |                 |
  "Coffee"       One-hot(V)      Projection(d)     Softmax(V)      ["Drink", "Bean"]
```

## Ⅳ. 문제점 및 개선방안

1. **[다의어 처리 한계]**: '배(Ship, Pear, Belly)'와 같이 형태는 같으나 의미가 다른 단어를 하나의 고정된 벡터로만 표현함
   - **개선방안**: 주변 문맥에 따라 임베딩 값이 변하는 ELMo나 BERT와 같은 문맥 기반 임베딩(Contextual Embedding)을 사용함 (확인: 유사도 정확도)
2. **[미등록어 (OOV) 문제]**: 학습 사전에 없는 단어는 벡터로 변환할 수 없어 정보를 완전히 소실함
   - **개선방안**: 단어를 더 작은 단위로 쪼개서 학습하는 FastText(n-gram 활용)를 사용하여 미등록어에 대응함 (확인: OOV 처리율)
3. **[말뭉치 편향 (Bias)]**: 학습 데이터에 내재된 성별, 인종 등에 대한 사회적 편향이 벡터 연산 결과에 그대로 반영됨
   - **개선방안**: 편향된 성분을 제거하는 디바이어싱(Debiasing) 기법을 적용하거나 데이터 정제를 강화함 (확인: 편향성 평가 지표)

## Ⅴ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| **검색 시스템** | 키워드와 문서 제목을 임베딩하여 단순 일치(Match)가 아닌 의미 기반 검색 구현 | nDCG, Click-Through Rate |
| **추천 알고리즘** | 사용자가 소비한 아이템 리스트를 단어 시퀀스로 간주하여 Item-Embedding 학습 | Recall@K, 다양성 지표 |
| **감성 분석 전처리** | 입력 텍스트를 임베딩 벡터로 변환하여 RNN/CNN 모델의 입력 피처로 활용 | F1-Score, Loss Convergence |

> 요약: 실무에서는 특정 도메인(금융, 의료 등)의 전문 용어를 처리하기 위해 자체 말뭉치로 임베딩을 재학습하는 경우가 많음

## Ⅵ. 결론

단어 임베딩은 자연어 처리의 패러다임을 규칙 기반에서 수치 기반의 딥러닝 체계로 전환시킨 핵심 기술임. 비록 최근에는 문맥 전체를 고려하는 Transformer 기반의 동적 임베딩이 대세가 되었으나, 정적 임베딩은 여전히 가벼운 모델이 필요한 환경이나 아이템 간의 고정된 관계를 파악해야 하는 추천 시스템 등에서 강력한 기본 도구로 활용되고 있음.
