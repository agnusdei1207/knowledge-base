## 미리 알고가기

- 원-핫 인코딩($One-hot$): 단어 하나를 사전의 전체 단어 수 크기의 벡터로 만들고, 단어 고유의 위치만 1로 표시하고 나머지는 0으로 채우는 희소 표현법임
- 분포 가설($Distributional$ $Hypothesis$): "비슷한 문맥에서 나타나는 단어들은 의미적으로도 유사하다"라는 자연어 처리의 핵심 가설임
- 동시 출현 행렬($Co-occurrence$ $Matrix$): 전체 말뭉치에서 각 단어 쌍이 정해진 문맥 크기($Window$ $Size$) 내에 동시에 출현한 빈도를 기록한 행렬임
- 정적 임베딩($Static$): 문맥에 상관없이 하나의 단어가 오직 하나의 고정된 벡터 값만 가지는 한계가 있는 임베딩 방식임

## Ⅰ. 개요

- **정의/개념**: 단어 임베딩은 사람이 사용하는 자연어를 컴퓨터가 연산할 수 있도록, 단어 간의 의미적 유사성과 관계성을 보존한 채 수십~수백 차원의 고밀도 실수 벡터($Dense$ $Vector$) 공간에 매핑하는 표현 기법임
- **배경/필요성**: 기존의 원-핫 인코딩 방식은 단어가 늘어날수록 차원이 기하급수적으로 커져 메모리가 낭비($Curse$ $of$ $Dimensionality$)되고 단어 사이의 의미적 유사도(예: 왕과 여왕의 거리)를 전혀 계산할 수 없기 때문에 이를 보완하기 위해 고안됨

## Ⅱ. 특징

- 단어들을 다차원 벡터 공간의 점으로 표시하며, 벡터의 방향과 거리를 계산하여 단어 간의 유사성을 정량적으로 비교(예: 코사인 유사도)할 수 있음
- 단어 간의 관계를 덧셈과 뺄셈으로 나타낼 수 있는 선형적인 "의미론적 대수 연산($Word$ $Analogy$)"이 가능하여 기계가 상식적 추론(예: '왕' - '남자' + '여자' = '여왕')을 수행할 수 있도록 도움을 줌
- 초기의 임베딩(Word2Vec, GloVe)은 학습 완료 후 단어의 벡터가 고정되는 정적 임베딩의 한계를 가지며, 문맥에 따라 단어 뜻이 변하는 다의어를 올바르게 표현하지 못함

## Ⅲ. 종류 및 비교

| 판단 기준 | Word2Vec (예측 기반) | GloVe (전역 통계 기반) | FastText (서브워드 확장) |
|:---|:---|:---|:---|
| **학습 원리** | 주변 단어로 중심 단어 예측 ($CBOW/Skip-gram$) | 전역 동시 출현 빈도 비율의 선형 회귀 | 단어를 문자 단위 n-gram으로 쪼개어 학습 |
| **장점** | 학습 속도가 매우 빠르고 직관적임 | 말뭉치 전체의 글로벌 통계 정보를 반영함 | 오타나 미등록 단어($OOV$)에 매우 강인함 |
| **단점** | 텍스트 전체의 전역적 정보는 누락됨 | 대용량 말뭉치의 행렬 분해에 시간 소요 | 학습 시간이 길고 메모리를 많이 사용함 |
| **핵심 기법** | 네거티브 샘플링 ($Negative$ $Sampling$) | 로그 동시 출현 빈도 근사화 함수 | 서브워드 벡터들의 합산 처리 |

> 요약: Word2Vec은 국소 문맥 예측에, GloVe는 전역 빈도 통계에, FastText는 철자 결합에 특화됨.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 슬라이딩 윈도우 | 중심 단어를 기준으로 문맥으로 인정할 주변 단어의 최대 앞뒤 범위(예: 윈도우 크기 5)임 |
| $Skip-gram$ | 중심 단어를 입력받아 주변 단어들을 예측하는 구조로, 희귀 단어 학습 성능이 상대적으로 우수함 |
| $CBOW$ | 주변에 있는 단어들을 조합하여 중앙에 올 가장 확률이 높은 단어를 예측하는 정방향 구조임 |
| 가중치 행렬 | 입력 레이어와 은닉 레이어 사이의 $W$ 행렬이 학습의 최종 결과물인 임베딩 테이블이 됨 |

```text
[ Word2Vec 두 아키텍처 비교 ]
- CBOW (주변 -> 중심): [Context 1, Context 2] -> [Sum/Average] -> [Target Word]
- Skip-gram (중심 -> 주변): [Target Word] -> [Projection] -> [Context 1, Context 2]
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 말뭉치 입력  | --> | 윈도우 슬라이드| --> | 손실 최소학습| --> | 임베딩 저장  |
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **말뭉치 정제** — 텍스트 데이터를 토크나이징하고, 학습 효율을 떨어뜨리는 불용어($Stopwords$)를 필터링하여 사전 학습에 최적화함
2. **샘플쌍 구성** — 윈도우 크기를 설정하여 중심 단어와 주변 단어를 슬라이딩 윈도우 방식으로 움직이며 양방향 단어 쌍들을 조립함
3. **네거티브 최적화** — 전체 단어를 소프트맥스 연산하면 비용이 폭증하므로, 무작위 가짜 단어 몇 개만 뽑아 비교하는 네거티브 샘플링 기법을 활용하여 학습 비용을 크게 절감함
4. **차원 추출** — 학습이 종료되면 단어 벡터 테이블을 저장하여 하위 의사결정 태스크(질의 응답, 텍스트 분류 등)의 신경망 입력 임베딩 층으로 사용함

## Ⅵ. 실무 적용 및 유의점

1. 단어가 문맥에 따라 뜻이 완전히 달라지는 다의어(예: 먹는 '배', 타고 다니는 '배')가 혼용된 환경에서는 정적 임베딩을 쓰면 단어 의미가 평균화되어 모델이 혼란스러워하므로, 반드시 문맥을 실시간 반영하는 '동적 임베딩($ELMo, BERT$)'을 활용해야 함
2. 임베딩 모델 학습 시 사용된 원본 말뭉치($Corpus$)의 한계(예: 인터넷 비속어 노출)가 임베딩 공간의 사회적 편향(성별, 인종 차별)으로 투영될 수 있으므로, 임베딩 편향 완화 기법($Debiasing$)이나 철저한 데이터 필터링을 동반해야 함

## Ⅶ. 결론

- 단어 임베딩은 자연어의 차가운 정수 코드를 인간 지능의 풍부한 벡터 공간으로 번역하는 기틀이며, 설계자는 단어 간 의미 관계를 파악하기 위해 말뭉치의 데이터 품질과 다의어 여부에 따라 최적의 표현법을 설계해야 함
