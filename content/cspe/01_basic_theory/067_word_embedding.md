## 미리 알고가기

- 원-핫 인코딩: 단어 하나만 1이고 나머지는 0인 희소 벡터 표현임
- 밀집 벡터: 원-핫 벡터보다 낮은 차원의 실수값으로 의미를 표현하는 벡터임
- 분포 가설: 비슷한 문맥에 나오는 단어는 의미도 비슷하다는 가정임
- 코사인 유사도: 두 벡터의 방향 유사도를 측정하는 지표임
- 정적 임베딩: 한 단어가 문맥과 무관하게 하나의 벡터만 갖는 방식임
- 문맥·중심 단어 예측(CBOW·Skip-gram): 문맥으로 중심 단어를 예측하거나 중심 단어로 문맥을 예측하는 방식임
- 동시 출현 행렬: 단어 쌍이 같은 문맥에 등장한 횟수를 저장한 행렬임
- n-그램(n-gram): 연속된 $n$개 문자나 토큰으로 구성한 부분 문자열 단위임
- 미등록어(OOV): 학습 어휘에 없어 벡터를 직접 찾을 수 없는 단어임
- 통계·서브워드 임베딩(GloVe·FastText): 동시 출현 통계를 학습하는 방식과 서브워드 벡터를 합산하는 방식임

## 작성 근거(검토용)

- **방향성**: 단어 임베딩은 원-핫보다 저차원 밀집 벡터로 유사도 연산·저장 비용을 줄이는 대신 한 단어에 벡터 하나만 고정돼 다의어를 구분하지 못하므로, 미등록어 처리와 관계 표현 요구에 맞춰 Word2Vec·GloVe·FastText 중 하나를 선택해야 함
- **Ⅰ. 개요 구성**: 원-핫 한계를 배경으로 두어 임베딩의 필요성을 직접 설명함
- **Ⅱ. 특징 선정**: 유사도·차원·관계 표현과 다의어 한계를 서로 다른 판단 축으로 둠
- **Ⅲ. 비교축 선정**: 학습 메커니즘·미등록어 처리·주요 리스크는 세 방식의 고유 스펙이라 축은 유지하고, 관계 표현·미등록어 요구에 따른 선택 기준은 요약 문장의 구체적 분기 조건으로 명시함
- **Ⅳ. 구조 선정**: 말뭉치, 사전, 문맥 창, 학습 목표, 행렬로 임베딩 생성 구조를 구성함
- **Ⅴ. 절차 선정**: 토큰화부터 벡터 재사용까지 학습·활용 흐름을 단계화함
- **Ⅵ. 사례 선정**: 다의어 한계와 미등록어 대응은 정적 임베딩의 대표 적용 위험임
- **전수 검수**: 제목부터 결론까지 용어·표·도식·요약을 대조하고 미등록어 표기를 통일했으며 절 간 판단축을 일치시킴

## Ⅰ. 개요

- **정의/개념**: 단어 임베딩은 말뭉치의 문맥 관계를 학습해 단어를 원-핫 표현보다 낮은 차원의 밀집 벡터로 바꾸는 자연어 표현 기법임
- **배경/필요성**: 원-핫 벡터는 단어 간 의미 관계를 반영하지 못하므로 유사도를 연산할 벡터 표현이 필요함

### 쉽게 이해하기 (학습용)
- 이름표만 붙은 서랍(원-핫)이 아니라, 뜻이 비슷한 단어끼리 가까이 놓이는 지도 위 좌표(밀집 벡터)로 단어를 옮겨 놓는 것과 같음

## Ⅱ. 특징

- 분포 가설에 따라 주변 문맥이 비슷한 단어를 가까운 벡터로 학습하고 코사인 유사도로 비교함
- 희소 원-핫 벡터를 저차원 밀집 벡터로 바꿔 저장·연산 차원을 줄임
- 성별·시제처럼 말뭉치에서 반복되는 일부 관계를 벡터 차이로 표현함
- 정적 임베딩은 다의어를 문맥별로 구분하지 못함

### 쉽게 이해하기 (학습용)
- 비슷한 문장 자리에 자주 나오는 단어끼리 지도 위 가까운 곳에 놓고, 둘이 얼마나 닮았는지는 좌표가 가리키는 방향으로 비교함
- 단어마다 칸 하나만 켜지던 방대한 이름표 대신, 훨씬 작은 개수의 실수 좌표로 뜻을 담아 저장·계산 부담을 줄임
- 왕과 여왕처럼 반복되는 관계는 좌표 차이로도 어느 정도 드러남
- 한 단어에 좌표가 하나로 고정돼 있어, 문맥에 따라 뜻이 달라지는 단어는 구분하지 못함

## Ⅲ. 종류 및 비교

| 판단 기준 | Word2Vec | GloVe | FastText |
|:---|:---|:---|:---|
| 학습 메커니즘 | CBOW·Skip-gram | 동시 출현 행렬 근사 | 서브워드 n-gram 합산 |
| 미등록어 처리 | 직접 조회 불가 | 직접 조회 불가 | 서브워드 조합 |
| 주요 리스크 | 문맥 창 제한 | 행렬 저장 비용 | 서브워드 저장 비용 |

> 요약: 국소 문맥의 관계 유추가 중요하면 Word2Vec, 대규모 말뭉치의 전역 통계를 반영하려면 GloVe, 미등록어가 많은 도메인이면 FastText를 적용함.

### 쉽게 이해하기 (학습용)
- Word2Vec은 주변 단어를 보고 빈칸을 맞히는 퀴즈를 반복해 좌표를 익히고, GloVe는 어떤 단어끼리 얼마나 자주 같이 나왔는지 통계표를 보고 좌표를 맞추며, FastText는 단어를 조각내 두어 처음 보는 단어도 조각을 합쳐 좌표를 만들어냄

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 말뭉치 | 임베딩이 학습할 언어 사용 범위 |
| 토큰 사전 | 벡터를 부여할 단어 목록 |
| 문맥 창 | 중심 단어가 참조하는 주변 범위 |
| 학습 목표 | 주변 단어 예측·동시 출현 행렬 근사 |
| 임베딩 행렬 | 단어 ID별 밀집 벡터 저장소 |

> 요약: 단어 임베딩은 말뭉치의 문맥 관계를 학습해 단어별 밀집 벡터를 임베딩 행렬에 저장함.

### 쉽게 이해하기 (학습용)
- 많은 글(말뭉치)에서 다룰 단어 목록(사전)을 뽑고, 각 단어가 앞뒤로 어디까지 참고할지(문맥 창) 정한 뒤, 그 관계를 배우게 해(학습 목표) 결과를 단어별 서랍(임베딩 행렬)에 저장함

## Ⅴ. 원리 및 절차 흐름도

```text
말뭉치 토큰화 -> 쌍/통계 구축 -> 벡터 학습 -> 유사도 측정 -> 재사용
```

1. 말뭉치를 토큰화하고 저빈도 단어를 정리함
2. 문맥 창으로 중심 단어와 주변 단어 관계를 수집함
3. 예측 기반 또는 통계 기반 목표를 최적화함
4. 학습된 벡터 간 코사인 유사도로 의미적 거리를 측정함
5. 벡터를 분류, 검색, 군집화 입력으로 재사용함

> 요약: 임베딩 학습은 말뭉치 문맥 관계를 벡터 공간 거리로 옮기는 과정임.

### 쉽게 이해하기 (학습용)
- 글을 잘게 썰고, 어떤 단어가 어떤 단어 옆에 자주 나오는지 모은 뒤, 그 관계를 좌표로 옮겨 학습하고, 완성된 좌표 사이 거리로 뜻이 얼마나 비슷한지 재서 다른 작업에 다시 씀

## Ⅵ. 실무 사례

1. 검색 질의 확장은 임베딩에서 질의와 가까운 단어를 추가 검색어로 사용함
2. 미등록어가 많은 검색은 FastText의 서브워드 벡터로 단어 표현을 생성함

### 쉽게 이해하기 (학습용)
- 검색어와 좌표가 가까운 단어를 함께 찾아 검색 범위를 넓히고, 사전에 없는 단어는 조각으로 쪼개 비슷한 조각들을 합쳐 좌표를 만들어 냄

## Ⅶ. 결론

- 단어 임베딩은 저차원 벡터로 유사도 연산 비용을 줄이지만 한 단어에 벡터가 하나로 고정돼 다의어를 구분하지 못하므로, 미등록어 처리와 관계 표현 요구에 맞는 방식을 선택해야 함
- 임베딩 교체는 검색·분류 기준 자체를 바꾸므로 버전별 재현율·집단별 오류를 검증하고 색인과 모델을 함께 전환해야 함

### 쉽게 이해하기 (학습용)
- 뜻이 비슷한 단어를 가깝게 두지만 한 단어에 좌표가 하나뿐이라 문맥별 뜻은 구분 못하므로 상황에 맞는 방식을 골라야 함
- 단어 사이 거리로 뜻을 나타내는 지도를 새로 그리면 예전 지도를 보고 만든 검색·분류 결과와 어긋나므로, 지도를 바꿀 때는 결과를 다시 확인하고 관련 시스템도 함께 바꿔야 함
