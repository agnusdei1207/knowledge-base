## 미리 알고가기

- 원-핫 인코딩: 단어 하나만 1이고 나머지는 0인 희소 벡터 표현임
- 밀집 벡터: 원-핫 벡터보다 낮은 차원의 실수값으로 의미를 표현하는 벡터임
- 분포 가설: 비슷한 문맥에 나오는 단어는 의미도 비슷하다는 가정임
- 코사인 유사도: 두 벡터의 방향 유사도를 측정하는 지표임
- 정적 임베딩: 한 단어가 문맥과 무관하게 하나의 벡터만 갖는 방식임
- 문맥·중심 단어 예측(CBOW·Skip-gram): 문맥으로 중심 단어를 예측하거나 중심 단어로 문맥을 예측하는 방식임
- 동시 출현 행렬: 단어 쌍이 같은 문맥에 등장한 횟수를 저장한 행렬임
- n-그램(n-gram): 연속된 $n$개 문자나 토큰으로 구성한 부분 문자열 단위임
- 미등록어(OOV): 학습 어휘에 없어 벡터를 직접 찾을 수 없는 단어임
- 통계·서브워드 임베딩(GloVe·FastText): 동시 출현 통계를 학습하는 방식과 서브워드 벡터를 합산하는 방식임

## 작성 근거(검토용)

- 개요는 원-핫 한계를 배경으로 두어 임베딩의 필요성을 직접 설명함
- 유사도·차원·관계 표현과 다의어 한계를 함께 제시해 장단점의 균형을 맞춤
- Ⅲ은 Word2Vec·GloVe를 중심으로 FastText를 보조 비교해 OOV 판단 축을 추가함
- Ⅳ는 말뭉치, 사전, 문맥 창, 학습 목표, 행렬로 임베딩 생성 구조를 구성함
- 다의어 한계와 편향 전이는 정적 임베딩의 대표 적용 위험임

## Ⅰ. 개요

- **정의/개념**: 단어 임베딩은 말뭉치의 문맥 관계를 학습해 단어를 원-핫 표현보다 낮은 차원의 밀집 벡터로 바꾸는 자연어 표현 기법임
- **배경/필요성**: 원-핫 벡터는 단어 간 의미 관계를 반영하지 못하므로 유사도를 연산할 벡터 표현이 필요함

## Ⅱ. 특징

- 분포 가설에 따라 주변 문맥이 비슷한 단어를 가까운 벡터로 학습하고 코사인 유사도로 비교함
- 희소 원-핫 벡터를 저차원 밀집 벡터로 바꿔 저장·연산 차원을 줄임
- 성별·시제처럼 말뭉치에서 반복되는 일부 관계를 벡터 차이로 표현함
- 정적 임베딩은 다의어를 문맥별로 구분하지 못함

## Ⅲ. 종류 및 비교

| 판단 기준 | Word2Vec | GloVe | FastText |
|:---|:---|:---|:---|
| 학습 메커니즘 | CBOW·Skip-gram | 동시 출현 행렬 근사 | 서브워드 n-gram 합산 |
| 미등록어 처리 | 직접 조회 불가 | 직접 조회 불가 | 서브워드 조합 |
| 주요 리스크 | 문맥 창 제한 | 행렬 저장 비용 | 서브워드 저장 비용 |

> 요약: Word2Vec은 예측, GloVe는 통계, FastText는 서브워드 정보에 기반함.

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 말뭉치 | 임베딩이 학습할 언어 사용 범위 |
| 토큰 사전 | 벡터를 부여할 단어 목록 |
| 문맥 창 | 중심 단어가 참조하는 주변 범위 |
| 학습 목표 | 주변 단어 예측·동시 출현 행렬 근사 |
| 임베딩 행렬 | 단어 ID별 밀집 벡터 저장소 |

> 요약: 단어 임베딩은 말뭉치의 문맥 관계를 학습해 단어별 밀집 벡터를 임베딩 행렬에 저장함.

## Ⅴ. 원리 및 절차 흐름도

```text
말뭉치 토큰화 -> 쌍/통계 구축 -> 벡터 학습 -> 유사도 측정 -> 재사용
```

1. 말뭉치를 토큰화하고 저빈도 단어를 정리함
2. 문맥 창으로 중심 단어와 주변 단어 관계를 수집함
3. 예측 기반 또는 통계 기반 목표를 최적화함
4. 학습된 벡터 간 코사인 유사도로 의미적 거리를 측정함
5. 벡터를 분류, 검색, 군집화 입력으로 재사용함

> 요약: 임베딩 학습은 말뭉치 문맥 관계를 벡터 공간 거리로 옮기는 과정임.

## Ⅵ. 실무 사례

1. 검색 질의 확장은 Word2Vec과 FastText의 상위 검색 재현율·추론 시간을 비교함
2. 임베딩 기반 분류는 민감 단어 평가셋과 편향 완화를 적용하고 집단별 오류율로 검증함

## Ⅶ. 결론

- 단어 임베딩은 문맥 관계를 벡터 거리로 표현하며, 말뭉치의 범위와 문맥이 다른 같은 단어의 처리를 고려해야 함
- 임베딩 교체는 검색·분류 기준 자체를 바꾸므로 버전별 재현율·집단별 오류를 검증하고 색인과 모델을 함께 전환해야 함
