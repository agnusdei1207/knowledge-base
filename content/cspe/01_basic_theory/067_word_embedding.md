# 단어 임베딩 (Word Embedding)

## 1. 개요

- **정의/개념**: 단어 임베딩은 단어를 의미 관계가 반영된 저차원 밀집 벡터로 표현해 모델이 단어 간 유사성과 문맥 관계를 계산할 수 있게 하는 방법이다.
- **배경/필요성**: one-hot 표현은 차원이 크고 단어 간 의미 유사도를 표현하지 못하므로, 분포 가설에 기반한 연속 벡터 표현이 필요하다.

임베딩의 핵심은 단어를 ID가 아니라 의미 공간의 위치로 바꾸는 것이다.

## 2. 특징 및 비교

| 구분 | One-hot | Word2Vec/GloVe | Contextual Embedding |
|---|---|---|---|
| 표현 | 희소 벡터 | 정적 밀집 벡터 | 문맥별 동적 벡터 |
| 의미 유사도 | 반영 어려움 | 반영 가능 | 문맥 의미 반영 |
| 다의어 처리 | 불가 | 하나의 벡터 | 가능 |
| 대표 모델 | 단순 인덱스 | Word2Vec, GloVe | BERT 등 |

선택 기준은 데이터 규모, 문맥 민감도, OOV, downstream task, 계산 비용이다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| Corpus | 임베딩 학습 데이터 | 도메인 의미 반영 |
| Vocabulary | 학습 대상 단어 집합 | OOV 영향 |
| Context Window | 주변 단어 범위 | 의미 관계 학습 |
| Embedding Vector | 단어의 밀집 표현 | 유사도 계산 |
| Objective | CBOW, Skip-gram 등 | 학습 방식 |

```text
말뭉치 -> 토큰화 -> 문맥쌍 생성 -> 임베딩 학습 -> 벡터 활용
```

문맥에서 함께 등장하는 단어가 가까운 벡터를 갖도록 학습되므로, corpus 품질이 임베딩 품질로 직접 이어진다.

## 4. 문제점 및 개선방안

1. **다의어 표현 한계**
   - 정적 임베딩은 같은 단어를 항상 같은 벡터로 표현한다.
   - **개선방안**: BERT 같은 contextual embedding을 사용한다.

2. **도메인 불일치**
   - 일반 말뭉치 임베딩은 전문 용어 의미를 충분히 반영하지 못할 수 있다.
   - **개선방안**: 도메인 corpus로 재학습 또는 fine-tuning한다.

3. **편향 내재**
   - 학습 corpus의 사회적·업무적 편향이 벡터에 반영될 수 있다.
   - **개선방안**: bias evaluation, debiasing, downstream 검증을 수행한다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| 검색·추천 | 문서·상품명을 벡터화해 유사도 검색 | precision@k |
| 문서 분류 | 단어 임베딩을 모델 입력 feature로 사용 | F1, accuracy |
| 의미 분석 | 단어 간 유사도와 군집 구조 분석 | 유사도 품질 |

## 6. 결론

단어 임베딩은 단어를 의미 공간의 벡터로 바꾸어 NLP 모델이 유사도와 관계를 학습하게 한다. 밀집 벡터의 의미와 정적 임베딩의 한계를 함께 이해해야 BERT 같은 문맥 임베딩으로의 발전 흐름이 자연스럽게 연결된다.
