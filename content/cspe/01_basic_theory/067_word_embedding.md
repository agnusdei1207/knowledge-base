## Ⅰ. 개요
- 정의: 단어를 고차원의 밀집 벡터(Dense Vector)로 변환하여 의미적 유사도를 표현하는 기술임.
- 배경: 원-핫 인코딩의 희소성(Sparsity) 및 차원의 저주 문제를 해결하기 위함임.
- 출제 의도:
| 분류 | 상세 |
| --- | --- |
| 핵심요소 | 분포 가설, CBOW, Skip-gram, 동시 출현 행렬 |
| 주요특징 | 의미 보존, 연산 가능(King-Man+Woman=Queen) |

## Ⅱ. 구성요소
- ASCII 구조도
 [Input: Word] -> [Hidden Layer] -> [Output: Context/Target]
     (One-hot)       (Embedding)      (Probability)
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| Word2Vec | 주변 단어를 통해 타겟 단어를 예측하며 학습 | 근묵자흑 |
| CBOW | 주변 단어들로 중앙의 단어를 예측 | 빈칸 채우기 |
| Skip-gram | 중앙의 단어로 주변의 단어들을 예측 | 파급 효과 |
> 요약: 단어의 문맥 정보를 수치 벡터로 압축하여 표현함.

## Ⅲ. 절차
- ASCII 흐름도
[코퍼스 확보] -> [윈도우 설정] -> [가중치 학습] -> [벡터 추출]
- 4단계 설명
1. 데이터셋 구축: 대량의 텍스트 말뭉치를 준비함.
2. 슬라이딩 윈도우: 특정 범위 내의 단어 쌍을 샘플링함.
3. 신경망 학습: 입력층과 은닉층 사이의 가중치를 업데이트함.
4. 벡터 행렬 저장: 학습된 은닉층의 값을 단어 벡터로 사용함.
> 요약: 문맥 내 단어 출현 빈도와 확률을 학습하여 벡터화함.

## Ⅳ. 문제점
- 단어의 순서 정보가 무시되며 문맥에 따른 중의성 처리가 불가함.

## Ⅴ. 개선방안
- 단기: FastText를 사용하여 단어 내부 정보를 반영함.
- 중기: GloVe와 같이 전역 통계 정보와 지역 문맥 정보를 결합함.
- 장기: ELMo나 BERT 같은 동적 임베딩(Contextual) 모델로 전환함.

## Ⅵ. 전망
- 검색 엔진, 챗봇, 감성 분석 등 모든 NLP 태스크의 기반 기술로 동작함.
