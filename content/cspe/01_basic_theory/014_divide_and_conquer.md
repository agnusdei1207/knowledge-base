## Ⅰ. 개요
- **정의**: 문제를 독립적인 부분 문제로 분할하고 재귀적으로 해결한 뒤 병합하는 알고리즘 설계 기법
- **배경/필요성**: 큰 문제를 한 번에 풀기 어려울 때, 작은 문제로 나누면 각각의 풀이가 단순해지고 전체 시간 복잡도가 줄어듦
- **비유**: 큰 짐을 여러 상자로 나눠 담고, 각 상자를 정리한 뒤 다시 합치는 이사 작업

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 분할-정복-병합 3단계와 마스터 정리 | 부분 문제가 독립적(중복 없음) | DP(013)와의 차이: 부분 문제 중복 유무 |

> 요약: 독립 부분 문제로 분할하여 재귀 해결 후 병합하는 설계 전략임

## Ⅱ. 구성요소
```text
  +---------------------+
  |  Divide and Conquer  |
  +---------+-----------+
            |
   +--------+--------+-----------+
   |                 |           |
   v                 v           v
  Divide           Conquer     Combine
  (문제 분할)     (재귀 해결)  (결과 병합)
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| Divide | 원래 문제를 같은 유형의 부분 문제 a개로 분할함 | 카드 더미를 절반씩 나누는 것 |
| Conquer | 부분 문제가 충분히 작으면 직접 풀고, 아니면 재귀 호출함 | 카드 몇 장이면 손으로 정렬하는 것 |
| Combine | 부분 문제의 해를 합쳐 원래 문제의 해를 구성함 | 정렬된 두 카드 더미를 하나로 합치는 것 |

> 요약: Divide-Conquer-Combine 3단계가 분할 정복의 골격이며, 부분 문제는 서로 독립적임

## Ⅲ. 절차
```text
  분할(Divide)     정복(Conquer)    병합(Combine)    복잡도 분석
  (크기 축소)     (재귀/기저)     (결과 통합)     (마스터 정리)
   |               |               |               |
   +---n/b 분할--->+---a개 재귀--->+---f(n) 병합-->+
  n -> n/b        T(n/b) x a     부분해 통합     T(n)=aT(n/b)+f(n)
```
- 1단계: 크기 n인 문제를 크기 n/b인 부분 문제 a개로 분할함
- 2단계: 각 부분 문제를 재귀적으로 해결하고, 기저 조건에 도달하면 직접 풀이함
- 3단계: 부분 문제의 해를 병합하여 원래 문제의 해를 구성함 (비용 f(n))
- 4단계: 마스터 정리 $T(n) = aT(n/b) + f(n)$으로 전체 시간 복잡도를 분석함

> 요약: 분할-재귀-병합 후 마스터 정리로 복잡도를 도출하는 4단계 절차임

## Ⅳ. 문제점
- 병합 비용 지배: 병합 단계의 비용 f(n)이 크면 분할의 이점이 상쇄됨 (예: 행렬 곱셈의 덧셈 비용)
- 재귀 오버헤드: 함수 호출 스택이 깊어지면 메모리 사용량과 호출 비용이 증가함
- 불균형 분할: 피벗 선택이 편향되면 부분 문제 크기가 불균등하여 최악 시간 복잡도가 증가함 (QuickSort 최악 O(n^2))

> 요약: 병합 비용, 재귀 스택, 불균형 분할이 분할 정복의 주요 한계임

## Ⅴ. 개선방안
1. 단기: Strassen 등 병합 비용을 줄이는 알고리즘을 적용하여 f(n)을 감소시킴
2. 중기: 꼬리 재귀 최적화 또는 반복문 전환으로 스택 오버헤드를 제거함
3. 장기: 중앙값 피벗(Median-of-3), 랜덤 피벗 등으로 분할 균형을 보장하여 최악 복잡도를 회피함

> 요약: 병합 최적화, 반복 전환, 균형 분할 전략으로 한계를 극복함

## Ⅵ. 전망
- 발전 방향: 병렬 컴퓨팅에서 독립 부분 문제를 멀티코어에 분배하는 fork-join 모델로 확장됨
- 기술사적 판단: DP(013)와의 차이(부분 문제 중복 유무)를 명확히 구분하는 것이 출제 빈출 포인트임
- 기술사 제언: 마스터 정리의 세 가지 경우를 숙지하고, 대표 알고리즘별 a, b, f(n) 값을 즉시 대입할 수 있도록 준비할 것을 권고함
