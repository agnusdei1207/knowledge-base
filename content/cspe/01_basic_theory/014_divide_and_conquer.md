## 미리 알고가기

- 분할(Divide): 큰 문제를 같은 성질의 작은 문제로 나누는 과정임
- 정복(Conquer): 부분 문제를 같은 방법으로 풀거나 종료 조건에서 직접 답을 내는 과정임
- 결합(Combine): 부분 해를 합쳐 원래 문제의 해를 만드는 과정임
- 종료 조건(Base Case): 더 분할하지 않고 답을 직접 구하는 최소 입력 조건임
- 점화식: 하위 문제 수·축소 비율·결합 비용으로 전체 비용을 표현한 식임
- 상태 폭발: DP의 상태 변수·범위가 늘어 계산할 상태 수와 메모리가 급증하는 현상임

## 작성 근거(검토용)

- **개요 구성**: 분할 정복의 정의는 분할·정복·결합의 세 동작으로 충분하므로 이 흐름을 첫 문장에 배치함
- **Ⅱ. 특징 선정**: 독립성, 분할 균형, 결합 비용, 점화식은 성능 분석에 직접 필요한 요소라 남김
- **Ⅲ 비교축 선정**: 분할 정복과 DP의 동작 메커니즘·계산 비용·주요 리스크만 남겨 선택 기준을 압축함
- **Ⅳ 구조 선정**: 분할 기준부터 결합 연산까지 재귀 구조를 만드는 요소만 남겨 답안 흐름을 줄임
- 중복 부분 문제와 불균형 분할은 실행 비용을 증가시키는 대표 조건이라 남김

## Ⅰ. 개요

- **정의/개념**: 분할 정복은 큰 문제를 독립적인 동일 구조의 부분 문제로 나누고 부분 해를 결합해 전체 해를 구하는 설계 기법임
- **배경/필요성**: 큰 입력의 재귀 비용을 예측하기 위해 분할 균형과 결합 비용을 함께 분석해야 함

## Ⅱ. 특징

- 부분 문제가 독립적이면 공유 상태 없이 각 부분 문제를 동시에 실행할 수 있음
- 분할이 불균형하면 재귀 깊이와 최악 시간이 커짐
- 결합 비용이 하위 문제 비용을 지배하면 분할에 따른 계산량 감소가 제한됨
- 비용은 보통 $T(n)=aT(n/b)+f(n)$ 형태로 분석함

## Ⅲ. 종류 및 비교

| 판단 기준 | 분할 정복 (Divide & Conquer) | 동적 계획법 (DP) |
|:---|:---|:---|
| 동작 메커니즘 | 독립 부분 문제 분할·재귀·결합 | 중복 상태 저장·점화식 재사용 |
| 계산 비용 | 재귀 깊이 + 결합 비용 | 상태 수 × 상태별 계산 비용 |
| 주요 리스크 | 불균형 분할 | 상태 폭발 |

> 요약: 부분 문제가 독립적이면 재귀 분할·결합하는 분할 정복을, 같은 상태가 반복되면 저장·재사용하는 동적 계획법을 선택함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 핵심 설명 |
|:---|:---|
| 분할 기준 | 입력을 같은 구조의 부분 문제로 나누는 기준 |
| 종료 조건 | 재귀 없이 답을 반환하는 최소 입력 |
| 정복 로직 | 각 부분 문제에 적용하는 동일 알고리즘 |
| 결합 연산 | 부분 해를 원래 문제의 해로 합치는 연산 |

> 요약: 분할 정복은 입력을 종료 조건까지 부분 문제로 나누고 각 해를 결합해 원래 문제의 해를 생성함.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------------+     +----------------+     +----------------+     +----------------+
| 종료 조건 확인 | --> | 부분 문제 분할 | --> | 부분 문제 해결 | --> | 부분 해 결합 |
+----------------+     +----------------+     +----------------+     +----------------+
```

1. **종료 조건 확인**: 입력이 최소 처리 단위이면 답을 직접 반환함
2. **부분 문제 분할**: 같은 구조의 작은 문제로 나누고 크기 균형을 맞춤
3. **부분 문제 해결**: 각 부분 문제에 같은 알고리즘을 적용함
4. **부분 해 결합**: 각 부분 문제의 결과를 원래 문제의 답으로 합침

> 요약: 분할 정복은 종료 조건까지 문제를 재귀 분할하고 부분 해를 결합해 원래 문제의 해를 구함.

## Ⅵ. 실무 사례

1. 병합 정렬은 부분 배열을 재귀 정렬·병합하고 실행 시간·추가 메모리를 확인함
2. 퀵 정렬은 피벗 무작위화로 편향 분할을 줄이고 최대 재귀 깊이·스택 사용량을 확인함

## Ⅶ. 결론

- 분할 정복은 독립 부분 문제를 재귀로 나눌 수 있을 때 적용하고 분할 균형·결합 비용·재귀 깊이로 성능을 판단해야 함
