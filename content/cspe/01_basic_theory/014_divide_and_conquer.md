# 분할 정복 (Divide and Conquer)

## 1. 개요

- **정의/개념**: 분할 정복은 큰 문제를 독립적인 하위 문제로 나누어 해결한 뒤, 부분 해를 결합해 전체 해를 구하는 알고리즘 설계 기법이다.
- **배경/필요성**: 큰 입력을 한 번에 처리하면 비용이 커지는 문제가 많으므로, 문제를 작은 단위로 쪼개 재귀적으로 처리하고 결합해 효율을 높인다.

## 2. 특징 및 비교

| 구분 | 분할 정복 | 동적 프로그래밍 | 탐욕 알고리즘 |
|---|---|---|---|
| 부분 문제 관계 | 독립적 | 중복됨 | 부분 문제보다 선택 중심 |
| 핵심 연산 | 분할, 정복, 결합 | 상태 저장, 점화식 | 국소 최선 선택 |
| 대표 예 | 병합 정렬, 퀵 정렬, 이진 탐색 | 배낭, LCS | MST, 허프만 |
| 주의점 | 분할 균형, 결합 비용 | 상태 폭발 | 정당성 증명 |

분할 정복은 부분 문제가 서로 겹치지 않고 결합 구조가 명확할 때 적합하다.

분할 정복의 핵심 판단 차원은 하위 문제 독립성, 분할 균형, 결합 비용, 재귀 깊이, 병렬 처리 가능성이다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| 분할(Divide) | 문제를 작은 하위 문제로 나눔 | 균형 분할 |
| 정복(Conquer) | 하위 문제를 재귀적으로 해결 | 기저 조건 |
| 결합(Combine) | 부분 해를 합쳐 전체 해 구성 | 결합 비용 |
| 기저 조건 | 더 이상 나누지 않는 최소 문제 | 종료 보장 |

```text
큰 문제 -> 하위 문제 분할 -> 재귀 해결 -> 부분 해 결합 -> 전체 해
```

## 4. 문제점 및 개선방안

1. **불균형 분할**
   - 입력이 한쪽으로 치우치면 재귀 깊이가 커지고 시간복잡도가 악화된다.
   - **개선방안**: 무작위 피벗, 균형 분할 기준, 최대 재귀 깊이 제한을 적용한다.

2. **결합 비용 과소평가**
   - 하위 문제를 빨리 풀어도 결합 단계가 병목이 될 수 있다.
   - **개선방안**: 재귀식에 결합 비용을 명시하고 병합 자료구조를 최적화한다.

3. **중복 부분 문제 방치**
   - 같은 하위 문제가 반복되면 불필요한 재계산이 발생한다.
   - **개선방안**: 중복이 확인되면 메모이제이션 또는 DP로 전환한다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| 대용량 정렬 | 병합 정렬·퀵 정렬로 데이터를 분할 처리 | 처리 시간, 재귀 깊이 |
| 병렬 처리 | 독립 블록을 분할해 병렬 실행 후 결과 병합 | 병렬 효율, 결합 비용 |
| 검색 문제 | 정렬 데이터에서 이진 탐색으로 후보 절반 제거 | 비교 횟수, 응답 지연 |

## 6. 결론

분할 정복은 큰 문제를 독립 하위 문제로 나누어 해결하는 기본 설계 전략이다. 성능은 분할 균형, 기저 조건, 결합 비용, 재귀 깊이에 의해 결정되며, 부분 문제가 겹치면 DP와 구분해 적용해야 한다.
