## Ⅰ. 개요
- 해결하기 어려운 문제를 작은 하위 문제로 분할하여 각각 해결하는 기법임.
- 하위 문제 간의 중복이 없는 경우에 주로 사용하며 재귀가 핵심임.
- [표] 출제 의도: 대형 문제의 구조적 분해 및 재귀적 해결 능력 평가.

## Ⅱ. 구성요소
- ASCII 구조도
  [ Big Problem ]
      /      \
  [ Sub1 ]  [ Sub2 ] -> Conquer -> [ Combined Result ]

| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| Divide | 문제를 더 이상 쪼갤 수 없을 때까지 분할 | 팀별 업무 분담 |
| Conquer | 가장 작은 단위의 문제를 직접 해결 | 개인 과제 수행 |
| Combine | 하위 문제의 해를 합쳐 전체 해를 만듦 | 결과물 취합 |

> 요약: 직접 해결 가능한 수준까지 쪼개어 정복하고 합침.

## Ⅲ. 절차
- ASCII 흐름도
  Divide -> Conquer(Recursive) -> Base Case Check -> Combine

1. 원래 문제를 동일한 형태의 작은 하위 문제들로 나눔.
2. 각 하위 문제를 재귀적으로 해결(Conquer)함.
3. 하위 문제가 충분히 작으면(Base Case) 직접 값을 반환함.
4. 얻어진 하위 문제의 해들을 결합하여 전체 해를 산출함.

> 요약: 하향식(Top-down) 접근으로 문제를 단순화하여 해결함.

## Ⅳ. 문제점
- 재귀 호출 오버헤드로 인해 n이 작을 때는 일반 반복문보다 느림.
- 중복되는 하위 문제가 있을 경우 DP에 비해 매우 비효율적임.

## Ⅴ. 개선방안
- 단기: 임계값(Threshold) 설정으로 소규모 데이터는 반복문 처리함.
- 중기: 메모이제이션과 결합하여 중복 계산 방지(DP적 요소 가미)함.
- 장기: 멀티코어 환경에서 하위 문제들을 병렬 처리하여 속도 향상함.

## Ⅵ. 전망
- 빅데이터 분산 처리 모델인 MapReduce의 논리적 기반으로서, 하드웨어 계층(CPU/GPU/FPGA)에 맞게 문제를 자동 분할하는 컴파일러 기술이 CSF로 부상할 것임.
- 초거대 AI 모델의 분산 학습 과정에서 파라미터를 효율적으로 쪼개고 결합하는 분할 정복 기반의 모델 병렬화 기술이 인공지능 인프라의 핵심이 될 전망임.
- 양자 알고리즘과 결합하여 기존 고속 푸리에 변환(FFT)의 한계를 넘는 초고속 신호 처리 기법이 6G 및 초정밀 계측 분야에서 혁신을 주도할 것임.
