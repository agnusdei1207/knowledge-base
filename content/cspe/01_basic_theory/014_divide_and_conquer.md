## 미리 알고가기

- 분할(Divide): 큰 문제를 동일한 구조의 작은 문제로 나누는 과정임
- 재귀 호출(Recursive Call): 처리 함수가 크기가 줄어든 부분 문제를 입력으로 자기 자신을 다시 호출하는 동작임
- 정복(Conquer): 각 부분 문제에 같은 함수를 다시 호출하고, 종료 조건에 도달하면 답을 직접 반환하는 과정임
- 결합(Combine): 부분 해를 합쳐 원래 문제의 해를 만드는 과정임
- 종료 조건(Base Case): 더 분할하지 않고 답을 직접 구하는 최소 입력 조건임
- 점화식: 부분 문제 수·입력 축소 비율·분할 및 결합 비용으로 전체 비용을 표현한 식임
- 상태 공간 폭발(State-space Explosion): 동적 계획법에서 상태 변수와 값의 범위가 증가하여 계산·저장할 상태 수가 조합적 또는 지수적으로 증가하는 현상임
- 동적 계획법(DP): 반복되는 부분 문제의 답을 저장·재사용하는 알고리즘 설계 기법임

## 작성 근거(검토용)

- **개요 구성**: 분할 정복의 정의는 분할·정복·결합의 세 동작으로 충분하므로 이 흐름을 첫 문장에 배치함
- **Ⅱ. 특징 선정**: 입력 축소를 동반한 동일 알고리즘 반복, 병렬 처리 가능성, 점화식은 분할 정복의 동작과 분석 방법을 설명하므로 남김
- **Ⅲ. 비교축 선정**: 분할 정복과 동적 계획법의 부분 문제 관계·처리 방식·저장 대상을 비교해 선택 기준을 드러냄
- **Ⅳ. 설계 요소 선정**: 절차와 중복되는 분할·정복·결합 나열을 제거하고 부분 문제 독립성·분할 균형도·종료 조건·결합 비용을 설계 판단 기준으로 배치함
- **Ⅴ. 절차 구성**: 종료 조건의 분기와 부분 해의 반환·결합을 표시하여 호출과 반환 방향을 구분함

## Ⅰ. 개요

- **정의/개념**: 분할 정복은 큰 문제를 서로 독립적인 부분 문제로 나누어 해결하고, 부분 해를 결합해 전체 해를 구하는 설계 기법임
- **배경/필요성**: 문제 전체를 직접 해결하기 어렵더라도 동일한 구조의 작은 문제는 해결 가능한 경우, 부분 해로 전체 해를 구성하는 접근이 필요함

## Ⅱ. 특징

- 동일한 알고리즘을 크기가 줄어든 부분 문제에 반복 적용하고 종료 조건에서 부분 해를 반환함
- 부분 문제가 독립적이면 공유 상태 없이 병렬 처리할 수 있음
- 크기 $n/b$인 부분 문제 $a$개로 나누면 시간복잡도는 $T(n)=aT(n/b)+f(n)$으로 표현함

## Ⅲ. 동적 계획법과 비교

| 판단 기준 | 분할 정복 (Divide & Conquer) | 동적 계획법 (DP) |
|:---|:---|:---|
| 부분 문제 관계 | 부분 문제 사이의 계산 결과가 중복되지 않음 | 동일한 부분 문제가 여러 계산 경로에서 반복됨 |
| 처리 방식 | 각 부분 문제를 별도로 해결한 뒤 부분 해를 결합 | 계산한 상태값을 저장하고 동일 상태에서 재사용 |
| 저장 대상 | 호출 경로와 부분 해 | 상태별 계산 결과를 저장한 메모이제이션·테이블 |

> 요약: 부분 문제가 독립적이면 분할 정복을, 같은 부분 문제가 반복되면 동적 계획법을 선택함.

## Ⅳ. 설계 요소 및 성능 결정 기준

| 설계 요소 | 설명 |
|:---|:---|
| 부분 문제 독립성 | 부분 문제 해결 과정의 상호 비의존성 |
| 분할 균형도 | 분할된 부분 문제의 입력 크기가 서로 비슷한 정도 |
| 종료 조건 | 입력 크기가 직접 계산 가능한 최소 단위에 도달한 상태 |
| 결합 비용 | 부분 해를 전체 해로 합칠 때 추가되는 실행 시간과 저장 공간 |

> 요약: 부분 문제의 독립성으로 적용 가능성을 확인하고 분할 균형도·종료 조건·결합 비용으로 실행 비용을 판단함.

## Ⅴ. 원리 및 절차 흐름도

```text
----------------+   충족   +----------------+
| 종료 조건 확인 | -------> | 직접 계산·반환 |
+----------------+          +----------------+
        | 미충족                    |
        v                           | 부분 해 반환
+----------------+     +----------------+     +----------------+
| 부분 문제 분할 | --> | 동일 함수 호출 | --> | 부분 해 결합·반환 |
+----------------+     +----------------+     +----------------+
```

1. **종료 조건 확인**: 입력이 직접 계산할 크기이면 답을 구해 호출한 함수로 반환함
2. **부분 문제 분할**: 종료 조건을 충족하지 않으면 입력을 동일한 구조의 작은 문제로 나눔
3. **동일 함수 호출**: 크기가 줄어든 각 부분 문제를 입력으로 같은 처리 함수를 호출함
4. **부분 해 결합·반환**: 각 호출이 반환한 부분 해를 합쳐 현재 문제의 답을 만들고 상위 호출로 반환함

> 요약: 종료 조건까지 입력 크기를 줄여 동일 함수를 호출하고, 반환되는 부분 해를 호출의 역순으로 결합하여 전체 해를 구함.

## Ⅵ. 실무 사례

1. 대용량 파일 정렬은 병합 정렬로 데이터를 분할 처리하고 병합 I/O와 임시 저장공간을 확인함
2. 퀵 정렬은 피벗 무작위화로 편향 분할을 줄이고 최대 연속 호출 횟수와 호출 스택 사용량을 확인함

## Ⅶ. 결론

- 분할 정복은 독립 부분 문제에 적용하고 분할 균형도와 결합 비용으로 시간·공간 복잡도를 판단해야 함
