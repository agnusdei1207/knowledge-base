## Ⅰ. 개요

- **정의**: 분할 정복(Divide and Conquer)은 문제를 동일 구조의 독립적 부분 문제로 분할(Divide)하고 재귀적으로 정복(Conquer)한 뒤 결합(Combine)하는 알고리즘 설계 패러다임임
- **배경/필요성**: 문제를 그대로 완전 탐색하거나 순차 처리하면 연산량이 크기에 비례해 급증하므로, 문제를 절반씩 줄여나가는 재귀 구조로 전체 복잡도의 차수 자체를 낮출 필요가 있음
- **출제 의도**: 분할-정복-결합 3단계 구조와 재귀 트리 분석 능력, Master Theorem을 통한 복잡도 도출 능력, DP·탐욕과 구분하는 판단 기준 확인
- **답안 방향**: 구조(3단계+Master Theorem) -> 동작(재귀 흐름) -> 특징 -> DP 대비 선택 기준 -> 실무 적용 순으로 전개함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 분할 정복 패러다임의 구조·복잡도 분석 서술 요구 | 3단계 구조, 재귀식 $T(N)=aT(N/b)+f(N)$, Master Theorem 판정, DP와의 부분 문제 독립성 차이 | 구체 알고리즘(정렬·탐색) 세부 재설명, DP와의 차이 누락, 복잡도 근거 없는 단정 |

> 요약: 분할 정복 답안은 3단계 구조와 재귀식 분석을 먼저 못박고, 그 위에서 DP와의 독립성/중복 차이를 논증해야 함.

## Ⅱ. 구조 및 구성요소

```text
문제(크기 N)
  -> Divide: 문제를 a개의 부분 문제(크기 N/b)로 분할
      |
   +--+--+--+
   |  |  |  |
 [N/b][N/b] ... [N/b]      (부분 문제는 서로 독립적 -> 겹치면 DP, 013 참조)
   |  |  |  |
  Conquer: 각 부분 문제를 재귀 호출로 해결 (기저 조건 충족 시 즉시 해결)
   |  |  |  |
   +--+--+--+
      |
  Combine: 부분 해를 결합해 전체 해 도출
      |
      v
  전체 해(크기 N 문제의 답)

재귀식: T(N) = a*T(N/b) + f(N)   (a=부분 문제 수, b=분할 비율, f(N)=Divide+Combine 비용)
Master Theorem 판정: f(N)과 N^log_b(a)의 크기 비교로 Case 1(잎 지배)/Case 2(균형)/Case 3(결합 지배) 결정
```

| 구성요소 | 역할 | 산출물/비고 |
|:---|:---|:---|
| Divide | 문제를 a개의 독립적 부분 문제로 분할 | 병합 정렬은 배열 이등분, 이진 탐색(004)은 탐색 범위 이등분 |
| Conquer | 부분 문제를 재귀적으로 해결 | 기저 조건 미충족 시 동일 알고리즘을 재호출 |
| Combine | 부분 해를 결합해 전체 해 생성 | 병합 정렬은 merge 연산으로 결합, 이진 탐색은 단일 경로라 결합 불필요 |
| 기저 조건(Base Case) | 재귀 종료 조건 | 크기 0~1인 부분 문제는 해가 자명해 즉시 반환 |
| Master Theorem | $T(N)=aT(N/b)+f(N)$의 닫힌 형태 해 도출 도구 | 구현 전에 복잡도 차수를 수식으로 사전 판정 |

> 요약: Divide·Conquer·Combine이 재귀의 뼈대를 이루고, 기저 조건이 재귀를 종료시키며, Master Theorem이 이 구조의 복잡도를 판정함.

## Ⅲ. 동작원리 및 흐름도

```text
문제(크기 N) -> 기저조건 판별
                  |
        충족(크기<=임계값)          미충족
            |                          |
        즉시 해 반환               Divide: N/b 크기 부분 문제 a개 생성
                                       |
                                   Conquer: 각 부분 문제에 1단계부터 재귀 호출
                                       |
                                   Combine: 반환된 부분 해를 결합
            |                          |
            +----------> 해 반환 <-----+
```

- 1단계(기저조건 판별): 문제 크기가 임계값(보통 1) 이하인지 확인하고, 충족하면 재귀를 종료하고 자명한 해를 반환함
- 2단계(Divide): 미충족 시 문제를 a개의 독립적 부분 문제(크기 N/b)로 분할함
- 3단계(Conquer): 각 부분 문제에 1단계부터 동일 알고리즘을 재귀 호출함(재귀 트리의 각 레벨에서 반복)
- 4단계(Combine): 재귀 호출이 반환한 부분 해를 결합해 상위 레벨의 해를 구성하며, 이 결합 비용이 재귀식의 $f(N)$으로 누적됨

> 요약: 기저조건 판별 -> Divide -> Conquer(재귀) -> Combine의 순서로 진행되며, 각 레벨의 Divide+Combine 비용 합이 전체 복잡도를 결정함.

## Ⅳ. 특징

- 부분 문제 독립성: 부분 문제가 서로 겹치지 않아 이전 계산 결과를 저장할 필요가 없음(013 DP는 겹치는 부분 문제를 메모이제이션으로 재사용한다는 점이 근본적 차이임)
- 복잡도 예측 가능성: 재귀식 $T(N)=aT(N/b)+f(N)$을 Master Theorem에 대입하면 구현 전에 닫힌 형태의 복잡도(예: Case 1의 Strassen 곱셈 $\Theta(N^{2.81})$, Case 2의 병합 정렬 $\Theta(N\log N)$)를 도출할 수 있음
- 병렬화 적합성: 부분 문제가 독립적이므로 각각을 별도 스레드·프로세스·노드에 배분해 동시에 처리할 수 있음(MapReduce의 Map 단계가 대표적 구현임)
- 분할 균형 의존성: 분할이 균등하지 않으면(예: 퀵 정렬의 편향된 피벗) 재귀식의 $a$, $b$ 값이 왜곡되어 이론적 복잡도가 무너짐

> 요약: 독립적 부분 문제 구조가 복잡도 예측과 병렬화라는 두 가지 이점을 만들지만, 분할 균형이 깨지면 이 이점이 사라짐.

## Ⅴ. 심화 비교 및 적용 판단

| 판단 기준 | 분할 정복 | DP | 선택 기준 |
|:---|:---|:---|:---|
| 부분 문제 관계 | 독립적(Non-overlapping) | 중복(Overlapping) | 같은 부분 문제가 재계산되면 DP로 전환 |
| 저장 필요성 | 불필요(재귀만으로 충분) | 필수(메모이제이션·테이블) | 저장 비용 감당 가능 여부로 판단 |
| 복잡도 분석 도구 | Master Theorem(닫힌 형태) | 상태 수 x 전이 비용 직접 계산 | 재귀식이 단순하면 Master Theorem 우선 적용 |
| 병렬화 | 부분 문제 독립으로 용이 | 상태 간 의존으로 제한적 | 대규모 병렬 처리가 필요하면 분할 정복 우선 검토 |

> 요약: 부분 문제가 겹치지 않으면 분할 정복, 겹치면 DP로 전환해야 하며(013 참조), 이 판단이 알고리즘 설계의 첫 분기점임.

**리스크·대응 (불릿):**
- 겹치는 부분 문제에 분할 정복 적용: 순수 재귀로 구현하면 동일 부분 문제가 반복 계산되어 지수적으로 폭증함 -> 재귀 호출 인자의 중복 여부를 사전 검증하고 중복되면 DP로 전환 (지표: 동일 인자 재귀 호출 횟수)
- 불균형 분할로 인한 성능 퇴화: 분할 비율이 극단적으로 치우치면 재귀식의 실질 부담이 커져 최악 복잡도가 상승함(003 퀵 정렬의 피벗 편향 참조) -> 랜덤화·중앙값 기반 분할 기준 적용으로 대응 (지표: 최악 케이스 실행 시간)
- Combine 비용 과소평가: $f(N)$이 분할 이점보다 커지면 전체 이득이 상쇄됨 -> Master Theorem으로 $f(N)$을 포함한 사전 분석 수행 (지표: 결합 단계 실행 시간 비중)

**도입 후 점검 지표 (불릿):**
- 복잡도 검증: 실측 실행 시간이 Master Theorem이 예측한 차수(Case 1/2/3)에 수렴하는지 벤치마크로 확인
- 병렬 확장성: 부분 문제 수(워커 수) 증가에 따라 처리 시간이 선형에 가깝게 단축되는지 측정(예: 분산 처리 노드 수 대비 처리 시간)

## Ⅵ. 실무 적용 및 결론

1. 단기: 대상 문제의 부분 문제가 독립적인지(분할 정복) 겹치는지(DP) 진단하고 적합한 패러다임을 선정함
2. 중기: Master Theorem으로 재귀식을 분석해 목표 복잡도 충족 여부를 사전 검증하고, 분할 균형을 보장하는 피벗·기준 선택 로직을 구현함
3. 장기: 독립적 부분 문제 구조를 병렬·분산 처리로 확장해 데이터 규모 증가에 대응하는 아키텍처를 운영함

- 기술사적 판단: 부분 문제의 독립성 여부가 분할 정복과 DP를 가르는 첫 번째 기준이며, 이 판단을 잘못하면 지수적 재계산(겹치는데 분할 정복 사용) 또는 불필요한 메모리 사용(독립적인데 DP 사용)이 발생함
- 기술사 제언: 재귀식 $T(N)=aT(N/b)+f(N)$과 Master Theorem 판정 결과를 설계 문서에 명시해, 이후 알고리즘 교체·최적화 시 판단 근거로 재사용함
