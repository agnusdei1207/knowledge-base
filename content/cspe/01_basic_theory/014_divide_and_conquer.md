## 미리 알고가기

- 분할(Divide): 큰 문제를 같은 성질의 작은 문제로 나누는 과정임
- 정복(Conquer): 부분 문제를 같은 방법으로 풀거나 기저 사례에서 직접 답을 내는 과정임
- 결합(Combine): 부분 해를 합쳐 원래 문제의 해를 만드는 과정임
- 기저 사례: 더 분할하지 않고 바로 처리하는 최소 입력 조건임
- 점화식: 하위 문제 수·축소 비율·결합 비용으로 전체 비용을 표현한 식임

## 작성 근거(검토용)

- **개요 구성**: 분할 정복의 정의는 분할·정복·결합의 세 동작으로 충분하므로 이 흐름을 첫 문장에 배치함
- **Ⅱ. 특징 선정**: 독립성, 분할 균형, 결합 비용, 점화식은 성능 분석에 직접 필요한 요소라 남김
- **Ⅲ 비교축 선정**: DP와 혼동하기 쉬워 부분 문제 관계·처리 방식·비용 기준을 비교축으로 삼음
- **Ⅳ 구조 선정**: 분할 기준부터 결합 연산까지 재귀 구조를 만드는 요소만 남겨 답안 흐름을 줄임
- 중복 부분 문제와 불균형 분할은 실행 비용을 증가시키는 대표 조건이라 남김

## Ⅰ. 개요

- **정의/개념**: 분할 정복은 큰 문제를 독립적인 동일 구조의 부분 문제로 나누고 부분 해를 결합해 전체 해를 구하는 설계 기법임
- **배경/필요성**: 큰 입력의 처리 비용을 통제하기 위해 균형 분할과 낮은 결합 비용이 필요함

## Ⅱ. 특징

- 부분 문제가 독립적이면 공유 상태 없이 각 부분 문제를 동시에 실행할 수 있음
- 분할이 불균형하면 재귀 깊이와 최악 시간이 커짐
- 결합 비용이 크면 분할 이점이 상쇄됨
- 비용은 보통 $T(n)=aT(n/b)+f(n)$ 형태로 분석함

## Ⅲ. 종류 및 비교

| 판단 기준 | 분할 정복 (Divide & Conquer) | 동적 계획법 (DP) |
|:---|:---|:---|
| 부분 문제 관계 | 독립적이고 중복이 적음 | 같은 상태가 반복됨 |
| 처리 방식 | 분할·해결·결합 | 저장·전이·재사용 |
| 비용 기준 | 재귀 깊이와 결합 비용 | 상태 수와 전이 비용 |
| 대표 사례 | 병합 정렬·퀵 정렬·이진 탐색 | 배낭 문제·편집 거리 |

> 요약: 부분 문제가 독립적이고 분할이 균형적이며 결합 비용이 낮으면 분할 정복을, 중복 상태를 저장해 재사용해야 하면 동적 계획법을 선택함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 분할 기준 | 입력을 몇 개의 부분 문제로 나눌지 결정함 |
| 기저 사례 | 재귀를 멈추고 직접 답을 반환하는 조건임 |
| 정복 로직 | 각 부분 문제에 같은 알고리즘을 적용함 |
| 결합 연산 | 부분 해를 상위 문제의 해로 합침 |
| 호출 관리 | 호출 스택이나 작업 큐로 실행 순서를 관리함 |

```text
[ 분할 정복 구조 ]
원 문제
  |-- 부분 문제 A -> 부분 해 A
  |-- 부분 문제 B -> 부분 해 B
  v
결합 해
```

> 요약: 분할 기준, 기저 사례, 정복 로직, 결합 연산이 정해져야 부분 해가 원래 문제의 해로 이어짐.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------------+     +----------------+     +----------------+     +----------------+
| 종료 조건 확인 | --> | 부분 문제 분할 | --> | 부분 문제 해결 | --> | 결합 비용 확인 |
+----------------+     +----------------+     +----------------+     +----------------+
```

1. **종료 조건 확인**: 입력이 기저 사례이면 바로 답을 반환함
2. **부분 문제 분할**: 같은 구조의 작은 문제로 나누고 균형을 확인함
3. **부분 문제 해결**: 각 부분 문제에 같은 알고리즘을 적용함
4. **결합 비용 확인**: 부분 해를 합치고 재귀 깊이와 결합 비용을 확인함

> 요약: 분할 정복은 종료 조건을 먼저 고정하고, 분할 균형과 결합 비용으로 재귀 비용을 예측함.

## Ⅵ. 실무 사례

1. 중복 하위 문제가 있는 재귀 계산은 호출 횟수·실행 시간을 측정해 DP 전환 여부를 판단함
2. 퀵 정렬은 피벗 무작위화로 편향 분할을 줄이고 최대 재귀 깊이·스택 사용량을 확인함

## Ⅶ. 결론

- 분할 정복은 독립 부분 문제를 균형 있게 나누고 결합 비용을 낮출 수 있을 때 점화식과 재귀 깊이 기준으로 적용해야 함
