## 미리 알고가기

- 분할(Divide): 큰 문제를 동일한 구조의 작은 문제로 나누는 과정임
- 정복(Conquer): 분할된 문제를 재귀적으로 풀되, 더 나눌 수 없으면 답을 직접 구하는 과정임
- 결합(Combine): 부분 해를 합쳐 원래 문제의 해를 만드는 과정임
- 종료 조건(Base Case): 더 분할하지 않고 답을 직접 구하는 최소 입력 조건임
- 점화식: 부분 문제 수·입력 축소 비율·분할 및 결합 비용으로 전체 비용을 표현한 식임
- 상태 폭발: DP의 상태 변수·범위가 늘어 계산할 상태 수와 메모리가 급증하는 현상임
- 동적 계획법(DP): 반복되는 부분 문제의 답을 저장·재사용하는 알고리즘 설계 기법임

## 작성 근거(검토용)

- **개요 구성**: 분할 정복의 정의는 분할·정복·결합의 세 동작으로 충분하므로 이 흐름을 첫 문장에 배치함
- **Ⅱ. 특징 선정**: 부분 문제의 독립성, 분할 균형, 결합 비용, 점화식은 성능 분석에 필요한 요소라 남김
- **Ⅲ. 비교축 선정**: 분할 정복과 DP의 동작 메커니즘·계산 비용·주요 리스크만 남겨 선택 기준을 압축함
- **Ⅳ. 구조 선정**: 분할 기준부터 결합 연산까지 재귀 구조를 만드는 요소만 남겨 답안 흐름을 줄임
- 중복 부분 문제와 불균형 분할은 실행 비용을 증가시키는 대표 조건이라 남김

## Ⅰ. 개요

- **정의/개념**: 분할 정복은 큰 문제를 서로 독립적인 부분 문제로 나누어 해결하고, 부분 해를 결합해 전체 해를 구하는 설계 기법임
- **배경/필요성**: 재귀 비용은 분할 균형과 결합 비용에 따라 달라지므로 두 요소를 함께 분석해야 함

## Ⅱ. 특징

- 부분 문제가 독립적이면 공유 상태 없이 병렬 처리할 수 있음
- 분할이 불균형하면 재귀 깊이와 실행 시간이 증가함
- 결합 비용이 크면 분할 효과가 제한됨
- 크기 $n/b$인 부분 문제 $a$개로 나누면 시간복잡도는 $T(n)=aT(n/b)+f(n)$으로 표현함

## Ⅲ. 종류 및 비교

| 판단 기준 | 분할 정복 (Divide & Conquer) | 동적 계획법 (DP) |
|:---|:---|:---|
| 동작 메커니즘 | 독립 부분 문제 재귀 해결·결합 | 중복 부분 문제의 결과 저장·재사용 |
| 계산 비용 | 부분 문제의 재귀 비용 + 분할·결합 비용 | 상태 수 × 상태별 계산 비용 |
| 주요 리스크 | 불균형 분할 | 상태 폭발 |

> 요약: 부분 문제가 독립적이면 분할 정복을, 같은 부분 문제가 반복되면 동적 계획법을 선택함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 핵심 설명 |
|:---|:---|
| 분할 기준 | 입력을 동일한 구조의 부분 문제로 나누는 규칙 |
| 종료 조건 | 재귀 없이 해를 구하는 최소 입력 |
| 부분 문제 해법 | 각 부분 문제에 재귀 적용하는 동일 절차 |
| 결합 연산 | 부분 해를 원래 문제의 해로 합치는 연산 |

> 요약: 분할 정복은 입력을 종료 조건까지 부분 문제로 나누고 각 해를 결합해 원래 문제의 해를 구함.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------------+     +----------------+     +----------------+     +----------------+
| 종료 조건 확인 | --> | 부분 문제 분할 | --> | 부분 문제 해결 | --> | 부분 해 결합 |
+----------------+     +----------------+     +----------------+     +----------------+
```

1. **종료 조건 확인**: 입력이 최소 처리 단위이면 해를 직접 구함
2. **부분 문제 분할**: 입력을 동일한 구조의 작은 문제로 나눔
3. **부분 문제 해결**: 각 부분 문제를 재귀적으로 해결함
4. **부분 해 결합**: 부분 해를 합쳐 원래 문제의 해를 구함

> 요약: 분할 정복은 종료 조건까지 문제를 재귀 분할하고 부분 해를 결합해 원래 문제의 해를 구함.

## Ⅵ. 실무 사례

1. 대용량 파일 정렬은 병합 정렬로 데이터를 분할 처리하고 병합 I/O와 임시 저장공간을 확인함
2. 퀵 정렬은 피벗 무작위화로 편향 분할을 줄이고 재귀 깊이와 스택 사용량을 확인함

## Ⅶ. 결론

- 분할 정복은 독립 부분 문제에 적용하며 분할 균형·결합 비용·재귀 깊이로 성능을 판단해야 함
