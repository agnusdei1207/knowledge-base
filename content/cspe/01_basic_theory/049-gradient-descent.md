## Ⅰ. 개요
- **정의**: 손실 함수의 값을 최소화하기 위해 파라미터를 기울기의 반대 방향으로 점진적으로 업데이트하는 최적화 알고리즘임.
- **배경/필요성**: 복잡한 고차원 공간에서 손실이 최소인 최적점(Global Minimum)을 효율적으로 찾기 위해 필요함.
- **출제 의도**: 학습률의 역할, SGD의 확률적 접근, 모멘텀 및 적응형 학습률(Adam 등)의 개선 원리를 이해하는지 평가함.

## Ⅱ. 구성요소
```text
+------------------+       +------------------+       +------------------+
| Current Weights  | ----> | Compute Gradient | ----> | Update Weights   |
| (Theta)          |       | (- dL / dTheta)  |       | (Theta_new)      |
+------------------+       +------------------+       +------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 기울기(Gradient)| 현재 위치에서 손실 함수가 가장 가파르게 증가하는 방향 | 산의 경사도 |
| 학습률(Learning) | 한 번 업데이트할 때 이동할 스텝의 크기 | 하산 보폭 |
| 옵티마이저 | SGD, Adam 등 경사하강법을 효율화하는 알고리즘 종류 | 하산 경로 탐색자 |

> 요약: 현재 위치의 기울기를 계산하고 학습률만큼 반대 방향으로 가중치를 이동시킴.

## Ⅲ. 절차
```text
+-------------+   +-------------+   +-------------+   +-------------+
| 1. 가중치   |-->| 2. 기울기   |-->| 3. 보폭/방향|-->| 4. 가중치   |
|    초기화   |   |    계산     |   |    결정     |   |    갱신     |
+-------------+   +-------------+   +-------------+   +-------------+
```
1. **가중치 초기화**: 임의의 값으로 파라미터(가중치)를 초기화함.
2. **기울기 계산**: 미니배치 데이터를 사용하여 현재 파라미터에 대한 손실 함수의 기울기를 계산함.
3. **보폭/방향 결정**: 모멘텀이나 적응형 학습률을 반영해 이동 벡터를 결정함(Adam 등).
4. **가중치 갱신**: 기존 파라미터에서 결정된 벡터를 빼서 새로운 파라미터로 업데이트하며 반복함.

> 요약: 초기 가중치에서 시작해 기울기와 옵티마이저 규칙에 따라 최적의 파라미터로 갱신함.

## Ⅳ. 문제점
- **국소 최적해 빠짐**: 전체 최적해가 아닌 지역적인 계곡에 갇혀 학습이 조기 종료됨.
- **학습률 설정 문제**: 학습률이 너무 크면 발산하고, 너무 작으면 수렴이 지나치게 느려짐.

## Ⅴ. 개선방안
- **국소 최적해 빠짐**: (단기) Momentum 도입으로 관성을 주어 탈출 유도 / (장기) 배치 사이즈 조절 및 구조 변경 필요.
- **학습률 설정 문제**: (단기) 학습률 스케줄러 적용 / (장기) 파라미터마다 학습률을 자동 조절하는 Adam 등 사용 필요.

## Ⅵ. 전망
- Adam 계열 옵티마이저가 딥러닝 표준으로 자리 잡았으며, 거대 모델 최적화 기법(ZeRO 등)이 부상하고 있음.
