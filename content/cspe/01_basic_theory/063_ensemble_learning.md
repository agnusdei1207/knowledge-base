# 앙상블 학습 - 배깅, 부스팅, 스태킹 (Ensemble Learning)

## 1. 개요

- **정의/개념**: 앙상블 학습은 여러 모델의 예측을 결합해 단일 모델보다 더 안정적이고 높은 성능을 얻는 학습 방법이다.
- **배경/필요성**: 개별 모델은 편향, 분산, 데이터 편차에 취약할 수 있으므로 서로 다른 오류를 결합해 일반화 성능을 높일 필요가 있다.

앙상블의 핵심은 모델을 많이 모으는 것이 아니라 서로 다른 오류 패턴을 유용하게 결합하는 것이다.

## 2. 특징 및 비교

| 구분 | Bagging | Boosting | Stacking |
|---|---|---|---|
| 결합 방식 | 병렬 학습 후 평균·투표 | 이전 오류를 순차 보정 | meta model이 예측 결합 |
| 주 효과 | 분산 감소 | 편향 감소 | 모델 다양성 활용 |
| 대표 모델 | Random Forest | XGBoost, AdaBoost | stacked generalization |
| 위험 | 해석성 저하 | 과적합·튜닝 민감 | 데이터 누수 |

선택 기준은 base model 다양성, 오류 상관, 계산 비용, 해석성, 데이터 누수 위험이다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| Base Learner | 결합할 개별 모델 | 다양성 |
| Sampling/Weighting | 데이터 또는 샘플 가중 조정 | bagging/boosting 차이 |
| Combination Rule | 투표, 평균, meta model | 최종 예측 |
| Validation Strategy | 결합 성능 검증 | 누수 방지 |
| Diversity | 모델 간 오류 차이 | 앙상블 효과 |

```text
데이터 -> 여러 모델 학습 -> 예측 결합 -> 최종 예측
```

base model의 오류가 서로 비슷하면 결합해도 성능 이득이 작으므로 다양성이 구조의 핵심이다.

## 4. 문제점 및 개선방안

1. **해석성 저하**
   - 여러 모델을 결합하면 의사결정 경로가 복잡해진다.
   - **개선방안**: feature importance, SHAP, 단순 모델 병행을 사용한다.

2. **데이터 누수**
   - stacking에서 검증 데이터 예측을 잘못 만들면 meta model이 정답 정보를 학습한다.
   - **개선방안**: out-of-fold prediction으로 meta feature를 생성한다.

3. **계산 비용 증가**
   - 여러 모델 학습·추론으로 자원 요구가 커진다.
   - **개선방안**: 모델 수 제한, distillation, latency 기준 pruning을 적용한다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| 금융 리스크 | 여러 모델을 결합해 예측 안정성 확보 | AUC, 안정성 |
| 대회·랭킹 시스템 | stacking으로 다양한 모델 예측 결합 | leaderboard score |
| 제조 품질 | bagging 계열로 센서 노이즈에 강한 예측 | recall, false alarm |

## 6. 결론

앙상블 학습은 여러 모델의 예측을 결합해 편향과 분산을 줄이는 방법이다. 배깅·부스팅·스태킹은 결합 순서와 목적이 다르므로 모델 다양성, 누수 방지, 계산 비용까지 함께 판단해야 한다.
