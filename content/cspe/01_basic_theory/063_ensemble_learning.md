## 미리 알고가기

- base learner: 앙상블을 구성하는 개별 모델임
- diversity: 개별 모델들이 서로 다른 오류를 내는 정도임
- meta model: 여러 모델 출력을 다시 결합하는 상위 모델임

## Ⅰ. 개요

- **정의/개념**: 앙상블 학습은 여러 개별 모델의 예측을 결합해 단일 모델보다 더 안정적이거나 더 정확한 결과를 얻는 기법으로, 배깅, 부스팅, 스태킹이 대표 방식임
- **배경/필요성**: 개별 모델은 편향이나 분산 한쪽에 취약할 수 있으므로, 서로 다른 오차 패턴을 결합해 성능을 보완할 필요가 있음

## Ⅱ. 특징

- 배깅은 분산 감소, 부스팅은 편향 감소에 강함
- 서로 다른 모델 결합으로 일반화 성능을 높일 수 있음
- 단일 모델보다 안정적이지만 구조와 운영 복잡도가 증가함
- 다양성이 부족하면 앙상블 이득이 제한됨

## Ⅲ. 종류 및 비교

| 판단 기준 | 배깅 | 부스팅 | 스태킹 |
|:---|:---|:---|:---|
| 학습 방식 | 병렬 독립 | 순차 보정 | 계층 결합 |
| 주요 목표 | 분산 감소 | 편향 감소 | 상보성 극대화 |
| 대표 모델 | 랜덤 포레스트 | XGBoost, LightGBM | meta learner 조합 |
| 운영 난도 | 중간 | 중간~높음 | 높음 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 개별 학습기 | 서로 다른 예측기를 구성하고 다양성의 원천임 |
| 학습 데이터 분할/가중치 | 샘플링 또는 오차 가중이 적용됨 알고리즘 차이를 만듦 |
| 결합 규칙 | 평균, 다수결, 메타모델 등이며 최종 품질을 결정함 |
| 검증 체계 | OOB, CV, hold-out 등을 씀 과적합 방지 장치임 |

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 모델다양화 | --> | 개별학습 | --> | 예측결합 | --> | 성능평가 |
+----------+     +----------+     +----------+     +----------+
```

1. **모델다양화**: 데이터 샘플, 특징, 알고리즘 차이를 부여함
2. **개별학습**: 각 base learner를 학습시킴
3. **예측결합**: 평균, 투표, 메타모델로 통합함
4. **성능평가**: 단일 모델 대비 개선 여부를 검증함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 운영 복잡도가 증가해 학습, 배포, 모니터링 대상이 많아짐
   - 해결방안: 성능 이득이 작은 모델은 제거하고 complexity vs gain로 검증함
2. 문제: 다양성이 부족하면 효과가 적음 비슷한 모델은 같은 오류를 낸다
   - 해결방안: 데이터 분할, 알고리즘, 특징을 다변화하고 prediction correlation로 검증함
3. 문제: 스태킹은 누수 위험이 있어 메타모델이 훈련 정답을 간접 학습할 수 있음
   - 해결방안: out-of-fold prediction으로 메타데이터를 생성하고 CV gap로 검증함

## Ⅶ. 적용 사례

- 금융 사기 탐지: 여러 모델 출력을 결합함, 확인 지표는 ROC-AUC와 recall임
- 추천/광고 예측: 트리와 선형 모델을 함께 사용함, 확인 지표는 CTR lift임
- 대회형 모델링: stacking으로 최고 성능을 추구함, 확인 지표는 leaderboard score임

## Ⅷ. 결론

앙상블 학습의 핵심은 모델 수가 아니라 서로 다른 오류를 어떻게 결합하느냐에 있으므로, 다양성과 운영 비용을 함께 평가해야 함.
