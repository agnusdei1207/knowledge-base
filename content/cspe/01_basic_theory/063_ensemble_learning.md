## 미리 알고가기

- 기본 학습기: 앙상블을 구성하는 개별 모델임
- 배깅: 복원추출 표본으로 여러 모델을 병렬 학습함
- 부스팅: 이전 모델의 오차를 다음 모델이 순차 보완함
- 스태킹: 여러 모델 예측값을 메타 모델 입력으로 사용함
- 다양성: 모델들이 서로 다른 오류를 내도록 만드는 성질임

## 작성 근거(검토용)

- 개요는 여러 모델 결합과 오류 안정화를 핵심 정의로 두어 앙상블의 목적을 바로 드러냄
- 오류 감소와 함께 비용·설명 가능성 저하를 제시해 선택 판단의 균형을 맞춤
- Ⅲ은 배깅·부스팅·스태킹을 학습 방식과 리스크로 비교해 문제 키워드를 직접 반영함
- Ⅳ는 데이터 변형, 학습기, 결합 규칙, 검증 절차로 앙상블의 정적 구조를 정리함
- 다양성 부족과 스태킹 누수는 앙상블의 핵심 실패 조건임

## Ⅰ. 개요

- **정의/개념**: 앙상블 학습은 여러 기본 학습기의 예측을 결합해 단일 모델보다 오류를 상쇄한 예측을 만드는 학습 방식임
- **배경/필요성**: 단일 모델의 편향·분산 오류를 상쇄하기 위해 여러 학습기를 결합하는 구조가 필요함

## Ⅱ. 특징

- 여러 모델의 예측을 결합해 분산이나 편향을 줄임
- 모델 다양성이 클수록 오류 상쇄 효과가 커짐
- 예측 성능은 높아질 수 있지만 학습·추론 비용이 증가함
- 결합 방식이 복잡해질수록 설명 가능성이 낮아짐

## Ⅲ. 종류 및 비교

| 판단 기준 | 배깅 | 부스팅 | 스태킹 |
|:---|:---|:---|:---|
| 학습 방식 | 병렬 독립 학습 | 순차 오류 보완 | 예측값 기반 2단 학습 |
| 데이터 구성 | 부트스트랩 표본 | 오분류 표본 가중 | 모델별 out-of-fold 예측 |
| 줄이는 오류 | 분산 | 편향 | 모델 조합 오류 |
| 대표 기법 | 랜덤 포레스트 | AdaBoost, GBM | 메타 모델 결합 |
| 대표 적용 사례 | 안정적인 정형 데이터 분류·회귀 | 고성능 랭킹·위험 예측 | 이종 모델 예측 결합 |
| 주의점 | 약한 다양성 | 과적합·튜닝 민감 | 데이터 누수 |

> 요약: 배깅은 여러 모델의 평균으로 분산을 줄이고, 부스팅은 이전 오류를 순차 보정하며, 스태킹은 서로 다른 모델의 강점을 메타 모델로 결합함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 학습 데이터 변형 | 표본·특징·가중치를 달리해 다양성을 확보함 |
| 기본 학습기 | 트리, 선형 모델, 신경망 등 개별 예측기임 |
| 결합 규칙 | 투표, 평균, 가중 평균으로 예측을 합침 |
| 메타 학습기 | 스태킹에서 하위 모델 예측을 다시 학습함 |
| 검증 절차 | 교차 검증으로 일반화 성능과 누수를 확인함 |

> 요약: 다양한 학습기와 결합 규칙, 검증 절차가 앙상블 효과를 결정함.

```text
입력 데이터
  -> 모델 A ----\
  -> 모델 B -----+-> 투표/평균/메타 모델 -> 최종 예측
  -> 모델 C ----/
```

## Ⅴ. 원리 및 절차 흐름도

```text
변형 데이터 준비 -> 학습기 훈련 -> 예측 수집 -> 출력 결합 -> 검증
```

1. 표본, 특징, 알고리즘을 달리해 학습기 다양성을 확보함
2. 배깅은 병렬로, 부스팅은 오차를 전달하며 순차 학습함
3. 각 모델의 예측값이나 확률값을 수집함
4. 결합 규칙 또는 메타 모델로 최종 예측을 산출함

> 요약: 앙상블 효과는 개별 모델의 다양성과 결합 후 검증 성능 상승으로 확인함.

## Ⅵ. 실무 사례

1. 정형 데이터 예측은 앙상블로 오차를 줄일 수 있지만 유사한 모델만 묶으면 개선 폭이 작으므로 모델 간 오류 상관과 검증 점수 상승을 함께 확인함
2. 스태킹은 훈련 예측값을 그대로 쓰면 데이터 누수가 생기므로 폴드 외 예측으로 메타 학습 데이터를 구성하고 단일 모델 대비 검증 점수 향상을 확인함

## Ⅶ. 결론

- 앙상블 학습은 오류를 상쇄하는 결합 전략이며, 성능 향상 폭이 비용과 설명 가능성 저하를 넘는지 판단해야 함
