# 📖 【암기용】 개념 완전 이해

> 목적: 앙상블 학습을 처음 보는 사람도 완벽히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 앙상블은 여러 모델의 예측을 결합해 오류를 줄이는 학습 방법이다.
- **왜 필요한가**: 단일 모델은 데이터 샘플링, 초기값, 모델 가정에 따라 편향·분산 오류가 생긴다. 여러 모델을 결합하면 오류 패턴을 상쇄할 수 있다.
- **핵심 직관**: 한 전문가의 판단보다 서로 다른 관점을 가진 전문가 여러 명의 투표가 더 낮은 분산을 만들 수 있다.

## 깊이 이해
- **배경·문제의식**: 머신러닝 오류는 편향(Bias), 분산(Variance), 잡음으로 나뉜다. 배깅은 분산을 줄이고, 부스팅은 편향을 줄이며, 스태킹은 서로 다른 모델의 예측을 메타 모델로 조합한다.
- **작동 원리**: 배깅은 부트스트랩 샘플을 여러 개 만들고 병렬 학습한다. 부스팅은 이전 모델이 틀린 샘플에 가중치를 부여해 순차 학습한다. 스태킹은 1단계 모델의 out-of-fold 예측을 2단계 모델 입력으로 사용한다.
- **비유**: 배깅은 여러 심사위원의 독립 투표, 부스팅은 오답노트를 반복 보완하는 과외, 스태킹은 전문가 의견을 종합하는 팀장 모델에 해당한다.
- **구체 예시**: Random Forest는 의사결정나무 100~500개를 부트스트랩 샘플로 학습해 개별 나무의 분산을 줄인다. Gradient Boosting은 잔차를 순차 보정해 손실을 감소시킨다.
- **흔한 오해·주의점**: 모델을 많이 섞는다고 자동으로 품질이 오르지 않는다. 서로 상관이 높은 모델만 결합하면 앙상블 이득이 작고, 스태킹은 데이터 누수 검증이 필수이다.

## 연결 개념
- 편향-분산 트레이드오프: 앙상블 선택 기준
- 랜덤 포레스트: 배깅 기반 대표 모델
- XGBoost·LightGBM: 부스팅 기반 대표 모델

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 앙상블 학습은 다수 모델의 예측을 투표·평균·메타학습으로 결합하는 오류 감소 기법이다.
> 2. **가치**: 배깅은 분산, 부스팅은 편향, 스태킹은 모델 상보성을 이용해 예측 오류를 낮춘다.
> 3. **판단 포인트**: 데이터 크기, 모델 상관도, 지연시간, 해석 요구에 따라 결합 방식을 선택한다.

---

## Ⅰ. 개요 및 필요성

앙상블은 예측 결합 학습이다. 단일 모델은 표본 변화와 모델 가정에 의해 일반화 오류가 발생한다. 앙상블은 여러 모델의 오류를 분산·편향·상보성 관점에서 결합해 분류·회귀 문제의 검증 지표를 개선한다.

---

## Ⅱ. 구조 및 구성요소

```text
학습 데이터 -> 샘플링/가중치 -> 기본 모델들 -> 예측 결합 -> 최종 예측
                         +-> 검증 분리 -> 누수 방지
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 기본 학습기 | 개별 예측 모델 생성 | Tree, SVM, Neural Network |
| 결합 전략 | 투표, 평균, 가중 평균, 메타 모델 | hard/soft voting |
| 다양성 확보 | 샘플·특징·알고리즘 차이 생성 | 상관도 0.8 이하 목표 |
| 검증 체계 | out-of-bag, out-of-fold 평가 | 데이터 누수 방지 |

> 요약: 앙상블은 다양한 기본 학습기를 만들고 검증 체계를 통해 예측 결합의 일반화 성능을 확인한다.

---

## Ⅲ. 동작원리 및 흐름도

```text
데이터 분리 -> 기본 모델 학습 -> 개별 예측 생성 -> 결합 규칙 적용 -> 검증 지표 산출
              +-> OOF 예측 -> 스태킹 메타 모델
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 학습/검증/테스트 분리 | stratified split, 시계열 분리 |
| 2 | 배깅·부스팅·스태킹 방식 선택 | 편향·분산 진단 |
| 3 | 개별 모델 학습과 예측 결합 | 모델 상관도, OOF 예측 |
| 4 | 최종 모델 평가와 배포 판단 | AUC, RMSE, p95 지연 |

> 요약: 앙상블은 데이터 분리 후 기본 모델을 학습하고 예측 결합을 검증해 최종 배포 여부를 판단한다.

---

## Ⅳ. 특징

| 구분 | 내용 | 판단 포인트 |
|:---|:---|:---|
| 장점 | 단일 모델 대비 분산·편향 오류 감소 | AUC 1~5%p 개선 여부 |
| 한계 | 학습·예측 비용과 해석 난이도 증가 | p95 예측 100ms 이하 요구 |
| 비교 대상 | 단일 모델, 딥러닝 | 탭ular 데이터와 지연시간 기준 |
| 수치 기준 | 모델 3~10개, OOF 5-fold | 상관도 0.8 이하 후보 우선 |

> 요약: 앙상블은 검증 지표 상승폭이 운영 비용과 지연시간 증가분을 초과할 때 선택한다.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존/대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | 단일 모델은 구조 단순 | 다수 모델 결합 | 검증 AUC 2%p 이상 개선 |
| 비용/성능 | 딥러닝은 GPU 의존 가능 | 트리 앙상블은 CPU 학습 가능 | 탭ular 100만 행 이하 |
| 운영/위험 | 규칙 기반은 변경 추적 용이 | 앙상블은 버전·피처 추적 필요 | 모델 레지스트리 보유 |

> 요약: 앙상블은 검증 지표 개선 폭과 운영 복잡도 증가를 함께 비교해 채택 여부를 결정한다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 데이터 누수 | 스태킹 학습에 검증 예측 재사용 | OOF 예측만 메타 학습 사용 | train-test AUC 차이 3%p 이하 |
| 과적합 | 모델 수 과다, 부스팅 반복 과다 | early stopping, depth 제한 | 검증 손실 20라운드 정체 |
| 운영 지연 | 다수 모델 동시 추론 | 모델 압축, 상위 3개 모델 선택 | p95 추론 100ms 이하 |

> 요약: 앙상블 리스크는 데이터 누수, 과적합, 추론 지연을 검증 분리와 지표 기준으로 통제한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 예측 품질 | AUC 0.90 이상 또는 단일 대비 2%p 상승 | holdout, 5-fold CV |
| 운영 비용 | p95 추론 100ms 이하, CPU 70% 이하 | APM, 부하테스트 |
| 재현성 | 모델·피처·데이터 버전 100% 기록 | MLflow, Feature Store |

> 요약: 앙상블의 성공은 품질 개선, 추론 비용, 재현성 기록이 동시에 기준을 만족하는지로 판단한다.

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 — 단계별 또는 항목별):**
1. 기준 모델 대비 AUC 2%p 이상 개선을 채택 조건으로 두고 Random Forest 300 trees, XGBoost, Logistic Regression을 후보로 비교함
2. 스태킹은 5-fold OOF 예측만 메타 모델 입력으로 사용해 데이터 누수를 차단함
3. 배포 전 p95 추론 100ms 이하, 모델 레지스트리 버전 100% 기록, 월 1회 드리프트 점검을 적용함

**결론 (2줄):**
- 기술사 판단: 검증 지표 개선이 2%p 미만이면 단일 모델, 2%p 이상이고 지연 조건을 만족하면 앙상블을 선택함
- 향후 방향: 앙상블은 AutoML, Feature Store, 모델 모니터링과 결합해 운영 가능한 예측 시스템으로 발전함
