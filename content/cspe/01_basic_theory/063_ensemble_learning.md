# 📖 【암기용】 개념 완전 이해

> 목적: 이 개념을 처음 보는 사람도 완벽히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: **편향-분산 트레이드오프**(Bias-Variance Tradeoff)를 구조적으로 완화하기 위해, 여러 개의 **약한 학습기**(Weak Learner)를 결합해 하나의 강한 예측기를 만드는 **메타 알고리즘**(다른 모델들의 출력을 다시 입력으로 쓰는 상위 알고리즘)이 앙상블 학습이다.
- **왜 필요한가**: 단일 모델은 너무 단순하면 편향(헛다리)이 크고, 너무 복잡하면 분산(오락가락)이 커진다. 한 모델로 둘 다 잡을 수 없다는 게 편향-분산 트레이드오프인데, 여러 모델을 합치면 이 딜레마를 우회할 수 있다.
- **핵심 직관**: "백지장도 맞들면 낫다" — 서로 다른 실수를 하는 모델 여럿을 모으면, 각자의 실수가 상쇄되어 전체 평균은 개별보다 정확해진다.

## 핵심 용어 정리 (내부에 등장하는 것들)

| 용어 | 의미 | 비유 |
|:---|:---|:---|
| 편향-분산 트레이드오프 | 앙상블이 풀려는 상위 문제 — 편향을 줄이면 분산이 늘고 분산을 줄이면 편향이 느는 근본 딜레마 | 시소 — 한쪽을 누르면 반대쪽이 뜬다 |
| 편향(Bias) | 모델이 정답 경향에서 체계적으로 벗어난 정도(과소적합 원인) | 항상 과녁 왼쪽 아래로만 쏘는 사수 |
| 분산(Variance) | 훈련 데이터가 조금만 바뀌어도 예측이 크게 흔들리는 정도(과적합 원인) | 쏠 때마다 완전히 다른 곳을 맞히는 사수 |
| 약한 학습기(Weak Learner) | 무작위 추측보다 조금 나은 수준의 단순 모델(주로 깊이 3~5의 얕은 결정 트리) | 한 과목만 겨우 아는 반쪽짜리 전문가 |
| 배깅(Bagging, Bootstrap Aggregating) | 원본 데이터를 복원추출로 여러 번 나눠 독립 모델을 병렬로 학습시키고 다수결·평균으로 합침 — 분산 감소 목적 | 10명에게 각자 풀게 하고 다수결로 답 정하기 |
| 부트스트래핑 | 원본 N건에서 중복을 허용해 N건을 다시 뽑는 복원추출 — 배깅의 데이터 분할 방법 | 같은 통에서 공을 뽑고 다시 넣기를 반복 |
| 부스팅(Boosting) | 앞 모델이 틀린 부분(잔차)에 가중치를 줘 다음 모델이 순차적으로 보완 — 편향 감소 목적 | 오답 노트를 계속 물려주는 이어달리기 |
| 잔차(Residual) | 실제값 − 예측값. 부스팅에서 다음 모델이 맞춰야 할 목표값 | 이번 시험에서 못 채운 나머지 점수 |
| 스태킹(Stacking) | 서로 다른 알고리즘(이기종)의 예측 결과를 새 입력으로 삼아 메타 모델이 최종 결론을 냄 | 과목별 전문가 의견을 팀장이 취합해 최종 결정 |
| 메타 모델 | 베이스 모델들의 예측 벡터를 입력으로 학습하는 2단계 모델(주로 로지스틱 회귀) | 보고서 여러 개를 종합하는 팀장 |
| 하드 보팅 / 소프트 보팅 | 클래스 결과의 단순 다수결 / 클래스 확률의 평균 | 손 들어 표결 / 점수를 평균 내 결정 |

## 깊이 이해

### 편향-분산 트레이드오프 — 왜 단일 모델은 한계가 있나 (수치로 이해)
- 결정 트리 깊이를 1(스텀프)로 제한하면 훈련 오차 25%, 테스트 오차 27%처럼 둘 다 높다 — 편향이 큰 과소적합이다. 반대로 깊이 제한 없이 끝까지 키우면 훈련 오차 0%, 테스트 오차 30%처럼 훈련-테스트 격차가 벌어진다 — 분산이 큰 과적합이다.
- 통계적으로 예측 오차는 (편향)² + 분산 + 노이즈로 분해된다(편향-분산 분해). 모델을 복잡하게 하면 편향²은 줄지만 분산이 늘고, 단순하게 하면 반대가 된다 — 한 모델로는 둘을 동시에 최소화할 수 없다.
- 1990년대 중반 이 딜레마를 우회하는 방법으로 배깅(Breiman, 1996)과 부스팅(AdaBoost, Freund & Schapire, 1997)이 각각 분산·편향 축을 공략하며 등장했다.

### 배깅이 분산을 줄이는 원리 — 수치로 이해
- 독립인 추정치 n개를 평균 내면 분산은 원래의 1/n로 줄어든다(통계학의 분산 축소 공식: Var(평균) = σ²/n). 트리 1개의 예측 분산이 100이라면, 완전히 독립인 트리 100개를 평균 내면 이론상 분산은 1에 가까워진다.
- 하지만 실제로는 같은 원본 데이터에서 부트스트랩으로 뽑기 때문에 트리들이 서로 상관(ρ)을 갖는다. 이때 평균의 분산은 ρσ² + (1−ρ)σ²/n으로, 트리 수를 아무리 늘려도 ρσ² 아래로는 못 내려간다. 그래서 랜덤 포레스트는 각 분할마다 후보 특징도 무작위로 일부만 보게 해(특징 서브샘플링) ρ를 더 낮춘다.
- 예: 트리 100개, 상관 ρ=0.2, 개별 분산 σ²=100이면 평균의 분산 ≈ 0.2×100 + 0.8×100/100 = 20.8 — 단일 트리 대비 약 80% 분산 감소.

### 부스팅이 편향을 줄이는 원리 — 잔차를 잇는 수치 예시
- 실제값 y=10인 샘플에서, 1번 모델이 6을 예측하면 잔차는 4. 2번 모델은 이 4를 목표로 학습해 3을 예측하면 누적 예측은 6+3=9, 남은 잔차는 1. 3번 모델이 1을 거의 맞추면 누적 예측은 9+1=10에 근접한다.
- 이렇게 모델을 순차로 더할수록 누적 예측이 정답에 수렴하므로, 개별 모델이 단순(편향 큼)해도 여러 개를 이어 붙이면 전체 편향이 줄어든다. 다만 순차적이라 병렬화가 어렵고, 너무 많이 이어 붙이면(라운드 과다) 훈련 데이터에 과적합할 수 있다.
- AdaBoost는 잔차 대신 오답 샘플에 가중치를 높여 다음 모델이 그 샘플을 더 중요하게 보게 한다(예: 틀린 샘플의 가중치를 1 → 2로 올림). GBM 이후로는 잔차(그래디언트)를 직접 학습 목표로 삼는 방식이 표준이 됐다(064 XGBoost·LightGBM에서 이어짐).

### 스태킹과 데이터 누수 — 왜 K-Fold가 필수인가
- 베이스 모델이 훈련에 썼던 데이터를 그대로 자기 예측값으로 메타 모델에 넘기면, 메타 모델은 "이미 답을 아는 문제"를 푸는 셈이라 검증 성능이 비현실적으로 좋아진다(데이터 누수).
- 그래서 5-Fold라면 데이터를 5등분해 4개 폴드로 학습한 모델이 나머지 1개 폴드(보지 못한 데이터)를 예측하게 하고, 이를 5번 반복해 전체 데이터에 대한 "out-of-fold 예측값"만 메타 모델의 입력으로 쓴다.

### 판별 원리 — 언제 무엇을 쓰나
- 모델이 과적합(분산 과다) 경향이면 배깅(예: 랜덤 포레스트)을 우선 검토한다.
- 모델이 과소적합(편향 과다) 경향이면 부스팅(예: XGBoost, LightGBM)을 우선 검토한다.
- 서로 다른 성질의 모델(선형+트리+신경망)을 이미 갖고 있고 최고 성능이 목표라면 스태킹으로 결합한다. 단, 해석력이 요구되는 도메인(금융 심사 등)에서는 블랙박스화 위험을 감수해야 한다.

## 연결 개념
- 편향-분산 트레이드오프 — 앙상블이 우회하려는 상위의 근본 문제
- 부트스트래핑 — 배깅에서 훈련 데이터를 나누는 통계적 방법
- 결정 트리 — 앙상블의 약한 학습기로 가장 흔히 쓰이는 기본 모델
- XGBoost·LightGBM (064) — 부스팅 계열을 병렬·근사 연산으로 고도화한 구현체

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 앙상블 학습(Ensemble Learning)은 다수의 약한 학습기(Weak Learner)를 결합하여 편향-분산 트레이드오프(Bias-Variance Tradeoff)의 한계를 구조적으로 극복하는 메타 알고리즘이다.
> 2. **가치**: 배깅(분산 감소)과 부스팅(편향 감소)을 통해 단일 알고리즘의 과대/과소적합 리스크를 상쇄하고, 예측 성능의 하한선 보장 및 대형 정형 데이터 대회(Kaggle) 우승 모델의 표준 지위를 확립했다.
> 3. **판단 포인트**: 성능(Accuracy) 향상에 비례하여 연산량 폭증과 해석 불가능(Black-box)이라는 치명적 기회비용이 발생하므로, XAI(SHAP 등) 도입 및 단일 모델과의 ROI 저울질이 필수적이다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 3대 앙상블 기법의 아키텍처 차이점 비교 | 배깅(병렬/독립) vs 부스팅(순차/가중치) vs 스태킹(이기종/메타) 메커니즘 차이 | 앙상블 기법 나열만 하고 각 기법이 줄이려는 에러(Bias/Variance) 누락 |
| 부스팅(Boosting)의 세부 발전 과정 | AdaBoost(가중치) $\rightarrow$ GBM(잔차/Gradient) $\rightarrow$ XGBoost(병렬/규제) | "부스팅이 항상 배깅보다 좋다"는 과적합 리스크를 무시한 단정 서술 |
| 앙상블 성공을 위한 통계적 전제 조건 | 비상관화(Decorrelation): 모델 간 오차 발생 원인이 달라야 다수결이 의미가 있음 | 데이터 샘플링(Bootstrap) 과정을 추상적으로 생략 |

> 요약: 앙상블은 단순히 여러 개를 묶는 물리적 작업이 아니라, "에러를 어떻게 통제할 것인가"에 대한 편향-분산 최적화의 수학적 설계도(병렬/순차/메타)를 묻는 것이다.

## Ⅰ. 개요 및 필요성

- 정의: 동일하거나 서로 다른 여러 기계학습 모델(기본 분류기)의 예측 결과를 다수결, 평균, 또는 메타 모델로 종합하여 최종 예측 성능을 향상시키는 학습 기법
- 배경: 단일 모델(Single Model)은 데이터 셋의 작은 노이즈에도 예측 경계가 붕괴되는 높은 분산(Variance)과, 본질적 비선형성을 파악하지 못하는 높은 편향(Bias)의 딜레마 보유
- 필요성: 모델들의 예측 오차 간 상관관계(Correlation)를 낮춰 상호 보완하게 만듦으로써, 단일 알고리즘 한계를 넘는 강력하고 일반화된 예측 체계(Robust System) 구현

## Ⅱ. 구조 및 구성요소 (3대 기법 설계)

```text
1. [배깅]   원본 -> (부트스트랩) -> 모델1, 모델2, 모델3 (병렬) -> 다수결 투표
2. [부스팅] 원본 -> 모델1 -> (오차 가중치) -> 모델2 -> (오차 가중치) -> 모델3 (직렬) -> 가중 합산
3. [스태킹] 훈련 데이터 -> KNN(이질), SVM(이질), Tree(이질) (Base) -> 예측값 묶음 -> 메타 모델(LR) 훈련 (직렬/계층)
```

| 기법 및 목적 | 데이터 공급 / 모델 간 관계 | 알고리즘 구현 사례 |
|:---|:---|:---|
| 배깅 (Bagging) / 분산 감소 | 부트스트랩 복원 추출 (모델 간 상호 독립, 병렬 연산) | Random Forest, Extra Trees |
| 부스팅 (Boosting) / 편향 감소 | 이전 모델의 오답/잔차(Residual)에 가중치 부여 집중 훈련 (순차적 종속) | AdaBoost, Gradient Boosting, XGBoost |
| 스태킹 (Stacking) / 복합 성능 향상 | 전체 데이터 사용하되 이기종(Heterogeneous) 모델 구성. 예측값이 다음 모델 입력 | 여러 대회 우승자의 맞춤형 자체 아키텍처 |

> 요약: 배깅은 평균을 내어 극단치를 중화(안정화)시키고, 부스팅은 틀린 문제를 파고들어 정밀도를 깎아내며(날카로움), 스태킹은 다른 시각을 가진 이기종 모델을 지휘관(메타)이 종합한다.

## Ⅲ. 세부 동작원리 (투표 및 집계 방식)

```text
개별 모델(Weak Learner) 학습 완료 -> 결과 종합 메커니즘 (Hard/Soft Voting, Weighted Sum) -> 최종 출력
```

| 집계 방식 (Aggregation) | 처리 메커니즘 | 검증 기준 / 적용 도메인 |
|:---|:---|:---|
| 하드 보팅 (Hard Voting) | 분류기들이 출력한 '클래스 결과'의 단순 다수결 | 가장 많은 표를 얻은 클래스 선택 (직관적) |
| 소프트 보팅 (Soft Voting) | 분류기들이 출력한 '클래스 확률(Probability)'의 평균 계산 | 확률 높은 예측에 가중치가 실려 성능 우수 |
| 잔차 학습 (Gradient / 부스팅) | 앞 모델의 정답-예측 차이(Gradient)를 타겟으로 다음 모델 훈련 | Loss 최소화 타겟 갱신 |
| 메타(Meta) 모델 학습 | Base 모델들의 예측 벡터를 새로운 입력 Feature로 사용하여 2단계 학습 | 과적합 방지를 위해 K-Fold Cross Validation 필수 |

> 요약: 앙상블의 최종 결과는 단순 투표를 넘어 확률을 더하거나(Soft), 틀린 값 자체(Residual)를 보완하는 미적분 최적화(Gradient Boosting)로 고도화되었다.

---

## Ⅳ. 주요 알고리즘 발전 계보 (Boosting 중심)

| 알고리즘 명 | 주요 발전 및 차별화 포인트 | 트레이드오프 / 한계 |
|:---|:---|:---|
| GBM (Gradient Boosting) | 가중치 부여(AdaBoost) 대신 오차(Residual) 자체를 맞추도록 수학적 최적화 진화 | 순차적 훈련으로 학습 속도가 매우 느림 |
| XGBoost | GBM에 병렬(Multi-core) 연산 노드 분할 도입, 과적합 방지 규제(L1/L2) 수식 결합 | 파라미터 튜닝 극도로 복잡, 여전히 무거움 |
| LightGBM | Leaf-wise(수직) 트리 분할과 히스토그램 기반 구간화로 학습 속도 5배 이상 혁신 | 데이터 크기가 작을 때(1만 건 이하) 과대적합 위험 극대화 |

> 요약: 트리 앙상블은 정확도를 높이는 부스팅(GBM)으로 진화한 뒤, 느린 속도라는 치명적 단점을 하드웨어 병렬 처리와 근사 탐색으로 극복(XGBoost, LGBM)하며 정형 데이터의 제왕이 되었다.

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 동종 앙상블 (배깅·부스팅) | 이기종 앙상블 (스태킹) | 선택 기준 |
|:---|:---|:---|:---|
| 구성 모델 | 동일 알고리즘(주로 트리)을 다수 반복 사용 | 서로 다른 알고리즘(선형/트리/신경망 등)을 조합 | 데이터가 단일 가설 공간으로 충분히 설명되는지 |
| 학습·검증 복잡도 | 단일 프레임워크 내 하이퍼파라미터만 튜닝 | Base 모델별 개별 튜닝 + 메타 모델 K-Fold 교차검증 필요 | 개발·운영 리소스 여유 |
| 성능 상한 및 리스크 | 정형 데이터 벤치마크에서 안정적 상위권, 구조가 단순해 누수 위험 낮음 | Base 모델 다양성 확보 시 최고 성능 가능하나 데이터 누수 위험 존재 | 대회/서비스가 요구하는 성능 상한 수준 |

> 요약: 배깅·부스팅은 같은 알고리즘을 반복해 안정적으로 에러를 통제하고, 스태킹은 이기종 모델의 이질적 시각을 결합해 성능 상한을 높이지만 데이터 누수 관리가 관건이다.

| 리스크 | 발생 원인 | 대응 방안 (실무 팁) | 확인 지표 |
|:---|:---|:---|:---|
| 설명 가능성 부재 (Black Box) | 수백~수천 개 트리의 복합 결정 경로 추적 불가 (금융 규제 위반) | SHAP(Shapley Value), LIME 라이브러리 도입으로 변수별 기여도 정량 산출 | 규제 감사 시 변수별 기여도 제출 가능 여부 |
| 스태킹 데이터 누수 (Data Leakage) | Base 모델이 훈련 데이터를 메타 모델에 그대로 예측해 넘기면 100% 과적합 | K-Fold Out-of-fold 예측 기법을 적용해 훈련되지 않은 Fold 데이터만 메타 모델로 전달 | 훈련/검증 성능 격차, Fold 간 성능 분산 |

> 요약: 앙상블의 실무 리스크는 성능 저하가 아니라 결과 설명 불가(Black Box)와 스태킹 메타 모델의 데이터 누수이며, XAI 도구와 K-Fold 검증으로 통제한다.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 시계열 예측/수요 예측 시스템: 하이퍼파라미터 튜닝이 완료된 LightGBM을 메인 모델로 배치하고, 트리의 깊이(Depth)를 5 이하로 억제하여 순차적 오차 학습에 따른 과적합 통제.
2. 카드사 신용 심사 앙상블: 서로 다른 수학적 관점을 가진 로지스틱 회귀(선형), Random Forest(비선형 배깅), XGBoost(비선형 부스팅) 3개를 Base로 두고, K-Fold 스태킹 메타 모델로 최종 승인 여부 분류(AUROC 향상).
3. 실시간 클릭 예측(CTR): 서비스 초기 트래픽 폭주 시, 깊은 앙상블 대신 Soft Voting 기반의 랜덤 포레스트를 사용해 훈련 시간을 압축하고 배치(Batch) 추론 스루풋(TPS) 확보.

**결론 (2줄):**
- 기술사 판단: 앙상블 학습은 단일 모델의 수학적 한계(편향-분산)를 아키텍처 결합(배깅/부스팅/스태킹)을 통해 공학적으로 타파한, 정형 데이터 처리 분야의 궁극적인 최적화 마스터키이다.
- 향후 방향: 비정형 데이터(이미지, 텍스트)는 딥러닝(Transformer)이 평정했으나, 금융/제조/마케팅 등 테이블 형태의 정형 빅데이터 도메인에서는 트리 기반 부스팅 앙상블이 여전히 최고의 ROI를 제공하는 실무 표준이다.
