## 미리 알고가기

- 기본 학습기: 앙상블을 구성하는 개별 모델임
- 배깅: 복원추출 표본으로 여러 모델을 병렬 학습함
- 부스팅: 이전 모델의 오차를 다음 모델이 순차 보완함
- 스태킹: 여러 모델 예측값을 메타 모델 입력으로 사용함
- 다양성: 모델들이 서로 다른 오류를 내도록 만드는 성질임
- 폴드 외 예측: 각 검증 폴드를 학습에서 제외한 모델로 생성한 예측값임
- 데이터 누수: 검증 데이터의 정보가 학습 과정에 들어가 성능이 과대평가되는 현상임

## 작성 근거(검토용)

- **방향성**: 앙상블 학습은 여러 모델을 결합해 편향·분산 오류를 줄이는 대신, 학습기 수가 늘수록 연산량이 커지고 예측 기여 추적이 어려워지므로 오류 감소 폭이 추가 비용보다 클 때만 목적에 맞는 결합 방식을 선택해야 함
- **Ⅰ. 개요 구성**: 여러 모델의 예측 결합과 오류 상쇄를 앙상블의 핵심 목적으로 정의함
- **Ⅱ. 특징 선정**: 오류 감소와 함께 연산량 증가·설명 가능성 저하를 제시해 선택 판단의 균형을 맞춤
- **Ⅲ. 비교축 선정**: 학습 메커니즘·예측 결합·주요 리스크는 세 방식의 고유 스펙이라 축은 유지하고, 분산·편향·이종 결합 필요에 따른 선택 기준은 요약 문장의 구체적 분기 조건으로 명시함
- **Ⅳ. 구조 선정**: 데이터 변형, 학습기, 결합 규칙, 메타 학습기로 앙상블의 정적 구조를 정리함
- **Ⅵ. 사례 선정**: 다양성 부족과 스태킹 누수는 앙상블의 핵심 실패 조건임
- **전수 검수**: 제목부터 결론까지 용어·표·도식·요약을 대조하고 방향성 불릿과 절 라벨을 보강했으며 본문에 쓰이지 않는 고아 용어(ROC 곡선 아래 면적)를 삭제하고 다양성 용어를 본문에 반영함

## Ⅰ. 개요

- **정의/개념**: 앙상블 학습은 여러 기본 학습기의 예측을 결합해 편향이나 분산을 줄이는 학습 방식임
- **배경/필요성**: 단일 모델의 편향·분산 오류를 상쇄하기 위해 여러 학습기를 결합하는 구조가 필요함

### 쉽게 이해하기 (학습용)
- 여러 전문가에게 따로 의견을 물은 뒤 다수결이나 평균으로 최종 판단을 내리는 것과 같음

## Ⅱ. 특징

- 배깅은 분산을 줄이고 부스팅은 편향을 줄임
- 기본 학습기 간 다양성이 클수록 오류 상관이 낮아져 같은 오분류의 반복이 줄어듦
- 학습기 수가 늘면 학습·추론 연산량도 증가함
- 결합 단계가 늘면 개별 모델의 예측 기여를 추적하기 어려움

### 쉽게 이해하기 (학습용)
- 여러 명이 각자 다른 실수를 하면 한 사람의 실수가 다른 사람들 판단에 묻혀 상쇄됨(배깅은 들쭉날쭉함을, 부스팅은 못 맞히던 부분을 줄임)
- 전문가를 더 부를수록 물어보고 취합하는 데 시간이 더 걸림
- 여러 명의 의견을 섞을수록 누구의 판단이 결정적이었는지 가려내기 어려워짐

## Ⅲ. 종류 및 비교

| 판단 기준 | 배깅 | 부스팅 | 스태킹 |
|:---|:---|:---|:---|
| 학습 메커니즘 | 병렬 독립 학습 | 순차 오류 보완 | 2단 메타 학습 |
| 예측 결합 | 평균·투표 | 가중 합산 | 메타 모델 |
| 주요 리스크 | 높은 오류 상관 | 잡음 증폭 | 메타 학습 데이터 누수 |

> 요약: 모델 예측 분산이 크면 배깅, 편향이 크면 부스팅, 서로 다른 유형의 모델을 결합해 성능을 높이려면 스태킹을 적용함.

### 쉽게 이해하기 (학습용)
- 배깅은 여러 전문가에게 같은 문제를 각자 따로 풀게 해 평균 내는 것, 부스팅은 앞사람이 틀린 문제를 다음 사람이 집중적으로 다시 푸는 것, 스태킹은 여러 전문가의 답을 모아 마지막 심사위원이 최종 판단하는 것임

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 학습 데이터 변형 | 유형별 표본·특징·가중치 구성 |
| 기본 학습기 | 각 표본·가중치·특징 구성에서 예측을 학습하는 개별 모델 |
| 결합 규칙 | 투표·평균·가중 합산 |
| 메타 모델 | 기본 학습기 예측의 2단 결합 모델 |

> 요약: 앙상블은 학습 데이터와 기본 학습기를 다양화하고 예측을 결합해 단일 모델의 편향·분산을 줄임.

```text
[배깅]   부트스트랩 표본 -> 병렬 기본 모델 -> 평균·투표
[부스팅] 이전 모델 오차 -> 다음 모델 학습 -> 가중 합산
[스태킹] 기본 모델별 폴드 외 예측 -> 메타 모델 -> 최종 예측
```

### 쉽게 이해하기 (학습용)
- 배깅은 문제지를 여러 장 복사해 나눠 풀고 답을 모아 투표하고, 부스팅은 틀린 문제만 골라 다음 사람에게 다시 풀게 하며, 스태킹은 각자 푼 답안을 모아 최종 심사위원(메타 모델)이 다시 채점함

## Ⅵ. 실무 사례

1. 서버 장애 예측기는 서로 다른 오류를 내는 모델의 예측을 투표·평균함
2. 시스템 이상 탐지는 폴드 외 예측으로 스태킹 메타 모델을 학습해 데이터 누수를 방지함

### 쉽게 이해하기 (학습용)
- 서로 다르게 틀리는 여러 모델의 판단을 투표·평균으로 모으되, 시험에 이미 나온 문제로 채점 기준(메타 모델)을 만들지 않도록 별도로 떼어둔 문제만 씀

## Ⅶ. 결론

- 앙상블 학습은 서로 다른 모델의 판단을 결합해 오류를 줄이지만, 추가 연산과 낮아지는 설명 가능성을 고려해야 함
- 단일 모델과 오류 상관이 충분히 낮을 때만 결합하고, 성능 개선이 추론 비용보다 작으면 복잡한 앙상블을 배제해야 함

### 쉽게 이해하기 (학습용)
- 여러 의견을 모으면 실수는 줄지만 그만큼 묻고 취합하는 수고가 늘어나므로, 의견 차이가 클 때만 모으고 효과가 수고에 못 미치면 혼자 판단하는 편이 나음
