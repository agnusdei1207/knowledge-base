## Ⅰ. 개요
- 정의: 여러 개의 약한 학습기를 결합하여 하나의 강력한 학습기를 만드는 기법임.
- 배경: 단일 모델의 한계(과적합, 편향)를 극복하고 성능을 극대화하기 위함임.
- 출제 의도:
| 분류 | 상세 |
| --- | --- |
| 핵심요소 | 배깅, 부스팅, 스태킹, 투표(Voting) |
| 주요특징 | 일반화 성능 향상, 복잡도 증가, 높은 정확도 |

## Ⅱ. 구성요소
- ASCII 구조도
 [Data] -> [M1] [M2] [M3] -> [Combination] -> [Result]
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 배깅(Bagging) | 복원 추출을 통해 병렬로 학습 (Random Forest) | 다수결 투표 |
| 부스팅(Boosting) | 오차를 보완하며 순차적으로 학습 (XGBoost) | 오답 노트 |
| 스태킹(Stacking) | 여러 모델의 예측 결과를 다시 학습 (Meta Learner) | 전문가 회의 |
> 요약: 다수 모델의 협력을 통해 오차를 줄이는 학습 전략임.

## Ⅲ. 절차
- ASCII 흐름도
[데이터 분할] -> [개별 모델 학습] -> [결합 연산] -> [최종 예측]
- 4단계 설명
1. 샘플링: 부트스트래핑(Bootstrapping) 등을 통해 학습 데이터 생성함.
2. 병렬/직렬 학습: 선택된 기법(Bagging/Boosting)에 따라 학습함.
3. 가중치 적용: 각 모델의 기여도에 따라 가중치를 부여함.
4. 결과 통합: 투표(Voting)나 평균(Averaging)으로 최종값을 도출함.
> 요약: 모델 생성, 개별 학습, 결합 단계를 거쳐 성능을 최적화함.

## Ⅳ. 문제점
- 모델 복잡도 증가로 인한 해석력 저하 및 학습 시간 과다가 발생함.

## Ⅴ. 개선방안
- 단기: 학습 속도가 빠른 약한 학습기(Decision Tree)를 기본 모델로 사용함.
- 중기: 하드웨어 가속기(GPU/NPU)를 활용해 병렬 처리를 강화함.
- 장기: 설명 가능한 AI(XAI) 기법을 도입하여 모델 투명성을 확보함.

## Ⅵ. 전망
- 개별 모델의 다양성(Diversity) 확보가 성공적 구현의 CSF이며, 향후 AutoML 기반의 동적 모델 선택 기술과 결합하여 데이터 변화에 실시간 대응하는 적응형 앙상블(Adaptive Ensemble) 아키텍처로 진화할 전망임.
- 특히 이기종 모델 간의 지식 증류(Knowledge Distillation)를 통한 경량화된 고성능 앙상블 모델 구축이 실무적 트렌드로 자리 잡을 것임.
