## 미리 알고가기

- 약한 학습기: 단독 성능은 제한적이지만 무작위 추정보다 나은 기반 모델임
- 편향: 모델이 실제 패턴을 단순하게 가정해 생기는 체계적 오차임
- 분산: 학습 데이터 변화에 따라 예측이 크게 흔들리는 민감도임
- 배깅: 여러 모델을 병렬 학습해 평균 또는 투표로 분산을 줄이는 방식임
- 부스팅: 앞 모델의 오류를 다음 모델이 보정하며 편향을 줄이는 순차 방식임
- 스태킹: 여러 모델의 예측값을 다시 메타 모델의 입력으로 사용하는 방식임

## Ⅰ. 개요

- **정의**: 앙상블 학습은 여러 기반 모델의 예측을 결합해 편향·분산·상관성을 조정하는 메타 학습 기법임
- **배경/필요성**: 실제 데이터에서는 단일 모델이 노이즈, 표본 변동, 복잡한 비선형성 중 하나에 취약해 예측 품질이 흔들릴 수 있음
- **비유**: 한 명의 전문가 판단에만 의존하지 않고 독립 전문가, 반복 코치, 최종 심사위원을 조합하는 의사결정 구조와 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 결합 전략 비교 | 배깅 병렬, 부스팅 순차, 스태킹 메타 학습 | Random Forest와 앙상블 전체 개념 혼동 |
| 성능 개선 원리 설명 | 편향-분산 트레이드오프 완화 | 단순 다수결 장점 나열 |

> 요약: 앙상블은 기반 모델을 결합하는 구조를 달리해 오류를 분산시키거나 순차 보정하거나 메타 판단으로 통합하는 학습 전략임

## Ⅱ. 특징/비교

| 판단 기준 | 배깅 | 부스팅 | 스태킹 |
|:---|:---|:---|:---|
| 학습 순서 | 부트스트랩 표본을 병렬 학습함 | 이전 모델의 오류를 다음 모델이 순차 보정함 | 여러 모델 예측을 새 학습 데이터로 사용함 |
| 주요 개선 대상 | 분산 감소와 과적합 완화 | 편향 감소와 복잡 패턴 적합 | 이종 모델의 장점 결합 |
| 대표 모델 | Random Forest | AdaBoost, XGBoost, LightGBM | Blending, Super Learner |
| 선택 기준 | 데이터 노이즈와 모델 변동이 클 때 | 예측 오차를 단계적으로 줄이고 싶을 때 | 서로 다른 모델군의 보완성이 클 때 |

> 요약: 배깅은 흔들림을 줄이고, 부스팅은 오답을 보정하며, 스태킹은 서로 다른 모델의 판단을 재학습하는 방식임

- **배깅 선택**: 과적합 위험이 큰 불안정 모델을 여러 표본으로 평균화해야 할 때 적합함
- **부스팅 선택**: 정형 데이터에서 성능 한계까지 끌어올리되 튜닝과 검증을 감당할 수 있을 때 적합함
- **스태킹 선택**: 모델별 강점이 뚜렷하고 OOF 예측으로 데이터 누수를 통제할 수 있을 때 적합함

## Ⅲ. 구성요소

```text
+-------------+       +-------------+       +-------------+
| Training    | ----> | Base        | ----> | Combiner    |
| Data        |       | Learners    |       | Vote/Weight |
+------+------+       +------+------+       +------+------+
       |                     |                     |
       v                     v                     v
+-------------+       +-------------+       +-------------+
| Sampling /  |       | Error /     |       | Final       |
| Weighting   |       | Meta Input  |       | Prediction  |
+-------------+       +-------------+       +-------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 학습 데이터 | 기반 모델이 공통으로 학습할 원천 데이터이며 샘플링·가중치 조정 대상임 | 회의 자료 |
| 기반 학습기 | 의사결정나무, 선형 모델, 신경망 등 결합 대상 모델임 | 개별 전문가 |
| 결합 규칙 | 평균, 투표, 가중합, 메타 모델로 여러 예측을 하나로 통합함 | 의사결정 규칙 |
| 오류 피드백 | 부스팅에서 오분류 표본의 중요도를 높여 다음 모델 학습에 반영함 | 오답 노트 |
| 검증 분리 | 스태킹에서 OOF 예측을 사용해 메타 모델의 데이터 누수를 막음 | 예비 심사 |

> 요약: 앙상블은 데이터 변형, 기반 학습기, 결합 규칙, 오류 피드백, 검증 분리를 조합해 예측을 안정화함

## Ⅳ. 절차

```text
+-----------+     +-----------+     +-----------+     +-----------+
| Prepare   | --> | Train     | --> | Combine   | --> | Validate  |
| Samples   |     | Learners  |     | Outputs   |     | Ensemble  |
+-----------+     +-----------+     +-----------+     +-----------+
      |                 |                 |                 |
      v                 v                 v                 v
bootstrap/weight   parallel/serial    vote/stack        metric check
```

1. **결합 전략 결정**: 데이터 크기, 노이즈, 모델 다양성, 지연 요구사항을 기준으로 배깅·부스팅·스태킹을 선택함
2. **기반 모델 학습**: 배깅은 표본을 병렬 학습하고, 부스팅은 오류 가중치를 갱신하며, 스태킹은 이종 모델을 학습함
3. **예측 결합**: 분류는 투표·확률 평균, 회귀는 평균·가중합, 스태킹은 메타 모델 예측으로 통합함
4. **검증·튜닝**: 홀드아웃 또는 교차검증으로 성능과 과적합을 점검하고 기반 모델 수와 깊이를 조정함

> 요약: 앙상블 절차는 전략 선택, 기반 학습, 결합, 검증을 반복하며 단일 모델 대비 안정성을 확인하는 흐름임

## Ⅴ. 문제점

- **P1 연산 비용 증가**: 여러 모델을 동시에 학습·추론하므로 CPU, 메모리, 응답 지연이 단일 모델보다 증가함
- **P2 해석성 저하**: 결합 결과가 복잡해져 어떤 모델과 피처가 최종 판단에 기여했는지 설명하기 어려움
- **P3 스태킹 데이터 누수**: 메타 모델이 검증에 사용해야 할 정답 정보를 간접 학습하면 일반화 성능이 과대평가됨

> 요약: 앙상블의 실무 위험은 모델 수 증가로 인한 비용, 복잡한 판단 구조, 검증 설계 오류에서 발생함

## Ⅵ. 개선방안

- **P1 대응**: 모델 수 제한, 병렬 학습, 지식 증류, 지연 예산 기반 pruning으로 추론 비용을 통제함 (확인: p95 지연, 메모리 사용량)
- **P2 대응**: SHAP 집계, permutation importance, 단순 기준 모델 비교로 설명 가능한 근거를 제공함 (확인: 주요 피처 순위 안정성)
- **P3 대응**: K-Fold OOF 예측만 메타 모델에 입력하고 최종 검증셋을 별도로 유지함 (확인: 학습-검증 성능 격차)

> 요약: 앙상블은 성능 향상만이 아니라 비용 예산, 설명 기준, 검증 분리를 함께 설계해야 실효성이 있음

## Ⅶ. 전망

- **발전 방향**: AutoML은 모델 탐색뿐 아니라 앙상블 조합, 가중치, 검증 전략까지 자동화하는 방향으로 확장될 전망임
- **기술사적 판단**: 정형 데이터에서는 부스팅 계열 앙상블이 여전히 강력하지만, 지연과 설명 의무가 큰 서비스에서는 단순 모델과 비교해야 함
- **기술사 제언**: 답안에서는 배깅·부스팅·스태킹을 한 줄 장점으로 끝내지 말고 결합 순서와 선택 기준을 함께 제시해야 함
