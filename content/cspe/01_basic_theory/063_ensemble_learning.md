## 미리 알고가기

- 기본 학습기($Base$ $Learner$): 앙상블을 구성하는 개별적인 단일 예측 모델(예: 얕은 결정 트리)임
- 다수결 투표($Voting$): 여러 모델의 예측 범주 중 가장 많은 표를 얻은 클래스를 최종 선택하는 방식임
- 메타 모델($Meta$ $Model$): 개별 모델들의 예측 결과값들을 입력 피처로 받아, 최종 예측을 수행하는 상위 예측 모델임
- 다양성($Diversity$): 앙상블 효과를 극대화하기 위해 개별 학습기들이 서로 다른 오류를 범하도록 구성하는 성질임

## Ⅰ. 개요

- **정의/개념**: 앙상블 학습은 단일 알고리즘을 사용하는 대신, 여러 개의 개별 학습기($Base$ $Learner$)를 결합하여 하나의 강력한 예측 성능을 발휘하는 모델을 구축하는 학습 프레임워크임
- **배경/필요성**: 단일 머신러닝 알고리즘은 오차의 두 축인 편향($Bias$)이나 분산($Variance$) 중 하나에 치우쳐 성능이 제한되기 쉬우므로, 서로 다른 장점을 가진 모델들의 의견을 종합하여 전체적인 오차를 줄이기 위해 도입됨

## Ⅱ. 특징

- 개별 모델들의 예측 오류가 서로 독립적이라는 전제하에, 모델들의 예측치를 합산하거나 투표하여 무작위 오류를 상쇄하고 진정한 데이터의 패턴만을 남겨 일반화 성능을 대폭 향상함
- 대중적인 배깅($Bagging$)은 오버피팅 완화(분산 감소)에, 부스팅($Boosting$)은 학습이 어려운 까다로운 데이터 정복(편향 감소)에 특화됨
- 개별 모델의 수와 종류가 늘어날수록 성능은 안정화되지만, 전체 학습 속도와 추론 시간이 지연되며 결과의 수학적 추적과 비즈니스적 설명력이 매우 떨어짐

## Ⅲ. 종류 및 비교

| 판단 기준 | 배깅 (Bagging) | 부스팅 (Boosting) | 스태킹 (Stacking) |
|:---|:---|:---|:---|
| **학습 방식** | 병렬 독립 학습 | 이전 모델 오차 보완하는 순차 학습 | 이종 모델 간의 계층적 결합 학습 |
| **데이터 활용** | 부트스트랩 샘플링 복원 추출 | 오분류 데이터에 높은 가중치 부여 | 개별 모델의 예측값을 새 데이터로 사용 |
| **목표 오차** | 분산($Variance$) 감소 | 편향($Bias$) 감소 | 성능(예측력)의 한계 돌파 |
| **대표 모델** | 랜덤 포레스트 | $XGBoost, LightGBM$ | 메타 학습기 기반 혼합 모델 |

> 요약: 배깅은 '독립적 다수결'로 흔들림을 잡고, 부스팅은 '연속적 보완'으로 정밀도를 높임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 데이터 다변화 | 부트스트랩, 피처 하위 집합 선택 등을 통해 모델마다 다른 데이터 환경을 줌 |
| 기본 학습기 | 앙상블의 재료가 되는 하위 모델들로, 동종($Homogeneous$) 또는 이종($Heterogeneous$)으로 구성함 |
| 결합 연산자 | 소프트/하드 보팅, 단순 산술 평균, 가중 평균 등 예측값을 뭉치는 수학적 연산임 |
| 메타 학습기 | 스태킹에서 개별 예측값들을 최적으로 융합하기 위해 최상단에 놓는 회귀/분류기임 |

```text
[ 스태킹 (Stacking) 아키텍처 구조 ]
Input -> [ Model A ] --\
      -> [ Model B ] ----> [ Meta Learner (Logistic Regression) ] -> Final Result
      -> [ Model C ] --/
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 개별모델 생성| --> | 모델 독립/순차| --> | 예측결과 집계| --> | 최적 결합결정|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **지능 다양화** — 모델 간의 다양성을 확보하기 위해 서로 다른 샘플링 데이터셋을 구성하거나, 이종 알고리즘(트리, 선형 모델, KNN 등)을 준비함
2. **개별 모델 훈련** — 설정된 앙상블 전략(배깅은 병렬로 동시에, 부스팅은 앞 모델의 오차를 전달받으며 순차적으로)에 따라 개별 학습기를 훈련시킴
3. **예측값 수집** — 테스트 데이터 입력 시 개별 모델들이 도출해낸 분류 확률이나 실수값들을 수집함
4. **통합 및 도출** — 사전에 정의된 다수결 투표, 가중 평균, 혹은 메타 모델의 재예측 연산을 거쳐 최종적인 종합 판정을 출력함

## Ⅵ. 실무 적용 및 유의점

1. 스태킹($Stacking$) 구현 시 개별 모델의 예측값을 메타 데이터로 그냥 사용하면 훈련 데이터 정보가 메타 모델로 그대로 흘러 들어가는 '데이터 누수($Leakage$)'가 발생하므로, 반드시 $K-fold$ 교차 검증의 Out-of-fold 예측값을 메타 피처로 활용해야 함
2. 앙상블에 참여하는 모델들의 오류 경향성(상관계수)이 너무 비슷하면 예측 오류가 상쇄되지 않아 성능 개선 없이 연산 비용만 가중되므로, 모델 간 예측 결과물의 상관 분석을 수행하여 상관관계가 낮은 이종 모델들을 결합해야 함

## Ⅶ. 결론

- 앙상블 학습은 개별 지능의 오차를 집단 지성의 합리성으로 극복해내는 머신러닝의 표준이며, 설계자는 성능 개선 정도와 연산 복잡도 및 유지보수 비용 간의 손익 계산을 통해 가장 효율적인 모델 결합 설계를 완성해야 함
