# 063. 앙상블 학습 — 배깅·부스팅·스태킹 (Ensemble Learning)

## Ⅰ. 개요

- **정의/개념**: 단일 모델의 한계를 극복하기 위해 여러 개의 개별 학습기(Base Learner)를 결합하여 하나의 강력한 예측 모델을 구축하는 머신러닝 기법임
- **배경/필요성**: 개별 모델이 가질 수 있는 높은 편향(Bias)이나 높은 분산(Variance) 문제를 모델 간 상호 보완을 통해 해결하고, 데이터의 복잡한 패턴을 보다 안정적이고 정확하게 예측하기 위해 필요함

## Ⅱ. 특징 및 비교

| 판단 기준 | 배깅 (Bagging) | 부스팅 (Boosting) | 스태킹 (Stacking) |
|:---|:---|:---|:---|
| **결합 방식** | 병렬 (Parallel) | 순차 (Sequential) | 계층 (Hierarchical) |
| **핵심 원리** | 부트스트랩 샘플링 + 투표 | 이전 모델의 오차 보정 | 메타 모델을 통한 예측 결합 |
| **주요 목적** | 분산 감소 (과적합 방지) | 편향 감소 (정확도 향상) | 모델 다양성 극대화 |
| **대표 알고리즘** | 랜덤 포레스트 | XGBoost, LightGBM | Stacked Generalization |

> 요약: 배깅은 안정성을, 부스팅은 정확도를, 스태킹은 다양한 모델의 시너지를 목표로 함

## Ⅲ. 구성요소/구조

- **구성요소**:
  - **Base Learner**: 앙상블의 기본 단위가 되는 약한 학습기(Weak Learner)들임
  - **Bootstrap (Bagging)**: 중복을 허용한 무작위 샘플링으로 다양한 데이터셋을 생성함
  - **Residual Learning (Boosting)**: 이전 모델이 틀린 부분(잔차)에 가중치를 두어 집중 학습함
  - **Meta Learner (Stacking)**: 개별 모델들의 예측값을 입력 피처로 받아 최종 예측을 수행하는 상위 모델임
  - **Aggregation**: 다수결 투표(Hard/Soft Voting)나 산술 평균 등을 통해 결과를 합침

- **유형별 구조도**:
```text
[Bagging]                [Boosting]               [Stacking]
Data -> Model 1 --+      Data -> Model 1          Models -> Preds
     -> Model 2 --|          (Residuals)             |        |
     -> Model 3 --+      Data -> Model 2             +--> Meta Model
          |                  (Residuals)                      |
      (Voting)           Data -> Model 3               (Final Prediction)
```

## Ⅳ. 문제점 및 개선방안

1. **[모델의 복잡도 및 해석력 저하]**: 수많은 모델이 얽혀 있어 예측 결과에 대한 직접적인 원인 분석이 어려움
   - **개선방안**: LIME이나 SHAP과 같은 설명 가능한 AI(XAI) 도구를 도입하여 피처 기여도를 분석함 (확인: 모델 설명력)
2. **[컴퓨팅 자원 및 시간 비용]**: 여러 모델을 동시에 또는 순차적으로 학습시켜야 하므로 학습 및 추론 시간이 길어짐
   - **개선방안**: 모델 가지치기(Pruning)를 수행하거나 병렬 처리가 최적화된 알고리즘(LightGBM 등)을 선택함 (확인: 처리 지연 시간)
3. **[과적합 (특히 부스팅/스태킹)]**: 모델이 너무 강력해져 훈련 데이터의 노이즈까지 학습하거나 데이터 누수(Data Leakage)가 발생할 수 있음
   - **개선방안**: 스태킹 시 교차 검증(Out-of-fold)을 엄격히 적용하고 규제(Regularization) 파라미터를 조정함 (확인: Validation Gap)

## Ⅴ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| **Kaggle 등 데이터 대회** | 상위권 도달을 위해 다양한 모델(GBM, NN, SVM)을 스태킹하여 결합 | Leaderboard Score |
| **금융권 신용 평가** | 배깅 계열인 랜덤 포레스트를 사용하여 안정적인 부도 예측 모델 운영 | AUC-ROC, 안정성 지수 |
| **전자상거래 클릭률(CTR)** | 부스팅 계열(XGBoost)을 사용하여 사용자 반응을 정밀하게 예측 | Log-Loss, F1-Score |

> 요약: 실무에서는 프로젝트의 목적(정확도 중시 vs 안정성 중시)에 따라 적절한 앙상블 기법을 선별하여 적용함

## Ⅵ. 결론

앙상블 학습은 '집단지성'의 원리를 머신러닝에 구현한 기술로, 단일 알고리즘의 한계를 넘어서는 현대 데이터 분석의 필수 도구임. 데이터의 편향과 분산을 효과적으로 제어하며 모델의 견고함을 더해주지만, 늘어나는 복잡도와 연산 비용 사이의 트레이드오프를 고려한 엔지니어링적 판단이 수반되어야 실제 서비스 환경에서 가치를 발휘할 수 있음.
