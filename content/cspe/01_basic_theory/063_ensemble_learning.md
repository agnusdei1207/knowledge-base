## Ⅰ. 개요
- **정의**: 다수의 약한 학습기를 전략적으로 결합하여 단일 모델의 편향·분산 한계를 극복하는 메타 학습 기법임
- **배경/필요성**: 단일 모델의 Bias-Variance 트레이드오프 한계를 구조적으로 해소할 방법론 필요
- **비유**: 여러 전문가의 의견을 종합하여 최종 판결을 내리는 배심원 제도

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 배깅·부스팅·스태킹의 원리 차이 비교 | 병렬(배깅) vs 순차(부스팅) 결합 구조 | 배깅의 구현체(060 Random Forest 참조)와 혼동하지 않도록 원리 수준에서 서술 |

> 요약: 약한 학습기의 결합 전략(병렬/순차/메타학습)으로 예측 성능과 강건성을 동시에 향상시키는 프레임워크임

## Ⅱ. 구성요소
```text
+-----------+          +-----------+          +-----------+
| Bagging   |          | Boosting  |          | Stacking  |
| (Parallel)|          | (Sequent) |          | (Meta)    |
+-----+-----+          +-----+-----+          +-----+-----+
      |                      |                      |
      v                      v                      v
+-----------+          +-----------+          +-----------+
| Voting /  |          | Weighted  |          | Meta      |
| Averaging |          | Sum       |          | Learner   |
+-----------+          +-----------+          +-----------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 배깅(Bagging) | 부트스트랩 샘플로 병렬 학습 후 투표/평균 결합 (060 Random Forest가 대표 구현체) | 다수결 투표 |
| 부스팅(Boosting) | 이전 모델의 오답에 가중치를 부여하며 순차 학습 (064 XGBoost/LightGBM이 대표 구현체) | 오답 노트 반복 |
| 스태킹(Stacking) | 이종 모델의 예측값을 피처로 삼아 메타 모델이 재학습 | 전문가 위원회 |

> 요약: 배깅은 분산 감소, 부스팅은 편향 감소, 스태킹은 이종 모델 상호 보완에 각각 특화됨

## Ⅲ. 절차
```text
+-----------+     +-----------+     +-----------+     +-----------+
| Data      | --> | Base      | --> | Result    | --> | Final     |
| Sampling  |     | Training  |     | Combine   |     | Predict   |
+-----------+     +-----------+     +-----------+     +-----------+
```

1. **데이터 분할/샘플링** — 배깅: 부트스트랩 복원 추출, 부스팅: 가중 샘플링, 스태킹: K-Fold 분할
2. **기반 모델 학습** — 동종(배깅/부스팅) 또는 이종(스태킹) 약한 학습기를 전략별로 훈련
3. **결과 결합** — 배깅: 다수결/평균, 부스팅: 가중합, 스태킹: 메타 모델 입력으로 전달
4. **최종 예측** — 결합된 단일 예측값을 산출하여 분류/회귀 결과 도출

> 요약: 샘플링 전략에 따라 기반 모델을 학습하고, 결합 방식별로 최종 예측을 산출하는 구조임

## Ⅳ. 문제점
- **연산 비용 증가**: 다수 모델 학습·추론으로 단일 모델 대비 CPU/메모리 사용량 N배 증가
- **모델 해석성 저하**: 개별 모델의 기여도가 불투명하여 규제 산업(금융·의료) 적용 시 설명 의무 미충족
- **스태킹 과적합 위험**: 메타 모델이 기반 모델의 편향까지 학습할 경우 일반화 성능 하락

> 요약: 연산 비용, 해석 불투명성, 스태킹 과적합이 실무 적용의 3대 장벽임

## Ⅴ. 개선방안
1. 단기: 배깅 기반 병렬 학습(GPU/멀티코어)으로 학습 시간을 단일 모델 수준으로 단축
2. 중기: SHAP Value 집계로 앙상블 내 피처별 기여도를 정량화하여 해석성 확보
3. 장기: Blending + K-Fold OOF(Out-of-Fold) 예측 분리를 통해 스태킹 과적합을 구조적으로 차단

- **스태킹 과적합**: 메타 모델 편향 학습 -> L2 정규화 + OOF 분리 (지표: 검증셋 AUC 변동폭)

> 요약: 병렬화, XAI 피처 기여도 분석, OOF 분리를 통해 앙상블 실용성을 단계적으로 확보함

## Ⅵ. 전망
- 향후 발전 방향: AutoML 파이프라인이 앙상블 전략 자동 선택·결합까지 수행하는 자율화 단계로 진입
- 기술사적 판단: 정형 데이터 분석에서 단일 딥러닝보다 앙상블 GBDT가 우위인 구간이 여전히 존재함
- 기술사 제언: 배깅·부스팅·스태킹 3가지를 비교표로 정리하되, 개별 구현체(RF, XGBoost)는 해당 노트 참조로 위임
