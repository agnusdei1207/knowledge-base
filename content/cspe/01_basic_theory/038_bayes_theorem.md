## Ⅰ. 개요
- 정의: 새로운 정보나 증거가 주어졌을 때 기존의 확률을 갱신하는 조건부 확률 이론임
- 배경/필요성: 불확실한 상황에서 데이터를 기반으로 최적의 의사결정을 내리기 위해 사용됨
- 출제 의도: 사전 확률, 사후 확률의 개념 및 베이즈 공식 적용 능력 측정

## Ⅱ. 구성요소
- ASCII 구조도
                  P(B|A) * P(A)
  P(A|B) = --------------------------
                     P(B)
  (사후확률) = (우도 * 사전확률) / (증거)

- 구성요소 표
| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| 사전 확률 P(A) | 사건 발생 전 이미 알고 있는 확률 | 기존 고정관념 |
| 우도 P(B|A) | 사건 A가 발생했을 때 결과 B가 나올 확률 | 가설의 설득력 |
| 사후 확률 P(A|B) | 결과 B가 관측된 후 갱신된 사건 A의 확률 | 업데이트된 믿음 |
| 증거 P(B) | 결과 B가 나타날 전체 확률 | 관측 데이터 |
> 요약: 베이즈 정리는 경험적 근거를 바탕으로 지식을 지속적으로 수정하는 메커니즘임

## Ⅲ. 절차
- ASCII 흐름도
  [Prior Prob] -> [New Evidence] -> [Update via Bayes] -> [Posterior Prob]

1. 사전 확률 설정: 과거 데이터나 지식을 바탕으로 초기 확률 P(A)를 부여함
2. 우도 산출: 모델이나 실험을 통해 조건부 확률 P(B|A)를 계산함
3. 전체 확률 계산: 모든 경우의 수를 고려하여 증거 P(B)의 확률을 구함
4. 사후 확률 도출: 베이즈 공식을 적용하여 업데이트된 최종 확률을 계산함
> 요약: 새로운 증거(B)가 발견될 때마다 가설(A)의 확률을 정교화함

## Ⅳ. 문제점
- 사전 확률의 주관성: 초기 확률 설정에 따라 결과가 크게 달라질 수 있는 편향 위험 존재함
- 복잡도 증가: 변수가 많아질 경우 연산량이 기하급수적으로 늘어남

## Ⅴ. 개선방안
- 나이브 베이즈: 변수 간 독립을 가정하여 계산 복잡도를 획기적으로 낮춤
- 베이지안 네트워크: 변수 간의 인과 관계를 그래프로 모델링하여 복잡한 추론 지원함

## Ⅵ. 전망
- 스팸 필터링: 특정 단어 출현 시 스팸일 확률을 계산하는 핵심 알고리즘임
- 의료 진단: 검사 결과에 따른 실제 질병 보유 확률 추정 등 정밀 의료에 필수적임
