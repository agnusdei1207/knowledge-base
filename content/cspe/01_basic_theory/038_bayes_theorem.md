## 미리 알고가기

- 조건부 확률($Conditional$ $Probability$): 사건 $B$가 일어났다는 전제 하에 사건 $A$가 일어날 확률($P(A|B)$)임
- 사전 확률($Prior$): 증거를 관측하기 전, 대상 사건에 대해 이미 알고 있는 주관적 또는 객관적 확률임
- 우도($Likelihood$): 특정 가설이 참일 때, 현재의 증거(데이터)가 관측될 확률임
- 사후 확률($Posterior$): 새로운 증거를 반영하여 업데이트된 최종 확률값임

## Ⅰ. 개요

- **정의/개념**: 베이즈 정리는 새로운 정보나 증거가 주어졌을 때, 해당 증거를 바탕으로 기존의 사전 확률을 갱신하여 보다 정확한 사후 확률을 도출하는 확률 추론 공식임
- **배경/필요성**: 모든 데이터가 주어지지 않은 불확실한 상황에서, 추가적인 관측 데이터를 통해 가설의 신뢰도를 점진적으로 수정해 나가는 동적 의사결정 체계를 구축하기 위해 필수적임

## Ⅱ. 특징

- 단순히 과거의 빈도에만 의존하는 빈도주의 통계와 달리, 전문가의 지식이나 과거의 경험(사전 확률)을 수학적 모델에 직접 통합할 수 있는 유연성을 가짐
- 데이터가 유입될 때마다 순차적으로 확률을 업데이트하는 '베이지안 업데이트'가 가능하여, 실시간으로 변화하는 시스템의 상태 추정(예: 칼만 필터)에 매우 적합함
- '기저율($Base$ $Rate$)'의 영향을 명시적으로 계산에 포함함으로써, 희귀 사건에 대한 검사 결과가 양성일 때의 실제 정답 확률을 정밀하게 분석할 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | 빈도주의 통계 (Frequentist) | 베이지안 통계 (Bayesian) |
|:---|:---|:---|
| **확률의 정의** | 무한 반복 시 발생하는 사건의 빈도 | 사건 발생에 대한 믿음의 정도 (확신) |
| **미지의 모수** | 고정된 값 (추정의 대상) | 확률 변수 (분포를 가진 값) |
| **데이터 활용** | 현재 관측된 데이터만 사용 | 과거 경험(사전 확률) + 현재 데이터 |
| **주요 활용** | 가설 검정 ($p-value$), 신뢰 구간 | 머신러닝 분류, 실시간 위치 추정 |

> 요약: 빈도주의는 객관적 사실에, 베이지안은 경험과 관측의 결합을 통한 추론에 집중함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 사전 확률 $P(H)$ | 가설 $H$가 관측 전부터 가지고 있던 초기 확률임 |
| 우도 $P(E|H)$ | 가설 $H$가 참일 때 증거 $E$가 나타날 조건부 확률임 |
| 사후 확률 $P(H|E)$ | 증거 $E$를 본 후 가설 $H$가 참일 최종 확률로, 베이즈 정리의 목적지임 |
| 주변 우도 $P(E)$ | 가설과 무관하게 증거 $E$가 나타날 전체 확률이며, 정규화 상수 역할을 함 |

```text
[ 베이즈 정리 공식 ]
P(H|E) = ( P(E|H) * P(H) ) / P(E)
- Posterior ∝ Likelihood * Prior
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 사전확률 설정| --> | 새로운 증거 관측| --> | 우도/정규화 계산| --> | 사후확률 업데이트|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **사전 정의** — 분석 대상 사건에 대한 과거 통계나 도메인 지식을 바탕으로 초기 믿음의 정도인 사전 확률을 설정함
2. **데이터 획득** — 실험, 설문, 센서 수집 등을 통해 가설의 진위 여부를 판단할 수 있는 새로운 증거 데이터를 확보함
3. **확률 결합** — 베이즈 공식에 따라 기존의 사전 확률에 데이터의 설명력(우도)을 곱하고, 전체 발생 확률로 나누어 가중치를 조절함
4. **연쇄 추론** — 도출된 사후 확률을 다음 관측 단계의 새로운 사전 확률로 사용하여, 정보가 축적될수록 확률의 정확도를 높여감

## Ⅵ. 실무 적용 및 유의점

1. 스팸 필터링($Naive$ $Bayes$) 설계 시, 각 단어의 발생 확률이 독립적이라는 가정을 통해 계산량을 획기적으로 줄일 수 있지만, 실제 언어의 문맥적 연관성을 무시하므로 대량의 학습 데이터를 통해 확률 편향을 보정해야 함
2. 의료 진단 시스템에서 기저율이 매우 낮은 희귀 질병의 경우, 검사의 정확도(우도)가 아무리 높아도 양성 판정 시 실제 유병률(사후 확률)은 낮을 수 있으므로 '기저율 무시의 오류'를 방지하기 위한 정밀한 확률 해석이 필요함

## Ⅶ. 결론

- 베이즈 정리는 데이터 기반의 합리적 추론을 가능케 하는 현대 AI와 데이터 과학의 철학적 뿌리이며, 설계자는 주관적 사전 지식과 객관적 관측 데이터 사이의 수학적 결합을 통해 가장 신뢰도 높은 최적의 판단을 도출해야 함
