## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 베이즈 정리(Bayes' Theorem)는 **사전 확률(Prior)에 새로운 증거(Evidence)를 반영하여 사후 확률(Posterior)을 갱신**하는 조건부 확률 공식이다. $P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}$. 새로운 데이터가 주어질 때마다 믿음(확률)을 합리적으로 업데이트하는 수학적 프레임워크이다.
> 2. **가치**: 스팸 필터(나이브 베이즈), 의료 진단(양성 판정의 실제 확률), 머신러닝(베이지안 추론), A/B 테스트(베이지안 실험 설계), 자율주행(칼만 필터의 이론적 기반) 등에서 의사결정의 핵심 도구이다.
> 3. **융합**: AI(나이브 베이즈, 베이지안 신경망), 보안(침입 탐지의 오탐 확률 계산), 의료(민감도·특이도에서 양성 예측값 계산), 검색(검색 결과의 관련성 추정), 법학(DNA 증거의 확률적 평가) 등.

---

### 🔑 핵심 용어 정리

| 용어 | 뜻 | 비유 |
|:---|:---|:---|
| **사전 확률(Prior, $P(A)$)** | 증거를 보기 전 사건 $A$에 대한 기존 믿음 | "첫인상" |
| **우도(Likelihood, $P(B\|A)$)** | $A$가 참일 때 증거 $B$가 관측될 확률 | "이 병이면 이 증상이 나올 확률" |
| **사후 확률(Posterior, $P(A\|B)$)** | 증거 $B$를 본 후 갱신된 $A$에 대한 믿음 | "진단 후 수정된 판단" |
| **증거(Evidence, $P(B)$)** | 증거 $B$가 관측될 전체 확률. 정규화 상수 역할 | "전체 모집단에서의 비율" |
| **조건부 확률** | $P(A\|B) = P(A \cap B) / P(B)$. $B$가 주어졌을 때 $A$의 확률 | "조건 붙은 확률" |
| **전확률 공식** | $P(B) = \sum_i P(B\|A_i) P(A_i)$. 모든 경우의 수를 합산 | "가능한 모든 경로의 합" |

---

## Ⅰ. 개요 및 필요성

- **개념**: 베이즈 정리는 조건부 확률의 역전 공식이다:

$$
P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}
$$

$P(B|A)$(우도: $A$일 때 $B$가 나올 확률)를 알면, $P(A|B)$(사후: $B$를 관측했을 때 $A$일 확률)를 구할 수 있다.

- **필요성**: 의료 검사의 정확도(민감도 99%)만으로는 의사결정이 불가능하다. 유병률이 0.1%인 질병에 대해 양성 반응이 나왔을 때 실제 질병일 확률은 베이즈 정리로 계산하면 약 9%에 불과하다. 이 "기저율 무시(Base Rate Neglect)"는 인간의 대표적 인지 편향이며, 베이즈 정리가 교정해준다.

- **비유**: 베이즈 정리는 **"첫인상(사전) + 새로운 증거(우도) = 수정된 판단(사후)"**이다. 처음에 "이 사람은 거짓말쟁이일 확률 10%(사전)"이라고 생각했는데, 거짓말쟁이가 하는 행동(우도)을 목격하면 확률을 올린다.

```text
+-----------------------------------------------------------------------+
|        베이즈 정리 — 의료 검사 예시                                    |
+-----------------------------------------------------------------------+
|                                                                       |
|  질병 유병률: P(D) = 0.001 (0.1%)                                    |
|  검사 민감도: P(+|D) = 0.99 (99%)                                    |
|  검사 특이도: P(-|¬D) = 0.95 (5% 위양성)                            |
|                                                                       |
|  양성일 때 실제 질병일 확률:                                          |
|                                                                       |
|           P(+|D) × P(D)                                              |
|  P(D|+) = ─────────────────                                          |
|           P(+|D)×P(D) + P(+|¬D)×P(¬D)                               |
|                                                                       |
|         = 0.99 × 0.001                                               |
|           ─────────────────────────                                   |
|           0.99×0.001 + 0.05×0.999                                    |
|                                                                       |
|         = 0.00099 / 0.05094                                          |
|                                                                       |
|         ≈ 0.019 → 약 1.9%!                                          |
|                                                                       |
|  ★ 민감도 99%인 검사에서 양성이 나와도                               |
|    실제 질병일 확률은 겨우 1.9%                                       |
|  ★ 유병률(사전 확률)이 낮으면 위양성이 압도적                        |
+-----------------------------------------------------------------------+
```

**[다이어그램 해설]** 민감도 99%의 우수한 검사라도 유병률이 0.1%로 낮으면, 양성 판정의 대부분(98%)이 위양성이다. 이는 건강한 999명 중 5%(약 50명)가 위양성인 반면, 실제 환자 1명 중 99%가 진양성이므로, 양성 51명 중 실제 환자는 1명뿐이기 때문이다. 이것이 **기저율 효과**이며, 베이즈 정리 없이는 이 직관에 반하는 결과를 파악할 수 없다.

- **📢 섹션 요약 비유**: 베이즈 정리는 "탐정의 추리"입니다. 사건 전 용의자 목록(사전) + 새 단서(우도) = 갱신된 용의자 순위(사후). 단서가 쌓일수록 범인이 좁혀집니다.

## Ⅱ. 아키텍처 및 핵심 원리

### 구성 요소

| 요소명 | 수식 | 역할 | 응용 | 비유 |
|:---|:---|:---|:---|:---|
| **사전(Prior)** | $P(A)$ | 기존 믿음 | 유병률, 스팸 비율 | 첫인상 |
| **우도(Likelihood)** | $P(B\|A)$ | 증거의 설명력 | 민감도, 단어 출현 확률 | 증거의 무게 |
| **사후(Posterior)** | $P(A\|B)$ | 갱신된 믿음 | 진단 확률, 스팸 확률 | 수정된 판단 |
| **증거(Evidence)** | $P(B)$ | 정규화 상수 | 전확률 공식으로 계산 | 전체 케이스 수 |

### 나이브 베이즈 분류기

스팸 필터에서 이메일 단어 $w_1, w_2, \ldots, w_n$이 주어졌을 때:

$$
P(\text{spam}|w_1, \ldots, w_n) \propto P(\text{spam}) \prod_{i=1}^{n} P(w_i|\text{spam})
$$

"나이브"한 이유는 단어 간 독립을 가정하기 때문이다. 이 가정은 현실에서 위배되지만, 실무에서 놀라울 만큼 잘 동작한다.

- **📢 섹션 요약 비유**: 나이브 베이즈는 "각 단서를 독립적으로 평가한 뒤 곱하기"입니다. "비아그라"라는 단어(우도 ↑) × "무료"라는 단어(우도 ↑) = 스팸 확률 ↑.

## Ⅲ. 비교 및 연결

### 비교 1: 빈도주의 vs 베이지안

| 비교 항목 | 빈도주의(Frequentist) | 베이지안(Bayesian) |
|:---|:---|:---|
| **확률의 의미** | 반복 시행의 빈도(장기 빈도) | 믿음의 정도(주관적 확률) |
| **파라미터** | 고정된 미지의 상수 | 확률 분포를 가진 확률 변수 |
| **사전 정보** | 사용하지 않음 | 사전 확률로 명시적 반영 |
| **데이터 부족 시** | 불안정한 추정 | 사전에 의존하여 안정적 |
| **대표 기법** | MLE, 신뢰 구간, p-value | MAP, 사후 분포, 베이즈 팩터 |

### 과목 융합 관점
- **보안**: 침입 탐지 시스템(IDS)에서 알람이 울렸을 때 실제 공격일 확률 = 베이즈 정리. 오탐률(위양성)이 높으면 유용성이 급감한다.
- **자율주행**: 칼만 필터는 센서 데이터(우도)로 차량 위치(사전)를 갱신(사후)하는 연속적 베이즈 갱신이다.
- **A/B 테스트**: 베이지안 A/B 테스트는 전환율의 사후 분포를 직접 구하여 "A가 B보다 나을 확률"을 계산한다.

- **📢 섹션 요약 비유**: 빈도주의는 "100번 던져서 센다"이고, 베이지안은 "경험(사전) + 새 데이터 = 업데이트"입니다.

## Ⅳ. 실무 적용 및 기술사 판단

### 실무 시나리오

1. **시나리오 — Gmail 스팸 필터**: 나이브 베이즈 기반으로 시작하여 수억 개의 이메일에서 단어별 우도를 학습한다. 새 이메일의 단어 조합에 대해 $P(\text{spam}|\text{words})$를 계산하여 0.5 이상이면 스팸으로 분류한다.

2. **시나리오 — COVID-19 신속 항원 검사**: 민감도 80%, 특이도 97%, 유병률 5%일 때 양성의 양성 예측값은 약 58%. 유병률이 0.5%로 떨어지면 양성 예측값은 약 12%로 급감한다.

### 안티패턴
- **기저율 무시**: "99% 정확한 검사에서 양성이 나왔으니 99% 확실하다"는 오류. 유병률을 무시하면 위양성에 속는다.

- **📢 섹션 요약 비유**: "99% 정확"이라는 말에 속지 마세요. 인구 1,000만 명 중 환자가 100명이면, 정상인 중 위양성이 50만 명 나옵니다.
