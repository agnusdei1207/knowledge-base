# 📖 【암기용】 개념 완전 이해

> 목적: 베이즈 정리를 처음 봐도 완전히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 새 증거를 관측한 뒤 원인 가설의 확률을 갱신하는 조건부 확률 규칙
- **왜 필요한가**: 스팸 필터, 진단, 이상탐지, 분류 모델은 관측 데이터가 주어졌을 때 어떤 원인이 더 그럴듯한지 계산해야 함
- **핵심 직관**: 처음 믿음(사전확률)에 증거의 설명력(우도)을 곱하고 전체 가능성으로 나눠 믿음을 갱신함

## 깊이 이해
- **배경·문제의식**
  - 현실 문제는 원인을 직접 볼 수 없는 경우가 많다
  - 베이즈 정리는 결과 B가 관측됐을 때 원인 A의 확률 `P(A|B)`를 계산함
- **작동 원리**
  - `P(A|B)=P(B|A)P(A)/P(B)`이다
  - 사전확률 `P(A)`, 우도 `P(B|A)`, 증거확률 `P(B)`를 결합해 사후확률을 산출함
- **비유**: 비가 올 가능성을 아침에는 30%로 보다가, 검은 구름이라는 증거를 본 뒤 70%로 갱신하는 방식임.
- **구체 예시**: 유병률 1%, 민감도 99%, 특이도 95% 검사에서 양성자의 실제 유병 확률은 `0.99*0.01 / (0.99*0.01+0.05*0.99) = 16.7%`임.
- **흔한 오해·주의점**
  - `P(A|B)`와 `P(B|A)`는 다르다
  - 검사 양성일 확률과 실제 질병일 확률을 바꾸면 기저율 오류가 발생함

## 연결 개념
- 조건부 확률: 베이즈 정리의 기반
- 나이브 베이즈: 특성 독립 가정 기반 분류기
- 사전확률·우도·사후확률: 베이지안 추론의 3요소

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 베이즈 정리는 증거 B 관측 후 가설 A의 확률 `P(A|B)`를 갱신하는 조건부 확률 공식이다.
> 2. **가치**: 불확실한 원인 추론을 사전확률·우도·증거확률의 곱셈 구조로 정량화함.
> 3. **판단 포인트**: 기저율, 민감도·특이도, 독립성 가정이 사후확률의 신뢰도를 좌우함.

---

## Ⅰ. 개요 및 필요성

- 정의: 증거 관측 후 원인 가설의 확률을 갱신하는 조건부 확률 규칙
- 배경: 장애 원인, 보안 이벤트, 의료 진단, 스팸 분류는 원인을 직접 관측하기 어려움
- 필요성: 사전확률과 우도를 결합하면 증거 관측 후 원인 가능성을 수치로 판단할 수 있음

---

## Ⅱ. 구조 및 구성요소

```text
사전확률 P(A) + 우도 P(B|A) -> 결합확률 P(A,B)
증거확률 P(B) -> 정규화 -> 사후확률 P(A|B)
```

| 구성요소 | 역할 | 판단 기준 |
|:---|:---|:---|
| 사전확률 `P(A)` | 증거 관측 전 가설 확률 | 기저율, 과거 빈도 |
| 우도 `P(B|A)` | 가설이 참일 때 증거 발생 확률 | 민감도, 탐지율 |
| 증거확률 `P(B)` | 증거가 전체에서 발생할 확률 | 전확률 공식 |
| 사후확률 `P(A|B)` | 증거 반영 후 가설 확률 | 의사결정 임계값 |

> 요약: 베이즈 정리는 사전확률과 우도를 곱한 값을 전체 증거확률로 정규화해 사후확률을 산출함.

---

## Ⅲ. 동작원리 및 흐름도

```text
가설 설정 -> 사전확률 산정 -> 증거 관측 -> 우도 계산 -> 사후확률 갱신
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 가설 A와 증거 B 구분 | 원인·결과 혼동 제거 |
| 2 | `P(A)` 산정 | 기저율 데이터 |
| 3 | `P(B|A)`, `P(B|not A)` 산정 | 민감도·위양성률 |
| 4 | `P(A|B)` 계산·임계값 비교 | `P(A|B) >= T` |

> 요약: 가설과 증거를 분리한 뒤 기저율과 우도를 전확률 공식으로 정규화해 사후확률을 계산함.

---

## Ⅳ. 특징

| 구분 | 빈도주의 판단 | 베이즈 판단 | 수치·판단 포인트 |
|:---|:---|:---|:---|
| 확률 관점 | 장기 빈도 | 믿음의 갱신 | 사전에서 사후로 갱신 |
| 입력 정보 | 표본 데이터 중심 | 사전정보+관측증거 | `P(A)`, `P(B|A)` |
| 오류 포인트 | 표본 편향 | 기저율 오류 | 양성예측도 16.7% 사례 |
| ML 적용 | 판별 모델 | 생성·확률 모델 | Naive Bayes |

> 요약: 베이즈 정리는 사전정보를 활용하지만, 기저율과 우도 품질이 낮으면 사후확률도 편향됨.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존/대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | 빈도주의 추정 | 베이즈 갱신 | 사전정보와 관측증거를 결합할 때 |
| 비용/성능 | 단일 임계값 | 사후확률 임계값 | 위양성 비용과 미탐 비용 비교 |
| 운영/위험 | 탐지율만 사용 | 기저율·우도 동시 사용 | 낮은 발생률 이벤트에서 필수 |

> 요약: 베이즈 정리는 사전확률이 낮은 보안·장애 이벤트에서 위양성 해석을 정량화함

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 기저율 오류 | 낮은 `P(A)` 무시 | 사전확률을 기간별 재산정 | posterior calibration error |
| 독립성 가정 오류 | Naive Bayes 특성 상관 | feature selection, 상관 제거 | AUC, Brier score |
| 0확률 문제 | 미관측 단어·이벤트 | Laplace smoothing `alpha=1` | 0 probability count |

> 요약: 베이즈 적용 리스크는 기저율, 독립성, 0확률이며 calibration과 smoothing으로 통제함

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 예측 품질 | AUC·precision·recall 목표 충족 | 검증 데이터 |
| 확률 보정 | Brier score 감소 | calibration plot |
| 운영 임계값 | 위양성률·미탐률 균형 | confusion matrix |

> 요약: 베이즈 모델 성공은 분류 정확도보다 확률 보정과 임계값 비용 균형으로 판단함

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 보안탐지: 이벤트 발생률 0.1%, 탐지율 98%, 위양성률 1%를 적용해 알람별 실제 침해확률을 계산
2. 장애진단: CPU 포화, DB Lock, 네트워크 지연의 사전확률과 관측 로그 우도로 원인 순위를 산출
3. 분류모델: 나이브 베이즈에서 단어별 조건부 확률에 Laplace Smoothing `alpha=1`을 적용해 0확률 문제 제거

**결론 (2줄):**
- 기술사 판단: 관측 증거로 원인을 추론하는 문제는 베이즈 정리를 적용하고, 기저율이 낮으면 위양성률을 먼저 검토함
- 향후 방향: MLOps에서는 베이지안 업데이트를 온라인 학습·A/B 테스트·이상탐지 임계값 보정에 결합하는 방식이 적합함
