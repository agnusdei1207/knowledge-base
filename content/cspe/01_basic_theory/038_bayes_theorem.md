## 미리 알고가기

- 조건부 확률: 어떤 사건이 발생했다는 조건에서 다른 사건의 확률을 계산하는 방식임
- 사전 확률: 증거를 관측하기 전에 가설이 참일 확률임
- 우도: 가설이 참이라고 가정할 때 관측 증거가 나타날 확률임
- 증거 확률: 모든 가능한 가설을 고려했을 때 증거가 나타날 전체 확률임
- 사후 확률: 증거를 반영한 뒤 갱신된 가설의 확률임

## Ⅰ. 개요

- **정의**: 베이즈 정리는 사전 확률과 우도를 증거 확률로 정규화해 사후 확률을 계산하는 조건부 확률 공식이며, 새로운 관측 데이터가 들어왔을 때 가설의 믿음 정도를 체계적으로 갱신하기 위해 사용함.
- **배경/필요성**: 진단, 스팸 필터링, 이상 탐지, 머신러닝 추론에서는 초기 정보와 관측 증거를 함께 반영해야 하므로 `P(A|B)`와 `P(B|A)`를 구분하는 확률 갱신 원리가 필요함.
- **비유**: 의사가 기본 유병률과 검사 정확도를 함께 고려해 양성 판정 후 실제 질병 가능성을 다시 계산하는 과정과 같음.

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 베이즈 공식과 확률 갱신 설명 | 사전, 우도, 증거, 사후 | `P(A|B)`와 `P(B|A)` 혼동 |
| 통계 추론 연결 이해 | 기저율, 나이브 베이즈, 베이지안 추론 | 검사 정확도만으로 결론 도출 |

> 요약: 베이즈 정리는 증거를 관측한 뒤 가설 확률을 사전에서 사후로 갱신하는 조건부 확률의 핵심 공식임.

## Ⅱ. 특징/비교

| 판단 기준 | 빈도론적 관점 | 베이지안 관점 |
|:---|:---|:---|
| 확률 해석 | 장기 반복 시행의 상대 빈도로 해석함 | 불확실한 믿음의 정도로 해석함 |
| 모수 관점 | 모수는 고정되어 있고 표본이 무작위임 | 모수도 확률분포로 표현할 수 있음 |
| 추론 방식 | p-value, 신뢰구간으로 판단함 | 사전분포와 우도로 사후분포를 계산함 |
| 선택 기준 | 반복 실험과 표준 검정이 명확할 때 적합함 | 사전 지식과 순차 갱신이 중요할 때 적합함 |

- **공식 기준**: `P(A|B) = P(B|A) P(A) / P(B)`에서 분모는 전체 확률로 결과를 정규화함.
- **해석 기준**: 우도는 증거가 가설을 얼마나 잘 설명하는지이고, 사후 확률은 증거 반영 후 가설 확률임.
- **주의 기준**: 기저율이 낮은 사건은 검사 정확도가 높아도 사후 확률이 낮을 수 있음.

> 요약: 베이즈 정리는 빈도론과 대립되는 철학만이 아니라 조건부 확률의 수학 공식이며, 사전 정보와 관측 증거를 결합하는 선택 기준을 제공함.

## Ⅲ. 구성요소

```text
+------------+      +------------+      +------------+
| Prior      | ---> | Likelihood | ---> | Posterior  |
| P(A)       |      | P(B|A)     |      | P(A|B)     |
+------------+      +------------+      +------------+
       |                   |                   ^
       v                   v                   |
+------------+      +------------+      +------------+
| Hypothesis |      | Evidence   | ---> | Normalize  |
| A          |      | B          |      | P(B)       |
+------------+      +------------+      +------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 가설 A | 참인지 알고 싶은 사건이나 원인 변수임 | 의심 질병 |
| 증거 B | 관측된 데이터나 검사 결과이며 확률 갱신의 근거가 됨 | 양성 검사 결과 |
| 사전 확률 P(A) | 증거 관측 전 가설의 기본 확률임 | 유병률 |
| 우도 P(B|A) | 가설이 참일 때 증거가 나타날 확률임 | 질병이 있을 때 양성일 확률 |
| 증거 확률 P(B) | 모든 가설에서 증거가 나타날 전체 확률로 사후 확률을 정규화함 | 전체 양성률 |

> 요약: 베이즈 정리는 가설, 증거, 사전 확률, 우도, 증거 확률을 결합해 사후 확률을 계산하는 구조임.

## Ⅳ. 절차

```text
+------------+      +------------+      +------------+      +------------+
| Set Prior  | ---> | Compute    | ---> | Normalize  | ---> | Update     |
| P(A)       |      | Likelihood |      | Evidence   |      | Posterior  |
+------------+      +------------+      +------------+      +------------+
```

1. **사전 확률 설정**: 과거 데이터, 도메인 지식, 기본 발생률로 가설의 초기 확률을 정함.
2. **우도 계산**: 가설이 참일 때 현재 증거가 관측될 확률을 모델이나 조건부 확률표로 구함.
3. **증거 확률 산출**: 모든 가설에 대해 `P(B|A_i)P(A_i)`를 합산해 정규화 상수를 계산함.
4. **사후 확률 갱신**: 베이즈 공식으로 `P(A|B)`를 구하고 의사결정 기준과 비교함.

> 요약: 베이즈 추론은 사전 확률, 우도, 증거 확률을 차례로 계산해 관측 후 가설 확률을 갱신하는 과정임.

## Ⅴ. 문제점

- **P1 사전 확률 민감성**: 데이터가 적거나 사전 정보가 강하면 사전 확률 선택이 결론을 크게 바꿀 수 있음.
- **P2 증거 확률 계산 난이도**: 고차원 연속 변수에서는 `P(B)` 적분이나 합산이 계산적으로 어려움.
- **P3 기저율 무시**: 낮은 기본 발생률을 무시하면 우도가 높은 검사 결과를 과대 해석해 사후 확률을 잘못 판단함.

> 요약: 베이즈 적용의 핵심 위험은 사전 선택, 정규화 계산, 기저율 해석 오류임.

## Ⅵ. 개선방안

- **P1 대응**: 약정보 사전, 민감도 분석, 데이터 증가에 따른 사후 변화 확인으로 사전 의존성을 점검함. (확인: prior sensitivity)
- **P2 대응**: MCMC, 변분 추론, 라플라스 근사 같은 근사 추론으로 계산 불가능한 적분을 처리함. (확인: 수렴 진단)
- **P3 대응**: 자연 빈도 표현과 혼동행렬로 기저율을 시각화해 우도와 사후 확률을 분리해 설명함. (확인: base-rate 포함 여부)

> 요약: 베이즈 추론은 사전 민감도, 근사 계산 품질, 기저율 설명을 함께 관리해야 의사결정에 안전하게 쓸 수 있음.

## Ⅶ. 전망

- **발전 방향**: 베이지안 딥러닝, 확률적 프로그래밍, 온라인 학습, 불확실성 정량화에서 베이즈 정리 기반 추론은 의사결정 설명 도구로 확대될 전망임.
- **설계 관점**: 사전 정보의 근거, 우도 모델, 증거 계산 방식, 사후 갱신 주기를 명시해 추론 구조를 설계해야 함.
- **검증 관점**: prior sensitivity, posterior predictive check, MCMC 수렴, 기저율 반영 여부를 확인해 결론이 입력 가정에 과도하게 의존하지 않는지 검증해야 함.
- **운영 관점**: 순차 데이터가 들어오는 서비스에서는 사전 확률 갱신 이력, 데이터 drift, 근사 추론 수렴 실패를 모니터링해야 함.
- **적용 관점**: 사전 지식과 불확실성 설명이 중요한 진단·위험평가에는 유용하지만, 사전 근거가 약하면 민감도 분석 없이 결론을 확정하지 않아야 함.
- **보안·신뢰 관점**: 조작된 우도 입력이나 기저율 누락은 과신 판정을 만들 수 있으므로 자연 빈도와 혼동행렬로 의사결정 근거를 검증해야 함.
- **기술사 제언**: 답안에서는 공식보다 `사전 -> 우도 -> 증거 -> 사후` 흐름과 `P(A|B)`/`P(B|A)` 구분을 중심으로 작성해야 함.
