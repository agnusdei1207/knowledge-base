## 미리 알고가기

- 조건부 확률: 사건 $B$가 발생했다는 조건에서 사건 $A$가 발생할 확률임
- 사전 확률: 증거를 보기 전 가설에 부여한 초기 확률임
- 우도: 특정 가설이 참일 때 현재 증거가 관측될 확률임
- 사후 확률: 증거를 반영한 뒤 갱신된 가설의 확률임
- 기저율: 모집단에서 사건이 원래 발생하는 기본 비율임

## 작성 근거(검토용)

- 베이즈 정리의 핵심은 공식 자체보다 사전에서 사후로 갱신되는 흐름이므로 절차를 갱신 중심으로 구성함
- 미리 알고가기에 사전 확률·우도·사후 확률을 정의해 베이즈 공식의 각 항과 연결함
- 비교표는 빈도주의와 베이지안을 두어 확률 해석과 데이터 사용 차이를 시험 답안형으로 정리함
- 구성요소는 공식의 각 항을 역할 중심으로 설명해 수식 암기가 아니라 의미 파악을 돕게 함
- 독립 가정 위반과 기저율 무시는 베이즈 적용의 대표 오판 원인임

## Ⅰ. 개요

- **정의/개념**: 베이즈 정리는 관측 증거를 이용해 사전 확률을 사후 확률로 갱신하는 조건부 확률 공식임
- **배경/필요성**: 불확실한 상황에서 가설 확률을 갱신하려면 기존 지식과 새 데이터를 결합하는 기준이 필요함

## Ⅱ. 특징

- 사전 지식과 관측 데이터를 하나의 확률식으로 결합함
- 새 증거가 들어올 때마다 순차적으로 확률을 갱신함
- 기저율을 반영해 검사 정확도만으로 희귀 사건의 발생 확률을 과대평가하는 오류를 줄임
- 모델 가정과 사전 확률 선택이 결과에 영향을 줌

## Ⅲ. 종류 및 비교

| 판단 기준 | 빈도주의 통계 | 베이지안 통계 |
|:---|:---|:---|
| 확률 해석 | 반복 실험의 장기 빈도 | 주어진 정보에서 가설이 갖는 불확실성의 정도 |
| 모수 관점 | 고정된 미지 값 | 확률분포를 갖는 값 |
| 결과 표현 | p-value·신뢰 구간 | 사후 분포·예측 확률 |
| 갱신 방식 | 반복 표본의 분포로 고정 모수를 추론 | 사전 분포와 우도를 결합해 사후 분포를 갱신 |
| 대표 적용 사례 | 임상 시험·품질 검정 | 스팸 필터·고장 진단·A/B 테스트 갱신 |

> 요약: 베이지안 접근은 기존 확률 판단을 데이터로 갱신하는 추론 방식임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 가설 $H$ | 판단하려는 원인 또는 상태임 |
| 증거 $E$ | 가설 판단에 새로 반영할 관측 데이터임 |
| 사전 확률 $P(H)$ | 증거 반영 전 가설의 초기 가능성임 |
| 우도 $P(E|H)$ | 가설이 참일 때 증거가 나올 가능성임 |
| 주변 확률 $P(E)$ | 모든 가설에서 증거가 발생할 전체 확률임 |

```text
P(H|E) = P(E|H) * P(H) / P(E)

사후 확률 = 우도 * 사전 확률 / 증거 확률
```

> 요약: 베이즈 정리는 우도와 사전 확률을 증거 확률로 정규화해 사후 확률을 만듦.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+   +----------+   +----------+   +----------+
| 사전 설정 | -> | 증거 관측 | -> | 우도 계산 | -> | 사후 갱신 |
+----------+   +----------+   +----------+   +----------+
```

1. 과거 데이터나 도메인 지식으로 사전 확률을 정함
2. 센서·로그·실험으로 새 증거를 수집함
3. 각 가설에서 증거가 나올 우도를 계산함
4. 베이즈 정리로 사후 확률을 구하고 다음 사전 확률로 사용함

> 요약: 새 증거가 들어올 때마다 사후 확률을 다음 판단의 사전 확률로 재사용함.

## Ⅵ. 실무 사례

1. 스팸 필터는 단어 우도와 사전 확률로 사후 확률을 계산하고 정밀도·재현율을 확인함
2. 서버 장애 진단은 장애 기저율과 센서 경보 우도로 사후 확률을 계산하고 오탐률을 확인함

## Ⅶ. 결론

- 베이즈 정리는 사전 지식과 관측 증거를 결합해 가설 확률을 반복적으로 갱신하는 확률 추론의 기본 원리임
