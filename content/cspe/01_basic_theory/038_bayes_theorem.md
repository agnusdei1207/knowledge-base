## Ⅰ. 개요
- **정의**: 사전 확률 P(A)와 우도 P(B|A)로부터 사후 확률 P(A|B)를 갱신하는 조건부 확률 공식
- **배경/필요성**: 새로운 데이터(증거)가 관측될 때 기존 믿음을 체계적으로 갱신하는 수학적 프레임워크가 필요함
- **비유**: 의사가 환자의 증상(증거)을 보고 질병 확률(믿음)을 갱신하는 진단 과정

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| P(A|B) = P(B|A)P(A)/P(B) 공식 유도 | 사전→우도→사후 갱신 흐름 | P(B|A)와 P(A|B)를 혼동(검사 오류율 ≠ 질병 확률)하지 않음 |
| 039 확률분포·040 가설검정과의 차이 | 베이즈는 확률 갱신, 빈도론은 고정 모수 추정 | 베이즈 정리 자체는 빈도론에서도 성립하는 수학 정리임을 명시 |

> 요약: P(A|B) = P(B|A)·P(A)/P(B)로, 새 증거에 따라 사전 확률을 사후 확률로 갱신하는 정리임.

## Ⅱ. 구성요소
```text
+----------+     +----------+     +----------+
| 사전확률  | --> |  우도    | --> | 사후확률  |
| P(A)     |     | P(B|A)  |     | P(A|B)  |
+----------+     +------|---+     +----------+
                        |
                   +----+-----+
                   | 증거확률  |
                   | P(B)     |
                   +----------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 사전 확률 P(A) | 증거 관측 전 가설 A의 초기 확률(도메인 지식 반영) | 검사 전 질병 유병률 |
| 우도 P(B\|A) | 가설 A가 참일 때 증거 B가 관측될 확률(모델의 설명력) | 질병 있을 때 양성 확률 |
| 증거 확률 P(B) | 모든 가설에서 증거 B가 관측될 전체 확률(정규화 상수) | 전체 양성률 |
| 사후 확률 P(A\|B) | 증거 B를 관측한 후 갱신된 가설 A의 확률 | 양성 결과 후 실제 질병 확률 |

> 요약: 사전 P(A) × 우도 P(B|A) / 증거 P(B) = 사후 P(A|B)로 확률을 갱신함.

## Ⅲ. 절차
```text
+------------+     +------------+
| 사전확률   | --> | 우도계산   |
| P(A) 설정  |     | P(B|A)    |
+------------+     +------------+
                        |
+------------+     +----+-------+
| 사후확률   | <-- | 정규화    |
| P(A|B)    |     | / P(B)    |
+------------+     +------------+
```

1. **사전 확률 설정** — 도메인 지식·과거 데이터로 가설의 초기 확률 P(A)를 설정함
2. **우도 계산** — 가설 A 하에서 증거 B가 관측될 조건부 확률 P(B|A)를 산출함
3. **증거 확률 계산** — P(B) = ΣP(B|Aᵢ)P(Aᵢ)로 전체 확률을 구함(정규화 상수)
4. **사후 확률 산출** — P(A|B) = P(B|A)·P(A)/P(B)를 계산하여 갱신된 확률을 도출함

> 요약: 사전 설정 → 우도 산출 → 정규화 → 사후 갱신의 4단계로 확률을 갱신함.

## Ⅳ. 문제점
- [사전 확률 주관성]: 사전 확률 선택이 분석자에 따라 달라져 결과 편향이 발생함
- [계산 복잡도]: 다변량·연속 분포에서 P(B) 적분이 해석적으로 풀리지 않음
- [기저율 무시]: 낮은 유병률(사전 확률)을 무시하고 양성 결과만 보면 위양성을 과대평가함

> 요약: 사전 주관성·적분 난이도·기저율 무시가 실무 적용의 주요 장벽임.

## Ⅴ. 개선방안
1. 단기: 무정보 사전(제프리스·균일분포)을 사용하여 사전 확률의 주관 편향을 최소화함
2. 중기: MCMC(Markov Chain Monte Carlo) 샘플링으로 해석 불가 적분을 근사 계산함
3. 장기: 변분 추론(Variational Inference)으로 대규모 데이터·모델에서 실시간 사후 추론을 수행함

- [사전 주관성]: 분석자 의존 → 무정보/약정보 사전 + 민감도 분석 (지표: 사전 변경 시 결론 불변)
- [계산 복잡도]: P(B) 적분 불가 → MCMC/VI로 근사 (지표: 수렴 진단 R-hat < 1.01)
- [기저율 무시]: 오해 빈발 → 자연 빈도(1000명 중 10명 유병) 표현으로 직관적 해석 유도

> 요약: 무정보 사전·MCMC·변분 추론으로 주관성과 계산 한계를 극복함.
