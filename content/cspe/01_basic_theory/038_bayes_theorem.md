## 미리 알고가기

- **사전 확률 (Prior Probability)**: 어떠한 증거가 관찰되기 전, 사건 $A$가 발생할 확률 $P(A)$. 기존의 지식이나 통계치를 의미함
- **사후 확률 (Posterior Probability)**: 증거 $B$가 관찰된 후, 사건 $A$가 발생할 확률 $P(A|B)$. 새로운 정보를 반영해 갱신된 믿음의 정도임
- **우도 (Likelihood)**: 가설 $A$가 참일 때 증거 $B$가 나타날 확률 $P(B|A)$. 해당 증거가 가설을 얼마나 잘 설명하는지의 척도임

## 1. 개요

- **정의/개념**: 베이즈 정리(Bayes' Theorem)는 새로운 정보나 증거가 주어졌을 때 기존의 확률을 정량적으로 갱신하는 조건부 확률 공식임. 즉, 관찰된 사실로부터 원인이 무엇인지를 역으로 추론(Inference)하는 수리적 체계임
- **배경/필요성**: 현실 세계의 의사결정은 항상 불확실성을 동반함. 암 진단 검사에서 양성이 나왔을 때 실제 암일 확률, 이메일에 특정 단어가 포함되었을 때 스팸일 확률 등은 단순한 검사 정확도만으로 판단할 수 없음. 베이즈 정리는 기존의 배경 지식(사전 확률)과 관측된 데이터(우도)를 결합하여, 불확실한 상황에서 가장 합리적인 판단을 내릴 수 있는 근거를 제공함

## 2. 특징 및 비교

### 가. 베이지안 확률과 빈도주의 확률의 비교

| 구분 | 빈도주의 (Frequentist) | 베이지안 (Bayesian) |
|:---|:---|:---|
| 확률의 정의 | 무한 반복 시행 시 나타나는 상대 빈도 | 주관적인 믿음의 정도 (Degree of belief) |
| 미지수 처리 | 고정된 상수로 취급 (알려지지 않음) | 확률 분포를 가진 변수로 취급 |
| 데이터 활용 | 현재 관측된 데이터에만 의존 | 관측 데이터 + 사전 지식(Prior) 결합 |
| 갱신 가능성 | 데이터가 늘어나면 추정값이 변함 | 새로운 증거에 의해 확률이 지속 갱신됨 |
| 주요 활용 | 가설 검정, p-value 산출 | 머신러닝, 스팸 필터, 자율주행 추론 |

> 요약: 빈도주의는 '데이터의 빈도'를 보고, 베이지안은 '지식의 갱신'을 중시함

### 나. 베이즈 정리의 핵심 원리
- **역확률 추론**: 결과($B$)로부터 원인($A$)을 추론함
- **증거의 힘**: 우도($P(B|A)$)가 높을수록 해당 증거는 사후 확률을 결정짓는 강력한 요인이 됨
- **사전 지식의 보존**: 관측 데이터가 부족할 때는 사전 확률이 판단의 기준이 되며, 데이터가 많아질수록 데이터의 영향력이 커짐

## 3. 구성요소/구조

### 가. 베이즈 정리 수식 구조

$$P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}$$

- $P(A|B)$: 사후 확률 (Posterior) - 우리가 알고 싶은 것
- $P(B|A)$: 우도 (Likelihood) - 가설 하에서 증거가 나올 확률
- $P(A)$: 사전 확률 (Prior) - 증거 전의 가설 확률
- $P(B)$: 증거 확률 (Evidence/Marginal) - 정규화 상수

### 나. 추론 시스템의 논리 흐름도

```text
[기존 믿음 (Prior)] -> [새로운 증거 관측] -> [증거의 신뢰도 분석 (Likelihood)] -> [믿음의 갱신 (Posterior)]

1. Prior: 인구 중 질병 유병률은 1%임
2. Evidence: 진단 키트 결과 '양성' 판정
3. Likelihood: 실제 환자가 양성일 확률(민감도)은 99%임
4. Posterior: 양성 판정 시 실제 환자일 확률은? (기존 1%에서 갱신됨)
```

| 구성요소 | 역할 및 설명 | 핵심 포인트 |
|:---|:---|:---|
| 가설 (Hypothesis) | 알고자 하는 원인이나 상태 | 예: 스팸 메일이다, 암에 걸렸다 |
| 증거 (Evidence) | 실제로 관찰된 현상이나 데이터 | 예: 특정 단어 포함, 검사 양성 |
| 조건부 확률 | 한 사건이 일어났다는 전제 하의 확률 | $P(A|B)$와 $P(B|A)$의 구분이 핵심 |
| 정규화 상수 | 전체 확률의 합을 1로 맞춰주는 분모 | 증거가 발생할 모든 경로의 합 |

> 요약: 사전 지식에 증거의 설명력을 곱해 사후 판단을 도출하는 정교한 연쇄 구조임

## 4. 문제점 및 개선방안

1. **사전 확률(Prior) 선정의 주관성**: 분석가의 주관에 따라 사전 확률이 달라지면 결과인 사후 확률도 왜곡될 수 있음
   - **개선방안**: 객관적인 통계 데이터(Base Rate)를 활용하거나, 정보가 없을 때는 무정보 사전 확률(Uninformative Prior)을 사용하여 편향을 최소화함

2. **기저율 무시(Base Rate Fallacy)의 오류**: 검사 결과가 매우 정확해 보이더라도, 실제 발생 확률(사전 확률)이 극히 낮으면 사후 확률도 낮을 수 있다는 점을 간과함
   - **개선방안**: 베이즈 정리를 시각화(Tree Diagram 등)하여 사전 확률의 영향력을 직관적으로 파악하고 정량적 수치를 반드시 산출함

3. **나이브 베이즈의 과도한 독립성 가정**: 여러 증거가 서로 연관되어 있음에도 모두 독립이라고 가정하면 정확도가 떨어짐
   - **개선방안**: 증거 간의 인과 관계를 반영하는 베이지안 네트워크(Bayesian Network)를 구축하여 복잡한 상관관계를 모델링함

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| 의료 진단 시스템 | 환자의 증상과 검사 결과를 결합하여 최종 질병 확진 확률 산출 | 민감도(Recall), 특이도(Specificity) |
| 스팸 메일 필터 | 제목/본문에 나타난 단어들의 우도를 곱해 스팸 여부 판단 | 정밀도(Precision), 오탐율(False Positive) |
| 로봇/자율주행 | 센서 데이터(LiDAR/GPS)를 통해 로봇의 현재 위치 확률 갱신 (Kalman Filter) | 위치 오차(RMSE), 수렴 속도 |

> 요약: 새로운 데이터가 끊임없이 유입되는 동적인 환경에서 판단을 최적화할 때 반드시 사용됨

## 6. 결론

베이즈 정리는 고정된 진리가 아닌, '데이터에 따라 진화하는 판단'을 수학적으로 구현한 철학적 기술임. 단순한 공식 계산을 넘어, 우리가 가진 지식의 한계를 인정하고 새로운 증거를 통해 이를 끊임없이 보정해 나가는 합리적 추론의 표준임.

기술사는 데이터 분석 시 단순 빈도에만 집착하지 않고, 비즈니스 맥락이 담긴 사전 확률을 모델에 어떻게 녹여낼지 고민해야 함. 특히 AI 모델의 신뢰성과 설명 가능성(XAI)이 중요해지는 시점에서, 베이즈 정리는 블랙박스 모델의 불확실성을 수치화하고 제어할 수 있는 가장 신뢰받는 도구로 남을 것임.
