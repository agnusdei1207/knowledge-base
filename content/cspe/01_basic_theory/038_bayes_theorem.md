## Ⅰ. 개요
- **정의**: 사전 확률과 관측 데이터를 결합하여 사후 확률을 갱신하는 조건부 확률 공식
- **배경/필요성**: 새 증거가 추가될 때 기존 판단을 체계적으로 수정하는 수학적 틀이 필요함
- **비유**: 의사가 검사 결과(증거)를 보고 환자의 질병 가능성(판단)을 재조정하는 과정과 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 조건부 확률 갱신 원리와 응용 이해 | 사전·사후 확률, 우도, 전확률 공식 | 사전 확률과 우도의 역할 혼동 주의 |

> 요약: 증거 기반으로 확률을 갱신하는 조건부 확률의 핵심 정리임

## Ⅱ. 구성요소
```text
         베이즈 정리 : P(A|B) = P(B|A)*P(A) / P(B)
              |
     +--------+--------+--------+
     |        |        |        |
  사전확률  우도     증거     사후확률
  P(A)     P(B|A)   P(B)    P(A|B)
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 사전 확률 P(A) | 증거 관측 전 가설 A가 참일 확률 | 병원 방문 전 환자의 유병률 |
| 우도 P(B\|A) | 가설 A가 참일 때 증거 B가 관측될 확률 | 질병이 있을 때 양성 결과가 나올 비율 |
| 증거 P(B) | 모든 가설 하에서 증거 B가 관측될 전체 확률 | 전체 검사 양성률 |
| 사후 확률 P(A\|B) | 증거 B 관측 후 가설 A가 참일 갱신된 확률 | 양성 결과를 본 뒤의 실제 유병 확률 |

> 요약: 사전 확률에 우도를 곱하고 증거로 정규화하여 사후 확률을 산출함

## Ⅲ. 절차
```text
  1.사전설정       2.우도산출       3.증거계산       4.사후갱신
  (가설확률)      (조건부확률)    (전확률공식)    (베이즈적용)
     |               |              |              |
     +---P(A)------->+---P(B|A)---->+---P(B)------>+
  도메인지식      데이터에서      전확률공식     P(A|B)계산
  기반사전분포    우도함수도출    으로정규화     후의사결정
```
- 1단계: 도메인 지식이나 기존 데이터를 활용하여 가설의 사전 확률 P(A)를 설정함
- 2단계: 가설이 참일 때 관측 데이터가 나올 우도 P(B|A)를 산출함
- 3단계: 전확률 공식 $P(B) = \sum P(B|A_i)P(A_i)$ 으로 증거 확률을 계산함
- 4단계: $P(A|B) = P(B|A) \cdot P(A) / P(B)$ 를 적용하여 사후 확률을 갱신함

> 요약: 사전 설정 → 우도 산출 → 증거 계산 → 사후 갱신의 4단계로 확률을 갱신함

## Ⅳ. 문제점
- 사전 확률 주관성: 분석자마다 사전 확률이 달라져 동일 데이터에서 상이한 결론이 도출됨
- 고차원 적분 난이도: 변수가 많아지면 사후 분포 계산에 필요한 다중 적분이 해석적으로 불가능함
- 계산 비용 증가: 연속 분포 모형에서 정규화 상수 계산에 대규모 연산 자원이 소요됨

> 요약: 사전 확률 주관성, 고차원 적분 난이도, 계산 비용이 주요 문제임

## Ⅴ. 개선방안
1. 단기: 무정보 사전분포(균등분포 등)를 사용하여 주관성의 영향을 최소화함
2. 중기: MCMC(마르코프 체인 몬테카를로)로 고차원 사후 분포를 근사 샘플링함
3. 장기: 변분 추론(Variational Inference)으로 계산 비용을 줄이며 대규모 모형에 적용함

> 요약: 무정보 사전, MCMC 샘플링, 변분 추론으로 각 문제를 해결함

## Ⅵ. 전망
- 발전 방향: 스팸 필터, 추천 시스템, 의료 진단 등 실시간 확률 갱신 수요가 확대됨
- 기술사적 판단: 딥러닝과 베이즈 추론을 결합한 베이지안 뉴럴넷 연구가 활발함
- 기술사 제언: 사전 분포 선택의 근거를 문서화하고 민감도 분석을 병행해야 함
