## 미리 알고가기

- 가중치: 간선을 따라 한 번 이동할 때 드는 비용, 거리, 지연 시간을 수치로 표현한 값임
- 완화: 기존 경로보다 더 짧은 경로를 찾았을 때 거리 값을 다시 줄이는 갱신 연산임
- 음수 사이클: 반복해서 돌수록 전체 비용이 계속 작아지는 순환 경로임
- 모든 정점 쌍: 그래프에 있는 모든 두 정점 사이의 최단 거리를 한 번에 구하는 범위임

## Ⅰ. 개요

- **정의/개념**: 최단 경로 알고리즘은 그래프에서 출발점과 도착점을 잇는 여러 경로 중 가중치 합이 가장 작은 경로를 구하는 방법임. 문제 범위에 따라 한 출발점에서 모든 정점까지 구할 수도 있고, 모든 정점 쌍의 거리를 한 번에 구할 수도 있음
- **배경/필요성**: 통신 라우팅, 내비게이션, 물류 이동 계획은 두 지점의 연결 여부만 확인해서는 부족하며, 어떤 경로가 가장 적은 비용과 지연으로 목적지에 도달하는지 계산해야 하므로 최단 경로 절차가 필요함

## Ⅱ. 특징

- 최단 경로 계산은 간선을 따라 누적한 비용을 비교하는 문제이므로, 가중치가 거리인지 지연인지 비용인지 먼저 분명히 정해야 함
- 핵심 동작은 완화 연산을 반복해 현재까지 알려진 최단 거리를 점진적으로 줄여 가는 데 있음
- 필요한 결과가 한 출발점 기준인지 모든 정점 쌍 기준인지에 따라 계산 범위와 메모리 사용량이 크게 달라짐
- 음수 가중치와 음수 사이클의 존재 여부가 알고리즘 선택을 좌우하므로, 입력 조건 확인이 계산 결과의 정확성만큼 중요함

## Ⅲ. 종류 및 비교

- **다익스트라**: 음수 가중치가 없을 때 아직 확정하지 않은 정점 중 거리 값이 가장 작은 정점부터 순서대로 확정해 한 출발점에서 다른 모든 정점까지의 최단 거리를 구하는 방식임
- **벨만-포드**: 모든 간선을 정해진 횟수만큼 반복해서 완화하므로 음수 가중치를 다룰 수 있고, 마지막 반복에서 값이 더 줄어드는지를 보고 음수 사이클 존재 여부도 함께 확인할 수 있음
- **플로이드-워셜**: 경유 정점을 하나씩 늘려 가며 모든 정점 쌍의 최단 거리를 갱신하므로 전체 경로표가 필요할 때 적합함

| 판단 기준 | 다익스트라 | 벨만-포드 | 플로이드-워셜 |
|:---|:---|:---|:---|
| 계산 범위 | 한 출발점에서 다른 모든 정점까지의 거리를 구함 | 한 출발점에서 다른 모든 정점까지의 거리를 구함 | 모든 정점 쌍의 거리를 한 번에 구함 |
| 음수 가중치 처리 | 음수 가중치가 있으면 올바른 결과를 보장하지 못함 | 음수 가중치가 있어도 계산할 수 있음 | 음수 가중치를 포함해도 계산할 수 있음 |
| 음수 사이클 확인 | 음수 사이클 존재를 직접 판별하지 못함 | 마지막 완화 검사로 음수 사이클을 확인할 수 있음 | 거리 행렬의 대각 값이 음수로 바뀌는지 보고 음수 사이클 징후를 확인할 수 있음 |
| 시간복잡도 | 시간복잡도는 $O((V+E)\log V)$임. 간선이 적은 희소 그래프에서 유리함 | 시간복잡도는 $O(VE)$임. 속도보다 범용성이 필요한 상황에 적합함 | 시간복잡도는 $O(V^3)$임. 정점 수가 많아지면 계산 부담이 커짐 |
| 적합한 상황 | 실시간 길찾기나 라우팅처럼 빠른 단일 출발점 계산에 적합함 | 입력 제약이 불명확하거나 음수 가중치 검증이 필요한 상황에 적합함 | 전체 거리표나 경유 비용표처럼 모든 정점 관계를 미리 계산해야 할 때 적합함 |

> 요약: 세 알고리즘은 모두 최단 거리를 구하지만, 실제 선택 기준은 속도가 아니라 가중치 제약과 필요한 산출 범위에 있음

## Ⅳ. 구성요소 및 구조

- 세 알고리즘은 출발점부터의 거리 정보를 저장하는 저장소, 간선 하나를 검사해 거리를 갱신하는 완화 연산, 완화를 반복할 대상을 정하는 제어 방식이라는 같은 뼈대를 공유하되, 계산 범위에 따라 저장소의 형태와 제어 방식만 달라짐

| 구성요소 | 설명 |
|:---|:---|
| 거리 저장소 | 다익스트라와 벨만-포드는 정점 수만큼의 거리 배열을 쓰고, 플로이드-워셜은 정점 쌍 전체를 담는 정점 수의 제곱 크기 거리 행렬을 씀 |
| 완화 연산 | 간선 하나를 따라 이동한 거리가 기존 저장 값보다 작으면 값을 갱신하는 연산이며, 세 알고리즘 모두 이 연산을 반복 적용해 최단 거리를 좁혀 감 |
| 반복 제어 | 다익스트라는 우선순위 큐로 거리가 가장 작은 미확정 정점을 뽑아 확정하고, 벨만-포드는 전체 간선을 정해진 횟수만큼 훑으며, 플로이드-워셜은 경유 정점을 하나씩 늘려 가며 모든 정점 쌍을 훑음 |
| 종료 판정 | 다익스트라는 모든 정점이 확정되면 종료하고, 벨만-포드는 반복 횟수를 채운 뒤 한 번 더 완화가 일어나는지로 음수 사이클을 판정하며, 플로이드-워셜은 거리 행렬 대각 값의 음수 여부로 판정함 |

```text
+------------+     +----------------+     +------------------+     +------------+
| 그래프 입력 | --> | 거리 저장소     | --> | 반복 제어         | --> | 거리 결과  |
| (V, E, W)  |     | (배열/행렬) 초기화|    | (완화 반복)       |     | 출력       |
+------------+     +----------------+     +------------------+     +------------+
                                                  |
                                                  v
                                          +------------------+
                                          | 종료/음수 사이클  |
                                          | 판정              |
                                          +------------------+
```

> 요약: 거리 저장소와 완화 연산은 세 알고리즘이 공유하는 구조이고, 반복 제어와 종료 판정 방식만 계산 범위와 음수 가중치 처리 여부에 따라 갈라짐

## Ⅴ. 원리 및 절차 흐름도

```text
+------------+     +----------------+     +------------------+     +------------+
| 조건 식별  | --> | 거리 초기화     | --> | 완화 반복 수행    | --> | 결과 반환  |
| (범위/음수)|     |                 |     |                  |     |            |
+------------+     +----------------+     +------------------+     +------------+
                                                  |
                          +-----------------------+-----------------------+
                          |                        |                       |
                          v                        v                       v
                  +----------------+      +----------------+      +----------------+
                  | 단일 출발점 +   |      | 단일 출발점 +   |      | 모든 정점 쌍    |
                  | 비음수 가중치   |      | 음수 가중치     |      |                |
                  | 다익스트라      |      | 벨만-포드       |      | 플로이드-워셜   |
                  +----------------+      +----------------+      +----------------+
```

1. **조건 식별**: 필요한 계산 범위(단일 출발점 또는 모든 정점 쌍)와 음수 가중치 포함 여부를 확인함
2. **거리 초기화**: 단일 출발점 방식은 출발점 거리를 0, 나머지를 무한대로 두고, 플로이드-워셜은 인접 행렬 값을 그대로 초기 거리로 채움
3. **완화 반복**: 다익스트라는 우선순위 큐로 뽑은 최소 거리 정점을 확정해 이웃을 완화하고, 벨만-포드는 전체 간선을 $V-1$번 반복 완화하며, 플로이드-워셜은 경유 정점을 하나씩 늘려 가며 모든 정점 쌍을 완화함
4. **검증/종료**: 벨만-포드는 한 번 더 완화를 시도해 값이 줄면 음수 사이클로 판정하고, 플로이드-워셜은 대각 값의 음수 여부로 판정하며, 다익스트라는 모든 정점이 확정되면 종료함
5. **결과 반환**: 단일 출발점 알고리즘은 거리 배열을 반환하고, 플로이드-워셜은 거리 행렬 전체를 반환함

## Ⅵ. 실무 적용 및 유의점

1. 실시간 내비게이션 경로 탐색이나 네트워크 라우팅처럼 응답 시간이 중요한 단일 출발점 계산에는 다익스트라를 쓰되, 혼잡 구간 패널티를 음수 값으로 표현하는 가중치 정책이 섞이면 최종 경로가 틀릴 수 있으므로 가중치 설계 단계에서 음수 값 사용을 금지하거나 오프라인에서 벨만-포드로 대조 검증하고 두 결과의 거리 값 차이로 확인함
2. 물류 거점 간 전체 비용표나 백본 라우팅 테이블처럼 모든 정점 쌍의 거리를 미리 계산해 두어야 하는 환경에서는 플로이드-워셜을 쓰되, 거점 수가 늘어나면 한 번의 계산이 배치 주기 안에 끝나지 않을 수 있으므로 거점 수 상한을 정해 야간 배치로 재계산하고 실행 시간과 거리 행렬 갱신 주기로 확인함

## Ⅶ. 결론

최단 경로 알고리즘의 선택은 속도 비교가 아니라 음수 가중치 포함 여부와 요구되는 계산 범위(단일 출발점 또는 모든 정점 쌍)라는 두 조건으로 결정해야 함.
