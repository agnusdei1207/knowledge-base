## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 가중 그래프에서 두 정점 간 간선 가중치 합이 최소인 경로를 찾는 알고리즘 군임 |
| **배경/필요성** | 네트워크 라우팅·네비게이션·물류 최적화 등에서 최적 경로 계산이 필수임 |
| **출제 의도** | 다익스트라·벨만-포드·플로이드의 적용 조건과 시간 복잡도 차이를 비교할 수 있는지 평가함 |

## Ⅱ. 구성요소
```
+----------+     +----------+     +----------+
| 다익스트라 | --> | 벨만-포드 | --> | 플로이드  |
| (단일출발 |     | (음의간선)|     | (전쌍)   |
|  양의가중)|     |          |     |          |
+----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| 다익스트라 | 음이 아닌 가중 그래프에서 단일 출발점 최단 경로를 O(E log V)에 구함 | 가장 빠른 길 내비 |
| 벨만-포드 | 음의 가중치를 허용하며 단일 출발점 최단 경로를 O(VE)에 구하고, 음의 사이클을 탐지함 | 할인 쿠폰(음의 비용)이 있는 경로 탐색 |
| 플로이드-워셜 | 모든 정점 쌍 간 최단 경로를 O(V³)에 구하는 DP 기반 알고리즘임 | 전체 구간 요금표 작성 |

> 요약: 양의 가중치(다익스트라), 음의 가중치(벨만-포드), 전쌍(플로이드)으로 조건에 따라 선택함.

## Ⅲ. 절차
```
+------------+     +------------+
| 거리배열   | --> | 최소정점   |
| 초기화(∞)  |     | 선택(PQ)  |
+------------+     +------------+
                        |
+------------+     +----+-------+
| 최단경로   | <-- | 인접정점  |
| 확정       |     | 거리갱신   |
+------------+     +------------+
```

1. 초기화: 출발 정점 거리를 0, 나머지를 ∞로 설정함
2. 최소 정점 선택: 우선순위 큐에서 거리가 가장 작은 미방문 정점을 추출함(다익스트라)
3. 인접 정점 거리 갱신: `dist[v] > dist[u] + w(u,v)`이면 dist[v]를 갱신함(Relaxation)
4. 반복·완료: 모든 정점이 확정될 때까지 반복하여 최단 경로를 확정함

> 요약: 초기화 → 최소 선택 → Relaxation → 반복으로 최단 경로를 구함.

## Ⅳ. 문제점
- 다익스트라 음의 가중치 불가: 음의 간선이 있으면 탐욕적 선택이 최적을 보장하지 않음
- 벨만-포드 O(VE): 대규모 그래프에서 다익스트라 대비 성능이 저하됨
- 플로이드 O(V³): 정점 수 증가 시 시간·공간이 급격히 증가하여 대규모 그래프에 부적합함

## Ⅴ. 개선방안
- (단기) 피보나치 힙: 다익스트라의 PQ를 피보나치 힙으로 교체하여 O(V log V + E)로 개선함
- (중기) SPFA: 벨만-포드의 변형으로 실제 갱신이 발생한 정점만 재검사하여 평균 성능을 개선함
- (장기) 계층적 라우팅: Contraction Hierarchy로 전처리 후 쿼리 시 O(log V)에 최단 경로를 응답함

## Ⅵ. 전망
- 자율주행·실시간 내비게이션에서 Contraction Hierarchy와 A* 조합이 표준이 되며, 동적 가중치(교통 혼잡) 반영을 위한 실시간 경로 갱신 기술이 확산될 전망임
