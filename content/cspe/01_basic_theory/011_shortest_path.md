## 미리 알고가기

- 가중치: 간선을 지날 때 드는 거리, 비용, 지연 시간임
- 완화: 더 짧은 경로를 찾으면 거리 값을 갱신하는 연산임
- 음수 가중치: 이동 비용이 0보다 작은 간선 비용임
- 음수 사이클: 반복해서 돌수록 총 비용이 계속 줄어드는 순환 경로임

## Ⅰ. 개요

- **정의/개념**: 최단 경로 알고리즘은 그래프에서 두 정점 또는 여러 정점 사이의 경로 중 가중치 합이 가장 작은 경로를 찾는 방법임
- **배경/필요성**: 라우팅, 내비게이션, 물류 계획은 연결 여부만으로 충분하지 않음. 여러 경로 중 비용과 지연이 가장 작은 경로를 계산해야 함

## Ⅱ. 특징

- 경로 비용은 간선 가중치의 합으로 계산하므로 가중치 의미를 먼저 정해야 함
- 중심 연산은 더 짧은 경로를 발견할 때 거리 값을 줄이는 완화임
- 한 출발점 기준인지 모든 정점 쌍 기준인지에 따라 계산량과 저장 공간이 달라짐
- 음수 가중치와 음수 사이클 여부가 알고리즘 선택을 좌우함

## Ⅲ. 종류 및 비교

| 판단 기준 | 다익스트라 | 벨만-포드 | 플로이드-워셜 |
|:---|:---|:---|:---|
| 계산 범위 | 한 출발점에서 모든 정점 | 한 출발점에서 모든 정점 | 모든 정점 쌍 |
| 음수 가중치 | 처리 불가 | 처리 가능 | 처리 가능 |
| 음수 사이클 확인 | 직접 확인 어려움 | 추가 완화 검사로 확인 | 대각 값으로 확인 |
| 시간복잡도 | $O((V+E)\log V)$ | $O(VE)$ | $O(V^3)$ |
| 적합한 상황 | 빠른 단일 출발점 탐색 | 음수 가중치 검증 | 전체 거리표 계산 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 거리 저장소 | 현재까지 알려진 최단 거리를 보관함 |
| 간선 목록 | 완화 대상이 되는 연결 관계와 가중치임 |
| 우선순위 큐 | 다익스트라에서 가장 짧은 후보 정점을 빠르게 꺼냄 |
| 거리 행렬 | 플로이드-워셜에서 모든 정점 쌍의 거리를 저장함 |

```text
+-----------+     +-----------+     +-----------+
| 초기 거리 | --> | 간선 완화 | --> | 거리 갱신 |
+-----------+     +-----------+     +-----------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 거리 초기화 | --> | 후보 선택 | --> | 완화 수행 | --> | 종료 판정 |
+-----------+     +-----------+     +-----------+     +-----------+
```

1. 출발점 또는 거리 행렬의 초기값을 설정함
2. 알고리즘 규칙에 따라 다음 완화 대상을 고름
3. 새 경로가 더 짧으면 거리 값을 갱신함
4. 모든 대상 처리가 끝나면 최단 거리를 확정함

## Ⅵ. 실무 적용 및 유의점

1. 음수 가중치가 있을 수 있는 입력에는 다익스트라를 쓰지 말고 벨만-포드나 플로이드-워셜로 조건을 확인해야 함
2. 전체 거리표가 필요하지 않은 문제에서 플로이드-워셜을 쓰면 계산량이 커지므로 필요한 산출 범위를 먼저 정해야 함

## Ⅶ. 결론

- 최단 경로 알고리즘은 가중치 조건과 계산 범위에 따라 골라야 하며, 음수 가중치 여부가 가장 먼저 확인할 조건임
