# 최단 경로 - 다익스트라·벨만-포드·플로이드 (Shortest Path)

## 1. 개요

- **정의/개념**: 최단 경로 알고리즘은 가중 그래프에서 출발 정점부터 목표 정점 또는 모든 정점까지의 누적 비용이 최소가 되는 경로를 찾는 알고리즘이다.
- **배경/필요성**: 네트워크 라우팅, 물류, 지도 길찾기처럼 단순 도달 여부가 아니라 비용이 가장 낮은 경로를 선택해야 하는 문제에서 필요하다.

## 2. 특징 및 비교

| 알고리즘 | 적용 조건 | 시간복잡도 | 주요 용도 |
|---|---|---:|---|
| **다익스트라** | 음수 간선 없음 | 우선순위 큐 기준 `O((V+E) log V)` | 단일 출발 최단 경로 |
| **벨만-포드** | 음수 간선 가능, 음수 사이클 검출 | `O(VE)` | 음수 간선 검증 |
| **플로이드-워셜** | 모든 정점 쌍 최단 경로 | `O(V³)` | 정점 수가 작은 조밀 그래프 |
| **Johnson** | 희소 그래프의 모든 쌍 최단 경로 | `O(VE log V)` 수준 | 음수 간선 포함 희소 그래프 |

가중치가 없는 그래프의 최단 간선 수는 BFS로 구할 수 있지만, 가중치가 있으면 최단 경로 알고리즘을 별도로 선택해야 한다.

최단 경로 선택은 음수 간선, 단일 출발/모든 쌍 요구, 그래프 밀도, 경로 복원, 동적 갱신 빈도를 핵심 차원으로 본다.

이 기준은 거리 배열과 완화 연산이 어떤 조건에서 올바르게 수렴하는지로 이어진다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| 정점(Vertex) | 경로의 위치 또는 상태 | `V` |
| 간선(Edge) | 정점 간 이동 가능 관계 | `E` |
| 가중치(Weight) | 이동 비용, 거리, 시간, 위험도 | 음수 여부 확인 |
| 거리 배열 | 출발점부터 각 정점까지의 현재 최소 비용 | 완화 결과 저장 |
| 이전 정점 배열 | 실제 경로 복원을 위한 부모 정보 | 경로 출력 필요 시 필수 |

```text
그래프 입력 -> 가중치 조건 확인 -> 완화(Relaxation) 반복 -> 거리/경로 반환
```

따라서 최단 경로의 문제점은 알고리즘 자체보다 가중치 조건, 규모, 산출물 요구를 잘못 맞출 때 발생한다.

## 4. 문제점 및 개선방안

1. **음수 가중치 오판**
   - 음수 간선이 있는 그래프에 다익스트라를 적용하면 결과가 틀릴 수 있다.
   - **개선방안**: 입력 검증에서 음수 간선을 탐지하고 벨만-포드 또는 Johnson 계열로 전환한다.

2. **규모에 맞지 않는 알고리즘 선택**
   - 큰 그래프에 플로이드-워셜을 적용하면 시간·메모리 비용이 과도하다.
   - **개선방안**: 단일/전체 출발점 요구와 그래프 밀도를 기준으로 알고리즘을 선택한다.

3. **경로 복원 누락**
   - 거리값만 저장하면 실제 경로, 도달 불가능 상태, 동률 정책을 설명하기 어렵다.
   - **개선방안**: 이전 정점 배열, 무한대 표시, 동률 처리 규칙을 함께 저장한다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| 네트워크 라우팅 | 링크 비용 기준 최단 경로 계산 | 경로 비용, 수렴 시간 |
| 지도·물류 경로 | 거리·시간·통행료 가중치로 최적 경로 산정 | ETA, 비용, 재계산 시간 |
| 게임·로봇 이동 | 장애물 비용을 포함해 이동 경로 탐색 | 탐색 시간, 경로 품질 |

## 6. 결론

최단 경로 알고리즘은 그래프의 가중치 조건과 산출물 요구에 따라 선택해야 한다. 다익스트라, 벨만-포드, 플로이드-워셜은 모두 목적이 다르므로 음수 간선, 그래프 규모, 단일/전체 경로 요구, 경로 복원 필요성을 먼저 판단해야 한다.
