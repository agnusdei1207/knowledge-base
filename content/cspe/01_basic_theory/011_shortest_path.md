## 미리 알고가기

- 노드(Node, 정점)와 간선: 노드는 지점, 간선은 노드 간 이동 경로임
- 가중치: 간선에 부여된 거리·비용·지연 값임
- 완화(Relaxation): 더 짧은 경로를 찾으면 최단 거리 값을 갱신하는 연산임
- 단일 출발 노드: 하나의 시작 노드에서 모든 노드까지의 거리를 구하는 조건임
- 전체 노드 쌍: 모든 출발·도착 노드 조합의 거리를 구하는 조건임
- 음수 사이클: 반복할수록 경로 비용이 계속 줄어 최단 경로 확정이 불가능한 순환임
- 단절 노드: 출발 노드와 연결된 경로가 없는 노드임

## 작성 근거(검토용)

- **개요 구성**: 최단 경로의 대상은 가중 그래프이므로 연결 여부가 아니라 비용 합 최소화로 정의함
- **Ⅱ. 특징 선정**: 완화·음수 가중치·음수 사이클·경로 복원은 세 알고리즘의 선택과 결과 해석을 가르는 기준이라 남김
- **Ⅲ 비교축 선정**: 계산 범위·음수 가중치·사이클 탐지·반복 기준·적합 조건·대표 적용 사례는 다익스트라·벨만-포드·플로이드-워셜의 선택과 활용을 가르는 기준임
- **Ⅳ 구조 축약**: 거리 저장소와 간선 정보가 공통 핵심이고, 반복 기준·경로 기록·검증 조건은 구현 판단에 직접 연결됨
- 라우팅과 음수 비용은 알고리즘 선택 오류가 발생하기 쉬운 대표 조건이라 남김

## Ⅰ. 개요

- **정의/개념**: 최단 경로는 가중 그래프에서 출발지와 도착지 사이의 경로 비용(가중치) 합이 가장 작은 경로임
- **배경/필요성**: 라우팅 비용 절감을 위해 거리·비용·지연 시간의 합이 가장 작은 경로가 필요함

## Ⅱ. 특징

- 완화 연산을 반복해 현재까지의 임시 거리값을 더 작은 값으로 갱신함
- 음수 가중치 존재 여부와 계산 범위가 알고리즘 선택을 가름
- 출발 노드에서 닿는 음수 사이클이 있으면 최단 거리가 정의되지 않음
- 실제 이동 경로를 되짚어야 하면 각 노드의 바로 앞 노드를 함께 저장함

## Ⅲ. 종류 및 비교

| 판단 기준   | 다익스트라                     | 벨만-포드                                 | 플로이드-워셜                             |
| :---------- | :----------------------------- | :---------------------------------------- | :---------------------------------------- |
| 계산 범위   | 한 출발 노드에서 모든 노드     | 한 출발 노드에서 모든 노드                | 모든 출발·도착 노드 쌍                    |
| 음수 가중치 | 불가                           | 가능                                      | 가능                                      |
| 음수 사이클 | 확인 불가                      | $V$번째 완화로 확인                       | 대각 원소 음수로 확인                     |
| 반복 기준   | 최소 거리 노드를 선택          | 모든 간선을 순서대로 완화                 | 경유 노드를 하나씩 추가                   |
| 대표 적용 사례 | 내비게이션·망 경로 계산          | 할인 포함 비용·차익 거래 검증             | 소규모 망의 모든 노드 쌍 경로 사전 계산   |
| 적합 조건   | 음수 가중치가 없는 그래프       | 음수 가중치와 사이클 검증이 필요한 그래프 | 노드 수가 적고 모든 쌍 거리가 필요한 경우 |

> 요약: 음수 가중치 존재 여부와 접근 범위를 보고 최단 경로 알고리즘을 선택함.

## Ⅳ. 구성요소 및 구조

| 구성요소    | 설명                                                                                               |
| :---------- | :------------------------------------------------------------------------------------------------- |
| 거리 저장소 | 노드별 거리 배열이나 노드 쌍 거리 행렬을 저장함                                                    |
| 간선 정보   | 연결 노드와 가중치를 담아 완화할 대상을 정함                                                       |
| 반복 기준   | 다익스트라는 최소 거리 노드, 벨만-포드는 모든 간선, 플로이드-워셜은 경유 노드를 반복함             |
| 경로 기록   | 도착 노드까지 실제 이동 경로를 되짚기 위해 각 노드에 바로 앞 노드를 기록함                         |
| 검증 조건   | 음수 사이클은 계산 실패로, 단절 노드는 경로 없음으로 표시함                                        |

```text
[ 최단 경로 구조 ]
그래프·가중치 -> 거리 저장소 -> 완화 -> 최단 거리
                      |
                      v
                 경로 기록·예외 검사
```

> 요약: 거리값과 바로 앞 노드를 함께 기록하면 최단 거리와 실제 이동 경로를 모두 확인할 수 있음.

## Ⅴ. 원리 및 절차 흐름도

```text
[다익스트라] 미확정 최소 거리 노드 선택 -> 인접 간선 완화 -> 모든 접근 노드 확정
[벨만-포드] 모든 간선 완화 x (V-1)     -> V번째 완화    -> 음수 사이클 판정
[플로이드]   경유 노드 k 추가            -> 모든 (i,j) 갱신 -> 대각 원소로 사이클 판정
```

1. **다익스트라**: 출발 노드의 거리를 0으로 두고 미확정 노드 중 거리가 가장 작은 노드를 선택해 인접 간선을 완화함
2. **벨만-포드**: 출발 노드 기준 거리를 초기화하고 모든 간선을 $V-1$회 완화한 뒤 $V$번째 갱신 여부로 음수 사이클을 판정함
3. **플로이드-워셜**: 인접 행렬을 거리 행렬로 초기화하고 경유 노드 $k$를 하나씩 추가해 모든 출발·도착 노드 쌍을 갱신함
4. **결과 해석**: 거리값과 이전 노드·경유 노드 정보를 이용해 경로를 복원하고 단절 노드와 음수 사이클을 구분함

> 요약: 다익스트라는 최소 거리 노드, 벨만-포드는 전체 간선, 플로이드-워셜은 경유 노드를 반복 기준으로 사용함.

## Ⅵ. 실무 사례

1. 음수 가중치가 없는 라우팅은 다익스트라를 적용하며, p99 지연 시간 및 큐 크기 기반으로 성능 임계치를 검증함
2. 정산 그래프에서 할인·환급처럼 음수 비용이 생기면 벨만-포드로 전환하고 음수 사이클 탐지 결과를 업무 규칙 오류 점검에 반영함

## Ⅶ. 결론

- 최단 경로는 음수 가중치·사이클 존재 여부와 접근 범위를 기준으로 알고리즘을 선택해야 함
