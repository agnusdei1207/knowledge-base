# 📖 【암기용】 개념 완전 이해

## 한눈에
- **정의**: 그래프 내의 두 정점 사이를 잇는 경로 중 간선들의 가중치 합이 최소가 되는 경로를 찾는 문제.
- **주요 알고리즘**:
  - **다익스트라 (Dijkstra)**: 단일 출발점, **음수 간선 불가**, $O(E \log V)$.
  - **벨만-포드 (Bellman-Ford)**: 단일 출발점, **음수 간선 가능**, 음수 사이클 탐지, $O(VE)$.
  - **플로이드-워셜 (Floyd-Warshall)**: 모든 쌍 최단 경로, $O(V^3)$.
- **핵심 직관**: "가장 싼 경로를 찾아 계속 업데이트(Relaxation)한다."

## 핵심 용어 정리

| 용어 | 의미 | 비유/예시 |
|:---|:---|:---|
| **완화 (Relaxation)** | 기존의 최단 거리보다 더 짧은 경로를 발견하면 값을 갱신함 | "아, 저 골목으로 가는 게 더 빠르네?" 하고 시간 고쳐 쓰기 |
| **가중치 (Weight)** | 간선을 통과하는 데 드는 비용 | 통행료, 소요 시간, 거리 |
| **음수 사이클** | 사이클을 한 바퀴 돌았을 때 가중치 합이 음수가 되는 경우 | 무한 동력 할인 루프 (계속 돌수록 이득) |
| **SSSP** | Single Source Shortest Path (한 점에서 모든 점으로) | 우리 집에서 전국 각지로 가는 최소 시간 |
| **APSP** | All Pairs Shortest Path (모든 점에서 모든 점으로) | 모든 도시간 최단 거리 표(Table) 만들기 |

## 깊이 이해

- **완화(Relaxation)의 마법**: 
  최단 경로 알고리즘의 심장은 `dist[v] = min(dist[v], dist[u] + weight(u, v))` 입니다. 이 단순한 비교 연산을 어떤 순서로, 몇 번 수행하느냐에 따라 알고리즘의 이름이 달라집니다.

- **다익스트라의 탐욕(Greedy)**: 
  다익스트라는 "지금 당장 가장 가까운 노드"를 확정하며 나아갑니다. 음수 간선이 있으면, 이미 확정한 노드의 최단 거리가 나중에 더 짧아질 수 있어 논리가 깨집니다. 그래서 **음수 간선이 없을 때만** 사용 가능합니다.

- **벨만-포드의 정직함(Dynamic Programming)**: 
  음수 간선이 걱정된다면, 모든 간선을 $V-1$번 동안 계속 훑어봅니다. $V-1$번인 이유는 최단 경로가 가질 수 있는 최대 간선 수가 $V-1$개이기 때문입니다. 만약 $V$번째에도 거리가 줄어든다면? 그것은 **음수 사이클**이 존재한다는 확실한 증거입니다.

- **A* (A-Star) 알고리즘**: 
  다익스트라에 **휴리스틱(Heuristic, 추정치)**을 더한 것입니다. "목표 지점까지 대략 이 정도 남았을 거야"라는 정보를 활용해 탐색 방향을 목표 쪽으로 집중시킵니다. (게임 캐릭터 이동의 표준)

- **일상 비유 (내비게이션)**: 
  - **다익스트라**: 목적지까지 가장 빠른 길을 실시간으로 계산.
  - **플로이드-워셜**: 지하철 노선도 전체의 모든 역 간 최단 시간 표를 미리 뽑아놓음.

# 📝 【답안용】 시험 답안 템플릿

## 핵심 인사이트 (3줄 요약)
> 1. **본질**: 간선 가중치가 존재하는 그래프에서 **삼각 부등식(Triangle Inequality)** 원리를 이용해 거리 상한선을 지속적으로 낮추는 과정임.
> 2. **가치**: 경로 최적화를 통해 물류 비용 절감, 네트워크 패킷 지연 최소화, 실시간 자율 주행 경로 생성을 가능케 함.
> 3. **판단 포인트**: 간선의 **음수 존재 여부**와 **탐색의 범위(단일 vs 전체)**에 따라 다익스트라, 벨만-포드, 플로이드를 전략적으로 선택해야 함.

## Ⅰ. 최적 경로 탐색의 정수, 최단 경로 알고리즘의 개요
### 1. 정의
- 두 지점 사이를 연결하는 수많은 경로 중 간선의 가중치 합이 최소가 되는 경로를 찾는 문제.
### 2. 핵심 메커니즘: 완화 (Relaxation)
- `d[v]`를 $s$에서 $v$까지의 최단 거리 상한선이라 할 때, `d[v] > d[u] + w(u, v)`인 경로 발견 시 `d[v]`를 갱신.

## Ⅱ. 상황별 최단 경로 알고리즘 비교 분석
| 구분 | 다익스트라 (Dijkstra) | 벨만-포드 (Bellman-Ford) | 플로이드-워셜 (Floyd-Warshall) |
|:---:|:---|:---|:---|
| **설계 철학** | 탐욕법 (Greedy) | 동적 계획법 (DP) | 동적 계획법 (DP) |
| **탐색 범위** | 단일 출발 (SSSP) | 단일 출발 (SSSP) | **모든 쌍 (APSP)** |
| **음수 간선** | **불가능 (사용 불가)** | **가능** | 가능 |
| **사이클 탐지** | 불가 | **음수 사이클 탐지 가능** | 음수 사이클 탐지 가능 |
| **시간 복잡도** | $O(E \log V)$ (힙 사용) | $O(VE)$ | **$O(V^3)$** |
| **주요 용도** | GPS, 네트워크 라우팅(OSPF) | 금융 거래(차익거래), RIP | 전체 네트워크 맵 구축 |

## Ⅲ. 알고리즘별 세부 동작 및 특징
### 1. 다익스트라 (Dijkstra)
- 우선순위 큐(Min-Heap)를 사용하여 '방문하지 않은 노드 중 거리가 가장 짧은 노드'를 선택.
- 가중치가 양수일 때만 최적해 보장.
### 2. 벨만-포드 (Bellman-Ford)
- 모든 간선을 $V-1$번 완화 수행. 마지막에 한 번 더 수행하여 값이 변하면 음수 사이클 존재로 판정.
- 가혹한 조건(음수 간선)에서도 해를 찾을 수 있는 강건함.
### 3. 플로이드-워셜 (Floyd-Warshall)
- '거쳐가는 정점'을 기준으로 3중 반복문 수행. `d[i][j] = min(d[i][j], d[i][k] + d[k][j])`.
- 구현이 매우 간단(코드 3~5줄)하나 정점 수가 많아지면 성능 급격히 저하.

## Ⅳ. 지능형 탐색의 진화: A* 알고리즘
### 1. 원리: $f(n) = g(n) + h(n)$
- $g(n)$: 출발지에서 현재 노드까지의 실제 비용.
- $h(n)$: 현재 노드에서 목적지까지의 **휴리스틱(추정)** 비용.
### 2. 가치
- 단순 다익스트라보다 탐색 범위를 목표 방향으로 집중시켜 연산량 획기적 절감.

## Ⅴ. 기술사 관점의 실무 적용 및 고려사항
### 1. 음수 가중치의 실무적 의미
- 비용(Cost)이 아닌 수익(Benefit)이나 할인(Discount)이 발생하는 경우 발생.
- **주의**: 음수 사이클이 존재하면 시스템이 무한 루프에 빠질 수 있으므로 반드시 사전 탐지 로직 포함 필수.
### 2. 대규모 그래프 처리 전략
- 국가 단위 도로망 탐색 시 $O(V^3)$이나 $O(VE)$는 사용 불가.
- **대응**: 계층적 그래프(Hierarchical Graph), 양방향 다익스트라, 전처리(Contraction Hierarchies) 기법 적용.

## Ⅵ. 기술사 관점의 결론: "비즈니스 효율의 나침반"
- 최단 경로 알고리즘은 단순히 길을 찾는 기능을 넘어, **비용 최적화와 가용성 확보**라는 비즈니스 핵심 가치와 직결됨.
- 아키텍트는 네트워크 위상과 데이터 특성을 고려하여, **다익스트라의 속도와 벨만-포드의 안정성** 사이에서 최적의 균형을 도출해야 함.
