## Ⅰ. 개요

- **정의**: 최단 경로 알고리즘은 가중 그래프에서 두 정점 간 간선 가중치 합이 최소가 되는 경로를 구하는 알고리즘군임.
- **배경/필요성**: 010(그래프 탐색)의 BFS는 간선 가중치가 모두 같거나 없을 때만 층 단위 방문 순서가 최단 거리와 일치하는데, 간선마다 가중치(거리·비용·시간)가 다르면 늦게 방문한 정점이 실제로는 더 짧은 누적 거리를 가질 수 있어 층 순서 대신 누적 가중치를 비교·갱신하는 전용 알고리즘이 필요함.
- **출제 의도**: 가중치 조건(음수 허용 여부)에 따른 알고리즘 선택 능력, 완화(Relaxation)라는 공통 연산 위에서 알고리즘별 반복 단위 차이 이해, 단일 출발점 대 모든 쌍 문제 유형 구분 능력을 확인함.
- **답안 방향**: 구조(공통 요소 dist 배열·완화 연산과 알고리즘별 차이) → 동작(다익스트라 절차 및 타 알고리즘과의 분기점) → 특징(정합성 전제·비용 구조) → 심화 비교(가중치 조건·범위별 선택 기준) → 실무 적용 순으로 전개함.

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 가중치 조건별 알고리즘 선택 능력 확인 | 다익스트라는 음이 아닌 가중치 전제, 벨만-포드는 음의 가중치·음의 사이클 탐지 지원 | 가중치 부호 확인 없이 다익스트라를 무조건 정답으로 단정 |
| 완화(Relaxation) 공통 원리와 반복 단위 차이 이해 | 세 알고리즘 모두 `dist[v] > dist[u] + w(u,v)` 갱신을 쓰되, 반복 단위(정점 확정/전체 간선/중간 정점 경유)가 다름 | 세 알고리즘의 시간 복잡도가 전부 동일하다고 혼동 |
| 단일 출발점 대 모든 쌍 문제 유형 구분 | 다익스트라·벨만-포드는 단일 출발점, 플로이드-워셜은 모든 쌍 | 모든 쌍이 필요한데 다익스트라를 정점마다 반복 실행하는 것이 항상 최선이라고 단정 |

> 요약: 이 답안은 완화라는 공통 연산 위에서 가중치 부호와 조회 범위(단일 출발점/모든 쌍) 두 축이 세 알고리즘의 적용 경계를 가른다는 판단으로 전개함.

## Ⅱ. 구조 및 구성요소

```text
가중 그래프(V,E,w) -> dist[] 초기화(출발점 0, 나머지 무한대) -> 완화(Relaxation) 반복 -> 최단 거리 확정
                                                                  |
                                                                  +-> 다익스트라: 우선순위 큐로 최소 dist 정점부터 확정
                                                                  +-> 벨만-포드: 전체 간선을 V-1회 반복 완화
                                                                  +-> 플로이드-워셜: 중간 정점 k 경유 여부를 전체 쌍에 갱신
```

| 구성요소 | 역할 | 산출물/비유 |
|:---|:---|:---|
| 거리 배열 `dist[]` | 출발점에서 각 정점까지 현재까지 알려진 최단 거리를 기록 | 지금까지 확인된 가장 짧은 길이만 적어두는 장부 |
| 완화(Relaxation) | `dist[v] > dist[u] + w(u,v)`이면 `dist[v]`를 갱신 | "이 길이 더 짧다"를 발견할 때마다 장부를 고쳐 쓰는 동작 |
| 우선순위 큐(다익스트라 전용) | 미확정 정점 중 `dist` 최소인 정점을 $O(\log V)$에 추출 | 가장 급한 대기자부터 처리하는 응급실 대기열 |
| 확정 집합(다익스트라 전용) | 최단 거리가 더 이상 변하지 않는다고 확정된 정점의 모임 | 음이 아닌 가중치 전제에서만 성립하는 안전 구역 |
| 간선 전수 반복(벨만-포드 전용) | 정점 확정 없이 모든 간선을 매 회차 검사 | 특정 순서 없이 전 구간을 매번 다시 재는 방식 |
| 중간 정점 `k`(플로이드-워셜 전용) | `i`에서 `j`로 갈 때 `k`를 경유하는 편이 짧은지 전체 쌍에 대해 갱신 | 모든 두 지점 쌍의 경유지 후보를 하나씩 대입해보는 방식 |

> 요약: `dist` 배열과 완화 연산은 세 알고리즘의 공통 뼈대이고, 그 위에서 우선순위 큐·전체 간선 반복·중간 정점 경유라는 서로 다른 반복 단위가 알고리즘을 가름.

## Ⅲ. 동작원리 및 흐름도

```text
예시 그래프(정점 A~D, 간선(가중치)): A-B(2), A-C(5), B-C(1), B-D(4), C-D(1)

다익스트라(출발 A):
1단계: dist=[A:0, B:inf, C:inf, D:inf] -> A 확정, 완화: B=2, C=5
2단계: 미확정 중 최소 B(2) 확정 -> 완화: C=min(5,2+1)=3, D=2+4=6
3단계: 미확정 중 최소 C(3) 확정 -> 완화: D=min(6,3+1)=4
4단계: 미확정 중 최소 D(4) 확정 -> 모든 정점 확정, 종료
최종 dist=[A:0, B:2, C:3, D:4]
```

- 1단계 초기화: `dist[출발점]=0`, 나머지는 무한대로 두고 다익스트라는 우선순위 큐에 출발점만 넣음.
- 2단계 정점(또는 간선) 선택: 다익스트라는 큐에서 `dist` 최소인 미확정 정점을 꺼내 확정 집합에 추가하고, 벨만-포드는 정점 확정 없이 전체 간선을 순서대로 훑음.
- 3단계 완화 적용: 위 예시처럼 확정(또는 검사) 대상의 인접 간선마다 `dist[v] > dist[u]+w(u,v)`이면 갱신함 — 벨만-포드는 이 전체 간선 완화를 $V-1$회 반복하고, 플로이드-워셜은 정점 확정 대신 "정점 `k`를 경유하면 `i-j` 거리가 더 짧은가"를 모든 $(i,j)$ 쌍에 대해 매 회차 검사하는 점이 다익스트라의 정점별 확정과 갈림.
- 4단계 종료 판정: 다익스트라는 모든 정점이 확정되면 종료하고, 벨만-포드는 $V$번째 반복에서도 `dist`가 줄어드는 정점이 있으면 음의 사이클로 판정하며, 플로이드-워셜은 `k`가 $V$개 정점을 모두 거치면 종료함.

> 요약: 세 알고리즘 모두 완화라는 같은 연산을 쓰지만, 반복 단위(정점 확정/전체 간선/중간 정점 경유)가 달라 종료 조건과 복잡도가 갈림.

## Ⅳ. 특징

- 다익스트라 정합성 조건: 확정된 정점의 `dist`가 이후 변하지 않는 성질은 간선 가중치가 모두 0 이상일 때만 성립하며, 음의 가중치가 있으면 이미 확정한 정점의 `dist`가 나중에 더 줄어들 수 있어 오류 신호 없이 잘못된 결과를 반환함.
- 벨만-포드 비용 구조: 매 반복마다 간선 $E$개를 전부 검사하고 이를 $V-1$회 반복해 $O(VE)$이며, 다익스트라보다 느리지만 음의 가중치와 음의 사이클 탐지를 함께 지원함.
- 플로이드-워셜 구현 단순성과 한계: 3중 반복문만으로 $O(V^3)$에 모든 쌍의 최단 거리를 구해 코드가 짧지만, 정점 수가 늘면 비용이 급격히 증가함(예: $V=1{,}000$이면 연산 횟수가 $10^9$ 규모).
- 밀집 그래프에서 다익스트라 구현 선택: 간선 수가 정점 수 제곱에 가까운 밀집 그래프에서는 우선순위 큐 기반 $O((V+E)\log V)$가 로그 계수 때문에 배열 기반 선형 탐색 $O(V^2)$보다 오히려 느려질 수 있어, 그래프 밀도에 따라 구현 방식을 다르게 선택해야 함.

> 요약: 다익스트라는 속도, 벨만-포드는 음수·사이클 대응, 플로이드-워셜은 전수 계산이라는 서로 다른 트레이드오프를 가짐.

## Ⅴ. 심화 비교 및 적용 판단

| 판단 기준 | 다익스트라 | 벨만-포드 | 플로이드-워셜 |
|:---|:---|:---|:---|
| 가중치 조건 | 음이 아닌 가중치만 허용 | 음의 가중치 허용, 음의 사이클 탐지 가능 | 음의 가중치 허용(단 음의 사이클이 없어야 유효) |
| 조회 범위 | 단일 출발점 -> 전 정점 | 단일 출발점 -> 전 정점 | 모든 정점 쌍 |
| 시간 복잡도 | $O((V+E)\log V)$ | $O(VE)$ | $O(V^3)$ |
| 선택 기준 | 반복 계산이 잦고(OSPF 등 링크 상태 라우팅) 음의 가중치가 없을 때 | 음의 가중치·사이클 탐지가 필요할 때(거리 벡터 라우팅, 환율 차익 탐지 등) | 정점 수가 적고(수백 이하) 모든 쌍 조회가 반복될 때 |

> 요약: 가중치 부호와 조회 범위(단일 출발점 대 모든 쌍) 두 축으로 세 알고리즘의 적용 영역이 갈림.

**리스크·대응 (불릿):**
- 음의 가중치 그래프에 다익스트라 적용: 확정 정점의 `dist`가 이후 변하지 않는다는 전제가 깨져 오류 없이 잘못된 결과를 반환 → 가중치 부호를 사전 검증해 음수 존재 시 벨만-포드로 전환 (지표: 음의 간선 존재 여부 정적 검사)
- 벨만-포드 결과의 무의미화: 음의 사이클이 있으면 최단 거리가 $-\infty$로 발산해 계산이 끝나도 값이 무효화됨 → $V$번째 반복의 갱신 발생 여부로 음의 사이클을 판정해 결과 신뢰도를 표시 (지표: $V$번째 반복 갱신 횟수)

**도입 후 점검 지표 (불릿):**
- 정확성: 알려진 정답 거리셋을 가진 검증용 그래프와 실행 결과 `dist` 값의 일치 여부로 확인함.
- 성능: 정점·간선 수 대비 실측 수행 시간이 이론 복잡도 상한 내에 수렴하는지 측정함.

## Ⅵ. 실무 적용 및 결론

1. 단기: 대상 그래프의 가중치 부호와 조회 범위(단일 출발점/모든 쌍)를 진단해 세 알고리즘 중 기본 정책을 선정함.
2. 중기: 반복 계산이 잦은 시스템은 우선순위 큐 기반 다익스트라 구현을 표준화하되, 그래프가 밀집형이면 배열 기반 구현과 성능을 비교해 대체함.
3. 장기: 음의 가중치·사이클 탐지가 필요한 도메인(차익 거래 탐지 등)은 벨만-포드 기반 모니터링 체계를 운영 정책에 반영함.

- 기술사적 판단: 음의 가중치 존재 여부와 조회 범위 두 질문으로 알고리즘 적용 경계를 먼저 확정한 뒤에만 성능 최적화를 논함.
- 기술사 제언: 다익스트라를 기본값으로 채택하되, 그래프 성격이 바뀌어 음의 가중치가 도입되는 시점을 감지해 재검토하는 절차를 설계 문서에 명시함.
