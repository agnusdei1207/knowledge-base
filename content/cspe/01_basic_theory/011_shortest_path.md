## 미리 알고가기

- 가중치(Weight): 간선에 부여된 비용·거리·지연 값으로, 경로 비용 계산의 기준이 됨
- 완화(Relaxation): 현재까지 알려진 거리보다 더 짧은 경로를 발견하면 거리 값을 갱신하는 연산임
- 음수 가중치: 이동 비용이 0보다 작은 간선으로, 우회 경로가 직행보다 총비용을 줄일 수 있음
- 음수 사이클: 순환할수록 총비용이 계속 줄어들어 최단 경로 탐색 자체를 무의미하게 만드는 경로임
- 우선순위 큐: 최솟값을 $O(\log n)$에 꺼내는 자료구조로, 정점 방문 순서 최적화에 사용함

## Ⅰ. 개요

- **정의/개념**: 최단 경로 알고리즘은 가중 그래프에서 출발 정점부터 도착 정점까지의 간선 가중치 합이 최소가 되는 경로를 찾는 절차임
- **배경/필요성**: 통신망 라우팅이나 물류 배차처럼 이동 비용과 지연 시간이 서비스 성능을 좌우하는 환경에서는 단순 연결 여부를 넘어 가중치 합이 가장 작은 경로를 식별하는 최적화 기준이 필요함

## Ⅱ. 특징

- 간선을 거쳐 도착하는 비용이 기존 값보다 작으면 갱신하는 완화 연산을 반복해 최적해를 도출함
- 단일 출발점 알고리즘은 1차원 거리 배열만 유지하여 공간을 절약하지만, 전체 정점 쌍 알고리즘은 2차원 거리 행렬을 유지함
- 음수 가중치 허용 여부에 따라 정점을 한 번만 확정할지, 아니면 전체 간선을 일정 횟수 반복 검사할지가 결정됨
- 음수 사이클이 존재하면 최단 경로 최솟값이 무한히 감소하므로, 알고리즘 내부에 사이클 탐지 메커니즘 유무가 중요함

## Ⅲ. 종류 및 비교

**다익스트라(Dijkstra)**

단일 출발점에서 모든 정점까지의 최단 거리를 구하며, 우선순위 큐로 가장 가까운 정점을 먼저 방문해 인접 간선을 완화함. 음수 가중치가 없을 때만 정확함을 보장함.

**벨만-포드(Bellman-Ford)**

단일 출발점에서 모든 정점까지의 거리를 구하되, 전체 간선을 $V-1$번 반복 완화함. 음수 가중치를 허용하며, $V$번째 반복에서 거리가 또 줄어들면 음수 사이클이 존재함을 판정함.

**플로이드-워셜(Floyd-Warshall)**

모든 정점 쌍의 최단 거리를 구하며, 중간 경유 정점을 하나씩 늘려가며 전체 거리 행렬을 갱신함. 자기 자신으로 돌아오는 대각 값이 음수가 되면 음수 사이클이 포함됨을 확인함.

| 판단 기준 | 다익스트라 | 벨만-포드 | 플로이드-워셜 |
|:---|:---|:---|:---|
| 계산 범위 | 단일 출발점 → 전체 정점 | 단일 출발점 → 전체 정점 | 전체 정점 쌍 |
| 음수 가중치 | 처리 불가 | 처리 가능 | 처리 가능 |
| 음수 사이클 탐지 | 탐지 불가 | $V$번째 반복 시 갱신 여부로 확인 | 대각 행렬 원소의 음수 여부로 확인 |
| 시간복잡도 | $O((V+E)\log V)$ | $O(VE)$ | $O(V^3)$ |
| 적합 조건 | 양수 가중치, 빠른 탐색 속도 | 음수 가중치 존재, 경로 유효성 검증 | 소규모 그래프의 전체 거점 간 거리표 |

> 요약: 양수 가중치 조건에서는 다익스트라를, 음수 가중치가 포함되면 벨만-포드를, 전체 정점 간 경로가 필요하면 플로이드-워셜을 선택함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 거리 저장 배열/행렬 | 출발점에서 각 정점까지 현재까지 알려진 최소 거리를 보관하며, 완화 연산 시 지속적으로 갱신됨 |
| 간선 정보 구조 | 정점 간 연결 상태와 가중치를 나타내며, 탐색 범위와 완화 대상을 식별하는 기준이 됨 |
| 미확정 정점 집합 | 아직 최단 거리가 확정되지 않은 대기 집합이며, 다익스트라에서는 우선순위 큐로 탐색 효율을 높임 |
| 중간 경유 정점 | 플로이드-워셜에서 두 정점 간 거리를 갱신할 때 새로운 우회 경로를 제공하는 기준점이 됨 |

```text
[ 단일 출발점 구조 ]          [ 전체 쌍 구조 ]
+---------------+          +---------------+
|    출발 정점   |          | 정점 $i$ 집합 |
+---------------+          +---------------+
       |                          |
(인접 간선 완화)             (경유 정점 $k$ 완화)
       v                          v
+---------------+          +---------------+
| 1차원 거리 배열 |          | 2차원 거리 행렬 |
+---------------+          +---------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 거리 초기화  | --> | 대상 선택     | --> | 간선 완화    | --> | 결과 검증    |
| (무한대 할당) |     | (우선순위/반복) |     | (거리 갱신)  |     | (사이클 검사) |
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **거리 초기화** — 출발점 거리는 0, 나머지는 무한대로 설정해 최초 비교 상태를 구성함
2. **대상 선택** — 알고리즘 기준에 따라 방문할 최소 거리 정점, 순회할 전체 간선, 또는 경유할 기준 정점을 선택함
3. **간선 완화** — 선택한 경로를 거쳐 가는 새로운 비용이 기존 기록보다 작으면 거리 값을 갱신함
4. **결과 검증** — 모든 정점 처리가 끝나면 거리를 확정하고, 음수 사이클이 그래프를 무효화하는지 검사함

## Ⅵ. 실무 적용 및 유의점

1. 네트워크 라우팅처럼 가중치가 양수인 대규모 트래픽 제어에는 다익스트라가 빠르지만, 비용 환급처럼 간선 가중치가 음수로 바뀔 수 있는 업무에서는 벨만-포드로 전환하고 음수 사이클 여부로 시스템 논리 오류를 통제해야 함
2. 물류 배차에서 전체 지점 간 거리표가 필요한 경우 플로이드-워셜을 쓰되 정점이 많아지면 $O(V^3)$ 연산이 병목이 되므로, 다익스트라를 모든 정점에서 반복 호출하는 방식으로 대체하고 지연 시간을 지표로 확인해야 함

## Ⅶ. 결론

- 최단 경로 탐색은 단순 연결을 넘어선 비용 최적화의 핵심이므로, 가중치 부호와 요구되는 산출 범위를 기준으로 알고리즘을 선택하고 이상 데이터에 대비한 사이클 검증 절차를 반드시 확보해야 함
