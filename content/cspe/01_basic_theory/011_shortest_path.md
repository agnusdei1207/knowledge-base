## 미리 알고가기

- 정점과 간선: 정점은 지점, 간선은 지점 간 이동 경로임
- 가중치: 간선에 부여된 거리·비용·지연 값임
- 완화(Relaxation): 더 짧은 경로를 찾으면 최단 거리 값을 갱신하는 연산임
- 단일 출발점: 하나의 시작 정점에서 모든 정점까지의 거리를 구하는 조건임
- 전체 정점 쌍: 모든 출발·도착 정점 조합의 거리를 구하는 조건임
- 음수 사이클: 반복할수록 경로 비용이 계속 줄어 최단 경로 확정이 불가능한 순환임

## 작성 근거(검토용)

- **개요 구성**: 최단 경로의 대상은 가중 그래프이므로 연결 여부가 아니라 비용 합 최소화로 정의함
- **Ⅱ. 특징 선정**: 완화·음수 가중치·음수 사이클·경로 복원은 세 알고리즘의 선택과 결과 해석을 가르는 기준이라 남김
- **Ⅲ 비교축 선정**: 계산 범위·음수 가중치·사이클 탐지·복잡도는 다익스트라·벨만-포드·플로이드-워셜의 실질 선택 기준임
- **Ⅳ 구조 축약**: 거리 저장소와 간선 정보가 공통 핵심이고, 반복 기준·이전 정점·검증 조건은 구현 판단에 직접 연결됨
- **Ⅵ 사례 선정**: 라우팅과 음수 비용은 알고리즘 선택 오류가 발생하기 쉬운 대표 조건이라 남김

## Ⅰ. 개요

- **정의/개념**: 최단 경로는 가중 그래프에서 출발지와 도착지 사이의 경로 비용(가중치) 합이 가장 작은 경로임
- **배경/필요성**: 라우팅 비용 절감을 위해 거리·비용·지연 시간의 합이 가장 작은 경로가 필요함

## Ⅱ. 특징

- 완화 연산을 반복해 현재까지의 임시 거리값을 더 작은 값으로 갱신함
- 음수 가중치 존재 여부와 계산 범위가 알고리즘 선택을 가름
- 출발점에서 닿는 음수 사이클이 있으면 최단 거리가 정의되지 않음
- 경로 복원이 필요하면 거리와 함께 이전 정점 정보를 저장함

## Ⅲ. 종류 및 비교

| 판단 기준   | 다익스트라                     | 벨만-포드                                 | 플로이드-워셜                             |
| :---------- | :----------------------------- | :---------------------------------------- | :---------------------------------------- |
| 계산 범위   | 한 출발점에서 모든 정점        | 한 출발점에서 모든 정점                   | 모든 출발·도착 정점 쌍                    |
| 음수 가중치 | 불가                           | 가능                                      | 가능                                      |
| 음수 사이클 | 확인 불가                      | $V$번째 완화로 확인                       | 대각 원소 음수로 확인                     |
| 시간복잡도  | $O((V+E)\log V)$ (이진 힙)     | $O(VE)$                                   | $O(V^3)$                                  |
| 맞는 상황   | 음수 가중치가 없는 그래프 | 음수 가중치와 사이클 검증이 필요한 그래프 | 정점 수가 적고 모든 쌍 거리가 필요한 경우 |

> 요약: 음수 가중치 여부와 계산 범위를 먼저 보고 최단 경로 알고리즘을 선택함.

## Ⅳ. 구성요소 및 구조

| 구성요소    | 설명                                                                                               |
| :---------- | :------------------------------------------------------------------------------------------------- |
| 거리 저장소 | 정점별 거리 배열이나 정점 쌍 거리 행렬을 저장함                                                    |
| 간선 정보   | 연결 정점과 가중치를 담아 완화할 대상을 정함                                                       |
| 반복 기준   | 다익스트라는 최소 거리 정점, 벨만-포드는 모든 간선, 플로이드-워셜은 경유 정점을 반복함 |
| 이전 정점   | 최단 경로 자체를 복원할 때 직전 정점을 기록함                                                      |
| 검증 조건   | 음수 사이클과 도달 불가능 정점을 결과 해석에 반영함                                                |

```text
[ 최단 경로 구조 ]
그래프·가중치 -> 거리 저장소 -> 완화 -> 최단 거리
                      |
                      v
                 이전 정점·예외 검사
```

> 요약: 거리 저장소와 완화 기준이 일치해야 최단 거리와 경로를 함께 산출함.

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 거리 초기화 | --> | 대상 선택    | --> | 간선 완화   | --> | 결과 검증   |
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **거리 초기화**: 출발점은 0으로, 나머지는 무한대로 둠
2. **대상 선택**: 정점·간선·경유 정점 중 알고리즘별 반복 대상을 고름
3. **간선 완화**: 새 경로 비용이 더 작으면 거리와 이전 정점을 갱신함
4. **결과 검증**: 음수 사이클·도달 불가·경로 복원 가능성을 확인함

> 요약: 최단 경로 알고리즘은 처리 대상이 달라도 거리값 갱신과 예외 검증으로 결과를 확정함.

## Ⅵ. 실무 사례

1. 라우팅처럼 음수 가중치가 없는 그래프는 다익스트라를 쓰고 p99 탐색 지연과 큐 크기로 검증함
2. 정산 그래프에서 할인·환급처럼 음수 비용이 생기면 벨만-포드로 전환하고 음수 사이클 탐지 결과를 업무 규칙 오류 점검에 반영함

## Ⅶ. 결론

- 최단 경로는 음수 가중치·계산 범위·음수 사이클 가능성을 기준으로 알고리즘과 검증 절차를 함께 선택해야 함
