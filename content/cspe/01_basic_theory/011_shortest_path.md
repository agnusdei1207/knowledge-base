# 📖 【암기용】 개념 완전 이해

> 목적: 최단 경로 문제를 그래프 조건별 알고리즘 선택 기준으로 이해하게 만든다.

## 한눈에
- **개요**: 가중 그래프에서 출발점과 도착점 사이 비용 합이 최소인 경로를 찾는 문제
- **왜 필요한가**: 네트워크 라우팅, 물류 경로, 서비스 호출 비용 분석은 간선 비용을 합산해 최저 비용 경로를 계산해야 함
- **핵심 직관**: 모든 길을 다 걸어보지 않고, 현재까지 확정 가능한 가장 싼 경로부터 차례로 넓혀 감

## 깊이 이해
- **배경·문제의식**: BFS는 간선 비용이 모두 1일 때만 최단거리를 보장함. 지연시간·요금·위험도처럼 간선마다 비용이 다르면 별도 최단 경로 알고리즘 필요
- **작동 원리**: 다익스트라는 음수 간선이 없을 때 최소 거리 정점을 확정함. 벨만-포드는 모든 간선을 V-1회 완화해 음수 간선과 음수 사이클을 처리함. 플로이드는 모든 정점 쌍을 동적 계획법으로 갱신함
- **비유**: 목적지까지 가는 교통비를 계산할 때, 다익스트라는 현재 가장 싼 중간 지점을 확정하고, 벨만-포드는 할인 쿠폰 같은 음수 비용까지 반복 확인함
- **구체 예시**: V=1,000, E=10,000인 희소 그래프는 우선순위 큐 다익스트라 O(E log V)가 적합하고, 모든 정점 쌍 거리는 플로이드 O(V^3)=10^9 연산 규모임
- **흔한 오해·주의점**: 다익스트라는 음수 간선이 있으면 확정한 거리가 나중에 더 작아질 수 있어 결과 오류가 발생함

## 연결 개념
- 그래프 탐색 — 무가중치 최단거리는 BFS로 처리
- 동적 프로그래밍 — 플로이드-워셜의 점화식 기반
- 라우팅 프로토콜 — OSPF는 링크 상태 기반 다익스트라, RIP은 거리 벡터 기반 벨만-포드 계열

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 최단 경로는 가중 그래프에서 간선 비용 합이 최소인 경로를 계산하는 그래프 최적화 문제이다.
> 2. **가치**: 네트워크 라우팅, 물류, 장애 우회, 서비스 메시 비용 산정에 적용되며 비용 모델과 알고리즘 조건이 결과를 좌우한다.
> 3. **판단 포인트**: 음수 간선 없음은 다익스트라, 음수 간선·사이클 검사는 벨만-포드, 모든 쌍 거리는 플로이드를 선택한다.

---

## Ⅰ. 개요 및 필요성

- 개요: 그래프에서 간선 비용 합이 최소인 경로를 찾는 알고리즘 문제
- 배경: 단순 BFS는 간선 비용이 모두 동일할 때만 최단 경로 계산에 유효함
- 필요성: 실제 시스템은 지연시간 ms, 링크 비용, 장애 위험도처럼 가중치가 달라 조건별 알고리즘 선택이 필요함

---

## Ⅱ. 구조 및 구성요소

```text
Graph(V,E,w) -> Distance[] -> Relaxation -> Path/Parent[]
              / Dijkstra: non-negative weight
              / Bellman-Ford: negative edge check
              / Floyd-Warshall: all pairs matrix
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 그래프 G(V,E,w) | 정점, 간선, 가중치 표현 | 인접 리스트 기준 희소 그래프 처리 |
| Distance 배열 | 시작점부터 각 정점까지 최소 비용 저장 | 초기값 INF, 시작점 0 |
| Relaxation | `dist[v] > dist[u]+w`이면 갱신 | 모든 최단 경로 알고리즘의 공통 연산 |
| Parent 배열 | 이전 정점 저장 | 실제 경로 역추적 |

> 요약: 최단 경로는 가중 그래프를 distance와 parent로 관리하고, relaxation 반복으로 비용을 갱신한다.

---

## Ⅲ. 동작원리 및 흐름도

```text
입력 그래프 -> 거리 초기화 -> 간선 완화 반복 -> 종료 조건 확인 -> 최단거리/경로 출력
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 그래프와 시작점 입력, dist 초기화 | dist[s]=0, 나머지 INF |
| 2 | 후보 정점 또는 간선 선택 | 다익스트라: 최소 dist, 벨만-포드: 전체 간선 |
| 3 | Relaxation 수행 | dist[v] 감소 여부 |
| 4 | 종료 후 경로 복원·음수 사이클 확인 | parent 추적, V번째 갱신 여부 |

> 요약: 알고리즘 차이는 후보 선택 방식이며, 공통 원리는 거리 초기화와 간선 완화의 반복이다.

---

## Ⅳ. 특징

| 구분 | 다익스트라 | 벨만-포드 | 플로이드-워셜 | 수치·판단 기준 |
|:---|:---|:---|:---|:---|
| 적용 범위 | 단일 출발, 음수 간선 불가 | 단일 출발, 음수 간선 가능 | 모든 정점 쌍 | 요구 범위 |
| 시간복잡도 | O(E log V) | O(VE) | O(V^3) | 희소/밀집 그래프 |
| 음수 사이클 | 미검출 | 검출 가능 | 대각 원소 음수로 검출 | 위험 비용 모델 |
| 대표 사례 | OSPF, 지도 경로 | 거리 벡터 라우팅 | 정점 수 작은 전체 분석 | V, E, 가중치 조건 |

> 요약: 최단 경로는 음수 가중치 여부와 단일 출발/모든 쌍 요구에 따라 알고리즘을 분기한다.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존/대안 | 최단 경로 알고리즘 | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | BFS 무가중치 | 가중치 기반 relaxation | 간선 비용이 모두 1이 아니면 적용 |
| 비용/성능 | 단일 방식 사용 | Dijkstra/Bellman-Ford/Floyd 분기 | 음수 간선·전체 쌍 여부로 선택 |
| 운영/위험 | 정적 그래프 가정 | 동적 링크·음수 사이클 검증 | topology 변경 빈도와 V,E 규모 |

> 요약: 최단 경로는 가중치 조건, 계산 범위, 그래프 변경 빈도로 알고리즘을 분기한다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 오답 경로 | 음수 간선에 다익스트라 적용 | 가중치 사전 검사, Bellman-Ford 전환 | negative edge count |
| 계산 폭증 | Floyd O(V^3) 무분별 적용 | V 임계치 설정, 단일 출발 반복 | 실행시간, matrix memory |
| 경로 불일치 | parent 갱신 누락 | relaxation 시 parent 동시 갱신 | path reconstruction test |

> 요약: 리스크는 조건 위반, 계산량 폭증, 경로 복원 오류이며 사전 검사와 테스트로 통제한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 정확도 | 기준 그래프 최단거리 100% 일치 | golden test |
| 계산량 | E log V, VE, V^3 중 선택 근거 명시 | 복잡도 리뷰 |
| 운영 | 링크 변경 후 재계산 p95 목표 충족 | 라우팅 시뮬레이션 |

> 요약: 성공 여부는 최단거리 정확도, 계산량 근거, 변경 후 재계산 지연으로 판단한다.

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 네트워크 라우팅: 링크 지연 ms를 가중치로 두고 다익스트라로 최저 비용 경로 산출, 링크 장애 시 parent 재계산
2. 금융·정산 그래프: 할인·환율 차익처럼 음수 간선 가능성이 있으면 벨만-포드로 V번째 relaxation을 검사
3. 서비스 메시 분석: 서비스 수 V<=500이면 플로이드로 모든 호출 경로 비용 행렬 산출, V>10,000이면 단일 출발 반복으로 분할

**결론 (2줄):**
- 기술사 판단: 음수 간선이 없고 실시간 경로 계산이면 다익스트라, 음수 비용 검증이 필요하면 벨만-포드, 전체 쌍 분석이면 플로이드를 선택함
- 향후 방향: 대규모 동적 그래프는 증분 최단 경로, A* 휴리스틱, 병렬 relaxation으로 계산량을 통제해야 함
