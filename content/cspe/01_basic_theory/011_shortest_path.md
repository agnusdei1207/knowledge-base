# 011. 최단 경로 — 다익스트라·벨만-포드·플로이드 (Shortest Path)

## 미리 알고가기

- **완화 (Relaxation)**: 현재 알고 있는 특정 정점까지의 거리보다 특정 간선을 거쳐가는 것이 더 짧을 때, 거리 정보를 갱신하는 핵심 연산임
- **가중치 (Weight)**: 간선을 통과하는 데 필요한 비용(거리, 시간, 요금 등)이며, 음수 가중치는 특수한 처리가 필요함
- **음수 사이클 (Negative Cycle)**: 순환 경로의 가중치 합이 음수인 경우로, 무한히 반복할수록 거리가 줄어들어 최단 경로 정의가 불가능해짐

## 1. 개요

- **정의/개념**: 최단 경로 알고리즘은 가중 그래프의 두 정점 사이를 잇는 경로 중 간선 가중치의 합이 최소가 되는 경로를 찾는 기법임
- **배경/필요성**: 네트워크 라우팅, 내비게이션 길찾기, 물류 배송 최적화 등 자원의 효율적 사용이 요구되는 실제 문제 해결의 핵심임. 간선 수 기준 최단 거리인 BFS와 달리, 비용 합산 기준의 최적 해를 도출하기 위해 고안됨

## 2. 특징 및 비교

가중치 조건(음수 존재 여부)과 탐색 범위(단일 출발 vs 모든 쌍)에 따라 적절한 알고리즘을 선택해야 함.

| 비교 항목 | 다익스트라 (Dijkstra) | 벨만-포드 (Bellman-Ford) | 플로이드-워셜 (Floyd-Warshall) |
|:---|:---|:---|:---|
| **동작 원리** | 그리디 (Greedy) + 우선순위 큐 | 모든 간선 반복 완화 (DP) | 모든 정점 경유지 대입 (DP) |
| **음수 간선** | **사용 불가** | 사용 가능 | 사용 가능 |
| **음수 사이클** | 감지 불가 | **감지 가능** | 감지 가능 (대각 성분 확인) |
| **탐색 범위** | 단일 출발점 → 모든 정점 | 단일 출발점 → 모든 정점 | **모든 정점 쌍 → 모든 정점 쌍** |
| **시간복잡도** | $O((V+E) \log V)$ | $O(VE)$ | $O(V^3)$ |
| **적합 그래프** | 대규모 네트워크, 지도 검색 | 음수 비용이 있는 경제 모델 | 소규모 그래프의 모든 경로 분석 |

> 요약: 양수 가중치 대규모 탐색은 다익스트라, 음수 가중치 및 사이클 검출은 벨만-포드, 소규모 모든 쌍 경로는 플로이드-워셜을 사용함.

## 3. 구성요소/구조

최단 경로 알고리즘은 거리 배열 갱신과 경로 역추적을 위한 부모 노드 기록 과정을 공통적으로 가짐.

- **구성요소**:
  - **Distance Array**: 출발점으로부터 각 정점까지의 현재 최단 거리 저장 ($Dist[v]$)
  - **Predecessor Array**: 경로 복원을 위해 각 정점의 이전 방문 정점 기록
  - **Priority Queue**: (다익스트라 한정) 방문하지 않은 정점 중 거리가 최소인 정점 선택용
  - **Relaxation Logic**: $Dist[v] > Dist[u] + Weight(u, v)$일 때 $Dist[v]$를 업데이트함

- **주요 알고리즘 동작 원리 (ASCII 흐름도)**:

```text
[Dijkstra: 우선순위 큐 기반]         [Bellman-Ford: 반복 완화]
1. 거리가 최소인 정점 u 추출          1. 모든 간선 (u, v)에 대해:
2. u의 인접 정점 v들에 대해 완화        - if Dist[v] > Dist[u] + w:
3. 갱신된 v를 큐에 삽입                   - Dist[v] 갱신
4. 큐가 빌 때까지 반복                 2. 위 과정을 V-1번 반복
                                     3. V번째 반복 시 갱신되면 음수 사이클
```

1. **Dijkstra**: 매 단계에서 '확정된' 최단 거리를 가진 정점을 하나씩 늘려가는 방식으로, 우선순위 큐를 통해 다음 대상 정점을 빠르게 선택함
2. **Bellman-Ford**: 최대 $V-1$개의 간선으로 최단 경로가 구성된다는 원리에 기반하여, 모든 간선을 $V-1$번 훑어 완화를 수행함
3. **Floyd-Warshall**: $k$번째 정점을 경유지로 할 때와 하지 않을 때를 비교하여 $O(V^3)$의 동적 계획법으로 모든 경로를 채움

## 4. 문제점 및 개선방안

1. **다익스트라의 음수 가중치 오작동**: 그리디 방식의 특성상 이미 방문한 정점의 거리는 확정되었다고 가정하므로, 나중에 발견된 음수 간선에 의해 최단 거리가 뒤집히는 상황을 반영하지 못함
   - **개선방안**: 가중치에 음수가 포함될 가능성이 있다면 반드시 벨만-포드를 사용하고, 음수가 없다면 성능이 월등한 다익스트라를 고수함 (확인: 입력 데이터 가중치 도메인 분석)

2. **플로이드-워셜의 공간 복잡도 부담**: 모든 정점 쌍의 거리를 저장하기 위해 $V^2$ 크기의 이차원 배열이 필요하여 정점 수가 수천 개를 넘어가면 메모리 부족이 발생함
   - **개선방안**: 모든 쌍의 경로가 반드시 필요한지 검토하고, 희소 그래프라면 각 정점을 출발점으로 하는 다익스트라를 $V$번 반복($O(VE \log V)$)하여 메모리를 절약함 (확인: 메모리 사용량 $V^2 \times 4$ bytes 산출)

3. **음수 사이클에 의한 무한 루프**: 벨만-포드나 플로이드-워셜 사용 시 음수 사이클이 존재하면 최단 거리가 계속 마이너스로 수렴하여 경로가 확정되지 않음
   - **개선방안**: 벨만-포드 5단계($V$번째 반복)에서 추가 완화 발생 시 예외 처리를 수행하고, 플로이드-워셜의 경우 자기 자신으로의 거리($Dist[i][i]$)가 음수가 되는지 체크함 (확인: 음수 사이클 감지 로그 및 중단 로직)

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| 라우팅 프로토콜 (OSPF) | 다익스트라(Link-State)를 사용하여 자율 시스템(AS) 내부의 최적 경로 테이블 구축 | 수렴 시간, 라우팅 루프 발생 여부 |
| GPS 내비게이션 | 도로망 데이터를 그래프화하고 교통 상황 가중치를 반영하여 다익스트라/A*로 경로 안내 | 경로 탐색 지연 시간, 도착 예정 시간(ETA) 정확도 |
| 환율 차익 거래 탐지 | 통화 간 환율을 로그($-\log$)로 변환하여 음수 사이클을 벨만-포드로 찾아 차익 발생 순환 식별 | 사이클 탐지 성공률, 거래 이익률 |
| 사회적 연결망 (SNS) | 모든 사용자 간의 최단 거리(촌수)를 계산하여 '알 수도 있는 친구' 추천 기능에 활용 | 평균 연결 거리, 추천 알고리즘 정밀도 |

> 요약: 양수 가중치 기반의 빠른 탐색은 다익스트라, 음수 가중치 및 특수 목적(차익 등) 탐색은 벨만-포드가 표준임.

## 6. 결론

최단 경로 알고리즘은 단순히 경로를 찾는 것을 넘어, 복잡한 시스템의 자원 배분과 비용 최적화를 실현하는 도구임. 기술사는 알고리즘의 시간복잡도뿐만 아니라, 대상 데이터의 특성(음수 유무, 밀집도)과 목표 결과(단일 출발 vs 모든 쌍)를 정확히 진단하여 가장 효율적인 모델을 선택할 수 있어야 함.

특히 대규모 실시간 서비스에서는 단순 다익스트라를 넘어 휴리스틱을 가미한 A* 알고리즘이나, 정적 경로를 미리 계산해두는 Contraction Hierarchies 같은 고도화 기법으로의 확장이 필요함. 결국 최단 경로는 '최적성'과 '효율성' 사이의 균형을 맞추는 문제이며, 이를 시스템 구조와 데이터 특성에 맞게 녹여내는 설계 역량이 필수적임.
