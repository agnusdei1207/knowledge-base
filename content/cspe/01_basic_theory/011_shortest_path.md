## 미리 알고가기

- 노드(Node, 정점)와 간선: 노드는 연결 대상, 간선은 노드 간 이동 경로임
- 가중치: 간선에 부여된 거리·비용·지연 값임
- 완화(Relaxation): 더 짧은 경로를 찾으면 최단 거리 값을 갱신하는 연산임
- 단일 출발점·모든 쌍 최단 경로(SSSP·APSP): 한 출발점 기준 경로와 모든 정점 쌍의 경로를 구하는 문제 유형임
- 노드 수 $V$: 그래프의 노드 개수이며 벨만-포드의 완화 횟수 기준임
- 음수 사이클: 반복할수록 경로 비용이 계속 줄어 최단 경로 확정이 불가능한 순환임
- 단절 노드: 출발 노드와 연결된 경로가 없는 노드임
- 다익스트라: 음수 가중치가 없을 때 최소 거리 노드를 확정하며 인접 간선을 완화하는 알고리즘임
- 벨만-포드: 모든 간선을 반복 완화해 음수 가중치를 처리하고 음수 사이클을 검출하는 알고리즘임
- 플로이드-워셜: 경유 노드를 차례로 추가해 모든 노드 쌍의 거리를 구하는 알고리즘임

## 쉽게 이해하기

- 여러 갈래 길이 있는 지도에서 더 짧은 길을 발견할 때마다 지금까지 알던 최단 거리를 그 값으로 갈아 끼우는 것과 같음
- 이렇게 갱신을 반복하다 보면 출발지에서 목적지까지 가장 싼 길이 남음

## 작성 근거(검토용)

- **개요 구성**: 최단 경로의 대상은 가중 그래프이므로 연결 여부가 아니라 비용 합 최소화로 정의함
- **Ⅱ. 특징 선정**: 완화·음수 가중치·음수 사이클·경로 복원은 세 알고리즘의 선택과 결과 해석을 가르는 기준이라 남김
- **Ⅲ. 비교축 선정**: 탐색 범위, 음수 가중치 처리, 음수 사이클 확인은 세 알고리즘 선택을 가르는 핵심 조건임
- **Ⅳ. 구조 선정**: 거리 저장소와 간선 정보가 공통 핵심이고, 반복 기준·경로 기록·결과 판정은 구현 판단에 직접 연결됨
- 라우팅과 음수 비용은 알고리즘 선택 오류가 발생하기 쉬운 대표 조건이라 남김

## Ⅰ. 개요

- **정의/개념**: 최단 경로는 가중 그래프에서 출발지와 도착지 사이의 경로 비용(가중치) 합이 가장 작은 경로임
- **배경/필요성**: 라우팅 비용 절감을 위해 거리·비용·지연 시간의 합이 가장 작은 경로가 필요함

## Ⅱ. 특징

- 완화 연산을 반복해 현재까지의 임시 거리값을 더 작은 값으로 갱신함
- 음수 가중치 존재 여부와 탐색 범위가 알고리즘 선택을 가름
- 출발 노드에서 닿는 음수 사이클이 있으면 최단 거리가 정의되지 않음
- 거리 갱신 시 이전 노드를 함께 저장하면 도착 노드부터 역추적해 경로를 복원함

## Ⅲ. 종류 및 비교

| 판단 기준 | 다익스트라 | 벨만-포드 | 플로이드-워셜 |
|:---|:---|:---|:---|
| 탐색 범위 | 단일 출발점 최단 경로(SSSP) | 단일 출발점 최단 경로(SSSP) | 모든 쌍 최단 경로(APSP) |
| 음수 가중치 처리 | 처리할 수 없음 | 처리할 수 있음 | 처리할 수 있음 |
| 음수 사이클 확인 | 확인 불가 | $V$번째 완화의 거리 갱신으로 확인 | 대각 원소의 음수 값으로 확인 |

> 요약: 음수 가중치·사이클 존재 여부와 탐색 범위를 보고 최단 경로 알고리즘을 선택함.

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 거리 저장소 | 노드 또는 노드 쌍의 최단 거리 저장 영역 |
| 간선 정보 | 완화 대상과 가중치 정보 |
| 완화 연산 | 간선을 거친 새 경로가 더 짧으면 저장된 거리를 갱신하는 연산 |
| 경로 기록 | 이전 노드나 경유 노드를 저장하는 복원 정보 |
| 결과 판정 | 음수 사이클 존재 여부와 단절 노드의 도달 불가 상태 구분 |

```text
[ 최단 경로 구조 ]
그래프·가중치 -> 거리 저장소 -> 완화 -> 최단 거리
                      |
                      v
                 경로 기록·예외 검사
```

> 요약: 최단 경로 알고리즘은 반복 기준에 따라 간선을 완화하고 거리와 경로 기록으로 최단 경로를 산출함.

## Ⅴ. 원리 및 절차 흐름도

```text
[다익스트라] 미확정 최소 거리 노드 선택 -> 인접 간선 완화 -> 모든 접근 노드 확정
[벨만-포드] 모든 간선 완화 × (V-1)     -> V번째 완화    -> 음수 사이클 판정
[플로이드]   경유 노드 추가              -> 모든 노드 쌍 갱신 -> 대각 원소로 사이클 판정
```

1. **다익스트라**: 출발 노드의 거리를 0으로 두고 미확정 노드 중 거리가 가장 작은 노드를 선택해 인접 간선을 완화함
2. **벨만-포드**: 출발 노드 기준 거리를 초기화하고 모든 간선을 $V-1$회 완화한 뒤 $V$번째 갱신 여부로 음수 사이클을 판정함
3. **플로이드-워셜**: 인접 행렬을 거리 행렬로 초기화하고 경유 노드를 하나씩 추가해 모든 출발·도착 노드 쌍을 갱신함
4. **결과 해석**: 거리값과 이전 노드·경유 노드 정보를 이용해 경로를 복원하고 단절 노드와 음수 사이클을 구분함

> 요약: 다익스트라는 최소 거리 노드, 벨만-포드는 전체 간선, 플로이드-워셜은 경유 노드를 반복 기준으로 사용함.

## Ⅵ. 실무 사례

1. 음수 가중치가 없는 서비스 호출 그래프는 다익스트라로 최소 호출 비용 경로를 찾음
2. 할인·환급 정산 그래프는 벨만-포드의 $V$번째 완화로 음수 사이클을 탐지함

## Ⅶ. 결론

- 최단 경로는 출발점에서 목적지까지 누적 비용이 가장 작은 길을 찾으며, 음수 간선과 탐색 범위에 맞는 알고리즘이 필요함
- 알고리즘보다 먼저 비용 모델과 음수 사이클 가능성을 확정하고, 조건이 바뀌면 기존 거리 결과를 재사용하지 말아야 함
