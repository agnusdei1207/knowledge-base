## 미리 알고가기

- 가중치(Weight): 간선에 부여된 비용·거리·지연 값으로, 경로 비용 계산의 단위임
- 완화(Relaxation): 현재 알려진 거리보다 더 짧은 경로를 발견하면 거리 값을 갱신하는 연산임
- 음수 가중치: 간선 비용이 0보다 작은 경우로, 우회 경로가 직행보다 총비용이 작아질 수 있음
- 음수 사이클: 순환 경로의 가중치 합이 음수여서 돌수록 총비용이 무한히 줄어드는 경로임
- 우선순위 큐: 최솟값을 $O(\log n)$에 꺼내는 자료구조로, 다익스트라의 후보 선택에 사용함

## Ⅰ. 개요

- **정의/개념**: 최단 경로 알고리즘은 가중 그래프에서 출발 정점으로부터 도착 정점까지 간선 가중치 합이 최소인 경로를 계산하는 알고리즘 군이며, 계산 범위와 가중치 조건에 따라 다익스트라, 벨만-포드, 플로이드-워셜로 나뉨
- **배경/필요성**: 네트워크 라우팅, 내비게이션, 물류 배차처럼 여러 경로 중 비용이 가장 작은 경로를 선택해야 하는 문제에서는 단순 연결 여부가 아닌 비용 최적 경로 계산 절차가 필요함

## Ⅱ. 특징

- 모든 최단 경로 알고리즘의 핵심 연산은 완화이며, 간선을 거쳐 도착하는 비용이 기존 값보다 작으면 갱신함
- 단일 출발점 알고리즘은 1차원 거리 배열만 유지하지만, 전체 쌍 알고리즘은 $V \times V$ 거리 행렬을 유지하므로 공간복잡도 차이가 큼
- 음수 가중치가 없으면 탐욕 방식으로 정점을 확정할 수 있지만, 음수 가중치가 있으면 확정 순서를 보장할 수 없어 전체 반복 검사가 필요함
- 음수 사이클이 존재하면 최단 경로 자체가 정의되지 않으므로 알고리즘이 이를 탐지할 수 있는지가 선택 기준이 됨

## Ⅲ. 종류 및 비교

**다익스트라(Dijkstra)**

한 출발점에서 모든 정점까지의 최단 거리를 구함. 우선순위 큐에서 거리가 가장 짧은 정점을 꺼내 인접 간선을 완화하고, 한 번 확정된 정점은 다시 방문하지 않음. 음수 가중치가 없을 때만 정확함.

**벨만-포드(Bellman-Ford)**

한 출발점에서 모든 정점까지의 최단 거리를 구하되, 전체 간선을 $V-1$번 반복 완화함. 음수 가중치를 처리할 수 있으며, $V$번째 반복에서 거리가 줄면 음수 사이클이 존재함을 확인할 수 있음.

**플로이드-워셜(Floyd-Warshall)**

모든 정점 쌍의 최단 거리를 구함. 중간 경유 정점을 하나씩 추가하며 $V \times V$ 거리 행렬을 갱신함. 대각 값이 음수가 되면 해당 정점이 음수 사이클에 포함됨을 알 수 있음.

| 판단 기준 | 다익스트라 | 벨만-포드 | 플로이드-워셜 |
|:---|:---|:---|:---|
| 계산 범위 | 단일 출발점 → 전체 정점 | 단일 출발점 → 전체 정점 | 전체 정점 쌍 |
| 음수 가중치 | 처리 불가 | 처리 가능 | 처리 가능 |
| 음수 사이클 탐지 | 불가 | $V$번째 반복 검사 | 대각 값 음수 검사 |
| 시간복잡도 | $O((V+E)\log V)$ | $O(VE)$ | $O(V^3)$ |
| 공간복잡도 | $O(V)$ 거리 배열 + 큐 | $O(V)$ 거리 배열 | $O(V^2)$ 거리 행렬 |
| 적합 조건 | 양수 가중치, 빠른 단일 출발점 | 음수 가중치 존재, 사이클 검증 | 소규모 그래프의 전체 거리표 |

> 요약: 양수 가중치에 단일 출발점이면 다익스트라, 음수 가중치가 있으면 벨만-포드, 모든 쌍 거리가 필요하면 플로이드-워셜을 선택함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 거리 배열/행렬 | 출발점에서 각 정점까지 현재까지 알려진 최단 거리를 보관하며, 완화 연산의 갱신 대상임. 단일 출발점은 1차원 배열, 전체 쌍은 2차원 행렬을 사용함 |
| 간선 목록/인접 리스트 | 정점 간 연결과 가중치를 저장하며, 완화 대상을 결정함. 다익스트라는 인접 리스트, 벨만-포드는 전체 간선 목록, 플로이드-워셜은 초기 거리 행렬로 표현함 |
| 우선순위 큐 | 다익스트라에서 거리가 가장 짧은 미확정 정점을 $O(\log V)$에 꺼내 완화 순서를 정함. 벨만-포드와 플로이드-워셜은 사용하지 않음 |
| 경유 정점 집합 | 플로이드-워셜에서 중간 경유 정점을 하나씩 추가하며 행렬을 갱신하는 기준이 됨 |

```text
+------------+     +------------+     +------------+     +-----------+
| 거리 초기화 | --> | 후보 정점   | --> |  간선 완화  | --> | 거리 확정  |
| (배열/행렬) |     | 선택/반복   |     | (거리 갱신) |     | (최단경로) |
+------------+     +------------+     +------------+     +-----------+
                         |                   |
                         +---< 미완료 시 >----+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +------------+     +-------------+
| 거리 초기화  | --> | 대상 정점     | --> | 완화 수행   | --> | 종료 판정    |
| 출발=0      |     | 선택          |     | 거리 갱신   |     | 사이클 검사  |
| 나머지=INF  |     |              |     |            |     |             |
+-------------+     +--------------+     +------------+     +-------------+
```

1. **거리 초기화** — 출발 정점의 거리를 0, 나머지를 무한대로 설정함. 플로이드-워셜은 직접 간선이 있는 쌍에 가중치를, 없는 쌍에 무한대를 넣음
2. **대상 선택** — 다익스트라는 우선순위 큐에서 최솟값 정점을, 벨만-포드는 전체 간선을, 플로이드-워셜은 경유 정점 $k$를 순서대로 선택함
3. **완화 수행** — 선택된 간선이나 경유 경로를 통한 거리가 기존보다 작으면 거리 값을 갱신함. 플로이드-워셜은 $dist[i][j] > dist[i][k] + dist[k][j]$이면 갱신함
4. **종료 판정** — 다익스트라는 모든 정점 확정 시 종료함. 벨만-포드는 $V-1$회 반복 후 $V$번째에서 거리가 줄면 음수 사이클을 보고함. 플로이드-워셜은 대각이 음수이면 음수 사이클을 보고함

## Ⅵ. 실무 적용 및 유의점

1. 네트워크 라우팅처럼 가중치가 양수인 대규모 그래프에서는 다익스트라가 적합하지만 간선 가중치가 음수로 바뀔 수 있는 환경에서는 벨만-포드로 전환하고 음수 사이클 탐지 결과로 경로 유효성을 확인해야 함
2. 전체 거리표가 필요한 경우에만 플로이드-워셜을 적용하며, 정점 수가 늘어나면 $O(V^3)$이 병목이 되므로 정점 규모와 응답 시간 요구를 먼저 확인해야 함

## Ⅶ. 결론

- 최단 경로 알고리즘은 음수 가중치 허용 여부와 계산 범위를 기준으로 선택하며, 음수 사이클 탐지 가능 여부가 실무 안전성을 좌우함
