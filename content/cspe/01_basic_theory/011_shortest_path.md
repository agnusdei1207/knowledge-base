## Ⅰ. 개요
- 그래프 내 두 정점 사이의 간선 가중치 합이 최소가 되는 경로를 찾는 기법임.
- 가중치 특성(양수/음수)과 시작점 수에 따라 다양한 알고리즘이 존재함.
- [표] 출제 의도: 네트워크 효율 최적화 및 상황별 알고리즘 선택 능력 평가.

## Ⅱ. 구성요소
- ASCII 구조도
  A --(5)--> B --(3)--> C  (Path A-C: 8)

| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| Dijkstra | 단일 시작점, 양수 가중치 최적화 | 내비게이션 |
| Bellman-Ford | 음수 가중치 허용, 사이클 감지 가능 | 손해 보는 경로 체크 |
| Floyd-Warshall | 모든 정점 쌍 간의 최단 경로 산출 | 전체 노선도 |

> 요약: 거리 갱신(Relaxation)을 통해 최소 비용 경로를 도출함.

## Ⅲ. 절차
- ASCII 흐름도
  Init Distance -> Select Node -> Update Neighbors -> Finalize

1. 모든 정점까지의 거리를 무한대로 초기화(시작점은 0)함.
2. 최단 거리인 미방문 정점을 선택(우선순위 큐 등 활용)함.
3. 선택된 정점을 거쳐 인접 정점으로 가는 비용 계산(Relaxation)함.
4. 더 작은 비용이 발견되면 거리를 갱신하고 모든 정점 처리까지 반복함.

> 요약: 인접 경로의 비용을 비교하여 최소 거리를 지속적으로 업데이트함.

## Ⅳ. 문제점
- Dijkstra는 음수 가중치가 있을 경우 오답을 도출할 수 있음.
- Floyd-Warshall은 O(V^3)으로 정점 수가 많을 시 성능이 급락함.

## Ⅴ. 개선방안
- 단기: 가중치 특성에 맞는 알고리즘(양수-D, 음수-B)을 선별함.
- 중기: 우선순위 큐(Heap)를 사용하여 Dijkstra의 성능을 O(E log V)로 개선함.
- 장기: A* 알고리즘 등 휴리스틱을 결합하여 탐색 효율 극대화함.

## Ⅵ. 전망
- 자율주행 서비스의 신뢰성 확보를 위해 V2X 통신 데이터와 결합하여 실시간 도로 상황을 예측 반영하는 다중 모달 최단 경로 알고리즘이 CSF로 부각됨.
- 양자 알고리즘인 Grover의 탐색 기법을 응용한 고속 경로 탐색이 실용화되어 초거대 물류망의 탄소 배출량을 획기적으로 줄이는 기술적 토대가 될 것임.
- 엣지 클라우드 환경에서 분산된 노드 간의 지연 시간을 최소화하는 동적 라우팅 프로토콜 최적화에 강화학습 기반의 최단 경로 추론이 적용될 전망임.
