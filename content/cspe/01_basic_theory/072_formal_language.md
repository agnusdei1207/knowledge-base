## 미리 알고가기

- 알파벳(Alphabet): 문자열을 구성하는 기호 집합임
- 문법(Grammar): 문자열을 생성하는 기호와 생성 규칙의 집합임
- 오토마타(Automata): 입력 문자열을 상태 전이로 읽고 수용 여부를 판단하는 추상 기계임
- 촘스키 계층: 문법 제약과 인식 기계의 능력에 따라 언어를 나누는 분류임
- 결정 가능성: 주어진 입력에 대해 유한 시간 안에 판정이 끝나는 성질임

## 작성 근거(검토용)

- 개요는 생성 문법과 인식 오토마타를 함께 제시해 이론의 두 축을 모두 드러냄
- 특징은 표현력, 판정 비용, 기억장치 차이를 촘스키 계층의 핵심 판단 기준으로 선정함
- Ⅲ은 언어 유형, 인식 기계, 기억장치, 활용을 연결해 계층 차이를 직관적으로 드러냄
- 구조 도식은 문법의 4원소와 예시 규칙을 제시해 추상 정의 이해를 도움
- 유의점은 렉서/파서 분리와 문법 모호성을 형식 언어 이론이 실제 컴파일러로 이어지는 지점으로 선정함

## Ⅰ. 개요

- **정의/개념**: 형식 언어 이론은 문자열 집합을 문법으로 생성하고 오토마타로 인식하는 계산 이론임
- **배경/필요성**: 프로그래밍 언어와 프로토콜의 구문을 명확히 정의하기 위해 문법과 인식 한계를 다루는 수학적 체계가 필요함

## Ⅱ. 특징

- 문법 제약이 약해질수록 표현력은 커지고 판정 비용은 커짐
- 정규 언어는 상태만으로, 문맥 자유 언어는 스택으로 구조를 인식함
- 문법과 오토마타를 대응시켜 생성 가능성과 인식 가능성을 함께 판단함
- 컴파일러 어휘·구문 분석의 이론적 기준을 제공함

## Ⅲ. 종류 및 비교

| 판단 기준 | 정규 언어 | 문맥 자유 언어 | 문맥 의존 언어 | 무제약 언어 |
|:---|:---|:---|:---|:---|
| 촘스키 유형 | Type 3 | Type 2 | Type 1 | Type 0 |
| 인식 기계 | 유한 오토마타 | 푸시다운 오토마타 | 선형 제한 오토마타 | 튜링 머신 |
| 기억장치 | 상태 | 스택 | 제한 테이프 | 무제한 테이프 |
| 주요 활용 | 정규식, 어휘 분석 | 파서, 언어 구문 | 일부 자연어 구조 | 계산 가능성 분석 |

> 요약: 단순 패턴은 정규 언어, 중첩 구조는 문맥 자유 언어, 일반 계산 한계는 튜링 머신으로 분석함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 단말 기호 | 최종 문자열에 남는 실제 입력 기호임 |
| 비단말 기호 | 생성 과정에서 다른 기호로 치환되는 중간 기호임 |
| 생성 규칙 | 좌변 기호를 우변 문자열로 바꾸는 규칙임 |
| 시작 기호 | 문자열 생성을 시작하는 기준 비단말 기호임 |

```text
[ 형식 문법 구조 ]
G = (Vn, Vt, P, S)
S -> aSb | ε
```

> 요약: 형식 문법은 기호 집합과 생성 규칙으로 문자열 집합을 엄밀하게 정의함.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 기호 정의 | --> | 규칙 적용 | --> | 문자열 생성 | --> | 수용 판정 |
+----------+     +----------+     +----------+     +----------+
```

1. **기호 정의**: 단말·비단말 기호와 시작 기호를 정함
2. **규칙 적용**: 문법 제약에 맞춰 생성 규칙을 반복 적용함
3. **문자열 생성**: 비단말 기호가 사라질 때까지 치환함
4. **수용 판정**: 대응 오토마타가 입력 문자열을 끝까지 읽고 수용 상태에 도달하는지 확인함

> 요약: 언어의 표현력은 생성 규칙 제약과 이를 인식하는 오토마타 능력으로 함께 판단함.

## Ⅵ. 실무 사례

1. 어휘 패턴은 정규식으로, 중첩 구문은 CFG 파서로 분리해 컴파일 속도와 문법 명확성을 확인함
2. 문법이 모호하면 파스 트리가 여러 개 생기므로 우선순위·결합 규칙을 명시하고 충돌 수로 검증함

## Ⅶ. 결론

- 형식 언어 이론은 표현하려는 구조의 복잡도에 맞는 최소 문법과 인식 기계를 선택하는 기준임
