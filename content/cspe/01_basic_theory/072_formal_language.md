## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 특정 규칙(문법)의 집합에 의해 생성될 수 있는 문자열들의 집합을 수학적으로 모델링하고 연구하는 이론임. |
| 배경/필요성 | 프로그래밍 언어의 구문을 명확히 정의하고 컴파일러가 이를 기계적으로 해석할 수 있는 기반 제공. |
| 출제 의도 | 촘스키 계층(Chomsky Hierarchy)과 오토마타를 통한 문법적 언어 인식 메커니즘 이해도 평가. |

## Ⅱ. 구성요소
```text
+-----------+    +-----------+    +-----------+
| Alphabet  | -> |  Strings  | -> | Automata  |
+-----------+    +-----------+    +-----------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 알파벳(Alphabet) | 언어를 구성하는 기호들의 유한한 집합 | 블록 조각 |
| 문자열(String) | 알파벳 기호들을 나열한 유한 길이의 시퀀스 | 조립품 |
| 문법(Grammar) | 올바른 문자열을 생성하기 위한 수학적 변환 규칙 | 설계도 |

> 요약: 알파벳과 규칙(문법)을 조합하여 유효한 문자열을 생성하고, 이를 오토마타를 통해 인식함.

## Ⅲ. 절차
```text
+----------+   +----------+   +----------+   +----------+
| Def Symb |-> | Set Rules|-> | Generate |-> | Recognize|
+----------+   +----------+   +----------+   +----------+
```
1. 기호 정의: 언어에서 사용할 알파벳과 상태 기호들을 정의함.
2. 규칙 설정: 생성 규칙(Production Rule)과 촘스키 문법 계층을 설정함.
3. 문자열 도출: 시작 기호부터 유도(Derivation)하여 유효한 문자열 생성함.
4. 기계 인식: 생성된 문자열이 해당 오토마타(DFA, PDA 등)에서 수용되는지 검증함.

> 요약: 기본 기호와 규칙을 통해 언어를 생성하고 그 언어를 인식하는 오토마타로 유효성을 평가함.

## Ⅳ. 문제점
- 자연어 수준의 고도화된 문맥 의존성을 정규 언어나 문맥 자유 문법만으로 표현하기 어려움
- 표현력이 높은 언어 체계일수록 오토마타의 상태 수와 파싱 알고리즘 복잡도가 급증함
- 기계 번역 등 복잡한 의미(Semantics) 분석 시 구문론적 규칙 기반 접근의 한계 직면

## Ⅴ. 개선방안
- [단기] 어휘/구문 분석 과정에서 정규 표현식과 문맥 자유 문법을 혼용하여 최소한의 파싱 효율 확보
- [중기] 문법적 애매성(Ambiguity)을 제거한 제한적 LALR 기법 도입으로 구문 분석 복잡도 억제
- [장기] 인공지능 기반 거대 언어 모델과 기호 논리(Symbolic Logic) 추론을 융합한 뉴로 심볼릭 AI 전환

## Ⅵ. 전망
- 프로그래밍 언어의 문법 검증기능 외에도 자연어 처리 초기 규칙 기반 모델 등 논리적 기반 체계로 존속함.
