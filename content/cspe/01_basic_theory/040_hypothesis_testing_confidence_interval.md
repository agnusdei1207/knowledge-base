## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 가설 검정(Hypothesis Testing)은 표본 데이터로 모집단에 대한 주장(귀무가설 $H_0$)을 기각할 충분한 증거가 있는지 판단하는 통계적 의사결정 절차이다. 신뢰 구간(Confidence Interval)은 모수의 참값이 포함될 것으로 기대되는 구간을 확률적으로 제시한다.
> 2. **가치**: A/B 테스트("전환율 변화가 우연인가 실제인가?"), 제조 품질("불량률이 기준 이내인가?"), 의약품("신약이 위약보다 효과가 있는가?"), 모델 평가("정확도 차이가 통계적으로 유의한가?") 등 데이터 기반 의사결정의 핵심 도구이다.
> 3. **융합**: A/B 테스트(빈도/베이지안), ML 모델 비교(McNemar 검정), 품질공학(관리도, SPC), 보안(이상 탐지 임계값 설정), 네트워크(성능 벤치마크 비교) 등.

---

### 🔑 핵심 용어 정리

| 용어 | 뜻 | 비유 |
|:---|:---|:---|
| **귀무가설($H_0$)** | "효과가 없다", "차이가 없다"는 기본 가정. 기각 대상 | "무죄 추정" |
| **대립가설($H_1$)** | "효과가 있다", "차이가 있다"는 연구자의 주장 | "유죄 주장" |
| **p-value** | $H_0$이 참일 때 관측된 결과 이상으로 극단적인 결과가 나올 확률 | "이 결과가 우연일 확률" |
| **유의 수준($\alpha$)** | $H_0$을 기각하는 기준. 보통 $\alpha = 0.05$. p-value $< \alpha$이면 기각 | "유죄 판결 기준" |
| **1종 오류(Type I)** | $H_0$이 참인데 기각. 위양성. 확률 = $\alpha$ | "무고한 사람 유죄 판결" |
| **2종 오류(Type II)** | $H_0$이 거짓인데 기각 못 함. 위음성. 확률 = $\beta$ | "범인을 놓침" |
| **검정력(Power)** | $1 - \beta$. $H_0$이 거짓일 때 올바르게 기각할 확률 | "범인 잡을 확률" |
| **신뢰 구간(CI)** | 모수의 참값이 포함될 것으로 기대되는 구간. 95% CI = 100번 중 95번 포함 | "그물의 너비" |

## Ⅰ. 개요 및 필요성

- **개념**: 가설 검정의 절차는 다음과 같다:

1. 귀무가설 $H_0$과 대립가설 $H_1$ 설정
2. 유의 수준 $\alpha$ 결정 (보통 0.05)
3. 검정 통계량 계산 (z, t, $\chi^2$, F 등)
4. p-value 계산 또는 기각역과 비교
5. p-value $< \alpha$이면 $H_0$ 기각 → "통계적으로 유의"

신뢰 구간은 점 추정치에 불확실성을 더한 것이다:

$$
\text{95\% CI} = \bar{x} \pm z_{0.025} \cdot \frac{s}{\sqrt{n}}
$$

- **필요성**: A/B 테스트에서 버전 A(전환율 5.0%)와 B(5.3%)의 차이가 우연인지 실제인지 판단해야 한다. 표본 크기 $n$과 효과 크기에 따라 p-value가 0.05보다 작으면 "B가 유의미하게 낫다"고 결론짓는다.

- **비유**: 가설 검정은 **"재판"**과 같다. $H_0$ = "무죄"가 기본 가정이고, 검찰(데이터)이 충분한 증거(p-value $< \alpha$)를 제시하면 "유죄"(기각)를 선고한다. 증거 부족이면 "무죄"(기각 못 함)이지, "결백 증명"이 아니다.

```text
+-----------------------------------------------------------------------+
|        가설 검정의 4가지 결과                                         |
+-----------------------------------------------------------------------+
|                    |  H₀이 참 (무죄)    |  H₀이 거짓 (유죄)           |
|  ─────────────────|───────────────────|──────────────────            |
|  H₀ 기각 (유죄)   |  1종 오류 (α)      |  올바른 기각 (검정력)        |
|                    |  위양성             |  1 - β                      |
|  ─────────────────|───────────────────|──────────────────            |
|  H₀ 미기각 (무죄) |  올바른 판단        |  2종 오류 (β)               |
|                    |  1 - α             |  위음성                      |
+-----------------------------------------------------------------------+
|                                                                       |
|  ★ α↓ → 1종 오류↓ but β↑ (보수적 판단)                             |
|  ★ α↑ → 1종 오류↑ but β↓ (공격적 판단)                             |
|  ★ n↑ → α, β 모두↓ (표본 크기가 해답)                              |
+-----------------------------------------------------------------------+
```

**[다이어그램 해설]** 가설 검정의 4가지 결과를 보여준다. 1종 오류($\alpha$)와 2종 오류($\beta$)는 트레이드오프 관계이다. $\alpha$를 낮추면(보수적 판결) 무고한 사람을 유죄로 만드는 실수는 줄지만, 범인을 놓치는 확률($\beta$)이 올라간다. 이 트레이드오프를 깨는 유일한 방법은 표본 크기 $n$을 키우는 것이다.

- **📢 섹션 요약 비유**: p-value는 "이 결과가 순전히 우연일 확률"입니다. 5% 미만이면 "우연이 아니라 진짜 차이가 있다"고 판단합니다.

## Ⅱ. 아키텍처 및 핵심 원리

### 주요 검정 방법

| 검정 | 조건 | 수식 | 용도 |
|:---|:---|:---|:---|
| **z-검정** | $n \geq 30$, $\sigma$ 기지 | $z = \frac{\bar{x} - \mu_0}{\sigma / \sqrt{n}}$ | 대표본 평균 비교 |
| **t-검정** | $n < 30$ 또는 $\sigma$ 미지 | $t = \frac{\bar{x} - \mu_0}{s / \sqrt{n}}$ | 소표본 평균 비교 |
| **$\chi^2$ 검정** | 범주형 데이터 | $\chi^2 = \sum \frac{(O_i - E_i)^2}{E_i}$ | 적합도, 독립성 |
| **ANOVA (F-검정)** | 3그룹 이상 평균 비교 | $F = \frac{\text{그룹 간 분산}}{\text{그룹 내 분산}}$ | 다중 비교 |

- **📢 섹션 요약 비유**: z/t-검정은 "평균의 차이가 진짜인가?", $\chi^2$는 "범주별 비율이 기대와 다른가?", ANOVA는 "3개 이상 그룹의 평균이 같은가?"를 판단합니다.

## Ⅲ. 비교 및 연결

### 비교 1: 빈도주의 검정 vs 베이지안 검정

| 비교 항목 | 빈도주의 | 베이지안 |
|:---|:---|:---|
| **결과** | p-value (기각/미기각) | 사후 확률 분포 |
| **해석** | "이 데이터가 $H_0$ 하에서 얼마나 극단적인가" | "파라미터가 이 범위에 있을 확률" |
| **사전 정보** | 사용 안 함 | 사전 분포로 명시적 반영 |
| **표본 크기 의존** | 크게 의존 | 적은 데이터에서도 합리적 |
| **다중 비교 보정** | 필요 (Bonferroni) | 자연스럽게 흡수 |

### 과목 융합 관점
- **ML 모델 비교**: 두 모델의 정확도 차이가 유의한지 McNemar 검정이나 교차 검증 t-검정으로 판단한다.
- **보안**: 이상 탐지 임계값은 정상 트래픽의 $\mu + 3\sigma$로 설정하고, 이를 초과하면 "통계적으로 비정상"으로 판단한다.

## Ⅳ. 실무 적용 및 기술사 판단

### 실무 시나리오

1. **시나리오 — A/B 테스트**: 전환율 A=5.0%, B=5.3%, 각 10,000명. 이항 비율의 z-검정으로 $z = 1.0$, $\text{p-value} = 0.32 > 0.05$ → "유의미한 차이 없음". 표본을 100,000명으로 늘리면 $z = 3.15$, $\text{p-value} = 0.002 < 0.05$ → "B가 유의미하게 우수".

### 안티패턴
- **p-hacking**: 유의한 결과가 나올 때까지 변수·시점·표본을 바꿔가며 검정하면 $\alpha$가 누적되어 위양성이 급증한다.
- **p-value 오해**: "p=0.03 → $H_0$이 참일 확률 3%"는 **오류**. p-value는 "$H_0$ 하에서 이런 데이터가 나올 확률"이다.

## Ⅴ. 기대효과 및 결론

### 정량/정성 기대효과

| 구분 | 직감 의사결정 | 가설 검정 적용 | 개선 효과 |
|:---|:---|:---|:---|
| **정량** | "느낌상 B가 낫다" | p=0.002, 95% CI: [0.1%, 0.5%] | **오판 확률 5% 이내** |
| **정성** | "나중에 뒤집힐 수 있다" | 통계적 유의성 + 효과 크기 제시 | **재현 가능한 의사결정** |

### 참고 표준
- **Fisher, R.A. (1925)**: 유의성 검정 방법론 정립
- **Neyman-Pearson (1933)**: 1종/2종 오류, 검정력 프레임워크

가설 검정과 신뢰 구간은 "데이터에서 결론을 내리되, 틀릴 확률을 정량화하는" 도구이다. p-value의 한계를 인식하고 효과 크기·신뢰 구간과 함께 보고해야 의미 있는 의사결정이 가능하다.

### 📈 관련 키워드 및 발전 흐름도

```text
[확률 분포 (정규·t·χ²)]
    |
    v
[가설 검정·신뢰 구간 (현재 개념)]
    |
    +---> [A/B 테스트 (전환율 비교)]
    +---> [ANOVA (다중 그룹 비교)]

    +---> [다중 비교 보정 (Bonferroni)]
```

### 👶 어린이를 위한 3줄 비유 설명

1. 가설 검정은 "재판"이에요. "차이 없다(무죄)"가 기본이고, 증거가 충분하면 "차이 있다(유죄)"로 판결해요.
2. p-value는 "이 결과가 순전히 운일 확률"이에요. 5% 미만이면 "운이 아니라 진짜야!"라고 해요.
3. 신뢰 구간은 "정답이 이 범위 안에 있을 거야"라는 그물이에요. 그물이 좁을수록 정확해요!
