# 📖 【암기용】 개념 완전 이해

> 목적: SVM을 처음 보는 사람도 완벽히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: SVM은 두 집단 사이 간격을 최대로 벌리는 분류 모델이다.
- **왜 필요한가**: 표본 수가 수천 건 이하이고 변수 차원이 큰 데이터에서 결정 경계가 흔들리면 오분류가 증가한다. SVM은 경계 주변 표본만 사용해 일반화 오차를 통제한다.
- **핵심 직관**: 두 무리를 나누는 선을 아무 데나 긋지 않고, 가장 가까운 점들과의 거리가 최대인 위치에 긋는 방식이다.

## 깊이 이해
- **배경·문제의식**: 선형 분류기는 학습 데이터만 맞추면 새 데이터에서 오류가 커질 수 있다. SVM은 마진(Margin)을 최대화해 Vapnik-Chervonenkis(VC) 차원을 낮추고 과적합을 줄인다.
- **작동 원리**: 결정 경계에 가장 가까운 데이터인 서포트 벡터만 경계 계산에 직접 영향을 준다. 선형 분리가 어려운 경우 커널 함수가 입력을 고차원 특징 공간으로 사상해 선형 분리 가능성을 높인다.
- **비유**: 두 차선 사이 중앙선을 그릴 때 양쪽 차량과의 거리를 최대한 같고 넓게 두는 것과 같다.
- **구체 예시**: 스팸 분류에서 TF-IDF 20,000차원, 학습 데이터 5,000건이면 Linear SVM은 전체 단어 공간을 쓰되 경계 근처 메일 수백 건이 분류면을 결정한다.
- **흔한 오해·주의점**: 커널 SVM은 모든 문제에 맞지 않는다. RBF 커널은 표본 50,000건 이상에서 커널 행렬 비용이 급증하므로 Linear SVM, SGDClassifier, XGBoost와 비교해야 한다.

## 연결 개념
- 로지스틱 회귀: 확률 출력 중심, SVM은 마진 중심
- 커널 트릭: 비선형 경계를 내적 함수로 계산
- 정규화: C 값으로 마진 위반과 과적합을 조절

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: SVM(Support Vector Machine)은 최대 마진 초평면으로 분류 경계를 결정하는 지도학습 모델이다.
> 2. **가치**: 고차원·소표본 데이터에서 경계 주변 서포트 벡터만 사용해 일반화 오차를 통제한다.
> 3. **판단 포인트**: 데이터 규모, 선형 분리 가능성, 커널 비용, C·gamma 튜닝 범위로 적용 여부를 판단한다.

---

## Ⅰ. 개요 및 필요성

SVM은 최대 마진 분류기이다. 텍스트·생물정보·이상탐지처럼 차원 수가 표본 수보다 큰 문제에서 단순 경험오차 최소화는 과적합을 만든다. SVM은 마진 최대화와 커널 트릭으로 결정 경계를 제어하므로, 분류 정확도와 해석 가능한 경계 판단이 필요한 문제에 적용된다.

---

## Ⅱ. 구조 및 구성요소

```text
학습 데이터 -> 특징 벡터 -> 커널/내적 -> 최적화 문제 -> 결정 초평면
                         +-> C, gamma 조정 -> 마진 통제
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 특징 벡터 | 입력 데이터를 수치 공간에 배치 | TF-IDF, 표준화 Z-score 적용 |
| 서포트 벡터 | 결정 경계와 가장 가까운 표본 | 경계 계산의 핵심 표본 |
| 커널 함수 | 비선형 관계를 고차원 내적으로 처리 | Linear, Polynomial, RBF |
| 최적화 파라미터 | 마진 위반과 복잡도 조절 | C, gamma, degree |

> 요약: SVM은 특징 벡터와 서포트 벡터를 기반으로 커널과 C·gamma를 조정해 최대 마진 경계를 산출한다.

---

## Ⅲ. 동작원리 및 흐름도

```text
데이터 수집 -> 스케일링 -> 커널 선택 -> 마진 최적화 -> 예측/검증
              +-> 이상치 확인 -> C 조정
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 결측치 처리, 표준화, 학습/검증 분리 | train:test=8:2, Z-score |
| 2 | Linear/RBF 커널 선택 | 차원 수, 비선형 패턴 |
| 3 | C·gamma 그리드 탐색 | 5-fold CV, F1·AUC |
| 4 | 서포트 벡터와 마진 산출 | 서포트 벡터 비율, 혼동행렬 |

> 요약: SVM은 전처리 후 커널과 규제 파라미터를 탐색하고, 검증 지표로 마진 기반 결정 경계를 확정한다.

---

## Ⅳ. 특징

| 구분 | 내용 | 판단 포인트 |
|:---|:---|:---|
| 장점 | 고차원 희소 데이터 분류에 적합 | TF-IDF 10,000차원 이상 Linear SVM |
| 한계 | 대용량 커널 행렬 계산 비용 증가 | RBF 커널 학습 O(n^2) 이상 |
| 비교 대상 | 로지스틱 회귀, 의사결정나무 | 확률 출력 필요 시 로지스틱 회귀 |
| 수치 기준 | C=0.1~100, gamma=1/d~1 | 5-fold CV F1 기준 선택 |

> 요약: SVM은 고차원·소표본 분류에서 강점을 가지며, 대용량·확률예측 문제에서는 선형 모델이나 트리 계열과 비교해야 한다.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존/대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | 로지스틱 회귀는 확률 경계 | SVM은 최대 마진 경계 | 확률 보정 필요 여부 |
| 비용/성능 | 트리 모델은 범주·비선형 처리 | 커널 SVM은 고차원 경계 처리 | 표본 50,000건 이하 |
| 운영/위험 | 딥러닝은 GPU와 대량 데이터 요구 | SVM은 CPU 학습 가능 | 소표본·고차원 문제 |

> 요약: 표본 수보다 특징 수가 많고 결정 경계 품질이 중요하면 SVM, 확률·대규모 학습이 중요하면 대안을 선택한다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 과적합 | C 과대, gamma 과대 | C 로그스케일 탐색, gamma 축소 | train-test F1 차이 5%p 이하 |
| 학습 지연 | 커널 행렬 크기 증가 | Linear SVM, 샘플링, SGD 적용 | 학습시간 30분 이하 |
| 클래스 불균형 | 소수 클래스 마진 왜곡 | class_weight, SMOTE, PR-AUC 사용 | 소수 클래스 Recall 80% 이상 |

> 요약: SVM 운영 리스크는 규제 파라미터, 데이터 규모, 클래스 불균형을 교차검증과 지표로 통제한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 분류 품질 | F1 0.85 이상, AUC 0.90 이상 | 5-fold CV, 혼동행렬 |
| 계산 비용 | 학습 30분 이하, 예측 p95 50ms 이하 | 학습 로그, API 벤치마크 |
| 모델 통제 | 서포트 벡터 비율 60% 이하 | 모델 속성 점검 |

> 요약: SVM 도입 후 성공 여부는 F1·AUC, 학습시간, 서포트 벡터 비율을 함께 확인한다.

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 — 단계별 또는 항목별):**
1. 텍스트 분류는 TF-IDF 1~2gram + Linear SVM으로 기준 모델 구성, F1 0.85 이상을 합격선으로 설정함
2. 비선형 소표본은 RBF 커널과 C={0.1,1,10,100}, gamma={1/d,0.01,0.1} 그리드 탐색 수행함
3. 운영 배포는 Platt Scaling으로 확률 보정, p95 예측 50ms 이하와 월 1회 재학습 기준 수립함

**결론 (2줄):**
- 기술사 판단: 고차원·소표본이면 SVM, 대용량·확률해석이면 로지스틱 회귀·XGBoost를 선택함
- 향후 방향: SVM은 AutoML 튜닝과 설명가능성 지표를 결합해 규제 산업의 기준 모델로 활용됨
