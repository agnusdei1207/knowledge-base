## Ⅰ. 개요
- **정의**: 모델 예측값과 실제 정답 간 차이를 스칼라로 정량화하는 함수
- **배경/필요성**: 경사하강법(049 참조)이 최소화할 목표가 있어야 파라미터 갱신 방향을 결정할 수 있으므로, 오차를 수치로 표현하는 함수가 필요함
- **비유**: 시험 채점표와 같음 — 정답과 답안을 비교해 점수(오차)를 매기고, 이 점수를 줄이는 방향으로 공부(학습)함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 과제 유형별 손실 함수 선택 근거를 설명할 수 있는지 | MSE vs Cross-Entropy 수식·적용 조건, 출력층 활성화 함수와의 조합 | 분류에 MSE를 쓰면 기울기 소실이 발생하는 이유를 설명해야 함 |

> 요약: 모델 오차를 수치화하여 최적화의 목표를 제공하는 함수임

## Ⅱ. 구성요소
```text
Input --> Model --> Prediction(y_hat)
                        |
                        v
Ground Truth(y) --> Loss Function --> Scalar Loss --> Gradient(049 참조)
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 예측값(`y_hat`) | 모델이 출력한 값(확률 또는 연속값) | 학생이 작성한 답안 |
| 정답(`y`) | 학습 데이터에 부여된 레이블 또는 목표값 | 채점 기준표의 모범 답안 |
| 손실 함수 | `y`와 `y_hat` 간 차이를 스칼라로 변환하는 수식 | 채점 공식 |
| 정규화 항 | 가중치 크기에 비례하는 페널티를 손실에 합산(046 참조) | 답안 분량 초과 시 감점 |

> 요약: 예측값·정답·손실 수식·정규화 항이 핵심 구성요소임

## Ⅲ. 절차
```text
과제 유형 판별 --> 출력층 활성화 선택 --> 손실 함수 결정 --> 정규화 항 부가
```
- 1단계: **과제 유형 판별** — 회귀(연속값 예측)인지, 이진 분류인지, 다중 클래스 분류인지 식별함
- 2단계: **출력층 활성화 함수 선택** — 회귀는 항등 함수, 이진 분류는 Sigmoid, 다중 분류는 Softmax를 적용함
- 3단계: **손실 함수 결정** — 아래 표에 따라 과제·활성화에 대응하는 손실 함수를 선택함
- 4단계: **정규화 항 부가** — 과적합 방지를 위해 L1(가중치 절댓값 합) 또는 L2(가중치 제곱합)를 손실에 합산함(046 참조)

| 과제 유형 | 출력 활성화 | 손실 함수 | 수식 핵심 |
|:---|:---|:---|:---|
| 회귀 | 항등 함수 | MSE | $\frac{1}{n}\sum(y - \hat{y})^2$ |
| 이진 분류 | Sigmoid | Binary Cross-Entropy | $-[y\log\hat{y} + (1-y)\log(1-\hat{y})]$ |
| 다중 분류 | Softmax | Categorical Cross-Entropy | $-\sum y_k \log\hat{y}_k$ |

> 요약: 과제 유형 → 활성화 → 손실 함수 → 정규화 순으로 결정함

## Ⅳ. 문제점
- 과제-손실 부적합: 분류 과제에 MSE를 적용하면 Sigmoid 포화 구간에서 기울기가 0에 수렴하여 학습이 정체됨 — 활성화 함수와 손실 함수의 미분 구조 불일치가 원인임
- 클래스 불균형 왜곡: 다수 클래스 샘플이 손실 합산을 지배하여 소수 클래스 오분류를 무시함 — 균등 가중 합산 방식이 원인임
- 정규화 강도 과설정: L2 계수(`lambda`)가 과도하면 가중치가 0 근처로 수축되어 모델 표현력이 저하됨 — 검증 데이터 없이 `lambda`를 고정하는 것이 원인임

> 요약: 손실-활성화 부적합, 클래스 불균형, 정규화 과설정이 주요 문제임

## Ⅴ. 개선방안
1. 단기: 과제 유형·활성화 함수 조합표를 기준으로 손실 함수를 선택하여 미분 구조 불일치를 방지함
2. 중기: Focal Loss·클래스 가중치 부여 등으로 소수 클래스 손실 기여를 증폭하여 불균형 왜곡을 해소함
3. 장기: 검증 손실 기반 `lambda` 탐색(Grid/Bayesian Search)을 자동화하여 정규화 강도를 데이터 기반으로 결정함

> 요약: 조합표 준수·클래스 가중치·자동 하이퍼파라미터 탐색으로 세 문제를 단계적으로 해결함

## Ⅵ. 전망
- 발전 방향: 자기지도학습의 Contrastive Loss, 생성 모델의 Perceptual Loss 등 과제 특화 손실 함수가 지속 확장되는 추세임
- 기술사적 판단: 손실 함수의 수학적 의미와 활성화 함수 조합 근거를 정량적으로 설명할 수 있어야 함
- 기술사 제언: 새 과제 도입 시 손실 함수·활성화·평가지표 간 정합성을 사전 검증하는 체크리스트를 운영할 것을 권장함
