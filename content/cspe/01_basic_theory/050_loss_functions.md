## 미리 알고가기

- objective: 모델이 최소화하려는 기준 함수임
- 회귀: 연속값 예측 문제임
- 분류: 클래스 확률 또는 레이블 예측 문제임

## Ⅰ. 개요

- **정의/개념**: 손실 함수는 모델 예측과 실제 정답 사이의 차이를 수치화해 학습 방향을 결정하는 함수이며, 회귀에는 MSE, 분류에는 Cross-Entropy가 대표적임
- **배경/필요성**: 모델이 무엇을 잘해야 하는지 수식으로 정의하지 않으면 optimizer가 어떤 방향으로 업데이트해야 할지 결정할 수 없음

## Ⅱ. 특징

- MSE는 큰 오차를 제곱으로 더 크게 벌해 연속값 회귀에 적합함
- Cross-Entropy는 정답 클래스 확률을 높이는 방향으로 분류 학습을 유도함
- 손실 함수 선택은 gradient 크기와 수렴 특성에 직접 영향을 줌
- 문제 유형과 맞지 않는 손실 함수는 학습 불안정과 성능 저하를 초래함

## Ⅲ. 종류 및 비교

| 판단 기준 | MSE | Cross-Entropy | Hinge |
|:---|:---|:---|:---|
| 대표 문제 | 회귀 | 확률 분류 | 마진 기반 분류 |
| 오차 해석 | 거리 제곱 | 음의 로그 우도 | 경계 여유 |
| 장점 | 직관적 | 분류에 효과적 | 결정 경계 강화 |
| 주의점 | 이상치 민감 | 확률 calibration 필요 | 확률 해석 약함 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 예측값 $\hat{y}$ | 모델 출력이며 손실 입력값임 |
| 정답 $y$ | 목표 레이블 또는 값이며 비교 기준임 |
| 오차 계산식 | 차이를 수식화하고 gradient 모양을 결정함 |
| 집계 방식 | 평균 또는 합산이며 배치 학습 안정성에 영향 줌 |

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 예측산출 | --> | 오차계산 | --> | 손실집계 | --> | 기울기전달 |
+----------+     +----------+     +----------+     +----------+
```

1. **예측산출**: 모델이 입력에 대한 결과를 계산함
2. **오차계산**: 예측과 정답 차이를 손실식에 넣음
3. **손실집계**: 배치 단위로 평균 또는 합을 구함
4. **기울기전달**: optimizer가 사용할 gradient를 생성함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 문제 유형과 맞지 않는 손실을 선택할 수 있어 분류에 MSE를 쓰면 학습이 느릴 수 있음
   - 해결방안: 출력층 활성화와 손실 함수를 쌍으로 설계하고 convergence speed로 검증함
2. 문제: 클래스 불균형에 취약해 다수 클래스 위주로 학습될 수 있음
   - 해결방안: weighted loss, focal loss를 적용하고 minority recall로 검증함
3. 문제: 이상치에 민감할 수 있어 MSE는 큰 오차에 과도하게 끌림
   - 해결방안: MAE, Huber loss를 검토하고 robust error로 검증함

## Ⅶ. 적용 사례

- 회귀 예측: 자원 사용량, 매출 예측에 MSE를 사용함, 확인 지표는 RMSE임
- 이미지 분류: softmax + cross-entropy를 사용함, 확인 지표는 top-1 accuracy임
- 불균형 탐지: focal loss로 어려운 샘플에 가중치를 둠, 확인 지표는 F1과 recall임

## Ⅷ. 결론

손실 함수의 핵심은 모델이 무엇을 틀렸는지 정의하는 데 있으므로, 문제 유형과 출력 해석에 맞는 손실을 선택해야 안정적인 학습이 가능함.
