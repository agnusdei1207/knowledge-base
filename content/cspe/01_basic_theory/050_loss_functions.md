## 미리 알고가기

- **비용 함수 (Cost Function)**: 데이터 전체의 오차를 나타내는 함수. 손실 함수(개별 샘플 오차)의 합 또는 평균임
- **로그 손실 (Log Loss)**: 분류 문제에서 모델이 예측한 확률값이 실제 정답과 멀어질수록 벌칙을 급격히 부여하는 방식
- **미분 가능성 (Differentiability)**: 경사 하강법을 적용하기 위해 손실 함수는 모든 구간에서 기울기를 계산할 수 있어야 함

## Ⅰ. 개요

- **정의/개념**: 손실 함수(Loss Function)는 인공지능 모델의 예측값($\hat{y}$)과 실제 정답($y$) 사이의 차이를 수치로 정량화하여, 학습 과정에서 모델이 나아가야 할 최적의 방향(최솟값 탐색)을 제시하는 목적 함수임
- **배경/필요성**: 모델의 학습은 곧 '오차를 줄이는 과정'임. "무엇을 틀렸다고 정의할 것인가"에 따라 모델의 성격이 결정됨. 연속적인 수치를 맞추는 회귀 문제와 범주를 구분하는 분류 문제는 오차를 측정하는 기준이 근본적으로 다름. 문제 유형에 부합하지 않는 손실 함수를 선택하면 학습이 불안정해지거나 전혀 엉뚱한 값으로 수렴하게 됨

## Ⅱ. 특징 및 비교

### 가. 문제 유형별 주요 손실 함수 비교

| 구분 | 평균 제곱 오차 (MSE) | 크로스 엔트로피 (Cross-Entropy) | 힌지 손실 (Hinge Loss) |
|:---|:---|:---|:---|
| 주요 대상 | 회귀 (Regression) | 분류 (Classification) | 분류 (SVM 등) |
| 수식 특성 | 오차의 제곱 ($y - \hat{y}$)$^2$ | $-\sum y \log(\hat{y})$ | $\max(0, 1-y\hat{y})$ |
| 민감도 | 큰 오차에 매우 민감함 | 정답 확률이 낮을수록 벌점 폭증 | 마진(Margin) 침범 시 발생 |
| 연계 출력층 | 선형 활성화 (Linear) | Sigmoid / Softmax | 선형 출력층 |
| 주요 강점 | 수리적으로 다루기 쉬움 | 확률 분포 간의 거리를 잘 측정함 | 결정 경계 근처의 안정성 확보 |

> 요약: 값의 차이를 줄이려면 MSE, 확률 분포를 일치시키려면 Cross-Entropy를 사용함

### 나. 손실 함수 선택의 결정 요인
- **연속성 vs 이산성**: 종속 변수가 실수값인지 카테고리인지가 1차 기준임
- **이상치(Outlier) 저항성**: 이상치가 많은 데이터에서는 제곱 오차(MSE)보다 절대 오차(MAE)나 Huber Loss가 유리함
- **클래스 불균형**: 특정 데이터가 압도적으로 많을 때는 가중치를 부여한 손실 함수(Weighted Cross-Entropy)가 필요함

## Ⅲ. 구성요소/구조

### 가. 손실 함수와 학습 알고리즘의 결합 구조

```text
[입력 데이터] -> [모델 예측] -> [손실 함수 연산] -> [미분(Gradient)] -> [가중치 업데이트]

1. Comparison: 예측 확률과 실제 라벨(One-hot)을 비교
2. Scoring: 차이를 로그 또는 제곱 연산을 통해 하나의 스칼라 값으로 요약
3. Feedback: 손실값을 역전파(Backprop) 엔진에 전달하여 기울기 도출
4. Convergence: 손실값이 더 이상 줄어들지 않을 때까지 반복 학습
```

### 나. 주요 구성 요소 및 역할

| 구성요소 | 역할 및 설명 | 핵심 포인트 |
|:---|:---|:---|
| 예측값 ($\hat{y}$) | 모델이 활성화 함수를 거쳐 내놓은 결과 | 0~1 확률값 혹은 실수값 |
| 정답 (Ground Truth) | 데이터셋에 명시된 실제 라벨 또는 수치 | 학습의 절대적 기준점 |
| 벌칙항 (Penalty) | 오차의 정도를 증폭하거나 보정하는 항 | 손실의 크기를 결정하는 수식적 장치 |
| 정규화 항 (Regularization) | 가중치 크기를 손실에 포함시켜 과적합 방지 | L1, L2 규제와 결합 |

> 요약: 예측과 정답의 거리를 잰 뒤, 이를 가중치 갱신을 위한 '신호'로 바꾸는 매개체임

## Ⅳ. 문제점 및 개선방안

1. **이상치에 의한 학습 왜곡**: MSE는 오차를 제곱하므로, 이상치 하나가 발생시키는 손실이 너무 커서 전체 모델을 비정상적으로 흔듦
   - **개선방안**: 오차에 선형적으로 대응하는 MAE를 쓰거나, 일정 범위까지만 제곱하는 Huber Loss를 적용함

2. **클래스 불균형에 따른 무시**: 데이터가 적은 클래스의 오차가 전체 손실(Average Loss)에 묻혀 학습이 제대로 안 됨
   - **개선방안**: 각 클래스에 가중치를 두는 Weighted Loss나, 맞추기 어려운 샘플에 집중하는 Focal Loss를 도입함

3. **기울기 소실(Vanishing Gradient)**: 출력층 함수와 손실 함수의 조합이 맞지 않으면 미분값이 0에 가까워져 학습이 멈춤
   - **개선방안**: Sigmoid 출력에는 반드시 Cross-Entropy를 짝지어(BCE), 로그 성질을 통해 기울기가 유지되도록 설계함

## Ⅴ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| 부동산 가격 예측 | MSE 또는 RMSE를 최소화하여 실제 거래가와 오차를 좁힘 | MAE, 결정계수 ($R^2$) |
| 스팸 메일 분류 | Binary Cross-Entropy를 적용해 스팸일 확률을 0 또는 1에 가깝게 학습 | Log Loss, F1-Score |
| 객체 탐지 (Object Detection) | 위치 좌표(회귀)는 MSE로, 클래스 분류는 Cross-Entropy로 결합된 Multi-task Loss 사용 | mAP, IoU |

> 요약: 문제의 성격에 맞춰 '맞춤형 오차 지표'를 설정하는 것이 딥러닝 성능 최적화의 첫 단추임

## Ⅵ. 결론

손실 함수는 단순히 맞고 틀림을 재는 척도를 넘어, 모델이 세상(Data)을 바라보는 '가치관'을 정의하는 것과 같음. MSE를 선택하면 '평균적인 정확함'을 지향하게 되고, Cross-Entropy를 선택하면 '확실한 구분'을 목표로 삼게 됨.

기술사는 서비스의 최종 KPI와 모델의 손실 함수를 정렬(Alignment)시킬 수 있어야 함. 특히 비즈니스적으로 실수의 비용이 큰 경우(예: 의료 오진) 단순한 손실 함수에 비용 가중치(Cost-sensitive)를 부여하여 리스크를 관리할 수 있는 공학적 설계 역량이 필수적임.
