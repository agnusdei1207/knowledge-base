## 미리 알고가기

- 손실 함수($Loss$ $Function$): 한 개의 데이터 포인트에서 발생한 오차를 계산하는 함수임
- 비용 함수($Cost$ $Function$): 전체 훈련 데이터셋의 모든 손실을 합하거나 평균을 낸 총 오차 지표임
- 목적 함수($Objective$ $Function$): 모델 학습 시 최적화(최소화 또는 최대화)하려는 대상이 되는 모든 함수를 통칭함
- 볼록성($Convexity$): 함수가 아래로 볼록하여 단 하나의 전역 최솟값을 가질 때, 경사하강법의 수렴이 보장됨

## Ⅰ. 개요

- **정의/개념**: 손실 함수는 모델이 예측한 값($\hat{y}$)과 실제 정답($y$) 사이의 거리나 정보량의 차이를 수치화한 지표이며, 경사하강법이 가중치를 업데이트할 '나침반' 역할을 수행하는 수식임
- **배경/필요성**: 인공지능 모델이 현재 얼마나 틀리고 있는지를 정량적으로 정의해야만, 오차를 줄이기 위한 수학적 미분이 가능해지고 비로소 기계의 자가 학습이 이루어지기 때문에 필수적임

## Ⅱ. 특징

- 평균 제곱 오차($MSE$)는 오차가 클수록 제곱에 비례하여 더 큰 벌점을 부여하므로 수치 예측(회귀)에서 안정적인 수렴을 유도함
- 교차 엔트로피($Cross-Entropy$)는 두 확률 분포 사이의 차이를 측정하며, 정답이 아닌 클래스에 높은 확률을 부여할 때 손실값이 급격히 커지는 특성이 있어 분류 문제의 표준으로 사용됨
- 손실 함수의 형태에 따라 '기울기($Gradient$)'의 모양이 결정되며, 이는 전체 네트워크의 학습 속도와 지역 최솟값($Local$ $Minimum$) 탈출 능력에 결정적 영향을 미침

## Ⅲ. 종류 및 비교

| 판단 기준 | MSE (Mean Squared Error) | Cross-Entropy (교차 엔트로피) |
|:---|:---|:---|
| **주요 용도** | 수치값 예측 (회귀) | 클래스 확률 예측 (분류) |
| **수식 원리** | 오차의 제곱 평균 ($Σ(y-\hat{y})^2/n$) | 정보 이론의 엔트로피 ($Σy \log(\hat{y})$) |
| **이상치 반응** | 매우 민감함 (제곱으로 증폭) | 확률 분포 간의 괴리에 민감함 |
| **장점** | 수렴 속도가 빠르고 직관적임 | 확률 분포를 직접적으로 최적화함 |
| **단점** | 분류 문제에서는 학습이 느려짐 | 값의 범위가 0~1 사이로 한정됨 |

> 요약: MSE는 '거리'의 최소화에, Cross-Entropy는 '확률 분포'의 일치에 집중함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 예측 결과값 | 모델이 연산한 최종 출력으로, 확률 또는 실수값 형태임 |
| 실제 정답값 | 데이터셋에 포함된 라벨로, 비교의 기준이 되는 $Ground$ $Truth$임 |
| 페널티 기법 | 오차가 클 때 손실값을 비선형적으로 키워 모델에 강한 학습 신호를 주는 방식임 |
| 미분 가능성 | 경사하강법 적용을 위해 모든 구간(또는 대부분)에서 미분이 가능해야 함 |

```text
[ Binary Cross-Entropy (BCE) 공식 ]
L = -[ y * log(p) + (1-y) * log(1-p) ]
- y: 정답 (0 또는 1)
- p: 모델이 예측한 성공(1) 확률
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 모델 예측 출력| --> | 실제값 비교/연산| --> | 손실값(Loss) 도출| --> | 기울기 생성/전달|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **결과 산출** — 입력 데이터를 순전파시켜 마지막 층에서 활성화 함수(시그모이드, 소프트맥스 등)를 거친 예측값을 얻음
2. **오차 정량화** — 문제 유형에 맞는 손실 함수를 선택하고, 예측값과 실제 정답 사이의 수치적 거리를 수식에 따라 계산함
3. **손실 집계** — 배치 내 모든 샘플의 손실을 평균 내어 현재 모델의 상태를 대표하는 '비용($Cost$)' 값을 산출함
4. **최적화 연계** — 산출된 손실값을 가중치로 편미분하여 오차 역전파를 시작하고, 손실이 최소화되는 방향으로 모델을 개선함

## Ⅵ. 실무 적용 및 유의점

1. 회귀 문제에서 이상치($Outlier$)의 영향이 너무 커서 학습이 방해받는다면, 오차의 절댓값을 사용하는 'MAE'나 두 방식의 장점을 결합한 'Huber 손실'을 적용하여 모델의 견고성($Robustness$)을 높여야 함
2. 클래스 불균형이 심한 분류 문제(예: 암 진단)에서는 일반적인 교차 엔트로피를 사용하면 다수 클래스에만 최적화될 수 있으므로, 적중하기 어려운 데이터에 더 큰 가중치를 주는 '포컬 손실($Focal$ $Loss$)'을 검토해야 함

## Ⅶ. 결론

- 손실 함수는 인공지능이 추구해야 할 '옳음'의 기준을 수학적으로 정의한 가이드라인이며, 설계자는 비즈니스 목적과 데이터의 분포적 특성을 고려하여 모델이 가장 효율적으로 정답을 찾아갈 수 있는 손실 지표를 설계해야 함
