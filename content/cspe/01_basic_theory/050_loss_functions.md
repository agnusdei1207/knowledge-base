## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 모델의 예측값과 실제 정답값 간의 불일치 정도를 측정하여 학습 최적화의 지표가 되는 함수임 |
| 배경/필요성 | 모델이 얼마나 잘 예측하고 있는지 정량적으로 평가하고 최적화 방향을 제시할 척도 필요 |
| 출제 의도 | 회귀(MSE)와 분류(Cross-Entropy) 등 문제 유형에 따른 손실 함수의 선택 및 원리 이해 평가 |

## Ⅱ. 구성요소
```text
+----------------+       +----------------+       +----------------+
| Predictions    |       | Loss Function  |       | Scalar Loss    |
| (Y_hat)        | ----> | (MSE/CEE)      | ----> | Value          |
+----------------+       +----------------+       +----------------+
```
| MSE (회귀용) | 예측값과 정답 간 차이의 제곱 평균 | 오답 거리 측정기 |
| CEE (분류용) | 예측 확률 분포와 실제 정답 분포 간의 차이 측정 | 정보량 불일치 검사 |
| 손실값 (Loss) | 모델의 오차 상태를 나타내는 단일 스칼라 지표 | 건강 검진 수치 |
> 요약: 손실 함수는 예측값과 정답 간 오차를 측정하여 MSE나 CEE를 통해 스칼라 지표를 산출함

## Ⅲ. 절차
```text
+----------------+       +----------------+       +----------------+       +----------------+
| Predict Value  |       | Error Diff     |       | Penalty Calc   |       | Target Loss    |
| (Model Out)    | ----> | (Diff to True) | ----> | (Square/Log)   | ----> | (Final Metric) |
+----------------+       +----------------+       +----------------+       +----------------+
```
1. 예측 산출: 순전파를 통해 모델의 최종 예측값(수치 또는 확률) 도출
2. 오차 측정: 예측값과 실제 정답 라벨 간의 산술적 차이 또는 확률비 계산
3. 페널티 부과: 오차가 클수록 제곱(MSE)이나 로그(CEE) 함수로 큰 비용 할당
4. 손실 도출: 배치 내 오차를 평균 내어 최종 역전파 기준 손실값 도출
> 요약: 예측값과 정답 간 오차에 수학적 페널티를 적용하여 최종 손실값을 도출함

## Ⅳ. 문제점
- 이상치 지배(MSE): 오차를 제곱하므로 큰 이상치 1개에 손실값이 과도하게 지배됨
- 학습 지연(분류 MSE): 분류에서 MSE 사용 시 Sigmoid와 결합하여 기울기 소실 유발
- 클래스 불균형 무시(CEE): 소수 클래스의 오차가 다수 클래스에 묻혀 오분류율 증가

## Ⅴ. 개선방안
- 단기 방안: 이상치에 덜 민감한 MAE 또는 Huber Loss를 회귀 문제 대안으로 적용
- 중기 방안: 분류 문제에는 Softmax와 짝을 이루는 Cross-Entropy를 사용하여 학습 가속화
- 장기 방안: Focal Loss 등을 도입하여 예측이 어려운 소수 클래스에 더 큰 가중치 부여

## Ⅵ. 전망
- 강화학습 보상 함수와 결합되거나 태스크 특화 형태의 복합(Custom) 손실 함수로 발전함
