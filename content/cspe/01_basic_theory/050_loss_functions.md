## Ⅰ. 개요

- **정의**: 손실 함수는 모델 예측값과 정답의 오차를 수치화해 학습이 최소화할 목표(스칼라)로 정의하는 함수임.
- **배경/필요성**: 049(경사 하강법)가 파라미터를 갱신하려면 미분 가능한 스칼라 목적함수가 먼저 정의돼야 하므로, 문제 유형(연속값 예측 vs 이산 클래스 분류)에 맞는 오차 정량화 방식이 필요함.
- **출제 의도**: 회귀에는 MSE/MAE, 분류에는 Cross-Entropy를 선택하는 기준과 그 수학적 근거(미분 가능성, 확률 해석)를 확인함.
- **답안 방향**: 구조(손실 함수 구성 요소) -> 동작(MSE·Cross-Entropy 계산 예시) -> 비교(선택 기준) -> 실무 적용 순으로 전개함.

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 문제 유형별 손실 함수 선택 근거 설명 요구 | 회귀=MSE/MAE, 분류=Cross-Entropy 구분, 미분 가능성·확률 해석 근거 | 손실 함수 종류 단순 나열, 선택 기준 없이 장점만 서술, 경사 하강법 절차와 혼동 |

> 요약: 손실 함수 답안은 "무엇을 최소화 대상으로 정의하는가"를 문제 유형별로 못 박고, 그 위에서 선택 기준을 논증해야 함.

## Ⅱ. 구조 및 구성요소

```text
학습 데이터(정답 y, 예측 y_hat) -> 문제 유형 판단
  연속값 예측(회귀) -> MSE / MAE
  이산 클래스 분류 -> Cross-Entropy(Binary/Categorical)
-> 손실 스칼라 L 산출 -> 048(역전파)의 미분 대상으로 전달
```

| 구성요소 | 역할 | 산출물/비유 |
|:---|:---|:---|
| MSE(평균제곱오차) | 회귀 오차를 제곱해 평균, 이상치에 큰 벌점 | "오차 제곱 평균" |
| MAE(평균절대오차) | 회귀 오차를 절댓값으로 평균, 이상치에 완만한 벌점 | "오차 절대값 평균" |
| Cross-Entropy(교차 엔트로피) | 예측 확률분포와 정답 분포 간 불일치를 로그로 계산 | "확률 불일치 벌점" |
| 정규화항(L1/L2) | 가중치 크기에 벌점을 더해 과적합 억제 | "손실에 페널티 가산" |

> 요약: 회귀는 MSE/MAE가, 분류는 Cross-Entropy가 핵심 손실이며 정규화항은 필요 시 덧붙는 보조 요소임.

## Ⅲ. 동작원리 및 흐름도

```text
예측값 y_hat 산출 -> 문제 유형별 손실 계산 -> 배치 평균 -> 손실 L(스칼라) -> 048(역전파)로 전달
```

- 1단계(문제 유형 판단): 출력이 연속값이면 회귀 손실, 클래스 확률이면 분류 손실을 선택함.
- 2단계(회귀 손실 계산, MSE 예시): 정답 `y=[3, 5]`, 예측 `y_hat=[2.5, 6]`일 때 오차 `[0.5, -1]`를 제곱해 `[0.25, 1]`, 평균을 내면 $\text{MSE} = 0.625$가 됨.
- 3단계(분류 손실 계산, Cross-Entropy 예시): 정답 원-핫 `[1, 0, 0]`, 예측 확률 `[0.7, 0.2, 0.1]`일 때 정답 클래스 확률만 로그를 취해 $-\log(0.7) \approx 0.357$이 손실값이 됨.
- 4단계(배치 집계 및 전달): N개 샘플의 손실을 평균해 스칼라 $L$을 만들고, 이 $L$을 048(역전파)이 가중치로 편미분해 기울기를 구하는 대상으로 넘김.

> 요약: 문제 유형별 계산식으로 샘플별 오차를 구하고 배치 평균으로 스칼라화해, 역전파가 미분할 단일 목적함수를 만드는 순서임.

## Ⅳ. 특징

- 미분 가능성: MSE는 포물선 형태라 전 구간에서 매끄럽게 미분되지만, MAE는 오차 0 지점에서 미분이 불가능해 최적화 시 불연속 기울기가 발생함.
- 이상치 민감도: MSE는 오차를 제곱해 소수의 이상치가 손실 전체를 지배할 수 있는 반면, MAE는 절댓값이라 이상치 영향이 상대적으로 완만함.
- 확률 해석: Cross-Entropy는 최대우도추정(MLE)의 음의 로그가능도와 수학적으로 동일해, 확률 분포 간 차이를 직접 측정하는 근거를 가짐.
- 발산 위험: 분류에서 정답 클래스 예측 확률이 0에 근접하면 로그 특성상 손실이 무한대로 발산할 위험이 있어, 구현에서 확률 하한(epsilon clipping)을 두는 것이 일반적임.

## Ⅴ. 심화 비교 및 적용 판단

| 비교 기준 | MSE | MAE | Cross-Entropy |
|:---|:---|:---|:---|
| 적용 문제 유형 | 회귀(연속값) | 회귀(연속값) | 분류(이산 클래스) |
| 미분 가능성 | 전 구간 매끄럽게 미분 가능 | 오차 0에서 미분 불가 | 전 구간 미분 가능 |
| 이상치 민감도 | 제곱 오차로 이상치에 매우 민감 | 절댓값으로 이상치에 상대적으로 강건 | 정답 확률이 0에 근접할 때 손실 급증 |
| 선택 기준 | 오차 분포가 정규분포에 가깝고 큰 오차를 강하게 벌하려는 경우 | 이상치 비율이 높고 안정적 수렴이 우선인 경우 | 클래스 확률 예측이 목표이고 정답 확신도를 직접 벌하려는 경우 |

> 요약: 회귀는 오차 분포·이상치 비율로 MSE와 MAE를 가르고, 분류는 확률 해석이 되는 Cross-Entropy를 표준으로 선택함.

**리스크·대응 (불릿):**
- 이상치에 의한 MSE 왜곡: 소수 이상치가 제곱 오차로 손실을 지배하는 것이 원인 -> 이상치 사전 제거 또는 Huber Loss 같은 완충형 손실로 대응함 (지표: 이상치 제거 전후 검증 MSE 변화율).
- 분류 손실 발산: 예측 확률이 0에 근접해 로그 항이 무한대로 발산하는 것이 원인 -> 확률 하한(epsilon clipping)으로 대응함 (지표: 학습 중 NaN/Inf 손실 발생 빈도).

**도입 후 점검 지표 (불릿):**
- 회귀: 검증셋 MSE/MAE가 에폭마다 감소하는 추이인지 확인함.
- 분류: 검증셋 Cross-Entropy와 정확도(accuracy)가 함께 개선되는지 확인함(손실만 보면 과적합을 놓칠 수 있음).

## Ⅵ. 실무 적용 및 결론

1. 단기: 문제 유형(연속값 예측 vs 이산 클래스 분류)을 확정해 MSE/MAE/Cross-Entropy 중 기본 손실을 선정함.
2. 중기: 이상치 비율·클래스 불균형 등 데이터 특성에 맞춰 Huber Loss·Focal Loss 같은 변형 손실로 교체함.
3. 장기: 손실 함수를 비즈니스 목표(순위 정확도, 사용자 선호 등)와 직접 정렬한 커스텀 손실로 고도화함.

- 기술사적 판단: 손실 함수는 049(경사 하강법)가 쫓아갈 목표 그 자체이므로, 데이터 분포와 문제 유형에 맞지 않는 손실을 선택하면 최적화 절차가 정교해도 잘못된 목표에 정확히 수렴하는 결과가 됨.
- 기술사 제언: 손실 값 하락만으로 모델 품질을 판단하지 말고, 실제 평가지표(정확도, RMSE 등)와 병행 모니터링해야 함.
