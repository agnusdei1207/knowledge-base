## 미리 알고가기

- 예측값($\hat{y}$): 모델이 입력을 처리해 산출한 결과값임
- 정답값($y$): 학습 데이터가 제공하는 실제 목표값 또는 라벨임
- 손실(Loss): 한 표본 또는 배치에서 예측과 정답의 차이를 수치화한 값임
- 비용(Cost): 여러 표본의 손실을 합산하거나 평균한 학습 목표값임
- 로그 확률(Log Probability): 작은 확률의 곱을 합으로 바꾸어 분류 손실 계산의 수치 안정성을 높이는 표현임
- 평균절대오차(MAE): 예측값과 정답값 차이의 절댓값을 평균한 회귀 손실임
- 허버 손실(Huber Loss): 작은 오차에는 제곱, 큰 오차에는 절댓값을 적용하는 회귀 손실임
- 포컬 손실(Focal Loss): 분류가 쉬운 다수 표본의 손실 비중을 낮춰 어려운 표본에 집중하는 손실 함수임
- 평균제곱오차(MSE): 예측 오차를 제곱해 평균한 회귀 손실임
- 교차 엔트로피: 정답 클래스의 예측 확률에 음의 로그를 적용한 분류 손실임

## 작성 근거(검토용)

- 손실 함수를 경사하강법과 역전파의 입력 목표로 정의해 048~049 키워드와 논리적으로 연결함
- MSE와 Cross-Entropy를 중심에 두고 오차 반응이 다른 MAE와 Huber를 각각 비교함
- 클래스 불균형과 이상치는 손실 선택을 바꾸는 대표 조건이라 사례에 포함함
- 손실의 기울기 특성은 학습 속도와 이상치 민감도를 좌우하므로 특징과 비교에 반영함
- 결론은 손실·데이터 분포·평가 지표의 정합성으로 정리해 단순 수식 암기를 피함

## Ⅰ. 개요

- **정의/개념**: 손실 함수는 예측값과 정답값의 차이를 수치화해 학습 목적값을 정의하는 함수임
- **배경/필요성**: 모델 파라미터의 기울기를 계산하려면 예측 오차를 하나의 목적값으로 표현해야 함

### 쉽게 이해하기 (학습용)
- 시험 답안과 정답을 비교해 몇 점이 틀렸는지 하나의 감점 점수로 매기는 채점 기준과 같음

## Ⅱ. 특징

- 문제 유형에 맞지 않는 손실 함수를 쓰면 손실은 낮아도 업무 목표와 다르게 학습함
- MSE는 큰 오차를 제곱으로 강하게 벌점화하므로 회귀에서 큰 예측 실패를 민감하게 반영함
- 교차 엔트로피는 정답 클래스 확률이 낮을 때 큰 손실을 주어 분류 확률 학습에 적합함
- 손실 함수의 기울기 모양이 학습 속도·이상치 민감도·클래스 불균형 대응을 좌우함

### 쉽게 이해하기 (학습용)
- 채점 기준을 시험 유형에 안 맞게 쓰면 점수는 좋아도 실력과 다르게 평가되고, 큰 실수를 유난히 크게 감점하는 채점표(MSE)와 자신 없는 답에 크게 감점하는 채점표(교차 엔트로피)는 서로 다른 것을 벌주는 것임

## Ⅲ. 종류 및 비교

| 판단 기준 | MSE | MAE | Huber Loss | 교차 엔트로피(Cross-Entropy) |
|:---|:---|:---|:---|:---|
| 오차 반영 | 오차 제곱 | 오차 절댓값 | 구간별 제곱과 선형 반영 | 정답 확률의 음의 로그 |
| 기울기 특성 | 오차 비례 기울기 | 일정 크기 기울기 | 구간별 연속 기울기 | 확률 오차 기울기 |
| 주요 리스크 | 이상치 민감 | 영점 미분 불가 | 임계값 의존 | 클래스 불균형 민감 |

> 요약: MSE는 오차 제곱, MAE는 절댓값, Huber는 절충, 교차 엔트로피는 확률로 반영함.

### 쉽게 이해하기 (학습용)
- 실수를 제곱해 크게 혼내는 선생님(MSE), 실수 크기와 상관없이 똑같이 혼내는 선생님(MAE), 작은 실수는 살살 큰 실수는 세게 혼내는 선생님(Huber), 자신 있게 틀린 답만 크게 혼내는 선생님(교차 엔트로피)임

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 예측값 $\hat{y}$ | 모델 산출값 |
| 정답값 $y$ | 학습 목표값 |
| 손실 수식 | 예측 오차를 학습용 벌점으로 변환하는 함수 |
| 손실 집계 | 개별 표본 손실을 합계 또는 평균으로 결합한 학습 목적값 |

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 예측값    | --> | 정답 비교 | --> | 손실 계산 | --> | 기울기 생성 |
+-----------+     +-----------+     +-----------+     +-----------+
```

> 요약: 손실 함수는 예측·정답 차이를 벌점화해 역전파·경사하강법의 목표값을 정의함.

### 쉽게 이해하기 (학습용)
- 내가 쓴 답(예측값)과 정답(정답값)을 비교해 감점 규칙(손실 수식)으로 점수를 매기고, 반 전체 감점을 더하거나 평균 내 최종 성적(손실 집계)을 매기는 것임

## Ⅵ. 실무 사례

1. 서버 지연 예측은 Huber Loss로 극단적인 지연값이 학습을 지배하지 않게 함
2. 보안 이벤트 분류는 Focal Loss로 드문 공격 표본의 학습 비중을 높임

### 쉽게 이해하기 (학습용)
- 튀는 값 하나에 채점 기준 전체가 휘둘리지 않게 하거나, 흔한 답보다 드문 답을 맞히는 데 더 큰 배점을 주는 것과 같음

## Ⅶ. 결론

- 손실 함수는 최적화 목표를 정의하므로 문제 유형·데이터 분포·평가 지표에 맞게 선택해야 함
- 학습 손실과 업무 비용이 어긋나면 정확도가 높아도 배포하지 말고 클래스 가중치·강건 손실로 실패 비용을 반영해야 함

### 쉽게 이해하기 (학습용)
- 시험 점수가 높다고 실제 업무 능력과 같다고 믿지 말고, 실수했을 때 진짜 손해가 큰 항목에는 채점 배점을 더 무겁게 매겨야 함
