## 미리 알고가기

- 예측값($\hat{y}$): 모델이 입력을 처리해 산출한 결과값임
- 정답값($y$): 학습 데이터가 제공하는 실제 목표값 또는 라벨임
- 손실($Loss$): 한 샘플 또는 배치에서 예측과 정답의 차이를 수치화한 값임
- 비용($Cost$): 여러 샘플 손실을 합산하거나 평균한 학습 목표값임
- 로그 확률($Log$ Probability): 작은 확률의 곱을 합으로 바꾸어 분류 손실 계산의 수치 안정성을 높이는 표현임
- Focal Loss: 쉬운 다수 표본의 손실 비중을 낮춰 불균형 분류에서 어려운 표본에 집중하는 손실 함수임

## 작성 근거(검토용)

- 손실 함수를 경사하강법과 역전파의 입력 목표로 정의해 048~049 키워드와 논리적으로 연결함
- MSE와 Cross-Entropy를 중심에 두되 이상치 대응을 위해 MAE·Huber를 비교 대상으로 추가함
- 클래스 불균형과 이상치는 손실 선택을 바꾸는 대표 실무 조건이라 유의점에 포함함
- 로짓·확률 변환은 분류 손실의 수치 안정성과 연결되므로 구성요소와 비교표에 반영함
- 결론은 손실·데이터 분포·평가 지표의 정합성으로 정리해 단순 수식 암기를 피함

## Ⅰ. 개요

- **정의/개념**: 손실 함수는 모델 예측값과 정답값의 차이를 수치화해 학습이 줄여야 할 오차 방향을 제공하는 목적 함수임
- **배경/필요성**: 모델 파라미터의 갱신 방향을 정하기 위해 예측 오차를 수치화하는 손실 함수가 필요함

## Ⅱ. 특징

- 문제 유형에 맞지 않는 손실 함수를 쓰면 모델은 낮은 손실을 달성해도 업무 목표와 다른 방향으로 학습함
- $MSE$는 큰 오차를 제곱으로 강하게 벌점화하므로 회귀에서 큰 예측 실패를 민감하게 반영함
- 교차 엔트로피는 정답 클래스 확률이 낮을 때 큰 손실을 주므로 분류 모델의 확률 학습에 적합함
- 손실 함수의 기울기 모양이 학습 속도·이상치 민감도·클래스 불균형 대응을 좌우함

## Ⅲ. 종류 및 비교

| 기준 | MSE | MAE·Huber | 교차 엔트로피(Cross-Entropy) |
|:---|:---|:---|:---|
| 주요 용도 | 회귀 예측 | 이상치가 있는 회귀 | 분류 확률 예측 |
| 오차 반응 | 큰 오차를 제곱으로 증폭 | 큰 오차 영향을 완화 | 낮은 정답 확률에 큰 벌점 |
| 기울기 특성 | 오차 크기에 비례 | MAE는 일정·Huber는 구간별 변화 | 확률 오차에 직접 반응 |
| 적합 조건 | 이상치가 적은 연속값 | 잡음과 이상치가 많은 연속값 | 이진·다중 클래스 분류 |
| 유의점 | 이상치에 민감 | 0 근처 미분 처리 확인 | 로짓·확률 변환과 함께 사용 |

> 요약: MSE는 거리 오차, MAE·Huber는 견고성, Cross-Entropy는 확률 분포 학습에 적합함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 예측값 | 모델 출력이며 회귀에서는 실수, 분류에서는 로짓이나 확률로 표현됨 |
| 정답값 | 손실 계산의 기준이며 연속값·이진 라벨·원-핫 벡터 형태임 |
| 손실 수식 | 예측과 정답의 차이를 문제 목적에 맞는 벌점으로 변환함 |
| 축약 방식 | 배치 손실을 평균 또는 합으로 묶어 최적화 대상 비용을 만듦 |
| 가중치 조정 | 클래스 가중치나 샘플 가중치로 불균형 데이터의 학습 신호를 보정함 |

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 예측값    | --> | 정답 비교 | --> | 손실 계산 | --> | 기울기 생성 |
+-----------+     +-----------+     +-----------+     +-----------+
```

> 요약: 손실 함수는 예측과 정답의 차이를 기울기로 바꿔 학습 방향을 제공함.

## Ⅴ. 원리 및 절차 흐름도

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 출력 산출 | --> | 함수 선택 | --> | 비용 집계 | --> | 역전파 연결 |
+-----------+     +-----------+     +-----------+     +-----------+
```

1. **출력 산출** — 모델이 입력을 처리해 회귀값·로짓·확률 중 하나의 형태로 예측값을 만듦
2. **함수 선택** — 회귀는 $MSE$, 이상치가 많으면 Huber, 분류는 교차 엔트로피를 선택함
3. **비용 집계** — 샘플별 손실을 배치 평균이나 가중 평균으로 묶어 최적화 목표를 계산함
4. **역전파 연결** — 손실을 출력에 대해 미분해 경사하강법이 사용할 기울기를 전달함

> 요약: 문제 유형과 데이터 분포에 맞는 손실을 선택해야 평가 지표와 학습 목표가 일치함.

## Ⅵ. 실무 사례

1. 회귀 모델에서 이상치가 손실을 지배하면 $MSE$ 대신 Huber 또는 $MAE$를 적용하고 평균 오차와 분위수 오차를 함께 확인함
2. 불균형 분류에서는 일반 교차 엔트로피가 다수 클래스에 치우치므로 클래스 가중치나 Focal Loss를 적용하고 재현율과 정밀도를 함께 검증함

## Ⅶ. 결론

- 손실 함수는 모델이 최적화할 목표를 정의하므로 문제 유형·데이터 분포·평가 지표와 일치하도록 선택해야 함
