# 📖 【암기용】 개념 완전 이해

> 목적: 이 개념을 처음 보는 사람도 완벽히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: **모델의 예측과 정답(Label)의 차이를 수치화**하는 함수 — 학습이 최소화해야 할 목적함수(Objective Function)
- **왜 필요한가**: 모델이 스스로 학습하려면 "얼마나 틀렸는지"를 하나의 숫자(스칼라)로 표현해야 하고, 그 숫자를 줄이는 방향을 미분으로 구할 수 있어야 한다. 이 숫자를 정의하는 것이 손실 함수다.
- **핵심 직관**: 양궁에서 과녁 정중앙(정답)과 화살(예측)이 떨어진 거리를 재어 점수(Loss)를 매기는 것과 같다.

## 핵심 용어 정리 (내부에 등장하는 것들)

| 용어 | 의미 | 비유 |
|:---|:---|:---|
| 목적함수 (Objective Function, 상위 키워드) | 학습이 최소화(또는 최대화)하려는 대상 전체를 가리키는 말 | 시험에서 맞혀야 할 목표 점수 |
| MSE (Mean Squared Error, 평균제곱오차) | 예측-정답 오차를 제곱해 평균 낸 값 — 회귀에 사용 | 과녁에서 벗어난 거리의 제곱으로 채점 |
| MAE (Mean Absolute Error, 평균절대오차) | 오차의 절댓값을 평균 낸 값 — 회귀에 사용, 이상치에 덜 민감 | 벗어난 거리를 부호만 없애고 그대로 채점 |
| Cross-Entropy Loss (교차 엔트로피) | 예측 확률분포와 정답 확률분포의 차이 — 분류에 사용 | 정답이라 믿는 확신의 정도에 매기는 벌점 |
| Binary Cross-Entropy (BCE) | 이진분류(정답이 0 또는 1)용 교차 엔트로피 | 스팸이다/아니다 둘 중 하나를 맞히는 채점 |
| Categorical Cross-Entropy | 다중분류(정답이 여러 클래스 중 하나)용 교차 엔트로피 | 여러 동물 사진 중 정답 하나를 맞히는 채점 |
| Huber Loss | 오차가 작으면 MSE처럼, 크면 MAE처럼 동작하는 절충형 | 살짝 벗어나면 부드럽게, 많이 벗어나면 냉정하게 채점 |

## 깊이 이해

### 왜 손실 함수가 필요했나 (배경)
- 모델 학습은 "예측이 정답과 얼마나 다른가"를 줄여나가는 과정이다. 그런데 "맞다/틀리다"라는 이산적 판정만으로는 049 경사하강법이 사용할 기울기를 구할 수 없다. 오차가 연속적이고 미분 가능한 하나의 스칼라 값이어야, 그 값을 어느 방향으로 줄이면 되는지(∂L/∂w) 계산할 수 있다. 이 스칼라 값을 정의하는 함수가 손실 함수다.

### 회귀 손실: MSE vs MAE — 수치로 비교
- 공식: MSE = (1/n)Σ(y−ŷ)², MAE = (1/n)Σ|y−ŷ|
- 정답 y=[3,5,2], 예측 ŷ=[2.5,5.5,2.5]라 하자. 오차(y−ŷ)는 각각 +0.5, −0.5, −0.5.
- MAE = (1/3)(|0.5|+|−0.5|+|−0.5|) = (1/3)(0.5+0.5+0.5) = **0.5**
- MSE = (1/3)(0.5²+(−0.5)²+(−0.5)²) = (1/3)(0.25+0.25+0.25) = **0.25**
- MSE가 오차를 제곱하기 때문에 이상치(outlier)에 훨씬 더 민감하다는 것을 숫자로 확인해보자: 만약 세 번째 오차만 유독 커서 10이었다면(예측이 정답보다 10 벗어남), MAE는 (1/3)(0.5+0.5+10) = **3.67**로 커지지만, MSE는 (1/3)(0.25+0.25+100) = **33.5**로 훨씬 더 크게 튄다. 제곱 연산이 큰 오차를 기하급수적으로 증폭시키기 때문이다.
- 그래서 큰 오차에 강한 페널티를 주고 싶으면 MSE, 이상치에 덜 흔들리고 싶으면 MAE(또는 절충형 Huber Loss)를 쓴다.

### 분류 손실: Binary Cross-Entropy — 확신에 찬 오답의 벌점
- 공식: BCE = −(1/n)Σ[y·log(ŷ) + (1−y)·log(1−ŷ)]
- 정답 y=1(실제 양성), 예측 확률 ŷ=0.9(모델이 90% 확신하며 양성으로 예측)일 때: BCE = −log(0.9) ≈ **0.105**. 정답을 확신 있게 맞혔으므로 손실이 작다.
- 같은 정답 y=1인데 예측 확률 ŷ=0.1(모델이 양성일 확률을 10%로 보아 사실상 음성이라 확신)이면: BCE = −log(0.1) ≈ **2.303**. 확신에 찬 오답이므로 손실이 크게 튄다.
- 즉 log 함수의 성질상 예측 확률이 정답에서 멀어질수록(0에 가까워질수록) −log(ŷ)이 급격히 커져, "자신 있게 틀린" 예측에 큰 벌점을 준다. 이는 "애매하게 틀린" 것보다 "확신에 차서 틀린" 것을 훨씬 강하게 억제하는 효과를 낸다.

### 왜 회귀엔 MSE/MAE, 분류엔 Cross-Entropy를 쓰는가 — 판별 기준
- 회귀는 예측값과 정답이 모두 연속적인 실수이므로, 둘 사이의 거리(유클리드 거리류)를 직접 재는 것이 자연스럽다 → MSE/MAE.
- 분류는 모델 출력이 "각 클래스일 확률분포"이고 정답도 원-핫(one-hot) 확률분포로 볼 수 있다. 두 확률분포가 얼마나 다른지는 거리가 아니라 정보이론적 차이(Cross-Entropy)로 재는 것이 자연스럽다 → Cross-Entropy.
- 만약 분류 문제에 MSE를 잘못 적용하면, 출력층이 시그모이드일 때 예측이 0 또는 1 근처에서 기울기가 0에 가까워져(기울기 소실) 학습이 매우 느려지는 문제가 생긴다. 그래서 분류에는 반드시 Cross-Entropy 계열을 쓴다.

### 비유와 흔한 오해
- **비유**: 양궁에서 과녁 중심(정답)과 화살(예측) 사이 거리를 재어 채점하는 것 — 거리 자체를 재면 회귀(MSE/MAE), "이 자리가 정답일 확률을 몇 %로 봤나"를 채점하면 분류(Cross-Entropy)에 가깝다.
- **오해 1**: Loss 값의 절대 크기만으로 서로 다른 모델의 성능을 비교할 수 없다. MSE와 Cross-Entropy는 스케일이 다르고, 데이터 정규화 여부에 따라서도 값이 달라진다. 같은 손실 함수·같은 데이터 스케일 안에서만 비교 의미가 있다.
- **오해 2**: "Loss가 0이면 완벽한 모델"이 아니다. 훈련 데이터에서 Loss가 0에 가까워지는 것은 오히려 과적합(overfitting)의 신호일 수 있어, 검증(validation) 데이터의 Loss를 함께 봐야 한다.

## 연결 개념
- 049 경사하강법(Gradient Descent) — 손실 함수의 출력을 최소화하는 방향으로 경사하강법이 파라미터를 갱신 (손실함수=목표 정의, 경사하강법=그 목표를 향한 이동)
- 048 역전파(Backpropagation) — 손실 함수 값을 각 파라미터로 미분해 기울기를 전달하는 시작점
- 소프트맥스(Softmax) — 다중분류에서 출력값을 확률분포로 변환해 Categorical Cross-Entropy에 입력하기 전 단계

> 2. **가치**: 옵티마이저가 경사하강법을 수행하기 위한 목적 함수(Objective Function) 역할을 하며, 학습 방향과 보폭(기울기)을 결정한다.

|:---|:---|:---|

## Ⅰ. 개요 및 필요성

- 정의: 기계학습에서 모델의 출력 예측값과 정답(Ground Truth) 간의 오차를 계산하여 스칼라 비용을 도출하는 평가 함수
- 배경: 역전파를 통한 가중치 갱신(Learning)을 위해서는 미분 가능(Differentiable)하고 매끄러운 곡면을 가진 오차 지표가 필요
- 필요성: 회귀 분석의 오차 제곱합 최소화 및 분류 문제의 정보량 차이(K-L Divergence) 최소화 수단으로 활용

---

## Ⅱ. 구조 및 구성요소

```text
입력 데이터(X) -> [신경망 Wx+b] -> [활성화 함수] -> 예측값(Y^)
                                                    |
실제 정답(Y)  ---------------------------------> [Loss Function] -> 오차(Loss) 반환 -> 역전파
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 예측값 ($Y\hat{}$) | 모델 포워드 패스를 통해 산출된 결과(실수 또는 확률값) | Softmax, Sigmoid 등을 통과 |
| 정답 레이블 ($Y$) | 지도 학습에서 제공되는 실제 목표값 | 분류 시 One-hot 인코딩 적용 |
| 비용 계산 수식 | $Y\hat{}$과 $Y$의 거리를 정량화하여 손실값(Cost) 도출 | 미분 가능(Differentiable) 필수 |

> 요약: 모델 출력과 정답 레이블을 입력받아 목적에 맞는 수학적 수식(제곱 오차, 로그 손실)으로 단일 오차값을 계산한다.

---

## Ⅲ. 동작원리 및 흐름도

```text
회귀: 예측(Y^) 및 실제값(Y) 입력 -> (Y - Y^)^2 연산 -> 배치 평균 계산 -> MSE 도출
분류: 확률 분포 예측(Y^) 입력 -> 정답(Y)과 -Y*log(Y^) 연산 -> 교차 엔트로피 도출
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 출력층 예측값 정규화 (필요 시) | 확률합 1.0 유지 (Softmax) |
| 2 | 배치 단위의 각 샘플별 Loss 계산 | MSE 또는 CEE 수식 적용 |
| 3 | 전체 배치의 손실 평균(Cost) 산출 | 스칼라(Scalar) 값 1개 도출 |
| 4 | 연쇄 법칙 적용하여 1차 미분(Gradient) 도출 | 레이어 역전파 입력으로 전달 |

> 요약: 배치 단위로 샘플별 오차를 계산하고 평균 내어 단일 Cost를 구한 뒤, 이를 가중치로 미분하여 역전파를 시작한다.

## Ⅳ. 회귀 vs 분류 손실 함수 비교

| 비교 축 | 회귀용: MSE (Mean Squared Error) | 분류용: Cross-Entropy Error (CEE) |
|:---|:---|:---|
| 사용 목적 | 연속형 수치 예측 (집값, 수요량) | 이산형 클래스 분류 (스팸 여부, 이미지 종류) |
| 수식 원리 | $(Y_i - Y\hat{}_i)^2$의 평균 | $-Y_i \log(Y\hat{}_i)$ 합 (정보이론 기반) |
| 미분 특성 | 예측값이 정답에서 멀수록 기울기가 선형 증가 | Softmax와 결합 시 오차가 클수록 기울기 급증 (빠른 학습) |
| 주요 변형 | MAE(절대오차), Huber Loss(이상치 강건) | Binary Cross-Entropy(이진), Categorical(다중) |

> 요약: 회귀는 값의 유클리디안 거리를 좁히는 제곱 오차를, 분류는 정답 클래스 확률을 1에 가깝게 강제하는 정보 엔트로피 오차를 사용한다.

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 지도학습 손실(MSE/CE 계열) | 메트릭러닝 손실(Contrastive/InfoNCE) | 선택 기준 |
|:---|:---|:---|:---|
| 학습 목표 | 정답 레이블과 예측값의 직접 오차 최소화 | 임베딩 공간에서 유사 샘플 간 거리 축소·비유사 샘플 간 거리 확대 | 레이블 형태(단일 정답 vs 유사도 관계) |
| 필요 데이터 구조 | (입력, 정답) 단일 쌍 | Anchor-Positive-Negative 또는 대조쌍(Contrastive Pair) | 유사도 쌍 구성 가능 여부, 레이블링 비용 |
| 대표 적용 사례 | 회귀·분류 지도학습 전반 | 얼굴 인식(Triplet Loss), 자기지도학습(SimCLR InfoNCE) | 표현학습(Representation Learning) 필요 여부 |

> 요약: 정답 레이블이 명확한 회귀·분류는 MSE/CE 계열로 충분하나, 표현 학습이 목표인 과업은 임베딩 거리 기반 Contrastive/InfoNCE 계열로 전환해야 한다.

| 리스크 (문제) | 발생 원인 (조건) | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 이상치(Outlier) 민감성 | 데이터 내 극단치가 존재할 때 MSE 제곱 연산으로 오차 폭발 | MAE 적용 또는 MSE+MAE 결합형인 Huber Loss로 교체 | 이상치 포함 시 Max Error 감소율 |
| 클래스 불균형 (Imbalance) | 암 진단(99:1)처럼 소수 클래스 데이터가 절대 부족 | 오답(Minority)에 높은 가중치를 주는 Focal Loss 적용 | 소수 클래스 재현율(Recall) 개선폭 |
| 기울기 소실 (Vanishing) | 분류 문제 출력(Sigmoid)에 MSE 적용 시 미분값 0에 수렴 | 출력층 Softmax/Sigmoid + Cross-Entropy 강제 결합 적용 | 출력층 Gradient Norm의 0 근접 여부 |

> 요약: 데이터의 잡음(이상치)이나 클래스 불균형이 심할 경우 표준 MSE/CEE 대신 Huber Loss나 Focal Loss를 적용해 편향된 최적화를 막아야 한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| Loss 수렴 여부 | Train Loss의 단조 감소, Validation Loss 분기 지점 확인 | Epoch 단위 Learning Curve 분석 |
| 평가지표 일치성 | Loss 감소가 실제 비즈니스 지표(Accuracy, F1-Score) 향상과 비례 | Confusion Matrix 동시 모니터링 |
| 과적합 징후 | Train Loss는 0에 수렴하나 Validation Loss 상승 | 조기 종료(Early Stopping) 임계값 |

> 요약: Loss의 절댓값 자체보다 하락 추세와 Validation 지표와의 괴리(과적합)를 모니터링하여 학습 종료 시점을 잡아야 한다.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 객체 탐지(Object Detection) 모델: Bounding Box 좌표 회귀에는 Smooth L1 (Huber) Loss를, 객체 여부 분류에는 Focal Loss를 혼합(Multi-task Loss)하여 학습.
2. 자연어 생성(LLM) 훈련: 다음 단어 예측을 위한 Causal Language Modeling 수행 시 크기가 V(Vocab Size)인 Categorical Cross-Entropy 적용.
3. 데이터 불균형 제어: 제조 불량 검출 시 양품 데이터가 95% 이상이므로, 불량 클래스 예측 실패 패널티를 높인 Weighted Cross-Entropy 설정.

**결론 (2줄):**
- 기술사 판단: 손실 함수는 신경망이 나아갈 목표 지점을 정의하므로, Task 특성(회귀/분류)과 데이터 분포(이상치/불균형)를 분석하여 수학적 미분 한계(기울기 소실)가 없는 함수를 설계해야 한다.
- 향후 방향: 단일 레이블 예측을 넘어, 대조 학습(Contrastive Learning)에 쓰이는 InfoNCE Loss 등 데이터 간 임베딩 거리를 직접 학습하는 메트릭 러닝 손실 함수 활용이 딥러닝 트렌드로 자리잡고 있다.
