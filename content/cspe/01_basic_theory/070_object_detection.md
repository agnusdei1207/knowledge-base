# 📖 【암기용】 개념 완전 이해

> 목적: 객체 탐지를 처음 보는 사람도 완벽히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 이미지 안 객체의 종류와 위치를 동시에 찾는 컴퓨터 비전 기법
- **왜 필요한가**: 이미지 분류는 사진 전체에 "고양이"라는 라벨만 붙이지만, 객체 탐지는 "어디에 몇 마리 있는지"까지 bounding box로 표시한다.
- **핵심 직관**: 사진 위에 사각형 후보를 만들고 각 사각형이 어떤 객체인지 확률과 좌표 오차로 판단한다.

## 깊이 이해
- **배경·문제의식**: 자율주행·CCTV·제조 검사에서는 객체 존재 여부뿐 아니라 위치·크기·개수가 중요하다. 따라서 class probability와 bounding box regression을 함께 해결해야 한다.
- **작동 원리**: R-CNN 계열은 후보 영역을 먼저 만들고 분류하는 two-stage 방식이다. YOLO 계열은 이미지를 grid로 나누어 한 번의 forward pass에서 class와 box를 동시에 예측하는 one-stage 방식이다.
- **비유**: R-CNN은 사진에서 의심 구역을 먼저 오려낸 뒤 정밀 감정하는 방식이고, YOLO는 전체 사진을 한 번 훑으며 위치와 종류를 동시에 표시하는 방식이다.
- **구체 예시**: COCO benchmark는 mAP@[.5:.95]를 사용한다. 제조 결함 탐지는 mAP 0.85 이상, 실시간 CCTV는 FPS 30 이상과 p95 지연 50ms 이하를 함께 목표로 둔다.
- **흔한 오해·주의점**: "정확도만 높으면 된다"는 틀림. 현장 영상은 조명·가림·소형 객체 문제로 false negative 비용이 크며, mAP, recall, latency, FPS를 같이 봐야 한다.

## 연결 개념
- CNN — 특징 추출 backbone
- 이미지 분류 — 객체 탐지보다 단순한 상위 라벨 예측
- 세그멘테이션 — 객체 위치를 pixel mask로 더 세밀하게 표현

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 객체 탐지는 이미지에서 객체 class와 bounding box 좌표를 동시에 예측하는 컴퓨터 비전 과제이다.
> 2. **가치**: 자율주행·CCTV·제조 검사에서 mAP, recall, FPS 지표로 위치 기반 자동 판단을 구현한다.
> 3. **판단 포인트**: YOLO는 실시간성, Faster R-CNN은 정밀 탐지, Mask R-CNN은 pixel 단위 분할 요구에 맞춰 선택한다.

---

## Ⅰ. 개요 및 필요성

객체 탐지는 이미지 내 객체의 종류와 위치를 찾는 기술이다. 분류 모델은 전체 이미지 라벨만 제공하므로 감시·검사·자율주행의 위치 판단 요구를 충족하지 못한다. 객체 탐지는 bounding box와 confidence score로 자동 인식·추적·경보의 입력을 제공한다.

---

## Ⅱ. 구조 및 구성요소

```text
이미지 입력 -> Backbone CNN -> Neck/FPN -> Detection Head -> Box/Class 출력
                              +-> NMS
                              +-> mAP/Recall 평가
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Backbone | 이미지 특징 추출 | ResNet, CSPDarknet, EfficientNet |
| Neck/FPN | 다중 해상도 특징 결합 | 소형 객체 탐지 보완 |
| Detection Head | class, box, objectness 예측 | anchor 기반 또는 anchor-free |
| NMS | 중복 box 제거 | IoU threshold 0.5 등 |

> 요약: 객체 탐지는 CNN 특징을 다중 스케일로 결합하고, 탐지 헤드와 NMS를 통해 최종 객체 위치를 산출한다.

---

## Ⅲ. 동작원리 및 흐름도

```text
학습 이미지/라벨 -> 특징 추출 -> 후보 box 예측 -> 손실 계산
-> 가중치 갱신 -> 추론 -> NMS -> 탐지 결과
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 이미지와 bounding box 라벨 수집 | 라벨 누락률 1% 이하 |
| 2 | 모델 학습과 augmentation | train/val split, loss 수렴 |
| 3 | box·class 추론 | confidence, IoU |
| 4 | NMS와 평가 | mAP, recall, FPS |

> 요약: 객체 탐지는 라벨 box 기반으로 위치·분류 손실을 학습하고, 추론 시 NMS로 중복을 제거해 결과를 확정한다.

---

## Ⅳ. 특징

| 구분 | 내용 | 판단 포인트 |
|:---|:---|:---|
| 장점 | 객체 위치·종류·개수 동시 산출 | mAP 0.85 이상, FPS 30 이상 |
| 한계 | 가림·소형 객체·조명 변화에 민감 | recall, false negative 비용 |
| 비교 대상 | YOLO one-stage, R-CNN two-stage | 실시간성 vs 정밀도 |

> 요약: 객체 탐지는 위치 기반 자동화를 가능하게 하지만 현장 조건에 따라 mAP와 FPS의 균형을 설계해야 한다.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존/대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | 이미지 분류 | box+class 동시 예측 | 위치·개수 판단 필요 시 |
| 비용/성능 | Faster R-CNN 정밀, 추론 비용 큼 | YOLO 실시간 추론 | CCTV FPS 30 이상이면 YOLO |
| 운영/위험 | 수동 검사 | 자동 탐지+human review | false negative 비용 큰 공정 |

> 요약: 실시간 영상은 YOLO, 정밀 분석은 Faster R-CNN, 결함 영역 면적 산출은 Mask R-CNN을 선택한다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 오탐 | 배경 패턴 유사 | hard negative mining | precision 0.90 이상 |
| 미탐 | 소형·가림 객체 | FPN, 고해상도 입력, augmentation | recall 0.95 이상 |
| 성능 저하 | 엣지 장비 자원 제약 | TensorRT, INT8, batch 1 최적화 | p95 50ms 이하 |

> 요약: 현장 리스크는 오탐·미탐·지연이며, 데이터 보강과 엣지 최적화로 관리한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 탐지 정확도 | mAP@[.5:.95] 0.75 이상, recall 0.95 이상 | COCO식 평가, 혼동행렬 |
| 실시간성 | FPS 30 이상, p95 50ms 이하 | 엣지 장비 벤치마크 |
| 운영 품질 | drift 탐지, 라벨 품질, 재학습 주기 | 샘플링 검수, 모니터링 |

> 요약: 객체 탐지 도입 후에는 mAP·recall·FPS·drift를 통합 지표로 추적해야 한다.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 — 단계별 또는 항목별):**
1. 제조 검사는 결함별 라벨 1,000건 이상 확보 후 mAP 0.85 이상, recall 0.95 이상을 승인 기준으로 둠
2. CCTV·엣지 환경은 YOLO 계열을 TensorRT INT8로 변환하고 Jetson급 장비에서 FPS 30 이상을 검증함
3. 오탐·미탐 사례를 주간 샘플링해 active learning 재라벨링 큐로 보내고, 월 1회 drift 리포트를 생성함

**결론 (2줄):**
- 기술사 판단: 실시간 탐지는 YOLO, 정밀 탐지는 Faster R-CNN, 픽셀 단위 결함 면적 산출은 Mask R-CNN을 선택함
- 향후 방향: 객체 탐지는 foundation vision model, synthetic data, edge AI 최적화와 결합해 소량 데이터 현장 적용으로 발전함
