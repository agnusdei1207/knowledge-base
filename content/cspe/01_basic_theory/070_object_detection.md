## 미리 알고가기

- 바운딩 박스: 객체 위치를 사각형 좌표로 표현한 영역임
- IoU (Intersection over Union): 예측 박스와 정답 박스의 겹침 정도를 나타내는 비율임
- mAP (mean Average Precision): 여러 클래스와 IoU 기준에서 탐지 정밀도를 평균한 지표임
- NMS (Non-Maximum Suppression): 겹친 예측 박스 중 신뢰도 높은 박스만 남기는 후처리임
- 앵커 박스: 사전에 정의한 후보 박스 크기와 비율 기준임

## Ⅰ. 개요

- **정의/개념**: 객체 탐지는 이미지나 영상에서 객체의 위치를 바운딩 박스로 찾고 해당 객체의 클래스를 함께 판정하는 컴퓨터 비전 기술임
- **배경/필요성**: 자율주행, CCTV, 스마트 팩토리처럼 객체가 어디에 있는지 알아야 하는 업무에는 이미지 분류만으로 부족함

## Ⅱ. 특징

- 위치 회귀와 클래스 분류를 동시에 수행함
- 여러 객체와 서로 겹친 객체를 한 장면에서 처리함
- 정확도는 mAP로, 실시간성은 FPS와 지연 시간으로 평가함
- 모델 구조는 1-Stage와 2-Stage 방식으로 구분됨

## Ⅲ. 종류 및 비교

| 구분 | 2-Stage Detector | 1-Stage Detector |
|:---|:---|:---|
| 대표 계열 | R-CNN, Faster R-CNN | YOLO, SSD |
| 처리 방식 | 후보 영역 생성 후 분류 | 위치와 클래스를 한 번에 예측 |
| 강점 | 정밀 탐지에 유리 | 실시간 처리에 유리 |
| 한계 | 추론 속도가 느림 | 작은 객체와 밀집 장면에 취약 |
| 적용 | 정밀 검사, 분석 업무 | CCTV, 엣지, 자율주행 보조 |

> 요약: R-CNN 계열은 정밀도, YOLO 계열은 실시간성 중심으로 선택함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 백본 | 이미지의 저수준·고수준 특징을 추출함 |
| 넥 | 여러 해상도 특징 맵을 결합해 작은 객체 정보를 보강함 |
| 탐지 헤드 | 바운딩 박스 좌표, 객체성, 클래스 확률을 출력함 |
| 손실 함수 | 위치 오차, 분류 오차, 객체성 오차를 함께 최적화함 |
| NMS 후처리 | 중복 박스를 제거해 최종 탐지 결과를 정리함 |

> 요약: 백본, 넥, 헤드, 손실, NMS가 위치 탐지와 클래스 판정을 나눠 담당함.

```text
입력 이미지
  -> 백본 특징 추출
  -> 넥 특징 융합
  -> 탐지 헤드
  -> 박스/클래스 점수
  -> NMS
```

## Ⅴ. 원리 및 절차 흐름도

```text
입력 이미지 -> 특징 맵 -> 박스/클래스 예측 -> 신뢰도 필터링 -> NMS 결과
```

1. 이미지를 백본에 넣어 공간 특징 맵을 생성함
2. 넥에서 다양한 크기의 특징을 결합해 탐지 단서를 보강함
3. 헤드가 후보 박스 좌표와 클래스 확률을 예측함
4. 낮은 신뢰도 박스를 제거하고 NMS로 중복 탐지를 정리함

> 요약: 객체 탐지는 특징 추출 후 박스·클래스 점수를 만들고 신뢰도와 NMS로 최종 결과를 정리함.

## Ⅵ. 실무 적용 및 유의점

1. 작은 객체와 가림이 많은 영상은 미탐이 늘어나므로 고해상도 입력, 특징 피라미드, 크롭 추론을 비교하고 클래스별 mAP로 확인함
2. 엣지 장비는 지연 시간과 전력 제약이 크므로 경량 모델, 양자화, 가속 런타임을 적용하고 FPS와 메모리 사용량을 측정함

## Ⅶ. 결론

- 객체 탐지는 위치와 의미를 동시에 판단하는 비전 기술이며, 정밀도와 실시간성의 균형에 따라 R-CNN 계열과 YOLO 계열을 선택해야 함

## 작성 근거(검토용)

- 개요는 위치 탐지와 클래스 판정을 함께 넣어 이미지 분류와의 차이를 명확히 함
- 특징은 다중 객체 처리, 평가 지표, 구조 분류를 포함해 객체 탐지 고유 판단 축을 구성함
- Ⅲ은 R-CNN 계열과 YOLO 계열의 속도·정밀도 차이를 중심으로 실무 선택표를 만듦
- Ⅳ는 백본, 넥, 헤드, 손실, NMS로 현대 탐지기의 공통 구조를 설명함
- Ⅵ은 작은 객체 미탐과 엣지 배포 제약을 핵심 운영 리스크로 선정함
