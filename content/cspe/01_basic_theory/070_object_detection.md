## Ⅰ. 개요
- 정의: 이미지 내 물체의 종류(Classification)와 위치(Localization)를 동시 파악함.
- 배경: 자율주행, 보안관제 등 실시간 영상 분석 수요 증가로 기술이 고도화됨.
- 출제 의도:
| 분류 | 상세 |
| --- | --- |
| 핵심요소 | Bounding Box, IoU, 1-stage vs 2-stage |
| 주요특징 | 실시간성(YOLO), 높은 정확도(R-CNN) |

## Ⅱ. 구성요소
- ASCII 구조도
 [Image] -> [Backbone(CNN)] -> [Neck/Head] -> [BBox & Class]
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| YOLO | 전체 이미지를 그리드로 나눠 한 번에 예측 | 속사포 사격 |
| R-CNN | 후보 영역을 추출한 후 정밀하게 분류 수행 | 신중한 저격 |
| IoU | 예측 박스와 실제 박스의 겹침 정도 측정 | 정조준 확인 |
> 요약: CNN 기반 특성 추출 후 물체 영역과 범주를 결정하는 기술임.

## Ⅲ. 절차
- ASCII 흐름도
[입력 영상] -> [특성 추출] -> [영역 제안/그리드 분할] -> [최종 탐지]
- 4단계 설명
1. 전처리: 이미지 크기 조정 및 정규화를 수행함.
2. 백본 네트워크: ResNet 등을 통해 이미지 특징 맵을 생성함.
3. 객체 후보 탐색: 앵커 박스를 활용해 객체 존재 가능성을 평가함.
4. NMS 적용: 중복된 탐지 박스를 제거하고 가장 확률 높은 것만 남김.
> 요약: 이미지 특징을 분석하여 다수의 객체 위치와 라벨을 확정함.

## Ⅳ. 문제점
- 작은 물체 탐지 성능 저하 및 조명 변화 등 환경 요인에 민감함.

## Ⅴ. 개선방안
- 단기: FPN(Feature Pyramid Network)을 사용해 다양한 크기에 대응함.
- 중기: 데이터 증강(Augmentation)을 통해 학습 데이터 다양성을 확보함.
- 장기: Transformer 기반 탐지기(DETR)를 도입해 전역 문맥을 활용함.

## Ⅵ. 전망
- 스마트 시티, 로봇 비전 분야에서 핵심 인지 엔진으로 지속 발전함.
