## Ⅰ. 개요
- **정의**: 이미지 내 다수 객체의 위치(Bounding Box)와 클래스를 동시에 식별하는 컴퓨터 비전 기법
- **배경/필요성**: 071 이미지 분류는 "무엇이 있는가"만 판별하나, 실환경(자율주행·보안)에서는 "어디에·몇 개" 정보까지 필수
- **비유**: 사진 속 모든 사물에 이름표와 위치 테두리를 붙이는 작업

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 1-Stage vs 2-Stage 구조 차이 | YOLO(1-Stage) vs R-CNN(2-Stage) 정확도/속도 트레이드오프 | 분류(071)와 탐지 차이 미구분 시 감점 |

> 요약: 위치 추정(Localization)과 분류(Classification)를 동시 수행하여 객체의 종류와 좌표를 산출하는 기법임.

## Ⅱ. 구성요소
```text
+----------+   +----------+   +----------+   +----------+
| Input    |-->| Backbone |-->| Neck     |-->| Head     |
| Image    |   | (ResNet) |   | (FPN)    |   | (Box+Cls)|
+----------+   +----+-----+   +----+-----+   +----------+
                    |               |
               +----+----+    +----+----+
               |Feature  |    |Multi-   |
               |Extract  |    |Scale Map|
               +---------+    +---------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| Backbone | ResNet·CSPDarknet 등 CNN으로 이미지 특징 맵 추출 | 망막 |
| Neck(FPN) | 다중 해상도 특징 맵을 피라미드로 융합하여 소형 객체 대응 | 다초점 렌즈 |
| Head | 앵커 박스 기반 좌표 회귀 + 클래스 분류를 동시 수행 | 판정관 |

> 요약: Backbone->Neck->Head 파이프라인으로 다중 스케일 특징을 추출하고 박스+클래스를 예측함.

## Ⅲ. 절차
```text
+----------+   +----------+   +----------+   +----------+
| Image In |-->| Feature  |-->| Proposal |-->| NMS      |
|          |   | Pyramid  |   | + Score  |   | Filter   |
+----------+   +----------+   +----------+   +----------+
```

1. **이미지 전처리** — 입력 영상을 고정 해상도(640x640 등)로 리사이즈 및 정규화
2. **특징 추출** — Backbone + FPN으로 다중 스케일 특징 맵(P3~P7) 생성
3. **박스 예측** — 그리드 셀별 앵커 박스에 대한 좌표 오프셋·객체 신뢰도·클래스 확률 산출
4. **NMS 필터링** — IoU 임계값(0.5~0.7) 기준 중복 박스 제거, 최종 탐지 결과 확정

> 요약: 특징 피라미드에서 박스 좌표와 클래스를 예측한 뒤 NMS로 중복을 제거하여 최종 결과를 산출함.

## Ⅳ. 문제점
- **속도-정확도 트레이드오프**: 2-Stage(Faster R-CNN) mAP 높으나 30FPS 미만, 1-Stage(YOLO) 속도 우세하나 소형 객체 정확도 하락
- **소형·겹침 객체 탐지 난이**: 8x8 픽셀 이하 객체나 Occlusion 환경에서 AP 20% 이상 하락
- **도메인 이동 취약**: 학습 환경(주간·맑음)과 추론 환경(야간·우천) 차이 시 오탐률 급증

> 요약: 속도-정확도 균형·소형 객체·도메인 이동이 핵심 과제임.

## Ⅴ. 개선방안
1. 단기: YOLOv8/v9의 Anchor-Free 헤드 도입으로 속도와 정확도 균형점 개선 (지표: mAP50 > 0.55 @100FPS)
2. 중기: DINO·RT-DETR 등 Transformer 기반 탐지기로 소형 객체 전역 문맥 활용
3. 장기: Domain Adaptation + 합성 데이터 증강으로 야간·우천 등 미지 환경 견고성 확보

- **속도-정확도**: 구조 한계 -> Anchor-Free + 경량 백본 (지표: FPS vs mAP 파레토)
- **소형 객체**: 저해상도 특징 -> FPN 고도화 + Sliced Inference (지표: AP_small > 0.3)
- **도메인 이동**: 분포 차이 -> 적대적 도메인 적응 (지표: Cross-domain mAP 하락률 < 10%)

> 요약: Anchor-Free·Transformer 탐지·도메인 적응으로 단계적 개선함.

## Ⅵ. 전망
- 향후 발전 방향: NPU 탑재 엣지 디바이스에서 실시간 탐지가 보편화되며, 멀티모달(LiDAR+카메라) 3D 탐지로 확장
- 기술사적 판단: 071 이미지 분류가 "무엇"이라면 객체 탐지는 "무엇+어디"로, 세그멘테이션은 "무엇+어디+경계"로 세분화
- 기술사 제언: 실서비스 도입 시 mAP뿐 아니라 FPS·오탐률·엣지 소비 전력까지 종합 평가하여 모델을 선정할 것을 권고함
