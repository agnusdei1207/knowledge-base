## 미리 알고가기

- 바운딩 박스: 객체 위치를 사각형 좌표로 표현한 영역임
- 박스 겹침 비율(IoU): 예측 박스와 정답 박스가 겹치는 정도를 나타내는 비율임
- 평균 탐지 정밀도(mAP): 여러 클래스와 박스 겹침 기준에서 탐지 정밀도를 평균한 지표임
- 중복 박스 억제(NMS): 겹친 예측 박스 중 신뢰도 높은 박스만 남기는 후처리임
- 2단계 탐지기(2-Stage Detector): 후보 영역을 만든 뒤 객체 위치와 클래스를 판정하는 구조임
- 1단계 탐지기(1-Stage Detector): 전체 특징 맵에서 객체 위치와 클래스를 함께 판정하는 구조임
- 클래스 불균형: 배경이나 일부 클래스 표본이 다른 클래스보다 많은 상태임
- 양자화(Quantization): 모델이 사용하는 숫자의 정밀도를 낮춰 크기와 연산량을 줄이는 기법임
- 초당 프레임 수(FPS): 모델이 1초 동안 처리하는 영상 프레임 개수임

## 작성 근거(검토용)

- **방향성**: 객체 탐지는 위치·클래스를 함께 판정해 이미지 분류보다 풍부한 정보를 제공하는 대신 연산량이 늘어나므로, 정확도와 지연 요구에 맞춰 2단계 또는 1단계 탐지기를 선택해야 함
- **Ⅰ. 개요 구성**: 위치 탐지와 클래스 판정을 함께 제시해 이미지 분류와의 차이를 명확히 함
- **Ⅱ. 특징 선정**: 다중 객체 처리·평가 지표·구조 분류를 서로 다른 판단 축으로 둠
- **Ⅲ. 비교축 선정**: 탐지 메커니즘·계산 범위·주요 리스크는 2-Stage·1-Stage의 고유 스펙이라 축은 유지하고, 정확도·지연 요구에 따른 선택 기준은 요약 문장의 구체적 분기 조건으로 명시함
- **Ⅳ. 구조 선정**: 백본, 넥, 헤드, 손실, NMS로 현대 탐지기의 공통 구조를 설명함
- **Ⅴ. 절차 선정**: 후보 생성부터 중복 억제 반복까지 NMS 흐름을 단계화함
- **Ⅵ. 사례 선정**: 작은 객체 미탐과 엣지 배포 제약은 객체 탐지의 핵심 운영 조건임
- **전수 검수**: 제목부터 결론까지 용어·표·도식·요약을 대조하고 절 간 판단축을 일치시킴

## Ⅰ. 개요

- **정의/개념**: 객체 탐지는 이미지나 영상에서 객체 위치를 바운딩 박스로 찾고 클래스를 함께 판정하는 컴퓨터 비전 기술임
- **배경/필요성**: 이미지 분류는 객체 위치와 개수를 구분하지 못하므로 자율주행·CCTV·스마트 팩토리에 위치 판정 기술이 필요함

### 쉽게 이해하기 (학습용)
- 사진에 무엇이 있는지 한 단어로 답하는 것을 넘어, 사진 속 각 사물에 사각형 테두리를 그리고 이름표까지 붙이는 것과 같음

## Ⅱ. 특징

- 위치 회귀와 클래스 분류를 동시에 수행함
- 여러 객체와 겹친 객체를 한 장면에서 처리함
- 정확도는 mAP로, 실시간성은 FPS와 지연 시간으로 평가함
- 모델 구조는 1-Stage와 2-Stage 방식으로 구분됨

### 쉽게 이해하기 (학습용)
- 어디에 있는지(위치)와 무엇인지(이름표)를 한 번에 같이 답함
- 사진 한 장에 사물이 여러 개, 심지어 서로 겹쳐 있어도 각각 찾아냄
- 얼마나 잘 맞혔는지는 정답률(mAP)로, 얼마나 빠른지는 처리 속도(FPS)로 따로 점수를 매김
- 후보부터 천천히 좁혀가는 방식과 한 번에 훑어 찾는 방식 두 갈래로 나뉨

## Ⅲ. 종류 및 비교

| 판단 기준 | 2-Stage(R-CNN 계열) | 1-Stage(YOLO 계열) |
|:---|:---|:---|
| 탐지 메커니즘 | 후보 영역 생성 후 분류 | 위치·클래스 동시 예측 |
| 계산 범위 | 후보 영역별 후속 연산 | 전체 특징 맵 일괄 예측 |
| 주요 리스크 | 추론 지연 | 클래스 불균형 |

> 요약: 정확도를 우선하면 2-Stage로 후보 영역을 순차 분류·보정하고, 실시간 처리가 필요하면 1-Stage로 위치와 클래스를 한 번에 예측함.

### 쉽게 이해하기 (학습용)
- 2-Stage는 사진에서 사물이 있을 법한 자리를 먼저 추린 뒤 하나하나 자세히 살펴 이름표를 붙이는 꼼꼼한 방식이고, 1-Stage는 사진 전체를 한 번 쓱 훑어 위치와 이름표를 동시에 매기는 빠른 방식임

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 백본 | 이미지의 계층별 특징 추출기 |
| 넥 | 여러 해상도 특징 맵의 결합 계층 |
| 탐지 헤드 | 박스 좌표·객체성·클래스 확률 출력층 |
| 손실 함수 | 위치·분류·객체성 오차의 최적화 기준 |
| NMS 후처리 | IoU 기준 중복 박스 억제 절차 |

> 요약: 객체 탐지기는 백본·넥으로 특징을 추출하고 탐지 헤드로 위치·클래스를 예측한 뒤 NMS로 중복 박스를 억제함.

### 쉽게 이해하기 (학습용)
- 사진의 특징을 뽑아내는 눈(백본)이 이미지를 훑고, 여러 크기의 특징을 한데 모으는 손(넥)을 거쳐, 실제로 테두리와 이름표를 매기는 입(탐지 헤드)이 답을 내고, 마지막으로 겹친 답 중 겹치는 것만 정리(NMS)함

## Ⅴ. 원리 및 절차 흐름도

```text
후보 박스 예측 → 신뢰도 미달 제거 → 최고 신뢰도 박스 선택
                                        ↓
                              나머지 박스와 IoU 비교
                         ├─ 임계값 초과 → 중복 박스 제거
                         └─ 임계값 이하 → 후보 유지
                                        ↓
                              남은 후보가 없을 때까지 반복
```

1. **후보 생성**: 탐지 헤드가 박스 좌표·객체성·클래스 확률을 예측함
2. **신뢰도 필터링**: 객체성이 임계값보다 낮은 후보를 제거함
3. **기준 박스 선택**: 남은 후보 중 신뢰도가 가장 높은 박스를 결과에 추가함
4. **중복 억제**: 기준 박스와 IoU가 임계값을 넘는 동종 후보를 제거함
5. **반복 종료**: 남은 후보가 없을 때까지 선택과 중복 억제를 반복함

> 요약: 객체 탐지는 신뢰도가 높은 박스를 우선 채택하고 IoU가 큰 동종 박스를 반복 제거해 최종 탐지 결과를 확정함.

### 쉽게 이해하기 (학습용)
- 같은 사물 주위에 여러 개 그려진 테두리 중, 자신 없는 테두리부터 지우고 가장 확신이 큰 테두리를 남긴 뒤 그것과 많이 겹치는 나머지 테두리를 차례로 지워, 사물마다 테두리가 하나만 남을 때까지 반복함

## Ⅵ. 실무 사례

1. CCTV의 작은 객체 탐지는 고해상도 입력과 특징 피라미드로 여러 크기의 객체를 예측함
2. 엣지 탐지 장비는 경량 모델과 양자화로 연산량을 줄임

### 쉽게 이해하기 (학습용)
- CCTV처럼 작게 찍힌 사물도 놓치지 않으려면 사진을 더 선명하게 보고 여러 크기로 나눠 살피며, 작은 장비에서 돌려야 할 때는 모델을 가볍게 줄여 연산 부담을 낮춤

## Ⅶ. 결론

- 객체 탐지는 위치와 클래스를 함께 판정하며 정확도와 지연 요구에 따라 2단계 또는 1단계 탐지기를 선택해야 함
- 안전 검사는 클래스별 미탐 비용으로 임계값을 따로 정하고, 실시간 한도를 넘으면 해상도·후처리·모델 구조를 함께 경량화해야 함

### 쉽게 이해하기 (학습용)
- 어디에 무엇이 있는지 함께 찾는 기술이므로 얼마나 정확해야 하는지와 얼마나 빨라야 하는지를 먼저 정하고, 놓치면 안 되는 검사일수록 판정 기준을 따로 두고 속도가 부족하면 화질·후처리·모델을 함께 가볍게 조정함
