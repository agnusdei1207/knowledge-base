## Ⅰ. 개요
- 매 순간 가장 최선이라고 생각되는 선택을 하여 최종 해답에 도달하는 기법임.
- 지역적 최적해가 전역적 최적해가 되는 보장이 있을 때 매우 효율적임.
- [표] 출제 의도: 근사해 도출 전략 및 알고리즘 타당성 검증 역량 측정.

## Ⅱ. 구성요소
- ASCII 구조도
  Current State -> [ Greedy Choice ] -> Next State -> Global?

| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| Greedy Choice | 미래를 보지 않고 현재 시점의 최적항 선택 | 당장 눈앞의 이득 |
| Feasibility | 선택이 제약 조건을 만족하는지 확인 | 예산 범위 체크 |
| Optimality | 최종 해가 전역 최적인지 검증 필요 | 최선인지 사후 확인 |

> 요약: 단순하고 빠르지만 적용 가능한 조건(Greedy Property)이 엄격함.

## Ⅲ. 절차
- ASCII 흐름도
  Selection -> Feasibility Test -> Solution Test -> Update State

1. 현재 상태에서 최적의 선택지 하나를 고름.
2. 선택된 항목이 문제의 제약 조건을 어기지 않는지 확인함.
3. 선택 항목을 부분 해집합에 추가하고 문제가 해결됐는지 봄.
4. 미해결 시 다음 선택을 진행하고, 해결 시 최종 해를 반환함.

> 요약: 앞날을 고려하지 않고 현재의 최선을 선택해 나감.

## Ⅳ. 문제점
- 근시안적 선택으로 인해 전체 문제의 최적해를 놓칠 가능성 높음.
- 정당성 증명이 어렵고 특정 문제(잔돈 거스르기 등)에만 국한됨.

## Ⅴ. 개선방안
- 단기: 최적 부분 구조(Optimal Substructure) 존재 여부를 우선 검토함.
- 중기: 허프만 코딩, MST 등 탐욕법이 검증된 알고리즘 위주 적용함.
- 장기: 최적해 보장이 안 될 경우 근사 알고리즘(Heuristic)으로 활용함.

## Ⅵ. 전망
- 클라우드 워크로드 스케줄링 및 Kubernetes의 파드(Pod) 배치 최적화에서 실시간 반응성을 확보하기 위한 온라인 탐욕 알고리즘이 시스템 운영의 CSF가 될 것임.
- 정교한 증명 없이도 실무적 근사치를 빠르게 도출하는 '메타 휴리스틱' 기법과 결합하여 스마트 팩토리의 실시간 공정 제어 분야에서 활용도가 극대화될 전망임.
- 탄소 배출 최소화 경로 산출 등 다중 목적(Multi-objective) 최적화 문제에서 초기해 도출을 위한 고속 엔진으로서 탐욕 알고리즘의 역할이 재조명될 것임.
