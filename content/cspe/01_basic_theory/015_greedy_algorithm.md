## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 매 단계에서 현재 시점의 국소 최적(locally optimal) 선택을 반복하여 전역 최적해를 구하는 알고리즘 설계 기법임 |
| **배경/필요성** | DP 대비 구현이 단순하고 빠르며, 탐욕 선택 속성과 최적 부분 구조를 만족하는 문제에 최적해를 보장함 |
| **출제 의도** | 탐욕 알고리즘의 정당성 증명 조건과 DP와의 차이를 설명할 수 있는지 평가함 |

## Ⅱ. 구성요소
```
+----------+     +----------+     +----------+
| 탐욕선택  | --> | 최적부분  | --> | 해구성   |
| 속성     |     | 구조     |     | (반복)   |
+----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| 탐욕 선택 속성 | 현재 최적 선택이 이후 선택에 영향을 주지 않고 전역 최적에 포함되는 성질임 | 가장 큰 동전부터 거스름돈 지급 |
| 최적 부분 구조 | 전체 최적해가 부분 문제의 최적해를 포함하는 성질임 | 부분 경로도 최단인 경우 |
| 해 구성 | 선택을 누적하여 최종 해를 점진적으로 완성함 | 동전을 하나씩 모아 총액 달성 |

> 요약: 탐욕 선택 속성 + 최적 부분 구조를 만족하면, 매 단계 국소 최적 선택이 전역 최적을 보장함.

## Ⅲ. 절차
```
+------------+     +------------+
| 후보집합   | --> | 선택함수   |
| 정렬       |     | (최적선택) |
+------------+     +------------+
                        |
+------------+     +----+-------+
| 해완성     | <-- | 적합성검사 |
| (반복종료) |     | (제약조건) |
+------------+     +------------+
```

1. 후보 정렬: 선택 기준(가중치·비율 등)에 따라 후보를 정렬함
2. 선택 함수: 현재 시점에서 가장 유리한 후보를 선택함
3. 적합성 검사: 선택이 제약 조건을 만족하는지 확인하고, 위반 시 다음 후보로 넘어감
4. 해 구성·종료: 선택을 누적하여 해가 완성되면 종료함

> 요약: 정렬 → 최적 선택 → 적합성 검사 → 해 구성으로 O(n log n)에 최적해를 구함.

## Ⅳ. 문제점
- 최적해 미보장: 탐욕 선택 속성을 만족하지 않는 문제에서 국소 최적이 전역 최적이 아닐 수 있음
- 정당성 증명 필요: 알고리즘이 최적해를 보장함을 수학적으로 증명해야 하며, 이 과정이 어려움
- 역추적 불가: 한 번 선택하면 되돌리지 않으므로 잘못된 선택을 수정할 수 없음

## Ⅴ. 개선방안
- (단기) 교환 논증: 탐욕 해와 최적 해를 교환해도 손해가 없음을 증명하여 정당성을 확보함
- (중기) 매트로이드 이론: 문제가 매트로이드 구조이면 탐욕 알고리즘의 최적성이 자동 보장됨
- (장기) 근사 알고리즘: NP-hard 문제에 탐욕을 적용하여 근사비가 보장되는 해를 구함

## Ⅵ. 전망
- 허프만 코딩·작업 스케줄링·MST(크루스칼) 등에서 탐욕이 핵심 전략이며, 조합 최적화의 근사 알고리즘 설계에서 탐욕 기반 접근이 지속 활용될 전망임
