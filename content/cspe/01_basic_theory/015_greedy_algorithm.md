# 📖 【암기용】 개념 완전 이해

## 한눈에
- **개요**: 탐욕 알고리즘은 **알고리즘 설계 패러다임**의 하나로, 매 단계에서 **당장 가장 좋아 보이는 국소 최적(local optimum)을 골라** 되돌아보지 않고 나아가, 그 선택들이 전체 최적해를 이루기를 기대하는 기법이다.
- **왜 필요한가**: 모든 경우를 표로 비교하는 DP는 정확하지만 상태가 많으면 비싸므로, 문제 구조가 허락할 때는 **한 번의 국소 선택으로 즉시 답을 확정**해 훨씬 빠르게 풀기 위해서다.
- **핵심 직관**: "**지금 가장 이득인 것을 집고 뒤돌아보지 않는다**" — 선택을 번복하지 않아 빠르지만, 그 국소 선택이 전체 최적이 됨은 **문제 구조가 증명**될 때만 보장된다.

## 핵심 용어 정리 (내부에 등장하는 것들)

답안용 Ⅰ~Ⅵ·표에 나오는 탐욕 고유 표기를 비유와 함께 먼저 세운다(복잡도 의미는 001·002 참조). 맨 위는 상위 핵심 키워드다.

| 용어/표기 | 의미 | 비유·예 |
|:---|:---|:---|
| 탐욕 알고리즘 (상위 키워드) | 매 단계 국소 최적을 골라 확정하는 설계 패러다임 | 눈앞에서 가장 큰 동전부터 집기 |
| 국소 최적 선택 (Greedy Choice) | 현재 시점에서 가장 이득인 하나를 고름 | 지금 마감 가장 빠른 회의부터 선택 |
| 탐욕 선택 속성 | 국소 최적 선택이 전체 최적해의 일부가 됨 | 큰 동전부터가 최소 개수를 보장 |
| 최적 부분 구조 | 부분 문제 최적해가 전체 최적을 이룸(013과 공통) | 남은 구간 최적을 이어 붙임 |
| 국소 vs 전역 최적 | 한 단계 최선(국소)이 전체 최선(전역)과 다를 수 있음 | 눈앞 지름길이 전체론 돌아가는 길 |
| 결정 불가역성 | 한 번 고른 선택을 번복하지 않음 | 집은 동전을 다시 안 내려놓음 |
| 매트로이드 (Matroid) | 탐욕의 최적성이 보장되는 대수 구조 | 탐욕이 항상 통하는 문제의 뼈대 |
| 근사·휴리스틱 | 최적 보장 없이 빠른 준최적 해를 냄(078 참조) | 완벽 대신 빠르고 그럴싸한 답 |

## 깊이 이해
- **배경·문제의식**: 최적화 문제를 모든 경우 탐색으로 풀면 지수 시간이 든다. 어떤 문제는 **매 단계 가장 이득인 것을 고르면 되돌아보지 않아도 전체 최적**이 된다. 이때 탐욕은 DP보다 훨씬 빠르지만, 아무 문제에나 쓰면 국소 최적에 갇혀 오답을 낸다.
- **작동 원리 (어떻게+왜)**:
  - **정당성 두 조건**: ① **탐욕 선택 속성** — 국소 최적 선택이 항상 어떤 전체 최적해에 포함됨, ② **최적 부분 구조** — 그 선택 후 남은 부분 문제의 최적해를 이으면 전체 최적이 됨. 이 둘이 **증명**돼야 탐욕이 정확하다.
  - **왜 빠른가**: 각 단계에서 하나만 확정하고 번복하지 않으므로, 대개 정렬 O(N log N) + 순회 O(N) 정도로 끝난다. DP처럼 표를 다 채우지 않는다.
  - **실패하는 경우**: 조건이 성립하지 않으면 국소 최적이 전역 최적을 놓친다. 이때는 DP(013)로 모든 경우를 비교하거나, 최적을 포기하고 **근사 알고리즘**(078)으로 준최적을 취한다.
- **비유**: 등산에서 매번 "지금 가장 가파르게 오르는 방향"만 택하면 눈앞 봉우리(국소 최적)엔 빨리 닿지만, 더 높은 다른 봉우리(전역 최적)를 놓칠 수 있다. 지형(문제 구조)이 단봉이어야 탐욕이 정답에 닿는다.
- **구체 예시(수치·사례)**: 거스름돈을 800원 낼 때 500·100·50·10원 체계에서는 큰 동전부터 집는 탐욕이 최소 개수(5개)를 보장한다. 그러나 1·3·4원 체계에서 6원은 탐욕(4+1+1=3개)이 최적(3+3=2개)을 놓친다 — 동전 체계가 조건을 만족해야 한다. 활동 선택(회의실 배정), 허프만 코딩(032), 크루스칼·프림(012), 다익스트라(011)가 탐욕의 대표 정당 사례다.
- **흔한 오해·주의점**:
  - **탐욕은 항상 최적이라는 오해** — 두 조건이 증명될 때만 최적이다. 0/1 배낭은 탐욕이 최적을 놓쳐 DP가 필요하다(단, 분할 가능 배낭은 탐욕이 최적).
  - **탐욕과 DP를 이득으로만 구분** — 핵심 차이는 **되돌아봄 여부**다. 탐욕은 한 번 고르면 번복 없음, DP는 모든 경우를 남겨 비교한다.
  - **국소=전역 착각** — 국소 최적의 합이 전역 최적이 되는지는 문제 구조(매트로이드 등)로 따로 증명해야 한다.

## 연결 개념
- **동적 프로그래밍 (013)**: 둘 다 최적 부분 구조를 쓰지만, 탐욕은 국소 선택 후 번복 없음·DP는 전 경우 비교라는 대비 개념(최적성 보장 여부가 갈림).
- **최소 신장 트리 (012)**: 크루스칼·프림이 매 단계 최소 간선을 고르는 탐욕의 대표 정당 사례.
- **근사 알고리즘 (078)**: 탐욕 조건이 깨질 때 최적 대신 준최적 보장을 취하는 확장 개념.

# 📝 【답안용】 시험 답안 템플릿

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 탐욕은 매 단계 국소 최적을 골라 번복 없이 확정하는 빠른 설계 패러다임임.
> 2. **가치**: 활동 선택·허프만·MST·다익스트라 등 조건이 성립하는 문제를 정렬+순회급으로 빠르게 최적 해결함.
> 3. **판단 포인트**: 탐욕 선택 속성과 최적 부분 구조가 증명될 때만 최적이며, 아니면 DP·근사로 전환해야 함.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 탐욕 정당성 조건 | 탐욕 선택 속성·최적 부분 구조 2조건 | 최적성이 무조건 보장된다고 단정 |
| 대표 응용 이해 | 허프만·MST·다익스트라·활동 선택 | 반례(1·3·4 동전) 인식 누락 |
| DP와의 차이 | 되돌아봄 여부·최적성 보장 여부 | 탐욕과 DP를 이득 크기로만 구분 |

> 요약: 탐욕 2조건(선택 속성·최적 부분 구조)과 대표 응용, DP와의 최적성 보장·번복 여부 차이를 짚어야 함.

## Ⅰ. 개요 및 필요성
- 개요: 매 단계 국소 최적을 골라 번복 없이 확정하는 최적화 설계 패러다임임
- 배경: 전 경우 탐색은 지수 시간, DP는 상태 폭증 시 비싸 더 빠른 확정 전략이 필요함
- 필요성: 조건이 성립하는 문제를 정렬+순회급 시간에 최적 또는 준최적으로 신속히 풀 필요가 있음

## Ⅱ. 구조 및 구성요소
선형 구조도 (국소 선택 반복):

    후보 집합 정렬(기준값) -> 매 단계 국소 최적 하나 선택 -> 제약 위반이면 폐기 / 아니면 확정 -> 후보 소진까지 반복 -> 해 완성
      / 정당성 성립 : 국소 선택 합이 전역 최적 (증명 필요)
      / 정당성 미성립 : 국소 최적 갇힘 -> DP(013) 또는 근사(078)로 전환

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 선택 기준(정렬 키) | 국소 최적을 정하는 우선순위 | 기준 설계가 정확성 좌우 |
| 국소 최적 선택 | 매 단계 최선 후보 하나 확정 | 번복 없음(불가역) |
| 제약 검사 | 선택이 실행 가능한지 확인 | 위반 시 해당 후보 폐기 |
| 정당성 증명 | 2조건 성립 여부 확인 | 미성립 시 오답 위험 |

> 요약: 후보를 기준으로 정렬해 매 단계 국소 최적을 번복 없이 확정하되, 2조건이 증명돼야 전역 최적이 됨.

## Ⅲ. 동작원리 및 흐름도
선형 흐름도 (활동 선택 기준):

    활동을 종료 시각 오름차순 정렬 -> 가장 빨리 끝나는 활동 선택 -> 겹치지 않는 다음 활동 선택 -> 후보 소진까지 반복 -> 최대 개수 확정

1. 정렬: 알고리즘이 후보(활동)를 선택 기준(종료 시각)으로 정렬함
2. 선택: 알고리즘이 매 단계 기준상 가장 이득인 후보 하나를 골라 확정함
3. 검사: 확정 후보가 이미 고른 것과 제약(시간 겹침)을 위반하지 않는지 확인해 위반 시 폐기함
4. 종료: 후보가 소진되면 확정 집합이 해가 되며, 정당성 2조건이 성립할 때 이 해가 전역 최적임

> 요약: 후보를 기준 정렬 후 매 단계 국소 최적을 골라 제약을 검사하며 확정하고, 2조건 성립 시 전역 최적을 얻음.

## Ⅳ. 특징
- 빠른 확정: 매 단계 하나만 골라 번복하지 않아 대개 정렬 O(N log N)+순회 O(N)에 끝남
- 조건부 최적성: 탐욕 선택 속성·최적 부분 구조가 증명될 때만 전역 최적을 보장함
- 결정 불가역: 한 번 고른 선택을 되돌리지 않아 DP보다 메모리·시간이 가벼움
- 실패 위험: 조건 미성립 시(예: 0/1 배낭·1·3·4 동전) 국소 최적에 갇혀 오답을 냄
- 근사 활용: 최적 보장이 없어도 NP-난해 문제에서 빠른 준최적 해(근사·휴리스틱, 078)로 널리 쓰임

## Ⅴ. 심화 비교 및 적용 판단

최적성 보장·되돌아봄·시간·적용 조건 축에서 탐욕과 DP를 대조함(DP vs 분할 정복의 부분 문제 중복 차이는 013 참조).

| 구분 | 탐욕 알고리즘 | 동적 프로그래밍(013) |
|:---|:---|:---|
| 최적성 보장 | 2조건 증명 시에만 보장 | 항상 전역 최적 보장 |
| 선택 방식 | 국소 최적·번복 없음 | 전 경우 비교·표에 남김 |
| 시간·메모리 | 정렬+순회급, 가벼움 | 상태 수 × 전이, 무거움 |
| 대표 예 | 허프만·MST·다익스트라 | 0/1 배낭·LCS·편집 거리 |

> 요약: 탐욕은 조건 성립 시 가볍고 빠르게 최적을 내지만, 조건이 없으면 항상 최적인 DP로 전환해야 함.

**리스크·대응:**
- 정당성 미증명 — 국소 최적이 전역 최적을 놓쳐 오답 → 탐욕 선택 속성·반례를 사전 검증
- 국소 최적 함정 — 0/1 배낭 등에서 탐욕 실패 → DP(013)로 전 경우 비교 전환
- 기준 설계 오류 — 정렬 키가 부적절해 준최적 → 문제 목적에 맞는 선택 기준 재설계

**점검 지표:**
- 정확성 — 탐욕 해 = DP·브루트포스 해(소입력) — 반례 탐색으로 최적성 확인
- 효율 — 총 연산 ≈ 정렬 O(N log N) — 선택 횟수 = N 확인

## Ⅵ. 실무 적용 및 결론

**적용 방안:**
1. 데이터 압축(허프만 코딩): 출현 빈도가 낮은 심볼부터 병합하는 탐욕으로 최소 평균 부호 길이의 접두 부호를 생성(032 참조)
2. 네트워크·인프라 설계(MST·최단 경로): 크루스칼·프림·다익스트라의 탐욕 선택으로 최소 비용 연결망·최단 경로를 산출(011·012 참조)
3. 스케줄링·자원 배분(활동 선택): 종료 시각 기준 탐욕으로 회의실·작업 배정 최대화, NP-난해 구간은 근사(078)로 준최적 확보

**결론:**
- 기술사 판단: 탐욕 선택 속성·최적 부분 구조가 증명되면 탐욕으로 가볍게 최적, 조건이 없으면 항상 최적인 DP(013), 최적이 불필요·NP-난해면 탐욕 기반 근사(078)를 택하는 조건부 선택이 유효함
- 향후 방향: 대규모 실시간 스케줄링·라우팅에서 탐욕 휴리스틱과 학습 기반 정책을 결합해 빠른 준최적 의사결정을 자동화하는 방향으로 확장되고 있음
