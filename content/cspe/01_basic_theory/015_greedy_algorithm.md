## 미리 알고가기

- 국소 최적해: 현재 단계의 기준에서 가장 유리한 선택임
- 전역 최적해: 전체 문제를 고려한 최종 최적 결과임
- 탐욕적 선택 속성: 현재 선택을 포함하는 전역 최적해가 존재하는 성질임
- 최적 부분 구조: 부분 문제의 최적해가 전체 최적해 구성에 쓰이는 성질임
- 교환 논증: 선택을 바꿔도 더 나빠지지 않음을 보여 탐욕 선택의 정당성을 증명하는 방식임

## Ⅰ. 개요

- **정의/개념**: 탐욕 알고리즘은 매 단계에서 현재 기준의 최선 후보를 선택하고 이전 선택을 되돌리지 않는 설계 기법임
- **배경/필요성**: 전체 후보 탐색이나 상태 저장 비용이 큰 문제에서는 선택 기준을 단순화하되 최적성 보장 여부를 검증해야 함

## Ⅱ. 특징

- 선택을 확정한 뒤 되돌리지 않아 상태 관리 비용이 작음
- 후보 정렬, 힙, 방문 집합 같은 선택 비용은 별도로 발생함
- 탐욕적 선택 속성이 증명되면 전역 최적해를 보장함
- 증명이 없으면 반례와 해 품질 지표로 휴리스틱 여부를 판단함

## Ⅲ. 종류 및 비교

| 판단 기준 | 탐욕 알고리즘 (Greedy) | 동적 프로그래밍 (DP) | 완전 탐색 (Brute-force) |
|:---|:---|:---|:---|
| 선택 논리 | 현재 최선 선택을 확정 | 상태 전이를 저장·비교 | 모든 후보를 열거 |
| 되돌림 | 없음 | 상태 재사용으로 우회 | 필요 없음 |
| 비용 구조 | 후보 관리 비용 중심 | 상태 수와 전이 비용 중심 | 후보 수 증가에 비례 |
| 정확성 조건 | 선택 속성 증명 | 점화식 검증 | 모든 후보 확인 |
| 대표 사례 | 허프만 코딩, 다익스트라, 프림 | 배낭 문제, 편집 거리 | 순열, 조합 전수 검사 |

> 요약: 탐욕적 선택의 정당성이 증명되면 탐욕법을 쓰고, 되돌림이 필요하거나 상태 의존성이 크면 DP나 완전 탐색으로 검증함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 후보 집합 | 현재 단계에서 선택 가능한 항목 모음임 |
| 선택 규칙 | 비용·이익·거리 같은 기준으로 최선 후보를 고름 |
| 타당성 검사 | 선택 후보가 제약을 위반하는지 확인함 |
| 부분해 | 채택된 선택을 누적해 결과를 구성함 |
| 남은 문제 | 선택 이후 후보와 제약 상태를 다시 정의함 |

```text
[ 탐욕 구조 ]
Candidate -> Select Best -> Feasible? -> Accept -> Update Remaining
                                |
                                v
                              Reject
```

> 요약: 탐욕법은 선택 규칙과 타당성 검사가 맞아야 되돌림 없이 해를 누적함.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------------+     +----------------+     +----------------+     +----------------+
| 선택 기준 정의 | --> | 후보 우선순위화 | --> | 타당성 검사    | --> | 부분해 갱신   |
+----------------+     +----------------+     +----------------+     +----------------+
```

1. **선택 기준 정의**: 비교할 비용·이익·거리 기준을 정함
2. **후보 우선순위화**: 정렬, 힙, 스캔으로 후보를 관리함
3. **타당성 검사**: 선택 후보가 문제 제약을 위반하는지 확인함
4. **부분해 갱신**: 통과한 후보를 확정하고 남은 문제를 갱신함

> 요약: 탐욕법은 후보를 고르는 기준뿐 아니라 선택 후 남은 문제가 같은 구조로 유지되는지까지 확인해야 함.

## Ⅵ. 실무 적용 및 유의점

1. 거스름돈처럼 선택 기준이 깨질 수 있는 문제는 작은 반례와 교환 논증으로 전역 최적해 보장 여부를 확인함
2. 스케줄링·배차에서 휴리스틱으로 쓰면 벤치마크 대비 gap, 제약 위반률, 계산 시간으로 해 품질을 관리함

## Ⅶ. 결론

- 탐욕 알고리즘은 선택 속성이 증명되면 정확 알고리즘으로, 증명하기 어렵다면 반례와 품질 지표로 통제하는 휴리스틱으로 써야 함

## 작성 근거(검토용)

- **개요 구성**: 탐욕법의 핵심은 현재 선택 확정과 되돌림 없음이므로 정의에 직접 배치함
- **Ⅱ. 특징 선정**: 상태 비용, 후보 관리 비용, 최적성 증명, 휴리스틱 통제는 탐욕법의 장단점을 가르는 요소임
- **Ⅲ 비교축 선정**: DP·완전 탐색과의 차이는 되돌림, 비용 구조, 정확성 조건에서 명확히 드러남
- **Ⅳ 구조 선정**: 후보, 선택 규칙, 타당성, 부분해, 남은 문제는 탐욕 반복의 필수 상태라 남김
- **Ⅵ 적용 선정**: 반례 검증과 gap 관리는 탐욕법을 정확 알고리즘과 휴리스틱으로 구분하는 실무 기준임
