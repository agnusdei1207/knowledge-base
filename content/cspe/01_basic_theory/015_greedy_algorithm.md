## Ⅰ. 개요
- **정의**: 각 단계에서 지역 최적해를 선택하여 전체 최적해를 구하는 알고리즘 설계 기법
- **배경/필요성**: 모든 경우를 탐색하면 지수 시간이 소요되므로, 탐욕 선택 속성이 보장되는 문제에서 빠른 풀이가 필요함
- **비유**: 거스름돈을 줄 때 가장 큰 동전부터 먼저 사용하는 것

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 탐욕 적용 조건과 DP와의 비교 | 탐욕 선택 속성 + 최적 부분 구조 | 탐욕이 최적해를 보장하지 않는 반례(0-1 배낭) 명시 |

> 요약: 탐욕 선택 속성과 최적 부분 구조가 성립할 때 지역 최적 선택만으로 전체 최적해를 구함

## Ⅱ. 구성요소
```text
  +---------------------+
  |  Greedy Algorithm    |
  +---------+-----------+
            |
    +-------+-------+
    |               |
    v               v
  탐욕 선택 속성   최적 부분 구조
  (지역 최적)     (부분 최적 -> 전체 최적)
        |
        v
  대표 적용: MST(012), 허프만(032), 분수 배낭
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 탐욕 선택 속성 | 현재 단계의 지역 최적 선택이 이후 선택에 영향을 주지 않고 전체 최적에 포함됨 | 가장 큰 동전을 먼저 써도 나중 거스름돈에 지장이 없는 화폐 체계 |
| 최적 부분 구조 | 전체 최적해가 부분 문제의 최적해를 포함함 | 최단 경로의 부분 경로도 최단인 성질 (011 참조) |
| 선택-제외 판단 | 선택한 원소를 포함한 부분 문제로 축소하고 되돌리지 않음 | 뷔페에서 접시에 담으면 돌려놓지 않는 것 |

> 요약: 탐욕 선택 속성과 최적 부분 구조가 정당성의 두 기둥이며, 선택은 되돌리지 않음

## Ⅲ. 절차
```text
  후보 정렬        탐욕 선택        적합성 검사      해 구성
  (기준 설정)     (지역 최적)     (제약 충족?)     (해 집합 갱신)
   |               |               |               |
   +---기준순----->+---최적 pick-->+---제약 확인--->+
  가치/무게순     상위 후보 선택  조건 만족 여부   해에 추가/제외
```
- 1단계: 후보 원소를 탐욕 기준(가치, 가중치 등)에 따라 정렬함
- 2단계: 정렬된 후보 중 현재 기준에서 최적인 원소를 선택함
- 3단계: 선택한 원소가 제약 조건을 충족하는지 검사함
- 4단계: 충족 시 해 집합에 추가하고, 미충족 시 제외한 뒤 다음 후보로 진행함

> 요약: 후보 정렬 후 지역 최적 선택-적합성 검사-해 갱신을 반복하는 4단계 절차임

## Ⅳ. 문제점
- 최적해 미보장: 탐욕 선택 속성이 성립하지 않는 문제(0-1 배낭 등)에서는 전체 최적해를 얻지 못함
- 정당성 증명 부담: 탐욕이 최적임을 증명(교환 논증, 귀류법)하는 과정이 문제마다 다르고 복잡함
- 되돌림 불가: 한번 선택한 원소를 변경할 수 없어 잘못된 지역 선택이 누적됨

> 요약: 최적해 미보장, 정당성 증명 어려움, 되돌림 불가가 주요 한계임

## Ⅴ. 개선방안
1. 단기: 탐욕 적용 전 탐욕 선택 속성 성립 여부를 교환 논증으로 사전 검증함
2. 중기: 탐욕이 부적합한 문제는 DP(013)로 전환하여 전체 최적해를 보장함
3. 장기: 매트로이드 이론 등 탐욕 적용 가능 문제군을 체계적으로 분류하여 오용을 방지함

> 요약: 사전 검증, DP 전환, 매트로이드 기반 분류로 한계를 극복함

## Ⅵ. 전망
- 발전 방향: 근사 알고리즘 설계에서 탐욕 기법이 근사 비율 보장의 기반으로 활용됨
- 기술사적 판단: 탐욕 vs DP(013) vs 분할 정복(014)의 적용 조건 비교가 출제 빈출 주제임
- 기술사 제언: 탐욕 선택 속성의 증명 패턴(교환 논증)을 숙지하고, 적용 불가 사례를 함께 준비할 것을 권고함
