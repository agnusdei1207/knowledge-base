# 탐욕 알고리즘 (Greedy Algorithm)

## 1. 개요

- **정의/개념**: 탐욕 알고리즘은 매 단계에서 현재 기준으로 가장 유리한 선택을 확정해 전체 해를 구성하는 알고리즘 설계 기법이다.
- **배경/필요성**: 완전탐색이나 동적 프로그래밍은 후보·상태 수가 커질 수 있으므로, 선택의 정당성이 보장되는 문제에서는 낮은 비용으로 해를 구성할 방법이 필요하다.

탐욕 알고리즘은 빠르지만, 국소 최적 선택이 전역 최적을 보장한다는 근거가 있어야 한다.

## 2. 특징 및 비교

| 구분 | 탐욕 알고리즘 | 동적 프로그래밍 | 완전탐색 |
|---|---|---|---|
| 선택 방식 | 매 단계 선택 확정 | 여러 상태 비교 | 모든 후보 확인 |
| 비용 | 대체로 낮음 | 상태 수에 비례 | 지수적 가능 |
| 필요 조건 | 탐욕 선택 속성, 최적 부분 구조 | 중복 부분 문제 | 정답 보장 |
| 대표 예 | MST, 허프만 코딩, 활동 선택 | 배낭, LCS | 순열·조합 탐색 |

탐욕은 한 번 선택한 결정을 되돌리지 않으므로 선택 기준의 정당성 검증이 핵심이다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| 후보 집합 | 선택 가능한 원소들 | 정렬·우선순위화 |
| 선택 기준 | 현재 가장 유리한 원소를 고르는 규칙 | 목표 함수와 일치 |
| 제약 조건 | 선택이 유효한지 판단 | 사이클, 용량, 시간 |
| 해 구성 | 선택 원소를 누적 | 되돌림 없음 |
| 정당성 증명 | 국소 선택이 전역 최적에 포함됨을 보임 | 교환 논증, 컷 속성 |

```text
후보 정렬/우선순위화 -> 최선 후보 선택 -> 제약 검증 -> 해에 추가 -> 반복
```

## 4. 문제점 및 개선방안

1. **국소 최적의 함정**
   - 현재 최선 선택이 이후 선택 가능성을 줄여 전역 최적을 놓칠 수 있다.
   - **개선방안**: 작은 입력 완전탐색 결과와 비교하고 반례를 검증한다.

2. **선택 기준 오정의**
   - 정렬 키나 우선순위가 목표 함수와 맞지 않으면 잘못된 해를 만든다.
   - **개선방안**: 교환 논증, 컷 속성, 최적 부분 구조를 통해 선택 기준을 검증한다.

3. **근사 해와 최적 해 혼동**
   - 일부 탐욕 알고리즘은 최적이 아니라 근사 보장만 제공한다.
   - **개선방안**: 최적 보장 여부와 근사비를 명확히 구분한다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| 네트워크 설계 | MST에서 최소 간선을 반복 선택 | 총 연결 비용 |
| 압축 | 허프만 코딩에서 빈도 낮은 심볼부터 병합 | 평균 코드 길이 |
| 스케줄링 | 종료 시간이 빠른 작업 우선 선택 | 처리 작업 수, 반례 여부 |

## 6. 결론

탐욕 알고리즘은 빠르고 단순하지만 적용 조건이 엄격하다. 정확성은 시간복잡도보다 탐욕 선택 속성, 최적 부분 구조, 반례 검증으로 설명되어야 한다.
