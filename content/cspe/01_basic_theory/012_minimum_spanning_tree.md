## 미리 알고가기

- 신장 트리: 모든 정점을 사이클 없이 연결한 부분 그래프임
- 컷: 그래프를 둘로 나누는 경계이며, 이 경계를 가르는 간선 중 어떤 것을 선택할지 판단할 때 기준이 됨
- Union-Find: 집합 병합과 사이클 판별을 빠르게 처리하는 자료구조임
- 최소 신장 트리(MST, Minimum Spanning Tree): 모든 정점을 가장 적은 총 간선 비용으로 연결한 신장 트리임

## Ⅰ. 개요

- **정의/개념**: 최소 신장 트리는 무방향 가중치 그래프에서 모든 정점을 끊김 없이 연결하되, 선택한 간선들의 총 비용이 가장 작아지도록 만든 트리임. 경로 하나를 짧게 만드는 문제가 아니라 전체 연결 비용을 가장 작게 만드는 문제가 핵심임
- **배경/필요성**: 통신망, 전력망, 도로망처럼 여러 지점을 모두 이어야 하는 구조에서는 연결 자체도 중요하지만 총 구축비를 함께 낮춰야 하므로 최소 신장 트리 계산이 필요함

## Ⅱ. 특징

- 최소 신장 트리는 간선 수를 $V-1$개로 제한해 불필요한 순환 비용을 제거하면서 전체 연결을 유지함
- 컷을 가르는 간선 중 비용이 가장 낮은 간선을 우선 고려하는 성질을 바탕으로 전체 비용을 줄여 감
- 어떤 간선이 싸더라도 사이클을 만들면 채택할 수 없으므로, 비용 판단과 연결 조건 검사가 항상 함께 움직여야 함
- 특정 두 지점 사이의 이동 경로가 아니라 전체 망의 총 구축비가 평가 대상이므로 최단 경로와 구분해서 봐야 함

## Ⅲ. 종류 및 비교

- **크루스칼**: 전체 간선을 비용순으로 정렬한 뒤, 사이클을 만들지 않는 간선만 차례로 채택하는 방식임
- **프림**: 하나의 시작 정점에서 출발해 현재 트리 밖으로 나가는 간선 중 가장 싼 간선을 계속 붙이는 방식임

| 판단 기준 | 크루스칼 | 프림 |
|:---|:---|:---|
| 확장 단위 | 전체 간선 목록에서 가장 싼 간선을 하나씩 고름 | 현재 트리에 인접한 간선 중 가장 싼 간선을 고름 |
| 핵심 자료구조 | 간선 정렬과 Union-Find로 사이클 여부를 빠르게 판별함 | 우선순위 큐로 경계 간선을 관리하며 가장 싼 간선을 꺼냄 |
| 시간복잡도 | 시간복잡도는 보통 $O(E \log E)$이어서 간선 정렬 비용이 중심이 됨 | 인접 리스트와 힙을 쓰면 시간복잡도는 보통 $O(E \log V)$가 됨 |
| 적합한 그래프 | 간선 수가 상대적으로 적은 희소 그래프에서 다루기 편함 | 정점 주변 연결을 자주 확장하는 밀집 그래프에서 자연스럽게 동작함 |
| 운영상 장점 | 구현 구조가 단순하고 여러 컴포넌트를 한꺼번에 연결하기 쉬움 | 시작 지점에서 점진적으로 망을 확장하는 설계 상황과 잘 맞음 |

> 요약: 크루스칼은 간선 중심으로, 프림은 정점 집합 중심으로 최소 신장 트리를 확장한다는 점이 가장 큰 차이임

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 간선 저장소 | 크루스칼은 전체 간선을 비용순으로 정렬한 배열에 담아 두고, 프림은 트리 경계에 닿은 간선만 우선순위 큐에 넣어 최소 비용 간선이 항상 큐 앞에 오도록 유지함 |
| 서로소 집합(Union-Find) | 크루스칼에서 간선 양 끝 정점이 이미 같은 트리에 속하는지 판별해 사이클을 만들 간선을 미리 걸러냄 |
| 트리 정점 방문 배열 | 프림에서 현재 트리에 포함된 정점을 표시해 큐에서 꺼낸 간선이 실제 경계 간선인지 확인함 |
| MST 간선 집합 | 두 방식이 공통으로 채택한 간선을 누적하는 결과 저장소이며, 간선 수가 $V-1$에 도달하면 트리가 완성됨 |

```text
크루스칼 구조                          프림 구조
+------------------+                 +------------------+
| 간선 정렬 배열    |                 | 트리 정점 방문     |
+------------------+                 | 배열              |
         |                           +------------------+
         v                                    |
+------------------+                          v
| Union-Find 판별   |                 +------------------+
+------------------+                 | 경계 간선 우선순위 |
         |                           | 큐                |
         |                           +------------------+
         |                                    |
         +-----------------+------------------+
                            v
                   +------------------+
                   | MST 간선 집합     |
                   | (V-1개 도달 시 종료)|
                   +------------------+
```

> 요약: 크루스칼은 정렬 배열과 Union-Find로, 프림은 방문 배열과 우선순위 큐로 각자 후보 간선을 걸러 같은 MST 간선 집합에 모은다는 구조임

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +------------+     +-------------+     +----------+
| 초기화   | ---> | 후보 간선   | ---> | 사이클/경계  | ---> | 간선 채택 |
+----------+     | 선택        |     | 검증         |     +----------+
                  +------------+     +-------------+           |
                       ^                                        v
                       |                              +------------------+
                       +------------------------------| V-1개 도달?       |
                                                        | 아니오: 2단계 반복 |
                                                        | 예: 종료          |
                                                        +------------------+
```

1. **초기화**: 크루스칼은 간선을 비용순으로 정렬하고 Union-Find를 정점 개수만큼 초기화하며, 프림은 시작 정점 하나를 트리에 넣고 그 인접 간선을 큐에 넣음
2. **후보 간선 선택**: 크루스칼은 정렬 배열에서 다음으로 싼 간선을 꺼내고, 프림은 우선순위 큐에서 최소 비용 간선을 꺼냄
3. **사이클/경계 검증**: 크루스칼은 Union-Find로 간선 양 끝 정점이 이미 연결됐는지 확인하고, 프림은 꺼낸 간선의 반대쪽 정점이 이미 트리에 포함됐는지 확인함
4. **간선 채택**: 검증을 통과한 간선만 MST 간선 집합에 추가하며, 크루스칼은 두 정점의 집합을 합치고 프림은 새 정점을 트리에 넣어 그 정점의 인접 간선을 큐에 추가함
5. **종료 판정**: 채택된 간선이 $V-1$개에 도달하면 종료하고, 미달이면 2단계로 돌아가 후보 간선 선택을 반복함

## Ⅵ. 실무 적용 및 유의점

1. 통신망처럼 간선 수가 적은 희소 그래프는 크루스칼이 잘 맞지만 간선이 많아지면 정렬 비용이 커지므로 간선 수 대비 정점 수 비율을 먼저 보고 밀집도가 높아지면 프림으로 바꾸고 정렬 시간과 총 간선 수로 확인함
2. 전력망처럼 인접 간선이 많은 밀집 그래프에서는 프림이 유리하지만 그래프가 여러 컴포넌트로 끊겨 있으면 일부만 연결될 수 있으므로 컴포넌트별로 반복 실행하거나 크루스칼로 바꾸고 최종 채택 간선 수가 $V-1$인지로 확인함

## Ⅶ. 결론

최소 신장 트리를 구현할 때는 그래프의 간선 밀도를 기준으로 희소 그래프면 간선 정렬과 Union-Find 중심의 크루스칼을, 밀집 그래프면 우선순위 큐 중심의 프림을 선택하는 것이 기술사적 판단임.
