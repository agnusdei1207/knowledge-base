## 미리 알고가기

- 신장 트리: 그래프의 모든 노드를 사이클 없이 연결한 트리임
- 최소 신장 트리(MST): 신장 트리 중 선택한 간선의 가중치 합이 가장 작은 트리임
- 무방향 연결 그래프: MST가 존재하려면 그래프 전체가 간선으로 연결되어야 함
- 노드 수 $V$: 그래프의 노드 개수이며 신장 트리는 $V-1$개 간선으로 구성됨
- 서로소 집합(Union-Find): 겹치지 않는 집합을 관리해 두 노드의 연결 여부를 식별하는 구조임
- 우선순위 큐: 가중치가 가장 작은 후보 간선을 먼저 꺼내는 저장 구조임
- 컷 속성: 두 노드 집합을 잇는 최소 가중치 간선이 MST에 들어갈 수 있는 안전한 선택이라는 성질임
- 크루스칼: 전체 간선을 가중치 순으로 검사하며 서로 다른 연결 영역을 합치는 알고리즘임
- 프림: 현재 트리와 외부 노드를 잇는 최소 간선을 선택해 트리를 확장하는 알고리즘임

## 작성 근거(검토용)

- **개요 구성**: MST의 본질은 모든 노드 연결과 총비용 최소화라 정의와 필요성을 이 축으로 정리함
- **Ⅱ. 특징 선정**: $V-1$개 간선·사이클 제외·탐욕 선택·최단 경로와의 차이는 MST 오적용을 방지하는 핵심 기준임
- **Ⅲ. 비교축 선정**: 간선 선택, 사이클 통제, 주요 처리 비용은 두 알고리즘의 동작·정합성·성능 차이를 각각 보여줌
- **Ⅳ. 구조 선정**: 간선 후보, 최소 간선 선택, 사이클 검사, 결과 트리는 두 알고리즘의 공통 구조라 표로 남김
- 서버 간선 목록과 기존 클러스터 증설은 크루스칼·프림의 후보 관리 차이를 보여주므로 사례로 남김

## Ⅰ. 개요

- **정의/개념**: 최소 신장 트리는 무방향 연결 가중 그래프의 모든 노드를 사이클 없이 이은 트리 중 가중치 합이 가장 작은 트리임
- **배경/필요성**: 통신·전력·도로망 설치 비용 최소화를 위해 모든 노드를 잇는 연결 기준이 필요함

## Ⅱ. 특징

- 노드가 $V$개이면 MST의 선택 간선 수는 항상 $V-1$개임
- 새 간선이 사이클을 만들면 전체 연결에는 불필요하므로 제외 대상이 됨
- 크루스칼과 프림은 모두 탐욕 선택을 쓰며 컷 속성으로 선택 정당성을 설명함
- 최단 경로는 두 노드 간 거리, MST는 전체 연결 비용을 최소화함

## Ⅲ. 종류 및 비교

| 판단 기준 | 크루스칼 (Kruskal) | 프림 (Prim) |
|:---|:---|:---|
| 간선 선택 | 가중치 오름차순의 전역 최소 간선 | 현재 트리 경계의 최소 간선 |
| 사이클 통제 | Union-Find로 같은 집합을 잇는 간선 제외 | 방문 집합으로 트리 내부 간선 제외 |
| 주요 처리 비용 | 전체 간선 정렬 $O(E \log E)$ | 우선순위 큐 갱신 $O(E \log V)$ |

> 요약: 전체 간선을 정렬해 고르면 크루스칼, 현재 트리 밖으로 확장하면 프림임.

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 간선 후보 | 전체 간선 또는 현재 트리 경계의 간선 집합 |
| 최소 간선 선택 | 정렬 목록 또는 우선순위 큐에서 가중치가 가장 작은 간선을 꺼내는 연산 |
| 연결 상태 | 서로 다른 연결 성분 또는 트리 밖 정점을 잇는 간선만 채택하기 위한 정보 |
| 결과 트리 | 선택한 $V-1$개 간선으로 구성한 트리 |

> 요약: MST는 서로 다른 연결 영역의 최소 간선을 $V-1$개 선택해 모든 노드를 잇는 최소 비용 트리를 구성함.

## Ⅴ. 원리 및 절차 흐름도

```text
간선 후보 초기화 → 최소 간선 선택 → 연결 상태 판정
                                    ├─ 다른 영역 연결 → 결과 트리에 추가
                                    └─ 사이클 형성 → 제외
                                                  ↓
                                           $V-1$개까지 반복
```

1. **후보 초기화**: 크루스칼은 전체 간선, 프림은 시작 노드의 인접 간선을 후보로 둠
2. **최소 간선 선택**: 현재 기준에서 비용이 가장 작은 간선을 고름
3. **채택 조건 확인**: 사이클을 만들면 제외하고 서로 다른 연결 영역을 이으면 채택함
4. **누적 및 종료**: 선택 간선 수가 $V-1$개가 될 때까지 반복함

> 요약: 최소 간선이 서로 다른 연결 영역을 이을 때 결과 트리에 누적함.

## Ⅵ. 실무 사례

1. 서버 연결 후보가 간선 목록이면 크루스칼로 사이클 없는 최소 비용 연결을 구성함
2. 기존 클러스터 증설은 프림으로 현재 구성과 가까운 노드를 하나씩 연결함

## Ⅶ. 결론

- 최소 신장 트리는 모든 정점을 최소 비용으로 연결하며, 간선 중심은 크루스칼, 정점 확장 중심은 프림이 적합함
- MST는 최소 연결 비용만 보장하므로 고가용성 시스템에서는 기본 연결로 사용하되 장애 우회 경로를 별도로 설계해야 함
