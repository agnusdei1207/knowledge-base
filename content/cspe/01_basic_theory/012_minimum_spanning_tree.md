## 미리 알고가기

- 신장 트리: 그래프의 모든 정점을 포함하면서 사이클이 없는 연결 부분 그래프임
- 최소 비용: 선택된 간선 가중치 합이 가능한 신장 트리 중 가장 작은 상태임
- 무방향 연결 그래프: MST가 정의되기 위한 기본 그래프 조건임
- 컷 속성: 어떤 컷을 가로지르는 최소 가중치 간선은 MST 후보가 될 수 있다는 성질임
- 서로소 집합: 크루스칼 알고리즘에서 사이클 발생 여부를 빠르게 판단하는 자료구조임

## Ⅰ. 개요

최소 신장 트리(MST)는 가중 무방향 연결 그래프에서 모든 정점을 연결하되 사이클 없이 간선 가중치 합이 최소가 되는 간선 집합임. 네트워크 회선 구축, 전력망 연결, 군집화처럼 전체 연결성은 필요하지만 중복 연결 비용은 줄여야 하는 문제에서 사용함.

MST는 두 정점 사이의 최단 경로를 보장하는 구조가 아니라 전체 연결 비용을 최소화하는 구조임. 따라서 경로 최적화 문제와 구분하고, 그래프가 연결되어 있는지와 간선 가중치 조건을 먼저 확인해야 함.

비유: 모든 건물을 한 번 이상 연결하는 통신선을 깔되, 순환 회선을 만들지 않고 총 공사비가 가장 낮은 배선을 고르는 것과 같음.

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 그래프 최적화 구조 이해 확인 | 신장 트리, 사이클 제거, 가중치 합, 크루스칼/프림 | 최단 경로와 혼동, 방향 그래프 적용 |

> 요약: MST는 모든 정점을 연결하는 최소 비용 간선 집합이며, 전체 연결 비용 최적화가 목적임.

## Ⅱ. 특징/비교

| 판단 기준 | 크루스칼 알고리즘 | 프림 알고리즘 | 선택 기준 |
|:---|:---|:---|:---|
| 접근 방식 | 간선을 가중치 오름차순으로 선택 | 한 정점에서 트리를 확장 | 간선 정렬과 인접 탐색 비용 비교 |
| 사이클 방지 | 서로소 집합으로 판정 | 방문 집합 밖의 최소 간선 선택 | 구현 자료구조가 다름 |
| 적합 그래프 | 희소 그래프에 유리 | 조밀 그래프 또는 인접 구조에 유리 | `E`, `V` 규모에 따라 선택 |
| 대표 복잡도 | 정렬 포함 `O(E log E)` | 힙 사용 시 `O(E log V)` | 표현 방식에 따라 달라짐 |
| 산출물 | 선택 간선 목록 | 확장된 트리 간선 목록 | 둘 다 MST 비용과 간선 제공 |

> 요약: MST 알고리즘 선택은 전체 간선 정렬이 쉬운지, 인접 간선으로 트리를 확장하는 것이 쉬운지에 따라 달라짐.

- 간선 가중치가 모두 다르면 MST는 유일하지만, 동일 가중치가 있으면 여러 MST가 존재할 수 있음
- MST는 음수 가중치를 포함해도 정의될 수 있으나 연결성과 무방향 조건이 중요함
- 방향 그래프의 유사 문제는 최소 신장 수목처럼 별도 알고리즘으로 다뤄야 함

## Ⅲ. 구성요소

```text
+----------+      +----------+      +----------+
| 가중그래프| ---> | 간선선택 | ---> | MST      |
+----------+      +----------+      +----------+
      |                 |                 |
      v                 v                 v
+----------+      +----------+      +----------+
| 정점집합 |      | 사이클검사|     | 비용합계 |
+----------+      +----------+      +----------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 정점 집합 | 반드시 모두 연결해야 하는 대상 노드 전체임 | 건물 목록 |
| 가중 간선 | 정점 사이의 연결 후보이며 비용, 거리, 위험도 등을 포함함 | 공사 가능한 선로 |
| 선택 규칙 | 최소 비용 간선을 고르되 트리 조건을 유지하는 판단 기준임 | 최저가 입찰 선택 |
| 사이클 검사 | 이미 연결된 정점끼리 다시 연결하지 않도록 확인하는 과정임 | 중복 배선 방지 |
| 비용 합계 | 선택된 간선 가중치의 총합이며 MST 최적성 판단값임 | 총 공사비 |

> 요약: MST는 가중 간선 후보 중 사이클을 만들지 않는 최소 비용 간선을 골라 전체 정점을 연결하는 구조임.

- MST는 정점 수가 `V`이면 항상 `V-1`개의 간선을 선택해야 함
- 크루스칼은 간선 중심, 프림은 정점 집합 확장 중심으로 구성요소의 흐름이 다름
- 연결되지 않은 그래프에서는 MST가 아니라 최소 신장 포리스트가 만들어짐

## Ⅳ. 절차

```text
+----------+      +----------+      +----------+      +----------+
| 조건확인 | ---> | 후보선택 | ---> | 사이클검사| ---> | 트리완성 |
+----------+      +----------+      +----------+      +----------+
      |                 |                 |                 |
      v                 v                 v                 v
+----------+      +----------+      +----------+      +----------+
| 연결/무방향|    | 최소간선 |      | 포함/제외|      | V-1간선 |
+----------+      +----------+      +----------+      +----------+
```

1. **입력/요구 식별** - 그래프가 무방향 연결 그래프인지, 가중치 의미와 정점·간선 규모를 확인함
2. **알고리즘 선택** - 희소 그래프와 간선 목록 중심이면 크루스칼, 인접 구조 중심이면 프림을 선택함
3. **간선 선택과 검증** - 최소 가중치 간선을 후보로 고르고 사이클 여부 또는 방문 집합 조건을 검사함
4. **출력/효과 확인** - `V-1`개 간선이 선택되면 비용 합계와 선택 간선 목록을 반환함

> 요약: MST 절차는 그래프 조건을 확인하고 최소 간선을 반복 선택하되 사이클을 막아 전체 연결을 완성하는 흐름임.

- 크루스칼은 간선 정렬 후 union-find로 서로 다른 컴포넌트만 연결함
- 프림은 현재 트리와 바깥 정점을 잇는 최소 간선을 우선순위 큐로 선택함
- 산출물 검증은 간선 수, 연결성, 사이클 부재, 비용 합계를 함께 확인해야 함

## Ⅴ. 문제점

- **P1 그래프 조건 불일치**: 연결되지 않은 그래프나 방향 그래프에 일반 MST를 적용하면 모든 정점을 하나의 트리로 연결할 수 없음
- **P2 동일 가중치에 따른 결과 다양성**: 같은 최소 비용을 갖는 MST가 여러 개면 실행 순서나 정렬 안정성에 따라 선택 간선이 달라질 수 있음
- **P3 동적 변경 대응 어려움**: 간선 비용이나 연결 상태가 자주 바뀌면 매번 MST를 다시 계산하는 비용이 커질 수 있음

> 요약: MST 적용 문제는 그래프 전제, 동률 처리, 변경 빈도에서 주로 발생함.

## Ⅵ. 개선방안

- **P1 대응**: 실행 전 연결성, 무방향성, 가중치 존재를 검증하고 비연결 그래프는 최소 신장 포리스트로 처리함 (확인: 컴포넌트 수)
- **P2 대응**: 동률 간선의 우선순위 규칙을 명시하고 결과 검증은 간선 목록보다 총 비용과 트리 조건 중심으로 수행함 (확인: 동률 테스트)
- **P3 대응**: 변경 빈도에 따라 동적 MST 알고리즘, 부분 재계산, 배치 갱신 전략을 적용함 (확인: 갱신당 계산 시간)

> 요약: MST 개선은 입력 전제를 검증하고, 동률과 동적 변경을 운영 규칙으로 통제하는 방향이 필요함.

## Ⅶ. 전망

- **향후 발전 방향**: 네트워크 설계, 클러스터링, 회로 배선에서는 MST를 기반으로 제약 조건을 추가한 변형 최적화가 계속 활용됨
- **기술사적 판단**: MST는 최단 경로가 아니라 전체 연결 비용 최적화 문제임을 명확히 하고 크루스칼·프림 선택 근거를 제시해야 함
- **기술사 제언**: 답안에서는 `정점 전체 연결`, `간선 수 V-1`, `사이클 없음`, `가중치 합 최소` 네 조건을 함께 적어야 감점을 줄일 수 있음

> 요약: MST는 연결 비용 최적화의 기본 모델이며, 그래프 전제와 알고리즘 선택 기준을 분리해 설명해야 함.
