## 미리 알고가기

- 신장 트리: 모든 정점을 연결하고 사이클이 없는 부분 그래프임
- 최소 신장 트리(MST): 신장 트리 중 선택 간선 가중치 합이 최소인 트리임
- 무방향 연결 그래프: MST가 존재하려면 모든 정점이 간선으로 이어져야 함
- Union-Find: 서로소 집합을 관리해 두 정점이 이미 연결됐는지 확인하는 구조임
- 컷 속성: 두 정점 집합 사이의 최소 가중치 간선은 MST 후보가 될 수 있다는 성질임

## Ⅰ. 개요

- **정의/개념**: 최소 신장 트리는 무방향 연결 가중치 그래프에서 모든 정점을 사이클 없이 연결하는 최소 비용 부분 트리임
- **배경/필요성**: 통신망·전력망·도로망 설계는 모든 지점을 연결하면서 중복 간선 비용을 줄이는 기준이 필요함

## Ⅱ. 특징

- 정점이 $V$개이면 MST의 선택 간선 수는 항상 $V-1$개임
- 사이클을 만들면 연결성은 유지되지만 총 비용만 늘어 제거 대상이 됨
- 크루스칼과 프림은 모두 탐욕 선택을 쓰며 컷 속성으로 안전성을 설명함
- 최단 경로는 두 지점 간 거리, MST는 전체 연결 비용을 최소화함

## Ⅲ. 종류 및 비교

| 판단 기준 | 크루스칼 (Kruskal) | 프림 (Prim) |
|:---|:---|:---|
| 처리 전략 | 전체 간선을 가중치 순으로 선택 | 현재 트리에서 외부 정점으로 확장 |
| 핵심 구조 | 간선 정렬, Union-Find | 우선순위 큐, 방문 배열 |
| 사이클 통제 | 같은 집합이면 제외 | 방문 정점으로 돌아가면 제외 |
| 시간복잡도 | $O(E \log E)$ | $O(E \log V)$ |
| 적합 조건 | 간선 목록 기반 희소 그래프 | 인접 후보 관리가 쉬운 그래프 |

> 요약: 전체 간선을 정렬해 고르면 크루스칼, 현재 트리 밖으로 확장하면 프림임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 간선 후보 | 비용이 붙은 연결 후보이며 선택 대상의 전체 집합임 |
| 최소 선택기 | 정렬 목록이나 우선순위 큐로 가장 작은 간선을 고름 |
| 사이클 검사기 | 새 간선이 이미 연결된 정점을 다시 잇는지 확인함 |
| 결과 트리 | 선택된 $V-1$개 간선을 저장해 최종 망 구조를 형성함 |

```text
[ MST 구조 ]
Weighted Edges -> Minimum Selector -> Cycle Check -> Result Tree
                                           |
                                           v
                                    Stop at V-1 edges
```

> 요약: MST는 최소 간선 선택과 사이클 통제가 함께 있어야 전체 연결 비용을 줄임.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------------+     +----------------+     +----------------+     +----------------+
| 후보 초기화    | --> | 최소 간선 선택 | --> | 안전성 검증    | --> | 결과 트리 누적 |
+----------------+     +----------------+     +----------------+     +----------------+
```

1. **후보 초기화**: 크루스칼은 전체 간선, 프림은 시작 정점의 인접 간선을 후보로 둠
2. **최소 간선 선택**: 현재 기준에서 비용이 가장 작은 간선을 고름
3. **안전성 검증**: 사이클을 만들면 버리고, 새 정점을 연결하면 채택함
4. **누적 및 종료**: 선택 간선 수가 $V-1$개가 될 때까지 반복함

> 요약: 최소 간선은 컷 속성으로 안전성을 확인한 뒤 결과 트리에 누적함.

## Ⅵ. 실무 적용 및 유의점

1. 회선 구축은 MST로 총 설치비를 줄이되 장애 우회가 필요하면 여분 경로를 별도 설계하고 총 비용과 단절 위험으로 검증함
2. 간선 목록이 작으면 크루스칼을 우선 검토하고, 간선 수·정렬 시간·Union-Find 호출 수로 적합성을 확인함

## Ⅶ. 결론

- 최소 신장 트리는 전체 연결 비용 최소화 문제이므로 최단 경로와 구분하고 그래프 표현에 맞춰 크루스칼·프림을 선택해야 함

## 작성 근거(검토용)

- **개요 구성**: MST의 본질은 모든 정점 연결과 총 비용 최소화라 정의와 필요성을 이 축으로 압축함
- **Ⅱ. 특징 선정**: $V-1$개 간선, 사이클 제거, 탐욕 선택, 최단 경로와의 차이는 MST 오적용을 막는 핵심임
- **Ⅲ 비교축 선정**: 처리 전략, 자료구조, 사이클 통제, 복잡도, 적합 조건이 크루스칼·프림 선택을 직접 가름
- **Ⅳ 구조 선정**: 후보, 선택기, 검사기, 결과 트리는 두 알고리즘에 공통인 최소 구조라 표로 남김
- **Ⅵ 적용 선정**: 망 구축에서는 비용 최소화와 장애 우회 요구가 충돌하므로 실무 유의점으로 분리함
