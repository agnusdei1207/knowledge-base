# 012. 최소 신장 트리 — 크루스칼·프림 (Minimum Spanning Tree)

## 미리 알고가기

- **신장 트리 (Spanning Tree)**: 그래프의 모든 정점을 포함하면서 사이클(Cycle)이 없는 연결 부분 그래프임. 정점이 $V$개일 때 간선은 $V-1$개임
- **그리디 알고리즘 (Greedy Algorithm)**: 매 순간 최적의 선택을 하는 방식이며, MST 알고리즘인 크루스칼과 프림의 공통된 설계 철학임
- **Union-Find (서로소 집합)**: 여러 정점들이 같은 집합(덩어리)에 속해 있는지 확인하고 합치는 자료구조로, 크루스칼에서 사이클 탐지에 필수적임

## Ⅰ. 개요

- **정의/개념**: 최소 신장 트리(Minimum Spanning Tree, MST)는 무방향 가중치 그래프에서 모든 정점을 연결하는 신장 트리 중 간선 가중치의 합이 최소인 트리임
- **배경/필요성**: 통신망, 도로망, 전력망 설계 등 모든 지점을 연결해야 하는 인프라 구축 시, 중복 경로를 제거하고 전체 부설 비용을 최소화하기 위한 최적 설계 기법으로 활용됨

## Ⅱ. 특징 및 비교

두 알고리즘은 모두 탐욕적 방법을 사용하지만, '간선 중심'인지 '정점 중심'인지에 따라 자료구조와 성능 특성이 갈림.

| 비교 항목 | 크루스칼 (Kruskal) | 프림 (Prim) |
|:---|:---|:---|
| **핵심 논리** | **간선 중심**: 가중치가 작은 간선부터 선택 | **정점 중심**: 현재 트리에서 인접한 최소 간선 선택 |
| **사이클 처리** | **Union-Find** 구조로 사이클 형성 확인 | 방문 배열($Visited$)로 이미 포함된 정점 확인 |
| **자료구조** | 간선 리스트 정렬 + Union-Find | 우선순위 큐 (Heap) + 인접 리스트 |
| **시간복잡도** | $O(E \log E)$ 또는 $O(E \log V)$ | $O(E \log V)$ 또는 $O(V^2)$ |
| **유리한 그래프** | 간선이 적은 **희소 그래프 (Sparse)** | 간선이 많은 **조밀 그래프 (Dense)** |
| **동작 특징** | 여러 개의 부분 트리가 합쳐지며 완성됨 | 하나의 시작점에서 트리가 점진적으로 확장됨 |

> 요약: 간선 정렬 비용이 지배적인 환경(희소 그래프)은 크루스칼을, 정점 기준 확장이 유리한 환경(조밀 그래프)은 프림을 선택함.

## Ⅲ. 구성요소/구조

MST 알고리즘은 '최소 비용 선택'과 '사이클 방지'라는 두 가지 핵심 기제를 구조화함.

- **구성요소**:
  - **Edge Set**: 그래프를 구성하는 가중치 간선들의 집합
  - **Forest/Tree**: 탐색 과정에서 형성되는 정점들의 연결 상태
  - **Cycle Detector**: 선택한 간선이 순환 구조를 만드는지 판별하는 로직
  - **Greedy Strategy**: 현재 상태에서 가중치가 가장 작은 요소를 취하는 기준

- **알고리즘별 처리 흐름 (원리/흐름도)**:

```text
[Kruskal: Global Greedy]            [Prim: Local Greedy]
1. 모든 간선을 가중치순 정렬          1. 임의의 시작 정점 선택
2. 싼 간선부터 하나씩 검토:           2. 현재 트리와 연결된 간선 중 최소값 선택
   - if (사이클 미형성):              3. 해당 정점을 트리에 포함
       - 트리 추가 & Union            4. 모든 정점이 포함될 때까지 2~3 반복
3. V-1개의 간선 선택 시 종료
```

1. **Kruskal**: 전역적인 관점에서 가장 저렴한 간선을 먼저 고려하되, 이미 같은 컴포넌트에 속한 두 정점을 잇는 간선(사이클 유발)은 과감히 버림
2. **Prim**: 특정 시작점에서 출발하여 '트리의 영토'를 확장해 나가는 방식으로, 매 단계마다 현재 트리에서 가장 가까운 외부 정점을 포섭함

## Ⅳ. 문제점 및 개선방안

1. **크루스칼의 간선 정렬 부하**: 간선 수($E$)가 매우 많은 조밀 그래프에서는 $O(E \log E)$의 정렬 과정이 전체 성능의 병목이 됨
   - **개선방안**: 정렬 대신 최소 힙(Min-Heap)을 사용하여 필요한 만큼만 간선을 추출하거나, 정점 중심인 프림 알고리즘으로 전환함 (확인: $E$와 $V^2$의 관계 분석)

2. **단일 장애 지점 (Single Point of Failure)**: MST는 사이클이 없는 구조이므로 간선 하나만 끊겨도 네트워크 전체가 분절되는 안정성 문제가 있음
   - **개선방안**: 실무에서는 비용이 조금 늘어나더라도 MST 기반에 예비 회로(Backup Line)를 추가한 2-Edge-Connected 구조를 설계함 (확인: 네트워크 가용성 지표)

3. **비연결 그래프에서의 작동 한계**: 시작 지점에서 도달할 수 없는 정점이 있을 경우 프림은 일부만 탐색하고 종료되며, 크루스칼은 여러 개의 나무(Forest)를 생성함
   - **개선방안**: 모든 정점의 방문 여부를 체크하여 방문하지 않은 정점에 대해 알고리즘을 재수행하거나, 연결 컴포넌트(Connected Component) 분석을 선행함 (확인: 생성된 간선 수 vs $V-1$)

## Ⅴ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| 도시 기간망 설계 | 수도, 가스, 전력 선로를 최소 길이로 매설하여 구축 비용 절감 | 총 선로 길이, 공사 비용 합계 |
| 클러스터링 (ML) | 정점 간 거리를 가중치로 MST를 만든 후, 특정 임계값 이상의 비싼 간선을 제거하여 군집 분리 | 군집 내 응집도, 군집 간 분리도 |
| 네트워크 브리징 (STP) | LAN 환경에서 루프(Loop) 발생을 방지하기 위해 Spanning Tree Protocol을 사용하여 논리적 트리 구성 | 브로드캐스트 스톰 방지, 수렴 속도 |
| 회로 설계 (VLSI) | 칩 내부의 여러 소자들을 최소 배선 길이로 연결하여 신호 지연 및 생산 비용 최적화 | 배선 면적, 신호 감쇄율 |

> 요약: 모든 지점을 연결해야 하는 최소 비용 문제뿐만 아니라, 루프 방지 및 데이터 군집화의 기초 도구로 활용됨.

## Ⅵ. 결론

최소 신장 트리는 자원 배분의 효율성을 극대화하는 최적화 알고리즘의 정수임. 기술사는 단순히 크루스칼과 프림의 수식을 외우는 것을 넘어, 그래프의 밀도와 동적 변화 여부에 따라 어떤 알고리즘이 시스템 자원(CPU, Memory)을 덜 소모할지 판단할 수 있어야 함.

특히 현대의 대규모 인프라 설계에서는 효율성뿐만 아니라 '복구력(Resilience)'이 중요하므로, MST를 기본 뼈대로 하되 가용성을 고려한 중복 경로를 전략적으로 배치하는 하이브리드 설계 역량이 요구됨. 결국 MST는 '가장 저렴한 연결'을 찾는 출발점이며, 이를 비즈니스 연속성과 연결 짓는 것이 기술사적 통찰임.
