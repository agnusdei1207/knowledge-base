## 미리 알고가기

- 신장 트리: 모든 정점을 사이클 없이 연결한 부분 그래프임
- MST: 모든 정점을 가장 낮은 총 간선 비용으로 연결한 신장 트리임
- Union-Find: 정점들이 같은 집합에 속하는지 빠르게 확인하는 자료구조임
- 컷: 그래프를 두 집합으로 나누는 경계임

## Ⅰ. 개요

- **정의/개념**: 최소 신장 트리는 무방향 가중치 그래프에서 모든 정점을 연결하되, 선택한 간선의 총 비용이 가장 작아지도록 만든 트리임
- **배경/필요성**: 통신망, 전력망, 도로망은 모든 지점을 이어야 하며 구축 비용도 줄여야 함. MST는 전체 연결 비용을 최소화하는 기준을 제공함

## Ⅱ. 특징

- 모든 정점을 연결하면서 간선 수는 $V-1$개만 사용함
- 사이클을 만들지 않아 불필요한 연결 비용을 제거함
- 간선 하나의 최단 경로가 아니라 전체 망의 총 비용을 최소화함
- 간선이 적은지 많은지에 따라 크루스칼과 프림의 구현 효율이 달라짐

## Ⅲ. 종류 및 비교

| 판단 기준 | 크루스칼 | 프림 |
|:---|:---|:---|
| 확장 방식 | 싼 간선부터 고름 | 현재 트리에서 가장 싼 외부 간선을 고름 |
| 주요 자료구조 | 정렬된 간선 목록, Union-Find | 우선순위 큐, 방문 배열 |
| 사이클 처리 | Union-Find로 같은 집합 여부 확인 | 이미 트리에 있는 정점인지 확인 |
| 시간복잡도 | 보통 $O(E \log E)$ | 보통 $O(E \log V)$ |
| 적합한 그래프 | 간선이 적은 그래프 | 간선이 많은 그래프 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 정점 집합 | 모두 연결해야 하는 대상임 |
| 간선과 비용 | 연결 후보와 그 비용임 |
| 사이클 검사 | 새 간선이 순환을 만드는지 확인함 |
| MST 간선 집합 | 최종적으로 선택된 간선을 누적하는 결과임 |

```text
+-----------+     +-----------+     +-----------+
| 간선 후보 | --> | 사이클 검사 | --> | MST 포함 |
+-----------+     +-----------+     +-----------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
크루스칼: 간선 정렬 -> 싼 간선 선택 -> 사이클 검사 -> 포함
프림: 시작 정점 -> 경계 간선 선택 -> 새 정점 포함 -> 반복
```

1. 연결할 정점과 간선 비용을 준비함
2. 알고리즘 방식에 따라 다음 간선을 선택함
3. 사이클을 만들지 않으면 결과에 포함함
4. 선택 간선 수가 $V-1$개가 되면 종료함

## Ⅵ. 실무 적용 및 유의점

1. 전체 망 구축비가 목적이면 MST를 쓰고, 특정 두 지점 이동 비용이 목적이면 최단 경로 알고리즘을 써야 함
2. 간선 수가 많은 그래프에서는 우선순위 큐 기반 프림이 자연스럽고, 간선 수가 적으면 크루스칼이 단순하게 적용됨

## Ⅶ. 결론

- 최소 신장 트리는 모든 정점을 가장 낮은 총 비용으로 잇는 구조이며, 최단 경로 문제와 목적을 구분해야 함
