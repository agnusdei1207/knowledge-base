## 미리 알고가기

- 신장 트리(Spanning Tree): 그래프의 모든 정점을 포함하되 사이클이 존재하지 않는 부분 그래프임
- 최소 신장 트리(MST): 모든 정점을 연결하는 신장 트리 중 간선 가중치의 합이 최소인 트리임
- Union-Find: 서로소 집합을 관리하며, 두 정점이 같은 집합(사이클 형성 여부)에 속하는지 효율적으로 판별하는 자료구조임
- 탐욕법(Greedy): 각 단계에서 가장 최선인 선택(최소 가중치 간선)을 하여 전체 최적해를 구하는 설계 기법임

## Ⅰ. 개요

- **정의/개념**: 최소 신장 트리는 무방향 가중치 그래프에서 모든 정점을 사이클 없이 연결하는 간선들의 집합 중 전체 가중치의 합이 최소가 되도록 구성된 트리임
- **배경/필요성**: 통신망, 전력망, 도로망 구축 시 모든 지점을 연결하면서도 설치 비용을 최소화해야 하는 최적화 설계 문제에서 비용 한계를 결정짓는 표준 모델로 활용됨

## Ⅱ. 특징

- 정점의 개수가 $V$개일 때 반드시 $V-1$개의 간선만 사용하여 모든 노드를 연결함으로써 불필요한 중복 경로와 사이클을 제거함
- 그래프 내의 모든 간선 중 가중치가 가장 작은 간선들을 우선적으로 선택하되, 선택된 간선들이 폐회로를 형성하지 않도록 엄격히 통제함
- 단일 출발점 최단 경로(다익스트라)와 달리, 전체 망($Network$)의 총합 비용을 최소화하는 데 목적이 있어 망 설계의 경제성을 보장함

## Ⅲ. 종류 및 비교

| 판단 기준 | 크루스칼 (Kruskal) | 프림 (Prim) |
|:---|:---|:---|
| **처리 전략** | 가중치가 작은 간선부터 정렬 후 선택 | 현재 트리에서 가장 가까운 정점 선택 |
| **핵심 자료구조** | $Union-Find$, 간선 리스트 정렬 | 우선순위 큐, 방문 배열 |
| **사이클 판별** | 두 정점의 루트 노드 일치 여부 확인 | 방문 배열을 통한 기방문 정점 확인 |
| **시간복잡도** | $O(E \log E)$ ($E \log V$) | $O(E \log V)$ ($V^2$ 가능) |
| **최적 그래프** | 간선이 적은 희소 그래프 ($Sparse$) | 간선이 많은 밀집 그래프 ($Dense$) |

> 요약: 간선 중심의 선택은 크루스칼, 정점 확장 중심의 선택은 프림 알고리즘을 사용하여 각각 그래프 밀도에 따른 효율성을 확보함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 가중치 간선 집합 | 연결 후보가 되는 모든 간선과 각 간선에 할당된 비용(거리, 비용 등) 정보임 |
| 사이클 검사기 | 새 간선을 추가했을 때 기존 트리와 순환 고리를 형성하는지 판별하여 트리의 정의를 유지함 |
| 우선순위 큐/정렬 | 후보 간선 중 최소 비용을 가진 대상을 상수 시간에 추출하기 위한 정렬 메커니즘임 |
| 결과 트리 저장소 | 최종적으로 선택된 $V-1$개의 간선과 해당 간선으로 연결된 정점들의 정보임 |

```text
[ MST 선택 모델 ]
1. Kruskal: Edge1(Min) -> Cycle Check? -> Add -> Repeat
2. Prim: Root -> Neighbor Edges -> Min Edge Select -> New Vertex -> Repeat
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 간선/정점 초기화| --> | 최소 비용 선택 | --> | 사이클 검증   | --> | 결과 트리 누적 |
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **초기화** — (크루스칼) 모든 간선을 가중치 순으로 오름차순 정렬하거나, (프림) 임의의 시작 정점을 선정함
2. **최소 선택** — 아직 선택되지 않은 간선 중 가중치가 가장 작은 간선(크루스칼) 또는 트리에 인접한 최소 간선(프림)을 추출함
3. **사이클 검증** — 해당 간선이 연결할 두 정점이 이미 같은 컴포넌트에 속해 있는지($Union-Find$ 등) 확인하여 사이클 형성을 차단함
4. **누적 및 종료** — 사이클이 없으면 트리에 추가하고, 선택된 간선의 수가 $V-1$개에 도달할 때까지 위 과정을 반복함

## Ⅵ. 실무 적용 및 유의점

1. 네트워크 설계 시 모든 노드 간의 전체 연결 비용을 줄이는 것이 목적인지($MST$), 혹은 특정 노드 간의 개별 이동 거리를 줄이는 것($Shortest$ $Path$)인지 명확히 구분하여 알고리즘 오용으로 인한 설계 오류를 방지해야 함
2. 크루스칼 알고리즘 적용 시 $Union-Find$ 자료구조의 경로 압축($Path$ $Compression$)과 랭크 기반 합치기($Union$ $by$ $Rank$)를 생략하면 최악의 경우 성능이 저하될 수 있으므로, 반드시 최적화 기법을 병행하여 수행 시간을 보장해야 함

## Ⅶ. 결론

- 최소 신장 트리는 자원 효율성을 극대화하는 망 설계의 핵심 알고리즘이며, 설계자는 그래프의 복잡도와 동적 변경 가능성을 고려하여 크루스칼과 프림 중 최적의 기법을 선별 적용해야 함
