## Ⅰ. 개요

- **정의**: 최소 신장 트리(MST, Minimum Spanning Tree)는 가중 무방향 연결 그래프에서 모든 정점을 사이클 없이 연결하면서(간선 `V-1`개) 간선 가중치 합이 최소가 되는 부분 그래프임.
- **배경/필요성**: 모든 정점 쌍을 직접 연결하면 간선 수가 정점 수의 제곱에 비례해 설치·유지 비용이 과다해지므로, 사이클(중복 연결)을 배제하고 최소 비용으로 전 정점의 연결성만 확보하는 부분 그래프가 필요함.
- **출제 의도**: 신장 트리 성립 조건(`V-1`개 간선, 사이클 없음)과 크루스칼(간선 중심 + Union-Find)·프림(정점 중심 + 우선순위 큐)의 구현 차이를 구분하는 능력, MST와 최단 경로(011)의 목적 차이를 판단하는 역량을 확인함.
- **답안 방향**: 구조(신장 트리 조건과 Union-Find)를 먼저 세우고(Ⅱ), 크루스칼·프림 각각의 판정·확장 절차를 대조하며(Ⅲ), 그리디 선택이 전역 최적을 보장하는 근거와 그래프 밀도별 유불리를 정리한 뒤(Ⅳ), 알고리즘 선택 기준과 최단 경로와의 차이로 마무리함(Ⅴ~Ⅵ).

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 신장 트리 구조와 사이클 판정 메커니즘 이해 확인 | `V-1`개 간선 조건, Union-Find의 Find/Union 동작, 경로 압축 | 사이클 판정 근거 없이 "탐욕적으로 추가"라고만 서술 |
| 크루스칼·프림 구현 차이 및 최단 경로와의 목적 차이 판단 | 간선 정렬 vs 우선순위 큐, 희소·밀집 그래프별 적용 기준 | MST를 최단 경로와 혼동, 두 알고리즘의 시간복잡도 근거 없는 단정 |

> 요약: MST 답안은 신장 트리 조건과 Union-Find 동작 근거를 먼저 세우고, 그 위에서 크루스칼·프림의 적용 조건과 최단 경로와의 목적 차이를 판단하는 축으로 전개해야 함.

## Ⅱ. 구조 및 구성요소

```text
가중 무방향 연결 그래프 입력 -> 간선 목록/인접 정보 구성 -> 알고리즘 선택
                                                              |
                                                              +-> 크루스칼: 간선 정렬 + Union-Find
                                                              +-> 프림: 시작 정점 + 우선순위 큐
                                                              |
                                                              +-> 채택 간선 V-1개 도달 시 MST 확정
```

| 구성요소 | 역할 | 산출물/비유 |
|:---|:---|:---|
| 간선 목록(정렬) | 크루스칼이 가중치 오름차순으로 훑을 후보를 제공 | 전국 도로 공사비를 싼 순서로 나열한 견적표 |
| Union-Find(Disjoint Set) | `Find`로 두 정점의 대표원소(루트)를 찾아 같은 집합인지 판정하고, `Union`으로 두 집합을 합침 | 같은 팀인지 팀장을 확인하고, 다르면 팀을 합병 |
| 우선순위 큐(Min-Heap) | 프림이 현재 트리와 인접한 간선 중 최소 가중치 간선을 매 단계 추출 | 대기 명단에서 가장 시급한 항목부터 처리 |
| 트리 집합(Prim) | 이미 MST에 편입된 정점의 집합, 매 단계 인접 간선 탐색 범위를 결정 | 이미 전화가 연결된 집들의 명단 |

> 요약: 크루스칼은 정렬된 간선과 Union-Find로 사이클 여부를 판정하고, 프림은 트리 집합과 우선순위 큐로 인접 최소 간선을 확장함.

## Ⅲ. 동작원리 및 흐름도

```text
예시 그래프(무방향, 가중치): A-B=4, A-C=8, A-D=2, B-D=6, C-D=1

크루스칼(정렬 순: C-D=1, A-D=2, A-B=4, B-D=6, A-C=8):
  C-D(1) Find(C)!=Find(D) -> Union, 채택      [parent: D->C]
  A-D(2) Find(A)!=Find(D) -> Union, 채택      [parent: A->C]
  A-B(4) Find(A)!=Find(B) -> Union, 채택      [parent: B->C]
  B-D(6) Find(B)==Find(D) -> 사이클, 스킵
  A-C(8) Find(A)==Find(C) -> 사이클, 스킵
  채택 3개(=V-1) 도달, 총 비용 1+2+4=7

프림(시작 A):
  트리={A} -> 인접 중 최소 A-D(2) 채택 -> 트리={A,D}
  트리={A,D} -> 인접 중 최소 D-C(1) 채택 -> 트리={A,D,C}
  트리={A,D,C} -> 인접 중 최소 A-B(4) 채택 -> 트리={A,D,C,B}
  전 정점 편입, 총 비용 2+1+4=7 (크루스칼과 동일 - 가중치 전부 상이해 MST 유일)
```

- 1단계(초기화): 크루스칼은 전 간선을 가중치 오름차순으로 정렬하고 Union-Find를 각 정점이 자기 자신의 대표원소인 상태로 초기화하며, 프림은 임의 시작 정점 하나를 트리 집합에 편입하고 그 인접 간선을 우선순위 큐에 적재함.
- 2단계(후보 추출): 크루스칼은 정렬된 간선을 순서대로 하나씩 꺼내고, 프림은 우선순위 큐에서 트리와 인접한 최소 가중치 간선을 꺼냄.
- 3단계(판정 및 채택): 크루스칼은 꺼낸 간선 양 끝점에 `Find`를 적용해 대표원소가 다르면 `Union` 후 채택하고 같으면 사이클이므로 스킵하며, 프림은 꺼낸 간선의 반대쪽 정점이 이미 트리에 속하면 스킵하고 아니면 트리에 편입하며 그 정점의 인접 간선을 큐에 새로 추가함.
- 4단계(종료 판정): 채택 간선이 `V-1`개에 도달하면(크루스칼) 또는 모든 정점이 트리에 편입되면(프림) 종료하며, 채택된 간선 가중치의 합이 MST 총 비용이 됨.

> 요약: 크루스칼은 간선 정렬과 Union-Find의 집합 판정으로, 프림은 트리 집합과 우선순위 큐의 최소 간선 추출로 각각 사이클을 피하며 `V-1`개 간선에 도달함.

## Ⅳ. 특징

- 그리디 선택의 전역 최적 보장: 그래프를 임의로 두 부분으로 나누는 컷(cut)을 가로지르는 간선 중 가중치가 최소인 간선은 항상 어떤 MST에 포함될 수 있다는 성질(cut property)이 성립해, 크루스칼·프림 모두 매 단계 지역 최소 선택만으로 전역 최적해에 도달함.
- 시간복잡도 차이: 크루스칼은 간선 정렬이 지배해 `O(E log E)`이고, 프림은 우선순위 큐(이진 힙) 사용 시 `O(E log V)`이며 인접 행렬과 선형 탐색으로 구현하면 `O(V^2)`임.
- 그래프 밀도별 유불리: 간선이 적은 희소 그래프(`E`가 `V^2`보다 훨씬 작음)에서는 정렬 비용이 작은 크루스칼이 유리하고, 간선이 많은 밀집 그래프(`E`가 `V^2`에 근접)에서는 힙 없이 배열 기반으로 구현한 프림(`O(V^2)`)이 유리함.
- MST 유일성 조건: 모든 간선 가중치가 서로 다르면 MST는 유일하며, 동일 가중치 간선이 존재하면 서로 다른 형태의 MST가 여러 개 나올 수 있으나 총 비용은 항상 같음.
- 적용 전제: 무방향 연결 그래프를 전제하며, 비연결 그래프에서는 연결요소별로 최소 신장 포리스트를 구성해야 하고 방향 그래프에는 별도의 최소 신장 수형도(Arborescence) 알고리즘이 필요함.

> 요약: 크루스칼·프림 모두 컷 성질에 근거한 그리디 선택으로 전역 최적을 보장하되, 시간복잡도와 그래프 밀도별 유불리, 무방향·연결 전제가 실제 적용 여부를 가름함.

## Ⅴ. 심화 비교 및 적용 판단

| 판단 기준 | 크루스칼 | 프림 | 선택 기준 |
|:---|:---|:---|:---|
| 접근 방식 | 간선 중심, 전역 정렬 후 사이클 판정 | 정점 중심, 트리에서 인접 확장 | 전체 간선을 한 번에 볼 수 있으면 크루스칼, 인접 정보만으로 확장하면 프림 |
| 자료구조 | Union-Find(경로 압축 시 `O(a(V))`, 사실상 상수) | 우선순위 큐(힙, `O(log V)`) | 사이클 판정 빈도가 높으면 Union-Find, 최소값 반복 추출이 핵심이면 힙 |
| 그래프 밀도 | 희소 그래프(`E << V^2`)에서 유리 | 밀집 그래프(`E ~ V^2`, 배열 기반)에서 유리 | 간선 밀도를 사전 측정해 정렬 비용과 힙 비용 중 낮은 쪽 선택 |
| 다중 연결요소 처리 | 별도 처리 없이 최소 신장 포리스트가 자연히 형성됨 | 연결요소마다 시작 정점을 바꿔 별도 실행 필요 | 그래프 연결성이 불확실하면 크루스칼이 구현 부담이 적음 |

> 요약: 그래프 밀도와 연결성 확실 여부로 크루스칼·프림을 선택하되, 두 알고리즘 모두 컷 성질에 근거해 같은 총 비용의 MST를 산출함.

- MST와 최단 경로(011)의 목적 차이: 프림은 우선순위 큐로 최소 간선을 추출한다는 점에서 다익스트라와 자료구조가 유사하나, 다익스트라는 시작 정점 `s`부터 각 정점까지의 누적 거리 합이 최소가 되도록 갱신하는 반면 프림은 트리에 새로 추가될 간선 하나의 가중치만 비교함. 따라서 MST 위의 두 정점 간 경로가 최단 경로라는 보장은 없음.

**리스크·대응 (불릿):**
- 방향 그래프에 크루스칼·프림을 그대로 적용하는 오류: 원인은 무방향 전제 미확인 → 그래프 방향성을 사전 검증하고 방향 그래프에는 최소 신장 수형도(Chu-Liu/Edmonds) 알고리즘 적용으로 대응함 (지표: 간선 방향성 여부).
- 비연결 그래프에서 단일 신장 트리로 오판: 원인은 연결요소 개수 미확인 → 탐색 전 연결요소 수를 확인하고 다중 연결요소면 최소 신장 포리스트로 취급함 (지표: 연결요소 개수).

**도입 후 점검 지표 (불릿):**
- 정확성: 채택 간선 수가 정확히 `V-1`개인지(연결 그래프 전제) 확인함.
- 성능: 그래프 밀도(`E/V^2`)를 측정해 이론상 유리한 알고리즘(크루스칼/프림)과 실측 처리 시간이 일치하는지 확인함.

## Ⅵ. 실무 적용 및 결론

1. 단기: 대상 그래프의 밀도(`E` vs `V^2`)와 연결성을 진단해 크루스칼·프림 중 기본 적용 알고리즘을 결정함.
2. 중기: Union-Find에 경로 압축과 랭크 기반 합치기를 표준 구현으로 반영해 크루스칼의 사이클 판정 비용을 최소화함.
3. 장기: 네트워크 토폴로지 변경이 잦은 환경에서는 스패닝 트리 프로토콜(STP/RSTP) 등 표준화된 동적 MST 갱신 절차 도입 여부를 운영 정책에 반영함.

- 기술사적 판단: 희소 그래프에서 정렬 비용을 감내할 수 있으면 크루스칼을, 밀집 그래프에서 정점 중심 확장이 유리하면 프림을 선택하되, MST가 두 정점 간 최단 경로를 보장하지 않는다는 점을 설계에 반드시 반영함.
- 기술사 제언: MST 도입 전 "목적이 전체 정점의 최소 비용 연결인지, 특정 두 지점 간 최단 경로인지"를 먼저 구분해 다익스트라 계열 알고리즘과 혼동하지 않아야 함.
