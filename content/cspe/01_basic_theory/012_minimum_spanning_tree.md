## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 가중 무방향 그래프에서 모든 정점을 연결하면서 간선 가중치 합이 최소인 트리를 구하는 알고리즘임 |
| **배경/필요성** | 통신망·도로망·전력망 설계에서 최소 비용으로 모든 노드를 연결하는 최적 네트워크 구축이 필요함 |
| **출제 의도** | 크루스칼(간선 기반)과 프림(정점 기반)의 동작 원리와 선택 기준을 이해하는지 평가함 |

## Ⅱ. 구성요소
```
+----------+     +----------+     +----------+
| 크루스칼  | --> |Union-Find| --> |  프림    |
| (간선정렬)|     | (사이클) |     | (PQ정점) |
+----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| 크루스칼 | 간선을 가중치 오름차순 정렬 후 사이클 없이 V-1개를 선택함(O(E log E)) | 가장 싼 도로부터 건설 |
| 프림 | 임의 정점에서 출발하여 인접 최소 간선을 확장함(O(E log V)) | 마을에서 가장 가까운 집 연결 |
| Union-Find | 크루스칼에서 사이클 여부를 O(α(V))에 판별하는 자료구조임 | 마을 소속 확인 카드 |

> 요약: 크루스칼(간선 정렬+Union-Find)과 프림(PQ 기반 정점 확장)으로 MST를 구함.

## Ⅲ. 절차
```
+------------+     +------------+
| 간선정렬   | --> | 최소간선   |
| (오름차순) |     | 선택       |
+------------+     +------------+
                        |
+------------+     +----+-------+
| MST완성    | <-- | 사이클검사 |
| (V-1개)   |     | (Union-Find)|
+------------+     +------------+
```

1. 간선 정렬: 모든 간선을 가중치 오름차순으로 정렬함(크루스칼)
2. 최소 간선 선택: 정렬된 순서대로 가중치가 가장 작은 간선을 선택함
3. 사이클 검사: Union-Find로 두 정점이 같은 집합이면 사이클이므로 해당 간선을 건너뜀
4. MST 완성: V-1개의 간선이 선택되면 MST가 완성됨

> 요약: 간선 정렬 → 최소 선택 → 사이클 검사 → V-1개 완성으로 MST를 구함.

## Ⅳ. 문제점
- 크루스칼 정렬 비용: 간선 수가 많은 밀집 그래프에서 O(E log E) 정렬 비용이 큼
- 프림 PQ 구현: 피보나치 힙 구현이 복잡하며 실용적 상수가 큼
- 동적 그래프 미대응: 간선 추가·삭제 시 MST를 처음부터 재계산해야 함

## Ⅴ. 개선방안
- (단기) 그래프 밀도별 선택: 희소 그래프는 크루스칼, 밀집 그래프는 프림을 선택함
- (중기) Borůvka 병렬화: Borůvka 알고리즘의 라운드별 독립성을 활용하여 병렬 MST를 구함
- (장기) 동적 MST: 간선 삽입·삭제 시 O(log⁴ n)에 MST를 갱신하는 동적 알고리즘을 적용함

## Ⅵ. 전망
- 클러스터링(Single-Link)·네트워크 설계·회로 배선에서 MST가 핵심 알고리즘으로 활용되며, 대규모 그래프의 근사 MST가 분산 컴퓨팅에서 활발히 연구되고 있음
