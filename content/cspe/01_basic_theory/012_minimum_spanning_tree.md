## 미리 알고가기

- 신장 트리(Spanning Tree): 그래프의 모든 정점을 포함하고 모든 정점이 연결되며 사이클이 없는 부분 그래프임
- 최소 신장 트리(MST): 연결 그래프의 신장 트리 중 간선 가중치의 합이 최소인 트리임
- Union-Find: 서로소 집합을 관리하며, 두 정점이 같은 집합(사이클 형성 여부)에 속하는지 효율적으로 판별하는 자료구조임
- 컷 속성(Cut Property): 정점 집합을 둘로 나누는 컷을 가로지르는 최소 가중치 간선은 MST 후보가 될 수 있다는 성질임
- 탐욕법(Greedy): 현재 단계의 선택 기준에서 가장 유리한 후보를 고르고, MST에서는 컷 속성으로 그 선택의 안전성을 설명하는 설계 기법임

## Ⅰ. 개요

- **정의/개념**: 최소 신장 트리는 연결된 무방향 가중치 그래프에서 모든 정점을 사이클 없이 연결하되 선택 간선의 가중치 합이 최소가 되도록 구성한 신장 트리임
- **배경/필요성**: 통신망, 전력망, 도로망 구축처럼 모든 지점을 한 번 이상 연결해야 하는 설계에서는 중복 경로를 줄이면서 총 설치 비용을 최소화하는 기준이 필요함

## Ⅱ. 특징

- 연결 그래프의 MST는 정점이 $V$개일 때 간선 $V-1$개로 모든 정점을 연결하므로, 사이클을 만들며 비용만 늘리는 중복 간선을 제거함
- 크루스칼은 전역 최소 간선을 순서대로 검토하고, 프림은 현재 트리와 외부 정점을 잇는 최소 간선을 선택하되 두 방식 모두 사이클을 만들지 않는 간선만 채택함
- 단일 출발점 최단 경로와 달리 MST는 두 정점 사이의 이동 거리가 아니라 전체 망의 총 연결 비용을 최소화하므로, 비용 최적화와 경로 최적화를 구분해야 함

## Ⅲ. 종류 및 비교

| 판단 기준 | 크루스칼 (Kruskal) | 프림 (Prim) |
|:---|:---|:---|
| **처리 전략** | 가중치가 작은 간선부터 정렬 후 선택 | 현재 트리와 외부 정점을 잇는 최소 간선 선택 |
| **핵심 자료구조** | $Union-Find$, 간선 리스트 정렬 | 우선순위 큐, 방문 배열 |
| **사이클 판별** | 두 정점의 집합 대표가 같은지 확인 | 트리 외부 정점으로 향하는 간선만 선택 |
| **시간복잡도** | 간선 정렬 기준 $O(E \log E)$ | 우선순위 큐 기준 $O(E \log V)$ |
| **적합 그래프** | 간선이 적은 희소 그래프 | 간선이 많은 그래프(행렬 구현 시) |

> 요약: 간선을 정렬해 전역 후보를 고르면 크루스칼을, 한 정점에서 트리를 확장하며 최소 인접 간선을 고르면 프림을 적용함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 가중치 간선 집합 | 연결 후보가 되는 모든 간선과 각 간선에 할당된 거리, 설치비, 지연 같은 비용 정보임 |
| 사이클 검사기 | 새 간선을 추가했을 때 기존 트리와 순환 고리를 형성하는지 판별하여 트리의 정의를 유지함 |
| 우선순위 큐/정렬 | 후보 간선 중 최소 비용 대상을 반복적으로 고르기 위한 구조이며, 정렬 목록이나 힙 구현에 따라 추출 비용이 달라짐 |
| 결과 트리 저장소 | 최종적으로 선택된 $V-1$개의 간선과 해당 간선으로 연결된 정점들의 정보임 |

```text
[ MST 선택 모델 ]
1. Kruskal: 전체 간선 정렬 -> 최소 간선 -> 사이클 검사 -> 추가
2. Prim: 시작 정점 -> 인접 간선 후보 -> 최소 간선 -> 새 정점 추가
```

> 요약: MST는 최소 비용 간선을 고르는 구조와 사이클을 막는 검증 구조가 함께 있어야 전체 연결 비용을 줄일 수 있음.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------------+     +----------------+     +----------------+     +----------------+
| 후보 초기화    | --> | 최소 간선 선택 | --> | 안전성 검증    | --> | 결과 트리 누적 |
+----------------+     +----------------+     +----------------+     +----------------+
```

1. **후보 초기화** — 크루스칼은 전체 간선을 가중치 순으로 정렬하고, 프림은 시작 정점과 인접 간선을 후보로 등록함
2. **최소 간선 선택** — 크루스칼은 아직 검토하지 않은 최소 간선을, 프림은 현재 트리에서 외부 정점으로 향하는 최소 간선을 선택함
3. **안전성 검증** — 크루스칼은 Union-Find로 사이클 여부를 확인하고, 프림은 이미 트리에 포함된 정점으로 되돌아가는 간선을 제외함
4. **누적 및 종료** — 안전한 간선을 결과 트리에 추가하고, 선택 간선 수가 $V-1$개에 도달할 때까지 반복함

> 요약: 최소 간선 선택은 컷 속성에 근거해 안전성을 확인한 뒤 결과 트리에 누적될 때 MST를 구성함.

## Ⅵ. 실무 적용 및 유의점

1. 네트워크 설계에서는 전체 연결 비용을 줄이는 MST 문제인지, 특정 노드 간 이동 거리를 줄이는 최단 경로 문제인지 구분하고, 총 비용·경로 지연·장애 우회 가능성으로 알고리즘 선택 결과를 검증해야 함
2. 희소 그래프에서는 크루스칼과 경로 압축·랭크 기반 Union-Find가 적합하고, 밀집 그래프에서는 프림 구현을 검토하되 간선 수, 실행 시간, 메모리 사용량으로 선택 근거를 확인해야 함

## Ⅶ. 결론

- 최소 신장 트리는 전체 연결 비용을 최소화하는 망 설계 알고리즘이므로, 그래프 밀도와 구현 자료구조를 기준으로 크루스칼과 프림을 구분 선택해야 함
