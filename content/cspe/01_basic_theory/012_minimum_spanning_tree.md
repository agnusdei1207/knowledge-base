# 최소 신장 트리 - 크루스칼·프림 (Minimum Spanning Tree)

## 1. 개요

- **정의/개념**: 최소 신장 트리(Minimum Spanning Tree, MST)는 가중 무방향 연결 그래프의 모든 정점을 사이클 없이 연결하면서 간선 가중치 합을 최소화한 간선 집합이다.
- **배경/필요성**: 네트워크, 전력망, 배관망처럼 모든 지점을 연결해야 하지만 전체 구축 비용은 최소화해야 하는 설계 문제에서 필요하다.

MST는 두 정점 사이의 최단 경로를 보장하는 알고리즘이 아니라 전체 연결 비용을 최소화하는 알고리즘이다.

## 2. 특징 및 비교

| 구분 | 크루스칼(Kruskal) | 프림(Prim) |
|---|---|---|
| 접근 방식 | 간선을 비용순으로 선택 | 한 정점에서 트리를 확장 |
| 핵심 자료구조 | 정렬, Union-Find | 우선순위 큐 |
| 적합 그래프 | 희소 그래프 | 조밀 그래프 |
| 사이클 방지 | Union-Find로 집합 확인 | 방문 정점 집합 관리 |
| 시간복잡도 | `O(E log E)` | 우선순위 큐 기준 `O(E log V)` |

크루스칼은 간선 정렬이 중심이고, 프림은 현재 트리와 인접한 최소 간선 선택이 중심이다.

MST 알고리즘 선택은 그래프 밀도, 간선 정렬 비용, Union-Find 비용, 우선순위 큐 효율, 동적 변경 빈도를 기준으로 판단한다.

이 선택 기준은 모든 정점을 연결하되 사이클을 만들지 않는다는 트리 조건에서 출발한다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| 정점 집합 | 연결 대상 전체 지점 | 모든 정점 포함 |
| 가중 간선 | 연결 비용을 가진 후보 | 비용 기준 선택 |
| 사이클 검증 | 선택 간선이 순환을 만드는지 확인 | 트리 조건 |
| 간선 선택 규칙 | 최소 비용 간선 우선 | greedy 선택 |
| 결과 트리 | `V-1`개 간선으로 모든 정점 연결 | 최소 비용 |

```text
가중 무방향 그래프 -> 최소 간선 선택 -> 사이클 방지 -> V-1개 간선 완성
```

이 흐름이 깨지면 MST가 아니라 단순 최소 간선 집합이나 최단 경로 문제로 오해되므로, 조건 검증이 먼저 필요하다.

## 4. 문제점 및 개선방안

1. **그래프 조건 불일치**
   - 방향 그래프나 비연결 그래프에는 일반 MST가 그대로 성립하지 않는다.
   - **개선방안**: 무방향성·연결성을 검증하고 비연결 그래프는 최소 신장 포리스트로 처리한다.

2. **동일 가중치 결과 다양성**
   - 같은 최소 비용의 MST가 여러 개 존재할 수 있다.
   - **개선방안**: 동률 간선 우선순위를 정하고 검증은 간선 목록보다 총 비용과 트리 조건 중심으로 수행한다.

3. **동적 변경 대응**
   - 간선 비용이 자주 바뀌면 매번 MST를 재계산하는 비용이 커진다.
   - **개선방안**: 변경 빈도에 따라 배치 갱신, 부분 재계산, 동적 MST 알고리즘을 검토한다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| 통신망 설계 | 모든 노드를 최소 회선 비용으로 연결 | 총 구축 비용, 연결성 |
| 전력·배관망 | 중복 루프 없이 전체 지점 연결 | 공사비, 장애 영향 |
| 클러스터링 | MST 기반으로 가까운 데이터 간 연결 후 절단 | 군집 수, 연결 비용 |

## 6. 결론

최소 신장 트리는 전체 연결 비용 최소화가 목적이며 최단 경로와 구분해야 한다. 크루스칼과 프림은 모두 탐욕 전략이지만 그래프 밀도, 간선 정렬 비용, 자료구조 조건, 변경 빈도에 따라 선택이 달라진다.
