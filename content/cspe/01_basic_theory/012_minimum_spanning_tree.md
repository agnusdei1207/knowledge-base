## Ⅰ. 개요
- 그래프의 모든 정점을 연결하면서 간선 가중치의 합이 최소인 트리 구조임.
- 사이클이 없어야 하며 정점 수가 V일 때 간선 수는 반드시 V-1개임.
- [표] 출제 의도: 네트워크 구축 비용 최소화 및 그리디 알고리즘 이해 측정.

## Ⅱ. 구성요소
- ASCII 구조도
  [ Kruskal: Edge-based ]  [ Prim: Vertex-based ]

| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| Kruskal | 간선을 가중치 순으로 정렬 후 연결 | 저렴한 전선부터 구매 |
| Prim | 특정 정점에서 인접한 최소 간선 확장 | 가까운 이웃부터 연결 |
| Union-Find | Kruskal에서 사이클 형성 여부 확인용 | 가족 관계 확인 |

> 요약: 최소 비용 간선을 선택하는 탐욕적(Greedy) 기법을 사용함.

## Ⅲ. 절차
- ASCII 흐름도
  Edge/Vertex Select -> Cycle Check -> Add to Tree -> Repeat V-1

1. (Kruskal) 모든 간선을 가중치 기준으로 오름차순 정렬함.
2. (Prim) 임의의 시작 정점을 선정하여 방문 정점 집합에 포함함.
3. 최소 가중치 간선을 선택하되 사이클 형성 여부를 판단함.
4. 선택된 간선을 트리에 추가하고 총 V-1개의 간선이 모일 때까지 반복함.

> 요약: 사이클 없이 최소 비용으로 모든 노드를 연결함.

## Ⅳ. 문제점
- 그래프가 분리되어 있을 경우 전체를 연결하는 MST 생성이 불가함.
- Prim 방식은 희소 그래프(Sparse Graph)에서 Kruskal보다 비효율적임.

## Ⅴ. 개선방안
- 단기: 간선의 밀도에 따라 알고리즘(희소-K, 밀집-P)을 선택함.
- 중기: Kruskal 적용 시 경로 압축된 Union-Find 자료구조 활용함.
- 장기: Fibonacci Heap을 사용한 Prim 성능 고도화(O(E+V log V))함.

## Ⅵ. 전망
- 소프트웨어 정의 네트워크(SDN) 환경에서 동적인 트래픽 변화에 즉각 대응하는 MST 기반 재구성 기술이 클라우드 데이터센터 가용성의 핵심 성공 요인(CSF)이 될 것임.
- 친환경 그린 컴퓨팅을 실현하기 위해 데이터 전송 에너지 소비량을 최소화하는 '에너지 인지형 신장 트리' 구축 기법이 IoT 네트워크의 표준으로 채택될 전망임.
- 대규모 클러스터링 알고리즘(Single-linkage)과의 결합을 통해 비정형 데이터의 계층 구조를 자동으로 추출하는 머신러닝 기반 그래프 기법이 고도화될 것임.
