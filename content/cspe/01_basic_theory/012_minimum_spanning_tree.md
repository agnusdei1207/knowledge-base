# 📖 【암기용】 개념 완전 이해

> 목적: MST를 연결 비용 최소화와 사이클 제거 관점으로 이해하게 만든다.

## 한눈에
- **개요**: 무방향 가중 그래프의 모든 정점을 사이클 없이 연결하는 최소 비용 트리
- **왜 필요한가**: 네트워크 회선, 전력망, 클러스터 연결처럼 전체 노드를 연결하되 중복 경로 비용을 제거해야 함
- **핵심 직관**: 모든 지점을 연결하는 데 필요한 간선은 V-1개뿐이며, 비싼 사이클 간선은 제거 대상임

## 깊이 이해
- **배경·문제의식**: 모든 노드를 연결하려고 가능한 간선을 전부 쓰면 비용과 장애 지점이 증가함. MST는 연결성은 유지하고 총 가중치 합은 최소화함
- **작동 원리**: 크루스칼은 간선을 가중치 오름차순으로 보며 사이클이 생기지 않을 때 채택함. 프림은 하나의 트리에서 시작해 가장 싼 인접 간선을 확장함
- **비유**: 여러 건물을 통신 케이블로 연결할 때, 이미 연결된 건물끼리 다시 케이블을 깔면 사이클 비용이므로 생략함
- **구체 예시**: 정점 6개인 연결 그래프의 MST 간선 수는 항상 5개임. 크루스칼은 Union-Find로 cycle 여부를 거의 O(alpha(V))에 판정함
- **흔한 오해·주의점**: MST는 두 정점 사이 최단 경로를 보장하지 않음. 전체 연결 비용 최소와 특정 경로 비용 최소는 다른 문제임

## 연결 개념
- 탐욕 알고리즘 — cut property와 cycle property에 기반한 선택
- Union-Find — 크루스칼의 사이클 판정 자료구조
- 네트워크 설계 — 최소 회선 비용과 이중화 요구의 균형 검토

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: MST는 무방향 가중 연결 그래프에서 모든 정점을 V-1개 간선으로 연결하는 총 비용 최소 트리이다.
> 2. **가치**: 통신망, 배선, 클러스터링에서 전체 연결 비용을 최소화하고 사이클 간선을 제거한다.
> 3. **판단 포인트**: 간선 중심 정렬은 크루스칼, 정점 중심 확장은 프림, 희소/밀집 그래프 조건에 따라 선택한다.

---

## Ⅰ. 개요 및 필요성

- 정의: 그래프의 모든 정점을 최소 비용으로 연결하는 트리
- 배경: 네트워크 구축은 연결성 확보, 총 비용 절감, 중복 간선 제거가 동시에 필요함
- 필요성: MST는 V개 정점을 V-1개 간선으로 연결해 총 가중치 합을 최소화하는 기준을 제공함

---

## Ⅱ. 구조 및 구성요소

```text
Weighted Undirected Graph -> Edge Selection -> Cycle Check -> MST(V-1 edges)
                         / Kruskal: sort edges and union-find
                         / Prim: priority queue and visited set
                         / Result: connected, acyclic, minimum total weight
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 무방향 가중 그래프 | MST의 입력 | 연결 그래프 필요 |
| 후보 간선 집합 | 가중치 기준 선택 대상 | 크루스칼은 전체 간선 정렬 |
| 사이클 판정 | 트리 조건 유지 | Union-Find 또는 visited 사용 |
| MST 결과 | V-1개 간선과 총 비용 | 사이클 0개, 모든 정점 연결 |

> 요약: MST는 가중 그래프에서 후보 간선을 선택하고 사이클을 배제해 V-1개 간선의 연결 트리를 만든다.

---

## Ⅲ. 동작원리 및 흐름도

```text
그래프 입력 -> 최소 간선 후보 선택 -> 사이클 여부 검사 -> 채택/제외 -> V-1개면 종료
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 그래프 G(V,E)와 가중치 입력 | 무방향·연결 그래프 |
| 2 | 최소 비용 후보 간선 선택 | 크루스칼: 정렬, 프림: PQ |
| 3 | 사이클 발생 여부 검사 | find(u) != find(v) |
| 4 | 간선 채택 후 종료 조건 확인 | 선택 간선 수 V-1 |

> 요약: MST는 최소 비용 간선을 반복 선택하되, 사이클을 만들지 않는 간선만 채택하는 탐욕 절차이다.

---

## Ⅳ. 특징

| 구분 | 크루스칼 | 프림 | 수치·판단 기준 |
|:---|:---|:---|:---|
| 선택 기준 | 전체 간선 오름차순 | 현재 트리의 인접 최소 간선 | 간선 중심 vs 정점 중심 |
| 자료구조 | Sorting + Union-Find | Priority Queue + Adj List | 구현 핵심 |
| 시간복잡도 | O(E log E) | O(E log V) | 희소 그래프에서 둘 다 적용 |
| 적합 조건 | 간선 목록 중심, 희소 그래프 | 밀집 그래프, 시작 정점 기반 확장 | E와 V 규모 |

> 요약: 크루스칼은 간선 정렬과 Union-Find가 핵심이고, 프림은 우선순위 큐 기반 트리 확장이 핵심이다.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 최단 경로 | 최소 신장 트리 | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | 특정 출발지 경로 최소 | 전체 정점 연결 비용 최소 | 전체 연결망 비용 산정은 MST |
| 비용/성능 | 경로별 distance | V-1개 간선 총합 | 회선·배선·클러스터링 비용 |
| 운영/위험 | 경로 우회 가능 | 기본 MST는 이중화 없음 | 장애 우회 요구 시 추가 간선 설계 |

> 요약: MST는 전체 연결 비용 최소 기준이며, 장애 우회와 특정 경로 최단은 별도 요구로 분리해야 한다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 비연결 그래프 | 입력 그래프 연결성 부족 | connected component 검사 | component count |
| 사이클 포함 | Union-Find 판정 누락 | find/union 불변식 테스트 | selected edge count = V-1 |
| 이중화 부족 | MST의 간선 최소 특성 | 중요 노드에 2nd path 추가 | single point edge count |

> 요약: MST 리스크는 연결성, 사이클, 이중화 부족이며 component와 간선 수로 검증한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 비용 | 총 가중치 기준안 대비 절감률 산정 | 비용 시뮬레이션 |
| 정확도 | 간선 수 V-1, 사이클 0개 | Union-Find 검증 |
| 운영 | 중요 구간 이중화율 목표 충족 | topology 분석 |

> 요약: 도입 효과는 총 비용, 트리 조건, 중요 구간 이중화율로 판단한다.

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 회선 설계: 지점 간 회선비를 가중치로 모델링하고 MST로 기본 연결 비용 산출, 중요 노드는 별도 이중화 간선 추가
2. 데이터 클러스터링: 거리 그래프의 MST에서 큰 가중치 간선을 k-1개 제거해 k개 군집 생성
3. 인프라 토폴로지 검토: V-1개 간선 기준과 실제 간선 수를 비교해 중복 회선 비용과 장애 우회 요구를 분리 산정

**결론 (2줄):**
- 기술사 판단: 전체 연결 비용 산정은 MST, 특정 출발지 경로 비용 산정은 최단 경로, 장애 우회 설계는 MST 이후 이중화 기준을 추가함
- 향후 방향: SDN·클라우드 네트워크에서는 비용, 대역폭, 지연시간을 다목적 가중치로 변환해 MST와 정책 라우팅을 병행해야 함
