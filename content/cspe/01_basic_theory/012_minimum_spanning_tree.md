## Ⅰ. 개요
- **정의**: 연결 그래프의 모든 정점을 포함하면서 간선 가중치 합이 최소인 트리
- **배경/필요성**: 네트워크 배선, 도로 설계 등에서 모든 노드를 연결하되 총 비용을 최소화해야 하는 문제가 빈번함
- **비유**: 마을 전체를 잇되 도로 포장 비용이 가장 적은 도로망을 설계하는 것

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| Kruskal vs Prim 비교·절단 속성 이해 | 간선 중심 vs 정점 중심, 절단 속성 증명 | 사이클 판별에 Union-Find 사용 명시 |

> 요약: 모든 정점을 최소 비용으로 연결하는 트리를 Kruskal 또는 Prim으로 구함

## Ⅱ. 구성요소
```text
  +---------------------+
  | Minimum Spanning Tree|
  +---------+-----------+
            |
    +-------+-------+
    |               |
    v               v
  Kruskal          Prim
  (간선 정렬)     (정점 확장)
  +Union-Find     +우선순위 큐
  O(E log E)      O(E log V)
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| Kruskal | 간선을 가중치 순 정렬 후 사이클을 만들지 않는 간선만 추가함 | 가장 싼 도로부터 깔되 순환 도로는 건너뛰는 시공 |
| Prim | 임의 정점에서 출발하여 인접 간선 중 최소 가중치를 반복 선택함 | 마을 하나에서 시작해 가장 가까운 이웃 마을로 도로를 뻗는 방식 |
| 절단 속성 | 그래프를 둘로 나누는 절단에서 최소 가중치 교차 간선은 MST에 포함됨 | 두 구역을 잇는 다리 중 가장 싼 다리가 최적 도로망에 포함되는 원리 |

> 요약: Kruskal은 간선 중심, Prim은 정점 중심이며, 절단 속성이 정당성을 보장함

## Ⅲ. 절차
```text
  정렬/초기화      간선 선택        사이클/연결 검사    트리 확정
  (전처리)        (최소 가중치)    (Union-Find/큐)    (V-1개 간선)
   |               |               |               |
   +---가중치순--->+---최소 pick--->+---검증-------->+
  간선 리스트      후보 간선       합집합/방문 확인  MST 완성
```
- 1단계: Kruskal은 간선을 가중치 오름차순 정렬, Prim은 시작 정점을 선택하고 우선순위 큐를 초기화함
- 2단계: 가중치가 가장 작은 간선(Kruskal) 또는 인접 간선(Prim)을 선택함
- 3단계: Kruskal은 Union-Find로 사이클 여부를 판별하고, Prim은 방문 여부를 확인함
- 4단계: V-1개 간선이 선택되면 MST가 완성됨

> 요약: 간선을 가중치 순으로 선택하되 사이클을 배제하여 V-1개 간선으로 트리를 완성함

## Ⅳ. 문제점
- 동일 가중치 간선: 같은 가중치의 간선이 여럿이면 MST가 유일하지 않아 결과 검증이 어려움
- 밀집 그래프 정렬 비용: Kruskal에서 간선 수가 많으면 정렬 비용 O(E log E)가 지배적임
- 동적 그래프 재계산: 간선 추가·삭제 시 MST 전체를 다시 계산해야 하므로 실시간 대응이 어려움

> 요약: MST 비유일성, 밀집 그래프 정렬 비용, 동적 변경 대응이 주요 한계임

## Ⅴ. 개선방안
1. 단기: 동일 가중치 간선에 대해 정점 번호 등 보조 기준을 두어 결과를 결정적으로 만듦
2. 중기: 밀집 그래프에서는 Prim + 피보나치 힙을 적용하여 O(E + V log V)로 성능을 개선함
3. 장기: 간선 추가·삭제에 대해 증분 MST 알고리즘을 적용하여 재계산 범위를 최소화함

> 요약: 보조 정렬 기준, 고급 힙 자료구조, 증분 알고리즘으로 한계를 극복함

## Ⅵ. 전망
- 발전 방향: IoT 센서 네트워크, 클러스터링 등 대규모 연결 최적화 문제에 MST 활용이 확대됨
- 기술사적 판단: 절단 속성의 이해가 MST 알고리즘 정당성 논증의 핵심임
- 기술사 제언: 그래프 밀도에 따라 Kruskal(희소)과 Prim(밀집)을 구분 적용할 것을 권고함
