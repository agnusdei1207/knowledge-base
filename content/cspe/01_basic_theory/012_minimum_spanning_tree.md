# 최소 신장 트리 - 크루스칼·프림 (Minimum Spanning Tree)

## 미리 알고가기

- **신장 트리(spanning tree)**: 그래프의 모든 정점을 하나도 빠뜨리지 않고 잇되, 돌아오는 순환이 없는 연결 뼈대. 정점이 `V`개면 간선은 정확히 `V-1`개로, 하나라도 빼면 어딘가가 끊기고 하나라도 더하면 순환이 생긴다.
- **사이클(cycle)**: 한 점에서 출발해 제자리로 돌아오는 순환. 이미 이어진 두 점을 또 이으면 생기는데, 연결에는 보탬이 안 되면서 비용만 더하는 낭비 간선이다.
- **Union-Find(합집합·찾기)**: 각 정점이 지금 어느 덩어리에 속하는지 빠르게 찾고, 두 덩어리를 하나로 합쳐 주는 자료구조. "이 둘이 이미 한 덩어리냐"를 거의 상수 시간에 답한다.
- **희소·조밀 그래프**: 간선 수가 정점 수에 비해 적으면 희소, 정점 대부분이 서로 이어져 간선이 많으면 조밀하다고 한다.

## 1. 개요

- **정의/개념**: 최소 신장 트리(Minimum Spanning Tree, MST)는 가중치가 매겨진 무방향 연결 그래프에서, 모든 정점을 순환 없이 이으면서 사용한 간선들의 비용 합이 가장 작아지도록 고른 `V-1`개짜리 연결망이다.
- **배경/필요성**: 여러 마을에 수도관을 깔거나 변전소를 전선으로 잇는 것처럼 모든 지점을 하나로 이어야 하는 설계에서, 아무렇게나 연결하면 이미 이어진 곳을 또 잇는 중복 구간이 생겨 공사비가 불어나고, 그렇다고 함부로 구간을 빼면 어떤 마을이 통째로 끊겨 버린다. MST는 "모든 정점이 이어져 있어야 한다"는 연결 조건과 "순환 같은 낭비 간선은 두지 않는다"는 트리 조건을 동시에 지키면서 비용 합만 최소로 눌러, 끊김 없이 가장 싸게 잇는 뼈대를 뽑아 준다.

여기서 헷갈리기 쉬운 점 하나. MST는 두 지점 사이를 최단으로 잇는 최단 경로 알고리즘이 아니다. 전체를 싸게 잇다 보면 A에서 B로 가는 MST 위의 길이 실제 최단 경로보다 멀리 돌아갈 수도 있다. MST가 아끼는 것은 개별 경로 길이가 아니라 망 전체의 총 부설 비용이다.

## 2. 특징 및 비교

두 알고리즘 모두 "지금 고를 수 있는 가장 싼 간선을 집되, 순환을 만드는 간선은 버린다"는 탐욕(greedy) 전략을 쓴다. 갈리는 지점은 **무엇을 기준으로 다음 간선을 고르느냐**다.

| 구분 | 크루스칼(Kruskal) | 프림(Prim) |
|:---|:---|:---|
| 고르는 방식 | 전체 간선을 싼 순서로 줄 세워 위에서부터 집음 | 씨앗 정점 하나에서 트리를 눈덩이처럼 키움 |
| 다음 간선 판단 | 그래프 전체에서 가장 싼 간선 | 지금 트리에 붙은 간선 중 가장 싼 것 |
| 핵심 자료구조 | 간선 정렬 + Union-Find | 우선순위 큐 |
| 순환 막는 법 | Union-Find로 "이미 한 덩어리냐" 확인 | 이미 트리에 든 정점인지 확인 |
| 유리한 그래프 | 간선이 적은 희소 그래프 | 간선이 많은 조밀 그래프 |
| 시간복잡도 | `O(E log E)` (간선 정렬이 지배) | `O(E log V)` (우선순위 큐 기준) |

> 요약: 간선을 싼 것부터 훑으면 크루스칼, 한 점에서 트리를 키워 나가면 프림.

크루스칼은 그래프 전체를 하나의 관점에서 본다. 모든 간선을 비용 오름차순으로 정렬해 두고 위에서부터 집되, 그 간선이 이미 이어진 두 덩어리를 다시 잇는 것이면(사이클) 버린다. 이 "이미 한 덩어리냐" 판정을 빠르게 해 주는 것이 Union-Find다. 그래서 간선 수가 적은 희소 그래프에서 정렬 비용이 가벼워 유리하다.

프림은 반대로 국소적으로 자란다. 아무 정점 하나를 씨앗으로 삼아, 지금까지 만든 트리에 걸쳐 있는 간선 가운데 가장 싼 것을 우선순위 큐로 골라 새 정점을 하나씩 빨아들인다. 트리가 커질 때마다 후보 간선을 큐에 넣고 최소값을 꺼내므로, 정점마다 간선이 촘촘히 붙은 조밀 그래프에서 강하다.

## 3. 구성요소/구조

작은 예로 크루스칼이 도는 모습을 보면 규칙이 한눈에 잡힌다.

```text
정점 A B C D, 간선 후보(비용):
   A-B:1   B-C:2   A-C:3   C-D:4   B-D:5

싼 것부터 집는다 ->
   A-B(1) 선택   : {A,B}
   B-C(2) 선택   : {A,B,C}
   A-C(3) 버림   : A와 C가 이미 한 덩어리 -> 사이클
   C-D(4) 선택   : {A,B,C,D}  간선 3개 = V-1, 완성

        A --1-- B
                |
                2
                |
                C --4-- D      (총비용 1+2+4 = 7)
```

가장 싼 `A-C(3)`을 넣지 않은 게 핵심이다. 비용만 보면 4보다 싸지만 A와 C는 이미 이어져 있어, 넣으면 순환만 만들 뿐 연결에는 아무 보탬이 없다. 이렇게 "싼 것 우선 + 순환이면 버림"을 `V-1`개가 찰 때까지 반복하면 MST가 완성된다.

| 구성요소 | 하는 일 | 왜 중요한가 |
|:---|:---|:---|
| 정점 집합 | 반드시 이어야 할 모든 지점 | 하나라도 빠지면 신장 트리가 아님 |
| 가중 간선 | 비용이 매겨진 연결 후보 | 이 비용이 곧 선택 기준 |
| 간선 선택 규칙 | 가능한 것 중 최소 비용 간선 우선 | 탐욕 전략의 심장 |
| 사이클 검증 | 고른 간선이 순환을 만드는지 확인 | 낭비 간선을 걸러 트리 조건 유지 |
| 결과 트리 | `V-1`개 간선으로 전 정점 연결 | 완성·종료 판정 기준 |

> 요약: 최소 비용 간선을 집는 탐욕 규칙이 비용을 낮추고, 사이클 검증이 그 결과를 트리로 붙들어 둔다.

## 4. 문제점 및 개선방안

1. **입력 그래프가 전제를 안 지킴**: MST는 무방향이고 하나로 이어진 연결 그래프를 전제로 하는데, 간선에 방향이 있거나 그래프가 여러 조각으로 나뉘어 있으면 정의 그대로는 성립하지 않는다.
   - **개선방안**: 돌리기 전에 무방향성과 연결성을 검사하고, 조각난 그래프는 조각마다 MST를 만드는 최소 신장 포리스트(forest)로 처리한다. (확인: 연결 컴포넌트 개수, 각 조각의 간선 수 = 정점 수 - 1)

2. **최소 비용은 하나여도 트리 모양은 여럿**: 같은 비용의 간선이 여러 개면 총비용이 똑같은 MST가 여러 벌 나올 수 있어, 간선 목록만 비교하면 정답인데도 틀렸다고 오판한다.
   - **개선방안**: 동률 간선의 우선순위 규칙(예: 정점 번호 순)을 정해 결과를 하나로 고정하고, 검증은 간선 목록이 아니라 총비용과 트리 조건으로 한다. (확인: 총 가중치 합, `V-1`개·무사이클 여부)

3. **간선 비용이 자주 바뀜**: 교통량이나 전력 부하로 간선 비용이 수시로 변하는데 그때마다 MST를 처음부터 다시 계산하면 갱신 비용이 눈덩이처럼 커진다.
   - **개선방안**: 변경 빈도에 맞춰 여러 변경을 모아 한 번에 처리하는 배치 갱신, 바뀐 간선 주변만 고치는 부분 재계산, 동적 MST 알고리즘을 골라 쓴다. (확인: 갱신 1건당 재계산 간선 수, 재계산 지연)

## 5. 실무 적용 사례

| 적용 영역 | 어떻게 쓰나 | 무엇으로 효과를 확인하나 |
|:---|:---|:---|
| 통신망 설계 | 모든 노드를 회선 비용이 가장 싸게 이어 초기 백본을 깔음 | 총 부설 비용, 전 노드 연결 여부 |
| 전력·배관망 | 중복 루프 없이 모든 수요지를 최소 공사비로 연결 | 공사비 합계, 단일 경로라 끊길 때 영향 범위 |
| 데이터 클러스터링 | 점 사이 거리를 간선으로 MST를 만든 뒤 가장 비싼 간선을 끊어 군집 분리 | 나뉜 군집 수, 절단 지점의 간선 비용 |

> 요약: 전 지점을 가장 싸게 잇는 설계에는 MST를, 군집화에는 MST를 만든 뒤 비싼 간선을 끊는 방식을 쓴다.

## 6. 결론

최소 신장 트리는 모든 지점을 끊김 없이 가장 싼 비용으로 잇는 뼈대를 뽑는 도구이며, 개별 구간을 최단으로 잇는 최단 경로 문제와는 목적이 다르므로 섞어 쓰면 안 된다. 크루스칼과 프림은 둘 다 탐욕 전략이라 답은 같지만, 간선이 적은 희소 그래프면 정렬이 가벼운 크루스칼을, 간선이 촘촘한 조밀 그래프면 트리를 키워 나가는 프림을 고르는 식으로 그래프 생김새와 변경 빈도에 맞춰 선택이 갈린다.
