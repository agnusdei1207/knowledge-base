## 미리 알고가기

- 확률 변수: 무작위 실험 결과를 수치로 표현한 변수임
- 이산 분포: 셀 수 있는 값에 확률을 부여하는 분포임
- 연속 분포: 구간의 면적으로 확률을 계산하는 분포임
- 모수: 분포의 모양과 위치를 정하는 값임
- 중심 극한 정리: 표본 평균 분포가 표본 수 증가에 따라 정규 분포에 가까워지는 원리임
- 확률 질량 함수(PMF): 이산 확률 변수의 각 값에 확률을 대응시키는 함수임
- 확률 밀도 함수(PDF): 연속 확률 변수의 구간 확률을 면적으로 계산하는 함수임
- 누적 분포 함수(CDF): 확률 변수가 특정 값 이하일 누적 확률을 나타내는 함수임
- Q-Q 도표: 표본 분위수와 이론 분포 분위수를 비교해 분포 적합성을 확인하는 도표임

## 작성 근거(검토용)

- 키워드에 정규·이항·포아송이 명시되어 세 분포의 변수 유형·모수·활용 조건을 한 표에 둠
- 특징은 이산·연속 구분과 평균·분산 요약으로 분포 선택의 기본 판단을 먼저 세움
- 구성요소는 PMF·PDF·CDF를 포함해 확률 계산 방식 차이를 드러냄
- 절차 절은 데이터 성격 파악·후보 선택·모수 추정·적합 검증으로 실제 분석 흐름에 맞춤
- 실무 절은 포아송 운영 활용과 정규 가정 리스크를 반영해 분포 가정의 검증 필요성을 강조함

## Ⅰ. 개요

- **정의/개념**: 확률 분포는 확률 변수가 가질 수 있는 값과 그 발생 가능성을 수학적으로 대응시킨 모델임
- **배경/필요성**: 예측·추정·검정·성능 분석의 기준을 세우기 위해 데이터 발생 패턴을 나타내는 확률 분포가 필요함

## Ⅱ. 특징

- 이산 분포는 각 값의 확률을 직접 더해 사건 확률을 구함
- 연속 분포는 특정 값이 아니라 구간 면적으로 확률을 구함
- 분포의 평균과 분산은 중심 위치와 변동성을 요약함
- 실제 데이터는 적합도 검정으로 분포 가정을 확인해야 함

## Ⅲ. 종류 및 비교

| 분포 | 변수 유형 | 모수 | 적합 상황 | 대표 활용 |
|:---|:---|:---|:---|:---|
| 이항 분포 | 이산 | $n, p$ | 독립 시행의 성공 횟수 | 불량 개수·클릭 수 |
| 포아송 분포 | 이산 | $\lambda$ | 단위 시간의 사건 발생 횟수 | 장애 건수·콜 도착 |
| 정규 분포 | 연속 | $\mu, \sigma^2$ | 측정값과 평균 주변 오차 | 품질 관리·추정 |

> 요약: 이항은 반복 시행, 포아송은 발생률, 정규는 연속 측정 오차에 적합함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 확률 변수 | 모델링할 사건 결과를 수치화한 값임 |
| 기대값 | 분포의 평균 위치를 나타냄 |
| 분산 | 평균 주변의 흩어짐 정도를 나타냄 |
| PMF | 이산 변수의 값별 확률 함수임 |
| PDF | 연속 변수의 구간 확률을 만드는 밀도 함수임 |
| CDF | 특정 값 이하의 누적 확률을 나타냄 |

```text
이산 분포: P(X=x)를 직접 더함
연속 분포: f(x) 아래 면적이 확률임

E[X]   -> 중심 위치
Var[X] -> 퍼짐 정도
```

> 요약: 분포는 확률 계산 방식과 평균·분산 요약값으로 데이터 발생 패턴을 설명함.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+   +----------+   +----------+   +----------+
| 데이터 파악 | -> | 분포 선택 | -> | 모수 추정 | -> | 적합 검증 |
+----------+   +----------+   +----------+   +----------+
```

1. 값이 이산인지 연속인지와 시행 조건이 독립인지 확인함
2. 생성 원리에 맞는 후보 분포를 선택함
3. 표본 평균·분산·최대우도 등으로 모수를 추정함
4. Q-Q 도표·카이제곱 검정·KS 검정으로 적합성을 확인함

> 요약: 분포 선택은 변수 유형, 생성 조건, 모수 추정, 적합도 검증이 함께 충족되어야 함.

## Ⅵ. 실무 적용 및 유의점

1. 장애 건수가 포아송 분포라면 대기 시간은 지수 분포와 연결되므로 발생률로 점검 주기와 SLA를 산정함
2. 정규 분포 가정은 꼬리 위험을 과소평가하므로 극단값 비율과 Q-Q 도표로 검증함

## Ⅶ. 결론

- 확률 분포는 데이터 생성 원리를 수학 모델로 바꾸는 기준이며, 변수 유형과 발생 조건에 맞는 분포 선택이 분석 품질을 결정함
