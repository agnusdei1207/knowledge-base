## Ⅰ. 개요
- 정의: 확률 변수가 특정한 값을 가질 확률을 함수 형태로 나타낸 것임
- 배경/필요성: 현상의 패턴을 통계적으로 모델링하여 미래 사건을 예측하고 분석함
- 출제 의도: 각 분포의 특징, 파라미터(평균, 분산), 적용 분야 비교 이해

## Ⅱ. 구성요소
- ASCII 구조도
  Normal:      / \          Binomial:   | | |
  (Bell)   ___/   \___      (Discrete)  | | |
           -3s  m  +3s                   n, p

- 구성요소 표
| 분포 종류 | 핵심 특징 | 적용 예시 |
| :--- | :--- | :--- |
| 정규 분포 | 좌우 대칭의 종 모양 (평균, 표준편차) | 키, 몸무게, 성적 |
| 이항 분포 | n번 시행 시 성공 횟수 (횟수, 확률) | 동전 던지기, 불량률 |
| 포아송 분포 | 단위 시간/공간 내 발생 횟수 (람다) | 콜센터 전화, 사고 발생 |
| 지수 분포 | 사건 발생 사이의 대기 시간 | 기기 수명, 대기 시간 |
> 요약: 현상의 성격(연속/이산, 횟수/시간)에 따라 적합한 확률 모델을 선택함

## Ⅲ. 절차
- ASCII 흐름도
  [Analyze Data Type] -> [Select Model] -> [Estimate Params] -> [Predict Prob]

1. 변수 유형 파악: 이산형(횟수)인지 연속형(측정값)인지 구분함
2. 모델 선택: 데이터 발생 원리에 맞는 확률 분포 모델을 결정함
3. 모수 추정: 평균(μ), 분산(σ^2), 발생률(λ) 등의 파라미터를 계산함
4. 확률 계산: PDF(확률밀도함수)나 PMF(확률질량함수)를 통해 확률값을 산출함
> 요약: 현실 데이터를 수학적 함수로 매핑하여 통계적 추론의 기반을 마련함

## Ⅳ. 문제점
- 이상치 민감도: 극단적인 값(Outlier)에 의해 평균과 분산이 왜곡될 수 있음
- 가정의 한계: 실제 데이터가 특정 분포를 따르지 않을 경우 분석 결과의 신뢰도 저하됨

## Ⅴ. 개선방안
- 중심극한정리: 표본 크기가 커지면 원래 분포에 상관없이 정규 분포에 근사함을 활용함
- 비모수 통계: 특정 분포를 가정하기 어려울 때 데이터 순위 등을 이용함

## Ⅵ. 전망
- 인공지능: 생성 모델(GAN, VAE) 등에서 데이터 분포 학습 및 샘플링의 기초가 됨
- 품질 관리: 6-시그마 등 공정의 안정성을 평가하고 불량을 예측하는 필수 도구임
