## Ⅰ. 개요
- **정의**: 확률 변수가 취할 수 있는 값과 그 확률을 대응시킨 함수로, 데이터의 불확실성을 수학적으로 모델링하는 틀
- **배경/필요성**: 품질 관리·신뢰도 예측·ML 모델 설계에서 데이터 생성 메커니즘을 적절한 분포로 모델링해야 추론이 가능함
- **비유**: 주사위(균일분포)·동전(이항분포)처럼 결과의 확률 구조를 정형화한 설계도

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 3대 분포의 적용 조건 구분 | 정규(연속·대칭), 이항(이산·n회 시행), 포아송(이산·희귀 사건) | 포아송은 이항의 n→∞, p→0 극한임을 언급 |
| 038 베이즈·040 가설검정과의 연결 | 분포 선택이 사전·우도 설정과 검정 통계량 결정에 직결됨 | 분포 자체는 도구이며, 추론은 038·040에서 다룸을 구분 |

> 요약: 정규·이항·포아송 등 확률 분포는 데이터의 불확실성을 모델링하는 수학적 틀임.

## Ⅱ. 구성요소
```text
+----------+     +----------+     +----------+
| 이산분포  |     | 연속분포  |     | 극한관계  |
| (이항,   |     | (정규,   |     | 이항->정규|
|  포아송) |     |  지수)   |     | 이항->포아|
+----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 이항분포 B(n,p) | n회 독립 시행에서 성공 횟수 k의 확률, P(k)=C(n,k)p^k(1-p)^(n-k) | 동전 n번 던져 앞면 수 |
| 포아송분포 Poi(λ) | 단위 시간·공간 내 희귀 사건 발생 횟수, P(k)=e^(-λ)λ^k/k! | 1시간 동안 콜센터 전화 건수 |
| 정규분포 N(μ,σ²) | 평균 μ·분산 σ²인 종 모양 연속 분포, 중심극한정리의 귀결 | 키·시험 점수의 분포 곡선 |

> 요약: 이항(이산·시행) + 포아송(이산·희귀) + 정규(연속·대칭)가 3대 핵심 분포임.

## Ⅲ. 절차
```text
+------------+     +------------+
| 데이터특성  | --> | 분포선택   |
| 파악       |     | (이산/연속)|
+------------+     +------------+
                        |
+------------+     +----+-------+
| 추론/검정   | <-- | 모수추정   |
| (038/040)  |     | (MLE/MoM) |
+------------+     +------------+
```

1. **데이터 특성 파악** — 이산/연속 여부, 대칭성, 사건 발생 빈도 등을 확인함
2. **분포 선택** — 시행 횟수 기반이면 이항, 희귀 사건이면 포아송, 연속·대칭이면 정규를 선택함
3. **모수 추정** — MLE(최대우도추정) 또는 MoM(적률법)으로 μ, σ², n, p, λ 등 모수를 추정함
4. **추론·검정 연결** — 추정된 분포를 038 베이즈(사전·우도)·040 가설검정(검정 통계량)에 적용함

> 요약: 특성 파악 → 분포 선택 → 모수 추정 → 추론 연결로 확률 모델링을 수행함.

## Ⅳ. 문제점
- [분포 오선택]: 데이터 생성 과정과 맞지 않는 분포를 가정하면 추론 결과가 왜곡됨
- [정규성 가정 위배]: 실제 데이터가 치우침·두꺼운 꼬리를 보여 정규분포 가정이 깨지는 경우 빈발
- [모수 추정 편향]: 소표본에서 MLE 추정치가 편향되어 과소·과대 추정이 발생함

> 요약: 분포 오선택·정규성 위배·소표본 편향이 확률 모델링의 주요 문제임.

## Ⅴ. 개선방안
1. 단기: 적합도 검정(χ²·K-S 검정)으로 선택한 분포가 데이터에 적합한지 검증함
2. 중기: 일반화 분포(t분포·감마·음이항)를 적용하여 정규 가정의 한계를 극복함
3. 장기: 비모수 밀도 추정(KDE·Normalizing Flow)으로 특정 분포 가정 없이 데이터 분포를 직접 추정함

- [분포 오선택]: 가정 불일치 → 적합도 검정 + QQ-plot 시각 검증 (지표: K-S p > 0.05)
- [정규성 위배]: 두꺼운 꼬리 → t분포(자유도 낮음) 또는 로그 변환 적용 (지표: 왜도|<2|, 첨도|<7|)
- [소표본 편향]: MLE 편향 → 편향 보정(Firth MLE) 또는 베이지안 추정 적용 (지표: 편향 < SE/10)

> 요약: 적합도 검정·일반화 분포·비모수 추정으로 분포 가정 한계를 극복함.

## Ⅵ. 전망
- 향후 발전 방향: Normalizing Flow·확산 모델(Diffusion) 등 심층 생성 모델이 복잡 분포를 직접 학습하는 방향으로 발전 중
- 기술사적 판단: 3대 분포는 통계·ML·신뢰성 공학의 기초 언어이며, 비모수 기법과 공존하며 지속 활용됨
- 기술사 제언: 039 분포 → 038 베이즈(사전·우도 분포) → 040 가설검정(검정 통계량 분포)의 연결 구조를 체계적으로 학습해야 함
