## 미리 알고가기

- 확률 변수: 무작위 실험 결과를 수치로 표현한 변수임
- 이산 분포: 셀 수 있는 값에 확률을 부여하는 분포임
- 연속 분포: 구간의 면적으로 확률을 계산하는 분포임
- 모수: 분포의 모양과 위치를 정하는 값임
- 확률 질량 함수(PMF): 이산 확률 변수의 각 값에 확률을 대응시키는 함수임
- 확률 밀도 함수(PDF): 연속 확률 변수의 구간 확률을 면적으로 계산하는 함수임
- 누적 분포 함수(CDF): 확률 변수가 특정 값 이하일 누적 확률을 나타내는 함수임
- 분위수 비교 도표(Q-Q 도표): 표본 분위수와 이론 분포 분위수를 비교해 분포 적합성을 확인하는 도표임
- $n,p,\lambda,\mu,\sigma^2$: 각각 시행 횟수, 성공 확률, 발생률, 평균, 분산을 나타내는 분포 모수임

## 작성 근거(검토용)

- 키워드에 정규·이항·포아송이 명시되어 세 분포의 변수 유형·모수·활용 조건을 한 표에 둠
- 특징은 이산·연속 구분과 평균·분산 요약으로 분포 선택의 기본 판단을 먼저 세움
- 구성요소는 PMF·PDF·CDF를 포함해 확률 계산 방식 차이를 드러냄
- 분포의 핵심은 분석 업무 순서가 아니라 변수 유형·생성 조건·모수의 차이이므로 별도 절차를 두지 않고 비교표에서 선택 기준을 설명함
- 포아송 과정 활용과 정규 가정의 꼬리 위험은 분포 검증 필요성을 보여줌

## Ⅰ. 개요

- **정의/개념**: 확률 분포는 확률 변수가 가질 수 있는 값과 그 발생 가능성을 수학적으로 대응시킨 모델임
- **배경/필요성**: 예측·추정·검정·성능 분석의 기준을 세우기 위해 데이터 발생 패턴을 나타내는 확률 분포가 필요함

### 쉽게 이해하기 (학습용)
- 주사위를 수천 번 던지기 전에 어떤 눈이 얼마나 자주 나올지 미리 그려둔 지도와 같음

## Ⅱ. 특징

- 이산 분포는 각 값의 확률을 직접 더해 사건 확률을 구함
- 연속 분포는 특정 값이 아니라 구간 면적으로 확률을 구함
- 분포의 평균과 분산은 중심 위치와 변동성을 요약함
- 실제 데이터는 Q-Q 도표로 분포 가정을 검증해야 함

### 쉽게 이해하기 (학습용)
- 계단처럼 딱딱 끊어 세는 것(이산)과 물이 흐르듯 구간 전체를 재는 것(연속)의 차이이며, 실제 데이터가 예상한 지도와 맞는지는 별도로 대조해봐야 함

## Ⅲ. 종류 및 비교

| 분포 | 변수 유형 | 모수 | 적합 데이터 조건 |
|:---|:---|:---|:---|
| 이항 분포 | 이산 | $n, p$ | 동일 확률의 독립 시행 성공 횟수 |
| 포아송 분포 | 이산 | $\lambda$ | 일정 발생률의 독립 사건 횟수 |
| 정규 분포 | 연속 | $\mu, \sigma^2$ | 다수 독립 변동의 합산 측정값 |

> 요약: 이항은 성공 횟수, 포아송은 발생 건수, 정규는 변동 합을 모델링함.

### 쉽게 이해하기 (학습용)
- 동전을 몇 번 던져 앞면이 몇 번 나오는지 세면 이항, 하루에 전화가 몇 통 오는지 세면 포아송, 여러 사람의 키처럼 자잘한 변수가 쌓여 만들어진 값을 재면 정규 분포에 해당함

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 확률 변수 | 사건 결과의 수치 표현 |
| 기대값 | 분포의 평균 위치 |
| 분산 | 평균 주변의 흩어짐 정도 |
| 확률 함수 | 이산 PMF·연속 PDF |
| 누적 분포 함수 | 특정 값 이하의 누적 확률 |

```text
이산 분포: P(X=x)를 직접 더함
연속 분포: f(x) 아래 면적이 확률임

E[X]   -> 중심 위치
Var[X] -> 퍼짐 정도
```

> 요약: 확률 분포는 확률 함수로 사건 가능성을 계산하고 기대값과 분산으로 중심과 변동을 설명함.

### 쉽게 이해하기 (학습용)
- 결과를 숫자로 바꾸고(확률 변수), 그 숫자들의 평균 자리(기대값)와 흩어진 정도(분산)를 재며, 특정 값까지 다 더한 누적치(누적분포함수)로 정리하는 것과 같음

## Ⅵ. 실무 사례

1. API 플랫폼은 단위 시간당 요청 건수를 포아송 분포로 모델링해 용량 초과 확률을 계산함
2. 장애 관리 시스템은 복구 시간 데이터의 Q-Q 도표를 비교해 맞는 후보 분포를 선택함

### 쉽게 이해하기 (학습용)
- 시간당 몇 번 전화가 올지 미리 예상해 상담원 수를 정하고, 실제 응대 시간이 예상한 분포와 맞는지 대조해서 더 잘 맞는 모델로 바꾸는 것과 같음

## Ⅶ. 결론

- 확률 분포는 데이터 발생을 모델링하므로 변수 유형과 발생 조건에 맞게 선택해야 함
- 선택한 분포를 고정 사실로 취급하지 말고 적합도와 꼬리 초과율을 감시해 용량·경보 임계값을 재조정해야 함

### 쉽게 이해하기 (학습용)
- 한 번 고른 지도를 영원히 믿지 말고, 실제 상황이 지도와 어긋나기 시작하면 지도를 다시 그려야 함
