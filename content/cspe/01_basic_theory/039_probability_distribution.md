## 미리 알고가기

- 확률 변수: 우연 실험의 결과를 수치로 대응시킨 변수임
- 확률 질량 함수: 이산 확률 변수의 각 값에 확률을 부여하는 함수임
- 확률 밀도 함수: 연속 확률 변수의 구간 확률을 적분으로 계산하는 함수임
- 모수: 분포의 모양과 위치를 정하는 평균, 분산, 성공확률, 발생률 같은 값임
- 기대값/분산: 분포의 중심과 흩어짐을 요약하는 대표 통계량임

## Ⅰ. 개요

- **정의**: 확률 분포는 확률 변수가 가질 수 있는 값과 가능성을 함수로 대응시켜 데이터 생성 과정과 추론 기준을 표현하는 모델임
- **배경/필요성**: 품질관리, 장애 예측, A/B 테스트, 머신러닝은 관측값이 우연히 변동한다는 전제를 다루므로 상황에 맞는 분포를 선택해야 모수 추정과 검정 결과가 의미를 가짐.
- **비유**: 주사위, 동전, 콜센터 전화, 사람 키처럼 결과가 어떤 모양으로 흩어지는지 그린 확률 지도와 같음.

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 주요 분포의 적용 조건 구분 | 정규, 이항, 포아송, 이산/연속 | 분포 공식 암기만 제시 |
| 추론과의 연결 이해 | 모수 추정, 우도, 검정 통계량 | 분포와 검정 절차 혼동 |

> 요약: 확률 분포는 불확실한 데이터의 값과 확률 구조를 모델링해 추론과 의사결정의 기준을 제공함.

## Ⅱ. 특징/비교

| 판단 기준 | 이항분포 | 포아송분포 | 정규분포 |
|:---|:---|:---|:---|
| 변수 형태 | n회 독립 시행의 성공 횟수 | 단위 시간·공간의 사건 발생 횟수 | 연속형 측정값 |
| 핵심 모수 | 시행 횟수 n, 성공확률 p | 평균 발생률 lambda | 평균 mu, 분산 sigma^2 |
| 적용 조건 | 성공/실패, 독립, 동일 p | 희귀 사건, 독립 발생, 일정 발생률 | 많은 작은 요인의 합, 대칭 분포 |
| 선택 기준 | 불량품 수, 클릭 수 같은 횟수 | 장애 건수, 도착 건수 같은 발생률 | 키, 오차, 평균 추정 |

> 요약: 분포 선택은 데이터가 횟수인지 측정값인지, 시행 구조와 발생률 조건이 무엇인지에 따라 달라짐.

- **이산 기준**: 값이 셀 수 있는 횟수이면 이항 또는 포아송 같은 확률 질량 함수를 검토함.
- **연속 기준**: 측정값이 연속이고 평균 주변에 대칭적으로 퍼지면 정규분포를 우선 검토함.
- **근사 기준**: n이 크고 p가 작으면 이항분포를 포아송으로, n이 크면 이항분포를 정규로 근사할 수 있음.

```text
+------------+      +------------+      +------------+

+------------+      +------------+      +------------+

| n,p,lambda |      | Mean/Var   |      | Use        |
+------------+      +------------+      +------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 확률 변수 | 우연한 결과를 수치로 표현한 분석 대상임 | 지도 위 위치 표시 |
| 분포 함수 | 값별 확률 또는 구간 확률을 계산하는 규칙임 | 확률 지도 |
| 모수 | 분포의 위치, 흩어짐, 발생률을 결정하는 값임 | 지도 축척 설정 |
| 기대값/분산 | 분포의 중심과 변동성을 요약하는 지표임 | 평균 위치와 퍼짐 |
| 적용 조건 | 독립성, 동일 분포, 희귀성, 연속성 같은 분포 선택 전제임 | 사용 설명서 |

> 요약: 확률 분포는 확률 변수, 분포 함수, 모수, 요약 통계량, 적용 조건이 맞아야 추론 도구로 사용할 수 있음.

## Ⅳ. 절차

```text
+------------+      +------------+      +------------+      +------------+
| Inspect    | ---> | Select     | ---> | Estimate   | ---> | Validate   |
| Data Type  |      | Dist       |      | Params     |      | Fit        |
+------------+      +------------+      +------------+      +------------+
```

1. **데이터 유형 확인**: 값이 이산 횟수인지 연속 측정값인지, 독립 시행인지 발생률 과정인지 확인함.
2. **분포 선택**: 조건에 따라 이항, 포아송, 정규 또는 다른 후보 분포를 선택함.
3. **모수 추정**: 표본 평균, 분산, 최대우도추정 등으로 분포 모수를 계산함.
4. **적합성 검증**: Q-Q plot, 카이제곱 검정, K-S 검정, 잔차 분석으로 분포 가정이 맞는지 확인함.

> 요약: 확률 분포 모델링은 데이터 유형을 확인하고 후보 분포를 고른 뒤 모수를 추정하고 적합성을 검증하는 절차임.

## Ⅴ. 문제점

- **P1 분포 오선택**: 데이터 생성 과정과 다른 분포를 가정하면 확률, 예측 구간, 검정 결과가 왜곡됨.
- **P2 정규성 과신**: 실제 데이터가 비대칭, 두꺼운 꼬리, 이상치를 가지면 정규분포 기반 추론이 부정확해짐.
- **P3 표본 부족**: 표본 수가 작으면 모수 추정의 불확실성이 커지고 적합성 검정의 검정력도 낮아짐.

> 요약: 분포 모델링은 잘못된 가정, 정규성 과신, 표본 부족 때문에 추론 결과의 신뢰성이 떨어질 수 있음.

## Ⅵ. 개선방안

- **P1 대응**: 데이터 생성 과정과 도메인 조건을 먼저 확인하고 여러 후보 분포를 AIC/BIC와 적합도 검정으로 비교함. (확인: 후보 분포 비교표)
- **P2 대응**: 변환, t분포·감마·로그정규 같은 대안 분포, robust 통계를 적용함. (확인: Q-Q plot과 잔차)
- **P3 대응**: 신뢰구간, 베이지안 추정, 부트스트랩으로 표본 불확실성을 명시함. (확인: interval width)

> 요약: 확률 분포는 도메인 기반 후보 설정, 적합도 검증, 불확실성 표시를 통해 가정 오류를 줄여야 함.

## Ⅶ. 전망

- **발전 방향**: 전통 분포는 통계 검정과 신뢰성 분석의 기본으로 유지되고, 복잡 분포는 KDE, Normalizing Flow, 확산 모델로 학습하는 방향이 확대될 전망임.
- **기술사적 판단**: 설명 가능성과 검정 가능성이 중요하면 전통 분포, 복잡한 생성 구조가 중요하면 비모수·딥러닝 분포 모델을 선택해야 함.
- **기술사 제언**: 답안에서는 분포의 공식보다 적용 조건과 추론 연결, 특히 038 베이즈와 040 가설검정의 입력 역할을 강조해야 함.
