## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 확률 분포(Probability Distribution)는 확률 변수가 특정 값을 가질 확률을 나타내는 함수이다. 이산형(이항, 포아송)은 확률 질량 함수(PMF), 연속형(정규, 지수)은 확률 밀도 함수(PDF)로 표현된다. 중심극한정리에 의해 독립 동일 분포의 합은 $N \to \infty$에서 정규 분포에 수렴한다.
> 2. **가치**: A/B 테스트(이항), 서버 장애 예측(포아송), 품질 관리(정규 분포의 $3\sigma$ 규칙), 딥러닝(가중치 초기화 = 정규 분포), 대기열 이론(지수 분포) 등 데이터 기반 의사결정의 수학적 기초이다.
> 3. **융합**: AI(가우시안 프로세스, VAE), 보안(이상 탐지 = 정규 분포에서의 아웃라이어), 네트워크(트래픽 = 포아송), 품질(6시그마 = 정규 분포 기반), 금융(블랙-숄즈 = 로그 정규) 등.

---

### 🔑 핵심 용어 정리

| 용어 | 뜻 | 비유 |
|:---|:---|:---|
| **확률 질량 함수(PMF)** | 이산 확률 변수가 특정 값을 가질 확률. $P(X = k)$ | "주사위 각 눈의 확률" |
| **확률 밀도 함수(PDF)** | 연속 확률 변수의 확률 밀도. $P(a \leq X \leq b) = \int_a^b f(x)\,dx$ | "히스토그램의 매끄러운 곡선" |
| **기대값($\mu = E[X]$)** | 확률 변수의 평균. $\mu = \sum x \cdot P(x)$ 또는 $\int x \cdot f(x)\,dx$ | "무게 중심" |
| **분산($\sigma^2 = \text{Var}(X)$)** | 기대값으로부터의 평균 편차 제곱. $\sigma^2 = E[(X - \mu)^2]$ | "퍼진 정도" |
| **중심극한정리(CLT)** | 독립 동일 분포의 표본 평균은 $N \to \infty$에서 정규 분포에 수렴 | "무엇이든 많이 더하면 종 모양" |
| **$3\sigma$ 규칙** | 정규 분포에서 $\mu \pm 3\sigma$ 범위에 데이터의 99.73%가 포함 | "거의 모든 데이터의 범위" |

## Ⅰ. 개요 및 필요성

- **개념**: 확률 분포는 확률 변수의 가능한 값과 그 확률을 대응시키는 함수이다.

| 분포 | 유형 | 수식 | 파라미터 | 대표 응용 |
|:---|:---|:---|:---|:---|
| **이항($B(n,p)$)** | 이산 | $P(X=k) = \binom{n}{k} p^k (1-p)^{n-k}$ | $n$: 시행 수, $p$: 성공 확률 | A/B 테스트, 불량률 |
| **포아송($\text{Poi}(\lambda)$)** | 이산 | $P(X=k) = \frac{\lambda^k e^{-\lambda}}{k!}$ | $\lambda$: 단위 시간당 평균 횟수 | 서버 요청, 사고 건수 |
| **정규($N(\mu, \sigma^2)$)** | 연속 | $f(x) = \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ | $\mu$: 평균, $\sigma$: 표준편차 | 품질 관리, 키/몸무게 |

- **필요성**: 서버 장애가 1시간에 평균 2건 발생한다면, 다음 1시간에 5건 이상 발생할 확률은? 포아송 분포로 $P(X \geq 5 | \lambda = 2) \approx 3.7\%$임을 계산하여 대비 수준을 결정한다.

- **비유**: 확률 분포는 **"미래의 가능성 지도"**이다. 정규 분포는 평균 근처에 대부분이 모이는 "종 모양 산", 포아송은 "드문 사건이 가끔 터지는 지뢰밭", 이항은 "동전 던지기 N번의 결과표"이다.

```text
+-----------------------------------------------------------------------+
|        세 가지 주요 확률 분포의 모양                                   |
+-----------------------------------------------------------------------+
|                                                                       |
|  [이항 B(10, 0.5)]     [포아송 Poi(3)]      [정규 N(0,1)]            |
|                                                                       |
|       ▃▅█▅▃                █                   ▁▃▅█▅▃▁              |
|     ▁▃▅███▅▃▁            ▃█▅                  ▃█████▃              |
|   ▁▃▅███████▅▃▁        ▃██▅▃▁             ▃███████████▃            |
|  ──────────────      ──────────           ─────────────────          |
|   0 1 2 3 ... 10     0 1 2 3 4 5...      -3  -2  -1  0  1  2  3    |
|                                                                       |
|  ★ 이항: 대칭 종 모양 (p=0.5일 때)                                  |
|  ★ 포아송: 왼쪽 치우침 (λ가 작을 때)                                |
|  ★ 정규: 완벽한 대칭 종 모양 (연속)                                  |
+-----------------------------------------------------------------------+
```

- **📢 섹션 요약 비유**: 이항은 "동전 10번의 결과", 포아송은 "1시간에 오는 전화 수", 정규는 "반 전체 키 분포"입니다.

## Ⅱ. 아키텍처 및 핵심 원리

### 분포 간 관계

$$
B(n, p) \xrightarrow{n \to \infty,\; np \to \lambda} \text{Poi}(\lambda) \xrightarrow{\lambda \to \infty} N(\lambda, \lambda)
$$

- 이항 분포에서 $n$이 크고 $p$가 작으면 포아송으로 근사된다.
- 포아송에서 $\lambda$가 크면 정규로 근사된다.
- **중심극한정리**: 어떤 분포든 독립 표본의 합/평균은 $N$이 충분히 크면 정규 분포에 수렴한다.

### 실무에서의 분포 선택

- **이항**: 성공/실패의 $n$번 반복. A/B 테스트에서 클릭 여부(이항), 전환율 추정.
- **포아송**: 단위 시간/공간당 사건 수. 시간당 서버 오류, 일일 사고 건수.
- **정규**: 연속 측정값. 응답 시간, 센서 데이터, 기기 수명(CLT 적용).

- **📢 섹션 요약 비유**: "동전 던지기"는 이항, "가게에 오는 손님 수"는 포아송, "키와 몸무게"는 정규입니다.

## Ⅲ. 비교 및 연결

### 비교 1: 이항 vs 포아송 vs 정규

| 비교 항목 | 이항 $B(n,p)$ | 포아송 $\text{Poi}(\lambda)$ | 정규 $N(\mu, \sigma^2)$ |
|:---|:---|:---|:---|
| **변수 유형** | 이산 (0~$n$) | 이산 (0~$\infty$) | 연속 ($-\infty$~$\infty$) |
| **파라미터** | $n, p$ | $\lambda$ | $\mu, \sigma$ |
| **기대값** | $np$ | $\lambda$ | $\mu$ |
| **분산** | $np(1-p)$ | $\lambda$ | $\sigma^2$ |
| **적용 조건** | 고정 횟수, 독립 시행 | 드문 사건, 무한 시행 가능 | CLT 적용 또는 자연적 종 모양 |

### 과목 융합 관점
- **딥러닝**: 가중치 초기화는 $N(0, 1/\sqrt{n})$(Xavier) 또는 $N(0, 2/n)$(He) 정규 분포를 사용한다.
- **품질공학**: 6시그마 = 공정 산포가 $\pm 6\sigma$ 이내면 불량률 3.4 PPM(백만 분의 3.4).
- **네트워크**: 트래픽 도착을 포아송 프로세스로 모델링하여 서버 용량을 산정한다.

## Ⅳ. 실무 적용 및 기술사 판단

### 실무 시나리오

1. **시나리오 — SLA 위반 확률 계산**: 서버 응답 시간이 $N(200, 30^2)$ms로 정규 분포를 따를 때, SLA 기준 300ms 초과 확률은 $P(X > 300) = P(Z > 3.33) \approx 0.04\%$이다.

2. **시나리오 — A/B 테스트**: 1,000명에게 버튼 A(전환 50명)와 B(전환 60명)를 보여줬을 때, 이항 분포 기반 z-검정 또는 베이지안 추론으로 B가 유의미하게 나은지 판단한다.

### 안티패턴
- **모든 데이터에 정규 분포 가정**: 소득 분포(로그 정규), 네트워크 장애 간격(지수), 극단값(와이블) 등 정규가 아닌 데이터에 정규를 가정하면 추론이 틀어진다.

## Ⅴ. 기대효과 및 결론

### 정량/정성 기대효과

| 구분 | 분포 모르고 직감 | 적절한 분포 적용 | 개선 효과 |
|:---|:---|:---|:---|
| **정량** | "장애가 많을 것 같다" | 포아송으로 $P(X \geq 5) = 3.7\%$ | **정량적 리스크 산정** |
| **정성** | 과잉/과소 대비 | SLA 달성 확률 99.96% 확인 | **합리적 자원 배분** |

### 참고 표준
- **ISO 3534**: 통계 용어 국제 표준
- **6시그마 (DMAIC)**: 정규 분포 기반 품질 관리 방법론

확률 분포는 "미래의 불확실성을 수학적으로 다루는 도구"이다. 올바른 분포를 선택하면 리스크를 정량화하고, 자원을 합리적으로 배분하며, 데이터 기반 의사결정을 내릴 수 있다.
