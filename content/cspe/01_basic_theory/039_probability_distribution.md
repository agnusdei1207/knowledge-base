## Ⅰ. 개요
- **정의**: 확률 변수가 취할 수 있는 값과 그 확률의 대응 관계를 수학적으로 표현한 함수
- **배경/필요성**: 현실의 불확실성을 정량화하려면 데이터 생성 과정을 확률 모형으로 추상화해야 하며, 분포 선택이 모형의 예측력을 결정함
- **비유**: 주사위 눈금별 확률표가 이산 분포, 다트 과녁의 적중 밀도가 연속 분포에 해당함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 이산·연속 분류와 대표 분포 특성 비교 | 이항·포아송·정규·지수 분포의 파라미터와 적용 조건 | 포아송과 이항의 근사 조건, CLT 전제 조건 누락 |

> 요약: 확률 분포는 불확실성을 모형화하는 기반이며, 이산형과 연속형으로 나뉨

## Ⅱ. 구성요소
```text
           +--- 이산형 ---+--- 이항 분포
           |              +--- 포아송 분포
확률 분포 -+
           |              +--- 정규 분포
           +--- 연속형 ---+--- 지수 분포
                          +--- 균등 분포
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 이항 분포 | 성공 확률 `p`, 시행 횟수 `n`일 때 성공 횟수 `k`의 확률: $P(X=k) = \binom{n}{k} p^k (1-p)^{n-k}$ | 동전 10회 던져 앞면 횟수 |
| 포아송 분포 | 단위 시간·공간당 평균 발생률 `lambda`로 사건 횟수 모형화: $P(X=k) = \frac{\lambda^k e^{-\lambda}}{k!}$ | 1시간 동안 콜센터 수신 건수 |
| 정규 분포 | 평균 `mu`와 표준편차 `sigma`로 결정되는 좌우 대칭 종 모양 밀도 함수 | 학생 키 분포 — 평균 근처에 밀집 |
| 지수 분포 | 포아송 사건 사이 대기 시간의 분포, 파라미터 `lambda` | 버스 도착 간격 |
| 균등 분포 | 구간 내 모든 값이 동일한 확률 밀도를 가짐 | 룰렛 바퀴의 멈춤 위치 |
| 기대값·분산 | 기대값 $E[X]$: 확률 가중 평균, 분산 $Var(X)$: 기대값 주변 퍼짐 정도 | 평균 소득과 소득 편차 |

> 요약: 데이터 생성 메커니즘에 따라 이산형 또는 연속형 분포를 선택하며, 각 분포는 고유 파라미터로 형태가 결정됨

## Ⅲ. 절차
```text
데이터 특성 파악 --> 분포 후보 선정 --> 파라미터 추정 --> 적합도 검증
```
- 1단계: **데이터 특성 파악** — 변수가 이산(횟수)인지 연속(측정값)인지, 범위가 유한인지 판별함
- 2단계: **분포 후보 선정** — 이산이면 이항·포아송, 연속이면 정규·지수·균등 중 조건에 맞는 후보를 선정함
- 3단계: **파라미터 추정** — 최대우도추정(MLE) 등으로 `mu`, `sigma`, `lambda` 등 파라미터를 데이터로부터 산출함
- 4단계: **적합도 검증** — 카이제곱 적합도 검정, Q-Q Plot 등으로 선택 분포와 실제 데이터 간 일치도를 확인함

> 요약: 데이터 성격 → 분포 후보 → 파라미터 추정 → 적합도 검증 순서로 모형을 확정함

## Ⅳ. 문제점
- **분포 오선택**: 데이터 생성 과정 분석 부족 — 이산 데이터에 정규 분포를 적용하면 음수 확률 등 비현실적 추정이 발생함
- **CLT 남용**: 표본 크기가 충분한지 확인하지 않음 — 비대칭 분포에서 소표본(`n` < 30)일 때 정규 근사가 왜곡됨
- **파라미터 과신**: 점추정치만 사용하고 불확실성을 반영하지 않음 — 추정 오차가 하류 의사결정에 전파됨

> 요약: 분포 선택·근사 조건·추정 불확실성 무시가 모형 신뢰도를 저하시킴

## Ⅴ. 개선방안
1. 단기: 탐색적 분석(히스토그램·Q-Q Plot)을 필수 단계로 적용하여 분포 후보를 데이터 기반으로 선정함
2. 중기: 부트스트랩·베이지안 추정(038 참조)을 도입하여 파라미터의 신뢰 구간을 함께 산출함
3. 장기: 비모수 밀도 추정·혼합 분포 모형을 활용하여 단일 분포 가정의 제약을 완화함

> 요약: 시각적 탐색 → 구간 추정 → 비모수·혼합 모형 순서로 분포 모형의 현실 적합성을 높임

## Ⅵ. 전망
- 발전 방향: 딥러닝 기반 정규화 흐름(Normalizing Flow)이 복잡한 분포를 유연하게 학습하는 방향으로 확장됨
- 기술사적 판단: 통계적 모형 선택 역량은 ML 파이프라인의 데이터 전처리·피처 엔지니어링 품질을 좌우함
- 기술사 제언: 가설 검정(040 참조)·회귀 분석(041 참조)과 연계하여 분포 가정의 타당성을 체계적으로 검증할 것을 권고함
