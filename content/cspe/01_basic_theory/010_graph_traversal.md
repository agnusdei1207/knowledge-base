## 미리 알고가기

- 정점(Vertex)과 간선(Edge): 정점은 개체, 간선은 정점 간 연결임
- 너비 우선 탐색(BFS): 시작점에서 거리 0, 1, 2 레벨 순으로 방문함
- 깊이 우선 탐색(DFS): 한 경로를 끝까지 따라간 뒤 분기점으로 되돌아감
- 인접 리스트(Adjacency List): 정점별 실제 이웃만 목록으로 저장하는 표현임
- 무가중치 최단 경로: 모든 간선 비용이 같을 때 간선 수가 가장 적은 경로임
- 사이클(Cycle): 간선을 따라 이동해 출발 정점으로 돌아오는 경로임

## Ⅰ. 개요

- **정의/개념**: 그래프 탐색은 시작 정점에서 간선을 따라 방문하며 도달성·연결 성분·사이클을 판단하는 알고리즘임
- **배경/필요성**: 네트워크 경로, 모듈 의존성, 관계망은 방문 순서가 결과를 바꾸므로 먼저 볼 정점을 정하는 기준이 필요함

## Ⅱ. 특징

- BFS는 같은 거리 레벨을 모두 처리한 뒤 다음 레벨로 확장함
- DFS는 스택에 분기점을 남기고 한 경로를 깊게 확장함
- 방문 상태를 발견 시점에 표시해 중복 삽입과 순환 방문을 막음
- BFS·DFS는 각 정점과 간선을 한 번씩 처리하므로 시간복잡도가 $O(V+E)$임

## Ⅲ. 종류 및 비교

| 판단 기준 | 너비 우선 탐색 (BFS) | 깊이 우선 탐색 (DFS) |
|:---|:---|:---|
| **자료구조** | 큐 ($Queue$) | 스택 ($Stack$) 또는 재귀 ($Recursion$) |
| **방문 순서** | 거리 레벨 순서로 확장 | 한 경로를 끝까지 확장 |
| **보장 결과** | 무가중치 최단 거리 | 완료 순서, 부모 관계 |
| **주요 활용** | 최단 경로, 네트워크 플러딩 | 순환 탐지, 위상 정렬, 미로 탐색 |
| **취약 조건** | 동일 거리 후보 폭증 | 깊은 경로, 재귀 한계 |

> 요약: 거리 중심의 최단 경로가 중요하면 BFS를, 경로의 구조 분석이나 전수 조사가 목적이면 DFS를 선택함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 방문 배열 ($Visited$) | 발견·완료 상태를 기록해 중복 방문과 순환 반복을 막음 |
| 후보 저장소 | 큐 또는 스택으로 다음 처리 정점을 보관하고 방문 순서를 결정함 |
| 인접 정보 | 리스트는 실제 간선, 행렬은 간선 존재 여부를 확인함 |
| 시작점 관리 | 비연결 그래프는 남은 미방문 정점에서 탐색을 다시 시작함 |

```text
[ 탐색 흐름 모델 ]
BFS: Start -> Queue -> Level 0 -> Level 1 -> Level 2
DFS: Start -> Stack/Recur -> Path -> Backtrack -> Next Path
```

## Ⅴ. 원리 및 절차 흐름도

```text
+----------------+     +----------------+     +----------------+     +----------------+     +----------------+
| 시작점 표시    | --> | 후보 정점 추출 | --> | 인접 정점 확인 | --> | 발견 표시/삽입 | --> | 반복/재시작   |
+----------------+     +----------------+     +----------------+     +----------------+     +----------------+
```

1. **시작점 표시**: 시작 정점을 방문 처리하고 후보 저장소에 넣음
2. **후보 추출**: BFS는 먼저 넣은 정점, DFS는 최근 정점을 꺼냄
3. **인접 확인**: 현재 정점의 미방문 이웃을 고름
4. **발견 삽입**: 발견 즉시 방문 표시하고 후보 저장소에 넣음
5. **반복/재시작**: 후보가 남으면 반복하고, 비연결 그래프는 새 시작점을 잡음

## Ⅵ. 실무 적용 및 유의점

1. 대규모 관계망 BFS는 발견 즉시 방문 표시하고 큐 길이·방문 배열 메모리로 확인함
2. 의존성 순환 검사는 반복 DFS로 호출 한계를 막고 방문 상태·최대 깊이로 검증함

## Ⅶ. 결론

- 그래프 탐색은 거리 보장은 BFS, 경로·순환 판단은 DFS를 쓰고 방문 상태와 후보 저장소 크기를 통제함
