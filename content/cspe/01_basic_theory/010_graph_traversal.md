## 미리 알고가기

- 정점과 간선: 그래프를 구성하는 노드와 연결 관계임
- 인접 리스트: 각 정점의 이웃 정점을 저장하는 표현 방식임
- 방문 표시: 중복 방문과 순환 탐색을 막기 위한 상태 기록임

## Ⅰ. 개요

- **정의/개념**: 그래프 탐색은 시작 정점에서 연결 관계를 따라 정점을 체계적으로 방문하는 알고리즘이며, 확산 순서에 따라 너비 우선 탐색과 깊이 우선 탐색으로 나뉨
- **배경/필요성**: 최단 홉 계산, 연결성 판별, 순환 탐지, 위상 구조 분석 같은 그래프 문제는 탐색 방식 선택에 따라 얻을 수 있는 결과와 비용이 달라짐

## Ⅱ. 특징

- BFS는 같은 거리의 정점을 층별로 확장하므로 무가중치 최단 경로에 강함
- DFS는 한 경로를 끝까지 파고들기 때문에 구조적 성질 분석과 백트래킹 문제에 적합함
- 두 방식 모두 인접 리스트 기준 $O(V+E)$이지만, 메모리 사용 패턴과 중간 결과의 의미가 다름
- 탐색 성능보다 더 중요한 차이는 어떤 문제를 직접 풀 수 있느냐는 점임

## Ⅲ. 종류 및 비교

| 판단 기준 | BFS | DFS |
|:---|:---|:---|
| 자료구조 | 큐 | 스택 또는 재귀 |
| 탐색 방향 | 층별 확산 | 경로 우선 하강 |
| 직접 해결 문제 | 무가중치 최단 경로 | 순환 탐지, 위상 정렬 보조 |
| 메모리 특성 | 폭이 넓을수록 큐 증가 | 깊이가 깊을수록 스택 증가 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 시작 정점 | 탐색 기준점이며 연결 컴포넌트 탐색 범위를 정함 |
| frontier | 다음 방문 후보 집합이며 BFS는 큐, DFS는 스택으로 관리함 |
| 방문 배열 | 이미 처리한 정점을 기록하고 순환 그래프에서 필수임 |
| 인접 정보 | 이웃 정점 목록 또는 행렬이며 자료구조에 따라 상수 비용이 달라짐 |

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 시작등록 | --> | 후보추출 | --> | 이웃확장 | --> | 방문완료 |
+----------+     +----------+     +----------+     +----------+
```

1. **시작등록**: 시작 정점을 frontier에 넣고 방문 표시함
2. **후보추출**: BFS는 먼저 들어온 정점, DFS는 마지막 정점을 꺼냄
3. **이웃확장**: 아직 방문하지 않은 이웃을 frontier에 추가함
4. **방문완료**: 더 이상 후보가 없을 때 탐색을 종료함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 방문 표시 시점이 늦어 추출 후 방문 처리하면 같은 정점이 중복 삽입될 수 있음
   - 해결방안: frontier에 넣는 순간 방문 표시하고 중복 삽입 횟수로 검증함
2. 문제: BFS에서 폭이 큰 그래프가 메모리를 압박해 동일 레벨 정점이 폭증하면 큐가 커짐
   - 해결방안: 깊이 제한, 양방향 탐색, 문제 축소 전략을 적용하고 큐 최대 길이로 검증함
3. 문제: DFS 재귀가 깊이 한계를 넘어 편향 그래프에서 호출 깊이가 시스템 제한을 초과할 수 있음
   - 해결방안: 명시적 스택 기반 반복 DFS로 전환하고 최대 깊이 테스트로 검증함

## Ⅶ. 적용 사례

- 네트워크 경로 분석: BFS로 최소 홉 경로를 찾음, 확인 지표는 탐색 시간과 홉 수 정확도임
- 소스 코드 의존성 검사: DFS로 순환 참조를 탐지함, 확인 지표는 사이클 검출률과 분석 시간임
- 게임 맵 탐색: BFS 또는 DFS를 문제 성격에 따라 선택함, 확인 지표는 경로 길이와 메모리 사용량임

## Ⅷ. 결론

그래프 탐색의 선택 기준은 복잡도보다 결과 의미에 있으므로, 거리 보장이 필요하면 BFS를, 구조 분석과 가지치기가 중요하면 DFS를 선택해야 함.
