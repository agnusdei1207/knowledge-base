# 그래프 탐색 - BFS·DFS (Graph Traversal)

## 1. 정의 및 개념

그래프 탐색은 정점(Vertex)과 간선(Edge)으로 표현된 관계 구조에서 시작 정점으로부터 도달 가능한 정점, 경로, 연결 요소, 사이클 등을 찾는 알고리즘이다.

| 구분 | 정의 | 사용 자료구조 |
|---|---|---|
| **BFS(Breadth-First Search)** | 시작점에서 가까운 정점부터 레벨 단위로 탐색 | 큐(Queue) |
| **DFS(Depth-First Search)** | 한 경로를 끝까지 탐색한 후 되돌아오는 방식 | 스택(Stack), 재귀 |
| **방문 표시** | 이미 방문한 정점을 기록하는 상태 관리 | visited 배열, 색상 상태 |

그래프는 사이클과 다중 경로가 존재하므로 방문 표시가 없으면 무한 반복이나 중복 처리가 발생할 수 있다.

## 2. BFS와 DFS 비교

| 구분 | BFS | DFS |
|---|---|---|
| 탐색 순서 | 가까운 정점부터 층별 탐색 | 가능한 경로를 깊게 탐색 |
| 자료구조 | 큐 | 스택 또는 재귀 |
| 시간복잡도 | 인접 리스트 기준 `O(V+E)` | 인접 리스트 기준 `O(V+E)` |
| 공간 특성 | 넓은 그래프에서 큐 증가 | 깊은 그래프에서 스택 증가 |
| 주요 활용 | 무가중 최단 거리, 레벨 탐색 | 사이클 탐지, 위상 정렬, 백트래킹 |

BFS와 DFS는 시간복잡도가 같아도 산출물의 의미가 다르므로 문제 요구사항에 따라 선택해야 한다.

## 3. 그래프 표현 방식

| 표현 | 공간복잡도 | 탐색 특성 | 적합한 경우 |
|---|---:|---|---|
| **인접 리스트** | `O(V+E)` | 연결된 간선만 순회 | 희소 그래프 |
| **인접 행렬** | `O(V²)` | 간선 존재 확인 빠름 | 조밀 그래프 |
| **압축 희소 행렬** | `O(V+E)` | 대규모 희소 그래프 처리 | 그래프 분석, 수치 계산 |
| **비트셋 행렬** | `O(V²)` bit | 집합 연산 빠름 | 조밀 그래프 최적화 |

그래프 탐색 복잡도는 알고리즘뿐 아니라 그래프 표현 방식에 따라 달라진다.

## 4. 응용 분야

**BFS**
- 무가중 그래프 최단 경로
- 네트워크 hop 수 계산
- 웹 크롤링의 레벨 탐색
- 소셜 네트워크 거리 분석
- 퍼즐·상태 공간의 최소 이동 횟수 탐색

**DFS**
- 사이클 탐지
- 위상 정렬
- 연결 요소 및 강한 연결 요소 분석
- 백트래킹, 조합 탐색
- 미로 탐색, 경로 존재 여부 확인

## 5. 심화 이슈 (기술사 포인트)

1. **방문 표시 시점**
   - 큐·스택에 넣을 때 방문 표시를 해야 중복 후보 삽입을 줄일 수 있다.

2. **BFS 최단 경로 조건**
   - BFS는 무가중 그래프에서 최단 간선 수를 보장하며, 가중 그래프는 다익스트라·벨만-포드가 필요하다.

3. **DFS 재귀 스택 문제**
   - 깊은 그래프에서는 재귀 스택 초과가 발생할 수 있어 반복 구현이 필요하다.

4. **방향 그래프 사이클 탐지**
   - 단순 visited만으로 부족할 수 있어 white/gray/black 색상 상태 또는 재귀 스택 상태를 사용한다.

5. **대규모 그래프 처리**
   - 소셜 그래프, 지식 그래프에서는 병렬 BFS, 분산 그래프 처리, 프론티어 압축이 필요하다.

## 6. 결론

그래프 탐색은 관계 구조에서 도달성, 경로, 연결성, 사이클을 분석하는 기본 알고리즘이다. 기술사 답안에서는 BFS·DFS의 자료구조와 방문 순서뿐 아니라 그래프 표현, 방문 표시, 무가중/가중 조건, 메모리 폭증 문제까지 함께 설명해야 한다.
