## 미리 알고가기

- 정점(Vertex)과 간선(Edge): 그래프의 구성 단위로, 개체(정점)와 그들 사이의 연결 관계(간선)를 나타냄
- 너비 우선 탐색(BFS): 시작 정점으로부터 가까운 정점을 먼저 모두 방문한 후 멀리 있는 정점을 탐색하는 방식임
- 깊이 우선 탐색(DFS): 한 방향으로 갈 수 있는 끝까지 탐색한 후, 더 이상 갈 곳이 없으면 복귀하여 다른 경로를 찾는 방식임
- 인접 리스트(Adjacency List): 각 정점과 연결된 이웃 정점들만 목록으로 관리하여 메모리 효율을 높인 그래프 표현 방식임

## Ⅰ. 개요

- **정의/개념**: 그래프 탐색은 시작 정점에서 간선을 따라 모든 정점을 체계적으로 방문하며 도달 가능성, 최단 경로, 연결 성분, 사이클 유무 등을 분석하는 알고리즘임
- **배경/필요성**: 사회 관계망 분석, 네트워크 라우팅, 모듈 의존성 파악 등 복잡한 데이터 연결 구조에서 특정 대상을 찾거나 구조적 특징을 식별하기 위해 데이터 방문 순서를 결정할 명확한 기준이 필요함

## Ⅱ. 특징

- BFS는 시작점에서 층($Level$)별로 탐색을 확장하므로, 모든 간선의 가중치가 동일할 때 시작 정점으로부터 특정 정점까지의 최소 간선 수(무가중치 최단 경로)를 보장함
- DFS는 경로의 끝까지 깊게 파고드는 특성상 스택 프레임을 통해 경로 이력을 유지하므로, 그래프 내 사이클($Cycle$) 탐지나 위상 정렬 보조, 백트래킹 기반의 전수 조사에 유리함
- 인접 리스트로 구현 시 두 방식 모두 정점($V$)과 간선($E$)을 각각 한 번씩 확인하므로 $O(V+E)$의 시간복잡도를 가지며, 정점 수가 많고 간선이 적은 희소 그래프($Sparse$ $Graph$)에서 효율적임

## Ⅲ. 종류 및 비교

| 판단 기준 | 너비 우선 탐색 (BFS) | 깊이 우선 탐색 (DFS) |
|:---|:---|:---|
| **자료구조** | 큐 ($Queue$) | 스택 ($Stack$) 또는 재귀 ($Recursion$) |
| **방문 방식** | 형제 노드 우선 (가까운 순) | 자식 노드 우선 (깊은 순) |
| **주요 장점** | 무가중치 최단 경로 보장 | 경로 특징 보존, 백트래킹 가능 |
| **주요 활용** | 최단 거리, 네트워크 플러딩 | 사이클 탐지, 위상 정렬, 미로 찾기 |
| **공간 오버헤드** | 인접 노드 수가 많으면 큐 비대화 | 그래프가 깊으면 재귀 스택 비대화 |

> 요약: 거리 중심의 최단 경로가 중요하면 BFS를, 경로의 구조 분석이나 전수 조사가 목적이면 DFS를 선택함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 방문 배열 ($Visited$) | 이미 방문한 정점을 기록하여 무한 루프와 중복 연산을 방지하는 핵심 체크 리스트임 |
| 대기 자료구조 | 다음 탐색 후보 정점을 관리하는 저장소로, 구조($Queue$ vs $Stack$)에 따라 탐색 순서가 결정됨 |
| 인접 정보 매핑 | 현재 정점에서 이동 가능한 이웃 정점들을 조회하는 참조 구조(행렬 또는 리스트)임 |
| 탐색 종료 조건 | 모든 정점을 방문했거나 대기 자료구조가 비어 더 이상 갈 곳이 없을 때 제어를 멈추는 규칙임 |

```text
[ 탐색 흐름 모델 ]
BFS: (Start) -> Q.push -> Q.pop -> Visit Neighbors -> Q.push ... (층별확장)
DFS: (Start) -> Recur -> Visit -> Recur Neighbors -> Return ... (경로추적)
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 시작점 설정  | --> | 후보군 추출   | --> | 방문 및 표시  | --> | 인접 정점 전이|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **시작 설정** — 탐색을 시작할 정점을 대기 자료구조($Queue/Stack$)에 넣고 방문 표시를 완료함
2. **후보 추출** — 자료구조에서 정점을 하나 꺼내 현재 방문 중인 기준 정점으로 확정함
3. **이웃 탐색** — 기준 정점과 연결된 모든 인접 정점을 순회하며, 아직 방문하지 않은 정점이 있는지 확인함
4. **전이/반복** — 발견된 미방문 정점을 대기 자료구조에 넣고 방문 표시를 한 뒤, 자료구조가 빌 때까지 위 과정을 반복함

## Ⅵ. 실무 적용 및 유의점

1. 방문 표시($Visited$ $Check$)는 자료구조에서 꺼낼 때가 아니라 넣을 때 수행해야 동일 정점이 중복해서 대기열에 쌓이는 성능 저하를 방지할 수 있으며, 정점 수가 매우 많은 경우 비트마스크($Bitmask$) 등을 활용해 메모리를 절약해야 함
2. 대규모 서비스의 의존성 그래프나 매우 깊은 경로를 탐색할 때 DFS 재귀 방식을 사용하면 시스템 호출 스택 한계를 초과($StackOverflow$)할 수 있으므로, 명시적 스택을 사용하는 반복문 기반의 DFS로 구현하고 타임아웃 설정을 통해 무한 탐색을 방지해야 함

## Ⅶ. 결론

- 그래프 탐색은 연결된 세계의 구조를 해석하는 가장 기초적이고 강력한 도구이며, 설계자는 탐색의 목적이 최단 거리 확보인지 혹은 전체 경로의 검증인지를 명확히 구분하여 BFS와 DFS 중 최적의 알고리즘을 적용해야 함
