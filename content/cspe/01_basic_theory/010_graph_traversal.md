## 미리 알고가기

- 정점(Vertex)과 간선(Edge): 그래프의 구성 단위로, 개체(정점)와 그들 사이의 연결 관계(간선)를 나타냄
- 너비 우선 탐색(BFS): 시작 정점으로부터 가까운 정점을 먼저 모두 방문한 후 멀리 있는 정점을 탐색하는 방식임
- 깊이 우선 탐색(DFS): 한 방향으로 갈 수 있는 끝까지 탐색한 후, 더 이상 갈 곳이 없으면 복귀하여 다른 경로를 찾는 방식임
- 인접 리스트(Adjacency List): 각 정점과 연결된 이웃 정점들만 목록으로 관리하여 메모리 효율을 높인 그래프 표현 방식임
- 무가중치 최단 경로: 모든 간선 비용이 같을 때 시작 정점에서 목표 정점까지 거치는 간선 수가 가장 적은 경로임
- 사이클(Cycle): 한 정점에서 출발해 간선을 따라 이동한 뒤 다시 같은 정점으로 돌아오는 경로임

## Ⅰ. 개요

- **정의/개념**: 그래프 탐색은 시작 정점에서 간선을 따라 도달 가능한 정점을 체계적으로 방문하고, 필요 시 미방문 정점을 새 시작점으로 반복해 도달 가능성, 연결 성분, 사이클 등을 분석하는 알고리즘임
- **배경/필요성**: 사회 관계망 분석, 네트워크 라우팅, 모듈 의존성 파악 등 복잡한 데이터 연결 구조에서 특정 대상을 찾거나 구조적 특징을 식별하기 위해 데이터 방문 순서를 결정할 명확한 기준이 필요함

## Ⅱ. 특징

- BFS는 시작점에서 거리 수준별로 탐색을 확장하므로, 무가중치 또는 동일 가중치 그래프에서 최소 간선 수 기준 최단 경로를 보장함
- DFS는 호출 스택 또는 명시적 스택으로 되돌아갈 분기점을 유지하므로, 사이클 탐지, 위상 정렬, 백트래킹 기반 전수 조사에 적합함
- 인접 리스트를 쓰면 두 방식 모두 시간복잡도는 $O(V+E)$이며, 인접 행렬의 $O(V^2)$ 순회보다 희소 그래프에서 불필요한 간선 확인을 줄일 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | 너비 우선 탐색 (BFS) | 깊이 우선 탐색 (DFS) |
|:---|:---|:---|
| **자료구조** | 큐 ($Queue$) | 스택 ($Stack$) 또는 재귀 ($Recursion$) |
| **방문 방식** | 시작점 거리 순으로 확장 | 한 경로를 끝까지 확장 후 되돌아감 |
| **주요 장점** | 무가중치 최단 경로 보장 | 경로 특징 보존, 백트래킹 가능 |
| **주요 활용** | 최단 거리, 네트워크 플러딩 | 사이클 탐지, 위상 정렬, 미로 찾기 |
| **공간 오버헤드** | 동일 거리 후보가 많으면 큐 길이 증가 | 경로가 깊으면 호출 스택 또는 명시적 스택 증가 |

> 요약: 거리 중심의 최단 경로가 중요하면 BFS를, 경로의 구조 분석이나 전수 조사가 목적이면 DFS를 선택함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 방문 배열 ($Visited$) | 방문 완료 또는 발견 상태를 기록해 중복 방문과 순환 탐색을 방지하는 상태 저장 구조임 |
| 대기 자료구조 | 다음 탐색 후보 정점을 관리하는 저장소로, 구조($Queue$ vs $Stack$)에 따라 탐색 순서가 결정됨 |
| 인접 정보 매핑 | 현재 정점에서 이동 가능한 이웃 정점들을 조회하는 참조 구조(행렬 또는 리스트)임 |
| 탐색 종료 조건 | 대기 자료구조가 비면 시작점에서 도달 가능한 영역의 탐색을 종료하고, 전체 그래프 분석은 남은 미방문 정점을 새 시작점으로 반복함 |

```text
[ 탐색 흐름 모델 ]
BFS: (Start) -> Mark/Q.push -> Q.pop -> Visit Neighbors ... (층별확장)
DFS: (Start) -> Mark -> Push/Recur Neighbor -> Backtrack ... (경로추적)
```

## Ⅴ. 원리 및 절차 흐름도

```text
+----------------+     +----------------+     +----------------+     +----------------+
| 시작점 표시    | --> | 후보 정점 추출 | --> | 인접 정점 확인 | --> | 발견 표시/삽입 |
+----------------+     +----------------+     +----------------+     +----------------+
```

1. **시작점 표시** — 탐색을 시작할 정점을 방문 상태로 표시하고 대기 자료구조($Queue/Stack$)에 넣어 초기 후보를 구성함
2. **후보 정점 추출** — 자료구조에서 정점을 하나 꺼내 현재 처리 중인 기준 정점으로 확정함
3. **인접 정점 확인** — 기준 정점과 연결된 모든 이웃 정점을 순회하며 미방문 여부를 확인함
4. **발견 표시/삽입** — 발견된 미방문 정점을 즉시 표시하고 대기 자료구조에 넣은 뒤, 자료구조가 빌 때까지 반복함

## Ⅵ. 실무 적용 및 유의점

1. 대규모 그래프에서는 발견 시점에 방문 표시를 수행해 중복 enqueue를 막고, 정점 ID를 조밀하게 매핑할 수 있으면 비트셋으로 저장하며 큐 길이, 중복 삽입 수, 방문 배열 메모리로 적합성을 확인해야 함
2. 깊은 의존성 그래프에서는 재귀 DFS가 언어 런타임의 호출 스택 한계를 넘을 수 있으므로 반복 DFS로 전환하고, 방문 상태·최대 깊이·실행 시간 제한으로 순환과 장기 실행을 통제해야 함

## Ⅶ. 결론

- 그래프 탐색은 거리 보장이 필요하면 BFS를, 경로 구조·순환·분기 검증이 필요하면 DFS를 선택하고 방문 상태와 대기 자료구조 크기를 함께 통제해야 함
