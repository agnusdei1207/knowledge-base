# 📖 【암기용】 개념 완전 이해

## 한눈에
- **개요**: 그래프 탐색은 **정점(Vertex)과 간선(Edge)으로 얽힌 비선형 구조의 모든 정점을 사이클에 갇히지 않고 한 번씩 방문하는 알고리즘**으로, 넓게 퍼지는 BFS(너비 우선)와 깊게 파는 DFS(깊이 우선)로 나뉜다.
- **왜 필요한가**: 도로망·SNS·라우팅망처럼 노드끼리 둥글게 연결돼 사이클이 있는 구조는, 방문 규칙과 방문 기록이 없으면 같은 정점을 무한 반복해 영원히 못 빠져나오기 때문이다.
- **핵심 직관**: 미로 찾기다. 한 갈림길에서 **한 길을 끝까지 파고 막히면 되돌아오면 DFS**(외길 파기·스택), 갈림길마다 분신해 **모든 길을 한 칸씩 동시에 넓히면 BFS**(물결 퍼지기·큐)다.

## 핵심 용어 정리 (내부에 등장하는 것들)

답안용 표·흐름도에 나오는 그래프 표현·복잡도 표기를 먼저 세운다(정점·간선을 여기서 정의하며, 이 표현은 011·012가 참조한다). 맨 위는 상위 핵심 키워드다.

| 용어/표기 | 의미 | 비유·예 |
|:---|:---|:---|
| 그래프 탐색 (상위 키워드) | 모든 정점을 사이클 없이 한 번씩 방문 | 미로의 모든 방을 빠짐없이 둘러보기 |
| 정점(Vertex, V) / 간선(Edge, E) | 그래프를 이루는 점(개체) / 점을 잇는 선(관계) | 지하철역(정점)과 철로(간선) |
| 인접 행렬(Adjacency Matrix) | V×V 2차원 배열, `M[i][j]=1`이면 i-j 연결 | 좌석표: 두 사람이 이웃이면 칸에 1 표시 |
| 인접 리스트(Adjacency List) | 정점마다 연결된 이웃만 목록으로 보관 | 각 사람의 친구 명단만 따로 적기 |
| 방문 배열(Visited) | 이미 지난 정점을 기록해 재방문·무한루프 차단 | 미로에 떨어뜨린 빵부스러기 |
| 스택(Stack, LIFO) | 나중에 넣은 것을 먼저 꺼냄, DFS의 뼈대(007 참조) | 접시를 위로 쌓았다 위부터 꺼내기 |
| 큐(Queue, FIFO) | 먼저 넣은 것을 먼저 꺼냄, BFS의 뼈대(007 참조) | 매표소 줄, 먼저 온 사람 먼저 |
| 사이클(Cycle) | 출발 정점으로 되돌아오는 순환 경로 | A→B→C→A로 돌아 제자리 |
| O(V+E) | 정점 수 + 간선 수에 비례하는 시간(의미는 001·002 참조) | 역 수 + 철로 수만큼 훑는 비용 |

## 깊이 이해
- **배경·문제의식**: 트리(008·009)는 위에서 아래로만 흐르고 사이클이 없어 아무렇게나 내려가도 끝난다. 그러나 그래프는 **정점끼리 되돌아오는 사이클**이 있어, 규칙 없이 돌면 A→B→A로 무한 반복한다. 그래서 방문 배열(기록)과 스택·큐(순서 통제)를 결합한 탐색 기법이 확립됐다.
- **작동 원리 (어떻게+왜)**:
  - **DFS(스택/재귀)**: 현재 정점에서 갈 수 있는 이웃 하나로 **끝까지 파고든다**. 막히면 스택에서 꺼내(Pop) 직전 갈림길로 되돌아온다(백트래킹). 경로 하나만 기억하므로 메모리가 적다.
  - **BFS(큐)**: 시작 정점의 이웃(1촌)을 모두 큐에 넣고(Enqueue), 넣은 순서대로 꺼내며 그 이웃의 이웃(2촌)을 넣는다. **가까운 층부터** 방문하므로, 가중치 없는 그래프에서 처음 닿은 목표가 곧 최단 거리다.
  - 그래프 표현이 성능을 가른다: 이웃을 훑는 작업이 인접 리스트는 실제 간선만, 인접 행렬은 V개 전부를 보므로, 간선이 적은 희소(Sparse) 그래프는 리스트가 유리하다.
- **비유**: SNS에서 지인 찾기. DFS는 친구 A→A의 친구→그 친구… 지구 반대편까지 한 줄로 파고든다. BFS는 내 친구 전원을 먼저 훑고, 그다음 건너 지인을 층별로 넓힌다.
- **구체 예시(수치·사례)**: 정점 6·간선 7인 그래프를 탐색하면 둘 다 O(V+E)=O(13)로 시간은 같다. 다만 내비 최단 경로(가중치 없음)는 BFS라야 하며, DFS로 하면 부산 가는데 러시아를 찍고 오는 우회로를 먼저 잡을 수 있다. 인접 행렬은 V=1만이면 1억 칸(간선 유무 무관)을 잡아 메모리가 커진다.
- **흔한 오해·주의점**:
  - **"BFS가 무조건 낫다"는 오해**다. 최단 거리엔 BFS지만, 브랜칭이 큰 그래프는 큐에 이웃이 수억 개 쌓여 메모리가 터진다(OOM). 반면 DFS는 경로 하나만 기억해 체스·백트래킹(016)에 적합하다.
  - **Visited 마킹 시점**은 큐·스택에 넣는 순간이어야 한다. 꺼낼 때 마킹하면 같은 정점이 중복 적재된다.
  - BFS의 최단 거리 보장은 **간선 가중치가 모두 같을 때만**이다. 가중치가 다르면 다익스트라(011)가 필요하다.

## 연결 개념
- **스택·큐 (007)**: DFS는 스택(재귀 콜 스택 포함), BFS는 큐를 뼈대로 사용하는 구현 근간.
- **최단 경로 (011)**: BFS를 가중치 그래프로 확장한 다익스트라·벨만-포드가 이어짐.
- **백트래킹 (016)**: DFS로 상태 공간을 파고들다 조건 위반 시 되돌아오는 완전 탐색 최적화.

# 📝 【답안용】 시험 답안 템플릿

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 그래프 탐색은 사이클 있는 비선형 구조에서 방문 배열로 무한루프를 막고 모든 정점을 한 번씩 순회하는 알고리즘임.
> 2. **가치**: BFS는 가중치 없는 최단 경로·레벨 탐색을, DFS는 완전 탐색·백트래킹·사이클 검출을 각각 가능케 함.
> 3. **판단 포인트**: 최단 거리·레벨 탐색이면 큐 기반 BFS, 완전 탐색·적은 메모리면 스택 기반 DFS를 택하는 트레이드오프가 핵심임.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 탐색-자료구조 매핑 이해 | DFS-스택/재귀, BFS-큐 매핑과 동작 | 기반 자료구조 명시 누락 |
| 사이클 무한루프 방지 인지 | Visited 배열의 필수 역할과 마킹 시점 | 트리·그래프의 사이클 차이 누락 |
| 시나리오별 선택 기준 | 가중치 없는 최단경로(BFS)·완전탐색(DFS) | 한 방식이 절대 빠르다고 단정 |

> 요약: 스택·큐 차이가 탐색 방향(깊이 vs 너비)을 결정하고, Visited로 사이클을 막으며 용도별로 취사선택함을 짚어야 함.

## Ⅰ. 개요 및 필요성
- 개요: 정점·간선으로 된 비선형 그래프의 모든 정점을 규칙에 따라 한 번씩 방문하는 순회 알고리즘임
- 배경: 트리와 달리 그래프는 사이클이 있어 무작위 탐색 시 무한 루프에 빠지는 결함이 존재함
- 필요성: 라우팅망·SNS 등 얽힌 네트워크에서 방문 배열로 순환을 막고 최단 경로(BFS)·완전 탐색(DFS)을 수행해야 함

## Ⅱ. 구조 및 구성요소
선형 구조도 (탐색 공통 골격):

    시작 정점 진입 -> Visited 마킹 -> 이웃 정점 검색 -> 대기 자료구조 보관/추출 -> 다음 정점 이동
      / DFS : 스택(LIFO) -> 최신 이웃 우선 -> 한 갈래 깊게 파기
      / BFS : 큐(FIFO)  -> 오래된 이웃 우선 -> 가까운 층부터 넓히기
    그래프 표현 : 인접 행렬(V×V) 또는 인접 리스트(이웃 목록)

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 그래프 표현 | 정점·간선을 인접 행렬/리스트로 저장 | 희소 그래프는 리스트가 메모리 유리 |
| 방문 배열(Visited) | 재방문·무한루프 차단 | 자료구조에 넣는 순간 마킹 |
| 스택(DFS) | 최신 이웃 우선, 깊이 방향 확장 | 재귀 콜 스택으로 대체 가능 |
| 큐(BFS) | 오래된 이웃 우선, 너비 방향 확장 | 가중치 동일 시 최단 거리 보장 |

> 요약: 표현(행렬/리스트) 위에서 Visited로 순환을 막고, 스택이면 깊이·큐면 너비로 탐색 방향이 갈림.

## Ⅲ. 동작원리 및 흐름도
선형 흐름도 (BFS 기준):

    시작 정점 큐 삽입/마킹 -> 큐에서 1개 추출 -> 미방문 이웃 전부 큐 삽입/마킹 -> 큐가 빌 때까지 반복

1. 상태 저장: 탐색기가 정점을 자료구조에 넣는 순간 Visited를 True로 마킹해 재진입을 차단함
2. 스캔 분기: DFS는 첫 미방문 이웃으로 즉시 재귀 하강, BFS는 모든 미방문 이웃을 큐 뒤에 적재함
3. 진행·복귀: DFS는 막히면 스택을 되짚어 직전 갈림길로 백트래킹, BFS는 큐 순서대로 다음 층으로 확산함
4. 종료: 목표 정점 발견 또는 자료구조가 완전히 비면 종료하며 시간은 O(V+E)로 동일함

> 요약: 넣는 순간 Visited 마킹 후, DFS는 백트래킹으로 깊게·BFS는 레벨 확산으로 넓게 돌며 O(V+E)에 끝냄.

## Ⅳ. 특징
- 시간 동일성: 두 방식 모두 정점 V·간선 E를 1회씩 검사해 O(V+E)로 시간 복잡도가 같음
- 메모리 대조: DFS는 경로 깊이만큼 스택 소모(적음), BFS는 한 레벨 정점 수만큼 큐 소모(많음·OOM 위험)
- 최단 거리 보장: BFS는 가중치가 모두 같은 그래프에서 처음 닿은 목표가 최단 거리임을 보장함
- 표현 의존성: 인접 리스트는 실제 간선만 훑어 희소 그래프에 유리, 인접 행렬은 이웃 확인이 O(1)이나 V² 공간 소모
- 용도 분기: BFS는 최단 경로·레벨 탐색, DFS는 완전 탐색·사이클 검출·위상 정렬 기반으로 갈림

## Ⅴ. 심화 비교 및 적용 판단

기반 자료구조·메모리·최단 거리·용도 축에서 두 탐색을 대조함(그래프 표현 비교는 위 용어 정리 참조).

| 구분 | DFS (깊이 우선) | BFS (너비 우선) |
|:---|:---|:---|
| 기반 자료구조 | 스택(LIFO)·재귀 | 큐(FIFO) |
| 탐색 방향/메모리 | 좁고 깊게 / 경로 깊이만큼(적음) | 넓고 얕게 / 레벨 정점 수만큼(많음) |
| 최단 거리 | 불가(우회로 선점 가능) | 가중치 동일 시 보장 |
| 대표 용도 | 완전 탐색·백트래킹·사이클 검출 | 최단 경로·레벨/근접 탐색 |

> 요약: 최단 거리·근접 탐색이면 BFS, 완전 탐색·적은 메모리·사이클 검출이면 DFS가 적합함.

**리스크·대응:**
- BFS 큐 메모리 고갈 — 브랜칭 큰 그래프에서 레벨당 정점 폭증 → 출발·도착 양방향 탐색으로 O(b^(d/2))로 감축
- 무한 루프 — Visited 마킹 누락으로 A→B→A 재진입 → 자료구조 삽입 시점에 마킹을 원자적으로 강제
- 스택 오버플로 — 깊은 그래프에서 재귀 DFS 깊이 초과 → 명시적 스택 반복형으로 전환

**점검 지표:**
- 정확성 — 방문 정점 수 = 전체 정점 수 V — 탐색 후 Visited 카운트 대조
- 효율 — 자료구조 최대 적재량 — 힙 덤프로 큐/스택 피크 사이즈 측정

## Ⅵ. 실무 적용 및 결론

**적용 방안:**
1. 네트워크 최단 경로(BFS): OSPF 등 동일 비용 간선망 최단 홉 계산, P2P 망의 최근접 시드 피어 탐색에 큐 기반 BFS 적용
2. 교착상태 검출(DFS): OS·RDBMS 커널의 자원 대기 그래프(Wait-for Graph)에 DFS를 돌려 순환(Cycle) 발견 시 해당 트랜잭션 강제 종료
3. 완전 탐색·보안 점검(DFS 백트래킹): 퍼즐 AI·자동 취약점 스캐너가 한 침투 경로를 끝까지 파고 복귀하는 방식으로 메모리 절약 탐색 수행

**결론:**
- 기술사 판단: 최단 거리·근접성이 목표면 BFS, 방대한 상태 공간을 좁은 메모리로 완주하려면 DFS 백트래킹을 택하는 조건부 선택이 유효함
- 향후 방향: 단순 완전 탐색을 넘어 목표 방향 휴리스틱으로 큐를 제어하는 A* 등 지능형 탐색으로 고도화되고 있음
