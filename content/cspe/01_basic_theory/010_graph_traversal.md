# 그래프 탐색 - BFS·DFS (Graph Traversal)

## 1. 개요

- **정의/개념**: 그래프 탐색은 정점과 간선으로 표현된 관계 구조에서 방문 규칙을 정해 도달성, 경로, 연결 요소, 사이클을 찾는 알고리즘이다.
- **배경/필요성**: 그래프는 사이클과 다중 경로가 존재하므로 방문 표시 없이 탐색하면 무한 반복이나 중복 처리가 발생할 수 있다.

## 2. 특징 및 비교

| 구분 | BFS | DFS |
|---|---|---|
| 탐색 순서 | 가까운 정점부터 레벨 단위 탐색 | 한 경로를 깊게 탐색 후 복귀 |
| 자료구조 | 큐 | 스택 또는 재귀 |
| 시간복잡도 | 인접 리스트 기준 `O(V+E)` | 인접 리스트 기준 `O(V+E)` |
| 공간 위험 | 넓은 그래프에서 큐 증가 | 깊은 그래프에서 스택 증가 |
| 주요 활용 | 무가중 최단 거리, 레벨 탐색 | 사이클 탐지, 위상 정렬, 백트래킹 |

BFS와 DFS는 시간복잡도가 같아도 방문 순서와 산출물이 다르므로 요구사항으로 선택해야 한다.

그래프 탐색 선택은 최단 간선 수 필요 여부, 그래프 폭과 깊이, 표현 방식, 가중치 존재, 방문 상태 관리 기준으로 판단한다.

이 판단은 큐·스택 후보 구조와 방문 표시가 어떤 순서로 정점을 확장하는지에서 드러난다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| 정점(Vertex) | 탐색 대상 객체 | 노드 수 `V` |
| 간선(Edge) | 정점 간 관계 | 간선 수 `E` |
| 인접 표현 | 인접 리스트, 인접 행렬 등 | 탐색 비용 결정 |
| 방문 표시 | 방문 여부 기록 | 중복·무한 반복 방지 |
| 후보 구조 | BFS 큐, DFS 스택 | 방문 순서 제어 |

```text
시작 정점 -> 방문 표시 -> 큐/스택 처리 -> 인접 정점 확장 -> 결과 반환
```

이 흐름에서 방문 표시, 그래프 표현, 가중치 전제가 맞지 않으면 탐색 결과의 의미가 달라진다.

## 4. 문제점 및 개선방안

1. **방문 표시 누락**
   - 사이클이 있는 그래프에서 무한 반복이나 중복 처리 폭증이 발생한다.
   - **개선방안**: 후보 구조에 넣는 시점에 방문 표시를 수행한다.

2. **가중 그래프 오적용**
   - BFS는 무가중 그래프의 최단 간선 수만 보장한다.
   - **개선방안**: 가중 그래프는 다익스트라, 벨만-포드 등 최단 경로 알고리즘을 사용한다.

3. **그래프 표현 부적합**
   - 희소 그래프에 인접 행렬을 쓰면 `O(V²)` 공간 낭비가 크다.
   - **개선방안**: 간선 밀도에 따라 인접 리스트, 행렬, 압축 희소 표현을 선택한다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| 네트워크 도달성 분석 | BFS로 hop 수와 장애 영향 범위 계산 | 도달 정점 수, 최대 큐 크기 |
| 의존성 검사 | DFS와 색상 상태로 빌드·패키지 사이클 탐지 | 사이클 검출률 |
| 소셜 그래프 분석 | 병렬 BFS로 거리·연결성 분석 | 처리량, 메모리 사용량 |

## 6. 결론

그래프 탐색은 관계 데이터의 도달성, 연결성, 경로, 사이클을 분석하는 기본 알고리즘이다. BFS와 DFS는 같은 `O(V+E)`라도 산출물과 자원 특성이 다르므로 방문 목적, 그래프 표현, 메모리 조건, 가중치 여부를 함께 판단해야 한다.
