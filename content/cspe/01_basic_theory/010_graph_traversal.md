## 미리 알고가기

- 정점과 간선: 그래프를 이루는 점과 연결 관계임
- BFS: 가까운 정점부터 층별로 방문하는 너비 우선 탐색임
- DFS: 한 경로를 깊게 따라간 뒤 되돌아오는 깊이 우선 탐색임
- 인접 리스트: 각 정점의 이웃 정점만 목록으로 저장하는 방식임
- 무가중치 최단 경로: 모든 간선 비용이 같을 때 간선 수가 가장 적은 경로임
- 위상 정렬: 방향 그래프에서 선후 관계를 만족하도록 정점을 나열하는 방법임

## Ⅰ. 개요

- **정의/개념**: 그래프 탐색은 시작 정점에서 간선을 따라 정점을 방문하며 도달 가능성, 경로, 순환 여부를 확인하는 알고리즘임
- **배경/필요성**: 네트워크 경로, 모듈 의존성, 상태 전이는 연결 순서가 결과를 바꿈. 이런 문제에서는 어떤 정점을 먼저 볼지 정하는 절차가 필요함

## Ⅱ. 특징

- BFS는 가까운 정점부터 넓게 퍼지므로 무가중치 최단 경로와 최소 홉 탐색에 적합함
- DFS는 한 경로를 깊게 따라가므로 순환 탐지와 위상 정렬 보조에 적합함
- 인접 리스트를 쓰면 두 방식 모두 정점과 간선을 한 번씩 확인하므로 시간복잡도는 $O(V+E)$임
- 계산량은 같아도 BFS는 거리 정보를, DFS는 경로 구조와 되돌아가는 지점을 더 잘 보여줌

## Ⅲ. 종류 및 비교

| 판단 기준 | BFS | DFS |
|:---|:---|:---|
| 자료구조 | 큐 | 스택 또는 재귀 |
| 방문 방식 | 가까운 정점부터 층별 확장 | 한 경로를 끝까지 따라간 뒤 복귀 |
| 주요 활용 | 무가중치 최단 경로, 레벨별 분석 | 순환 탐지, 위상 정렬 보조, 백트래킹 |
| 메모리 부담 | 같은 거리의 후보가 많으면 큐가 커짐 | 깊이가 계속 깊어지면 스택이 커짐 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 시작 정점 | 탐색이 출발하는 기준점임 |
| 대기 집합 | 아직 처리하지 않은 후보 정점 모음임 |
| 방문 표시 | 이미 본 정점을 기록해 중복 방문을 막음 |
| 인접 정보 | 인접 리스트는 실제 연결만 따라가고, 인접 행렬은 간선 존재 여부를 바로 확인함 |

```text
+-----------+     +----------+     +-----------+     +-----------+
| 시작 정점 | --> | 대기 집합 | --> | 방문 표시 | --> | 이웃 확장 |
+-----------+     +----------+     +-----------+     +-----------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
BFS: 시작 -> 큐 삽입 -> 큐 추출 -> 이웃 삽입 -> 반복
DFS: 시작 -> 스택 삽입 -> 스택 추출 -> 이웃 삽입 -> 반복
```

1. 시작 정점을 대기 집합에 넣고 방문 표시함
2. BFS는 큐에서, DFS는 스택에서 다음 정점을 꺼냄
3. 꺼낸 정점의 이웃 중 아직 방문하지 않은 정점을 넣음
4. 대기 집합이 빌 때까지 반복함

## Ⅵ. 실무 적용 및 유의점

1. 방문 표시가 늦으면 같은 정점이 여러 번 들어갈 수 있으므로 대기 집합에 넣는 순간 표시하고 중복 삽입 여부를 테스트해야 함
2. DFS에서는 깊이가 계속 깊어지면 시스템 한계를 넘을 수 있으므로 깊은 입력은 반복 DFS로 바꾸고 최대 깊이를 확인해야 함

## Ⅶ. 결론

- 그래프 탐색은 연결 관계를 확인하는 기본 절차이며, BFS는 거리와 레벨, DFS는 경로와 순환 분석에 맞음
