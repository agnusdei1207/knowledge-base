## Ⅰ. 개요
- 그래프의 모든 정점을 방문하는 기법으로 BFS와 DFS가 대표적임.
- 데이터 간의 관계를 분석하고 경로 존재 여부를 확인하는 핵심 도구임.
- [표] 출제 의도: 비선형 구조 탐색 전략 수립 및 최단 경로 응용력 검증.

## Ⅱ. 구성요소
- ASCII 구조도
  DFS: Stack/Recursive -> Deep  BFS: Queue -> Wide

| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| DFS | 깊이 우선 탐색 (Depth First) | 미로 찾기 |
| BFS | 너비 우선 탐색 (Breadth First) | 파동 퍼지기 |
| Visited Array | 방문한 정점을 기록하여 무한 루프 방지 | 이정표 표시 |

> 요약: 방문할 정점 관리 방식(Stack vs Queue)에 따라 특성이 달라짐.

## Ⅲ. 절차
- ASCII 흐름도
  Start Node -> Check Neighbors -> Mark Visit -> Add to Container

1. 시작 정점을 정하고 방문 표시를 한 후 자료구조에 삽입함.
2. 자료구조에서 정점을 꺼내 인접한 미방문 정점들을 탐색함.
3. 탐색된 정점들을 방문 표시하고 자료구조에 추가함.
4. 자료구조가 빌 때까지 반복하여 모든 연결 성분을 방문함.

> 요약: 정점 방문 순서를 제어하여 그래프 전체를 순회함.

## Ⅳ. 문제점
- 사이클이 존재하는 그래프에서 방문 체크 누락 시 무한 루프 발생함.
- DFS는 최단 경로 보장이 안 되며, BFS는 메모리 사용량이 많음.

## Ⅴ. 개선방안
- 단기: 방문 배열(Boolean)을 필수로 활용하여 중복 방문 차단함.
- 중기: 가중치 그래프의 경우 다익스트라 등 최적화 탐색 적용함.
- 장기: 대규모 그래프는 병렬 BFS 및 분산 탐색 기법으로 처리함.

## Ⅵ. 전망
- 대규모 소셜 그래프 분석을 위해 정점 중심(Vertex-centric)의 분산 그래프 처리 엔진(Pregel 모델)을 활용한 병렬 탐색 기법이 빅데이터 분석의 CSF가 될 것임.
- 실시간 이상 거래 탐지(FDS)를 위해 초저지연 그래프 데이터베이스(Neo4j 등)와 연동된 지능형 그래프 순회 알고리즘이 핀테크 보안의 핵심으로 자리 잡을 것임.
- 엣지 컴퓨팅 노드 간의 동적 토폴로지 변화를 실시간으로 추적하는 자가 학습형 탐색 에이전트 기술이 6G 네트워크 인프라에 통합될 전망임.
