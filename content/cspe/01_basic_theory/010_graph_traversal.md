## 미리 알고가기

- 정점(Vertex)과 간선(Edge): 정점은 개체, 간선은 정점 간 연결임
- 복잡도 표기 $O(V+E)$: $V$는 정점 수, $E$는 간선 수이며 탐색이 정점과 간선을 최대 한 번씩 확인한다는 뜻임
- 인접 리스트·행렬: 리스트는 이웃 목록, 행렬은 정점 쌍의 연결 여부를 저장하는 표현 방식임
- 방문 상태: 미방문·발견·완료를 구분해 중복 삽입과 순환 방문을 막는 표시값임
- 후보 저장소: 큐나 스택처럼 다음 처리 정점을 보관해 방문 순서를 정하는 구조임
- 너비 우선 탐색(BFS): 시작점에서 간선 수 기준 거리 0, 1, 2 레벨 순으로 방문함
- 깊이 우선 탐색(DFS): 한 경로의 미방문 이웃을 계속 따라간 뒤 분기점으로 되돌아감
- 도달성·연결 성분: 도달성은 경로 존재 여부, 연결 성분은 서로 도달 가능한 정점 묶음임
- 무가중치 최단 경로: 모든 간선 비용이 같을 때 간선 수가 가장 적은 경로임
- 사이클·위상 정렬: 사이클은 출발 정점으로 돌아오는 경로이며, 위상 정렬은 방향 비순환 그래프($DAG$)의 선후관계를 선형 순서로 배치하는 절차임
- 네트워크 플러딩: 수신한 패킷을 인접 노드로 확산해 도달 범위를 넓히는 전파 방식임

## Ⅰ. 개요

- **정의/개념**: 그래프 탐색은 시작 정점에서 간선을 따라 후보 정점을 선택·방문하며 도달성, 연결 성분, 경로 구조를 판단하는 알고리즘임
- **배경/필요성**: 네트워크 경로와 의존성 분석은 방문 순서에 따라 최단 거리 산출과 순환 판정이 갈리므로 탐색 기준이 필요함

## Ⅱ. 특징

- BFS는 같은 거리 레벨의 후보를 모두 처리한 뒤 다음 레벨로 확장함
- DFS는 분기점을 스택에 남긴 채 한 경로를 끝까지 확장함
- 방문 상태를 발견 시점에 표시해야 중복 삽입과 순환 반복을 막음
- BFS·DFS는 시간복잡도가 모두 $O(V+E)$로 같아, 선택 기준은 속도가 아니라 방문 절차임

## Ⅲ. 종류 및 비교

| 판단 기준 | 너비 우선 탐색 (BFS) | 깊이 우선 탐색 (DFS) |
|:---|:---|:---|
| **자료구조** | 큐 ($Queue$) | 스택 ($Stack$) 또는 재귀 ($Recursion$) |
| **방문 순서** | 거리 레벨 순서로 확장 | 한 경로를 끝까지 확장 |
| **방문 절차** | 큐 기반 레벨 확장 | 스택·재귀 기반 깊이 확장 |
| **주요 활용** | 최단 경로, 네트워크 플러딩 | 순환 탐지, 위상 정렬, 미로 탐색 |
| **취약 조건** | 동일 거리 후보 폭증 | 깊은 경로, 재귀 한계 |

> 요약: 거리 중심의 최단 경로가 중요하면 BFS를, 경로의 구조 분석이나 전수 조사가 목적이면 DFS를 선택함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 방문 배열 ($Visited$) | 발견·완료 상태를 기록해 중복 방문과 순환 반복을 막음 |
| 후보 저장소 | 큐 또는 스택으로 다음 처리 정점을 보관하고 BFS·DFS 방문 순서를 결정함 |
| 인접 정보 | 현재 정점에서 갈 수 있는 이웃을 제공해 다음 후보 범위를 만듦 |
| 시작점 관리 | 비연결 그래프는 남은 미방문 정점에서 탐색을 다시 시작해 모든 성분을 찾음 |
| 부모/거리 정보 | BFS의 최단 거리나 DFS의 탐색 트리를 복원하는 부가 상태임 |

```text
[ 탐색 흐름 모델 ]
BFS: Start -> Queue -> Level 0 -> Level 1 -> Level 2
DFS: Start -> Stack/Recur -> Path -> Backtrack -> Next Path
```

> 요약: 후보 저장소와 방문 상태가 BFS·DFS의 방문 순서와 중복 방지를 결정함.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------------+     +----------------+     +----------------+     +----------------+     +----------------+
| 시작점 표시    | --> | 후보 정점 추출 | --> | 인접 정점 확인 | --> | 발견 표시/삽입 | --> | 반복/재시작   |
+----------------+     +----------------+     +----------------+     +----------------+     +----------------+
```

1. **시작점 표시**: 시작 정점을 발견 처리하고 후보 저장소에 넣음
2. **후보 추출**: BFS는 먼저 넣은 정점, DFS는 최근 정점이나 재귀 호출 정점을 처리함
3. **인접 확인**: 현재 정점의 이웃 중 아직 발견되지 않은 정점을 고름
4. **발견 삽입**: 발견 즉시 방문 표시하고 부모·거리 정보를 함께 갱신함
5. **반복/재시작**: 후보가 남으면 반복하고, 비연결 그래프는 새 시작점을 잡음

> 요약: 발견 시점에 방문 표시를 해야 큐·스택 중복 삽입과 순환 반복을 막음.

## Ⅵ. 실무 적용 및 유의점

1. 대규모 관계망 BFS는 동일 거리 후보가 폭증하므로 발견 즉시 방문 표시하고 큐 길이·방문 배열 메모리로 확인함
2. 의존성 순환 검사는 DFS가 맞지만 깊은 그래프는 호출 한계를 넘으므로 반복 DFS와 방문 상태·최대 깊이로 검증함

## Ⅶ. 결론

- 그래프 탐색은 최단 거리 산출이 필요하면 BFS, 경로·순환 판단이 필요하면 DFS를 선택하고 방문 상태와 후보 저장소 크기를 통제해야 함

## 작성 근거(검토용)

- **핵심 키워드 선정**: 이 주제의 판단축은 `방문 절차`와 `방문 상태`이므로 BFS·DFS·후보 저장소를 핵심 키워드로 잡음. 인접 리스트/행렬, 희소/밀집은 표현법 주제라 후보에서 제외함
- **방향·전개**: 개요에서 `방문 순서가 판단을 바꾼다`는 축을 잡고, 특징->비교->구조->절차->유의점이 `어떤 절차로 다음 정점을 고르는가`를 이어받게 배치함
- **Ⅱ 특징 구성**: BFS 레벨 확장, DFS 깊이 확장, 방문 상태, 동일 복잡도 대비 절차 차이가 선택 기준을 만듦
- **복잡도 문장**: $O(V+E)$ 값만 쓰면 두 방식을 구분하지 못하므로 속도가 아니라 방문 절차가 기준임을 명시함
- **인접 정보 처리**: 희소·밀집 그래프 논의로 새지 않고 현재 정점의 다음 후보 제공 역할만 구조에 남김
- **Ⅲ 비교축 선정**: 자료구조·방문 순서·방문 절차·활용·취약 조건은 BFS/DFS 선택을 가르는 축이라 남김
- **결론 1문장**: 최단 거리 산출은 BFS, 경로·순환 판단은 DFS라는 선택 기준을 방문 상태 통제와 함께 회수함
