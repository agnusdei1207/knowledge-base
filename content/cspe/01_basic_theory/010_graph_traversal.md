## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 그래프 탐색은 정점(Vertex)과 간선(Edge)으로 구성된 그래프의 모든 정점을 체계적으로 방문하는 알고리즘임. BFS(너비 우선 탐색)는 큐로 가까운 정점부터 층별 방문, DFS(깊이 우선 탐색)는 스택(재귀)으로 한 경로를 끝까지 파고든 후 되돌아오며 방문함.
> 2. **가치**: 트리(009 참조)는 항상 하나의 루트에서 모든 노드로의 경로가 유일한 연결 구조지만, 그래프는 **사이클**과 **비연결 요소**가 존재할 수 있어 **방문 배열(visited)** 관리가 탐색 성패를 가름. BFS는 비가중 그래프의 최단 거리(홉 수)를 보장하고, DFS는 사이클 탐지·연결 요소 판별·위상 정렬의 기반임.
> 3. **융합**: 소셜 그래프 친구 추천(BFS 2홉), 웹 크롤링(BFS/DFS), 빌드 시스템 종속성 해결(DFS 위상 정렬), OS 교착상태 탐지(DFS 사이클 탐지) 등 비가중 그래프 문제의 표준 해법임.

### 🔑 핵심 용어 정리

| 용어 | 뜻 | 비유 |
|:---|:---|:---|
| BFS (너비 우선 탐색) | 큐로 시작점에서 가까운 정점부터 층별로 방문 | 연못에 던진 돌의 동심원 파문 |
| DFS (깊이 우선 탐색) | 스택/재귀로 한 경로를 끝까지 파고든 후 되돌아옴 | 미로에서 한 길을 끝까지 가보는 탐험가 |
| 방문 배열 (visited) | 정점별 방문 여부를 기록해 재방문·무한루프를 차단하는 배열 | 갈림길마다 남기는 표시 |
| 연결 요소 (Connected Component) | 그래프 내에서 서로 도달 가능한 정점들의 최대 집합 | 섬처럼 나뉜 친구 그룹 |
| 역방향 간선 (Back Edge) | DFS 중 조상 정점으로 향하는 간선, 사이클 존재의 증거 | 가계도에서 손자가 할아버지를 가리키는 경우 |
| 위상 정렬 (Topological Sort) | DAG(사이클 없는 방향 그래프)에서 의존 순서를 만족하는 정점 나열 | 라이브러리 A가 B에 의존하면 A를 먼저 빌드하는 규칙 |

## Ⅰ. 개요 및 필요성

- **개념**: 그래프 $G=(V,E)$에서 BFS는 큐를 이용해 시작 정점에서 거리 1인 정점 전체 → 거리 2인 정점 전체 순으로 방문하고, DFS는 스택(또는 재귀)으로 한 경로를 끝까지 따라간 후 백트래킹함. 시간복잡도는 인접 리스트 기준 두 방식 모두 $O(V+E)$임.
- **필요성**: 009(이진트리 순회)는 트리가 항상 단일 루트의 연결 구조라는 전제 위에서 재귀 순회만으로 전체 노드 방문이 보장됐음. 그래프는 사이클과 비연결 요소가 존재할 수 있어 이 전제가 깨지므로, **방문 배열(visited)로 재방문을 차단**하고 **모든 정점을 순회하는 외부 루프로 비연결 요소를 빠짐없이 처리**하는 두 가지 장치가 반드시 필요함.
- **비유**: BFS는 연못에 돌을 던졌을 때 퍼지는 동심원 파문이며, DFS는 미로에서 한 길을 끝까지 가보고 막히면 되돌아오는 탐험임.
- **등장 배경 및 발전 과정**:
  1. **1959년 — BFS**: Edward F. Moore가 논문 "The Shortest Path Through a Maze"에서 미로 탈출 문제 해법으로 BFS에 해당하는 방식을 제안함.
  2. **1972년 — DFS의 형식화**: Robert Tarjan이 논문 "Depth-First Search and Linear Graph Algorithms"에서 DFS 트리의 간선 분류(트리/역방향/순방향/교차 간선)를 정립하고 이를 기반으로 강연결 요소(SCC)를 $O(V+E)$에 찾는 알고리즘을 발표함. 이 업적으로 John Hopcroft와 함께 1986년 튜링상을 수상함.

```text
+-----------------------------------------------------------------------+
|          BFS vs DFS — 같은 그래프, 다른 방문 순서                     |
+-----------------------------------------------------------------------+
|  그래프:                                                              |
|        (A)----(B)                                                    |
|         |      |                                                     |
|        (C)----(D)----(E)                                             |
|         |                                                            |
|        (F)                                                           |
|                                                                       |
|  [BFS — 시작: A, 큐 사용]                                            |
|  큐 변화: [A] -> visit A, enqueue B,C                                 |
|          [B,C] -> visit B, enqueue D                                 |
|          [C,D] -> visit C, enqueue F                                 |
|          [D,F] -> visit D, enqueue E                                 |
|          [F,E] -> visit F ; [E] -> visit E                           |
|  방문 순서: A -> B,C -> D,F -> E  (거리 0 -> 1 -> 2 -> 3)             |
|                                                                       |
|  [DFS — 시작: A, 스택(재귀) 사용]                                    |
|  스택 변화: [A] -> visit A, push B                                    |
|            [A,B] -> visit B, push D                                  |
|            [A,B,D] -> visit D, push C,E                              |
|            [A,B,D,C] -> visit C, push F                              |
|            [A,B,D,C,F] -> visit F (막다른 길, 백트래킹)               |
|            [A,B,D,E] -> visit E                                      |
|  방문 순서: A -> B -> D -> C -> F -> E                                |
+-----------------------------------------------------------------------+
```

같은 6개 정점 그래프에서 BFS는 시작점 A에서 거리 1(B, C) -> 거리 2(D, F) -> 거리 3(E) 순으로 파문처럼 방문하고, DFS는 A에서 한 방향(B-D-C-F)으로 끝까지 파고든 후 더 갈 곳이 없으면 백트래킹하여 E를 방문함. BFS의 방문 순서가 곧 시작점부터의 최단 거리(최소 간선 수) 순서라는 점이 비가중 그래프에서 BFS가 최단 경로 알고리즘으로 쓰이는 이유임(가중 그래프의 최단 경로는 011 참조).

## Ⅱ. 아키텍처 및 핵심 원리

### 구성 요소

| 요소명 | BFS | DFS | 비유 |
|:---|:---|:---|:---|
| 탐색 자료구조 | 큐 (FIFO) | 스택 (LIFO) / 재귀 | 줄 서기 / 되짚어가기 |
| 방문 배열 | visited[v] | visited[v] | 표시 남기기 |
| 거리 배열 | dist[v] = 시작점~v 최소 간선 수 | (해당 없음) | 거리 표지판 |
| 부모 배열 | parent[v] = BFS 트리 부모 | parent[v] = DFS 트리 부모 | 돌아올 길 기록 |
| 시간 복잡도 | $O(V+E)$ | $O(V+E)$ | — |
| 공간 복잡도 | $O(V)$ (큐 + visited) | $O(V)$ (스택 + visited, 최악 시 재귀 깊이 $V$) | — |

> 요약: BFS·DFS 모두 $O(V+E)$·$O(V)$로 동일하나, 큐(FIFO)가 층별 방문을, 스택(LIFO)이 경로별 방문을 결정함.

### 비연결 그래프 처리 — 트리 순회와의 결정적 차이

트리는 단일 루트에서 모든 노드로의 경로가 유일해 한 번의 순회로 전체가 방문되지만, 그래프는 어느 정점에서도 도달 불가능한 **비연결 요소(Disconnected Component)**가 존재할 수 있음. 이를 놓치지 않으려면 모든 정점을 순회하며 미방문 정점마다 새로 탐색을 시작하는 외부 루프가 필요함.

```text
+-----------------------------------------------------------------------+
|   비연결 그래프 — 외부 루프 없이는 일부 정점을 영원히 놓친다           |
+-----------------------------------------------------------------------+
|  그래프: {A-B-C} (요소1)   {D-E} (요소2)   {F} (요소3, 고립 정점)      |
|                                                                       |
|  for u in V:                                                         |
|      if visited[u] == False:                                        |
|          BFS(u)   # 또는 DFS(u) — 새 연결 요소 시작                 |
|                                                                       |
|  u=A: 미방문 -> BFS(A) 실행, {A,B,C} 방문 완료, 요소 수 = 1          |
|  u=D: 미방문 -> BFS(D) 실행, {D,E} 방문 완료, 요소 수 = 2            |
|  u=F: 미방문 -> BFS(F) 실행, {F} 방문 완료, 요소 수 = 3              |
+-----------------------------------------------------------------------+
```

이 외부 루프가 곧 연결 요소 개수를 세는 표준 기법이며, 소셜 네트워크의 고립 사용자 그룹 탐지, 네트워크 단절 구간 파악 등에 직접 쓰임. 아울러 그래프에 사이클(예: F-A 간선 추가)이 있으면 visited 검사가 없을 때 BFS/DFS가 A-C-F-A를 무한 반복하므로, visited 배열은 트리 순회에는 없던 그래프 탐색만의 필수 장치임.

### DFS 간선 분류 — 그래프 구조 분석의 핵심

```text
+-----------------------------------------------------------------------+
|          DFS 간선 분류 — 사이클·구조를 드러낸다                       |
+-----------------------------------------------------------------------+
|  [트리 간선] u -> v : DFS 중 처음 발견, v가 미방문 (DFS 트리의 뼈대)  |
|  [역방향 간선] u -> v : v가 u의 조상 (★ 사이클 존재의 증거)          |
|  [순방향 간선] u -> v : v가 u의 자손이나 트리 간선이 아님             |
|  [교차 간선] u -> v : 조상-자손 관계가 아닌 이미 방문된 정점 간 간선  |
|                                                                       |
|  ★ 핵심: 방향 그래프에 사이클이 있다 <=> DFS에 역방향 간선이 있다     |
+-----------------------------------------------------------------------+
```

역방향 간선 판별은 (1) 사이클 탐지, (2) 위상 정렬(사이클 없는 DAG에서만 가능), (3) 강연결 요소(SCC) 분해의 공통 기반임.

## Ⅲ. 비교 및 연결

### 비교 1: BFS vs DFS 특성 비교

| 비교 항목 | BFS | DFS |
|:---|:---|:---|
| 자료구조 | 큐 (FIFO) | 스택 / 재귀 (LIFO) |
| 탐색 패턴 | 층별로 넓게 | 경로별로 깊게 |
| 최단 경로(비가중) | 보장됨 | 보장 안 됨 |
| 사이클 탐지 | 가능하나 비효율적 | 역방향 간선으로 즉시 판별 |
| 위상 정렬 | Kahn 알고리즘(진입차수 기반 BFS) | DFS 종료 순서의 역순 |
| 무한/대형 그래프 | 가까운 정점부터 확정 | 한 경로 끝까지 파고들어 깊이 폭발 위험 |

> 요약: 자료구조(큐 vs 스택) 하나의 차이가 탐색 패턴·최단 경로 보장 여부·사이클 탐지 방식을 모두 가름함.

### 과목 융합 관점

- 네트워크: 라우터 장애 시 영향 범위를 BFS로 도달 가능한 하위 네트워크 집합으로 파악함(가중치 기반 최적 경로 재계산은 011 참조).
- 운영체제: 프로세스 교착상태(Deadlock) 탐지는 자원 할당 그래프에서 DFS로 사이클(역방향 간선)을 찾는 것임.
- 웹 크롤링: 검색 엔진 크롤러는 URL 그래프를 BFS(넓은 도메인 커버리지)와 DFS(특정 사이트 깊이 탐색)를 혼합해 탐색함.

## Ⅳ. 실무 적용 및 기술사 판단

### 실무 시나리오

1. **소셜 네트워크 2촌 이내 친구 추천(BFS)**: 시작 사용자에서 BFS로 거리 2 이내 정점을 수집하면 $O(V+E)$에 2촌 관계를 모두 찾음.
2. **빌드 시스템의 종속성 해결(DFS 위상 정렬)**: Maven·Gradle 등은 패키지 의존성 그래프에서 DFS 기반 위상 정렬로 빌드 순서를 결정하고, 사이클(순환 의존성) 발견 시 빌드 실패로 보고함.

### 도입 체크리스트

- **기술적**: 비가중 그래프의 최단 거리(홉 수)가 필요한가(BFS) 아니면 사이클 탐지·연결 요소·위상 정렬 같은 구조 분석이 필요한가(DFS) 판단 필요.
- **운영 및 보안적**: 그래프에 사이클 또는 비연결 요소가 존재할 가능성이 있는가, visited 배열과 전체 정점 외부 루프가 모두 구현되어 있는가 확인 필요.

### 안티패턴

- **DFS로 최단 경로 판단**: DFS가 먼저 발견한 경로가 우연히 최단일 수는 있으나 보장되지 않으므로 비가중 최단 경로에는 반드시 BFS를 사용해야 함.
- **visited 배열 누락**: 사이클이 있는 그래프에서 visited 검사 없이 탐색하면 무한 루프에 빠짐.
- **외부 루프 누락**: 시작 정점 하나만 탐색하면 비연결 요소의 정점들이 방문되지 않고 누락됨.

## Ⅴ. 기대효과 및 결론

### 정량/정성 기대효과

| 구분 | 미적용 | BFS/DFS 활용 | 개선 효과 |
|:---|:---|:---|:---|
| 정량 | 사이클 탐지에 $O(V^2)$ 인접행렬 전수 검사 | DFS 역방향 간선 판별 $O(V+E)$ | 희소 그래프에서 대폭 단축 |
| 정량 | 비가중 최단 거리 미보장 탐색 | BFS로 $O(V+E)$ 최단 거리(홉 수) 보장 | 정확한 최단 거리 확보 |
| 정성 | 비연결 요소 누락 위험 | 외부 루프 + visited로 전체 정점 커버 보장 | 그래프 완전 탐색 신뢰성 확보 |

> 요약: BFS/DFS는 트리 순회(009)에 없던 visited 배열과 외부 루프라는 두 장치로 사이클·비연결 요소를 안전하게 처리함.

### 미래 전망

- 그래프 신경망(GNN): 이웃 노드 정보를 BFS의 층 개념과 유사한 메시지 전달(Message Passing) 방식으로 집계해 그래프 구조를 학습하는 딥러닝 기법임.
- 대규모 그래프 처리: 수십억 정점 규모에서는 단일 머신 BFS/DFS가 불가능해 Pregel(Google), GraphX(Spark) 같은 분산 그래프 처리 프레임워크가 필요함.

### 참고 표준

- Moore, E.F. (1959): "The Shortest Path Through a Maze" — BFS 방식의 최초 제안.
- Tarjan, R.E. (1972): "Depth-First Search and Linear Graph Algorithms" — DFS 간선 분류·SCC 알고리즘.

그래프 탐색은 "최단 거리가 필요한가, 구조 분석이 필요한가"라는 질문에서 BFS/DFS 선택이 갈리며, 트리와 달리 방문 배열과 외부 루프로 사이클·비연결 요소를 처리해야 한다는 점이 이후 모든 그래프 알고리즘(011 최단경로, 012 최소신장트리)의 공통 전제가 됨.

| 이진 트리 순회(009) | 트리 순회는 단일 루트 전제로 재귀만으로 충분하나, 그래프는 visited·외부 루프가 추가로 필요함. |
| 최단 경로(011) | BFS는 비가중 그래프 최단 거리 전용이며, 가중 그래프의 최적 경로는 011의 다익스트라 등이 담당함. |
| 최소 신장 트리(012) | 크루스칼·프림도 그래프 탐색 프레임워크 위에서 간선을 선택함. |
| 위상 정렬 | DFS 종료 순서의 역순으로 DAG의 의존 순서를 구함. |

### 📈 관련 키워드 및 발전 흐름도

```text
[그래프 기본 구조 (인접 행렬 / 인접 리스트)]
    |
    v
[BFS·DFS (현재 개념)]
    |
    +---> [최단 경로 (011: 다익스트라, 벨만-포드)]
    +---> [최소 신장 트리 (012: 크루스칼, 프림)]
    +---> [위상 정렬 / 강연결 요소(SCC)]
    +---> [그래프 신경망 (GNN)]
```

### 👶 어린이를 위한 3줄 비유 설명

1. BFS는 돌멩이를 연못에 던지면 파문이 퍼지는 것처럼, 가까운 친구부터 먼 친구 순으로 만나요.
2. DFS는 미로에서 한 길을 끝까지 가보고, 막히면 돌아와서 다른 길을 시도해요.
3. 그런데 미로에 뱅글뱅글 도는 길(사이클)이 있으면 지나온 곳을 표시(visited)해 두지 않으면 같은 길을 영원히 돌게 돼요!
