## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 그래프의 모든 정점을 체계적으로 방문하는 탐색 기법으로, 너비 우선(BFS)과 깊이 우선(DFS)으로 구분됨 |
| **배경/필요성** | 경로 탐색·연결 요소 판별·위상 정렬 등 그래프 기반 문제 해결의 기본 연산으로 필수임 |
| **출제 의도** | BFS·DFS의 자료구조(큐/스택)·시간 복잡도·활용 차이를 설명할 수 있는지 평가함 |

## Ⅱ. 구성요소
```
+----------+     +----------+     +----------+
|   BFS    | --> | 방문배열  | --> |   DFS    |
| (큐 사용) |     | (visited)|     | (스택/재귀)|
+----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| BFS | 시작 정점에서 가까운 정점부터 레벨별로 탐색하며, 큐를 사용함 | 물결이 퍼지듯 탐색 |
| DFS | 시작 정점에서 깊이 방향으로 끝까지 탐색 후 백트래킹하며, 스택/재귀를 사용함 | 미로에서 한 갈래를 끝까지 탐색 |
| 방문 배열 | 각 정점의 방문 여부를 기록하여 중복 방문을 방지함 | 방문 도장 |

> 요약: BFS(큐·레벨별·최단 경로)와 DFS(스택·깊이 우선·백트래킹)로 그래프를 탐색함.

## Ⅲ. 절차
```
+------------+     +------------+
| 시작정점   | --> | 큐/스택    |
| 방문처리   |     | 에 삽입    |
+------------+     +------------+
                        |
+------------+     +----+-------+
| 모든정점   | <-- | 인접정점  |
| 방문완료   |     | 방문·삽입  |
+------------+     +------------+
```

1. 초기화: 시작 정점을 방문 처리하고 큐(BFS) 또는 스택(DFS)에 삽입함
2. 정점 추출: 큐에서 Dequeue(BFS) 또는 스택에서 Pop(DFS)하여 현재 정점을 선택함
3. 인접 정점 탐색: 현재 정점의 미방문 인접 정점을 방문 처리하고 큐/스택에 삽입함
4. 반복·종료: 큐/스택이 빌 때까지 2~3을 반복하여 모든 도달 가능 정점을 방문함

> 요약: 초기화 → 추출 → 인접 탐색 → 반복으로 O(V+E) 시간에 전체 그래프를 탐색함.

## Ⅳ. 문제점
- BFS 메모리 O(V): 레벨이 넓은 그래프에서 큐에 다수 정점이 동시 저장되어 메모리가 큼
- DFS 스택 오버플로우: 깊이가 깊은 그래프에서 재귀 호출 스택이 초과될 수 있음
- 가중치 미고려: BFS는 무가중 그래프의 최단 경로만 보장하며, 가중 그래프에는 부적합함

## Ⅴ. 개선방안
- (단기) 반복 DFS: 명시적 스택으로 재귀를 대체하여 스택 오버플로우를 방지함
- (중기) 양방향 BFS: 시작·목표 양쪽에서 동시에 BFS를 수행하여 탐색 공간을 줄임
- (장기) A* 탐색: 휴리스틱 함수를 추가하여 가중 그래프에서 최적 경로를 탐색함

## Ⅵ. 전망
- 소셜 네트워크 친구 추천(BFS)·웹 크롤링(DFS)·경로 탐색(A*)에서 그래프 탐색이 핵심이며, 대규모 그래프의 분산 BFS/DFS(Pregel·GraphX)가 빅데이터 분석의 표준이 될 전망임
