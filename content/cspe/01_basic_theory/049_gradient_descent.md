# 📖 【암기용】 개념 완전 이해

> 목적: 경사하강법을 처음 봐도 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 설명이다.

## 한눈에
- **개요**: 손실 함수 기울기의 반대 방향으로 파라미터를 반복 갱신하는 최적화 방법
- **왜 필요한가**: 신경망은 닫힌 해를 구하기 어려운 비선형 최적화 문제임
- 손실을 줄이는 방향을 기울기로 추정해 작은 보폭으로 이동해야 함
- **핵심 직관**: 산에서 가장 가파른 오르막 반대 방향으로 한 걸음씩 내려가 낮은 지점을 찾는 절차임.

## 깊이 이해
- **배경·문제의식**: 모델 파라미터 W가 수백만 개이면 모든 조합 탐색은 불가능함
- 경사하강법은 현재 위치의 미분값으로 다음 위치를 정함
- **작동 원리**: 기본식은 `W = W - η∂L/∂W`임
- SGD는 미니배치 기울기, AdaGrad는 누적 제곱 기울기, Adam은 1차·2차 모멘트를 사용함
- **비유**: 안개 낀 산길에서 전체 지형도 없이 발밑 기울기만 보고 0.001~0.01 크기의 보폭으로 이동하는 방식임.
- **구체 예시**: 학습률 η=0.01, 기울기 5이면 파라미터는 0.05만큼 감소함
- η=1.0이면 최소점을 지나 손실이 발산할 수 있음
- **흔한 오해·주의점**: Adam이 항상 최종 일반화 지표를 보장하지는 않음
- 학습률 스케줄, Weight Decay, 검증 지표를 함께 조정해야 함

## 연결 개념
- 역전파(Backpropagation) — 옵티마이저에 기울기 제공
- 학습률(Learning Rate) — 갱신 보폭 결정

---

## Ⅰ. 개요 및 필요성

- 정의: 경사하강법은 손실 함수 기울기의 반대 방향으로 파라미터를 반복 갱신하는 최적화 절차임
- 배경: 딥러닝 모델은 파라미터 수와 비선형성이 커서 해석적 해를 얻기 어려움
- 필요성: 경사하강법은 역전파 기울기를 이용해 손실을 줄이는 방향으로 파라미터를 갱신함

---

## Ⅱ. 구조 및 구성요소

```text
데이터 배치 -> 순전파 -> 손실 L -> 역전파 ∇L -> 옵티마이저 선택
                                      +-> SGD/AdaGrad 갱신
                                      +-> Adam/AdamW 모멘트 보정
옵티마이저 갱신 -> 파라미터 W 변경 -> 검증 손실 확인
```

| 구성요소 | 역할 | 주요 파라미터 |
|:---|:---|:---|
| 기울기 ∇L | 손실 증가 방향 산출 | Gradient Norm |
| 학습률 η | 갱신 보폭 결정 | 1e-4~1e-1 탐색 |
| 모멘텀/적응률 | 이전 기울기·제곱 기울기 반영 | β1=0.9, β2=0.999 |

> 요약: 경사하강법은 기울기, 학습률, 모멘텀, 규제 파라미터 조합으로 갱신량을 결정함.

---

## Ⅲ. 동작원리 및 흐름도

```text
초기화 -> 미니배치 선택 -> 기울기 계산
   -> 옵티마이저별 보정 -> W 갱신 -> 검증 손실 확인
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | Xavier/He 초기화 | 활성값 분산 유지 |
| 2 | 미니배치로 손실 계산 | Batch 32~1024 |
| 3 | 역전파로 ∇L 산출 | NaN/Inf 0건 |
| 4 | SGD·Adam·AdaGrad 규칙 적용 | Loss 감소, 진동 여부 |

> 요약: 경사하강법은 배치별 기울기를 산출하고 옵티마이저 규칙으로 보정한 뒤 검증 손실로 반복 여부를 결정함.

---

## Ⅳ. 특징

| 구분 | SGD | AdaGrad | Adam |
|:---|:---|:---|:---|
| 갱신 방식 | 미니배치 기울기 | 누적 제곱 기울기로 좌표별 보폭 조정 | 1차·2차 모멘트 보정 |
| 장점 | 일반화 지표 검증 용이 | 희소 특징 학습에 적합 | 초기 수렴 epoch 감소 |
| 수치 기준 | η=0.1~0.001 | ε=1e-8 | β1=0.9, β2=0.999 |

> 요약: SGD는 단순성, AdaGrad는 희소 특징, Adam은 모멘트 보정이 강점이며 검증 손실로 선택함.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존·대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | 전체 데이터 Batch GD | Mini-batch SGD/AdamW | Batch 32~1024, GPU 메모리 사용률 70~90% |
| 비용/성능 | 고정 학습률 | Cosine/Step Scheduler, Warmup | 검증 손실 3 epoch 정체 시 η 0.1배 |
| 운영/위험 | 단일 옵티마이저 고정 | AdamW 후보 후 SGD+Momentum 비교 | seed 3개 평균·표준편차 보고 |

> 요약: 옵티마이저 선택은 배치 크기, 학습률 스케줄, seed별 검증 손실 편차로 판단함.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 발산 | 학습률 과대, 초기화 부적합 | η 0.1배 감소, Warmup 5%, Gradient Clipping 1.0 | Loss NaN/Inf 0건 |
| 수렴 지연 | 학습률 과소, Plateau | Scheduler, Momentum 0.9, AdamW β1=0.9/β2=0.999 | epoch별 검증 손실 감소율 |
| 일반화 저하 | Weight Decay 부족, 배치 과대 | weight_decay=1e-2, Early Stopping patience 10 | Train-Test Gap 10%p 이하 |

> 요약: 발산은 학습률, 수렴 지연은 스케줄, 일반화 저하는 규제와 조기 종료로 통제함.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 성능/효율 | GPU 사용률 70~90%, epoch 시간 기록 | 학습 로그, nvidia-smi, 프로파일러 |
| 품질/정확도 | 검증 Loss 감소, F1·AUC·RMSE 목표 충족 | 검증 데이터, 실험 추적 |
| 운영/보안 | 하이퍼파라미터·seed·데이터 버전 기록 | MLflow/W&B, Git commit hash |

> 요약: 경사하강법 적용 결과는 자원 사용률, 검증 지표, 실험 재현성으로 평가함.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 기본 탐색: AdamW(η=1e-3, weight_decay=1e-2)로 시작 후 검증 손실 정체 시 η를 0.1배 감소
2. 일반화 확인: 최종 후보는 SGD+Momentum 0.9와 AdamW를 동일 epoch·seed 3개로 비교
3. 운영 통제: Gradient Clipping 1.0, Early Stopping patience 10, 학습률 로그를 실험 추적 시스템에 저장

**결론 (2줄):**
- 기술사 판단: 희소 특징은 AdaGrad, 대규모 딥러닝 기본은 AdamW, 최종 일반화 검증은 SGD 계열 비교가 필요함
- 향후 방향: LAMB, Lion 등 대규모 배치 최적화는 분산 학습의 통신·수렴 조건과 함께 평가해야 함
