## 미리 알고가기

- 목적 함수($Objective$ $Function$): 학습에서 최소화하거나 최대화하려는 대상 함수임
- 기울기($Gradient$): 함수값이 가장 빠르게 증가하는 방향을 나타내는 미분 벡터임
- 학습률($Learning$ $Rate$): 한 번의 업데이트에서 파라미터를 이동시키는 보폭임
- 미니배치($Mini$-$batch$): 전체 데이터 중 일부 샘플 묶음으로 기울기를 추정하는 단위임
- 모멘텀($Momentum$): 과거 기울기 방향을 누적해 진동을 줄이고 수렴을 돕는 방식임

## Ⅰ. 개요

- **정의/개념**: 경사하강법은 손실 함수의 기울기 반대 방향으로 파라미터를 반복 이동시켜 손실을 최소화하는 수치 최적화 알고리즘임
- **배경/필요성**: 복잡한 모델은 닫힌 형태의 최적해를 구하기 어렵기 때문에 손실을 줄이는 방향으로 점진적으로 근사하는 학습 절차가 필요함

## Ⅱ. 특징

- 현재 위치의 기울기만 사용해 다음 파라미터를 정하므로 대규모 모델에도 반복 적용함
- 학습률이 크면 발산하고 작으면 수렴이 느려져 보폭 조정이 성능과 안정성을 좌우함
- 배치 크기에 따라 기울기 추정의 안정성과 계산 비용이 달라짐
- Adam, AdaGrad 같은 변형은 파라미터별 학습률이나 모멘텀을 사용해 수렴 특성을 바꿈

## Ⅲ. 종류 및 비교

| 기준 | SGD | AdaGrad | Adam |
|:---|:---|:---|:---|
| 학습률 처리 | 전역 학습률 사용 | 자주 갱신된 파라미터 학습률 감소 | 모멘텀과 적응형 학습률 결합 |
| 기울기 사용 | 미니배치 기울기 | 누적 제곱 기울기 | 1차·2차 모멘트 추정 |
| 적합 데이터 | 대규모 일반 학습 | 희소 특징 데이터 | 깊은 신경망 초기 학습 |
| 장점 | 단순하고 일반화 성능이 좋음 | 희소 파라미터 조정에 유리 | 빠르고 안정적으로 수렴 |
| 유의점 | 진동과 느린 수렴 가능 | 학습률이 너무 빨리 작아짐 | 최종 일반화 검증 필요 |

> 요약: SGD는 단순성, AdaGrad는 희소 특징, Adam은 빠른 수렴에 강점이 있음.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 파라미터 $\theta$ | 모델이 학습으로 조정하는 가중치와 편향의 집합임 |
| 손실 함수 $L$ | 파라미터가 얼마나 잘못 예측했는지 수치화한 최적화 대상임 |
| 기울기 $\nabla L$ | 현재 파라미터에서 손실이 증가하는 방향을 나타내며 반대 방향으로 이동함 |
| 학습률 $\eta$ | 업데이트 크기를 정하는 값으로 수렴 속도와 발산 위험을 함께 결정함 |
| 옵티마이저 상태 | 모멘텀, 누적 기울기처럼 다음 업데이트에 쓰는 내부 상태임 |

```text
기본 업데이트:
theta_next = theta_now - eta * gradient
```

> 요약: 경사하강법은 손실이 증가하는 기울기의 반대 방향으로 파라미터를 이동함.

## Ⅴ. 원리 및 절차 흐름도

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 초기화    | --> | 기울기 계산 | --> | 파라미터 갱신 | --> | 수렴 확인 |
+-----------+     +-----------+     +-----------+     +-----------+
```

1. **초기화** — 파라미터, 학습률, 배치 크기, 옵티마이저를 설정함
2. **기울기 계산** — 미니배치 데이터를 사용해 손실과 각 파라미터의 기울기를 계산함
3. **파라미터 갱신** — 선택한 옵티마이저 규칙에 따라 기울기 반대 방향으로 파라미터를 이동함
4. **수렴 확인** — 검증 손실, 학습률 변화, 반복 횟수 기준으로 학습 지속 여부를 판단함

> 요약: 최적화 안정성은 기울기 계산보다 학습률과 수렴 기준을 어떻게 조정하는지에 달림.

## Ⅵ. 실무 적용 및 유의점

1. 학습 초기에 손실이 급등하면 학습률이 큰 경우가 많으므로 워밍업이나 스케줄러를 적용하고 손실 곡선과 기울기 노름을 확인함
2. Adam은 빠르게 수렴하지만 최종 일반화가 항상 최선은 아니므로 검증 성능을 기준으로 가중치 감쇠, 학습률 감소, SGD 전환을 비교함

## Ⅶ. 결론

- 경사하강법은 손실을 줄이는 반복 최적화 절차이므로 학습률, 배치 크기, 옵티마이저 상태를 검증 성능 기준으로 조정해야 함

## 작성 근거(검토용)

- 경사하강법의 본질을 기울기 반대 방향 반복 이동으로 정의해 역전파와의 역할 차이를 분명히 함
- SGD, AdaGrad, Adam은 제목에 포함된 대표 변형이므로 비교표 중심 대상으로 구성함
- 학습률은 발산과 수렴 지연을 모두 만드는 핵심 변수라 특징, 구조, 실무에 반복 반영함
- 옵티마이저 상태를 구성요소에 넣어 Adam과 AdaGrad의 차이가 단순 이름 차이가 아님을 설명함
- 결론은 검증 성능 기준 조정으로 회수해 훈련 손실만 보는 오판을 줄임
