## 미리 알고가기

- 목적 함수(Objective Function): 학습에서 최소화하거나 최대화하려는 대상 함수임
- 기울기(Gradient): 함수값이 가장 빠르게 증가하는 방향을 나타내는 미분 벡터임
- 학습률(Learning Rate): 한 번의 업데이트에서 파라미터를 이동시키는 보폭임
- 미니배치(Mini-batch): 전체 데이터 중 일부 샘플 묶음으로 기울기를 추정하는 단위임
- 모멘텀(Momentum): 과거 기울기 방향을 누적해 진동을 줄이고 수렴을 돕는 방식임
- 확률적 경사하강법(SGD): 미니배치 기울기와 전역 학습률로 파라미터를 갱신하는 방식임
- AdaGrad: 누적 제곱 기울기로 파라미터별 학습률을 줄이는 방식임
- Adam: 기울기의 1차 모멘트와 제곱 기울기의 2차 모멘트로 파라미터별 갱신 폭을 정하는 방식임
- $\theta,L,\nabla L,\eta$: 각각 파라미터, 손실 함수, 손실 기울기, 학습률을 나타내는 기호임

## 작성 근거(검토용)

- 경사하강법의 본질을 기울기 반대 방향 반복 이동으로 정의해 역전파와의 역할 차이를 분명히 함
- SGD, AdaGrad, Adam은 제목에 포함된 대표 변형이므로 비교표 중심 대상으로 구성함
- 학습률은 발산과 수렴 지연을 모두 만드는 핵심 변수라 특징·구조·사례에 반영함
- 최적화기 상태를 구성요소에 넣어 Adam과 AdaGrad의 차이가 단순 이름 차이가 아님을 설명함
- 결론은 검증 성능 기준 조정으로 정리해 훈련 손실만 보는 오판을 줄임

## Ⅰ. 개요

- **정의/개념**: 경사하강법은 기울기 반대 방향으로 파라미터를 반복 이동해 손실을 최소화하는 알고리즘임
- **배경/필요성**: 닫힌 형태 최적해가 없는 모델 학습을 위해 손실을 점진적으로 줄이는 절차가 필요함

## Ⅱ. 특징

- 현재 파라미터에서 계산한 기울기와 최적화기 상태로 다음 파라미터를 반복 결정함
- 학습률이 크면 발산하고 작으면 수렴이 느려져 보폭 조정이 성능과 안정성을 좌우함
- 배치 크기에 따라 기울기 추정의 안정성과 계산 비용이 달라짐
- Adam·AdaGrad 변형은 파라미터별 학습률이나 모멘텀으로 수렴 특성을 바꿈

## Ⅲ. 종류 및 비교

| 판단 기준 | SGD | AdaGrad | Adam |
|:---|:---|:---|:---|
| 보폭 결정 메커니즘 | 전역 학습률 | 누적 제곱 기울기 | 1차와 2차 모멘트 |
| 상태 저장 범위 | 누적 상태 없음 | 파라미터별 누적값 | 파라미터별 두 모멘트 |
| 주요 제약 | 학습률 튜닝 의존 | 학습률 소진 | 모멘트 저장 비용 |

> 요약: SGD는 전역 학습률, AdaGrad는 누적 기울기, Adam은 모멘트로 보폭을 정함.

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 파라미터 $\theta$ | 최적화할 가중치·편향 |
| 손실 함수 $L$ | 최소화 목적값 |
| 기울기 $\nabla L$ | 손실 증가 방향 |
| 학습률 $\eta$ | 1회 갱신 보폭 |
| 최적화기 상태 | AdaGrad의 누적 제곱 기울기와 Adam의 1·2차 모멘트처럼 갱신 방향·보폭을 조정하는 상태 변수 |

$$
\theta_{t+1} = \theta_t - \eta \nabla L(\theta_t)
$$

> 요약: 경사하강법은 손실 기울기의 반대 방향으로 파라미터를 갱신하며 적응형 최적화기는 누적 기울기 상태로 방향과 보폭을 조정함.

## Ⅴ. 원리 및 절차 흐름도

```text
파라미터·최적화기 상태 초기화 → 손실·기울기 계산
                                      ↓
학습률·상태로 파라미터 갱신 → 수렴 판정
                                ├─ 미수렴 → 다음 배치 반복
                                └─ 수렴 → 학습 종료
```

1. **초기화**: 파라미터·학습률·배치 크기·최적화기를 설정함
2. **기울기 계산**: 미니배치 데이터의 순전파로 손실을 구하고 역전파로 각 파라미터의 기울기를 계산함
3. **파라미터 갱신**: 선택한 최적화기 규칙에 따라 기울기 반대 방향으로 파라미터를 이동함
4. **수렴 확인**: 검증 손실·학습률 변화·반복 횟수 기준으로 학습 지속 여부를 판단함

> 요약: 기울기·학습률·최적화기 상태로 파라미터를 갱신하고 검증 손실로 수렴 여부를 판단함.

## Ⅵ. 실무 사례

1. 대규모 언어 모델 학습은 Adam·단계별 학습률을 적용하고 손실 곡선으로 수렴 양상을 판단함
2. 추천 임베딩 학습은 Adam을 적용하고 상위 추천 재현율·검증 손실로 평가함

## Ⅶ. 결론

- 경사하강법은 손실이 줄어드는 방향으로 모델을 반복 개선하며, 이동 폭이 너무 크거나 작지 않게 조정해야 함
- 최적화기는 관성적으로 고르지 말고 배치 크기·희소성·수렴 예산에 맞춰 선택하며 발산 시 복구할 체크포인트를 유지해야 함
