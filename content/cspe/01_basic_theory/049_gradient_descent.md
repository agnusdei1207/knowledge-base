## 미리 알고가기

- 목적 함수: 최소화하거나 최대화하려는 수학적 목표이며 ML에서는 보통 손실 함수임
- 기울기: 현재 위치에서 목적 함수가 가장 빠르게 증가하는 방향을 나타내는 벡터임
- 학습률: 기울기 반대 방향으로 한 번에 이동하는 크기를 정하는 값임
- 배치: 한 번의 파라미터 갱신에 사용하는 데이터 묶음임
- 옵티마이저: 기울기와 보정 규칙으로 파라미터 갱신을 수행하는 알고리즘임

## Ⅰ. 개요

- **정의**: 경사하강법은 손실 함수의 기울기 방향을 따라 파라미터를 반복 갱신해 예측 오차가 작은 해를 찾는 최적화 알고리즘임
- **배경/필요성**: 회귀, 분류, 딥러닝 모델은 파라미터 공간이 크고 닫힌 해가 없거나 직접 해법의 계산 비용이 커 반복적 수치 최적화가 필요함
- **비유**: 안개 낀 산에서 발밑 경사를 보고 가장 낮은 곳을 향해 조금씩 내려가는 과정과 같음

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 최적화 원리 이해 | 손실, 기울기, 학습률, 반복 갱신 | 학습률 역할 누락 |
| 옵티마이저 선택 | Batch GD, SGD, Adam, AdaGrad | SGD와 Adam 차이 혼동 |

> 요약: 경사하강법은 손실 함수의 변화율을 이용해 모델 파라미터를 점진적으로 개선하는 기본 최적화 절차임.

## Ⅱ. 특징/비교

| 판단 기준 | Batch GD·SGD | Mini-batch·Adam |
|:---|:---|:---|
| 갱신 단위 | 전체 데이터 또는 단일 샘플 기준으로 갱신함 | 작은 배치와 적응형 학습률을 조합해 갱신함 |
| 수렴 특성 | Batch는 손실 변동이 작지만 느리고 SGD는 계산량이 작지만 잡음이 큼 | 계산량과 손실 변동 폭의 균형을 제공함 |
| 메모리·병렬성 | Batch는 메모리 부담이 크고 SGD는 병렬 효율이 낮음 | GPU 학습과 대규모 데이터 처리에 적합함 |
| 선택 조건 | 작은 데이터 또는 이론적 분석에 적합함 | 딥러닝과 대규모 학습에서 기본 선택지가 됨 |

> 요약: 옵티마이저는 데이터 규모, 손실 표면, 학습 안정성, 하드웨어 효율을 기준으로 선택해야 함.

- **입력 조건**: 미분 가능한 손실 함수와 갱신 가능한 파라미터가 정의되어야 함
- **평가 기준**: 수렴 속도, 손실 안정성, 검증 성능을 함께 확인함
- **선택 판단**: 대규모 학습은 mini-batch와 Adam 계열을 우선 비교함

## Ⅲ. 구성요소

```text
+------------+      +------------+      +------------+
| 파라미터    | ---> | 손실 함수   | ---> | 기울기 계산 |
+------------+      +------------+      +------------+
       |                  |                  |
       v                  v                  v
+------------+      +------------+      +------------+
| 학습률     |      | 배치 데이터 |      | 갱신 규칙   |
+------------+      +------------+      +------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 파라미터 | 모델이 학습을 통해 조정하는 가중치와 편향 값임 | 조절 손잡이 |
| 손실 함수 | 현재 파라미터의 예측 오차를 수치화한 최적화 대상임 | 목표 지형 |
| 기울기 | 손실을 줄이기 위해 파라미터를 어느 방향으로 움직일지 알려줌 | 내리막 방향 |
| 학습률 | 한 번에 이동할 크기를 정해 수렴 속도와 안정성을 좌우함 | 보폭 |
| 갱신 규칙 | SGD, Momentum, AdaGrad, Adam 등 기울기 보정 방식을 적용함 | 걷는 방식 |

> 요약: 경사하강법은 손실 함수, 기울기, 학습률, 갱신 규칙의 조합으로 파라미터 이동을 결정함.

## Ⅳ. 절차

```text
+------------+      +------------+      +------------+      +------------+
| 초기화     | ---> | 손실·기울기 | ---> | 파라미터 갱신 | ---> | 수렴 판정   |
+------------+      +------------+      +------------+      +------------+
```

1. **초기화**: 파라미터, 학습률, 배치 크기, 종료 조건을 설정함
2. **손실·기울기 계산**: 현재 배치에서 예측값과 손실을 계산하고 기울기를 구함
3. **파라미터 갱신**: 기울기 반대 방향으로 파라미터를 이동시키고 옵티마이저 보정을 적용함
4. **수렴 판정**: 손실 감소, 검증 성능, epoch 수, 조기 종료 조건을 확인함

> 요약: 경사하강법 절차는 현재 손실의 기울기를 반복 계산해 파라미터를 이동시키고 수렴 여부를 판단하는 흐름임.

- **산출물**: 손실 곡선, 파라미터 갱신량, 선택 optimizer 설정임
- **검증 기준**: 손실이 발산하지 않고 검증 성능이 함께 개선되어야 함
- **운영 기록**: 학습률, 배치 크기, 스케줄러, seed를 실험별로 남겨야 함

## Ⅴ. 문제점

- **P1 학습률 민감성**: 학습률이 크면 손실이 발산하고 작으면 수렴이 지나치게 느리거나 지역 정체에 머물 수 있음
- **P2 손실 표면 문제**: 비볼록 함수에서는 지역 최소점, saddle point, plateau 때문에 최적화가 지연되거나 불안정해질 수 있음
- **P3 잡음·일반화 불균형**: 배치가 너무 작으면 갱신 잡음이 커지고, 너무 크면 계산 비용과 일반화 특성이 나빠질 수 있음

> 요약: 경사하강법은 이동 방향은 단순하지만 보폭, 손실 지형, 배치 잡음에 따라 성능이 크게 달라짐.

## Ⅵ. 개선방안

- **P1 대응**: learning rate range test, 스케줄러, warm-up, adaptive optimizer를 적용함 (확인: 손실 발산 여부와 수렴 속도)
- **P2 대응**: Momentum, Adam, Xavier/He 초기화, 정규화, gradient clipping을 사용함 (확인: gradient norm과 validation loss 추세)
- **P3 대응**: 배치 크기 실험, gradient accumulation, 조기 종료, 검증 성능 기반 모델 선택을 적용함 (확인: 배치별 성능과 자원 사용량)

> 요약: 경사하강법 개선은 학습률과 배치 크기를 실험적으로 조정하고 손실·기울기 곡선을 관측하는 것임.

- **우선순위**: 학습률 범위와 손실 발산 여부를 가장 먼저 확인함
- **확인 지표**: training loss, validation loss, gradient norm, 학습 시간을 함께 사용함
- **재평가 조건**: 데이터 규모, 배치 크기, 하드웨어 설정이 바뀌면 optimizer를 다시 비교함

## Ⅶ. 전망

- **발전 방향**: 경사하강법은 회귀부터 대규모 딥러닝까지 대부분의 학습 알고리즘을 실제로 움직이는 최적화 기반으로 유지될 것임
- **기술사적 판단**: 기술사는 옵티마이저 이름보다 손실 곡선, 학습률, 배치 크기, 검증 성능이 함께 수렴하는지 확인해야 함
- **기술사 제언**: 향후에는 대규모 분산 학습, 저정밀 연산, 자동 학습률 탐색, 2차 근사 기법과 결합해 학습 비용과 안정성을 동시에 개선하는 방향으로 발전할 것임
