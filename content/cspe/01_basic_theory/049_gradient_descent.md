## 미리 알고가기

- learning rate: 한 번 업데이트에서 얼마나 이동할지 정하는 크기임
- batch: 한 번 gradient 계산에 쓰는 데이터 묶음임
- optimizer: gradient를 실제 파라미터 업데이트 규칙으로 바꾸는 알고리즘임

## Ⅰ. 개요

- **정의/개념**: 경사하강법은 손실 함수의 기울기 반대 방향으로 파라미터를 반복 이동시켜 최소값을 찾는 최적화 방법이며, SGD, AdaGrad, Adam이 대표 변형임
- **배경/필요성**: 머신러닝 모델은 닫힌 해를 구하기 어려운 경우가 많아, 반복적인 수치 최적화 방식이 필요함

## Ⅱ. 특징

- 구현이 단순하고 대규모 파라미터 학습에 적합함
- SGD는 노이즈가 있어 지역 최소값 탈출과 일반화에 유리할 수 있음
- Adam은 적응형 학습률과 모멘텀을 결합해 빠른 수렴을 지원함
- 학습률 설정이 잘못되면 발산하거나 지나치게 느려질 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | SGD | AdaGrad | Adam |
|:---|:---|:---|:---|
| 학습률 | 고정/스케줄 | 파라미터별 감소 | 적응형 + 모멘텀 |
| 장점 | 단순, 일반화 우수 | 희소 특징에 강함 | 수렴 속도 빠름 |
| 단점 | 튜닝 민감 | 학습률이 너무 작아질 수 있음 | 일반화가 불리할 수 있음 |
| 대표 적용 | 대규모 비전 모델 | NLP 희소 특징 | 범용 딥러닝 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 손실 함수 | 최소화 대상이며 optimizer의 목표임 |
| gradient | 이동 방향을 제공하고 업데이트 근거임 |
| learning rate | 이동 폭을 조절하고 안정성과 속도를 좌우함 |
| 상태 변수 | momentum, 1차/2차 모멘트 등이며 Adam류의 핵심임 |

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 배치선택 | --> | 기울기계산 | --> | 파라미터갱신 | --> | 수렴확인 |
+----------+     +----------+     +----------+     +----------+
```

1. **배치선택**: 전체 또는 미니배치 데이터를 선택함
2. **기울기계산**: 현재 파라미터에서 loss gradient를 구함
3. **파라미터갱신**: optimizer 규칙으로 가중치를 갱신함
4. **수렴확인**: loss와 metric 변화로 학습 상태를 점검함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 학습률이 너무 크면 발산해 최솟값 주변을 넘나들 수 있음
   - 해결방안: warm-up, decay, scheduler를 적용하고 loss curve로 검증함
2. 문제: 평평한 구간이나 saddle point에서 느려져 진행 속도가 급감함
   - 해결방안: momentum, Adam, gradient clipping을 사용하고 gradient norm로 검증함
3. 문제: optimizer 선택이 일반화에 영향을 줘 빠른 수렴이 항상 좋은 최종 성능은 아님
   - 해결방안: 후반에 SGD로 전환하거나 weight decay를 병행하고 validation accuracy로 검증함

## Ⅶ. 적용 사례

- CNN/Transformer 학습: AdamW와 스케줄러를 사용함, 확인 지표는 loss 수렴 속도임
- 희소 특징 추천 모델: AdaGrad로 자주 업데이트되지 않는 파라미터를 보정함, 확인 지표는 CTR 개선폭임
- 대규모 비전 모델: SGD with momentum을 사용함, 확인 지표는 최종 top-1 accuracy임

## Ⅷ. 결론

경사하강법의 핵심은 기울기 계산보다 업데이트 규칙 제어에 있으므로, optimizer 선택은 수렴 속도와 최종 일반화 성능을 함께 보고 결정해야 함.
