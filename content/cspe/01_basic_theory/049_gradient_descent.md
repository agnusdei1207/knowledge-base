## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 손실 함수의 기울기를 계산해 오차가 최소화되는 방향으로 가중치를 점진적 갱신하는 최적화 알고리즘임 |
| 배경/필요성 | 방대한 파라미터 공간에서 전역 최적해(Global Minimum)를 효율적으로 탐색할 방법 필요 |
| 출제 의도 | 옵티마이저의 원리, 모멘텀 및 적응형 학습률(Adaptive Learning Rate)의 개념 이해 평가 |

## Ⅱ. 구성요소
```text
+----------------+       +----------------+       +----------------+
| Objective Func |       | Learning Rate  |       | Parameter      |
| (Loss Curve)   | ----> | (Step Size)    | ----> | Optimization   |
+----------------+       +----------------+       +----------------+
```
| 학습률 (LR) | 한 번에 가중치를 업데이트하는 이동 보폭의 크기 | 걸음의 폭 |
| 모멘텀 (Momentum)| 이전 기울기 방향을 유지하려는 관성 성질 | 가속도 |
| 적응형 학습률 | 변수마다 상황에 맞게 학습률을 동적으로 조절 | 지형 맞춤형 신발 |
> 요약: 경사하강법은 손실 곡선, 학습률, 최적화 방식을 구성요소로 파라미터를 갱신함

## Ⅲ. 절차
```text
+----------------+       +----------------+       +----------------+       +----------------+
| Grad Calc      |       | Momentum Upd   |       | LR Adjust      |       | Weight Update  |
| (Derivative)   | ----> | (Inertia add)  | ----> | (Decay scale)  | ----> | (Apply change) |
+----------------+       +----------------+       +----------------+       +----------------+
```
1. 기울기 산출: 현재 가중치 위치에서 손실 함수의 편미분 기울기 계산
2. 모멘텀 적용: (선택) 이전 스텝의 기울기 정보를 더하여 현재 이동 방향 보정
3. 학습률 조절: (선택) 과거 기울기 누적치를 바탕으로 변수별 학습률 감쇄
4. 가중치 갱신: 계산된 최종 스텝만큼 가중치에서 차감하여 이동
> 요약: 기울기 산출 후 모멘텀과 적응형 학습률을 반영해 가중치를 갱신하며 이동함

## Ⅳ. 문제점
- 지역 최적해 고립: 전체 최적해가 아닌 국소적인 골짜기에 갇혀 학습 종료
- 고정 학습률 한계: 학습률이 너무 크면 발산하고, 너무 작으면 수렴 속도 저하
- 학습 조기 중단: AdaGrad 등은 기울기 누적으로 인해 학습률이 0에 수렴함

## Ⅴ. 개선방안
- 단기 방안: SGD에 모멘텀 기법을 추가하여 관성으로 지역 최적해를 탈출
- 중기 방안: 하이퍼파라미터 튜닝을 통해 데이터에 맞는 적정 초기 학습률 탐색
- 장기 방안: Adam, RMSProp 등 최신 옵티마이저를 도입하여 적응형 학습률과 모멘텀 동시 해결

## Ⅵ. 전망
- 다양한 옵티마이저 장점을 융합한 AdamW 및 2차 미분 기반 최적화 기법으로 고도화 중임
