## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 유한 오토마타(DFA/NFA)가 인식할 수 있는 언어 클래스이며, 정규 문법(Type-3)·정규 표현식과 동치인 형식 언어임 |
| **배경/필요성** | 어휘 분석·패턴 매칭·프로토콜 검증에서 정규 언어가 기반이 되며, 촘스키 계층의 최하위 클래스로 계산 이론의 출발점임 |
| **출제 의도** | 정규 언어의 닫힘 성질과 펌핑 보조 정리를 이용한 비정규 증명을 이해하는지 평가함 |

## Ⅱ. 구성요소
```
+----------+     +----------+     +----------+
| 정규표현식| --> | 유한     | --> | 정규문법  |
| (RegEx)  |     | 오토마타  |     | (Type-3) |
+----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| 정규 표현식 | `(a|b)*abb` 형태로 패턴을 기술하는 대수적 표기법임 | 검색 필터 규칙 |
| 유한 오토마타 | 정규 표현식을 인식하는 상태 기계(DFA/NFA)임 | 자동 패턴 검사기 |
| 정규 문법 | `A → aB | ε` 형태의 우선형/좌선형 생성 규칙으로 정규 언어를 생성함 | 문장 생성 규칙서 |

> 요약: 정규 표현식 ≡ 유한 오토마타 ≡ 정규 문법은 모두 동일한 정규 언어를 표현함.

## Ⅲ. 절차
```
+------------+     +------------+
| RegEx작성  | --> | NFA변환   |
| (패턴정의) |     | (Thompson) |
+------------+     +------------+
                        |
+------------+     +----+-------+
| 최소DFA   | <-- | DFA변환   |
| (최적화)   |     | (부분집합)|
+------------+     +------------+
```

1. 정규 표현식 작성: 인식할 패턴을 정규 표현식으로 기술함
2. NFA 변환: Thompson 구성법으로 정규 표현식을 NFA로 변환함
3. DFA 변환: 부분집합 구성법(Subset Construction)으로 NFA를 DFA로 변환함
4. DFA 최소화: Hopcroft 알고리즘으로 동치 상태를 병합하여 최소 DFA를 구함

> 요약: RegEx → NFA(Thompson) → DFA(부분집합) → 최소 DFA로 정규 언어 인식기를 구성함.

## Ⅳ. 문제점
- DFA 상태 폭발: NFA → DFA 변환 시 상태 수가 지수적으로 증가할 수 있음
- 표현력 한계: `{aⁿbⁿ | n≥0}` 같은 문맥 자유 언어는 정규 언어로 표현 불가함
- 역참조 미지원: 실용적 정규 표현식의 역참조(backreference)는 이론적 정규 언어를 초과함

## Ⅴ. 개선방안
- (단기) Lazy DFA: 필요한 상태만 동적 생성하여 상태 폭발을 회피함
- (중기) PDA 확장: 문맥 자유 언어가 필요하면 푸시다운 오토마타를 적용함
- (장기) RE2 엔진: 역참조 없는 선형 시간 정규 표현식 엔진(RE2)을 채택하여 ReDoS를 방지함

## Ⅵ. 전망
- 네트워크 DPI·WAF·로그 분석에서 정규 표현식이 핵심이며, 하드웨어(FPGA) 기반 정규 표현식 매칭이 고속 패킷 처리의 표준으로 확산될 전망임
