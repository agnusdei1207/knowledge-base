## Ⅰ. 개요
- 정의: 고급 언어로 작성된 소스 코드를 기계어로 변환하는 단계별 처리 과정임.
- 배경: 프로그래밍 언어의 실행 효율성과 하드웨어 종속성 해결을 위해 필요함.
- 출제 의도:
| 분류 | 상세 |
| --- | --- |
| 핵심요소 | 스캐너, 파서, 중간 코드, 최적화 |
| 주요특징 | 단계별 분리, 오류 탐지, 코드 품질 향상 |

## Ⅱ. 구성요소
- ASCII 구조도
 [Lexical] -> [Syntax] -> [Semantic] -> [ICG] -> [Opt] -> [Target]
 (Tokens)     (AST)      (Annotated)  (Code)   (Best)   (Obj)
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 어휘 분석 | 소스 코드를 토큰 단위로 분리 (Scanner) | 단어 쪼개기 |
| 구문 분석 | 문법적 구조를 파악하여 트리 생성 (Parser) | 문장 성분 분석 |
| 의미 분석 | 타입 체크 등 논리적 정당성 검사 | 문맥 확인 |
> 요약: 소스 코드를 분석하여 의미를 추출하고 기계어로 재구성함.

## Ⅲ. 절차
- ASCII 흐름도
[코드 입력] -> [전반부 분석] -> [후반부 생성] -> [실행 파일]
- 4단계 설명
1. 프런트엔드: 언어 사양을 분석하여 중간 표현(IR)을 생성함.
2. 미들엔드: 기계 독립적 최적화를 통해 코드 성능을 개선함.
3. 백엔드: 대상 아키텍처에 맞는 목적 코드를 생성함.
4. 링킹/로딩: 여러 모듈을 합쳐 실제 실행 가능 상태로 만듦.
> 요약: 분석, 최적화, 생성 단계를 거쳐 소프트웨어를 하드웨어에 연결함.

## Ⅳ. 문제점
- 컴파일 시간이 길어지거나 생성된 코드가 비효율적일 수 있음.

## Ⅴ. 개선방안
- 단기: 점진적 컴파일(Incremental)이나 캐싱을 사용함.
- 중기: JIT(Just-In-Time) 컴파일 방식을 혼합하여 실행 속도를 높임.
- 장기: LLVM과 같은 범용 인프라를 활용해 다국어/다플랫폼 대응함.

## Ⅵ. 전망
- AI 모델 컴파일러(TVM 등)의 발전으로 딥러닝 가속화 기술로 확장됨.
