# 전이 학습 (Transfer Learning)

## 1. 개요

- **정의/개념**: 전이 학습은 대규모 데이터나 관련 도메인에서 학습한 모델의 지식을 새로운 과제에 재사용해 학습 비용과 데이터 요구량을 줄이는 방법이다.
- **배경/필요성**: 실무에서는 충분한 라벨 데이터가 부족한 경우가 많으므로, 범용 특징을 이미 학습한 모델을 활용해 빠르게 성능을 확보할 필요가 있다.

전이 학습의 핵심은 원천 도메인에서 배운 표현이 목표 도메인에도 유효한지 판단하는 것이다.

## 2. 특징 및 비교

| 구분 | Feature Extraction | Fine-tuning | From Scratch |
|---|---|---|---|
| 방식 | backbone 고정 | 일부 또는 전체 재학습 | 무작위 초기화 학습 |
| 데이터 요구 | 낮음 | 중간 | 높음 |
| 계산 비용 | 낮음 | 중간~높음 | 높음 |
| 위험 | 표현 한계 | catastrophic forgetting | 과적합 |

선택 기준은 도메인 유사도, 라벨 데이터 규모, 계산 자원, 성능 목표, 배포 제약이다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| Pre-trained Model | 원천 과제에서 학습된 모델 | 지식 재사용 |
| Source Domain | 사전학습 데이터·과제 | 유사도 판단 |
| Target Domain | 적용할 새 업무 데이터 | 성능 목표 |
| Frozen Layer | 고정할 파라미터 | 과적합 방지 |
| Task Head | 새 과제 출력층 | 분류·회귀 등 |

```text
+-------------+      +----------+      +----------+      +----------+
| 사전학습모델 | ---> | layer선택 | ---> | head교체 | ---> | fine-tune |
+-------------+      +----------+      +----------+      +----------+
```

사전학습 표현이 목표 데이터와 맞지 않으면 재사용이 오히려 성능을 해칠 수 있으므로 도메인 유사도 검증이 먼저 필요하다.

## 4. 문제점 및 개선방안

1. **Negative Transfer**
   - 원천 도메인과 목표 도메인이 다르면 잘못된 표현이 전이될 수 있다.
   - **개선방안**: 도메인 유사도 평가, 일부 layer만 재학습, domain adaptation을 적용한다.

2. **Catastrophic Forgetting**
   - fine-tuning 과정에서 기존 유용한 표현이 급격히 손상될 수 있다.
   - **개선방안**: 낮은 learning rate, gradual unfreezing, regularization을 사용한다.

3. **라이선스·보안 위험**
   - 사전학습 모델의 데이터 출처와 사용 조건이 불명확할 수 있다.
   - **개선방안**: 모델 라이선스, 데이터 정책, 보안 검증 절차를 확인한다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| 이미지 분류 | ImageNet backbone에 업무 head를 추가 | accuracy, 학습 시간 |
| NLP 분류 | 사전학습 언어모델을 도메인 문서로 fine-tuning | F1, latency |
| 제조 검사 | 소량 불량 이미지로 pretrained CNN 재학습 | recall, 오탐률 |

## 6. 결론

전이 학습은 기존 모델의 표현을 새 과제에 재사용해 데이터와 비용 제약을 완화하는 방법이다. 도메인 유사도, freeze/fine-tuning 범위, 데이터 규모, 운영 제약을 함께 판단해야 재사용 이점과 위험을 균형 있게 설명할 수 있다.
