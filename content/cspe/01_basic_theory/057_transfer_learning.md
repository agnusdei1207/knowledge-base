# 📖 【암기용】 개념 완전 이해

> 목적: 이 개념을 처음 보는 사람도 완벽히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: **사전 학습(Pre-training)**된 모델이 다른 문제를 풀면서 익힌 지식(가중치)을, 비슷하지만 다른 새로운 문제에 그대로 가져와 재사용하는 머신러닝 기법
- **왜 필요한가**: 수천만 장의 이미지나 수십억 개의 문서로 모델을 처음부터 바닥(Scratch)에서 학습시키려면 천문학적인 컴퓨팅 자원과 시간이 든다. 이를 피하기 위해 이미 똑똑해진 사전 학습 모델(Pre-trained Model)의 지식을 빌려오는 것이다.
- **핵심 직관**: 자전거 타는 법을 배운 사람은 오토바이 타는 법을 아주 빨리 배운다. 균형을 잡는다는 "공통된 핵심 지식"을 이미 알고 있기 때문이다.

## 핵심 용어 정리 (내부에 등장하는 것들)

| 용어 | 의미 | 비유 |
|:---|:---|:---|
| 사전 학습 (Pre-training) | 대규모 범용 데이터로 모델을 미리 훈련시켜 두는 과정 — 이 개념의 핵심 키워드 | 대학 4년간의 기초 교육 |
| 소스 도메인/타겟 도메인 (Source/Target) | 사전 학습에 쓰인 원래 데이터·과제(Source)와 새로 풀려는 실제 데이터·과제(Target) | 배운 학과(Source)와 실제 배치받은 부서(Target) |
| 특성 추출기 (Feature Extractor) | 모델의 앞쪽 층. 선·색깔·기본 문법 등 범용 패턴을 인식하는 부분 | 어느 분야든 통하는 기초 소양 |
| 동결 (Freeze) | 특정 층의 가중치를 학습 중 갱신하지 않도록 고정하는 것 | 이미 완성된 지식은 건드리지 않음 |
| 분류기/헤드 (Head) | 모델의 맨 뒤쪽 층. 타겟 과제의 클래스 수에 맞춰 새로 갈아 끼우는 부분 | 새 업무에 맞춘 실무 교육 |
| 미세 조정 (Fine-tuning) | 사전 학습된 가중치를 타겟 데이터로 소폭만 추가 학습시키는 과정 | 현장 배치 후 1주일 OJT |
| 부정 전이 (Negative Transfer) | 소스와 타겟 도메인이 너무 달라 전이가 오히려 성능을 떨어뜨리는 실패 | 엉뚱한 전공 지식을 억지로 적용해 오히려 방해 |
| 파국적 망각 (Catastrophic Forgetting) | 학습률이 너무 커서 기존에 배운 좋은 가중치가 무너지는 현상 | 새 업무를 배우다 기존 실력까지 잊어버림 |
| PEFT/LoRA | 원본 가중치는 그대로 두고 작은 추가 모듈만 학습시키는 경량 전이 기법 | 원서에 밑줄만 긋고 본문은 안 고침 |

## 깊이 이해

### 왜 처음부터 학습하면 안 되나 (수치로)
- ResNet-50은 파라미터가 약 2,500만 개다. 이런 모델을 라벨링된 데이터 100만 장(ImageNet 규모)으로 학습시키는 데는 고성능 GPU로도 며칠이 걸린다. 반면 회사가 가진 불량 이미지가 500장뿐이라면, 2,500만 개 가중치를 500장만으로 처음부터 학습시키는 것은 사실상 불가능하다 — 데이터당 파라미터 비율이 극단적으로 낮아 100% 암기(과적합)로 귀결된다.
- 전이 학습은 이미 다른 대규모 데이터(ImageNet 100만 장 등)로 학습된 가중치를 초기값으로 가져와, 500장만으로 마지막 층 몇 개만 살짝 조정(Fine-tuning)한다. "선, 모서리, 질감을 구분하는 능력"처럼 범용적인 저수준 지식은 이미 갖춰져 있으므로 다시 배울 필요가 없다.

### 동결(Freeze)과 미세조정을 수치로 따라가기
- ResNet-50(약 2,500만 파라미터)에서 앞쪽 특성 추출기(하위 40개 층, 약 2,300만 파라미터)는 가중치 갱신을 멈추고(Freeze), 마지막 분류층(Head)만 새로 만들어(자사 불량 클래스 5개에 맞춰 재설계) 학습 가능 상태로 둔다. 이 경우 실제로 갱신되는 파라미터는 200만 개 남짓으로, 전체의 8% 수준만 500장의 데이터로 학습하면 된다.
- 학습률도 처음부터 학습할 때(보통 $10^{-2} \sim 10^{-3}$)보다 훨씬 작은 $10^{-4} \sim 10^{-5}$를 쓴다. 학습률이 크면 몇 스텝 만에 사전 학습된 좋은 가중치가 무너져(파국적 망각) 원래 가진 일반화 능력을 잃는다. 학습률 $10^{-2}$로 몇 에폭만 돌려도 검증 손실이 초반보다 오히려 급증하는 현상이 파국적 망각의 전형적인 신호다.

### 데이터 크기 × 도메인 유사도로 전략이 갈리는 이유
- 데이터가 적고(<1,000장) 도메인이 유사(예: ImageNet 강아지 → 우리집 강아지 품종): 특성 추출기 전부를 동결하고 Head만 학습해도 충분하다. 이미 배운 저수준 특징이 그대로 재사용 가능하기 때문이다.
- 데이터가 적고 도메인이 상이(예: 자연 이미지 → 의료 초음파): 전부 동결하면 부정 전이가 발생할 수 있다. 초음파 이미지의 결(texture) 패턴이 자연 이미지의 결과 근본적으로 달라, 억지로 재사용하면 바닥부터 학습한 것보다 오히려 성능이 나빠질 수 있다. 이때는 중간층 일부를 풀어(Unfreeze) 도메인 특성을 재학습시킨다.
- 데이터가 많고(>10만 장): 도메인 유사도와 무관하게 전체 층을 풀어 미세조정해도 과적합 위험이 낮으므로, 사전 학습 가중치는 사실상 "좋은 초기값" 역할만 하고 전체를 재학습한다.

### PEFT·LoRA — 초거대 모델 시대의 전이 학습
- 파라미터가 70억 개(7B)인 LLM은 전이 학습 시 모든 가중치를 갱신하려면 GPU 메모리가 감당되지 않는다. LoRA(Low-Rank Adaptation)는 원본 가중치는 완전히 동결한 채, 각 층 옆에 작은 저차원 행렬(Rank=8 정도)만 추가로 붙여 그것만 학습시킨다.
- 예: 원본 가중치 행렬이 4096×4096(약 1,678만 개)이라면, Rank 8 LoRA는 $4096\times8 + 8\times4096 = 65,536$개 파라미터만 추가로 학습한다 — 원본 대비 약 0.4% 수준이다. 7B 모델 전체로 보면 학습 가능 파라미터가 전체의 0.1% 미만으로 줄어들어, 일반 GPU 한 대로도 미세조정이 가능해진다.

### 비유와 흔한 오해
- **비유**: 대학에서 4년간 물리학·수학(사전 학습)을 마친 졸업생을 뽑아, 회사의 반도체 공정 매뉴얼(Fine-tuning)만 1주일 가르쳐 현장에 투입하는 것과 같다. 유치원생부터 새로 가르칠 필요가 없다.
- **오해**: "사전 학습 모델을 가져오면 무조건 좋다"고 오해하기 쉽지만, 소스 도메인과 타겟 도메인이 너무 다르면(예: 자율주행 이미지 모델을 세포 현미경 이미지에 그대로 적용) 오히려 바닥부터 학습한 것보다 성능이 떨어지는 부정 전이가 발생할 수 있다. 도메인 유사도를 먼저 확인하는 것이 전이 학습의 첫 단계다.

## 연결 개념
- 파인 튜닝 (Fine-tuning) — 전이 학습의 일환으로, 가져온 모델의 가중치를 내 데이터에 맞게 미세 조정하는 작업
- 사전 학습 모델 (Pre-trained Model) — 전이 학습의 뼈대가 되는 모델 (ResNet, BERT, GPT 등)
- 제로샷 러닝 (Zero-shot Learning) — 추가 학습(Fine-tuning)조차 없이, 프롬프트만으로 새로운 태스크를 수행하는 기법

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 전이 학습(Transfer Learning)은 소스 도메인(Source Domain)에서 학습된 모델의 가중치를 타겟 도메인(Target Domain)의 문제 해결을 위한 초기값으로 재사용하는 기법이다.
> 2. **가치**: 대규모 연산 자원과 빅데이터가 필요한 모델의 초기 학습(Pre-training) 비용을 매몰시키지 않고, 소규모 데이터셋 환경에서도 과적합 없이 고성능 모델을 빠르게 수렴시킨다.
> 3. **판단 포인트**: 타겟 데이터의 크기와 소스 데이터와의 유사성에 따라 가중치 동결(Freezing) 범위와 파인 튜닝(Fine-tuning) 전략을 다르게 설계해야 부정 전이(Negative Transfer)를 막을 수 있다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 딥러닝 실무의 핵심 파이프라인(Pre-train + Fine-tuning) 파악 | Source Domain과 Target Domain 개념, 가중치 동결(Freeze) 메커니즘 | 단순 "가져다 쓴다"는 추상 서술 |
| 데이터 제약 환경에서의 전이 전략 선택 | 데이터 크기 및 유사도 4분면에 따른 Fine-tuning 계층 조절 | 모든 층을 훈련시킨다고 오답 서술 |
| 전이 학습 실패 리스크 관리 | 부정 전이(Negative Transfer) 원인과 Domain Adaptation 방안 | LLM 중심 시대의 전이 학습(PEFT 등) 발전 방향 누락 |

> 요약: 바닥부터 학습(Training from scratch)할 때의 연산 병목과 과적합을 어떻게 기존 모델의 지식(Feature Extractor) 재활용으로 우회하는지 묻는다.

## Ⅰ. 개요 및 필요성

- 정의: 특정 태스크(Source)를 해결하기 위해 훈련된 신경망의 파라미터(지식)를 다른 연관된 태스크(Target)의 학습 모델에 이식하는 기법
- 배경: ResNet, BERT 등 1억 개 이상의 파라미터를 가진 거대 모델을 개별 기업이 바닥(Scratch)부터 훈련시키는 것은 비용 및 데이터 한계로 불가능
- 필요성: 수천 장 미만의 Small Data 환경에서 과적합을 회피하고 훈련 수렴 속도를 O(1) 수준으로 단축하기 위한 필수 파이프라인

---

## Ⅱ. 구조 및 구성요소

```text
[Source Task 훈련] 대규모 데이터 -> [사전 학습 모델 (Pre-trained Backbone)] -> Source 맵핑 지식(가중치) 확보
                                         | (지식 전이)
[Target Task 적용] 소규모 데이터 -> [Backbone 일부 고정(Freeze) + 신규 분류기(Head) 결합] -> Fine-tuning
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 사전 학습 모델 (Pre-trained) | 범용적 특성(선, 색상, 기본 문법 등)이 이미 학습된 가중치 | ImageNet(Vision), Wikipedia(NLP) 활용 |
| 특성 추출기 (Feature Extractor) | 모델의 앞단(하위 층). 저수준의 일반적 패턴 추출 | 전이 시 파라미터 업데이트를 중지(Freeze)함 |
| 분류기 (Classifier / Head) | 모델의 뒷단(상위 층). 태스크에 특화된 최종 결과 도출 | 타겟 클래스 수에 맞춰 새로 생성(Random Init) |

> 요약: 앞쪽 층은 인류 공통의 범용 지식을 담고 있으므로 얼리고(Freeze), 뒷쪽 층만 내 문제에 맞게 새로 갈아 끼워(Head Replacement) 학습한다.

---

## Ⅲ. 동작원리 및 흐름도

```text
Pre-trained 모델 다운로드 -> 분류 층(Head) 교체 -> 가중치 동결(Freeze) 설정 -> 소규모 데이터로 오차 역전파
```

| 단계 | 처리 내용 | 검증 기준 / 효과 |
|:---:|:---|:---|
| 1 | 타겟 태스크와 도메인이 유사한 사전 학습 모델 선정 | ImageNet 기반 ResNet, VGG 등 로드 |
| 2 | 기존 모델의 마지막 FC 층 제거 및 타겟 클래스용 FC 층 결합 | 분류 노드 수 N개로 재설정 |
| 3 | Feature Extractor(하위 층)의 Gradient 계산 비활성화 (Freeze) | 기존 학습된 가중치 훼손(Catastrophic Forgetting) 방지 |
| 4 | 아주 작은 학습률(Learning Rate)로 Target 데이터 Fine-tuning | $10^{-4}$ 이하 LR로 분류기 가중치만 갱신 |

> 요약: 범용 지식이 파괴되지 않도록 앞쪽 층을 단단히 고정하고, 매우 작은 보폭(학습률)으로 출력층만 섬세하게 미세 조정한다.

---

## Ⅳ. 데이터 조건에 따른 전이 학습(Fine-Tuning) 전략

| 타겟 데이터 크기 | 소스(Pre-trained)와의 유사도 | 학습(Update) 전략 | 판단 포인트 |
|:---|:---|:---|:---|
| 크기가 작음 | 도메인이 매우 유사함 | 분류기(Head)만 학습, 나머지 전층 동결 | 과적합 위험 극대화 상황. 특성 추출기 완전 신뢰 |
| 크기가 작음 | 도메인이 상이함 | 모델의 중반부 이후부터 학습(일부 Unfreeze) | 데이터가 적어 부정 전이 발생 위험, 조심스러운 튜닝 필요 |
| 크기가 큼 | 도메인이 매우 유사함 | 전체 층 미세 조정 (All-layer Fine-tuning) | 데이터가 충분하므로 모델 전체를 내 데이터에 최적화 가능 |
| 크기가 큼 | 도메인이 상이함 | 전체 층 미세 조정 또는 Scratch 학습 | 사실상 사전 학습 모델은 가중치 초기화(Init) 용도로만 사용 |

> 요약: 데이터가 적을수록 과적합을 막기 위해 가중치를 많이 얼려야(Freeze) 하며, 데이터가 충분하면 전체를 녹여서(Unfreeze) 튜닝해도 무방하다.

---

## Ⅴ. 심화 비교 및 적용 판단

| 리스크 | 발생 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 부정 전이 (Negative Transfer) | 자율주행 모델을 현미경 세포 분석에 적용하는 등 소스/타겟 도메인 간 특징 교집합 부재 | Domain Adaptation 적용, 전이 거부 및 바닥(Scratch) 학습 | Target Test Accuracy 폭락 |
| 파국적 망각 (Catastrophic Forgetting) | 큰 학습률(LR)로 튜닝하여 기존 사전 학습 모델이 가진 우수한 일반화 특성을 모두 잃어버림 | LR을 $10^{-5}$로 축소, 하위 층 강력히 동결 | Validation Loss 급증 |

> 요약: 전이 학습의 실패는 억지로 맞지 않는 지식을 끼워 넣거나(부정 전이), 너무 세게 학습시켜 원래 똑똑했던 뇌를 망치는(파국적 망각) 데서 온다.

| 구분 | Fine-tuning (전이 학습 주류) | PEFT (Parameter-Efficient FT) | 선택 기준 |
|:---|:---|:---|:---|
| 학습 파라미터 | 타겟 태스크에 맞춘 전체 또는 일부 층 가중치 갱신 | 1% 미만의 어댑터(Adapter/LoRA) 파라미터만 추가 학습 | VRAM 자원 (GPU 메모리 제약) |
| 원본 모델 보존 | 튜닝 과정에서 원본 가중치가 영구적으로 변경됨 | 원본 거대 모델은 완벽히 보존(Freeze)됨 | 여러 고객사(Multi-Tenant) 서빙 여부 |

> 요약: 수백억 파라미터의 LLM 시대에는 전체를 튜닝하기 불가능하므로, 옆구리에 작은 모듈만 달아 학습시키는 LoRA 등 PEFT(매개변수 효율적 튜닝)가 전이 학습의 새 표준이다.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 제조업 불량 검출 비전: ImageNet으로 사전 학습된 ResNet-50을 백본으로 활용, 앞단의 40개 계층을 동결(Freeze)하고 끝단의 분류기만 자사 불량 이미지 1,000장으로 Fine-tuning.
2. 금융권 문서 분류 NLP: 한국어 위키피디아로 학습된 KLUE-BERT 모델을 로드하여, 은행 규정집 및 대출 약관 도메인 텍스트로 Task-specific Fine-tuning 수행(F1-score 90% 달성).
3. LLM 효율적 튜닝 (LoRA): 7B 파라미터 오픈소스 LLM을 사내 보안망에 띄우고, 원본 모델은 동결한 채 LoRA 기법으로 Rank 8의 저차원 행렬만 학습시켜 VRAM 사용량을 1/4로 절감.

**결론 (2줄):**
- 기술사 판단: 전이 학습은 모델의 '구조'가 아닌 '지식(가중치)'을 재사용함으로써 딥러닝의 실용화 장벽(데이터/연산량 부족)을 허문 가장 결정적인 엔지니어링 패러다임이다.
- 향후 방향: 사전 학습 모델의 크기가 LLM급으로 거대해짐에 따라, 전이 방식은 가중치 갱신(Fine-tuning)을 넘어 프롬프트 튜닝이나 RAG(검색 증강)로 지식을 덧대는 방향으로 진화 중이다.
