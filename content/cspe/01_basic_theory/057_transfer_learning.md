## 미리 알고가기

- 소스 도메인: 사전 학습에 사용된 데이터 영역이며 범용 표현의 출처가 됨
- 타깃 도메인: 새로 해결하려는 업무와 데이터 영역이며 최종 성능 평가 기준이 됨
- 사전 학습 모델: 대규모 데이터로 먼저 학습되어 재사용 가능한 표현을 가진 모델임
- 특징 추출: 백본 가중치를 고정하고 새 태스크 헤드만 학습하는 전이 학습 방식임
- 미세 조정: 사전 학습 가중치 일부 또는 전체를 낮은 학습률로 추가 학습하는 방식임
- 부정적 전이: 소스와 타깃 도메인이 달라 전이 학습이 오히려 성능을 낮추는 현상임

## 작성 근거(검토용)

- 개요는 소스·타깃 도메인과 가중치 재사용을 포함해 전이 학습의 범위를 명확히 함
- 특징은 수렴, 계층 재사용, 비용 절감, 부정적 전이를 균형 있게 배치함
- 비교표는 처음부터 학습, 특징 추출, 미세 조정의 선택 조건을 직접 비교함
- 구성요소는 백본, 헤드, 동결, 학습률, 검증 데이터로 실제 절차 단위를 일치시킴
- 절차는 모델 선택에서 점진 조정까지 실무 흐름을 단계화함
- 라벨 부족과 소스·타깃 도메인 차이는 전이 효과를 가르는 대표 조건임

## Ⅰ. 개요

- **정의/개념**: 전이 학습은 소스 도메인에서 학습한 모델의 표현과 가중치를 타깃 도메인 학습에 재사용하는 학습 전략임
- **배경/필요성**: 타깃 라벨 수집량과 학습 연산량을 줄이기 위해 사전 학습 표현을 재사용해야 함

## Ⅱ. 특징

- 사전 학습 표현을 초기값으로 사용해 무작위 가중치에서 시작하는 학습 단계를 줄임
- 하위 층의 범용 특징과 상위 층의 과제 특화 특징을 분리해 재사용 범위를 조절함
- 소스와 타깃의 특징이 유사하면 적은 타깃 라벨로도 사전 학습 표현을 재사용할 수 있음
- 소스와 타깃 분포 차이가 크면 부정적 전이가 발생해 처음부터 학습한 모델보다 성능이 낮아질 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | 처음부터 학습 | 특징 추출 | 미세 조정 |
|:---|:---|:---|:---|
| 초기 가중치 | 무작위 초기값 | 사전 학습 가중치 | 사전 학습 가중치 |
| 갱신 범위 | 전체 가중치 | 태스크 헤드 | 일부 또는 전체 백본 |
| 적용 조건 | 적합한 사전 학습 모델이 없고 타깃 라벨이 충분함 | 소스·타깃 도메인이 유사하고 타깃 라벨이 적음 | 타깃 라벨로 사전 학습 표현을 조정해야 함 |

> 요약: 타깃 라벨이 적고 두 도메인이 유사하면 특징 추출, 타깃 라벨로 표현을 조정해야 하면 미세 조정을 선택함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 사전 학습 백본 | 소스 도메인의 표현을 가진 모델 본체이며 타깃 데이터의 특징 추출에 재사용됨 |
| 태스크 헤드 | 타깃 클래스, 회귀값, 토큰 출력처럼 새 업무 형식에 맞는 출력층임 |
| 동결 정책 | 어떤 층을 고정하고 어떤 층을 학습할지 정해 지식 보존과 적응을 조절함 |
| 학습률 정책 | 백본은 낮게, 태스크 헤드는 높게 설정해 파괴적 망각을 줄임 |
| 검증 데이터 | 전이 효과와 부정적 전이를 판정하는 기준 데이터임 |

```text
+-------------+      +-------------+      +-------------+
| 사전 학습   | ---> | 태스크 헤드 | ---> | 타깃 예측   |
| 백본        |      | 새 출력층   |      | 결과        |
+-------------+      +-------------+      +-------------+
       |
       v
+-------------+
| 동결/조정   |
+-------------+
```

> 요약: 전이 학습은 사전 학습 백본을 보존하거나 조정하며 새 태스크 헤드에 연결함.

## Ⅴ. 원리 및 절차 흐름도

```text
모델 선택 ---> 헤드 교체 ---> 헤드 학습 ---> 필요 시 미세 조정
```

1. **모델 선택**: 타깃 업무와 가장 유사한 소스 도메인의 사전 학습 모델을 선택함
2. **태스크 헤드 교체**: 타깃 데이터의 클래스 수와 출력 형식에 맞게 태스크 헤드를 교체함
3. **초기 학습**: 백본을 동결하고 태스크 헤드를 먼저 학습해 출력 분포를 맞춤
4. **점진 조정**: 검증 성능 개선이 필요하면 상위 층부터 동결을 풀고 낮은 학습률로 타깃 도메인에 적응시킴

> 요약: 소스와 타깃의 특징이 유사하면 백본을 동결하고, 타깃 라벨이 충분하면 상위 층부터 동결을 풀어 조정함.

## Ⅵ. 실무 사례

1. 장애 티켓 분류는 사전 학습 백본을 동결하고 Macro-F1·학습 시간으로 전이 효과를 확인함
2. 내부 문서 분류는 상위 층을 점진적으로 비동결하고 Macro-F1·클래스별 재현율로 검증함

## Ⅶ. 결론

- 전이 학습은 사전 학습 지식을 재사용해 데이터와 비용을 줄이는 전략이며, 도메인 유사성과 미세 조정 범위가 핵심 판단 기준임
