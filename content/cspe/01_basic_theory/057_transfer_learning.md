## 미리 알고가기

- 사전학습: 대규모 데이터로 일반적인 표현을 먼저 학습하는 단계임
- 미세조정: 사전학습 모델을 목표 태스크 데이터로 추가 학습하는 단계임
- 동결: 일부 층의 파라미터를 업데이트하지 않도록 고정하는 방법임
- 도메인 차이: 원천 데이터와 목표 데이터의 분포·용어·형식이 다른 정도임
- PEFT: 일부 파라미터만 학습해 비용을 줄이는 파라미터 효율 미세조정 방식임

## Ⅰ. 개요

- **정의**: 전이 학습은 원천 도메인에서 사전학습된 모델의 표현이나 파라미터를 목표 도메인 태스크에 재사용하고, 데이터 차이와 목표 지표 기준으로 일부 또는 전체를 조정하는 학습 전략임
- **배경/필요성**: 딥러닝 모델은 많은 데이터와 연산 자원이 필요하지만 실무에서는 라벨이 부족한 경우가 많으므로, 이미 학습된 일반 표현을 활용해 비용과 시간을 줄여야 함
- **비유**: 기본기를 익힌 전문가가 새 업무의 규칙만 추가로 배워 더 빠르게 적응하는 방식과 같음

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 재사용 학습 구조 이해 | Pre-train, feature extraction, fine-tuning | 단순 모델 복사로 설명 |
| 적용 조건 판단 | 도메인 유사도, 데이터 규모, 동결 범위 | 부정 전이 누락 |

> 요약: 전이 학습은 사전학습 지식을 목표 문제에 맞게 재사용해 적은 데이터와 비용으로 성능을 확보하는 방법임.

## Ⅱ. 특징/비교

| 판단 기준 | 처음부터 학습·특징 추출 | Fine-tuning·PEFT |
|:---|:---|:---|
| 데이터 요구 | 처음부터 학습은 많은 라벨과 연산이 필요하고 특징 추출은 표현 수정이 제한됨 | 적은 데이터로도 목표 태스크에 표현을 조정할 수 있음 |
| 비용 | 전체 학습은 비용이 크고 특징 추출은 비용이 작음 | 풀 미세조정은 중간 이상, PEFT는 비용을 크게 줄임 |
| 적응력 | 처음부터 학습은 도메인 맞춤이 강하고 특징 추출은 약함 | 목표 도메인에 맞춰 성능을 개선할 수 있음 |
| 선택 조건 | 데이터가 충분하거나 원천 모델이 부적합할 때 대안이 됨 | 원천·목표 도메인이 어느 정도 유사하고 빠른 적용이 필요할 때 적합함 |

> 요약: 전이 학습 방식은 데이터 규모, 도메인 유사도, 비용 제약에 따라 특징 추출, 부분 동결, 풀 미세조정, PEFT를 선택함.

- **입력 조건**: 원천 모델의 입력 형식과 목표 데이터 형식이 변환 가능해야 함
- **평가 기준**: 기준선 대비 성능 향상, 비용 절감, 도메인별 편차를 함께 확인함
- **선택 판단**: 라벨이 부족하고 원천·목표 도메인이 유사할 때 우선 적용함

## Ⅲ. 구성요소

```text
+------------+      +------------+      +------------+
| 원천 데이터 | ---> | 사전학습 모델 | ---> | 목표 모델   |
+------------+      +------------+      +------------+
                                            |
                                            v
+------------+      +------------+      +------------+
| 목표 데이터 | ---> | 미세조정    | ---> | 성능 평가   |
+------------+      +------------+      +------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 원천 데이터 | 모델이 일반 표현을 배우는 데 사용된 대규모 데이터임 | 기본 교재 |
| 사전학습 모델 | 원천 데이터에서 학습된 파라미터와 표현을 보유한 모델임 | 경력자 |
| 목표 데이터 | 실제 해결하려는 도메인의 라벨 또는 입력 데이터임 | 새 업무 자료 |
| 미세조정 전략 | 동결 범위, 학습률, PEFT 모듈 등 목표 적응 방법을 결정함 | 적응 교육 |
| 성능 평가 | 목표 태스크 지표와 도메인 검증셋으로 전이 효과를 확인함 | 현장 평가 |

> 요약: 전이 학습은 사전학습 모델과 목표 데이터를 연결하고 조정 범위를 설계해 목표 성능을 검증하는 구조임.

## Ⅳ. 절차

```text
+------------+      +------------+      +------------+      +------------+
| 모델 선택   | ---> | 헤드 교체   | ---> | 미세조정    | ---> | 검증·배포   |
+------------+      +------------+      +------------+      +------------+
```

1. **모델 선택**: 목표 데이터와 유사한 원천 도메인에서 학습된 모델을 고르고 라이선스와 입력 형식을 확인함
2. **구조 조정**: 출력 헤드, 토크나이저, 입력 크기, 클래스 수를 목표 태스크에 맞게 변경함
3. **미세조정**: 동결 범위, 학습률, PEFT 여부를 정해 목표 데이터로 추가 학습함
4. **검증·배포**: 기준선 모델과 비교하고 도메인별 성능, 편향, 추론 비용을 확인함

> 요약: 전이 학습 절차는 적합한 사전학습 모델을 고르고 목표 태스크에 맞게 조정한 뒤 실제 성능과 비용을 검증하는 흐름임.

- **산출물**: 조정된 모델, 동결 범위, fine-tuning 로그, 목표 태스크 성능임
- **검증 기준**: 기준선보다 성능 또는 비용 측면에서 명확한 이득이 있어야 함
- **운영 기록**: 원천 모델, 라이선스, 데이터 출처, 학습 파라미터를 함께 남겨야 함

## Ⅴ. 문제점

- **P1 부정 전이**: 원천 도메인과 목표 도메인이 다르면 기존 표현이 오히려 목표 성능을 낮출 수 있음
- **P2 파국적 망각**: 풀 미세조정 과정에서 기존 일반 표현이 손상되어 소량 데이터에 과적합될 수 있음
- **P3 라이선스·데이터 위험**: 사전학습 데이터 출처, 모델 라이선스, 개인정보 포함 여부가 불명확하면 운영·법적 문제가 생김

> 요약: 전이 학습은 재사용 효율이 크지만 도메인 차이, 지식 손상, 원천 모델의 책임 범위를 관리해야 함.

## Ⅵ. 개선방안

- **P1 대응**: 원천·목표 도메인 유사도 점검, 기준선 비교, 소량 샘플 검증을 먼저 수행함 (확인: scratch 모델 대비 성능)
- **P2 대응**: 층별 동결, 낮은 학습률, LoRA·Adapter 등 PEFT, 조기 종료를 적용함 (확인: 검증 손실과 일반 태스크 성능)
- **P3 대응**: 모델 카드, 데이터 카드, 라이선스, 개인정보 처리 기록을 검토하고 승인 절차를 둠 (확인: 사용 조건과 감사 로그)

> 요약: 전이 학습 개선은 기술 성능뿐 아니라 원천 모델 적합성, 조정 범위, 사용 책임을 함께 검증하는 것임.

- **우선순위**: 도메인 유사도와 원천 모델 사용 조건을 먼저 확인함
- **확인 지표**: 기준선 대비 성능, 학습 비용, 도메인별 오류율을 함께 사용함
- **재평가 조건**: 목표 데이터가 누적되거나 업무 용어·클래스가 바뀌면 미세조정 범위를 재검토함

## Ⅶ. 전망

- **발전 방향**: 전이 학습은 PEFT, RAG, 지속 학습, 사내 모델 거버넌스와 결합해 제한된 데이터로 업무 특화 AI를 구축하는 기본 방식으로 발전함
- **설계 관점**: 원천·목표 도메인 유사도, 데이터 규모, 동결 범위, 학습률, 추론 비용, 유지보수 가능성을 기준으로 전이 전략을 선택해야 함
- **검증 관점**: scratch 모델 대비 성능, 도메인별 오류율, 검증 손실, 일반 태스크 성능을 함께 확인해 부정 전이와 파국적 망각을 검증해야 함
- **운영 관점**: 목표 데이터가 누적되거나 업무 용어·클래스가 바뀌면 미세조정 범위, 모델 버전, 성능 드리프트를 관리해야 함
- **적용 관점**: 비전·언어·멀티모달처럼 사전학습 표현이 강한 분야에는 효과적이지만 원천 도메인과 목표 도메인이 다르면 기준선 비교가 선행되어야 함
- **보안·신뢰 관점**: 사전학습 데이터 출처, 라이선스, 개인정보 포함 여부가 불명확하면 운영 책임이 생기므로 모델 카드와 감사 로그로 사용 조건을 확인해야 함
- **기술사 제언**: 전이 학습은 큰 모델 선택 문제가 아니라 원천 모델 적합성, 조정 범위, 데이터 책임을 함께 판단하는 아키텍처 결정으로 설명해야 함
