## 미리 알고가기

- 사전 학습 모델($Pre-trained$ $Model$): 이미 방대한 양의 데이터로 학습이 완료되어 데이터의 일반적인 특징을 잘 파악하고 있는 모델(예: $BERT, ResNet$)임
- 미세 조정($Fine-tuning$): 사전 학습된 모델을 새로운 목적에 맞춰 일부 파라미터를 추가적으로 학습시키는 과정임
- 가중치 동결($Freezing$): 사전 학습된 층의 가중치가 변하지 않도록 학습 대상에서 제외하는 설정임
- 도메인($Domain$): 데이터가 발생한 영역이나 환경을 의미하며, 학습 데이터와 실제 데이터의 도메인이 다르면 성능이 떨어질 수 있음

## Ⅰ. 개요

- **정의/개념**: 전이 학습은 특정 분야(Source Domain)에서 이미 학습된 풍부한 지식과 파라미터를 다른 새로운 분야(Target Domain)에 재사용하여, 모델의 성능을 높이고 학습 시간을 획기적으로 단축시키는 효율적인 학습 방식임
- **배경/필요성**: 실제 현장에서는 대규모의 정답 라벨($Label$)이 있는 데이터를 확보하기 어렵고 연산 자원이 부족한 경우가 많으므로, 이미 검증된 지식을 활용하여 '거인의 어깨 위에서' 학습을 시작하기 위해 도입됨

## Ⅱ. 특징

- 데이터가 부족한 환경에서도 높은 초기 성능($Jumpstart$)을 보이며, 밑바닥부터 학습하는 것보다 훨씬 더 빠르게 수렴($Convergence$)하여 전체적인 인프라 비용을 절감함
- 하위 층($Lower$ $Layer$)은 선이나 면과 같은 범용적인 특징을 제공하고, 상위 층($Upper$ $Layer$)은 특정 도메인에 특화된 정보를 처리하는 신경망의 계층적 특성을 이용함
- 학습에 필요한 데이터 양을 수십 분의 일 수준으로 줄일 수 있어, 특수 목적(예: 희귀 질병 판독)의 인공지능 개발을 가능케 함

## Ⅲ. 종류 및 비교

| 판단 기준 | 밑바닥부터 학습 (From Scratch) | 전이 학습 (Feature Extraction) | 전이 학습 (Fine-tuning) |
|:---|:---|:---|:---|
| **데이터 요구량** | 매우 큼 | 매우 적음 | 중간 |
| **가중치 업데이트** | 모든 층 갱신 | 마지막 출력층만 갱신 | 전체 또는 일부 상위 층 갱신 |
| **학습 시간** | 매우 길음 | 매우 짧음 | 중간 |
| **적응력** | 가장 높음 (도메인 특화) | 낮음 (범용 특징에 의존) | 높음 (타깃 데이터 반영) |

> 요약: 데이터가 극소량이면 특징 추출 방식을, 어느 정도 있다면 미세 조정을 선택함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 백본 ($Backbone$) | 이미 학습이 완료된 모델의 본체로, 범용적인 특징 추출을 담당함 |
| 분류 헤드 ($Head$) | 타깃 도메인의 클래스 개수에 맞게 새로 설계하여 백본 위에 얹는 층임 |
| 학습률 분리 | 백본은 낮은 학습률로 조심스럽게, 헤드는 높은 학습률로 빠르게 학습시키는 전략임 |
| 층별 비동결 | 학습이 진행됨에 따라 동결했던 층을 아래서부터 점진적으로 해제하며 적응력을 높임 |

```text
[ 전이 학습 아키텍처 구조 ]
[ Pre-trained Backbone (Frozen) ] -> [ New Adapter Layers ] -> [ New Classifier ]
- 범용 지식은 보존하고, 과제 특화 지식만 새로 학습함
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 사전 모델 선택| --> | 모델 구조 변경| --> | 가중치 동결설정| --> | 미세 조정 학습|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **백본 선정** — 해결하려는 과제와 가장 유사한 도메인에서 학습된 대규모 사전 학습 모델(예: 이미지-ImageNet, 자연어-Wiki)을 선택함
2. **레이어 이식** — 사전 학습 모델의 상위 층을 제거하고, 새로운 목표 데이터의 클래스 수와 형식에 맞는 새로운 층($Head$)을 결합함
3. **가중치 잠금** — 학습 초기에는 기존의 범용 지식이 파괴되지 않도록 백본 층의 가중치를 고정하고, 새로 추가된 층의 가중치만 먼저 학습시킴
4. **점진적 해제** — 모델이 어느 정도 안정화되면 백본의 일부 상위 층부터 동결을 해제하고 매우 낮은 학습률로 정교하게 재학습하여 타깃 데이터에 최적화함

## Ⅵ. 실무 적용 및 유의점

1. 원래 학습된 데이터 도메인과 타깃 도메인이 너무 다를 경우, 오히려 성능이 떨어지는 '부정적 전이($Negative$ $Transfer$)'가 발생할 수 있으므로, 두 도메인 간의 데이터 분포 유사성을 사전에 검토해야 함
2. 미세 조정 시 학습률을 너무 크게 설정하면 기존에 잘 학습된 정보들이 한꺼번에 지워지는 '파괴적 망각($Catastrophic$ $Forgetting$)' 현상이 발생하므로, 일반적인 학습보다 10~100배 작은 학습률을 사용하는 것이 권장됨

## Ⅶ. 결론

- 전이 학습은 제한된 자원으로 인공지능의 한계를 돌파하는 경제적이고 강력한 전략이며, 설계자는 사전 학습 지식의 보존과 새로운 도메인으로의 적응 사이에서 미세 조정의 강도를 정교하게 조율하여 실질적인 비즈니스 성과를 창출해야 함
