## 미리 알고가기

- 소스 도메인: 사전 학습에 사용된 데이터 영역이며 범용 표현의 출처가 됨
- 타깃 도메인: 새로 해결하려는 업무와 데이터 영역이며 최종 성능 평가 기준이 됨
- 사전 학습 모델: 대규모 데이터로 먼저 학습되어 재사용 가능한 표현을 가진 모델임
- 특징 추출: 백본 가중치를 고정하고 새 출력층만 학습하는 전이 학습 방식임
- 미세 조정: 사전 학습 가중치 일부 또는 전체를 낮은 학습률로 추가 학습하는 방식임
- 부정적 전이: 소스와 타깃 도메인이 달라 전이 학습이 오히려 성능을 낮추는 현상임

## Ⅰ. 개요

- **정의/개념**: 전이 학습은 소스 도메인에서 학습한 모델의 표현과 가중치를 타깃 도메인 학습에 재사용하는 학습 전략임
- **배경/필요성**: 실무에서는 라벨 데이터와 연산 자원이 부족한 경우가 많으므로 검증된 표현을 활용해 학습 시간과 데이터 요구량을 줄여야 함

## Ⅱ. 특징

- 사전 학습 표현에서 시작해 초기 성능과 수렴 속도를 높임
- 하위 층의 범용 특징과 상위 층의 과제 특화 특징을 분리해 재사용 범위를 조절함
- 적은 라벨 데이터에서도 과적합을 줄이고 모델 개발 비용을 낮춤
- 소스와 타깃 분포 차이가 크면 부정적 전이가 발생해 처음부터 학습한 모델보다 성능이 낮아질 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | 처음부터 학습 | 특징 추출 | 미세 조정 |
|:---|:---|:---|:---|
| 데이터 요구량 | 매우 큼 | 작음 | 중간 |
| 갱신 범위 | 전체 가중치 | 새 헤드 중심 | 일부 또는 전체 백본 |
| 학습 비용 | 높음 | 낮음 | 중간 |
| 적합 조건 | 충분한 데이터와 시간 | 타깃 데이터가 매우 적음 | 소스와 타깃이 유사하고 일부 적응 필요 |

> 요약: 데이터가 매우 적으면 특징 추출, 도메인 차이를 줄여야 하면 미세 조정을 선택함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 사전 학습 백본 | 범용 표현을 가진 모델 본체이며 전이 성능의 출발점임 |
| 태스크 헤드 | 타깃 클래스, 회귀값, 토큰 출력처럼 새 업무 형식에 맞는 출력층임 |
| 동결 정책 | 어떤 층을 고정하고 어떤 층을 학습할지 정해 지식 보존과 적응을 조절함 |
| 학습률 정책 | 백본은 낮게, 새 헤드는 높게 설정해 파괴적 망각을 줄임 |
| 검증 데이터 | 전이 효과와 부정적 전이를 판정하는 기준 데이터임 |

```text
+-------------+      +-------------+      +-------------+
| pretrained  | ---> | task head   | ---> | target out  |
| backbone    |      | new layers  |      | prediction  |
+-------------+      +-------------+      +-------------+
       |
       v
+-------------+
| freeze/tune |
+-------------+
```

> 요약: 전이 학습은 사전 학습 백본을 보존하거나 조정하며 새 태스크 헤드에 연결함.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+      +----------+      +----------+      +----------+
| select   | ---> | replace  | ---> | freeze   | ---> | fine tune|
+----------+      +----------+      +----------+      +----------+
```

1. **모델 선택**: 타깃 업무와 가장 유사한 소스 도메인의 사전 학습 모델을 선택함
2. **출력층 교체**: 타깃 데이터의 클래스 수와 출력 형식에 맞게 헤드를 교체함
3. **초기 학습**: 백본을 동결하고 새 헤드를 먼저 학습해 출력 분포를 맞춤
4. **점진 조정**: 상위 층부터 동결을 풀고 낮은 학습률로 타깃 도메인에 적응시킴

> 요약: 소스와 타깃이 가까울수록 특징 추출이 유리하고 차이가 클수록 점진 미세 조정이 필요함.

## Ⅵ. 실무 적용 및 유의점

1. 라벨이 적은 영상·문서 분류는 백본을 동결해 시작하고 검증 정확도와 학습 시간으로 전이 효과를 확인함
2. 도메인 차이가 크면 낮은 학습률과 점진적 비동결을 적용하고 부정적 전이를 검증 성능과 오류 유형으로 판단함

## Ⅶ. 결론

- 전이 학습은 사전 학습 지식을 재사용해 데이터와 비용을 줄이는 전략이며, 도메인 유사성과 미세 조정 범위가 핵심 판단 기준임

## 작성 근거(검토용)

- 개요는 소스·타깃 도메인과 가중치 재사용을 포함해 전이 학습의 범위를 명확히 함
- 특징은 수렴, 계층 재사용, 비용 절감, 부정적 전이를 균형 있게 배치함
- 비교표는 처음부터 학습, 특징 추출, 미세 조정의 선택 조건을 직접 비교함
- 구성요소는 백본, 헤드, 동결, 학습률, 검증 데이터로 실제 절차 단위를 일치시킴
- 절차는 모델 선택에서 점진 조정까지 실무 흐름을 단계화함
- 유의점은 소량 라벨 상황과 도메인 차이를 대표 적용 조건으로 선택함
