## 미리 알고가기

- 사전학습 모델: 대규모 데이터로 먼저 학습된 기준 모델임
- fine-tuning: 사전학습 모델을 새 데이터에 맞게 추가 학습하는 과정임
- domain shift: 원본 학습 도메인과 목표 도메인의 분포 차이임

## Ⅰ. 개요

- **정의/개념**: 전이 학습은 한 도메인에서 학습한 표현과 파라미터를 다른 관련 과제에 재사용해 데이터와 학습 비용을 줄이는 학습 방식임
- **배경/필요성**: 실무 데이터는 적고 라벨링 비용이 크기 때문에, 대규모 사전학습 지식을 재활용하는 방식이 효율적임

## Ⅱ. 특징

- 적은 데이터에서도 높은 초기 성능을 확보하기 쉬움
- 학습 시간과 연산 비용을 크게 줄일 수 있음
- 범용 특징은 재사용하고 과제 특화 층만 조정할 수 있음
- 원본 도메인과 차이가 크면 negative transfer가 발생할 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | From Scratch | Feature Extraction | Fine-tuning |
|:---|:---|:---|:---|
| 데이터 요구량 | 큼 | 작음 | 중간 |
| 학습 비용 | 큼 | 낮음 | 중간 |
| 적응력 | 높음 | 낮음 | 높음 |
| 대표 적용 | 대규모 자체 데이터 | 소량 데이터 분류 | 실무 맞춤 최적화 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 사전학습 백본 | 범용 표현을 제공하고 전이 성능의 기반임 |
| 고정층/학습층 | 어느 층을 동결할지 결정하고 비용과 적응력 균형점임 |
| 타깃 데이터 | 새 과제의 입력과 라벨이며 분포 차이를 결정함 |
| 미세조정 전략 | learning rate, layer unfreeze 정책이며 안정적 적응 핵심임 |

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 백본선택 | --> | 층동결설정 | --> | 미세조정 | --> | 성능검증 |
+----------+     +----------+     +----------+     +----------+
```

1. **백본선택**: 과제와 가까운 사전학습 모델을 고름
2. **층동결설정**: 재사용할 층과 새로 학습할 층을 나눔
3. **미세조정**: 작은 학습률로 목표 데이터에 맞게 적응시킴
4. **성능검증**: 전이 이득과 과적합 여부를 확인함

## Ⅵ. 문제점 및 해결 방안

1. **negative transfer가 발생함**: 원 도메인 지식이 오히려 방해가 됨
   - **해결 방안**: 도메인 유사도가 높은 백본을 선택하고 baseline 대비 성능 차이로 검증함
2. **과적합이 쉽게 생김**: 데이터가 적은데 파라미터가 많음
   - **해결 방안**: head만 학습 후 점진적으로 unfreeze하고 validation gap로 검증함
3. **학습률 설정이 까다로움**: 기존 표현을 깨뜨릴 수 있음
   - **해결 방안**: discriminative learning rate와 warm-up을 적용하고 loss stability로 검증함

## Ⅶ. 적용 사례

- 의료 영상 분류: ImageNet 백본을 활용함, 확인 지표는 소량 데이터 정확도 향상임
- 제조 비전 검사: 결함 샘플이 적을 때 사전학습 CNN을 미세조정함, 확인 지표는 recall임
- 문서 분류/NLP: BERT 기반 fine-tuning을 사용함, 확인 지표는 F1임

## Ⅷ. 결론

전이 학습의 핵심은 모델 재사용이 아니라 도메인 차이를 얼마나 잘 흡수하느냐에 있으므로, 백본 선택과 미세조정 범위를 함께 설계해야 함.
