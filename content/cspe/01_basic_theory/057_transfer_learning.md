## Ⅰ. 개요
- 정의: 대량의 데이터로 사전 학습된(Pre-trained) 모델을 유사한 목적의 새로운 작업에 재사용하는 기법임
- 배경: 적은 양의 타겟 데이터로 고성능 모델을 빠르게 구축할 필요성
- 출제 의도:
| 구분 | 내용 |
| --- | --- |
| 핵심 | 사전 학습, 미세 조정(Fine-tuning), 동결(Freezing) |

## Ⅱ. 구성요소
- ASCII 구조도
  [Task A Knowledge] --(Transfer)--> [Task B Model]
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 사전 학습 모델 | 거대 데이터로 미리 훈련된 모델 (VGG, BERT 등) | 전문가 |
| 미세 조정 | 새로운 데이터에 맞춰 일부 가중치를 재학습함 | 적응 훈련 |
| 층 동결 | 학습된 특징을 유지하기 위해 특정 층 갱신 막음 | 기본기 보존 |
> 요약: 보편적인 특징(지식)을 먼저 배우고 특수 분야에 적응시킴

## Ⅲ. 절차
- ASCII 흐름도
  [모델선택] -> [층동결] -> [출력층변경] -> [미세조정]
- 4단계 설명
1. 모델 선택: 타겟 문제와 유사한 도메인의 사전 학습 모델 고름
2. 층 동결: 범용적 특징을 가진 초기 층들의 가중치 고정함
3. 출력층 변경: 타겟 클래스 수에 맞게 마지막 층을 재설계함
4. 미세 조정: 낮은 학습률로 타겟 데이터를 이용해 전체 재학습함
> 요약: 기존 지식을 지렛대 삼아 학습 효율과 성능을 극대화함

## Ⅳ. 문제점
- 이전 지식이 타겟 도메인과 너무 다르면 성능이 하락(Negative Transfer)함
- 거대 모델 사용 시 추론 속도가 느려질 수 있음

## Ⅴ. 개선방안
- (단기) 도메인 유사도를 사전에 분석하여 적절한 모델 선정함
- (중기) 점진적 동결 해제(Unfreezing) 기법으로 안정성 확보함
- (장기) 지식 증류(Distillation)를 통해 모델 경량화 병행함

## Ⅵ. 전망
- 거대 언어 모델(LLM) 시대의 핵심 학습 방법론으로 자리잡음
