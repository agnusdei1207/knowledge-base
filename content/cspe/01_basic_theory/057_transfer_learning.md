# 📖 【암기용】 개념 완전 이해

## 한눈에
- **개요**: 방대한 데이터로 미리 학습된 기존 모델(Pre-trained Model)의 지식(가중치)을 가져와, 데이터가 부족한 나의 새로운 문제(Target Task)를 해결하는 데 재사용하는 딥러닝 학습 기법.
- **왜 필요한가**: 수천만 장의 이미지나 텍스트를 처음부터(From Scratch) 학습시키려면 막대한 컴퓨팅 비용과 시간이 들며, 내게 주어진 데이터가 적으면 과적합에 빠지기 때문.
- **핵심 직관**: 자전거 타는 법(균형 감각)을 완전히 마스터한 사람은 오토바이를 배울 때 처음부터 배우는 사람보다 훨씬 빨리 배운다. '균형 잡는 지식'을 '전이(Transfer)'했기 때문.

## 핵심 용어 정리

| 용어/표기 | 의미 | 비유·예 |
|:---|:---|:---|
| 사전 학습 모델 (Pre-trained Model) | ImageNet 등 대규모 데이터로 이미 며칠씩 학습을 마친 검증된 모델 (ResNet, BERT 등) | 수능 만점을 받은 모범생의 두뇌 |
| 소스/타겟 도메인 (Source/Target) | 소스는 지식을 가져올 원래 분야, 타겟은 내가 풀고자 하는 새로운 분야 | 소스: 영어 문서 / 타겟: 법률 영어 문서 |
| 특징 추출기 (Feature Extractor) | 모델의 앞부분(Conv 층 등)으로 선, 질감 등 범용적인 패턴을 뽑아내는 역할 | 세상을 바라보는 눈 (바꾸지 않고 그대로 씀) |
| 미세 조정 (Fine-Tuning) | 가져온 모델의 뒷부분(출력층 근처) 가중치만 내 목적에 맞게 살짝 다시 학습시키는 과정 | 수능 만점자에게 사법고시 문제 유형만 조금 훈련시키는 것 |

## 깊이 이해
- **배경·문제의식**: 딥러닝 모델이 깊어지면서 파라미터가 수억 개를 넘어감. 일반 기업이나 연구자가 수억 개의 가중치를 초기화 상태(랜덤)부터 수렴시키는 것은 불가능함.
- **작동 원리**: CNN의 경우 앞쪽 레이어는 물체의 외곽선, 모서리 같은 '범용적 특징'을 추출하고, 뒤쪽 레이어로 갈수록 강아지 귀, 자동차 바퀴 같은 '구체적 특징'을 추출함. 전이 학습은 이 앞부분(범용 특징 추출기)의 가중치를 꽁꽁 얼려(Freezing) 그대로 가져오고, 뒤쪽의 분류기(Classifier) 부분만 내 데이터로 가중치를 업데이트함.
- **구체 예시**: 개/고양이 100만 장으로 학습된 VGG 모델을 가져옴. 내 목표는 '엑스레이 사진에서 폐렴 찾기'임. 데이터가 1000장뿐이라도, VGG의 앞부분(질감, 선 인식 능력)을 그대로 쓴 뒤 마지막 층만 폐렴/정상으로 미세조정(Fine-Tuning)하면 놀라운 성능이 나옴.
- **흔한 오해·주의점**: 소스 도메인과 타겟 도메인이 완전히 다르면(예: 자연어 모델을 가져와 주가 예측에 씀) 오히려 성능이 떨어지는 '부정 전이(Negative Transfer)'가 발생함.

## 연결 개념
- **도메인 적응 (Domain Adaptation)**: 전이 학습의 한 분야로, 학습 환경(낮 사진)과 테스트 환경(밤 사진)이 다를 때 그 차이를 극복하게 만드는 기술.

# 📝 【답안용】 시험 답안 템플릿

## 핵심 인사이트 (3줄 요약)
> 1. **본질**: 대규모 소스 도메인(Source)에서 학습된 가중치를 타겟 도메인(Target) Task로 이전하는 기법
> 2. **가치**: 학습 데이터 부족(Data Sparsity) 극복, 컴퓨팅 비용 절감, 초기 학습 수렴 속도 극대화
> 3. **판단 포인트**: 타겟 데이터의 크기와 소스 도메인과의 유사도에 따른 가중치 동결(Freezing) 전략 수립이 핵심

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 딥러닝의 데이터 부족 한계 극복 및 재사용 원리 | 사전학습(Pre-training)과 미세조정(Fine-tuning), 동결(Freezing), 부정 전이 | 특징 추출기 개념 없이 무작정 파라미터 전체 복사라고 단정 |

> 요약: 사전에 훈련된 범용 특징 추출(Feature Extraction) 능력을 재사용하여 적은 자원으로 고성능 모델을 구축하는 기술

---

## Ⅰ. 개요 및 필요성
- 개요: 특정 과제(Source Task)를 해결하기 위해 대규모 데이터로 사전 훈련된 모델의 파라미터를 다른 목적(Target Task)의 신경망 학습에 재사용하는 기법
- 배경: 심층 신경망은 파라미터 폭증으로 대량의 레이블 데이터와 막대한 GPU 자원이 필요하여 From Scratch(바닥부터) 학습이 비효율적임
- 필요성: 레이블 데이터 부족(Few-Shot) 환경 극복, 과적합(Overfitting) 방지, 비즈니스 타임 투 마켓(Time-to-Market) 단축 필요

---

## Ⅱ. 구조 및 구성요소

```text
[사전학습 모델 (Pre-trained Model)]
  +--------------------------------+
  | 앞단: 범용 특징 추출 (Conv 등)  | --(가중치 복사/동결)--> [나의 모델 (Target Model)]
  |                                |                            |
  | 뒷단: 구체적 태스크 분류기 (FC) | --(버림/재설계)      --> [새 분류기 장착] -> (미세조정)
  +--------------------------------+
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 소스 도메인 (Source Domain) | 지식의 원천이 되는 대규모 공개 데이터세트 | ImageNet(비전), Wikipedia(NLP) 등 |
| 특징 추출기 (Feature Extractor) | 선, 질감, 구문 등 데이터의 범용적 표현(Representation)을 뽑아내는 망 | 전이 시 가중치를 동결(Freezing)하여 유지 |
| 분류기 (Classifier / Head) | 추출된 특징을 바탕으로 최종 정답 레이블을 예측하는 망 | 타겟 태스크에 맞게 노드 수 변경 및 초기화 |
| 미세조정 (Fine-Tuning) | 타겟 데이터로 모델의 일부 또는 전체 가중치를 다시 세밀하게 업데이트 | 매우 작은 학습률(Learning Rate) 사용 필수 |

> 요약: 범용 특징을 추출하는 앞부분은 재사용하고, 목적이 다른 뒷부분 분류기만 교체하여 내 데이터로 미세하게 재학습하는 구조

---

## Ⅲ. 동작원리 및 흐름도

```text
사전학습 모델 로드 -> 분류기 헤드 교체 -> 특징 추출부 가중치 동결 -> 미세조정 (Fine-Tuning) -> 서비스 배포
```

- 1단계 [모델 아키텍처 로드]: 검증된 대규모 모델(ResNet, BERT 등)의 구조와 사전 학습된 최적 가중치 파일 다운로드
- 2단계 [네트워크 커스터마이징]: 소스 태스크(예: 1000개 분류)에 맞춰진 마지막 출력층(Fully Connected)을 타겟 태스크(예: 2개 분류) 크기로 교체
- 3단계 [가중치 동결 (Freezing)]: 앞단 계층들의 가중치는 역전파 업데이트가 일어나지 않도록 잠금 설정하여 범용 지식 파괴 방지
- 4단계 [미세조정 (Fine-Tuning)]: 교체된 출력층 근처만 타겟 데이터로 학습시키며, 점진적으로 동결을 풀어(Unfreeze) 전체 최적화 유도

> 요약: 거대 지식을 이식한 후, 목표 태스크에 맞춘 분류 계층만 타겟 데이터로 약하게 업데이트함

---

## Ⅳ. 특징
- [높은 자원 효율성]: 초기 가중치가 이미 최적점에 가까우므로 수 에포크(Epoch)만 훈련해도 최고 성능(SOTA)에 도달
- [소규모 데이터 제약 극복]: 타겟 데이터가 수백 장 수준이어도, 이미 추출된 범용 특징을 활용하므로 과적합에 빠지지 않음
- [계층별 특징 의존성]: 망의 얕은 층(초반)은 범용 특징(일반화)을, 깊은 층(후반)은 특정 태스크에 종속된 특징을 가지는 딥러닝 특성 활용
- [부정 전이 (Negative Transfer)]: 소스와 타겟 간의 데이터 분포나 도메인 연관성이 전혀 없을 경우 오히려 From Scratch보다 성능이 떨어짐

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 특징 추출 (Feature Extraction) 전략 | 미세조정 (Fine-Tuning) 전략 | 선택 기준 (데이터 연관성) |
|:---|:---|:---|:---|
| 가중치 업데이트 | 분류기(Head)만 새로 학습 | 망 전체 또는 절반 이상 재학습 | 타겟 데이터의 크기 |
| 연산량 및 속도 | 연산 최소화, 초고속 | 연산량 많음, 시간 소요 | 자원 제약 및 가용 시간 |
| 적용 환경 | 소스-타겟 유사도 높고 데이터 적음 | 데이터가 많거나 도메인 이질적 | 모델과 타겟의 분포 차이 |

**리스크·대응:**
- [Catastrophic Forgetting]: 미세조정 시 학습률을 높게 주면 사전학습된 범용 지식이 파괴됨 → LRF(Learning Rate Finder)로 초저학습률 적용 (지표: 타겟 훈련 손실 함수)
- [부정 전이 발생]: 의료용 초음파 사진(타겟)에 자연 실사 이미지(ImageNet 소스) 전이 시 성능 저하 → 도메인 적응(DA) 수행 또는 인접 도메인(의료 영상) 사전학습 모델 탐색 (지표: 타겟 검증 정확도)

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. [자연어 처리 (NLP) 백본 구축]: 텍스트 분류, 감성 분석 챗봇 구축 시 BERT, GPT 등의 거대 언어 모델(LLM) 백본을 불러와 사내 문서를 주입하는 미세조정 수행
2. [의료 진단 비전 시스템]: 엑스레이, MRI 등 수집이 몹시 어려운 의료 영상 판독기 개발 시 ResNet 사전학습 가중치를 동결하고 출력층만 질병 유무 2진 분류로 교체 학습
3. [도메인 적응 (Domain Adaptation)]: 시뮬레이터(게임) 데이터로 학습된 자율주행 모델을 실제 도로 환경에 적용할 때, 적대적 손실(Adversarial Loss)을 추가하여 도메인 간 괴리 최소화

**결론:**
- 기술사 판단: 현대 딥러닝 실무에서 모든 모델 개발의 출발점이 되는 표준 프랙티스이며, 데이터의 크기와 도메인 유사도에 따른 동결(Freezing) 범위 결정이 성패를 가름
- 향후 방향: 전이 학습을 넘어, 미세조정조차 필요 없이 프롬프트(Prompt)만으로 다양한 태스크를 수행하는 제로샷(Zero-shot) 학습 형태로 발전 중임
