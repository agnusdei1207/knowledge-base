## Ⅰ. 개요
- **정의**: 대규모 데이터로 사전 학습된 모델의 파라미터를 새 도메인 태스크에 재사용하는 기법
- **배경/필요성**: 딥러닝 모델의 학습 비용(GPU 시간·데이터 구축)이 막대하여 기학습 지식의 재활용 필요
- **비유**: 10년 경력 요리사가 새 레스토랑에서 메뉴만 바꿔 바로 적응하는 것

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| Pre-train → Fine-tune 흐름 이해 | 동결(Freeze) 범위 결정 기준 | 부정 전이(Negative Transfer)와 과적합 구분 |
| PEFT/LoRA 등 최신 기법 인지 | 풀 파인튜닝 vs 파라미터 효율적 미세조정 차이 | 카타스트로픽 포겟팅 원인 설명 필수 |

> 요약: 전이 학습은 기학습 모델의 범용 지식을 새 태스크에 전이하여 학습 비용을 절감하는 기법임

## Ⅱ. 구성요소
```text
+----------------+       +----------------+       +----------------+
| Pre-trained    |       | Freeze / Adapt |       | Fine-tuned     |
| Base Model     | ----> | Strategy       | ----> | Target Model   |
+----------------+       +----------------+       +----------------+
        |                        |                        |
   ImageNet, LLM          Head 교체, LoRA           Target Task 최적화
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 사전 학습 모델(Pre-trained) | 대규모 범용 데이터로 특징 추출 능력을 확보한 베이스 모델 | 경력직 채용 |
| 동결 전략(Freeze Strategy) | 하위 레이어(범용 특징)를 고정하고 상위만 재학습하는 방식 | 기본기 유지 |
| 미세 조정(Fine-tuning) | 타겟 데이터에 맞게 가중치를 낮은 학습률로 재학습 | 맞춤 적응 |

> 요약: 사전 학습 모델의 레이어를 선택적으로 동결·조정하여 타겟 태스크에 최적화함

## Ⅲ. 절차
```text
+----------------+       +----------------+       +----------------+       +----------------+
| Load Model     |       | Replace Head   |       | Freeze Layers  |       | Fine-Tune      |
| (Pre-trained)  | ----> | (Output Layer) | ----> | (Fix Base)     | ----> | (Low LR Train) |
+----------------+       +----------------+       +----------------+       +----------------+
```

1. **모델 로드** — 대형 데이터셋(ImageNet, C4 등)으로 학습된 가중치 파일 불러오기
2. **헤드 교체** — 기존 분류기/출력층을 제거하고 타겟 태스크에 맞는 새 출력층 부착
3. **레이어 동결** — 도메인 유사도·타겟 데이터 크기에 따라 하위 레이어 파라미터 고정
4. **미세 조정** — 비동결 레이어를 타겟 데이터로 낮은 학습률(1e-5 수준)에서 재학습

> 요약: 기학습 모델 로드 → 출력층 교체 → 선택적 동결 → 저학습률 미세 조정 순서로 수행함

## Ⅳ. 문제점
- 부정 전이(Negative Transfer): 소스-타겟 도메인 유사도가 낮을 시 오히려 성능 하락
- 과적합 위험: 타겟 데이터가 수백 건 수준으로 적을 때 전체 파인튜닝 시 훈련 데이터에 편향
- 카타스트로픽 포겟팅: 새 태스크 학습 과정에서 기존 범용 특징 추출 능력 점진적 소실

> 요약: 도메인 불일치에 의한 부정 전이, 소규모 데이터 과적합, 기존 지식 망각이 핵심 한계임

## Ⅴ. 개선방안
1. 단기: 도메인 유사도를 사전 정량 평가(MMD 거리 등)하여 전이 적합성 판단
2. 중기: LoRA·Adapter 등 파라미터 효율적 미세조정(PEFT)으로 과적합 억제 및 비용 절감
3. 장기: EWC·LwF 등 지속 학습(Continual Learning) 기법으로 포겟팅 방지

- 부정 전이: 도메인 불일치 → MMD 기반 유사도 사전 평가 (지표: MMD 거리값)
- 과적합: 소규모 타겟 데이터 → LoRA 랭크 r=8~16으로 학습 파라미터 0.1% 이하 제한 (지표: Val Loss)
- 포겟팅: 새 학습에 의한 가중치 변형 → EWC 페널티 항 추가 (지표: 원 태스크 정확도 유지율)

> 요약: 사전 유사도 평가, PEFT 기반 효율적 조정, 지속 학습 기법으로 3대 한계를 대응함

## Ⅵ. 전망
- 향후 발전 방향: LLM 시대에 풀 파인튜닝은 비용상 비현실적이며, LoRA·QLoRA·Prefix Tuning 등 PEFT가 표준으로 정착
- 기술사적 판단: 전이 학습 자체가 Foundation Model 패러다임의 기반이며, 도메인 특화 모델 구축의 필수 경로로 고착화
- 기술사 제언: 프로젝트 설계 시 풀 파인튜닝 vs PEFT vs 프롬프트 튜닝의 비용-성능 트레이드오프를 정량 비교하여 전략 선택할 것
