## 미리 알고가기

- 소스 도메인: 사전 학습에 사용된 데이터 영역이며 범용 표현의 출처가 됨
- 타깃 도메인: 새로 해결하려는 업무와 데이터 영역이며 최종 성능 평가 기준이 됨
- 사전 학습 모델: 대규모 데이터로 먼저 학습되어 재사용 가능한 표현을 가진 모델임
- 백본·태스크 헤드: 범용 특징을 추출하는 본체와 타깃 업무의 출력을 만드는 계층임
- 특징 추출: 백본 가중치를 고정하고 새 태스크 헤드만 학습하는 전이 학습 방식임
- 미세 조정: 사전 학습 가중치 일부 또는 전체를 낮은 학습률로 추가 학습하는 방식임
- 부정적 전이: 소스와 타깃 도메인이 달라 전이 학습이 오히려 성능을 낮추는 현상임

## 작성 근거(검토용)

- **방향성**: 전이 학습은 소스 도메인 표현을 재사용해 라벨 확보량과 연산량을 줄이는 대신, 소스·타깃 도메인 차이가 크면 부정적 전이로 처음부터 학습한 모델보다 성능이 낮아지므로 도메인 유사도에 맞춰 특징 추출·미세 조정·처음부터 학습 중 하나를 선택해야 함
- **Ⅰ. 개요 구성**: 소스·타깃 도메인과 가중치 재사용을 포함해 전이 학습의 범위를 명확히 함
- **Ⅱ. 특징 선정**: 초기값 재사용·계층별 재사용·소량 라벨 학습·부정적 전이로 전개함
- **Ⅲ. 비교축 선정**: 학습 시작점·갱신 범위·주요 리스크는 세 방식의 고유 스펙이라 축은 유지하고, 도메인 유사도·라벨량에 따른 선택 기준은 요약 문장의 구체적 분기 조건으로 명시함
- **Ⅳ. 구조 선정**: 백본, 헤드, 동결 범위, 학습률로 실제 조정 단위를 일치시킴
- **Ⅴ. 절차 선정**: 모델 선택에서 점진 조정까지 실무 흐름을 단계화함
- **Ⅵ. 사례 선정**: 라벨 부족과 소스·타깃 도메인 차이는 전이 효과를 가르는 대표 조건임
- **전수 검수**: 제목부터 결론까지 용어·표·도식·요약을 대조하고 처음부터 학습한 모델을 가리키는 표현을 일치시킴

## Ⅰ. 개요

- **정의/개념**: 전이 학습은 소스 도메인에서 학습한 모델의 표현과 가중치를 타깃 도메인 학습에 재사용하는 학습 전략임
- **배경/필요성**: 타깃 라벨 수집량과 학습 연산량을 줄이기 위해 사전 학습 표현을 재사용해야 함

### 쉽게 이해하기 (학습용)
- 자전거를 탈 줄 알면 오토바이를 배울 때 이미 가진 균형 감각으로 더 빨리 배우는 것과 같음

## Ⅱ. 특징

- 사전 학습 표현을 초기값으로 사용해 무작위 가중치에서 시작하는 학습 단계를 줄임
- 하위 층의 범용 특징과 상위 층의 과제 특화 특징을 분리해 재사용 범위를 조절함
- 소스와 타깃의 특징이 유사하면 적은 타깃 라벨로도 사전 학습 표현을 재사용할 수 있음
- 소스와 타깃 분포 차이가 크면 부정적 전이가 발생해 처음부터 학습한 모델보다 성능이 낮아질 수 있음

### 쉽게 이해하기 (학습용)
- 완전 초보로 시작하지 않고 이미 익힌 균형 감각부터 출발해 배우는 시간을 줄이며, 오토바이만의 조작법만 새로 익히면 됨
- 너무 다른 탈것이라면 예전 습관이 오히려 방해가 될 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | 처음부터 학습 | 특징 추출 | 미세 조정 |
|:---|:---|:---|:---|
| 학습 시작점 | 무작위 초기값 | 사전 학습 가중치 | 사전 학습 가중치 |
| 갱신 범위 | 전체 모델 | 태스크 헤드 | 백본 일부 또는 전체 |
| 주요 리스크 | 소량 데이터 과적합 | 부정적 전이 | 사전 학습 표현 손상 |

> 요약: 타깃 라벨이 적고 두 도메인이 유사하면 특징 추출, 타깃 라벨이 있고 표현을 조정해야 하면 미세 조정, 두 도메인이 크게 달라 부정적 전이가 우려되면 처음부터 학습을 선택함.

### 쉽게 이해하기 (학습용)
- 처음부터 배우기는 자전거도 처음 타보는 것이고, 특징 추출은 균형 감각은 그대로 두고 손잡이 조작법만 새로 배우는 것이며, 미세 조정은 균형 감각까지 오토바이에 맞게 조금씩 다시 다듬는 것임

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 사전 학습 백본 | 소스 도메인 표현 모델 |
| 태스크 헤드 | 타깃 업무 출력층 |
| 동결 정책 | 사전 학습 백본에서 가중치를 고정하거나 갱신할 계층의 범위 |
| 학습률 정책 | 백본과 태스크 헤드의 가중치 갱신 폭을 구분하는 학습률 설정 |

```text
+-------------+      +-------------+      +-------------+
| 사전 학습   | ---> | 태스크 헤드 | ---> | 타깃 예측   |
| 백본        |      | 새 출력층   |      | 결과        |
+-------------+      +-------------+      +-------------+
       |
       v
+-------------+
| 동결/조정   |
+-------------+
```

> 요약: 전이 학습은 사전 학습 백본에 타깃 헤드를 연결하고 가중치를 조정해 타깃 모델을 학습함.

### 쉽게 이해하기 (학습용)
- 몸에 익은 균형 감각(백본)은 그대로 두고 새 탈것에 맞는 조작 요령(태스크 헤드)만 새로 배우되, 어디까지 그대로 쓰고 어디를 다시 익힐지(동결 정책)와 얼마나 조금씩 고칠지(학습률)를 정함

## Ⅴ. 원리 및 절차 흐름도

```text
모델 선택 ---> 헤드 교체 ---> 초기 학습 ---> 점진 조정
```

1. **모델 선택**: 타깃 업무와 가장 유사한 소스 도메인의 사전 학습 모델을 선택함
2. **태스크 헤드 교체**: 타깃 데이터의 클래스 수와 출력 형식에 맞게 태스크 헤드를 교체함
3. **초기 학습**: 백본을 동결하고 태스크 헤드를 먼저 학습해 출력 분포를 맞춤
4. **점진 조정**: 검증 성능이 부족하면 상위 층부터 동결을 풀고 낮은 학습률로 조정함

> 요약: 소스와 타깃의 특징이 유사하면 백본을 동결하고, 타깃 라벨이 충분하면 상위 층부터 동결을 풀어 조정함.

### 쉽게 이해하기 (학습용)
- 비슷한 탈것을 골라 손잡이 조작법만 새로 배운 뒤, 익숙해지면 균형 잡는 방식까지 조금씩 다시 조정해 나감

## Ⅵ. 실무 사례

1. 장애 티켓 분류기는 사전 학습 언어 모델의 백본을 동결하고 분류 헤드부터 학습함
2. 내부 문서 분류기는 도메인 용어가 사전 학습 데이터와 다르면 상위 계층부터 동결을 해제해 재학습함

### 쉽게 이해하기 (학습용)
- 장애 티켓 분류는 기존에 익힌 언어 감각은 그대로 두고 분류 요령만 새로 익히고, 낯선 전문 용어가 많은 내부 문서는 언어 감각 일부까지 다시 손봐야 함

## Ⅶ. 결론

- 전이 학습은 이미 배운 지식을 재사용해 학습 데이터와 시간을 줄이며, 두 도메인의 유사성과 재학습 범위를 고려해야 함
- 소스·타깃 분포 차이가 크면 전체 동결을 피하고 상위 층부터 해제하되, 성능이 처음부터 학습한 모델보다 낮으면 전이를 중단해야 함

### 쉽게 이해하기 (학습용)
- 이미 배운 감각을 재활용하는 방식이므로 새 탈것이 얼마나 다른지부터 살피고, 너무 다르면 처음부터 다시 배우는 편이 나을 수도 있음
