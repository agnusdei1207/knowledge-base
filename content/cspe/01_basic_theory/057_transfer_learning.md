## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 대규모 데이터로 사전 학습된 모델의 파라미터(지식)를, 데이터가 부족한 새 도메인 작업에 재사용하는 기법임 |
| 배경/필요성 | 딥러닝 모델의 막대한 훈련 시간 및 컴퓨팅 비용 절감, 소규모 데이터셋 환경 극복 필요 |
| 출제 의도 | 사전 학습(Pre-training)과 미세 조정(Fine-tuning)의 개념, 동결(Freezing) 전략의 이해 평가 |

## Ⅱ. 구성요소
```text
+----------------+       +----------------+       +----------------+
| Pre-trained    |       | Target Task    |       | Fine-tuned     |
| Base Model     | ----> | Data & Layers  | ----> | Target Model   |
+----------------+       +----------------+       +----------------+
```
| 사전 학습 모델 | 대용량 일반 데이터로 범용적 특징을 학습해둔 모델 | 베테랑 경력자 |
| 타겟 태스크 | 새롭게 풀고자 하는, 상대적으로 데이터가 적은 문제 | 새로운 부서 업무 |
| 미세 조정 (Fine-tune)| 타겟 데이터에 맞게 모델 일부나 전체 가중치를 재학습 | 업무 적응 훈련 |
> 요약: 전이 학습은 기학습된 범용 모델을 기반으로 타겟 태스크에 맞게 미세 조정을 수행함

## Ⅲ. 절차
```text
+----------------+       +----------------+       +----------------+       +----------------+
| Load Pre-train |       | Replace Head   |       | Freeze Layers  |       | Fine-Tuning    |
| (Base Model)   | ----> | (Task Layer)   | ----> | (Fix Weights)  | ----> | (Train Model)  |
+----------------+       +----------------+       +----------------+       +----------------+
```
1. 모델 로드: ImageNet 등 대형 데이터셋으로 사전 학습된 가중치 모델 불러오기
2. 헤드 교체: 기존 모델의 최종 분류기 층을 잘라내고 새로운 목적에 맞는 출력층 부착
3. 레이어 동결: (선택적) 모델 하위층의 범용 가중치 파라미터를 고정(Freeze)하여 학습 방지
4. 미세 조정: 새로운 데이터셋으로 출력층과 상위층 일부를 낮은 학습률로 재학습
> 요약: 기학습 모델을 불러와 목적에 맞게 출력층을 교체하고 미세 조정을 거쳐 최적화함

## Ⅳ. 문제점
- 부정 전이(Negative Transfer): 원본 도메인과 타겟 도메인 간 연관성이 적을 시 성능 악화
- 과적합 발생 위험: 타겟 데이터가 매우 적은 상태에서 전체 모델을 미세 조정 시 과적합
- 카타스트로픽 포겟팅: 새 지식 학습 과정에서 과거 범용적인 특징 추출 능력을 상실함

## Ⅴ. 개선방안
- 단기 방안: 도메인 유사도를 사전 평가하고 낮은 유사도 시 특징 추출기(Feature Extractor)로만 사용
- 중기 방안: 타겟 데이터 크기에 따라 동결(Freezing)할 계층 깊이를 유연하게 조절
- 장기 방안: LwF, EWC 등 지속 학습(Continual Learning) 기법을 도입하여 포겟팅 방지

## Ⅵ. 전망
- 파라미터 효율적 미세조정(PEFT, LoRA 등) 기법으로 발전하여 LLM 커스터마이징의 표준이 됨
