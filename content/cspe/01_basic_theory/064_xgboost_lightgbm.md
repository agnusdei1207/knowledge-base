## 미리 알고가기

- 그래디언트 부스팅: 이전 모델의 잔차를 다음 트리가 학습해 오류를 줄이는 방식임
- 잔차: 실제값과 현재 예측값의 차이임
- 레벨 단위(Level-wise) 성장: 같은 깊이의 노드를 균형 있게 확장함
- 리프 단위(Leaf-wise) 성장: 손실 감소가 큰 리프를 우선 확장함
- GOSS(Gradient-based One-Side Sampling): 그래디언트가 큰 표본을 남겨 학습 표본 수를 줄이는 방식임
- EFB(Exclusive Feature Bundling): 동시에 0이 아닌 경우가 드문 특징을 묶어 특징 수를 줄이는 방식임
- 조기 종료: 검증 성능이 개선되지 않으면 학습을 멈춤

## 작성 근거(검토용)

- 개요는 두 라이브러리의 공통 기반인 그래디언트 부스팅과 정형 데이터 활용 목적을 함께 제시함
- 잔차 학습·정규화·특징별 예측 기여는 XGBoost·LightGBM 선택에 필요한 핵심 요소임
- Ⅲ은 성장 방식과 최적화 차이를 중심으로 두 도구의 실무 선택 기준을 제시함
- Ⅳ는 목적 함수, 트리, 학습률, 버킷, 검증 세트로 학습 구조와 운영 통제를 연결함
- 정형 데이터 적용과 LightGBM 과적합 조정은 두 모델의 대표 판단 조건임

## Ⅰ. 개요

- **정의/개념**: XGBoost와 LightGBM은 현재 모델의 손실 그래디언트를 다음 결정 트리가 줄이도록 트리를 순차 결합한 그래디언트 부스팅 구현임
- **배경/필요성**: 정형 데이터 규모와 과적합 위험에 맞는 트리 성장·분할 탐색 방식을 선택하기 위해 부스팅 구현별 판단 기준이 필요함

## Ⅱ. 특징

- 얕은 결정 트리를 순차 결합해 전체 모델의 손실을 줄임
- 수치·범주형 특징이 섞인 정형 데이터의 비선형 관계를 트리 분할로 학습함
- 정규화와 조기 종료로 과적합을 제어함
- 분할 이득·빈도로 특징별 예측 기여를 산출함

## Ⅲ. 종류 및 비교

| 판단 기준 | XGBoost | LightGBM |
|:---|:---|:---|
| 성장 방식 | 기본 설정에서 같은 깊이의 노드를 함께 확장 | 손실 감소가 큰 리프를 우선 확장 |
| 분할 탐색 | 설정에 따라 정확·근사·히스토그램 방식 사용 | 히스토그램 방식 사용 |
| 표본·특징 축소 | 행·열 서브샘플링 | GOSS 표본 선택·EFB 특징 묶음 |
| 주의 조건 | 깊이별 확장 노드가 늘면 연산량이 증가 | 표본 수 대비 리프 수가 많으면 리프별 학습 표본이 줄어 과적합될 수 있음 |

> 요약: XGBoost는 레벨 단위로 트리를 확장하고, LightGBM은 손실 감소가 큰 리프를 선택해 확장함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 목적 함수 | 손실 함수와 정규화 항을 함께 최소화함 |
| 결정 트리 | 잔차를 설명하는 약한 학습기 역할을 함 |
| 학습률 | 새 트리의 반영 폭을 낮춰 과적합을 줄임 |
| 히스토그램 버킷 | 연속값을 구간화해 분할 탐색 비용을 낮춤 |
| 검증 세트 | 조기 종료와 튜닝 성능 판단에 사용함 |

> 요약: 목적 함수, 트리, 학습률, 검증 세트가 부스팅 반복을 통제함.

## Ⅴ. 원리 및 절차 흐름도

```text
초기 점수 -> 그래디언트 계산 -> 트리 학습 -> 트리 추가 -> 검증 성능 기준 종료
```

1. 초기 예측값을 만들고 손실 기준의 잔차나 그래디언트를 계산함
2. 잔차 손실을 줄이는 새 결정 트리를 학습함
3. 학습률을 적용해 새 트리를 기존 모델에 더함
4. 검증 성능이 개선되는 동안 트리 추가를 반복하고 개선이 멈추면 종료함

> 요약: 부스팅은 잔차를 줄이는 트리를 순차 추가하되 검증 성능으로 반복 중단 시점을 정함.

## Ⅵ. 실무 사례

1. 장애 로그 분류는 전처리 조건을 고정하고 AUC로 XGBoost와 LightGBM을 비교함
2. LightGBM은 `num_leaves`·`min_data_in_leaf`·조기 종료를 조정하고 훈련-검증 손실 격차로 과적합을 확인함

## Ⅶ. 결론

- XGBoost와 LightGBM은 트리 성장 방식과 분할 탐색이 다르므로 데이터 규모·학습 비용·과적합 위험에 따라 선택해야 함
