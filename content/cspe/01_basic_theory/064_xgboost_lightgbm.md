## 미리 알고가기

- gradient boosting: 이전 모델 오차를 다음 모델이 순차적으로 보정하는 방식임
- leaf-wise growth: LightGBM의 리프 기준 성장 전략임
- regularization: 복잡한 트리의 과적합을 제어하는 장치임

## Ⅰ. 개요

- **정의/개념**: XGBoost와 LightGBM은 결정 트리를 약한 학습기로 사용해 오차를 순차 보정하는 고성능 gradient boosting 프레임워크임
- **배경/필요성**: 정형 데이터에서는 복잡한 비선형 관계와 변수 상호작용을 빠르게 포착하는 부스팅 모델이 높은 실전 성능을 보임

## Ⅱ. 특징

- 높은 예측 성능과 강한 feature interaction 학습 능력을 가짐
- XGBoost는 정규화와 안정성이 강점이고 LightGBM은 대용량 속도에 강함
- 결측치 처리와 중요도 추정이 비교적 편리함
- 하이퍼파라미터 민감도가 높고 과적합 관리가 중요함

## Ⅲ. 종류 및 비교

| 판단 기준 | XGBoost | LightGBM |
|:---|:---|:---|
| 성장 방식 | level-wise 중심 | leaf-wise 중심 |
| 장점 | 안정성, 범용성 | 속도, 대규모 데이터 |
| 메모리 효율 | 중간 | 높음 |
| 주의점 | 학습 시간 | 과적합 가능성 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 약한 트리 | 각 단계 보정 모델이며 기본 학습기임 |
| 잔차/gradient | 다음 트리가 학습할 목표이며 순차 보정의 핵심임 |
| 정규화 항 | 트리 복잡도를 제어하고 과적합 억제 장치임 |
| 학습률 | 단계별 기여도를 조절하고 수렴과 일반화 균형점임 |

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 초기예측 | --> | 오차계산 | --> | 트리추가 | --> | 누적갱신 |
+----------+     +----------+     +----------+     +----------+
```

1. **초기예측**: 기본값으로 시작함
2. **오차계산**: 현재 예측의 gradient와 residual을 구함
3. **트리추가**: 오차를 잘 줄이는 새 트리를 학습함
4. **누적갱신**: 학습률을 반영해 예측을 업데이트함

## Ⅵ. 문제점 및 해결 방안

1. **과적합이 쉽게 발생할 수 있음**: 트리 수와 깊이가 커지면 훈련셋에 과도 적합함
   - **해결 방안**: early stopping, max_depth, min_child_weight 등을 조정하고 validation score로 검증함
2. **파라미터가 많아 튜닝 부담이 큼**: 탐색 비용이 높다
   - **해결 방안**: 기본값에서 learning rate, depth, leaf 수를 우선 조정하고 tuning efficiency로 검증함
3. **범주형/희소 처리 방식 차이로 성능 편차가 생김**: 데이터 전처리 영향이 큼
   - **해결 방안**: 인코딩 전략과 histogram 설정을 함께 최적화하고 CV variance로 검증함

## Ⅶ. 적용 사례

- 신용평가/사기탐지: 정형 데이터 분류에 활용함, 확인 지표는 AUC임
- 광고 클릭 예측: 대규모 특징 상호작용을 학습함, 확인 지표는 log loss임
- 제조 예지보전: 센서 기반 불량 예측에 사용함, 확인 지표는 recall과 PR-AUC임

## Ⅷ. 결론

XGBoost와 LightGBM의 핵심은 작은 트리를 순차적으로 쌓아 편향을 줄이는 데 있으므로, 최고 성능보다 먼저 과적합 제어와 튜닝 비용을 관리해야 함.
