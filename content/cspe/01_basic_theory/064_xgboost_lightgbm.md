## 미리 알고가기

- 그래디언트 부스팅: 이전 모델의 잔차를 다음 트리가 학습해 오류를 줄이는 방식임
- 잔차: 실제값과 현재 예측값의 차이임
- 레벨 단위(Level-wise) 성장: 같은 깊이의 노드를 균형 있게 확장함
- 리프 단위(Leaf-wise) 성장: 손실 감소가 큰 리프를 우선 확장함
- Gradient-based One-Side Sampling(GOSS): 큰 기울기 표본은 유지하고 작은 기울기 표본은 일부 추출해 학습량을 줄이는 방식임
- Exclusive Feature Bundling(EFB): 동시에 0이 아닌 값을 갖는 경우가 드문 상호 배타적 특성을 묶어 특성 수를 줄이는 방식임
- 히스토그램 버킷: 연속 특징값을 구간으로 나눠 분할 탐색 연산을 줄이는 단위임
- 조기 종료: 검증 성능이 개선되지 않으면 학습을 멈춤
- 음의 그래디언트: 손실이 감소하는 방향을 나타내며 다음 트리가 학습하는 목표값임
- ROC 곡선 아래 면적(AUC): 분류 임계값을 바꾸며 양성·음성을 구분하는 성능을 종합한 지표임

## 작성 근거(검토용)

- 개요는 두 라이브러리의 공통 기반인 그래디언트 부스팅과 정형 데이터 활용 목적을 함께 제시함
- 잔차 학습·정규화·특징 중요도는 XGBoost·LightGBM 선택에 필요한 핵심 요소임
- Ⅲ은 트리 성장, 연산 절감, 과적합 리스크로 두 구현의 선택 기준을 제시함
- Ⅳ는 목적 함수, 그래디언트·헤시안, 결정 트리, 성장 정책, 학습률로 부스팅 갱신 구조를 설명함
- 정형 데이터 적용과 LightGBM 과적합 조정은 두 모델의 대표 판단 조건임

## Ⅰ. 개요

- **정의/개념**: XGBoost와 LightGBM은 손실의 음의 그래디언트를 다음 트리가 학습하도록 순차 결합한 그래디언트 부스팅 구현임
- **배경/필요성**: 정형 데이터 규모와 과적합 위험에 맞는 트리 성장·분할 탐색 방식을 선택하기 위해 부스팅 구현별 판단 기준이 필요함

## Ⅱ. 특징

- 얕은 결정 트리를 순차 결합해 전체 모델의 손실을 줄임
- 수치·범주형 특징이 섞인 정형 데이터의 비선형 관계를 트리 분할로 학습함
- 정규화와 조기 종료로 과적합을 제어함
- 분할 이득·빈도로 특징 중요도를 산출함

## Ⅲ. 종류 및 비교

| 판단 기준 | XGBoost | LightGBM |
|:---|:---|:---|
| 트리 성장 | 깊이별 확장 | 손실 기준 리프 우선 확장 |
| 연산 절감 | 행·열 서브샘플링 | GOSS·EFB |
| 주요 리스크 | 깊이 증가 연산량 | 소표본 리프 과적합 |

> 요약: XGBoost는 레벨 단위로 트리를 확장하고, LightGBM은 손실 감소가 큰 리프를 선택해 확장함.

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 목적 함수 | 손실 함수와 정규화 항의 합 |
| 그래디언트·헤시안 | 현재 예측의 손실 감소 방향·곡률 정보 |
| 결정 트리 | 그래디언트·헤시안 기반 분할 이득으로 잔여 오차를 보정하는 약한 학습기 |
| 성장 정책 | XGBoost의 레벨 단위·LightGBM의 리프 단위 확장 기준 |
| 학습률 | 새 트리의 반영 비율 |

> 요약: XGBoost·LightGBM은 손실의 그래디언트·헤시안으로 분할 이득을 계산하고 성장 정책과 학습률로 새 트리의 구조·반영 폭을 조절함.

## Ⅴ. 원리 및 절차 흐름도

```text
초기 점수 -> 그래디언트 계산 -> 트리 학습 -> 트리 추가 -> 검증 성능 기준 종료
```

1. 초기 예측값에서 손실 함수의 음의 그래디언트를 계산함
2. 음의 그래디언트를 예측하는 새 결정 트리를 학습함
3. 학습률을 적용해 새 트리를 기존 모델에 더함
4. 검증 성능이 개선되는 동안 트리 추가를 반복하고 개선이 멈추면 종료함

> 요약: 부스팅은 음의 그래디언트를 학습하는 트리를 순차 추가하되 검증 성능으로 반복 중단 시점을 정함.

## Ⅵ. 실무 사례

1. 장애 로그 분류기는 XGBoost로 이전 예측 오류를 줄이는 새 트리를 순차적으로 추가함
2. 대용량 로그 분류기는 LightGBM의 리프 수와 최소 표본 수를 제한해 한 리프의 과적합을 줄임

## Ⅶ. 결론

- XGBoost와 LightGBM은 이전 트리의 오류를 다음 트리가 보완하며, 데이터 규모와 학습 속도·과적합 위험에 따라 선택해야 함
- 메모리와 학습 시간이 제한된 대용량 데이터는 LightGBM을 우선 검토하되, 리프 성장을 조기 종료·최소 표본 수로 통제해야 함
