## Ⅰ. 개요
- 정의: 그래디언트 부스팅(GBM) 프레임워크를 기반으로 속도와 성능을 개선한 알고리즘임.
- 배경: 대규모 정형 데이터 처리를 위한 고성능 및 확장성 필요성으로 등장함.
- 출제 의도:
| 분류 | 상세 |
| --- | --- |
| 핵심요소 | 정규화, 결측치 처리, 리프 중심 성장(Leaf-wise) |
| 주요특징 | 빠른 속도, 병렬 처리, 높은 예측력 |

## Ⅱ. 구성요소
- ASCII 구조도
 [Level-wise] (XGB) vs [Leaf-wise] (LGBM)
    (Tree)               (Deep Tree)
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| XGBoost | 정규화 기능을 포함한 병렬 GBM 구현체 | 정교한 조각가 |
| LightGBM | 히스토그램 기반 및 리프 중심 성장을 사용 | 고속 질주 레이서 |
| 조기 종료 | 성능 개선이 없으면 학습을 중단하는 기법 | 적절한 휴식 |
> 요약: 효율적인 트리 성장과 최적화를 통해 성능을 극대화한 부스팅 도구임.

## Ⅲ. 절차
- ASCII 흐름도
[손실 함수 설정] -> [트리 순차 생성] -> [잔차 업데이트] -> [모델 결합]
- 4단계 설명
1. 기울기 산출: 현재 모델의 예측값과 실제값 사이의 그래디언트 계산함.
2. 최적 분할 검색: 정보를 가장 많이 얻을 수 있는 분할 지점을 탐색함.
3. 규제 적용: L1, L2 정규화를 통해 모델의 복잡도를 제어함.
4. 모델 업데이트: 이전 단계의 오차를 반영하여 모델을 갱신함.
> 요약: 오차의 기울기를 따라 트리를 순차적으로 최적화하는 과정임.

## Ⅳ. 문제점
- 데이터 양이 적을 경우 과적합 위험이 크며 하이퍼파라미터가 매우 많음.

## Ⅴ. 개선방안
- 단기: 학습 데이터 셋 분할 및 교차 검증을 필수적으로 수행함.
- 중기: 베이지안 최적화(Optuna 등)를 활용해 파라미터를 자동 탐색함.
- 장기: 데이터 특성에 최적화된 자동 머신러닝(AutoML) 파이프라인 구축함.

## Ⅵ. 전망
- CPU 병렬화를 넘어 GPU 가속 및 분산 환경(Dask, Spark) 최적화가 필수적이며, 트리 모델의 해석 가능성을 높이는 XAI 기법(SHAP 등)과의 결합을 통해 금융/의료 등 고신뢰 의사결정 분야의 주류 기술로 안착할 것임.
- 정형 데이터 기반의 성능 지표가 우수한 만큼 향후 비정형 데이터를 정형화하여 결합 분석하는 멀티모달 프레임워크의 핵심 추론 엔진으로 활용될 전망임.
