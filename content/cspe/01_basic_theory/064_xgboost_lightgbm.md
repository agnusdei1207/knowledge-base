## 미리 알고가기

- 그래디언트 부스팅($Gradient$ $Boosting$): 이전 단계의 결정 트리가 예측하고 남긴 오차(잔차)를 다음 트리가 학습하여 오차를 줄여나가는 알고리즘임
- 수평 성장($Level-wise$ $Growth$): 균형 잡힌 트리 구조를 만들기 위해 노드를 좌우 균등하게 확장해 나가는 방식임
- 수직 성장($Leaf-wise$ $Growth$): 좌우 균형에 상관없이 최대 손실 값을 감소시키는 리프 노드를 깊게 파고들며 분할하는 방식임
- 히스토그램 기반 알고리즘: 연속형 변수를 유한한 범위($Bin$)로 이산화하여 최적의 분할 지점을 고속으로 찾아내는 최적화 기법임

## Ⅰ. 개요

- **정의/개념**: XGBoost와 LightGBM은 앙상블 학습의 그래디언트 부스팅($GBM$) 이론을 기반으로 각각 정규화 제어와 히스토그램 기반 수직 성장을 도입하여 연산 속도와 예측력을 극대화한 고성능 머신러닝 라이브러리임
- **배경/필요성**: 기존의 그래디언트 부스팅 모델은 연산량이 너무 많고 학습 속도가 극도로 느려 빅데이터 분석에 부적합하므로, 병렬 연산 및 메모리 절약을 통해 실시간 서비스가 가능한 수준으로 최적화하기 위해 제안됨

## Ⅱ. 특징

- 정형 데이터($Tabular$ $Data$) 분야에서 최신 딥러닝 아키텍처보다 더 빠른 수렴 속도와 높은 일반화 성능을 보여주며 실무의 표준($De$ $facto$ $Standard$)으로 사용됨
- 가중치 규제(L1, L2 Regularization)와 조기 종료($Early$ $Stopping$) 기능을 자체 내장하여 전통적인 부스팅 알고리즘의 고질적인 문제인 오버피팅을 효과적으로 방지함
- 변수 중요도($Feature$ $Importance$)를 계산하여 비즈니스 의사결정의 핵심 인자가 무엇인지 도출해 주는 설명 편의성을 제공함

## Ⅲ. 종류 및 비교

| 판단 기준 | XGBoost (eXtreme Gradient Boosting) | LightGBM (Light Gradient Boosting Machine) |
|:---|:---|:---|
| **트리 성장 방식** | 수평 성장 ($Level-wise$ $Growth$) | 수직 성장 ($Leaf-wise$ $Growth$) |
| **연산 속도** | 빠름 | 매우 빠름 (XGBoost 대비 2~10배) |
| **메모리 사용량** | 중간 | 매우 낮음 |
| **대용량 적합성** | 적합함 | 매우 적합함 (데이터가 작으면 오버피팅 발생) |
| **핵심 최적화** | 분산 환경 지원, 결측치 자동 처리 | 히스토그램 기반 의사결정 나무 탐색 |

> 요약: XGBoost는 안정적인 균형 트리를, LightGBM은 대규모 데이터에 대한 초고속 불균형 트리를 지향함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 목적 함수 ($Objective$) | 부스팅 모델이 최소화하려는 오차 수식으로, 사용자 정의($Custom$) 함수 구현이 가능함 |
| 테일러 2차 근사 | XGBoost에서 목적 함수의 1차 미분(Gradient)과 2차 미분(Hessian)을 활용해 최적화 속도를 높인 기술임 |
| 히스토그램 버킷 | LightGBM에서 특징 값들을 여러 구간으로 묶어 메모리 사용량과 분할 비교 횟수를 줄이는 단위임 |
| $GOSS$ 기법 | LightGBM에서 gradient가 큰 데이터 위주로 샘플링하여 학습 효율을 높이는 기술임 |

```text
[ 트리 성장 알고리즘 비교 ]
XGBoost (Level-wise): 균형 성장
      [Root]
     /      \
  [Node]  [Node] (양쪽을 다 맞추어 확장)

LightGBM (Leaf-wise): 비대칭 깊이 성장
      [Root]
     /      \
  [Node]   (안쪽 하나만 손실이 크면 계속 파고듬)
  /
[Leaf]
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 오차(잔차)계산| --> | 신규 트리 훈련| --> | 학습률 가중치| --> | 가중치에 추가|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **오차 검출** — 현재 모델이 가진 예측 성능의 한계를 진단하기 위해 실제값과 예측값의 잔차(Residual)와 1, 2차 미분 계수를 계산함
2. **트리 학습** — 계산된 잔차를 정답 라벨로 삼아 새로운 결정 트리를 생성하며, 라이브러리 방식에 따라 수평 혹은 수직 성장을 진행함
3. **학습률 제어** — 새로 생성된 트리의 영향력을 낮추어 급격한 변화를 막기 위해 학습률($eta$ 또는 $learning$ $rate$)을 적용하여 강도를 제어함
4. **결과 누적** — 조정된 트리를 기존 모델 사슬에 결합하는 과정을 수십~수백 번 반복하며 점진적으로 정답에 도달함

## Ⅵ. 실무 적용 및 유의점

1. LightGBM의 수직 성장 방식은 데이터를 매우 세밀하게 표현할 수 있지만, 데이터 수(보통 1만 개 이하)가 적을 때는 특정 노드만 과하게 학습하는 오버피팅이 쉽게 발생하므로 최소 데이터 수 제한($min$ $data$ $in$ $leaf$) 옵션을 높여야 함
2. 부스팅 모델 훈련 시 검증 데이터셋에 대한 성능이 특정 횟수 이상 개선되지 않으면 학습을 즉시 멈추는 '조기 종료($Early$ $Stopping$)'를 설정하여, 과적합을 방지하고 불필요한 컴퓨팅 비용 낭비를 차단해야 함

## Ⅶ. 결론

- XGBoost와 LightGBM은 현대 머신러닝의 예측력을 지배하는 최고의 양대 무기이며, 설계자는 데이터의 크기와 범주형 변수의 비율 및 실시간 응답 지연 요구 사항을 파악하여 최적의 알고리즘 엔진을 선택하고 튜닝해야 함
