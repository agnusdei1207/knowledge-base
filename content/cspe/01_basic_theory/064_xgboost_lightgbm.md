## 미리 알고가기

- 그래디언트 부스팅: 이전 모델의 잔차를 다음 트리가 학습해 오류를 줄이는 방식임
- 잔차: 실제값과 현재 예측값의 차이임
- Level-wise 성장: 같은 깊이의 노드를 균형 있게 확장함
- Leaf-wise 성장: 손실 감소가 큰 리프를 우선 확장함
- 조기 종료: 검증 성능이 더 나아지지 않으면 학습을 멈춤

## Ⅰ. 개요

- **정의/개념**: XGBoost와 LightGBM은 그래디언트 부스팅 트리를 고속화하고 정규화·분산 처리·히스토그램 최적화를 결합한 정형 데이터 예측 모델임
- **배경/필요성**: 정형 데이터 예측에서는 높은 정확도와 빠른 학습, 과적합 제어를 동시에 만족하는 부스팅 구현이 필요함

## Ⅱ. 특징

- 잔차를 반복 학습해 약한 트리를 강한 모델로 결합함
- 정형 데이터에서 높은 성능과 튜닝 유연성을 제공함
- 정규화와 조기 종료로 과적합을 제어함
- 변수 중요도로 주요 영향 요인을 해석함

## Ⅲ. 종류 및 비교

| 구분 | XGBoost | LightGBM |
|:---|:---|:---|
| 성장 방식 | Level-wise 중심 | Leaf-wise 중심 |
| 강점 | 안정적 일반화와 정규화 | 빠른 학습과 낮은 메모리 |
| 최적화 | 2차 미분, 병렬 처리 | 히스토그램, 기울기 샘플링, 특징 묶음 |
| 적합 데이터 | 중소~대규모 정형 데이터 | 대규모·고차원 정형 데이터 |
| 주의점 | 학습 시간이 상대적으로 큼 | 소규모 데이터 과적합 위험 |

> 요약: XGBoost는 안정적 균형 성장, LightGBM은 대규모 고속 학습에 초점이 있음.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 목적 함수 | 손실 함수와 정규화 항을 함께 최소화함 |
| 결정 트리 | 잔차를 설명하는 약한 학습기 역할을 함 |
| 학습률 | 새 트리의 반영 폭을 낮춰 과적합을 줄임 |
| 히스토그램 버킷 | 연속값을 구간화해 분할 탐색 비용을 낮춤 |
| 검증 세트 | 조기 종료와 튜닝 성능 판단에 사용함 |

> 요약: 목적 함수, 트리, 학습률, 검증 세트가 부스팅 반복을 통제함.

```text
Current model -> Residual/gradient -> New tree -> Learning rate -> Updated model
                     ^                                      |
                     +------------- repeat ----------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
Initialize score -> Compute gradient -> Fit tree -> Add tree -> Stop by validation
```

1. 초기 예측값을 만들고 손실 기준의 잔차나 그래디언트를 계산함
2. 잔차를 잘 설명하는 새 결정 트리를 학습함
3. 학습률을 적용해 새 트리를 기존 모델에 더함
4. 검증 성능이 개선되는 동안 반복하고 조기 종료로 멈춤

> 요약: 부스팅은 잔차를 줄이는 트리를 순차 추가하되 검증 성능으로 반복 중단 시점을 정함.

## Ⅵ. 실무 적용 및 유의점

1. 신용평가나 수요예측 같은 정형 데이터에는 부스팅 계열이 강하지만 범주형 처리, 결측치, 불균형 표본을 명확히 설정하고 검증 AUC나 RMSE로 확인함
2. LightGBM은 빠르지만 Leaf-wise 성장이 깊어지면 과적합되기 쉬우므로 `num_leaves`, `min_data_in_leaf`, 조기 종료를 함께 조정함

## Ⅶ. 결론

- XGBoost와 LightGBM은 정형 데이터에서 정확도와 비용의 균형을 잡는 부스팅 도구이며, 데이터 규모와 과적합 위험에 맞춰 선택해야 함
