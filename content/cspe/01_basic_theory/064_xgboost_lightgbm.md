## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 트리 기반 부스팅 알고리즘의 학습 속도와 성능을 극대화한 분산형 앙상블 학습 프레임워크임. |
| 배경/필요성 | 기존 GBM의 느린 순차 학습 속도를 개선하고 과적합을 제어하는 병렬/최적화 부스팅 엔진 필요성 증가. |
| 출제 의도 | Level-wise 트리 분할(XGBoost)과 Leaf-wise 트리 분할(LightGBM)의 차이 및 정규화 기반 최적화 평가. |

## Ⅱ. 구성요소
```text
+-------------+      +-------------+
| Loss Func.  |      | Reg. Term   |
+-------------+      +-------------+
       |                    |
       +---------+----------+
                 |
          +-------------+
          | Tree Split  |
          +-------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 손실 함수(Loss Function) | 모델 예측과 실제값의 오차를 산출하는 기준 | 나침반 |
| 정규화 항(Regularization)| 트리의 복잡도를 제한하여 과적합 방지 | 브레이크 |
| 트리 분할 방식(Split) | 최적의 피처 기준을 찾아 노드를 분리 | 이정표 |

> 요약: 목적 함수(손실 함수+정규화 항)를 최소화하는 방향으로 트리를 최적 분할하며 성장시킴.

## Ⅲ. 절차
```text
+----------+   +----------+   +----------+   +----------+
| Base Pred|-> | Residual |-> | Grow Tree|-> | Update   |
+----------+   +----------+   +----------+   +----------+
```
1. 기본 예측: 초기 베이스라인 예측값을 설정하고 오차(잔차)를 계산함.
2. 잔차 모델링: 잔차를 타겟으로 하여 새로운 의사결정 트리를 생성함.
3. 최적 트리 성장: XGBoost는 Level-wise, LightGBM은 Leaf-wise로 분할함.
4. 가중치 업데이트: 학습률(Learning Rate)을 반영하여 최종 모델을 업데이트함.

> 요약: 잔차를 타겟으로 순차적으로 트리를 성장시키고 정규화를 통해 가중치를 갱신함.

## Ⅳ. 문제점
- 잔차를 지속 학습하는 과정에서 노이즈까지 학습하여 과적합 위험성 상존
- 하이퍼파라미터 수가 매우 많아 수동 튜닝 시 최적 성능 도출에 장시간 소요
- 대량의 범주형 변수(Categorical Feature) 처리 시 원핫 인코딩으로 인한 메모리 오버헤드

## Ⅴ. 개선방안
- [단기] 학습 조기 종료(Early Stopping) 및 학습률(Learning Rate) 스케줄링 적용
- [중기] 베이지안 기반 최적화(Optuna 등)를 활용하여 파라미터 탐색 효율성 극대화
- [장기] 히스토그램 기반의 카테고리 분할을 자체 지원하는 LightGBM 등 최적 프레임워크로 일원화

## Ⅵ. 전망
- 정형(Tabular) 데이터 기반 머신러닝 과제에서 최고의 성능을 자랑하며, 실무 데이터 분석의 표준으로 지속 사용될 것임.
