## Ⅰ. 개요
- **정의**: 잔차를 순차적으로 보정하는 그래디언트 부스팅을 최적화한 트리 기반 앙상블 프레임워크임
- **배경/필요성**: 기존 GBM의 느린 학습 속도와 메모리 비효율을 해결하여 대규모 정형 데이터 처리 필요 (앙상블 원리는 063 참조)
- **비유**: 시험 오답만 집중 복습하되, 복습 속도를 극한까지 끌어올린 학습법

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| XGBoost vs LightGBM 트리 분할 전략 차이 | Level-wise(XGB) vs Leaf-wise(LGBM) | 정규화 항(L1/L2)의 과적합 방지 역할 누락 시 감점 |

> 요약: GBM의 속도·메모리 한계를 구조적으로 개선한 부스팅 프레임워크로, 정형 데이터 분석의 사실상 표준임

## Ⅱ. 구성요소
```text
+-----------+     +-----------+     +-----------+
| Loss +    | --> | Tree      | --> | Learning  |
| Reg Term  |     | Split     |     | Rate      |
| (Object)  |     | Strategy  |     | Update    |
+-----------+     +-----------+     +-----------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 목적 함수 | 손실 함수(예측 오차) + 정규화 항(트리 복잡도 페널티)의 합 | 성적 + 벌점 |
| 트리 분할 전략 | XGB: Level-wise(균형 성장), LGBM: Leaf-wise(손실 최대 감소 리프 우선 분할) | 층별 vs 잎 우선 |
| 히스토그램 분할 | 연속값을 이산 구간(bin)으로 변환하여 분할점 탐색 속도 향상 (LGBM 핵심) | 눈금자 단순화 |
| 학습률(η) | 각 트리의 기여도를 축소하여 과적합을 억제하는 shrinkage 계수 | 보폭 조절 |

> 요약: 목적 함수 최소화를 위해 분할 전략과 학습률을 조절하며 순차적으로 트리를 추가하는 구조임

## Ⅲ. 절차
```text
+-----------+     +-----------+     +-----------+     +-----------+
| Init      | --> | Compute   | --> | Grow      | --> | Shrink    |
| Predict   |     | Residual  |     | New Tree  |     | & Update  |
+-----------+     +-----------+     +-----------+     +-----------+
```

1. **초기 예측** — 전체 데이터의 평균값(회귀) 또는 로그 오즈(분류)를 기본 예측값으로 설정
2. **잔차 계산** — 현재 모델의 예측과 실제값 간 잔차(그래디언트)를 산출
3. **신규 트리 성장** — 잔차를 타겟으로 XGB는 Level-wise, LGBM은 Leaf-wise로 트리 분할
4. **축소 갱신** — 학습률(η)을 곱하여 신규 트리를 기존 모델에 가산, Early Stopping 평가

> 요약: 잔차를 타겟으로 트리를 순차 추가하고 학습률로 기여도를 축소하며 모델을 점진 개선함

## Ⅳ. 문제점
- **노이즈 과적합**: 잔차 순차 학습 구조상 노이즈까지 피팅하여 검증 손실이 발산할 위험 존재
- **하이퍼파라미터 과다**: max_depth, n_estimators, subsample 등 20개 이상 파라미터의 조합 탐색 부담
- **범주형 변수 처리 비용**: XGBoost는 원핫 인코딩 필수로, 고카디널리티 피처 시 메모리 급증

> 요약: 노이즈 과적합, 파라미터 튜닝 복잡도, 범주형 인코딩 오버헤드가 실무 적용의 주요 병목임

## Ⅴ. 개선방안
1. 단기: Early Stopping(n_rounds 무개선 시 중단) + 학습률 스케줄링으로 과적합 조기 차단
2. 중기: Optuna·Hyperopt 등 베이지안 최적화 프레임워크로 탐색 공간 자동 축소
3. 장기: LightGBM의 네이티브 범주형 분할(Optimal Split for Categorical)로 원핫 인코딩 제거

- **범주형 변수 비용**: 원핫 인코딩 메모리 폭증 → CatBoost 또는 LGBM 네이티브 분할 전환 (지표: 메모리 사용량 50% 이상 절감)

> 요약: 조기 종료, 자동 튜닝, 네이티브 범주형 처리로 부스팅 프레임워크의 실용성을 극대화함

## Ⅵ. 전망
- 향후 발전 방향: 분산 학습(Spark/Dask 연동)과 GPU 가속으로 10억건급 정형 데이터 실시간 학습 가능
- 기술사적 판단: 비정형(이미지·텍스트)은 딥러닝이 우세하나, 정형 데이터는 GBDT가 여전히 SOTA급 성능임
- 기술사 제언: XGBoost와 LightGBM의 트리 분할 차이를 그림으로 비교하고 정규화 항의 수식적 의미까지 서술해야 고득점
