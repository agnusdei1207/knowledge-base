## 미리 알고가기

- 가중합($z$): 입력값과 가중치를 곱해 더하고 편향을 더한 뉴런의 선형 입력임
- 비선형성($Non-linearity$): 입력과 출력이 단순 직선 관계가 아니어서 복잡한 패턴을 표현하는 성질임
- 도함수($Derivative$): 역전파에서 오차 기울기가 이전 층으로 전달되는 비율임
- 포화($Saturation$): 입력이 커질 때 출력 변화가 거의 없어 도함수가 0에 가까워지는 현상임
- 기울기 소실: 깊은 층을 거치며 기울기가 작아져 앞쪽 층이 학습되지 않는 현상임
- 죽은 ReLU(Dying ReLU): 음수 입력이 계속되어 ReLU 출력과 기울기가 0으로 고정된 뉴런 상태임

## 작성 근거(검토용)

- 기출 범위의 ReLU, Sigmoid, Tanh를 비교표 중심에 두고 Softmax는 출력층 구성요소로만 제한함
- 활성화 함수의 본질을 비선형 출력과 역전파 도함수로 정의해 구조와 절차를 연결함
- 포화와 기울기 소실은 함수 선택의 핵심 위험이라 미리 알고가기와 특징에 포함함
- 죽은 ReLU는 ReLU의 대표 실패 조건이라 사례에 반영함
- 출력층 함수는 손실 함수와 함께 선택해야 하므로 사례에서 확률 해석 기준을 제시함

## Ⅰ. 개요

- **정의/개념**: 활성화 함수는 뉴런의 가중합에 비선형 변환을 적용해 다음 층으로 전달할 출력값과 역전파 기울기를 결정하는 함수임
- **배경/필요성**: 복잡한 패턴을 학습하기 위해 선형 층에 비선형성을 더하는 활성화 함수가 필요함

## Ⅱ. 특징

- 신경망에 비선형성을 부여해 선형 분리 불가능한 데이터도 표현하게 함
- 도함수 크기가 역전파 신호를 결정하므로 학습 속도와 기울기 소실에 직접 영향을 줌
- 출력 범위가 다르므로 은닉층·이진 분류 출력층·다중 분류 출력층에 맞는 함수를 구분해야 함
- 포화 구간이나 음수 구간 처리 방식에 따라 죽은 뉴런·수렴 지연·확률 해석 문제가 발생함

## Ⅲ. 종류 및 비교

| 기준 | Sigmoid | Tanh | ReLU |
|:---|:---|:---|:---|
| 출력 범위 | $(0, 1)$ | $(-1, 1)$ | $[0, \infty)$ |
| 중심 | 양수 중심 | 0 중심 | 양수 영역 선형 |
| 기울기 특성 | 양 끝에서 소실 | 양 끝에서 소실 | 양수 영역에서 1 유지 |
| 주요 용도 | 이진 분류 출력 확률 | 순환 신경망 내부 상태 | 깊은 신경망 은닉층 |
| 유의점 | 은닉층 사용 시 학습 지연 | 포화 구간 주의 | 죽은 ReLU 발생 가능 |

> 요약: Sigmoid는 확률 출력, Tanh는 0 중심 표현, ReLU는 깊은 망의 기울기 전달에 유리함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 가중합 $z$ | $z = Wx + b$로 계산되며 활성화 함수의 입력이 됨 |
| 활성화 함수 $f(z)$ | 선형 입력을 비선형 출력으로 바꿔 표현력을 만드는 핵심 함수임 |
| 도함수 $f'(z)$ | 역전파에서 이전 층으로 전달할 기울기 크기를 결정함 |
| 출력층 함수 | Sigmoid나 Softmax처럼 손실 함수와 결합해 확률 해석을 제공함 |
| 초기화 방식 | 입력 분포와 활성화 함수에 맞춰 기울기 폭주나 소실을 줄임 |

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 입력 x    | --> | z = Wx+b  | --> | f(z)      | --> | 다음 층 출력 |
+-----------+     +-----------+     +-----------+     +-----------+
                                      |
                                      v
                               역전파 f'(z)
```

> 요약: 활성화 함수는 순전파 출력과 역전파 기울기를 동시에 결정하는 비선형 변환임.

## Ⅴ. 원리 및 절차 흐름도

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 가중합 계산 | --> | 함수 적용 | --> | 출력 전달 | --> | 기울기 전달 |
+-----------+     +-----------+     +-----------+     +-----------+
```

1. **가중합 계산** — 이전 층 출력에 가중치와 편향을 적용해 선형 입력 $z$를 산출함
2. **함수 적용** — $z$를 Sigmoid, Tanh, ReLU 같은 활성화 함수에 넣어 비선형 출력을 만듦
3. **출력 전달** — 변환된 값이 다음 층의 입력이 되어 더 복잡한 특징 조합을 형성함
4. **기울기 전달** — 역전파 시 손실 기울기에 $f'(z)$를 곱해 이전 층 가중치 갱신에 사용함

> 요약: 함수의 출력 범위와 도함수 특성이 층별 표현력과 학습 안정성을 좌우함.

## Ⅵ. 실무 사례

1. 깊은 신경망의 은닉층에서는 Sigmoid보다 ReLU 계열을 우선 적용하고 학습 손실과 죽은 뉴런 비율로 기울기 전달 상태를 확인함
2. 분류 출력층은 함수와 손실 조합이 어긋나면 확률이 왜곡되므로 이진 분류에는 Sigmoid, 다중 분류에는 Softmax를 쓰고 교정 오차로 검증함

## Ⅶ. 결론

- 활성화 함수는 표현력과 기울기 전달을 함께 결정하므로 층의 역할·출력 범위·도함수 특성에 맞게 선택해야 함
