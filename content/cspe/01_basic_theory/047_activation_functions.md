## 미리 알고가기

- 인공 뉴런: 생물학적 뉴런을 모사하여 입력을 가중치와 합산한 뒤 특정 함수를 거쳐 출력하는 단위임
- 비선형성($Non-linearity$): 출력값이 입력값에 단순 비례하지 않는 성질로, 신경망이 복잡한 데이터 패턴을 학습하게 함
- 기울기 소실($Vanishing$ $Gradient$): 역전파 과정에서 기울기가 점차 작아져 0에 수렴함으로써 학습이 중단되는 현상임
- 포화($Saturation$): 입력값이 커지거나 작아짐에 따라 출력값의 변화가 거의 없어지는 현상임

## Ⅰ. 개요

- **정의/개념**: 활성화 함수는 퍼셉트론의 가중합 결과에 비선형 변환을 적용하여 다음 층으로 신호를 전달할지 여부와 강도를 결정하는 함수이며, 신경망의 깊이가 깊어져도 표현력이 상실되지 않도록 보장하는 핵심 요소임
- **배경/필요성**: 활성화 함수 없이 선형 결합만으로 층을 쌓으면 전체 네트워크가 결국 하나의 선형 함수와 같아져($W_2(W_1x) = W_{new}x$) 복잡한 비선형 문제를 해결할 수 없기 때문에 도입됨

## Ⅱ. 특징

- 신경망에 비선형성을 부여하여 $XOR$ 문제와 같은 선형 불가능한 데이터 분포를 모델링할 수 있는 수학적 근간을 마련함
- 함수의 형태에 따라 연산 복잡도와 기울기 전달 특성이 다르며, 이는 전체 네트워크의 수렴 속도($Convergence$ $Rate$)와 학습 안정성에 직접적인 영향을 미침
- 미분 가능해야 역전파($Backpropagation$)를 통한 가중치 업데이트가 가능하며, 도함수의 값이 0에 너무 가깝지 않아야 깊은 층까지 학습 신호가 도달함

## Ⅲ. 종류 및 비교

| 판단 기준 | 시그모이드 (Sigmoid) | 하이퍼볼릭 탄젠트 (Tanh) | ReLU |
|:---|:---|:---|:---|
| **출력 범위** | 0 ~ 1 | -1 ~ 1 | 0 ~ $\infty$ |
| **중심값** | 0.5 (양수 편향) | 0 (Zero-centered) | 없음 |
| **기울기 소실** | 매우 심함 | 심함 | 거의 없음 (양수 영역) |
| **연산 속도** | 지수 함수로 인해 느림 | 지수 함수로 인해 느림 | 매우 빠름 (단순 비교) |
| **주요 용도** | 이진 분류의 출력층 | 순환 신경망($RNN$) | 일반적인 은닉층 (표준) |

> 요약: 시그모이드는 확률 표현에, Tanh는 데이터 중심화에, ReLU는 깊은 망의 고속 학습에 유리함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 가중합 ($z$) | 입력 벡터와 가중치 벡터의 내적($\sum w_ix_i + b$)이며, 함수의 입력값임 |
| 임계치 | 특정 신호 세기 이상에서만 뉴런이 활성화되도록 제어하는 기준값임 |
| 시그모이드 | $1 / (1 + e^{-z})$ 형태이며, 모든 입력을 0과 1 사이로 압축함 |
| 소프트맥스 | 여러 뉴런의 출력 합을 1로 만들어 다중 클래스 분류의 확률값으로 변환함 |

```text
[ ReLU 함수 정의 ]
f(x) = max(0, x)
- x > 0 이면 기울기가 1로 유지되어 Gradient Vanishing 해결
- x ≤ 0 이면 뉴런이 비활성화됨
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 입력 가중합  | --> | 활성화 함수 적용| --> | 비선형 출력 생성| --> | 다음 층 전파  |
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **신호 집계** — 이전 층으로부터 전달된 신호들에 가중치를 곱하고 편향($Bias$)을 더해 하나의 스칼라 값인 가중합을 산출함
2. **비선형 사상** — 산출된 가중합을 활성화 함수($\sigma, \phi$ 등)에 입력하여 선형 공간에서 비선형 공간으로 데이터를 매핑함
3. **뉴런 발화** — 변환된 값이 임계치를 넘거나 특정 영역에 속하면 활성화된 상태로 간주하여 유의미한 정보를 생성함
4. **역전파 갱신** — 손실 함수로부터 계산된 오차 기울기가 활성화 함수의 미분값을 타고 이전 층으로 전달되어 가중치를 최적화함

## Ⅵ. 실무 적용 및 유의점

1. 시그모이드나 Tanh는 층이 깊어질수록 양 끝단에서 기울기가 0에 수렴하는 포화 현상이 발생하여 학습이 멈추는 '기울기 소실' 문제가 빈번하므로, 현대의 깊은 신경망($DNN$)에서는 은닉층 활성화 함수로 ReLU를 우선적으로 고려해야 함
2. ReLU 사용 시 입력값이 음수이면 출력이 0이 되어 가중치 갱신이 영구히 멈추는 'Dying ReLU' 현상이 발생할 수 있으므로, 음수 영역에서도 미세한 기울기를 갖는 'Leaky ReLU'나 'ELU'와 같은 개선된 함수를 대안으로 검토해야 함

## Ⅶ. 결론

- 활성화 함수는 인공지능이 복잡한 패턴을 인지하게 만드는 비선형성의 마법이며, 설계자는 함수의 수치적 특성과 학습 안정성을 종합적으로 판단하여 최적의 신경망 아키텍처를 구축해야 함
