## Ⅰ. 개요
- 정의: 입력 신호의 총합을 출력 신호로 변환할 때 비선형성을 부여하는 함수임
- 배경: 선형 결합만으로는 복잡한 비선형 데이터를 표현할 수 없는 한계 극복
- 출제 의도:
| 구분 | 내용 |
| --- | --- |
| 핵심 | Sigmoid, ReLU, 기울기 소실(Vanishing Gradient) |

## Ⅱ. 구성요소
- ASCII 구조도
  [X] --(W)--> [Sum] --(f)--> [Out]
                 ^
                 |
               [b]
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| Sigmoid | 0~1 사이로 압축, 초기 신경망에 사용 | 관문 |
| ReLU | 0 이하는 0, 양수는 그대로 통과 | 필터 |
| Softmax | 출력 총합을 1로 만들어 확률로 변환 | 투표 |
> 요약: 비선형 임계값을 설정하여 신경망의 표현력을 극대화함

## Ⅲ. 절차
- ASCII 흐름도
  [가중합] -> [임계값적용] -> [비선형변환] -> [전파]
- 4단계 설명
1. 가중합 계산: 입력값과 가중치를 곱하고 편향을 더함
2. 함수 입력: 계산된 값을 선택된 활성화 함수에 입력함
3. 비선형 변환: 함수 정의에 따라 특정 범위로 매핑함
4. 결과 전파: 변환된 출력값을 다음 계층의 입력으로 전달함
> 요약: 선형 연산 결과를 비선형 영역으로 매핑하여 전달함

## Ⅳ. 문제점
- Sigmoid는 깊은 층에서 기울기 소실 문제 유발함
- ReLU는 음수 영역에서 뉴런이 죽는 'Dying ReLU' 현상 발생함

## Ⅴ. 개선방안
- (단기) 은닉층에서는 ReLU를 우선적으로 적용함
- (중기) Leaky ReLU, ELU 등 변형 함수로 음수 영역 보완함
- (장기) 가중치 초기화 기법(He, Xavier)과 결합하여 학습 최적화함

## Ⅵ. 전망
- 하드웨어 가속기(NPU)에 최적화된 Swish, GeLU 등 고도화된 함수 도입을 통한 학습 효율 개선이 기대됨
- 모델 경량화를 위한 활성화 함수 양자화(Quantization) 기술과 결합하여 Edge AI 상용화의 핵심 요소로 작용함
- 도메인 특화 데이터에 적합한 적응형(Adaptive) 활성화 함수 설계가 딥러닝 성능 한계 돌파의 CSF임
