## 미리 알고가기

- 가중합: 뉴런 입력과 가중치를 곱해 더한 값으로 활성화 함수의 입력이 됨
- 비선형성: 선형 변환만으로 표현할 수 없는 복잡한 관계를 학습하게 하는 성질임
- 기울기: 손실을 줄이기 위해 가중치를 어느 방향으로 바꿀지 알려주는 값임
- 포화 영역: 입력이 커지거나 작아져 함수 출력 변화가 거의 없어지는 구간임
- 출력층 함수: 문제 유형에 따라 Sigmoid, Softmax, Linear 등을 선택함

## Ⅰ. 개요

- **정의**: 활성화 함수는 뉴런의 가중합을 출력값으로 변환하고, 미분 가능한 비선형 기준을 제공해 신경망이 복잡한 데이터 관계를 학습하도록 하는 함수임
- **배경/필요성**: 선형 변환만 여러 층으로 쌓으면 전체도 선형 함수에 불과하므로 이미지, 음성, 텍스트의 비선형 패턴을 표현할 수 없음
- **비유**: 입력 신호를 그대로 통과시키지 않고 상황에 따라 켜거나 줄이는 스위치와 같음

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 신경망 비선형성 이해 | ReLU, Sigmoid, Tanh, 미분 가능성 | 선형층 반복과 차이 누락 |
| 학습 안정성 판단 | 기울기 소실, dead ReLU, 출력층 선택 | 은닉층·출력층 함수 혼동 |

> 요약: 활성화 함수는 신경망에 비선형 표현력과 학습 가능한 기울기 흐름을 제공하는 핵심 요소임.

## Ⅱ. 특징/비교

| 판단 기준 | Sigmoid·Tanh | ReLU·변형 ReLU |
|:---|:---|:---|
| 출력 범위 | Sigmoid는 0~1, Tanh는 -1~1로 제한됨 | 양수 입력은 그대로 통과하고 음수 입력은 0 또는 작은 기울기로 처리함 |
| 기울기 흐름 | 포화 영역에서 기울기 소실이 쉽게 발생함 | 계산이 단순하고 양수 영역 기울기 유지가 유리함 |
| 적용 위치 | 이진 확률 출력, 게이트 구조에 주로 사용함 | 깊은 은닉층의 기본 활성화 함수로 자주 사용함 |
| 선택 조건 | 출력 해석이 확률이나 게이트 값일 때 적합함 | 빠른 학습과 깊은 네트워크 학습 안정성이 필요할 때 적합함 |

> 요약: 은닉층은 기울기 흐름을, 출력층은 예측값의 의미와 범위를 기준으로 활성화 함수를 선택해야 함.

- **입력 조건**: 층의 위치, 입력 분포, 손실 함수와 출력값 의미를 함께 확인해야 함
- **평가 기준**: 층별 기울기 분포와 학습 손실 안정성을 함께 봄
- **선택 판단**: 은닉층은 학습 안정성, 출력층은 확률·수치 해석 기준으로 결정함

## Ⅲ. 구성요소

```text
+------------+      +------------+      +------------+
| 입력 벡터   | ---> | 가중합 z    | ---> | 활성화 출력 |
+------------+      +------------+      +------------+
       |                  |                  |
       v                  v                  v
+------------+      +------------+      +------------+
| 가중치     |      | 비선형 함수 |      | 기울기 전달 |
+------------+      +------------+      +------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 입력 벡터 | 이전 층에서 전달된 특징값이며 뉴런 계산의 대상임 | 들어오는 신호 |
| 가중합 `z` | 입력과 가중치를 곱해 더한 값으로 함수 적용 전 선형 결과임 | 스위치 입력 전압 |
| 활성화 함수 | ReLU, Sigmoid, Tanh, GELU 등 출력 변환 규칙임 | 신호 조절 스위치 |
| 출력값 | 다음 층으로 전달되는 비선형 변환 결과임 | 조절된 신호 |
| 도함수 | 역전파에서 손실 기울기를 앞 층으로 전달하는 계산 기준임 | 되돌아가는 안내선 |

> 요약: 활성화 함수는 뉴런의 선형 계산 결과를 비선형 출력으로 바꾸고 그 변화율을 통해 역전파를 가능하게 함.

## Ⅳ. 절차

```text
+------------+      +------------+      +------------+      +------------+
| 가중합 계산 | ---> | 함수 적용   | ---> | 출력 전달   | ---> | 기울기 계산 |
+------------+      +------------+      +------------+      +------------+
```

1. **가중합 계산**: 입력 특징과 가중치를 곱해 더하고 편향을 더해 `z`를 산출함
2. **함수 적용**: 은닉층 또는 출력층 목적에 맞는 활성화 함수를 적용해 출력값을 만듦
3. **출력 전달**: 변환된 값을 다음 층 입력 또는 최종 예측값으로 전달함
4. **기울기 계산**: 역전파 때 도함수를 사용해 앞 층 가중치 갱신 방향을 계산함

> 요약: 활성화 함수는 순전파에서 값을 변환하고 역전파에서 기울기 전달 경로를 결정함.

- **산출물**: 활성화 출력, 도함수 값, 다음 층 입력 분포임
- **검증 기준**: 포화 영역이나 0 출력 뉴런이 과도하게 많지 않아야 함
- **운영 기록**: 함수 종류, 초기화 방식, 정규화 위치를 모델 설정으로 남겨야 함

## Ⅴ. 문제점

- **P1 기울기 소실**: Sigmoid나 Tanh의 포화 영역에서는 도함수가 작아 깊은 층 앞부분의 가중치가 거의 갱신되지 않음
- **P2 dead ReLU**: 큰 음수 입력이 반복되면 ReLU 출력과 기울기가 0이 되어 일부 뉴런이 학습에 참여하지 못함
- **P3 출력 의미 불일치**: 회귀에 Sigmoid를 쓰거나 다중분류에 단일 Sigmoid를 쓰면 예측 범위와 손실 함수 의미가 어긋남

> 요약: 활성화 함수의 문제는 기울기 흐름과 출력 해석이 모델 구조와 맞지 않을 때 발생함.

## Ⅵ. 개선방안

- **P1 대응**: ReLU 계열, Xavier/He 초기화, Batch Normalization을 적용해 포화 영역 진입을 줄임 (확인: 층별 기울기 분포)
- **P2 대응**: Leaky ReLU, ELU, GELU, 학습률 조정을 사용해 음수 영역에서도 기울기 흐름을 유지함 (확인: 0 출력 뉴런 비율)
- **P3 대응**: 회귀는 Linear, 이진분류는 Sigmoid, 다중분류는 Softmax처럼 손실 함수와 출력 의미를 맞춤 (확인: 출력 범위와 라벨 형식 일치)

> 요약: 활성화 함수 개선은 은닉층의 기울기 흐름과 출력층의 예측 의미를 분리해 설계하는 것임.

- **우선순위**: 기울기 소실 여부와 출력층-손실 함수 일치 여부를 먼저 확인함
- **확인 지표**: gradient norm, activation histogram, validation loss를 함께 사용함
- **재평가 조건**: 네트워크 깊이, 초기화, 손실 함수가 바뀌면 활성화 함수를 재검토함

## Ⅶ. 전망

- **발전 방향**: 활성화 함수는 GELU, Swish, Mish 같은 부드러운 함수와 정규화 기법이 결합되며 대규모 CNN·Transformer·MLP의 학습 안정성을 높이는 방향으로 발전함
- **설계 관점**: 은닉층은 기울기 흐름과 표현력을, 출력층은 라벨 형식과 손실 함수 의미를 기준으로 활성화 함수를 분리 설계해야 함
- **검증 관점**: gradient norm, activation histogram, validation loss를 확인해 기울기 소실, dead neuron, 출력 의미 불일치가 없는지 검증해야 함
- **운영 관점**: 네트워크 깊이, 초기화, 손실 함수, 추론 정밀도가 바뀌면 활성화 분포와 검증 손실 변화를 재점검해야 함
- **적용 관점**: 깊은 은닉층에는 ReLU 계열 또는 GELU 계열이 유리하지만, 회귀·이진분류·다중분류 출력층은 업무 예측 범위에 맞춰 선택해야 함
- **보안·신뢰 관점**: 포화 영역이나 수치 overflow가 예측을 불안정하게 만들 수 있으므로 입력 정규화, 출력 범위 점검, 경계 입력 테스트로 신뢰성을 확인해야 함
- **기술사 제언**: 활성화 함수는 단순 공식이 아니라 기울기 전달과 출력 해석을 동시에 결정하는 설계 요소로 설명해야 함
