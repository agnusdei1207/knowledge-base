## 미리 알고가기

- **비선형성 ($Non-linearity$)**: 입력과 출력의 관계가 직선으로 설명되지 않는 특성. 활성화 함수는 신경망에 이 성질을 부여함
- **기울기 소실 ($Vanishing$ $Gradient$)**: 역전파 과정에서 미분값이 층을 거듭할수록 작아져 $0$에 수렴함으로써 학습이 중단되는 현상
- **포화 ($Saturation$)**: 함수의 입력값이 극단적으로 커지거나 작아질 때 출력이 특정 값으로 수렴하여 미분값이 $0$에 가까워지는 상태

## Ⅰ. 개요

- **정의/개념**: 활성화 함수($Activation$ $Function$)는 인공 신경망의 각 노드(뉴런)에서 입력받은 신호의 가중합($Weighted$ $Sum$)을 최종 출력 신호로 변환하는 함수임. 선형적인 결합 결과에 '비선형 사상'을 수행하여 신경망이 복잡한 패턴을 학습할 수 있게 만드는 핵심 기전임
- **배경/필요성**: 선형 활성화 함수만 사용하면 신경망을 아무리 깊게 쌓아도 결국 단일 선형 모델과 수학적으로 동일해짐($f(g(x)) = W_2(W_1x) = W'x$). 실제 세계의 복잡한 데이터(이미지, 음성 등)를 고차원 특징($Feature$)으로 추출하기 위해서는 비선형 임계치를 가진 활성화 함수가 필수적임

## Ⅱ. 특징 및 비교

### 가. 주요 활성화 함수별 기술적 특성 비교

| 구분 | 시그모이드 ($Sigmoid$) | 하이퍼볼릭 탄젠트 ($Tanh$) | $ReLU$ ($Rectified$ $Linear$) |
|:---|:---|:---|:---|
| 수학적 정의 | $f(x) = \frac{1}{1+e^{-x}}$ | $f(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$ | $f(x) = \max(0, x)$ |
| 출력 범위 | $(0, 1)$ | $(-1, 1)$ | $[0, \infty)$ |
| 중심 정렬 | 미지원 (항상 양수) | **지원 ($Zero-centered$)** | 미지원 (항상 양수/0) |
| 미분 특성 | 중앙 최대 $0.25$ | 중앙 최대 $1.0$ | 양수 영역 항상 $1.0$ |
| 주요 강점 | 확률적 해석이 가능함 | 기울기 소실 완화($Sigmoid$ 대비) | **연산 속도 극대화**, 소실 해결 |
| 주요 한계 | 심각한 기울기 소실 발생 | 포화 구간에서의 소실 존재 | $Dying$ $ReLU$ (음수 영역 사망) |

> 요약: 초기는 확률 기반의 $Sigmoid$를 사용했으나, 심층 신경망의 학습 효율성($Vanishing$ $Grad.$ 해결)을 위해 현대는 $ReLU$ 계열을 표준으로 선정함

### 나. 설계 판단 기준 및 트레이드오프 (PPA 관점)
- **수렴 속도 ($Performance$)**: $ReLU$는 단순한 임계값 비교 연산만 수행하므로 $Exponential$ 연산을 포함하는 $Sigmoid/Tanh$보다 수십 배 빠른 학습이 가능함
- **기울기 안정성 ($Stability$)**: $Tanh$는 출력이 $0$을 중심으로 분포하여 역전파 시 가중치 업데이트가 지그재그로 튀는 현상을 억제함
- **희소성 ($Sparsity$)**: $ReLU$는 음수 입력을 $0$으로 처리하여 뉴런의 불필요한 활성화를 억제함으로써 정보의 밀도를 높임

## Ⅲ. 구성요소/구조

### 가. 뉴런 내부 연산 아키텍처 인사이트 ($Architecture Insight$)

```text
  | (Linear Comb.) |    | (Activation)   |    | (Output a)     |    | Backprop.      |
  +----------------+    +----------------+    +----------------+    +----------------+
          |                      |                     |                     |
     Net Input             Decision Logic        Feature Extract       Weight Update
```

### 나. 주요 구성 요소 및 역할

| 구성요소 | 역할 및 설명 | 핵심 포인트 (Performance) |
|:---|:---|:---|
| 가중합 ($z$) | 입력과 가중치의 선형 결합 결과 | 신호의 세기를 정량화한 기초 데이터 |
| 임계치 ($Bias$) | 활성화 여부를 결정하는 기준 이동 | 뉴런이 쉽게 활성화될지 조절하는 인자 |
| 비선형 필터 | 고차원 공간으로의 데이터 사상 | 신경망의 표현력($Expressivity$) 결정 |
| 미분 계수 ($f'$) | 오차 신호가 거슬러 올라가는 통로 | 기울기 소실($Vanishing$) 여부를 결정 |

> 요약: 선형 가중합을 비선형 필터로 여과하여 유의미한 특징만을 추출하고 다음 계층으로 전파하는 구조임

## Ⅳ. 절차/동작 원리

1. **입력 신호 수신**: 이전 층($Layer$)의 출력들에 가중치를 곱하고 편향($Bias$)을 더함
2. **함수 사상**: 합산된 값($z$)을 활성화 함수($f$)에 통과시켜 출력값($a$)을 산출함
3. **순전파 전파**: 산출된 $a$를 다음 층의 입력으로 전달함
4. **오차 역전파**: 손실 함수($Loss$)로부터 계산된 기울기가 $f'(z)$를 곱하며 하위 층으로 전파되어 가중치를 갱신함

## Ⅴ. 문제점 및 개선방안

1. **기울기 소실 ($Vanishing$ $Gradient$)**: $Sigmoid$ 등 포화 함수는 층이 깊어질수록 미분값이 $0$에 수렴하여 학습이 중단됨
   - **개선방안**: 양수 미분이 $1$인 $ReLU$ 사용, 배치 정규화($Batch$ $Norm$)를 통해 입력을 포화 구간 밖으로 제어
2. **$Dying$ $ReLU$ 현상**: 입력이 음수일 때 출력이 $0$이 되어 해당 뉴런이 영구적으로 비활성화되는 현상
   - **개선방안**: 음수 영역에서 작은 기울기를 허용하는 $Leaky$ $ReLU$, $ELU$ 또는 지수 기반의 $GeLU$ 도입
3. **평균 편향 ($Mean$ $Shift$)**: $Sigmoid/ReLU$ 출력이 항상 양수이므로 가중치 업데이트 시 $Bias$가 특정 방향으로 편향됨
   - **개선방안**: $Zero-centered$ 특성을 가진 $Tanh$ 또는 $SELU$를 도입하여 학습 안정성 확보

## Ⅵ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 (Validation) |
|:---|:---|:---|
| 컴퓨터 비전 ($CNN$) | 수십 개의 컨볼루션 계층 사이에 $ReLU$ 배치 | $Training$ $Speed$, 특징 맵의 희소성 |
| 시계열 분석 ($LSTM$) | 게이트($Gate$) 제어에 $Sigmoid$, 정보 업데이트에 $Tanh$ 혼용 | 장기 의존성 보존, 기울기 안정성 |
| 광고 클릭 예측 ($CTR$) | 출력층에 $Sigmoid$를 사용하여 클릭 확률($0\sim 1$) 도출 | $Log$ $Loss$, $AUC-ROC$ |

> 요약: 은닉층에서는 학습 효율($ReLU$)을, 출력층에서는 문제 유형(이진/다중 분류)에 맞는 함수를 선택함

## Ⅶ. 결론

활성화 함수는 인공 신경망에 **'지능적 판단'**과 **'유연성'**을 부여하는 핵심 수치 변환기임. 단순한 수학 공식처럼 보이지만, 선택된 함수에 따라 신경망의 깊이(Depth) 한계와 학습 속도가 결정되는 결정적인 아키텍처 요소임.

기술사는 단순히 함수명을 나열하는 수준을 넘어, 각 함수의 미분 특성이 역전파 알고리즘에 미치는 물리적 영향력을 정밀하게 분석해야 함. 향후 대규모 언어 모델(LLM) 등에서 사용되는 $SwiGLU$, $GeLU$ 등 최신 활성화 함수의 특성을 파악하여, 연산 효율과 일반화 성능을 동시에 확보할 수 있는 설계 역량이 요구됨.
