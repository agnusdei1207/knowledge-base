## 미리 알고가기

- **비선형성 (Non-linearity)**: 입력과 출력의 관계가 직선으로 설명되지 않는 특성. 활성화 함수는 신경망에 이 성질을 부여함
- **기울기 소실 (Vanishing Gradient)**: 역전파 과정에서 미분값이 층을 거듭할수록 작아져 0에 수렴함으로써 학습이 중단되는 현상
- **포화 (Saturation)**: 함수의 입력값이 매우 커지거나 작아질 때 출력이 특정 값으로 수렴하여 미분값이 0에 가까워지는 상태

## 1. 개요

- **정의/개념**: 활성화 함수(Activation Function)는 인공 신경망의 각 노드(뉴런)에서 입력받은 신호의 가중치 합을 최종 출력 신호로 변환하는 함수임. 특히 선형적인 결합 결과에 '비선형성'을 부여하여 신경망이 복잡한 패턴을 학습할 수 있게 만드는 핵심 장치임
- **배경/필요성**: 만약 활성화 함수가 선형(Linear) 함수라면, 신경망을 아무리 깊게 쌓아도 단일 선형 회귀 모델과 수학적으로 동일해짐. 현실의 복잡한 데이터(이미지, 음성, 자연어)는 직선만으로는 설명할 수 없는 비선형 구조를 가짐. 따라서 층을 쌓는 의미를 살리고 고차원적인 특징(Feature)을 추출하기 위해서는 비선형 활성화 함수가 반드시 필요함

## 2. 특징 및 비교

### 가. 주요 활성화 함수별 특성 비교

| 구분 | 시그모이드 (Sigmoid) | 하이퍼볼릭 탄젠트 (Tanh) | ReLU (Rectified Linear Unit) |
|:---|:---|:---|:---|
| 수식 | $1 / (1 + e^{-x})$ | $\frac{e^x - e^{-x}}{e^x + e^{-x}}$ | $\max(0, x)$ |
| 출력 범위 | 0 ~ 1 | -1 ~ 1 | 0 ~ $\infty$ |
| 장점 | 확률적 해석이 가능함 | Zero-centered (평균 0) | 연산 빠름, 기울기 소실 완화 |
| 단점 | 기울기 소실 발생 (중심부 외) | 기울기 소실 (포화 구간) | Dying ReLU (음수 영역 사망) |
| 주요 용도 | 이진 분류의 출력층 | 초창기 DNN의 은닉층 | 현대 CNN, DNN의 표준 은닉층 |

> 요약: 초기는 Sigmoid 위주였으나, 깊은 망의 학습을 위해 현대는 ReLU 계열이 표준으로 자리 잡음

### 나. 활성화 함수의 설계 판단 기준
- **미분 가능성**: 역전파(Backpropagation) 시 가중치 업데이트를 위해 필수적임
- **계산 효율성**: 수백만 개의 뉴런에서 반복 연산되므로 함수가 단순할수록 학습 속도가 빨라짐
- **중심 정렬 (Zero-centered)**: 입력의 평균을 0으로 맞춰 다음 층으로 전달할 때 학습 안정성을 높임 (Tanh의 강점)

## 3. 구성요소/구조

### 가. 뉴런 내부의 연산 흐름

```text
[입력 x1, x2...] -> [가중합 Σ (wx+b)] -> [활성화 함수 f] -> [최종 출력 a]

1. Net Input: 입력과 가중치의 선형 결합을 통해 하나의 실수값 도출
2. Transformation: f(z)를 통해 신호를 압축하거나 특정 방향으로 활성화
3. Gradient Flow: 역전파 시 f'(z) 값이 가중치 갱신 속도를 결정
```

### 나. 주요 구성 요소 및 역할

| 구성요소 | 역할 및 설명 | 핵심 포인트 |
|:---|:---|:---|
| 입력 신호 | 이전 층에서 넘어온 데이터 또는 특징 | 활성화 여부를 결정하는 원천 |
| 가중치/편향 | 신호의 강도와 활성화 임계치를 조절 | 학습을 통해 최적화되는 대상 |
| 비선형 사상 | 데이터의 공간을 뒤틀어 클래스를 분리 | 신경망의 표현력(Expressivity) 결정 |
| 미분 계수 | 오차 신호가 거슬러 올라가는 통로 | 기울기 소실/폭주 여부를 결정함 |

> 요약: 선형 가중합을 비선형 필터(활성화 함수)로 걸러내어 의미 있는 정보를 다음 층으로 넘기는 구조임

## 4. 문제점 및 개선방안

1. **기울기 소실(Vanishing Gradient)**: Sigmoid나 Tanh는 $|x|$가 커질수록 미분값이 0으로 수렴하여 깊은 망에서 하위 층의 학습이 멈춤
   - **개선방안**: 양수 영역에서 미분이 1로 유지되는 ReLU를 사용하거나, Batch Normalization을 통해 입력을 포화 구간 밖으로 밀어냄

2. **Dying ReLU 현상**: 입력이 음수일 때 출력이 0이 되어 해당 뉴런이 영영 학습되지 않는 '죽은 뉴런'이 발생함
   - **개선방안**: 음수 영역에서 작은 기울기를 허용하는 Leaky ReLU, Parametric ReLU(PReLU) 또는 지수 함수를 쓰는 ELU를 적용함

3. **Softmax 오용**: 다중 분류 시 출력층에서 각 클래스 확률의 합이 1이 되어야 하는데 일반 활성화 함수를 쓰면 해석 불가
   - **개선방안**: 출력층에 Softmax를 적용하여 상호 배타적인 확률 분포를 생성하고, Cross-Entropy 손실 함수와 결합함

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| 컴퓨터 비전 (CNN) | 수십 개의 Convolution 레이어 사이에 ReLU를 배치하여 빠른 특징 추출 | 학습 속도, 정확도, Sparsity |
| NLP (RNN/LSTM) | 시퀀스 데이터의 게이트 제어를 위해 Sigmoid와 Tanh를 복합 사용 | 장기 의존성 유지, Gradient Stability |
| 광고 클릭 예측 (CTR) | 마지막 레이어에 Sigmoid를 사용하여 클릭할 '확률'을 0~1 사이로 산출 | Log Loss, AUC-ROC |

> 요약: 은닉층은 학습 효율(ReLU)을, 출력층은 문제 유형(Sigmoid/Softmax)을 고려하여 선택함

## 6. 결론

활성화 함수는 신경망에 '지능'과 '유연성'을 불어넣는 핵심 수치 변환기임. 단순한 수학 공식처럼 보이지만, 어떤 함수를 선택하느냐에 따라 망의 깊이가 결정되고 학습의 성패가 갈림.

기술사는 단순히 함수명을 암기하는 수준을 넘어, 각 함수의 미분 그래프와 출력 분포가 역전파 학습에 미치는 물리적 영향을 이해해야 함. 특히 과적합 방지, 학습 속도 개선, 기울기 안정성 확보라는 관점에서 데이터의 특성에 가장 부합하는 활성화 함수와 배치 정규화 등의 보조 기법을 조화롭게 설계할 수 있는 역량이 요구됨.
