## 미리 알고가기

- 비선형성: 단순 선형 결합만으로 표현하지 못하는 관계를 학습하게 하는 성질임
- gradient saturation: 출력 구간이 포화되어 기울기가 거의 0이 되는 현상임
- dead neuron: ReLU가 계속 0만 출력하는 상태임

## Ⅰ. 개요

- **정의/개념**: 활성화 함수는 뉴런의 선형 결합 결과에 비선형 변환을 적용해 신경망이 복잡한 함수 관계를 학습하도록 만드는 핵심 함수임
- **배경/필요성**: 여러 층을 쌓더라도 활성화 함수가 없으면 전체 네트워크는 하나의 선형 변환과 같아져 표현력이 제한됨

## Ⅱ. 특징

- Sigmoid와 Tanh는 출력 범위가 제한되어 확률 해석과 중심화에 유리함
- ReLU는 계산이 단순하고 gradient 소실이 상대적으로 적어 깊은 네트워크에 유리함
- 활성화 함수 선택은 학습 안정성, 수렴 속도, 표현력에 직접 영향 줌
- 부적절한 함수는 saturation, dead neuron, 계산 비용 증가를 초래함

## Ⅲ. 종류 및 비교

| 판단 기준 | Sigmoid | Tanh | ReLU |
|:---|:---|:---|:---|
| 출력 범위 | $(0,1)$ | $(-1,1)$ | $[0,\infty)$ |
| 장점 | 확률 해석 용이 | zero-centered | 단순, 빠름 |
| 단점 | saturation 큼 | saturation 가능 | 음수 영역 죽음 |
| 대표 사용 | 출력층 이진 분류 | RNN 일부 | 은닉층 기본 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 선형 합 $z$ | 가중합과 편향 결과이며 활성화 입력값임 |
| 비선형 함수 $f(z)$ | 출력을 변환하고 표현력의 원천임 |
| 도함수 $f'(z)$ | 역전파 시 사용됨 학습 안정성을 좌우함 |
| 층 위치 | 은닉층/출력층 위치이며 함수 선택 기준이 달라짐 |

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 가중합계산 | --> | 함수적용 | --> | 출력전달 | --> | 기울기전파 |
+----------+     +----------+     +----------+     +----------+
```

1. **가중합계산**: 입력과 가중치를 합산해 $z$를 만듦
2. **함수적용**: 선택된 활성화 함수로 비선형 변환함
3. **출력전달**: 다음 층에 활성값을 전달함
4. **기울기전파**: 도함수로 학습 신호를 역전파함

## Ⅵ. 문제점 및 해결 방안

1. 문제: gradient saturation이 발생해 Sigmoid, Tanh는 큰 절댓값 구간에서 학습이 느려짐
   - 해결방안: ReLU 계열이나 정규화 기법을 사용하고 gradient norm로 검증함
2. 문제: ReLU dead neuron이 생겨 음수 영역에서 계속 0이면 회복이 어려움
   - 해결방안: Leaky ReLU, 적절한 초기화, learning rate 조정이 필요하고 active neuron ratio로 검증함
3. 문제: 출력층 함수가 목적과 맞지 않을 수 있어 손실 함수와 불일치하면 학습이 불안정함
   - 해결방안: 이진 분류는 Sigmoid, 다중 분류는 Softmax를 사용하고 loss convergence로 검증함

## Ⅶ. 적용 사례

- 이미지 분류 CNN에서는 은닉층에 ReLU를 사용함, 확인 지표는 수렴 속도와 정확도임
- 이진 분류 모델에서는 출력층에 Sigmoid를 사용함, 확인 지표는 ROC-AUC임
- 시계열 모델에서는 특정 구조에서 Tanh를 상태 갱신에 사용함, 확인 지표는 gradient 안정성임

## Ⅷ. 결론

활성화 함수의 핵심은 비선형성을 주는 동시에 학습 신호를 살아 있게 유지하는 데 있으므로, 표현력보다 gradient 흐름을 기준으로 선택해야 함.
