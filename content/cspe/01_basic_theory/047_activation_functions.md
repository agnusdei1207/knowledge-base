## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 뉴런에서 입력 신호의 가중합을 출력 신호로 변환하여 신경망에 비선형성을 부여하는 함수임 |
| 배경/필요성 | 선형 함수의 단순 반복 연결로는 복잡한 데이터 간의 비선형적 상관관계를 학습할 수 없음 |
| 출제 의도 | 각 활성화 함수의 특징, 기울기 소실(Vanishing Gradient) 원인 및 해결방안 이해도 평가 |

## Ⅱ. 구성요소
```text
+----------------+       +----------------+       +----------------+
| Weighted Sum   |       | Activation     |       | Non-linear     |
| (WX + b)       | ----> | Function       | ----> | Output         |
+----------------+       +----------------+       +----------------+
```
| Sigmoid | 출력을 0과 1 사이로 압축하는 S자 형태 (이진 분류) | 확률 변환기 |
| Tanh | 출력을 -1과 1 사이로 압축, 중심이 0인 함수 | 중심잡힌 변환기 |
| ReLU | 입력이 음수면 0, 양수면 그대로 통과시키는 함수 | 양수 통과 필터 |
> 요약: 활성화 함수는 입력 가중합을 받아 Sigmoid, Tanh, ReLU를 거쳐 비선형 출력을 생성함

## Ⅲ. 절차
```text
+----------------+       +----------------+       +----------------+       +----------------+
| Input Calc     |       | Threshold Test |       | Non-linear Map |       | Forward Output |
| (Affine Trans) | ----> | (Condition)    | ----> | (Apply Func)   | ----> | (To Next Layer)|
+----------------+       +----------------+       +----------------+       +----------------+
```
1. 입력 계산: 이전 층 뉴런들의 출력값과 가중치를 곱하고 편향을 더함
2. 임계 비교: 가중합 결과가 활성화 함수의 기준 범위에 속하는지 평가
3. 비선형 변환: 선택된 활성화 함수를 통해 비선형 값으로 매핑(압축 등)
4. 출력 전달: 계산된 최종 결과값을 다음 층 뉴런의 입력으로 전달(순전파)
> 요약: 가중합을 계산하고, 활성화 함수로 비선형 매핑 후 다음 층으로 전달함

## Ⅳ. 문제점
- 기울기 소실 문제: Sigmoid/Tanh는 미분값이 작아 얕은 층으로 갈수록 학습이 정지됨
- 중심 이동 문제: Sigmoid는 출력 평균이 0이 아니어서 학습 경로가 지그재그로 흔들림
- Dying ReLU 현상: 음수 입력 시 출력이 0, 미분도 0이 되어 가중치 갱신이 영구 중단됨

## Ⅴ. 개선방안
- 단기 방안: 은닉층에 기울기 소실 방지를 위해 ReLU 또는 Tanh를 우선적으로 배치
- 중기 방안: 출력층은 목적에 맞게 Sigmoid(이진) 또는 Softmax(다중) 적용
- 장기 방안: Leaky ReLU, ELU, Swish 등 개선된 활성화 함수를 도입하여 Dying 문제 해결

## Ⅵ. 전망
- AutoML을 통해 데이터 특성에 맞는 최적의 활성화 함수 형태를 자체 탐색하는 방식으로 발전함
