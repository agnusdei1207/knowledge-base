# 📖 【암기용】 개념 완전 이해

> 목적: 활성화 함수를 처음 봐도 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 설명이다.

## 한눈에
- **개요**: 신경망에 비선형 표현 능력을 부여하는 함수
- **왜 필요한가**: 선형층만 여러 개 쌓으면 전체는 하나의 선형 변환과 같음
- XOR, 이미지 경계, 문장 의미처럼 꺾인 패턴을 표현하려면 비선형 함수가 필요함
- **핵심 직관**: 뉴런 출력에 문턱과 곡선을 넣어 단순 직선을 여러 조각의 결정 경계로 바꿈.

## 깊이 이해
- **배경·문제의식**: 딥러닝은 행렬곱과 편향만으로 구성되면 층 수와 무관하게 선형 모델임
- 활성화 함수가 층마다 비선형성을 삽입함
- **작동 원리**: Sigmoid는 0~1 확률형 출력, Tanh는 -1~1 중심화 출력, ReLU는 0 이하를 차단하고 양수를 그대로 통과시킴
- **비유**: 물길에 수문을 둔 구조와 같음
- ReLU는 음수 방향 물길을 막고, Sigmoid는 수위를 0~1 사이로 눌러 표시함
- **구체 예시**: 은닉층 ReLU는 `max(0,x)`라서 x=3이면 3, x=-2이면 0임
- 이 단순 절단이 수백만 뉴런에서 조합되어 복잡한 경계를 만듦
- **흔한 오해·주의점**: Sigmoid를 깊은 은닉층에 반복 사용하면 기울기 최대값 0.25 때문에 역전파 신호가 층마다 축소됨.

## 연결 개념
- 역전파(Backpropagation) — 활성화 함수 미분값을 체인룰에 사용
- 소실 기울기(Vanishing Gradient) — Sigmoid/Tanh 포화 구간에서 발생
- 배치정규화(Batch Normalization) — 입력 분포를 조정해 활성화 포화 완화

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 활성화 함수는 신경망 각 층의 선형 출력을 비선형 출력으로 변환하는 함수임.
> 2. **가치**: 다층 신경망이 XOR, 이미지·음성·문장 패턴의 비선형 결정 경계를 학습하게 함.
> 3. **판단 포인트**: 은닉층은 ReLU 계열, 이진 출력은 Sigmoid, 다중분류 출력은 Softmax를 선택함.

---

## Ⅰ. 개요 및 필요성

- 개요: 활성화 함수는 신경망 각 층에 비선형성을 부여하는 변환 함수임
- 배경: 신경망은 행렬곱만 반복하면 선형 모델 하나와 동일하므로 복잡한 패턴을 표현할 수 없음
- 필요성: 활성화 함수는 층마다 비선형성을 삽입해 깊은 표현 학습을 가능하게 함

---

## Ⅱ. 구조 및 구성요소

```text
입력 x -> 선형결합 z=Wx+b -> 활성화 a=f(z) -> 다음 층
                         +-> Sigmoid/Tanh: 포화형 출력
                         +-> ReLU/GELU: 은닉층 비선형
                         +-> Softmax: 다중분류 확률
```

| 구성요소 | 역할 | 수식·범위 |
|:---|:---|:---|
| Sigmoid | 이진 확률 출력 | 1/(1+e^-x), 0~1 |
| Tanh | 중심화 비선형 출력 | (e^x-e^-x)/(e^x+e^-x), -1~1 |
| ReLU | 은닉층 희소 활성 | max(0,x), 0~∞ |
| Softmax | 다중 클래스 확률화 | exp(z_i)/Σexp(z_j), 합 1 |

> 요약: 활성화 함수는 선형결합 뒤에 위치하며 출력 범위와 미분 특성에 따라 용도가 달라짐.

---

## Ⅲ. 동작원리 및 흐름도

```text
특징 입력 -> 가중합 계산 -> 활성화 함수 적용
      -> 손실 계산 -> 미분값 역전파 -> 가중치 갱신
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | z=Wx+b로 선형 출력 계산 | 텐서 차원 일치 |
| 2 | f(z)로 비선형 출력 생성 | 출력 범위 확인 |
| 3 | 손실 함수에서 오차 산출 | Cross-Entropy, MSE |
| 4 | f'(z)를 체인룰에 반영 | 기울기 0 또는 폭주 여부 |

> 요약: 순전파에서는 표현을 비선형화하고 역전파에서는 미분값으로 학습 신호 크기를 결정함.

---

## Ⅳ. 특징

| 구분 | Sigmoid/Tanh | ReLU 계열 | 수치 판단 |
|:---|:---|:---|:---|
| 출력 범위 | 0~1, -1~1 | 0~∞ 또는 근사 곡선 | 평균·분산 추적 |
| 기울기 | 포화 구간에서 0에 근접 | 양수 구간 기울기 1 | Gradient Norm |
| 적용 위치 | 출력층, 게이트 구조 | CNN/MLP 은닉층 | 손실 수렴 epoch |

> 요약: 은닉층은 ReLU 계열로 기울기 축소를 줄이고, 출력층은 문제 유형에 맞춰 Sigmoid·Softmax를 사용함.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존·대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | 선형층만 적층 | 선형결합 뒤 활성화 함수 삽입 | XOR·이미지 경계 등 비선형 패턴 |
| 비용/성능 | Sigmoid 은닉층 반복 | ReLU/GELU 은닉층 적용 | Gradient Norm 1e-6 미만이면 포화 의심 |
| 운영/위험 | 함수 선택을 경험값으로 고정 | 층 위치·출력 범위·손실 함수 조합 선택 | 이진 Sigmoid+BCE, 다중 Softmax+CE |

> 요약: 활성화 함수는 문제 유형과 층 위치에 따라 ReLU 계열, Sigmoid, Softmax를 구분 선택함.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 소실 기울기 | Sigmoid/Tanh 포화 구간 반복 | ReLU/GELU, BatchNorm, 잔차 연결 적용 | Gradient Norm 1e-6 이상 |
| Dead ReLU | 음수 입력 누적으로 출력 0 고착 | Leaky ReLU α=0.01, He 초기화 | 0 활성 뉴런 비율 30% 이하 |
| 출력-손실 불일치 | 회귀·분류별 출력 범위 오선택 | 회귀 선형, 이진 Sigmoid, 다중 Softmax 매핑 | Loss NaN/Inf 0건, 확률 합 1 |

> 요약: 주요 위험은 기울기 소실, ReLU 사멸, 출력층 조합 오류이며 기울기·활성값·손실 지표로 점검함.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 학습 신호 | Gradient Norm 1e-6~1e2, NaN/Inf 0건 | TensorBoard, 학습 로그 |
| 표현 분포 | 활성값 평균·분산 층별 기록, Dead ReLU 30% 이하 | Activation Histogram |
| 문제 적합성 | BCE·CE·MSE와 출력층 조합 일치 | 단위 테스트, 검증 손실 곡선 |

> 요약: 활성화 함수 도입 후 기울기 범위, 활성값 분포, 출력-손실 조합을 동시에 확인함.

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 은닉층 선택: CNN·MLP 기본은 ReLU/Leaky ReLU, 음수 입력 사멸률 30% 초과 시 Leaky ReLU α=0.01 적용
2. 출력층 선택: 이진 분류 Sigmoid+BCE, 다중분류 Softmax+Cross-Entropy, 회귀는 선형 출력+MSE 적용
3. 학습 점검: TensorBoard로 Gradient Norm, Dead ReLU 비율, 활성값 평균·분산을 epoch 단위 확인

**결론 (2줄):**
- 기술사 판단: 은닉층 표현 학습은 ReLU 계열, 확률 해석이 필요한 출력층은 Sigmoid·Softmax를 선택함
- 향후 방향: Transformer 계열은 GELU·SwiGLU와 Pre-LN 구조를 결합해 Gradient Norm 1e-6~1e2 범위로 관리함
