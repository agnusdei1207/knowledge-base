## Ⅰ. 개요

- **정의**: 활성화 함수는 신경망 각 층의 가중합 출력 `z = Wx + b`에 비선형 변환을 적용해 다음 층으로 전달하는 함수임.
- **배경/필요성**: 층을 아무리 쌓아도 각 층이 선형 변환(`Wx+b`)뿐이면 전체 신경망이 단일 선형 변환으로 붕괴함. 예컨대 2개 층을 합성하면 $W_2(W_1x+b_1)+b_2 = (W_2W_1)x + (W_2b_1+b_2)$로 정리되어 결국 1개 층의 아핀 변환과 동치이므로, 층 사이에 비선형 함수를 끼워 넣어야 표현력이 실제로 늘어남.
- **출제 의도**: 비선형성이 왜 필수인지에 대한 논증력, Sigmoid/Tanh/ReLU 등 각 함수의 수식·미분값 범위 이해도, 기울기 소실·Dying ReLU 등 학습 실패 패턴과 대응 기법 판단력을 확인함.
- **답안 방향**: 구조(대표 함수 수식과 역할) → 동작원리(신호 통과와 국소 기울기 특성) → 특징(함수별 미분 범위·연산비용) → 비교(은닉층/출력층 선택 기준) → 실무 적용 순으로 전개함.

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 비선형 함수의 필요성과 함수별 기울기 특성 설명 요구 | 선형 합성의 붕괴 증명, $\sigma'(z)$·ReLU $f'(z)$ 범위, 기울기 소실/Dying ReLU 메커니즘 | 비선형 필요성 논증 없이 함수 나열, 기울기 소실 원인을 수식 없이 뭉뚱그림 |

> 요약: 활성화 함수 답안은 "왜 비선형이 필요한가"를 먼저 증명하고, 그 위에서 함수별 미분값 범위가 기울기 소실·폭주에 미치는 영향을 논증해야 함.

## Ⅱ. 구조 및 구성요소

```text
입력(x1,x2,...,xn) -> 가중합 z=Wx+b(선형) -> 활성화 함수 f(z)(비선형) -> 출력 a -> 다음 층 입력

예: z=1.5일 때 함수별 출력
  Sigmoid: f(1.5) = 1/(1+e^-1.5) ≈ 0.818
  Tanh   : f(1.5) = tanh(1.5)    ≈ 0.905
  ReLU   : f(1.5) = max(0,1.5)   = 1.5
```

| 구성요소 | 역할 | 산출물/비유 |
|:---|:---|:---|
| 가중합 `z=Wx+b` | 이전 층 출력의 선형 결합 계산 | 활성화 함수에 넣을 원재료 수치 |
| Sigmoid $\sigma(z)=1/(1+e^{-z})$ | 출력을 $(0,1)$로 압축, 이진 확률 표현 | 게이트를 얼마나 열지 정하는 밸브 |
| Tanh $\tanh(z)$ | 출력을 $(-1,1)$로 압축, 0 중심 대칭 | Sigmoid를 원점 대칭으로 늘린 형태 |
| ReLU $f(z)=\max(0,z)$ | 음수는 차단(0), 양수는 그대로 통과 | 문턱 미달 신호를 끊는 차단기 |
| Softmax(출력층 전용) | 벡터를 합이 1인 확률분포로 정규화 | 득표수를 득표율로 환산 |

> 요약: 가중합이 만든 순수 숫자를 각 활성화 함수가 서로 다른 방식(압축/차단/정규화)으로 비선형 변환해 다음 층에 넘김.

## Ⅲ. 동작원리 및 흐름도

```text
입력 -> 선형결합(z=Wx+b) -> 활성화 함수 통과(a=f(z)) -> 다음 층 입력으로 전달
                                    |
                                    +-> 국소 기울기 f'(z) 계산·저장 (역전파 시 사용, 048 참조)
```

1. 선형 결합: 이전 층 출력에 가중치를 곱하고 편향을 더해 `z` 산출.
2. 비선형 변환: 활성화 함수 $f(z)$를 적용해 압축·차단·굴절된 출력 `a`를 생성함. 이 단계가 없으면 몇 층을 쌓든 하나의 아핀 변환과 동치가 되므로, 실제 비선형성은 이 단계에서만 발생함.
3. 국소 기울기 결정: $f'(z)$의 값 범위가 그 층의 기울기 전달 특성을 정함. Sigmoid는 $\sigma'(z)=\sigma(z)(1-\sigma(z))$로 최댓값이 0.25이고 $|z|$가 크면 0에 수렴함. ReLU는 $z>0$일 때 $f'(z)=1$, $z\le0$일 때 $f'(z)=0$.
4. 누적 특성: 여러 층을 거치며 국소 기울기가 곱해지는 방식이므로(구체적 곱셈 과정은 048 역전파 참조), 1 미만 값이 층마다 곱해지면 기울기가 지수적으로 0에 수렴하는 기울기 소실이, 1보다 큰 값이 반복 곱해지면 기울기 폭주가 발생함.

> 요약: 활성화 함수를 통과할 때마다 국소 기울기 $f'(z)$가 결정되고, 이 값이 층 수만큼 곱해지는 구조 때문에 함수 선택이 기울기 소실·폭주를 좌우함.

## Ⅳ. 특징

- 기울기 소실 위험: Sigmoid/Tanh는 $|z|$가 크면 $f'(z)$가 0에 근접해, 10개 층만 거쳐도 $0.25^{10}\approx1.0\times10^{-6}$ 수준으로 신호가 소멸함.
- 연산 비용: Sigmoid/Tanh/GELU는 지수 함수($e^{-z}$) 연산이 필요하나, ReLU는 `max(0,z)` 비교 연산만 필요해 대규모 모델에서 연산 비용이 낮음.
- Dying ReLU: 큰 학습률 등으로 가중치가 $z\le0$ 영역에 고정되면 $f'(z)=0$이 되어 해당 뉴런이 영구히 갱신되지 않음. Leaky ReLU·PReLU·ELU는 음수 영역에도 미세한 기울기를 남겨 이를 완화함.
- 출력층 전용 역할: Sigmoid(이진 확률)·Softmax(다중클래스 확률분포)는 은닉층 비선형 변환과 달리 결과를 확률로 해석 가능하게 만드는 역할이므로 은닉층 함수와 목적이 다름.

> 요약: 은닉층 선택은 기울기 소실·연산비용·Dying 위험의 트레이드오프이고, 출력층 선택은 확률 해석 요구가 기준임.

## Ⅴ. 심화 비교 및 적용 판단

| 판단 기준 | Sigmoid/Tanh | ReLU | GELU/Swish | 선택 기준 |
|:---|:---|:---|:---|:---|
| 미분값 범위 | 최댓값 0.25(Sigmoid), 0 근접 구간 넓음 | $z>0$에서 항상 1, $z\le0$에서 0 | 0 부근에서 매끄럽게 변화, 음수도 소량 통과 | 은닉층은 미분값이 안정적인 ReLU 계열을 우선 채택 |
| 기울기 소실/Dying 위험 | 깊은 망에서 소실 심각 | 소실은 없으나 Dying ReLU 발생 가능 | 소실·Dying 모두 완화 | 20층 이상 심층망은 Sigmoid/Tanh를 은닉층에서 배제 |
| 연산 비용 | 지수 함수 필요 | 비교 연산만 필요(경량) | 지수·오차함수 근사 필요(무거움) | GPU 자원이 제약되면 ReLU 우선 |
| 주 사용처 | 이진분류 출력층, LSTM/GRU 게이트 | CNN/MLP 은닉층 기본값 | Transformer(GPT 등) 은닉층 | 출력층은 문제 유형(이진/다중분류)별로 별도 고정 |

> 요약: 은닉층은 계산 비용과 기울기 소실 위험을 함께 낮추는 함수를 고르고, 출력층은 문제 유형이 요구하는 확률 형태를 기준으로 별도 선택함.

**리스크·대응 (불릿):**
- 기울기 소실: 깊은 망에 Sigmoid/Tanh를 은닉층으로 적층한 것이 원인 → 은닉층을 ReLU 계열로 교체하고 배치 정규화 병행 (지표: 층별 기울기 norm)
- Dying ReLU: 과도한 학습률로 가중치가 음수 영역에 고정된 것이 원인 → Leaky ReLU 적용 또는 학습률 하향 (지표: 활성값이 0인 뉴런 비율)
- 출력층 오선택: 다중클래스 문제에 Sigmoid를 그대로 쓴 것이 원인 → Softmax로 교체하고 손실 함수도 함께 정합성 점검 (지표: 클래스별 확률 합이 1인지 검증)

**도입 후 점검 지표 (불릿):**
- 학습 안정성: 층별 기울기 norm이 하위층까지 소실 없이 유효 범위를 유지하는지 확인
- 뉴런 활성 비율: ReLU 계열 적용 후 활성값이 0으로 고정된 뉴런 비율이 임계치(예: 30%) 이하인지 확인

## Ⅵ. 실무 적용 및 결론

1. 단기: 은닉층 활성화 함수를 ReLU 계열로 표준화하고 Sigmoid/Tanh 사용처를 출력층·게이트로 한정함.
2. 중기: 심층 CNN·Transformer 아키텍처에는 GELU/Swish 등 매끄러운 변형을 적용해 기울기 흐름을 개선함.
3. 장기: 활성화 함수 선택을 하이퍼파라미터 탐색 파이프라인에 포함해 데이터·아키텍처별 최적 함수를 자동 결정함.

- 기술사적 판단: 은닉층은 연산비용과 기울기 소실 위험을 함께 낮추는 ReLU 계열을 기본값으로 채택하고, 출력층은 문제 유형에 맞는 함수로 별도 고정함.
- 기술사 제언: 활성화 함수 교체만으로 학습이 불안정하면 초기화 전략·배치 정규화까지 함께 점검해야 함(역전파 세부 과정은 048 참조).
