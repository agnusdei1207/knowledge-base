## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 각 노드에 색상(Red/Black) 속성을 부여하고 특정 규칙을 강제하여 근사적으로 균형을 유지하는 이진 탐색 트리임 |
| **배경/필요성** | AVL 트리의 과도한 회전 연산 오버헤드를 줄이면서도 O(log N) 탐색 성능을 보장하기 위해 고안됨 |
| **출제 의도** | 레드-블랙 속성(5가지 규칙)을 이해하고, 색상 변환과 회전을 통한 트리 균형 조정 역량을 평가함 |

## Ⅱ. 구성요소
+-------------------+      +-------------------+
|       색상 속성       | ---> |     연속 Red 금지     |
+-------------------+      +-------------------+
           |                         |
           v                         v
+-------------------+      +-------------------+
|  Black-Height 보장  | <--- |   Core Mechanism  |
+-------------------+      +-------------------+

| 구성요소 | 설명 | 비유 |
|---|---|---|
| 색상 속성 | 모든 노드는 Red 또는 Black 중 하나의 색상을 가짐 | 신호등의 정지/주의 표시 |
| 연속 Red 금지 | Red 노드의 자식은 반드시 Black이어야 함 (Double Red 불가) | 동일 등급 팀원 연속 배치 불가 |
| Black-Height 보장 | 루트에서 리프까지 경로상 Black 노드 수는 모두 동일함 | 모든 경로의 검문소 개수 동일 |

> 요약: 레드-블랙 트리는 색상 속성을 부여하고, 연속 Red 금지 및 Black-Height 일치 규칙으로 균형을 제어함.

## Ⅲ. 절차
+-------------------+      +-------------------+
|      Step 1       | ---> |      Step 2       |
+-------------------+      +-------------------+
                                     |
+-------------------+      +---------+---------+
|      Step 4       | <--- |      Step 3       |
+-------------------+      +-------------------+

1. 신규 삽입: 새 노드를 Red 색상으로 트리의 적절한 리프 위치에 추가
2. 규칙 위반 체크: 부모도 Red일 경우 Double Red 규칙 위반 발생 확인
3. 삼촌 노드 확인: 부모의 형제(삼촌) 노드 색상을 검사하여 해결책 분기
4. Recoloring / Restructuring: 색상만 바꾸거나(Recoloring), 트리를 회전(Restructuring)하여 균형 복구

> 요약: 새 노드 Red 삽입, 규칙 위반 확인, 삼촌 노드 색상 판별, 재색칠 혹은 회전을 통해 복구함.

## Ⅳ. 문제점
- 구현 난이도 극상: 규칙이 복잡하고 예외 케이스(LL, LR 등) 처리가 많아 코드 버그 발생 위험 높음
- 완전한 균형 미달: AVL 대비 균형이 다소 느슨하여 최악의 탐색 시 상수 시간만큼 더 느림
- 디스크 접근 한계: 이진 트리 특성상 노드가 물리적으로 분산되어 RDBMS 등 디스크 환경엔 부적합

## Ⅴ. 개선방안
- (단기) 검증된 라이브러리 활용: 직접 구현을 피하고 C++ std::map이나 Java TreeMap 등 내장 컨테이너 사용
- (중기) 사용 도메인 명확화: 삽입/삭제가 잦은 메모리 내부(In-Memory) 스케줄링(CFS)과 맵 자료구조에 집중 적용
- (장기) 락 프리(Lock-free) RB 트리: 멀티스레드 환경에서 병목을 줄이기 위한 동시성 제어 트리로 고도화

## Ⅵ. 전망
- Linux 커널의 Completely Fair Scheduler(CFS) 등 핵심 시스템 소프트웨어 자료구조로 독보적 위치를 고수함
