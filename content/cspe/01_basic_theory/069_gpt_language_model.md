## Ⅰ. 개요
- **정의**: Transformer 디코더를 적층하여 이전 토큰만 참조하며 다음 토큰을 순차 생성하는 자기 회귀 언어 모델
- **배경/필요성**: 068 BERT는 양방향 이해에 특화되나 텍스트 생성이 불가하여, 대화·요약·코드 생성 등 NLG 수요를 충족 못함
- **비유**: 앞 문장만 읽고 다음 문장을 이어 쓰는 작가 — 뒤를 미리 보지 않고 순차 집필

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 자기 회귀 생성 원리 | 인과적 마스킹으로 미래 토큰 차단 | 068 BERT(양방향 인코더)와 혼동 시 감점 |

> 요약: Transformer 디코더 기반 자기 회귀 모델로, 프롬프트 입력에 따라 텍스트를 순차 생성하는 NLG 핵심 아키텍처임.

## Ⅱ. 구성요소
```text
+----------+   +--------------+   +----------+
| Prompt + |-->| Transformer  |-->| LM Head  |
| Position |   | Decoder x N  |   | (Softmax)|
+----------+   +------+-------+   +----------+
                      |
               +------+------+
               |             |
          +----+----+  +-----+---+
          |Masked   |  |Feed-Fwd |
          |Self-Att |  |Network  |
          +---------+  +---------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| Masked Self-Attention | 현재 위치 이후 토큰을 삼각 마스크로 차단하여 좌->우만 참조 | 블라인드 커튼 |
| Feed-Forward Network | 어텐션 출력을 비선형 변환 (068 BERT와 동일 구조, 방향성만 차이) | 정보 변환기 |
| LM Head | 어휘 사전 크기의 로짓을 출력하고 소프트맥스로 다음 토큰 확률 산출 | 선택지 채점 |

> 요약: 인과적 마스킹 어텐션으로 좌->우 문맥만 활용하여 다음 토큰 확률을 순차 산출함.

## Ⅲ. 절차
```text
+----------+   +----------+   +----------+   +----------+
| Prompt   |-->| Masked   |-->| Next Tok |-->| Iterate  |
|          |   | Att + FFN|   | Predict  |   | until EOS|
+----------+   +----------+   +----------+   +----------+
```

1. **프롬프트 입력** — 사용자 지시문을 토큰화하여 초기 시퀀스로 구성
2. **인과적 어텐션** — 삼각 마스크 적용, 현재 위치까지의 토큰만으로 셀프 어텐션 수행
3. **다음 토큰 예측** — LM Head에서 어휘 전체에 대한 확률 분포를 산출, Top-K/Top-P 샘플링
4. **반복 생성** — 예측 토큰을 시퀀스에 추가하고 EOS 또는 최대 길이까지 2~3단계 반복

> 요약: 프롬프트로부터 인과적 어텐션->토큰 예측->시퀀스 확장을 EOS까지 반복하는 자기 회귀 루프임.

## Ⅳ. 문제점
- **환각(Hallucination)**: 학습 분포 밖 질문에 대해 사실이 아닌 내용을 유창하게 생성 — 의료·법률 도메인에서 치명적
- **정렬(Alignment) 부재**: 사전학습만으로는 윤리·안전 기준 미충족, 유해·편향 텍스트 생성 위험
- **추론 비용 과다**: GPT-4 기준 파라미터 추정 1.7T, 단일 추론에 GPU 수백 장 필요

> 요약: 환각·정렬 부재·추론 비용이 대규모 GPT 운영의 3대 과제임.

## Ⅴ. 개선방안
1. 단기: RAG(검색 증강 생성)로 외부 지식 DB를 참조하여 환각 발생률 감소 (지표: FaithfulScore > 0.9)
2. 중기: RLHF(인간 피드백 강화학습) + Constitutional AI로 안전 정렬 강화
3. 장기: MoE(Mixture of Experts) 아키텍처 + LoRA/QLoRA 경량 파인튜닝으로 추론 비용 1/10 절감

- **환각**: 내부 지식 한계 -> RAG + 팩트 체크 파이프라인 (지표: Hallucination Rate < 5%)
- **정렬 부재**: 사전학습 편향 -> RLHF 보상 모델 적용 (지표: ToxiGen 유해성 < 1%)
- **추론 비용**: 파라미터 비대 -> MoE 활성 파라미터 제한 (지표: Token/s per GPU)

> 요약: RAG·RLHF·MoE로 환각·정렬·비용 문제에 각각 대응함.

## Ⅵ. 전망
- 향후 발전 방향: 멀티모달(텍스트+이미지+오디오) 통합 생성, 에이전트형 자율 실행 아키텍처로 확장
- 기술사적 판단: 068 BERT가 NLU 표준이라면 GPT 계열은 NLG 표준으로 양분 — 태스크별 선택이 핵심
- 기술사 제언: GPT 도입 시 RAG + 가드레일 + 비용 모니터링을 3대 필수 요소로 설계하고, 단순 분류 태스크에는 BERT 계열 우선 검토를 권고함
