# 069. GPT 언어 모델 (GPT Language Model) [출제: 124, 127회]

## Ⅰ. 개요

- **정의/개념**: 트랜스포머(Transformer)의 디코더 구조를 기반으로, 이전의 토큰(Token)들로부터 다음 토큰이 나타날 확률을 예측하도록 사전 학습된 자기회귀(Autoregressive) 생성 언어 모델임
- **배경/필요성**: 대규모 텍스트 데이터로부터 범용적인 언어 패턴을 학습하여, 특정 과제에 대한 미세 조정 없이도 질문 답변, 요약, 번역, 코드 생성 등 광범위한 생성형 AI 태스크를 수행하기 위해 필요함

## Ⅱ. 특징 및 비교

| 판단 기준 | BERT (Bidirectional Encoder) | GPT (Generative Pre-trained) | T5 (Text-to-Text Transfer) |
|:---|:---|:---|:---|
| **모델 구조** | Transformer Encoder | Transformer Decoder | Encoder-Decoder |
| **학습 방식** | 빈칸 채우기 (MLM) | 다음 단어 예측 (Causal LM) | 텍스트 입력-텍스트 출력 |
| **문맥 방향** | 양방향 (Bidirectional) | 단방향 (Left-to-Right) | 양방향(Enc) + 단방향(Dec) |
| **주요 강점** | 텍스트 이해, 분류, NER | 문장 생성, 대화, 창작 | 요약, 번역, 멀티 태스크 |

> 요약: GPT는 이전 문맥을 바탕으로 다음 내용을 생성하는 능력이 탁월하며, 모델 규모(Scaling)를 통해 범용 추론 능력을 확보함

## Ⅲ. 구성요소/구조

- **구성요소**:
  - **Masked Self-Attention**: 현재 시점 이후의 단어를 보지 못하도록 마스킹하여, 오직 과거의 정보로만 다음 단어를 예측하게 함
  - **Few-shot / Zero-shot Learning**: 별도의 파라미터 업데이트 없이 프롬프트(Prompt) 예시만으로 새로운 과제를 수행함
  - **RLHF (Reinforcement Learning from Human Feedback)**: 사람의 피드백을 반영해 모델의 답변이 유익하고 안전하도록 정렬(Alignment)함
  - **In-context Learning**: 입력 프롬프트 내에 포함된 정보를 바탕으로 즉석에서 학습하고 추론함

- **자기회귀(Autoregressive) 생성 구조**:
```text
[입력 프롬프트] -> [GPT Decoder Stack] -> [다음 토큰 확률 분포] -> [토큰 선택(Sampling)]
      |                                                                 |
      +-----------------------------------------------------------------+
                         (선택된 토큰을 다시 입력에 추가하여 반복)

예시: "오늘" -> [GPT] -> "날씨는" -> [GPT] -> "정말" -> [GPT] -> "좋다"
```

## Ⅳ. 문제점 및 개선방안

1. **[할루시네이션 (Hallucination)]**: 사실이 아니거나 논리적으로 맞지 않는 내용을 그럴듯하게 생성하는 '환각' 현상 발생
   - **개선방안**: 검색 증강 생성(RAG)을 통해 외부 신뢰 데이터를 참조하게 하거나, 사고의 사슬(CoT) 기법을 사용하여 논리적 단계를 밟게 함 (확인: 사실성 지표)
2. **[보안 및 개인정보 유출]**: 학습 데이터나 입력 프롬프트에 포함된 민감 정보가 생성 결과물에 노출될 위험이 있음
   - **개선방안**: 입력 필터링 및 출력 모니터링 시스템을 구축하고, 기업용 프라이빗 LLM을 도입함 (확인: DLP/DPI 필터링)
3. **[높은 추론 비용 및 지연]**: 모델이 비대해짐에 따라 토큰 생성당 연산 비용이 높고 실시간 응답성이 저하됨
   - **개선방안**: 모델 양자화(FP16 -> INT8/4), KV 캐싱 최적화, 지식 증류를 통한 소형 모델(SLM) 구축을 수행함 (확인: TPS (Tokens Per Second))

## Ⅴ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| **고객 응대 (Chatbot)** | RAG 기술과 결합하여 기업 내부 매뉴얼 기반의 정확한 상담 서비스 제공 | CS 만족도, 상담 완결률 |
| **코드 생성 (Copilot)** | 개발 요구사항을 자연어로 입력하면 해당 언어의 코드 초안 및 테스트 케이스 생성 | 개발 생산성 향상도, 결함 밀도 |
| **문서 요약 및 추출** | 대량의 법률/금융 문서를 핵심 요약하거나 특정 조건의 데이터를 추출 | 요약 정확도, 작업 소요 시간 |

> 요약: 실무에서는 모델의 단순 생성 능력보다 프롬프트 엔지니어링과 외부 도구 연결(Tool-use) 능력이 중요하게 다뤄짐

## Ⅵ. 결론

GPT 모델은 인공지능이 '이해'를 넘어 '생성'과 '추론'의 단계로 도약하게 한 파운데이션 모델(Foundation Model)임. 환각 현상이나 보안 등 운영 측면의 과제가 남아있으나, RAG와 같은 아키텍처적 보완과 RLHF를 통한 인간 가치 정렬을 통해 기업의 생산성을 혁신하는 도구로 정착하고 있으며, 향후 멀티모달(Multimodal) 역량 강화와 에이전트(Agentic Workflow)로서의 발전이 기대됨.
