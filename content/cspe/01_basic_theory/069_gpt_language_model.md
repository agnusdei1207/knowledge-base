## 미리 알고가기

- 자기회귀: 이미 생성한 토큰을 입력에 추가해 다음 토큰을 예측하는 방식임
- 트랜스포머 디코더: 이전 토큰만 보며 다음 토큰을 생성하는 구조임
- 인과 마스크: 미래 토큰을 보지 못하도록 어텐션을 제한하는 장치임
- 프롬프트: 모델에 작업 목적과 입력 조건을 전달하는 자연어 지시문임
- 컨텍스트 윈도우: 한 번에 참조하는 토큰 범위임
- RAG (Retrieval-Augmented Generation): 외부 지식을 검색해 생성 입력에 추가하는 방식임
- 디코딩 전략: 다음 토큰 확률에서 탐욕·빔 탐색·확률 샘플링으로 출력 토큰을 선택하는 방식임

## 작성 근거(검토용)

- 개요는 GPT를 디코더 기반 자기회귀 모델로 정의해 구조와 동작 원리를 동시에 제시함
- 생성·인과 마스크·프롬프트 적응·확률적 한계는 GPT의 핵심 판단축임
- Ⅲ은 BERT와 Encoder-Decoder의 구조·학습 목표·대표 적용 사례를 비교해 GPT의 순차 생성 구조를 드러냄
- Ⅳ는 토큰화부터 디코딩까지 생성 루프에 필요한 정적 구성요소를 배치함
- 환각과 토큰 비용은 RAG 대응과 운영 지표를 요구하는 핵심 위험임

## Ⅰ. 개요

- **정의/개념**: GPT는 트랜스포머 디코더 기반 자기회귀 언어 모델로, 이전 문맥을 바탕으로 다음 토큰을 반복 예측해 텍스트를 생성함
- **배경/필요성**: 다양한 자연어 업무를 지시문과 예시로 처리하기 위해 사전학습 생성 모델이 필요함

## Ⅱ. 특징

- 다음 토큰 예측을 반복해 문장을 생성함
- 인과 마스크로 순방향 문맥만 사용함
- 모델 매개변수를 바꾸지 않고 컨텍스트 윈도우의 지시와 예시를 작업 조건으로 사용함
- 생성 결과가 확률적이라 사실 검증과 출력 통제가 필요함

## Ⅲ. 종류 및 비교

| 판단 기준 | BERT 계열 | GPT 계열 | Encoder-Decoder 계열 |
|:---|:---|:---|:---|
| 구조·문맥 방향 | 인코더로 전체 문맥을 양방향 처리 | 디코더로 이전 문맥을 단방향 처리 | 인코더가 입력 전체를 읽고 디코더가 출력을 순차 생성 |
| 학습 목표 | 마스크 토큰 복원 | 다음 토큰 예측 | 입력을 출력 시퀀스로 변환 |
| 대표 적용 사례 | 검색 의도·문서 분류 | 대화·문서·코드 생성 | 번역·요약·음성 인식 |
| 핵심 제약 | 생성 과제에 직접 사용하기 어려움 | 생성 사실성과 토큰 비용을 검증해야 함 | 인코더·디코더를 각각 학습·운영해야 함 |

> 요약: GPT는 이전 토큰을 바탕으로 다음 토큰을 생성하므로 문서 작성·대화·코드 생성과 프롬프트 기반 작업에 적합함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 토크나이저 | 프롬프트를 토큰 ID로 변환함 |
| 토큰·위치 임베딩 | 단어 의미와 순서 정보를 입력함 |
| 디코더 블록 | 마스크드 셀프 어텐션과 피드포워드 계층으로 이전 문맥을 처리함 |
| 출력 소프트맥스 | 다음 토큰 확률 분포를 계산함 |
| 디코딩 전략 | 탐욕·빔 탐색·확률 샘플링으로 토큰을 선택함 |

> 요약: GPT 생성은 토큰화, 인과 어텐션, 소프트맥스, 디코딩 전략의 반복 구조임.

## Ⅴ. 원리 및 절차 흐름도

```text
프롬프트 -> 토큰화 -> 인과 어텐션 -> 다음 토큰 분포 -> 디코딩 -> 반복
```

1. 프롬프트를 토큰 ID와 위치 정보로 변환함
2. 디코더 블록이 이전 토큰 관계만 어텐션으로 계산함
3. 출력층이 다음 토큰 후보의 확률 분포를 산출함
4. 선택된 토큰을 문맥에 붙이고 종료 조건까지 반복함

> 요약: GPT는 이전 토큰만 보는 인과 어텐션으로 다음 토큰을 반복 선택해 문장을 생성함.

## Ⅵ. 실무 사례

1. 지식 질의응답은 GPT에 RAG·출처 검증을 결합하고 정답률·근거 일치율로 검증함
2. 대화 서비스는 이력 요약·캐싱·입력 축소를 적용하고 토큰 사용량·p95 지연으로 검증함

## Ⅶ. 결론

- GPT는 자기회귀 방식으로 텍스트를 생성하며, 사실성 검증과 토큰 비용 통제가 실무 적용 조건임
