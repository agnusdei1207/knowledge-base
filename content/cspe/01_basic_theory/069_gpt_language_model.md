## Ⅰ. 개요
- 정의: 트랜스포머의 디코더 구조를 기반으로 다음 단어를 예측하는 생성형 언어 모델임.
- 배경: 대규모 데이터를 통한 비지도 학습으로 인간 수준의 문장 생성을 목표로 함.
- 출제 의도:
| 분류 | 상세 |
| --- | --- |
| 핵심요소 | Transformer Decoder, Autoregressive, Few-shot |
| 주요특징 | 생성 능력 우수, 대규모 파라미터, 인컨텍스트 러닝 |

## Ⅱ. 구성요소
- ASCII 구조도
 [Token] -> [Decoder] -> [Next Token]
               ^ (Masked Self-Attention)
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 디코더 | 이전 단어들을 참조하여 다음 단어를 생성 | 이야기꾼 |
| 자기회귀 | 자신의 출력을 다음 입력으로 다시 사용하는 방식 | 꼬리 물기 |
| 프롬프트 | 모델에 지시를 내리는 입력 문구 | 작업 지시서 |
> 요약: 문맥에 기반하여 확률적으로 가장 적절한 다음 토큰을 생성함.

## Ⅲ. 절차
- ASCII 흐름도
[프롬프트 입력] -> [문맥 임베딩] -> [순차적 생성] -> [텍스트 출력]
- 4단계 설명
1. 입력 처리: 텍스트를 토큰화하고 위치 인코딩을 추가함.
2. 어텐션 연산: 이전 토큰들과의 관계를 계산하여 가중치를 부여함.
3. 확률 분포 산출: 소프트맥스 함수를 통해 다음 단어 후보를 결정함.
4. 반복 생성: 종결 토큰이 나올 때까지 위 과정을 반복함.
> 요약: 입력된 맥락을 유지하며 한 단어씩 이어서 문장을 완성함.

## Ⅳ. 문제점
- 사실이 아닌 내용을 그럴듯하게 답하는 환각(Hallucination) 현상이 발생함.

## Ⅴ. 개선방안
- 단기: RLHF(인간 피드백 기반 강화학습)를 통해 답변 품질을 교정함.
- 중기: RAG(검색 증강 생성)를 도입하여 외부 지식을 실시간 참조함.
- 장기: 모델의 추론 과정을 검증하는 가드레일 시스템을 구축함.

## Ⅵ. 전망
- 할루시네이션(Hallucination) 제어를 위한 RAG 기술과의 결합이 필수적이며, 향후 멀티모달 추론 능력을 갖춘 AGI 지향적 아키텍처 및 자율적 작업 수행을 위한 에이전트(Agentic) 워크플로우의 핵심 엔진으로 진화할 전망임.
- 모델의 거대화보다는 특정 도메인에 최적화된 sLLM(소형언어모델) 개발과 프롬프트 엔지니어링의 표준화가 실무적 성공 요인으로 부각될 것임.
