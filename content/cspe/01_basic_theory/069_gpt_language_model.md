## 미리 알고가기

- 자기회귀: 이미 생성한 토큰을 입력에 붙여 다음 토큰을 예측하는 방식임
- 트랜스포머 디코더: 이전 토큰만 보며 다음 토큰을 생성하는 구조임
- 인과 마스크: 미래 토큰을 보지 못하도록 어텐션을 제한하는 장치임
- 프롬프트: 모델에 작업 목적과 입력 조건을 전달하는 자연어 지시문임
- 컨텍스트 윈도우: 한 번에 참조하는 토큰 범위임
- RAG: 외부 지식을 검색해 생성 입력에 넣는 방식임

## Ⅰ. 개요

- **정의/개념**: GPT는 트랜스포머 디코더 기반 자기회귀 언어 모델로, 이전 문맥을 바탕으로 다음 토큰을 반복 예측해 텍스트를 생성함
- **배경/필요성**: 다양한 자연어 업무를 별도 모델 없이 지시문과 예시만으로 처리하려면 대규모 사전학습 생성 모델이 필요함

## Ⅱ. 특징

- 다음 토큰 예측을 반복해 문장을 생성함
- 인과 마스크로 순방향 문맥만 사용함
- 프롬프트와 예시만으로 새 작업에 적응함
- 생성 결과가 확률적이라 사실 검증과 통제가 필요함

## Ⅲ. 종류 및 비교

| 구분 | BERT 계열 | GPT 계열 | Encoder-Decoder 계열 |
|:---|:---|:---|:---|
| 구조 | 인코더 중심 | 디코더 중심 | 인코더와 디코더 결합 |
| 학습 목표 | 마스크 토큰 복원 | 다음 토큰 예측 | 입력을 출력 시퀀스로 변환 |
| 강점 | 문장 이해·분류 | 대화·작성·코드 생성 | 번역·요약 등 변환 |
| 입력 처리 | 전체 문맥 양방향 | 이전 문맥 단방향 | 입력 전체와 출력 순차 |
| 주의점 | 생성 능력 제한 | 환각과 비용 | 구조가 상대적으로 복잡 |

> 요약: GPT는 인코더 이해보다 순차 생성과 프롬프트 기반 작업 처리에 적합함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 토크나이저 | 프롬프트를 토큰 ID로 변환함 |
| 토큰·위치 임베딩 | 단어 의미와 순서 정보를 입력함 |
| 마스크드 셀프 어텐션 | 미래 토큰을 차단하고 이전 문맥만 참조함 |
| 피드포워드 계층 | 어텐션 결과를 비선형 특징으로 변환함 |
| 출력 소프트맥스 | 다음 토큰 확률 분포를 계산함 |
| 디코딩 전략 | greedy, beam, sampling으로 토큰을 선택함 |

> 요약: GPT 생성은 토큰화, 인과 어텐션, 소프트맥스, 디코딩 전략의 반복 구조임.

```text
Prompt tokens
  -> Decoder blocks with causal mask
  -> Next-token probability
  -> Select token
  -> Append token and repeat
```

## Ⅴ. 원리 및 절차 흐름도

```text
Prompt -> Tokenize -> Causal attention -> Next-token distribution -> Decode -> Repeat
```

1. 프롬프트를 토큰 ID와 위치 정보로 변환함
2. 디코더 블록이 이전 토큰 관계만 어텐션으로 계산함
3. 출력층이 다음 토큰 후보의 확률 분포를 산출함
4. 선택된 토큰을 문맥에 붙이고 종료 조건까지 반복함

## Ⅵ. 실무 적용 및 유의점

1. 지식 질의응답에 GPT를 쓰면 환각 위험이 있으므로 RAG와 출처 검증을 결합하고 정답률과 근거 일치율을 측정함
2. 긴 프롬프트는 비용과 지연을 키우므로 대화 이력 요약, 캐싱, 입력 최소화를 적용하고 토큰 사용량을 관리함

## Ⅶ. 결론

- GPT는 범용 생성 능력이 강한 자기회귀 모델이며, 사실성 검증과 토큰 비용 통제가 실무 적용의 핵심 조건임

## 작성 근거(검토용)

- 개요는 GPT를 디코더 기반 자기회귀 모델로 정의해 구조와 동작 원리를 동시에 제시함
- 특징은 생성, 인과 마스크, 프롬프트 적응, 확률적 한계를 GPT 판단 축으로 선정함
- Ⅲ은 BERT와 Encoder-Decoder를 비교해 GPT가 이해보다 생성에 강한 이유를 보이게 함
- Ⅳ는 토큰화부터 디코딩까지 생성 루프에 필요한 정적 구성요소를 배치함
- Ⅵ은 환각과 토큰 비용을 실무 리스크로 두어 RAG와 운영 지표를 연결함
