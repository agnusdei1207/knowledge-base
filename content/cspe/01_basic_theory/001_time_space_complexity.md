## Ⅰ. 개요
- 알고리즘이 수행되는 데 필요한 자원(시간, 메모리)의 양을 나타내는 척도임.
- 입력 크기(n)에 따른 효율성을 객관적으로 평가하기 위해 사용함.
- [표] 출제 의도: 알고리즘 성능 평가 기초 역량 및 최적화 능력 검증.

## Ⅱ. 구성요소
- ASCII 구조도
  +---------------------------------------+
  | [ Complexity ]                        |
  |  - Time Complexity: Ops Count         |
  |  - Space Complexity: Memory Usage     |
  +---------------------------------------+

| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| 시간복잡도 | 연산 횟수의 총합 (Worst/Average) | 작업 완료 시간 |
| 공간복잡도 | 알고리즘 실행 시 메모리 필요량 | 작업대 크기 |
| 입력 크기(n) | 데이터의 양 또는 노드의 개수 | 짐의 개수 |

> 요약: 자원 효율성을 정량화하여 알고리즘 선택의 기준을 제공함.

## Ⅲ. 절차
- ASCII 흐름도
  Problem -> Operation Check -> Count n -> Asymptotic Analysis

1. 알고리즘 로직 및 기본 연산(비교, 대입) 식별함.
2. 입력 크기 n에 따른 연산 횟수와 메모리 할당량을 수식화함.
3. 가장 영향력이 큰 최고차항을 추출함.
4. 점근적 표기법(Big-O)으로 복잡도를 확정함.

> 요약: 분석 단계를 거쳐 성능 한계치를 도출하고 최적화를 수행함.

## Ⅳ. 문제점
- 시간 최적화 시 메모리 사용량이 급증하는 트레이드오프(Trade-off) 발생함.
- 상수항과 계수가 무시되어 실제 소요 시간과 괴리가 생길 수 있음.

## Ⅴ. 개선방안
- 단기: 가용 메모리 범위를 고려한 알고리즘 선별 및 벤치마킹 실시함.
- 중기: 동적 프로그래밍 등을 통한 중복 연산 제거로 시간 절약함.
- 장기: 하이브리드 구조 도입으로 시간과 공간의 균형점 확보함.

## Ⅵ. 전망
- 양자 컴퓨팅 시대를 대비한 BQP(Bounded-error Quantum Polynomial time) 클래스 기반의 새로운 복잡도 분석 체계가 정립될 것임.
- 실무적으로는 프로파일링 기반 최적화(PGO)를 통해 실제 런타임 데이터에 근거한 동적 복잡도 관리가 하이퍼스케일 서비스의 핵심 성공 요인(CSF)이 될 것임.
- 하드웨어 가속기(GPU, NPU)의 메모리 계층 구조를 고려한 캐시 효율적(Cache-aware) 알고리즘 설계가 복잡도 최적화의 주류가 될 전망임.
