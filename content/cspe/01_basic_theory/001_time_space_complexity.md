## Ⅰ. 개요
- **정의**: 알고리즘이 입력 크기 `n`에 대해 소비하는 연산 횟수와 메모리 양을 함수로 표현한 척도
- **배경/필요성**: 동일 문제를 푸는 알고리즘이 여럿일 때, 자원 소비량을 객관적으로 비교할 기준이 필요함
- **비유**: 같은 목적지까지 가는 여러 경로의 소요 시간(시간 복잡도)과 연료비(공간 복잡도)를 비교하는 것과 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 알고리즘 분석 능력 확인 | 시간=연산 횟수, 공간=메모리 사용량 구분 | 점근적 표기법(002 참조)과 혼동하지 않을 것 |

> 요약: 알고리즘의 자원 소비량을 입력 크기의 함수로 정량화하는 분석 기법임

## Ⅱ. 구성요소
```text
        +--- 시간 복잡도 --- 기본 연산 횟수
        |
  복잡도 분석 --+--- 공간 복잡도 --- 고정 공간 + 가변 공간
        |
        +--- 입력 크기 n --- 분석의 독립변수
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 시간 복잡도 | 입력 `n`에 대해 기본 연산이 수행되는 횟수를 함수 `T(n)`으로 표현 | 요리 레시피의 총 조리 시간 |
| 공간 복잡도 | 알고리즘 실행에 필요한 메모리 총량을 함수 `S(n)`으로 표현 | 조리에 필요한 조리대 넓이 |
| 고정 공간 | 입력 크기와 무관하게 상수로 소비되는 메모리(코드, 상수 변수 등) | 기본 주방 기구 |
| 가변 공간 | 입력 크기에 비례하여 증가하는 메모리(재귀 스택, 임시 배열 등) | 재료 수에 따라 늘어나는 그릇 |
| 입력 크기 `n` | 문제 규모를 나타내는 독립변수(배열 길이, 그래프 정점 수 등) | 손님 수 |

> 요약: 시간·공간 복잡도는 입력 크기 `n`을 독립변수로 연산 횟수와 메모리 사용량을 정량화한 것임

## Ⅲ. 절차
```text
  입력 모델 정의     기본 연산 식별     반복 횟수 산출     점근적 표기
  (n 결정)          (비교/대입 등)    (루프/재귀 분석)   (상한 함수 도출)
   |                 |                 |                 |
   +----정의-------->+----식별-------->+----계산-------->+
  배열 길이 등      핵심 연산 선택    최악/최선/평균     O, Omega, Theta
```
- 1단계: 입력 크기 `n`을 정의함 — 배열 길이, 정점 수 등 문제 규모를 결정
- 2단계: 기본 연산을 식별함 — 비교, 대입, 산술 중 지배적 연산을 선택
- 3단계: 반복 횟수를 산출함 — 루프 중첩 깊이, 재귀 호출 트리를 분석하여 `T(n)` 도출
- 4단계: 점근적 표기로 변환함 — 최고차항만 남기고 계수를 제거하여 Big-O 등으로 표현(002 참조)

> 요약: 입력 정의 → 기본 연산 식별 → 반복 횟수 산출 → 점근 표기 순서로 복잡도를 분석함

## Ⅳ. 문제점
- 최악 편향 분석: 최악 경우만 고려 시 평균 성능이 우수한 알고리즘을 과소평가함
- 상수 계수 무시: 점근 분석에서 상수 계수를 버리므로 소규모 입력에서 실제 성능 차이를 반영하지 못함
- 공간-시간 트레이드오프 누락: 시간·공간을 개별 분석하면 둘 사이의 상충 관계를 놓칠 수 있음

> 요약: 점근 분석의 추상화로 인해 실제 실행 환경과 괴리가 발생할 수 있음

## Ⅴ. 개선방안
1. 단기: 최악·최선·평균 케이스를 모두 분석하여 편향 판단을 방지함
2. 중기: 소규모 입력 구간에서는 상수 계수를 포함한 실측 벤치마크를 병행함
3. 장기: 시간-공간 동시 분석 프레임워크를 적용하여 트레이드오프를 명시적으로 평가함

> 요약: 다중 케이스 분석, 실측 병행, 동시 분석 프레임워크로 점근 분석의 한계를 보완함

## Ⅵ. 전망
- 발전 방향: 캐시 미스, 분기 예측 등 하드웨어 특성을 반영한 세밀 복잡도 모델로 확장됨
- 기술사적 판단: 알고리즘 설계의 출발점이므로 모든 SW 엔지니어링 판단의 기초 역량임
- 기술사 제언: 이론적 복잡도와 실측 성능을 함께 제시하여 의사결정 근거를 강화할 필요
