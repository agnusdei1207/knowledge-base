# 알고리즘 시간복잡도·공간복잡도 (Time/Space Complexity)

## 1. 개요

- **정의/개념**: 시간복잡도와 공간복잡도는 알고리즘이 입력 크기 증가에 따라 수행 연산과 추가 메모리를 얼마나 요구하는지 함수로 표현한 분석 기준이다.
- **배경/필요성**: 같은 기능이라도 데이터 규모가 커지면 알고리즘별 비용 증가율이 크게 달라지므로, 구현 전에 성능·메모리·확장성 한계를 예측할 기준이 필요하다.

복잡도 분석은 실행 시간을 초 단위로 맞히는 작업이 아니라, 입력 증가에 따른 비용 증가 추세를 보고 알고리즘 선택의 근거를 만드는 작업이다.

## 2. 특징 및 비교

| 구분 | 시간복잡도 | 공간복잡도 |
|---|---|---|
| 분석 대상 | 기본 연산 수행 횟수 | 입력 외 추가 메모리 |
| 대표 표기 | `T(n)`, `O(f(n))` | `S(n)`, `O(f(n))` |
| 주요 판단 | 응답시간, 처리량, 배치 시간 | 메모리 한계, 동시 처리량, 캐시 효율 |
| 실무 영향 | 지연시간, CPU 사용량 | 메모리 피크, GC, 장애 가능성 |

- 시간과 공간은 독립 지표가 아니라 서로 교환되는 자원이다.
- 해시 테이블·인덱스·메모이제이션은 시간을 줄이는 대신 공간을 사용한다.
- 제자리 정렬·스트리밍 처리는 공간을 줄이는 대신 계산이나 I/O 제약을 감수한다.
- 복잡도 판단은 입력 규모, 기본 연산, 보조 공간, 최악·평균 조건, 운영 지표를 함께 보되 핵심 병목 차원만 남긴다.

따라서 복잡도 답안은 시간·공간을 따로 외우는 것이 아니라, 어떤 입력 변수가 어떤 연산과 메모리 사용으로 이어지는지 연결해 설명해야 한다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| 입력 크기 | `n`, `V`, `E`, 행·열 크기처럼 비용을 좌우하는 변수 | 문제별 변수 정의 |
| 기본 연산 | 비교, 대입, 탐색, 병합, 해시 계산 등 | 시간 비용 산정 기준 |
| 보조 공간 | 임시 배열, 큐, 스택, DP 테이블, 재귀 호출 스택 | 공간 비용 산정 기준 |
| 점근 표기 | 상수와 하위항을 제거하고 지배항으로 표현 | 큰 입력의 성장률 |
| 경우 분석 | 최악, 평균, 최선, 상각 조건 구분 | 성능 보장 수준 |

```text
입력 크기 정의 -> 기본 연산/보조 공간 산정 -> 비용 함수 도출 -> 점근 표기 -> 요구사항 적합성 판단
```

이 구조에서 입력 변수와 기본 연산을 잘못 잡으면 뒤의 시간·공간 판단도 함께 틀어지므로, 문제점 역시 대부분 분석 기준 오해에서 발생한다.

## 4. 문제점 및 개선방안

1. **실행시간과 복잡도 혼동**
   - `O(n)` 알고리즘이 항상 `O(log n)` 알고리즘보다 빠른 것은 아니다.
   - **개선방안**: 입력 크기별 벤치마크, p95/p99 지연, 캐시 적중률을 함께 확인한다.

2. **평균·최악 조건 혼동**
   - 해시 평균 `O(1)`, 퀵 정렬 평균 `O(n log n)`을 항상 보장되는 성능으로 오해할 수 있다.
   - **개선방안**: 최악·평균·상각 조건을 표기 옆에 명시하고 최악 입력 테스트를 수행한다.

3. **공간복잡도 누락**
   - 시간만 보고 DP 테이블, 재귀 스택, 인덱스 메모리를 빠뜨리면 운영 환경에서 장애가 발생할 수 있다.
   - **개선방안**: 메모리 피크, 보조 공간 크기, 동시 실행 수를 함께 산정한다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| API 대량 조회 | 정렬·필터링 알고리즘의 시간복잡도와 인덱스 공간을 비교 | p95 지연, CPU, 메모리 피크 |
| 임베디드 제어 | 보조 배열·재귀 스택이 제한 메모리를 넘지 않도록 알고리즘 선택 | RAM 여유율, 최악 응답시간 |
| 배치 처리 | `O(n²)` 처리 구간을 정렬·해시·분할 처리로 개선 | 처리 시간, I/O 횟수 |

## 6. 결론

시간복잡도와 공간복잡도는 알고리즘 선택의 1차 필터이다. Big-O 표기만으로 끝내지 않고 입력 변수, 기본 연산, 보조 공간, 최악 조건, 운영 지표를 연결해야 실제 시스템에서 쓸 수 있는 선택 근거가 된다.
