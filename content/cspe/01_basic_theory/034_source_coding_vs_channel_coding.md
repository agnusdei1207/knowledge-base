## Ⅰ. 개요
- **정의**: 소스 코딩은 데이터 여분도를 제거하여 압축하고, 채널 코딩은 여분도를 추가하여 전송 오류를 정정하는 기법
- **배경/필요성**: 저장·전송 비용 절감과 채널 잡음 극복이라는 상충 목표를 분리 설계해야 전체 통신 시스템을 최적화할 수 있음
- **비유**: 소스 코딩은 짐을 줄여 가방을 가볍게 하는 것, 채널 코딩은 깨질 물건에 완충재를 넣는 것과 같음

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 두 코딩의 목적·방향 대비 | 여분도 제거 vs 여분도 추가 | 소스 코딩 정리와 채널 코딩 정리(031 참조)를 혼동하지 않을 것 |
| 대표 기법 매핑 | 허프만(032 참조)/RLE(033 참조) vs 해밍(030 참조)/RS/LDPC | 소스 코딩 출력이 채널 코딩 입력이 되는 파이프라인 순서 |

> 요약: 여분도 제거(압축)와 여분도 추가(오류 정정)를 분리하여 통신 효율을 최적화하는 설계임

## Ⅱ. 구성요소
```text
원본 데이터
  |
  v
+-- 소스 인코더 --+-- 채널 인코더 --+-- 채널(잡음) --+
                                                      |
                                                      v
+-- 소스 디코더 --+-- 채널 디코더 --+-----------------+
  |
  v
복원 데이터
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 소스 인코더 | 심볼 확률 분포 기반으로 여분도를 제거하여 비트 수를 줄임 | 짐 압축 포장 |
| 소스 디코더 | 압축된 비트열을 원래 심볼로 복원함 | 포장 해체 |
| 채널 인코더 | 패리티·검사 비트를 추가하여 오류 검출·정정 능력을 부여함 | 완충재 삽입 |
| 채널 디코더 | 수신 비트열에서 오류를 검출·정정 후 원래 코드워드를 복원함 | 완충재 제거 및 파손 확인 |

> 요약: 소스 인코더-채널 인코더-채널-채널 디코더-소스 디코더 순으로 파이프라인이 구성됨

## Ⅲ. 절차
```text
원본 --> 소스 인코딩(압축) --> 채널 인코딩(오류 정정 부호 추가)
  --> 전송(채널) --> 채널 디코딩(오류 정정) --> 소스 디코딩(복원)
```
- 1단계: 원본 데이터의 심볼 확률 분포를 분석하여 소스 인코딩(허프만/LZW/RLE 등)으로 압축함
- 2단계: 압축된 비트열에 채널 인코딩(해밍/RS/LDPC 등)으로 검사 비트를 추가함
- 3단계: 채널을 통해 전송된 수신 비트열에서 채널 디코딩으로 오류를 검출·정정함
- 4단계: 정정된 비트열을 소스 디코딩하여 원본 데이터를 복원함

> 요약: 압축 후 오류 정정 부호를 추가하여 전송하고, 수신 측에서 역순으로 복원함

## Ⅳ. 문제점
- 분리 설계 비효율: 소스 코딩과 채널 코딩을 독립 설계하면 유한 블록 길이에서 이론적 한계 대비 성능 손실이 발생함
- 채널 부호율 트레이드오프: 오류 정정 능력을 높이면 검사 비트가 증가하여 유효 전송률이 감소함
- 소스 모델 불일치: 실제 데이터의 확률 분포가 인코더 가정과 다르면 압축률이 저하되고 채널 코딩 부하가 증가함

> 요약: 분리 설계 손실, 부호율-정정 능력 트레이드오프, 소스 모델 불일치가 주요 한계임

## Ⅴ. 개선방안
1. 단기: 결합 소스-채널 코딩(JSCC)을 적용하여 유한 블록 길이에서의 분리 설계 손실을 줄임
2. 중기: 적응형 부호율 제어(Rate-Compatible 부호)를 도입하여 채널 상태에 따라 검사 비트 비율을 동적으로 조절함
3. 장기: 딥러닝 기반 오토인코더로 소스 모델과 채널 모델을 동시에 학습하여 end-to-end 최적화를 달성함

> 요약: JSCC, 적응형 부호율, 딥러닝 end-to-end 학습 순으로 한계를 극복함

## Ⅵ. 전망
- 발전 방향: 6G·위성 통신에서 JSCC와 시맨틱 코딩이 결합된 의미 기반 통신으로 확장됨
- 기술사적 판단: 분리 정리는 이론적 기반으로 유효하나, 저지연·초신뢰 요구가 커지며 결합 설계의 실용화가 가속됨
- 기술사 제언: 시스템 설계 시 소스-채널 분리 가정의 유효 범위를 점검하고, 채널 변동이 큰 환경에서는 결합 코딩 도입을 검토할 것을 권고함
