## 핵심 인사이트 (3줄 요약)
> 1. **본질**: 통신 시스템의 양대 축으로, **소스 코딩**은 데이터의 불필요한 군더더기를 '제거'하는 압축 과정이고, **채널 코딩**은 전송 중 생길 오류를 잡기 위해 보호막(잉여 비트)을 '추가'하는 보호 과정이다.
> 2. **가치**: 한정된 주파수 자원을 아끼는 '효율성(압축)'과 잡음 속에서도 데이터가 깨지지 않는 '신뢰성(보호)'이라는 두 마리 토끼를, 섀넌 분리 정리에 의해 각각 독립적으로 통제할 수 있게 해준다.
> 3. **판단 포인트**: 통신망 환경에 따라 대역폭이 비싸면 소스 코딩의 압축률을 극대화하고, 잡음이 심한 무선 환경이면 채널 코딩의 패리티 비트를 넉넉히 붙이는 '트레이드오프(Trade-off)' 조율 역량을 서술해야 한다.

---

## Ⅰ. 개요 및 필요성
- **개요**: 데이터 송신 전 기저대역(Baseband)에서 데이터를 가공하는 두 단계로, 소스 코딩(정보원 부호화)으로 크기를 줄인 뒤, 채널 코딩(전송로 부호화)으로 오류 검출/정정 능력을 부여한다.
- **배경**: 초기 무선 통신에서는 압축과 오류 보호의 경계가 모호하여 툭하면 통신이 끊어지거나 대역폭이 낭비되었다. 섀넌은 "압축은 엔트로피 한계 내에서, 전송은 채널용량 한계 내에서 따로따로 완벽히 쪼개서 설계하라"고 수학적으로 증명(분리 정리)했다.
- **필요성**: 넷플릭스 4K 영상을 스마트폰으로 끊김 없이 쏘려면, 영상 용량을 1/1000로 쥐어짜는 압축기(소스)와 전파 간섭을 이겨내는 오류 방어기(채널)의 결합형 파이프라인 구조가 절대적으로 필요하다.

## Ⅱ. 아키텍처 및 핵심 원리

```text
       [송신단(TX): 짐을 싸고 포장함]                 [수신단(RX): 포장을 풀고 짐을 연다]
┌──────────────────────────────────────┐     ┌──────────────────────────────────────┐
│ Data(100MB)  ──>  [Source Encoder]   │     │   [Source Decoder]  ──> Data(100MB)  │
│                     (잉여성 제거/압축) │     │    (압축 원상복구)                   │
│                          │           │     │          ▲                           │
│                     Comp(10MB)       │====>│      Comp(10MB)                      │
│                          │           │잡음 │          ▲                           │
│                  [Channel Encoder]   │인입 │  [Channel Decoder]                   │
│                    (패리티 비트 추가)  │     │   (깨진 데이터 자체 수리)              │
│                          │           │     │          ▲                           │
│                   보호막 포함(12MB)    │     │   손상된 12MB 도착                     │
└──────────────────────────────────────┘     └──────────────────────────────────────┘
```

- **1단계 [송신 소스 코딩]**: 원본 100MB 파일의 통계적 패턴을 분석해 잉여 데이터를 과감히 잘라내어 10MB 크기로 극한 압축한다. (섀넌 제1정리 적용)
- **2단계 [송신 채널 코딩]**: 10MB 파일 겉면에 전송 중 깨질 경우를 대비해 복구용 수학 방정식(패리티 비트) 2MB를 덧붙여 12MB짜리 튼튼한 패킷으로 포장한다. (섀넌 제2정리 적용)
- **3단계 [물리 채널 전송]**: 무선 안테나를 통해 12MB를 쏘면, 공기 중의 잡음(Noise)을 맞아 0과 1이 뒤집히는 비트 오류가 발생한다.
- **4단계 [수신 오류 정정 및 압축 해제]**: 수신단 채널 디코더는 손상된 12MB 속의 패리티를 계산해 오류 난 비트를 정답으로 스스로 고치고 순수 10MB만 추출한다. 이후 소스 디코더가 압축을 풀어 100MB 원본을 띄운다.

## Ⅲ. 비교 및 연결

| 비교 축 | 소스 코딩 (Source Coding) | 채널 코딩 (Channel Coding) |
|:---|:---|:---|
| **본질적 방향성** | **제거 (Removal)** - 불필요한 것 빼기 | **추가 (Addition)** - 잉여 보호막 씌우기 |
| **추구하는 목표** | 대역폭 최적화, 통신 **효율성(Efficiency)** 극대화 | 무결점 전송 보장, 통신 **신뢰성(Reliability)** 극대화 |
| **지배하는 한계 법칙** | 섀넌 제1정리 (엔트로피 하한선) | 섀넌 제2정리 (채널용량 상한선) |
| **대표 알고리즘** | 허프만, 런랭스, LZW, JPEG, H.265 비디오 | 해밍코드, 길레이, LDPC, 터보 코드 |
| **에러에 대한 취약성**| 1비트만 깨져도 전체 데이터 복구 불가 (치명적) | 에러가 나면 수학적으로 역추산해서 스스로 고침 |

> ※ **연결 포인트**: 극한으로 다이어트(소스 압축)를 한 파일은 아주 작은 충격(에러)에도 파일 전체가 사망해버린다. 즉, 소스 코딩 기술이 발달하여 파일을 작게 쥐어짤수록, 이를 지켜주는 강력한 갑옷(채널 코딩)의 병행 발전이 무조건 수반되어야만 시스템이 굴러간다.

## Ⅳ. 실무 적용 및 기술사 판단

- **적용 사례 1 (심우주 통신 아키텍처)**: 화성에 있는 탐사선은 전력이 약해 전송 속도가 초당 몇 kbps에 불과하고 잡음은 우주 방사선 때문에 최악이다. 따라서 사진을 초고도 손실 코딩(소스)으로 뭉개서 작게 만든 뒤, 파일 크기보다 더 큰 엄청난 두께의 LDPC 에러 정정 코드(채널)를 덧씌워 보내는 설계로 끊김을 방지한다.
- **적용 사례 2 (5G 이동통신 AMC 기술)**: 기지국과 스마트폰 사이의 전파 상태가 비가 와서 나빠지면 기지국은 재빨리 소스 코딩 화질을 낮추고 채널 코딩의 잉여 비트율을 높여 넷플릭스 화질은 구려져도 끊기지는 않게 만든다. 반대로 날씨가 좋으면 보호막을 빼고 고화질 데이터를 꽉꽉 채워 보낸다 (적응형 변조 및 코딩).
- **기술사 판단**: 섀넌의 분리 정리는 "무한한 시간(지연)"을 대기할 수 있다는 수학적 전제하에 성립한다. 하지만 자율주행 자동차 충돌 방지 시스템(URLLC)처럼 0.001초 만에 데이터 처리가 끝나야 하는 실무 환경에서는 이 전제가 깨지므로, 두 코딩을 별개 모듈로 두지 않고 통합 설계하는 최신 기법이 설계의 당락을 가른다.

## Ⅴ. 기대효과 및 결론

- **기대효과**: 통신망 구축 시 압축 로직과 오류 방어 로직을 독립적으로 모듈화하여 개발하더라도, 두 톱니바퀴가 맞물려 시스템 전체 최적화를 이뤄낼 수 있다.
- **향후 발전 방향**: 최근 6G R&D에서는 이 두 단계를 사람이 짠 알고리즘이 아니라, 인공지능 딥러닝 모델(오토인코더)에게 맡겨 압축과 오류 방어를 한 방에 처리하는 **조인트 소스-채널 코딩(JSCC)** 기술로 패러다임이 이동 중이다.

### 📌 관련 개념 맵
- **전방오류정정 (FEC)**: 에러가 났을 때 "다시 보내줘(ARQ)"라고 하지 않고, 수신 측 채널 디코더가 패리티 비트를 활용해 알아서 깨진 비트를 복구하는 자생력 기술.
- **섀넌의 분리 정리 (Separation Theorem)**: 압축 최적화 놈과 오류 제어 놈이 서로 대화 없이 각자 자기 일방에만 100% 충실해도 통신 시스템 전체 최적화가 보장된다는 증명.

### 📈 관련 키워드 및 발전 흐름도
`데이터 통신의 양대 산맥 분리` $\to$ `소스(압축)와 채널(방어)의 독립 발전` $\to$ `실시간 상태 감지형 조율 (AMC)` $\to$ `저지연 한계 돌파형 결합 통신 (JSCC)` $\to$ `AI 기반 통신 모뎀 혁명`

### 👶 어린이를 위한 3줄 비유 설명
1. 여름 옷들을 해외에 보낼 때, 부피를 줄이려고 진공 압축팩에 넣어 납작하게 만드는 것이 바로 '소스 코딩'이에요.
2. 하지만 비행기 화물칸에서 팩이 터지면 안 되니까 그 위에 빵빵한 뽁뽁이를 둘둘 감아 안전장치를 하는 것이 '채널 코딩'이랍니다.
3. 짐을 최대한 줄이면서도(효율), 절대로 망가지지 않게 지키는(안전) 이 두 가지 협동 작전 덕분에 우리는 핸드폰으로 영상을 잘 볼 수 있어요!
