## Ⅰ. 개요
- **정의**: 트리 탐색과 무작위 시뮬레이션을 결합하여 최적 행동을 선택하는 탐색 알고리즘
- **배경/필요성**: 바둑·체스 등 상태 공간이 방대한 순차 의사결정 문제에서 완전 탐색이 불가능하므로, 샘플링 기반으로 유망 경로를 집중 탐색하는 방법이 필요함
- **비유**: 미로에서 갈림길마다 랜덤으로 끝까지 달려본 뒤, 출구에 도착한 횟수가 많은 방향을 선택하는 것과 유사함

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 탐색-활용 균형 원리와 4단계 절차 이해 | UCT 공식에서 탐색(exploration)과 활용(exploitation) 항의 역할 | 역전파가 시뮬레이션 결과를 루트까지 갱신하는 과정을 누락하지 말 것 |

> 요약: 무작위 시뮬레이션 결과를 트리에 축적하여 방대한 상태 공간에서 최적 행동을 근사적으로 선택하는 알고리즘임

## Ⅱ. 구성요소
```text
        +--- [Selection] --- UCT 기반 노드 선택
        |
[Root] -+--- [Expansion] --- 미방문 자식 노드 추가
        |
        +--- [Simulation] -- 랜덤 플레이아웃
        |
        +--- [Backpropagation] -- 결과 역전파
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 게임 트리 | 상태-행동 쌍을 노드-간선으로 표현한 탐색 공간 | 미로의 전체 갈림길 지도 |
| UCT(Upper Confidence Bound for Trees) | 승률 항(활용)과 방문 빈도 역수 항(탐색)을 합산하여 다음 노드를 선택하는 공식 | 맛집 재방문(활용)과 새 식당 시도(탐색)를 균형 잡는 기준 |
| 플레이아웃(Rollout) | 현재 노드에서 종료 상태까지 랜덤 행동으로 시뮬레이션하는 과정 | 갈림길에서 눈 감고 끝까지 달려보는 것 |
| 통계 저장소 | 각 노드의 방문 횟수 `N`과 누적 보상 `Q`를 저장하는 구조 | 각 갈림길에 붙인 성공/실패 기록표 |

> 요약: 게임 트리·UCT·플레이아웃·통계 저장소가 탐색-활용 균형을 실현하는 핵심 요소임

## Ⅲ. 절차
```text
Step1 선택 --> Step2 확장 --> Step3 시뮬레이션 --> Step4 역전파
     |              |               |                   |
     v              v               v                   v
UCT 최대 노드    자식 노드 생성   랜덤 플레이아웃    Q, N 갱신
```
- 1단계: 루트에서 리프까지 UCT 값이 최대인 자식을 반복 선택하여 내려감
- 2단계: 리프 노드에서 미방문 행동 하나를 선택해 새 자식 노드를 트리에 추가함
- 3단계: 새 노드에서 종료 상태까지 랜덤 행동으로 플레이아웃을 수행하고 승패를 판정함
- 4단계: 시뮬레이션 결과(승/패/무)를 새 노드에서 루트까지 경로상 모든 노드의 `Q`와 `N`에 반영함

> 요약: 선택 → 확장 → 시뮬레이션 → 역전파를 반복하여 유망 경로의 통계를 축적함

## Ⅳ. 문제점
- 플레이아웃 품질 한계: 완전 랜덤 시뮬레이션은 도메인 지식을 반영하지 못해 승패 판정의 신호 대 잡음비가 낮음
- 탐색-활용 불균형: UCT의 탐색 상수 `C` 설정이 부적절하면 탐색 과다(수렴 지연) 또는 활용 편향(지역 최적 수렴)이 발생함
- 넓은 분기 계수 비효율: 행동 공간이 넓은 문제(연속 행동 등)에서는 확장 단계의 노드 수가 폭증하여 유의미한 통계 축적이 지연됨

> 요약: 랜덤 플레이아웃 품질·탐색 상수 설정·넓은 분기 계수가 성능 병목임

## Ⅴ. 개선방안
1. 단기: 도메인 휴리스틱 또는 경량 평가 함수로 플레이아웃을 안내(guided rollout)하여 시뮬레이션 신호 품질을 높임
2. 중기: 탐색 상수 `C`를 적응적으로 조정하는 기법(RAVE, Progressive Widening)을 적용하여 탐색-활용 균형을 자동화함
3. 장기: 신경망 기반 가치·정책 함수를 플레이아웃 대신 사용(017 참조의 몬테카를로 샘플링과 결합)하여 넓은 분기 계수 문제를 근본적으로 완화함

> 요약: 안내형 플레이아웃 → 적응적 상수 조정 → 신경망 가치 함수 대체 순으로 고도화함

## Ⅵ. 전망
- 발전 방향: 신경망 정책·가치 평가와 MCTS의 결합이 게임 AI를 넘어 로봇 경로 계획·분자 설계·자동 코드 생성 등으로 확장되는 추세임
- 기술사적 판단: 상태 공간이 이산적이고 시뮬레이션이 가능한 순차 의사결정 문제에서 사실상 표준 탐색 프레임워크로 자리잡음
- 기술사 제언: 도메인별 분기 계수와 시뮬레이션 비용을 사전 분석한 뒤, 플레이아웃 전략과 UCT 상수를 튜닝하는 체계적 실험 설계를 권장함
