## Ⅰ. 개요
- 무작위 시뮬레이션을 통해 상태 공간을 탐색하고 최적의 수를 찾는 기법임.
- 탐색 트리 확장과 몬테카를로 시뮬레이션을 결합하여 방대한 공간 처리함.
- [표] 출제 의도: AI 탐색 전략 및 AlphaGo 핵심 알고리즘 이해 측정.

## Ⅱ. 구성요소
- ASCII 구조도
  Selection -> Expansion -> Simulation -> Backpropagation

| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| Selection | 승산 높은 노드 선택 (UCB1 사용) | 유망한 인재 선발 |
| Expansion | 새로운 자식 노드 추가 및 확장 | 사업 영역 확장 |
| Simulation | 리프에서 승패가 날 때까지 무작위 진행 | 연습 게임 수행 |
| Backprop | 결과 점수를 루트까지 역전파 갱신 | 성과 보고 및 전파 |

> 요약: 탐험과 활용의 균형을 맞추며 최적의 경로를 점진적으로 찾아감.

## Ⅲ. 절차
- ASCII 흐름도
  Tree Traverse -> New Node -> Playout -> Update Statistics

1. 루트부터 정책(UCB)에 따라 최적의 자식 노드를 선택해 내려감.
2. 미방문 상태 도달 시 노드를 생성하고 트리에 추가함.
3. 해당 지점부터 무작위 시뮬레이션(Playout)을 끝까지 진행함.
4. 승리 여부 결과를 경로상의 모든 노드에 승률로 반영함.

> 요약: 4단계를 반복하며 승률이 높은 유망한 경로 위주로 탐색함.

## Ⅳ. 문제점
- 시뮬레이션 횟수가 부족할 경우 통계적 편향으로 오판할 수 있음.
- 상태 공간이 비상식적으로 클 경우 초기 수렴 속도가 매우 느림.

## Ⅴ. 개선방안
- 단기: 정책망(Policy)과 가치망(Value)을 결합하여 탐색 폭 제한함.
- 중기: 도메인 지식을 활용한 휴리스틱으로 무작위성 보완함.
- 장기: 대규모 분산 컴퓨팅 환경에서 병렬 시뮬레이션 가동함.

## Ⅵ. 전망
- 강화학습과 결합된 'Hybrid MCTS-RL' 모델이 불완전 정보 게임 및 주식 시장 예측 등 비결정론적 도메인의 의사결정 최적화에서 CSF로 작용할 것임.
- 자율주행차의 동적 장애물 회피 및 경로 계획에서 실시간 안정성을 확보하기 위해 병렬 MCTS 가속 기술이 차량용 임베디드 SoC에 통합될 전망임.
- 초거대 언어 모델(LLM)의 추론 단계에서 논리적 단계별 사고(Chain of Thought)를 검증하고 최적의 답변을 선택하는 탐색 알고리즘으로 진화할 것임.
