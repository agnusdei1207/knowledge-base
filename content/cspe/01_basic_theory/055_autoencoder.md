## Ⅰ. 개요
- 정의: 입력을 압축했다가 다시 복원하며 데이터의 효율적인 특징을 학습하는 신경망임
- 배경: 레이블 없는 데이터의 특징 추출(Embedding) 및 노이즈 제거 필요
- 출제 의도:
| 구분 | 내용 |
| --- | --- |
| 핵심 | 인코더, 디코더, 잠재 벡터(Latent Vector) |

## Ⅱ. 구성요소
- ASCII 구조도
  [In] -> [Encoder] -> [Latent] -> [Decoder] -> [Out]
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 인코더 | 고차원 입력을 저차원 압축 특징으로 변환함 | 요약자 |
| 잠재 벡터 | 데이터의 정수만 담긴 핵심 정보 표현 | 압축파일 |
| 디코더 | 압축된 벡터를 다시 원본 크기로 복원함 | 복원기 |
> 요약: 자기 자신을 타겟으로 학습하여 의미 있는 특징 표현을 획득함

## Ⅲ. 절차
- ASCII 흐름도
  [데이터입력] -> [특징압축] -> [원본복원] -> [오차비교]
- 4단계 설명
1. 데이터 입력: 원본 이미지나 수치 데이터를 인코더에 전달함
2. 특징 압축: 병목(Bottleneck) 층을 거쳐 핵심 성분만 추출함
3. 원본 복원: 디코더를 통해 압축된 정보로부터 원본 재구성함
4. 오차 비교: 입력과 출력의 차이(Reconstruction Loss) 최소화함
> 요약: 정보의 손실을 최소화하는 최적의 압축 방식을 스스로 찾아냄

## Ⅳ. 문제점
- 과도한 압축 시 데이터의 미세한 디테일이 손실될 수 있음
- 학습 데이터에만 특화되어 새로운 데이터 복원에 취약할 수 있음

## Ⅴ. 개선방안
- (단기) Denoising AE를 사용하여 노이즈 강건성 확보함
- (중기) VAE(Variational AE)로 데이터 생성 모델로 확장함
- (장기) GAN 등과 결합하여 고품질의 특징 추출 성능 구현함

## Ⅵ. 전망
- 이상 징후 탐지, 이미지 검색 등 비지도 학습 기반 서비스에 필수적임
