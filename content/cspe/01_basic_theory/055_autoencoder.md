## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 입력 데이터를 저차원 잠재 공간으로 압축한 후 다시 원본과 동일하게 복원하도록 학습하는 비지도 모델임 |
| 배경/필요성 | 정답(Label) 없는 방대한 데이터로부터 본질적인 특징 추출, 차원 축소 및 노이즈 제거 필요 |
| 출제 의도 | 인코더-디코더 병목 구조의 원리와 이상 탐지, 데이터 증강 등 활용 사례 적용 능력 평가 |

## Ⅱ. 구성요소
```text
+----------------+       +----------------+       +----------------+
| Input Data (X) |       | Latent Vector  |       | Reconstruct    |
| (High Dim)     | ----> | (Bottleneck)   | ----> | Output (X')    |
+----------------+       +----------------+       +----------------+
```
| 인코더 (Encoder)| 입력 데이터를 저차원의 핵심 특징 벡터로 압축 | 압축기 |
| 잠재 벡터 (Z) | 병목 계층(Bottleneck)에 저장된 데이터의 본질적 정보 | 요약본 |
| 디코더 (Decoder)| 잠재 벡터를 다시 원본 차원의 데이터로 복원 | 해제기 |
> 요약: 오토인코더는 인코더를 통한 잠재 벡터 생성과 디코더를 통한 원본 복원으로 구성됨

## Ⅲ. 절차
```text
+----------------+       +----------------+       +----------------+       +----------------+
| Data Input     |       | Encoding Phase |       | Decoding Phase |       | Reconstruct.   |
| (Feed Image)   | ----> | (Dim Compress) | ----> | (Dim Restore)  | ----> | (Loss Calc)    |
+----------------+       +----------------+       +----------------+       +----------------+
```
1. 입력 수신: 원본 데이터를 인코더 신경망에 주입
2. 압축 인코딩: 점진적으로 차원을 축소하여 핵심 특징만 남은 잠재 벡터(Z) 생성
3. 복원 디코딩: 잠재 벡터를 디코더에 통과시켜 원래 차원과 유사하게 데이터 재구성
4. 손실 계산: 원본 입력과 복원된 출력 간의 차이(Reconstruction Loss)를 최소화하도록 학습
> 요약: 데이터를 잠재 공간으로 압축한 후 다시 복원하며 그 차이를 최소화하도록 학습함

## Ⅳ. 문제점
- 단순 암기(Identity): 병목 크기가 크면 특징 추출 없이 입력을 그대로 복사하는 문제 발생
- 생성력 부재: 잠재 공간이 연속적이지 않아 새로운 데이터 생성(Generative) 기능 불가
- 이상치에 취약: 극단적 이상치가 포함된 훈련 데이터를 학습하면 복원 손실 기준이 모호해짐

## Ⅴ. 개선방안
- 단기 방안: 잠재 공간의 차원(Bottleneck)을 충분히 작게 제한하여 강제적 정보 압축
- 중기 방안: 입력에 노이즈를 주고 원본을 복원하게 하는 Denoising AE 적용
- 장기 방안: 잠재 공간을 정규 분포로 강제하여 생성 모델 역할을 하는 Variational AE(VAE) 도입

## Ⅵ. 전망
- Stable Diffusion 등 대형 생성 모델의 차원 축소 모듈(Latent Space)로 핵심 역할을 수행함
