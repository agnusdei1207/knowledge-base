## 미리 알고가기

- 비지도 학습($Unsupervised$ $Learning$): 별도의 정답 라벨 없이 입력 데이터 자체의 구조나 특징을 학습하는 방식임
- 잠재 공간($Latent$ $Space$): 데이터의 고차원 특징들을 핵심 정보만 남겨 축약한 저차원의 추상적 공간임
- 재구성 오차($Reconstruction$ $Error$): 인코딩 후 디코딩된 결과물이 원래의 입력과 얼마나 차이가 나는지 나타내는 지표임
- 병목 현상($Bottleneck$): 중간 층의 크기를 고의로 작게 하여 데이터의 불필요한 정보는 버리고 핵심만 남기게 하는 구조임

## Ⅰ. 개요

- **정의/개념**: 오토인코더는 입력을 잠재 변수로 압축하는 인코더와 이를 다시 원래의 입력으로 복원하는 디코더로 구성되어, 입력 데이터 자체를 학습 목표($Target$)로 삼아 데이터의 핵심 특징을 스스로 추출하는 신경망 구조임
- **배경/필요성**: 수많은 비정형 데이터에서 유의미한 특징을 추출하거나 차원을 축소하여 데이터의 본질적 구조를 파악하고, 노이즈를 제거하거나 이상치를 탐지하기 위한 자동화된 도구가 필요해짐

## Ⅱ. 특징

- 정답 라벨이 필요 없는 '자기 지도 학습($Self-supervised$)'의 형태를 띠며, 입력과 출력을 같게 만듦으로써 데이터의 가장 지배적인 특징($Feature$)을 보틀넥 구간에 강제로 농축시킴
- 선형적인 방식의 PCA와 달리 활성화 함수를 통한 비선형 차원 축소가 가능하여, 훨씬 더 복잡한 구조의 데이터 분포를 효율적으로 압축하고 표현할 수 있음
- 학습이 완료된 후 재구성 오차가 비정상적으로 높게 나타나는 데이터는 '학습 데이터와 다른 특성'을 가진 이상치로 간주할 수 있어 보안 및 모니터링 분야에 강력함

## Ⅲ. 종류 및 비교

| 판단 기준 | 기본 오토인코더 | 디노이징 ($DAE$) | 변이형 ($VAE$) |
|:---|:---|:---|:---|
| **학습 목표** | 단순 입력 복원 | 노이즈 제거 후 복원 | 데이터의 확률 분포 학습 |
| **핵심 기법** | 보틀넥 구조 사용 | 입력에 무작위 노이즈 추가 | 잠재 변수의 정규 분포화 |
| **주요 용도** | 특징 추출, 차원 축소 | 데이터 정제, 견고한 특징 학습 | 새로운 데이터 생성 ($Generative$) |
| **특이 사항** | 과적합 시 단순 복제 위험 | 노이즈에 강인한 모델 생성 | 생성 모델의 한 축을 담당함 |

> 요약: 기본형은 압축에, DAE는 정제에, VAE는 생성에 특화되어 있음.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 인코더 ($Encoder$) | 고차원 입력을 의미 있는 저차원 잠재 벡터로 변환하는 특징 추출기임 |
| 잠재 벡터 ($z$) | 데이터의 본질이 응축된 결과물로, 차원 축소의 최종 목적지임 |
| 디코더 ($Decoder$) | 잠재 벡터로부터 원본의 해상도와 구조를 다시 살려내는 재구성기임 |
| 손실 함수 ($Loss$) | 입력 $x$와 출력 $\hat{x}$의 차이(MSE 등)이며, 이를 최소화하는 방향으로 학습함 |

```text
[ 오토인코더 전체 구조 ]
Input (x) -> Encoder -> Latent (z) -> Decoder -> Output (x')
- x ≈ x' 가 되도록 네트워크의 가중치를 최적화함
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 데이터 입력  | --> | 특징 압축(인코딩)| --> | 특징 복원(디코딩)| --> | 오차 역전파  |
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **정보 압축** — 입력 데이터를 점점 좁아지는 신경망 층에 통과시켜 중요도가 낮은 정보는 걸러내고 핵심적인 특징만 잠재 공간에 남김
2. **원본 재구성** — 압축된 잠재 벡터를 다시 넓어지는 신경망 층에 통과시켜, 원래의 입력값과 가장 흡사한 형태의 결과물을 만들어냄
3. **오차 측정** — 원본과 재구성된 결과물 사이의 손실값을 계산하며, 이때 손실이 크다는 것은 정보 압축 과정에서 본질적인 내용이 유실되었음을 의미함
4. **표현 최적화** — 오차를 줄이기 위해 전체 네트워크를 갱신하며, 결과적으로 인코더는 가장 효율적인 요약 방법을 학습하게 됨

## Ⅵ. 실무 적용 및 유의점

1. 오토인코더 설계 시 잠재 공간의 차원($Dimension$)이 너무 크면 데이터의 특징을 배우는 대신 단순히 입력값을 그대로 복사해서 출력하는 '항등 함수'로 전락할 수 있으므로, 적절한 보틀넥 크기 설정이나 규제($Sparsity$ 등)를 적용해야 함
2. 이상 탐지 시스템에서 사용할 경우 정상 데이터로만 학습을 진행해야 하며, 실제 운영 시에는 '재구성 오차의 임계값($Threshold$)'을 정밀하게 튜닝하여 오탐과 미탐 사이의 균형을 맞춰야 함

## Ⅶ. 결론

- 오토인코더는 데이터의 본질을 꿰뚫는 '눈'을 기계에게 부여하는 기술이며, 설계자는 압축 효율과 복원 정밀도 사이의 상충 관계를 이해하여 데이터의 가치를 가장 밀도 있게 추출하는 잠재 표현 체계를 구축해야 함
