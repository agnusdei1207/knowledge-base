## Ⅰ. 개요
- **정의**: 입력을 저차원 잠재 공간으로 압축 후 원본으로 복원하도록 학습하는 비지도 신경망
- **배경/필요성**: 레이블 없는 데이터에서 핵심 특징 추출, 차원 축소, 노이즈 제거를 자기지도 방식으로 수행 필요
- **비유**: 긴 문서를 핵심 요약문으로 압축한 뒤 다시 원문을 복원하는 과정

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 병목 구조 원리 | 인코더 -> 잠재 벡터(Z) -> 디코더 대칭 구조 | 병목 차원이 크면 항등 함수(Identity) 학습 위험 |
| 활용 사례 적용 | 이상 탐지(재구성 오차 임계), Denoising AE | VAE와의 차이(잠재 공간 정규 분포 강제) 혼동 주의 |

> 요약: 오토인코더는 병목 구조의 자기지도 학습으로 데이터의 본질적 특징을 추출하는 모델임

## Ⅱ. 구성요소
```text
+---------------+       +------------------+       +------------------+
| Input X       |       | Latent Z         |       | Output X'        |
| (High Dim)    | ----> | (Bottleneck)     | ----> | (Reconstructed)  |
+---------------+       +------------------+       +------------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 인코더 | 입력 차원을 점진적으로 축소하여 잠재 벡터 Z 생성 | 압축기 |
| 잠재 벡터 Z | 병목 계층에 위치한 저차원 표현, 데이터의 핵심 정보 응축 | 핵심 요약문 |
| 디코더 | 잠재 벡터를 원본 차원으로 복원하는 대칭 구조 네트워크 | 복원기 |

> 요약: 인코더(압축) -> 잠재 벡터(핵심 표현) -> 디코더(복원)의 대칭 3요소로 구성됨

## Ⅲ. 절차
```text
+---------------+       +---------------+       +---------------+       +---------------+
| Feed Input    |       | Encode        |       | Decode        |       | Calc Loss     |
| (Raw Data)    | ----> | (Compress Z)  | ----> | (Restore X')  | ----> | (X vs X')     |
+---------------+       +---------------+       +---------------+       +---------------+
```

1. **입력 주입** — 원본 데이터 X를 인코더 네트워크에 입력
2. **인코딩** — 계층적 차원 축소를 거쳐 병목 계층의 잠재 벡터 Z 생성
3. **디코딩** — 잠재 벡터 Z를 디코더에 통과시켜 원본 차원의 X' 복원
4. **손실 계산** — 원본 X와 복원 X' 간 재구성 손실(MSE 또는 BCE)을 최소화하도록 가중치 갱신

> 요약: 입력 -> 인코딩(압축) -> 디코딩(복원) -> 재구성 손실 최소화의 4단계로 학습함

## Ⅳ. 문제점
- 항등 함수 학습: 병목 차원이 입력 차원과 유사하면 특징 추출 없이 입력을 그대로 복사
- 불연속 잠재 공간: 잠재 벡터 분포에 제약이 없어 임의의 Z에서 의미 있는 데이터 생성 불가
- 이상치 민감: 극단값 포함 훈련 시 재구성 손실 기준선이 왜곡되어 이상 탐지 정밀도 저하

> 요약: 항등 학습·불연속 잠재 공간·이상치 민감성이 기본 AE의 3대 한계임

## Ⅴ. 개선방안
1. 단기: 병목 차원을 입력의 5~10%로 제한하거나 L1 정규화(Sparse AE)로 항등 학습 방지
2. 중기: 입력에 가우시안 노이즈를 주입하고 원본을 복원하는 Denoising AE로 강건성 확보
3. 장기: 잠재 공간을 정규 분포로 강제하는 VAE 도입으로 연속적 생성 능력 확보

- 이상치 민감: 극단값에 의한 손실 기준선 왜곡 -> Robust AE(이상치 분리 항 추가) 적용 (지표: F1-Score > 0.9)

> 요약: 병목 제한 -> Denoising AE -> VAE로 단계적 고도화, 이상치는 Robust AE로 대응함

## Ⅵ. 전망
- 향후 발전 방향: Stable Diffusion 등 대형 생성 모델의 Latent Space 압축 모듈로 AE 구조 핵심 활용
- 기술사적 판단: 단독 생성 모델로는 GAN·Diffusion에 밀리나, 차원 축소·이상 탐지·사전학습 표현 추출 영역에서 실용적 가치 유지
- 기술사 제언: 이상 탐지 시스템 설계 시 AE 기반 재구성 오차 임계와 지도학습 분류기 앙상블 전략 비교 검토 필요
