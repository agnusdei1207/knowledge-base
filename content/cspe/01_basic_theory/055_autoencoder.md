## 미리 알고가기

- 자기지도 학습: 입력 데이터 자체에서 학습 목표를 만들어 별도 라벨 없이 학습하는 방식임
- 잠재 공간: 고차원 입력을 핵심 특징 중심으로 압축한 저차원 표현 공간임
- 재구성 오차: 입력 $x$와 복원 출력 $\hat{x}$의 차이를 나타내는 손실값임
- 병목 구조: 중간 표현 차원을 제한해 입력의 핵심 정보만 통과시키는 구조임
- 디노이징: 노이즈가 섞인 입력에서 원래 신호를 복원하도록 학습하는 방식임

## Ⅰ. 개요

- **정의/개념**: 오토인코더는 인코더가 입력을 잠재 벡터로 압축하고 디코더가 이를 복원하도록 학습해 데이터 표현을 얻는 신경망 구조임
- **배경/필요성**: 라벨이 부족한 데이터에서도 차원 축소, 특징 추출, 노이즈 제거, 이상 탐지를 수행하려면 입력 자체를 학습 목표로 삼는 구조가 필요함

## Ⅱ. 특징

- 입력과 출력 목표를 같게 두어 라벨 없이 데이터의 주요 구조를 학습함
- 병목 구조와 규제로 단순 복제를 막고 의미 있는 잠재 표현을 만들도록 유도함
- 비선형 활성화를 사용해 PCA보다 복잡한 데이터 분포도 압축함
- 정상 데이터와 다르게 복원되는 샘플은 재구성 오차가 커져 이상 탐지 신호가 됨

## Ⅲ. 종류 및 비교

| 판단 기준 | 기본 오토인코더 | 디노이징 오토인코더 | 변이형 오토인코더 |
|:---|:---|:---|:---|
| 학습 목표 | 입력 복원 | 노이즈 제거 후 복원 | 잠재 분포 학습과 생성 |
| 핵심 제약 | 병목 차원 | 입력 노이즈 | 정규분포 잠재 변수 |
| 주요 활용 | 차원 축소·특징 추출 | 데이터 정제·견고한 표현 | 샘플 생성·확률 표현 |
| 주의점 | 항등 함수 위험 | 노이즈 설계 영향 | 복원 품질과 분포 제약 균형 |

> 요약: 기본형은 압축, 디노이징은 정제, 변이형은 생성 가능 잠재 공간에 초점이 있음.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 인코더 | 입력 $x$를 잠재 벡터 $z$로 변환해 핵심 표현을 추출함 |
| 잠재 벡터 $z$ | 원본 정보를 압축한 표현이며 분석, 검색, 생성의 중간 결과가 됨 |
| 디코더 | $z$에서 원본과 유사한 $\hat{x}$를 복원해 표현 품질을 검증함 |
| 재구성 손실 | $x$와 $\hat{x}$의 차이를 계산해 네트워크 학습 방향을 정함 |
| 규제 조건 | 희소성, 노이즈, 분포 제약으로 의미 없는 단순 복제를 억제함 |

```text
+----------+      +----------+      +----------+      +----------+
| input x  | ---> | encoder  | ---> | latent z | ---> | decoder  |
+----------+      +----------+      +----------+      +----------+
                                                          |
                                                          v
                                                    +-----------+
                                                    | output x' |
                                                    +-----------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+      +----------+      +----------+      +----------+
| input    | ---> | encode   | ---> | decode   | ---> | loss     |
+----------+      +----------+      +----------+      +----------+
```

1. **입력 제공**: 학습 데이터 $x$를 입력과 목표값으로 동시에 사용함
2. **잠재 압축**: 인코더가 중요한 정보만 남겨 잠재 벡터 $z$를 생성함
3. **원본 복원**: 디코더가 $z$에서 원본과 유사한 $\hat{x}$를 생성함
4. **오차 최소화**: 재구성 손실을 줄이도록 인코더와 디코더를 함께 갱신함

## Ⅵ. 실무 적용 및 유의점

1. 이상 탐지는 정상 데이터 중심으로 학습하고 재구성 오차 임계값을 검증 데이터의 오탐·미탐 비율로 조정함
2. 잠재 차원이 너무 크면 입력 복사로 끝나므로 병목 크기와 희소 규제를 바꾸며 검증 재구성 오차를 확인함

## Ⅶ. 결론

- 오토인코더는 라벨 없이 잠재 표현을 학습하는 구조이며, 병목 제어와 재구성 오차 해석이 적용 성패를 결정함

## 작성 근거(검토용)

- 개요는 인코더, 잠재 벡터, 디코더를 한 흐름으로 묶어 구조와 목적을 동시에 설명함
- 특징은 라벨 불필요, 병목, 비선형 압축, 이상 탐지로 활용 근거를 나눔
- 비교표는 기본형, 디노이징, 변이형의 학습 제약 차이를 중심으로 구성함
- 구성요소는 복원 손실과 규제 조건을 포함해 단순 구조 나열을 피함
- 절차는 입력을 목표로 쓰는 점부터 오차 최소화까지 학습 원리를 보이게 함
- 유의점은 정상 데이터 학습과 잠재 차원 과대 설정을 핵심 리스크로 선택함
