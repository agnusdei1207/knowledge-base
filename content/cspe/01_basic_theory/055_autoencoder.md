# 📖 【암기용】 개념 완전 이해

> 목적: 이 개념을 처음 보는 사람도 완벽히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: **비지도 학습(Unsupervised Learning)** 기반으로 입력 데이터를 압축(인코딩)해 핵심 특징만 남긴 뒤, 그 압축본에서 다시 원래 데이터로 복원(디코딩)하도록 학습하는 신경망
- **왜 필요한가**: 정답(Label)이 없는 방대한 데이터 속에서 "가장 본질적인 특징(잠재 변수)"을 모델 스스로 찾아내게 하여, 차원 축소·노이즈 제거·이상 탐지 등에 활용하기 위해서다.
- **핵심 직관**: 긴 문서를 3줄로 요약(압축)한 뒤, 다른 사람이 그 요약본만 보고 원래 문서를 거의 똑같이 다시 써내는 훈련을 반복하는 것과 같다. 요약을 잘해야 복원도 잘할 수 있다.

## 핵심 용어 정리 (내부에 등장하는 것들)

| 용어 | 의미 | 비유 |
|:---|:---|:---|
| 비지도 학습 (Unsupervised Learning) | 정답 라벨 없이 데이터 자체의 구조를 학습하는 방식 — 이 개념의 핵심 키워드 | 답안지 없이 문제 패턴만 보고 익히기 |
| 인코더 (Encoder) | 입력을 저차원으로 압축하는 앞쪽 신경망 | 요약문을 쓰는 사람 |
| 잠재 벡터/병목 (Latent Vector, Bottleneck) | 압축이 끝난 가장 작은 중간 표현 $Z$ | 3줄 요약문 그 자체 |
| 디코더 (Decoder) | 압축된 $Z$를 원본 크기로 복원하는 뒤쪽 신경망 | 요약문만 보고 원문을 재현하는 사람 |
| 복원 오차 (Reconstruction Loss) | 원본 $X$와 복원값 $X'$의 차이를 수치화한 손실(보통 MSE) | 원문과 재현본을 대조해 매긴 감점 |
| 항등 함수 (Identity Function) | 압축 없이 입력을 그대로 베껴 출력하는 실패 상태 | 요약 없이 원문을 그대로 옮겨 적음 |
| Undercomplete | 병목 차원을 입력보다 강제로 작게 만드는 설계 | 요약 글자 수를 강제로 제한 |
| Sparse (희소) | 병목 차원은 크게 두되 활성 뉴런 수를 규제로 제한 | 단어는 많이 써도 되지만 핵심어만 강조 |
| Denoising | 입력에 일부러 노이즈를 섞고 원본으로 복원하게 학습 | 흐릿한 사본을 보고 깨끗한 원본을 재현 |

## 깊이 이해

### 병목 구조가 강제로 압축을 시키는 원리 (수치로)
- 28×28 흑백 이미지(MNIST)는 784차원 벡터다. 인코더가 이를 32차원 잠재 벡터 $Z$로 줄인다면 압축률은 $784/32 \approx 24.5$배다. 만약 병목층 노드 수를 입력과 같은 784로 그대로 둔다면(Overcomplete), 네트워크는 굳이 특징을 요약하지 않고 값을 그대로 복사하는 항등 함수로 수렴해버려 아무것도 배우지 못한다. 그래서 반드시 $d < D$로 강제로 좁혀야(Undercomplete) 정보를 쥐어짜게 된다.

### 복원 오차를 수치로 따라가기
- 손실 함수는 보통 평균제곱오차(MSE)다: $L = \frac{1}{n}\sum (x_i - x'_i)^2$. 예를 들어 원본 픽셀 벡터가 $[1, 0, 1]$이고 복원된 벡터가 $[0.9, 0.1, 0.8]$이라면, 오차 제곱은 $(0.1)^2+(0.1)^2+(0.2)^2 = 0.01+0.01+0.04 = 0.06$이고 평균을 내면 $MSE = 0.06/3 = 0.02$다. 학습은 이 값을 역전파로 줄이는 방향으로 진행된다.

### 이상 탐지가 작동하는 구체 로직
- 정상 데이터로만 학습시키면, 모델은 정상 패턴을 복원하는 데는 능숙해지지만 한 번도 보지 못한 불량 패턴은 서투르게 복원한다. 예: 정상 제품 이미지들의 평균 복원 오차가 0.02, 표준편차가 0.005라면, 임계치를 평균+3×표준편차 = 0.035로 잡는다. 새로 들어온 이미지의 복원 오차가 0.15로 임계치를 크게 넘으면 "본 적 없는 패턴 → 불량"으로 판정한다.

### 정규화 기법의 세 갈래 — 항등 함수화를 막는 방법들
- Undercomplete AE: 병목 차원을 입력보다 작게 강제(위 784→32 예시).
- Sparse AE: 병목 차원은 오히려 크게 두되, 손실 함수에 L1 규제항을 추가해 한 번에 활성화되는 뉴런 수를 제한한다(예: 노드 128개 중 실제로 값이 0이 아닌 뉴런은 10개 미만으로 유도).
- Denoising AE: 입력에 일부러 노이즈를 섞은 뒤(예: 픽셀의 20%를 무작위로 0으로 만듦), 노이즈 없는 원본 이미지를 복원하도록 학습시켜 노이즈에 강건한 표현을 익히게 한다.

### PCA와의 관계, VAE로의 확장
- PCA는 선형 변환(행렬 곱)만으로 차원을 축소하지만, 오토인코더는 인코더·디코더에 비선형 활성화 함수(ReLU 등)를 넣을 수 있어 휘어진(비선형) 데이터 구조도 압축할 수 있다. 인코더에 선형 활성화만 쓰고 은닉층이 1개면 오토인코더는 수학적으로 PCA와 거의 동일한 해를 찾는다.
- VAE(Variational Autoencoder)는 잠재 벡터 $Z$를 하나의 고정값이 아니라 평균 $\mu$와 분산 $\sigma^2$로 이루어진 확률 분포로 만든다. 그 분포에서 임의의 점을 샘플링해 디코더에 넣으면 학습 데이터에 없던 새로운 데이터를 "생성"할 수 있다 — 압축·복원만 하는 일반 AE와 VAE(생성 모델)의 결정적 차이다.

### 비유와 흔한 오해
- **비유**: 긴 문서를 3줄로 요약(압축)한 뒤, 다른 사람이 그 요약본만 보고 원래 문서를 거의 똑같이 다시 써내는 훈련을 반복하는 것과 같다.
- **오해**: 오토인코더가 "압축을 잘한다"고 항상 좋은 것은 아니다. 병목이 너무 넉넉하면(Overcomplete) 압축 없이 그대로 베끼는 항등 함수가 되어 아무 특징도 배우지 못하므로, 의도적으로 정보를 쥐어짜는 제약이 핵심이다.

## 연결 개념
- 비지도 학습 (Unsupervised Learning) — 라벨(Y) 없이 데이터(X) 자체의 패턴을 학습
- PCA (주성분 분석) — 오토인코더의 선형적인 조상격 차원 축소 기법
- VAE (Variational Autoencoder) — 압축된 벡터에 확률 분포를 더해 새로운 데이터를 생성하는 발전형(생성 모델)

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 단속, 수치/도식 활용)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 오토인코더는 입력을 압축된 잠재 공간(Latent Space)으로 변환한 후 원본과 동일하게 복원하는 비지도 기반 신경망 차원 축소 아키텍처이다.
> 2. **가치**: 정보의 병목(Bottleneck) 구조를 통해 데이터의 다차원 비선형 매니폴드(Manifold) 특징을 추출하여 노이즈 제거와 이상 탐지에 범용적으로 활용된다.
> 3. **판단 포인트**: 단순 데이터 복사(항등 함수화) 방지를 위해, 은닉층 차원을 축소(Undercomplete)하거나 노이즈 주입(Denoising), 규제항 추가(Sparse) 등의 제약 설계가 필수적이다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 비지도 기반 특징 추출(Representation Learning)의 원리 파악 | 병목 은닉층(Latent Z) 중심의 인코더-디코더 대칭 구조 | 단순 압축기로만 설명하고 "이상 탐지" 활용 가치를 누락 |
| 과적합(항등 변환) 방지 메커니즘 확인 | Denoising AE, Sparse AE 등 정규화 적용 기법 | 인코더와 디코더의 손실 함수(Loss) 구조 설명 생략 |
| VAE 등 최신 생성형 발전으로의 맥락 | 결정론적 압축(AE)과 확률론적 생성(VAE) 차이점 | 생성(GAN) 모델과 구조적 차이 혼동 |

> 요약: 정답 라벨 없이 데이터 구조 자체를 학습하는 비지도 원리를 묻고, 복원 오차(Reconstruction Error)를 역이용한 산업 현장의 이상 탐지 활용 역량을 평가한다.

## Ⅰ. 개요 및 필요성

- 정의: 입력 데이터 $X$를 저차원 특징 벡터 $Z$로 압축(Encoding)한 뒤, 이를 다시 $X$와 가장 유사한 $X'$로 재구성(Decoding)하는 인공 신경망
- 배경: 라벨링이 어려운 대규모 비정형 데이터 환경에서 PCA의 선형 한계를 극복할 비선형 특성 추출(Feature Extraction) 요구 증대
- 필요성: 노이즈에 강건한 데이터 복원 및 정상 패턴에만 매핑시켜 비정상 패턴을 튕겨내는(높은 복원 오차) 비지도 이상 탐지 솔루션

---

## Ⅱ. 구조 및 구성요소

```text
[입력 데이터 X] ---> (Encoder: 압축) ---> [Latent 벡터 Z (Bottleneck)] ---> (Decoder: 복원) ---> [출력 데이터 X']
      차원 D             가중치 W              차원 d (d << D)                가중치 W'             차원 D
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 인코더 (Encoder) | 입력 차원 D를 저차원 d로 맵핑 ($Z = f(W X + b)$) | 차원 축소를 통해 핵심 의미(Feature) 압축 |
| 잠재 공간 (Latent Space, $Z$) | 원본의 압축된 특징(Representation)을 담는 벡터 영역 | 네트워크 내 최소 차원(Bottleneck) 층 |
| 디코더 (Decoder) | 잠재 벡터 $Z$로부터 원본 크기 데이터 재생성 ($X' = g(W' Z + b')$) | 인코더와 대칭적인(Symmetric) 구조를 가짐 |
| 손실 함수 (Reconstruction Loss) | 입력 $X$와 출력 $X'$ 간의 차이 최소화 (MSE 또는 Cross Entropy) | $L(X, X') = \lVert X - X' \rVert^2$ (비지도 학습) |

> 요약: 인코더-병목-디코더의 모래시계형 구조가 입력값을 강제로 요약하게 만들어, 의미 없는 노이즈 정보가 병목을 통과하지 못하고 탈락되게 유도한다.

---

## Ⅲ. 동작원리 및 흐름도

```text
입력 X(정상 데이터) 투입 -> 병목 레이어로 비선형 축소(Z) -> 차원 재확장(X') 복원 -> MSE 오차 역전파 학습
```

| 단계 | 처리 내용 | 검증 기준 / 효과 |
|:---:|:---|:---|
| 1 | 데이터 입력 및 인코딩 연산 통과 | 다중 은닉층을 통한 매니폴드 구조 학습 |
| 2 | 병목층에서 압축 변수 Z 추출 (Information Bottleneck) | 항등 함수화 방지 (차원 축소 강제) |
| 3 | 디코딩 통한 데이터 X' 복원 | Z 맵핑 기반 공간 재구성 |
| 4 | X와 X' 간 Reconstruction 오차 산출 및 역전파 가중치 갱신 | 오차 감소(정상 패턴 암기 완료) |

> 요약: 정답 $Y$ 대신 입력 $X$ 자체를 정답으로 놓고 학습하며, 복원 오차가 작아지도록 훈련한 뒤, 테스트 시 오차가 큰 데이터를 불량(Anomaly)으로 규정한다.

---

## Ⅳ. 주요 파생형 특징 (정규화 기법)

| 파생 모델 | 특징적 제약 조건 | 핵심 활용 분야 |
|:---|:---|:---|
| Undercomplete AE | 병목 차원 수(d)를 입력(D)보다 작게 제한 | 기본 차원 축소 (PCA 비선형 대체) |
| Sparse AE | 은닉층 뉴런에 희소성(Sparsity) 규제(L1 등)를 주어 소수만 활성화 | 피처 중요도 파악, 분류 전처리 임베딩 |
| Denoising AE | 입력 이미지에 강제로 노이즈를 주입하고, 원본(Clean)으로 복원 | 영상 노이즈 제거, 데이터 강건성(Robust) 확보 |

> 요약: 모두 "그냥 똑같이 외우는 현상"을 막기 위한 장치들이며, 제약 조건에 따라 노이즈 제거기능이나 특성 맵핑 기법으로 파생 발전한다.

## Ⅴ. 심화 비교 및 적용 판단

| 구분 | Autoencoder (AE) | Variational Autoencoder (VAE) | 선택 기준 |
|:---|:---|:---|:---|
| 목적 | 데이터 차원 축소, 특징 추출, 이상 탐지 | 연속적인 Latent Space를 통한 **새로운 데이터 생성** | 기존 특징 활용 vs 신규 데이터 합성 |
| 잠재 변수(Z) 형태 | 단일 고정 벡터 (결정론적) | 평균($\mu$)과 분산($\sigma$)의 확률 분포 (확률론적) | 결과의 다양성 요구 |
| 손실 함수 | 복원 오차(Reconstruction Loss) | 복원 오차 + K-L Divergence(정규분포 맵핑 제약) | 생성 제어 가능성 |

> 요약: AE가 데이터를 요약해 저장하는 "압축기"라면, VAE는 압축 공간을 정규분포로 둥글게 다듬어 그 안에서 임의의 점을 뽑아 "창작"을 가능하게 한 생성 모델이다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 모드 붕괴(Identity Mapping) | 인코더-디코더 용량이 과대하여 압축 없이 데이터를 그대로 복사 | 차원 축소(Undercomplete), 노이즈 주입(Denoising) | Train/Validation 복원 오차 수렴 양상 |
| 미지 불량 탐지 실패 | 훈련 데이터에 노이즈/비정상 데이터가 오염됨 | One-class SVM 등 앙상블, 순수 정상 데이터 엄선 | 이상 탐지 AUROC / F1-Score |

> 요약: 훈련셋에 비정상(불량) 패턴이 섞여 들어가면 오토인코더가 불량마저 완벽히 복원해버리므로 이상 탐지 기능이 마비된다(Data Cleansing 필수).

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. 제조업 비전 이상 탐지: 정상 제품 이미지로만 오토인코더를 학습시킨 후, 신규 제품 검사 시 복원 오차(MSE) 픽셀 값이 임계치(Threshold)를 초과하는 부분을 불량 영역(스크래치)으로 자동 분류.
2. 카드 부정 사용 탐지(FDS): 수많은 피처를 가진 정상 결제 로그를 AE 병목 레이어로 축소(임베딩)하여 비지도 방식으로 패턴화하고, 복원 실패 건을 이상 거래로 Flagging.
3. 데이터 전처리 및 차원 축소: 1,000차원 이상의 텍스트/유전자 희소 데이터를 50차원 Latent 공간으로 인코딩한 뒤, 그 벡터를 XGBoost나 SVM의 입력으로 넘겨 분류 정확도 및 속도 30% 이상 향상.

**결론 (2줄):**
- 기술사 판단: 오토인코더는 데이터 레이블링 비용이 막대한 현실 산업에서 지도 학습의 한계를 극복하는 가장 실용적인 비지도 특징 추출기(Feature Extractor)이자 이상 탐지기이다.
- 향후 방향: 최근에는 단순 차원 축소를 넘어, VAE나 Diffusion 모델의 잠재 공간 처리 모듈(Latent Diffusion)로 흡수되어 거대 생성 AI의 핵심 병목 계층으로 진화하고 있다.
