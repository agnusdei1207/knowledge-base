# 📖 【암기용】 개념 완전 이해

> 목적: 오토인코더를 처음 보는 사람도 완전하게 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 입력을 압축 표현으로 줄였다가 다시 복원하도록 학습하는 비지도 신경망
- **왜 필요한가**: 라벨이 없는 데이터에서도 중요한 특징을 학습하고, 차원 축소·이상 탐지·노이즈 제거에 활용할 수 있다.
- **핵심 직관**: 원본을 그대로 외우지 못하도록 병목을 두고, 복원에 필요한 핵심 정보만 잠재공간에 담게 만드는 구조다.

## 깊이 이해
- **배경·문제의식**: 실제 시스템 로그·이미지·센서 데이터는 라벨 확보 비용이 크다. 오토인코더는 입력 자체를 정답으로 삼아 특징 표현을 학습한다.
- **작동 원리**: 인코더가 입력 x를 잠재벡터 z로 압축하고, 디코더가 z에서 x'를 복원한다. 학습 목표는 재구성 오차(MSE, BCE)를 최소화하는 것이다.
- **비유**: 긴 문서를 요약한 뒤 그 요약만 보고 원문에 가까운 내용을 다시 쓰게 하는 훈련과 같다. 좋은 요약은 핵심 구조를 보존한다.
- **구체 예시**: 784차원 MNIST 이미지를 32차원 잠재벡터로 압축하고 복원 MSE를 최소화한다. 정상 데이터만 학습한 뒤 복원 오차가 임계값 0.05를 넘으면 이상 후보로 분류한다.
- **흔한 오해·주의점**: 오토인코더는 무조건 압축률이 높을수록 유용한 것이 아니다. 잠재 차원이 너무 작으면 정보 손실이 커지고, 너무 크면 입력을 그대로 복사해 재구성 오차가 0에 수렴하여 정상·이상 구분 능력(ROC-AUC)이 0.5에 가까워진다.

## 연결 개념
- PCA — 선형 차원 축소 기준선
- VAE(Variational Autoencoder) — 확률 잠재공간을 학습하는 생성 모델
- 이상 탐지(Anomaly Detection) — 재구성 오차 기반 활용 분야

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 오토인코더(Autoencoder)는 입력을 잠재공간으로 인코딩한 뒤 다시 복원하며 재구성 오차를 최소화하는 비지도 신경망이다.
> 2. **가치**: 라벨 없는 데이터에서 차원 축소, 특징 학습, 노이즈 제거, 이상 탐지를 수행할 수 있다.
> 3. **판단 포인트**: 잠재 차원, 복원 손실, 정상 데이터 학습 범위, 임계값 설정, PCA·VAE와의 비교가 필요하다.

---

## Ⅰ. 개요 및 필요성

오토인코더는 입력을 압축 후 복원하는 신경망이다. 라벨 확보가 어려운 환경에서도 입력 자체를 정답으로 사용해 특징 표현을 학습할 수 있다. 재구성 오차를 활용하면 차원 축소, 노이즈 제거, 이상 탐지 문제에 적용 가능하다.

---

## Ⅱ. 구조 및 구성요소

```text
입력 x -> 인코더 -> 잠재벡터 z -> 디코더 -> 복원 x_hat
        +-> 병목 차원 통제       +-> 재구성 손실 계산
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 인코더 | 입력을 잠재벡터로 압축 | MLP, CNN, RNN 구조 가능 |
| 잠재공간 | 주요 표현 저장 | 784 -> 32차원 등 병목 설계 |
| 디코더 | 잠재벡터에서 입력 복원 | 출력 분포에 맞는 활성화 선택 |
| 재구성 손실 | 원본과 복원값 차이 측정 | MSE, BCE, MAE 사용 |

> 요약: 오토인코더는 인코더·잠재공간·디코더·재구성 손실로 입력의 압축 표현을 학습한다.

---

## Ⅲ. 동작원리 및 흐름도

```text
정상 데이터 입력 -> 잠재벡터 압축 -> 입력 복원
-> 재구성 오차 계산 -> 역전파 학습 -> 임계값 기반 판정
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 입력 전처리·정규화 | 결측·스케일 처리 완료 |
| 2 | 인코딩·디코딩 수행 | 잠재 차원과 출력 차원 확인 |
| 3 | 재구성 오차 계산 | MSE·BCE 분포 기록 |
| 4 | 임계값 판정 | ROC-AUC, Precision@K 측정 |

> 요약: 오토인코더는 정상 패턴을 복원하도록 학습하고 복원 오차가 큰 샘플을 이상 또는 정보 손실 후보로 판단한다.

---

## Ⅳ. 특징

| 구분 | 기존 방식 | 본 기술 | 수치·판단 포인트 |
|:---|:---|:---|:---|
| 학습 방식 | 지도학습은 라벨 필요 | 입력 자체를 정답으로 사용 | 라벨 0건에서도 학습 가능 |
| 차원 축소 | PCA는 선형 변환 | 비선형 잠재공간 학습 | latent 32/64/128 비교 |
| 이상 탐지 | 규칙 기반 임계값 | 재구성 오차 기반 | ROC-AUC, FPR 관리 |
| 한계 | 단순 모델은 표현 제한 | 과대용량이면 입력 복사 | bottleneck·regularization 필요 |

> 요약: 오토인코더는 라벨 없이 비선형 표현을 학습하지만 잠재 차원과 모델 용량을 통제해야 한다.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존/대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | PCA는 선형 투영 | Autoencoder는 비선형 인코더·디코더 | 비선형 패턴이면 Autoencoder |
| 비용/성능 | 규칙 기반 이상탐지는 설명 용이 | 복원 오차 기반 탐지 | 라벨 부족·패턴 복잡 시 선택 |
| 운영/위험 | 지도 모델은 라벨 관리 | 정상 데이터 품질 의존 | 정상 데이터 오염률 관리 필요 |

> 요약: 비선형 패턴과 라벨 부족 환경에서는 오토인코더를 검토하되 정상 데이터 품질이 선행 조건이다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 입력 복사 | 잠재 차원 과대 | bottleneck, sparsity, denoising 적용 | train/test 복원오차 차이 |
| 이상 누락 | 정상 데이터에 이상 포함 | 데이터 클렌징, robust threshold | FNR, recall |
| 임계값 오류 | 오차 분포 변화 | percentile·EVT 기반 재산정 | drift score, FPR |

> 요약: 오토인코더 이상 탐지는 모델 용량, 정상 데이터 오염, 임계값 drift를 통제해야 한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 복원 품질 | MSE·BCE 목표 범위 충족 | 검증 세트 재구성 오차 |
| 탐지 품질 | ROC-AUC, Precision@K 목표 충족 | 라벨 샘플 또는 전문가 검수 |
| 운영 감시 | 오차 분포 drift 임계값 관리 | PSI, KS test, 모니터링 |

> 요약: 복원 품질, 탐지 품질, 오차 분포 drift를 함께 봐야 운영 가능한 오토인코더를 판단할 수 있다.

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 — 단계별 또는 항목별):**
1. 정상 데이터만 선별해 학습하고 latent dimension 16/32/64를 비교해 검증 MSE와 ROC-AUC를 함께 평가함.
2. 이상 탐지는 재구성 오차 95~99 percentile 임계값과 전문가 검수 라벨로 FPR·FNR을 보정함.
3. 운영 단계는 오차 분포 PSI 0.2 초과 시 재학습 후보로 등록하고 데이터 drift 원인을 분석함.

**결론 (2줄):**
- 기술사 판단: 라벨 부족·비선형 정상 패턴이면 오토인코더, 선형 차원 축소·설명 우선이면 PCA를 선택함.
- 향후 방향: VAE, Denoising Autoencoder, Self-Supervised Learning과 결합해 표현 학습과 이상 탐지 정확도를 개선함.
