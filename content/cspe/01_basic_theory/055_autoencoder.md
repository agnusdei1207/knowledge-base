## 미리 알고가기

- encoder: 입력을 잠재 표현으로 압축하는 부분임
- latent vector: 핵심 정보만 담긴 저차원 표현임
- decoder: 잠재 표현에서 원본을 복원하는 부분임

## Ⅰ. 개요

- **정의/개념**: 오토인코더는 입력을 잠재 공간으로 압축한 뒤 다시 복원하도록 학습해 데이터의 핵심 특징을 스스로 추출하는 비지도 신경망임
- **배경/필요성**: 라벨 없이도 차원 축소, 노이즈 제거, 특징 추출을 수행하려면 입력 자체를 학습 목표로 삼는 구조가 필요함

## Ⅱ. 특징

- 입력 재구성을 통해 중요한 패턴을 압축 표현으로 학습함
- 차원 축소와 비선형 특징 추출에 유용함
- 재구성 오차를 이상탐지 지표로 활용할 수 있음
- 너무 큰 잠재 공간은 단순 복사에 가까워져 의미 있는 압축이 약해질 수 있음

## Ⅲ. 종류 및 비교

| 판단 기준 | PCA | 기본 오토인코더 | Variational Autoencoder |
|:---|:---|:---|:---|
| 선형성 | 선형 | 비선형 | 비선형 + 확률 |
| 목표 | 분산 보존 | 재구성 | 재구성 + 분포 학습 |
| 생성 능력 | 약함 | 제한적 | 있음 |
| 대표 적용 | 전처리 | 특징 추출 | 생성 모델 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 인코더 | 입력을 축약하고 특징 추출부임 |
| 잠재 공간 | 정보가 압축된 표현이며 의미 표현 품질 핵심임 |
| 디코더 | 원본을 재구성하고 복원 능력을 측정함 |
| 재구성 손실 | 입력과 출력 차이를 계산하고 학습 목표임 |

```text
+-----------+     +-----------+     +-----------+     +---------------+
| 인코더      | --> | 잠재 공간    | --> | 디코더      | --> | 재구성 손실    |
+-----------+     +-----------+     +-----------+     +---------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 입력인코딩 | --> | 잠재표현 생성 | --> | 복원디코딩 | --> | 오차최소화 |
+----------+     +----------+     +----------+     +----------+
```

1. **입력인코딩**: 원본 데이터를 저차원 표현으로 압축함
2. **잠재표현 생성**: 핵심 특징만 남긴 벡터를 만듦
3. **복원디코딩**: 잠재 벡터에서 입력을 재구성함
4. **오차최소화**: 재구성 손실을 줄이도록 학습함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 단순 복사 학습으로 전락할 수 있어 잠재 공간이 너무 넓거나 모델이 과도하게 큼
   - 해결방안: bottleneck, sparsity, denoising 제약을 적용하고 latent dimension efficiency로 검증함
2. 문제: 잠재 표현 해석이 어려워 특징 의미가 명확하지 않을 수 있음
   - 해결방안: disentanglement 제약이나 시각화를 병행하고 cluster separability로 검증함
3. 문제: 재구성 오차만으로 품질을 평가하면 한계가 있어 의미 보존 여부와 다를 수 있음
   - 해결방안: downstream task 성능을 함께 평가하고 representation quality로 검증함

## Ⅶ. 적용 사례

- 이상탐지에서는 정상 데이터만 학습해 높은 재구성 오차를 이상으로 판단함, 확인 지표는 AUC임
- 이미지 노이즈 제거에서는 깨진 입력을 복원하도록 학습함, 확인 지표는 PSNR임
- 특징 압축에서는 고차원 센서 데이터를 저차원으로 줄임, 확인 지표는 reconstruction error임

## Ⅷ. 결론

오토인코더의 핵심은 재구성 자체가 아니라 의미 있는 잠재 표현을 만드는 데 있으므로, 압축 강도와 표현 품질을 함께 통제해야 함.
