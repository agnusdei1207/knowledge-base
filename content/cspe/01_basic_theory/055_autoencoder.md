## 미리 알고가기

- 자기지도 학습: 입력 데이터 자체에서 학습 목표를 만들어 별도 라벨 없이 학습하는 방식임
- 잠재 공간: 고차원 입력을 복원에 필요한 특징으로 변환한 저차원 표현 공간임
- 재구성 오차: 입력 $x$와 복원 출력 $\hat{x}$의 차이를 나타내는 손실값임
- 병목 구조: 중간 표현 차원을 제한해 입력 정보를 그대로 복사하지 못하게 하는 구조임
- 디노이징: 노이즈가 섞인 입력에서 원래 신호를 복원하도록 학습하는 방식임
- 항등 함수: 입력을 변형하지 않고 그대로 출력해 유용한 잠재 표현을 만들지 못하는 함수임
- 변이형 오토인코더(VAE): 잠재 벡터를 확률분포로 학습해 새 샘플을 생성하는 오토인코더임
- 쿨백-라이블러 발산(KL Divergence): 학습한 잠재 분포와 기준 분포의 차이를 측정하는 값임
- 희소 규제: 잠재 벡터의 일부 값만 활성화되도록 제약해 핵심 특징을 분리하는 방식임
- 주성분 분석(PCA): 데이터 분산을 많이 보존하는 선형 축으로 차원을 줄이는 기법임

## 쉽게 이해하기
- 긴 문장을 짧게 요약했다가 다시 원래 문장으로 복원하는 연습을 반복하면 요약본에 문장의 핵심만 남는 것과 같음
- 평소와 달리 잘 복원되지 않는 입력은 이상 신호로 볼 수 있음

## 작성 근거(검토용)

- 개요는 인코더·디코더 구조를 정의에, 라벨 부족 문제를 배경에 담아 구조와 목적을 구분함
- 특징은 라벨 불필요, 병목, 비선형 압축, 이상 탐지로 활용 근거를 나눔
- 비교표는 기본형, 디노이징, 변이형의 학습 메커니즘·표현 제약·주요 리스크를 비교함
- 구성요소는 입력·인코더·잠재 벡터·디코더·재구성 손실의 복원 메커니즘으로 압축함
- 절차는 입력을 목표로 쓰는 점부터 오차 최소화까지 학습 원리를 보이게 함
- 정상 데이터의 대표성과 잠재 차원은 이상 탐지 성능을 좌우하는 핵심 조건임

## Ⅰ. 개요

- **정의/개념**: 오토인코더는 인코더가 입력을 잠재 벡터로 압축하고 디코더가 이를 복원하도록 학습해 데이터 표현을 얻는 신경망 구조임
- **배경/필요성**: 라벨이 부족한 데이터에서 특징 추출·노이즈 제거·이상 탐지를 수행하려면 라벨 없이 학습할 자기지도 구조가 필요함

## Ⅱ. 특징

- 입력과 출력 목표를 같게 두어 라벨 없이 재구성 오차를 줄이는 표현을 학습함
- 병목 구조와 규제로 입력을 그대로 복사하지 못하게 하고 복원에 필요한 특징을 잠재 벡터에 담도록 유도함
- 비선형 활성화를 사용해 원본 변수를 선형 결합하는 PCA와 다른 비선형 표현을 학습함
- 정상 데이터와 다르게 복원되는 샘플은 재구성 오차가 커져 이상 탐지 신호가 됨

## Ⅲ. 종류 및 비교

| 판단 기준 | 기본 오토인코더 | 디노이징 오토인코더 | 변이형 오토인코더 |
|:---|:---|:---|:---|
| 학습 메커니즘 | 원본 입력 복원 | 오염 입력의 원본 복원 | 잠재 분포 기반 생성 |
| 표현 제약 | 병목 차원 | 입력 노이즈 | KL 분포 제약 |
| 주요 리스크 | 항등 함수 학습 | 원본 정보 손실 | 잠재 변수 무시 |

> 요약: 기본형은 입력 압축, 디노이징은 잡음 제거, 변이형은 샘플을 생성할 잠재 분포 학습에 초점이 있음.

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 입력·복원 목표 | 인코더에 넣는 데이터와 디코더 출력의 비교 대상 |
| 인코더 | 입력의 잠재 표현 압축 |
| 잠재 벡터 $z$ | 복원 특징의 압축 표현 |
| 디코더 | 잠재 벡터의 원본 복원 |
| 재구성 손실 | $x$와 $\hat{x}$의 차이 |

> 요약: 오토인코더는 입력을 잠재 벡터로 압축·복원하고 재구성 오차로 표현을 학습함.

## Ⅴ. 원리 및 절차 흐름도

```text
입력·목표 x → 인코딩·디코딩 → 복원값 x̂
                                  ↓
                         재구성 손실 계산
                                  ↓
                    인코더·디코더 역전파 갱신
                         ├─ 미수렴 → 다음 배치 반복
                         └─ 수렴 → 잠재 표현 활용
```

1. **입력 제공**: 학습 데이터 $x$를 입력과 목표값으로 동시에 사용함
2. **잠재 압축**: 인코더가 복원 손실을 줄이는 특징을 잠재 벡터 $z$로 변환함
3. **원본 복원**: 디코더가 $z$에서 원본과 유사한 $\hat{x}$를 생성함
4. **오차 최소화**: 재구성 손실을 줄이도록 인코더와 디코더를 함께 갱신함

> 요약: 병목과 규제로 입력 복사를 제한하고 재구성 오차를 줄이는 잠재 표현을 학습함.

## Ⅵ. 실무 사례

1. 서버 이상 탐지는 정상 지표로 오토인코더를 학습하고 재구성 오차가 큰 관측값을 이상으로 분류함
2. 고차원 서버 지표는 병목 계층을 거쳐 낮은 차원의 잠재 벡터로 압축함

## Ⅶ. 결론

- 오토인코더는 입력 복원으로 잠재 표현을 학습하므로 병목 크기와 재구성 오차 임계값을 목적에 맞게 정해야 함
- 이상 탐지는 정상 분포 변화에 따라 임계값을 재보정하고, 재구성이 쉬운 이상 데이터는 별도 탐지 규칙으로 보완해야 함
