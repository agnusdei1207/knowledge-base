# 오토인코더 (Autoencoder)

## 1. 개요

- **정의/개념**: 오토인코더는 입력을 잠재 표현으로 압축하는 인코더와 다시 원본에 가깝게 복원하는 디코더를 학습해 데이터의 핵심 표현을 얻는 신경망 구조이다.
- **배경/필요성**: 라벨이 부족한 상황에서도 데이터의 구조를 학습하고 차원 축소, 노이즈 제거, 이상 탐지에 활용하기 위해 자기복원 기반 학습이 필요하다.

오토인코더의 핵심은 정답 라벨이 아니라 입력 자체를 복원 목표로 삼아 latent representation을 학습하는 것이다.

## 2. 특징 및 비교

| 구분 | PCA | Autoencoder | VAE |
|---|---|---|---|
| 변환 | 선형 | 비선형 가능 | 확률적 latent |
| 목표 | 분산 보존 | 재구성 오차 최소화 | 생성 가능성 포함 |
| 해석성 | 상대적으로 높음 | 낮을 수 있음 | 분포 해석 가능 |
| 활용 | 차원 축소 | 압축·이상 탐지 | 생성 모델 |

선택 기준은 비선형 구조, 재구성 품질, latent 해석성, 과적합 위험, 생성 필요성이다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| Encoder | 입력을 latent vector로 압축 | 특징 추출 |
| Bottleneck | 낮은 차원 표현 | 정보 압축 |
| Decoder | latent에서 입력 복원 | 재구성 |
| Reconstruction Loss | 입력과 복원값 차이 | 학습 목표 |
| Latent Space | 압축 표현 공간 | 활용 대상 |

```text
+--------+      +---------+      +----------+      +--------+
| Input  | ---> | Encoder | ---> | Latent   | ---> | Decoder |
+--------+      +---------+      +----------+      +--------+
                                           복원값과 입력 비교
```

복원 오차가 작다는 것은 입력 구조를 잘 표현했다는 신호이지만, 그것이 항상 유용한 의미 표현을 보장하지는 않는다.

## 4. 문제점 및 개선방안

1. **단순 복사 학습**
   - 모델 용량이 너무 크면 의미 있는 압축 없이 입력을 그대로 복사할 수 있다.
   - **개선방안**: bottleneck, sparsity, denoising, regularization을 적용한다.

2. **이상 탐지 기준 불안정**
   - 이상 데이터도 잘 복원하면 재구성 오차 기반 탐지가 실패한다.
   - **개선방안**: 정상 데이터 중심 학습, threshold 검증, latent distance를 함께 사용한다.

3. **해석성 부족**
   - latent vector 각 차원의 의미가 명확하지 않을 수 있다.
   - **개선방안**: latent 시각화, disentanglement, 도메인 feature와 비교한다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| 이상 탐지 | 정상 데이터로 학습 후 재구성 오차로 이상 판단 | recall, false alarm |
| 차원 축소 | latent vector를 downstream 모델 입력으로 사용 | 성능 변화, 압축률 |
| 노이즈 제거 | noisy input에서 clean output 복원 학습 | PSNR, 복원 오차 |

## 6. 결론

오토인코더는 입력 복원을 통해 데이터의 잠재 표현을 학습하는 구조이다. Encoder-Bottleneck-Decoder와 재구성 손실을 연결해 설명해야 차원 축소, 이상 탐지, 노이즈 제거 활용의 기준이 분명해진다.
