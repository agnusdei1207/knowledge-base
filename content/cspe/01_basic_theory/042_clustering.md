# 클러스터링 - K-Means·DBSCAN (Clustering)

## 1. 개요

- **정의/개념**: 클러스터링은 정답 라벨 없이 데이터 간 유사도와 거리 구조를 기준으로 유사한 객체를 같은 그룹으로 묶는 비지도 학습 기법이다.
- **배경/필요성**: 고객 세분화, 이상 탐지, 문서 군집처럼 사전 라벨이 없지만 데이터 구조를 파악해야 하는 업무에서 패턴 발견이 필요하다.

클러스터링은 "정답 분류"가 아니라 데이터 구조를 가정하고 드러내는 분석이므로 거리 정의와 군집 형태가 핵심이다.

## 2. 특징 및 비교

| 구분 | K-Means | DBSCAN | 계층적 군집 |
|---|---|---|---|
| 기준 | 중심점 거리 | 밀도 연결성 | 병합·분할 구조 |
| 군집 수 | K 사전 지정 | 자동 형성 가능 | cut 기준 필요 |
| 강점 | 빠르고 단순 | 이상치 탐지, 비구형 군집 | 계층 구조 해석 |
| 약점 | 구형 군집 가정 | 파라미터 민감 | 계산 비용 |

선택 기준은 군집 형태, 이상치 존재, 거리 척도, 차원 수, 군집 수 사전 지식이다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| Feature Space | 군집을 나눌 변수 공간 | 스케일링 필요 |
| Distance Metric | 유사도·거리 계산 기준 | 유클리드, 코사인 |
| Cluster Criterion | 군집 형성 규칙 | 중심, 밀도, 계층 |
| Parameter | K, eps, minPts 등 | 결과 민감도 |
| Validation Metric | 군집 품질 평가 | silhouette, DBI |

```text
+----------+      +----------+      +----------+      +----------+
| 특징공간 | ---> | 거리계산 | ---> | 군집형성 | ---> | 품질검증 |
+----------+      +----------+      +----------+      +----------+
```

거리 계산이 잘못되면 이후 군집 형성은 그 오류를 확대하므로 전처리와 척도 선택이 구조의 출발점이다.

## 4. 문제점 및 개선방안

1. **거리 척도 부적합**
   - 스케일이 다른 변수나 희소 벡터에 유클리드 거리를 그대로 쓰면 군집이 왜곡된다.
   - **개선방안**: 표준화, cosine distance, 도메인 기반 거리 함수를 적용한다.

2. **파라미터 민감성**
   - K, eps, minPts 선택에 따라 결과가 크게 달라진다.
   - **개선방안**: elbow, silhouette, k-distance plot으로 후보를 검증한다.

3. **고차원 희소성**
   - 차원이 높으면 거리 차이가 작아져 군집 의미가 약해질 수 있다.
   - **개선방안**: PCA, feature selection, embedding을 적용한다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| 고객 세분화 | 구매·방문 특성으로 유사 고객 그룹 생성 | silhouette, 매출 차이 |
| 이상 탐지 | DBSCAN으로 밀도 낮은 점을 이상치로 식별 | 탐지율, 오탐률 |
| 문서 군집 | 임베딩 벡터를 유사도 기준으로 묶음 | 군집 일관성 |

## 6. 결론

클러스터링은 라벨 없는 데이터에서 구조를 찾는 비지도 학습 기법이다. 군집 결과는 거리 척도, 전처리, 파라미터, 검증 지표에 의해 결정되므로 알고리즘 이름보다 데이터 구조와 선택 기준을 먼저 설명해야 한다.
