## 미리 알고가기

- **비지도 학습 (Unsupervised Learning)**: 정답(Label)이 없는 상태에서 데이터 자체의 특성과 구조를 분석하여 패턴을 찾아내는 학습 방식
- **거리 척도 (Distance Metric)**: 데이터 간의 유사성을 측정하는 기준. 유클리드(직선), 코사인(각도), 맨해튼 거리 등이 사용됨
- **실루엣 계수 (Silhouette Coefficient)**: 군집 내 응집도와 군집 간 분리도를 수치화한 지표. 1에 가까울수록 군집화가 잘 된 것임

## Ⅰ. 개요

- **정의/개념**: 클러스터링(Clustering)은 데이터 간의 유사도(Similarity)를 기준으로 전체 데이터를 유사한 속성을 가진 여러 개의 그룹(Cluster)으로 묶는 비지도 학습 기법임. 같은 군집에 속한 데이터는 서로 비슷하고, 다른 군집에 속한 데이터는 이질적이 되도록 만듦
- **배경/필요성**: 현실 세계의 많은 데이터는 사전에 정답이 매겨져 있지 않음. 수백만 명의 고객 구매 이력에서 숨겨진 패턴을 찾아 세분화하거나, 수많은 뉴스 기사 중 비슷한 주제를 묶고, 로그 데이터에서 평소와 다른 이상 징후를 발견하기 위해서는 데이터의 기하학적 분포를 스스로 파악하는 클러스터링 기술이 필수적임

## Ⅱ. 특징 및 비교

### 가. K-Means와 DBSCAN 알고리즘의 핵심 비교

| 구분 | K-Means (중심 기반) | DBSCAN (밀도 기반) |
|:---|:---|:---|
| 핵심 원리 | 각 군집의 중심점(Centroid)과 거리 최소화 | 데이터의 밀집 정도(Density)와 연결성 활용 |
| 군집 수 (K) | 사전에 K 값을 지정해야 함 | 파라미터($\epsilon$, MinPts)에 의해 자동 결정 |
| 군집 형태 | 구형(Spherical) 군집에 유리 | 비구형, 기하학적 형태의 군집도 잘 찾아냄 |
| 이상치 처리 | 이상치에 민감함 (중심이 크게 흔들림) | 노이즈(Noise)를 별도로 구분하여 제거 가능 |
| 연산 속도 | 매우 빠르고 단순함 | 상대적으로 느리며 메모리 사용량이 많음 |

> 요약: 정형화된 군집을 빠르게 찾으려면 K-Means, 복잡한 형태와 이상치 제거가 중요하면 DBSCAN을 선택함

### 나. 클러스터링의 주요 판단 기준
- **응집도 (Cohesion)**: 군집 내부의 데이터들이 얼마나 촘촘하게 모여 있는가
- **분리도 (Separation)**: 서로 다른 군집들이 얼마나 멀리 떨어져 있는가
- **차원의 저주**: 차원이 너무 높으면 모든 데이터 간 거리가 비슷해져 군집화 효율이 급감함

## Ⅲ. 구성요소/구조

### 가. 클러스터링 수행 메커니즘 (K-Means 기준)

```text
[초기 중심점 설정] -> [데이터 할당] -> [중심점 재계산] -> [수렴 여부 확인]

1. 임의의 K개 중심점(Centroid) 선택
2. 모든 데이터를 가장 가까운 중심점에 할당하여 군집 형성
3. 형성된 군집 내부의 평균값으로 중심점을 새롭게 갱신
4. 중심점의 이동이 거의 없을 때까지 2~3단계 반복
```

### 나. 주요 구성 요소 및 역할

| 구성요소 | 역할 및 설명 | 핵심 포인트 |
|:---|:---|:---|
| 특징 공간 (Feature Space) | 데이터가 놓이는 좌표 평면 | 스케일링(Scaling)이 거리 계산에 절대적 영향 |
| 하이퍼파라미터 | 모델의 구조를 결정하는 설정값 | K, $\epsilon$(반경), MinPts(최소 이웃 수) |
| 중심점 (Centroid) | 각 군집을 대표하는 가상의 중앙 위치 | 초기값 설정(K-Means++)이 결과에 영향 |
| 밀도 (Density) | 반경 $\epsilon$ 내에 존재하는 데이터의 밀집도 | 핵심 포인트(Core Point) 판별 기준 |
| 품질 지표 (Validation) | 군집화 결과의 정량적 평가 기준 | 실루엣 점수, 엘보우(Elbow) 기법 |

> 요약: 거리 정의와 파라미터 설정이 군집의 경계와 개수를 결정하는 핵심 동인임

## Ⅳ. 문제점 및 개선방안

1. **파라미터 선정의 어려움**: 적절한 K값이나 밀도 반경을 찾는 것은 분석가의 주관에 의존하기 쉬움
   - **개선방안**: Elbow Method(SSE 급감 지점)나 Silhouette Analysis를 통해 통계적으로 최적의 지점을 찾고, 도메인 지식을 결합함

2. **변수 스케일에 의한 왜곡**: 변수 간 단위 차이가 크면 특정 변수가 거리 계산을 지배함
   - **개선방안**: 모든 독립 변수에 대해 표준화(Standardization) 또는 정규화(Normalization)를 선행하여 기여도를 균등하게 맞춤

3. **초기 중심점 민감도**: K-Means의 경우 처음에 잡힌 중심점 위치에 따라 지역 최적점(Local Optima)에 빠질 수 있음
   - **개선방안**: 중심점 간 거리를 최대한 멀리 배치하는 'K-Means++' 초기화 기법을 사용하거나, 여러 번 반복 수행하여 최상의 결과를 선택함

## Ⅴ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| 마케팅 고객 세분화 | 구매 금액, 주기, 최근 방문일(RFM) 기반으로 고객 등급 분류 | 군집별 매출 기여도, 실루엣 점수 |
| 사이버 보안 이상 탐지 | 평상시 트래픽 밀도와 동떨어진 데이터를 노이즈로 식별하여 차단 | 오탐률(False Positive), 미탐률 |
| 생물 정보학 | 유사한 유전자 발현 패턴을 가진 세포군을 묶어 질병 연관성 분석 | 유전적 유사도, 생물학적 유의성 |

> 요약: 정답이 없는 데이터에서 '숨겨진 질서'를 찾아내어 의사결정의 그룹핑 기준으로 활용함

## Ⅵ. 결론

클러스터링은 복잡한 데이터 바다에서 유사성이라는 밧줄로 의미 있는 섬(Cluster)들을 만들어내는 핵심적인 비지도 학습 도구임. 단순히 알고리즘을 돌리는 것을 넘어, 거리 척도의 정의와 전처리가 결과에 미치는 결정적인 영향을 이해하는 것이 실무의 핵심임.

기술사는 데이터의 분포 특성(구형 vs 밀집형)에 따라 최적의 알고리즘을 선택할 수 있어야 하며, 클러스터링의 결과가 비즈니스적으로 어떤 해석력을 갖는지(Explainability) 제시할 수 있어야 함. 또한, 고차원 데이터의 경우 차원 축소 기법(PCA 등)과 클러스터링을 결합하여 분석의 신뢰성을 높이는 통합적 접근이 요구됨.
