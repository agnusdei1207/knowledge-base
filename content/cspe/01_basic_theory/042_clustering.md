## Ⅰ. 개요
- **정의**: 레이블 없는 데이터를 유사도 기준으로 동질 집단으로 자동 분류하는 비지도 학습 기법
- **배경/필요성**: 고객 세분화·이상 탐지 등에서 사전 라벨 없이 데이터 내재 구조를 발견할 필요
- **비유**: 색깔 표시 없는 구슬을 비슷한 크기·질감끼리 그릇에 나누는 작업

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| K-Means vs DBSCAN 비교 | 중심점 기반 vs 밀도 기반 원리 차이 | K 값 결정법(Elbow/Silhouette) 미언급 감점 |
| 비지도 학습 적용 역량 | 군집 평가 지표(Silhouette 계수) | DBSCAN의 eps·minPts 파라미터 설명 누락 |

> 요약: 클러스터링은 비지도 학습으로 데이터 내재 구조를 그룹화하는 기법임

## Ⅱ. 구성요소
```text
+------------+     +---------------+     +------------+
| Unlabeled  |     | Clustering    |     | K Clusters |
| Data (N)   | --> | Algorithm     | --> | (C1..Ck)   |
+------------+     +---------------+     +------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 중심점(Centroid) | K-Means에서 각 군집을 대표하는 가상 좌표 | 조장 |
| eps/minPts | DBSCAN의 반경 기준·최소 점 수 밀도 파라미터 | 이웃 판정 기준 |
| 거리 함수 | 데이터 간 유사성 산출(유클리드, 코사인 등) | 친밀도 자 |

> 요약: 중심점·밀도 파라미터·거리 함수로 데이터를 동질 그룹으로 분할함

## Ⅲ. 절차
```text
+------------+     +------------+     +------------+     +------------+
| Init       |     | Distance   |     | Assign     |     | Update     |
| (K/eps)    | --> | Calc       | --> | Cluster    | --> | Centroid   |
+------------+     +------------+     +------------+     +------------+
```

1. **초기화** — K-Means: K개 초기 중심점 랜덤 배치 / DBSCAN: eps·minPts 설정
2. **거리 계산** — 각 데이터와 중심점(또는 이웃 점) 간 유클리드 거리 산출
3. **군집 할당** — 최근접 중심점에 배정(K-Means) 또는 밀도 도달 점을 군집에 편입(DBSCAN)
4. **갱신/수렴** — 중심점을 군집 평균으로 재계산, 변화 없을 때까지 2~3 반복

> 요약: 초기화 → 거리 산출 → 할당 → 갱신 반복으로 군집을 형성함

## Ⅳ. 문제점
- K 값 사전 설정: K-Means는 군집 수를 사전에 지정해야 하나 최적 K를 모르는 경우가 대부분
- 구형 군집 제약: K-Means는 유클리드 기반이므로 비구형·비등방 분포에 부적합
- 밀도 불균일: DBSCAN은 군집 간 밀도 차이가 크면 동일 eps로 탐지 불가

> 요약: K 결정·형태 제약·밀도 불균일이 클러스터링의 3대 약점임

## Ⅴ. 개선방안
1. 단기: Elbow Method·Silhouette 분석으로 최적 K 탐색
2. 중기: 비구형 군집에 Spectral Clustering 또는 GMM(가우시안 혼합) 적용
3. 장기: OPTICS·HDBSCAN으로 밀도 가변 데이터의 자동 군집 탐지

- 대규모 데이터 지연: N² 거리 계산 → Mini-Batch K-Means 적용 (지표: 10만 건 이상 처리 시간 50% 감소)

> 요약: K 탐색 자동화 → 비구형 모델 전환 → 밀도 적응 알고리즘으로 대응함

## Ⅵ. 전망
- 향후 발전 방향: 오토인코더 임베딩 + 클러스터링을 결합한 딥 클러스터링으로 고차원 군집화
- 기술사적 판단: K-Means는 해석성과 속도 면에서 1차 탐색 도구로 존속, 복잡 구조는 HDBSCAN 우위
- 기술사 제언: 데이터 분포 시각화(t-SNE/UMAP) 후 형태에 맞는 알고리즘 선정 필요
