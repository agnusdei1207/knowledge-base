## 미리 알고가기

- 클러스터링($Clustering$): 정답 라벨 없이 유사한 데이터를 같은 그룹으로 묶는 비지도 학습임
- 거리 척도(Distance Metric): 두 데이터가 얼마나 가까운지 계산하는 기준임
- 중심점($Centroid$): K-Means에서 군집을 대표하는 평균 위치임
- 밀도($Density$): 일정 반경 안에 데이터가 얼마나 모여 있는지 나타내는 기준임
- 실루엣 계수: 군집 내부 응집도와 군집 간 분리도를 함께 보는 품질 지표임
- 반경($\varepsilon$): DBSCAN에서 이웃으로 인정할 최대 거리임
- 최소 이웃 수($MinPts$): DBSCAN에서 핵심점으로 인정할 반경 내 최소 데이터 수임

## 작성 근거(검토용)

- K-Means와 DBSCAN을 중심에 두되 계층적 군집화를 보조 비교 대상으로 포함해 선택 폭을 분명히 함
- 거리와 밀도 기준을 반복 축으로 삼아 특징·구조·절차가 같은 판단 체계를 갖게 함
- 스케일 민감도는 거리 기반 군집화의 대표 실패 원인이므로 선행 용어와 사례에 반영함
- 품질 지표를 정답률이 아닌 응집도·분리도·업무 해석으로 잡아 비지도 학습의 평가 특성을 드러냄
- 보안 이상 탐지는 DBSCAN의 노이즈 처리 장점을 설명하기 적합해 실무 예시로 선택함

## Ⅰ. 개요

- **정의/개념**: 클러스터링은 라벨 없는 데이터의 거리, 밀도, 연결 관계를 기준으로 유사한 객체를 군집으로 나누는 비지도 학습 기법임
- **배경/필요성**: 정답이 없는 데이터의 숨은 구조를 찾아 후속 분석 기준을 세우기 위해 군집화가 필요함

## Ⅱ. 특징

- 라벨이 없어도 데이터의 자연스러운 묶음을 찾으므로 탐색적 분석과 사전 라벨 설계에 적합함
- 거리 기반 모델은 스케일과 차원 수에 민감하므로 전처리 품질이 군집 결과를 좌우함
- 군집 수나 밀도 기준을 잘못 정하면 같은 데이터도 전혀 다른 그룹으로 분리됨
- 군집 품질은 정답률보다 응집도, 분리도, 도메인 해석 가능성으로 판단함

## Ⅲ. 종류 및 비교

| 기준 | K-Means | DBSCAN | 계층적 군집화 |
|:---|:---|:---|:---|
| 군집 결정 | 군집 수 $k$ 사전 지정 | 밀도 연결로 자동 확장 | 병합 또는 분할 순서로 결정 |
| 군집 모양 | 원형·구형에 적합 | 비정형 모양에 적합 | 덴드로그램 절단 위치에 좌우 |
| 이상치 처리 | 모든 점을 군집에 포함 | 노이즈 점으로 제외 가능 | 이상치가 병합 구조를 왜곡함 |
| 주요 파라미터 | $k$·초기 중심점 | $\varepsilon$·$MinPts$ | 거리 기준·연결 방식 |
| 대표 적용 사례 | 고객 세분화·문서 군집 | 위치 이상 탐지·공간 밀집 구역 탐색 | 생물 분류·고객군 계층 분석 |
| 적합 조건 | 군집 수와 구형 구조가 예상되는 데이터 | 밀도 차가 뚜렷하고 노이즈가 많은 데이터 | 군집 계층 해석이 필요한 데이터 |

> 요약: K-Means는 빠른 분할, DBSCAN은 노이즈 분리, 계층적 군집화는 관계 구조 해석에 유리함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 특징 행렬 | 각 객체를 수치 벡터로 표현하며 군집 계산의 입력이 됨 |
| 거리·밀도 기준 | 데이터 간 가까움이나 밀집 정도를 계산해 군집 경계를 정함 |
| 군집 할당 규칙 | 중심점 최소 거리 또는 밀도 연결 조건으로 객체 소속을 결정함 |
| 품질 지표 | 실루엣 계수·$SSE$·도메인 해석으로 군집 결과를 검증함 |

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 특징 행렬 | --> | 기준 계산 | --> | 군집 할당 | --> | 품질 평가 |
+-----------+     +-----------+     +-----------+     +-----------+
```

> 요약: 클러스터링은 특징 표현과 거리·밀도 기준이 군집 경계를 직접 결정함.

## Ⅴ. 원리 및 절차 흐름도

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 전처리    | --> | 알고리즘 선택 | --> | 군집 생성 | --> | 해석 검증 |
+-----------+     +-----------+     +-----------+     +-----------+
```

1. **전처리** — 결측치와 이상치를 정리하고 거리 왜곡을 줄이기 위해 표준화 또는 정규화를 수행함
2. **기준 선택** — 군집 수를 알면 K-Means, 노이즈와 비정형 모양이 중요하면 DBSCAN을 선택함
3. **군집 생성** — 거리 최소화나 밀도 연결 규칙에 따라 객체를 반복적으로 재배치함
4. **해석 검증** — 실루엣 계수와 업무 의미를 함께 확인해 군집이 실제 의사결정에 쓸 수 있는지 판단함

> 요약: 군집 결과는 수치 지표와 도메인 해석이 함께 일치해야 후속 분석 기준으로 쓸 수 있음.

## Ⅵ. 실무 사례

1. 고객 세분화는 금액·빈도·최근성의 단위가 다르면 K-Means 중심점이 왜곡되므로 스케일링 후 실루엣 계수와 세그먼트 해석을 함께 확인함
2. 보안 이상 탐지에서는 DBSCAN의 $\varepsilon$이 작으면 정상도 노이즈가 되므로 $k$-거리 그래프로 후보 값을 정하고 탐지율과 오탐률을 함께 검증함

## Ⅶ. 결론

- 클러스터링은 정답 없는 데이터의 구조를 만드는 기법이므로 거리 기준·파라미터·해석 가능성을 함께 검증해야 함
