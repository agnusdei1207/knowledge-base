## 미리 알고가기

- 비지도 학습: 정답 라벨 없이 데이터의 구조나 패턴을 찾는 학습 방식임
- 거리·유사도: 두 데이터가 얼마나 가깝거나 비슷한지 계산하는 기준임
- 중심 기반 군집: 군집 중심과의 거리로 소속을 결정하는 방식임
- 밀도 기반 군집: 점이 충분히 몰린 영역을 하나의 군집으로 보는 방식임
- 군집 평가: 라벨 없이 군집 응집도와 분리도를 함께 확인하는 절차임

## Ⅰ. 개요

- **정의**: 클러스터링은 정답 라벨이 없는 데이터를 거리, 유사도, 밀도 기준으로 묶어 내부적으로 비슷한 관측치를 같은 집단으로 배치하는 비지도 학습 기법임
- **배경/필요성**: 고객 세분화, 이상 탐지, 문서 분류처럼 사전 정답을 만들기 어려운 문제에서는 데이터가 가진 자연스러운 구조를 먼저 발견해야 함
- **비유**: 이름표 없는 물건을 모양과 쓰임새가 비슷한 것끼리 바구니에 나누어 담는 작업과 같음

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 비지도 학습 구조 이해 | 거리·밀도 기준, 군집 할당, 군집 평가 | 지도학습 분류와 혼동 |
| 알고리즘 선택 역량 | K-Means, DBSCAN, 계층 군집 | K값·eps·minPts 기준 누락 |

> 요약: 클러스터링은 라벨 없이 데이터 간 가까움의 기준을 정하고 그 기준에 따라 숨은 집단 구조를 찾는 기법임.

## Ⅱ. 특징/비교

| 판단 기준 | K-Means | DBSCAN·계층 군집 |
|:---|:---|:---|
| 군집 가정 | 구형 군집과 평균 중심을 가정함 | 밀도 연결 또는 병합·분할 구조를 가정함 |
| 사전 파라미터 | 군집 수 `K`를 먼저 정해야 함 | DBSCAN은 `eps`, `minPts`, 계층 군집은 절단 높이가 필요함 |
| 이상치 처리 | 모든 점을 어느 군집에든 배정함 | DBSCAN은 밀도가 낮은 점을 잡음으로 분리할 수 있음 |
| 선택 조건 | 대규모 수치 데이터와 명확한 중심 구조에 적합함 | 불규칙 모양, 잡음 포함, 계층 관계 확인에 적합함 |

> 요약: 클러스터링 알고리즘은 데이터 모양, 잡음 여부, 군집 수 사전 지식에 따라 선택해야 함.

- **입력 조건**: 라벨 없이도 유사도 계산이 가능한 특징 표현이 준비되어야 함
- **평가 기준**: 응집도, 분리도, 군집별 업무 해석 가능성을 함께 확인함
- **선택 판단**: 중심 구조면 K-Means, 잡음·불규칙 모양이면 DBSCAN을 우선 검토함

## Ⅲ. 구성요소

```text
+------------+      +------------+      +------------+
| 입력 데이터 | ---> | 유사도 기준 | ---> | 군집 모델   |
+------------+      +------------+      +------------+
       |                  |                  |
       v                  v                  v
+------------+      +------------+      +------------+
| 전처리     |      | 파라미터    |      | 군집 평가   |
+------------+      +------------+      +------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 입력 데이터 | 관측치를 벡터, 좌표, 집합 형태로 표현해 군집화 대상으로 사용함 | 분류 전 물건 |
| 전처리 | 스케일 조정, 결측 처리, 차원 축소로 거리 계산의 왜곡을 줄임 | 같은 눈금의 자 |
| 유사도 기준 | 유클리드, 코사인, 자카드 등 데이터 유형에 맞는 가까움 기준을 정함 | 물건을 비교하는 기준표 |
| 군집 모델 | 중심 이동, 밀도 확장, 계층 병합 등으로 소속 집단을 계산함 | 바구니를 나누는 규칙 |
| 군집 평가 | 실루엣 계수, 응집도, 분리도, 업무 해석 가능성으로 결과를 검증함 | 정리 상태 점검표 |

> 요약: 클러스터링 구조는 데이터 표현과 유사도 기준을 먼저 정한 뒤 알고리즘으로 집단을 만들고 평가하는 구조임.

## Ⅳ. 절차

```text
+------------+      +------------+      +------------+      +------------+
| 데이터 준비 | ---> | 기준 선택   | ---> | 군집 생성   | ---> | 결과 해석   |
+------------+      +------------+      +------------+      +------------+
```

1. **데이터 준비**: 분석 목적에 맞는 관측치와 특징을 고르고 결측치·스케일·이상치를 처리함
2. **기준 선택**: 데이터 유형과 군집 모양을 고려해 거리 척도와 알고리즘을 선택함
3. **군집 생성**: `K`, `eps`, linkage 등 파라미터를 조정하며 군집 소속을 계산함
4. **평가·해석**: 실루엣 계수와 업무 의미를 함께 확인하고 군집별 프로파일을 작성함

> 요약: 클러스터링 절차는 데이터 표현을 정리한 뒤 가까움의 기준으로 군집을 만들고 해석 가능성을 검증하는 흐름임.

- **산출물**: 군집 라벨, 군집별 프로파일, 이상치 또는 잡음 후보임
- **검증 기준**: 내부 지표와 샘플 검토 결과가 같은 방향이어야 함
- **운영 기록**: 거리 척도, 파라미터, 군집 해석 기준을 버전별로 남겨야 함

## Ⅴ. 문제점

- **P1 거리 척도 민감성**: 스케일이 큰 변수나 고차원 희소 데이터가 거리 계산을 지배하면 군집이 실제 의미와 다르게 형성됨
- **P2 파라미터 결정 어려움**: `K`, `eps`, 절단 높이 같은 값을 잘못 정하면 군집이 과분할되거나 서로 다른 집단이 합쳐짐
- **P3 평가 기준 부족**: 정답 라벨이 없는 경우 실루엣 점수만 높고 업무적으로 해석 불가능한 군집이 선택될 수 있음

> 요약: 클러스터링은 라벨이 없기 때문에 거리 기준, 파라미터, 평가 해석이 흔히 깨지는 지점임.

## Ⅵ. 개선방안

- **P1 대응**: 표준화, 정규화, 차원 축소, 데이터 유형별 거리 척도 선택을 적용함 (확인: 변수별 분포와 거리 기여도 점검)
- **P2 대응**: Elbow, Silhouette, k-distance plot, 도메인 제약을 함께 사용해 후보 파라미터를 비교함 (확인: 후보별 군집 수와 안정성 비교)
- **P3 대응**: 내부 지표와 함께 군집별 프로파일, 샘플 검토, 후속 업무 성과를 검증함 (확인: 군집 설명 문장과 활용 지표 작성)

> 요약: 클러스터링 개선은 수학적 군집 품질과 업무 해석 가능성을 동시에 검증하도록 기준을 보강하는 것임.

- **우선순위**: 스케일 보정과 거리 척도 선택을 먼저 점검함
- **확인 지표**: Silhouette, Davies-Bouldin, 군집 크기 분포를 함께 사용함
- **재평가 조건**: 데이터 분포나 고객·문서 유형이 바뀌면 군집을 다시 해석함

## Ⅶ. 전망

- **발전 방향**: 클러스터링은 표현학습, 그래프 분석, 자동 파라미터 탐색과 결합해 고객 세분화, 로그 이상 탐지, 임베딩 검색의 구조 발견 도구로 확장됨
- **설계 관점**: 데이터 유형, 스케일, 차원, 군집 활용 목적에 맞춰 거리 척도와 파라미터 후보를 먼저 설계해야 함
- **검증 관점**: Silhouette, Davies-Bouldin, 군집 크기 분포와 샘플 검수를 함께 사용해 수학적 품질과 업무 해석 가능성을 같이 확인해야 함
- **운영 관점**: 데이터 분포나 고객·문서 유형이 바뀌면 군집 프로파일과 임계 파라미터를 재검토해 군집 의미의 변질을 막아야 함
- **적용 관점**: 정답 라벨이 부족한 탐색·세분화 업무에는 유용하지만, 군집 라벨을 곧바로 의사결정 규칙으로 쓰는 업무에는 사후 검증이 필요함
- **보안·신뢰 관점**: 오염 데이터나 비정상 샘플이 군집 중심을 끌어당길 수 있으므로 이상치 처리, 샘플 출처, 거리 기여도 점검으로 결과 신뢰성을 확보해야 함
- **기술사 제언**: 클러스터링 답안은 알고리즘 명칭보다 데이터 표현, 거리 기준, 군집 결과의 업무 사용 가능성을 우선 판단하는 흐름으로 전개해야 함
