## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 데이터의 유사성을 바탕으로 유사한 특성을 가진 객체들을 같은 그룹으로 묶는 비지도 학습 기법임 |
| 배경/필요성 | 방대한 무작위 데이터에서 의미 있는 패턴 및 구조를 발견하여 인사이트 도출 필요성 대두 |
| 출제 의도 | K-Means, DBSCAN 등 다양한 군집화 알고리즘의 원리와 장단점 비교 이해도 평가 |

## Ⅱ. 구성요소
```text
+----------------+       +----------------+       +----------------+
|   Unlabeled    |       |   Clustering   |       |   Meaningful   |
|     Data       | ----> |   Algorithm    | ----> |    Clusters    |
+----------------+       +----------------+       +----------------+
```
| 군집 (Cluster) | 비슷한 특성을 공유하는 데이터 객체들의 집합 | 끼리끼리 모인 집단 |
| 중심점 (Centroid) | 각 군집을 대표하는 가상의 기준점 (K-Means 등) | 그룹의 리더 |
| 거리 측도 | 데이터 간 유사성을 판단하기 위한 계산 방법 | 친밀도 척도 |
> 요약: 클러스터링은 군집, 중심점, 거리 측도로 구성되어 데이터 간 거리를 기반으로 그룹화를 수행함

## Ⅲ. 절차
```text
+----------------+       +----------------+       +----------------+       +----------------+
| Initialization |       | Distance Eval  |       | Group Assign   |       | Optimization   |
| (Set Params)   | ----> | (Calc Metric)  | ----> | (Form Cluster) | ----> | (Update Cntr)  |
+----------------+       +----------------+       +----------------+       +----------------+
```
1. 초기화: 군집 수(K) 지정 및 초기 중심점 또는 밀도 기준 설정
2. 거리 계산: 각 데이터와 중심점(또는 주변 데이터) 간의 거리 산출
3. 군집 할당: 가장 가까운 중심점이나 밀도가 높은 영역으로 데이터 편입
4. 최적화: 조건(중심점 변경 없음 등) 충족 시까지 중심점 갱신 및 재할당 반복
> 요약: 초기 파라미터 설정 후 거리 계산과 군집 할당을 반복하여 최적의 군집을 형성함

## Ⅳ. 문제점
- K값 설정 한계: K-Means의 경우 사전에 최적의 군집 수(K)를 알기 어려움
- 형태 제약 문제: K-Means는 구형 군집에만 적합하고 비선형 구조 군집화에 취약함
- 밀도 불균일 문제: 밀도 기반(DBSCAN)은 데이터 밀도가 불균일하면 성능이 저하됨

## Ⅴ. 개선방안
- 단기 방안: 엘보우(Elbow) 기법이나 실루엣(Silhouette) 계수를 활용하여 최적의 K 도출
- 중기 방안: 비선형/복잡한 형태의 데이터 군집화를 위해 DBSCAN 등 밀도 알고리즘 적용
- 장기 방안: OPTICS 등 밀도 차이에 강건한 알고리즘 또는 계층적 군집화 병행 활용

## Ⅵ. 전망
- 고차원 데이터 군집화 성능 향상을 위해 딥러닝 기반 딥 클러스터링(Deep Clustering)으로 진화 중임
