## 미리 알고가기

- 군집화($Clustering$): 정답(라벨)이 없는 상태에서 데이터 간의 유사성만을 근거로 유사한 객체들을 그룹으로 묶는 비지도 학습 기법임
- 비지도 학습($Unsupervised$ $Learning$): 입력 데이터만 주어지고 정답이 없는 상태에서 데이터의 숨겨진 구조나 패턴을 찾아내는 학습 방식임
- 거리 척도($Distance$ $Metric$): 데이터 간의 '가까움'을 정의하는 수학적 기준으로, 유클리드·맨해튼 거리 등이 사용됨
- 응집도와 분리도: 군집 내부 객체들은 서로 가깝고(응집도↑), 서로 다른 군집 간에는 멀리 떨어져야(분리도↑) 좋은 군집화임

## Ⅰ. 개요

- **정의/개념**: 클러스터링은 방대한 양의 비라벨링 데이터 내에서 객체들 사이의 유사성(거리 또는 밀도)을 수치화하여 자연스러운 그룹 구조를 발견해내는 데이터 마이닝의 핵심 기술임
- **배경/필요성**: 마케팅에서의 고객 세분화, 보안 분야의 이상 패턴 탐지, 이미지 분할 등 데이터의 사전 정보가 부족한 상황에서 유의미한 구조적 통찰을 얻기 위해 사용됨

## Ⅱ. 특징

- 정답이 필요 없는 유연한 탐색적 데이터 분석 기법이며, 도출된 각 군집의 특성을 분석하여 새로운 라벨링의 기준을 마련할 수 있음
- 알고리즘에 따라 군집의 모양(원형/비정형)과 개수 결정 방식이 상이하며, 특히 데이터의 스케일에 매우 민감하므로 사전 정규화가 필수적임
- '차원의 저주' 현상으로 인해 고차원 데이터에서는 객체 간 거리 변별력이 낮아져 군집화 성능이 급격히 저하될 수 있음을 유의해야 함

## Ⅲ. 종류 및 비교

| 판단 기준 | K-Means (중심 기반) | DBSCAN (밀도 기반) |
|:---|:---|:---|
| **군집 개수(K)** | 사전에 지정해야 함 | 자동으로 결정됨 |
| **군집 모양** | 원형(구형)에 한정됨 | 기하학적 비정형 모양 가능 |
| **이상치 처리** | 모든 데이터를 군집에 포함 (취약) | 노이즈로 인식하여 제외 (강력) |
| **속도 및 복잡도** | 매우 빠름, 단순함 | 상대적으로 느리고 파라미터에 민감함 |
| **주요 파라미터** | 군집 수 ($k$) | 반경($eps$), 최소 이웃 수($MinPts$) |

> 요약: K-Means는 빠르고 명확한 군집 분할에, DBSCAN은 복잡한 모양과 노이즈 제거에 특화됨.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 중심점 ($Centroid$) | 군집의 기하학적 중심이며, K-Means에서 각 데이터가 소속될 기준점이 됨 |
| 코어 포인트 | $eps$ 반경 내에 최소 $MinPts$ 이상의 데이터가 있는 밀집 지역의 중심점임 |
| 실루엣 계수 | 군집 내 거리와 이웃 군집 간 거리를 비교하여 군집화 품질을 측정하는 지표임 |
| Elbow Method | $k$ 값 변화에 따른 $SSE$ 감소율을 분석하여 최적의 군집 수를 찾는 시각적 도구임 |

```text
[ K-Means 알고리즘 흐름 ]
1. K개의 랜덤 중심점 선택 -> 2. 모든 데이터를 가장 가까운 중심점에 할당 
-> 3. 할당된 데이터의 평균으로 중심점 이동 -> 4. 변화 없을 때까지 2,3 반복
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 데이터 전처리| --> | 유사도/밀도 계산| --> | 군집 할당/확장| --> | 품질 평가/해석|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **특징 공학** — 분석 목적에 맞는 변수를 선택하고, 거리 계산 왜곡을 방지하기 위해 표준화($Standardization$) 또는 정규화를 수행함
2. **알고리즘 선택** — 데이터의 분포가 균일하고 군집 수를 대략 안다면 K-Means를, 모양이 복잡하고 노이즈가 많다면 DBSCAN을 선택함
3. **반복 수행** — 선택된 알고리즘의 기준(거리 최소화 또는 밀도 연결)에 따라 객체들을 그룹화하고, 수렴할 때까지 중심점을 갱신하거나 영역을 확장함
4. **결과 검증** — 실루엣 계수가 1에 가까운지 확인하고, 도출된 각 군집의 도메인 특성을 분석하여 비즈니스적 의미를 부여함

## Ⅵ. 실무 적용 및 유의점

1. K-Means 사용 시 초기 중심점 위치에 따라 결과가 달라지는 '국소 최적해' 문제에 빠질 수 있으므로, 초기점을 서로 멀리 떨어뜨려 배치하는 'K-Means++' 초기화 기법을 적용하여 안정성을 확보해야 함
2. 고차원 데이터셋에서는 특징 추출($Feature$ $Extraction$)이나 차원 축소($PCA$)를 먼저 수행하여 거리 계산의 유효성을 확보한 후 클러스터링을 진행해야 군집 분별력을 높일 수 있음

## Ⅶ. 결론

- 클러스터링은 복잡한 데이터의 본질적인 질서를 찾아내는 비지도 학습의 핵심 도구이며, 설계자는 데이터의 기하학적 특성과 비즈니스 요구사항을 고려하여 최적의 알고리즘과 거리 척도를 선택함으로써 데이터 가치를 극대화해야 함
