## 미리 알고가기

- 클러스터링(Clustering): 정답 라벨 없이 유사한 데이터를 같은 군집으로 묶는 비지도 학습임
- 거리 척도(Distance Metric): 두 데이터가 얼마나 가까운지 계산하는 기준임
- 중심점(Centroid): K-Means에서 군집을 대표하는 평균 위치임
- 밀도(Density): 일정 반경 안에 데이터가 얼마나 모여 있는지 나타내는 기준임
- 실루엣 계수: 군집 내부 응집도와 군집 간 분리도를 함께 보는 품질 지표임
- 반경($\varepsilon$): DBSCAN에서 이웃으로 인정할 최대 거리임
- 최소 이웃 수(MinPts): DBSCAN에서 핵심점으로 인정할 반경 내 최소 데이터 수임
- K-평균 군집화(K-Means): 각 데이터를 가까운 중심점에 배정하고 중심점을 반복 갱신하는 기법임
- 밀도 기반 군집화(DBSCAN): 반경 내 데이터 밀도로 군집을 연결하고 저밀도 데이터를 노이즈로 분리하는 기법임

## 작성 근거(검토용)

- K-Means와 DBSCAN의 중심점·밀도 차이에 집중해 핵심 선택 기준을 분명히 함
- 동작 메커니즘·처리 결과·주요 리스크를 비교축으로 삼고 두 알고리즘을 하나의 공통 절차로 묶지 않음
- 스케일 민감도는 거리 기반 군집화의 대표 실패 원인이므로 선행 용어와 사례에 반영함
- 품질 지표를 정답률이 아닌 응집도·분리도·업무 해석으로 잡아 비지도 학습의 평가 특성을 드러냄
- 보안 이상 탐지는 DBSCAN의 노이즈 처리 장점을 설명하기 적합해 실무 예시로 선택함
- K-Means와 DBSCAN은 반복 조건과 상태 전이가 달라 원리 흐름도를 알고리즘별로 분리해 하나의 절차로 뭉개지 않음

## Ⅰ. 개요

- **정의/개념**: 클러스터링은 거리·밀도·연결 관계로 유사 객체를 군집으로 나누는 비지도 학습 기법임
- **배경/필요성**: 정답이 없는 데이터의 숨은 구조를 찾아 후속 분석 기준을 세우기 위해 군집화가 필요함

### 쉽게 이해하기 (학습용)
- 이름표 없는 물건들을 비슷한 것끼리 저절로 상자에 나눠 담는 것과 같음

## Ⅱ. 특징

- 거리·밀도 분포 기반 군집으로 데이터 구조 탐색과 세분화 기준을 제공함
- 거리 기반 모델은 스케일과 차원 수에 민감하므로 전처리 품질이 군집 결과를 좌우함
- 군집 수나 밀도 기준을 잘못 정하면 같은 데이터도 전혀 다른 군집으로 분리됨
- 군집 품질은 정답률보다 응집도, 분리도, 도메인 해석 가능성으로 판단함

### 쉽게 이해하기 (학습용)
- 자를 잘못 고르면(단위가 안 맞으면) 분류가 엉망이 되고, 몇 무리로 나눌지 기준을 살짝만 바꿔도 상자 안 구성이 확 달라짐

## Ⅲ. 종류 및 비교

| 판단 기준 | K-Means | DBSCAN |
|:---|:---|:---|
| 동작 메커니즘 | 최근접 중심점 할당 | 밀도 연결 확장 |
| 처리 결과 | $k$개 중심 기반 군집 | 노이즈 분리형 비정형 군집 |
| 주요 리스크 | 초기 중심점 의존 | 밀도 편차 민감 |

> 요약: K-Means는 중심점 분할, DBSCAN은 밀도 연결로 노이즈를 분리함.

### 쉽게 이해하기 (학습용)
- K-Means는 정해진 개수의 깃발을 꽂고 가까운 사람을 모으는 방식, DBSCAN은 촘촘히 붙어 있는 무리만 따라가며 묶고 외딴 사람은 남겨두는 방식임

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 특징 행렬 | 객체별 수치 벡터 |
| 유사성 척도 | 객체 간 근접성을 계산하는 거리·유사도 함수 |
| 군집 형성 규칙 | 최근접 중심 할당 또는 밀도 연결성으로 객체의 군집 소속을 정하는 규칙 |
| 군집 평가 지표 | 군집 내 응집도·군집 간 분리도로 결과 품질을 측정하는 지표 |

```text
+-----------+     +-------------+     +-----------+
| 특징 행렬 | --> | 근접성·밀도 계산 | --> | 군집 형성 |
+-----------+     +-------------+     +-----------+
```

> 요약: 클러스터링은 특징 벡터의 거리·밀도로 객체 소속을 정하고 응집도·분리도로 군집 품질을 판단함.

### 쉽게 이해하기 (학습용)
- 사람들의 신체 치수표(특징 행렬)를 놓고 가까운 정도를 재는 자(척도)로 무리 짓는 규칙을 정한 뒤, 무리가 잘 나뉘었는지 채점표로 확인하는 과정임

## Ⅴ. 원리 및 절차 흐름도

**K-Means**

```text
중심점 초기화 → 최근접 중심으로 군집 배정 → 군집별 중심 갱신
                                           ├─ 중심 이동 큼 → 군집 배정 반복
                                           └─ 임계값 이하 → 군집 확정
```

1. **중심점 초기화**: $k$개 중심점을 초기 위치에 배치함
2. **군집 배정**: 각 데이터를 가장 가까운 중심점의 군집으로 배정함
3. **중심점 갱신**: 군집별 평균 위치로 중심점을 다시 계산함
4. **수렴 판정**: 중심점 이동이 임계값 이하이면 종료하고, 아니면 군집 배정을 반복함

**DBSCAN**

```text
$\varepsilon$ 이웃 수 계산 → 핵심점 판정
                         ├─ 핵심점 → 밀도 도달 이웃 반복 연결
                         └─ 비핵심점 → 경계점·노이즈 판정
```

1. **핵심점 판별**: 반경 $\varepsilon$ 내 이웃 수가 MinPts 이상인 데이터를 핵심점으로 표시함
2. **이웃 연결**: 핵심점과 밀도 도달 가능한 이웃을 같은 군집으로 연결함
3. **군집 확장**: 새로 편입된 핵심점의 이웃까지 반복 연결해 군집을 넓힘
4. **노이즈 분리**: 어떤 핵심점의 이웃에도 속하지 않는 데이터를 노이즈로 분류함

> 요약: K-Means는 중심점 갱신, DBSCAN은 이웃 연결을 반복해 군집·노이즈를 분리함.

### 쉽게 이해하기 (학습용)
- K-Means는 깃발을 꽂고 사람을 모은 뒤 무리의 중심으로 깃발을 계속 옮기다 안정되면 멈추는 것이고, DBSCAN은 사람이 많이 모인 곳부터 옆 사람을 계속 끌어들이다 더 이어질 사람이 없으면 혼자 남은 사람을 외톨이로 남기는 것임

## Ⅵ. 실무 사례

1. 서버 워크로드 군집화는 CPU·메모리·I/O 지표를 스케일링한 뒤 비슷한 사용 패턴을 묶음
2. 보안 로그 분석은 DBSCAN으로 밀도가 낮아 어떤 군집에도 속하지 않는 이벤트를 이상으로 분류함

### 쉽게 이해하기 (학습용)
- 비슷하게 일하는 서버들끼리 묶어 관리하거나, 무리에 끼지 못하고 혼자 뚝 떨어진 로그를 수상한 낌새로 보는 것과 같음

## Ⅶ. 결론

- 클러스터링은 정답 라벨 없이 비슷한 데이터를 묶어 숨은 구조를 찾으며, 유사성 기준이 군집 결과를 좌우함
- 실루엣 계수만으로 정책을 자동화하지 말고 스케일링·거리 기준과 업무 해석을 함께 검증해 반복해서 나타나는 군집만 사용해야 함

### 쉽게 이해하기 (학습용)
- 채점표(실루엣 계수) 점수 하나만 믿지 말고, 여러 번 다시 나눠봐도 똑같이 묶이는 무리만 진짜로 인정해야 함
