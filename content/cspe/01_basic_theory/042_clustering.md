## 미리 알고가기

- 군집: 서로 유사한 데이터끼리 묶인 집합임
- 거리 척도: 두 데이터가 얼마나 가까운지 재는 기준임
- 노이즈 포인트: 어떤 군집에도 속하지 않는 이상 데이터임

## Ⅰ. 개요

- **정의/개념**: 클러스터링은 정답 라벨 없이 데이터 간 유사성을 기준으로 자연스러운 그룹 구조를 찾는 비지도 학습 기법이며, K-Means와 DBSCAN이 대표적임
- **배경/필요성**: 고객 세분화, 이상탐지, 로그 패턴 분석처럼 사전 라벨이 없는 데이터에서 구조를 먼저 발견해야 하는 경우가 많음

## Ⅱ. 특징

- 데이터의 숨은 구조를 찾아 탐색과 분류 전처리에 활용함
- K-Means는 빠르고 단순하지만 구형 군집에 유리함
- DBSCAN은 밀도 기반이라 비정형 군집과 이상치 분리에 강함
- 거리 척도와 파라미터 선택이 결과 품질을 크게 좌우함

## Ⅲ. 종류 및 비교

| 판단 기준 | K-Means | DBSCAN |
|:---|:---|:---|
| 군집 기준 | 중심점 거리 | 밀도 연결성 |
| 군집 수 입력 | 필요 | 불필요 |
| 이상치 처리 | 약함 | 강함 |
| 적합 데이터 | 구형, 균일 밀도 | 비정형, 노이즈 포함 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 특징 벡터 | 군집화 대상 입력이며 스케일 영향이 큼 |
| 거리 함수 | 유사도를 수치화하고 결과 구조를 결정함 |
| 중심점/밀도 기준 | 알고리즘 핵심 판단 요소이며 군집 경계를 정함 |
| 평가 지표 | silhouette, Davies-Bouldin 등이며 품질 검증 도구임 |

```text
+-----------+     +-----------+     +---------------+     +-----------+
| 특징 벡터    | --> | 거리 함수    | --> | 중심점/밀도 기준  | --> | 평가 지표    |
+-----------+     +-----------+     +---------------+     +-----------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 특징정규화 | --> | 유사도계산 | --> | 군집형성 | --> | 품질평가 |
+----------+     +----------+     +----------+     +----------+
```

1. **특징정규화**: 거리 왜곡을 막기 위해 스케일을 맞춤
2. **유사도계산**: 거리 또는 밀도 기반 이웃 관계를 구함
3. **군집형성**: 중심점 할당 또는 밀도 확장으로 그룹을 만듦
4. **품질평가**: 분리도와 응집도를 검증함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 스케일 차이가 결과를 왜곡해 큰 단위 변수에 군집이 끌림
   - 해결방안: 표준화와 feature selection을 수행하고 silhouette score로 검증함
2. 문제: 파라미터 민감도가 커 $k$, eps, minPts 선택이 어렵다
   - 해결방안: elbow method, k-distance plot으로 탐색하고 군집 안정성로 검증함
3. 문제: 고차원에서 거리 의미가 약해짐 차원의 저주가 발생함
   - 해결방안: PCA, UMAP 등으로 차원 축소 후 적용하고 군집 분리도로 검증함

## Ⅶ. 적용 사례

- 고객 세분화에서는 구매 패턴 기반 군집을 나눔, 확인 지표는 군집별 전환율 차이임
- 보안 이상탐지에서는 정상 로그와 다른 밀도 패턴을 분리함, 확인 지표는 이상치 탐지율임
- 이미지/문서 탐색에서는 유사 콘텐츠를 그룹화함, 확인 지표는 군집 응집도임

## Ⅷ. 결론

클러스터링의 핵심은 알고리즘 자체보다 데이터의 거리 구조를 맞게 표현하는 데 있으므로, 파라미터 조정보다 먼저 특징 공간을 제대로 설계해야 함.
