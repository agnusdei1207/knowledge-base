## 미리 알고가기

- mini-batch: 한 번 학습 단계에 사용하는 샘플 묶음임
- 정규화: 평균과 분산을 맞춰 분포를 안정화하는 처리임
- affine transform: 정규화 후 $\gamma$, $\beta$로 다시 스케일과 이동을 주는 단계임

## Ⅰ. 개요

- **정의/개념**: 배치 정규화는 각 층 활성값을 미니배치 단위 평균과 분산으로 정규화한 뒤 학습 가능한 스케일과 이동을 적용해 학습을 안정화하는 기법임
- **배경/필요성**: 깊은 신경망은 층이 깊어질수록 입력 분포가 흔들려 학습이 느려지고 초기화에 민감해지므로 분포 안정 장치가 필요함

## Ⅱ. 특징

- 학습률을 더 크게 써도 수렴이 비교적 안정적임
- 내부 활성 분포 변동을 줄여 깊은 모델 학습을 쉽게 함
- 약한 정규화 효과가 있어 일반화에도 도움을 줄 수 있음
- 배치 크기에 민감하고 추론 시에는 이동 평균 통계를 사용해야 함

## Ⅲ. 종류 및 비교

| 판단 기준 | BatchNorm | LayerNorm | GroupNorm |
|:---|:---|:---|:---|
| 정규화 축 | 배치 기준 | 샘플 내부 기준 | 채널 그룹 기준 |
| 배치 크기 의존성 | 큼 | 작음 | 작음 |
| 대표 적용 | CNN | Transformer | 소배치 비전 |
| 추론 통계 | 필요 | 불필요 | 불필요 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 배치 평균 $\mu_B$ | 미니배치 중심값이며 정규화 기준임 |
| 배치 분산 $\sigma_B^2$ | 퍼짐 정도이며 스케일 보정 기준임 |
| 정규화 출력 $\hat{x}$ | 평균 0, 분산 1 근사값이며 학습 안정화를 담당함 |
| 학습 파라미터 $\gamma,\beta$ | 표현력을 다시 조정하고 단순 표준화 한계를 보완함 |

```text
+---------------+     +---------------+     +---------------+     +----------------+
| 배치 평균 mu_B    | --> | 배치 분산 sigma_B | --> | 정규화 출력 xhat  | --> | 학습 파라미터 g,b |
+---------------+     +---------------+     +---------------+     +----------------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 배치입력 | --> | 평균/분산 계산 | --> | 정규화 | --> | 재스케일 |
+----------+     +----------+     +----------+     +----------+
```

1. **배치입력**: 동일 층 활성값 묶음을 받음
2. **평균/분산 계산**: 미니배치 통계를 구함
3. **정규화**: 각 값을 평균 0, 분산 1에 가깝게 변환함
4. **재스케일**: $\gamma$, $\beta$로 표현력을 보정함

## Ⅵ. 문제점 및 해결 방안

1. 문제: 소배치에서 통계가 불안정해 분산 추정이 흔들림
   - 해결방안: GroupNorm, LayerNorm으로 전환하고 training variance로 검증함
2. 문제: 학습과 추론 동작이 다름 running statistic 관리가 틀리면 성능 저하가 큼
   - 해결방안: train/eval 모드를 엄격히 분리하고 inference accuracy gap로 검증함
3. 문제: 분산 학습 시 통계 동기화 비용이 커 multi-GPU에서 배치 통계가 나뉨
   - 해결방안: SyncBatchNorm 또는 큰 global batch를 사용하고 sync overhead로 검증함

## Ⅶ. 적용 사례

- CNN 학습에서는 각 합성곱 블록 사이에 BatchNorm을 두며, 수렴 epoch 수로 결과를 확인함
- 이미지 분류 대회 모델에서는 큰 학습률 전략과 함께 사용하며, top-1 accuracy로 결과를 확인함
- 분산 학습 환경에서는 SyncBatchNorm으로 통계를 맞추며, 멀티 GPU 일관성으로 결과를 확인함

## Ⅷ. 결론

배치 정규화의 핵심은 표현력 확대가 아니라 학습 분포 안정화에 있으므로, 배치 크기와 추론 통계 관리까지 함께 설계해야 함.
