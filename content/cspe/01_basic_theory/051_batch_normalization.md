# 📖 【암기용】 개념 완전 이해

## 한눈에
- **개요**: 딥러닝 모델 학습 중 각 미니배치 단위로 입력 데이터의 분포를 평균 0, 분산 1로 정규화하는 기법.
- **왜 필요한가**: 학습 과정에서 이전 층의 가중치가 변함에 따라 다음 층의 입력 분포가 계속 바뀌는 '내부 공변량 변화(Internal Covariate Shift)' 문제로 인해 학습이 느려지고 불안정해짐.
- **핵심 직관**: 학생(신경망)에게 매번 난이도와 유형이 완전히 다른 시험지(분포가 요동치는 데이터)를 주면 혼란스러우니, 난이도를 항상 평균 50점짜리로 맞춰주어(정규화) 학습을 쉽게 만든다.

## 핵심 용어 정리

| 용어/표기 | 의미 | 비유·예 |
|:---|:---|:---|
| 내부 공변량 변화 (Internal Covariate Shift) | 층이 깊어질수록 데이터 분포의 변동이 증폭되어 학습을 방해하는 현상 | 앞주자가 바톤 위치를 계속 바꿔 뒷주자가 매번 적응해야 하는 상황 |
| 스케일과 시프트 (Scale & Shift) | 정규화로 인해 비선형성을 잃지 않도록 파라미터(γ, β)로 데이터를 다시 변환하는 과정 | 평균 난이도를 맞춘 후, 학생의 실제 수준에 맞게 점수를 미세 조정해주는 것 |
| 이동 평균 (Moving Average) | 미니배치 통계 대신 추론 시에 사용할 전체 데이터의 통계 누적치 | 모의고사 성적을 1년 내내 누적 평균 내어 수능(실전) 기준으로 삼는 것 |

## 깊이 이해
- **배경·문제의식**: 심층 신경망은 활성화 함수(Sigmoid 등)의 특성상 입력값이 너무 크거나 작으면 기울기가 0이 되는 그래디언트 소실(Vanishing Gradient) 문제가 발생함.
- **작동 원리**: 각 미니배치마다 노드별 평균과 분산을 구하고 표준정규분포로 만든다. 하지만 정규화만 하면 모델의 표현력(비선형성)이 훼손될 수 있으므로, 모델이 역전파를 통해 스스로 학습하는 감마(γ, 스케일)와 베타(β, 시프트)를 곱하고 더해 최적의 분포 형태를 스스로 찾게 한다.
- **비유**: 공장의 조립 라인에서 각 단계마다 부품이 들어오는 속도와 방향이 계속 달라지면(분포 변화) 로봇팔이 조립하기 힘듦. 배치 정규화는 각 단계 시작점에서 부품을 일정한 규격으로 가지런히 정렬해주는 장치.
- **구체 예시**: 152계층의 ResNet은 배치 정규화 없이는 사실상 수렴이 불가능함. 초기 학습률을 10배 이상 높여도 발산하지 않아 초고속 학습이 가능함.
- **흔한 오해·주의점**: 학습 단계와 추론(Test) 단계의 동작이 다름. 추론 시에는 배치 데이터가 1개일 수도 있으므로, 학습 시 누적해둔 '지수 이동 평균'을 사용하여 고정된 통계량으로 연산함.

## 연결 개념
- **층 정규화(Layer Normalization)**: 미니배치 크기에 의존하지 않도록, 배치가 아닌 특징(Feature) 차원 방향으로 정규화하는 기법 (RNN, 트랜스포머에 주로 사용).

> 2. **가치**: 내부 공변량 변화 해결, 안정적 그래디언트 흐름 보장 및 초고속 수렴(학습률 증가) 달성

## Ⅰ. 개요 및 필요성
- 개요: 딥러닝 모델의 각 층에 들어가는 입력 데이터 분포를 미니배치 단위로 정규화하여 학습을 안정화하는 기법
- 배경: 망이 깊어질수록 이전 층 파라미터 변동에 의해 다음 층 입력 분포가 요동치는 내부 공변량 변화(Internal Covariate Shift) 발생
- 필요성: 그래디언트 소실·폭발 방지, 초기 가중치 의존성 탈피, 높은 학습률(High Learning Rate) 적용을 통한 수렴 속도 향상 필요

---

## Ⅱ. 구조 및 구성요소

```text
입력(Mini-batch) -> 배치 통계 산출 -> 데이터 정규화 -> 스케일/시프트 변환 -> 최종 출력
                     |                  |                  |
                     +-> μ_B, σ^2_B     +-> N(0,1) 분포화  +-> γ 곱합, β 합산
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 배치 평균/분산 | 현재 입력된 미니배치 데이터의 중심과 퍼짐 정도 산출 | 학습 단계에서만 실시간 데이터로 계산 |
| 정규화 (Normalization) | 입력값을 평균 0, 분산 1의 표준 정규분포로 스케일링 | 분모 0 방지용 ε(epsilon) 상수 추가 |
| 스케일/시프트 파라미터 | 활성화 함수의 비선형성 보존 및 표현력 복원 | 역전파 통해 최적값을 자율 학습(γ, β) |
| 지수 이동 평균 (EMA) | 추론(Inference) 시 사용할 전체 데이터의 통계량 누적 | 평가 시에는 고정된 μ, σ값으로 연산 |

> 요약: 데이터 배치의 평균/분산으로 정규화한 뒤, 학습 파라미터(γ, β)로 원본의 표현력을 보존하며 출력하는 구조

---

## Ⅲ. 동작원리 및 흐름도

```text
학습 데이터 유입 -> 평균/분산 계산 -> 편차 정규화 수행 -> γ, β 복원 변환 -> 활성화 함수 인가
```

- 1단계 [통계량 산출]: 주어진 미니배치 크기(N) 내에서 데이터 x의 특징별 평균(μ)과 분산(σ^2)을 계산
- 2단계 [데이터 정규화]: 입력 x에서 μ를 빼고 표준편차로 나누어 정규화된 x_hat 생성
- 3단계 [표현력 복원]: 정규화된 값 x_hat에 스케일 파라미터(γ)를 곱하고 시프트(β)를 더하여 y값 산출
- 4단계 [추론 모드 전환]: 실 서비스 배포(추론) 시에는 실시간 배치 통계 대신 누적된 지수 이동 평균(EMA) 통계 적용

> 요약: 학습 시에는 배치의 실시간 통계를 사용하여 정규화하고, 추론 시에는 학습 중 누적된 고정 통계를 사용함

---

## Ⅳ. 특징
- [안정적 기울기 확보]: 내부 공변량 변화 억제로 그래디언트 소실 및 폭발 문제 원천 차단
- [높은 학습률 허용]: 파라미터 스케일 변화에 덜 민감해져 학습 속도를 높여도 안정적인 수렴 보장
- [자체 정규화 효과]: 미니배치 샘플링의 통계적 노이즈가 과적합을 억제하는 부수적 앙상블 효과 제공
- [배치 크기 의존성]: 메모리 제약으로 미니배치 크기가 8 이하로 작아지면 통계량이 부정확해져 성능 급감

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | Batch Normalization | Layer Normalization | Instance Normalization |
|:---|:---|:---|:---|
| 정규화 방향 | 미니배치(Batch) 축 기준 | 특징(Feature) 축 기준 | 채널(Channel) 축 독립적 기준 |
| 배치 의존성 | 매우 높음 (작으면 성능 저하) | 없음 (배치 1이어도 동작) | 없음 (스타일 전이에 유리) |
| 주요 적용 | CNN (이미지 분류/객체 탐지) | RNN, 트랜스포머 (자연어) | GAN, 스타일 변환 네트워크 |

> 요약: 모델 아키텍처와 처리 데이터 차원(공간적 vs 순차적)에 따라 최적의 정규화 축을 선택해야 함

**리스크·대응:**
- [성능 급감]: GPU 메모리 제약으로 초고해상도 이미지 처리 시 배치 크기가 극도로 작아짐 → Group Normalization 대안 적용 (지표: 검증 오차율)
- [추론 오작동]: 학습과 추론 데이터 간 분포(Domain)가 크게 다를 경우 이동 평균값의 괴리 발생 → 전이 학습 전 단계 도메인 적응(DA) 수행 (지표: Train-Test Acc 갭)

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. [구조 설계]: ResNet 기반 CNN 구조 설계 시 합성곱(Conv) 계층 직후, 활성화 함수(ReLU) 직전에 BN 계층을 삽입하여 효율 극대화
2. [초매개변수 튜닝]: 모델 초기에는 높은 학습률(예: 0.1)을 인가하여 빠르게 손실함수 최소점을 찾고, 이후 학습률 감소 스케줄러 적용
3. [자원 제약 대응]: 엣지 디바이스 배포 시 추론 연산 경량화를 위해 BN 계층의 γ, β를 이전 Conv 가중치에 병합(Folding)하여 연산 생략

**결론:**
- 기술사 판단: 깊은 신경망 구조에서는 선택이 아닌 필수 기술이며, RNN이나 소규모 배치 환경에서는 정규화 축을 변경(Layer Norm)하여 대응해야 함
- 향후 방향: 하드웨어 성능 제약을 극복하고 배치 데이터와 무관하게 안정적인 정규화를 수행하는 범용 Self-Normalizing 기법으로 고도화될 것
