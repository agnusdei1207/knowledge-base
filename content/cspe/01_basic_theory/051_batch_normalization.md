## 미리 알고가기

- 미니 배치: 전체 학습 데이터를 작은 묶음으로 나누어 순전파와 역전파를 수행하는 단위임
- 배치 통계량: 현재 미니 배치의 평균과 분산이며 정규화 기준값으로 사용됨
- 내부 공변량 변화: 앞 층의 가중치 변화로 뒤 층 입력 분포가 계속 바뀌는 현상임
- 이동 평균: 학습 중 누적한 평균과 분산이며 추론 시 고정 통계로 사용됨
- 스케일·시프트: $\gamma$, $\beta$로 정규화 결과의 크기와 위치를 다시 조정하는 연산임

## Ⅰ. 개요

- **정의/개념**: 배치 정규화는 신경망 층의 입력을 미니 배치 통계로 표준화한 뒤 $\gamma$, $\beta$로 재조정해 학습 분포와 기울기를 안정화하는 기법임
- **배경/필요성**: 깊은 신경망의 학습률 선택과 수렴을 안정화하기 위해 층 단위 입력 분포 제어가 필요함

## Ⅱ. 특징

- 미니 배치 평균과 분산으로 입력 분포를 맞춰 큰 학습률에서도 손실 진동을 줄임
- $\gamma$, $\beta$를 학습해 정규화로 줄어든 표현 범위를 다시 확보함
- 학습은 배치 통계를 쓰고 추론은 이동 평균 통계를 써 실행 모드를 분리함
- 배치별 통계 노이즈가 약한 규제 효과를 주어 과적합을 일부 완화함

## Ⅲ. 종류 및 비교

| 판단 기준 | 배치 정규화 | 레이어 정규화 | 그룹 정규화 |
|:---|:---|:---|:---|
| 통계 축 | 미니 배치와 채널 축 | 샘플 내부 특징 축 | 채널을 나눈 그룹 축 |
| 배치 크기 영향 | 작을수록 통계가 흔들림 | 거의 영향 없음 | 거의 영향 없음 |
| 적합 모델 | CNN, 대규모 배치 학습 | RNN, Transformer | 소규모 배치 비전 모델 |
| 주의점 | 학습·추론 통계 분리 필요 | 배치 간 분포 보정은 약함 | 그룹 수 선택이 성능에 영향 |

> 요약: 배치 정규화는 배치 통계가 충분할 때 강하고, 작은 배치에서는 LayerNorm·GroupNorm 검토가 필요함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 입력 활성값 $x$ | 특정 층으로 들어오는 미니 배치 값이며 정규화 대상임 |
| 평균 $\mu_B$ | 현재 배치의 중심값으로 입력 분포를 원점 근처로 이동시킴 |
| 분산 $\sigma_B^2$ | 현재 배치의 퍼짐 정도이며 입력 크기 차이를 줄이는 기준임 |
| 안정화 상수 $\epsilon$ | 분모가 0에 가까워지는 수치 불안정을 방지함 |
| 학습 파라미터 $\gamma$, $\beta$ | 표준화된 값을 다시 스케일링하고 이동해 표현력을 보존함 |

```text
+----------+      +-----------+      +-------------+      +-------------+
| x batch  | ---> | mean,var  | ---> | normalize   | ---> | scale,shift |
+----------+      +-----------+      +-------------+      +-------------+
                                                              |
                                                              v
                                                        +-------------+
                                                        | y output    |
                                                        +-------------+
```

> 요약: 배치 정규화는 배치 통계로 표준화한 뒤 학습 파라미터로 표현 범위를 복원함.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+      +----------+      +-----------+      +----------+
| x input  | ---> | stats    | ---> | x_hat     | ---> | y output |
+----------+      +----------+      +-----------+      +----------+
```

1. **통계 계산**: 미니 배치 단위로 $\mu_B$와 $\sigma_B^2$를 계산함
2. **표준화 수행**: $\hat{x} = (x - \mu_B) / \sqrt{\sigma_B^2 + \epsilon}$로 평균과 분산을 맞춤
3. **표현 복원**: $y = \gamma \hat{x} + \beta$로 모델이 필요한 분포를 다시 학습함
4. **추론 통계 고정**: 학습 중 누적한 이동 평균과 이동 분산을 서비스 추론에 사용함

> 요약: 학습 통계와 추론 통계가 분리되므로 실행 모드 전환이 결과 일관성을 좌우함.

## Ⅵ. 실무 사례

1. 소규모 배치 비전 모델은 통계 추정이 흔들리므로 GroupNorm과 비교하고 검증 손실과 추론 일관성으로 확인함
2. 서비스 추론은 이동 통계를 고정해야 하므로 학습·평가 모드를 분리하고 배포 전 출력 편차를 확인함

## Ⅶ. 결론

- 배치 정규화는 층별 분포 제어로 깊은 신경망 학습을 안정화하되, 배치 크기와 추론 통계 관리가 선택 기준임

## 작성 근거(검토용)

- 개요는 분포 제어와 기울기 안정화를 함께 제시해 배치 정규화의 목적을 명확히 함
- 특징은 학습률, 표현력, 실행 모드, 규제 효과로 절마다 다른 판단 축을 배치함
- 비교표는 정규화 축과 배치 의존성을 중심으로 대안 선택 기준을 드러냄
- 구성요소는 수식에 필요한 값만 남겨 평균, 분산, $\epsilon$, $\gamma$, $\beta$의 역할을 연결함
- 절차는 학습 통계 계산에서 추론 통계 고정까지 이어져 실무 오류 지점을 설명함
- 유의점은 작은 배치와 학습·평가 모드 전환을 대표 리스크로 선별함
