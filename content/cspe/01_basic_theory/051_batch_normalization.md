## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 각 은닉층 입력을 미니배치 단위로 정규화(평균 0, 분산 1)하여 학습을 안정화하는 기법임 |
| 배경/필요성 | 파라미터 업데이트로 다음 층 입력 분포가 흔들리는 내부 공변량 변화(Internal Covariate Shift) 해결 |
| 출제 의도 | 내부 공변량 변화 원리 이해 및 배치 정규화를 통한 기울기 소실 방지, 학습 가속 효과 평가 |

## Ⅱ. 구성요소
```text
+----------------+       +----------------+       +----------------+
| Hidden Layer   |       | Mini-Batch     |       | Scale & Shift  |
| Input (Z)      | ----> | Normalization  | ----> | (Gamma, Beta)  |
+----------------+       +----------------+       +----------------+
```
| 미니배치 | 정규화 연산의 기준이 되는 소규모 데이터 묶음 | 소집단 통계 |
| 정규화 (Norm)| 평균 0, 분산 1로 맞추어 데이터 분포를 균일화 | 톤 앤 매너 통일 |
| 스케일/시프트 | 정규화 후 표현력을 복원하는 파라미터(γ, β) | 개성 복구 필터 |
> 요약: 배치 정규화는 미니배치 단위로 입력을 정규화하고 감마/베타로 스케일을 보정함

## Ⅲ. 절차
```text
+----------------+       +----------------+       +----------------+       +----------------+
| Batch Mean/Var |       | Normalize Input|       | Scale/Shift    |       | Moving Average |
| (Calc Stats)   | ----> | (Zero Mean)    | ----> | (Apply Params) | ----> | (For Inference)|
+----------------+       +----------------+       +----------------+       +----------------+
```
1. 통계량 계산: 훈련 시 현재 미니배치의 평균과 분산 산출
2. 정규화: 통계량을 이용해 은닉층 입력을 표준 정규 분포로 변환
3. 변환 복원: 학습 가능한 파라미터(감마, 베타)로 스케일링 및 시프트 수행
4. 추론 적용: 테스트 시에는 훈련 중 누적된 이동 평균(Moving Average) 통계량 사용
> 요약: 미니배치 통계로 정규화, 감마/베타로 복원 후 추론 시 이동 평균을 사용함

## Ⅳ. 문제점
- 배치 크기 민감성: 배치 크기가 너무 작으면 통계량이 불안정하여 성능 극하락
- 시계열 적용 불가: RNN 등 길이가 변하는 시계열 데이터에는 배치 통계량 적용 난해
- 학습/추론 괴리: 훈련 시(미니배치)와 추론 시(이동 평균) 통계량 산출 방식 불일치 위험

## Ⅴ. 개선방안
- 단기 방안: 미니배치 크기를 충분히 크게(32 이상) 설정하여 안정적 분산 확보
- 중기 방안: 시계열(RNN) 모델에는 배치 대신 특징 차원을 정규화하는 Layer Norm 적용
- 장기 방안: Group Norm, Instance Norm 등 모델과 데이터 특성에 맞는 대체 정규화 도입

## Ⅵ. 전망
- 트랜스포머 등 거대 모델에 특화된 RMSNorm 등의 최적화된 계층 정규화 기법으로 진화함
