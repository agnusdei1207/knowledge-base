# 📖 【암기용】 개념 완전 이해

> 목적: 이 개념을 처음 보는 사람도 완벽히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: **정규화**(Normalization) 기법의 하나로, 신경망 각 층에 들어오는 미니배치 입력의 분포를 평균 0·분산 1로 맞춘 뒤, 학습 가능한 파라미터로 다시 스케일·이동시켜 **내부 공변량 변화**(Internal Covariate Shift)를 줄이는 기법
- **왜 필요한가**: 층이 깊어질수록 앞쪽 층의 가중치가 학습 중 조금만 바뀌어도 그 결과가 뒤 층에는 입력 분포 자체의 흔들림으로 증폭되어 전달된다. 뒤 층은 매 스텝 달라지는 분포에 계속 다시 적응해야 하므로 학습이 느려지고, 학습률을 높이면 쉽게 발산한다. 배치 정규화는 각 층 입구의 분포를 강제로 고정해 이 문제를 완화한다.
- **핵심 직관**: 릴레이 경주에서 바통(입력 분포)을 건네받는 위치가 구간마다 들쭉날쭉하면 다음 주자가 잡기 어렵다. 매 구간 시작점에서 바통을 항상 같은 위치로 맞춰주는 정리 담당이 배치 정규화다.

## 핵심 용어 정리

| 용어 | 의미 | 비유 |
|:---|:---|:---|
| 배치 정규화 (Batch Normalization, BN) | 미니배치 단위로 층의 입력 분포를 정규화하는 기법 — 이 표 전체의 상위 키워드 | 이 문서의 주인공 |
| 내부 공변량 변화 (Internal Covariate Shift, ICS) | 학습 중 앞 층 파라미터가 바뀌면서 뒤 층에 들어오는 입력 분포가 계속 변하는 현상 — BN이 줄이려는 문제 그 자체 | 계속 움직이는 과녁 |
| 미니배치 평균 ($\mu_B$) | 한 미니배치 안에서 특정 채널(피처)의 평균값 | 이번 시험 반 평균 |
| 미니배치 분산 ($\sigma_B^2$) | 한 미니배치 안에서 값이 평균으로부터 퍼진 정도(모집단 분산, N으로 나눔) | 반 점수가 들쭉날쭉한 정도 |
| 정규화 (Normalize, $\hat{x}$) | $\hat{x}=(x-\mu_B)/\sqrt{\sigma_B^2+\epsilon}$ 로 평균 0, 분산 1로 바꾼 값 | 원점수를 표준점수(z-score)로 환산 |
| $\epsilon$ (엡실론) | 분산이 0에 가까울 때 분모가 0이 되는 것을 막는 아주 작은 상수(예: $10^{-5}$) | 나눗셈 안전장치 |
| 스케일 파라미터 ($\gamma$, gamma) | 정규화된 값을 다시 얼마나 넓게 펼칠지 역전파로 학습하는 파라미터 | 표준점수를 우리 반 기준 배율로 다시 늘림 |
| 시프트 파라미터 ($\beta$, beta) | 정규화된 값을 다시 어디로 옮길지 역전파로 학습하는 파라미터 | 표준점수에 다시 더하는 보정값 |
| 학습(train) 시 통계 | 현재 미니배치에서 직접 계산한 $\mu_B, \sigma_B^2$ 사용 | 이번 시험만의 반 평균 |
| 추론(inference) 시 통계 | 학습 내내 누적해 둔 이동평균(moving average, EMA)의 $\mu, \sigma^2$ 사용 | 그동안 누적된 전체 평균 시세 |

## 깊이 이해

### 왜 필요했나 (배경)
- 입력 데이터를 학습 시작 전에 한 번 표준화해도, 층을 하나씩 지날 때마다 가중치와 곱해지고 활성화 함수를 통과하면서 분포가 다시 흐트러진다. 특히 학습이 진행되며 앞 층의 가중치가 갱신될 때마다 뒤 층에 들어오는 입력 분포의 평균·분산 자체가 스텝마다 바뀐다 — 이것이 내부 공변량 변화다.
- 분포가 Sigmoid/Tanh 같은 활성화 함수의 포화 영역(값이 매우 크거나 작은 구간)으로 쏠리면 그 지점의 기울기가 0에 가까워져 역전파 신호가 사라진다(기울기 소실). 그 결과 학습률을 크게 잡을 수 없고 가중치 초기화에도 민감해진다. 배치 정규화는 매 층의 입력 분포를 강제로 재정렬해 이 악순환을 끊는다.

### 순전파 계산 — 수치로 검증
- 어떤 미니배치에서 한 채널의 활성화 값이 [2, 4, 4, 4, 5, 5, 7, 9] (n=8)라고 하자.
- **평균**: $\mu_B = (2+4+4+4+5+5+7+9)/8 = 40/8 = 5$
- **분산**: 편차 제곱의 합 $= (2-5)^2+(4-5)^2 \times 3+(5-5)^2\times 2+(7-5)^2+(9-5)^2 = 9+1+1+1+0+0+4+16 = 32$ → $\sigma_B^2 = 32/8 = 4$
- **정규화**: $\hat{x}=(x-5)/\sqrt{4+\epsilon}\approx(x-5)/2$ (ε은 무시할 만큼 작음)
  - x=2 → x̂=-1.5, x=4 → x̂=-0.5, x=5 → x̂=0, x=7 → x̂=1, x=9 → x̂=2
  - 검산: 정규화된 8개 값 [-1.5, -0.5, -0.5, -0.5, 0, 0, 1, 2]의 합은 0(평균 0), 제곱합/8 = (2.25+0.25×3+0+0+1+4)/8 = 8/8 = 1(분산 1) — 정의대로 평균 0·분산 1을 만족한다.
- **스케일·시프트**: $y=\gamma\hat{x}+\beta$
  - 학습 초기 $\gamma=1, \beta=0$이면 $y=\hat{x}$ 그대로: x=2 → y=-1.5
  - 학습이 진행되어 $\gamma=2, \beta=1$이 되면: x=2 → $y=2\times(-1.5)+1=-3+1=-2$

### 왜 정규화 후 다시 γ, β로 복원하는가
- 모든 층의 입력을 무조건 평균 0·분산 1로 고정해버리면, 예를 들어 Sigmoid를 거의 선형인 중앙 구간에만 머물게 강제하는 셈이 되어 신경망이 원래 표현할 수 있던 비선형성과 다양한 분포를 잃는다. 표현력이 제한되는 것이다.
- 그래서 정규화 직후 학습 가능한 $\gamma, \beta$로 다시 스케일·이동시켜, "필요하면 원래 분포로 되돌릴 자유도"를 모델에 남겨둔다. 극단적으로 $\gamma=\sqrt{\sigma_B^2+\epsilon}=2, \beta=\mu_B=5$로 학습된다면, x=2 → $y=2\times(-1.5)+5=2$로 원래 값이 그대로 복원된다. 즉 BN은 표현력을 강제로 줄이는 것이 아니라 "정규화 vs 원래 분포" 사이를 모델이 스스로 고르게 하는 장치다.

### 학습 vs 추론 — 통계량이 다르다
- 학습 시에는 매 미니배치마다 그 배치의 $\mu_B, \sigma_B^2$를 직접 계산해서 정규화에 쓴다. 동시에 이 값들을 지수 이동평균(EMA)으로 누적해 전역 통계 $\mu, \sigma^2$를 갱신해 둔다.
- 추론 시에는 배치가 1개 샘플뿐이거나 아예 배치 개념이 없을 수 있어(예: 실시간 서비스에서 요청 1건씩 처리) 배치 통계를 신뢰할 수 없다. 그래서 학습 중 누적해 둔 이동평균 $\mu, \sigma^2$라는 고정값을 대신 사용한다. 이 값은 학습이 끝나면 더 이상 바뀌지 않는 상수로 취급된다.

### 왜 학습을 안정화·가속화하는가
- 각 층 입력 분포가 스텝마다 안정적으로 유지되므로, 뒤 층은 매번 달라지는 분포에 재적응할 필요가 없어 더 적은 스텝으로 수렴한다.
- 분포가 포화 영역에 몰리지 않아 그래디언트가 죽지 않고 잘 흐르며, 이 덕분에 훨씬 큰 학습률을 써도 발산하지 않는다.
- 가중치 초기화 값의 영향도 줄어든다 — 초기 가중치가 다소 크거나 작아도 BN이 다음 층 입력 분포를 다시 정규화해주기 때문이다.

### 한계 — 배치 크기가 너무 작을 때
- 예를 들어 배치 크기가 2인 경우, 단 2개의 샘플로 $\mu_B, \sigma_B^2$를 추정하게 된다. 표본 수가 극히 적어 평균·분산 추정치가 실제 전체 데이터 분포와 크게 달라질 수 있고(추정 분산 자체의 변동이 큼), 배치마다 통계량이 크게 흔들려 학습이 불안정해지거나 성능이 떨어진다. 고해상도 이미지처럼 메모리 제약으로 배치를 키우기 어려운 경우 이 한계가 특히 두드러지며, 이때는 Group Normalization 등 배치 크기에 의존하지 않는 대안을 쓴다.

## 연결 개념
- 내부 공변량 변화 (Internal Covariate Shift) — 배치 정규화가 해결하려는 핵심 문제 현상
- 활성화 함수 (Activation Function) — 분포가 쏠릴 때 포화(Saturation)되어 기울기 소실을 일으키는 지점
- Layer Normalization — 배치 크기가 1이거나 가변적인 NLP(Transformer) 환경에서 대안으로 쓰이는 정규화
- 052 드롭아웃 — BN도 배치 샘플링 과정에서 약한 규제(정규화) 효과를 겸하므로, 함께 쓸 때는 상호작용을 고려해야 하는 다른 과적합 방지 기법

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 배치 정규화는 심층 신경망 은닉층의 활성화 입력 분포를 미니 배치 단위로 평균 0, 분산 1로 유지시키는 네트워크 정규화(Regularization) 기법이다.
> 2. **가치**: 깊은 모델의 기울기 소실(Vanishing Gradient)을 억제하여 10배 이상 높은 학습률 적용을 가능하게 하고, 초기화 민감도를 대폭 낮춘다.
> 3. **판단 포인트**: CNN에서는 필수적인 표준 기법이나, 배치 크기가 매우 작거나 시계열 길이가 가변적인 RNN/Transformer에서는 Layer Normalization으로 대체해야 한다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 딥러닝 병목 해소 원리 이해 확인 | 내부 공변량 변화(ICS) 통제 및 Scale(γ)·Shift(β) 파라미터 복원 과정 명시 | "정규화한다"만 적고 학습 가능 파라미터(γ, β) 복원 생략 |
| 학습/추론 단계 동작 차이 인지 | 학습 시 미니배치 통계량 vs 추론 시 이동평균(Moving Average) 통계량 분리 | 추론 시에도 배치 평균을 구한다고 오답 서술 |
| 적용 환경 제약 판단 | 배치 크기 의존성 한계 및 대안(Layer Norm, Instance Norm) | 모든 도메인/네트워크에 Batch Norm이 최적이라 단정 |

> 요약: 내부 분포 변화로 인한 학습 지연 원리를 구조적으로 해소한 BN의 수식적 메커니즘과, 추론 시 동작 방식의 차이점을 묻는다.

## Ⅰ. 개요 및 필요성

- 정의: 신경망 계층의 입력 데이터 분포를 미니 배치 단위로 강제 정규화(Normalization)하여 학습을 안정화하는 기법
- 배경: 망이 깊어짐에 따라 은닉층 통과 시 데이터 분포가 변하는 내부 공변량 변화(Internal Covariate Shift) 발생
- 필요성: Sigmoid/Tanh 계열의 포화 영역으로 값이 빠져 기울기가 0이 되는 현상 방지 및 고속 학습률(Learning Rate) 허용

---

## Ⅱ. 구조 및 구성요소

```text
이전 레이어 출력(X) -> [Batch 평균(μ)/분산(σ^2) 산출] -> [정규화 X_hat] -> [γ, β 변환] -> [활성화 함수]
                          | (학습 시)                        |                   |
                          +-> 이동 평균/분산 누적 (추론 시 사용)  +-> Scale & Shift   +-> ReLU 등
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 배치 통계량 ($\mu_B, \sigma_B^2$) | 해당 미니배치 내 피처의 평균 및 분산 계산 | 미니배치 크기(Batch Size) 의존성 존재 |
| 정규화 값 ($X\hat{}$) | 분포를 평균 0, 표준편차 1로 스케일링 | 0으로 나누기 방지 상수 $\epsilon$ 추가 |
| Scale ($\gamma$) 및 Shift ($\beta$) | 정규화로 파괴된 비선형성/표현력을 원래대로 복원 | 역전파를 통해 신경망이 직접 학습하는 파라미터 |

> 요약: 배치의 통계량으로 강제 정규화 후, 모델 스스로 최적의 분포를 다시 찾도록 가중치 감마(γ)와 베타(β)를 역전파로 학습시킨다.

---

## Ⅲ. 동작원리 및 흐름도

```text
학습: 미니배치 통계량 계산 -> 정규화 -> 이동평균 누적 -> γ, β 적용 -> 활성화 값 출력
추론: 사전에 누적된 이동평균/분산 고정값 로드 -> 정규화 -> γ, β 적용 -> 출력
```

| 단계 | 처리 내용 (Train 단계) | 검증 기준 / 수식 |
|:---:|:---|:---|
| 1 | 미니 배치 데이터 집합의 미니 평균 $\mu_B$ 산출 | $\mu_B = \frac{1}{m} \sum X_i$ |
| 2 | 분산 $\sigma_B^2$ 산출 및 정규화(Normalization) | $X\hat{}_i = \frac{X_i - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}$ |
| 3 | 학습 파라미터 $\gamma, \beta$로 선형 변환 | $Y_i = \gamma X\hat{}_i + \beta$ |
| 4 | 추론(Test)을 위해 글로벌 이동평균·분산 업데이트 | 지수 이동 평균(EMA) 업데이트 |

> 요약: 학습 과정에서는 배치 단위 통계를 쓰면서 EMA를 업데이트하고, 실제 서비스(추론) 환경에서는 고정된 글로벌 EMA 통계로 정규화한다.

| 구분 | 내용 | 판단 포인트 |
|:---|:---|:---|
| 학습 속도 | 기울기 소실 제어로 기존 대비 10배 높은 학습률 적용 가능 | Epoch 수 대폭 감소 |
| 초기화 강건성 | 가중치 초기화(Weight Initialization) 방식에 덜 민감함 | He/Xavier 외 랜덤 초기화도 수렴 보장 |
| 정규화(규제) 효과 | 배치 샘플링 과정이 약간의 노이즈 추가 역할을 하여 일반화에 기여 | Dropout 비율 축소 또는 대체 가능 |

> 요약: 가중치 초기화나 학습률 튜닝에 대한 민감도를 낮춰 딥러닝 실무의 생산성을 비약적으로 높이는 "기본 장착" 계층이다.

## Ⅴ. 심화 비교 및 적용 판단

| 구분 | Batch Normalization | Layer Normalization | 선택 기준 |
|:---|:---|:---|:---|
| 정규화 단위 | 미니 배치의 동일 채널(Feature) 축 기준 정규화 | 단일 데이터 1개의 모든 피처 축 기준 정규화 | 처리 데이터의 차원 구조 |
| 배치 크기 의존도 | Batch Size 16 미만 시 평균 신뢰도 하락(성능 저하) | Batch Size와 무관하게 개별 샘플별 동작 | 메모리 제약 하의 Batch Size 한계 |
| 주요 적용 도메인 | 컴퓨터 비전 (CNN, ResNet) | 자연어 처리 (RNN, Transformer 구조) | 데이터 가변 길이(Sequence Length) 허용 여부 |

> 요약: 이미지 처리(CNN)에서는 BN이 압도적이나, 문장 길이가 다르고 배치 크기를 키우기 힘든 NLP 환경에서는 LN을 강제로 선택해야 한다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| Small Batch 문제 | 고해상도 이미지 학습 시 VRAM 한계로 Batch 2~4 사용 | Group Normalization 도입 또는 Gradient Accumulation 적용 | Training Loss 진동 여부 |
| Train/Test 불일치 | 평가 환경 샘플 분포가 EMA 누적 분포와 상이함 | 도메인 적응(Domain Adaptation), 실시간 통계 보정 | Test Accuracy 급락 |

> 요약: Batch 크기가 8 미만으로 떨어질 경우 BN의 평균·분산 추정이 왜곡되므로, Group Norm이나 LN으로 아키텍처를 우회해야 한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 활성화 분포 안정성 | 레이어 전 구간에서 활성화 값이 포화 영역으로 쏠리지 않음 | 레이어별 활성화 값 히스토그램 시각화 |
| 고학습률 허용도 | BN 미적용 대비 학습률을 높여도 발산 없이 수렴 | 학습률 스윕(Sweep) 후 Loss 발산 여부 비교 |
| 추론 정합성 | 학습 시 배치 통계와 추론 시 EMA 통계 간 정확도 격차 최소화 | Train/Test 정확도 차이 모니터링 |

> 요약: BN 도입 효과는 활성화 분포의 포화 여부, 고학습률 허용 범위, 추론 시 EMA 통계 정합성 세 가지를 함께 확인해야 검증된다.

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개:**
1. CNN 아키텍처 설계: 활성화 함수 이전에 BN을 배치하는 구조 (Conv -> BN -> ReLU)를 표준 템플릿으로 적용하여 내부 포화(Saturation) 사전 차단.
2. 초거대 모델 OOM(Out of Memory) 대응: 배치 크기가 4 이하로 강제되는 3D 의료 영상 분할(Medical Segmentation) 모델에서는 Batch Norm 대신 Group Norm으로 전환 적용.
3. 드롭아웃(Dropout) 충돌 방지: BN이 자체 규제(Regularization) 역할을 하므로, CNN 뒷단에서 분산을 왜곡하는 Dropout 사용을 최소화하거나 완전 연결층(FC)에만 격리 적용.

**결론 (2줄):**
- 기술사 판단: 배치 정규화는 딥러닝 르네상스를 이끈 핵심 최적화 기술이나, 데이터 도메인(Vision/NLP)과 H/W 메모리(배치 크기 한계)에 따라 Layer/Group/Instance Norm을 분별해 적용해야 한다.
- 향후 방향: 최근 ConvNeXt 등 구조 자체를 BN 없이 안정화하는 연구가 제안되고 있으나, 당분간 CNN 기반 산업 비전 분야의 표준 정규화 기법 지위를 유지할 것이다.
