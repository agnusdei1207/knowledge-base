# 📖 【암기용】 개념 완전 이해

> 목적: 배치 정규화를 처음 보는 사람도 완전하게 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 배치 단위 평균·분산으로 은닉층 입력을 보정하는 학습 안정화 기법
- **왜 필요한가**: 신경망은 앞 층 가중치가 바뀔 때마다 뒤 층 입력 분포가 계속 흔들린다. 분포 흔들림을 줄이면 학습률을 0.001에서 0.01 수준까지 키우는 설계가 가능하다.
- **핵심 직관**: 각 층으로 들어가는 값을 매 미니배치마다 평균 0, 분산 1 근처로 맞춘 뒤, 다시 학습 가능한 배율과 편향을 붙이는 절차다.

## 깊이 이해
- **배경·문제의식**: 깊은 신경망은 층이 20개 이상이면 입력 분포 변화와 기울기 소실이 누적된다. 배치 정규화는 층 입력을 표준화해 가중치 업데이트의 흔들림을 줄인다.
- **작동 원리**: 미니배치 평균과 분산 계산 -> 표준화 -> 감마 스케일과 베타 이동 적용 -> 역전파로 감마·베타까지 학습함. 추론 시에는 학습 중 누적한 이동 평균·분산을 사용함.
- **비유**: 여러 학생의 시험 점수를 반별 평균과 표준편차로 표준점수화한 뒤, 과목별 난이도 보정을 다시 붙이는 방식과 같다.
- **구체 예시**: 64개 미니배치에서 특정 뉴런 입력 평균 12, 표준편차 4이면 입력 20은 `(20-12)/4=2`로 표준화되고, 감마 1.5·베타 0.2 적용 시 3.2가 다음 활성화 함수로 전달됨.
- **흔한 오해·주의점**: 배치 정규화는 드롭아웃 대체물이 아니다. 배치 크기 4 이하에서는 평균·분산 추정 오차가 커져 LayerNorm·GroupNorm 선택이 필요하다.

## 연결 개념
- 내부 공변량 변화(Internal Covariate Shift) — 층 입력 분포 변화 설명
- 경사하강법(Gradient Descent) — 학습률 확대와 수렴 경로 관련
- Layer Normalization — 작은 배치·Transformer 계열 대안

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 배치 정규화(Batch Normalization)는 미니배치 평균·분산으로 층 입력을 표준화하고 감마·베타로 표현력을 복원하는 신경망 학습 보정 기법이다.
> 2. **가치**: 입력 분포 변동을 줄여 학습률 확대, 기울기 소실 완화, 초기화 민감도 감소를 제공한다.
> 3. **판단 포인트**: 배치 크기, 추론 시 이동 평균, CNN·MLP·Transformer별 정규화 선택 기준을 함께 판단해야 한다.

---

## Ⅰ. 개요 및 필요성

배치 정규화는 층 입력 분포를 보정하는 기법이다. 심층 신경망은 층별 입력 분포가 학습 중 계속 변해 수렴 시간이 늘고 기울기 소실이 발생한다. 미니배치 통계와 학습 파라미터를 결합해 20층 이상 네트워크에서도 학습률 0.01 수준의 설계를 가능하게 한다.

---

## Ⅱ. 구조 및 구성요소

```text
미니배치 입력 -> 평균/분산 계산 -> 표준화 -> 감마/베타 보정 -> 활성화 함수
                         +-> 이동 평균/분산 저장 -> 추론 시 사용
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 미니배치 통계 | 배치 평균·분산 산출 | 배치 크기 32~256에서 추정 오차 감소 |
| 표준화 연산 | 평균 0, 분산 1 입력으로 변환 | epsilon 1e-5 수준으로 0 나눗셈 방지 |
| 감마·베타 | 스케일·시프트 학습 | 표현력 손실 복원 |
| 이동 평균·분산 | 추론 단계 통계 고정 | 학습/추론 모드 전환 필수 |

> 요약: 배치 정규화는 배치 통계로 표준화하고 감마·베타와 이동 통계로 학습·추론 동작을 분리한다.

---

## Ⅲ. 동작원리 및 흐름도

```text
입력 x -> 배치 평균 산출 -> 배치 분산 산출 -> x_hat 표준화
-> y = gamma*x_hat + beta -> 역전파 -> 이동 통계 갱신
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 미니배치 입력 수집 | 배치 크기 32 이상 또는 대안 정규화 검토 |
| 2 | 평균·분산 계산 | epsilon 적용, NaN 발생 0건 |
| 3 | 감마·베타 적용 | 학습 파라미터 기울기 기록 |
| 4 | 추론 통계 반영 | train/eval 모드 정확도 차이 1%p 이하 |

> 요약: 학습 단계에서는 배치 통계를 쓰고 추론 단계에서는 이동 통계를 써서 입력 분포 보정과 결과 재현성을 분리한다.

---

## Ⅳ. 특징

| 구분 | 기존 방식 | 본 기술 | 수치·판단 포인트 |
|:---|:---|:---|:---|
| 학습률 | 작은 학습률과 초기화 민감 | 0.001에서 0.01 수준 확대 가능 | 손실 발산 여부와 validation loss 확인 |
| 정규화 위치 | 입력층 전처리 중심 | 은닉층·합성곱 출력에 적용 | Conv 뒤, ReLU 앞 배치가 일반적 |
| 추론 방식 | 배치 통계 의존 없음 | 이동 평균·분산 사용 | train/eval 모드 불일치 점검 |
| 한계 | 작은 배치 영향 제한 | 배치 4 이하 통계 오차 | LayerNorm·GroupNorm 대체 |

> 요약: 배치 정규화는 은닉층 입력 분포를 통제하지만 작은 배치와 추론 통계 불일치가 주요 판단 조건이다.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존/대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 적용 단위 | LayerNorm은 샘플 단위 | BatchNorm은 배치 단위 | CNN·배치 32 이상이면 BatchNorm |
| 비용/성능 | 정규화 없음은 수렴 에폭 증가 | 연산은 평균·분산 추가 | 학습 에폭 30% 이상 감소 시 채택 |
| 운영/위험 | 통계 없음 | 이동 통계 필요 | 추론 재현성 테스트 필수 |

> 요약: CNN 학습에는 BatchNorm, 작은 배치·시퀀스 모델에는 LayerNorm을 우선 검토한다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 추론 정확도 하락 | train/eval 모드 누락 | 모델 배포 전 eval 고정 | 검증 정확도 차이 1%p 이하 |
| 작은 배치 오차 | 평균·분산 표본 부족 | GroupNorm·SyncBatchNorm 적용 | 배치별 분산 변동률 |
| 분산 학습 불일치 | GPU별 통계 분리 | SyncBatchNorm 또는 통계 동기화 | 노드별 loss 편차 |

> 요약: 배치 통계 품질과 추론 모드 고정이 배치 정규화 운영 리스크의 핵심 통제점이다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 수렴 | 동일 모델 기준 에폭 30% 이상 감소 | 학습 로그, loss curve |
| 정확도 | validation accuracy 하락 1%p 이하 | 홀드아웃 검증 |
| 운영 | NaN 0건, train/eval 차이 1%p 이하 | APM, 배포 전 회귀 테스트 |

> 요약: 수렴 속도, 검증 정확도, 추론 모드 일치성을 함께 측정해야 도입 효과를 판단할 수 있다.

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 — 단계별 또는 항목별):**
1. CNN은 `Conv -> BatchNorm -> ReLU` 순서로 배치하고 batch size 32 이상에서 학습 로그를 비교함.
2. 멀티 GPU 학습은 SyncBatchNorm을 적용해 GPU별 통계 편차를 줄이고 노드별 loss 편차를 5% 이하로 관리함.
3. 배포 파이프라인에서 `model.eval()` 고정, 이동 평균·분산 포함 여부, 검증 정확도 차이 1%p 이하를 자동 점검함.

**결론 (2줄):**
- 기술사 판단: CNN·충분한 배치면 BatchNorm, 작은 배치·Transformer면 LayerNorm 또는 GroupNorm을 선택함.
- 향후 방향: 정규화 기법은 모델 구조별 통계 단위 선택과 분산 학습 동기화 전략으로 발전함.
