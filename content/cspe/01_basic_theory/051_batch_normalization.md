## 미리 알고가기

- 미니배치: 한 번의 학습 갱신에 사용하는 데이터 묶음임
- 정규화: 평균과 분산을 조정해 값의 분포를 일정 범위로 맞추는 처리임
- `gamma`, `beta`: 정규화된 값을 다시 학습 가능한 스케일과 위치로 조정하는 파라미터임
- 이동 평균: 추론 시 사용할 평균과 분산을 학습 중 누적한 값임
- 내부 공변량 변화: 학습 중 앞 층 파라미터 변화로 뒤 층 입력 분포가 계속 바뀌는 현상임

## Ⅰ. 개요

- **정의**: 배치 정규화는 미니배치 평균·분산으로 신경망 활성화 값을 표준화하고 학습 가능한 계수로 복원하는 정규화 기법임
- **배경/필요성**: 깊은 신경망은 층별 입력 분포가 계속 변하면 학습률을 크게 쓰기 어렵고 수렴이 느려지므로, 층 입력 분포를 일정하게 관리할 장치가 필요함
- **비유**: 생산 공정 중간마다 재료의 농도와 온도를 맞춘 뒤 다음 공정으로 보내는 품질 관리 절차와 같음

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 정규화 구조 이해 | 배치 평균·분산, `gamma`, `beta` | 추론 시 이동 평균 누락 |
| 학습 안정화 판단 | 높은 학습률, 기울기 흐름, 초기화 민감도 | Layer Norm과 혼동 |

> 요약: 배치 정규화는 미니배치 통계로 층 입력 분포를 조정해 깊은 신경망의 학습 속도와 안정성을 높이는 방법임.

## Ⅱ. 특징/비교

| 판단 기준 | 정규화 없음·Layer Norm | Batch Normalization |
|:---|:---|:---|
| 기준 통계 | 정규화 없음은 분포 변화를 그대로 두고 Layer Norm은 샘플 내부 특징 기준으로 정규화함 | 미니배치 전체의 평균과 분산으로 정규화함 |
| 적용 위치 | 정규화 없음은 구현이 단순하고 Layer Norm은 배치 크기 영향이 작음 | CNN·MLP에서 배치 기반 학습 안정화에 강점이 있음 |
| 훈련·추론 차이 | Layer Norm은 훈련과 추론 계산 기준이 거의 같음 | 훈련은 배치 통계, 추론은 이동 평균을 사용함 |
| 선택 조건 | 작은 배치, 시퀀스 모델, 온라인 추론에는 Layer Norm이 유리할 수 있음 | 충분한 배치 크기와 이미지·정형 딥러닝 학습에 적합함 |

> 요약: Batch Normalization은 배치 통계가 신뢰 가능한 학습 환경에서 층별 분포 변화를 줄이는 선택지임.

- **입력 조건**: 미니배치 평균·분산의 표본 변동이 작을 만큼 배치 크기가 확보되어야 함
- **평가 기준**: 학습 속도, 검증 성능, train/eval 모드 성능 차이를 함께 확인함
- **선택 판단**: CNN·MLP에서 깊은 층 학습이 불안정할 때 우선 검토함

## Ⅲ. 구성요소

```text
+------------+      +------------+      +--------------+
| 층 입력 x  | ---> | 배치 통계  | ---> | 정규화 값    |
+------------+      +------------+      +--------------+
       |                   |                    |
       v                   v                    v
+------------+      +------------+      +--------------+
| 이동 평균  |      | gamma·beta |      | 다음 층 입력 |
+------------+      +------------+      +--------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 층 입력 | 정규화 대상이 되는 활성화 값 또는 선형 변환 출력임 | 공정 투입 재료 |
| 배치 통계 | 미니배치 평균과 분산을 계산해 현재 분포 기준을 제공함 | 현장 측정값 |
| 정규화 값 | 입력에서 평균을 빼고 표준편차로 나누어 분포를 맞춘 결과임 | 표준 농도 |
| `gamma`, `beta` | 모델이 필요한 스케일과 위치를 다시 학습하도록 하는 보정 파라미터임 | 미세 조절 밸브 |
| 이동 평균 | 추론 단계에서 배치 없이 사용할 평균·분산의 누적 추정치임 | 표준 운영 기준 |

> 요약: 배치 정규화는 배치 통계로 값을 표준화하고 학습 가능한 보정값과 이동 평균으로 훈련·추론을 연결함.

## Ⅳ. 절차

```text
+------------+      +------------+      +------------+      +------------+
| 통계 계산  | ---> | 표준화     | ---> | 재스케일링 | ---> | 추론 적용  |
+------------+      +------------+      +------------+      +------------+
```

1. **통계 계산**: 미니배치별 평균과 분산을 산출하고 학습 중 이동 평균을 갱신함
2. **표준화**: 각 입력에서 평균을 빼고 표준편차로 나누어 분포를 평균 0, 분산 1에 가깝게 만듦
3. **재스케일링**: `gamma`, `beta`를 적용해 모델이 필요한 표현 범위를 다시 학습하게 함
4. **추론 적용**: 학습된 `gamma`, `beta`와 이동 평균·분산으로 단일 입력도 일관되게 처리함

> 요약: BatchNorm 절차는 배치 통계를 이용한 표준화와 학습 가능한 복원, 추론용 통계 고정으로 이루어짐.

- **산출물**: 정규화된 활성화 값, 이동 평균·분산, 학습된 `gamma`, `beta`임
- **검증 기준**: 훈련 모드와 평가 모드의 성능 차이가 허용 범위여야 함
- **운영 기록**: batch size, momentum, 정규화 위치를 모델 설정으로 관리해야 함

## Ⅴ. 문제점

- **P1 작은 배치 불안정**: 배치 크기가 작으면 평균·분산 추정이 흔들려 정규화 값과 검증 성능이 불안정해짐
- **P2 훈련·추론 불일치**: 이동 평균이 실제 운영 데이터 분포를 대표하지 못하면 추론 성능이 학습 성능과 달라짐
- **P3 모델 구조 제약**: RNN, 온라인 추론, 배치 의존성이 민감한 환경에서는 배치 통계 사용 자체가 부적합할 수 있음

> 요약: BatchNorm은 배치 통계가 전제이므로 작은 배치, 분포 변화, 구조 제약에서 문제가 집중됨.

## Ⅵ. 개선방안

- **P1 대응**: 배치 크기를 확보하거나 Ghost BatchNorm, GroupNorm, LayerNorm을 비교 적용함 (확인: 배치 크기별 검증 성능 분산)
- **P2 대응**: 학습·추론 모드 전환을 점검하고 이동 평균 momentum, 재보정 캘리브레이션을 수행함 (확인: train/eval 모드 성능 차이)
- **P3 대응**: 시퀀스·온라인 모델에는 LayerNorm, RMSNorm, WeightNorm 등 배치 비의존 정규화를 선택함 (확인: 단일 샘플 추론 안정성)

> 요약: BatchNorm 개선은 배치 통계 신뢰성을 확보하거나 배치 비의존 정규화로 대체하는 방향으로 설계함.

- **우선순위**: 작은 배치와 추론 모드 전환 문제를 먼저 확인함
- **확인 지표**: train/eval accuracy gap, activation variance, 배치 크기별 성능을 사용함
- **재평가 조건**: 배치 크기, 추론 방식, 모델 구조가 바뀌면 정규화 방식을 재검토함

## Ⅶ. 전망

- **발전 방향**: BatchNorm은 CNN과 대규모 MLP 학습에서 여전히 강력한 기본 기법이지만, Transformer 계열에서는 LayerNorm·RMSNorm 같은 대안이 더 널리 쓰임
- **기술사적 판단**: 기술사는 정규화 기법을 선택할 때 배치 크기, 모델 구조, 추론 방식, 분포 변화 가능성을 함께 판단해야 함
- **기술사 제언**: 향후 정규화는 자동 혼합 정밀도, 분산 학습, 작은 배치 학습과 결합해 학습 안정성과 추론 일관성을 동시에 보장하는 방향으로 발전할 것임
