## Ⅰ. 개요
- **정의**: 미니배치 단위로 은닉층 입력을 정규화(평균 0, 분산 1)하여 학습을 안정화하는 기법
- **배경/필요성**: 파라미터 갱신 시 다음 층의 입력 분포가 변동하는 내부 공변량 변화(ICS) 해결 필요
- **비유**: 요리 중간중간 양념 농도를 일정하게 맞추는 표준화 공정

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| ICS 해결 원리 이해 | 정규화 → γ·β 복원 2단계 구조 | 추론 시 이동 평균 사용 차이 누락 |
| 학습 가속 효과 평가 | 높은 학습률 허용, 초기화 민감도 감소 | Layer Norm 등 대안과 혼동 주의 |

> 요약: 배치 정규화는 층 입력의 분포 변동(ICS)을 미니배치 통계로 억제하여 학습을 가속하는 기법임

## Ⅱ. 구성요소
```text
+---------------+       +------------------+       +------------------+
| Hidden Input  |       | Normalize        |       | Scale & Shift    |
| (Z_l)         | ----> | (mean=0, var=1)  | ----> | (gamma, beta)    |
+---------------+       +------------------+       +------------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 미니배치 통계 | 현재 배치의 평균(μ_B)·분산(σ²_B)을 산출하는 단위 | 소집단 체온 측정 |
| 정규화 연산 | (x - μ_B) / √(σ²_B + ε)로 입력을 표준 분포로 변환 | 체온 보정 |
| γ·β 파라미터 | 정규화 후 표현력 복원을 위한 학습 가능 스케일·시프트 값 | 개성 복구 필터 |

> 요약: 미니배치 통계 → 정규화 → γ·β 복원의 3단 파이프라인으로 구성됨

## Ⅲ. 절차
```text
+---------------+       +---------------+       +---------------+       +---------------+
| Calc Stats    |       | Normalize     |       | Scale/Shift   |       | Moving Avg    |
| (mu, sigma)   | ----> | (zero-mean)   | ----> | (gamma, beta) | ----> | (for infer)   |
+---------------+       +---------------+       +---------------+       +---------------+
```

1. **통계 산출** — 미니배치 내 활성값의 평균(μ_B)과 분산(σ²_B) 계산
2. **정규화** — 각 활성값을 (x - μ_B) / √(σ²_B + ε)로 변환하여 표준 분포화
3. **스케일·시프트** — 학습 파라미터 γ(스케일)와 β(시프트)를 곱·합하여 표현력 복원
4. **이동 평균 축적** — 훈련 중 μ·σ²의 지수 이동 평균을 누적, 추론 시 배치 대신 사용

> 요약: 배치 통계 산출 → 정규화 → γ·β 복원 → 추론용 이동 평균 축적의 4단계로 수행함

## Ⅳ. 문제점
- 배치 크기 민감: 배치 크기 < 16이면 표본 통계가 불안정하여 정규화 품질 저하
- 시계열 부적합: RNN처럼 시퀀스 길이가 가변인 구조에서는 배치 축 통계 적용 불가
- 학습/추론 괴리: 훈련 시 미니배치 통계 vs 추론 시 이동 평균 간 분포 불일치 위험

> 요약: 소규모 배치·시계열·학습-추론 통계 불일치가 주요 한계임

## Ⅴ. 개선방안
1. 단기: 배치 크기를 32 이상으로 설정하거나 Batch Renorm으로 소배치 통계 보정
2. 중기: 시계열·소배치 환경에서 특징 차원 기준으로 정규화하는 Layer Norm 적용
3. 장기: Group Norm·Instance Norm·RMSNorm 등 태스크·아키텍처별 최적 정규화 전략 수립

- 학습/추론 괴리: 이동 평균 윈도우 불일치 → Batch Renorm의 보정 클리핑 적용 (지표: 학습-추론 정확도 갭 < 1%p)

> 요약: 소배치 보정 → Layer Norm 전환 → 아키텍처 특화 정규화 로드맵으로 대응함

## Ⅵ. 전망
- 향후 발전 방향: 트랜스포머 시대에 RMSNorm·DeepNorm 등 연산량을 줄인 경량 정규화로 전환
- 기술사적 판단: BN 자체의 사용 비중은 감소하나 "정규화 → 복원" 설계 패턴은 모든 정규화 기법의 원형으로 존속
- 기술사 제언: 모델 규모·배치 크기·데이터 특성에 따라 BN/LN/GN/RMSNorm을 비교 실험 후 선정 필요
