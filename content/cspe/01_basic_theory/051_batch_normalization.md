## 미리 알고가기

- 미니 배치: 전체 학습 데이터를 작은 묶음으로 나누어 순전파와 역전파를 수행하는 단위임
- 배치 통계량: 현재 미니 배치의 평균과 분산이며 정규화 기준값으로 사용됨
- 이동 평균: 학습 중 누적한 평균과 분산이며 추론 시 고정 통계로 사용됨
- 스케일·시프트: $\gamma$, $\beta$로 정규화 결과의 크기와 위치를 다시 조정하는 연산임
- 레이어 정규화: 샘플 내부 특징의 평균과 분산으로 정규화하는 방식임
- 그룹 정규화: 샘플의 채널을 그룹으로 나누어 평균과 분산을 계산하는 방식임
- $x,\hat{x},\mu_B,\sigma_B^2,\epsilon$: 각각 입력, 표준화값, 배치 평균, 배치 분산, 분모 안정화 상수임

## 작성 근거(검토용)

- 개요는 분포 제어와 기울기 안정화를 함께 제시해 배치 정규화의 목적을 명확히 함
- 특징은 학습률, 표현력, 실행 모드, 규제 효과로 절마다 다른 판단 축을 배치함
- 비교표는 통계 계산 범위·배치 의존성·주요 리스크로 대안 선택 기준을 드러냄
- 구성요소는 수식에 필요한 값만 남겨 평균, 분산, $\epsilon$, $\gamma$, $\beta$의 역할을 연결함
- 절차는 학습 통계 계산에서 추론 통계 고정까지 이어져 실무 오류 지점을 설명함
- 작은 배치와 학습·평가 모드 전환은 배치 정규화의 대표 실패 조건임

## Ⅰ. 개요

- **정의/개념**: 배치 정규화는 미니 배치 평균과 분산으로 층 입력을 표준화한 뒤 $\gamma$, $\beta$로 재조정하는 기법임
- **배경/필요성**: 깊은 신경망은 층마다 입력 분포가 흔들려 학습이 불안정해지므로 입력 분포 안정화가 필요함

### 쉽게 이해하기 (학습용)
- 요리 중 재료 상태가 매번 달라질 때마다 같은 기준으로 간을 맞춘 뒤 필요하면 취향껏 양념을 더 치는 것과 같음

## Ⅱ. 특징

- 미니 배치 평균과 분산으로 층의 입력 분포를 표준화해 학습률 변화에 따른 손실 진동을 줄임
- $\gamma$, $\beta$를 학습해 정규화로 줄어든 표현 범위를 다시 확보함
- 학습은 배치 통계를 쓰고 추론은 이동 평균 통계를 써 실행 모드를 분리함
- 배치별 통계 노이즈가 약한 규제 효과를 주어 과적합을 일부 완화함

### 쉽게 이해하기 (학습용)
- 재료 양이 매번 들쭉날쭉해도 같은 기준으로 맞춰 요리 편차를 줄이고, 밍밍해지지 않도록 취향껏 양념(γ,β)을 다시 더함
- 연습할 땐 그날 재료로 기준을 잡고, 실전에선 그동안 쌓아온 평균 기준을 씀

## Ⅲ. 종류 및 비교

| 판단 기준 | 배치 정규화 | 레이어 정규화 | 그룹 정규화 |
|:---|:---|:---|:---|
| 통계 계산 범위 | 채널별 배치와 공간 축 | 샘플 내부 특징 축 | 샘플별 그룹과 공간 축 |
| 배치 의존성 | 배치 크기 의존 | 배치 크기 독립 | 배치 크기 독립 |
| 주요 리스크 | 소형 배치 통계 오차 | 정규화 축 오설정 | 그룹 수 오설정 |

> 요약: 배치 정규화는 배치 축, 레이어 정규화는 샘플 특징 축, 그룹 정규화는 샘플 채널 그룹의 통계를 사용함.

### 쉽게 이해하기 (학습용)
- 배치 정규화는 여러 사람(배치)의 평균으로 기준을 맞추고, 레이어 정규화는 한 사람의 여러 부위 평균으로 맞추며, 그룹 정규화는 몇 부위씩 묶어 평균 내는 것과 같음

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 입력 활성값 $x$ | 정규화 대상 |
| 배치 통계 $\mu_B$·$\sigma_B^2$ | 중심 이동과 크기 조정 기준 |
| 표준화 연산 | 배치 평균을 빼고 $\sqrt{\sigma_B^2+\epsilon}$으로 나누는 변환 |
| 학습 파라미터 $\gamma$, $\beta$ | 표준화 결과의 스케일·시프트 |
| 이동 평균·분산 | 학습 중 누적해 추론 시 고정 정규화 기준으로 사용하는 통계량 |

> 요약: 배치 정규화는 학습 시 배치 통계로 표준화하고 추론 시 이동 통계를 사용하며 학습 파라미터로 표현 범위를 재조정함.

### 쉽게 이해하기 (학습용)
- 원재료(x)를 그날 평균·편차(배치 통계)로 맞춘 뒤 조리법(표준화 연산)을 거쳐 취향 양념(γ,β)을 더하고, 그동안의 기록(이동 평균)은 나중을 위해 남겨둠

## Ⅴ. 원리 및 절차 흐름도

```text
실행 모드 판정
├─ 학습 → 배치 평균·분산 계산 → 표준화 → $\gamma,\beta$ 재조정
└─ 추론 → 이동 평균·분산 사용 → 표준화 → $\gamma,\beta$ 재조정
```

1. **통계 계산**: 미니 배치 단위로 $\mu_B$와 $\sigma_B^2$를 계산함
2. **표준화 수행**: $\hat{x} = (x - \mu_B) / \sqrt{\sigma_B^2 + \epsilon}$로 평균과 분산을 맞춤
3. **표현 복원**: $y = \gamma \hat{x} + \beta$로 모델이 필요한 분포를 다시 학습함
4. **추론 통계 고정**: 학습 중 누적한 이동 평균과 이동 분산을 서비스 추론에 사용함

> 요약: 학습 통계와 추론 통계가 분리되므로 실행 모드 전환이 결과 일관성을 좌우함.

### 쉽게 이해하기 (학습용)
- 요리할 때는 오늘 재료로 기준을 잡아 간을 맞추고 양념을 더하며, 손님상에 낼 때는 미리 정해둔 기준 그대로 간을 맞추는 순서임

## Ⅵ. 실무 사례

1. 소형 배치 비전 모델은 배치 통계 대신 채널 그룹별 통계를 쓰는 그룹 정규화를 적용함
2. 모델 서빙은 학습 중 누적한 이동 평균·분산을 고정해 추론 입력을 정규화함

### 쉽게 이해하기 (학습용)
- 손님이 적어 그날그날 평균이 들쭉날쭉한 가게는 인원수 대신 다른 기준(그룹)으로 간을 맞추고, 정식 매장은 미리 정해둔 기준표 그대로 서빙함

## Ⅶ. 결론

- 배치 정규화는 배치 통계로 층 입력을 안정화하며, 작은 배치와 학습·추론 통계 차이를 주의해야 함
- 소형·가변 배치 서비스는 그룹·레이어 정규화를 우선 검토하고, 배치 정규화 사용 시 이동 통계를 모델 버전과 함께 고정해야 함

### 쉽게 이해하기 (학습용)
- 그날그날 재료 평균으로 기준을 잡는 방식은 편리하지만, 손님이 적은 날은 다른 기준표를 쓰는 편이 안전하고 정해진 기준표는 레시피와 함께 보관해야 함
