## 미리 알고가기

- 미니 배치: 전체 학습 데이터를 작은 묶음으로 나누어 순전파와 역전파를 수행하는 단위임
- 배치 통계량: 현재 미니 배치의 평균과 분산이며 정규화 기준값으로 사용됨
- 이동 평균: 학습 중 누적한 평균과 분산이며 추론 시 고정 통계로 사용됨
- 스케일·시프트: $\gamma$, $\beta$로 정규화 결과의 크기와 위치를 다시 조정하는 연산임
- 레이어 정규화: 샘플 내부 특징의 평균과 분산으로 정규화하는 방식임
- 그룹 정규화: 샘플의 채널을 그룹으로 나누어 평균과 분산을 계산하는 방식임
- $x,\hat{x},\mu_B,\sigma_B^2,\epsilon$: 각각 입력, 표준화값, 배치 평균, 배치 분산, 분모 안정화 상수임

## 작성 근거(검토용)

- 개요는 분포 제어와 기울기 안정화를 함께 제시해 배치 정규화의 목적을 명확히 함
- 특징은 학습률, 표현력, 실행 모드, 규제 효과로 절마다 다른 판단 축을 배치함
- 비교표는 통계 계산 범위·배치 의존성·주요 리스크로 대안 선택 기준을 드러냄
- 구성요소는 수식에 필요한 값만 남겨 평균, 분산, $\epsilon$, $\gamma$, $\beta$의 역할을 연결함
- 절차는 학습 통계 계산에서 추론 통계 고정까지 이어져 실무 오류 지점을 설명함
- 작은 배치와 학습·평가 모드 전환은 배치 정규화의 대표 실패 조건임

## Ⅰ. 개요

- **정의/개념**: 배치 정규화는 신경망 층의 입력을 미니 배치 통계로 표준화한 뒤 $\gamma$, $\beta$로 재조정해 층 입력 분포와 기울기 변동을 줄이는 기법임
- **배경/필요성**: 깊은 신경망의 층별 입력 분포와 기울기 변동을 줄이기 위해 정규화가 필요함

## Ⅱ. 특징

- 미니 배치 평균과 분산으로 층의 입력 분포를 표준화해 학습률 변화에 따른 손실 진동을 줄임
- $\gamma$, $\beta$를 학습해 정규화로 줄어든 표현 범위를 다시 확보함
- 학습은 배치 통계를 쓰고 추론은 이동 평균 통계를 써 실행 모드를 분리함
- 배치별 통계 노이즈가 약한 규제 효과를 주어 과적합을 일부 완화함

## Ⅲ. 종류 및 비교

| 판단 기준 | 배치 정규화 | 레이어 정규화 | 그룹 정규화 |
|:---|:---|:---|:---|
| 통계 계산 범위 | 채널별 배치와 공간 축 | 샘플 내부 특징 축 | 샘플별 그룹과 공간 축 |
| 배치 의존성 | 배치 크기 의존 | 배치 크기 독립 | 배치 크기 독립 |
| 주요 리스크 | 소형 배치 통계 오차 | 정규화 축 오설정 | 그룹 수 오설정 |

> 요약: 배치 정규화는 배치 축, 레이어 정규화는 샘플 특징 축, 그룹 정규화는 샘플 채널 그룹의 통계를 사용함.

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 입력 활성값 $x$ | 정규화 대상 |
| 배치 평균 $\mu_B$ | 중심 이동 기준 |
| 배치 분산 $\sigma_B^2$ | 크기 조정 기준 |
| 안정화 상수 $\epsilon$ | 분모 수치 안정화 |
| 학습 파라미터 $\gamma$, $\beta$ | 표준화 결과의 스케일·시프트 |

> 요약: 배치 정규화는 층 입력을 배치 통계로 표준화한 뒤 학습 파라미터로 표현 범위를 재조정함.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+      +----------+      +-----------+      +----------+
| 입력 x   | ---> | 배치 통계 | ---> | 표준화 x_hat | ---> | 재조정 y |
+----------+      +----------+      +-----------+      +----------+
```

1. **통계 계산**: 미니 배치 단위로 $\mu_B$와 $\sigma_B^2$를 계산함
2. **표준화 수행**: $\hat{x} = (x - \mu_B) / \sqrt{\sigma_B^2 + \epsilon}$로 평균과 분산을 맞춤
3. **표현 복원**: $y = \gamma \hat{x} + \beta$로 모델이 필요한 분포를 다시 학습함
4. **추론 통계 고정**: 학습 중 누적한 이동 평균과 이동 분산을 서비스 추론에 사용함

> 요약: 학습 통계와 추론 통계가 분리되므로 실행 모드 전환이 결과 일관성을 좌우함.

## Ⅵ. 실무 사례

1. GPU 메모리 제약으로 소형 배치를 쓰는 비전 모델은 그룹 정규화를 적용하고 검증 손실·배치 크기별 정확도 편차를 확인함
2. 모델 서빙 파이프라인은 이동 통계를 고정하고 학습·평가 모드의 출력 차이로 검증함

## Ⅶ. 결론

- 배치 정규화는 배치 크기가 충분한 학습에 적용하고 추론 시 이동 평균 통계와 실행 모드를 검증해야 함
