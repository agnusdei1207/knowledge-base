# 051. 배치 정규화 (Batch Normalization)

## Ⅰ. 개요

- **정의/개념**: 신경망의 각 층마다 입력 분포를 평균 0, 분산 1로 정규화한 후 학습 가능한 파라미터($\gamma, \beta$)를 통해 스케일링과 시프트를 수행하여 내부 공변량 변화를 억제하는 기법임
- **배경/필요성**: 층이 깊어질수록 이전 층의 파라미터 변화가 다음 층 입력 분포를 크게 변화시키는 내부 공변량 변화(Internal Covariate Shift) 문제를 해결하고, 학습 속도 향상 및 가중치 초기화 의존성을 낮추기 위해 필요함

## Ⅱ. 특징 및 비교

| 판단 기준 | Batch Normalization | Layer Normalization | Group Normalization |
|:---|:---|:---|:---|
| **정규화 단위** | Mini-batch 전체 (동일 채널) | 개별 샘플의 전체 채널 | 개별 샘플의 채널 그룹 |
| **장점** | 학습 속도 개선, 가중치 초기화 의존성 감소 | 시계열 데이터(RNN) 적합, 배치 크기 무관 | 소규모 배치 학습 안정성 확보 |
| **단점** | 배치 크기에 의존적, RNN 적용 어려움 | 배치 간 상관관계 무시 | 그룹 크기 하이퍼파라미터 필요 |
| **주요 용도** | CNN 기반 이미지 처리 모델 | RNN, Transformer 기반 자연어 처리 | 메모리 제한적 환경, 객체 탐지 모델 |

> 요약: 배치 정규화는 배치 통계를 활용해 학습 효율을 극대화하나 배치 크기 의존성이라는 트레이드오프가 존재함

## Ⅲ. 구성요소/구조

- **구성요소**:
  - **Mini-batch Mean/Variance**: 현재 배치 내 데이터들의 평균과 분산을 계산하여 정규화 기준점으로 활용함
  - **Normalize**: 각 뉴런의 입력을 평균 0, 분산 1로 변환하여 활성화 함수의 비선형 영역을 고루 활용하게 함
  - **Scale and Shift**: 학습 가능한 $\gamma$(Scale)와 $\beta$(Shift)를 적용해 정규화로 인한 표현력 제한을 복구함
  - **Running Statistics**: 추론 시 사용하기 위해 학습 중 계산된 이동 평균(Moving Average) 통계량을 유지함

- **원리/흐름도**:
```text
[입력 데이터 x] 
      |
      v
[평균(μ), 분산(σ²) 계산] -- (Mini-batch 단위)
      |
      v
[정규화: (x - μ) / √(σ² + ε)] -- (안정성을 위한 ε 추가)
      |
      v
[스케일/시프트: y = γ * 정규화x + β] -- (표현력 복원)
      |
      v
[활성화 함수(ReLU 등) 적용]
```

## Ⅳ. 문제점 및 개선방안

1. **[배치 크기 의존성]**: 배치 크기가 작을 경우 평균/분산 추정의 편차가 커져 학습이 불안정해짐
   - **개선방안**: 배치 크기에 무관한 Layer Normalization 또는 Group Normalization을 적용함 (확인: 수렴 안정성)
2. **[학습/추론 모드 불일치]**: 학습 시의 배치 통계와 추론 시의 이동 평균 통계 간의 차이로 성능 저하 발생 가능
   - **개선방안**: 추론 전 충분한 학습 데이터를 통한 이동 평균(Running Statistics) 업데이트를 수행함 (확인: 추론 정확도)
3. **[순환 신경망(RNN) 적용 한계]**: 시퀀스 길이에 따라 배치 통계 산출이 어렵고 시간축 정규화가 복잡함
   - **개선방안**: 시간축 영향이 적은 Layer Normalization을 대안으로 사용함 (확인: 시퀀스 손실값)

## Ⅴ. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|:---|:---|:---|
| **대규모 CNN 모델 학습** | ResNet, Inception 등 깊은 신경망의 Conv 레이어 직후 적용 | Top-1 Accuracy, 학습 수렴 속도 |
| **전이 학습(Fine-tuning)** | 사전 학습된 BN 층의 통계량 고정(Freeze) 또는 재학습 여부 결정 | Val-Loss, 학습률(Learning Rate) 최적화 |
| **분산 환경 학습** | 다중 GPU 환경에서 SyncBatchNorm을 통해 배치 통계의 일관성 확보 | GPU별 Gradient 편차, 모델 일반화 성능 |

> 요약: 실무에서는 모델 구조와 데이터 특성에 맞춰 BN의 적용 위치와 통계 갱신 전략을 설계해야 함

## Ⅵ. 결론

배치 정규화는 내부 공변량 변화 억제와 가중치 스케일링을 통해 딥러닝 모델의 안정적인 고속 학습을 가능케 하는 표준 기술임. 다만 배치 크기에 대한 의존성과 추론 시 통계량 관리의 복잡성을 고려하여, 분산 학습이나 시계열 데이터 처리 시에는 상황에 맞는 정규화 기법(LayerNorm, GroupNorm 등)과의 비교 선택이 필수적임.
