## Ⅰ. 개요
- 정의: 각 층의 활성화 값을 평균 0, 분산 1로 정규화하여 학습 속도와 안정성을 높이는 기법임
- 배경: 계층이 깊어질수록 입력 분포가 변하는 '내부 공변량 변화' 문제 해결 필요
- 출제 의도:
| 구분 | 내용 |
| --- | --- |
| 핵심 | 내부 공변량 변화, 정규화, 스케일링/시프트 |

## Ⅱ. 구성요소
- ASCII 구조도
  [X] -> [Mean/Var Calc] -> [Normalize] -> [Scale/Shift] -> [Out]
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 평균/분산 | 미니배치 단위로 계산되는 통계량 | 기준점 |
| 정규화 | 데이터를 표준 분포 형태로 변환함 | 평준화 |
| 감마/베타 | 학습 가능한 파라미터로 데이터 복원함 | 미세조정 |
> 요약: 학습 과정에서 입력 분포를 일정하게 유지하여 최적화를 가속함

## Ⅲ. 절차
- ASCII 흐름도
  [배치추출] -> [통계량계산] -> [표준화] -> [변환복구]
- 4단계 설명
1. 배치 추출: 학습 데이터 중 정해진 크기의 미니배치를 가져옴
2. 통계량 계산: 해당 배치의 평균과 분산을 산출함
3. 표준화: 계산된 통계량을 바탕으로 데이터를 0~1 사이로 조정함
4. 변환 복구: 학습된 감마, 베타를 적용하여 비선형성을 보존함
> 요약: 층별 입력 데이터의 불균형을 해소하여 기울기 소실을 방지함

## Ⅳ. 문제점
- 미니배치 크기에 의존적이어서 너무 작은 배치에선 성능 저하됨
- RNN 등 순차 데이터 모델에 적용하기 까다로움

## Ⅴ. 개선방안
- (단기) 충분한 크기의 미니배치 사이즈를 확보함
- (중기) Layer/Group Normalization 등 대안 기법을 검토함
- (장기) Weight Standardization 등 가중치 자체 정규화와 혼용함

## Ⅵ. 전망
- CNN 기반 모델의 표준 구성 요소로 정착되었으며 성능 필수요소임
