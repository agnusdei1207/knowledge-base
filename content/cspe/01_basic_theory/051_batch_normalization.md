## 미리 알고가기

- 내부 공변량 변화($Internal$ $Covariate$ $Shift$): 학습 과정에서 이전 층의 파라미터 변화로 인해 다음 층의 입력 분포가 계속 바뀌는 현상임
- 미니 배치($Mini-batch$): 학습 효율을 위해 전체 데이터를 작은 단위로 나누어 가중치를 업데이트하는 묶음임
- 정규화($Normalization$): 데이터의 범위를 특정 구간으로 맞추거나 평균 0, 분산 1의 분포로 변환하는 작업임
- 학습 가능 파라미터 ($\gamma, \beta$): 정규화된 데이터를 다시 적절히 변형($Scale$ & $Shift$)하여 모델의 표현력을 유지하는 계수임

## Ⅰ. 개요

- **정의/개념**: 배치 정규화는 신경망의 각 층에 들어오는 입력값의 분포를 미니 배치 단위로 평균 0, 분산 1이 되도록 강제로 정규화하여 학습 과정을 안정화하고 가속화하는 기법임
- **배경/필요성**: 층이 깊어질수록 하위 층의 미세한 변화가 상위 층에 누적되어 분포가 요동치는 '내부 공변량 변화' 문제가 발생하고, 이로 인해 학습 속도가 느려지고 초기값에 너무 민감해지는 문제를 해결하기 위해 도입됨

## Ⅱ. 특징

- 각 층의 입력 분포를 일정하게 유지함으로써 가중치 초기화($Initialization$)에 대한 의존성을 크게 줄여주며, 훨씬 더 큰 학습률($Learning$ $Rate$)을 사용해도 수렴이 안정적임
- 정규화 과정에서 미니 배치마다 다른 평균과 분산이 노이즈 역할을 수행하여, 마치 드롭아웃($Dropout$)과 같은 약간의 규제($Regularization$) 효과를 주어 과적합을 방지하는 데 도움을 줌
- 학습 시에는 현재 배치의 통계치를 사용하지만, 추론($Inference$) 시에는 학습 과정에서 계산된 이동 평균($Moving$ $Average$) 통계치를 고정하여 사용함

## Ⅲ. 종류 및 비교

| 판단 기준 | 배치 정규화 (Batch Norm) | 레이어 정규화 (Layer Norm) | 그룹 정규화 (Group Norm) |
|:---|:---|:---|:---|
| **정규화 대상** | 배치($N$) 축 기준 | 각 샘플의 특징($C,H,W$) 축 기준 | 채널별 소그룹 기준 |
| **배치 크기 영향** | 매우 큼 (작으면 불안정) | 영향 없음 | 영향 없음 |
| **적합 분야** | 합성곱 신경망 ($CNN$) | 순환 신경망 ($RNN$), 트랜스포머 | 소규모 배치 비전 모델 |
| **주요 특징** | 가장 범용적이나 병렬화 복잡 | 가변 길이 데이터에 유리 | 배치 정규화의 배치 의존성 해결 |

> 요약: BatchNorm은 배치 간 통계를, LayerNorm은 샘플 내부 통계를 활용함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 배치 평균 ($\mu_B$) | 현재 미니 배치 내 모든 데이터의 평균값으로, 원점 이동의 기준임 |
| 배치 분산 ($\sigma_B^2$) | 현재 미니 배치 데이터의 퍼짐 정도로, 스케일 조정의 기준임 |
| 표준화 ($Standardize$) | 평균을 빼고 표준편차로 나누어 데이터 분포를 일정하게 맞추는 연산임 |
| 아핀 변환 ($Affine$) | $\gamma \cdot \hat{x} + \beta$ 연산을 통해 정규화된 데이터에 표현력을 다시 부여함 |

```text
[ 배치 정규화 공식 ]
y = γ * ((x - μ) / √(σ² + ε)) + β
- ε: 분모가 0이 되는 것을 방지하는 아주 작은 상수
- γ: 스케일 (Scale) 조정 파라미터
- β: 이동 (Shift) 파라미터
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 미니 배치 입력| --> | 평균/분산 산출 | --> | 정규화/아핀변환| --> | 활성화 함수 통과|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **통계량 계산** — 현재 층에 들어온 미니 배치 데이터셋에 대해 채널별로 평균과 분산을 실시간으로 계산함
2. **분포 표준화** — 계산된 통계를 바탕으로 모든 데이터를 평균 0, 분산 1인 표준 정규 분포의 형태로 변환함
3. **복원 및 변형** — 정규화로 인해 손실될 수 있는 모델의 표현력을 복구하기 위해, 학습 가능한 파라미터($\gamma, \beta$)를 적용하여 데이터를 다시 변형함
4. **연쇄 업데이트** — 역전파 시 오차 기울기가 $\gamma, \beta$까지 전달되어 업데이트되며, 학습이 끝나면 전체 훈련 데이터의 평균/분산 기댓값을 저장하여 추론에 사용함

## Ⅵ. 실무 적용 및 유의점

1. 배치 정규화는 배치 크기가 너무 작으면(예: $N=1$) 평균과 분산의 추정치가 부정확해져 학습이 오히려 방해받을 수 있으므로, 최소 8~16 이상의 배치 크기를 확보하거나 '그룹 정규화'와 같은 대안을 고려해야 함
2. 활성화 함수 적용 '직후'보다는 가중합 계산 '직후'($Linear$ $\rightarrow$ $BN$ $\rightarrow$ $Activation$)에 배치 정규화를 배치하는 것이 초기 논문에서 권장된 표준적인 위치이며 학습 효율이 더 높은 경우가 많음

## Ⅶ. 결론

- 배치 정규화는 깊은 신경망의 학습을 고속도로처럼 시원하게 뚫어주는 인프라 기술이며, 설계자는 정규화의 축과 배치 크기 사이의 제약 사항을 명확히 이해하여 시스템의 수렴 안정성을 최대로 끌어올려야 함
