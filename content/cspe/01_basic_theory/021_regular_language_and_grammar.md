## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| 정의 | 정규 표현식으로 표현 가능하고 유한 상태 기계(FSM)가 인식할 수 있는 가장 단순한 형태의 형식 언어임 |
| 배경/필요성 | 컴파일러의 어휘 분석, 텍스트 검색(grep), 문자열 패턴 매칭의 자동화를 위해 필요함 |
| 출제 의도 | 촘스키 위계의 최하위 계층에 대한 이해와 오토마타와의 연관성 파악 능력 평가 |

## Ⅱ. 구성요소
```text
+-------------------+       +-------------------+       +-------------------+
|  Regular Grammar  | ----> | Regular Expression| ----> | Finite Automaton  |
|  (Type-3 Grammar) |       | (Pattern Match)   |       | (DFA / NFA)       |
+-------------------+       +-------------------+       +-------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 정규 문법 | A -> aB 또는 A -> a 형태의 규칙을 갖는 생성 문법 | 언어 생성의 규칙집 |
| 정규 표현식 | 문자열의 패턴을 대수적 연산(합집합, 연결, 클레이니 스타)으로 표현 | 텍스트 검색 필터 |
| 유한 상태 기계 | 상태 전이를 통해 정규 언어를 인식하는 추상 기계 (상태 메모리 없음) | 패턴 판별기 |
> 요약: 정규 언어는 정규 문법, 정규 표현식, 유한 상태 기계라는 세 가지 등가적 방식으로 정의됨

## Ⅲ. 절차
```text
+----------------+    +----------------+    +----------------+    +----------------+
| 1. 정규식 작성 | -> | 2. NFA로 변환  | -> | 3. DFA로 변환  | -> | 4. DFA 최소화  |
+----------------+    +----------------+    +----------------+    +----------------+
```
1. 정규식 작성: 검출할 문자열의 패턴을 정규 표현식으로 정의함
2. NFA로 변환: 톰슨 구조 등을 이용하여 정규 표현식을 비결정적 유한 오토마타로 변환함
3. DFA로 변환: 부분집합 구성 알고리즘을 통해 NFA를 결정적 유한 오토마타로 변환함
4. DFA 최소화: 도달 불가능 상태 제거 및 동치 상태 병합으로 최소 상태 DFA를 생성함
> 요약: 정규식을 NFA를 거쳐 최소 상태 DFA로 변환하여 효율적인 패턴 매칭기를 구현함

## Ⅳ. 문제점
- 표현의 한계: 메모리(스택 등)가 없어 괄호의 짝 맞추기나 좌우 대칭 문자열 등 문맥 의존적 패턴을 표현할 수 없음
- 상태 폭발 현상: NFA를 DFA로 변환 시, 상태 수가 지수적으로 증가할 수 있어 메모리 부족 문제가 발생함

## Ⅴ. 개선방안
- 문맥 자유 문법 활용: 괄호 검사 등 재귀적 구조가 필요한 경우 푸시다운 오토마타(PDA)와 문맥 자유 문법을 사용함
- 최적화 알고리즘 적용: 레이지 DFA(Lazy DFA) 구성 방식이나 정규식 엔진 최적화를 통해 상태 폭발을 방지함

## Ⅵ. 전망
- 정규 언어는 어휘 분석과 로그 파싱 등에서 핵심 기술로 계속 사용되며, 복잡성 문제를 해결하기 위해 다양한 휴리스틱이 결합된 하이브리드 패턴 매칭 엔진으로 발전할 전망임
