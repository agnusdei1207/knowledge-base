## Ⅰ. 개요
- 정의: 기호들의 집합으로 구성된 언어의 수학적 추상화 및 생성 규칙 이론임.
- 배경: 프로그래밍 언어 설계 및 컴파일러 구현의 이론적 토대를 마련함.
- 출제 의도:
| 분류 | 상세 |
| --- | --- |
| 핵심요소 | 촘스키 계층, 오토마타, 생성 문법 |
| 주요특징 | 추상화 수준 분류, 계산 가능성 판단 |

## Ⅱ. 구성요소
- ASCII 구조도
 [Type 0: RE] > [Type 1: CSG] > [Type 2: CFG] > [Type 3: RG]
 (Turing M)    (LBA)          (Pushdown A)   (Finite A)
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 문법(Grammar) | 언어를 생성하는 규칙의 집합 (V, T, P, S) | 언어의 레시피 |
| 오토마타 | 해당 언어를 인식하는 추상적 기계 | 문법 검사기 |
| 촘스키 계층 | 제약 조건에 따른 언어의 4단계 분류 체계 | 언어의 계급도 |
> 요약: 언어의 생성 조건에 따라 계산 복잡도와 장치 수준을 정의함.

## Ⅲ. 절차
- ASCII 흐름도
[생성 규칙 설정] -> [심볼 치환] -> [문장 도출] -> [언어 형성]
- 4단계 설명
1. 비단말 기호 정의: 변환 가능한 중간 매개 기호를 설정함.
2. 단말 기호 정의: 최종적으로 생성될 결과물 기호를 결정함.
3. 생성 규칙 적용: 시작 기호로부터 규칙에 따라 기호를 확장함.
4. 언어 유도: 가능한 모든 단말 기호열의 집합을 도출함.
> 요약: 정해진 규칙에 따라 유한한 단계로 문장을 만들어내는 과정임.

## Ⅳ. 문제점
- 상위 계층으로 갈수록 인식 장치의 구현이 복잡하고 결정 불가능성이 존재함.

## Ⅴ. 개선방안
- 단기: 실제 컴파일러에서는 구현이 용이한 CFG와 RG를 주로 사용함.
- 중기: 파서 생성기(Yacc, Antlr)를 활용해 복잡한 문법 처리를 자동화함.
- 장기: 자연어의 복잡성을 모델링하기 위해 확률적 문법(PCFG)을 도입함.

## Ⅵ. 전망
- 양자 컴퓨팅 및 신경망 기반 언어 이해의 이론적 검증 도구로 지속 활용됨.
