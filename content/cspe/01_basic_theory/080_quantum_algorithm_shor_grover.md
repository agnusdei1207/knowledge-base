## Ⅰ. 개요
- 정의: 양자 역학의 중첩과 얽힘 현상을 이용해 계산 효율을 극대화한 알고리즘임.
- 배경: 고전 컴퓨터로 해결 불가능한 지수적 복잡도 문제를 해결하기 위함임.
- 출제 의도:
| 분류 | 상세 |
| --- | --- |
| 핵심요소 | 큐비트, 쇼어(Shor), 그로버(Grover), 양자 게이트 |
| 주요특징 | 지수적/제곱근 가속, 확률적 결과 도출 |

## Ⅱ. 구성요소
- ASCII 구조도
 |0> --[H]---[Target]---[H]-- (Measurement)
 |1> --[H]---[Oracle]---[H]--
 (Superposition) (Compute)
- 구성요소 표
| 구성요소 | 설명 | 비유 |
| --- | --- | --- |
| 큐비트(Qubit) | 0과 1이 동시에 존재 가능한 양자 정보 단위 | 동전 던지기 중 |
| 쇼어 알고리즘 | 소인수 분해를 다항 시간 내 수행 (RSA 위협) | 암호 해독기 |
| 그로버 알고리즘 | 비정렬 데이터 검색 속도를 제곱근으로 단축 | 고속 탐색기 |
> 요약: 양자 병렬성을 활용해 특정 난제에 대해 혁신적 속도를 제공함.

## Ⅲ. 절차
- ASCII 흐름도
[양자 상태 초기화] -> [중첩 생성] -> [연산 수행] -> [상태 관측]
- 4단계 설명
1. 중첩 형성: 하다마드(H) 게이트를 적용해 모든 가능성을 동시 표현함.
2. 오라클 적용: 찾고자 하는 데이터나 수식에 표식을 남김.
3. 진폭 증폭: 확률 간섭을 통해 정답의 발생 확률을 높임.
4. 측정: 양자 상태를 붕괴시켜 최종적인 비트 값을 얻음.
> 요약: 모든 가능성에서 시작하여 확률 조작을 통해 정답을 도출함.

## Ⅳ. 문제점
- 양자 결어긋남(Decoherence) 및 낮은 연산 정확도(Error Rate)가 존재함.

## Ⅴ. 개선방안
- 단기: 양자 오류 정정(QEC) 코드를 적용하여 계산의 신뢰성을 높임.
- 중기: NISQ(중간규모 양자) 장치에 적합한 하이브리드 알고리즘을 개발함.
- 장기: 상온 동작 및 확장 가능한 결함 허용(Fault-tolerant) 양자 컴퓨터 구축함.

## Ⅵ. 전망
