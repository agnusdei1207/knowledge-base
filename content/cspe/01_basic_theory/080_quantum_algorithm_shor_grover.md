# 📖 【암기용】 개념 완전 이해

> 목적: 양자 알고리즘을 처음 보는 사람도 완벽히 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 양자 알고리즘은 큐비트의 중첩·간섭·측정을 이용해 특정 문제에서 고전 알고리즘과 다른 계산 복잡도를 달성하는 방법임
- **왜 필요한가**: RSA·ECC 같은 암호 난제와 비정렬 검색 문제는 고전 컴퓨터에서 비용이 크다. 쇼어 알고리즘은 소인수분해, 그로버 알고리즘은 비정렬 탐색에서 대표 이점을 제시함.
- **핵심 직관**: 가능한 답을 모두 동시에 "살펴본다"기보다, 틀린 경로의 진폭은 줄이고 맞는 경로의 진폭은 키우는 간섭을 설계하는 방식임.

## 깊이 이해
- **배경·문제의식**: 고전 비트는 0 또는 1이지만 큐비트는 측정 전 중첩 상태를 갖는다. 양자 게이트는 상태 벡터를 단위 행렬로 변환하고, 측정은 확률적으로 결과를 확정함.
- **작동 원리**: 쇼어 알고리즘은 주기 찾기를 양자 푸리에 변환(QFT)으로 처리해 소인수분해를 다항시간에 수행함. 그로버 알고리즘은 oracle과 amplitude amplification으로 N개 후보 검색을 O(sqrt N) 반복으로 줄임.
- **비유**: 물결이 서로 보강·상쇄되는 것처럼, 양자 회로는 정답 진폭이 보강되도록 게이트 순서를 설계함.
- **구체 예시**: 128비트 대칭키 전수조사는 고전 기준 2^128 후보이나, 그로버 적용 시 보안 강도는 대략 2^64 수준으로 감소하므로 AES-256 선택 근거가 됨.
- **흔한 오해·주의점**: 양자 알고리즘이 모든 문제를 지수적으로 줄이지 않는다. 이점은 문제 구조, oracle 구성, 오류정정 큐비트 수, 회로 깊이에 의존함.

## 연결 개념
- 양자 오류정정 — 긴 회로 실행을 위해 논리 큐비트를 보호하는 기술
- PQC — 양자 위협에 대비한 격자·해시·코드 기반 암호
- 계산복잡도 — BQP, P, NP 관계를 판단하는 이론 배경

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 양자 알고리즘은 큐비트 중첩, 얽힘, 간섭, 측정을 이용해 특정 문제의 시간복잡도를 변화시키는 계산 절차임.
> 2. **가치**: 쇼어는 RSA/ECC 기반 공개키 암호 전환 압력, 그로버는 대칭키·해시 보안 강도 재평가 근거를 제공함.
> 3. **판단 포인트**: 알고리즘 이점과 실제 적용 가능성은 논리 큐비트 수, 오류율, 회로 깊이, oracle 구성 비용을 함께 봐야 함.

---

## Ⅰ. 개요 및 필요성

양자 알고리즘은 양자역학 원리를 이용한 계산 절차이다. 쇼어·그로버 알고리즘은 암호, 검색, 최적화 영역에서 고전 계산 한계를 재평가하게 만든다. CSPE 답안에서는 알고리즘 원리뿐 아니라 PQC 전환, 키 길이 조정, 오류정정 한계를 함께 제시해야 함.

---

## Ⅱ. 구조 및 구성요소

```text
문제 입력 -> 큐비트 초기화 -> 양자 게이트 -> oracle/QFT -> 측정 -> 고전 후처리
                         / Shor: QFT 기반 주기 찾기
                         / Grover: amplitude amplification
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 큐비트 | 0과 1의 중첩 상태 표현 | 측정 전 확률 진폭 유지 |
| 양자 게이트 | 상태 벡터를 단위 변환 | Hadamard, CNOT, phase gate |
| Oracle/QFT | 문제 구조를 회로에 반영 | Grover oracle, Shor QFT |
| 측정·후처리 | 확률 결과를 고전 값으로 변환 | 반복 실행과 통계 검증 필요 |

> 요약: 양자 알고리즘은 큐비트 상태를 게이트와 oracle/QFT로 조작한 뒤 측정 결과를 고전 후처리해 해를 얻음.

---

## Ⅲ. 동작원리 및 흐름도

```text
문제 인코딩 -> 중첩 생성 -> 정답 진폭 조작 -> 반복 증폭/주기 추출 -> 측정 -> 검증
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 문제를 큐비트와 회로로 인코딩 | 큐비트 수, gate count 산정 |
| 2 | Hadamard 등으로 중첩 생성 | 상태 준비 오류율 확인 |
| 3 | Shor QFT 또는 Grover oracle 적용 | 회로 깊이, oracle 비용 |
| 4 | 측정 후 고전 검증 | 성공확률, 반복 횟수, 오류율 |

> 요약: 양자 알고리즘은 인코딩, 중첩, 간섭 조작, 측정, 고전 검증 순서로 동작하며 오류율과 회로 깊이가 실행 가능성을 결정함.

---

## Ⅳ. 특징

| 구분 | 내용 | 판단 포인트 |
|:---|:---|:---|
| 장점 | Shor는 소인수분해를 다항시간, Grover는 검색을 O(sqrt N)으로 처리 | RSA/ECC, 대칭키 보안 강도 영향 |
| 한계 | 오류정정 없는 NISQ 장비는 긴 회로 실행 제한 | 논리 큐비트, physical qubit overhead |
| 비교 대상 | 고전 알고리즘은 비트·순차/병렬 연산 기반 | 양자는 진폭 간섭과 측정 확률 기반 |
| 보안 영향 | AES-128은 Grover 고려 시 64비트 강도 수준으로 평가 | AES-256, SHA-384 이상 검토 |

> 요약: 양자 알고리즘은 암호와 검색의 복잡도 판단을 바꾸지만 실제 적용은 오류정정과 회로 자원 확보가 전제임.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | 기존/대안 | 본 키워드 | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | 고전 비트와 논리 게이트 | 큐비트, 양자 게이트, 측정 | 문제에 양자 이점이 증명된 경우 |
| 비용/성능 | RSA 인수분해는 큰 입력에서 고전 비용 증가 | Shor는 다항시간 이론 이점 | 오류정정 논리 큐비트 확보 여부 |
| 운영/위험 | 기존 PKI, RSA/ECC 인증서 | PQC 하이브리드 전환 필요 | 장기 기밀 데이터는 crypto-agility 적용 |

> 요약: 양자 알고리즘은 이론 이점과 실물 자원 요구를 분리해 판단하고, 보안 영역은 PQC 전환을 선제 적용해야 함.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 암호 붕괴 위험 | Shor의 RSA/ECC 영향 | NIST PQC KEM/서명 전환, 하이브리드 TLS | RSA/ECC 자산 비율, PQC 적용률 |
| 보안강도 감소 | Grover의 sqrt 탐색 | AES-256, SHA-384/512 적용 | 키 길이, 해시 출력 길이 |
| 실행 불확실성 | NISQ 오류율과 decoherence | 오류정정, 회로 최적화, 반복 검증 | logical error rate, circuit depth |

> 요약: 양자 리스크는 공개키 전환, 대칭키 길이 조정, 오류정정 성숙도 지표로 관리해야 함.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 암호 자산 | RSA/ECC 사용처 100% 식별 | 인증서·소스·KMS 인벤토리 |
| 전환 준비 | PQC 하이브리드 PoC, crypto-agility API | TLS handshake 테스트, 상호운용성 시험 |
| 양자 실행성 | 큐비트 수, gate fidelity, circuit depth 기록 | Qiskit/Cirq 시뮬레이션, 벤치마크 |

> 요약: 실무 점검은 알고리즘 설명보다 암호 자산 식별, PQC PoC, 회로 자원 지표 확보에 초점을 둬야 함.

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 — 단계별 또는 항목별):**
1. 암호 자산 조사: RSA, ECDSA, ECDH, DH 사용처를 인증서·KMS·소스코드에서 식별하고 장기 보존 데이터부터 위험 등급을 부여함.
2. PQC 전환: NIST PQC 기반 ML-KEM/ML-DSA 적용 가능성을 PoC하고, 기존 ECDHE와 PQC KEM을 병행하는 하이브리드 방식을 검토함.
3. 대칭키 조정: Grover 영향이 큰 장기 보안 데이터는 AES-256, SHA-384 이상을 기준으로 키 길이와 해시 정책을 개정함.

**결론 (2줄):**
- 기술사 판단: 현재 범용 업무는 고전 알고리즘을 유지하되, 장기 기밀성과 PKI 영역은 PQC 하이브리드 전환을 우선 수행해야 함.
- 향후 방향: 양자 오류정정과 논리 큐비트 규모가 확대될수록 쇼어·그로버는 암호 정책과 최적화 알고리즘의 핵심 판단 기준이 됨.
