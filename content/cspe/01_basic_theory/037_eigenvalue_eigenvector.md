# 고유값·고유벡터 (Eigenvalue Eigenvector)

## 1. 개요

- **정의/개념**: 고유벡터는 선형 변환을 적용해도 방향이 변하지 않는 벡터이고, 고유값은 그 벡터가 얼마나 확대·축소되는지를 나타내는 스칼라이다.
- **배경/필요성**: 행렬 변환의 본질적 방향과 크기를 알면 차원 축소, 안정성 분석, 그래프 중요도 계산처럼 복잡한 구조를 해석할 수 있다.

고유값·고유벡터는 `A x = lambda x` 관계로 선형 변환의 핵심 축을 찾는 개념이다.

## 2. 특징 및 비교

| 구분 | 고유값·고유벡터 | 특이값 분해(SVD) |
|---|---|---|
| 대상 | 주로 정방행렬 | 임의 행렬 가능 |
| 의미 | 변하지 않는 방향과 배율 | 직교 축과 크기 분해 |
| 활용 | 안정성, PageRank, PCA | 차원 축소, 추천, 압축 |
| 제약 | 대각화 가능성 영향 | 일반적으로 더 안정적 |

선택 기준은 행렬 형태, 대각화 가능성, 수치 안정성, 해석 목적이다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| Matrix A | 선형 변환 | 분석 대상 |
| Eigenvector x | 방향이 유지되는 벡터 | `x != 0` |
| Eigenvalue lambda | 확대·축소 비율 | 변환 강도 |
| Characteristic Equation | `det(A - lambda I)=0` | 고유값 계산 |
| Diagonalization | 고유벡터 기저로 행렬 분해 | 계산 단순화 |

```text
+----------+      +----------+      +----------+
| 변환 A   | ---> | 방향유지 | ---> | 배율 lambda |
+----------+      +----------+      +----------+
                 A x = lambda x
```

고유값은 변환의 크기 특성을, 고유벡터는 변환의 방향 특성을 설명하므로 둘을 분리해 이해해야 한다.

## 4. 문제점 및 개선방안

1. **대각화 불가능**
   - 고유벡터가 충분하지 않으면 대각화로 단순화할 수 없다.
   - **개선방안**: Jordan form, Schur decomposition, SVD를 검토한다.

2. **수치 불안정**
   - 근접한 고유값이나 ill-conditioned 행렬에서는 계산 오차가 커질 수 있다.
   - **개선방안**: 정규화, 안정적 분해 알고리즘, 조건수 확인을 수행한다.

3. **해석 과잉**
   - 큰 고유값이 항상 도메인상 중요한 의미를 갖는 것은 아니다.
   - **개선방안**: 데이터 전처리, 스케일링, 도메인 검증과 함께 해석한다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| PCA | 공분산 행렬의 고유벡터로 주성분 추출 | 설명 분산 |
| PageRank | 전이 행렬의 주 고유벡터로 중요도 계산 | 수렴성, 순위 안정성 |
| 시스템 안정성 | 상태 행렬 고유값으로 안정성 판단 | 고유값 위치 |

## 6. 결론

고유값과 고유벡터는 선형 변환이 유지하는 방향과 배율을 드러내는 분석 도구이다. `A x = lambda x`, 특성 방정식, 대각화 조건, SVD 대안을 함께 연결해야 계산 의미와 실무 한계가 분명해진다.
