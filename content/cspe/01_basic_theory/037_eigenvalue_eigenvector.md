## 미리 알고가기

- 선형 변환: 행렬 $A$를 벡터 $x$에 곱하여 새로운 벡터 $Ax$로 변환하는 과정임
- 불변 방향: 변환 전후의 방향은 같고 크기만 변하는 특별한 벡터의 방향임
- 고유벡터($Eigenvector$): 선형 변환 시 방향이 변하지 않는 0이 아닌 벡터임
- 고유값($Eigenvalue$): 고유벡터가 변환에 의해 확대 또는 축소되는 배율($\lambda$)임

## Ⅰ. 개요

- **정의/개념**: 고유값과 고유벡터는 선형 변환 $Ax = \lambda x$를 만족하는 상수 $\lambda$와 벡터 $x$를 의미하며, 복잡한 행렬 연산을 본질적인 물리적 특성(축과 배율)으로 분해하여 해석하는 도구임
- **배경/필요성**: 데이터의 주성분 추출($PCA$), 진동 해석, 양자 역학, 구글의 페이지랭크($PageRank$) 알고리즘 등에서 시스템의 가장 지배적인 특성을 파악하고 계산량을 줄이기 위해 필수적임

## Ⅱ. 특징

- 행렬 $A$에 의한 변환을 단순히 스칼라 값 $\lambda$의 곱셈으로 환원시켜 계산 효율성을 극대화하며, 이를 통해 행렬의 거듭제곱 등을 매우 빠르게 수행할 수 있음
- 고유벡터들은 서로 독립적일 경우 시스템의 새로운 기저($Basis$) 역할을 수행하며, 원본 데이터를 고유벡터 축으로 투영함으로써 데이터의 핵심 정보를 보존한 채 차원을 축소할 수 있음
- 고유값의 크기는 해당 고유벡터 방향으로의 정보량 또는 영향력을 나타내며, 고유값이 0에 가까울수록 해당 방향의 정보는 무시하거나 제거할 수 있는 노이즈로 간주됨

## Ⅲ. 종류 및 비교

| 비교 항목 | 고유값 분해 (Eigendecomposition) | 특이값 분해 (SVD) |
|:---|:---|:---|
| **대상 행렬** | 주로 정방행렬 ($n \times n$) | 모든 형태의 행렬 ($m \times n$) |
| **분해 방식** | $A = PDP^{-1}$ (대각화 가능 시) | $A = U\Sigma V^T$ (항상 가능) |
| **물리적 의미** | 시스템의 고유한 진동/주축 특성 | 데이터의 공간적 변동성/특징 추출 |
| **주요 활용** | 마르코프 연쇄, 선형 미분방정식 | 이미지 압축, 추천 시스템, $LSA$ |

> 요약: 고유값 분해는 시스템의 내적 성질에 집중하고, SVD는 데이터의 일반적인 구조 분석에 집중함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 특성 방정식 | $\det(A - \lambda I) = 0$을 만족하는 $\lambda$를 구하는 다항식임 |
| 고유 공간 | 동일한 고유값 $\lambda$에 대응하는 모든 고유벡터들과 영벡터의 집합임 |
| 대각 행렬 ($D$) | 대각 성분에 고유값들을 배치한 행렬로, 연립방정식의 결합을 해제함 |
| 직교 행렬 | 대칭 행렬의 경우 고유벡터들이 서로 수직(직교)인 성질을 가짐 |

```text
[ 기본 관계식 ]
A * x = λ * x
- A: n x n 행렬 (변환)
- x: 고유벡터 (방향)
- λ: 고유값 (스칼라 배율)
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 특성방정식 도출| --> | 고유값(λ) 산출| --> | 연립방정식 풀이| --> | 고유벡터(x) 결정|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **방정식 구성** — 행렬 $A$에서 단위 행렬의 $\lambda$배를 뺀 행렬의 행렬식($Determinant$)을 0으로 만드는 특성 다항식을 세움
2. **해 탐색** — 다항식의 근을 구하여 행렬 $A$가 가지는 모든 고유값 $\lambda$들을 찾아냄
3. **벡터 도출** — 각 고유값 $\lambda$를 $(A - \lambda I)x = 0$ 식에 대입하여, 영벡터가 아닌 해(고유벡터)들을 계산함
4. **정규화/활용** — 얻어진 고유벡터들의 크기를 1로 맞추고(정규화), 이를 주축으로 사용하여 데이터를 변환하거나 행렬을 대각화함

## Ⅵ. 실무 적용 및 유의점

1. 데이터 분석 시 모든 고유성분을 다 사용하기보다 고유값의 크기 순으로 정렬하여 누적 기여율이 80~90%가 되는 상위 고유벡터만 선택함으로써, 데이터의 차원을 획기적으로 줄이되 정보 손실은 최소화하는 전략($PCA$)을 수립해야 함
2. 실제 대규모 행렬 연산에서는 특성 방정식을 직접 푸는 방식이 매우 비효율적이므로, $QR$ 알고리즘이나 거듭제곱법($Power$ $Method$)과 같은 수치 해석적 반복법을 활용하여 계산 안정성과 속도를 확보해야 함

## Ⅶ. 결론

- 고유값과 고유벡터는 선형 시스템의 내부 구조를 꿰뚫어 보는 수학적 렌즈이며, 설계자는 이를 통해 대규모 데이터의 본질적인 특징을 추출하고 복잡한 동적 시스템의 안정성을 정밀하게 제어해야 함
