## Ⅰ. 개요
- 정의: 선형 변환 시 방향은 변하지 않고 크기만 변하는 벡터(고유벡터)와 그 배율(고유값)임
- 배경/필요성: 행렬의 본질적인 특성을 파악하고 차원 축소(PCA) 등에 핵심적으로 사용됨
- 출제 의도: 특성 방정식 det(A-λI)=0을 이용한 고유값 계산 및 물리적 의미 파악

## Ⅱ. 구성요소
- ASCII 구조도
      Ax = λx
  (Matrix)*(Vector) = (Scalar)*(Vector)
      |      |           |      |
     변환   고유벡터     고유값  고유벡터

- 구성요소 표
| 구성요소 | 설명 | 비유 |
| :--- | :--- | :--- |
| 고유값 (λ) | 변환 후 벡터의 길이가 늘어나거나 줄어드는 비율 | 확대/축소율 |
| 고유벡터 (x) | 변환 후에도 방향이 유지되는 영이 아닌 벡터 | 주축 (Main Axis) |
| 특성 방정식 | 고유값을 구하기 위한 다항 방정식 | 단서 찾기 |
| 고유 공간 | 동일한 고유값에 대응하는 고유벡터들의 집합 | 확장 공간 |
> 요약: 행렬 A의 작용을 단순한 스칼라 곱 λ로 대체할 수 있는 특별한 상태임

## Ⅲ. 절차
- ASCII 흐름도
  [Matrix A] -> [det(A-λI)=0] -> [Solve λ] -> [Solve (A-λI)x=0] -> [Find x]

1. 방정식 설정: (A - λI)v = 0 형태의 식을 구성함
2. 고유값 산출: 행렬식이 0이 되는 λ 값을 다항식 풀이를 통해 찾음
3. 고유벡터 계산: 각 고유값을 대입하여 연립방정식을 풀고 기저 벡터를 구함
4. 정규화: 계산된 고유벡터의 크기를 1로 맞추어 표준화함
> 요약: 행렬 연산을 단순 수치(스칼라) 연산으로 치환하는 과정임

## Ⅳ. 문제점
- 계산 복잡도: 행렬이 커질수록 고차 방정식 풀이가 어려워져 수치 해석적 기법 필요함
- 허근 발생: 실수 행렬에서도 고유값이 복소수로 나올 수 있어 물리적 해석이 난해해짐

## Ⅴ. 개선방안
- 대각화: 고유벡터를 기저로 삼아 행렬을 대각 행렬로 변환하여 연산 효율화함
- QR 알고리즘: 반복법을 통해 대규모 행렬의 고유값을 안정적으로 근사함

## Ⅵ. 전망
- PCA (주성분 분석): 데이터의 분산이 최대인 고유벡터 방향을 찾아 차원을 축소함
- 구글 페이지랭크: 웹 페이지 간 연결 행렬의 주 고유벡터를 이용해 순위를 산정함
