## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 정사각 행렬 $A$에 대해 $Av = \lambda v$를 만족하는 영이 아닌 벡터 $v$가 **고유벡터(Eigenvector)**, 스칼라 $\lambda$가 **고유값(Eigenvalue)**이다. 고유벡터는 선형 변환 $A$에 의해 **방향이 변하지 않고 크기만 $\lambda$배 되는** 특별한 벡터이다.
> 2. **가치**: PCA(주성분 분석)는 공분산 행렬의 고유벡터 방향으로 데이터를 투영하여 차원을 축소한다. PageRank는 웹 그래프 전이 행렬의 최대 고유값에 대응하는 고유벡터이다. 진동 분석, 양자역학, 마르코프 체인 — 모두 고유값 문제이다.
> 3. **융합**: AI(PCA, SVD, 스펙트럼 클러스터링), 검색(PageRank), 물리(고유 진동수 = 고유값), 제어공학(시스템 안정성 = 고유값의 절대값 < 1), 양자(에너지 준위 = 해밀토니안의 고유값) 등.

### 🔑 핵심 용어 정리

| 용어 | 뜻 | 비유 |
|:---|:---|:---|
| **고유값($\lambda$)** | $Av = \lambda v$의 스칼라. 선형 변환이 고유벡터를 늘이거나 줄이는 배율 | "확대/축소 배율" |
| **고유벡터($v$)** | $Av = \lambda v$의 벡터. 선형 변환 후에도 방향이 변하지 않는 특별한 벡터 | "바람에 안 흔들리는 깃대 방향" |
| **특성 방정식** | $\det(A - \lambda I) = 0$. $N$차 다항식으로, 근이 곧 고유값 | "고유값 찾는 공식" |
| **고유 분해(Eigendecomposition)** | $A = P \Lambda P^{-1}$. 대각화 가능 시 행렬을 고유값·고유벡터로 분해 | "행렬의 DNA 검사" |
| **SVD(Singular Value Decomposition)** | $A = U \Sigma V^T$. 모든 행렬(비정사각 포함)에 적용 가능한 일반화된 분해 | "만능 행렬 분해" |
| **스펙트럼(Spectrum)** | 행렬의 모든 고유값의 집합. 행렬의 본질적 성질을 결정 | "행렬의 지문" |

## Ⅰ. 개요 및 필요성

- **개념**: $N \times N$ 행렬 $A$에 대해:

$$
Av = \lambda v \quad (v \neq 0)
$$

특성 방정식 $\det(A - \lambda I) = 0$을 풀면 고유값 $\lambda_1, \ldots, \lambda_N$을 구할 수 있고, 각 $\lambda_i$에 대해 $(A - \lambda_i I)v = 0$을 풀면 고유벡터 $v_i$를 구한다.

- **필요성**: $A^k$를 구해야 하는 상황(마르코프 체인, 피보나치 수열의 닫힌 형태)에서 고유 분해를 사용하면 $A^k = P \Lambda^k P^{-1}$이므로, 대각 행렬의 $k$제곱은 각 원소를 $k$제곱하는 $O(N)$ 연산으로 줄어든다.

- **비유**: 선형 변환을 받았을 때 대부분의 벡터는 방향이 변하지만, 고유벡터는 **"굳건히 한 방향을 유지하며 크기만 변하는"** 벡터이다. 진동하는 기타줄의 각 진동 모드(기본음, 배음)가 고유벡터이고, 각 모드의 진동수가 고유값이다.

```text
+-----------------------------------------------------------------------+
|        고유벡터의 기하학적 의미                                        |
+-----------------------------------------------------------------------+
|                                                                       |
|  일반 벡터 u:                                                         |
|  u → Au (방향도 크기도 바뀜)                                         |
|                                                                       |
|  고유벡터 v:                                                          |
|  v → Av = λv (방향 유지, 크기만 λ배)                                |
|                                                                       |
|  예시: A = [[2, 1], [1, 2]]                                         |
|  고유값: λ₁ = 3, λ₂ = 1                                              |
|  고유벡터: v₁ = [1, 1], v₂ = [1, -1]                                |
|                                                                       |
|     v₂ [1,-1]                                                        |
|      ↑                                                                |
|      |   / v₁ [1,1]                                                  |
|      |  /                                                             |
|      | /                                                              |
|  ----O--------→                                                      |
|      |                                                                |
|  A를 적용하면:                                                        |
|  v₁ 방향은 3배 늘어남 (λ₁=3)                                        |
|  v₂ 방향은 그대로 (λ₂=1)                                            |
+-----------------------------------------------------------------------+
```

**[다이어그램 해설]** 행렬 $A = \begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}$의 두 고유벡터를 보여준다. $v_1 = (1,1)$ 방향은 $\lambda_1 = 3$배로 늘어나고, $v_2 = (1,-1)$ 방향은 $\lambda_2 = 1$배(변화 없음)이다. 이 두 고유벡터 방향으로 좌표축을 잡으면, 행렬 $A$는 대각 행렬 $\text{diag}(3, 1)$이 된다 — 이것이 대각화의 기하학적 의미이다.

- **📢 섹션 요약 비유**: 고유벡터는 "태풍의 눈"입니다. 주변은 다 휘청거리는데, 고유벡터 방향만은 꿋꿋이 자기 방향을 유지합니다.

## Ⅱ. 아키텍처 및 핵심 원리

### 구성 요소

| 요소명 | 수식 | 시간 복잡도 | 용도 | 비유 |
|:---|:---|:---|:---|:---|
| **특성 방정식** | $\det(A - \lambda I) = 0$ | $O(N^3)$ 이상 | 고유값 이론적 정의 | 방정식 풀기 |
| **QR 알고리즘** | $A = QR$ 반복 | $O(N^3)$ 수렴 | 수치적 고유값 계산 | 반복 다듬기 |
| **거듭제곱법(Power Iteration)** | $v_{k+1} = Av_k / \|Av_k\|$ | $O(N^2)$/반복 | 최대 고유값·벡터 | 방향 수렴 |
| **고유 분해** | $A = P\Lambda P^{-1}$ | — | 행렬 거듭제곱, 행렬 함수 | DNA 분석 |
| **SVD** | $A = U\Sigma V^T$ | $O(\min(mN^2, m^2 N))$ | 추천, 압축, PCA | 만능 분해 |

### PCA에서의 고유값 활용

$$
C = \frac{1}{N-1} X^T X \quad \text{(공분산 행렬)}
$$

$C$의 고유값 $\lambda_1 \geq \lambda_2 \geq \ldots$가 각 주성분이 설명하는 분산이고, 대응하는 고유벡터가 주성분 방향이다. 상위 $k$개 고유벡터로 투영하면 $d$차원 → $k$차원 축소가 된다.

- **📢 섹션 요약 비유**: PCA는 "데이터를 가장 잘 펼쳐 보이는 각도(고유벡터)를 찾아 사진 찍기"입니다. 고유값이 큰 방향이 "가장 많은 정보가 보이는 각도"입니다.

## Ⅲ. 비교 및 연결

### 비교 1: 고유 분해 vs SVD

| 비교 항목 | 고유 분해 | SVD |
|:---|:---|:---|
| **적용 범위** | 정사각 행렬만 | 모든 행렬 ($m \times n$) |
| **분해 형태** | $A = P\Lambda P^{-1}$ | $A = U\Sigma V^T$ |
| **대각 원소** | 고유값 (음수·복소수 가능) | 특이값 (항상 $\geq 0$) |
| **직교성** | $P$가 직교일 보장 없음 | $U, V$ 항상 직교 |
| **대표 응용** | 마르코프 체인, 안정성 | PCA, 추천, 이미지 압축 |

### 과목 융합 관점
- **Google PageRank**: 웹 페이지 전이 행렬 $M$의 최대 고유값($\lambda = 1$)에 대응하는 고유벡터가 페이지 순위 벡터이다. 거듭제곱법으로 계산한다.
- **제어공학**: 상태 공간 모델 $\dot{x} = Ax$에서 $A$의 고유값의 실수부가 모두 음수이면 시스템이 안정적이다.
- **양자역학**: 관측 가능량은 에르미트 행렬(고유값이 실수)이며, 측정값은 고유값, 측정 후 상태는 고유벡터이다.

- **📢 섹션 요약 비유**: 고유값은 "행렬의 DNA"입니다. PageRank, PCA, 안정성 — 모두 행렬의 DNA(고유값)를 읽어서 판단합니다.

## Ⅳ. 실무 적용 및 기술사 판단

### 실무 시나리오

1. **시나리오 — 추천 시스템의 SVD**: Netflix는 사용자×영화 평점 행렬을 SVD로 분해하여 상위 $k$개 특이값·벡터만 사용한다. 100만×10만 행렬을 $k=100$ 잠재 요인으로 축소하면 저장 공간 1,000배 절감 + 미평가 영화 점수 예측이 가능하다.

2. **시나리오 — 이미지 압축**: 이미지를 행렬로 보고 SVD 적용 후 상위 $k$개 특이값만 유지하면, 원본의 90% 이상 정보를 10%의 데이터로 표현할 수 있다.

### 안티패턴
- **특성 방정식 직접 풀기**: $N > 4$이면 $N$차 다항식의 근을 해석적으로 구할 수 없다(Abel-Ruffini 정리). 실무에서는 QR 알고리즘 같은 수치적 방법을 사용한다.

- **📢 섹션 요약 비유**: 특성 방정식 직접 풀기는 "방정식을 손으로 풀기"입니다. 3차까지는 되지만, 5차부터는 공식이 존재하지 않으므로 컴퓨터(수치 해법)가 필요합니다.

## Ⅴ. 기대효과 및 결론

### 정량/정성 기대효과

| 구분 | 고유값 미활용 | 고유값 활용 | 개선 효과 |
|:---|:---|:---|:---|
| **정량** | 100차원 데이터 직접 처리 | PCA로 10차원 축소 | 계산량 **100배↓** |
| **정량** | 행렬 $A^{100}$ 직접 계산 | $P\Lambda^{100}P^{-1}$ | $O(N^3 \cdot 100)$ → $O(N^3)$ |
| **정성** | 시스템 안정성 직관에 의존 | 고유값 실수부 < 0 확인 | **수학적 안정성 보장** |

### 참고 표준
- **LAPACK**: 고유값 계산 표준 라이브러리 (QR 알고리즘 구현)
- **NumPy/SciPy**: `np.linalg.eig()`, `np.linalg.svd()`

고유값과 고유벡터는 행렬의 "본질적 성질"을 드러내는 도구이다. 방향이 변하지 않는 벡터(고유벡터)와 그 배율(고유값)을 알면, 행렬의 거듭제곱, 차원 축소, 안정성 판단, 데이터 압축 등 다양한 문제를 우아하게 풀 수 있다.
