## 미리 알고가기

- 정방행렬: 행과 열의 수가 같은 행렬이며 고유값 문제의 기본 대상임
- 고유값: 변환 후 고유벡터가 몇 배로 늘거나 줄었는지 나타내는 스칼라임
- 고유벡터: 행렬 변환 후에도 방향이 변하지 않는 0이 아닌 벡터임
- 특성 방정식: `det(A - lambda I) = 0`으로 고유값을 구하는 방정식임
- 대각화: 고유벡터 기저에서 행렬을 대각 행렬로 단순화하는 분해임

## Ⅰ. 개요

- **정의**: 고유값과 고유벡터는 정방행렬 `A`가 벡터 `x`의 방향을 유지한 채 크기만 `lambda`배로 바꾸는지 `A x = lambda x` 기준으로 찾는 값과 벡터이며, 행렬 변환의 핵심 축과 스케일을 해석하기 위해 사용함.
- **배경/필요성**: PCA, PageRank, 진동 해석, 안정성 판별은 복잡한 행렬 변환을 지배하는 방향과 크기를 찾아야 하므로 고유값 분해가 기본 분석 도구가 됨.
- **비유**: 지도 전체를 잡아당겨도 방향은 그대로이고 길이만 달라지는 특별한 축을 찾는 과정과 같음.

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 고유값·고유벡터 정의 설명 | `A x = lambda x`, 특성 방정식 | 고유벡터를 0벡터로 허용 |
| 응용 의미 이해 | 대각화, PCA, 안정성, PageRank | 선형 변환과의 관계 누락 |

> 요약: 고유값·고유벡터는 행렬 변환에서 방향이 보존되는 축과 그 축의 스케일 변화를 나타내는 핵심 성질임.

## Ⅱ. 특징/비교

| 판단 기준 | 고유값 분해 | 특잇값 분해 |
|:---|:---|:---|
| 대상 행렬 | 주로 정방행렬을 대상으로 함 | 정방·비정방 행렬 모두 가능함 |
| 핵심 의미 | 방향이 유지되는 벡터와 스케일을 찾음 | 직교 축에서 늘어나는 정도를 찾음 |
| 분해 조건 | 고유벡터가 충분해야 대각화 가능함 | 모든 행렬에 대해 안정적으로 존재함 |
| 선택 기준 | 동역학, 안정성, PCA의 공분산 행렬 해석에 적합함 | 차원 축소, 저랭크 근사, 수치 안정성이 중요할 때 적합함 |

- **정의 기준**: 고유벡터는 크기보다 방향이 중요하므로 상수배는 같은 고유 방향으로 봄.
- **해석 기준**: 고유값의 크기와 부호 또는 복소 성분은 성장, 감쇠, 진동, 안정성을 설명함.
- **계산 기준**: 큰 행렬에서는 특성 다항식 직접 풀이보다 QR, Lanczos 같은 반복법을 사용함.

> 요약: 고유값 분해는 행렬 변환의 불변 방향 해석에 강하지만, 조건이 나쁘거나 비정방 행렬이면 SVD 같은 대안이 필요함.

## Ⅲ. 구성요소

```text
+------------+      +------------+      +------------+
| Matrix A   | ---> | Character  | ---> | Eigen      |
| Square     |      | Equation   |      | Values     |
+------------+      +------------+      +------------+
       |                   |                   |
       v                   v                   v
+------------+      +------------+      +------------+
| Eigen      |      | Diagonal   |      | Application|
| Vectors    |      | Form       |      | Metric     |
+------------+      +------------+      +------------+
```

| 구성요소 | 설명 | 비유 |
|:---|:---|:---|
| 정방행렬 A | 분석할 선형 변환이며 입력과 출력 차원이 같아야 함 | 변환 장치 |
| 고유값 lambda | 고유 방향에서 크기가 얼마나 변하는지 나타내는 스케일 값임 | 배율 눈금 |
| 고유벡터 x | 변환 후에도 방향이 유지되는 0이 아닌 벡터임 | 변하지 않는 방향축 |
| 특성 방정식 | `det(A - lambda I)=0`으로 고유값 후보를 찾는 식임 | 축 찾는 조건식 |
| 대각화 | 고유벡터를 기저로 행렬을 대각 형태로 바꾸어 계산을 단순화함 | 좌표축 재정렬 |

> 요약: 고유값 문제는 정방행렬에서 특성 방정식으로 스케일을 찾고, 각 스케일에 대응하는 불변 방향을 구해 변환을 단순화하는 구조임.

## Ⅳ. 절차

```text
+------------+      +------------+      +------------+      +------------+
| Build      | ---> | Solve      | ---> | Find       | ---> | Diagonal   |
| det(A-lI)  |      | lambda     |      | Vectors    |      | or Analyze |
+------------+      +------------+      +------------+      +------------+
```

1. **특성 방정식 수립**: `det(A - lambda I)=0`을 구성해 고유값 후보를 찾을 조건을 만듦.
2. **고유값 계산**: 방정식의 근을 구하거나 QR, Lanczos 등 수치 알고리즘으로 고유값을 산출함.
3. **고유벡터 계산**: 각 고유값에 대해 `(A - lambda I)x = 0`의 영공간을 구함.
4. **해석·분해**: 고유벡터가 충분하면 대각화하고, 고유값 크기와 방향으로 시스템 성질을 해석함.

> 요약: 고유값 분석은 특성 방정식, 고유값 계산, 고유벡터 산출, 대각화 또는 응용 해석 순서로 진행됨.

## Ⅴ. 문제점

- **P1 대각화 불가**: 고유값은 있어도 독립 고유벡터가 부족하면 행렬을 대각화할 수 없음.
- **P2 수치 불안정**: 특성 다항식을 직접 풀거나 조건수가 나쁜 행렬을 다루면 부동소수점 오차가 크게 증폭됨.
- **P3 복소 고유값 해석**: 실수 행렬도 복소 고유값을 가질 수 있어 회전·진동 성분 해석이 필요함.

> 요약: 고유값 분석은 대각화 조건, 수치 안정성, 복소수 해석을 관리하지 않으면 결과를 잘못 적용할 수 있음.

## Ⅵ. 개선방안

- **P1 대응**: Schur 분해, Jordan 정규형, SVD를 사용해 대각화 불가 행렬도 분석 가능하게 함. (확인: 독립 고유벡터 수)
- **P2 대응**: 특성 다항식 직접 풀이를 피하고 QR/Lanczos/Arnoldi 반복법과 스케일링을 적용함. (확인: residual norm)
- **P3 대응**: 복소 고유값을 크기와 위상으로 해석하고 실수 Schur 블록으로 표현함. (확인: 안정성 판정 기준)

> 요약: 고유값 문제는 안정적인 수치 분해와 대안 분해법을 사용해 대각화 실패와 오차 증폭을 완화해야 함.

## Ⅶ. 전망

- **향후 발전 방향**: 그래프 분석, 추천, 제어 시스템, PCA, 양자 계산에서 고유값 기반 해석은 계속 핵심 연산으로 쓰일 전망임.
- **기술사적 판단**: 전체 행렬을 모두 보지 않고 지배 고유값과 고유벡터만으로 시스템의 주요 동작을 파악할 수 있는지가 선택 기준임.
- **기술사 제언**: 답안에서는 `A x = lambda x` 정의, 특성 방정식, 대각화 가능 조건과 SVD 대안을 함께 정리해야 함.

답안 정리:
- **핵심 키워드**: 정방행렬, 고유값, 고유벡터, 특성 방정식, 대각화임.
- **연계 키워드**: 선형 변환, 행렬 분해, PCA, PageRank로 연결함.
- **검증 관점**: `A x`와 `lambda x`의 잔차가 충분히 작은지 확인함.
