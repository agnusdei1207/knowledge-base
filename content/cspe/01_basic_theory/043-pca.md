## Ⅰ. 개요
- **정의**: 고차원의 데이터를 정보 손실을 최소화하면서 저차원으로 축소하는 선형 변환 기법임.
- **배경/필요성**: 차원의 저주 문제를 해결하고, 데이터 시각화 및 모델 학습 속도 향상을 위해 필요함.
- **출제 의도**: 공분산 행렬, 고유벡터와 고윳값의 의미를 이해하고 차원 축소의 원리를 아는지 평가함.

## Ⅱ. 구성요소
```text
+------------------+       +------------------+       +------------------+
| High-Dim Data    | ----> | PCA Transform    | ----> | Low-Dim Data     |
| (N Features)     |       | (Eigenvectors)   |       | (K Components)   |
+------------------+       +------------------+       +------------------+
```
| 구성요소 | 설명 | 비유 |
|---|---|---|
| 원본 데이터 | 차원 축소의 대상이 되는 다변량 데이터 | 그림자 없는 입체물 |
| 공분산 행렬 | 변수 간의 분산 및 상관관계를 나타내는 행렬 | 방향 지시도 |
| 주성분 (PC) | 분산을 최대로 보존하는 새로운 직교 기저 | 그림자가 비치는 캔버스 |

> 요약: 공분산 행렬의 고유벡터(주성분)를 찾아 고차원 데이터를 저차원 공간에 투영함.

## Ⅲ. 절차
```text
+-------------+   +-------------+   +-------------+   +-------------+
| 1. 데이터   |-->| 2. 공분산   |-->| 3. 고윳값/  |-->| 4. 데이터   |
|    정규화   |   |    계산     |   |    벡터추출 |   |    투영     |
+-------------+   +-------------+   +-------------+   +-------------+
```
1. **데이터 정규화**: 스케일 차이에 의한 왜곡을 막기 위해 평균 0, 분산 1로 표준화함.
2. **공분산 계산**: 정규화된 변수들 간의 상호 상관관계를 나타내는 공분산 행렬을 생성함.
3. **고윳값/벡터추출**: 행렬을 분해하여 고윳값이 큰 순서대로 주성분(고유벡터)을 선정함.
4. **데이터 투영**: 선택된 K개의 주성분 축에 원본 데이터를 투영하여 차원을 축소함.

> 요약: 정규화 후 공분산 행렬의 고윳값이 큰 주성분을 찾아 원본 데이터를 새로운 공간에 투영함.

## Ⅳ. 문제점
- **선형성 한계**: PCA는 선형 변환이므로 비선형 구조를 가진 데이터 군집은 분리하기 어려움.
- **해석력 저하**: 추출된 주성분은 기존 변수들의 선형 결합이므로 직관적인 물리적 의미 해석이 힘듦.

## Ⅴ. 개선방안
- **선형성 한계**: (단기) Kernel PCA 등 비선형 투영 기법 활용 / (장기) t-SNE, UMAP 등 매니폴드 학습 도입 필요.
- **해석력 저하**: (단기) 로딩 매트릭스로 기여도 확인 / (장기) 희소 PCA(Sparse PCA) 적용으로 변수 선택 효과 확보 필요.

## Ⅵ. 전망
- 빅데이터 전처리 및 시각화의 필수 도구로 쓰이며, 오토인코더와 같은 딥러닝 기반 차원 축소와 보완적으로 활용됨.
