## 미리 알고가기

- 난수: 확률 분포에 따라 생성한 무작위 입력값임
- 표본: 난수 실험에서 얻은 개별 관측값임
- 대수의 법칙: 표본 수가 늘수록 표본 평균이 기대값에 가까워지는 성질임
- 분산: 표본 결과가 평균 주변에 퍼진 정도임
- 신뢰구간: 반복 표본에서 정한 신뢰수준의 비율로 모수를 포함하도록 구성한 추정 범위임
- 수치 근사: 정확한 해 대신 계산 가능한 근삿값을 구하는 방식임

## 작성 근거(검토용)

- **개요 구성**: 기출 키워드이므로 난수 반복, 통계량, 근사라는 정의 요소를 짧게 고정함
- **Ⅱ. 특징 선정**: 적용성, 병렬성, 오차-계산량 관계, 신뢰구간은 몬테카를로의 장단점을 직접 설명함
- **Ⅲ 비교축 선정**: 결정론적 격자법과 차원 증가·확률 오차·대표 적용 사례를 비교해야 선택 기준이 드러남
- **Ⅳ 구조 선정**: 확률 모델, 난수 생성기, 시뮬레이션, 집계기, 수렴 기준이 실험 재현성의 최소 구성임
- 난수 품질과 $1/\sqrt{N}$ 오차 감소는 계산 자원 산정의 판단 기준임

## Ⅰ. 개요

- **정의/개념**: 몬테카를로 방법은 난수 표본을 반복 생성하고 결과 통계량으로 해를 근사하는 수치 계산 기법임
- **배경/필요성**: 계산 비용이 크거나 정확해를 구하기 어려운 문제를 풀기 위해 표본 기반 근사가 필요함

## Ⅱ. 특징

- 확률 모델로 표현되는 복잡한 문제도 표본 평균으로 근사함
- 각 표본 시행이 독립적이므로 여러 노드에서 동시에 실행한 뒤 통계량을 합산할 수 있음
- 오차는 표본 수 증가에 따라 줄지만 계산량은 함께 늘어남
- 추정 결과는 분산과 신뢰구간으로 함께 제시해야 함

## Ⅲ. 종류 및 비교

| 판단 기준 | 결정론적 수치 해석 (격자법) | 몬테카를로 방법 (통계법) |
|:---|:---|:---|
| 계산 방식 | 구간을 규칙적으로 나눠 합산 | 난수 표본을 뽑아 통계량 산출 |
| 차원 증가 | 격자 수가 급격히 증가 | 격자 폭증을 피함 |
| 결과 성격 | 같은 입력에서 같은 근사값 | 확률 오차가 있는 추정값 |
| 검증 기준 | 격자 간격·수렴 차이 | 분산·표준오차·신뢰구간 |
| 대표 적용 사례 | 저차원 수치 적분·격자 해석 | 금융 위험 분석·고차원 수치 적분 |

> 요약: 저차원 구간을 규칙적으로 분할하면 격자법을, 차원 증가로 격자 수가 급증하면 표본 추출 기반 몬테카를로 방법을 적용함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 확률 모델 | 원 문제를 표본 추출 가능한 분포와 변수로 바꿈 |
| 난수 생성기 | 설정한 분포에 맞는 표본 입력을 생성함 |
| 시뮬레이션 함수 | 표본을 입력받아 실험 결과값을 반환함 |
| 통계 집계기 | 평균·분산·표준오차·신뢰구간을 산출함 |
| 수렴 기준 | 목표 오차와 시행 횟수의 종료 조건을 정함 |

```text
[ 몬테카를로 구조 ]
원 문제 -> 확률 모델 -> 난수 표본 -> 반복 실험 -> 통계량 -> 추정값
```

> 요약: 확률 모델과 표본 집계 방식을 먼저 정해야 계산한 근삿값과 오차 범위를 함께 제시할 수 있음.

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 확률 모델링 | --> | 표본 생성   | --> | 반복 실험   | --> | 오차 평가   |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **확률 모델링**: 입력 분포와 결과 판정 기준을 정의함
2. **표본 생성**: 난수 생성기로 독립 표본을 반복 추출함
3. **반복 실험**: 각 표본을 시뮬레이션 함수에 넣고 결과를 저장함
4. **오차 평가**: 평균·분산·신뢰구간으로 목표 정밀도 도달 여부를 판단함

> 요약: 표본 생성과 오차 평가가 함께 있어야 근삿값의 신뢰 수준을 설명함.

## Ⅵ. 실무 사례

1. 금융 위험 시뮬레이션은 난수 품질이 낮으면 추정이 편향되므로 검증된 생성기를 쓰고 시드·표본 수·분포 적합성을 기록함
2. 확률적 성능 예측은 표본 수를 늘려도 표준오차가 $1/\sqrt{N}$에 비례해 줄어드므로 목표 오차·계산 시간을 정하고 수렴 곡선으로 확인함

## Ⅶ. 결론

- 몬테카를로 방법은 난수 표본으로 복잡한 문제를 근사하는 기법이므로 난수 품질과 시행 횟수를 통제하고 신뢰구간으로 정밀도를 검증해야 함
