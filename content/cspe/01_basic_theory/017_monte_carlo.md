## 미리 알고가기

- 확률 모델: 계산 문제를 확률 변수와 시행으로 바꾼 표현임
- 표본 수 $N$: 추정 정확도와 계산량을 함께 결정하는 반복 횟수임
- 분산 감소: 같은 표본 수로 더 안정적인 추정을 얻기 위한 기법임

## Ⅰ. 개요

- **정의/개념**: 몬테카를로 방법은 복잡한 문제를 확률적 실험으로 바꾸고, 난수 기반 반복 시행 결과의 평균이나 분포로 해를 추정하는 수치 계산 기법임
- **배경/필요성**: 고차원 적분, 불확실성 평가, 복잡 계통 시뮬레이션은 해석식이나 격자 계산이 어려우므로 표본 기반 근사 접근이 필요함

## Ⅱ. 특징

- 계산 대상이 복잡해도 샘플 생성과 집계만 가능하면 적용할 수 있어 범용성이 높음
- 차원이 늘어나도 표본 기반 구조는 유지되므로 고차원 문제에 강함
- 결과는 근사치이므로 정확도는 표본 수와 분산 제어 능력에 달려 있음
- 각 시행이 독립적이라 병렬 처리에 특히 유리함

## Ⅲ. 종류 및 비교

| 판단 기준 | 격자 기반 수치해석 | 몬테카를로 방법 |
|:---|:---|:---|
| 계산 방식 | 영역 분할 후 체계적 계산 | 무작위 샘플링 후 통계 추정 |
| 고차원 대응 | 급격히 불리함 | 상대적으로 유리함 |
| 결과 성격 | 결정론적 | 확률적 |
| 대표 강점 | 저차원 정밀 계산 | 복잡 구조와 불확실성 처리 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 확률 분포 | 입력 변수의 발생 규칙이며 실제 현상을 잘 반영해야 함 |
| 난수 생성기 | 표본을 만드는 엔진이며 품질이 낮으면 편향이 생김 |
| 시뮬레이션 모델 | 입력을 받아 결과를 계산하고 도메인 로직 정확성이 중요함 |
| 집계 통계량 | 평균, 분산, 신뢰구간 등을 산출하고 의사결정 근거가 됨 |

```text
+-----------+     +-----------+     +---------------+     +-----------+
| 확률 분포    | --> | 난수 생성기  | --> | 시뮬레이션 모델   | --> | 집계 통계량  |
+-----------+     +-----------+     +---------------+     +-----------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----------+
| 모델정의 | --> | 표본생성 | --> | 반복실행 | --> | 통계집계 |
+----------+     +----------+     +----------+     +----------+
```

1. **모델정의**: 문제를 확률 변수와 출력 함수로 표현함
2. **표본생성**: 분포에 맞는 난수를 생성함
3. **반복실행**: 각 표본에 대해 결과를 계산함
4. **통계집계**: 평균과 신뢰구간으로 추정치를 얻음

## Ⅵ. 문제점 및 해결 방안

1. 문제: 수렴이 느려 정밀도를 높이려면 많은 샘플이 필요해 계산량이 커짐
   - 해결방안: 중요도 샘플링 등 분산 감소 기법을 적용하고 분산, 신뢰구간 폭로 검증함
2. 문제: 난수 품질이 낮아 특정 패턴이 반복되면 추정 결과가 편향될 수 있음
   - 해결방안: 검증된 난수 생성기와 시드 관리 정책을 사용하고 난수 분포 테스트로 검증함
3. 문제: 모델 오류를 표본 수로 숨김 시행을 많이 해도 모델이 틀리면 결과는 틀림
   - 해결방안: 실측 데이터와 시뮬레이션 결과를 교차 검증하고 모델 오차율로 검증함

## Ⅶ. 적용 사례

- 금융 리스크 분석에서는 가격 경로를 반복 생성해 손실 분포를 추정함, 확인 지표는 $VaR$와 신뢰구간 안정성임
- 물리 시뮬레이션에서는 복잡한 입자 이동이나 충돌을 확률적으로 계산함, 확인 지표는 추정 오차와 실행시간임
- 게임 탐색 보조에서는 무작위 대국 결과를 통계화해 의사결정을 지원함, 확인 지표는 승률 추정 오차와 탐색 횟수임

## Ⅷ. 결론

몬테카를로 방법의 본질은 정답을 직접 계산하는 것이 아니라 불확실성을 통제 가능한 추정으로 바꾸는 데 있음.
