## 미리 알고가기

- 표본(Sample): 확률 분포로부터 추출된 개별적인 관측값 또는 실험 데이터임
- 대수의 법칙(Law of Large Numbers): 표본의 크기가 커질수록 표본 평균이 모평균에 가까워진다는 통계적 원리임
- 난수(Random Number): 특정한 규칙 없이 무작위로 생성된 수이며, 몬테카를로 실험의 기초 입력이 됨
- 수치적 근사: 해석적인 해(Exact Solution)를 구하기 어려운 문제에 대해 반복 실험을 통해 근삿값을 도출하는 방식임

## Ⅰ. 개요

- **정의/개념**: 몬테카를로 방법은 수학적 또는 물리적 문제의 해를 구하기 위해 확률적 난수를 이용한 반복 시행을 수행하고, 그 표본 결과들의 통계적 평균을 통해 근삿값을 추정하는 수치 계산 기법임
- **배경/필요성**: 변수가 많고 복잡한 고차원 적분, 금융 리스크 모델링, 불확실성이 큰 물리 현상 시뮬레이션 등은 정확한 수식으로 풀기 어렵거나 계산 비용이 극심하므로, 표본 추출을 통한 현실적인 해법이 필요함

## Ⅱ. 특징

- 문제의 수식적 난해함에 상관없이 확률 모델로 치환 가능하면 모든 영역에 적용할 수 있는 범용성을 가지며, 시행 횟수가 늘어날수록 추정의 정밀도가 높아짐
- 각 시행이 서로 독립적인 특성을 가지므로 분산 처리 및 멀티코어 컴퓨팅 환경에서 병렬화하기가 매우 쉬워, 하드웨어 확장을 통해 계산 속도를 극대화할 수 있음
- 결과값이 확률적 추정치이므로 반드시 분산($Variance$)과 신뢰구간($Confidence$ $Interval$)을 함께 분석하여 추정의 신뢰도를 객관적으로 평가해야 함

## Ⅲ. 종류 및 비교

| 판단 기준 | 결정론적 수치 해석 (격자법) | 몬테카를로 방법 (통계법) |
|:---|:---|:---|
| **계산 방식** | 구간을 일정하게 나누어 전수 합산 | 난수 기반 무작위 표본 추출 후 평균 |
| **차원의 저주** | 차원이 높을수록 격자 수가 기하급수 증가 | 차원 증가에 따른 영향이 상대적으로 적음 |
| **결과 성격** | 오차 범위가 고정된 확정적 결과 | 확률적 오차를 포함하는 추정 결과 |
| **적합 문제** | 변수가 적고 정밀함이 요구되는 계산 | 변수가 많고 비선형적인 고차원 시뮬레이션 |

> 요약: 저차원의 정밀 계산은 격자 기반 해석이 유리하며, 고차원의 복잡한 불확실성 문제는 몬테카를로 방법이 효율적임.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 확률 모델 | 원래의 수치적 문제를 난수 실험으로 수행 가능한 확률 변수와 분포로 치환한 모델임 |
| 난수 생성기 | 설정된 확률 분포(균등분포, 정규분포 등)에 따라 편향되지 않은 고품질 표본을 생성하는 엔진임 |
| 시뮬레이션 함수 | 각 표본을 입력받아 실험을 수행하고 그 결과값(성공/실패 또는 특정 수치)을 반환하는 로직임 |
| 통계 집계기 | 수만 번 이상의 실험 결과를 누적하여 평균, 표준편차, 오차 범위를 산출하는 집계 모듈임 |

```text
[ 몬테카를로 메커니즘 ]
Input -> [ Random Seed ] -> [ Model Logic ] -> [ Trial 1..N ] -> [ Aggregator ] -> Result
             (난수생성)          (실험수행)         (반복시행)        (통계분석)
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +--------------+     +-------------+     +-------------+
| 확률 모델링  | --> | 표본 생성/실험| --> | 결과 데이터 집계| --> | 오차 및 신뢰도|
+-------------+     +--------------+     +-------------+     +-------------+
```

1. **모델링** — 해결하고자 하는 문제를 확률 공간으로 옮기고, 입력 난수의 분포와 성공/실패 판정 기준을 정의함
2. **실험 수행** — 난수 생성기를 통해 대량의 표본을 추출하고, 각 표본에 대해 시뮬레이션 함수를 실행하여 결과값을 얻음
3. **데이터 집계** — 수집된 모든 실험 결과의 산술 평균을 계산하여 찾고자 하는 값의 추정치로 확정함
4. **신뢰도 분석** — 표본 수($N$)와 분산을 바탕으로 표준 오차를 계산하고, 목표하는 정밀도에 도달했는지 신뢰구간을 확인함

## Ⅵ. 실무 적용 및 유의점

1. 난수의 무작위성 품질($Randomness$)이 낮거나 편향된 시드($Seed$)를 사용하면 추정 결과에 심각한 왜곡이 발생하므로, 검증된 난수 생성 알고리즘을 사용하고 실험의 재현성을 보장하기 위해 시드 값을 기록·관리해야 함
2. 추정의 오차는 시행 횟수의 제곱근($\sqrt{N}$)에 반비례하여 감소하므로, 정밀도를 10배 높이기 위해 100배의 계산 시간이 소요되는 특성을 고려하여 목표 오차 범위와 가용 자원 사이의 적정선을 설계에 반영해야 함

## Ⅶ. 결론

- 몬테카를로 방법은 현대 과학과 금융, AI 분야에서 불확실성을 수치화하는 가장 강력한 기법이며, 설계자는 난수의 품질과 통계적 유의성을 철저히 통제하여 추정 결과의 신뢰도를 확보해야 함
