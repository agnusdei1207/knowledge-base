## 미리 알고가기

- 난수(Random Number): 정해진 확률분포를 따르되 다음 값을 미리 알 수 없는 수이며, 몬테카를로 표본 추출의 재료임
- 확률분포(Probability Distribution): 확률변수가 가질 값과 각 값의 발생 가능성을 정한 규칙이며, 난수 표본을 생성하는 기준임
- 독립 표본(Independent Sample): 확률분포에서 추출한 값인 표본들이 서로의 발생 확률에 영향을 주지 않는 것임
- 모집단·모수·통계량(Population, Parameter and Statistic): 모집단은 분석 대상 전체 집합이고, 모수는 모집단의 고정된 특성값이며, 통계량은 표본에서 계산해 모수를 추정하는 값임
- 표본평균(Sample Mean): 표본값의 합을 표본 수로 나눈 통계량이며, 몬테카를로 방법은 이를 이용해 기댓값을 근사함
- 표준편차(Standard Deviation): 개별 값이 평균 주변에 퍼진 정도를 나타내며, 원래 데이터의 변동성을 설명함
- 표집분포(Sampling Distribution): 모집단에서 같은 수의 표본을 여러 번 뽑고 매번 평균 같은 통계량을 계산해, 그 결과값들이 어떻게 퍼지는지를 나타냄
- 표준오차(Standard Error): 표집분포의 표준편차이며, 표본평균의 불확실성을 나타내고 표본 수의 제곱근에 반비례해 감소함
- 신뢰구간(Confidence Interval): 같은 추정 절차를 반복할 때 정한 신뢰수준의 비율로 모수를 포함하도록 계산한 구간임
- 분산·희귀사건(Variance and Rare Event): 분산은 결과값이 평균에서 퍼진 정도이고, 희귀사건은 발생확률이 매우 낮아 표본에 드물게 나타나는 사건으로, 둘 다 몬테카를로 추정 오차를 키움

## 작성 근거(검토용)

- **방향성**: 오차가 표본 수 제곱근에만 반비례해 완만히 줄어들므로, 적당히 정확한 근사는 싸게 얻지만 극도로 정밀한 값은 비용이 기하급수적으로 늘어나 표본 수와 계산 비용의 타협점을 먼저 정해야 함
- **개요 구성**: 기출 키워드이므로 난수 반복, 통계량, 근사라는 정의 요소를 짧게 고정함
- **Ⅱ. 특징 선정**: 표본평균 근사, 완만한 오차 감소, 병렬 집계, 분산·희귀사건·난수 편향은 몬테카를로의 동작과 적용 한계를 직접 설명함
- **Ⅲ. 비교축 선정**: 계산 방식, 적용 기준(차원), 주요 위험은 격자법과 몬테카를로 방법의 선택을 가름
- **Ⅳ. 구조 선정**: 확률 모델, 난수 생성기, 시뮬레이션 함수, 통계 집계기, 수렴 기준은 실험 재현에 필요한 구성임
- **전수 검수**: 제목부터 결론까지 용어·표·도식·요약을 대조하고 표준오차의 정의와 절 간 판단축을 일치시킴

## Ⅰ. 개요

- **정의/개념**: 몬테카를로 방법은 난수 표본을 반복 생성하고 통계 결과로 근삿값을 구하는 수치 계산 기법임
- **배경/필요성**: 계산 비용이 크거나 정확한 해를 구하기 어려운 문제를 풀기 위해 표본 기반 근사가 필요함

### 쉽게 이해하기 (학습용)
- 눈을 감고 과녁에 화살을 수백 번 쏜 뒤, 화살이 맞은 자리들의 평균 위치로 과녁 중심을 짐작하는 것과 같음

## Ⅱ. 특징

- 확률분포에서 독립 표본을 생성하고 평균으로 기댓값을 근사함
- 표준오차는 표본 수의 제곱근에 반비례하므로 오차를 절반으로 줄이려면 표본이 4배 필요함
- 표본별 계산이 독립적이므로 병렬 실행이 가능하며 추정값과 신뢰구간을 산출함
- 차원이 늘어도 오차 감소 법칙은 유지되나 분산·희귀사건·난수 편향이 오차를 키움

### 쉽게 이해하기 (학습용)
- 여러 사람이 같은 주사위를 나누어 던진 뒤 결과를 합쳐도 한 사람이 모두 던진 것처럼 평균과 오차를 계산할 수 있음
- 각자 던진 값의 오차가 무작위로 어긋나 여러 번 던지면 서로 부분적으로만 상쇄되므로, 평균의 오차는 던진 횟수에 반비례하지 않고 던진 횟수의 제곱근에만 반비례해 줄어듦
- 오차를 절반으로 줄이려면 주사위를 약 4배 더 던져야 하므로 정밀도와 계산량을 함께 정해야 함

## Ⅲ. 종류 및 비교

| 판단 기준 | 결정론적 수치 해석 (격자법) | 몬테카를로 방법 (통계법) |
|:---|:---|:---|
| 계산 방식 | 규칙 격자점의 결정론적 합산 | 난수 표본의 통계량 추정 |
| 적용 기준 | 저차원 구간에서 격자점 수가 감당 가능할 때 적합 | 고차원이거나 격자 분할이 비현실적일 때 적합 |
| 주요 위험 | 격자 이산화 오차 | 고분산·희귀사건의 표본 부족 |

> 요약: 저차원 구간을 규칙적으로 분할할 수 있으면 격자법, 차원 증가로 격자 수가 감당 불가능해지면 몬테카를로 방법을 적용함.

### 쉽게 이해하기 (학습용)
- 격자법은 과녁 전체를 촘촘한 그물로 나눠 일일이 계산해 변수(차원)가 늘면 그물코가 폭발적으로 늘어나지만, 몬테카를로는 무작위로 툭툭 쏘기만 하면 되니 차원이 늘어도 크게 느려지지 않음

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 확률 모델 | 원문제의 불확실성을 나타내는 확률변수와 표본의 확률분포 |
| 난수 생성기 | 확률 분포에 따른 표본 입력 생성 |
| 시뮬레이션 함수 | 표본을 결과값으로 변환하는 실행 모델 |
| 통계 집계기 | 근삿값과 오차 범위 산출 |
| 수렴 기준 | 목표 오차에 따른 반복 종료 조건 |

> 요약: 몬테카를로 방법은 확률 모델의 난수 표본을 반복 실행하고 통계량으로 근삿값과 오차 범위를 산출함.

### 쉽게 이해하기 (학습용)
- 주사위를 굴리는 규칙(확률 모델), 실제로 굴리는 도구(난수 생성기), 굴린 결과를 기록하는 장부(통계 집계기)가 각자 역할을 나눠 맡음

## Ⅴ. 원리 및 절차 흐름도

```text
확률 모델 정의 → 난수 표본 생성 → 시뮬레이션·통계 갱신
                                      ↓
                                목표 오차 판정
                         ├─ 미달 → 다음 표본 반복
                         └─ 충족 → 추정값·오차 범위 반환
```

1. **확률 모델링**: 확률변수의 분포와 결과 산출 기준을 정의함
2. **표본 생성**: 난수 생성기로 독립 표본을 반복 추출함
3. **반복 실험**: 각 표본의 함수값으로 합계·제곱합·표본 수를 갱신함
4. **오차 평가**: 표준오차와 신뢰구간으로 목표 정밀도 도달을 판정함

> 요약: 난수 표본의 통계량으로 근삿값을 구하고 표준오차와 신뢰구간으로 정밀도를 평가함.

### 쉽게 이해하기 (학습용)
- 규칙을 정하고, 주사위를 굴리고, 결과를 쌓아가다가, 오차가 충분히 작아지면 멈추는 반복 과정임

## Ⅵ. 실무 사례

1. 서버 용량 계획은 부하 분포를 반복 표본화하고 허용 용량 초과 확률로 증설 여부를 정함
2. 시스템 신뢰도 평가는 장애 시나리오를 반복 실행해 장애 확률과 신뢰구간을 구함

### 쉽게 이해하기 (학습용)
- 서버를 몇 대 준비할지 미리 알 수 없을 때, 여러 상황을 무작위로 수백 번 시뮬레이션해서 감당 못 할 확률을 미리 가늠하는 것과 같음

## Ⅶ. 결론

- 몬테카를로 방법은 오차가 표본 수의 제곱근에만 반비례해 완만히 줄어들므로, 적당히 정확한 근사는 싸게 얻지만 극도로 정밀한 값은 비용이 기하급수적으로 증가함
- 수식으로 직접 풀기 어렵고 입력 분포를 모델링할 수 있을 때 적용하며, 드문 장애는 발생 가능성이 높은 구간을 집중 추출해 가중치를 보정해야 함

### 쉽게 이해하기 (학습용)
- 정확히 계산하기 힘든 문제는 많이 시도해 평균을 내는 방식으로 근사치를 구하되, 시도 횟수와 계산 비용의 균형을 스스로 정해야 함
