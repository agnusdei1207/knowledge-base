## 미리 알고가기

- 확률 모델: 계산 문제를 확률 변수와 시행으로 바꾼 표현임
- 표본 수 $N$: 추정 정확도와 계산량을 함께 결정하는 반복 횟수임
- 분산 감소: 같은 표본 수로 더 안정적인 추정을 얻기 위한 기법임
- 신뢰구간: 반복 시행으로 얻은 추정값이 어느 범위에 있을지 나타내는 통계 구간임
- 격자 기반 수치해석: 계산 영역을 일정 간격의 격자로 나눈 뒤 각 구간을 체계적으로 합산해 값을 구하는 전통적 수치 계산 방식임

## Ⅰ. 개요

- **정의/개념**: 몬테카를로 방법은 카지노에서 룰렛을 여러 번 돌려 확률을 가늠하듯, 계산 대상을 확률 실험으로 바꾼 뒤 난수로 생성한 표본을 반복 평가하고 그 결과의 평균과 분포로 원하는 값을 추정하는 수치 계산 기법임
- **배경/필요성**: 고차원 적분, 불확실성 전파, 복잡한 물리 계통 해석처럼 해석식으로 풀기 어렵거나 경우의 수가 너무 큰 문제는 표본 기반 근사 계산이 더 현실적임

## Ⅱ. 특징

- 모델링 범위가 넓어, 해석식을 직접 세우기 어려운 문제라도 표본을 만들고 결과를 집계할 수만 있으면 적용할 수 있음
- 차원이 커져도 계산량 증가가 완만한데, 표본 생성과 평균 계산이라는 처리 절차 자체가 차원 수와 무관하게 유지되기 때문임
- 정확도는 표본 수와 분산 관리 수준으로 결정되는데, 결과 자체가 확정값이 아닌 추정값이기 때문임
- 병렬화가 쉬운데, 각 시행이 서로 독립인 경우가 많아 다중 코어나 분산 환경에서 동시에 처리할 수 있기 때문임

## Ⅲ. 종류 및 비교

| 판단 기준 | 격자 기반 수치해석 | 몬테카를로 방법 |
|:---|:---|:---|
| 계산하는 방식 | 계산 영역을 잘게 나눈 뒤 각 구간을 체계적으로 합산함 | 무작위 또는 의도적으로 뽑은 표본을 반복 평가해 통계적으로 추정함 |
| 차원이 늘어날 때 | 분할해야 할 격자 수가 급격히 늘어 계산량이 빠르게 커짐 | 표본 수를 더 늘려야 하지만 기본 절차는 유지되어 상대적으로 덜 불리함 |
| 결과를 해석하는 방식 | 같은 입력이면 같은 값을 내는 결정론적 계산에 가깝게 동작함 | 같은 입력이라도 난수 시드와 표본 수에 따라 추정 오차가 달라질 수 있음 |
| 주로 강한 상황 | 저차원에서 높은 정밀도가 필요한 계산에 적합함 | 고차원 구조나 불확실성이 큰 계통을 근사해야 할 때 적합함 |

> 요약: 격자 기반 수치해석은 저차원 고정밀 계산에 적합하고, 몬테카를로 방법은 고차원·고불확실성 문제의 근사 추정에 적합함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 확률 모델 | 계산 문제를 확률 변수와 이를 평가할 함수로 바꾸는 단계이며, 이 변환이 원래 문제를 얼마나 정확히 대표하는지가 이후 모든 표본 평가의 전제가 됨 |
| 난수 생성기 | 확률 모델이 따르는 분포에서 표본을 뽑아내는 원천이며, 생성된 난수가 특정 구간에 치우치면 표본 자체가 왜곡되어 뒤 단계의 통계량을 신뢰할 수 없게 됨 |
| 표본 추출·평가 | 확률 모델에서 표본 수 $N$개를 뽑아 각각 함수값을 계산하는 단계이며, $N$을 늘릴수록 추정 오차는 줄어들지만 계산량도 함께 늘어남 |
| 집계 및 신뢰구간 | 개별 표본의 함수값을 평균·분산으로 합산해 최종 추정값과 신뢰구간을 산출하는 단계이며, 분산이 클수록 같은 $N$에서도 신뢰구간이 넓게 나옴 |

```text
+------------+     +------------+     +------------+     +------------+
| 확률 모델  | --> | 난수 생성  | --> | 표본 추출· | --> | 집계 및    |
|            |     |            |     | 평가       |     | 신뢰구간   |
+------------+     +------------+     +------------+     +------------+
```

> 요약: 확률 모델이 표본 생성과 평가를 거쳐 집계·신뢰구간으로 이어지는 구조이며, 표본 수 $N$과 분산이 이 구조 전체의 정확도를 결정함.

## Ⅴ. 원리 및 절차 흐름도

```text
+----------+     +----------+     +----------+     +----+-----+
| 확률모델 | --> | 표본생성 | --> | 함수평가 | --> | 신뢰구간 |
| 정의     |     |          |     | 및 누적  |     | 판정     |
+----------+     +----------+     +----------+     +----+-----+
                                                          |
                              +---------------------------+---------------------------+
                              | 정밀도 미달                                            | 정밀도 달성
                              v                                                        v
                        +-----------+                                          +-----------+
                        | 표본 추가/ |                                          | 추정값    |
                        | 분산 감소  |                                          | 확정      |
                        +-----------+                                          +-----------+
```

1. **확률모델 정의**: 계산 대상을 확률 변수 $X$와 이를 평가할 함수로 정함
2. **표본생성**: 난수 생성기로 확률 모델을 따르는 표본을 뽑음
3. **함수평가 및 누적**: 각 표본에 함수를 적용해 값을 얻고 합계와 제곱합을 누적함
4. **신뢰구간 판정**: 누적값으로 평균·분산을 계산해 신뢰구간 폭이 목표 정밀도를 만족하는지 확인함
5. **분기 처리**: 정밀도가 미달이면 표본 수를 늘리거나 분산 감소 기법을 적용해 2단계로 돌아가고, 정밀도가 달성되면 추정값을 확정함

## Ⅵ. 실무 적용 및 유의점

1. 금융 파생상품 가격 산정이나 리스크 측정처럼 고차원 적분이 필요한 환경에서는 몬테카를로 방법을 쓰지만, 표본 수 $N$이 적으면 분산이 커져 신뢰구간이 넓어지므로 분산 감소 기법을 적용해 표본 배치를 조정하고 신뢰구간 폭과 표준오차로 정밀도를 확인함
2. 물리 계통 시뮬레이션처럼 표본 시행을 다중 코어나 분산 환경에서 병렬화하는 경우, 각 코어가 같은 난수 시드나 상관된 난수 스트림을 쓰면 표본 간 독립성이 깨져 추정값이 편향되므로 코어마다 독립된 난수 스트림을 배정하고 코어 간 추정값 편차와 신뢰구간 수렴 속도로 독립성을 확인함

## Ⅶ. 결론

몬테카를로 방법의 판단 기준은 표본 수 $N$과 분산 감소 기법으로 신뢰구간을 얼마나 좁히느냐에 있으며, 고차원·고불확실성 문제에서는 격자 기반 수치해석보다 이 표본 기반 추정이 더 현실적인 선택임.
