## 미리 알고가기

- 난수: 확률 분포에 따라 생성한 무작위 입력값임
- 표본: 난수 실험에서 얻은 개별 관측값임
- 분산: 표본 결과가 평균 주변에 퍼진 정도임
- 표준오차: 표본 통계량의 표본 간 변동 정도이며 독립 표본 수 $N$에 대해 $1/\sqrt{N}$ 비율로 감소함
- 신뢰구간: 같은 절차로 구간을 반복 추정할 때 정한 비율만큼 모수를 포함하도록 구성한 구간임
- 수치 근사: 정확한 해 대신 계산 가능한 근삿값을 구하는 방식임
- 격자법: 정의역을 규칙적인 격자점으로 나누어 값을 합산하는 결정론적 수치 해석법임

## 작성 근거(검토용)

- **개요 구성**: 기출 키워드이므로 난수 반복, 통계량, 근사라는 정의 요소를 짧게 고정함
- **Ⅱ. 특징 선정**: 적용성, 병렬성, 오차-계산량 관계, 신뢰구간은 몬테카를로의 장단점을 직접 설명함
- **Ⅲ. 비교축 선정**: 계산 방식, 차원 증가 영향, 주요 위험은 격자법과 몬테카를로 방법의 선택을 가름
- **Ⅳ. 구조 선정**: 확률 모델, 난수 생성기, 시뮬레이션 함수, 통계 집계기, 수렴 기준은 실험 재현에 필요한 구성임
- 난수 품질과 $1/\sqrt{N}$ 오차 감소는 계산 자원 산정의 판단 기준임

## Ⅰ. 개요

- **정의/개념**: 몬테카를로 방법은 난수 표본을 반복 생성하고 결과 통계량으로 해를 근사하는 수치 계산 기법임
- **배경/필요성**: 계산 비용이 크거나 정확한 해를 구하기 어려운 문제를 풀기 위해 표본 기반 근사가 필요함

## Ⅱ. 특징

- 확률 모델로 표현한 문제의 해를 표본 평균·빈도 등의 통계량으로 근사함
- 각 표본 시행이 독립적이므로 여러 노드에서 병렬 실행한 뒤 통계량을 합산할 수 있음
- 표준오차는 표본 수의 제곱근에 반비례해 감소하지만 계산량은 표본 수에 비례해 증가함
- 추정 결과는 표준오차와 신뢰구간으로 함께 제시해야 함

## Ⅲ. 종류 및 비교

| 판단 기준 | 결정론적 수치 해석 (격자법) | 몬테카를로 방법 (통계법) |
|:---|:---|:---|
| 계산 방식 | 규칙 격자점의 결정론적 합산 | 난수 표본의 통계량 추정 |
| 차원 증가 영향 | 격자점 수가 지수적으로 증가 | $1/\sqrt{N}$의 표준오차 감소율 유지 |
| 주요 위험 | 격자 이산화 오차 | 난수 생성 편향 |

> 요약: 저차원 구간을 규칙적으로 분할하면 격자법, 차원 증가로 격자 수가 급증하면 몬테카를로 방법을 적용함.

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 확률 모델 | 원문제의 불확실성을 나타내는 확률변수와 표본의 확률분포 |
| 난수 생성기 | 확률 분포에 따른 표본 입력 생성 |
| 시뮬레이션 함수 | 표본을 결과값으로 변환하는 실행 모델 |
| 통계 집계기 | 근삿값과 오차 범위 산출 |
| 수렴 기준 | 목표 오차에 따른 반복 종료 조건 |

```text
[ 몬테카를로 구조 ]
원문제 -> 확률 모델 -> 난수 표본 -> 반복 실험 -> 통계량 -> 추정값
```

> 요약: 몬테카를로 방법은 확률 모델의 난수 표본을 반복 실행하고 통계량으로 근삿값과 오차 범위를 산출함.

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 확률 모델링 | --> | 표본 생성   | --> | 반복 실험   | --> | 오차 평가   |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **확률 모델링**: 확률변수의 분포와 결과 산출 기준을 정의함
2. **표본 생성**: 난수 생성기로 독립 표본을 반복 추출함
3. **반복 실험**: 각 표본을 시뮬레이션 함수에 넣고 결과를 저장함
4. **오차 평가**: 표준오차와 신뢰구간으로 목표 정밀도 도달 여부를 판단함

> 요약: 난수 표본의 통계량으로 해를 근사하고 표준오차와 신뢰구간으로 정밀도를 평가함.

## Ⅵ. 실무 사례

1. 서버 용량 계획은 부하 분포를 표본화하고 허용 용량 초과 확률과 신뢰구간 폭을 확인함
2. 시스템 신뢰도 평가는 장애 시나리오를 반복 실행하고 장애 확률의 표준오차와 계산 시간을 확인함

## Ⅶ. 결론

- 몬테카를로 방법은 난수 표본으로 복잡한 문제를 근사하는 기법이므로 난수 품질과 시행 횟수를 통제하고 신뢰구간으로 정밀도를 검증해야 함
