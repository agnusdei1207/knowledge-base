## 미리 알고가기

- 난수: 확률 분포에 따라 생성한 무작위 입력값임
- 표본: 난수 실험에서 얻은 개별 관측값임
- 대수의 법칙: 표본 수가 늘수록 표본 평균이 기대값에 가까워지는 성질임
- 분산: 표본 결과가 평균 주변에 퍼진 정도임
- 신뢰구간: 추정값이 포함될 가능성이 높은 값의 범위임
- 수치 근사: 정확한 해 대신 계산 가능한 근삿값을 구하는 방식임

## Ⅰ. 개요

- **정의/개념**: 몬테카를로 방법은 난수 표본을 반복 생성하고 결과의 통계량으로 해를 근사하는 수치 계산 기법임
- **배경/필요성**: 고차원 적분·금융 리스크·복잡 시뮬레이션은 정확 해가 어렵거나 비싸므로 표본 기반 근사가 필요함

## Ⅱ. 특징

- 확률 모델로 표현되는 복잡한 문제도 표본 평균으로 근사함
- 시행 간 의존성이 작아 병렬 실행과 분산 집계가 쉬움
- 오차는 표본 수 증가에 따라 줄지만 계산량은 함께 늘어남
- 추정 결과는 분산과 신뢰구간으로 함께 제시해야 함

## Ⅲ. 종류 및 비교

| 판단 기준 | 결정론적 수치 해석 (격자법) | 몬테카를로 방법 (통계법) |
|:---|:---|:---|
| 계산 방식 | 구간을 규칙적으로 나눠 합산 | 난수 표본을 뽑아 통계량 산출 |
| 차원 증가 | 격자 수가 급격히 증가 | 차원 영향이 상대적으로 작음 |
| 결과 성격 | 확정적 근사값 | 확률 오차가 있는 추정값 |
| 검증 기준 | 격자 간격, 수렴 차이 | 분산, 표준오차, 신뢰구간 |
| 적합 문제 | 저차원 정밀 계산 | 고차원 불확실성 계산 |

> 요약: 저차원의 정밀 계산은 격자 기반 해석이 유리하며, 고차원 불확실성 문제는 표본 추출 기반 근사가 적합함.

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 확률 모델 | 원 문제를 표본 추출 가능한 분포와 변수로 바꿈 |
| 난수 생성기 | 설정한 분포에 맞는 표본 입력을 생성함 |
| 시뮬레이션 함수 | 표본을 입력받아 실험 결과값을 반환함 |
| 통계 집계기 | 평균, 분산, 표준오차, 신뢰구간을 산출함 |
| 수렴 기준 | 목표 오차와 시행 횟수의 종료 조건을 정함 |

```text
[ 몬테카를로 구조 ]
Problem -> Probability Model -> Random Samples -> Trials -> Statistics -> Estimate
```

> 요약: 확률 모델과 표본 집계가 맞아야 근삿값과 오차 범위를 함께 제시함.

## Ⅴ. 원리 및 절차 흐름도

```text
+-------------+     +-------------+     +-------------+     +-------------+
| 확률 모델링 | --> | 표본 생성   | --> | 반복 실험   | --> | 오차 평가   |
+-------------+     +-------------+     +-------------+     +-------------+
```

1. **확률 모델링**: 입력 분포와 결과 판정 기준을 정의함
2. **표본 생성**: 난수 생성기로 독립 표본을 반복 추출함
3. **반복 실험**: 각 표본을 시뮬레이션 함수에 넣고 결과를 저장함
4. **오차 평가**: 평균, 분산, 신뢰구간으로 목표 정밀도 도달 여부를 판단함

> 요약: 표본 생성과 오차 평가가 함께 있어야 근삿값의 신뢰 수준을 설명함.

## Ⅵ. 실무 적용 및 유의점

1. 난수 품질이 낮으면 추정이 편향되므로 검증된 생성기를 쓰고 시드, 표본 수, 분포 적합성을 기록함
2. 표준오차는 대체로 $1/\sqrt{N}$에 비례해 줄어드므로 목표 오차와 계산 시간을 함께 정하고 수렴 곡선으로 확인함

## Ⅶ. 결론

- 몬테카를로 방법은 난수 표본으로 복잡한 문제를 근사하는 기법이므로 난수 품질, 시행 횟수, 신뢰구간을 함께 통제해야 함

## 작성 근거(검토용)

- **개요 구성**: 기출 키워드이므로 난수 반복, 통계량, 근사라는 정의 요소를 짧게 고정함
- **Ⅱ. 특징 선정**: 적용성, 병렬성, 오차-계산량 관계, 신뢰구간은 몬테카를로의 장단점을 직접 설명함
- **Ⅲ 비교축 선정**: 결정론적 격자법과 비교해야 차원 증가와 확률 오차의 의미가 드러남
- **Ⅳ 구조 선정**: 확률 모델, 난수 생성기, 시뮬레이션, 집계기, 수렴 기준이 실험 재현성의 최소 구성임
- **Ⅵ 적용 선정**: 난수 품질과 $1/\sqrt{N}$ 오차 감소는 실무 계산 자원 산정의 핵심 기준임
