# 몬테카를로 방법 (Monte Carlo Method)

## 1. 개요

- **정의/개념**: 몬테카를로 방법은 난수 표본을 반복 생성하고 그 결과를 통계적으로 집계해 정확 계산이 어려운 값을 확률적으로 추정하는 방법이다.
- **배경/필요성**: 고차원 적분, 복잡계 시뮬레이션, 불확실성 분석처럼 결정론적 정확 계산 비용이 큰 문제에서 근사와 오차 통제가 필요하다.

## 2. 특징 및 비교

| 구분 | 결정론적 계산 | 몬테카를로 방법 |
|---|---|---|
| 계산 방식 | 규칙 기반 정확 계산 | 무작위 표본 기반 추정 |
| 결과 | 동일 입력이면 동일 결과 | 난수 시드와 표본에 따라 변동 |
| 강점 | 정확성 | 고차원·복잡 문제 근사 |
| 약점 | 상태 공간이 크면 비용 폭증 | 표본 분산, 재현성 관리 필요 |
| 품질 기준 | 수학적 정확성 | 신뢰구간, 표준오차 |

몬테카를로 방법은 표본 수가 늘수록 추정 오차가 감소하지만, 오차 감소 속도는 일반적으로 느리다.

몬테카를로 판단은 표본 수, 분산, 신뢰구간, 난수 품질, 재현성, 병렬 실행 가능성을 핵심 차원으로 본다.

이 기준은 난수 표본이 문제 분포를 대표하고, 추정량의 오차를 해석할 수 있을 때만 신뢰도를 갖는다.

## 3. 구성요소/구조

| 구성요소 | 설명 | 핵심 포인트 |
|---|---|---|
| 난수 생성기 | 표본을 생성하는 기반 | 품질과 재현성 |
| 표본 분포 | 어떤 확률분포에서 뽑는지 결정 | 문제 반영 |
| 추정량 | 표본 결과를 평균·비율 등으로 집계 | 편향·분산 |
| 반복 횟수 | 표본 수 | 오차와 비용 |
| 신뢰도 평가 | 표준오차, 신뢰구간 | 결과 해석 |

```text
문제 모델링 -> 난수 표본 생성 -> 반복 실험 -> 통계량 집계 -> 오차 평가
```

따라서 몬테카를로의 문제점은 계산 절차보다 표본 품질, 분산, 재현성 관리가 부족할 때 발생한다.

## 4. 문제점 및 개선방안

1. **수렴 속도 한계**
   - 높은 정확도를 얻기 위해 매우 많은 표본이 필요할 수 있다.
   - **개선방안**: 중요도 샘플링, 층화 샘플링, 제어 변량, 준몬테카를로를 적용한다.

2. **표본 편향**
   - 표본 분포가 실제 문제를 반영하지 못하면 추정값이 치우친다.
   - **개선방안**: 입력 분포 검증, 민감도 분석, 난수 생성기 검정을 수행한다.

3. **재현성 부족**
   - 시드와 실행 조건을 기록하지 않으면 결과 검증이 어렵다.
   - **개선방안**: 난수 시드, 표본 수, 버전, 병렬 스트림 정책을 실험 로그로 남긴다.

## 5. 실무 적용 사례

| 적용 영역 | 적용 방식 | 확인 지표 |
|---|---|---|
| 금융 리스크 | 자산 가격 경로를 무작위 시뮬레이션해 VaR 추정 | 신뢰구간, 표준오차 |
| 시스템 신뢰성 | 장애 확률과 복구 시나리오를 반복 시뮬레이션 | 가용성, 실패 확률 |
| AI·그래픽스 | 샘플링 기반 렌더링과 확률적 추론 | 샘플 수, 품질·시간 |

## 6. 결론

몬테카를로 방법은 정확 계산이 어려운 문제를 확률적 근사로 해결하는 실용적 방법이다. 표본 품질, 분산 감소, 신뢰구간, 재현성, 병렬 실행 정책이 결과 신뢰도를 좌우한다.
