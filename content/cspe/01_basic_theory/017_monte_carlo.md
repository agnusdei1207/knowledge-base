## 미리 알고가기

```text
모집단(전체 대상) → 표본 추출(일부 관측) → 표본평균 계산 → 모집단 평균 추정
                                                       ↓
                                      표준오차로 추정값의 불확실성 평가
```

| 개념 | 의미 | 예시 |
|:---|:---|:---|
| 모집단 (Population) | 통계적 추론의 대상이 되는 모든 관측 단위의 집합 | 전국 성인 남성 전체 또는 확률분포에서 발생 가능한 모든 결과 |
| 표본 (Sample) | 모집단에서 실제로 뽑아 관측한 일부 데이터 | 조사에 참여한 성인 남성 1,000명 또는 난수 1,000개 |
| 평균 (Mean) | 데이터의 대표적인 중심값 | 표본 1,000명의 평균 키 |
| 표준편차 (SD) | 데이터가 평균 주변에 퍼진 정도 | 사람마다 키가 평균 키에서 벗어난 정도 |
| 오차 (Error) | 실제값과 추정값의 차이 | 실제 평균 키가 175cm이고 추정값이 174cm이면 오차는 1cm |
| 표준오차 (SE) | 표본을 다시 뽑을 때 평균 추정치가 흔들리는 정도 | 표본을 바꿔 조사할 때 표본평균이 달라지는 정도 |

즉, 표준편차는 데이터 자체의 산포이고 표준오차는 그 데이터를 이용해 계산한 평균의 불확실성임. 표본 수가 많아지면 데이터의 표준편차가 반드시 줄어드는 것은 아니지만, 평균의 표준오차는 줄어듦.

- 난수: 확률 분포에 따라 생성한 무작위 입력값임
- 표본: 난수 실험에서 얻은 개별 관측값임
- 분산: 표본 결과가 평균 주변에 퍼진 정도임
- 모수: 모집단의 평균·분산·확률 같은 고정된 특성값이며 표본 통계량으로 추정함
- 신뢰구간: 같은 절차로 구간을 반복 추정할 때 정한 비율만큼 모수를 포함하도록 구성한 구간임
- 중요도 표본추출: 드문 사건이 본 확률 분포에서 거의 0이라 직접 추출이 어려울 때, 해당 사건을 더 자주 발생시키는 보조 분포에서 표본을 뽑아 가중치로 보정해 기댓값을 추정하는 기법임
- 수치 근사: 정확한 해 대신 계산 가능한 근삿값을 구하는 방식임
- 격자법: 정의역을 규칙적인 격자점으로 나누어 값을 합산하는 결정론적 수치 해석법임

## 작성 근거(검토용)

- **개요 구성**: 기출 키워드이므로 난수 반복, 통계량, 근사라는 정의 요소를 짧게 고정함
- **Ⅱ. 특징 선정**: 적용성, 병렬성, 오차-계산량 관계, 신뢰구간은 몬테카를로의 장단점을 직접 설명함
- **Ⅲ. 비교축 선정**: 계산 방식, 차원 증가 영향, 주요 위험은 격자법과 몬테카를로 방법의 선택을 가름
- **Ⅳ. 구조 선정**: 확률 모델, 난수 생성기, 시뮬레이션 함수, 통계 집계기, 수렴 기준은 실험 재현에 필요한 구성임
- 난수 품질과 표본 수 증가에 따른 점진적 오차 감소는 계산 자원 산정의 판단 기준임

## Ⅰ. 개요

- **정의/개념**: 몬테카를로 방법은 난수 표본을 반복 생성하고 통계 결과로 근삿값을 구하는 수치 계산 기법임
- **배경/필요성**: 계산 비용이 크거나 정확한 해를 구하기 어려운 문제를 풀기 위해 표본 기반 근사가 필요함

### 쉽게 이해하기 (학습용)
- 눈을 감고 과녁에 화살을 수백 번 쏜 뒤, 화살이 맞은 자리들의 평균 위치로 과녁 중심을 짐작하는 것과 같음

## Ⅱ. 특징

- 확률 모델로 표현한 문제의 근삿값을 표본 평균·빈도 등의 통계량으로 구함
- 각 표본 시행이 독립적이므로 여러 노드에서 병렬 실행한 뒤 통계량을 합산할 수 있음
- 표본 수를 늘릴수록 표준오차는 감소하지만 개선 폭은 점차 작아지고 계산량은 계속 증가함
- 추정 결과는 표준오차와 신뢰구간으로 함께 제시해야 함

### 쉽게 이해하기 (학습용)
- 화살을 쏠 때마다 서로 영향이 없어 여러 사람이 동시에 쏴서 결과만 합쳐도 됨(병렬 가능)
- 정밀도를 조금 더 높이려 해도 표본 수를 크게 늘려야 하므로 정확도와 계산 비용을 함께 판단해야 함

## Ⅲ. 종류 및 비교

| 판단 기준 | 결정론적 수치 해석 (격자법) | 몬테카를로 방법 (통계법) |
|:---|:---|:---|
| 계산 방식 | 규칙 격자점의 결정론적 합산 | 난수 표본의 통계량 추정 |
| 차원 증가 영향 | 격자점 수가 지수적으로 증가 | 차원 수와 무관하게 표본 증가에 따른 점진적 오차 감소 특성 유지 |
| 주요 위험 | 격자 이산화 오차 | 난수 생성 편향 |

> 요약: 저차원 구간을 규칙적으로 분할하면 격자법, 차원 증가로 격자 수가 급증하면 몬테카를로 방법을 적용함.

### 쉽게 이해하기 (학습용)
- 격자법은 과녁 전체를 촘촘한 그물로 나눠 일일이 계산해 변수(차원)가 늘면 그물코가 폭발적으로 늘어나지만, 몬테카를로는 무작위로 툭툭 쏘기만 하면 되니 차원이 늘어도 크게 느려지지 않음

## Ⅳ. 구성요소 및 구조

| 설계 요소 | 설명 |
|:---|:---|
| 확률 모델 | 원문제의 불확실성을 나타내는 확률변수와 표본의 확률분포 |
| 난수 생성기 | 확률 분포에 따른 표본 입력 생성 |
| 시뮬레이션 함수 | 표본을 결과값으로 변환하는 실행 모델 |
| 통계 집계기 | 근삿값과 오차 범위 산출 |
| 수렴 기준 | 목표 오차에 따른 반복 종료 조건 |

> 요약: 몬테카를로 방법은 확률 모델의 난수 표본을 반복 실행하고 통계량으로 근삿값과 오차 범위를 산출함.

### 쉽게 이해하기 (학습용)
- 주사위를 굴리는 규칙(확률 모델), 실제로 굴리는 도구(난수 생성기), 굴린 결과를 기록하는 장부(통계 집계기)가 각자 역할을 나눠 맡음

## Ⅴ. 원리 및 절차 흐름도

```text
확률 모델 정의 → 난수 표본 생성 → 시뮬레이션·통계 갱신
                                      ↓
                                목표 오차 판정
                         ├─ 미달 → 다음 표본 반복
                         └─ 충족 → 추정값·오차 범위 반환
```

1. **확률 모델링**: 확률변수의 분포와 결과 산출 기준을 정의함
2. **표본 생성**: 난수 생성기로 독립 표본을 반복 추출함
3. **반복 실험**: 각 표본을 시뮬레이션 함수에 넣고 결과를 저장함
4. **오차 평가**: 표준오차와 신뢰구간으로 목표 정밀도 도달 여부를 판단함

> 요약: 난수 표본의 통계량으로 근삿값을 구하고 표준오차와 신뢰구간으로 정밀도를 평가함.

### 쉽게 이해하기 (학습용)
- 규칙을 정하고, 주사위를 굴리고, 결과를 쌓아가다가, 오차가 충분히 작아지면 멈추는 반복 과정임

## Ⅵ. 실무 사례

1. 서버 용량 계획은 부하 분포를 반복 표본화하고 허용 용량 초과 확률로 증설 여부를 정함
2. 시스템 신뢰도 평가는 장애 시나리오를 반복 실행해 장애 확률과 신뢰구간을 구함

### 쉽게 이해하기 (학습용)
- 서버를 몇 대 준비할지 미리 알 수 없을 때, 여러 상황을 무작위로 수백 번 시뮬레이션해서 감당 못 할 확률을 미리 가늠하는 것과 같음

## Ⅶ. 결론

- 몬테카를로 방법은 무작위 실험을 반복해 답을 근사하며, 시행 횟수와 계산 비용 사이에서 필요한 정밀도를 정해야 함
- 수식으로 직접 풀기 어렵고 입력 분포를 모델링할 수 있을 때 적용하며, 드문 장애는 중요도 표본추출로 추정 오차를 줄여야 함

### 쉽게 이해하기 (학습용)
- 정확히 계산하기 힘든 문제는 많이 시도해 평균을 내는 방식으로 근사치를 구하되, 시도 횟수와 계산 비용의 균형을 스스로 정해야 함
