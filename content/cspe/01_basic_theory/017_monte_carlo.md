## Ⅰ. 개요
| 항목 | 내용 |
|---|---|
| **정의** | 무작위 표본(Random Sampling)을 반복 추출하여 수치적 근사해를 구하는 확률적 알고리즘 기법임 |
| **배경/필요성** | 해석적 해가 불가능하거나 고차원 적분·최적화 문제에서 결정론적 방법의 계산 비용이 급증하며, 확률적 근사가 필요함 |
| **출제 의도** | 몬테카를로의 수렴 원리(큰 수의 법칙)와 적용 분야를 설명할 수 있는지 평가함 |

## Ⅱ. 구성요소
```
+----------+     +----------+     +----------+
| 난수생성  | --> | 시뮬레이션| --> | 통계추정  |
| (RNG)    |     | (반복시행)|     | (평균/분산)|
+----------+     +----------+     +----------+
```

| 구성요소 | 설명 | 비유 |
|---|---|---|
| 난수 생성기 | 균일 분포·정규 분포 등에서 무작위 표본을 생성함 | 주사위 던지기 |
| 시뮬레이션 | 각 표본에 대해 모델을 실행하여 결과를 수집함 | 주사위를 N번 던져 기록 |
| 통계 추정 | 수집된 결과의 평균·분산을 계산하여 근사해와 신뢰 구간을 산출함 | 평균 눈금 계산 |

> 요약: 난수 생성 → 반복 시뮬레이션 → 통계 추정으로 해석 불가 문제의 근사해를 구함.

## Ⅲ. 절차
```
+------------+     +------------+
| 문제모델링  | --> | 난수표본   |
| (확률분포)  |     | N개 생성   |
+------------+     +------------+
                        |
+------------+     +----+-------+
| 근사해     | <-- | 결과집계  |
| 신뢰구간   |     | 통계계산   |
+------------+     +------------+
```

1. 문제 모델링: 구하려는 값을 확률적 기대값으로 정의함(예: π = 4 × 원 내부 점 비율)
2. 난수 표본 생성: N개의 무작위 표본을 관련 확률 분포에서 추출함
3. 결과 집계: 각 표본에 대해 함수값을 계산하고 합산함
4. 근사해·신뢰 구간 산출: 표본 평균을 근사해로, 표준오차로 신뢰 구간을 계산함(오차 ∝ 1/√N)

> 요약: 모델링 → 표본 생성 → 집계 → 통계 추정으로 O(1/√N) 수렴의 근사해를 구함.

## Ⅳ. 문제점
- 느린 수렴: 오차가 1/√N에 비례하여 정밀도를 10배 높이려면 표본이 100배 필요함
- 난수 품질: 의사 난수 생성기의 주기·편향이 결과 정확도에 영향을 줌
- 분산 문제: 함수의 분산이 크면 동일 표본 수에서 추정 정밀도가 저하됨

## Ⅴ. 개선방안
- (단기) 분산 감소 기법: 층화 표본 추출·중요도 표본 추출로 추정 분산을 줄임
- (중기) 준몬테카를로: 저불일치 수열(Sobol·Halton)로 균일 분포를 개선하여 수렴을 가속함
- (장기) GPU 병렬화: 수억 개 표본을 GPU에서 병렬 생성·계산하여 실시간 시뮬레이션을 달성함

## Ⅵ. 전망
- 금융 파생상품 가격 산정·핵물리 시뮬레이션·강화 학습(MCTS)에서 몬테카를로가 핵심이며, 양자 컴퓨팅 기반 양자 몬테카를로가 O(1/N) 수렴을 목표로 연구되고 있음
