# 📖 【암기용】 개념 완전 이해

## 한눈에
- **개요**: ETA(Event Tree Analysis)는 **상향식(bottom-up) 귀납적 분석** 기법으로, 하나의 초기사건(Initiating Event)에서 출발해 안전장치·방어벽의 성공/실패 분기를 순서대로 전개하며 가능한 결과들을 확률로 예측하는 방법임.
- **왜 필요한가**: 초기사건(화재·누출 등) 발생 후 방어벽(스프링클러·차단밸브·경보)이 작동/미작동함에 따라 결과가 갈리므로, 각 경로의 확률을 산출해야 대응 설계를 수립할 수 있음.
- **핵심 직관**: 도미노 첫 조각(초기사건)이 넘어진 뒤, 이후 조각들이 세워져 있으면(방어벽 성공) 멈추고, 넘어지면(실패) 대형 사고로 이어지는 것.

## 핵심 용어 정리 (내부에 등장하는 것들)

032가 FTA(하향식 역추적)를, 034가 FMEA(부품 단위)를 다뤘으므로 여기서는 ETA 고유의 순전개·분기 용어에 집중함.

| 용어/표기 | 의미 | 비유·예 |
|:---|:---|:---|
| ETA (상위 키워드) | 초기사건→방어벽 분기→결과 시나리오 순전개 상향식 분석 | 도미노 연쇄 전개 |
| Initiating Event(초기사건) | 사고 연쇄의 출발점 | 배관 누출, 화재 발생 |
| Pivotal Event(핵심 분기) | 방어벽·안전기능의 성공/실패 분기점 | 가스 감지기 작동 여부 |
| 성공 분기 | 방어벽이 정상 작동해 사고 확산을 억제 | 스프링클러 작동 |
| 실패 분기 | 방어벽이 미작동해 사고가 다음 단계로 진행 | 차단밸브 미작동 |
| 경로 확률 | 각 분기의 성공/실패 확률을 곱해 산출한 최종 결과 확률 | 0.1 × 0.05 = 0.005 |
| Bowtie 기법 | FTA(032, 원인)+ETA(결과)를 초기사건 중심으로 결합한 양방향 분석 | 나비넥타이 형태 시각화 |

## 깊이 이해
- **배경·문제의식**: 원자력·화학 플랜트의 확률론적 위험성 평가(PRA, Probabilistic Risk Assessment)에서 초기사건 발생 후 사고 전개 경로를 예측하기 위해 발전함. IT 영역에서는 장애 초기사건 후 방어벽(모니터링·페일오버·백업)의 작동 여부에 따른 결과 시나리오 분석에 활용.
- **작동 원리 — ETA 구축**:
  - 초기사건을 트리 왼쪽(시작점)에 놓음.
  - 각 방어벽·안전기능(Pivotal Event)마다 성공(위 분기)·실패(아래 분기)로 이진 분기를 오른쪽으로 순서대로 전개.
  - 최종 결과 시나리오(안전 정지, 제한적 누출, 대형 폭발 등)가 트리 오른쪽 끝에 나열됨.
- **정량화**:
  - 각 분기의 성공확률(P_s)·실패확률(P_f=1−P_s)를 경로별로 곱해 최종 시나리오 발생확률을 산출.
  - 예: 초기사건 발생 후 감지기 성공(0.95) → 차단밸브 성공(0.9) → 안전 정지: 0.95 × 0.9 = 0.855.
  - 감지기 성공(0.95) → 차단밸브 실패(0.1) → 제한 누출: 0.95 × 0.1 = 0.095.
- **FTA와의 결합(Bowtie)**: 각 Pivotal Event(방어벽)의 실패확률 자체를 FTA(032)로 구해 ETA에 대입하면, 왼쪽(원인→초기사건)은 FTA, 오른쪽(초기사건→결과)은 ETA인 bowtie 분석이 완성됨.
- **방향성 핵심**: ETA = "원인(Initiating Event) → 결과" 상향식·귀납적(inductive). FTA(032) = "결과(Top Event) → 원인" 하향식·연역적(deductive). 방향이 정반대.
- **비유**: 나무 뿌리(초기사건)에서 줄기를 타고 올라가 여러 가지(결과 시나리오)로 뻗어나가는 방식.
- **구체 예시**: 초기사건 "배관 누출" → 분기1: 가스 감지기(성공/실패) → 분기2: 자동 차단밸브(성공/실패) → 결과: "안전 정지(P=0.855)", "제한적 누출(P=0.095)", "확산 누출(P=0.045)", "대형 폭발(P=0.005)".
- **흔한 오해·주의점**: ① ETA를 "결과에서 원인을 추적하는 기법"으로 착각하기 쉬움 — 실제로는 초기사건에서 결과를 순전개. ② 방어벽 순서가 결과에 영향 — 순서를 잘못 정하면 시나리오 확률이 왜곡됨. ③ FTA(032)·FMEA(034)와 역할이 다름 — ETA는 결과 예측, FTA는 원인 규명, FMEA는 고장모드 나열.

## 연결 개념
- **FTA (032)**: 결과→원인 역추적. ETA와 방향이 반대. bowtie로 결합 가능.
- **FMEA (034)**: 부품·공정 단위 고장모드 나열. ETA 방어벽 실패 모드의 후보 공급원.
- **Bowtie 기법**: FTA(032)+ETA를 초기사건 중심으로 결합한 양방향 분석.

# 📝 【답안용】 시험 답안 템플릿

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: ETA는 초기사건에서 방어벽 성공/실패 분기를 순전개해 결과 시나리오별 확률을 산출하는 상향식·귀납적 기법임.
> 2. **가치**: 초기사건 이후 가능한 결과들의 확률 분포를 제공해 방어벽 투자 우선순위와 대응 설계의 근거가 됨.
> 3. **판단 포인트**: 원인→결과 예측이면 ETA, 결과→원인 규명이면 FTA(032), 양방향은 bowtie 결합.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 상향식·귀납적 방향 | 초기사건 → 방어벽 분기 → 결과 순전개 | 방향을 하향식으로 오술 |
| 분기 논리 이해 | 성공/실패 이진 분기, 경로 확률 곱셈 | 분기를 AND/OR 게이트(FTA)와 혼동 |
| FTA 구분 | 방향성·분석 출발점 차이 | ETA와 FTA를 동일하게 서술 |

> 요약: 상향식 방향성 + 성공/실패 분기 논리 + 경로 확률 곱셈 + FTA(032) 구분을 보여야 함.

## Ⅰ. 개요 및 필요성

- 개요: 초기사건에서 방어벽 성공/실패 분기를 순전개해 결과 시나리오별 확률을 산출하는 상향식·귀납적 분석 기법
- 배경: 원자력·화학 PRA에서 초기사건 이후 사고 전개 경로 예측을 위해 발전, IT 장애 분석으로 확산
- 필요성: 초기사건 발생 후 방어벽 작동/미작동 조합에 따른 결과 확률을 산출해야 대응 투자 우선순위 결정 가능

---

## Ⅱ. 구조 및 구성요소

```text
Initiating Event(초기사건)
  -> Pivotal Event 1(방어벽1): 성공/실패 분기
  -> Pivotal Event 2(방어벽2): 성공/실패 분기
  -> ... -> 최종 결과 시나리오별 확률 산출
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Initiating Event | 사고 연쇄의 출발점 | 트리 왼쪽 시작 |
| Pivotal Event | 방어벽·안전기능의 성공/실패 분기점 | 순서가 결과에 영향 |
| 성공/실패 분기 | 이진 분기(P_s, P_f=1−P_s) | 확률 곱셈으로 경로 계산 |
| 결과 시나리오 | 트리 오른쪽 끝 최종 결과 | 안전 정지~대형 사고 범위 |
| 경로 확률 | 분기 확률의 곱 | 모든 경로 합 = 1 |

> 요약: 초기사건에서 방어벽 순서대로 성공/실패를 분기하고 경로 확률 곱으로 결과 시나리오를 산출하는 구조임.

---

## Ⅲ. 동작원리 및 흐름도

```text
초기사건 정의 -> 방어벽 순서 결정 -> 성공/실패 이진 분기 전개
  -> 각 분기에 확률 부여 -> 경로별 확률 곱셈
  -> 결과 시나리오별 확률 산출 -> 고위험 경로 식별
```

1. 분석 대상 초기사건을 정의함(예: "배관 누출", "서버 전원 장애")
2. 초기사건 이후 작동할 방어벽·안전기능을 시간순·논리순으로 나열하고 Pivotal Event 순서를 결정함
3. 각 Pivotal Event마다 성공(P_s)/실패(P_f=1−P_s) 이진 분기를 전개하고 경로별 확률을 곱셈으로 산출함
4. 최종 결과 시나리오별 확률을 정리하고 고위험 경로(대형 사고·높은 확률)를 식별해 방어벽 강화 우선순위를 결정함

> 요약: 초기사건 → 방어벽 분기 → 확률 곱셈 → 고위험 경로 식별 순으로 진행함.

---

## Ⅳ. 특징

- 상향식·귀납적: 원인(초기사건)에서 결과로 순전개 — FTA(032)와 방향 반대
- 이진 분기: 각 방어벽에서 성공/실패 두 가지로만 분기, 경로 확률은 곱셈
- 시나리오 망라: 가능한 결과 시나리오를 빠짐없이 열거해 확률 분포 제공
- 순서 민감: 방어벽 순서가 결과를 좌우하므로 논리적·시간적 순서 결정이 핵심
- Bowtie 결합: FTA(032)와 결합하면 원인(FTA)→초기사건→결과(ETA)의 양방향 분석 가능

---

## Ⅴ. 심화 비교 및 적용 판단

| 구분 | ETA (상향식·귀납적) | FTA (032, 하향식·연역적) | 선택 기준 |
|:---|:---|:---|:---|
| 시작점 | Initiating Event(초기 원인) | Top Event(결과) | 출발이 원인인지 결과인지 |
| 방향 | 원인 → 결과 순전개 | 결과 → 원인 역추적 | 결과 예측 vs 원인 규명 |
| 분기 논리 | 성공/실패 이진 분기 | AND/OR 게이트 | 방어벽 작동 분석 vs 원인 조합 분석 |
| 출력 | 결과 시나리오별 확률 분포 | 최소 컷셋, Top Event 확률 | 영향도 분석 vs SPOF 식별 |

> 요약: 결과 시나리오 예측·방어벽 투자 우선순위는 ETA, 원인 규명·SPOF 식별은 FTA(032)를 적용함.

**리스크·대응:**
- 방어벽 순서 오류: 논리적·시간적 순서 잘못 설정 → 현장 전문가 검토 + 운영 시나리오 매핑 (지표: 순서 검토 완료 여부)
- 분기 확률 부정확: 방어벽 성공/실패 확률 데이터 미확보 → FTA(032)로 방어벽 실패확률 정밀 산출 + 현장 이력 데이터 (지표: 확률 데이터 출처 신뢰도)
- 시나리오 누락: 방어벽 후보를 빠뜨림 → FMEA(034) 결과와 교차 검증 (지표: 방어벽 커버리지율)

**점검 지표:**
- 성능: 고위험 시나리오(대형 사고) 발생확률이 허용 기준 이하 — 경로 확률 곱셈 결과
- 운영: 방어벽 커버리지 100% + bowtie 분석 완성도 — FMEA(034) 교차 검증 체크리스트

---

## Ⅵ. 실무 적용 및 결론

**적용 방안:**
1. 초기사건(장애·사고)을 정의하고 이후 작동할 방어벽을 시간순·논리순으로 나열해 ETA 트리를 구축함
2. 각 방어벽의 성공/실패 확률을 FTA(032)·현장 이력으로 산출하고 경로별 확률을 곱셈으로 계산함
3. 고위험 경로(높은 확률 × 큰 영향)를 식별해 방어벽 강화(이중화·자동화) 우선순위를 결정하고, FTA(032)와 bowtie로 결합해 양방향 분석을 완성함

**결론:**
- 기술사 판단: 결과 시나리오 예측·방어벽 투자 판단이 목적이면 ETA를 우선 적용하고, FTA(032)와 bowtie로 결합해 분석 완성도를 높여야 함
- 향후 방향: 동적 ETA(Dynamic ETA)와 실시간 모니터링 데이터를 연계해 방어벽 실패 확률을 운영 중 갱신하는 방향으로 발전 중임
