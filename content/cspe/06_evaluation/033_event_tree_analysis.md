# 📖 【암기용】 개념 완전 이해

> 목적: ETA를 처음 봐도 왜 "원인에서 결과로" 앞으로 전개하는지, 성공/실패 분기가 무엇을 의미하는지 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 하나의 초기사건(Initiating Event)에서 출발해 안전장치·방어벽의 성공/실패 여부를 순서대로 분기하며 가능한 결과들을 앞으로 전개하는 상향식(bottom-up) 귀납적 분석 기법
- **왜 필요한가**: 화재·누출 같은 초기사건이 발생했을 때 이후 방어벽(스프링클러, 차단밸브, 경보)이 순서대로 작동/미작동함에 따라 어떤 결과로 이어지는지 확률로 예측해야 대응 설계를 세울 수 있다.
- **핵심 직관**: 도미노 첫 조각(초기사건)이 넘어진 뒤 이후 조각들이 세워져 있는지(방어벽 성공) 넘어지는지(방어벽 실패)에 따라 최종 결과가 갈리는 것과 같다.

## 깊이 이해
- **배경·문제의식**: 원자력·화학 플랜트 위험성 평가(PRA, Probabilistic Risk Assessment)에서 초기사건 발생 이후의 사고 전개 경로를 예측하기 위해 발전했다.
- **작동 원리**: 초기사건을 트리의 왼쪽(시작점)에 놓고, 각 방어벽·안전기능(Pivotal Event)마다 성공(위쪽 분기)과 실패(아래쪽 분기)로 나눈 이진 분기를 오른쪽으로 순서대로 전개한다.
- **방향성 핵심**: ETA는 "초기사건 -> 순차적 방어벽 -> 최종 결과"로 나아가는 상향식·귀납적(inductive) 분석이며, 결과에서 원인으로 내려가는 하향식 연역적 분석(FTA)과 방향이 반대다.
- **비유**: 나무 뿌리(초기사건)에서 줄기를 타고 올라가 여러 가지(결과)로 뻗어나가는 방식이다.
- **구체 예시**: 초기사건 "배관 누출" 이후 "가스 감지기 작동 여부(성공/실패)" -> "자동 차단밸브 작동 여부(성공/실패)" 순으로 분기해 "안전 정지", "제한적 누출", "대형 폭발" 등 결과 시나리오와 각각의 확률을 산출한다.
- **정량화**: 각 분기의 성공확률·실패확률을 경로별로 곱해 최종 결과 시나리오의 발생확률을 계산한다.
- **FTA와의 결합**: 각 Pivotal Event(방어벽)의 실패확률 자체를 FTA로 구해 ETA에 대입하는 bowtie 기법이 실무에서 널리 쓰인다.
- **흔한 오해·주의점**: ETA를 "결과에서 원인을 추적하는 기법"으로 착각하기 쉽지만, 실제로는 이미 정의된 초기사건에서 출발해 앞으로 결과를 전개하는 기법이다.
- **FTA·FMEA와 구분**: FTA는 정상사건에서 원인을 역추적하는 하향식 기법이고, FMEA는 부품 단위 고장모드를 사전 나열하는 상향식 기법이다.

## 연결 개념
- FTA — 결과에서 원인으로 역추적하는 하향식 연역 기법, ETA와 방향이 반대
- FMEA — 부품·공정 단위 고장모드를 나열하는 상향식 기법
- Bowtie 기법 — FTA(원인)와 ETA(결과)를 초기사건 중심으로 결합한 시각화 기법

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.
> 핵심: ETA 답안은 상향식·귀납적 방향성, Pivotal Event 성공/실패 분기, 결과 확률 계산, FTA와의 방향 차이를 함께 제시한다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: ETA는 초기사건에서 출발해 방어벽의 성공/실패를 순차 분기하며 결과를 예측하는 상향식·귀납적 분석 기법이다.
> 2. **가치**: 방어벽별 성공/실패 확률을 경로별로 곱해 각 결과 시나리오의 발생확률을 정량화한다.
> 3. **판단 포인트**: 원인에서 결과를 예측할 때는 ETA, 결과에서 원인을 역추적할 때는 FTA를 선택한다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 상향식·귀납적 방향 이해 확인 | 초기사건 -> 순차 분기 -> 결과 전개 | 방향을 하향식으로 반대 서술 |
| 분기 논리 이해 확인 | Pivotal Event 성공/실패 이진 분기 | 분기를 AND/OR 게이트로 혼동 |
| FTA·FMEA와 구분 확인 | 방향성·분석 단위 차이 | 세 기법을 동일하게 서술 |

> 요약: 이 문제는 ETA의 상향식 방향성과 방어벽 분기 확률 계산을 정확히 구분해 보여야 한다.

---

## Ⅰ. 개요 및 필요성

- 정의: 초기사건에서 방어벽 성공/실패를 순차 분기해 결과를 전개하는 상향식 귀납적 분석 기법
- 배경: 원자력·화학 플랜트 확률론적 위험성 평가(PRA)에서 사고 전개 경로 예측을 위해 발전
- 필요성: 초기사건 발생 후 방어벽 작동 여부에 따른 결과 시나리오와 확률을 예측하려면 순차 분기 트리 구조가 필요

---

## Ⅱ. 구조 및 구성요소

```text
Initiating Event(초기사건)
  -> Pivotal Event 1(성공/실패) -> Pivotal Event 2(성공/실패)
  -> ... -> Outcome(결과 시나리오)
  -> 경로별 확률 곱셈 -> 결과별 발생확률 산출
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Initiating Event | 분석 시작점이 되는 사건 | 트리 왼쪽에 위치 |
| Pivotal Event | 방어벽·안전기능의 작동 여부 | 성공/실패 이진 분기 |
| Success Path | 방어벽이 정상 작동한 경로 | 결과 완화 방향 |
| Failure Path | 방어벽이 미작동한 경로 | 결과 악화 방향 |
| Outcome | 최종 결과 시나리오 | 시나리오별 발생확률 산출 |

> 요약: ETA는 초기사건 이후 방어벽 성공/실패를 순차 분기해 결과 시나리오별 확률을 산출하는 구조다.

---

## Ⅲ. 동작원리 및 흐름도

```text
초기사건 식별 -> 방어벽(Pivotal Event) 순서 정의
  -> 각 방어벽 성공/실패 확률 부여 -> 순차 분기 전개
  -> 경로별 확률 곱셈 -> 결과 시나리오 확정
  -> 고위험 시나리오 식별 -> 방어벽 보강
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 분석 대상 초기사건을 명확히 정의 | 초기사건 발생빈도 데이터 확보 |
| 2 | 관련 방어벽을 발생 순서대로 나열 | 방어벽 누락 여부 |
| 3 | 방어벽별 성공/실패 확률로 분기 전개 | 확률 데이터의 신뢰도 |
| 4 | 경로별 확률을 곱해 결과 시나리오 확정 | 시나리오 총합 확률 1.0 |

> 요약: ETA는 초기사건 이후 방어벽을 순서대로 분기하며 결과 시나리오별 확률을 산출한다.

---

## Ⅳ. 특징

| 구분 | 내용 | 판단 포인트 |
|:---|:---|:---|
| 장점 | 초기사건 이후 다양한 결과 시나리오를 확률로 정량화 | 방어벽 다중화 효과 검증 가능 |
| 한계 | 초기사건 발생빈도 자체는 별도 데이터 필요 | 초기사건 확률 미확보 시 결과 신뢰도 저하 |
| 비교 포인트 | 상향식·귀납적 방향, 원인에서 결과로 이동 | FTA(하향식)와 방향이 반대 |

> 요약: ETA는 결과 시나리오 정량화에 강하지만 초기사건 발생빈도 데이터에 의존한다.

---

## Ⅴ. 심화 비교 및 적용 판단

| 비교 축 | ETA | FTA | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | 상향식(bottom-up), 초기사건에서 결과로 순전개 | 하향식(top-down), Top Event에서 원인으로 역추적 | 분석 목적이 결과 예측인지 원인 규명인지 |
| 분석 논리 | 귀납적(inductive), 성공/실패 이진 분기 | 연역적(deductive), AND/OR 게이트 | 방어벽 중심이면 ETA, 원인 조합 중심이면 FTA |
| 운영/위험 | 분기 누락 시 결과 시나리오 과소 추정 | 원인 누락 시 확률 과소 추정 | bowtie로 결합해 상호 보완 |

> 요약: 결과 시나리오 예측은 ETA, 원인 규명은 FTA로 역할을 분리하고 bowtie 기법으로 결합한다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 방어벽 누락 | 안전기능 목록 불완전 | 설계 문서·HAZOP 결과와 교차 검증 | 방어벽 커버리지율 |
| 확률 데이터 부실 | Pivotal Event 실패확률 미확보 | FTA로 방어벽별 실패확률 산출 후 대입 | 데이터 출처 신뢰도 |
| 시나리오 누락 | 저확률 경로 임의 제외 | 전체 경로 확률 합이 1.0인지 검증 | 시나리오 확률 총합 |

> 요약: ETA 운영 리스크는 방어벽 누락과 확률 데이터 부실이 핵심이므로 FTA·HAZOP과 연계해 보완한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| 고위험 시나리오 확률 | 목표 허용확률 이하 | 경로별 확률 계산 결과 |
| 방어벽 커버리지 | 설계 안전기능 대비 반영률 100% | HAZOP·설계 문서 대조 |
| 시나리오 완결성 | 전체 확률 합 1.0 | 트리 전체 경로 검증 |

> 요약: ETA 성공 여부는 고위험 시나리오 확률, 방어벽 커버리지, 시나리오 완결성으로 판단한다.

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 — 단계별 또는 항목별):**
1. 초기사건을 정의하고 관련 방어벽을 발생 순서대로 나열해 이진 분기 트리를 구축함
2. FTA로 산출한 방어벽별 실패확률을 ETA 분기에 대입해 결과 시나리오 확률을 계산함
3. 고위험 결과 시나리오를 식별해 방어벽 다중화·자동화로 발생확률을 낮춤

**결론 (2줄):**
- 기술사 판단: 결과 시나리오 예측이 목적이면 ETA를 우선 적용하고 FTA와 bowtie로 결합해 보완함
- 향후 방향: ETA 결과를 신뢰성 성장 모델·FMEA와 연계해 방어벽 개선 효과를 지속 검증해야 함

### 🔀 문제 유형별 목차 전환 (이 키워드 출제 시)

| 유형 | 문제 신호어 | Ⅲ 강조 | Ⅳ 강조 |
|:---|:---|:---|:---|
| 포괄형 | "ETA를 설명하시오" | 초기사건-방어벽 분기 절차 | FTA와의 방향 차이 |
| 비교형 | "FTA와 ETA를 비교하시오" | 상향식 vs 하향식 절차 대비 | 귀납적·연역적 논리 차이 |

> 요약: 설명형은 방어벽 분기 절차, 비교형은 ETA·FTA의 방향성 차이 중심으로 답안 축을 바꾼다.
