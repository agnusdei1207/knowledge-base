## 미리 알고가기

- Sizing: 목표 업무량을 처리하기 위해 필요한 CPU, 메모리, 디스크, 네트워크 용량을 산정하는 활동임
- Peak Factor: 평균 부하 대비 피크 부하 증가율을 반영하는 보정 계수임
- Headroom: 장애, 증가율, 운영 변동을 흡수하기 위해 남겨 두는 여유 용량임
- tpmC: TPC-C 벤치마크에서 분당 처리 트랜잭션 수를 나타내는 지표임
- 보정 계수: 업무 복잡도, 이중화, 성장률, 피크 부하처럼 기본 계산값을 조정하는 값임

## Ⅰ. 개요

- **정의/개념**: TPS 기반 하드웨어 규모 산정은 목표 트랜잭션량과 업무 특성을 CPU, 메모리, 디스크, 네트워크 요구량으로 변환하는 용량 계획 절차임
- **배경/필요성**: 경험만으로 장비를 정하면 과소 산정은 성능 장애를 만들고 과대 산정은 비용 낭비를 만들기 때문에 업무량 기반의 계산과 검증이 필요함

## Ⅱ. 특징

- 목표 TPS는 업무 트랜잭션 정의와 피크 부하 비율이 정해진 뒤 계산해야 함
- CPU 산정은 벤치마크 지표를 참고하되 실제 업무 복잡도와 보정 계수를 반영해야 함
- 메모리와 디스크는 동시 사용자, 데이터 증가율, 캐시, 로그 보관 정책에 따라 달라짐
- 산정 결과는 이론값이므로 BMT나 부하 테스트로 실측 검증을 거쳐야 함

## Ⅲ. 종류 및 비교

| 산정 항목 | 입력 기준 | 확인 지표 | 주의점 |
|:---|:---|:---|:---|
| CPU | 목표 TPS, 업무 복잡도, 벤치마크 성능 | CPU utilization, run queue | 벤치마크와 실제 업무 차이를 보정함 |
| 메모리 | 동시 사용자, 세션, 캐시, JVM heap | RSS, heap usage, page fault | 캐시와 누수를 구분해야 함 |
| 디스크 | 데이터량, 증가율, IOPS, 보관 기간 | IOPS, latency, capacity | 용량과 I/O 성능을 함께 봄 |
| 네트워크 | 요청 크기, 응답 크기, 동시 처리량 | throughput, packet loss, RTT | 대역폭과 처리율을 구분함 |

## Ⅳ. 구성요소 및 구조

|:---|:---|

| 기본 산정 | CPU, 메모리, 디스크, 네트워크별 요구량을 계산함 |

| 검증 절차 | BMT와 성능 테스트로 산정값이 목표 부하를 만족하는지 확인함 |

## Ⅴ. 원리 및 절차 흐름도

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 목표 TPS 산정 | --> | 자원별 계산  | --> | 여유율 반영  | --> | BMT 확인    |
+-----------+     +-----------+     +-----------+     +-----------+
```

1. **목표 TPS 산정**: 업무량, 사용자 수, 피크 패턴으로 목표 처리량을 계산함
2. **자원별 계산**: CPU, 메모리, 디스크, 네트워크 요구량을 나누어 계산함
3. **여유율 반영**: 성장률, 장애 대응, 클러스터 오버헤드를 보정함
4. **BMT 확인**: 후보 장비와 실제 업무 시나리오로 성능을 검증함

## Ⅵ. 실무 적용 및 유의점

1. 공공·대형 사업 산정에서는 벤치마크 수치만으로 장비를 확정하지 말고 업무 복잡도와 피크 계수를 반영해야 하므로 목표 TPS, 보정 계수, BMT TPS를 함께 확인함
2. 클라우드 환경에서는 오토스케일링이 있어도 초기 용량이 낮으면 피크 초기에 지연이 커질 수 있으므로 base capacity, scale-out time, p95 latency를 확인함

## Ⅶ. 결론

TPS 기반 규모 산정은 장비 사양을 크게 잡는 일이 아니라 목표 업무량을 자원별 요구량으로 나누고 보정 계수와 실측 시험으로 검증하는 절차임.

## 작성 근거(검토용)

- 126회, 129회 기출 이력이 있어 산정 입력, 자원별 계산, 보정, 검증 순서로 답안 흐름을 구성함
- 넓은 평가어를 직접 쓰지 않고 피크, 성장률, BMT, p95 지연으로 판단 근거를 제시함
- 결론은 규모 산정의 역할을 계산과 검증 절차로 좁혀 과장 표현을 제거함
