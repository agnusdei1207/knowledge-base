## 미리 알고가기

- Benchmark: 정해진 워크로드와 측정 조건으로 시스템 성능을 비교하는 시험 방식임
- SPEC: CPU, Java, 서버 등 범용 컴퓨팅 성능을 평가하는 벤치마크 계열임
- TPC: 트랜잭션 처리와 데이터베이스 성능을 평가하는 벤치마크 계열임
- LINPACK: 선형방정식 계산 성능을 FLOPS 기준으로 측정하는 HPC 벤치마크임
- BMT: 도입 후보 시스템을 실제 업무 조건에 가깝게 비교 시험하는 활동임

## Ⅰ. 개요

- **정의/개념**: 벤치마크는 표준 워크로드와 측정 조건을 사용해 시스템 성능을 정량적으로 비교하는 평가 방식임
- **배경/필요성**: 제조사 사양만으로는 시스템 간 성능 차이를 같은 기준에서 비교하기 어려우므로, 공통 워크로드와 지표가 필요함

## Ⅱ. 특징

- 표준 벤치마크는 동일 조건의 비교를 돕지만 실제 업무 성능을 그대로 대변하지는 않음
- SPEC, TPC, LINPACK은 평가 대상과 지표가 달라 업무 유형에 맞게 골라야 함
- 가격 대비 성능은 성능 수치와 도입·운영 비용을 함께 계산해 판단함
- 최종 도입 판단은 표준 벤치마크보다 실제 업무 BMT 결과와 함께 내려야 함

## Ⅲ. 종류 및 비교

| 판단 기준 | SPEC | TPC | LINPACK |
|:---|:---|:---|:---|
| 평가 대상 | CPU, JVM, 서버 처리 성능 | DB 트랜잭션과 분석 처리 | HPC 수치 연산 성능 |
| 대표 지표 | SPECint, SPECfp, SPECjbb | tpmC, QphH, price/performance | FLOPS, Rmax, Rpeak |
| 적합 업무 | 범용 서버와 미들웨어 성능 비교 | OLTP, OLAP, DB 서버 비교 | 과학 계산, 슈퍼컴퓨팅 |
| 주의점 | 애플리케이션 업무 특성과 차이가 날 수 있음 | DB 설정과 가격 조건을 함께 봐야 함 | 일반 업무 처리량과 직접 연결되지 않음 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 표준 워크로드 | 비교 대상 시스템에 동일하게 적용할 작업 유형과 데이터 규모를 정의함 |
| 측정 환경 | 하드웨어, OS, DB, 컴파일러, 설정 값을 명시해 재현성을 확보함 |
| 성능 지표 | 처리량, 응답시간, FLOPS, 가격 대비 성능처럼 비교 단위를 정함 |
| 결과 해석 | 표준 결과와 실제 업무 차이를 확인해 BMT 필요 여부를 판단함 |

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 워크로드 선택 | --> | 환경 고정    | --> | 지표 측정    | --> | 업무 적합성 판단 |
+-----------+     +-----------+     +-----------+     +-----------+
```

## Ⅴ. 원리 및 절차 흐름도

```text
+-----------+     +-----------+     +-----------+     +-----------+
| 대상 선정    | --> | 벤치마크 선택 | --> | 결과 비교    | --> | BMT 보완    |
+-----------+     +-----------+     +-----------+     +-----------+
```

1. **대상 선정**: CPU, DB, HPC 등 비교하려는 시스템 계층을 정함
2. **벤치마크 선택**: 평가 대상에 맞는 SPEC, TPC, LINPACK 계열을 고름
3. **결과 비교**: 성능 수치와 가격 대비 성능을 같은 기준으로 비교함
4. **BMT 보완**: 실제 업무 데이터와 시나리오로 후보 시스템을 다시 확인함

## Ⅵ. 실무 적용 및 유의점

1. 서버 도입 검토에서는 SPEC 수치만으로 업무 성능을 단정하지 말고 애플리케이션 특성과 병목 계층을 맞춰야 하므로 표준 점수와 BMT TPS를 함께 확인함
2. DB 장비 비교에서는 TPC 결과의 가격 조건과 설정이 자사 환경과 다를 수 있으므로 구성 명세, price/performance, 실제 쿼리 응답시간을 확인함

## Ⅶ. 결론

벤치마크는 가장 높은 점수를 고르는 절차가 아니라 평가 대상에 맞는 표준 지표를 고르고 실제 업무 시험으로 해석 범위를 검증하는 비교 방식임.

## 작성 근거(검토용)

- SPEC, TPC, LINPACK은 이름 나열이 되기 쉬워 평가 대상과 대표 지표를 비교표의 중심으로 배치함
- 추상 평가어를 삭제하고 업무 적합성과 BMT 보완으로 판단을 구체화함
- 결론은 표준 점수의 한계와 실제 업무 검증 필요성을 회수함
