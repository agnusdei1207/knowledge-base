# 📖 【암기용】 개념 완전 이해

## 한눈에
- **개요**: 신뢰성 성장 모델은 **시스템 신뢰성 예측** 기법으로, TAAF(Test-Analyze-And-Fix) 반복으로 결함을 제거할 때 **누적 MTBF가 시험시간에 따라 증가하는 추세**를 정량식으로 추적하는 모델임. 대표 모델이 Duane과 Crow-AMSAA임.
- **왜 필요한가**: "신뢰성 목표를 달성했는가, 테스트를 얼마나 더 해야 하는가"를 감으로 판단할 수 없음. 누적 시험시간과 누적 MTBF의 관계식이 있어야 잔여 시험시간과 출시 시점을 정량 예측 가능.
- **핵심 직관**: 재활 환자가 훈련을 반복할수록 회복 속도를 그래프로 그려, 완치 기준 도달 시점을 예측하는 것과 같음.

## 핵심 용어 정리 (내부에 등장하는 것들)

018이 MTBF·MTTR 정의를, 032·034가 FTA·FMEA를 다루므로 여기서는 신뢰성 성장 고유의 모델·파라미터 용어에 집중함.

| 용어/표기 | 의미 | 비유·예 |
|:---|:---|:---|
| 신뢰성 성장 모델 (상위 키워드) | TAAF 반복 시 MTBF 증가 추세를 추적하는 정량 모델 | 재활 환자 회복 곡선 |
| TAAF | Test-Analyze-And-Fix, 시험→원인분석→근본수정 반복 절차 | 시험→진단→치료 반복 |
| Duane 모델 | 누적 시험시간과 누적 MTBF의 log-log 직선 관계 경험식 | 성적 향상 추세선(경험적) |
| Crow-AMSAA 모델 | Duane을 NHPP(비동질 포아송 과정)로 통계 재정식화한 모델 | 성적 향상의 통계적 검증 |
| 성장률 α | log-log 기울기, 결함 수정 효과가 MTBF에 반영되는 속도 | 성적 향상 기울기 |
| β (형상 파라미터) | Crow-AMSAA 강도함수 계수, β<1이면 신뢰도 개선 추세 | β<1 = 회복 중, β≥1 = 정체/악화 |
| 순간 MTBF | Crow-AMSAA가 산출하는 현 시점의 MTBF 추정값 | 현재 컨디션 수치 |
| NHPP | Non-Homogeneous Poisson Process, 고장 강도가 시간에 따라 변하는 확률 과정 | 시간에 따라 고장 빈도가 달라지는 모델 |

## 깊이 이해
- **배경·문제의식**: 1962년 Duane(GE)이 항공기·발전기 개발 과정에서 누적 시험시간과 누적 고장률을 log-log 좌표에 찍었더니 직선에 가까운 관계를 발견함. 이를 Crow가 NHPP로 통계 재정식화해 신뢰구간·순간 MTBF 산출이 가능한 Crow-AMSAA 모델로 발전시킴.
- **작동 원리 — Duane 모델**:
  - 누적 MTBF(θc)와 누적 시험시간(T)이 log-log 좌표에서 직선: log(θc) = log(K) + α·log(T).
  - α(성장률)가 클수록 결함 수정 효과가 빠르게 반영됨. 일반적으로 α=0.3~0.6이 현실적.
  - 한계: 결정론적 경험식이라 신뢰구간 산출 불가, 통계적 유의성 검증 불가.
- **작동 원리 — Crow-AMSAA 모델**:
  - 강도함수: λ(t) = λβt^(β−1). β<1이면 고장 강도 감소 = 신뢰도 개선 추세.
  - 순간 MTBF(현 시점의 MTBF)와 신뢰구간 산출 가능 → Duane보다 통계 검증력이 높음.
  - MIL-HDBK-189(군사 표준)이 Crow-AMSAA를 기반 모델로 채택.
- **비유**: Duane = 학생의 모의고사 점수를 눈대중 추세선으로 그리는 것. Crow-AMSAA = 같은 데이터를 통계 회귀로 분석해 신뢰구간과 현재 실력을 정밀 추정하는 것.
- **구체 예시**: 누적시험시간 100h에서 누적 MTBF 50h, 1000h에서 158h → log-log 기울기 α≈0.5. 목표 MTBF 200h 달성에 필요한 잔여 시험시간을 역산해 시험 계획을 수정.
- **흔한 오해·주의점**: ① 시험시간만 늘려도 MTBF가 오르는 것이 아님 — TAAF 절차로 발견된 결함의 근본 원인을 제거해야 성장 곡선이 형성됨. ② 이 항목은 하드웨어·시스템 레벨(Duane/Crow-AMSAA)을 다루며, SW 신뢰도 성장 모델(Musa·Goel-Okumoto)은 040에서 별도로 다룸.

## 연결 개념
- **MTBF·MTTR (018)**: 성장 모델이 추적하는 목표 지표.
- **FTA·FMEA (032·034)**: 성장 곡선 정체 시 근본 원인 분석에 사용하는 기법.
- **SW 신뢰도 성장 모델 (040)**: 소프트웨어 결함 검출 중심 모델(Musa·Goel-Okumoto).

# 📝 【답안용】 시험 답안 템플릿

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 신뢰성 성장 모델은 TAAF 반복에 따른 누적 MTBF 증가 추세를 Duane(경험식)·Crow-AMSAA(NHPP 통계식)로 정량 추적하는 기법임.
> 2. **가치**: 잔여 시험시간과 목표 MTBF 도달 시점을 정량 예측해 시험 계획과 출시 판단의 근거를 제공함.
> 3. **판단 포인트**: 초기 추세 파악은 Duane, 통계적 신뢰구간·순간 MTBF가 필요하면 Crow-AMSAA를 선택함.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 성장 모델 원리 | Duane log-log 직선, Crow-AMSAA NHPP | "테스트 반복하면 좋아진다"만 서술 |
| 정량 추정 역량 | 성장률 α, 강도함수 β, 순간 MTBF | 수식·수치 없이 개념만 서술 |
| SW 모델 구분 | HW Duane/Crow-AMSAA vs SW Musa/Goel-Okumoto(040) | 두 모델 계열 혼용 |

> 요약: Duane/Crow-AMSAA 관계식 + 성장률 α + TAAF 절차 + SW 모델(040)과 구분을 보여야 함.

---

## Ⅰ. 개요 및 필요성

- 개요: TAAF 반복에 따른 누적 MTBF 증가 추세를 log-log 관계식(Duane)·NHPP(Crow-AMSAA)로 추적하는 정량 모델
- 배경: Duane(1962)이 항공기·발전기 시험 데이터에서 누적 시험시간-누적 MTBF의 log-log 직선 관계를 발견
- 필요성: 목표 MTBF 달성 시점과 잔여 시험시간을 예측하려면 성장률 파라미터 기반 정량 모델 필수

---

## Ⅱ. 구조 및 구성요소

```text
TAAF 반복(시험->분석->수정) -> 고장 시각·누적 시험시간 기록
  -> 누적 MTBF 계산 -> Duane/Crow-AMSAA 회귀 -> 성장률(α/β) 추정
  -> 목표 MTBF 도달 시점 역산
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| TAAF 절차 | 결함 발생 시 원인 분석→근본 수정 | 수정 없이 시험만으로는 성장 불가 |
| 누적 시험시간(T) | 모델 입력 변수(x축) | log 스케일 |
| 누적 MTBF(θc) | 모델 출력 변수(y축) | log 스케일 |
| 성장률(α) | Duane log-log 기울기, 개선 속도 | 0.3~0.6이 현실적 범위 |
| β(형상 파라미터) | Crow-AMSAA 강도함수 계수 | β<1이면 개선 추세, β≥1이면 정체/악화 |

> 요약: TAAF 데이터를 회귀식에 대입해 성장률(α/β)과 목표 도달 시점을 산출하는 구조임.

---

## Ⅲ. 동작원리 및 흐름도

```text
시험 시작 -> 고장 발생 기록 -> 원인 분석(TAAF)
  -> 설계/공정 수정 -> 누적(T, θc) 갱신
  -> log-log 회귀(Duane) 또는 NHPP 추정(Crow-AMSAA)
  -> 목표 MTBF 비교: 미달→시험 지속, 도달→시험 종료
```

1. 시험 중 고장 발생 시각과 누적 시험시간을 기록하고 TAAF로 근본 원인을 분석·수정함
2. 누적 MTBF를 갱신하고 log-log 좌표에 데이터 포인트를 추가함
3. Duane 모델(경험식)로 성장률 α를 추정하거나, 데이터 20건 이상 확보 후 Crow-AMSAA(NHPP)로 전환해 순간 MTBF·신뢰구간을 산출함
4. 목표 MTBF 대비 달성률을 비교해 미달 시 잔여 시험시간을 역산하고, 도달 시 시험을 종료함

> 요약: TAAF → 데이터 축적 → Duane/Crow-AMSAA 회귀 → 목표 대비 판정 → 시험 지속/종료 순으로 진행함.

---

## Ⅳ. 특징

- Duane 모델: log-log 직선 경험식, 계산 단순, 초기 추세 파악에 적합하나 신뢰구간 산출 불가
- Crow-AMSAA: NHPP 기반 통계식, 순간 MTBF·신뢰구간 산출 가능, MIL-HDBK-189 채택 모델
- β<1 개선: β<1이면 고장 강도 감소(MTBF 증가) 추세, β≥1이면 정체 또는 악화 → TAAF 재점검 필요
- TAAF 전제: 시험시간만 늘리면 안 됨 — 발견된 결함을 근본 원인까지 제거해야 성장 곡선 형성
- SW 모델과 구분: 이 항목은 HW·시스템 레벨(Duane/Crow-AMSAA), SW 결함 중심(Musa/Goel-Okumoto)은 040 참조

## Ⅴ. 심화 비교 및 적용 판단

| 구분 | Duane 모델 | Crow-AMSAA 모델 | 선택 기준 |
|:---|:---|:---|:---|
| 통계 기반 | 결정론적 경험식(log-log 직선) | NHPP 기반 최우추정(MLE) | 통계 검증 필요 여부 |
| 산출 지표 | 누적 MTBF 추세선 | 순간 MTBF + 신뢰구간 | 신뢰구간·유의성 요구 여부 |
| 표본 요구 | 소수 데이터 허용 | 고장 20건 이상 권장 | 확보 가능한 고장 데이터 수 |
| 적용 시점 | 시험 초기(추세 파악) | 시험 후반(통계 검증) | 시험 진행 단계 |

> 요약: 초기 소수 데이터에는 Duane, 데이터 확보 후 통계 검증에는 Crow-AMSAA를 적용함.

**리스크·대응:**
- 성장 정체: 근본 원인 미제거(임시 조치만 수행) → FTA(032)·FMEA(034)로 근본 원인 재분석 + TAAF 이력 점검 (지표: 동일 고장 모드 재발 건수)
- 모델 과적합: 소수 데이터로 α를 확정해 오판 → 고장 20건 이상 확보 후 회귀, 적합도 검정(R² ≥ 0.8) (지표: 결정계수·잔차 분포)
- 목표 미달: 시험 종료 압박으로 조기 판단 → 잔여 시험시간 재계산 후 일정 연장 판단 (지표: 목표 MTBF 대비 현재 달성률)

**점검 지표:**
- 성능: 목표 MTBF 대비 달성률 100% + 모델 적합도 R² ≥ 0.8 — Crow-AMSAA 순간 MTBF 산출
- 운영: 결함 재발률(동일 고장 모드 재발 0건) — TAAF 이력 로그 대조

## Ⅵ. 실무 적용 및 결론

**적용 방안:**
1. 시험 초기에는 Duane 모델로 log-log 추세선을 그려 개략적 성장률 α와 잔여 시험시간을 산정함
2. 고장 데이터 20건 이상 확보 후 Crow-AMSAA로 전환해 순간 MTBF·신뢰구간을 산출하고 목표 달성 여부를 통계 검증함
3. 성장 정체 구간은 FTA(032)·FMEA(034)로 근본 원인을 재분석하고 TAAF 이력의 재발률 지표를 관리함

**결론:**
- 기술사 판단: 초기 추세 파악은 Duane, 목표 달성의 통계적 검증은 Crow-AMSAA를 선택하며 TAAF 기반 근본 수정이 성장의 전제임
- 향후 방향: HW 성장 모델(Duane/Crow-AMSAA)과 SW 성장 모델(040, Musa/Goel-Okumoto)을 통합한 시스템 수준 신뢰성 예측 체계로 확장 추세임
