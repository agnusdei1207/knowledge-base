# 📖 【암기용】 개념 완전 이해

## 한눈에
- **개요**: 리틀의 법칙(Little's Law)은 안정 상태(steady state) 대기 시스템에서 **계 내 평균 개수 L, 도착률 λ, 평균 체류시간 W가 항상 L = λW로 연결된다는 항등식**이다.
- **왜 필요한가**: 세 값 중 둘만 측정하면 나머지를 곱셈·나눗셈으로 즉시 역산할 수 있어, 직접 세기 어려운 값(평균 동시 처리 건수·평균 재공품 수)을 쉽게 구하기 때문이다.
- **핵심 직관**: 매장 안 평균 손님 수 = 분당 입장객 × 평균 체류 분. 얼마나 자주 들어오고(λ) 얼마나 오래 머무느냐(W)만 알면 안에 몇 명이 있는지(L)가 곱으로 정해진다.

## 핵심 용어 정리 (내부에 등장하는 것들)

이 법칙은 변수 3개짜리 곱셈식 하나가 전부이므로, 각 변수와 적용 조건을 정확히 못 박는 것이 핵심이다. 맨 위 상위 키워드가 정체성이다.

| 용어/표기 | 의미 | 비유·예 |
|:---|:---|:---|
| 리틀의 법칙(Little's Law) | L=λW 항등식. 평균 개수=도착률×체류시간 | 매장 인원 = 입장속도 × 체류시간 |
| L (계 내 평균 개수) | 시스템 안에 머무는 평균 항목 수 | 지금 매장 안 평균 손님 수 |
| λ(도착률) | 단위 시간당 도착(=완료) 평균 건수 | 분당 입장객 수 |
| W (평균 체류시간) | 항목이 도착~완료까지 머문 평균 시간 | 손님 1명의 평균 체류 분 |
| Lq·Wq | 대기 구간에만 적용한 L·W (Lq=λWq) | 줄에 선 평균 인원 = λ×대기시간 |
| 안정 상태(steady state) | 장기적으로 도착=완료로 개수가 발산·소멸하지 않는 상태 | 입장객과 퇴장객이 균형 잡힌 매장 |
| 항등식(보존 법칙) | 특정 조건이 아니라 항상 성립하는 등식 | 분포·순서와 무관한 불변 관계 |

## 깊이 이해
- **배경·문제의식**: 큐잉 이론(005)은 L·Lq와 W·Wq를 각각 산출하지만, 이 둘을 잇는 다리가 필요하다. 리틀의 법칙은 그 다리 역할을 하는 단일 항등식으로, 005가 Lq에서 Wq를 뽑을 때(Wq=Lq/λ) 쓰는 바로 그 식이다. 이 파일은 그 항등식 자체의 일반성과 증명·적용에 집중한다.
- **작동 원리(왜 항상 성립하는가)**: 오랜 시간 T 동안 시스템에 머문 모든 항목의 체류시간을 다 더한 총량은, 시각별 계 내 개수 N(t)를 시간으로 적분한 넓이와 같다. 이 넓이를 T로 나누면 평균 개수 L이고, 같은 넓이를 "도착 수(=λT)"로 나누면 평균 체류시간 W다. 두 관점이 같은 넓이를 가리키므로 L·T = λT·W, 즉 L = λW가 도착·서비스 분포와 무관하게 성립한다.
- **일반성(가장 중요한 성질)**: M/M/1 같은 특정 모델에서만 성립하는 공식이 아니다. 도착이 포아송이 아니어도, 서비스가 지수분포가 아니어도, 처리 순서가 FIFO가 아니어도, 안정 상태이기만 하면 성립하는 보존 법칙이다.
- **경계를 어디에 긋느냐로 여러 식이 나온다**: 시스템 전체를 경계로 잡으면 L=λW, 대기열만 잡으면 Lq=λWq, 서버만 잡으면 서버 내 평균 수 Ls=λ×(1/μ)=ρ가 된다. 즉 "이용률 ρ=λ/μ"조차 서버에 리틀의 법칙을 적용한 결과다.
- **비유**: 물이 흐르는 욕조. 단위 시간당 유입량(λ)과 물 한 방울이 욕조에 머무는 평균 시간(W)을 알면, 욕조 안 평균 물의 양(L)은 두 값의 곱으로 정해진다 — 수도꼭지 물살이 일정하든 불규칙하든 무관하다.
- **구체 예시(워크드)**: ① 콜센터에 초당 2콜(λ=2)이 들어오고 통화가 평균 90초(W=90s)면, 동시에 통화 중인 상담사는 평균 L=2×90=180명이 필요하다. ② 웹 서비스가 500 TPS(λ)이고 평균 응답시간 0.2초(W)면 동시 처리 건수 L=500×0.2=100건 — 001에서 쓴 "동시 사용자 N=TPS×응답시간"이 바로 리틀의 법칙이다.
- **흔한 오해·주의점**: ① 특정 큐잉 모델(M/M/1) 전용 공식으로 오해하면 안 된다 — 분포 가정이 필요 없다. ② 안정 상태가 전제다. 도착이 처리를 계속 앞지르는 폭주 구간(ρ≥1)에서는 L이 발산해 적용 불가다. ③ λ와 W의 경계(전체냐 큐냐)를 섞으면(예: 전체 λ에 큐 W) 틀린다 — 같은 경계의 변수끼리만 곱한다.

## 연결 개념
- 시스템 성능 지표(001) — 동시 사용자 N=TPS×응답시간이 리틀의 법칙의 실무 형태
- 큐잉 이론(005) — Lq에서 Wq를 뽑는 다리(Wq=Lq/λ)로 이 법칙을 사용
- 응답 시간 분해(002) — 전체 W와 대기 Wq에 각각 L=λW·Lq=λWq를 나눠 적용

# 📝 【답안용】 시험 답안 템플릿

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 리틀의 법칙은 안정 상태에서 계 내 평균 개수 L = 도착률 λ × 평균 체류시간 W로 항상 성립하는 항등식임.
> 2. **가치**: 분포·순서 가정 없이 성립하므로 동시 사용자·TPS·응답시간 중 둘을 알면 나머지를 역산해 용량 근거로 씀.
> 3. **판단 포인트**: 경계를 전체로 잡으면 L=λW, 큐로 잡으면 Lq=λWq이며 같은 경계의 변수끼리만 곱해야 함.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 산식·변수 정의 확인 | L=λW와 L·λ·W의 정확한 의미 | 변수 순서 뒤바꿈, λ=L/W만 암기 |
| 일반성 이해 확인 | 분포 무관·안정 상태에서 항상 성립 | M/M/1 전용 공식으로 서술 |
| 실무 역산 활용 확인 | TPS·응답시간으로 동시 처리 건수 역산 | 공식만 제시하고 적용 예시 누락 |

> 요약: 공식 암기가 아니라 일반성(분포 무관)과 경계별 역산 적용을 보여야 함.

---

## Ⅰ. 개요 및 필요성

- 개요: 안정 상태 시스템에서 계 내 평균 개수 L이 도착률 λ과 체류시간 W의 곱과 같다는 항등식(L=λW)
- 배경: 큐잉 이론(005)이 산출한 L·Lq와 W·Wq를 잇는 다리로, 분포 가정 없이 성립하는 보존 법칙
- 필요성: 직접 세기 어려운 동시 처리 건수를 λ·W 측정만으로 역산해 용량 산정 근거로 삼기 위함

---

## Ⅱ. 구조 및 구성요소

- 역산 구조(선형 구조도):

```text
경계 정의(전체 vs 큐) -> λ(도착률) 측정 + W(체류시간) 측정
  -> L = λW 계산 -> 동시 처리 건수(L) 또는 대기 인원(Lq) 산출
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| 도착률 λ | 단위 시간당 도착=완료 건수 | TPS·RPS로 측정 |
| 체류시간 W | 도착~완료 평균 시간 | 전체는 W, 대기는 Wq |
| 평균 개수 L | 계 내 평균 항목 수 | 동시 사용자·재공품에 대응 |
| 경계 정의 | 전체(L,W)냐 큐(Lq,Wq)냐 | 변수 경계 일치가 필수 |

> 요약: 경계를 정하고 λ·W를 측정하면 그 경계의 평균 개수를 곱으로 산출함.

---

## Ⅲ. 동작원리 및 흐름도

- 산출·검증 흐름(선형 흐름도):

```text
경계 정의 -> λ 측정 -> W 측정 -> L=λW 계산
  -> 실측 동시 개수와 대조 -> 괴리 시 병목·측정오류 의심
```

1. 분석 경계를 시스템 전체(L,W) 또는 대기열(Lq,Wq)로 정의해 변수 짝을 고정함
2. 로그·APM에서 단위 시간당 도착률 λ을 측정함
3. 동일 경계의 평균 체류시간 W(또는 대기시간 Wq)를 측정함
4. L=λW를 계산해 실측 동시 개수와 대조하고, 괴리가 크면 안정성 위반·측정 오류를 점검함

---

## Ⅳ. 특징

- 도착·서비스 분포나 처리 순서와 무관하게 안정 상태에서 항상 성립하는 보존 법칙임
- 경계를 전체로 잡으면 L=λW, 대기열로 잡으면 Lq=λWq로 같은 형태가 재사용됨
- 서버에 적용하면 서버 내 평균 수가 이용률 ρ=λ/μ가 되어 ρ도 이 법칙의 결과임
- 세 변수 중 둘만 측정하면 나머지를 역산할 수 있어 용량 산정의 기본 검증 도구가 됨
- 안정 상태(도착=완료)가 전제이므로 ρ≥1 폭주 구간에서는 L이 발산해 적용 불가함

---

## Ⅴ. 심화 비교 및 적용 판단

- 적용 경계에 따른 해석 비교:

| 구분 | 시스템 전체 (L=λW) | 대기열만 (Lq=λWq) |
|:---|:---|:---|
| 측정 대상 | 도착~완료 전체 체류 | 큐 진입~서버 할당 대기 |
| 결과 의미 | 동시 처리 건수·동시 사용자 | 평균 대기 인원 |
| 활용 | 서버·커넥션 풀 용량 산정 | 큐 버퍼 크기·오버플로 설계 |

> 요약: 동시 사용자 산정은 전체 경계(L=λW), 큐 버퍼 설계는 대기 경계(Lq=λWq)를 사용함.

- 리스크와 대응(불릿):
  - 경계 혼용 → 전체 λ에 큐 Wq를 곱하는 오적용 → L/Lq·W/Wq 짝을 문서에 명시(확인: 계산값-실측 오차)
  - 안정 상태 위반 → 피크 폭주 구간(ρ≥1)에 적용 → 시간대별로 분리 측정·산정(확인: 구간별 λ 변동)
  - 실측 미검증 → 계산값만 신뢰 → 모니터링으로 주기 대조(확인: 계산 L vs 실측 동시 수 오차율)

---

## Ⅵ. 실무 적용 및 결론

- 적용 방안:
  1. 신규 용량 산정 시 목표 TPS(λ)와 목표 응답시간(W)으로 필요한 동시 처리 용량(L)·커넥션 풀 크기를 사전 계산함
  2. 운영 중 실측 동시 사용자 수와 계산값 L=λW를 대조해 병목·측정 오류를 조기 탐지함
  3. 분석 경계(전체 L,W / 큐 Lq,Wq)를 문서에 표준화해 변수 짝 혼용을 방지함
- 결론:
  - 리틀의 법칙은 분포 가정 없이 성립하는 항등식이라 용량 산정·검증의 기본 잣대로 활용해야 함
  - 실시간 λ·W를 자동 수집해 L을 상시 계산하고 오토스케일링 트리거로 연계하는 체계로 확장 필요
