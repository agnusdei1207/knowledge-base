# 📖 【암기용】 개념 완전 이해

## 한눈에
- **개요**: FTA(Fault Tree Analysis)는 **하향식(top-down) 연역적 결함 분석** 기법으로, 정상사건(Top Event, 최상위 고장)에서 출발해 AND/OR 게이트로 기본원인까지 역추적하는 방법임.
- **왜 필요한가**: 이미 발생했거나 우려되는 대형 고장의 원인 조합을 구조적으로 밝혀야 재발 방지 대책을 원인 수준에서 수립할 수 있음.
- **핵심 직관**: 화재 현장 감식반이 불이 난 결과(정상사건)에서 출발해 "누전 AND 가연물 존재" 같은 조합 원인을 역으로 추적하는 것.

## 핵심 용어 정리 (내부에 등장하는 것들)

033이 ETA(순방향 분석)를, 034가 FMEA(부품 단위 분석)를, 024가 SPOF 제거를 다루므로 여기서는 FTA 고유의 트리·게이트·컷셋 용어에 집중함.

| 용어/표기 | 의미 | 비유·예 |
|:---|:---|:---|
| FTA (상위 키워드) | 정상사건→기본원인 역추적 하향식 결함 분석 | 화재 감식: 결과에서 원인으로 |
| Top Event(정상사건) | 분석 대상 최상위 고장 사건 | "서버실 화재" |
| AND Gate | 하위 사건 모두 발생해야 상위 사건 발생 | 누전 AND 가연물 근접 |
| OR Gate | 하위 사건 중 하나만 발생해도 상위 사건 발생 | 전기적 요인 OR 인적 요인 |
| Basic Event(기본사건) | 더 이상 분해되지 않는 최하위 원인 | 배선 노후화, 소화기 미비 |
| Minimal Cut Set(최소 컷셋) | Top Event를 유발하는 기본사건의 최소 조합 | 단일 원소면 SPOF(024) |
| 불 대수(Boolean Algebra) | AND/OR 게이트를 확률식으로 변환하는 논리 체계 | 확률의 곱·합 계산 |

## 깊이 이해
- **배경·문제의식**: 1961년 벨연구소가 미니트맨 미사일 발사 통제 시스템의 오발사 원인을 분석하기 위해 고안함. 이후 항공·원자력·IT 시스템까지 확산.
- **작동 원리 — FTA 구축**:
  - Top Event를 트리 꼭대기에 놓고, 이를 유발하는 중간사건(Intermediate Event)과 기본사건(Basic Event)을 AND/OR 게이트로 연결함.
  - AND Gate: 하위 사건이 **모두** 발생해야 상위 사건 발생 → 확률은 곱셈(P₁ × P₂).
  - OR Gate: 하위 사건 중 **하나만** 발생해도 상위 사건 발생 → 확률은 합집합(P₁ + P₂ − P₁P₂).
- **작동 원리 — 정량화와 최소 컷셋**:
  - 기본사건에 고장확률을 부여하면 불 대수로 Top Event 발생확률을 계산 가능.
  - 최소 컷셋(Minimal Cut Set): Top Event를 일으키는 기본사건의 최소 조합. 단일 원소 컷셋은 그 자체가 SPOF(024).
  - 최소 컷셋의 크기(원소 수)가 작을수록 위험 → 이중화·다중 방어벽으로 컷셋 크기를 키워야 함.
- **방향성 핵심**: FTA = "결과(Top Event) → 원인(Basic Event)" 하향식·연역적(deductive). ETA(033) = "원인(Initiating Event) → 결과" 상향식·귀납적(inductive). 방향이 정반대.
- **비유**: 나무의 뿌리(기본 원인)를 찾기 위해 줄기·가지를 타고 내려가는 방식. 나무 꼭대기(Top Event)에서 시작.
- **구체 예시**: Top Event "서버실 화재" → OR Gate: [전기적 요인, 인적 요인]. 전기적 요인 → AND Gate: [누전, 가연물 근접]. 기본사건 확률: 누전 P=0.01, 가연물 근접 P=0.05 → 전기적 화재 P=0.0005.
- **흔한 오해·주의점**: ① FTA를 "원인에서 결과를 예측하는 기법"으로 착각하기 쉬움 — 실제로는 결과에서 원인을 역추적. ② 사전에 식별되지 않은 원인은 트리에 반영 불가 → FMEA(034) 결과를 기본사건 후보로 교차 검증. ③ ETA(033)와 결합하면 양방향 분석(bowtie 분석)이 가능.

## 연결 개념
- **ETA (033)**: 초기사건에서 결과로 전개하는 상향식 귀납 기법. FTA와 방향이 반대.
- **FMEA (034)**: 부품·공정 단위 고장모드를 나열하는 상향식 기법. FTA 기본사건 후보 공급원.
- **SPOF 제거 (024)**: 최소 컷셋 크기 1 = SPOF. FTA 결과로 SPOF를 정량 식별.

# 📝 【답안용】 시험 답안 템플릿

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: FTA는 정상사건(Top Event)에서 AND/OR 게이트로 기본원인까지 역추적하는 하향식·연역적 분석 기법임.
> 2. **가치**: 최소 컷셋을 도출해 SPOF(024)와 원인 조합별 발생확률을 정량 식별함.
> 3. **판단 포인트**: 결과→원인 역추적이면 FTA, 원인→결과 예측이면 ETA(033), 양방향은 bowtie 결합.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 하향식·연역적 방향 | Top Event → Basic Event 역추적 | 방향을 상향식으로 오술 |
| 게이트 논리 이해 | AND(모두 필요, 곱셈) vs OR(하나로 충분, 합집합) | 게이트 의미 반대 서술 |
| ETA·FMEA 구분 | 방향성·분석 단위 차이 | 세 기법을 동일하게 서술 |

> 요약: 하향식 방향성 + AND/OR 게이트 논리 + 최소 컷셋 + ETA(033)·FMEA(034)와의 구분을 보여야 함.

---

## Ⅰ. 개요 및 필요성

- 개요: 정상사건에서 기본원인까지 AND/OR 게이트로 역추적하는 하향식·연역적 결함 분석 기법
- 배경: 1961년 벨연구소가 미사일 오발사 원인 분석을 위해 고안, 이후 항공·원자력·IT까지 확산
- 필요성: 대형 장애의 원인 조합을 구조적으로 규명하고 최소 컷셋으로 SPOF(024)를 정량 식별해야 재발 방지 가능

---

## Ⅱ. 구조 및 구성요소

```text
Top Event(정상사건)
  -> OR/AND Gate -> 중간사건(Intermediate Event)
  -> OR/AND Gate -> 기본사건(Basic Event)
  -> 확률 대입(불 대수) -> 최소 컷셋(Minimal Cut Set) 도출
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Top Event | 분석 대상 최상위 고장 사건 | 트리 최상단 |
| AND Gate | 하위 사건 모두 발생 시 상위 사건 발생 | 확률 곱셈(P₁×P₂) |
| OR Gate | 하위 사건 하나만 발생해도 상위 사건 발생 | 확률 합집합(P₁+P₂−P₁P₂) |
| Basic Event | 최하위 기본원인(분해 불가) | 고장확률 데이터 필요 |
| Minimal Cut Set | Top Event 유발 최소 기본사건 조합 | 단일 원소 = SPOF(024) |

> 요약: Top Event를 게이트 논리로 분해해 기본사건 확률과 최소 컷셋을 산출하는 구조임.

---

## Ⅲ. 동작원리 및 흐름도

```text
Top Event 정의 -> 직접 원인 식별(중간사건)
  -> AND/OR 게이트 연결 -> 기본사건까지 반복 분해
  -> 기본사건 고장확률 대입 -> Top Event 확률 계산
  -> 최소 컷셋 도출 -> SPOF·고위험 조합 식별
```

1. 분석 대상 Top Event를 명확히 정의함(예: "서버실 화재", "결제 시스템 전면 중단")
2. Top Event의 직접 원인을 식별하고 AND/OR 게이트로 연결, 기본사건까지 반복 분해함
3. 기본사건에 고장확률을 대입하고 불 대수(Boolean Algebra)로 Top Event 발생확률을 계산함
4. 최소 컷셋을 도출해 단일 원소 컷셋(SPOF, 024)을 식별하고 이중화·다중 방어벽으로 제거함

> 요약: Top Event 정의 → 게이트 분해 → 확률 계산 → 최소 컷셋/SPOF 식별 순으로 진행함.

---

## Ⅳ. 특징

- 하향식·연역적: 결과(Top Event)에서 원인(Basic Event)으로 내려감 — ETA(033)와 방향 반대
- 정량화 가능: 불 대수로 Top Event 확률을 수치 산출, 최소 컷셋으로 고위험 조합 정량 식별
- SPOF 식별: 최소 컷셋 크기 1 = SPOF(024). 이중화로 컷셋 크기를 키워야 위험 감소
- 원인 누락 취약: 사전에 식별되지 않은 원인은 트리에 반영 불가 → FMEA(034)로 보완 필수
- bowtie 결합: FTA(결과→원인) + ETA(033, 원인→결과)를 결합하면 양방향 분석 가능

---

## Ⅴ. 심화 비교 및 적용 판단

| 구분 | FTA (하향식·연역적) | ETA (033, 상향식·귀납적) | 선택 기준 |
|:---|:---|:---|:---|
| 시작점 | Top Event(결과) | Initiating Event(초기 원인) | 결과가 정해졌는지 원인이 정해졌는지 |
| 방향 | 결과 → 원인 역추적 | 원인 → 결과 순전개 | 원인 규명 vs 결과 예측 |
| 출력 | 최소 컷셋, Top Event 확률 | 결과 시나리오별 확률 | SPOF 식별 vs 영향도 분석 |
| 보완 관계 | FMEA(034)로 기본사건 후보 보완 | FTA 결과로 초기사건 후보 보완 | bowtie로 양방향 결합 가능 |

> 요약: 원인 규명·SPOF 식별은 FTA, 결과 시나리오 예측은 ETA(033), 양방향은 bowtie로 결합함.

**리스크·대응:**
- 원인 누락: 브레인스토밍 부족·신규 고장모드 미반영 → FMEA(034) 결과를 기본사건 후보로 교차 검증 (지표: 기본사건 커버리지율)
- 확률 데이터 부실: 기본사건 고장률 미확보 → 신뢰성 성장 모델(031)·현장 이력 데이터 활용 (지표: 데이터 출처 신뢰도)
- SPOF 방치: 최소 컷셋 크기 1인 사건 미대응 → 이중화(023)·다중 방어벽 설계로 컷셋 크기 확대 (지표: 단일 원소 컷셋 0건)

**점검 지표:**
- 성능: Top Event 발생확률이 목표 허용확률 이하 — 불 대수 기반 확률 계산
- 운영: 단일 원소 최소 컷셋(SPOF) 0건 + FMEA 대비 기본사건 반영률 100% — 교차 검증 체크리스트

---

## Ⅵ. 실무 적용 및 결론

**적용 방안:**
1. 대형 장애·안전사고 대상 Top Event를 정의하고 AND/OR 게이트로 기본사건까지 원인 트리를 구축함
2. 기본사건 고장확률을 확보해 불 대수로 Top Event 확률과 최소 컷셋을 계산하고, 단일 원소 컷셋(SPOF, 024)을 식별함
3. SPOF를 이중화(023)·다중 방어벽으로 제거하고, ETA(033)·FMEA(034)와 교차 검증해 원인 누락을 보완함

**결론:**
- 기술사 판단: 원인 규명·SPOF 식별이 목적이면 FTA를 우선 적용하고, ETA(033)·FMEA(034)와 교차 보완해 분석 완성도를 높여야 함
- 향후 방향: 동적 FTA(Dynamic FTA)와 정량 FTA 결과를 신뢰성 성장 모델(031)과 연계해 원인 제거 효과를 MTBF 개선으로 검증하는 방향으로 발전 중임
