# 📖 【암기용】 개념 완전 이해

> 목적: FTA를 처음 봐도 왜 "결과에서 원인으로" 거꾸로 분석하는지, AND/OR 게이트가 무엇을 의미하는지 이해하게 만든다. 시험 답안 양식이 아니라, 이해를 위한 친절한 설명이다.

## 한눈에
- **개요**: 하나의 정상사건(Top Event, 최상위 고장)에서 출발해 원인이 되는 하위 사건들을 AND/OR 게이트로 역추적하는 하향식(top-down) 연역적 분석 기법
- **왜 필요한가**: 이미 발생했거나 우려되는 대형 고장을 놓고 "무엇이 결합돼야 이 고장이 나는가"를 구조적으로 밝혀야 재발 방지 대책을 원인 수준에서 세울 수 있다.
- **핵심 직관**: 화재 현장 감식반이 불이 난 결과(정상사건)에서 출발해 "누전 AND 가연물 존재" 같은 조합 원인을 역으로 추적하는 것과 같다.

## 깊이 이해
- **배경·문제의식**: 1961년 벨연구소가 미니트맨 미사일 발사 통제 시스템의 오발사 원인을 분석하기 위해 고안한 기법이다.
- **작동 원리**: 최상위 정상사건을 트리의 꼭대기에 놓고, 이를 유발하는 중간사건과 기본사건(Basic Event)들을 AND 게이트(모두 발생해야 상위 사건 발생) 또는 OR 게이트(하나만 발생해도 상위 사건 발생)로 연결한다.
- **방향성 핵심**: FTA는 "결과(Top Event) -> 원인(Basic Event)"으로 내려가는 하향식·연역적(deductive) 분석이며, 원인에서 결과로 올라가는 상향식 귀납적 분석(ETA)과 방향이 반대다.
- **비유**: 나무의 뿌리(기본원인)를 찾기 위해 줄기와 가지를 타고 내려가는 방식이다.
- **구체 예시**: Top Event "서버실 화재"는 "전기적 요인 OR 인적 요인"으로 분기하고, 전기적 요인은 다시 "누전 AND 가연물 근접"의 AND 게이트로 세분화한다.
- **정량화**: 각 기본사건에 고장확률을 부여하면 게이트별 논리식(불 대수)으로 Top Event 발생확률을 계산할 수 있다.
- **최소 컷셋(Minimal Cut Set)**: Top Event를 일으키는 기본사건들의 최소 조합으로, 컷셋이 단일 원소면 그 자체가 단일 장애점(SPOF)이다.
- **흔한 오해·주의점**: FTA를 "원인에서 결과를 예측하는 기법"으로 착각하기 쉽지만, 실제로는 이미 정의된 결과(Top Event)에서 원인을 역추적하는 기법이다.
- **ETA·FMEA와 구분**: ETA는 초기사건에서 출발해 순방향으로 결과를 전개하는 상향식 귀납 기법이고, FMEA는 부품·공정 단위 고장모드를 사전에 나열하는 상향식 기법이다.

## 연결 개념
- ETA — 초기사건에서 결과로 전개하는 상향식 귀납 기법, FTA와 방향이 반대
- FMEA — 부품·공정 단위 고장모드를 나열하는 상향식 기법
- 신뢰성 성장 모델 — 정체 구간 원인 분석에 FTA를 활용

# 📝 【답안용】 시험 답안 템플릿

> 목적: 시험장에서 25분에 그대로 쓰는 답안 양식. 작성방식(추상표현 금지·수치·도식·문제유형 전환)을 엄격히 지킨다.
> 핵심: FTA 답안은 하향식·연역적 방향성, AND/OR 게이트 논리, 최소 컷셋, ETA·FMEA와의 방향 차이를 함께 제시한다.

## 핵심 인사이트 (3줄 요약)

> 1. **본질**: FTA는 정상사건(Top Event)에서 출발해 AND/OR 게이트로 기본원인까지 역추적하는 하향식·연역적 분석 기법이다.
> 2. **가치**: 최소 컷셋을 도출해 단일 장애점과 원인 조합별 발생확률을 정량적으로 식별한다.
> 3. **판단 포인트**: 결과에서 원인을 찾을 때는 FTA, 원인에서 결과를 예측할 때는 ETA를 선택한다.

## 출제 의도 및 답안 포인트

| 출제 의도 | 반드시 짚을 핵심 | 감점 회피 포인트 |
|:---|:---|:---|
| 하향식·연역적 방향 이해 확인 | Top Event -> 기본사건 역추적 | 방향을 상향식으로 반대 서술 |
| 게이트 논리 이해 확인 | AND(모두 필요) vs OR(하나로 충분) | 게이트 의미를 반대로 서술 |
| ETA·FMEA와 구분 확인 | 방향성·분석 단위 차이 | 세 기법을 동일하게 서술 |

> 요약: 이 문제는 FTA의 하향식 방향성과 게이트 논리를 정확히 구분해 보여야 한다.

---

## Ⅰ. 개요 및 필요성

- 개요: 정상사건에서 기본원인까지 AND/OR 게이트로 역추적하는 하향식 연역적 결함 분석 기법
- 배경: 1961년 벨연구소가 미사일 발사 통제 시스템 오작동 원인 분석을 위해 고안
- 필요성: 대형 사고나 시스템 장애의 원인 조합을 구조적으로 규명하려면 Top-down 논리 트리와 최소 컷셋 분석이 필요

---

## Ⅱ. 구조 및 구성요소

```text
Top Event(정상사건)
  -> OR/AND Gate -> 중간사건(Intermediate Event)
  -> OR/AND Gate -> 기본사건(Basic Event)
  -> 확률 대입 -> 최소 컷셋(Minimal Cut Set) 도출
```

| 구성요소 | 역할 | 특이사항 |
|:---|:---|:---|
| Top Event | 분석 대상 최상위 고장 | 트리 최상단에 위치 |
| AND Gate | 하위 사건 모두 발생해야 상위 사건 발생 | 확률은 곱셈 결합 |
| OR Gate | 하위 사건 중 하나만 발생해도 상위 사건 발생 | 확률은 합집합 결합 |
| Basic Event | 더 이상 분해되지 않는 기본원인 | 고장확률 데이터 필요 |
| Minimal Cut Set | Top Event를 유발하는 최소 기본사건 조합 | 단일 원소면 SPOF |

> 요약: FTA는 Top Event를 게이트 논리로 분해해 최소 컷셋과 기본사건 확률을 산출하는 구조다.

---

## Ⅲ. 동작원리 및 흐름도

```text
Top Event 정의 -> 직접 원인 식별(중간사건)
  -> AND/OR 게이트로 연결 -> 기본사건까지 반복 분해
  -> 기본사건 고장확률 대입 -> Top Event 발생확률 계산
  -> 최소 컷셋 도출 -> SPOF·고위험 조합 식별
```

| 단계 | 처리 내용 | 검증 기준 |
|:---:|:---|:---|
| 1 | 분석 대상 Top Event를 명확히 정의 | 사건 정의의 모호성 여부 |
| 2 | Top Event의 직접 원인을 게이트로 연결 | 게이트 종류 선정 근거 |
| 3 | 기본사건까지 반복 분해 | 분해 완결성, 누락 원인 여부 |
| 4 | 확률 대입 후 최소 컷셋과 발생확률 산출 | 컷셋 크기, SPOF 존재 여부 |

> 요약: FTA는 Top Event를 반복 분해해 기본사건에 도달한 뒤 확률 계산과 최소 컷셋 도출로 마무리한다.

---

## Ⅳ. 특징

| 구분 | 내용 | 판단 포인트 |
|:---|:---|:---|
| 장점 | Top Event 원인 조합을 정량적 확률로 표현 | Boolean 대수 기반 계산 가능 |
| 한계 | 사전에 식별되지 않은 원인은 트리에 반영 불가 | 브레인스토밍·체크리스트로 누락 보완 |
| 비교 포인트 | 하향식·연역적 방향, 결과에서 원인으로 이동 | ETA(상향식)와 방향이 반대 |

> 요약: FTA는 정량적 원인 분석에 강하지만 사전 식별 누락 원인에는 취약하다.

---

## Ⅴ. 심화 비교 및 적용 판단

| 구분 | FTA | ETA | 선택 기준 |
|:---|:---|:---|:---|
| 구조 | 하향식(top-down), Top Event에서 원인으로 역추적 | 상향식(bottom-up), 초기사건에서 결과로 순전개 | 분석 시작점이 결과인지 초기사건인지 |
| 분석 논리 | 연역적(deductive), AND/OR 게이트 | 귀납적(inductive), 성공/실패 분기 | 원인 규명 목적이면 FTA, 결과 예측 목적이면 ETA |
| 운영/위험 | 원인 누락 시 확률 과소 추정 | 분기 누락 시 결과 시나리오 과소 추정 | 두 기법을 bowtie로 결합해 상호 보완 |

> 요약: 원인 규명은 FTA, 결과 시나리오 예측은 ETA로 역할을 분리하고 필요 시 bowtie 기법으로 결합한다.

| 리스크 | 원인 | 대응 방안 | 확인 지표 |
|:---|:---|:---|:---|
| 원인 누락 | 브레인스토밍 부족, 신규 고장모드 미반영 | FMEA 결과를 기본사건 후보로 교차 검증 | 기본사건 커버리지율 |
| 확률 데이터 부실 | 기본사건 고장률 데이터 미확보 | 신뢰성 성장 모델·현장 이력 데이터 활용 | 데이터 출처 신뢰도 |
| SPOF 방치 | 최소 컷셋 크기 1 방치 | 이중화·다중 방어벽 설계 반영 | 단일 원소 컷셋 개수 |

> 요약: FTA 운영 리스크는 원인 누락과 확률 데이터 부실이 핵심이므로 FMEA·이력 데이터로 보완한다.

| 점검 항목 | 목표 기준 | 측정 방법 |
|:---|:---|:---|
| Top Event 발생확률 | 목표 허용확률 이하 | Boolean 대수 기반 확률 계산 |
| 최소 컷셋 관리 | 단일 원소 컷셋 0건 | 컷셋 분석 결과표 |
| 원인 커버리지 | FMEA 대비 기본사건 반영률 100% | 교차 검증 체크리스트 |

> 요약: FTA 성공 여부는 Top Event 확률, SPOF 컷셋 존재 여부, 원인 커버리지로 판단한다.

---

## Ⅵ. 실무 적용 및 결론

**적용 방안 3개 (필수 — 단계별 또는 항목별):**
1. 대형 장애·안전사고 대상 Top Event를 정의하고 AND/OR 게이트로 원인 트리를 구축함
2. 기본사건 고장확률 데이터를 확보해 Top Event 발생확률과 최소 컷셋을 계산함
3. 단일 원소 최소 컷셋(SPOF)을 식별해 이중화·다중 방어벽 설계로 제거함

**결론 (2줄):**
- 기술사 판단: 원인 규명이 목적이면 FTA를 우선 적용하고 ETA·FMEA와 상호 보완적으로 결합함
- 향후 방향: 정량 FTA 결과를 신뢰성 성장 모델과 연계해 원인 제거 효과를 MTBF 개선으로 검증해야 함

| 유형 | 문제 신호어 | Ⅲ 강조 | Ⅳ 강조 |
|:---|:---|:---|:---|
| 포괄형 | "FTA를 설명하시오" | 게이트 분해 절차, 최소 컷셋 도출 | ETA와의 방향 차이 |
| 비교형 | "FTA와 ETA를 비교하시오" | 하향식 vs 상향식 절차 대비 | 연역적·귀납적 논리 차이 |

> 요약: 설명형은 게이트 분해와 확률 계산, 비교형은 FTA·ETA의 방향성 차이 중심으로 답안 축을 바꾼다.
