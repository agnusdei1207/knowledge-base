## 미리 알고가기

- 도착률 $\lambda$: 단위 시간당 큐에 들어오는 요청 수임
- 서비스율 $\mu$: 처리 자원이 단위 시간당 처리할 수 있는 요청 수임
- 이용률 $\rho$: 처리 능력 대비 도착 부하의 비율이며 M/M/1에서는 $\rho = \lambda / \mu$임
- M/M/1: 포아송 도착, 지수 서비스 시간, 단일 서버를 가정한 큐 모델임
- M/M/c: 같은 조건에서 서버가 $c$개인 다중 서버 큐 모델임

## Ⅰ. 개요

- **정의/개념**: 큐잉 이론은 요청 도착, 대기열, 처리 자원의 관계를 수식으로 표현해 응답시간과 대기 길이를 예측하는 성능 평가 모델임
- **배경/필요성**: 처리 자원이 충분해 보여도 이용률이 높아지면 대기 시간이 급증하므로, 부하와 용량의 관계를 수치로 판단할 기준이 필요함

## Ⅱ. 특징

- 요청은 도착률과 서비스율의 관계로 해석하며 $\lambda$가 $\mu$에 가까워질수록 대기가 커짐
- 이용률 100%에 가까운 운영은 처리 자원을 모두 쓰는 상태가 아니라 대기 지연이 폭증하는 상태임
- M/M/1은 단일 병목 자원을 설명하기 쉽고 M/M/c는 서버 풀과 병렬 처리 효과를 설명함
- 모델 가정이 단순하므로 실제 시스템에서는 실측값으로 도착 분포와 서비스 시간을 보정해야 함

## Ⅲ. 종류 및 비교

| 판단 기준 | M/M/1 | M/M/c |
|:---|:---|:---|
| 처리 자원 | 서버 1개가 요청을 순차 처리함 | 서버 $c$개가 요청을 나누어 처리함 |
| 주요 활용 | 단일 DB, 단일 큐, 단일 병목 자원 분석 | WAS 풀, 상담원, 서버 풀 용량 산정 |
| 해석 초점 | 이용률 증가에 따른 대기 시간 급증 | 서버 수 증가에 따른 대기 완화 |
| 주의점 | 단일 서버 가정이 강해 분산 구조를 과소표현함 | 서버 간 부하 분산과 동기화 비용을 따로 봐야 함 |

## Ⅳ. 구성요소 및 구조

| 구성요소 | 설명 |
|:---|:---|
| 입력 흐름 | 요청 도착률 $\lambda$를 정의해 시스템에 들어오는 부하를 표현함 |
| 대기열 | 요청이 처리 자원을 기다리는 위치이며 큐 길이와 대기 시간이 응답시간을 키움 |
| 처리 자원 | 서비스율 $\mu$와 서버 수 $c$로 처리 능력을 표현함 |
| 출력 흐름 | 완료 처리량과 응답시간으로 모델 예측값을 운영 기준과 비교함 |

```text
+---------+     +---------+     +---------+     +---------+
| 도착 요청  | --> | 대기열    | --> | 처리 자원  | --> | 완료 응답  |
+---------+     +---------+     +---------+     +---------+
    lambda                         mu, c
```

## Ⅴ. 원리 및 절차 흐름도

```text
+---------+     +---------+     +---------+     +---------+
| 부하 측정  | --> | 모델 선택  | --> | 지표 계산  | --> | 용량 판단  |
+---------+     +---------+     +---------+     +---------+
```

1. **부하 측정**: 도착률, 서비스 시간, 동시 요청 수를 측정함
2. **모델 선택**: 단일 자원은 M/M/1, 서버 풀은 M/M/c로 단순화함
3. **지표 계산**: 이용률, 평균 대기 시간, 평균 큐 길이를 계산함
4. **용량 판단**: 목표 응답시간을 넘는 구간에서 처리 자원 조정 여부를 판단함

## Ⅵ. 실무 적용 및 유의점

1. 콜센터, WAS, DB connection pool 용량 산정에서는 평균 처리시간만 보지 말고 대기열 증가를 함께 봐야 하므로 utilization, queue length, p95 wait time으로 확인함
2. 실제 서비스는 요청 도착이 균일하지 않으므로 큐잉 모델 결과를 그대로 쓰지 말고 피크 구간 실측값으로 보정하고 예측 오차율로 확인함

## Ⅶ. 결론

큐잉 이론은 자원을 얼마나 쓰는지보다 요청이 기다리는 구조를 수치화해 이용률, 대기 시간, 용량 사이의 한계를 판단하게 함.

## 작성 근거(검토용)

- 131회 기출 키워드이므로 M/M/1, M/M/c, $\lambda$, $\mu$, $\rho$를 미리 설명해 답안 이해를 막지 않게 함
- 넓은 평가어를 쓰지 않고 이용률과 대기 시간의 관계로 직접 설명함
- 실무 절은 용량 산정과 모델 보정에 한정해 수식 나열에서 운영 판단으로 이어지게 함
