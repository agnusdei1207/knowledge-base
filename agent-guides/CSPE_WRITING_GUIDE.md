# 노트 작성·교정 기준

## 어려운 개념의 정의

어려운 개념일수록 설명을 늘이지 말고, 개념을 구별하는 **직관적 핵심 키워드**만 남겨 한 문장으로 압축한다.

- 기본 형식: `용어: 핵심 대상 + 핵심 성질`
- 정의에는 원리·예시·주의사항을 한꺼번에 넣지 않는다.
- “그럴듯한 정도” 같은 구어적 표현보다 `적합도`, `일관성`, `격리`, `복원력`처럼 개념을 구별하는 표준 용어를 쓴다.
- 수식어를 빼도 의미가 유지되면 뺀다.
- 세부 원리와 비교 예시는 정의 다음 본문에서 설명한다.

### 교정 절차

1. 긴 설명에서 개념의 대상과 구별되는 성질을 찾는다.
2. 핵심 키워드 한두 개만 남긴다.
3. 중복되는 주어·수식어·비유를 제거한다.
4. 한 번 읽어 뜻이 잡히는 한 문장인지 확인한다.
5. 정확성을 해치지 않는 범위에서 더 줄인다.

### 기준 사례

우도 정의는 다음과 같이 발전했다.

1. `관측한 데이터를 고정했을 때, 각 가설이나 모델이 그 데이터를 얼마나 그럴듯하게 설명하는지를 나타내는 값`
2. `특정 가설이 관측된 결과 데이터를 얼마나 잘 설명하는지를 나타내는 값`
3. `관측된 결과 데이터에 대한 가설의 적합도를 수치화한 값`
4. `가설의 적합도를 나타내는 수치`

1단계에서 `관측된 결과 데이터`와 `가설`의 관계를 명확히 하고, 모호한 `그럴듯하게`를 표준 핵심어인 `적합도`로 바꿨다. 그다음 정의에 없어도 되는 관측 조건과 중복 표현을 제거해 `가설`, `적합도`, `수치`만 남겼다.

핵심 정의만으로 부족한 확률과 우도의 차이, 동전 예시, 최대 우도 추정은 본문에서 분리해 설명한다.
