## 빌드

- 빌드 명령은 `npm.cmd run build`이며, 의존성이 없으면 `npm.cmd ci`를 먼저 실행한다.
- 알려진 기존 경고는 `Entry docs → 404 was not found` 하나이며 새 오류와 구분한다.
- 과목 완료·설정/의존성 변경·렌더링 오류 의심 시에만 실행한다.

## 작업 트리 보호

- `src/styles/custom.css`의 미커밋 변경과 루트 `.bashrc`는 사용자 작업이므로 건드리지 않는다.
- 현재 체크포인트 범위 밖 변경을 수정·원복하지 않는다.
- `git add .`와 `git add -A`를 쓰지 않고, 이번 체크포인트의 정확한 파일 경로와 이 문서만 스테이징한다.
